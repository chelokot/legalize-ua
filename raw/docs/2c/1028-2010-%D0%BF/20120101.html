КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 листопада 2010 р. N 1028 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

Про внесення змін у додатки 3 і 4 до постанови Кабінету Міністрів України від 3 вересня 2005 р. N 865

Кабінет Міністрів України постановляє:

1. Внести у додатки 3 і 4 до постанови Кабінету Міністрів України від 3 вересня 2005 р. N 865 ( 865-2005-п ) "Про оплату праці та щомісячне грошове утримання суддів" (Офіційний вісник України, 2005 р., N 36, ст. 2195; 2006 р., N 1-2, ст. 32; 2008 р., N 6, ст. 144) такі зміни:

у графі "Посада" додатка 3 ( 865-2005-п ) позицію "Заступник голови судової палати, секретар Пленуму вищого спеціалізованого суду" замінити такою позицією:

"Заступник голови судової палати, секретар судової палати, секретар Пленуму вищого спеціалізованого суду";

у графі "Посада" додатка 4 ( 865-2005-п ) позицію "Заступник голови судової палати" замінити такою позицією:

"Заступник голови судової палати, секретар судової палати".

2. Умови оплати праці суддів, призначених на посади секретарів судових палат, застосовуються з дня призначення їх на посади.
