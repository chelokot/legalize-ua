Кабінет Міністрів України; Постанова від 30.05.2011 № 609

Про внесення зміни до пункту 1 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

Стан: Втратив чинність

Ідентифікатор: 609-2011-п

Текст документа від 12.03.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 травня 2011 р. N 609 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 65 ( 65-2014-п ) від 01.03.2014 }

Про внесення зміни до пункту 1 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

Кабінет Міністрів України постановляє:

Внести зміну до пункту 1 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів, затверджених постановою Кабінету Міністрів України від 22 жовтня 2008 р. N 943 ( 943-2008-п ) "Про економію бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів" (Офіційний вісник України, 2008 р., N 84, ст. 2816; 2009 р., N 45, ст. 1507, N 83, ст. 2823, N 95, ст. 3269; 2010 р., N 5, ст. 200, N 60, ст. 2094, N 74, ст. 2621, N 81, ст. 2847, N 96, ст. 3403, ст. 3406, N 98, ст. 3494, N 100, ст. 3550; 2011 р., N 2, ст. 111, N 26, ст. 1069), доповнивши його після слів "усіх бюджетних установ" словами ", а також придбання меблів для приміщень після проведення в них капітального ремонту чи реконструкції".

Прем'єр-міністр України М.АЗАРОВ
