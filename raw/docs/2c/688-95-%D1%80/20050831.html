Кабінет Міністрів України; Розпорядження від 10.11.1995 № 688-р

Про дозвіл державному підприємству "Севастопольський морський завод" на реалізацію за кордон суден

Стан: Втратив чинність

Ідентифікатор: 688-95-р

Текст документа від 31.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 листопада 1995 р. N 688-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 832 ( 832-2005-п ) від 31.08.2005 )

Для компенсації витрат державного підприємства "Севастопольський морський завод", пов'язаних з виконанням ремонтних робіт на кораблях Чорноморського флоту, дозволити цьому підприємству в установленому порядку реалізувати за кордон списані великий протичовновий корабель "Красный Крым", суден постачання "Виктор Котельников" і "Гаджиев" ( у нерозібраному стані).

Прем'єр-міністр України Є.МАРЧУК
