Про звільнення від обкладення прибутковим податком з громадян грошової частини щорічної премії для переможців Міжнародного конкурсу з української мови імені Петра Яцика

Стан: Втратив чинність

Ідентифікатор: 530-2003-п

Текст документа від 01.01.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 квітня 2003 р. N 530 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1628 ( 1628-2003-п ) від 15.10.2003 )

Про звільнення від обкладення прибутковим податком з громадян грошової частини щорічної премії для переможців Міжнародного конкурсу з української мови імені Петра Яцика

Відповідно до пункту 5 статті 6 Декрету Кабінету Міністрів України від 26 грудня 1992 р. N 13-92 ( 13-92 ) "Про прибутковий податок з громадян" Кабінет Міністрів України постановляє:

Звільнити від обкладення прибутковим податком з громадян грошову частину щорічної премії для переможців Міжнародного конкурсу з української мови імені Петра Яцика.

Прем'єр-міністр України В.ЯНУКОВИЧ
