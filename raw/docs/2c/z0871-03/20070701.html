ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

09.09.2003 N 389

Зареєстровано в Міністерстві юстиції України 29.09.2003 р. за N 871/8192

Про затвердження Положення про порядок подання банками до Національного банку України аудиторських звітів за результатами щорічної перевірки фінансової звітності

{ Із змінами, внесеними згідно з Постановами Національного банку N 368 ( z1088-06 ) від 20.09.2006 N 135 ( z0423-07 ) від 13.04.2007 }

Відповідно до статті 69 Закону України "Про банки і банківську діяльність" ( 2121-14 ) та з метою реалізації стратегічного курсу України на інтеграцію до Європейського Союзу, урегулювання процесів нагляду за дотриманням банками вимог законодавства України щодо подання фінансової звітності до Національного банку України і її щорічної перевірки та підтвердження аудитором (аудиторською фірмою) Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити Положення про порядок подання банками до Національного банку України аудиторських звітів за результатами щорічної перевірки фінансової звітності (далі - Положення), що додається. { Пункт 1 із змінами, внесеними згідно з Постановою Національного банку N 368 ( z1088-06 ) від 20.09.2006 }

2. Визнати таким, що втратило чинність, Положення про порядок подання до Національного банку України аудиторського звіту та висновку за результатами перевірки річної фінансової звітності банку, затверджене постановою Правління Національного банку України від 28.01.2002 N 38 ( z0231-02 ) та зареєстроване в Міністерстві юстиції України 06.03.2002 за N 231/6519 (із змінами).

3. Банки мають забезпечити виконання вимог Положення, починаючи з подання фінансової звітності за 2003 рік.

4. Генеральному департаменту банківського нагляду (В.В.Пушкарьов) після державної реєстрації в Міністерстві юстиції України довести зміст цієї постанови до відома територіальних управлінь Національного банку України та банків для керівництва в роботі.

5. Контроль за виконанням цієї постанови покласти на заступника Голови О.В.Шлапака, Генеральний департамент банківського нагляду (В.В.Пушкарьов) та начальників територіальних управлінь Національного банку України.

6. Постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

Голова С.Л.Тігіпко

ЗАТВЕРДЖЕНО Постанова Правління Національного банку України 09.09.2003 N 389

Зареєстровано в Міністерстві юстиції України 29.09.2003 р. за N 871/8192

ПОЛОЖЕННЯ про порядок подання банками до Національного банку України аудиторських звітів за результатами щорічної перевірки фінансової звітності

{ У назві та тексті Положення слова "(аудиторських висновків)" у всіх відмінках виключено згідно з Постановою Національного банку N 368 ( z1088-06 ) від 20.09.2006 }

1. Загальні положення

1.1. Це Положення встановлює вимоги до банків щодо порядку подання до Національного банку України (далі - Національний банк) аудиторських звітів про результати щорічної перевірки аудитором (аудиторською фірмою) фінансової звітності та консолідованої фінансової звітності (далі - аудит) банків, що подається до Національного банку. { Пункт 1.1 глави 1 із змінами, внесеними згідно з Постановою Національного банку N 368 ( z1088-06 ) від 20.09.2006 }

1.2. Положення розроблено на підставі Законів України "Про Національний банк України" ( 679-14 ), "Про банки і банківську діяльність" ( 2121-14 ), "Про аудиторську діяльність" ( 3125-12 ) та нормативно-правових актів Національного банку.

1.3. Положення розроблене з метою врегулювання процесів нагляду за дотриманням банками вимог законодавства України, у тому числі нормативно-правових актів Національного банку, щодо подання фінансової звітності до Національного банку та її щорічної перевірки аудитором (аудиторською фірмою). { Пункт 1.3 глави 1 в редакції Постанови Національного банку N 368 ( z1088-06 ) від 20.09.2006 }

1.4. Вимоги Положення поширюються на банки, що зареєстровані на території України та згідно з вимогами законодавства України зобов'язані подавати до Національного банку фінансову звітність, щорічно перевірену аудитором (аудиторською фірмою) відповідно до положень статті 69 Закону України "Про банки і банківську діяльність" ( 2121-14 ).

1.5. Об'єктом аудиту є річна фінансова звітність та консолідована фінансова звітність, що визначені законодавством України, у тому числі нормативно-правовими актами Національного банку, і подаються до Національного банку та підлягають публікації в газеті "Голос України" чи "Урядовий кур'єр" у встановленому законодавством України порядку. { Пункт 1.5 глави 1 в редакції Постанови Національного банку N 368 ( z1088-06 ) від 20.09.2006 }

2. Вимоги до банків щодо подання до Національного банку перевіреної та підтвердженої аудитором (аудиторською фірмою) фінансової звітності

2.1. Річна фінансова звітність (консолідована фінансова звітність), що подається банком до Національного банку та підлягає оприлюдненню, має бути перевірена аудитором (аудиторською фірмою) з метою надання аудитором висновку, що вона складена відповідно до законодавства України та справедливо і достовірно (або достовірно в усіх суттєвих аспектах) відображає (або не відображає) дійсний фінансовий стан банку. { Пункт 2.1 глави 2 в редакції Постанови Національного банку N 368 ( z1088-06 ) від 20.09.2006; із змінами, внесеними згідно з Постановою Національного банку N 135 ( z0423-07 ) від 13.04.2007 }

2.2. Банки зобов'язані подавати до Національного банку висновки про аудит банку після їх розгляду та затвердження загальними зборами учасників у складі звіту, що складаються та підписуються аудитором (або керівником аудиторської фірми), який включений до реєстру аудиторів банків Національного банку. { Пункт 2.2 глави 2 в редакції Постанов Національного банку N 368 ( z1088-06 ) від 20.09.2006, N 135 ( z0423-07 ) від 13.04.2007 }

2.3. Звіт аудитора (аудиторської фірми) щодо підтвердження (або не підтвердження) достовірності, повноти та відповідності законодавству України річної фінансової звітності (консолідованої фінансової звітності), що подається банками до Національного банку, має бути складений згідно з вимогами законодавства України, у тому числі відповідати вимогам Міжнародних стандартів аудиту, надання впевненості та етики, що прийняті як Національні стандарти аудиту відповідним рішенням Аудиторської палати України (далі - Стандарти). { Пункт 2.3 глави 2 в редакції Постанови Національного банку N 368 ( z1088-06 ) від 20.09.2006 }

2.4. Перед проведенням аудиту банк має укласти з аудитором (аудиторською фірмою) договір на проведення обов'язкового аудиту, у якому передбачається предмет і термін перевірки, обсяг аудиторських послуг, розмір і умови оплати, відповідальність сторін (далі - договір). Договір має відповідати вимогам законодавства України, у тому числі цього Положення, та Стандартів.

До часу укладання договору банк зобов'язаний перевірити наявність в аудитора, який проводитиме аудит банку, права на здійснення такого аудиту.

Банк має подати до Національного банку та відповідного територіального управління Національного банку до 1 листопада поточного року, за який здійснюється аудит, по одному примірнику копії договору.

У разі внесення в установленому порядку змін до договору банк протягом п'яти днів з дня їх внесення має подати засвідчену банком копію цих змін до Національного банку та відповідного територіального управління Національного банку.

{ Пункт 2.4 глави 2 в редакції Постанов Національного банку N 368 ( z1088-06 ) від 20.09.2006, N 135 ( z0423-07 ) від 13.04.2007 }

2.5. Банк не має права укладати договір з аудитором (аудиторською фірмою), якому згідно із законами України, Стандартами заборонено проводити аудит у цьому банку, якщо: { Абзац перший пункту 2.5 глави 2 із змінами, внесеними згідно з Постановами Національного банку N 368 ( z1088-06 ) від 20.09.2006, N 135 ( z0423-07 ) від 13.04.2007 }

аудитор (керівник аудиторської фірми) має прямі родинні стосунки з керівниками банку;

аудитор (аудиторська фірма) має особисті майнові інтереси в банку;

аудитор (керівник аудиторської фірми) є членом керівництва, засновником або власником банку;

аудитор (керівник аудиторської фірми) є працівником банку;

аудитор (керівник аудиторської фірми) є працівником, співвласником дочірнього підприємства банку;

розмір винагороди за надання аудиторських послуг не враховує необхідного для якісного виконання таких послуг часу, належних навичок, знань, професійної кваліфікації та ступінь відповідальності аудитора; { Пункт 2.5 глави 2 доповнено абзацом згідно з Постановою Національного банку N 135 ( z0423-07 ) від 13.04.2007 }

наявні інші випадки, за яких не забезпечуються вимоги щодо незалежності аудитора. { Пункт 2.5 глави 2 доповнено абзацом згідно з Постановою Національного банку N 368 ( z1088-06 ) від 20.09.2006 }

2.6. Якщо за результатами розгляду укладеного банком договору Національний банк з'ясує, що договір укладений з порушенням вимог законодавства України, у тому числі цього Положення, або з аудитором (аудиторською фірмою), який не дотримується Стандартів, то Національний банк пропонує банку внести зміни до цього договору або укласти договір з іншим аудитором (аудиторською фірмою). { Абзац перший пункту 2.6 із змінами, внесеними згідно з Постановою Національного банку N 135 ( z0423-07 ) від 13.04.2007 }

Національний банк рекомендує банкам у разі проведення аудиту не перевищувати тривалість договірних відносин між банком та однією і тією самою аудиторською фірмою (аудитором) більше ніж п'ять років поспіль.

{ Пункт 2.6 глави 2 в редакції Постанови Національного банку N 368 ( z1088-06 ) від 20.09.2006 }

2.7. Недійсними є будь-які положення договору, спрямовані на повне звільнення аудитора (аудиторської фірми) від установленої законом майнової відповідальності за недостовірність аудиторського звіту, у якому відображені результати аудиту банку. { Главу 2 доповнено пунктом 2.7 згідно з Постановою Національного банку N 135 ( z0423-07 ) від 13.04.2007 }

2.8. Банк зобов'язаний створити аудитору (аудиторській фірмі) належні умови для якісного проведення аудиту.

Банку забороняється вчиняти дії, що обмежують доступ аудитора (аудиторської фірми) до бухгалтерських та інших документів, які підлягають аудиту, впливати на аудитора або створювати умови, що перешкоджають підготовці об'єктивного аудиторського звіту.

Керівники банку несуть персональну відповідальність за повноту та достовірність бухгалтерських та інших документів, які надаються аудитору (аудиторській фірмі) для проведення аудиту.

2.9. Аудитор (аудиторська фірма) самостійно визначає форми і методи аудиту на підставі законодавства України і Стандартів.

Банк разом з аудитором (аудиторською фірмою) визначає ті філії банку, які підлягатимуть аудиту.

2.10. У разі виявлення Національним банком за результатами інспекційної перевірки банку фактів порушень аудитором (аудиторською фірмою) умов проведення аудиту, що передбачені пунктом 2.5 цього Положення, банк за рішенням Комітету з питань аудиту банків повинен в установленому порядку здійснити повторний аудит іншим аудитором (аудиторською фірмою) до початку нового звітного періоду (рік). { Главу 2 доповнено пунктом 2.10 згідно з Постановою Національного банку N 135 ( z0423-07 ) від 13.04.2007 }

2.11. Усі спори щодо невиконання умов договору, а також спори майнового характеру між аудитором (аудиторською фірмою) та банком вирішуються у встановленому законодавством України порядку. { Главу 2 доповнено пунктом 2.11 згідно з Постановою Національного банку N 135 ( z0423-07 ) від 13.04.2007 }

3. Порядок подання до Національного банку аудиторського звіту

3.1. Після завершення аудиту банк має отримати від аудитора (аудиторської фірми) аудиторський звіт про перевірку річної фінансової звітності (далі - аудиторський звіт), кількість примірників якого обумовлюється договором, але не менше трьох. { Пункт 3.1 глави 3 в редакції Постанови Національного банку N 135 ( z0423-07 ) від 13.04.2007 }

3.2. Банк зобов'язаний подати по одному примірнику аудиторського звіту до підрозділу банківського нагляду Національного банку та до відповідного підрозділу територіального управління Національного банку, на які покладено функції моніторингу та інспектування діяльності банків, щорічно не пізніше 30 квітня року, наступного за звітним, а про перевірку річної консолідованої фінансової звітності не пізніше 15 травня року, наступного за звітним. { Пункт 3.2 глави 3 в редакції Постанов Національного банку N 368 ( z1088-06 ) від 20.09.2006, N 135 ( z0423-07 ) від 13.04.2007 }

3.3. Аудиторський звіт, який складається відповідно до вимог законодавства України та Стандартів, має містити:

висновок аудитора (безумовно-позитивна, умовно-позитивна думка, відмова від висловлення думки, негативна думка) про відповідність (невідповідність) дійсного фінансового стану банку складеній банком річній фінансовій звітності та консолідованій фінансовій звітності;

річну фінансову звітність та консолідовану фінансову звітність, які складені банком в обсязі, що відповідає вимогам Інструкції про порядок складання та оприлюднення фінансової звітності банків України, затвердженої постановою Правління Національного банку України від 07.12.2004 N 598 ( z1660-04 ) і зареєстрованої в Міністерстві юстиції України 28.12.2004 за N 1660/10259 (із змінами);

інформацію стосовно: { Абзац четвертий пункту 3.3 в редакції Постанови Національного банку N 135 ( z0423-07 ) від 13.04.2007 }

відповідності обсягу активів і зобов'язань банку за строками погашення, яка має базуватися на підставі аналізу статистичної форми N 631 ( za353-03 ) "Звіт про структуру активів та пасивів за строками", затвердженої постановою Правління Національного банку України від 19.03.2003 N 124 ( za353-03 ) і зареєстрованої в Міністерстві юстиції України 07.05.2003 за N 353/7674 (із змінами), якості управління активами та пасивами банку;

якості кредитного портфеля та портфеля цінних паперів, стану дебіторської заборгованості;

достатності резервів та капіталу банку, у тому числі щодо відповідності формування капіталу банку, фондів, резервів вимогам нормативно-правових актів Національного банку, а також оцінку ризиків банківських операцій та операцій з інсайдерами/пов'язаними особами;

адекватності бухгалтерського обліку, процедур внутрішнього аудиту та заходів контролю банку.

3.4. У разі потреби проведення аудиту на вимогу іноземних фінансових установ та організацій банк повинен проінформувати про це підрозділ банківського нагляду Національного банку, на який покладено функції моніторингу та інспектування діяльності банків, та надати йому результати такого аудиту банку в місячний термін після його закінчення, додатково до звіту, підготовленого згідно з вимогами цього Положення. { Главу 3 доповнено пунктом 3.4 згідно з Постановою Національного банку N 368 ( z1088-06 ) від 20.09.2006 }

3.5. Аудиторський звіт, який подається до Національного банку (у тому числі відповідного територіального управління Національного банку), має бути підписаний аудитором (керівником аудиторської фірми), який включений до реєстру аудиторів банків Національного банку та проводив аудит, викладений українською мовою, зброшурований та засвідчений відбитком печатки аудитора (аудиторської фірми). На зворотному боці останньої сторінки робиться такий напис: "Прошнуровано, пронумеровано та скріплено відбитком печатки (кількість) сторінок". { Пункт 3.5 глави 3 із змінами, внесеними згідно з Постановами Національного банку N 368 ( z1088-06 ) від 20.09.2006, N 135 ( z0423-07 ) від 13.04.2007 }

3.6. Аудиторський звіт аудитора (аудиторської фірми) іноземної держави, підтверджений аудитором (аудиторською фірмою) України, банк подає до Національного банку та відповідного територіального управління Національного банку згідно з вимогами законодавства України, Стандартів.

3.7. Подання до Національного банку аудиторського звіту, що не відповідає вимогам законодавства України, цього Положення та Стандартів, не своєчасне його подання уважається невиконанням банком вимог законодавства України щодо подання до Національного банку достовірної фінансової звітності, що перевірена та підтверджена аудитором (аудиторською фірмою). { Абзац перший пункту 3.7 глави 3 із змінами, внесеними згідно з Постановою Національного банку N 368 ( z1088-06 ) від 20.09.2006 }

Національний банк інформує банк про подання аудиторського звіту, що не відповідає вимогам законодавства України, а також про невиконання банком вимог щодо підтвердження його фінансової звітності.

Банк у порядку, визначеному законодавством України, звертається до аудитора (аудиторської фірми), який проводив аудит банку, для доопрацювання аудиторського звіту з метою приведення його у відповідність до вимог законодавства України, Стандартів або звертається до іншого аудитора (аудиторської фірми), який включений до реєстру аудиторів банків Національного банку. { Абзац третій пункту 3.7 глави 3 із змінами, внесеними згідно з Постановою Національного банку N 135 ( z0423-07 ) від 13.04.2007 }

3.8. У разі отримання банком від аудитора (аудиторської фірми) аудиторського звіту, що містить відмову від підтвердження (відмову від висловлення думки, негативну думку) достовірності, повноти та відповідності законодавству України його фінансової звітності, банк протягом п'яти робочих днів має повідомити про це Національний банк та відповідне територіальне управління Національного банку, надіславши аудиторський звіт та пояснення щодо причин виникнення такої ситуації.

3.9. У разі порушення банками вимог законодавства України, у тому числі цього Положення та інших нормативно-правових актів Національного банку з питань подання фінансової звітності, яка має бути щорічно перевірена та підтверджена аудитором (аудиторською фірмою), Національний банк застосовує до банків адекватні заходи впливу. { Пункт 3.9 глави 3 із змінами, внесеними згідно з Постановою Національного банку N 135 ( z0423-07 ) від 13.04.2007 }
