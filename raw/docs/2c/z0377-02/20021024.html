( Із змінами, внесеними згідно з Наказами УДППЗ "Укрпошта" N 163 ( z0440-02 ) від 07.05.2002 - вводяться у дію з 1 липня 2002 року

N 205 ( z0540-02 ) від 11.06.2002 )

Відповідно до Закону України "Про поштовий зв'язок" ( 2759-14 ), Правил надання послуг поштового зв'язку, затверджених постановою Кабінету Міністрів України від 04.10.2000 N 1515 ( 1515-2000-п ), та з метою впорядкування тарифів на інші послуги поштового зв'язку НАКАЗУЮ:

1. Затвердити Тарифи на інші послуги поштового зв'язку (далі - тарифи), що додаються, та ввести їх у дію у відповідності до діючого законодавства України.

2. Директорам філіалів УДППЗ "Укрпошта":

2.1. Довести тарифи до відома всіх відособлених виробничих підрозділів, які надають послуги споживачам.

2.2. Забезпечити своєчасне та правильне застосування тарифів.

2.3. Інформувати споживачів про нову редакцію тарифів.

3. Наказ УДППЗ "Укрпошта" від 02.01.2002 N 3 ( z0021-02 ), зареєстрований Міністерством юстиції України 10.01.2002 за N 21/6309, уважати таким, що втратив чинність.

4. Контроль за виконанням даного наказу покласти на директора з питань економіки та фінансів Л.В.Кузнецову.

ЗАТВЕРДЖЕНО Наказ Українського державного підприємства поштового зв'язку "Укрпошта" 03.04.2002 N 127

Зареєстровано в Міністерстві юстиції України 19 квітня 2002 р. за N 377/6665

Тарифи на інші послуги поштового зв'язку

Загальні положення

1. Ці Тарифи застосовуються всіма об'єктами поштового зв'язку УДППЗ "Укрпошта", що надають послуги споживачам.

2. Вартість бланків, що використовуються при наданні послуг поштового зв'язку, враховано в тарифах на ці послуги.

3. Ці Тарифи встановлені без урахування податку на додану вартість, який стягується додатково, відповідно до Закону України "Про податок на додану вартість" ( 168/97-ВР ).

4. Філіали підприємства з дозволу УДППЗ "Укрпошта" мають право знижувати рівень Тарифів не більш як на 20 відсотків.

5. Зміни та доповнення до цих Тарифів уносяться на підставі наказу УДППЗ "Укрпошта" та реєструються в Міністерстві юстиції України.

6. Оплата користувачами послуг поштового зв'язку з країнами СНД та іншими іноземними державами провадиться в національній валюті України. Розмір оплати визначається із застосуванням курсу гривні до іноземної валюти, що встановлюється Національним банком України на момент надання послуги. До країн СНД віднесені: Азербайджан, Білорусь, Вірменія, Грузія, Казахстан, Киргизстан, Молдова, Росія, Таджикистан, Туркменістан, Узбекистан.

Тарифи на доставку рекламних матеріалів по Україні встановлені без урахування податку на рекламу, який стягується додатково, відповідно до діючого законодавства України.

Адресна доставка рекламних матеріалів здійснюється за тарифами на пересилання простих листів у межах України відповідно до розділу I, ст.2, поз.2; ст.6, поз.7 Тарифів на універсальні послуги поштового зв'язку ( z0020-02 ).

за інших обставин - сплачує об'єкт поштового зв'язку УДППЗ "Укрпошта".
