КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 листопада 2007 р. N 1360 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 198 ( 198-2008-п ) від 19.03.2008 }

Деякі питання Державної акціонерної компанії "Укрресурси"

Кабінет Міністрів України постановляє:

1. Покласти на Державний комітет державного матеріального резерву виконання повноважень уповноваженого органу управління щодо Державної акціонерної компанії "Укрресурси", передбачених статтею 6 Закону України "Про управління об'єктами державної власності" ( 185-16 ) стосовно господарських структур.

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

3. Державному комітетові з державного матеріального резерву розробити в місячний строк та затвердити нову редакцію Статуту Державної акціонерної компанії "Укрресурси".

4. Ця постанова набирає чинності з дня її прийняття, крім пункту 2, який набирає чинності з 20 грудня 2007 року.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 18

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 листопада 2007 р. N 1360

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Пункти 3 і 6 постанови Кабінету Міністрів України від 21 січня 1995 р. N 46 ( 46-95-п ) "Питання Державної акціонерної компанії "Укрресурси".

2. Постанова Кабінету Міністрів України від 3 квітня 1995 р. N 233 ( 233-95-п ) "Про доповнення Статуту Державної акціонерної компанії "Укрресурси".

3. Постанова Кабінету Міністрів України від 30 серпня 1995 р. N 701 ( 701-95-п ) "Про внесення змін до Статуту Державної акціонерної компанії "Укрресурси".

4. Постанова Кабінету Міністрів України від 25 вересня 1995 р. N 757 ( 757-95-п ) "Про внесення змін до складу спостережної ради Державної акціонерної компанії "Укрресурси".

5. Пункт 1 змін та доповнень, що вносяться до деяких рішень Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 18 грудня 1996 р. N 1521 ( 1521-96-п ) "Про внесення змін до статутного фонду Державної акціонерної компанії "Укрресурси".

6. Постанова Кабінету Міністрів України від 16 жовтня 1997 р. N 1146 ( 1146-97-п ) "Про внесення змін до складу спостережної ради Державної акціонерної компанії "Укрресурси".

7. Постанова Кабінету Міністрів України від 29 листопада 1997 р. N 1330 ( 1330-97-п ) "Про доповнення Статуту Державної акціонерної компанії "Укрресурси".

8. Пункт 1 змін та доповнень, що вносяться до деяких рішень Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 15 грудня 1997 р. N 1390 ( 1390-97-п ) "Про зміну статутного фонду Державної акціонерної компанії "Укрресурси".

9. Пункт 1 змін та доповнень, що вносяться до деяких рішень Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 5 травня 1998 р. N 597 ( 597-98-п ) "Про зміну статутного фонду Державної акціонерної компанії "Укрресурси".

10. Пункт 6 змін, що вносяться до актів Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 25 серпня 1998 р. N 1336 ( 1336-98-п ) "Про внесення змін до деяких актів Кабінету Міністрів України з питань діяльності державної податкової служби" (Офіційний вісник України, 1998 р., N 34, ст. 1277).

11. Пункт 5 постанови Кабінету Міністрів України від 19 серпня 1999 р. N 1538 ( 1538-99-п ) "Про зміну статутного фонду Державної акціонерної компанії "Укрресурси".

12. Постанова Кабінету Міністрів України від 11 квітня 2002 р. N 503 ( 503-2002-п ) "Деякі питання Державного комітету з державного матеріального резерву" (Офіційний вісник України, 2002 р., N 15, ст. 819).

13. Постанова Кабінету Міністрів України від 25 грудня 2002 р. N 1963 ( 1963-2002-п ) "Про внесення зміни до Статуту Державної акціонерної компанії "Укрресурси" (Офіційний вісник України, 2002 р., N 52, ст. 2383).

14. Постанова Кабінету Міністрів України від 26 квітня 2003 р. N 602 ( 602-2003-п ) "Про внесення зміни до Статуту Державної акціонерної компанії "Укрресурси" (Офіційний вісник України, 2003 р., N 18-19, ст. 821).
