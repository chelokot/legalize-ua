Про створення умов для випуску суден Чорноморським суднобудівним заводом

Стан: Втратив чинність

Ідентифікатор: 405-93-п

Текст документа від 29.11.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 червня 1993 р. N 405 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 957 ( 957-95-п ) від 29.11.95 }

Про створення умов для випуску суден Чорноморським суднобудівним заводом

{ Постанова втратила чинність у частині, що стосується питань оподаткування, на підставі Постанови КМ N 644 ( 644-94-п ) від 19.09.94 }

З метою створення умов для випуску транспортних і промислових суден Чорноморським суднобудівним заводом і виконання укладених контрактів з іноземними фірмами в 1993 році Кабінет Міністрів України постановляє:

1. Звільнити Чорноморський суднобудівний завод від:

сплати податку на доходи та обов'язкового продажу на міжбанківському валютному ринку України надходжень в іноземній валюті, отриманій за поставку суден, в обсягах, що компенсують витрати на придбання комплектуючих виробів і матеріалів, технологічно необхідних для їх будівництва, у межах номенклатури, обумовленої контрактами та підтвердженої платіжними документами, а також усіх надходжень у російських рублях, отриманих за реалізацію продукції заводом;

сплати вивізного (експортного) і ввізного мита на комплектуючі вироби і матеріали, отримані за іноземну валюту і використані на будівництві суден.

2. Дозволити Чорноморському суднобудівному заводу у разі продажу суден на експорт з оплатою в розстрочку провадити розрахунки з бюджетом по податках на доходи і здійснювати обов'язковий продаж валюти згідно з чинним законодавством в міру одержання платежів в терміни, визначені умовами контрактів.
