КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 вересня 2005 р. N 400-р Київ

Про затвердження складу Комісії у справах осіб, депортованих за національною ознакою

{ Додатково див. Постанову КМ N 1493 ( 1493-99-п ) від 13.08.99 }

Затвердити склад Комісії у справах осіб, депортованих за національною ознакою, що додається.

Надати право голові Комісії вносити у разі потреби зміни до її складу.

Організаційне та матеріально-технічне забезпечення роботи Комісії покласти на Держкомнацміграції.
