Про внесення зміни до розпорядження Кабінету Міністрів України від 26 березня 2003 р. N 172

У розпорядженні Кабінету Міністрів України від 26 березня 2003 р. N 172 ( 172-2003-р ) "Про деякі заходи щодо забезпечення створення товариством з обмеженою відповідальністю "Співдружність ініціативних працездатних інвалідів" (м. Херсон) нових робочих місць для працевлаштування інвалідів" (із змінами, внесеними розпорядженнями Кабінету Міністрів України від 25 квітня 2003 р. N 254 ( 254-2003-р ) і від 11 березня 2004 р. N 131 ( 131-2004-р ) цифри "50 000" замінити цифрами "100 000".
