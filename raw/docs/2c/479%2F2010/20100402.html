Про ліквідацію Ради громадськості

Стан: Чинний

Ідентифікатор: 479/2010

Текст документа від 02.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про ліквідацію Ради громадськості

Відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Ліквідувати Раду громадськості.

У зв'язку з цим визнати такими, що втратили чинність:

Указ Президента України від 29 вересня 2006 року N 795 ( 795/2006 ) "Про Раду громадськості при Президентові України";

Указ Президента України від 23 лютого 2007 року N 139 ( 139/2007 ) "Питання Ради громадськості".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ
