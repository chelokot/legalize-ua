N 135 від 14.08.95 Зареєстровано в Міністерстві м.Київ юстиції України 21 серпня 1995 р. vd950814 vn135 за N 307/843

Про рівень роздрібних цін на енергоносії

( Із змінами, внесеними згідно з Наказом Міністерства економіки N 185 ( z0470-95 ) від 20.12.1995 )

З метою часткового відшкодування витрат, пов'язаних з реалізацією енергоносіїв населенню, та згідно з повноваженнями, затвердженими постановою Кабінету Міністрів України від 13 лютого 1995 року N 109 ( 109-95-п ) "Про уточнення повноважень центральних органів державної виконавчої влади, Уряду Автономної Республіки Крим та виконкомів місцевих Рад у галузі ціноутворення", НАКАЗУЮ:

1. Затвердити граничні розміри роздрібних цін на енергоносії, що відпускаються на комунально-побутові потреби населенню, додаються.

2. Вважати такими, що втратили чинність, граничні розміри роздрібних цін на газ сітьовий і вугілля та вугільні брикети, затверджені наказом Мінекономіки України від 19.05.95 р. N 78 ( z0144-95 ) і додаток N 1 до наказу Мінекономіки України від 17.02.95 р. N 16 ( z0041-95 ).

Міністр В.Гуреєв ( Граничні розміри втратили чинність на підставі Наказу Міністерства економіки N 185 ( z0470-95 ) від 20.12.1995 )
