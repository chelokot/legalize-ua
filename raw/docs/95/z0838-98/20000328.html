МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ ДЕРЖАВНА АДМІНІСТРАЦІЯ ЗАЛІЗНИЧНОГО ТРАНСПОРТУ УКРАЇНИ УКРАЇНСЬКЕ ОБ'ЄДНАННЯ ДЕРЖАВНИХ МІЖГАЛУЗЕВИХ ПІДПРИЄМСТВ ПРОМИСЛОВОГО ЗАЛІЗНИЧНОГО ТРАНСПОРТУ

НАКАЗ

N 81 від 24.09.98 Зареєстровано в Міністерстві м.Київ юстиції України 29 грудня 1998 р. за N 838/3278

( Наказ втратив чинність на підставі Наказу Мінтрансу N 25 ( z0193-00 ) від 01.03.2000 )

Про затвердження тарифів на перевезення вантажів залізничними під'їзними коліями, вантажно-розвантажувальні роботи та інші послуги

З метою забезпечення фінансової стабільності підприємств об'єднання "Укрпромзалізтранс" та усунення викликаних кризовими явищами негативних наслідків, відповідно до постанови Кабінету Міністрів України від 25 грудня 1996 року N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та поданих розрахунків НАКАЗУЮ:

1. Затвердити тарифи на перевезення вантажів залізничними під'їзними коліями, вантажно-розвантажувальні роботи та інші послуги, що надаються міжгалузевими підприємствами промислового залізничного транспорту (додаються).

2. Економічній службі (Парамонова В.В.) забезпечити своєчасне доведення цього наказу до відома вантажовідправників та вантажоодержувачів.

3. Головному юрисконсульту об'єднання Моргунову Г.Д. зареєструвати даний наказ у Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника директора об'єднання з економічних питань Категоренка І.І.

5. Наказ об'єднання від 13.03.97 N 29 ( z0185-97 ) "Про затвердження тарифів на перевезення вантажів залізничними під'їзними коліями, вантажно-розвантажувальні роботи та інші послуги", зареєстрований Міністерством юстиції від 20.05.97 за N 185/1989, визнати таким, що втратив чинність.

Директор об'єднання Е.С.Краснослободцев

Затверджено Наказ об'єднання "Укрпромзалізтранс" 24.09.98 N 81

Зареєстровано в Міністерстві юстиції України 29 грудня 1998 р. за N 838/3278

Тарифи на перевезення вантажів залізничними під'їзними коліями, вантажно-розвантажувальні роботи та інші послуги, що надаються підприємствами промислового залізничного транспорту

Загальні вказівки

1. Тарифи розроблені на підставі постанови Кабінету Міністрів України від 25 грудня 1996 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)".

2. Ці тарифи поширюються на підприємства промислового залізничного транспорту об'єднання "Укрпромзалізтранс" (далі ППЗТ) та застосовуються для розрахунків із замовниками за роботи та послуги, що надаються ППЗТ.

3. При формуванні тарифів не враховано податок на додану вартість, який сплачується замовником додатково до тарифів відповідно до законодавчих актів України.

4. Тарифи на роботи та послуги, які виконуються ППЗТ, але не ввійшли до цього збірника, встановлюються за погодженням сторін.

5. Плата за вантажно-розвантажувальні роботи сплачується замовником за фактичну вагу вантажу, а за перевезення вантажів - за вагу, що визначена перевізними документами.

6. Плата за вантажно-розвантажувальні роботи обчислюється за тарифами розділу II із застосуванням коефіцієнтів розділу III.

7. Відстань для сплати за перевезення вантажів встановлюється в договорах із закругленням до цілих кілометрів, при цьому неповний кілометр приймається за повний.

8. Затверджені тарифи є граничні. ППЗТ надано право знижувати їх рівень, але не менше собівартості.

Примітки:

1. Ці тарифні ставки сплачуються за кожну тонно-операцію незалежно від способу виконання вантажно-розвантажувальних робіт.

2. Однією тонно-операцією вважається переміщення вантажу:

- зі складу в вагон або на автомашину - при навантаженні;

- із вагону або автомашини в склад при розвантаженні;

- із вагону в вагон, із вагону на автомобіль, із автомобіля у вагон - при перевантаженні (пряма операція); в середині складу з метою перевірки або переважування вантажу; при переміщенні вантажу від залізничної колії для вивільнення місця для розвантаження та інші, коли за умовами роботи виникає потреба в цих операціях, що підтверджується договором на транспортне обслуговування або іншим документом.

3. При переважуванні вантажу в процесі навантаження, розвантаження, перевантаження або при переміщенні тарифні ставки збільшуються на 100 відсотків.

4. При перевантаженні вантажів із вагону в вагон, із вагону на автомашину, з автомашини у вагон тарифні ставки збільшуються на 50 відсотків.

5. При навантаженні та розвантаженні вантажів змерзлих, злежалих, закам'янілих, що потребують розрихлення, відігріву, киркування, плата за виконання робіт провадиться, виходячи з їхньої собівартості, але не менше ніж ці тарифні ставки, збільшені на відсоток змерзлості, злежалості, закам'янілості.

6. За навантаження, розвантаження та перевантаження вантажів, що не значаться в цьому збірнику, плата провадиться як за аналогічні вантажі.
