Питання Секретаріату Президента України

Стан: Чинний

Ідентифікатор: 73/2008

Текст документа від 31.01.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Секретаріату Президента України

1. Внести до Указу Президента України від 14 жовтня 2005 року N 1445 ( 1445/2005 ) "Про створення Секретаріату Президента України" (зі змінами, внесеними Указами від 2 жовтня 2006 року N 814 ( 814/2006 ), від 19 лютого 2007 року N 120 ( 120/2007 ), від 26 лютого 2007 року N 143 ( 143/2007 ), від 23 березня 2007 року N 238 ( 238/2007 ), від 5 квітня 2007 року N 276 ( 276/2007 ), від 6 червня 2007 року N 507 ( 507/2007 ), від 9 листопада 2007 року N 1079 ( 1079/2007 ), від 24 грудня 2007 року N 1244 ( 1244/2007 ) та від 23 січня 2008 року N 46) ( 46/2008 ) такі зміни:

1) у частині другій статті 2 слова "сімох заступників" замінити словами "вісьмох заступників";

2) у статті 4:

доповнити статтю після абзацу "Головна служба гуманітарної політики та з питань збереження національного культурного надбання" новим абзацом такого змісту:

"Головна служба з питань освіти, науки та інноваційного розвитку";

абзац "Служба забезпечення зв'язків з Верховною Радою України та Кабінетом Міністрів України" викласти в такій редакції:

"Головна служба забезпечення зв'язків з Верховною Радою України та Кабінетом Міністрів України";

3) Схему розподілу обов'язків між Главою Секретаріату Президента України, його першими заступниками та заступниками, закріплення за ними структурних підрозділів, затверджену зазначеним Указом ( 1445/2005 ), викласти в новій редакції, що додається ( 73а/2008 ).

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 31 січня 2008 року N 73/2008

ЗАТВЕРДЖЕНО Указом Президента України від 14 жовтня 2005 року N 1445 ( 1445/2005 ) (в редакції Указу від 31 січня 2008 року N 73/2008)
