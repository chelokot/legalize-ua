Президент України; Указ від 23.01.2004 № 91/2004

Про збільшення кількісного складу суддів Вищого господарського суду України

Стан: Втратив чинність

Ідентифікатор: 91/2004

Текст документа від 23.01.2004:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про збільшення кількісного складу суддів Вищого господарського суду України

Відповідно до частини четвертої статті 20 Закону України "Про судоустрій України" ( 3018-14 ) постановляю:

1. Збільшити кількісний склад суддів Вищого господарського суду України на 30 одиниць.

2. Внести до додатка N 2 до Указу Президента України від 11 липня 2001 року N 511 ( 511/2001 ) (зі змінами, внесеними Указами від 30 травня 2002 року N 499 ( 499/2002 ) та від 25 червня 2003 року N 552 ( 552/2003 ) такі зміни:

у позиції "Вищий господарський суд України" цифри "65" замінити цифрами "95";

цифри "1034" замінити цифрами "1064".

Президент України Л.КУЧМА

м. Київ, 23 січня 2004 року N 91/2004
