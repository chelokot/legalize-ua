Кабінет Міністрів України; Розпорядження від 12.12.1994 № 897-р

Про призначення голови Урядової комісії для розроблення Національної програми відродження села

Стан: Втратив чинність

Ідентифікатор: 897-94-р

Текст документа від 20.04.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 грудня 1994 р. N 897-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 646 ( 646-2007-п ) від 20.04.2007 }

Призначити головою Урядової комісії для організації розроблення Національної програми відродження села на 1995-2005 роки, утвореної постановою Кабінету Міністрів України від 11 червня 1994 р. N 393 ( 393-94-п ), Віце-прем'єр-міністра Саблука Петра Трохимовича, увільнивши від обов'язків голови Дем'янова Володимира Васильовича.

Ввести до складу зазначеної Комісії першого заступника Міністра охорони здоров'я Марієвського Віктора Федоровича, увільнивши від обов'язків члена комісії Передерія В'ячеслава Григоровича.

Надати голові Урядової комісії право вносити зміни до її складу.

Прем'єр-міністр України В.МАСОЛ
