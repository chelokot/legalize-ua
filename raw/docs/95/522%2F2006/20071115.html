Про внесення зміни до Указу Президента України від 29 жовтня 2003 року N 1226

Внести до Переліку посад в органах виконавчої влади та інших цивільних установах, які можуть бути заміщені особами вищого офіцерського складу Збройних Сил України, Служби безпеки України, інших військових формувань і особами вищого начальницького складу органів внутрішніх справ, та граничних військових і спеціальних звань за цими посадами, затвердженого Указом Президента України від 29 жовтня 2003 року N 1226 ( 1226/2003 ) (зі змінами, внесеними Указами від 26 листопада 2003 року N 1357 ( 1357/2003 ), від 3 грудня 2003 року N 1395 ( 1395/2003 ), від 25 грудня 2003 року N 1484 ( 1484/2003 ), від 21 січня 2004 року N 63 ( 63/2004 ), від 19 квітня 2004 року N 447 ( 447/2004 ), від 17 вересня 2004 року N 1098 ( 1098/2004 ) і N 1099 ( 1099/2004 ), від 30 вересня 2004 року N 1158 ( 1158/2004 ), від 13 жовтня 2004 року N 1232 ( 1232/2004 ), від 13 грудня 2004 року N 1475 ( 1475/2004 ), від 30 грудня 2004 року N 1579 ( 1579/2004 ), від 5 січня 2005 року N 3 ( 3/2005 ), від 10 березня 2005 року N 458 ( 458/2005 ), від 18 березня 2005 року N 491 ( 491/2005 ), від 10 червня 2005 року N 943 ( 943/2005 ), від 11 липня 2005 року N 1083 ( 1083/2005 ), від 14 вересня 2005 року N 1272 ( 1272/2005 ), від 2 грудня 2005 року N 1690 ( 1690/2005 ), від 22 грудня 2005 року N 1819 ( 1819/2005 ) та від 23 січня 2006 року N 56 ( 56/2006 ), зміну, доповнивши його після розділу "Державна митна служба України" розділом такого змісту:

"Державна служба спеціального зв'язку та захисту інформації України

Голова генерал-лейтенант одна*". (на період до 1 січня 2007 року)
