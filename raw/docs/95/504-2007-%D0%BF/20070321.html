КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 березня 2007 р. N 504 Київ

Про затвердження переліку об'єктів, що фінансуються за рахунок державних капітальних вкладень, виділених для виконання Чорнобильської будівельної програми у 2007 році

Кабінет Міністрів України постановляє:

1. Затвердити перелік об'єктів, що фінансуються за рахунок державних капітальних вкладень, виділених для виконання Чорнобильської будівельної програми у 2007 році ( 489-16 ) (додається).

2. Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи у місячний строк доопрацювати та затвердити в установленому порядку зведений кошторисний розрахунок вартості реконструкції автомобільної дороги Прип'ять - Буряківка.

3. Міністерству регіонального розвитку та будівництва довести відомості про показники фінансування об'єктів, зазначених у пункті 1 цієї постанови, до Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи.

Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи інформувати щомісяця до 10 числа наступного періоду Міністерство регіонального розвитку та будівництва про стан використання державних капітальних вкладень, виділених для виконання Чорнобильської будівельної програми ( 489-16 ) за об'єктами, що споруджуються за їх рахунок.

4. Міністерству регіонального розвитку та будівництва інформувати щомісяця до 15 числа наступного періоду Кабінет Міністрів України про стан використання державних капітальних вкладень, виділених для виконання Чорнобильської будівельної програми ( 489-16 ) за об'єктами, що споруджуються за їх рахунок.
