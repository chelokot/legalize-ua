МІНІСТЕРСТВО ОХОРОНИ ЗДОРОВ'Я УКРАЇНИ

НАКАЗ

11.07.2005 N 342

Зареєстровано в Міністерстві юстиції України 21 липня 2005 р. за N 787/11067

Про внесення змін до наказу МОЗ України від 04.12.2001 N 482 "Про затвердження порядку видачі медичного висновку про дитину-інваліда віком до 16 років" (зі змінами)

У зв'язку з прийняттям Закону України від 4 листопада 2004 року N 2154-IV ( 2154-15 ) "Про внесення змін до Закону України "Про державну соціальну допомогу інвалідам з дитинства та дітям-інвалідам" та відповідно до постанови Кабінету Міністрів України від 13 квітня 2005 року N 279 ( 279-2005-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 26 липня 2001 року N 889" НАКАЗУЮ:

1. У назві, тексті наказу МОЗ України від 04.12.2001 N 482 ( z0011-02 ) "Про затвердження порядку видачі медичного висновку про дитину-інваліда віком до 16 років", зареєстрованого у Міністерстві юстиції України 10.01.2002 за N 11/6299 (зі змінами, внесеними наказом МОЗ України від 23.05.2002 N 187 ( z0478-02 ), зареєстрованим у Міністерстві юстиції України 05.06.2002 за N 478/6766), та Порядку видачі медичного висновку про дитину-інваліда віком до 16 років, затвердженого цим наказом, цифри "16" замінити цифрами "18".

2. Міністру охорони здоров'я Автономної Республіки Крим, начальникам управлінь охорони здоров'я обласних, Севастопольської міської державних адміністрацій, Головного управління охорони здоров'я та медичного забезпечення Київської міської державної адміністрації забезпечити виконання цього наказу.

3. Контроль за виконанням цього наказу покласти на першого заступника Міністра Ханенка С.М.

Міністр М.Є.Поліщук
