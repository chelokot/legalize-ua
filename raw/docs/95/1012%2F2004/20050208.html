Президент України; Указ від 27.08.2004 № 1012/2004

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

Стан: Втратив чинність

Ідентифікатор: 1012/2004

Текст документа від 08.02.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 208/2005 ( 208/2005 ) від 08.02.2005 )

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

1. Увести до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України, затвердженого Указом Президента України від 24 березня 2004 року N 362 ( 362/2004 ) (зі змінами, внесеними Указом від 11 травня 2004 року N 512 ( 512/2004 ), МОТРЕНКА Тимофія Валентиновича - Начальника Головного управління державної служби України, ПЕТРОЧЕНКА Юрія Адамовича - заступника Секретаря Ради національної безпеки і оборони України та ЯРОШЕНКА Федора Олексійовича - Голову Державної податкової адміністрації України.

2. Затвердити у складі зазначеного Комітету ДУБИНУ Олега Вікторовича - президента Національної акціонерної компанії "Енергетична компанія України".

3. Вивести із складу цього Комітету Кравченка Ю.Ф.

Президент України Л.КУЧМА

м. Київ, 27 серпня 2004 року N 1012/2004
