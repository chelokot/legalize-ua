Про втрату чинності Положення про порядок відчуження основних засобів, що є державною власністю, та Положення про порядок продажу на аукціоні, за конкурсом основних засобів, що є державною власністю

Реєстрація: Мін'юст України від 07.12.2006 № 1285/13159

Стан: Втратив чинність

Ідентифікатор: z1285-06

Текст документа від 21.04.2017:

ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

24.11.2006 N 1758

Зареєстровано в Міністерстві юстиції України 7 грудня 2006 р. за N 1285/13159

{ Наказ втратив чинність на підставі Наказу Фонду державного майна N 347 ( z0378-17 ) від 02.03.2017 }

Про втрату чинності Положення про порядок відчуження основних засобів, що є державною власністю, та Положення про порядок продажу на аукціоні, за конкурсом основних засобів, що є державною власністю

У зв'язку з набранням чинності Законом України "Про управління об'єктами державної власності" ( 185-16 ) та згідно з дорученням Кабінету Міністрів України від 12.10.2006 N 38060/2/1-06 НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

Положення про порядок відчуження основних засобів, що є державною власністю, затверджене наказом Фонду державного майна України від 30.07.99 N 1477 ( z0573-99 ) та зареєстроване в Міністерстві юстиції України 19.08.99 за N 573/3866 (у редакції наказу Фонду державного майна України від 29.03.2004 N 604 ( z0471-04 ), зареєстрованого в Міністерстві юстиції України 13.04.2004 за N 471/9070);

Положення про порядок продажу на аукціоні, за конкурсом основних засобів, що є державною власністю, затверджене наказом Фонду державного майна України від 22.09.2000 N 1976 ( z0692-00 ) та зареєстроване в Міністерстві юстиції України 10.10.2000 за N 692/4913 (із змінами і доповненнями).

2. Директору Департаменту банкрутства, санації та реструктуризації А. Гладченку забезпечити в установленому порядку подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Голови Фонду С. Лєдомську.
