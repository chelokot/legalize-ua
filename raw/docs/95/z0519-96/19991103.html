N 65 від 29.08.96 Зареєстровано в Міністерстві м.Київ юстиції України 12 вересня 1996 р. vd960829 vn65 за N 519/1544

( Постанова втратила чинність на підставі Постанови Нацкомелектроенергетики N 1350 ( z0758-99 ) від 26.10.99 )

Про порядок розрахунків за спожиту населенням електроенергію

( Додатково див. Постанову Нацкомелектроенергетики N 1034 ( v1034227-99 ) від 04.08.99 )

З метою впорядкування оплати населенням (побутовими споживачами) вартості спожитої електроенергії і для зменшення заборгованості енергопостачальним організаціям Національна комісія з питань регулювання електроенергетики України (НКРЕ) ПОСТАНОВЛЯЄ:

1. Встановити, що населення (побутові споживачі) має здійснювати оплату спожитої електричної енергії не пізніше 10 числа наступного місяця.

2. Встановити, що в разі зміни тарифів на електричну енергію розрахунки за спожиту населенням (побутовими споживачами) за попередній місяць електроенергію, які не здійснені до 10 числа наступного місяця, провадяться за тарифами, що діють на час сплати.

3. При виявленні фактів порушення Правил користування електричною енергією (п.8.16, п.8.17), затверджених постановою НКРЕ від 31.07.96 р. N 28 ( z0417-96 ), перерахунок за користування електроенергією здійснюється за тарифами, що діяли на час встановлення порушення, на підставі належно оформлених матеріалів.

4. Визнати такою, що втратила чинність, постанову від 15 листопада 1995 року N 8 ( z0451-95 ).
