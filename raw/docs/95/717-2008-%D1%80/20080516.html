Кабінет Міністрів України; Розпорядження від 16.05.2008 № 717-р

Про здійснення Кабінетом Міністрів України повноважень з управління державними корпоративними правами

Стан: Втратив чинність

Ідентифікатор: 717-2008-р

Текст документа від 16.05.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 травня 2008 р. N 717-р Київ

Про здійснення Кабінетом Міністрів України повноважень з управління державними корпоративними правами

1. З метою забезпечення належного управління державними корпоративними правами відкритих акціонерних товариств "Одеський припортовий завод", "Київський завод реле та автоматики", "Київський мотоциклетний завод", "Турбоатом", "Завод "Маяк", "Феодосійська суднобудівна компанія "Море", "Науково-виробничий комплекс "Київський завод автоматики імені Г.І.Петровського", "Науково-дослідний інститут електромеханічних приладів", "Укртелеком", "Меридіан" імені С.П.Корольова" та Державної акціонерної компанії "Україна туристична" покласти повноваження з управління зазначеними корпоративними правами на Кабінет Міністрів України.

2. Визнати таким, що втратив чинність, пункт 1 розпорядження Кабінету Міністрів України від 28 жовтня 2004 р. N 777 ( 777-2004-р ) "Деякі питання управління державними корпоративними правами ВАТ "Укртелеком".

Прем'єр-міністр України Ю.ТИМОШЕНКО
