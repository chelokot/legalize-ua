Кабінет Міністрів України; Розпорядження від 16.05.2008 № 717-р

Про здійснення Кабінетом Міністрів України повноважень з управління державними корпоративними правами

Стан: Втратив чинність

Ідентифікатор: 717-2008-р

Текст документа від 02.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 травня 2008 р. N 717-р Київ

{ Розпорядження скасовано на підставі Розпорядження КМ N 348-р ( 348-2009-р ) від 02.04.2009 }

Про здійснення Кабінетом Міністрів України повноважень з управління державними корпоративними правами

{ Дію Розпорядження зупинено згідно з Указом Президента N 462/2008 ( 462/2008 ) від 20.05.2008 - втратив чинність на підставі Указу Президента N 874/2008 ( 874/2008 ) від 29.09.2008 }

{ Відмовлено у відкритті конституційного провадження у справі за конституційним поданням Президента України ( n0015100-08 ) щодо відповідності Конституції України ( 254к/96-ВР ) (конституційності) цього Розпорядження Ухвалою Конституційного Суду N 35-у/2008 ( v035u710-08 ) від 09.09.2008 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1335-р ( 1335-2008-р ) від 17.10.2008 }

{ Пункт 1 втратив чинність в частині, що стосується відкритих акціонерних товариств "Одеський припортовий завод", "Київський завод реле та автоматики", "Київський мотоциклетний завод", "Турбоатом", "Завод "Маяк", "Феодосійська суднобудівна компанія "Море", "Науково-виробничий комплекс "Київський завод автоматики імені Г.І. Петровського", "Науково-дослідний інститут електромеханічних приладів" і "Меридіан" імені С.П. Корольова" на підставі Розпорядження КМ N 1335-р ( 1335-2008-р ) від 17.10.2008 } 1. З метою забезпечення належного управління державними корпоративними правами відкритих акціонерних товариств "Одеський припортовий завод", "Київський завод реле та автоматики", "Київський мотоциклетний завод", "Турбоатом", "Завод "Маяк", "Феодосійська суднобудівна компанія "Море", "Науково-виробничий комплекс "Київський завод автоматики імені Г.І.Петровського", "Науково-дослідний інститут електромеханічних приладів", "Укртелеком", "Меридіан" імені С.П.Корольова" та Державної акціонерної компанії "Україна туристична" покласти повноваження з управління зазначеними корпоративними правами на Кабінет Міністрів України.

2. Визнати таким, що втратив чинність, пункт 1 розпорядження Кабінету Міністрів України від 28 жовтня 2004 р. N 777 ( 777-2004-р ) "Деякі питання управління державними корпоративними правами ВАТ "Укртелеком".
