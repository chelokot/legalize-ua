РОЗПОРЯДЖЕННЯ від 14 липня 2010 р. N 1474-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 312 ( 312-2011-п ) від 30.03.2011 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 17 вересня 2008 р. N 1250

У графі "Зміст заходу, строк виконання" пункту 4.9 плану заходів щодо реалізації положень Генеральної угоди між Кабінетом Міністрів України, всеукраїнськими об'єднаннями організацій роботодавців і підприємців та всеукраїнськими профспілками і профоб'єднаннями на 2008-2009 роки, затвердженого розпорядженням Кабінету Міністрів України від 17 вересня 2008 р. N 1250 ( 1250-2008-р ) (Офіційний вісник України, 2008 р., N 72, ст. 2431, N 86, ст. 2876, N 95, ст. 3147), абзац четвертий виключити.

Прем'єр-міністр України М.АЗАРОВ
