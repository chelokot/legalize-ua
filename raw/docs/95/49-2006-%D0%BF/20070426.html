{ Постанова втратила чинність на підставі Постанови КМ N 674 ( 674-2007-п ) від 26.04.2007 }

Про затвердження складу спостережної ради Державної акціонерної компанії "Хліб України"

Кабінет Міністрів України постановляє:

На часткову зміну пункту 3 постанови Кабінету Міністрів України від 14 березня 2001 р. N 240 ( 240-2001-п ) "Про затвердження Статуту Державної акціонерної компанії "Хліб України" (Офіційний вісник України, 2001 р., N 12, ст. 489; 2004 р., N 5, ст. 236) затвердити склад спостережної ради Державної акціонерної компанії "Хліб України", що додається.

ДАНИЛИШИН - директор департаменту фінансів АПК та

Анатолій Антонович природоохоронних заходів Мінфіну

КОНДРАТЕНКО - заступник начальника Управління

ПЕНДЗИН - директор департаменту економічної

Олег Володимирович конкуренції та секторальних перетворень Мінекономіки

ПЕТРОВ - перший заступник Голови Фонду державного

СТАНІВ - заступник директора юридичного
