ПОСТАНОВА від 17 липня 2003 р. N 1081 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Про внесення зміни у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

Кабінет Міністрів України постановляє:

У додатку 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851, N 33, ст. 1526; 2002 р., N 27, ст. 1277) позицію

"Міністерство закордонних справ 790 6"

викласти у такій редакції:

"Міністерство закордонних справ 765 8 25".
