Кабінет Міністрів України; Розпорядження від 11.04.2006 № 199-р

Про поховання колишнього Міністра зовнішніх економічних зв'язків Герца І.І.

Стан: Чинний

Ідентифікатор: 199-2006-р

Текст документа від 25.10.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 квітня 2006 р. N 199-р Київ

Про поховання колишнього Міністра зовнішніх економічних зв'язків Герца І.І.

{ Із змінами, внесеними згідно з Постановою КМ N 1474 ( 1474-2006-п ) від 25.10.2006 }

1. Поховати Герца І.І. на Байковому кладовищі.

2. Витрати, пов'язані з похованням Герца І.І., в сумі 10,476 тис. гривень здійснити за рахунок держави.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1474 ( 1474-2006-п ) від 25.10.2006 }

3. Київській міськдержадміністрації спорудити на могилі Герца І.І. надгробок вартістю до 8 тис. гривень.

4. Видати одноразову допомогу в сумі 3 тис. гривень вдові Герца І.І. - Герц Світлані Василівні.

5. Мінфіну профінансувати зазначені в пунктах 2-4 цього розпорядження витрати за рахунок коштів резервного фонду державного бюджету ( 3235-15 ).

6. Мінекономіки подати до кінця 2006 року Мінфіну та Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.
