Текст документа від 10.09.2012:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 479/2012 ( 479/2012 ) від 20.08.2012 }

Про делегацію України для участі в роботі Групи держав Ради Європи проти корупції (GRECO)

{ Із змінами, внесеними згідно з Указом Президента N 496/2011 ( 496/2011 ) від 22.04.2011 }

1. Утворити делегацію України для участі в роботі Групи держав Ради Європи проти корупції (GRECO) у такому складі:

ЛУТКОВСЬКА - Урядовий уповноважений у справах

Валерія Володимирівна Європейського суду з прав людини, глава делегації

БУРОМЕНСЬКИЙ - президент Інституту прикладних

Михайло Всеволодович та гуманітарних досліджень, заступник члена делегації (за згодою)

СМІРНОВА - начальник відділу Департаменту

Олена Львівна законодавства про правосуддя, правоохоронної діяльності та антикорупційної політики Міністерства юстиції України, член делегації.

{ Пункт 1 із змінами, внесеними згідно з Указом Президента N 496/2011 ( 496/2011 ) від 22.04.2011 }

2. Визнати таким, що втратило чинність, Розпорядження Президента України від 20 лютого 2006 року N 33 ( 33/2006-рп ) "Про делегацію України у Групі держав Ради Європи проти корупції (GRECO)".

Президент України В.ЯНУКОВИЧ
