Кабінет Міністрів України; Постанова від 31.05.2006 № 770

Про встановлення розміру стипендій Президента України для переможців всеукраїнських учнівських олімпіад з базових навчальних предметів і Всеукраїнського конкурсу-захисту науково-дослідницьких робіт учнів - членів Малої академії наук

Стан: Втратив чинність

Ідентифікатор: 770-2006-п

Текст документа від 23.03.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 травня 2006 р. N 770 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 177 ( 177-2012-п ) від 07.03.2012 }

Про встановлення розміру стипендій Президента України для переможців всеукраїнських учнівських олімпіад з базових навчальних предметів і Всеукраїнського конкурсу-захисту науково-дослідницьких робіт учнів - членів Малої академії наук

Кабінет Міністрів України постановляє:

Установити, що стипендії Президента України для переможців всеукраїнських учнівських олімпіад з базових навчальних предметів і Всеукраїнського конкурсу-захисту науково-дослідницьких робіт учнів - членів Малої академії наук виплачуються у розмірі 3,125 мінімальної академічної стипендії студентів вищих навчальних закладів III-IV рівня акредитації.

Прем'єр-міністр України Ю.ЄХАНУРОВ
