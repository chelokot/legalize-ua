Реєстрація: Мін'юст України від 13.08.2008 № 750/15441

Стан: Чинний

Ідентифікатор: z0750-08

Текст документа від 26.09.2014:

МІНІСТЕРСТВО З ПИТАНЬ ЖИТЛОВО-КОМУНАЛЬНОГО ГОСПОДАРСТВА УКРАЇНИ

НАКАЗ

27.06.2008 N 189

Зареєстровано в Міністерстві юстиції України 13 серпня 2008 р. за N 750/15441

Про внесення змін до Галузевих технологічних нормативів використання питної води на підприємствах водопровідно-каналізаційного господарства України, затверджених наказом Держжитлокомунгоспу України від 17.02.2004 N 33

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Державного комітету України з питань житлово-комунального господарства N 33 ( z1557-04 ) від 17.02.2004, до якого вносились зміни }

Відповідно до Водного кодексу України ( 213/95-ВР ) та Законів України "Про житлово-комунальні послуги" ( 1875-15 ), "Про питну воду та питне водопостачання" ( 2918-14 ), з метою поступового зменшення нормативів використання питної води у галузі водопровідно-каналізаційного господарства НАКАЗУЮ:

1. Унести до Галузевих технологічних нормативів використання питної води на підприємствах водопровідно-каналізаційного господарства України, затверджених наказом Держжитлокомунгоспу України від 17.02.2004 N 33 ( z1557-04 ), зареєстрованих у Міністерстві юстиції України 07.12.2004 за N 1557/10156, такі зміни:

у пункті 3.3 розділу 3 слова "Без спеціальних додаткових обґрунтувань" вилучити;

у таблиці додатка 1 позицію "Поточний ІТНВПВ на підприємстві ВКГ" викласти у такій редакції:

"------------------------------------------------------------------------------------------------------------------

| Поточний ІТНВПВ на |Норматив визначається як сума обсягів ТНВПВ у водопровідному та |

| підприємстві ВКГ |каналізаційному господарствах в кубічних метрах на рік, віднесена на планову |

| |подачу питної води в тисячах кубічних метрів на рік. |

| |Загальний ТНВПВ товарної води не повинен перевищувати 300,0 куб.м/1000 куб.м |

------------------------------------------------------------------------------------------------------------------"

2. Управлінню водопровідно-каналізаційного господарства (В.П.Рудий) разом Юридичним відділом (І.І.Крилова) подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра О.В.Мазурчака.

Міністр О.Ю.Кучеренко
