Про внесення зміни до Закону України "Про вибори народних депутатів України"

Стан: Втратив чинність

Ідентифікатор: 130/98-вр

Текст документа від 18.10.2001:

ЗАКОН УКРАЇНИ

( Закон втратив чинність на підставі Закону N 2766-III ( 2766-14 ) від 18.10.2001, ВВР, 2001, N 51-52, ст. 265 )

Про внесення зміни до Закону України "Про вибори народних депутатів України"

( Відомості Верховної Ради України (ВВР), 1998, N 10, ст.38 )

У зв'язку з прийняттям Конституційним Судом України Рішення від 26 лютого 1998 року стосовно відповідності Конституції України (конституційності) Закону України "Про вибори народних депутатів України" ( v001p710-98 ), керуючись статтями 71, 150 і 152 Конституції України ( 254к/96-ВР ), Верховна Рада України постановляє:

1. У частині першій статті 26 Закону України "Про вибори народних депутатів України" ( 541/97-ВР ) (Відомості Верховної Ради України, 1997 р., N 43, ст.280) із змінами, внесеними законами України від 11 грудня 1997 року ( 715/97-ВР ), від 25 грудня 1997 року ( 783/97-ВР ) і від 30 грудня 1997 року ( 801/97-ВР ), слова "до дня виборів" виключити.

2. Цей Закон набирає чинності з дня його офіційного опублікування.

Президент України Л.КУЧМА

м. Київ, 3 березня 1998 року N 130/98-ВР
