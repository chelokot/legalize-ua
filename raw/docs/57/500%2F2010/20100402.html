Президент України; Указ від 02.04.2010 № 500/2010

Про ліквідацію робочої групи з розроблення концепції вдосконалення законодавства з питань приватизації

Стан: Чинний

Ідентифікатор: 500/2010

Текст документа від 02.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про ліквідацію робочої групи з розроблення концепції вдосконалення законодавства з питань приватизації

Відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Ліквідувати робочу групу з розроблення концепції вдосконалення законодавства з питань приватизації.

2. Визнати таким, що втратив чинність, Указ Президента України від 4 лютого 2008 року N 90 ( 90/2008 ) "Про робочу групу з розроблення концепції вдосконалення законодавства з питань приватизації".

3. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 2 квітня 2010 року N 500/2010
