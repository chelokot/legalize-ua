НКРЕ; Постанова від 16.12.1998 № 1613

Про встановлення терміну ліцензування підприємницької діяльності з передачі електроенергії місцевими (локальними) електромережами

Реєстрація: Мін'юст України від 21.12.1998 № 805/3245

Стан: Втратив чинність

Ідентифікатор: z0805-98

Текст документа від 18.09.2005:

НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

N 1613 від 16.12.98 Зареєстровано в Міністерстві м.Київ юстиції України 21 грудня 1998 р. за N 805/3245

( Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 690 ( z0998-05 ) від 22.08.2005 )

Про встановлення терміну ліцензування підприємницької

діяльності з передачі електроенергії місцевими (локальними) електромережами

Згідно із Законом України "Про електроенергетику" ( 575/97-ВР ) та Указом Президента України від 21 квітня 1998 р. N 335/98 "Питання Національної комісії регулювання електроенергетики України" Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Встановити, що підприємницька діяльність з передачі електричної енергії місцевими (локальними) електромережами створених в результаті реструктуризації галузей промисловості суб'єктів, для яких ця діяльність є основною, з 01.04.99 без ліцензії забороняється.

2. Вважати постанову НКРЕ від 17.06.98 N 762 ( z0387-98 ) такою, що втрачає чинність з 01.01.99.
