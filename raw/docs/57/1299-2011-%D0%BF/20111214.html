Кабінет Міністрів України; Постанова від 14.12.2011 № 1299

Про внесення зміни до пункту 1 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

Стан: Втратив чинність

Ідентифікатор: 1299-2011-п

Текст документа від 14.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 грудня 2011 р. N 1299 Київ

Про внесення зміни до пункту 1 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

Кабінет Міністрів України постановляє:

Внести зміну до пункту 1 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів, затверджених постановою Кабінету Міністрів України від 22 жовтня 2008 р. N 943 ( 943-2008-п ) "Про економію бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів" (Офіційний вісник України, 2008 р., N 84, ст. 2816; 2009 р., N 45, ст. 1507, N 83, ст. 2823, N 95, ст. 3269; 2010 р., N 5, ст. 200, N 60, ст. 2094, N 74, ст. 2621, N 81, ст. 2847, N 96, ст. 3403, ст. 3406, N 98, ст. 3494, N 100, ст. 3550; 2011 р., N 2, ст. 111, N 26, ст. 1069, N 44, ст. 1797, N 46, ст. 1888, N 59, ст. 2369, N 78, ст. 2885, N 80, ст. 2944, N 90, ст. 3266), доповнивши його після слова "Держінформнауки" словами і цифрами ", а також приміщень третього поверху будівлі по вул. І. Франка, 19, в якій розміщено Мінкультури".

Прем'єр-міністр України М.АЗАРОВ
