Питання Управління державної охорони України

Стан: Чинний

Ідентифікатор: 506/2006

Текст документа від 09.06.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Управління державної охорони України

Відповідно до Закону України "Про загальну структуру і чисельність Управління державної охорони України" ( 3106-15 ) постановляю:

1. Внести зміну до Указу Президента України від 22 травня 1998 року N 502 ( 502/98 ) "Про державну охорону окремих посадових осіб", виключивши абзац "Голови Державної податкової адміністрації України".

2. Визнати такими, що втратили чинність:

1) Указ Президента України від 15 липня 1994 року N 395 ( 395/94 ) "Про внесення змін до структури Управління державної охорони України";

2) статтю 2 Указу Президента України від 11 травня 1998 року N 451 ( 451/98 ) "Про державну охорону Рахункової палати";

3) Указ Президента України від 24 липня 1998 року N 820 ( 820/98 ) "Про забезпечення безпеки Заступника Голови Верховної Ради України";

4) статті 2 і 3 Указу Президента України від 23 вересня 1998 року N 1059 ( 1059/98 ) "Про державну охорону будинку Генеральної прокуратури України та забезпечення безпеки Генерального прокурора України";

5) статті 2 і 3 Указу Президента України від 6 листопада 1998 року N 1219 ( 1219/98 ) "Про державну охорону будинку Вищого арбітражного суду України та забезпечення безпеки його Голови";

6) статті 2 і 3 Указу Президента України від 4 листопада 2000 року N 1206 ( 1206/2000 ) "Про державну охорону адміністративного будинку Міністерства закордонних справ України та новоутворених об'єктів";

7) Указ Президента України від 7 грудня 2000 року N 1312 ( 1312/2000 ) "Про забезпечення безпеки Міністра юстиції України С. Станік";

8) Указ Президента України від 30 грудня 2000 року N 1397 ( 1397/2000 ) "Про забезпечення безпеки Глави Адміністрації Президента України";

9) статті 2 і 3 Указу Президента України від 8 жовтня 2002 року N 913 ( 913/2002 ) "Про державну охорону державної резиденції "Юсуповський палацо-парковий садибний комплекс".

3. Начальникові Управління державної охорони України затвердити у місячний строк структуру і штат Управління державної охорони України.

4. Надати право начальникові Управління державної охорони України зберігати за військовослужбовцями, посади яких підлягають скороченню у зв'язку з проведенням організаційних заходів, у разі надання ними згоди на призначення їх на нижчі посади, розміри посадових окладів і порядок матеріально-технічного та інших видів забезпечення, які вони мали за попередньою посадою, діючи у межах коштів Державного бюджету України, передбачених на відповідні цілі.

Президент України В.ЮЩЕНКО

м. Київ, 9 червня 2006 року N 506/2006
