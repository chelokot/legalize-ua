Про контрольні пости державних податкових інспекцій на підприємствах, що виробляють спирт та алкогольні напої

Стан: Втратив чинність

Ідентифікатор: 9-97-п

Текст документа від 25.08.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 січня 1997 р. N 9 Київ

Про контрольні пости державних податкових інспекцій на підприємствах, що виробляють спирт та алкогольні напої

( Із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

З метою посилення контролю за повнотою та своєчасністю надходження до бюджету акцизного збору із спирту етилового та алкогольних напоїв, що виробляються в Україні, Кабінет Міністрів України постановляє:

1. Затвердити Положення про контрольні пости державних податкових інспекцій на підприємствах, що виробляють спирт і алкогольні напої (додається).

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

2. Державній податковій інспекції створити з 1 лютого 1997 р. на підприємствах, що виробляють спирт та алкогольні напої, контрольні пости державних податкових інспекцій (далі - контрольні пости), які забезпечуватимуть цілодобове чергування, в межах чисельності і фонду заробітної плати державної податкової адміністрації. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

3. Суб'єктам підприємницької діяльності, що виробляють спирт та алкогольні напої, забезпечити контрольні пости пристосованими приміщеннями, обладнаними охоронною сигналізацією, телефонним зв'язком та іншими засобами, необхідними для їх ефективного функціонування.

4. Державній податковій адміністрації, Міністерству фінансів, Державному комітету по харчовій промисловості, Державному комітету з питань садівництва, виноградарства та виноробної промисловості, Державній митній службі, іншим міністерствам і центральним органам виконавчої влади привести нормативні акти з питань зберігання, відпуску і транспортування спирту та алкогольних напоїв у відповідність із цим Положенням.

5. Ця постанова вводиться в дію з 1 лютого 1997 року.

Прем'єр-міністр України П.ЛАЗАРЕНКО

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 11 січня 1997 р. N 9

ПОЛОЖЕННЯ про контрольні пости державних податкових інспекцій на підприємствах, що виробляють спирт та алкогольні напої ( Назва із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

Загальна частина

1. Контрольні пости державних податкових інспекцій (далі

- контрольні пости) створюються на всіх підприємствах України, що виробляють спирт та алкогольні напої, незалежно від форм власності для здійснення контролю за повнотою та своєчасністю сплати акцизного збору.

Місцем діяльності контрольного поста є підприємство, що виробляє спирт та алкогольні напої.

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

2. Рішення про створення контрольних постів з визначенням чисельності працівників та їх ліквідацію приймається Державною податковою адміністрацією.

3. Контрольні пости формуються з числа посадових осіб державних податкових інспекцій за місцем державної реєстрації виробників спирту та алкогольних напоїв (далі - працівники контрольного поста) відповідно до наказу начальників цих державних податкових інспекцій. У наказі також визначається режим роботи з урахуванням режиму роботи контрольованого підприємства, порядок контролю за роботою постів, заходи матеріально-технічного забезпечення постів, транспортного обслуговування та інші умови, необхідні для здійснення ефективного контролю.

Копія наказу надсилається керівнику підприємства, який у триденний термін зобов'язаний видати відповідний наказ, передбачивши створення належних умов для ефективної роботи контрольного поста.

( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

4. Працівники контрольного поста користуються правами, передбаченими Законом України "Про державну податкову службу в Україні" ( 509-12 ) та цим Положенням.

Працівник контрольного поста має право за узгодженням з начальником державної податкової інспекції у разі потреби проводити більш детальну документальну перевірку та аналіз фінансово-господарської діяльності підприємства і залучати до неї інших фахівців державної податкової інспекції.

Працівники контрольного поста відповідно до законодавства несуть відповідальність за збереження державної та комерційної таємниці.

( Пункт 4 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

5. Порядок виконання контрольними постами своїх функцій визначається цим Положенням і нормативними актами Державної податкової адміністрації.

Форми довідок, журналів, звітів, відомостей, типові посадові інструкції та інші нормативні документи, необхідні для забезпечення ефективного функціонування контрольних постів, розробляються відповідно до цього Положення та затверджуються Державною податковою адміністрацією в установленому порядку.

Основні завдання та функції контрольних постів

6. Основним завданням контрольних постів є здійснення постійного контролю безпосередньо на підприємствах, що виробляють спирт та алкогольні напої, за дотриманням встановленого порядку сплати акцизного збору.

7. Відповідно до покладених завдань контрольні пости:

1) забезпечують контроль за:

обліком зберігання, відпуску та транспортування спирту і алкогольних напоїв за даними складського і бухгалтерського обліку підприємств, що виробляють алкогольні напої;

обліком, зберіганням, використанням марок акцизного збору та додержанням встановленого порядку маркування алкогольних напоїв;

обліком надходження та витрачання сировини, яка містить спирт для виготовлення алкогольних напоїв;

додержанням вимог чинного законодавства під час здійснення експорту спирту і алкогольних напоїв;

додержанням встановленого порядку обчислення та дотриманням термінів сплати акцизного збору;

2) аналізують правильність обліку використання сировини, яка містить спирт, та готової продукції і стан розрахунків з отримувачами продукції;

3) беруть участь у проведенні інвентаризації спирту, алкогольних напоїв та марок акцизного збору;

4) забезпечують усунення порушень, виявлених в обліку зберігання, відпуску і транспортування спирту та алкогольних напоїв;

5) своєчасно складають та подають відповідним державним податковим інспекціям звітність про свою роботу за затвердженими Державною податковою адміністрацією формами;

6) розробляють і вносять пропозиції щодо удосконалення системи контролю за обліком зберігання, відпуску та транспортування спирту і алкогольних напоїв за даними складського і бухгалтерського обліку підприємств, що виробляють алкогольні напої.

( Пункт 7 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

Функції контрольних постів на підприємствах, що виробляють спирт

8. Контрольні пости здійснюють контроль на підприємствах, що виробляють спирт, за обліком зберігання і відпуску спирту та сировини, яка містить спирт.

9. Відпуск спирту або сировини, яка містить спирт, підприємством без погодження з контрольним постом забороняється.

10. Для отримання спирту або сировини, яка містить спирт, для виробництва підакцизних товарів на території України та інших потреб без сплати акцизного збору або на пільгових умовах суб'єкт підприємницької діяльності або інший споживач, що здійснює його закупівлю (далі - покупець), надає контрольному посту:

копію спеціального дозволу (ліцензії) на виробництво продукції, що ліцензується;

довідку державної податкової інспекції, в якій зазначаються обсяги і мета використання спирту або сировини, яка містить спирт, підстави для звільнення від сплати акцизного збору, а також підтверджується реєстрація покупця як платника акцизного збору (довідка видається на підставі наряду на отримання спирту);

довіреність покупця в установленій формі у разі вивезення спирту або сировини, яка його містить, безпосередньо представником покупця.

Відомості, що містяться у вищезазначених документах, реєструються у спеціальному журналі, який ведеться контрольним постом.

( Пункт 10 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

11. Відвантаження спирту та сировини, яка містить спирт, здійснюється на підставі письмового розпорядження керівника підприємства, погодженого з контрольним постом.

12. На відвантажений спирт або сировину, яка містить спирт, заповнюється спеціальна товарно-транспортна накладна, в якій контрольний пост робить відмітку про погодження відпуску.

Перевезення спирту без спеціальних товарно-транспортних накладних з відміткою контрольних постів забороняється.

13. Всі обсяги відвантаженого спирту та сировини, яка містить спирт, реєструються контрольним постом у спеціальному журналі. Контрольний пост у дводенний термін повідомляє контрольний пост на підприємстві-покупці або державну податкову інспекцію за

місцезнаходженням покупця (у разі відсутності контрольного поста) про обсяги відвантаження спирту або сировини, яка містить спирт. У разі експорту спирту або сировини, яка містить спирт, повідомлення надсилається відповідному органу митного контролю. ( Пункт 13 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

Функції контрольних постів на підприємствах, що виробляють алкогольні напої

14. Контрольні пости здійснюють контроль за обліком надходження, використання та зберігання спирту і сировини, яка містить спирт, та відвантаження алкогольних напоїв за даними складського і бухгалтерського обліку підприємств, що виробляють алкогольні напої.

15. Пропуск спирту та сировини, яка містить спирт, на підприємства, що виробляють алкогольні напої, дозволяється лише за наявності супроводжувальних документів з відмітками контрольного поста на підприємстві, що виробляє спирт або сировину, яка містить спирт, та погодження контрольного поста на підприємстві-покупці або довідки митного органу, який видав дозвіл на пропуск імпортованого спирту або сировини, яка містить спирт.

16. Контрольний пост реєструє всі обсяги прийнятого на подальшу переробку спирту або сировини, яка містить спирт, у спеціальному журналі, куди вносяться також відомості наряду, згідно з яким одержано спирт або сировину, яка містить спирт.

17. Контрольний пост на підприємстві, яке одержало спирт або сировину, яка містить спирт, або державна податкова інспекція

за місцезнаходженням іншого покупця спирту або сировини, яка містить спирт, у разі відсутності контрольного поста у дводенний термін повідомляє контрольний пост на підприємстві, що відвантажило спирт або сировину, яка містить спирт, про фактичні обсяги його надходження. ( Пункт 17 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

18. Відвантаження (реалізація) алкогольних напоїв без погодження з контрольним постом забороняється.

19. Контрольний пост у дводенний термін повідомляє державну податкову інспекцію за місцем реєстрації одержувача

алкогольних напоїв або орган митного контролю на кордоні, через який здійснюється експорт, про обсяги і асортимент відвантаженої продукції. ( Пункт 19 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

20. Перелік алкогольних напоїв, що виробляються на підприємстві, повинен відповідати переліку найменувань продукції, на виробництво яких видана ліцензія, погодженому з контрольним постом на підприємстві.

21. Транспортування алкогольних напоїв без товарно-транспортних накладних встановленого зразка з відміткою контрольних постів забороняється.

Прикінцеві положення

22. Державні податкові інспекції після одержання від

контрольних постів довідки про відвантаження (реалізацію) алкогольних напоїв реєструють її у спеціальному журналі та протягом десяти робочих днів з дня одержання здійснюють перевірку отримувачів алкогольних напоїв щодо повноти оприбуткування їх за бухгалтерським обліком. ( Пункт 22 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

23. Орган митного контролю на кордоні, через який здійснюється експорт спирту або алкогольних напоїв, у тижневий термін після проходження зазначеної продукції через митний контроль подає про це повідомлення контрольному посту на підприємстві, з якого здійснюється експорт.

24. У разі виявлення випадків неоприбуткування або неповного оприбуткування спирту та алкогольних напоїв державні податкові інспекції проводять відповідне розслідування і вживають

заходів до притягнення винних до відповідальності згідно з вимогами чинного законодавства. ( Пункт 24 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

25. У разі використання не за призначенням покупцем спирту, одержаного відповідно до чинного законодавства без сплати акцизного збору, на пільгових умовах або за зниженою ставкою акцизного збору, державна податкова інспекція стягує з цього

підприємства акцизний збір відповідно до чинного законодавства та вносить пропозиції відповідному органу, що видав цьому покупцю спеціальний дозвіл (ліцензію), про його анулювання. ( Пункт 25 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )

26. Державна автомобільна інспекція МВС та інші правоохоронні органи, уповноважені перевіряти транспортні засоби у разі здійснення перевезення алкогольних напоїв без товарно-транспортної накладної встановленого зразка з відміткою контрольних постів зобов'язані затримувати такі транспортні засоби з одночасним повідомленням підрозділів податкової міліції відповідних державних податкових інспекцій для термінового проведення ними податкового розслідування.

( Пункт 26 із змінами, внесеними згідно з Постановою КМ N 1336 ( 1336-98-п ) від 25.08.98 )
