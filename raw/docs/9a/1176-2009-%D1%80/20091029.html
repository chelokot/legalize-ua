Кабінет Міністрів України; Розпорядження, Перелік від 23.09.2009 № 1176-р

Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов

Стан: Чинний

Ідентифікатор: 1176-2009-р

Текст документа від 29.10.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 вересня 2009 р. N 1176-р Київ

Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1401-р ( 1401-2009-р ) від 21.10.2009 N 1284-р ( 1284-2009-р ) від 29.10.2009 }

1. Погодитися з пропозицією Мінрегіонбуду щодо придбання Державною іпотечною установою квартир за переліком згідно з додатком на загальну суму 99280,057 тис. гривень в житлових будинках, прийнятих в експлуатацію, та на об'єктах незавершеного житлового будівництва із строком здачі в експлуатацію не пізніше ніж 25 грудня 2009 р. за наявності відповідної банківської гарантії або іншого виду забезпечення виконання зобов'язань забудовників, що прийматимуться Державною іпотечною установою, або наявності графіка виконання будівельно-монтажних робіт, погодженого з керівником інспекції державного архітектурно-будівельного контролю в Автономній Республіці Крим, областях, мм. Києві та Севастополі, для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов та перебувають на квартирному обліку.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 1401-р ( 1401-2009-р ) від 21.10.2009 }

2. Державній іпотечній установі передати квартири, придбані згідно з пунктом 1 цього розпорядження, відповідно до затвердженого Кабінетом Міністрів України розподілу.

{ Пункт 2 в редакції Розпорядження КМ N 1284-р ( 1284-2009-р ) від 29.10.2009 }

3. Внести у додаток до розпорядження Кабінету Міністрів України від 3 вересня 2009 р. N 1047 ( 1047-2009-р ) "Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов" такі зміни:

1) у позиції "м. Яремча Івано-Франківської області, вул. Свободи, 204б, "Будівництво 30-квартирного житлового будинку на вул. Свободи, 204б в м. Яремча Івано-Франківської області" цифри та літеру "204б" замінити цифрами та літерою "204а";

2) у позиції "с. Хутір-Будилів Снятинського району Івано-Франківської області, вул. Баронська, 16б, "Реконструкція з надбудовою незавершеного будинку готельного типу під багатоквартирний житловий будинок по вул. Баронська N 16б, в с. Хутір-Будилів Снятинського району Івано-Франківської області" графу "Власник (управитель фонду), код згідно з ЄДРПОУ" доповнити словами і цифрами "фізична особа Вовк Сергій Михайлович, ідентифікаційний номер 2929620250".

4. У позиції "м. Білгород-Дністровський Одеської області, вул. Сонячна, 13в, "72-квартирний житловий будинок по вул. Сонячній, 13в, в м. Білгород-Дністровський Одеської області" додатка до розпорядження Кабінету Міністрів України від 9 вересня 2009 р. N 1081 ( 1081-2009-р ) слова і цифри "Головне управління капітального будівництва Одеської облдержадміністрації, 33656763" замінити словами і цифрами "ТОВ "Чорномор'є Плюс", 32478489".

5. Головним розпорядникам бюджетних коштів разом з Мінфіном та органами місцевого самоврядування під час уточнення показників Державного бюджету України на 2009 рік ( 835-17 ) та складання проектів державного бюджету на наступні роки передбачати кошти для компенсації Державній іпотечній установі витрат, пов'язаних з придбанням квартир відповідно до пункту 1 цього розпорядження.

{ Пункт 5 із змінами, внесеними згідно з Розпорядженням КМ N 1284-р ( 1284-2009-р ) від 29.10.2009 }
