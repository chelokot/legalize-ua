23.07.2007 N 1007/7

{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 39/7 ( v39_7323-08 ) від 21.01.2008 }

Про затвердження нового складу тендерного комітету Міністерства юстиції для закупівлі послуг юридичних радників для захисту прав та інтересів України в закордонних юрисдикційних органах

Відповідно до частини 2 статті 12 Закону України "Про закупівлю товарів, робіт та послуг за державні кошти" від 14 грудня 2000 року N 1490-III ( 1490-14 ), пункту 1.3 Положення про тендерний комітет Міністерства юстиції для закупівлі послуг юридичних радників для захисту прав та інтересів України в закордонних юрисдикційних органах, затвердженого наказом Міністерства юстиції від 21 березня 2006 року N 272/7, НАКАЗУЮ:

1. Затвердити новий склад тендерного комітету Міністерства юстиції для закупівлі послуг юридичних радників для захисту прав та інтересів України в закордонних юрисдикційних органах згідно з додатком.

2. Визнати таким, що втратив чинність, додаток до наказу Міністерства юстиції від 21 березня 2006 року N 272/7.

3. Контроль за виконанням наказу залишаю за собою.

Перший заступник Міністра В.Бондик
