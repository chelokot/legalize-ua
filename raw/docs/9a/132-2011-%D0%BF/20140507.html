Кабінет Міністрів України; Постанова, Порядок від 23.02.2011 № 132

Про затвердження Порядку використання коштів, передбачених у державному бюджеті для підготовки та участі національних збірних команд у Паралімпійських і Дефлімпійських іграх

Стан: Чинний

Ідентифікатор: 132-2011-п

Текст документа від 07.05.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 лютого 2011 р. N 132 Київ

Про затвердження Порядку використання коштів, передбачених у державному бюджеті для підготовки та участі національних збірних команд у Паралімпійських і Дефлімпійських іграх

{ Із змінами, внесеними згідно з Постановами КМ N 742 ( 742-2012-п ) від 08.08.2012 N 822 ( 822-2013-п ) від 13.11.2013 N 125 ( 125-2014-п ) від 30.04.2014 }

Відповідно до частини сьомої статті 20 Бюджетного кодексу України ( 2456-17 ) Кабінет Міністрів України постановляє:

1. Затвердити Порядок використання коштів, передбачених у державному бюджеті для підготовки та участі національних збірних команд у Паралімпійських і Дефлімпійських іграх, що додається.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 23 грудня 2009 р. N 1399 ( 1399-2009-п ) "Деякі питання фінансового забезпечення підготовки та участі національних збірних команд в Олімпійських, Паралімпійських і Дефлімпійських іграх" (Офіційний вісник України, 2009 р., N 100, ст. 3473).

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 23 лютого 2011 р. N 132

ПОРЯДОК використання коштів, передбачених у державному бюджеті для підготовки та участі національних збірних команд у Паралімпійських і Дефлімпійських іграх

{ У тексті Порядку слова “для спортсменів та тренерів” виключено на підставі Постанови КМ N 742 ( 742-2012-п ) від 08.08.2012 }

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті за програмою "Підготовка і участь національних збірних команд в Паралімпійських і Дефлімпійських іграх" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів та відповідальним виконавцем бюджетної програми є Мінмолодьспорт. { Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 822 ( 822-2013-п ) від 13.11.2013 }

{ Абзац другий пункту 2 виключено на підставі Постанови КМ N 822 ( 822-2013-п ) від 13.11.2013 }

Розпорядники бюджетних коштів нижчого рівня, які безпосередньо здійснюють видатки за напрямами, зазначеними в пункті 3 цього Порядку, визначаються головним розпорядником бюджетних коштів з урахуванням вимог щодо формування єдиного реєстру розпорядників бюджетних коштів і одержувачів бюджетних коштів та даних такого реєстру. { Абзац третій пункту 2 із змінами, внесеними згідно з Постановою КМ N 822 ( 822-2013-п ) від 13.11.2013 }

3. Бюджетні кошти з метою забезпечення належної підготовки та результативної участі національних збірних команд в літніх та зимових Паралімпійських і Дефлімпійських іграх спрямовуються на:

1) у рік проведення літніх (зимових) Паралімпійських і Дефлімпійських ігор:

проведення в Україні та за кордоном навчально-тренувальних зборів заключного етапу підготовки спортсменів - кандидатів до складу національних збірних команд на літніх (зимових) Паралімпійських і Дефлімпійських іграх (далі - національні збірні команди), включених до Єдиного календарного плану фізкультурно-оздоровчих та спортивних заходів на поточний рік;

здійснення витрат, пов'язаних із забезпеченням участі національних збірних команд в літніх (зимових) Паралімпійських і Дефлімпійських іграх (оплата проживання відповідно до умов прийому, що встановлені організаційним комітетом ігор, харчування, проїзду, бронювання квитків, перевезення багажу, транспортних послуг, у тому числі придбання пально-мастильних матеріалів, послуг поштового, телеграфного та телефонного зв'язку, страхування, оформлення віз, виплата добових, внесок за участь національних збірних команд в зазначених іграх, придбання медикаментів та перев'язувальних матеріалів, у тому числі медико-відновлювальних засобів, придбання і виготовлення сувенірної, поліграфічної продукції, квітів, придбання спортивного одягу, взуття та аксесуарів загального і спеціального призначення, парадного одягу, канцелярських товарів, малоцінних предметів (строк експлуатації яких не перевищує 365 календарних днів або вартість яких без податку на додану вартість не перевищує 2500 гривень), матеріалів спортивного призначення, спортивного інвентарю індивідуального користування, оплата інших послуг, необхідних для забезпечення участі національних збірних команд в зазначених іграх), включаючи організацію роботи штабу паралімпійської (дефлімпійської) підготовки за місцем проведення ігор та матеріально-технічне забезпечення участі його членів у таких іграх; { Абзац третій підпункту 1 пункту 3 із змінами, внесеними згідно з Постановами КМ N 742 ( 742-2012-п ) від 08.08.2012, N 822 ( 822-2013-п ) від 13.11.2013 }

виплату винагород спортсменам - чемпіонам і призерам літніх (зимових) Паралімпійських і Дефлімпійських ігор та їх тренерам відповідно до постанови Кабінету Міністрів України від 6 серпня 2008 р. N 704 ( 704-2008-п ) "Про заохочення спортсменів-інвалідів та їх тренерів" (Офіційний вісник України, 2008 р., N 60, ст. 2036);

висвітлення в засобах масової інформації ходу підготовки та участі національних збірних команд у літніх (зимових) Паралімпійських і Дефлімпійських іграх (виготовлення та розміщення тематичних відеороликів і фільмів, інформаційних повідомлень у засобах масової інформації);

організацію і проведення урочистих церемоній проводів національної збірної команди на літні (зимові) Паралімпійські і Дефлімпійські ігри, зустрічей після повернення з ігор, заходів з відзначення спортсменів - чемпіонів та призерів таких ігор та їх тренерів за участю Президента України, Голови Верховної Ради України, Прем’єр-міністра України (оплата проживання, проїзду, бронювання квитків, виплата добових членам національної збірної команди - учасникам зазначених заходів, крім випадків, коли такі заходи проводяться безпосередньо перед відрядженням національної збірної команди на літні (зимові) Паралімпійські і Дефлімпійські ігри чи одразу після повернення з них, придбання і виготовлення сувенірної, поліграфічної продукції, квітів, канцелярських товарів, оплата транспортних послуг, витрат, пов’язаних з орендою приміщень та обладнання, інших послуг, необхідних для проведення таких заходів); { Підпункт 1 пункту 3 доповнено абзацом згідно з Постановою КМ N 822 ( 822-2013-п ) від 13.11.2013 }

2) у рік, що передує року проведення зимових Паралімпійських і Дефлімпійських ігор:

проведення в Україні та за кордоном навчально-тренувальних зборів заключного етапу підготовки спортсменів - кандидатів до складу національних збірних команд на зимових Паралімпійських і Дефлімпійських іграх, включених до Єдиного календарного плану фізкультурно-оздоровчих та спортивних заходів на поточний рік;

здійснення витрат, пов'язаних із забезпеченням участі національних збірних команд в зимових Паралімпійських і Дефлімпійських іграх (оплата проїзду, в тому числі бронювання квитків, оформлення віз, придбання і виготовлення сувенірної, поліграфічної продукції, спортивного одягу, взуття та аксесуарів загального і спеціального призначення, парадного одягу, малоцінних предметів та інвентарю (строк експлуатації яких не перевищує 365 календарних днів або вартість яких без податку на додану вартість не перевищує 2500 гривень), матеріалів спортивного призначення, спортивного інвентарю індивідуального користування, оплата інших послуг, необхідних для забезпечення участі національних збірних команд в зазначених іграх), включаючи організацію роботи штабу паралімпійської (дефлімпійської) підготовки за місцем проведення ігор та матеріально-технічне забезпечення участі його членів у таких іграх. { Абзац третій підпункту 2 пункту 3 із змінами, внесеними згідно з Постановами КМ N 742 ( 742-2012-п ) від 08.08.2012, N 822 ( 822-2013-п ) від 13.11.2013 }

Заключний етап підготовки спортсменів - кандидатів до складу національних збірних команд до літніх Паралімпійських і Дефлімпійських ігор розпочинається з 1 січня року проведення зазначених ігор, до зимових Паралімпійських і Дефлімпійських ігор - з 1 липня року, що передує року проведення зазначених ігор;

3) виплату у 2014 році грошових винагород тренерам спортсменів - чемпіонів і призерів XXII літніх Дефлімпійських ігор, які проходили у 2013 році.

{ Пункт 3 доповнено підпунктом 3 згідно з Постановою КМ N 125 ( 125-2014-п ) від 30.04.2014 }

4. Розподіл бюджетних коштів за напрямами, зазначеними в пункті 3 цього Порядку, здійснюється головним розпорядником бюджетних коштів з урахуванням обґрунтованої потреби в коштах і детальних розрахунків витрат, визначених на підставі норм та нормативів, діючих цін і тарифів, кількісного складу національних збірних команд, переліку необхідного інвентарю, спортивного одягу, взуття та аксесуарів загального і спеціального призначення, парадного одягу, календарних планів заходів та регламентних документів міжнародних спортивних організацій тощо, а також з урахуванням необхідності виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державної казначейської служби, у разі їх відповідності паспорту бюджетної програми. { Абзац перший пункту 4 із змінами, внесеними згідно з Постановою КМ N 822 ( 822-2013-п ) від 13.11.2013 }

Склад національних збірних команд, перелік необхідного спортивного інвентарю, одягу, взуття та аксесуарів загального і спеціального призначення, парадного одягу затверджується Мінмолодьспортом за погодженням з Національним комітетом спорту інвалідів. До складу національних збірних команд включаються також особи, що супроводжують спортсменів-інвалідів. { Абзац другий пункту 4 із змінами, внесеними згідно з Постановою КМ N 822 ( 822-2013-п ) від 13.11.2013 }

5. Закупівля товарів і послуг за бюджетні кошти здійснюється в установленому законодавством порядку.

6. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку казначейського обслуговування державного бюджету за витратами ( z0130-13 ), затвердженого Мінфіном.

{ Пункт 6 із змінами, внесеними згідно з Постановою КМ N 125 ( 125-2014-п ) від 30.04.2014 }

7. Не допускається спрямування бюджетних коштів на:

придбання товарів і послуг, які безпосередньо не пов'язані з організацією та проведенням навчально-тренувальних зборів заключного етапу підготовки національних збірних команд, забезпеченням їх участі в літніх (зимових) Паралімпійських і Дефлімпійських іграх;

оплату участі в літніх (зимових) Паралімпійських і Дефлімпійських іграх осіб, які безпосередньо не здійснюють підготовку спортсменів національних збірних команд до таких змагань, а також тих, участь яких у зазначених іграх не є обов'язковою, в тому числі офіційних осіб;

оплату посередницьких послуг;

здійснення видатків, які фінансуються за рахунок інших бюджетних програм.

8. Складення та подання звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються відповідно до законодавства.

{ Пункт 9 виключено на підставі Постанови КМ N 822 ( 822-2013-п ) від 13.11.2013 }
