Текст документа від 07.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 грудня 2011 р. N 1261 Київ

Про внесення змін до постанов Кабінету Міністрів України від 28 березня 2011 р. N 334 і від 28 вересня 2011 р. N 1025

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 28 березня 2011 р. N 334 ( 334-2011-п ) "Деякі питання використання у 2011 році державних капітальних видатків" (Офіційний вісник України, 2011 р., N 24, ст. 999, N 35, ст. 1440, N 44, ст. 1785, N 46, ст. 1884, N 73, ст. 2736, N 77, ст. 2860, ст. 2861, N 87, ст. 3164, N 85, ст. 3106) і від 28 вересня 2011 р. N 1025 ( 1025-2011-п ) "Деякі питання будівництва підземних відділень алергологічних лікарень на території Солотвинського родовища кам'яної солі Закарпатської області" (Офіційний вісник України, 2011 р., N 77, ст. 2860) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 грудня 2011 р. N 1261

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 28 березня 2011 р. N 334 ( 334-2011-п ) та від 28 вересня 2011 р. N 1025 ( 1025-2011-п )

1. У підпункті 20 пункту 2 постанови Кабінету Міністрів України від 28 березня 2011 р. N 334 ( 334-2011-п ) слова "Солотвинського родовища кам'яної солі" замінити словами "покладів кам'яної солі у межах Тереблянського купола Солотвинської западини".

2. У постанові Кабінету Міністрів України від 28 вересня 2011 р. N 1025 ( 1025-2011-п ):

1) у назві та пункті 1 постанови слова "Солотвинського родовища кам'яної солі" замінити словами "покладів кам'яної солі у межах Тереблянського купола Солотвинської западини";

2) у Порядку використання коштів, передбачених у державному бюджеті для розроблення проектно-кошторисної документації та початку робіт з будівництва підземних відділень алергологічних лікарень на території Солотвинського родовища кам'яної солі Закарпатської області ( 1025-2011-п ), затвердженому зазначеною постановою:

у назві Порядку ( 1025-2011-п ) слова "Солотвинського родовища кам'яної солі" замінити словами "покладів кам'яної солі у межах Тереблянського купола Солотвинської западини";

у пункті 6 слова "кам'яної солі Солотвинського родовища" замінити словами "покладів кам'яної солі у межах Тереблянського купола Солотвинської западини";

у тексті Порядку ( 1025-2011-п ) слова "Солотвинського родовища кам'яної солі" замінити словами "покладів кам'яної солі у межах Тереблянського купола Солотвинської западини".
