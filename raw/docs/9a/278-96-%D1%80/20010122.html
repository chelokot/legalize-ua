Кабінет Міністрів України; Розпорядження від 13.04.1996 № 278-р

Про створення робочої групи для здійснення оперативного нагляду за реалізацією програми економічних реформ в Україні

Стан: Втратив чинність

Ідентифікатор: 278-96-р

Текст документа від 22.01.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 квітня 1996 р. N 278-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 34 ( 34-2001-п ) від 22.01.2001 )

Для здійснення оперативного нагляду за реалізацією програми економічних реформ в Україні, підтриманої міжнародними фінансовими організаціями, та забезпечення діяльності Міжвідомчої ради з впровадження програми економічних реформ, утвореної відповідно до постанови Кабінету Міністрів України від 16.01.96 р. N 86 ( 86-96-п ), створити робочу групу у складі згідно з додатком.

Прем'єр-міністр України Є.МАРЧУК

Інд. 27

Додаток до розпорядження Кабінету Міністрів України від 13 квітня 1996 р. N 278-р

СКЛАД робочої групи Міжвідомчої ради з впровадження програми економічних реформ

БУКОВИНСЬКИЙ - перший заступник Міністра фінансів Станіслав Альбінович

ТЕНТЮК - заступник Міністра фінансів, начальник Віктор Петрович Головного управління Державного казначейства

НАУМЕНКО - заступник Міністра економіки Володимир Іванович

ГРЕБЕННИК - директор емісійно-кредитного Наталія Іванівна департаменту Національного банку

МАКСЮТА - начальник головного бюджету управління Анатолій Аркадійович Мінфіну

КУЧИН - заступник начальника Головного Леонід Степанович управління Державного казначейства

ШУМИЛО - начальник зведеного відділу стратегії Ігор Анатолійович економічного розвитку та балансів національної економіки Мінекономіки
