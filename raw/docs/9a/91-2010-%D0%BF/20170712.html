Стан: Чинний

Текст документа від 12.07.2017:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 січня 2010 р. N 91 Київ

Про встановлення винагород спортсменам України - чемпіонам, призерам Олімпійських ігор та їх тренерам

{ Із змінами, внесеними згідно з Постановами КМ N 1312 ( 1312-2011-п ) від 21.12.2011 N 749 ( 749-2012-п ) від 01.08.2012 N 550 ( 550-2013-п ) від 24.07.2013 N 760 ( 760-2013-п ) від 17.10.2013 N 91 ( 91-2016-п ) від 04.02.2016 N 463 ( 463-2017-п ) від 14.06.2017 }

З метою відзначення спортсменів, які своїми досягненнями сприяють утвердженню міжнародного авторитету України, підвищення їх соціального захисту та заохочення до успішних виступів на міжнародних змаганнях Кабінет Міністрів України постановляє:

1. Установити спортсменам України - чемпіонам, призерам Олімпійських ігор та їх тренерам починаючи з ХХХ літніх Олімпійських ігор винагороди у таких розмірах: I місце - 125 тис. доларів США, II місце - 80 тис., III місце - 55 тис. доларів США. { Пункт 1 в редакції Постанови КМ N 749 ( 749-2012-п ) від 01.08.2012 }

2. Виплата винагород спортсменам України - чемпіонам, призерам Олімпійських ігор та їх тренерам здійснюється відповідно до постанови Кабінету Міністрів України від 4 лютого 2016 р. N 91 ( 91-2016-п ) "Про заохочення спортсменів і тренерів з олімпійських та неолімпійських видів спорту".

{ Пункт 2 в редакції Постанови КМ N 91 ( 91-2016-п ) від 04.02.2016 }

3. Винагороди виплачуються у гривнях за офіційним курсом гривні до долара США, встановленим Національним банком на дату прийняття організаторами відповідних Олімпійських ігор рішення щодо результатів змагань, яке є підставою для отримання права на такі винагороди, за рахунок коштів, передбачених у державному бюджеті Міністерству молоді та спорту для проведення заходів з фізичної культури і спорту.

{ Пункт 3 із змінами, внесеними згідно з Постановами КМ N 1312 ( 1312-2011-п ) від 21.12.2011, N 760 ( 760-2013-п ) від 17.10.2013; в редакції Постанови КМ N 463 ( 463-2017-п ) від 14.06.2017 }

{ Пункт 4 втратив чинність на підставі Постанови КМ N 91 ( 91-2016-п ) від 04.02.2016 }

5. Виплата винагород спортсменам - чемпіонам, призерам попередніх Олімпійських ігор та їх тренерам у разі прийняття організаторами відповідних Олімпійських ігор рішення щодо результатів змагань, яке є підставою для отримання права на такі винагороди, здійснюється у розмірах та порядку, визначених цією постановою.

{ Постанову доповнено пунктом 5 згідно з Постановами КМ N 463 ( 463-2017-п ) від 14.06.2017 }
