КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 червня 2004 р. N 731 Київ

Про затвердження Порядку призначення та проведення компенсаційних виплат у разі загибелі (смерті) або каліцтва військовослужбовців Державної прикордонної служби

( Із змінами, внесеними згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

Відповідно до статті 26 Закону України "Про Державну прикордонну службу України" ( 661-15 ) Кабінет Міністрів України постановляє:

Затвердити Порядок призначення та проведення компенсаційних виплат у разі загибелі (смерті) або каліцтва військовослужбовців Державної прикордонної служби, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 2 червня 2004 р. N 731

ПОРЯДОК призначення та проведення компенсаційних виплат у разі загибелі (смерті) або каліцтва військовослужбовців Державної прикордонної служби

1. Компенсаційні виплати військовослужбовцям Держприкордонслужби (далі - військовослужбовці) проводяться в разі:

поранення (контузії, травми або каліцтва), захворювання, одержаного під час виконання службових обов'язків пов'язаних з безпосередньою охороною державного кордону чи суверенних прав України в її виключній (морській) економічній зоні у складі прикордонного наряду, екіпажу корабля (катера), екіпажу літака (вертольота) або проведення оперативно-розшукових заходів, або здійснення самостійно чи у складі підрозділу відбиття збройного нападу або вторгнення на територію України військових груп і злочинних угруповань, припинення збройних конфліктів та інших провокацій на державному кордоні (далі - поранення або захворювання), чи у разі встановлення інвалідності внаслідок зазначених ушкоджень - у розмірі до десятирічного грошового забезпечення; ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

настання інвалідності в період проходження служби чи не пізніше ніж через три місяці після звільнення із служби, чи після закінчення цього строку, але внаслідок захворювання або нещасного випадку, що мали місце в період проходження служби (далі - захворювання або нещасний випадок), - у розмірі до річного грошового забезпечення. ( Абзац третій пункту 1 із змінами, внесеними згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

2. У разі загибелі або смерті військовослужбовця Держприкордонслужби під час виконання службових обов'язків пов'язаних з безпосередньою охороною державного кордону чи суверенних прав України в її виключній (морській) економічній зоні у складі прикордонного наряду, екіпажу корабля (катера), екіпажу літака (вертольота) або проведення оперативно-розшукових заходів, або здійснення самостійно чи у складі підрозділу відбиття збройного нападу або вторгнення на територію України військових груп і злочинних угруповань, припинення збройних конфліктів та інших провокацій на державному кордоні членам його сім'ї компенсаційні виплати проводяться у розмірі двадцятирічного грошового забезпечення. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

3. Розмір компенсаційної виплати визначається відповідно до грошового забезпечення за останньою посадою, яку займав військовослужбовець на день втрати працездатності, з урахуванням посадового окладу, окладу за військове звання, відсоткових надбавок за вислугу років, інших надбавок, доплат та премій, які мають щомісячний постійний характер.

У разі встановлення групи інвалідності після проведення військовослужбовцю компенсаційної виплати у зв'язку з пораненням або захворюванням компенсаційна виплата у зв'язку з інвалідністю призначається з урахуванням раніше виплаченої суми.

4. Розмір компенсаційної виплати військовослужбовцю у разі поранення або захворювання визначається відповідно до ступеня втрати працездатності, який визначається медико-соціальною експертною комісією, у відсотках розміру десятирічного грошового забезпечення.

5. Компенсаційна виплата військовослужбовцю у разі настання інвалідності внаслідок поранення або захворювання проводиться у таких розмірах:

інвалідам першої групи - десятирічне грошове забезпечення;

інвалідам другої групи - шестирічне грошове забезпечення;

інвалідам третьої групи - чотирирічне грошове забезпечення.

6. Компенсаційна виплата військовослужбовцю у зв'язку з настанням інвалідності внаслідок захворювання або нещасного випадку проводиться у таких розмірах:

інвалідам першої групи - річне грошове забезпечення; ( Абзац другий пункту 6 із змінами, внесеними згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

інвалідам другої групи - піврічне грошове забезпечення; ( Абзац третій пункту 6 із змінами, внесеними згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

інвалідам третьої групи - тримісячне грошове забезпечення. ( Абзац четвертий пункту 6 із змінами, внесеними згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

7. Для проведення компенсаційної виплати у разі поранення або захворювання чи у разі настання інвалідності військовослужбовець подає до Адміністрації Держприкордонслужби, її територіального органу, морської охорони, органу охорони державного кордону, розвідувального органу, навчального закладу, науково-дослідної установи, підрозділу спеціального призначення та органу забезпечення Держприкордонслужби (далі - органи Держприкордонслужби) за місцем проходження служби такі документи:

рапорт (заяву) про проведення компенсаційної виплати у зв'язку із захворюванням чи настанням інвалідності;

рішення медико-соціальної експертної комісії щодо визначення ступеня втрати працездатності внаслідок поранення або захворювання чи встановлення інвалідності;

довідку органу реєстрації або відповідного житлово-експлуатаційного підприємства, організації чи органу місцевого самоврядування про своє місце проживання та місце перебування або копію сторінок паспорта з даними про прізвище, ім'я та по батькові і місце проживання;

довідку, видану Національною страховою компанією "ОРАНТА", про розмір страхової суми, яка підлягає виплаті військовослужбовцю відповідно до Умов державного обов'язкового особистого страхування військовослужбовців і військовозобов'язаних, призваних на збори, і порядку виплат їм та членам їх сімей страхових сум, затверджених постановою Кабінету Міністрів України від 19 серпня 1992 р. N 488 ( 488-92-п ), у разі настання страхової події, за якою проводиться компенсаційна виплата (далі - довідка Національної страхової компанії "ОРАНТА"). ( Пункт 7 доповнено абзацом згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

8. Для проведення компенсаційної виплати в разі загибелі або смерті військовослужбовця заінтересовані члени його сім'ї подають до органу Держприкордонслужби за місцем проходження служби військовослужбовця такі документи:

заяву про проведення компенсаційної виплати дружини (чоловіка), кожного іншого повнолітнього члена сім'ї, а у разі наявності неповнолітніх дітей - іншого з батьків або опікунів чи піклувальників дітей;

витяг з наказу про виключення загиблого військовослужбовця із списків особового складу Держприкордонслужби;

копію довідки кадрового підрозділу органу Держприкордонслужби про обставини загибелі військовослужбовця;

копію свідоцтва про смерть військовослужбовця;

копію свідоцтва про шлюб військовослужбовця - для виплати компенсації дружині (чоловікові);

копії свідоцтва про народження дітей - для проведення компенсаційної виплати дітям;

довідку навчального закладу про навчання повнолітніх дітей;

довідку органу реєстрації або відповідного житлово-експлуатаційного підприємства, організації чи органу місцевого самоврядування про місце проживання та місце перебування або копію сторінок паспорта з даними про прізвище, ім'я та по батькові і місце проживання дружини (чоловіка), дітей або опікуна чи піклувальника дітей та інших осіб, що проживали однією сім'єю з військовослужбовцем;

копію посвідчення про призначення особи опікуном чи піклувальником (у разі здійснення опіки чи піклування над дітьми військовослужбовця);

довідку кадрового підрозділу органу Держприкордонслужби про родинні стосунки військовослужбовця з особами, які перебували на його утриманні, складену за матеріалами його особової справи з доданими до неї копіями свідоцтв про народження, про шлюб тощо;

довідку Національної страхової компанії "ОРАНТА". ( Пункт 8 доповнено абзацом згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

9. Орган Держприкордонслужби, у якому проходив службу військовослужбовець, подає до Адміністрації Держприкордонслужби висновок щодо можливості проведення компенсаційної виплати, до якого додаються документи, зазначені в пунктах 7 і 8 цього Порядку, а також копію висновку службового розслідування за фактом поранення або захворювання військовослужбовця чи його загибелі або смерті. ( Абзац перший пункту 9 із змінами, внесеними згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

Адміністрація Держприкордонслужби приймає на підставі зазначених документів рішення про призначення компенсаційної виплати і надсилає його разом з цими документами до органу Держприкордонслужби, у якому проходив службу військовослужбовець, для видання наказу про проведення компенсаційної виплати військовослужбовцю або членам його сім'ї.

Компенсаційна виплата військовослужбовцю або членам його сім'ї проводиться шляхом перерахування її суми на рахунок в установі банку, поштовим переказом або через касу органу Держприкордонслужби.

10. Компенсаційні виплати не проводяться, якщо загибель або смерть, поранення або захворювання чи інвалідність:

настали у зв'язку з вчиненням військовослужбовцем злочину чи адміністративного правопорушення або є наслідком вчинення дій у стані алкогольного сп'яніння чи у стані, зумовленому вживанням наркотичних засобів, психотропних речовин, їх аналогів, інших одурманюючих засобів; ( Абзац другий пункту 10 із змінами, внесеними згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

є наслідком умисного заподіяння військовослужбовцем собі тілесного ушкодження;

настали внаслідок шкоди, яку військовослужбовець завдав собі джерелом підвищеної небезпеки, у разі, коли він особисто на відповідній правовій підставі (право власності, інше речове право, договір підряду, оренди тощо) володів транспортним засобом, механізмом, іншим об'єктом, використання, зберігання або утримання якого створювало підвищену небезпеку. ( Пункт 10 доповнено абзацом згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )

11. Компенсаційні виплати згідно з цією постановою проводяться за рахунок коштів, передбачуваних у державному бюджеті на утримання Держприкордонслужби.

Сума компенсаційної виплати зменшується на суму страхової виплати, яку має одержати військовослужбовець або його сім'я відповідно до статті 16 Закону України "Про соціальний і правовий захист військовослужбовців та членів їх сімей" ( 2011-12 ) та Умов і порядку, зазначених в абзаці п'ятому пункту 7 цього Порядку.

( Пункт 11 доповнено абзацом згідно з Постановою КМ N 1549 ( 1549-2004-п ) від 17.11.2004 )
