Про придбання обладнання для технічного переоснащення підприємств геологічної галузі за рахунок коштів державного бюджету

Стан: Втратив чинність

Ідентифікатор: 1190-98-п

Текст документа від 14.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 липня 1998 р. N 1190 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 279 ( 279-2006-п ) від 14.03.2006 }

Про придбання обладнання для технічного переоснащення підприємств геологічної галузі за рахунок коштів державного бюджету

Кабінет Міністрів України постановляє:

1. Погодитися з пропозиціями Державного комітету по геології і використанню надр про:

використання у розмірі до 15 відсотків коштів, передбачених цьому Комітетові в державному бюджеті на проведення геологорозвідувальних робіт, для придбання обладнання для технічного переоснащення підприємств геологічної галузі, що належать до сфери його управління;

централізацію коштів, передбачених для придбання обладнання, на окремому бюджетному рахунку Комітету.

2. Міністерству фінансів:

разом з Міністерством економіки під час формування видатків державного бюджету на проведення геологорозвідувальних робіт враховувати, що до 15 відсотків зазначених коштів мають спрямовуватися Державним комітетом по геології і використанню надр на придбання обладнання для технічного переоснащення підприємств геологічної галузі;

забезпечити перерахування коштів, передбачених для придбання цього обладнання, на окремий бюджетний рахунок Комітету.

Перший віце-прем'єр-міністр України А.ГОЛУБЧЕНКО
