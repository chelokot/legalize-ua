КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 лютого 1998 р. N 150 Київ

Про внесення змін до ставок ввізного мита на окремі види товарів та до деяких постанов Кабінету Міністрів України

( Із змінами, внесеними згідно з Постановами КМ N 1401 ( 1401-99-п ) від 30.07.99 N 1798 ( 1798-99-п ) від 27.09.99 N 40 ( 40-2000-п ) від 15.01.2000 N 121 ( 121-2000-п ) від 24.01.2000 )

Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита на окремі види товарів ( 4а-93, 4б-93, 4в-93 ) згідно з додатком.

2. Затвердити зміни, що вносяться до деяких постанов Кабінету Міністрів України (додаються).

3. Ця постанова набирає чинності через 45 днів з дня її опублікування у газеті "Урядовий кур'єр".
