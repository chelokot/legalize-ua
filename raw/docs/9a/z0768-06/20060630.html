Про визнання таким, що втратив чинність, наказу Міністерства юстиції від 16.07.99 N 43/5 "Про затвердження Положення про районний, міський (міст обласного значення), районний у містах відділ державної виконавчої служби"

Стан: Чинний

Ідентифікатор: z0768-06

Текст документа від 30.06.2006:

МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

30.06.2006 N 52/5

Зареєстровано в Міністерстві юстиції України 3 липня 2006 р. за N 768/12642

Про визнання таким, що втратив чинність, наказу Міністерства юстиції від 16.07.99 N 43/5 "Про затвердження Положення про районний, міський (міст обласного значення), районний у містах відділ державної виконавчої служби"

Відповідно до Закону України "Про внесення змін до законів України "Про державну виконавчу службу" та "Про виконавче провадження" від 23 червня 2005 року N 2716-IV ( 2716-15 ), Указу Президента України від 20 квітня 2005 року N 701/2005 ( 701/2005 ) "Питання Міністерства юстиції України" (із змінами і доповненнями), постанови Кабінету Міністрів України від 23 квітня 2005 року N 320 ( 320-2005-п ) "Про утворення урядового органу державного управління у складі Міністерства юстиції" та Положення про Департамент державної виконавчої служби, затвердженого постановою Кабінету Міністрів України від 3 серпня 2005 року N 711 ( 711-2005-п ), НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства юстиції від 16 липня 1999 року N 43/5 ( z0484-99 ) "Про затвердження Положення про районний, міський (міст обласного значення), районний у містах відділ державної виконавчої служби", зареєстрований в Мін'юсті 20 липня 1999 року за N 484/3777.

2. В.о. директора Департаменту державної виконавчої служби Стадніку Г.В. забезпечити державну реєстрацію цього наказу відповідно до Указу Президента України від 3 жовтня 1992 року N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами та доповненнями).

3. Контроль за виконанням цього наказу покласти на заступника Міністра юстиції І.І.Ємельянову.

Міністр Сергій Головатий
