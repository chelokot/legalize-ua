N 749 від 22.12.2000 Зареєстровано в Міністерстві м.Київ юстиції України 19 січня 2001 р. vd20001222 vn749 за N 46/5237

( Наказ втратив чинність на підставі Наказу Державної митної служби N 345 ( z0597-02 ) від 02.07.2002 )

Про внесення доповнення до розділу 1 Положення про порядок контролю за ввезенням на митну територію України окремих видів товарів

Відповідно до постанови Кабінету Міністрів України від 02.04.98 N 419 ( 419-98-п ) та з метою вдосконалення контролю за ввезенням на митну територію України окремих видів товарів НАКАЗУЮ:

1. Розділ 1 Положення про порядок контролю за ввезенням на митну територію України окремих видів товарів, затвердженого наказом Держмитслужби від 04.05.98 N 267 ( z0339-98 ) і зареєстрованого в Міністерстві юстиції України 21.05.98 за N 339/2779, доповнити такими пунктами:

"1.17. При оформленні ПД на ввезення в Україну вантажів як унеску до статутного фонду підприємств з іноземними інвестиціями сплата нарахованих платежів здійснюється шляхом подання митниці векселя, який є підставою для застосування пільгового режиму в оподаткуванні при митному оформленні.

1.18. Для вантажів, що ввозяться на митну територію України з метою реалізації інвестиційних проектів, застосовується ПД з умовно нарахованими платежами у разі подання митниці потрібних документів, які при митному оформленні є підставою для застосування пільгового режиму в оподаткуванні.

1.19. При оформленні ПД на продукцію, яка поставляється за виробничою кооперацією відповідно до угод про виробничу кооперацію між Кабінетом Міністрів України й урядами держав-учасниць СНД, сплата нарахованих платежів здійснюється шляхом подання митниці векселя, оформленого згідно з Порядком оформлення векселями сплати податків з продукції, що поставляється за виробничою кооперацією, та їх погашення, затвердженим постановою Кабінету Міністрів України від 24.11.97 N 1303 ( 1303-97-п )".

2. Управлінню нетарифного регулювання (Пашинний О.І.) та Правовому управлінню (Мельник М.В.) зареєструвати наказ у Міністерстві юстиції України.

3. Начальникам регіональних митниць, митниць довести цей наказ до відома суб'єктів підприємницької діяльності.

4. Контроль за виконанням цього наказу покласти на заступника Голови Служби Соболя І.М.
