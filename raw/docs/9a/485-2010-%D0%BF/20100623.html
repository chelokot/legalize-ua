Кабінет Міністрів України; Постанова від 23.06.2010 № 485

Про порядок використання у 2010 році коштів, передбачених у державному бюджеті для обслуговування кредитів, залучених для реалізації проекту "Циклон-4"

Стан: Чинний

Ідентифікатор: 485-2010-п

Текст документа від 23.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 червня 2010 р. N 485 Київ

Про порядок використання у 2010 році коштів, передбачених у державному бюджеті для обслуговування кредитів, залучених для реалізації проекту "Циклон-4"

Кабінет Міністрів України постановляє:

Установити, що у 2010 році кошти, передбачені у державному бюджеті за програмою "Обслуговування кредитів, залучених для реалізації проекту "Циклон-4" ( 2154-17 ), використовуються відповідно до Порядку, затвердженого постановою Кабінету Міністрів України від 14 березня 2007 р. N 451 ( 451-2007-п ) (Офіційний вісник України, 2007 р., N 21, ст. 830; 2008 р., N 24, ст. 741; 2009 р., N 24, ст. 807).

Внести до зазначеного Порядку ( 451-2007-п ) такі зміни:

у пункті 2 слова "Державне конструкторське бюро "Південне" імені М.К. Янгеля, м. Дніпропетровськ" замінити словами "державне підприємство "Конструкторське бюро "Південне" імені М.К. Янгеля", м. Дніпропетровськ";

абзац перший пункту 3 виключити;

абзац другий пункту 4 викласти в такій редакції:

"Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.".

Прем'єр-міністр України М.АЗАРОВ
