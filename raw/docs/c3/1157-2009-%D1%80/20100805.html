Кабінет Міністрів України; Розпорядження від 03.09.2009 № 1157-р

Про виділення коштів для здійснення в регіонах деяких невідкладних природоохоронних заходів

Стан: Чинний

Ідентифікатор: 1157-2009-р

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 вересня 2009 р. N 1157-р Київ

Про виділення коштів для здійснення в регіонах деяких невідкладних природоохоронних заходів

{ Із змінами, внесеними згідно з Постановами КМ N 1134 ( 1134-2009-п ) від 14.10.2009 N 1339 ( 1339-2009-п ) від 02.12.2009 N 666 ( 666-2010-п ) від 28.07.2010 }

1. Виділити у 2009 році за рахунок залишку коштів Державного фонду охорони навколишнього природного середовища, який утворився на 1 січня 2009 року:

Мінрегіонбуду 35 млн. гривень для проведення першочергових робіт з будівництва системи відводу стічних вод від станції біологічної очистки "Північна" в м. Одесі;

Мінприроди 48,5 млн. гривень для здійснення в регіонах невідкладних природоохоронних заходів з очищення стічних вод, забезпечення екологічно безпечного збирання, перевезення, зберігання, оброблення та знешкодження непридатних пестицидів, небезпечних хімічних речовин, будівництва і реконструкції сміттєзвалищ, придбання обладнання та машин для безпечного поводження з побутовими відходами.

Визначити Мінрегіонбуд та Мінприроди головними розпорядниками коштів Державного фонду охорони навколишнього природного середовища, виділених на зазначені цілі.

Мінфіну забезпечити визначення бюджетної програми, закріплення за нею кодів програмної та функціональної класифікації видатків кредитування бюджету та внесення змін до розпису державного бюджету.

{ Пункт 1 в редакції Постанов КМ N 1134 ( 1134-2009-п ) від 14.10.2009, N 1339 ( 1339-2009-п ) від 02.12.2009 }

{ Пункт 2 втратив чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

3. Мінрегіонбуду та Мінприроди:

забезпечити використання виділених згідно з пунктом 1 цього розпорядження коштів з урахуванням Порядку державного фінансування капітального будівництва, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) (Офіційний вісник України, 2001 р., N 52, ст. 2374);

подати до 20 січня 2010 р. Мінфіну та Державному казначейству звіт про використання зазначених коштів.

{ Пункт 3 в редакції Постанов КМ N 1134 ( 1134-2009-п ) від 14.10.2009, N 1339 ( 1339-2009-п ) від 02.12.2009 }
