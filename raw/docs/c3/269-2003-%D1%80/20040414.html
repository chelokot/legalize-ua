Кабінет Міністрів України; Розпорядження від 15.05.2003 № 269-р

Про зміну складу Міжвідомчої комісії з питань заміни системи пільг на адресну грошову допомогу населенню

Стан: Втратив чинність

Ідентифікатор: 269-2003-р

Текст документа від 14.04.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 травня 2003 р. N 269-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 457 ( 457-2004-п ) від 14.04.2004 )

Про зміну складу Міжвідомчої комісії з питань заміни системи пільг на адресну грошову допомогу населенню

На часткову зміну розпорядження Кабінету Міністрів України від 11 липня 2002 р. N 382 ( 382-2002-р ) (Офіційний вісник України, 2002 р., N 29, ст. 1385) затвердити новий склад Міжвідомчої комісії з питань заміни системи пільг на адресну грошову допомогу населенню, що додається.
