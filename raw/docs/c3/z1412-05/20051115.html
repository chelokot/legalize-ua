ПРАВЛІННЯ ПЕНСІЙНОГО ФОНДУ УКРАЇНИ

ПОСТАНОВА

15.11.2005 N 21-1

Зареєстровано в Міністерстві юстиції України 23 листопада 2005 р. за N 1412/11692

Про визнання такими, що втратили чинність, деяких постанов правління Пенсійного фонду України

Відповідно до пункту 12 Положення про Пенсійний фонд України, затвердженого Указом Президента України від 01.03.2001 N 121 ( 121/2001 ) (із змінами), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Визнати такими, що втратили чинність, постанову правління Пенсійного фонду України від 05.09.2003 N 15-4 ( z0849-03 ) "Про затвердження Порядку проведення органами Пенсійного фонду України списання та розстрочення податкового боргу, пов'язаного з виплатою заробітної плати негрошовою формою розрахунків", зареєстровану в Міністерстві юстиції України 25.09.2003 за N 849/817, постанову правління Пенсійного фонду України від 12.03.2001 N 7 ( z0282-01 ) "Про затвердження Порядку проведення органами Пенсійного фонду України списання та розстрочення податкового боргу (недоїмки) зі збору на обов'язкове державне пенсійне страхування", зареєстровану в Міністерстві юстиції України 27.03.2001 за N 282/5473 (із змінами).

2. Юридичному управлінню Пенсійного фонду України (Рябцева Т.Б.) подати цю постанову для державної реєстрації до Міністерства юстиції України.
