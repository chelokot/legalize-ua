Кабінет Міністрів України; Постанова від 30.04.1998 № 590

Про термін виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах у разі будівництва яхт та суден парусних

Стан: Втратив чинність

Ідентифікатор: 590-98-п

Текст документа від 23.04.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 квітня 1998 р. N 590 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 198 ( 198-2015-п ) від 15.04.2015 }

Про термін виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах у разі будівництва яхт та суден парусних

( Із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )

Ураховуючи технологічні особливості будівництва яхт та суден парусних, Кабінет Міністрів України постановляє:

Встановити термін виконання операцій з давальницькою сировиною у разі будівництва яхт та суден парусних (код УКТ ЗЕД 89.03 91) 600 днів з дня оформлення вивізної (ввізної) вантажної митної декларації.

( Постанова із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )
