Кабінет Міністрів України; Постанова від 25.02.2009 № 135

Про внесення зміни до переліку постанов Кабінету Міністрів України, якими затверджено порядки, відповідно до яких у 2009 році використовуються кошти, передбачені у державному бюджеті за деякими програмами

Стан: Чинний

Ідентифікатор: 135-2009-п

Текст документа від 25.02.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 лютого 2009 р. N 135 Київ

Про внесення зміни до переліку постанов Кабінету Міністрів України, якими затверджено порядки, відповідно до яких у 2009 році використовуються кошти, передбачені у державному бюджеті за деякими програмами

Кабінет Міністрів України постановляє:

Внести до переліку постанов Кабінету Міністрів України, якими затверджено порядки, відповідно до яких у 2009 році використовуються кошти, передбачені у державному бюджеті за деякими програмами, затвердженого постановою Кабінету Міністрів України від 14 січня 2009 р. N 32 ( 32-2009-п ) (Офіційний вісник України, 2009 р., N 6, ст. 169), зміну, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 25 лютого 2009 р. N 135

ЗМІНА, що вноситься до переліку постанов Кабінету Міністрів України, якими затверджено порядки, відповідно до яких у 2009 році використовуються кошти, передбачені у державному бюджеті за деякими програмами ( 32-2009-п )

Доповнити перелік ( 32-2009-п ) пунктами 41-45 такого змісту:

41. Постанова Кабінету Міністрів України від 14 лютого 2007 р. N 198 ( 198-2007-п ) "Про затвердження Порядку використання коштів, передбачених у державному бюджеті для інформаційного та організаційного забезпечення участі України у міжнародних форумах, конференціях, виставках" (Офіційний вісник України, 2007 р., N 12, ст. 416; 2008 р., N 18, ст. 484).

42. Постанова Кабінету Міністрів України від 7 березня 2007 р. N 413 ( 413-2007-п ) "Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для трансляції телерадіопрограм, вироблених для державних потреб" (Офіційний вісник України, 2007 р., N 18, ст. 721; 2008 р., N 18, ст. 484).

43. Постанова Кабінету Міністрів України від 21 березня 2007 р. N 534 ( 534-2007-п ) "Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для випуску книжкової продукції за програмою "Українська книга" (Офіційний вісник України, 2007 р., N 22, ст. 894; 2008 р., N 18, ст. 484).

44. Постанова Кабінету Міністрів України від 21 березня 2007 р. N 535 ( 535-2007-п ) "Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки преси" (Офіційний вісник України, 2007 р., N 22, ст. 895; 2008 р., N 18, ст. 484).

45. Постанова Кабінету Міністрів України від 16 травня 2007 р. N 740 ( 740-2007-п ) "Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки державних музичних колективів" (Офіційний вісник України, 2007 р., N 37, ст. 1490; 2008 р., N 18, ст. 484).
