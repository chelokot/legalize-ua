Кабінет Міністрів України; Розпорядження від 05.03.1997 № 128-р

Про віднесення посад працівників апарату Управління санаторно-курортних закладів в Автономній Республіці Крим до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 128-97-р

Текст документа від 05.03.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 березня 1997 р. N 128-р Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників апарату Управління санаторно-курортних закладів в Автономній Республіці Крим до таких категорій посад державних службовців:

третя категорія - посади заступників начальника Управління, керівників структурних підрозділів, їх заступників, завідуючих секторами;

четверта категорія - посади головних, провідних спеціалістів;

п'ята категорія - посади спеціалістів першої категорії.

Прем'єр-міністр України П.ЛАЗАРЕНКО
