Зареєстровано в Міністерстві юстиції України 12 березня 2007 р. за N 215/13482

Про втрату чинності деяких наказів

Відповідно до пункту 2 постанови Кабінету Міністрів України від 12.10.2000 N 1544 ( 1544-2000-п ) "Про портові збори" НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази:

Міністерства транспорту України від 21.12.98 N 529 ( z0849-98 ) "Про порядок застосування знижок до ставки канального збору", зареєстрований в Міністерстві юстиції України 30.12.98 за N 849/3289;

Міністерства транспорту України від 30.08.2002 N 600 ( z0753-02 ) "Про затвердження Положення про порядок застосування знижок до канального збору", зареєстрований в Міністерстві юстиції України 16.09.2002 за N 753/7041;

Міністерства транспорту та зв'язку України від 27.02.2006 N 185 ( z0255-06 ) "Про встановлення понижуючого коефіцієнта до портових зборів для суден, які заходять в порти Дніпро-Бузького регіону", зареєстрований в Міністерстві юстиції України 11.03.2006 за N 255/12129.

2. Державному департаменту морського і річкового транспорту (Кушніренко А.В.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Касапчука В.А.

Міністр М.Рудьковський
