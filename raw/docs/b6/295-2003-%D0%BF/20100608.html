ПОСТАНОВА від 4 березня 2003 р. N 295 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про внесення змін до структури Секретаріату Кабінету Міністрів України

На виконання Указу Президента України від 13 серпня 2002 р. N 700 ( 700/2002 ) "Про додаткові заходи щодо забезпечення реалізації громадянами конституційного права на звернення" Кабінет Міністрів України постановляє:

1. Утворити у складі Департаменту діловодства та моніторингу Секретаріату Кабінету Міністрів України Управління організації роботи із зверненнями громадян в межах граничної чисельності працівників Секретаріату Кабінету Міністрів України.

2. Державному Секретарю Кабінету Міністрів України внести відповідні зміни до структури, штатного розпису та положення про Департамент діловодства та моніторингу Секретаріату Кабінету Міністрів України.

Прем'єр-міністр України В.ЯНУКОВИЧ
