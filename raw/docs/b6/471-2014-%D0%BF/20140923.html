КАБІНЕТ МІНІСТРІВ УКРАЇНИ
ПОСТАНОВА

від 23 вересня 2014 р. № 471
Київ

Питання закупівлі послуг, необхідних для підготовки та проведення позачергових виборів народних депутатів України 26 жовтня 2014 року

Кабінет Міністрів України постановляє :

На часткову зміну пункту 3 Порядку закупівлі товарів, робіт і послуг, необхідних для підготовки та проведення виборів народних депутатів України, затвердженого постановою Кабінету Міністрів України від 23 квітня 2012 р. № 320 (Офіційний вісник України, 2012 р., № 31, ст. 1145, № 64, ст. 2612), установити, що закупівля послуг з підтримки, обслуговування та модифікації Єдиної інформаційно-аналітичної системи “Вибори” здійснюється Центральною виборчою комісією для підготовки та проведення позачергових виборів народних депутатів України 26 жовтня 2014 р. на підставі укладених договорів.

Прем'єр-міністр України
