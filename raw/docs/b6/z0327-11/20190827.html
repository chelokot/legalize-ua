ЗАТВЕРДЖЕНО Наказ Міністерства охорони здоров'я України 21.12.2010 N 1141 ( z0319-11 )

Зареєстровано в Міністерстві юстиції України 14 березня 2011 р. за N 327/19065

ІНСТРУКЦІЯ щодо заповнення форми первинної облікової документації N 503-6/0 "Довідка N ___ про результати досліджень на наявність антитіл до ВІЛ зразка крові дитини, народженої ВІЛ-інфікованою матір'ю"

1. Інструкція визначає порядок заповнення форми первинної облікової документації N 503-6/0 "Довідка N ___ про результати досліджень на наявність антитіл до ВІЛ зразка крові дитини, народженої ВІЛ-інфікованою матір'ю" (далі - Довідка).

2. У лівому верхньому куті Довідки зазначають найменування і місцезнаходження закладу, в якому заповнюється форма, та ідентифікаційний код Єдиного державного реєстру підприємств та організацій України (ЄДРПОУ).

3. Номер Довідки зазначають відповідно до Направлення на проведення дослідження на наявність антитіл до ВІЛ (при взятті на диспансерний облік) (форма N 249-6/0) ( z0334-11 ).

4. У Довідці зазначають ім'я дитини та індивідуальний номер, під яким вона стоїть на диспансерному обліку.

5. У Довідці зазначають установу або відділення центру СНІДу, з якого надійшов зразок на дослідження, дату проведення досліджень та результат тестування.

6. Підкреслюють результат дослідження (позитивні результати в трьох альтернативних тест-системах або негативні результати в __ альтернативних тест-системах).

{ Інструкцію доповнено новим пунктом 6 згідно з Наказом Міністерства охорони здоров'я N 718 ( z1931-12 ) від 17.09.2012 }

7. Вписують кількість тест-систем, на яких отримано негативний результат.

{ Інструкцію доповнено новим пунктом 7 згідно з Наказом Міністерства охорони здоров'я N 718 ( z1931-12 ) від 17.09.2012 }

8. Довідку заповнює лікар-лаборант, який відповідно до покладених на нього функціональних обов'язків здійснює дослідження на серологічні маркери ВІЛ-інфекції.
