Мін'юст України; Наказ від 15.08.2006 № 68/5

Про здійснення експертизи проектів нормативно-правових актів, на які поширюється вимога державної реєстрації, на відповідність Конвенції про захист прав людини і основоположних свобод

Стан: Втратив чинність

Ідентифікатор: v0068323-06

Текст документа від 22.01.2007:

МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

15.08.2006 N 68/5

Про здійснення експертизи проектів нормативно-правових актів, на які поширюється вимога державної реєстрації, на відповідність Конвенції про захист прав людини і основоположних свобод

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 19/5 ( v0019323-07 ) від 22.01.2007 }

На виконання Закону України "Про виконання рішень та застосування практики Європейського суду з прав людини" ( 3477-15 ) та Положення про державну реєстрацію нормативно-правових актів міністерств, інших органів виконавчої влади, органів господарського управління та контролю, що зачіпають права, свободи й законні інтереси громадян або мають міжвідомчий характер, затвердженого постановою Кабінету Міністрів України від 28 грудня 1992 р. N 731 ( 731-92-п ) (далі - Положення), НАКАЗУЮ:

1. Установити, що експертиза проектів нормативно-правових актів, на які поширюється вимога державної реєстрації, на відповідність Конвенції про захист прав людини і основоположних свобод ( 995_004 ) здійснюється відповідно до Методичних рекомендацій щодо здійснення експертизи нормативно-правових актів (їх проектів) на відповідність Конвенції про захист прав людини і основоположних свобод ( n0003323-06 ). { Пункт 1 із змінами, внесеними згідно з Наказом Міністерства юстиції N 19/5 ( v0019323-07 ) від 22.01.2007 }

2. Висновки, передбачені підпунктом "д" пункту 9 Положення ( 731-92-п ), щодо проектів нормативно-правових актів міністерств, інших центральних органів виконавчої влади, органів господарського управління та контролю готує Секретаріат Урядового уповноваженого у справах Європейського суду з прав людини Міністерства юстиції протягом 10 днів з моменту отримання проекту нормативно-правового акта, направленого на експертизу. { Пункт 2 в редакції Наказу Міністерства юстиції N 19/5 ( v0019323-07 ) від 22.01.2007 }

3. Висновки, передбачені підпунктом "д" пункту 9 Положення ( 731-92-п ), щодо інших нормативно-правових актів надають головні управління юстиції Міністерства юстиції в Автономній Республіці Крим, областях, містах Києві та Севастополі, районні управління юстиції протягом 10 днів з моменту отримання нормативно-правового акта, направленого на експертизу. { Пункт 3 із змінами, внесеними згідно з Наказом Міністерства юстиції N 19/5 ( v0019323-07 ) від 22.01.2007 }

4. Висновки, які надаються відповідно до пункту 2 цього наказу, підписуються заступником Міністра відповідно до розподілу функціональних повноважень. { Пункт 4 в редакції Наказу Міністерства юстиції N 19/5 ( v0019323-07 ) від 22.01.2007 }

5. Висновки, які надаються відповідно до пункту 3 цього наказу, підписуються посадовими особами, уповноваженими на це керівниками головних управлінь юстиції Міністерства юстиції в Автономній Республіці Крим, областях, містах Києві та Севастополі, районних управлінь юстиції. { Пункт 5 із змінами, внесеними згідно з Наказом Міністерства юстиції N 19/5 ( v0019323-07 ) від 22.01.2007 }

6. Управлінню систематизації законодавства та правової інформації (Пушенку О.Г.) довести цей наказ до відома центральних і місцевих органів виконавчої влади, Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських державних адміністрацій, управлінь юстиції.

7. Контроль за виконанням цього наказу покласти на першого заступника Міністра Крупка П.М.

Міністр Р.Зварич
