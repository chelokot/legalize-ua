КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 січня 2006 р. N 6-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку переробки на митній території України товарів, необхідних для виконання робіт з ремонту і відновлення газотурбінного агрегату та його складових частин

З урахуванням технологічних особливостей установити строк переробки на митній території України товарів, необхідних для виконання робіт з ремонту і відновлення газотурбінного агрегату та його складових частин за кодами згідно з УКТЗЕД 8411829100 і 8411999000 ( 2371г-14 ), 360 днів від дати завершення митного оформлення товарів, що ввозяться для переробки.

Прем'єр-міністр України Ю.ЄХАНУРОВ
