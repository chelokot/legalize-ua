Про затвердження бланків документів суворого обліку "Експортний сертифікат якості" та Інструкції про порядок виготовлення, замовлення, застосування і зберігання бланків документів суворого обліку форми N СЯ-1 "Експортний сертифікат якості"

( Із змінами, внесеними згідно з Наказами Держпромполітики N 50/51 ( z0170-01 ) від 06.02.2001 Мінпромполітики

N 53/76 ( z0236-04 ) від 04.02.2004 )

( Слова "сертифікат якості" замінено на слова "експортний сертифікат якості" у відповідних відмінках згідно з Наказом Держпромполітики N 50/51 ( z0170-01 ) від 06.02.2001 )

Відповідно до статті 9 Закону України "Про металобрухт" ( 619-14 ), з метою регулювання експортних операцій із зливками кольорових металів та їх сплавів НАКАЗУЄМО:

1. Затвердити:

форму бланка N СЯ-1 "Експортний сертифікат якості" як форму бланка документів суворого обліку (додається);

Інструкцію про порядок виготовлення, замовлення, застосування і зберігання бланків документів суворого обліку форми N СЯ-1 "Експортний сертифікат якості" (додається).

2. Увести в дію форму бланка N СЯ-1 "Експортний сертифікат якості" та Інструкцію про порядок виготовлення, замовлення, застосування і зберігання бланків документів суворого обліку форми N СЯ-1 "Експортний сертифікат якості" з 15 липня 2000 року.

3. Визнати таким, що втратив чинність, наказ Міністерства промислової політики та Державної митної служби України від 02.12.99 N 411/785 ( z0836-99 ) "Про тимчасовий порядок оформлення операцій з експорту зливків кольорових металів та їх сплавів", зареєстрований в Міністерстві юстиції України 03.12.99 за N 836/4129, з 15 липня 2000 року.

4. Контроль за виконанням цього наказу покласти на першого заступника Голови Державного комітету промислової політики України В.Г.Падалка.

Затверджено Наказ Державного комітету промислової політики України та Державної митної служби України 16.03.2000 N 31/138

Зареєстровано в Міністерстві юстиції України 23 червня 2000 р. за N 367/4588

Інструкція про порядок виготовлення, замовлення, застосування і зберігання бланків документів суворого обліку форми N СЯ-1 "Експортний сертифікат якості"

( Слова "сертифікат якості" замінено на слова "експортний сертифікат якості" у відповідних відмінках згідно з Наказом Держпромполітики N 50/51 ( z0170-01 ) від 06.02.2001 )

( Слова "підприємствами, установами, організаціями та їх структурними підрозділами (надалі - підприємства)", "підприємства-виготівника" замінити на слова "спеціалізовані металургійні переробні підприємства" у відповідних відмінках згідно з Наказом Держпромполітики N 50/51 ( z0170-01 ) від 06.02.2001 )

1. Загальні положення

1.1. Ця Інструкція, розроблена відповідно до статті 9 Закону України "Про металобрухт" від 5 травня 1999 року N 619-XIV ( 619-14 ), із змінами й доповненнями, унесеними Законами України від 16 листопада 2000 року N 2114-III ( 2114-14 ), від 25 грудня 2002 року N 359-IV ( 359-15 ), визначає порядок виготовлення, замовлення, застосування, зберігання та заповнення бланків документів суворого обліку, які застосовуються в процесі оформлення експортних операцій продуктів (напівфабрикатів) металургійної переробки брухту кольорових металів та їх сплавів у формі зливків, чушок та пластин. ( Пункт 1.1 в редакції Наказу Мінпромполітики N 53/76 ( z0236-04 ) від 04.02.2004 )

1.2. Форма бланка документів суворого обліку N СЯ-1 "Експортний сертифікат якості" є обов'язковою для застосування всіма спеціалізованими металургійними переробними підприємствами, що пройшли атестацію в порядку, установленому центральним органом виконавчої влади з питань промислової політики, які здійснюють експорт продуктів (напівфабрикатів) металургійної переробки брухту кольорових металів та їх сплавів у формі зливків, чушок та пластин. ( Пункт 1.2 із змінами, внесеними згідно з Наказом Мінпромполітики N 53/76 ( z0236-04 ) від 04.02.2004 )

1.3. Бланки документів N СЯ-1 "Експортний сертифікат якості" згідно з номенклатурою, затвердженою постановою Кабінету Міністрів України від 19.04.93 N 283 ( 283-93-п ) "Про встановлення порядку виготовлення бланків цінних паперів і документів суворого обліку", є бланками документів суворого обліку, що передбачає:

облік їх одержання, зберігання та використання як бланків суворого обліку;

їх виготовлення з друкарською нумерацією відповідно до Правил виготовлення бланків цінних паперів і документів суворого обліку, затверджених спільним наказом Міністерства фінансів України від 25.11.93 N 98 ( z0008-94 ), Служби безпеки України від 15.11.93 N 118, Міністерства внутрішніх справ України від 24.11.93 N 740 та зареєстрованих Міністерством юстиції України 14.01.94 за N 8/217;

видачу бланків тій посадовій особі підприємства (організації), на яку покладено обов'язки з реєстрації виданих та повернутих форм первинного обліку за прибутково-видатковою накладною на бланки суворого обліку (типова форма N СЗ-1);

списання використаних бланків за Актом на списання використаних бланків суворого обліку (типова форма N СЗ-3).

1.4. Термін зберігання документів визначається наказом Головного архівного управління при Кабінеті Міністрів України від 20.07.98 N 41 ( z0576-98 ) "Про затвердження переліку типових документів", зареєстрованим Міністерством юстиції України 17.09.98 за N 576/316.

1.5. Нумерація бланків документів суворого обліку складається з серії і номера:

серія складається з чотирьох знаків: двох цифр (номер ліцензії, яку надано Міністерством фінансів України спеціалізованому металургійному переробному підприємству бланків документів суворого обліку, та двох букв, які визначають серію;

номер складається з шістьох цифр, що визначають порядковий номер бланка в даній серії.

( Пункт 1.5 із змінами, внесеними згідно з Наказом Мінпромполітики N 53/76 ( z0236-04 ) від 04.02.2004 )

2. Заповнення бланків

2.1. Бланки документа заповнюються в трьох примірниках, що позначені однією серією та номером:

перший примірник надається митниці;

другий примірник надається одержувачу продуктів (напівфабрикатів) металургійної переробки брухту кольорових металів та їх сплавів у формі зливків, чушок та пластин;

третій примірник залишається у спеціалізованому металургійному переробному підприємстві.

( Пункт 2.1 в редакції Наказу Мінпромполітики N 53/76 ( z0236-04 ) від 04.02.2004 )

2.2. Пункти 4 та 5 "Експортного сертифіката якості" заповнює спеціалізоване металургійне переробне підприємство, яке формує контейнер та опломбовує його у разі наявності відомих даних щодо транспортного засобу (вид, номер), яким буде здійснюватися перевезення товару. ( Пункт 2.2 із змінами, внесеними згідно з Наказом Держпромполітики N 50/51 ( z0170-01 ) від 06.02.2001 )

2.3. Пункти 6, 7, 8 та 9 "Експортного сертифіката якості" заповнює вимірювальна лабораторія". ( Пункт 2.3 в редакції Наказу Держпромполітики N 50/51 ( z0170-01 ) від 06.02.2001 )

( Пункт 2.4 виключено на підставі Наказу Держпромполітики N 50/51 ( z0170-01 ) від 06.02.2001 )

2.4. Другий примірник бланка N СЯ-1 "Експортний сертифікат якості", що надається одержувачу продуктів (напівфабрикатів) металургійної переробки брухту кольорових металів та їх сплавів у формі зливків, чушок та пластин, може заповнюватися також текстом англійською мовою, автентичним українському тексту на вимогу одержувача. ( Інструкцію доповнено пунктом 2.4 згідно з Наказом Мінпромполітики N 53/76 ( z0236-04 ) від 04.02.2004 )
