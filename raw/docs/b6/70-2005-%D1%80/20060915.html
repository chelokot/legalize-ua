Ідентифікатор: 70-2005-р

Текст документа від 15.09.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 березня 2005 р. N 70-р Київ

Про затвердження складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 549-р ( 549-2005-р ) від 21.12.2005 N 248-р ( 248-2006-р ) від 27.04.2006 N 488-р ( 488-2006-р ) від 15.09.2006 }

На часткову зміну пункту 1 постанови Кабінету Міністрів України від 10 грудня 2003 р. N 1901 ( 1901-2003-п ) "Про затвердження складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів загальнообов'язкового державного соціального страхування" (Офіційний вісник України, 2003 р., N 51, ст. 2677; 2004 р., N 46, ст. 3070) затвердити склад осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття, згідно з додатком.
