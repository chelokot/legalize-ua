Кабінет Міністрів України; Постанова від 17.03.2010 № 271

Питання використання у 2010 році коштів Стабілізаційного фонду для фінансування робіт, пов'язаних із завершенням будівництва центру із застосування ПЕТ-технології для раннього виявлення онкологічних захворювань

Стан: Чинний

Ідентифікатор: 271-2010-п

Текст документа від 17.03.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 березня 2010 р. N 271 Київ

Питання використання у 2010 році коштів Стабілізаційного фонду для фінансування робіт, пов'язаних із завершенням будівництва центру із застосування ПЕТ-технології для раннього виявлення онкологічних захворювань

Кабінет Міністрів України постановляє:

Установити, що у 2010 році фінансування робіт, пов'язаних із завершенням будівництва центру із застосування ПЕТ-технології для раннього виявлення онкологічних захворювань, здійснюється відповідно до Порядку використання у 2009 році коштів Стабілізаційного фонду, передбачених у державному бюджеті для виконання функцій столиці відповідно до Закону України "Про столицю України - місто-герой Київ", включаючи будівництво метрополітену, затвердженого постановою Кабінету Міністрів України від 11 лютого 2009 р. N 271 ( 271-2009-п ) (Офіційний вісник України, 2009 р., N 23, ст. 751, N 72, ст. 2481, N 94, ст. 3220).

Прем'єр-міністр України М.АЗАРОВ
