Кабінет Міністрів УРСР; Розпорядження від 24.06.1991 № 74-р

Про внесення змін до постанови Ради Міністрів УРСР від 1 жовтня 1990 року N 296

Стан: Втратив чинність

Ідентифікатор: 74-91-р

Текст документа від 17.03.2017:

КАБІНЕТ МІНІСТРІВ УКРАЇНСЬКОЇ РСР

РОЗПОРЯДЖЕННЯ від 24 червня 1991 р. N 74-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1066 ( 1066-2016-п ) від 23.11.2016 }

Погодитись з пропозицією Міністерства сільського господарства УРСР, підтриманою Міністерством економіки УРСР та Міністерством фінансів УРСР, про закупівлю починаючи з урожаю 1991 року винограду від населення для промислової переробки за цінами згідно з домовленістю без обмеження їх рівня.

У зв'язку з цим пункт 5 примітки до додатка N 7 до постанови Ради Міністрів УРСР від 1 жовтня 1990 р. N 296 ( 296-90-п ) викласти в такій редакції: "5. Закупівля винограду від населення для промислової переробки починаючи з урожаю 1991 року проводиться за цінами згідно з домовленістю".

Перший віце-прем'єр-міністр УРСР К.МАСИК
