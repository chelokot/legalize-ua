Верховна Рада України; Закон від 11.05.2000 № 1709-III

Про внесення змін до деяких законів України у зв'язку з прийняттям Закону України "Про джерела фінансування органів державної влади"

Стан: Чинний

Ідентифікатор: 1709-14

Текст документа від 16.12.2023:

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України у зв'язку з прийняттям Закону України "Про джерела фінансування органів державної влади"

( Відомості Верховної Ради України (ВВР), 2000, N 32, ст.257 )

{ Із змінами, внесеними згідно із Законами N 2398-VI ( 2398-17 ) від 01.07.2010, ВВР, 2010, N 38, ст.509 N 2849-IX ( 2849-20 ) від 13.12.2022 N 3310-IX ( 3310-20 ) від 09.08.2023 }

У зв'язку з прийняттям Закону України "Про джерела фінансування органів державної влади" ( 783-14 ) Верховна Рада України постановляє:

I. Внести зміни до таких законів України:

1. Частину другу статті 19 Закону України "Про нотаріат" ( 3425-12 ) (Відомості Верховної Ради України, 1993 р., N 39, ст. 383) доповнити реченням такого змісту: "Кошти, одержані від надання таких додаткових послуг, спрямовуються до Державного бюджету України".

{ Пункт 2 розділу I втратив чинність на підставі Закону N 2849-IX ( 2849-20 ) від 13.12.2022 }

{ Пункт 3 розділу I втратив чинність на підставі Закону N 2398-VI ( 2398-17 ) від 01.07.2010 }

{ Пункт 4 розділу I втратив чинність на підставі Закону N 3310-IX ( 3310-20 ) від 09.08.2023 }

{ Пункт 5 розділу I втратив чинність на підставі Закону N 2849-IX ( 2849-20 ) від 13.12.2022 }

II. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА
