Про затвердження Порядку використання коштів, передбачених у державному бюджеті для забезпечення проведення засідань спільних комісій з науково-технічного співробітництва

Стан: Чинний

Ідентифікатор: 732-2008-п

Текст документа від 20.06.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 серпня 2008 р. N 732 Київ

Про затвердження Порядку використання коштів, передбачених у державному бюджеті для забезпечення проведення засідань спільних комісій з науково-технічного співробітництва

{ Із змінами, внесеними згідно з Постановою КМ N 596 ( 596-2009-п ) від 17.06.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання коштів, передбачених у державному бюджеті ( 107-17 ) для забезпечення проведення засідань спільних комісій з науково-технічного співробітництва, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 20 серпня 2008 р. N 732

ПОРЯДОК використання коштів, передбачених у державному бюджеті ( 107-17 ) для забезпечення проведення засідань спільних комісій з науково-технічного співробітництва

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті ( 107-17 ) МОН за програмою "Виконання зобов'язань України у сфері міжнародного науково-технічного співробітництва" (далі - бюджетні кошти).

Розпорядником бюджетних коштів нижчого рівня є Український інститут науково-технічної та економічної інформації. { Абзац другий пункту 1 в редакції Постанови КМ N 596 ( 596-2009-п ) від 17.06.2009 }

2. Бюджетні кошти спрямовуються на проведення засідань спільних комісій з науково-технічного співробітництва та організацію міжнародних науково-технічних форумів, семінарів і презентацій, а саме на фінансування витрат, пов'язаних з:

відрядженням у межах України та за кордон членів офіційних українських делегацій (придбання квитків, страхових полісів, оплата вартості проживання, сплата зборів та оформлення візових документів, відшкодування добових витрат);

підготовкою та проведенням на території України засідань у рамках двостороннього співробітництва з іноземними державами та міжнародними організаціями (буфетне обслуговування під час проведення заходів з урахуванням двосторонньої домовленості про таке обслуговування, витрати на оренду приміщень та обладнання, на проживання і придбання інформаційно-довідкових, канцелярських та інших витратних матеріалів);

транспортним обслуговуванням на території України членів офіційних українських та іноземних делегацій;

обслуговуванням на території України членів офіційних українських та іноземних делегацій в залі офіційних делегацій, аеропортах і залізничних вокзалах;

проведенням протокольних заходів від імені голови офіційної української делегації з урахуванням двосторонньої домовленості про проведення таких заходів;

наданням послуг із синхронного та послідовного перекладу, що здійснюється під час проведення заходів за участю членів офіційних українських та іноземних делегацій, орендою обладнання, необхідного для надання таких послуг;

придбанням сувенірної та квіткової продукції, протокольної атрибутики (прапорів, настільних прапорців, бланків запрошень та конвертів, вітальних листівок), виготовленням візитних карток для членів офіційних українських делегацій;

проведенням культурної частини програми перебування членів офіційних іноземних делегацій.

3. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється в установленому законодавством порядку.

4. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством. { Пункт 4 в редакції Постанови КМ N 596 ( 596-2009-п ) від 17.06.2009 }

5. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
