Президент України; Указ від 13.10.2008 № 922/2008

Питання мережі та кількісного складу суддів адміністративних судів України

Стан: Втратив чинність

Ідентифікатор: 922/2008

Текст документа від 17.10.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 940/2008 ( 940/2008 ) від 16.10.2008 }

Питання мережі та кількісного складу суддів адміністративних судів України

{ Додатково див. Ухвалу Київського апеляційного адміністративного суду N 22-а-35980/08 ( v5980705-08 ) від 15.01.2009 }

Відповідно до пункту 23 частини першої статті 106 Конституції України ( 254к/96-ВР ) та частин першої - четвертої статті 20, частини другої статті 21 Закону України "Про судоустрій України" ( 3018-14 ) постановляю:

1. Ліквідувати окружний адміністративний суд міста Києва.

2. Утворити з 14 жовтня 2008 року:

Центральний окружний адміністративний суд міста Києва у кількості 37 суддів;

Лівобережний окружний адміністративний суд міста Києва у кількості 22 суддів.

3. Внести до Указу Президента України від 16 листопада 2004 року N 1417 ( 1417/2004 ) "Про утворення місцевих та апеляційних адміністративних судів, затвердження їх мережі та кількісного складу суддів" (зі змінами, внесеними Указом від 16 травня 2007 року N 417) ( 417/2007 ) такі зміни:

1) абзац двадцять сьомий статті 1 визнати таким, що втратив чинність;

2) у додатку N 1 до зазначеного Указу ( 1417/2004 ) позицію "Окружний адміністративний суд міста Києва" замінити двома позиціями такого змісту:

"Центральний окружний Голосіївський, Оболонський, адміністративний суд міста Києва Печерський, Подільський, Святошинський, Солом'янський, Шевченківський райони м. Києва

Лівобережний окружний Дарницький, Деснянський, адміністративний суд міста Києва Дніпровський райони м. Києва";

3) у розділі "Місцеві адміністративні суди" додатку N 3 до зазначеного Указу ( 1417/2004 ) позицію "Окружний адміністративний суд міста Києва" замінити двома позиціями такого змісту:

"Центральний окружний 37 м. Київ адміністративний суд міста Києва

Лівобережний окружний 22 м. Київ". адміністративний суд міста Києва

4. Цей Указ набирає чинності з дня опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 13 жовтня 2008 року N 922/2008
