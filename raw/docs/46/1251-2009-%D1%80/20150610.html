КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 жовтня 2009 р. N 1251-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 333 ( 333-2015-п ) від 27.05.2015 }

Про розміщення Національної експертної комісії з питань захисту суспільної моралі

1. Погодитися з пропозицією Національної експертної комісії з питань захисту суспільної моралі (далі - Комісія) щодо розміщення структурних підрозділів Комісії у приміщеннях робочою площею 363,9 кв. метра на п'ятнадцятому і шістнадцятому поверхах нежитлового будинку по вул. Артема, 73, у м. Києві.

2. Господарсько-фінансовому департаменту Секретаріату Кабінету Міністрів України вжити у місячний строк заходів щодо розміщення Комісії у зазначених приміщеннях.

3. Фондові державного майна та Комісії забезпечити укладення договору оренди приміщень на умовах відшкодування балансоутримувачеві нежитлового будинку по вул. Артема, 73, у м. Києві фактичних витрат, пов'язаних з їх утриманням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
