КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 грудня 2006 р. N 1753 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 117 ( 117-2014-п ) від 23.04.2014 }

Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404

Кабінет Міністрів України постановляє:

Внести до підпункту 1 пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752, N 44, ст. 2946) зміну, доповнивши його абзацом такого змісту:

"медичного обладнання та санітарних автотранспортних засобів для забезпечення закладів охорони здоров'я згідно з державними програмами і заходами програмного характеру;".

Прем'єр-міністр України В.ЯНУКОВИЧ
