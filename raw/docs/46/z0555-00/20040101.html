Про затвердження форм державної статистичної звітності з питань статистики науково-технічного прогресу та Інструкцій про порядок їх складання

Реєстрація: Мін'юст України від 29.08.2000 № 555/4776

Стан: Втратив чинність

Ідентифікатор: z0555-00

Текст документа від 01.01.2004:

ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

N 261 від 04.08.2000 Зареєстровано в Міністерстві м. Київ юстиції України 29 серпня 2000 р. за N 555/4776

Про затвердження форм державної статистичної звітності

з питань статистики науково-технічного прогресу та Інструкцій про порядок їх складання

( Із змінами, внесеними згідно з Наказами Державного комітету статистики N 352 ( z0827-02 ) від 30.09.2002 N 290 ( z0850-03 ) від 09.09.2003 )

У відповідності до статті 12 Закону України "Про державну статистику" ( 2614-12 ) та з метою подальшого вдосконалення державної статистичної звітності і показників статистики науково-технічного прогресу НАКАЗУЮ:

1. Затвердити такі документи (додаються) і ввести їх у дію:

1.1. Форми державної статистичної звітності:

починаючи зі звіту за 2000 рік:

( Наказ втратив чинність в частині затвердження форми державної статистичної звітності N 3-наука на підставі Наказу Держкомстату N 352 ( z0827-02 ) від 30.09.2002 ) N 3-наука "Показники наукової та науково-технічної діяльності" ( z0557-00 );

N 1-інновація "Обстеження технологічних інновацій промислового підприємства";

починаючи зі звіту за І квартал 2001 року:

( Наказ втратив чинність в частині затвердження форми державної статистичної звітності N 1-наука на підставі Наказу Держкомстату N 352 ( z0827-02 ) від 30.09.2002 ) N 1-наука "Звіт про виконання наукових та науково-технічних робіт" ( z0556-00 ).

1.2. Інструкції про порядок складання статистичної звітності за формами:

( Наказ втратив чинність у частині затвердження інструкції щодо заповнення форми державних статистичних спостережень N 3-наука-річна на підставі Наказу Держкомстату N 290 ( z0850-03 ) від 09.09.2003 ) N 3-наука "Показники наукової та науково-технічної діяльності" ( z0557-00 );

( Наказ втратив чинність у частині затвердження форми державних статистичних спостережень N 1-інновація та інструкції про порядок її складання на підставі Наказу Держкомстату N 290 ( z0850-03 ) від 09.09.2003 ) N 1-інновація "Обстеження технологічних інновацій промислового підприємства";

( Наказ втратив чинність у частині затвердження інструкції щодо заповнення форми державних статистичних спостережень N 1-наука-квартальна на підставі Наказу Держкомстату N 290 ( z0850-03 ) від 09.09.2003 ) N 1-наука "Звіт про виконання наукових та науково-технічних робіт" ( z0556-00 ).

2. Управлінню статистики інвестицій та будівництва Головного управління статистики виробництва (Луценко Н.Г.):

2.1. Визначити необхідний тираж, підготувати і передати фінансово-економічному управлінню в установлений термін оригінали бланків форм державної статистичної звітності та Інструкцій про порядок їх складання, затверджені цим наказом, для їх тиражування.

2.2. Підготувати спільно з Державним підприємством "Головний міжрегіональний інформаційний центр" (далі - ДП ГМІЦ) Держкомстату України (Сидоренко М.М.) зміни і доповнення до постановок задач автоматизованої обробки статистичної інформації в терміни відповідно до Плану розробки та експлуатації комплексів електронної обробки статистичної інформації (КЕОІ) на 2000 рік.

2.3. Здійснювати методологічне керівництво збиранням та розробкою звітності за вказаними формами.

3. Фінансово-економічному управлінню (Сорокіна Т.В.) забезпечити фінансування виготовлення бланків форм державної статистичної звітності та Інструкцій про порядок їх складання для Головного управління статистики в Автономній Республіці Крим, обласних, Київського та Севастопольського міських управлінь статистики.

4. Управлінню справами (Москот В.Ф.) забезпечити контроль за своєчасним тиражуванням і розсиланням зазначених бланків форм державної статистичної звітності та Інструкцій до Головного управління статистики в Автономній Республіці Крим, обласних, Київського та Севастопольського міських управлінь статистики.

5. ДП ГМІЦ Держкомстату України (Сидоренко М.М.) забезпечити:

5.1. Виконання робіт з розробки програмного забезпечення КЕОІ звітності, затвердженої цим наказом, у терміни відповідно до Плану розробки та експлуатації комплексів електронної обробки статистичної інформації на 2000 рік.

5.2. Збір і розробку державної статистичної звітності за формами N 1-наука, 3-наука, 1-інновація.

6. Начальнику Головного управління статистики в Автономній Республіці Крим, начальникам обласних, Київського та Севастопольського міських управлінь статистики забезпечити в установленому порядку збір, розробку і подання ДП ГМІЦ Держкомстату України звітів у встановлені терміни.

7. Уважати такими, що втратили чинність:

7.1. Наказ Мінстату України від 09.07.96 N 207 ( z0391-96 ), зареєстрований Міністерством юстиції України 26.07.96 за N 391/1416, "Про затвердження форм державної статистичної звітності по статистиці науки, інформатики та інновацій, а також інструкцій про порядок їх заповнення" в частині затвердження форми державної статистичної звітності N 5-нт (ліцензії) - річна та інструкції щодо її заповнення.

7.2. Наказ Мінстату України від 27.08.97 N 10 ( z0441-97 ), зареєстрований Міністерством юстиції України 24.09.97 за N 441/2245, "Про затвердження форм державної статистичної звітності по статистиці науки, інформатики та інновацій і інструкцій про порядок їх заповнення" в частині затвердження форм державної статистичної звітності N 3-наука - річна, N 1-інновація - річна та інструкцій щодо їх заповнення.

7.3. Наказ Мінстату України від 14.07.98 N 252 ( z0664-98 ), зареєстрований Міністерством юстиції 16.10.98 за N 664/3104, "Про затвердження форм державної статистичної звітності з статистики науки та інновацій, а також інструкцій щодо їх заповнення" в частині затвердження форми державної статистичної звітності N 1-наука - квартальна та інструкції щодо її заповнення.

8. Контроль за виконанням наказу залишаю за собою.

В.о. Голови Комітету В.А.Головко

( Форма державних статистичних спостережень N 1-інновація та інструкція про порядок її складання втратила чинність на підставі Наказу Держкомстату N 290 ( z0850-03 ) від 09.09.2003 )
