Зареєстровано в Міністерстві юстиції України 12 вересня 2005 р. за N 1032/11312

Про визнання таким, що втратив чинність, наказу Міністерства економіки України від 04.07.95 N 103

Відповідно до Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" НАКАЗУЮ:

Визнати таким, що втратив чинність, наказ Міністерства економіки України від 04.07.95 N 103 ( z0201-95 ) "Про встановлення надбавки до оптової ціни на природний газ для створення позабюджетного фонду сприяння виробництву та впровадженню приладів обліку споживання газу в побуті", зареєстрований у Міністерстві юстиції України 05.07.95 за N 201/737.
