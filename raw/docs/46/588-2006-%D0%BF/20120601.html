Кабінет Міністрів України; Постанова від 27.04.2006 № 588

Про внесення зміни до переліку місць митного контролю природного газу, що переміщується через митний кордон України трубопровідним транспортом

Стан: Втратив чинність

Ідентифікатор: 588-2006-п

Текст документа від 01.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 квітня 2006 р. N 588 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 450 ( 450-2012-п ) від 21.05.2012 }

Про внесення зміни до переліку місць митного контролю природного газу, що переміщується через митний кордон України трубопровідним транспортом

Кабінет Міністрів України постановляє:

Внести зміну до переліку місць митного контролю природного газу, що переміщується через митний кордон України трубопровідним транспортом, затвердженого постановою Кабінету Міністрів України від 17 грудня 2003 р. N 1958 ( 1958-2003-п ) (Офіційний вісник України, 2003 р., N 51, ст. 2699; 2005 р., N 37, ст. 2309), доповнивши його позицією такого змісту:

"Пункт вимірювання витрати с. Лиманське Роздільнянського газу "Лиманське" району Одеської області".

Прем'єр-міністр України Ю.ЄХАНУРОВ
