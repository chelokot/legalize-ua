Про сплату державного мита за вексельні бланки

Стан: Втратив чинність

Ідентифікатор: 504/93

Текст документа від 23.06.2019:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 418/2019 ( 418/2019 ) від 20.06.2019 }

Про сплату державного мита за вексельні бланки

( Із змінами, внесеними згідно з Указами Президента N 196/94 ( 196/94 ) від 29.04.94 N 798/94 ( 798/94 ) від 22.12.94 N 658/95 ( 658/95 ) від 26.07.95 N 533/96 ( 533/96 ) від 11.07.96 N 162/2001 ( 162/2001 ) від 07.03.2001 )

З метою створення умов для приведення грошової маси у відповідність з потребами товарного і грошового обігу, оперативного здійснення розрахунків та більш широкого використання векселів у господарському обороті України постановляю:

( Стаття 1 втратила чинність на підставі Указу Президента N 162/2001 ( 162/2001 ) від 07.03.2001 )

2. Вексельні бланки купуються підприємствами в комерційних банках України. Під час придбання вексельних бланків покупці в обов'язковому порядку, крім вартості бланку, сплачують державне мито за кожен бланк у розмірі 10 відсотків від неоподатковуваного мінімуму доходів громадян, якщо інше не передбачено законодавством України. Державне мито зараховується в доход Державного бюджету України. ( Стаття 2 із змінами, внесеними згідно з Указами Президента N 196/94 ( 196/94 ) від 29.04.94, N 798/94 ( 798/94 ) від 22.12.94, N 533/96 ( 533/96 ) від 11.07.96 )
