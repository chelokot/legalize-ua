Про реалізацію жита з державного продовольчого резерву

Стан: Чинний

Ідентифікатор: 350-2007-р

Текст документа від 02.08.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 травня 2007 р. N 350-р Київ

Про реалізацію жита з державного продовольчого резерву

{ Із змінами, внесеними згідно з Постановою КМ N 973 ( 973-2007-п ) від 27.07.2007 }

1. Для забезпечення внутрішнього ринку житнім борошном до кінця поточного маркетингового періоду, стабілізації цін на масові сорти хліба та відповідно до підпункту "г" пункту 6.2 статті 6 Закону України "Про державну підтримку сільського господарства України" ( 1877-15 ) погодитися з пропозицією Мінагрополітики щодо реалізації Аграрним фондом на умовах попередньої оплати до 15 серпня 2007 р. підприємствам ДАК "Хліб України" жита з державного продовольчого резерву за ціною закупівлі з урахуванням вартості зберігання, але не вище максимальних закупівельних цін, з подальшою його переробкою згідно з планом-графіком, затвердженим Мінагрополітики, та реалізацією борошна, виробленого із зазначеного жита, підприємствам хлібопекарської промисловості, визначеним Радою міністрів Автономної Республіки Крим, обласними, Київською та Севастопольською міськими держадміністраціями.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 973 ( 973-2007-п ) від 27.07.2007 }

2. Контроль за виконанням цього розпорядження покласти на Міністра аграрної політики Мельника Ю.Ф.

Прем'єр-міністр України В.ЯНУКОВИЧ
