КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 вересня 1999 р. N 1782 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про внесення змін і доповнень до деяких постанов Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановами КМ N 51 ( 51-2000-п ) від 17.01.2000 N 445 ( 445-2002-п ) від 30.03.2002 N 862 ( 862-2012-п ) від 19.09.2012 }

На виконання Указу Президента України від 12 червня 1999 р. N 640 ( 640/99 ) "Про заходи щодо підвищення ефективності діяльності Державної компанії з експорту та імпорту продукції і послуг військового та спеціального призначення" Кабінет Міністрів України постановляє:

1. Внести зміни і доповнення до деяких постанов Кабінету Міністрів України, що додаються.

{ Пункт 2 втратив чинність на підставі Постанови КМ N 862 ( 862-2012-п ) від 19.09.2012 }

3. З метою освоєння Державною компанією з експорту та імпорту продукції і послуг військового та спеціального призначення "Укрспецекспорт" міжнародних ринків озброєння, військової та спеціальної техніки дозволити їй самостійне визначати та здійснювати витрати на проведення маркетингових досліджень, пов'язаних з реалізацією майна Збройних Сил та інших військових формувань.

4. Установити, що Державна кампанія з експорту та імпорту продукції і послуг військового та спеціального призначення "Укрспецекспорт" реалізує військове майно, яке застаріло або не користується попитом, за ціною нижчою, ніж залишкова вартість, якщо воно не реалізовано протягом року з дати затвердження Кабінетом Міністрів України переліків військового майна, що пропонується до реалізації, за погодженням відповідно з Міністерством оборони, Міністерствам внутрішніх справ, Головним управлінням Командувача Національної гвардії та іншими центральними органами виконавчої влади, що здійснюють управління військовими формуваннями які запропонували це майно для реалізації.
