Про порядок внесення обов'язкових платежів у разі імпорту окремих видів товарів

Стан: Втратив чинність

Текст документа від 13.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 січня 1997 р. N 52 Київ

Про порядок внесення обов'язкових платежів у разі імпорту окремих видів товарів

( Із змінами, внесеними згідно з Постановами КМ N 1078 ( 1078-97-п ) від 29.09.97 N 1462 ( 1462-97-п ) від 24.12.97 N 460 ( 460-98-п ) від 02.04.98 N 1204 ( 1204-98-п ) від 03.08.98 N 1648 ( 1648-2001-п ) від 13.12.2001 )

З метою недопущення ухилення від оподаткування окремих видів товарів, які ввозяться в Україну, Кабінет Міністрів України постановляє:

1. Установити, що умовою пропуску через митний кордон України окремих видів товарів, зазначених у додатку до цієї постанови, які ввозяться в Україну суб'єктами підприємницької діяльності, є оформлення попередньої вантажної митної декларації на підакцизні товари у митниці, в зоні діяльності якої зареєстрований суб'єкт підприємницької діяльності - імпортер таких товарів, зі сплатою під час її оформлення всіх належних платежів (ввізного мита, податку на додану вартість, акцизного та митних зборів).

Пропуск через митний кордон таких товарів здійснюється після перевірки відповідності вантажу і документів на електронній копії попередньої вантажної митної декларації.

Дія цього пункту не поширюється на транспортні засоби (код товару згідно з УКТ ЗЕД 87.03), які ввозяться на митну територію України відповідно до зовнішньоекономічних договорів консигнації, а також як експонати, пов'язані з виставковою діяльністю іноземних підприємств. ( Абзац третій пункту 1 із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )

( Пункт 1 в редакції Постанови КМ N 460 ( 460-98-п ) від 02.04.98 )

2. Державній митній службі у двотижневий термін розробити порядок оформлення попередньої вантажної митної декларації на підакцизні товари та справляння митних платежів під час її оформлення у митницях, в зоні діяльності яких зареєстровані суб'єкти підприємницької діяльності, що ввозять (імпортують) товари, зазначені у додатку до цієї постанови, до фактичного перетину такими товарами митного кордону України.

3. Ця постанова набирає чинності через 30 днів після її опублікування у газеті "Урядовий кур'єр".
