РОЗПОРЯДЖЕННЯ від 29 жовтня 2009 р. N 1304-р Київ

Про внесення змін до переліку об'єктів, що фінансуються у 2009 році за рахунок коштів Стабілізаційного фонду, передбачених для реалізації інвестиційних проектів соціально-економічного розвитку регіонів

Внести до переліку об'єктів, що фінансуються у 2009 році за рахунок коштів Стабілізаційного фонду, передбачених для реалізації інвестиційних проектів соціально-економічного розвитку регіонів, затвердженого розпорядженням Кабінету Міністрів України від 13 травня 2009 р. N 544 ( 544-2009-р ), - із змінами, внесеними розпорядженнями Кабінету Міністрів України від 5 серпня 2009 р. N 933 ( 933-2009-р ), від 26 серпня 2009 р. N 1084 ( 1084-2009-р ) та від 23 вересня 2009 р. N 1153 ( 1153-2009-р ), зміни, що додаються.
