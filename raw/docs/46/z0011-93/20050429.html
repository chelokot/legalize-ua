Про умови оплати праці працівників місцевих органів Мінприроди

( Із змінами, внесеними згідно з Наказом Мінпраці N 95 ( z0197-93 ) від 15.12.93 )

Відповідно до ст.45 Декрету Кабінету Міністрів України "Про оплату праці" ( 23-92 ) за дорученням Кабінету Міністрів України від 15.02.93 N 2892/16 з метою упорядкування оплати праці працівників місцевих органів Мінприроди України Міністерство праці за погодженням з Міністерством фінансів і міністерством охорони навколишнього природного середовища постановляє:

1. Затвердити:

умови оплати праці працівників місцевих органів Мінприроди стосовно умов оплати праці, передбачених постановою Кабінету Міністрів України від 21 січня 1993 р. N 35 ( 35-93-п ) для працівників апарату органів державної виконавчої влади та їх органів;

шкали співвідношень посадових окладів керівних працівників і спеціалістів місцевих органів Мінприроди згідно з додатками 1-3; посадові оклади службовців апарату зазначених органів стосовно коефіцієнтів співвідношень посадових окладів до мінімального розміру заробітної плати, затверджених постановою Кабінету Міністрів України від 21 січня 1993 р. N 35 (таблиця N 15) для службовців державних адміністрацій районів.

2. Посадові оклади працівників місцевих органів Мінприроди, визначені зазначеним наказом, обчислюються із установленого мінімального розміру заробітної плати і підвищуються за коефіцієнтами згідно з додатком N 6 до Постанови Кабінету Міністрів України від 2 червня 1993 р. N 393 ( 393-93-п ) "Про підвищення заробітної плати на державних підприємствах, в установах, організаціях". ( Пункт 2 в редакції Наказу Мінпраці N 95 ( z0197-93 ) від 15.12.93 )

3. Установити, що міські державні інспекції охорони навколишнього природного середовища відносяться по оплаті праці працівників до тих груп, до яких віднесені відповідні міста за показниками, затвердженими постановою Кабінету Міністрів України від 10 червня 1992 р. N 320 ( 320-92-п ) "Про віднесення областей та міст до груп за оплатою праці".

4. Умови оплати праці і посадові оклади, затверджені цією постановою, впроваджуються з 1 січня 1993 р.
