Про умови оплати праці працівників Національного центру управління та випробувань космічних засобів

Стан: Чинний

Ідентифікатор: 1193-2000-п

Текст документа від 01.09.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 серпня 2000 р. N 1193 Київ

Про умови оплати праці працівників Національного центру управління та випробувань космічних засобів

( Із змінами, внесеними згідно з Постановами КМ N 541 ( 541-2001-п ) від 18.05.2001 N 609 ( 609-2003-п ) від 26.04.2003 N 494 ( 494-2004-п ) від 14.04.2004 N 762 ( 762-2004-п ) від 16.06.2004 N 790 ( 790-2005-п ) від 22.08.2005 )

( Дію Постанови поширено на працівників представництв генерального замовника - Національного космічного агентства на підприємствах космічної галузі згідно з Постановою КМ N 762 ( 762-2004-п ) від 16.06.2004 )

Кабінет Міністрів України постановляє:

1. Поширити дію постанови Кабінету Міністрів України від 30 серпня 2002 р. N 1298 ( 1298-2002-п ) "Про оплату праці працівників на основі Єдиної тарифної сітки розрядів і коефіцієнтів з оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" (Офіційний вісник України, 2002 р., N 36, ст. 1699) на працівників Національного центру управління та випробувань космічних засобів. ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановами КМ N 541 ( 541-2001-п ) від 18.05.2001, N 790 ( 790-2005-п ) від 22.08.2005 )

Установити, що посадові оклади керівних і наукових працівників зазначеного Центру визначаються на рівні посадових окладів, установлених для відповідних працівників галузевих науково-дослідних установ і організацій (розділ II "Наукові установи і організації" додатка 1 до постанови Кабінету Міністрів України від 29 травня 1996 р. N 565 ( 565-96-п ) у редакції постанови Кабінету Міністрів України від 2 грудня 1996 р. N 1458 ( 1458-96-п ).

2. Надати Генеральному директору Національного космічного агентства право установлювати працівникам Національного центру управління та випробувань космічних засобів:

доплату в розмірі до 50 відсотків посадового окладу за підтримання технічних засобів у постійній готовності до виконання завдань управління космічними апаратами та спеціального контролю, а також забезпечення контролю за якістю виготовлення ракетно-космічної техніки; ( Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 762 ( 762-2004-п ) від 16.06.2004 )

надбавку до посадового окладу за стаж роботи в Центрі та в представництвах генерального замовника - Національного космічного агентства на підприємствах космічної галузі, крім працівників, на яких поширюється дія постанови Кабінету Міністрів України від 26 квітня 2003 р. N 609 ( 609-2003-п ) "Про виплату надбавки за стаж наукової роботи", у таких розмірах: понад 2 роки - 5 відсотків, понад 5 років - 10, понад 10 років - 15, понад 15 років - 20, понад 20 років - 25 відсотків посадового окладу. ( Абзац третій пункту 2 із змінами, внесеними згідно з Постановою КМ N 609 ( 609-2003-п ) від 26.04.2003 - Постанова втратила чинність на підставі Постанови КМ N 494 ( 494-2004-п ) від 14.04.2004; із змінами, внесеними згідно з Постановою КМ N 762 ( 762-2004-п ) від 16.06.2004 )

3. Національному космічному агентству за погодженням з Міністерством праці та соціальної політики і Міністерством фінансів у місячний термін розробити і затвердити схему посадових окладів працівників Національного центру управління та випробування космічних засобів, представництв генерального замовника - Національного космічного агентства на підприємствах космічної галузі та положення про виплату надбавки за стаж роботи. ( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 762 ( 762-2004-п ) від 16.06.2004 )

4. Витрати, пов'язані із запровадженням умов оплати праці, встановлених цією постановою, провадяться у межах коштів, передбачених Національному центру управління та випробувань космічних засобів на оплату праці.

5. Ця постанова набирає чинності з 1 січня 2001 року.
