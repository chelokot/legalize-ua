РОЗПОРЯДЖЕННЯ

від 5 листопада 2014 р. № 1181-р
Київ

Про погодження умов тендеру на отримання ліцензій на користування радіочастотним ресурсом України для впровадження радіотехнології “Цифровий стільниковий радіозв’язок ІМТ-2000 (UMTS)” в смугах радіочастот 1920 - 1935/2110 - 2125, 1950 - 1965/2140 - 2155, 1965 - 1980/2155 - 2170 Мгц

Погодити умови тендеру на отримання ліцензій на користування радіочастотним ресурсом України для впровадження радіотехнології “Цифровий стільниковий радіозв’язок IМТ-2000 (UMTS)” в смугах радіочастот 1920 - 1935/2110 - 2125, 1950 - 1965/2140 - 2155, 1965 - 1980/2155 - 2170 Мгц, затверджені рішенням Національної комісії, що здійснює державне регулювання у сфері зв’язку та інформатизації, від 28 жовтня 2014 р. № 730.
