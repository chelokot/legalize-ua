Мінагрополітики України; Наказ від 30.07.2008 № 467

Про внесення змін до Інструкції з оформлення посадовими особами Української державної помологічно-ампелографічної інспекції матеріалів про адміністративні правопорушення

Реєстрація: Мін'юст України від 13.08.2008 № 749/15440

Стан: Втратив чинність

Ідентифікатор: z0749-08

Текст документа від 20.09.2013:

МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

30.07.2008 N 467

Зареєстровано в Міністерстві юстиції України 13 серпня 2008 р. за N 749/15440

{ Наказ втратив чинність на підставі Наказу Міністерства аграрної політики та продовольства N 495 ( z1477-13 ) від 12.08.2013 }

Про внесення змін до Інструкції з оформлення посадовими особами Української державної помологічно-ампелографічної інспекції матеріалів про адміністративні правопорушення

Відповідно до Кодексу України про адміністративні правопорушення ( 80731-10, 80732-10 ) та з метою приведення у відповідність до нової редакції Положення про Українську державну помологічно-ампелографічну інспекцію, затвердженого наказом Мінагрополітики від 31.10.2007 N 770 ( z1279-07 ), зареєстрованого в Міністерстві юстиції України 16.11.2007 за N 1279/14546, НАКАЗУЮ:

1. Внести до Інструкції з оформлення посадовими особами Української державної помологічно-ампелографічної інспекції матеріалів про адміністративні правопорушення, затвердженої наказом Міністерства аграрної політики України від 04.02.2005 N 62 ( z0314-05 ), зареєстрованої в Міністерстві юстиції України 18.03.2005 за N 314/10594, такі зміни:

1.1. Пункт 1.1 викласти у такій редакції:

"1.1. Ця Інструкція розроблена відповідно до Кодексу України про адміністративні правопорушення ( 80731-10, 80732-10 ), Положення про Українську державну помологічно-ампелографічну інспекцію, затвердженого наказом Міністерства аграрної політики України від 31.10.2007 N 770 ( z1279-07 ), зареєстрованого в Міністерстві юстиції України 16.11.2007 за N 1279/14546".

1.2. Пункт 3.1 після слів "державні інспектори з розсадництва" доповнити словом "Української".

2. Українській державній помологічно-ампелографічній інспекції (Гудзій Ю.Б.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Мельника С.І.

Міністр Ю.Ф.Мельник
