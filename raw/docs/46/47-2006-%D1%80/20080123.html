{ Розпорядження втратило чинність на підставі Розпорядження КМ N 501-р ( 501-2008-р ) від 23.01.2008 }

Про затвердження складу Української частини Підкомітету з питань гуманітарного співробітництва Українсько-Російської міждержавної комісії

Затвердити склад Української частини Підкомітету з питань гуманітарного співробітництва Українсько-Російської міждержавної комісії (додається).

Дозволити голові Української частини Підкомітету вносити в разі потреби зміни до її складу.
