Текст документа від 11.06.2001:

МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ

НАКАЗ

N 271 від 11.11.99 Зареєстровано в Міністерстві юстиції України 25 листопада 1999 р. за N 815/4108

Про оцінку вартості дорогоцінних металів та дорогоцінного каміння під час приватизації

( Із змінами, внесеними згідно з Наказом Мінфіну N 242/855 ( z0494-01 ) від 21.05.2001 )

Відповідно до постанови Кабінету Міністрів України від 22 липня 1998 р. N 1114 ( 1114-98-п ) "Про затвердження Методики оцінки вартості майна під час приватизації" НАКАЗУЮ:

1. Затвердити Положення про оцінку вартості дорогоцінних металів та дорогоцінного каміння під час приватизації, що додається.

2. Головному управлінню дорогоцінних металів і дорогоцінного каміння разом з юридичним управлінням зареєструвати цей наказ у Міністерстві юстиції у встановлений чинним законодавством термін.

3. Головному управлінню дорогоцінних металів і дорогоцінного каміння (Видолоб В.В.) довести зазначене Положення до відома зацікавлених міністерств та інших центральних органів виконавчої влади.

4. Визнати таким, що втратило чинність, Положення про порядок оцінки вартості дорогоцінних металів та дорогоцінного каміння під час приватизації, затверджене наказом Міністерства фінансів України від 14 жовтня 1996 р. N 220/1 ( z0634-96 ).

В.о.Міністра П.К.Германчук

( Положення про оцінку вартості дорогоцінних металів та дорогоцінного каміння під час приватизації втратив чинність на підставі Наказу Мінфіну N 242/855 ( z0494-01 ) від 21.05.2001 )
