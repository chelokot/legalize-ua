{ Наказ втратив чинність на підставі Наказу Міністерства освіти і науки N 781 ( z1074-07 ) від 03.09.2007 }

Про внесення змін до наказу Міністерства освіти і науки України від 03.06.2004 N 446

На виконання постанови Кабінету Міністрів України від 22.08.2005 N 790 ( 790-2005-п ) "Про внесення змін та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести до наказу Міністерства освіти і науки України від 03.06.2004 N 446 ( z0774-04 ) "Про затвердження розмірів посадових окладів окремих категорій працівників навчальних закладів, що мають навчальні судна або літаки (гелікоптери)", зареєстрованого в Міністерстві юстиції України 23.06.2004 за N 774/9373, із змінами і доповненнями, унесеними наказами Міністерства освіти і науки України від 25.01.2005 N 43 ( z0114-05 ), зареєстрованим у Міністерстві юстиції України 28.01.2005 за N 114/10394, та від 16.06.2005 N 362 ( z0701-05 ), зареєстрованим у Міністерстві юстиції України 30.06.2005 за N 701/10981, такі зміни:

1.1. Викласти додатки 1, 2 в редакції, що додається.

2. Керівникам навчальних закладів, що мають навчальні судна або літаки (гелікоптери), у межах затвердженого фонду заробітної плати установити з 1 вересня 2005 року посадові оклади (ставки заробітної плати) відповідним категоріям працівників цих навчальних закладів у розмірах, визначених у додатках 1, 2.

3. Контроль за виконанням наказу покласти на заступника Міністра Богомолова А.Г.

Міністр C.М.Ніколаєнко
