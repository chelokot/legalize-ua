КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 серпня 1998 р. N 669-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 235-р ( 235-2000-р ) від 15.05.2000 )

Про створення робочої групи із закінчення розроблення проекту Податкового кодексу України

1. З метою закінчення розроблення проекту Податкового кодексу України створити робочу групу у складі згідно з додатком.

2. Робочій групі у двотижневий термін доопрацювати проект Концепції Податкового кодексу України з урахуванням зауважень, висловлених під час її обговорення на засіданні Кабінету Міністрів України, та затвердити її за погодженням з Віце-прем'єр-міністром України Тігіпком С.Л.

3. Робочій групі до 25 вересня 1998 року подати Кабінету Міністрів України робочий варіант проекту Податкового кодексу України.

4. Контроль за виконанням цього розпорядження покласти на Віце-прем'єр-міністра України Тігіпка С.Л.
