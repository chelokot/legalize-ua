КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 вересня 2001 р. N 409-р Київ

( Розпорядження скасовано на підставі Розпорядження КМ N 377-р ( 377-2005-р ) від 31.08.2005 )

Про передачу будівлі N 13 військового містечка N 36 у м. Києві Академії медичних наук

Прийняти пропозицію Міноборони та Академії медичних наук, погоджену з Мінекономіки, Мінфіном, Фондом державного майна та Держкомстатом, про передачу із сфери управління Міноборони будівлі N 13 військового містечка N 36 у м. Києві (вул. Мельникова, 24) Академії медичних наук для розміщення центру кардіохірургії новонароджених.

Прем'єр-міністр України А.КІНАХ
