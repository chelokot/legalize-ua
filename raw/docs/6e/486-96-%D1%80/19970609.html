Кабінет Міністрів України; Розпорядження від 02.08.1996 № 486-р

Про робочу групу для координації робіт з підготовки перебудови фінансового сектора

Стан: Втратив чинність

Ідентифікатор: 486-96-р

Текст документа від 09.06.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 серпня 1996 р. N 486-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 556 ( 556-97-п ) від 09.06.97 )

Затвердити склад міжвідомчої робочої групи для координації робіт з підготовки проекту щодо структурної перебудови фінансового сектора, що підтримується Міжнародним банком реконструкції та розвитку, згідно з додатком.

Прем'єр-міністр України П.ЛАЗАРЕНКО

Інд. 27

Додаток до розпорядження Кабінету Міністрів України від 2 серпня 1996 р. N 486-р

СКЛАД міжвідомчої робочої групи для координації робіт з підготовки проекту щодо структурної перебудови фінансового сектора

БОНДАР - перший заступник Голови правління Володимир Олексійович Національного банку (голова робочої групи)

НАУМЕНКО - заступник Міністра економіки Володимир Іванович

МАКАЦАРІЯ - заступник Міністра фінансів Сергій Мегонович

ЯСІНСЬКИЙ - головний консультант Комісії Володимир Миколайович Верховної Ради України з питань фінансів і банківської діяльності (за згодою)

РИБАЧУК - начальник управління Національного Олег Борисович банку (за згодою)

КОВБАСЮК - заступник начальника управління Юрій Васильович Мінфіну

ШУМИЛО - начальник відділу Мінекономіки Ігор Анатолійович

ІСКРА - головний спеціаліст відділу Лариса Анатоліївна Кабінету Міністрів України
