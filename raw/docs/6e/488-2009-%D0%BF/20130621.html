КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 травня 2009 р. N 488 Київ

Про межі акваторії морського порту Скадовськ

{ Назва Постанови в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

{ Із змінами, внесеними згідно з Постановою КМ N 406 ( 406-2013-п ) від 03.06.2013 }

Кабінет Міністрів України постановляє:

1. Визначити межі акваторії морського порту Скадовськ згідно з додатком.

{ Пункт 1 в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

2. Державному підприємству "Адміністрація морських портів України" забезпечити безпеку мореплавства в межах акваторії, визначених у додатку.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 406 ( 406-2013-п ) від 03.06.2013 }

МЕЖІ акваторії морського порту Скадовськ

{ Назва додатка в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

Акваторія порту включає:

акваторію, обмежену лініями, що проходять через точки з такими координатами:

46 град. 06' 27,9" північної широти, 32 град. 54' 28,9" східної довготи; далі вздовж лінії кордонів причалів до точок з координатами 46 град. 06' 28,2" північної широти, 32 град. 55' 06,4" східної довготи; 46 град. 02' 48,8" північної широти, 32 град. 56' 28,1" східної довготи;

далі по береговій лінії до точок з координатами 46 град. 02' 19,1" північної широти, 32 град. 56' 05,3" східної довготи; 46 град. 05' 35,3" північної широти, 32 град. 50' 41,8" східної довготи; 46 град. 06' 02,3" північної широти, 32 град. 50' 41,8" східної довготи;

акваторію портопункту Хорли, обмежену лініями, що проходять через точки з такими координатами:

46 град. 04' 30,4" північної широти, 33 град. 17' 23,4" східної довготи;

далі вздовж лінії кордонів причалів до точок з координатами 46 град. 04' 30,7" північної широти, 33 град. 17' 48,9" східної довготи; 46 град. 01' 46,9" північної широти, 33 град. 18' 00,9" східної довготи; 46 град. 00' 42,0" північної широти, 33 град. 16' 36,0" східної довготи; 46 град. 01' 33,0" північної широти, 33 град. 13' 00,5" східної довготи; 46 град. 01' 38,7" північної широти, 33 град. 13' 00,5" східної довготи.

На півночі акваторія обмежується береговою лінією.
