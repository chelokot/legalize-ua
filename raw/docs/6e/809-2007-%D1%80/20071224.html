Кабінет Міністрів України; Розпорядження від 03.10.2007 № 809-р

Про притягнення до дисциплінарної відповідальності члена Національної комісії з питань регулювання зв'язку України Єжової Л.М.

Стан: Втратив чинність

Ідентифікатор: 809-2007-р

Текст документа від 24.12.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 жовтня 2007 р. N 809-р Київ

{ Розпорядження скасовано на підставі Постанови КМ N 1403 ( 1403-2007-п ) від 24.12.2007 }

{ Дію Розпорядження зупинено згідно з Указом Президента N 1010/2007 ( 1010/2007 ) від 24.10.2007 }

Про притягнення до дисциплінарної відповідальності члена Національної комісії з питань регулювання зв'язку України Єжової Л.М.

Оголосити догану члену Національної комісії з питань регулювання зв'язку України Єжовій Людмилі Михайлівні за несумлінне виконання службових обов'язків.

Прем'єр-міністр України В.ЯНУКОВИЧ
