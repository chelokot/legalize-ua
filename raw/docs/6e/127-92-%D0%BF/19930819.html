ПОСТАНОВА від 13 березня 1992 р. N 127 Київ

( Постанова втратила чинність на підставі Постанови КМ N 656 ( 656-93-п ) від 19.08.93 )

Про склад Української частини Постійної українсько-баварської робочої комісії

Кабінет Міністрів України постановляє:

Затвердити склад Української частини Постійної українсько-баварської робочої комісії згідно з додатком.

Визнати таким, що втратив чинність, пункт 1 постанови Ради Міністрів УРСР від 17 березня 1990 р. N 58 в частині складу вказаної Комісії.
