КАБІНЕТ МІНІСТРІВ УКРАЇНИ
РОЗПОРЯДЖЕННЯ

від 25 квітня 2012 р. № 238-р
Київ

Про внесення змін до розпоряджень Кабінету Міністрів України від 24 липня 2003 р. № 456 і від 8 квітня 2009 р. № 381

Внести до розпоряджень Кабінету Міністрів України від 24 липня 2003 р. № 456 “Про відкриття пунктів контролю через державний кордон” (Офіційний вісник України, 2003 р., № 31, ст. 1631) і від 8 квітня 2009 р. № 381 “Про відкриття пункту контролю через державний кордон на території контейнерного терміналу Одеса - Ліски” зміни, що додаються.

Прем'єр-міністр України

М.АЗАРОВ

Інд. 70





ЗАТВЕРДЖЕНО
розпорядженням Кабінету Міністрів України
від 25 квітня 2012 р. № 238-р

ЗМІНИ,
що вносяться до розпоряджень Кабінету Міністрів України від 24 липня 2003 р. № 456 і від 8 квітня 2009 р. № 381

1. Абзаци другий - восьмий розпорядження Кабінету Міністрів України від 24 липня 2003 р. № 456 замінити абзацами такого змісту:

“на ділянці українсько-російського державного кордону:

Іловайськ - для пункту пропуску Квашине;

Куп’янськ-Сортувальний, Куп’янськ-Вузловий - для пункту пропуску Тополі;

Харків-Сортувальний, Харків-Пасажирський - для пункту пропуску Козача Лопань;

Ворожба - для пункту пропуску Волфіне;

Хутір-Михайлівський, Конотоп - для пункту пропуску Зернове;

на ділянці українсько-білоруського державного кордону:

Хоробичі - для пункту пропуску Щорс;

Чернігів - для пункту пропуску Горностаївка;

Коростень, Овруч - для пункту пропуску Виступовичі;

Сарни - для пункту пропуску Удрицьк;

Ковель - для пункту пропуску Заболоття;

на ділянці українсько-польського державного кордону:

Лудин, Ізов - для пункту пропуску Володимир-Волинський;

на ділянці українсько-словацького державного кордону:

Ужгород - для пункту пропуску Павлове;

на ділянці українсько-угорського державного кордону:

Батєве - для пункту пропуску Саловка;

на ділянці українсько-молдовського державного кордону:

Ларга - для пункту пропуску Кельменці;

Болград, Карабуцени - самостійні пункти контролю.”.

2. У розпорядженні Кабінету Міністрів України від 8 квітня 2009 р. № 381 слова “пункту пропуску через державний кордон в Одеському морському торговельному порту” замінити словами “пунктів пропуску через державний кордон для морського сполучення  в Одеському морському торговельному порту, Іллічівському морському торговельному порту і Морському торговельному порту “Южний”.
