( Указ втратив чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про зміни у складі Тимчасової ради Національного банку України

Увести до складу Тимчасової ради Національного банку України, затвердженого Указом Президента України від 13 травня 1997 року N 424 ( 424/97 ) "Про Тимчасову раду Національного банку України" (із зміною, внесеною Указом Президента України від 19 червня 1997 року N 561 ( 561/97 ), РОГОВОГО Василя Васильовича - Міністра економіки України та АЛЬОШИНА Валерія Борисовича - Голову Комітету Верховної Ради України з питань фінансів і банківської діяльності (за згодою), вивівши зі складу Тимчасової ради Єханурова Ю.І., Суслова В.І.

Президент України Л.КУЧМА

м. Київ, 2 жовтня 1998 року N 1101/98
