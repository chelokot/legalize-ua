Про внесення зміни до Порядку заняття торговельною діяльністю і правил торговельного обслуговування населення

Стан: Втратив чинність

Ідентифікатор: 1611-2003-п

Текст документа від 28.11.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 жовтня 2003 р. N 1611 Київ

Про внесення зміни до Порядку заняття торговельною діяльністю і правил торговельного обслуговування населення

( Із змінами, внесеними згідно з Постановою КМ N 1860 ( 1860-2003-п ) від 28.11.2003 )

Кабінет Міністрів України постановляє:

1. Пункт 39 Порядку заняття торговельною діяльністю і правил торговельного обслуговування населення, затверджених постановою Кабінету Міністрів України від 8 лютого 1995 р. N 108 ( 108-95-п ) (ЗП України, 1995 р., N 5, ст. 118; Офіційний вісник України, 1997 р., число 51, с. 27; 1998 р., N 28, ст. 1037, N 46, ст. 1697; 1999 р., N 42, ст. 2096; 2001 р., N 20, ст. 856; 2002 р., N 34, ст. 1588), викласти в такій редакції:

"39. Товари у суб'єкта господарської діяльності повинні бути з відповідними документами, наявність яких передбачена законодавством (накладні, товарно-транспортні накладні, копії сертифікатів відповідності державної системи сертифікації або копії свідоцтв про визнання відповідності на захищених голографічними елементами бланках на товари, що підлягають обов'язковій сертифікації)".

2. Установити, що копії сертифікатів відповідності або копії свідоцтв про визнання відповідності на не захищених голографічними елементами бланках, отримані суб'єктами господарської діяльності на партію товару до 1 лютого 2004 р., дійсні до реалізації цієї партії. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1860 ( 1860-2003-п ) від 28.11.2003 )

3. Ця постанова набирає чинності з 1 лютого 2004 року. ( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1860 ( 1860-2003-п ) від 28.11.2003 )
