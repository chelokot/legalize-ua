КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 липня 1998 р. N 1078 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1140 ( 1140-2012-п ) від 05.12.2012 }

Деякі питання Державного комітету по геології і використанню надр

{ Із змінами, внесеними згідно з Постановою КМ N 792 ( 792-2004-п ) від 21.06.2004 }

На виконання Указу Президента України від 21 січня 1998 р. N 41 ( 41/98 ) "Про запровадження режиму жорсткого обмеження бюджетних видатків та інших державних витрат, заходи щодо забезпечення надходження доходів до бюджету і запобігання фінансовій кризі" Кабінет Міністрів України постановляє:

1. Покласти на Державний комітет природних ресурсів функції єдиного замовника державного контракту з приросту запасів корисних копалин та головного розпорядника коштів Державного бюджету, спрямованих на проведення геологорозвідувальних робіт на території України. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 792 ( 792-2004-п ) від 21.06.2004 )

2. Державному комітетові по геології і використанню надр за погодженням з Міністерством економіки, Міністерством фінансів і Міністерством юстиції у тримісячний термін подати на затвердження Кабінету Міністрів України проект Порядку доведення геологічних завдань, їх виконання, звітності, фінансування та встановлення відносин між головним розпорядником коштів Державного бюджету, спрямованих на проведення геологорозвідувальних робіт та виконавцями цих робіт.

3. Державному комітету природних ресурсів, Міністерству економіки і Міністерству фінансів під час складання проектів Державної програми економічного і соціального розвитку України та Державного бюджету України на 1999 та наступні роки враховувати вимоги пункту 1 цієї постанови. ( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 792 ( 792-2004-п ) від 21.06.2004 )
