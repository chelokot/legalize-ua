( Додатково див. Указ Президента N 245/99 від 11.03.99 )

На зміну статті 2 Указу Президента України від 13 травня 1997 року N 421 ( 421/97 ) "Про Координаційну раду з питань місцевого самоврядування" (із змінами, внесеними Указом Президента України від 8 жовтня 1997 року N 1131 ( 1131/97 ) затвердити новий персональний склад Координаційної ради (додається).
