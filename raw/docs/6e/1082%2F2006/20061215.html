Президент України; Указ від 15.12.2006 № 1082/2006

Про визнання таким, що втратив чинність, та відновлення дії деяких указів Президента України

Стан: Чинний

Ідентифікатор: 1082/2006

Текст документа від 15.12.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання таким, що втратив чинність, та відновлення дії деяких указів Президента України

1. Визнати таким, що втратив чинність, Указ Президента України від 26 червня 2006 року N 582 ( 582/2006 ) "Про визнання такими, що втратили чинність, деяких Указів Президента України".

2. Відновити дію:

Указу Президента України від 1 квітня 2004 року N 387 ( 387/2004 ) "Про призначення членів Вищої ради юстиції" (зі змінами, внесеними Указом від 22 вересня 2004 року N 1112 ( 1112/2004 );

Указу Президента України від 25 вересня 2004 року N 1138 ( 1138/2004 ) "Про призначення членів Вищої ради юстиції".

3. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 15 грудня 2006 року N 1082/2006
