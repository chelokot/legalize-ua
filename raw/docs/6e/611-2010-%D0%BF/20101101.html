КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 липня 2010 р. N 611 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 969 ( 969-2010-п ) від 18.10.2010 }

Про затвердження Порядку використання у 2010 році коштів Стабілізаційного фонду для виконання Державної цільової оборонної програми утилізації звичайних видів боєприпасів, непридатних для подальшого використання і зберігання

Відповідно до частини другої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2010 році коштів Стабілізаційного фонду ( 2154-17 ) для виконання Державної цільової оборонної програми утилізації звичайних видів боєприпасів, непридатних для подальшого використання і зберігання ( 940-2008-п ), що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 липня 2010 р. N 611

ПОРЯДОК використання у 2010 році коштів Стабілізаційного фонду ( 2154-17 ) для виконання Державної цільової оборонної програми утилізації звичайних видів боєприпасів, непридатних для подальшого використання і зберігання ( 940-2008-п )

1. Цей Порядок визначає механізм використання у 2010 році коштів Стабілізаційного фонду за напрямом, передбаченим пунктом 2 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) для виконання Державної цільової оборонної програми утилізації боєприпасів, непридатних для подальшого використання і зберігання ( 940-2008-п ) (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Міноборони.

3. Бюджетні кошти виділяються Міноборони на безповоротній основі у межах 730 млн. гривень, передбачених Міноборони пунктом 2 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ).

Бюджетні кошти спрямовуються на проведення робіт з утилізації боєприпасів відповідно до Державної цільової оборонної програми утилізації звичайних видів боєприпасів, непридатних для подальшого використання і зберігання, на 2008-2017 роки (далі - Державна програма утилізації), затвердженої постановою Кабінету Міністрів України від 22 жовтня 2008 р. N 940 ( 940-2008-п ) (Офіційний вісник України, 2008 р., N 82, ст. 2765; 2010 р., N 46, ст. 1500).

Джерелом покриття бюджетних коштів, передбачених для виконання Державної програми утилізації ( 940-2008-п ), є кошти, одержані від продажу земельних ділянок несільськогосподарського призначення, що перебувають у державній власності, на яких розташовані об'єкти, що підлягають приватизації, кошти, одержані від приватизації державного майна та інших надходжень, безпосередньо пов'язаних з процесом приватизації та кредитуванням підприємств, а також кошти, які надійдуть від сплати штрафів, пені та неустойки за невиконання власниками приватизованих об'єктів умов договорів їх купівлі-продажу, а також надходження від цільового розміщення державних цінних паперів та коштів Стабілізаційного фонду ( 2154-17 ), що були надані на поворотній основі.

4. Міноборони подає Мінфіну пропозиції щодо розподілу бюджетних коштів за кодами економічної класифікації видатків державного бюджету.

Мінфін з урахуванням зазначених пропозицій визначає бюджетну програму, закріплює за нею код програмної та функціональної класифікації видатків і кредитування державного бюджету за напрямом використання бюджетних коштів та вносить у встановленому порядку зміни до розпису бюджету.

5. Міноборони після одержання довідки про внесення змін до розпису державного бюджету розробляє і затверджує в установленому порядку паспорт бюджетної програми та інші документи, необхідні для забезпечення виконання Державної програми утилізації і передбачені Порядком складання, розгляду, затвердження та основних вимог до виконання кошторисів бюджетних установ, затвердженим постановою Кабінету Міністрів України від 28 лютого 2002 р. N 228 ( 228-2002-п ) (Офіційний вісник України, 2002 р., N 9, ст. 414).

6. Закупівля робіт з утилізації боєприпасів за рахунок бюджетних коштів та їх попередня оплата здійснюються в установленому законодавством порядку.

7. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

8. Після закінчення бюджетного періоду залишки бюджетних коштів, що обліковуються на рахунках Міноборони станом на 1 січня 2011 р. за визначеною бюджетною програмою, повертаються до державного бюджету.

9. Міноборони подає щомісяця до 5 числа Мінфіну звіт про використання бюджетних коштів, а в разі повернення їх залишків до державного бюджету - також відповідну інформацію.

10. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим використанням здійснюються в установленому законодавством порядку.
