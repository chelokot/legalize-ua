НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

N 310 від 10.03.99 Зареєстровано в Міністерстві м.Київ юстиції України 10 березня 1999 р. vd990310 vn310 за N 153/3446

Про роздрібні ціни на газ природний, що використовується населенням на комунально-побутові потреби

( Із змінами, внесеними згідно з Постановою НКРЕ N 1080 ( z0961-01 ) від 24.10.2001 - набуває чинності з 01.12.2001 )

Згідно з повноваженнями, наданими Указом Президента України від 21 квітня 1998 року N 335 ( 335/98 ) "Питання Національної комісії регулювання електроенергетики України", постановою Кабінету Міністрів України від 25 грудня 1996 року N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", та для забезпечення більш повного відшкодування населенням фактичних витрат з видобутку, транспортування та постачання газу Національна комісія регулювання електроенергетики ПОСТАНОВЛЯЄ:

1. Затвердити роздрібні ціни на газ природний, що використовується населенням на комунально-побутові потреби, згідно з додатком, крім населення смт Солотвина Закарпатської області, яке споживає природний газ безпосередньо із Солотвинського родовища. ( Пункт 1 в редакції Постанови НКРЕ N 1080 ( z0961-01 ) від 24.10.2001 - набуває чинності з 01.12.2001 )

2. Встановити, що ця постанова набуває чинності з 1 квітня 1999 року.

В.о.Голови Комісії О.Гридасов
