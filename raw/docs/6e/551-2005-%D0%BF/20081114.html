Кабінет Міністрів України; Постанова від 12.07.2005 № 551

Про внесення змін у додатки до постанов Кабінету Міністрів України від 26 лютого 2000 р. N 403 та від 2 квітня 2001 р. N 314

Стан: Втратив чинність

Ідентифікатор: 551-2005-п

Текст документа від 14.11.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 липня 2005 р. N 551 Київ

Про внесення змін у додатки до постанов Кабінету Міністрів України від 26 лютого 2000 р. N 403 та від 2 квітня 2001 р. N 314

{ Із змінами, внесеними згідно з Постановою КМ N 954 ( 954-2008-п ) від 22.10.2008 }

На виконання Указу Президента України від 20 квітня 2005 р. N 675 ( 675/2005 ) "Про Міністерство охорони навколишнього природного середовища України" Кабінет Міністрів України постановляє:

1. У додатку 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851; 2004 р., N 8, ст. 481, N 30, ст. 2018):

1) позицію "Державний комітет природних ресурсів 146 5" виключити;

2) у позиції "Міністерство охорони навколишнього природного середовища" цифри "360" і "6" замінити відповідно цифрами "506" і "4".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 954 ( 954-2008-п ) від 22.10.2008 }
