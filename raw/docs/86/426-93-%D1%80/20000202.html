Кабінет Міністрів України; Розпорядження від 26.06.1993 № 426-р

Про чисельність та умови оплати праці працівників секретаріату Комісії з питань ядерної політики при Президентові України

Стан: Втратив чинність

Ідентифікатор: 426-93-р

Текст документа від 02.02.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 червня 1993 р. N 426-р Київ

( Із змінами, внесеними згідно з Постановою КМ N 207 ( 207-2000-п ) від 02.02.2000 )

На виконання розпорядження Президента України від 19 березня 1993 р. N 34/93-рп "Про Положення про Комісію з питань ядерної політики при Президентові України":

1. Затвердити чисельність штатних працівників секретаріату Комісії з питань ядерної політики при Президентові України у кількості 4 одиниць.

( Пункт 2 втратив чинність на підставі Постанови КМ N 207 ( 207-2000-п ) від 02.02.2000 ) 2. Установити умови оплати праці працівників секретаріату Комісії з питань ядерної політики при Президентові України стосовно до умов оплати праці, передбачених постановою Кабінету Міністрів України від 21 січня 1993 р. N 35 ( 35-93-п ) для працівників апарату органів державної виконавчої влади.

Затвердити коефіцієнти співвідношень посадових окладів до мінімального розміру заробітної плати у таких розмірах:

заступник голови Комісії - 14,5

секретар Комісії, консультант - 12,5

секретар-друкарка - 3,5-4,5

Посадові оклади працівників визначаються у порядку, встановленому постановою Кабінету Міністрів України від 2 червня 1993 р. N 393 ( 393-93-п ).

3. Взяти до відома, що фінансово-господарське обслуговування діяльності Комісії здійснюється Адміністрацією Президента України.

4. Мінфіну профінансувати у 1993 році витрати на утримання Комісії з питань ядерної політики при Президентові України в межах асигнувань, затверджених в державному бюджеті на утримання державних органів виконавчої влади.
