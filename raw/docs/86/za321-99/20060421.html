{ Постанова втратила чинність на підставі Постанови Національного банку N 89 ( z0410-06 ) від 16.03.2006 }

Про затвердження Положення щодо організації діяльності комерційних банків на ринку цінних паперів

Відповідно до статей 8 та 16 Закону України "Про банки і банківську діяльність" ( 872-12 ) та у зв'язку з необхідністю впорядкування діяльності комерційних банків на ринку цінних паперів Правління ПОСТАНОВЛЯЄ:

1. Затвердити Положення щодо організації діяльності комерційних банків на ринку цінних паперів ( z0321-99 ).

2. Емісійно-кредитному департаменту (Гребеник Н.І.) передати Положення Державній комісії з цінних паперів та фондового ринку для реєстрації у Міністерстві юстиції України.

3. Комерційним банкам привести свою діяльність на ринку цінних паперів у відповідність до вимог даного Положення протягом двох місяців з дати набуття чинності цією постановою.

4. Постанова набуває чинності через 10 днів після її реєстрації у Міністерстві юстиції України.

Голова В.А.Ющенко
