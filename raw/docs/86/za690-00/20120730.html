Держкомісціннихпаперів; Рішення від 15.09.2000 № 139

Про затвердження Положення про порядок приватизації акцій (часток, паїв), що належать державі у статутному капіталі господарських товариств, інших господарських організацій та підприємств, заснованих на базі об'єднання майна різних форм власності

Реєстрація: Мін'юст України від 06.10.2000 № 690/4911

Стан: Втратив чинність

Ідентифікатор: za690-00

Текст документа від 30.07.2012:

ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

N 139 від 15.09.2000 Зареєстровано в Міністерстві м.Київ юстиції України 6 жовтня 2000 р. за N 690/4911

Про затвердження Положення про порядок приватизації

акцій (часток, паїв), що належать державі у статутному

капіталі господарських товариств, інших господарських організацій та підприємств, заснованих на базі об'єднання майна різних форм власності

{ Заголовок Рішення в редакції Рішення Національної комісії з цінних паперів та фондового ринку

N 675 ( za177-12 ) від 10.05.2012 }

{ Із змінами, внесеними згідно з Рішенням Національної комісії з цінних паперів та фондового ринку

N 675 ( za177-12 ) від 10.05.2012 }

З метою удосконалення порядку приватизації акцій (часток, паїв), що належать державі в майні міжгосподарських підприємств та в статутних фондах створених на їх базі господарських товариств, Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Положення про порядок приватизації акцій (часток, паїв), що належать державі у статутному капіталі господарських товариств, інших господарських організацій та підприємств, заснованих на базі об'єднання майна різних форм власності (додається)( z0690-00 ).

{ Пункт 1 в редакції Рішення Національної комісії з цінних паперів та фондового ринку N 675 ( za177-12 ) від 10.05.2012 }

2. Контроль за виконанням цього рішення покласти на члена Комісії - заступника Голови М. Пефтієва.
