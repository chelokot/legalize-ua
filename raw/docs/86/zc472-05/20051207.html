Зареєстровано в Міністерстві юстиції України 9 грудня 2005 р. за N 1472/11752

Про реалізацію постанови Кабінету Міністрів України від 14.09.2005 N 909

Відповідно до пункту 12 Положення про Пенсійний фонд України, затвердженого Указом Президента України від 01.03.2001 N 121 ( 121/2001 ), пункту 2 постанови Кабінету Міністрів України від 14.09.2005 N 909 ( 909-2005-п ) "Про проведення експерименту із створення автоматизованої системи Накопичувального фонду загальнообов'язкового державного пенсійного страхування" правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Затвердити такі, що додаються:

Порядок проведення експерименту із створення автоматизованої системи Накопичувального фонду загальнообов'язкового державного пенсійного страхування ( z1472-05 ) (далі - Порядок);

Склад Міжвідомчої робочої групи з питань проведення експерименту із створення автоматизованої системи Накопичувального фонду загальнообов'язкового державного пенсійного страхування ( z1472-05 );

План-графік створення автоматизованої системи Накопичувального фонду загальнообов'язкового державного пенсійного страхування ( z1472-05 ).

3. Юридичному управлінню (Т.Рябцева) Пенсійного фонду України подати цю постанову для державної реєстрації до Міністерства юстиції України.

4. Контроль за виконанням цієї постанови покласти на заступника Голови правління О.Зарудного.
