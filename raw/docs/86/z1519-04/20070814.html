ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

17.11.2004 N 467

Зареєстровано в Міністерстві юстиції України 30 листопада 2004 р. за N 1519/10118

{ Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку

N 1611 ( z0891-07 ) від 19.07.2007 }

Про затвердження Змін та доповнень до рішення Державної комісії з цінних паперів та фондового ринку від 29.09.2000 N 149 "Про передачу повноважень з реєстрації випусків акцій до територіальних управлінь Комісії"

Відповідно до статті 7 Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ) та у зв'язку з прийняттям Державною комісією з цінних паперів та фондового ринку рішень: від 09.02.2001 N 18 ( z0449-01 ) "Про затвердження Положення про порядок реєстрації випуску акцій і облігацій підприємств та інформації про їх емісію (07-01/98) (у новій редакції)", зареєстрованого в Міністерстві юстиції України 25.05.2001 за N 449/5640, та від 11.06.2002 N 167 ( z0587-02 ) "Про затвердження Положення про порядок реєстрації випуску акцій закритих акціонерних товариств", зареєстрованого в Міністерстві юстиції України 16.07.2002 за N 587/6875, Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Зміни та доповнення до рішення Державної комісії з цінних паперів та фондового ринку від 29.09.2000 N 149 ( z0721-00 ) "Про передачу повноважень з реєстрації випусків акцій до територіальних управлінь Комісії".

2. Заступнику Виконавчого секретаря О.Петрашку забезпечити:

- державну реєстрацію цього рішення в Міністерстві юстиції України;

- опублікування цього рішення відповідно до вимог чинного законодавства.

3. Рішення набирає чинності відповідно до чинного законодавства.

4. Контроль за виконанням цього рішення покласти на заступника Виконавчого секретаря О.Петрашка.

Голова Комісії А.Балюк

Протокол засідання Комісії 17 листопада 2004 року N 40

ЗАТВЕРДЖЕНО Рішення Державної комісії з цінних паперів та фондового ринку 17.11.2004 N 467

Зареєстровано в Міністерстві юстиції України 30 листопада 2004 р. за N 1519/10118

ЗМІНИ ТА ДОПОВНЕННЯ до рішення Державної комісії з цінних паперів та фондового ринку від 29.09.2000 N 149 "Про передачу повноважень з реєстрації випусків акцій до територіальних управлінь Комісії" ( z0721-00 )

Підпункт 1.1 пункту 1 викласти в такій редакції:

"1.1. Закритих акціонерних товариств, крім тих, що створюються згідно з планом санації суб'єктів господарювання усіх форм власності, - відповідно до вимог Положення про порядок реєстрації випуску акцій закритих акціонерних товариств, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 11.06.2002 N 167 ( z0587-02 ) та зареєстрованого в Міністерстві юстиції України 16.07.2002 за N 587/6875".

Підпункт 1.6 пункту 1 викласти в такій редакції:

"1.6. Відкритих акціонерних товариств та інформації про їх емісію, крім тих, що створюються згідно з планом санації суб'єктів господарювання усіх форм власності, - відповідно до вимог Положення про порядок реєстрації випуску акцій і облігацій підприємств та інформації про їх емісію (07-01/98) (у новій редакції), затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 09.02.2001 N 18 ( z0449-01 ) та зареєстрованого в Міністерстві юстиції 25.05.2001 за N 449/5640, - якщо розмір статутного фонду на дату прийняття рішення про випуск акцій (з урахуванням емісії, щодо якої прийнято рішення) не перевищує 500 000 грн.".
