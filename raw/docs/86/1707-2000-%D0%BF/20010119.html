( Постанова втратила чинність на підставі Постанови КМ N 16 ( 16-2001-п ) від 12.01.2001 )

Про внесення змін до ставок ввізного мита на окремі види товарів

Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита ( 4а-93, 4б-93, 4в-93 ) на окремі види товарів згідно з додатком.

2. Затвердити зміни, що вносяться до постанови Кабінету Міністрів України від 18 липня 1995 р. N 531 ( 531-95-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів та до деяких рішень Уряду України" (ЗП України, 1995 р., N 10, ст. 246; Офіційний вісник України, 1998 р., N 9, ст. 337, N 31, ст. 1177; 1999 р., N 31, ст. 1619), які додаються.
