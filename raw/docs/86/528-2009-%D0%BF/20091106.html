КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 травня 2009 р. N 528 Київ

Про затвердження Порядку використання у 2009 році коштів Стабілізаційного фонду для будівництва та реконструкції об'єктів централізованого водопостачання сільських населених пунктів і для погашення кредиторської заборгованості за виконані у 2008 році роботи з будівництва та реконструкції зазначених об'єктів

{ Із змінами, внесеними згідно з Постановою КМ N 1146 ( 1146-2009-п ) від 14.10.2009 }

Відповідно до частини другої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) Кабінет Міністрів України постановляє:

1. Затвердити Порядок використання у 2009 році коштів Стабілізаційного фонду ( 835-17 ) для будівництва та реконструкції об'єктів централізованого водопостачання сільських населених пунктів і для погашення кредиторської заборгованості за виконані у 2008 році роботи з будівництва та реконструкції зазначених об'єктів, що додається.

2. Виділити Державному комітетові по водному господарству на безповоротній основі за рахунок нерозподілених коштів Стабілізаційного фонду кошти для будівництва та реконструкції об'єктів централізованого водопостачання сільських населених пунктів і для погашення кредиторської заборгованості за виконані у 2008 році роботи з будівництва та реконструкції зазначених об'єктів.

Джерелом покриття зазначених витрат визначити надходження від цільового розміщення державних цінних паперів, а в разі їх недостатності - кошти, отримані від приватизації державного майна, та залишок коштів Стабілізаційного фонду станом на 1 січня 2009 року.

3. Державному казначейству перерахувати кошти, виділені згідно з пунктом 2 цієї постанови.

4. Державному комітетові по водному господарству забезпечити погодження виділення відповідно до цієї постанови коштів Стабілізаційного фонду з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 20 травня 2009 р. N 528

ПОРЯДОК використання у 2009 році коштів Стабілізаційного фонду для будівництва та реконструкції об'єктів централізованого водопостачання сільських населених пунктів і для погашення кредиторської заборгованості за виконані у 2008 році роботи з будівництва та реконструкції зазначених об'єктів

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 1146 ( 1146-2009-п ) від 14.10.2009 }

1. Цей Порядок визначає механізм використання у 2009 році нерозподілених коштів Стабілізаційного фонду ( 835-17 ) для будівництва та реконструкції об'єктів централізованого водопостачання сільських населених пунктів і для погашення кредиторської заборгованості за виконані у 2008 році роботи з будівництва та реконструкції зазначених об'єктів (далі - бюджетні кошти).

{ Пункт 1 в редакції Постанови КМ N 1146 ( 1146-2009-п ) від 14.10.2009 }

2. Головним розпорядником бюджетних коштів є Держводгосп.

3. Бюджетні кошти спрямовуються з урахуванням Порядку, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) (Офіційний вісник України, 2009 р., N 24, ст. 793), на будівництво та реконструкцію об'єктів централізованого водопостачання сільських населених пунктів (далі - об'єкти) згідно з переліком, наведеним у додатку, а також для погашення кредиторської заборгованості за виконані у 2008 році роботи з будівництва та реконструкції об'єктів централізованого водопостачання сільських населених пунктів.

Перелік об'єктів, за якими утворилася кредиторська заборгованість, формується Держводгоспом на підставі фінансової звітності за бюджетною програмою "Першочергове забезпечення населених пунктів централізованим водопостачанням". { Пункт 3 доповнено абзацом згідно з Постановою КМ N 1146 ( 1146-2009-п ) від 14.10.2009 }

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1146 ( 1146-2009-п ) від 14.10.2009 }

4. Фінансування об'єктів капітального будівництва здійснюється відповідно до Порядку державного фінансування капітального будівництва, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) (Офіційний вісник України, 2001 р., N 52, ст. 2374).

5. Прийняття в експлуатацію закінчених будівництвом об'єктів здійснюється відповідно до Порядку, затвердженого постановою Кабінету Міністрів України від 8 жовтня 2008 р. N 923 ( 923-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2694).

6. Одержувачі бюджетних коштів подають щомісяця до 10 числа наступного періоду Держводгоспу звіт про їх використання.

7. Держводгосп подає щомісяця до 5 числа наступного періоду Мінфіну звіт про використання бюджетних коштів, а річний звіт - не пізніше ніж до 20 січня 2010 р. Мінфіну та Кабінетові Міністрів України.

8. Основні засоби, придбані за рахунок бюджетних коштів, після введення в експлуатацію зараховуються на баланс балансоутримувача об'єкта.

9. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
