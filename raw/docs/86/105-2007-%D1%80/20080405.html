Стан: Втратив чинність

Текст документа від 05.04.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 березня 2007 р. N 105-р Київ

Про встановлення строку виконання робіт з ремонту та відновлення верстатів за межами митної території України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 558-р ( 558-2008-р ) від 02.04.2008 }

1. Відповідно до статті 240 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити строк виконання робіт з ремонту та відновлення верстатів за кодами згідно з УКТЗЕД 8460 21 90 00, 8457 10 10 00 ( 2371г-14 ) за межами митної території України 230 днів.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 558-р ( 558-2008-р ) від 02.04.2008 }

2. Це розпорядження набирає чинності з дня опублікування.
