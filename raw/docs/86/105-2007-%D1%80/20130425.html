КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 березня 2007 р. N 105-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання робіт з ремонту та відновлення верстатів за межами митної території України

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 558-р ( 558-2008-р ) від 02.04.2008 N 87-р ( 87-2010-р ) від 13.01.2010 }

1. Відповідно до статті 240 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити строк виконання робіт з ремонту та відновлення верстатів за кодами згідно з УКТЗЕД 8460 21 90 00, 8457 10 10 00 ( 2371г-14 ) за межами митної території України 270 днів.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 558-р ( 558-2008-р ) від 02.04.2008, N 87-р ( 87-2010-р ) від 13.01.2010 }

2. Це розпорядження набирає чинності з дня опублікування.
