Про Спеціальну комісію з перевірки достовірності інформації про розрахунки підприємств паливно-енергетичного комплексу з постачальниками енергоносіїв, бюджетом та позабюджетними фондами

Стан: Втратив чинність

Ідентифікатор: 312/2000-рп

Текст документа від 13.11.2001:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про Спеціальну комісію з перевірки достовірності інформації про розрахунки підприємств паливно-енергетичного комплексу з постачальниками енергоносіїв, бюджетом та позабюджетними фондами

З метою з'ясування об'єктивності інформації про стан розрахунків підприємств паливно-енергетичного комплексу з постачальниками енергоносіїв, бюджетом та позабюджетними фондами:

1. Утворити Спеціальну комісію з перевірки достовірності інформації про розрахунки підприємств паливно-енергетичного комплексу з постачальниками енергоносіїв, бюджетом та позабюджетними фондами (далі - Комісія).

2. Затвердити персональний склад Комісії (додається).

Призначити головою Комісії Секретаря Ради національної безпеки і оборони України МАРЧУКА Євгена Кириловича.

3. Надати голові Комісії право залучати до роботи фахівців центральних і місцевих органів виконавчої влади, підприємств, установ та організацій (за погодженням з їх керівниками), одержувати інформацію, документи та матеріали, необхідні для роботи Комісії.

4. Комісії провести у тижневий строк міжвідомчі звірки даних про розрахунки підприємств паливно-енергетичного комплексу з постачальниками енергоносіїв, бюджетом та позабюджетними фондами, проаналізувати стан розрахунків і платіжної дисципліни у паливно-енергетичному комплексі, в разі необхідності провести в установленому порядку службові розслідування за фактами виявлених порушень.

5. Голові Комісії Є. Марчуку доповісти до 1 листопада 2000 року про результати роботи Комісії Президентові України, Голові Верховної Ради України, Прем'єр-міністрові України.
