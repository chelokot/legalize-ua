Кабінет Міністрів України; Розпорядження від 12.09.2005 № 394-р

Питання щодо тимчасового перебування в Україні осіб, змушених залишити місця постійного проживання в Абхазії (Грузія)

Стан: Чинний

Ідентифікатор: 394-2005-р

Текст документа від 17.06.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 вересня 2005 р. N 394-р Київ

Питання щодо тимчасового перебування в Україні осіб, змушених залишити місця постійного проживання в Абхазії (Грузія)

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 250-р ( 250-2006-р ) від 27.04.2006 N 484-р ( 484-2007-р ) від 26.06.2007 N 648-р ( 648-2009-р ) від 17.06.2009 }

Погодитися з пропозицією Мін'юсту стосовно продовження до 1 березня 2010 р. строку дії тимчасових довідок, виданих відповідно до постанови Кабінету Міністрів України від 26 червня 1996 р. N 674 ( 674-96-п ) "Про заходи щодо надання допомоги особам, які змушені були залишити місця постійного проживання в Автономній Республіці Абхазія Грузії та прибули в Україну" - із змінами, внесеними постановою Кабінету Міністрів України від 10 грудня 1998 р. N 1942 ( 1942-98-п ).

{ Розпорядження із змінами, внесеними згідно з Розпорядженнями КМ N 250-р ( 250-2006-р ) від 27.04.2006, N 484-р ( 484-2007-р ) від 26.06.2007, N 648-р ( 648-2009-р ) від 17.06.2009 }
