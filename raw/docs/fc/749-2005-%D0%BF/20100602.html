ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 18 серпня 2005 р. N 749

ПОРЯДОК використання коштів, передбачених у державному бюджеті для реструктуризації вугільної та торфодобувної промисловості

1. Цей Порядок визначає напрями використання коштів, передбачених у державному бюджеті за програмою "Реструктуризація вугільної та торфодобувної промисловості, в тому числі погашення заборгованості за спожиту у минулих роках електричну енергію державними вугледобувними підприємствами, на яких здійснюються заходи з підготовки до ліквідації, у сумі 420473,6 тис.грн. (далі - бюджетні кошти).

{ Пункт 1 в редакції Постанови КМ N 192 ( 192-2009-п ) від 05.03.2009; із змінами, внесеними згідно з Постановою КМ N 1379 ( 1379-2009-п ) від 23.12.2009 }

2. Бюджетні кошти використовуються для:

підготовки вугледобувних підприємств до ліквідації (підготовка до передачі чи списання запасів вугілля, інших корисних копалин, гірничих виробок, обладнання та устатковання, що не потрібні для виконання робіт, пов'язаних з фізичною ліквідацією вугледобувного підприємства; скорочення чисельності працівників; погашення заборгованості з виплати працівникам заробітної плати та інших соціальних виплат з відшкодування шкоди, заподіяної їх здоров'ю під час виконання трудових обов'язків; безоплатне забезпечення побутовим вугіллям; оформлення державних актів на володіння або користування земельними ділянками; охорона довкілля та запобігання небезпечному впливу на діючі підприємства, будівлі, споруди, стан довкілля та здоров'я людей); { Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 720 ( 720-2006-п ) від 25.05.2006 }

ліквідації вугледобувних, вуглепереробних та торфодобувних підприємств (фізична ліквідація зазначених підприємств, охорона довкілля, забезпечення гідроекологічної безпеки діючих підприємств та прилеглих територій; подолання негативних соціально-економічних наслідків відповідно до затверджених в установленому порядку проектів їх ліквідації);

{ Абзац четвертий пункту 2 виключено на підставі Постанови КМ N 192 ( 192-2009-п ) від 05.03.2009 }

погашення заборгованості за спожиту у минулих роках електричну енергію державними вугледобувними підприємствами, на яких здійснюються заходи з підготовки до ліквідації (далі - вугледобувні підприємства). { Пункт 2 доповнено абзацом згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009 }

Видатки на придбання побутового палива для осіб, які мають таке право відповідно до статті 48 Гірничого Закону України ( 1127-14 ) у сумі 182,667 млн. гривень, та капітального характеру здійснюються у 2009 році за рахунок коштів Стабілізаційного фонду, передбачених пунктом 3 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) відповідно до проектів ліквідації шахт для фінансування робіт, пов'язаних з гідроекологічною безпекою сусідніх шахт, що діють, і охороною навколишнього природного середовища, з розроблення таких проектів за переліком, що затверджується Кабінетом Міністрів України. { Пункт 2 доповнено абзацом згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009; із змінами, внесеними згідно з Постановою КМ N 201 ( 201-2009-п ) від 16.03.2009, N 1396 ( 1396-2009-п ) від 16.12.2009 }

Перелік повинен містити такі відомості: { Пункт 2 доповнено абзацом згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009 }

назва проекту ліквідації та напрями використання коштів; { Пункт 2 доповнено абзацом згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009 }

дата початку виконання робіт, передбачених проектом; { Пункт 2 доповнено абзацом згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009 }

загальна кошторисна вартість проекту, зокрема вартість робіт капітального характеру; { Пункт 2 доповнено абзацом згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009 }

залишкова вартість проекту станом на 1 січня 2009 р., зокрема робіт капітального характеру; { Пункт 2 доповнено абзацом згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009 }

вартість робіт капітального характеру за проектом, що підлягають виконанню у 2009 році, і обсяг їх бюджетного фінансування. { Пункт 2 доповнено абзацом згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009 }

3. Головний розпорядник бюджетних коштів спрямовує бюджетні кошти підприємствам, на які покладені функції замовника з виконання робіт і здійснення заходів з ліквідації вугледобувних, вуглепереробних та торфодобувних підприємств, забезпечення гідроекологічної безпеки діючих підприємств та прилеглих територій, і вугледобувним підприємствам, які повинні бути підготовлені до ліквідації, а також вугледобувним підприємствам, які здійснюють розрахунки, пов'язані з погашенням заборгованості за спожиту у минулих роках електричну енергію.

{ Пункт 3 із змінами, внесеними згідно з Постановами КМ N 448 ( 448-2007-п ) від 14.03.2007, N 192 ( 192-2009-п ) від 05.03.2009 }

4. Обсяги та напрями використання бюджетних коштів для виконання робіт і здійснення заходів з ліквідації вугледобувних, вуглепереробних та торфодобувних підприємств визначаються головним розпорядником на підставі поданих підприємствами-замовниками матеріалів у розрізі підприємств, що ліквідуються, а також кошторису витрат і переліку робіт, передбачених проектами ліквідації зазначених підприємств, титулів будов (об'єктів), затверджених головним розпорядником бюджетних коштів, та з урахуванням потреби у першочерговому виконанні ліквідаційних робіт.

Обсяг фінансування об'єктів, що використовуються для забезпечення гідроекологічної безпеки діючих підприємств та прилеглих територій, будівництво і реконструкція яких передбачена проектами ліквідації вугледобувних підприємств з метою запобігання підтопленню діючих підприємств та негативному впливу на довкілля, визначається відповідно до цих проектів.

Обсяг фінансування вугледобувних підприємств, які повинні бути підготовлені до ліквідації, визначається на підставі поданих ними матеріалів і кошторису витрат із застосуванням галузевих нормативів та з урахуванням потреби у здійсненні заходів з підготовки підприємств до ліквідації і затверджується наказом головного розпорядника бюджетних коштів.

{ Абзац четвертий пункту 4 виключено на підставі Постанови КМ N 192 ( 192-2009-п ) від 05.03.2009 }

4-1. Вугледобувні підприємства та енергопостачальники складають і подають Мінвуглепрому:

до 1 березня акти звіряння заборгованості за спожиту в минулих періодах електричну енергію станом на 1 січня 2009 р., яка підлягає погашенню за рахунок 160000 тис. гривень нарахованих та несплачених зобов'язань державного підприємства "Енергоринок" перед державним бюджетом із збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію за минулі роки;

до 24 грудня акти звіряння такої заборгованості станом на 1 грудня 2009 р., яка підлягає погашенню за рахунок невикористаного залишку коштів у сумі 260473,6 тис. гривень, джерелом формування яких були надходження зазначеного збору.

{ Порядок доповнено пунктом 4-1 згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009; в редакції Постанови КМ N 1379 ( 1379-2009-п ) від 23.12.2009 }

4-2. Мінвуглепром:

формує реєстр актів звіряння заборгованості вугледобувних підприємств за спожиту у минулих періодах електричну енергію, який є підставою для проведення розподілу бюджетних коштів. У реєстрі зазначається загальний обсяг заборгованості кожного вугледобувного підприємства і обсяг заборгованості, що підлягає погашенню у 2009 році, зокрема за рахунок 160000 тис. гривень нарахованих та несплачених зобов'язань державного підприємства "Енергоринок" перед державним бюджетом із збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію за минулі роки та за рахунок невикористаного залишку коштів у сумі 260473,6 тис. гривень, джерелом формування яких були надходження від сплати зазначеного збору;

подає відповідно до 20 березня 2009 р. та 25 грудня 2009 р. реєстр актів звіряння заборгованості вугледобувних підприємств за спожиту у минулих періодах електричну енергію Державному казначейству та інформує вугледобувні підприємства про заплановані обсяги фінансування, пов'язаного з погашенням заборгованості, у межах видатків державного бюджету за джерелами.

{ Порядок доповнено пунктом 4-2 згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009; в редакції Постанови КМ N 1379 ( 1379-2009-п ) від 23.12.2009 }

4-3. Розрахунки проводяться за рахунок 160000 тис. гривень нарахованих та несплачених зобов'язань державного підприємства "Енергоринок" перед державним бюджетом із збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію за минулі роки та за рахунок невикористаного залишку коштів у сумі 260473,6 тис. гривень, джерелом формування яких були надходження від сплати зазначеного збору, на підставі укладених договорів між вугледобувними підприємствами і енергопостачальниками у межах обсягів, визначених у реєстрі актів звіряння заборгованості вугледобувних підприємств за спожиту у минулих періодах електричну енергію. Примірний договір затверджує Державне казначейство за погодженням з Мінвуглепромом.

Енергопостачальники подають щомісяця до 23 числа копії договорів Мінвуглепрому, який формує зведений реєстр таких договорів, подає його щомісяця до 25 числа Державному казначейству разом з їх копіями та повідомляє протягом трьох днів Державному казначейству про обсяг проведених розрахунків.

Перерахування бюджетних коштів здійснюється з єдиного казначейського рахунка у порядку, встановленому Державним казначейством за погодженням з Мінфіном.

Для проведення розрахунків усі їх учасники, крім енергопостачальників та державного підприємства "Енергоринок", відкривають рахунки в органах Державного казначейства.

Енергопостачальники та державне підприємство "Енергоринок" проводять розрахунки за спожиту електричну енергію через відкриті в установах уповноваженого банку поточні рахунки із спеціальним режимом використання.

Мінвуглепром перераховує бюджетні кошти в обсязі:

160000 тис. гривень - на рахунки вугледобувних підприємств, відкриті в органах Державного казначейства, для перерахування на поточні рахунки із спеціальним режимом використання енергопостачальників з метою проведення розрахунків відповідно до договорів з державним підприємством "Енергоринок", яке перераховує зазначені кошти до державного бюджету як збір у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію. При цьому у графі платіжного доручення "Призначення платежу" додатково зазначається "Пункт 5 статті 6 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 );

260473,6 тис. гривень - на рахунки вугледобувних підприємств, відкриті в органах Державного казначейства, для перерахування на поточні рахунки із спеціальним режимом використання енергопостачальників. Енергопостачальники проводять розрахунки відповідно до договорів з державним підприємством "Енергоринок", яке перераховує зазначені кошти на погашення заборгованості перед енергогенеруючими компаніями теплових електростанцій. Енергогенеруючі компанії теплових електростанцій перераховують кошти, що надійшли, у повному обсязі на рахунок державного підприємства "Вугілля України", яке перераховує зазначені кошти у повному обсязі на відкриті в органах Державного казначейства рахунки вугледобувних підприємств за поставлене ними вугілля. Під час здійснення платежів усіма учасниками розрахунків у графі платіжного доручення "Призначення платежу" додатково зазначається "Пункт 7 статті 20 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ).

{ Порядок доповнено пунктом 4-3 згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009; в редакції Постанови КМ N 1379 ( 1379-2009-п ) від 23.12.2009 }

4-4. Кошти Стабілізаційного фонду, не використані станом на 27 грудня бюджетного року, підлягають поверненню до 31 грудня до спеціального фонду державного бюджету.

{ Порядок доповнено пунктом 4-4 згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009 }

4-5. Мінвуглепром щомісяця до 20 числа наступного періоду подає Мінфіну звіт про використання коштів Стабілізаційного фонду за затвердженою ним формою.

{ Порядок доповнено пунктом 4-5 згідно з Постановою КМ N 192 ( 192-2009-п ) від 05.03.2009 }

5. Звітність про використання бюджетних коштів подається Мінфіну та Державному казначейству в установленому порядку.
