Про внесення зміни до Мережі та кількісного складу суддів місцевих судів

Стан: Втратив чинність

Ідентифікатор: 576/2007

Текст документа від 27.06.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення зміни до Мережі та кількісного складу суддів місцевих судів

Внести зміну до розділу "Донецька область" Мережі та кількісного складу суддів місцевих судів, затвердженої Указом Президента України від 20 серпня 2001 року N 641 ( 641/2001 ) (зі змінами, внесеними Указами від 22 жовтня 2002 року N 938 ( 938/2002 ), від 15 березня 2004 року N 328 ( 328/2004 ), від 15 січня 2005 року N 36 ( 36/2005 ), від 31 серпня 2006 року N 729 ( 729/2006 ) та від 16 січня 2007 року N 20) ( 20/2007 ), замінивши у пункті 31 цифри "16" цифрами "18".

Президент України В.ЮЩЕНКО

м. Київ, 27 червня 2007 року N 576/2007
