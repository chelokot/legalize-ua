ПОСТАНОВА від 28 листопада 2011 р. N 1207 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 85 ( 85-2014-п ) від 05.04.2014 }

Деякі питання Міністерства аграрної політики та продовольства

Кабінет Міністрів України постановляє:

1. У додатку до постанови Кабінету Міністрів України від 7 вересня 2011 р. N 937 ( 937-2011-п ) "Про затвердження граничної чисельності працівників апарату центральних органів виконавчої влади" (Офіційний вісник України, 2011 р., N 69, ст. 2623) у позиції "Мінагрополітики" цифри "377" і "372" замінити відповідно цифрами "397" і "392".

2. Міністерству фінансів під час доопрацювання проекту Державного бюджету України на 2012 рік передбачити видатки на утримання додаткової чисельності працівників Міністерства аграрної політики та продовольства.
