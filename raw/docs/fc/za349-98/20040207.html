Стан: Втратив чинність

Текст документа від 07.02.2004:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 174 від 05.05.98 Зареєстровано в Міністерстві м.Київ юстиції України 27 травня 1998 р. за N 349/2789

( Постанова втратила чинність на підставі Постанови Національного банку N 4 ( za113-04 ) від 12.01.2004 )

Про внесення змін і доповнень до Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик

У зв'язку з переходом Національного банку України та комерційних банків з 1 січня 1998 року на новий План рахунків бухгалтерського обліку ( va493500-97 ) Правління ПОСТАНОВЛЯЄ:

1. Внести зміни і доповнення до Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик, затвердженого постановою Правління Національного банку України від 23.07.97 N 246 ( za373-97 ) і наказом Міністерства фінансів України від 10.07.97 N 149 ( z0373-97 ) та зареєстрованого в Міністерстві юстиції України 02.09.97 за N 373/2177 (додаються).

2. Емісійно-кредитному департаменту (Н.І.Гребеник) після реєстрації Міністерством юстиції України змін і доповнень до Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик надіслати їх Кримському республіканському, обласним та по м.Києву і Київській області управлінням Національного банку України, а також комерційним банкам для керівництва і використання в роботі.

3. Контроль за виконанням цієї постанови покласти на першого заступника Голови Правління В.С.Стельмаха.

Голова В.А.Ющенко

Затверджено наказ Міністерства фінансів України 08.05.98 N 111 ( z0349-98 )

постанова Правління Національного банку України 05.05.98 N 174

Зміни і доповнення до Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик ( z0373-97 )

У пунктах 3.5, 3.6, 3.9, 5.6 замість рахунку N 076 "Дебітори і кредитори банку за операціями клієнтів у вільно конвертованій валюті" ввести новий мультивалютний рахунок N 2901 "Кредиторська заборгованість за розрахунками за цінними паперами для клієнтів".

У пунктах 3.6, 3.7, 3.8, 5.4, 5.6 замість рахунку N 903 "Дебітори і кредитори банку за операціями з клієнтами" ввести новий мультивалютний рахунок N 2901 "Кредиторська заборгованість за розрахунками за цінними паперами для клієнтів".
