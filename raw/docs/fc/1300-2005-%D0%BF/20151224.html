{ Постанова втратила чинність на підставі Постанови КМ N 1015 ( 1015-2015-п ) від 09.12.2015 }

Про внесення зміни до пункту 2 Порядку здійснення нагляду за забезпеченням безпеки руху на транспорті

Кабінет Міністрів України постановляє:

Пункт 2 Порядку здійснення нагляду за забезпеченням безпеки руху на транспорті, затвердженого постановою Кабінету Міністрів України від 4 березня 1997 р. N 204 ( 204-97-п ) (Офіційний вісник України, 1997 р., число 11, с. 85; 1998 р., N 52, ст. 1953; 2003 р., N 37, ст. 1981; 2004 р., N 52, ст. 3452), викласти у такій редакції:

"2. Нагляд здійснюється за видами транспорту Мінтрансзв'язку, Мінбудом, Державіаслужбою, Головавтотрансінспекцією, Держфлотінспекцією, Укрзалізницею та їх органами на місцях у взаємодії з іншими державними органами (Державна автомобільна інспекція МВС, Державний департамент промислової безпеки, охорони праці та гірничого нагляду тощо)".

Прем'єр-міністр України Ю.ЄХАНУРОВ
