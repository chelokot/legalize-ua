Про внесення змін до деяких наказів ДПА України

Відповідно до статті 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ) та пунктів 16.4, 16.15 статті 16 Закону України "Про оподаткування прибутку підприємств" ( 334/94-ВР ) НАКАЗУЮ:

1. Затвердити Зміни до форми розрахунку податкових зобов'язань щодо сплати консолідованого податку на прибуток підприємства та Порядку складання розрахунку податкових зобов'язань щодо сплати консолідованого податку на прибуток підприємства, затверджених наказом Державної податкової адміністрації України від 10.02.2003 N 68 ( z0182-03 ), зареєстрованим у Міністерстві юстиції України 05.03.2003 за N 182/7503, що додаються.

2. Затвердити Зміни до форми декларації з податку на доходи (прибуток) страховика та Порядку складання декларації з податку на доходи (прибуток) страховика ( z0432-06 ), затверджених наказом Державної податкової адміністрації України від 31.03.2003 N 146 ( z0280-03 ), зареєстрованим у Міністерстві юстиції України 10.04.2003 за N 280/7601, що додаються.

3. Затвердити Зміни до Порядку складання розрахунку податку на прибуток нерезидента, що проводить діяльність на території України через постійне представництво ( z0433-06 ), затвердженого наказом Державної податкової адміністрації України від 31.07.97 N 274 ( z0352-97 ), зареєстрованого у Міністерстві юстиції України 28.08.97 за N 352/2156, що додаються.

4. Затвердити Зміни до Порядку складання податкового звіту про використання коштів неприбутковими установами й організаціями ( z0434-06 ), затвердженого наказом ДПА України від 11.07.97 N 233 ( z0290-97 ), зареєстрованого у Міністерстві юстиції України 06.08.97 за N 290/2094, що додаються.

5. Затвердити Зміни до Порядку ведення і складання податкового звіту про прибуток, що звільняється від оподаткування, підприємств та організацій громадських організацій інвалідів, майно яких є їх власністю, отриманий від продажу товарів (робіт, послуг), крім підакцизних товарів та прибутку, одержаного від грального бізнесу ( z0435-06 ), затвердженого наказом ДПА України від 30.07.97 N 270 ( z0315-97 ), зареєстрованого у Міністерстві юстиції України 15.08.97 за N 315/2119, що додаються.

6. Затвердити Зміни до Порядку складання декларації з податку на прибуток банку ( z0436-06 ), затвердженого наказом ДПА України від 31.03.2003 N 148 ( z0281-03 ), зареєстрованого у Міністерстві юстиції України 10.04.2003 за N 281/7602, що додаються.

7. Департаменту податку на прибуток та інших податків і зборів (обов'язкових платежів) подати цей наказ до Міністерства юстиції України для державної реєстрації.

8. Контроль за виконанням цього наказу покласти на першого заступника Голови Оперенка Г.М.
