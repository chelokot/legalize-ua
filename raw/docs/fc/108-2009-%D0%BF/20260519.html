КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 лютого 2009 р. N 108 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 620 ( 620-2026-п ) від 13.05.2026 }

Про внесення змін до постанови Кабінету Міністрів України від 23 квітня 2008 р. N 413

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 23 квітня 2008 р. N 413 ( 413-2008-п ) "Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для здійснення протиепізоотичних заходів, та переліку послуг спеціалістів ветеринарної медицини, які провадять ветеринарну практику, за здійснення обов'язкових або необхідних протиепізоотичних заходів та розмірів їх оплати" (Офіційний вісник України, 2008 р., N 33, ст. 1094) зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 22

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 18 лютого 2009 р. N 108

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 23 квітня 2008 р. N 413 ( 413-2008-п )

1. У назві та абзаці другому постановляючої частини постанови ( 413-2008-п ) слова і цифри "у 2008 році" виключити.

2. У Порядку використання у 2008 році коштів, передбачених у державному бюджеті для здійснення протиепізоотичних заходів, затвердженому цією постановою ( 413-2008-п ):

у назві слова і цифри "у 2008 році" виключити;

доповнити абзац перший пункту 1 після слова "визначає" словами і цифрами "з урахуванням статей 98 і 99 Закону України "Про ветеринарну медицину" ( 2498-12 );

у підпункті 5 пункту 2 слова "ветеринарних препаратів" замінити словами "дослідження ветеринарних препаратів, кормів та кормових добавок і методів контролю їх безпечності та якості".

3. У додатку 1 до Порядку ( 413-2008-п ):

позицію "Диктіокаульоз" виключити;

доповнити додаток такими позиціями:

"Емкар

Міксоматоз

Хламідіоз

Геморагічна хвороба кролів

Пастерельоз великої рогатої худоби

Сальмонельоз".

4. Перелік послуг спеціалістів ветеринарної медицини, які провадять ветеринарну практику, за здійснення обов'язкових або необхідних протиепізоотичних заходів та розміри їх оплати, затверджені зазначеною постановою ( 413-2008-п ), викласти у такій редакції:

"ПЕРЕЛІК послуг спеціалістів ветеринарної медицини, які провадять ветеринарну практику, за здійснення обов'язкових або необхідних протиепізоотичних заходів та розміри їх оплати
