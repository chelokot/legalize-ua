Верховна Рада України; Постанова від 23.02.2007 № 715-V

Про визнання такими, що втратили чинність, деяких постанов Верховної Ради України та зняття з розгляду деяких проектів постанов Верховної Ради України щодо проведення у Верховній Раді України "Дня Уряду України"

Стан: Чинний

Ідентифікатор: 715-16

Текст документа від 23.02.2007:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про визнання такими, що втратили чинність, деяких постанов Верховної Ради України та зняття з розгляду деяких проектів постанов Верховної Ради України щодо проведення у Верховній Раді України "Дня Уряду України"

( Відомості Верховної Ради України (ВВР), 2007, N 16, ст.235 )

У зв'язку з набранням чинності Законом України "Про Кабінет Міністрів України" ( 514-16 ) та відповідно до частини другої статті 48 Регламенту Верховної Ради України ( 3547-15 ) Верховна Рада України постановляє:

1. Взяти до відома, що у дні пленарних засідань Верховної Ради України щотижня відводиться час для запитань членам Кабінету Міністрів України (година запитань до Уряду України).

2. Доручити Комітету Верховної Ради України з питань Регламенту, депутатської етики та забезпечення діяльності Верховної Ради України підготувати проект постанови Верховної Ради України про внесення змін до Регламенту Верховної Ради України ( 3547-15 ) щодо порядку проведення години запитань до Уряду України.

3. Визнати такими, що втратили чинність:

Постанову Верховної Ради України від 21 вересня 2006 року "Про "День Уряду України" у грудні 2006 року (з порядком денним "Про захист прав онкологічних хворих в Україні та виконання державної програми "Онкологія")" ( 179-16 ) (Відомості Верховної Ради України, 2006 р., N 43, ст. 429, N 50, ст. 505);

Постанову Верховної Ради України від 2 листопада 2006 року "Про "День Уряду України" у березні 2007 року (з порядком денним "Про стан виконання Плану дій "Україна - ЄС")" ( 303-16 ) (Відомості Верховної Ради України, 2006 р., N 50, ст. 516);

Постанову Верховної Ради України від 14 грудня 2006 року "Про "День Уряду України" у квітні 2007 року" ( 457-16 ) (Відомості Верховної Ради України, 2007 р., N 4, ст. 45);

Постанову Верховної Ради України від 14 грудня 2006 року "Про "День Уряду України" у квітні 2007 року" ( 456-16 ) (Відомості Верховної Ради України, 2007 р., N 5-6, ст. 65).

4. Зняти з розгляду:

проект Постанови Верховної Ради України "Про "День Уряду України" у червні 2007 року (з порядком денним "Про дотримання Кабінетом Міністрів України, органами місцевого самоврядування вимог законодавства щодо надання санаторно-курортних послуг населенню та раціонального використання природних лікувальних ресурсів України")" (реєстр. N 3093);

проект Постанови Верховної Ради України "Про "День Уряду України" у червні 2007 року (з порядком денним "Про стан виконання державних зобов'язань по відновленню знецінених заощаджень громадян України та страхових внесків")" (реєстр. N 3146).
