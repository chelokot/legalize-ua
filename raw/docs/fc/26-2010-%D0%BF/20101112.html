Про затвердження нового складу наглядових рад Національної кіностудії художніх фільмів імені Олександра Довженка та Національної кінематеки України

Стан: Втратив чинність

Ідентифікатор: 26-2010-п

Текст документа від 12.11.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 січня 2010 р. N 26 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1008 ( 1008-2010-п ) від 03.11.2010 }

Про затвердження нового складу наглядових рад Національної кіностудії художніх фільмів імені Олександра Довженка та Національної кінематеки України

Кабінет Міністрів України постановляє:

1. На часткову зміну постанови Кабінету Міністрів України від 2 серпня 1996 р. N 913 ( 913-96-п ) затвердити новий склад наглядових рад Національної кіностудії художніх фільмів імені Олександра Довженка та Національної кінематеки України, що додаються.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 21 січня 2004 р. N 64 ( 64-2004-п ) "Про затвердження нового складу наглядових рад Національної кіностудії художніх фільмів імені Олександра Довженка та Національної кінематеки України".
