Про розширення складу Міжвідомчої комісії з питань ліцензування використання радіочастот

Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 червня 2002 р. N 724 Київ

( Постанова втратила чинність на підставі Постанов КМ N 753 ( 753-2005-п ) від 18.08.2005 N 788 ( 788-2005-п ) від 20.08.2005 )

Про розширення складу Міжвідомчої комісії з питань ліцензування використання радіочастот

Кабінет Міністрів України постановляє:

Ввести до складу Міжвідомчої комісії з питань ліцензування використання радіочастот, затвердженого постановою Кабінету Міністрів України від 7 лютого 2001 р. N 112 ( 112-2001-п ) "Про порядок надання ліцензій на використання радіочастотного ресурсу України" (Офіційний вісник України, 2001 р., N 6, ст. 230), начальника Департаменту спеціальних телекомунікаційних систем та захисту інформації Служби безпеки.

Прем'єр-міністр України А.КІНАХ
