Текст документа від 01.07.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 лютого 1999 р. N 240 Київ

( Постанова втратила чинність на підставі Постанови КМ N 913 ( 913-2002-п ) від 01.07.2002 )

Про внесення змін до складу президії Вищої атестаційної комісії України

Кабінет Міністрів України постановляє:

1. Ввести до складу президії Вищої атестаційної комісії України, затвердженого постановою Кабінету Міністрів України від 9 листопада 1998 р. N 1757 ( 1757-98-п ):

кандидата фізико-математичних наук, доцента, першого заступника голови Вищої атестаційної комісії України Степка Михайла Филимоновича як першого заступника голови президії Вищої атестаційної комісії України;

кандидата педагогічних наук, доцента, член-кореспондента Академії педагогічних наук, Міністра освіти України Зайчука Валентина Олександровича.

2. Не для друку.
