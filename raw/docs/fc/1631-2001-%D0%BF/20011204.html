КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 грудня 2001 р. N 1631 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про внесення змін до постанови Кабінету Міністрів України від 24 квітня 2000 р. N 692

У зв'язку з ліквідацією Указом Президента України від 13 листопада 2001 р. N 1071 ( 1071/2001 ) Комісії з питань житлової політики при Президентові України Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 24 квітня 2000 р. N 692 ( 692-2000-п ) такі зміни:

у назві постанови ( 692-2000-п ) слова "покладених на Комісію" та "при Президентові України" виключити;

у пункті 1 слова і цифри "З метою утворення групи із забезпечення виконання завдань, покладених на Комісію з питань житлової політики при Президентові України, яка створена відповідно до Указу Президента України від 22 квітня 1999 р. N 423 ( 423/99 )" замінити словами "З метою забезпечення виконання завдань з питань житлової політики".

Прем'єр-міністр України А.КІНАХ
