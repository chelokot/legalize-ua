Кабінет Міністрів України; Розпорядження від 03.08.1998 № 639-р

Про закріплення у державній власності пакету акцій ВАТ "Модуль"

Стан: Втратив чинність

Ідентифікатор: 639-98-р

Текст документа від 27.07.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 серпня 1998 р. N 639-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 739-р ( 739-99-р ) від 27.07.99 )

Відповідно до пункту 14 Державної програми приватизації на 1998 рік ( 124/98-ВР ) закріпити у державній власності на 3 роки пакет акцій у розмірі 25 відсотків статутного фонду плюс одна акція ВАТ "Модуль".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
