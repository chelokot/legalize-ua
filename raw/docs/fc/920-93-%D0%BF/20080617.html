Про призначення уповноваженого Уряду України і його заступників по виконанню Угоди між Урядом України та Урядом Угорської Республіки з питань водного господарства на прикордонних водах

Текст документа від 17.06.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 листопада 1993 р. N 920 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 511 ( 511-2008-п ) від 04.06.2008 }

Про призначення уповноваженого Уряду України і його заступників по виконанню Угоди між Урядом України та Урядом Угорської Республіки з питань водного господарства на прикордонних водах

{ Із змінами, внесеними згідно з Постановами КМ N 1118 ( 1118-98-п ) від 18.07.98 N 989 ( 989-2001-п ) від 09.08.2001 }

Кабінет Міністрів України постановляє:

Призначити:

першого заступника голови Державного комітету по водному господарству Лелявського Віталія Володимировича Уповноваженим Кабінету Міністрів України по виконанню Угоди між Урядом України та Урядом Угорської Республіки з питань водного господарства на прикордонних водах ( 348_059 );

начальника відділу зовнішніх зв'язків Державного комітету по водному господарству Касьянчука Валерія Павловича і директора державного підприємства "Закарпаттяводгосп" цього Комітету Іваницького Ореста Михайловича заступниками уповноваженого Уряду України по виконанню зазначеної Угоди.

( Постанова із змінами, внесеними згідно з Постановами КМ N 1118 ( 1118-98-п ) від 18.07.98, N 989 ( 989-2001-п ) від 09.08.2001 )
