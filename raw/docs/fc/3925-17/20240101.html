Про внесення зміни до статті 40 Закону України "Про страхування"

Стан: Втратив чинність

Ідентифікатор: 3925-17

Текст документа від 01.01.2024:

ЗАКОН УКРАЇНИ

{ Закон втратив чинність на підставі Закону N 1909-IX ( 1909-20 ) від 18.11.2021 }

Про внесення зміни до статті 40 Закону України "Про страхування"

( Відомості Верховної Ради України (ВВР), 2012, N 22, ст.218 )

Верховна Рада України постановляє:

1. Частину третю статті 40 Закону України "Про страхування" ( 85/96-ВР ) (Відомості Верховної Ради України, 2002 р., N 7, ст. 50) доповнити абзацом п'ятим такого змісту:

"центральному органу виконавчої влади з питань фінансового моніторингу відповідно до Закону України "Про запобігання та протидію легалізації (відмиванню) доходів, одержаних злочинним шляхом, або фінансуванню тероризму" ( 249-15 ).

2. Цей Закон набирає чинності з дня, наступного за днем його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 18 жовтня 2011 року N 3925-VI
