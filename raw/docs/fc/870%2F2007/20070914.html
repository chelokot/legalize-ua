Президент України; Указ від 14.09.2007 № 870/2007

Про зупинення дії розпоряджень Кабінету Міністрів України від 10 вересня 2007 року N 706-р, від 11 вересня 2007 року N 710-р

Стан: Втратив чинність

Ідентифікатор: 870/2007

Текст документа від 14.09.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії розпоряджень Кабінету Міністрів України від 10 вересня 2007 року N 706-р, від 11 вересня 2007 року N 710-р

{ Додатково див. Конституційне подання Президента ( n0025100-07 ) від 14.09.2007 }

Кабінетом Міністрів України видано розпорядження від 10 вересня 2007 року N 706-р ( 706-2007-р ) "Про звільнення Склярова О.І. з посади члена Національної комісії з питань регулювання зв'язку України", від 11 вересня 2007 року N 710-р ( 710-2007-р ) "Про призначення Пащука В.П. членом Національної комісії з питань регулювання зв'язку України".

Названими актами ( 706-2007-р, 710-2007-р ) Кабінет Міністрів України прийняв рішення з кадрових питань діяльності Національної комісії з питань регулювання зв'язку України, до компетенції якої віднесено регулювання природних монополій у сфері зв'язку.

Між тим згідно з частиною третьою статті 42 Конституції України ( 254к/96-ВР ) види і межі монополії визначаються законом. Особливості правового регулювання зазначених питань передбачено Законами України "Про природні монополії" ( 1682-14 ) та "Про телекомунікації" ( 1280-15 ). Відповідно до статті 4 Закону України "Про природні монополії" ( 1682-14 ) Національна комісія з питань регулювання зв'язку України є органом регулювання у сфері зв'язку. Згідно зі статтею 20 Закону України "Про телекомунікації" ( 1280-15 ) членів Національної комісії з питань регулювання зв'язку призначає за поданням Прем'єр-міністра України на посади та припиняє їх повноваження на цих посадах Президент України.

Конституційним обов'язком Президента України є забезпечення національної безпеки, складовою якої є економічна та інформаційна безпека держави, та здійснення керівництва у цій сфері (стаття 17, пункти 1 і 17 частини першої статті 106 Конституції України) ( 254к/96-ВР ).

Ураховуючи, що створення ефективного механізму державного регулювання природних монополій за статтею 8 Закону України "Про основи національної безпеки України" ( 964-15 ) є одним із основних напрямів державної політики з питань національної безпеки України в економічній сфері, зазначені акти Кабінету Міністрів України ( 706-2007-р, 710-2007-р ) не відповідають статтям 17, 42, пункту 1 і 17 частини першої статті 106 Конституції України ( 254к/96-ВР ), Законам України "Про природні монополії" ( 1682-14 ) та "Про телекомунікації" ( 1280-15 ).

Крім того, названі акти Кабінету Міністрів України не відповідають і частині другій статті 8 Конституції України ( 254к/96-ВР ), згідно з якою нормативно-правові акти мають прийматися на основі Конституції України ( 254к/96-ВР ) і відповідати їй, а також частині другій статті 6 та частині другій статті 19 Основного Закону ( 254к/96-ВР ) держави, за якими органи державної влади зобов'язані діяти лише в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України.

З огляду на викладене відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію:

розпорядження Кабінету Міністрів України від 10 вересня 2007 року N 706-р ( 706-2007-р ) "Про звільнення Склярова О.І. з посади члена Національної комісії з питань регулювання зв'язку України";

розпорядження Кабінету Міністрів України від 11 вересня 2007 року N 710-р ( 710-2007-р ) "Про призначення Пащука В.П. членом Національної комісії з питань регулювання зв'язку України".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
