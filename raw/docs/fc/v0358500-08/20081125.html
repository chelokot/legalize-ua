{ Постанова втратила чинність на підставі Постанови Національного банку N 395 ( v0395500-08 ) від 25.11.2008 }

Про внесення змін до постанови Правління Національного банку України від 21.04.2008 N 107

Відповідно до статей 15, 25 Закону України "Про Національний банк України" ( 679-14 ) та з метою удосконалення механізмів регулювання грошово-кредитного ринку Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Унести до постанови Правління Національного банку України від 21.04.2008 N 107 ( v0107500-08 ) "Про регулювання грошово-кредитного ринку" такі зміни:

1.1. Пункт 2 викласти в такій редакції:

"Призупинити дію абзацу другого пункту 4 постанови Правління Національного банку України від 14.11.2006 N 434 ( v0434500-06 ) "Про терміни та можливі обсяги проведення Національним банком України окремих операцій з банками, передбачених у Положенні про регулювання Національним банком України ліквідності банків України, та вимоги щодо забезпечення, що пропонується банками" (зі змінами)".

1.2. У пункті 3 слова "До кінця 2008 року" замінити словами "На час призупинення дії абзацу другого пункту 4 постанови Правління Національного банку України від 14.11.2006 N 434 ( v0434500-06 )".

2. Департаменту монетарної політики (Н.І.Гребеник) довести зміст цієї постанови до відома Операційного і територіальних управлінь Національного банку України, Центральної розрахункової палати, Департаменту інформатизації, Департаменту з управління валютним резервом та здійснення операцій на відкритому ринку, Департаменту нормативно-методологічного забезпечення банківського регулювання та нагляду, Управління контролю ризиків і банків України для використання в роботі.

3. Постанова набирає чинності з дня її підписання.

4. Контроль за виконанням цієї постанови покласти на першого заступника Голови А.В.Шаповалова.

Голова В.С.Стельмах
