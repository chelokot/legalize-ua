Про затвердження Порядку контролю за дотриманням Ліцензійних умов провадження професійної діяльності на ринку цінних паперів

Реєстрація: Мін'юст України від 12.05.2003 № 358/7679

Стан: Втратив чинність

Ідентифікатор: z0358-03

Текст документа від 26.06.2009:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ПИТАНЬ РЕГУЛЯТОРНОЇ ПОЛІТИКИ ТА ПІДПРИЄМНИЦТВА

НАКАЗ

21.04.2003 N 52

Зареєстровано в Міністерстві юстиції України 12 травня 2003 р. за N 358/7679

{ Наказ втратив чинність на підставі Наказу Державного комітету України з питань регуляторної політики та підприємництва N 55 ( z0465-09 ) від 17.03.2009 }

Про затвердження Порядку контролю за дотриманням Ліцензійних умов провадження професійної діяльності на ринку цінних паперів

На виконання вимог Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ), Указу Президента України від 25 травня 2000 року N 721 ( 721/2000 ) "Питання Державного комітету України з питань регуляторної політики та підприємництва" і постанови Кабінету Міністрів України від 14 листопада 2000 року N 1698 ( 1698-2000-п ) "Про затвердження переліку органів ліцензування" НАКАЗУЮ:

1. Затвердити Порядок контролю за дотриманням Ліцензійних умов провадження професійної діяльності на ринку цінних паперів ( zb358-03 ) (додається). ( Додатково див. ( za358-03 ).

2. Департаменту контролю та дозвільної системи (Апатенко О.П.) в установленому порядку забезпечити подання цього наказу на державну реєстрацію в Міністерство юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Голови Третьякова С.І.
