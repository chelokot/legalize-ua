Про внесення змін до постанов Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 та від 26 листопада 2008 р. N 1036

{ Із змінами, внесеними згідно з Постановою КМ N 324 ( 324-2010-п ) від 28.04.2010 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752, N 44, ст. 2946, N 51, ст. 3406; 2007 р., N 43, ст. 1715, N 53, ст. 2157, N 56, ст. 2252, N 59, ст. 2344, N 91, ст. 3336; 2008 р., N 9, ст. 220, N 63, ст. 2146, N 69, ст. 2322, N 70, ст. 2355, N 81, ст. 2737, N 90, ст. 3004, N 95, ст. 3142; 2009 р., N 5, ст. 128, N 43, ст. 1442, N 46, ст. 1550, N 52, ст. 1794, N 79, ст. 2679, N 97, ст. 3362, N 99, ст. 3423) та від 26 листопада 2008 р. N 1036 ( 1036-2008-п ) "Деякі питання організації бюджетного процесу" (Офіційний вісник України, 2008 р., N 92, ст. 3053, N 95, ст. 3133, N 98, ст. 3244, N 100, ст. 3328; 2009 р., N 7, ст. 218, N 11, ст. 338, N 20, ст. 633, N 42, ст. 1407, N 50, ст. 1708, N 58, ст. 2033, N 66, ст. 2282, N 85, ст. 2865, N 99, ст. 3423) зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 11 лютого 2010 р. N 120

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) та від 26 листопада 2008 р. N 1036 ( 1036-2008-п )

1. У пункті 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ):

абзац другий підпункту 5 виключити;

підпункт 6 викласти в такій редакції:

"6) на строк не більш як дев'ять місяців:

матеріалів, конструкцій, виробів, необхідних для виконання робіт з будівництва великих і позакласних мостів;

товарів, робіт і послуг, пов'язаних із створенням уніфікованої телекомунікаційної системи диспетчерського контролю та автоматизованого керування гірничими машинами і технологічними комплексами (УТАС) на вугледобувних підприємствах;";

в останньому абзаці слова і цифру "абзацом другим підпункту 5" замінити словами і цифрою "абзацом третім підпункту 6".
