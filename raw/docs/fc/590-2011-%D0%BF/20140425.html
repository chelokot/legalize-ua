Текст документа від 25.04.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 червня 2011 р. N 590 Київ

Про внесення змін до постанов Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 та від 30 травня 2007 р. N 788

{ Із змінами, внесеними згідно з Постановою КМ N 117 ( 117-2014-п ) від 23.04.2014 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752, N 44, ст. 2946, N 51, ст. 3406; 2007 р., N 43, ст. 1715, N 53, ст. 2157, N 56, ст. 2252, N 59, ст. 2344, N 91, ст. 3336; 2008 р., N 9, ст. 220, N 63, ст. 2146, N 69, ст. 2322, N 70, ст. 2355, N 81, ст. 2737, N 90, ст. 3004, N 95, ст. 3142; 2009 р., N 5, ст. 128, N 43, ст. 1442, N 46, ст. 1550, N 52, ст. 1794, N 79, ст. 2679, N 97, ст. 3362, N 99, ст. 3423; 2010 р., N 9, ст. 462, N 39, ст. 1307, N 70, ст. 2529, N 84, ст. 2958, N 90, ст. 3180, N 91, ст. 3222, N 94, ст. 3342, N 100, ст. 3567; 2011 р., N 14, ст. 568) та від 30 травня 2007 р. N 788 ( 788-2007-п ) "Питання здійснення попередньої оплати робіт (послуг) замовниками будівництва великих та позакласних мостів" (Офіційний вісник України, 2007 р., N 41, ст. 1624; 2010 р., N 86, ст. 3017) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ
