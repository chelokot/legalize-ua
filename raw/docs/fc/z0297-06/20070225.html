Про затвердження Змін до Положення про Головне управління юстиції Міністерства юстиції України в Автономній Республіці Крим, обласні, Київське та Севастопольське міські управління юстиції

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 47/5 ( z0124-07 ) від 14.02.2007 }

Відповідно до Положення про Міністерство юстиції України, затвердженого Указом Президента України від 30.12.97 N 1396 ( 1396/97 ) (із змінами), постанови Кабінету Міністрів України від 22.02.94 N 114 ( 114-94-п ) "Про затвердження Положення про Вищу кваліфікаційну комісію нотаріату" (у редакції постанови Кабінету Міністрів України від 14.03.2006 N 281 ( 281-2006-п ) НАКАЗУЮ:

{ Пункт 1 фактично втратив чинність у зв'язку з втратою чинності Положення, затвердженого Наказом Міністерства юстиції N 36/5 ( z0558-00 ) від 30.08.2000, до якого вносились зміни } 1. Затвердити Зміни до Положення про Головне управління юстиції Міністерства юстиції України в Автономній Республіці Крим, обласні, Київське та Севастопольське міські управління юстиції, затвердженого наказом Міністерства юстиції України від 30.08.2000 N 36/5 ( z0558-00 ), зареєстрованого в Мін'юсті України 30.08.2000 за N 558/4779 (із змінами), що додаються.

2. Визнати таким, що втратив чинність, наказ Міністерства юстиції України від 04.03.2005 N 23/5 ( z0286-05 ) "Про внесення змін та доповнень до Положення про порядок реєстрації приватної нотаріальної діяльності", зареєстрований у Міністерстві юстиції України 04.03.2005 за N 286/10566.

3. Департаменту нотаріату та реєстрації адвокатських об'єднань (Н.Круковес):

3.1. Подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами).

3.2. Довести цей наказ до відома начальників Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, обласних, Київського та Севастопольського міських управлінь юстиції та забезпечити належне його виконання.

4. Начальникам управлінь юстиції забезпечити приведення посадових інструкцій працівників і планів роботи у відповідність до цього наказу.

5. Контроль за виконанням цього наказу покласти на першого заступника Міністра юстиції України П.Крупка.

Міністр Сергій Головатий

ЗМІНИ до Положення про Головне управління юстиції Міністерства юстиції України в Автономній Республіці Крим, обласні, Київське та Севастопольське міські управління юстиції ( z0558-00 )

1. Підпункт 30 пункту 4 викласти в такій редакції:

"30) організовує роботу установ нотаріату, перевіряє їх діяльність і вживає заходів до її поліпшення, здійснює контроль за виконанням нотаріусами їх професійних обов'язків, забезпечує роботу кваліфікаційної комісії нотаріату, організовує та забезпечує надання нотаріусами правової допомоги з питань учинення нотаріальних дій".

2. Підпункт 32 пункту 4 вилучити.

3. Підпункт 33 пункту 4 після слів "реєструє приватну нотаріальну діяльність" доповнити словами "осіб, переможців конкурсу на реєстрацію нотаріальної діяльності".

4. Підпункт 35 пункту 4 після слів "готує обґрунтовані подання на розгляд Мін'юсту України" доповнити словами "щодо необхідності заслуховування нотаріуса на засіданні Вищої кваліфікаційної комісії нотаріату або".

5. У підпункті 60 пункту 4 слова "організовує професійне навчання, стажування і підвищення кваліфікації працівників установ нотаріату" замінити словами "організовує професійне навчання, стажування працівників установ нотаріату".

Директор Департаменту нотаріату та реєстрації адвокатських об'єднань Н.В.Круковес
