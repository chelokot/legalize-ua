Про внесення зміни до переліку інвестиційних проектів міжнародних фінансових організацій, для реалізації яких при ввезенні (пересиланні) товарів на митну територію України може видаватися податковий вексель із строком погашення до кінця поточного бюджетного року

Стан: Втратив чинність

Ідентифікатор: 1038-2007-п

Текст документа від 12.01.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 серпня 2007 р. N 1038 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1236 ( 1236-2010-п ) від 27.12.2010 }

Про внесення зміни до переліку інвестиційних проектів міжнародних фінансових організацій, для реалізації яких при ввезенні (пересиланні) товарів на митну територію України може видаватися податковий вексель із строком погашення до кінця поточного бюджетного року

Кабінет Міністрів України постановляє:

1. У переліку інвестиційних проектів міжнародних фінансових організацій, для реалізації яких при ввезенні (пересиланні) товарів на митну територію України може видаватися податковий вексель із строком погашення до кінця поточного бюджетного року, затвердженому постановою Кабінету Міністрів України від 24 жовтня 2001 р. N 1384 ( 1384-2001-п ) "Про внесення зміни до Порядку випуску, обігу та погашення векселів, які видаються на суму податку на додану вартість при ввезенні (пересиланні) товарів на митну територію України" (Офіційний вісник України, 2001 р., N 43, ст. 1928), позицію

"Європейський банк від 9 травня Фінансування Української реконструкції та 1998 р. N 616 енергозберігаючої сервісної розвитку компанії (УкрЕско)"

замінити такою позицією:

"Європейський банк від 21 жовтня Фінансування Української реконструкції та 2005 р. N 33832 енергозберігаючої сервісної розвитку компанії (УкрЕСКО) (друга фаза)".

2. Ця постанова набирає чинності з дня опублікування.
