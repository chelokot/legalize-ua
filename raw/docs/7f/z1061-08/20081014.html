14.10.2008 N 738

Зареєстровано в Міністерстві юстиції України 31 жовтня 2008 р. за N 1061/15752

Про внесення змін до наказу МНС від 17.11.2003 N 441

Відповідно до Закону України "Про аварійно-рятувальні служби" ( 1281-14 ) та Порядку атестації аварійно-рятувальних служб та рятувальників, затвердженого наказом МНС від 19.06.2003 N 201 ( z0640-03 ) і зареєстрованого в Міністерстві юстиції України 24.07.2003 за N 640/7961, НАКАЗУЮ:

1. Внести зміни до Положення про Центральну міжвідомчу атестаційну комісію з атестації аварійно-рятувальних служб та рятувальників, затвердженого наказом МНС від 17.11.2003 N 441 ( z1120-03 ), зареєстрованого в Міністерстві юстиції 04.12.2003 за N 1120/8441 (далі - Положення).

1.1. Викласти абзац перший пункту 1.4. Положення ( z1120-03 ) у новій редакції:

"1.4. Головою ЦМАК призначається заступник Міністра з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи".

2. Державній інспекції цивільного захисту та техногенної безпеки (Стоєцький В.Ф.) та Управлінню правового забезпечення (Сухомлин О.М.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу залишаю за собою.

Міністр В.Шандра
