Текст документа від 22.01.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 квітня 1997 р. N 188-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 34 ( 34-2001-п ) від 22.01.2001 )

Про склад міжвідомчої робочої групи з підготовки проекту закупівлі та впровадження газових лічильників за рахунок коштів кредиту ЄБРР

Для координації робіт з підготовки проекту закупівлі та впровадження газових лічильників за рахунок коштів кредиту Європейського банку реконструкції та розвитку утворити міжвідомчу робочу групу у складі згідно з додатком.

Дозволити голові міжвідомчої групи вносити зміни до її персонального складу.

Визначити Держнафтогазпром відповідальним виконавцем проекту.

Рішення зазначеної міжвідомчої робочої групи, прийняті в межах її компетенції, є обов'язковими для учасників проекту і доводяться до них у вигляді протоколів засідань цієї групи.
