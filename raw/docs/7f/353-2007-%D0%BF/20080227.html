Кабінет Міністрів України; Постанова, Порядок від 01.03.2007 № 353

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для підтримки розвитку інфраструктури наукової діяльності у сфері зв'язку

Стан: Чинний

Ідентифікатор: 353-2007-п

Текст документа від 27.02.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 2007 р. N 353 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для підтримки розвитку інфраструктури наукової діяльності у сфері зв'язку та інформатизації

{ Із змінами, внесеними згідно з Постановою КМ N 106 ( 106-2008-п ) від 27.02.2008 }

{ Установити, що у 2008 році кошти, передбачені у державному бюджеті ( 107-17 ) Міністерству транспорту та зв'язку для підтримки розвитку інфраструктури наукової діяльності у сфері зв'язку та інформатизації, використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 106 ( 106-2008-п ) від 27.02.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для підтримки розвитку інфраструктури наукової діяльності у сфері зв'язку та інформатизації, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 1 березня 2007 р. N 353

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для підтримки розвитку інфраструктури наукової діяльності у сфері зв'язку та інформатизації

Загальні питання

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Мінтрансзв'язку за програмою "Фінансова підтримка розвитку інфраструктури наукової діяльності у сфері зв'язку та інформатизації" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Мінтрансзв'язку.

Розпорядником бюджетних коштів є Держзв'язку.

Напрями використання бюджетних коштів

3. Бюджетні кошти спрямовуються на здійснення заходів щодо забезпечення участі вітчизняних установ, підприємств і організацій державної форми власності у міжнародних виставках, конференціях, конгресах та семінарах, пов'язаних із науковою діяльністю у сфері зв'язку та інформатизації.

{ Пункт 3 в редакції Постанови КМ N 106 ( 106-2008-п ) від 27.02.2008 }

Вимоги щодо використання бюджетних коштів

4. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

Виконавцем робіт відповідно до цього Порядку є переможець процедури закупівлі товарів, робіт і послуг.

5. З метою недопущення виникнення кредиторської заборгованості на кінець року до тендерної документації та договору про закупівлю товарів, робіт і послуг включається вимога щодо коригування визначеної в договорі суми та зобов'язань сторін договору в разі зменшення бюджетних призначень під час уточнення показників державного бюджету.

{ Пункт 6 виключено на підставі Постанови КМ N 106 ( 106-2008-п ) від 27.02.2008 }

7. Попередня оплата здійснюється відповідно до постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752).

{ Абзац другий пункту 7 виключено на підставі Постанови КМ N 106 ( 106-2008-п ) від 27.02.2008 }

Остаточні розрахунки здійснюються замовником згідно з умовами договору на підставі відповідних рахунків та актів приймання-передачі робіт або послуг.

8. Перерахування бюджетних коштів здійснюється відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

Звітність про використання бюджетних коштів та контроль за їх витрачанням

9. Головний розпорядник бюджетних коштів затверджує план виконання робіт і проведення організаційних заходів із забезпечення участі у міжнародних виставках, конференціях, конгресах і семінарах, пов'язаних із науковою діяльністю у сфері зв'язку та інформатизації, та затверджує результативні показники щодо його виконання з поквартальною розбивкою.

Зазначені матеріали подаються до Мінфіну у тижневий строк після затвердження паспорту бюджетної програми.

Інформація щодо виконання результативних показників подається головним розпорядником бюджетних коштів Мінфіну у тижневий строк після закінчення кожного кварталу та одинадцяти місяців.

10. Складення та подання фінансової звітності про використання коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому порядку.
