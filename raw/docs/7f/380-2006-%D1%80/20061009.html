Кабінет Міністрів України; Розпорядження від 04.07.2006 № 380-р

Про виділення додаткових коштів для проведення розрахунків за оздоровлення та навчання дітей м. Алчевська Луганської області

Стан: Чинний

Ідентифікатор: 380-2006-р

Текст документа від 09.10.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 липня 2006 р. N 380-р Київ

Про виділення додаткових коштів для проведення розрахунків за оздоровлення та навчання дітей м. Алчевська Луганської області

{ Із змінами, внесеними згідно з Розпорядженням КМ N 505-р ( 505-2006-р ) від 09.10.2006 }

{ У тексті Розпорядження слова "оздоровлення та навчання дітей м. Алчевська" в усіх відмінках замінено словами "перебування дітей шкільного та дошкільного віку м. Алчевська разом із супроводжуючими особами в оздоровчих закладах, перевезення їх до місць оздоровлення та у зворотному напрямку" у відповідному відмінку згідно з Розпорядженням КМ N 505-р ( 505-2006-р ) від 09.10.2006 }

1. Виділити Луганській облдержадміністрації додатково 6712942 гривень для проведення розрахунків за перебування дітей шкільного та дошкільного віку м. Алчевська разом із супроводжуючими особами в оздоровчих закладах, перевезення їх до місць оздоровлення та у зворотному напрямку.

Мінфіну здійснити зазначені видатки за рахунок резервного фонду державного бюджету ( 3235-15 ).

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 505-р ( 505-2006-р ) від 09.10.2006 }

2. Луганській облдержадміністрації:

затвердити у тижневий строк за погодженням з Мінекономіки і Мінфіном розподіл додаткових витрат, пов'язаних з перебуванням дітей шкільного та дошкільного віку м. Алчевська разом із супроводжуючими особами в оздоровчих закладах, перевезенням їх до місць оздоровлення та у зворотному напрямку;

подати до 1 листопада 2006 р. Мінекономіки, Мінфіну і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України Ю.ЄХАНУРОВ
