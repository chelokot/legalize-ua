{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики України N 97 ( z0407-06 ) від 31.03.2006 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 03.09.2002 N 473

На виконання постанови Кабінету Міністрів України від 06.08.2003 N 1207 ( 1207-2003-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 03.09.2002 N 473 ( z0744-02 ) "Про умови оплати праці працівників територіальних органів Держнаглядохоронпраці", зареєстрованого в Міністерстві юстиції України 10.09.2002 за N 744/7032, виклавши додаток у новій редакції (додається).

2. Ці умови набирають чинності з 1 вересня 2003 року.

Міністр Михайло Папієв

Додаток до наказу Міністерства праці та соціальної політики України 03.09.2002 N 473 ( z0744-02 ) (у редакції наказу Міністерства праці та соціальної політики України від 12.09.2003 N 252)
