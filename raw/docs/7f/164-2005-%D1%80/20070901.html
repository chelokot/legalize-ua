Текст документа від 01.09.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 травня 2005 р. N 164-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 570-р ( 570-2007-р ) від 25.07.2007 }

Про внесення змін до розпорядження Кабінету Міністрів України від 16 червня 2003 р. N 365

1. Внести до переліку пунктів пропуску через митний кордон України для автомобільного сполучення, через які здійснюється ввезення на її митну територію та переміщення транзитом товарів 1-24 груп (крім підакцизних) згідно з УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ), затвердженого розпорядженням Кабінету Міністрів України від 16 червня 2003 р. N 365 ( 365-2003-р ) (Офіційний вісник України, 2003 р., N 25, ст. 1215), такі зміни:

1) у розділі "На кордоні з Республікою Молдова" виключити:

пункти пропуску "Росошани - Бричень" і "Кельменці - Ларга" Кельменецької митниці;

Роздільнянську митницю та пункт пропуску "Кучурган - Первомайськ" цієї митниці;

Котовську митницю та пункт пропуску "Платонове - Гоянул Ноу" цієї митниці;

2) у розділі "На кордоні з Республікою Польща" виключити пункт пропуску "Шегині - Медика" Галицької митниці.

2. Це розпорядження набирає чинності через 7 днів після опублікування.

Прем'єр-міністр України Ю.ТИМОШЕНКО
