Щодо звітування торговцями цінними паперами про укладені ними угоди з купівлі-продажу цінних паперів перед фондовими біржами

Реєстрація: Мін'юст України від 15.09.1998 № 573/3013

Стан: Втратив чинність

Ідентифікатор: z0573-98

Текст документа від 29.11.2005:

ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

N 100 від 31.07.98 Зареєстровано в Міністерстві м.Київ юстиції України 15 вересня 1998 р. vd980731 vn100 за N 573/3013

Щодо звітування торговцями цінними паперами про укладені ними угоди з купівлі-продажу цінних паперів перед фондовими біржами

( Із змінами, внесеними згідно з Рішенням Держкомісціннихпаперів N 203 ( z0043-99 ) від 25.12.98 )

( Щодо скасування Рішення додатково див. Рішення Державної комісії з цінних паперів та фондового ринку

N 457 ( vr457312-05 ) від 30.08.2005 - Рішення скасовано

на підставі Рішення Державної комісія з цінних паперів

та фондового ринку N 684 ( vr684312-05 ) від 29.11.2005 )

При перевірках діяльності торговців цінними паперами та фондових бірж відмічено те, що не всі біржі використовують свої повноваження щодо контролю за діяльністю торговців цінними паперами, в тому числі щодо контролю вимог ст.29 Закону України "Про цінні папери та фондову біржу" ( 1201-12 ). У з'вязку з цим, Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Фондовим біржам до 1 жовтня прийняти та в установленому порядку погодити з Державною комісією з цінних паперів та фондового ринку правила подання біржі торговцем цінними паперами, інформації про всі укладені ним угоди з цінними паперами.

Встановити, що за угодами, які укладаються з 1 січня 1999 року, торгівці цінними паперами - члени фондових бірж щоквартально звітують перед однією обраною фондовою біржею. Торгівці цінними паперами, які не є членами фондових бірж, звітують перед обраною фондовою біржею або саморегулівною організацією в разі делегування їй таких повноважень Державною комісією з цінних паперів та фондового ринку. ( Абзац другий пункту 1 в редакції Рішення Держкомісціннихпаперів N 203 ( z0043-99 ) від 25.12.98 )

Біржі звітують перед Державною комісією з цінних паперів та фондового ринку в двотижневий термін після закінчення звітного періоду.

Для звітування фондові біржі користуються Положенням про електронну форму звітності для діючих в Україні бірж та торгово-інформаційних систем, затвердженим рішенням Комісії від 11.11.97 р. N 57 ( v0057312-97 ).

Державна комісія з цінних паперів та фондового ринку може делегувати саморегулівним організаціям, які володіють електронною торговельно-інформаційною мережею, але не мають статусу фондової біржі, повноваження щодо прийняття від торгівців цінними паперами, які не є членами фондових бірж, інформації про всі укладені ними угоди з цінними паперами при виконанні саморегулівною організацією наступних умов, зокрема:

- достатності людських, фінансових та технічних ресурсів для здійснення вищезазначених заходів;

- наявності погоджених Комісією правил подання саморегулівній організації торговцем цінними паперами інформації про всі укладені ним угоди з цінними паперами;

- звітування саморегулівної організації перед Комісією в двотижневий термін після закінчення звітного періоду згідно з Положенням про порядок подання електронної форми звітності для бірж та ПФТС, затвердженим рішенням Комісії N 57 ( v0057312-97 ) від 11.11.97 "Про затвердження Положення про електронну форму звітності для діючих в Україні бірж та торговельно-інформаційних систем. ( Пункт 1 доповнено абзацом згідно з Рішенням Держкомісціннихпаперів N 203 ( z0043-99 ) від 25.12.98 )

2. Керівнику Прес-центру Шевкіній Л.В. забезпечити опублікування пункту 1 цього рішення в установленому порядку.

3. Управлінню регулювання діяльності організаторів торгівлі цінними паперами та СРО (Пугач Н.І.) разом з Юридичним управлінням забезпечити реєстрацію цього рішення в Міністерстві юстиції України.

4. Контроль за виконанням рішення покласти на Члена Комісії Волкова М.Ф.

Голова Комісії О.Мозговий
