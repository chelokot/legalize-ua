Про створення галузевого державного архіву Державного комітету по гідрометеорології

Стан: Втратив чинність

Ідентифікатор: 570-95-п

Текст документа від 31.07.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 липня 1995 р. N 570 Київ

Про створення галузевого державного архіву Державного комітету по гідрометеорології

Відповідно до статті 9 Закону України "Про Національний архівний фонд і архівні установи" ( 3814-12 ) Кабінет Міністрів України ПОСТАНОВЛЯЄ :

1. Створити галузевий державний архів Державного комітету по гідрометеорології на базі відділу державного фонду даних Республіканського центру спостережень за станом природного середовища Комітету для постійного зберігання та використання гідрометеорологічних та інших спеціальних документів Національного архівного фонду.

2. Головному архівному управлінню при Кабінеті Міністрів України і Державному комітетові по гідрометеорології затвердити у двомісячний термін Положення про державний архів Державного комітету України по гідрометеорології.

3. Установити, що витрати на утримання зазначеного архіву провадяться в межах коштів, передбачених в Державному бюджеті для Державного комітету по гідрометеорології.
