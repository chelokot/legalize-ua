МОЗ України; Наказ від 31.08.2007 № 511

Про затвердження Великих та особливо великих розмірів отруйних та сильнодіючих лікарських засобів, які знаходяться у незаконному обігу

Реєстрація: Мін'юст України від 14.09.2007 № 1070/14337

Стан: Чинний

Ідентифікатор: z1070-07

Текст документа від 04.10.2008:

МІНІСТЕРСТВО ОХОРОНИ ЗДОРОВ'Я УКРАЇНИ

НАКАЗ

31.08.2007 N 511

Зареєстровано в Міністерстві юстиції України 14 вересня 2007 р. за N 1070/14337

Про затвердження Великих та особливо великих розмірів отруйних та сильнодіючих лікарських засобів, які знаходяться у незаконному обігу

{ Із змінами, внесеними згідно з Наказом Міністерства охорони здоров'я N 481 ( z0886-08 ) від 20.08.2008 }

Відповідно до Закону України "Про лікарські засоби" ( 123/96-ВР ) та Закону України "Про внесення змін до Кримінального кодексу України щодо встановлення відповідальності за незаконні дії стосовно отруйних чи сильнодіючих лікарських засобів" ( 875-16 ), доручення Кабінету Міністрів України від 16.06.2007 N 26215/1/1-07 до Закону України від 05.04.07 N 875-V ( 875-16 ) НАКАЗУЮ:

1. Затвердити Великі та особливо великі розміри отруйних лікарських засобів, які знаходяться у незаконному обігу, що додаються.

2. Затвердити Великі та особливо великі розміри сильнодіючих лікарських засобів, які знаходяться у незаконному обігу ( z1071-07 ), що додаються.

3. Державній службі лікарських засобів і виробів медичного призначення забезпечити в установленому порядку державну реєстрацію цього наказу в Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Гудзенка О.П.

Міністр Ю.О.Гайдаєв

Т.в.о. Міністра внутрішніх справ України М.В.Корнієнко
