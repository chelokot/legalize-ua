Кабінет Міністрів України; Постанова, Порядок від 16.05.2007 № 740

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки державних музичних колективів

Стан: Чинний

Ідентифікатор: 740-2007-п

Текст документа від 05.03.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 травня 2007 р. N 740 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки державних музичних колективів

{ Із змінами, внесеними згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) за програмою "Фінансова підтримка державних музичних колективів", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки державних музичних колективів, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 51

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 16 травня 2007 р. N 740

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки державних музичних колективів

Загальні питання

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Держкомтелерадіо за програмою "Фінансова підтримка державних музичних колективів" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Держкомтелерадіо.

Одержувачами бюджетних коштів є державні музичні колективи, що належать до сфери управління Держкомтелерадіо.

Напрями використання бюджетних коштів

3. Бюджетні кошти спрямовуються на забезпечення державної підтримки музичної діяльності державних музичних колективів, зокрема оновлення репертуару та концертних програм, організацію гастролей, зміцнення матеріально-технічної бази.

Вимоги щодо використання бюджетних коштів

4. Бюджетні кошти використовуються Держкомтелерадіо в межах бюджетних асигнувань з урахуванням необхідності виконання взятих на облік в органах Державного казначейства бюджетних зобов'язань минулих років у разі їх відповідності паспорту бюджетної програми. { Пункт 4 із змінами, внесеними згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

5. Обсяг фінансової підтримки державних музичних колективів на покриття поточних витрат, не забезпечених власними доходами, не повинен перевищувати 95 відсотків фактичного обсягу валового доходу, одержаного за результатами діяльності державних музичних колективів у поточному році.

Інформація про розрахунок суми, на яку зменшується обсяг фінансової підтримки, подається одержувачами бюджетних коштів Держкомтелерадіо, який визначає розмір фінансової підтримки з державного бюджету, щокварталу до 10 числа наступного місяця для подання Мінфіну до 10 грудня поточного року.

6. У разі зменшення бюджетних призначень Держкомтелерадіо з метою недопущення виникнення кредиторської заборгованості на кінець року здійснює відповідне коригування суми видатків для фінансової підтримки державних музичних колективів.

7. Операції з бюджетними коштами проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

Звітність про використання бюджетних коштів та контроль за їх витрачанням

{ Пункт 8 виключено на підставі Постанови КМ N 127 ( 127-2008-п ) від 05.03.2008 }

9. У разі коли під час виконання бюджетної програми допущено суттєві порушення, Мінфін та Держкомтелерадіо проводять узгоджувальні наради, за результатами яких вносять на розгляд Першого віце-прем'єр-міністра України, Міністра фінансів пропозиції щодо подальшого порядку її фінансування.

10. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються у встановленому законодавством порядку.
