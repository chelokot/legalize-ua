{ Розпорядження втратило чинність на підставі Постанови КМ N 439 ( 439-2020-п ) від 03.06.2020 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 23 квітня 2001 р. N 149

Внести до розпорядження Кабінету Міністрів України від 23 квітня 2001 р. N 149 ( 149-2001-р ) (Офіційний вісник України, 2001 р., N 17, ст. 764) зміну, доповнивши його абзацом такого змісту:

"МОЗ - щодо продуктів харчування, продовольчої сировини та мінеральних природних вод".
