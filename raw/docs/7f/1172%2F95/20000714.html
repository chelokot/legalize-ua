УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 889/2000 ( 889/2000 ) від 14.07.2000 )

Про внесення змін до статті 3 Указу Президента України від 14 квітня 1995 року N 312

Внести до статті 3 Указу Президента України від 14 квітня 1995 року N 312 ( 312/95 ) "Про заходи щодо поліпшення роботи органів державної статистики України" такі зміни:

частину другу статті викласти в такій редакції:

"Установити, що Головою Національної ради є за посадою віце-Прем'єр-міністр України з питань економіки, заступником Голови - Міністр статистики України, членами Ради - перші заступники (заступники) міністрів, керівників інших центральних органів державної виконавчої влади".

Президент України Л.КУЧМА
