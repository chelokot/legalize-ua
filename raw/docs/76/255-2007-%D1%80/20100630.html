Питання утворення регіональних центрів інноваційного розвитку

Стан: Чинний

Текст документа від 30.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 травня 2007 р. N 255-р Київ

Питання утворення регіональних центрів інноваційного розвитку

{ Щодо перейменування регіональних центрів інноваційного розвитку, утворених відповідно до цього Розпорядження, на регіональні центри з інвестицій та розвитку див. Розпорядження КМ N 1289-р ( 1289-2010-р ) від 30.06.2010 }

1. Прийняти пропозицію Держінвестицій щодо утворення регіональних центрів інноваційного розвитку як бюджетних установ з віднесенням їх до сфери управління Агентства.

2. Мінфіну та Держінвестицій забезпечити утримання регіональних центрів інноваційного розвитку за рахунок бюджетних коштів, передбачених Агентству Законом України "Про Державний бюджет України на 2007 рік" ( 489-16 ) за програмою "Утримання регіональних центрів інноваційного розвитку та впровадження регіональних і галузевих інноваційних програм".

3. Мінфіну під час складання проекту Державного бюджету України на 2008 та наступні роки передбачити кошти для Держінвестицій з метою забезпечення діяльності регіональних центрів інноваційного розвитку.

4. Мінпраці на підставі подання Держінвестицій затвердити у місячний строк за погодженням з Мінфіном умови оплати праці працівників регіональних центрів інноваційного розвитку.

Прем'єр-міністр України В.ЯНУКОВИЧ
