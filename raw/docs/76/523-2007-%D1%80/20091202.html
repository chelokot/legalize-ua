РОЗПОРЯДЖЕННЯ від 11 липня 2007 р. N 523-р Київ

Про підписання Угоди між Кабінетом Міністрів України та Урядом Королівства Марокко про співробітництво у сфері культури

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1448-р ( 1448-2009-р ) від 02.12.2009 }

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Королівства Марокко про співробітництво у сфері культури.

Уповноважити заступника Міністра культури і туризму Кохана Тимофія Григоровича підписати Угоду між Кабінетом Міністрів України та Урядом Королівства Марокко про співробітництво у сфері культури. { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 1448-р ( 1448-2009-р ) від 02.12.2009 }
