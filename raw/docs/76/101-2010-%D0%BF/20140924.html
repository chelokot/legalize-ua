ПОСТАНОВА від 3 лютого 2010 р. N 101 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 459 ( 459-2014-п ) від 20.08.2014 }

Про доповнення пункту 11 Положення про Міністерство економіки України

Кабінет Міністрів України постановляє:

Доповнити перше речення абзацу другого пункту 11 Положення про Міністерство економіки України, затвердженого постановою Кабінету Міністрів України від 26 травня 2007 р. N 777 ( 777-2007-п ) (Офіційний вісник України, 2007 р., N 39, ст. 1563; 2009 р., N 72, ст. 2480, N 95, ст. 3262), після слова "Мінекономіки" словами ", члени виконавчого або іншого органу управління всеукраїнських асоціацій органів місцевого самоврядування".

Прем'єр-міністр України Ю.ТИМОШЕНКО
