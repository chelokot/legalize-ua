Про внесення зміни до Статуту Державної акціонерної компанії "Укрресурси"

Текст документа від 20.12.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 грудня 2002 р. N 1963 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1360 ( 1360-2007-п ) від 21.11.2007 }

Про внесення зміни до Статуту Державної акціонерної компанії "Укрресурси"

Кабінет Міністрів України постановляє:

Абзац перший пункту 18 Розділу VI Статуту Державної акціонерної компанії "Укрресурси", затвердженого постановою Кабінету Міністрів України від 21 січня 1995 р. N 46 "Питання Державної акціонерної компанії "Укрресурси" ( 46-95-п ), викласти у такій редакції:

"18. У період до проведення перших загальних зборів Голова правління та заступники Голови правління Компанії призначаються Кабінетом Міністрів України".

Прем'єр-міністр України В.ЯНУКОВИЧ
