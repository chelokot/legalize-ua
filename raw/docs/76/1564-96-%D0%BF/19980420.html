Текст документа від 20.04.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 грудня 1996 р. N 1564 Київ

( Постанова втратила чинність на підставі Постанови КМ N 516 ( 516-98-п ) від 20.04.98 )

( Дію Постанови відновлено на підставі Постанови КМ N 727 ( 727-97-п ) від 09.07.97 )

( Постанова втратила чинність на підставі Постанови КМ N 330 ( 330-97-п ) від 14.04.97 )

Про часткову зміну структури апарату Кабінету Міністрів України затвердженої постановою Кабінету Міністрів України від 3 липня 1996 р. N 713

На часткову зміну структури апарату Кабінету Міністрів України, затвердженої постановою Кабінету Міністрів України від 3 липня 1996 р. N 713 ( 713-96-п ) "Про реорганізацію структури апарату Кабінету Міністрів України" Кабінет Міністрів України постановляє:

Перейменувати Відділ з підготовки засідань Кабінету Міністрів України та його Президії у Відділ з підготовки засідань Кабінету Міністрів України.

Прем'єр-міністр України П.ЛАЗАРЕНКО
