( Постанова втратила чинність на підставі Постанови N 50 ( 50-2006-п ) від 25.01.2006 )

Про затвердження складу Міжвідомчої комісії з міжнародної торгівлі

Кабінет Міністрів України постановляє:

1. Затвердити склад Міжвідомчої комісії з міжнародної торгівлі, що додається.

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 11 березня 2004 р. N 300 ( 300-2004-п ) "Про затвердження складу Міжвідомчої комісії з міжнародної торгівлі";

розпорядження Кабінету Міністрів України від 12 травня 2004 р. N 284 ( 284-2004-р ) "Про зміну складу Міжвідомчої комісії з міжнародної торгівлі";

розпорядження Кабінету Міністрів України від 30 листопада 2004 р. N 872 ( 872-2004-р ) "Про зміну складу Міжвідомчої комісії з міжнародної торгівлі".
