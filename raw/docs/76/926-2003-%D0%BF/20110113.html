Кабінет Міністрів України; Постанова від 20.06.2003 № 926

Про розміри плати за марки акцизного збору для алкогольних напоїв та тютюнових виробів

Стан: Втратив чинність

Ідентифікатор: 926-2003-п

Текст документа від 13.01.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 червня 2003 р. N 926 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1251 ( 1251-2010-п ) від 27.12.2010 }

Про розміри плати за марки акцизного збору для алкогольних напоїв та тютюнових виробів

{ Із змінами, внесеними згідно з Постановами КМ N 486 ( 486-2008-п ) від 21.05.2008 N 1039 ( 1039-2010-п ) від 10.11.2010 }

Відповідно до абзацу третього статті 1 Закону України "Про акцизний збір на алкогольні напої та тютюнові вироби" ( 329/95-ВР ) Кабінет Міністрів України постановляє:

1. Затвердити такі розміри плати за марки акцизного збору, запроваджені постановою Кабінету Міністрів України від 23 квітня 2003 р. N 567 ( 567-2003-п ) "Про запровадження марок акцизного збору нового зразка з голографічними захисними елементами для маркування алкогольних напоїв та тютюнових виробів":

за одну марку акцизного збору для алкогольних напоїв - 0,103 гривні; { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 486 ( 486-2008-п ) від 21.05.2008 }

за одну марку акцизного збору для тютюнових виробів - 0,055 гривні. { Абзац третій пункту 1 із змінами, внесеними згідно з Постановою КМ N 486 ( 486-2008-п ) від 21.05.2008 }

{ Абзац четвертий пункту 1 виключено на підставі Постанови КМ N 1039 ( 1039-2010-п ) від 10.11.2010 }

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 16 листопада 1995 р. N 919 ( 919-95-п ) "Про розміри плати за марки акцизного збору на алкогольні напої та тютюнові вироби" (ЗП України, 1996 р., N 3, ст. 98);

постанову Кабінету Міністрів України від 22 лютого 1999 р. N 231 ( 231-99-п ) "Про внесення змін до постанови Кабінету Міністрів України від 16 листопада 1995 р. N 919" (Офіційний вісник України, 1999 р., N 8, ст. 283).
