ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ПИТАНЬ РЕГУЛЯТОРНОЇ ПОЛІТИКИ ТА ПІДПРИЄМНИЦТВА МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ

ЗАТВЕРДЖЕНО Наказ Державного комітету України з питань регуляторної політики та підприємництва, Міністерства фінансів України 22.09.2008 N 117/1164 ( z0890-08 )

Зареєстровано в Міністерстві юстиції України 23 вересня 2008 р. за N 891/15582

{ Наказ втратив чинність на підставі Наказу Державного комітету України з питань регуляторної політики та підприємництва N 171/1176 ( z1055-09 ) від 07.10.2009 }

ЗМІНИ до Порядку контролю за додержанням Ліцензійних умов провадження організації діяльності з проведення азартних ігор ( z0623-06 )

Пункт 1.5 глави 1 викласти у такій редакції:

"1.5. Позапланові перевірки додержання ліцензіатами, які проводять азартні ігри в гральних закладах (казино, зал гральних автоматів тощо), вимог Ліцензійних умов ( z0622-06 ) здійснюються із залученням фахівців Державного комітету фінансового моніторингу України у разі, якщо підставою для проведення такої перевірки стало надходження письмової заяви (повідомлення) про порушення ліцензіатом підпункту 3.6.8 пункту 3.6 Ліцензійних умов.

Строк, протягом якого Державний комітет фінансового моніторингу України повинен надати інформацію про фахівця (фахівців), який візьме участь у перевірці, встановлюється органом, що організовує таку перевірку.

Інформація про фахівця (фахівців) Державного комітету фінансового моніторингу України, який візьме участь у перевірці, надається до органу, який організовує таку перевірку, у письмовій формі.

У разі неподання або несвоєчасного подання Державним комітетом фінансового моніторингу України до відповідного органу контролю інформації про фахівця (фахівців), який братиме участь у перевірці, остання проводиться без залучення такого фахівця (фахівців)".

Начальник Управління ліцензування Державного комітету України з питань регуляторної політики та підприємництва О.Б.Іванченко

Начальник Управління державного регулювання у сфері випуску та проведення лотерей, інших азартних ігор О.В.Андреєв
