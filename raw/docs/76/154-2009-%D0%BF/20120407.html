Про утворення Державної холдингової компанії "Титан України"

Стан: Чинний

Ідентифікатор: 154-2009-п

Текст документа від 07.04.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 лютого 2009 р. N 154 Київ

Про утворення Державної холдингової компанії "Титан України"

{ Із змінами, внесеними згідно з Постановою КМ N 243 ( 243-2012-п ) від 23.01.2012 }

{ Щодо зупинення дії пунктів 1, 3, 6 див. Указ Президента N 241/2009 ( 241/2009 ) від 14.04.2009 - втратив чинність на підставі Указу Президента N 821/2009 ( 821/2009 ) від 13.10.2009 }

{ Відмовлено у відкритті конституційного провадження у справі за конституційним поданням Президента України щодо відповідності Конституції України ( 254к/96-ВР ) (конституційності) положень пунктів 1 (стосовно казенного підприємства "Запорізький титано-магнієвий комбінат"), 3, 6 цієї Постанови Ухвалою Конституційного Суду N 29-у/2009 ( v029u710-09 ) від 10.06.2009 }

Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Міністерства промислової політики щодо утворення Державної холдингової компанії "Титан України" (далі - Компанія), статутний фонд якої формується шляхом передачі до нього 100 відсотків акцій, що належать державі у статутних фондах відкритих акціонерних товариств "Сумихімпром" і "ДАК "Титан". { Щодо дії пункту 1 у частині, що стосується казенного підприємства "Запорізький титано-магнієвий комбінат" див. Указ Президента N 241/2009 ( 241/2009 ) від 14.04.2009, Ухвалу Конституційного Суду N 29-у/2009 ( v029u710-09 ) від 10.06.2009 } { Пункт 1 із змінами, внесеними згідно з Постановою КМ N 243 ( 243-2012-п ) від 23.01.2012 }

2. Установити, що:

засновником Компанії є держава в особі Міністерства промислової політики;

повноваження з управління корпоративними правами держави щодо Компанії здійснюються Міністерством промислової політики;

державні пакети акцій, передані державою до статутного фонду Компанії, не можуть бути відчужені або перебувати в заставі, використані для формування статутних фондів будь-яких підприємств.

3. Перетворити казенне підприємство "Запорізький титано-магнієвий комбінат" у державне комерційне підприємство "Запорізький титано-магнієвий комбінат". { Щодо дії пункту 3 див. Указ Президента N 241/2009 ( 241/2009 ) від 14.04.2009, Ухвалу Конституційного Суду N 29-у/2009 ( v029u710-09 ) від 10.06.2009 }

Міністерству промислової політики здійснити організаційні заходи, пов'язані з перетворенням зазначеного підприємства у державне комерційне підприємство. { Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 243 ( 243-2012-п ) від 23.01.2012 }

4. Погодитися з пропозицією Фонду державного майна стосовно передачі Міністерству промислової політики у двотижневий строк повноважень з управління корпоративними правами держави щодо відкритих акціонерних товариств "Сумихімпром" і "ДАК "Титан" з подальшим включенням пакетів акцій, що належать державі у статутних фондах цих товариств, до статутного фонду Компанії.

5. Міністерству промислової політики затвердити статут Компанії та здійснити організаційні заходи, пов'язані з її утворенням.

6. У розділі "Мінпромполітики" переліку державних підприємств, які перетворюються у казенні, затвердженого постановою Кабінету Міністрів України від 30 червня 1998 р. N 987 ( 987-98-п ) (Офіційний вісник України, 1998 р., N 26, ст. 953; 1999 р., N 50, ст. 2474), позицію

"00194731 Запорізький державний титано-магнієвий комбінат"

виключити. { Щодо дії пункту 6 див. Указ Президента N 241/2009 ( 241/2009 ) від 14.04.2009, Ухвалу Конституційного Суду N 29-у/2009 ( v029u710-09 ) від 10.06.2009 }

7. Міністерству економіки разом з Міністерством промислової політики в місячний строк після утворення Компанії подати Кабінету Міністрів України пропозиції щодо включення Компанії, її дочірніх підприємств до переліку об'єктів права державної власності, що не підлягають приватизації.
