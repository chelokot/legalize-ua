КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 січня 1997 р. N 67 Київ

Про внесення змін до ставок ввізного мита на окремі види товарів

( Із змінами, внесеними згідно з Постановами КМ N 1120 ( 1120-97-п ) від 08.10.97 N 352 ( 352-98-п ) від 20.03.98 N 693 ( 693-98-п ) від 18.05.98 N 2000 ( 2000-98-п ) від 18.12.98 )

Кабінет Міністрів України постановляє :

1. Внести зміни до ставок ввізного мита на окремі види товарів згідно з додатком.

2. У додатку до постанови Кабінету Міністрів України від 3 травня 1994 р. N 285 ( 285-94-п ) "Про зміни ставок ввізного мита на окремі види товарів" (ЗП України, 1994 р., N 11, ст.266) види товарів за кодами 39.14 00000, 84.24 20900, у додатку до постанови Кабінету Міністрів України від 20 липня 1996 р. N 770 ( 770-96-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів" вид товару за кодом 33.02 90 000, у додатку до постанови Кабінету Міністрів України від 8 листопада 1996 р. N 1376 ( 1376-96-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів" види товарів за кодами 34.02 20900, 34.02 90900 виключити.

3. У додатку до постанови Кабінету Міністрів України від 22 лютого 1995 р. N 139 ( 139-95-п ) "Про внесення змін до ставок ввізного мита на товари, яких достатньо виробляється у країні" (ЗП України, 1995 р., N 5, ст.128):

види товарів за кодом 84.34 10000 виключити;

цифри і слова

"87.05 30000 Автомобілі пожежні 20 30"

замінити цифрами і словами

"87.05 30000 Автомобілі 20 30". пожежні (крім пожежних автомобілів з підіймачем або драбиною)

4. У додатку до постанови Кабінету Міністрів України від 18 липня 1995 р. N 531 ( 531-95-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів та до деяких рішень Уряду України" (ЗП України, 1995 р., 10, ст.246) цифри і слова

"84.34 90000 Установки і апарати доїльні, 2 10" устаткування для обробки та переробки молока в сільсько- му господарстві та промисло- вості

замінити цифрами і словами

"84.34 90000 Тільки частини до устаткува- 2 10" ння для обробки та переробки молока в сільському госпо- дарстві та промисловості

5. Ця постанова набирає чинності через 10 днів після опублікування у газеті "Урядовий кур'єр".
