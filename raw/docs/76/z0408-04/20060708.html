{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 228 ( z0759-06 ) від 19.06.2006 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 21.11.2002 N 588

На виконання постанови Кабінету Міністрів України від 11 лютого 2004 року N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 21.11.2002 N 588 ( z0926-02 ) "Про умови оплати праці працівників Національного антидопінгового центру", зареєстрованого в Міністерстві юстиції України 28.11.2002 за N 926/7214 (зі змінами), виклавши додаток у новій редакції (додається).

2. Ці зміни застосовуються з 1 березня 2004 року.
