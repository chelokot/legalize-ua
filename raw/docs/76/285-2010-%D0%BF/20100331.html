N 431 ( 431-2009-п ) "Про особливості закупівлі автобусів для забезпечення оздоровлення та відпочинку дітей у державному підприємстві "Міжнародний дитячий центр "Артек" (Офіційний вісник України, 2009 р., N 33, ст. 1145).
