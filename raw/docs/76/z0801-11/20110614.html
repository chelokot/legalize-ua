Про затвердження Змін до Умов оплати праці працівників Державної прикордонної служби України, затверджених наказом Адміністрації Державної прикордонної служби України від 19.06.2007 N 430

Відповідно до постанови Кабінету Міністрів України від 30.08.2002 N 1298 ( 1298-2002-п ) "Про оплату праці працівників на основі Єдиної тарифної сітки розрядів і коефіцієнтів з оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" (із змінами), постанови Кабінету Міністрів України від 03.02.2010 N 109 ( 109-2010-п ) "Про оплату праці працівників закладів культури, яким надано статус академічних", розпорядження Кабінету Міністрів України від 18.08.2010 N 1679-р ( 1679-2010-р ) "Про створення галузевого державного архіву Державної прикордонної служби" та з метою упорядкування умов оплати праці працівників органів Державної прикордонної служби України НАКАЗУЮ:

1. Затвердити Зміни до Умов оплати праці працівників Державної прикордонної служби України, затверджених наказом Адміністрації Державної прикордонної служби України від 19.06.2007 N 430 ( z0718-07 ) "Про упорядкування умов оплати праці працівників Державної прикордонної служби України", зареєстрованих у Міністерстві юстиції України 22.06.2007 за N 718/13985, що додаються.

2. Контроль за виконанням наказу покласти на директора Фінансово-економічного департаменту Адміністрації Державної прикордонної служби України генерал-майора Рудика Я.Р.

3. Наказ розіслати згідно з розрахунком розсилки.

4. Цей наказ набирає чинності з дня його офіційного опублікування.
