Президент України; Розпорядження від 26.07.2007 № 165/2007-рп

Питання діяльності української частини Спільної робочої групи Україна - НАТО з питань воєнної реформи високого рівня

Стан: Втратив чинність

Ідентифікатор: 165/2007-рп

Текст документа від 17.06.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Питання діяльності української частини Спільної робочої групи Україна - НАТО з питань воєнної реформи високого рівня

{ Із змінами, внесеними згідно з Розпорядженням Президента N 199/2008-рп ( 199/2008-рп ) від 17.06.2008 }

З метою забезпечення продовження інтенсифікованого діалогу з Північно-Атлантичним альянсом щодо прагнень України до набуття членства в НАТО та відповідних реформ, реалізації пріоритетних завдань співробітництва Україна - НАТО у сфері реформування сектору національної безпеки і оборони за євроатлантичними стандартами, згідно з пунктами 3 і 17 частини першої статті 106 Конституції України ( 254к/96-ВР ):

1. Призначити Першого заступника Секретаря Ради національної безпеки і оборони України ГАВРИША Степана Богдановича головою української частини Спільної робочої групи Україна - НАТО з питань воєнної реформи високого рівня.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням Президента N 199/2008-рп ( 199/2008-рп ) від 17.06.2008 }

2. Секретареві Ради національної безпеки і оборони України визначити структурний підрозділ Апарату Ради національної безпеки і оборони України, на який покладається організаційно-технічне забезпечення діяльності української частини Спільної робочої групи Україна - НАТО з питань воєнної реформи високого рівня.

3. Визнати таким, що втратило чинність, Розпорядження Президента України від 23 жовтня 2001 року N 287 ( 287/2001-рп ) "Про призначення С. Пирожкова головою української частини Спільної робочої групи Україна - НАТО з питань військової реформи високого рівня".

Президент України В.ЮЩЕНКО

м. Київ, 26 липня 2007 року N 165/2007-рп
