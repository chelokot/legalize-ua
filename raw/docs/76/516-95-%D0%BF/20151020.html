ПОСТАНОВА від 13 липня 1995 р. N 516 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 818 ( 818-2015-п ) від 07.10.2015 }

Про плату за видачу та переоформлення Національною комісією, що здійснює державне регулювання у сфері енергетики, ліцензій на здійснення певних видів підприємницької діяльності

{ Із змінами, внесеними згідно з Постановами КМ N 912 ( 912-98-п ) від 16.06.98 N 481 ( 481-99-п ) від 30.03.99 N 501 ( 501-2000-п ) від 16.03.2000 N 821 ( 821-2001-п ) від 11.07.2001 N 57 ( 57-2006-п ) від 25.01.2006 N 781 ( 781-2012-п ) від 22.08.2012 N 261 ( 261-2014-п ) від 17.07.2014 }

{ У назві та тексті Постанови і назві додатка до неї слова "Національна комісія регулювання електроенергетики" в усіх відмінках замінено словами "Національна комісія, що здійснює державне регулювання у сфері енергетики" у відповідному відмінку згідно з Постановою КМ N 781 ( 781-2012-п ) від 22.08.2012 }

Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. Установити, що розмір плати за видачу Національною комісією, що здійснює державне регулювання у сфері енергетики, ліцензій на здійснення певних видів підприємницької діяльності складається з одноразової плати, яка визначається згідно з додатком, і поточної плати.

Поточна плата встановлюється виходячи із затвердженого Головою Національної комісії, що здійснює державне регулювання у сфері енергетики, кошторису витрат Комісії у розрахунку на 1 мегават установленої потужності, 1 млн. кіловат-годин виробленої, переданої та поставленої електричної енергії, 1 Гкал/год установленої теплової потужності, 1000 Гкал виробленої теплової енергії з урахуванням коштів, які надходять від одноразової плати за видачу ліцензій, технічної допомоги від міжнародних організацій та інших джерел, і сплачується відповідно до умов та правил здійснення певних видів підприємницької діяльності, ліцензування яких належить до компетенції Національної комісії, що здійснює державне регулювання у сфері енергетики. { Абзац другий пункту 1 із змінами, внесеними згідно з Постановами КМ N 821 ( 821-2001-п ) від 11.07.2001, N 57 ( 57-2006-п ) від 25.01.2006 }

Плата за видачу ліцензій вноситься у гривнях і зараховується до державного бюджету. { Абзац третій пункту 1 в редакції Постанови КМ N 501 ( 501-2000-п ) від 16.03.2000 }

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 912 ( 912-98-п ) від 16.06.98, в редакції Постанови КМ N 481 ( 481-99-п ) від 30.03.99 }

2. У разі своєчасного подання суб'єктом підприємницької діяльності заяви про переоформлення ліцензії (протягом десяти днів з дня державної реєстрації зміни місцезнаходження, найменування юридичної особи або зміни відомостей, зазначених у ліцензії, виданій підприємцю-громадянину) з нього справляється плата у розмірі 2 відсотків одноразової плати, яка зараховується до державного бюджету. { Абзац перший пункту 2 із змінами, внесеними згідно з Постановами КМ N 821 ( 821-2001-п ) від 11.07.2001, N 57 ( 57-2006-п ) від 25.01.2006 }

У разі несвоєчасного подання суб'єктом підприємницької діяльності заяви про переоформлення ліцензії з нього справляється плата у розмірі, встановленому для її видачі.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 912 ( 912-98-п ) від 16.06.98, в редакції Постанови КМ N 481 ( 481-99-п ) від 30.03.99 }

3. Залишок не використаних протягом року Національною комісією, що здійснює державне регулювання у сфері енергетики, коштів вилученню не підлягає І враховується під час визначення рівня поточної плати на наступний фінансовий рік.

{ Постанову доповнено пунктом 3 згідно з Постановою КМ N 912 ( 912-98-п ) від 16.06.98 }
