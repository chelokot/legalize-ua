Про плату за видачу та переоформлення Національною комісією, що здійснює державне регулювання у сфері енергетики, ліцензій на здійснення певних видів підприємницької діяльності

Стан: Втратив чинність

Ідентифікатор: 516-95-п

Текст документа від 16.06.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 липня 1995 р. N 516 Київ

Про плату за видачу ліцензій на виробництво, передачу та постачання електроенергії

( Із змінами, внесеними згідно з Постановою КМ N 912 ( 912-98-п ) від 16.06.98 )

Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. Установити, що плата з громадян та юридичних осіб - суб'єктів підприємницької діяльності за видачу Національною комісією регулювання електроенергетики ліцензій на виробництво, передачу та постачання електроенергії складається з одноразової плати, яка визначається згідно з додатком, і поточної плати.

( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 912 ( 912-98-п ) від 16.06.98 )

Поточна плата встановлюється виходячи із затвердженого головою Національної комісії регулювання електроенергетики кошторису витрат Комісії у розрахунку на 1 мегават установленої потужності та 1 млн. кіловат-годин виробленої, переданої та поставленої електричної енергії з урахуванням коштів, які надходять від одноразової плати за видачу ліцензій, технічної допомоги від міжнародних організацій, надходжень від державних фондів та з інших джерел, і сплачується відповідно до умов та правил здійснення підприємницької діяльності з виробництва, передачі та постачання електричної енергії. ( Абзац другий пункту 1 в редакції Постанови КМ N 912 ( 912-98-п ) від 16.06.98 )

Одноразова і поточна плата вноситься у гривнях і зараховується на рахунок Національної комісії регулювання електроенергетики. ( Абзац третій пункту 1 в редакції Постанови КМ N 912 ( 912-98-п ) від 16.06.98 )

( Абзац четвертий пункту 1 виключено на підставі Постанови КМ N 912 ( 912-98-п ) від 16.06.98 ) Залишок не використаних протягом року Національною комісією з питань регулювання електроенергетики коштів вилученню не підлягає і враховується під час визначення рівня поточної плати на наступний фінансовий рік.

2. За видачу Національною комісією регулювання електроенергетики дубліката ліцензії справляється плата у розмірі 5 відсотків одноразової плати, за переоформлення ліцензії - 2 відсотків, яка зараховується на рахунок Комісії. ( Пункт 2 в редакції Постанови Нацбанку N 912 ( 912-98-п ) від 16.06.98 )

3. Залишок не використаних протягом року Національною комісією регулювання електроенергетики коштів вилученню не підлягає І враховується під час визначення рівня поточної плати на наступний фінансовий рік. ( Постанову доповнено пунктом 3 згідно з Постановою КМ N 912 ( 912-98-п ) від 16.06.98 )
