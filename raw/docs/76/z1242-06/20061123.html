МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

23.11.2006 N 1104

Зареєстровано в Міністерстві юстиції України від 29 листопада 2006 р. за N 1242/13116

Про втрату чинності деяких наказів Мінзв'язку України, Держкомзв'язку України та Мінтрансзв'язку України

Відповідно до Закону України "Про телекомунікації" ( 1280-15 ) та Положення про Міністерство транспорту та зв'язку України, затвердженого постановою Кабінету Міністрів України від 06.06.2006 N 789 ( 789-2006-п ), НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

наказ Міністерства зв'язку України від 30.10.96 N 234 ( z0673-96 ) "Про порядок взаєморозрахунків між операторами міжміського, міжнародного та місцевого телефонного зв'язку різних форм власності", зареєстрований в Міністерстві юстиції України 21.11.96 за N 673/1698;

наказ Державного комітету зв'язку та інформатизації України від 07.06.2002 N 120 ( z0595-02 ) "Про затвердження Граничних тарифів на основні послуги електрозв'язку та тарифів на виплату державних пенсій та грошової допомоги", зареєстрований в Міністерстві юстиції України 19.07.2002 за N 595/6883 (із змінами);

наказ Державного комітету зв'язку та інформатизації України від 04.01.2003 N 1 ( z0108-03 ) "Про Порядок взаєморозрахунків між операторами за проведені міжнародні та міжміські телефонні розмови", зареєстрований в Міністерстві юстиції України 10.02.2003 за N 108/7429;

наказ Державного комітету зв'язку та інформатизації України від 18.02.2003 N 28 ( z0144-03 ) "Про призупинення дії наказу Державного комітету зв'язку та інформатизації України від 04.01.2003 N 1", зареєстрований в Міністерстві юстиції України 20.02.2003 за N 144/7465;

наказ Державного комітету зв'язку та інформатизації України від 03.09.2003 N 166 ( z0773-03 ) "Про Тимчасовий порядок проведення взаєморозрахунків між операторами телефонних мереж загального користування та операторами мереж стільникового рухомого зв'язку", зареєстрований в Міністерстві юстиції України 08.09.2003 за N 773/8094 (із змінами);

наказ Державного комітету зв'язку та інформатизації України від 14.05.2004 N 97 ( z0662-04 ) "Про Порядок проведення взаєморозрахунків між операторами мереж фіксованого зв'язку, фіксованого зв'язку з використанням безпроводового доступу, рухомого (мобільного) зв'язку", зареєстрований в Міністерстві юстиції України 25.05.2004 за N 662/9261;

наказ Міністерства транспорту та зв'язку України від 16.12.2004 N 1114 ( z1622-04 ) "Про внесення зміни до наказу Держкомзв'язку України від 14.05.2004 N 97", зареєстрований в Міністерстві юстиції України 21.12.2004 за N 1622/10221.

2. Державному департаменту з питань зв'язку та інформатизації (Яцук П.П.):

2.1. Подати цей наказ на державну реєстрацію до Міністерства юстиції України.

2.2. Забезпечити розміщення цього наказу на веб-сайті Мінтрансзв'язку.

3. Цей наказ набирає чинності з 01.01.2007.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Нетудихату Л.І.

Міністр М.Рудьковський
