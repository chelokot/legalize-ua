Про ліквідацію деяких консультативних, дорадчих та інших допоміжних органів

Текст документа від 19.02.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про ліквідацію деяких консультативних, дорадчих та інших допоміжних органів

З метою оптимізації системи консультативних, дорадчих та інших допоміжних органів, утворених для забезпечення здійснення Президентом України його конституційних повноважень, постановляю:

1. Ліквідувати:

Раду з питань виставкової діяльності в Україні;

Громадську раду експертів із внутрішньополітичних питань;

Раду з питань інформаційної політики при Президентові України;

Державну раду з питань пенсійної реформи;

Державну комісію з питань стратегії економічного та соціального розвитку;

Міжвідомчу комісію з питань усиновлення іноземцями дітей, які є громадянами України;

Антикризовий центр;

Національну раду зі сталого розвитку України;

Громадську раду з питань забезпечення реалізації виборчих прав громадян України під час проведення виборів 2006 року.

2. Визнати такими, що втратили чинність:

статті 1-4 Указу Президента України від 30 жовтня 1996 року N 1015 ( 1015/96 ) "Про заходи щодо поліпшення виставкової діяльності в Україні";

Указ Президента України від 8 жовтня 1998 року N 1130 ( 1130/98 ) "Про Положення про Координаційну раду з питань внутрішньої політики";

Указ Президента України від 30 жовтня 2000 року N 1168 ( 1168/2000 ) "Про Положення про Комісію з питань адміністративно-територіального устрою";

Указ Президента України від 4 листопада 2000 року N 1203 ( 1203/2000 ) "Про Громадську раду експертів із внутрішньополітичних питань";

Указ Президента України від 22 січня 2001 року N 31 ( 31/2001 ) "Про деякі питання діяльності Ради з питань виставкової діяльності в Україні";

Указ Президента України від 3 квітня 2001 року N 230 ( 230/2001 ) "Про Раду з питань інформаційної політики при Президентові України";

Указ Президента України від 11 червня 2001 року N 421 ( 421/2001 ) "Про Державну раду з питань пенсійної реформи";

Указ Президента України від 30 жовтня 2001 року N 1019 ( 1019/2001 ) "Про внесення змін до Указу Президента України від 30 жовтня 1996 року N 1015";

Указ Президента України від 5 грудня 2001 року N 1191 ( 1191/2001 ) "Про Державну комісію з питань стратегії економічного та соціального розвитку";

Указ Президента України від 17 січня 2002 року N 34 ( 34/2002 ) "Про Міжвідомчу комісію з питань усиновлення іноземцями дітей, які є громадянами України";

Указ Президента України від 5 листопада 2002 року N 991 ( 991/2002 ) "Про Антикризовий центр";

статтю 1 Указу Президента України від 4 лютого 2003 року N 76 ( 76/2003 ) "Про рішення Ради національної безпеки і оборони України від 11 листопада 2002 року "Про стан техногенної та природної безпеки в Україні";

3. Главі Секретаріату Президента України здійснити заходи, пов'язані з ліквідацією зазначених у статті 1 Указу консультативних, дорадчих та інших допоміжних органів.

4. Кабінету Міністрів України привести свої рішення у відповідність із цим Указом.
