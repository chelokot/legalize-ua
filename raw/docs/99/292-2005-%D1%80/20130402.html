КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 липня 2005 р. N 292-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про голову робочої групи з координації роботи щодо ефективного використання нежитлових будинків та приміщень у м. Києві, які належать до державної власності

Затвердити головою робочої групи з координації роботи щодо ефективного використання нежитлових будинків та приміщень у м. Києві, які належать до державної власності ( 605-2002-р ), Голову Фонду державного майна Семенюк Валентину Петрівну, увільнивши від цих обов'язків Чечетова Михайла Васильовича.

Прем'єр-міністр України Ю.ТИМОШЕНКО
