Текст документа від 01.01.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 червня 2009 р. N 614 Київ

Про внесення змін до постанов Кабінету Міністрів України від 3 грудня 1997 р. N 1349 і від 3 червня 2009 р. N 549

{ Із змінами, внесеними згідно з Постановою КМ N 664 ( 664-2014-п ) від 26.11.2014 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 664 ( 664-2014-п ) від 26.11.2014 }

2. У постанові Кабінету Міністрів України від 3 червня 2009 р. N 549 ( 549-2009-п ) "Про запровадження обмежень щодо проведення перевірок діяльності сільських та селищних рад, їх виконавчих органів і посадових осіб" (Офіційний вісник України, 2009 р., N 42, ст. 1402):

1) у пункті 1:

в абзаці першому слова "Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським, районним державним адміністраціям" замінити словами "Державній автомобільній інспекції (стосовно здійснення контролю за утриманням автомобільних доріг, вулиць), Раді міністрів Автономної Республіки Крим, обласним, Севастопольській міській, районним, районним у м. Севастополі державним адміністраціям";

в абзаці другому підпункту 1 слова ", пожежної безпеки" замінити словами "і пожежної безпеки на об'єктах, що перебувають у власності відповідної територіальної громади";

2) доповнити пункт 2 абзацом такого змісту:

"Установити, що протягом зазначеного періоду органи виконавчої влади здійснюють контроль за виконанням органами місцевого самоврядування делегованих їм повноважень лише у разі забезпечення державою відповідного фінансування.".

3. Ця постанова набирає чинності з дня опублікування, крім пункту 1, який набирає чинності з 1 січня 2010 року.
