Про передачу будинку в оперативне управління Центрвиборчкому

Стан: Втратив чинність

Ідентифікатор: 452-2004-р

Текст документа від 28.10.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 липня 2004 р. N 452-р Київ

Про передачу будинку в оперативне управління Центрвиборчкому

( Із змінами, внесеними згідно з Розпорядженням КМ N 795-р ( 795-2004-р ) від 28.10.2004 )

Прийняти пропозицію Центрвиборчкому щодо передачі будинку Українського науково-дослідного інституту цукрової промисловості загальною площею 7030 кв. метрів по вул. Лютеранській, 20, у м. Києві в оперативне управління Центрвиборчкому.

Дозволити Центрвиборчкому компенсувати незаплановані витрати Українського науково-дослідного інституту цукрової промисловості на ремонтні роботи у зв'язку з переїздом в інше приміщення в сумі до 2,5 млн. гривень. ( Розпорядження доповнено абзацом згідно з Розпорядженням КМ N 795-р ( 795-2004-р ) від 28.10.2004 )
