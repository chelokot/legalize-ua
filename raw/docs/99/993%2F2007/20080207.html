Президент України; Указ від 24.10.2007 № 993/2007

Про утворення делегації України для участі у переговорах між Україною та Алжирською Народною Демократичною Республікою щодо підготовки проекту Договору між Україною та Алжирською Народною Демократичною Республікою про взаємну правову допомогу у кримінальних справах

Стан: Втратив чинність

Ідентифікатор: 993/2007

Текст документа від 07.02.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про утворення делегації України для участі у переговорах між Україною та Алжирською Народною Демократичною Республікою щодо підготовки проекту Договору між Україною та Алжирською Народною Демократичною Республікою про взаємну правову допомогу у кримінальних справах

1. Утворити делегацію України для участі у переговорах між Україною та Алжирською Народною Демократичною Республікою щодо підготовки проекту Договору між Україною та Алжирською Народною Демократичною Республікою про взаємну правову допомогу у кримінальних справах (м. Алжир, Алжирська Народна Демократична Республіка) у такому складі:

ЛУТКОВСЬКА - заступник Міністра юстиції України,

Валерія Володимирівна глава делегації

КОВАЛЕНКО - начальник відділу міжнародно-правового Олександр Володимирович управління Генеральної прокуратури України (за згодою)

МАРЧЕНКО - завідувач відділу Головної

Людмила Іванівна державно-правової служби Секретаріату Президента України

СИБІГА - заступник директора

Андрій Іванович Договірно-правового департаменту Міністерства закордонних справ України

СЛИЗЬКИЙ - начальник відділу Головного слідчого

Олександр Іванович управління Міністерства внутрішніх справ України

ШЕВЧЕНКО - заступник директора Департаменту

Катерина Георгіївна міжнародного співробітництва Міністерства юстиції України.

Дозволити главі делегації вносити в разі потреби зміни до складу делегації України, залучаючи до її роботи членів Експертної групи з підготовки проектів міжнародних договорів України про правові відносини та правову допомогу у цивільних і кримінальних справах, утвореної Указом Президента України від 24 квітня 2004 року N 476 ( 476/2004 ).

2. Міністерству юстиції України за погодженням з Міністерством закордонних справ України затвердити вказівки делегації України на переговори.

3. Кабінету Міністрів України вирішити питання щодо виділення коштів в іноземній валюті для забезпечення участі у переговорах делегації України.

Президент України В.ЮЩЕНКО
