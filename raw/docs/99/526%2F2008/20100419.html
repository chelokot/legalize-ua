Про внесення зміни до Указу Президента України від 12 жовтня 2005 року N 1435

На зміну статті 2 Указу Президента України від 12 жовтня 2005 року N 1435 ( 1435/2005 ) "Про Політичну раду при Президентові України" (зі змінами, внесеними Указами від 17 травня 2006 року N 410 ( 410/2006 ) та від 18 жовтня 2006 року N 885) ( 885/2006 ) призначити КИСЛИНСЬКОГО Андрія Миколайовича - заступника Глави Секретаріату Президента України - секретарем Політичної ради при Президентові України, увільнивши від виконання цих обов'язків І. Васюника.
