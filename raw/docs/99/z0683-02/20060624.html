МІНІСТЕРСТВО ОСВІТИ І НАУКИ УКРАЇНИ

НАКАЗ

N 453 від 08.08.2002 Зареєстровано в Міністерстві м. Київ юстиції України 20 серпня 2002 р. N 683/6971

Про упорядкування умов оплати праці працівників окремих бюджетних наукових установ Міністерства освіти і науки України

{ Із змінами, внесеними згідно з Наказами Міністерства освіти і науки N 71 ( z0191-04 ) від 29.01.2004 N 161 ( z0301-04 ) від 26.02.2004 N 713 ( z1131-04 ) від 08.09.2004 N 42 ( z0113-05 ) від 25.01.2005 N 335 ( z0645-05 ) від 03.06.2005 N 149 ( z0269-06 ) від 03.03.2006 N 425 ( z0704-06 ) від 01.06.2006 }

Відповідно до постанови Кабінету Міністрів України від 02.12.1996 N 1442 ( 1442-96-п ) "Про посадові оклади керівних і наукових працівників Національного наукового центру "Харківський фізико-технічний інститут", Кримської астрофізичної обсерваторії та Миколаївської астрономічної обсерваторії", розпорядження Кабінету Міністрів України від 17 червня 2004 року N 381-р ( 381-2004-р ) "Про умови оплати праці працівників Науково-дослідного інституту українознавства" та з метою упорядкування умов оплати праці керівних і наукових працівників зазначених наукових установ НАКАЗУЮ:

{ Преамбула із змінами, внесеними згідно з Наказом Міністерства освіти і науки N 149 ( z0269-06 ) від 03.03.2006 }

1. Затвердити розміри посадових окладів керівних і наукових працівників Науково-дослідного інституту українознавства, науково-дослідного інституту "Кримська астрофізична обсерваторія" та науково-дослідного інституту "Миколаївська астрономічна обсерваторія", які розроблені відповідно до схем посадових окладів керівних і наукових працівників, затверджених постановою Кабінету Міністрів України від 31.01.2001 N 74 ( 74-2001-п ) "Про умови оплати праці працівників бюджетних науково-дослідних установ і організацій та інших наукових установ Національної академії наук", згідно з додатком.

{ Пункт 1 із змінами, внесеними згідно з Наказом Міністерства освіти і науки N 149 ( z0269-06 ) від 03.03.2006 }

2. Надати право керівникам Науково-дослідного інституту українознавства, науково-дослідного інституту "Кримська астрофізична обсерваторія" та науково-дослідного інституту "Миколаївська астрономічна обсерваторія" (далі - установи) в межах фонду заробітної плати, затвердженого в кошторисі:

1) установлювати:

а) конкретні посадові оклади керівним і науковим працівникам цих установ, згідно з додатком. У разі, коли встановлені для працівників відповідно до цього наказу посадові оклади (ставки заробітної плати) нижчі, ніж діючі посадові оклади (ставки заробітної плати), таким працівникам на період роботи в установі, закладі та організації на цій посаді зберігається діючий розмір посадового окладу (ставки заробітної плати). ( Підпункт 1 "а" пункту 2 із змінами, внесеними згідно з Наказом Міністерства освіти і науки N 335 ( z0645-05 ) від 03.06.2005 )

б) посадові оклади (ставки заробітної плати) спеціалістам, службовцям та робітникам установ у розмірах, передбачених наказом Міністерства освіти і науки України від 29.03.2001 N 161 ( z0303-01 ) "Про затвердження розмірів посадових окладів (ставок заробітної плати) працівників навчальних закладів, установ освіти та наукових установ", зареєстрованим Міністерством юстиції України 03.04.2001 за N 303/5494 (із змінами, унесеними наказами Міністерства освіти і науки України: від 22.10.2001 N 697 ( z0925-01 ) та від 25.02.2002 N 145) ( z0234-02 ), від 30.05.2003 N 338 ( z0465-03 ); ( Підпункт "б" пункту 2 із змінами, внесеними згідно з Наказом Міністерства освіти і науки N 71 ( z0191-04 ) від 29.01.2004 )

в) посадові оклади заступникам керівників установ, заступникам керівників структурних підрозділів цих установ на 5 - 15 відсотків, головним бухгалтерам - на 10 - 30 відсотків, помічникам керівників - на 30 - 40 відсотків нижче, ніж посадовий оклад відповідного керівника;

г) підвищені посадові оклади (ставки заробітної плати) працівникам установ, які мають почесні звання: за почесні звання України, СРСР: "народний" - на 40 відсотків, "заслужений" - на 20 відсотків.

За наявності двох або більше звань посадові оклади (ставки заробітної плати) працівників підвищуються за одним (вищим) званням.

Посадові оклади (ставки заробітної плати) працівників установ підвищуються, якщо діяльність працівників за профілем відповідає почесному званню".

( Підпункт 1 "г" пункту 2 в редакції Наказу Міністерства освіти і науки N 335 ( z0645-05 ) від 03.06.2005 )

ґ) прибиральникам приміщень, які використовують дезінфекційні засоби, а також тим, що зайняті прибиранням туалетів, - підвищення місячних посадових окладів на 10 відсотків;

д) доплати працівникам у розмірі до 50 відсотків посадового окладу відсутнього працівника або за вакантною посадою:

за виконання обов'язків тимчасово відсутніх працівників;

за суміщення професій (посад);

за розширення зони обслуговування або збільшення обсягу виконуваних робіт.

Зазначені види доплат не встановлюються керівникам установ, їх заступникам, керівникам структурних підрозділів цих установ та їх заступникам;

е) доплати працівникам у розмірі до 40 відсотків годинної тарифної ставки (посадового окладу) за роботу в нічний час, якщо вищий розмір не визначено законодавством, за кожну годину роботи з 10 години вечора до 6 години ранку;

є) надбавки працівникам у розмірі до 50 відсотків посадового окладу:

за високі досягнення у праці;

за виконання особливо важливої роботи (на термін її виконання);

за складність, напруженість роботи.

Граничний розмір зазначених надбавок для одного працівника не повинен перевищувати 50 відсотків посадового окладу. Це обмеження не поширюється на працівників національних установ.

У разі несвоєчасного виконання завдань, погіршення якості роботи і порушення трудової дисципліни зазначені надбавки скасовуються або розмір їх зменшується;

ж) водіям автомобілів:

надбавки за класність у таких розмірах: водіям 2-го класу - 10 відсотків, водіям 1-го класу - 25 відсотків установленої тарифної ставки за відпрацьований час;

доплати за ненормований робочий день у розмірі 25 відсотків тарифної ставки за відпрацьований час;

з) доплати працівникам за:

вчене звання професора - у граничному розмірі 33 відсотки посадового окладу (ставки заробітної плати);

вчене звання доцента, старшого наукового співробітника - у граничному розмірі 25 відсотків посадового окладу (ставки заробітної плати);

науковий ступінь доктора наук - у граничному розмірі 25 відсотків посадового окладу (ставки заробітної плати);

науковий ступінь кандидата наук - у граничному розмір 15 відсотків посадового окладу (ставки заробітної плати).

Доплати встановлюються, якщо діяльність працівника за профілем відповідає вченому званню або науковому ступеню.

( Пункт 2 доповнено підпунктом 1 "з" згідно з Наказом Міністерства освіти і науки N 335 ( z0645-05 ) від 03.06.2005 )

2) надавати працівникам матеріальну допомогу, в тому числі на оздоровлення, за винятком матеріальної допомоги на поховання, в сумі не більше ніж один посадовий оклад на рік;

3) затверджувати порядок і розміри преміювання працівників відповідно до їх особистого внеску в загальні результати роботи. { Пункт 2 із змінами, внесеними згідно з Наказом Міністерства освіти і науки N 149 ( z0269-06 ) від 03.03.2006 }

3. Контроль за виконанням наказу покласти на заступника Державного секретаря Богомолова А.Г.

4. Наказ Міністерства України у справах науки і технологій від 25 квітня 1997 року N 105 скасувати.

В.о.Міністра А.М. Гуржій
