КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 серпня 2002 р. N 1227 Київ

Деякі питання Державного комітету у справах сім'ї та молоді

{ Із змінами, внесеними згідно з Постановою КМ N 954 ( 954-2008-п ) від 22.10.2008 }

З метою забезпечення виконання Державним департаментом з питань молодіжної політики завдань, спрямованих на залучення молоді до участі у державних та громадських справах, розв'язання проблем її працевлаштування, розвиток молодіжного підприємництва, пропаганду здорового способу життя, підтримку творчої та обдарованої молоді, Кабінет Міністрів України постановляє:

Внести зміни до таких постанов Кабінету Міністрів України:

у додатку 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р. N 9, ст. 339; 2001 р., N 20, ст. 851, N 51, ст. 2291) у позиції "Державний комітет у справах сім'ї та молоді" цифри "90" і "4" замінити відповідно цифрами "100" і "5";

{ Абзац третій постановляючої частини втратив чинність на підставі Постанови КМ N 954 ( 954-2008-п ) від 22.10.2008 }
