( Постанова втратила чинність на підставі Постанови КМ N 34 ( 34-2001-п ) від 22.01.2001 )

Про склад Державної міжвідомчої комісії з соціально-економічних питань вугільних регіонів

Кабінет Міністрів України постановляє:

Затвердити новий склад Державної міжвідомчої комісії з соціально-економічних питань вугільних регіонів, утвореної постановою Кабінету Міністрів України від 27 червня 1996 р. N 686 ( 686-96-п ) "Про Державну міжвідомчу комісію з соціально-економічних питань вугільних регіонів" (ЗП України, 1996 р. N 14, ст. 382), що додається.
