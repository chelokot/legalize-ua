Кабінет Міністрів України постановляє:

1. Визначити межі акваторії морського порту Чорноморськ згідно з додатком.

{ Пункт 1 в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013; із змінами, внесеними згідно з Постановою КМ N 46 ( 46-2017-п ) від 25.01.2017 }

2. Державному підприємству "Адміністрація морських портів України" забезпечити безпеку мореплавства в межах акваторії.

{ Пункт 3 виключено на підставі Постанови КМ N 480 ( 480-2019-п ) від 05.06.2019 }
