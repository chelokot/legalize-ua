КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 жовтня 2007 р. N 1278 Київ

Про межі акваторії морського порту Чорноморськ

{ Назва Постанови в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013; із змінами, внесеними згідно з Постановою КМ N 46 ( 46-2017-п ) від 25.01.2017 }

{ Із змінами, внесеними згідно з Постановами КМ N 406 ( 406-2013-п ) від 03.06.2013 N 46 ( 46-2017-п ) від 25.01.2017 }

Кабінет Міністрів України постановляє:

1. Визначити межі акваторії морського порту Чорноморськ згідно з додатком.

{ Пункт 1 в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013; із змінами, внесеними згідно з Постановою КМ N 46 ( 46-2017-п ) від 25.01.2017 }

2. Державному підприємству "Адміністрація морських портів України" забезпечити безпеку мореплавства в межах акваторії.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 406 ( 406-2013-п ) від 03.06.2013 }

3. Міністерству інфраструктури разом з Держкомрибгоспом розробити механізм взаємодії державного підприємства "Чорноморський морський торговельний порт" з державним підприємством "Морська адміністрація Чорноморського рибного порту" з питань забезпечення безпеки мореплавства в межах акваторії.

{ Пункт 3 із змінами, внесеними згідно з Постановами КМ N 406 ( 406-2013-п ) від 03.06.2013, N 46 ( 46-2017-п ) від 25.01.2017 }
