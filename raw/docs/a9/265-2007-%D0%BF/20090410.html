Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для здійснення заходів з виконання Національної програми сприяння розвитку малого підприємництва в Україні

Стан: Чинний

Ідентифікатор: 265-2007-п

Текст документа від 10.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 лютого 2007 р. N 265 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для здійснення заходів з виконання Національної програми сприяння розвитку малого підприємництва в Україні

{ Із змінами, внесеними згідно з Постановою КМ N 78 ( 78-2008-п ) від 22.02.2008 N 298 ( 298-2009-п ) від 02.04.2009 }

{ Установити, що у 2009 році кошти, передбачені у державному бюджеті ( 835-17 ) для здійснення заходів з виконання Національної програми сприяння розвитку малого підприємництва в Україні, використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 298 ( 298-2009-п ) від 02.04.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для здійснення заходів ( 28-2007-р ) з виконання Національної програми сприяння розвитку малого підприємництва в Україні ( 2157-14 ), що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 25

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 лютого 2007 р. N 265

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для здійснення заходів ( 28-2007-р ) з виконання Національної програми сприяння розвитку малого підприємництва в Україні ( 2157-14 )

{ У тексті Порядку слово "Держпідприємництво" у всіх відмінках замінено словом "Держкомпідприємництво" у відповідному відмінку згідно з Постановою КМ N 78 ( 78-2008-п ) від 22.02.2008 }

Загальна частина

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті ( 489-16 ) Держкомпідприємництву за програмою 8681030 "Заходи по реалізації Національної програми сприяння розвитку малого підприємництва в Україні у 2007 році" (далі - бюджетні кошти).

Напрями спрямування бюджетних коштів

2. Бюджетні кошти спрямовуються на:

забезпечення виконання освітньої програми з питань провадження підприємницької діяльності для підприємців та широких верств населення, зокрема, щодо започаткування та ведення власної справи, застосування дозвільних процедур, реєстрації, ліцензування, реалізації регуляторної політики;

проведення Всеукраїнського конкурсу бізнес-планів підприємницької діяльності серед молоді;

проведення конференцій, нарад, засідань за круглим столом, форумів, виставок та ярмарків за участю представників малого підприємництва, відзначення Дня підприємця;

організацію проведення презентації-обговорення з питань впровадження в Україні принципів Європейської хартії для малих підприємств ( 994_860 ).

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 78 ( 78-2008-п ) від 22.02.2008; в редакції Постанови КМ N 298 ( 298-2009-п ) від 02.04.2009 }

Вимоги щодо використання бюджетних коштів

3. Видатки здійснюються згідно з планом заходів щодо виконання Національної програми сприяння розвитку малого підприємництва в Україні, затвердженим Кабінетом Міністрів України. { Абзац перший пункту 3 в редакції Постанови КМ N 78 ( 78-2008-п ) від 22.02.2008 }

Відповідно до розподілу бюджетних коштів за напрямами, зазначеними у пункті 2 цього Порядку, Держкомпідприємництво затверджує перелік робіт та їх кошторис.

4. Перерахування бюджетних коштів здійснюється відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 4 в редакції Постанови КМ N 298 ( 298-2009-п ) від 02.04.2009 }

5. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється в установленому законодавством порядку.

{ Пункт 5 в редакції Постанови КМ N 298 ( 298-2009-п ) від 02.04.2009 }

Звітність про використання бюджетних коштів та контроль за їх витрачанням

6. Відповідальність за цільове використання бюджетних коштів несе Держкомпідприємництво.

7. Держкомпідприємництво подає щокварталу до 20 числа місяця, що настає за звітним періодом, Мінфіну інформацію про стан виконання результативних показників відповідно до паспорта бюджетної програми разом із висновками про виконання зазначених показників та пропозиціями щодо врегулювання проблемних питань.

8. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюється в установленому законодавством порядку.
