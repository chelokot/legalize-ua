Зареєстровано в Міністерстві юстиції України 29 грудня 2010 р. за N 1405/18700

Про втрату чинності наказів ДПА України

Відповідно до Податкового кодексу України ( 2755-17 ), статті 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ) НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази ДПА України:

від 17.03.2001 N 110 ( z0268-01 ) "Про затвердження Інструкції про порядок застосування та стягнення сум штрафних (фінансових) санкцій органами державної податкової служби", зареєстрований у Міністерстві юстиції України 25.03.2001 за N 268/5459;

від 11.03.2002 N 98 ( z0327-02 ) "Про внесення змін та доповнень до наказів Державної податкової адміністрації України", зареєстрований у Міністерстві юстиції України 02.04.2002 за N 327/6615;

від 11.04.2003 N 174 ( z0334-03 ) "Про затвердження Змін та доповнень до Інструкції про порядок застосування штрафних (фінансових) санкцій органами державної податкової служби", зареєстрований у Міністерстві юстиції України 25.04.2003 за N 334/7655;

від 10.08.2005 N 326 ( z0924-05 ) "Про затвердження Змін та доповнень до Інструкції про порядок застосування штрафних (фінансових) санкцій органами державної податкової служби", зареєстрований у Міністерстві юстиції України 25.08.2005 за N 924/11204.

2. Департаменту податкового контролю юридичних осіб (Удачина І.М.):

2.1. В установленому порядку подати цей наказ на державну реєстрацію до Міністерства юстиції України.

2.2. Забезпечити оприлюднення цього наказу.

3. Державним податковим адміністраціям в Автономній Республіці Крим, областях, мм. Києві та Севастополі забезпечити доведення цього наказу до підпорядкованих податкових органів.

4. Цей наказ набирає чинності з дня офіційного опублікування.

5. Контроль за виконанням цього наказу покласти на заступника Голови Носачову І.В.
