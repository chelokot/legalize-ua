N 87 від 27.03.97 Зареєстровано в Міністерстві м.Київ юстиції України 21 квітня 1997 р. за N 151/1955

{ Наказ втратив чинність на підставі Наказу Міністерства освіти і науки N 1060 ( z1205-14 ) від 19.09.2014 }

Про затвердження Положення про державну атестацію (екстернат) для одержання документів про загальну середню освіту

( Із змінами, внесеними згідно з Наказом МОН N 588 ( z0925-00 ) від 14.12.2000 )

На виконання Закону України "Про внесення змін і доповнень до Закону Української РСР "Про освіту" ( 100/96-ВР ), з метою створення умов для здобуття громадянами повної загальної середньої освіти у формі екстернату НАКАЗУЮ :

1. Затвердити Положення про державну атестацію (екстернат) для одержання документів про загальну середню освіту (додається).

2. Вважати таким, що втратив чинність, підпункт 1.2 пункту 1 наказу Міносвіти від 01.07.93 N 230 ( z0098-93 ) "Про затвердження Положення про індивідуальне навчання в системі загальної середньої освіти, Положення про державну атестацію (екстернат) для одержання документів про загальну середню освіту, Положення про психологічну службу в системі освіти України".

3. Міністру освіти Автономної Республіки Крим, начальникам управлінь освіти обласних, Київської та Севастопольської міських держадміністрацій, директорам середніх закладів освіти забезпечити виконання цього Положення.

4. Контроль за виконанням наказу покласти на Першого заступника Міністра Зайчука В.О.

Міністр М.З.Згуровський
