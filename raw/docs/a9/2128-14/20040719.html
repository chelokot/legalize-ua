Верховна Рада України; Закон від 07.12.2000 № 2128-III

Про чисельність Збройних Сил України на 2000-2004 роки

Стан: Чинний

Ідентифікатор: 2128-14

Текст документа від 19.07.2004:

ЗАКОН УКРАЇНИ

Про чисельність Збройних Сил України на 2000-2004 роки

( Назва Закону в редакції Закону N 1825-IV ( 1825-15 ) від 22.06.2004 )

( Відомості Верховної Ради України (ВВР), 2001, N 4, ст.13 )

( Із змінами, внесеними згідно із Законами N 1449-IV ( 1449-15 ) від 05.02.2004, ВВР, 2004, N 19, ст.269 N 1825-IV ( 1825-15 ) від 22.06.2004, ВВР, 2004, N 38, ст.472 )

Стаття 1. Затвердити чисельність Збройних Сил України за станом на:

30 грудня 2000 року - 30 грудня 2001 року - у кількості 400000 чоловік, у тому числі 310000 військовослужбовців;

30 грудня 2002 року - у кількості 394750 чоловік, у тому числі 307500 військовослужбовців;

30 грудня 2003 року - у кількості 390000 чоловік, у тому числі 305000 військовослужбовців;

30 грудня 2004 року - у кількості до 285000 чоловік, у тому числі 210000 військовослужбовців; ( Абзац п'ятий статті 1 в редакції Закону N 1825-IV ( 1825-15 ) від 22.06.2004 )

( Абзац шостий статті 1 виключено на підставі Закону N 1825-IV ( 1825-15 ) від 22.06.2004 )

( Щодо чисельності Збройних Сил див. Закон N 1449-IV ( 1449-15 ) від 05.02.2004 )

Стаття 2. Чисельність військових підрозділів Збройних Сил України, які направляються Україною для участі у міжнародних миротворчих операціях, у тому числі і військових підрозділів, що входять до складу об'єднаних військових підрозділів, створюваних спільно з іноземними державами, не входить до чисельності, визначеної статтею 1 цього Закону.

Стаття 3. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 7 грудня 2000 року N 2128-III
