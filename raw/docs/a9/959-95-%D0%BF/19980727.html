Кабінет Міністрів України; Постанова від 01.12.1995 № 959

Про встановлення тимчасових норм споживання населенням електроенергії та природного газу, на оплату яких надається субсидія

Стан: Втратив чинність

Ідентифікатор: 959-95-п

Текст документа від 27.07.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 грудня 1995 р. N 959 Київ

Про встановлення тимчасових норм споживання населенням електроенергії та природного газу, на оплату яких надається субсидія

( Із змінами, внесеними згідно з Постановами КМ N 479 ( 479-97-п ) від 22.05.97 N 1156 ( 1156-98-п ) від 27.07.98 )

Кабінет Міністрів України постановляє:

1. Встановити, що з 1 листопада 1995 р. при нарахуванні населенню субсидій для відшкодування витрат на оплату житлово-комунальних послуг до них включається спожита електроенергія. ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1156 ( 1156-98-п ) від 27.07.98 )

Затвердити для розрахунку субсидій тимчасові норми споживання електроенергії населенням за місяць на абонента:

у будинках, обладнаних стаціонарними електроплитами, - 100 кВт.год. на сім'ю з однієї - двох осіб і додатково 25 кВт.год. на кожного іншого члена сім'ї, але не більше 200 кВт.год;

у будинках, обладнаних електроопалювальними установками, - 28 кВт.год на 1 кв. метр опалюваної площі в опалювальний період із розрахунку 21 кв. метр опалюваної площі на одну особу і додатково 10,5 кв. метра на сім'ю, але не більше загального розміру опалюваної площі; ( Пункт 1 доповнено абзацом четвертим згідно з Постановою КМ N 479 ( 479-97-п ) від 22.05.97 )

в інших будинках - 75 кВт.год. на сім'ю з однієї - двох осіб і додатково 15 кВт.год. на кожного іншого члена сім'ї, але не більше 150 кВт.год.

2. Встановити, що при нарахуванні населенню субсидій для відшкодування витрат на оплату за користування природним газом у жилих приміщеннях, обладнаних газовими лічильниками, використовується фактичне споживання, але не вище норм, що встановлені для приміщень, не обладнаних ними.
