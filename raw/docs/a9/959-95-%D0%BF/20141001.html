Кабінет Міністрів України; Постанова від 01.12.1995 № 959

Про встановлення тимчасових норм споживання населенням електроенергії та природного газу, на оплату яких надається субсидія

Стан: Втратив чинність

Ідентифікатор: 959-95-п

Текст документа від 01.10.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 грудня 1995 р. N 959 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 409 ( 409-2014-п ) від 06.08.2014 }

Про встановлення тимчасових норм споживання населенням електроенергії та природного газу, на оплату яких надається субсидія

( Із змінами, внесеними згідно з Постановами КМ N 479 ( 479-97-п ) від 22.05.97 N 1156 ( 1156-98-п ) від 27.07.98 N 1740 ( 1740-2003-п ) від 07.11.2003 )

Кабінет Міністрів України постановляє:

1. Встановити, що з 1 листопада 1995 р. при нарахуванні населенню субсидій для відшкодування витрат на оплату житлово-комунальних послуг до них включається спожита електроенергія. ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1156 ( 1156-98-п ) від 27.07.98 )

Затвердити для розрахунку субсидій тимчасові норми споживання електроенергії населенням за місяць на абонента:

у будинках, обладнаних стаціонарними електроплитами, - 100 кВт.год. на сім'ю з однієї - двох осіб і додатково 25 кВт.год. на кожного іншого члена сім'ї, але не більше 200 кВт.год;

у будинках, обладнаних електроопалювальними установками, - 28 кВт.год на 1 кв. метр опалюваної площі в опалювальний період із розрахунку 21 кв. метр опалюваної площі на одну особу і додатково 10,5 кв. метра на сім'ю, але не більше загального розміру опалюваної площі; ( Пункт 1 доповнено абзацом четвертим згідно з Постановою КМ N 479 ( 479-97-п ) від 22.05.97 )

в інших будинках - 75 кВт.год. на сім'ю з однієї - двох осіб і додатково 15 кВт.год. на кожного іншого члена сім'ї, але не більше 150 кВт.год.

Надати право місцевим органам виконавчої влади та органам місцевого самоврядування у разі використання населенням побутових електроприладів для обігріву приміщень у зв'язку з припиненням згідно з їх рішенням централізованого теплопостачання приймати рішення щодо застосування для розрахунку субсидій в опалювальний сезон норм споживання електроенергії, встановлених для будинків, обладнаних електроопалювальними установками. Зазначені розрахунки здійснюються починаючи з опалювального сезону 2003/04 року на підставі акта обстеження матеріально-побутових умов сім'ї та акта обстеження стану зовнішніх і внутрішньобудинкових електромереж на їх відповідність вимогам нормативно-правових актів. ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 1740 ( 1740-2003-п ) від 07.11.2003 )

2. Встановити, що під час нарахування населенню субсидій для відшкодування витрат на оплату за користування природним газом та електроенергією у житлових приміщеннях, обладнаних лічильниками, використовується обсяг їх фактичного споживання, але не вище норм, встановлених цією постановою та постановою Кабінету Міністрів України від 8 червня 1996 р. N 619 ( 619-96-п ) (ЗП України, 1996 р., N 13, ст. 360). ( Пункт 2 в редакції Постанови КМ N 1740 ( 1740-2003-п ) від 07.11.2003 )
