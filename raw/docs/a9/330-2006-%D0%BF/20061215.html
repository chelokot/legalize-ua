Текст документа від 15.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 березня 2006 р. N 330 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1695 ( 1695-2006-п ) від 08.12.2006 }

Про внесення змін до переліку органів ліцензування

Кабінет Міністрів України постановляє:

Внести до графи "Вид господарської діяльності" переліку органів ліцензування, затвердженого постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001; 2004 р., N 25, ст. 1650, N 46, ст. 3046; 2005 р., N 25, ст. 1433, N 52, ст. 3293), такі зміни:

пункт 3 доповнити абзацом такого змісту:

"видобуток дорогоцінних металів і дорогоцінного каміння, дорогоцінного каміння органогенного утворення, напівдорогоцінного каміння";

абзац другий пункту 14 виключити.
