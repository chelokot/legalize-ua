КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 вересня 2000 р. N 1421 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1236 ( 1236-2010-п ) від 27.12.2010 }

Про внесення змін до деяких постанов Кабінету Міністрів України

Відповідно до Указу Президента України від 14 липня 2000 р. N 898 ( 898/2000 ) "Про Положення про Державний комітет України по водному господарству" Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 18 травня 1999 р. N 836 ( 836-99-п ) "Про затвердження нормативів збору за спеціальне використання водних ресурсів та збору за користування водами для потреб гідроенергетики і водного транспорту" (Офіційний вісник України, 1999 р., N 20, ст. 889; 1999 р., N 30, ст. 1533), від 29 липня 1999 р. N 1379 ( 1379-99-п ) "Про затвердження переліку платних послуг, які можуть надаватися бюджетними установами та організаціями, що належать до сфери управління Комітету водного господарства, на замовлення юридичних і фізичних осіб" (Офіційний вісник України, 1999 р., N 31, ст. 1611) та від 16 серпня 1999 р. N 1494 ( 1494-99-п ) "Про затвердження Порядку справляння збору за спеціальне використання водних ресурсів та збору за користування водами для потреб гідроенергетики і водного транспорту" (Офіційний вісник України, 1999 р., N 33, ст. 1734), такі зміни:

1) у тексті постанов слова "Комітет водного господарства" і "Міністерство охорони навколишнього природного середовища та ядерної безпеки" в усіх відмінках замінити відповідно словами "Державний комітет по водному господарству" та "Міністерство екології та природних ресурсів" у необхідному відмінку;

2) у Порядку справляння збору за спеціальне використання водних ресурсів та збору за користування водами для гідроенергетики і водного транспорту, затвердженому постановою Кабінету Міністрів України від 16 серпня 1999 р. N 1494:

слово "Мінекобезпеки" замінити словом "Мінекоресурсів";

у пункті 21 слова "Комітету водного господарства" замінити словом "Держводгоспу".

Прем'єр-міністр України В.ЮЩЕНКО
