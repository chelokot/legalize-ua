Про продовження виплати одноразової грошової компенсації, передбаченої пунктом 5 постанови Кабінету Міністрів України від 16 червня 1992 р. N 332

Стан: Чинний

Ідентифікатор: 1096-97-п

Текст документа від 03.10.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 жовтня 1997 р. N 1096 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про продовження виплати одноразової грошової компенсації, передбаченої пунктом 5 постанови Кабінету Міністрів України від 16 червня 1992 р. N 332

Кабінет Міністрів України постановляє:

Продовжити до 31 грудня 1997 р. виплату одноразової грошової компенсації, передбаченої пунктом 5 постанови Кабінету Міністрів України від 16 червня 1992 р. N 332 ( 332-92-п ) "Про вдосконалення грошового забезпечення військовослужбовців Збройних Сил України".

В абзаці першому пункту 5 зазначеної постанови ( 332-92-п ) цифри і слова "100-кратної мінімальної заробітної плати на час виплати компенсації" замінити цифрами і словами "670 гривень".

Виплату одноразової компенсації здійснювати за рахунок кошторису Міністерства оборони.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
