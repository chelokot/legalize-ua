ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 147 від 12.05.97 Зареєстровано в юридичному м.Київ департаменті Нацбанку 12 травня 1997 р. vd970512 vn147 за N 441

Про затвердження Переліку і Тарифів банківських послуг, що надаються установами та регіональними управліннями Національного банку України за операціями (послугами), пов'язаними з діяльністю клієнтів і банків-кореспондентів Національного банку України

( Із змінами, внесеними згідно з Постановами Нацбанку N 381 ( v0496500-97 ) від 17.11.97 N 46 ( v0522500-98 ) від 12.02.98 N 210 ( v0547500-98 ) від 22.05.98 N 466 ( v0587500-98 ) від 06.11.98 )

Відповідно до статті 9 Статуту Національного банку України ( 1605-12 ) Правління постановляє:

1. Затвердити Перелік і Тарифи банківських послуг, що надаються установами та регіональними управліннями Національного банку України за операціями (послугами), пов'язаними з діяльністю клієнтів і банків-кореспондентів (додатки NN 1-8 додаються).

( Пункт 2 втратив чинність на підставі Постанови Нацбанку N 381 ( v0496500-97 ) від 17.11.97 ) 2. При переході на розрахункове обслуговування з використанням системи електронних платежів "Клієнт банку - Банк" керуватись додатком N 5, який у цьому разі вважається як додаток N 2 до Типового договору "Про банківське обслуговування з використанням програмно-технічного комплексу "Клієнт - Банк".

( Пункт 3 втратив чинність на підставі Постанови Нацбанку N 381 ( v0496500-97 ) від 17.11.97 ) 3. Тарифи на платні послуги вводяться згідно з порядком розрахунків, обумовлених при укладанні договорів між Національним банком України та клієнтами і банками-кореспондентами (далі - "Клієнт") на надання їм цих послуг.

( Пункт 4 втратив чинність на підставі Постанови Нацбанку N 381 ( v0496500-97 ) від 17.11.97 ) 4. На послуги, щодо яких не вказано розмір плати, регіональні управління й установи Національного банку України самостійно встановлюють тарифи з урахуванням реальних витрат та рентабельності на покриття витрат, що передбачені умовами оплати праці, і на розвиток виробництва, але не більш як 30 відсотків, з коригуванням тарифів на індекс інфляції.

( Пункт 5 втратив чинність на підставі Постанови Нацбанку N 381 ( v0496500-97 ) від 17.11.97 ) 5. Керівникам структурних підрозділів Національного банку України неухильно дотримуватися затверджених тарифів при наданні послуг фізичним та юридичним особам.

( Пункт 6 втратив чинність на підставі Постанови Нацбанку N 381 ( v0496500-97 ) від 17.11.97 ) 6. Розмір плати за послуги служб перевезення цінностей та організації інкасації встановлюється і затверджується начальниками регіональних управлінь відповідно до порядку розрахунків за ці послуги (додаток N 8).

( Пункт 7 втратив чинність на підставі Постанови Нацбанку N 381 ( v0496500-97 ) від 17.11.97 ) 7. Доходи від надання платних послуг зараховуються до складу загальної суми доходів від діяльності регіонального управління, установи Національного банку України.

( Пункт 8 втратив чинність на підставі Постанови Нацбанку N 381 ( v0496500-97 ) від 17.11.97 ) 8. Вважати такими, що втратили чинність, пункти 4 та 7 додатка N 1, додаток N 2 до постанови Правління від 28.09.95 р. N 245 ( v0298500-95 ) "Про вдосконалення надання послуг у галузі розрахункового обслуговування комерційних банків та регіональних управлінь Національного банку України", лист від 04.02.97 р. N 20-011/58-873.

9. Персональну відповідальність за виконання цієї постанови несуть керівники відповідних структурних підрозділів. Контроль за дотриманням умов виконання цієї постанови покласти на заступника Голови Правління та директора фінансового департаменту О.М.Кандибку.

В.о.Голови С.Стельмах

Примітки

1) Для нових банків-членів міжнародних платіжних систем (що стануть членами міжнародних платіжних систем після 01.05.98).

2) Банк-замовник сплачує за всі проведені транзакції, але не менше 511 гривень щомісячно.

3) Емітент або еквайер сплачує вказану суму, якщо з'ясовується, що при виконанні клірингу він подав помилкові відомості на взаємообмін. Крім того, емітент або еквайер повинен буде відшкодувати збитки, що викликані подачею неправильних відомостей.

4) Плюс відповідна сума за комунікаційні витрати.

5) Файл винятків містить записи вимог емітента на специфічні авторизаційні дії для індивідуальних рахунків держателів карток. Емітент мусить платити за видалення, зміну та супровід файла, але не за занесення запису до файла.

6) Кількість авторизаційних відповідей, якими запрошують торговця чи еквайера зв'язатися з емітентом для подальших інструкцій перед закінченням транзакції, які емітент карток VISA, його авторизуючий член або процесинговий центр, що його замінює, можуть зробити протягом одного календарного місяця без стягнення додаткової комісії, обмежена 1,5% за картками VISA Classic та 0,5% за картками VISA Business та VISA Gold від загальної кількості відповідей, що згенеровані протягом календарного місяця.

7) Файл активності містить підсумкову інформацію про кількість транзакцій, що підтверджені в кожній категорії торговців для індивідуальних держателів карток за поточний день та за останні чотири дні. Коли емітент використовує повний авторизаційний сервіс, відповіді-підтвердження від центра емітента або процесингового центру, що його замінює, акумулюються за поточний день, останні чотири дні та останні 30 днів. В іншому разі включаються тільки відповіді від процесингового центру, що замінює емітента. Файл активності також містить число послідовних вводів персональних ідентифікаційних кодів для кожного індивідуального держателя картки.

8) Файл події створюється, якщо транзакція не може бути підтверджена, або якщо центр емітента вирішить отримати письмове підтвердження.

*) Тарифи зафіксовані за станом на 1 жовтня 1998 року. При проведенні поточного розрахунку тарифи перераховуються пропорційно зміни курсу гривні.
