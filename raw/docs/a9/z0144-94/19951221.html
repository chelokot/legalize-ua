Про затвердження Інструкції про склад коштів, що направлені на споживання

Реєстрація: Мін'юст України від 05.07.1994 № 144/353

Стан: Втратив чинність

Ідентифікатор: z0144-94

Текст документа від 21.12.1995:

МІНІСТЕРСТВО СТАТИСТИКИ УКРАЇНИ

НАКАЗ

N 150 від 27.06.94 Зареєстровано в Міністерстві м.Київ юстиції України 5 липня 1994 р. за N 144/353

Про затвердження Інструкції про склад коштів, що направлені на споживання

( Із змінами, внесеними згідно з Наказом Міністерства статистики N 323 ( z0465-95 ) від 11.12.95 )

На виконання постанови Кабінету Міністрів України і Національного банку України від 29 січня 1994 р. N 49 ( 49-94-п ) "Про контроль за видачею у 1994 році коштів, спрямованих на споживання" НАКАЗУЮ:

1. Внести зміни та доповнення до Інструкції про склад коштів, що направлені на споживання, затвердженої наказом Мінстату України від 22.02.93 N 31 ( z0023-93 ), затвердивши її в новій редакції (додається).

2. Управлінню демографічної статистики і праці (Григорович Н.В.):

2.1. Довести через засоби масової інформації до відома підприємств, установ, організацій нову редакцію Інструкції.

2.2. Забезпечити Держкомстат Республіки Крим, обласні, Київське та Севастопольське міські управління статистики, міністерства, відомства, державні комітети, концерни, корпорації, інші об'єднання Інструкцією про склад коштів, що направлені на споживання, в новій редакції.

3. Економічному управлінню (Єрофеєва Н.В., Пишнюк М.І.):

3.1. Забезпечити фінансування та необхідну кількість паперу для виготовлення Інструкції.

4. Визнати такими, що втратили чинність, накази Міністерства статистики України від 22.02.93 N 31 ( z0023-93 ), від 2.08.93 N 171 ( z0107-93 ).

5. Контроль за виконанням наказу покласти на Заступника Міністра Хайнацьку І.В.

Міністр М.І.Борисенко

( Інструкція про склад коштів, що направлені на споживання втратила чинність на підставі Наказу Мінстатистики N 323 ( z0465-95 ) від 11.12.95 )
