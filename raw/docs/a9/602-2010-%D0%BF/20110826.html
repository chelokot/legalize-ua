Кабінет Міністрів України; Постанова від 21.07.2010 № 602

Про внесення змін до постанов Кабінету Міністрів України від 27 травня 1999 р. N 920 і від 24 червня 2006 р. N 868

Стан: Чинний

Ідентифікатор: 602-2010-п

Текст документа від 26.08.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 липня 2010 р. N 602 Київ

Про внесення змін до постанов Кабінету Міністрів України від 27 травня 1999 р. N 920 і від 24 червня 2006 р. N 868

{ Із змінами, внесеними згідно з Постановою КМ N 883 ( 883-2011-п ) від 17.08.2011 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 27 травня 1999 р. N 920 ( 920-99-п ) "Про затвердження Положення про порядок надання гарантій та здійснення державного контролю за виконанням зобов'язань щодо використання у заявлених цілях товарів, які підлягають державному експортному контролю" (Офіційний вісник України, 1999 р., N 22, ст. 1005; 2003 р., N 32, ст. 1711; 2004 р., N 44, ст. 2881; 2006 р., N 22, ст. 1609) і від 24 червня 2006 р. N 868 ( 868-2006-п ) "Про затвердження Положення про Адміністрацію Державної служби спеціального зв'язку та захисту інформації" (Офіційний вісник України, 2006 р., N 26, ст. 1889; 2008 р., N 59, ст. 1981; 2010 р., N 11, ст. 537) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 49

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 липня 2010 р. N 602

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 27 травня 1999 р. N 920 ( 920-99-п ) і від 24 червня 2006 р. N 868 ( 868-2006-п )

1. Абзац перший пункту 29 Положення про порядок надання гарантій та здійснення державного контролю за виконанням зобов'язань щодо використання у заявлених цілях товарів, які підлягають державному експортному контролю, затвердженого постановою Кабінету Міністрів України від 27 травня 1999 р. N 920 ( 920-99-п ), після слів "Служби зовнішньої розвідки," доповнити словами "Адміністрації Держспецзв'язку,".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 883 ( 883-2011-п ) від 17.08.2011 }
