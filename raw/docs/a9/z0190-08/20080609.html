Про внесення змін до наказу Держкомрезерву України від 26.01.2007 N 28

З метою забезпечення належного функціонування конкурсної комісії з реалізації матеріальних цінностей державного резерву, на виконання вимог Закону України "Про державний матеріальний резерв" ( 51/97-ВР ), постанови Кабінету Міністрів України від 25 серпня 2004 року N 1078 ( 1078-2004-п ) "Про затвердження Порядку реалізації матеріальних цінностей державного резерву" (із змінами) та у зв'язку з кадровими змінами НАКАЗУЮ:

1. Унести зміни до Складу конкурсної комісії з реалізації матеріальних цінностей державного резерву, затвердженого наказом Держкомрезерву України від 26.01.2007 N 28 ( z0185-07 ) "Про затвердження Положення про конкурсну комісію з реалізації матеріальних цінностей державного резерву та Складу конкурсної комісії з реалізації матеріальних цінностей державного резерву", зареєстрованим у Міністерстві юстиції України 03.03.2007 за N 185/13452, виклавши його в новій редакції, що додається.

2. Юридичному управлінню подати даний наказ на погодження до Міністерства економіки України та державну реєстрацію до Міністерства юстиції України у встановленому законодавством порядку.

3. Загальному відділу Департаменту забезпечення діяльності Комітету довести цей наказ до відома керівників структурних підрозділів Держкомрезерву та ДП "Ресурспостач".

4. Контроль за виконанням наказу залишаю за собою.

Голова Комітету М.О.Поживанов

ЗАТВЕРДЖЕНО Наказ Державного комітету України з державного матеріального резерву 26.01.2007 N 28 ( z0185-07 ) (у редакції наказу Державного комітету України з державного матеріального резерву 28.02.2008 N 61)
