Текст документа від 03.08.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 травня 1994 р. N 343-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1213 ( 1213-98-п ) від 03.08.98 )

Про деякі питання організаційного забезпечення роботи Митно-тарифної ради України

1. Установити, про проекти актів законодавства з питань митно-тарифного регулювання, в тому числі щодо встановлення, зміни або скасування ставок мита, вносяться до Кабінету Міністрів України лише після попереднього їх розгляду і схвалення Митно-тарифною радою України.

2. Збільшити граничну чисельність працівників центрального апарату Держмиткому на 3 одиниці для організаційного забезпечення роботи Митно-тарифної ради України.

3. Мінфіну передбачити додаткові витрати на утримання апарату Держмиткому в межах асигнувань на утримання органів державної виконавчої влади.
