Президент України; Указ від 30.04.2009 № 280/2009

Про Консультативну раду з питань розвитку сільського господарства та сільських територій

Стан: Втратив чинність

Ідентифікатор: 280/2009

Текст документа від 30.07.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Консультативну раду з питань розвитку сільського господарства та сільських територій

{ Із змінами, внесеними згідно з Указом Президента N 525/2009 ( 525/2009 ) від 08.07.2009 }

З метою забезпечення розроблення та реалізації державної політики щодо розвитку сільського господарства та сільських територій, підвищення інвестиційної привабливості вітчизняного аграрного сектора економіки та конкурентоспроможності сільськогосподарських товаровиробників, відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Утворити при Президентові України Консультативну раду з питань розвитку сільського господарства та сільських територій (далі - Консультативна рада).

2. Визначити основними завданнями Консультативної ради:

вивчення стану реалізації державної політики у сфері розвитку сільського господарства та сільських територій, у тому числі розвитку земельних відносин на таких територіях;

аналіз проблем, що стримують розвиток аграрного сектора економіки;

підготовку пропозицій щодо стимулювання інвестицій в агропромисловий комплекс України та підвищення конкурентоспроможності аграрного сектора економіки, в тому числі із залученням міжнародної технічної допомоги;

розроблення пропозицій, у тому числі із залученням вітчизняних та міжнародних експертів, щодо підготовки проектів нормативно-правових актів з питань розвитку сільського господарства та сільських територій, удосконалення земельних відносин на таких територіях.

3. Призначити КАРАСИКА Юрія Михайловича - голову Всеукраїнського союзу сільськогосподарських підприємств - головою Консультативної ради. { Абзац перший статті 3 із змінами, внесеними згідно з Указом Президента N 525/2009 ( 525/2009 ) від 08.07.2009 }

Голові Консультативної ради подати у місячний строк:

пропозиції щодо персонального складу Консультативної ради, передбачивши включення до нього представників міністерств, інших центральних органів виконавчої влади, підприємств, установ, організацій, у тому числі науково-дослідних установ, виробничих кооперативів, асоціацій виробників сільськогосподарської продукції та громадськості, за їх згодою;

проект Положення про Консультативну раду з питань розвитку сільського господарства та сільських територій.

4. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
