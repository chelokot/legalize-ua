ПОСТАНОВА від 4 вересня 2003 р. N 1398 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 937 ( 937-2011-п ) від 07.09.2011 }

Про граничну чисельність працівників Адміністрації Державної прикордонної служби

Кабінет Міністрів України постановляє:

1. Затвердити граничну чисельність працівників Адміністрації Державної прикордонної служби в кількості 531 одиниця, у тому числі 417 військовослужбовців.

2. Визнати такими, що втратили чинність:

пункти 3 і 4 постанови Кабінету Міністрів України від 2 січня 1992 р. N 3 ( 3-92-п ) "Питання Державного комітету у справах охорони державного кордону України" (ЗП України, 1992 р., N 2, ст. 31);

абзаци третій і четвертий постанови Кабінету Міністрів України від 26 січня 1993 р. N 48 ( 48-93-п ) "Про внесення змін до постанови Кабінету Міністрів України від 2 січня 1992 р. N 3".

3. Ця постанова набирає чинності з 1 вересня 2003 року.
