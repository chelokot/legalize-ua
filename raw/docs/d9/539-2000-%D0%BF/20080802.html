Про встановлення винагород спортсменам України - чемпіонам, призерам спортивних змагань міжнародного рівня та їх тренерам

{ Із змінами, внесеними згідно з Постановами КМ N 416 ( 416-2002-п ) від 29.03.2002 N 1953 ( 1953-2003-п ) від 17.12.2003 N 979 ( 979-2004-п ) від 28.07.2004 N 616 ( 616-2005-п ) від 21.07.2005 N 963 ( 963-2005-п ) від 24.09.2005 N 867 ( 867-2007-п ) від 26.06.2007 N 1156 ( 1156-2007-п ) від 19.09.2007 N 680 ( 680-2008-п ) від 23.07.2008 }

З метою відзначення спортсменів, досягнення яких сприяють утвердженню міжнародного авторитету України, підвищення їх соціального захисту, заохочення до успішних виступів на міжнародних змаганнях Кабінет Міністрів України постановляє:

1. Установити спортсменам України - чемпіонам, призерам спортивних змагань міжнародного рівня та їх тренерам винагороди в розмірах згідно з додатком.

Винагороди виплачуються у гривнях за офіційним курсом гривні до долара США, встановленим Національним банком на дату виплати винагород, за рахунок коштів, передбачених у державному бюджеті Державному комітетові з питань фізичної культури і спорту та Міністерству освіти і науки на проведення заходів з фізичної культури і спорту. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1953 ( 1953-2003-п ) від 17.12.2003 )

2. Затвердити Порядок виплати винагород спортсменам України - чемпіонам, призерам спортивних змагань міжнародного рівня та їх тренерам (додається).

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 12 жовтня 1994 р. N 704 ( 704-94-п ) "Про встановлення винагород для чемпіонів, призерів Олімпійських ігор, чемпіонатів світу і Європи та їх тренерів".

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 22 березня 2000 р. N 539

ПОРЯДОК виплати винагород спортсменам України - чемпіонам, призерам спортивних змагань міжнародного рівня та їх тренерам

1. Винагороди за високі спортивні результати на змаганнях міжнародного рівня виплачуються:

спортсменам, спортсменам-інвалідам, які зайняли перше, друге і третє місця у складі збірних команд України з видів спорту (далі - спортсменам);

тренерам (державним, головним, провідним, старшим), начальникам команд, тренерам-лікарям, тренерам-масажистам, тренерам-ветеринарам, тренерам-адміністраторам, тренерам-механікам, тренерам-операторам, тренерам-викладачам (особистим), тренерам-викладачам з хореографії, тренерам-реабілітологам, тренерам-психологам, тренерам-хореографам (далі - тренерам). ( Абзац третій пункту 1 із змінами, внесеними згідно з Постановами КМ N 416 ( 416-2002-п ) від 29.03.2002, N 979 ( 979-2004-п ) від 28.07.2004 )

2. Списки спортсменів і тренерів із зазначенням розмірів винагород затверджуються наказами Держкомспорту, а списки спортсменів, які брали участь у Всесвітній універсіаді та Європейських молодіжних олімпійських днях, і їх тренерів із зазначенням розмірів винагород - МОН.

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 416 ( 416-2002-п ) від 29.03.2002 )

3. Списки спортсменів і тренерів, які затверджуються Держкомспортом, формуються його відповідними підрозділами на підставі рішень федерацій з видів спорту, нозологій та Українського центру з фізичної культури і спорту інвалідів "Інваспорт" і протоколів спортивних змагань.

( Абзац перший пункту 3 із змінами, внесеними згідно з Постановою КМ N 416 ( 416-2002-п ) від 29.03.2002 )

Списки спортсменів і тренерів, які затверджуються МОН, формуються Комітетом з фізичного виховання та спорту МОН.

( Абзац другий пункту 3 в редакції Постанови КМ N 416 ( 416-2002-п ) від 29.03.2002 )

4. Виплата винагород спортсменам здійснюється за кожне зайняте призове (I - III) місце по кожному виду програми (виступу). Якщо спортсмен на одному змаганні зайняв кілька призових місць, винагорода виплачується за кожне призове місце.

5. У разі встановлення спортсменом протягом одного змагання кількох рекордів світу, Європи винагорода виплачується за вищий рекорд після його реєстрації в установленому порядку відповідно до розмірів, визначених за перше місце на чемпіонатах світу, Європи.

6. Виплата винагород здійснюється в місячний термін після затвердження списків спортсменів і тренерів за рахунок коштів, передбачених у державному бюджеті на заходи фізичної культури і спорту за кодом економічної класифікації 1340 "Трансферти населенню".

Винагороди виплачуються у гривнях за офіційним курсом гривні до долара США, встановленим Національним банком на дату виплати винагород.

7. Обсяг коштів, передбачених для виплати винагород тренерам, які безпосередньо брали участь у підготовці спортсменів, команд або запрошувалися для підготовки спортсменів - членів збірних команд України під час проведення навчально-тренувальних зборів перед міжнародними змаганнями, визначається:

а) 50 відсотків загальної суми винагород, отриманих спортсменами на Олімпійських, Параолімпійських іграх, Дефлімпійських іграх, Всесвітній шаховій олімпіаді, чемпіонатах світу, Європи, фіналах кубків світу з олімпійських номерів програми (дорослі спортсмени) в індивідуальних та командних видах програми; ( Підпункт "а" пункту 7 із змінами, внесеними згідно з Постановою КМ N 416 ( 416-2002-п ) від 29.03.2002 )

б) до 100 відсотків відповідного розміру винагороди кожного спортсмена в індивідуальних видах програми та 50 відсотків загальної суми винагород спортсменів у команді - в командних видах програм та ігрових видах спорту (не менш як два спортсмени) у разі участі спортсменів у змаганнях міжнародного рівня, крім зазначених у підпункті "а" цього пункту.

8. Виплата винагород за рахунок бюджетних коштів за результатами міжнародних змагань, що проводилися на комерційній основі, забороняється.
