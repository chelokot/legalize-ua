ДЕРЖАВНА ПОДАТКОВА АДМІНІСТРАЦІЯ УКРАЇНИ МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

25.08.2005 N 365/426

Зареєстровано в Міністерстві юстиції України 5 вересня 2005 р. за N 986/11266

Про визнання такими, що втратили чинність, деяких наказів

З метою дотримання вимог Закону України "Про засади державної регуляторної політики у сфері господарської діяльності" ( 1160-15 ) на виконання статті 3 Указу Президента України від 1 червня 2005 року N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" НАКАЗУЄМО:

1. Визнати такими, що втратили чинність, накази:

Головної державної податкової інспекції України та Державного комітету України по харчовій промисловості

від 14.06.96 N 51/38 ( z0326-96 ) "Про сплату акцизного збору по продукції, виготовленій з використанням давальницької сировини спиртовими та лікеро-горілчаними підприємствами", зареєстрований у Міністерстві юстиції України 26.06.96 за N 326/1351;

Головної державної податкової інспекції України та Державного комітету України з питань садівництва, виноградарства та виноробної промисловості

від 19.07.96 N 63/101 ( z0423-96 ) "Про сплату акцизного збору по продукції, виготовленій з використанням давальницької сировини підприємствами виноробної галузі", зареєстрований у Міністерстві юстиції України 06.08.96 за N 423/1448;

Головної державної податкової інспекції України та Державного комітету України по харчовій промисловості

від 23.08.96 N 70/70 ( z0549-96 ) "Про затвердження Порядку реалізації спирту, горілки та лікеро-горілчаних виробів, виготовлених з сировини замовників, та обкладання їх акцизним збором", зареєстрований у Міністерстві юстиції України 23.09.96 за N 549/1574.

2. Директору Департаменту з питань адміністрування акцизного збору і контролю за виробництвом та обігом підакцизних товарів Гончару І.М. подати цей наказ до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Голови ДПА України Лекаря С.І.

В.о. Голови Державної податкової адміністрації України Б.М.Горбанський

Міністр аграрної політики України О.П.Баранівський
