КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 травня 2004 р. N 631 Київ

Про утворення Міжвідомчої робочої групи з питань координації та контролю за реалізацією проекту "Модернізація державної податкової служби України - 1", який підтримується Міжнародним банком реконструкції та розвитку

{ Із змінами, внесеними згідно з Постановами КМ N 1253 ( 1253-2005-п ) від 21.12.2005 N 147 ( 147-2006-п ) від 15.02.2006 N 1379 ( 1379-2006-п ) від 04.10.2006 N 1233 ( 1233-2011-п ) від 02.11.2011 }

Кабінет Міністрів України постановляє:

1. Утворити Міжвідомчу робочу групу з питань координації та контролю за реалізацією проекту "Модернізація державної податкової служби України - 1", який підтримується Міжнародним банком реконструкції та розвитку, у складі згідно з додатком.

Надати голові Міжвідомчої робочої групи право вносити у разі потреби зміни до її складу.

2. Затвердити Положення про Міжвідомчу робочу групу з питань координації та контролю за реалізацією проекту "Модернізація державної податкової служби України - 1" (додається).

3. Визначити Державну податкову службу відповідальною за виконання робіт з реалізації проекту "Модернізація державної податкової служби України - 1".

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1233 ( 1233-2011-п ) від 02.11.2011 }

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 13 травня 2004 р. N 631

ПОЛОЖЕННЯ про Міжвідомчу робочу групу з питань координації та контролю за реалізацією проекту "Модернізація державної податкової служби України - 1"

1. Міжвідомча робоча група з питань координації та контролю за реалізацією проекту "Модернізація державної податкової служби України - 1" (далі - Міжвідомча робоча група) є тимчасовим консультативно-дорадчим органом Кабінету Міністрів України.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1233 ( 1233-2011-п ) від 02.11.2011 }

2. Міжвідомча робоча група у своїй діяльності керується Конституцією ( 254к/96-ВР ) та законами України, актами Президента України, Кабінету Міністрів України, а також цим Положенням.

3. Міжвідомча робоча група утворюється на період реалізації проекту "Модернізація державної податкової служби України - 1" (далі - проект модернізації).

4. У складі Міжвідомчої робочої групи утворюються підгрупи:

зв'язків з громадськістю; { Абзац другий пункту 4 із змінами, внесеними згідно з Постановою КМ N 1253 ( 1253-2005-п ) від 21.12.2005 }

з податкового законодавства та аналізу податкової політики;

з міжвідомчого обміну інформацією.

Голова Міжвідомчої робочої групи затверджує персональний склад підгруп, плани їх роботи, має право змінювати назву і кількість підгруп.

5. До складу підгруп входять:

підгрупа зв'язків з громадськістю - народні депутати України (за згодою), представники ДПС, Мінінфраструктури, Українського союзу промисловців і підприємців, Укрінформу, спільного представницького органу сторони роботодавців на національному рівні; { Абзац другий пункту 5 із змінами, внесеними згідно з Постановами КМ N 1253 ( 1253-2005-п ) від 21.12.2005, N 1233 ( 1233-2011-п ) від 02.11.2011 }

підгрупа з податкового законодавства та аналізу податкової політики - представники Мінфіну, Мінекономрозвитку, ДПС, Мін'юсту; { Абзац третій пункту 5 із змінами, внесеними згідно з Постановами КМ N 1253 ( 1253-2005-п ) від 21.12.2005, N 1233 ( 1233-2011-п ) від 02.11.2011 }

підгрупа з міжвідомчого обміну інформацією - народні депутати України (за згодою), представники ДПС, Мінекономрозвитку, Держстату, Держмитслужби, Казначейства, Національного банку, МВС і СБУ. { Абзац четвертий пункту 5 із змінами, внесеними згідно з Постановами КМ N 1253 ( 1253-2005-п ) від 21.12.2005, N 1233 ( 1233-2011-п ) від 02.11.2011 }

За рішенням голови Міжвідомчої робочої групи до складу підгруп можуть включатися також представники інших органів державної влади, установ та організацій.

6. Завданнями Міжвідомчої робочої групи є:

координація взаємодії центральних органів виконавчої влади під час реалізації проекту модернізації та здійснення контролю за його реалізацією;

сприяння ДПС у створенні прозорої та ефективної системи функціонування державної податкової служби; { Абзац третій пункту 6 із змінами, внесеними згідно з Постановою КМ N 1233 ( 1233-2011-п ) від 02.11.2011 }

контроль за цільовим та ефективним використанням фінансової допомоги Міжнародного банку реконструкції та розвитку, яка надається у рамках проекту модернізації.

Основними завданнями підгруп є:

підгрупи зв'язків з громадськістю - інформування українського суспільства про діяльність державної податкової служби та хід реалізації проекту модернізації; { Абзац шостий пункту 6 із змінами, внесеними згідно з Постановою КМ N 1253 ( 1253-2005-п ) від 21.12.2005 }

підгрупи з податкового законодавства та аналізу податкової політики - проведення аналізу податкового законодавства та розроблення пропозицій щодо його вдосконалення, реалізація яких сприятиме ліквідації прогалин у податковому законодавстві, наповненню державного бюджету необхідними ресурсами, а також зниженню податкового навантаження на платників податків;

підгрупи з міжвідомчого обміну інформацією - підтримка належного, ефективного і своєчасного обміну аналітичною, статистичною та оперативною інформацією між органами державної влади, установами та організаціями, діяльність яких пов'язана з податковою політикою та управлінням податковими надходженнями.

7. Міжвідомча робоча група відповідно до покладених на неї завдань:

контролює виконання заходів з реалізації проекту модернізації, їх відповідність державній політиці у сфері оподаткування і цілям проекту модернізації;

заслуховує звіти ДПС про результати реалізації проекту модернізації та заплановані заходи; { Абзац третій пункту 7 із змінами, внесеними згідно з Постановою КМ N 1233 ( 1233-2011-п ) від 02.11.2011 }

готує рекомендації щодо усунення недоліків та розв'язання проблем, що стримують реалізацію проекту модернізації;

розглядає проекти законів та інших нормативно-правових актів, спрямованих на забезпечення реалізації Стратегічного плану розвитку державної податкової служби України на період до 2013 року, затвердженого наказом Державної податкової адміністрації від 7 квітня 2003 р. N 160 ( v0160225-03 );

організовує взаємодію органів державної влади, установ та організацій з питань проведення статистичного аналізу та внесення до законодавчих актів змін, спрямованих на формування податкової політики.

8. Міжвідомча робоча група має право:

утворювати на громадських засадах експертні та робочі підгрупи із залученням міжнародних і провідних українських експертів, учених, представників підприємств, установ та організацій;

залучати посадових осіб органів державної влади, органів місцевого самоврядування, представників підприємств, установ та організацій до участі в засіданнях Міжвідомчої робочої групи з правом дорадчого голосу;

отримувати в установленому порядку від органів державної влади, органів місцевого самоврядування, підприємств, установ та організацій інформацію, необхідну для виконання покладених на неї завдань.

9. Основною формою роботи Міжвідомчої робочої групи є засідання, які скликаються її головою у разі потреби, але не менше ніж два рази на рік.

Засідання Міжвідомчої робочої групи проводить її голова, а в разі його відсутності - заступник голови.

Засідання Міжвідомчої робочої групи є правоможним, якщо на ньому присутні не менше ніж дві третини її членів.

Рішення Міжвідомчої робочої групи приймається простою більшістю голосів її членів, присутніх на засіданні. У разі рівного розподілу голосів вирішальним є голос головуючого на засіданні.

Рішення Міжвідомчої робочої групи оформляються протоколами, які підписуються головуючим на засіданні. Протоколи надсилаються органам державної влади, підприємствам, установам та організаціям, представники яких є членами Міжвідомчої робочої групи, а також іншим заінтересованим органам державної влади.

10. Голова Міжвідомчої робочої групи:

здійснює керівництво діяльністю Міжвідомчої робочої групи, несе персональну відповідальність за виконання покладених на неї завдань;

за поданням секретаря Міжвідомчої робочої групи затверджує протоколи засідань;

затверджує плани робіт з координації та контролю за реалізацією проекту модернізації;

бере участь у підготовці питань до розгляду на засіданні Міжвідомчої робочої групи, приймає рішення про їх винесення на обговорення;

надає утвореним Міжвідомчою робочою групою експертним та робочим підгрупам доручення, співпрацює з наглядовою радою з питань реалізації проекту "Модернізація державної податкової служби України - 1".

11. Секретар Міжвідомчої робочої групи відповідає за підготовку аналітичних матеріалів, ведення протоколу засідання Міжвідомчої робочої групи, збирання та узагальнення інформації, що надходить від членів групи та підгруп, підготовку звіту про роботу Міжвідомчої робочої групи для подання його на розгляд голові Міжвідомчої робочої групи.

12. Рішення Міжвідомчої робочої групи з питань, що належать до її компетенції, є обов'язковими для розгляду центральними та місцевими органами виконавчої влади.

{ Пункт 12 із змінами, внесеними згідно з Постановою КМ N 1379 ( 1379-2006-п ) від 04.10.2006 }

13. Організаційне забезпечення діяльності Міжвідомчої робочої групи здійснює ДПС.

{ Пункт 13 із змінами, внесеними згідно з Постановою КМ N 1233 ( 1233-2011-п ) від 02.11.2011 }
