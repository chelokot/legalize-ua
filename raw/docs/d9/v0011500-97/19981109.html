( Із змінами, внесеними згідно з Постановою Нацбанку N 470 ( v0470500-98 ) від 09.11.98 )

( Постанова втратила чинність в частині внесення змін до Постанови Нацбанку N 184 ( va184500-96 ) від 23.07.96 на підставі Постанови Нацбанку N 470 ( v0470500-98 ) від 09.11.98 )

Заслухавши та обговоривши пропозицію департаменту банківського нагляду про необхідність внесення змін та доповнень до положень "Про порядок ліцензування банків в Україні", затвердженого постановою Правління Національного банку України N 77 ( v0077500-96 ) від 27 березня 1996 року, "Про Комісію з питань нагляду та регулювання діяльності банків", затвердженого постановою Правління Національного банку України N 184 ( va184500-96 ) від 23 липня 1996 року, та "Порядку надання ліцензій Національного банку України на право здійснення комерційними банками операцій з валютними цінностями", затвердженого постановою Правління Національного банку України N 243 ( va243500-95 ) від 27 вересня 1995 року Правління ПОСТАНОВЛЯЄ:

1. Доповнити розділ 3 "Умови надання ліцензії новоствореному банку" положення "Про порядок ліцензування банків в Україні", затвердженого постановою Правління Національного банку України N 77 від 27 березня 1996 року пунктом 3.6, та доповнити зміст пункту 3.7 положення "Про комісію з питань нагляду та регулювання діяльності банків", затвердженого постановою Правління Національного банку України N 184 від 23 липня 1996 року, а також викласти пункт 3.5 "Порядку надання ліцензій Національного банку України на право здійснення комерційними банками операцій з валютними цінностями", затвердженого постановою Правління Національного банку України N 243 від 27 вересня 1995 раку, у такій редакції:

"У разі утворення нового комерційного банку внаслідок реорганізації банку, що мав ліцензію на здійснення відповідних операцій, Комісія з питань нагляду та регулювання діяльності банків, враховуючи досвід роботи, наявність необхідних спеціалістів відповідної кваліфікації, технічні умови здійснення банківських операцій, має право прийняти відповідне рішення щодо надання такому банку ліцензій на здійснення банківських операцій у національній та іноземних валютах, знизивши при цьому до встановленого чинним законодавством рівня рівень вимог щодо розміру статутного фонду та терміну функціонування банку".

2. Контроль за виконанням постанови покласти на заступника Голови Правління О.О.Веселовського і директора департаменту банківського нагляду А.І.Степаненка.
