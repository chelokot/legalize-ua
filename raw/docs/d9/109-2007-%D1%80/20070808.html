КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 березня 2007 р. N 109-р Київ

Про перелік урядових комітетів та їх посадовий склад

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 131-р ( 131-2007-р ) від 04.04.2007 N 183-р ( 183-2007-р ) від 12.04.2007 N 225-р ( 225-2007-р ) від 26.04.2007 N 616-р ( 616-2007-р ) від 08.08.2007 }

1. Затвердити такий перелік урядових комітетів:

Урядовий комітет з реформ;

Урядовий комітет з питань економічної політики та європейської інтеграції;

Урядовий комітет з питань національної безпеки, оборони та правоохоронної діяльності;

Урядовий комітет з питань розвитку галузей економіки;

Урядовий комітет з питань регіональної політики, будівництва та житлово-комунального господарства;

Урядовий комітет з питань аграрної політики;

Урядовий комітет з питань гуманітарної і соціальної політики.

2. Затвердити посадовий склад урядових комітетів згідно з додатками 1-7.
