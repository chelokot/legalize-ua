Текст документа від 17.11.1998:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про затвердження штатного розпису апарату Представництва Президента України в Автономній Республіці Крим

( Із змінами, внесеними згідно з Розпорядженнями Президента N 419/97-рп від 27.11.97 N 68/98-рп від 27.03.98 N 335/98-рп від 23.06.98 N 550/98-рп від 17.11.98 )

1. Затвердити штатний розпис апарату Представництва Президента України в Автономній Республіці Крим (додається).

2. Внести зміни до структури апарату Представництва Президента України в Автономній Республіці Крим, затвердженої Розпорядженням Президента України від 11 квітня 1997 року N 162 ( 162/97-рп ), передбачивши в складі апарату замість посади бухгалтера посади головного бухгалтера та бухгалтера.

3. Визнати таким, що втратило чинність Розпорядження Президента України від 4 липня 1996 року N 183 ( 183/96-рп ) "Про затвердження штатного розпису апарату Представництва Президента України в Автономній Республіці Крим".

Президент України Л.КУЧМА
