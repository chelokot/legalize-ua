Кабінет Міністрів України; Розпорядження від 15.05.2003 № 275-р

Про віднесення посад працівників апарату Національного центру з питань євроатлантичної інтеграції України до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 275-2003-р

Текст документа від 03.10.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 травня 2003 р. N 275-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Про віднесення посад працівників апарату Національного центру з питань євроатлантичної інтеграції України до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженням КМ N 211-р ( 211-2006-р ) від 19.04.2006 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників апарату Національного центру з питань євроатлантичної інтеграції України до таких категорій посад державних службовців:

друга категорія - керівник апарату, начальник управління, заступник начальника управління; { Абзац другий в редакції Розпорядження КМ N 211-р ( 211-2006-р ) від 19.04.2006 }

третя категорія - заступник завідувача відділу, головний консультант, старший консультант. { Абзац третій в редакції Розпорядження КМ N 211-р ( 211-2006-р ) від 19.04.2006 }
