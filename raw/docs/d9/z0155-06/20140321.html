ДЕРЖАВНИЙ КОМІТЕТ ЯДЕРНОГО РЕГУЛЮВАННЯ УКРАЇНИ

НАКАЗ

09.02.2006 N 22

Зареєстровано в Міністерстві юстиції України 21 лютого 2006 р. за N 155/12029

{ Наказ втратив чинність на підставі Наказу Державної інспекції ядерного регулювання N 15 ( z0325-14 ) від 06.02.2014 }

Про затвердження Переліку посад працівників центрального апарату Державного комітету ядерного регулювання України, які отримують надбавку за особливі умови роботи

Відповідно до абзацу першого пункту 3 постанови Кабінету Міністрів України від 2 квітня 2001 року N 313 ( 313-2001-п ) "Деякі питання Державного комітету ядерного регулювання", із змінами, НАКАЗУЮ:

1. Затвердити Перелік посад працівників центрального апарату Державного комітету ядерного регулювання України, які отримують надбавку за особливі умови роботи (далі - Перелік), що додається.

2. Установити посадовим особам, зазначеним у Переліку, надбавку за особливі умови роботи в розмірі 50 відсотків посадового окладу з урахуванням доплати за ранг державного службовця.

3. Начальнику Відділу економіки, фінансів, бухгалтерського обліку та звітності Бережній С.Ф. у п'ятиденний термін після підписання наказу забезпечити його подання на державну реєстрацію до Міністерства юстиції України.

4. Наказ Держатомрегулювання України від 18.11.2005 N 131 ( z1440-05 ) "Про затвердження Переліку посад працівників центрального апарату Державного комітету ядерного регулювання України, які безпосередньо виконують функції державного регулювання", зареєстрований в Міністерстві юстиції України 30.11.2005 за N 1440/11720, уважати таким, що втратив чинність.

5. Контроль за виконанням цього наказу залишаю за собою.
