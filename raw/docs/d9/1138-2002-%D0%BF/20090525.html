Кабінет Міністрів України; Постанова від 17.08.2002 № 1138

Про внесення змін до постанов Кабінету Міністрів України від 26 лютого 2000 р. N 403 і від 2 квітня 2001 р. N 314

Стан: Втратив чинність

Ідентифікатор: 1138-2002-п

Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 серпня 2002 р. N 1138 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Про внесення змін до постанов Кабінету Міністрів України від 26 лютого 2000 р. N 403 і від 2 квітня 2001 р. N 314

{ Із змінами, внесеними згідно з Постановою КМ N 954 ( 954-2008-п ) від 22.10.2008 }

Кабінет Міністрів України постановляє:

1. Внести у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади, і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851) такі зміни:

у позиції "Державний комітет по водному господарству" цифру "3" замінити цифрою "4";

у позиції "Державний комітет по земельних ресурсах" цифри "109" і "10500" замінити відповідно цифрами "140" і "10469".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 954 ( 954-2008-п ) від 22.10.2008 }

3. Державному комітетові по водному господарству видатки на утримання додаткової чисельності працівників центрального апарату та додаткової кількості автомобілів здійснити в межах асигнувань, передбачених у Державному бюджеті на 2002 рік ( 2905-14 ) за програмою "Керівництво управління у сфері водного господарства".

Прем'єр-міністр України А.КІНАХ
