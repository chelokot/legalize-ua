( Розпорядження втратило чинність на підставі Постанови КМ N 142 ( 142-2003-п ) від 29.01.2003 )

Про внесення змін до розпорядження Кабінету Міністрів України від 24 квітня 2000 р. N 195

На зміну розпорядження Кабінету Міністрів України від 24 квітня 2000 р. N 195 ( 195-2000-р ) затвердити новий склад Міжвідомчої комісії з аналізу діяльності підприємств, які мають стратегічне значення для економіки та безпеки держави або займають монопольне становище на загальнодержавному ринку товарів (робіт, послуг), згідно з додатком.
