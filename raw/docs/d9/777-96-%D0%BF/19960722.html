{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про фінансування заходів, пов'язаних із святкуванням п'ятої річниці незалежності України

Кабінет Міністрів України постановляє:

1. Для забезпечення реалізації заходів, передбачених Програмою підготовки й відзначення п'ятої річниці незалежності України, виділити міністерствам і відомствам 479520,5 млн. крб. згідно з додатком.

2. Міністерству фінансів профінансувати:

зазначені витрати в сумі 374285 млн. крб. за рахунок коштів, передбачених міністерствам і відомствам у Державному бюджеті України на 1996 рік ( 96/96-ВР ) для утримання підвідомчих установ і закладів;

витрати Управління справами Верховної Ради України та Міністерства закордонних справ на проведення конференції за участю представників парламентів країн Співдружності Незалежних Держав із запрошенням представників Організації Безпеки та Співробітництва в Європі, Ради Європи, Європейського Союзу, Міністерства культури і мистецтв, Київської міської державної адміністрації на інші заходи в сумі 105235,5 млн. крб. за рахунок резервного фонду Кабінету Міністрів України.
