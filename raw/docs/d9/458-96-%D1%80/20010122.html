Кабінет Міністрів України; Розпорядження від 20.07.1996 № 458-р

Про склад міжвідомчої робочої групи для координації робіт з підготовки проекту будівництва Дністровської гідроакумулюючої електростанції

Стан: Втратив чинність

Ідентифікатор: 458-96-р

Текст документа від 22.01.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 липня 1996 р. N 458-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 34 ( 34-2001-п ) від 22.01.2001 )

Затвердити склад міжвідомчої робочої групи для координації робіт з підготовки проекту завершення будівництва Дністровської гідроакумулюючої електростанції, що підтримується Міжнародним банком реконструкції та розвитку, згідно з додатком.

Дозволити голові міжвідомчої робочої групи за погодженням з керівниками відповідних міністерств, відомств вносити зміни до складу групи.
