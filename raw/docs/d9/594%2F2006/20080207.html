Президент України; Указ, Склад колегіального органу від 05.07.2006 № 594/2006

Про делегацію України для участі у переговорах між Україною та Великою Соціалістичною Народною Лівійською Арабською Джамагирією щодо підготовки проекту Договору між Україною та Великою Соціалістичною Народною Лівійською Арабською Джамагирією про передачу засуджених осіб

Стан: Втратив чинність

Ідентифікатор: 594/2006

Текст документа від 07.02.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у переговорах між Україною та Великою Соціалістичною Народною Лівійською Арабською Джамагирією щодо підготовки проекту Договору між Україною та Великою Соціалістичною Народною Лівійською Арабською Джамагирією про передачу засуджених осіб

1. Утворити делегацію України для участі у переговорах між Україною та Великою Соціалістичною Народною Лівійською Арабською Джамагирією щодо підготовки проекту Договору між Україною та Великою Соціалістичною Народною Лівійською Арабською Джамагирією про передачу засуджених осіб (м. Київ) у такому складі:

ГОРБУНОВА - заступник Міністра юстиції України,

Лідія Миколаївна глава делегації

ГОРБАЧОВА - головний експерт Управління

Вікторія Ігорівна міжнародних зв'язків Міністерства внутрішніх справ України

ДВОЙНІС - начальник управління по контролю за

Олексій Григорович виконанням судових рішень Державного департаменту України з питань виконання покарань

МАРЧЕНКО - завідувач відділу Головної державно-

Людмила Іванівна правової служби Секретаріату Президента України

СИБІГА - заступник директора департаменту - начальник Андрій Іванович відділу Договірно-правового департаменту Міністерства закордонних справ України

ФІЛАТОВ - суддя Верховного Суду України (за

Василь Миколайович згодою)

ШЕВЧЕНКО - заступник директора Департаменту

Катерина Георгіївна міжнародного співробітництва Міністерства юстиції України.

Дозволити главі делегації вносити в разі потреби зміни до її складу, залучаючи до роботи делегації членів Експертної групи з підготовки проектів міжнародних договорів України про правові відносини та правову допомогу у цивільних і кримінальних справах, утвореної Указом Президента України від 24 квітня 2004 року N 476 ( 476/2004 ).

2. Міністерству юстиції України за погодженням з Міністерством закордонних справ України затвердити вказівки делегації України на переговори.

3. Кабінету Міністрів України забезпечити фінансування проведення у м. Києві переговорів щодо підготовки проекту Договору між Україною та Великою Соціалістичною Народною Лівійською Арабською Джамагирією про передачу засуджених осіб.

Президент України В.ЮЩЕНКО
