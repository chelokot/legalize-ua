НАКАЗ

N 344 від 14.06.2000 Зареєстровано в Міністерстві юстиції України 3 липня 2000 р. за N 384/4605

( Наказ втратив чинність на підставі Наказу Державної митної служби N 129 ( z0424-03 ) від 28.02.2003 )

Про внесення змін до Переліку, затвердженого наказом Державної митної служби України від 27.07.98 N 436

Відповідно до пункту 1 постанови Кабінету Міністрів України від 02.04.98 N 419 ( 419-98-п ) "Про заходи щодо посилення контролю за ввезенням в Україну окремих видів товарів, що імпортуються суб'єктами підприємницької діяльності" НАКАЗУЮ:

1. Доповнити Перелік товарів, що ввозяться за попередньою вантажною митною декларацією, затверджений наказом Державної митної служби України від 27.07.98 N 436 ( z0506-98 ) і зареєстрований у Міністерстві юстиції України 12.08.98 за N 506/2946, зі змінами та доповненнями, товарами, що класифікуються за кодом 0603 ("Зрізані квіти і бутони") відповідно до ТН ЗЕД ( n0001410-92 ).

2. Управлінню організації митного контролю (Дьомін Ю.М.), Правовому управлінню (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції.

3. Управлінню справами (Карпенко В.П.) забезпечити доведення наказу до відома особового складу митних органів.

4. Управлінню аналізу, прогнозування та зв'язку з громадськістю (Козик Л.Г.), начальникам регіональних митниць, начальникам митниць довести наказ до відома суб'єктів ЗЕД і громадян.

5. Контроль за виконанням цього наказу покласти на заступника Голови Служби Соболя І.М.
