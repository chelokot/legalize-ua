ЗАТВЕРДЖЕНО Наказ Мін'юсту 07.12.2006 N 89/5

Зареєстровано в Міністерстві юстиції України 7 грудня 2006 р. за N 1275/13149

ПОРЯДОК проходження стажування громадянами України в державних нотаріальних конторах або в нотаріусів, що займаються приватною нотаріальною практикою

{ У тексті Порядку слова "Головні обласні, Київське та Севастопольське міські управління юстиції" в усіх відмінках замінено словами "головні управління юстиції в областях, містах Києві та Севастополі" згідно з Наказом Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007 }

1. Цей Порядок розроблений з метою реалізації вимог статті 3 Закону України "Про нотаріат" ( 3425-12 ) для встановлення єдиних умов та правил проходження стажування громадянами України в державних нотаріальних конторах або в нотаріусів, що займаються приватною нотаріальною практикою.

2. Громадянин України (далі - особа) для одержання свідоцтва про право на заняття нотаріальною діяльністю на ряду з виконанням інших умов, передбачених законодавством, має пройти стажування протягом шести місяців у державній нотаріальній конторі або в нотаріуса, що займається приватною нотаріальною практикою (далі - стажування).

3. До стажування допускаються особи, які:

дієздатні;

мають вищу юридичну освіту (університет, академія, інститут);

не мають судимості.

4. З метою забезпечення справедливості, неупередженості та визначення професійного рівня осіб, які бажають пройти стажування, проводиться іспит.

5. Рішення про проведення іспиту приймається кваліфікаційною комісією, утвореною при Головному управлінні юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управліннях юстиції в областях, містах Києві та Севастополі (далі - кваліфікаційна комісія) один раз на рік.

{ Пункт 5 із змінами, внесеними згідно з Наказом Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007 }

6. Повідомлення про проведення іспиту має бути розміщене в загальнодоступних місцях у приміщеннях відповідно Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управліннях юстиції в областях, містах Києві та Севастополі (далі - управління юстиції) не пізніше ніж за місяць до дати проведення іспиту. Повідомлення також може бути опубліковано додатково в засобах масової інформації.

7. Повідомлення про проведення іспиту повинно включати:

дату, час, місце проведення іспиту;

кількість посад стажистів (із зазначенням державних нотаріальних контор та нотаріальних округів, в яких передбачається проходження стажування); { Абзац третій пункту 7 із змінами, внесеними згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

перелік документів, які подаються для складання іспиту;

перелік питань, які можуть бути включені до білетів для складання іспиту;

кандидатури керівників стажування.

У повідомленні про оголошення іспиту може міститися додаткова інформація.

8. Кандидатури керівників стажування визначаються наказом управління юстиції. Кількість керівників стажування не може бути меншою кількості посад стажистів. { Абзац перший пункту 8 із змінами, внесеними згідно з Наказами Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007, N 445/5 ( z0239-08 ) від 20.03.2008 }

Керівником стажування може бути державний нотаріус або нотаріус, що займається приватною нотаріальною практикою, за їх згодою та має стаж роботи нотаріусом не менше п'яти років.

Керівник стажування не може одночасно стажувати двох і більше стажистів. { Пункт 8 доповнено абзацом третім згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

9. Для визначення кількості посад стажистів нотаріуса управління юстиції подає один раз на календарний рік до Міністерства юстиції України пропозиції з відповідним обґрунтуванням, виходячи з кількості наявних вакантних посад державних нотаріусів у державних нотаріальних конторах та з реальних потреб щодо забезпечення нотаріальними послугами в нотаріальних округах, де відсутні державні та/або приватні нотаріуси, з зазначенням нотаріусів, які пропонуються (за їх згодою) керівниками стажування. Кількість посад стажистів нотаріуса у відповідних регіонах визначається наказом Міністерства юстиції України. { Пункт 9 із змінами, внесеними згідно з Наказом Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007, в редакції Наказу Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

10. Особа, яка має намір пройти стажування, не пізніше ніж за тиждень до дня проведення іспиту особисто подає до кваліфікаційної комісії такі документи:

заяву на ім'я голови кваліфікаційної комісії;

оригінал та копію диплома про вищу юридичну освіту;

оригінал та копію довідки про відсутність судимості (інформація, викладена у довідці, береться до уваги протягом одного місяця); { Абзац четвертий пункту 10 із змінами, внесеними згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

трудову книжку та копію трудової книжки чи завірену з місця роботи копію трудової книжки (за наявності трудового стажу);

паспорт та копію першої та другої сторінок паспорта громадянина України;

заповнену особову картку за формою, наведеною у додатку до цього Порядку. { Пункт 10 доповнено абзацом згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

11. Копії вищезазначених документів, крім паспорта, повинні бути завірені в установленому порядку, а оригінали повернуті особі.

12. Особи, які бажають узяти участь у іспиті, можуть подавати додаткову інформацію стосовно своєї освіти, досвіду роботи, професійного рівня (копії документів про підвищення кваліфікації, присвоєння наукового ступеня чи вченого звання, характеристики, рекомендації, наукові публікації тощо).

13. Засвідчені копії документів формуються в особову справу особи, яка має намір скласти іспит.

14. Приміщення для проведення іспиту має відповідати умовам зручного розміщення, унеможливлювати спілкування осіб, допущених до іспиту, та забезпечувати індивідуальну підготовку відповідей.

Особи, допущені до іспиту, не можуть самостійно залишати приміщення, в якому проходить іспит, до його закінчення. { Пункт 14 доповнено абзацом згідно з Наказом Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007 }

15. Іспит, як правило, проводиться в один день.

У разі допущення до складання іспиту більше двадцяти осіб, іспит проводиться у декілька днів і вважається закінченим після участі в ньому всіх осіб, що допущені та з'явилися на іспит.

{ Пункт 15 в редакції Наказу Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007 }

16. Іспит проводиться за білетами державною мовою письмово.

17. Білети розробляються Міністерством юстиції до кожного іспиту на підставі Примірного переліку питань для іспиту громадян України, які бажають пройти стажування в державних нотаріальних конторах або в нотаріусів, що займаються приватною нотаріальною практикою, затвердженого Вищою кваліфікаційною комісією нотаріату. Білет має складатися з п'яти питань, різних за тематикою, підписується директором або заступником директора Департаменту нотаріату та реєстрації адвокатських об'єднань Мін'юсту, скріплюється печаткою цього Департаменту. Білети заклеюються у конверт. Конверт з білетами доставляє член кваліфікаційної комісії - представник Мін'юсту в день проведення іспиту. { Пункт 17 в редакції Наказу Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007, із змінами, внесеними згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

18. На початку іспиту кваліфікаційна комісія інформує осіб, допущених до складання цього іспиту, про порядок проведення іспиту.

Білети пропонуються кваліфікаційною комісією особам, допущеним до складання іспиту, на їх вибір після відкриття конверта членом кваліфікаційної комісії - представником Мін'юсту у присутності інших членів кваліфікаційної комісії та осіб, що складають іспит. { Абзац другий пункту 18 із змінами, внесеними згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

Аркуші для відповідей підписуються членами кваліфікаційної комісії. Кожній особі, яка складає іспит, видається по два аркуші для відповідей. У разі необхідності на прохання особи, яка складає іспит, видаються додаткові аркуші для відповідей. Кількість виданих аркушів має відповідати кількості зданих аркушів. { Абзац третій пункту 18 із змінами, внесеними згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

Аркуші, на яких викладено відповіді на питання, що включені до білетів, підписуються особами, допущеними до складання іспиту, із зазначенням своїх прізвища, імені та по батькові.

{ Пункт 18 в редакції Наказу Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007 }

19. Під час підготовки відповідей на білети мають бути присутні не менше трьох членів кваліфікаційної комісії.

20. На підготовку відповідей відводиться не більше двох годин.

21. Під час проведення іспиту забороняється використовувати акти законодавства України, підручники, навчальні посібники та інші джерела інформації. При користуванні під час іспиту сторонніми джерелами інформації (у тому числі підказуванням) особа, допущена до складання іспиту, усувається від участі в іспиті. При перевірці відповіді в цьому разі виставляється незадовільна оцінка незалежно від обсягу і змісту написаного.

22. Після закінчення часу, відведеного для іспиту, письмові роботи здаються для перевірки членами кваліфікаційної комісії. Відповідь на кожне питання оцінюється за дванадцятибальною системою.

Особи, які в сумі по всіх питаннях білета набрали менше ніж 50 балів, вважаються такими, що не склали іспит. { Пункт 22 доповнено абзацом згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

{ Пункт 22 в редакції Наказу Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007 }

23. За результатами оцінки письмової роботи та співбесіди кваліфікаційна комісія більшістю присутніх приймає рішення про допуск осіб до стажування.

У разі, якщо правильні відповіді надано особами, кількість яких перевищує кількість посад стажистів, визначених наказом Міністерства юстиції України, перевага надається особам, відповіді яких є найбільш повними та змістовними. { Абзац другий пункту 23 із змінами, внесеними згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

Для з'ясування обсягу знань осіб, які складають іспит, кваліфікаційна комісія може проводити з ними співбесіду, на якій присутність інших осіб, що складають іспит, не допускається.

Особи, не допущені до стажування, мають право взяти участь у наступному іспиті для допуску до стажування на загальних підставах.

Представник Мін'юсту має право перевірити повноту, об'єктивність, правильність результатів оцінювання. У разі неналежного оцінювання відповідей членами кваліфікаційної комісії, представник Мін'юсту повідомляє про це Міністерство юстиції України. { Абзац п'ятий пункту 23 із змінами, внесеними згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 } { Пункт 23 в редакції Наказу Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007 }

24. У разі порушення вимог цього Порядку представник Мін'юсту має право ініціювати перед кваліфікаційною комісією питання про зупинення проведення іспиту до усунення порушення. Кваліфікаційна комісія зобов'язана негайно усунути порушення. У разі неможливості усунення порушень, кваліфікаційна комісія зобов'язана припинити проведення цього іспиту.

У разі припинення іспиту дата проведення наступного іспиту визначається кваліфікаційною комісією за погодженням з Міністерством юстиції.

Рішення кваліфікаційної комісії оформляється протоколом, який підписують головуючий на засіданні та секретар.

{ Пункт 24 в редакції Наказу Міністерства юстиції N 733/5 ( z1050-07 ) від 07.09.2007 }

25. На підставі рішення кваліфікаційної комісії про допуск до стажування управління юстиції або приватний нотаріус-керівник стажування видають наказ про проходження протягом шести місяців стажування.

У наказі обов'язково зазначаються місце проходження стажування керівник стажування, дата початку та закінчення стажування.

{ Пункт 25 в редакції Наказу Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

26. Документи, подані особами, які допущені до стажування, за результатами іспиту зберігаються в управлінні юстиції.

Документи, подані особами, які за результатами іспиту не допущені до стажування, повертаються їм у місячний термін після проведення іспиту.

Відповіді учасників іспиту на питання, що включені до білетів, зберігаються в управлінні юстиції.

27. Керівник стажування складає індивідуальний план стажування на підставі примірної програми стажування і подає для затвердження начальнику управління юстиції чи його заступнику з питань нотаріату.

28. Контроль за проведенням стажування, засвоєнням програми стажування, виконанням індивідуального плану стажистом здійснює керівник стажування та вповноважена на те особа управління юстиції.

У разі проходження особою стажування в державній нотаріальній конторі запис у трудовій книжці про проходження стажування вноситься уповноваженою на те особою управління юстиції. У разі проходження особою стажування у приватного нотаріуса такий запис вноситься приватним нотаріусом - керівником стажування. { Пункт 28 доповнено абзацом згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }

29. За результатами проходження стажування керівник стажування складає висновок про проходження стажування і подає його на затвердження начальнику управління юстиції чи його заступнику з питань нотаріату.

30. Затвердження висновку здійснюється у разі, коли особа, яка пройшла стажування, виконала в повному обсязі індивідуальний план стажування та досягла обсягу знань, достатніх для участі в складанні кваліфікаційного іспиту.

31. У разі затвердження вказаного висновку вважається, що стажист пройшов стажування.

32. У разі незатвердження вказаного висновку має бути винесена вмотивована відмова, що направляється особі, яка не пройшла стажування.

33. Особа, яка не пройшла стажування, може бути допущена до наступного стажування на загальних підставах відповідно до цього Порядку. { Пункт 33 із змінами, внесеними згідно з Наказом Міністерства юстиції N 445/5 ( z0239-08 ) від 20.03.2008 }
