N 1431 від 11.07.2000 Зареєстровано в Міністерстві юстиції України 27 липня 2000 р. за N 449/4670

( Наказ втратив чинність на підставі Наказу Фонду державного майна N 848 ( z0616-04 ) від 27.04.2004 )

Про затвердження форми заяви про включення об'єкта до переліку об'єктів, що підлягають приватизації

( Із змінами, внесеними згідно з Наказом Фонду державного майна N 452 ( z0320-01 ) від 21.03.2001 )

На виконання пункту 4 статті 7 Закону України "Про приватизацію невеликих державних підприємств (малу приватизацію)" ( 2171-12 ) та з метою упорядкування процесу включення об'єктів груп А, Д та Ж до переліків об'єктів, що підлягають приватизації, НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Фонду державного майна України від 08.10.96 N 1180 ( z0624-96 ) "Про затвердження форми заяви на приватизацію об'єкта малої приватизації", зареєстрований в Міністерстві юстиції України 23.10.96 за N 624/1649.

2. Затвердити форму заяви про включення об'єкта до переліку об'єктів, що підлягають приватизації, згідно з додатком.

3. Департаменту індивідуального продажу в триденний термін із дня прийняття цього наказу забезпечити подання форми заяви на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням наказу покласти на заступника Голови Фонду Л.Кальніченка.

В.о. Голови Фонду М.Чечетов
