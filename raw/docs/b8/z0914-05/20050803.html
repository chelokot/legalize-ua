Зареєстровано в Міністерстві юстиції України 19 серпня 2005 р. за N 914/11194

Про втрату чинності деяких наказів Міністерства транспорту України

Відповідно до Положення про Міністерство транспорту та зв'язку України, затвердженого Указом Президента України від 27.08.2004 N 1009 ( 1009/2004 ), НАКАЗУЮ:

1. Уважати такими, що втратили чинність, накази Міністерства транспорту України:

від 26.12.2000 N 741 ( z0044-01 ) "Про затвердження Положення про акредитацію суб'єктів, які здійснюють попередню перевірку агентств з продажу авіаційних перевезень", зареєстрований в Міністерстві юстиції України 19.01.2001 за N 44/5235;

від 28.05.2001 N 328 ( z0500-01 ) "Про внесення змін і доповнень до Положення про акредитацію суб'єктів, які здійснюють попередню перевірку агентств з продажу авіаційних перевезень", зареєстрований в Міністерстві юстиції України 12.06.2001 за N 500/5691;

від 15.06.2004 N 502 ( z0758-04 ) "Про внесення змін до Положення про акредитацію суб'єктів, які здійснюють попередню перевірку агентств з продажу авіаційних перевезень", зареєстрований в Міністерстві юстиції України 21.06.2004 за N 758/9357.

2. Юридичному департаменту (Ониськів М.М.) подати цей наказ в установленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Рябікіна П.Б.

Міністр Є.А.Червоненко
