Текст документа від 24.09.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 липня 1999 р. N 1184 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1387 ( 1387-99-п ) від 29.07.99 )

Про внесення змін до постанови Кабінету Міністрів України від 3 листопада 1997 р. N 1215

Кабінет Міністрів України постановляє:

1. У додатку до постанови Кабінету Міністрів України від 3 листопада 1997 р. N 1215 ( 1215-97-п ) "Про встановлення мінімальної митної вартості окремих видів товарів" (Офіційний вісник України, 1997 р., N 45, ст. 49) виключити цифри і слова:

"12.01.00 Соя подрібнена або неподрібнена 0,51".

2. Ця постанова набирає чинності з дня опублікування.
