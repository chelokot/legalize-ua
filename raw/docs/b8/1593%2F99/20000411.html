УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 583/2000 від 11.04.2000 )

Про внесення зміни до складу Комісії по державних нагородах України

На зміну Указу Президента України від 9 грудня 1994 року N 747 ( 747/94 ) "Про Комісію по державних нагородах України при Президентові України" (із змінами, внесеними Указами Президента України від 31 травня 1996 року N 391 ( 391/96 ), від 7 лютого 1997 року N 103 ( 103/97 ), від 2 грудня 1998 року N 1322 ( 1322/98 ) та від 29 грудня 1998 року N 1380 ( 1380/98 ) ввести до складу зазначеної Комісії ЛИТВИНА Володимира Михайловича - Главу Адміністрації Президента України, призначивши його Головою Комісії, та вивести з її складу Білоблоцького М.П.

Президент України Л.КУЧМА
