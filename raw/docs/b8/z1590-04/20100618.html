Зареєстровано в Міністерстві юстиції України 16 грудня 2004 р. за N 1590/10189

{ Наказ втратив чинність на підставі Наказу Головного контрольно-ревізійного управління N 152 ( z0365-10 ) від 17.05.2010 }

Про внесення змін до наказу від 28.11.2002 N 242

Відповідно до пункту 3 постанови Кабінету Міністрів України від 22.05.2002 N 685 ( 685-2002-п ) "Про здійснення міністерствами, іншими центральними органами виконавчої влади внутрішнього фінансового контролю" (із змінами) та у зв'язку зі зміною структури ГоловКРУ України НАКАЗУЮ:

1. Унести до наказу ГоловКРУ України від 28.11.2002 N 242 ( z0989-02 ) "Про затвердження Порядку погодження з органами державної контрольно-ревізійної служби питання щодо призначення та звільнення з посад керівників контрольно-ревізійних підрозділів міністерств, інших центральних органів виконавчої влади та їх територіальних підрозділів", зареєстрованого в Міністерстві юстиції України 19 грудня 2002 року за N 989/7277 (далі - наказ) та Порядку погодження з органами державної контрольно-ревізійної служби питання щодо призначення та звільнення з посад керівників контрольно-ревізійних підрозділів міністерств, інших центральних органів виконавчої влади та їх територіальних підрозділів, затвердженого цим наказом, такі зміни:

у назві наказу, пункті 1 наказу, назві Порядку ( z0989-02 ) та пунктах 1.2, 1.3 Порядку слова "територіальні підрозділи" у всіх відмінках замінити словами "територіальні органи" у відповідних відмінках;

у пункті 2.3 Порядку ( z0989-02 ) слова "Управлінням організаційної роботи" замінити словами "Управлінням нормативно-методологічного забезпечення та взаємодії з підрозділами внутрішнього фінансового контролю".

2. Управлінню нормативно-методологічного забезпечення та взаємодії з підрозділами внутрішнього фінансового контролю (Бариніна-Закірова М.В.) забезпечити державну реєстрацію цього наказу в Міністерстві юстиції України.

3. Загальному відділу (Грошикова Г.А.) довести цей наказ до відома заступників Голови ГоловКРУ України, начальників управлінь та самостійних відділів центрального апарату, начальників контрольно-ревізійних управлінь в Автономній Республіці Крим, областях, містах Києві та Севастополі.

Голова П.К.Германчук
