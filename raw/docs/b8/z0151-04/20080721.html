Про впорядкування окремих питань застосування заходів гарантування доставки товарів

{ Із змінами, внесеними згідно з Наказом Державної митної служби N 396 ( z0508-08 ) від 17.04.2008 }

Відповідно до статей 161 і 163 Митного кодексу України від 11.07.2002 N 92-IV ( 92-15 ), з метою забезпечення реалізації підпункту 5 пункту 1 розділу IV Комплексної програми утвердження України як транзитної держави у 2002-2010 роках, затвердженої Законом України від 07.02.2002 N 3022-III ( 3022-14 ), НАКАЗУЮ:

1. Доповнити пункт 1.3 Інструкції про організацію та порядок охорони й супроводження товарів підрозділами митної варти Державної митної служби України, затвердженої наказом Держмитслужби України від 20.08.2003 N 565 ( z0746-03 ) і зареєстрованої в Міністерстві юстиції України 29.08.2003 за N 746/8067, другим, третім і четвертим абзацами такого змісту:

"У випадку, коли нарахована сума податків і зборів (обов'язкових платежів), що підлягає сплаті, за товар, який має переміщуватися транзитом через митну територію України із застосуванням книжки МДП, перевищує суму гарантійного забезпечення (більше ніж еквівалент 50 000 доларів США), процедура перевезення із застосуванням книжки МДП призупиняється, і в разі необхідності подальше переміщення товару через митну територію України здійснюється із застосуванням заходів гарантування доставки, передбачених пунктами 1-3 статті 161 Митного кодексу України від 11.07.2002 N 92-IV ( 92-15 ).

При переміщенні митною територією України товарів, що перебувають під митним контролем, їх охорона й супроводження силами митних органів як при внутрішньому, так і прохідному транзиті застосовуються в кожному конкретному випадку за рішенням митного органу, що приймається на підставі всебічного аналізу ступеня ризику, обумовленого відомостями про перевізника, маршрут перевезення, характер вантажу тощо.

При цьому митним органом визначаються строки, коли може бути застосований цей захід гарантування доставки, з урахуванням наявних сил і засобів".

{ Пункт 2 фактично втратив чинність у зв'язку з втратою чинності Наказу Державної митної служби N 49 ( z0087-03 ) від 27.01.2003, до якого вносились зміни } 2. У пункті 1 наказу Держмитслужби України N 49 ( z0087-03 ) "Про посилення контролю за доставкою в митниці призначення окремих видів товарів", зареєстрованого в Міністерстві юстиції України 04.02.2003 за N 87/7408, слова "із залученням у потрібних випадках підрозділів Міністерства внутрішніх справ України відповідно до постанови Кабінету Міністрів України від 29.06.96 N 699 ( 699-96-п ) "Про затвердження Положення про порядок охорони і супроводження товарів митними органами та підрозділами Міністерства внутрішніх справ" замінити словами "відповідно до наказу Держмитслужби України від 20.08.2003 N 565 ( z0746-03 ) "Про затвердження Інструкції про організацію та порядок охорони й супроводження товарів підрозділами митної варти Державної митної служби України", зареєстрованого в Міністерстві юстиції України 29.08.2003 за N 746/8067".

3. Управлінню митної варти (Романенко Г.В.) і Управлінню правової роботи (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Установити, що цей наказ набирає чинності через 10 днів після його державної реєстрації в Міністерстві юстиції України.

5. Контроль за виконанням цього наказу покласти на першого заступника Голови Служби Лозка В.Я.
