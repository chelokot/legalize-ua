УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Адміністрацію Президента України

( Із змінами, внесеними згідно з Указами Президента N 552/92 ( 552/92 ) від 07.11.92 N 638/92 ( 638/92 ) від 28.12.92 )

1. Утворити Адміністрацію Президента України у складі:

Соціально-економічної ради Президента України та апарату Радника Президента України з соціально-економічних питань;

Комісії Президента України з політико-правових питань та апарату Радника Президента України з політико-правових питань;

Комісії Президента України з питань науки та апарату Радника Президента України з питань науки;

Комісії Президента України по зв'язках з міжнародними фінансовими установами та контролю за зовнішньоекономічною діяльністю та апарату Радника Президента України з зовнішньоекономічних питань;

Групи помічників та референтів Президента України;

Служба Президента України з питань територій; ( Статтю 1 доповнено абзацом сьомим згідно з Указом Президента N 638/92 ( 638/92 ) від 28.12.92 )

Служби Президента України з міжнародних питань;

Служби безпеки Президента України;

Прес-служби Президента України;

Інформаційно-аналітичної служби Президента України;

Служби Протоколу Президента України;

Служби матеріально-технічного і фінансового забезпечення;

Загального відділу;

Відділу нагород;

Відділу у питаннях громадянства;

Відділу у питаннях помилування;

Відділу листів і прийому громадян;

Відділу оргтехніки і комп'ютеризації;

Канцелярії;

Сектора кадрів;

Сектора контролю.

( Стаття 1 в редакції Указу Президента N 552/92 ( 552/92 ) від 07.11.92 )

2. Адміністрацію Президента України очолює Секретар.
