Кабінет Міністрів України; Постанова від 01.07.2009 № 745

Питання фінансово-господарської діяльності Державної адміністрації залізничного транспорту та залізниць

Стан: Втратив чинність

Ідентифікатор: 745-2009-п

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 липня 2009 р. N 745 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Питання фінансово-господарської діяльності Державної адміністрації залізничного транспорту та залізниць

Кабінет Міністрів України постановляє:

Установити, що внесення змін до договорів про зовнішні кредити та закупівля послуг юридичних радників, необхідних для виконання зобов'язань за зовнішніми кредитами та внесення змін до таких договорів, здійснюється Державною адміністрацією залізничного транспорту та залізницями без застосування процедур Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006).
