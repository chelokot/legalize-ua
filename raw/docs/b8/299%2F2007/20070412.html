Президент України; Указ від 12.04.2007 № 299/2007

Про зупинення дії постанови Кабінету Міністрів України від 11 квітня 2007 року N 617

Стан: Втратив чинність

Ідентифікатор: 299/2007

Текст документа від 12.04.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанови Кабінету Міністрів України від 11 квітня 2007 року N 617

{ Додатково див. Конституційне подання Президента ( n0007100-07 ) від 12.04.2007 }

Кабінетом Міністрів України 11 квітня 2007 року видано постанову N 617 ( 617-2007-п ) "Про заходи щодо запобігання діям, які порушують Конституцію та закони України".

Названою постановою ( 617-2007-п ) визнається неможливим виконання Указу Президента України від 6 квітня 2007 року N 285 ( 285/2007 ) "Про рішення Ради національної безпеки і оборони України від 5 квітня 2007 року "Про суспільно-політичну ситуацію та невідкладні заходи щодо забезпечення конституційних прав громадян України".

Зазначене суперечить частині третій статті 106 Конституції України ( 254к/96-ВР ), якою встановлено, що укази Президента України, видані на основі та на виконання Конституції ( 254к/96-ВР ) і законів України, є обов'язковими до виконання на території України, частині третій статті 113 Основного Закону України ( 254к/96-ВР ), якою Кабінет Міністрів України зобов'язано у своїй діяльності керуватися, зокрема, прийнятими відповідно до Конституції ( 254к/96-ВР ) та законів України указами Президента України.

Указ Президента України ( 285/2007 ), про неможливість виконання якого йдеться у зазначеній постанові ( 617-2007-п ), прийнято на основі та на виконання частини сьомої статті 107 Конституції України ( 254к/96-ВР ), за якою рішення Ради національної безпеки і оборони України вводяться в дію указами глави держави.

Таким чином, Указ N 285 ( 285/2007 ) є обов'язковим до виконання Кабінетом Міністрів України, центральними та місцевими органами виконавчої влади, їх посадовими особами.

Відповідно до статті 116 Конституції України ( 254к/96-ВР ) Кабінет Міністрів України здійснює повноваження, визначені Конституцією ( 254к/96-ВР ) та законами України. Ні Конституція України ( 254к/96-ВР ), ні Закон України "Про Кабінет Міністрів України" ( 514-16 ), ні інші закони України не відносять до повноважень Кабінету Міністрів України вирішення питання щодо можливості виконання актів Президента України. Тож, вирішуючи питання про неможливість виконання Указу Президента України від 6 квітня 2007 року N 285 ( 285/2007 ), Кабінет Міністрів України вийшов за межі повноважень, передбачених для нього Конституцією України ( 254к/96-ВР ).

З огляду на це зазначене положення постанови Кабінету Міністрів України ( 617-2007-п ) не відповідає статті 116 Конституції України ( 254к/96-ВР ), а також статті 117 Основного Закону України ( 254к/96-ВР ), яка зобов'язує Кабінет Міністрів України видавати постанови і розпорядження виключно в межах своєї компетенції.

Постановою Кабінету Міністрів України ( 617-2007-п ), про яку йдеться, також доручено Прем'єр-міністру України Януковичу В.Ф., Першому віце-прем'єр-міністру України, Міністру фінансів України Азарову М.Я., Голові Державного казначейства України Харченку С.І., керівникам міністерств, інших центральних та місцевих органів виконавчої влади, Ради міністрів Автономної Республіки Крим керуватися у своїй діяльності постановами Верховної Ради України від 2 квітня 2007 року N 837-V ( 837-16 ) "Про запобігання діям, що загрожують конституційному правопорядку, громадському спокою і стабільності в Україні" та N 839-V ( 839-16 ) "Про політичну ситуацію в Україні, пов'язану з оголошенням Указу Президента України від 2 квітня 2007 року "Про дострокове припинення повноважень Верховної Ради України".

Указом Президента України від 2 квітня 2007 року N 264 ( 264/2007 ) "Про дострокове припинення повноважень Верховної Ради України", який набрав чинності з дня його опублікування в інформаційному бюлетені "Офіційний вісник Президента України" 2 квітня 2007 року, повноваження парламенту достроково припинено. За цих обставин зазначене доручення, передбачене постановою Кабінету Міністрів України ( 617-2007-п ), не відповідає статті 19 Конституції України ( 254к/96-ВР ), якою встановлено, що ніхто не може бути примушений робити те, що не передбачено законодавством, посадові особи органів державної влади зобов'язані діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) і законами України.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 11 квітня 2007 року N 617 ( 617-2007-п ) "Про заходи щодо запобігання діям, які порушують Конституцію та закони України".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
