Про затвердження Порядку проведення перевірки дотримання вимог нормативних документів і нормативів обчислення вартості будівництва об'єктів, що споруджуються із залученням бюджетних коштів, а також коштів державних і комунальних підприємств, установ та організацій, кредитів, наданих під державні гарантії

Стан: Втратив чинність

Ідентифікатор: 1210-98-п

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 серпня 1998 р. N 1210 Київ

Про Порядок здійснення контролю за визначенням вартості будівництва об'єктів, що споруджуються із залученням коштів державного та місцевих бюджетів, а також коштів державних підприємств, установ та організацій

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 663 ( 663-2012-п ) від 25.07.2012 }

{ Із змінами, внесеними згідно з Постановами КМ N 1231 ( 1231-2000-п ) від 07.08.2000 N 663 ( 663-2012-п ) від 25.07.2012 }

З метою ефективного використання інвестицій та забезпечення контролю за визначенням вартості будівництва на об'єктах, що споруджуються із залученням коштів державного та місцевих бюджетів, а також коштів державних підприємств, установ та організацій, Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 663 ( 663-2012-п ) від 25.07.2012 }

1. Затвердити Порядок здійснення контролю за визначенням вартості будівництва об'єктів, що споруджуються із залученням коштів державного та місцевих бюджетів, а також коштів державних підприємств, установ та організацій (додається).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 663 ( 663-2012-п ) від 25.07.2012 }

2.{ Абзац перший пункту 2 втратив чинність на підставі Постанови КМ N 1231 ( 1231-2000-п ) від 07.08.2000 }

Міністерству фінансів передбачити у проектах Державного бюджету України на 1999 та наступні роки необхідні асигнування для утримання зазначеної інспекції.

3. Державному комітетові будівництва, архітектури та житлової політики у тримісячний термін розробити і затвердити Інструкцію про проведення перевірок визначення вартості будівництва об'єктів, що споруджуються із залученням коштів Державного бюджету України, бюджету Автономної Республіки Крим, місцевих бюджетів, а також коштів державних підприємств, установ та організацій.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 3 серпня 1998 р. N 1210

ПОРЯДОК здійснення контролю за визначенням вартості будівництва об'єктів, що споруджуються із залученням коштів державного та місцевих бюджетів, а також коштів державних підприємств, установ та організацій

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 663 ( 663-2012-п ) від 25.07.2012 }

{ У тексті Порядку слова "Держбуд", "Держцінбудінспекція" в усіх відмінках замінено словом "Мінрегіон" у відповідному відмінку згідно з Постановою КМ N 663 ( 663-2012-п ) від 25.07.2012 }

1. Контроль за визначенням вартості будівництва об'єктів, що споруджуються із залученням коштів державного та місцевих бюджетів, а також коштів державних підприємств, установ та організацій, здійснює Мінрегіон.

{ Пункт 1 в редакції Постанови КМ N 663 ( 663-2012-п ) від 25.07.2012 }

2. Контролю підлягають усі учасники інвестиційного процесу незалежно від форм власності, а саме - проектно-вишукувальні, підрядні організації, постачальники, підприємства, установи, організації та інші суб'єкти підприємницької діяльності, що надають відповідні послуги (далі - підприємства), а також замовники. Цей контроль здійснюється за окремими планами на об'єктах нового будівництва, реконструкції, технічного переоснащення, реставрації, ремонту, створення інженерної і транспортної інфраструктури та комплексного благоустрою територій. { Пункт 2 із змінами, внесеними згідно з Постановою КМ N 663 ( 663-2012-п ) від 25.07.2012 }

3. Здійснюючи контроль, Мінрегіон виконує такі основні функції:

формує плани перевірок;

готує пропозиції щодо складу спеціальних комісій для проведення перевірок визначення вартості будівництва конкретних об'єктів (далі - комісії);

організує роботу комісій і здійснює методичне керівництво та нормативне забезпечення з питань контролю визначення вартості будівництва.

4. Мінрегіон має право:

одержувати від центральних та місцевих органів виконавчої влади, органів місцевого самоврядування відповідну інформацію щодо переліків об'єктів будівництва, що споруджуються із залученням коштів державного та місцевих бюджетів, а також коштів державних підприємств, установ та організацій, обсягів фінансування цих об'єктів, термінів введення в дію, а також найменування і адреси замовників; { Абзац другий пункту 4 із змінами, внесеними згідно з Постановою КМ N 663 ( 663-2012-п ) від 25.07.2012 }

розглядати акти перевірок і направляти замовнику та керівникові підприємства, яке перевірялось, вимоги до усунення виявлених порушень і уточнення взаєморозрахунків з поверненням відповідних сум на розрахунковий рахунок замовника, за формою, яка затверджується Мінрегіоном;

направляти в разі потреби відповідні матеріали до органів державної податкової служби та до слідчих органів.

5. Мінрегіон, виконуючи покладені функції, взаємодіє з відповідними контрольними органами.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 663 ( 663-2012-п ) від 25.07.2012 }

6. До складу комісій, що утворюються наказом Мінрегіону для проведення перевірки на конкретних об'єктах, включаються працівники Мінрегіону, інших центральних та місцевих органів виконавчої влади, органів місцевого самоврядування, а також фахівці науково-дослідних, проектних та підрядних організацій за згодою їх керівників. Головою комісії призначається працівник Мінрегіону. Для роботи з комісією замовник і підприємство, яке перевіряється, направляють своїх уповноважених представників.

7. Комісія здійснює перевірку правильності визначення:

вартості будівництва на всіх її стадіях формування з використанням затвердженої в установленому порядку проектно-кошторисної документації, облікових, звітних, платіжних та інших документів та проведенням у необхідних випадках обстежень об'єкта і контрольних обмірів виконаних робіт;

обсягу коштів, необхідних для фінансування робіт, що виконуються за рахунок резервного фонду бюджету, у тому числі пов'язаних з ліквідацією наслідків надзвичайних ситуацій, та готує висновки для Мінекономрозвитку. { Абзац третій пункту 7 в редакції Постанови КМ N 663 ( 663-2012-п ) від 25.07.2012 }

8. Комісія має право на:

1) безперешкодний доступ на об'єкт, що перевіряється;

2) одержання від замовника та підприємства, яке перевіряється, нормативної, проектно-кошторисної документації, документів первинного, бухгалтерського обліків тощо, необхідних для виконання покладених на неї функцій;

3) безоплатне одержання від виробників будівельних матеріалів, виробів та конструкцій, продукцію яких придбано підприємством, яке перевіряється, та автотранспортних підприємств, що надавали йому послуги, а також органів державної статистики даних:

про вартість матеріальних ресурсів (послуг) з її обгрунтуванням, калькуляцією тощо;

статистичної звітності з капітального будівництва;

4) одержання від посадових і матеріально відповідальних осіб письмових пояснень з питань, що виникають у ході перевірок.

9. За наслідками перевірки комісія складає акт перевірки за формою, що затверджується Мінрегіоном. У разі виявлення фактів порушень порядку ціноутворення, що діяв на момент розрахунків за виконані на будівництві роботи, визначається сума завищень як у розрахунках за виконані роботи і послуги, так і у витратах замовника. Акт підписується головою та членами комісії, а також уповноваженими представниками замовника та підприємства, яке перевірялось. Акт передається до Мінрегіону, а копія - замовнику та підприємству, яке перевірялось.

10. У разі незгоди з фактами, викладеними в акті перевірки, керівники замовника та підприємства, яке перевірялось, зобов'язані підписати акт і в триденний термін подати Мінрегіону письмові пояснення з відповідними документами. У разі незгоди з рішенням Мінрегіону, прийнятим після розгляду пояснень та поданих документів, спірні питання вирішуються у встановленому законодавством порядку. Заперечення та пояснення не дають права на припинення виконання вимог Мінрегіону.

{ Пункт 10 із змінами, внесеними згідно з Постановою КМ N 663 ( 663-2012-п ) від 25.07.2012 }
