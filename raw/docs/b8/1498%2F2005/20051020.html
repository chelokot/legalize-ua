Про внесення змін до Мережі та кількісного складу суддів місцевих судів

Стан: Втратив чинність

Текст документа від 20.10.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Мережі та кількісного складу суддів місцевих судів

Відповідно до частини четвертої статті 20 Закону України "Про судоустрій України" ( 3018-14 ) постановляю:

Внести до Мережі та кількісного складу суддів місцевих судів, затверджених Указом Президента України від 20 серпня 2001 року N 641 ( 641/2001 ) (зі змінами, внесеними Указами від 18 жовтня 2001 року N 990 ( 990/2001 ), від 19 лютого 2002 року N 152 ( 152/2002 ), від 22 жовтня 2002 року N 938 ( 938/2002 ), від 25 січня 2003 року N 41 ( 41/2003 ), від 15 березня 2004 року N 328 ( 328/2004 ), від 21 травня 2004 року N 573 ( 573/2004 ) та від 15 січня 2005 року N 36 ( 36/2005 ), такі зміни:

у розділі "м. Київ":

у пункті 6 цифри "25" замінити цифрами "28";

цифри "237" замінити цифрами "250".

Президент України В.ЮЩЕНКО

м. Київ, 20 жовтня 2005 року N 1498/2005
