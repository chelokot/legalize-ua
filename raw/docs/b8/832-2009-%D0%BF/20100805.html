Кабінет Міністрів України; Постанова від 05.08.2009 № 832

Питання забезпечення житлом окремих категорій громадян, які відповідно до законодавства потребують поліпшення житлових умов

Стан: Чинний

Ідентифікатор: 832-2009-п

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 серпня 2009 р. N 832 Київ

Питання забезпечення житлом окремих категорій громадян, які відповідно до законодавства потребують поліпшення житлових умов

{ Із змінами, внесеними згідно з Постановами КМ N 861 ( 861-2009-п ) від 12.08.2009 N 891 ( 891-2009-п ) від 19.08.2009 N 666 ( 666-2010-п ) від 28.07.2010 }

Кабінет Міністрів України постановляє:

Установити, що:

Державна іпотечна установа має право спрямовувати кошти, отримані від запозичень, здійснених шляхом випуску облігацій під державні гарантії відповідно до Порядку надання державних гарантій за зобов'язаннями Державної іпотечної установи, затвердженого постановою Кабінету Міністрів України від 3 серпня 2006 р. N 1094 ( 1094-2006-п ) "Питання надання державних гарантій за зобов'язаннями Державної іпотечної установи" (Офіційний вісник України, 2006 р., N 32, ст. 2319), на фінансування заходів щодо забезпечення житлом окремих категорій громадян, які відповідно до законодавства потребують поліпшення житлових умов та перебувають на квартирному обліку, зокрема на придбання квартир за переліками, що затверджуються Кабінетом Міністрів України, у житлових будинках, зданих в експлуатацію, у яких виконано внутрішні опоряджувальні роботи та визначена забудовником вартість 1 кв. метра житла становить 2500-4200 гривень, а також квартир на об'єктах незавершеного житлового будівництва за умови, що строк здачі в експлуатацію об'єкта не пізніше ніж 25 грудня 2009 р., у квартирах на момент здачі будуть виконані внутрішні опоряджувальні роботи і визначена забудовником вартість 1 кв. метра житла становитиме 2500-4200 гривень, та за наявності у забудовника відповідної банківської гарантії або іншого виду забезпечення виконання зобов'язань забудовників, що прийматимуться Державною іпотечною установою, або наявності графіка виконання будівельно-монтажних робіт, погодженого з керівником інспекції державного архітектурно-будівельного контролю в Автономній Республіці Крим, областях, мм. Києві та Севастополі. { Абзац другий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 861 ( 861-2009-п ) від 12.08.2009 }

{ Абзац третій постановляючої частини втратив чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Оплата Державною іпотечною установою квартир на об'єктах незавершеного житлового будівництва здійснюється: { Постановляючу частину доповнено абзацом згідно з Постановою КМ N 891 ( 891-2009-п ) від 19.08.2009 }

не менш як 70 відсотків загальної вартості квартир перераховується після укладення зазначеною установою договору про відчуження майнових прав на відповідні квартири та його державної реєстрації згідно із законодавством; { Постановляючу частину доповнено абзацом згідно з Постановою КМ N 891 ( 891-2009-п ) від 19.08.2009 }

решта - після виконання внутрішніх опоряджувальних робіт та здачі об'єкта в експлуатацію, а також реєстрації прав власності Державної іпотечної установи на придбані квартири. { Постановляючу частину доповнено абзацом згідно з Постановою КМ N 891 ( 891-2009-п ) від 19.08.2009 }
