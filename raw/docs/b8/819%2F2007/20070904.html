Президент України; Указ від 04.09.2007 № 819/2007

Про зупинення дії постанови Кабінету Міністрів України від 8 серпня 2007 року N 1037

Стан: Втратив чинність

Ідентифікатор: 819/2007

Текст документа від 04.09.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанови Кабінету Міністрів України від 8 серпня 2007 року N 1037

{ Додатково див. Конституційне подання Президента ( n0020100-07 ) від 04.09.2007 }

Кабінетом Міністрів України 8 серпня 2007 року видано постанову N 1037 ( 1037-2007-п ) "Про управління державними корпоративними правами закритого акціонерного товариства "Транснаціональна фінансово-промислова нафтова компанія "Укртатнафта".

Відповідно до цієї постанови ( 1037-2007-п ) Міністерство палива та енергетики України разом з Національною акціонерною компанією "Нафтогаз України" мають здійснити заходи щодо передачі Фонду державного майна України пакета акцій, які належать державі у статутному капіталі закритого акціонерного товариства "Транснаціональна фінансово-промислова нафтова компанія "Укртатнафта" (пункт 2) ( 1037-2007-п ). Постановою ( 1037-2007-п ) також установлюється, що повноваження з управління державними корпоративними правами закритого акціонерного товариства "Транснаціональна фінансово-промислова нафтова компанія "Укртатнафта" здійснює Фонд державного майна України (пункт 1) ( 1037-2007-п ).

У зв'язку з цим слід зазначити, що пакет акцій, який належить державі у статутному капіталі акціонерного товариства "Транснаціональна фінансово-промислова нафтова компанія "Укртатнафта", входить до складу активів Національної акціонерної компанії "Нафтогаз України" і впливає на її господарську діяльність, зокрема на кредитну політику.

Позбавлення Національної акціонерної компанії "Нафтогаз України" зазначених активів не тільки призведе до недоотримання цією компанією економічних вигод, погіршення її платоспроможності, але й унеможливить виконання взятих компанією зобов'язань, зокрема перед своїми кредиторами, що може мати наслідком порушення справи про її банкрутство.

Отже, зазначена постанова Кабінету Міністрів України ( 1037-2007-п ) створює передумови для погіршення фінансово-економічного стану і навіть банкрутства Національної акціонерної компанії "Нафтогаз України", метою діяльності якої є підвищення рівня енергетичної безпеки держави, забезпечення ефективного функціонування та розвитку нафтогазового комплексу. Це, в свою чергу, створює загрозу економічній безпеці держави.

Відтак, названа постанова Кабінету Міністрів України ( 1037-2007-п ) не відповідає частині першій статті 17 Конституції України ( 254к/96-ВР ), за якою забезпечення економічної безпеки держави є однією з її найважливіших функцій, порушує Закон України "Про основи національної безпеки України" ( 964-15 ), яким стале функціонування і розвиток паливно-енергетичного комплексу держави визначено одним з основних напрямів державної політики з питань національної безпеки в економічній сфері (стаття 8). Тому зазначена постанова ( 1037-2007-п ) суперечить також частині другій статті 8 Основного Закону України ( 254к/96-ВР ), за якою нормативно-правові акти приймаються на основі Конституції України ( 254к/96-ВР ) і повинні відповідати їй, нормам частини другої статті 6, частини другої статті 19 та частини третьої статті 113 Конституції України ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, діяти на підставі та у спосіб, що ними передбачені.

Ураховуючи наведене та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 8 серпня 2007 року N 1037 ( 1037-2007-п ) "Про управління державними корпоративними правами закритого акціонерного товариства "Транснаціональна фінансово-промислова нафтова компанія "Укртатнафта".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 4 вересня 2007 року N 819/2007
