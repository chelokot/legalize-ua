Деякі питання увічнення пам'яті жертв війни та політичних репресій

Стан: Чинний

Ідентифікатор: 767-2010-п

Текст документа від 25.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 серпня 2010 р. N 767 Київ

Деякі питання увічнення пам'яті жертв війни та політичних репресій

1. Внести до постанови Кабінету Міністрів України від 2 серпня 1996 р. N 897 ( 897-96-п ) "Про Державну міжвідомчу комісію у справах увічнення пам'яті жертв війни та політичних репресій" (ЗП України, 1996 р., N 16, ст. 426; Офіційний вісник України, 2004 р., N 28, ст. 1896; 2008 р., N 25, ст. 765) зміни, що додаються.

2. Українському інститутові національної пам'яті, Міністерству з питань житлово-комунального господарства разом з Міністерством фінансів вирішити в установленому порядку питання щодо передачі бюджетних призначень за програмою "Пошук і впорядкування поховань жертв війни та політичних репресій" Міністерству з питань житлово-комунального господарства у зв'язку з перерозподілом функцій.

Прем'єр-міністр України М.АЗАРОВ

Інд. 29

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 25 серпня 2010 р. N 767

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 2 серпня 1996 р. N 897 ( 897-96-п )

1. У пункті 3 постанови ( 897-96-п ) слова "державне підприємство "Центр", яке належить до сфери управління Українського інституту національної пам'яті" замінити словами "Міністерство з питань житлово-комунального господарства".

2. Додаток до постанови ( 897-96-п ) викласти у такій редакції:

"Додаток до постанови Кабінету Міністрів України від 2 серпня 1996 р. N 897 ( 897-96-п ) (у редакції постанови Кабінету Міністрів України від 25 серпня 2010 р. N 767)
