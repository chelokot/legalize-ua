Про організаційне забезпечення роботи Директора Національного бюро розслідувань

Стан: Чинний

Ідентифікатор: 932-97-п

Текст документа від 27.12.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 серпня 1997 р. N 932 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про організаційне забезпечення роботи Директора Національного бюро розслідувань

{ Службу Директора Національного бюро розслідувань України, утворену цією постановою, ліквідовано згідно з Постановою КМ N 2375 ( 2375-99-п ) від 27.12.1999 }

З метою організаційного забезпечення роботи Директора Національного бюро розслідувань та на виконання статті 10 Указу Президента України від 24 квітня 1997 р. N 371 ( 371/97 ) "Про Національне бюро розслідувань України" Кабінет Міністрів України постановляє:

1. Створити на період до завершення формування апарату Національного бюро розслідувань Службу Директора Національного бюро розслідувань.

2. Призначити Устименка Василя Євдокимовича керівником Служби Директора Національного бюро розслідувань.

3. Видатки на утримання Служби Директора Національного бюро розслідувань профінансувати у 1997 році за рахунок асигнувань, передбачених Кабінету Міністрів України у Державному бюджеті України на 1997 рік ( 404/97-ВР ).

4. Установити, що фінансове, транспортне та матеріально-технічне забезпечення Служби Директора Національного бюро розслідувань здійснюється через Господарське управління Кабінету Міністрів України.

5. Затвердити граничну чисельність працівників Служби Директора Національного бюро розслідувань у кількості 15 одиниць, відповідно збільшивши чисельність апарату Кабінету Міністрів України.

6. Прирівняти працівників Служби Директора Національного бюро розслідувань України за умовами оплати праці, матеріально-побутового, медичного і транспортного забезпечення до відповідних категорій працівників апарату Кабінету Міністрів України.
