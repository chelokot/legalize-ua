РОЗПОРЯДЖЕННЯ від 26 квітня 2007 р. N 232-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1063 ( 1063-2007-п ) від 15.08.2007 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 22 вересня 2006 р. N 491

У розпорядженні Кабінету Міністрів України від 22 вересня 2006 р. N 491 ( 491-2006-р ) "Деякі питання управління майном, яке вивільняється в ході реформування Збройних Сил" (Офіційний вісник України, 2006 р., N 39, ст. 2625, N 42, ст. 2821) слова ", та із спільною забудовою під житло територій колишніх військових містечок" виключити.

Прем'єр-міністр України В.ЯНУКОВИЧ
