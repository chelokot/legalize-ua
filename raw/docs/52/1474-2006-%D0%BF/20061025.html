ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 25 жовтня 2006 р. N 1474

ЗМІНИ, що вносяться до актів Кабінету Міністрів України

1. В абзаці першому пункту 1 розпорядження Кабінету Міністрів України від 2 лютого 2006 р. N 59 ( 59-2006-р ) "Про невідкладні заходи з відновлення систем життєзабезпечення у м. Алчевську Луганської області, забезпечення оздоровлення та навчання дітей" (Офіційний вісник України, 2006 р., N 5, ст. 245) цифри "15000" і "10000" замінити відповідно цифрами "14777" і "9777".

2. У пункті 2 розпорядження Кабінету Міністрів України від 15 березня 2006 р. N 134 ( 134-2006-р ) "Про поховання двічі Героя Соціалістичної Праці Буркацької Г.Є." слово та цифри "до 14" замінити цифрами "11,942".

3. У пункті 2 розпорядження Кабінету Міністрів України від 11 квітня 2006 р. N 199 ( 199-2006-р ) "Про поховання колишнього Міністра зовнішніх економічних зв'язків Герца І.І." слово та цифри "до 16" замінити цифрами "10,476".

4. В абзаці першому пункту 1 постанови Кабінету Міністрів України від 25 травня 2006 р. N 741 ( 741-2006-п ) "Про надання гуманітарної допомоги Ісламській Республіці Іран" цифри "2 660,5" замінити цифрами "2 656,004".

5. В абзаці першому пункту 1 постанови Кабінету Міністрів України від 7 червня 2006 р. N 799 ( 799-2006-п ) "Про надання гуманітарної допомоги Республіці Індонезія" цифри "3 363,5" замінити цифрами "3 356,636".

6. В абзаці першому пункту 1 розпорядження Кабінету Міністрів України від 15 червня 2006 р. N 329 ( 329-2006-р ) "Про виділення коштів для виплати компенсації за птицю, вилучену у зв'язку з виявленням у Сумській області випадків захворювання на пташиний грип, та проведення профілактичних заходів" цифри "786" замінити цифрами "755,134".

7. В абзаці першому пункту 1 постанови Кабінету Міністрів України від 24 червня 2006 р. N 878 ( 878-2006-п ) "Про надання гуманітарної допомоги Киргизькій Республіці" цифри "2 092 500" замінити цифрами "2 087 784".
