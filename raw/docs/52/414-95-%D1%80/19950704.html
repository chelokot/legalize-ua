Кабінет Міністрів України; Розпорядження від 04.07.1995 № 414-р

Щодо встановлення надбавок за особливий характер роботи та інтенсивність праці

Стан: Втратив чинність

Ідентифікатор: 414-95-р

Текст документа від 04.07.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 липня 1995 р. N 414-р Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Реєстраційний код акта: 20246/2001

Дата внесення до Реєстру: 23.10.2001

Надати право Міністру Кабінету Міністрів України встановлювати працівникам апарату Кабінету Міністрів України за особливий характер роботи та інтенсивність праці надбавки до 80 відсотків посадового окладу з урахуванням доплати за ранг та вислугу років.
