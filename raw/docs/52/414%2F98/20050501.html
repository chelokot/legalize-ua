( Указ втратив чинність на підставі Указу Президента N 625/2005 ( 625/2005 ) від 11.04.2005 )

Про зміни у складі Консультативної ради з питань іноземних інвестицій в Україні

На часткову зміну Указу Президента України від 11 квітня 1997 року N 323 ( 323/97 ) "Про Консультативну раду з питань іноземних інвестицій в Україні" (із змінами, внесеними Указом Президента України від 29 липня 1997 року N 717 ( 717/97 ) та Указом Президента України від 11 вересня 1997 року N 1006 ( 1006/97 ) ввести до складу Консультативної ради з питань іноземних інвестицій в Україні:

ДЖЕРОЕНА ВАН ДЕР ВЕЄРА - директора-розпорядника компанії "Роял Датч-Шелл" (Великобританія), ВЯХІРЄВА РЕМА ІВАНОВИЧА - голову правління РАТ "Газпром" (Російська Федерація), МОРІТЦА ГЕРКЕ - керівника регіонального відділення по Східній Європі "Дойче Телеком АГ" (ФРН), НЕВІЛЛА ІЗДЕЛЛА - виконавчого директора "Кока-Кола Бевереджіз" компанії "Кока-Кола Аматіл" (Австралія), ЕБЕРХАРДА ФОН КЕРБЕРА - президента "АББ Європа" концерну "АББ" (Швейцарія-Швеція), ЛЕБЕДЄВА ОЛЕКСАНДРА ЄВГЕНОВИЧА - голову правління комерційного банку "Національний резервний банк" (Російська Федерація), виключивши зі складу цієї Ради Еріка Яна Недеркоорна, Марка Муді-Стюарта, Герана Ліндаля, Мухтара Кента, В. Ланового, І. Мітюкова, С. Осику, В. Суслова, С. Тігіпка.
