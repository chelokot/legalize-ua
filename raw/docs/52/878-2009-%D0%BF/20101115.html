Кабінет Міністрів України; Постанова від 19.08.2009 № 878

Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 12 липня 1999 р. N 1228 та визнання такою, що втратила чинність, постанови Кабінету Міністрів України від 10 вересня 2008 р. N 816

Стан: Чинний

Ідентифікатор: 878-2009-п

Текст документа від 15.11.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 серпня 2009 р. N 878 Київ

Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 12 липня 1999 р. N 1228 та визнання такою, що втратила чинність, постанови Кабінету Міністрів України від 10 вересня 2008 р. N 816

{ Із змінами, внесеними згідно з Указом Президента N 716/2009 ( 716/2009 ) від 08.09.2009 }

{ Відмовлено у відкритті конституційного провадження у справі за конституційним поданням Президента України ( n0031100-09 ) щодо відповідності Конституції України ( 254к/96-ВР ) (конституційності) пункту 1 цієї Постанови Ухвалою Конституційного Суду N 60-у/2009 ( v060u710-09 ) від 01.12.2009 }

{ Додатково див. Постанову Окружного адміністративного суду міста Києва

N 2а-3242/10/2670 ( v3242805-10 ) від 15.11.2010 }

Кабінет Міністрів України постановляє:

1. В абзаці третьому пункту 1 постанови Кабінету Міністрів України від 12 липня 1999 р. N 1228 ( 1228-99-п ) "Про надання суб'єктам зовнішньоекономічної діяльності повноважень на право здійснення експорту, імпорту товарів військового призначення та товарів, які містять відомості, що становлять державну таємницю" (Офіційний вісник України, 1999 р., N 28, ст. 1412, N 45, ст. 2230; 2001 р., N 5, ст. 181; 2003 р., N 40, ст. 2096; 2006 р., N 27, ст. 1940, N 40, ст. 2677; 2007 р., N 52, ст. 2100; 2008 р., N 70, ст. 2353) позиції "ML5, ML8b," замінити позиціями "ML5, ML6, ML8b, ML9, ML10, ML14,". { Щодо дії пункту 1 див. Указ Президента N 716/2009 ( 716/2009 ) від 08.09.2009, Ухвалу Конституційного Суду N 60-у/2009 ( v060u710-09 ) від 01.12.2009 }

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 10 вересня 2008 р. N 816 ( 816-2008-п ) "Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 12 липня 1999 р. N 1228" (Офіційний вісник України, 2008 р., N 70, ст. 2353).
