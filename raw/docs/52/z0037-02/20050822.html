{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 86/5 ( z0882-05 ) від 09.08.2005 }

Про внесення змін до наказу Міністра юстиції України від 15.07.97 N 285/7-А "Про експертно-кваліфікаційні комісії та атестацію судових експертів"

Відповідно до частини другої ст. 9, ст. 16 Закону України "Про судову експертизу" ( 4038-12 ) та з метою впорядкування назв експертних спеціальностей НАКАЗУЮ:

1. Затвердити зміни до Положення про експертно-кваліфікаційні комісії та атестацію судових експертів, затвердженого наказом Міністра юстиції України від 15.07.97 N 285/7-А ( z0283-97 ) і зареєстрованого в Міністерстві юстиції України 04.08.97 за N 283/2087 (із змінами і доповненнями), що додаються.

2. Контроль за виконанням цього наказу покласти на Заступника Державного секретаря Міністерства юстиції Пасенюка О.М.

В.о. Міністра О.В.Лавринович
