Про керівника групи повноважних представників Сторони власників, які об'єдналися для ведення переговорів щодо укладення Генеральної угоди між Кабінетом Міністрів України, спільним представницьким органом сторони роботодавців на національному рівні та всеукраїнськими профспілками і профоб'єднаннями на новий строк

Стан: Втратив чинність

Ідентифікатор: 590-2010-р

Текст документа від 12.10.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 березня 2010 р. N 590-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1005-р ( 1005-2011-р ) від 12.10.2011 }

Про керівника групи повноважних представників Сторони власників, які об'єдналися для ведення переговорів щодо укладення Генеральної угоди між Кабінетом Міністрів України, спільним представницьким органом сторони роботодавців на національному рівні та всеукраїнськими профспілками і профоб'єднаннями на новий строк

Затвердити Міністра праці та соціальної політики Надрагу Василя Івановича керівником групи повноважних представників Сторони власників, які об'єдналися для ведення переговорів щодо укладення Генеральної угоди між Кабінетом Міністрів України, спільним представницьким органом сторони роботодавців на національному рівні та всеукраїнськими профспілками і профоб'єднаннями на новий строк і здійснення контролю за її виконанням, затвердженої розпорядженням Кабінету Міністрів України від 2 грудня 2009 р. N 1513 ( 1513-2009-р ), увільнивши від цих обов'язків Денісову Людмилу Леонтіївну.

Прем'єр-міністр України М.АЗАРОВ
