Кабінет Міністрів України; Постанова від 21.12.2005 № 1242

Про встановлення строку виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах під час виготовлення феронікелю

Стан: Втратив чинність

Ідентифікатор: 1242-2005-п

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 грудня 2005 р. N 1242 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах під час виготовлення феронікелю

Відповідно до статті 2 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ) Кабінет Міністрів України постановляє:

Установити строк виконання операцій з давальницькою сировиною (руди та концентрати нікелеві за кодами згідно з УКТЗЕД 2604000000 ( 2371а-14 ), що ввозиться на митну територію України, під час виготовлення феронікелю (код УКТЗЕД 7202600000 ( 2371в-14 ) - 201 календарний день з моменту оформлення ввізної вантажної митної декларації.

Прем'єр-міністр України Ю.ЄХАНУРОВ
