Кабінет Міністрів України; Постанова від 07.12.2005 № 1167

Питання управління часткою держави у статутному фонді Національного депозитарію

Стан: Втратив чинність

Ідентифікатор: 1167-2005-п

Текст документа від 06.04.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 грудня 2005 р. N 1167 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 256 ( 256-2012-п ) від 28.03.2012 }

Питання управління часткою держави у статутному фонді Національного депозитарію

{ Із змінами, внесеними згідно з Постановами КМ N 775 ( 775-2007-п ) від 26.05.2007 N 104 ( 104-2008-п ) від 27.02.2008 }

Кабінет Міністрів України постановляє:

1. Державній комісії з цінних паперів та фондового ринку забезпечити відповідно до статті 2 Закону України "Про Національну депозитарну систему та особливості електронного обігу цінних паперів в Україні" ( 710/97-ВР ) виконання функцій уповноваженного органу з управління часткою держави у статутному фонді Національного депозитарію.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 17 липня 2001 р. N 847 ( 847-2001-п ) "Про управління часткою держави у статутному фонді Національного депозитарію" (Офіційний вісник України, 2001 р., N 29, ст. 1322).

{ Постанова із змінами, внесеними згідно з Постановою КМ N 104 ( 104-2008-п ) від 27.02.2008 }
