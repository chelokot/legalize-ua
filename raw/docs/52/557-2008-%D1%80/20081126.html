КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 квітня 2008 р. N 557-р Київ

Про утворення Української частини Спільного комітету з питань реадмісії

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1481-р ( 1481-2008-р ) від 26.11.2008 }

1. Відповідно до Угоди між Україною та Європейським Співтовариством про реадмісію осіб ( 994_851 ) утворити Українську частину Спільного комітету з питань реадмісії (далі - Українська частина) у складі згідно з додатком.

Надати голові Української частини право вносити у разі потреби зміни до її складу.

2. Організаційне забезпечення роботи Української частини покласти на МВС.
