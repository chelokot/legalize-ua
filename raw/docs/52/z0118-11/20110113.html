ПРАВЛІННЯ ПЕНСІЙНОГО ФОНДУ УКРАЇНИ

ПОСТАНОВА

13.01.2011 N 1-1

Зареєстровано в Міністерстві юстиції України 26 січня 2011 р. за N 118/18856

Про визнання такими, що втратили чинність, деяких постанов правління Пенсійного фонду України

Відповідно до пункту 12 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261 ( 1261-2007-п ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Визнати такими, що втратили чинність:

постанову правління Пенсійного фонду України від 26.09.95 N 6-5 ( z0050-96 ) "Про затвердження Інструкції про стягнення не внесених в строк обов'язкових страхових внесків та інших платежів до Пенсійного фонду України", зареєстровану в Міністерстві юстиції України 06.02.96 за N 50/1075;

постанову правління Пенсійного фонду України від 06.09.96 N 11-1 ( z0550-96 ) "Про затвердження Інструкції про порядок обчислення і сплати підприємствами, установами, організаціями та громадянами страхових внесків до Пенсійного фонду України, а також обліку надходження і витрачання його коштів", зареєстровану в Міністерстві юстиції України 24.09.96 за N 550/1575;

постанову правління Пенсійного фонду України від 03.06.99 N 4-6 ( z0436-99 ) "Про затвердження Інструкції про порядок обчислення і сплати підприємствами, установами, організаціями та громадянами збору на обов'язкове державне пенсійне страхування, інших платежів, а також обліку їх надходження до Пенсійного фонду України", зареєстровану в Міністерстві юстиції України 05.07.99 за N 436/3729;

постанову правління Пенсійного фонду України від 19.10.2001 N 16-6 ( z0998-01 ) "Про затвердження Інструкції про порядок обчислення і сплати підприємствами, установами, організаціями та громадянами збору на обов'язкове державне пенсійне страхування, інших платежів, а також обліку їх надходження до Пенсійного фонду України", зареєстровану в Міністерстві юстиції України 29.11.2001 за N 998/6189.

2. Юридичному управлінню (Рябцева Т.Б.) подати цю постанову для державної реєстрації до Міністерства юстиції України.

3. Ця постанова набирає чинності з дня її офіційного опублікування.

4. Контроль за виконанням цієї постанови покласти на заступника Голови правління Є.Максимчука.
