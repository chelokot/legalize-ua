Про затвердження плану заходів з підготовки та проведення пісенного конкурсу "Євробачення - 2005"

( Із змінами, внесеними згідно з Розпорядженням КМ N 88-р ( 88-2005-р ) від 02.04.2005 )

1. Затвердити план заходів з підготовки та проведення пісенного конкурсу "Євробачення - 2005", що додається.

2. Національній телекомпанії забезпечити організацію та проведення пісенного конкурсу "Євробачення-2005" згідно з вимогами Європейської мовної спілки.

( Пункт 2 в редакції Розпорядження КМ N 88-р ( 88-2005-р ) від 02.04.2005 )

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 21 січня 2005 р. N 24-р

ПЛАН заходів з підготовки та проведення пісенного конкурсу "Євробачення - 2005"

1. Підготовка і підписання контракту з Європейською мовною спілкою щодо проведення пісенного конкурсу "Євробачення - 2005" (далі - пісенний конкурс).

Національна телекомпанія.

Січень.

2. Організація і забезпечення проведення засідань Організаційного комітету з підготовки та проведення пісенного конкурсу "Євробачення - 2005".

Національна телекомпанія, Держкомтелерадіо.

Січень - травень.

( Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 88-р ( 88-2005-р ) від 02.04.2005 )

3. Забезпечення оформлення віз іноземним учасникам та гостям пісенного конкурсу.

МЗС.

Січень - травень.

4. Організація пропуску через державний кордон іноземних учасників і гостей пісенного конкурсу та здійснення митного контролю предметів, що їм належать.

Держприкордонслужба, Держмитслужба, Національна телекомпанія,

Січень - травень.

5. Виготовлення пост-кардів для трансляції пісенного конкурсу.

Держтурадміністрація, Національна телекомпанія.

Січень - березень.

6. Забезпечення охорони громадського порядку у місцях проведення пісенного конкурсу, перебування та тимчасового проживання його учасників.

МВС.

Січень - травень.

7. Обстеження транспортних маршрутів до місць проведення пісенного конкурсу та зон паркування, а також визначення місць тимчасової дислокації підрозділів дорожньо-патрульної служби Державтоінспекції для забезпечення безпеки руху під час здійснення заходів з підготовки та проведення пісенного конкурсу.

Київська міськдержадміністрація, Національна телекомпанія, МВС.

Березень - травень.

8. Проведення акредитації учасників та гостей пісенного конкурсу.

Національна телекомпанія, МЗС.

Січень - травень.

9. Забезпечення медичного обслуговування учасників та гостей пісенного конкурсу.

МОЗ, Київська міськдержадміністрація, Національна телекомпанія.

Травень.

10. Підготовка і здійснення урочистих заходів, пов'язаних з проведенням пісенного конкурсу.

Національна телекомпанія, Держкомтелерадіо, Київська міськдержадміністрація, Управління державної охорони, Держтурадміністрація.

Січень - травень.

( Пункт 10 із змінами, внесеними згідно з Розпорядженням КМ N 88-р ( 88-2005-р ) від 02.04.2005 )

11. Забезпечення транспортного обслуговування учасників та гостей пісенного конкурсу.

Національна телекомпанія.

Березень - травень.

12. Організація міського, міжміського та міжнародного телефонного зв'язку, підключення до мережі Інтернет, надання каналів зв'язку для інтерактивного голосування під час проведення пісенного конкурсу.

Мінтрансзв'язку, Держкомтелерадіо, Національна телекомпанія.

Січень - травень.

13. Забезпечення державного нагляду за будівництвом та реконструкцією об'єктів, пов'язаних з проведенням пісенного конкурсу, протипожежної безпеки у місцях проведення конкурсу, перебування та тимчасового проживання його учасників.

Національна телекомпанія, Київська міськдержадміністрація, МНС, Держбуд.

Січень - травень.

14. Складення і затвердження кошторису витрат, пов'язаних з підготовкою та проведенням пісенного конкурсу, в межах коштів, які передбачені у Державному бюджеті України на 2005 рік ( 2285-15 ) для цієї мети.

Держкомтелерадіо, Мінфін, Мінекономіки, Державне казначейство, Національна телекомпанія.

Січень.

15. Вирішення питань щодо залучення коштів Європейської мовної спілки, спонсорів, інших позабюджетних джерел фінансування.

Національна телекомпанія, Держкомтелерадіо.

Січень.

( Пункт 15 із змінами, внесеними згідно з Розпорядженням КМ N 88-р ( 88-2005-р ) від 02.04.2005 )

16. Забезпечення фінансування заходів з підготовки та проведення пісенного конкурсу за рахунок коштів державного бюджету.

Держкомтелерадіо, Мінфін, Державне казначейство, Національна телекомпанія.

Січень - червень.

17. Проведення тендерів серед компаній, запропонованих Європейською мовною спілкою, для підготовки до підписання контрактів, пов'язаних з проведенням пісенного конкурсу.

Національна телекомпанія, Держкомтелерадіо, Мінекономіки, Мінфін.

Січень - березень.

( Пункт 17 із змінами, внесеними згідно з Розпорядженням КМ N 88-р ( 88-2005-р ) від 02.04.2005 )

18. Подання Організаційному комітетові з підготовки та проведення пісенного конкурсу "Євробачення - 2005" пропозицій щодо:

визначення обсягу коштів, необхідних для технічного обстеження місця проведення пісенного конкурсу, розроблення проектно-кошторисної документації;

організації обстеження технічного стану конструкцій та проведення технічної експертизи інженерних систем будівлі, де проводитиметься пісенний конкурс;

приведення технічного оснащення приміщення, в якому проводитиметься пісенний конкурс у відповідність з вимогами Європейської мовної спілки до проведення таких конкурсів.

Національна телекомпанія, Держкомтелерадіо, Держбуд, Фонд державного майна, Київська міськдержадміністрація.

Січень - травень.

( Пункт 18 із змінами, внесеними згідно з Розпорядженням КМ N 88-р ( 88-2005-р ) від 02.04.2005 )

19. Підготовка та опублікування матеріалів з питань проведення пісенного конкурсу, створення та оновлення інформації веб-сайту цього конкурсу.

Національна телекомпанія, МЗС.

Січень - травень.

20. Забезпечення висвітлення у засобах масової інформації заходів з підготовки і проведення пісенного конкурсу.

Національна телекомпанія, Держкомтелерадіо, Національна радіокомпанія, обласні та регіональні державні телерадіокомпанії, Укрінформ, МЗС.

Січень - червень.

( Пункт 20 із змінами, внесеними згідно з Розпорядженням КМ N 88-р ( 88-2005-р ) від 02.04.2005 )

21. Організація здійснення заходів, спрямованих на інформаційну підтримку пісенного конкурсу в Україні та за кордоном (періодичні видання, телерадіомовлення, друкована продукція, інтернет-сайти тощо).

Національна телекомпанія, Національна радіокомпанія, Держкомтелерадіо, Укрінформ, МЗС, Держтурадміністрація.

Січень - травень.

22. Забезпечення прямої телетрансляції півфіналу та фіналу пісенного конкурсу.

Національна телекомпанія, Держкомтелерадіо, Мінтрансзв'язку.

Травень.

Держтурадміністрація, Київська міськдержадміністрація, Держкомтелерадіо, Національна телекомпанія, МВС, МЗС.

Травень.

24. Організація розважального містечка по вул. Хрещатик (від бульв. Тараса Шевченка до вул. Інститутської), проведення концертів на Майдані Незалежності, Співочому полі, в Київській фортеці для учасників та гостей пісенного конкурсу.
