( Указ втратив чинність на підставі Указу Президента N 1871/2005 ( 1871/2005 ) від 29.12.2005 )

Про співголову Національної ради соціального партнерства

На часткову зміну Указу Президента України від 8 лютого 1993 року N 34 ( 34/93 ) "Про Національну раду соціального партнерства" ввести до складу Національної ради соціального партнерства БІЛОБЛОЦЬКОГО Миколу Петровича - Міністра праці України, призначивши його співголовою Національної ради соціального партнерства від Кабінету Міністрів України. Вивести зі складу Національної ради соціального партнерства КАСКЕВИЧА Михайла Григоровича.

Президент України Л.КУЧМА
