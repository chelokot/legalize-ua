ПОСТАНОВА від 24 червня 2006 р. N 865 Київ

Про затвердження переліку автомобільних доріг загального користування державного значення

{ Із змінами, внесеними згідно з Постановами КМ N 632 ( 632-2007-п ) від 20.04.2007 N 544 ( 544-2008-п ) від 11.06.2008 }

Відповідно до статті 8 Закону України "Про автомобільні дороги" ( 2862-15 ) Кабінет Міністрів України постановляє:

1. Затвердити перелік автомобільних доріг загального користування державного значення, що додається.

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

3. Раді міністрів Автономної Республіки Крим, Севастопольській міській державній адміністрації, обласним державним адміністраціям за поданням служб автомобільних доріг, погодженим Державною службою автомобільних доріг, затвердити переліки автомобільних доріг загального користування місцевого значення.
