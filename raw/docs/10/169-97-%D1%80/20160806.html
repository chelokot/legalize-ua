Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 березня 1997 р. N 169-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Про віднесення посад працівників Рахункової палати Верховної Ради України до відповідних категорій посад державних службовців

( Із змінами, внесеними згідно з Розпорядженнями КМ N 139-р ( 139-99-р ) від 23.02.99 N 2199-р ( 2199-2010-р ) від 08.12.2010 )

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Рахункової палати до таких категорій посад державних службовців: { Абзац перший із змінами, внесеними згідно з Розпорядженням КМ N 2199-р ( 2199-2010-р ) від 08.12.2010 }

перша категорія - посади Першого заступника, заступника Голови палати, головних контролерів-керівників департаментів, головних контролерів, Секретаря палати;

друга категорія - заступників керівників департаментів, начальників управлінь, самостійних відділів;

третя категорія - посади заступників начальників управлінь, самостійних відділів, начальників відділів у складі департаментів та їх заступників, керівника служби Голови палати, помічника Голови палати, прес-секретаря Голови палати, завідуючих секторами, консультантів, головних спеціалістів, посади радника, помічника Першого заступника Голови Рахункової палати, помічника заступника Голови Рахункової палати; { Абзац із змінами, внесеними згідно з Розпорядженнями КМ N 139-р ( 139-99-р ) від 23.02.99, N 2199-р ( 2199-2010-р ) від 08.12.2010 }

четверта категорія - посади інших спеціалістів.
