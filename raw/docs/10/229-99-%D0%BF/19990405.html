Текст документа від 05.04.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 лютого 1999 р. N 229 Київ

( Постанова втратила чинність на підставі Постанови КМ N 541 ( 541-99-п ) від 05.04.99 )

( Дію постанови зупинено на підставі Указу Президента N 309/99 від 31.03.99 )

Про внесення зміни до постанови Кабінету Міністрів України від 18 грудня 1998 р. N 2006

Кабінет Міністрів України постановляє:

У пункті 2 постанови Кабінету Міністрів України від 18 грудня 1998 р. N 2006 ( 2006-98-п ) "Про пільговий проїзд студентів вищих навчальних закладів I-IV рівнів акредитації та учнів професійно-технічних навчальних закладів" (Офіційний вісник України, 1998 р., N 51, ст. 1881) слова "та Порядок відшкодування витрат транспортним підприємствам" замінити словами "а також відшкодування витрат, пов'язаних з наданням зазначеної пільги".
