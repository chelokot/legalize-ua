Кабінет Міністрів України; Постанова від 19.01.2004 № 47

Про порядок випуску, обігу і погашення податкових векселів при ввезенні (пересиланні) на митну територію України товарів з метою ремонту

Стан: Втратив чинність

Ідентифікатор: 47-2004-п

Текст документа від 19.11.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 січня 2004 р. N 47 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1524 ( 1524-2004-п ) від 17.11.2004 )

Про порядок випуску, обігу і погашення податкових векселів при ввезенні (пересиланні) на митну територію України товарів з метою ремонту

( Із змінами, внесеними згідно з Постановою КМ N 1020 ( 1020-2004-п ) від 10.08.2004 )

Кабінет Міністрів України постановляє:

Установити, що платники податку на додану вартість при ввезенні (пересиланні) відповідно до режиму переробки на митній території України товарів з метою гарантійного ремонту, а також товарів за кодами згідно з УКТЗЕД 8406, 8411, 8412, 8413, 8414, 8430, 8501, 8503, 8504, 8518, 8602, 8605, 8606, 8802, 8803, 8901, 8902, 8904, 8905, 8906, 9009, 9014 ( 2371г-14 ) з метою ремонту можуть за своїм рішенням надавати органам митного контролю податковий вексель із строком погашення, який дорівнює строку переробки цих товарів, але не більш як 360 днів, за умови вивезення за межі митної території України продуктів переробки відповідно до митного режиму експорту. ( Абзац перший із змінами, внесеними згідно з Постановою КМ N 1020 ( 1020-2004-п ) від 10.08.2004 )

Випуск, обіг та погашення зазначених векселів здійснюється згідно з Порядком випуску, обігу та погашення векселів, які видаються на суму податку на додану вартість при ввезенні (пересиланні) товарів на митну територію України, затвердженим постановою Кабінету Міністрів України від 1 жовтня 1997 р. N 1104 ( 1104-97-п ) (Офіційний вісник України, 1997 р., число 41, с. 26; 1998 р., N 28, ст. 1050, N 34, ст. 1277; 1999 р., N 27, ст. 1330; 2000 р., N 47, ст. 2040; 2001 р., N 43, ст. 1928; 2002 р., N 2, ст. 69, N 7, ст. 288, N 42, ст. 1925; 2003 р., N 15, ст. 666, N 20, ст. 890), без урахування вимог, передбачених абзацом п'ятим пункту 4 зазначеного Порядку.
