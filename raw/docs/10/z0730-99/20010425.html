{ Постанова втратила чинність на підставі Постанови Нацбанку

N 135 ( z0368-01 ) від 29.03.2001 }

Про внесення змін до Інструкції N 7 про безготівкові розрахунки в господарському обороті України

У зв'язку з прийняттям Верховною Радою України Закону України "Про приєднання України до Женевської конвенції 1930 року, якою запроваджено Уніфікований закон про переказні векселі та прості векселі" ( 826-14 ) та відповідно до Закону України "Про виконавче провадження" ( 606-14 ) Правління ПОСТАНОВЛЯЄ:

1. Виключити з розділу IX Інструкції N 7 про безготівкові розрахунки в господарському обороті України, затвердженої постановою Правління від 02.08.96 N 204 ( v0204500-96 ) (із змінами та доповненнями), пункт 143-1 та абзаци сьомий, восьмий і дев'ятий пункту 147.

2. З дня набуття чинності цією постановою платіжні вимоги на безспірне списання коштів за опротестованими векселями повертаються установами банків стягувачам без виконання.

На зворотному боці цих платіжних вимог установа банку має зробити напис про повернення без виконання згідно з пунктом 2 цієї постанови за підписами головного бухгалтера і виконавця, завіреними штампом банку.

3. Департаменту платіжних систем (В.М.Кравець) надіслати цю постанову територіальним управлінням Національного банку України і комерційним банкам для керівництва в роботі.

4. Зобов'язати установи банків довести зміст цієї постанови до відома своїх клієнтів.

5. Контроль за виконанням цієї постанови покласти на територіальні управління Національного банку України.

6. Постанова набуває чинності через 10 днів після її державної реєстрації в Міністерстві юстиції України.
