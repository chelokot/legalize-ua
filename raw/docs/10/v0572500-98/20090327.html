Текст документа від 27.03.2009:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 358 від 10.09.98 Зареєстровано в юридичному м.Київ департаменті Нацбанку 11 вересня 1998 р. vd980910 vn358 за N 572

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про Порядок формування коригуючих проводок, що здійснюються комерційними банками України з метою забезпечення реальної фінансової звітності

{ Із змінами, внесеними згідно з Постановами Нацбанку N 579 ( z0900-99 ) від 08.12.99 N 348 ( z0625-00 ) від 06.09.2000 Постановою Національного банку N 427 ( z0909-01 ) від 09.10.2001 }

З метою забезпечення реальної фінансової звітності, що надається комерційними банками Національному банку України, Правління ПОСТАНОВЛЯЄ:

1. Затвердити Порядок формування коригуючих проводок, що здійснюються комерційними банками України з метою забезпечення реальної фінансової звітності (додається).

2. Ввести в дію Порядок формування коригуючих проводок, що здійснюються комерційними банками України з 1 жовтня 1998 року.

3. Зобов'язати комерційні банки забезпечити виконання вимог, які встановлені цим Порядком з тим, щоб отримувати реальну фінансову звітність (файл 02), починаючи зі звітності за вересень 1998 року.

4. Контроль за виконанням цієї постанови покласти на Департамент бухгалтерського обліку (Сенищ П.М.) та Департамент інформатизації (Савченко А.С.)

Голова В.А.Ющенко

{ Порядок формування коригуючих проводок, що здійснюються комерційними банками України з метою забезпечення реальної фінансової звітності, втратив чинність на підставі Постанови Національного банку N 427 ( z0909-01 ) від 09.10.2001 }
