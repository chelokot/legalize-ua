Про Порядок формування коригуючих проводок, що здійснюються комерційними банками України з метою забезпечення реальної фінансової звітності

( Із змінами, внесеними згідно з Постановами Нацбанку N 579 ( z0900-99 ) від 08.12.99 N 348 ( z0625-00 ) від 06.09.2000 )

З метою забезпечення реальної фінансової звітності, що надається комерційними банками Національному банку України, Правління ПОСТАНОВЛЯЄ:

1. Затвердити Порядок формування коригуючих проводок, що здійснюються комерційними банками України з метою забезпечення реальної фінансової звітності (додається).

2. Ввести в дію Порядок формування коригуючих проводок, що здійснюються комерційними банками України з 1 жовтня 1998 року.

3. Зобов'язати комерційні банки забезпечити виконання вимог, які встановлені цим Порядком з тим, щоб отримувати реальну фінансову звітність (файл 02), починаючи зі звітності за вересень 1998 року.

4. Контроль за виконанням цієї постанови покласти на Департамент бухгалтерського обліку (Сенищ П.М.) та Департамент інформатизації (Савченко А.С.)

Голова В.А.Ющенко

Затверджено постановою Правління Національного банку України від 10 вересня 1998 р. N 358 реєстр. N 572 від 11.09.98 р.

Порядок формування коригуючих проводок, що здійснюються комерційними банками України з метою забезпечення реальної фінансової звітності

1. Загальні положення

1.1. Порядок формування коригуючих проводок для забезпечення реальної фінансової звітності застосовується для таких бухгалтерських коригувань, як переоцінка, нарахування, рух резервів, розрахунок за податками та обов'язковими платежами, що безпосередньо суттєво впливають на фінансовий результат звітного періоду.

Коригуюча проводка здійснюється, якщо події, згідно з якими вона проводиться, стосуються операцій вже здійснених у звітному періоді або відображених у балансі банку на кінець попереднього періоду. ( Абзац другий пункту 1.1 розділу 1 в редакції Постанови Нацбанку N 579 ( z0900-99 ) від 08.12.99 )

1.2. Враховуючи специфіку роботи, Ощадному банку України надається право здійснювати додаткові проводки за минулий місяць за операційними документами останніх 2-3 робочих днів віддалених безбалансових філій.

2. Основні принципи здійснення коригуючих проводок

2.1. Коригуючі проводки здійснюються після звітного місяця протягом перших днів наступного місяця, до дати надання файлу 02.

2.2. Коригуючі проводки відображаються в балансі банку за поточну дату (в день фактичного здійснення проводки). Коригуючі проводки за результатом зовнішнього аудиту здійснюються після звітного року протягом періоду з 1 лютого по 1 травня поточного року (з окремою ознакою).

Рахунки класів 6 та 7, за якими здійснені вищезазначені коригуючі проводки, у кінці операційного дня закриваються коригуючими проводками на балансовий рахунок 5040 "Прибуток чи збиток минулого року, що очікує затвердження".

11 травня поточного року дані щодо коригуючих оборотів та залишки формуються в окремий файл та надаються Національному банку України.

( Пункт 2.2 розділу 2 в редакції Постанови Нацбанку N 579 ( z0900-99 ) від 08.12.99 )

2.3. У виписці з особового рахунку коригуючі проводки відображаються окремою групою, яка відокремлюється незаповненим рядком, або іншим способом після проводок поточного дня.

У виписці поточного дня додатково проставляється позначка місяця, року, за який проводиться коригування. ( Абзац другий пункту 2.3 розділу 2 із змінами, внесеними згідно з Постановою Нацбанку N 579 ( z0900-99 ) від 08.12.99 )

2.4. В меморіальному ордері за коригуючою проводкою ставиться дата таким же чином, як описано у п.2.3.

2.5. Меморіальні ордери за коригуючими проводками підписуються виконавцем, головним бухгалтером або його заступником.

2.6. Комерційні банки щоденно роздруковують список проведених коригуючих проводок, який у подальшому підшивається разом з документами за коригуючими проводками. В документах дня вони підшиваються окремою групою.

2.7. Комерційні банки щомісячно ведуть накопичувальні реєстри коригуючих проводок, які в подальшому використовують для формування 02 файлу (включають в обороти звітного місяця).

2.8. Строк зберігання документів такий же самий як меморіальних і касових документів дня (згідно з "Переліком документів Національного банку України, установ і організацій його системи, акціонерно-комерційних та комерційних банків України із зазначенням строків зберігання", затвердженим постановою Правління НБУ від 23.12.96 N 327 та начальником Головного архівного управління при Кабінеті Міністрів України 05.12.96).

2.9. Комерційні банки можуть встановлювати окремий порядок здійснення коригуючих проводок у своїй внутрішній системі за рахунками, визначеними цим Порядком. При цьому банк контролює правильність здійснення коригуючих проводок.

4. Звітність за коригуючими проводками

4.1. Комерційний банк - юридична особа формує файл 02 з врахуванням оборотів за коригуючими проводками в поточному місяці в цілому по банку та надсилає його в обласному розрізі регіональним управлінням НБУ у встановлений ними термін.

Регіональні управління НБУ надають файл 02 Департаменту бухгалтерського обліку через Центральну розрахункову палату 10 числа після звітного періоду.

4.2. Центральна розрахункова палата надсилає роздруковані консолідовані та в розрізі банків - юридичних осіб відомості коригуючих проводок окремо за звітний місяць та окремо за звітний період (за результатами перевірок зовнішнього аудиту) до Національного банку України. Відомості формуються з файлу 02 та мають вигляд форми звітності N 10-КБ "Оборотносальдовий баланс комерційного банку". ( Пункту 4.2 розділу 4 із змінами, внесеними згідно з Постановою Нацбанку N 579 ( z0900-99 ) від 08.12.99 )

4.3. Зважаючи на те, що Ощадному банку України надається право проведення коригуючих проводок за балансовими рахунками розділу 10 "Готівкові кошти", він надає електронною поштою файли 12 (звіт, форма N 747Д (щоденна) "Звіт про касові обороти банку" за останній робочий день звітного місяця) та 13 (звіт N 748 (місячна) "Звіт про касові обороти банку") повторно з врахуванням коригуючих проводок регіональним управлінням НБУ у встановлений ними термін. Регіональні управління НБУ надають зазначені файли Департаменту готівково-грошового обігу 10 числа після звітного періоду. Ці звіти звіряються з місячним балансом (файл 02). Контроль за звітністю N 747Д, N 748 покладається на регіональні управління НБУ.

4.4. Звіт, форма N 747Д (щоденна) "Звіт про касові обороти банку" надається Ощадним банком України у перші дні наступного місяця за звітним без врахування коригуючих проводок.

4.5. Показники місячних форм звітності звіряються з місячним балансом (файл 02).

4.6. Балансовий звіт.

При проведенні коригуючої проводки звіт, форма N 1Д-КБ "Баланс комерційного банку" (файл 01) надається з урахуванням змін залишку балансового рахунку, що відбулися після проведення цих проводок.

4.7. Звіт про прибутки та збитки.

У звіт про прибутки та збитки мають бути включені всі коригування звітного періоду, що стосуються цієї звітності. Ця звітність звіряється з місячним балансом (файл 02).
