Про оплату послуг, пов'язаних із здійсненням поточної господарської діяльності Пенсійним фондом та його органами

Стан: Чинний

Ідентифікатор: 840-2004-п

Текст документа від 26.02.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 липня 2004 р. N 840 Київ

Про оплату послуг, пов'язаних із здійсненням поточної господарської діяльності Пенсійним фондом та його органами

{ Із змінами, внесеними згідно з Постановою КМ N 134 ( 134-2011-п ) від 23.02.2011 }

Кабінет Міністрів України постановляє:

Установити, що за тарифами, установленими для бюджетних установ, Пенсійним фондом України та його органами здійснюється оплата:

наданих послуг з оренди приміщень та їх експлуатації, водопостачання, користування електроенергією, теплопостачання, послуг електрозв'язку, комунальних та інших послуг, за надання яких встановлені окремі тарифи для бюджетних установ;

земельного податку відповідно до Податкового кодексу України ( 2755-17 ); { Абзац третій постановляючої частини із змінами, внесеними згідно з Постановою КМ N 134 ( 134-2011-п ) від 23.02.2011 }

{ Абзац четвертий постановляючої частини виключено на підставі Постанови КМ N 134 ( 134-2011-п ) від 23.02.2011 }

{ Абзац п'ятий постановляючої частини виключено на підставі Постанови КМ N 134 ( 134-2011-п ) від 23.02.2011 }

єдиного внеску на загальнообов'язкове державне соціальне страхування відповідно до статті 8 Закону України "Про збір та облік єдиного внеску на загальнообов'язкове державне соціальне страхування" ( 2464-17 ). { Абзац шостий постановляючої частини в редакції Постанови КМ N 134 ( 134-2011-п ) від 23.02.2011 }
