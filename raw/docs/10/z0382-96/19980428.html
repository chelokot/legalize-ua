Стан: Втратив чинність

Текст документа від 28.04.1998:

МІНІСТЕРСТВО ЗОВНІШНІХ ЕКОНОМІЧНИХ ЗВ'ЯЗКІВ І ТОРГІВЛІ УКРАЇНИ

НАКАЗ

N 411 від 23.07.96 Зареєстровано в Міністерстві м.Київ юстиції України 25 липня 1996 р. vd960723 vn411 за N 382/1407

( Наказ втратив чинність на підставі Наказу МЗЕЗторгу N 248 ( z0274-98 ) від 28.04.98 )

Про справляння державного збору за видачу ліцензій по індивідуальному режиму ліцензування згідно з наказом МЗЕЗторгу від 23.07.96 р. N 410

З метою поповнення доходної частини Державного бюджету, посилення відповідальності суб'єктів господарської діяльності за дотриманням вимог чинного законодавства та у відповідності зі ст.16 Закону України "Про зовнішньоекономічну діяльність" ( 959-12 ) НАКАЗУЮ:

1. Встановити, що видача ліцензій суб'єктам господарської діяльності, всіх форм власності, по індивідуальному режиму ліцензування, згідно з наказом МЗЕЗторгу від 23.07.96 р. N 410 ( z0381-96 ), здійснюється за умови надання заявником копії платіжного доручення (з відміткою банку про сплату) та довідки відповідного фінансового органу про фактичне надходження коштів до Державного бюджету.

Ці документи додаються до документів заявника і залишаються в справі органу, що видає ліцензію.

2. Державний збір за видачу ліцензії по індивідуальному режиму ліцензування здійснюється у розмірі встановленому Постановою Кабінету Міністрів України від 05.11.91 р. N 312 ( 312-91-п ) "Про порядок експорту товарів (робіт, послуг)".

3. Головному договірно-правовому управлінню (Нестер Л.Д.) забезпечити реєстрацію цього наказу в Міністерстві юстиції України.

4. Управлінню інформаційного забезпечення (Загорняк О.В.) забезпечити публікацію цього наказу в газеті "Урядовий кур'єр".

5. Оперативний контроль за виконанням цього наказу покласти на заступника Міністра Олійника В.І.

6. Загальний контроль за виконанням цього наказу залишаю за собою.

В.о.Міністра С.Г.Осика
