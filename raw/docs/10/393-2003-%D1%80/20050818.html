КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 червня 2003 р. N 393-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про внесення змін до розпорядження Кабінету Міністрів України від 16 листопада 2002 р. N 675

Ввести до складу Координаційної групи з питань прискорення підготовки та прийняття законодавчих актів, що випливають із Земельного кодексу України ( 2768-14 ), утвореної розпорядженням Кабінету Міністрів України від 16 листопада 2002 р. N 675 ( 675-2002-р ), Хорошковського Валерія Івановича - Міністра економіки та з питань європейської інтеграції, Ярошенка Федора Олексійовича - Державного секретаря Міністерства фінансів, вивівши з її складу Курикіна Сергія Івановича, Шлапака Олександра Віталійовича та Юшка Ігоря Олеговича.

Перший віце-прем'єр-міністр України М.АЗАРОВ
