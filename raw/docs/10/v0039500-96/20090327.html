Національний банк; Постанова від 22.02.1996 № 39

Вимоги до формування уповноваженими банками статутного фонду та власних коштів

Стан: Втратив чинність

Ідентифікатор: v0039500-96

Текст документа від 27.03.2009:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 39 від 22.02.96 м.Київ

vd960222 vn39

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Вимоги до формування уповноваженими банками статутного фонду та власних коштів

{ Із змінами, внесеними згідно з Постановами Нацбанку N 69 ( v0069500-96 ) від 25.03.96 N 56 ( z0119-99 ) від 10.02.99 N 207 ( v0207500-99 ) від 27.04.99 }

{ Постанова втратила чинність у частині відкликання у комерційних банків до 01.01.99 ліцензій на здійснення всіх або окремих банківських операцій з валютними цінностями на підставі Постанови Нацбанку N 207 ( v0207500-99 ) від 27.04.99 }

Розглянувши пропозиції департаменту валютного регулювання щодо формування комерційними та уповноваженими банками статутного фонду та власних коштів, Правління ПОСТАНОВЛЯЄ:

1. Відмінити п.1 постанови Правління Національного банку України від 2 червня 1994 року N 106 ( v0106500-94 ) "Про внесення змін до порядку ліцензування комерційних банків".

2. Ввести обов'язкові нормативи капіталу банку для банків, що мають або бажають одержати чи розширити ліцензію на право здійснення операцій з валютними цінностями, які розраховуються шляхом застосування спеціальних підвищуючих коефіціентів до встановленого для комерційних банків мінімуму статутного фонду на кожну із зазначених в п.4 постанови Верховної Ради України N 25/96-ВР від 01.02.96 р. дат. ( Пункт 2 в редакції Постанови Нацбанку N 69 ( v0069500-96 ) від 25.03.96, із змінами внесеними згідно з Постановою Нацбанку N 56 ( z0119-99 ) від 10.02.99 )

( Пункт 3 втратив чинність на підставі Постанови Нацбанку N 69 ( v0069500-96 ) від 25.03.96 ) 3. Вимоги до розміру статутного фонду, передбачені п.2 цієї постанови, застосовуються також до всіх банків, які раніше одержали ліцензію на здійснення операцій з валютними цінностями. Уповноважені банки мають до 1 січня 1997 року сформувати статутний фонд у розмірі з урахуванням коефіцієнта, який відповідає пунктам Роз'яснень до ліцензії, за якими надано їм право проводити валютні операції.

4. Встановити, що втрачають силу:

- пункт 1 "Змін до порядку ліцензування комерційних банків", затверджених постановою Правління Національного банку України N 106 від 2 червня 1994 року;

- пункт 1 постанови Правління Національного банку України N 123 ( v0123500-95 ) від 16 травня 1995 року "Про внесення змін до порядку ліцензування банків та перереєстрації ліцензій уповноважених банків".

5. Контроль за виконанням цієї постанови покласти на першого заступника Голови Правління Національного банку України В.О.Бондаря.

6. Постанова набирає чинності з дня її підписання.

Голова Правління В.А.Ющенко
