КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 серпня 2005 р. N 380-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про утворення робочої групи з розроблення державних соціальних стандартів надання послуг населенню у сфері культури, що гарантуються державою

( Із змінами, внесеними згідно з Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 )

Утворити робочу групу з розроблення державних соціальних стандартів надання послуг населенню у сфері культури, що гарантуються державою, у складі згідно з додатком.

Дозволити голові робочої групи вносити в разі потреби зміни до її складу.

Прем'єр-міністр України Ю.ТИМОШЕНКО
