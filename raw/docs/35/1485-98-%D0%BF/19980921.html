ПОСТАНОВА від 21 вересня 1998 р. N 1485 Київ

Про затвердження складу Митно-тарифної ради України

Кабінет Міністрів України постановляє:

1. Затвердити склад Митно-тарифної ради України згідно з додатком.

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України від 21 грудня 1995 р. N 1031 ( 1031-95-п ) "Про затвердження персонального складу Митно-тарифної ради України", від 19 серпня 1996 р. N 979 ( 979-96-п ) "Про внесення змін до складу Митно-тарифної ради України", від 4 лютого 1998 р. N 117 ( 117-98-п ) "Про внесення змін до складу Митно-тарифної ради України" та від 27 червня 1998 р. N 964 ( 964-98-п ) "Про внесення змін до складу Митно-тарифної ради України".

СКЛАД Митно-тарифної ради України

РОГОВИЙ - Міністр економіки (голова Ради) Василь Васильович

ЄГОРОВ - перший заступник Голови Держмитслужби Олександр Борисович (заступник голови Ради)

ВИСЛОУХ - заступник Міністра зовнішніх економічних Олег Валентинович зв'язків і торгівлі

ІГНАЩЕНКО - заступник Міністра економіки Володимир Анатолійович

КІБІТКО - завідуючий Відділом з питань Олексій Андрійович міждержавних відносин та зовнішньоекономічної діяльності Кабінету Міністрів України

ЛОПАТА - заступник Голови Державної податкової Василь Григорович адміністрації

МАКАЦАРІЯ - заступник Міністра фінансів Сергій Мегонович

НАЗАРЕНКО - завідуючий Відділом з питань розвитку Юрій Миколайович національної економіки Кабінету Міністрів України

ПРЯДКО - заступник Міністра промислової політики Володимир Володимирович

РИЛАЧ - заступник Міністра закордонних справ Юрій Олександрович

СКРИПЧЕНКО - перший віце-президент Торгово- Сергій Парфенович промислової палати

СТРУК - державний уповноважений Василь Миколайович Антимонопольного комітету

ЧАЮН - перший заступник начальника управління Віталій Миколайович кредитно-фінансового та зовнішньоекономічного законодавства Мін'юсту

ЯРОШОВЕЦЬ - заступник Міністра агропромислового Василь Степанович комплексу
