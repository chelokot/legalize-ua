10.09.2010 N 344

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 168 ( v0168359-15 ) від 10.08.2015 }

Про зразки та описи печаток територіальних і дільничних виборчих комісій з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів і штампа з написом "ВИБУВ"

Відповідно до частин п'ятої, сьомої статті 20, пункту 4 частини першої статті 24 Закону України "Про вибори депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів" ( 2487-17 ), керуючись статтями 11-13, пунктом 7 статті 21, частиною другою статті 27 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Затвердити:

зразки (додатки 1-8) ( va344359-10 ) та опис (додаток 9) ( va344359-10 ) печаток територіальних виборчих комісій з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів;

зразки (додаток 10) ( va344359-10 ) та опис (додаток 11) ( va344359-10 ) печаток дільничних виборчих комісій з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів;

зразок штампа з написом "ВИБУВ" (додаток 12) ( va344359-10 ).

2. Державному комітету України з питань регуляторної політики та підприємництва надати роз'яснення державним реєстраторам щодо забезпечення оперативного вирішення питань, пов'язаних з державною реєстрацією територіальних виборчих комісій як юридичних осіб або змін до документів про їх реєстрацію.

3. Міністерству внутрішніх справ України сприяти територіальним виборчим комісіям в оперативній видачі дозволів на виготовлення печаток і штампів.

4. Визнати такими, що втратили чинність, постанови Центральної виборчої комісії від 13 лютого 1998 року N 69 ( v0069359-98, va069359-98 ) "Про зразок печатки Київської міської виборчої комісії", від 10 березня 1999 року N 16 ( v0016359-99 ) "Про внесення зміни до постанови Центральної виборчої комісії від 13 лютого 1998 року N 69 "Про зразок печатки Київської міської виборчої комісії", від 25 січня 2002 року N 82 ( v0082359-02, v0a82359-02 ) "Про зразки печаток сільських, селищних, міських, районних у містах, районних, обласних виборчих комісій по виборах депутатів місцевих рад та сільських, селищних, міських голів", від 9 січня 2006 року N 110 ( v0110359-06 ) "Про використання печаток територіальних виборчих комісій з підготовки та проведення виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів 26 березня 2006 року" та від 28 березня 2008 року N 13 ( v0013359-08, va013359-08 ) "Про печатки дільничних виборчих комісій, що здійснюють підготовку і проведення позачергових, проміжних, повторних або перших (у разі формування нових місцевих рад) виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів".

5. Цю постанову надіслати Міністерству внутрішніх справ України, Державному комітету України з питань регуляторної політики та підприємництва, а також Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям для доведення до відома територіальних виборчих комісій після сформування нового складу цих комісій.
