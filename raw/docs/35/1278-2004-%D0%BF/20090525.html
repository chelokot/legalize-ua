КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 вересня 2004 р. N 1278 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Про внесення змін у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

На виконання Указів Президента України від 16 липня 2004 р. N 811 ( 811/2004 ) "Про утворення Міністерства транспорту та зв'язку України" і від 21 серпня 2004 р. N 943 ( 943/2004 ) "Про Національну комісію з питань регулювання зв'язку України" Кабінет Міністрів України постановляє:

Внести у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851; 2001 р., N 39, ст. 1764; 2002 р., N 29, ст. 1358; 2003 р., N 51, ст. 2671) такі зміни:

позиції "Міністерство транспорту 351 4" та

"Державний комітет зв'язку 198 4" виключити; та інформатизації

доповнити додаток після позиції "Міністерство промислової політики" позицією такого змісту:

"Міністерство транспорту 489 та зв'язку 445***********";

доповнити додаток позицією такого змісту:

"Національна комісія з 44***********". питань регулювання зв'язку
