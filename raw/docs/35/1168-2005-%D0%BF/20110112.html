КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 грудня 2005 р. N 1168 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1236 ( 1236-2010-п ) від 27.12.2010 }

Про відновлення дії постанови Кабінету Міністрів України від 4 лютого 2004 р. N 127

Кабінет Міністрів України постановляє:

Відновити дію постанови Кабінету Міністрів України від 4 лютого 2004 р. N 127 ( 127-2004-п ) "Про затвердження Порядку нарахування штрафів за неповне або несвоєчасне повернення суми надміру сплаченого податку з доходів фізичних осіб" (Офіційний вісник України, 2004 р., N 5, ст. 244).

У зв'язку з цим пункт 52 переліку постанов Кабінету Міністрів України, що втратили чинність, затвердженого постановою Кабінету Міністрів України від 20 серпня 2005 р. N 788 ( 788-2005-п ) (Офіційний вісник України, 2005 р., N 34, ст. 2062), виключити.
