25.12.2008 N 519

Зареєстровано в Міністерстві юстиції України 13 січня 2009 р. за N 13/16029

{ Наказ втратив чинність на підставі Наказу Державного комітету статистики N 271 ( z0731-09 ) від 20.07.2009 }

Про внесення змін до наказу Держкомстату від 04.08.2008 N 265

Відповідно до статей 4, 14, 18 Закону України "Про державну статистику" ( 2614-12 ), з метою подальшого вдосконалення державного статистичного спостереження щодо дебіторської і кредиторської заборгованості та отримання повної, всебічної, об'єктивної статистичної інформації для потреб складання платіжного балансу та статистики зовнішнього боргу НАКАЗУЮ:

1. Унести зміни до Інструкції щодо заповнення форми державного статистичного спостереження N 1-Б "Звіт про фінансові результати і дебіторську та кредиторську заборгованість", затвердженої наказом Державного комітету статистики України від 04.08.2008 N 265 ( z0780-08 ), зареєстрованої в Міністерстві юстиції України 22.08.2008 за N 780/15471, а саме:

пункт 3.6. розділу III доповнити абзацом такого змісту:

"У вписуваному рядку 031 із рядка 030 за всіма графами звіту виділяється заборгованість за надані (отримані) товари, роботи, послуги, в тому числі забезпечена векселями, та сплачені (отримані) аванси у рахунок наступних поставок продукції, виконання робіт, послуг (рядки 160, 530, 540 форми N 1 ( z0396-99 ) або рядки 160, 530 форми N 1-м ( z0161-00 ), а також частково (виключно в частині заборгованості (авансів) за товари, роботи, послуги) - рядки 50, 150, 180, 470, 520 форми N 1 або рядки 70, 210, 610 форми N 1-м)";

пункт 3.7. розділу III після слів "Податковий кредит" доповнити словами "заборгованість за довгостроковими та короткостроковими кредитами банку".

2. Зміни, внесені цим наказом, увести в дію, починаючи зі звіту за 2008 рік.

3. Респондентам при заповненні форми державного статистичного спостереження N 1-Б "Звіт про фінансові результати і дебіторську та кредиторську заборгованість" ( va264202-08 ) використовувати Інструкцію ( z0780-08 ) зі змінами, внесеними цим наказом.

4. Департаменту міжгалузевої статистики підприємств (Жук І.М.) довести цей наказ до відома головних управлінь статистики в Автономній Республіці Крим, областях, місті Києві та Управління статистики у місті Севастополі.

5. Контроль за виконанням цього наказу покласти на першого заступника Голови Піщейка В.О.

Голова О.Г.Осауленко
