Текст документа від 26.01.2001:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 225 від 11.05.99 Зареєстровано в юридичному м.Київ департаменті Нацбанку 16 червня 1999 року vd990511 vn225 за N 656

Про Положення про регіональне управління Національного банку України

( Із змінами, внесеними згідно з Постановою Нацбанку N 495 ( z0081-01 ) від 22.12.2000 )

Відповідно до пункту 14 постанови Правління від 28.12.98 N 555 "Про організаційні питання діяльності Національного банку України в 1999 році" Правління ПОСТАНОВЛЯЄ:

1. Затвердити Положення про регіональне управління Національного банку України (додається).

2. Кримському республіканському, обласним та по місту Києву і Київській області управлінням Національного банку України забезпечити виконання функцій та обов'язків, що передбачені Положенням, з використанням прав, наданих Національним банком України.

3. Директору Ревізійного департаменту здійснювати контроль за виконанням регіональними управліннями основних завдань, функцій та наданих прав.

4. Контроль за виконанням цієї постанови покласти на заступника Голови Правління.

5. Визнати таким, що втратило чинність, Положення про регіональне управління Національного банку України, затверджене протоколом Правління НБУ від 12.06.93 N 39 ( v0039500-93 ) (додаток до п. 6).

Голова В.А.Ющенко

( Положення про регіональне управління Національного банку України втратило чинність на підставі Постанови Нацбанку N 495 ( z0081-01 ) від 22.12.2000 )
