КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 грудня 1999 р. N 2336 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 857 ( 857-2006-п ) від 24.06.2006 }

Про визначення Банку депозитно-кредитного (Україна) Лтд банком-агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під державні гарантії

Кабінет Міністрів України постановляє:

1. Визначити Банк депозитно-кредитний (Україна) Лтд банком-агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під державні гарантії.

2. Уповноважити Міністра фінансів Мітюкова І.О. підписати від імені Кабінету Міністрів України агентську угоду з Банком депозитно-кредитним (Україна) Лтд.

Перший віце-прем'єр-міністр України А.КІНАХ
