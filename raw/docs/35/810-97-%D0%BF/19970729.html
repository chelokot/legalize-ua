ПОСТАНОВА від 29 липня 1997 р. N 810 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про виділення коштів Господарському управлінню Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Виділити Господарському управлінню Кабінету Міністрів України 13,7 млн. гривень для покриття витрат на проведення аварійно-відновних та ремонтно-реставраційних робіт на об'єктах, що забезпечують діяльність Кабінету Міністрів України.

Міністерству фінансів профінансувати зазначені витрати за рахунок резервного фонду Кабінету Міністрів України.
