КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 жовтня 2008 р. N 1345-р Київ

Про віднесення наукових об'єктів до таких, що становлять національне надбання

{ Із змінами, внесеними згідно з Постановою КМ N 1206 ( 1206-2021-п ) від 10.11.2021 }

Віднести до таких, що становлять національне надбання, наукові об'єкти згідно з додатком.

{ Перелік наукових об'єктів, що становлять національне надбання додатково див. у Постанові КМ N 1709 ( 1709-2001-п ) від 19.12.2001 р. }

МОН включити зазначені об'єкти до Державного реєстру наукових об'єктів, що становлять національне надбання.
