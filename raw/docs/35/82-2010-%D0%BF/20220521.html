Кабінет Міністрів України; Постанова від 20.01.2010 № 82

Про норми відшкодування витрат, пов'язаних з направленням здобувачів освіти та наукових ступенів для участі у заходах, що проводяться в Україні та за кордоном

Стан: Чинний

Ідентифікатор: 82-2010-п

Текст документа від 21.05.2022:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 січня 2010 р. N 82 Київ

Про норми відшкодування витрат, пов’язаних з направленням здобувачів освіти та наукових ступенів для участі у заходах, що проводяться в Україні та за кордоном

{ Назва Постанови в редакції Постанови КМ N 599 ( 599-2022-п ) від 13.05.2022 }

{ Із змінами, внесеними згідно з Постановами КМ N 243 ( 243-2014-п ) від 09.07.2014 N 599 ( 599-2022-п ) від 13.05.2022 }

Кабінет Міністрів України постановляє:

Установити, що відшкодування витрат, пов’язаних з направленням здобувачів освіти та наукових ступенів (учнів, студентів, курсантів, вихованців, слухачів, лікарів (провізорів) - інтернів, аспірантів, асистентів-стажистів, ад’юнктів, докторантів) для участі в освітній та науковій діяльності (у тому числі конференціях, олімпіадах, виставках, конкурсах), що провадиться в Україні та за кордоном, здійснюється в розмірах та порядку, встановлених постановою Кабінету Міністрів України від 2 лютого 2011 р. N 98 ( 98-2011-п ) "Про суми та склад витрат на відрядження державних службовців, а також інших осіб, що направляються у відрядження підприємствами, установами та організаціями, які повністю або частково утримуються (фінансуються) за рахунок бюджетних коштів" (Офіційний вісник України, 2011 р., N 11, ст. 488) для державних службовців і працівників підприємств, установ і організацій, що повністю або частково утримуються (фінансуються) за рахунок бюджетних коштів.

Зазначені вимоги не поширюються на заклади освіти (наукові установи) і здобувачів освіти та наукових ступенів, які беруть участь у програмах академічної мобільності та програмах міжнародного співробітництва відповідно до Порядку реалізації права на академічну мобільність, затвердженого постановою Кабінету Міністрів України від 12 серпня 2015 р. N 579 ( 579-2015-п ) (Офіційний вісник України, 2015 р., N 66, ст. 2183), - із змінами, внесеними постановою Кабінету Міністрів України від 13 травня 2022 р. N 599.
