Про встановлення терміну виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах під час виготовлення мідних катодів, мідної та алюмінієвої катанки

Стан: Втратив чинність

Ідентифікатор: 109-99-п

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 січня 1999 р. N 109 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення терміну виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах під час виготовлення мідних катодів, мідної та алюмінієвої катанки

( Із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )

Відповідно до статті 5 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ) Кабінет Міністрів України постановляє:

Встановити термін виконання операцій з давальницькою сировиною (відходи і брухт міді та алюмінію за кодами згідно з УКТ ЗЕД 7404 00 10 00, 7602 00 90 00, 7601 20 10 00), що вивозиться з митної території України для виготовлення мідних катодів, мідної та алюмінієвої катанки за кодами згідно з УКТ ЗЕД 7403 11 00 00, 7408 11 00 00, 7605 11 00 00, 150 календарних днів з дати оформлення вивізної вантажної митної декларації.

( Постанова із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )
