Кабінет Міністрів України; Розпорядження від 10.12.2008 № 1566-р

Питання підприємств з виробництва первинного алюмінію та титану губчастого в період фінансово-економічної кризи

Стан: Втратив чинність

Ідентифікатор: 1566-2008-р

Текст документа від 03.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 грудня 2008 р. N 1566-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1063-р ( 1063-2011-р ) від 26.10.2011 }

Питання підприємств з виробництва первинного алюмінію та титану губчастого в період фінансово-економічної кризи

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1174-р ( 1174-2009-р ) від 23.09.2009 }

1. Мінпромполітики разом з Мінекономіки, Мінпаливенерго і НКРЕ затвердити у двотижневий строк порядок розрахування роздрібних цін на електроенергію, використану підприємствами з виробництва первинного алюмінію та титану губчастого виключно для технологічних потреб, залежно від коливань цін на продукцію зазначених підприємств на світовому ринку.

2. НКРЕ визначити механізм компенсації можливих втрат енергопостачальників, пов'язаних з постачанням електроенергії підприємствам з виробництва первинного алюмінію та титану губчастого за ціною, розрахованою згідно з порядком, зазначеним у пункті 1 цього розпорядження.

3. Погодитися з пропозицією Мінпромполітики та Мінпаливенерго щодо розстрочення заборгованості підприємства з виробництва титану губчастого перед енергопостачальною компанією ВАТ "Запоріжжяобленерго" за спожиту електроенергію, яка склалася на 1 вересня 2009 р., із строком погашення до 24 місяців з оплатою щомісяця рівними частками (у разі оплати обсягу поточного споживання електроенергії) починаючи з моменту укладення відповідного договору.

{ Розпорядження доповнено пунктом 3 згідно з Розпорядженням КМ N 1174-р ( 1174-2009-р ) від 23.09.2009 }

4. Державному підприємству "Енергоринок" в установленому порядку здійснити розстрочення заборгованості енергопостачальної компанії ВАТ "Запоріжжяобленерго" за придбану протягом поточного року електроенергію, яка склалася на 1 вересня 2009 р., на визначених у пункті 3 цього розпорядження умовах.

{ Розпорядження доповнено пунктом 4 згідно з Розпорядженням КМ N 1174-р ( 1174-2009-р ) від 23.09.2009 }
