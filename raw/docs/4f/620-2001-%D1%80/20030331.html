КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 грудня 2001 р. N 620-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 189-р ( 189-2003-р ) від 31.03.2003 )

Про затвердження нового складу групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий термін і здійснення контролю за її виконанням

На зміну пункту 1 розпорядження Кабінету Міністрів України від 12 січня 2001 р. N 1 ( 1-2001-р ) "Про ведення колективних переговорів з укладення Генеральної, галузевих і регіональних угод" затвердити новий склад групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий термін і здійснення контролю за її виконанням (додається).
