Про затвердження Строків проведення користувачами мисливських угідь натаскування, наганяння, вимуштрування, польових випробувань і змагань мисливських собак

Відповідно до статей 6, 34 Закону України «Про мисливське господарство та полювання», абзацу шістнадцятого підпункту 156 пункту 4 Положення про Міністерство захисту довкілля та природних ресурсів України, затвердженого постановою Кабінету Міністрів України від 25 червня 2020 року № 614, НАКАЗУЮ:

1. Затвердити Строки проведення користувачами мисливських угідь натаскування, наганяння, вимуштрування, польових випробувань і змагань мисливських собак, що додаються.

2. Управлінню охорони біорізноманіття та земельних ресурсів (Володимир ДОМАШЛІНЕЦЬ) в установленому законодавством порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності з дня його офіційного опублікування.

4. Контроль за виконанням цього наказу покласти на заступника Міністра відповідно до розподілу функціональних обов’язків.

СТРОКИ
проведення користувачами мисливських угідь натаскування, наганяння, вимуштрування, польових випробувань і змагань мисливських собак

1. Строки проведення користувачами мисливських угідь натаскування, наганяння, вимуштрування, польових випробувань і змагань мисливських собак розроблені відповідно до статті 34 Закону України «Про мисливське господарство та полювання».

2. Натаскування, наганяння, вимуштрування, польові випробування і змагання мисливських собак проводиться у такі строки:

1) для групи порід хортих:

по зайцю русаку - з листопада по січень включно;

по лисиці - з жовтня по лютий включно;

2) для групи порід гончих:

по зайцю русаку - з листопада по січень включно;

по лисиці - з жовтня по лютий включно;

3) для групи порід лайок:

по борсуку - з жовтня по листопад включно;

по кабану, оленю європейському та плямистому - з серпня по січень включно;

по фазану - з жовтня по грудень включно;

по білці, бобру, куниць лісову та кам’яну, норці американській - з жовтня по лютий включно;

4) для групи порід лягавих, спанієлів і ретриверів:

по качці (крім гоголя, черні білоокої, савки, огара, галагаза, гаги звичайної, лутка, крохалів, черні червонодзьобої, нерозня, креха середнього, каменярки, казарок білощокої та червоноволої) та лисці - з серпня по грудень включно;

по кулику (крім кулика-сороки, ходуличника, шилодзьобки, кроншнепів, чайки, лежня, дерихвоста, поручайника, крем’яшника, чорниша, перевізника, фіфі, зуйків морського, малого, великодзьобого, галстучника, пісочників, плавунців, баранця великого) - з серпня по грудень включно;

по куріпці сірій та фазану - з жовтня по грудень включно;

по перепілці - з серпня по листопад включно;

5) для групи порід норових:

по хутрових у природних норах - під час сезону полювання.
