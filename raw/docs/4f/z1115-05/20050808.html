НАКАЗ

08.08.2005 N 293

Зареєстровано в Міністерстві юстиції України 28 вересня 2005 р. за N 1115/11395

Про визнання таким, що втратив чинність, наказу Міністерства промислової політики України

З метою виконання Указу Президента України N 901 ( 901/2005 ) від 01.06.2005 "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства промислової політики України від 27 грудня 1995 року N 239 ( z0015-96 ) "Про затвердження Прейскуранта оптових регульованих цін на кокс кам'яновугільний, крім ливарного", зареєстрований в Міністерстві юстиції України 11 січня 1996 року за N 15/1040.

2. Контроль за виконанням наказу залишаю за собою.

B.о. Міністра О.С.Уруський
