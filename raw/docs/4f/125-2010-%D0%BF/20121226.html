КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 лютого 2010 р. N 125 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1182 ( 1182-2012-п ) від 19.12.2012 }

Про внесення змін у додаток до постанови Кабінету Міністрів України від 20 травня 2009 р. N 506

Кабінет Міністрів України постановляє:

Внести зміни у додаток до постанови Кабінету Міністрів України від 20 травня 2009 р. N 506 ( 506-2009-п ) "Про затвердження Порядку проведення органами державної контрольно-ревізійної служби державного фінансового аудиту окремих господарських операцій" (Офіційний вісник України, 2009 р., N 39, ст. 1307, N 51, ст. 1753, N 65, ст. 2271), виклавши його в редакції, що додається.
