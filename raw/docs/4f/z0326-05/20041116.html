Текст документа від 16.11.2004:

МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

16.11.2004 N 286

Зареєстровано в Міністерстві юстиції України 23 березня 2005 р. за N 326/10606

Про визнання таким, що втратив чинність, наказу Мінпраці України від 22.08.2000 N 215 "Про затвердження Правил безпеки у вугільних шахтах"

З метою приведення наказу Міністерства праці та соціальної політики України від 22.08.2000 N 215 ( z0715-00 ) "Про затвердження Правил безпеки у вугільних шахтах" до вимог Закону України "Про охорону праці" ( 2694-12 ) НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства праці та соціальної політики України від 22.08.2000 N 215 ( z0715-00 ) "Про затвердження Правил безпеки у вугільних шахтах", зареєстрований в Міністерстві юстиції України 17.10.2000 за N 715/4936.

2. Контроль за виконанням цього наказу покласти на першого заступника Міністра - керівника апарату Солдатенка М.О.
