03.11.2008 N 625

Зареєстровано в Міністерстві юстиції України 22 квітня 2009 р. за N 361/16377

Про внесення змін до наказу МОЗ від 23.04.2007 N 202

З метою приведення нормативно-правових актів Міністерства охорони здоров'я України у відповідність до постанови Кабінету Міністрів України від 04.06.2008 N 518 ( 518-2008-п ) "Деякі питання обігу наркотичних засобів і психотропних речовин" НАКАЗУЮ:

1. Унести зміни до Переліку наркотичних (психотропних) комбінованих лікарських засобів, що містять малу кількість наркотичних засобів списку N 1 таблиці II Переліку наркотичних засобів, психотропних речовин і прекурсорів, затвердженого постановою Кабінету Міністрів України від 06.05.2000 N 770, затвердженого наказом МОЗ від 23.04.2007 N 202 ( z0700-07 ), зареєстрованого в Міністерстві юстиції України 21.06.2007 за N 700/13967:

після позиції

"21. Спазмо-проксивон, капсули N 8, N 16, декстропропоксифену гідрохлорид - 65 мг"

новими позиціями:

"22. Залдіар, таблетки, вкриті оболонкою, по 37,5 мг/325 мг N 10, N 20, N 30, N 50, трамадолу гідрохлорид - 37,5 мг

23. Пара-трал, капсули N 10х1, N 10х2, N 10х5 у контурних чарункових упаковках, трамадолу гідрохлорид - 37,5 мг".

2. Комітету з контролю за наркотиками (Хобзей М.К.) забезпечити в установленому порядку державну реєстрацію цього наказу в Міністерстві юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Юрченка В.Д.

Міністр В.М.Князевич
