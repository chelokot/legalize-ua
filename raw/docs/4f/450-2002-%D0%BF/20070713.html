Кабінет Міністрів України постановляє:

1. Затвердити Порядок централізованого оформлення, виготовлення та видачі паспорта громадянина України для виїзду за кордон (додається).

2. Установити, що конкретні терміни запровадження в регіонах затвердженого цією постановою Порядку визначаються Міністерством внутрішніх справ у міру створення Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 2 квітня 2002 р. N 450

ПОРЯДОК централізованого оформлення, виготовлення та видачі паспорта громадянина України для виїзду за кордон

1. Централізоване оформлення, виготовлення та видача паспортів громадянина України для виїзду за кордон здійснюється управліннями (відділами) у справах громадянства, імміграції та реєстрації фізичних осіб головних управлінь, управлінь МВС в Автономній Республіці Крим, областях, мм. Києві та Севастополі, відділів, відділень у справах громадянства, імміграції та реєстрації фізичних осіб міських, районних управлінь (відділів) МВС (далі - територіальний орган чи підрозділ), на базі яких утворюються вузли місцевого рівня (у районах, районах у містах, містах обласного значення) та вузли регіонального рівня (в Автономній Республіці Крим, областях, мм. Києві та Севастополі), Головним обчислювальним центром і Державним центром виготовлення паспортних документів (далі - Центр) Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування (далі - Система).

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 1723 ( 1723-2004-п ) від 23.12.2004, N 378 ( 378-2005-п ) від 26.05.2005, N 327 ( 327-2006-п ) від 15.03.2006, N 580 ( 580-2006-п ) від 27.04.2006 }

2. Для оформлення паспорта громадянина України для виїзду за кордон (далі - паспорт) з використанням Системи заявник подає особисто до територіального органу чи підрозділу - вузла місцевого рівня паспорт громадянина України, свідоцтво про народження (для осіб віком до 16 років), довідку податкового органу про присвоєння ідентифікаційного номера, крім осіб, які через свої релігійні або інші переконання відмовляються від прийняття ідентифікаційного номера і офіційно повідомили про це відповідні державні органи, та квитанцію про сплату державного мита або документ, що підтверджує повне чи часткове звільнення від його сплати. { Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 580 ( 580-2006-п ) від 27.04.2006 }

Справляння будь-яких додаткових зборів забороняється.

3. Анкета отримувача паспорта (з внесенням фотовідбитка - відтворене з використанням лазерного друку безпосередньо у документі зображення особи) оформляється згідно з додатком безпосередньо уповноваженою особою територіального органу чи підрозділу.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 580 ( 580-2006-п ) від 27.04.2006 }

4. Підставою для виготовлення та видачі паспорта є рішення, прийняте начальником (або його заступником) територіального органу чи підрозділу, про що у відведеному в анкеті місці робиться відмітка. Анкета зберігається у територіальному органі чи підрозділі. Зазначені в анкеті персональні дані передаються до Головного обчислювального центру через вузол відповідного регіонального рівня.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 580 ( 580-2006-п ) від 27.04.2006 }

5. Між суб'єктами Системи (вузли місцевих та регіональних рівнів, Головний обчислювальний центр) персональні дані передаються каналами зв'язку, згрупованими у спеціальні файли, що містять графічні та текстові дані. У період до завершення у Центрі роботи, пов'язаної із забезпеченням технічного захисту інформації, така передача здійснюється з використанням оптичних носіїв інформації.

6. Головний обчислювальний центр:

проводить з використанням бази даних Державного реєстру платників податків та інших обов'язкових платежів перевірку достовірності ідентифікаційного номера;

передає до Центру персональні дані, необхідні для виготовлення паспортів, які після виготовлення паспортів повертаються до Головного обчислювального центру.

7. Паспорти виготовляються Центром відповідно до рекомендацій Міжнародної організації цивільної авіації (IKAO, Doc 9303/1) з відтворенням фотовідбитка та власноручного підпису заявника в день отримання від Головного обчислювального центру персональних даних.

8. Центр надсилає виготовлені паспорти до відповідного територіального органу чи підрозділу (вузла місцевого рівня) у порядку, встановленому для передачі документів суворого обліку, не пізніше ніж у 3-денний термін.

{ Пункт 8 із змінами, внесеними згідно з Постановою КМ N 580 ( 580-2006-п ) від 27.04.2006 }

9. Паспорт видається заявникові не пізніше ніж через 30 днів після оформлення анкети.

Про видачу паспорта в анкеті та паспорті громадянина України робляться відповідні відмітки, а факт його отримання засвідчується власноручним підписом заявника.

10. Передача персональних даних між суб'єктами Системи, відправлення Центром виготовлених паспортів, а також їх видача підтверджується складенням відповідних реєстрів.

11. Персональні дані, внесені до анкети заявника, зберігаються в електронному вигляді в усіх (крім Центру) суб'єктів Системи, які здійснювали оформлення паспорта.
