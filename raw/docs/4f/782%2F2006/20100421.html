Про внесення зміни до Указу Президента України від 28 лютого 2005 року N 384

Стан: Чинний

Ідентифікатор: 782/2006

Текст документа від 21.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення зміни до Указу Президента України від 28 лютого 2005 року N 384

{ Указ втратив чинність в частині призначення Яценюка А.П. на підставі Указу Президента N 545/2010 ( 545/2010 ) від 16.04.2010 }

Відповідно до пункту 12 частини першої статті 106 Конституції України ( 254к/96-ВР ) та статті 10 Закону України "Про Національний банк України" ( 679-14 ) постановляю:

На часткову зміну Указу Президента України від 28 лютого 2005 року N 384 ( 384/2005 ) "Про членів Ради Національного банку України" призначити членом Ради Національного банку України ЯЦЕНЮКА Арсенія Петровича - Першого заступника Глави Секретаріату Президента України - Представника Президента України у Кабінеті Міністрів України, звільнивши члена цієї Ради О. Дуброва.

Президент України В.ЮЩЕНКО

м. Київ, 25 вересня 2006 року N 782/2006
