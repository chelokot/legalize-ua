Про умови матеріально-побутового забезпечення, медичного і транспортного обслуговування Спеціального представника України з питань придністровського врегулювання

Текст документа від 08.12.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 жовтня 2005 р. N 441-р Київ

Про умови матеріально-побутового забезпечення, медичного і транспортного обслуговування Спеціального представника України з питань придністровського врегулювання

{ Із змінами, внесеними згідно з Розпорядженням КМ N 2205-р ( 2205-2010-р ) від 08.12.2010 }

Погодитися з пропозицією МЗС щодо матеріально-побутового забезпечення, медичного і транспортного обслуговування Спеціального представника України з питань придністровського врегулювання на умовах, визначених для директора департаменту центрального апарату Міністерства закордонних справ.

{ Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 2205-р ( 2205-2010-р ) від 08.12.2010 }

Прем'єр-міністр України Ю.ЄХАНУРОВ
