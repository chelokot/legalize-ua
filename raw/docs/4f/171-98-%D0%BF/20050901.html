Питання Національного інституту стратегічних досліджень

Стан: Втратив чинність

Ідентифікатор: 171-98-п

Текст документа від 01.09.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 лютого 1998 р. N 171 Київ

Питання Національного інституту стратегічних досліджень

( Із змінами, внесеними згідно з Постановами КМ N 1229 ( 1229-99-п ) від 12.07.99 N 541 ( 541-2001-п ) від 18.05.2001 N 790 ( 790-2005-п ) від 22.08.2005 )

На виконання Указу Президента України від 21 липня 1997 р. N 663 ( 663/97 ) "Про рішення Ради національної безпеки і оборони України від 17 червня 1997 р. "Про невідкладні заходи щодо впорядкування системи здійснення державної інформаційної політики та удосконалення державного регулювання інформаційних відносин" Кабінет Міністрів України постановляє:

1. Підтримати пропозицію Національного інституту стратегічних досліджень про створення в Автономній Республіці Крим, Донецькій, Закарпатській, Львівській, Одеській областях регіональних інформаційно-аналітичних центрів - філіалів Національного інституту стратегічних досліджень.

2. Раді міністрів Автономної Республіки Крим, обласним державним адміністраціям у місячний термін вирішити питання щодо виділення приміщень та забезпечення зв'язком інформаційно-аналітичних центрів - філіалів Національного інституту стратегічних досліджень.

3. Установити умови оплати праці працівників інформаційно-аналітичних центрів - філіалів Національного інституту стратегічних досліджень відповідно до умов оплати праці керівних працівників і спеціалістів галузевих науково-дослідних установ, встановлених постановами Кабінету Міністрів України від 30 серпня 2002 р. N 1298 ( 1298-2002-п ) та від 2 грудня 1996 р. N 1458 ( 1458-96-п ). ( Пункт 3 із змінами, внесеними згідно з Постановами КМ N 541 ( 541-2001-п ) від 18.05.2001, N 790 ( 790-2005-п ) від 22.08.2005 )

4. Міністерству економіки і Міністерству фінансів:

здійснювати фінансування інформаційно-аналітичних центрів - філіалів Національного інституту стратегічних досліджень у 1998 році в межах коштів, передбачених Національному інституту стратегічних досліджень Державним бюджетом України на 1998 рік;

передбачати щорічно під час формування проекту Державного бюджету України кошти на забезпечення діяльності Національного інституту стратегічних досліджень та його філіалів окремим рядком у видатках Державного бюджету України.

( Пункт 5 втратив чинність на підставі Постанови КМ N 1229 ( 1229-99-п ) від 12.07.99 ) 5. Установити ліміт легкових автомобілів, що обслуговують Національний інститут стратегічних досліджень, у кількості 2 одиниць.
