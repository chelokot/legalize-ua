КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 лютого 2006 р. N 52-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 46-р ( 46-2007-р ) від 14.02.2007 }

Про використання залишків заставного зерна врожаю 2004 року, що перейшло у власність держави

З метою використання зерна, яке залишилося від продажу, що здійснювався відповідно до розпорядження Кабінету Міністрів України від 15 липня 2005 р. N 266 ( 266-2005-р ) "Про використання заставного зерна врожаю 2004 року, що перейшло у власність держави" ДАК "Хліб України":

передати в установленому порядку Аграрному фонду заставне продовольче зерно (пшениця III-IV класу та жито групи "А") за його вартістю, включаючи витрати на зберігання на момент передачі, але не вище мінімальної закупівельної ціни;

здійснити продаж фуражного зерна за цінами, що склалися на біржових торгах на момент укладення договорів купівлі-продажу, але не менше, ніж його вартість (з урахуванням заставної ціни та вартості зберігання).

Витрати, пов'язані із зберіганням зерна, розраховуються у порядку, визначеному законодавством;

повертати щотижня до спеціального фонду державного бюджету ( 3235-15 ) за кодом згідно з КПКВК 2801120 кошти, отримані від реалізації фуражного зерна з відрахуванням витрат за надані послуги з його зберігання, які спрямовуються на формування державного продовольчого резерву Аграрним фондом, здійснення заставних закупівель, товарних та фінансових інтервенцій на організованому аграрному ринку.

Прем'єр-міністр України Ю.ЄХАНУРОВ
