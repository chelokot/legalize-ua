Кабінет Міністрів України; Постанова від 06.06.2007 № 798

Про внесення змін до пункту 27 Положення про проходження служби рядовим і начальницьким складом органів внутрішніх справ Української РСР

Стан: Втратив чинність

Ідентифікатор: 798-2007-п

Текст документа від 21.07.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 червня 2007 р. N 798 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 624 ( 624-2008-п ) від 09.07.2008 }

Про внесення змін до пункту 27 Положення про проходження служби рядовим і начальницьким складом органів внутрішніх справ Української РСР

Кабінет Міністрів України постановляє:

Внести до пункту 27 Положення про проходження служби рядовим і начальницьким складом органів внутрішніх справ Української РСР, затвердженого постановою Кабінету Міністрів Української РСР від 29 липня 1991 р. N 114 ( 114-91-п ), - із змінами, внесеними постановами Кабінету Міністрів України від 20 березня 1998 р. N 349 ( 349-98-п ) (Офіційний вісник України, 1998 р., N 12, ст. 449), від 7 червня 1999 р. N 986 ( 986-99-п ) (Офіційний вісник України, 1999 р., N 23, ст. 1055) і від 8 червня 2005 р. N 428 ( 428-2005-п ) (Офіційний вісник України, 2005 р., N 23, ст. 1283), такі зміни:

в абзаці третьому:

доповнити абзац після слова "старшого" словами "і вищого";

слова "вищі офіцерські звання запасу" замінити словами "офіцерські звання запасу вищі ніж звання майора";

в абзаці п'ятому слово "підполковника" замінити словом "капітана";

абзаци сьомий і восьмий виключити.

Прем'єр-міністр України В.ЯНУКОВИЧ
