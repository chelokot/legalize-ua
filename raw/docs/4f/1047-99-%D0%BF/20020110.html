КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 червня 1999 р. N 1047 Київ

( Постанова втратила чинність на підставі Постанови КМ N 32 ( 32-2002-п ) від 10.01.2002 )

Про забезпечення виконання завдань, покладених на Комісію з питань житлової політики при Президентові України

Кабінет Міністрів України постановляє:

1. Збільшити граничну чисельність працівників апарату Кабінету Міністрів України на чотирі одиниці для утворення у складі Управління структурних змін у сфері матеріального виробництва сектору з питань житлової політики.

Покласти на новоутворений сектор функції з організаційного забезпечення діяльності Комісії з питань житлової політики при Президентові України, утвореної Указом Президента України від 22 квітня 1999 р. N 423 ( 423/99 ).

2. Міністерству фінансів внести необхідні зміни до кошторису на утримання апарату Кабінету Міністрів України.
