Президент України; Указ від 12.01.2000 № 47/2000

Про призначення В. Скопенка Ректором Київського національного університету імені Тараса Шевченка

Стан: Дію відновлено

Ідентифікатор: 47/2000

Текст документа від 05.05.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про призначення В. Скопенка Ректором Київського національного університету імені Тараса Шевченка

{ Додатково див. Указ Президента N 410/2008 ( 410/2008 ) від 05.05.2008 }

Призначити СКОПЕНКА Віктора Васильовича Ректором Київського національного університету імені Тараса Шевченка.

Кабінету Міністрів України в установленому порядку вирішити питання про медичне, побутове та інше обслуговування Ректора Київського національного університету імені Тараса Шевченка відповідно до статусу міністра України.

Президент України Л.КУЧМА

м. Київ, 12 січня 2000 року N 47/2000
