Президент України; Указ від 10.10.2005 № 1431/2005

Про збільшення розміру довічних державних стипендій окремим категоріям громадян

Стан: Чинний

Ідентифікатор: 1431/2005

Текст документа від 10.10.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про збільшення розміру довічних державних стипендій окремим категоріям громадян

1. Установити, що з 1 вересня 2005 року довічні державні стипендії для учасників бойових дій у період Великої Вітчизняної війни 1941-1945 років та довічні державні іменні стипендії громадянам України, які зазнали переслідувань за правозахисну діяльність, виплачуються щомісячно у розмірі 232 гривень кожна, довічні державні стипендії для осіб, які мають особливі заслуги перед Батьківщиною, виплачуються щомісячно у розмірі 332 гривень.

2. Внести до указів Президента України такі зміни:

1) у частині другій статті 1 Указу Президента України від 17 травня 2000 року N 689 ( 689/2000 ) "Про заснування довічних державних стипендій для учасників бойових дій у період Великої Вітчизняної війни 1941-1945 років" (зі зміною, внесеною Указом від 25 жовтня 2003 року N 1212 ( 1212/2003 ) цифри "165" замінити цифрами "232";

2) у частині другій статті 1 Указу Президента України від 26 листопада 2001 року N 1147 ( 1147/2001 ) "Про довічні державні іменні стипендії громадянам України, які зазнали переслідувань за правозахисну діяльність" (зі зміною, внесеною Указом від 2 грудня 2002 року N 1113 ( 1113/2002 ) цифри "165" замінити цифрами "232";

3) у частині другій статті 1 Указу Президента України від 12 жовтня 2004 року N 1226 ( 1226/2004 ) "Про довічні державні стипендії для осіб, які мають особливі заслуги перед Батьківщиною" цифри "205" замінити цифрами "332".

Президент України В.ЮЩЕНКО
