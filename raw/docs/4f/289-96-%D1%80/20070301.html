{ Розпорядження втратило чинність на підставі Постанови КМ N 317 ( 317-2007-п ) від 01.03.2007 }

Про зміни до додатка N 1 розпорядження Кабінету Міністрів України від 23 жовтня 1995 р. N 643

Внести до додатку N 1 розпорядження Кабінету Міністрів України від 23 жовтня 1995 р. N 643 ( 643-95-р ) такі зміни:

1) доповнити розділ "По інших державних установах і організаціях" абзацами такого змісту:

"перший заступник, заступники генерального директора Державної адміністрації залізничного транспорту

перший заступник, заступники голови Державного департаменту автомобільного транспорту

перший заступник, заступники голови Державного департаменту морського і річкового транспорту";

2) виключити з розділу "По міністерствах та інших центральних органах державної виконавчої влади" абзац "заступники голови, вчений секретар Вищої атестаційної комісії".

Прем'єр-міністр України Є.МАРЧУК
