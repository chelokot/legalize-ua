ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

18.06.2003 N 266

Зареєстровано в Міністерстві юстиції України 27 червня 2003 р. за N 528/7849

Про внесення змін до постанови Правління Національного банку України від 25.11.2002 N 447 та Положення про порядок формування обов'язкових резервів для банків України

( Із змінами, внесеними згідно з Постановою Національного банку N 352 ( z0775-03 ) від 20.08.2003 )

Відповідно до статті 15 Закону України "Про Національний банк України" ( 679-14 ) та враховуючи стан грошово-кредитного ринку і ліквідність банківської системи України, Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Унести зміни до таких нормативно-правових актів Національного банку України:

( Пункт втратив чинність на підставі Постанови Національного банку N 352 ( z0775-03 ) від 20.08.2003 )

1.2. Пункт 4 у таблиці додатка 1 до Положення про порядок формування обов'язкових резервів для банків України, затвердженого постановою Правління Національного банку України від 27.06.2001 N 244 ( z0586-01 ) та зареєстрованого в Міністерстві юстиції України 11.07.2001 за N 586/5777 (із змінами), викласти в такій редакції:

"4. Готівка в касі в національній валюті, яка зараховується в покриття обов'язкових резервів банку".

2. Департаменту монетарної політики (Н.І.Гребеник) після державної реєстрації довести зміст цієї постанови до відома територіальних управлінь Національного банку України та банків для використання в роботі.

3. Контроль за виконанням цієї постанови покласти на першого заступника Голови А.П.Яценюка.

Голова С.Л.Тігіпко
