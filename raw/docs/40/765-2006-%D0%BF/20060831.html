{ Постанова втратила чинність на підставі Постанови КМ N 1266 ( 1266-2006-п ) від 31.08.2006 }

Про затвердження складу наглядової ради Національного спортивного комплексу "Олімпійський"

Кабінет Міністрів України постановляє:

1. Затвердити склад наглядової ради Національного спортивного комплексу "Олімпійський", що додається.

Надати право голові ради затвердити її персональний склад та вносити у разі потреби до нього зміни.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 24 лютого 2003 р. N 244 ( 244-2003-п ) "Про затвердження складу наглядової ради Національного спортивного комплексу "Олімпійський".
