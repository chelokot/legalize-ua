Про виділення коштів для проведення першочергових заходів з ліквідації наслідків надзвичайної ситуації, що виникла 24 грудня 2008 р. у м. Євпаторії

Стан: Чинний

Ідентифікатор: 1591-2008-р

Текст документа від 27.12.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 грудня 2008 р. N 1591-р Київ

Про виділення коштів для проведення першочергових заходів з ліквідації наслідків надзвичайної ситуації, що виникла 24 грудня 2008 р. у м. Євпаторії

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1633-р ( 1633-2008-р ) від 27.12.2008 }

1. Виділити Мінпраці 70 млн. гривень для надання допомоги постраждалим від надзвичайної ситуації, що виникла 24 грудня 2008 р. у м. Євпаторії.

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 107-17 ).

Дозволити Мінпраці здійснювати попередню оплату вартості житла для постраждалих. { Пункт 1 доповнено абзацом згідно з Розпорядженням КМ N 1633-р ( 1633-2008-р ) від 27.12.2008 }

Кошти, не використані у 2008 році, залишити у розпорядженні Мінпраці для забезпечення з 1 січня 2009 р. грошових виплат постраждалим. { Пункт 1 доповнено абзацом згідно з Розпорядженням КМ N 1633-р ( 1633-2008-р ) від 27.12.2008 }

2. Мінфіну та Державному казначейству забезпечити перерахування 25 грудня 2008 р. Мінпраці виділених коштів та здійснити передбачені цим розпорядженням видатки без затвердження переліків витрат, пов'язаних з проведенням першочергових заходів з ліквідації наслідків надзвичайної ситуації, виплатою матеріальної допомоги, придбанням житла для постраждалих та відшкодуванням вартості втраченого майна.

3. Мінпраці:

1) забезпечити протягом 25 грудня 2008 р. виплату матеріальної допомоги сім'ям загиблих з розрахунку по 100 тис. гривень на кожного загиблого члена сім'ї та частини матеріальної допомоги постраждалим (аванс) з розрахунку 20 тис. гривень на зруйновану квартиру та 10 тис. гривень на пошкоджену квартиру, яка непридатна для проживання.

Решту коштів спрямувати на придбання житла для постраждалих, відшкодування вартості втраченого майна та виплату в повному обсязі матеріальної допомоги відповідно до цього розпорядження;

2) затвердити в одноденний строк нормативи витрат на придбання житла для постраждалих, відшкодування вартості втраченого майна, розміри матеріальної допомоги постраждалим та протягом двох робочих днів здійснити відповідні виплати;

3) подати до 1 березня 2009 р. Мінекономіки, Мінфіну, Державному казначейству та Мінрегіонбуду звіт про використання виділених згідно з цим розпорядженням коштів.
