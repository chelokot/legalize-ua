Зареєстровано в Міністерстві юстиції України 19 лютого 2003 р. за N 141/7462

( Наказ втратив чинність на підставі Наказу Міністерства аграрної політики N 592 ( z1346-05 ) від 01.11.2005 )

Про внесення змін до наказу Мінагрополітики України від 11 квітня 2001 р. N 102

Відповідно до наказу Міністерства аграрної політики України від 10 вересня 2002 р. N 261 ( v0261555-02 ) "Про зміни до наказу від 5 червня 2001 р. N 150" НАКАЗУЮ:

1. Внести доповнення до наказу Міністерства аграрної політики України від 11.04.2001 N 102 ( z0425-01 ), зареєстрованого в Міністерстві юстиції України 17.05.2001 за N 425/5616, із змінами і доповненнями:

- до додатка 2 - "Український науково-дослідний інститут цукрової промисловості I";

- до додатка 3 - "Смілянське спеціалізоване конструкторське бюро по обладнанню для цукрової промисловості".

2. Контроль за виконанням наказу покласти на першого заступника Державного секретаря Лузана Ю.Я.
