{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 228 ( z0759-06 ) від 19.06.2006 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 13.02.2001 N 52

Відповідно до постанови Кабінету Міністрів України від 22 серпня 2005 року N 790 ( 790-2005-п ) "Про внесення змін та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 13.02.2001 N 52 ( z0140-01 ) "Про упорядкування умов оплати праці працівників управління "Укрспортзабезпечення" (із змінами), зареєстрованого в Міністерстві юстиції України 15.02.2001 за N 140/5331, виклавши додатки 1 та 2 у новій редакції (додаються).

2. Ці зміни застосовуються з 1 вересня 2005 року.

Міністр І.Сахань
