{ Із змінами, внесеними згідно з Постановами КМ N 118 ( 118-2016-п ) від 18.02.2016 N 239 ( 239-2017-п ) від 10.03.2017 N 758 ( 758-2018-п ) від 19.09.2018 N 827 ( 827-2019-п ) від 14.08.2019 N 869 ( 869-2020-п ) від 23.09.2020 N 1030 ( 1030-2022-п ) від 13.09.2022 }

Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України зміни, що додаються.

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

3. Ця постанова набирає чинності з дня опублікування.
