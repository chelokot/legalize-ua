КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 вересня 2008 р. N 1218-р Київ

Про утворення комісії з ліквідації Укравтотрансу

{ Із змінами, внесеними згідно з Розпорядженням КМ N 99-р ( 99-2010-р ) від 20.01.2010 }

1. Утворити комісію з ліквідації Укравтотрансу.

Затвердити головою зазначеної комісії заступника Міністра транспорту та зв'язку - голову Державної адміністрації автомобільного транспорту Кравчука Петра Костянтиновича. { Абзац другий пункту 1 в редакції Розпорядження КМ N 99-р ( 99-2010-р ) від 20.01.2010 }

2. Голові комісії:

затвердити її персональний склад і забезпечити здійснення заходів, пов'язаних з ліквідацією Укравтотрансу;

поінформувати у тримісячний строк Кабінет Міністрів України про результати проведеної роботи.

Прем'єр-міністр України Ю.ТИМОШЕНКО
