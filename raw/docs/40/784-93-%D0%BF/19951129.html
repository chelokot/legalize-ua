Текст документа від 29.11.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 вересня 1993 р. N 784 Київ

( Постанова втратила чинність на підставі Постанови КМ N 957 ( 957-95-п ) від 29.11.95 )

Про надання економічних пільг Державному комітетові по матеріальних резервах

Кабінет Міністрів України постановляє:

Для забезпечення електронавантажувачами підприємств Державного комітету по матеріальних резервах звільнити Комітет від сплати податку на добавлену вартість та вивізного (експортного) мита на металопродукцію, що реалізується при проведенні бартерної (товарообмінної) операції згідно з укладеним із зарубіжною фірмою контрактом від 15 травня 1993 р. N ГК-029-5.
