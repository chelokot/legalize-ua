Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов

Стан: Чинний

Ідентифікатор: 988-2009-р

Текст документа від 28.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 серпня 2009 р. N 988-р Київ

Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1045-р ( 1045-2009-р ) від 03.09.2009 N 1401-р ( 1401-2009-р ) від 21.10.2009 N 1284-р ( 1284-2009-р ) від 29.10.2009 N 1563-р ( 1563-2010-р ) від 28.07.2010 }

1. Погодитися з пропозицією Мінрегіонбуду щодо придбання Державною іпотечною установою квартир за переліком згідно з додатком на загальну суму 351 136,365 тис. гривень в житлових будинках, прийнятих в експлуатацію, та на об'єктах незавершеного житлового будівництва із строком здачі в експлуатацію не пізніше ніж 25 грудня 2009 р. за наявності відповідної банківської гарантії або іншого виду забезпечення виконання зобов'язань забудовників, що прийматимуться Державною іпотечною установою, або наявності графіка виконання будівельно-монтажних робіт, погодженого з керівником інспекції державного архітектурно-будівельного контролю в Автономній Республіці Крим, областях, мм. Києві та Севастополі, для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов та перебувають на квартирному обліку.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженнями КМ N 1045-р ( 1045-2009-р ) від 03.09.2009, N 1401-р ( 1401-2009-р ) від 21.10.2009, N 1563-р ( 1563-2010-р ) від 28.07.2010 }

2. Державній іпотечній установі передати квартири, придбані згідно з пунктом 1 цього розпорядження, відповідно до затвердженого Кабінетом Міністрів України розподілу.

{ Пункт 2 в редакції Розпорядження КМ N 1284-р ( 1284-2009-р ) від 29.10.2009 }

3. Внести до розпорядження Кабінету Міністрів України від 5 серпня 2009 р. N 929 ( 929-2009-р ) "Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов" - із змінами, внесеними постановою Кабінету Міністрів України від 12 серпня 2009 р. N 861 ( 861-2009-п ), такі зміни:

1) у пункті 1 цифри "147085,119" замінити цифрами "147981,519";

2) у додатку до розпорядження:

у позиції "смт Нові Санжари Полтавської області, вул. Шевченка, 20/15, "Завершення будівництва 5-поверхового 47-квартирного жилого будинку з об'єктами громадського призначення, розташованого по вул. Шевченка, 20/15, в смт Нові Санжари, Полтавської області" у графі "Вартість одного кв. метра, гривень" цифри "3400" замінити цифрами "3800", а у графі "Загальна вартість квартир, тис. гривень" цифри "7619,4" - цифрами "8515,8";

4. Головним розпорядникам бюджетних коштів разом з Мінфіном та органами місцевого самоврядування під час уточнення показників Державного бюджету України на 2009 рік ( 835-17 ) та складання проектів державного бюджету на наступні роки передбачати кошти для компенсації Державній іпотечній установі витрат, пов'язаних з придбанням квартир відповідно до пункту 1 цього розпорядження, та кошти для придбання та будівництва житла для окремих категорій громадян, які відповідно до законодавства потребують поліпшення житлових умов та перебувають на квартирному обліку.
