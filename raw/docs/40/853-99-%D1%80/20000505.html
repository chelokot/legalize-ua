Кабінет Міністрів України; Розпорядження від 18.08.1999 № 853-р

Про дозвіл на митне оформлення обладнання, що надходить на адресу ТОВ "Олімпекс Купе Інтернешнл" (м. Одеса)

Стан: Втратив чинність

Ідентифікатор: 853-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 серпня 1999 р. N 853-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

( Із змінами, внесеними згідно з Розпорядженням КМ N 1240-р ( 1240-99-р ) від 13.11.99 )

Дозволити Держмитслужбі здійснити митне оформлення обладнання, що надходить на адресу ТОВ "Олімпекс Купе Інтернешнл" (м. Одеса) для власних виробничих потреб згідно з контрактом від 10 грудня 1998 р. N 0/77 з додатками 1, 2 та 3, укладеним з фірмою "Omega Terminal S.A." (Швейцарія), як товарів критичного імпорту, встановивши ставку ввізного мита у розмірі 0,1 відсотка митної вартості цього обладнання, та без сплати додаткового збору, встановленого постановою Кабінету Міністрів України від 19 травня 1999 р. N 840 ( 840-99-п ).

( Розпорядження із змінами, внесеними згідно з Розпорядження КМ N 1240-р ( 1240-99-р ) від 13.11.99 )

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
