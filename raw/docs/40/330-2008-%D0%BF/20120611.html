Кабінет Міністрів України; Постанова від 09.04.2008 № 330

Про внесення змін до Порядку використання коштів, передбачених у державному бюджеті для провадження міжнародної діяльності у галузі рибного господарства

Стан: Втратив чинність

Ідентифікатор: 330-2008-п

Текст документа від 11.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 квітня 2008 р. N 330 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 470 ( 470-2012-п ) від 31.05.2012 }

Про внесення змін до Порядку використання коштів, передбачених у державному бюджеті для провадження міжнародної діяльності у галузі рибного господарства

Кабінет Міністрів України постановляє:

Внести до Порядку використання коштів, передбачених у державному бюджеті для провадження міжнародної діяльності у галузі рибного господарства, затвердженого постановою Кабінету Міністрів України від 1 березня 2007 р. N 305 ( 305-2007-п ) (Офіційний вісник України, 2007 р., N 16, ст. 591), такі зміни:

доповнити Порядок ( 305-2007-п ) пунктом 2-1 такого змісту:

"2-1. Держкомрибгосп розробляє план заходів щодо виконання бюджетної програми, який затверджується Мінагрополітики та погоджується з Мінфіном, і оприлюднює його на сайті Держкомрибгоспу.";

абзац перший пункту 3 викласти у такій редакції:

"3. Бюджетні кошти спрямовуються Держкомрибгоспом відповідно до плану заходів на:".

Прем'єр-міністр України Ю.ТИМОШЕНКО
