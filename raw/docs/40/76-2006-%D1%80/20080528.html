КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 лютого 2006 р. N 76-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 774-р ( 774-2008-р ) від 28.05.2008 }

Про затвердження складу робочої групи щодо взаємодії з Європейським комітетом з питань запобігання катуванням чи нелюдському або такому, що принижує гідність, поводженню чи покаранню

На часткову зміну пункту 3 розпорядження Кабінету Міністрів України від 20 листопада 1999 р. N 1257 ( 1257-99-р ) (Офіційний вісник України, 1999 р., N 47, ст. 2312; 2002 р., N 44, ст. 2042) затвердити склад робочої групи щодо взаємодії з Європейським комітетом з питань запобігання катуванням чи нелюдському або такому, що принижує гідність, поводженню чи покаранню (додається).
