Текст документа від 21.04.1997:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 148/98 від 24.02.98 )

Про заходи щодо вдосконалення співробітництва України з Європейським Союзом

( Із змінами, внесеними згідно з Указом Президента N 355/97 від 21.04.97 )

З метою забезпечення більш ефективного співробітництва України з Європейським Союзом постановляю:

1. Перейменувати Міжвідомчий комітет України у справах Європейських Співтовариств у Міжвідомчий комітет України у справах Європейського Союзу.

У зв'язку з цим внести до Указу Президента України від 28 серпня 1993 року N 358 ( 358/93 ) "Про Міжвідомчий комітет України у справах Європейських Співтовариств" та Положення про Міжвідомчий комітет України у справах Європейських Співтовариств, затвердженого цим Указом, такі зміни:

у тексті Указу та Положення слова "Європейські Співтовариства" замінити словами "Європейський Союз" у відповідному відмінку;

у частині четвертій пункту 5 Положення слова "Національного центру реалізації міжнародної технічної допомоги Україні" замінити словами "Агентства міжнародного співробітництва та інвестицій";

пункт 8 Положення викласти в такій редакції: "Функції виконавчого органу Комітету здійснює управління міжнародного економічного співробітництва Міністерства закордонних справ України".

2. Увільнити ЛАНДИКА Валентина Івановича від обов'язків Голови Міжвідомчого комітету України у справах Європейських Співтовариств.

3. Призначити МІТЮКОВА Ігоря Олександровича - віце-Прем'єр-міністра України Головою Міжвідомчого комітету України у справах Європейського Союзу.

( Частина друга статті 3 втратила чинність на підставі Указу Президента N 355/97 від 21.04.97 ) Надати право Голові Міжвідомчого комітету України у справах Європейського Союзу за погодженням з керівниками міністерств, інших центральних органів державної виконавчої влади України, вказаних у частині п'ятій пункту 5 Положення про Міжвідомчий комітет України у справах Європейського Союзу, визначати персональний склад Міжвідомчого комітету України у справах Європейського Союзу та вносити до нього зміни.

Президент України Л.КУЧМА
