Кабінет Міністрів України; Постанова від 29.04.1999 № 749

Про Уповноваженого Кабінету Міністрів України і його заступника з питань співпраці на прикордонних водах

Стан: Втратив чинність

Ідентифікатор: 749-99-п

Текст документа від 17.06.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 квітня 1999 р. N 749 Київ

Про Уповноваженого Кабінету Міністрів України і його заступника з питань співпраці на прикордонних водах

{ Із змінами, внесеними згідно з Постановами КМ N 599 ( 599-2003-п ) від 26.04.2003 N 512 ( 512-2008-п ) від 04.06.2008 }

Кабінет Міністрів України постановляє:

На виконання Угоди між Урядом України та Урядом Республіки Польща про співробітництво в галузі водного господарства на прикордонних водах, затвердити першого заступника Голови Державного комітету по водному господарству Кобринського Андрія Юрійовича Уповноваженим Кабінету Міністрів України з питань співпраці на прикордонних водах, його заступником - начальника Львівського обласного виробничого управління по меліорації і водному господарству Козака Василя Серафимовича.

{ Постанова із змінами, внесеними згідно з Постановами КМ N 599 ( 599-2003-п ) від 26.04.2003, N 512 ( 512-2008-п ) від 04.06.2008 }
