Верховна Рада України; Постанова від 22.09.2009 № 1623-VI

Про зміну способу голосування щодо законопроектів, які стосуються підвищення розмірів державних соціальних стандартів

Стан: Втратив чинність

Ідентифікатор: 1623-17

Текст документа від 06.10.2009:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

{ Постанова втратила чинність на підставі Постанови ВР N 1624-VI ( 1624-17 ) від 06.10.2009, ВВР, 2009, N 49, ст.742 }

Про зміну способу голосування щодо законопроектів, які стосуються підвищення розмірів державних соціальних стандартів

( Відомості Верховної Ради України (ВВР), 2009, N 49, ст.741 )

Враховуючи нагальну потребу у підвищенні розмірів державних соціальних стандартів, зважаючи на перешкоджання народними депутатами України проведенню пленарних засідань у Верховній Раді України, що унеможливлює голосування картками та фіксацію результатів голосування за допомогою електронної системи підрахунку голосів, Верховна Рада України постановляє:

1. Провести у визначений цією Постановою спосіб голосування щодо законопроектів, які стосуються підвищення розмірів державних соціальних стандартів, охорони трудових прав громадян і забезпечення відповідних гарантій (реєстр. N 4762, N 5062, N 5091-1, N 5091-2, N 5091-3).

Забезпечення процедури голосування покласти на Лічильну комісію Верховної Ради України.

2. Встановити, що:

голосування на пленарному засіданні Верховної Ради України щодо законопроектів (реєстр. N 4762, N 5062, N 5091-1, N 5091-2, N 5091-3) за наслідками їх обговорення здійснюється народними депутатами України особисто відкритим голосуванням шляхом підняття руки. При цьому голова Лічильної комісії Верховної Ради України за алфавітним списком зачитує прізвище, ім'я та по батькові кожного народного депутата України. Кожен народний депутат України, чиє прізвище оголошено, якщо він голосує "за" - піднімає руку і виголошує своє волевиявлення - "за" у мікрофон з робочого місця, якщо ж він голосує "проти" чи "утримався" - не піднімаючи руки, сидячи на своєму місці, виголошує відповідне волевиявлення. Волевиявлення кожного народного депутата України фіксується за допомогою аудіо- і відеозасобів, а також у стенограмі пленарного засідання;

Лічильна комісія Верховної Ради України здійснює підрахунок голосів та голова Лічильної комісії повідомляє Верховній Раді України про результати голосування.

3. Ця Постанова набирає чинності з дня її прийняття.
