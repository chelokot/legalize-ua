{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 1104 ( z1242-06 ) від 23.11.2006 }

Про внесення змін до наказу Держкомзв'язку України від 03.09.2003 N 166

З метою додаткового відпрацювання механізму взаєморозрахунків між операторами телефонних мереж загального користування та операторами мереж стільникового рухомого зв'язку НАКАЗУЮ:

1. Внести зміни до наказу Держкомзв'язку України від 03.09.2003 N 166 ( z0773-03 ) "Про Тимчасовий порядок проведення взаєморозрахунків між операторами телефонних мереж загального користування та операторами мереж стільникового рухомого зв'язку", зареєстрованого Міністерством юстиції України 8 вересня 2003 року за N 773/8094:

1.1. У пункті 4 цифри та слова "1 березня 2004 року" замінити на цифри та слова "1 червня 2004 року".

2. Управлінню економічної політики (Артюшенко Л.В.) розмістити інформацію про введення у дію наказу на веб-сайті Держкомзв'язку України.

3. Контроль за виконанням наказу покласти на заступника Голови Проживальського О.П.

Голова О.В.Яценко
