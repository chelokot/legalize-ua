КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2001 р. N 1487 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 388 ( 388-2018-п ) від 10.05.2018 }

Про внесення доповнень до постанови Кабінету Міністрів України від 17 серпня 1998 р. N 1301

Кабінет Міністрів України постановляє:

Внести до Положення про передприватизаційну підготовку підприємств, затвердженого постановою Кабінету Міністрів України від 17 серпня 1998 р. N 1301 ( 1301-98-п ) (Офіційний вісник України, 1998 р., N 33, ст. 1250; 2000 р., N 7, ст. 280, N 43, ст. 1847), такі доповнення:

пункт 6 доповнити абзацом такого змісту:

"Якщо показники фінансового стану підприємств, що займають монопольне становище на загальнодержавному ринку відповідних товарів і послуг або мають стратегічне значення для економіки та безпеки держави, не відповідають нормативним вимогам, встановленим Мінфіном, Фондом державного майна та Методикою оцінки вартості майна під час приватизації ( 1114-98-п ), передприватизаційна підготовка зазначених підприємств здійснюється обов'язково";

абзац перший пункту 11 після слів "представники цього органу" доповнити словами "Міністерства економіки та з питань європейської інтеграції".

Прем'єр-міністр України А.КІНАХ
