КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 травня 2008 р. N 697-р Київ

Про підготовку та проведення XXIII Конгресу Всесвітньої асоціації юристів

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1480-р ( 1480-2008-р ) від 26.11.2008 }

1. З метою забезпечення підготовки та проведення у березні 2009 р. у м. Києві XXIII Конгресу Всесвітньої асоціації юристів (далі - Конгрес) утворити Організаційний комітет у складі згідно з додатком.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 1480-р ( 1480-2008-р ) від 26.11.2008 }

2. Організаційному комітетові розробити та подати в установленому порядку на розгляд Кабінету Міністрів України план заходів з підготовки та проведення Конгресу.

3. Мінфіну і Мін'юсту під час доопрацювання законопроекту про Державний бюджет України на 2009 рік передбачити кошти для підготовки та проведення Конгресу.

{ Пункт 3 в редакції Розпорядження КМ N 1480-р ( 1480-2008-р ) від 26.11.2008 }
