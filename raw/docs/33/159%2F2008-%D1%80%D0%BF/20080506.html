Текст документа від 06.05.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення зміни до Розпорядження Президента України від 28 лютого 2008 року N 81

На часткову зміну Розпорядження Президента України від 28 лютого 2008 року N 81 ( 81/2008-рп ) "Питання дальшого розвитку українсько-лівійського співробітництва" ввести до складу української частини Робочої групи високого рівня з дальшого розвитку українсько-лівійських відносин ГОНЧАРУКА Андрія Івановича - заступника Глави Секретаріату Президента України, Спеціального уповноваженого України з питань торговельно-економічного співробітництва з Великою Соціалістичною Народною Лівійською Арабською Джамахирією, призначивши його першим заступником керівника української частини Робочої групи.

Президент України В.ЮЩЕНКО

м. Київ, 6 травня 2008 року N 159/2008-рп
