МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ ДЕРЖАВНЕ КАЗНАЧЕЙСТВО УКРАЇНИ

НАКАЗ

15.05.2009 N 196

Зареєстровано в Міністерстві юстиції України 1 червня 2009 р. за N 481/16497

Про визнання деяких наказів Державного казначейства України такими, що втратили чинність

Відповідно до Положення про Державне казначейство України, затвердженого постановою Кабінету Міністрів України від 21.12.2005 N 1232 ( 1232-2005-п ), враховуючи вимоги Міністерства юстиції України за результатами проведеної у 2008 році перевірки стану додержання законодавства про державну реєстрацію нормативно-правових актів у Державному казначействі України, та з метою оптимізації нормативної бази Державного казначейства України НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

наказ Головного управління Державного казначейства України від 21.03.97 N 28 ( z0102-97 ) "Про впровадження казначейської системи виконання державного бюджету", зареєстрований у Міністерстві юстиції України 21.03.97 за N 102/1906 (зі змінами);

наказ Головного управління Державного казначейства України від 09.04.97 N 32 ( z0172-97 ) "Про затвердження Інструкції про відкриття реєстраційних рахунків органами Державного казначейства України", зареєстрований у Міністерстві юстиції України 12.05.97 за N 172/1976 (зі змінами);

наказ Головного управління Державного казначейства України від 31.12.98 N 109 ( z0069-99 ) "Про затвердження Інструкції про порядок складання річних бухгалтерських звітів установами та організаціями, що утримуються за рахунок державного та/або місцевих бюджетів", зареєстрований у Міністерстві юстиції України 04.02.99 за N 69/3362 (зі змінами);

наказ Головного управління Державного казначейства України від 25.03.99 N 27 ( z0202-99 ) "Про затвердження Порядку казначейського обслуговування позабюджетних коштів установ і організацій, що утримуються за рахунок коштів державного бюджету", зареєстрований у Міністерстві юстиції України 01.04.99 за N 202/3495 (зі змінами);

наказ Державного казначейства України від 10.08.2001 N 141 ( z0776-01 ) "Про затвердження Інструкції про порядок відображення в обліку бюджетних установ операцій з централізованого постачання матеріальних цінностей", зареєстрований у Міністерстві юстиції України 03.09.2001 за N 776/5967 (зі змінами);

наказ Державного казначейства України від 07.03.2003 N 48 ( z0237-03 ) "Про порядок виконання Державним казначейством України рішень суду щодо відшкодування шкоди, завданої громадянинові незаконними діями органів дізнання, попереднього (досудового) слідства, прокуратури, а також судів", зареєстрований у Міністерстві юстиції України 26.03.2003 за N 237/7558;

наказ Державного казначейства України від 23.01.2004 N 11 ( z0174-04 ) "Про затвердження Порядку виконання Державним казначейством України рішень суду щодо відшкодування шкоди, завданої громадянинові незаконними діями органів дізнання, досудового слідства, прокуратури, а також судів", зареєстрований у Міністерстві юстиції України 09.02.2004 за N 174/8773;

наказ Державного казначейства України від 20.01.2005 N 8 ( z0211-05 ) "Про затвердження Порядку виконання Державним казначейством України рішень суду щодо відшкодування шкоди, завданої громадянинові незаконними діями органів дізнання, досудового слідства, прокуратури, а також судів", зареєстрований у Міністерстві юстиції України 11.02.2005 за N 211/10491 (зі змінами).

2. Юридичному департаменту (Зіневич О.Л.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Юридичному департаменту (Зіневич О.Л.) довести цей наказ до відома заступників голови, керівників самостійних структурних підрозділів центрального апарату Державного казначейства України та начальників Головних управлінь Державного казначейства України в Автономній Республіці Крим, областях, містах Києві та Севастополі.

4. Головним управлінням Державного казначейства України в Автономній Республіці Крим, областях, містах Києві та Севастополі довести цей наказ до відома установ, що ними обслуговуються, а головним розпорядникам бюджетних коштів - до підпорядкованих установ.

5. Контроль за виконанням цього наказу залишаю за собою.

6. Цей наказ набирає чинності через 10 днів після державної реєстрації у Міністерстві юстиції України.

Голова Т.Я.Слюз
