КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 серпня 2005 р. N 844 Київ

Про утворення Державної інспекції зв'язку

{ Із змінами, внесеними згідно з Постановами КМ N 954 ( 954-2008-п ) від 22.10.2008 N 464 ( 464-2009-п ) від 13.05.2009 N 709 ( 709-2010-п ) від 11.08.2010 }

Кабінет Міністрів України постановляє:

1. Утворити у складі Національної комісії з питань регулювання зв'язку Державну інспекцію зв'язку.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 709 ( 709-2010-п ) від 11.08.2010 }

2. Національній комісії з питань регулювання зв'язку подати у місячний строк Кабінетові Міністрів України проект Положення про Державну інспекцію зв'язку і пропозиції стосовно внесення відповідних змін до законодавчих актів.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }
