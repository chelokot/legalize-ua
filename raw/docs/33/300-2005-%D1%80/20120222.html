Кабінет Міністрів України; Розпорядження від 01.08.2005 № 300-р

Про передачу державного підприємства "Український державний центр радіочастот" до сфери управління Національної комісії з питань регулювання зв'язку

Стан: Втратив чинність

Ідентифікатор: 300-2005-р

Текст документа від 22.02.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 серпня 2005 р. N 300-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 95-р ( 95-2012-р ) від 22.02.2012 }

Про передачу державного підприємства "Український державний центр радіочастот" до сфери управління Національної комісії з питань регулювання зв'язку

1. Відповідно до статті 16 Закону України "Про радіочастотний ресурс України" ( 1770-14 ) передати державне підприємство "Український державний центр радіочастот" (м. Київ, просп. Перемоги, 15-й кілометр) із сфери управління Мінтрансзв'язку до сфери управління Національної комісії з питань регулювання зв'язку.

У зв'язку з цим у розділі "м. Київ" переліку підприємств, установ та організацій, що передаються до сфери управління Мінтрансзв'язку, затвердженого розпорядженням Кабінету Міністрів України від 28 вересня 2004 р. N 684 ( 684-2004-р ), виключити таку позицію:

"1181765 Український державний центр радіочастот, просп. Перемоги, 15-й кілометр".

2. Мінтрансзв'язку разом з Національною комісією з питань регулювання зв'язку подати у тримісячний строк проект нормативно-правового акта щодо виконання державним підприємством "Український державний центр радіочастот" окремих функцій Адміністрації зв'язку та радіочастот.

Прем'єр-міністр України Ю.ТИМОШЕНКО
