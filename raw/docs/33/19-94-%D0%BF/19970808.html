Стан: Втратив чинність

Текст документа від 08.08.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 січня 1994 р. N 19 Київ

Про особливості приватизації в агропромисловому комплексі майна, що перебуває в державній власності, та майна, що належить Автономній Республіці Крим

( Із змінами, внесеними згідно з Постановами КМ N 1144 ( 1144-96-п ) від 17.09.96 N 865 ( 865-97-п ) від 08.08.97 )

З метою прискорення приватизації та забезпечення виконання Закону України "Про особливості приватизації майна в агропромисловому комплексі" ( 290/96-ВР ) Кабінет Міністрів України постановляє: ( Преамбула із змінами, внесеними згідно з Постановою КМ N 1144 ( 1144-96-п ) від 17.09.96 )

1. Установити, що погодження з Кабінетом Міністрів України питань про приватизацію майна підприємств і організацій агропромислового комплексу здійснюється в порядку, передбаченому постановою Кабінету Міністрів України від 29 серпня 1994 р. N 598 ( 598-94-п ) "Про затвердження Порядку погодження з Кабінетом Міністрів України умов приватизації окремих об'єктів державної власності. ( Абзац перший пункту 1 в редакції Постанови КМ N 1144 ( 1144-96-п ) від 17.09.96 )

При цьому державний орган приватизації, крім документів, передбачених у пунктах 2 та 3 Порядку погодження з Кабінетом Міністрів України умов приватизації окремих об'єктів державної власності, затвердженого зазначеною постановою, подає пропозиції щодо розміру частки акцій, що тимчасово залишається у власності держави, погоджені відповідно з Міністерством сільського господарства і продовольства, Державним комітетом по харчовій промисловості або іншим органом, до сфери управління якого належить підприємство, що приватизується, а також з Антимонопольним комітетом у разі, коли підприємство займає монопольне становище на ринку. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1144 ( 1144-96-п ) від 17.09.96 )

2. Оцінка вартості майна підприємств і організацій агропромислового комплексу, приватизація яких здійснюється відповідно до Закону України "Про особливості приватизації майна в агропромисловому комплексі" ( 290/96-ВР ), проводиться відповідно до методики, що затверджується Кабінетом Міністрів України. ( Абзац перший пункту 2 в редакції Постанови КМ N 1144 ( 1144-96-п ) від 17.09.96, із змінами, внесеними згідно з Постановою КМ N 865 ( 865-97-п ) від 08.08.97 )

Вартість майна, що у процесі приватизації безоплатно передається членам трудових колективів радгоспів та інших державних сільськогосподарських підприємств і організацій та прирівняним до них особам, визначається з урахуванням вартості майна, яке припадає на одного члена колективного сільськогосподарського підприємства по області (Республіці Крим), в якій знаходиться державне сільськогосподарське підприємство (організація), що приватизується, обчисленої за схемою, наведеною в додатку, і кількості працівників цього підприємства (організації) та прирівняних до них осіб.

У разі зміни форм бухгалтерської звітності Міністерство сільського господарства і продовольства та Міністерство статистики вносять відповідні уточнення до зазначеної схеми.

3. Приватизація частки державного майна орендних підприємств і організацій агропромислового комплексу здійснюється відповідно до статті 17 Закону України "Про приватизацію державного майна" ( 2163-12 ). ( Пункт 3 із змінами, внесеними згідно з Постановами КМ N 1144 ( 1144-96-п ) від 17.09.96, N 865 ( 865-97-п ) від 08.08.97 )

( Пункт 4 виключено на підставі Постанови КМ N 1144 ( 1144-96-п ) від 17.09.96 )

5. Міністерству сільського господарства і продовольства, Державному комітетові по харчовій промисловості, Державному комітетові по водному господарству з участю Фонду державного майна проаналізувати хід приватизації підприємств харчової промисловості, які переробляють сільськогосподарську сировину, борошномельно-круп'яної та комбікормової промисловості, сервісних, будівельних, фірмових торговельних, несільськогосподарських підприємств і організацій агропромислового комплексу, а також радгоспів та інших державних сільськогосподарських підприємств і про результати проінформувати Кабінет Міністрів України у IV кварталі 1994 року.

6. Фонду державного майна внести відповідні зміни та доповнення до Положення про план приватизації та інших прийнятих ним нормативних актів з урахуванням особливостей приватизації майна в агропромисловому комплексі.
