Кабінет Міністрів України; Постанова від 26.11.2009 № 1246

Деякі питання перерахунку пенсій відповідно до Закону України "Про підвищення престижності шахтарської праці"

Стан: Чинний

Ідентифікатор: 1246-2009-п

Текст документа від 07.05.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 листопада 2009 р. N 1246 Київ

Деякі питання перерахунку пенсій відповідно до Закону України "Про підвищення престижності шахтарської праці"

{ Із змінами, внесеними згідно з Постановою КМ N 331 ( 331-2010-п ) від 05.05.2010 }

Кабінет Міністрів України постановляє:

Здійснити з 1 листопада 2009 р. перерахунок пенсій, призначених у мінімальному розмірі особам, на яких поширюється дія Закону України "Про підвищення престижності шахтарської праці" ( 345-17 ), та працівникам, зайнятим повний робочий день під землею обслуговуванням зазначених осіб, виходячи з розміру прожиткового мінімуму для осіб, які втратили працездатність, що становить 573 гривні, при цьому розмір пенсії не може бути менший ніж 1719 гривень на місяць.

{ Абзац другий постановляючої частини втратив чинність на підставі Постанови КМ N 331 ( 331-2010-п ) від 05.05.2010 }
