КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 лютого 2007 р. N 299 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для підтримки екологічно безпечного стану в зонах відчуження і безумовного (обов'язкового) відселення

{ Із змінами, внесеними згідно з Постановами КМ N 1322 ( 1322-2007-п ) від 14.11.2007 N 81 ( 81-2008-п ) від 22.02.2008 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи за програмою "Підтримка екологічно безпечного стану в зонах відчуження і безумовного (обов'язкового) відселення", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 81 ( 81-2008-п ) від 22.02.2008 }

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для підтримки екологічно безпечного стану в зонах відчуження і безумовного (обов'язкового) відселення, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 лютого 2007 р. N 299

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для підтримки екологічно безпечного стану в зонах відчуження і безумовного (обов'язкового) відселення

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених за бюджетною програмою "Підтримка екологічно безпечного стану в зонах відчуження і безумовного (обов'язкового) відселення" ( 489-16 ) (далі - бюджетні кошти).

2. Виконання бюджетної програми передбачається за рахунок загального та спеціального фонду державного бюджету ( 489-16 ).

3. Головним розпорядником бюджетних коштів є МНС, розпорядником нижчого рівня - державний департамент - Адміністрація зони відчуження і зони безумовного (обов'язкового) відселення (далі - розпорядник).

Одержувачами бюджетних коштів є:

державне спеціалізоване підприємство "Регіональне управління забезпечення організаційно-технічної та розпорядчої діяльності";

державне спеціалізоване підприємство по поводженню з радіоактивними відходами та дезактивації "Комплекс";

державне спеціалізоване науково-виробниче підприємство "Чорнобильський радіоекологічний центр";

державне спеціалізоване комплексне підприємство "Чорнобильська пуща";

державне спеціалізоване підприємство "Центр переробки та захоронення техногенних відходів" "Техноцентр";

державне спеціалізоване виробниче комплексне водоохоронне підприємство "Чорнобильводексплуатація";

державне підприємство "Управління капітального будівництва";

державне підприємство "Спеціалізована будівельна компанія";

державне підприємство по забезпеченню життєдіяльності зони відчуження і зони безумовного (обов'язкового) відселення "Чорнобильсервіс".

4. Бюджетні кошти спрямовуються на виконання плану заходів на 2007 рік (далі - план заходів) з помісячним розподілом одержувачам, розробленого розпорядником і затвердженого МНС за погодженням з Мінфіном, зокрема на:

проведення робіт із зменшення обсягів винесення радіонуклідів з території зони відчуження шляхом зміцнення захисних бар'єрів, зокрема здійснення лісозахисних заходів, підтримки діючих і створення нових водоохоронних споруд; { Абзац другий пункту 4 із змінами, внесеними згідно з Постановою КМ N 81 ( 81-2008-п ) від 22.02.2008 }

збирання, перевезення, зберігання, захоронення радіоактивних відходів, що утворилися внаслідок Чорнобильської катастрофи, експлуатацію та обслуговування об'єктів, призначених для поводження з радіоактивними відходами;

проведення радіаційного та дозиметричного контролю, екологічного моніторингу природного середовища забруднених територій;

утримання території зони відчуження і безумовного (обов'язкового) відселення в належному санітарному та пожежобезпечному стані, фізичний захист об'єктів, призначених для поводження з радіоактивними відходами, та охорону території;

розроблення нормативних документів з питань поводження з радіоактивними відходами;

експлуатацію об'єктів інфраструктури (систем управління діяльністю, інженерних мереж та об'єктів, доріг тощо).

5. Розпорядник:

складає кошторис видатків та помісячний план асигнувань і подає його для затвердження МНС;

затверджує на виконання плану заходів річні програми робіт з помісячним розписом одержувачам;

затверджує на підставі розрахунків, проведених одержувачами бюджетних коштів відповідно до їх річних програм робіт, плани використання бюджетних коштів;

визначає пріоритетні напрями робіт у цілому за планом заходів і для кожного одержувача та враховує їх при затвердженні плану використання бюджетних коштів;

встановлює за погодженням з МНС результативні показники, виконання яких є обов'язковою умовою для перерахування бюджетних коштів їх одержувачам;

здійснює контроль за виконанням робіт одержувачами бюджетних коштів;

укладає із суб'єктами господарювання договори про здійснення заходів, виконання робіт та надання послуг, пов'язаних з ліквідацією наслідків Чорнобильської катастрофи та підтримкою екологічно безпечного стану в зоні відчуження і зоні безумовного (обов'язкового) відселення.

6. Одержувачі бюджетних коштів використовують їх у межах кошторисних призначень та виключно для здійснення заходів, визначених планом заходів.

Одержувачі складають щомісяця акти виконання робіт за попередній місяць, які затверджує розпорядник і на підставі яких розпорядник виділяє бюджетні кошти одержувачам для здійснення платежів. { Абзац другий пункту 6 в редакції Постанови КМ N 1322 ( 1322-2007-п ) від 14.11.2007 }

7. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ), а попередня оплата - згідно з постановою Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752).

8. Перерахування бюджетних коштів проводиться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

9. Відкриття рахунків в органах Державного казначейства розпорядником та одержувачами бюджетних коштів, а також відображення проведених процедур у бухгалтерському обліку та фінансовій звітності про виконання державного бюджету здійснюються у порядку, встановленому Державним казначейством.

10. Одержувачі бюджетних коштів подають до 10 числа місяця, що настає за звітним періодом, розпоряднику звіт про виконання річних програм робіт з помісячним розписом та планів використання бюджетних коштів у натуральних та вартісних показниках, а також результативних показників.

Розпорядник надсилає до 15 числа місяця, що настає за звітним періодом, МНС звіт про виконання плану заходів.

{ Пункт 10 із змінами, внесеними згідно з Постановою КМ N 81 ( 81-2008-п ) від 22.02.2008 }

11. МНС подає щокварталу до 20 числа наступного місяця Мінфіну звіт про виконання плану заходів з аналізом та пропозиціями щодо врегулювання проблемних питань.

12. Контроль за цільовим і ефективним витрачанням бюджетних коштів здійснюється в установленому законодавством порядку.
