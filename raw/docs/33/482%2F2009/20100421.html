УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 539/2010 ( 539/2010 ) від 14.04.2010 }

Питання наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України"

Відповідно до статті 7 Закону України "Про банки і банківську діяльність" ( 2121-14 ) постановляю:

1. На часткову зміну статті 3 Указу Президента України від 1 березня 2005 року N 390 ( 390/2005 ) "Про членів наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України" (зі змінами, внесеними Указами від 2 березня 2006 року N 182 ( 182/2006 ), від 25 вересня 2006 року N 781 ( 781/2006 ), від 4 грудня 2006 року N 1023 ( 1023/2006 ), від 27 лютого 2007 року N 156 ( 156/2007 ), від 12 березня 2007 року N 200 ( 200/2007 ), від 25 квітня 2007 року N 352 ( 352/2007 ), від 27 липня 2007 року N 668 ( 668/2007 ) та від 6 серпня 2008 року N 692) ( 692/2008 ):

1) призначити членами наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України":

ГАЛІНСЬКУ - заступника генерального директора

Лідію Лаврентіївну державного підприємства "Культурно-мистецький та музейний комплекс "Мистецький арсенал"

КОСЯНЧУК - начальника Управління економічного розвитку Наталю Олександрівну та координації діяльності підприємств Державного управління справами

СТАВНІЙЧУК - заступника Глави Секретаріату Президента

Марину Іванівну України - Представника Президента України у Конституційному Суді України

ТАРАСЮКА - Керівника Державного управління справами; Ігоря Григоровича

2) припинити повноваження членів наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України" Я. Берназюка, А. Пишного, І. Пукшина, В. Тополова.

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 24 червня 2009 року N 482/2009
