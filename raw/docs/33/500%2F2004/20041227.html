Президент України; Указ від 30.04.2004 № 500/2004

Про створення Єдиного державного реєстру фізичних осіб

Стан: Втратив чинність

Ідентифікатор: 500/2004

Текст документа від 27.12.2004:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про створення Єдиного державного реєстру фізичних осіб

( Із змінами, внесеними згідно з Указом Президента N 1461/2004 ( 1461/2004 ) від 09.12.2004 )

З метою прискорення створення і введення в дію Єдиного державного реєстру фізичних осіб та забезпечення виготовлення ідентифікаційних документів - носіїв інформації персонального характеру постановляю:

1. Покласти на Міністерство внутрішніх справ України:

виконання функцій спеціально уповноваженого центрального органу виконавчої влади з питань громадянства, імміграції та реєстрації фізичних осіб;

забезпечення створення Єдиного державного реєстру фізичних осіб.

1-1. Установити, що ідентифікаційними документами є:

а) документи, визначені статтею 5 Закону України "Про громадянство України" ( 2235-14 );

б) документи, передбачені у Законах України "Про правовий статус іноземців та осіб без громадянства" ( 3929-12 ), "Про біженців" ( 2557-14 ), "Про імміграцію" ( 2491-14 );

в) посвідчення водія, військовий квиток, пенсійне посвідчення, дозвіл на зберігання і носіння зброї та інші ідентифікаційні документи - носії інформації персонального характеру, визначені Кабінетом Міністрів України.

( Указ доповнено статтею 1-1 згідно з Указом Президента N 1461/2004 ( 1461/2004 ) від 09.12.2004 )

1-2. Документи, зазначені у пунктах "а" і "б" статті 1-1 цього Указу, крім паспорта громадянина України та свідоцтва про належність до громадянства України, виготовляються у формі книжечки із вшитою полікарбонатною сторінкою, а свідоцтво про належність до громадянства України та документи, перелічені у пункті "в" тієї самої статті, - у формі пластикової картки з полімерного матеріалу формату ПД-1 з додержанням рекомендацій Міжнародної організації цивільної авіації (IKAO).

Порядок виготовлення бланків паспортів громадянина України та строки впровадження паспортної картки визначаються Кабінетом Міністрів України.

( Указ доповнено статтею 1-2 згідно з Указом Президента N 1461/2004 ( 1461/2004 ) від 09.12.2004 )

2. Кабінету Міністрів України:

а) для забезпечення створення Єдиного державного реєстру фізичних осіб вирішити питання щодо утворення Міжвідомчої комісії Єдиного державного реєстру фізичних осіб;

б) покласти на зазначену Міжвідомчу комісію функції щодо координації робіт зі створення Єдиного державного реєстру фізичних осіб та вирішення питань його функціонування;

в) проаналізувати у місячний строк хід виконання актів Президента України і Кабінету Міністрів України з питань реєстрації фізичних осіб, затвердити план робіт зі створення Єдиного державного реєстру фізичних осіб у 2004 році і забезпечити його виконання;

г) привести свої акти та забезпечити приведення нормативно-правових актів центральних органів виконавчої влади у відповідність із цим Указом;

д) затвердити у місячний строк за поданням Міністерства внутрішніх справ України зразки і технічний опис документів Єдиного державного реєстру фізичних осіб. ( Статтю 2 доповнено пунктом "д" згідно з Указом Президента N 1461/2004 ( 1461/2004 ) від 09.12.2004 )

3. Міністерству внутрішніх справ України:

забезпечити до 1 липня 2004 року створення Єдиного державного реєстру фізичних осіб на базі Єдиної державної автоматизованої паспортної системи;

( Абзац третій статті 3 вилучено на підставі Указу Президента N 1461/2004 ( 1461/2004 ) від 09.12.2004 )

забезпечити організацію разом із Міністерством фінансів України виготовлення ідентифікаційних документів, які б відповідали вимогам європейських стандартів, рішенням Варшавської конференції 2001 року з боротьби з тероризмом та сприяли спрощенню процедури оформлення документів під час пересування українських громадян за кордоном, реєстрації за місцем проживання на території України.

4. Міністерству фінансів України забезпечити фінансування витрат на створення Єдиного державного реєстру фізичних осіб та виготовлення ідентифікаційних документів у межах видатків, передбачених на створення Єдиної державної автоматизованої паспортної системи.

Президент України Л.КУЧМА
