Деякі питання оплати праці працівників Секретаріату Президента України

Стан: Втратив чинність

Ідентифікатор: 230-2005-р

Текст документа від 09.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 липня 2005 р. N 230-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

Деякі питання оплати праці працівників Секретаріату Президента України

( Із змінами, внесеними згідно з Постановою КМ N 89 ( 89-2006-п ) від 01.02.2006 )

Відповідно до статті 8 Закону України "Про оплату праці" ( 108/95-ВР ) надати право Главі Секретаріату Президента України встановлювати працівникам Секретаріату Президента України надбавку за особливий характер роботи та інтенсивність праці у розмірі та порядку, визначених розпорядженням Кабінету Міністрів України від 4 липня 1995 р. N 414 ( 414-95-р ).

( Розпорядження із змінами, внесеними згідно з Постановою КМ N 89 ( 89-2006-п ) від 01.02.2006 )
