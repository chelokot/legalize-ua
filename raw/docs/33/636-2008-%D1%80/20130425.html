КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 квітня 2008 р. N 636-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах під час виготовлення стаціонарних бурових агрегатів

1. Відповідно до статті 2 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ) та з урахуванням технологічних особливостей виробництва встановити строк виконання на митній території України операцій з давальницькою сировиною під час виготовлення стаціонарних бурових агрегатів за кодом 8430 49 00 00 згідно з УКТЗЕД ( 2371г-14 ) 270 днів з моменту оформлення ввізної вантажної митної декларації.

2. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України Ю.ТИМОШЕНКО
