Про підтримку сімей при народженні дитини

Текст документа від 21.07.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 липня 2004 р. N 981 Київ

( Постанова втратила чинність на підставі Постанови КМ N 617 ( 617-2005-п ) від 21.07.2005 )

Про підтримку сімей при народженні дитини

( Із змінами, внесеними згідно з Постановою КМ N 305 ( 305-2005-п ) від 20.04.2005 )

З метою посилення соціального захисту сімей з дітьми Кабінет Міністрів України постановляє:

1. Запровадити видачу усім жінкам одноразово при народженні дитини під час їх перебування у пологовому будинку (відділенні) пакунків малюка.

Видача пакунка малюка оформляється як одноразова адресна допомога сім'ям при народженні кожної дитини.

Затвердити перелік дитячих товарів для комплектування пакунка малюка (додається).

2. Міністерству у справах молоді та спорту забезпечити:

централізовану закупівлю дитячих товарів вітчизняного виробництва в установленому порядку та формування пакунків малюка вартістю 100 гривень кожний. Закупівлю товарів здійснювати за рахунок коштів, передбачених бюджетною програмою "Здійснення державними органами централізованих заходів з питань дітей, молоді, жінок та сім'ї" ( 1344-15 );

розподіл пакунків малюка між Республіканським комітетом у справах сім'ї та молоді Автономної Республіки Крим, управліннями у справах сім'ї та молоді обласних, Київської та Севастопольської міських державних адміністрацій відповідно до середніх показників народжуваності у регіонах.

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 305 ( 305-2005-п ) від 20.04.2005 )

3. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям забезпечувати доставку пакунків малюка до місць їх призначення і видачу жінкам під час перебування у пологовому будинку (відділенні), а також ведення реєстрів отримувачів згідно з Інструкцією про порядок видачі жінкам пакунків малюка при народженні дитини.

Міністерству у справах сім'ї, дітей та молоді разом з Міністерством охорони здоров'я розробити та затвердити Інструкцію про порядок видачі жінкам пакунків малюка при народженні дитини ( z1059-04 ).

4. Рекомендувати Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям вирішувати питання щодо надання додаткової допомоги сім'ям при народженні дитини у межах коштів, передбачених у відповідних бюджетах на ці цілі.
