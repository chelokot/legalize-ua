Про голову Міжвідомчої групи з розроблення заходів щодо виведення ВАТ "Авіакомпанія "Авіалінії України" з кризового стану

Стан: Втратив чинність

Ідентифікатор: 9-2002-р

Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 січня 2002 р. N 9-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про голову Міжвідомчої групи з розроблення заходів щодо виведення ВАТ "Авіакомпанія "Авіалінії України" з кризового стану

Затвердити головою Міжвідомчої групи з розроблення заходів щодо виведення ВАТ "Авіакомпанія "Авіалінії України" з кризового стану, утвореної розпорядженням Кабінету Міністрів України від 28 грудня 2000 р. N 527 ( 527-2000-р ), Першого віце-прем'єр-міністра України Дубину Олега Вікторовича, увільнивши від цих обов'язків Єханурова Юрія Івановича.

Прем'єр-міністр України А.КІНАХ
