Кабінет Міністрів України; Постанова від 02.06.2004 № 722

Про представників від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму

Стан: Втратив чинність

Ідентифікатор: 722-2004-п

Текст документа від 25.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 червня 2004 р. N 722 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 444 ( 444-2010-п ) від 16.06.2010 }

Про представників від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму

Кабінет Міністрів України постановляє:

На зміну пункту 2 постанови Кабінету Міністрів України від 24 вересня 1999 р. N 1767 ( 1767-99-п ) "Про науково-громадську експертизу набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 1999 р., N 39, ст. 1946) затвердити представниками від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму Білого В.Я. - заступника Міністра охорони здоров'я, Гнибіденка І.Ф. - першого заступника Міністра праці та соціальної політики, Мусіну Л.А. - заступника Міністра економіки та з питань європейської інтеграції, Мярковського А.І. - заступника Міністра фінансів, увільнивши від цих обов'язків Бобильову О.О., Матвійчука В.М., Овчаренка П.П., Яременка О.С.
