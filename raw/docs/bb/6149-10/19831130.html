Президія Верховної Ради УРСР; Указ від 30.11.1983 № 6149-X

Про перетворення Головного управління по іноземному туризму при Раді Міністрів УРСР у Головне управління Української РСР по іноземному туризму

Стан: Не застосовується на території України

Ідентифікатор: 6149-10

Текст документа від 30.11.1983:

УКАЗ ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

Про перетворення Головного управління по іноземному туризму при Раді Міністрів УРСР у Головне управління Української РСР по іноземному туризму

( Відомості Верховної Ради (ВВР), 1983, N 50, ст. 996 )

Президія Верховної Ради Української РСР постановляє:

Перетворити Головне управління по іноземному туризму при Раді Міністрів УРСР у Головне управління Української РСР по іноземному туризму.
