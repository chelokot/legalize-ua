Кабінет Міністрів України; Постанова від 08.12.2009 № 1322

Про внесення змін до пункту 3 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

Стан: Втратив чинність

Ідентифікатор: 1322-2009-п

Текст документа від 08.12.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 грудня 2009 р. N 1322 Київ

Про внесення змін до пункту 3 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

Кабінет Міністрів України постановляє:

У пункті 3 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів, затверджених постановою Кабінету Міністрів України від 22 жовтня 2008 р. N 943 ( 943-2008-п ) "Про економію бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів" (Офіційний вісник України, 2008 р., N 84, ст. 2816; 2009 р., N 45, ст. 1507, N 83, ст. 2823), слова "структурних підрозділів Управління державної охорони" замінити словами "органу управління державною охороною".

Прем'єр-міністр України Ю.ТИМОШЕНКО
