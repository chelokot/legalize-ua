Про порядок використання коштів, передбачених у державному бюджеті для виконання Державної програми розвитку Національної депозитарної системи України

Стан: Чинний

Ідентифікатор: 907-2005-п

Текст документа від 05.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 вересня 2005 р. N 907 Київ

Про порядок використання коштів, передбачених у державному бюджеті для виконання Державної програми розвитку Національної депозитарної системи України

{ Установлено, що використання у 2006 році коштів, передбачених у державному бюджеті для виконання Державної програми розвитку Національної депозитарної системи України, здійснюється за напрямами, визначеними цією Постановою, згідно з Постановою Кабінету Міністрів N 455 ( 455-2006-п ) від 05.04.2006 }

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ) Кабінет Міністрів України постановляє:

Установити, що у 2005 році кошти, передбачені у державному бюджеті для виконання Державної програми розвитку Національної депозитарної системи України, використовуються на:

часткове створення автоматизованої інформаційної системи Національної депозитарної системи - технічні проекти центрального сховища документарних цінних паперів та архівних документів, національної інформаційної мережі та системи передачі даних, програма захисту інформації про цінні папери, підсистема електронного цифрового підпису;

удосконалення програмно-технічного комплексу депозитарної діяльності - створення модулів для обслуговування розміщення всіх видів облігацій за єдиним стандартом, для забезпечення кореспондентських відносин з іноземними депозитарними установами та здійснення грошових розрахунків за договорами щодо цінних паперів;

створення програмного продукту для передачі та зберігання контрольних копій реєстрів власників іменних цінних паперів;

проведення досліджень та підготовки на основі їх результатів пропозицій щодо удосконалення законодавства з питань функціонування Національної депозитарної системи;

здійснення заходів, передбачених розпорядженням Кабінету Міністрів України від 28 липня 2004 р. N 535-рт.
