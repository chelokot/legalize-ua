Про розмір стипендій для молодих учених

Кабінет Міністрів України постановляє:

1. На часткову зміну пункту 2 Положення про стипендії Президента України для молодих учених, затвердженого постановою Кабінету Міністрів України від 23 серпня 1994 р. N 582 ( 582-94-п ) "Про стипендії Президента України для молодих учених" (ЗП України, 1994 р., N 11, ст. 291), установити розмір стипендій Президента України для молодих учених у сумі 6,4 млн. крб. кожна.

2. Установити розмір стипендій Кабінету Міністрів України для молодих учених, заснованих постановою Кабінету Міністрів України від 16 серпня 1994 р. N 560 ( 560-94-п ) "Про стипендії Кабінету Міністрів України для молодих учених" (ЗП України, 1994 р., N 11, ст.285), у сумі 5,5 млн. крб. кожна.

3. Ця постанова набуває чинності з 1 січня 1995 року.
