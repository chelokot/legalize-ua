Кабінет Міністрів України; Розпорядження від 10.06.2009 № 641-р

Про виділення коштів для ліквідації наслідків аварії у відокремленому підрозділі "Шахта імені О.О. Скочинського" державного підприємства "Донецька вугільна енергетична компанія"

Стан: Чинний

Ідентифікатор: 641-2009-р

Текст документа від 22.07.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 червня 2009 р. N 641-р Київ

Про виділення коштів для ліквідації наслідків аварії у відокремленому підрозділі "Шахта імені О.О. Скочинського" державного підприємства "Донецька вугільна енергетична компанія"

{ Назва Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 850-р ( 850-2009-р ) від 22.07.2009 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 850-р ( 850-2009-р ) від 22.07.2009 }

1. Виділити Мінвуглепрому 8763,3 тис. гривень для ліквідації наслідків аварії на державному підприємстві "Шахта імені О.О. Скочинського", що сталася 8 червня 2009 р., у тому числі для надання допомоги на лікування потерпілих та для забезпечення виплати матеріальної допомоги сім'ям загиблих з розрахунку по 200 тис. гривень на кожного загиблого члена сім'ї.

Мінфіну здійнити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 835-17 ).

Мінфіну та Державному казначейству забезпечити перерахування коштів Мінвуглепрому згідно з кошторисом витрат, затвердженим головою Урядової комісії з розслідування причин та ліквідації наслідків аварії у відокремленому підрозділі "Шахта імені О.О. Скочинського" державного підприємства "Донецька вугільна енергетична компанія".

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 850-р ( 850-2009-р ) від 22.07.2009 }

2. Мінвуглепрому подати до кінця 2009 року Мінекономіки, Мінфіну, Мінрегіонбуду та Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
