Ідентифікатор: 484-2004-п

Текст документа від 28.10.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 квітня 2004 р. N 484 Київ

Про внесення змін до постанов Кабінету Міністрів України від 22 липня 1998 р. N 1135 та від 29 березня 2002 р. N 426

( Із змінами, внесеними згідно з Постановою КМ N 1444 ( 1444-2004-п ) від 28.10.2004 )

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 22 липня 1998 р. N 1135 ( 1135-98-п ) "Про забезпечення військовослужбовців Збройних Сил речовим майном у мирний час" (Офіційний вісник України, 1998 р., N 30, ст. 1135; 2003 р., N 37, ст. 1981) та від 29 березня 2002 р. N 426 ( 426-2002-п ) "Про норми харчування військовослужбовців Збройних Сил та інших військових формувань" (Офіційний вісник України, 2002 р., N 14, ст. 739, N 40, ст. 1859; 2003 р., N 37, ст. 1981) зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 29

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 квітня 2004 р. N 484

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 22 липня 1998 р. N 1135 та від 29 березня 2002 р. N 426

( Пункт 1 втратив чинність на підставі Постанови КМ N 1444 ( 1444-2004-п ) від 28.10.2004 )

2. У нормах харчування військовослужбовців Збройних Сил та інших військових формувань, затверджених постановою Кабінету Міністрів України від 29 березня 2002 р. N 426 ( 426-2002-п ), підпункт "д" пункту 1 приміток до норми N 1 доповнити словами "та на гауптвахті (відшкодування витрат за харчування військовослужбовців інших військових формувань, які засуджені до арешту і відбувають покарання на гауптвахті, здійснюється у десятиденний строк з дня надходження рахунків від Міноборони)".
