( Розпорядження втратило чинність на підставі Розпорядження КМ N 493-р ( 493-2003-р ) від 06.08.2003 )

Про надання будинку по вул. Федорова, 16/64, у користування Національного депозитарію

Надати будинок по вул. Федорова, 16/64, у м. Києві в безоплатне користування Національного депозитарію для розміщення його структурних підрозділів.

Національній академії наук здійснити передачу зазначеного будинку в установленому порядку.
