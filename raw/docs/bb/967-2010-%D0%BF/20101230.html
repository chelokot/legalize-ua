Деякі питання функціонування у 2010 році Вищої кваліфікаційної комісії суддів України та Вищого спеціалізованого суду України з розгляду цивільних і кримінальних справ

Ідентифікатор: 967-2010-п

Текст документа від 30.12.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 жовтня 2010 р. N 967 Київ

Деякі питання функціонування у 2010 році Вищої кваліфікаційної комісії суддів України та Вищого спеціалізованого суду України з розгляду цивільних і кримінальних справ

{ Із змінами, внесеними згідно з Постановою КМ N 1157 ( 1157-2010-п ) від 20.12.2010 }

Кабінет Міністрів України постановляє:

1. Затвердити Порядок використання у 2010 році коштів Стабілізаційного фонду ( 2154-17 ) для здійснення заходів, пов'язаних з функціонуванням Вищої кваліфікаційної комісії суддів України та Вищого спеціалізованого суду України з розгляду цивільних і кримінальних справ, що додається.

2. Відповідно до частини другої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) здійснити перерозподіл коштів Стабілізаційного фонду в сумі 6396,7 тис. гривень шляхом зменшення обсягу видатків за напрямом, передбаченим пунктом 5 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік", і збільшення обсягу видатків за напрямом, передбаченим пунктом 14 частини першої статті 74 зазначеного Закону ( 2154-17 ), спрямувавши їх на здійснення заходів, пов'язаних з функціонуванням Вищої кваліфікаційної комісії суддів України та Вищого спеціалізованого суду України з розгляду цивільних і кримінальних справ.

3. Виділити Державній судовій адміністрації та Вищому спеціалізованому суду України з розгляду цивільних і кримінальних справ на безповоротній основі зазначені в пункті 2 цієї постанови кошти за рахунок надходжень до Стабілізаційного фонду ( 2154-17 ) від цільового розміщення державних цінних паперів, а в разі їх недостатності - від приватизації державного майна або продажу земельних ділянок несільськогосподарського призначення, які перебувають у державній власності та на яких розміщені об'єкти, що підлягають приватизації.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1157 ( 1157-2010-п ) від 20.12.2010 }

4. Відповідно до частини другої статті 26 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ):

1) передати бюджетні призначення загального фонду державного бюджету, передбачені Верховному Суду України за програмою 0601010 "Здійснення правосуддя Верховним Судом України", у сумі 1288,5 тис. гривень (видатки споживання, з них оплата праці - 904,6 тис. гривень) Вищому спеціалізованому суду України з розгляду цивільних і кримінальних справ;

{ Підпункт 1 пункту 4 із змінами, внесеними згідно з Постановою КМ N 1157 ( 1157-2010-п ) від 20.12.2010 }

2) здійснити перерозподіл бюджетних призначень загального фонду державного бюджету, передбачених Державній судовій адміністрації, у межах їх загального обсягу в сумі 514,3 тис. гривень шляхом зменшення обсягу видатків споживання за програмою 0501010 "Організаційне забезпечення діяльності судів та установ судової системи" (з них оплата праці - 361,1 тис. гривень) і збільшення обсягу видатків на утримання Вищої кваліфікаційної комісії суддів України.

5. Міністерству фінансів забезпечити відкриття нових бюджетних програм, закріплення за ними кодів програмної та функціональної класифікації видатків і кредитування державного бюджету та внести відповідні зміни до розпису державного бюджету.

6. Державному казначейству перерахувати кошти, виділені відповідно до цієї постанови.

Прем'єр-міністр України М.АЗАРОВ

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 20 жовтня 2010 р. N 967

ПОРЯДОК використання у 2010 році коштів Стабілізаційного фонду ( 2154-17 ) для здійснення заходів, пов'язаних з функціонуванням Вищої кваліфікаційної комісії суддів України та Вищого спеціалізованого суду України з розгляду цивільних і кримінальних справ

1. Цей Порядок визначає механізм використання у 2010 році коштів Стабілізаційного фонду ( 2154-17 ), передбачених пунктом 14 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) за напрямом "Інші витрати", для здійснення заходів, пов'язаних з функціонуванням Вищої кваліфікаційної комісії суддів України та Вищого спеціалізованого суду України з розгляду цивільних і кримінальних справ (далі - бюджетні кошти).

2. Головними розпорядниками бюджетних коштів є Державна судова адміністрація - для забезпечення діяльності Вищої кваліфікаційної комісії суддів України та Вищий спеціалізований суд України з розгляду цивільних і кримінальних справ.

{ Пункт 2 в редакції Постанови КМ N 1157 ( 1157-2010-п ) від 20.12.2010 }

3. Бюджетні кошти спрямовуються на утримання:

1) Вищої кваліфікаційної комісії суддів України - 2039,6 тис. гривень, з них на:

оплату праці працівників та нарахування на заробітну плату - 872,5 тис. гривень;

відрядження, придбання витратних матеріалів, обладнання і предметів довгострокового користування та оплату послуг - 1167,1 тис. гривень;

2) Вищого спеціалізованого суду України з розгляду цивільних і кримінальних справ - 4357,1 тис. гривень, з них на:

оплату праці працівників та нарахування на заробітну плату - 1696,8 тис. гривень;

оплату комунальних та інших послуг і енергоносіїв, відрядження, придбання витратних матеріалів, обладнання і предметів довгострокового користування - 2660,3 тис. гривень.

4. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законом порядку.

5. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

6. Державна судова адміністрація та Вищий спеціалізований суд України з розгляду цивільних і кримінальних справ: { Абзац перший пункту 6 із змінами, внесеними згідно з Постановою КМ N 1157 ( 1157-2010-п ) від 20.12.2010 }

беруть бюджетні зобов'язання виключно у межах фактично перерахованих на рахунки коштів; { Абзац другий пункту 6 із змінами, внесеними згідно з Постановою КМ N 1157 ( 1157-2010-п ) від 20.12.2010 }

подають Мінфіну щомісяця до 5 числа звіт про використання бюджетних коштів. { Абзац третій пункту 6 із змінами, внесеними згідно з Постановою КМ N 1157 ( 1157-2010-п ) від 20.12.2010 }

7. Після закінчення бюджетного періоду залишки бюджетних коштів, що обліковуються на рахунках Державної судової адміністрації та Вищого спеціалізованого суду України з розгляду цивільних і кримінальних справ станом на 1 січня 2011 р., повертаються до державного бюджету.

{ Пункт 7 із змінами, внесеними згідно з Постановою КМ N 1157 ( 1157-2010-п ) від 20.12.2010 }

8. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
