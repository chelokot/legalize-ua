Про представника Міністерства охорони здоров'я в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму

Стан: Втратив чинність

Текст документа від 10.06.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 червня 2009 р. N 575 Київ

Про представника Міністерства охорони здоров'я в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму

Кабінет Міністрів України постановляє:

На часткову зміну пункту 2 постанови Кабінету Міністрів України від 24 вересня 1999 р. N 1767 ( 1767-99-п ) "Про науково-громадську експертизу набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 1999 р., N 39, ст. 1946; 2008 р., N 100, ст. 3345) затвердити представником Міністерства охорони здоров'я в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму Біловола О.М. - першого заступника Міністра охорони здоров'я, головного державного санітарного лікаря України, увільнивши від цих обов'язків Пономаренка А.М.

Прем'єр-міністр України Ю.ТИМОШЕНКО
