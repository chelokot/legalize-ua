КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 березня 2000 р. N 445 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1493 ( 1493-2000-п ) від 29.09.2000 )

Про внесення доповнень до деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Доповнити перелік банків України, до яких рекомендується звертатися для авалювання векселів, що видаються з метою митного оформлення пально-мастильних матеріалів, визначений постановою Кабінету Міністрів України від 24 червня 1999 р. N 1112 ( 1112-99-п ) "Про деякі питання митного оформлення пально-мастильних матеріалів" (Офіційний вісник України, 1999 р., N 25, ст. 1184, N 30, ст. 1546, N 35, ст. 1799) і змінами, внесеними постановою Кабінету Міністрів України від 28 лютого 2000 р. N 409 ( 409-2000-п ), такими словами:

"Акціонерний комерційний банк "Форум".

2. Доповнити перелік банків України, до яких рекомендується звертатися для авалювання векселів, визначений постановою Кабінету Міністрів України від 21 липня 1999 р. N 1300 ( 1300-99-п ), "Про тимчасовий порядок сплати податків суб'єктами підприємницької діяльності України, які здійснюють реалізацію нафтопродуктів вітчизняного виробництва на території України" (Офіційний вісник України, 1999 р., N 29. ст. 1488), такими словами:

"Акціонерний комерційний банк "Форум".
