КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 липня 1999 р. N 1289 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

{ Постанова втратила чинність на підставі Постанови КМ N 1057 ( 1057-2010-п ) від 17.11.2010 }

Про затвердження переліку пунктів пропуску через державний кордон, через які здійснюється переміщення вантажів військового призначення, а також вантажів, що стосуються ядерної діяльності, у разі їх транзиту територією України

{ Із змінами, внесеними згідно з Постановою КМ N 1306 ( 1306-2003-п ) від 20.08.2003 }

{ Зміни до Постанови див. в Постанові КМ N 1042 ( 1042-2006-п ) від 31.07.2006 }

Кабінет Міністрів України постановляє:

Затвердити перелік пунктів пропуску через державний кордон, через які здійснюється переміщення вантажів військового призначення, а також вантажів, що стосуються ядерної діяльності, у разі їх транзиту територією України (додається).
