МІНІСТЕРСТВО ОСВІТИ І НАУКИ, МОЛОДІ ТА СПОРТУ УКРАЇНИ

НАКАЗ

14.12.2011 N 1429

Зареєстровано в Міністерстві юстиції України 23 грудня 2011 р. за N 1513/20251

{ Наказ втратив чинність на підставі Наказу Міністерства економіки N 19944 ( z0188-24 ) від 20.12.2023 }

Про внесення змін до Положення про Комісію щодо погодження питань про внесення позначення, що містить офіційну назву держави "Україна", до знака для товарів і послуг

Відповідно до Указів Президента України від 09.12.2010 N 1085 ( 1085/2010 ) "Про оптимізацію системи центральних органів виконавчої влади", від 08.04.2011 N 410 ( 410/2011 ) "Про затвердження Положення про Міністерство освіти і науки, молоді та спорту України", від 08.04.2011 N 436 ( 436/2011 ) "Про затвердження Положення про Державну службу інтелектуальної власності України" та постанови Кабінету Міністрів України від 28.03.2011 N 346 ( 346-2011-п ) "Про ліквідацію урядових органів" НАКАЗУЮ:

1. Внести до Положення про Комісію щодо погодження питань про внесення позначення, що містить офіційну назву держави "Україна", до знака для товарів і послуг, затвердженого наказом Міністерства освіти і науки України від 07.10.2003 N 677 ( z0931-03 ), зареєстрованого в Міністерстві юстиції України 14.10.2003 за N 931/8252, такі зміни:

1.1. У пунктах 1, 5 слова "Міністерства освіти і науки України" замінити словами "Державної служби інтелектуальної власності України".

1.2.У пункті 8 слова "Державний департамент інтелектуальної власності" замінити словами "Державна служба інтелектуальної власності".

2. Державній службі інтелектуальної власності (Паладій М.В.) в установленому законодавством порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на голову Державної служби інтелектуальної власності Паладія М.В.

4. Цей наказ набирає чинності з дня його офіційного опублікування.
