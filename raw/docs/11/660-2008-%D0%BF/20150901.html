КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 липня 2008 р. N 660 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 266 ( 266-2015-п ) від 29.04.2015 }

Про внесення зміни до пункту 3 постанови Кабінету Міністрів України від 13 грудня 2006 р. N 1719

Кабінет Міністрів України постановляє:

В абзаці четвертому пункту 3 постанови Кабінету Міністрів України від 13 грудня 2006 р. N 1719 ( 1719-2006-п ) "Про перелік напрямів, за якими здійснюється підготовка фахівців у вищих навчальних закладах за освітньо-кваліфікаційним рівнем бакалавра" (Офіційний вісник України, 2006 р., N 50, ст. 3333) слова і цифри "до 1 березня 2008 року" замінити словами і цифрами "до 1 травня 2010 року".
