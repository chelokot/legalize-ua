Верховна Рада УРСР; Постанова від 11.06.1990 № 15-XII

Про зміну порядку обчислення часу на території Української РСР

Стан: Втратив чинність

Ідентифікатор: 15-12

Текст документа від 06.03.1992:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

Про зміну порядку обчислення часу на території Української РСР

( Відомості Верховної Ради УРСР (ВВР), 1990, N 26, ст.400 )

( Із змінами, внесеними згідно з Постановою ВР N 2176-XII ( 2176-12 ) від 06.03.92, ВВР, 1992, N 22, ст.309 )

Верховна Рада Української Радянської Соціалістичної Республіки постановляє:

1. Установити з 1 липня 1990 року на території Української РСР час другого часового поясу без додання однієї години.

( Частина перша статті 1 із змінами, внесеними згідно з Постановою ВР N 2176-12 від 06.03.92 )

( Частина друга статті 1 втратила чинність на підставі Постанови ВР N 2176-12 від 06.03.92 )

2. Доручити Раді Міністрів Української РСР забезпечити введення в дію нового порядку обчислення часу на території республіки.
