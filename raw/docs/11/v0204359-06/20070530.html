16.01.2006 N 204

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 41 ( v0041359-07 ) від 30.05.2007 }

Про внесення змін до структури і чисельності Секретаріату, патронатної служби та автогосподарства Центральної виборчої комісії, затверджених постановою Центральної виборчої комісії від 22 лютого 2005 року N 45

З метою оптимізації структури Секретаріату Центральної виборчої комісії ( v0045359-05 ), керуючись статтею 12, пунктом 7 частини другої статті 26, частиною другою статті 33 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Утворити відділ взаємодії із засобами масової інформації Секретаріату Центральної виборчої комісії на базі Прес-служби Центральної виборчої комісії.

2. Ввести посаду завідуючого відділом взаємодії із засобами масової інформації Секретаріату Центральної виборчої комісії замість посади прес-секретаря Голови Центральної виборчої комісії, керівника Прес-служби.

3. Внести до додатка 1 до постанови Центральної виборчої комісії від 22 лютого 2005 року N 45 ( v0045359-05 ) "Про структуру і чисельність Секретаріату, патронатної служби та автогосподарства Центральної виборчої комісії" (із змінами, внесеними постановами Центральної виборчої комісії від 26 квітня 2005 року N 74 ( v0074359-05 ), від 29 квітня 2005 року N 79 ( v0079359-05 ), від 13 липня 2005 року N 115 ( v0115359-05 ) та від 6 вересня 2005 року N 119 ( v0119359-05 ) відповідні зміни.
