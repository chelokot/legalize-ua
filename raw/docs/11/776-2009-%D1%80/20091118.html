Кабінет Міністрів України; Розпорядження від 01.07.2009 № 776-р

Про виділення коштів Стабілізаційного фонду для підтримки окремих проектів в агропромисловому комплексі

Стан: Чинний

Ідентифікатор: 776-2009-р

Текст документа від 18.11.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 липня 2009 р. N 776-р Київ

Про виділення коштів Стабілізаційного фонду для підтримки окремих проектів в агропромисловому комплексі

{ Із змінами, внесеними згідно з Постановою КМ N 1090 ( 1090-2009-п ) від 14.10.2009 - дію Постанови зупинено згідно з Указом Президента N 916/2009 ( 916/2009 ) від 10.11.2009 }

1. Виділити Мінагрополітики за рахунок коштів Стабілізаційного фонду за напрямом, визначеним у пункті 1 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), 432 380 тис. гривень для підтримки окремих проектів в агропромисловому комплексі, в тому числі:

1) на безповоротній основі у сумі 15 8818 тис. гривень для: { Абзац перший підпункту 1 пункту 1 із змінами, внесеними згідно з Постановою КМ N 1090 ( 1090-2009-п ) від 14.10.2009 - дію Постанови зупинено згідно з Указом Президента N 916/2009 ( 916/2009 ) від 10.11.2009 }

проведення державних виставкових заходів у сфері агропромислового комплексу - 9 000 тис. гривень;

оздоровлення та відпочинку дітей працівників агропромислового комплексу - 10 000 тис. гривень;

державної підтримки сільськогосподарської дорадчої служби - 5 000 тис. гривень;

погашення кредиторської заборгованості, що виникла у 2008 році, зокрема за бюджетними програмами часткової компенсації вартості складної сільськогосподарської техніки вітчизняного виробництва - 2 642 тис. гривень; здешевлення вартості страхових премій (внесків), фактично сплачених суб'єктам аграрного ринку, - 12 176 тис. гривень;

для сплати відсоткової ставки за залученими НАК "Украгролізинг" кредитами під державні гарантії для реалізації інвестиційних проектів, пов'язаних із закупівлею сільськогосподарської техніки вітчизняного виробництва, яка використовується для виробництва сільськогосподарської продукції за сучасними ресурсозберігаючими технологіями, з метою її подальшої передачі сільгосптоваровиробникам на умовах фінансового лізингу - 120000 тис. гривень; { Підпункт 1 пункту 1 доповнено абзацом згідно з Постановою КМ N 1090 ( 1090-2009-п ) від 14.10.2009 - дію Постанови зупинено згідно з Указом Президента N 916/2009 ( 916/2009 ) від 10.11.2009 }

2) на поворотній основі у сумі 273 562 тис. гривень за таким напрямом, як підтримка окремих проектів в агропромисловому комплексі, зокрема для фінансування заходів по операціях фінансового лізингу вітчизняної сільськогосподарської техніки. { Абзац перший підпункту 2 пункту 1 із змінами, внесеними згідно з Постановою КМ N 1090 ( 1090-2009-п ) від 14.10.2009 - дію Постанови зупинено згідно з Указом Президента N 916/2009 ( 916/2009 ) від 10.11.2009 }

Зазначені кошти Стабілізаційного фонду використовуються відповідно до Порядку, затвердженого постановою Кабінету Міністрів України від 13 травня 2009 р. N 463 ( 463-2009-п ) (Офіційний вісник України, 2009 р., N 36, ст. 1225).

2. Мінфіну виділити асигнування в обсязі 432 380 тис. гривень, визначивши джерелом покриття зазначених витрат надходження від цільового розміщення державних цінних паперів.

Прем'єр-міністр України Ю.ТИМОШЕНКО
