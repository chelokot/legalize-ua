{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 135 ( z0459-06 ) від 14.04.2006 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 30.04.2002 N 223

Відповідно до Указу Президента України від 20 березня 2002 року N 271 ( 271/2002 ) "Про Комітет із Державної премії України в галузі архітектури" та з метою удосконалення умов оплати праці працівників Секретаріату Комітету із Державної премії України в галузі архітектури НАКАЗУЮ:

1. Внести зміни до наказу Міністерства праці та соціальної політики України від 30.04.2002 N 223 ( z0497-02 ) "Про умови оплати праці працівників Секретаріату Комітету із Державної премії України в галузі архітектури", зареєстрованого в Міністерстві юстиції України 12 червня 2002 року за N 497/6785, виклавши пункт 3 у такій редакції:

"3. Преміювання, установлення надбавок і доплат до посадового окладу, надання матеріальної допомоги заступнику голови Комітету із Державної премії України в галузі архітектури - керівнику Секретаріату здійснюється згідно з рішенням президії Комітету".
