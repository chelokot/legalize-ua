{ Указ втратив чинність на підставі Указу Президента N 1053/2008 ( 1053/2008 ) від 18.11.2008 }

Про день працівників морського та річкового флоту

На підтримку ініціативи працівників морського та річкового флоту України постановляю:

Встановити в Україні професійне свято працівників морського та річкового флоту - День працівників морського та річкового флоту, яке відзначати щорічно у першу неділю липня.

Президент України Л.КРАВЧУК

м. Київ, 29 червня 1993 року N 236/93
