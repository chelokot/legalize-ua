{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 172 ( z0390-07 ) від 17.04.2007 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 21.06.2004 N 139

Відповідно до постанови Кабінету Міністрів України від 09.04.2005 N 267 ( 267-2005-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери та внесення змін до деяких постанов Кабінету Міністрів України" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 21.06.2004 N 139 ( z0770-04 ) "Про умови оплати праці працівників Центру сприяння інституційному розвитку державної служби", зареєстрованого в Міністерстві юстиції України 23.06.2004 за N 770/9369 (зі змінами), виклавши додаток у новій редакції (додається).

2. Установити працівникам посадові оклади, виходячи з розмірів та у терміни, що визначені додатком.

Міністр В.Кириленко

Заступник Міністра фінансів України В.Матвійчук
