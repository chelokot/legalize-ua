{ Постанова втратила чинність на підставі Постанови КМ N 765 ( 765-2006-п ) від 31.05.2006 }

Про затвердження складу наглядової ради Національного спортивного комплексу "Олімпійський"

Кабінет Міністрів України постановляє:

1. Затвердити склад наглядової ради Національного спортивного комплексу "Олімпійський" (додається).

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 29 серпня 2002 р. N 1292 ( 1292-2002-п ) "Про затвердження складу наглядової ради Національного спортивного комплексу "Олімпійський".
