КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 березня 1998 р. N 177-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Про дозвіл на митне оформлення вантажів для ВАТ "Алчевський коксохімічний завод"

Дозволити Держмитслужбі здійснити митне оформлення вантажів, що надійшли на адресу ВАТ "Алчевський коксохімічний завод" з 18 червня по 22 липня 1996 р. відповідно до контракту від 25 червня 1996 р. N 003-25/06/96-357, укладеного з швейцарською фірмою "Праймтрейд А.Г.", для виробничих потреб, із нарахуванням митного збору за їх перебування під митним контролем лише за перші 10 днів періоду, за який цей збір справляється.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
