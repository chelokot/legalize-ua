НАКАЗ

N 253 від 19.10.2000 Зареєстровано в Міністерстві юстиції України 1 листопада 2000 р. за N 761/4982

{ Наказ втратив чинність на підставі Наказу Міністерства фінансів N 987 ( z1300-14 ) від 30.09.2014 }

Про доповнення до Інструкції про порядок реєстрації виданих, повернутих і використаних довіреностей на одержання цінностей

Відповідно до Положення про Міністерство фінансів України, затвердженого Указом Президента України від 26 серпня 1999 року N 1081/99 ( 1081/99 ), НАКАЗУЮ:

1. Доповнити Інструкцію про порядок реєстрації виданих, повернутих і використаних довіреностей на одержання цінностей, затверджену наказом Міністерства фінансів України від 16 травня 1996 року N 99 ( z0293-96 ) і зареєстровану в Міністерстві юстиції України 12 червня 1996 року за N 293/1318 (зі змінами і доповненнями), пунктом 1 такого змісту: "1. Інструкція поширюється на підприємства, установи та організації, їхні відділення, філії, інші відособлені підрозділи та представництва іноземних суб'єктів господарської діяльності (далі-підприємство)".

2. Пункти 1-15 уважати відповідно пунктами 2-16.

3. У пункті 4 слова "в організації, установі (надалі-підприємство)" вилучити.
