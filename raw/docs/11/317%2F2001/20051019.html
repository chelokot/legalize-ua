Про Представника України у Спільній комісії по виконанню та інспекціях

Стан: Втратив чинність

Текст документа від 19.10.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1462/2005 ( 1462/2005 ) від 19.10.2005 )

Про Представника України у Спільній комісії по виконанню та інспекціях

1. Призначити ЩЕРБУ Анатолія Анатолійовича Представником України у Спільній комісії по виконанню та інспекціях (СКВІ), створеній відповідно до Договору між Союзом Радянських Соціалістичних Республік та Сполученими Штатами Америки про скорочення та обмеження стратегічних наступальних озброєнь ( 840_050 ) від 31 липня 1991 року.

2. Визнати таким, що втратив чинність, Указ Президента України від 12 березня 1993 року N 80 ( 80/93 ) "Про Представника України у Спільній комісії по виконанню та інспекціях".

Президент України Л.КУЧМА
