Кабінет Міністрів України; Розпорядження від 01.02.2006 № 57-р

Про встановлення строку виконання на митній території України ремонтно-відновлювальних робіт для деяких видів тягового рухомого складу залізниць та його частин, силових установок і частин до них

Стан: Втратив чинність

Ідентифікатор: 57-2006-р

Текст документа від 24.01.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 лютого 2006 р. N 57-р Київ

Про встановлення строку виконання на митній території України ремонтно-відновлювальних робіт для деяких видів тягового рухомого складу залізниць та його частин, силових установок і частин до них

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1052-р ( 1052-2007-р ) від 28.11.2007 }

Відповідно до статті 232 Митного кодексу України ( 92-15 ) з урахуванням технологічних особливостей установити для тягового рухомого складу залізниць та його частин, силових установок і частин до них, що класифікуються згідно з УКТЗЕД ( 2371г-14 ) за товарними позиціями 8408, 8409, 8501, 8502, 8503, 8601, 8602 і 8607, строк виконання ремонтно-відновлювальних робіт на митній території України 360 днів.

{ Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 1052-р ( 1052-2007-р ) від 28.11.2007 }
