ПОСТАНОВА від 30 вересня 1981 р. N 496 Київ

{ Постанова втратила чинність на підставі Постанови Кабінету Міністрів України N 855 ( 855-2026-п ) від 01.07.2026 }

Про використання жилих будинків для малосімейних для тимчасового забезпечення жилими приміщеннями малих сімей

( Із змінами, внесеними згідно з Постановою КМ N 349 ( 349-85-п ) від 17.09.85 )

З метою якнайшвидшого задоволення потреб у житлі малих сімей Рада Міністрів Української РСР і Українська республіканська рада професійних спілок постановляють:

1. Визнати за доцільне використовувати, при необхідності, як сімейні гуртожитки для тимчасового забезпечення жилими приміщеннями малих сімей жилі будинки для малосімейних.

Рішення про це приймається адміністрацією підприємства, установи, організації чи органом кооперативної або іншої громадської організації та відповідним профспілковим комітетом і комітетом комсомолу до початку спорудження будинку. ( Абзац другий пункту 1 в редакції Постанови КМ N 349 ( 349-85-п ) від 17.09.85 )

Використання жилих будинків для малосімейних відповідно до цього пункту провадяться після реєстрації їх виконкомами місцевих Рад народних депутатів як гуртожитків.

Будинки для малосімейних, відносно яких не прийнято такого рішення, заселяються у відповідності з Правилами обліку громадян, які потребують поліпшення житлових умов, і надання їм жилих приміщень в Українській РСР, затвердженими постановою Ради Міністрів УРСР і Укрпрофради від 11 грудня 1984 р. N 470 ( 470-84-п ) (ЗП УРСР, 1984 р., N 12, ст. 80). ( Абзац четвертий пункту 1 в редакції Постанови КМ N 349 ( 349-85-п ) від 17.09.85 )

2. Затвердити Положення про використання жилих будинків для малосімейних для тимчасового забезпечення жилими приміщеннями малих сімей, що додається, і ввести його в дію з 1 січня 1982 року.

Заступник Голови Ради Міністрів Української РСР Г.ВАЩЕНКО

Голова Української республіканської ради професійних спілок В.СОЛОГУБ

Інд. 35

ЗАТВЕРДЖЕНЕ постановою Ради Міністрів УРСР і Укрпрофради від 30 вересня 1981 р. N 496

ПОЛОЖЕННЯ про використання жилих будинків для малосімейних для тимчасового забезпечення жилими приміщеннями малих сімей

1. Для тимчасового забезпечення жилими приміщеннями малих сімей підприємства, установи, організації, при необхідності, приймають рішення про використання як сімейних гуртожитків жилих будинків для малосімейних (далі - будинки для тимчасового проживання малосімейних).

2. На підприємствах, в установах, організаціях, зазначених у пункті 1 цього Положення, ведуться списки працівників на одержання жилих приміщень у будинках для тимчасового проживання малосімейних.

До списків включаються малі сім'ї, що перебувають на квартирному обліку і бажають одержати квартири у таких будинках.

3. Включення до списку на одержання жилих приміщень у будинках для тимчасового проживання малосімейних, а також виключення із списку провадиться за спільним рішенням:

у будинках відомчого житлового фонду - адміністрації підприємства, установи, організації та профспілкового комітету і комітету комсомолу;

у будинках громадського житлового фонду - органу кооперативної або іншої громадської організації та профспілкового комітету і комітету комсомолу.

У рішенні про включення до списку зазначається:

дата включення до списку;

відомості про перебування на квартирному обліку (дата і номер рішення про взяття на облік);

склад сім'ї.

Датою включення до списку є день прийняття рішення про це.

( Пункт 3 в редакції Постанови КМ N 349 ( 349-85-п ) від 17.09.85 )

4. Виключення зі списку на одержання жилих приміщень у будинках для тимчасового проживання малосімейних провадиться у випадках:

а) зняття відповідних осіб з квартирного обліку;

б) подання відомостей, що не відповідають дійсності, які стали підставою для включення до списку, або неправомірних дій службових осіб при вирішенні питання про включення до списку. ( Підпункт "б" пункту 4 в редакції Постанови КМ N 349 ( 349-85-п ) від 17.09.85 )

5. Особи, які перебувають у списку на одержання жилих приміщень у будинках для тимчасового проживання малосімейних і переведені на роботу на інше підприємство, в установу, організацію, включаються до аналогічного списку, що ведеться там, з урахуванням часу перебування у списку за попереднім місцем роботи.

6. Сім'ї, включені до списку на одержання жилих приміщень у будинках для тимчасового проживання малосімейних, а також ті, які одержали жилі приміщення в цих будинках, зберігають право перебування на квартирному обліку.

7. Надання жилих приміщень у будинках для тимчасового проживання малосімейних провадиться виходячи з 6 кв. метрів на члена сім'ї.

При відсутності достатнього за розміром жилого приміщення на просьбу повнолітніх членів сім'ї, у якої настала черга на одержання квартири у вказаних будинках, їй може бути надане жиле приміщення меншого розміру.

8. Працівникам, які перебувають у списку на одержання жилих приміщень у будинках для тимчасового проживання малосімейних, жилі приміщення надаються в порядку їх черговості у цьому списку.

9. Жилі приміщення в будинках для тимчасового проживання малосімейних надаються за рішенням органів, вказаних у пункті 3 цього Положення.

10. На підставі рішення про надання жилого приміщення в будинку для тимчасового проживання малосімейних адміністрація підприємства, установи, організації видає працівникові спеціальний ордер, який є єдиною підставою для вселення в надане жиле приміщення. ( Пункт 10 із змінами, внесеними згідно з Постановою КМ N 349 ( 349-85-п ) від 17.09.85 )

11. Плата за користування жилими приміщеннями в будинках для тимчасового проживання малосімейних провадиться у розмірах, встановлених для оплати жилих приміщень у будинках державного і громадського житлового фонду.

12. Жилі приміщення, що звільняються у будинках для тимчасового проживання малосімейних, споруджених із залученням у порядку пайової участі коштів підприємств, установ, організацій, заселяються в першу чергу працівниками цих підприємств, установ, організацій. ( Пункт 12 в редакції Постанови КМ N 349 ( 349-85-п ) від 17.09.85 )

13. Підприємства, установи, організації, що збудували будинки для тимчасового проживання малосімейних, відповідно до чинного законодавства звільняються від передачі частини жилої площі у цих будинках виконкомам місцевих Рад народних депутатів та іншим організаціям.
