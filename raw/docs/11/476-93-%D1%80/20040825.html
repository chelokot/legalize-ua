Кабінет Міністрів України; Розпорядження від 08.07.1993 № 476-р

Про надання пільг Північному державному гірничо-збагачувальному комбінату при визначенні розрахункового фонду споживання

Стан: Втратив чинність

Ідентифікатор: 476-93-р

Текст документа від 25.08.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 липня 1993 р. N 476-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1109 ( 1109-2004-п ) від 25.08.2004 )

Дозволити, як виняток, Північному державному гірничо-збагачувальному комбінату з 1 червня 1993 р. при визначенні розрахункового фонду споживання не застосовувати індекс зменшення обсягів виробництва.

Перший віце-прем'єр-міністр України Ю.ЗВЯГІЛЬСЬКИЙ
