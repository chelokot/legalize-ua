Зареєстровано в Міністерстві юстиції України 1 квітня 2005 р. за N 356/10636

Про втрату чинності наказу від 21.11.94 N 116

З метою удосконалення законодавства про охорону праці, у зв'язку із втратою чинності постанови Кабінету Міністрів України від 27.01.93 N 62 ( 62-93-п ) "Про питання нагляду за охороною праці" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Держнаглядохоронпраці України від 21.11.94 N 116 ( z0004-95, z0005-95 ) "Про експертно-технічні центри (госпрозрахункові підрозділи) Держнаглядохоронпраці", зареєстрований у Міністерстві юстиції України 05.01.95 за N 4/540, N 5/541.

2. Начальнику управління науково-технічного забезпечення державного нагляду (Больман Г.О.) подати цей наказ до Міністерства юстиції України для державної реєстрації.

3. Управлінню нормативно-правового та юридичного забезпечення (Калиновська І.Г.) внести цей наказ до Державного реєстру нормативно-правових актів з охорони праці.

4. Контроль за виконанням наказу покласти на заступника Голови Комітету Плетньова В.А.
