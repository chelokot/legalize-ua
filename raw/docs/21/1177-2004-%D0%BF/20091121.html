Про порядок відшкодування шкоди, заподіяної життю, здоров'ю чи майну члена окружної, дільничної виборчої комісії, що здійснює підготовку та проведення виборів Президента України, у зв'язку з виконанням обов'язків члена виборчої комісії

Стан: Чинний

Ідентифікатор: 1177-2004-п

Текст документа від 21.11.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 вересня 2004 р. N 1177 Київ

Про порядок відшкодування шкоди, заподіяної життю, здоров'ю чи майну члена окружної, дільничної виборчої комісії, що здійснює підготовку та проведення виборів Президента України, у зв'язку з виконанням обов'язків члена виборчої комісії

{ Назва постанови із змінами, внесеними згідно з Постановою КМ N 1220 ( 1220-2009-п ) від 18.11.2009 }

{ Із змінами, внесеними згідно з Постановою КМ N 1220 ( 1220-2009-п ) від 18.11.2009 }

Відповідно до статті 29 Закону України "Про вибори Президента України" ( 474-14 ) Кабінет Міністрів України постановляє:

1. Установити, що відшкодування шкоди, заподіяної життю, здоров'ю чи майну члена територіальної, дільничної виборчої комісії, що здійснює підготовку та проведення виборів Президента України, у зв'язку з виконанням обов'язків члена виборчої комісії, здійснюється відповідно до Порядку, затвердженого постановою Кабінету Міністрів України від 17 травня 2002 р. N 662 ( 662-2002-п ) (Офіційний вісник України, 2002 р., N 21, ст. 1035; 2004 р., N 30, ст. 2019).

Облік нещасних випадків, що сталися з членами виборчої комісії у зв'язку з виконанням ними обов'язків члена виборчої комісії, ведеться окружними виборчими комісіями. { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1220 ( 1220-2009-п ) від 18.11.2009 }

2. В абзаці другому пункту 3 Порядку відшкодування шкоди, заподіяної життю, здоров'ю чи майну члена окружної, дільничної виборчої комісії, що здійснює підготовку та проведення виборів народних депутатів України, у зв'язку з виконанням обов'язків члена виборчої комісії, затвердженого постановою Кабінету Міністрів України від 17 травня 2002 р. N 662 ( 662-2002-п ), слова і цифри "від 27 грудня 2001 р. N 1738 ( 1738-2001-п ) "Про умови та порядок оплати праці членів окружних і дільничних виборчих комісій по виборах народних депутатів України" (Офіційний вісник України, 2001 р., N 52, ст. 2355)" замінити словами і цифрами "від 28 липня 2004 р. N 966 ( 966-2004-п ) "Про умови оплати праці членів виборчих комісій" (Офіційний вісник України, 2004 р., N 31, ст. 2063).
