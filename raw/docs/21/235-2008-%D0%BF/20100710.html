Про затвердження складу Комісії з питань діяльності підприємств та організацій громадських організацій інвалідів

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 березня 2008 р. N 235 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 520 ( 520-2010-п ) від 30.06.2010 }

Про затвердження складу Комісії з питань діяльності підприємств та організацій громадських організацій інвалідів

Кабінет Міністрів України постановляє:

1. На часткову зміну пункту 1 постанови Кабінету Міністрів України від 26 грудня 2000 р. N 1888 ( 1888-2000-п ) (Офіційний вісник України, 2000 р., N 52, ст. 2265; 2001 р., N 13, ст. 553; 2007 р., N 86, ст. 3155) затвердити склад Комісії з питань діяльності підприємств та організацій громадських організацій інвалідів, що додається.

2. Визнати таким, що втратив чинність, пункт 1 змін, що вносяться до постанови Кабінету Міністрів України від 26 грудня 2000 р. N 1888, затверджених постановою Кабінету Міністрів України від 8 листопада 2007 р. N 1301 ( 1301-2007-п ) (Офіційний вісник України, 2007 р., N 86, ст. 3155).
