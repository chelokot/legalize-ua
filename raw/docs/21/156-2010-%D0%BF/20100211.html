Стан: Втратив чинність

Текст документа від 11.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 лютого 2010 р. N 156 Київ

Про внесення змін до постанов Кабінету Міністрів України від 27 грудня 2001 р. N 1729 і від 5 березня 2008 р. N 163

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 27 грудня 2001 р. N 1729 ( 1729-2001-п ) "Про забезпечення споживачів природним газом" (Офіційний вісник України, 2001 р., N 52, ст. 2347; 2006 р., N 10, ст. 616, N 50, ст. 3321; 2007 р., N 4, ст. 149, N 81, ст. 3009; 2008 р., N 12, ст. 298; 2009 р., N 72, ст. 2484, N 91, ст. 3071) і від 5 березня 2008 р. N 163 ( 163-2008-п ) "Про реалізацію імпортованого природного газу на території України" (Офіційний вісник України, 2008 р., N 22, ст. 630) зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 11 лютого 2010 р. N 156

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 27 грудня 2001 р. N 1729 ( 1729-2001-п ) і від 5 березня 2008 р. N 163 ( 163-2008-п )

1. Підпункт 5 пункту 2 постанови Кабінету Міністрів України від 27 грудня 2001 р. N 1729 ( 1729-2001-п ) після абзацу шостого доповнити новим абзацом такого змісту:

"суб'єктів господарювання - підприємств - виробників азотних мінеральних добрив, перелік яких затверджено розпорядженням Кабінету Міністрів України від 3 червня 2009 р. N 880 ( 880-2009-р ), отриманих за зовнішньоекономічними контрактами та договорами купівліпродажу.".

У зв'язку з цим абзаци сьомий - десятий вважати відповідно абзацами восьмим - одинадцятим.

2. Абзац другий пункту 1 постанови Кабінету Міністрів України від 5 березня 2008 р. N 163 ( 163-2008-п ) викласти у такій редакції:

"з 1 січня 2010 р. природний газ, який надходить в газотранспортну систему України за зовнішньоекономічними контрактами та договорами купівлі-продажу, укладеними підприємствами - виробниками азотних мінеральних добрив, перелік яких затверджено розпорядженням Кабінету Міністрів України від 3 червня 2009 р. N 880 ( 880-2009-р ), використовується такими підприємствами виключно для задоволення власних потреб в обсягах відповідно до річного балансу надходження та розподілу природного газу, що затверджений Кабінетом Міністрів України;".
