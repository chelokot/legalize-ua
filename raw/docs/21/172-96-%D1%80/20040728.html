Кабінет Міністрів України; Розпорядження від 06.03.1996 № 172-р

Про технічний нагляд за суднами, які мають право плавання під прапором України

Стан: Втратив чинність

Ідентифікатор: 172-96-р

Текст документа від 28.07.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 березня 1996 р. N 172-р Київ

Про технічний нагляд за суднами, які мають право плавання під прапором України

( Із змінами, внесеними згідно з Розпорядженням КМ N 395-р ( 395-97-р ) від 15.07.97 Постановами КМ N 814 ( 814-98-п ) від 08.06.98 N 963 ( 963-2004-п ) від 28.07.2004 )

1. З метою забезпечення безпеки судноплавства доручити здійснення технічного нагляду за суднами, які мають право плавання під прапором України, згідно з вимогами міжнародних договорів України з оформленням відповідних документів від імені Уряду України таким класифікаційним товариствам (за їхньою згодою):

Регістр судноплавства України; ( Абзац другий пункту 1 в редакції Постанови КМ N 814 ( 814-98-п ) від 08.06.98 )

( Абзац третій пункту 1 виключено на підставі Постанови КМ N 814 ( 814-98-п ) від 08.06.98 ) Український Регістр судноплавства;

Американське Бюро судноплавства (American Bureau of Shipping), США;

Бюро Верітас (Bureau Veritas), Франція;

Німецький Ллойд (Germanischer Lloyd), ФРН;

Грецький Регістр судноплавства (Hellenic Register of Shipping), Греція;

Дет Норске Верітас (Det Norske Veritas Classification as), Норвегія;

Морський Регістр судноплавства, Російська Федерація.

Мінтрансу та Укрдержрибгоспу укласти відповідно до їх компетенції двосторонні угоди із зазначеними класифікаційними товариствами за формою, встановленою Міжнародною морською організацією (Резолюція ІМО А.739(18). ( Абзац в редакції Розпорядження КМ N 395-р ( 395-97-р ) від 15.07.97 )

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 963 ( 963-2004-п ) від 28.07.2004 )

2. МЗС у встановленому порядку повідомляти Міжнародну морську організацію (ІМО) про офіційні доручення Уряду України класифікаційним товариствам здійснювати технічний нагляд за суднами, які мають право плавання під прапором України, після укладення відповідних угод згідно з пунктом 1 цього розпорядження.
