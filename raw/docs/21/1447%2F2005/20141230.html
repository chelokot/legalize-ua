{ Указ втратив чинність на підставі Указу Президента N 950/2014 ( 950/2014 ) від 24.12.2014 }

Питання Консультативної ради з питань іноземних інвестицій в Україні

{ Із змінами, внесеними згідно з Указом Президента N 892/2010 ( 892/2010 ) від 01.09.2010 }

1. На часткову зміну статті 4 Указу Президента України від 11 квітня 1997 року N 323 ( 323/97 ) "Про Консультативну раду з питань іноземних інвестицій в Україні" (зі змінами, внесеними Указами від 11 квітня 2005 року N 625 ( 625/2005 ) та від 22 вересня 2005 року N 1326 ( 1326/2005 ):

1) затвердити у складі Консультативної ради з питань іноземних інвестицій в Україні КІНАХА Анатолія Кириловича - Секретаря Ради національної безпеки і оборони України;

2) увести до складу Консультативної ради:

з української сторони ЄХАНУРОВА Юрія Івановича - Прем'єр-міністра України та ЯЦЕНЮКА Арсенія Петровича - Міністра економіки України;

з іноземної сторони ДЕРГУНОВУ Ольгу Костянтинівну - президента компанії "Майкрософт" по Росії та країнах СНД (Російська Федерація), Лео МЕЛАМЕДА - почесного голову та старшого радника з питань політики Чиказької торгової біржі (Сполучені Штати Америки) та Крістофера ЛЯЙТЛЯ - президента Палати економіки Республіки Австрія (Республіка Австрія);

3) вивести зі складу Консультативної ради Терьохіна С.А.

{ Стаття 2 втратила чинність на підставі Указу Президента N 892/2010 ( 892/2010 ) від 01.09.2010 }

Президент України В.ЮЩЕНКО
