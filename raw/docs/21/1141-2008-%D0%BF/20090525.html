КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 грудня 2008 р. N 1141 Київ

Про внесення змін у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 та визнання такою, що втратила чинність, постанови Кабінету Міністрів України від 14 січня 2004 р. N 14

{ Із змінами, внесеними згідно з Постановою КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 14 січня 2004 р. N 14 ( 14-2004-п ) "Деякі питання Інституту проблем національної безпеки" (Офіційний вісник України, 2004 р., N 2, ст. 44).
