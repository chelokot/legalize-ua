Президент України; Указ від 27.11.2003 № 1365/2003

Питання Всеукраїнської політичної консультативної ради

Стан: Втратив чинність

Ідентифікатор: 1365/2003

Текст документа від 06.11.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президент N 1435/2005 ( 1435/2005 ) від 12.10.2005 )

Питання Всеукраїнської політичної консультативної ради

1. На часткову зміну Указу Президента України від 25 грудня 2000 року N 1371 ( 1371/2000 ) (зі змінами, внесеними Указом від 24 липня 2001 року N 547 ( 547/2001 ) призначити КУРАСА Івана Федоровича - народного депутата України - Секретарем Всеукраїнської політичної консультативної ради (за згодою).

Увільнити від виконання обов'язків Секретаря зазначеної Ради Бєлова О.Ф.

2. Секретареві Всеукраїнської політичної консультативної ради подати у місячний строк пропозиції щодо персонального складу та порядку роботи цієї Ради.

Президент України Л.КУЧМА
