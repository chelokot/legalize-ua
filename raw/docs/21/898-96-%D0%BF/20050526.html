КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 серпня 1996 р. N 898 Київ

Про створення Єдиної державної автоматизованої паспортної системи

( Із змінами, внесеними згідно з Постановами КМ N 2159 ( 2159-99-п ) від 27.11.99 N 399 ( 399-2002-п ) від 29.03.2002 N 789 ( 789-2004-п ) від 18.06.2004 N 378 ( 378-2005-п ) від 26.05.2005 )

Кабінет Міністрів України постановляє:

1. Започаткувати роботи, пов'язані із створенням Єдиної державної автоматизованої паспортної системи (далі - Система), яка забезпечуватиме видачу громадянам паспортів, що оформлюватимуться за єдиною технологією, та облік громадян за місцем проживання із застосуванням комп'ютерної мережі на єдиних принципах їх ідентифікації (із використанням особистих (ідентифікаційних) номерів громадян, відцифрованого образу осіб і біометричної ідентифікації) і взаємодії з базами даних інших інформаційних систем (як вітчизняних, так і іноземних).

Виходити з того, що Система входитиме складовою частиною до Державного реєстру фізичних осіб. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 2159 ( 2159-99-п ) від 27.11.99 )

Визначити замовником створення Системи Міністерство внутрішніх справ, а головним виконавцем робіт - відкрите акціонерне товариство "КП ОТІ. ( Абзац третій пункту 1 в редакції Постанови КМ N 2159 ( 2159-99-п ) від 27.11.99, із змінами, внесеними згідно з Постановою КМ N 399 ( 399-2002-п ) від 29.03.2002 )

Загальне керівництво роботою, пов'язаною із створенням Системи, покладається на Міністерство внутрішніх справ. ( Абзац четвертий пункту 1 із змінами, внесеними згідно з Постановами КМ N 399 ( 399-2002-п ) від 29.03.2002, N 789 ( 789-2004-п ) від 18.06.2004; в редакції Постанови КМ N 378 ( 378-2005-п ) від 26.05.2005 )

( Абзац п'ятий пункту 1 виключено на підставі Постанови КМ N 2159 ( 2159-99-п ) від 27.11.99 )

( Абзац шостий пункту 1 виключено на підставі Постанови КМ N 2159 ( 2159-99-п ) від 27.11.99 )

( Пункт 2 виключено на підставі Постанови КМ N 2159 ( 2159-99-п ) від 27.11.99 )

3. Визнати такою, що втратила чинність з 1 серпня 1996 р., постанову Кабінету Міністрів України від 27 січня 1995 р. N 56 ( 56-95-п ) "Про плату за оформлення паспорта громадянина України для виїзду за кордон" (ЗП України, 1995 р., N 4, ст. 91).
