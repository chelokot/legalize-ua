Про внесення змін до ставок ввізного мита на окремі види товарів та до деяких рішень Уряду України

( Додатково див. Постанову КМ N 583 ( 583-96-п ) від 30.05.96 )

( Із змінами, внесеними згідно з Постановами КМ N 1106 ( 1106-96-п ) від 11.09.96 N 1376 ( 1376-96-п ) від 08.11.96 N 1378 ( 1378-96-п ) від 08.11.96 N 1379 ( 1379-96-п ) від 08.11.96 )

Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита на окремі види товарів згідно з додатком.

2. У додатку до постанови Кабінету Міністрів України від 3 травня 1994 р. N 285 ( 285-94-п ) "Про зміни ставок ввізного мита на окремі види товарів" (ЗП України, 1994 р., N 11, ст. 266) види товарів за кодами 32.08 10900 (тільки для позицій 87.02 - 87.05), 57.01 - 57.03 та у додатку до постанови Кабінету Міністрів України від 18 липня 1995 р. N 531 ( 531-95-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів та до деяких рішень Уряду України" вид товару за кодом 84.07 33100 виключити.
