Текст документа від 29.09.2020:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 квітня 2001 р. N 143-р Київ

{ Дію Розпорядження відновлено згідно з Постановою КМ N 886 ( 886-2020-п ) від 23.09.2020}

{ Розпорядження втратило чинність на підставі Постанови КМ N 820 ( 820-2008-п ) від 10.09.2008 }

Про передачу Житомирського лікеро-горілчаного заводу та Чуднівського спиртового заводу в управління Державного управління справами

На часткову зміну додатка 2 до постанови Кабінету Міністрів України від 29 червня 1996 р. N 701 ( 701-96-п ) "Про вдосконалення управління підприємствами спиртової та лікеро-горілчаної промисловості" (в редакції постанови Кабінету Міністрів України від 5 травня 1997 р. N 413) ( 413-97-п ) вивести із складу Державного концерну спиртової та лікеро-горілчаної промисловості і передати в управління Державного управління справами Житомирський лікеро-горілчаний завод та Чуднівський спиртовий завод.

Мінекономіки установити контроль за ефективністю управління зазначеними лікеро-горілчаним та спиртовим заводами.

Перший віце-прем'єр-міністр України Ю.ЄХАНУРОВ
