Про реалізацію Угоди між Урядом України та Урядом Російської Федерації про вільну торгівлю

Стан: Втратив чинність

Ідентифікатор: 13-98-п

Текст документа від 27.06.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 січня 1998 р. N 13 Київ

Про реалізацію Угоди між Урядом України та Урядом Російської Федерації про вільну торгівлю

( Із змінами, внесеними згідно з Постановами КМ N 2201 ( 2201-99-п ) від 03.12.99 N 1485 ( 1485-2000-п ) від 28.09.2000 N 745 ( 745-2001-п ) від 27.06.2001 )

Відповідно до досягнутих з Урядом Російської Федерації домовленостей щодо забезпечення належного виконання Угоди між Урядом України та Урядом Російської Федерації про вільну торгівлю, укладеної 24 червня 1993 р., ( 643_009 ) що набрала чинності 21 лютого 1994 р., Кабінет Міністрів України постановляє:

1. Державній митній службі на виконання статті 1 Угоди між Урядом України та Урядом Російської Федерації про вільну торгівлю забезпечити митне оформлення нафти сирої (код УКТЗЕД 2709 00), газового конденсату природного (код УКТЗЕД 2709 00 10 00) та газу природного в газоподібному стані (код УКТЗЕД 2711 21 00 00) походженням з митної території Російської Федерації і призначених для митної території України у разі їх ввезення на цю територію без справляння з 1 липня 2001 р. податку на додану вартість. ( Пункт 1 із змінами, внесеними згідно з Постановами КМ N 2201 ( 2201-99-п ) від 03.12.99, N 1485 ( 1485-2000-п ) від 28.09.2000, N 745 ( 745-2001-п ) від 27.06.2001 )

2. Міністерству закордонних справ поінформувати в установленому порядку Російську Федерацію про прийняття цієї постанови.

3. Контроль за виконанням цієї постанови покласти на Віце-прем'єр-міністра України Тігіпка С.Л.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
