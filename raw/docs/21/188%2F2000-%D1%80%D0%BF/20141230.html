Про робочі органи Консультативної ради з питань іноземних інвестицій в Україні

( Із змінами, внесеними згідно з Розпорядженнями Президента N 333/2000-рп ( 333/2000-рп ) від 30.10.2000 N 334/2000-рп ( 334/2000-рп ) від 30.10.2000 N 108/2001-рп ( 108/2001-рп ) від 17.04.2001 N 155/2001-рп ( 155/2001-рп ) від 14.06.2001 )

З метою оптимізації діяльності Консультативної ради з питань іноземних інвестицій в Україні, забезпечення системного підходу в її роботі та дієвого виконання прийнятих рішень:

1. Призначити співголовами утворених згідно з рішенням Консультативної ради з питань іноземних інвестицій в Україні:

робочої групи з питань фінансової політики - МІТЮКОВА Ігоря Олександровича - Міністра фінансів України, АЗАРОВА Миколу Яновича - Голову Державної податкової адміністрації України;

робочої групи з питань промислової політики та енергетики - СТАШЕВСЬКОГО Станіслава Телісфоровича - Міністра палива та енергетики України - керівником підгрупи з питань енергетики, ГУРЕЄВА Василя Миколайовича - Міністра промислової політики України - керівником підгрупи з питань промислової політики;

робочої групи з питань зв'язку - ШЕВЧУКА Олега Борисовича - Голову Державного комітету зв'язку та інформатизації України;

робочої групи з питань нафтогазової промисловості - ТУЛУБА Сергія Борисовича - заступника Секретаря Ради національної безпеки і оборони України;

робочої групи з питань власності та усунення адміністративних перешкод, утвореної згідно з рішенням зазначеної Консультативної ради шляхом об'єднання робочої групи з питань формування інвестиційного іміджу та робочої групи з питань реформування відносин власності та усунення адміністративних перешкод, - ШЛАПАКА Олександра Віталійовича - заступника Міністра економіки України.

2. Секретарю Консультативної ради разом із співголовами робочих груп розробити Регламент Консультативної ради з питань іноземних інвестицій в Україні та внести його для затвердження на четвертому пленарному засіданні 14 червня 2000 року.

( Розпорядження із змінами, внесеними згідно з Розпорядженнями Президента N 333/2000-рп ( 333/2000-рп ) від 30.10.2000, N 334/2000-рп ( 334/2000-рп ) від 30.10.2000, N 108/2001-рп ( 108/2001-рп ) від 17.04.2001, N 155/2001-рп ( 155/2001-рп ) від 14.06.2001 )
