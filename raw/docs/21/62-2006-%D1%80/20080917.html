{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1242-р ( 1242-2008-р ) від 17.09.2008 }

Про заходи щодо забезпечення ефективного залучення та використання коштів міжнародних фінансових організацій

1. Затвердити план заходів щодо підвищення ефективності залучення та використання коштів міжнародних фінансових організацій (додається).

2. Мінекономіки проводити моніторинг виконання затвердженого цим розпорядженням плану заходів та щокварталу інформувати Кабінет Міністрів України про результати роботи із залучення та використання коштів міжнародних фінансових організацій.

3. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 1 липня 2002 р. N 358 ( 358-2002-р ) "Про заходи щодо підвищення ефективності залучення та використання коштів міжнародних фінансових організацій" (Офіційний вісник України, 2002 р., N 27, ст. 1284);

розпорядження Кабінету Міністрів України від 6 серпня 2003 р. N 497 ( 497-2003-р ) "Про встановлення нових термінів виконання деяких заходів щодо підвищення ефективності залучення та використання коштів міжнародних фінансових організацій" (Офіційний вісник України, 2003 р., N 32, ст. 1721).
