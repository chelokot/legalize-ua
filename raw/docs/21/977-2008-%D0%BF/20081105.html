Текст документа від 05.11.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 листопада 2008 р. N 977 Київ

Про доповнення додатка до постанови Кабінету Міністрів України від 25 грудня 1996 р. N 1548

Кабінет Міністрів України постановляє:

Доповнити додаток до постанови Кабінету Міністрів України від 25 грудня 1996 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" (ЗП України, 1996 р., N 21, ст. 596; Офіційний вісник України, 1997 р., число 14, с. 52; 2000 р., N 28, ст. 1167; 2001 р., N 47, ст. 2073; 2002 р., N 8, ст. 344, N 11, ст. 511, N 13, ст. 658, N 30, ст. 1427, N 52, ст. 2396; 2003 р., N 29, ст. 1464; 2004 р., N 24, ст. 1584, N 42, ст. 2757, N 52, ст. 3452; 2005 р., N 17, ст. 903, N 33, ст. 1989; 2006 р., N 20, ст. 1463, ст. 1472, N 50, ст. 3321, ст. 3324; 2007 р., N 46, ст. 1882, N 48, ст. 1974, N 73, ст. 2718, N 88, ст. 3221; 2008 р. N 25, ст. 795, N 29, ст. 926) пунктом 24 такого змісту:

"24. Держкомветмедицини встановлює за погодженням з Мінекономіки, Мінфіном та Мінагрополітики тарифи на платні послуги, що надаються державними установами ветеринарної медицини, крім тарифів на проведення обстежень (експертиз), які є підставою для видачі документів дозвільного характеру, що затверджуються Кабінетом Міністрів України.".
