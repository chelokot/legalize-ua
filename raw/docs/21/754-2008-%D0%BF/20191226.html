КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 серпня 2008 р. N 754 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1085 ( 1085-2019-п ) від 04.12.2019 }

Про доповнення постанови Кабінету Міністрів України від 29 грудня 2007 р. N 1411

Кабінет Міністрів України постановляє:

1. Доповнити постанову Кабінету Міністрів України від 29 грудня 2007 р. N 1411 ( 1411-2007-п ) "Про затвердження переліків товарів, експорт та імпорт яких підлягає ліцензуванню, та обсягів квот у 2008 році" (Офіційний вісник України, 2008 р., N 1, ст. 11) пунктом 2-1 такого змісту:

"2-1. Установити, що відповідно до частини тридцятої статті 16 Закону України "Про зовнішньоекономічну діяльність" ( 959-12 ) для митного оформлення товарів, які навантажуються навалом та операції з експорту (імпорту) яких підлягають ліцензуванню, гранична різниця фактичного значення їх вартості, кількості або ваги не може перевищувати 5 відсотків значення, зафіксованого у відповідній ліцензії.".

2. Ця постанова набирає чинності з дня опублікування.
