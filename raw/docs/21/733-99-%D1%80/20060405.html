Кабінет Міністрів України; Розпорядження від 26.07.1999 № 733-р

Про віднесення посад працівників Комітету із Державних премій України імені Тараса Шевченка до категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 733-99-р

Текст документа від 05.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 липня 1999 р. N 733-р Київ

{ Із змінами, внесеними згідно з Розпорядженням КМ N 187-р ( 187-2006-р ) від 05.04.2006 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Комітету з Національної премії України імені Тараса Шевченка до таких категорій посад державних службовців: { Абзац перший із змінами, внесеними згідно з Розпорядженням КМ N 187-р ( 187-2006-р ) від 05.04.2006 }

друга категорія - посада голови Комітету, заступника голови - керівника Секретаріату; { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 187-р ( 187-2006-р ) від 05.04.2006 }

четверта категорія - завідувач сектору; { Абзац третій в редакції Розпорядження КМ N 187-р ( 187-2006-р ) від 05.04.2006 }

п'ята категорія - посади спеціалістів.
