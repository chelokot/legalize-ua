Стан: Чинний

Ідентифікатор: 156/2009

Текст документа від 16.03.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про делегацію України для участі у переговорах з Європейською Комісією, Міжнародним банком реконструкції та розвитку, Європейським банком реконструкції та розвитку, Європейським інвестиційним банком з підготовки проекту заключного документа Міжнародної інвестиційної конференції з питань модернізації газотранзитної системи України

Відповідно до пункту 3 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Утворити делегацію України для участі у переговорах з Європейською Комісією, Міжнародним банком реконструкції та розвитку, Європейським банком реконструкції та розвитку, Європейським інвестиційним банком з підготовки проекту заключного документа Міжнародної інвестиційної конференції з питань модернізації газотранзитної системи України (16-18 березня 2009 року, м. Брюссель, Королівство Бельгія) у такому складі:

ЄЛІСЄЄВ - заступник Міністра закордонних справ Костянтин Петрович України, глава делегації

ВЕСЕЛОВСЬКИЙ - Представник України при Європейських Андрій Іванович Співтовариствах (Європейському Союзі)

ДІДЕНКО - перший заступник голови правління

Ігор Миколайович Національної акціонерної компанії "Нафтогаз України"

КНЯЖНИЦЬКИЙ - радник Представництва України при

В'ячеслав Леонідович Європейських Співтовариствах

ПАВЛУША - заступник Міністра палива та

Сергій Миколайович енергетики України

СОКОЛОВСЬКИЙ - Уповноважений Президента України з

Богдан Іванович міжнародних питань енергетичної безпеки.

2. Затвердити Директиви делегації України для участі у переговорах з Європейською Комісією, Міжнародним банком реконструкції та розвитку, Європейським банком реконструкції та розвитку, Європейським інвестиційним банком з підготовки проекту заключного документа Міжнародної інвестиційної конференції з питань модернізації газотранзитної системи України (додаються, таємно).

3. Кабінету Міністрів України вирішити питання щодо виділення коштів для забезпечення роботи делегації.

Президент України В.ЮЩЕНКО

м. Київ, 16 березня 2009 року N 156/2009
