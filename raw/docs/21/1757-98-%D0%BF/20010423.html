Текст документа від 23.04.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 листопада 1998 р. N 1757 Київ

Про затвердження складу президії Вищої атестаційної комісії України

( Із змінами, внесеними згідно з Постановами КМ N 240 ( 240-99-п ) від 22.02.99 N 444 ( 444-2000-п ) від 02.03.2000 N 1548 ( 1548-2000-п ) від 12.10.2000 N 378 ( 378-2001-п ) від 23.04.2001 )

Кабінет Міністрів України постановляє:

1. Затвердити склад президії Вищої атестаційної комісії України згідно з додатком 1.

2. Не для друку.

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 17 жовтня 1996 р. N 1270 ( 1270-96-п ) "Про затвердження складу головної ради та президії Вищої атестаційної комісії України" (ЗП України, 1996 р., N 19, ст. 533), за винятком пункту 1 у частині затвердження складу головної ради Вищої атестаційної комісії.
