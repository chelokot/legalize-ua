Кабінет Міністрів України; Постанова від 31.08.2005 № 845

Питання кваліфікаційної атестації та стимулювання працівників Державної інспекції ядерного регулювання, які безпосередньо виконують функції з державного регулювання ядерної та радіаційної безпеки

Стан: Чинний

Ідентифікатор: 845-2005-п

Текст документа від 04.12.2018:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 серпня 2005 р. N 845 Київ

Питання кваліфікаційної атестації та стимулювання працівників Державної інспекції ядерного регулювання, які безпосередньо виконують функції з державного регулювання ядерної та радіаційної безпеки

{ Із змінами, внесеними згідно з Постановами КМ N 591 ( 591-2008-п ) від 02.07.2008 N 969 ( 969-2011-п ) від 14.09.2011 N 995 ( 995-2018-п ) від 28.11.2018 }

{ У назві і тексті Постанови слова "Державний комітет ядерного регулювання" та "Міністерство праці та соціальної політики" в усіх відмінках замінено відповідно словами "Державна інспекція ядерного регулювання" та "Міністерство соціальної політики" у відповідному відмінку згідно з Постановою КМ N 969 ( 969-2011-п ) від 14.09.2011 }

Відповідно до статті 23 Закону України "Про використання ядерної енергії та радіаційну безпеку" ( 39/95-ВР ) Кабінет Міністрів України постановляє:

1. Установити, що кваліфікаційна атестація працівників Державної інспекції ядерного регулювання та її територіальних органів (державних інспекцій з ядерної та радіаційної безпеки), які безпосередньо виконують функції з державного регулювання ядерної та радіаційної безпеки, проводиться відповідно до Положення про проведення атестації державних службовців, затвердженого постановою Кабінету Міністрів України від 28 грудня 2000 р. N 1922 ( 1922-2000-п ), з урахуванням особливостей, що визначаються Державною інспекцією ядерного регулювання за погодженням з Головним управлінням державної служби та Міністерством соціальної політики.

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 591 ( 591-2008-п ) від 02.07.2008, N 969 ( 969-2011-п ) від 14.09.2011 }

2. Державній інспекції ядерного регулювання затвердити за погодженням з Міністерством соціальної політики та Міністерством фінансів перелік посадових осіб, які безпосередньо виконують функції з державного регулювання ядерної та радіаційної безпеки та підлягають кваліфікаційній атестації.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 995 ( 995-2018-п ) від 28.11.2018 }
