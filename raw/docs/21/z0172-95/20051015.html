Мінтранс України; Наказ, Тариф від 08.06.1995 № 220

Про затвердження Тарифів на перевезення іноземних громадян залізничним транспортом у внутрішньодержавному сполученні

Реєстрація: Мін'юст України від 09.06.1995 № 172/708

Стан: Втратив чинність

Ідентифікатор: z0172-95

Текст документа від 15.10.2005:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

N 220 від 08.06.95 Зареєстровано в Міністерстві м.Київ юстиції України 9 червня 1995 р. vd950608 vn220 за N 172/708

( Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 559 ( z1133-05 ) від 16.09.2005 )

Про затвердження Тарифів на перевезення іноземних громадян залізничним транспортом у внутрішньодержавному сполученні

( Із змінами, внесеними згідно з Наказами Міністерства транспорту N 394 ( z0402-95 ) від 31.10.95 N 182 ( z0351-98 ) від 11.05.98 )

Згідно з Постановою Кабінету Міністрів України N 109 ( 109-95-п ) від 13 лютого 1995 р. "Про уточнення повноважень центральних органів державної виконавчої влади Уряду Автономної Республіки Крим та виконкомів місцевих Рад у галузі ціноутворення", НАКАЗУЮ:

1. Затвердити Тарифи на перевезення іноземних громадян залізничним транспортом у внутрішньодержавному сполученні, що додаються.

2. Встановити, що зазначені Тарифи вводяться в дію з 20 червня 1995 року.

3. Укрзалізниці (Макаренко М.В.) та керівникам залізниць України забезпечити своєчасне введення в дію Тарифів та правильність їх застосування і проінформувати про це населення в засобах масової інформації та на вокзалах.

4. Управлінню економічної політики та прогнозування (Бурдей В.В.) разом з управлінням нормативних актів та правової роботи (Наапетян М.Р.) в установленому порядку зареєструвати зазначені Тарифи в Міністерстві юстиції України.

5. Контроль за виконанням цього наказу залишаю за собою.

Перший заступник Міністра транспорту України - Генеральний директор Укрзалізниці Л.Л.Железняк

( Тарифи на перевезення іноземних громадян залізничним транспортом у внутрішньодержавному сполученні втратили чинність на підставі Наказу Міністерства транспорту N 182 ( z0351-98 ) від 11.05.98 )
