НАКАЗ

N 440 від 25.07.2001 Зареєстровано в Міністерстві юстиції України 9 серпня 2001 р. за N 686/5877

Про запровадження імміграційної картки іноземця

( Із змінами, внесеними згідно з Наказами Держкомкордону N 623 ( z0927-01 ) від 16.10.2001 N 248 ( z0429-02 ) від 19.04.2002 Наказом Адміністрації Державної прикордонної служби N 297/793 ( z1133-03 ) від 24.11.2003 )

( У тексті наказу та Форми реєтраційної картки іноземця слова "реєстраційна картка" в усіх відмінках та числах змінено на слова "імміграційна картка" у відповідних відмінках та числах згідно з Наказом Держкомкордону N 623 ( z0927-01 ) від 16.10.2001 )

На виконання пункту 1 Указу Президента України від 15 червня 2001 року N 435 ( 435/2001 ) "Про додаткові заходи щодо реалізації права людини на свободу пересування і вільний вибір місця проживання" та відповідно до Закону України "Про правовий статус іноземців" ( 3929-12 ) НАКАЗУЮ:

1. Затвердити форму імміграційної картки іноземця (додається).

2. Затвердити порядок заповнення імміграційної картки іноземця ( z0687-01 ) (додається).

3. Начальнику управління прикордонного контролю, командувачам військ напрямів, командирам з'єднань та частин провести роботу щодо запровадження під час реєстрації іноземців та їх паспортних документів у пунктах пропуску через державний кордон оформлення імміграційної картки іноземця.

4. Копію наказу надіслати до Міністерства закордонних справ, Міністерства внутрішніх справ, Міністерства праці та соціальної політики, Міністерства освіти та науки, Міністерства транспорту, Міністерства юстиції, Служби безпеки, Державного комітету молодіжної політики, спорту і туризму України.

5. Прес-центру Держкомкордону підготувати та надіслати інформацію до засобів масової інформації про запровадження імміграційної картки іноземця та порядок її заповнення.

6. Контроль за виконанням цього наказу покласти на першого заступника Голови Держкомкордону України - Командувача Прикордонних військ України - начальника Головного штабу Прикордонних військ України.

Подається разом з паспортом посадовій особі органів охорони державного кордону під час перетинання державного кордону та зберігається протягом усього часу перебування в Україні.

Предоставляется вместе с паспортом должностному лицу органов охраны государственной границы и сохраняется в течение всего времени пребывания в Украине.

This card must be presented together with the passport to Ukrainian border authorities when crossing the State border of and is kept for the whole period of stay in Ukraine.

Зворотний бік імміграційної картки іноземця

1. У частині "Прибуття" правила заповнення граф імміграційної картки наводяться українською, англійською та російською мовами.

2. У частині "Вибуття" розміщується інформація для іноземця.
