Про доповнення пункту 4 постанови Кабінету Міністрів України від 31 травня 2000 р. N 865

Стан: Втратив чинність

Ідентифікатор: 688-2004-п

Текст документа від 23.09.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 травня 2004 р. N 688 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 622 ( 622-2016-п ) від 14.09.2016 }

Про доповнення пункту 4 постанови Кабінету Міністрів України від 31 травня 2000 р. N 865

{ Додатково див. Постанову КМ N 426 ( 426-2013-п ) від 19.06.2013 }

Кабінет Міністрів України постановляє:

1. Доповнити підпункт 2 пункту 4 постанови Кабінету Міністрів України від 31 травня 2000 р. N 865 ( 865-2000-п ) "Про деякі питання вдосконалення визначення розмірів заробітку для обчислення пенсії" (Офіційний вісник України, 2000 р., N 22, ст. 906; 2003 р., N 17, ст. 773, N 52, ст. 2785) абзацом такого змісту:

"За бажанням осіб, під час перерахунку пенсій виплати, отримані на час призначення (перерахунку) пенсії (крім посадових окладів, надбавок за ранг, вислугу років), визначаються у порядку, передбаченому абзацом першим пункту 1 цієї постанови, та коригуються відповідно до пункту 2 цієї постанови".

2. Дія цієї постанови поширюється на пенсіонерів, право на перерахунок пенсії у яких виникло з дня набрання чинності Законом України від 16 січня 2003 р. N 432-IV ( 432-15 ) "Про внесення змін до Закону України "Про державну службу".
