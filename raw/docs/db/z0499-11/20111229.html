{ Із змінами, внесеними згідно з Наказами Міністерства екології та природних ресурсів N 372 ( z1223-11 ) від 07.10.2011 N 468 ( z1451-11 ) від 23.11.2011 }

Відповідно до статті 13 Закону України "Про тваринний світ" ( 2894-14 ), статті 16 Закону України "Про мисливське господарство та полювання" ( 1478-14 ) та статті 9-1 Закону України "Про природно-заповідний фонд України" ( 2456-12 ), з метою раціонального використання державного мисливського фонду НАКАЗУЮ:

1. Затвердити ліміти добування (відстрілу, відлову) диких парнокопитих та хутрових звірів, віднесених до державного мисливського фонду, у сезон полювання 2011/2012 років, що додаються.

2. Встановити норми відстрілу інших мисливських тварин, віднесених до державного мисливського фонду, одним мисливцем за день полювання у сезон полювання 2011/2012 років згідно з додатком.

3. Департаменту біорізноманіття, охорони землі та екомережі (Мовчан М.М.):

3.1. У встановленому порядку подати наказ на державну реєстрацію до Міністерства юстиції України.

3.2. У десятиденний термін після реєстрації в Міністерстві юстиції України довести його для керівництва в роботі та здійснення контролю.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Вільдмана І.Л.

5. Цей наказ набирає чинності з дня його офіційного опублікування.
