Президент України; Указ від 02.06.2001 № 398/2001

Про внесення змін до Тимчасового положення про Координаційний комітет по боротьбі з корупцією і організованою злочинністю

Стан: Втратив чинність

Ідентифікатор: 398/2001

Текст документа від 13.05.2003:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 402/2003 ( 402/2003 ) від 13.05.2003 )

Про внесення змін до Тимчасового положення про Координаційний комітет по боротьбі з корупцією і організованою злочинністю

З метою дальшого вдосконалення діяльності Координаційного комітету по боротьбі з корупцією і організованою злочинністю постановляю:

Внести до пункту 4 Тимчасового положення про Координаційний комітет по боротьбі з корупцією і організованою злочинністю при Президентові України, затвердженого Указом Президента України від 31 грудня 1999 року N 1659 ( 1659/99 ) (із змінами, внесеними Указом від 1 серпня 2000 року N 943 ( 943/2000 ), такі зміни:

підпункт 1 доповнити абзацом другим такого змісту:

"накопичує та аналізує інформацію з питань організованої злочинності";

підпункт 2 доповнити словами "вживає заходів до недопущення паралелізму в роботі цих органів";

підпункт 3 доповнити абзацом другим такого змісту:

"надає допомогу спецслужбам у виявленні та припиненні діяльності організованих злочинних угруповань".

Президент України Л.КУЧМА

м. Київ, 2 червня 2001 року N 398/2001
