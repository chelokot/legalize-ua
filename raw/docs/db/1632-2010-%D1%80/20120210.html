{ Із змінами, внесеними згідно з Постановою КМ N 48 ( 48-2012-п ) від 01.02.2012 }

1. Скасувати обмеження доступу до актів Ради Міністрів Української РСР, Кабінету Міністрів Української РСР, Кабінету Міністрів України та зняти з них позначки "Не для друку" і "Не для преси" згідно з додатками 1 і 2.

2. Зняти позначки "Не для друку" і "Опублікуванню не підлягає" з актів Кабінету Міністрів України та надати таким актам гриф обмеження доступу "Для службового користування" згідно з додатком 3.
