Стан: Чинний

Текст документа від 18.11.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Секретаріату Президента України

З метою вдосконалення діяльності Секретаріату Президента України, відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Увести в Секретаріаті Президента України посади Радників Президента України.

2. Внести до Указів Президента України такі зміни:

1) в Указі Президента України від 14 жовтня 2005 року N 1445 ( 1445/2005 ) "Про створення Секретаріату Президента України" (зі змінами, внесеними Указом від 10 липня 2009 року N 534) ( 534/2009 ):

а) доповнити статтю 4 після абзацу "Уповноважений Президента України з питань безпеки заходів з проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" новим абзацом такого змісту:

"три радники Президента України";

б) викласти Схему розподілу обов'язків між Главою Секретаріату Президента України, його першими заступниками та заступниками, закріплення за ними структурних підрозділів, затверджену зазначеним Указом ( 1445/2005 ), у новій редакції, що додається ( 934а/2009 );

2) у Положенні про Секретаріат Президента України, затвердженому Указом Президента України від 4 листопада 2005 року N 1548 ( 1548/2005 ) (зі змінами, внесеними Указами Президента України від 18 листопада 2005 року N 1614 ( 1614/2005 ), від 2 жовтня 2006 року N 814 ( 814/2006 ), від 5 квітня 2007 року N 276 ( 276/2007 ), від 6 червня 2007 року N 507 ( 507/2007 ), від 9 листопада 2007 року N 1079 ( 1079/2007 ), від 24 грудня 2007 року N 1244 ( 1244/2007 ), від 23 січня 2008 року N 46 ( 46/2008 ), від 4 листопада 2008 року N 997 ( 997/2008 ) та від 10 липня 2009 року N 534) ( 534/2009 ):

а) доповнити пункт 7 після абзацу "Уповноважений Президента України з питань безпеки заходів з проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" новим абзацом такого змісту:

"три радники Президента України";

б) доповнити абзац перший пункту 8 після слів "Уповноважений Президента України з питань безпеки заходів з проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" словами "радники Президента України";

в) доповнити підпункт 4 пункту 9 після слів "Уповноваженого Президента України з питань безпеки заходів з проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" словами "радників Президента України";

г) доповнити Положення ( 1548/2005 ) пунктом 11-1 такого змісту:

"11-1. Функції Радника Президента України визначаються Положенням про Радника Президента України";

д) пункт 14 після слів "передбачених у Державному бюджеті України" доповнити словами "Положення про Радника Президента України".

3. Главі Секретаріату Президента України у тижневий строк:

подати проект Положення про Радника Президента України;

внести пропозиції щодо призначення на посади радників Президента України;

привести штатний розпис Секретаріату Президента України у відповідність із цим Указом.

4. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 18 листопада 2009 року N 934/2009

ЗАТВЕРДЖЕНО Указом Президента України від 14 жовтня 2005 року N 1445 ( 1445/2005 ) (в редакції Указу від 18 листопада 2009 року N 934/2009)
