Про затвердження Порядку покриття Державним казначейством України планових обсягів тимчасових касових розривів місцевих бюджетів

( Із змінами, внесеними згідно з Наказом Державного казначейства N 114 ( z0420-03 ) від 22.05.2003 )

На виконання статті 49 Закону України "Про Державний бюджет України на 2003 рік" ( 380-15 ) НАКАЗУЮ:

1. Затвердити Порядок покриття Державним казначейством України планових обсягів тимчасових касових розривів місцевих бюджетів, що додається.

2. Управлінню фінансових ресурсів Державного казначейства України подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3. Управлінню організації діловодства та контролю виконавської дисципліни Державного казначейства України Порядок покриття Державним казначейством України планових обсягів тимчасових касових розривів місцевих бюджетів довести до відома органів Державного казначейства України.

4. Наказ набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України і діє протягом 2003 року.

5. Контроль за виконанням цього наказу залишаю за собою.

Голова П.Г.Петрашко

ПОРЯДОК покриття Державним казначейством України планових обсягів тимчасових касових розривів місцевих бюджетів

1. Цей Порядок розроблено на виконання статті 49 Закону України "Про Державний бюджет України на 2003 рік" ( 380-15 ).

2. Порядок визначає механізм покриття Державним казначейством України планових обсягів тимчасових касових розривів, що виникають під час виконання загального фонду місцевих бюджетів, пов'язаних із забезпеченням видатків на оплату праці працівників бюджетних установ та нарахування на заробітну плату, придбання продуктів харчування та медикаментів, шляхом надання органами Державного казначейства короткотермінових позичок місцевим бюджетам за рахунок коштів єдиного казначейського рахунку (далі - короткотермінові позички) на договірних умовах без нарахування відсотків за користування цими позичками.

3. Тимчасовий касовий розрив - різниця між доходами і видатками помісячного розпису асигнувань загального фонду місцевого бюджету, що виникає у процесі його виконання, пов'язана з необхідністю здійснювати платежі впродовж поточного бюджетного періоду відповідно до бюджетних зобов'язань.

4. Надання короткотермінових позичок органами Державного казначейства провадиться без нарахування відсотків за користування цими позичками та за умови:

4.1. Наявності рішення Верховної Ради Автономної Республіки Крим чи відповідної ради щодо отримання короткотермінових позичок.

4.2. Отримання позичок на термін до трьох місяців у межах планового бюджетного періоду. ( Пункт 4.2 із змінами, внесеними згідно з Наказом Державного казначейства N 114 ( z0420-03 ) від 22.05.2003 )

4.3. Величина основної суми боргу місцевого бюджету не може перевищувати 15 відсотків дохідної частини загального фонду місцевого бюджету у плановому бюджетному періоді за вирахуванням субвенцій з інших бюджетів. ( Пункт 4.3 із змінами, внесеними згідно з Наказом Державного казначейства N 114 ( z0420-03 ) від 22.05.2003 )

5. Короткотермінові позички, отримані в органах Державного казначейства, підлягають погашенню до 30 листопада поточного бюджетного періоду.

6. Голова Державного казначейства України щомісячно затверджує на наступний місяць ліміт Автономній Республіці Крим, областям, містам Києву та Севастополю для надання за рахунок коштів єдиного казначейського рахунку короткотермінових позичок місцевим бюджетам, які входять до їх складу.

7. Договір про надання короткотермінової позички укладається між управлінням Державного казначейства в Автономній Республіці Крим, областях, містах Києві і Севастополі та Радою міністрів Автономної Республіки Крим, місцевою державною адміністрацією, виконавчим органом відповідних рад. ( Абзац перший пункту 7 в редакції Наказу Державного казначейства N 114 ( z0420-03 ) від 22.05.2003 )

Договір підписується уповноваженою на це в установленому порядку особою.

8. У договорі обов'язково зазначається механізм погашення короткотермінової позички.

9. Для укладання договору про отримання короткотермінової позички необхідно подати:

9.1. Заяву про отримання короткотермінової позички за формою згідно з додатком 1 до цього Порядку за умови дотримання заявником вимог пункту 4 цього Порядку. ( Пункту 9.1 в редакції Наказу Державного казначейства N 114 ( z0420-03 ) від 22.05.2003 )

9.2. Прогноз надходжень доходів загального фонду (без урахування субвенцій з інших бюджетів) місцевого бюджету на період, на який планується отримання короткотермінової позички (додаток 2). ( Пункт 9.2 із змінами, внесеними згідно з Наказом Державного казначейства N 114 ( z0420-03 ) від 22.05.2003 )

10. Для аналізу кредитоспроможності заявника органи Державного казначейства України можуть вимагати від заявника додаткову інформацію.

11. Рішення про надання короткотермінової позички або відмову в наданні такої позички приймається управлінням Державного казначейства в Автономній Республіці Крим, областях, містах Києві та Севастополі протягом двох робочих днів з часу отримання повного пакета документів. ( Абзац перший пункту 11 в редакції Наказу Державного казначейства N 114 ( z0420-03 ) від 22.05.2003 )

Про прийняте рішення заявник інформується письмово.
