Кабінет Міністрів України; Постанова від 16.10.2008 № 924

Про внесення змін до деяких постанов Кабінету Міністрів України з питань Національної комісії з питань Червоної книги України

Стан: Втратив чинність

Ідентифікатор: 924-2008-п

Текст документа від 20.06.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 жовтня 2008 р. N 924 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 414 ( 414-2013-п ) від 12.06.2013 }

Про внесення змін до деяких постанов Кабінету Міністрів України з питань Національної комісії з питань Червоної книги України

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України з питань Національної комісії з питань Червоної книги України зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 16 жовтня 2008 р. N 924

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України з питань Національної комісії з питань Червоної книги України

1. Пункт 4 Положення про Національну комісію з питань Червоної книги України, затвердженого постановою Кабінету Міністрів України від 8 вересня 2004 р. N 1176 ( 1176-2004-п ) "Про Національну комісію з питань Червоної книги України" (Офіційний вісник України, 2004 р., N 36, ст. 2399; 2006 р., N 7, ст. 360; 2007 р., N 73, ст. 2722), викласти у такій редакції:

"4. Роботою Комісії керує її голова. Персональний склад Комісії затверджується Кабінетом Міністрів України.".

2. Підпункт 16 пункту 1 постанови Кабінету Міністрів України від 15 лютого 2006 р. N 147 ( 147-2006-п ) "Про керівників деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України" (Офіційний вісник України, 2006 р., N 7, ст. 360) виключити.

3. Внести до складу Національної комісії з питань Червоної книги України, затвердженого постановою Кабінету Міністрів України від 26 вересня 2007 р. N 1165 ( 1165-2007-п ) "Деякі питання Національної комісії з питань Червоної книги України" (Офіційний вісник України, 2007 р., N 73, ст. 2722), такі зміни:

затвердити Мовчана Миколу Михайловича - заступника Міністра охорони навколишнього природного середовища головою Комісії;

ввести до складу Комісії Губаря Сергія Івановича - заступника директора департаменту Мінприроди як першого заступника голови Комісії, Попович Оксану Петрівну - головного спеціаліста Мінприроди як відповідального секретаря Комісії та Радченка Володимира Григоровича - директора Наукового центру екомоніторингу та біорізноманіття мегаполісу Національної академії наук, вивівши з її складу Большакова Павла Яковича, Грановську Тетяну Миколаївну і Таращука Сергія Володимировича.
