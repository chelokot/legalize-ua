{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про затвердження головою Державної комісії з питань зв'язку і радіочастот Дурдинця В.В.

Кабінет Міністрів України постановляє:

Затвердити головою Державної комісії з питань зв'язку і радіочастот Першого віце-прем'єр-міністра України Дурдинця Василя Васильовича, звільнивши від цих обов'язків Лазаренка Павла Івановича.
