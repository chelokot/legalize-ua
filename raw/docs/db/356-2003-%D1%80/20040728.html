( Розпорядження втратило чинність на підставі Розпорядження КМ N 531-р ( 531-2004-р ) від 28.07.2004 )

Про затвердження складу Урядової комісії з реструктуризації ДАК "Хліб України"

На часткову зміну пункту 1 розпорядження Кабінету Міністрів України від 25 жовтня 2002 р. N 604 ( 604-2002-р ) "Про реструктуризацію ДАК "Хліб України" (Офіційний вісник України, 2002 р., N 44, ст. 2039) затвердити склад Урядової комісії з реструктуризації ДАК "Хліб України" згідно з додатком.
