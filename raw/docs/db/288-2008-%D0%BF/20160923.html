КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 квітня 2008 р. N 288 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 622 ( 622-2016-п ) від 14.09.2016 }

Про доповнення пункту 5 постанови Кабінету Міністрів України від 31 травня 2000 р. N 865

{ Додатково див. Постанову КМ N 426 ( 426-2013-п ) від 19.06.2013 }

Відповідно до статті 37-1 Закону України "Про державну службу" ( 3723-12 ) Кабінет Міністрів України постановляє:

1. Доповнити абзац перший пункту 5 постанови Кабінету Міністрів України від 31 травня 2000 р. N 865 ( 865-2000-п ) "Про деякі питання вдосконалення визначення розмірів заробітку для обчислення пенсії" (Офіційний вісник України, 2000 р., N 22, ст. 906; 2003 р., N 17, ст. 773) реченням такого змісту: "Форма довідки про заробітну плату, що подається для призначення (перерахунку) пенсії державним службовцям, затверджується правлінням Пенсійного фонду України за погодженням з Міністерством праці та соціальної політики.".

2. Ця постанова набирає чинності з дня опублікування.

Прем'єр-міністр України Ю.ТИМОШЕНКО
