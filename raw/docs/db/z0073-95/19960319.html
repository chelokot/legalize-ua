МІНІСТЕРСТВО ЗОВНІШНІХ ЕКОНОМІЧНИХ ЗВ'ЯЗКІВ УКРАЇНИ

НАКАЗ

N 41 від 20.03.95 Зареєстровано в Міністерстві м.Київ юстиції України 20 березня 1995 р. за N 73/609

( Наказ втратив чинність на підставі Наказу МЗЕЗ N 133-а ( z0124-96, z0117-96 ) від 24.02.96 )

Про затвердження кошторису витрат, пов'язаних з оформленням МЗЕЗ зовнішньоекономічних договорів (контрактів)

( Із змінами, внесеними згідно з Наказом МЗЕЗ N 97 ( z0176-95 ) від 29.05.95 )

У зв'язку з підвищенням тарифів і цін на послуги, пов'язані з оформленням та видачею карток обліку-реєстрації зовнішньоекономічних договорів (контрактів), та на часткову зміну наказу Міністерства зовнішніх економічних зв'язків України від 18.11.94 р. N 210 ( z0291-94 ) "Про заходи МЗЕЗ щодо забезпечення виконання Указу Президента України від 07.11.94 р. N 659/94", НАКАЗУЮ:

1. Затвердити кошторис витрат МЗЕЗ України, пов'язаних з оформленням та видачею карток обліку-реєстрації зовнішньоекономічних договорів (додається).

2. Юридичному управлінню (Красуля О.І.) у встановлений законом термін зареєструвати цей наказ в Міністерстві юстиції України.

3. Вважати таким, що втратив чинність додаток 10 до наказу МЗЕЗ від 18.11.94 р. N 210 ( z0294-94 ) "Про заходи МЗЕЗ щодо забезпечення виконання Указу Президента України від 07.11.94 р. N 659/94".

4. Управлінню справами (Павлов С.М.) довести наказ до Комітету ЗЕД Автономної Республіки Крим та регіональних управлінь ЗЕЗ.

5. Управлінню інформації та стратегічних досліджень (Загорняк О.В.) забезпечити публікацію цього наказу в засобах масової інформації, після реєстрації його в Міністерстві юстиції України в триденний термін.

6. Контроль за виконанням цього наказу покласти на заступника Міністра Щербатюка А.А.
