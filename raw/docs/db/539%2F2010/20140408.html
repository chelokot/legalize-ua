Павла Івановича

НОСАЧОВА - голова державної податкової

Ірина Вікторівна служби у м. Києві

Андрія Володимировича Президента України - Керівника Головного управління з питань судової реформи та судоустрою

ФЕДОСОВА - завідувача кафедри фінансів

Віктора Миколайовича Київського національного економічного університету імені Вадима Гетьмана.

{ Стаття 1 із змінами, внесеними згідно з Указами Президента N 625/2012 ( 625/2012 ) від 01.11.2012, N 626/2012 ( 626/2012 ) від 01.11.2012 }
