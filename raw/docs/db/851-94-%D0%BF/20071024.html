{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Української частини Міжурядової Українсько-Польської комісії з питань торгівлі та економічного співробітництва

Кабінет Міністрів України постановляє:

Призначити заступника Міністра зовнішніх економічних зв'язків України Гончарука Андрія Івановича головою Української частини Міжурядової Українсько-Польської комісії з питань торгівлі та економічного співробітництва, звільнивши від цих обов'язків Колоса Анатолія Івановича.
