Зареєстровано в Міністерстві юстиції України 22 червня 2004 р. за N 761/9360

Про втрату чинності наказу Фонду державного майна України від 26.05.98 N 1026

На виконання вимог пункту 2 постанови Кабінету Міністрів України від 28.12.92 N 731 ( 731-92-п ) "Про затвердження Положення про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами і доповненнями) НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Фонду державного майна України від 26.05.98 N 1026 ( z0397-98 ) "Щодо визначення початкової ціни акцій для продажу їх на спеціалізованих аукціонах за грошові кошти", зареєстрований в Міністерстві юстиції України 25.06.98 N 397/2837.

2. Департаменту оцінки майна, майнових прав та професійної оціночної діяльності (Н.Лебідь) подати цей наказ у встановленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Д.Парфененка.
