( Розпорядження втратило чинність на підставі Розпорядження КМ N 725-р ( 725-2002-р ) від 26.12.2002 )

Про утворення Міжвідомчої робочої групи з удосконалення роботи санаторно-курортних закладів

Утворити Міжвідомчу робочу групу з удосконалення роботи санаторно-курортних закладів у складі згідно з додатком.

Надати право голові Міжвідомчої робочої групи вносити у разі потреби зміни до її складу.

Голові Міжвідомчої робочої групи затвердити у місячний термін план її роботи.
