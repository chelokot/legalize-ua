КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 грудня 1999 р. N 1425-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснювати митне оформлення товарів (згідно з додатком), що надходять на адресу авіакомпаній "Авіалінії України", "Міжнародні авіалінії України", "Аеросвіт", як товарів критичного імпорту за ставкою ввізного мита у розмірі 0,05 відсотка митної вартості цих товарів та без сплати додаткового збору, передбаченого постановою Кабінету Міністрів України від 19 травня 1999 р. N 840 ( 840-99-п ).

Митне оформлення зазначених вантажів здійснюється за поданням Укравіації.
