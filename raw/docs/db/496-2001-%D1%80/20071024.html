{ Розпорядження втратило чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Міжвідомчої комісії з реалізації реформи житлово-комунального господарства

Затвердити головою Міжвідомчої комісії з реалізації реформи житлово-комунального господарства, утвореної постановою Кабінету Міністрів України від 1 грудня 1999 р. N 2194 ( 2194-99-п ) (Офіційний вісник України, 1999 р., N 48, ст. 2374; 2000 р., N 51, ст. 2224), Першого віце-прем'єр-міністра України Дубину Олега Вікторовича, увільнивши від цих обов'язків Єханурова Юрія Івановича.
