Кабінет Міністрів України; Постанова від 26.02.2009 № 199

Про розміри компенсації у 2009 році відсоткової ставки за залученими підприємствами агропромислового комплексу кредитами

Стан: Чинний

Ідентифікатор: 199-2009-п

Текст документа від 14.04.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 лютого 2009 р. N 199 Київ

Про розміри компенсації у 2009 році відсоткової ставки за залученими підприємствами агропромислового комплексу кредитами

{ Із змінами, внесеними згідно з Постановами КМ N 653 ( 653-2009-п ) від 01.07.2009 N 1056 ( 1056-2009-п ) від 07.10.2009 }

{ Установити, що до набрання чинності Законом України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) кошти, виділені згідно з Постановою КМ N 296 ( 296-2010-п ) від 07.04.2010, використовуються відповідно до цієї постанови, згідно з Постановою КМ N 296 ( 296-2010-п ) від 07.04.2010 }

Кабінет Міністрів України постановляє:

1. Установити, що у 2009 році компенсація підприємствам агропромислового комплексу відсоткової ставки надається:

1) за кредитами та напрямами їх використання, передбаченими пунктом 3 Порядку використання у 2009-2013 роках бюджетних коштів, що спрямовуються на підтримку підприємств агропромислового комплексу через механізм здешевлення кредитів, затвердженого постановою Кабінету Міністрів України від 26 лютого 2009 р. N 153 ( 153-2009-п ) (Офіційний вісник України, 2009 р., N 15, ст. 479): залученими у національній валюті - в розмірі 1,5 облікової ставки Національного банку, що діє на дату нарахування відсотків за користування кредитами, та в іноземній валюті - в розмірі 12 відсотків річних, але не вище розмірів, передбачених кредитними договорами;

{ Підпункт 1 пункту 1 із змінами, внесеними згідно з Постановами КМ N 653 ( 653-2009-п ) від 01.07.2009, N 1056 ( 1056-2009-п ) від 07.10.2009 }

2) за залученими у національній валюті у 2007-2008 роках короткостроковими, у 2005-2008 роках середньостроковими та у 2008 році довгостроковими кредитами визначеними в установленому порядку МНС або Торгово-промисловою палатою підприємствами агропромислового комплексу, які зазнали збитків внаслідок стихійного лиха, яке сталося в червні - липні 2008 р., і яким згідно з розпорядженнями Кабінету Міністрів України від 28 липня 2008 р. N 1010 ( 1010-2008-р ) і від 2 серпня 2008 р. N 1045 ( 1045-2008-р ) надано право на отримання часткової компенсації втрат та/або на часткове відшкодування збитків, та рішеннями, прийнятими конкурсними комісіями згідно з Порядком використання у 2008 році коштів, передбачених у державному бюджеті для здійснення фінансової підтримки підприємств агропромислового комплексу через механізм здешевлення кредитів, затвердженим постановою Кабінету Міністрів України від 27 лютого 2008 р. N 126 ( 126-2008-п ) (Офіційний вісник України, 2008 р., N 18, ст. 483), надано право на отримання компенсації за такими кредитами, - в розмірах, передбачених відповідно пунктами 5, 6 та 7 зазначеного Порядку ( 126-2008-п );

2-1) за короткостроковими кредитами, залученими підприємствами агропромислового комплексу (сільськогосподарські, хлібозаготівельні, борошномельні, хлібопекарські, комбікормові підприємства, крупозаводи, спиртові заводи, ДАК "Хліб України" та її дочірні підприємства) для закупівлі продовольчого та фуражного зерна урожаю 2008 року, за умови закупівлі продовольчого зерна за цінами, які склалися на біржовому ринку на дату його закупівлі, але не нижче мінімальних закупівельних цін, та фуражного зерна за цінами, які склалися на біржовому ринку на дату його закупівлі, в обсягах їх річної потреби за договорами, укладеними безпосередньо із сільськогосподарськими товаровиробниками, - в розмірі подвійної облікової ставки Національного банку, що діє на дату нарахування відсотків за користування кредитами, але не вище розмірів, передбачених кредитними договорами;

{ Пункт 1 доповнено підпунктом 2-1 згідно з Постановою КМ N 653 ( 653-2009-п ) від 01.07.2009 }

3) за довгостроковими кредитами, залученими сільськогосподарськими підприємствами у 2007-2008 роках для будівництва птахівничих комплексів та систем зрошення, будівництва і реконструкції приміщень, придбання обладнання і техніки для утримання і обслуговування тварин (крім птиці) та закупівлі племінної худоби та за довгостроковими кредитами, залученими сільськогосподарськими підприємствами, підприємствами агропромислового комплексу (хлібозаготівельні, борошномельні, хлібопекарські, комбікормові, крупозаводи, спиртові заводи) виключно у 2008 році для будівництва елеваторів та підлогових складів для зберігання зернових і олійних культур, яким рішеннями, прийнятими конкурсними комісіями згідно з Порядком використання у 2008 році коштів, передбачених у державному бюджеті для здійснення фінансової підтримки підприємств агропромислового комплексу через механізм здешевлення кредитів, затвердженим постановою Кабінету Міністрів України від 27 лютого 2008 р. N 126 ( 126-2008-п ) (Офіційний вісник України, 2008 р., N 18, ст. 483), надано право на отримання компенсації за такими кредитами, - в національній валюті в розмірі 1,5 облікової ставки Національного банку, що діє на дату нарахування відсотків за користування кредитами, але не вище розмірів, передбачених кредитними договорами, а в іноземній валюті - в розмірі 12 відсотків річних, але не вище розмірів, передбачених кредитними договорами;

{ Підпункт 3 пункту 1 із змінами, внесеними згідно з Постановами КМ N 653 ( 653-2009-п ) від 01.07.2009, N 1056 ( 1056-2009-п ) від 07.10.2009 }

4) за довгостроковими кредитами, залученими сільськогосподарськими підприємствами у поточному році для реконструкції тваринницьких та птахівничих комплексів і ферм, закупівлі племінної худоби, техніки та технологічного обладнання, - в розмірі подвійної облікової ставки Національного банку, що діє на дату нарахування відсотків за користування кредитами, але не вище розмірів, передбачених кредитними договорами;

{ Підпункт 4 пункту 1 із змінами, внесеними згідно з Постановою КМ N 1056 ( 1056-2009-п ) від 07.10.2009 }

4-1) за довгостроковими кредитами, залученими у поточному році у національній та іноземній валюті, - в розмірі 90 відсотків відсоткової ставки за кредитами:

сільськогосподарським підприємствам - для будівництва виробничих приміщень, тваринницьких і птахівничих комплексів і ферм, сховищ для зберігання зерна, овочів та фруктів;

суб'єктам господарювання - для будівництва оптових ринків сільськогосподарської продукції;

{ Пункт 1 доповнено підпунктом 4-1 згідно з Постановою КМ N 1056 ( 1056-2009-п ) від 07.10.2009 }

5) за середньо- та довгостроковими кредитами, залученими підприємствами агропромислового комплексу у 2006-2008 роках та поточному році для реалізації спрямованих на розвиток агропромислового комплексу інноваційних проектів, які пройшли державну реєстрацію в установленому законодавством порядку, - в розмірі 1,5 облікової ставки Національного банку, що діє на дату нарахування відсотків за користування кредитами, але не вище розмірів, передбачених кредитними договорами.

{ Пункт 1 доповнено підпунктом 5 згідно з Постановою КМ N 653 ( 653-2009-п ) від 01.07.2009 }

2. Виплата компенсації відсоткової ставки за залученими підприємствами агропромислового комплексу кредитами здійснюється в розмірах, визначених цією постановою, в межах відповідних бюджетних призначень, установлених Міністерству аграрної політики у Державному бюджеті України на 2009 рік ( 835-17 ).
