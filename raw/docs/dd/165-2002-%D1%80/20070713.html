Текст документа від 13.07.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 березня 2002 р. N 165-р Київ

( Дію Розпорядження відновлено згідно з Постановою КМ N 378 ( 378-2005-п ) від 26.05.2005 )

( Розпорядження втратило чинність на підставі Розпорядження КМ N 935-р ( 935-2004-р ) від 23.12.2004 )

Про внесення змін до розпоряджень Кабінету Міністрів України з питань створення Єдиної державної автоматизованої паспортної системи

{ Із змінами, внесеними згідно з Постановою КМ N 858 ( 858-2007-п ) від 26.06.2007 }

1. У розпорядженні Кабінету Міністрів України від 18 лютого 1998 р. N 96 ( 96-98-р ) після слів "щодо розміщення" доповнити словами і цифрами "на період до 2003 року".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 858 ( 858-2007-п ) від 26.06.2007 }
