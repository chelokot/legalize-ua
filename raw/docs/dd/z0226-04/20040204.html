ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З НАГЛЯДУ ЗА ОХОРОНОЮ ПРАЦІ

04.02.2004 N 31

Зареєстровано в Міністерстві юстиції України 20 лютого 2004 р. за N 226/8825

Про втрату чинності наказу від 04.06.99 N 103

У зв'язку з прийняттям постанови Кабінету Міністрів України від 15.10.2003 N 1631 ( 1631-2003-п ) "Про затвердження Порядку видачі дозволів Державним комітетом з нагляду за охороною праці та його територіальними органами" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Держнаглядохоронпраці від 04.06.99 N 103 ( z0690-99 ) "Про затвердження Положення про порядок видачі дозволів Комітетом по нагляду за охороною праці України", зареєстрований у Міністерстві юстиції України 08.10.99 за N 690/3983.

2. Начальнику управління науково-технічного забезпечення державного нагляду Больману Г.О. подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3. Заступнику начальника управління політики охорони праці Нефедченку Л.А. виключити з Державного реєстру міжгалузевих і галузевих нормативних актів про охорону праці ДНАОП 0.00-4.34-99 Положення про порядок видачі дозволів Комітетом по нагляду за охороною праці України, затверджене наказом Держнаглядохоронпраці від 04.06.99 N 103 ( z0690-99 ).

4. Контроль за виконанням цього наказу покласти на заступника Голови Держнаглядохоронпраці Плетньова В.А.
