Кабінет Міністрів України; Розпорядження від 28.07.1995 № 471-р

Про зміни у розпорядженні Кабінету Міністрів України від 19 січня 1994 р. N 26

Стан: Втратив чинність

Ідентифікатор: 471-95-р

Текст документа від 02.06.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 липня 1995 р. N 471-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 818 ( 818-2003-п ) від 02.06.2003 )

На часткову зміну пункту 1 розпорядження Кабінету Міністрів України від 19 січня 1994 р. N 26 ( 26-94-р ) надати Донецькій обласній державній адміністрації повноваження щодо управління державним пакетом акцій акціонерного товариства "Макіївський завод деревинних плит".

Прем'єр-міністр України Є.МАРЧУК
