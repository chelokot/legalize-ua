Кабінет Міністрів України; Постанова від 03.11.2010 № 992

Про внесення змін до пункту 2 Порядку використання коштів, передбачених у державному бюджеті для фінансової підтримки громадських організацій фізкультурно-спортивного спрямування

Стан: Втратив чинність

Ідентифікатор: 992-2010-п

Текст документа від 01.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 листопада 2010 р. N 992 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 294 ( 294-2011-п ) від 23.03.2011 }

Про внесення змін до пункту 2 Порядку використання коштів, передбачених у державному бюджеті для фінансової підтримки громадських організацій фізкультурно-спортивного спрямування

Кабінет Міністрів України постановляє:

Внести до пункту 2 Порядку використання коштів, передбачених у державному бюджеті для фінансової підтримки громадських організацій фізкультурно-спортивного спрямування, затвердженого постановою Кабінету Міністрів України від 5 березня 2009 р. N 165 ( 165-2009-п ) (Офіційний вісник України, 2009 р., N 17, ст. 519), такі зміни:

абзац другий після слів "та обладнання," доповнити словами "видатки на службові відрядження працівників в межах України,";

абзац четвертий після слів "оренда приміщень" доповнити словами ", спортивних споруд".

Прем'єр-міністр України М.АЗАРОВ
