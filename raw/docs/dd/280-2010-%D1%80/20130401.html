{ Розпорядження втратило чинність на підставі Розпорядження КМ N 195-р ( 195-2013-р ) від 01.04.2013 }

Про внесення змін до розпорядження Кабінету Міністрів України від 23 грудня 2009 р. N 1682

Внести до розпорядження Кабінету Міністрів України від 23 грудня 2009 р. N 1682 ( 1682-2009-р ) "Про зупинення дії технічних умов" такі зміни:

назву розпорядження ( 1682-2009-р ) викласти у такій редакції: "Про скасування державної реєстрації технічних умов";

у пункті 1:

слова "забезпечити зупинення в установленому порядку дії" замінити словами "здійснити в установленому порядку заходи щодо скасування державної реєстрації";

літери і цифри "ТУ У 23.2-00152388-2003" замінити літерами і цифрами "ТУ У 23.2-00152388-002-2003".
