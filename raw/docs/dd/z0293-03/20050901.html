МІНІСТЕРСТВО КУЛЬТУРИ І МИСТЕЦТВ УКРАЇНИ

НАКАЗ

24.03.2003 N 161

Зареєстровано в Міністерстві юстиції України 11 квітня 2003 р. за N 293/7614

( Наказ втратив чинність на підставі Наказу Міністерства культури і туризму N 745 ( z1285-05 ) від 18.10.2005 )

Про внесення доповнень до наказу Мінкультури України від 16.01.2002 N 20

Відповідно до постанови Кабінету Міністрів України від 18.01.2003 N 52 ( 52-2003-п ) "Про внесення зміни у додаток до постанови Кабінету Міністрів України від 1 липня 2002 р. N 890" НАКАЗУЮ:

1. Унести до наказу Міністерства культури і мистецтв України від 16.01.2002 N 20 ( z0046-02 ) "Про оплату праці працівників національних закладів культури (мистецьких)", зареєстрованого в Міністерстві юстиції України 18.01.2002 за N 46/6334 (із змінами), такі доповнення:

1.1. Пункт 4 після слова "Укрдержцирк" доповнити словами "від 01.07.1993 N 266-к "Про доповнення до наказу Міністерства культури України від 23.12.91 р. N 741-к".

1.2. Пункт 6 наказу після слів "для працівників Національного академічного українського драматичного театру імені Марії Заньковецької з 1 липня 2002 року" доповнити словами " для працівників Національного одеського філармонійного оркестру з 1 січня 2003 року".

1.3. Назву додатка 1 після слів "Київська камерата" доповнити словами "Національного одеського філармонійного оркестру".

2. Контроль за виконанням наказу покласти на заступника Державного секретаря В.В.Корнієнка.

Міністр Ю.П.Богуцький
