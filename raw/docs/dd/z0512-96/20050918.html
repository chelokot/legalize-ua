N 51 від 21.08.96 Зареєстровано в Міністерстві м.Київ юстиції України 10 вересня 1996 р. vd960821 vn51 за N 512/1537

( Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 686 ( z0996-05 ) від 22.08.2005 )

Про ліцензування підприємницької діяльності з постачання електричної енергії за нерегульованим тарифом

На виконання Указів Президента України "Про Національну комісію з питань регулювання електроенергетики" від 08.12.94 р. N 738 ( 738/94 ) та "Про заходи щодо забезпечення діяльності Національної комісії з питань регулювання електроенергетики України" від 14.03.95 р. N 213 ( 213/95 ) Національна комісія з питань регулювання електроенергетики України ПОСТАНОВЛЯЄ:

Встановити, що з 1 грудня 1996 року на території України діяльність суб'єктів підприємницької діяльності з постачання електричної енергії за нерегульованим тарифом без наявності ліцензії забороняється.
