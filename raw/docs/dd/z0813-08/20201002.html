Про затвердження Змін до постанови правління Пенсійного фонду України від 27.04.2000 N 7-4

Відповідно до пункту 3 постанови Кабінету Міністрів України від 15.03.2006 N 332 ( 332-2006-п ) "Деякі питання пенсійного забезпечення службовців Національного банку", пункту 12 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261 ( 1261-2007-п ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Затвердити Зміни до Порядку виплати пенсій працівникам установ Національного банку України, які виходять на пенсію за віком як державні службовці, затвердженого постановою правління Пенсійного фонду України від 27.04.2000 N 7-4 ( z0301-00 ), зареєстрованого в Міністерстві юстиції 24.05.2000 за N 301/4522, що додаються.

2. Департаменту зведеного бюджету (Придня Т.Г.) разом з юридичним управлінням (Рябцева Т.Б.) подати цю постанову на державну реєстрацію до Міністерства юстиції України.

В.о. Голови правління В.Кравчук

ПОГОДЖЕНО:

Перший заступник Міністра юстиції України Євген Корнійчук

Заступник Голови Правління Національного банку України П.М.Сенищ

Міністр праці та соціальної політики України Л.Денісова

Заступник Міністра фінансів України В.Матвійчук

ЗАТВЕРДЖЕНО Постанова правління Пенсійного фонду України 13.08.2008 N 16-3

Зареєстровано в Міністерстві юстиції України 5 вересня 2008 р. за N 813/15504

ЗМІНИ до Порядку виплати пенсій працівникам установ Національного банку України, які виходять на пенсію за віком як державні службовці ( z0301-00 )

1. У пункті 1.1 слова та цифри "пункту 3 постанови Кабінету Міністрів України від 28 січня 2000 р. N 166 ( 166-2000-п ) "Про реалізацію статті 64 Закону України "Про Національний банк України" при визначенні пенсії відповідно до Закону України "Про державну службу" замінити словами та цифрами "пункту 3 постанови Кабінету Міністрів України від 15 березня 2006 року N 332 ( 332-2006-п ) "Деякі питання пенсійного забезпечення службовців Національного банку".

2. У пункті 1.4 слова "районними (міськими) відділами Пенсійного фонду" замінити словами "управліннями Пенсійного фонду України в районах, містах і районах у містах".

3. У пункті 2.1 слова та цифри "Інструкцією про відкриття банками рахунків у національній та іноземній валюті, затвердженою постановою Правління Національного банку України від 18 грудня 1998 р. N 527 ( z0819-98 ) і зареєстрованою в Міністерстві юстиції України 24.12.98 за N 819/3259" замінити словами "нормативно-правовими актами Національного банку України, що регулюють порядок відкриття та використання рахунків у національній та іноземній валюті".

4. В абзаці третьому пункту 2.5 виключити слова "не включаються до спадщини і".

5. У пунктах 3.2 та 4.1 слова "протягом одного банківського дня" замінити словами "не пізніше наступного операційного дня".
