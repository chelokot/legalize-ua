Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 червня 2002 р. N 295-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про утворення Міжвідомчої комісії з розгляду та вирішення питань соціального захисту громадян, які постраждали внаслідок Чорнобильської катастрофи

( Із змінами, внесеними згідно з Розпорядженням КМ N 43-р ( 43-2003-р ) від 29.01.2003 )

1. Утворити Міжвідомчу комісію з розгляду та вирішення питань соціального захисту громадян, які постраждали внаслідок Чорнобильської катастрофи (далі - Міжвідомча комісія), і затвердити її склад згідно з додатком.

Надати право голові Міжвідомчої комісії вносити у разі потреби зміни до її складу.

2. МНС здійснити організаційно-технічне забезпечення роботи Міжвідомчої комісії.
