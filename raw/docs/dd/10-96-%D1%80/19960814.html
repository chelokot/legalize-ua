Кабінет Міністрів України; Розпорядження від 09.01.1996 № 10-р

Про передачу Українській зовнішньоекономічній корпорації з іноземного туризму будинку у безоплатне користування

Стан: Втратив чинність

Ідентифікатор: 10-96-р

Текст документа від 14.08.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 січня 1996 р. N 10-р Київ

{ Розпорядження скасовано на підставі Розпорядження КМ N 509-р ( 509-96-р ) від 14.08.96 }

{ Дію Розпорядження призупинено згідно з Розпорядженням КМ N 41-р ( 41-96-р ) від 18.01.96 }

З метою впорядкування використання будинку по вул. Богдана Хмельницького, 26, у м. Києві і завершення його реконструкції погодитися з пропозицією Фонду державного майна щодо передачі Українській зовнішньоекономічній корпорації з іноземного туризму цього будинку у безоплатне користування.

Прем'єр-міністр України Є.МАРЧУК
