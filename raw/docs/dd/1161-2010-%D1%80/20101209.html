Про заходи щодо забезпечення розвитку Міжнародного аеропорту "Львів"

Стан: Чинний

Ідентифікатор: 1161-2010-р

Текст документа від 09.12.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 червня 2010 р. N 1161-р Київ

Про заходи щодо забезпечення розвитку Міжнародного аеропорту "Львів"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1236-р ( 1236-2010-р ) від 16.06.2010 Постановою КМ N 1105 ( 1105-2010-п ) від 06.12.2010 }

{ Дію пункту 1 зупинено до 20 липня 2010 р. згідно з Розпорядженням КМ N 1236-р ( 1236-2010-р ) від 16.06.2010 }

1. Передати функції замовника з будівництва та реконструкції Міжнародного аеропорту "Львів" від Управління капітального будівництва Львівської облдержадміністрації державному підприємству "Дирекція з будівництва об'єктів ЄВРО-2012 у м. Львові" (далі - Дирекція), що належить до сфери управління Національного агентства з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу та реалізації інфраструктурних проектів.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2010-п ) від 06.12.2010 }

2. Управлінню капітального будівництва Львівської облдержадміністрації здійснити у двотижневий строк передачу Дирекції об'єктів, пов'язаних з будівництвом та реконструкцією Міжнародного аеропорту "Львів", та відповідної документації.

3. Управлінню капітального будівництва Львівської облдержадміністрації, Національному агентству з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу та реалізації інфраструктурних проектів разом з іншими заінтересованими органами виконавчої влади забезпечити у двотижневий строк укладення договорів про заміну сторін у зобов'язаннях щодо будівництва та реконструкції Міжнародного аеропорту "Львів" (у разі потреби за погодженням з відповідними контрагентами) з урахуванням того, що всі права та обов'язки переходять до Дирекції, і вирішити в установленому порядку питання стосовно переоформлення документів дозвільного характеру, виданих Управлінню капітального будівництва Львівської облдержадміністрації, або правонаступництва за ними.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2010-п ) від 06.12.2010 }

4. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 31 серпня 2009 р. N 1009 ( 1009-2009-р ) "Про заходи щодо забезпечення розвитку Міжнародного аеропорту "Львів".

Прем'єр-міністр України М.АЗАРОВ
