Про утворення міжвідомчої робочої групи з опрацювання питання щодо надання земельної ділянки для будівництва хвостосховища ВАТ "АрселорМіттал Кривий Ріг"

Ідентифікатор: 220-2010-р

Текст документа від 11.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 січня 2010 р. N 220-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про утворення міжвідомчої робочої групи з опрацювання питання щодо надання земельної ділянки для будівництва хвостосховища ВАТ "АрселорМіттал Кривий Ріг"

1. Утворити міжвідомчу робочу групу з опрацювання питання щодо надання земельної ділянки для будівництва хвостосховища ВАТ "АрселорМіттал Кривий Ріг" у складі згідно з додатком.

2. Міжвідомчій робочій групі, утвореній згідно з цим розпорядженням, у тижневий строк опрацювати питання щодо надання земельної ділянки для будівництва хвостосховища ВАТ "АрселорМіттал Кривий Ріг" та подати Кабінетові Міністрів України узгоджені пропозиції щодо визначення можливих шляхів його вирішення.
