Стан: Чинний

Текст документа від 11.08.2008:

ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

11.08.2008 N 277

Зареєстровано в Міністерстві юстиції України 1 вересня 2008 р. за N 796/15487

Про внесення змін до наказу Держкомстату від 27.10.2005 N 331 та визнання такими, що втратили чинність, інструкцій

Відповідно до статей 4, 14, 18 Закону України "Про державну статистику" ( 2614-12 ) та з метою приведення нормативно-правових актів у відповідність до чинного законодавства НАКАЗУЮ:

1. Унести до наказу Держкомстату від 27.10.2005 N 331 ( z1277-05 ) "Про затвердження інструкцій щодо заповнення форм державних статистичних спостережень зі статистики товарних ринків", зареєстрованого в Міністерстві юстиції України 27.10.2005 за N 1277/11557 (далі - Наказ), такі зміни:

1.1. Підпункти 1.5, 1.6, 1.7 Наказу ( z1277-05 ) виключити.

1.2. У зв'язку з цим підпункт 1.8 Наказу ( z1277-05 ) вважати відповідно підпунктом 1.5.

2. Визнати такими, що втратили чинність:

2.1. Інструкцію щодо заповнення форми державного статистичного спостереження N 2-дм "Звіт про залишки, надходження і витрати дорогоцінних металів та виробів з них" ( z1282-05 ), затверджену Наказом ( z1277-05 ), зареєстровану в Міністерстві юстиції України 27.10.2005 за N 1282/11562.

2.2. Інструкцію щодо заповнення додатка до форми державного статистичного спостереження N 2-дм "Звіт про залишки, надходження та використання дорогоцінних металів у вигляді брухту та відходів" ( z1283-05 ), затверджену Наказом ( z1277-05 ), зареєстровану в Міністерстві юстиції України 27.10.2005 за N 1283/11563.

2.3. Інструкцію щодо заповнення форми державного статистичного спостереження N 3-дм "Звіт про залишки, надходження і витрати природних алмазів на виготовлення алмазних інструментів і діамантів" ( z1284-05 ), затверджену Наказом ( z1277-05 ), зареєстровану в Міністерстві юстиції України 27.10.2005 за N 1284/11564.

3. Контроль за виконанням цього наказу покласти на першого заступника Голови Піщейка В.О.
