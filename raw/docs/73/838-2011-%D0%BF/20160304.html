КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 серпня 2011 р. N 838 Київ

Про внесення змін до порядків, затверджених постановами Кабінету Міністрів України від 26 листопада 2008 р. N 1027 і від 5 вересня 2007 р. N 1090

{ Із змінами, внесеними згідно з Постановою КМ N 70 ( 70-2016-п ) від 27.01.2016 }

Кабінет Міністрів України постановляє:

1. Внести до Порядку ініціювання, підготовки та реалізації проектів економічного і соціального розвитку України, що підтримуються міжнародними фінансовими організаціями, затвердженого постановою Кабінету Міністрів України від 26 листопада 2008 р. N 1027 ( 1027-2008-п ) (Офіційний вісник України, 2008 р., N 91, ст. 3025; 2009 р., N 68, ст. 2342; 2011 р., N 45, ст. 1839), і Порядку казначейського обслуговування коштів, передбачених у спеціальному фонді державного бюджету для виконання бюджетних програм, спрямованих на реалізацію проектів економічного та соціального розвитку, які підтримуються Міжнародним банком реконструкції та розвитку, затвердженого постановою Кабінету Міністрів України від 5 вересня 2007 р. N 1090 ( 1090-2007-п ) "Деякі питання виконання бюджетних програм, спрямованих на реалізацію проектів економічного та соціального розвитку, які підтримуються Міжнародним банком реконструкції та розвитку" (Офіційний вісник України, 2007 р., N 67, ст. 2577; 2011 р., N 28, ст. 1175), зміни, що додаються.

2. Установити, що для реалізації інвестиційних проектів відповідно до договорів України з міжнародними фінансовими організаціями, які набрали чинності в установленому законодавством порядку до набрання чинності цією постановою, відповідальний виконавець та/або бенефіціар подає у двотижневий строк після опублікування цієї постанови Міністерству фінансів засвідчений зразок підпису особи, на яку покладено повноваження щодо підписання запитів на одержання коштів позики із спеціальних та транзитних рахунків і підтвердних документів, що обґрунтовують такі запити.

3. Міністерству фінансів привести в місячний строк власні нормативні акти у відповідність з цією постановою.

Прем'єр-міністр України М.АЗАРОВ

Інд. 27

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 3 серпня 2011 р. N 838

ЗМІНИ, що вносяться до порядків, затверджених постановами Кабінету Міністрів України від 26 листопада 2008 р. N 1027 ( 1027-2008-п ) і від 5 вересня 2007 р. N 1090 ( 1090-2007-п )

{ Пункт 1 втратив чинність на підставі Постанови КМ N 70 ( 70-2016-п ) від 27.01.2016 }

2. У Порядку казначейського обслуговування коштів, передбачених у спеціальному фонді державного бюджету для виконання бюджетних програм, спрямованих на реалізацію проектів економічного та соціального розвитку, які підтримуються Міжнародним банком реконструкції та розвитку, затвердженому постановою Кабінету Міністрів України від 5 вересня 2007 р. N 1090 ( 1090-2007-п ):

1) пункт 3 доповнити підпунктами 13-1 і 13-2 такого змісту:

"13-1) поповнює спеціальний рахунок в іноземній валюті, відкритий в уповноваженому банку на ім'я Казначейства;

13-2) здійснює платежі з рахунка позики для оплати товарів (робіт, послуг) у рамках реалізації проектів;";

2) підпункти 2 і 3 пункту 6 виключити.
