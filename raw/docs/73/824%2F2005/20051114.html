Президент України; Указ від 19.05.2005 № 824/2005

Про внесення змін та визнання такими, що втратили чинність, деяких актів Президента України

Стан: Чинний

Ідентифікатор: 824/2005

Текст документа від 14.11.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін та визнання такими, що втратили чинність, деяких актів Президента України

( Із змінами, внесеними згідно з Указом Президента N 1599/2005 ( 1599/2005 ) від 14.11.2005 )

1. Внести до Указів Президента України такі зміни:

1) в Указі Президента України від 10 червня 1997 року N 503 ( 503/97 ) "Про порядок офіційного оприлюднення нормативно-правових актів та набрання ними чинності" (зі змінами, внесеними Указами від 4 грудня 1997 року N 1327 ( 1327/97 ), від 8 квітня 2004 року N 399 ( 399/2004 ) та від 28 травня 2004 року N 589 ( 589/2004 ):

а) у частині другій статті 1 абзац "газета "Президентський вісник" виключити;

б) частину другу статті 6 викласти в такій редакції:

"Якщо інший нормативно-правовий акт опубліковано в газеті "Урядовий кур'єр" до його опублікування в "Офіційному віснику України", він набирає чинності після опублікування в цій газеті".

( Пункт 2 статті 1 втратив чинність на підставі Указу Президента N 1599/2005 ( 1599/2005 ) від 14.11.2005 )

2. Визнати такими, що втратили чинність:

Розпорядження Президента України від 14 січня 2003 року N 3 ( 3/2003-рп ) "Про всеукраїнську громадсько-політичну газету "Президентський вісник";

Розпорядження Президента України від 7 квітня 2003 року N 89 ( 89/2003-рп ) "Про інформаційно-аналітичний бюлетень "Президентський контроль".

3. Державному управлінню справами здійснити в установленому порядку заходи щодо ліквідації редакцій газети "Президентський вісник" і бюлетеня "Президентський контроль", забезпечивши при цьому додержання вимог законодавства під час вивільнення їх працівників.

Президент України В.ЮЩЕНКО

м. Київ, 19 травня 2005 року N 824/2005
