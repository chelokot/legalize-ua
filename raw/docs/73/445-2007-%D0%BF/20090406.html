КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 березня 2007 р. N 445 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки друкованих періодичних видань культурологічного та літературно-художнього напряму

{ Із змінами, внесеними згідно з Постановою КМ N 195 ( 195-2008-п ) від 19.03.2008 }

{ Установити, що у 2008 році кошти, передбачені у державному бюджеті ( 107-17 ) Міністерству культури і туризму за програмою "Фінансова підтримка друкованих періодичних видань культурологічного та літературно-художнього напрямку", використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 195 ( 195-2008-п ) від 19.03.2008 }

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки друкованих періодичних видань культурологічного та літературно-художнього напряму, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 березня 2007 р. N 445

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки друкованих періодичних видань культурологічного та літературно-художнього напряму

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті ( 489-16 ) МКТ за програмою "Фінансова підтримка друкованих періодичних видань культурологічного та літературно-художнього напрямку" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є МКТ.

3. Одержувачами бюджетних коштів є редакції друкованих періодичних видань, у тому числі "Редакція журналу "Пам'ятки України: історія і культура" і "Газетно-журнальне видавництво Мінкультури".

4. Бюджетні кошти спрямовуються на фінансову підтримку друкованих періодичних видань культурологічного та літературно-художнього напряму.

5. Бюджетні кошти використовуються МКТ з урахуванням необхідності виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державного казначейства, у разі відповідності таких зобов'язань паспорту бюджетної програми.

6. У разі зменшення бюджетних призначень МКТ з метою недопущення виникнення кредиторської заборгованості на кінець року здійснює відповідне коригування суми видатків на фінансову підтримку друкованих періодичних видань культурологічного та літературно-художнього напряму.

7. Державна фінансова підтримка друкованим періодичним виданням літературно-художнього напряму надається виключно для оплати поліграфічних послуг та закупівлі паперу як найбільш витратних складових частин виробничого процесу.

Редакції друкованих видань, які потребують державної фінансової підтримки, подають МКТ документи згідно з переліком та в порядку, визначеними ним.

Після визначення переліку друкованих видань МКТ розподіляє бюджетні кошти між ними.

8. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

8-1. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти ( 1490-14 ).

{ Порядок доповнено пунктом 8-1 згідно з Постановою КМ N 195 ( 195-2008-п ) від 19.03.2008 }

9. МКТ затверджує результативні показники використання бюджетних коштів з поквартальною розбивкою та подає Мінфіну у двотижневий строк після затвердження розпису державного бюджету.

Інформацію про виконання зазначених показників одержувачі бюджетних коштів надсилають МКТ у тижневий строк після закінчення звітного періоду для узагальнення та подання Мінфіну щокварталу і за результатами виконання показників за одинадцять місяців.

10. Відповідальність за нецільове використання бюджетних коштів встановлюється відповідно до законодавства.

{ Пункт 11 виключено на підставі Постанови КМ N 195 ( 195-2008-п ) від 19.03.2008 }

12. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
