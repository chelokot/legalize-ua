КАБІНЕТ МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 19 серпня 1991 р. N 158 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1758 ( 1758-2001-п ) від 27.12.2001 )

Питання Фонду державного майна Української РСР

( Із змінами, внесеними згідно з Постановами КМ N 357 ( 357-2000-п ) від 18.02.2000 N 1038 ( 1038-2000-п ) від 27.06.2000 )

Кабінет Міністрів Української РСР постановляє:

1. Покласти на Фонд державного майна УРСР виконання таких завдань: організація роботи та оформлення переходу в юрисдикцію Української РСР державних підприємств і організацій союзного підпорядкування, визначення форм і порядку зміни державної власності, нагляд за ефективністю використання і здійснення акціонування державного майна УРСР.

2. Дозволити Фонду державного майна УРСР мати колегію в кількості 7 чоловік і раду у справах використання державного майна та реформування власності у складі членів колегії Фонду, представників відповідних міністерств і відомств УРСР, обл/міськ/ виконкомів, провідних учених та фахівців. Рада готує пропозиції та проекти рішень щодо своїх повноважень і в разі необхідності подає їх Кабінету Міністрів УРСР.

3. Установити, що рішення Фонду державного майна УРСР, прийнятті в межах його повноважень, є обов'язковими для виконання міністерствами і відомствами УРСР, іншими організаціями.

4. Рекомендувати Раді Міністрів Кримської АРСР, облвиконкомам, Київському міськвиконкому створити у двомісячний строк регіональні фонди державного майна.

Видатки на утримання апаратів регіональних фондів профінансувати за рахунок місцевих бюджетів.

Організаційно-методичне керівництво роботою зазначених фондів покласти на Фонд державного майна УРСР.

5. Міністерству статистики УРСР надавати Фонду державного майна УРСР безкоштовно матеріали, необхідні для реалізації покладених на нього завдань.

6. Фонду державного майна УРСР:

створити правління, до складу якого включити голову, його заступників, керівників головних управлінь центрального апарату Фонду, голів регіональних фондів державного майна.

( Абзац третій пункту 6 втратив чинність на підставі Постанови КМ N 1038 ( 1038-2000-п ) від 27.06.2000 )

7. Міністерству економіки УРСР, Державному комітетові УРСР по зв'язку забезпечити оснащення службових приміщень Фонду державного майна УРСР меблями, обладнанням, друкарською, обчислювальною і розмножувальною технікою, засобами зв'язку.

( Пункт 8 втратив чинність на підставі Постанови КМ N 357 ( 357-2000-п ) від 18.02.2000 )

9. Фонду державного майна УРСР подати у місячний строк до Кабінету Міністрів УРСР погоджений з Міністерством економіки УРСР і Міністерством юстиції УРСР проект Положення про Фонд державного майна УРСР.
