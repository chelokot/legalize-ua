N 190 ( z1084-15 ) від 19.08.2015 }

Про внесення змін і доповнень до форм державної статистичної

звітності з земельних ресурсів та Інструкції з заповнення державної статистичної звітності з кількісного обліку земель (форми N 6-зем, N 6а-зем, N 6б-зем, N 2-зем), затверджених наказом Держкомстату України від 05.11.98 N 377

Відповідно до рішення Вищого арбітражного суду України від 24.02.2000 справа N 8/6 та статті 14 Закону України "Про державну статистику" ( 2614-12 ) НАКАЗУЮ:

1. Унести зміни і доповнення до форм державної статистичної звітності з земельних ресурсів та Інструкції з заповнення державної статистичної звітності з кількісного обліку земель (форми N 6-зем, N 6а-зем, N 6б-зем, N 2-зем) ( za788-98 ), затверджених наказом Держкомстату України від 05.11.98 N 377 ( z0788-98 ), який зареєстровано Мін'юстом 14.12.98 за N 788/3228, що додаються, і враховувати їх, починаючи зі звіту за 2001 рік.

2. Державному комітету України по земельних ресурсах довести цей наказ до відома для керівництва в роботі підпорядкованим йому державним органам земельних ресурсів.

Голова Комітету О.Г.Осауленко

Погоджено: Заступник голови Держкомзему України К.Г.Радченко

ЗАТВЕРДЖЕНО Наказ Державного комітету статистики України 16 жовтня 2001 р. N 420

Зареєстровано в Міністерстві юстиції України 26 жовтня 2001 р. за N 910/6101

Зміни і доповнення до форм державної статистичної звітності з земельних ресурсів та Інструкції з заповнення державної статистичної звітності з кількісного обліку земель (форми N 6-зем, N 6а-зем, N 6б-зем, N 2-зем) ( za788-98 ), затверджених наказом Держкомстату України від 05.11.98 N 377 ( z0788-98 ) та зареєстрованих Мін'юстом 14.12.98 за N 788/3228

1. У формах державної статистичної звітності з земельних ресурсів (форми N 6-зем, N 6а-зем, N 6б-зем, N 2-зем):

1.1. По всіх формах звітності слово "радгоспи" замінити словом "держгоспи".

1.2. Рядок 44 форм N 6-зем та N 2-зем після слова "науки" доповнити словами "науково-дослідні та проектні організації".

1.3. Назву графи 42 форми N 6-зем викласти у новій редакції такого змісту: "Землі комерційного та іншого використання".

2. У Інструкції з заповнення державної статистичної звітності з кількісного обліку земель ( форми N 6-зем, N 6а-зем, N 6б-зем, N 2-зем):

2.1. По всій інструкції слово "радгоспи" замінити словом "держгоспи".

2.2. Рядок 44 форми N 6-зем після слова "науки" доповнити словами "науково-дослідні та проектні організації".

2.3. Рядок 49 форми N 6-зем після слів "ветеринарні установи" доповнити словом "аптеки".

2.4. У рядку 52 форми N 6-зем слово "аптеки" виключити.

2.5. Графу 1 форми N 6-зем доповнити абзацом такого змісту:

"У рядках 25, 29, 33, 37 потрібно вказувати кількість товариств, кооперативів".

2.6. Графу 6 форми N 6-зем після слова "перелоги:" доповнити словом "орні".

2.7. У графі 42 форми N 6-зем:

слова "дані про землі, які використовуються в комерційних цілях:" замінити словами "дані про землі комерційного та іншого використання";

перед словом "банками" додати слово "комерційними";

слова "Включати до цієї категорії землі потрібно за видами діяльності, вказаними в додатку 3. Землі наукових організацій також потрібно включати до цих земель" викласти в новій редакції такого змісту:

"Включати потрібно землі за видами економічної діяльності, вказаними в додатку 3; частину земель, наданих юридичним та фізичним особам для підприємницької діяльності, зазначеної в цьому додатку, а також землі згідно з додатком 4, на яких проводиться підприємницька діяльність".

2.8. У графі 43 форми N 6-зем:

після слів "включати землі" доповнити графу 43 словами "на яких не проводиться підприємницька діяльність і";

після слів "охорони здоров'я" доповнити словами "релігійних організацій";

після слів "згідно з додатком 4" доповнити словами "а також землі згідно з додатком 3, на яких не проводиться підприємницька діяльність".

2.9. У графі 56 форми N 6-зем слова "бульвари тощо" виключити.

3. У додатку 3 до Інструкції з заповнення державної статистичної звітності з кількісного обліку земель (форми N 6-зем, N 6а-зем, N 6б-зем, N 2-зем):

3.1. Назву додатка 3 викласти в новій редакції такого змісту:

"Класифікація видів економічної діяльності на землях комерційного та іншого використання (у графі 42)".

3.2. Розділ 73 доповнити абцазом такого змісту:

"Цей розділ не включає діяльність наукових установ, що займаються фундаментальними дослідженнями".

3.3. Виключити розділ та групи:

"91 Громадська діяльність

91.1 Організації у сфері економіки;

91.2 Профспілка робітників найманої праці;

91.3 Інші громадські організації".

3.4. У Розділі 93 "Індивідуальні послуги", група 93.0 графу "Опис" викласти у новій редакції такого змісту:

"Індивідуальні послуги: чищення та фарбування хутрових виробів; послуги перукарень та салонів краси; ритуальні послуги та інші індивідуальні послуги (діяльність астрологів та екстрасенсів; діяльність, пов'язану з соціальним життям, наприклад, надання супроводження, послуги служб знайомства та бюро одружень; послуги з дослідження геніології; послуги чистильників взуття, носіїв, обслуговуючого персоналу автомобільних стоянок)".

4. У додатку 4 до Інструкції з заповнення державної статистичної звітності з кількісного обліку земель (форми N 6-зем, N 6а-зем, N 6б-зем, N 2-зем):

4.1. Розділ 92 "Діяльність у сфері відпочинку і розваг, культури та спорту" доповнити розділом та групами такого змісту:

"91 Громадська діяльність

91.1 Організації у сфері економіки;

91.2 Профспілка робітників найманої праці;

91.3 Інші громадські організації".

Начальник Управління державного земельного кадастру М.Г.Лихогруд
