Кабінет Міністрів України; Розпорядження від 12.10.1992 № 668-р

Про відкриття пункту пропуску через державний кордон України у Севастопольському морському рибному порту управління "Південтрансзбут"

Стан: Втратив чинність

Ідентифікатор: 668-92-р

Текст документа від 10.07.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 жовтня 1992 р. N 668-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 551-р ( 551-98-р ) від 10.07.98 )

Відкрити після належного облаштування пункт пропуску через державний кордон України у Севастопольському морському рибному порту управління "Південтрансзбут" для міжнародного вантажного сполучення з правом заходження в цей порт іноземних невійськових суден.
