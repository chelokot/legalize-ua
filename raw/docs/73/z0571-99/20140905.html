ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

N 942 ( z0926-14 ) від 22.07.2014 }

Про затвердження Інструкції про порядок видачі, обліку, зберігання та знищення бланків сертифікатів цінних паперів

{ Із змінами, внесеними згідно з Рішеннями Державної комісії з цінних паперів та фондового ринку

N 55 ( z0333-05 ) від 23.02.2005

N 1951 ( z0122-11 ) від 28.12.2010 }

З метою вдосконалення діяльності учасників ринку цінних паперів, керуючись Законами України "Про цінні папери і фондову біржу" ( 1201-12 ), "Про Національну депозитарну систему та особливості електронного обігу цінних паперів в Україні" ( 710/97-ВР ), Указом Президента України "Про інвестиційні фонди та інвестиційні компанії" ( 55/94 ) та Положенням про вимоги до сертифікатів цінних паперів, випущених у документарній формі, затвердженим рішенням Комісії від 31.07.98 року N 95 ( z0510-98 ), і Положенням про порядок ведення реєстрів власників іменних цінних паперів, затвердженим рішенням Комісії від 26.05.98 року N 60 ( vr060312-98 ), Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Інструкцію про порядок видачі, обліку, зберігання та знищення бланків сертифікатів цінних паперів.

2. Начальнику управління регулювання випуску та обігу цінних паперів забезпечити реєстрацію цього рішення у Міністерстві юстиції України.

3. Доручити прес-центру забезпечити публікацію цього рішення у встановленому законодавством порядку.

4. Рішення набуває чинності відповідно до законодавства.

5. Контроль за виконанням рішення покласти на члена Комісії Бойка О.І.

Голова Комісії О.Мозговий

Протокол засідання Комісії від 6 липня 1999 року N 45

Затверджено Рішення Державної комісії з цінних паперів та фондового ринку від 30.07.99 N 156

Інструкція про порядок видачі, обліку, зберігання та знищення бланків сертифікатів іменних цінних паперів

Ця Інструкція розроблена відповідно до статей 6, 7, 47 Закону України "Про цінні папери та фондовий ринок" ( 3480-15 ), статей 1, 9, 16, 17 Закону України "Про Національну депозитарну систему та особливості електронного обігу цінних паперів в Україні" ( 710/97-ВР ), Положення про вимоги до сертифікатів цінних паперів, документарної форми існування, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 31.07.98 N 95 ( z0510-98 ), зареєстрованого в Міністерстві юстиції України 13.08.98 за N 510/2950 (із змінами), та Положення про порядок ведення реєстрів власників іменних цінних паперів, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 17.10.2006 N 1000 ( z0049-07 ), зареєстрованого в Міністерстві юстиції України 22.01.2007 за N 49/13316 (із змінами) (далі - Положення про порядок ведення реєстрів).

{ Преамбула в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

Загальні положення

1. Замовником бланків цінних паперів можуть бути емітент, який випускає цінні папери документарної форми існування, або організації, що визначаються на тендерній основі, окремим рішенням Державної комісії з цінних паперів та фондового ринку.

{ Пункт 1 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

2. Емітент має право замовляти виготовлення бланків цінних паперів на підприємствах-виробниках або купувати бланки сертифікатів, виготовлених за типовою формою, у визначеній організації тільки після реєстрації відповідного випуску цінних паперів у Державній комісії з цінних паперів та фондового ринку.

Визначена організація має право замовляти виготовлення бланків сертифікатів за типовою формою з моменту прийняття Державною комісією з цінних паперів та фондового ринку відповідного окремого Рішення.

3. Емітент іменних цінних паперів, випущених у документарній формі, може замовити виготовлення бланків цінних паперів на державних підприємствах, що мають ліцензію Міністерства фінансів України. ( Абзац перший пункту 3 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 55 ( z0333-05 ) від 23.02.2005 )

Виготовлення та ввезення в Україну бланків цінних паперів, а також напівфабрикатів і паперів для їх виготовлення здійснюється лише за ліцензіями, виданими Міністерством фінансів України.

Визначена організація має право замовляти виготовлення бланків сертифікатів за типовою формою тільки на державних підприємствах, що мають ліцензію Міністерства фінансів України. ( Абзац третій пункту 3 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 55 ( z0333-05 ) від 23.02.2005 )

4. Отримання замовником тиражу бланків цінних паперів від підприємства-виробника, а також емітентом від організації-замовника, здійснюється на підставі акта про приймання-передання та накладної.

5. Продаж або передача емітентом або реєстратором бланків сертифікатів, виготовлених за типовою формою, іншим емітентам забороняється.

6. Емітент повинен отримати у підприємства-виробника два сертифікати якості на виготовлені бланки цінних паперів для створення можливості перевірки цінних паперів на справжність (автентичність).

Один з сертифікатів якості емітент зобов'язаний надати до Національного депозитарія України.

Сертифікати якості на бланки сертифікатів, виготовлені за типовою формою, підприємства-виробники зобов'язані надати до Національного депозитарія України самостійно, після запровадження у друк нової серії бланків.

7. Транспортування виготовлених бланків цінних паперів від підприємства-виробника до замовника здійснюється на транспорті з охороною.

8. Передання бланків сертифікатів від емітента до реєстратора здійснюється на підставі акта про приймання-передання, який складається у двох примірниках (один - для емітента, другий - для реєстратора) за формою, що встановлена у додатку 1 цієї Інструкції.

Реєстратор зобов'язаний надати до Національного депозитарію України відомості про серії та номери бланків сертифікатів, виготовлених за типовою формою, та реквізити емітента, що передав їх для заповнення.

9. Керівник емітента для здійснення обліку бланків сертифікатів, що зберігаються, та керівник реєстроутримувача для здійснення обліку бланків сертифікатів, що зберігаються та видаються для заповнення, призначають матеріально відповідальних осіб, з якими укладаються відповідні договори про матеріальну відповідальність.

10. Якщо у емітента кількість власників іменних цінних паперів документарної форми існування не перевищує максимальної кількості осіб, установленої Державною комісією з цінних паперів та фондового ринку для організації самостійного ведення реєстру емітентом та ведення реєстру здійснюється емітентом самостійно, то відповідальність за зберігання бланків сертифікатів, здійснення їх обліку та їх видавання для заповнення несе матеріально відповідальна особа емітента.

{ Пункт 10 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

Порядок обліку сертифікатів

11. Керівники та головні бухгалтери емітентів, реєстраторів та зберігачів несуть персональну відповідальність за організацію зберігання, обліку та видачі сертифікатів.

12. Облік бланків сертифікатів, що зберігаються у сховищі емітента або реєстратора, ведеться відповідною матеріально відповідальною особою та здійснюється згідно з "Прибутково-видатковою книгою з обліку бланків суворої звітності" (форма N С 3-2, затверджена наказом Мінстату України від 11.03.96 N 67 ( v0067202-96 ).

Облік бланків сертифікатів цінних паперів у сховищі реєстратора ведеться окремо за кожним емітентом.

13. Реєстратор повинен повідомити емітента про зменшення кількості бланків сертифікатів, що є у його розпорядженні, до критичної кількості, значення якої має становити не менш як 5 відсотків від кількості власників іменних цінних паперів емітента.

Емітент, після отримання повідомлення від реєстратора про критичну кількість бланків сертифікатів, повинен у тижневий строк зробити замовлення або придбати додаткову кількість бланків сертифікатів, що будуть мати той самий дизайн, відповідатимуть тому самому сертифікату якості та будуть виготовлені у того самого виробника.

Загальні збори емітента можуть прийняти рішення про заміну сертифікатів.

14. Реєстроутримувач одержує бланки сертифікатів зі сховища своєї організації, на підставі прибутково-видаткової накладної на бланки суворої звітності (форма N С 3-1, затверджена наказом Мінстату України від 11.03.96 N 67), на відповідальне збереження та повертає їх до сховища у випадку псування або погашення бланка цінного папера.

15. Облік виданих, утрачених, погашених та знищених сертифікатів іменних цінних паперів, отриманих реєстроутримувачем для оформлення прав власності на іменні цінні папери, здійснюється в журналі обліку сертифікатів та свідоцтв про знерухомлення іменних цінних паперів (далі - журнал обліку сертифікатів).

{ Пункт 15 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

16. Журнал обліку сертифікатів ведеться відповідно до вимог Положення про порядок ведення реєстрів ( z0049-07 ).

{ Пункт 16 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

17. Для обліку сертифікатів іменних цінних паперів, які виготовлені за типовою формою, до журналу додатково включається графа "наскрізний номер бланка сертифіката".

18. Облік сертифікатів іменних цінних паперів у журналі повинен провадитися у хронологічному порядку, в міру оформлення їх, у порядку зростання серії та номера сертифіката (для типової форми - і у порядку зростання наскрізного номера бланка сертифіката) в межах окремого тиражу.

19. Також у журналі слід вказувати такі дані:

- дата знищення сертифіката (крім сертифікатів, які оголошені втраченими) та номер акта про знищення сертифіката;

- підстава для погашення сертифіката (перехід прав власності, зіпсовані та інше).

20. Після закінчення використання бланків сертифікатів певного тиражу та отримання реєстроутримувачем бланків нового тиражу у цьому журналі продовжується облік бланків сертифікатів нового тиражу.

21. При переданні ведення реєстру від одного реєстроутримувача до іншого реєстроутримувача, який буде здійснювати подальше ведення реєстру власників іменних цінних паперів, разом з документами, що віднесені до системи реєстру, слід передати копію журналу обліку сертифікатів, засвідчену підписом уповноваженого представника та печаткою реєстроутримувача, який здійснював ведення реєстру, та копії таких журналів, переданих попередніми реєстроутримувачами (за наявності).

{ Пункт 21 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

22. Обіг сертифікатів іменних цінних паперів є разовим.

23. У разі отримання іменних цінних паперів реєстроутримувач у журналі обліку сертифікатів повинен:

а) перевірити, чи сертифікат, який поданий для перереєстрації на ім'я нового власника, має статус "виданого", з відповідним записом у журналі обліку сертифікатів;

б) здійснити погашення сертифіката, виписаного на ім'я власника, що передає право власності на цінні папери, шляхом надання йому статусу "погашено" з відповідним записом у журналі обліку сертифікатів;

в) оформити новий сертифікат на ім'я нового власника відповідно до вимог Положення про порядок ведення реєстрів;

г) здійснити в журналі обліку сертифікатів запис про видачу нового сертифіката та надати йому статус виданого шляхом проставлення грифа "видано".

{ Пункт 23 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

24. Записи для оформлення документів щодо обліку сертифікатів та їх бланків слід робити чорнилом, кульковою ручкою, друкарською машинкою та/або іншими засобами, які забезпечують можливість перевірити недоторканність цих записів протягом тривалого часу, встановленого для їх зберігання в архівах.

25. Дійсним є сертифікат іменних цінних паперів, виготовлений та оформлений відповідно до чинного законодавства, що має статус виданого проставленням грифу "видано" в журналі обліку сертифікатів.

{ Пункт 25 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

26. Недійсним є сертифікат, що має статус:

"погашено";

"втрачено", тобто визнаний таким у результаті непред'явлення для погашення попереднім власником, про що свідчить запис у журналі обліку сертифікатів.

Також уважається недійсним сертифікат, що не був пред'явлений реєстроутримувачу для погашення попереднім власником, якого за рішенням суду позбавлено права власності на цінні папери.

{ Пункт 26 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

27. Підставою для погашення сертифіката іменних цінних паперів можуть бути документи, за якими вимагається внесення змін до системи реєстру власників іменних цінних паперів відповідно до вимог Положення про порядок ведення реєстрів ( z0049-07 ).

{ Пункт 27 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

28. Погашення сертифікатів іменних цінних паперів виконується матеріально відповідальною особою нанесенням на сертифікат відбитку штампа "ПОГАШЕНО" та надрізанням у полі з написом "сертифікат".

29. Штамп "ПОГАШЕНО" має бути проставлений синьою, темно-синьою, фіолетовою, зеленою або червоною штемпельною фарбою, яка не втрачає своєї контрастності протягом тривалого часу.

30. Відбиток штампа проставляється на вільному від написів полі сертифіката.

31. У відбиток штампа матеріально відповідальною особою вписується, у відповідності до запису у журналі обліку сертифікатів, дата погашення сертифіката.

{ Пункт 31 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

32. В разі втрати сертифіката іменних цінних паперів власник цінних паперів повинен надати реєстроутримувачу письмову заяву про втрату сертифіката іменних цінних паперів.

33. На підставі заяви про втрату сертифіката реєстроутримувач у журналі обліку сертифікатів повинен:

а) перевірити, чи сертифікат, зазначений у заяві, має статус "виданого", з відповідним записом у журналі обліку сертифікатів;

б) надати сертифікату статус "втраченого" з відповідним записом у журналі обліку сертифікатів;

в) оформити новий сертифікат на ім'я власника відповідно до заяви про втрату сертифіката та видати його власнику;

г) здійснити у журналі обліку сертифікатів запис про видачу нового сертифіката та надати йому статус "видано".

{ Пункт 33 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

Вимоги до зберігання сертифікатів цінних паперів та їх бланків

34. Емітент та реєстратор повинні забезпечити зберігання бланків сертифікатів у спеціально обладнаних сучасними технічними засобами охорони сховищах або в металевих шафах (сейфах) з додержанням вимог, Ліцензійних умов провадження професійної діяльності на фондовому ринку - депозитарної діяльності, а саме діяльності з ведення реєстру власників іменних цінних паперів, затверджених рішенням Державної комісії з цінних паперів та фондового ринку від 26.05.2006 N 348 ( z0973-06 ), зареєстрованих в Міністерстві юстиції України 11.08.2006 за N 973/12847.

{ Пункт 34 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1951 ( z0122-11 ) від 28.12.2010 }

35. Реєстроутримувач повинен забезпечити зберігання зіпсованих бланків сертифікатів та погашених сертифікатів цінних паперів окремими пакетами, які формуються в хронологічному порядку та у відповідності до вимог, установлених чинним законодавством щодо зберігання документів суворої звітності.

36. Погашені сертифікати слід зберігати протягом трьох років від дати погашення сертифікатів.

37. У разі виявлення факту зникнення (втрати, крадіжки тощо) бланків сертифікатів у емітента або у реєстратора, а також у випадку встановлення факту підробки сертифікатів цінних паперів відповідальна особа емітента або реєстратора зобов'язана негайно вжити заходів задля їх розшуку шляхом повідомлення правоохоронних органів з зазначенням назви цінних паперів, серії та номерів викрадених бланків сертифікатів.

Одночасно з цим про факт зникнення бланків сертифікатів слід повідомити емітента та територіальні органи Державної комісії з цінних паперів та фондового ринку за місцезнаходженням емітента та реєстроутримувача.

Порядок знищення сертифікатів цінних паперів та їхніх бланків

38. Погашені сертифікати цінних паперів та зіпсовані бланки сертифікатів після закінчення терміну їх зберігання підлягають знищенню.

39. Знищення погашених сертифікатів цінних паперів та зіпсованих бланків сертифікатів у паперорізальних машинах або шляхом спалення здійснює комісія, склад якої затверджується наказом керівника реєстроутримувача.

40. До складу комісії повинні бути включені: матеріально відповідальна особа, що відповідала за збереження погашених сертифікатів цінних паперів та зіпсованих бланків сертифікатів, а також представники реєстроутримувача та емітента.

Склад комісії повинен становити не менше ніж три особи.

41. Знищення погашених сертифікатів цінних паперів та зіпсованих бланків сертифікатів оформляється відповідним актом, складеним у двох примірниках, один з яких передається емітенту, а другий залишається у реєстроутримувача.

42. Невід'ємною частиною акта повинен бути реєстр знищених сертифікатів, який повинен містити інформацію щодо серії та номера сертифіката (для типової форми - і наскрізного номера бланка сертифіката), дати його погашення або відмітку "зіпсований" для бланків сертифікатів.

Інвентаризація сертифікатів цінних паперів

43. Інвентаризація сертифікатів провадиться з метою звірення наявності бланків сертифікатів, які є на зберіганні у матеріально відповідальних осіб, з обліковими даними емітента та реєстратора.

44. Для проведення інвентаризації керівником емітента призначається комісія з інвентаризації.

Періодичність проведення інвентаризації встановлюється керівником реєстратора за погодженням з керівником емітента, але не менше одного разу на рік.

45. Інвентаризація обов'язково проводиться:

а) при зміні матеріально відповідальних осіб;

б) після стихійного лиха, пожежі;

в) після пошкодження або втрати даних обліку сертифікатів цінних паперів;

г) при встановленні фактів розкрадання сертифікатів цінних паперів;

ґ) в інших випадках, які передбачені чинним законодавством та внутрішніми документами цієї організації.

46. Матеріально відповідальна особа, що відповідає за зберігання бланків сертифікатів цінних паперів, до складу комісії не включається, але має право бути присутньою при роботі комісії.

47. За результатами інвентаризації комісія з інвентаризації складає інвентаризаційну відомість, в якій відображаються дійсний стан обліку бланків сертифікатів.

У випадку виявлення нестачі або надлишку бланків сертифікатів керівник реєстратора зобов'язаний вжити негайних заходів зі з'ясування причин їх виникнення, усунення наслідків виявлених нестач або надлишків та негайно повідомити про це Національний депозитарій України.
