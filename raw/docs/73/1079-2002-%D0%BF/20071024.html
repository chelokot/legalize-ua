КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 липня 2002 р. N 1079 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про внесення зміни до деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

У постановах Кабінету Міністрів України від 8 грудня 2000 р. N 1797 ( 1797-2000-п ) "Про голову Української частини Двосторонньої Українсько-Словацької комісії з питань національних меншин, освіти і культури", від 8 грудня 2000 р. N 1798 ( 1798-2000-п ) "Про голову Української частини Змішаної міжурядової Українсько-Румунської комісії з питань забезпечення прав осіб, які належать до національних меншин" і від 8 грудня 2000 р. N 1799 ( 1799-2000-п ) "Про голову Української частини Змішаної Українсько-Угорської комісії з питань забезпечення прав національних меншин" слова "директора Державного департаменту у справах національностей та міграції" замінити словами "Голову Державного комітету у справах національностей та міграції".

Прем'єр-міністр України А.КІНАХ
