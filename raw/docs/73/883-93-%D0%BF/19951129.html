КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 жовтня 1993 р. N 883 Київ

( Постанова втратила чинність на підставі Постанови КМ N 957 ( 957-95-п ) від 29.11.95 )

Про надання пільг Маріупольській фірмі "Азовзагальмаш"

Кабінет Міністрів України постановляє:

Звільнити Маріупольську фірму "Азовзагальмаш" концерну "Азовмаш" від сплати ввізного мита на лінію сухого емалювання та податку на добавлену вартість під час реалізації нею бартерного (товарообмінного) контракту від 22 вересня 1992 р. N 200/05763618- 20054 із Словацькою фірмою "Естап".
