Текст документа від 15.02.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 грудня 2001 р. N 581-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 91-р ( 91-2006-р ) від 15.02.2006 )

Про генерального конструктора із створення двигунів для бронетанкової техніки

1. Надати Рязанцеву Миколі Карповичу повноваження генерального конструктора із створення двигунів для бронетанкової техніки.

2. Державній комісії з питань оборонно-промислового комплексу за поданням Мінпромполітики затвердити перелік видів продукції, яка підлягає розробленню і впровадженню у виробництво та експлуатацію під керівництвом генерального конструктора із створення двигунів для бронетанкової техніки.

Мінпромполітики визначити в установленому порядку головних конструкторів з розроблення видів продукції, включених до зазначеного переліку, та її складових частин.

Прем'єр-міністр України А.КІНАХ
