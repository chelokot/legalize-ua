Про внесення змін до Указу Президента України від 21 березня 2002 року N 277

Стан: Чинний

Ідентифікатор: 1114/2007

Текст документа від 16.11.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Указу Президента України від 21 березня 2002 року N 277

Внести до Указу Президента України від 21 березня 2002 року N 277 ( 277/2002 ) "Про переліки посад військовослужбовців і працівників правоохоронних органів, що підлягають заміщенню особами вищого офіцерського (начальницького) складу, та граничних військових і спеціальних звань за цими посадами" (зі змінами, внесеними Указами від 27 червня 2003 року N 562 ( 562/2003 ), від 27 грудня 2005 року N 1846 ( 1846/2005 ), від 17 липня 2006 року N 616 ( 616/2006 ), від 20 листопада 2006 року N 986 ( 986/2006 ), від 23 серпня 2007 року N 786 ( 786/2007 ) та від 9 жовтня 2007 року N 953) ( 953/2007 ) такі зміни:

1) у примітці до додатка N 3 слова "(крім посад заступників Голови)" виключити;

2) у додатку N 4:

а) назву позиції "Заступник начальника Управління - начальник відділу охорони Президента України" викласти в такій редакції: "Заступник начальника Управління - начальник Служби охорони Президента України";

б) позицію "Заступник начальника Управління - начальник відділу охорони Прем'єр-міністра України" виключити.

Президент України В.ЮЩЕНКО

м. Київ, 16 листопада 2007 року N 1114/2007
