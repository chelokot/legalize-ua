Мінрегіонбуд; Наказ від 02.07.2007 № 76

Про внесення змін до наказу Мінбуду України від 20 березня 2006 року N 69 "Про затвердження Порядку проведення роботи з підтвердження придатності нових будівельних виробів для застосування в будівництві та Переліку нових будівельних виробів, що підлягають перевірці та підтвердженню придатності для застосування в будівництві"

Реєстрація: Мін'юст України від 11.07.2007 № 792/14059

Стан: Втратив чинність

Ідентифікатор: z0792-07

Текст документа від 02.07.2007:

МІНІСТЕРСТВО РЕГІОНАЛЬНОГО РОЗВИТКУ ТА БУДІВНИЦТВА УКРАЇНИ

НАКАЗ

02.07.2007 N 76

Зареєстровано в Міністерстві юстиції України 11 липня 2007 р. за N 792/14059

Про внесення змін до наказу Мінбуду України від 20 березня 2006 року N 69 "Про затвердження Порядку проведення роботи з підтвердження придатності нових будівельних виробів для застосування в будівництві та Переліку нових будівельних виробів, що підлягають перевірці та підтвердженню придатності для застосування в будівництві"

У зв'язку з реорганізацією Міністерства будівництва, архітектури та житлово-комунального господарства України відповідно до постанови Кабінету Міністрів України від 01.03.2007 N 323 ( 323-2007-п ) НАКАЗУЮ:

1. Внести зміни до наказу Мінбуду від 20 березня 2006 року N 69 ( z0577-06 ) "Про затвердження Порядку проведення роботи з підтвердження придатності нових будівельних виробів для застосування в будівництві та Переліку нових будівельних виробів, що підлягають перевірці та підтвердженню придатності для застосування в будівництві", зареєстрованого в Міністерстві юстиції 18 травня 2006 року за N 577/12451:

1.1. Пункт 3 цього наказу ( z0577-06 ) викласти в такій редакції:

"3. Право підпису технічного свідоцтва надати заступнику Міністра за належністю питань."

1.2. Пункт 7 цього наказу ( z0577-06 ) викласти в такій редакції:

"7. Контроль за виконанням цього наказу покласти на заступника Міністра за належністю питань."

2. У тексті Порядку проведення роботи з підтвердження придатності нових будівельних виробів для застосування в будівництві, затвердженого наказом Мінбуду від 20 березня 2006 року N 69 ( z0577-06 ), зареєстрованого в Міністерстві юстиції 18 травня 2006 року за N 577/12451, слова "Міністерство будівництва, архітектури та житлово-комунального господарства" і слово "Мінбуд" у всіх відмінках замінити словами "Міністерство регіонального розвитку та будівництва" у відповідних відмінках.

3. Управлінню технічного регулювання в будівництві (Барзилович Д.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції в порядку, установленому чинним законодавством.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Беркуту А.В.

Міністр В.Г.Яцуба
