Про зміни у складі Ради з питань створення культурно-мистецького та музейного комплексу "Мистецький арсенал"

Стан: Втратив чинність

Ідентифікатор: 208/2006-рп

Текст документа від 14.04.2010:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Розпорядження Президента

N 41/2010-рп ( 41/2010-рп ) від 02.04.2010 }

Про зміни у складі Ради з питань створення культурно-мистецького та музейного комплексу "Мистецький арсенал"

На часткову зміну пункту 2 Розпорядження Президента України від 7 жовтня 2005 року N 1191 ( 1191/2005-рп ) "Про Раду з питань створення культурно-мистецького та музейного комплексу "Мистецький арсенал":

1. Увести до складу Ради з питань створення культурно-мистецького та музейного комплексу "Мистецький арсенал" РИБАЧУКА Олега Борисовича - Главу Секретаріату Президента України, призначивши його першим заступником Голови Ради, ЧЕРНОВЕЦЬКОГО Леоніда Михайловича - голову Київської міської державної адміністрації, призначивши його заступником Голови Ради, ЛУБКІВСЬКОГО Маркіяна Романовича - Радника Президента України - Керівника Головної служби гуманітарної політики Секретаріату Президента України.

2. Затвердити у складі зазначеної Ради ЖУЛИНСЬКОГО Миколу Григоровича - директора Інституту літератури імені Т.Г.Шевченка НАН України, МОВЧАНА Павла Михайловича - голову Всеукраїнського товариства "Просвіта" імені Тараса Шевченка (за згодою), ОЛІЙНИКА Бориса Ілліча - голову Українського фонду культури (за згодою), ТАНЮКА Леоніда (Леся) Степановича - народного депутата України (за згодою).

3. Вивести зі складу Ради Омельченка О.О.

Президент України В.ЮЩЕНКО

м. Київ, 23 червня 2006 року N 208/2006-рп
