{ Постанова втратила чинність на підставі Рішення Національного банку N 803-рш від 15.12.2017 }

Про схвалення Змін до Методики розрахунку економічних нормативів регулювання діяльності банків в Україні

Відповідно до статей 7, 15, 55, 58 Закону України "Про Національний банк України" ( 679-14 ) та статей 66, 69 Закону України "Про банки і банківську діяльність" ( 2121-14 ), з метою підвищення ефективності та забезпечення стабільності діяльності банків України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Схвалити Зміни до Методики розрахунку економічних нормативів регулювання діяльності банків в Україні, схваленої постановою Правління Національного банку України від 02 червня 2009 року N 315 ( v0315500-09 ) (зі змінами), що додаються.

2. Департаменту нормативно-методологічного забезпечення банківського регулювання та нагляду (Іваненко Н.В.) довести зміст цієї постанови до відома банків України та територіальних управлінь Національного банку України для використання в роботі.

3. Контроль за виконанням цієї постанови покласти на заступника Голови Національного банку України Ткаченка О.О.

Голова І.В.Соркін
