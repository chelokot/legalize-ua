Кабінет Міністрів України; Розпорядження від 27.04.1994 № 284-р

Про дозвіл на комерційну експлуатацію літака АН-124

Стан: Втратив чинність

Ідентифікатор: 284-94-р

Текст документа від 27.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 квітня 1994 р. N 284-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1758 ( 1758-2001-п ) від 27.12.2001 )

( Із змінами, внесеними згідно з Постановою КМ N 1017 ( 1017-95-п ) від 18.12.95 )

1. Дозволити Київському державному авіаційному заводу комерційну експлуатацію протягом поточного року виготовленого ним літака Ан-124 (заводський номер 03-02) до його реалізації.

Реєстрацію літака та його допуск до польотів провести згідно з вимоогами Повітряного кодексу України та відповідними авіаційними правилами.

( Пункт 2 втратив чинність на підставі Постанови КМ N 1017 ( 1017-95-п ) від 18.12.95 )

3. Мінмашпрому забезпечити створення умов для комерційної експлуатації аеродрому Святошин і проведення прикордонного, митного та інших видів контролю.
