Про затвердження плану заходів щодо подальшого впровадження замісної підтримувальної терапії для споживачів опіоїдних ін'єкційних наркотиків

Ідентифікатор: 1002-2011-р

Текст документа від 07.07.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 жовтня 2011 р. N 1002-р Київ

Про затвердження плану заходів щодо подальшого впровадження замісної підтримувальної терапії для споживачів опіоїдних ін'єкційних наркотиків

{ Із змінами, внесеними згідно з Постановою КМ N 431 ( 431-2015-п ) від 26.06.2015 }

1. Затвердити план заходів щодо подальшого впровадження замісної підтримувальної терапії для споживачів опіоїдних ін'єкційних наркотиків, що додається.

2. Міністерству охорони здоров'я разом з Міністерством внутрішніх справ, Службою безпеки, Державною пенітенціарною службою, Державною службою з лікарських засобів, Державною службою з контролю за наркотиками, Національною академією медичних наук забезпечити виконання плану заходів, затвердженого цим розпорядженням.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 431 ( 431-2015-п ) від 26.06.2015 }

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 12 жовтня 2011 р. N 1002-р

ПЛАН ЗАХОДІВ щодо подальшого впровадження замісної підтримувальної терапії для споживачів опіоїдних ін'єкційних наркотиків

1. Вивчити світовий та вітчизняний досвід щодо виконання програм проведення замісної підтримувальної терапії для споживачів опіоїдних ін'єкційних наркотиків та подати Кабінетові Міністрів України узгоджені пропозиції із зазначених питань.

МОЗ, МВС, Держслужба соцзахворювань, Національна академія медичних наук.

IV квартал 2011 року.

2. Активізувати в установленому законодавством порядку роботу з виконання заходів, пов'язаних з проведенням замісної підтримувальної терапії для споживачів ін'єкційних опіоїдних наркотиків.

МОЗ.

Постійно.

3. Сприяти налагодженню вітчизняного виробництва лікарських препаратів, які використовуються для проведення замісної підтримувальної терапії для споживачів опіоїдних ін'єкційних наркотиків.

МОЗ, Держлікслужба, ДСКН.

I квартал 2013 року.

4. Продовжити роботу з удосконалення нормативно-правової бази, спрямовану на розширення застосування замісної підтримувальної терапії для споживачів опіоїдних ін'єкційних наркотиків, зокрема ВІЛ-інфікованих та хворих на СНІД.

МОЗ, МВС, ДСКН, ДПтС, Національна академія медичних наук.

Постійно.

5. Запропонувати сучасні методики лікування хворих на опіоїдну наркотичну залежність з доведеною на засадах доказової медицини ефективністю, які б закріплювали можливі позитивні результати проведення замісної підтримувальної терапії.

Національна академія медичних наук, МОЗ.

I квартал 2012 року.

6. Забезпечити в установленому порядку здійснення контролю за провадженням діяльності, пов'язаної з обігом наркотичних препаратів, які використовуються для проведення замісної підтримувальної терапії для споживачів опіоїдних ін'єкційних наркотиків.

ДСКН, МОЗ, МВС, СБУ.

Постійно.

7. Вивчити питання щодо створення реєстру споживачів опіоїдних ін'єкційних наркотиків, яким надаються послуги з проведення замісної підтримувальної терапії, та подати Кабінетові Міністрів України відповідні пропозиції.

МОЗ, Національна академія медичних наук.

I квартал 2013 року.

8. Видати спільний наказ про порядок взаємодії закладів охорони здоров'я, територіальних органів внутрішніх справ, органів і установ виконання покарань щодо забезпечення безперервності проведення замісної підтримувальної терапії.

МОЗ, Мін'юст, МВС, ДСКН, ДПтС.

IV квартал 2011 року.

9. Вивчити та визначити потреби у замісній підтримувальній терапії та розробити індикатори її ефективності.

МОЗ, Національна академія медичних наук.

IV квартал 2011 р. - 2012 рік.
