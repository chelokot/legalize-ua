МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

21.03.2006 N 249

Зареєстровано в Міністерстві юстиції України 21 березня 2006 р. за N 302/12176

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 1104 ( z1242-06 ) від 23.11.2006 }

Про внесення змін до наказу Держкомзв'язку України від 07.06.2002 N 120

З метою приведення нормативно-правових актів у відповідність до Закону України "Про телекомунікації" ( 1280-15 ) НАКАЗУЮ:

1. Розділ VIII Граничних тарифів на основні послуги електрозв'язку та тарифів на виплату державних пенсій та грошової допомоги, затверджених наказом Держкомзв'язку України від 07.06.2002 N 120 ( z0595-02 ), зареєстрованих у Міністерстві юстиції України 19.07.2002 за N 595/6883, вилучити.

2. Цей наказ набирає чинності з 1 квітня 2006 року.

3. Директору Державного департаменту з питань зв'язку та інформатизації Бутенку Г.Г.:

3.1. Подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3.2. Забезпечити інформування споживачів про внесені зміни до наказу через web-сайт Мінтрансзв'язку України.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Гандабуру В.Т.

Міністр В.Бондар
