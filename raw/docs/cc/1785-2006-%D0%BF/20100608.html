Про внесення змін до пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88

Стан: Втратив чинність

Ідентифікатор: 1785-2006-п

Текст документа від 08.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 грудня 2006 р. N 1785 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про внесення змін до пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88

Кабінет Міністрів України постановляє:

Внести зміни до пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) "Питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2000 р., N 4, ст. 110; 2005 р., N 50, ст. 3129; 2006 р., N 3, ст. 92, N 33, ст. 2383, N 45, ст. 3003), виклавши його у такій редакції:

"2. Установити з 18 жовтня 2006 р. граничну чисельність працівників Секретаріату Кабінету Міністрів України - 967 одиниць, патронатних служб керівництва Кабінету Міністрів - 165, з них Прем'єр-міністра України - 80, Першого віце-прем'єр-міністра - 25, віце-прем'єр-міністрів - 43, Міністра Кабінету Міністрів України - 10, Міністра у зв'язках з Верховною Радою України та іншими органами державної влади України - 7 одиниць.

Міністрові Кабінету Міністрів України під час вирішення питань щодо визначення штатної чисельності працівників Секретаріату Кабінету Міністрів України виходити з граничної кількості 1139 штатних одиниць і розміру асигнувань, передбачених державним бюджетом на оплату праці керівництва Кабінету Міністрів України, його патронатних служб та працівників Секретаріату.".

Прем'єр-міністр України В.ЯНУКОВИЧ
