МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ ДЕРЖАВНА ПОДАТКОВА АДМІНІСТРАЦІЯ УКРАЇНИ

НАКАЗ

18.08.2005 N 92/5/347

Зареєстровано в Міністерстві юстиції України 18 серпня 2005 р. за N 908/11188

Про внесення змін до спільного наказу Міністерства юстиції України та Державної податкової адміністрації України від 07.02.2003 N 9/5/59

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства юстиції N 9/5/59 ( z0107-03 ) від 07.02.2003, до якого вносились зміни }

З метою приведення нормативно-правових актів Міністерства юстиції України та Державної податкової адміністрації України, що регламентують функціонування Державного реєстру обтяжень рухомого майна, у відповідність до Закону України "Про забезпечення вимог кредиторів та реєстрацію обтяжень" від 18.11.2003 N 1255-IV ( 1255-15 ) НАКАЗУЄМО:

1. Пункт 1 спільного наказу Міністерства юстиції України та Державної податкової адміністрації України від 07.02.2003 N 9/5/59 ( z0107-03 ) "Про реєстрацію податкових застав нерухомого майна", зареєстрованого в Мін'юсті України 07.02.2003 за N 107/7428, викласти в такій редакції:

"1. Установити, що реєстрація податкових застав нерухомого майна здійснюється в Державному реєстрі обтяжень рухомого майна в порядку, установленому Законом України від 18.11.2003 N 1255-IV ( 1255-15 ) "Про забезпечення вимог кредиторів та реєстрацію обтяжень", Порядком ведення Державного реєстру обтяжень рухомого майна, затвердженим постановою Кабінету Міністрів України від 05.07.2004 N 830 ( 830-2004-п ), Інструкцією про порядок ведення Державного реєстру обтяжень рухомого майна та заповнення заяв, затвердженою наказом Міністерства юстиції України від 29.07.2004 N 73/5 (z0942-04, za942-04 ), зареєстрованим у Мін'юсті України 29.07.2004 за N 942/9541".

2. Департаменту нотаріату та реєстрації адвокатських об'єднань (Павлова Л.М.):

подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (зі змінами);

довести наказ до відома начальників Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, обласних, Київського та Севастопольського міських управлінь юстиції та забезпечити його належне застосування у роботі.

3. Департаменту забезпечення податкових зобов'язань (Чмерук М.О.) довести цей наказ до відома державних податкових адміністрацій в Автономній Республіці Крим, обласних, міст Києва та Севастополя.

4. Контроль за виконанням цього наказу покласти на заступника Міністра юстиції України Єфіменка Л.В. та заступника Голови Державної податкової адміністрації України Лекаря С.І.
