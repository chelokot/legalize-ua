Про зупинення дії постанови Кабінету Міністрів України від 5 вересня 2007 року N 1105

Стан: Втратив чинність

Ідентифікатор: 907/2007

Текст документа від 20.09.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанови Кабінету Міністрів України від 5 вересня 2007 року N 1105

{ Додатково див. Конституційне подання Президента ( n0029100-07 ) від 20.09.2007 }

Кабінетом Міністрів України 5 вересня 2007 року видано постанову N 1105 ( 1105-2007-п ) "Про вилучення пакетів акцій із статутного фонду Національної акціонерної компанії "Енергетична компанія України".

Цією постановою ( 1105-2007-п ) Міністерству палива та енергетики України доручено вилучити із статутного фонду Національної акціонерної компанії "Енергетична компанія України" та передати Фонду державного майна України для приватизації пакети акцій відкритих акціонерних товариств "Львівобленерго", "ЕК "Одесаобленерго", "Полтаваобленерго", "Прикарпаттяобленерго", "Сумиобленерго", "ЕК "Чернігівобленерго".

У зв'язку із цим слід зазначити, що належні державі пакети акцій згаданих акціонерних товариств входять до складу активів Національної акціонерної компанії "Енергетична компанія України".

Позбавлення Національної акціонерної компанії "Енергетична компанія України" зазначених активів призведе до недоотримання цією компанією економічних вигод, погіршення її платоспроможності, унеможливить виконання взятих нею зобов'язань, зокрема перед своїми кредиторами, що може мати наслідком порушення справи про її банкрутство.

Таким чином, зазначена постанова Кабінету Міністрів України ( 1105-2007-п ) створює передумови для погіршення фінансово-економічного стану і навіть банкрутства Національної акціонерної компанії "Енергетична компанія України", метою діяльності якої є створення умов для надійного та ефективного функціонування і розвитку електроенергетичного комплексу, забезпечення економічної та енергетичної безпеки держави. Це, в свою чергу, спричиняє загрозу економічній безпеці держави.

Відтак названа постанова Кабінету Міністрів України ( 1105-2007-п ) не відповідає частині першій статті 17 Конституції України ( 254к/96-ВР ), за якою забезпечення економічної безпеки держави є однією з її найважливіших функцій, порушує Закон України "Про основи національної безпеки України" ( 964-15 ), яким стале функціонування і розвиток паливно-енергетичного комплексу держави визначено одним з основних напрямів державної політики з питань національної безпеки в економічній сфері (стаття 8). Через наведене зазначена постанова суперечить також частині другій статті 8 Основного Закону України ( 254к/96-ВР ), за якою нормативно-правові акти приймаються на основі Конституції України ( 254к/96-ВР ) і повинні відповідати їй, нормам частини другої статті 6, частини другої статті 19 та частини третьої статті 113 Конституції України ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, діяти на підставі та у спосіб, що ними передбачені.

Ураховуючи наведене та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 5 вересня 2007 року N 1105 ( 1105-2007-п ) "Про вилучення пакетів акцій із статутного фонду Національної акціонерної компанії "Енергетична компанія України".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
