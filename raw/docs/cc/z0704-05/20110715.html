14.06.2005 N 211

Зареєстровано в Міністерстві юстиції України 1 липня 2005 р. за N 704/10984

Про затвердження Змін до деяких нормативно-правових актів Національного банку України

{ Із змінами, внесеними згідно з Постановою Національного банку N 174 ( z0790-11 ) від 01.06.2011 }

Відповідно до статей 7, 33 Закону України "Про Національний банк України" ( 679-14 ) та з метою вдосконалення організації касової роботи в банках України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити:

{ Підпункт 1.1 пункту 1 втратив чинність на підставі Постанови Національного банку N 174 ( z0790-11 ) від 01.06.2011 }

1.2. Зміни до Правил визначення платіжності та обміну банкнот і монет Національного банку України, затверджених постановою Правління Національного банку України від 17.11.2004 N 547 ( z1549-04 ) і зареєстрованих у Міністерстві юстиції України 06.12.2004 за N 1549/10148, що додаються ( z0705-05 ).

1.3. Зміни до Інструкції про організацію виготовлення, випуску в обіг і реалізації пам'ятних монет України та сувенірної продукції, затвердженої постановою Правління Національного банку України від 14.01.2005 N 8 ( z0124-05 ) і зареєстрованої в Міністерстві юстиції України 01.02.2005 за N 124/10404, що додаються ( z0706-05 ).

2. Визнати такою, що втратила чинність, постанову Правління Національного банку України від 07.07.94 N 129 ( v0001500-94 ) "Про затвердження Інструкції по організації емісійно-касової роботи в установах банків України".

3. Департаменту готівково-грошового обігу (Н.В.Дорофєєва) після державної реєстрації в Міністерстві юстиції України довести зміст цієї постанови до відома територіальних управлінь Національного банку України та банків України для використання в роботі.

4. Контроль за виконанням цієї постанови покласти на виконавчого директора з питань готівково-грошового обігу О.М.Толстого та директора Департаменту готівково-грошового обігу Н.В.Дорофєєву.

5. Постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

Голова В.С.Стельмах

{ Зміни до Інструкції про касові операції в банках України втратили чинність на підставі Постанови Національного банку N 174 ( z0790-11 ) від 01.06.2011 }
