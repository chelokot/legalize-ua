Кабінет Міністрів України; Розпорядження від 21.05.2008 № 740-р

Про припинення Угоди між Кабінетом Міністрів України та компанією "Венко інтернешнл лімітед" про розподіл вуглеводнів, які видобуватимуться у межах Прикерченської ділянки надр континентального шельфу Чорного моря

Стан: Втратив чинність

Ідентифікатор: 740-2008-р

Текст документа від 11.02.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 травня 2008 р. N 740-р Київ

{ Розпорядження скасовано на підставі Розпорядження КМ N 58-р ( 58-2013-р ) від 11.02.2013 }

{ Дію Розпорядження зупинено згідно з Указом Президента N 566/2008 ( 566/2008 ) від 18.06.2008 }

Про припинення Угоди між Кабінетом Міністрів України та компанією "Венко інтернешнл лімітед" про розподіл вуглеводнів, які видобуватимуться у межах Прикерченської ділянки надр континентального шельфу Чорного моря

1. У зв'язку з недотриманням вимог законодавства під час підготовки та укладення Угоди між Кабінетом Міністрів України та компанією "Венко інтернешнл лімітед" про розподіл вуглеводнів, які видобуватимуться у межах Прикерченської ділянки надр континентального шельфу Чорного моря, та з метою захисту національних інтересів відповідно до пунктів 3, 5 і 7 статті 116 Конституції України ( 254к/96-ВР ) припинити участь держави Україна у зазначеній Угоді.

2. Скасувати розпорядження Кабінету Міністрів України від 3 жовтня 2007 р. N 828 ( 828-2007-р ) "Про підписання Угоди між Кабінетом Міністрів України та компанією "Венко інтернешнл лімітед" про розподіл вуглеводнів, які видобуваються у межах Прикерченської ділянки надр континентального шельфу Чорного моря".

Прем'єр-міністр України Ю.ТИМОШЕНКО
