ЗАТВЕРДЖЕНО Рішення Державної комісії з цінних паперів та фондового ринку 13.04.2005 N 158

Зареєстровано в Міністерстві юстиції України 29 квітня 2005 р. за N 462/10742

ПОЛОЖЕННЯ про порядок скасування реєстрації випуску (випусків) інвестиційних сертифікатів пайового інвестиційного фонду

Це Положення розроблено відповідно до статей 7, 8 Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ), статті 3, розділу III Закону України "Про інститути спільного інвестування (пайові та корпоративні інвестиційні фонди)" ( 2299-14 ), Закону України "Про цінні папери та фондовий ринок" ( 3480-15 ).

{ Преамбула в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

1. Загальні положення

1.1. Відповідно до цього Положення здійснюється скасування реєстрації випуску (випусків) інвестиційних сертифікатів компанії з управління активами, проспекту емісії інвестиційних сертифікатів та анулювання свідоцтва про реєстрацію випуску інвестиційних сертифікатів у разі припинення діяльності пайового інвестиційного фонду (далі - Фонд) або прийняття Державною комісією з цінних паперів та фондового ринку (далі - Комісія) рішення про невідповідність Фонду мінімальному обсягу активів інститутів спільного інвестування (далі - ІСІ).

{ Пункт 1.1 розділу 1 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

1.2. У цьому Положенні наведені терміни вживаються у такому значенні:

припинення діяльності Фонду - ліквідація Фонду, яка здійснюється в порядку, передбаченому чинним законодавством України, з обов'язковим урахуванням особливостей, визначених Законом України "Про інститути спільного інвестування (пайові та корпоративні інвестиційні фонди)" ( 2299-14 );

комісія з припинення діяльності Фонду (далі - комісія з припинення) - колегіальний орган, створений відповідно до вимог чинного законодавства України, який виконує функції щодо припинення діяльності Фонду;

скасування реєстрації випуску (випусків) інвестиційних сертифікатів - унесення відповідного запису до реєстру випусків цінних паперів ІСІ. { Абзац четвертий пункту 1.2 розділу 1 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

{ Пункт 1.3 розділу 1 виключено на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

1.3. Скасування реєстрації випуску (випусків) інвестиційних сертифікатів Фонду здійснюється з кожного випуску окремо.

2. Перелік документів, які подаються для скасування реєстрації випуску (випусків) інвестиційних сертифікатів, проспекту емісії інвестиційних сертифікатів та анулювання свідоцтва про реєстрацію їх випуску

2.1. Для скасування реєстрації випуску (випусків) інвестиційних сертифікатів, проспекту емісії інвестиційних сертифікатів та анулювання свідоцтва про реєстрацію їх випуску, у разі ліквідації Фонду, або прийняття Комісією рішення про невідповідність Фонду мінімальному обсягу активів ІСІ компанія з управління активами подає (за кожним Фондом окремо) такі документи: { Абзац перший пункту 2.1 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

заяву про скасування реєстрації випуску (випусків) інвестиційних сертифікатів, проспекту емісії інвестиційних сертифікатів та анулювання свідоцтва про реєстрацію їх випуску, підписану головою комісії з припинення та засвідчену печаткою компанії з управління активами (додаток 1);

засвідчену в установленому чинним законодавством України порядку копію документа, що містить рішення уповноваженого органу про ліквідацію Фонду або про невідповідність Фонду мінімальному обсягу активів ІСІ; { Абзац третій пункту 2.1 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

примірники публікацій повідомлень щодо ліквідації Фонду, здійснених відповідно до законодавства; { Абзац четвертий пункту 2.1 розділу 2 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

примірники публікацій повідомлень щодо розрахунків з учасниками, здійснених відповідно до законодавства (при відкритому (публічному) розміщенні інвестиційних сертифікатів Фонду); { Абзац пункту 2.1 розділу 2 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

копії документів, що підтверджують персональне повідомлення всіх учасників про припинення діяльності Фонду, засвідчені підписом голови комісії з припинення та печаткою компанії з управління активами (у разі здійснення приватного розміщення інвестиційних сертифікатів); { Абзац шостий пункту 2.1 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

оригінал (дублікат) свідоцтва про реєстрацію випуску (випусків) інвестиційних сертифікатів; { Абзац сьомий пункту 2.1 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

оригінал проспекту (проспектів) емісії інвестиційних сертифікатів Фонду та змін до них;

баланс Фонду, звіт про фінансові результати за станом на дату прийняття рішення про ліквідацію Фонду, підтверджені висновком аудитора (аудиторської фірми) та підписом уповноваженої особи компанії з управління активами та їх печатками;

довідку про вартість чистих активів Фонду, довідку про інвестиційний портфель Фонду та довідку про фінансові інвестиції Фонду за станом на дату прийняття рішення про ліквідацію Фонду, складені відповідно до Положення про порядок визначення вартості чистих активів інститутів спільного інвестування (пайових та корпоративних інвестиційних фондів), затвердженого рішенням Комісії від 02.07.2002 N 201 ( z0606-02 ), зареєстрованого в Міністерстві юстиції України 24.07.2002 за N 606/6894;

копії ліквідаційного балансу та довідки про вартість чистих активів Фонду за станом на дату складання ліквідаційного балансу, підписані головою комісії з припинення, засвідчені печаткою компанії з управління активами;

звіт комісії з припинення про здійснені розрахунки з учасниками Фонду, підписаний всіма членами комісії з припинення, засвідчений печаткою компанії з управління активами та зберігача;

документи, що підтверджують депонування до відповідного банку грошових коштів, що залишились унаслідок неподання заявок учасниками Фонду з метою отримання розрахунків за належними їм на праві власності інвестиційними сертифікатами в межах установленого строку у разі здійснення депонування таких грошових коштів. { Абзац тринадцятий пункту 2.1 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

Звіт комісії з припинення про здійснені розрахунки з учасниками Фонду повинен містити:

інформацію, що зазначається в свідоцтві про реєстрацію випуску інвестиційних сертифікатів Фонду, а саме: загальну суму випуску інвестиційних сертифікатів; номінальну вартість інвестиційного сертифіката; кількість інвестиційних сертифікатів; форму випуску, форму існування та тип інвестиційних сертифікатів; { Абзац п'ятнадцятий пункту 2.1 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

кількість інвестиційних сертифікатів, що є в обігу на дату прийняття рішення про ліквідацію Фонду;

кількість розміщених інвестиційних сертифікатів серед фізичних та/або юридичних осіб на дату прийняття рішення про ліквідацію Фонду;

вартість чистих активів Фонду у розрахунку на один інвестиційний сертифікат за станом на дату прийняття рішення про ліквідацію;

вартість чистих активів Фонду у розрахунку на один інвестиційний сертифікат за станом на дату початку розрахунку з учасниками Фонду;

кількість учасників Фонду, з якими проведено розрахунки грошовими коштами із зазначенням грошової суми, яка була їм виплачена;

кількість інвестиційних сертифікатів, щодо яких здійснено розрахунки; { Пункт 2.1 розділу 2 доповнено абзацом згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

витрати на комісію з припинення;

суму задепонованих грошових коштів, у разі здійснення депонування.

Зазначені документи повинні бути прошиті та пронумеровані.

2.2. Для скасування реєстрації випуску (випусків), проспекту емісії інвестиційних сертифікатів Фонду та анулювання свідоцтва про реєстрацію їх випуску, у разі, якщо після реєстрації випуску (випусків) та проспекту емісії інвестиційних сертифікатів Фонду жоден із інвестиційних сертифікатів не розміщено та Комісією прийнято рішення про невідповідність Фонду мінімальному обсягу активів ІСІ та визнано випуск таким, що не відбувся, компанія з управління активами подає такі документи:

а) заяву згідно з додатком 1 до цього Положення;

б) рішення уповноваженого органу компанії з управління активами про припинення Фонду (копія протоколу або витяг з протоколу, прошитий, пронумерований, засвідчений підписом уповноваженої особи та печаткою компанії з управління активами);

в) довідку зберігача про те, що розміщення інвестиційних сертифікатів Фонду не здійснювалось;

г) довідку реєстратора (депозитарної установи) про те, що розміщення інвестиційних сертифікатів Фонду не здійснювалось;

ґ) довідку компанії з управління активами ІСІ про те, що розміщення інвестиційних сертифікатів Фонду не здійснювалось;

д) відповідний документ аудитора (аудиторської фірми) про те, що розміщення інвестиційних сертифікатів Фонду не здійснювалось;

е) баланс Фонду на останню звітну дату перед прийняттям рішення уповноваженого органу компанії з управління активами про припинення Фонду, засвідчений підписами та печатками компанії з управління активами та аудитора (аудиторської фірми);

є) оригінал (дублікат) свідоцтва про реєстрацію випуску інвестиційних сертифікатів Фонду;

ж) оригінал зареєстрованого проспекту емісії інвестиційних сертифікатів Фонду (змін до нього).

{ Розділ 2 доповнено пунктом згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

2.3. Документи, зазначені в пунктах 2.1 та 2.2 розділу 2 цього Положення, подаються до Комісії протягом 5 робочих днів з дати підписання звіту комісії з припинення про здійснення розрахунків з учасниками Фонду.

{ Пункт 2.3 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

2.4. Комісія протягом 30 днів з дати надходження до Комісії документів, зазначених в пунктах 2.1 або 2.2 розділу 2 цього Положення, здійснює розгляд зазначених документів на предмет їх відповідності вимогам чинного законодавства України. { Абзац перший пункту 2.4 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1974 ( z1180-07 ) від 25.09.2007 }

У разі відповідності поданих документів вимогам чинного законодавства України, уповноважена особа Комісії видає розпорядження про скасування реєстрації випуску (випусків) інвестиційних сертифікатів, проспекту емісії інвестиційних сертифікатів та анулювання свідоцтва про реєстрацію їх випуску (додаток 2).

У разі невідповідності поданих документів вимогам чинного законодавства України, Комісія відмовляє у скасуванні реєстрації випуску (випусків) інвестиційних сертифікатів, проспекту емісії інвестиційних сертифікатів та анулюванні свідоцтва про реєстрацію їх випуску із зазначенням порушень вимог чинного законодавства України, а також строку, протягом якого зазначені у відмові порушення необхідно усунути та подати доопрацьований пакет документів на скасування реєстрації випуску інвестиційних сертифікатів Фонду, проспекту емісії інвестиційних сертифікатів та анулювання свідоцтва про реєстрацію їх випуску відповідно до вимог цього Положення.

У разі відмови в скасуванні реєстрації випуску (випусків) інвестиційних сертифікатів, проспекту емісії інвестиційних сертифікатів та в анулюванні свідоцтва про реєстрацію їх випуску така відмова письмово доводиться до відома заявника.

За письмовим запитом заявника уповноважена особа Комісії приймає рішення щодо повернення раніше наданих оригіналів документів.

На підставі письмового запиту заявника до Комісії щодо усунення невідповідностей уповноважена особа Комісії може прийняти рішення щодо подовження строку розгляду документів.

2.5. Повідомлення учасників ринку цінних паперів України щодо скасування реєстрації випуску (випусків) інвестиційних сертифікатів, проспекту емісії інвестиційних сертифікатів та анулювання свідоцтва про реєстрацію їх випуску здійснюється Комісією шляхом опублікування у двотижневий строк з дати видання розпорядження про скасування реєстрації випуску (випусків) інвестиційних сертифікатів, проспекту емісії інвестиційних сертифікатів та анулювання свідоцтва про реєстрацію їх випуску в офіційному друкованому виданні Комісії.

2.6. Знищення викуплених бланків інвестиційних сертифікатів та невикористаних бланків інвестиційних сертифікатів здійснюється комісією з припинення на підставі розпорядження про скасування реєстрації випуску (випусків) інвестиційних сертифікатів, проспекту емісії інвестиційних сертифікатів та анулювання свідоцтва про реєстрацію їх випуску. Акт про знищення бланків інвестиційних сертифікатів, підписаний всіма членами комісії з припинення і засвідчений печаткою компанії з управління активами, надається до Комісії протягом 5 робочих днів з дати його підписання.
