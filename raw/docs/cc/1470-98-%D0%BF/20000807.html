КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 вересня 1998 р. N 1470 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1231 ( 1231-2000-п ) від 07.08.2000 )

Про контроль за проведенням "Національної лотереї"

( Із змінами, внесеними згідно з Постановою КМ N 501 ( 501-2000-п ) від 16.03.2000 )

З метою здійснення контролю за своєчасним зарахуванням належних державному бюджету коштів, отриманих від реалізації лотерейних білетів "Національної лотереї", яку організовує і проводить підприємство "Українська національна лотерея", та їх цільовим використанням Кабінет Міністрів України постановляє:

1. На часткову зміну додатка 1 до постанови Кабінету Міністрів України від 25 травня 1998 р. N 755 ( 755-98-п ) (Офіційний вісник України, 1998 р. N 22, ст. 800) збільшити граничну чисельність працівників апарату Міністерства фінансів на 3 одиниці з метою відповідного збільшення граничної чисельності працівників апарату Головного управління Державного казначейства України.

( Пункт 2 втратив чинність на підставі Постанови КМ N 501 ( 501-2000-п ) від 16.03.2000 ) 2. Взяти до відома, що операційні видатки Державного казначейства України, пов'язані з контролем за продажем лотерейних білетів "Національної лотереї" та цільовим використанням коштів, отриманих від їх реалізації, видатки на утримання працівників, що здійснюватимуть цей контроль, проводитимуться за рахунок фонду витрат "Національної лотереї".

3. Контроль за виконанням цієї постанови покласти на Міністерство фінансів.
