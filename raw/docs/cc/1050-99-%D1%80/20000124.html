Кабінет Міністрів України; Розпорядження від 07.10.1999 № 1050-р

Про призначення компанії "Казнафта" (Республіка Казахстан) уповноваженою особою з управління пакетом акцій відкритого акціонерного товариства "Херсоннафтопереробка"

Стан: Втратив чинність

Ідентифікатор: 1050-99-р

Текст документа від 24.01.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 жовтня 1999 р. N 1050-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 48-р ( 48-2000-р ) від 24.01.2000 )

1. Призначити компанію "Казнафта" (Республіка Казахстан) уповноваженою особою з управління пакетом акцій відкритого акціонерного товариства "Херсоннафтопереробка" у розмірі 50 відсотків статутного фонду плюс одна акція, що належать державі.

2. Національному агентству з управління державними корпоративними правами розробити та затвердити умови передачі та завдання з управління державними корпоративними правами відкритого акціонерного товариства "Херсоннафтопереробка".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
