НАКАЗ

04.11.2003 N 745

Зареєстровано в Міністерстві юстиції України 10 листопада 2003 р. за N 1028/8349

( Наказ втратив чинність на підставі Наказу Державної митної служби N 169 ( z0310-05 ) від 14.03.2005 )

Про внесення доповнення до наказу Державної митної служби України від 08.09.2003 N 598 "Про визначення місць митного оформлення окремих видів товарів"

Відповідно до статті 38 Митного кодексу України ( 1970-12 ) та з метою вдосконалення механізму застосування наказу Державної митної служби України від 08.09.2003 N 598 ( z0838-03 ) "Про визначення місць митного оформлення окремих видів товарів" НАКАЗУЮ:

1. Пункт 1 наказу Державної митної служби України від 08.09.2003 N 598 ( z0838-03 ) "Про визначення місць митного оформлення окремих видів товарів" після слів "Бориспільську, Бердянську й Севастопольську" доповнити словом "Миколаївську".

2. Управлінню контролю митної вартості та номенклатури (Войцещук А.Д.) й Управлінню правової роботи (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Управлінню справами (Карпенко В.П.) після державної реєстрації цього наказу забезпечити тиражування та розсилку його до митних органів.

4. Контроль за виконанням наказу покласти на заступника Голови Служби Дьоміна Ю.М.

В.о. Голови Служби М.М.Іванюк
