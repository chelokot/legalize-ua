( Наказ втратив чинність на підставі Наказу МЗЕЗ N 133-а ( z0124-96, z0117-96 ) від 24.02.96 )

Про заходи МЗЕЗ щодо забезпечення виконання Указу Президента України від 07.11.94 N 659/94

( Із змінами, внесеними згідно з Наказом МЗЕЗ N 221 ( z0295-94 ) від 06.12.94 )

( Додатково див. Наказ МЗЕЗ N 3 ( z0012-95 ) від 19.01.95 )

( Із змінами, внесеними згідно з Наказом МЗЕЗ N 71 ( z0122-95 ) від 26.04.95 )

Відповідно до Указу Президента України від 07.11.94 N 659/94 "Про облік окремих видів зовнішньоекономічних договорів (контрактів) в Україні", НАКАЗУЮ:

1. Установити, що Міністерство зовнішніх економічних зв'язків України з 22.11.94 р. здійснює облік, реєстрацію окремих видів зовнішньоекономічних договорів (контрактів), передбачених статтею 1 Указу Президента України від 07.11.94 N 659/94

2. Затвердити:

- Інструкцію про порядок оформлення Інформаційної картки зовнішньоекономічного договору (контракту) " (додаток N 1);

- форму Інформаційної картки зовнішньоекономічного договору (контракту) (додаток N 2) та форму додатку до Інформаційної картки зовнішньоекономічного договору (контракту) (додаток N 2а);

- Інструкцію про порядок оформлення Картки реєстрації-обліку зовнішньоекономічного договору (контракту) (Для службового користування) (додаток N 3) ( z0292-94 );

- форму Картки реєстрації-обліку зовнішньоекономічного договору (контракту) (додаток N 4) та форму додатку до Картки реєстрації-обліку зовнішньоекономічного договору (контракту) (додаток N 4а) ( z0292-94 );

- "Порядок здійснення обліку (реєстрації) зовнішньоекономічних договорів (контрактів) Міністерством зовнішніх економічних зв'язків України" (додаток N 5) ( z0293-94 );

- переліки товарів, зазначених у абзацах другому - п'ятому частини першої статті 1 Указу Президента України від 17.11.94 N 681/94 (додатки NN 6-9) ( z0293-94 );

- кошторис витрат МЗЕЗ України, пов'язаних з оформленням та видачею карток реєстрації-обліку зовнішньоекономічних договорів (контрактів) (додаток N 10) ( z0294-94 ).

3. Покласти обов'язки щодо здійснення обліку (реєстрації) зовнішньоекономічних договорів (контрактів) на управління нетарифного регулювання (Гупало А.П.) спільно з головним управлінням з питань зовнішньої торгівлі (С.Д. Манах), управлінням експортно-імпортного контролю (Уваров В.В), управлінням кон'юнктури та цінової інформації (Кліточенко Т.М.), юридичним управлінням (Кузнецов О.В.) та валютно-кредитним управлінням (Іваненко Ю.В.) відповідно до Порядку, затвердженого цим наказом (додаток N 5).

4. Уповноважити управління ЗЕЗ Запорізької, Луганської, Дніпропетровської та Донецької обласних Рад народних депутатів здійснювати реєстрацію зовнішньоекономічних договорів (контрактів), укладених суб'єктами підприємницької діяльності цих регіонів, якщо облікова вартість цих договорів (контрактів) не перевищує одного мільйона п'ятисот тисяч доларів США крім тих, що підпадають під дію Декретів Кабінету Міністрів України від 26.12.1992 року N 16-92 та від 31.12.1992 року N 25-92 та експорт яких здійснюється відповідно до конкретних заходів з метою запобігання антидемпінгових процедур, зазначених у переліку, який міститься в додатку 8 цього наказу. ( Абзац перший пункту 4 із змінами, внесеними згідно з Наказом МЗЕЗ N 71 ( z0122-95 ) від 28.04.95 )

Уповноважити управління ЗЕЗ обласних, Київської та

Севастопольської міських Рад народних депутатів (крім зазначених в частині 1 цього пункту) здійснювати реєстрацію зовнішньоекономічних договорів (контрактів), укладених суб'єктами підприємницької діяльності цих регіонів, якщо облікова вартість цих договорів (контрактів) не перевищує п'ятисот тисяч доларів США крім тих, що підпадають під дію Декретів Кабінету Міністрів України від 26.12.1992 року N 16-92 та від 31.12.1992 року N 25-92 та експорт яких здійснюється відповідно до конкретних заходів з метою запобігання антидемпінгових процедур, зазначених у переліку, який міститься в додатку 8 цього наказу. ( Абзац другий пункту 4 із змінами, внесеними згідно з Наказом МЗЕЗ N 71 ( z0122-95 ) від 28.04.95 )

Всім управлінням ЗЕЗ, зазначеним у цьому пункті, щомісячно до 20 числа відповідного місяця надавати МЗЕЗ повну інформацію стосовно здійснення реєстрації по встановленій МЗЕЗ формі.

Головному управлінню з питань зовнішньої торгівлі (Манах С.Д.), управлінню інформації та стратегічних досліджень (Загорняк О.В.) разом з регіональними управліннями ЗЕЗ в тижневий термін розробити та подати на затвердження форму, зазначену в частині третій цього пункту, та порядок надання регіональними управліннями ЗЕЗ відповідної інформації до МЗЕЗ.

(Пункт 4 в редакції Наказу МЗЕЗ N 221 ( z0295-94 ) від 06.12.94 ) 5. Головному управлінню з питань зовнішньої торгівлі (С.Д.Манах), управлінню нетарифного регулювання (А.П. Гупало), управлінню експортно-імпортного контролю (В.В. Уваров) спільно з юридичним управлінням (Кузнєцов О.В.) направити затверджені документи, передбачені у абзацах 1 - 4 пункту 2 цього наказу до Мінюсту України для державної реєстрації.

6. Головному управлінню з питань зовнішньої торгівлі (С.Д.Манах) у десятиденний термін, забезпечити проведення наради з керівництвом регіональних управлінь ЗЕЗ з метою ознайомлення їх з порядком реєстрації зовнішньоекономічних договорів (контрактів).

7. Управлінню праці та соціального захисту (Л.О.Романенко) до 18.11.94 р. розглянути питання щодо введення додаткових одиниць у штатний розклад управлінь, які здійснюють реєстрацію контрактів.

8. Управлінню інформації та стратегічних досліджень (О.В.Загорняк) до 25.11.94 організувати необхідне програмне та інформаційне забезпечення процесу реєстрації.

9. Управлінню справами (Павлов С.М.), режимно-секретному відділу (Гудима А.П.) за заявками управлінь, які здійснюють реєстрацію контрактів та тих, що задіяні у цій роботі, організувати до 25.11.94 р. виготовлення відповідних печаток для міністерства і обласних управлінь ЗЕЗ, необхідної кількості бланків реєстраційних та інформаційних карток.

10. Управлінню фінансування, обліку та контролю (П.І.Закусило) разом з управлінням справами (Павлов С.М.), економічним управлінням (Главацький В.О.) і юридичним управлінням (Кузнецов О.В.) скласти кошторис витрат на реєстрацію та забезпечити необхідне фінансування всіх робіт та послуг, пов'язаних із здійсненням реєстрації контрактів в порядку, передбаченому чинним законодавством України.

11. Установити, що Картки реєстрації обліку зовнішньоекономічних договорів (контрактів) видані у період з 22.11.1994 р. до 31.12.1994 р. включно, є дійсними для митного оформлення вантажів на строк дії відповідного контракту, але не пізніше ніж до 31 грудня 1995 року включно.

(Пункт 11 в редакції Наказу МЗЕЗ N 221 ( z0295-94 ) від 06.12.94 ) 12. Контроль за виконанням цього наказу покласти на Першого заступника міністра Подолєва І.В.

Міністр С.Г.Осика Додаток N 1

ІНСТРУКЦІЯ

про порядок заповнення Інформаційної картки зовнішньоекономічного договору (контракту)

Дана Інструкція визначає єдиний порядок оформлення Інформаційної картки зовнішньоекономічного договору (контракту) (далі - Інформаційна картка) і розрахована для суб'єктів підприємницької діяльності в Україні.

1. Інформаційна картка оформлюзться за встановленою формою.

2. Інформаційна картка має бути надрукована друкарським способом у відповідності з формою документа. Скорочення слів повинно відповідати вимогам діючих стандартів України.

3. Назви реквізитів та їх коди повинні відповідати загальноукраїнським класифікаторам техніко-економічної інформації (ЗКТЕІ). Забезпечення ЗКТЕІ виконується органами Держстандарту України через головні організації міністерств, відомств, Кабінету міністрів України.

Порядок отримання кодів ЗКТЕІ встановлюється діючими положеннями про введення в дію ЗКТЕІ.

4. Коди реквізитів, що підлягають обробці засобами обчислювальної техніки, розташовуються праворуч від назви.

5. У складі реквізиту 1 зазначається повна назва організації-експортера, юридична адреса організації, телефон, телефакс, код за Загальноукраїнським класифікатором підпризмств і організацій (ЗУКПО), номери рахунків та Банки експортера (повна назва банку, поштова адреса, МФО).

6. У складі реквізиту 2 вказується назва іноземної організації, що є контрагентом згідно з контрактом, (назва організації вказується на мові краини реєстрації іноземнои організаціи), юридична адреса організаціи, телефон, телефакс, номер рахунку т Банк імпортера (повна назва банку, поштова адреса, МФО/Код).

7. У реквізиті 3 вказується 9-значний код експортного товару за Товарною номенклатурою зовнішньоекономічної діяльності (ТН ЗЕД).

8. У реквізиті 4 вказується одиниця виміру експортного товару та її код.

9. У реквізиті 5 зазначається загальна кількість експортного товару, вказаного в контракті.

10. У реквізиті 6 визначається вартість експортного товару у валюті контракту.

11. У реквізиті 7 вказується вартість експортного товару в доларах США.

12. У реквізиті 8 зазначається назва краинї, куди буде поставлено товар і цифровий код за Загальноукраїнським класифікатором країн світу (ЗУККС).

13. У реквізиті 9 вказується повне або коротке найменування країни, на території якої знаходиться фірма чи організація іноземного партнера і код країни за ЗУККС.

14. У складі реквізиту 10 зазначається назва країни - виробника товару та її код за ЗУККС.

15. У реквізиті 11 зазначається валюта контракту та її код.

16. У реквізиті 12 зазначається валюта розрахунку та її код.

17. У реквізиті 13 визначається базис експортних поставок відповідно до ІНКОТЕРМС в редакціи 1990 року.

18. У реквізиті 14 вказується повна назва характеру угоди, умови розрахунку та код операції.

19. У реквізиті 15 вказузться прізвище, ім'я та по батькові керівника організації-заявника, посада, його паспортні дані (серія, номер, дата видачі, ким), дата підпису та печатка.

20. У реквізиті 16 вказується податкова інспекція організації-заявника (її адреса, телефон).

21. У реквізиті 17 вказуються особливі умови щодо митного оформлення експортного товару, та номери реєстраційних карток, що раніше були видані суб'єкту і по яких розпочалися (з поміткою "р" в кінці номера реєстраційної картки) зовнішньоекономічної операції або (з поміткою "к" в кінці номера реєстраційної картки) зовнішньоекономічні операції, по яких закінчилися.

Резстраційні картки, по яких зовнішньоекономічні операції суб'єктом підпризмницької діяльності не виконувались на момент реєстрації чергового контракту, не вказуються.

22. У реквізиті 18 вказується 9-значний код імпортного товару за ТН ЗЕД.

23. У реквізиті 19 вказується одиниця виміру імпортного товару та її код.

24. У реквізиті 20 зазначається загальна кількість імпортного товару, вказаного в контракті.

25. У реквізиті 21 визначається вартість імпортного товару у валюті контракту.

26. У реквізиті 22 вказується вартість імпортного товару в доларах США.

27. У реквізиті 23 зазначається назва краини, куди буде поставлено товар, і цифровий код за ЗУККС.

28. У реквізиті 24 вказується повне або коротке найменування країни, на території якої знаходиться фірма чи організація іноземного партнера, і код країни за ЗУККС.

29. У складі реквізиту 25 зазначається назва країни - виробника товару та ии код за ЗУККС.

30. У реквізиті 26 зазначається валюта контракту та її код.

31. У реквізиті 27 визначається базис імпортних поставок відповідно ІНКОТЕРМС в редакції 1990 року.

32. У разі реалізації товару за валюту заявник заповнює реквізити 1-17 інформаційної картки.

33. У разі здійснення експорту в рамках бартерних (товарообмінних) операцій або операцій з зустрічною торгівлею заявник заповнює реквізити 1-27 інформаційної картки. ІНФОРМАЦІЙНА КАРТКА РЕЄСТРАЦІЇ ЗОВНІШНЬОЕКОНОМІЧНОГО ДОГОВОРУ (КОНТРАКТУ) Контракт N від
