Про затвердження порядків використання коштів, передбачених у Державному бюджеті України Міністерству культури і туризму за деякими програмами

{ Із змінами, внесеними згідно з Наказом Міністерства культури і туризму N 8 ( z0215-08 ) від 03.03.2008 Наказом Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

З метою підвищення ефективності використання бюджетних коштів НАКАЗУЮ:

{ Преамбула в редакції Наказу Міністерства культури і туризму N 8 ( z0215-08 ) від 03.03.2008 }

1. Затвердити такі, що додаються:

1.1. Порядок використання коштів державного бюджету на поповнення експозицій музеїв та репертуарів театрів, концертних та циркових організацій.

{ Підпункт 1.1 пункту 1 в редакції Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

1.2. Порядок використання коштів державного бюджету на фінансову підтримку гастрольної діяльності вітчизняних виконавців ( z0208-07 );

1.3. Порядок використання коштів державного бюджету на здійснення заходів з відтворення культури національних меншин ( z0209-07 );

1.4. Порядок використання коштів державного бюджету на здійснення заходів щодо встановлення культурних зв'язків з українською діаспорою ( z0210-07 );

1.5. Порядок використання коштів державного бюджету на здійснення заходів з виявлення та підтримки творчо обдарованих дітей та молоді ( z0211-07 );

1.6. Порядок використання коштів державного бюджету на забезпечення розвитку та застосування української мови ( z0212-07 );

1.7. Порядок використання коштів державного бюджету на здійснення заходів Всеукраїнського товариства "Просвіта" ( z0213-07 );

1.8. Порядок використання коштів державного бюджету на заходи щодо запобігання незаконному переміщенню культурних цінностей через державний кордон України та сприяння їх поверненню державам, яким вони належали ( z0214-07 ).

2. Контроль за виконанням наказу покласти на першого заступника Міністра В.В.Корнієнка.

Зареєстровано в Міністерстві юстиції України 7 березня 2007 р. за N 207/13474

ПОРЯДОК використання коштів державного бюджету на поповнення експозицій музеїв та репертуарів театрів, концертних та циркових організацій

{ Заголовок Порядку в редакції Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

{ У тексті Порядку слова та абревіатуру "Міністерству культури і туризму України (далі - МКТ)" замінено словами "Міністерству культури України" у відповідних відмінках згідно з Наказом Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

1. Загальні положення

1.1. Цей Порядок визначає механізм використання коштів, передбачених Міністерству культури України у Державному бюджеті України за загальним фондом за бюджетною програмою 1801150 "Поповнення експозицій музеїв та репертуарів театрів, концертних та циркових організацій", на поповнення експозицій музеїв та репертуарів театрів, концертних та циркових організацій (далі - бюджетні кошти). { Абзац перший пункту 1.1 розділу 1 в редакції Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

Головний розпорядник бюджетних коштів - Міністерство культури України.

Виконавцем заходів може бути переможець процедури закупівлі робіт (послуг) чи підприємство, установа та організація, віднесені до сфери управління Міністерства культури України.

2. Мета Порядку та напрями використання бюджетних коштів

2.1. Мета Порядку полягає у забезпеченні прозорої та ефективної процедури використання бюджетних коштів.

2.2. Бюджетні кошти спрямовуються на:

придбання творів образотворчого мистецтва для поповнення музейних фондів;

придбання творів драматичного мистецтва для поповнення репертуарів драматичних театрів;

придбання творів музичного мистецтва для поповнення репертуарів музичних театрів та концертних організацій;

створення нових вистав, концертних та циркових програм за державним замовленням.

{ Абзац шостий пункту 2.2 розділу 2 виключено на підставі Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

3. Вимоги щодо використання бюджетних коштів

3.1. Бюджетні кошти використовуються Міністерством культури України у межах відповідних бюджетних призначень, установлених Законом України про Державний бюджет України на відповідний рік, згідно із затвердженим Міністерством культури України Планом заходів щодо придбання творів образотворчого, драматичного, музичного мистецтва, створення нових вистав, концертних та циркових програм (далі - План заходів), з урахуванням:

заявок, що подані підприємствами, установами чи організаціями;

рішень суду, а також виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державної казначейської служби України, у разі їх відповідності паспорту бюджетної програми; { Абзац третій пункту 3.1 розділу 3 в редакції Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється виконавцем в установленому законодавством порядку. { Пункт 3.1 розділу 3 доповнено новим абзацом четвертим згідно з Наказом Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

3.2. У разі оновлення підприємствами, установами чи організаціями, що віднесені до сфери управління Міністерства культури України, вистав, концертних та циркових програм костюмами та реквізитом, видатки на які здійснюються з державного бюджету, за постановами колегії Міністерства культури України відповідним наказом Міністерства культури України затверджується План заходів.

У разі потреби до Плану заходів у встановленому порядку вносяться зміни.

Підставою для включення конкретних заходів до Плану заходів є завдання, визначені державними програмами, актами законодавства України, дорученнями Президента України, Кабінету Міністрів України, рішеннями колегії та наказами Міністерства культури України.

На здійснення заходів у кожному окремому випадку Міністерством культури України видається наказ, у якому визначаються: назва заходу, його виконавець, дата і місце проведення, сума витрат на проведення заходу.

До наказу додається кошторис витрат на підготовку та проведення заходу, затверджений виконавцем за погодженням Міністерства культури України.

У разі виникнення потреби Міністерство культури України може в установленому порядку вносити зміни до наказу та за згодою виконавця - до кошторису витрат на підготовку й проведення заходу.

3.3. За рішеннями колегії Міністерства культури України відповідним наказом Міністерства культури України затверджується План заходів, видатки на які здійснюються з державного бюджету.

Підставою для включення конкретних заходів до Плану заходів є завдання, визначені державними програмами, актами законодавства України, дорученнями Президента України, Кабінету Міністрів України, постановами колегії та наказами Міністерства культури України.

Заходи здійснюються виконавцями.

На здійснення заходів у кожному окремому випадку Міністерством культури України видається наказ, у якому визначаються: назва заходу, його виконавець, дата і місце проведення, сума витрат на проведення заходу.

З виконавцем заходу укладається державний контракт.

До державного контракту додається кошторис витрат на підготовку та проведення заходу, затверджений виконавцем за погодженням Міністерства культури України.

У разі виникнення потреби Міністерство культури України може в установленому порядку вносити зміни до наказу та за згодою виконавця - до державного контракту та кошторису витрат на підготовку й проведення заходу.

До державного контракту можуть включатися такі вимоги: { Абзац пункту 3.3 розділу 3 в редакції Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

можливість коригування визначеної в ньому суми у разі зменшення бюджетних призначень; { Абзац пункту 3.3 розділу 3 в редакції Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

забезпечення надання послуг, передбачених контрактом, до закінчення календарного року в повному обсязі; { Абзац пункту 3.3 розділу 3 в редакції Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

застосування штрафних санкцій за невиконання або несвоєчасне виконання переможцем процедури закупівлі зобов'язань. { Абзац пункту 3.3 розділу 3 в редакції Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

3.4. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04 ), зареєстрованого в Мін'юсті 10.06.2004 за N 716/9315 (із змінами).

{ Пункт 3.5 розділу 3 виключено на підставі Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

3.5. Виконавці дотримуються положень законодавства щодо попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти, встановлених Бюджетним кодексом України ( 2456-17 ) та постановою Кабінету Міністрів України від 09.10.2006 N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (із змінами).

Головний розпорядник та виконавці забезпечують цільове та ефективне використання бюджетних коштів.

{ Пункт 3.5 розділу 3 в редакції Наказу Міністерства культури N 22 ( z0428-11 ) від 21.03.2011 }

4. Звітність про використання бюджетних коштів та контроль за їх витрачанням

4.1. Міністерство культури України відповідно до Плану заходів затверджує результативні показники щодо використання бюджетних коштів з поквартальною розбивкою та подає їх у двотижневий строк до Мінфіну після затвердження розпису державного бюджету.

Інформацію про виконання зазначених показників виконавці надсилають у тижневий строк після закінчення кварталу Міністерству культури України для її узагальнення та подання Мінфіну щокварталу і за результатами їх виконання за одинадцять місяців.

4.2. Складання та подання фінансової і бюджетної звітності, звітів про виконання паспортів бюджетних програм, а також контроль за цільовим та ефективним витрачанням бюджетних коштів здійснюються в установленому законодавством порядку.

Інформація про виконання Плану заходів подається Міністерством культури України щопівроку до Мінфіну.

Виконавці відповідають за цільове використання бюджетних коштів, а головний розпорядник контролює витрачання бюджетних коштів згідно з чинним законодавством.
