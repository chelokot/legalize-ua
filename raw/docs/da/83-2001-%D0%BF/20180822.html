Про вдосконалення державного нагляду за станом підготовки та дипломуванням моряків

Стан: Втратив чинність

Текст документа від 22.08.2018:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 січня 2001 р. N 83 Київ

Про вдосконалення державного нагляду за станом підготовки та дипломуванням моряків

{ Із змінами, внесеними згідно з Постановами КМ N 622 ( 622-2013-п ) від 21.08.2013 N 1095 ( 1095-2017-п ) від 06.09.2017 }

На виконання вимог Міжнародної конвенції з підготовки та дипломування моряків і несення вахти ( 995_053 ) та Кодексу торговельного мореплавства ( 176/95-ВР ) і з метою здійснення ефективного нагляду за функціонуванням національної системи підготовки і дипломування моряків Кабінет Міністрів України постановляє:

1. Покласти на Державну службу морського та річкового транспорту виконання передбачених Міжнародною конвенцією з підготовки та дипломування моряків і несення вахти та визначених статтями 10 і 51 Кодексу торговельного мореплавства функцій щодо здійснення державного нагляду і загального керівництва з питань підготовки та дипломування моряків.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1095 ( 1095-2017-п ) від 06.09.2017 }

2. Погодитися з пропозиціями Міністерства транспорту про:

{ Абзац другий пункту 2 виключено на підставі Постанови КМ N 622 ( 622-2013-п ) від 21.08.2013 }

{ Абзац третій пункту 2 виключено на підставі Постанови КМ N 622 ( 622-2013-п ) від 21.08.2013 }

утворення державної організації - Інспекції з питань підготовки та дипломування моряків (далі - інспекція) та її представництв (філій, відділень) у відповідних регіонах України і затвердження положення про цю інспекцію, передбачивши, що до її компетенції належить підтвердження дипломів, кваліфікаційних свідоцтв та інших документів моряків, визначених законодавством.

3. Установити, що дипломи, кваліфікаційні свідоцтва та інші документи, видані морякам після набрання чинності цією постановою без підтвердження інспекцією, є недійсними.

4. Міністерству економіки за поданням Міністерства транспорту затвердити розміри плати за підтвердження кваліфікації моряків.

5. Міністерству транспорту внести в місячний термін Кабінету Міністрів України пропозиції щодо приведення нормативно-правових актів у відповідність з Міжнародною конвенцією з підготовки та дипломування моряків і несення вахти, Кодексом торговельного мореплавства та цією постановою.

6. Ця постанова набирає чинності з 1 квітня 2001 року.
