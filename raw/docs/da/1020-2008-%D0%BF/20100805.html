Про закупівлю будівельно-монтажних робіт з реконструкції Національного спортивного комплексу "Олімпійський"

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 листопада 2008 р. N 1020 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про закупівлю будівельно-монтажних робіт з реконструкції Національного спортивного комплексу "Олімпійський"

Кабінет Міністрів України постановляє:

Відповідно до пункту 6 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 p., N 80, ст. 2692), - у редакції постанови Кабінету Міністрів України від 19 листопада 2008 р. N 1017 ( 1017-2008-п ), визначити будівельно-монтажні роботи з реконструкції Національного спортивного комплексу "Олімпійський" специфічними з урахуванням їх унікальності та складності будови, стислих строків реалізації проекту згідно з наданими державою Спілці європейських футбольних асоціацій (УЄФА) гарантіями.

Установити, що закупівля зазначених робіт здійснюється на основі показників схваленого розпорядженням Кабінету Міністрів України від 19 листопада 2008 р. N 1456 ( 1456-2008-р ) техніко-економічного обґрунтування реконструкції Національного спортивного комплексу "Олімпійський" (м. Київ) за процедурою закупівлі в одного учасника.

Прем'єр-міністр України Ю.ТИМОШЕНКО
