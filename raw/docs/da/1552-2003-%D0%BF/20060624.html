{ Постанова втратила чинність на підставі Постанови КМ N 865 ( 865-2006-п ) від 24.06.2006 }

Про внесення змін до переліку автомобільних доріг України загального користування державного значення

Кабінет Міністрів України постановляє:

Внести до переліку автомобільних доріг України загального користування державного значення, затвердженого постановою Кабінету Міністрів України від 6 квітня 1998 р. N 455 ( 455-98-п ) "Про класифікацію автомобільних доріг та перелік автомобільних доріг України державного значення" (Офіційний вісник України, 1998 р., N 14, ст. 538; 2001 р., N 9, ст. 363; 2002 р., N 34, ст. 1609), зміни, що додаються.
