Кабінет Міністрів України; Розпорядження від 06.04.2011 № 281-р

Про встановлення строку виконання операцій з виготовлення заготовок колін головних циркулярних трубопроводів на митній території України

Стан: Втратив чинність

Ідентифікатор: 281-2011-р

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 квітня 2011 р. N 281-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання операцій з виготовлення заготовок колін головних циркулярних трубопроводів на митній території України

1. Відповідно до частини третьої статті 232 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей установити строк виконання операцій з виготовлення заготовок колін головних циркулярних трубопроводів за кодом згідно з УКТЗЕД 7307 93 91 00 ( 2371в-14 ) на митній території України 120 днів.

2. Установити, що розпочаті та не завершені на момент набрання чинності цим розпорядженням операції з виготовлення заготовок колін головних циркулярних трубопроводів виконуються у строк, передбачений пунктом 1 цього розпорядження.

3. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України М.АЗАРОВ
