Кабінет Міністрів України; Постанова від 12.07.2005 № 568

Про управління корпоративними правами держави щодо публічного акціонерного товариства "Науково-дослідний інститут прогресивних наукових та технічних досліджень "Вектор" і визнання таким, що втратив чинність, пункту 1 постанови Кабінету Міністрів України від 18 лютого 2004 р. N 183

Стан: Чинний

Ідентифікатор: 568-2005-п

Текст документа від 09.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 липня 2005 р. N 568 Київ

Про управління державними корпоративними правами відкритого акціонерного товариства "Науково-дослідний інститут "Вектор" і визнання таким, що втратив чинність, пункту 1 постанови Кабінету Міністрів України від 18 лютого 2004 р. N 183

{ Із змінами, внесеними згідно з Постановою КМ N 912 ( 912-2011-п ) від 31.08.2011 }

Кабінет Міністрів України постановляє:

1. Передати Міністерству охорони навколишнього природного середовища повноваження з управління державними корпоративними правами відкритого акціонерного товариства "Науково-дослідний інститут "Вектор".

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 912 ( 912-2011-п ) від 31.08.2011 }

2. Міністерству охорони навколишнього природного середовища визначити у місячний строк представників Міністерства та укласти з ними договір доручення на виконання функцій з управління пакетом акцій відкритого акціонерного товариства "Науково-дослідний інститут "Вектор".

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 912 ( 912-2011-п ) від 31.08.2011 }

3. Визнати таким, що втратив чинність, пункт 1 постанови Кабінету Міністрів України від 18 лютого 2004 р. N 183 ( 183-2004-п ) "Про управління державними корпоративними правами Національної акціонерної компанії "Надра України" і внесення змін до деяких постанов Кабінету Міністрів України" (Офіційний вісник України, 2004 р., N 7, ст. 402).
