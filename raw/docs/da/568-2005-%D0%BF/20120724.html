Текст документа від 24.07.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 липня 2005 р. N 568 Київ

Про управління корпоративними правами держави щодо публічного акціонерного товариства "Науково-дослідний інститут прогресивних наукових та технічних досліджень "Вектор" і визнання таким, що втратив чинність, пункту 1 постанови Кабінету Міністрів України від 18 лютого 2004 р. N 183

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 636 ( 636-2012-п ) від 18.07.2012 }

{ Із змінами, внесеними згідно з Постановами КМ N 912 ( 912-2011-п ) від 31.08.2011 N 636 ( 636-2012-п ) від 18.07.2012 }

Кабінет Міністрів України постановляє:

1. Передати Міністерству екології та природних ресурсів повноваження з управління корпоративними правами держави щодо публічного акціонерного товариства "Науково-дослідний інститут прогресивних наукових та технічних досліджень "Вектор".

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 912 ( 912-2011-п ) від 31.08.2011; в редакції Постанови КМ N 636 ( 636-2012-п ) від 18.07.2012 }

{ Пункт 2 виключено на підставі Постанови КМ N 636 ( 636-2012-п ) від 18.07.2012 }

3. Визнати таким, що втратив чинність, пункт 1 постанови Кабінету Міністрів України від 18 лютого 2004 р. N 183 ( 183-2004-п ) "Про управління державними корпоративними правами Національної акціонерної компанії "Надра України" і внесення змін до деяких постанов Кабінету Міністрів України" (Офіційний вісник України, 2004 р., N 7, ст. 402).
