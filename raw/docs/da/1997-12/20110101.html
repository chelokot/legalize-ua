( Зупинено дію Постанови ВР згідно з Декретом N 18-92 від 26.12.92, ВВР, 1993, N 10, ст. 82 )

Про порядок введення в дію Закону України "Про акцизний збір"

( Відомості Верховної Ради України (ВВР), 1992, N 12, ст. 173 )

( Із змінами, внесеними згідно з Постановою ВР N 2148-XII ( 2148-12 ) від 21.02.92, ВВР, 1992, N 21, ст.298 )

Верховна Рада України постановляє:

1. Ввести в дію Закон України "Про акцизний збір" ( 1996-12 ) з моменту його прийняття.

2. Затвердити перелік товарів (продукції), по яких сплачується акцизний збір, та його ставки згідно з додатком.

Акцизний збір справляється з обороту з продажу на внутрішньому ринку України підакцизних товарів (продукції), відвантажених після 1 січня 1992 року.

3. Кабінету Міністрів України у двотижневий строк затвердити Положення про акцизний збір.
