Про затвердження Положення про Державну інспекцію з контролю якості сільськогосподарської продукції та моніторингу її ринку

Текст документа від 20.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 січня 2004 р. N 65 Київ

Про затвердження Положення про Державну інспекцію з контролю якості сільськогосподарської продукції та моніторингу її ринку

{ Із змінами, внесеними згідно з Постановами КМ N 849 ( 849-2009-п ) від 23.07.2009 N 346 ( 346-2011-п ) від 28.03.2011 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність одночасно з набранням чинності Указом Президента ( 459/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

2. Призначити головою Державної інспекції з контролю якості сільськогосподарської продукції та моніторингу її ринку Білого Олександра Івановича.

{ Пункт 3 втратив чинність одночасно з набранням чинності Указом Президента ( 459/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

{ Пункт 4 втратив чинність одночасно з набранням чинності Указом Президента ( 459/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 22
