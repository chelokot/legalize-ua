ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

ПОСТАНОВА

06.03.2004 N 18

Про структуру і чисельність Секретаріату Центральної виборчої комісії та автогосподарства Центральної виборчої комісії

( Зміни до додатків 1, 2 див. в Постановах Центральної виборчої комісії N 26 ( v0026359-04 ) від 25.03.2004 N 44 ( v0044359-04 ) від 21.04.2004 N 100 ( v0100359-04 ) від 04.06.2004 N 130 ( v0130359-04 ) від 23.06.2004 )

З метою вдосконалення організації роботи, спрямованої на здійснення Комісією повноважень, передбачених чинним законодавством, та відповідно до статей 11, 12 та 27 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ) Центральна виборча комісія постановляє:

1. Затвердити структуру і чисельність Секретаріату Центральної виборчої комісії та автогосподарства Центральної виборчої комісії (додатки 1, 2*).

2. Управлінню планування та фінансового контролю Секретаріату Комісії відповідно до затвердженої структури і чисельності Секретаріату Центральної виборчої комісії та автогосподарства Комісії підготувати штатний розпис Секретаріату та автогосподарства Центральної виборчої комісії для затвердження його Комісією.

3. Постанову Центральної виборчої комісії від 17 березня 2000 року N 38 ( v0038359-00 ) "Про структуру і чисельність Секретаріату та автогосподарства Центральної виборчої комісії" та постанову Центральної виборчої комісії від 8 листопада 2001 року N 45 ( v0045359-01 ) "Про внесення змін до додатків 1 та 2 постанови Центральної виборчої комісії "Про структуру і чисельність Секретаріату та автогосподарства Центральної виборчої комісії" від 17 березня 2000 року N 38"" вважати такими, що втратили чинність.
