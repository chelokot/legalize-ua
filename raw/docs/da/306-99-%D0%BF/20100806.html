Про заступників Уповноваженого Кабінету Міністрів України з виконання Угоди між Урядом України та Урядом Республіки Молдова про спільне використання та охорону прикордонних вод

Стан: Втратив чинність

Ідентифікатор: 306-99-п

Текст документа від 06.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 1999 р. N 306 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 638 ( 638-2010-п ) від 28.07.2010 }

Про заступників Уповноваженого Кабінету Міністрів України з виконання Угоди між Урядом України та Урядом Республіки Молдова про спільне використання та охорону прикордонних вод

( Із змінами, внесеними згідно з Постановою КМ N 956 ( 956-2004-п ) від 28.07.2004 )

Кабінет Міністрів України постановляє:

Затвердити начальника Дністровського басейнового управління водними ресурсами річок Дністра, Пруту і Серету Прачука Олега Михайловича та начальника Одеського обласного виробничого управління по водному господарству цього Комітету Бузіяна Георгія Дмитровича заступниками Уповноваженого Кабінету Міністрів України з виконання Угоди між Урядом України та Урядом Республіки Молдова про спільне використання та охорону прикордонних вод ( 498_051 ), увільнивши від цих обов'язків Незвинського Олександра Федоровича та Віру Михайла Йосиповича.

( Постанова із змінами, внесеними згідно з Постановою КМ N 956 ( 956-2004-п ) від 28.07.2004 )
