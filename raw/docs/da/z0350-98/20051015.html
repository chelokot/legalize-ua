Текст документа від 15.10.2005:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

N 181 від 11.05.98 Зареєстровано в Міністерстві м.Київ юстиції України 27 травня 1998 р. vd980511 vn181 за N 350/2790

( Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 559 ( z1133-05 ) від 16.09.2005 )

Про затвердження Тарифів на перевезення вантажобагажу залізничним транспортом у внутрішньодержавному сполученні

( Із змінами, внесеними згідно з Наказом Міністерства транспорту N 248 ( z0411-98 ) від 26.06.1998 )

Згідно з постановою Кабінету Міністрів України від 26 січня 1998 р. N 96 ( 96-98-п ) "Про внесення змін та доповнень до постанови Кабінету Міністрів України від 25 грудня 1996 р. N 1548" НАКАЗУЮ:

1. Затвердити Тарифи на перевезення вантажобагажу залізничним транспортом у внутрішньодержавному сполученні, що додаються.

2. Укрзалізниці (Макаренко М.В.) та начальникам залізниць України забезпечити своєчасне введення в дію Тарифів та правильність їх застосування і проінформувати про це населення в засобах масової інформації та на вокзалах.

3. Управлінню тарифної та цінової політики (Осадча Т.М.) разом із Головним управлінням правового забезпечення діяльності транспорту (Логінова Л.М.) в установленому порядку зареєструвати зазначені Тарифи в Міністерстві юстиції.

4. Контроль за виконанням цього наказу покласти на першого заступника Міністра транспорту України - Генерального директора Укрзалізниці А.В.Слободяна.

Перший заступник Міністра Л.М.Костюченко ( Тарифи на перевезення вантажобагажу залізничним транспортом у внутрішньодержавному сполученні втратили чинність на підставі Наказу Мінтрансу N 248 ( z0411-98 ) від 26.06.98 )
