ПОСТАНОВА від 28 грудня 1994 р. N 878 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 229 ( 229-2016-п ) від 25.03.2016 }

{ Додатково див. Постанову КМ N 559 ( 559-2012-п ) від 20.06.2012 }

Про внесення доповнень до Порядку обчислення стажу державної служби

Відповідно до Закону України "Про внесення змін і доповнень до законодавчих актів України щодо врегулювання деяких питань, пов'язаних з умовами відбування покарання засудженими" ( 137/94-ВР ) (Відомості Верховної Ради України, 1994 р., N 37, ст. 342) Кабінет Міністрів України ПОСТАНОВЛЯЄ:

Внести до Порядку обчислення стажу державної служби, затвердженого постановою Кабінету Міністрів України від 3 травня 1994 р. N 283 ( 283-94-п ) (ЗП України, 1994 р., N 8, ст. 213), такі доповнення:

пункт 2 доповнити абзацом такого змісту:

"на посадах спеціалістів органів виконання покарань, які не мають спеціальних звань";

додаток до зазначеного Порядку доповнити абзацом такого змісту:

"Органи виконання покарань (спеціалісти, які не мають спеціальних звань)".

Прем'єр-міністр України В.МАСОЛ
