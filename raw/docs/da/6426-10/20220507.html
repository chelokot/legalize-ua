( Відомості Верховної Ради (ВВР), 1984, N 4, ст. 83 )

{ Із змінами, внесеними згідно із Законом N 514-V ( 514-16 ) від 21.12.2006, ВВР, 2007, N 11, ст.94 }

від 14 вересня 1983 року "Про об'єднання Міністерства сільського господарства Української РСР і Міністерства радгоспів Української РСР в Міністерство сільського господарства Української РСР";

від 30 листопада 1983 року "Про перетворення Головного управління по іноземному туризму при Раді Міністрів УРСР у Головне управління Української РСР по іноземному туризму".
