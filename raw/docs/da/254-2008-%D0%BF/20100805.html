КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 березня 2008 р. N 254 Київ

Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для інформаційного та організаційного забезпечення участі України у міжнародних форумах, конференціях, виставках

{ Установити, що використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) Міністерству економіки за програмою "Інформаційне та організаційне забезпечення участі України у міжнародних форумах, конференціях, виставках", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 256 ( 256-2009-п ) від 25.03.2009 }

{ Установити, що у 2010 році кошти, передбачені у державному бюджеті ( 2154-17 ) Міністерству економіки за програмою "Інформаційне та організаційне забезпечення участі України у міжнародних форумах, конференціях, виставках", використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 633 ( 633-2010-п ) від 28.07.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) за програмою "Інформаційне та організаційне забезпечення участі України у міжнародних форумах, конференціях, виставках", що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 березня 2008 р. N 254

ПОРЯДОК використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для інформаційного та організаційного забезпечення участі України у міжнародних форумах, конференціях, виставках

1. Цей Порядок визначає механізм використання у 2008 році коштів, передбачених Мінекономіки у загальному фонді державного бюджету ( 107-17 ) за програмою "Інформаційне та організаційне забезпечення участі України у міжнародних форумах, конференціях, виставках" (далі - бюджетні кошти).

2. За рахунок бюджетних коштів Мінекономіки проводить закупівлю робіт і послуг для забезпечення участі України у міжнародних форумах, конференціях, виставках у порядку, встановленому законодавством.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 256 ( 256-2009-п ) від 25.03.2009 }

3. Бюджетні кошти спрямовуються за відповідним рішенням Кабінету Міністрів України на:

сплату щорічних членських внесків до Міжнародного бюро виставок (Франція), членом якого є Україна;

{ Абзац третій пункту 3 виключено на підставі Постанови КМ N 633 ( 633-2010-п ) від 28.07.2010 }

проведення заходів, пов'язаних з участю України у Міжнародній виставці "Експо-2012" (м. Йосу, Республіка Корея) (далі - "Експо-2012"); { Абзац четвертий пункту 3 із змінами, внесеними згідно з Постановою КМ N 633 ( 633-2010-п ) від 28.07.2010 }

підготовку та забезпечення роботи національних експозицій України на міжнародних виставках і ярмарках за кордоном;

забезпечення участі України в економічних форумах та конференціях.

{ Пункт 3 в редакції Постанови КМ N 256 ( 256-2009-п ) від 25.03.2009 }

4. Бюджетні кошти використовуються для оплати:

робіт (послуг), пов'язаних з орендою виставкових площ, обладнання, меблів і приміщень, необхідних для проведення презентації інвестиційних проектів, економічних форумів і конференцій, автотранспортних та інших технічних засобів, комунальних послуг, послуг з перевезення вантажів та їх митного оформлення тощо;

проведення рекламної кампанії, включення до офіційного електронного каталогу відповідного міжнародного заходу інформації, що стосується українських учасників;

придбання витратних матеріалів і сувенірів;

телекомунікаційних послуг, зокрема з підключення до Інтернет;

послуг медичного страхування, перекладачів, з виготовлення та розповсюдження рекламно-інформаційних матеріалів на друкованих і електронних носіях;

придбання квитків для відвідування міжнародних виставок;

витрат, пов'язаних з відрядженням членів офіційних делегацій, організацією ділових зустрічей з представниками державних органів та ділових кіл країни під час проведення виставкового заходу, проведенням підготовчих робіт та перебуванням на виставці працівників, що обслуговують національні експозиції, а також з відрядженням генерального комісара України для підписання Договору про участь України в "Експо-2012" і участі у засіданнях генеральних комісарів країн - учасниць "Експо-2012"; { Абзац восьмий пункту 4 в редакції Постанови КМ N 633 ( 633-2010-п ) від 28.07.2010 }

представницьких заходів керівника офіційної делегації України на міжнародних виставках та ярмарках;

послуг з розроблення проектної документації на створення національної експозиції України (далі - національна експозиція) на "Експо-2012" та логотипу емблеми національної експозиції; { Абзац десятий пункту 4 в редакції Постанови КМ N 633 ( 633-2010-п ) від 28.07.2010 }

послуг розпорядника з підготовки національної експозиції на "Експо-2012"; { Абзац одинадцятий пункту 4 в редакції Постанови КМ N 633 ( 633-2010-п ) від 28.07.2010 }

{ Абзац дванадцятий пункту 4 виключено на підставі Постанови КМ N 633 ( 633-2010-п ) від 28.07.2010 }

проведення тендеру на визначення інтернет-провайдера, створення і супроводження веб-сайту національної експозиції; { Абзац тринадцятий пункту 4 із змінами, внесеними згідно з Постановою КМ N 633 ( 633-2010-п ) від 28.07.2010 }

послуг з перекладу на українську мову офіційно наданих організаторами виставки Україні документів, необхідних для забезпечення участі України в "Експо-2012". { Пункт 4 доповнено абзацом згідно з Постановою КМ N 256 ( 256-2009-п ) від 25.03.2009; із змінами, внесеними згідно з Постановою КМ N 633 ( 633-2010-п ) від 28.07.2010 }

5. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством. { Абзац перший пункту 5 в редакції Постанови КМ N 633 ( 633-2010-п ) від 28.07.2010 }

Попередня оплата за договорами про закупівлю робіт і послуг здійснюється у розмірі 70 відсотків суми, зазначеної у договорі, на строк не більше ніж один місяць. { Пункт 5 доповнено новим абзацом згідно з Постановою КМ N 633 ( 633-2010-п ) від 28.07.2010 }

Розрахунки за виконані роботи і надані послуги проводяться їх замовником згідно з умовами договору на підставі актів приймання-передачі та відповідних документів щодо виконання робіт і надання послуг.

6. Мінекономіки надсилає щокварталу до 20 числа наступного місяця Мінфіну звіт про стан виконання показників згідно із паспортом бюджетної програми з доданням інформації про результати аналізу, пояснень та висновків щодо виконання затверджених показників.

7. Складення та подання фінансової звітності про використання коштів, а також контроль за їх цільовим витрачанням на окремих стадіях здійснюються в установленому законодавством порядку.
