Про затвердження Положення про спеціальні звання посадових осіб органів державної податкової служби

( Із змінами, внесеними згідно з Постановою КМ N 880 ( 880-2001-п ) від 26.07.2001 )

У зв'язку з прийняттям Закону України від 5 лютого 1998 р. "Про внесення змін до Закону України "Про державну податкову службу в Україні" ( 83/98-ВР ) Кабінет Міністрів України постановляє:

1. Затвердити Положення про спеціальні звання посадових осіб органів державної податкової служби (додається).

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 5 жовтня 1992 р. N 559 ( 559-92-п ) "Питання державної податкової служби в Україні";

пункт 1 додатка до постанови Кабінету Міністрів України від 11 березня 1994 р. N 161 ( 161-94-п ) "Про внесення змін до постанов Кабінету Міністрів України з питань державної податкової служби в Україні".

3. Спеціальні звання посадовим особам органів державної податкової служби присвоюються:

головного державного радника податкової служби - Президентом України за поданням Кабінету Міністрів України;

державних радників податкової служби I рангу та II рангу (першим заступникам, заступникам Голови Державної податкової адміністрації України) - Кабінетом Міністрів України за поданням Голови Державної податкової адміністрації України; ( Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 880 ( 880-2001-п ) від 26.07.2001 )

державних радників податкової служби II рангу, державних радників податкової служби III рангу, радників податкової служби I, II, III рангів, інспекторів податкової служби I, II, III рангів - Державною податковою адміністрацією України, державними податковими адміністраціями в Автономній Республіці Крим, областях, містах Києві та Севастополі, державними податковими інспекціями в районах, містах і районах у містах, міжрайонними та об'єднаними державними податковими інспекціями згідно із займаною посадою за поданням керівника відповідного рівня. ( Абзац четвертий пункту 3 із змінами, внесеними згідно з Постановою КМ N 880 ( 880-2001-п ) від 26.07.2001 )

4. Під час зарахування на посаду посадовим особам органів державної податкової служби присвоюється спеціальне звання у межах відповідної категорії посад. У разі встановлення випробувального терміну, особам, вперше прийнятим на роботу до органів державної податкової служби, спеціальне звання присвоюється після закінчення такого терміну. ( Абзац перший пункту 4 із змінами, внесеними згідно з Постановою КМ N 880 ( 880-2001-п ) від 26.07.2001 )

Для присвоєння чергового спеціального звання у межах відповідної категорії посад посадові особи органів державної податкової служби повинні успішно відпрацювати не менш як:

державний радник податкової служби II рангу - 2 роки

( Абзац пункту 4 із змінами, внесеними згідно з Постановою КМ N 880 ( 880-2001-п ) від 26.07.2001 )

державний радник податкової служби III рангу - 2 роки

( Абзац пункту 4 із змінами, внесеними згідно з Постановою КМ N 880 ( 880-2001-п ) від 26.07.2001 )

радник податкової служби III рангу - 2 роки

радник податкової служби II рангу - 2 роки

радник податкової служби I рангу - 3 роки

інспектор податкової служби III рангу - 3 роки

інспектор податкової служби II рангу - 4 роки

інспектор податкової служби I рангу - 4 роки.

( Абзац третій пункту 4 втратив чинність на підставі Постанови КМ N 880 ( 880-2001-п ) від 26.07.2001 )

Затримка у присвоєнні чергового спеціального звання до одного року може застосовуватися до посадових осіб органів державної податкової служби як захід дисциплінарного впливу. ( Пункт 4 доповнено абзацом згідно з Постановою КМ N 880 ( 880-2001-п ) від 26.07.2001 )

5. Голові Державної податкової адміністрації України надається право:

а) за особливі досягнення в роботі присвоювати посадовим особам органів державної податкової служби спеціальні звання, крім спеціальних звань, що присвоюються Кабінетом Міністрів України, до закінчення термінів, зазначених у пункті 4 цього Положення, в межах наступних двох рангів за поданням керівників відповідного рівня;

б) у разі призначення посадових осіб на вищу посаду присвоювати спеціальне звання до закінчення термінів, зазначених у пункті 4 цього Положення, в межах наступних двох рангів за поданням керівників відповідного рівня.

6. За сумлінну працю посадовим особам органів державної податкової служби у разі виходу на пенсію може бути присвоєно чергове спеціальне звання поза межами відповідної категорії посад. ( Пункт 6 із змінами, внесеними згідно з Постановою КМ N 880 ( 880-2001-п ) від 26.07.2001 )

7. Спеціальні звання, присвоєні посадовим особам органів державної податкової служби, зберігаються у них довічно.

8. Посадові особи органів державної податкової служби можуть бути позбавлені спеціальних звань лише за вироком суду.

9. Посадовим особам органів державної податкової служби, які мають спеціальні звання, виплачуються відповідні грошові надбавки до посадових окладів.

10. Це Положення не поширюється на посадових осіб податкової міліції.

11. Державній податковій адміністрації України надавати роз'яснення щодо застосування цього Положення. ( Положення доповнено пунктом 11 згідно з Постановою КМ N 880 ( 880-2001-п ) від 26.07.2001 )
