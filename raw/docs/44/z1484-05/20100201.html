Про встановлення вартості ліцензій на добування мисливських тварин

Згідно із Законом України "Про мисливське господарство та полювання" ( 1478-14 ) та на виконання Указу Президента України від 23 травня 2005 року N 837 ( 837/2005 ) "Про невідкладні заходи у сфері збереження, відтворення та раціонального використання мисливських тварин" НАКАЗУЮ:

1. Установити вартість ліцензій на добування мисливських тварин у мисливських угіддях України, що додається.

2. Голові Республіканського комітету по лісовому і мисливському господарству АР Крим, начальникам обласних управлінь лісового господарства, директору Севастопольського державного лісомисливського господарства довести цей наказ до відома всіх користувачів мисливських угідь.

3. Накази від 8 серпня 1996 року N 85 ( z0473-96 ) "Про затвердження вартості ліцензій для полювання в мисливських угіддях України для громадян України та іноземних громадян", зареєстрований в Міністерстві юстиції України 23 серпня 1996 року за N 473/1498, та від 10 листопада 2000 року N 122 ( z0851-00 ) "Про установлення вартості ліцензій на добування мисливських тварин", зареєстрований в Міністерстві юстиції України 22 листопада 2000 року за N 851/5072, визнати такими, що втратили чинність.

4. Контроль за виконанням наказу покласти на начальника відділу мисливського господарства Шадуру М.В.

Голова В.О.Червоний

ПОГОДЖЕНО:

Голова Державного комітету України з питань регуляторної політики та підприємництва А.В.Дашкевич

ЗАТВЕРДЖЕНО Наказ Держкомлісгоспу України 24.11.2005 N 493

Вартість ліцензій на добування мисливських тварин у мисливських угіддях України

Вартість ліцензій на добування мисливських тварин у мисливських угіддях України затверджено на підставі Указу Президента України від 23 травня 2005 року N 837 ( 837/2005 ) "Про невідкладні заходи у сфері збереження, відтворення та раціонального використання мисливських тварин" та статті 18 Закону України "Про мисливське господарство та полювання" ( 1478-14 ).

1. Розрахунки з мисливцями за ліцензії проводяться в національній валюті України перед початком полювання.
