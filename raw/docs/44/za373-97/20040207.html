НАЦІОНАЛЬНИЙ БАНК УКРАЇНИ

ПОСТАНОВА

N 246 від 23.07.97 Зареєстровано в Міністерстві м.Київ юстиції України 2 вересня 1997 року за N 373/2177

( Постанова втратила чинність на підставі Постанови Національного банку N 4 ( za113-04 ) від 12.01.2004 )

Про затвердження Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик

( Додатково див. Наказ Мінфіну N 111 ( za349-98, z0349-98 ) від 08.05.98 )

Заслухавши та обговоривши інформацію директора Емісійно-кредитного департаменту Н.І. Гребеник щодо проекту Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик, Правління ПОСТАНОВЛЯЄ:

1. Затвердити Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик ( z0373-97 ) ( додається).

2. Ввести в дію пункт 2.5 Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик через місяць після його державної реєстрації.

3. Визнати таким, що втратив чинність пункт 3 постанови Правління Національного банку України від 26 грудня 1996 року N 333 ( v0333500-96 ).

4. Емісійно-кредитному департаменту (Н.І. Гребеник) після державної реєстрації Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик Міністерством юстиції України надіслати його обласним управлінням Національного банку України та комерційним банкам для керівництва і використання в роботі.

Голова В.А. Ющенко
