{ Розпорядження втратило чинність на підставі Постанови КМ N 314 ( 314-2010-п ) від 14.04.2010 }

Про затвердження складу Міжвідомчої комісії з організації укладення та виконання угод про розподіл продукції

Кабінет Міністрів України постановляє:

На часткову зміну пункту 1 постанови Кабінету Міністрів України від 12 липня 2000 р. N 1119 ( 1119-2000-п ) "Про утворення Міжвідомчої комісії з організації укладення та виконання угод про розподіл продукції" (Офіційний вісник України, 2000 р., N 29, ст. 1216; 2005 р., N 51, ст. 3202; 2006 р., N 40, ст. 2681) затвердити склад Міжвідомчої комісії з організації укладення та виконання угод про розподіл продукції, що додається.
