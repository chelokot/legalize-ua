КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 вересня 2001 р. N 1263 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 242 ( 242-2023-п ) від 17.03.2023 }

Про внесення змін до постанови Кабінету Міністрів України від 11 листопада 1999 р. N 2076

( Щодо змін додатково див. Постанову КМ N 973 ( 973-2003-п ) від 27.06.2003 )

Кабінет Міністрів України постановляє:

Внести до переліку пріоритетних видів економічної діяльності на території м. Харкова, для яких встановлено спеціальний режим інвестиційної діяльності, затвердженого постановою Кабінету Міністрів України від 11 листопада 1999 р. N 2076 ( 2076-99-п ) (Офіційний вісник України, 1999 р., N 46, ст. 2267; 2000 р., N 30, ст. 1281), зміни, що додаються.

Прем'єр-міністр України А.КІНАХ

Інд. 27

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 вересня 2001 р. N 1263

ЗМІНИ, що вносяться до переліку пріоритетних видів економічної діяльності на території м. Харкова, для яких встановлено спеціальний режим інвестиційної діяльності ( 2076-99-п )

1. Доповнити перелік:

після позиції "15.6 Оброблення зерна, виробництво крохмалю" позицією

"15.84 Виробництво какао";

після позиції "15.97 Виробництво солоду та солодових екстрактів" позицією

"17.4 Виробництво виробів з текстилю";

після позиції "17.52 Виробництво канатів, мотузок, шпагату та сіткового полотна" такими позиціями:

"21.22 Виробництво санітарно-гігієнічних виробів та паперових виробів для побутового користування;

22.22 Поліграфічна діяльність, не віднесена до інших угруповань: друкування продукції, виконаної на друкарському обладнанні рельєфним друком та за іншою технологією;

23.20 Виробництво матеріалів для покриття доріг: бітуму, асфальту";

після позиції "24.4 Фармацевтичне виробництво" такими позиціями:

"25.22 Виробництво тари з пластмас;

26.3 Виробництво керамічної плитки;

26.4 Виробництво цегли, черепиці з глини;

26.61 Виробництво виробів з бетону для використання в будівництві;

26.82 Виробництво інших неметалевих мінеральних виробів, не віднесених до інших угруповань;

28.4 Кування, штампування, карбування; порошкова металургія";

після позиції "28.30 Виробництво нагрівальних котлів, крім діяльності, пов'язаної з виробництвом ядерних реакторів" позицією

"28.51 Оброблення та покриття металу";

після позиції "45.2 Будівництво завершених будівель; цивільне будівництво" такими позиціями:

"45.3 Роботи з обладнання будівель;

45.4 Роботи з завершення будівництва;

60.2 Міський та автодорожній транспорт". -
