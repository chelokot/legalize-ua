Про утворення Національної акціонерної компанії "Енергетична компанія України"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 679-р ( 679-2004-р ) від 22.09.2004 Постановою КМ N 1717 ( 1717-2004-п ) від 23.12.2004 Розпорядженням КМ N 162-р ( 162-2005-р ) від 26.05.2005 Постановами КМ N 1205 ( 1205-2005-п ) від 15.12.2005 N 1437 ( 1437-2006-п ) від 18.10.2006 N 824 ( 824-2007-п ) від 13.06.2007 N 1105 ( 1105-2007-п ) від 05.09.2007 N 1403 ( 1403-2007-п ) від 24.12.2007 N 66 ( 66-2008-п ) від 22.02.2008 N 134 ( 134-2008-п ) від 05.03.2008 N 196 ( 196-2008-п ) від 19.03.2008 }

Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 1437 ( 1437-2006-п ) від 18.10.2006 }

1. Утворити Національну акціонерну компанію "Енергетична компанія України" (далі - Компанія) у формі відкритого акціонерного товариства.

2. Установити, що статутний фонд Компанії формується шляхом передачі до нього:

пакетів акцій, що належать державі у статутних фондах господарських товариств, зазначених у додатку 1;

100 відсотків акцій, що належать державі у статутних фондах господарських товариств, зазначених у додатку 2.

{ Абзац четвертий пункту 2 виключено на підставі Постанови КМ N 134 ( 134-2008-п ) від 05.03.2008 }

Майно державних підприємств, зазначених у додатку 3, та адміністративний будинок по вул. Хрещатик, 34, у м. Києві закріплюються за Компанією на праві господарського відання для забезпечення її діяльності.

Розмір статутного фонду Компанії на етапі її утворення визначається виходячи з номінальної вартості пакетів акцій господарських товариств, зазначених у додатках 1 і 2.

3. Залишити у державній власності пакети акцій у статутних фондах господарських товариств у розмірах, зазначених у додатках 1 і 2.

4. Фонду державного майна передати у місячний строк Компанії за номінальною вартістю акції, що належать державі у статутних фондах господарських товариств, зазначених у додатку 1. Для цього в установленому порядку вирішити питання щодо:

розірвання угод про передачу повноважень на здійснення функцій з управління корпоративними правами держави;

внесення до планів розміщення акцій змін у зв'язку із закріпленням та передачею до статутного фонду Компанії пакетів акцій;

перереєстрації пакетів акцій.

5. Міністерству палива та енергетики, Фонду державного майна в установленому порядку:

передати Компанії у тижневий строк після її державної реєстрації за номінальною вартістю 100 відсотків акцій, що належать державі у статутних фондах господарських товариств, зазначених у додатку 2;

забезпечити проведення перереєстрації зазначених пакетів акцій.

6. Фонду державного майна забезпечити у тримісячний строк проведення оцінки пакетів акцій господарських товариств, зазначених у додатках 1 і 2. За результатами оцінки подати Кабінетові Міністрів України пропозиції щодо уточнення розміру статутного фонду Компанії.

{ Пункт 7 виключено на підставі Постанови КМ N 134 ( 134-2008-п ) від 05.03.2008 }

{ Пункт 8 виключено на підставі Постанови КМ N 134 ( 134-2008-п ) від 05.03.2008 }

9. Міністерству палива та енергетики:

передати у місячний строк Компанії майно державних підприємств, зазначених у додатку 3, та адміністративний будинок по вул. Хрещатик, 34, у м. Києві;

подати в установленому порядку пропозиції щодо внесення змін до Положення про Міністерство палива та енергетики ( 598/2000 ) у зв'язку з утворенням Компанії.

{ Абзац четвертий пункту 9 виключено на підставі Постанови КМ N 134 ( 134-2008-п ) від 05.03.2008 }

10. Міністерству палива та енергетики, Фонду державного майна разом з Компанією:

визначити перелік державного майна, що перебуває на балансі господарських товариств, пакети акцій яких передано до статутного фонду Компанії, але не ввійшло до їх статутних фондів, та подати Кабінетові Міністрів України пропозиції щодо подальшого його використання з метою забезпечення виконання Компанією статутних завдань.

11. Затвердити Статут Компанії (додається).

( Пункт 11 із змінами, внесеними згідно з Постановою КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

12. Фонду державного майна, Міністерству палива та енергетики подати у двотижневий строк Кабінетові Міністрів України узгоджені пропозиції щодо складу ревізійної комісії Компанії, а також проекти положень про наглядову раду та ревізійну комісію Компанії.

13. Установити, що:

100 відсотків акцій, які випускаються на величину статутного фонду Компанії, є власністю держави;

акції Компанії та інше передане Їй державне майно не можуть відчужуватися або використовуватися для формування статутних фондів інших підприємств.

14. Президентові Компанії забезпечити у двотижневий строк державну реєстрацію Компанії, відкриття рахунків в установах банків, вирішення кадрових та інших першочергових питань функціонування Компанії.

15. Розмістити Компанію у м. Києві по вул. Хрещатик, 34.

16. Контроль за виконанням цієї постанови покласти на Віце-прем'єр-міністра України Клюєва А.П.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 22 червня 2004 р. N 794

СТАТУТ Національної акціонерної компанії "Енергетична компанія України"

Загальні положення

1. Національна акціонерна компанія "Енергетична компанія України" (далі - Компанія) утворена на виконання Указу Президента України від 22 січня 2004 р. N 69 ( 69/2004 ) "Про заходи щодо підвищення ефективності управління електроенергетичним комплексом".

2. Компанія є відкритим акціонерним товариством.

3. Офіційна назва Компанії: українською мовою - Національна акціонерна компанія "Енергетична компанія України" (НАК "Енергетична компанія України"), англійською мовою - National Joint Stock Company "Energy Company of Ukraine" (NJSC "Energy Company of Ukraine").

4. Місцезнаходження Компанії: м. Київ, вул. Хрещатик, 34.

Мета і предмет діяльності Компанії

5. Метою діяльності Компанії є створення умов для надійного та ефективного функціонування і розвитку електроенергетичного комплексу для забезпечення економічної та енергетичної безпеки держави, більш повного задоволення потреб споживачів в електричній і тепловій енергії, поліпшення стану розрахунків за енергоносії, підвищення прозорості енергетичного ринку та ефективності управління державним майном, залучення інвестицій та отримання прибутку.

6. Предмет діяльності Компанії:

розвиток ринкових механізмів у діяльності господарських товариств, акції яких передано до статутного фонду Компанії, та її дочірніх підприємств (далі - підприємства електроенергетичного комплексу);

координація діяльності підприємств електроенергетичного комплексу для забезпечення надійності енергопостачання споживачів;

забезпечення проведення єдиної технічної, інноваційної, фінансової та інвестиційної політики підприємствами електроенергетичного комплексу;

впровадження єдиних засад інвестиційної діяльності, відновлення основних виробничих фондів, матеріально-технічного забезпечення підприємств електроенергетичного комплексу;

організація та координація науково-дослідних і проектно-конструкторських робіт, а також робіт, пов'язаних з розробленням і впровадженням нової техніки, передових технологій у сфері виробництва, передачі та розподілу електричної і теплової енергії;

виробництво електричної і теплової енергії;

продаж електроенергії на оптовий ринок електричної енергії України;

постачання електричної і теплової енергії;

охорона об'єктів електроенергетики та інших об'єктів;

провадження зовнішньоекономічної діяльності, зокрема здійснення операцій з експорту (імпорту) енергетичного устаткування, технологій, електроенергії, енергоносіїв, інших товарів і послуг; виконання робіт з будівництва енергетичних об'єктів за кордоном;

удосконалення роботи із споживачами електричної і теплової енергії, у тому числі щодо зміцнення платіжної дисципліни, обмеження постачання електричної і теплової енергії неплатникам, запобігання несанкціонованому доступу до електричних мереж;

визначення єдиних підходів до створення та впровадження системи комерційного обліку електроенергії;

проведення техніко-економічного аналізу та оцінки діяльності підприємств електроенергетичного комплексу, розроблення і здійснення заходів щодо підвищення її ефективності;

здійснення контролю за провадженням господарської діяльності підприємствами електроенергетичного комплексу, у тому числі за використанням ними майна та коштів, рівнем закупівельних цін на паливо, обладнання і устаткування, його якістю, проведенням ремонту обладнання, дотриманням технологічних правил безпеки та екологічних норм;

концентрація та розпорядження фінансовими ресурсами для реалізації інвестиційних проектів, налагодження ефективних зв'язків між підприємствами електроенергетичного комплексу та іншими суб'єктами підприємницької діяльності;

виробництво необхідних для підприємств електроенергетичного комплексу обладнання, будівельних матеріалів, машин, механізмів, приладів, запасних частин і деталей;

організація та проведення досліджень, випробувань і пусконалагоджувальних робіт, а також здійснення контролю за експлуатацією основного і допоміжного тепломеханічного та електричного обладнання;

технічний огляд та діагностування ємностей, що працюють під тиском, вантажопідіймальних кранів та машин;

виконання проектних, проектно-вишукувальних, будівельних, ремонтних та реставраційних робіт;

надання послуг з перевезення пасажирів і вантажів автомобільним транспортом загального користування та транспортно-експедиційних послуг;

провадження торговельної діяльності, у тому числі комісійної, торговельно-посередницької і торговельно-закупівельної;

проектування, монтаж, технічне обслуговування засобів протипожежного захисту та систем опалення;

заготівля та переробка брухту кольорових і чорних металів;

збирання та переробка вторинної сировини і відходів виробництва, здійснення операцій у сфері поводження з небезпечними відходами;

надання інформаційних, консультаційних і маркетингових послуг; виробництво товарів широкого вжитку;

проведення виставок, виставок-продажу, семінарів, конференцій та аукціонів;

надання послуг зв'язку;

провадження видавничої діяльності, надання поліграфічних послуг.

Відповідно до мети, визначеної цим Статутом, Компанія провадить також інші види діяльності згідно із законодавством.

7. Окремі види господарської діяльності які згідно із законодавством підлягають ліцензуванню, Компанія провадить після отримання в установленому порядку ліцензій.

8. Роботи, що потребують спеціальних знань і допуску до державної таємниці, виконуються підготовленими в установленому порядку особами, за наявності у них документа відповідної форми.

Захист державної таємниці здійснюється Компанією відповідно до вимог Закону України "Про державну таємницю" ( 3855-12 ) та інших актів законодавства.

9. Компанія провадить діяльність із залучення інвестицій, зокрема іноземних, розробляє та реалізує відповідні проекти, бере участь у залученні коштів міжнародних фінансових організацій,

10. Компанія вживає заходів для розвитку науково-технічного співробітництва з іноземними підприємствами та організаціями, забезпечує виконання спільних науково-дослідних; проектно-конструкторських та експериментальних робіт, обмін у встановленому порядку науково-технічною інформацією, організовує навчання та стажування спеціалістів за кордоном.

Юридичний статус Компанії

11. Компанія є юридичною особою.

Компанія набуває права юридичної особи з дня її державної реєстрації.

Компанія у своїй діяльності керується Конституцією ( 254к/96-ВР ) і законами України, актами Президента України, Кабінету Міністрів України і Мінпаливенерго, а також цим Статутом. ( Абзац третій пункту 11 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

12. Компанія має самостійний баланс, рахунки в установах банків, а також печатку із своїм найменуванням, штампи, бланки та інші реквізити.

13. Компанія діє на принципах повної господарської самостійності і самоокупності, несе відповідальність за результати своєї господарської діяльності та виконання зобов'язань.

14. Компанія може набувати майнові та особисті немайнові права, укладати з іншими суб'єктами господарювання та громадянами договори (контракти), бути позивачем та відповідачем у судах України, інших держав.

15. Компанія має право:

випускати (емітувати) в установленому порядку цінні папери;

утворювати дочірні підприємства, філії, представництва, інші відособлені структурні підрозділи як на території України, так і за її межами. Дочірні підприємства Компанії діють на підставі статутів філії, представництва, інші відособлені структурні підрозділи - на підставі положень, затверджених президентом Компанії;

утворювати разом з іншими суб'єктами господарювання спілки, асоціації та інші об'єднання для координації діяльності та захисту своїх інтересів;

вносити в установленому порядку Кабінетові Міністрів України та іншим центральним органам виконавчої влади пропозиції щодо підвищення ефективності функціонування електроенергетичного комплексу, в тому числі проекти нормативно-правових актів з цих питань.

16. Компанія у своїй діяльності взаємодіє з органами виконавчої влади та органами місцевого самоврядування, громадськими організаціями з питань, що стосуються функціонування електроенергетичного комплексу.

Засновник Компанії

17. Засновником Компанії є держава в особі Кабінету Міністрів України. Єдиним акціонером Компанії є держава в особі Мінпаливенерго.

( Пункт 17 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

Майно Компанії

18. Майно Компанії складається з оборотних засобів, основних фондів, обігових коштів, акцій, переданих до її статутного фонду, та інших активів, вартість яких відображається у бухгалтерському балансі Компанії.

19. Компанії належить майно, передане засновником Компанії до статутного фонду; доходи від провадження виробничої діяльності; доходи, отримані від реалізації цінних паперів; дивіденди на акції, передані до статутного фонду Компанії; кредити (позички) банків; інше майно, набуте Компанією на підставах, не заборонених законодавством.

Компанія несе ризик випадкової втрати або пошкодження майна, що їй належить.

20. Майно державних підприємств та адміністративний будинок по вул. Хрещатик, 34, у м. Києві закріплюються за Компанією на праві господарського відання для забезпечення її діяльності.

21. Компанія в порядку, визначеному цим Статутом, володіє, користується та розпоряджається належним їй майном, вчиняючи стосовно нього будь-які дії, що не суперечать законодавству та меті діяльності Компанії.

Пакети акцій, закріплені у державній власності та передані до статутного фонду Компанії, не можуть відчужуватися або використовуватися для формування статутних фондів інших підприємств.

Майно та кошти, набуті Компанією в результаті її господарської діяльності, спрямовуються насамперед на зміцнення матеріально-технічної бази і розвиток Компанії.

Статутний фонд Компанії

22. Матеріально-фінансовою основою діяльності Компанії є статутний фонд, який формується за рахунок вартості майна, переданого до статутного фонду.

Статутний фонд Компанії становить 9 831 180 093 (дев'ять мільярдів вісімсот тридцять один мільйон сто вісімдесят тисяч дев'яносто три) гривні. ( Абзац другий пункту 22 із змінами, внесеними згідно з Постановою КМ N 1717 ( 1717-2004-п ) від 23.12.2004 )

23. Статутний фонд Компанії поділяється на 9 831 180 093 (дев'ять мільярдів вісімсот тридцять один мільйон сто вісімдесят тисяч дев'яносто три) прості іменні акції номінальною вартістю 1 гривня кожна.

( Пункт 23 із змінами, внесеними згідно з Постановою КМ N 1717 ( 1717-2004-п ) від 23.12.2004 )

24. Статутний фонд Компанії може бути змінено виключно за рішенням Мінпаливенерго, погодженим з Кабінетом Міністрів України. ( Пункт 24 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

Акції Компанії

25. Компанія випускає на величину статутного фонду акції в документарній формі та забезпечує реєстрацію їх випуску в установленому порядку.

26. Акції Компанії є неподільними.

27. Компанія не має права без погодження з Мінпаливенерго здійснювати знерухомлення акцій, випущених у документарній формі. ( Пункт 27 із змінами, внесеними згідно з Постановою КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

Прибуток Компанії та його використання. Порядок покриття збитків

28. Прибуток Компанії є показником фінансових результатів її господарської діяльності, що визначається шляхом зменшення суми валового доходу Компанії за певний період на суму валових витрат та суму амортизаційних відрахувань.

29. За рішенням президента Компанії, погодженим з Мінпаливенерго, за рахунок прибутку можуть створюватися фонди, призначені для фінансування заходів із зміцнення її матеріально-технічної бази, розвитку науково-технічного потенціалу, матеріального стимулювання працівників Компанії, вирішення соціальних та інших питань.

( Пункт 29 із змінами, внесеними згідно з Постановою КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

30. Для покриття непередбачених витрат та відшкодування можливих збитків Компанія створює резервний (страховий) фонд у розмірі 25 відсотків статутного фонду.

Резервний (страховий) фонд формується шляхом щорічних відрахувань у розмірі 5 відсотків суми чистого прибутку. Відрахування провадяться до досягнення фондом зазначеного розміру.

У разі повного або часткового використання резервного (страхового) фонду його поповнення здійснюється в порядку, передбаченому цим пунктом.

31. Збитки від господарської діяльності Компанії покриваються за рахунок коштів резервного (страхового) фонду, а у разі їх недостатності - у порядку, визначеному президентом Компанії за погодженням з Мінпаливенерго.

( Пункт 31 із змінами, внесеними згідно з Постановою КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

32. Фонд виплати дивідендів створюється за рахунок чистого прибутку Компанії.

Рішення про розмір дивідендів, порядок та строки їх виплати приймаються щороку Мінпаливенерго за результатами фінансово-господарської діяльності Компанії у минулому році. ( Абзац другий пункту 32 із змінами, внесеними згідно з Постановою КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

Управління Компанією

33. Органами управління Компанії є:

Мінпаливенерго, яке здійснює повноваження загальних зборів акціонерів; ( Абзац другий пункту 33 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

наглядова рада;

президент Компанії (виконавчий орган);

ревізійна комісія.

Мінпаливенерго

( Назва розділу в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

34. До повноважень Мінпаливенерго належить:

1) за погодженням з Кабінетом Міністрів України:

зміна розміру статутного фонду Компанії;

затвердження та відкликання голови, заступників голови, членів наглядової ради та ревізійної комісії Компанії;

прийняття рішення про припинення діяльності Компанії (реорганізацію, ліквідацію), утворення ліквідаційної комісії, затвердження ліквідаційного балансу;

2) внесення змін до Статуту Компанії;

3) затвердження річних результатів діяльності та річних фінансових планів Компанії, включаючи її дочірні підприємства, та звітів про їх виконання, а також звітів і висновків ревізійної комісії, визначення порядку розподілу прибутку та покриття збитків Компанії;

4) прийняття рішення про визначення розміру, порядку та строку сплати Компанією дивідендів до державного бюджету;

5) погодження рішень про додаткову емісію акцій Компанії та акціонерних товариств, пакети акцій яких передано до статутного фонду Компанії;

6) заслуховування звітів президента Компанії з питань її діяльності;

7) створення, реорганізація та ліквідація дочірніх підприємств, філій та представництв, затвердження їх статутів та положень;

8) затвердження положення про структурні підрозділи Компанії.

( Пункт 34 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

Наглядова рада Компанії

35. Наглядову раду утворює Мінпаливенерго за погодженням з Кабінетом Міністрів України у складі голови ради, його заступника та п'яти членів ради. Діяльність наглядової ради припиняється з дати прийняття Мінпаливенерго погодженого з Кабінетом Міністрів України рішення про її зміну. ( Абзац перший пункту 35 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

До складу наглядової ради не можуть входити особи, які перебувають у трудових відносинах з Компанією, а також особи, яким це заборонено законодавством.

Наглядова рада діє на підставі положення, що затверджується Мінпаливенерго. ( Абзац третій пункту 35 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

36. До компетенції наглядової ради Компанії належить:

1) здійснення контролю за виконанням Компанією рішень Кабінету Міністрів України і Мінпаливенерго; ( Підпункт 1 пункту 36 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

2) попередній розгляд річних фінансових планів та звітів про їх виконання, пропозицій щодо визначення розміру, порядку та строків сплати Компанією дивідендів до державного бюджету, інших матеріалів з питань, зазначених у пункті 34 цього Статуту;

3) погодження рішень президента Компанії про створення за рахунок прибутку фондів, призначених для фінансування заходів із зміцнення матеріально-технічної бази Компанії, розвитку її науково-технічного потенціалу, матеріального стимулювання працівників, вирішення соціальних та інших питань;

4) погодження умов оплати праці керівних працівників Компанії;

5) визначення переліку конфіденційної інформації та інформації, яка становить комерційну таємницю;

6) погодження кандидатур, що призначаються на посади першого віце-президента та віце-президентів Компанії;

7) заслуховування звітів президента, першого віце-президента та віце-президентів Компанії з питань її діяльності;

8) затвердження бухгалтерського балансу Компанії;

9) затвердження договорів (контрактів), укладених Компанією, та операцій з майном Компанії на суму, що перевищує 2 відсотки її статутного фонду;

10) погодження питань щодо участі Компанії у господарських товариствах.

Наглядова рада не має права втручатися в оперативну господарську діяльність Компанії.

Президент Компанії

37. Оперативне управління поточною діяльністю Компанії здійснює її президент, який є одноосібним виконавчим органом Компанії.

Президент Компанії підзвітний Мінпаливенерго, Кабінету Міністрів України та наглядовій раді Компанії і несе перед ними відповідальність за результати роботи Компанії. ( Абзац другий пункту 37 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

Президент Компанії призначається на посаді Кабінетом Міністрів України. ( Абзац третій пункту 37 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

Трудовий контракт з президентом Компанії укладає в установленому порядку Міністр палива та енергетики. ( Абзац четвертий пункту 37 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

38. Перший віце-президент та віце-президенти призначаються на посаду та звільняються з посади президентом Компанії за погодженням з наглядовою радою. Кількість віце-президентів визначається президентом Компанії.

39. Президент Компанії без доручення діє від імені Компанії, представляє її інтереси в органах державної влади та органах місцевого самоврядування, інших організаціях, у відносинах з юридичними особами і громадянами.

40. Президент Компанії:

1) вирішує питання господарської діяльності, фінансування, ведення обліку та звітності, роботи з цінними паперами, участі у господарських товариствах, придбання акцій інших акціонерних товариств тощо, а також питання організації роботи дочірніх підприємств, філій, представництв та інших відособлених структурних підрозділів;

2) приймає рішення про притягнення до дисциплінарної та матеріальної відповідальності посадових осіб Компанії;

3) проводить аналіз матеріалів перевірок (ревізій), а також звітів керівників дочірніх підприємств, філій, представництв, інших відособлених структурних підрозділів Компанії, приймає рішення за їх результатами;

4) розглядає і подає наглядовій раді річний фінансовий звіт і бухгалтерський баланс Компанії;

5) призначає керівників дочірніх підприємств, філій, представництв та інших відособлених структурних підрозділів Компанії;

6) приймає за погодженням з Мінпаливенерго рішення про створення за рахунок прибутку фондів, призначених для фінансування заходів із зміцнення матеріально-технічної бази Компанії, розвитку її науково-технічного потенціалу, матеріального стимулювання працівників, вирішення соціальних та інших питань; ( Підпункт 6 пункту 40 із змінами, внесеними згідно з Постановою КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

7) розпоряджається відповідно до законодавства та цього Статуту майном Компанії, в тому числі грошовими коштами;

8) установлює порядок укладення договорів від імені Компанії;

9) розподіляє обов'язки між першим віце-президентом та віце-президентами Компанії;

10) затверджує структуру та штатний розпис Компанії;

11) вирішує питання добору, підготовки та підвищення кваліфікації кадрів;

12) підписує договори (контракти) від імені Компанії;

13) укладає (розриває) в установленому порядку контракти з керівниками акціонерних товариств та інших підприємств, що утворюються Компанією;

14) видає накази з питань діяльності Компанії;

15) виконує інші функції відповідно до законодавства та цього Статуту.

Ревізійна комісія Компанії

41. Ревізійну комісію Компанії утворює Мінпаливенерго за погодженням з Кабінетом Міністрів України у складі голови комісії, його заступника та трьох членів комісії. Діяльність ревізійної комісії припиняється з дати прийняття Мінпаливенерго погодженого з Кабінетом Міністрів України рішення про її зміну. ( Абзац перший пункту 41 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

До складу ревізійної комісії не можуть входити особи, які перебувають у трудових відносинах з Компанією.

Ревізійна комісія діє на підставі положення, що затверджується Мінпаливенерго. ( Абзац третій пункту 41 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

42. Ревізійна комісія Компанії:

1) проводить перевірку фінансово-господарської діяльності Компанії та інформує Мінпаливенерго, Кабінет Міністрів України і наглядову раду Компанії про її результати; ( Підпункт 1 пункту 42 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

2) складає висновок за результатами перевірки річного фінансового звіту і бухгалтерського балансу Компанії;

3) повідомляє Мінпаливенерго і Кабінет Міністрів України про виникнення загрози інтересам держави та інтересам Компанії або виявлення зловживань, вчинених керівництвом Компанії. ( Підпункт 3 пункту 42 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

Трудовий колектив Компанії

43. Трудовий колектив Компанії становлять усі громадяни, які своєю працею беруть участь в її діяльності на основі трудового договору (контракту, угоди) або інших договорів, що регулюють трудові відносини працівника з Компанією.

44. Умови організації та оплати праці членів трудового колективу Компанії, а також їх соціального страхування визначаються відповідно до законодавства.

Відносини між адміністрацією Компанії та трудовим колективом регулюються колективним договором (угодою).

45. Трудовий колектив Компанії реалізує свої права через збори уповноважених представників трудового колективу (профспілкових органів).

Збори уповноважених представників трудового колективу проводяться не рідше ніж один раз на рік. Рішення зборів приймаються простою більшістю голосів присутніх на зборах представників трудового колективу шляхом відкритого голосування.

46. Збори уповноважених представників трудового колективу:

1) розглядають і схвалюють проект колективного договору;

2) заслуховують інформацію про виконання колективного договору;

3) розглядають питання матеріального і морального стимулювання працівників, заохочення винахідницької та раціоналізаторської діяльності.

47. Компанія встановлює норми праці, визначає форми, системи, розміри та види оплати праці згідно із законодавством.

Облік та звітність Компанії

48. Компанія веде оперативний, бухгалтерський та інший облік результатів своєї господарської діяльності відповідно до законодавства.

49. Фінансові результати діяльності Компанії визначаються на підставі річного бухгалтерського балансу.

Річний фінансовий звіт і бухгалтерський баланс підлягають затвердженню відповідно до цього Статуту.

50. Перший фінансовий рік Компанії починається з дати її державної реєстрації і закінчується 31 грудня того ж року. Наступні фінансові роки відповідають календарним.

51. Компанія забезпечує подання статистичної звітності органам державної статистики в обсягах та у строки, передбачені законодавством.

Припинення діяльності Компанії

52. Діяльність Компанії припиняється шляхом її реорганізації (злиття, приєднання, поділу, перетворення) або ліквідації.

53. Реорганізація Компанії проводиться за рішенням Мінпаливенерго, погодженим з Кабінетом Міністрів України.

У разі реорганізації Компанії її майнові права та обов'язки переходять до правонаступника.

( Пункт 53 із змінами, внесеними згідно з Постановою КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

54. Компанія ліквідується:

за рішенням Мінпаливенерго, погодженим з Кабінетом Міністрів України; ( Абзац другий пункту 54 із змінами, внесеними згідно з Постановою КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

у разі визнання її в установленому порядку банкрутом;

у разі скасування її державної реєстрації згідно із законодавством.

55. Ліквідація Компанії проводиться призначеною Мінпаливенерго за погодженням з Кабінетом Міністрів України комісією, а у разі припинення діяльності Компанії за рішенням суду - комісією, утвореною відповідно до рішення суду.

( Пункт 55 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

56. Ліквідаційна комісія протягом 10 днів після прийняття рішення про ліквідацію Компанії розміщує у газеті "Урядовий кур'єр" повідомлення про ліквідацію Компанії, порядок і строки подачі кредиторами претензій, а явних (відомих) кредиторів повідомляє письмово.

Одночасно ліквідаційна комісія вживає заходів до стягнення дебіторської заборгованості Компанії та виявлення кредиторів, повідомляючи кожного з них у письмовій формі про ліквідацію Компанії.

57. Ліквідаційна комісія оцінює наявне майно Компанії, розраховується з кредиторами, складає ліквідаційний баланс та подає його Мінпаливенерго або суду, за рішенням якого утворено комісію. Достовірність та повнота ліквідаційного балансу перевіряються в установленому законодавством порядку.

( Пункт 57 із змінами, внесеними згідно з Постановою КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

58. Майно Компанії, що залишилося після задоволення вимог кредиторів, використовується за рішенням Мінпаливенерго, погодженим з Кабінетом Міністрів України.

( Пункт 58 в редакції Постанови КМ N 1205 ( 1205-2005-п ) від 15.12.2005 )

59. Ліквідація Компанії вважається завершеною, а Компанія такою, що припинила свою діяльність, з моменту внесення запису про її ліквідацію до Державного реєстру.
