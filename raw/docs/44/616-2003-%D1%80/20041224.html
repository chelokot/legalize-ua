Кабінет Міністрів України; Розпорядження від 15.10.2003 № 616-р

Деякі питання Української державної акціонерної холдингової компанії "Укрпапірпром"

Стан: Дію відновлено

Ідентифікатор: 616-2003-р

Текст документа від 24.12.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 жовтня 2003 р. N 616-р Київ

( Дію Розпорядження відновлено згідно з Розпорядженням КМ N 969-р ( 969-2004-р ) від 24.12.2004 )

( Розпорядження втратило чинність на підставі Розпорядження КМ N 949-р ( 949-2004-р ) від 23.12.2004 )

Деякі питання Української державної акціонерної холдингової компанії "Укрпапірпром"

Прийняти пропозицію Фонду державного майна про передачу йому в управління державного пакета акцій ВАТ "Український науково-дослідний інститут паперу" у розмірі 50 відсотків плюс одна акція статутного фонду товариства, які вилучаються із статутного фонду Української державної акціонерної холдингової компанії "Укрпапірпром".

Прем'єр-міністр України В.ЯНУКОВИЧ
