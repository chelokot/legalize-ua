Кабінет Міністрів України; Розпорядження від 28.02.2000 № 100-р

Про зміни у складі робочої групи з проведення реформи центральних органів виконавчої влади

Стан: Втратив чинність

Ідентифікатор: 100-2000-р

Текст документа від 23.08.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 лютого 2000 р. N 100-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1115 ( 1115-2001-п ) від 23.08.2001 )

Затвердити Першого віце-прем'єр-міністра України Єханурова Юрія Івановича керівником робочої групи з проведення реформи центральних органів виконавчої влади, утвореної згідно з розпорядженням Кабінету Міністрів України від 16 вересня 1998 р. N 739 ( 739-98-р ), увільнивши від цих обов'язків Тігіпка Сергія Леонідовича.

Надати право керівнику робочої групи вносити зміни до її персонального складу.

Прем'єр-міністр України В.ЮЩЕНКО
