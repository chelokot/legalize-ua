Текст документа від 28.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 листопада 2006 р. N 580-р Київ

Про відзначення 175-річчя Київського національного університету імені Тараса Шевченка

{ Із змінами, внесеними згідно з Розпорядженням КМ N 470-р ( 470-2009-р ) від 28.04.2009 }

1. Утворити Організаційний комітет з підготовки та відзначення 175-річчя Київського національного університету імені Тараса Шевченка у складі згідно з додатком.

Надати голові Організаційного комітету право вносити у разі потреби зміни до його складу.

2. Затвердити план заходів з підготовки та відзначення 175-річчя Київського національного університету імені Тараса Шевченка на 2007-2009 роки, що додається.

3. МОН разом з Мінфіном та Мінекономіки передбачати під час формування проекту Державного бюджету України на відповідний рік видатки для виконання плану заходів, затвердженого цим розпорядженням.
