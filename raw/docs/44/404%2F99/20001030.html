Президент України; Указ від 21.04.1999 № 404/99

Про присвоєння почесного найменування "Львівський" 540 зенітному ракетному полку 28 корпусу протиповітряної оборони Військ Протиповітряної оборони України

Стан: Втратив чинність

Ідентифікатор: 404/99

Текст документа від 30.10.2000:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1173/2000 ( 1173/2000 ) від 30.10.2000 )

Про присвоєння почесного найменування "Львівський" 540 зенітному ракетному полку 28 корпусу протиповітряної оборони Військ Протиповітряної оборони України

Враховуючи бойові заслуги особового складу в період Великої Вітчизняної війни, його високий професіоналізм у забезпеченні протиповітряної оборони міста Львова у мирний час та з метою виховання військової молоді на бойових традиціях старшого покоління постановляю:

Присвоїти 540 зенітному ракетному полку 28 корпусу протиповітряної оборони Військ Протиповітряної оборони України почесне найменування "Львівський" і надалі іменувати його - 540 зенітний ракетний Львівський полк 28 корпусу протиповітряної оборони Військ Протиповітряної оборони України.

Президент України Л.КУЧМА

м. Київ, 21 квітня 1999 року N 404/99
