Президент України; Указ від 17.10.1997 № 1160/97

Про українську частину Спеціальної групи швидкого реагування для сприяння вирішенню спірних питань, що виникають у процесі реалізації інвестиційних проектів за участю американських компаній

Стан: Втратив чинність

Ідентифікатор: 1160/97

Текст документа від 13.11.2001:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про українську частину Спеціальної групи швидкого реагування для сприяння вирішенню спірних питань, що виникають у процесі реалізації інвестиційних проектів за участю американських компаній

( Із змінами, внесеними згідно з Указом Президента N 866/98 від 10.08.98 )

З метою подолання перешкод, що виникають у процесі реалізації інвестиційних проектів, постановляю:

1. Утворити українську частину Спеціальної групи швидкого реагування для сприяння вирішенню спірних питань, що виникають у процесі реалізації інвестиційних проектів за участю американських компаній (далі - українська частина Спеціальної групи), підпорядкувавши її Українській частині Секретаріату Українсько-американської міждержавної комісії.

Українська частина Спеціальної групи сприяє вирішенню спірних питань, що виникають між американськими інвесторами та органами виконавчої влади і місцевого самоврядування в Україні.

2. Затвердити персональний склад української частини Спеціальної групи (додається).

Уповноважити керівника української частини Спеціальної групи у разі потреби вносити зміни до її персонального складу.

3. Українська частина Спеціальної групи має право одержувати від центральних та місцевих органів виконавчої влади необхідну для її діяльності інформацію щодо реалізації інвестиційних проектів.

4. Українська частина Спеціальної групи співпрацює з українськими частинами Комітету з питань торгівлі та інвестицій Українсько-американської міждержавної комісії і Комітету з питань економічного співробітництва Українсько-американської міждержавної комісії.

5. Установити, що рішення української частини Спеціальної групи з питань, що належать до її компетенції, є обов'язковими для виконання центральними та місцевими органами виконавчої влади.

6. Робочим органом української частини Спеціальної групи є Національне агентство України з питань розвитку та європейської інтеграції. ( Стаття 6 із змінами, внесеними згідно з Указом Президента N 866/98 від 10.08.98 )

7. Керівникові української частини Спеціальної групи С. Тігіпку підготувати та подати в місячний строк проект Положення про українську частину Спеціальної групи швидкого реагування для сприяння вирішенню спірних питань, що виникають у процесі реалізації інвестиційних проектів за участю американських компаній.
