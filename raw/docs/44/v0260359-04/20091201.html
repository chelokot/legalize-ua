28.07.2004 N 260

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 395 ( v0395359-09 ) від 01.12.2009 }

Про форми фінансового звіту про надходження та використання коштів Державного бюджету України на підготовку і проведення виборів Президента України

Відповідно до частини дев'ятої статті 38 Закону України "Про вибори Президента України" ( 474-14 ), керуючись статтями 12, 13, пунктами 1, 17 статті 18, частиною п'ятою статті 23 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Затвердити форми фінансового звіту про надходження та використання коштів Державного бюджету України ( 1344-15 ) на підготовку і проведення виборів Президента України, що подаються до Центральної виборчої комісії територіальними виборчими комісіями після офіційного оприлюднення результатів виборів (додатки 1 ( va260359-04 ), 12 ( vb260359-04 ), 16 ( vc260359-04 ) до Інструкції про порядок складання місячної фінансової звітності у 2004 році установами та організаціями, які отримують кошти державного та/або місцевих бюджетів, затвердженої наказом Державного казначейства України від 31 січня 2004 року N 17 ( z0184-04 ).

2. Цю постанову надіслати територіальним виборчим комісіям після їх утворення.
