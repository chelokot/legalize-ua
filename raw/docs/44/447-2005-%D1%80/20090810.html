Про Голову Української частини комісій з військово-технічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 447-2005-р

Текст документа від 10.08.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 листопада 2005 р. N 447-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 780 ( 780-2009-п ) від 29.07.2009 }

Про Голову Української частини комісій з військово-технічного співробітництва

{ Із змінами, внесеними згідно з Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 }

Затвердити першого заступника Міністра промислової політики Головою Української частини Міждержавної Українсько-Французької комісії в галузі озброєння і військової техніки та Української частини Міжурядової Українсько-Південно-Африканської комісії з військово-технічного співробітництва, Міжурядової українсько-німецької комісії з питань військово-технічного співробітництва, міжурядових українсько-в'єтнамської, українсько-китайської координаційних комісій з питань військово-технічного співробітництва, увільнивши від обов'язків Голови цих комісій Казакова Валерія Петровича.

Мінпромполітики подати в установленому порядку на затвердження Кабінету Міністрів України оновлений склад Української частини зазначених комісій.

{ Розпорядження із змінами, внесеними згідно з Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 }

Прем'єр-міністр України Ю.ЄХАНУРОВ
