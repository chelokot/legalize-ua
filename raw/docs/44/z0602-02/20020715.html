N 372 від 15.07.2002 Зареєстровано в Міністерстві м. Київ юстиції України 23 липня 2002 р. за N 602/6890

Про затвердження Порядку проведення Держмитслужбою України деталізації товарів в Українській класифікації товарів зовнішньоекономічної діяльності на національному рівні

Відповідно до постанови Кабінету Міністрів України від 13.01.99 N 41 ( 41-99-п ) "Про Порядок ведення Української класифікації товарів зовнішньоекономічної діяльності" та з метою впорядкування роботи з розроблення, підготовки та реалізації заходів щодо деталізації товарів в Українській класифікації товарів зовнішньоекономічної діяльності ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) на національному рівні НАКАЗУЮ:

1. Затвердити Порядок проведення Держмитслужбою України деталізації товарів в Українській класифікації товарів зовнішньоекономічної діяльності ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) на національному рівні (додається).

2. Управлінню контролю митної вартості та номенклатури (Войцещук А.Д.) та Правовому управлінню (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Управлінню справами (Карпенко В.П.) забезпечити тиражування та розсилку цього наказу до регіональних митниць, митниць після його реєстрації в Міністерстві юстиції України.

4. Прес-службі (Гунько С.О.) забезпечити публікацію цього наказу в засобах масової інформації після його реєстрації в Міністерстві юстиції України.

5. Контроль за виконанням цього наказу покласти на заступника Голови Служби Дьоміна Ю.М.

Голова Служби М.М.Каленський

ЗАТВЕРДЖЕНО Наказ Державної митної служби України 15.07.2002 N 372

Зареєстровано в Міністерстві юстиції України 23 липня 2002 р. за N 602/6890

ПОРЯДОК проведення Держмитслужбою України деталізації товарів в Українській класифікації товарів зовнішньоекономічної діяльності ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) на національному рівні

Цей Порядок визначає процедуру розроблення, підготовки та реалізації Держмитслужбою України заходів щодо деталізації товарів в Українській класифікації товарів зовнішньоекономічної діяльності ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) (далі - УКТЗЕД) на національному рівні.

1. Прийняття Держмитслужбою України рішення про проведення деталізації товарів в УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) на національному рівні (далі - рішення)

1.1. Пропозиції про проведення деталізації товару в УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) на національному рівні (далі - пропозиції) приймаються Держмитслужбою України від:

центральних органів виконавчої влади;

управлінь центрального апарату Держмитслужби України.

1.2. Пропозиції мають містити такі відомості:

висновок про потребу проведення деталізації товару - від центрального органу виконавчої влади;

обгрунтування необхідності проведення деталізації товару в УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) - від управління центрального апарату Держмитслужби України;

класифікаційний код товару згідно з УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ), який потрібно деталізувати;

текстовий опис товару, який пропонується для виділення в УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 );

про призначення, склад, основні характеристики товару;

про характерні ознаки, які відрізняють товар, що пропонується для деталізації в УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ), від інших подібних товарів.

1.3. Пропозиції управлінь центрального апарату Держмитслужби України оформлюються службовою запискою на ім'я заступника Голови Служби, який курирує напрям ведення УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ).

1.4. Пропозиції розглядаються Управлінням контролю митної вартості та номенклатури й відділом ведення УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) Центральної митної лабораторії Держмитслужби України.

1.5. Відділ ведення УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) Центральної митної лабораторії:

перевіряє відповідність коду за УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ), до якого належить на цей час товар, текстовому опису товару, який пропонується для деталізації в УКТЗЕД;

визначає можливість класифікації та ідентифікації товару за запропонованим текстовим описом при проведенні його митного оформлення;

готує проект рішення та передає його до Управління контролю митної вартості та номенклатури.

1.6. Управління контролю митної вартості та номенклатури погоджує проект рішення з причетними до цього питання управліннями центрального апарату Держмитслужби України та подає на підпис заступнику Голови Служби, який курирує напрям ведення УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ).

1.7. Рішення складається з висновку про можливість або неможливість проведення деталізації товару в УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) на національному рівні та має містити: код товару за УКТЗЕД, запропонованого для деталізації, якщо проведення деталізації визнано можливим, і його текстовий опис, в іншому разі - обґрунтування неможливості проведення такої деталізації.

1.8. У разі відсутності інформації, зазначеної в пункті 1.2 цього Порядку, приймається рішення про неможливість проведення деталізації товару в УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) на національному рівні.

2. Здійснення Держмитслужбою України заходів щодо проведення деталізації товарів в УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 )

2.1. Рішення надсилається Держмитслужбою України центральному органу виконавчої влади або передається Управлінням контролю митної вартості та номенклатури управлінню центрального апарату Держмитслужби України, які звернулися з пропозиціями, для врахування при підготовці проекту закону України про внесення змін до Митного тарифу України (далі - проект закону).

2.2. Проект закону розглядається управліннями центрального апарату Держмитслужби України відповідно до Тимчасового регламенту Кабінету Міністрів України, затвердженого постановою Кабінету Міністрів України від 05.06.2000 N 915 ( 915-2000-п ).

2.3. Управління контролю митної вартості та номенклатури погоджує проект закону в частині відповідності текстових описів товарів кодам цих товарів за УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ).

2.4. Відділ ведення УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) Центральної митної лабораторії:

перевіряє відповідність кодів товарів за УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) текстовим описам цих товарів, що пропонуються в проекті закону;

перевіряє, чи враховані рішення Держмитслужби України про проведення деталізації товарів в УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) на національному рівні в проекті закону;

готує пропозиції Управлінню контролю митної вартості та номенклатури щодо погодження проекту закону, які стосуються відповідності кодів товарів за УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) текстовим описам цих товарів, наведеним у проекті закону.

2.5. Управління контролю митної вартості та номенклатури й відділ ведення УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) Центральної митної лабораторії готують проект наказу Держмитслужби України про внесення змін до еталонного примірника УКТЗЕД. Цей наказ набирає чинності одночасно з набранням чинності законом України про внесення змін до Митного тарифу України.

Начальник Управління контролю митної вартості та номенклатури А.Д.Войцещук
