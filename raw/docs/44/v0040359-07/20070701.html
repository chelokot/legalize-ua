ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

ПОСТАНОВА

30.05.2007 N 40

Про штатний розпис Центральної виборчої комісії на 2007 рік

{ Із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 565 ( v0565359-07 ) від 06.12.2007 }

Відповідно до статей 11, 12, пункту 7 частини другої статті 26, частини другої статті 33, частини першої статті 36 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), постанов Кабінету Міністрів України від 28 лютого 2002 року N 228 ( 228-2002-п ) "Про затвердження Порядку складання, розгляду, затвердження та основних вимог до виконання кошторисів бюджетних установ", від 30 червня 2005 року N 522 ( 522-2005-п ) "Про оплату праці Голови, заступників Голови та членів Центральної виборчої комісії", від 9 березня 2006 року N 268 ( 268-2006-п ) "Про упорядкування структури та умов оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів", наказу Міністерства праці та соціальної політики України від 2 жовтня 1996 року N 77 ( z0593-96 ) "Про умови оплати праці робітників, зайнятих обслуговуванням органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів" та Колективного договору автогосподарства Центральної виборчої комісії на 2005 рік, зареєстрованого Управлінням праці та соціального захисту населення Печерської районної державної адміністрації 15 вересня 2006 року N 309, Центральна виборча комісія постановляє:

1. Затвердити штатний розпис Центральної виборчої комісії на 2007 рік (додається*).

{ Зміни до штатного розпису див. в Постанові Центральної виборчої комісії N 565 ( v0565359-07 ) від 06.12.2007 }

2. Відділу бухгалтерського обліку та звітності Секретаріату Центральної виборчої комісії провести перерахунок заробітної плати Секретаря Центральної виборчої комісії з 26 травня 2007 року, працівників Секретаріату, патронатної служби Центральної виборчої комісії з 1 травня 2007 року та технічних працівників Секретаріату Центральної виборчої комісії - з 1 квітня 2007 року.

3. Визнати такими, що втратили чинність, постанови Центральної виборчої комісії від 26 травня 2006 року N 1246 ( v1246359-06 ), від 25 вересня 2006 року N 1277 ( v1277359-06 ) та від 14 грудня 2006 року N 1296 ( v1296359-06 ).
