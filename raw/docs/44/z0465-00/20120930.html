N 388 від 13.07.2000 Зареєстровано в Міністерстві юстиції України 31 липня 2000 р. за N 465/4686

{ Наказ втратив чинність на підставі Наказу Міністерства фінансів N 651 ( z1372-12 ) від 30.05.2012 }

Про внесення доповнень до додатка 2 до наказу Держмитслужби від 09.07.97 N 307

У зв'язку з набранням чинності Законами України "Про спеціальну економічну зону "Рені" ( 1605-14 ), "Про спеціальний режим інвестиційної та інноваційної діяльності технологічних парків "Напівпровідникові технології і матеріали, оптоелектроніка та сенсорна техніка", "Інститут електрозварювання імені Є.О.Патона", "Інститут монокристалів" ( 991-14 ) та з метою вдосконалення контролю за переміщенням товарів та інших предметів через митний кордон України НАКАЗУЮ:

1. Унести до розділу 2 "Особливості переміщення товарів через митний кордон України" додатка 2 до наказу Держмитслужби від 09.07.97 N 307 ( z0443-97 ) такі доповнення:

1.1. "N Найменування особливості поставки товарів Код

47 Переміщення товарів та інших предметів 90 технологічними парками для реалізації інвестиційних та інноваційних проектів за пріоритетними напрямами науково- технічної діяльності, у тому числі:

"Напівпровідникові технології і мате- 91 ріали, оптоелектроніка та сенсорна техніка" (Київ)

"Інститут електрозварювання імені 92 Є.О.Патона" (Київ)

"Інститут монокристалів" (м.Харків) 93.

1.2. Порядковий номер 44 доповнити словами:

"у (із) СЕЗ "Рені" 67".

2. Управлінню статистики (Овдієнко Н.Т.), Правовому управлінню (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Інформаційно-аналітичному митному управлінню (Копосов С.А.) у п'ятиденний термін після реєстрації цього наказу в Міністерстві юстиції України внести потрібні зміни до нормативно-довідкової інформації, у тому числі до довідників програмно-інформаційного комплексу "Митне оформлення вантажів" та інших, які використовуються при митному оформленні.

4. Начальникам регіональних митниць, митниць довести цей наказ до відома митних брокерів та суб'єктів зовнішньоекономічної діяльності, зареєстрованих у зоні діяльності митних органів.

5. Контроль за виконанням наказу покласти на заступника Голови Служби Шейка О.П.
