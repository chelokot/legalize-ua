Текст документа від 01.01.2012:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Указу Президента України від 21 вересня 2001 року N 850

{ Із змінами, внесеними згідно з Указом Президента N 1110/2011 ( 1110/2011 ) від 09.12.2011 }

Внести до Указу Президента України від 21 вересня 2001 року N 850 ( 850/2001 ) "Питання Української Академії державного управління при Президентові України" такі зміни:

{ Стаття 1 втратила чинність у частині внесення змін до статті 1 Указу ( 850/2001 ) та до Основних напрямів реформування Української Академії державного управління при Президентові України ( 850/2001 ) на підставі Указу Президента N 1110/2011 ( 1110/2011 ) від 09.12.2011 }

1. У назві, преамбулі, статтях 1-3 Указу ( 850/2001 ), Основних напрямах реформування Української Академії державного управління при Президентові України слова "Українська Академія державного управління при Президентові України" в усіх відмінках замінити словами "Національна академія державного управління при Президентові України" у відповідних відмінках.

2. У Положенні про Українську Академію державного управління при Президентові України ( 850/2001 ):

1) слова "Українська Академія державного управління при Президентові України" в усіх відмінках замінити словами "Національна академія державного управління при Президентові України" у відповідних відмінках;

2) доповнити Положення новим пунктом 14-1 такого змісту:

"14-1. Для сприяння належному функціонуванню Академії створюється Наглядова рада, склад якої затверджує Президент України".

Президент України Л.КУЧМА

м. Київ, 6 жовтня 2003 року N 1153/2003
