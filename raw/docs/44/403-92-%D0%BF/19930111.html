Кабінет Міністрів України; Постанова від 21.07.1992 № 403

Про надання додаткових пільг по акцизному збору запорізькому виробничому об'єднанню "АвтоЗАЗ"

Стан: Втратив чинність

Ідентифікатор: 403-92-п

Текст документа від 11.01.1993:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 липня 1992 р. N 403 Київ

( Постанова втратила чинність на підставі Постанови КМ N 741 ( 741-92-п ) від 26.12.92 )

Про надання додаткових пільг по акцизному збору запорізькому виробничому об'єднанню "АвтоЗАЗ"

З метою збереження обсягів виробництва автомобілів марки "Запорожець" ЗАЗ-968М та відповідно до статті 5 Закону України "Про акцизний збір" ( 1996-12 ) Кабінет Міністрів України постановляє:

Зменшити на 60 процентів ставку акцизного збору на автомобілі марки "Запорожець" ЗАЗ-968М для запорізького виробничого об'єднання "АвтоЗАЗ", відвантажені після 21 липня 1992 року.
