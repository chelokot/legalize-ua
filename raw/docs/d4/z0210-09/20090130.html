МІНІСТЕРСТВО ЕКОНОМІКИ УКРАЇНИ

НАКАЗ

30.01.2009 N 60

Зареєстровано в Міністерстві юстиції України 10 березня 2009 р. за N 210/16226

Про визнання такими, що втратили чинність, наказів Мінекономіки

У зв'язку з втратою чинності постанови Кабінету Міністрів України від 28.03.2008 N 274 ( 274-2008-п ) "Про здійснення закупівель товарів, робіт і послуг за державні кошти" та набранням чинності постанови Кабінету Міністрів України від 17.10.2008 N 921 ( 921-2008-п ) "Про затвердження Положення про закупівлю товарів, робіт і послуг за державні кошти" (зі змінами) НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

наказ Міністерства економіки України від 04.04.2008 N 108 ( z0326-08 ) "Про затвердження форм документів у сфері державних закупівель", зареєстрований у Міністерстві юстиції України 17.04.2008 за N 326/15017;

наказ Міністерства економіки України від 04.04.2008 N 110 ( z0372-08 ) "Про затвердження Порядку приймання та опублікування оголошень щодо проведення закупівель товарів, робіт і послуг в інформаційному бюлетені "Вісник державних закупівель", зареєстрований у Міністерстві юстиції України 25.04.2008 за N 372/15063;

наказ Міністерства економіки України від 14.04.2008 N 126 ( z0373-08 ) "Про затвердження Порядку розгляду скарг, поданих учасниками до моменту укладення договору про закупівлю", зареєстрований у Міністерстві юстиції України 25.04.2008 за N 373/15064;

наказ Міністерства економіки України від 15.04.2008 N 128 ( z0374-08 ) "Про затвердження Порядку погодження застосування процедури торгів з обмеженою участю та процедури закупівлі в одного учасника", зареєстрований у Міністерстві юстиції України 25.04.2008 за N 374/15065;

наказ Міністерства економіки України від 01.07.2008 N 251 ( z0763-08 ) "Про здійснення контролю за дотриманням законодавства щодо державних закупівель", зареєстрований у Міністерстві юстиції України 18.08.2008 за N 763/15454;

наказ Міністерства економіки України від 01.07.2008 N 252 ( z0764-08 ) "Про затвердження форми річного плану державних закупівель та Інструкції щодо її заповнення", зареєстрований у Міністерстві юстиції України 18.08.2008 за N 764/15455.

2. Скасувати наказ Міністерства економіки України від 05.11.2008 N 630 "Про визнання такими, що втратили чинність, наказів Мінекономіки".

3. Департаменту державних закупівель забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням цього наказу залишаю за собою.

Міністр економіки України Б.М.Данилишин
