Кабінет Міністрів України; Постанова від 25.12.2002 № 2005

Про голову Української частини міжурядових комісій з питань національних меншин

Стан: Втратив чинність

Ідентифікатор: 2005-2002-п

Текст документа від 05.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 грудня 2002 р. N 2005 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 440 ( 440-2012-п ) від 17.05.2012 }

Про голову Української частини міжурядових комісій з питань національних меншин

{ Із змінами, внесеними згідно з Постановами КМ N 147 ( 147-2006-п ) від 15.02.2006 N 960 ( 960-2007-п ) від 25.07.2007 }

Кабінет Міністрів України постановляє:

Затвердити Голову Державного комітету у справах національностей та релігій за посадою головою Української частини Двосторонньої Українсько-Словацької комісії з питань національних меншин, освіти і культури, Змішаної міжурядової Українсько-Румунської комісії з питань забезпечення прав осіб, які належать до національних меншин, Змішаної Українсько-Угорської комісії з питань забезпечення прав національних меншин.

{ Постановляюча частина в редакції Постанови КМ N 147 ( 147-2006-п ) від 15.02.2006; із змінами внесеними згідно з Постановою КМ N 960 ( 960-2007-п ) від 25.07.2007 }
