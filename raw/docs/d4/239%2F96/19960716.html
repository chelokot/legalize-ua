Ідентифікатор: 239/96

Текст документа від 16.07.1996:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про утворення Урядової комісії з питань акціонування стратегічно важливих промислових підприємств із залученням іноземних інвестицій

( Перейменувати комісію в Комісію з питань акціонування стратегічно важливих промислових підприємств згідно з Указом Президента N 574/96 ( 574/96 ) від 16.07.96 )

З метою забезпечення ефективного використання іноземних інвестицій, визначення найбільш раціональних форм співробітництва з іноземними інвесторами, підготовки висновків щодо оптимальних варіантів приватизації, розроблених у встановленому законом порядку, підвищення конкурентоспроможності вітчизняної продукції, організації проведення тендерів серед іноземних інвесторів постановляю:

1. Утворити Урядову комісію з питань акціонування стратегічно важливих промислових підприємств із залученням іноземних інвестицій (далі - Комісія).

( Перейменувати комісію в Комісію з питань акціонування стратегічно важливих промислових підприємств згідно з Указом Президента N 574/96 ( 574/96 ) від 16.07.96 )

2. Затвердити персональний склад Комісії (додається).

3. Надати право Комісії залучати до роботи вчених, спеціалістів міністерств, інших органів державної виконавчої влади та одержувати інформацію, необхідну для її роботи.

Президент України Л.КУЧМА

м.Київ, 5 квітня 1996 року N 239/96
