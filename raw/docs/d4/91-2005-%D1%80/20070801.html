Про індексацію тарифів на перевезення вантажів залізничним транспортом та пов'язані з цим послуги

{ Із змінами, внесеними згідно з Розпорядженням КМ N 233-р ( 233-2005-р ) від 01.07.2005 }

1. Погодитися з пропозицією Мінтрансзв'язку щодо індексації тарифів на перевезення вантажів залізничним транспортом та пов'язані з цим послуги у розмірах згідно з додатком.

( Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 233-р ( 233-2005-р ) від 01.07.2005 )

2. Мінтрансзв'язку до 1 травня 2005 р. подати Міжвідомчій комісії з моніторингу впливу на економіку тарифної політики, що проводиться на залізничному транспорті, пропозиції стосовно удосконалення системи тарифного регулювання перевезень вантажів залізничним транспортом.
