Про порядок розгляду питання про обрання на посаду судді безстроково

Стан: Втратив чинність

Ідентифікатор: 253/97-вр

Текст документа від 14.05.1997:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про порядок розгляду питання про обрання на посаду судді безстроково

( Відомості Верховної Ради України (ВВР), 1997, N 22, ст. 164 )

Верховна Рада України постановляє:

Відповідно до пункту 27 статті 85 Конституції України ( 254к/96-ВР ) встановити тимчасово, до законодавчого врегулювання, такий порядок обрання суддів безстроково:

1. Комітет з питань правової політики та судово-правової реформи після розгляду кандидатур на своєму засіданні, із запрошенням на нього народних депутатів України від відповідних виборчих округів, подає свій висновок на проект постанови щодо особи, яка рекомендується для обрання на посаду судді безстроково.

2. Особа, яка пропонується для обрання на посаду судді безстроково, запрошується на трибуну Верховної Ради України для відповіді на запитання народних депутатів України. Обговорення кандидатури проводиться за процедурою, визначеною Регламентом Верховної Ради України ( 129а/94-ВР, 129б/94-ВР ).

3. Голосування відбувається по кожній особі, яка рекомендується на посаду судді безстроково (за винятком суддів Верховного Суду України та суддів Вищого арбітражного суду України), за допомогою електронної системи підрахунку голосів у відкритому нефіксованому режимі.

Відповідно до статті 91 Конституції України обраною на посаду судді безстроково вважається особа, за яку проголосувала більшість від конституційного складу Верховної Ради України.

4. Результати голосування щодо обрання осіб, яких рекомендовано на посади суддів безстроково, оформляються постановою Верховної Ради України.
