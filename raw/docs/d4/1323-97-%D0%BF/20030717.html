Кабінет Міністрів України; Постанова від 28.11.1997 № 1323

Про фінансове забезпечення будівництва енергоблоків N 2 Хмельницької та N 4 Рівненської АЕС

Стан: Втратив чинність

Ідентифікатор: 1323-97-п

Текст документа від 17.07.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 листопада 1997 р. N 1323 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1098 ( 1098-2003-п ) від 17.07.2003 )

Про фінансове забезпечення будівництва енергоблоків N 2 Хмельницької та N 4 Рівненської АЕС

( Із змінами, внесеними згідно з Постановою КМ N 776 ( 776-2000-п ) від 07.05.2000 )

З метою забезпечення фінансування закінчення будівництва енергоблоків N 2 Хмельницької та N 4 Рівненської АЕС Кабінет Міністрів України постановляє:

1. Рекомендувати Національній комісії з питань регулювання електроенергетики підвищити з 1 січня 1998 р. тарифи на електроенергію, що відпускається атомними електростанціями Міністерства енергетики, шляхом встановлення цільової надбавки до загального тарифу для Національної атомної енергогенеруючої компанії "Енергоатом" у розмірі, достатньому для добудови енергоблоків N 2 Хмельницької та N 4 Рівненської АЕС згідно з графіками будівництва, з одночасним коригуванням роздрібних цін для споживачів електроенергії.

Компанії "Енергоатом":

відкрити спеціальний рахунок в установі банку для акумулювання коштів шляхом щоденного перерахування з транзитного рахунку частини виручки за реалізовану на енергоринку електроенергію, пропорційної підвищенню тарифів;

забезпечити цільове використання коштів і цінних паперів для виконання робіт, закупівлі обладнання і комплектуючих, необхідних для добудови зазначених енергоблоків.

( Пункт 2 втратив чинність на підставі Постанови КМ N 776 ( 776-2000-п ) від 07.05.2000 )

3. Міністерству енергетики, Міністерству економіки, Міністерству фінансів, Державній податковій адміністрації підготувати пропозиції щодо виключення фактичних витрат на фінансування добудови енергоблоків з валового доходу Національної атомної енергогенеруючої компанії "Енергоатом", який підлягає оподаткуванню.

4. Контроль за виконанням цієї постанови покласти на Міністра енергетики Шеберстова О.М. та Першого віце-прем'єр-міністра України Голубченка А.К.
