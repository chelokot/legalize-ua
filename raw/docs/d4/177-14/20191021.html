Текст документа від 21.10.2019:

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України

( Відомості Верховної Ради України (ВВР), 1998, N 49, ст.301 )

{ Із змінами, внесеними згідно із Законом N 2269-VIII ( 2269-19 ) від 18.01.2018, ВВР, 2018, N 12, ст.68 Кодексом N 2597-VIII ( 2597-19 ) від 18.10.2018, ВВР, 2019, N 19, ст.74 }

У зв'язку з прийняттям Закону України "Про внесення змін до Закону України "Про підприємства в Україні" ( 72/98-ВР ) ( Відомості Верховної Ради України, 1998 р., N 24, ст.138 ) Верховна Рада України постановляє:

I. Внести до деяких законів України такі зміни:

{ Пункт 1 розділу I втратив чинність на підставі Кодексу N 2597-VIII ( 2597-19 ) від 18.10.2018 }

2. Частину другу статті 4 Закону України "Про оренду державного та комунального майна" ( 2269-12 ) (Відомості Верховної Ради України, 1995 р., N 15, ст. 99; 1998 р., N 18, ст. 88) доповнити абзацами третім та четвертим такого змісту:

"цілісні майнові комплекси казенних підприємств;

цілісні майнові комплекси структурних підрозділів (філій, цехів, дільниць) казенних підприємств, що здійснюють діяльність, передбачену частиною першою статті 4 Закону України "Про підприємництво".

{ Пункт 3 розділу I втратив чинність на підставі Закону N 2269-VIII ( 2269-19 ) від 18.01.2018 }

II. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА
