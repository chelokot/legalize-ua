Стан: Втратив чинність

Текст документа від 05.06.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 496/2007 ( 496/2007 ) від 05.06.2007 }

Про зупинення дії статті 2 Указу Президента України від 26 квітня 2007 року N 355

{ Із змінами, внесеними згідно з Указом Президента N 480/2007 ( 480/2007 ) від 31.05.2007 N 482/2007 ( 482/2007 ) від 01.06.2007 }

З метою реалізації невідкладних заходів, спрямованих на розв'язання політичної кризи шляхом проведення позачергових виборів до Верховної Ради України, постановляю:

1. Зупинити на 29, 30, 31 травня та 1 червня 2007 року дію статті 2 Указу Президента України від 26 квітня 2007 року N 355 ( 355/2007 ) "Про дострокове припинення повноважень Верховної Ради України та призначення позачергових виборів".

{ Стаття 1 із змінами, внесеними згідно з Указами Президента N 480/2007 ( 480/2007 ) від 31.05.2007, N 482/2007 ( 482/2007 ) від 01.06.2007 }

2. Цей Указ набирає чинності з дня його офіційного оприлюднення.

Президент України В.ЮЩЕНКО

м. Київ, 29 травня 2007 року N 476/2007
