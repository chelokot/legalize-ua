Кабінет Міністрів України; Постанова від 11.05.2006 № 635

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для здійснення заходів з відтворення культури національних меншин та фінансової підтримки газет, що видаються мовами національних меншин

Стан: Чинний

Ідентифікатор: 635-2006-п

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 травня 2006 р. N 635 Київ

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для здійснення заходів з відтворення культури національних меншин та фінансової підтримки газет, що видаються мовами національних меншин

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Установити, що кошти, передбачені у державному бюджеті ( 3235-15 ) для здійснення заходів з відтворення культури національних меншин та фінансової підтримки газет, що видаються мовами національних меншин, використовуються у 2006 році відповідно до Порядку використання коштів, передбачених у державному бюджеті для здійснення заходів з відтворення культури національних меншин та фінансової підтримки газет мовами національних меншин, затвердженого постановою Кабінету Міністрів України від 30 листопада 2005 р. N 1124 ( 1124-2005-п ) (Офіційний вісник України, 2005 р., N 48, ст. 3001).

Прем'єр-міністр України Ю.ЄХАНУРОВ
