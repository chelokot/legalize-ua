( Із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 418/711 ( z1453-04 ) від 15.11.2004 )

На виконання Закону України "Про Державний бюджет України на 2004 рік" ( 1344-15 ) та рішення Урядового Комітету з реформування аграрного сектору від 15 березня 2004 року, з метою забезпечення фінансової підтримки виробництва сільськогосподарської продукції на зрошуваних землях у 2004 році через механізм компенсації вартості електроенергії, яка спожита сільськогосподарськими підприємствами для поливу сільськогосподарських культур на зрошуваних землях та заповнення водою земель для вирощування рису, НАКАЗУЄМО:

1. Затвердити Порядок використання коштів Державного бюджету України на 2004 рік, що спрямовуються на повну компенсацію вартості електроенергії, спожитої сільськогосподарськими підприємствами для поливу сільськогосподарських культур на зрошуваних землях та заповнення водою земель для вирощування рису (додається). ( Пункт 1 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 418/711 ( z1453-04 ) від 15.11.2004 )

2. Департаменту науково-технічної політики (Саченко В.І.), Департаменту фінансово-кредитної та податкової політики (Зуб Г.І.) Міністерства аграрної політики України в установленому порядку:

забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України;

довести Порядок до відома структурних підрозділів Міністерства аграрної політики України, Державного комітету по водному господарству України, Міністерства агропромислового комплексу Автономної Республіки Крим, головних управлінь сільського господарства і продовольства обласних державних адміністрацій, Республіканського комітету по водному господарству Автономної Республіки Крим, обласних виробничих управлінь меліорації та водного господарства.

ЗАТВЕРДЖЕНО Наказ Міністерства аграрної політики України, Міністерства фінансів України 25.03.2004 N 105/223

Зареєстровано в Міністерстві юстиції України 29 березня 2004 р. за N 382/8981

ПОРЯДОК використання коштів Державного бюджету України на 2004 рік, що спрямовуються на повну компенсацію вартості електроенергії, спожитої сільськогосподарськими підприємствами для поливу сільськогосподарських культур на зрошуваних землях та заповнення водою земель для вирощування рису

( У назві Порядку і далі за текстом слово "часткову" у всіх відмінках замінено словом "повну" у відповідних відмінках згідно з Наказом Міністерства аграрної політики N 418/711 ( z1453-04 ) від 15.11.2004 )

1. Цей Порядок визначає механізм нарахування і виплат коштів загального фонду Державного бюджету України на 2004 рік (КПКВ 2801210) в обсязі 20000 тис. гривень на компенсацію сільськогосподарським підприємствам усіх форм власності та господарювання, у тому числі дослідним господарствам Української академії аграрних наук, фермерським господарствам та приватним підприємствам, повної вартості електроенергії, спожитої для поливу сільськогосподарських культур на зрошуваних землях та заповнення водою земель для вирощування рису (далі - для поливу), у межах бюджетних коштів, які виділяються регіонам згідно з додатком 1. ( Абзац перший пункту 1 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 418/711 ( z1453-04 ) від 15.11.2004 )

Головним розпорядником коштів, виділених для оплати електроенергії, використаної для поливу, є Міністерство аграрної політики України, розпорядниками другого рівня - Міністерство агропромислового комплексу Автономної Республіки Крим та головні управління сільського господарства і продовольства облдержадміністрацій, одержувачами - сільськогосподарські підприємства, які мають зрошувані землі та здійснюють заповнення водою земель для вирощування рису.

2. Міністерство агропромислового комплексу Автономної Республіки Крим, головні управління сільського господарства і продовольства обласних державних адміністрацій:

- за поданням управлінь сільського господарства і продовольства районних державних адміністрацій визначають перелік сільськогосподарських підприємств із зазначенням орієнтовного обсягу споживання електроенергії та суми коштів, на яку буде надана повна компенсація вартості спожитої електроенергії для поливу у 2004 році. До переліку включаються сільськогосподарські підприємства, які отримують воду з насосних станцій державних меліоративних систем, а також ті, які забезпечують подачу води для поливу власними насосними установками і мають відповідний облік електроенергії, що споживається для поливу (далі - сільськогосподарські підприємства). Інформація про прийняте рішення обов'язково доводиться до управлінь сільського господарства і продовольства районних державних адміністрацій.

При цьому не може бути прийнято рішень щодо включення до переліку сільськогосподарських підприємств для надання повної компенсації вартості електроенергії, спожитої для поливу сільськогосподарських культур на зрошуваних землях та заповнення водою земель для вирощування рису, понад бюджетні призначення, установлені регіонам додатком 1 до цього Порядку;

- щомісяця складають реєстри сільськогосподарських підприємств, включених до переліків для надання повної компенсації, у яких зазначається обсяг фактично спожитої електроенергії для поливу та обсяг належної їм 50-відсоткової компенсації.

До помісячних реєстрів включаються сільськогосподарські підприємства в порядку черговості подання ними відповідних документів управлінням сільського господарства і продовольства районних державних адміністрацій, з урахуванням сум компенсації, не відшкодованої їм у попередні місяці, та в межах доведеного помісячного розпису асигнувань.

3. Фактичні витрати електроенергії, використаної для поливу сільгоспкультур, по сільськогосподарських підприємствах підтверджуються актами звіряння на підставі показів приладів обліку електроенергії, установлених на зрошувальних насосних станціях, які зводяться у реєстр щодо району. Акти звіряння підписуються представниками водогосподарської організації, у зоні діяльності якої перебуває внутрішньогосподарська зрошувальна система, енергопостачальної компанії і сільськогосподарських підприємств. Зведений реєстр щодо району підписується керівниками управлінь сільського господарства і продовольства райдержадміністрацій, енергопостачальної та водогосподарської організацій і затверджується головою райдержадміністрації згідно з додатком 2.

Районні реєстри зводяться Міністерством агропромислового комплексу Автономної Республіки Крим, головними управліннями сільського господарства і продовольства обласних державних адміністрацій в регіональні реєстри, які погоджуються з Республіканським комітетом по водному господарству Автономної Республіки Крим, обласними виробничими управліннями водного господарства і меліорації, регіональними енергопостачальними організаціями та подаються Міністерству аграрної політики України за формою згідно з додатком 3.

Підставою для визначення обсягів компенсації є погоджені з енергопостачальною організацією розрахунки вартості електроенергії, необхідної для поливу сільгоспкультур, здійснені на підставі угоди між власником зрошуваних земель і водогосподарською організацією, на балансі якої перебуває точка водовиділу. Якщо вода з джерела зрошення забирається насосною станцією, що належить власнику зрошуваних сільгоспугідь, то підставою є погоджені з водогосподарською організацією плани водокористування та угода між цим власником і енергопостачальною організацією.

У розрахунки для повного відшкодування вартості електроенергії, спожитої для поливу, включаються тільки обсяги електроенергії, необхідної для реалізації угод, укладених з водогосподарськими або енергопостачальницькими організаціями за умови наявності у власника зрошуваних земель дозволу на спеціальне водокористування.

Міністерство аграрної політики України на підставі поданих реєстрів у межах наявних коштів подає Державному казначейству розподіл коштів по Міністерству агропромислового комплексу Автономної Республіки Крим, головних управліннях сільського господарства і продовольства обласних державних адміністрацій.

Проведення видатків державного бюджету, що спрямовуються на повну компенсацію вартості електроенергії, яка спожита сільськогосподарськими підприємствами для поливу, здійснюється Державним казначейством України за розподілом Мінагрополітики України відповідно до діючого порядку касового виконання державного бюджету за видатками.

Міністерство агропромислового комплексу Автономної Республіки Крим, головні управління сільського господарства і продовольства обласних державних адміністрацій за умови наявності в сільськогосподарського підприємства платіжного доручення з відміткою банку про оплату за використану електроенергію для поливу в обсязі не менше 50 відсотків, угоди з водогосподарською або енергопостачальницькою організацією, актів звірок витрат електроенергії на підставі показів приладів обліку споживання електроенергії, підписаних водогосподарською або енергопостачальницькою організацією, кошторису і плану використання бюджетних коштів забезпечують перерахування коштів на поточні рахунки сільськогосподарських підприємств в установах банку, а при відсутності зазначеного платіжного доручення - на рахунки водогосподарських або енергопостачальницьких організацій.

Кошти, що надходитимуть у регіони, повинні розподілятися пропорційно між усіма сільськогосподарськими підприємствами, уключеними до реєстрів на отримання повної компенсації.

Міністерство агропромислового комплексу Автономної Республіки Крим, головні управління сільського господарства і продовольства обласних державних адміністрацій складають додатковий реєстр за формою згідно з додатком 4, у якому враховується обсяг компенсації за електроенергію, спожиту для поливу, який не було враховано в попередніх реєстрах. ( Пункт 3 доповнено абзацом дев'ятим згідно з Наказом Міністерства аграрної політики N 418/711 ( z1453-04 ) від 15.11.2004 )

4. Складання та подання звітності про використання бюджетних коштів здійснюється за формами та в порядку, що встановлені Державним казначейством України.

Міністерство агропромислового комплексу Автономної Республіки Крим, головні управління сільського господарства і продовольства щомісяця до 15-го числа місяця, наступного за звітним, подають Міністерству аграрної політики звіти про надання повної компенсації вартості електроенергії для поливу згідно з додатком 5, а також подають до 5 грудня 2004 року підсумковий звіт згідно з додатком 6. ( Абзац другий пункту 4 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 418/711 ( z1453-04 ) від 15.11.2004 )

Департамент фінансово-кредитної та податкової політики Міністерства аграрної політики України до 20-го числа місяця, наступного за звітним, подає звіт Міністерству фінансів.

5. Міністерство аграрної політики України за погодженням з Міністерством фінансів України має право перерозподіляти між регіонами невикористаний обсяг бюджетних коштів, передбачених на повну компенсацію електроенергії, спожитої сільськогосподарськими підприємствами для поливу.

6. Контроль за використанням та відповідальність за нецільове використання коштів, передбачених на повну компенсацію вартості електроенергії, що споживається сільськогосподарськими підприємствами для поливу, покладаються на Міністерство аграрної політики України, Міністерство агропромислового комплексу

Автономної Республіки Крим, головні управління сільського господарства і продовольства обласних державних адміністрацій та на керівників сільгосппідприємств згідно із законодавством.
