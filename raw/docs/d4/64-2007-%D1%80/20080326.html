РОЗПОРЯДЖЕННЯ від 21 лютого 2007 р. N 64-р Київ

Про утворення робочої групи з підготовки проекту Податкового кодексу України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 536-р ( 536-2008-р ) від 26.03.2008 }

Утворити робочу групу з підготовки проекту Податкового кодексу України у складі згідно з додатком.

Надати керівникові робочої групи право вносити у разі потреби зміни до її складу.
