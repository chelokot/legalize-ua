Про затвердження тарифів на оплату послуг, пов'язаних з виплатою і доставкою державних пенсій та грошової допомоги

{ Із змінами, внесеними згідно з Наказом Міністерства транспорту та зв'язку N 1104 ( z1242-06 ) від 23.11.2006 }

Відповідно до постанови Кабінету Міністрів України від 25 грудня 1996 року N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", із змінами та доповненнями, НАКАЗУЮ:

1. Затвердити тарифи на оплату послуг, пов'язаних з виплатою і доставкою державних пенсій та грошової допомоги, що додаються, та запровадити їх з моменту набрання чинності постановою Кабінету Міністрів України від 04.08.2004 N 996 ( 996-2004-п ) "Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України".

2. Генеральному директору Українського державного підприємства поштового зв'язку "Укрпошта" Мухіну В.Г. забезпечити своєчасне доведення до регіональних дирекцій затверджених тарифів, здійснення постійного контролю за правильністю їх застосування відповідно до чинного законодавства.

{ Пункт 3 втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 1104 ( z1242-06 ) від 23.11.2006 }

4. Контроль за виконанням цього наказу покласти на заступника Голови Коляденка В.А.

ТАРИФИ на оплату послуг, пов'язаних з виплатою і доставкою державних пенсій та грошової допомоги

1. Тарифи на оплату послуг, пов'язаних з виплатою і доставкою державних пенсій та грошової допомоги, застосовуються підприємствами (операторами) зв'язку, що надають ці послуги, крім випадків, обумовлених законодавством.

2. Тарифи розраховані без урахування податку на додану вартість відповідно до Закону України "Про податок на додану вартість" ( 168/97-ВР ).
