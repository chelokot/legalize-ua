НАКАЗ

N 24 від 21.01.2002 Зареєстровано в Міністерстві юстиції України 24 січня 2002 р. за N 53/6341

( Наказ втратив чинність на підставі Наказу Міністерства транспорту N 934 ( z1015-02 ) від 27.12.2002 )

Про внесення доповнень до наказу Міністерства транспорту України від 05.02.01 N 68

Відповідно до постанови Кабінету Міністрів України від 25 грудня 1996 року N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

1. Унести доповнення до Коефіцієнтів, що застосовуються до тарифів Збірника тарифів на перевезення вантажів залізничним транспортом України, затверджених наказом Міністерства транспорту України від 05.02.2001 N 68 ( z0115-01 ) "Про затвердження Коефіцієнтів, що застосовуються до тарифів Збірника тарифів на перевезення вантажів залізничним транспортом України, змін і доповнень до цього Збірника" і зареєстрованих у Міністерстві юстиції України 05.02.2001 за N 115/5306 (із доповненнями, внесеними наказом Міністерства транспорту України від 21.05.2001 N 302 ( z0460-01 ) "Про внесення доповнень до наказу Міністерства транспорту України від 05.02.01 N 68" і зареєстрованими у Міністерстві юстиції України 30.05.2001 за N 460/5651), що додаються.

2. Департаменту транспортної політики (Легенький Г.М.) разом з Департаментом нормативно-правового забезпечення (Логінова Л.М.) в установленому порядку зареєструвати цей наказ у Міністерстві юстиції України.

3. Укрзалізниці (Кірпа Г.М.) після реєстрації цього наказу в Міністерстві юстиції України забезпечити своєчасне його доведення до відома вантажовідправників, вантажоодержувачів та населення України.

4. Контроль за виконанням наказу покласти на заступника Державного секретаря Вислоуха О.В.

Міністр транспорту України В.Пустовойтенко
