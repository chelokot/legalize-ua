{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 1104 ( z1242-06 ) від 23.11.2006 }

Про внесення змін та доповнень до наказу Держкомзв'язку України від 07.06.2002 N 120

На виконання Закону України "Про внесення змін до статті 12 Закону України "Про зв'язок" ( 556-15 ), наказу Держкомзв'язку України від 20.08.2003 N 152 ( z0747-03 ) "Про встановлення одиниць обліку часу телефонних розмов та телеграфних повідомлень" та відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

1. Внести до наказу Держкомзв'язку та інформатизації України від 07.06.2002 N 120 ( z0595-02 ), зареєстрованого в Міністерстві юстиції України 19.07.2002 за N 595/6883, зміни та доповнення, що додаються, та ввести їх у дію з 21 вересня 2003 року.

2. Заступнику Голови Омельченку А.В., начальнику управління економічної політики Артюшенко Л.В. забезпечити інформування операторів зв'язку та споживачів послуг про внесені зміни та доповнення до Граничних тарифів на основні послуги електрозв'язку через Web-сайт Держкомзв'язку України.

3. Операторам зв'язку:

3.1. Довести до відома споживачів інформацію про введення в дію змін та доповнень до Граничних тарифів на основні послуги електрозв'язку.

3.2. Забезпечити застосування змін та доповнень до Граничних тарифів на основні послуги електрозв'язку відповідно до чинного законодавства.

4. Контроль за виконанням цього наказу покласти на заступника Голови Омельченка А.В.

В.о. Голови Л.І.Нетудихата
