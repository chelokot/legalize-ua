Про заходи щодо виконання постанови Кабінету Міністрів України від 7 листопада 2007 року N 1294 "Про упорядкування структури та умов грошового забезпечення військовослужбовців, осіб рядового і начальницького складу"

{ Із змінами, внесеними згідно з Наказами Державного департаменту України з питань виконання покарань N 235 ( z1145-09 ) від 20.10.2009 N 147 ( z0321-10 ) від 20.04.2010 }

На виконання постанови Кабінету Міністрів України від 7 листопада 2007 року N 1294 ( 1294-2007-п ) "Про упорядкування структури та умов грошового забезпечення військовослужбовців, осіб рядового і начальницького складу" (із змінами) (далі - постанова) НАКАЗУЮ:

1. Затвердити Схеми посадових окладів осіб рядового і начальницького складу Державної кримінально-виконавчої служби України (далі - кримінально-виконавча служба) згідно з додатками 1-16 до наказу.

2. Цей наказ набирає чинності з дня його офіційного опублікування.

3. Скасувати наказ Державного департаменту України з питань виконання покарань (далі - Департамент) від 19.08.99 N 111 "Про виконання постанови Кабінету Міністрів України від 18 серпня 1999 року N 1510 "Про умови грошового забезпечення осіб рядового і начальницького складу та оплати праці працівників кримінально-виконавчої системи" (зі змінами).

4. Управлінню економіки та оплати праці Департаменту відповідно до пункту 2 постанови підготувати та подати на затвердження порядок виплати грошового забезпечення особам рядового і начальницького складу кримінально-виконавчої служби.

5. Управлінню економіки та оплати праці Департаменту (Стрілецький М.М.) подати цей наказ у встановленому порядку на державну реєстрацію до Міністерства юстиції України.

6. Контроль за виконанням цього наказу покласти на заступника Голови Департаменту Височанського А.Ф.

7. Наказ оголосити персоналу кримінально-виконавчої служби.

Голова В.В.Кощинець
