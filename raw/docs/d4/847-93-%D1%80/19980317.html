Кабінет Міністрів України; Розпорядження від 13.10.1993 № 847-р

Щодо уповноваження підприємств на здійснення експорту товарів

Стан: Втратив чинність

Ідентифікатор: 847-93-р

Текст документа від 17.03.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 жовтня 1993 р. N 847-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 315 ( 315-98-п ) від 17.03.98 )

Відповідно до Декрету Кабінету Міністрів України від 26 грудня 1992 р. N 16-92 ( 16-92 ) "Про встановлення спеціального режиму експорту окремих товарів" уповноважити здійснювати експорт товарів за кодами ТН ЗЕД:

Дніпродзержинське виробниче об'єднання "Азот" - 71.12;

державне підприємство Харківський завод "Радіодеталь" - 8103.10900, 8112.91390;

державне підприємство завод "Радіоприлад" імені С.П. Корольова - 71.12;

державне зовнішньоекономічне підприємство "Укрзовнішпром" - 74.01-74.19;

орендний концерн "Стирол" - 71.12.

Виконуючий обов'язки Прем'єр-міністра України Ю.ЗВЯГІЛЬСЬКИЙ
