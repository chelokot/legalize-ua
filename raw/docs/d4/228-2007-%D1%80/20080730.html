Текст документа від 30.07.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 квітня 2007 р. N 228-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1031-р ( 1031-2008-р ) від 30.07.2008 }

Про закупівлю гірничошахтного обладнання, матеріалів та сировини для підприємств вугільної галузі на засадах міжвідомчої координації

Для зменшення витрат погодитися з пропозицією Мінвуглепрому щодо проведення закупівлі гірничошахтного обладнання, матеріалів та сировини для підприємств вугільної галузі, які належать до сфери управління Міністерства, на засадах міжвідомчої координації згідно з додатком.

Генеральним замовником визначити державне підприємство "Вугілля України".
