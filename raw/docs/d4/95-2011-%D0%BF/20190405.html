Кабінет Міністрів України; Постанова від 26.01.2011 № 95

Про реалізацію об'єктів державного цінового регулювання з державного інтервенційного фонду

Стан: Втратив чинність

Ідентифікатор: 95-2011-п

Текст документа від 05.04.2019:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 січня 2011 р. N 95 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 260 ( 260-2019-п ) від 06.03.2019 }

Про реалізацію об'єктів державного цінового регулювання з державного інтервенційного фонду

{ Із змінами, внесеними згідно з Постановами КМ N 123 ( 123-2012-п ) від 22.02.2012 N 1211 ( 1211-2012-п ) від 26.12.2012 }

Відповідно до підпункту "г" пункту 6.2 статті 6 та підпункту 9.2.1 пункту 9.2 статті 9 Закону України "Про державну підтримку сільського господарства України" ( 1877-15 ) Кабінет Міністрів України постановляє:

Дозволити Аграрному фондові здійснювати у 2013 році в установленому законодавством порядку реалізацію об'єктів державного цінового регулювання з державного інтервенційного фонду, не пов'язану з державним ціновим регулюванням, за цінами, не нижчими середньозважених цін рівноваги (фіксингу), що склалися протягом останніх трьох торгових сесій на Аграрній біржі та сертифікованих нею акредитованих товарних біржах. При цьому ціни продажу не повинні бути нижчими більш як на 20 відсотків мінімальної та вищими більш як на 20 відсотків максимальної інтервенційних цін, установлених на поточний маркетинговий період для об’єктів державного цінового регулювання.

{ Постановляюча частина із змінами, внесеними згідно з Постановами КМ N 123 ( 123-2012-п ) від 22.02.2012, N 1211 ( 1211-2012-п ) від 26.12.2012 }
