ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 23 березня 2011 р. N 296

ПОРЯДОК використання коштів, передбачених у державному бюджеті для фінансування проектів, пов'язаних з підвищенням техніки безпеки шахт шляхом впровадження уніфікованих телекомунікаційних систем диспетчерського контролю та автоматизованого керування гірничими машинами і технологічними комплексами (УТАС) та проектів модернізації цих систем

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 162 ( 162-2012-п ) від 29.02.2012 }

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті за програмою "Фінансування проектів, пов'язаних з підвищенням техніки безпеки шахт шляхом впровадження уніфікованих телекомунікаційних систем диспетчерського контролю та автоматизованого керування гірничими машинами і технологічними комплексами (УТАС) та проектів модернізації цих систем" (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 162 ( 162-2012-п ) від 29.02.2012 }

2. Бюджетні кошти використовуються з метою підвищення техніки безпеки шахт шляхом впровадження та модернізації уніфікованих телекомунікаційних систем диспетчерського контролю та автоматизованого керування гірничими машинами і технологічними комплексами (УТАС) (далі - уніфіковані телекомунікаційні системи (УТАС).

{ Пункт 2 в редакції Постанови КМ N 162 ( 162-2012-п ) від 29.02.2012 }

3. Головним розпорядником бюджетних коштів є МНС. Відповідальним виконавцем бюджетної програми та розпорядником бюджетних коштів нижчого рівня є Держгірпромнагляд.

{ Пункт 3 в редакції Постанови КМ N 162 ( 162-2012-п ) від 29.02.2012 }

4. Завданням Держгірпромнагляду є впровадження та модернізація на шахтах уніфікованих телекомунікаційних систем (УТАС) згідно з проектною документацією, затвердженою Держгірпромнаглядом.

{ Пункт 4 в редакції Постанови КМ N 162 ( 162-2012-п ) від 29.02.2012 }

5. Держгірпромнагляд визначає шахти, на яких будуть впроваджуватися уніфіковані телекомунікаційні системи (УТАС), та шахти, на яких буде здійснюватися їх модернізація, з урахуванням: { Абзац перший пункту 5 в редакції Постанови КМ N 162 ( 162-2012-п ) від 29.02.2012 }

відносного показника оцінки аварійної небезпеки виробничих параметрів шахти (Кп);

відносного показника оцінки аварійної небезпеки гірничотехнічних параметрів шахти (Кгт);

відносного показника оцінки аварійної небезпеки внаслідок дії основних небезпечних чинників гірничого виробництва (Коп).

6. Перелік шахт та розподіл обсягів фінансування затверджуються Держгірпромнаглядом за погодженням з Мінфіном.

{ Пункт 6 в редакції Постанови КМ N 162 ( 162-2012-п ) від 29.02.2012 }

{ Пункт 7 виключено на підставі Постанови КМ N 162 ( 162-2012-п ) від 29.02.2012 }

8. Держгірпромнагляд здійснює закупівлю товарів, робіт і послуг, необхідних для впровадження та модернізації уніфікованих телекомунікаційних систем (УТАС), в установленому законодавством порядку.

Попередня оплата таких товарів, робіт і послуг проводиться з урахуванням вимог бюджетного законодавства.

Впроваджені або модернізовані уніфіковані телекомунікаційні системи (УТАС) передаються на підставі акта приймання - передачі шахтам або вугледобувним підприємствам із закріпленням зазначених систем за цими шахтами або вугледобувними підприємствами на праві господарського відання.

{ Пункт 8 в редакції Постанови КМ N 162 ( 162-2012-п ) від 29.02.2012 }

9. Відображення у первинному та бухгалтерському обліку інформації про отримані (створені) оборотні і необоротні активи, а також відкриття рахунків, реєстрація, облік бюджетних зобов’язань в органах Казначейства та проведення операцій, пов'язаних з використанням бюджетних коштів, здійснюються в установленому законодавством порядку.

{ Пункт 9 із змінами, внесеними згідно з Постановою КМ N 162 ( 162-2012-п ) від 29.02.2012 }

10. Складення та подання фінансової і бюджетної звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
