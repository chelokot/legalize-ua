КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 квітня 2004 р. N 574 Київ

Про внесення змін до постанови Кабінету Міністрів України від 18 серпня 1999 р. N 1510

{ Із змінами, внесеними згідно з Постановою КМ N 1294 ( 1294-2007-п ) від 07.11.2007 }

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 18 серпня 1999 р. N 1510 ( 1510-99-п ) "Про умови грошового забезпечення осіб рядового і начальницького складу та оплати праці працівників кримінально-виконавчої системи" (Офіційний вісник України, 1999 р., N 33, ст. 1736) зміни, що додаються.

Ця постанова набирає чинності з дня її опублікування.

Прем'єр-міністр України В.ЯНУКОВИЧ
