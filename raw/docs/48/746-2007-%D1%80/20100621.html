КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 вересня 2007 р. N 746-р Київ

{ Дію Розпорядження відновлено згідно з Розпорядженням КМ N 1245-р ( 1245-2010-р ) від 21.06.2010 }

{ Розпорядження скасовано на підставі Розпорядження КМ N 79-р ( 79-2008-р ) від 16.01.2008 }

Про погодження пропозиції щодо створення Музею виноробства "Магарач"

Погодитися з пропозицією Української академії аграрних наук щодо створення Музею виноробства "Магарач" як підприємства з державною часткою у його статутному фонді більше 50 відсотків у межах повноважень галузевих академій наук відповідно до статті 4 Закону України "Про особливості правового режиму діяльності Національної академії наук України, галузевих академій наук та статусу їх майнового комплексу" ( 3065-14 ).

Прем'єр-міністр України В.ЯНУКОВИЧ
