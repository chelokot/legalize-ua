Про внесення змін до Указу Президента України від 4 жовтня 1994 року N 567

Стан: Втратив чинність

Текст документа від 26.05.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 589/2011 ( 589/2011 ) від 19.05.2011 }

Про внесення змін до Указу Президента України від 4 жовтня 1994 року N 567

З метою запобігання колізіям, що виникають при застосуванні суб'єктами підприємницької діяльності Міжнародних правил інтерпретації комерційних термінів, постановляю:

У частині першій статті 1 Указу Президента України від 4 жовтня 1994 року N 567 ( 567/94 ) "Про застосування Міжнародних правил інтерпретації комерційних термінів" слова "(роботи, послуги)" виключити.

Президент України Л.КУЧМА

м.Київ, 1 липня 1995 року N 505/95
