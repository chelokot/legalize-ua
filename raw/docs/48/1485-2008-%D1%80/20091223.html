Про затвердження основних напрямів контрольно-ревізійної роботи органів державної контрольно-ревізійної служби на 2009 рік

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1163-р ( 1163-2009-р ) від 30.09.2009 N 1602-р ( 1602-2009-р ) від 23.12.2009 }

1. Затвердити основні напрями контрольно-ревізійної роботи органів державної контрольно-ревізійної служби на 2009 рік, що додаються.

2. Міністерствам, іншим центральним органам виконавчої влади забезпечувати у разі звернення ГоловКРУ участь своїх контрольно-ревізійних підрозділів у здійсненні контрольних заходів, що проводяться згідно з основними напрямами, затвердженими цим розпорядженням.
