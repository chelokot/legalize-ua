{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про фінансування загальнодержавних витрат Кабінету Міністрів України

З метою забезпечення фінансування загальнодержавних витрат Кабінет Міністрів України постановляє:

Виділити Господарському управлінню Кабінету Міністрів України 1,67 млн. грн. на утримання Маріїнського палацу, будинків прийомів, інших урядових об'єктів, проведення прийомів зарубіжних урядових делегацій, міжурядових заходів та інших загальнодержавних витрат.

Міністерству фінансів профінансувати зазначені видатки у III кварталі 1996 р. за рахунок резервного фонду Кабінету Міністрів України.
