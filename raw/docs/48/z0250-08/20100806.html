"Відповідно до статті 26 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ), а також на виконання протоколу N 2 засідання Кабінету Міністрів України від 14 січня 2009 року НАКАЗУЮ:

{ Преамбула в редакції Наказу Державного комітету України у справах національностей та релігій N 34 ( z0353-09 ) від 30.03.2009; із змінами, внесеними згідно з Наказом Державного комітету України у справах національностей та релігій N 79 ( z0554-10 ) від 19.07.2010 }

1. Затвердити:

1.1. Порядок використання коштів, передбачених у державному бюджеті для здійснення заходів з реалізації Європейської хартії регіональних мов або мов меншин, що додається.

1.2. Порядок використання коштів, передбачених у державному бюджеті для здійснення заходів щодо відтворення культури національних меншин та фінансової підтримки газет, що видаються їх мовами ( z0251-08 ), що додається.

1.3. Порядок використання коштів, передбачених у державному бюджеті для здійснення заходів, пов'язаних із забезпеченням свободи совісті та релігії ( z0252-08 ), що додається.

{ Пункт 1.4 виключено на підставі Наказу Державного комітету України у справах національностей та релігій N 34 ( z0353-09 ) від 30.03.2009 }

2. Відділу юридичного забезпечення та законопроектної експертизи (Бударін М.П.) у встановленому порядку подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Голови Божка О.Ф.

ПОРЯДОК використання коштів, передбачених у державному бюджеті для здійснення заходів з реалізації Європейської хартії регіональних мов або мов меншин ( 994_014 )

I. Загальні положення

1.1. Цей Порядок визначає механізм використання коштів, передбачених Державному комітету України у справах національностей та релігій (далі - Держкомнацрелігій) у Державному бюджеті України на відповідний рік за бюджетною програмою "Заходи з реалізації Європейської хартії регіональних мов або мов меншин" (далі - бюджетні кошти).

1.2. Головний розпорядник бюджетних коштів - Держкомнацрелігій.

1.3. Одержувачами бюджетних коштів є громадські організації національних меншин України, діяльність яких згідно зі статутом спрямована на сприяння збереженню і розвитку рідної мови і які беруть участь у проведенні заходів відповідно до затвердженого Держкомнацрелігій календарного плану заходів з реалізації Європейської хартії регіональних мов або мов меншин.

{ Пункт 1.3 розділу I в редакції Наказу Державного комітету України у справах національностей та релігій N 79 ( z0554-10 ) від 19.07.2010 }

II. Мета Порядку та напрями використання бюджетних коштів

2.1. Мета Порядку полягає у забезпеченні прозорої та ефективної процедури використання бюджетних коштів.

2.2. Бюджетні кошти спрямовуються на:

підготовку та проведення в Україні міжнародних, всеукраїнських, регіональних конкурсів, олімпіад на краще знання мов національних меншин, навчальних семінарів для керівників та педагогічних працівників недільних шкіл, у яких вивчаються рідні мови (в частині оплати витрат з оренди приміщення, на поліграфію та друк, виготовлення дипломів, придбання канцелярських матеріалів);

сприяння виданню посібників, словників, розмовників, довідників з рідних мов, що видаються мовою національних меншин, програм, планів, науково-методичних видань для недільних шкіл та інформаційно-аналітичних видань, збірників матеріалів, присвячених питанням реалізації мовних прав національних меншин, визначених Європейською хартією, виходячи з потреби в них, чисельності представників національних меншин та комплектації недільних шкіл учнями - представниками національних меншин (витрати на поліграфію та друк), сприяння виданню друкованих засобів масової інформації (витрати на поліграфію та друк), співзасновником яких не є Держкомнацрелігій;

підготовку та проведення в Україні з'їздів, конгресів, форумів, конференцій, симпозіумів, семінарів, "круглих столів", соціологічних досліджень з питань функціонування та розвитку мов національних меншин (у частині оплати оренди приміщення, витрат на поліграфію та друк матеріалів, пов'язаних з реалізацією положень Європейської хартії регіональних мов або мов меншин);

сприяння в організації виставок, стендів, що присвячені відродженню і розвитку мов національних меншин (у частині оплати витрат з оренди приміщення й обладнання, на поліграфію та друк);

підготовку та проведення на території України робочих засідань у рамках двостороннього співробітництва з Комітетом експертів Європейської хартії регіональних мов або мов меншин Ради Європи (у частині оплати витрат з оренди приміщення й обладнання, на поліграфію та друк матеріалів, транспортне обслуговування на території України експертів Комітету експертів Європейської хартії регіональних мов або мов меншин Ради Європи, придбання канцелярських матеріалів для забезпечення засідання).

{ Пункт 2.2 розділу II в редакції Наказу Державного комітету України у справах національностей та релігій N 79 ( z0554-10 ) від 19.07.2010 }

III. Вимоги щодо використання бюджетних коштів

3.1. Бюджетні кошти використовуються громадськими організаціями у межах бюджетних призначень, установлених Законом України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) Держкомнацрелігій, згідно із затвердженим Держкомнацрелігій календарним планом заходів за погодженням з Міністерством фінансів України щодо виконання бюджетної програми з визначенням обсягів видатків, дати і місця проведення заходу та його виконавця.

До календарного плану додаються відповідні розрахунки та обґрунтування витрат, пов'язаних з проведенням заходів громадськими організаціями.

У разі потреби Держкомнацрелігій вносить до календарного плану зміни за погодженням з Міністерством фінансів України.

Для проведення заходів, передбачених календарним планом, Держкомнацрелігій у кожному конкретному випадку укладає з громадською організацією угоду на проведення заходу, в якій зазначаються найменування заходу, дата і місце його проведення та виконавець. Невід'ємною частиною угоди є кошторис витрат на проведення заходу з відповідними розрахунками та обґрунтуваннями.

{ Пункт 3.1 розділу III в редакції Наказу Державного комітету України у справах національностей та релігій N 79 ( z0554-10 ) від 19.07.2010 }

{ Пункт 3.2 розділу III виключено на підставі Наказу Державного комітету України у справах національностей та релігій N 79 ( z0554-10 ) від 19.07.2010 }

3.2. Держкомнацрелігій подає у двотижневий строк Мінфіну План заходів разом з поквартальними результативними показниками їх виконання.

3.3. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється в установленому законодавством порядку.

У договорі про закупівлю передбачається:

можливість коригування визначеної в ньому суми у разі зменшення бюджетних призначень;

норма про недопущення включення до собівартості послуг витрат, які безпосередньо не пов'язані з їх наданням, або необґрунтованого завищення їх вартості, а також про штрафні санкції, які застосовуються до суб'єктів господарювання за невиконання або несвоєчасне виконання зобов'язань за договором.

Не допускається спрямування бюджетних коштів на:

здійснення заходів, придбання товарів, робіт і послуг, не пов'язаних з напрямами, зазначеними в пункті 2.2 розділу II цього Порядку;

проведення заходів, метою яких є отримання прибутку;

придбання для проведення заходів загальнодержавного та міжнародного рівня товарів і послуг, використання яких безпосередньо не пов'язане з організацією таких заходів та участю в них;

здійснення видатків, що фінансуються за рахунок інших бюджетних програм.

{ Пункт із змінами, внесеними згідно з Наказом Державного комітету України у справах національностей та релігій N 34 ( z0353-09 ) від 30.03.2009; в редакції Наказу Державного комітету України у справах національностей та релігій N 79 ( z0554-10 ) від 19.07.2010 }

3.4. Попередня оплата товарів, робіт і послуг здійснюється відповідно до вимог законодавства.

{ Пункт 3.4 розділу III із змінами, внесеними згідно з Наказом Державного комітету України у справах національностей та релігій N 79 ( z0554-10 ) від 19.07.2010 }

3.5. Остаточні розрахунки здійснюються на підставі актів приймання-передавання товарів, виконаних робіт (послуг) та відповідних рахунків, що подаються їх виконавцями.

3.6. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04 ), зареєстрованого в Міністерстві юстиції України 10.06.2004 за N 716/9315 (із змінами).

{ Пункт із змінами, внесеними згідно з Наказом Державного комітету України у справах національностей та релігій N 34 ( z0353-09 ) від 30.03.2009 }

IV. Звітність про використання бюджетних коштів та контроль за їх витрачанням

4.1. Інформацію про виконання поквартальних результативних показників, зазначених у пункті 3.3 цього Порядку, і використання бюджетних коштів Держкомнацрелігій подає Мінфіну в тижневий строк після завершення звітного кварталу та за результатами одинадцяти місяців.

4.2. Одержувачі бюджетних коштів подають головному розпоряднику щоквартальні звіти про використання бюджетних коштів до 3 числа місяця, що настає за звітним періодом, а річний звіт - до 12 січня 2011 року. { Пункт 4.2 розділу IV доповнено абзацом згідно з Наказом Державного комітету України у справах національностей та релігій N 79 ( z0554-10 ) від 19.07.2010 }

Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.

4.3. Відповідальність за управління бюджетними асигнуваннями і здійснення контролю за виконанням процедур та вимог, установлених чинним законодавством, несе головний розпорядник бюджетних коштів відповідно до чинного законодавства України.
