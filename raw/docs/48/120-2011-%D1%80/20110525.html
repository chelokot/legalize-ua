КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 лютого 2011 р. N 120-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 447-р ( 447-2011-р ) від 25.05.2011 }

Про підписання Рамкової угоди між Урядом України та Урядом Перу щодо співробітництва у сфері космічної діяльності

Схвалити проект Рамкової угоди між Урядом України та Урядом Перу щодо співробітництва у сфері космічної діяльності.

Уповноважити Голову Державного космічного агентства Алексєєва Юрія Сергійовича підписати зазначену Угоду.
