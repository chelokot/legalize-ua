Про затвердження максимальних граничних норм

( Про визнання недійсним Наказу додатково див. Рішення Господарського суду міста Києва N 3/302 ( v_302805-04 ) від 04.08.2004 )

( Рішення про державну реєстрацію Наказу скасовано на підставі Висновку Міністерства юстиції N 19/51 ( v19_5323-05 ) від 26.08.2005 )

За дорученням Кабінету Міністрів України від 26.12.2003 N 82090, з урахуванням результатів ревізії фінансово-господарської діяльності ряду наукових установ, організацій та підприємств Національної академії наук України органами Державної контрольно-ревізійної служби Міністерства фінансів України, у зв'язку із законодавчою неврегульованістю розмірів накладних витрат і обсягу робіт сторонніх організацій при визначенні кошторисної вартості наукових проектів, що фінансуються за рахунок бюджетних коштів, та з метою попередження бюджетних правопорушень НАКАЗУЄМО:

1. Затвердити максимальну граничну норму накладних витрат при визначенні кошторисної вартості наукових, науково-дослідних та дослідно-конструкторських робіт, які виконуються за рахунок бюджетних коштів для установ, організацій, підприємств сфери науково-технічної діяльності усіх форм власності в розмірі до 50% від обсягу витрат на оплату праці основних виконавців проекту, та граничну норму обсягів робіт сторонніх організацій до 40% від кошторисної вартості наукового проекту.

2. Міністерству освіти і науки України довести цей наказ до відома головних розпорядників коштів державного бюджету для застосування в роботі.
