Кабінет Міністрів України; Постанова від 22.07.2009 № 837

Про спрямування коштів Стабілізаційного фонду на часткову компенсацію відсоткової ставки за кредитами, наданими комерційними банками молодим сім'ям та одиноким молодим громадянам для будівництва (реконструкції) і придбання житла

Стан: Чинний

Ідентифікатор: 837-2009-п

Текст документа від 28.10.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 липня 2009 р. N 837 Київ

Про спрямування коштів Стабілізаційного фонду на часткову компенсацію відсоткової ставки за кредитами, наданими комерційними банками молодим сім'ям та одиноким молодим громадянам для будівництва (реконструкції) і придбання житла

{ Із змінами, внесеними згідно з Постановою КМ N 1106 ( 1106-2009-п ) від 07.10.2009 }

Кабінет Міністрів України постановляє:

1. Здійснити перерозподіл коштів Стабілізаційного фонду у сумі 50 000 тис. гривень, у тому числі 7 171,9 тис. гривень шляхом зменшення обсягу видатків за напрямом, передбаченим пунктом 6 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), і 42 828,1 тис. гривень шляхом зменшення обсягу видатків за напрямом, передбаченим пунктом 12 частини першої статті 76 зазначеного Закону, та збільшення обсягу видатків за напрямом, передбаченим пунктом 22 частини першої статті 76 зазначеного Закону, із спрямуванням їх на часткову компенсацію відсоткової ставки кредитів комерційних банків молодим сім'ям та одиноким молодим громадянам для будівництва (реконструкції) і придбання житла.

{ Пункт 1 в редакції Постанови КМ N 1106 ( 1106-2009-п ) від 07.10.2009 }

2. Виділити на безповоротній основі за рахунок надходжень від цільового розміщення державних цінних паперів суму, зазначену у пункті 1 цієї постанови, для часткової компенсації відсоткової ставки за кредитами, наданими комерційними банками молодим сім'ям та одиноким молодим громадянам для будівництва (реконструкції) і придбання житла.

3. Установити, що:

головним розпорядником бюджетних коштів, виділених згідно з пунктом 2 цієї постанови, є Міністерство у справах сім'ї, молоді та спорту;

зазначені кошти використовуються відповідно до Порядку часткової компенсації відсоткової ставки кредитів комерційних банків молодим сім'ям та одиноким молодим громадянам на будівництво (реконструкцію) і придбання житла, затвердженого постановою Кабінету Міністрів України від 4 червня 2003 р. N 853 ( 853-2003-п ) (Офіційний вісник України, 2003 р., N 23, ст. 1065), та Порядку використання у 2009 році коштів Стабілізаційного фонду, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) (Офіційний вісник України, 2009 р., N 24, ст. 793).

4. Міністерству фінансів без попереднього погодження з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету забезпечити відкриття нової бюджетної програми та внесення змін до розпису державного бюджету. { Пункт 4 в редакції Постанови КМ N 1106 ( 1106-2009-п ) від 07.10.2009 }

5. Міністерству у справах сім'ї, молоді та спорту забезпечити погодження перерозподілу та виділення відповідно до цієї постанови коштів Стабілізаційного фонду з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету.

{ Пункт 5 в редакції Постанови КМ N 1106 ( 1106-2009-п ) від 07.10.2009 }

6. Державному казначейству забезпечити перерахування виділених відповідно до цієї постанови коштів.

{ Постанову доповнено пунктом 6 згідно з Постановою КМ N 1106 ( 1106-2009-п ) від 07.10.2009 }
