Про підвищення граничних тарифів на послуги зв'язку

З метою відшкодування зростання витрат, пов'язаних з збільшенням тарифів і цін на електро- та теплову енергію, перевезення пошти, матеріали, запчастини тощо та у відповідності з постановою Кабінету Міністрів України від 21.10.94 N 733 ( 733-94-п ) "Про ціноутворення в умовах реформування економіки" і за погодженням з Мінекономіки НАКАЗУЮ:

1. Затвердити граничні тарифи на послуги зв'язку, що додаються.

2. Генеральним директорам об'єднань "Укрелектрозв'язок", "Укрпошта", РПЗ "Кримзв'язок", ОПЗ, ОППЗ "Закарпатпошта", ОПЕЗ "Закарпателектрозв'язок", МПЗ "Севастопользв'язок":

2.1. Забезпечити своєчасне впровадження затверджених тарифів на послуги зв'язку.

2.2. Подати необхідну інформацію в пресу про підвищення граничних тарифів на послуги зв'язку.

3. Контроль за виконанням наказу покласти на заступника Міністра Третякова С.М.

Міністр О.П.Проживальський

| 1. Щорічні експлуатаційні збори за передавачі судових станцій |

| сплачуються як за одноканальні станції (одне частотне при- |

| 2. За судовий аварійний передавач щорічний експлуатаційний |

| збір стягується у розмірі 50% тарифу, встановленого для |

| передавачів тієї ж потужності. |

| 3. Наведені в Прейскуранті тарифи відносно частотних присвоєнь |

| засобам радіозв'язку стосуються тільки випадків, коли зона |

| дії радіомережі цілком знаходиться в межах адміністративної |

| області. В разі збільшення зони розміри всіх видів зборів |

| збільшуються відповідно коефіцієнту, що враховує ускладне- |

| ність вибору частотних присвоєнь і забезпечення електромаг- |

| нітної сумісності |

| |

| Ky = 2 n - 1 |

| де: |

| Ky - коефіцієнт ускладнення, |

| n - кількість адміністративних областей, в межах яких |

| застосовуються радіозасоби радіомережі, що розгля- |

| дається. |

| 4. За резервні передавачі, в тому числі і за ті, що зберіга- |

| ються на складах, всі види зборів сплачуються у повному |

| розмірі. |

| 5. Реєстраційний збір сплачується замовником в залежності від |

| виду РЕЗ. |

| 6. Державній інспекції електрозв'язку надається право звільняти|

| на умовах взаємності від сплати тарифних зборів станції|

| дипломатичних представництв іноземних держав в Україні. |

| 7. Від сплати щорічного експлуатаційного збору за аматорські |

| радіостанції колективного користування можуть бути звільнені|

| школи дитячі будинки та інші подібні установи. |

| 8. Експертна робота фахівців ДІЕ оплачується за фактичними |

| трудовитратами, але не менше як за 1 годину. До вартості |

| експертних послуг не входить сума витрат на відрядження які,|

| при їх наявності, сплачуються замовником окремо. |

| 9. До нескладних експертних робіт відносяться роботи, що прово-|

| дяться фахівцями ДІЕ без залучення фахівців інших установ і |

| загальні трудовитрати на які не перевищують 5 годин. |

| лектронним засобам, а також заявок на погодження технічної |

|11. Зазначені тарифи не включають вартості платних послуг |

| до експертних та інших робіт. |
