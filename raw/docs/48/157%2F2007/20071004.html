Стан: Втратив чинність

Ідентифікатор: 157/2007

Текст документа від 04.10.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ скасовано на підставі Указу Президента N 869/2007 ( 869/2007 ) від 14.09.2007 }

Питання добору кандидатур для призначення на посаду судді Європейського суду з прав людини від України

З метою забезпечення виконання статті 22 Конвенції про захист прав людини і основоположних свобод ( 995_004 ) 1950 року та відповідно до пункту 3 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

Кабінету Міністрів України забезпечити відповідно до Рекомендацій Парламентської Асамблеї Ради Європи N 1429 (1999) і N 1649 (2004) формування списку кандидатур для призначення на посаду судді Європейського суду з прав людини від України, в тому числі проведення попередніх консультацій з Верховною Радою України, та внести його до 30 березня 2007 року до Ради Європи.

Президент України В.ЮЩЕНКО

м. Київ, 28 лютого 2007 року N 157/2007
