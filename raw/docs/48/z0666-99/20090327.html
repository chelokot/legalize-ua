ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 455 від 15.09.99 Зареєстровано в Міністерстві м.Київ юстиції України 1 жовтня 1999 р. за N 666/3959

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про внесення змін і доповнень до деяких нормативно-правових актів Національного банку України

{ Із змінами, внесеними згідно з Постановою Нацбанку N 101 ( z0359-05 ) від 31.03.2005 }

Відповідно до пункту 1 статті 6 Декрету Кабінету Міністрів України від 19 лютого 1993 року N 15-93 "Про систему валютного регулювання і валютного контролю" та з метою вдосконалення діючого порядку здійснення обов'язкового продажу надходжень в іноземній валюті на користь резидентів - юридичних осіб Правління ПОСТАНОВЛЯЄ:

( Пункт 1 втратив чинність на підставі Постанови Нацбанку N 101 ( z0359-05 ) від 31.03.2005 )

2. У вступній частині постанови Правління Національного банку України від 10.06.99 N 281 ( z0380-99 ) "Про скасування обмежень на попередню (авансову) оплату за імпортними договорами", зареєстрованої в Міністерстві юстиції України 17.06.99 за N 380/3673, абревіатуру "(IFF)" замінити на абревіатуру "(EFF)".

3. Ця постанова набуває чинності через десять днів після її державної реєстрації в Міністерстві юстиції України.
