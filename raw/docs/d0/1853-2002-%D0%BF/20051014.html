КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 грудня 2002 р. N 1853 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1020 ( 1020-2005-п ) від 14.10.2005 )

Про внесення змін до постанови Кабінету Міністрів України від 17 лютого 2000 р. N 339

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 17 лютого 2000 р. N 339 ( 339-2000-п ) "Про урядові комітети" (Офіційний вісник України, 2000 р., N 7, ст. 283, N 47, ст. 2038; 2001 р., N 37, ст. 1698; 2002 р., N 34, ст. 1589, N 39, ст. 1824) такі зміни:

в абзаці другому пункту 9 Загального положення, затвердженого зазначеною постановою, слова "(а замість Голови НКРЕ - один з членів цієї Комісії)" замінити словами "(а замість керівника колегіального органу - один з членів цього органу)";

додатки 1-5 до постанови викласти в редакції, що додається.
