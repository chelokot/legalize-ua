Президент України; Указ від 18.10.1997 № 1165/97

Про склад Спостережної ради по контролю за проведенням експерименту у Північнокримській експериментальній економічній зоні "Сиваш"

Стан: Втратив чинність

Ідентифікатор: 1165/97

Текст документа від 19.08.2000:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 994/2000 ( 994/2000 ) від 19.08.2000 )

Про склад Спостережної ради по контролю за проведенням експерименту у Північнокримській експериментальній економічній зоні "Сиваш"

1. Затвердити новий персональний склад Спостережної ради по контролю за проведенням експерименту у Північнокримській експериментальній економічній зоні "Сиваш" (додається).

2. Дозволити голові Спостережної ради по контролю за проведенням експерименту у Північнокримській експериментальній економічній зоні "Сиваш" у разі потреби вносити зміни до її персонального складу.

3. Визнати такими, що втратили чинність:

статтю 1 Указу Президента України від 17 листопада 1995 року N 1062 ( 1062/95 ) "Про заходи щодо проведення експерименту у Північнокримській експериментальній економічній зоні "Сиваш";

Указ Президента України від 20 грудня 1996 року N 1263 ( 1263/96 ) "Про зміни у складі Спостережної ради по контролю за проведенням експерименту у Північнокримській експериментальній економічній зоні "Сиваш".

4. Цей Указ набирає чинності з дня його підписання.

Президент України Л.КУЧМА

м. Київ, 18 жовтня 1997 року N 1165/97
