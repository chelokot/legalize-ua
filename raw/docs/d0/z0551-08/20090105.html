НАЦІОНАЛЬНА КОМІСІЯ З ПИТАНЬ РЕГУЛЮВАННЯ ЗВ'ЯЗКУ УКРАЇНИ

РІШЕННЯ

10.06.2008 N 1059

Зареєстровано в Міністерстві юстиції України 25 червня 2008 р. за N 551/15242

Про затвердження Змін до Граничних тарифів на роботи (послуги) Державного підприємства "Український державний центр радіочастот", пов'язані з користуванням радіочастотним ресурсом України

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Рішення Національної комісії з питань регулювання зв'язку

N 217 ( z0329-06 ) від 02.03.2006, до якого вносились зміни }

Відповідно до пункту 7 статті 14 Закону України "Про радіочастотний ресурс України" ( 1770-14 ) Національна комісія з питань регулювання зв'язку України ВИРІШИЛА:

1. Затвердити Зміни до Граничних тарифів на роботи (послуги) Державного підприємства "Український державний центр радіочастот", пов'язані з користуванням радіочастотним ресурсом України, затверджених рішенням НКРЗ від 02.03.2006 N 217 ( z0329-06 ), зареєстрованих у Міністерстві юстиції України 24.03.2006 за N 329/12203, що додаються.

2. Департаменту економіки та фінансів, Юридичному управлінню в установленому законодавством порядку подати це рішення на державну реєстрацію до Міністерства юстиції України.

ЗАТВЕРДЖЕНО Рішення Національної комісії з питань регулювання зв'язку України 10.06.2008 N 1059

Зареєстровано в Міністерстві юстиції України 25 червня 2008 р. за N 551/15242

ЗМІНИ до Граничних тарифів на роботи (послуги) Державного підприємства "Український державний центр радіочастот", пов'язані з користуванням радіочастотним ресурсом України, затверджених рішенням НКРЗ від 02.03.2006 N 217, зареєстрованих у Міністерстві юстиції України 24.03.2006 за N 329/12203 ( z0329-06 )

Доповнити Загальні положення пунктами 31-33 такого змісту:

"31. Для мереж радіозв'язку з фіксованим абонентським радіодоступом стандарту DECT за роботи з технічного радіоконтролю застосовувати тариф, визначений статтею 25, за одне частотне присвоєння (один номінал частоти) для кожної базової станції незалежно від кількості частотних каналів, які використовуються згідно з дозвільними документами.

32. Для РЕЗ широкосмугового радіодоступу, що використовують технологію FHSS, за роботи з технічного радіоконтролю застосовувати тариф, визначений позицією 148 статті 28, за один частотний канал для кожного радіоелектронного засобу базової станції незалежно від кількості каналів, які можуть використовуватися цим РЕЗ згідно з дозвільними документами.

33. Для окремої станції супутникового радіозв'язку типу VSAT за роботи з технічного радіоконтролю застосовувати тариф, визначений статтею 33, за один номінал незалежно від загальної кількості заявлених та зазначених у дозвільних документах частот".

У зв'язку з цим пункт 31 Загальних положень вважати відповідно пунктом 34.
