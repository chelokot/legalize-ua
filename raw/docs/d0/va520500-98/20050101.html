ПОСТАНОВА

N 520 від 16.12.98 м.Київ

vd981216 vn520

( Постанова втратила чинність на підставі Постанови Правління Національного банку N 555 ( z1511-04 ) від 17.11.2004 )

Про внесення змін і доповнень до деяких нормативних актів Національного банку України

( Із змінами, внесеними згідно з Постановою Національного банку N 280 ( z0918-04 ) від 17.06.2004 )

Для забезпечення бухгалтерського обліку деяких видів операцій у комерційних банках України та у зв'язку із внесенням змін і доповнень до Плану рахунків бухгалтерського обліку комерційних банків України й Інструкції про застосування Плану рахунків бухгалтерського обліку комерційних банків України Правління ПОСТАНОВЛЯЄ:

1. Затвердити Правила бухгалтерського обліку уповноваженими банками України обмінних операцій в іноземній валюті та банківських металах ( v0604500-99 ).

2. Затвердити Порядок бухгалтерського обліку формування і використання резервів, списання та повернення раніше списаних безнадійних активів у комерційних банках України ( v0605500-99 ).

( Пункт 3 втратив чинність на підставі Постанови Національного банку N 280 ( z0918-04 ) від 17.06.2004 )

4. Затвердити зміни та доповнення до Інструкції з бухгалтерського обліку операцій з цінними паперами установ комерційних банків України ( v0608500-99 ) та до Порядку ведення аналітичного обліку установами банків України ( v0609500-99 ), затверджених постановою Правління від 30.12.97 N 466 ( v0510500-97, v0511500-97 ), реєстр. N 510 від 31.12.97.

5. Затвердити зміни та доповнення до Положення про порядок формування і використання резерву для відшкодування можливих втрат за кредитними операціями комерційних банків ( v0610500-99 ), затвердженого постановою Правління від 27.03.98 N 122 ( v0538500-98 ).

6. Не для друку.

7. Не для друку.

8. Визнати такою, що втратила чинність, постанову Правління від 21.07.97 N 238 ( v0461500-97 ) (в редакції постанови Правління від 22.12.97 N 450 ( v0508500-97 ), реєстр. N 508 від 23.12.97).

9. Доручити Департаменту безвиїзного нагляду (Ю.О.Герасименко) внести зміни до Інструкції про порядок регулювання та аналіз діяльності комерційних банків, затвердженої постановою Правління від 14.04.98 N 141 ( z0323-98 ), реєстр. N 323/2763 від 15.05.98 (в редакції постанови Правління від 21.09.98 N 383 ( z0600-98 ), реєстр. N 600/3040 від 25.09.98) та доопрацювати Положення про порядок формування і використання резерву для відшкодування можливих втрат за кредитними операціями комерційних банків, затвердженого постановою Правління від 27.03.98 N 122 ( v0538500-98 ).

10. Дозволити Департаменту бухгалтерського обліку (П.М.Сенищ) у разі негайної потреби вводити окремі балансові рахунки з подальшим затвердженням Правлінням Національного банку України протягом одного кварталу.

11. Постанова набуває чинності з 1 січня 1999 року.

12. Контроль за виконанням цієї постанови покласти на Департамент бухгалтерського обліку (П.М.Сенищ).
