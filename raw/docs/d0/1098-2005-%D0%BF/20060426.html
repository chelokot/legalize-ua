Кабінет Міністрів України; Постанова від 16.11.2005 № 1098

Про порядок використання коштів, передбачених у державному бюджеті для завершення будівництва транспортних рефрижераторних суден з високим ступенем готовності

Стан: Чинний

Ідентифікатор: 1098-2005-п

Текст документа від 26.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2005 р. N 1098 Київ

Про порядок використання коштів, передбачених у державному бюджеті для завершення будівництва транспортних рефрижераторних суден з високим ступенем готовності

{ Установлено, що у 2006 році кошти, передбачені у державному бюджеті, використовуються за програмою "Заходи по завершенню

будівництва транспортних рефрижераторних суден з високим

ступенем готовності" ( 3235-15 ) відповідно до цієї

Постанови, згідно з Постановою Кабінету Міністрів

N 557 ( 557-2006-п ) від 26.04.2006 }

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ) Кабінет Міністрів України постановляє:

Установити, що кошти, передбачені у державному бюджеті Міністерству промислової політики за програмою "Заходи по завершенню будівництва транспортних рефрижераторних суден з високим ступенем готовності", спрямовуються на покриття витрат державного підприємства "Суднобудівний завод імені 61 комунара" (м. Миколаїв), пов'язаних із завершенням добудови транспортного рефрижераторного судна (замовлення N 1148) з високим ступенем готовності.

Кошти зараховуються на рахунок, відкритий у відповідному органі Державного казначейства одержувачу бюджетних коштів - державному підприємству "Суднобудівний завод імені 61 комунара", і використовуються згідно з кошторисом.

Прем'єр-міністр України Ю.ЄХАНУРОВ
