КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 лютого 2007 р. N 33-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 198 ( 198-2015-п ) від 15.04.2015 }

Про встановлення строку виконання операцій з переробки літака Ан-74 N 74015 на митній території України

1. Відповідно до частини третьої статті 232 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей установити строк виконання операцій з переробки літака Ан-74 N 74015 за кодом згідно з УКТЗЕД 8802401000 ( 2371г-14 ) у варіант Ан-74Д на митній території України 390 днів.

2. Це розпорядження набирає чинності з дня опублікування.
