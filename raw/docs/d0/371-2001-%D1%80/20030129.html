Кабінет Міністрів України; Розпорядження від 15.08.2001 № 371-р

Про утворення робочої групи для опрацювання питань поводження з відходами як вторинною сировиною

Стан: Втратив чинність

Ідентифікатор: 371-2001-р

Текст документа від 29.01.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 серпня 2001 р. N 371-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 142 ( 142-2003-п ) від 29.01.2003 )

Про утворення робочої групи для опрацювання питань поводження з відходами як вторинною сировиною

1. З метою забезпечення прозорості, залучення широких кіл громадськості до вирішення питань та внесення пропозицій, пов'язаних із створенням умов для організації збирання, сортування, транспортування, переробки та утилізації відходів як вторинної сировини, утворити постійно діючу робочу групу з числа представників центральних та місцевих органів виконавчої влади, органів місцевого самоврядування, державної компанії "Укртарапереробка", інших підприємств, установ і організацій (у тому числі громадських), провідних науковців та фахівців з питань поводження з відходами як вторинною сировиною.

Координацію діяльності робочої групи покласти на Віце-прем'єр-міністра України Рогового В.В. та доручити йому до 27 серпня 2001 р. затвердити її склад.

2. Взяти до відома, що організаційно-технічне забезпечення діяльності робочої групи буде здійснюватися Мінекономіки.

Прем'єр-міністр України А.КІНАХ
