КАБІНЕТ МІНІСТРІВ УКРАЇНИ
ПОСТАНОВА

від 5 лютого 2020 р. № 68
Київ

Про затвердження переліку призначених прикордонних інспекційних постів та призначених пунктів пропуску через державний кордон

Відповідно до частини другої статті 195 Митного кодексу України, частини першої статей 5 і 46 Закону України “Про державний контроль за дотриманням законодавства про харчові продукти, корми, побічні продукти тваринного походження, здоров’я та благополуччя тварин” Кабінет Міністрів України постановляє:

1. Затвердити перелік призначених прикордонних інспекційних постів та призначених пунктів пропуску через державний кордон згідно з додатком.

2. Ця постанова набирає чинності з 5 липня 2022 року.

ПЕРЕЛІК
призначених прикордонних інспекційних постів та призначених пунктів пропуску через державний кордон

1. Призначені прикордонні інспекційні пости та призначені пункти пропуску через державний кордон з Республікою Польща:

для автомобільного сполучення - Краківець, Ягодин;

для залізничного сполучення - Володимир-Волинський, Мостиська.

2. Призначені прикордонні інспекційні пости та призначені пункти пропуску через державний кордон із Словацькою Республікою:

для автомобільного сполучення - Ужгород;

для залізничного сполучення - Чоп (Страж).

3. Призначені прикордонні інспекційні пости та призначені пункти пропуску через державний кордон з Угорською Республікою:

для автомобільного сполучення - Чоп (Тиса);

для залізничного сполучення - Батєве - для пункту пропуску Саловка.

4. Призначені прикордонні інспекційні пости та призначені пункти пропуску через державний кордон з Румунією:

для автомобільного сполучення - Порубне;

для залізничного сполучення - Вадул-Сірет.

5. Призначені прикордонні інспекційні пости та призначені пункти пропуску через державний кордон з Республікою Молдова:

для автомобільного сполучення - Платонове, Кучурган, Рені, Мамалига, Старокозаче;

для залізничного сполучення - Могилів-Подільський.

6. Призначені прикордонні інспекційні пости та призначені пункти пропуску через державний кордон з Російською Федерацією:

для автомобільного сполучення - Бачівськ, Сеньківка, Грем’яч;

для залізничного сполучення - Зернове, Тополі.

7. Призначені прикордонні інспекційні пости та призначені пункти пропуску через державний кордон з Республікою Білорусь:

для автомобільного сполучення - Виступовичі, Нові Яриловичі;

для залізничного сполучення - Коростень - для пункту пропуску Виступовичі.

8. Призначені прикордонні інспекційні пости та призначені пункти пропуску через державний кордон для повітряного сполучення - Бориспіль, Дніпро, Львів, Одеса, Харків.

9. Призначені прикордонні інспекційні пости та призначені пункти пропуску через державний кордон для морського сполучення - Бердянський морський торговельний порт, Чорноморський морський порт, Чорноморський рибний порт, Маріупольський морський торговельний порт, морський порт Південний, Одеський морський торговельний порт.

10. Призначений прикордонний інспекційний пост та призначений пункт пропуску через державний кордон для паромного сполучення - Чорноморський морський порт.

11. Призначений прикордонний інспекційний пост та призначений пункт пропуску через державний кордон для річкового сполучення - Миколаївський річковий порт.

__________
Примітка.


Через призначені прикордонні інспекційні пости, зазначені у цьому переліку, переміщуються продукти, включені до переліку, затвердженого відповідно до частини четвертої статті 41 Закону України “Про державний контроль за дотриманням законодавства про харчові продукти, корми, побічні продукти тваринного походження, здоров’я та благополуччя тварин”.
