Кабінет Міністрів України постановляє:

Затвердити Положення про Міжвідомчу комісію з питань регулювання закупівлі товарів (робіт, послуг) для державних потреб (додається).

Міністр Кабінету Міністрів України В.ПУСТОВОЙТЕНКО

Інд. 23

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 20 липня 1996 р. N 786

ПОЛОЖЕННЯ про Міжвідомчу комісію з питань регулювання закупівлі товарів (робіт, послуг) для державних потреб

( Назва Положення із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

1. Міжвідомча комісія з питань регулювання закупівлі товарів (робіт, послуг) для державних потреб (далі - Комісія) є постійно діючим органом Кабінету Міністрів України. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

2. Основними завданнями Комісії є:

розгляд пропозицій міністерств та відомств щодо використання коштів Державного бюджету України і позабюджетних коштів, які виділяються на закупівлю товарів (робіт, послуг) для державних потреб, на придбання товарів (робіт, послуг) іноземного походження і прийняття попереднього рішення щодо доцільності використання зазначених коштів; ( Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

аналіз обсягів та структури закупівлі товарів (робіт, послуг) іноземного походження, здійснених за рішенням Прем'єр-міністра України; ( Пункт 2 доповнено абзацом третім згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

підготовка пропозицій Прем'єр-міністру України щодо надання дозволу міністерствам та відомствам на закупівлю для державних потреб товарів (робіт, послуг) іноземного походження; ( Абзац четвертий пункту 2 із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

підготовка пропозицій щодо організації виробництва на відчизняних підприємствах імпортозамінних товарів (робіт, послуг); ( Абзац п'ятий пункту 2 із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

участь у підготовці проектів законодавчих та інших нормативних актів з питань захисту відчизняних виробників та стимулювання виробництва товарів (виконання робіт, надання послуг) на українських підприємствах. ( Абзац шостий пункту 2 із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

3. Комісія має право:

залучати для розгляду питань, що належать до її компетенції, керівних працівників відповідних міністерств і відомств;

одержувати в установленому порядку від міністерств, відомств, підприємств і організацій інформацію, необхідну для виконання покладених на Комісію завдань;

визначати за погодженням із замовниками торгів (тендерів) у певних випадках інші способи проведення торгів (тендерів) щодо закупівлі товарів (робіт, послуг) іноземного походження, ніж передбачені для таких випадків постановою Кабінету Міністрів України від 28 червня 1997 р. N 694 (із внесеними до неї змінами і доповненнями); ( Пункт 3 доповнено абзацом четвертим згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

складати висновки щодо можливості закупівлі товарів (робіт, послуг) іноземного походження без проведення торгів (тендерів), передбачених законодавством. ( Пункт 3 доповнено абзацом п'ятим згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

Перелік документів, які повинні подаватися міністерствами та відомствами разом з пропозиціями щодо видачі дозволу на закупівлю для державних потреб товарів (робіт, послуг) іноземного походження, затверджується Комісією. ( Абзац шостий пункту 3 із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

4. Склад комісії затверджується Кабінетом Міністрів України.

Комісію очолює голова, який за посадою є Міністром економіки. Голова Комісії організує її роботу і несе персональну відповідальність за виконання покладених на Комісію завдань.

( Абзац другий пункту 4 із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

5. Формою роботи Комісії є засідання, які проводяться в міру потреби, але не рідше ніж один раз на місяць.

Рішення про проведення засідання приймає голова Комісії.

Засідання Комісії вважається правомочним, якщо на ньому присутні не менш як половина членів Комісії.

6. Рішення приймається простою більшістю голосів членів Комісії, присутніх на засіданні. У разі рівного розподілу голосів голос голови Комісії є вирішальним.

7. Засідання Комісії оформляється протоколом, який підписується головою Комісії, а в разі відсутності голови Комісії - його заступником.

8. Організаційно-технічне забезпечення роботи Комісії покладається на Мінекономіки.
