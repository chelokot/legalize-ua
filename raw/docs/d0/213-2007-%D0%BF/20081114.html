Текст документа від 14.11.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 лютого 2007 р. N 213 Київ

Деякі питання Державного комітету у справах національностей та релігій

{ Із змінами, внесеними згідно з Постановою КМ N 954 ( 954-2008-п ) від 22.10.2008 }

Кабінет Міністрів України постановляє:

1. Установити граничну чисельність працівників центрального апарату Державного комітету у справах національностей та релігій у кількості 123 одиниці.

Державному комітетові у справах національностей та релігій забезпечити утримання чисельності працівників в межах асигнувань, передбачених у Державному бюджеті України на 2007 рік ( 489-16 ).

2. Внести у додаток 1 до постанов Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851; 2002 р., N 6, ст. 244; 2004 р., N 21, ст. 1447; 2005 р., N 30, ст. 1797; 2006 р., N 6, ст. 302, N 28, ст. 2016) і від 2 квітня 2001 р. N 314 ( 314-2001-п ) "Про встановлення ліміту легкових автомобілів, що обслуговують державні органи" (Офіційний вісник України, 2001 р., N 14, ст. 602; 2002 р., N 6, ст. 244) зміни, що додаються.

3. Міністерству юстиції, Державному комітетові з питань національностей та релігій разом з Міністерством фінансів вирішити в установленому порядку питання щодо передачі бюджетних призначень від Міністерства юстиції до Державного комітету з питань національностей та релігій з урахуванням змін, внесених згідно з цією постановою.

4. Взяти до відома, що Державний комітет у справах національностей та релігій розташовується на умовах оренди в приміщеннях будинку по вул. Володимирській, 9, та п'ятого поверху будинку по вул. Прорізній, 15, у м. Києві.
