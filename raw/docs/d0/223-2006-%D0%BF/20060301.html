Кабінет Міністрів України; Постанова від 01.03.2006 № 223

Про доповнення переліків органів ліцензування та документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності

Стан: Втратив чинність

Ідентифікатор: 223-2006-п

Текст документа від 01.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 2006 р. N 223 Київ

Про доповнення переліків органів ліцензування та документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності

Кабінет Міністрів України постановляє:

1. Доповнити перелік органів ліцензування, затверджений постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001; 2004 р., N 25, ст. 1650), позицією 37 такого змісту:

"37. Мін'юст збирання, оброблення, зберігання, захист, використання інформації, яка складає кредитну історію"."

{ Текст пункту 1 Постанови змінено згідно з ДІ ОВУ N 13, 2006 р., стор. 501 }

2. Доповнити перелік документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності, затверджений постановою Кабінету Міністрів України від 4 липня 2001 р. N 756 ( 756-2001-п ) (Офіційний вісник України, 2001 р., N 27, ст. 1212; 2005 р., N 52, ст. 3297), пунктом 71 такого змісту:

"71. Збирання, оброблення, довідка банку про підтвердження сплати статутного

зберігання, захист, використання капіталу у розмірі, що передбачений Законом України

інформації, яка складає кредитну "Про організацію формування та обігу кредитних

історію історій" ( 2704-15 )

положення про бюро кредитних історій".

Прем'єр-міністр України Ю.ЄХАНУРОВ
