РОЗПОРЯДЖЕННЯ від 2 грудня 2009 р. N 1456-р Київ

Про затвердження плану заходів щодо реалізації Концепції реформи місцевого самоврядування

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1910-р ( 1910-2010-р ) від 29.09.2010 }

1. Затвердити план заходів щодо реалізації Концепції реформи місцевого самоврядування, схваленої розпорядженням Кабінету Міністрів України від 29 липня 2009 р. N 900 ( 900-2009-р ) (Офіційний вісник України, 2009 р., N 60, ст. 2130) (далі - план заходів), згідно з додатком.

2. Міністерствам, іншим центральним та місцевим органам виконавчої влади забезпечити виконання плану заходів у межах відповідних бюджетних призначень та за рахунок інших джерел.

3. Мінрегіонбуду подавати щокварталу до 10 числа наступного місяця Кабінетові Міністрів України узагальнену інформацію про стан виконання плану заходів.
