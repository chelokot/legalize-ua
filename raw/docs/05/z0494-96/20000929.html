ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

N 903 від 09.08.96 Зареєстровано в Міністерстві м.Київ юстиції України 3 вересня 1996 р. за N 494/1519

Про затвердження положень, з питань приватизації майна в агропромисловому комплексі

{ Із змінами, внесеними згідно з Наказами Фонду державного майна N 803 ( z0336-97 ) від 31.07.97 N 795 ( z0303-98 ) від 21.04.98 N 1718 ( z0666-00 ) від 17.08.2000 }

На виконання Постанови Верховної Ради України "Про порядок введення в дію Закону України "Про особливості приватизації майна в агропромисловому комплексі" ( 291/96-ВР ) та постанови Кабінету Міністрів України від 15 листопада 1995 р. N 911 ( 911-95-п ) "Про першочергові заходи щодо реалізації Програми діяльності Кабінету Міністрів України на 1995-1996 роки" НАКАЗУЮ:

1. Затвердити Положення про порядок приватизації несільськогосподарських підприємств і організацій агропромислового комплексу (додається).

2. Затвердити Положення про типовий план приватизації несільськогосподарських підприємств і організацій агропромислового комплексу ( z0495-96 ). { Положення втратило чинність на підставі Наказу Фонду державного майна N 1718 ( z0666-00 ) від 17.08.2000 }

3. Затвердити Положення про порядок приватизації майна радгоспів та інших державних сільськогосподарських підприємств, а також заснованих на їх базі орендних підприємств ( z0496-96 ). { Положення втратило чинність на підставі Наказу Фонду державного майна N 1718 ( z0666-00 ) від 17.08.2000 }

4. Директору Департаменту з питань реформування власності в агропромисловому комплексі Чорноіванову В.В. забезпечити державну реєстрації Положень в Міністерстві юстиції України. Після державної реєстрації Положень забезпечити публікацію документів в Державному інформаційному бюлетені "Про приватизацію".

5. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Ковтюха В.М.

Голова Фонду Ю.Єхануров

( Положення про порядок приватизації несільськогосподарських підприємств і організацій агропромислового комплексу втратило чинність на підставі Наказу Фонду державного майна N 1718 ( z0666-00 ) від 17.08.2000 )
