Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 жовтня 2010 р. N 2083-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання робіт з ремонту напівпричепів-цистерн для транспортування кріогенних продуктів (скраплених газів) за межами митної території України

1. Відповідно до статті 240 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей установити до 1 січня 2012 р. строк виконання робіт з ремонту напівпричепів-цистерн для транспортування кріогенних продуктів (скраплених газів) за кодом згідно з УКТЗЕД 8716310000 ( 2371г-14 ) за межами митної території України 180 днів.

2. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України М.АЗАРОВ
