Кабінет Міністрів України; Розпорядження від 01.07.2009 № 733-р

Про виділення коштів для проведення невідкладних заходів з ліквідації наслідків стихійного лиха, що сталося в Автономній Республіці Крим 25 червня - 10 липня 2009 року

Стан: Чинний

Ідентифікатор: 733-2009-р

Текст документа від 22.07.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 липня 2009 р. N 733-р Київ

Про виділення коштів для проведення невідкладних заходів з ліквідації наслідків стихійного лиха, що сталося в Автономній Республіці Крим 25 червня - 10 липня 2009 року

{ Назва Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 930-р ( 930-2009-р ) від 22.07.2009 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 930-р ( 930-2009-р ) від 22.07.2009 }

1. Виділити Мінпраці 21611,8 тис. гривень для проведення невідкладних заходів з ліквідації наслідків стихійного лиха, що сталося в Автономній Республіці Крим 25 червня - 10 липня 2009 р., у тому числі для виплати часткової грошової допомоги постраждалим сім'ям та часткового відшкодування збитків сільськогосподарським підприємствам (зокрема за пошкоджені дахи їх виробничих приміщень), фізичним особам - власникам земельних ділянок для ведення особистих селянських господарств та земельних ділянок для ведення товарного сільськогосподарського виробництва (земельних часток (паїв), які не здані в оренду) на безповоротній основі (далі - кошти). { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 930-р ( 930-2009-р ) від 22.07.2009 }

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 835-17 ).

2. Мінфіну та Державному казначейству забезпечити перерахування 3 липня 2009 р. Мінпраці коштів без затвердження переліків витрат, пов'язаних з проведенням невідкладних заходів з ліквідації наслідків стихійного лиха.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 930-р ( 930-2009-р ) від 22.07.2009 }

3. Кошти використовуються для виплати:

часткової грошової допомоги постраждалим сім'ям та часткового відшкодування збитків сільськогосподарським підприємствам у порядку, передбаченому розпорядженням Кабінету Міністрів України від 13 червня 2009 р. N 637 ( 637-2009-р );

часткового відшкодування збитків фізичним особам - власникам земельних ділянок для ведення особистих селянських господарств та земельних ділянок для ведення товарного сільськогосподарського виробництва (земельних часток (паїв), які не здані в оренду) із розрахунку 1500 гривень за 1 гектар пошкодженої площі. Сума такого відшкодування зменшується на суму виплаченої допомоги постраждалим сім'ям, у яких втрачена лише сільськогосподарська продукція на городах та присадибних ділянках.

{ Пункт 3 в редакції Розпорядження КМ N 930-р ( 930-2009-р ) від 22.07.2009 }

3-1. Райдержадміністрації складають та затверджують списки фізичних осіб, зазначених у пункті 1 цього розпорядження, на підставі актів обстеження пошкоджених земельних ділянок, яке проводиться відповідно до Порядку обстеження майна, пошкодженого унаслідок стихійного лиха, що сталося 23-27 липня 2008 року, затвердженого постановою Кабінету Міністрів України від 30 липня 2008 р. N 688 ( 688-2008-п ) (Офіційний вісник України, 2008 р., N 58, ст. 1939), а також завірених копій державних актів на право власності на земельну ділянку (сертифікатів на право на земельну частку (пай) та довідок Центру державного земельного кадастру про те, що земельна частка (пай) не перебуває в оренді.

{ Розпорядження доповнено пунктом 3-1 згідно з Розпорядженням КМ N 930-р ( 930-2009-р ) від 22.07.2009 }

4. Мінпраці подати до 15 жовтня 2009 р. Мінекономіки, Мінфіну, Мінагрополітики та Державному казначейству звіт про використання коштів.

{ Пункт 4 із змінами, внесеними згідно з Розпорядженням КМ N 930-р ( 930-2009-р ) від 22.07.2009 }
