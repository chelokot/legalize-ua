Про затвердження Положення про порядок подання до Національного банку України аудиторського звіту та висновку за результатами перевірки річної фінансової звітності банку

Стан: Втратив чинність

Ідентифікатор: z0231-02

Текст документа від 27.03.2009:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 38 від 28.01.2002 Зареєстровано в Міністерстві м.Київ юстиції України 6 березня 2002 р. за N 231/6519

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про затвердження Положення про порядок подання до Національного банку України аудиторського звіту та висновку за результатами перевірки річної фінансової звітності банку

{ Із змінами, внесеними згідно з Постановами Національного банку

N 479 ( z1012-02 ) від 09.12.2002 - з 07.01.2003

N 389 ( z0871-03 ) від 09.09.2003 }

Відповідно до вимог статті 61 Закону України "Про Національний банк України" ( 679-14 ) і статті 69 Закону України "Про банки і банківську діяльність" ( 2121-14 ) та з метою врегулювання проведення в банках аудиторських перевірок річної фінансової звітності та подання їх результатів до Національного банку України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити Положення про порядок подання до Національного банку України аудиторського звіту та висновку за результатами перевірки річної фінансової звітності банку (додається).

2. Визнати такою, що втратила чинність, постанову Правління Національного банку України від 09.02.99 N 53 ( v0053500-99 ) "Про заходи щодо подальшого розвитку банківського аудиту" (із змінами).

3. Керівникам структурних підрозділів центрального апарату та установ Національного банку України, а також банків взяти до керівництва в роботі це Положення і неухильно дотримуватися його вимог.

4. Постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

5. Контроль за виконанням цієї постанови покласти на заступника Голови В.Л.Кротюка, директора Генерального департаменту банківського нагляду О.І.Кірєєва.

Голова В.С.Стельмах

( Положення про порядок подання до Національного банку України аудиторського звіту та висновку за результатами перевірки річної фінансової звітності банку втратило чинність на підставі Постанови Національного банку N 389 ( z0871-03 ) від 09.09.2003 )
