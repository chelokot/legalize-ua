Кабінет Міністрів України; Розпорядження від 03.12.2005 № 492-р

Про виділення коштів для виплати компенсації за птицю, вилучену у зв'язку з виявленням в Автономній Республіці Крим випадків захворювання на пташиний грип, та проведення профілактичних заходів

Стан: Чинний

Ідентифікатор: 492-2005-р

Текст документа від 15.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 грудня 2005 р. N 492-р Київ

Про виділення коштів для виплати компенсації за птицю, вилучену у зв'язку з виявленням в Автономній Республіці Крим випадків захворювання на пташиний грип, та проведення профілактичних заходів

( Із змінами, внесеними згідно з Розпорядження КМ N 528-р ( 528-2005-р ) від 15.12.2005 )

1. Виділити:

МНС 12 млн. гривень для виплати компенсації юридичним та фізичним особам за птицю, вилучену у зв'язку з виявленням в Автономній Республіці Крим випадків захворювання на пташиний грип (далі - компенсація), і для проведення карантинних заходів; ( Абзац другий пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 528-р ( 528-2005-р ) від 15.12.2005 )

МОЗ 5,5 млн. гривень для закупівлі обладнання, вакцин (у тому числі "Грипол"), препаратів, медикаментів, сироваток та реактивів з метою проведення профілактичних, протиепідемічних і дезінфекційних заходів, спрямованих на запобігання поширенню вірусу пташиного грипу. ( Абзац третій пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 528-р ( 528-2005-р ) від 15.12.2005 )

Мінфіну здійснити зазначені видатки за рахунок резервного фонду державного бюджету ( 2285-15 ).

2. МНС:

визначити розміри компенсації та забезпечити виплату її сум готівкою фізичним особам і у безготівковій формі юридичним особам протягом трьох робочих днів за встановленим Міністерством зразком платіжної відомості;

визначити форму акта вилучення птиці у юридичних осіб.

3. МНС та МОЗ:

під час проведення карантинних, профілактичних, протиепідемічних і дезінфекційних заходів здійснити закупівлю необхідних товарів та послуг шляхом застосування процедури закупівлі в одного учасника без погодження з Мінекономіки;

подати до кінця 2005 року Мінекономіки, Мінфіну і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

( Пункт 3 в редакції Розпорядження КМ N 528-р ( 528-2005-р ) від 15.12.2005 )
