Зареєстровано в Міністерстві юстиції України 28 травня 2008 р. за N 468/15159

Про затвердження Тарифів за надання додаткових послуг правового і технічного характеру в Лівобережному відділі реєстрації шлюбів міста Києва з Державним центром розвитку сім'ї

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 2259/5 ( z1243-08 ) від 24.12.2008 }

Відповідно до статей 6, 17 Закону України "Про органи реєстрації актів громадянського стану" ( 3807-12 ) НАКАЗУЮ:

1. Затвердити Тарифи за надання додаткових послуг правового і технічного характеру в Лівобережному відділі реєстрації шлюбів міста Києва з Державним центром розвитку сім'ї, що додаються.

2. Визнати таким, що втратив чинність, наказ Міністерства юстиції України від 20.06.2007 N 405/5 ( z0680-07 ) "Про затвердження Тарифів за надання додаткових послуг правового і технічного характеру в Лівобережному відділі реєстрації шлюбів міста Києва з Державним центром розвитку сім'ї", зареєстрований у Міністерстві юстиції України 20.06.2007 за N 680/13947.

3. Контроль за виконанням цього наказу покласти на заступника Міністра юстиції України Ємельянову І.І.

Міністр Микола Оніщук
