{ Указ втратив чинність на підставі Указу N 148/2015 ( 148/2015 ) від 18.03.2015 }

Про День внутрішніх військ Міністерства внутрішніх справ України

Враховуючи заслуги внутрішніх військ Міністерства внутрішніх справ України у справі охорони громадського порядку і боротьби зі злочинністю, охорони важливих державних об'єктів, постановляю:

Установити в Україні свято - День внутрішніх військ Міністерства внутрішніх справ України, яке відзначати щорічно 26 березня - у день прийняття Верховною Радою України 1992 року Закону України "Про внутрішні війська Міністерства внутрішніх справ України" ( 2235-12 ).

Президент України Л.КУЧМА

м.Київ, 26 березня 1996 року N 216/96
