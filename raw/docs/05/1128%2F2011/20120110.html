Президент України; Указ від 16.12.2011 № 1128/2011

Про направлення миротворчого контингенту для участі України в Місії ООН зі стабілізації у Демократичній Республіці Конго

Стан: Чинний

Ідентифікатор: 1128/2011

Текст документа від 10.01.2012:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про направлення миротворчого контингенту для участі України в Місії ООН зі стабілізації у Демократичній Республіці Конго

{ Рішення Президента схвалено Законом N 4274-VI ( 4274-17 ) від 22.12.2011, ВВР, 2012, N 31, ст.385 }

Ураховуючи зобов'язання України як держави - члена Організації Об'єднаних Націй,

беручи до уваги Резолюції Ради Безпеки ООН N 1258 ( 995_527 ) від 6 серпня 1999 року, N 1279 ( 995_468 ) від 30 листопада 1999 року, N 1843 ( 995_h55 ) від 20 листопада 2008 року, N 1856 ( 995_h74 ) від 22 грудня 2008 року, N 1896 ( 995_i49 ) від 30 листопада 2009 року, N 1906 ( 995_i59 ) від 23 грудня 2009 року, N 1925 ( 995_i79 ) від 28 травня 2010 року та N 1991 ( 995_k10 ) від 28 червня 2011 року,

ураховуючи, що участь України в Місії ООН зі стабілізації у Демократичній Республіці Конго відповідає національним інтересам держави, сприятиме підтриманню міжнародного миру і безпеки,

на підставі пропозиції Ради національної безпеки і оборони України, відповідно до Закону України "Про участь України в міжнародних миротворчих операціях" ( 613-14 ) постановляю:

1. Направити для участі України в Місії ООН зі стабілізації у Демократичній Республіці Конго миротворчий контингент загальною чисельністю до 200 військовослужбовців.

2. Кабінету Міністрів України забезпечити направлення миротворчого контингенту, зазначеного у статті 1 цього Указу.

Президент України В.ЯНУКОВИЧ

м. Київ, 16 грудня 2011 року N 1128/2011
