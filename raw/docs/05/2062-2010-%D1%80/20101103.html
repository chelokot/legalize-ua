Кабінет Міністрів України; Розпорядження, Склад колегіального органу, Перелік від 03.11.2010 № 2062-р

Про затвердження та внесення змін до складу Української частини комісій з військово-технічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 2062-2010-р

Текст документа від 03.11.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 листопада 2010 р. N 2062-р Київ

Про затвердження та внесення змін до складу Української частини комісій з військово-технічного співробітництва

1. Затвердити згідно з додатками 1-11 оновлений склад Української частини:

Міжурядової українсько-грузинської комісії з питань військово-технічного співробітництва;

Міжурядової українсько-білоруської комісії з питань військово-технічного співробітництва;

Спільної українсько-американської комісії про обмін інформацією з питань досліджень та розробок у сфері військово-технічного співробітництва;

Спільної міжурядової українсько-сербсько-чорногорської комісії з питань військово-технічного співробітництва;

Спільної міжурядової українсько-казахстанської комісії з питань військово-технічного співробітництва;

Українсько-угорської спільної комісії з питань військово-технічного співробітництва;

Спільної українсько-хорватської комісії з питань військово-технічного співробітництва;

Міжурядової українсько-азербайджанської комісії з питань військово-технічного співробітництва;

Спільної українсько-італійської комісії з військово-технічного співробітництва;

Міжурядової українсько-німецької комісії з питань військово-технічного співробітництва;

Спільної міждержавної Українсько-Французької комісії в галузі озброєння і військової техніки.

2. Дозволити голові Української частини зазначених у пункті 1 цього розпорядження комісій вносити у разі потреби зміни до їх складу.

3. Внести до розпоряджень Кабінету Міністрів України від 8 лютого 2006 р. N 66 ( 66-2006-р ) "Про затвердження оновленого складу Української частини комісій з військово-технічного співробітництва" - із змінами, внесеними розпорядженням Кабінету Міністрів України від 7 травня 2008 р. N 691 ( 691-2008-р ), та від 8 жовтня 2008 р. N 1298 ( 1298-2008-р ) "Про затвердження складу Української частини комісій з військово-технічного співробітництва" зміни, що додаються.

4. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України згідно з переліком, що додається.

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 3 листопада 2010 р. N 2062-р

ЗМІНИ, що вносяться до розпоряджень Кабінету Міністрів України від 8 лютого 2006 р. N 66 ( 66-2006-р ) та від 8 жовтня 2008 р. N 1298 ( 1298-2008-р )

1. У розпорядженні Кабінету Міністрів України від 8 лютого 2006 р. N 66 ( 66-2006-р ):

1) в абзаці першому розпорядження слова "Міждержавної Українсько-Французької комісії в галузі озброєння і військової техніки," і "українсько-німецької комісії з питань військово-технічного співробітництва," виключити;

2) додатки 1 і 3 до розпорядження ( 66-2006-р ) виключити.

2. У розпорядженні Кабінету Міністрів України від 8 жовтня 2008 р. N 1298 ( 1298-2008-р ):

1) в абзаці першому розпорядження слова "Спільної українсько-італійської комісії з військово-технічного співробітництва," виключити;

2) додаток 1 до розпорядження ( 1298-2008-р ) виключити.

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 3 листопада 2010 р. N 2062-р

ПЕРЕЛІК розпоряджень Кабінету Міністрів України, що втратили чинність

1. Розпорядження Кабінету Міністрів України від 17 квітня 2006 р. N 206 ( 206-2006-р ) "Про затвердження складу Української частини комісій з військово-технічного співробітництва".

2. Розпорядження Кабінету Міністрів України від 14 травня 2008 р. N 710 ( 710-2008-р ) "Про внесення змін до розпорядження Кабінету Міністрів України від 17 квітня 2006 р. N 206".

3. Розпорядження Кабінету Міністрів України від 18 листопада 2009 р. N 1382 ( 1382-2009-р ) "Про внесення змін до розпорядження Кабінету Міністрів України від 17 квітня 2006 р. N 206".
