{ Наказ втратив чинність на підставі Наказу Фонду державного майна N 347 ( z0378-17 ) від 02.03.2017 }

Про затвердження Положення про порядок продажу на аукціоні, за конкурсом основних засобів, що є державною власністю

{ Із змінами, внесеними згідно з Наказами Фонду державного майна N 9 ( z0038-01 ) від 10.01.2001 N 298 ( z0189-02 ) від 15.02.2002 N 604 ( z0471-04 ) від 29.03.2004 N 1758 ( z1285-06 ) від 24.11.2006 }

З метою вдосконалення порядку відчуження основних засобів, що є державною власністю, приведення його у відповідність до чинного законодавства України НАКАЗУЮ:

1. Затвердити Положення про порядок продажу на аукціоні, за конкурсом основних засобів, що є державною власністю (додається).

2. Директору Управління індивідуального продажу Зеленському В.В. забезпечити в установленому порядку державну реєстрацію Положення в Міністерстві юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Кальніченка Л.Ф.

Голова Фонду О.Бондар

{ Положення про порядок продажу на аукціоні, за конкурсом основних засобів, що є державною власністю втратило чинність на підставі Наказу Фонду державного майна N 1758 ( z1285-06 ) від 24.11.2006 }
