УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зміни у складі Комісії державних нагород та геральдики

На часткову зміну статті 3 Указу Президента України від 11 квітня 2000 року N 583 ( 583/2000 ) "Про Комісію державних нагород та геральдики" (зі змінами, внесеними Указами від 2 листопада 2006 року N 929 ( 929/2006 ) та від 25 червня 2009 року N 492) ( 492/2009 ) ввести до складу Комісії державних нагород та геральдики ЧЕПЕЛИКА Володимира Андрійовича - голову Національної спілки художників України, народного художника України (за згодою).
