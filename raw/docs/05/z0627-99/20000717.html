N 660 від 03.09.99 Зареєстровано в Міністерстві м.Київ юстиції України 16 вересня 1999 р. vd990903 vn660 за N 627/3920

( Наказ втратив чинність на підставі Наказу Мінекономіки N 136 ( z0420-00 ) від 29.06.2000 )

Про внесення доповнень до наказу МЗЕЗторгу від 24.02.96 N 133-а в редакції наказу МЗЕЗторгу від 10.09.98 N 576а

Відповідно до частини 1 статті 9 Закону України "Про металобрухт" ( 619-14 ) та згідно з Указом Президента України від 07.11.94 N 659/94 "Про облік окремих видів зовнішньоекономічних договорів (контрактів) в Україні" НАКАЗУЮ:

1. Доповнити пункт 7 наказу МЗЕЗторгу від 24.02.96 N 133-а ( z0117-96 ), зареєстрованого в Міністерстві юстиції України 19.03.96 за N 117/1142 в редакції наказу МЗЕЗторгу від 10.09.98 N 576а ( z0564-98 ), зареєстрованого в Міністерстві юстиції України від 14.09.98 за N 564/3004, новим абзацом 5 такого змісту:

"Установити, що облік (реєстрація) зовнішньоекономічних договорів (контрактів) на експорт відходів та брухту чорних металів (код ТН ЗЕД - 72 04), здійснюється виключно МЗЕЗторгом за погодженням з Мінпромполітики незалежно від облікової вартості контрактів".

2. Управлінню правового забезпечення (Сервинський А.Ю.) забезпечити реєстрацію цього наказу в Міністерстві юстиції України.

3. Управлінню справами (Дробний В.В.) у десятиденний термін після реєстрації цього наказу в Міністерстві юстиції України забезпечити його публікацію в засобах масової інформації та довести до відома Міністерства промислової політики України, Державної митної служби України, Міністерства економіки АР Крим і регіональних управлінь зовнішніх економічних зв'язків.

4. Контроль за виконанням цього наказу покласти на заступника Міністра В.І. Олійника.

Міністр А.І.Гончарук
