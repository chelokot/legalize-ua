Президент України; Розпорядження від 10.05.2000 № 192/2000-рп

Про зміни у складі Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар

Стан: Втратив чинність

Ідентифікатор: 192/2000-рп

Текст документа від 13.11.2001:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про зміни у складі Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар

На зміну пункту 2 Розпорядження Президента України від 27 березня 1998 року N 67 ( 67/98-рп ) (із змінами, внесеними Розпорядженням від 23 лютого 1999 року N 38 ( 38/99-рп ) та пункту 1 Розпорядження Президента України від 15 квітня 1998 року N 86 ( 86/98-рп ) (із змінами, внесеними Розпорядженнями від 22 вересня 1998 року N 501 ( 501/98-рп ) та від 23 лютого 1999 року N 38):

1. Призначити РОГОВОГО Василя Васильовича - Першого заступника Глави Адміністрації Президента України керівником Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар.

2. Затвердити новий склад Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар (додається).

Президент України Л.КУЧМА

м. Київ, 10 травня 2000 року N 192/2000-рп
