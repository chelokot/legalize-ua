Верховна Рада України; Постанова від 17.12.2008 № 674-VI

Про визнання такою, що втратила чинність, Постанови Верховної Ради України "Про продовження терміну використання житлових чеків для приватизації державного житлового фонду"

Стан: Чинний

Ідентифікатор: 674-17

Текст документа від 17.12.2008:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про визнання такою, що втратила чинність, Постанови Верховної Ради України "Про продовження терміну використання житлових чеків для приватизації державного житлового фонду"

( Відомості Верховної Ради України (ВВР), 2009, N 9, ст.135 )

У зв'язку з тим, що в Законі України "Про приватизацію державного житлового фонду" ( 2482-12 ) термін використання житлових чеків для реалізації громадянами права на приватизацію житла з державного житлового фонду не встановлено, Верховна Рада України постановляє:

1. Визнати такою, що втратила чинність, Постанову Верховної Ради України від 21 грудня 2000 року "Про продовження терміну використання житлових чеків для приватизації державного житлового фонду" ( 2160-14 ) (Відомості Верховної Ради України, 2001 р., N 4, ст. 26; 2003 р., N 7, ст. 74; 2006 р., N 49, ст. 495).

2. Ця Постанова набирає чинності з дня її опублікування.

Голова Верховної Ради України В.ЛИТВИН
