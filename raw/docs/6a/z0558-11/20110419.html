Про внесення змін до наказів Міністерства охорони здоров'я України від 13.02.2006 N 67 та від 29.03.2006 N 179

Відповідно до Положення про Міністерство охорони здоров'я України, затвердженого Указом Президента України від 13.04.2011 N 467 ( 467/2011 ), та з метою приведення нормативно-правових актів Міністерства охорони здоров'я України у відповідність до вимог чинного законодавства НАКАЗУЮ:

1. Унести до Інструкції щодо заповнення форми первинної облікової документації N 153/о "Журнал обліку випадків перинатальної смерті" ( z0225-06 ), затвердженої наказом Міністерства охорони здоров'я України від 13.02.2006 N 67 ( z0221-06 ), зареєстрованої в Міністерстві юстиції України 02.03.2006 за N 225/12099, такі зміни:

1.1. Пункт 4 викласти в такій редакції:

"4. Дані про перинатальну смерть в журналі заповнюються на підставі Лікарського свідоцтва про перинатальну смерть (форма N 106-2/о) ( z1154-06 ), яке оформлюється у порядку, визначеному Інструкцією щодо заповнення і реєстрації лікарського свідоцтва про перинатальну смерть (форма N 106-2/о), затвердженою наказом Міністерства охорони здоров'я України від 08.08.2006 N 545 ( z1150-06 ), зареєстрованою в Міністерстві юстиції України 25.10.2006 за N 1154/13028.";

1.2. В абзаці другому пункту 5 знаки, слова та цифри "(форма N 103/о-95)" замінити знаками, словами та цифрами "(форма N 103/о) ( z1150-06 )".

2. Унести до Порядку реєстрації живонароджених і мертвонароджених ( z0428-06 ), затвердженого наказом Міністерства охорони здоров'я України від 29.03.2006 N 179 ( z0427-06 ), зареєстрованого в Міністерстві юстиції України 12.04.2006 за N 428/12302, такі зміни:

2.1. У абзацах четвертому та дев'ятому пункту 1 Порядку ( z0428-06 ) знаки, букви та цифри "(ф. N 103/о-95)" замінити знаками, буквами та цифрами "(ф. N 103/о) ( z1150-06 )";

2.2. В абзаці п'ятому пункту 1 Порядку ( z0428-06 ) знаки, букви та цифри "(ф. N 103-1/о-96)" замінити знаками, буквами та цифрами "(ф. N 103-1/о) ( z1151-06 )".

3. Директору Департаменту охорони материнства, дитинства та санаторного забезпечення забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням цього наказу покласти на першого заступника Міністра Аніщенка О.В.

Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр І.М.Ємець
