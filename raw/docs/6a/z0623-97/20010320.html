N 121 від 16.12.97 Зареєстровано в Міністерстві м.Київ юстиції України 25 грудня 1997 р. vd971216 vn121 за N 623/2427

Про заходи щодо відстрілу і відлову хижих та шкідливих тварин

( Із змінами, внесеними згідно з Наказом Держкомлісгоспу N 21 ( z0255-01 ) від 02.03.2001 )

У відповідності до статті 33 Закону України "Про мисливське господарство та полювання" ( 1478-14 ) та з метою посилення роботи з відстрілу і відлову хижих та шкідливих тварин, у першу чергу вовків та бродячих собак, НАКАЗУЮ:

( Преамбула в редакції Наказу Держкомлісгоспу N 21 ( z0255-01 ) від 02.03.2001 )

1. Начальникам обласних управлінь лісового господарства, генеральним директорам державних лісогосподарських об'єднань створити в областях постійно діючі бригади мисливців по відстрілу і відлову хижих та шкідливих тварин, в першу чергу вовків та бродячих собак, забезпечивши їх набоями, організувавши відповідну підготовку мисливців для виконання цієї роботи.

( Пункт 1 із змінами, внесеними згідно з Наказом Держкомлісгоспу N 21 ( z0255-01 ) від 02.03.2001 )

2. Встановити винагороду за добування вовка (незалежно від статі і віку) в розмірі 100 грн. за голову. ( Пункт 2 із змінами, внесеними згідно з Наказом Держкомлісгоспу N 21 ( z0255-01 ) від 02.03.2001 )

3. Умовою виплати винагороди за добутого вовка є пред'явлення мисливцем в державний орган лісового господарства відповідних документів заготівельної організації про здачу шкіри хижака та довідки-підтвердження мисливствознавця в районі, або ж здача шкіри вовка в державний орган лісового господарства чи мисливствознавцю в районі. ( Пункт 3 із змінами, внесеними згідно з Наказом Держкомлісгоспу N 21 ( z0255-01 ) від 02.03.2001 )

4. Винагорода за добутих вовків виплачується державним органом лісового господарства за рахунок коштів, передбачених статтею 36 Закону України "Про мисливське господарство та полювання" ( 1478-14 ), згідно з кошторисом, затвердженим Держкомлісгоспом України.

( Пункт 4 із змінами, внесеними згідно з Наказом Держкомлісгоспу N 21 ( z0255-01 ) від 02.03.2001 )

5. Контроль за виконанням наказу покласти на начальника Управління мисливського господарства ШАДУРУ М.В. ( Пункт 5 із змінами, внесеними згідно з Наказом Держкомлісгоспу N 21 ( z0255-01 ) від 02.03.2001 )
