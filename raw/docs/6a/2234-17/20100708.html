Про призначення позачергових виборів Рижківського сільського голови (Рижківська сільська рада Коропського району Чернігівської області)

Стан: Втратив чинність

Ідентифікатор: 2234-17

Текст документа від 08.07.2010:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

{ Постанова втратила чинність на підставі Постанови ВР N 2473-VI ( 2473-17 ) від 08.07.2010, ВВР, 2010, N 40, ст.528 }

Про призначення позачергових виборів Рижківського сільського голови (Рижківська сільська рада Коропського району Чернігівської області)

( Відомості Верховної Ради України (ВВР), 2010, N 30, ст.413 )

У зв'язку з достроковим припиненням повноважень Рижківського сільського голови Колоди Н.М. (Рижківська сільська рада Коропського району Чернігівської області) та відповідно до пункту 30 частини першої статті 85 Конституції України ( 254к/96-ВР ), частини третьої статті 14, частин другої та шостої статті 15, статей 82, 83 Закону України "Про вибори депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів" ( 1667-15 ) Верховна Рада України постановляє:

1. Призначити позачергові вибори Рижківського сільського голови (Рижківська сільська рада Коропського району Чернігівської області) на неділю 1 серпня 2010 року.

2. Центральній виборчій комісії з урахуванням пропозицій відповідної територіальної виборчої комісії визначити в установленому порядку обсяг бюджетних видатків, необхідних для проведення позачергових виборів Рижківського сільського голови.

3. Кабінету Міністрів України в межах повноважень вжити невідкладних заходів щодо забезпечення фінансування позачергових виборів Рижківського сільського голови за рахунок коштів цільової субвенції з Державного бюджету України ( 2154-17 ).

4. Ця Постанова набирає чинності з дня її опублікування.
