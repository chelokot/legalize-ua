Кабінет Міністрів України; Розпорядження від 23.06.2010 № 1249-р

Деякі питання реалізації інвестиційного проекту створення національної супутникової системи зв'язку

Стан: Чинний

Ідентифікатор: 1249-2010-р

Текст документа від 05.12.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 червня 2010 р. N 1249-р Київ

Деякі питання реалізації інвестиційного проекту створення національної супутникової системи зв'язку

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1009-р ( 1009-2012-р ) від 05.12.2012 }

Уповноважити Міністра фінансів підписувати документи, пов'язані з державними гарантіями, наданими в 2009 році стосовно виконання зобов'язань державного підприємства "Укркосмос" щодо фінансування робіт із створення національної супутникової системи зв'язку в рамках підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, у тому числі погодження, пов'язані із внесенням змін до графіка погашення кредиту за кредитним договором, укладеним між зазначеним підприємством та Канадською експортною агенцією.

{ Текст Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 1009-р ( 1009-2012-р ) від 05.12.2012 }

Прем'єр-міністр України М.АЗАРОВ
