Про внесення змін до наказів МОЗ України від 14 квітня 2006 року N 225 та від 17 квітня 2006 року N 230

Реєстрація: Мін'юст України від 31.07.2006 № 893/12767

Стан: Чинний

Ідентифікатор: z0893-06

Текст документа від 11.07.2006:

МІНІСТЕРСТВО ОХОРОНИ ЗДОРОВ'Я УКРАЇНИ

НАКАЗ

11.07.2006 N 461

Зареєстровано в Міністерстві юстиції України 31 липня 2006 р. за N 893/12767

Про внесення змін до наказів МОЗ України від 14 квітня 2006 року N 225 та від 17 квітня 2006 року N 230

З метою виправлення технічної помилки в наказах МОЗ України від 14 квітня 2006 року N 225 ( z0505-06 ) "Про затвердження Положення про Український центр з профілактики та боротьби зі СНІДом Міністерства охорони здоров'я України", зареєстрованому в Міністерстві юстиції України 3 травня 2006 року за N 505/12379, та від 17 квітня 2006 року N 230 ( z0504-06 ) "Про створення Референс-лабораторії діагностики ВІЛ-інфекції/СНІДу при Українському центрі з профілактики та боротьби зі СНІДом Міністерства охорони здоров'я України", зареєстрованому в Міністерстві юстиції України 3 травня 2006 року за N 504/12378, НАКАЗУЮ:

1. Унести такі зміни до наказу МОЗ України від 14 квітня 2006 року N 225 ( z0505-06 ) "Про затвердження Положення про Український центр з профілактики та боротьби зі СНІДом Міністерства охорони здоров'я України", зареєстрованого в Міністерстві юстиції України 3 травня 2006 року за N 505/12379 (далі - Наказ):

1.1. У назві та тексті Наказу ( z0505-06 ) слова "Український центр з профілактики та боротьби зі СНІДом" у всіх відмінках замінити словами "Український центр профілактики і боротьби зі СНІДом" у відповідних відмінках.

1.2. У назві та тексті Положення про Український центр з профілактики та боротьби зі СНІДом Міністерства охорони здоров'я України, затвердженого Наказом ( z0505-06 ), слова "Український центр з профілактики та боротьби зі СНІДом" у всіх відмінках замінити словами "Український центр профілактики і боротьби зі СНІДом" у відповідних відмінках.

2. Унести такі зміни до наказу МОЗ України від 17 квітня 2006 року N 230 ( z0504-06 ) "Про створення Референс-лабораторії діагностики ВІЛ-інфекції/СНІДу при Українському центрі з профілактики та боротьби зі СНІДом Міністерства охорони здоров'я України", зареєстрованого в Міністерстві юстиції України 3 травня 2006 року за N 504/12378 (далі - Наказ):

2.1. У назві та тексті Наказу ( z0504-06 ) слова "Український центр з профілактики та боротьби зі СНІДом" у всіх відмінках замінити словами "Український центр профілактики і боротьби зі СНІДом" у відповідних відмінках.

2.2. У назві та тексті Положення про Референс-лабораторію діагностики ВІЛ-інфекції/СНІДу при Українському центрі з профілактики та боротьби зі СНІДом Міністерства охорони здоров'я України, затвердженого Наказом ( z0504-06 ), слова "Український центр з профілактики та боротьби зі СНІДом" у всіх відмінках замінити словами "Український центр профілактики і боротьби зі СНІДом" у відповідних відмінках.

3. Начальнику Відділу інфекційних соціально небезпечних хвороб МОЗ України Федьку О.А. разом з директором Українського центру профілактики і боротьби зі СНІДом Щербінською А.М. здійснити в установленому порядку державну реєстрацію цього наказу в Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника Міністра охорони здоров'я України Івасюка В.П.

Міністр Ю.В.Поляченко
