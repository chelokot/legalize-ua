РОЗПОРЯДЖЕННЯ від 9 липня 1997 р. N 380-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 646 ( 646-2007-п ) від 20.04.2007 }

Про створення міжвідомчої робочої групи з координації та контролю за ходом реалізації Проекту з розвитку насінництва

Для забезпечення координації та контролю за ходом реалізації Угоди про надання позики (Проект з розвитку насінництва) між Україною та Міжнародним банком реконструкції і розвитку від 28 вересня 1995 р. ( 996_664 ) утворити міжвідомчу робочу групу у складі згідно з додатком.

Дозволити голові міжвідомчої робочої групи вносити зміни до її персонального складу.

Рішення зазначеної міжвідомчої робочої групи, прийняті в межах її компетенції, є обов'язковими для учасників проекту і доводяться до них у вигляді протоколів засідань цієї групи.
