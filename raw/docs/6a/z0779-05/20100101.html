Держкомстат України; Наказ, Інструкція, Форма від 07.07.2005 № 169

Про затвердження форм переписних листів та інструкцій щодо проведення обліку (перепису) поголів'я худоби у домашніх господарствах за станом на 1 січня 2006 року

Реєстрація: Мін'юст України від 20.07.2005 № 779/11059

Стан: Чинний

Ідентифікатор: z0779-05

Текст документа від 01.01.2010:

ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

07.07.2005 N 169

Зареєстровано в Міністерстві юстиції України 20 липня 2005 р. за N 779/11059

Про затвердження форм переписних листів та інструкцій щодо проведення обліку (перепису) поголів'я худоби у домашніх господарствах за станом на 1 січня 2006 року

{ Із змінами, внесеними згідно з Наказом Державного комітету статистики N 189 ( z0839-07 ) від 02.07.2007 }

{ Щодо втрати чинності Наказу додатково див. Наказ Державного комітету статистики N 222 ( v0222202-09 ) від 30.06.2009 }

Відповідно до статті 14 Закону України "Про державну статистику" ( 2614-12 ) та на виконання розпорядження Кабінету Міністрів України від 5 липня 2004 року N 424-р ( 424-2004-р ) "Про проведення перезакладення книг погосподарського обліку та перепису поголів'я худоби у домашніх господарствах" НАКАЗУЮ:

1. Затвердити форми переписних листів з обліку худоби в домашніх господарствах сільської місцевості та перепису худоби у міських населених пунктах, що додаються:

1.1. Форма N 3 "Переписний лист домашніх господарств з обліку худоби та наявності сільськогосподарської техніки на 1 січня 200_ року";

{ Наказ втратив чинність в частині затвердження форми N 5 на підставі Наказу Державного комітету статистики N 189 ( z0839-07 ) від 02.07.2007 } 1.2. Форма N 5 "Переписний лист перевірки (контрольного обходу) чисельності худоби у домашніх господарствах сільської місцевості та міських населених пунктів".

2. Поширити форми переписних листів, затверджених пунктом 1 цього наказу, на сільські, селищні та міські ради, на території яких розташовані сільські населені пункти, та на міські населені пункти.

{ Наказ втратив чинність в частині затвердження інструкцій щодо проведення обліку (перепису) поголів'я худоби у домашніх господарствах на підставі Наказу Державного комітету статистики N 189 ( z0839-07 ) від 02.07.2007 } 3. Затвердити інструкції щодо проведення обліку (перепису) поголів'я худоби у домашніх господарствах, що додаються.

3.1. Інструкцію для районних органів державної статистики щодо проведення обліку (перепису) худоби за станом на 1 січня 2006 року;

3.2. Інструкцію обліковцям щодо перепису худоби у домашніх господарствах у міських населених пунктах за станом на 1 січня 2006 року ( z0780-05 );

3.3. Інструкцію щодо обліку худоби у домашніх господарствах у сільських, селищних та міських радах, на території яких розташовані сільські населені пункти, за станом на 1 січня 2006 року ( z0781-05 ).

4. Поширити інструкцію, затверджену підпунктом 3.3 пункту 3 цього наказу, на сільські, селищні та міські ради, на території яких розташовані сільські населені пункти.

5. Департаменту статистики сільського господарства та навколишнього середовища (Прокопенко О.М.):

5.1. Запровадити в практику органів державної статистики інструкції, затверджені підпунктами 3.1 та 3.2 пункту 3 цього наказу.

5.2. Здійснювати керівництво збором та розробкою цих форм переписних листів, затверджених пунктом 1 цього наказу.

5.3. Визначити потрібний тираж, підготувати і передати адміністративно-господарському департаменту (Царський В.І.) оригінали бланків форм та інструкцій, затверджених пунктами 1 та 3 цього наказу, для виготовлення.

6. Департаменту фінансового забезпечення, бухгалтерського обліку та звітності (Сорокіна Т.В.) забезпечити фінансування робіт щодо виготовлення бланків форм та інструкцій, затверджених пунктами 1 та 3 цього наказу.

7. Адміністративно-господарському департаменту (Царський В.І.) забезпечити контроль за своєчасним виготовленням та відправленням бланків форм (N 3 і N 5) та інструкцій на адресу головних управлінь статистики в Автономній Республіці Крим, областях, м. Києві та Управління статистики у м. Севастополі.

8. Визнати такими, що втратили чинність, накази Держкомстату України:

8.1. Від 27.08.2000 N 275 ( v0275202-00 ) "Про затвердження форм державної статистичної звітності з сільського і рибного господарства та заготівлі" в частині форми державного статистичного спостереження N 5 "Акт-список перевірки (контрольного обходу) дворів"; Рекомендацій по перепису худоби в господарствах населення, що проживає в міських поселеннях, для обліковця; Рекомендацій по проведенню обліку худоби для керівника районного відділу статистики; Рекомендацій по обліку худоби при закладці та уточненні даних погосподарських книг сільських (селищних) рад, затверджених пунктом 1 наказу.

8.2. Від 25.06.2004 N 412 ( v0412202-04 ) "Про затвердження форм державних статистичних спостережень із сільського і рибного господарства" в частині форми державного статистичного спостереження N 3 "Подвірний список по обліку худоби та наявності сільськогосподарської техніки в сільській місцевості", затвердженої підпунктом 1.2. пункту 1 наказу.

9. Контроль за виконанням цього наказу покласти на заступника Голови Остапчука Ю.М.

Голова О.Г.Осауленко
