Кабінет Міністрів України; Розпорядження від 12.11.2008 № 1436-р

Про структуру апарату центральних органів виконавчої влади та їх територіальних підрозділів, апарату місцевих державних адміністрацій, їх управлінь, відділів, інших структурних підрозділів

Стан: Чинний

Ідентифікатор: 1436-2008-р

Текст документа від 03.12.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 листопада 2008 р. N 1436-р Київ

Про структуру апарату центральних органів виконавчої влади та їх територіальних підрозділів

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1514-р ( 1514-2008-р ) від 03.12.2008 }

Установити, що у разі прийняття рішення про скорочення чисельності працівників центральних органів виконавчої влади та їх територіальних підрозділів, пов'язаного з проведенням заходів щодо економії бюджетних коштів, допускається за погодженням з Мінфіном з урахуванням існуючої структури органу виконавчої влади збереження в 2008-2010 роках структурних підрозділів та посад заступників начальників відділів без урахування критеріїв, встановлених постановою Кабінету Міністрів України від 12 березня 2005 р. N 179 ( 179-2005-п ) "Про упорядкування структури апарату центральних органів виконавчої влади, їх територіальних підрозділів та місцевих державних адміністрацій" (Офіційний вісник України, 2005 р., N 11, ст. 522, N 43, ст. 2715; 2006 р., N 33, ст. 2391; 2007 р., N 20, ст. 798; 2008 р., N 68, ст. 2270), щодо чисельності працівників таких підрозділів та кількості підрозділів у їх складі. { Абзац перший із змінами, внесеними згідно з Розпорядженням КМ N 1514-р ( 1514-2008-р ) від 03.12.2008 }

{ Абзац другий виключено на підставі Розпорядження КМ N 1514-р ( 1514-2008-р ) від 03.12.2008 }
