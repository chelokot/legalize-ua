( Із змінами, внесеними згідно з Постановою КМ N 1935 ( 1935-98-п ) від 09.12.98 )

Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита на окремі види товарів ( 4а-93, 4б-93, 4в-93 ) згідно з додатком.

2. Затвердити зміни, що вносяться до деяких постанов Кабінету Міністрів України (додаються).

3. У пункті 5 змін, що вносяться до деяких постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 18 травня 1998 р. N 693 ( 693-98-п ) (Офіційний вісник України, 1998 р., N 20, ст. 734), посилання на число 17 замінити посиланням на число 14.

4. Ця постанова набирає чинності через 45 днів з дня її опублікування у газеті "Урядовий кур'єр".
