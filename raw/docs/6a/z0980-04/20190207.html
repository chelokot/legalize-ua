Про затвердження граничного ліміту на вивезення за межі України валюти України

{ Із змінами, внесеними згідно з Постановою Національного банку N 321 ( z1074-05 ) від 31.08.2005 }

Відповідно до вимог статей 5, 11, 13 Декрету Кабінету Міністрів України від 19.02.93 N 15-93 ( 15-93 ) "Про систему валютного регулювання і валютного контролю", а також пункту 14 статті 7 та статті 44 Закону України "Про Національний банк України" ( 679-14 ) та пункту 4 постанови Правління Національного банку України від 19.04.2004 N 166 ( z0629-04 ) "Про вивезення з України та ввезення в Україну готівкових гривень", зареєстрованої в Міністерстві юстиції України 18.05.2004 за N 629/9228, Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити граничний ліміт на вивезення за межі України валюти України для здійснення валютно-обмінних операцій на території іноземних держав (далі - граничний ліміт), у межах якого Департамент валютного контролю та ліцензування (далі - Департамент) надає спеціальні дозволи уповноваженим банкам:

усього на III квартал 2004 року - 9,5 млн.грн., у тому числі:

липень - 5,0 млн.грн.;

серпень - 3,0 млн.грн.;

вересень - 1,5 млн.грн.;

усього на IV квартал 2004 року - 4,5 млн.грн., у тому числі:

жовтень - 1,5 млн.грн.;

листопад - 1,5 млн.грн.;

грудень - 1,5 млн.грн.

{ Пункт 1 із змінами, внесеними згідно з Постановою Національного банку N 321 ( z1074-05 ) від 31.08.2005 }

2. Граничний ліміт поточного місяця може бути збільшено на суму невикористаного залишку ліміту минулого місяця або кварталу в межах одного календарного року.

3. Спеціальні дозволи на вивезення за межі України валюти України надаються Департаментом у межах установленого граничного ліміту. Якщо сума граничного ліміту є меншою, ніж загальна сума відповідно до заяв, які надійшли від уповноважених банків до Департаменту для отримання зазначених спеціальних дозволів, то граничний ліміт розподіляється Департаментом пропорційно наданим заявам. У разі звернення одного уповноваженого банку для отримання спеціального дозволу і ненадходження заяв від інших уповноважених банків до часу оформлення спеціального дозволу уповноваженому банку, що звернувся за ним, зазначений спеціальний дозвіл може бути надано на суму не більше ніж 50% установленого граничного ліміту.

4. Контроль за виконанням цієї постанови покласти на Департамент валютного контролю та ліцензування (О.Г.Біланенко). { Пункт 4 із змінами, внесеними згідно з Постановою Національного банку N 321 ( z1074-05 ) від 31.08.2005 }
