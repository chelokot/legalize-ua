Кабінет Міністрів України; Розпорядження від 24.02.2010 № 267-р

Про покладення виконання обов'язків Міністра внутрішніх справ на Клюєва М.М.

Стан: Чинний

Ідентифікатор: 267-2010-р

Текст документа від 02.03.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 лютого 2010 р. N 267-р Київ

Про покладення виконання обов'язків Міністра внутрішніх справ на Клюєва М.М.

{ Із змінами, внесеними згідно з Розпорядженням КМ N 336-р ( 336-2010-р ) від 02.03.2010 }

З метою забезпечення виконання завдань, покладених на Міністерство внутрішніх справ та підпорядковані йому органи і підрозділи, до завершення розгляду справи у відповідних судах стосовно Луценка Ю.В. покласти виконання обов'язків Міністра внутрішніх справ на його першого заступника Клюєва Михайла Михайловича.

Першому заступникові Міністра внутрішніх справ Клюєву М.М. здійснювати повноваження Міністра, передбачені абзацом третім пункту 9, підпунктами 3, 4, 7, 9, 13 і 15 пункту 10 та абзацом третім пункту 13 Положення про Міністерство внутрішніх справ України, затвердженого постановою Кабінету Міністрів України від 4 жовтня 2006 р. N 1383 ( 1383-2006-п ) (Офіційний вісник України, 2006 р., N 40, ст. 2687; 2008 р., N 16, ст. 416, N 35, ст. 1174), за погодженням з Першим віце-прем'єр-міністром України. { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 336-р ( 336-2010-р ) від 02.03.2010 }
