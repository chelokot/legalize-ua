Президент України; Розпорядження від 14.09.2005 № 1166/2005-рп

Про делегацію України на четверту Конференцію із сприяння набуттю чинності Договором про всеосяжну заборону ядерних випробувань

Стан: Втратив чинність

Ідентифікатор: 1166/2005-рп

Текст документа від 07.02.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України на четверту Конференцію із сприяння набуттю чинності Договором про всеосяжну заборону ядерних випробувань

1.Утворити делегацію України на четверту Конференцію із сприяння набуттю чинності Договором про всеосяжну заборону ядерних випробувань ( 995_372 ) (21-23 вересня 2005 року, м. Нью-Йорк) у такому складі:

ДОЛГОВ - заступник Міністра закордонних справ Ігор Олексійович України, глава делегації

КУЧИНСЬКИЙ - Постійний представник України при

Валерій Павлович Організації Об'єднаних Націй

НІМЧИНСЬКИЙ - начальник відділу Департаменту

Руслан Михайлович контролю над озброєнням та військово-технічного співробітництва Міністерства закордонних справ України

ПЕРЕБИЙНІС - заступник Керівника Головної служби

Євген Петрович зовнішньої політики Секретаріату Президента України.

2. Міністрові закордонних справ України затвердити Вказівки делегації України на четверту Конференцію із сприяння набуттю чинності Договором про всеосяжну заборону ядерних випробувань ( 995_372 ).

3. Кабінету Міністрів України виділити кошти в іноземній валюті для забезпечення участі Перебийноса Є.П. у роботі четвертої Конференції із сприяння набуттю чинності Договором про всеосяжну заборону ядерних випробувань ( 995_372 ).

Президент України В.ЮЩЕНКО

м. Київ, 14 вересня 2005 року N 1166/2005-рп
