ЗАТВЕРДЖЕНО Наказ Міністерства охорони здоров'я України 21.12.2010 N 1141 ( z0319-11 )

Зареєстровано в Міністерстві юстиції України 14 березня 2011 р. за N 320/19058

ІНСТРУКЦІЯ щодо заповнення форми первинної облікової документації N 502-3/0 "Журнал реєстрації надходження зразків сироваток крові для проведення скринінгових досліджень на наявність серологічних маркерів ВІЛ"

{ Заголовок Інструкції редакції Наказу Міністерства охорони здоров'я N 718 ( z1931-12 ) від 17.09.2012 }

1. Інструкція визначає порядок заповнення форми первинної облікової документації N 502-3/о "Журнал реєстрації надходження зразків сироваток крові для проведення скринінгових досліджень на наявність серологічних маркерів ВІЛ" (далі - Журнал).

{ Пункт 1 в редакції Наказу Міністерства охорони здоров'я N 718 ( z1931-12 ) від 17.09.2012 }

2. N 502-3/0 "Журнал реєстрації надходження зразків сироваток крові для проведення скринінгових досліджень на антитіла до ВІЛ" (далі - Журнал).

3. У лівому верхньому куті Журналу зазначають найменування і місцезнаходження закладу, в якому заповнюється форма, та ідентифікаційний код Єдиного державного реєстру підприємств та організацій України (ЄДРПОУ).

4. У графі 1 вказують порядковий номер реєстраційного Журналу. Нумерація Журналу починається 1 січня та закінчується 31 грудня поточного року.

5. У графі 2 вказують дату надходження зразка на дослідження в лабораторію.

6. У графі 3 вказують прізвище, ім'я, по батькові особи або індивідуальний номер особи.

7. У графі 4 вказують найменування ЛПЗ або установи, з якої надійшов зразок.

8. У графі 5 вказують стать особи: Ч - чоловіча, Ж - жіноча.

9. У графі 6 вказують рік народження особи.

10. У графі 7 вказують код обстеження контингентів відповідно до форми звітності N 2 - ВІЛ/СНІД "Звіт про осіб із станами та хворобами, що зумовлені вірусом імунодефіциту людини (ВІЛ), за 20__ рік" (річна), затвердженої наказом Міністерства охорони здоров'я України, Державного комітету статистики України від 24.12.2004 N 640/663 ( z0062-05 ), зареєстрованої у Міністерстві юстиції України 19.01.2005 за N 62/10342.

11. У графі 8 вказують назву тесту, на якому проводили скринінгові дослідження.

12. У графі 9 вказують дату проведення дослідження.

13. У графі 10 вказують результат тестування у вигляді "негативний", "позитивний", "невизначений, сумнівний".
