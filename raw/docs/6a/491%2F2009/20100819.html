{ Указ втратив чинність на підставі Указу Президента N 827/2010 ( 827/2010 ) від 19.08.2010 }

Про зміну у складі Комісії при Президентові України у питаннях помилування

На часткову зміну статті 1 Указу Президента України від 29 квітня 2005 року N 731 ( 731/2005 ) "Про новий склад Комісії при Президентові України у питаннях помилування" (зі змінами, внесеними Указами від 28 грудня 2005 року N 1868 ( 1868/2005 ) та від 15 вересня 2008 року N 834) ( 834/2008 ) призначити головою Комісії при Президентові України у питаннях помилування МОЙСИКА Володимира Романовича - народного депутата України (за згодою), увільнивши його від виконання обов'язків заступника голови цієї Комісії.

Президент України В.ЮЩЕНКО
