Текст документа від 30.07.2007:

МІНІСТЕРСТВО УКРАЇНИ З ПИТАНЬ НАДЗВИЧАЙНИХ СИТУАЦІЙ ТА У СПРАВАХ ЗАХИСТУ НАСЕЛЕННЯ ВІД НАСЛІДКІВ ЧОРНОБИЛЬСЬКОЇ КАТАСТРОФИ

НАКАЗ

N 308 від 16.11.2000 Зареєстровано в Міністерстві м.Київ юстиції України 28 листопада 2000 р. vd20001116 vn308 за N 877/5098

{ Наказ втратив чинність на підставі Наказу Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 444 ( z0833-07 ) від 25.06.2007 }

Про затвердження форми Розрахунку з відшкодування витрат організаціям, які забезпечують паливом громадян, постраждалих внаслідок Чорнобильської катастрофи

На виконання пункту 23 постанови Кабінету Міністрів України від 20 червня 2000 р. N 987 ( 987-2000-п ) "Порядок використання коштів Фонду для здійснення заходів щодо ліквідації наслідків Чорнобильської катастрофи та соціального захисту населення" НАКАЗУЮ:

1. Затвердити форму Розрахунку з відшкодування витрат організаціям, які забезпечують паливом громадян, постраждалих внаслідок Чорнобильської катастрофи, що додається. Відшкодування витрат організаціям провадиться територіальними органами Державного казначейства на підставі поданих розрахунків.

2. Начальнику управління соціального захисту та роботи з населенням Байраку М.В. і начальнику юридичного відділу Орленку М.Т. забезпечити подання на державну реєстрацію до Міністерства юстиції України наказу "Про затвердження форми Розрахунку з відшкодування витрат організаціям, які забезпечують паливом громадян, постраждалих внаслідок Чорнобильської катастрофи".

3. Начальнику управління діловодства Дяченко Г.П. в 10-денний термін після державної реєстрації наказу "Про затвердження форми Розрахунку з відшкодування витрат організаціям, які забезпечують паливом громадян, постраждалих внаслідок Чорнобильської катастрофи" забезпечити тиражування його та надсилання Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям.

4. Контроль за виконанням цього наказу покласти на першого заступника Міністра Логінова В.В.

Міністр В.В.Дурдинець
