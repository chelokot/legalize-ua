(та інструкцій щодо їх заповнення) по статистиці фінансів на 1998 рік

( Щомісячний збір державної статистичної звітності за формою N 1-Б "Звіт про дебіторську та кредиторську заборгованість" від малих підприємств і організацій у 1998 році відмінено згідно з Наказом Держкомстату N 27 ( v0027202-98 ) від 23.01.98 )

( Наказ втратив чинність в частині затвердження статистичної звітності за формою N 1-СТ на підставі Наказу Держкомстатистики N 222 ( z0521-99 ) від 25.06.99 )

( Наказ втратив чинність, у частині затвердження форми N 1-ДТ (квартальна, річна) та інструкції щодо її заповнення на підставі Наказу Державного комітету статистики N 103 ( z0265-04 ) від 16.02.2004 )

З метою оперативного одержання даних щодо результатів фінансової діяльності України та відповідно до п.5 Положення про Міністерство статистики України, затвердженого постановою Кабінету Міністрів від 22 березня 1993 р. N 214 ( 214-93-п ), НАКАЗУЮ:

1. Затвердити такі форми державної статистичної звітності:

( Абзац другий пункту 1 втратив чинність на підставі Наказу Держкомстатистики N 290 ( z0568-98 ) від 20.08.98 ) N 1-Б термінова (місячна) "Звіт про дебіторську та кредиторську заборгованість";

N 2-Б (квартальна, річна) "Звіт про випуск, реалізацію та обіг цінних паперів";

N 1-СТ (квартальна, річна) "Звіт про фінансову діяльність страхової організації";

( Абзац пункту 1 втратив чинність на підставі Наказу Держкомстатистики N 223 ( z0522-99 ) від 25.06.99 ) N 1-ПФ (квартальна, річна) "Звіт про фінансову діяльність позабюджетного фонду";

( Абзац пункту 1 втратив чинність на підставі Наказу Держкомстатистики N 223 ( z0522-99 ) від 25.06.99 ) N 1-ДТ (квартальна, річна) "Звіт про фінансову діяльність довірчого товариства"

та інструкції щодо їх заповнення, що додаються.

Ввести в дію, починаючи зі звіту за 1997 рік, вищеназвані форми статистичної звітності та інструкції до них.

2. Розповсюдити вказані форми на підприємства та організації всіх галузей народного господарства і форм власності (крім установ, що утримуються на кошти бюджету).

3. Управлінню статистики фінансів (Шах Г.А.) своєчасно забезпечити поліграфічне підприємство затвердженими оригіналами форм статистичної звітності.

4. Економічному управлінню Мінстату України (Шевченко Т.М.) забезпечити фінансування робіт по виготовленню бланкової продукції.

5. Голові Держкомстату Автономної Республіки Крим, начальникам обласних, Київського та Севастопольського міських управлінь статистики забезпечити доведення бланків вказаних форм до підприємств, організацій та установ, що розташовані на території їх регіонів, здійснювати збір та розробку цих форм.

6. ГОЦ Мінстату України (Крамарєв В.Г.) здійснювати збирання та зведення статистичної інформації по вказаних формах.

7. Контроль за виконанням цього наказу залишаю за собою.

Зареєстровано в Міністерстві юстиції України 19 вересня 1997 р. за N 414/2218

( Інструкція втратила чинність на підставі Наказу Держкомстатистики N 290 ( z0568-98 ) від 20.08.98 )

Інструкція щодо заповнення форми N 1-Б "Звіт про дебіторську та кредиторську заборгованість"

( Дані по графах 4 - 7, 9 - 12 форми N 1-Б "Звіт про дебіторську та кредиторську заборгованість", в яких наведено групування дебіторської та кредиторської заборгованості по термінах прострочення заборгованості, заповнюються підприємствами та організаціями за окремими запитами органів статистики згідно з Наказом Держкомстату N 27 ( v0027202-98 ) від 23.01.98 )

1. Статистичний звіт за формою N 1-Б складають всі підприємства та організації, незалежно від підпорядкування та форми власності, які перебувають на господарському розрахунку, мають самостійний баланс і є юридичними особами (включаючи банки, малі, спільні підприємства), крім організацій, що утримуються на кошти бюджету.

2. Заповнення форми провадиться на підставі даних первинного бухгалтерського обліку та звітності та щомісячного аналітичного обліку. В цілому її показники повинні співпадати з показниками форми N 1 "Баланс підприємства", що затверджується Міністерством фінансів України для річної та квартальної бухгалтерської звітності.

3. Форма N 1-Б складається з трьох розділів:

I розділ "Заборгованість між підприємствами України";

II розділ "Заборгованість з суб'єктами господарської діяльності країн - колишніх республік СРСР";

III розділ "Заборгованість з суб'єктами господарської діяльності інших країн".

Рядок 010 відображає загальну суму заборгованості - розділ I (рядок 020) + розділ II (рядок 130) + розділ III (рядок 280).

4. Дебіторська і кредиторська заборгованість між підприємствами України (розділ I ряд.020) поділяється на основні її види, а саме:

- "за товари, роботи, послуги" (рядок 030) відповідає сумі рядків зі 160 по 180 активу балансу по дебіторській заборгованості та з 630 по 640 пасиву - по кредиторській;

- "по векселях" (рядок 040) - рядка 190 активу та 650 пасиву балансу;

- "по оплаті праці" (рядок 050) - рядка 700 пасиву балансу;

- "з персоналом за іншими операціями" (рядок 060) - рядка 210 активу балансу;

- "з бюджетом" (рядок 070) - рядка 200 активу та 670 пасиву балансу;

- "по позабюджетних платежах" (рядок 080) - рядка 680 пасиву балансу;

- "по авансах" (рядок 090) - рядка 220 активу та 660 пасиву балансу;

- "по страхуванню" (рядок 100) - рядка 690 пасиву балансу;

- "з дочірніми підприємствами" (рядок 110) - рядка 230 активу та 710 пасиву балансу;

- "інша заборгованість" (рядок 120) - рядка 240 активу та 720 пасиву балансу. Із загальної суми іншої заборгованості (рядок 120 форми N 1-Б) виділяються штрафи, пені, неустойки (рядок 121), що були визнані боржником або по яких отримані рішення суду, арбітражного суду чи іншого належного органу про їх стягнення.

5. Дебіторська і кредиторська заборгованість між підприємствами України та суб'єктами господарської діяльності країн - колишніх республік СРСР (розділ II рядок 130) буде приблизно відповідати даним активу та пасиву форми N 1 "Баланс підприємства" в частині, що стосується виключно взаємовідносин з країнами - колишніми республіками СРСР, а саме сумі рядків:

- "за товари, роботи, послуги" відповідає сумі рядків зі 160 по 180 активу балансу по дебіторській заборгованості та з 630 по 640 пасиву - по кредиторській;

- "по векселях" - рядка 190 активу та 650 пасиву балансу;

- "по оплаті праці" - рядка 700 пасиву балансу;

- "по авансах" - рядка 220 активу та 660 пасиву балансу;

- "по страхуванню" - рядка 690 пасиву балансу;

- "інша заборгованість" - рядка 240 активу та 720 пасиву балансу.

6. Розділ III (рядок 280) заповнюється за взірцем розділу II, але у частині, що стосується взаємовідносин з країнами так званого далекого зарубіжжя.

7. Присудок форми N 1-Б складається з 12 колонок, які є загальними для всіх трьох розділів. У колонках 1 та 2 відображається загальна сума дебіторської та кредиторської заборгованості. У колонках 3 та 8 із загальної суми дебіторської та кредиторської заборгованості вирізняється сума простроченої заборгованості з розбивкою по термінах, а саме:

- до 3 місяців;

- з 3 місяців до 1 року;

- з 1 року до 2 років;

- понад 2 роки.

Обсяги простроченої заборгованості по кожному з термінів визначаються згідно з умовами конкретних договорів між суб'єктами господарської діяльності.

Слід зауважити, що дані колонки 3 по всіх рядках повинні бути меншими або дорівнювати даним колонки 1. Аналогічне співвідношення зберігається між колонками 8 і 2.

8. Підприємства заповнюють форму у тис.гривень (без десяткового знаку) та подають на 15-й день після звітного періоду до статистичного органу за місцем розташування.

9. Статистичні органи Автономної Республіки Крим, всіх областей та міст Києва і Севастополя подають звітність за цією формою на адресу ГОЦ Мінстату України у терміни, передбачені планом статистичних робіт на 1998 рік.

Інструкція щодо заповнення форми N 1-ПФ "Звіт про фінансову діяльність позабюджетного фонду"

1. Статистичний звіт за формою N 1-ПФ складають всі позабюджетні фонди, що є юридичними особами, включаючи загальнодержавні, згідно з чинним законодавством, а також всі інші фонди регіону, створені як під певну довгострокову програму, так і з конкретною некомерційною метою (відрахування до останніх здійснюється на добровільній основі).

2. Заповнення форми проводиться за відповідний звітний період, на дискретній основі (за I квартал, II квартал, III квартал, IV квартал, рік) у тис.гривень (без десяткового знаку) на підставі даних первинного бухгалтерського обліку та звітності.

У звіті за рік передбачається уточнення звітних даних за попередні квартали. Сума уточнених даних за квартали повинна дорівнювати даним у цілому за рік.

( Пункт 2 в редакції Наказу Держкомстатистики N 223 ( z0522-99 ) від 25.06.99 )

3. Методологія побудови форми базується на такій основі складання фінансового звіту: залишки коштів на початок звітного періоду, надходження, витрати, залишки коштів на кінець звітного періоду.

3.1. У рядку 010 "Залишки коштів на початок звітного періоду" показуються залишки грошових коштів фонду на початок року.

3.2. Надходження коштів до фонду (рядок 020) включають всі види надходжень з усіх джерел, тобто як від обов'язкових та благодійних перерахунків, так і від комерційної діяльності фонду, якщо така має місце, тобто сума всіх надходжень дорівнює сумі рядків 030, 040, 050, 060, 070, 080, 110 та вільних рядків 090 та 100 (що залишені для запису значних за питомою вагою видів надходжень, не передбачених формою, які можуть виникнути в процесі діяльності фонду; вказівки щодо їх заповнення будуть надходити централізовано від Мінстату України).

У рядку 030 проставляється сума перерахунків до фонду з бюджетів усіх рівнів, якщо такі мали місце.

У рядку 040 враховуються надходження від підприємств та організацій (юридичних осіб) України та інших держав, в перерахунку в гривні за курсом, встановленим Національним банком України (ряд.040 = ряд.041 + 042 + 043).

У рядку 050 показується обсяг перерахунків від громадян (фізичних осіб) України та інших країн в перерахунку в гривні за курсом, встановленим Національним банком України (ряд.050 = = ряд.051 + 052 + 053).

Доходи від комерційної діяльності (рядок 060) включають надходження до фонду від діяльності, не пов'язаної з основною метою його створення і направленої на отримання додаткового прибутку.

Крім комерційної діяльності, зазначеної вище, в певній мірі до цієї діяльності включаються і види, перелічені у рядках 070 ("Кредити, отримані від банків та інших фінансових установ"), 080 ("Проценти, отримані по кредитах наданих"), 110 ("Інші надходження").

3.3. Витрати фонду (рядок 120) включають всі види видатків та виплат, що здійснюються фондом (ряд.120 = ряд.130 + 140 + 150 + + 160 + 170 + 180 + 190).

У рядку 130 показуються витрати на діяльність, пов'язану з основною метою створення фонду.

Видатки на утримання апарату управління (рядок 140) включають виплату заробітної плати та всі інші витрати на апарат управління фонду.

Платежі до бюджету (рядок 150) складаються з обсягів внесків до бюджетів (як Державного, так і до місцевих), нарахованих з загальної суми надходжень.

У рядку 160 показуються проценти, які були сплачені за кредити, отримані фондом.

Витрати (якщо такі були) на фінансування державних закладів відображаються у рядку 170.

У рядку 180 показуються витрати на капітальні вкладення та капітальний ремонт.

Інші витрати (рядок 190) враховують всі види господарських та інших витрат, які виникають в процесі діяльності фонду.

3.4. У рядку 200 "Залишки коштів на кінець звітного періоду" показуються залишки грошових коштів фонду на кінець I кварталу, I півріччя, 9 місяців, звітного року і є підсумком фінансової діяльності фонду (ряд.200 = ряд.010 + 020 - 120).

3.5. У рядках 210 та 220 довідково наводяться відповідно: вартість основних фондів на кінець звітного періоду та середньоспискова чисельність працівників за звітний період.

4. Терміни подання звітності для позабюджетних фондів до органів статистики за місцем знаходження за формою N 1-ПФ вказані на бланку. Регіональні органи статистики подають на адресу ГОЦ Мінстату України звітність за цією формою у терміни, передбачені планом статистичних робіт на 1998 рік, в тис.гривень (без десяткового знаку) у трьох розрізах: всього, в тому числі окремо загальнодержавні фонди та всі інші фонди, що існують в регіоні.

3. Методологія побудови форми базується на стандартній основі складання фінансового звіту, тобто вказуються доходи, видатки, перевищення доходів над видатками (+) або видатків над доходами (-).

3.1. Доходи страхової організації (рядок 010) складаються з доходів від її прямої діяльності, тобто надходжень від страхових платежів (рядок 020), надходжень від перестраховування (рядок 030), та інших доходів (рядок 050), що включають доходи від непрямої діяльності організації (ряд.010 = ряд.020 + 030 + 040 + + 050).

Обсяг надходжень від страхових платежів (рядок 020) більший або рівний сумі рядків 021 - 029, куди входять такі їх види, як:

- добровільне особисте страхування (без страхування життя) (рядок 021), в тому числі від населення (0211), що включає пенсійне, від нещасних випадків, медичне;

- добровільне особисте страхування життя (рядок 022), в тому числі від населення (0221);

- добровільне майнове страхування (рядок 023), в тому числі від населення (0231), що включає страхування всіх засобів транспорту, вантажів, фінансових ризиків, майна державних підприємств, всіх інших видів майна (домашнього майна, майна кооперативних підприємств та. ін.);

- добровільне страхування відповідальності (рядок 024), в тому числі від населення (рядок 0241), що включає страхування таких видів відповідальності, як ризик неповернення кредиту, відповідальність позичальника за неповернення кредиту і та. ін.;

- обов'язкове особисте страхування (рядок 025), в тому числі від населення (рядок 0251), що включає страхування працівників правоохоронних органів та військовослужбовців, працівників прокуратури, митних органів, органів внутрішніх справ, КРУ, народних депутатів, суддів, службових осіб державних податкових інспекцій, працівників пожежної та лісової охорони, спортсменів, донорів крові, медпрацівників на випадок інфікування вірусом СНІД, працівників ветеринарної медицини, водіїв, членів екіпажу та авіаційного персоналу, авіапасажирів і т.п.;

- обов'язкове майнове страхування (рядок 026), в тому числі від населення (рядок 0261), що включає страхування врожаю сільськогосподарських культур і багаторічних насаджень в державних сільськогосподарських підприємствах; страхування авіаційних суден і т.п.;

- обов'язкове страхування відповідальності (рядок 027), в тому числі від населення (рядок 0271), що включає страхування відповідальності повітряного перевізника і виконавця повітряних робіт щодо відшкодування збитків, заподіяних пасажирам, пошті, багажеві, вантажеві; страхування відповідальності експлуатанта повітряного судна за збитки, які можуть бути завдані ним при виконанні авіаційних робіт; страхування цивільної відповідальності власників транспортних засобів.

Вільні рядки 028 та 029 передбачені для запису інших видів страхування, що можуть виникати в процесі господарської діяльності. Вказівки щодо їх заповнення будуть надходити централізовано від Мінстату України.

Надходження від перестраховування (рядок 030) включають надходження від перестраховування страхового договору, товарів в дорозі та всіх інших страхових премій за договорами перестраховування.

Вільний рядок 040 передбачений для запису не перелічених вище видів прямих доходів (безпосередньо від страхової діяльності), які можуть виникнути в процесі функціонування страхових організацій. Вказівки щодо їх заповнення будуть надходити централізовано від Мінстату України.

Інші доходи (рядок 050), в тому числі від інвестування та розміщення тимчасових вільних коштів (рядок 051), включають такі, що безпосередньо не пов'язані зі страховою діяльністю, зокрема від цінних паперів та дольової участі в спільних підприємствах; прибуток від реалізації і ліквідації основних фондів; від здачі окремого майна в оренду; від курсових різниць валютних рахунків та операцій в іноземній валюті; прибутки минулих років, що виявлені у звітному періоді; від надходження боргів, раніше списаних як безнадійні; пені, неустойки та інші види санкцій за порушення господарських договорів, які визнані боржником або щодо яких одержано рішення про вилучення.

У вільному рядку 060 показуються надходження зі страхових резервів, що не входять до загальної суми доходів (рядок 010).

У рядку 070 із загального обсягу доходів проставляються надходження страхових платежів від нерезидентів України.

3.2. Видатки страхової організації (рядок 080) складаються з видатків на безпосередню її діяльність, тобто на виплати страхових відшкодувань (рядок 090), виплат по перестраховуванню (рядок 100), видатків на утримання апарату управління (рядок 110), видатків на ведення справи (рядок 120), та видатків на непряму діяльність, тобто дивідендів та процентів, виплачених по цінних паперах (рядок 140), інших видатків (рядок 150). Також до видатків страхової організації належать платежі до бюджетів всіх рівнів (рядок 130). Виходячи з викладеного вище, ряд.080 = ряд.090 + + 100 + 110 + 120 + 130 + 140 + 150.

Обсяг виплат страхових відшкодувань (рядок 090) більше або дорівнює сумі рядків 091 - 097, що включають такі види виплат, як:

- по добровільному особистому страхуванню (без страхування життя); в тому числі населенню;

- по добровільному особистому страхуванню життя; в тому числі населенню;

- по добровільному майновому страхуванню; в тому числі населенню;

- по добровільному страхуванню відповідальності; в тому числі населенню;

- по обов'язковому особистому страхуванню; в тому числі населенню.

Вільні рядки 096 та 097 передбачені для запису страхових виплат по інших видах страхування, що можуть виникати в процесі господарської діяльності. Вказівки щодо їх заповнення будуть надходити централізовано від Мінстату України.

Виплати по перестраховуванню (рядок 100) включають всі страхові премії, передані страховою організацією на перестраховування.

Видатки на утримання апарату управління (рядок 110) включають виплату заробітної плати (рядок 111) та всі інші витрати на апарат управління.

Видатки на ведення справи (рядок 120) включають всі господарські видатки страхової організації.

Платежі до бюджетів всіх рівнів (рядок 130) складаються з обсягів внесків до бюджетів (як Державного, так і до місцевих), з загального обсягу доходів (як від прямої, так і непрямої діяльності).

Дивіденди та проценти, виплачені по цінних паперах (рядок 140), включають всі види цих виплат з боку страхової організації юридичним та фізичним особам, що придбали її цінні папери.

Інші видатки (рядок 150) враховують всі види витрат на непряму діяльність страхової організації.

Резервування коштів (рядок 160) включає суми відрахувань від платежів по всіх видах страхування згідно з встановленими нормами до запасних, резервних та фондів запобіжних заходів на випадки незапланованих видатків, а також для майбутніх виплат за звітний період. Ця сума не включається в загальний обсяг видатків (рядок 080).

У рядку 170 із загального обсягу видатків показуються страхові премії, передані страховою компанією нерезидентам України.

3.3. Рядок 080 розраховується як різниця між доходами та видатками (рядок 010 - рядок 080) і буде позитивним (зі знаком плюс) при прибутковій діяльності організації та негативним (зі знаком мінус) у випадку збиткової діяльності.

3.4. У рядку 190 "Прибуток" проставляється балансовий прибуток страхової організації - рядок 090 "Балансовий прибуток або збиток" з форми N 2 "Звіт про фінансові результати та їх використання" (як для річної, так і для квартальної звітності).

4. Терміни подання звітності для страхових організацій до органів статистики за місцем знаходження за формою N 1-СТ вказані на бланку. Регіональні органи статистики подають на адресу ГОЦ Мінстату України звітність за цією формою у терміни, передбачені планом статистичних робіт на 1998 рік, в тис.гривень (без десяткового знаку) у трьох розрізах: всього, в тому числі окремо організації колишнього Укрдержстраху (тепер Національна акціонерна страхова компанія "ОРАНТА") та всі інші комерційні організації регіону.

Інструкція щодо заповнення форми N 2-Б "Звіт про випуск, реалізацію та обіг цінних паперів"

1. Статистичний звіт по формі N 2-Б складають всі підприємства та організації незалежно від підпорядкування та форми власності, які перебувають на господарському розрахунку, мають самостійний баланс і є юридичними особами, а також банки (але крім малих і спільних підприємств та бюджетних організацій).

Звіт складають як емітенти, так і ті, що мають в обігу цінні папери (не власні). Підприємства, що не є емітентами та оперують не власними цінними паперами, заповнюють тільки підрозділи "Цінні папери інших емітентів" у розділі II та "Цінні папери, що придбані у нерезидентів" у розділі III.

2. Заповнення форми провадиться за відповідний звітний період наростаючим підсумком з початку року (за I квартал, I півріччя, 9 місяців, рік), на підставі даних первинного бухгалтерського обліку та звітності, за номінальною вартістю цінних паперів.

3. Розділ I вміщує інформацію про випуск і розміщення цінних паперів емітентами, котра включає їх наявність на початок року, випуск та первинне розміщення цінних паперів у звітному періоді, без урахування подальших операцій з ними (вторинного ринку цінних паперів).

3.1. В підрозділі "Випущено цінних паперів" вказується:

- у колонці 1 - вартість тих цінних паперів, випущених підприємством за весь період його діяльності, які реально існують на 1 січня звітного року (тобто не були погашені до цієї дати). Вона повинна залишатись без змін протягом звітного року (якщо не було переоцінок чи інших державних заходів стосовно цінних паперів);

- у колонці 2 - вартість всіх власних цінних паперів, випущених у звітному періоді (включно із такими, які встигли погасити протягом цього періоду). Якщо підприємство стало акціонерним після 1 січня звітного року, то вартість цінних паперів відображається тільки у даній колонці. У такому разі колонка 1 не заповнюється і показники колонки 2 дорівнюватимуть відповідним показникам колонки 3;

- у колонці 3 - вартість власних цінних паперів на кінець звітного періоду, яка обраховується як сума вартостей цінних паперів на початок року та випущених у звітному періоді (колонка 1 + колонка 2).

3.2. У підрозділі "Розміщено на початок року" проставляється вартість цінних паперів емітента, що знаходяться у власності фізичних та юридичних осіб (включно з нерезидентами) станом на 1 січня звітного року, незалежно від того, було це первинне розміщення цих паперів чи подальші операції з ними (повторний продаж):

- у колонці 4 - всього, тобто розміщено юридичним та фізичним особам і інвесторам інших країн (колонка 4 дорівнює сумі колонок 5, 6 та 7);

- у колонці 5 - юридичним особам (суб'єктам господарської діяльності, що мають ознаки юридичної особи);

- у колонці 6 - фізичним особам, тобто населенню;

- у колонці 7 - інвесторам інших країн (нерезидентам).

3.3. У підрозділі "Вперше розміщено у звітному періоді" показується вартість власних цінних паперів, вперше розміщених безпосередньо емітентом протягом звітного періоду (як з випущених у звітному періоді, так і з залишку нерозміщених на початок року, незалежно від того, чи знаходилися вони в обігу до звітного періоду). Колонки 8, 9, 10, 11 побудовані за взірцем колонок 4, 5, 6, 7 підрозділу 3.2.

3.4. Показники підрозділу "Розміщено в цілому" розраховуються як сума даних з відповідних колонок другого і третього підрозділів, а саме: колонка 12 = колонка 4 + колонка 8 (а також дорівнює сумі колонок 13, 14, 15); колонка 13 = = колонка 5 + колонка 9; колонка 14 = колонка 6 + колонка 10; колонка 15 = колонка 7 + колонка 11.

3.5. У підметі таблиці наведено види цінних паперів згідно з Законом України "Про цінні папери та фондову біржу" ( 1201-12 ), проте через складнощі ведення детального первинного бухгалтерського обліку цінних паперів вони приведені в таблиці, в основному, в загальному вигляді:

- рядок 010 "Всього" відображає загальну вартість всіх видів цінних паперів (акцій, облігацій, казначейських зобов'язань, ощадних сертифікатів, векселів, інших цінних паперів) і по всіх колонках є сумою рядків 020, 030, 040, 050, 060, 070;

- рядок 020 "Акції", крім простих (рядок 021) та привілейованих (рядок 022), містить також інші їх різновиди, але без акцій підприємств та акцій трудового колективу, що не мають вільного обігу. Тому дані рядка 020 повинні бути більшими або дорівнювати сумі рядків 021, 022;

- рядок 030 "Облігації", крім республіканських позик (рядок 031) та облігацій підприємств (рядок 032), містить облігації місцевих безпроцентних позик, місцевих процентних позик та облігацій колишнього СРСР. Через це дані рядка 030 будуть більшими або дорівнюватимуть сумі рядків 031 та 032. В свою чергу, облігації республіканських позик складаються з внутрішніх республіканських безпроцентних (цільових) позик, внутрішніх республіканських процентних позик та інших видів державних облігацій.

Облігації підприємств містять іменні процентні, іменні безпроцентні, на пред'явника процентні та безпроцентні облігації.

Слід зазначити, що всі вищезгадані облігації можуть бути як вільнообіговими, так і з обмеженим колом обігу.

Такі види цінних паперів, як казначейські зобов'язання та ощадні сертифікати (депозитні) відрізняються за термінами погашення:

- рядок 040 "Казначейські зобов'язання" показує вартість довгострокових, середньострокових та короткострокових зобов'язань;

- рядок 050 "Ощадні сертифікати (депозитні)" містить в собі іменні строкові, іменні до запитання, на пред'явника строкові та на пред'явника до запитання;

- рядок 060 "Векселі" складається з вартості простих і переказних векселів;

- рядок 070 "Інші цінні папери" має включати вартість акцій підприємств, акцій трудових колективів та інших цінних паперів, не передбачених формою, тобто тих, які не можна повністю зарахувати до цінних, оскільки вони не мають всіх ознак цінного паперу (зокрема ознаки їх вільного обігу), бо реалізуються тільки робітникам тих підприємств, де вони випущені.

Крім того, довідково введено рядки про обсяг статутного фонду підприємства, декларованого з урахуванням випуску цінних паперів:

- 080 "на початок року";

- 090 "на кінець звітного періоду".

Це дозволяє провадити логічний контроль при складанні форми за умови, що: вартість акцій та облігацій на початок року, випущених під створення або збільшення статутного фонду, (сума рядків 020 та 030, колонка 1), не повинна перевищувати обсяг статутного фонду на початок року. Таким чином контролюються і вищевказані показники на кінець звітного періоду (рядок 090 повинен бути більшим або дорівнювати сумі рядків 020 та 030 у колонці 3). Також слід зазначити, що вартість випущених за звітний період акцій та облігацій (сума рядків 020 та 030, колонка 2) не повинна перевищувати приріст статутного фонду за відповідний період (рядок 090 - рядок 080).

4. Розділ II "Обіг цінних паперів" характеризує операції з усіма цінними паперами, які є у власності емітента (як випущеними ним безпосередньо, так і придбаними у інших емітентів), тобто висвічує вторинний ринок цінних паперів.

4.1. У підрозділі "Цінні папери емітента власні" показуються операції з цінними паперами, випущеними саме емітентом, зокрема:

- у колонці 1 - вартість всіх власних цінних паперів підприємства на кінець звітного періоду, тобто дані цієї колонки повинні бути ідентичними даним колонки 3 розділу I;

- у колонці 2 - сума вартості цінних паперів, розміщених на початок року та вперше розміщених у звітному періоді (тобто дані колонки 12, розділ I), в тому числі:

- у колонці 3 - за особисті приватизаційні рахунки (майнові сертифікати та житлові чеки чи інші державні приватизаційні папери, що будуть існувати на момент здійснення операцій);

- у колонці 4 - обсяги повторно придбаних (викуплених) власних цінних паперів за звітний період;

- у колонці 5 - обсяг повторно проданих цінних паперів з викуплених у звітному періоді;

- у колонці 6 - обсяг повторно проданих цінних паперів з викуплених у звітному періоді, в тому числі за особисті приватизаційні рахунки;

- у колонці 7 - вартість поданих до погашення та погашених у звітному періоді власних цінних паперів;

- у колонці 8 - залишок не розміщених власних цінних паперів, що зосталися у емітента на кінець звітного періоду (як вперше випущених, так і придбаних удруге), що розраховується таким чином: колонка 1 - колонка 2 + колонка 4 - колонка 5 - колонка 7;

- у колонці 9 - дивіденди по акціях та проценти по всіх інших видах цінних паперів, виплачених емітентом у звітному періоді.

4.2. У підрозділі "Цінні папери інших емітентів" показуються операції підприємства з цінними паперами, випущеними виключно іншими емітентами:

- у колонці 10 - вартість не власних цінних паперів, якими володіє підприємство на початок року;

- у колонці 11 - придбано підприємством цінних паперів інших емітентів за звітний період;

- у колонці 12 - придбано підприємством цінних паперів інших емітентів за звітний період, в тому числі за особисті приватизаційні рахунки. Це стосується структур, що займаються приватизаційною посередницькою діяльністю (інвестиційних фондів та трастових компаній) та беруть на себе відповідальність за розміщення особистих приватизаційних паперів, довірених їх власниками;

- у колонці 13 - обсяги не власних цінних паперів, проданих підприємством за звітний період як безпосередньо емітентам, так і іншим покупцям;

- у колонці 14 показується залишок не власних цінних паперів, що знаходяться у підприємства на кінець звітного періоду;

- у колонці 15 - дивіденди по акціях та проценти по всіх інших видах цінних паперів, отримані підприємством у звітному періоді від емітентів за придбані у них цінні папери.

4.3. Підмет розділу II ідентичний до підмета розділу I (крім довідкових даних про обсяги статутного фонду) і на нього розповсюджуються вказівки, викладені у пункті 3.5.

5. Розділ III "Обсяги взаємного інвестування у вигляді цінних паперів" висвітлює як інвестування через цінні папери суб'єктів господарської діяльності України - резидентів-емітентів суб'єктами господарської діяльності інших держав - нерезидентами (перший підрозділ), так і інвестування резидентами нерезидентів-емітентів.

5.1. У підрозділі "Цінні папери резидента-емітента у нерезидентів" показується:

- у колонці 1 - залишок на початок року цінних паперів резидента-емітента у власності нерезидентів;

- у колонці 2 - вартість цінних паперів, придбаних нерезидентами у резидента-емітента у звітному періоді (включно як з первинним їх розміщенням, так і вторинним продажем);

- у колонці 3 - обсяги власних цінних паперів резидента, проданих та пред'явлених з метою погашення нерезидентами резидентові-емітенту, а також погашених останніми у звітному періоді;

- у колонці 4 - залишок вартості власних цінних паперів резидента у нерезидентів на кінець звітного періоду, тобто колонка 1 + колонка 2 - колонка 3;

- у колонці 5 - дивіденди по акціях та проценти по всіх інших видах цінних паперів, виплачених резидентом нерезидентам у звітному періоді.

5.2. У підрозділі "Цінні папери нерезидентів-емітентів у резидентів" відображується:

- у колонці 6 - залишок нерезидентських цінних паперів у власності резидента на початок року;

- у колонці 7 - вартість цінних паперів нерезидентів, придбаних резидентом у звітному періоді як безпосередньо у нерезидентів-емітентів, так і у інших продавців;

- у колонці 8 - обсяги нерезидентських цінних паперів, проданих резидентом нерезидентам-емітентам та іншим покупцям у звітному періоді;

- у колонці 9 - залишок вартості нерезидентських цінних паперів у резидента на кінець звітного періоду, тобто колонка 6 + + колонка 7 - колонка 8;

- у колонці 10 - дивіденди по акціях та проценти по всіх інших видах цінних паперів, отримані резидентом у звітному періоді від нерезидентів-емітентів за придбані у них цінні папери.

5.3. Підмет розділу III побудований у більш загальному вигляді порівняно з попередніми двома розділами, оскільки не всі види цінних паперів мають вільний обіг (наприклад, інші цінні папери), про що докладно розповідається у пункті 3.5. Проте щодо всіх узагальнюючих рядків цього розділу мають силу вказівки, викладені у пункті 3.5.

6. Терміни подання звітності для суб'єктів господарської діяльності до органів статистики за місцем знаходження по формі N 2-Б вказані на бланку. Вказівки щодо заповнення статистичної форми N 2-Б

Резидент - юридична чи фізична особа, постійним місцем знаходження та реєстрації якого є Україна.

Нерезидент - юридична чи фізична особа, постійним місцем знаходження чи реєстрації якого є інша держава, крім України.

Розділ I. К.3 = к.1 + к.2 К.4 = к.5 + к.6 + к.7. К.8 = к.9 + + к.10 + к.11. К.12 = к.4 + к.8 = к.13 + к.14 + к.15. К.13 = к.5 + + к.9. К.14 = к.6 + к.10. К.15 = к.7 + к.11.

Розділ II. К.8 = к.1 - к.2 + к.4 - к.5 - к.7. К.14 = к.10 + + к.11 - к.13.

Розділ III. К.4 = к.1 + к.2 - к.3. К.9 = к.6 + к.7 + к.8.

К.1 та к.4 - вартість цінних паперів суб'єкта господарської діяльності України (резидента-емітента), що знаходилися у власності нерезидентів відповідно на початок року і кінець звітного періоду.

К.2 - вартість цінних паперів резидентів-емітентів, придбаних у них нерезидентами за звітний період.

К.3 - вартість власних цінних паперів, викуплених у звітному періоді резидентом-емітентом у нерезидентів з метою повторного продажу чи погашення.

К.6 та к.9 - вартість цінних паперів нерезидентів-емітентів, що знаходилися у власності резидента на початок року і кінець звітного періоду.

К.7 - цінні папери нерезидентів, придбані резидентом за звітний період як у емітентів, так і у інших продавців.

К.8 - цінні папери нерезидентів, продані резидентом за звітний період як емітенту, так і іншим покупцям.
