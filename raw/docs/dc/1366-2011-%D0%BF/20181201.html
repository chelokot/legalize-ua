Кабінет Міністрів України; Постанова від 28.12.2011 № 1366

Про внесення зміни до переліку об'єктів, що підлягають обов'язковій охороні підрозділами Державної служби охорони при Міністерстві внутрішніх справ за договорами

Стан: Втратив чинність

Ідентифікатор: 1366-2011-п

Текст документа від 01.12.2018:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 грудня 2011 р. N 1366 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 975 ( 975-2018-п ) від 21.11.2018 }

Про внесення зміни до переліку об'єктів, що підлягають обов'язковій охороні підрозділами Державної служби охорони при Міністерстві внутрішніх справ за договорами

Кабінет Міністрів України постановляє:

Внести зміну до переліку об'єктів, що підлягають обов'язковій охороні підрозділами Державної служби охорони при Міністерстві внутрішніх справ за договорами, затвердженого постановою Кабінету Міністрів України від 10 серпня 1993 р. N 615 ( 615-93-п ) "Про заходи щодо вдосконалення охорони об'єктів державної та інших форм власності" (ЗП України, 1994 р., N 2, ст. 31; Офіційний вісник України, 2002 р., N 29, ст. 1383; 2004 р., N 29, ст. 1961; 2008 р., N 28, ст. 882; 2009 р., N 67, ст. 2324; 2011 р., N 26, ст. 1066, N 28, ст. 1199), доповнивши його абзацом такого змісту:

"Клінічна лікарня "Феофанія" Державного управління справами".

Прем'єр-міністр України М.АЗАРОВ
