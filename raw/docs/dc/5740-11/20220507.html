ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

{ Постанова не застосовується на території України згідно із Законом N 2215-IX ( 2215-20 ) від 21.04.2022 }

Про утворення Комісії Верховної Ради Української РСР з питань патріотичного та інтернаціонального виховання і міжнаціональних відносин

( Відомості Верхвоної Ради (ВВР), 1988, N 18, ст. 445 )

Верховна Рада Української Радянської Соціалістичної Республіки постановляє:

Утворити Комісію Верховної Ради Української РСР з питань патріотичного та інтернаціонального виховання і міжнаціональних відносин.
