07.03.2007 N 297

Зареєстровано в Міністерстві юстиції України 13 березня 2007 р. за N 221/13488

{ Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 934 ( z0769-08 ) від 07.08.2008 }

Про внесення змін до постанови НКРЕ від 19.12.2006 N 1672

Відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" (із змінами) та постанови Кабінету Міністрів України від 29.04.2006 N 605 ( 605-2006-п ) "Деякі питання діяльності Національної акціонерної компанії "Нафтогаз України" (із змінами, унесеними постановою Кабінету Міністрів України від 01.03.2007 N 338 ( 338-2007-п ) Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Пункт 5 Роздрібних цін на природний газ, що використовується для потреб населення, затверджених постановою НКРЕ від 19.12.2006 N 1672 ( z1330-06 ), зареєстрованих у Міністерстві юстиції України 20.12.2006 за N 1330/13204, виключити.

2. Ця постанова застосовується з 1 березня 2007 року.

3. Управлінню регулювання та цінової політики нафтогазового комплексу в установленому законодавством порядку забезпечити подання цієї постанови на державну реєстрацію до Міністерства юстиції України.

Голова Комісії С.Тітенко
