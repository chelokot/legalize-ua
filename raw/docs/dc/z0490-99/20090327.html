Стан: Втратив чинність

Текст документа від 27.03.2009:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 322 від 05.07.99 Зареєстровано в Міністерстві м.Київ юстиції України 21 липня 1999 р. vd990705 vn322 за N 490/3783

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про затвердження Правил залучення до охорони установ банків IV-V категорій охорони суб'єктів підприємницької діяльності, які отримали ліцензії на надання охоронних послуг

{ Із змінами, внесеними згідно з Постановою Нацбанку N 134 ( z0338-01 ) від 28.03.2001 }

На виконання п.1.10 Інструкції з організації охорони установ банків України, затвердженої постановою Правління Національного банку України від 25.12.98 N 548дск та наказом Міністерства внутрішніх справ України від 25.12.98 N 963дск, з метою визначення Національним банком України Правил залучення до охорони установ банків IV-V категорій охорони суб'єктів підприємницької діяльності, які отримали ліцензії на надання охоронних послуг, Правління ПОСТАНОВЛЯЄ:

1. Затвердити Правила залучення до охорони установ банків IV-V категорій охорони суб'єктів підприємницької діяльності, які отримали ліцензії на надання охоронних послуг (далі - Правила, що додаються).

2. Департаменту готівково-грошового обігу (Н.В.Дорофєєва) довести ці Правила до відома регіональних управлінь Національного банку України та комерційних банків для використання в роботі.

3. Ця постанова набуває чинності через десять днів після державної реєстрації в Міністерстві юстиції України.

Голова В.А.Ющенко

( Правила залучення до охорони установ банків IV-V категорій охорони суб'єктів підприємницької діяльності, які отримали ліцензії на надання охоронних послуг втратили чинність на підставі Постанови Нацбанку N 134 ( z0338-01 ) від 28.03.2001 )
