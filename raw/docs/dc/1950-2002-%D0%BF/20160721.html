КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 грудня 2002 р. N 1950 Київ

Про затвердження переліку пунктів пропуску через митний кордон України, через які дозволяється переміщення наркотичних засобів, психотропних речовин і прекурсорів

{ Із змінами, внесеними згідно з Постановами КМ N 92 ( 92-2003-п ) від 18.01.2003 N 577 ( 577-2004-п ) від 29.04.2004 N 871 ( 871-2005-п ) від 08.09.2005 N 552 ( 552-2009-п ) від 03.06.2009 N 1351 ( 1351-2011-п ) від 28.12.2011 N 415 ( 415-2016-п ) від 06.07.2016 }

Відповідно до частини другої статті 195 Митного кодексу України ( 4495-17 ) Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 415 ( 415-2016-п ) від 06.07.2016 }

1. Затвердити перелік пунктів пропуску через митний кордон України, через які дозволяється переміщення наркотичних засобів, психотропних речовин і прекурсорів (додається).

2. Ця постанова набирає чинності з 1 січня 2004 року.

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 92 ( 92-2003-п ) від 18.01.2003 )
