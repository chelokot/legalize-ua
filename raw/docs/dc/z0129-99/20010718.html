ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 542 від 24.12.98 Зареєстровано в Міністерстві м.Київ юстиції України 2 березня 1999 р. vd981224 vn542 за N 129/3422

Про затвердження Тимчасового положення про порядок навчання та атестації фахівців з дилінгових операцій на валютних ринках

( Із змінами, внесеними згідно з Постановою Національного банку N 234 ( z0603-01 ) від 21.06.2001 )

З метою забезпечення координації діяльності з навчання та атестації фахівців, які здійснюють професійну діяльність з дилінгових операцій на валютних ринках, керуючись статтею 8 Статуту Національного банку України, затвердженого Постановою Президії Верховної Ради України від 7 жовтня 1991 року N 1605-12, Правління ПОСТАНОВЛЯЄ:

1. Затвердити Тимчасове положення про порядок навчання та атестації фахівців з дилінгових операцій на валютних ринках (додається).

2. Зареєструвати постанову в установленому порядку в Міністерстві юстиції України та надіслати Асоціації українських банків, Українській міжбанківській валютній біржі, Міністерству освіти України, а також Кримському республіканському, обласним та по м.Києву і Київській області управлінням та установам Національного банку України.

3. Контроль за виконанням цієї постанови покласти на Департамент персоналу (М.В.Ільїн) та Департамент валютного регулювання (С.О.Яременко).

4. Постанова набуває чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

Голова В.А.Ющенко

( Тимчасове положення про порядок навчання та атестації фахівців з дилінгових операцій на валютних ринках втратило чинність на підставі Постанови Національного банку N 234 ( z0603-01 ) від 21.06.2001 )
