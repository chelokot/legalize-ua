Кабінет Міністрів України; Постанова від 27.06.2003 № 1009

Про внесення зміни до Тимчасового порядку внесення змін до алгоритму оптового ринку електричної енергії та здійснення контролю за його дотриманням

Стан: Втратив чинність

Ідентифікатор: 1009-2003-п

Текст документа від 17.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 червня 2003 р. N 1009 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 513 ( 513-2016-п ) від 08.08.2016 }

Про внесення зміни до Тимчасового порядку внесення змін до алгоритму оптового ринку електричної енергії та здійснення контролю за його дотриманням

Кабінет Міністрів України постановляє:

У пункті 2 Тимчасового порядку внесення змін до алгоритму оптового ринку електричної енергії та здійснення контролю за його дотримання, затвердженого постановою Кабінету Міністрів України від 19 лютого 2002 р. N 200 ( 200-2002-п ) (Офіційний вісник України, 2002 р., N 8, ст. 363), слова "в офіційному друкованому органі Кабінету Міністрів України" виключити.

Перший віце-прем'єр-міністр України М.АЗАРОВ
