Інструкція про порядок обчислення і справляння платежів за користування надрами для видобування корисних копалин

1. Загальні положення

1.1. Інструкція про порядок обчислення і справляння платежів за користування надрами для видобування корисних копалин (надалі - Інструкція) розроблена на підставі Закону України "Про охорону навколишнього природного середовища" ( 1264-12 ), Кодексу України про надра ( 132/94-ВР ), Закону України "Про підприємництво" ( 698-12 ), постанов Кабінету Міністрів України від 12 грудня 1994 року N 827 ( 827-94-п ) "Про затвердження переліків корисних копалин загальнодержавного та місцевого значення", від 2 серпня 1996 року N 899 ( 899-96-п ) "Про платежі за користування надрами", від 5 травня 1997 року N 432 ( 432-97-п ) "Про затвердження Класифікації запасів і ресурсів корисних копалин державного фонду надр" та від 12 вересня 1997 року N 1014 ( 1014-97-п ) "Про затвердження базових нормативів плати за користування надрами для видобування корисних копалин та Порядку справляння плати за користування надрами для видобування корисних копалин".

1.2. Інструкція визначає єдині на території України, в межах її континентального шельфу та виключної (морської) економічної зони правила справляння платежів за користування надрами для видобування корисних копалин.

1.3. Платежі за користування надрами для видобування корисних копалин є формою реалізації економіко-правових відносин між власником ресурсів надр в особі держави та суб'єктами підприємницької діяльності, які здійснюють видобування корисних копалин (надалі - надрокористувачі).

1.4. Інструкція передбачає порядок обчислення і сплати надрокористувачами платежів за користування надрами для видобування корисних копалин, а також відповідальність платників за достовірність даних про обсяги погашених у надрах балансових та позабалансових запасів (обсяги видобутих) корисних копалин, правильність обчислення, повноту і своєчасність сплати цих платежів до бюджетів.

1.5. Інструкція обов'язкова для виконання усіма суб'єктами підприємницької діяльності незалежно від форм власності, включаючи підприємства з іноземними інвестиціями, які здійснюють видобування корисних копалин.

1.6. Внесення плати за користування надрами для видобування корисних копалин не звільняє суб'єктів підприємницької діяльності від сплати відрахувань за геологорозвідувальні роботи, виконані за рахунок Державного бюджету, інших обов'язкових платежів, якщо інше не передбачено чинним законодавством та міжнародними угодами України. Плата за користування надрами для видобування корисних копалин не справляється за видобуті прісні підземні води. Плата за спеціальне використання прісних підземних вод справляється згідно з Порядком справляння плати за спеціальне використання водних ресурсів, затвердженим постановою Кабінету Міністрів України від 8 лютого 1994 року N 75 ( 75-94-п ) "Про затвердження Порядку справляння плати за спеціальне використання прісних водних ресурсів і тимчасових нормативів плати за їх спеціальне використання" та постановою Кабінету Міністрів України від 8 лютого 1997 року N 164 ( 164-97-п ) "Про встановлення нормативів плати за спеціальне використання водних ресурсів".

1.7. Плата справляється за користування надрами для видобування корисних копалин загальнодержавного та місцевого значення. Перелік корисних копалин загальнодержавного та місцевого значення визначено постановою Кабінету Міністрів України від 12 грудня 1994 року N 827 ( 827-94-п ) "Про затвердження переліків корисних копалин загальнодержавного та місцевого значення".

2. Платники платежів за користування надрами для видобування корисних копалин

2.1. Платниками платежів за користування надрами для видобування корисних копалин є усі суб'єкти підприємницької діяльності незалежно від форм власності, які здійснюють видобування корисних копалин, включаючи підприємства з іноземними інвестиціями.

2.2. У випадку, якщо платник перестає функціонувати як самостійна юридична особа, в тому числі при його об'єднанні на будь-яких засадах з іншим підприємством, платником стає підприємство-правонаступник.

3. Об'єкт обчислення плати за користування надрами для видобування корисних копалин

3.1. Плата за користування надрами для видобування корисних копалин справляється за фактично погашені в надрах обсяги балансових та позабалансових запасів (обсяги видобутих) корисних копалин.

Об'єктом обчислення плати за користування надрами для видобування корисних копалин є:

при видобутку вугілля кам'яного, вугілля бурого, металевих корисних копалин, сировини нерудної для металургії, гірничо-хімічної, гірничорудної та будівельної сировини - обсяг фактично погашених у надрах балансових та позабалансових запасів корисних копалин;

при видобутку нафти, конденсату, газу природного, підземних вод (мінеральних, термальних, промислових), ропи, мінеральних грязей та мулу - обсяг фактично видобутих з надр корисних копалин;

при видобутку урану, сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння), виробної (виробне каміння) та для облицьовувальних матеріалів - вартість мінеральної сировини чи продукції її первинної переробки, віднесена до обсягу видобутку чи обсягу погашених в надрах запасів корисних копалин.

3.2. Обсяг погашених запасів корисних копалин визначається як сума обсягів видобутих корисних копалин та фактичних Їх втрат у надрах під час видобування.

3.3. Плата за користування надрами не справляється у разі:

- видобування раніше погашених запасів корисних копалин, що в процесі розробки родовищ були віднесені у встановленому порядку до категорії втрачених у надрах;

- використання гірничо-промислових відходів, що утворюються в процесі переробки корисних копалин (шлами, пил, шлаки тощо);

- використання розкривних і супутних порід, що утворюються в процесі видобування корисних копалин, не взятих у встановленому порядку на баланс запасів.

4. Нормативи плати за користування надрами для видобування корисних копалин

4.1. Нормативи плати за користування надрами для видобування корисних копалин встановлюються для кожного виду корисних копалин (групи корисних копалин, близьких за призначенням) як базові з подальшою їх диференціацією залежно від геологічних особливостей та умов експлуатації родовищ. Базові нормативи плати за видобування корисних копалин встановлюються:

для вугілля кам'яного, вугілля бурого, металевих корисних копалин, сировини нерудної для металургії, гірничо-хімічної, гірничо-рудної та будівельної сировини - як фіксована сума відрахувань у гривнях за одиницю погашених в надрах запасів корисних копалин;

для нафти, конденсату, газу природного, підземних вод (мінеральних, термальних, промислових), ропи, мінеральних грязей та мулу - як фіксована сума відрахувань у гривнях за одиницю видобутих корисних копалин;

для урану, сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння), виробної (виробне каміння) та для облицьовувальних матеріалів - як частка (відсоток) вартості видобутих (погашених в надрах запасів) корисних копалин.

Базові нормативи плати за користування надрами для видобування корисних копалин наведені у додатку до постанови Кабінету Міністрів України від 12 вересня 1997 року N 1014 ( 1014-97-п ) "Про затвердження базових нормативів плати за користування надрами для видобування корисних копалин та Порядку справляння плати за користування надрами для видобування корисних копалин".

Розрахована за базовими нормативами плата за користування надрами для видобування корисних копалин є мінімальною величиною, яку надрокористувачі сплачують незалежно від геологічних особливостей родовищ та умов їх експлуатації.

4.2. Базові нормативи плати можуть переглядатися у разі зміни умов господарювання (оподаткування, кон'юнктура ринку, інфляція) та в результаті вичерпання запасів надр. Перегляд базових нормативів плати та коефіцієнтів до них здійснюється Кабінетом Міністрів України за поданням Мінекобезпеки, Держкомгеології, Мінекономіки та Мінфіну.

4.3. На період до 2000 року до базових нормативів плати за користування надрами для видобування залізної руди багатої, залізної руди для збагачення, доломіту, флюсового вапняку, вапняків для цукрової промисловості застосовується коефіцієнт 0,2, а для решти корисних копалин (крім нафти, конденсату, газу природного, вугілля кам'яного, вугілля бурого) - коефіцієнт 0,3.

До базових нормативів плати за користування надрами для видобування нафти, конденсату, газу природного, вугілля кам'яного, вугілля бурого коефіцієнти не встановлюються.

4.4. При розробці техногенних родовищ до нормативів плати, встановлених для відповідних видів корисних копалин, застосовується коефіцієнт 0,5.

4.5. При видобуванні піщано-гравійної сировини в акваторіях морів, водосховищ, у річках та їх заплавах до встановлених нормативів плати застосовується коефіцієнт 2,0 (крім видобування, пов'язаного з очищенням фарватерів річок, за звітністю про відповідні роботи, виконані спеціалізованими організаціями - ДП "Укрводшлях" та ін.).

4.6. Нормативи плати за користування надрами для видобування торфу, сировини для виготовлення оптичної та п'єзооптичної продукції, залізної руди багатої підземного видобутку у Кривбасі (Дніпропетровська область) не встановлюються, і плата, відповідно, не справляється.

5. Порядок обчислення платежів за користування надрами для видобування корисних копалин

5.1. Розмір платежів за користування надрами для видобування корисних копалин визначається надрокористувачами самостійно і обчислюється:

для вугілля кам'яного, вугілля бурого, металевих корисних копалин, сировини нерудної для металургії, гірничо-хімічної, гірничорудної та будівельної сировини - виходячи з обсягів погашених у надрах балансових та позабалансових запасів корисних копалин та нормативів плати до одиниці погашення в надрах запасів корисних копалин;

для нафти, конденсату, газу природного, підземних вод (мінеральних, термальних, промислових), ропи, мінеральних грязей та мулу - виходячи з обсягів видобутих корисних копалин та нормативів плати до одиниці видобутку корисних копалин;

для урану, сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння), виробної (виробне каміння) та для облицьовувальних матеріалів - виходячи з вартості мінеральної сировини чи продукції її первинної переробки та нормативів плати.

5.2. В разі встановлення квот (лімітів) на видобуток окремих видів корисних копалин в межах конкретних родовищ і окремих їх ділянок на обумовлений термін з визначенням граничного обсягу видобутку, розмір платежів за користування надрами для видобування корисних копалин обчислюється з їх урахуванням. Порядок встановлення квот (лімітів) визначається постановою Кабінету Міністрів України від 22 грудня 1994 року N 862 ( 862-94-п ) "Про затвердження Положення про порядок установлення квот на видобуток окремих видів корисних копалин".

5.3. Обсяги погашених балансових та позабалансових запасів, обсяги видобутку корисних копалин визначаються за даними державної статистичної звітності та геолого-маркшейдерською документацією.

Відповідними формами державної статистичної звітності є:

"Зведений баланс запасів корисних копалин" (форма 5-гр (металеві, неметалеві корисні копалини, вугілля), форма 6-гр (нафта, газ, конденсат), форма 7-гр (підземні води), форма 8-гр (техногенні корисні копалини));

"Звіт про втрати корисних копалин при видобутку" (форма 70-ТП), "Звіт про втрати вугілля в надрах (підземні та відкриті роботи)" (форма 11-шрп);

"Звіт про комплексне використання корисних копалин при збагаченні та металургійному переділі, розкривних порід і відходів виробництва" (форма 71-ТП).

Обсяги щоквартального погашення запасів корисних копалин приймаються за оперативними обмірами чи підрахунками маркшейдерської (геологічної) служби підприємств-надрокористувачів з уточненням за підсумками року.

5.4. Обчислення плати за користування надрами для видобування корисних копалин, виходячи з обсягів погашених балансових запасів, здійснюється відповідно до прикладу 1 (додаток 2), з обсягу видобутих корисних копалин - відповідно до прикладу 2 (додаток 2).

Обчислення плати за користування надрами для видобування урану, сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння), виробної (виробне каміння) та для облицьовувальних матеріалів здійснюється за окремою методикою (додаток 1) відповідно до прикладів 8, 9, 10, 11 (додаток 2).

5.5. За обсяги наднормативних втрат корисних копалин у надрах при їх видобуванні, а також за обсяги видобування понад встановлені квоти (ліміти), плата справляється в подвійному розмірі.

Нормативи втрат корисних копалин в процесі видобутку встановлюються для кожного родовища під час затвердження запасів Державною комісією України по запасах корисних копалин, у проектах розробки родовищ (чи їх ділянок), а також щорічними планами гірничих робіт.

Нормативи втрат погоджуються у встановленому порядку з органами державного гірничого нагляду.

Для надрокористувачів, що здійснюють видобування нафти, конденсату та природного газу, наднормативними втратами вважаються обсяги витрачання нафти, конденсату та природного газу понад розрахункові (планові) власні технологічні потреби. Останні визначаються проектами та поточними планами розробки родовищ.

Наявність наднормативних втрат, в тому числі за рахунок неправильного проведення гірничих робіт, визначається за підсумками року. Плата за наднормативні втрати обчислюється по закінченні року за даними статистичної звітності форми 70-ТП. Обчислення плати здійснюється відповідно до прикладу 3, а щодо нафти, конденсату і природного газу - відповідно до прикладу 4 (додаток 2).

Видобуток корисних копалин понад встановлені квоти (ліміти) визначається і, відповідно, плата обчислюється по закінченні року.

Розрахунок плати здійснюється відповідно до прикладів 5 і 6 (додаток 2).

5.6. При розробці позабалансових запасів корисних копалин плата за відповідні обсяги погашення запасів визначається як при розробці балансових запасів корисних копалин і справляється з коефіцієнтом 0,5.

Розрахунок плати за користування надрами при розробці забалансових запасів здійснюється відповідно до прикладу 7 (додаток 2).

5.7. При розробці користувачем надр більше одного виду корисних копалин плата обчислюється за кожний вид окремо.

Конкретний перелік корисних копалин для комбінованих та комплексних родовищ визначається ліцензіями (ліцензійними угодами) чи іншими відповідними документами на право користування надрами. Плата обчислюється за кожний зазначений ліцензією (ліцензійною угодою) вид корисних копалин.

5.8. При користуванні надрами для видобування титанової руди плата встановлюється для розсипних родовищ іршанської групи (Житомирська область).

5.9. При користуванні надрами для видобування сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння) плата обчислюється, виходячи з вартості відповідного каміння в необробленому вигляді, що одержується в результаті сукупності процесів вилучення каміння з гірських порід, його сортування, розділу, первинного контролю якості.

Щодо сировини виробної (виробне каміння) плата обчислюється, виходячи з вартості блоків-заготовок, що одержуються в результаті вибірки з гірської маси, первинної обробки та сортування.

5.10. При користуванні надрами для видобування сировини для облицьовувальних матеріалів плата обчислюється, виходячи із вартості блочної продукції. Блочною продукцією вважаються блоки колоті, пиляні, розсортовані за розмірами та якістю, що відповідають вимогам відповідного державного стандарту.

5.11. Якщо нафта, конденсат та природний газ видобуваються понад базові обсяги (рівні) плата за відповідні обсяги їх видобування справляється з коефіцієнтом 0,5.

Перелік родовищ, щодо яких встановлюються базові обсяги (рівні) видобування затверджується Кабінетом Міністрів України.

Розрахунок плати при встановленні базових обсягів видобування здійснюється відповідно до прикладу 2 (додаток 2).

5.12. До платежів за користування надрами може застосовуватись знижка за вичерпання запасів надр.

Знижка надається надрокористувачам, які здійснюють видобування:

дефіцитних корисних копалин при низькій економічній ефективності розробки родовищ, об'єктивно обумовленій і не пов'язаній з порушенням умов раціонального використання розвіданих запасів;

корисних копалин із залишкових запасів зниженої якості, а також важковидобувних запасів, крім випадків погіршення якості запасів корисних копалин в результаті вибіркового відпрацювання родовища.

Знижка за вичерпання запасів надр надається Кабінетом Міністрів України за поданням органу, що видав ліцензію, погодженим з Мінекономіки, Мінфіном, органами державного гірничого нагляду та Мінекобезпеки на підставі техніко-економічних обгрунтувань, наданих надрокористувачем.

6. Порядок справляння платежів за користування надрами для видобування корисних копалин

6.1. Плата за користування надрами для видобування корисних копалин обчислюється щоквартально за наростаючим підсумком з початку року.

Надрокористувачі обчислюють повну суму плати після закінчення першого кварталу, півріччя, 9 місяців і року наростаючим підсумком з початку року, виходячи з фактичного обсягу погашених в надрах запасів, обсягу видобутку або вартості видобутої мінеральної сировини чи продукції її первинної переробки.

6.2. Надрокористувачі - платники щоквартально складають розрахунки за встановленими формами (додатки 3, 4, 5) та подають їх державним податковим органам за місцезнаходженням родовища корисних копалин не пізніше 25 числа місяця, наступного за звітним кварталом, та 15 лютого року, що наступає за звітним.

При розробці надрокористувачем більше одного виду корисних копалин форми розрахунку плати подаються за кожен вид корисних копалин окремо.

6.3. Суб'єкт підприємницької діяльності, зареєстрований у податковій адміністрації іншого району (міста), ніж місцезнаходження родовища корисних копалин, додатково до 30 числа місяця, наступного за звітним кварталом, подає копію розрахунку у податкову адміністрацію, де він зареєстрований, з відміткою податкової адміністрації, яка прийняла оригінал розрахунку і копію платіжного документа.

6.4. Сплата платежу за користування надрами для видобування корисних копалин проводиться платниками щоквартально не пізніше 20 числа місяця, наступного за звітним кварталом.

6.5. Підприємство, що сплачує платежі за користування надрами за включені до його складу гірничовидобувні підрозділи (шахти, рудники, кар'єри тощо), в тому числі при експлуатації декількох родовищ, складає розрахунки плати в розрізі цих підрозділів (родовищ).

Розрахунок плати здійснюється відповідно до прикладу 3 (додаток 2).

6.6. Платежі за користування надрами для видобування корисних копалин загальнодержавного значення перераховуються платниками в розмірі 40 відсотків до державного бюджету і 60 відсотків - до бюджетів Автономної Республіки Крим, областей, міст Києва і Севастополя за місцезнаходженням родовища корисних копалин на розділ 16 Класифікації доходів і видатків Державного та місцевих бюджетів України, затвердженої наказом Міністерства фінансів України від 20 травня 1993 року N 28 ( v0028201-93 ). Символ звітності банку державного бюджету - 53.

Платежі за користування надрами для видобування корисних копалин місцевого значення перераховуються платником до бюджетів Автономної Республіки Крим, областей, міст Києва і Севастополя за місцезнаходженням родовища корисних копалин у розмірі 100 відсотків на розділ 16 Класифікації доходів і видатків державного і місцевих бюджетів. Перелік корисних копалин місцевого значення наведено в додатку 6 до Інструкції.

Платежі за користування надрами для видобування корисних копалин, що надходять до бюджетів Автономної Республіки Крим, областей, міст Києва і Севастополя, розподіляються між місцевими бюджетами різних рівнів відповідно Верховною Радою Автономної Республіки Крим, обласними, Київською і Севастопольською міськими Радами.

6.7. Плата за користування надрами для видобування корисних копалин за обсяги видобутих корисних копалин та обсяги втрат у надрах, що не перевищують нормативні, відноситься до валових витрат виробництва та обігу.

Плата за обсяги наднормативних втрат корисних копалин, а також за обсяги їх видобування понад встановлені квоти (ліміти), справляється з прибутку, що залишається у розпорядженні підприємств.

7. Звільнення від плати за користування надрами для видобування корисних копалин

Від плати за користування надрами для видобування корисних копалин звільняються землевласники і землекористувачі, які здійснюють у встановленому порядку видобування корисних копалин місцевого значення для власних потреб (тобто без реалізації видобутої мінеральної сировини чи продукції її первинної переробки) або користування надрами для господарських і побутових потреб на наданих їм у власність чи користування земельних ділянках.

8. Контроль за визначенням обсягів видобутку та погашення

балансових та позабалансових запасів корисних копалин,

станом їх обліку, правильністю обчислення та своєчасністю

сплати платежів за користування надрами для видобування корисних копалин

8.1. Контроль за дотриманням умов користування надрами здійснюється органами державного гірничого нагляду та державного геологічного контролю у встановленому порядку.

8.2. Контроль за правильністю визначення обсягів видобутку та погашення балансових і позабалансових запасів корисних копалин здійснюється органами державного гірничого нагляду у встановленому порядку.

8.3. Органи державного гірничого нагляду у місячний термін надсилають державним податковим органам в Автономній Республіці Крим, областях, містах Києві і Севастополі за місцезнаходженням родовищ корисних копалин, які передбачається розробляти, повідомлення про надання дозволів на початок ведення гірничих робіт за формою, наведеною у додатку 7. Форма повідомлення заповнюється надрокористувачами самостійно.

8.4. Контроль за правильністю обчислення, своєчасністю сплати до бюджетів платежів за користування надрами для видобування корисних копалин здійснюється державними податковими органами за місцезнаходженням родовища корисних копалин.

8.5. Документальна перевірка правильності обчислення і своєчасності перерахування до відповідних бюджетів платежів за користування надрами для видобування корисних копалин здійснюється державними податковими органами за місцезнаходженням родовища корисних копалин.

До перевірок, при необхідності, залучаються органи Держкомгеології, Мінекобезпеки та державного гірничого нагляду.

8.6. Облік нарахованих і сплачених сум платежів за користування надрами для видобування корисних копалин ведеться державними податковими органами відповідно до встановленого порядку ведення оперативно-бухгалтерського обліку.

8.7. Повернення та зарахування неправильно сплачених сум платежів за користування надрами для видобування корисних копалин проводиться із відповідних бюджетів згідно із чинним законодавством України.

9. Відповідальність і права платників

9.1. Платники платежів за користування надрами для видобування корисних копалин несуть відповідальність за правильність обчислення і своєчасність сплати платежів до бюджетів, а також за правильність складання і своєчасність подання розрахунків державним податковим адміністраціям відповідно до чинного законодавства України.

9.2. Суми платежів за користування надрами для видобування корисних копалин, що не були внесені у встановлений термін, сплачуються до бюджетів з нарахуванням пені відповідно до чинного законодавства України.

9.3. Платники мають право оскаржити дії посадових осіб державних податкових адміністрацій у порядку, встановленому чинним законодавством України.

Тимчасова методика розрахунку платежів за користування надрами для видобування урану, сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння), виробної (виробне каміння) та для облицьовувальних матеріалів

Методика розроблена у відповідності з постановою Кабінету Міністрів України від 12 вересня 1997 року N 1014 ( 1014-97-п ) "Про затвердження базових нормативів плати за користування надрами для видобування корисних копалин та Порядку справляння плати за користування надрами для видобування корисних копалин".

Методика визначає єдиний порядок розрахунку платежів за користування надрами для видобування урану, сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння), виробної (виробне каміння) та облицьовувальних матеріалів, виходячи з вартості мінеральної сировини чи продукції її первинної переробки.

1. Розрахунок плати здійснюється на основі показників вартості видобутої мінеральної сировини чи продукції її первинної переробки, нормативів плати та поправочного коефіцієнта (для облицьовувальних матеріалів і урану).

Вартість видобутої мінеральної сировини чи продукції її первинної переробки визначається як доход, одержаний від її реалізації (без урахування податку на додану вартість).

Поправочний коефіцієнт виступає як показник повноти використання запасів корисних копалин при їх видобуванні.

2. Плата за користування надрами - П (грн.) для видобування сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння) та виробної (виробне каміння) визначається за формулою:

П = Д х Н/100% х Кп, грн., (1)

де: Д - доход, отриманий (нарахований) протягом звітного періоду від реалізації видобутої мінеральної сировини чи продукції її первинної переробки (окремо по даному виду діяльності), грн.;

Н - норматив плати, %;

Кп - понижувальний коефіцієнт, визначений постановою Кабінету Міністрів України від 12.09.1997 р. N 1014.

Розрахунок плати для даного випадку здійснюється відповідно до прикладу 8 (додаток 2 до Інструкції).

3. Плата за користування надрами П (грн.) для видобування урану та облицьовувальних матеріалів визначається за формулою:

П = Д х Н/100% х Кз х Кп, грн., (2)

де Кз - поправочний коефіцієнт на погашення запасів корисних копалин.

4. Поправочний коефіцієнт на погашення запасів розраховується:

а) для урану за формулою:

Кз = Vпог / Vвид, (3)

де: Vпог - обсяг фактично погашених в надрах запасів корисних копалин, т;

Vвид - обсяг видобутих корисних копалин, т.

Розрахунок плати за користування надрами для видобування урану здійснюється відповідно до прикладу 9 (додаток 2 до Інструкції).

б) для облицьовувальних матеріалів за формулою:

Кз = Vпог / Обл х Dбл / 100%, (4)

де: Vпог - обсяг погашених в надрах запасів корисних копалин, куб.м;

Обл - обсяг видобутих блоків, куб.м;

Dбл - вихід блоків із 1 куб.м гірничої маси, %.

Вихід блоків із 1 куб.м гірничої маси визначається планами розвитку гірничих робіт.

Розрахунок плати за користування надрами для видобування облицьовувальних матеріалів здійснюється відповідно до прикладу 10 (додаток 2 до Інструкції).

5. Якщо надрокористувач частково реалізує або частково (чи повністю) направляє одержану продукцію первинної переробки мінеральної сировини (блоків, необробленого дорогоцінного каміння тощо) на власний виробничий підрозділ для її подальшої переробки, плата за користування надрами визначається за формулами (1) або (2), в яких показник доходу розраховується за формулою:

Д = Дф + Дрозр, грн., (5)

де: Дф - доход, отриманий (нарахований) від реалізації частини продукції первинної переробки мінеральної сировини, грн.;

Дрозр - доход, нарахований на частину продукції первинної переробки мінеральної сировини, передану на подальшу переробку, грн.;

Дрозр = О х Ц, грн., (6)

де: О - обсяг продукції первинної переробки мінеральної сировини, переданої на подальшу переробку, т, куб.м, кг, г;

Ц - ціна зазначеної продукції первинної переробки, грн./т, грн./куб.м, грн./кг, грн./г.

Рівень цін визначається підприємствами самостійно, виходячи із середньозважених цін реалізації аналогічної продукції первинної переробки (блоків, необробленого дорогоцінного та напівдорогоцінного каміння, блоків-заготовок виробного каміння), якщо вона здійснюється у звітному періоді, а при відсутності такої реалізації - виходячи із середньозважених цін у попередньому до звітного періоді.

У разі відсутності реалізації продукції первинної переробки на даному підприємстві у звітному (попередньому до звітного) періоді ціна визначається за іншими обгрунтуваннями цін на аналогічну продукцію (цінниками, офіційними бюлетенями тощо) на кінець звітного періоду.

Розрахунок плати за користування надрами щодо такого випадку здійснюється відповідно до прикладу 11 (додаток 2 до Інструкції).

6. Якщо податкові органи за результатами документальної перевірки мають підстави для висновків щодо правомірності встановлення рівня цін платником, ці органи мають право звернутися із запитом, а платник-надрокористувач зобов'язаний за таким запитом надати обгрунтування рівня таких цін.

Гірничовидобувне підприємство веде розробку родовища залізної руди для збагачення. Обсяг погашених у надрах балансових запасів з початку року (за I і II квартали) склав 5200 тис.т. Плата за користування надрами для видобування залізної руди: 5200 тис.т х 0,32 грн./т х 0,2 = 332,8 тис.грн.

Приклад 3

Гірничовидобувне підприємство веде розробку родовища марганцевої руди. У його складі знаходяться два гірничовидобувні підрозділи (цехи) - шахта і кар'єр.

а) На шахті обсяг погашених у надрах балансових запасів за звітний рік склав 500 тис.т.

Наднормативні втрати корисних копалин у надрах дорівнюють 11,0 тис.т (за формою 70-ТП).

Базовий норматив плати до одиниці погашених у надрах запасів - 0,58 грн./т.

Понижувальний коефіцієнт до нормативу плати (для марганцевої руди) - 0,3.

Плата за користування надрами без урахування додаткової плати за наднормативні втрати руди: 500 тис.т х 0,58 грн./т х 0,3 = 87 тис.грн.

Плата за наднормативні втрати руди у надрах: 11,0 тис.т х 0,58 грн./т х 0,3 = 1,914 тис.грн.

Сумарний обсяг плати за користування надрами по шахті: 87,0 тис.грн. + 1,914 тис.грн. = 88,914 тис.грн.

В тому числі з прибутку, що залишається у розпорядженні підприємства, має стягуватись 3,828 тис.грн. (1,914 х 2,0).

б) На кар'єрі обсяг погашених балансових запасів дорівнює 620 тис.тонн. Наднормативні втрати відсутні.

Плата за користування надрами для видобування марганцевої руди: 620 тис.т х 0,58 грн./т х 0,3 = 107,88 тис.грн.

в) В цілому по підприємству плата за користування надрами складає:

88,914 тис.грн. + 107,88 тис.грн = 196,794 тис.грн.

Нараховано за попередній період - 90,0 тис.грн.

Підлягає сплаті за звітний період - 106,794 тис.грн. (196,794 - 90,0).

В тому числі підлягає стягненню з прибутку, що залишається у розпорядженні підприємства, 3,828 тис.грн.
