Кабінет Міністрів України; Розпорядження від 20.05.1994 № 365-р

Про передачу адміністративного житлового фонду

Стан: Втратив чинність

Ідентифікатор: 365-94-р

Текст документа від 31.12.1994:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 травня 1994 р. N 365-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 970-р ( 970-94-р ) від 31.12.94 )

1. У зв'язку з передачею адміністративного будинку по вул. Садовій, 3, у м. Києві для потреб Верховної Ради України надати Мінекономіки для розміщення його підрозділів, що займають приміщення на шостому поверсі цього будинку, службові приміщення на першому поверсі в будинку Уряду по вул. М. Грушевського, 12/2, робочею площею 556 кв. метрів (кімнати 101-125).

Держкомресурсів в місячний термін звільнити всі займані приміщення на першому і в цокольному поверхах будинку по вул. М. Грушевського, 12/2.

2. Розмістити центральний апарат Держкомресурсів у будинку в Музейному провулку, 10, 12 та інших адміністративних будинках, що належать цьому Комітетові.
