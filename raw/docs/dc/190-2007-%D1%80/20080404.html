{ Розпорядження скасовано на підставі Розпорядження КМ N 350-р ( 350-2008-р ) від 27.02.2008 }

Про передачу будинку на Контрактовій площі, 4, у м. Києві (Гостинного двору)

Прийняти пропозицію Держінвестицій, погоджену з Фондом державного майна, щодо передачі будинку на Контрактовій площі, 4, у м. Києві (Гостинного двору) до сфери управління Держінвестицій для розміщення центрального апарату Агентства.

Фонду державного майна відповідно до Декрету Кабінету Міністрів України від 11 січня 1993 р. N 5-93 ( 5-93 ) "Про впорядкування використання адміністративних будинків і нежилих приміщень, що перебувають у державній власності" забезпечити розірвання договору оренди зазначеного будинку та вивільнення орендарем його приміщень.

Прем'єр-міністр України В.ЯНУКОВИЧ
