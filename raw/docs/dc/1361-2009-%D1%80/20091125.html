Кабінет Міністрів України; Розпорядження від 11.11.2009 № 1361-р

Деякі питання проведення конверсії смуг радіочастот

Стан: Чинний

Ідентифікатор: 1361-2009-р

Текст документа від 25.11.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 листопада 2009 р. N 1361-р Київ

Деякі питання проведення конверсії смуг радіочастот

{ Із змінами, внесеними згідно з Указом Президента N 967/2009 ( 967/2009 ) від 25.11.2009 }

{ Дію пункту 1 зупинено згідно з Указом Президента N 967/2009 ( 967/2009 ) від 25.11.2009 }

1. Міноборони, Мінтрансзв'язку, НКРЗ з урахуванням висновків міжвідомчої комісії з обґрунтування обсягів та витрат, пов'язаних з проведенням конверсії радіочастотного ресурсу, провести конверсію смуг радіочастот 1920-1935 МГц, 1950-1980 МГц, 2010-2015 МГц, 2020-2025 МГц, 2110-2125 МГц, 2140-2170 МГц для запровадження системи мобільного зв'язку третього покоління стандарту IMT-2000 (UMTS) шляхом зміни частотних присвоєнь радіоелектронних засобів спеціальних користувачів, які працюють у зазначених смугах радіочастот, і переведення їх поза такі смуги радіочастот в межах асигнувань, виділених для утримання зазначених центральних органів виконавчої влади.

{ Дію пункту 2 зупинено згідно з Указом Президента N 967/2009 ( 967/2009 ) від 25.11.2009 }

2. НКРЗ забезпечити проведення тендерів (відкритих аукціонів) на видачу ліцензії на користування радіочастотним ресурсом у смугах радіочастот 1920-1935 МГц, 1950-1980 МГц, 2010-2015 МГц, 2020-2025 МГц, 2110-2125 МГц, 2140-2170 МГц для впровадження радіотехнології "Цифровий стільниковий радіозв'язок IMT-2000 (UMTS)".

{ Дію пункту 3 зупинено згідно з Указом Президента N 967/2009 ( 967/2009 ) від 25.11.2009 }

3. Мінфіну під час доопрацювання проекту Закону України "Про Державний бюджет України на 2010 рік" та розроблення проекту Закону про Державний бюджет України на 2011 рік передбачити асигнування Міноборони для забезпечення переозброєння Збройних Сил засобами радіорелейного зв'язку та радіолокації у сумі 941,334 млн. гривень за рахунок коштів, отриманих за видачу ліцензій на користування радіочастотним ресурсом України для впровадження радіотехнології "Цифровий стільниковий радіозв'язок IMT-2000 (UMTS)".

Фінансування заходів, пов'язаних з переозброєнням спеціальних користувачів радіочастотного ресурсу засобами радіорелейного зв'язку та радіолокації протягом 2012-2014 років у розмірі 1568,286 млн. гривень, передбачати за рахунок видатків на закупівлю та модернізацію озброєння та військової техніки.

4. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 16 вересня 2009 р. N 1119 ( 1119-2009-р ) "Деякі питання проведення конверсії смуг радіочастот".
