Текст документа від 11.05.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 травня 2011 р. N 534 Київ

Про внесення змін до постанов Кабінету Міністрів України від 30 червня 2005 р. N 510 і від 9 березня 2006 р. N 268

{ Із змінами, внесеними згідно з Постановою КМ N 323 ( 323-2016-п ) від 05.05.2016 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України такі зміни:

{ Абзац другий постановляючої частини втратив чинність стосовно працівників, розміри посадових окладів яких затверджені Постановою КМ N 323 від 5 травня 2016 р., на підставі Постанови КМ N 323 ( 323-2016-п ) від 05.05.2016 }

у пункті 1 постанови Кабінету Міністрів України від 30 червня 2005 р. N 510 ( 510-2005-п ) "Про оплату праці керівних працівників державних органів" (Офіційний вісник України, 2005 р., N 27, ст. 1545, N 35, ст. 2118, N 44, ст. 2772, N 50, ст. 3119; 2006 р., N 5, ст. 230, N 15, ст. 1083, N 22, ст. 1655; 2007 р., N 1, ст. 28, ст. 29, N 78, ст. 2892; 2008 р., N 35, ст. 1179, N 47, ст. 1530; 2010 р., N 27, ст. 1063, N 92, ст. 3273, N 98, ст. 3490; 2011 р., N 28, ст. 1179, ст. 1193, N 30, ст. 1297) графу "Найменування посади" після слів "Постійний Представник Президента України в Автономній Республіці Крим" доповнити словами ", Радник Президента України, Радник Президента України - Керівник Головного управління Адміністрації Президента України";

у додатку 1 до постанови Кабінету Міністрів України від 9 березня 2006 р. N 268 ( 268-2006-п ) "Про упорядкування структури та умов оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" (Офіційний вісник України, 2006 р., N 10, ст. 632; 2010 р., N 27, ст. 1063) у графі "Найменування посади" слова ", радник Президента України" виключити.
