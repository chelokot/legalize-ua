Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов

Стан: Чинний

Ідентифікатор: 1047-2009-р

Текст документа від 21.10.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 вересня 2009 р. N 1047-р Київ

Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1081-р ( 1081-2009-р ) від 09.09.2009 N 1176-р ( 1176-2009-р ) від 23.09.2009 N 1401-р ( 1401-2009-р ) від 21.10.2009 }

1. Погодитися з пропозицією Мінрегіонбуду щодо придбання Державною іпотечною установою квартир за переліком згідно з додатком на загальну суму 192 862,472 тис. гривень в житлових будинках, прийнятих в експлуатацію, та на об'єктах незавершеного житлового будівництва із строком здачі в експлуатацію не пізніше ніж 25 грудня 2009 р. за наявності відповідної банківської гарантії або іншого виду забезпечення виконання зобов'язань забудовників, що прийматимуться Державною іпотечною установою, або наявності графіка виконання будівельно-монтажних робіт, погодженого з керівником інспекції державного архітектурно-будівельного контролю в Автономній Республіці Крим, областях, мм. Києві та Севастополі, для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов та перебувають на квартирному обліку.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 1401-р ( 1401-2009-р ) від 21.10.2009 }

2. Державній іпотечній установі передати квартири, придбані відповідно до пункту 1 цього розпорядження, головним розпорядникам бюджетних коштів за розподілом Мінпраці, погодженим з Мінсім'ямолодьспортом та Мінфіном.

3. Внести до розпорядження Кабінету Міністрів України від 26 серпня 2009 р. N 1000 ( 1000-2009-р ) "Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов" такі зміни:

1) у пункті 1 цифри "153 229,705" замінити цифрами "153299,905";

2) у додатку до розпорядження:

у позиції "м. Балаклія Харківської області, вул. Куйбишева, 2б, "9-поверховий 213-квартирний житловий будинок блок-секції 1,2,3,4" цифри "9046,8" і "35282,52" замінити відповідно цифрами "9064,8" і "35352,72";

у позиції "Усього" цифри "37949,57" і "153229,705" замінити відповідно цифрами "37967,57" і "153299,905".

4. Головним розпорядникам бюджетних коштів разом з Мінфіном під час уточнення показників Державного бюджету України на 2009 рік та складання проектів державного бюджету на наступні роки передбачати кошти для компенсації Державній іпотечній установі витрат, пов'язаних з придбанням квартир відповідно до пункту 1 цього розпорядження.
