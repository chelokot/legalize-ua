Про розрахунок з постачальниками цукрової сировини

Стан: Втратив чинність

Ідентифікатор: 829-96-р

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 грудня 1996 р. N 829-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Прийняти пропозицію Мінсільгосппроду і Держхарчопрому про здійснення господарською асоціацією "Харківцукор" в порядку експерименту остаточних розрахунків з постачальниками цукрової сировини після завершення збирання та переробки цукрових буряків виходячи з фактичної частки витрат цукрових заводів у загальних витратах на виробництво цукру.
