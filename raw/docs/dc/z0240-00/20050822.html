{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 86/5 ( z0882-05 ) від 09.08.2005 }

Про внесення змін до наказу Міністра юстиції України від 15.07.97 N 285/7-А "Про експертно-кваліфікаційні комісії та атестацію судових експертів"

З метою вдосконалення роботи Центральної експертно-кваліфікаційної комісії при Міністерстві юстиції України та на підставі наказу Міністерства юстиції України від 05.04.2000 N 249/7 "Про розподіл функціональних повноважень керівництва Міністерства юстиції України" НАКАЗУЮ:

1. Внести такі зміни до наказу Міністра юстиції України від 15.07.97 N 285/7-А ( z0283-97 ) "Про експертно-кваліфікаційні комісії та атестацію судових експертів":

1.1. Абзац другий пункту першого наказу викласти в такій редакції:

"Матеріально-технічне, фінансове та інформаційне забезпечення Центральної експертно-кваліфікаційної комісії покласти на науково-дослідні інститути судових експертиз Міністерства юстиції України".

1.2. Додаток N 1 до наказу викласти в такій редакції:

"Додаток 1 до наказу Міністра юстиції України від 15.07.97 N 285/7-А ( z0283-97 ) (в редакції наказу від 18.04.2000 N 11/5а)

1.3. Доповнити Перелік основних видів судових експертиз та експертних спеціальностей, по який присвоюються кваліфікація судового експерта фахівцям науково-дослідних інститутів судових експертиз Міністерства юстиції України, наведений у додатку N 4 до Положення про експертно-кваліфікаційні комісії та атестацію судових експертів, затвердженого наказом Міністра юстиції України від 15.07.97 N 285/7-А ( z0283-97 ), після розділу VII розділом VIII такого змісту:

"VIII

14. "Психологічна експертиза 14.1. Психологічні дослідження"

У зв'язку з цим розділ VIII та рядок 14 вважати розділом IX та рядком 15.

1.4. Додаток N 5 до Положення про експертно-кваліфікаційні комісії та атестацію судових експертів, затвердженого наказом Міністра юстиції України від 15.07.97 N 285/7-А ( z0283-97 ), викласти в такій редакції:

"Додаток 5 до Положення про експертно-кваліфікаційні комісії та атестацію судових експертів, затвердженого наказом Міністра юстиції України від 15.07.97 N 285/7-А ( z0283-97 ) (в редакції наказу від 18.04.2000 N 11/5а)
