Кабінет Міністрів України; Постанова від 14.03.2007 № 448

Про доповнення Порядку використання коштів, передбачених у державному бюджеті для реструктуризації вугільної та торфодобувної промисловості

Стан: Втратив чинність

Ідентифікатор: 448-2007-п

Текст документа від 02.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 березня 2007 р. N 448 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 375 ( 375-2010-п ) від 19.05.2010 }

Про доповнення Порядку використання коштів, передбачених у державному бюджеті для реструктуризації вугільної та торфодобувної промисловості

Кабінет Міністрів України постановляє:

У Порядку використання коштів, передбачених у державному бюджеті для реструктуризації вугільної та торфодобувної промисловості, затвердженому постановою Кабінету Міністрів України від 18 серпня 2005 р. N 749 ( 749-2005-п ) (Офіційний вісник України, 2005 р., N 34, ст. 2032), доповнити:

пункт 2 абзацом такого змісту:

"виконання ремонтно-відновлювальних робіт на підприємствах з видобування бурого вугілля.";

пункт 3 словами ", а також для виконання ремонтно-відновлювальних робіт на підприємствах з видобування бурого вугілля.";

пункт 4 абзацом такого змісту:

"Обсяги та напрями використання бюджетних коштів для виконання ремонтно-відновлювальних робіт на підприємствах з видобування бурого вугілля визначаються згідно з кошторисом витрат і переліком робіт, затвердженими головним розпорядником на підставі поданих підприємствами-замовниками матеріалів.".

Прем'єр-міністр України В.ЯНУКОВИЧ
