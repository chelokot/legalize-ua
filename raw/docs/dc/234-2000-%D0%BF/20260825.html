Про збільшення розміру академічної стипендії Президента України для найбільш обдарованих молодих митців

Стан: Втратив чинність

Ідентифікатор: 234-2000-п

Текст документа від 25.08.2026:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 лютого 2000 р. N 234 Київ

{ Постанова втратила чинність на підставі Постанови Кабінету Міністрів України N 1052 ( 1052-2026-п ) від 19.08.2026 }

Про збільшення розміру академічної стипендії Президента України для найбільш обдарованих молодих митців

{ Із змінами, внесеними згідно з Постановами КМ N 882 ( 882-2004-п ) від 12.07.2004 N 1313 ( 1313-2020-п ) від 23.12.2020 }

З метою посилення соціального захисту учнів і студентів Кабінет Міністрів України постановляє:

1. Установити починаючи з 1 липня 2004 р. такі розміри академічних стипендій Президента України для найбільш обдарованих молодих митців:

учнів державних мистецьких ліцеїв - 9,7 відсотка прожиткового мінімуму на одну особу з розрахунку на місяць; { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1313 ( 1313-2020-п ) від 23.12.2020 }

студентів вищих мистецьких навчальних закладів - 4,375 мінімальної академічної стипендії студентів вищих навчальних закладів відповідного рівня акредитації.

{ Пункт 1 в редакції Постанови КМ N 882 ( 882-2004-п ) від 12.07.2004 }

2.Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 29 лютого 1996 р. N 253 ( 253-96-п ) "Про розмір стипендії Президента України для найбільш обдарованих молодих митців України" (ЗП України, 1996 р., N 8, ст. 232);

постанову Кабінету Міністрів України від 2 серпня 1996 р. N 900 ( 900-96-п ) "Про збільшення розміру стипендії Президента України для найбільш обдарованих молодих митців України" ( ЗП України, 1996 р., N 16, ст. 429).
