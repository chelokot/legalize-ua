Кабінет Міністрів України; Розпорядження від 05.09.2007 № 699-р

Про передачу державного підприємства "Культурно-мистецький та музейний комплекс "Мистецький арсенал" в управління Державного управління справами

Стан: Чинний

Ідентифікатор: 699-2007-р

Текст документа від 10.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 вересня 2007 р. N 699-р Київ

Про передачу державного підприємства "Культурно-мистецький та музейний комплекс "Мистецький арсенал" в управління Державного управління справами

{ Із змінами, внесеними згідно з Розпорядженням КМ N 873-р ( 873-2007-р ) від 10.10.2007 }

1. Прийняти пропозицію Державного управління справами та МКТ щодо передачі державного підприємства "Культурно-мистецький та музейний комплекс "Мистецький арсенал" в управління Державного управління справами.

2. Визнати такими, що втратили чинність, пункти 2-4 розпорядження Кабінету Міністрів України від 14 лютого 2007 р. N 44 ( 44-2007-р ) "Деякі питання культурно-мистецького та музейного комплексу "Мистецький арсенал".

3. Взяти до відома, що у 2007 році:

замовником проектних, будівельних та інших робіт із створення культурно-мистецького та музейного комплексу "Мистецький арсенал" визначено державне підприємство "Культурно-мистецький та музейний комплекс "Мистецький арсенал";

виконання зазначених робіт, утримання і експлуатація культурно-мистецького та музейного комплексу "Мистецький арсенал" здійснюється в межах призначень, передбачених МКТ у державному бюджеті ( 489-16 ) за програмою КПКВК 1802040 "Заходи з охорони культурної спадщини, паспортизація, інвентаризація та реставрація пам'яток культурної спадщини".

{ Розпорядження доповнено пунктом 3 згідно з Розпорядженням КМ N 873-р ( 873-2007-р ) від 10.10.2007 }

Прем'єр-міністр України В.ЯНУКОВИЧ
