{ Указ втратив чинність на підставі Указу Президента N 452/2006 ( 452/2006 ) від 29.05.2006 }

Про внесення зміни до Указу Президента України від 18 жовтня 2000 року N 1144

Внести зміну до Переліку посадових осіб органів державної влади, на яких покладається виконання функцій державного експерта з питань таємниць, затвердженого Указом Президента України від 18 жовтня 2000 року N 1144 ( 1144/2000 ) (в редакції Указу від 11 жовтня 2002 року N 917 ( 917/2002 ), доповнивши його після розділу "Рада національної безпеки і оборони України" розділом такого змісту:

"Верховний Суд України

Голова

Перший заступник Голови".

Президент України Л.КУЧМА
