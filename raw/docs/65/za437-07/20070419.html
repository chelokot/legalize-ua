Про внесення змін до постанови правління Пенсійного фонду України від 12 липня 2006 року N 9-3

Відповідно до пункту 12 Положення про Пенсійний фонд України, затвердженого Указом Президента України від 01.03.2001 N 121 ( 121/2001 ) (із змінами), постанови Кабінету Міністрів України від 31.01.2007 N 98 ( 98-2007-п ) "Про продовження строку дії постанов Кабінету Міністрів України від 20 березня 2006 р. N 357 і від 12 квітня 2006 р. N 511" правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Унести до постанови правління Пенсійного фонду України від 12.07.2006 N 9-3 ( za876-06 ) "Про затвердження Порядку обміну інформацією між Державною податковою адміністрацією України, Пенсійним фондом України та Державним центром зайнятості Міністерства праці та соціальної політики України", зареєстрованої в Міністерстві юстиції України 26.07.2006 за N 876/12750, такі зміни:

1.1. У пункті 3 ініціали та прізвище "О.Б.Зарудного" замінити ініціалами та прізвищем "В.Б.Підліснюка".

2. Унести зміни до Порядку обміну інформацією між Державною податковою адміністрацією України, Пенсійним фондом України та Державним центром зайнятості Міністерства праці та соціальної політики України, затвердженого наказом Міністерства праці та соціальної політики України, Державної податкової адміністрації України від 12.07.2006 N 259/407 ( z0876-06 ), постановою правління Пенсійного фонду України від 12.07.2006 N 9-3 ( za876-06 ), зареєстрованого в Міністерстві юстиції України 26.07.2006 за N 876/12750:

2.1. У пунктах 1.2, 2.1 та 2.3 цифри "2006" замінити цифрами "2007".

2.2. У пункті 2.3 цифри "2005" замінити цифрами "2006".

3. Юридичному управлінню (Рябцева Т.Б.) подати цю постанову для державної реєстрації до Міністерства юстиції України.

4. Контроль за виконанням цієї постанови покласти на заступника Голови правління В.Б.Підліснюка.
