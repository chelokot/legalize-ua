Текст документа від 21.09.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 жовтня 1997 р. N 1106 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1145 ( 1145-98-п ) від 27.07.98 )

Про перелік товарів критичного імпорту, ввезення яких здійснюється без сплати податку на додану вартість

( Із змінами, внесеними згідно з Постановами КМ N 1464 ( 1464-97-п ) від 24.12.97 N 307 ( 307-98-п ) від 17.03.98 N 556 ( 556-98-п ) від 24.04.98 )

Відповідно до статті 11 Закону України "Про податок на додану вартість" ( 168/97-ВР ) Кабінет Міністрів України постановляє:

1. Встановити, що до товарів критичного імпорту, які ввозяться для вітчизняного виробництва (крім їх ввезення на умовах переробки давальницької сировини), відносяться товари, ввезення яких на митну територію України регламентується Указом Президента України від 30 червня 1995 р. N 499 ( 499/95 ) "Про справляння податку на добавлену вартість з імпортних товарів", за винятком товарів, щодо яких не застосовуються пільги, визначені постановами Кабінету Міністрів України від 31 травня 1996 р. N 602 ( 602-96-п ), від 2 серпня 1996 р. N 907 ( 907-96-п ), від 14 серпня 1996 р. N 967 ( 967-96-п ), від 3 вересня 1996 р. N 1034, від 23 вересня 1996 р. N 1165 ( 1165-96-п ), від листопада 1996 р. N 1356 ( 1356-96-п ), від 17 січня 1997 р. N 23 ( 23-97-п ), від 23 січня 1997 р. N 53 ( 53-97-п ), від 28 березня 1997 р. N 282 ( 282-97-п ), від 5 травня 1997 р. N 415 ( 415-97-п ), від 30 травня 1997 р. N 519 ( 519-97-п ), від 12 червня 1997 р. N 577 ( 577-97-п ), від 12 червня 1997 р. N 582 ( 582-97-п ), від 21 серпня 1997 р. N 915 ( 915-97-п ), від 19 вересня 1997 р. N 1037 ( 1037-97-п ) та розпорядженням Кабінету Міністрів України від 12 грудня 1996 р. N 799 ( 799-96-р ), а також сільськогосподарська техніка та запасні частини до неї, закупівля яких здійснюється за рахунок іноземних кредитів під гарантії Кабінету Міністрів України, за кодами ТН ЗЕД 87.01.90.390, 84.32.21.000, 84.32.30.190, 84.24.81.910, 87.08. ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1464 ( 1464-97-п ) від 24.12.97 )

Міністерству економіки разом з Міністерством зовнішніх економічних зв'язків і торгівлі та Державною митною службою в 10-денний термін розробити порядок подання Кабінету Міністрів України галузевими міністерствами, іншими центральними органами виконавчої влади пропозицій щодо внесення змін та доповнень до зазначеного переліку.

( На часткову зміну пункту 1 установлено, що до товарів критичного імпорту, ввезення яких здійснюється без сплати податку на додану вартість, не належать товари, внесені до переліку згідно з додатком згідно з Постановою КМ N 307 ( 307-98-п ) від 17.03.98 )

2. З метою впорядкування і скорочення переліку товарів, з оподаткування імпорту яких надаються пільги, утворити міжвідомчу комісію на чолі з Міністром зовнішніх економічних зв'язків і торгівлі Осикою С.Г., включивши до її складу представників галузевих міністерств та інших центральних органів виконавчої влади, зокрема Міністерства економіки, Міністерства зовнішніх економічних зв'язків і торгівлі, Державної митної служби і Торгово-промислової палати.

3. Ця постанова набирає чинності з дня її опублікування.

( На часткову зміну Постанови КМ віднести до товарів критичного імпорту, ввезення яких здійснюється без сплати податку на додану вартість, товари за кодами ТН ЗЕД 42.02 92 110, 42.02 92 910 (тільки дорожні сумки, рюкзаки і спортивні сумки); 61.09; 61.10; 61.12; 61.16; 62.01 13 900, 62.01 19 000; 63.02; 64.03; 64.04; 65.05 90 900; 65.06; 73.17 00 300, які ввозяться на митну територію України за спонсорськими контрактами фізкультурно-спортивними організаціями для потреб національних збірних та команд майстрів з ігрових видів спорту згідно з Постановою КМ N 556 ( 556-98-п ) від 24.04.98 )
