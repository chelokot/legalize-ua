Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань діяльності колегії Державної податкової адміністрації

Стан: Чинний

Ідентифікатор: 444-2011-п

Текст документа від 27.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 квітня 2011 р. N 444 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань діяльності колегії Державної податкової адміністрації

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, постанови Кабінету Міністрів України з питань діяльності колегії Державної податкової адміністрації згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 27 квітня 2011 р. N 444

ПЕРЕЛІК постанов Кабінету Міністрів України з питань діяльності колегії Державної податкової адміністрації, що втратили чинність

1. Постанова Кабінету Міністрів України від 5 березня 1997 р. N 215 ( 215-97-п ) "Про затвердження колегії Державної податкової адміністрації України".

2. Пункт 2 постанови Кабінету Міністрів України від 30 травня 1997 р. N 518 ( 518-97-п ) "Про підготовку, перепідготовку та підвищення кваліфікації працівників податкової міліції" (Офіційний вісник України, 1997 р., число 22, с. 69).

3. Постанова Кабінету Міністрів України від 16 липня 1997 р. N 775 ( 775-97-п ) "Про затвердження Савченка О.Я. членом колегії Державної податкової адміністрації".

4. Постанова Кабінету Міністрів України від 31 березня 1998 р. N 412 ( 412-98-п ) "Про затвердження Копилова В.А. членом колегії Державної податкової адміністрації України".

5. Постанова Кабінету Міністрів України від 28 липня 1998 р. N 1171 ( 1171-98-п ) "Про колегію Державної податкової адміністрації України".

6. Постанова Кабінету Міністрів України від 31 грудня 1998 р. N 2111 ( 2111-98-п ) "Про затвердження Брезвіна А.І. членом колегії Державної податкової адміністрації України".

7. Постанова Кабінету Міністрів України від 17 березня 1999 р. N 419 ( 419-99-п ) "Про членів колегії Державної податкової адміністрації України".

8. Постанова Кабінету Міністрів України від 1 вересня 1999 р. N 1611 ( 1611-99-п ) "Про затвердження Росоловського В.М. членом колегії Державної податкової адміністрації України".

9. Постанова Кабінету Міністрів України від 23 листопада 1999 р. N 2127 ( 2127-99-п ) "Про затвердження Шнипка О.С. членом колегії Державної податкової адміністрації України".

10. Постанова Кабінету Міністрів України від 13 грудня 1999 р. N 2301 ( 2301-99-п ) "Про затвердження Хорошковського В.І. членом колегії Державної податкової адміністрації".

11. Постанова Кабінету Міністрів України від 27 вересня 2000 р. N 1458 ( 1458-2000-п ) "Про членів колегії Державної податкової адміністрації".

12. Постанова Кабінету Міністрів України від 18 червня 2002 р. N 854 ( 854-2002-п ) "Про колегію Державної податкової адміністрації України" (Офіційний вісник України, 2002 р., N 25, ст. 1212).

13. Постанова Кабінету Міністрів України від 23 вересня 2002 р. N 1404 ( 1404-2002-п ) "Про колегію Державної податкової адміністрації" (Офіційний вісник України, 2002 р., N 39, ст. 1808).
