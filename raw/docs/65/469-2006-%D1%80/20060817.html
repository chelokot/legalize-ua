КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 серпня 2006 р. N 469-р Київ

Про внесення змін у додаток 1 до розпорядження Кабінету Міністрів України від 31 травня 2006 р. N 296

Внести зміни у додаток 1 до розпорядження Кабінету Міністрів України від 31 травня 2006 р. N 296 ( 296-2006-р ) "Про вдосконалення структури розпорядників бюджетних коштів" (Офіційний вісник України, 2006 р., N 22, ст. 1657, N 29, ст. 2099) - із змінами, внесеними розпорядженнями Кабінету Міністрів України від 3 серпня 2006 р. N 464 ( 464-2006-р ) і від 3 серпня 2006 р. N 465 ( 465-2006-р ), виклавши його в редакції, що додається.
