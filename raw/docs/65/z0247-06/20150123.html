ДЕРЖАВНИЙ ДЕПАРТАМЕНТ УКРАЇНИ З ПИТАНЬ ВИКОНАННЯ ПОКАРАНЬ

НАКАЗ

23.02.2006 N 40

Зареєстровано в Міністерстві юстиції України 9 березня 2006 р. за N 247/12121

Про зупинення на 2006 рік дії окремих норм відомчих нормативно-правових актів

{ Із змінами, внесеними згідно з Наказами Міністерства юстиції N 460/5 ( z0445-13 ) від 18.03.2013 N 2186/5 ( z1656-14 ) від 29.12.2014 }

На виконання пунктів 20 та 21 статті 77, статті 114 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) та з метою приведення відомчих нормативно-правових актів у відповідність до вимог цього Закону НАКАЗУЮ:

1. Зупинити на 2006 рік дію таких норм:

{ Пункт 1.1 втратив чинність на підставі Наказу Міністерства юстиції N 2186/5 ( z1656-14 ) від 29.12.2014 }

{ Пункт 1.2 втратив чинність на підставі Наказу Міністерства юстиції N 460/5 ( z0445-13 ) від 18.03.2013 }

2. Начальникам територіальних органів управління Державного департаменту України з питань виконання покарань (далі - Департамент), установ виконання покарань та слідчих ізоляторів забезпечити створення необхідних місць для зберігання посилок (передач) та бандеролей, що одержують засуджені і особи, взяті під варту, з дотриманням санітарно-епідеміологічних умов.

3. Управлінню охорони, нагляду і безпеки Департаменту (Ільтяй М.П.) подати цей наказ у встановленому порядку на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням цього наказу покласти на першого заступника Голови Департаменту полковника внутрішньої служби Лагоду А.С. та начальників територіальних органів управління Департаменту.

5. Наказ оголосити персоналу органів і установ виконання покарань та слідчих ізоляторів.

Голова В.В.Кощинець
