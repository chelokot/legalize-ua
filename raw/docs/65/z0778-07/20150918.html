МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

09.07.2007 N 473/5

Зареєстровано в Міністерстві юстиції України 9 липня 2007 р. за N 778/14045

Про встановлення тарифів за надання послуг державним підприємством "Національні інформаційні системи"

{ Заголовок із змінами, внесеними згідно з Наказом Міністерства юстиції N 1725/5 ( z1099-15 ) від 14.09.2015 }

{ Із змінами, внесеними згідно з Наказами Міністерства юстиції N 787/5 ( z0363-11 ) від 16.03.2011 N 256/5 ( z0257-13 ) від 12.02.2013 N 1583/5 ( z1300-13 ) від 02.08.2013 N 2435/5 ( z1970-13 ) від 18.11.2013 }

Відповідно до постанови Кабінету Міністрів України від 14.07.99 N 1272 ( 1272-99-п ) "Про державне підприємство "Інформаційний центр" Міністерства юстиції" НАКАЗУЮ:

1. Установити тариф:

за послуги (разові) державного підприємства "Національні інформаційні системи" за підключення до єдиних та державних реєстрів/реєстру інформаційної мережі Міністерства юстиції України (далі - Реєстри), адміністратором яких є державне підприємство "Національні інформаційні системи", - у розмірі 1500,00 грн;

за інформаційно-консультативні послуги з навчання роботі з Реєстрами (Реєстром) користувача/реєстратора, співробітника користувача/реєстратора або іншої особи, обов'язковість проходження навчання якої встановлена законодавством (крім працівників Міністерства юстиції України та його територіальних органів, державних нотаріальних контор та державних нотаріальних архівів, виконання посадових обов’язків яких пов’язане з роботою з Реєстрами, а також державних нотаріусів, яким ці послуги надаються безоплатно), із застосуванням погодинної оплати - у розмірі 51,00 грн. за 1 академічну годину (45 хвилин) навчання, відповідно до укладених договорів; { Абзац третій пункту 1 в редакції Наказу Міністерства юстиції N 1583/5 ( z1300-13 ) від 02.08.2013; із змінами, внесеними згідно з Наказом Міністерства юстиції N 2435/5 ( z1970-13 ) від 18.11.2013 }

за технічне обслуговування автоматизованого робочого місця (у тому числі виконання робіт, пов'язаних з поновленням роботи Реєстрів, установлення програмного забезпечення Реєстрів на додатковий комп'ютер тощо) - у розмірі 180,00 грн. за одну годину. { Пункт 1 із змінами, внесеними згідно з Наказом Міністерства юстиції N 787/5 ( z0363-11 ) від 16.03.2011; в редакції Наказу Міністерства юстиції N 256/5 ( z0257-13 ) від 12.02.2013; із змінами, внесеними згідно з Наказом Міністерства юстиції N 1725/5 ( z1099-15 ) від 14.09.2015 }

2. Установити, що кошти, які надходять на поточний рахунок державного підприємства "Національні інформаційні системи" за надання послуг, установлених пунктом 1 цього наказу, спрямовуються на забезпечення ведення Реєстрів та розвиток державного підприємства "Національні інформаційні системи".

{ Пункт 2 із змінами, внесеними згідно з Наказом Міністерства юстиції N 1725/5 ( z1099-15 ) від 14.09.2015 }

3. Держінформ'юсту (Добжанський В.Б.):

подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади";

довести цей наказ до відома начальників Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управлінь юстиції в областях, містах Києві та Севастополі, регіональних філій державного підприємства "Інформаційний центр" Міністерства юстиції України та забезпечити його належне виконання.

4. Начальникам Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управлінь юстиції в областях, містах Києві та Севастополі довести цей наказ до відома нотаріусів.

5. Контроль за виконанням цього наказу покласти на першого заступника Міністра Бондика В.А.

Міністр О.Лавринович
