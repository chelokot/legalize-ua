Кабінет Міністрів України; Розпорядження від 08.10.2008 № 1302-р

Про виділення коштів Держкомтелерадіо для оплати послуг з трансляції телерадіопрограм, вироблених для державних потреб, та забезпечення функціонування Інформаційного центру "Євро-2012 - Україна"

Стан: Чинний

Ідентифікатор: 1302-2008-р

Текст документа від 08.10.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 жовтня 2008 р. N 1302-р Київ

Про виділення коштів Держкомтелерадіо для оплати послуг з трансляції телерадіопрограм, вироблених для державних потреб, та забезпечення функціонування Інформаційного центру "Євро-2012 - Україна"

1. Виділити Держкомтелерадіо 19851 тис. гривень для оплати послуг з трансляції телерадіопрограм, вироблених для державних потреб, та 2500 тис. гривень для забезпечення функціонування Інформаційного центру "Євро-2012 - Україна".

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 107-17 ).

2. Держкомтелерадіо:

затвердити у тижневий строк за погодженням з Мінекономіки та Мінфіном перелік витрат, пов'язаних з проведенням оплати послуг з трансляції телерадіопрограм, вироблених для державних потреб, та забезпечення функціонування Інформаційного центру "Євро-2012 - Україна";

подати до кінця 2008 року Мінекономіки, Мінфіну і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
