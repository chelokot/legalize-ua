Кабінет Міністрів України; Постанова від 23.12.2004 № 1720

Про внесення зміни до переліку суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості

Стан: Втратив чинність

Ідентифікатор: 1720-2004-п

Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 грудня 2004 р. N 1720 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1256 ( 1256-2005-п ) від 21.12.2005 )

Про внесення зміни до переліку суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості

Кабінет Міністрів України постановляє:

У переліку суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості, затвердженому постановою Кабінету Міністрів України від 16 червня 2000 р. N 978 ( 978-2000-п ) (Офіційний вісник України, 2000 р., N 25, ст. 1047), позицію:

"01125011 Кілійський суднобудівний-судноремонтний завод" замінити такою позицією:

"01125821 ВАТ "Українське Дунайське пароплавство", м. Ізмаїл (у частині провадження товариством суднобудівної діяльності)".

Виконуючий обов'язки Прем'єр-міністра України М.АЗАРОВ
