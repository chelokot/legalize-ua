{ Розпорядження втратило чинність на підставі Постанови КМ N 333 ( 333-2015-п ) від 27.05.2015 }

Про зміну складу Національної експертної комісії з питань захисту суспільної моралі

Внести до складу Національної експертної комісії з питань захисту суспільної моралі, затвердженого розпорядженням Кабінету Міністрів України від 17 листопада 2004 р. N 862 ( 862-2004-р ), - із змінами, внесеними розпорядженнями Кабінету Міністрів України від 11 червня 2008 р. N 835 ( 835-2008-р ), від 19 листопада 2008 р. N 1445 ( 1445-2008-р ) та від 17 червня 2009 р. N 650 ( 650-2009-р ), такі зміни:

включити до складу Національної комісії ( 862-2004-р ) Байду Ларису Юріївну - начальника відділу взаємодії з органами державної влади, громадськими та міжнародними організаціями у сфері соціального захисту інвалідів Всеукраїнського громадського соціально-політичного об'єднання "Національна асамблея інвалідів України" (за згодою), Горпинченка Ігоря Івановича - президента Всеукраїнської громадської організації "Асоціація сексологів та андрологів України" (за згодою), Копиленко Марію Любимівну - члена Національної спілки журналістів України (за згодою), Рублюк Оксану Василівну - члена Асоціації українських правників (за згодою), Унгуряна Павла Якимовича - народного депутата України (за згодою);

виключити із складу ( 862-2004-р ) Іваничука Романа Івановича.

Прем'єр-міністр України Ю.ТИМОШЕНКО
