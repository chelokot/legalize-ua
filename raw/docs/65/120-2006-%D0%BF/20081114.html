ПОСТАНОВА від 8 лютого 2006 р. N 120 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 954 ( 954-2008-п ) від 22.10.2008 }

Про внесення зміни у додаток 1 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314

Кабінет Міністрів України постановляє:

У додатку 1 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314 ( 314-2001-п ) "Про встановлення ліміту легкових автомобілів, що обслуговують державні органи" (Офіційний вісник України, 2001 р., N 14, ст. 602; 2004 р., N 38, ст. 2496) у позиції "Державна комісія з цінних паперів та фондового ринку" цифри "7" і "22" замінити відповідно цифрами "8" і "21".
