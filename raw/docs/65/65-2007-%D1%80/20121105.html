КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 лютого 2007 р. N 65-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 863-р ( 863-2012-р ) від 05.11.2012 }

Про підписання Конвенції між Урядом України і Урядом Республіки Кіпр про уникнення подвійного оподаткування та запобігання податковим ухиленням стосовно податків на доходи

{ Із змінами, внесеними згідно з Розпорядженням КМ N 84-р ( 84-2008-р ) від 16.01.2008 }

Схвалити проект Конвенції між Урядом України і Урядом Республіки Кіпр про уникнення подвійного оподаткування та запобігання податковим ухиленням стосовно податків на доходи.

Уповноважити Надзвичайного і Повноважного Посла України в Республіці Кіпр Дем'янюка Олександра Павловича підписати зазначену Конвенцію. { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 84-р ( 84-2008-р ) від 16.01.2008 }
