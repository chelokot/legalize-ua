Стан: Втратив чинність

Ідентифікатор: z1204-03

Текст документа від 16.08.2005:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

08.12.2003 N 952

Зареєстровано в Міністерстві юстиції України 23 грудня 2003 р. за N 1204/8525

( Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 400 ( z0862-05 ) від 02.08.2005 )

Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні

( Із змінами, внесеними згідно з Наказом Міністерства транспорту та зв'язку N 95 ( z0380-05 ) від 24.03.2005 )

Згідно з постановою Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та з метою більш повного відшкодування витрат, пов'язаних з оновленням багажних вагонів, НАКАЗУЮ:

1. Затвердити Тарифи на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні, що додаються.

2. Державній адміністрації залізничного транспорту України (Федюшин Ю.М.) забезпечити своєчасне введення у дію цих Тарифів та правильність їх застосування і проінформувати про це населення на вокзалах та пунктах продажу проїзних документів.

3. З уведенням у дію цього наказу втрачають чинність Тарифи на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні, затверджені наказом Міністерства транспорту України від 19 лютого 2001 року N 103 ( z0191-01 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні" і зареєстровані в Міністерстві юстиції України 5 березня 2001 року за N 191/5382 (із змінами і доповненнями), що додаються.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Дунаєва Л.Ф.

Міністр Г.Кірпа
