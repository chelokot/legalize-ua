Кабінет Міністрів України; Розпорядження, Норми від 02.12.1993 № 1030-р

Про затвердження норм забезпечення військовослужбовців строкової служби Збройних Сил та інших військових формувань України

Стан: Втратив чинність

Ідентифікатор: 1030-93-р

Текст документа від 29.03.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 грудня 1993 р. N 1030-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 426 ( 426-2002-п ) від 29.03.2002 )

( Із змінами, внесеними згідно з Розпорядженням КМ N 133-р ( 133-96-р ) від 21.02.96 )

Затвердити з 1 січня 1994 р. норми забезпечення військовослужбовців строкової служби Збройних Сил України та інших військових формувань, створених відповідно до законодавства, тютюновими виробами згідно з додатком.

Зазначеним військовослужбовцям за їх бажанням виплачується грошова компенсація вартості тютюнових виробів за нормою їх забезпечення. ( Розпорядження доповнено абзацом згідно з Розпорядженням КМ N 133-р ( 133-96-р ) від 21.02.96 )

Виконуючий обов'язки Прем'єр-міністра України Ю.ЗВЯГІЛЬСЬКИЙ
