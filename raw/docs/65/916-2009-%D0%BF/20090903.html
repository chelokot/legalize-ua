Кабінет Міністрів України; Постанова, Порядок від 03.09.2009 № 916

Про фінансування у 2009 році витрат, пов'язаних з придбанням автомобілів швидкої медичної допомоги

Стан: Чинний

Ідентифікатор: 916-2009-п

Текст документа від 03.09.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 вересня 2009 р. N 916 Київ

Про фінансування у 2009 році витрат, пов'язаних з придбанням автомобілів швидкої медичної допомоги

Відповідно до статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) Кабінет Міністрів України постановляє:

1. Виділити на безповоротній основі Міністерству охорони здоров'я 350 млн. гривень за рахунок нерозподілених коштів Стабілізаційного фонду ( 835-17 ) для фінансування витрат, пов'язаних з придбанням автомобілів швидкої медичної допомоги.

2. Затвердити Порядок використання у 2009 році коштів Стабілізаційного фонду для фінансування витрат, пов'язаних з придбанням автомобілів швидкої медичної допомоги, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 3 вересня 2009 р. N 916

ПОРЯДОК використання у 2009 році коштів Стабілізаційного фонду ( 835-17 ) для фінансування витрат, пов'язаних з придбанням автомобілів швидкої медичної допомоги

1. Цей Порядок визначає механізм використання у 2009 році коштів Стабілізаційного фонду за напрямом "Інші витрати", передбаченим пунктом 22 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), для фінансування витрат, пов'язаних з придбанням автомобілів швидкої медичної допомоги (далі - кошти Стабілізаційного фонду).

2. Бюджетна програма, за якою використовуються кошти Стабілізаційного фонду ( 835-17 ), визначається Мінфіном, який закріплює за нею код програмної та функціональної класифікації видатків та кредитування державного бюджету і вносить у встановленому порядку зміни до розпису державного бюджету.

3. Кошти Стабілізаційного фонду ( 835-17 ) спрямовуються на централізовану закупівлю автомобілів швидкої медичної допомоги відповідно до державного стандарту з урахуванням Порядку використання у 2007 році коштів, передбачених у державному бюджеті для виконання програм та здійснення централізованих заходів з охорони здоров'я, затвердженого постановою Кабінету Міністрів України від 4 квітня 2007 р. N 601 ( 601-2007-п ) (Офіційний вісник України, 2007 р., N 26, ст. 1043; 2009 р., N 6, ст. 169, N 20, ст. 632).

4. Перерахування коштів Стабілізаційного фонду ( 835-17 ) здійснюється після внесення змін до розпису державного бюджету в межах установленого обсягу видатків у порядку, затвердженому Державним казначейством.
