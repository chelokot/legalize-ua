КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАН ОВ А від 3 червня 2009 р. N 555 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 449 ( 449-2016-п ) від 22.07.2016 }

Про внесення змін у додаток до постанови Кабінету Міністрів України від 24 червня 2006 р. N 869

Кабінет Міністрів України постановляє:

Внести у додаток до постанови Кабінету Міністрів України від 24 червня 2006 р. N 869 ( 869-2006-п ) "Деякі питання організації діяльності Державної служби спеціального зв'язку та захисту інформації" (Офіційний вісник України, 2006 р., N 26, ст. 1890, 46, ст. 3075) такі зміни:

виключити такі позиції:

"Департамент з питань протидії технічним розвідкам";

"Відділ внутрішньої безпеки";

позицію "Управління контролю безпеки урядового зв'язку" замінити такою позицією:

"Департамент контролю безпеки урядового зв'язку";

доповнити додаток після позиції "Режимно-секретне управління" такою позицією:

"Управління внутрішньої безпеки".

Прем'єр-міністр України Ю.ТИМОШЕНКО
