Текст документа від 08.09.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 вересня 2004 р. N 643-р Київ

Про внесення змін до переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку Автономної Республіки Крим, для яких установлено спеціальний режим інвестиційної діяльності

Внести до переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку Автономної Республіки Крим, для яких установлено спеціальний режим інвестиційної діяльності, погодженого розпорядженням Кабінету Міністрів України від 23 травня 2001 р. N 212 ( 212-2001-р ) (Офіційний вісник України, 2001 р., N 21, ст. 957; 2002 р., N 23, ст. 1129; 2003 р., N 27, ст. 1337), зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 27

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 8 вересня 2004 р. N 643-р

ЗМІНИ, що вносяться до переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку Автономної Республіки Крим, для яких установлено спеціальний режим інвестиційної діяльності ( 212-2001-р )

1. У розділі "Територія пріоритетного розвитку "Велика Ялта" позицію "Секція D Обробна промисловість" замінити такими позиціями:

"Секція B Рибне господарство

05.01.1 Ловля риби (в межах територіальних вод України)

Секція D Обробна промисловість

Підсекція DA Харчова промисловість та перероблення сільськогосподарських продуктів

15.2 Промислове виробництво рибної продукції (за винятком виробництва рибної продукції на суднах)".

2. Розділ "Територія пріоритетного розвитку "Сиваш" переліку доповнити:

1) після позиції "15.61.2 Виробництво круп (обробка рису)" такою позицією:

"15.62 Виробництво крохмалю та крохмальних продуктів";

2) після позиції "36.1 Виробництво меблів" такою позицією:

"37.20.2 Оброблення пластичних мас".
