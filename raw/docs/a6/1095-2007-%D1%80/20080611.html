{ Розпорядження втратило чинність на підставі Розпорядження КМ N 835-р ( 835-2008-р ) від 11.06.2008 }

Про склад Національної експертної комісії з питань захисту суспільної моралі

1. На часткову зміну розпорядження Кабінету Міністрів України від 17 листопада 2004 р. N 862 ( 862-2004-р ) затвердити склад Національної експертної комісії з питань захисту суспільної моралі (додається).

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 23 грудня 2004 р. N 950 ( 950-2004-р ) "Про зміну складу Національної експертної комісії з питань захисту суспільної моралі";

розпорядження Кабінету Міністрів України від 10 жовтня 2007 р. N 855 ( 855-2007-р ) "Про зміни у складі Національної експертної комісії з питань захисту суспільної моралі".
