Про деякі питання Державного комітету з питань фізичної культури і спорту

{ Із змінами, внесеними згідно з Постановами КМ N 954 ( 954-2008-п ) від 22.10.2008 N 464 ( 464-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє:

1. Взяти до відома, що Державний комітет з питань фізичної культури і спорту розміщується в будинку по вул. Еспланадній, 42, у м. Києві.

{ Пункт 2 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }
