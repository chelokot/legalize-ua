{ Розпорядження втратило чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

Про Міжвідомчу раду з підготовки проекту Закону України "Про адміністративно-територіальний устрій України"

Утворити Міжвідомчу раду з підготовки проекту Закону України "Про адміністративно-територіальний устрій України" у складі згідно з додатком.

Дозволити голові Міжвідомчої ради вносити у разі потреби зміни до її складу, а також залучати в установленому порядку для підготовки зазначеного проекту Закону працівників центральних та місцевих органів виконавчої влади, наукових установ та організацій.
