{ Розпорядження втратило чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у переговорах з Європейським інвестиційним банком щодо укладення рамкової угоди між Україною та Європейським інвестиційним банком

( Із змінами, внесеними згідно з Розпорядженням Президента N 954/2005-рп ( 954/2005-рп ) від 11.04.2005 )

1. Утворити делегацію України для участі у переговорах з Європейським інвестиційним банком щодо укладення рамкової угоди між Україною та Європейським інвестиційним банком у такому складі:

ТЕРЬОХІН - Міністр економіки та з питань

Сергій Анатолійович європейської інтеграції України, глава делегації

БАЛЮК - Голова Державної комісії з цінних

Анатолій Іванович паперів та фондового ринку

ДАНИЛЕЙКО - керівник управління Головного

Олександр Іванович управління з питань зовнішньої політики Адміністрації Президента України

ДІР - начальник управління Міністерства

Ігор Юрійович закордонних справ України

ДОВГАНЮК - директор департаменту Міністерства

Леся Володимирівна економіки та з питань європейської інтеграції України

КОЛОСОВА - начальник управління Міністерства

Вікторія Павлівна фінансів України

ЛЕКАРЬ - заступник Голови Державної

Сергій іванович податкової адміністрації України

МАРМАЗОВ - заступник Міністра юстиції України

Василь Євгенович

МЕЛЕШКО - заступник начальника управління

Юлія Ігорівна Секретаріату Кабінету Міністрів України

ПАВЛІКОВСЬКА - заступник директора департаменту

Лада Анатоліївна Секретаріату Кабінету Міністрів України

СУСЛОВ - Голова Державної комісії з

Віктор Іванович регулювання ринків фінансових послуг України

ШЕЙКО - заступник директора департаменту

Олег Леонтійович Державної митної служби України

ШОВКАЛЮК - заступник директора департаменту

Віктор Степанович Міністерства економіки та з питань європейської інтеграції України

Дозволити главі делегації С. Терьохіну вносити в разі потреби зміни до її складу.

( Пункт 1 в редакції Розпорядження Президента N 954/2005-рп ( 954/2005-рп ) від 11.04.2005 )

2. Кабінету Міністрів України:

затвердити директиви делегації України для участі у переговорах з Європейським інвестиційним банком щодо укладення рамкової угоди між Україною та Європейським інвестиційним банком;

виділити кошти в іноземній валюті для забезпечення участі у зазначених переговорах С. Терьохіна, А. Балюка, О. Данилейка, Л. Довганюк, В. Колосової, С. Лекаря, В. Мармазова, Ю. Мелешко, Л. Павліковської, В. Суслова, О. Шейка, В. Шовкалюка. ( Абзац третій пункту 2 в редакції Розпорядження Президента N 954/2005-рп ( 954/2005-рп ) від 11.04.2005 )
