Кабінет Міністрів України; Постанова від 21.03.2007 № 515

Про встановлення розміру плати за надання кредиту Міжнародного банку реконструкції та розвитку, що залучається державою для реалізації проекту "Розвиток міської інфраструктури"

Стан: Втратив чинність

Ідентифікатор: 515-2007-п

Текст документа від 15.12.2017:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 березня 2007 р. N 515 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 953 ( 953-2017-п ) від 06.12.2017 }

Про встановлення розміру плати за надання кредиту Міжнародного банку реконструкції та розвитку, що залучається державою для реалізації проекту "Розвиток міської інфраструктури"

Кабінет Міністрів України постановляє:

Установити, що плата за надання кредиту Міжнародного банку реконструкції та розвитку, що залучається державою для реалізації проекту "Розвиток міської інфраструктури", вноситься щороку комунальними підприємствами, які беруть участь у проекті, до державного бюджету в розмірі 0,01 відсотка непогашеної суми кредиту.

Прем'єр-міністр України В.ЯНУКОВИЧ
