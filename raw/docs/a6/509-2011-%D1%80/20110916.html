КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 червня 2011 р. N 509-р Київ

Про виконання повноважень Прем'єр-міністра України у разі його відсутності

{ Із змінами, внесеними згідно з Постановою КМ N 944 ( 944-2011-п ) від 07.09.2011 }

Установити, що у разі відсутності:

Прем'єр-міністра України його повноваження виконує Перший віце-прем'єр-міністр України - Міністр економічного розвитку і торгівлі;

{ Абзац третій Розпорядження виключено на підставі Постанови КМ N 944 ( 944-2011-п ) від 07.09.2011 }

Прем'єр-міністра України, Першого віце-прем'єр-міністра України - Міністра економічного розвитку і торгівлі повноваження Прем'єр-міністра України виконує Віце-прем'єр-міністр України - Міністр соціальної політики; { Абзац четвертий Розпорядження із змінами, внесеними згідно з Постановою КМ N 944 ( 944-2011-п ) від 07.09.2011 }

Прем'єр-міністра України, Першого віце-прем'єр-міністра України - Міністра економічного розвитку і торгівлі та Віце-прем'єр-міністра України - Міністра соціальної політики повноваження Прем'єр-міністра України виконує Віце-прем'єр-міністр України - Міністр інфраструктури. { Абзац п'ятий Розпорядження із змінами, внесеними згідно з Постановою КМ N 944 ( 944-2011-п ) від 07.09.2011 }

Прем'єр-міністр України М.АЗАРОВ
