Президент України; Указ від 04.08.2006 № 678/2006

Про визнання такими, що втратили чинність, деяких указів Президента України з питань діяльності Міністерства закордонних справ України

Стан: Чинний

Ідентифікатор: 678/2006

Текст документа від 04.08.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання такими, що втратили чинність, деяких указів Президента України з питань діяльності Міністерства закордонних справ України

Визнати такими, що втратили чинність:

Указ Президента України від 3 квітня 1999 року N 357 ( 357/99 ) "Про Положення про Міністерство закордонних справ України";

Указ Президента України від 14 вересня 2000 року N 1069 ( 1069/2000 ) "Про внесення змін до Положення про Міністерство закордонних справ України";

пункт 12 змін, що вносяться до указів Президента України, затверджених Указом Президента України від 5 березня 2004 року N 280 ( 280/2004 ) "Про внесення змін та визнання такими, що втратили чинність, деяких указів Президента України";

Указ Президента України від 29 листопада 2005 року N 1660 ( 1660/2005 ) "Про внесення змін до Положення про Міністерство закордонних справ України".

Президент України В.ЮЩЕНКО
