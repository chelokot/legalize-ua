КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 червня 2010 р. N 444 Київ

Про внесення зміни до пункту 2 Порядку проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму і визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Абзац другий пункту 2 Порядку проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму, затвердженого постановою Кабінету Міністрів України від 24 вересня 1999 р. N 1767 ( 1767-99-п ) "Про науково-громадську експертизу набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 1999 р., N 39, ст. 1946), викласти в такій редакції:

"Представниками центральних органів виконавчої влади в експертній комісії є перші заступники (заступники) Міністра праці та соціальної політики, Міністра економіки, Міністра фінансів, Міністра охорони здоров'я, визначені згідно з наказами відповідного Міністра.".

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 16 червня 2010 р. N 444

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Пункт 2 постанови Кабінету Міністрів України від 24 вересня 1999 р. N 1767 ( 1767-99-п ) "Про науково-громадську експертизу набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 1999 р., N 39, ст. 1946).

2. Постанова Кабінету Міністрів України від 2 червня 2004 р. N 722 ( 722-2004-п ) "Про представників від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 2004 р., N 22, ст. 1499).

3. Постанова Кабінету Міністрів України від 18 травня 2005 р. N 360 ( 360-2005-п ) "Про представників від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 2005 р., N 20, ст. 1074).

4. Постанова Кабінету Міністрів України від 13 червня 2007 р. N 827 ( 827-2007-п ) "Про представників від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 2007 р., N 44, ст. 1800).

5. Постанова Кабінету Міністрів України від 27 грудня 2008 р. N 1155 ( 1155-2008-п ) "Про представників від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 2008 р., N 100, ст. 3345).

6. Постанова Кабінету Міністрів України від 10 червня 2009 р. N 575 ( 575-2009-п ) "Про представника Міністерства охорони здоров'я в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 2009 р., N 43, ст. 1447).
