Кабінет Міністрів України; Розпорядження від 11.07.1997 № 388-р

Про відрядження підполковника міліції Лепеха С.І.

Стан: Втратив чинність

Ідентифікатор: 388-97-р

Текст документа від 07.02.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 липня 1997 р. N 388-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 105 ( 105-2001-п ) від 07.02.2001 )

Прийняти пропозицію Львівської обласної державної адміністрації, погоджену з МВС, про відрядження підполковника міліції Лепеха Степана Ілліча до Львівської обласної державної адміністрації із залишенням в кадрах МВС.

Виконуючий обов'язки Прем'єр-міністра України В.ДУРДИНЕЦЬ
