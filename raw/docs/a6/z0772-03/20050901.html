Про внесення змін до наказу Міністерства фінансів України від 30.07.01 N 359

Відповідно до постанови Кабінету Міністрів України від 19.05.2003 N 740 ( 740-2003-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів і організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

Унести зміни до наказу Міністерства фінансів України від 30.07.2001 N 359 ( z0680-01 ) "Про схему посадових окладів працівників Музею коштовного і декоративного каміння, що фінансується з державного бюджету", зареєстрованого в Міністерстві юстиції України 09.08.2001 за N 680/5871 (із змінами і доповненнями, внесеними наказом Міністерства фінансів України від 18.06.2002 N 437 ( z0532-02 ), зареєстрованого в Міністерстві юстиції України 25.06.2002 за N 532/6820), виклавши додаток до нього у новій редакції (додається).

Перший віце-прем'єр-міністр України, Міністр фінансів України М.Я.Азаров Додаток до наказу Міністерства фінансів України 30.07.2001 N 359 ( z0680-01 ) (зі змінами і доповненнями, внесеними наказом Міністерства фінансів України від 18.06.2002 N 437 ( z0532-02 ), у редакції наказу Міністерства фінансів України від 28.08.2003 N 521)
