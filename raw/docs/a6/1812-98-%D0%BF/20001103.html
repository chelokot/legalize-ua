КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 1998 р. N 1812 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1554 ( 1554-2000-п ) від 12.10.2000 )

Про внесення змін до деяких постанов Кабінету Міністрів України

З метою впорядкування методології оцінки вартості майна підприємств агропромислового комплексу, що приватизуються, Кабінет Міністрів України постановляє:

Внести такі зміни до постанов Кабінету Міністрів України:

1. Пункт 14 Методики оцінки вартості основних фондів, придбаних (введених у дію) за рахунок бюджетних коштів у радгоспах та інших державних сільськогосподарських підприємствах, організованих на базі колгоспів та заснованих ними міжгосподарських сільськогосподарських підприємств без викупу державного майна, затвердженої постановою Кабінету Міністрів України від 21 червня 1995 р. N 447 ( 447-95-п ), в редакції абзацу першого пункту постанови Кабінету Міністрів України від 17 вересня 1996 р. N 1144 ( 1144-96-п ) (ЗП України, 1996 р., N 18, ст. 503), виключити.

2. Останнє речення пункту 2 постанови Кабінету Міністрів України від 19 липня 1996 р. N 755 ( 755-96-п ) "Про прискорення приватизації майна в агропромисловому комплексі та спрощення процедури її проведення" викласти у такій редакції: "При цьому враховується вартість нематеріальних активів, які не відображені в балансі підприємства (крім підприємств сільського та рибного господарства)".

3. Абзац шостий пункту 33 Методики оцінки вартості майна під час приватизації, затвердженої постановою Кабінету Міністрів України від 22 липня 1998 р. N 1114 ( 1114-98-п ) (Офіційний вісник України, 1998 р., N 29, ст. 1094, N 32, ст. 1208), виключити.
