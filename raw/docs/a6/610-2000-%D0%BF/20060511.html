ПОСТАНОВА від 4 квітня 2000 р. N 610 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Про членів колегії Державного комітету у справах охорони державного кордону

Кабінет Міністрів України постановляє:

Затвердити членами колегії Державного комітету у справах охорони державного кордону генерал-майора Бідаха Володимира Прокоповича, полковника Іщенка Дмитра Васильовича, генерал-майора Мельникова Олександра Григоровича, полковника Сафіна Олександра Джамільовича, увільнивши від цих обов'язків контр-адмірала Алфер'єва Ігоря Вікторовича, полковника Баранова Віктора Петровича, полковника Голінка Володимира Васильовича, генерал-майора Головаша Олега Петровича, полковника Рахманного Михайла Івановича.
