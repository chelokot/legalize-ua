МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

09.07.2008 N 316

Зареєстровано в Міністерстві юстиції України 17 липня 2008 р. N 662/15353

Про внесення змін до наказу Мінпраці від 04.10.2007 N 535

Відповідно до пункту 12 Положення про Єдиний державний автоматизований реєстр осіб, які мають право на пільги, затвердженого постановою Кабінету Міністрів України від 29 січня 2003 року N 117 ( 117-2003-п ), та з метою удосконалення структури файла, який формується підприємствами та організаціями, що надають послуги, та надається до управлінь праці та соціального захисту населення для проведення розрахунків на відшкодування витрат, пов'язаних з наданням пільг окремим категоріям громадян, НАКАЗУЮ:

Унести до додатка "Опис електронного формату форми "2-пільга" до наказу Мінпраці від 04.10.2007 N 535 ( z1172-07 ) "Про затвердження форми для розрахунку видатків на відшкодування витрат, пов'язаних з наданням пільг "2-пільга", та Інструкції про порядок її заповнення", зареєстрованого в Міністерстві юстиції України 12.10.2007 за N 1172/14439, такі зміни:

1. Рядок 12 таблиці Структура DBF-файла викласти в такій редакції: "

------------------------------------------------------------------

| 12. | LGKAT | NUMERIC | 3 |Код категорії |

| | | | |пільговика |

------------------------------------------------------------------

".

2. Рядок 8 таблиці "Структура текстового файла" викласти в такій редакції: "

------------------------------------------------------------------

| 8 |Код категорії | 3 |Після коду |

| | | |категорії |

| |пільговика | |обов'язково |

| | | |повинен бути |

| | | |пробіл |

------------------------------------------------------------------

".

Міністр Л.Денісова
