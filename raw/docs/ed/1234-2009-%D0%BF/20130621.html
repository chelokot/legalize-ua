КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 жовтня 2009 р. N 1234 Київ

Про межі акваторії морського порту Рені

{ Назва Постанови в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

{ Із змінами, внесеними згідно з Постановою КМ N 406 ( 406-2013-п ) від 03.06.2013 }

Кабінет Міністрів України постановляє:

1. Визначити межі акваторії морського порту Рені згідно з додатком.

{ Пункт 1 в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

2. Державному підприємству "Адміністрація морських портів України" забезпечити безпеку мореплавства в межах акваторії, визначених у додатку.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 406 ( 406-2013-п ) від 03.06.2013 }

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

Додаток до постанови Кабінету Міністрів України від 7 жовтня 2009 р. N 1234

МЕЖІ акваторії морського порту Рені

{ Назва додатка в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

Акваторія порту включає водний простір р. Дунай від 62,5 милі до 71 милі, рахуючи від лівого берега до лінії державного кордону.

_______________ Примітка. На ділянці р. Дунай від 62,5 милі до 64,2 милі за умови інформування служби капітана морського порту здійснюється промисловий вилов риби та спеціальне використання інших водних живих ресурсів в установленому законодавством порядку.
