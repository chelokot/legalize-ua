{ Розпорядження втратило чинність на підставі Постанови КМ N 623 ( 623-2007-п ) від 13.04.2007 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 23 листопада 2000 р. N 467

У розпорядженні Кабінету Міністрів України від 23 листопада 2000 р. N 467 ( 467-2000-р ) слова "право реалізувати на внутрішньому ринку майно Збройних Сил та інших утворених відповідно до законів України військових формувань, за винятком військової зброї, боєприпасів та вибухових речовин" замінити словами "повноваження на реалізацію на внутрішньому ринку військового майна, яке придатне для подальшого використання, але не може бути застосоване у повсякденній діяльності військ, надлишкового військового майна, за винятком цілісних майнових комплексів, військових містечок, будівель та споруд, іншого нерухомого майна, всіх видів озброєння, бойової та іншої техніки, боєприпасів".

Прем'єр-міністр України Ю.ЄХАНУРОВ
