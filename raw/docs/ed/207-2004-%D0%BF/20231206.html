КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 лютого 2004 р. N 207 Київ

Про нагородження Почесною грамотою Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 1265 ( 1265-2023-п ) від 01.12.2023 }

Кабінет Міністрів України постановляє:

За багаторічну сумлінну працю і високий професіоналізм нагородити Почесною грамотою Кабінету Міністрів України з врученням пам'ятного знака:

БАБІЧ - викладача Сумського державного

Віру Григорівну педагогічного інституту

{ Позицію виключено на підставі Постанови КМ N 1265 ( 1265-2023-п ) від 01.12.2023 }

ДУНЦЯ - депутата Хмельницької міської ради,

Івана Івановича генерального директора ВАТ "АК "Адвіс"

КАФАРСЬКОГО - народного депутата України

Володимира Івановича

КИСЛЮКА - голову Шацької районної ради

Леоніда Петровича (Волинська область)

КРУКА - народного депутата України

Юрія Борисовича

МАКОВЕЦЬКОГО - заступника голови Львівської обласної Ігоря Анатолійовича державної адміністрації

НЕБРАТА - директора Одеського центру

Валерія Миколайовича науково-технічної і економічної інформації

ТІШКІНА - заступника начальника організаційного Олексія Миколайовича відділу апарату Дніпропетровської обласної державної адміністрації

ФАЛКО - директора Клеванської школи-інтернату Жанну Василівну для дітей з вадами зору (Рівненська область)

Прем'єр-міністр України В.ЯНУКОВИЧ
