Кабінет Міністрів України; Розпорядження від 17.12.2008 № 1575-р

Про проведення Київської міжнародної книжкової виставки "Книжкові контракти"

Стан: Чинний

Ідентифікатор: 1575-2008-р

Текст документа від 17.05.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 грудня 2008 р. N 1575-р Київ

Про проведення Київської міжнародної книжкової виставки "Книжкові контракти"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 278-р ( 278-2012-р ) від 17.05.2012 }

{ У назві та тексті Розпорядження слово "виставки-ярмарку" замінено словом "виставки" згідно з Розпорядженням КМ N 278-р ( 278-2012-р ) від 17.05.2012 }

1. Погодитися з пропозицією Держкомтелерадіо щодо проведення щороку в грудні Київської міжнародної книжкової виставки "Книжкові контракти".

2. Взяти до відома, що фінансування заходів з проведення зазначеної в пункті 1 цього розпорядження виставки здійснюватиметься в установленому порядку за рахунок коштів, передбачених Держкомтелерадіо за відповідною бюджетною програмою.

Прем'єр-міністр України Ю.ТИМОШЕНКО
