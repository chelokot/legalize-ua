Про затвердження Положення про єдину систему оцінки роботи фізкультурно-спортивних організацій України зі спортивної майстерності на 2005-2008 роки

{ Із змінами, внесеними згідно з Наказами Міністерства України у справах сім'ї, молоді та спорту N 3337 ( z1554-05 ) від 19.12.2005 N 1915 ( z0751-06 ) від 07.06.2006 }

З метою забезпечення об'єктивності проведення щорічних підсумків роботи фізкультурно-спортивних організацій України зі спортивної майстерності НАКАЗУЮ:

1. Затвердити Положення про єдину систему оцінки роботи фізкультурно-спортивних організацій України зі спортивної майстерності на 2005-2008 роки (далі - Положення), додається.

2. Департаментам олімпійського спорту (Артем'єв О.К.), фізичної культури, Українському центру з фізичної культури і спорту інвалідів "Інваспорт" (Скугарева О.А.) щорічно до 20 січня поточного року згідно з Положенням підводити підсумки роботи з олімпійських, неолімпійських видів спорту, видів спорту інвалідів. { Пункт 2 в редакції Наказу Міністерства України у справах сім'ї, молоді та спорту N 1915 ( z0751-06 ) від 07.06.2006 }

3. Департаменту економіки та фінансів (Крищенко К.Є.) щорічно планувати виділення коштів на виготовлення (придбання) нагородної атрибутики, а управлінню справами (Тарасюк Ю.І.) забезпечити виготовлення спортивних нагород для відзначення переможців згідно з Положенням.

4. Скасувати наказ Державного комітету України з питань фізичної культури і спорту від 10.03.2005 N 681 "Про затвердження Положення про єдину систему оцінки роботи фізкультурно-спортивних організацій України зі спортивної майстерності з видів спорту на 2005-2008 роки".

5. Контроль за виконанням цього наказу покласти на заступника Міністра В.М.Бринзака.

ЗАТВЕРДЖЕНО Наказ Міністерства України у справах молоді та спорту 07.07.2005 N 1122

Зареєстровано в Міністерстві юстиції України 20 липня 2005 р. за N 777/11057

ПОЛОЖЕННЯ про єдину систему оцінки роботи фізкультурно-спортивних організацій України зі спортивної майстерності на 2005-2008 роки

1. Мета і завдання

1.1. Підведення підсумків роботи фізкультурно-спортивних організацій, спеціалізованих навчальних закладів спортивного профілю, ДЮСШ, СДЮШОР, ШВСМ, ДЮСШІ, СДЮШПДР визначення рейтингу кращих тренерів та спортсменів України. { Пункт 1.1 розділу 1 із змінами, внесеними згідно з Наказом Міністерства України у справах сім'ї, молоді та спорту N 1915 ( z0751-06 ) від 07.06.2006 }

1.2. Популяризація, пропаганда кращих результатів роботи зі спортивної майстерності та стимулювання високих спортивних результатів спортсменів і роботи тренерів.

2. Порядок підведення підсумків роботи

2.1. Підсумки роботи зі спортивної майстерності підводяться один раз на рік серед структурних підрозділів у справах сім'ї, молоді та спорту Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських держадміністрацій, розподілених на групи (додаток 1), фізкультурно-спортивних товариств (ФСТ), шкіл вищої спортивної майстерності (ШВСМ), спеціалізованих навчальних закладів спортивного профілю (училища олімпійського резерву - УОР, училища фізичної культури - УФК, інтернати та ліцеї), спеціалізованих дитячо-юнацьких шкіл олімпійського резерву (СДЮШОР), дитячо-юнацьких спортивних шкіл (ДЮСШ), дитячо-юнацьких спортивних шкіл інвалідів (ДЮСШІ), спеціалізованих дитячо-юнацьких шкіл паралімпійського і дефлімпійського резерву (СДЮШПДР), спортсменів та тренерів України з літніх та зимових олімпійських і неолімпійських видів спорту, видів спорту інвалідів (окремо). { Пункт 2.1 розділу 2 в редакції Наказу Міністерства України у справах сім'ї, молоді та спорту N 1915 ( z0751-06 ) від 07.06.2006 }

2.2. Підсумки роботи зі спортивної майстерності підводять відповідні департаменти Міністерства України у справах молоді та спорту (далі - Мінмолодьспорт України) та федерації з видів спорту, Український центр з фізичної культури і спорту інвалідів "Інваспорт" разом з федераціями інвалідів з нозологій. { Пункт 2.2 розділу 2 із змінами, внесеними згідно з Наказом Міністерства України у справах сім'ї, молоді та спорту N 1915 ( z0751-06 ) від 07.06.2006 }

2.3. Переможцями стають організації, тренери, спортсмени, які протягом поточного року за підсумками змагань, визначеними у Єдиному календарному плані спортивних змагань та навчально-тренувальних зборів України, набрали більшу кількість очок згідно з Таблицею оцінки роботи (додаток 2) ( za777-05 ).

Очки нараховуються за виборене місце в індивідуальних, групових та командних номерах програми кожному спортсмену.

2.4. Результати виступів спортсменів ДЮСШ, СДЮШОР, ДЮСШІ, СДЮШПДР, переданих на підготовку до УФК, УОР, ШВСМ, додаткового контингенту УФК, УОР, змінного складу ШВСМ (члени, кандидати та резерв збірних команд України з олімпійських видів спорту) рахуються у загальному підсумку оцінки роботи організації з коефіцієнтом 0,5. { Пункт 2.4 розділу 2 в редакції Наказу Міністерства України у справах сім'ї, молоді та спорту N 3337 ( z1554-05 ) від 19.12.2005, із змінами, внесеними згідно з Наказом Міністерства України у справах сім'ї, молоді та спорту N 1915 ( z0751-06 ) від 07.06.2006 }

2.5. Неолімпійські номери програм з олімпійських видів спорту, які входять до змагань чемпіонатів Європи, світу та України, а також види програм олімпійських видів спорту, які проводяться в умовах, неадекватних регламенту проведення Олімпійських ігор (легка атлетика і стрільба із лука в закритих приміщеннях, плавання у 25-метровому басейні та інші), - очки нараховуються з коефіцієнтом 0,5.

2.6. За підготовку спортсмена очки рівномірно поділяються на кількість тренерів бригади.

2.7. За встановлення одночасно рекордів світу та Європи очки нараховуються один раз за найвищими показниками.

2.8. У разі набрання однакової кількості очок найвище місце дається організації, тренеру, спортсмену, які мають кращі місця на Олімпійських, Паралімпійських, Дефлімпійських іграх, чемпіонатах світу та Європи. { Пункт 2.8 розділу 2 із змінами, внесеними згідно з Наказом Міністерства України у справах сім'ї, молоді та спорту N 1915 ( z0751-06 ) від 07.06.2006 }

3. Порядок проведення нагородження

3.1. Фізкультурно-спортивні організації, які посіли 1-3 місця у групі, нагороджуються відповідною атрибутикою (пам'ятні кубки та грамоти) Мінмолодьспорту України.

3.2. Республіканському комітету з фізичної культури і спорту Автономної Республіки Крим, управлінням у справах сім'ї, молоді та спорту обласних, Київської та Севастопольської міських державних адміністрацій за поданням федерацій з видів спорту та регіональних центрів "Інваспорт" рекомендується розглянути питання щодо відзначення:

тренерів та спортсменів;

СДЮШОР, ДЮСШ, ДЮСШІ, СДЮШПДР, спортивних клубів (КФК).

{ Пункт 3.2 розділу 3 в редакції Наказу Міністерства України у справах сім'ї, молоді та спорту N 1915 ( z0751-06 ) від 07.06.2006 }

3.3. Вартість пам'ятних кубків, затверджених згідно з додатком 3, може змінюватись шляхом її індексації. Нагородження переможців здійснюється керівництвом Мінмолодьспорту України в урочистій обстановці.
