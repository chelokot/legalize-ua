{ Постанова втратила чинність на підставі Постанови КМ N 871 ( 871-2008-п ) від 01.10.2008 }

Про склад Міжвідомчої координаційної ради з підготовки другого проекту розвитку підприємств

Кабінет Міністрів України постановляє:

1. Затвердити новий склад Міжвідомчої координаційної ради з підготовки другого проекту розвитку підприємств (додається).

2. Визнати таким, що втратив чинність, додаток до постанови Кабінету Міністрів України від 24 листопада 1997 р. N 1308 (1308-97-п ) "Про Міжвідомчу координаційну раду з підготовки другого проекту розвитку підприємств".
