КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 лютого 1998 р. N 207 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про внесення зміни до постанови Кабінету Міністрів України від 16 лютого 1998 р. N 157

Кабінет Міністрів України постановляє:

Внести зміну до постанови Кабінету Міністрів України від 16 лютого 1998 р. N 157 ( 157-98-п ) "Про укладення Угоди між Кабінетом Міністрів України та Урядом Російської Федерації про співробітництво в галузі урядового зв'язку", виклавши абзац другий в такій редакції:

"Доручити заступнику Голови Служби безпеки - начальнику Головного управління урядового зв'язку Лазарєву Григорію Петровичу підписати від імені Кабінету Міністрів України зазначену Угоду, дозволивши в разі потреби вносити до неї зміни і доповнення, що не мають принципового характеру".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
