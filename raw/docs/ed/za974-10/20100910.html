Про внесення змін до постанови правління Пенсійного фонду України від 24.12.2009 N 28-2

Відповідно до Закону України "Про збір та облік єдиного внеску на загальнообов'язкове державне соціальне страхування" ( 2464-17 ), пункту 12 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261 ( 1261-2007-п ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Унести до постанови правління Пенсійного фонду України від 24.12.2009 N 28-2 ( za261-10 ) "Про затвердження Порядку взаємодії при обміні інформацією між органами Міністерства внутрішніх справ України та Пенсійного фонду України щодо захисту інтересів держави при нарахуванні та сплаті внесків на загальнообов'язкове державне пенсійне страхування та інших платежів до Пенсійного фонду України", зареєстрованої в Міністерстві юстиції України 30.03.2010 за N 261/17556 (далі - Постанова), такі зміни:

у назві та пункті 1 Постанови ( za261-10 ) слова "внесків на загальнообов'язкове державне пенсійне страхування" замінити словами "єдиного внеску на загальнообов'язкове державне соціальне страхування".

2. Затвердити Зміни до Порядку взаємодії при обміні інформацією між органами Міністерства внутрішніх справ України та Пенсійного фонду України щодо захисту інтересів держави при нарахуванні та сплаті внесків на загальнообов'язкове державне пенсійне страхування та інших платежів до Пенсійного фонду України, затвердженого наказом Міністерства внутрішніх справ України від 24.12.2009 N 552 ( z0261-10 ) та Постановою ( za261-10 ), зареєстрованими в Міністерстві юстиції України 30.03.2010 за N 261/17556 (додаються) ( z0974-10 ).

3. Юридичному управлінню (Рябцева Т.Б.) разом з департаментом надходження доходів (Литвиненко В.В.) подати цю постанову для державної реєстрації до Міністерства юстиції України.

4. Ця постанова набирає чинності з 01.01.2011.

5. Контроль за виконанням цієї постанови покласти на заступника Голови правління Короневського В.М.

Голова правління Б.Зайчук

ПОГОДЖЕНО:

Міністр праці та соціальної політики України В.Надрага

ЗАТВЕРДЖЕНО Наказ Міністерства внутрішніх справ України 10.09.2010 N 437, Постанова правління Пенсійного фонду України 10.09.2010 N 20-3 ( za974-10 )

Зареєстровано в Міністерстві юстиції України 25 жовтня 2010 р. за N 974/18269

ЗМІНИ до Порядку взаємодії при обміні інформацією між органами Міністерства внутрішніх справ України та Пенсійного фонду України щодо захисту інтересів держави при нарахуванні та сплаті внесків на загальнообов'язкове державне пенсійне страхування та інших платежів до Пенсійного фонду України ( z0261-10 )

1. У заголовку слова "внесків на загальнообов'язкове державне пенсійне страхування" замінити словами "єдиного внеску на загальнообов'язкове державне соціальне страхування".

2. У пункті 1.1 після слів "Законами України "Про міліцію" ( 565-12 ) доповнити словами "Про збір та облік єдиного внеску на загальнообов'язкове державне соціальне страхування" ( 2464-17 ) та слова "пенсійного страхування" замінити словами "соціального страхування".

3. Абзац перший пункту 2.1 викласти у такій редакції:

"2.1. Обмін інформацією здійснюється щодо платників єдиного внеску на загальнообов'язкове державне соціальне страхування (далі - платники єдиного внеску), у тому числі стосовно платників єдиного внеску, які мають заборгованість зі сплати єдиного внеску на загальнообов'язкове соціальне страхування (далі - єдиний внесок), страхових внесків та/або щодо яких виявлені порушення у сфері оплати праці та соціального страхування, під час виконання покладених на суб'єктів інформаційного обміну функцій".

4. У пунктах 2.2, 2.3, 2.4 слова "суб'єктів пенсійного страхування" замінити словами "платників єдиного внеску" у відповідних відмінках.

5. У пункті 2.5 слова "страхових внесків" замінити словами "єдиного внеску".
