Кабінет Міністрів України; Розпорядження від 23.11.2000 № 467-р

Про надання ДП "Укроборонпостачальник" права реалізації майна Збройних Сил

Стан: Втратив чинність

Ідентифікатор: 467-2000-р

Текст документа від 03.08.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 листопада 2000 р. N 467-р Київ

{ Із змінами, внесеними згідно з Розпорядженням КМ N 457-р ( 457-2006-р ) від 03.08.2006 }

Надати державному підприємству "Укроборонпостачальник", яке належить до сфери управління Міноборони, повноваження на реалізацію на внутрішньому ринку військового майна, яке придатне для подальшого використання, але не може бути застосоване у повсякденній діяльності військ, надлишкового військового майна, за винятком цілісних майнових комплексів, військових містечок, будівель та споруд, іншого нерухомого майна, всіх видів озброєння, бойової та іншої техніки, боєприпасів.

{ Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 457-р ( 457-2006-р ) від 03.08.2006 }

Прем'єр-міністр України В.ЮЩЕНКО
