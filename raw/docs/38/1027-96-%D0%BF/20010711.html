КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 вересня 1996 р. N 1027 Київ

( Постанова втратила чинність на підставі Постанови КМ N 787 ( 787-2001-п ) від 11.07.2001 )

Про гарантії Кабінету Міністрів України за іноземними кредитами

З метою вдосконалення механізму залучення, використання та погашення іноземних кредитів, що залучаються під державні гарантії, Кабінет Міністрів України постановляє:

Установити, що рішення про надання Кабінетом Міністрів України гарантій за іноземними кредитами оформляється постановами Кабінету Міністрів України за поданням Валютно-кредитної ради Кабінету Міністрів України.
