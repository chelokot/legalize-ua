Текст документа від 04.06.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 квітня 2007 р. N 243-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 794 ( 794-2007-п ) від 04.06.2007 }

Про реалізацію Аграрним фондом пшениці врожаю 2005 року з державного продовольчого резерву

1. Відповідно до підпункту "г" пункту 6.2 статті 6 Закону України "Про державну підтримку сільського господарства України" ( 1877-15 ) дозволити Аграрному фонду провадити у 2006/07 маркетинговому періоді відповідно до кон'юнктури ринку продаж пшениці врожаю 2005 року з державного продовольчого резерву на Аграрній біржі за цінами, які не перевищують встановленого максимального рівня для об'єктів державного цінового регулювання, із забезпеченням покриття витрат з її закупівлі та зберігання.

2. Мінагрополітики інформувати щомісяця Кабінет Міністрів України та Мінфін про виконання цього розпорядження.

Прем'єр-міністр України В.ЯНУКОВИЧ
