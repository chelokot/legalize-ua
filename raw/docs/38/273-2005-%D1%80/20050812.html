Про утворення робочої групи з підготовки законопроекту про створення сприятливих умов для залучення інвестицій в економіку

Стан: Втратив чинність

Ідентифікатор: 273-2005-р

Текст документа від 12.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 липня 2005 р. N 273-р Київ

Про утворення робочої групи з підготовки законопроекту про створення сприятливих умов для залучення інвестицій в економіку

( Із змінами, внесеними згідно з Розпорядженням КМ N 340-р ( 340-2005-р ) від 12.08.2005 )

Утворити робочу групу з питань спеціальних (вільних) економічних зон та територій пріоритетного розвитку із спеціальним режимом інвестиційної діяльності та підготовки законопроекту про створення сприятливих умов для залучення інвестицій в економіку в складі згідно з додатком.

( Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 340-р ( 340-2005-р ) від 12.08.2005 )
