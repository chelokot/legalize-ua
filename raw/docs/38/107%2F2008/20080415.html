Президент України; Указ від 07.02.2008 № 107/2008

Про зупинення дії розпоряджень Кабінету Міністрів України від 6 лютого 2008 року N 202-р, N 205-р, N 206-р і N 207-р

Стан: Втратив чинність

Ідентифікатор: 107/2008

Текст документа від 15.04.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 360/2008 ( 360/2008 ) від 15.04.2008 }

Про зупинення дії розпоряджень Кабінету Міністрів України від 6 лютого 2008 року N 202-р, N 205-р, N 206-р і N 207-р

{ Додатково див. Конституційне подання Президента ( n0001100-08 ) від 07.02.2008 }

Кабінетом Міністрів України 6 лютого 2008 року видано розпорядження N 202-р ( 202-2008-р ) "Про звільнення Лєдомської С.Ю. з посади заступника Голови Фонду державного майна України", N 205-р ( 205-2008-р ) "Про призначення Портнова А.В. першим заступником Голови Фонду державного майна України", N 206-р ( 206-2008-р ) "Про призначення Петрашка С.Я. заступником Голови Фонду державного майна України" і N 207-р ( 207-2008-р ) "Про призначення Фесенка В.І. заступником Голови Фонду державного майна України".

Названими актами ( 202-2008-р, 205-2008-р, 206-2008-р, 207-2008-р ) Кабінет Міністрів України звільнив з посади заступника Голови Фонду державного майна України, призначив першого заступника та заступників Голови Фонду державного майна України.

Ураховуючи те, що Фонд державного майна України за Законом України "Про приватизацію державного майна" ( 2163-12 ) та Тимчасовим положенням про Фонд державного майна України ( 2558-12 ) визначено державним органом, що здійснює державну політику у сфері приватизації державного майна, зазначені розпорядження Кабінету Міністрів України ( 202-2008-р, 205-2008-р, 206-2008-р, 207-2008-р ) не відповідають Конституції України ( 254к/96-ВР ), яка відносить до повноважень Кабінету Міністрів України призначення на посади та звільнення з посад керівників центральних органів виконавчої влади (пункт 9-2 статті 116) ( 254к/96-ВР ).

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію:

розпорядження Кабінету Міністрів України від 6 лютого 2008 року N 202-р ( 202-2008-р ) "Про звільнення Лєдомської С.Ю. з посади заступника Голови Фонду державного майна України";

розпорядження Кабінету Міністрів України від 6 лютого 2008 року N 205-р ( 205-2008-р ) "Про призначення Портнова А.В. першим заступником Голови Фонду державного майна України";

розпорядження Кабінету Міністрів України від 6 лютого 2008 року N 206-р ( 206-2008-р ) "Про призначення Петрашка С.Я. заступником Голови Фонду державного майна України";

розпорядження Кабінету Міністрів України від 6 лютого 2008 року N 207-р ( 207-2008-р ) "Про призначення Фесенка В.І. заступником Голови Фонду державного майна України".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
