ДЕПАРТАМЕНТ СПЕЦІАЛЬНИХ ТЕЛЕКОМУНІКАЦІЙНИХ СИСТЕМ ТА ЗАХИСТУ ІНФОРМАЦІЇ СЛУЖБИ БЕЗПЕКИ УКРАЇНИ

НАКАЗ

19.12.2005 N 147

Зареєстровано в Міністерстві юстиції України 28 грудня 2005 р. за N 1578/11858

Про затвердження Змін та доповнень до наказу Департаменту спеціальних телекомунікаційних систем та захисту інформації Служби безпеки України від 14.07.2004 N 56

Відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", з метою регулювання тарифів на послуги конфіденційного зв'язку, які надаються в Національній системі конфіденційного зв'язку, НАКАЗУЮ:

1. Затвердити Зміни та доповнення до Граничних тарифів на послуги конфіденційного зв'язку, затверджених наказом Департаменту спеціальних телекомунікаційних систем та захисту інформації Служби безпеки України "Про затвердження Граничних тарифів на послуги конфіденційного зв'язку" від 14.07.2004 N 56 ( z0909-04 ), зареєстрованих у Міністерстві юстиції України 22.07.2004 за N 909/9508, що додаються.

2. Начальнику Головного управління криптографічного захисту інформації забезпечити подання цього наказу в установленому порядку на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на першого заступника начальника Департаменту спеціальних телекомунікаційних систем та захисту інформації Служби безпеки України.

Начальник Департаменту К.Бойко
