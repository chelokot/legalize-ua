Кабінет Міністрів України; Постанова від 29.05.1999 № 928

Про внесення зміни до переліку культових споруд - визначних пам'яток архітектури, які не підлягають передачі у постійне користування релігійним організаціям

Стан: Втратив чинність

Ідентифікатор: 928-99-п

Текст документа від 14.02.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 травня 1999 р. N 928 Київ

( Постанова втратила чинність на підставі Постанови КМ N 137 ( 137-2002-п ) від 14.02.2002 )

Про внесення зміни до переліку культових споруд - визначних пам'яток архітектури, які не підлягають передачі у постійне користування релігійним організаціям

Відповідно до Указу Президента України від 4 березня 1992 р. N 125 ( 125/92 ) "Про заходи щодо повернення релігійним організаціям культового майна" Кабінет Міністрів України постановляє:

За пропозицією Державного комітету у справах релігій, погодженою з Державним комітетом будівництва, архітектури та житлової політики, Міністерством культури і мистецтв та Київською міською державною адміністрацією, та на часткову зміну переліку культових споруд - видатних пам'яток архітектури, які не підлягають передачі у постійне користування релігійним організаціям, затвердженого постановою Ради Міністрів УРСР від 5 квітня 1991 р. N 83 ( 83-91-п ) (ЗП УРСР, 1991 р., N 4, ст. 33), з наступними змінами, установити, що заборона передачі культових споруд - визначних пам'яток архітектури релігійним організаціям не поширюється на корпус N 34 Національного Києво-Печерського історико-культурного заповідника, який входить до складу ансамблю споруд верхньої частини Києво-Печерської лаври XI-XIX ст. (охор. N 4).

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
