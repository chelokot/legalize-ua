Кабінет Міністрів України; Розпорядження від 10.07.2006 № 394-р

Про встановлення строку виконання ремонтно-відновлювальних робіт для турбореактивних, турбогвинтових двигунів та інших газових турбін за межами митної території України

Стан: Втратив чинність

Ідентифікатор: 394-2006-р

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 липня 2006 р. N 394-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання ремонтно-відновлювальних робіт для турбореактивних, турбогвинтових двигунів та інших газових турбін за межами митної території України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 454-р ( 454-2006-р ) від 03.08.2006 }

1. Відповідно до статті 240 Митного кодексу України ( 92-15 ) та з урахуванням технічних особливостей встановити строк виконання ремонтно-відновлювальних робіт для турбореактивних, турбогвинтових двигунів та інших газових турбін за товарною позицією 8411 згідно з УКТЗЕД ( 2371г-14 ) за межами митної території України 360 днів. { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 454-р ( 454-2006-р ) від 03.08.2006 }

Установити, що у зазначений строк виконуються також розпочаті і не закінчені до набрання чинності цим розпорядженням роботи з ремонту та відновлення таких двигунів.

2. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України Ю.ЄХАНУРОВ
