Про голову Міжвідомчої комісії з координації роботи, пов'язаної з реалізацією положень Концепції функціонування та розвитку оптового ринку електричної енергії України

Стан: Втратив чинність

Ідентифікатор: 412-2004-р

Текст документа від 24.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 липня 2004 р. N 412-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Міжвідомчої комісії з координації роботи, пов'язаної з реалізацією положень Концепції функціонування та розвитку оптового ринку електричної енергії України

Затвердити Голову Національної комісії регулювання електроенергетики Тітенка Сергія Михайловича головою Міжвідомчої комісії з координації роботи, пов'язаної з реалізацією положень Концепції функціонування та розвитку оптового ринку електричної енергії України, утвореної постановою Кабінету Міністрів України від 17 березня 2004 р. N 328 ( 328-2004-п ) (Офіційний вісник України, 2004 р., N 11, ст. 666), увільнивши від цих обов'язків Продана Юрія Васильовича.

Прем'єр-міністр України В.ЯНУКОВИЧ
