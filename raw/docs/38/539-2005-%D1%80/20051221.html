Про затвердження проекту та титулу реконструкції з розширенням будинку для розміщення адміністративних приміщень по вул. Білоруській, 24, м. Києва

Стан: Чинний

Ідентифікатор: 539-2005-р

Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 грудня 2005 р. N 539-р Київ

Про затвердження проекту та титулу реконструкції з розширенням будинку для розміщення адміністративних приміщень по вул. Білоруській, 24, м. Києва

1. Затвердити поданий Держфінмоніторингом проект "Реконструкція з розширенням будинку для розміщення адміністративних приміщень по вул. Білоруській, 24, у Шевченківському районі м. Києва", рекомендований до затвердження Центральною службою Укрінвестекспертизи Міністерства будівництва, архітектури та житлово-комунального господарства, з такими основними техніко-економічними показниками:

загальна площа - 5692,4 кв. метра

будівельний об'єм - 24131,4 куб. метра

загальна кошторисна вартість - 38950,888 тис. гривень

у тому числі

будівельно-монтажних робіт - 22060,181 тис. гривень.

2. Затвердити титул будови "Реконструкція з розширенням будинку для розміщення адміністративних приміщень по вул. Білоруській, 24, у Шевченківському районі м. Києва", що додається.

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 17 листопада 2004 р. N 827 ( 827-2004-р ) "Про затвердження проекту та титулу будови "Реконструкція з розширенням будинку для розміщення адміністративних приміщень по вул. Білоруській, 24, у Шевченківському районі м. Києва".

Прем'єр-міністр України Ю.ЄХАНУРОВ
