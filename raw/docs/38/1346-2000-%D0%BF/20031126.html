Про затвердження переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

( Із змінами, внесеними згідно з Постановами КМ N 1251 ( 1251-2001-п ) від 26.09.2001 N 232 ( 232-2002-п ) від 01.03.2002 N 1470 ( 1470-2002-п ) від 30.09.2002 N 331 ( 331-2003-п ) від 12.03.2003 N 1357 ( 1357-2003-п ) від 27.08.2003 N 1828 ( 1828-2003-п ) від 26.11.2003 )

( У тексті постанови слова "Міністерство економіки" в усіх відмінках замінено словами "Міністерство економіки та з питань європейської інтеграції" у відповідному відмінку згідно з Постановою КМ N 232 ( 232-2002-п ) від 01.03.2002 )

Кабінет Міністрів України постановляє:

1. Затвердити перелік підприємств, які мають стратегічне значення для економіки і безпеки держави, згідно з додатком.

Рішення про внесення змін до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави, приймаються Кабінетом Міністрів України за поданням Міністерства економіки та з питань європейської інтеграції.

Міністерствам та іншим центральним органам виконавчої влади два рази на рік переглядати зазначений перелік та 10 січня і 10 липня кожного року подавати Міністерству економіки та з питань європейської інтеграції пропозиції з обгрунтуванням щодо кожного об'єкта для коригування зазначеного переліку.

2. Фонду державного майна у планах розміщення акцій підприємств, що не увійшли до цього переліку, не передбачати залишення акцій у державній власності, крім випадків, передбачених законодавством.

3. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.
