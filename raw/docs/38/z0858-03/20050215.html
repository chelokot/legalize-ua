Про внесення змін до наказу Міністерства праці та соціальної політики України від 20.01.2000 N 7

На виконання постанови Кабінету Міністрів України від 6 серпня 2003 року N 1207 ( 1207-2003-п ) "Про підвищення посадових окладів працівників органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести до наказу Міністерства праці та соціальної політики України від 20.01.2000 N 7 ( z0054-00 ) "Про умови оплати праці працівників Українського державного центру соціальних служб для молоді", зареєстрованого в Міністерстві юстиції України 28.01.2000 за N 54/4275 (зі змінами), такі зміни:

1) у назві наказу слова "Українського державного центру соціальних служб для молоді" замінити на слова "Державного центру соціальних служб для молоді";

2) пункт 1 наказу викласти у такій редакції: "Затвердити схеми посадових окладів працівників Державного центру соціальних служб для молоді згідно з додатками 1-3";

3) додатки 1-3 викласти в новій редакції (додаються).

2. Ці умови набирають чинності з 1 вересня 2003 року.
