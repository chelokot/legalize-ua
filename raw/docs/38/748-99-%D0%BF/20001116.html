ПОСТАНОВА від 29 квітня 1999 р. N 748 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1712 ( 1712-2000-п ) від 16.11.2000 )

Про склад Міжвідомчої комісії з питань формування промислово-фінансових груп

Кабінет Міністрів України постановляє:

1. Затвердити новий склад Міжвідомчої комісії з питань формування промислово-фінансових груп, що додається.

2. Визнати таким, що втратив чинність, пункт 3 постанови Кабінету Міністрів України від 15 листопада 1996 р. N 1392 ( 1392-96-п ) "Про Міжвідомчу комісію з питань формування промислово-фінансових груп".
