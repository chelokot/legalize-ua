Кабінет Міністрів України; Постанова від 10.09.2003 № 1436

Про закупівлю продукції підприємств громадських організацій інвалідів та Державної кримінально-виконавчої служби

Стан: Втратив чинність

Ідентифікатор: 1436-2003-п

Текст документа від 01.08.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 вересня 2003 р. N 1436 Київ

Про закупівлю продукції підприємств громадських організацій інвалідів та Державної кримінально-виконавчої служби

{ Із змінами, внесеними згідно з Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

Відповідно до частини другої статті 2 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ) та з метою надання підтримки підприємствам громадських організацій інвалідів та Державної кримінально-виконавчої служби Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

1. Визначити як специфічну продукцію, що виробляється підприємствами громадських організацій інвалідів та установ виконання покарань, іншими підприємствами, створеними для забезпечення виконання завдань Державної кримінально-виконавчої служби, закупівля якої здійснюється відповідно до пункту 2 цієї постанови.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

2. Установити, що у межах обсягів виконання державного замовлення державні замовники залучають до участі у торгах виключно підприємства громадських організацій інвалідів та установ виконання покарань, інші підприємства, створені для забезпечення виконання завдань Державної кримінально-виконавчої служби для закупівлі продукції їх власного виробництва, перелік якої затверджується Міністерством економіки та з питань європейської інтеграції за погодженням Міністерством праці та соціальної політики і Державним департаментом з питань виконання покарань.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

3. Внести до Порядку формування та розміщення державних замовлень на поставку продукції для державних потреб і контролю за їх виконанням, затвердженого постановою Кабінету Міністрів України від 29 лютого 1996 р. N 266 ( 266-96-п ) (ЗП України, 1996 р., N 8, ст. 239; Офіційний вісник України, 2001 р., N 51, ст. 2271; 2003 р., N 23, ст. 1053), такі зміни:

в абзаці восьмому пункту 2 та абзаці третьому пункту 6 слова "УТОСу, УТОГу, Союзу організацій інвалідів" замінити словами "громадських організацій інвалідів";

в абзаці третьому пункту 6 слова "Кабінетом Міністрів України" замінити словами "Міністерством економіки та з питань європейської інтеграції".

4. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 13 лютого 2001 р. N 44 ( 44-2001-р ) "Про перелік продукції, у разі закупівлі якої державні замовники допускають до участі у конкурсах виключно підприємства УТОСу, УТОГу, Спілки організацій інвалідів України та пенітенціарної системи" (Офіційний вісник України, 2001 р., N 7, ст. 287);

розпорядження Кабінету Міністрів України від 26 вересня 2001 р. N 457 ( 457-2001-р ) "Про внесення змін до розпорядження Кабінету Міністрів України від 13 лютого 2001 р. N 44" (Офіційний вісник України, 2001 р., N 40, ст. 1810).
