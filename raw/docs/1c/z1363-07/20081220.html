Про затвердження індексу для визначення розміру плати за виконання робіт

На виконання постанови Кабінету Міністрів України від 20.12.99 N 2328 ( 2328-99-п ) "Про Порядок надання архітектурно-планувального завдання та технічних умов щодо інженерного забезпечення об'єкта архітектури і визначення розміру плати за їх видачу" НАКАЗУЮ:

1. Затвердити індекс розцінок для обрахування розміру плати за видачу архітектурно-планувального завдання та технічних умов щодо інженерного забезпечення об'єкта архітектури, які встановлені Порядком надання архітектурно-планувального завдання та технічних умов щодо інженерного забезпечення об'єкта архітектури і визначення розміру плати за їх видачу, затвердженим постановою Кабінету Міністрів України від 20.12.99 N 2328 ( 2328-99-п ), у розмірі 4,37.

2. Уважати таким, що втратив чинність, наказ Міністерства будівництва, архітектури та житлово-комунального господарства України від 27.03.2006 N 91 ( z0377-06 ) "Про затвердження індексу для визначення розміру плати за виконання робіт", зареєстрований у Міністерстві юстиції України 04.04.2006 за N 377/12251.

3. Управлінню планування та забудови територій (Вашкулат О.М.) подати цей наказ на державну реєстрацію до Міністерства юстиції України.

4. Управлінню планування та забудови територій і Управлінню ціноутворення, експертизи та контролю вартості у будівництві (Губень П.І.) забезпечити доведення наказу до відома заінтересованих організацій.

5. Контроль за виконанням цього наказу покласти на заступника Міністра А.В.Беркуту.

Міністр В.Г.Яцуба
