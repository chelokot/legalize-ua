КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 березня 1997 р. N 147-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Про віднесення посад працівників апарату Конституційного Суду України до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Постановою КМ N 703 ( 703-2013-п ) від 14.08.2013 }

{ Пункт 1 втратив чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 3 березня 1995 р. N 131 ( 131-95-р ) у частині віднесення до категорій посад державних службовців працівників апарату Конституційного Суду України.
