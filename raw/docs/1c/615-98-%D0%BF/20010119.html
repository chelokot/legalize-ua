Текст документа від 19.01.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 травня 1998 р. N 615 Київ

( Постанова втратила чинність на підставі Постанови КМ N 16 ( 16-2001-п ) від 12.01.2001 )

Про внесення змін до ставок ввізного мита на окремі види товарів та до постанови Кабінету Міністрів України від 3 листопада 1997 р. N 1213

Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита ( 4а-93, 4б-93, 4в-93 ) на окремі види товарів згідно з додатком.

2. Затвердити зміни, що вносяться в додаток до постанови Кабінету Міністрів України від 3 листопада 1997 р. N 1213 ( 1213-97-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів" (Офіційний вісник України, 1997 р., число 45, с. 38) із змінами, внесеними постановою Кабінету Міністрів України від 2 квітня 1998 р. N 420 ( 420-98-п ) (додається).

3. Ця постанова набирає чинності через 45 днів після її опублікування у газеті "Урядовий кур'єр".
