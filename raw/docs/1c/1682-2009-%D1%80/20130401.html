Текст документа від 01.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 2009 р. N 1682-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 195-р ( 195-2013-р ) від 01.04.2013 }

Про скасування державної реєстрації технічних умов

{ Назва Розпорядження в редакції Розпорядження КМ N 280-р ( 280-2010-р ) від 24.02.2010 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 280-р ( 280-2010-р ) від 24.02.2010 }

1. Державному комітетові з питань технічного регулювання та споживчої політики здійснити в установленому порядку заходи щодо скасування державної реєстрації технічних умов на компоненти автомобільних бензинів ТУ У 23.2-00152388-002-2003 на період до внесення змін до Закону України "Про ставки акцизного збору і ввізного мита на деякі товари (продукцію)" ( 313/96-ВР ) в частині встановлення акцизного збору на компоненти автомобільних бензинів на рівні акцизного збору на зазначені бензини.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 280-р ( 280-2010-р ) від 24.02.2010 }

2. Міністерству фінансів, Міністерству економіки, Міністерству палива та енергетики в місячний строк подати Кабінетові Міністрів України проект закону про внесення змін до Закону України "Про ставки акцизного збору і ввізного мита на деякі товари (продукцію)" ( 313/96-ВР ) в частині встановлення акцизного збору на компоненти автомобільних бензинів на рівні акцизного збору на зазначені бензини.

Прем'єр-міністр України Ю.ТИМОШЕНКО
