Про внесення змін до наказу Міністерства праці та соціальної політики України від 03.09.2002 N 473

На виконання постанови Кабінету Міністрів України від 15.01.2005 N 37 ( 37-2005-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 03.09.2002 N 473 ( z0744-02 ) "Про умови оплати праці працівників територіальних органів Держнаглядохоронпраці України", зареєстрованого в Міністерстві юстиції України 10.09.2002 за N 744/7032 (зі змінами), виклавши додаток у новій редакції (додається).

2. Ці умови застосовуються з 1 січня 2005 року.

В.о. Міністра М.Папієв
