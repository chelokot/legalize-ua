КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 червня 2010 р. N 595 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 719 ( 719-2014-п ) від 29.12.2014 }

Про внесення змін до переліку та обсягів енергозберігаючих матеріалів, обладнання, устаткування та комплектуючих, що звільняються від ввізного мита та операції з увезення яких на митну територію України звільняються від обкладення податком на додану вартість

{ Із змінами, внесеними згідно з Постановою КМ N 738 ( 738-2010-п ) від 18.08.2010 }

Кабінет Міністрів України постановляє:

Внести до переліку та обсягів енергозберігаючих матеріалів, обладнання, устаткування та комплектуючих, що звільняються від ввізного мита та операції з увезення яких на митну територію України звільняються від обкладення податком на додану вартість, затверджених постановою Кабінету Міністрів України від 14 травня 2008 р. N 444 ( 444-2008-п ) "Питання ввезення на митну територію України енергозберігаючих матеріалів, обладнання, устаткування та комплектуючих" (Офіційний вісник України, 2008 р., N 35, ст. 1169, N 89, ст. 2975; 2009 р., N 70, ст. 2428, N 93, ст. 3161, N 100, ст. 3475; 2010 р., N 3, ст. 107, N 13, ст. 617), зміни, що додаються.

Ця постанова набирає чинності з 19 серпня 2010 року. { Постановляючу частину доповнено абзацом згідно з Постановою КМ N 738 ( 738-2010-п ) від 18.08.2010 }
