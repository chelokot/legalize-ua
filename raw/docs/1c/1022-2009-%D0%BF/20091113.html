Про закупівлю Аграрним фондом цукру для формування державного інтервенційного фонду

Стан: Чинний

Ідентифікатор: 1022-2009-п

Текст документа від 13.11.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 вересня 2009 р. N 1022 Київ

Про закупівлю Аграрним фондом цукру для формування державного інтервенційного фонду

{ Із змінами, внесеними згідно з Постановою КМ N 1175 ( 1175-2009-п ) від 04.11.2009 }

Відповідно до Закону України "Про державну підтримку сільського господарства України" ( 1877-15 ) Кабінет Міністрів України постановляє:

Дозволити Аграрному фонду здійснювати в установленому порядку для формування державного інтервенційного фонду не пов'язану з державним ціновим регулюванням закупівлю виробленого з цукрових буряків урожаю 2009 року цукру, що постачається за квотою "А", за середньозваженими цінами, які склалися протягом останніх трьох торгових сесій на Аграрній біржі та сертифікованих нею акредитованих товарних біржах, після погодження Міністерством аграрної політики з Міністерством фінансів обсягів фінансування на такі цілі. У разі зниження середньозважених цін до рівня мінімальної ціни, визначеної постановою Кабінету Міністрів України від 4 лютого 2009 р. N 63 ( 63-2009-п ) "Про державне регулювання виробництва цукру та цукрових буряків у період з 1 вересня 2009 р. до 1 вересня 2010 р." (Офіційний вісник України, 2009 р., N 9, ст. 270), закупівлю цукру здійснювати за мінімальною ціною.

Аграрному фонду в разі потреби передбачати з урахуванням ринкової кон'юнктури у договорах про закупівлю цукру з його постачальниками оплату в два етапи: 70 відсотків вартості цукру сплачується після поставки товару, а 30 відсотків - після реалізації цукру з державного інтервенційного фонду. { Постановляючу частину доповнено абзацом згідно з Постановою КМ N 1175 ( 1175-2009-п ) від 04.11.2009 }
