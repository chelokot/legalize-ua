Текст документа від 06.05.2021:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 березня 2004 р. N 408 Київ

Про створення галузевого державного архіву дипломатичної служби

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 436 ( 436-2021-п ) від 28.04.2021 }

{ Із змінами, внесеними згідно з Постановою КМ N 436 ( 436-2021-п ) від 28.04.2021 }

Кабінет Міністрів України постановляє:

1. Створити галузевий державний архів дипломатичної служби у межах граничної чисельності працівників Міністерства закордонних справ для постійного зберігання документів, що утворюються в процесі діяльності органів дипломатичної служби, оригіналів міжнародних договорів України, їх завірених копій.

{ Пункт 1 в редакції Постанови КМ N 436 ( 436-2021-п ) від 28.04.2021 }

2. Міністерству закордонних справ разом з Міністерством юстиції затвердити у тримісячний строк Положення про галузевий державний архів дипломатичної служби.

{ Пункт 2 в редакції Постанови КМ N 436 ( 436-2021-п ) від 28.04.2021 }

3. Міністерству закордонних справ забезпечити галузевий державний архів відповідними приміщеннями та технологічним обладнанням.

Прем'єр-міністр України В.ЯНУКОВИЧ
