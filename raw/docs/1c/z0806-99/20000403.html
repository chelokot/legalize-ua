Про затвердження цін на дорогоцінні метали, що скуповуються у населення

Відповідно до п. 4 додатка до постанови Кабінету Міністрів України від 25 грудня 1996 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" (із змінами та доповненнями від 01.02.97 N 116 ( 116-97-п ); 03.04.97 N 293 ( 293-97-п ); 15.07.97 N 743 ( 743-97-п ); 15.07.97 N 747 ( 747-97-п ); 26.01.98 N 96 ( 96-98-п ); 27.04.98 N 567 ( 567-98-п ); 16.06.98 N 912 ( 912-98-п ); 10.09.98 N 1414 ( 1414-98-п ); 30.11.98 N 1887 ( 1887-98-п ) НАКАЗУЮ:

1. Затвердити погоджені з Національним банком України та Міністерством економіки Ціни на дорогоцінні метали, що скуповуються у населення у виробах і брухті (додаються).

2. Головному управлінню дорогоцінних металів і дорогоцінного каміння (Видолоб В.В.) забезпечити доведення нових цін до відома зацікавлених міністерств та інших органів виконавчої влади.

3. Визнати таким, що втратив чинність, наказ Міністерства фінансів України від 9 вересня 1999 р. N 207 ( z0623-99 ) "Про затвердження цін на дорогоцінні метали, що скуповуються у населення".

Примітки: 1. Золото (у виробах і брухті) проб, не передбачених у таблиці, купується за цінами, обчисленими, виходячи з ціни 35,50 гривні, платина - 46,50 гривні, срібло - 0,60 гривні, паладій - 43,10 гривні (за грам металу в чистоті). 2. Зубні протези, що були в користуванні, із вмістом золота 900/750-ї проб, елементи знімних протезів із сплаву ЗлПлСрМ 750-90-80 купуються за ціною 28,76 гривні за грам. 3. Брухт виробів, комбінований із золота і срібла, із вмістом срібла до 70 відсотків, купується за ціною 11,07 гривні за грам, більше 70 відсотків - за ціною срібла. 4. Предмети релігійного культу, медалі й жетони дореволюційного карбування, монети, зливки купуються за вищевказаними цінами відповідного металу та проби. 5. Визначення маси виробів і брухту із золота, платини та паладію проводиться шляхом зважування на терезах із точністю до 0,01 грама, а срібла - з точністю до 0,1 грама.
