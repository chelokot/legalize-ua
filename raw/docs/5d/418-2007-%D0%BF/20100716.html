Кабінет Міністрів України; Постанова від 07.03.2007 № 418

Про затвердження граничної чисельності працівників центрального апарату Міністерства внутрішніх справ

Стан: Втратив чинність

Ідентифікатор: 418-2007-п

Текст документа від 16.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 березня 2007 р. N 418 Київ

Про затвердження граничної чисельності працівників центрального апарату Міністерства внутрішніх справ

{ Із змінами, внесеними згідно з Постановами КМ N 783 ( 783-2008-п ) від 03.09.2008 N 807 ( 807-2009-п ) від 29.07.2009 - дію змін зупинено згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009 N 559 ( 559-2010-п ) від 07.07.2010 }

Кабінет Міністрів України постановляє:

1. Затвердити граничну чисельність працівників центрального апарату Міністерства внутрішніх справ у кількості 3900 осіб.

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 783 ( 783-2008-п ) від 03.09.2008, N 807 ( 807-2009-п ) від 29.07.2009 - дію змін зупинено згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009; із змінами, внесеними згідно з Постановами КМ N 559 ( 559-2010-п ) від 07.07.2010 }

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 5 серпня 1997 р. N 834 ( 834-97-п ) "Про затвердження граничної чисельності центрального апарату Міністерства внутрішніх справ".

3. Міністерству внутрішніх справ:

підготувати та внести у двотижневий строк Кабінетові Міністрів України для погодження відповідні зміни до структури центрального апарату Міністерства;

привести власні нормативно-правові акти у відповідність з цією постановою.

Прем'єр-міністр України В.ЯНУКОВИЧ
