Стан: Втратив чинність

Текст документа від 30.01.1992:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про підпорядкування військових прокуратур

( Відомості Верховної Ради України (ВВР), 1992, N 18, ст. 228 )

Верховна Рада України постановляє:

1. Підпорядкувати з 1 лютого 1992 року Генеральному прокурору України військові прокуратури, розташовані на території України, та на перехідний період реорганізації органів прокуратури України зберегти їх існуючі структури.

2. Генеральному прокурору України при укомплектуванні особовим складом прокуратур по нагляду за додержанням законів у Збройних Силах та інших військових формуваннях, розташованих на території України, врахувати можливість використання підготовлених прокурорсько-слідчих працівників військових прокуратур.

3. З метою збереження кваліфікованих кадрів військових прокуратур та створення умов для їх переходу на службу до прокуратур по нагляду за додержанням законів у військових формуваннях, як виняток, поширити передбачене для військовослужбовців право на пенсію за вислугу років на осіб, яким з урахуванням віку залишилося не більше п'яти років до виходу на пенсію.

4. До прийняття нового положення про формений одяг працівників органів прокуратури України зберегти за прокурорсько-слідчими працівниками прокуратур по нагляду за додержанням законів у військових формуваннях, які перейшли з військових прокуратур, право носіння військової форми одягу з відповідними відзнаками.

5. Міністерству оборони України зберегти для прокуратур по нагляду за додержанням законів у військових формуваннях діючий порядок забезпечення військових прокуратур службовими приміщеннями та їх охорони, транспортом, засобами зв'язку, іншим майном, необхідним для їх нормальної діяльності.
