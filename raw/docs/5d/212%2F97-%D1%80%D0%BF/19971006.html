Про оновлення складу Оперативної міжвідомчої комісії з питань подолання платіжної кризи

Стан: Втратив чинність

Ідентифікатор: 212/97-рп

Текст документа від 06.10.1997:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Розпорядження Президента N 344/97-рп ( 344/97-рп ) від 06.10.97 )

Про оновлення складу Оперативної міжвідомчої комісії з питань подолання платіжної кризи

1. Затвердити оновлений склад Оперативної міжвідомчої комісії з питань подолання платіжної кризи (додається).

2. Визнати таким, що втратило чинність, Розпорядження Президента України від 25 вересня 1996 року N 296 ( 296/96-рп ) "Про новий склад Оперативної міжвідомчої комісії з питань подолання платіжної кризи".

Президент України Л.КУЧМА

м. Київ, 20 травня 1997 року N 212/97-рп

ЗАТВЕРДЖЕНО Розпорядженням Президента України від 20 травня 1997 року N 212/97-рп

Юрій Іванович

ЛАНОВИЙ - виконуючий обов'язки Голови Фонду Володимир Тимофійович державного майна України

ЛИТВИЦЬКИЙ - помічник президента України

Валерій Олексійович

МАЗУР - Міністр промисловості України

Валерій Леонідович

МІТЮКОВ - Міністр фінансів України

ПЕРШИН - заступник Міністра Кабінету Володимир Леонідович Міністрів України, відповідальний секретар Комісії

ПЕТРАШКО - Керівник Управління економічної і Петро Геннадійович соціальної політики Адміністрації Президента України

ПІДГАЙНИЙ - перший заступник Міністра вугільної Ярослав Михайлович промисловості України

ПОДОЛЄВ - перший заступник Міністра зовнішніх Ігор Валентинович економічних зв'язків і торгівлі України
