Кабінет Міністрів України; Постанова, Порядок від 14.03.2007 № 452

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для виконання Державної програми розвитку Національної депозитарної системи

Стан: Чинний

Ідентифікатор: 452-2007-п

Текст документа від 14.03.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 березня 2007 р. N 452 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для виконання Державної програми розвитку Національної депозитарної системи

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для виконання Державної програми розвитку Національної депозитарної системи ( 1707-2004-п ), що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 34

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 березня 2007 р. N 452

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для виконання Державної програми розвитку Національної депозитарної системи ( 1707-2004-п )

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Держінвестицій за програмою "Державна програма розвитку Національної депозитарної системи України ( 1707-2004-п )" (далі - бюджетні кошти).

2. Бюджетні кошти Держінвестицій спрямовує Національному депозитарію для виконання Державної програми розвитку Національної депозитарної системи України, затвердженої постановою Кабінету Міністрів України від 21 грудня 2004 р. N 1707 ( 1707-2004-п ) (Офіційний вісник України, 2004 р., N 51, ст. 3350), на:

створення автоматизованої інформаційної системи Національної депозитарної системи, зокрема національної інформаційної мережі та системи передачі даних, комплексної системи захисту інформації;

удосконалення програмно-технічного комплексу депозитарної діяльності, зокрема для забезпечення обслуговування державних облігацій, облігацій підприємств та облігацій місцевих позик за єдиним стандартом, для удосконалення кореспондентських відносин з депозитарними установами інших держав та проведення грошового розрахунку за договорами про цінні папери;

створення програмного продукту для передачі та зберігання контрольних копій реєстрів власників іменних цінних паперів;

здійснення заходів, передбачених розпорядженням Кабінету Міністрів України від 28 липня 2004 р. N 535-рт;

виконання робіт із завершення будівництва комплексу споруд (архітектор В. Гесте) на Контрактовій пл., 1, у м. Києві, зокрема розроблення проекту будівництва для розміщення Національного депозитарію та його структурних підрозділів.

3. Перерахування бюджетних коштів здійснюється відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

4. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів провадиться відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

5. Національний депозитарій подає щокварталу до 15 числа наступного місяця Держінвестицій інформацію про використання бюджетних коштів.

6. Держінвестицій подає щокварталу до 20 числа наступного місяця Мінфіну інформацію про стан виконання результативних показників відповідно до паспорта бюджетної програми з результатами їх аналізу.

7. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
