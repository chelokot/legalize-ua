Кабінет Міністрів України; Розпорядження від 12.12.1994 № 900-р

Про віднесення посад працівників Українського державного Центру соціальних служб для молоді Мінмолодьспорту до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 900-94-р

Текст документа від 18.01.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 грудня 1994 р. N 900-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 9-р ( 9-2003-р ) від 18.01.2003 )

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади директора Українського державного Центру соціальних служб для молоді Мінмолодьспорту - до 3 категорії, заступника директора Українського державного Центру соціальних служб для молоді - до 4 категорії, інших працівників соціальних служб для молоді - до відповідних категорій посад державних службовців міністерств і місцевих органів державної виконавчої влади.

Прем'єр-міністр України В.МАСОЛ
