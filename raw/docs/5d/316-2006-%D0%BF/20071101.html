Про збільшення статутного капіталу Державної іпотечної установи

Стан: Чинний

Ідентифікатор: 316-2006-п

Текст документа від 01.11.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 березня 2006 р. N 316 Київ

Про збільшення статутного капіталу Державної іпотечної установи

{ Із змінами, внесеними згідно з Постановою КМ N 1140 ( 1140-2007-п ) від 19.09.2007 }

Кабінет Міністрів України постановляє:

1. Збільшити за рахунок коштів, передбачених Законом України "Про Державний бюджет України на 2006 рік" ( 3235-15 ), статутний капітал Державної іпотечної установи на суму 80000000 гривень.

2. Внести до постанов Кабінету Міністрів України такі зміни:

у пункті 1 постанови Кабінету Міністрів України від 8 жовтня 2004 р. N 1330 ( 1330-2004-п ) "Деякі питання Державної іпотечної установи" (Офіційний вісник України, 2004 р., N 41, ст. 2709, 2005 р., N 16, ст. 847) цифри і слова "20000000 (двадцять мільйонів)" замінити цифрами і словами "100000000 (сто мільйонів)".

{ Абзац третій пункту 2 втратив чинність на підставі Постанови КМ N 1140 ( 1140-2007-п ) від 19.09.2007 }

3. Для здійснення зазначених у пункті 1 цієї постанови виплат Державне казначейство перераховує на реєстраційний рахунок Міністерства фінансів кошти в сумі 80000000 гривень, які Міністерство платіжним дорученням перераховує на рахунок Державної іпотечної установи згідно з розписом видатків державного бюджету.

Прем'єр-міністр Ю.ЄХАНУРОВ
