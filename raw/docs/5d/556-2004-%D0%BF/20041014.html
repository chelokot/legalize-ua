( Постанова втратила чинність на підставі Постанови КМ N 1350 ( 1350-2004-п ) від 14.10.2004 )

Про затвердження складу Ради підприємців України при Кабінеті Міністрів України

Кабінет Міністрів України постановляє:

1. Затвердити склад Ради підприємців України при Кабінеті Міністрів України згідно з додатком.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 16 листопада 2002 р. N 1779 ( 1779-2002-п ) "Про склад Ради підприємців України при Кабінеті Міністрів України" (Офіційний вісник України, 2002 р., N 47, ст. 2159).
