КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 липня 2007 р. N 568-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1157 ( 1157-2018-п ) від 27.12.2018 }

Питання державного регулювання виробництва і реалізації цукру

Для підвищення ефективності роботи бурякоцукрового комплексу, забезпечення внутрішнього ринку цукром вітчизняного виробництва та удосконалення механізму квотування вирощування цукрових буряків і виробництва цукру Мінагрополітики розробити та затвердити до 1 вересня 2007 р.:

Порядок розподілу на конкурсних засадах між бурякосіючими господарствами обсягів вирощування цукрових буряків для виробництва цукру в межах квоти "А" ( z0997-07 );

Порядок розподілу на конкурсних засадах між цукровими заводами обсягів виробництва цукру в межах квоти "А" ( z0996-07 ).
