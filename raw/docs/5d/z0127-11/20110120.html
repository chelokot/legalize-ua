НАКАЗ

20.01.2011 N 24/35

Зареєстровано в Міністерстві юстиції України 31 січня 2011 р. за N 127/18865

Про визнання такими, що втратили чинність, деяких наказів Комітету України з питань геології та використання надр, Державної податкової адміністрації України

З метою приведення чинних нормативно-правових актів до норм Податкового Кодексу України ( 2755-17 ) НАКАЗУЄМО:

1. Визнати таким, що втратив чинність, наказ Комітету України з питань геології та використання надр, Державної податкової адміністрації України від 23.06.99 N 105/309 ( z0474-99 ) "Про затвердження Інструкції про порядок справляння збору за геологорозвідувальні роботи, виконані за рахунок державного бюджету", зареєстрований у Міністерстві юстиції України 16.07.99 за N 474/3767; наказ Міністерства екології та природних ресурсів України, Державної податкової адміністрації України від 09.01.2002 N 7/7 ( z0075-02 ) "Про внесення змін і доповнень до Інструкції про порядок справляння збору за геологорозвідувальні роботи, виконані за рахунок державного бюджету", зареєстрований у Міністерстві юстиції України 29.01.2002 за N 75/6363; накази Міністерства охорони навколишнього природного середовища України, Державної податкової адміністрації України від 04.11.2009 N 583/610 ( z0014-10 ) "Про затвердження Змін до наказу Геолкому України та ДПА від 23.06.99 N 105/309", зареєстрований в Міністерстві юстиції України 13.01.2010 за N 14/17309; накази Міністерства охорони навколишнього природного середовища та ядерної безпеки України, Державної податкової адміністрації України від 19.07.99 N 162/379 ( z0544-99 ) "Про затвердження Інструкції про порядок обчислення та сплати збору за забруднення навколишнього природного середовища", зареєстрований у Міністерстві юстиції України 09.08.99 за N 544/3837; від 27.01.2000 N 24/37 ( z0091-00 ) "Про внесення змін і доповнень до Інструкції про порядок обчислення та сплати збору за забруднення навколишнього природного середовища", зареєстрований у Міністерстві юстиції України 14.02.2000 за N 91/4312; накази Міністерства екології та природних ресурсів України, Державної податкової адміністрації України від 28.02.2001 N 75/76 ( z0245-01 ) "Про внесення змін і доповнень до Інструкції про порядок обчислення та сплати збору за забруднення навколишнього природного середовища", зареєстрований в Міністерстві юстиції України 19.03.2001 за N 245/5436; від 09.01.2002 N 6/8 ( z0074-02 ) "Про внесення змін і доповнень до Інструкції про порядок обчислення та сплати збору за забруднення навколишнього природного середовища", зареєстрований в Міністерстві юстиції України 29.01.2002 за N 74/6362; наказ Міністерства охорони навколишнього природного середовища України, Державної податкової адміністрації України від 07.10.2004 N 383/587 ( z1360-04 ) "Про внесення змін і доповнень до Інструкції про порядок обчислення та сплати збору за забруднення навколишнього природного середовища", зареєстрований в Міністерстві юстиції України 25.10.2004 за N 1360/9959; від 18.04.2007 N 194/240 ( z0481-07 ) "Про затвердження Змін до Інструкції про порядок обчислення та сплати збору за забруднення навколишнього природного середовища", зареєстрований в Міністерстві юстиції України 08.05.2007 за N 481/13748; від 22.06.2009 N 327/322 ( z0641-09 ) "Про затвердження Змін до Інструкції про порядок обчислення та сплати збору за забруднення навколишнього природного середовища", зареєстрований в Міністерстві юстиції України 15.07.2009 за N 641/16657.

2. Юридичному департаменту Міністерства (Роменський Д.В.) в установленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу залишаємо за собою.

4. Цей наказ набирає чинності з дня його офіційного опублікування.
