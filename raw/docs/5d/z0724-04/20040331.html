ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

31.03.2004 N 645

Зареєстровано в Міністерстві юстиції України 11 червня 2004 р. за N 724/9323

Про визнання таким, що втратив чинність, наказу Фонду державного майна України від 08.10.96 N 1182

У зв'язку з набранням чинності Господарським ( 436-15 ) та Цивільним кодексами України ( 435-15 ) НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Фонду державного майна України від 08.10.96 N 1182 ( z0687-96 ) "Про затвердження Положення про порядок створення господарських товариств для участі в приватизації об'єктів групи А", зареєстрований в Міністерстві юстиції України 27.11.96 за N 687/1712.

2. Департаменту продажу цілісних майнових комплексів та активів підприємств (В. Зеленський) подати наказ на державну реєстрацію до Міністерства юстиції України.

3. Відповідальність за виконання наказу покласти на Голову Фонду майна Автономної Республіки Крим, начальників регіональних відділень ФДМУ та директора Департаменту продажу цілісних майнових комплексів та активів підприємств В. Зеленського.

4. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Л. Кальніченко.

Голова Фонду М.Чечетов
