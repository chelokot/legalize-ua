Текст документа від 29.10.2003:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про вдосконалення організації шефства над Державною прикордонною службою України

( Із змінами, внесеними згідно з Указом Президента N 1227/2003 ( 1227/2003 ) від 29.10.2003 )

З метою вдосконалення організації шефства та підтримання розвитку і зміцнення Прикордонних військ України постановляю:

1. Підтримати пропозицію Державного комітету у справах охорони державного кордону України, місцевих органів виконавчої влади та громадських організацій про дальший розвиток шефства над з'єднаннями, частинами та підрозділами Прикордонних військ України.

2. Кабінету Міністрів України, Раді міністрів Автономної Республіки Крим, обласним, Київській і Севастопольській міським державним адміністраціям з урахуванням набутого досвіду закріпити за з'єднаннями, частинами та підрозділами Державної прикордонної служби України конкретні організації та установи згідно з переліком, що додається.

Покласти в основу шефської роботи військово-патріотичне виховання молоді, піднесення престижу прикордонної служби, надання практичної допомоги у справах охорони державного кордону. ( Стаття 2 із змінами, внесеними згідно з Указом Президента N 1227/2003 ( 1227/2003 ) від 29.10.2003 )

3. У порядку шефства надавати допомогу в забезпеченні Державної прикордонної служби України продовольством, паливно-мастильними матеріалами, матеріально-технічними засобами, у розв'язанні житлових, комунально-побутових та інших соціальних проблем військовослужбовців.

( Стаття 3 із змінами, внесеними згідно з Указом Президента N 1227/2003 ( 1227/2003 ) від 29.10.2003 )

4. Визнати таким, що втратив чинність, Указ Президента України від 17 вересня 1999 року N 1194 ( 1194/99 ) "Про поширення дії Указу Президента України від 7 жовтня 1994 року N 577 "Про організацію шефства над кораблями Військово-Морських Сил України" на морські з'єднання і частини Прикордонних військ України".
