Кабінет Міністрів України; Розпорядження від 07.07.2010 № 1376-р

Деякі питання фінансування будівництва залізнично-автомобільного мостового переходу через р. Дніпро у м. Києві

Стан: Чинний

Ідентифікатор: 1376-2010-р

Текст документа від 09.12.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 липня 2010 р. N 1376-р Київ

Деякі питання фінансування будівництва залізнично-автомобільного мостового переходу через р. Дніпро у м. Києві

{ Із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2010-п ) від 06.12.2010 }

1. Виділити Національному агентству з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу та реалізації інфраструктурних проектів відповідно до пункту 4 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) кошти Стабілізаційного фонду в сумі 625000 тис. гривень, у тому числі у червні - 100000 тис., липні - 200000 тис., серпні - 175000 тис., вересні - 150000 тис. гривень, для будівництва залізнично-автомобільного мостового переходу через р. Дніпро у м. Києві.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2010-п ) від 06.12.2010 }

2. Відкритому акціонерному товариству "Державний ощадний банк України", публічним акціонерним товариствам "Державний експортно-імпортний банк України", "Акціонерний комерційний банк "Київ", "Родовід Банк" та акціонерний банк "Укргазбанк" розглянути протягом 30 робочих днів питання щодо можливості надання державному територіальному галузевому об'єднанню "Південно-Західна залізниця" кредитів на загальну суму 370000 тис. гривень із строком погашення до 31 грудня 2011 р. та відсотковою ставкою не більш як 15 відсотків річних для будівництва залізнично-автомобільного мостового переходу через р. Дніпро у м. Києві.

Міністерству фінансів забезпечити контроль за наданням таких кредитів.

3. Національному агентству з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу та реалізації інфраструктурних проектів, Міністерству фінансів та Міністерству економіки передбачити під час підготовки проекту Державного бюджету України на 2011 рік видатки на погашення державним територіальним галузевим об'єднанням "Південно-Західна залізниця" кредитів, наданих відповідно до пункту 2 цього розпорядження, і сплату відсотків за ними.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2010-п ) від 06.12.2010 }

4. Погодитися з пропозицією Міністерства транспорту та зв'язку щодо можливості включення до зведеного кошторисного розрахунку вартості будівництва залізнично-автомобільного мостового переходу через р. Дніпро у м. Києві (з підходами) на залізничній дільниці Київ-Московський - Дарниця витрат, пов'язаних із сплатою відсотків за кредитами, наданими відповідно до пункту 2 цього розпорядження.

Прем'єр-міністр України М.АЗАРОВ
