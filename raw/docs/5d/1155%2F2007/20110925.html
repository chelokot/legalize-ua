Президент України; Указ від 28.11.2007 № 1155/2007

Про деякі заходи щодо піднесення ролі української мови

Стан: Чинний

Ідентифікатор: 1155/2007

Текст документа від 25.09.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про деякі заходи щодо піднесення ролі української мови

{ Із змінами, внесеними згідно з Указом Президента N 906/2011 ( 906/2011 ) від 10.09.2011 }

З метою забезпечення всебічного розвитку і функціонування української мови в усіх сферах суспільного життя, заохочення молоді до вивчення та навчання державною мовою постановляю:

1. Заснувати, починаючи з 2008 року, 14 щорічних стипендій Президента України переможцям Міжнародного конкурсу з української мови імені Петра Яцика.

Установити, що розмір зазначених стипендій визначається Кабінетом Міністрів України.

{ Стаття 2 втратила чинність на підставі Указу Президента N 906/2011 ( 906/2011 ) від 10.09.2011 }

3. Кабінету Міністрів України:

розробити та подати у місячний строк проект Положення про порядок призначення стипендій Президента України переможцям Міжнародного конкурсу з української мови імені Петра Яцика;

передбачити під час доопрацювання проекту закону про Державний бюджет України на 2008 рік та в проектах закону про Державний бюджет України на наступні роки видатки на виплату стипендій, зазначених у статті 1 цього Указу;

опрацювати питання щодо запровадження системи заохочення педагогічних та науково-педагогічних працівників навчальних закладів, в яких навчально-виховний процес ведеться мовами національних меншин, до вивчення дітьми української мови.

4. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 28 листопада 2007 року N 1155/2007
