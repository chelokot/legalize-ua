КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 грудня 1998 р. N 2083 Київ

( Постанова втратила чинність на підставі Постанови КМ N 215 ( 215-2003-п ) від 24.02.2003 )

Про розмір стипендії Кабінету Міністрів України для молодих учених

Кабінет Міністрів України постановляє:

На зміну пункту 2 постанови Кабінету Міністрів України від 18 грудня 1995 р. N 1014 ( 1014-95-п ) "Про підвищення розміру стипендій для молодих учених" (ЗП України, 1996 р., N 4, ст. 128) збільшити розмір стипендії Кабінету Міністрів України для молодих учених, установивши її з 1 січня 1999 р. у розмірі 90 гривень.
