РОЗПОРЯДЖЕННЯ від 7 червня 2005 р. N 173-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 646 ( 646-2007-п ) від 20.04.2007 }

Про затвердження нового персонального складу урядової частини Спільної парламентсько-урядової комісії з інтеграції України до Світової організації торгівлі

На часткову зміну розпорядження Кабінету Міністрів України від 29 квітня 2004 р. N 265 ( 265-2004-р ) затвердити новий персональний склад урядової частини Спільної парламентсько-урядової комісії з інтеграції України до Світової організації торгівлі, що додається.
