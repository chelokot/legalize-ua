Кабінет Міністрів України; Розпорядження від 11.02.2010 № 211-р

Питання розроблення та затвердження проектної документації для будівництва, реконструкції та капітального ремонту автомобільних доріг

Стан: Чинний

Ідентифікатор: 211-2010-р

Текст документа від 11.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 лютого 2010 р. N 211-р Київ

Питання розроблення та затвердження проектної документації для будівництва, реконструкції та капітального ремонту автомобільних доріг

Погодитися з пропозицією Державної служби автомобільних доріг щодо розроблення проектної документації на стадіях "проект" і "робочий проект" для будівництва, реконструкції та капітального ремонту окремих ділянок автомобільних доріг, техніко-економічне обґрунтування будівництва, реконструкції та капітального ремонту яких затверджене та схвалене розпорядженнями Кабінету Міністрів України від 24 жовтня 2007 р. N 907 ( 907-2007-р ) "Про затвердження техніко-економічного обґрунтування інвестицій реконструкції автомобільної дороги М-26 Харків - Сімферополь - Севастополь на ділянці Харків - Сімферополь", від 27 грудня 2008 р. N 1621 ( 1621-2008-р ) "Про схвалення техніко-економічного обґрунтування будівництва, реконструкції та капітального ремонту автомобільної дороги за напрямком Ульяновка - Миколаїв - Херсон - Красноперекопськ - Сімферополь (М-23, М-14, М24)", від 27 грудня 2008 р. N 1623 ( 1623-2008-р ) "Про схвалення техніко-економічного обґрунтування будівництва, реконструкції та капітального ремонту автомобільної дороги за напрямком Київ - Харків - Дебальцеве - Ізварине (М-03, М-04)" та від 27 грудня 2008 р. N 1624 ( 1624-2008-р ) "Про схвалення техніко-економічного обґрунтування будівництва, реконструкції та капітального ремонту автомобільної дороги Київ - Ковель - Ягодин (на Люблін) (М-07)".

Затвердження зазначеної проектної документації на стадіях "проект" і "робочий проект" здійснюється в установленому законодавством порядку.

Прем'єр-міністр України Ю.ТИМОШЕНКО
