АДМІНІСТРАЦІЯ ДЕРЖАВНОЇ СЛУЖБИ СПЕЦІАЛЬНОГО ЗВ'ЯЗКУ ТА ЗАХИСТУ ІНФОРМАЦІЇ УКРАЇНИ

НАКАЗ

18.05.2011 N 110

Зареєстровано в Міністерстві юстиції України 6 червня 2011 р. за N 673/19411

Про внесення змін до наказу Адміністрації Держспецзв'язку від 09.06.2009 N 115

{ Наказ фактично втратив чинність у зв'язку з втратою чинності наказу Адміністрації Державної служби спеціального зв'язку та захисту інформації N 115 ( z0597-09 ) від 09.06.2009, до якого вносились зміни }

Відповідно до статті 10 Дисциплінарного статуту Державної служби спеціального зв'язку та захисту інформації України ( 373-17 ), Указів Президента України від 18.11.96 N 1094 ( 1094/96 ) "Про відомчі заохочувальні відзнаки", від 13.02.97 N 134 ( 134/97 ) "Про Примірне положення про відомчі заохочувальні відзнаки" (зі змінами), від 21.02.2002 N 157 ( 157/2002 ) "Про додаткові заходи щодо посилення турботи про захисників Вітчизни, їх правового і соціального захисту, поліпшення військово-патріотичного виховання молоді" НАКАЗУЮ:

1. Унести до Положення про Почесну грамоту та відомчі заохочувальні відзнаки Державної служби спеціального зв'язку та захисту інформації України, затвердженого наказом Адміністрації Державної служби спеціального зв'язку та захисту інформації України від 09.06.2009 N 115 ( z0597-09 ), зареєстрованого в Міністерстві юстиції України 03.07.2009 за N 597/16613, такі зміни:

1.1. Пункт 1.8 розділу I викласти у такій редакції:

"1.8. Нагородження нагрудними знаками "Ветеран спеціального зв'язку" та "За бездоганну службу" здійснюється з нагоди дня спеціального зв'язку та захисту інформації України. Нагородження здійснюється також при звільненні особи рядового і начальницького складу Держспецзв'язку зі служби за наявності у неї відповідної вислуги.";

1.2. У розділі II:

доповнити розділ після пункту 2.2 новим пунктом 2.3 такого змісту:

"2.3. Для нагородження ветеранів Держспецзв'язку та ветеранів підрозділів спеціального зв'язку органів державної безпеки, інших громадян України, іноземців та осіб без громадянства "Почесною відзнакою Державної служби спеціального зв'язку та захисту інформації України" та "Хрестом Заслуги" керівниками заінтересованих підрозділів готується рапорт (клопотання) із зазначенням конкретних заслуг особи, який після прийняття позитивного рішення Головою Держспецзв'язку або особою, яка виконує його обов'язки, передається до Департаменту кадрового забезпечення Адміністрації Держспецзв'язку для підготовки наказу.".

У зв'язку з цим пункти 2.3 - 2.7 вважати відповідно пунктами 2.4 - 2.8;

пункт 2.7 викласти у такій редакції:

"2.7. Рапорти (клопотання) про нагородження нагрудними знаками "Ветеран спеціального зв'язку" та "За бездоганну службу" надсилаються до Департаменту кадрового забезпечення Адміністрації Держспецзв'язку до 1 вересня кожного року. Вислуга років кандидатів до нагородження обчислюється станом на 12 жовтня поточного року.".

2. Директору Департаменту кадрового забезпечення Адміністрації Державної служби спеціального зв'язку та захисту інформації України забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України в установленому порядку.

3. Цей наказ набирає чинності з дня його офіційного опублікування.

Голова Служби Л.І.Нетудихата
