Кабінет Міністрів України; Розпорядження від 01.03.2010 № 301-р

Питання надання громадянам квартир, що придбані Державною іпотечною установою, у м. Пирятині

Стан: Чинний

Ідентифікатор: 301-2010-р

Текст документа від 15.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 березня 2010 р. N 301-р Київ

Питання надання громадянам квартир, що придбані Державною іпотечною установою, у м. Пирятині

{ Із змінами, внесеними згідно з Розпорядженням КМ N 240-р ( 240-2013-р ) від 15.04.2013 }

1. Затвердити погоджений Координаційною радою з питань розподілу квартир, що придбані Державною іпотечною установою, при Кабінеті Міністрів України поіменний список громадян, яким надаються придбані у м. Пирятині Полтавської області (вул. Цибаня, 6) квартири (далі - список), що додається до оригіналу.

2. Державній іпотечній установі передати Міністерству внутрішніх справ, Державній службі з надзвичайних ситуацій, Адміністрації Державної прикордонної служби, Службі безпеки, Генеральній прокуратурі України та Пирятинській міській раді квартири для надання зазначеним у списку громадянам.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 240-р ( 240-2013-р ) від 15.04.2013 }

3. Після передачі Державною іпотечною установою квартир виконавчому комітетові Пирятинської міської ради видати зазначеним у списку громадянам ордери на жилі приміщення.

{ Пункт 3 в редакції Розпорядження КМ N 240-р ( 240-2013-р ) від 15.04.2013 }

4. Міністерству внутрішніх справ, Державній службі з надзвичайних ситуацій, Адміністрації Державної прикордонної служби, Службі безпеки, Генеральній прокуратурі України та Пирятинській міській раді забезпечити неухильне дотримання встановленого Кабінетом Міністрів України порядку розподілу квартир, що придбані Державною іпотечною установою.

{ Пункт 4 із змінами, внесеними згідно з Розпорядженням КМ N 240-р ( 240-2013-р ) від 15.04.2013 }
