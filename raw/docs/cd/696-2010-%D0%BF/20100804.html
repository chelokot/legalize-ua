Текст документа від 04.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 серпня 2010 р. N 696 Київ

Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України

Відповідно до Указу Президента України від 8 квітня 2010 р. N 522 ( 522/2010 ) "Про деякі питання представництва економічних інтересів України за кордоном" Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 27

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 4 серпня 2010 р. N 696

ПЕРЕЛІК актів Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 28 грудня 1993 р. N 1067 ( 1067-93-п ) "Про організацію роботи торговельно-економічних місій у складі дипломатичних представництв України за кордоном".

2. Постанова Кабінету Міністрів України від 7 червня 1994 р. N 369 ( 369-94-п ) "Про внесення змін до деяких рішень Уряду України".

3. Постанова Кабінету Міністрів України від 29 травня 1995 р. N 359 ( 359-95-п ) "Про відкриття торговельно-економічних місій у складі дипломатичних представництв України за кордоном у 1995 році".

4. Розпорядження Кабінету Міністрів України від 1 березня 1996 р. N 153 ( 153-96-р ).

5. Постанова Кабінету Міністрів України від 9 червня 1997 р. N 554 ( 554-97-п ) "Про відкриття торгівельно-економічної місії у складі Посольства України в Королівстві Іспанія".

6. Постанова Кабінету Міністрів України від 15 липня 1997 р. N 741 ( 741-97-п ) "Про відкриття торгівельно-економічної місії у складі Посольства України в Азербайджанській Республіці".

7. Постанова Кабінету Міністрів України від 24 вересня 1997 р. N 1057 ( 1057-97-п ) "Про відкриття торговельно-економічної місії у складі Посольства України в Литовській Республіці".

8. Постанова Кабінету Міністрів України від 7 лютого 2001 р. N 108 ( 108-2001-п ) "Про відкриття торговельно-економічних місій у складі дипломатичних представництв України за кордоном" (Офіційний вісник України, 2001 р., N 6, ст. 227).

9. Розпорядження Кабінету Міністрів України від 10 січня 2002 р. N 11 ( 11-2002-р ) "Про відкриття торговельно-економічної місії у складі посольства України в Японії".

10. Розпорядження Кабінету Міністрів України від 14 червня 2002 р. N 327 ( 327-2002-р ) "Про відкриття торговельно-економічної місії у складі Представництва України при Європейських Співтовариствах (Європейському Союзі)".

11. Розпорядження Кабінету Міністрів України від 17 серпня 2002 р. N 466 ( 466-2002-р ) "Про відкриття торговельно-економічних місій у складі дипломатичних представництв України за кордоном".

12. Розпорядження Кабінету Міністрів України від 16 листопада 2002 р. N 653 ( 653-2002-р ) "Про відкриття торговельно-економічної місії у складі Посольства України в Сирійській Арабській Республіці".

13. Розпорядження Кабінету Міністрів України від 24 лютого 2003 р. N 105 ( 105-2003-р ) "Про відкриття торговельно-економічної місії у складі Посольства України в Малайзії".

14. Розпорядження Кабінету Міністрів України від 23 квітня 2003 р. N 230 ( 230-2003-р ) "Про відкриття торговельно-економічної місії у складі дипломатичного представництва України в Республіці Македонія".

15. Розпорядження Кабінету Міністрів України від 15 травня 2003 р. N 278 ( 278-2003-р ) "Про відкриття торговельно-економічної місії у складі Дипломатичного представництва України в Королівстві Нідерланди" (Офіційний вісник України, 2003 р., N 21, ст. 958).

16. Розпорядження Кабінету Міністрів України від 27 червня 2003 р. N 388 ( 388-2003-р ) "Про відкриття торговельно-економічної місії у складі Дипломатичного представництва України в Державі Кувейт".

17. Розпорядження Кабінету Міністрів України від 4 лютого 2004 р. N 46 ( 46-2004-р ) "Про відкриття торговельно-економічних місій у складі дипломатичних представництв України в Грузії, Естонській Республіці, Королівстві Саудівська Аравія, Королівстві Швеція, Мексиканських Сполучених Штатах та Республіці Хорватія".

18. Розпорядження Кабінету Міністрів України від 16 грудня 2004 р. N 923 ( 923-2004-р ) "Про відкриття торговельно-економічної місії у складі дипломатичного представництва України в Республіці Словенія" (Офіційний вісник України, 2004 р., N 51, ст. 3369).
