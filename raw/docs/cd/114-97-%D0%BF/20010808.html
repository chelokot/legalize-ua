Про зміни в стипендіальному забезпеченні студентів і слухачів вищих навчальних закладів

Стан: Втратив чинність

Ідентифікатор: 114-97-п

Текст документа від 08.08.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 лютого 1997 р. N 114 Київ

( Постанова втратила чинність на підставі Постанови КМ N 950 ( 950-2001-п ) від 08.08.2001 )

Про зміни в стипендіальному забезпеченні студентів і слухачів вищих навчальних закладів

( Із змінами, внесеними згідно з Постановою КМ N 1265 ( 1265-97-п ) від 14.11.97 )

З метою впорядкування стипендіального забезпечення студентів і слухачів вищих навчальних закладів, матеріального стимулювання якісного навчання Кабінет Міністрів України постановляє:

Установити, що стипендії студентам і слухачам вищих навчальних закладів виплачуються в межах доведених лімітів стипендіального фонду. В межах доведених лімітів навчальні заклади вирішують питання призначення стипендій, забезпечуючи її виплату в першу чергу студентам і слухачам з числа дітей-сиріт і дітей, що залишилися без піклування батьків, та з малозабезпечених сімей (за умови отримання сім'єю відповідної державної допомоги), а також студентам і слухачам, що мають середній бал успішності 4 і вище. ( Абзац перший із змінами, внесеними згідно з Постановою КМ N 1265 ( 1265-97-п ) від 14.11.97 )

Зазначені ліміти згідно з показниками бюджету на черговий фінансовий рік встановлюються Міністерством фінансів, Радою міністрів Автономної Республіки Крим, обласними, Київською та Севастопольською міськими державними адміністраціями для відповідних органів державного управління освітою, які доводять показники до закладів освіти.
