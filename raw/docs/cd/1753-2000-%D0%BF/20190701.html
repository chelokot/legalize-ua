Відповідно до частин першої та другої статті 14 Закону України "Про державне регулювання виробництва і торгівлі спиртом етиловим, коньячним і плодовим, алкогольними напоями та тютюновими виробами" ( 481/95-ВР ) Кабінет Міністрів України постановляє:

1. Затвердити Порядок надання державним підприємствам повноважень на експорт, імпорт і оптову торгівлю спиртом етиловим і плодовим та включення закладів і підприємств до реєстру закладів охорони здоров'я і підприємств зооветеринарного постачання, які здійснюють оптову торгівлю спиртом етиловим для медичних і ветеринарних цілей (додається).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2010-п ) від 02.03.2010 }

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 30 липня 1996 р. N 850 ( 850-96-п ) "Про порядок надання державним підприємствам повноважень на експорт, імпорт та оптову торгівлю спиртом етиловим, коньячним і плодовим" (ЗП України, 1996 р., N 15, ст. 416);

постанову Кабінету Міністрів України від 24 березня 1999 р. N 450 ( 450-99-п ) "Про утворення Міжвідомчої координаційної ради з монополії на виробництво та обіг спирту, алкогольних напоїв і тютюнових виробів" (Офіційний вісник України, 1999 р., N 12, ст. 482);

пункт 1 змін, що вносяться до деяких постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 21 червня 2000 р. N 1002 ( 1002-2000-п ) (Офіційний вісник України, 2000 р., N 25, ст. 1062).

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 29 листопада 2000 р. N 1753

ПОРЯДОК надання державним підприємствам повноважень на експорт, імпорт і оптову торгівлю спиртом етиловим і плодовим та включення закладів і підприємств до реєстру закладів охорони здоров'я і підприємств зооветеринарного постачання, які здійснюють оптову торгівлю спиртом етиловим для медичних і ветеринарних цілей

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2010-п ) від 02.03.2010 }

1. Цей порядок визначає механізм надання державним підприємствам повноважень на експорт, імпорт і оптову торгівлю спиртом етиловим і плодовим, включення закладів і підприємств до реєстру закладів охорони здоров'я і підприємств зооветеринарного постачання, які здійснюють оптову торгівлю спиртом етиловим для медичних і ветеринарних цілей. { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2010-п ) від 02.03.2010 }

Рішення про надання цим підприємствам і закладам зазначених повноважень та включення до відповідного реєстру приймається Кабінетом Міністрів України. { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2010-п ) від 02.03.2010 }

2. Для отримання державними підприємствами повноважень на експорт, імпорт і оптову торгівлю спиртом етиловим і плодовим, включення закладів і підприємств до реєстру закладів охорони здоров'я і підприємств зооветеринарного постачання, які здійснюють оптову торгівлю спиртом для медичних і ветеринарних цілей, цими підприємствами і закладами подаються заяви із зазначенням у них своєї назви, виду діяльності, дати державної реєстрації, кількості працівників, основних напрямів господарської, в тому числі зовнішньоекономічної діяльності, обсягу товарообігу, розміру прибутку за останній рік. { Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2010-п ) від 02.03.2010 }

До заяви додаються:

реєстраційна картка підприємства (закладу) за формою згідно з додатком;

довідка про стан розрахунків із сплати податків, зборів (внесення обов'язкових платежів), видана органом державної податкової служби за місцезнаходженням заявника;

довідка банку про наявність рахунків у національній та іноземній валюті;

довідка про проведення декларування валютних цінностей, що належать резидентові України і знаходяться за її межами, видана філією Національного банку та органом державної податкової служби за місцезнаходженням заявника;

нотаріально засвідчена копія довідки про включення підприємства (закладу) до Єдиного державного реєстру підприємств та організацій України;

нотаріально засвідчені копії установчих документів;

нотаріально засвідчена копія свідоцтва про державну реєстрацію підприємства (закладу);

лист-клопотання підприємства (закладу) або уповноваженого центрального органу виконавчої влади (якщо підприємство (заклад) належить до сфери його управління) чи відповідного органу місцевого самоврядування (для комунального підприємства);

копія ліцензії на виробництво спирту етилового і плодового (для виробників цієї продукції). { Абзац одинадцятий пункту 2 із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2010-п ) від 02.03.2010 }

Заява та інші документи, передбачені цим пунктом, подаються до ДПС, який після відповідного опрацювання передає їх для розгляду до Кабінету Міністрів України. { Абзац пункту 2 із змінами, внесеними згідно з Постановами КМ N 230 ( 230-2010-п ) від 02.03.2010, N 850 ( 850-2011-п ) від 10.08.2011 }
