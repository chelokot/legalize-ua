Про зупинення дії розпорядження Кабінету Міністрів України від 3 жовтня 2007 року N 809-р

{ Додатково див. Конституційне подання Президента ( n0034100-07 ) від 24.10.2007 }

Кабінетом Міністрів України видано розпорядження від 3 жовтня 2007 року N 809-р ( 809-2007-р ), яким члену Національної комісії з питань регулювання зв'язку України оголошено догану за несумлінне виконання службових обов'язків.

Вирішення Кабінетом Міністрів України питання про притягнення до дисциплінарної відповідальності члена Національної комісії з питань регулювання зв'язку України не відповідає статті 42 Конституції України ( 254к/96-ВР ), згідно з якою види і межі монополії визначаються законом, нормам Законів України "Про природні монополії" ( 1682-14 ), "Про телекомунікації" ( 1280-15 ), за якими Національна комісія з питань регулювання зв'язку України є органом регулювання у сфері зв'язку, членів цієї Комісії призначає за поданням Прем'єр-міністра України на посади та припиняє їх повноваження на цих посадах Президент України, та статті 147-1 Кодексу законів про працю України ( 322-08 ), виходячи з якої притягнення до дисциплінарної відповідальності членів Національної комісії з питань регулювання зв'язку України має здійснюватись з урахуванням вищезазначених особливостей призначення на посади та припинення повноважень членів названої Комісії.

Відтак, вирішення Кабінетом Міністрів України зазначеного питання не відповідає й положенням частини другої статті 6, частини другої статті 19 та частини третьої статті 113 Основного Закону держави ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, діяти в межах повноважень, на підставі та у спосіб, що ними передбачені.

З огляду на викладене відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 3 жовтня 2007 року N 809-р ( 809-2007-р ) "Про притягнення до дисциплінарної відповідальності члена Національної комісії з питань регулювання зв'язку України Єжової Л.М.".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 24 жовтня 2007 року N 1010/2007
