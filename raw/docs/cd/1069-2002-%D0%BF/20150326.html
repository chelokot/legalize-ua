Деякі питання державної компанії "Укрекокомресурси"

Стан: Втратив чинність

Ідентифікатор: 1069-2002-п

Текст документа від 26.03.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 липня 2002 р. N 1069 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 128 ( 128-2015-п ) від 18.03.2015 }

Деякі питання державної компанії "Укрекокомресурси"

( Із змінами, внесеними згідно з Постановою КМ N 1844 ( 1844-2003-п ) від 26.11.2003 )

З метою подальшого поліпшення умов впровадження системи роздільного збирання, комплексної переробки та утилізації відходів як вторинної сировини Кабінет Міністрів України постановляє:

1. На часткову зміну пункту 1 постанови Кабінету Міністрів України від 26 липня 2001 р. N 915 ( 915-2001-п ) "Про впровадження системи збирання, сортування, транспортування, переробки та утилізації відходів як вторинної сировини" (Офіційний вісник України, 2001 р., N 31, ст. 1412) підпорядкувати державну компанію "Укрекокомресурси" (далі - Компанія) Кабінетові Міністрів України.

2. Установити, що контролюючим органом Компанії є наглядова рада, яка здійснює аналіз діяльності Компанії, нагляд за виконанням статутних завдань, затверджує річні звіти, рішення Компанії про утворення, реорганізацію і ліквідацію регіональних відділень, філіалів та представництв, розробляє пропозиції щодо визначення основних напрямів діяльності. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1844 ( 1844-2003-п ) від 26.11.2003 )

3. Компанії подати в місячний термін Кабінетові Міністрів України проект статуту та пропозиції щодо визначення складу наглядової ради.
