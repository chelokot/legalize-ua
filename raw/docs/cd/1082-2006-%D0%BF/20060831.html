Текст документа від 31.08.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 серпня 2006 р. N 1082 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1267 ( 1267-2006-п ) від 31.08.2006 }

Про внесення змін до постанови Кабінету Міністрів України від 26 липня 2006 р. N 1007

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 26 липня 2006 р. N 1007 ( 1007-2006-п ) "Про будівництво залізничної лінії Ізмаїл - Рені" такі зміни:

доповнити постанову вступною частиною такого змісту:

"Кабінет Міністрів України постановляє:"

викласти пункт 3 в такій редакції:

"3. Звільнити залізниці від відрахувань до бюджету у 2006 році частини прибутку (доходу) на суму витрат, що будуть здійснені залізницями у 2006 році для розроблення техніко-економічного обґрунтування, проектування та початку робіт з будівництва залізничної лінії Ізмаїл - Рені і модернізації інфраструктури для посилення пропускної спроможності лінії Одеса - Ізмаїл".

Прем'єр-міністр України Ю.ЄХАНУРОВ
