Про доповнення пункту 4 Положення про Державний департамент з питань банкрутства

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 лютого 2009 р. N 81 Київ

{ Постанова втратила чинність одночасно з набранням чинності Указом Президента ( 395/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Про доповнення пункту 4 Положення про Державний департамент з питань банкрутства

Кабінет Міністрів України постановляє:

Доповнити пункт 4 Положення про Державний департамент з питань банкрутства, затвердженого постановою Кабінету Міністрів України від 19 квітня 2006 р. N 533 ( 533-2006-п ) (Офіційний вісник України, 2006 р., N 16, ст. 1190), підпунктом 15-1 такого змісту:

"15-1) здійснює моніторинг стану задоволення вимог кредиторів щодо виплати заборгованості із заробітної плати з метою використання зазначеної інформації під час здійснення контролю за діяльністю арбітражних керуючих;".

Прем'єр-міністр України Ю.ТИМОШЕНКО
