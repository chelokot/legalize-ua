Кабінет Міністрів України; Розпорядження від 02.09.2010 № 1766-р

Питання віднесення деяких посад працівників Адміністрації Президента України до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 1766-2010-р

Текст документа від 25.05.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 вересня 2010 р. N 1766-р Київ

Питання віднесення деяких посад працівників Адміністрації Президента України до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженням КМ N 446-р ( 446-2011-р ) від 25.05.2011 }

1. Внести до розпоряджень Кабінету Міністрів України від 10 листопада 1994 р. N 828 ( 828-94-р ) і від 2 червня 2010 р. N 1154 ( 1154-2010-р ) "Про віднесення посад працівників Адміністрації Президента України до відповідних категорій посад державних службовців" (Офіційний вісник України, 2010 р., N 42, ст. 1383) зміни, що додаються.

2. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 24 квітня 1998 р. N 264 ( 264-98-р ) і від 9 жовтня 2002 р. N 566 ( 566-2002-р ) "Про віднесення посади радника Глави Адміністрації Президента України до другої категорії посад державних службовців" (Офіційний вісник України, 2002 р., N 41, ст. 1908).

Прем'єр-міністр України М.АЗАРОВ

Інд. 19

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 2 вересня 2010 р. N 1766-р

ЗМІНИ, що вносяться до розпоряджень Кабінету Міністрів України від 10 листопада 1994 р. N 828 ( 828-94-р ) і від 2 червня 2010 р. N 1154 ( 1154-2010-р )

1. У розпорядженні Кабінету Міністрів України від 10 листопада 1994 р. N 828 ( 828-94-р ) слова "Адміністрації Президента України," виключити.
