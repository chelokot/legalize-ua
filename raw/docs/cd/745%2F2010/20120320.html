Про зміну у складі Національного антикорупційного комітету

На часткову зміну статті 1 Указу Президента України від 26 березня 2010 року N 454 ( 454/2010 ) "Питання Національного антикорупційного комітету" (зі змінами, внесеними Указом від 14 травня 2010 року N 626) ( 626/2010 ) увести до складу Національного антикорупційного комітету ІЛЛЯШОВА Григорія Олексійовича - Голову Служби зовнішньої розвідки України.
