Кабінет Міністрів України; Постанова від 01.03.2006 № 226

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для розбудови та модернізації об'єктів митної системи

Стан: Чинний

Ідентифікатор: 226-2006-п

Текст документа від 01.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 2006 р. N 226 Київ

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для розбудови та модернізації об'єктів митної системи

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Установити, що використання у 2006 році коштів, передбачених Державній митній службі за бюджетною програмою "Розбудова та модернізація об'єктів митної системи" ( 3235-15 ), здійснюється відповідно до Порядку використання коштів державного бюджету для розбудови та модернізації об'єктів митної системи, затвердженого постановою Кабінету Міністрів України від 5 вересня 2005 р. N 867 ( 867-2005-п ) (Офіційний вісник України, 2005 р., N 36, ст. 2197).

Прем'єр-міністр України Ю.ЄХАНУРОВ
