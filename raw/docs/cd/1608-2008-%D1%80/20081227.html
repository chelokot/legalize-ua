Кабінет Міністрів України; Розпорядження від 27.12.2008 № 1608-р

Про придбання нерухомого майна для розміщення Посольства України в Республіці Сербія

Стан: Чинний

Ідентифікатор: 1608-2008-р

Текст документа від 27.12.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 грудня 2008 р. N 1608-р Київ

Про придбання нерухомого майна для розміщення Посольства України в Республіці Сербія

1. Погодитися з пропозицією МЗС щодо придбання в 2008 році у державну власність України нерухомого майна у м. Белграді по вул. Пає Адамова, 4, вартістю 3 млн. євро для розміщення Посольства України в Республіці Сербія.

2. Скасувати розпорядження Кабінету Міністрів України від 25 грудня 2002 р. N 712 ( 712-2002-р ) "Про придбання нерухомого майна для розміщення Посольства України в Союзній Республіці Югославія".

Прем'єр-міністр України Ю.ТИМОШЕНКО
