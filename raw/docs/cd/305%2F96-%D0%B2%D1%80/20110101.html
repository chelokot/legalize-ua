ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

{ Постанова втратила чинність на підставі Кодексу N 2755-VI ( 2755-17 ) від 02.12.2010, ВВР, 2011, N 13-14, N 15-16, N 17, ст.112 }

Про внесення зміни до пункту 1 Постанови Верховної Ради

України від 15 вересня 1995 року "Про порядок введення

в дію Закону України "Про акцизний збір на алкогольні напої та тютюнові вироби"

( Відомості Верховної Ради України (ВВР), 1996, N 41, ст. 197 )

Верховна Рада України постановляє:

1. Абзац третій пункту 1 Постанови Верховної Ради України від 15 вересня 1995 року "Про порядок введення в дію Закону України "Про акцизний збір на алкогольні напої та тютюнові вироби" ( 330/95-ВР ) (Відомості Верховної Ради України, 1995 р., N 40, ст. 298) доповнити словами:

"а по алкогольних напоях, вироблених в Україні, із вмістом спирту етилового більш як 25% - з 1 вересня 1996 року".

2. Зазначити, що Кабінет Міністрів України продовжує приймати нормативні акти, які суперечать діючому законодавству. Запропонувати Кабінету Міністрів України негайно привести у відповідність із чинними законодавчими актами постанови Кабінету Міністрів України від 20 червня 1996 року N 665 ( 665-96-п ) "Про зупинення видачі суб'єктам підприємницької діяльності спеціальних дозволів (ліцензій) на виготовлення горілки, горілчаних, лікерних і коньячних виробів", від 20 червня 1996 року N 666 ( 666-96-п ) "Про заходи щодо запровадження марок акцизного збору на алкогольні напої вітчизняного виробництва", від 13 травня 1996 року N 493 ( 493-96-п ) "Про тимчасовий порядок видачі ліцензій на право імпорту, експорту, оптової торгівлі спиртом етиловим, коньячним і плодовим, алкогольними напоями та тютюновими виробами і роздрібної торгівлі алкогольними напоями та тютюновими виробами", розпорядження від 19 лютого 1996 року N 121-р ( 121-96-р ) та інші акти.

3. Ця Постанова набирає чинності з дня опублікування.
