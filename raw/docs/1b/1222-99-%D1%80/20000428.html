Кабінет Міністрів України; Розпорядження від 10.11.1999 № 1222-р

Про внесення змін до розпорядження Кабінету Міністрів України від 6 квітня 1999 р. N 272

Стан: Втратив чинність

Ідентифікатор: 1222-99-р

Текст документа від 28.04.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 листопада 1999 р. N 1222-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 201-р ( 201-2000-р ) від 28.04.2000 )

( Із змінами, внесеними згідно з Розпорядженням КМ N 65-р ( 65-2000-р ) від 01.02.2000 )

1. На часткову зміну розпорядження Кабінету Міністрів України від 6 квітня 1999 р. N 272 ( 272-99-р ) затвердити:

Віце-прем'єр-міністра України Семиноженка Володимира Петровича - керівником міжвідомчої робочої групи з координації роботи та підготовки проектів рішень щодо проведення пенсійної реформи;

Міністра праці та соціальної політики Саханя Івана Яковича - заступником керівника міжвідомчої робочої групи з координації роботи та підготовки проектів рішень щодо проведення пенсійної реформи;

начальника Управління з питань соціальної політики Кабінету Міністрів України Іванкевича Віктора Вікторовича - відповідальним секретарем міжвідомчої робочої групи з координації роботи та підготовки проектів рішень щодо проведення пенсійної реформи та керівником міжвідомчої експертної робочої групи з розроблення пропозицій та проектів законодавчих актів щодо проведення пенсійної реформи;

заступника Міністра праці та соціальної політики - начальника Головного пенсійного управління Гарячу Олену Василівну - заступником керівника міжвідомчої експертної робочої групи з розроблення пропозицій та проектів законодавчих актів щодо проведення пенсійної реформи.

( Пункт 2 втратив чинність на підставі Розпорядження КМ N 65-р ( 65-2000-р ) від 01.02.2000 ) 2. Пункт 4 розпорядження Кабінету Міністрів України від 6 квітня 1999 р. N 272 викласти в такій редакції:

"4. Контроль за виконанням цього розпорядження покласти на Віце-прем'єр-міністра України Семиноженка В.П.".
