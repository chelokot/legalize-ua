Про затвердження інструкцій щодо заповнення форм державних статистичних спостережень N 1-готель, N 1-каналізація

{ Із змінами, внесеними згідно з Наказом Державного комітету статистики N 274 ( z0585-10 ) від 14.07.2010 Наказом Державної служби статистики N 291 ( z1789-13 ) від 01.10.2013 }

Відповідно до статті 14 Закону України "Про державну статистику" ( 2614-12 ) та з метою подальшого удосконалення державних статистичних спостережень за діяльністю підприємств готельного, каналізаційного та водопровідно-каналізаційного господарства НАКАЗУЮ:

1. Затвердити:

Інструкцію щодо заповнення форми державного статистичного спостереження N 1-готель (річна) "Звіт про роботу готелю" (додається).

Інструкцію щодо заповнення форми державного статистичного спостереження N 1-каналізація (річна) "Звіт про роботу каналізації" (додається) ( z0658-04 ).

2. Поширити дію затверджених інструкцій щодо заповнення форм державних статистичних спостережень на такі підприємства:

2.1. Інструкцію щодо заповнення форми державного статистичного спостереження N 1-готель (річна) "Звіт про роботу готелю" - на всіх суб'єктів підприємницької діяльності, які надають місця для короткотермінового проживання приїжджим (терміном до 45 діб) та перебувають на самостійному балансі або на балансі підприємств (організацій) усіх форм власності.

2.2. Інструкцію щодо заповнення форми державного статистичного спостереження N 1-каналізація (річна) "Звіт про роботу каналізації" - на каналізаційні, водопровідно-каналізаційні підприємства, як самостійні, так і ті, що перебувають на балансі підприємств (організацій) усіх видів економічної діяльності, які здійснюють відведення стічних вод від житлових будинків та комунально-побутових, промислових, будівельних, сільськогосподарських та інших підприємств та організацій.

3. З моменту набрання чинності цим наказом скасувати всі роз'яснення, що додаються до форм державних статистичних спостережень N 1-готель, N 1-каналізація, затверджених наказом Держкомстату від 11 липня 2003 року N 215 ( v0215202-03 ).

4. Контроль за виконанням цього наказу покласти на заступника Голови комітету Власенко Н.С.

Голова комітету О.Г.Осауленко
