N 687 ( 687-2006-п ) "Про зупинення дії постанов Кабінету Міністрів України від 11 травня 2006 р. N 665 і N 667" в частині зупинення дії постанови Кабінету Міністрів України від 11 травня 2006 р. N 667 ( 667-2006-п ).
