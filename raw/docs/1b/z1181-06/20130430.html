Про внесення змін до порядків, затверджених наказами Міністерства праці та соціальної політики України від 20.11.2000 N 307 і від 20.11.2000 N 308

Реєстрація: Мін'юст України від 02.11.2006 № 1181/13055

Стан: Чинний

Ідентифікатор: z1181-06

Текст документа від 30.04.2013:

МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

30.10.2006 N 398

Зареєстровано в Міністерстві юстиції України 2 листопада 2006 р. за N 1181/13055

Про внесення змін до порядків, затверджених наказами Міністерства праці та соціальної політики України від 20.11.2000 N 307 і від 20.11.2000 N 308

{ Із змінами, внесеними згідно з Наказом Міністерства соціальної політики N 123 ( z0566-13 ) від 18.03.2013 }

Відповідно до Закону України "Про загальнообов'язкове державне соціальне страхування на випадок безробіття" ( 1533-14 ) та з метою приведення нормативно-правових актів у відповідність до законів України "Про внесення змін до деяких законів України щодо реалізації інвалідами права на трудову зайнятість" ( 3483-15 ) та "Про внесення змін до деяких законів України щодо Державної спеціальної служби транспорту" ( 3428-15 ) НАКАЗУЮ:

1. Унести до Порядку надання допомоги по безробіттю, у тому числі одноразової її виплати для організації безробітними підприємницької діяльності, затвердженого наказом Міністерства праці та соціальної політики України від 20.11.2000 N 307 ( z0915-00 ), зареєстрованого в Міністерстві юстиції України 14.12.2000 за N 915/5136 (із змінами), такі зміни:

1.1. У розділі 2:

1) в абзаці четвертому пункту 2.3 цифри "16" замінити цифрами "18";

2) доповнити новим пунктом 2.12 такого змісту:

"2.12. Допомога по безробіттю інвалідам із числа осіб, зазначених у пункті 2.7 цього Порядку, не призначається".

1.2. У розділі 3:

1) підпункт 4 пункту 3.1 доповнити новим абзацом такого змісту:

"відповідно до Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ) - пенсію по інвалідності";

2) підпункт 2 пункту 3.2 після слів "Службі безпеки України" доповнити словами "Державній спеціальній службі транспорту".

1.3. Доповнити розділ 4 новим пунктом 4.6 такого змісту:

"4.6. Допомога по безробіттю інвалідам з числа осіб, визначених у пункті 4.3, не призначається".

1.4. Підпункт 7 пункту 5.5 розділу 5 викласти в новій редакції:

"7) призначення чи отримання права на призначення пенсії за віком, у тому числі на пільгових умовах, пенсії за вислугу років або досягнення особою встановленого законом пенсійного віку".

{ Пункт 2 втратив чинність на підставі Наказу Міністерства соціальної політики N 123 ( z0566-13 ) від 18.03.2013 }

3. Цей наказ набирає чинності з 1 січня 2007 року, крім абзацу четвертого підпункту 1.2.

Міністр М.Папієв
