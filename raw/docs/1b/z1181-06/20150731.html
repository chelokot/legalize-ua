Зареєстровано в Міністерстві юстиції України 2 листопада 2006 р. за N 1181/13055

Про внесення змін до порядків, затверджених наказами Міністерства праці та соціальної політики України від 20.11.2000 N 307 і від 20.11.2000 N 308

{ Із змінами, внесеними згідно з Наказами Міністерства соціальної політики N 123 ( z0566-13 ) від 18.03.2013 N 613 ( z0821-15 ) від 15.06.2015 }

Відповідно до Закону України "Про загальнообов'язкове державне соціальне страхування на випадок безробіття" ( 1533-14 ) та з метою приведення нормативно-правових актів у відповідність до законів України "Про внесення змін до деяких законів України щодо реалізації інвалідами права на трудову зайнятість" ( 3483-15 ) та "Про внесення змін до деяких законів України щодо Державної спеціальної служби транспорту" ( 3428-15 ) НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства соціальної політики N 613 ( z0821-15 ) від 15.06.2015 }

{ Пункт 2 втратив чинність на підставі Наказу Міністерства соціальної політики N 123 ( z0566-13 ) від 18.03.2013 }

3. Цей наказ набирає чинності з 1 січня 2007 року, крім абзацу четвертого підпункту 1.2.

Міністр М.Папієв
