ЗАКОН УКРАЇНИ

{ Закон втратив чинність на підставі Закону N 145-IX ( 145-20 ) від 02.10.2019, ВВР, 2019, N 46, ст.302 }

Про внесення змін до Закону України "Про перелік об'єктів права державної власності, що не підлягають приватизації"

( Відомості Верховної Ради України (ВВР), 2005, N 48, ст.485 )

Верховна Рада України постановляє:

1. Внести зміни до переліку об'єктів права державної власності, що не підлягають приватизації, затвердженого Законом України "Про перелік об'єктів права державної власності, що не підлягають приватизації" ( 847-14 ) (Відомості Верховної Ради України, 1999 р., N 37, ст. 332; 2001 р., N 48, ст. 255; 2002 р., N 11, ст. 82, N 14, ст. 94, N 29, ст. 196, ст. 197; 2003 р., N 39, ст. 337, ст. 338, ст. 339; 2004 р., N 22, ст. 310, ст. 311; 2005 р., N 1, ст. 16, ст. 17, ст. 18, N 2, ст. 29, N 9, ст. 171), згідно з додатком.

2. Цей Закон набирає чинності з дня його опублікування.
