КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 серпня 2004 р. N 1132 Київ

Про нагородження Почесною грамотою Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 1387 ( 1387-2024-п ) від 05.12.2024 }

Кабінет Міністрів України постановляє:

За вагомий особистий внесок у розвиток вугільної промисловості нагородити Почесною грамотою Кабінету Міністрів України з врученням пам'ятного знака КОЛЕСОВА Ореста Андрійовича, ГРИНЬКО Миколу Костянтиновича, ПОЛТАВЦЯ Віктора Івановича, ПОЛЯКОВА Сергія Васильовича, РУСАНЦОВА Юрія Олександровича, СУРГАЯ Миколу Сафоновича, ЯНКА Станіслава Васильовича, ГАЙДУКА Віталія Анатолійовича, ЄРМІЛОВА Сергія Федоровича, СТАШЕВСЬКОГО Станіслава Телісфоровича.

{ Постанова із змінами, внесеними згідно з Постановою КМ N 1387 ( 1387-2024-п ) від 05.12.2024 }
