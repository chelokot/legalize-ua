Текст документа від 11.06.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 листопада 2007 р. N 958-р Київ

Про підготовку та проведення в Україні VI чемпіонату Європи з футболу серед студентів

{ Із змінами, внесеними згідно з Розпорядженням КМ N 818-р ( 818-2008-р ) від 11.06.2008 }

1. З метою забезпечення підготовки та проведення в Україні (м. Київ та Київська область) в липні 2008 р. VI чемпіонату Європи з футболу серед студентів утворити Організаційний комітет у складі згідно з додатком.

Призначити Віце-прем'єр-міністра України Васюника Івана Васильовича головою Організаційного комітету, надавши йому право вносити у разі потреби зміни до складу Комітету.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 818-р ( 818-2008-р ) від 11.06.2008 }

2. Організаційному комітетові розробити і затвердити у місячний строк план заходів з підготовки та проведення в Україні VI чемпіонату Європи з футболу серед студентів.

3. МОН і Мінсім'ямолодьспорту разом із заінтересованими центральними органами виконавчої влади, Київською міською та Київською обласною держадміністраціями забезпечити фінансування в установленому порядку заходів з підготовки та проведення в Україні VI чемпіонату Європи з футболу серед студентів.

Прем'єр-міністр України В.ЯНУКОВИЧ
