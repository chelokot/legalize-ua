Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 17 листопада 2004 р. N 1571

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

{ Пункт 1 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

2. Доповнити пункт 3 переліку центральних органів виконавчої влади, відповідальних за виконання зобов'язань, що випливають із членства України в міжнародних організаціях, затвердженого постановою Кабінету Міністрів України від 13 вересня 2002 р. N 1371 ( 1371-2002-п ) (Офіційний вісник України, 2002 р., N 38, ст. 1776) після позиції

"Вассенаарська домовленість МЗС, Мінекономіки, СБУ, Держмитслужба"

такою позицією:

"Гаазька конференція з Мін'юст, МЗС, МВС, міжнародного приватного права Мінсім'ядітимолодь, Генеральна прокуратура України (за згодою)".
