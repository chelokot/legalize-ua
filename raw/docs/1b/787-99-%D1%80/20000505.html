Кабінет Міністрів України; Розпорядження від 09.08.1999 № 787-р

Про митне оформлення вантажів, що надходять на адресу ВАТ "Запоріжтрансформатор"

Стан: Втратив чинність

Ідентифікатор: 787-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 серпня 1999 р. N 787-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Для збереження експортного потенціалу підприємства-виготовлювача електротехнічного обладнання в Україні, яким є ВАТ "Запоріжтрансформатор", дозволити Держмитслужбі здійснити митне оформлення вантажів, що надходять на адресу цього підприємства для власних виробничих потреб відповідно до контрактів, укладених з інофірмами згідно з додатком, як товарів критичного імпорту.
