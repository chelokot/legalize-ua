Кабінет Міністрів України; Розпорядження від 12.11.2008 № 1422-р

Про зміни складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів соціального страхування

Стан: Втратив чинність

Ідентифікатор: 1422-2008-р

Текст документа від 11.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 листопада 2008 р. N 1422-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 19-р ( 19-2012-р ) від 11.01.2012 }

Про зміни складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів соціального страхування

Внести до складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах Фонду соціального страхування від нещасних випадків на виробництві та професійних захворювань, затвердженого розпорядженням Кабінету Міністрів України від 15 вересня 2006 р. N 488 ( 488-2006-р ) (Офіційний вісник України, 2006 р., N 38, ст. 2597; 2008 р., N 15, ст. 395), Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття, затвердженого розпорядженням Кабінету Міністрів України від 21 лютого 2007 р. N 59 ( 59-2007-р ) (Офіційний вісник України, 2007 р., N 14, ст. 536; 2008 р., N 15, ст. 396), та Фонду соціального страхування з тимчасової втрати працездатності, затвердженого розпорядженням Кабінету Міністрів України від 14 листопада 2007 р. N 996 ( 996-2007-р ) (Офіційний вісник України, 2007 р., N 88, ст. 3222), зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 26

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 12 листопада 2008 р. N 1422-р
