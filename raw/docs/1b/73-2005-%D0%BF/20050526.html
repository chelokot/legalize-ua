Стан: Втратив чинність

Текст документа від 26.05.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 січня 2005 р. N 73 Київ

( Постанова втратила чинність на підставі Постанови КМ N 378 ( 378-2005-п ) від 26.05.2005 )

Про внесення зміни до пункту 3 постанови Кабінету Міністрів України від 23 грудня 2004 р. N 1725

Кабінет Міністрів України постановляє:

Пункт 3 постанови Кабінету Міністрів України від 23 грудня 2004 р. N 1725 ( 1725-2004-п ) "Про затвердження технічного опису і зразка бланка паспорта громадянина України для виїзду за кордон" викласти у такій редакції:

"3. Установити, що:

оформлення паспортів громадян України для виїзду за кордон попереднього зразка може здійснюватися до повного використання залишків раніше замовлених і виготовлених бланків таких паспортів;

паспорти громадян України для виїзду за кордон попереднього зразка використовуються до закінчення строку їх дії".
