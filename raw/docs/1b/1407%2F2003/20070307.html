{ Указ втратив чинність на підставі Указу Президента N 118/2007 ( 118/2007 ) від 19.02.2007 }

Про внесення зміни до Указу Президента України від 30 жовтня 1996 року N 1015

Внести зміну до статті 3 Указу Президента України від 30 жовтня 1996 року N 1015 ( 1015/96 ) "Про заходи щодо поліпшення виставкової діяльності в Україні" (зі змінами, внесеними Указами від 22 січня 2001 року N 31 ( 31/2001 ) та від 30 жовтня 2001 року N 1019 ( 1019/2001 ), виклавши перше речення в такій редакції:

"Членами Ради за посадою є: заступник Міністра аграрної політики України, заступник Міністра економіки та з питань європейської інтеграції України, заступник Міністра закордонних справ України, заступник Міністра культури і мистецтв України, заступник Міністра освіти і науки України, заступник Міністра промислової політики України, заступник Міністра фінансів України, заступник Міністра юстиції України, заступник Голови Державного комітету зв'язку та інформатизації України, заступник Голови Державного комітету статистики України, заступник Голови Державного комітету України з питань технічного регулювання та споживчої політики, заступник Голови Державної митної служби України, віце-президент Національної академії наук України (за згодою), віце-президент Торгово-промислової палати України (за згодою), заступник голови Київської міської державної адміністрації".

Президент України Л.КУЧМА

м. Київ, 5 грудня 2003 року N 1407/2003
