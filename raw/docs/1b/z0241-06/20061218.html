{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 1105 ( z1284-06 ) від 23.11.2006 }

Про затвердження Змін до Порядку створення системи та плану нумерації телефонної мережі загального користування України

Відповідно до статті 15 Закону України "Про телекомунікації" ( 1280-15 ) та з метою забезпечення подальшого розвитку мереж рухомого (мобільного) зв'язку в Україні НАКАЗУЮ:

1. Затвердити Зміни до Порядку створення системи та плану нумерації телефонної мережі загального користування України, затвердженого наказом Державного комітету зв'язку та інформатизації України від 25.06.99 N 124 ( z0644-99 ), зареєстрованого у Міністерстві юстиції України 23.09.99 за N 644/3937, що додаються.

2. Державному департаменту з питань зв'язку та інформатизації (Бутенко Г.Г.):

2.1. Подати цей наказ на державну реєстрацію до Міністерства юстиції України.

2.2. Забезпечити розміщення цього наказу на Web-сайті Держзв'язку.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Гандабуру В.Т.

Міністр В.Бондар
