Кабінет Міністрів України; Розпорядження від 11.03.2011 № 211-р

Про затвердження фінансового плану та основних показників руху коштів Національної акціонерної компанії "Нафтогаз України" як окремої юридичної особи на 2011 рік

Стан: Чинний

Ідентифікатор: 211-2011-р

Текст документа від 09.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 березня 2011 р. N 211-р Київ

Про затвердження фінансового плану та основних показників руху коштів Національної акціонерної компанії "Нафтогаз України" як окремої юридичної особи на 2011 рік

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1061-р ( 1061-2011-р ) від 17.10.2011 N 1375-р ( 1375-2011-р ) від 09.11.2011 }

1. Затвердити фінансовий план та основні показники руху коштів Національної акціонерної компанії "Нафтогаз України" як окремої юридичної особи (далі - Компанія) на 2011 рік, що додаються до оригіналу.

{ Нову редакцію фінансового плану та основних показників руху коштів Національної акціонерної компанії "Нафтогаз України" як окремої юридичної особи на 2011 рік див. в Розпорядженнях КМ N 1061-р ( 1061-2011-р ) від 17.10.2011, N 1375-р ( 1375-2011-р ) від 09.11.2011 }

2. Міністерству фінансів здійснити відповідно до затвердженого фінансового плану Компанії на 2011 рік випуск облігацій внутрішньої державної позики в обсязі 12500000 тис. гривень з подальшим придбанням у державну власність в обмін на зазначені облігації акцій додаткової емісії Компанії. { Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 1061-р ( 1061-2011-р ) від 17.10.2011 }

3. Міністерству енергетики та вугільної промисловості у разі несвоєчасного або не в повному обсязі здійснення заходів, передбачених планом співпраці Уряду України і Міжнародного валютного фонду на 2011 рік та включених до фінансового плану Компанії на 2011 рік, подати Кабінетові Міністрів України пропозиції щодо внесення змін до зазначеного фінансового плану.

Прем'єр-міністр України М.АЗАРОВ
