МІНІСТЕРСТВО ЕКОНОМІКИ УКРАЇНИ

НАКАЗ

22.07.2005 N 217

Зареєстровано в Міністерстві юстиції України 5 вересня 2005 р. за N 984/11264

Про визнання такими, що втратили чинність, деяких наказів Міністерства економіки та з питань європейської інтеграції України

Відповідно до Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

наказ Міністерства економіки та з питань європейської інтеграції України від 30.01.2002 N 31 ( z0087-02 ) "Про Порядок ліцензування експорту труб з чорних металів, походженням з України, до Російської Федерації", зареєстрований у Міністерстві юстиції України 01.02.2002 за N 87/6375;

наказ Міністерства економіки та з питань європейської інтеграції України від 15.10.2003 N 282 ( z0948-03 ) "Про Тимчасовий порядок видачі разових ліцензій на імпорт спирту коньячного", зареєстрований у Міністерстві юстиції України 17.10.2003 за N 948/8269;

наказ Міністерства економіки та з питань європейської інтеграції України від 18.02.2002 N 48 ( z0178-02 ) "Про ліцензування імпорту в Україну плит, листів, плівки та платівки з поліуретанів походженням з Російської Федерації, Республіки Білорусь, Литовської Республіки, Республіки Польща, Чеської Республіки та Угорської Республіки", зареєстрований у Міністерстві юстиції України 22.02.2002 за N 178/6466;

наказ Міністерства економіки та з питань європейської інтеграції України від 18.02.2002 N 49 ( z0177-02 ) "Про ліцензування імпорту в Україну хутра штучного та полотна ворсового з Республіки Білорусь, Китайської Народної Республіки (у тому числі з Гонконгу /Сянгану/, Макао /Аоміню/, Тайваню), Російської Федерації та Угорської Республіки", зареєстрований у Міністерстві юстиції України 22.02.2002 за N 177/6465;

наказ Міністерства економіки та з питань європейської інтеграції України від 22.03.2002 N 80 ( z0321-02 ) "Про ліцензування імпорту в Україну ламп електричних походженням з Республіки Білорусь, Республіки Польща, Російської Федерації та Угорської Республіки", зареєстрований у Міністерстві юстиції України 01.04.2002 за N 321/6609;

наказ Міністерства економіки та з питань європейської інтеграції України від 05.07.2002 N 200 ( z0585-02 ) "Про застосування спеціальних заходів щодо імпорту в Україну шприців з голками чи без голок з пластмасових матеріалів", зареєстрований у Міністерстві юстиції України 15.07.2002 за N 585/6873;

наказ Міністерства економіки та з питань європейської інтеграції України від 02.09.2003 N 239 ( z0783-03 ) "Про застосування спеціальних заходів щодо імпорту в Україну шприців з голками чи без голок з пластмасових матеріалів", зареєстрований у Міністерстві юстиції України 10.09.2003 за N 783/8104;

наказ Міністерства економіки та з питань європейської інтеграції України від 11.07.2002 N 207 ( z0586-02 ) "Про затвердження Переліку товарів, експорт яких здійснюється за умови реєстрації зовнішньоекономічних договорів (контрактів)", зареєстрований у Міністерстві юстиції України 16.07.2002 за N 586/6874;

наказ Міністерства економіки та з питань європейської інтеграції України від 31.01.2004 N 35 ( z0142-04 ) "Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 11.07.2002 N 207", зареєстрований у Міністерстві юстиції України 02.02.2004 за N 142/8741.
