Про затвердження Порядку здійснення митного оформлення важких дистилятів (дизельного палива)

{ Із змінами, внесеними згідно з Наказом Державної митної служби

N 190 ( z0318-10 ) від 03.03.2010 }

Відповідно до пункту 7 Положення про Державну митну службу України, затвердженого постановою Кабінету Міністрів України від 18.07.2007 N 940 ( 940-2007-п ), та на виконання чистини другої пункту 2 постанови Кабінету Міністрів України від 21.03.2007 N 545 ( 545-2007-п ) "Деякі питання проведення обліку, зберігання та реалізації дизельного палива залежно від вмісту масової частки сірки" НАКАЗУЮ:

1. Затвердити Порядок здійснення митного оформлення важких дистилятів (дизельного палива) (далі - Порядок), що додається.

{ Пункт 2 виключено на підставі Наказу Державної митної служби N 190 ( z0318-10 ) від 03.03.2010 }

3. Департаменту декларування та митних режимів (Науменко В.П.) і Юридичному департаменту (Небрат Л.М.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Регіональній інформаційній митниці (Копосов С.А.), Департаменту декларування та митних режимів (Науменко В.П.), Департаменту митної статистики (Овдієнко Н.Т.), Енергетичній регіональній митниці (Конєв О.І.) у десятиденний строк узгодити форму окремого реєстру відомостей про масову частку сірки у важких дистилятах (дизельному паливі) та внести відповідні зміни до наказу Держмитслужби України від 29.11.2006 N 1063 ( v_063342-06 ) "Про затвердження специфікацій форматів електронних повідомлень".

5. Департаменту митної статистики (Овдієнко Н.Т.), Регіональній інформаційній митниці (Копосов С.А.) у місячний строк забезпечити внесення змін до Протоколу погодження реквізитів та способу обміну інформацією між Державною митною службою України та Державною податковою адміністрацією України від 16.08.2004 N 8.

6. Регіональній інформаційній митниці (Копосов С.А.) після підписання Протоколу про внесення змін до Протоколу погодження реквізитів та способу обміну інформацією між Державною митною службою України та Державною податковою адміністрацією України від 16.08.2004 N 8 забезпечити інформування органів Державної податкової служби України протягом трьох днів після митного оформлення важких дистилятів (дизельного палива) про обсяги ввезених на митну територію України важких дистилятів (дизельного палива) окремо за кожним видом, залежно від умісту масової частки сірки в розрізі окремих партій та імпортерів.

7. Центральному митному управлінню лабораторних досліджень та експертної роботи (Рамусь І.П.) після забезпечення обладнанням інформувати Енергетичну регіональну митницю та митні органи про можливість проведення експертиз важких дистилятів (дизельного палива) на вміст масової частки сірки експертними підрозділами Управління.

8. Начальникам регіональних митниць, митниць інформувати суб'єктів зовнішньоекономічної діяльності про вимоги цього наказу та забезпечити його виконання.

9. Установити, що цей наказ набирає чинності через 10 днів після його державної реєстрації в Міністерстві юстиції України.

10. Контроль за виконанням наказу покласти на першого заступника Голови Служби Черкасського Р.А.

Голова Державної митної служби України О.Б.Єгоров

ПОРЯДОК здійснення митного оформлення важких дистилятів (дизельного палива)

1. Митне оформлення важких дистилятів (дизельного палива) здійснюється відповідно до Митного кодексу України ( 92-15 ), постанов Кабінету Міністрів України від 21.03.2007 N 545 ( 545-2007-п ) "Деякі питання проведення обліку, зберігання та реалізації дизельного палива залежно від вмісту масової частки сірки", від 17.12.2003 N 1958 ( 1958-2003-п ) "Про митний контроль та митне оформлення природного газу, нафти, нафтопродуктів, етилену і аміаку, що переміщуються через митний кордон України трубопровідним транспортом", Положення про вантажну митну декларацію, затвердженого постановою Кабінету Міністрів України від 09.06.97 N 574 ( 574-97-п ), Порядку здійснення митного контролю й митного оформлення товарів із застосуванням вантажної митної декларації, затвердженого наказом Державної митної служби України від 20.04.2005 N 314 ( z0439-05 ), зареєстрованого в Міністерстві юстиції України 27.04.2005 за N 439/10719, та з урахуванням особливостей, визначених цим Порядком.

2. Терміни вживаються в цьому Порядку в такому значенні:

важкі дистиляти (дизельне паливо) - товари, на які згідно із Законом України "Про ставки акцизного збору і ввізного мита на деякі товари (продукцію)" ( 313/96-ВР ) (зі змінами) установлені ставки акцизного збору залежно від умісту масової частки сірки.

{ Абзац третій пункту 2 виключено на підставі Наказу Державної митної служби N 190 ( z0318-10 ) від 03.03.2010 }

{ Пункт 3 виключено на підставі Наказу Державної митної служби N 190 ( z0318-10 ) від 03.03.2010 }

{ Пункт 4 виключено на підставі Наказу Державної митної служби N 190 ( z0318-10 ) від 03.03.2010 }

5. Під час здійснення митного контролю важких дистилятів (дизельного палива), що ввозяться на митну територію України, посадова особа митного органу може відбирати зразки важких дистилятів (дизельного палива) для проведення в установленому порядку експертизи щодо вмісту масової частки сірки.

6. Відбір зразків проводиться відповідно до вимог статті 75 Митного кодексу України ( 92-15 ) та Порядку взяття (надання) проб і зразків товарів, проведення досліджень (аналізу, експертизи) з метою їх митного оформлення, а також розпорядження зразками, затвердженого постановою Кабінету Міністрів України від 12.12.2002 N 1862 ( 1862-2002-п ) (зі змінами).

7. Експертиза важких дистилятів (дизельного палива) на вміст масової частки сірки проводиться експертними підрозділами Центрального митного управління лабораторних досліджень та експертної роботи, регіональних служб з експертного забезпечення та Енергетичної регіональної митниці, які мають матеріально-технічну базу для визначення масової частки сірки.

8. Якщо за результатами проведення експертизи буде встановлена невідповідність задекларованих відомостей щодо масової частки сірки у важких дистилятах (дизельному паливі) показникам, зазначеним у паспорті якості та сертифікаті відповідності, то для визначення виду важких дистилятів (дизельного палива) застосовуються результати зазначеної експертизи.

9. Результати експертизи можуть бути оскаржені в судовому порядку.
