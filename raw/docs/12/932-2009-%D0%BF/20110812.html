ПОСТАНОВА від 3 вересня 2009 р. N 932 Київ

Кабінет Міністрів України постановляє:

Затвердити Порядок формування переліку товарів для будівництва і оснащення спортивних споруд з метою забезпечення проведення фінальної частини чемпіонату Європи 2012 року з футболу в Україні, при ввезенні яких на митну територію України ввізне мито не справляється (додається).

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 44

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 3 вересня 2009 р. N 932

ПОРЯДОК формування переліку товарів (крім підакцизних) для будівництва і оснащення спортивних споруд з метою забезпечення проведення фінальної частини чемпіонату Європи 2012 року з футболу в Україні, при ввезенні яких на митну територію України ввізне мито не справляється

1. Цей Порядок визначає механізм формування переліку товарів (крім підакцизних), які не виробляються в Україні або виробляються, але не відповідають технічним характеристикам світового рівня та вимогам міжнародних спортивних організацій, для будівництва і оснащення (придбання обладнання та інвентарю) спортивних споруд з метою забезпечення проведення фінальної частини чемпіонату Європи 2012 року з футболу в Україні, при ввезенні яких на митну територію України ввізне мито не справляється відповідно до пункту "щ-1" частини першої статті 19 Закону України "Про єдиний митний тариф" ( 2097-12 ) (далі - товари).

2. Суб'єкт господарювання подає Укрєвроінфрапроекту заяву про включення товарів до переліку, в якій зазначається назва спортивної споруди, для будівництва і оснащення якої ввозиться товар. { Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 379 ( 379-2011-п ) від 06.04.2011 }

До заяви додаються:

засвідчені в установленому порядку копії установчих документів та виписка або витяг з Єдиного державного реєстру юридичних осіб та фізичних осіб - підприємців; { Абзац третій пункту 2 в редакції Постанови КМ N 849 ( 849-2011-п ) від 10.08.2011 }

копія:

- довідки Державного агентства з управління державними корпоративними правами та майном про те, що певний товар не виробляється в Україні або виробляється, але не відповідає технічним характеристикам світового рівня; { Абзац п'ятий пункту 2 із змінами, внесеними згідно з Постановою КМ N 379 ( 379-2011-п ) від 06.04.2011 }

- документа, що підтверджує участь суб'єкта господарювання у виконанні Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженої постановою Кабінету Міністрів України від 14 квітня 2010 р. N 357 ( 357-2010-п ) (Офіційний вісник України, 2010 р., N 39, ст. 1297); { Абзац шостий пункту 2 із змінами, внесеними згідно з Постановою КМ N 466 ( 466-2010-п ) від 16.06.2010 }

- договору (контракту), укладеного між отримувачем товарів і постачальником;

- довідки суб'єкта господарювання про найменування, вартість, технічні характеристики, обсяг поставок товарів, коди товарів згідно з УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 );

- виданої замовником будівництва спортивних споруд, на яких передбачається проводити заходи фінальної частини чемпіонату Європи 2012 року з футболу в Україні, довідки про те, що товари включені до проектно-кошторисної документації.

3. Укрєвроінфрапроект надсилає копію документа, в якому зазначаються найменування товарів, їх технічні характеристики та коди згідно з УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ), Держмитслужбі для опрацювання в частині відповідності товарів зазначеним кодам.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 379 ( 379-2011-п ) від 06.04.2011 }

4. Після перевірки документів, зазначених у пункті 2 цього Порядку, Укрєвроінфрапроект за погодженням з Мінфіном, Міністерством економічного розвитку і торгівлі, Держмитслужбою та Державною податковою службою подає в установленому порядку проект постанови Кабінету Міністрів України щодо затвердження переліку та обсягів товарів.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 379 ( 379-2011-п ) від 06.04.2011 }

5. Суб'єкт господарювання після звільнення товарів від сплати мита та ввезення їх на митну територію України подає щомісяця до 5 числа митному органові, що здійснював митне оформлення товару, погоджений з Укрєвроінфрапроектом звіт про цільове використання товарів у двох примірниках. { Абзац перший пункту 5 із змінами, внесеними згідно з Постановою КМ N 379 ( 379-2011-п ) від 06.04.2011 }

Один примірник звіту залишається митному органові, другий - з відміткою зазначеного органу суб'єкт господарювання подає щомісяця до 15 числа органові державної податкової служби за місцем реєстрації такого суб'єкта.

6. Орган державної податкової служби інформує митний орган, що здійснював митне оформлення товару, про факти нецільового використання товарів.

Митний орган в установленому порядку вживає заходів до стягнення сум несплаченого ввізного мита.
