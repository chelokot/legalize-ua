Кабінет Міністрів України; Постанова від 18.08.2000 № 1278

Про заходи щодо впровадження проекту спільного кредитування комерційними банками енергогенеруючих компаній

Стан: Втратив чинність

Ідентифікатор: 1278-2000-п

Текст документа від 29.06.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 серпня 2000 р. N 1278 Київ

Про заходи щодо впровадження проекту спільного кредитування комерційними банками енергогенеруючих компаній

( Із змінами, внесеними згідно з Постановою КМ N 743 ( 743-2001-п ) від 29.06.2001 )

Кабінет Міністрів України постановляє:

1. Міністерству палива та енергетики, використовуючи механізм управління державними корпоративними правами, вжити заходів щодо відкриття енергогенеруючими компаніями в установах відкритого акціонерного товариства "Державний ощадний банк України" поточних рахунків у національній валюті із спеціальним режимом використання, що функціонують незалежно від наявності першочергових претензій до них, з метою накопичення на них цільових коштів для погашення кредитів, отриманих в комерційних банках, що входять до банківського консорціуму, створеного відкритим акціонерним товариством "Державний ощадний банк України" згідно з Порядком визначення уповноваженого банку, в якому відкриваються розподільчі рахунки для зарахування коштів за електричну енергію, затвердженим постановою Кабінету Міністрів України від 19 липня 2000 р. N 1136 ( 1136-2000-п ) (Офіційний вісник України, 2000 р., N 29, ст. 1227), для створення запасів палива, вивезення відпрацьованого ядерного палива та поповнення обігових коштів енергогенеруючих компаній. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 743 ( 743-2001-п ) від 29.06.2001 )

2. Просити Національний банк розробити та затвердити у п'ятиденний термін спеціальний режим використання рахунків, зазначених у пункті 1 цієї постанови.

3. Національній комісії регулювання електроенергетики вирішити у п'ятиденний термін питання про внесення зміни до алгоритму розподілу коштів по розподільчому рахунку державного підприємства "Енергоринок" з метою забезпечення щоденного надходження коштів на зазначені у пункті 1 цієї постанови поточні рахунки енергогенеруючих компаній у сумі, погодженій з відкритим акціонерним товариством "Державний ощадний банк України".

4. Міністерству палива та енергетики, Державній податковій адміністрації, Міністерству фінансів, Міністерству економіки, Ощадному банку щокварталу здійснювати перевірки спрямування коштів, що акумулюються на поточних рахунках із спеціальним режимом використання електроенергетичних підприємств. У разі виявлення фактів використання цих коштів не за призначенням внести Кабінетові Міністрів України пропозиції щодо припинення дії цієї постанови. ( Постанову доповнено пунктом 4 згідно з Постановою КМ N 743 ( 743-2001-п ) від 29.06.2001 )
