Про генерального державного замовника і керівника Національної програми інформатизації

Стан: Втратив чинність

Ідентифікатор: 1377-99-п

Текст документа від 24.01.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 липня 1999 р. N 1377 Київ

( Постанова втратила чинність на підставі Постанови КМ N 91 ( 91-2005-п ) від 24.01.2005 )

Про генерального державного замовника і керівника Національної програми інформатизації

( Із змінами, внесеними згідно з Розпорядженням КМ N 571-р ( 571-2001-р ) від 13.12.2001 )

Відповідно до статей 10 і 11 Закону України "Про Національну програму інформатизації" ( 74/98-ВР ) Кабінет Міністрів України постановляє:

1. Покласти на Державний комітет зв'язку та інформатизації функції генерального державного замовника Національної програми інформатизації.

2. Призначити Проживальського Олега Петровича - заступника Голови Держкомзв'язку керівником Національної програми інформатизації. ( Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 571-р ( 571-2001-р ) від 13.12.2001 )

3. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України від 7 квітня 1998 р. N 470 ( 470-98-п ) "Про Генерального державного замовника Національної програми інформатизації" та від 27 квітня 1998 р. N 560 ( 560-98-п ) "Про Керівника Національної програми інформатизації'.
