МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

10.01.2006 N 19

Зареєстровано в Міністерстві юстиції України 16 січня 2006 р. за N 30/11904

Про втрату чинності наказу Міністерства транспорту України від 19.08.2003 N 650

Відповідно до Положення про Міністерство транспорту та зв'язку України, затвердженого Указом Президента України від 27.08.2004 N 1009 ( 1009/2004 ), та Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства транспорту України від 19.08.2003 N 650 ( z0754-03 ) "Про затвердження Положення про систему управління безпекою польотів на авіаційному транспорті", зареєстрований в Міністерстві юстиції України 29.08.2003 за N 754/8075.

2. Юридичному департаменту (Ониськів М.М.) забезпечити подання цього наказу в установленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Рябікіна П.Б.

Міністр В.Бондар
