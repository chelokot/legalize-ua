Кабінет Міністрів України; Розпорядження від 17.02.2010 № 249-р

Про заходи щодо удосконалення державного регулювання та посилення контролю у сфері виготовлення бланків цінних паперів і документів суворої звітності

Стан: Втратив чинність

Ідентифікатор: 249-2010-р

Текст документа від 20.03.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 лютого 2010 р. N 249-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 268 ( 268-2010-п ) від 17.03.2010 }

Про заходи щодо удосконалення державного регулювання та посилення контролю у сфері виготовлення бланків цінних паперів і документів суворої звітності

{ Із змінами, внесеними згідно з Постановою КМ N 218 ( 218-2010-п ) від 02.03.2010 }

1. З метою удосконалення державного регулювання та посилення контролю у сфері виготовлення бланків цінних паперів і документів суворої звітності, а також удосконалення системи державного управління у зазначеній сфері утворити на базі майна державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів", що ліквідується, казенне підприємство "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" та передати підприємство в управління Кабінету Міністрів України. { Пункт 1 із змінами, внесеними згідно з Постановою КМ N 218 ( 218-2010-п ) від 02.03.2010 }

2. Установити, що основними завданнями казенного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" є виготовлення бланків цінних паперів і документів суворої звітності в обсягах, що відповідають потребам держави.

3. Міністерству фінансів:

подати у тижневий строк на затвердження Кабінету Міністрів України проект Статуту казенного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів";

вжити організаційних заходів до ліквідації державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів". { Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 218 ( 218-2010-п ) від 02.03.2010 }
