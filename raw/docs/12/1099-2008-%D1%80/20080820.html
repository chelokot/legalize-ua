Про відпуск розброньованої спеціальної ветеринарної техніки мобілізаційного резерву для ліквідації наслідків стихійного лиха, що сталося 23-27 липня 2008 року

Стан: Чинний

Ідентифікатор: 1099-2008-р

Текст документа від 20.08.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 серпня 2008 р. N 1099-р Київ

Про відпуск розброньованої спеціальної ветеринарної техніки мобілізаційного резерву для ліквідації наслідків стихійного лиха, що сталося 23-27 липня 2008 року

1. З метою проведення протиепізоотичних заходів у зоні стихійного лиха, що сталося 23-27 липня 2008 р., дозволити Держкомрезерву відпустити Держкомветмедицини розброньовані два спецавтомобілі ДУК ГАЗ-52-01 мобілізаційного резерву за обліковими цінами.

2. Виділити Держкомветмедицини 14,254 тис. гривні з резервного фонду державного бюджету ( 107-17 ) для відшкодування вартості відпущених спецавтомобілів.

Мінфіну у двотижневий строк профінансувати зазначені видатки.

3. Держкомветмедицини подати до кінця 2008 року Мінекономіки, Мінфіну та Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.
