РОЗПОРЯДЖЕННЯ від 12 березня 2008 р. N 430-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Про віднесення посад працівників Центру нормопроектного забезпечення діяльності Президента України до відповідних категорій посад державних службовців

На виконання Указу Президента України від 4 лютого 2008 р. N 83 ( 83/2008 ) та відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Центру нормопроектного забезпечення діяльності Президента України до таких категорій посад державних службовців:

третя - перший заступник керівника Центру, заступник керівника Центру, завідувач сектору, головний консультант, старший консультант, головний спеціаліст;

четверта - провідний спеціаліст.
