Про затвердження Змін до деяких нормативно-правових актів МВС з питань діяльності Державтоінспекції

{ Із змінами, внесеними згідно з Наказом Міністерства внутрішніх справ N 1330 ( z0037-17 ) від 21.12.2016 }

Відповідно до Закону України від 17.03.2011 N 3163-VI ( 3163-17 ) "Про внесення змін до деяких законодавчих актів України щодо скасування талона до посвідчення водія та вдосконалення регулювання відносин у сфері забезпечення безпеки дорожнього руху", з метою приведення нормативно-правових актів МВС України у відповідність до вимог законодавства НАКАЗУЮ:

1. Затвердити Зміни до деяких нормативно-правових актів МВС з питань діяльності Державтоінспекції, що додаються.

2. Управлінню Державтоінспекції МВС (Лозовий В.М.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України у визначений законодавством термін.

3. Визнати такими, що втратили чинність, накази МВС від 02.04.94 N 166 ( z0107-94 ) "Про затвердження зразка талона до посвідчення водія, Положення про талон до посвідчення водія та внесення доповнень до Інструкції про порядок приймання екзаменів, оформлення видачі (обміну) посвідчень водія, обліку та зберігання документів, які стосуються екзаменаційної роботи", зареєстрований у Міністерстві юстиції України 24.05.94 за N 107/316, та від 03.10.2000 N 672 ( z0726-00, z0727-00 ) "Про затвердження зразка талона до посвідчення водія та внесення змін і доповнень до Положення про талон до посвідчення водія, затвердженого наказом МВС України від 02.04.94 N 166", зареєстрований в Міністерстві юстиції України 20.10.2000 за N 726/4947.

4. Контроль за виконанням цього наказу покласти на першого заступника Міністра внутрішніх справ генерал-лейтенанта міліції Попкова С.Є.

5. Наказ оголосити особовому складу органів та підрозділів внутрішніх справ.

6. Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр генерал-лейтенант міліції А.В.Могильов

ПОГОДЖЕНО:

В.о. Міністра інфраструктури України К.Єфименко

ЗАТВЕРДЖЕНО Наказ МВС України 22.08.2011 N 604

Зареєстровано в Міністерстві юстиції України 14 вересня 2011 р. за N 1085/19823

ЗМІНИ до деяких нормативно-правових актів МВС з питань діяльності Державтоінспекції

1. В Інструкції про порядок приймання іспитів для отримання права керування транспортними засобами та видачі посвідчень водія ( z0074-10 ), затвердженій наказом МВС України від 07.12.2009 N 515 ( z0072-10 ), зареєстрованій в Міністерстві юстиції України 22.01.2010 за N 74/17369:

1.1. В абзаці шостому пункту 2.1 розділу II слова "та талон попереджень" виключити.

1.2. У Книзі видачі посвідчень водія ( z0074-10 ), що наведена у додатку 8, колонку 8 виключити.

У зв'язку з цим колонки 9-11 уважати відповідно колонками 8-10.

1.3. У Реєстрі посвідчень водія ( z0074-10 ), що наведений у додатку 9, колонку 14 виключити.

2. У Картці водія, що наведена у додатку 5 до Інструкції про порядок організації та контролю за підготовкою, перепідготовкою та підвищенням кваліфікації водіїв транспортних засобів ( z0073-10 ), затвердженої наказом МВС України від 07.12.2009 N 515 ( z0072-10 ), зареєстрованої в Міністерстві юстиції України 22.01.2010 за N 73/17368, колонку "Серія, N талона" виключити.

{ Пункт 3 втратив чинність на підставі Наказу Міністерства внутрішніх справ N 1330 ( z0037-17 ) від 21.12.2016 }

4. У Положенні про порядок спеціального навчання водіїв транспортних засобів, що перевозять небезпечні вантажі, та про уповноважених з питань безпеки перевезень небезпечних вантажів автомобільними дорогами, затвердженому наказом МВС України від 21.03.2008 N 130 ( z0309-08 ), зареєстрованому в Міністерстві юстиції України 15.04.2008 за N 309/15000:

4.1. У підпункті 4.2.12 пункту 4.2 глави 4 слова "та талона до посвідчення" виключити;

4.2. У Поданні для направлення на підготовку водіїв транспортних засобів до транспортування небезпечних вантажів ( z0309-08 ), що наведене у додатку 1, слова "талон до посвідчення водія: серія, номер, видане" виключити.

5. В Інструкції про порядок приймання іспитів, видачі (обміну) ДОПНВ-свідоцтв про підготовку водіїв транспортних засобів, що перевозять небезпечні вантажі, свідоцтв про підготовку уповноважених з питань безпеки перевезень небезпечних вантажів, а також про облік і зберігання документів, що є підставою для видачі ДОПНВ-свідоцтв і свідоцтв про підготовку уповноважених ( z0310-08 ), затвердженій наказом МВС України від 21.03.2008 N 130 ( z0309-08 ), зареєстрованій в Міністерстві юстиції України 15.04.2008 за N 310/15001:

5.1. У підпункті 1.2.1 пункту 1.2 глави 1 слова "та талона до посвідчення" виключити;

5.2. У Поданні для направлення на підготовку водіїв транспортних засобів до транспортування небезпечних вантажів, що наведене у додатку 4, слова "талон до посвідчення водія: серія, номер, видане," виключити.
