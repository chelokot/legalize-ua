Кабінет Міністрів України; Розпорядження від 13.12.1999 № 1406-р

Про внесення змін до постанов Кабінету Міністрів України від 19 травня 1999 р. N 841 та від 3 червня 1999 р. N 951

Стан: Втратив чинність

Ідентифікатор: 1406-99-р

Текст документа від 07.03.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 грудня 1999 р. N 1406-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 301 ( 301-2003-п ) від 07.03.2003 )

1. Виключити у додатку 2 до постанови Кабінету Міністрів України від 19 травня 1999 р. N 841 ( 841-99-п ) "Про переліки відкритих акціонерних товариств, пакети акцій яких підлягають продажу у 1999 році за кошти" (Офіційний вісник України, 1999 р., N 20, ст. 899) позицію:

"191112 Донецьккокс 25".

2. Доповнити додаток 21 до постанови Кабінету Міністрів України від 3 червня 1999 р. N 951 ( 951-99-п ) "Про передачу повноважень з управління державними корпоративними правами Раді міністрів Автономної Республіки Крим, міністерствам, іншим центральним і місцевим органам виконавчої влади" (Офіційний вісник України, 1999 р., N 23, ст. 1053, N 44, ст. 2175) позицією:

"191112 ВАТ "Донецьккокс".
