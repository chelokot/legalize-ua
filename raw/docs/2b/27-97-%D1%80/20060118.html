Кабінет Міністрів України; Розпорядження від 21.01.1997 № 27-р

Про віднесення посад працівників Апарату Ради національної безпеки і оборони України до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 27-97-р

Текст документа від 18.01.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 січня 1997 р. N 27-р Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 713-р ( 713-97-р ) від 09.12.97 }

{ Зміни до Розпорядження див. в Розпорядженні КМ N 995-р ( 995-98-р ) від 01.12.98 }

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1250-р ( 1250-99-р ) від 15.11.99 N 73-р ( 73-2000-р ) від 07.02.2000 N 195-р ( 195-2003-р ) від 31.03.2003 N 173-р ( 173-2004-р ) від 25.03.2004 N 20-р ( 20-2006-р ) від 18.01.2006 }

На виконання Указу Президента України від 12 грудня 1996 р. N 1192 ( 1192/96 ) та відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Апарату Ради національної безпеки і оборони України до таких категорій посад державних службовців:

перша категорія - посаду Керівника Апарату Ради, заступника Секретаря Ради національної безпеки і оборони України, першого заступника Секретаря Ради національної безпеки і оборони України, Голови Комітету з політики військово-технічного співробітництва та експортного контролю при Президентові України, керівника служби Секретаря Ради національної безпеки і оборони України та його заступника, керівника департаменту та його заступника; { Абзац із змінами, внесеними згідно з Розпорядженнями КМ N 73-р ( 73-2000-р ) від 07.02.2000, N 173-р ( 173-2004-р ) від 25.03.2004, N 20-р ( 20-2006-р ) від 18.01.2006 }

друга категорія - посади заступника Керівника Апарату Ради, першого помічника Секретаря Ради національної безпеки і оборони України - керівника групи помічників, консультантів та референтів Секретаря Ради, помічника Секретаря Ради національної безпеки і оборони України, керівників управлінь, відділів, керівника Групи організаційного і протокольного забезпечення діяльності Секретаря Ради національної безпеки і оборони України, керівника Служби заступника Секретаря Ради національної безпеки і оборони України, помічників заступника Секретаря Ради національної безпеки і оборони України, керівника Аналітичної служби, заступника керуючого справами Управління справами Апарату Ради національної безпеки і оборони України, керівника апарату Комітету з політики військово-технічного співробітництва та експортного контролю при Президентові України Апарату Ради національної безпеки і оборони України, заступника начальника управління та начальника відділу у складі управління, керівника групи радників, радника і першого помічника Секретаря Ради національної безпеки і оборони України; керівника служби, керівника управління у складі департаменту, заступника керівника управління - завідувача відділу; { Абзац із змінами, внесеними згідно з Розпорядженнями КМ N 713-р ( 713-97-р ) від 09.12.97, N 1250-р ( 1250-99-р ) від 15.11.99, N 195-р ( 195-2003-р ) від 31.03.2003, N 20-р ( 20-2006-р ) від 18.01.2006 }

третя категорія - посади консультанта Секретаря Ради національної безпеки і оборони України, координатора роботи міжвідомчих комісій у сфері національної безпеки і оборони, державних експертів, завідуючих секторами, головних консультантів, головних спеціалістів, консультантів, заступника завідувача Фінансово-адміністративного відділу - бухгалтера, заступника завідувача відділу; { Абзац із змінами, внесеними згідно з Розпорядженнями КМ N 713-р ( 713-97-р ) від 09.12.97, N 20-р ( 20-2006-р ) від 18.01.2006 }

четверта категорія - посади старшого референта, референтів.
