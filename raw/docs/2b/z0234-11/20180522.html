ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

08.02.2011 N 141

Зареєстровано в Міністерстві юстиції України 25 лютого 2011 р. за N 234/18972

Про внесення змін до деяких нормативно-правових актів

{ Із змінами, внесеними згідно з Наказом Фонду державного майна N 496 ( z0495-18 ) від 10.04.2018 }

На виконання Закону України від 22.12.2010 N 2850-VI ( 2850-17 ) "Про внесення змін до деяких законодавчих актів України щодо статутного капіталу" НАКАЗУЮ:

1. Внести зміни до таких нормативно-правових актів:

{ Підпункт 1.1 пункту 1 втратив чинність на підставі Наказу Фонду державного майна N 496 ( z0495-18 ) від 10.04.2018 }

{ Підпункт 1.2 пункту 1 втратив чинність на підставі Наказу Фонду державного майна N 496 ( z0495-18 ) від 10.04.2018 }

2. Департаменту продажу акцій на фондових ринках та проведення аукціонів в установленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Голови Фонду відповідно до розподілу функціональних обов'язків.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

Голова Фонду О.Рябченко
