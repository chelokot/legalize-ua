Кабінет Міністрів України; Розпорядження від 11.02.2010 № 204-р

Про розміщення Асоціації малих міст України

Стан: Чинний

Ідентифікатор: 204-2010-р

Текст документа від 10.03.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 лютого 2010 р. N 204-р Київ

Про розміщення Асоціації малих міст України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 370-р ( 370-2010-р ) від 10.03.2010 }

1. Погодитися з пропозицією добровільного об'єднання органів місцевого самоврядування "Асоціація малих міст України" (далі - Асоціація малих міст України) щодо надання йому частини приміщень робочою площею 75,9 кв. метра на першому поверсі (кімнати 27, 28 і 28а) нежитлового будинку по вул. Артема, 73, у м. Києві на умовах оренди.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 370-р ( 370-2010-р ) від 10.03.2010 }

2. Господарсько-фінансовому департаменту Секретаріату Кабінету Міністрів України вжити у двотижневий строк заходів до розміщення Асоціації малих міст України у приміщеннях, зазначених у пункті 1 цього розпорядження.

3. Фондові державного майна та Асоціації малих міст України забезпечити укладення договору оренди приміщень та відшкодування балансоутримувачеві нежитлового будинку по вул. Артема, 73, у м. Києві фактичних витрат, пов'язаних з їх утриманням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
