Президент України; Указ від 14.06.2007 № 529/2007

Про звільнення В. Іващенка з посади судді Конституційного Суду України

Стан: Чинний

Ідентифікатор: 529/2007

Текст документа від 01.11.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про звільнення В. Іващенка з посади судді Конституційного Суду України

{ Із змінами, внесеними згідно з Указом Президента N 1040/2007 ( 1040/2007 ) від 01.11.2007 }

Відповідно до пунктів 3, 9 частини п'ятої статті 126 Конституції України ( 254к/96-ВР ), статті 43 Закону України "Про статус суддів" ( 2862-12 ) постановляю:

{ Преамбула із змінами, внесеними згідно з Указом Президента N 1040/2007 ( 1040/2007 ) від 01.11.2007 }

Звільнити ІВАЩЕНКА Володимира Івановича з посади судді Конституційного Суду України у зв'язку з поданням заяви про відставку через неможливість виконувати свої повноваження за станом здоров'я.

{ Указ із змінами, внесеними згідно з Указом Президента N 1040/2007 ( 1040/2007 ) від 01.11.2007 }

Президент України В.ЮЩЕНКО

м. Київ, 14 червня 2007 року N 529/2007
