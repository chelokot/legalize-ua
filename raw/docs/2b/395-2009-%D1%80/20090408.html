Кабінет Міністрів України; Розпорядження від 08.04.2009 № 395-р

Про виділення коштів для компенсації витрат із завершення будівництва житла для сімей, які втратили його внаслідок стихійного лиха, що сталося 23 - 27 липня 2008 року

Стан: Чинний

Ідентифікатор: 395-2009-р

Текст документа від 08.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 квітня 2009 р. N 395-р Київ

Про виділення коштів для компенсації витрат із завершення будівництва житла для сімей, які втратили його внаслідок стихійного лиха, що сталося 23 - 27 липня 2008 року

1. Виділити Чернівецькій облдержадміністрації 7292,5 тис. гривень для компенсації витрат із завершення будівництва житла для сімей, які втратили його внаслідок стихійного лиха, що сталося 23 - 27 липня 2008 року.

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 835-17 ).

2. Чернівецькій облдержадміністрації:

затвердити у тижневий строк за погодженням з Мінекономіки, Мінфіном та Мінрегіонбудом перелік витрат, пов'язаних з проведенням розрахунків з підрядними організаціями за споруджене житло для постраждалих;

подати до 1 травня 2009 р. Мінекономіки, Мінфіну та Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
