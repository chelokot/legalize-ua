Кабінет Міністрів України; Розпорядження від 21.02.1996 № 133-р

Про доповнення до розпорядження від 2 грудня 1993 р. N 1030

Стан: Втратив чинність

Ідентифікатор: 133-96-р

Текст документа від 29.03.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 лютого 1996 р. N 133-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 426 ( 426-2002-п ) від 29.03.2002 )

Доповнити розпорядження Кабінету Міністрів України від 2 грудня 1993 р. N 1030 ( 1030-93-р ) абзацом такого змісту:

"Зазначеним військовослужбовцям за їх бажанням виплачується грошова компенсація вартості тютюнових виробів за нормою їх забезпечення".
