Кабінет Міністрів України; Постанова, Перелік від 30.03.2005 № 223

Деякі питання структури Секретаріату Кабінету Міністрів України та Служби Прем'єр-міністра України

Стан: Чинний

Ідентифікатор: 223-2005-п

Текст документа від 21.08.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 березня 2005 р. N 223 Київ

Деякі питання структури Секретаріату Кабінету Міністрів України та Служби Прем'єр-міністра України

{ Із змінами, внесеними згідно з Постановою КМ N 850 ( 850-2009-п ) від 12.08.2009 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 850 ( 850-2009-п ) від 12.08.2009 }

2. Визнати такими, що втратили чинність з дня затвердження Міністром Кабінету Міністрів України нової структури Секретаріату Кабінету Міністрів України та Служби Прем'єр-міністра України, постанови Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 19

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 30 березня 2005 р. N 223

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 9 березня 2000 р. N 466 ( 466-2000-п ) "Про вдосконалення структури Служби Прем'єр-міністра України та Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2000 р., N 10, ст. 384).

2. Постанова Кабінету Міністрів України від 20 червня 2001 р. N 660 ( 660-2001-п ) "Про внесення змін до структури Секретаріату Кабінету Міністрів України та структури Служби Прем'єр-міністра України" (Офіційний вісник України, 2001 р., N 25, ст. 1113).

3. Пункт 1 постанови Кабінету Міністрів України від 9 вересня 2003 р. N 1425 ( 1425-2003-п ) "Деякі питання Секретаріату Кабінету Міністрів України".

4. Постанова Кабінету Міністрів України від 12 січня 2004 р. N 4 ( 4-2004-п ) "Про керівника Протоколу Прем'єр-міністра України - завідуючого Відділом протокольного забезпечення та прийому офіційних делегацій Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2004 р., N 2, ст. 36), крім пункту 2.

5. Постанова Кабінету Міністрів України від 15 жовтня 2004 р. N 1376 ( 1376-2004-п ) "Про утворення Управління моніторингу та аналізу справ щодо захисту інтересів держави в юрисдикційних органах у структурі Секретаріату Кабінету Міністрів України".

6. Пункт 1 постанови Кабінету Міністрів України від 13 січня 2005 р. N 26 ( 26-2005-п ) "Про Історико-документальне управління Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2005 р., N З, ст. 129).

7. Постанова Кабінету Міністрів України від 19 січня 2005 р. N 63 ( 63-2005-п ) "Про утворення Управління інноваційної політики в структурі Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2005 р., N З, ст. 154).
