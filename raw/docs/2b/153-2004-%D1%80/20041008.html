Кабінет Міністрів України; Розпорядження від 19.03.2004 № 153-р

Про поховання колишнього Міністра фінансів Забродіна І.О.

Стан: Чинний

Ідентифікатор: 153-2004-р

Текст документа від 08.10.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 березня 2004 р. N 153-р Київ

Про поховання колишнього Міністра фінансів Забродіна І.О.

( Із змінами, внесеними згідно з Розпорядженням КМ N 711-р ( 711-2004-р ) від 08.10.2004 )

1. Поховати колишнього Міністра фінансів Забродіна Івана Олександровича на Байковому кладовищі.

2. Витрати, пов'язані з похованням Забродіна І.О. в сумі до 5.85 тис. гривень, здійснити за рахунок держави.

( Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 711-р ( 711-2004-р ) від 08.10.2004 )

3. Київській міськдержадміністрації спорудити на могилі Забродіна І.О. надгробок вартістю до 19,15 тис. гривень.

( Пункт 3 із змінами, внесеними згідно з Розпорядженням КМ N 711-р ( 711-2004-р ) від 08.10.2004 )

4. Видати одноразову допомогу вдові Забродіна І.О. - Забродіній Євгенії Петрівні в сумі 3 тис. гривень.

5. Мінфіну профінансувати зазначені в пунктах 2-4 цього розпорядження власні витрати за рахунок коштів резервного фонду державного бюджету ( 1344-15 ).

6. Мінфіну подати до кінця 2004 року Мінекономіки та Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України В.ЯНУКОВИЧ
