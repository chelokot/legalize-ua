Зареєстровано в Міністерстві юстиції України 7 грудня 2011 р. за N 1408/20146

{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 271/5 ( z0272-13 ) від 14.02.2013 }

Про внесення змін до Положення про відомчу заохочувальну відзнаку Міністерства юстиції України - нагрудний знак "За сумлінну службу в органах державної виконавчої служби"

Відповідно до Указу Президента України від 09.12.2010 N 1085 ( 1085/2010 ) "Про оптимізацію системи центральних органів виконавчої влади" та Указу Президента України від 06.04.2011 N 385 ( 385/2011 ) "Про затвердження Положення про Державну виконавчу службу України", з метою приведення нормативно-правових актів у відповідність до вимог чинного законодавства, НАКАЗУЮ:

1. Внести до Положення про відомчу заохочувальну відзнаку Міністерства юстиції України - нагрудний знак "За сумлінну службу в органах державної виконавчої служби", затвердженого наказом Міністерства юстиції України від 24.07.2009 N 1333/5 ( z1057-09 ), зареєстрованого в Міністерстві юстиції України 11.11.2009 за N 1057/17073, такі зміни:

1.1. У розділі II:

1.1.1. У пункті 2.2 слова "на розгляд колегії" замінити словом "до", а слова "директором Департаменту державної виконавчої служби Міністерства юстиції України" замінити словами "Головою Державної виконавчої служби України".

1.1.2. У пункті 2.5 перше речення виключити.

1.2. Пункт 3.1 розділу III викласти в такій редакції:

"3.1. Вручення нагрудного знака проводиться Міністром юстиції України або за його дорученням Головою Державної виконавчої служби України в урочистій обстановці.".

2. Департаменту взаємодії з органами влади (Зеркаль О.В.) подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (зі змінами).

3. Цей наказ набирає чинності з дня його офіційного опублікування.

4. Контроль за виконанням цього наказу покласти на заступника Міністра юстиції України - керівника апарату Сєдова А.Ю.

Міністр О.Лавринович
