Президент України; Указ від 18.12.2009 № 1074/2009

Питання Української частини Українсько-Російської міждержавної комісії

Стан: Втратив чинність

Ідентифікатор: 1074/2009

Текст документа від 23.03.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 438/2010 ( 438/2010 ) від 23.03.2010 }

Питання Української частини Українсько-Російської міждержавної комісії

1. На часткову зміну статті 1 Указу Президента України від 29 січня 2008 року N 58 ( 58/2008 ) "Про оновлення складу Української частини Українсько-Російської міждержавної комісії":

увести до складу Української частини Українсько-Російської міждержавної комісії ПОРОШЕНКА Петра Олексійовича - Міністра закордонних справ України та ГОНЧАРУКА Андрія Івановича - заступника Глави Секретаріату Президента України;

вивести зі складу Української частини Українсько-Російської міждержавної комісії Ю. Єханурова та О. Чалого.

2. Секретареві Української частини Українсько-Російської міждержавної комісії у місячний строк внести пропозиції щодо оновлення персонального складу української частини робочих органів Українсько-Російської міждержавної комісії.

Президент України В.ЮЩЕНКО
