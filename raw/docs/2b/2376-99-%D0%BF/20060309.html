Текст документа від 09.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 грудня 1999 р. N 2376 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

Про доповнення постанови Кабінету Міністрів України від 22 грудня 1999 р, N 2358

Кабінет Міністрів України постановляє:

Доповнити постанову Кабінету Міністрів України від 22 грудня 1999 р. N 2358 ( 2358-99-п ) "Про внесення змін до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288" абзацом такого змісту:

"Умови оплати праці, визначені для працівників Секретаріату Кабінету Міністрів України, поширюються на працівників апарату Кабінету Міністрів України".

Прем'єр-міністр України В.ЮЩЕНКО
