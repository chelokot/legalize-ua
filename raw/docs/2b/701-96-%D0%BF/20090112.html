Про вдосконалення управління підприємствами спиртової та лікеро-горілчаної промисловості

{ Із змінами, внесеними згідно з Постановами КМ N 1132 ( 1132-96-п ) від 17.09.96 N 1437 ( 1437-96-п ) від 02.12.96 N 413 ( 413-97-п ) від 05.05.97 Розпорядженнями КМ N 441-р ( 441-2000-р ) від 08.11.2000 N 143-р ( 143-2001-р ) від 23.04.2001 Постановою КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

З метою формування та здійснення єдиної державної політики у виробництві спирту етилового, горілки та лікеро-горілчаних виробів та враховуючи, що підприємства, які їх виробляють, не підлягають приватизації, Кабінет Міністрів України постановляє:

{ Пункт 1 виключено на підставі Постанови КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

2. Підтримати пропозицію Державного комітету по харчовій промисловості про утворення Державного концерну спиртової та лікеро-горілчаної промисловості (концерн "Укрспирт").

Установити, що до складу зазначеного концерну входять державні підприємства згідно з додатком N 2. { Пункт 2 доповнено абзацом згідно з Постановою КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

3. Установити, що контроль за діяльністю концерну "Укрспирт" здійснює Міністерство аграрної політики. { Абзац перший пункту 3 в редакції Постанови КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

Концерн провадить свою діяльність на підставі Статуту, затверджуваного Кабінетом Міністрів України. { Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

До концерну на добровільних засадах можуть входити об'єднання, підприємства та організації незалежно від форм власності, що мають спільні економічні і соціальні інтереси.

4. Визначити, що основними завданнями концерну "Укрспирт" є:

забезпечення виробництва спирту етилового, горілки та лікеро-горілчаних виробів;

здійснення розміщення централізованих капіталовкладень;

координація роботи об'єднань, підприємств та організацій, що беруть участь у виробництві спирту етилового, горілки та лікеро-горілчаних виробів;

здійснення комплексу заходів щодо підвищення якості та конкурентоспроможності продукції, що виробляється підприємствами концерну;

проведення маркетингу ринку спирту етилового, горілки та лікеро-горілчаних виробів та освоєння нових ринків збуту продукції;

забезпечення державних потреб в спирті етиловому;

експорт спирту етилового, горілки та лікеро-горілчаних виробів;

реалізація єдиної технічної політики, спрямованої на досягнення світового рівня технології виробництва та якості продукції;

вжиття заходів до створення нових виробництв і ліквідації застарілих;

оптимізація галузевої та міжгалузевої кооперації у сфері виробництва спирту етилового, горілки, лікеро-горілчаних виробів.

{ Пункт 5 виключено на підставі Постанови КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

{ Пункт 6 виключено на підставі Постанови КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

7. Установити, що Міністерство економіки складає разом з Міністерством аграрної політики баланси виробництва і споживання спирту етилового.

{ Пункт 7 із змінами, внесеними згідно з Постановою КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

8. Уповноважити концерн "Укрспирт" здійснювати експорт спирту етилового (код згідно з УКТЗЕД 2207).
