Стан: Втратив чинність

Ідентифікатор: z0380-95

Текст документа від 24.09.1998:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

N 342 від 13.10.95 Зареєстровано в Міністерстві м.Київ юстиції України 19 жовтня 1995 р. vd951013 vn342 за N 380/916

( Наказ втратив чинність на підставі Наказу Мінтрансу N 364 ( z0597-98 ) від 16.09.98 )

Про внесення змін та доповнень до наказу від 21.07.95 р.

N 273 "Про встановлення платних послуг по обслуговуванню

пасажирів на вокзалах та в поїздах на залізницях України"

( Із змінами, внесеними згідно з Наказом Мінтранспорту N 414 ( z0016-96 ) від 14.11.95 )

У зв'язку з відсутністю можливості внесення змін в математичне програмне забезпечення АСУ "Експресс" при наданні послуг по продажу квитків, передбачених наказом від 21.07.95 р. N 273 ( z0277-95 ), з метою уточнення деяких пунктів НАКАЗУЮ:

1. Внести до наказу від 21.07.95 р. N 273 такі доповнення:

1.1. В абзаці першому пункту 1 після слів "продаж квитка в" додати слово "будь-якій";

1.2. Абзац шістнадцятий пункту 1 доповнити словами та цифрами "за 45-10 діб до відправлення поїзда в напрямку "туди";

1.3. В абзаці першому пункту 2 після слів "продаж квитка в" додати слово "будь-якій";

1.4. Пункт 3.5. після слів "не стягується" доповнити словами "крім випадків продажу у причепні вагони та вагони зі зміною трафарету."

2. Вважати такими, що втратили чинність у наказі від 21.07.95 р. N 273:

- абзац шостий та десятий пункту 1; ( Абзац другий пункту 2 із змінами, внесеними згідно з Наказом Мінтранспорту N 414 ( z0016-96 ) від 14.11.95 )

- абзац шостий пункту 2;

- пункти 3.4. та 3.7.

3. Укрзалізниці (Л.Л.Железняк) зареєструвати згідно з чинним законодавством цей наказ в Міністерстві юстиції.

4. Контроль за виконанням цього наказу покласти на першого заступника Міністра транспорту України - Генерального директора Укрзалізниці Л.Л.Железняка.
