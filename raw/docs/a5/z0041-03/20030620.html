Мінекономіки, європ.інтеграції; Наказ від 08.01.2003 № 7

Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 28.02.2002 N 61

Реєстрація: Мін'юст України від 20.01.2003 № 41/7362

Стан: Чинний

Ідентифікатор: z0041-03

Текст документа від 20.06.2003:

МІНІСТЕРСТВО ЕКОНОМІКИ ТА З ПИТАНЬ ЄВРОПЕЙСЬКОЇ ІНТЕГРАЦІЇ УКРАЇНИ

НАКАЗ

08.01.2003 N 7

Зареєстровано в Міністерстві юстиції України 20 січня 2003 р. за N 41/7362

Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 28.02.2002 N 61

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства економіки та з питань європейської інтеграції N 61 ( z0265-02 ) від 28.02.2002, до якого вносились зміни }

У зв'язку з прийняттям постанови Кабінету Міністрів України від 29 серпня 2002 р. N 1266 ( 1266-2002-п ) "Про затвердження Порядку здійснення контролю за обігом спирту" НАКАЗУЮ:

1. Унести до наказу Міністерства економіки та з питань європейської інтеграції України від 28.02.2002 N 61 ( z0265-02 ) "Про затвердження Порядку отримання фондів (лімітів) на спирт етиловий", зареєстрованого в Міністерстві юстиції України 18 березня 2002 р. за N 265/6553, такі зміни:

вступну частину викласти в такій редакції: "Відповідно до порядків, затверджених постановами Кабінету Міністрів України від 29 серпня 2002 р. N 1266 ( 1266-2002-п ) "Про затвердження Порядку здійснення контролю за обігом спирту" та від 5 липня 1999 р. N 1197 ( 1197-99-п ) "Про порядок отримання закладами та установами охорони здоров'я, суб'єктами підприємницької діяльності, вітчизняними товаровиробниками спирту етилового і здійснення контролю за його цільовим використанням", та з метою впорядкування механізму отримання лімітів на спирт етиловий";

у назві наказу та пункті 1 слова "фондів (лімітів)" замінити словом "лімітів".

2. Унести до Порядку отримання фондів (лімітів) на спирт етиловий, затвердженого наказом Міністерства економіки та з питань європейської інтеграції України від 28.02.2002 N 61 ( z0265-02 ), такі зміни:

у назві та тексті Порядку слова "фонди (ліміти)" в усіх відмінках замінити словом "ліміти" у відповідному відмінку;

в абзаці першому підпункту "б" пункту 3 слово "парфуми" замінити словами "парфумерно-косметичну продукцію";

абзац перший підпункту "в" пункту 3 викласти в такій редакції: "суб'єкт підприємницької діяльності, що використовує спирт етиловий ректифікований для виготовлення алкогольних напоїв";

в абзаці третьому підпункту "в" пункту 3 слова "виноградних виноматеріалів" замінити словами "алкогольних напоїв";

в абзацах четвертому та п'ятому підпункту "в" пункту 3 слово "неденатурованого" замінити словом "ректифікованого".

3. Начальнику управління розвитку ринків продовольства та сільськогосподарської продукції Ситих В.В. забезпечити державну реєстрацію цього наказу в Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника Державного секретаря Зубарєва В.В.

5. Цей наказ набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.
