Стан: Втратив чинність

Текст документа від 10.01.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 травня 2000 р. N 789 Київ

( Постанова втратила чинність на підставі Постанови КМ N 20 ( 20-2002-п ) від 10.01.2002 )

Про затвердження складу Митно-тарифної ради України

( Із змінами, внесеними згідно з Постановою КМ N 1846 ( 1846-2000-п ) від 20.12.2000 )

Кабінет Міністрів України постановляє:

1. Затвердити склад Митно-тарифної ради України згідно з додатком.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 21 вересня 1998 р. N 1485 ( 1485-98-п ) "Про затвердження складу Митно-тарифної ради України".

СКЛАД Митно-тарифної ради України

РОГОВИЙ - Міністр економіки (голова Ради) Василь Васильович

ШЕЙКО - заступник Голови Державної митної Олександр Петрович служби (перший заступник голови Ради)

ГОНЧАРУК - заступник Міністра економіки Андрій Іванович (заступник голови Ради)

БІЛОУС - заступник Голови Державного комітету Геннадій Михайлович з питань регуляторної політики та підприємництва

ВИСЛОУХ - начальник департаменту державної Олег Валентинович політики у сфері зовнішньої торгівлі Мінекономіки

ГОЛУБОВ - заступник Голови Держпромполітики Олексій Григорович

КОЛЕСНІКОВ - перший заступник Міністра транспорту Олександр Олександрович

ЄФІМЕНКО - заступник Міністра юстиції Леонід Васильович

КРУТЬ - заступник Міністра палива та Олександр Анатолійович енергетики

ЛУЗАН - перший заступник Міністра Юрій Якович аграрної політики

МАКАЦАРІЯ - начальник департаменту Сергій Мегонович зовнішньо-економічних зв'язків Мінфіну

ОПЕРЕНКО - заступник Голови Державної податкової Григорій Миколайович адміністрації

ПІНСЬКИЙ - начальник Управління міжнародного Олександр Іванович співробітництва, міждержавних відносин та зовнішньої політики Департаменту економічної політики Секретаріату Кабінету Міністрів України

СКРИПЧЕНКО - віце-президент Торгово-промислової Сергій Парфенович палати

СТЕЦЕНКО - заступник Міністра екології та Микола Пилипович природних ресурсів

СТРУК - державний уповноважений Василь Миколайович Антимонопольного комітету

ЧАЛИЙ - перший заступник Міністра закордонних Олександр Олександрович справ
