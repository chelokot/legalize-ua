КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 березня 2011 р. N 283 Київ

Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 березня 2011 р. N 283

ПЕРЕЛІК актів Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 13 червня 2000 р. N 965 ( 965-2000-п ) "Про затвердження Порядку спрямування і координації діяльності центральних органів виконавчої влади через відповідних міністрів" (Офіційний вісник України, 2000 р., N 24, ст. 1017).

2. Постанова Кабінету Міністрів України від 21 грудня 2005 р. N 1229 ( 1229-2005-п ) "Про внесення змін до Порядку спрямування і координації діяльності центральних органів виконавчої влади через відповідних міністрів" (Офіційний вісник України, 2005 р., N 52, ст. 3272).

3. Постанова Кабінету Міністрів України від 23 лютого 2006 р. N 207 ( 207-2006-п ) "Про спрямування і координацію діяльності центральних органів виконавчої влади через відповідних міністрів" (Офіційний вісник України, 2006 р., N 8, ст. 458).

4. Постанова Кабінету Міністрів України від 17 травня 2006 р. N 683 ( 683-2006-п ) "Про внесення змін до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів" (Офіційний вісник України, 2006 р., N 20, ст. 1480).

5. Постанова Кабінету Міністрів України від 8 червня 2006 р. N 811 ( 811-2006-п ) "Про внесення змін до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів" (Офіційний вісник України, 2006 р., N 23, ст. 1728).

6. Постанова Кабінету Міністрів України від 23 червня 2006 р. N 845 ( 845-2006-п ) "Про внесення змін до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів" (Офіційний вісник України, 2006 р., N 26, ст. 1876).

7. Постанова Кабінету Міністрів України від 23 листопада 2006 р. N 1646 ( 1646-2006-п ) "Про внесення зміни до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів" (Офіційний вісник України, 2006 р., N 48, ст. 3192).

8. Пункт 1 змін, що вносяться до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів, та постанови Кабінету Міністрів України від 2 листопада 2006 р. N 1523, затверджених постановою Кабінету Міністрів України від 29 листопада 2006 р. N 1650 ( 1650-2006-п ) (Офіційний вісник України, 2006 р., N 48, ст. 3193).

9. Постанова Кабінету Міністрів України від 14 лютого 2007 р. N 214 ( 214-2007-п ) "Про внесення змін до Порядку спрямування і координації діяльності центральних органів виконавчої влади через відповідних міністрів" (Офіційний вісник України, 2007 р., N 12, ст. 432).

10. Пункт 2 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 30 серпня 2007 р. N 1075 ( 1075-2007-п ) "Питання Державного департаменту ветеринарної медицини" (Офіційний вісник України, 2007 р., N 66, ст. 2547).

11. Пункт 4 змін, що вносяться до постанов Кабінету Міністрів України з питань Міністерства транспорту та зв'язку, затверджених постановою Кабінету Міністрів України від 14 листопада 2007 р. N 1325 ( 1325-2007-п ) (Офіційний вісник України, 2007 р., N 88, ст. 3221).

12. Постанова Кабінету Міністрів України від 19 березня 2008 р. N 220 ( 220-2008-п ) "Про внесення змін до Порядку спрямування і координації діяльності центральних органів виконавчої влади через відповідних міністрів" (Офіційний вісник України, 2008 р., N 23, ст. 694).

13. Пункт 3 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 20 грудня 2008 р. N 1121 ( 1121-2008-п ) "Деякі питання державного управління у сфері контролю якості лікарських засобів" (Офіційний вісник України, 2008 р., N 100, ст. 3312).

14. Пункт 1 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 5 серпня 2009 р. N 814 ( 814-2009-п ) (Офіційний вісник України, 2009 р., N 59, ст. 2076).

15. Пункт 4 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 5 серпня 2009 р. N 844 ( 844-2009-п ) "Деякі питання реалізації права власності на землю громадянами України" (Офіційний вісник України, 2009 р., N 61, ст. 2158).

16. Пункт 3 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 17 березня 2010 р. N 275 ( 275-2010-п ) "Деякі питання здійснення державного контролю якості лікарських засобів" (Офіційний вісник України, 2010 р., N 21, ст. 868).

17. Розпорядження Кабінету Міністрів України від 17 березня 2010 р. N 456 ( 456-2010-р ) "Про визначення питань, що належать до компетенції Першого віце-прем'єр-міністра України, віце-прем'єр-міністрів та Міністра Кабінету Міністрів України".

18. Пункт 2 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 17 травня 2010 р. N 356 ( 356-2010-п ) "Про Державне агентство з інвестицій та розвитку" (Офіційний вісник України, 2010 р., N 38, ст. 1280).

19. Розпорядження Кабінету Міністрів України від 19 липня 2010 р. N 1502 ( 1502-2010-р ) "Про внесення змін у додатки до розпорядження Кабінету Міністрів України від 17 березня 2010 р. N 456".

20. Розпорядження Кабінету Міністрів України від 20 жовтня 2010 р. N 2012 ( 2012-2010-р ) "Про внесення змін у додатки до розпорядження Кабінету Міністрів України від 17 березня 2010 р. N 456".
