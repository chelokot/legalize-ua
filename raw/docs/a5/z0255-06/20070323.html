Про встановлення понижуючого коефіцієнта до портових зборів для суден, які заходять в порти Дніпро-Бузького регіону

Стан: Втратив чинність

Ідентифікатор: z0255-06

Текст документа від 23.03.2007:

МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

27.02.2006 N 185

Зареєстровано в Міністерстві юстиції України 11 березня 2006 р. N 255/12129

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 142 ( z0215-07 ) від 21.02.2007 }

Про встановлення понижуючого коефіцієнта до портових зборів для суден, які заходять в порти Дніпро-Бузького регіону

Відповідно до пункту 2 постанови Кабінету Міністрів України від 12.10.2000 N 1544 ( 1544-2000-п ) "Про портові збори" (із змінами та доповненнями) та з метою створення сприятливих умов для розвитку портів Дніпро-Бузького регіону, збереження існуючих та залучення додаткових вантажопотоків НАКАЗУЮ:

1. Установити, що терміном до 01.03.2007 для суден, які заходять у ДП "Миколаївський морський торговельний порт", ДП "Херсонський морський торговельний порт", ДП "Дніпро-Бузький морський торговельний порт" та ДП "Спеціалізований морський порт "Октябрський" під навантаження (розвантаження) вантажів, підприємства, які стягують відповідні портові збори можуть застосовувати понижуючий коефіцієнт 0,5 до ставок портових зборів (крім адміністративного та маякового).

2. Керівникам ДП "Миколаївський морський торговельний порт" (Капацина В.М.), ДП "Херсонський морський торговельний порт" (Іванюк В.В.), ДП "Дніпро-Бузький морський торговельний порт" (Холявко І.В.), ДП "Спеціалізований морський порт "Октябрський" (Крапива В.П.) та ДП "Дельта - Лоцман" (Нагірний О.І) забезпечити згідно з цим наказом нарахування відповідних портових зборів для суден, що заходять під навантаження (розвантаження) вантажів у зазначені порти.

3. Державному департаменту морського і річкового транспорту (Кушніренко А.В.) запровадити моніторинг обсягів переробки вантажів у вказаних портах та щомісяця до 5 числа місяця, наступного за звітним, інформувати Міністерство транспорту та зв'язку України.

4. Юридичному управлінню (Тарасова Л.О.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

5. Контроль за виконанням цього наказу покласти на заступника Міністра Рябікіна П.Б.

Міністр В.В.Бондар
