ПОСТАНОВА від 1 березня 2003 р. N 270 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Міжвідомчої комісії з питань розвитку транскордонного співробітництва та єврорегіонів

Кабінет Міністрів України постановляє:

Затвердити головою Міжвідомчої комісії з питань розвитку транскордонного співробітництва та єврорегіонів, утвореної постановою Кабінету Міністрів України від 29 квітня 2002 р. N 587 ( 587-2002-п ) (Офіційний вісник України, 2002 р., N 18, ст, 938), Міністра економіки та з питань європейської інтеграції Хорошковського Валерія Івановича, звільнивши від цих обов'язків Шлапака Олександра Віталійовича.

Прем'єр-міністр України В.ЯНУКОВИЧ
