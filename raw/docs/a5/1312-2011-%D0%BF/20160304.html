КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 грудня 2011 р. N 1312 Київ

Про внесення змін до деяких актів Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановами КМ N 550 ( 550-2013-п ) від 24.07.2013 N 91 ( 91-2016-п ) від 04.02.2016 }

Кабінет Міністрів України постановляє:

Внести до актів Кабінету Міністрів України зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 грудня 2011 р. N 1312

ЗМІНИ, що вносяться до актів Кабінету Міністрів України

{ Пункт 1 втратив чинність на підставі Постанови КМ N 550 ( 550-2013-п ) від 24.07.2013 }

2. У постанові Кабінету Міністрів України від 24 січня 2002 р. N 80 ( 80-2002-п ) "Про заснування стипендії Кабінету Міністрів України для видатних спортсменів, тренерів та діячів фізичної культури і спорту" (Офіційний вісник України, 2002 р., N 4, ст. 141; 2004 р., N 31, ст. 2068; 2005 р., N 30, ст. 1800):

1) у пункті 3 слова "Державному комітетові з питань фізичної культури і спорту" і "Комітету" замінити відповідно словами "Міністерству освіти і науки, молоді та спорту" і "Міністерству";

2) у тексті Положення про стипендію Кабінету Міністрів України для видатних спортсменів, тренерів та діячів фізичної культури і спорту, затвердженого зазначеною постановою ( 80-2002-п ), слова "Державний комітет з питань фізичної культури і спорту" і "Комітет" у всіх відмінках замінити відповідно словами "Міністерство освіти і науки, молоді та спорту" і "Міністерство" у відповідному відмінку.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 91 ( 91-2016-п ) від 04.02.2016 }

4. У пункті 3 постанови Кабінету Міністрів України від 27 січня 2010 р. N 91 ( 91-2010-п ) "Про встановлення винагород спортсменам України - чемпіонам, призерам Олімпійських ігор та їх тренерам" (Офіційний вісник України, 2010 р., N 8, ст. 391) слова "Міністерству у справах сім'ї, молоді та спорту" замінити словами "Міністерству освіти і науки, молоді та спорту".
