{ Постанова втратила чинність на підставі Постанови КМ N 986 ( 986-2007-п ) від 01.08.2007 }

Про затвердження складу наглядових рад національних історико-культурних заповідників

Кабінет Міністрів України постановляє:

1. На часткову зміну постанови Кабінету Міністрів України від 2 серпня 1996 р. N 913 ( 913-96-п ) затвердити склад наглядових рад національних історико-культурних заповідників, що додається.

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 22 липня 1999 р. N 1330 ( 1330-99-п ) "Про затвердження складу наглядової ради Національного історико-етнографічного заповідника "Переяслав";

постанову Кабінету Міністрів України від 17 липня 2003 р. N 1107 ( 1107-2003-п ) "Про затвердження складу наглядової ради Національного Києво-Печерського історико-культурного заповідника".
