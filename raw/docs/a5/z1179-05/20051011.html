ПЕНСІЙНИЙ ФОНД УКРАЇНИ МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

22.09.2005 N 137/498

Зареєстровано в Міністерстві юстиції України 11 жовтня 2005 р. за N 1179/11459

Про визнання таким, що втратив чинність, наказу Пенсійного фонду України, Міністерства сільського господарства і продовольства України від 04.04.97 N 32/111

Відповідно до пункту 13 Положення про Пенсійний фонд України, затвердженого Указом Президента України від 01.03.2001 N 121 ( 121/2001 ) (із змінами), пункту 7 Положення про Міністерство аграрної політики України, затвердженого Указом Президента України від 07.06.2000 N 772 ( 772/2000 ) (із змінами), НАКАЗУЄМО:

1. Визнати таким, що втратив чинність, наказ Пенсійного фонду України, Міністерства сільського господарства і продовольства України від 04.04.97 N 32/111 ( z0152-97 ) "Про затвердження Порядку погашення суб'єктами підприємницької діяльності агропромислового комплексу заборгованості по обов'язкових платежах до Пенсійного фонду за рахунок продукції власного виробництва та майна", зареєстрований в Міністерстві юстиції України 21.04.97 за N 152/1956.

2. Юридичному управлінню Пенсійного фонду України (Рябцева Т.Б.) подати цей наказ для державної реєстрації до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Голови правління Пенсійного фонду України Зарудного О.Б.

Голова правління Пенсійного фонду України Б.О.Зайчук

Міністр аграрної політики України О.П.Баранівський
