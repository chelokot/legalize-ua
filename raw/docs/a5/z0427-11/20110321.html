МІНІСТЕРСТВО КУЛЬТУРИ І ТУРИЗМУ УКРАЇНИ

НАКАЗ

21.03.2011 N 20

Зареєстровано в Міністерстві юстиції України 31 березня 2011 р. за N 427/19165

Про доповнення Переліку національних закладів культури, для працівників яких при визначенні посадових окладів застосовується додатковий коефіцієнт підвищення посадових окладів

Відповідно до постанови Кабінету Міністрів України від 09.02.2011 N 90 ( 90-2011-п ) "Про внесення зміни в додаток до постанови Кабінету Міністрів України від 3 квітня 2006 р. N 413" НАКАЗУЮ:

1. Доповнити Перелік національних закладів культури, для працівників яких при визначенні посадових окладів застосовується додатковий коефіцієнт підвищення посадових окладів, наведений у додатку до наказу Міністерства культури і туризму України від 05.06.2006 N 385 ( z0709-06 ) "Про умови оплати праці працівників національних закладів культури", зареєстрованого у Міністерстві юстиції України 14.06.2006 за N 709/12583 (зі змінами), новим пунктом 20 такого змісту:

"20. Київський національний академічний театр оперети".

2. Цей наказ набирає чинності з дня його офіційного опублікування.

3. Контроль за виконанням наказу покласти на заступника Міністра Арсірія Я.О.

Перший заступник Міністра, Голова комісії з проведення реорганізації В.М.Андріанов
