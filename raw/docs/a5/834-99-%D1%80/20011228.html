Кабінет Міністрів України; Розпорядження від 14.08.1999 № 834-р

Про розміщення Вищого арбітражного суду

Стан: Втратив чинність

Ідентифікатор: 834-99-р

Текст документа від 28.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 серпня 1999 р. N 834-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 621 ( 621-2001-р ) від 28.12.2001 )

Прийняти пропозицію Вищого арбітражного суду про його розміщення у будинку по вул. Б. Хмельницького, 6, у м. Києві, передавши зазначений будинок в оперативне управління Суду.

НАК "Нафтогаз України" передати будинок по вул. Б. Хмельницького, 6, Вищому арбітражному суду після завершення будівництва будинку по вул. Луначарського, 2.

Взяти до відома, що вивільнені Вищим арбітражним судом приміщення у будинку по вул. Хрещатик, 5, будуть використані Кабінетом Міністрів України для розміщення в них апарату центральних органів виконавчої влади.

Держкомзв'язку забезпечити Вищий арбітражний суд телефонним зв'язком.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
