ПОСТАНОВА

N 61 від 28.08.96 Зареєстровано в Міністерстві м.Київ юстиції України 30 вересня 1996 р. vd960828 vn61 за N 557/1582

Про визначення екологічної складової тарифу на електроенергію для споживачів Донецької області

( Із змінами, внесеними згідно з Постановою Нацкомелектроенергетики N 592 ( v0592227-98 ) від 13.05.98 )

З метою фінансування робіт із встановлення на Миронівській ДРЕС головного енергоблоку з експериментальним котлоагрегатом, на якому будуть відпрацьовані режими спалювання низькосортного палива із забезпеченням європейських екологічних норм викидів у атмосферу, Національна комісія з питань регулювання електроенергетики України ПОСТАНОВЛЯЄ:

Встановити, що тарифи на електроенергію для споживачів Донецької області включають екологічну складову у розмірі 3%. ( Абзац перший в редакції Постанови Нацкомелектроенергетики N 592 ( v0592227-98 ) від 13.05.98 )

Екологічна складова не поширюється на споживачів IV тарифної групи (сільськогосподарські споживачі-виробники), споживачів VIII тарифної групи (населення), споживачів IX тарифної групи (населені пункти), а також на бюджетні організації VII тарифної групи (непромислові споживачі). ( Абзац другий із змінами, внесеними згідно з Постановою Нацкомелектроенергетики N 592 ( v0592227-98 ) від 13.05.98 )
