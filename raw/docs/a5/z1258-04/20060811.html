Про внесення змін до наказу МНС України від 28.08.2002 N 222 "Про впорядкування умов оплати праці членів екіпажів морських суден аварійно-рятувального загону МНС України"

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 222 ( z0071-03 ) від 28.08.2002, до якого вносились зміни }

На виконання постанови Кабінету Міністрів України від 25 серпня 2004 року N 1097 ( 1097-2004-п ) "Про підвищення з 1 вересня 2004 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести до наказу МНС України від 28.08.2002 N 222 ( z0071-03 ) "Про впорядкування умов оплати праці членів екіпажів морських суден аварійно-рятувального загону МНС України", зареєстрованого в Міністерстві юстиції України 29 січня 2003 року за N 71/7392, із змінами, унесеними наказами МНС України: від 26.08.2003 N 301 ( z0792-03 ) "Про внесення змін до наказу МНС України від 28.08.2002 N 222 "Про впорядкування умов оплати праці членів екіпажів морських суден аварійно-рятувального загону МНС України", зареєстрованим в Міністерстві юстиції України 10 вересня 2003 року за N 792/8113; від 01.06.2004 N 242 ( z0727-04 ) "Про внесення змін до наказу МНС України від 28.08.2002 N 222 "Про впорядкування умов оплати праці членів екіпажів морських суден аварійно-рятувального загону МНС України", зареєстрованим в Міністерстві юстиції України 14 червня 2004 року за N 727/9326, такі зміни, виклавши додатки 1-4, а також пункт 1 розділу II (Особливості оплати праці водолазів) у новій редакції, що додається.

2. Ці зміни застосовуються з 1 вересня 2004 року.

3. Контроль за виконанням цього наказу покласти на першого заступника Міністра Косолапова А.Г.

Міністр Г.В.Рева
