МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ

НАКАЗ

30.06.2011 N 785

Зареєстровано в Міністерстві юстиції України 11 липня 2011 р. за N 835/19573

Про визнання такими, що втратили чинність, деяких наказів Міністерства фінансів України

Відповідно до постанови Кабінету Міністрів України від 28.03.2011 N 346 ( 346-2011-п ) "Про ліквідацію урядових органів", наказу Міністерства фінансів України від 30.04.2011 N 574 "Про заходи щодо ліквідації Державного казначейства України" НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Міністерства фінансів України:

від 04.04.2006 N 332 ( z0454-06 ) "Про затвердження Типового положення про Головне управління Державного казначейства України в Автономній Республіці Крим, областях, містах Києві та Севастополі", зареєстрований в Міністерстві юстиції України 19.04.2006 за N 454/12328;

від 14.04.2008 N 573 ( z0354-08 ) "Про внесення зміни до Типового положення про Головне управління Державного казначейства України в Автономній Республіці Крим, областях, містах Києві та Севастополі", зареєстрований в Міністерстві юстиції України 23.04.2008 за N 354/15045;

від 11.08.2010 N 859 ( z0820-10 ) "Про внесення зміни до Типового положення про Головне управління Державного казначейства України в Автономній Республіці Крим, областях, містах Києві та Севастополі", зареєстрований в Міністерстві юстиції України 15.09.2010 за N 820/18115.

2. Департаменту забезпечення бюджетного процесу (Лозицький В.П.) в установленому порядку подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності з дня його офіційного опублікування.

4. Контроль за виконанням цього наказу покласти на першого заступника Міністра Мярковського А.І.

Міністр Ф.Ярошенко
