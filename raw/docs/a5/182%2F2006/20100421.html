Президент України; Указ від 02.03.2006 № 182/2006

Питання наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України"

Стан: Втратив чинність

Ідентифікатор: 182/2006

Текст документа від 21.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 539/2010 ( 539/2010 ) від 14.04.2010 }

{ Дію Указу відновлено згідно з Указом Президента N 200/2007 ( 200/2007 ) від 12.03.2007 }

{ Указ втратив чинність на підставі Указу Президента N 156/2007 ( 156/2007 ) від 27.02.2007 }

Питання наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України"

Відповідно до статті 7 Закону України "Про банки і банківську діяльність" ( 2121-14 ) постановляю:

на часткову зміну статей 1 і 3 Указу Президента України від 1 березня 2005 року N 390 ( 390/2005 ) "Про членів наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України":

призначити РИБАЧУКА Олега Борисовича - Главу Секретаріату Президента України - членом наглядової ради відкритого акціонерного товариства "Державний ощадний банк України" та членом наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України";

припинити повноваження члена наглядової ради відкритого акціонерного товариства "Державний ощадний банк України" Морозова О.В. та члена наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України" Капустіна В.В. на підставі поданих ними заяв.

Президент України В.ЮЩЕНКО

м. Київ, 2 березня 2006 року N 182/2006
