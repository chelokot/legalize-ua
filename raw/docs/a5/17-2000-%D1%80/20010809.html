Кабінет Міністрів України; Розпорядження від 13.01.2000 № 17-р

Про затвердження віце-прем'єр-міністра України координатором співробітництва Кабінету Міністрів України з міжнародними фінансовими організаціями

Стан: Втратив чинність

Ідентифікатор: 17-2000-р

Текст документа від 09.08.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 січня 2000 р. N 17-р Київ

( Із змінами, внесеними згідно з Розпорядженням КМ N 340-р ( 340-2001-р ) від 09.08.2001 )

1. Затвердити Віце-прем'єр-міністра України з питань економічної політики координатором співробітництва Кабінету Міністрів України з міжнародними фінансовими організаціями. ( Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 340-р ( 340-2001-р ) від 09.08.2001 )

2. Визначити відповідальними та підзвітними перед координатором за проведення переговорів з керівництвом і місіями:

Міжнародного валютного фонду за такими напрямами:

структурна політика - Міністра економіки;

бюджетна та податкова політика - Міністра фінансів;

монетарна та грошово-кредитна політика - Голову Національного банку (за згодою);

групи Світового банку, Європейського банку реконструкції та розвитку, іншими міжнародними фінансовими угрупованнями та союзами:

Міністра економіки разом з Міністром фінансів та Головою Національного банку (за згодою).

3. Установити, що:

участь у переговорах з міжнародними фінансовими організаціями беруть керівники заінтересованих органів виконавчої влади, у разі їх відсутності - особи, які виконують їх обов'язки;

перелік посадових осіб, що залучаються до участі в переговорах для обговорення проблемних питань за визначеними напрямами, затверджується Міністром економіки і Міністром фінансів.

( Пункт 4 виключено на підставі Розпорядження КМ N 340-р ( 340-2001-р ) від 09.08.2001 )

5. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 24 березня 1999 р. N 216 ( 216-99-р ).
