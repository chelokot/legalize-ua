Президент України; Розпорядження від 04.01.1995 № 3/95-рп

Про підготовку проектів міждержавних договорів про правові відносини та правову допомогу

Стан: Втратив чинність

Ідентифікатор: 3/95-рп

Текст документа від 22.09.2000:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про підготовку проектів міждержавних договорів про правові відносини та правову допомогу

( Із змінами, внесеними згідно з Розпорядженнями Президента N 399/96-рп ( 399/96-рп ) від 17.10.96 N 610/96-рп ( 610/96-рп ) від 23.11.96 N 491/98-рп ( 491/98-рп ) від 15.09.98 N 290/2000-рп ( 290/2000-рп ) від 22.09.2000 )

З метою підготовки проектів міждержавних договорів про правові відносини та правову допомогу у цивільних, шлюбно-сімейних та кримінальних справах:

1. Утворити при Міністерстві юстиції України експертну групу з питань підготовки проектів міждержавних договорів про правові відносини та правову допомогу у цивільних, шлюбно-сімейних та кримінальних справах.

( Пункт 2 втратив чинність на підставі Розпорядження Президента N 290/2000-рп ( 290/2000-рп ) від 22.09.2000 )

3. Надати керівнику експертної групи повноваження на ведення переговорів з уповноваженими представниками іноземних держав щодо прийняття текстів міждержавних договорів про правові відносини та правову допомогу у цивільних, шлюбно-сімейних та кримінальних справах чи встановлення їх автентичності.

4. Визнати такими, що втратили чинність, Розпорядження Президента України від 24 вересня 1992 року N 147 ( 147/92-рп ) "Про експертну групу з питань підготовки проектів міждержавних угод про правову допомогу" та від 13 липня 1994 року N 63 ( 63/94-рп ) "Про внесення змін до Розпорядження Президента України від 24 вересня 1992 року N 147".

Президент України Л.КУЧМА

м.Київ, 4 січня 1995 року N 3/95-рп

( Склад експертної групи з питань підготовки проектів міждержавних договорів про правові відносини та правову допомогу у цивільних, шлюбно-сімейних та кримінальних справах втратив чинність на підставі Розпорядження Президента N 290/2000-рп ( 290/2000-рп ) від 22.09.2000 )
