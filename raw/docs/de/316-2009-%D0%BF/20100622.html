Кабінет Міністрів України; Постанова від 25.03.2009 № 316

Деякі питання оплати оренди державного майна

Стан: Чинний

Ідентифікатор: 316-2009-п

Текст документа від 22.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 березня 2009 р. N 316 Київ

Деякі питання оплати оренди державного майна

{ Із змінами, внесеними згідно з Постановами КМ N 1341 ( 1341-2009-п ) від 02.12.2009 N 440 ( 440-2010-п ) від 16.06.2010 }

Кабінет Міністрів України постановляє:

1. Установити, що до 1 січня 2011 р. орендні ставки, визначені в додатку 2 до Методики розрахунку і порядку використання плати за оренду державного майна, затвердженої постановою Кабінету Міністрів України від 4 жовтня 1995 р. N 786 ( 786-95-п ) (ЗП України, 1996 р., N 2, ст. 57), крім ставок, визначених пунктами 1-3 зазначеного додатка, застосовуються у розмірі 45 відсотків встановленого обсягу.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1341 ( 1341-2009-п ) від 02.12.2009 } { На часткову зміну пункту 1 установити, що з 1 липня 2010 р. орендні ставки, зазначені у пункті 1, застосовуються у розмірі 45 відсотків установленого обсягу для орендарів - суб'єктів малого підприємництва і 80 відсотків установленого обсягу - для інших орендарів згідно з Постановою КМ N 440 ( 440-2010-п ) від 16.06.2010 }

2. Для проведення розрахунків за чинними договорами оренди державного нерухомого майна, що укладені до набрання чинності цією постановою, застосовується орендна ставка, визначена відповідно до пункту 1 цієї постанови.

{ Пункт 3 виключено на підставі Постанови КМ N 1341 ( 1341-2009-п ) від 02.12.2009 }
