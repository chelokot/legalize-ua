Про внесення змін та доповнень до наказу Держмитслужби України від 06.05.2003 N 289

Відповідно до Положення про Державну митну службу України, затвердженого Указом Президента України від 24.08.2000 N 1022 ( 1022/2000 ) "Питання Державної митної служби України", та з метою посилення контролю за повнотою і своєчасністю справляння податків та зборів, забезпечення неухильного дотримання вимог законодавства з питань оподаткування НАКАЗУЮ:

1. Внести до Типового положення про митний пост (далі - Положення), затвердженого наказом Держмитслужби України від 06.05.2003 N 289 ( z0378-03 ) і зареєстрованого в Міністерстві юстиції України 20.05.2003 за N 378/7699, такі зміни та доповнення:

1.1. Пункт 2.2 розділу 2 Положення ( z0378-03 ) викласти у такій редакції:

"2.2. Застосування відповідно до законів України заходів тарифного й нетарифного регулювання, повне та своєчасне справляння податків, зборів (інших обов'язкових платежів) при переміщенні товарів і транспортних засобів через митний кордон України або проведенні митних процедур".

1.2. Підпункт 2.7.2 пункту 2.7 розділу 2 Положення ( z0378-03 ) викласти у такій редакції:

"2.7.2. Здійснює контроль за достовірністю класифікації товарів згідно з УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14), визначення митної вартості та країни походження товарів, що переміщуються через митний кордон України".

1.3. Підпункт 2.7.11 пункту 2.7 розділу 2 Положення ( z0378-03 ) викласти у такій редакції:

"2.7.11. Вживає заходів для забезпечення справляння в повному обсязі податків, зборів (інших обов'язкових платежів) в установленому законодавством порядку".

1.4. Пункт 3.3 розділу 3 Положення ( z0378-03 ) доповнити абзацом третім такого змісту:

"повне та своєчасне справляння податків, зборів (інших обов'язкових платежів) у зоні діяльності митного поста".

У зв'язку з цим абзаци третій - п'ятий пункту 3.3 розділу 3 Положення ( z0378-03 ) вважати відповідно абзацами четвертим - шостим.

2. Начальникам регіональних митниць, митниць у десятиденний строк з моменту державної реєстрації наказу привести положення про митний пост у відповідність до нього й у місячний строк проінформувати Державну митну службу України про його виконання.

3. Департаменту податків та тарифного регулювання (Шейко О.Л.) і Департаменту правового забезпечення (Ступак Ю.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням наказу покласти на заступника Голови Служби Войцещука А.Д.

В.о. Голови Служби М.Іванюк
