Про закупівлю енергетичного вугілля

Стан: Втратив чинність

Ідентифікатор: 1416-2009-п

Текст документа від 30.01.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 грудня 2009 р. N 1416 Київ

Про закупівлю енергетичного вугілля

{ Із змінами, внесеними згідно з Постановою КМ N 59 ( 59-2010-п ) від 27.01.2010 }

Кабінет Міністрів України постановляє:

Установити, що:

відповідно до пункту 6 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006), у 2010 році за процедурою закупівлі в одного учасника без погодження з Міністерством економіки здійснюється закупівля за державні кошти: { Абзац другий постановляючої частини в редакції Постанови КМ N 59 ( 59-2010-п ) від 27.01.2010 }

- вугілля кам'яного державним підприємством "Вугілля України" у постачальників; { Абзац постановляючої частини в редакції Постанови КМ N 59 ( 59-2010-п ) від 27.01.2010 }

- енергетичного вугілля для виробництва електричної та теплової енергії енергогенеруючими компаніями, які провадять ліцензовану діяльність з виробництва електричної та/або теплової енергії, у державного підприємства "Вугілля України; { Абзац постановляючої частини в редакції Постанови КМ N 59 ( 59-2010-п ) від 27.01.2010 }

енергогенеруючі компанії надсилають у триденний строк після укладення договорів про закупівлю енергетичного вугілля їх копії Міністерству економіки та Головному контрольно-ревізійному управлінню.
