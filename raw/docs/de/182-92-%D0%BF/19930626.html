Про державні комітети та інші підвідомчі Кабінету Міністрів України органи державної виконавчої влади

Стан: Втратив чинність

Ідентифікатор: 182-92-п

Текст документа від 26.06.1993:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 квітня 1992 р. N 182 Київ

Про державні комітети та інші підвідомчі Кабінету Міністрів України органи державної виконавчої влади

( Із змінами, внесеними згідно з Постановами КМ N 166 ( 166-93-п ) від 06.03.93 N 487 ( 487-93-п ) від 26.06.93 )

На виконання Указу Президента України від 25 лютого 1992 р. ( 98/92 ) "Про зміни в системі центральних органів державної виконавчої влади України" Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. Перетворити:

Комітет по науково-технічному прогресу при Кабінеті Міністрів України у Державний комітет України з питань науки і технологій;

Державний комітет України по стандартизації, метрології та якості продукції в Державний комітет України по стандартизації, метрології та сертифікації;

Державний комітет України по харчовій і переробній промисловості в Державний комітет України по харчовій промисловості.

2. Ліквідувати Державну раду з питань економічної політики, Раду з питань державної науково-технічної політики, Державний комітет України по деревообробній промисловості та Валютний фонд України.

3. Установити, що при Кабінеті Міністрів Укараїни діють:

державні комітети:

Державний комітет України по водному господарству,

Державний комітет України по вугільній промисловості,

Державний комітет України по геології і використанню надр,

Державний комітет України по гідрометеорології,

Державний комітет України по житлово-комунальному господарству,

Державний комітет України по земельних ресурсах,

Державний комітет України по матеріальних резервах,

Державний митний комітет України,

Державний комітет України по нагляду за безпечним ведення робіт у промисловості і гірничому нагляду,

Державний комітет України по пресі,

Державний комітет України по рибному господарству і рибній промисловості,

Державний комітет у справах охорони державного кордону України,

Державний комітет України по сприянню малим підприємствам і підприємництву,

Державний комітет України по хлібопродуктах,

Державний комітет України з ядерної та радіаційної безпеки;

інші органи державної виконавчаї влади:

Комітет з питань соціального захисту військовослужбовців,

Комітет по Державних преміях України в галузі науки і техніки,

Комітет по Державних преміях України імені Т.Шевченка,

Державна інспекція України по захисту прав споживачів,

Головне архівне управління,

Головне управління геодезії, картографії та кадастру,

Головне управління по охороні державних таємниць у пресі та інших засобах масової інформації,

Національне космічне агентство України,

Державне агентство України з авторських і суміжних прав,

Вища атестаційна комісія України,

Рада в справах релігій,

Державний фонд української кінематографії.

( Пункт 3 із змінами, внесеними згідно з Постановами КМ N 166 ( 166-93-п ) від 06.03.93, N 487 ( 487-93-п ) від 26.06.93 )

4. Установити, що Міністерство транспорту України координує діяльність Державної адміністрації залізничного транспорту України, Державної адміністрації морського транспорту України, Державної адміністрації авіаційного транспорту України, підприємств й організацій корпорації "Укравтотранс", об'єднання "Укррічфлот"; Міністерство інвестицій і будівництва України - підприємств та організацій будівельних корпорацій "Укрбуд", "Укрмонтажспецбуд", "Укрбудматеріали", концернів "Укршляхбуд", "Укрцемент", "Укртрансбуд", "Укрметротунельбуд"; Міністерство сільського господарства і продовольства України - концерну "Украгротехсервіс".

5. Установити, що структура центральних апаратів міністерств, державних комітетів та інших центральних органів державної виконавчої влади затверджується віце-прем'єр-міністрами України у межах установленої Кабінетом Міністрів України чисельності працівників апарату.

6. Визнати такою, що втратила чинність, постанову Кабінету Міністрів УРСР від 24 травня 1991 р. N 12 ( 12-91-п ) "Про порядок реалізації Закону УРСР "Про перелік міністерств та інші центральні органи державного управління Української РСР" крім пунктів 3, 8 і 11.
