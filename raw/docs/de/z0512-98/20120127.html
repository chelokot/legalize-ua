ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ЕНЕРГОЗБЕРЕЖЕННЯ

НАКАЗ

N 60 від 10.08.98 Зареєстровано в Міністерстві м.Київ юстиції України 17 серпня 1998 р. за N 512/2952

{ Наказ втратив чинність на підставі Наказу Міністерства економічного розвитку і торгівлі N 408 ( z0021-12 ) від 26.12.2011 }

Про затвердження Переліку платних послуг, які надаються підприємствам та організаціям Державною інспекцією з енергозбереження

{ Із змінами, внесеними згідно з Наказами Держкоменергозбереження N 103 ( z0883-99 ) від 02.12.99 N 18 ( z0218-00 ) від 22.03.2000 N 76 ( z0595-00 ) від 27.08.2000 Наказом Національного агентства України з питань забезпечення ефективного використання енергетичних ресурсів N 89 ( z0733-07 ) від 07.06.2007 }

Відповідно до абзацу 14 пункту 4 Положення про Державну інспекцію з енергозбереження, затвердженого постановою Кабінету Міністрів України від 29 червня 2000 року N 1039 ( 1039-2000-п ), НАКАЗУЮ: { Преамбула в редакції Наказу Держкоменергозбереження N 76 ( z0595-00 ) від 27.08.2000 }

1. Затвердити та ввести в дію з моменту набрання чинності Перелік платних послуг, які надаються Державною інспекцією з енергозбереження, що додається.

2. Державній інспекції з енергозбереження (Тимошик А.М.) у п'ятнадцятиденний термін після державної реєстрації цього наказу оприлюднити його у регіонах та областях.

3. Контроль за виконанням наказу покласти на заступника Голови Комітету Лихошву Ю.В.

Т.в.о.Голови Комітету Г.М.Бабієв
