РОЗПОРЯДЖЕННЯ від 31 серпня 1991 р. N 217-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1109 ( 1109-2004-п ) від 25.08.2004 )

Про поширення дії постанови Ради Міністрів УРСР від 28 березня 1991 р. N 72

Поширити з 1 квітня 1991 р. дію пункту 13 постанови Ради Міністрів УРСР від 28 березня 1991 р. N 72 ( 72а-91-п ) "Про соціальний захист населення у зв'язку з реформою роздрібних цін" у частині встановлення стипендій устигаючим учням усіх типів професійно-технічних навчальних закладів зі строком навчання не більше 10 місяців у розмірі 85 крб. на місяць на учнів Гадяцької сільськогосподарської школи бджільництва, Закарпатської та Одеської обласних шкіл майстрів сільського будівництва, Учбово-виробничого комбінату бджільництва Мінсільгоспу України.

Витрати, пов'язані зі зміною розміру стипендій учням зазначених сільськогосподарських шкіл у 1991 році, провести в межах асигнувань, затверджених Мінсільгоспу України на підготовку кадрів.

Перший віце-прем'єр-міністр України К.МАСИК
