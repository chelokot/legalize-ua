Кабінет Міністрів України; Постанова від 01.08.2011 № 827

Про внесення змін до пункту 2 Порядку використання коштів, передбачених у державному бюджеті для фінансової підтримки розвитку інфраструктури у сфері наукової діяльності

Стан: Втратив чинність

Ідентифікатор: 827-2011-п

Текст документа від 08.09.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 серпня 2011 р. N 827 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 620 ( 620-2015-п ) від 19.08.2015 }

Про внесення змін до пункту 2 Порядку використання коштів, передбачених у державному бюджеті для фінансової підтримки розвитку інфраструктури у сфері наукової діяльності

Кабінет Міністрів України постановляє:

Внести до пункту 2 Порядку використання коштів, передбачених у державному бюджеті для фінансової підтримки розвитку інфраструктури у сфері наукової діяльності, затвердженого постановою Кабінету Міністрів України від 28 лютого 2011 р. N 273 ( 273-2011-п ) (Офіційний вісник України, 2011 p., N 20, ст. 850), такі зміни:

абзац перший після слова "з'їздів" доповнити словом ", форумів";

в абзаці другому слова "прийому офіційних іноземних делегацій" замінити словом "заходів";

доповнити пункт абзацом такого змісту:

"оплату кава-брейків, часткову оплату вартості проживання та харчування учасників VI Форуму творчої та наукової інтелігенції держав - учасниць СНД.".

Прем'єр-міністр України М.АЗАРОВ
