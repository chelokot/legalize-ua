ПРАВЛІННЯ ПЕНСІЙНОГО ФОНДУ УКРАЇНИ

ПОСТАНОВА

24.12.2009 N 28-2

Зареєстровано в Міністерстві юстиції України 30 березня 2010 р. за N 261/17556

Про затвердження Порядку взаємодії при обміні інформацією між органами Міністерства внутрішніх справ України та Пенсійного фонду України щодо захисту інтересів держави при нарахуванні та сплаті єдиного внеску на загальнообов'язкове державне соціальне страхування та інших платежів до Пенсійного фонду України

{ Із змінами, внесеними згідно з Постановою Пенсійного фонду N 20-3 ( za974-10 ) від 10.09.2010 }

Відповідно до пункту 12 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261 ( 1261-2007-п ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Затвердити Порядок взаємодії при обміні інформацією між органами Міністерства внутрішніх справ України та Пенсійного фонду України щодо захисту інтересів держави при нарахуванні та сплаті єдиного внеску на загальнообов'язкове державне соціальне страхування та інших платежів до Пенсійного фонду України, що додається ( z0261-10 ).

{ Пункт 1 із змінами, внесеними згідно з Постановою Пенсійного фонду N 20-3 ( za974-10 ) від 10.09.2010 }

2. Юридичному управлінню (Рябцева Т.Б.) разом з департаментом надходження доходів (Литвиненко В.В.) подати цю постанову на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цієї постанови покласти на заступника Голови правління Короневського В.М.

4. Ця постанова набирає чинності з дня офіційного опублікування.
