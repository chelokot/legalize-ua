Про внесення змін до Порядку надання спеціальних дозволів (ліцензій) на користування надрами

Кабінет Міністрів України постановляє:

Внести до Порядку надання спеціальних дозволів (ліцензій) на користування надрами, затвердженого постановою Кабінету Міністрів України від 31 серпня 1995 р. N 709 ( 709-95-п ) (ЗП України, 1996 р., N 1, ст. 28; Офіційний вісник України, 1997 р., число 30, с. 34; 1999 р., N 1, ст. 16, N 32, ст. 1165, N 50, ст. 2444), зміни, що додаються.

Прем'єр-міністр України А.КІНАХ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 30 травня 2002 р. N 705

ЗМІНИ, що вносяться до Порядку надання спеціальних дозволів (ліцензій) на користування надрами ( 709-95-п )
