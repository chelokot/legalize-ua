ПОСТАНОВА від 14 лютого 2001 р. N 142 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 808 ( 808-2013-п ) від 28.08.2013 }

Про внесення зміни до постанови Кабінету Міністрів України від 27 липня 1995 р. N 554

Кабінет Міністрів України постановляє:

Пункт 4 переліку видів діяльності та об'єктів, що становлять підвищену екологічну небезпеку, затвердженого постановою Кабінету Міністрів України від 27 липня 1995 р. N 554 ( 554-95-п ) (ЗП України, 1995 р., N 10, ст. 252), доповнити абзацом "Автозаправні станції".
