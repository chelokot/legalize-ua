{ Розпорядження втратило чинність на підставі Розпорядження КМ N 629-р ( 629-2006-р ) від 22.12.2006 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 17 листопада 2004 р. N 832

На часткову зміну абзацу другого розпорядження Кабінету Міністрів України від 17 листопада 2004 р. N 832 ( 832-2004-р ) уповноважити Міністра освіти і науки Ніколаєнка Станіслава Миколайовича підписати Угоду між Кабінетом Міністрів України та Урядом Російської Федерації про взаємну охорону прав на результати інтелектуальної діяльності, що використовуються та отримані в ході двостороннього військово-технічного співробітництва.

Прем'єр-міністр України Ю.ТИМОШЕНКО
