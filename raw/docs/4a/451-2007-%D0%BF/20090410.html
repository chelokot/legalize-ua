КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 березня 2007 р. N 451 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для обслуговування кредитних ресурсів, залучених для реалізації проекту "Циклон-4"

{ Із змінами, внесеними згідно з Постановою КМ N 241 ( 241-2008-п ) від 26.03.2008 }

{ Установити, що у 2008 році кошти, передбачені у державному бюджеті ( 107-17 ) Національному космічному агентству за бюджетною програмою "Обслуговування кредитів, залучених для реалізації проекту "Циклон-4", використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 241 ( 241-2008-п ) від 26.03.2008 }

{ Установити, що у 2009 році кошти, передбачені у державному бюджеті ( 835-17 ) за програмою "Обслуговування кредитів, залучених для реалізації проекту "Циклон-4", використовуються відповідно до Порядку, затвердженого цією Постановою, з урахуванням особливостей, зазначених в Постанові КМ N 304 ( 304-2009-п ) від 02.04.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для обслуговування кредитних ресурсів, залучених для реалізації проекту "Циклон-4", що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 березня 2007 р. N 451

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для обслуговування кредитних ресурсів, залучених для реалізації проекту "Циклон-4"

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) НКАУ за програмою "Обслуговування кредитів, залучених для реалізації проекту "Циклон-4" (далі - бюджетні кошти).

2. Одержувачем бюджетних коштів є Державне конструкторське бюро "Південне" імені М.К.Янгеля, м. Дніпропетровськ (далі - Конструкторське бюро).

3. Бюджетні кошти спрямовуються на забезпечення обслуговування кредитних ресурсів, залучених для реалізації проекту "Циклон-4", шляхом їх перерахування Конструкторському бюро.

За рахунок бюджетних коштів сплачується різниця між сумою відсотків, нарахованих за користування кредитними ресурсами відповідно до умов договору від 18 листопада 2004 р., укладеного між Конструкторським бюро і лондонською філією банку "Кредит Свісс Фьорст Бостон Інтернешнл" (далі - кредитний договір), та інших платежів, пов'язаних з обслуговуванням кредитних ресурсів, і сумою доходів, отриманих Конструкторським бюро від розміщення в установах банків тимчасово вільних кредитних ресурсів на депозитних рахунках (далі - розміщені кредитні кошти) станом на 5 травня та 5 листопада 2008 року. { Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 241 ( 241-2008-п ) від 26.03.2008 }

У разі коли розмір процентної ставки за розміщеними Конструкторським бюро кредитними коштами у національній або іноземній валюті в установах банків нижче від найменшого розміру середньозваженої процентної ставки за залученими депозитами (у розрізі видів валюти) за останні 12 місяців, що наводиться у бюлетені Національного банку за місяць, який передує місяцю використання бюджетних коштів, НКАУ здійснює розрахунок доходів Конструкторського бюро, отриманих від розміщення кредитних коштів, виходячи з найменшого розміру середньозваженої процентної ставки.

4. Конструкторське бюро до 5 травня та 5 листопада 2008 р. подає НКАУ довідку про суму розміщених кредитних коштів, отриманий від цього дохід та розрахунок платежів, що підлягають внесенню відповідно до умов кредитного договору. { Абзац перший пункту 4 із змінами, внесеними згідно з Постановою КМ N 241 ( 241-2008-п ) від 26.03.2008 }

НКАУ на підставі зазначених документів готує та подає Державному казначейству доручення щодо перерахування бюджетних коштів Конструкторському бюро для здійснення обслуговування кредитних ресурсів за десять робочих днів до дати внесення платежу згідно з кредитним договором.

5. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку. { Пункт 5 в редакції Постанови КМ N 241 ( 241-2008-п ) від 26.03.2008 }
