( Постанова втратила чинність на підставі Постанови Ради Міністрів УРСР N 93 ( 93-81-п ) від 17.02.81 )

Про створення Комісії Президії Ради Міністрів Української РСР з питань галузей групи "Б"

З метою забезпечення систематичного контролю за ходом виконання завдань державних планів по розвитку галузей промисловості, які виробляють товари народного споживання, та координації діяльності відповідних міністерств по випуску вказаних товарів Центральний Комітет Компартії України і Рада Міністрів Української РСР постановляють:

Створити Комісію Президії Ради Міністрів Української РСР з питань галузей групи "Б" у такому складі:
