Про роздрібні ціни на газ природний, що використовується для потреб населення

{ Із змінами, внесеними зідно з Постановою Національної комісії регулювання електроенергетики N 1034 ( z0986-06 ) від 03.08.2006 }

Відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", на виконання пункту 1 постанови Кабінету Міністрів України від 29.04.2006 N 605 ( 605-2006-п ) "Деякі питання діяльності Національної акціонерної компанії "Нафтогаз України", ураховуючи погодження Міністерством економіки України граничного рівня оптової ціни підприємств на газ природний, що використовується для потреб населення (лист від 07.06.2006 N 89-24/43), Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Затвердити роздрібні ціни на газ природний, що використовується для потреб населення, що додаються, крім населення смт Солотвина Закарпатської області, яке споживає газ природний безпосередньо із Солотвинського родовища.

{ Пункт 1 в редакції Постанови НКРЕ N 1034 ( z0986-06 ) від 03.08.2006 }

2. Управлінню регулювання та цінової політики нафтогазового комплексу в установленому порядку забезпечити подання цієї постанови на державну реєстрацію до Міністерства юстиції України.

3. Постанову НКРЕ від 30.03.2006 N 400 ( z0412-06 ) "Про роздрібні ціни на газ природний, що використовується для потреб населення", зареєстровану в Міністерстві юстиції України 11.04.2006 за N 412/12286, визнати такою, що втратила чинність.

4. Ця постанова набуває чинності з 1 липня 2006 року.

Голова Комісії В.Кальченко
