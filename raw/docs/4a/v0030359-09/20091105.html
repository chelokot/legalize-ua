форму акта приймання-передачі оптичного носія з електронною копією бази даних Державного реєстру виборців (оптичних носіїв з вторинними електронними копіями окремих частин бази даних Державного реєстру виборців), оптичного носія з програмою установки спеціалізованого програмного забезпечення для перегляду копій баз даних Державного реєстру виборців та відповідними інструктивними матеріалами, носія (носіїв) ключової інформації (додаток 4);

ПОРЯДОК надання електронної копії бази даних Державного реєстру виборців представнику політичної партії для здійснення політичною партією публічного контролю ведення Державного реєстру виборців

I. Загальні положення

1.1. Цей Порядок відповідно до статті 24 Закону України "Про Державний реєстр виборців" ( 698-16 ) (далі - Закон) встановлює процедуру надання представнику політичної партії для здійснення політичною партією публічного контролю ведення Державного реєстру виборців (далі - Реєстр) електронної копії бази даних Реєстру, виготовлення вторинних електронних копій окремих частин бази даних Реєстру, а також повернення Центральній виборчій комісії електронної копії бази даних Реєстру та електронних копій окремих її частин.

1.2. Електронна копія бази даних Реєстру надається представнику політичної партії, яка має свою фракцію у поточному скликанні Верховної Ради України, а також політичної партії, що входить до складу блоку, який має свою фракцію у поточному скликанні Верховної Ради України, уповноваженому відповідним керівним органом політичної партії.

1.3. Для передачі представнику політичної партії виготовляється електронна копія бази даних Реєстру, розділена на частини відповідно до органів ведення Реєстру, що включає ідентифікаційні персональні дані виборців, виборча адреса яких належить до території, на яку поширюються повноваження відповідного органу ведення Реєстру, та персональні дані, що визначають місце та умови голосування виборців.

1.4. Електронна копія бази даних Реєстру надається уповноваженому представнику політичної партії протягом місяця після завершення щорічного уточнення Реєстру, а також не пізніш як за 60 днів до дня голосування на виборах Президента України, виборах народних депутатів України, всеукраїнському референдумі, чергових місцевих виборах або позачергових місцевих виборах, які проводяться на всій території України.

1.5. Політична партія використовує надану їй електронну копію бази даних Реєстру, виготовлені вторинні електронні копії окремої частини бази даних Реєстру лише для здійснення в порядку публічного контролю перевірки повноти та достовірності персональних даних Реєстру з дотриманням вимог законодавства України.

II. Виготовлення електронної копії бази даних Реєстру та вторинних електронних копій окремих частин бази даних Реєстру

2.1. Електронна копія бази даних Реєстру виготовляється на письмову вимогу політичної партії, зазначеної у пункті 1.2 цього Порядку, подану до Центральної виборчої комісії.

У зверненні із вказаною вимогою зазначаються прізвище, ім'я, по батькові уповноваженого представника політичної партії, дані документа, що посвідчує особу представника та його належність до громадянства України, місце проживання із зазначенням адреси житла, номер засобу зв'язку, адреса електронної пошти (якщо така є). Звернення підписується керівником політичної партії та скріплюється печаткою цієї партії.

До звернення додається рішення керівного органу політичної партії, яким представника цієї партії уповноважено отримати електронну копію бази даних Реєстру.

2.2. Виготовлення електронної копії бази даних Реєстру здійснюється Службою розпорядника Державного реєстру виборців (далі - Служба розпорядника Реєстру) за допомогою технічних засобів автоматизованої інформаційно-телекомунікаційної системи Реєстру (далі - АІТС Реєстру) з використанням відповідних інструктивних матеріалів щодо виготовлення електронних копій баз даних Реєстру та ініціалізації носіїв ключової інформації.

2.3. Політична партія може самостійно виготовити по одній вторинній електронній копії кожної окремої частини бази даних Реєстру (відповідно до записів бази даних Реєстру, що стосуються виборців, виборча адреса яких відноситься до території, на яку поширюються повноваження органу ведення Реєстру) виключно за дозволом Центральної виборчої комісії, який надається рішенням Центральної виборчої комісії.

Виготовлення вторинних електронних копій кожної окремої частини бази даних Реєстру здійснюється у приміщенні Центральної виборчої комісії з використанням технічних засобів АІТС Реєстру в присутності та під контролем відповідальних працівників Служби розпорядника Реєстру.

2.4. Електронна копія бази даних Реєстру та вторинні електронні копії кожної окремої частини бази даних Реєстру записуються на оптичні носії, які надаються представнику політичної партії, та засвідчуються електронним цифровим підписом уповноваженої на це посадової особи Служби розпорядника Реєстру. { Пункт 2.4 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 258 ( v0258359-09 ) від 05.11.2009 }

2.5. До електронних копій бази даних Реєстру та окремих частин бази даних Реєстру додаються:

1) програма установки спеціалізованого програмного забезпечення для перегляду копій баз даних Реєстру;

2) інструктивні матеріали;

3) носій ключової інформації з персональним ідентифікаційним номером і персональним кодом розблокування.

III. Надання політичній партії електронної копії бази даних Реєстру, виготовлення вторинних електронних копій окремих частин бази даних Реєстру

3.1. Оптичний носій з електронною копією бази даних Реєстру, вторинними електронними копіями кожної окремої частини бази даних Реєстру, а також оптичний носій з програмою установки спеціалізованого програмного забезпечення для перегляду копій баз даних Реєстру та відповідними інструктивними матеріалами, носій ключової інформації, запечатаний конверт із персональним ідентифікаційним номером та персональним кодом розблокування, що надаються представникам політичних партій, реєструються Службою розпорядника Реєстру з нанесенням на них реєстраційних номерів, про що здійснюється відповідний запис у журналі, який ведеться за встановленою формою.

3.2. Служба розпорядника Реєстру встановлює дату передачі уповноваженому представнику політичної партії електронної копії бази даних Реєстру чи виготовлення вторинних електронних копій окремих частин бази даних Реєстру, про що письмово повідомляється уповноважений представник політичної партії.

3.3. Уповноважений представник політичної партії особисто отримує електронну копію бази даних Реєстру, вторинні електронні копії кожної окремої частини бази даних Реєстру, засвідчені електронним цифровим підписом, на оптичних носіях, носій ключової інформації, запечатаний конверт із персональним ідентифікаційним номером та персональним кодом розблокування, програму установки спеціалізованого програмного забезпечення для перегляду копій баз даних Реєстру, інструктивні матеріали у приміщенні, визначеному Службою розпорядника Реєстру, про що складається акт за встановленою формою.

Зазначений акт складається у двох примірниках, один з яких надається уповноваженому представнику політичної партії, а другий - зберігається в Центральній виборчій комісії.

При отриманні оптичних носіїв з електронними копіями бази даних Реєстру, носія ключової інформації, конверту із персональним ідентифікаційним номером та персональним кодом розблокування уповноважений представник політичної партії пред'являє документ, що посвідчує його особу та належність до громадянства України.

Передача носія ключової інформації здійснюється за договором відповідно до Положення про порядок розроблення, виробництва та експлуатації засобів криптографічного захисту конфіденційної інформації та відкритої інформації з використанням електронного цифрового підпису, затвердженого наказом Адміністрації Державної служби спеціального зв'язку та захисту інформації України від 20 липня 2007 року N 141 ( z0862-07 ).

{ Пункт 3.3 доповнено абзацом четвертим згідно з Постановою Центральної виборчої комісії N 258 ( v0258359-09 ) від 05.11.2009 }

3.4. Про надання представнику політичної партії електронної копії бази даних Реєстру, виготовлення вторинних електронних копій окремої частини бази даних Реєстру Центральна виборча комісія повідомляє спеціально уповноважений центральний орган виконавчої влади з питань організації спеціального зв'язку та захисту інформації, який відповідно до закону здійснює контроль за забезпеченням захисту інформації, яка є власністю держави, або інформації з обмеженим доступом, вимога щодо захисту якої встановлена законом.

3.5. Електронна копія бази даних Реєстру, вторинні електронні копії окремих частин бази даних Реєстру не можуть передаватися будь-яким особам з іншою метою, ніж здійснення відповідною політичною партією публічного контролю ведення Реєстру.

IV. Повернення політичною партією електронної копії бази даних Реєстру та вторинних електронних копій окремих частин бази даних Реєстру Центральній виборчій комісії

4.1. Політична партія не пізніш як через місяць після отримання електронної копії бази даних Реєстру зобов'язана повернути Центральній виборчій комісії отриману раніше електронну копію бази даних Реєстру та всі виготовлені вторинні електронні копії окремих частин бази даних Реєструна оптичних носіях, засвідчені електронним цифровим підписом, а також носій ключової інформації, оптичний носій з програмою установки спеціалізованого програмного забезпечення для перегляду копій баз даних Реєстру та інструктивними матеріалами.

4.2. Політична партія, яка за підсумками виборів народних депутатів України перестала відповідати вимогам частини першої статті 24 Закону ( 698-16 ), втрачає право надалі отримувати копії бази даних Реєстру. Така партія зобов'язана не пізніш як через три місяці після цих виборів повернути розпоряднику Реєстру отриману копію бази даних Реєстру та всі вторинні електронні копії окремих її частин.

4.3. Про повернення електронної копії бази даних Реєстру, вторинних електронних копій окремих частин бази даних Реєстру на оптичних носіях, засвідчених електронним цифровим підписом, носія ключової інформації, оптичного носія з програмою установки спеціалізованого програмного забезпечення для перегляду копій баз даних Реєстру та інструктивними матеріалами складається акт у двох примірниках за встановленою формою.

Один примірник зазначеного акта надається уповноваженому представнику політичної партії, а другий - зберігається в Центральній виборчій комісії.

{ Пункт 4.3 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 258 ( v0258359-09 ) від 05.11.2009 }

V. Облік наданих електронних копій бази даних Реєстру та вторинних електронних копій окремих частин бази даних Реєстру

5.1. 5.2. Центральна виборча комісія здійснює контроль за поверненням електронних копій бази даних Реєстру, вторинних електронних копій окремих частин бази даних Реєстру.
