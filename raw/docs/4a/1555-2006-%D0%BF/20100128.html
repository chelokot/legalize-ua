Кабінет Міністрів України; Постанова від 08.11.2006 № 1555

Питання оплати праці, медичного та соціально-побутового забезпечення деяких працівників Національної академії державного управління при Президентові України

Стан: Чинний

Ідентифікатор: 1555-2006-п

Текст документа від 28.01.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 листопада 2006 р. N 1555 Київ

Питання оплати праці, медичного та соціально-побутового забезпечення деяких працівників Національної академії державного управління при Президентові України

{ Із змінами, внесеними згідно з Постановою КМ N 37 ( 37-2010-п ) від 20.01.2010 }

Кабінет Міністрів України постановляє:

Установити, що:

за умовами оплати праці директори інститутів Національної академії державного управління при Президентові України прирівнюються до відповідних працівників вищих навчальних закладів IV рівня акредитації, що мають статус національних; { Абзац другий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 37 ( 37-2010-п ) від 20.01.2010 }

за умовами медичного та соціально-побутового забезпечення президент прирівнюється до керівника, перший віце-президент - до першого заступника керівника, віце-президенти та директори інститутів Національної академії державного управління при Президентові України - до заступників керівників центральних органів виконавчої влади, що не входять до складу Кабінету Міністрів України.

Прем'єр-міністр України В.ЯНУКОВИЧ
