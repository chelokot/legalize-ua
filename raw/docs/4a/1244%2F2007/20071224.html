Президент України; Указ від 24.12.2007 № 1244/2007

Питання Секретаріату Президента України

Стан: Чинний

Ідентифікатор: 1244/2007

Текст документа від 24.12.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Секретаріату Президента України

1. Внести до указів Президента України такі зміни:

1) в Указі Президента України від 14 жовтня 2005 року N 1445 ( 1445/2005 ) "Про створення Секретаріату Президента України" (зі змінами, внесеними Указами від 2 жовтня 2006 року N 814 ( 814/2006 ), від 19 лютого 2007 року N 120 ( 120/2007 ), від 26 лютого 2007 року N 143 ( 143/2007 ), від 23 березня 2007 року N 238 ( 238/2007 ), від 5 квітня 2007 року N 276 ( 276/2007 ), від 6 червня 2007 року N 507 ( 507/2007 ), від 3 вересня 2007 року N 815 ( 815/2007 ) та від 9 листопада 2007 року N 1079) ( 1079/2007 ):

а) частину другу статті 2 викласти в такій редакції:

"Глава Секретаріату Президента України має Першого заступника Глави Секретаріату Президента України - Представника Президента України у Кабінеті Міністрів України та сімох заступників, у тому числі заступника Глави Секретаріату Президента України - Представника Президента України у Верховній Раді України, заступника Глави Секретаріату Президента України - Представника Президента України у Конституційному Суді України та заступника Глави Секретаріату Президента України - Уповноваженого Президента України з питань контролю за діяльністю Служби безпеки України";

б) у статті 4:

абзаци третій і четвертий викласти відповідно в такій редакції:

"Перший заступник Глави Секретаріату Президента України - Представник Президента України у Кабінеті Міністрів України;

заступники Глави Секретаріату Президента України, в тому числі заступник Глави Секретаріату Президента України - Представник Президента України у Верховній Раді України, заступник Глави Секретаріату Президента України - Представник Президента України у Конституційному Суді України, заступник Глави Секретаріату Президента України - Уповноважений Президента України з питань контролю за діяльністю Служби безпеки України";

абзац п'ятий виключити;

доповнити статтю абзацом такого змісту: "Служба підготовки виступів Президента України";

в) Схему розподілу обов'язків між Главою Секретаріату Президента України, його першими заступниками та заступниками, закріплення за ними структурних підрозділів ( 1445а/2005 ), затверджену зазначеним Указом ( 1445/2005 ), викласти в новій редакції, що додається ( 1244а/2007 );

2) у Положенні про Секретаріат Президента України, затвердженому Указом Президента України від 4 листопада 2005 року N 1548 ( 1548/2005 ) "Питання Секретаріату Президента України" (зі змінами, внесеними Указами від 18 листопада 2005 року N 1614 ( 1614/2005 ), від 2 жовтня 2006 року N 814 ( 814/2006 ), від 19 лютого 2007 року N 120 ( 120/2007 ), від 26 лютого 2007 року N 143 ( 143/2007 ), від 5 квітня 2007 року N 276 ( 276/2007 ), від 6 червня 2007 року N 507 ( 507/2007 ) та від 9 листопада 2007 року N 1079) ( 1079/2007 ):

а) у пункті 7:

абзаци третій і четвертий викласти відповідно в такій редакції:

"Перший заступник Глави Секретаріату Президента України - Представник Президента України у Кабінеті Міністрів України;

заступники Глави Секретаріату Президента України, в тому числі заступник Глави Секретаріату Президента України - Представник Президента України у Верховній Раді України, заступник Глави Секретаріату Президента України - Представник Президента України у Конституційному Суді України, заступник Глави Секретаріату Президента України - Уповноважений Президента України з питань контролю за діяльністю Служби безпеки України";

абзац п'ятий виключити;

б) у абзаці першому пункту 8:

слова "перші заступники Глави Секретаріату Президента України" замінити словами "Перший заступник Глави Секретаріату Президента України - Представник Президента України у Кабінеті Міністрів України";

слова "Представник Президента України у Верховній Раді України" виключити;

в) у підпункті 4 пункту 9:

слова "перших заступників Глави Секретаріату Президента України" замінити словами "Першого заступника Глави Секретаріату Президента України - Представника Президента України у Кабінеті Міністрів України";

слова "Представника Президента України у Верховній Раді України" виключити;

г) у пункті 10:

абзац перший викласти в такій редакції:

"Перший заступник Глави Секретаріату Президента України - Представник Президента України у Кабінеті Міністрів України, заступники Глави Секретаріату Президента України виконують обов'язки відповідно до Схеми розподілу обов'язків між Главою Секретаріату Президента України, його Першим заступником та заступниками, закріплення за ними структурних підрозділів ( 1445а/2005 ), яка затверджується Президентом України";

доповнити пункт після абзацу другого новим абзацом такого змісту:

"Заступник Глави Секретаріату Президента України - Представник Президента України у Верховній Раді України також представляє Президента України у відносинах з Верховною Радою України".

У зв'язку з цим абзаци третій - п'ятий вважати відповідно абзацами четвертим - шостим.

абзац шостий викласти у такій редакції:

"У разі відсутності Глави Секретаріату Президента України його повноваження здійснює Перший заступник Глави Секретаріату Президента України - Представник Президента України у Кабінеті Міністрів України, а за відсутності Першого заступника Глави Секретаріату Президента України - Представника Президента України у Кабінеті Міністрів України - визначений відповідним рішенням Глави Секретаріату Президента України заступник Глави Секретаріату Президента України";

д) абзац перший пункту 11 виключити.

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 24 грудня 2007 року N 1244/2007
