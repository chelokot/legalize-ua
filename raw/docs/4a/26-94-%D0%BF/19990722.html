Про перелік посад, що заміщуються вищим начальницьким складом в органах внутрішніх справ

{ Із змінами, внесеними згідно з Постановами КМ N 258 ( 258-94-п ) від 27.04.94 N 317 ( 317-94-п ) від 18.05.94 N 617 ( 617-98-п ) від 06.05.98 N 1296 ( 1296-98-п ) від 17.08.98 N 1338 ( 1338-99-п ) від 22.07.99 }

Відповідно до постанови Верховної Ради України від 22 квітня 1993 р. ( 3135-12 ) "Про спеціальні звання, формений одяг та знаки розрізнення в органах внутрішніх справ України" Кабінет Міністрів України постановляє:

1. Затвердити перелік посад, що заміщуються вищим начальницьким складом в органах внутрішніх справ, та граничні спеціальні звання за цими посадами згідно з додатком.

2. Визнати таким, що втратив чинність, пункт 2 постанови Кабінету Міністрів України від 15 лютого 1992 р. N 75 ( 75-92-п ).
