Питання Представництва Президента України в Автономній Республіці Крим

Стан: Втратив чинність

Ідентифікатор: 1433/2005

Текст документа від 07.06.2014:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 487/2014 ( 487/2014 ) від 24.05.2014 }

Питання Представництва Президента України в Автономній Республіці Крим

{ Із змінами, внесеними згідно з Указами Президента N 1134/2006 ( 1134/2006 ) від 27.12.2006 N 364/2007 ( 364/2007 ) від 28.04.2007 N 554/2007 ( 554/2007 ) від 25.06.2007 N 832/2007 ( 832/2007 ) від 07.09.2007 N 997/2008 ( 997/2008 ) від 04.11.2008 }

З метою підвищення ефективності діяльності Представництва Президента України в Автономній Республіці Крим, забезпечення належного виконання завдань та повноважень, покладених на нього Конституцією України ( 254к/96-ВР ), Законом України "Про Представництво Президента України в Автономній Республіці Крим" ( 1524-14 ) та актами Президента України, постановляю:

1. Затвердити:

нову структуру Представництва Президента України в Автономній Республіці Крим (додається);

{ Абзац третій статті 1 втратив чинність на підставі Указу Президента N 997/2008 ( 997/2008 ) від 04.11.2008 }

2. Установити, що Постійний Представник Президента України в Автономній Республіці Крим має чотирьох заступників, у тому числі одного першого.

{ Стаття 2 із змінами, внесеними згідно з Указами Президента N 1134/2006 ( 1134/2006 ) від 27.12.2006, N 364/2007 ( 364/2007 ) від 28.04.2007, N 554/2007 ( 554/2007 ) від 25.06.2007, N 832/2007 ( 832/2007 ) від 07.09.2007 }

3. Постійному Представникові Президента України в Автономній Республіці Крим:

затвердити у місячний строк штатний розпис Представництва Президента України в Автономній Республіці Крим, положення про його структурні підрозділи та визначити посадові обов'язки працівників;

забезпечити вирішення в установленому порядку питань, пов'язаних зі зміною структури Представництва.

4. Кабінету Міністрів України:

вирішити у двотижневий строк питання вдосконалення умов оплати праці працівників Представництва Президента України в Автономній Республіці Крим та віднесення їх посад до відповідних категорій посад державних службовців;

забезпечити разом із Державним управлінням справами поліпшення фінансового та матеріально-технічного забезпечення діяльності Представництва Президента України в Автономній Республіці Крим, зокрема вирішити питання щодо виділення коштів, необхідних для завершення реконструкції будівлі для розміщення Представництва;

привести свої рішення у відповідність із цим Указом.

5. Визнати такими, що втратили чинність:

статті 1 та 2 Указу Президента України від 22 липня 2000 року N 911 ( 911/2000 ) "Питання Представництва Президента України в Автономній Республіці Крим";

Указ Президента України від 14 грудня 2000 року N 1336 ( 1336/2000 ) "Про внесення зміни до Указу Президента України від 22 липня 2000 року N 911";

Указ Президента України від 4 липня 2003 року N 564 ( 564/2003 ) "Про внесення змін до структури Представництва Президента України в Автономній Республіці Крим";

Указ Президента України від 30 квітня 2004 року N 496 ( 496/2004 ) "Про внесення змін до Указу Президента України від 22 липня 2000 року N 911".
