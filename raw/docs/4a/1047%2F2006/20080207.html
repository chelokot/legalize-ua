Про делегацію України для участі у переговорах між Україною та офісом Секретаря Міжнародного кримінального трибуналу для колишньої Югославії щодо підготовки проекту Угоди між Україною та Організацією Об'єднаних Націй про виконання вироків Міжнародного кримінального трибуналу для колишньої Югославії

Ідентифікатор: 1047/2006

Текст документа від 07.02.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у переговорах між Україною та офісом Секретаря Міжнародного кримінального трибуналу для колишньої Югославії щодо підготовки проекту Угоди між Україною та Організацією Об'єднаних Націй про виконання вироків Міжнародного кримінального трибуналу для колишньої Югославії

1. Утворити делегацію України для участі у переговорах між Україною та офісом Секретаря Міжнародного кримінального трибуналу для колишньої Югославії щодо підготовки проекту Угоди між Україною та Організацією Об'єднаних Націй про виконання вироків Міжнародного кримінального трибуналу для колишньої Югославії (м. Гаага, Королівство Нідерланди) у такому складі:

ГОРБУНОВА - заступник Міністра юстиції України,

Лідія Миколаївна глава делегації

ДВОЙНІС - начальник управління Державного

Олексій Григорович департаменту України з питань виконання покарань

ПЕРЕВЕЗЕНЦЕВ - головний консультант Головної

Олексій Юрійович служби зовнішньої політики Секретаріату Президента України

ФІЛАТОВ - суддя Верховного Суду України (за

Василь Миколайович згодою)

ШЕВЧЕНКО - заступник директора Департаменту

Катерина Георгіївна міжнародного співробітництва Міністерства юстиції України.

Дозволити главі делегації України вносити в разі потреби зміни до складу делегації, залучаючи до роботи в ній членів Експертної групи з підготовки проектів міжнародних договорів України про правові відносини та правову допомогу у цивільних і кримінальних справах, утвореної Указом Президента України від 24 квітня 2004 року N 476 ( 476/2004 ).

2. Міністерству юстиції України за погодженням з Міністерством закордонних справ України затвердити вказівки делегації України на переговори.

3. Кабінету Міністрів України вирішити питання щодо виділення коштів в іноземній валюті для забезпечення участі у переговорах делегації України.

Президент України В.ЮЩЕНКО
