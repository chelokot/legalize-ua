Стан: Чинний

Ідентифікатор: z0871-05

Текст документа від 08.08.2005:

МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ПО ЗЕМЕЛЬНИХ РЕСУРСАХ

НАКАЗ

08.08.2005 N 84/5/232

Зареєстровано в Міністерстві юстиції України 9 серпня 2005 р. за N 871/11151

Про визнання таким, що втратив чинність, спільного наказу Міністерства юстиції України, Державного комітету України по земельних ресурсах від 06.06.96 N 14/5/48

З метою приведення нормативно-правових актів у відповідність до Цивільного ( 435-15 ) та Земельного ( 2768-14 ) кодексів України, Закону України "Про засади державної регуляторної політики у сфері господарської діяльності" ( 1160-15 ) НАКАЗУЄМО:

1. Визнати таким, що втратив чинність, спільний наказ Міністерства юстиції України, Державного комітету України по земельних ресурсах від 06.06.96 N 14/5/48 ( z0324-96 ) "Про затвердження Порядку посвідчення договорів відчуження земельних ділянок", зареєстрований у Міністерстві юстиції України 24.06.96 за N 324/1349 (із змінами).

2. Департаменту нотаріату та реєстрації адвокатських об'єднань Міністерства юстиції України (Павлова Л.М.) та Управлінню справами Державного комітету України по земельних ресурсах (Кудін В.І.) довести цей наказ до відома начальника Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, начальників обласних, Київського та Севастопольського міських управлінь юстиції та голови Республіканського комітету по земельних ресурсах Автономної Республіки Крим, начальників обласних, Київського та Севастопольського міських головних управлінь земельних ресурсів відповідно.

3. Контроль за виконанням цього наказу покласти: у Міністерстві юстиції України - на заступника Міністра юстиції України Л.В.Єфіменка, у Державному комітеті України по земельних ресурсах - на заступника Голови Державного комітету України по земельних ресурсах В.В.Жмуцького.

Міністр юстиції України Р.М.Зварич

Голова Державного комітету України по земельних ресурсах А.С.Даниленко
