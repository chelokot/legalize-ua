Стан: Втратив чинність

Ідентифікатор: 3691-17

Текст документа від 20.10.2019:

ЗАКОН УКРАЇНИ

{ Закон втратив чинність на підставі Закону N 145-IX ( 145-20 ) від 02.10.2019, ВВР, 2019, N 46, ст.302 }

Про внесення зміни до Закону України "Про перелік об'єктів права державної власності, що не підлягають приватизації" щодо виключення з переліку підприємств, що не підлягають приватизації, готелю "Спорт"

( Відомості Верховної Ради України (ВВР), 2012, N 15, ст.93 )

Верховна Рада України постановляє:

1. Внести зміну до переліку об'єктів права державної власності, що не підлягають приватизації, затвердженого Законом України "Про перелік об'єктів права державної власності, що не підлягають приватизації" ( 847-14 ) (Відомості Верховної Ради України, 1999 р., N 37, ст. 332 із наступними змінами), згідно з додатком.

2. Цей Закон набирає чинності з дня його опублікування.
