КАБІНЕТ МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 16 серпня 1991 р. N 141 Київ

Про структуру Секретаріату Кабінету Міністрів УРСР

( Із змінами, внесеними згідно з Постановою КМ N 186 ( 186-91-п ) від 06.09.91 )

Кабінет Міністрів Української РСР постановляє:

1. Затвердити структуру Секретаріату Кабінету Міністрів УРСР (додається).

2. Установити чисельність працівників апарату Кабінету Міністрів УРСР в кількості 485 одиниць.
