Текст документа від 01.09.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 серпня 2007 р. N 1062 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 654 ( 654-2008-п ) від 16.07.2008 }

Про підвищення рівня матеріального забезпечення окремих категорій населення

Кабінет Міністрів України постановляє:

Установити, що щомісячна державна адресна допомога до пенсії (дотація), передбачена пунктом 1 постанови Кабінету Міністрів України від 3 травня 2007 р. N 684 ( 684-2007-п ) "Про поліпшення матеріального забезпечення окремих категорій населення" (Офіційний вісник України, 2007 р., N 32, ст. 1312), надається з 1 вересня 2007 р. без урахування пенсій за особливі заслуги перед Україною.

Прем'єр-міністр України В.ЯНУКОВИЧ
