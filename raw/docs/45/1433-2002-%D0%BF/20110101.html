КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 вересня 2002 р. N 1433 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1171 ( 1171-2010-п ) від 22.12.2010 }

Про внесення змін до постанови Кабінету Міністрів України від 7 червня 1999 р. N 983

Кабінет Міністрів України постановляє:

Внести до абзацу другого постанови Кабінету Міністрів України від 7 червня 1999 р. N 983 ( 983-99-п ) "Про поліпшення забезпечення інвалідів по зору деякими засобами реабілітації" (з доповненнями, внесеними постановою Кабінету Міністрів України від 28 грудня 2000 р. N 1918 ( 1918-2000-п ) такі зміни:

слова "телевізійні зменшувальні прилади" замінити словами "телевізійні збільшувальні прилади";

доповнити абзац словами "комплекси для друкування продукції шрифтом Брайля, комплекси для друкування продукції укрупненим шрифтом, комплекси для друкування продукції рельєфно-графічним способом, комп'ютерні тифлокомплекси, комп'ютери і адаптивне програмне забезпечення".

Прем'єр-міністр України А.КІНАХ
