ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 604 від 22.12.99 Зареєстровано в Міністерстві м.Київ юстиції України 17 січня 2000 р. за N 20/4241

( Постанова втратила чинність на підставі Постанови Нацбанку N 101 ( z0359-05 ) від 31.03.2005 )

Про внесення змін до постанови Правління Національного банку України від 04.09.98 N 349

( Додатково див. Лист Нацбанку N 13-124/570-1261 ( v1261500-00 ) від 25.02.2000 )

( Із змінами, внесеними згідно з Постановою Нацбанку N 93 ( z0172-00 ) від 09.03.2000 )

Відповідно до пункту 1 статті 6 Декрету Кабінету Міністрів України від 19 лютого 1993 року N 15-93 "Про систему валютного регулювання і валютного контролю" та на виконання Постанови Верховної Ради України від 06.07.99 N 823-XIV ( 823-14 ) "Про внесення зміни до Постанови Верховної Ради України "Про порядок введення в дію Закону України "Про режим іноземного інвестування", а також з метою вдосконалення діючого порядку здійснення обов'язкового продажу надходжень в іноземній валюті на користь резидентів - юридичних осіб Правління ПОСТАНОВЛЯЄ:

( Пункт 1 втратив чинність на підставі Постанови Нацбанку N 93 ( z0172-00 ) від 09.03.2000 ) 1. Внести до пункту 1 постанови Правління Національного банку України від 04.09.98 N 349 ( v0575500-98 ) "Про введення обов'язкового продажу надходжень в іноземній валюті на користь резидентів - юридичних осіб" (зі змінами і доповненнями) такі зміни:

1.1. Доповнити підпунктом "ї" такого змісту:

"ї) що складають суми виручки в іноземній валюті суб'єктів господарської діяльності з іноземними інвестиціями за експорт продукції (робіт, послуг) власного виробництва, на письмову вимогу іноземного інвестора протягом десяти років з дня реєстрації інвестиції за умови, що іноземні інвестиції були фактично здійснені та зареєстровані в період дії Закону України від 13 березня 1992 року N 2198-XII ( 2198-12 ) "Про іноземні інвестиції". Підставою для визначення продукції як такої, що належить до власного виробництва, є документ торгово-промислової палати".

1.2. Доповнити пункт останнім абзацом такого змісту:

"У разі об'єктивної потреби та обгрунтування економічної необхідності звільнення від обов'язкового продажу коштів в іноземній валюті, які не ввійшли до переліку, визначеного в пункті 1 цієї постанови, Національний банк України приймає окреме рішення за кожним таким випадком".

2. Департаменту валютного регулювання (С.О.Яременко) довести зміст цієї постанови до відома Кримського республіканського, Головного, обласних та по м.Києву і Київській області управлінь Національного банку України, а також комерційних банків для керівництва і використання в роботі.

3. Постанова набуває чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

Голова В.А.Ющенко
