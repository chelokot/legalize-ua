Про Комісію з питань соціального захисту населення

( Із змінами, внесеними згідно з Указами Президента N 17/95 ( 17/95 ) від 04.01.95 N 249/95 ( 249/95 ) від 21.03.95 )

1. Створити при Президентові України Комісію з питань соціального захисту населення (далі - Комісія).

2. Призначити МІТЮКОВА Ігоря Олександровича - віце-Прем'єр-міністра України, Головою Комісії.

Затвердити персональний склад Комісії (додається).

3. І.Мітюкову подати у тижневий строк проект Положення про Комісію з питань соціального захисту населення.

4. Надати Комісії право залучати для роботи фахівців центральних органів державної виконавчої влади, науково-дослідних установ, вищих навчальних закладів, а також одержувати необхідну для її діяльності інформацію.

5. Комісії подати у двотижневий строк до Адміністрації Президента України пропозиції щодо соціального захисту населення у зв'язку з лібералізацією цін.
