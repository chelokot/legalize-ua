25.07.2006 N 277

Зареєстровано в Міністерстві юстиції України 3 серпня 2006 р. за N 933/12807

Про втрату чинності наказу Міністерства праці України від 17.04.96 N 41

На виконання Указу Президента України від 1 червня 2005 року N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" та з метою приведення регуляторних актів Міністерства праці та соціальної політики України у відповідність з принципами державної регуляторної політики НАКАЗУЮ:

Визнати таким, що втратив чинність, наказ Міністерства праці України від 17.04.96 N 41 ( z0205-96 ) "Про затвердження Положення про центр організації професійного навчання незайнятого населення державної служби зайнятості", зареєстрований у Міністерстві юстиції України 29 квітня 1996 року за N 205/1230.

Міністр І.Сахань
