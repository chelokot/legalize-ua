УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про паспорт громадянина України для виїзду за кордон

( Із змінами, внесеними згідно з Указами Президента N 1058/2003 ( 1058/2003 ) від 20.09.2003 N 1465/2004 ( 1465/2004 ) від 10.12.2004 N 1513/2004 ( 1513/2004 ) від 21.12.2004 N 457/2005 ( 457/2005 ) від 10.03.2005 N 1404/2005 ( 1404/2005 ) від 01.10.2005 )

Відповідно до Положення про паспорт громадянина України, затвердженого Постановою Верховної Ради України від 26 червня 1992 року "Про затвердження положень про паспорт громадянина України та свідоцтво про народження" ( 2503-12 ) (в редакції Постанови Верховної Ради України від 2 вересня 1993 року ( 3423-12 ), постановляю:

1. Затвердити Положення про паспорт громадянина України для виїзду за кордон (додається).

2. Кабінету Міністрів України забезпечити видачу паспорта громадянина України для виїзду за кордон з 1 січня 1994 року.

Президент України Л. КРАВЧУК

м.Київ, 28 жовтня 1993 року N 491/93

ЗАТВЕРДЖЕНО Указом Президента України від 28 жовтня 1993 року N 491/93

ПОЛОЖЕННЯ про паспорт громадянина України для виїзду за кордон

1. Паспорт громадянина України для виїзду за кордон (далі - паспорт) є документом, що посвідчує особу громадянина України під час перетинання державного кордону України та перебування за кордоном.

Паспорт є власністю України.

2. Паспорт являє собою зшиту внакидку нитками обрізну книжечку розміром 88 х 125 міліметрів, що складається з обкладинки та 32 (64 або 96) сторінок.

Усі сторінки паспорта пронумеровано й на кожній з них зображено Державний герб України, зроблено напис "Україна" і перфоровано номер паспорта.

У верхній частині лицьового боку обкладинки фольгою золотого кольору видруковано слово "Паспорт", нижче - зображення Державного герба України, під ним - слово "Україна".

На внутрішньому лівому боці обкладинки впоперек угорі надруковано слово "Україна". Нижче зліва - слово "Паспорт" і під ним відведено місце для фотокартки пред'явника паспорта (розмір фотокартки - 35 х 45 міліметрів). Справа - відомості про тип, код держави, номер паспорта, а також прізвище, ім'я, по батькові, громадянство, дата народження, стать, місце народження пред'явника паспорта, дата видачі й орган, що видав паспорт, дата закінчення терміну дії паспорта. У нижній частині - смужка на всю ширину сторінки для машинозчитувальної інформації. Точне місце написів і відомостей про пред'явника паспорта визначається за рекомендаціями Міжнародної організації цивільної авіації (ІКАО. Дос. N 9303).

Після відповідного текстового заповнення та вміщення фотокартки внутрішній лівий бік обкладинки заклеюється плівкою.

На першій сторінці паспорта впоперек угорі надруковано номер паспорта, під ним - слова "Термін дії паспорта продовжено до". Посередині впоперек напис "Паспорт є власністю України", під ним у два стовпчики - українською та англійською мовами - текст "Іменем України Міністр закордонних справ України просить усіх, кого це може стосуватися, всіма можливими заходами полегшити поїздку пред'явника паспорта, подавати йому необхідну допомогу та захист". У нижній частині сторінки відведено місце для підпису пред'явника паспорта.

Друга і третя сторінки паспорта призначені для відомостей про дітей, які виїжджають за кордон разом із пред'явником паспорта без документів для виїзду за кордон. Четверта і п'ята сторінки - для особливих відміток. Сторінки з шостої по тридцять другу (шістдесят четверту або дев'яносто шосту) призначені для проставлення віз на в'їзд до іноземних держав і відміток щодо перетинання державного кордону пред'явником паспорта.

На прохання громадянина на четверту і п'яту сторінки паспорта можуть бути внесені на підставі відповідних документів дані про його місце проживання, номер телефону, групу крові та резус-фактор.

На внутрішньому правому боці обкладинки українською мовою надруковано інформацію стосовно митних, валютних, медичних і консульських вимог, текст якої визначається Кабінетом Міністрів України.

Зразок паспорта затверджується Кабінетом Міністрів України. ( Пункт 2 в редакції Указів Президента N 1465/2004 ( 1465/2004 ) від 10.12.2004, N 457/2005 ( 457/2005 ) від 10.03.2005 )

3. Усі друковані написи в паспорті, а також відомості щодо пред'явника паспорта виконуються українською і англійською мовами. ( Пункт 3 в редакції Указів Президента N 1465/2004 ( 1465/2004 ) від 10.12.2004, N 457/2005 ( 457/2005 ) від 10.03.2005 )

4. Внесення відомостей до паспорта може здійснюватися шляхом вклеювання спеціальних аркушів, форма яких визначається Міністерством внутрішніх справ України.

( Пункт 4 в редакції Указів Президента N 1465/2004 ( 1465/2004 ) від 10.12.2004, N 457/2005 ( 457/2005 ) від 10.03.2005 )

5. Забороняється вносити до паспорта записи, не передбачені цим Положенням або законодавчими актами України.

6. Термін дії паспорта - до десяти років. Цей строк може бути продовжено на десять років у порядку, передбаченому цим Положенням для оформлення паспорта.

7. Паспорт оформляється:

громадянам України, які досягли 18-річного віку і постійно проживають в Україні, за їх особистим зверненням (зверненням їхніх законних представників) про одержання паспорта до підрозділів служби громадянства, імміграції та реєстрації фізичних осіб за місцем проживання. У виняткових випадках - за наявності вимог держави, до якої здійснюється виїзд, чи вимог міжнародної організації, для участі в заходах якої здійснюється виїзд, а також у разі виїзду на постійне проживання за кордон усиновленої іноземцями дитини - громадянина України паспорт може бути оформлено до досягнення громадянином 18-річного віку; ( Абзац другий пункту 7 в редакції Указу Президента N 1058/2003 ( 1058/2003 ) від 20.09.2003 )

громадянам України, які постійно проживають, перебувають у довгостроковому відрядженні, на навчанні, стажуванні, працюють за контрактом або перебувають на лікуванні за кордоном і досягли 16-річного віку, - за їх особистим клопотанням про отримання паспорта або через їх законних представників до закордонних дипломатичних установ України. Громадяни України, які постійно проживають за кордоном, можуть звернутися з клопотанням про отримання паспорта також до Міністерства закордонних справ України. Оформлення паспорта громадянам України, які не досягли 16-річного віку, провадиться на підставі нотаріально засвідченого клопотання батьків або їх законних представників у разі потреби в самостійному виїзді таких осіб за кордон; ( Абзац третій пункту 7 в редакції Указу Президента N 1513/2004 ( 1513/2004 ) від 21.12.2004 )

особам, які проживають за кордоном і в установленому законодавством порядку набули громадянство України, - дипломатичними представництвами чи консульськими установами України за кордоном.

Паспорт оформляється протягом трьох місяців від дня звернення про одержання паспорта, а у випадках, коли поїздка пов'язана з терміновим лікуванням від'їжджаючого, від'їздом особи, яка супроводжує тяжкохворого, чи викликана смертю родича, який проживав за кордоном, - протягом трьох робочих днів. У разі виїзду на постійне проживання за кордон усиновленої іноземцями дитини - громадянина України для неї оформляється паспорт. Термін його оформлення - до десяти робочих днів. ( Абзац п'ятий пункту 7 із змінами, внесеними згідно з Указом Президента N 1058/2003 ( 1058/2003 ) від 20.09.2003 )

8. Правила та порядок оформлення і видачі паспортів визначаються Кабінетом Міністрів України.

Зразки печаток і бланків документів для оформлення паспортів затверджуються Міністерством внутрішніх справ України.

9. Бланки паспортів виготовляються на замовлення Міністерства внутрішніх справ України та Міністерства закордонних справ України з високоякісного паперу з використанням спеціального захисту і є документами суворої звітності. ( Абзац перший пункту 9 із змінами, внесеними згідно з Указом Президента N 1465/2004 ( 1465/2004 ) від 10.12.2004; в редакції Указу Президента N 457/2005 ( 457/2005 ) від 10.03.2005; із змінами, внесеними згідно з N 1404/2005 ( 1404/2005 ) від 01.10.2005 )

Порядок зберігання бланків паспортів і знищення паспортів, термін дії яких закінчився, визначається Міністерством внутрішніх справ України.

10. За видачу і продовження терміну дії паспорта на території України справляється державне мито, а за кордоном - консульський збір.

11. Громадянин повинен надійно зберігати паспорт.

Про втрату паспорта громадянин зобов'язаний невідкладно повідомити орган, який видав паспорт чи найближчу закордонну дипломатичну установу України. ( Абзац другий пункту 11 із змінами, внесеними згідно з Указом Президента N 1465/2004 ( 1465/2004 ) від 10.12.2004 )
