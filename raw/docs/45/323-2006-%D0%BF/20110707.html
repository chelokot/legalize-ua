КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 березня 2006 р. N 323 Київ

Про внесення змін до деяких постанов Кабінету Міністрів України з питань забезпечення житлом військовослужбовців, звільнених у запас або відставку

{ Із змінами, внесеними згідно з Постановами КМ N 706 ( 706-2006-п ) від 22.05.2006 N 704 ( 704-2011-п ) від 22.06.2011 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України з питань забезпечення житлом військовослужбовців, звільнених у запас або відставку, зміни, що додаються.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 29

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 15 березня 2006 р. N 323

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України з питань забезпечення житлом військовослужбовців, звільнених у запас або відставку

1. У першому реченні підпункту 3 пункту 9 Порядку обліку, зберігання, оцінки конфіскованого та іншого майна, що переходить у власність держави, і розпорядження ним, затвердженого постановою Кабінету Міністрів України від 25 серпня 1998 р. N 1340 ( 1340-98-п ) (Офіційний вісник України, 1998 р., N 34, ст. 1280; 1999 р., N 21, ст. 951; 2000 р., N 4, ст. 117; 2001 р., N 52, ст. 2345; 2002 р., N 18, ст. 941; 2003 р., N 29, ст. 1476), слова "Національному координаційному центру адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів" замінити словами "Державному департаменту адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 704 ( 704-2011-п ) від 22.06.2011 }

3. У тексті Порядку розпорядження майном, конфіскованим за рішенням суду і переданим органам державної виконавчої служби, затвердженого постановою Кабінету Міністрів України від 11 липня 2002 р. N 985 ( 985-2002-п ) (Офіційний вісник України, 2002 р., N 29, ст. 1371; 2003 р., N 29, 1476), слова "Національному координаційному центру адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів" та "Центру" замінити відповідно словами "Державному департаменту адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів" та "Державному департаменту".

{ Пункт 4 втратив чинність на підставі Постанови КМ N 704 ( 704-2011-п ) від 22.06.2011 }

{ Пункт 5 втратив чинність на підставі Постанови КМ N 706 ( 706-2006-п ) від 22.05.2006 }

6. У тексті постанови Кабінету Міністрів України від 24 березня 2004 р. N 361 ( 361-2004-п ) "Деякі питання фінансування Програми забезпечення житлом військовослужбовців, звільнених у запас або відставку" (Офіційний вісник України, 2004 р., N 12, ст. 734) слова "Національний координаційний центр адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів" та "Національний координаційний центр" в усіх відмінках замінити відповідно словами "Державний департамент адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів" та "Державний департамент" у відповідному відмінку.
