КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 травня 2010 р. N 401 Київ

Про затвердження Порядку використання у 2010 році коштів Стабілізаційного фонду, передбачених у державному бюджеті для виконання функцій столиці відповідно до Закону України "Про столицю України - місто-герой Київ"

{ Із змінами, внесеними згідно з Постановою КМ N 756 ( 756-2010-п ) від 18.08.2010 }

Відповідно до пункту 9 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) Кабінет Міністрів України постановляє:

1. Затвердити Порядок використання у 2010 році коштів Стабілізаційного фонду ( 2154-17 ), передбачених у державному бюджеті для виконання функцій столиці відповідно до Закону України "Про столицю України - місто-герой Київ" ( 401-14 ), що додається.

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України від 17 лютого 2010 р. N 225 ( 225-2010-п ) "Про фінансування видатків для виконання функцій столиці відповідно до Закону України "Про столицю України - місто-герой Київ" (Офіційний вісник України, 2010 р., N 16, ст. 746) та від 24 лютого 2010 р. N 185 ( 185-2010-п ) "Питання використання у 2010 році коштів Стабілізаційного фонду для виконання функцій столиці відповідно до Закону України "Про столицю України - місто-герой Київ" (Офіційний вісник України, 2010 р., N 13, ст. 634).

Прем'єр-міністр України М.АЗАРОВ

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 травня 2010 р. N 401

ПОРЯДОК використання у 2010 році коштів Стабілізаційного фонду ( 2154-17 ), передбачених у державному бюджеті для виконання функцій столиці відповідно до Закону України "Про столицю України - місто-герой Київ" ( 401-14 )

1. Цей Порядок визначає механізм використання у 2010 році коштів Стабілізаційного фонду ( 2154-17 ), передбачених пунктом 9 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) для виконання функцій столиці відповідно до Закону України "Про столицю України - місто-герой Київ" ( 401-14 ), які надаються на безповоротній основі з урахуванням вимог Порядку використання коштів Стабілізаційного фонду, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) (Офіційний вісник України, 2009 р., N 24, ст. 793; 2010 р., N 2, ст. 69) (далі - бюджетні кошти), та спрямовуються на фінансування проектів будівництва та реконструкції згідно з додатком.

2. Джерелами покриття бюджетних коштів для виконання функцій столиці відповідно до Закону України "Про столицю України - місто-герой Київ" ( 401-14 ) є надходження від цільового розміщення державних цінних паперів, кошти, одержані від приватизації державного майна та інших надходжень, безпосередньо пов'язаних з процесом приватизації та кредитуванням підприємств, а також кошти, які надійдуть від сплати штрафів, пені та неустойки за невиконання власниками приватизованих об'єктів, умов договорів, їх купівлі-продажу, а у разі їх недостатності - кошти, отримані від продажу земельних ділянок несільськогосподарського призначення, що перебувають у державній власності, на яких розташовані об'єкти, що підлягають приватизації, або надходження коштів Стабілізаційного фонду ( 2154-17 ), що були надані на поворотній основі.

3. Головним розпорядником бюджетних коштів (крім коштів, спрямованих на реалізацію напряму "Нове будівництво адміністративних споруд з підземним паркінгом, їдальнею та трансформаторною підстанцією другої черги об'єкта "Комплекс споруд Верховного Суду України по вул. П. Орлика, 8, в м. Києві") є Мінфін.

Розпорядником бюджетних коштів нижчого рівня в сумі 425,6 млн. гривень є Головне фінансове управління виконавчого органу Київської міської ради (Київської міськдержадміністрації), структурні підрозділи Київської міськдержадміністрації відповідно до компетенції, зокрема Головне управління капітального будівництва м. Києва. Одержувачами бюджетних коштів є комунальні підприємства виконавчого органу Київської міської ради (Київської міськдержадміністрації) - "Інженерний центр", "Київський метрополітен", "Дирекція будівництва шляхово-транспортних споруд м. Києва".

будівництво дільниці Куренівсько-Червоноармійської лінії метрополітену в м. Києві від станції "Либідська" до станції "Виставковий центр" - 50 млн. гривень;

реконструкція транспортної розв'язки на Московській площі - 50 млн. гривень;

будівництво південно-західного каналізаційного колектора (I-IV пускові комплекси) у м. Києві - 85 млн. гривень;

будівництво водопровідної мережі діаметром 1400 міліметрів від вул. Гречка до Великої кільцевої дороги у Подільському, Шевченківському та Святошинському районах м. Києва - 40 млн. гривень;

каналізаційний колектор від Мостицького до Головного міського колектора, перша черга, будівництво - 30 млн. гривень;

реконструкція прохідного колектора водопроводу діаметром 1400 міліметрів від станції метро "Дніпро" до вул. Кіровоградської у м. Києві - 13,5 млн. гривень;

каналізаційний колектор по вул. Стеценка з метою ліквідації каналізаційної напірної станції "Нивки" в м. Києві, будівництво - 24,2 млн. гривень;

центр із застосування ПЕТ-технології для раннього виявлення онкологічних захворювань на території Київської міської онкологічної лікарні по вул. Верховинній, 69, будівництво - 42,5 млн. гривень.

Розпорядником бюджетних коштів нижчого рівня в сумі 86,2 млн. гривень є Головне управління капітального будівництва м. Києва виконавчого органу Київської міської ради (Київської міськдержадміністрації), бюджетні кошти якому спрямовуються для фінансування таких проектів: { Пункт 3 доповнено абзацом згідно з Постановою КМ N 756 ( 756-2010-п ) від 18.08.2010 }

будівництво другої нитки Головного міського каналізаційного колектора в сумі 57,2 млн. гривень. { Пункт 3 доповнено абзацом згідно з Постановою КМ N 756 ( 756-2010-п ) від 18.08.2010 }

Одержувачами бюджетних коштів у сумі 436,7 млн. гривень, отриманих від головного розпорядника бюджетних коштів, є: { Абзац сімнадцятий пункту 3 із змінами, внесеними згідно з Постановою КМ N 756 ( 756-2010-п ) від 18.08.2010 }

4. Головним розпорядником бюджетних коштів за напрямом "Нове будівництво адміністративних споруд з підземним паркінгом, їдальнею та трансформаторною підстанцією другої черги об'єкта "Комплекс споруд Верховного Суду України по вул. П. Орлика, 8, в м. Києві" є Верховний Суд України.

5. Видатки, пов'язані з фінансуванням об'єктів капітального будівництва за рахунок бюджетних коштів, здійснюються відповідно до постанови Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) "Про затвердження Порядку державного фінансування капітального будівництва" (Офіційний вісник України, 2001 р., N 52, ст. 2374).

6. Перерахування бюджетних коштів здійснюється в межах установлених обсягів видатків відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

7. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

8. Головне фінансове управління виконавчого органу Київської міської ради (Київської міськдержадміністрації) подає Мінфіну щомісяця до 5 числа наступного періоду інформацію про використання бюджетних коштів, за якими Головне фінансове управління виконавчого органу Київської міської ради (Київської міськдержадміністрації) є розпорядником нижчого рівня, в розрізі об'єктів.

Головний розпорядник бюджетних коштів подає щокварталу до 20 числа наступного місяця Кабінетові Міністрів України інформацію про використання бюджетних коштів у розрізі об'єктів.

Державне казначейство подає щомісяця до 16 числа Мінфіну інформацію про обсяги перерахування бюджетних коштів в розрізі об'єктів.

9. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
