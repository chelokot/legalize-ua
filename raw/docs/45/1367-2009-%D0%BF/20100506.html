Текст документа від 06.05.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 грудня 2009 р. N 1367 Київ

Про внесення змін до постанов Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 та від 26 листопада 2008 р. N 1036

{ Із змінами, внесеними згідно з Постановою КМ N 324 ( 324-2010-п ) від 28.04.2010 }

Кабінет Міністрів України постановляє:

1. Останній абзац пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752, N 44, ст. 2946, N 51, ст. 3406; 2007 р., N 43, ст. 1715, N 53, ст. 2157, N 56, ст. 2252, N 59, ст. 2344, N 91, ст. 3336; 2008 р., N 9, ст. 220, N 63, ст. 2146, N 69, ст. 2322, N 70, ст. 2355, N 81, ст. 2737, N 90, ст. 3004, N 95, ст. 3142; 2009 р., N 5, ст. 128, N 43, ст. 1442, N 46, ст. 1550, N 52, ст. 1794, N 77, ст. 2613, N 79 ст. 2679) після слова "крім" доповнити словами "товарів, робіт і послуг, передбачених абзацом другим підпункту 5 цього пункту, а також".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 324 ( 324-2010-п ) від 28.04.2010 }
