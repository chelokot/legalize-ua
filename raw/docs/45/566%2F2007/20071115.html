Про заміщення посади помічника заступника Глави Секретаріату Президента України військовослужбовцем

Стан: Втратив чинність

Ідентифікатор: 566/2007

Текст документа від 15.11.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1020/2007 ( 1020/2007 ) від 25.10.2007 }

Про заміщення посади помічника заступника Глави Секретаріату Президента України військовослужбовцем

Установити, що одна посада помічника заступника Глави Секретаріату Президента України може бути заміщена військовослужбовцем Служби безпеки України з граничним військовим званням полковника.

Президент України В.ЮЩЕНКО
