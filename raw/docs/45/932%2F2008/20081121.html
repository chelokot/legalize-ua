Про відновлення дії деяких Указів Президента України

{ Додатково див. Постанову Окружного адміністративного суду N 1/1130 ( v1130805-08 ) від 21.11.2008 }

У зв'язку із завершенням перевірок обставин переведення В. Колесниченка на роботу на посаді судді Печерського районного суду міста Києва та призначення його головою цього суду постановляю:

1. Відновити дію:

Указу Президента України від 15 червня 2005 року N 950 ( 950/2005 ) "Про переведення судді Колесниченка В.М.";

Указу Президента України від 21 червня 2005 року N 977 ( 977/2005 ) "Про призначення голови місцевого загального суду".

У зв'язку з цим скасувати:

Указ Президента України від 30 березня 2007 року N 253 ( 253/2007 ) "Про скасування Указу Президента України від 21 червня 2005 року N 977";

Указ Президента України від 5 квітня 2007 року N 278 ( 278/2007 ) "Про скасування Указу Президента України від 15 червня 2005 року N 950".

2. Цей Указ набирає чинності з дня його опублікування.
