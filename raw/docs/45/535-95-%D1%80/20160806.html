Кабінет Міністрів України; Розпорядження від 22.08.1995 № 535-р

Про віднесення деяких посад до другої категорії посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 535-95-р

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 серпня 1995 р. N 535-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

{ Розпорядження втратило чинність в частині віднесення посад державних службовців Секретаріату Верховної Ради України на підставі Розпорядження КМ N 663-р ( 663-2013-р ) від 28.08.2013 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади перших заступників керівника Юридичного управління Адміністрації Президента України, завідуючого Юридичним відділом Секретаріату Верховної Ради України та завідуючого Юридичним відділом Кабінету Міністрів України до другої категорії посад державних службовців.

Прем'єр-міністр України Є.МАРЧУК
