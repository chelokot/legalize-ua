УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 141/94 від 07.04.94 )

Про випуск Державних товарних облігацій національних ресурсів України

( Про накладення вето на Указ див. Постанову ВР N 3585-XII ( 3585-12 ) від 12.11.93, ВВР, 1993, N 50, ст.476 )

З метою залучення коштів іноземних інвесторів для модернізації промисловості, впровадження передових технологій, стабілізації економіки, збільшення експортного потенціалу України та забезпечення державних гарантій використання залучених іноземних капіталів постановляю:

1. Випустити в обіг Державні товарні облігації національних ресурсів України.

2. Міністерству фінансів України здійснити у місячний строк організаційні заходи щодо забезпечення випуску та обігу Державних товарних облігацій національних ресурсів України.

3. Затвердити Положення про Державні товарні облігації національних ресурсів України (Положення додається до оригіналу, опублікуванню не підлягає).

Президент України Л.КРАВЧУК
