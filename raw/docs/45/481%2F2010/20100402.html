Президент України; Указ від 02.04.2010 № 481/2010

Про ліквідацію Координаційної ради з проблем ВІЛ-інфекції/СНІДу, туберкульозу та наркоманії

Стан: Чинний

Ідентифікатор: 481/2010

Текст документа від 02.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про ліквідацію Координаційної ради з проблем ВІЛ-інфекції/СНІДу, туберкульозу та наркоманії

Відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Ліквідувати Координаційну раду з проблем ВІЛ-інфекції/СНІДу, туберкульозу та наркоманії.

У зв'язку з цим визнати такими, що втратили чинність:

статтю 2 Указу Президента України від 12 грудня 2007 року N 1208 ( 1208/2007 ) "Про додаткові невідкладні заходи щодо протидії ВІЛ-інфекції/СНІДу в Україні";

Указ Президента України від 17 березня 2008 року N 220 ( 220/2008 ) "Про Координаційну раду з проблем ВІЛ-інфекції/СНІДу, туберкульозу та наркоманії";

Указ Президента України від 28 серпня 2009 року N 692 ( 692/2009 ) "Про внесення змін до Указу Президента України від 17 березня 2008 року N 220".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 2 квітня 2010 року N 481/2010
