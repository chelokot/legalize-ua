ПОСТАНОВА від 3 грудня 2008 р. N 1038 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 850 ( 850-2009-п ) від 12.08.2009 }

Питання Секретаріату Кабінету Міністрів України

Відповідно до частини п'ятої статті 50 Закону України "Про Кабінет Міністрів України" ( 279-17 ) Кабінет Міністрів України постановляє:

1. Установити, що директори департаментів та бюро, начальники управлінь Секретаріату Кабінету Міністрів України призначаються на посаду та звільняються з посади Кабінетом Міністрів України за поданням Міністра Кабінету Міністрів України.

Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 23 травня 2007 р. N 758 ( 758-2007-п ) "Деякі питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2007 р., N 38, ст. 1522);

постанову Кабінету Міністрів України від 16 липня 2008 р. N 635 ( 635-2008-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 23 травня 2007 р. N 758" (Офіційний вісник України, 2008 р., N 53, ст. 1767);

пункт 2 змін, що вносяться до постанов Кабінету Міністрів України від 9 березня 2006 р. N 268 ( 268-2006-п ) і від 23 травня 2007 р. N 758 ( 758-2007-п ), затверджених постановою Кабінету Міністрів України від 17 вересня 2008 р. N 829 ( 829-2008-п ) "Деякі питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2008 р., N 71, ст. 2382).
