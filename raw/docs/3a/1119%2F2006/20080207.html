Президент України; Указ від 23.12.2006 № 1119/2006

Про делегацію України для участі у траурних заходах у зв'язку зі смертю Президента Туркменистану С.А. Ніязова

Стан: Втратив чинність

Ідентифікатор: 1119/2006

Текст документа від 07.02.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у траурних заходах у зв'язку зі смертю Президента Туркменистану С.А. Ніязова

1. Утворити делегацію України для участі у траурних заходах у зв'язку зі смертю Президента Туркменистану С.А. Ніязова (Туркменистан) на чолі з Прем'єр-міністром України В. Януковичем.

Главі делегації України сформувати її персональний склад.

2. Кабінету Міністрів України забезпечити фінансування витрат, пов'язаних з участю делегації України у траурних заходах у зв'язку зі смертю Президента Туркменистану С.А. Ніязова.

Президент України В.ЮЩЕНКО
