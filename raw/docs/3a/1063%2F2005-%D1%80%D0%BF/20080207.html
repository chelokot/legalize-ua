РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у переговорах з Міжнародним банком реконструкції та розвитку щодо підготовки проекту Угоди про позику (Проект реабілітації гідроелектростанцій) між Україною та Міжнародним банком реконструкції та розвитку

1. Утворити делегацію України для участі у переговорах з Міжнародним банком реконструкції та розвитку щодо підготовки проекту Угоди про позику (Проект реабілітації гідроелектростанцій) між Україною та Міжнародним банком реконструкції та розвитку в такому складі:

ТІТЕНКО - заступник Міністра палива та

Сергій Михайлович енергетики України, глава делегації

АНДРІЄВА - директор департаменту міжнародного

Тамара Володимирівна співробітництва Міністерства юстиції України

ЖОВАНИК - головний спеціаліст управління

Наталія Олегівна міжнародного співробітництва, міждержавних відносин та зовнішньоекономічної політики департаменту економічної політики Секретаріату Кабінету Міністрів України

КОЛОСОВА - начальник управління співробітництва Вікторія Павлівна з міжнародними фінансовими організаціями департаменту фінансової політики та управління державним боргом Міністерства фінансів України

КОТКО - член Національної комісії регулювання Василь Григорович електроенергетики України

ПЕРЕБИЙНІС - третій секретар управління

Вадим Миколайович економічного співробітництва Міністерства закордонних справ України

ПОТАШНИК - голова правління відкритого

Семен Ізраїльович акціонерного товариства "Укргідроенерго"

СИДОРЕНКО - начальник відділу управління

Лариса Василівна взаємодії з міжнародними фінансовими організаціями департаменту економічної стратегії Міністерства економіки України

ШАПОВАЛОВ - директор департаменту інвестиційної Олександр Едуардович політики та перспективного розвитку паливно-енергетичного комплексу Міністерства палива та енергетики України.

Дозволити главі делегації С. Тітенку за погодженням із Міністерством закордонних справ України вносити в разі потреби зміни до персонального складу делегації.

2. Затвердити Директиви делегації України на переговори з Міжнародним банком реконструкції та розвитку щодо підготовки проекту Угоди про позику (Проект реабілітації гідроелектростанцій) між Україною та Міжнародним банком реконструкції та розвитку.
