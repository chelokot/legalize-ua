Президент України; Указ від 11.06.2007 № 515/2007

Про зупинення дії постанови Кабінету Міністрів України від 25 травня 2007 року N 774

Стан: Втратив чинність

Ідентифікатор: 515/2007

Текст документа від 11.06.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанови Кабінету Міністрів України від 25 травня 2007 року N 774

{ Додатково див. Конституційне подання Президента ( n0010100-07 ) від 11.06.2007 }

Кабінетом Міністрів України 25 травня 2007 року видано постанову N 774 ( 774-2007-п ) "Питання контролю та забезпечення діяльності органів та підрозділів Міністерства внутрішніх справ".

Названою постановою ( 774-2007-п ) Міністрові внутрішніх справ України доручено, зокрема, забезпечити дотримання посадовими і службовими особами Міністерства внутрішніх справ України вимог Конституції ( 254к/96-ВР ) та законів України, актів Кабінету Міністрів України, наказів Міністра внутрішніх справ України, заборонити передислокацію органів та підрозділів внутрішніх військ без дозволу Міністра внутрішніх справ України (підпункт 2 пункту 1) ( 774-2007-п ).

Крім того, взято до відома, що органи та підрозділи внутрішніх військ для виконання будь-яких завдань застосовуються лише за наказом чи за погодженням з Міністром внутрішніх справ України, а також попереджено командувача внутрішніх військ про персональну відповідальність за недотримання внутрішніми військами вимог Конституції ( 254к/96-ВР ) та законів України, наказів Міністра внутрішніх справ України та названої постанови (пункт 2) ( 774-2007-п ).

Зазначеною постановою ( 774-2007-п ) Кабінету Міністрів України обмежено конституційні повноваження Президента України щодо забезпечення національної безпеки, керівництва у сферах національної безпеки, передбачені пунктами 1 та 17 частини першої статті 106 Конституції України ( 254к/96-ВР ).

Саме на виконання зазначених конституційних повноважень глави держави, а також виходячи з положень частини другої статті 102 Основного Закону України ( 254к/96-ВР ), було видано Указ Президента України від 25 травня 2007 року N 474 ( 474/2007 ) "Про приведення системи управління внутрішніми військами у відповідність із Конституцією України". Цим Указом ( 474/2007 ) з метою забезпечення запобігання і нейтралізації реальних та потенційних загроз національним інтересам, недопущення використання внутрішніх військ Міністерства внутрішніх справ України в інтересах певних політичних сил, що створює загрозу національній безпеці України, приведення системи керівництва внутрішніми військами як військовим формуванням у відповідність із Конституцією України ( 254к/96-ВР ) внутрішні війська виведено з підпорядкування Міністра внутрішніх справ України і підпорядковано Президентові України.

Однак, видаючи постанову N 774 ( 774-2007-п ), Кабінет Міністрів України проігнорував зазначений Указ ( 474/2007 ) Президента України, чим порушив наведені норми Конституції України ( 254к/96-ВР ), а також положення статті 4 Закону України "Про внутрішні війська Міністерства внутрішніх справ України" ( 2235-12 ), за якими правовою основою діяльності внутрішніх військ є, в тому числі, укази Президента України.

Відтак, постанова Кабінету Міністрів України від 25 травня 2007 року N 774 ( 774-2007-п ) суперечить також частині третій статті 106 Конституції України ( 254к/96-ВР ), якою встановлено, що укази Президента України, видані на основі та на виконання Конституції ( 254к/96-ВР ) і законів України, є обов'язковими до виконання на території України, частині третій статті 113 та пункту 1 статті 116 Основного Закону України ( 254к/96-ВР ), що зобов'язують Кабінет Міністрів України керуватися у своїй діяльності, зокрема, прийнятими відповідно до Конституції ( 254к/96-ВР ) та законів України указами Президента України, забезпечувати виконання актів глави держави.

Постановою Кабінету Міністрів України N 774 ( 774-2007-п ) також доручено Міністрові внутрішніх справ України запровадити посилений режим охорони адміністративних будинків Верховної Ради України, Генеральної прокуратури України, Національного банку України, центральних органів виконавчої влади, інших державних органів у місті Києві та Київської міської державної адміністрації, погодивши у разі потреби здійснення заходів охорони з відповідними органами та посадовими особами (підпункт 4 пункту 1) ( 774-2007-п ).

Таке доручення Міністрові внутрішніх справ України надано Кабінетом Міністрів України з перевищенням повноважень, оскільки питання щодо охорони Верховної Ради України, інших визначених Президентом України важливих державних об'єктів та прилеглих до них територій і акваторій Управлінням державної охорони України врегульовано Законом України "Про державну охорону органів державної влади України та посадових осіб" ( 160/98-ВР ). Цим дорученням порушено також норму частини першої статті 117 Конституції України ( 254к/96-ВР ), яка зобов'язує Кабінет Міністрів України видавати постанови і розпорядження в межах своєї компетенції.

Пунктом 3 постанови N 774 ( 774-2007-п ) Кабінет Міністрів України доручив Міністерству фінансів України забезпечити фінансування Міністерства внутрішніх справ України шляхом спрямування коштів для розв'язання пріоритетних завдань його діяльності. Оскільки при цьому не визначено, що йдеться про видатки в межах асигнувань, передбачених у Державному бюджеті України на 2007 рік ( 489-16 ), постанова ( 774-2007-п ) Кабінету Міністрів України в цій частині суперечить статті 95 Конституції України ( 254к/96-ВР ), статтям 30 та 31 Бюджетного кодексу України ( 2542-14 ), якими встановлено, що будь-які видатки держави на загальносуспільні потреби (в тому числі видатки, передбачені на діяльність органів державної влади, в інтересах національної безпеки), розмір і цільове спрямування цих видатків визначаються виключно законом про Державний бюджет України.

Видаючи постанову ( 774-2007-п ) всупереч Конституції України ( 254к/96-ВР ), Закону України "Про внутрішні війська Міністерства внутрішніх справ України" ( 2235-12 ), Закону України "Про державну охорону органів державної влади України та посадових осіб" ( 160/98-ВР ), Бюджетному кодексу України ( 2542-14 ), Кабінет Міністрів України порушив, крім наведених, також норми частини другої статті 6 та частини другої статті 19 Конституції України ( 254к/96-ВР ), за якими органи виконавчої влади зобов'язані здійснювати свої повноваження у встановлених Конституцією України ( 254к/96-ВР ) межах, зобов'язані діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) і законами України.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 25 травня 2007 року N 774 ( 774-2007-п ) "Питання контролю та забезпечення діяльності органів та підрозділів Міністерства внутрішніх справ".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
