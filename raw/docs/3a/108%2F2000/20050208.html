Президент України; Указ від 28.01.2000 № 108/2000

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

Стан: Втратив чинність

Ідентифікатор: 108/2000

Текст документа від 08.02.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 208/2005 ( 208/2005 ) від 08.02.2005 )

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

Увести до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України, затвердженого Указом Президента України від 31 грудня 1999 року N 1659 ( 1659/99 ), СТАНІК Сюзанну Романівну - Міністра юстиції України.

Президент України Л.КУЧМА
