Про внесення доповнення до складу Комісії з питань реформування правоохоронних органів в Україні

Стан: Втратив чинність

Текст документа від 11.06.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президент N 834/2005 ( 834/2005 ) від 23.05.2005 )

Про внесення доповнення до складу Комісії з питань реформування правоохоронних органів в Україні

Увести до складу Комісії з питань реформування правоохоронних органів в Україні, затвердженого Указом Президента України від 17 січня 2001 року N 17 ( 17/2001 ) (із змінами, внесеними Указами від 22 березня 2001 року N 194 ( 194/2001 ) та від 18 квітня 2001 року N 263 ( 263/2001 ), БІЛОКОНЯ Миколу Васильовича - Керівника Управління по роботі правоохоронних органів Адміністрації Президента України.

Президент України Л.КУЧМА

м. Київ, 7 вересня 2001 року N 811/2001
