КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 жовтня 2006 р. N 521-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про затвердження керівника робочої групи з питань сприяння органам місцевого самоврядування у встановленні меж м. Києва

Затвердити Віце-прем'єр-міністра України, Міністра будівництва, архітектури та житлово-комунального господарства Рибака Володимира Васильовича керівником робочої групи з питань сприяння органам місцевого самоврядування у встановленні меж м. Києва, утвореної розпорядженням Кабінету Міністрів України від 15 грудня 2005 р. N 522-р ( 522-2005-р ), увільнивши від цих обов'язків Сташевського Станіслава Телісфоровича.

Надати керівникові зазначеної робочої групи право вносити у разі потреби зміни до її складу.

Прем'єр-міністр України В.ЯНУКОВИЧ
