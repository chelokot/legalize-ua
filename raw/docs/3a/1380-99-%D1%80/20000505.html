Кабінет Міністрів України; Розпорядження від 11.12.1999 № 1380-р

Про дозвіл Держмитслужбі на здійснення митного оформлення обладнання для годівлі, забою, переробки птиці, виробництва комбікормів та сільськогосподарської техніки, що надходять для власних виробничих потреб відповідно до контрактів, укладених концерном "Комплекс"

Стан: Втратив чинність

Ідентифікатор: 1380-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 грудня 1999 р. N 1380-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

З метою підтримки виробників сільськогосподарської продукції дозволити Держмитслужбі здійснити митне оформлення обладнання для годівлі, забою, переробки птиці, виробництва комбікормів та сільськогосподарської техніки, що надходять для власних виробничих потреб відповідно до контрактів, укладених концерном "Комплекс" (м. Київ) з фірмами "Peja export B.V." (Нідерланди) - від 24 червня 1998 р. N 2-UK-101 і N 2-UK-102, "Stork PMT B.V." (Нідерланди) - від 20 травня 1999 р. N 2-UK-105 та "Ottevanger Maschinenfabrieken B.V." (Нідерланди) - від 25 травня 1999 р. N YM/HVP/0519/1; контракту, укладеного ЗАТ "Гаврилівський птахівничий комплекс" (Київська область) з компанією "Big Dutchman International GmbH" (Німеччина) - від 20 жовтня 1999 р. N 081099; договору між дочірнім підприємством "Тернопільський газопромисловий комплекс" та підприємством "Holmer maschinenbau GmbH" (Німеччина) від 1 вересня 1998 р. N 1/9; договору між ЗАТ "Тернопільський агропромисловий комплекс" та підприємством "Holmer maschinenbau GmbH" (Німеччина) від 15 липня 1999 р. N 15/07 і контракту, укладеного цим товариством з корпорацією "Wholetrade inc." (Англія) - від 23 червня 1999 р. N UKR 3/35-99, як товарів критичного імпорту, встановивши ставку ввізного мита в розмірі 0,1 відсотка митної вартості товару.
