Стан: Чинний

Ідентифікатор: 1284-2009-п

Текст документа від 01.08.2021:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 грудня 2009 р. N 1284 Київ

{ Постанова втратила чинність в частині визначення ліміту автомобілів для центральних органів виконавчої влади, ліміт автомобілів для яких встановлено Постановою КМ N 1399 ( 1399-2011-п ) від 26.12.2011, на підставі Постанови КМ N 1399 ( 1399-2011-п ) від 26.12.2011 }

Про встановлення ліміту легкових автомобілів, що обслуговують державні органи, які здійснюють керівництво військовими формуваннями та правоохоронними органами, органи і підрозділи цивільного захисту, Державної спеціальної служби транспорту, Державної служби спеціального зв'язку та захисту інформації

{ Із змінами, внесеними згідно з Постановою КМ N 1109 ( 1109-2011-п ) від 20.10.2011 }

{ Установити, що у зв’язку з проведенням урочистих заходів, присвячених 30-й річниці незалежності України, Управлінням державної охорони під час укладання договорів оренди легкових автомобілів не застосовується ліміт легкових автомобілів, що обслуговують державні органи, які здійснюють керівництво військовими формуваннями та правоохоронними органами, органи і підрозділи цивільного захисту, Державної спеціальної служби транспорту, Державної служби спеціального зв’язку та захисту інформації, встановлений згідно з додатком до цієї Постанови, згідно з Постановою КМ N 744 ( 744-2021-п ) від 21.07.2021 - діє по 31 серпня 2021 року}

Кабінет Міністрів України постановляє:

1. Установити ліміт легкових автомобілів, що обслуговують державні органи, які здійснюють керівництво військовими формуваннями та правоохоронними органами, органи і підрозділи цивільного захисту, Державної спеціальної служби транспорту, Державної служби спеціального зв'язку та захисту інформації, згідно з додатком.

2. Легкові автомобілі, що перебувають на балансі державних органів, які здійснюють керівництво військовими формуваннями та правоохоронними органами, органів і підрозділів цивільного захисту, Державної спеціальної служби транспорту, Державної служби спеціального зв'язку та захисту інформації та вивільняються у зв'язку з установленням ліміту згідно з цією постановою, підлягають реалізації у визначеному законодавством порядку або передачі підпорядкованим органам та підрозділам.

3. Державним органам, які здійснюють керівництво військовими формуваннями та правоохоронними органами, органам і підрозділам цивільного захисту, Державної спеціальної служби транспорту, Державної служби спеціального зв'язку та захисту інформації, зазначеним у додатку, привести протягом двох місяців загальну кількість легкових автомобілів, що перебувають на їх балансі або орендуються ними в установленому порядку, у відповідність з установленим лімітом та про результати поінформувати Міністерство фінансів.

4. Визнати таким, що втратив чинність, пункт 5 постанови Кабінету Міністрів України від 22 квітня 1999 р. N 653 ( 653-99-п ) "Про заходи щодо забезпечення діяльності Державного департаменту з питань виконання покарань" (Офіційний вісник України, 1999 р., N 16, ст. 661).
