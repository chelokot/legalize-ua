Кабінет Міністрів України; Постанова, Перелік від 19.12.2006 № 1758

Про визнання такими, що втратили чинність, постанов Кабінету Міністрів України з питань діяльності Державної воєнізованої гірничорятувальної служби

Стан: Чинний

Ідентифікатор: 1758-2006-п

Текст документа від 19.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 грудня 2006 р. N 1758 Київ

Про визнання такими, що втратили чинність, постанов Кабінету Міністрів України з питань діяльності Державної воєнізованої гірничорятувальної служби

Кабінет Міністрів України постановляє:

1. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України з питань діяльності Державної воєнізованої гірничорятувальної служби згідно з переліком, що додається.

2. Міністерству вугільної промисловості у зв'язку з прийняттям цієї постанови розробити та затвердити у двомісячний строк правові акти, що регламентують діяльність Державної воєнізованої гірничорятувальної служби у вугільній промисловості.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 37

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 19 грудня 2006 р. N 1758

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність, з питань діяльності Державної воєнізованої гірничорятувальної служби

1. Постанова Кабінету Міністрів України від 5 листопада 1992 р. N 608 ( 608-92-п ) "Про Державну воєнізовану гірничорятувальну службу у вугільній промисловості" (ЗП України, 1992 р., N 11, ст. 277).

2. Постанова Кабінету Міністрів України від 29 квітня 1993 р. N 312 ( 312-93-п ) "Про внесення змін до Положення про Державну воєнізовану гірничорятувальну службу у вугільній промисловості" (ЗП України, 1993 р., N 10, ст. 199).

3. Постанова Кабінету Міністрів України від 27 вересня 1995 р. N 765 ( 765-95-п ) "Про внесення змін до Положення про Державну воєнізовану гірничорятувальну службу у вугільній промисловості" (ЗП України, 1996 р., N 2, ст. 43).

4. Постанова Кабінету Міністрів України від 22 березня 1999 р. N 428 ( 428-99-п ) "Про доповнення Положення про Державну воєнізовану гірничорятувальну службу у вугільній промисловості" (Офіційний вісник України, 1999 р., N 12, ст. 472).

5. Постанова Кабінету Міністрів України від 4 жовтня 2000 р. N 1508 ( 1508-2000-п ) "Про внесення змін і доповнень до Положення про Державну воєнізовану гірничорятувальну службу у вугільній промисловості" (Офіційний вісник України, 2000 р., N 40, ст. 1703).

6. Пункт 1 змін, що вносяться до постанов Кабінету Міністрів України з питань вугільної промисловості, затверджених постановою Кабінету Міністрів України від 25 травня 2006 р. N 720 ( 720-2006-п ) (Офіційний вісник України, 2006 р., N 21, ст. 1564).
