КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 жовтня 2006 р. N 1377 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 644 ( 644-2013-п ) від 01.08.2013 }

Про внесення змін до постанов Кабінету Міністрів України від 16 березня 2000 р. N 509 і від 12 липня 2000 р. N 1119

{ Із змінами, внесеними згідно з Постановою КМ N 314 ( 314-2010-п ) від 14.04.2010 }

Відповідно до статті 5 Закону України "Про угоди про розподіл продукції" ( 1039-14 ) Кабінет Міністрів України постановляє:

1. У тексті Положення про Міжвідомчу комісію з організації укладення та виконання угод про розподіл продукції, затвердженого постановою Кабінету Міністрів України від 16 березня 2000 р. N 509 ( 509-2000-п ) (Офіційний вісник України, 2000 р., N 12, ст. 463, N 48, ст. 2095; 2004 р., N 25, ст. 1650; 2006 р., N 22, ст. 1635), слово "МНС" замінити словом "Держгірпромнагляд" у відповідному відмінку.

{ Пункт 2 втратив чинність на підставі Постанови КМ N 314 ( 314-2010-п ) від 14.04.2010 }
