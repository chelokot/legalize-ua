КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 лютого 2009 р. N 93 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про доповнення постанов Кабінету Міністрів України від 17 жовтня 2008 р. N 921 і від 26 листопада 2008 р. N 1036

{ Із змінами, внесеними згідно з Постановою КМ N 324 ( 324-2010-п ) від 28.04.2010 }

Кабінет Міністрів України постановляє:

1. Доповнити пункт 7 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006; 2009 р., N 1, ст. 17), абзацом такого змісту:

"путівки до державних підприємств "Міжнародний дитячий центр "Артек" та "Український дитячий центр "Молода гвардія".".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 324 ( 324-2010-п ) від 28.04.2010 }
