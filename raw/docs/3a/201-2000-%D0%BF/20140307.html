КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 лютого 2000 р. N 201 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 61 ( 61-2014-п ) від 12.02.2014 }

Про відновлення дії деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Відновити дію постанов Кабінету Міністрів України від 9 грудня 1993 р. N 1022 ( 1022-93-п ) "Про формений одяг посадових осіб органів державної податкової служби" та від 18 квітня 1998 р. N 522 ( 522-98-п ) "Про внесення змін до постанови Кабінету Міністрів України від 9 грудня 1993 р. N 1022" (Офіційний вісник України, 1998 р., N 16, ст. 598).

2. Призупинити у 2000 році фінансування виготовлення для посадових осіб органів державної податкової служби форменого одягу, крім розрахунків за предмети цього одягу, що знаходяться на зберіганні та в процесі виготовлення.

Прем'єр-міністр України В.ЮЩЕНКО
