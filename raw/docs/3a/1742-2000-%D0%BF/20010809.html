Кабінет Міністрів України; Постанова, Положення від 29.11.2000 № 1742

Про затвердження Положення про порядок обчислення і сплати до державного бюджету рентної плати за транспортування нафти магістральними нафтопроводами та за транзитне транспортування трубопроводами аміаку, природного газу територією України

Стан: Втратив чинність

Ідентифікатор: 1742-2000-п

Текст документа від 09.08.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 листопада 2000 р. N 1742 Київ

Про затвердження Положення про порядок обчислення і сплати до державного бюджету відрахувань від надходжень за транспортування нафти магістральними нафтопроводами та від плати за транзит трубопроводом аміаку, природного газу через територію України

( Із змінами, внесеними згідно з Постановами КМ N 259 ( 259-2001-п ) від 22.03.2001 N 992 ( 992-2001-п ) від 09.08.2001 )

Кабінет Міністрів України постановляє:

( Вступна частина із змінами, внесеними згідно з Постановою КМ N 259 ( 259-2001-п ) від 22.03.2001 )

1. Затвердити Положення про порядок обчислення і сплати до державного бюджету відрахувань від надходжень за транспортування нафти магістральними нафтопроводами та від плати за транзит трубопроводом аміаку, природного газу через територію України.

( Пункт 1 в редакції Постанови КМ N 259 ( 259-2001-п ) від 22.03.2001 )

2. Визнати таким, що втратив чинність, пункт 1 постанови Кабінету Міністрів України від 21 грудня 1999 р. N 2335 ( 2335-99-п ) "Про затвердження Положення про порядок обчислення і сплати до Державного бюджету України відрахувань від плати за транзит природного газу, аміаку через територію України та відрахувань від прибутку, що залишається у розпорядженні підприємств, які здійснюють транспортування нафти магістральними нафтопроводами" (Офіційний вісник України, 1999 р., N 51, ст. 2540).

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 29 листопада 2000 р. N 1742

ПОЛОЖЕННЯ про порядок обчислення і сплати до державного бюджету відрахувань від надходжень за транспортування нафти магістральними нафтопроводами та від плати за транзит трубопроводом аміаку, природного газу через територію України ( Назва Положення в редакції Постанови КМ N 259 ( 259-2001-п ) від 22.03.2001 )

1. Це Положення визначає механізм обчислення і сплати до державного бюджету відрахувань від надходжень за транспортування нафти магістральними нафтопроводами та від плати за транзит трубопроводом аміаку, природного газу через територію України (далі - транспортування нафти та транзит аміаку, природного газу). ( Пункт 1 в редакції Постанови КМ N 259 ( 259-2001-п ) від 22.03.2001 )

2. Суб'єкти підприємницької діяльності відраховують до державного бюджету кошти в розмірі, еквівалентному:

від надходжень за транспортування нафти - 0,685 долара США за 1 тонну;

від плати за транзит аміаку - 0,23 долара США за 1 тонну на кожні 100 кілометрів відстані;

від плати за транзит природного газу - 0,29 долара США за 1000 куб. метрів газу на кожні 100 кілометрів відстані. ( Пункт 2 доповнено абзацом четвертим згідно з Постановою КМ N 259 ( 259-2001-п ) від 22.03.2001 )

Сплата зазначених відрахувань здійснюється щодекади, виходячи з обсягів нафти, аміаку та природного газу. ( Абзац пункту 2 в редакції Постанови КМ N 259 ( 259-2001-п ) від 22.03.2001 )

3. Платниками відрахувань від надходжень за транспортування нафти є Державне акціонерне товариство "Магістральні нафтопроводи "Дружба" та Державне акціонерне товариство "Придніпровські магістральні нафтопроводи".

Платником відрахувань від плати за транзит аміаку є державне підприємство "Укрхімтрансаміак". ( Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 992 ( 992-2001-п ) від 09.08.2001 )

Платником відрахувань від плати за транзит природного газу є НАК "Нафтогаз України. ( Пункт 3 доповнено абзацом згідно з Постановою КМ N 259 ( 259-2001-п ) від 22.03.2001 )

4. Сума відрахувань від надходжень за транспортування нафти та відрахувань від плати за транзит аміаку та природного газу обчислюється у валюті України виходячи з розмірів, зазначених у пункті 2 цього Положення, за офіційним курсом Національного банку, встановленим на день, що передує дню внесення платежу.

У разі коли день, що передує терміну внесення платежу, збігається з вихідним (святковим) днем, сума відрахувань обчислюється у валюті України за офіційним курсом Національного банку, встановленим на день, який настає за вихідним (святковим) днем, і на цей день відповідно переноситься термін внесення платежу.

( Пункт 4 із змінами, внесеними згідно з Постановою КМ N 259 ( 259-2001-п ) від 22.03.2001 )

5. Відрахування від надходжень за транспортування нафти та від плати за транзит аміаку вносяться платниками до державного бюджету щодекади авансовими платежами 15 і 25 числа поточного місяця та 5 числа місяця, що настає за звітним, виходячи з обсягів нафти, аміаку та природного газу за минулу декаду та суми відрахувань, визначеної згідно з пунктом 4 цього Положення. Відрахування зараховуються до державного бюджету за такими кодами бюджетної класифікації: ( Абзац перший пункту 5 із змінами, внесеними згідно з Постановою КМ N 259 ( 259-2001-п ) від 22.03.2001 )

за транспортування нафти - код 24061100, символ звітності банку - 203;

за транзит аміаку - код 24061200, символ звітності банку - 204;

за транзит природного газу - код 24060100, символ звітності банку - 048. ( Пункт 5 доповнено абзацом згідно з Постановою КМ N 259 ( 259-2001-п ) від 22.03.2001 )

6. Платники відрахувань щомісяця до 20 числа місяця, що настає за звітним, подають органам державної податкової служби за місцезнаходженням розрахунки відрахувань за формами згідно з додатком.

У разі коли обчислені у місячному розрахунку суми відрахувань більші від сум щодекадних авансових платежів, різниця доплачується не пізніше 25 числа місяця, що настає за звітним.

Не внесені в установлений термін суми відрахувань сплачуються до державного бюджету з нарахуванням пені відповідно до законодавства. ( Абзац третій пункту 6 в редакції Постанови КМ N 259 ( 259-2001-п ) від 22.03.2001 )

Зайво сплачені суми відрахувань зараховуються в рахунок відповідних чергових платежів або повертаються платникові в установленому порядку.

7. Відповідальність за правильність обчислення і своєчасність внесення відрахувань покладається на платника та його посадових осіб згідно із законодавством.

8. Контроль за правильністю обчислення і своєчасністю внесення до державного бюджету відрахувань за транспортування нафти та від плати за транзит аміаку та природного газу здійснюють органи державної податкової служби.

( Пункт 8 із змінами, внесеними згідно з Постановою КМ N 259 ( 259-2001-п ) від 22.03.2001 )
