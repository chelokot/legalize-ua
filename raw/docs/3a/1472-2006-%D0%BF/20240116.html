Про введення нових посад працівників у Секретаріаті Кабінету Міністрів України та умови оплати їх праці

Стан: Чинний

Ідентифікатор: 1472-2006-п

Текст документа від 16.01.2024:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 жовтня 2006 р. N 1472 Київ

Про введення нових посад працівників у Секретаріаті Кабінету Міністрів України та умови оплати їх праці

{ Із змінами, внесеними згідно з Постановою КМ N 33 ( 33-2024-п ) від 12.01.2024 }

Кабінет Міністрів України постановляє:

1. Ввести у Секретаріаті Кабінету Міністрів України посади референта та старшого референта, які не належать до посад державної служби.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 33 ( 33-2024-п ) від 12.01.2024 - застосовується з 1 січня 2024 року }

2. Надати право Державному секретареві Кабінету Міністрів України: { Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 33 ( 33-2024-п ) від 12.01.2024 - застосовується з 1 січня 2024 року }

1) установлювати у межах фонду оплати праці Секретаріату Кабінету Міністрів України на основі поданої керівниками самостійних структурних підрозділів Секретаріату інформації посадові оклади референта на рівні посадового окладу головного спеціаліста, а старшого референта на рівні посадового окладу завідуючого сектором у складі самостійного структурного підрозділу Секретаріату з урахуванням критеріїв класифікації посад, визначених Каталогом типових посад державної служби і критеріїв віднесення до таких посад ( 1109-2023-п ), затвердженим постановою Кабінету Міністрів України від 23 жовтня 2023 р. N 1109 (Офіційний вісник України, 2023 р., N 98, ст. 5869);

{ Підпункт 1 пункту 2 в редакції Постанови КМ N 33 ( 33-2024-п ) від 12.01.2024 - застосовується з 1 січня 2024 року }

2) надавати референтам та старшим референтам щорічні відпустки тривалістю 30 календарних днів з виплатою допомоги для оздоровлення у розмірі, що не перевищує їх середньомісячної заробітної плати;

3) установлювати референтам та старшим референтам надбавку за високі досягнення у праці або за виконання особливо важливої роботи у розмірі до 50 відсотків посадового окладу;

{ Підпункт 3 пункту 2 в редакції Постанови КМ N 33 ( 33-2024-п ) від 12.01.2024 - застосовується з 1 січня 2024 року }

4) здійснювати преміювання референтів та старших референтів відповідно до їх особистого внеску в загальний результат роботи Секретаріату у межах коштів, передбачених для преміювання працівників Секретаріату Кабінету Міністрів України;

{ Підпункт 4 пункту 2 із змінами, внесеними згідно з Постановою КМ N 33 ( 33-2024-п ) від 12.01.2024 - застосовується з 1 січня 2024 року }

5) надавати референтам та старшим референтам матеріальну допомогу для вирішення соціально-побутових питань у розмірі, що не перевищує їх середньомісячної заробітної плати.

{ Підпункт 6 пункту 2 виключено на підставі Постанови КМ N 33 ( 33-2024-п ) від 12.01.2024 - застосовується з 1 січня 2024 року }

Прем'єр-міністр України В.ЯНУКОВИЧ
