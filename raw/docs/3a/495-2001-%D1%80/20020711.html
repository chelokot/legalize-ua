КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 жовтня 2001 р. N 495-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 384-р ( 384-2002-р ) від 11.07.2002 )

Про Міжвідомчу робочу групу з підготовки проекту концепції створення та функціонування фінансової установи для підтримки підприємств агропромислового комплексу

Утворити Міжвідомчу робочу групу з підготовки проекту концепції створення та функціонування фінансової установи для підтримки підприємств агропромислового комплексу у складі згідно з додатком.

Дозволити керівнику Міжвідомчої робочої групи залучати в установленому порядку для підготовки зазначеного проекту працівників міністерств, інших центральних органів виконавчої влади, наукових і фінансових установ та організацій, а також вносити у разі потреби зміни до складу групи.

Міжвідомчій робочій групі подати в місячний термін проект концепції.
