Про митне оформлення вантажів, що надходять на адресу ВАТ "Укрелектроапарат" (м. Хмельницький)

Стан: Втратив чинність

Ідентифікатор: 1459-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 грудня 1999 р. N 1459-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснювати митне оформлення вантажів, що надходять на адресу ВАТ "Укрелектроапарат" (м. Хмельницький) для власних виробничих потреб за контрактами згідно з додатком, як товарів критичного імпорту.

Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 14 серпня 1999 р. N 809 ( 809-99-р ).
