Про зміни у складі Координаційної ради з підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

Стан: Втратив чинність

Ідентифікатор: 18/2009

Текст документа від 08.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 470/2010 ( 470/2010 ) від 02.04.2010 }

Про зміни у складі Координаційної ради з підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

На часткову зміну статті 2 Указу Президента України від 8 травня 2007 року N 389 ( 389/2007 ) "Про забезпечення підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" (зі змінами, внесеними Указами від 15 січня 2008 року N 22 ( 22/2008 ) та від 14 лютого 2008 року N 125) ( 125/2008 ):

увести до складу Координаційної ради з підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу ШЕВЛЯКА Іллю Миколайовича - заступника Міністра Кабінету Міністрів України - директора Координаційного бюро з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу Секретаріату Кабінету Міністрів України;

призначити БОГУЦЬКОГО Юрія Петровича - заступника Глави Секретаріату Президента України - секретарем Координаційної ради, увільнивши від виконання цих обов'язків О. Слюсаренко;

вивести зі складу Координаційної ради О. Слюсаренко та Є. Червоненка.

Президент України В.ЮЩЕНКО

м. Київ, 13 січня 2009 року N 18/2009
