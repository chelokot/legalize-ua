ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

08.09.2003 N 386

Зареєстровано в Міністерстві юстиції України 29 вересня 2003 р. за N 869/8190

Про внесення змін до окремих нормативно-правових актів Національного банку України

{ Із змінами, внесеними згідно з Постановами Національного банку

N 306 ( z1203-11 ) від 08.09.2011

N 346 ( z1590-12 ) від 17.08.2012 }

Відповідно до вимог статей 30 та 73 Закону України "Про банки і банківську діяльність" ( 2121-14 ) та з метою забезпечення стабільної діяльності банків Правління Національного банку України ПОСТАНОВЛЯЄ:

{ Пункт 1 втратив чинність на підставі Постанови Національного банку N 346 ( z1590-12 ) від 17.08.2012 }

2. Затвердити Зміни до розділу III Інструкції про порядок регулювання діяльності банків в Україні, затвердженої постановою Правління Національного банку України від 28.08.2001 N 368 ( z0841-01 ) та зареєстрованої в Міністерстві юстиції України 26.09.2001 за N 841/6032 (зі змінами), що додаються ( z0870-03 ).

{ Пункт 3 втратив чинність на підставі Постанови Національного банку N 306 ( z1203-11 ) від 08.09.2011 }

4. Генеральному департаменту банківського нагляду (В.В.Пушкарьов) після державної реєстрації в Міністерстві юстиції України довести зміст цієї постанови до відома самостійних структурних підрозділів і територіальних управлінь Національного банку України, а також банків для керівництва та використання в роботі.

5. Ця постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

6. Контроль за виконанням цієї постанови покласти на заступника Голови О.В.Шлапака, Генеральний департамент банківського нагляду (В.В.Пушкарьов) та начальників територіальних управлінь Національного банку України.

Голова С.Л.Тігіпко

{ Зміни до Положення про застосування Національним банком України заходів впливу за порушення банківського законодавства ( z0845-01 ) втратили чинність на підставі Постанови Національного банку N 346 ( z1590-12 ) від 17.08.2012 }
