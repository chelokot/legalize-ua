УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Указ Президента України від 25 лютого 1992 року N 100 ( 100/92 ) "Про Вищу атестаційну комісію України";

Указ Президента України від 25 лютого 1999 року N 216 ( 216/99 ) "Про Положення про Вищу атестаційну комісію України";

пункт 11 змін, що вносяться до указів Президента України, затверджених Указом Президента України від 5 березня 2004 року N 280 ( 280/2004 ) "Про внесення змін та визнання такими, що втратили чинність, деяких указів Президента України".
