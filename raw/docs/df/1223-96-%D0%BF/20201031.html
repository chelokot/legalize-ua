Кабінет Міністрів України; Постанова від 04.10.1996 № 1223

Про внесення доповнень до Граничних розмірів страхових тарифів з добровільного страхування майна громадян

Стан: Втратив чинність

Ідентифікатор: 1223-96-п

Текст документа від 31.10.2020:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 жовтня 1996 р. N 1223 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1000 ( 1000-2020-п ) від 28.10.2020 }

Про внесення доповнень до Граничних розмірів страхових тарифів з добровільного страхування майна громадян

З метою визначення страхових сум з добровільного страхування будівель громадян з урахуванням індексації об'єктів житлового фонду Кабінет Міністрів України постановляє:

Доповнити примітку Граничних розмірів страхових тарифів з добровільного страхування майна громадян, затверджених постановою Кабінету Міністрів України від 17 вересня 1996 р. N 1122 ( 1122-96-п ), після слів та цифр "(ЗП України, 1995 р., N 5, ст. 131)" словами і цифрами "та постанови Кабінету Міністрів України від 31 серпня 1996 р. N 1024 ( 1024-96-п ) "Про порядок індексації вартості об'єктів житлового фонду".
