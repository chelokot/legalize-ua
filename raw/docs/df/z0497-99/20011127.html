N 170 від 16.07.99 Зареєстровано в Міністерстві м.Київ юстиції України 23 липня 1999 р. vd990716 vn170 за N 497/3790

( Наказ втратив чинність на підставі Наказу Мінфіну N 521 ( z0990-01 ) від 13.11.2001 )

Про затвердження Інструкції про порядок обліку операцій з векселями, випущеними Радою міністрів Автономної Республіки Крим, обласними, Київською та Севастопольською міськими державними адміністраціями

На виконання постанови Кабінету Міністрів України від 20 травня 1999 року N 871 ( 871-99-п ) "Про затвердження Порядку випуску та обігу векселів Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських державних адміністрацій" (із змінами, внесеними постановою Кабінету Міністрів України від 15.06.99 N 1031 ( 1031-99-п ) НАКАЗУЮ:

1. Затвердити Інструкцію про порядок обліку операцій з векселями, випущеними Радою міністрів Автономної Республіки Крим, обласними, Київською та Севастопольською міськими державними адміністраціями (додається).

2. Міністерству фінансів Автономної Республіки Крим, обласним, Київському та Севастопольському міським фінансовим управлінням операції з векселями відображати в бухгалтерському обліку згідно з цією Інструкцією.

3. Контроль за виконанням наказу покласти на заступника Міністра фінансів П.Г.Петрашка.

Міністр І.О.Мітюков

Затверджено Наказ Міністерства фінансів України 16.07.99 N 170

Зареєстровано в Міністерстві юстиції України 23 липня 1999 р. за N 497/3790

Інструкція про порядок обліку операцій з векселями, випущеними Радою міністрів Автономної Республіки Крим, обласними, Київською та Севастопольською міськими державними адміністраціями

1. Відповідно до цієї Інструкції ведеться облік векселів Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських державних адміністрацій, випущених згідно з Порядком, затвердженим постановою Кабінету Міністрів України від 20.05.99 N 871 ( 871-99-п ) (із змінами, внесеними постановою Кабінету Міністрів України від 15.06.99 N 1031 ( 1031-99-п ), і призначених для погашення заборгованості виплат з відповідних бюджетів.

2. Операції з векселями місцевих державних адміністрацій у бухгалтерському обліку виконання місцевих бюджетів відображаються:

2.1. На суму випущених векселів:

Дебет рахунку 11302 "Короткострокові векселі"

Кредит рахунку 23103 "Зобов'язання місцевого бюджету по векселях"

2.2. На векселі, що видаються розпорядникам бюджетних коштів для розрахунків за надані послуги:

Дебет рахунку 11301 "Поточні бюджетні рахунки розпорядників коштів"

Кредит рахунку 13102 "Короткострокові векселі"

2.3. На суму проведених векселями касових видатків розпорядників коштів (наприкінці місяця):

Дебет рахунку 611 "Поточні видатки"

Кредит рахунку 11301 "Поточні бюджетні рахунки розпорядників коштів"

2.4. На суму векселів, погашених шляхом зарахування суми векселя у сплату недоїмки до місцевого бюджету:

Дебет рахунку 23103 "Зобов'язання місцевого бюджету по векселях"

Кредит рахунку 511 "Податкові надходження" 512 "Неподаткові надходження"

2.5. На закриття рахунків наприкінці року:

а) за доходами:

Дебет рахунку 511 "Податкові надходження" 512 "Неподаткові надходження"

Кредит рахунку 411 "Результати виконання бюджету"

б) за видатками:

Дебет рахунку 411 "Результати виконання бюджету"

Кредит рахунку 611 "Поточні видатки" 612 "Капітальні видатки"
