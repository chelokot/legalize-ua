Про додаткові заходи щодо посилення соціального захисту населення

Стан: Втратив чинність

Ідентифікатор: 215-91-п

Текст документа від 19.06.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 вересня 1991 р. N 215 Київ

( Постанова втратила чинність на підставі Постанови КМ N 856 ( 856-2002-п ) від 19.06.2002 )

Про додаткові заходи щодо посилення соціального захисту населення

( Із змінами, внесеними згідно з Постановами КМ N 691 ( 691-92-п ) від 09.12.92 N 1032 ( 1032-96-п ) від 31.08.96 )

Відповідно до постанови Президії Верховної Ради України від 30 серпня 1991 р. "Про додаткові заходи щодо посилення соціального захисту населення у зв'язку з прийняттям Верховною Радою України Акта проголошення незалежності України" ( 1470-12 ) Кабінет Міністрів України постановляє:

1. Установити, що витрати на придбання путівок для дітей - сиріт і дітей, які залишилися без батьківської опіки, провадяться за рахунок Фонду соціального захисту населення.

( Пункт 2 втратив чинність на підставі Постанови КМ N 691 ( 691-92-п ) від 09.12.92 )

3. Запровадити безплатні гарячі обіди для учнів 1-4 класів загальноосвітніх шкіл.

( На зміну пункту 3 установити, що з 1 вересня 1996 р. безплатні обіди у загальноосвітніх школах надаються дітям-сиротам та дітям із сімей, які отримують допомогу відповідно до статей 52 і 53 Закону України "Про державну допомогу сім'ям з дітьми" ( 2811-12 ) згідно з Постановою КМ N 1032 ( 1032-96-п ) від 31.08.96 )

( Пункт 4 втратив чинність на підставі Постанови КМ N 691 ( 691-92-п ) від 09.12.92 )

( Пункт 5 втратив чинність на підставі Постанови КМ N 691 ( 691-92-п ) від 09.12.92 )

6. Міністерству фінансів України в двотижневий строк визначити джерела фінансування заходів, передбачених в пунктах 3-5 цієї постанови.

7. Цю постанову ввести в дію з 1 жовтня 1991 року.
