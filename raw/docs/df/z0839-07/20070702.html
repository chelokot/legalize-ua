Зареєстровано в Міністерстві юстиції України 20 липня 2007 р. за N 839/14106

Про визнання деяких наказів такими, що втратили чинність

Відповідно до Закону України "Про державну статистику" ( 2614-12 ) та з метою приведення нормативно-правових акті у відповідність до чинного законодавства НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

1.1. Наказ Міністерства статистики України від 07.12.95 N 319 ( z0475-95 ) "Про затвердження форми державної статистичної звітності по формі N 1 - екологічні фонди та Інструкції по її складанню", зареєстрований в Міністерстві юстиції України 22.12.95 за N 475/1011.

1.2. Наказ Міністерства статистики України від 13.05.96 N 135 ( z0250-96 ) "Про затвердження форми державної статистичної звітності по формі N 1 - екологічні витрати та Інструкції по її складанню", зареєстрований в Міністерстві юстиції України 25.05.96 за N 250/1275.

1.3. Наказ Держкомстату України від 30.08.2004 N 497 ( z1134-04 ) "Про затвердження інструкцій щодо заповнення форм державних статистичних спостережень в галузі сільського господарства" в частині Інструкції щодо заповнення форми державного статистичного спостереження N 6-мех "Стан сільськогосподарської техніки та надходження пального на "__" 200 року", затвердженої пунктом 1 наказу, зареєстрованої в Міністерстві юстиції України 13.09.2004 за N 1134/9733.

1.4. Наказ Держкомстату України від 24.06.2005 N 162 ( z0731-05 ) "Про затвердження інструкцій щодо заповнення форм державних статистичних спостережень в галузі сільського господарства" в частині Інструкції щодо заповнення форми державного статистичного спостереження N 5-сг ( z0736-05 ) "Сортові посіви під урожай 200_року", затвердженої підпунктом 1.6 пункту 1 наказу, зареєстрованої в Міністерстві юстиції України 12.07.2005 за N 731/11011.

1.5. Наказ Держкомстату України від 07.07.2005 N 169 ( z0779-05 ) "Про затвердження форм переписних листів та інструкцій щодо проведення обліку (перепису) поголів'я худоби у домашніх господарствах за станом на 1 січня 2006 року" в частині форми N 5 "Переписний лист перевірки (контрольного обходу) чисельності худоби у домашніх господарствах сільської місцевості та міських населених пунктів", затвердженої підпунктом 1.2 пункту 1 наказу, та в частині інструкцій щодо проведення обліку (перепису) поголів'я худоби у домашніх господарствах, затверджених пунктом 3 наказу, зареєстрованих в Міністерстві юстиції України 20.07.2005 за N 779/11059.

2. Контроль за виконанням цього наказу покласти на заступника Голови Остапчука Ю.М.
