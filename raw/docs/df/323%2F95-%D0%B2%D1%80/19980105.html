Текст документа від 05.01.1998:

ЗАКОН УКРАЇНИ

( Закон втратив чинність на підставі Закону N 738/97-ВР від 17.12.97, ВВР, 1998, N 16, ст.72 )

Про приєднання України до Конвенції про відмивання, пошук, арешт та конфіскацію доходів, одержаних злочинним шляхом, 1990 року

( Відомості Верховної Ради України (ВВР), 1995, N 31, ст.243 )

Верховна Рада України постановляє:

Приєднатися від імені України до Конвенції про відмивання, пошук, арешт та конфіскацію доходів, одержаних злочинним шляхом ( 995_029 ), 1990 року.
