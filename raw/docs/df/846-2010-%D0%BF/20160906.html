КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 вересня 2010 р. N 846 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 545 ( 545-2016-п ) від 23.08.2016 }

Питання Департаменту державної виконавчої служби Міністерства юстиції

Кабінет Міністрів України постановляє:

1. На часткову зміну абзацу другого пункту 1 постанови Кабінету Міністрів України від 12 березня 2005 р. N 179 ( 179-2005-п ) "Про упорядкування структури апарату центральних органів виконавчої влади, їх територіальних підрозділів та місцевих державних адміністрацій" (Офіційний вісник України, 2005 р., N 11, ст. 522; 2006 р., N 33, ст. 2391; 2007 р., N 48, ст. 1969; 2008 р., N 68, ст. 2270; 2009 р., N 84, ст. 2843, N 88, ст. 2971) установити, що директор Департаменту державної виконавчої служби Міністерства юстиції має п'ять заступників, у тому числі одного першого заступника та одного заступника директора Департаменту - начальника відділу примусового виконання рішень.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 16 вересня 2009 р. N 1156 ( 1156-2009-п ) "Питання Департаменту державної виконавчої служби Міністерства юстиції" (Офіційний вісник України, 2009 р., N 84, ст. 2843).
