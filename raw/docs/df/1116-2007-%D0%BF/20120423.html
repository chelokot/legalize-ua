{ Постанова втратила чинність на підставі Постанови КМ N 295 ( 295-2012-п ) від 11.04.2012 }

Про доповнення пункту 102 Правил надання та отримання телекомунікаційних послуг

Кабінет Міністрів України постановляє:

Доповнити друге речення абзацу третього пункту 102 Правил надання та отримання телекомунікаційних послуг, затверджених постановою Кабінету Міністрів України від 9 серпня 2005 р. N 720 ( 720-2005-п ) (Офіційний вісник України, 2005 р., N 32, ст. 1935; 2006 р., N 22, ст. 1609, N 25, ст. 1815; 2007 р., N 39, ст. 1559), після слів "(у сільській місцевості)" словами ", а також роботи з організації абонентської лінії на основі використання радіотехнологій із встановленням стаціонарних (квартирних) терміналів".

Прем'єр-міністр України В.ЯНУКОВИЧ
