УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії розпоряджень Кабінету Міністрів України від 28 травня 2008 року N 744-р, N 745-р, N 746-р, N 747-р, N 756-р, N 757-р, N 758-р, N 759-р, N 760-р, N 761-р, N 762-р і N 763-р

{ Додатково див. Конституційне подання Президента ( n0019100-08 ) від 10.06.2008 }

Кабінетом Міністрів України 28 травня 2008 року видано розпорядження N 744-р ( 744-2008-р ) "Про звільнення Звєрєва В.П. з посади Голови Національної комісії з питань регулювання зв'язку України", N 745-р ( 745-2008-р ) "Про звільнення Колобова С.О. з посади члена Національної комісії з питань регулювання зв'язку України", N 746-р ( 746-2008-р ) "Про призначення Колобова С.О. Головою Національної комісії з питань регулювання зв'язку України", N 747-р ( 747-2008-р ) "Про призначення Звєрєва В.П. членом Національної комісії з питань регулювання зв'язку України", N 756-р ( 756-2008-р ) "Про звільнення Єжової Л.М. з посади члена Національної комісії з питань регулювання зв'язку України", N 757-р ( 757-2008-р ) "Про звільнення Мазура В.О. з посади члена Національної комісії з питань регулювання зв'язку України", N 758-р ( 758-2008-р ) "Про звільнення Костриби Н.П. з посади члена Національної комісії з питань регулювання зв'язку України", N 759-р ( 759-2008-р ) "Про звільнення Філіпової О.І. з посади члена Національної комісії з питань регулювання зв'язку України", N 760-р ( 760-2008-р ) "Про призначення Артюшенко Л.В. членом Національної комісії з питань регулювання зв'язку України", N 761-р ( 761-2008-р ) "Про призначення Мирного С.В. членом Національної комісії з питань регулювання зв'язку України", N 762-р ( 762-2008-р ) "Про призначення Степанова О.А. членом Національної комісії з питань регулювання зв'язку України", N 763-р ( 763-2008-р ) "Про призначення Тичинського А.В. членом Національної комісії з питань регулювання зв'язку України".

Названими актами ( 744-2008-р, 745-2008-р, 746-2008-р, 747-2008-р, 756-2008-р, 757-2008-р, 758-2008-р, 759-2008-р, 760-2008-р, 761-2008-р, 762-2008-р, 763-2008-р ) Кабінет Міністрів України призначив на посади та звільнив з посад Голову та членів Національної комісії з питань регулювання зв'язку України - органу, до компетенції якого віднесено регулювання природних монополій у сфері зв'язку. Ці акти ( 744-2008-р, 745-2008-р, 746-2008-р, 747-2008-р, 756-2008-р, 757-2008-р, 758-2008-р, 759-2008-р, 760-2008-р, 761-2008-р, 762-2008-р, 763-2008-р ) прийнято Кабінетом Міністрів України всупереч Конституції України ( 254к/96-ВР ).

Згідно з частиною третьою статті 42 Конституції України ( 254к/96-ВР ) види і межі монополії визначаються законом. Особливості правового регулювання зазначених питань визначено Законами України "Про природні монополії" ( 1682-14 ) та "Про телекомунікації" ( 1280-15 ). Законом України "Про природні монополії" ( 1682-14 ) Національну комісію з питань регулювання зв'язку України визначено як орган регулювання у сфері зв'язку (стаття 4). За статтею 20 Закону України "Про телекомунікації" ( 1280-15 ) Голову та членів Національної комісії з питань регулювання зв'язку України призначає за поданням Прем'єр-міністра України на посади та припиняє їх повноваження на цих посадах Президент України.

Конституційним обов'язком Президента України є забезпечення національної безпеки, складовою якої є економічна та інформаційна безпека держави, та здійснення керівництва у цій сфері (стаття 17, пункти 1 і 17 частини першої статті 106 Конституції України) ( 254к/96-ВР ).

Ураховуючи, що створення ефективного механізму державного регулювання природних монополій за статтею 8 Закону України "Про основи національної безпеки України" ( 964-15 ) є одним із основних напрямів державної політики з питань національної безпеки України в економічній сфері, зазначені акти Кабінету Міністрів України ( 744-2008-р, 745-2008-р, 746-2008-р, 747-2008-р, 756-2008-р, 757-2008-р, 758-2008-р, 759-2008-р, 760-2008-р, 761-2008-р, 762-2008-р, 763-2008-р ) не відповідають статтям 17, 42, пункту 1 і 17 частини першої статті 106 Конституції України ( 254к/96-ВР ), Законам України "Про природні монополії" ( 1682-14 ) та "Про телекомунікації" ( 1280-15 ).

Відтак, видавши названі розпорядження ( 744-2008-р, 745-2008-р, 746-2008-р, 747-2008-р, 756-2008-р, 757-2008-р, 758-2008-р, 759-2008-р, 760-2008-р, 761-2008-р, 762-2008-р, 763-2008-р ), Кабінет Міністрів України вийшов за межі повноважень, визначених для нього Конституцією ( 254к/96-ВР ) і законами України, чим порушив вищезазначені норми Конституції України ( 254к/96-ВР ), а також вимоги положень частини другої статті 6, частини другої статті 19 та частини третьої статті 113 Основного Закону ( 254к/96-ВР ) держави, які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, а також діяти на підставі та у спосіб, що ними передбачені.
