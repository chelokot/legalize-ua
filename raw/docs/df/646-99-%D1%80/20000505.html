Кабінет Міністрів України; Розпорядження від 03.07.1999 № 646-р

Про митне оформлення напівавтоматичної лінії для переробки тонкомірної деревини на базі багатопильних двовальних верстатів, що надійшли на адресу державного лісогосподарського об'єднання "Рівнеліс"

Стан: Втратив чинність

Ідентифікатор: 646-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 липня 1999 р. N 646-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Для забезпечення виконання інвестиційного проекту створення сучасної лінії виготовлення високоякісних клеєних меблевих щитів Держмитслужбі здійснити митне оформлення напіватоматичної лінії для переробки тонкомірної деревини на базі багатопильних двовальних верстатів моделей "MULTIPRISMA" 280/100-100 та "GHEPARDO" 2-75, (код згідно із ТН ЗЕД 8465 91000) вартістю 588 тис. німецьких марок, що надійшли на адресу державного лісогосподарського об'єднання "Рівнеліс" за контрактом від 28 липня 1998 р. N 00994377-33, з фірмою "Alexis Holzhandel GmbH" (Німеччина), відповідно до порядку, що діяв на момент укладення контракту без нарахування митного збору за перебування обладнання під митним контролем.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
