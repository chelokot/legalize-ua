Текст документа від 03.10.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 894/2008 ( 894/2008 ) від 03.10.2008 }

Про зупинення дії розпорядження Кабінету Міністрів України від 18 червня 2008 року N 839-р

{ Додатково див. Конституційне подання Президента ( n0021100-08 ) від 02.07.2008 }

Кабінетом Міністрів України 18 червня 2008 року видано розпорядження N 839-р ( 839-2008-р ) "Про тимчасове покладення виконання обов'язків Голови Антимонопольного комітету України на Мельниченка О.І.", яким вирішено питання про тимчасове виконання обов'язків Голови Антимонопольного комітету України на період до призначення в установленому порядку Голови цього Комітету.

Назване розпорядження ( 839-2008-р ) видано Кабінетом Міністрів України всупереч Конституції України ( 254к/96-ВР ).

Відповідно до конституційно-правових засад поділу влади на законодавчу, виконавчу та судову (частина перша статті 6) ( 254к/96-ВР ) та принципів конституційності, законності органи державної влади та органи місцевого самоврядування, їх посадові особи зобов'язані діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України (частина друга статті 19) ( 254к/96-ВР ), Конституція України ( 254к/96-ВР ) має найвищу юридичну силу, її норми є нормами прямої дії (частини друга та третя статті 8) ( 254к/96-ВР ).

За приписом пункту 12 частини першої статті 85 Конституції України ( 254к/96-ВР ) Голову Антимонопольного комітету України призначає Верховна Рада України за поданням Прем'єр-міністра України. Внесення Прем'єр-міністром України подання щодо кандидатури на посаду Голови Антимонопольного комітету України згідно з вимогами Основного Закону ( 254к/96-ВР ) держави має здійснюватися у межах парламентських процедур.

У такому ж порядку за Конституцією України ( 254к/96-ВР ) призначаються і міністри (крім Міністра оборони України та Міністра закордонних справ України). Однак, якщо Конституцією України ( 254к/96-ВР ) прямо встановлено, що міністри входять до складу Кабінету Міністрів України (частина перша статті 114) ( 254к/96-ВР ), а міністерства належать до центральних органів виконавчої влади (пункти 9, 9-1 статті 116, частина третя статті 117) ( 254к/96-ВР ), то щодо Антимонопольного комітету України норми, які б визначали його як орган, що належить до системи органів виконавчої влади, в Основному Законі ( 254к/96-ВР ) держави відсутні.

Чинним же Законом України "Про Антимонопольний комітет України" ( 3659-12 ) Антимонопольний комітет України визначено як державний орган зі спеціальним статусом (частина перша статті 1) ( 3659-12 ), який будує свої відносини з Кабінетом Міністрів України на засадах взаємодії (стаття 20-1) ( 3659-12 ).

Згідно з пунктами 9, 9-2 статті 116 Конституції України ( 254к/96-ВР ) до повноважень Кабінету Міністрів України належать спрямування і координація роботи міністерств, інших центральних органів виконавчої влади, призначення на посади та звільнення з посад за поданням Прем'єр-міністра України керівників центральних органів виконавчої влади, які не входять до складу Кабінету Міністрів України. Законом України "Про Кабінет Міністрів України" ( 279-17 ) деталізовано повноваження Кабінету Міністрів України стосовно спрямування і координації роботи органів виконавчої влади, вирішення кадрових питань діяльності органів виконавчої влади (статті 22, 44, 46, 49) ( 279-17 ) і водночас визначено, що з державними органами Кабінет Міністрів України взаємодіє з питань, що належать до його компетенції (стаття 40) ( 279-17 ). Участь Кабінету Міністрів України у вирішенні кадрових питань діяльності Антимонопольного комітету України за Конституцією України ( 254к/96-ВР ) зводиться до внесення Прем'єр-міністром України до Верховної Ради України подання щодо кандидатури на посаду Голови Антимонопольного комітету України (пункт 12 частини першої статті 85) ( 254к/96-ВР ); цю конституційну норму відтворено і в Законі України "Про Кабінет Міністрів України" ( 279-17 ) (пункт 3 частини першої статті 44).

За таких обставин, вирішивши питання про тимчасове виконання обов'язків Голови Антимонопольного комітету України - органу, який не є центральним органом виконавчої влади, Кабінет Міністрів України вийшов за межі повноважень, визначених для нього Конституцією України ( 254к/96-ВР ), діяв у спосіб, що не передбачений ні Основним Законом ( 254к/96-ВР ) держави, ні чинними законами. Отже, розпорядження Кабінету Міністрів України від 18 червня 2008 року N 839-р ( 839-2008-р ) прийнято на порушення вищезазначених норм Конституції України ( 254к/96-ВР ), частини третьої статті 113, частини першої статті 117 Основного Закону ( 254к/96-ВР ) держави, які є нормами прямої дії і зобов'язують Кабінет Міністрів України керуватися, зокрема, Конституцією ( 254к/96-ВР ) та законами України, видавати постанови і розпорядження в межах своєї компетенції.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 18 червня 2008 року N 839-р ( 839-2008-р ) "Про тимчасове покладення виконання обов'язків Голови Антимонопольного комітету України на Мельниченка О.І.".

2. Цей Указ набирає чинності з дня його опублікування.
