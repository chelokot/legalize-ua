РОЗПОРЯДЖЕННЯ від 11 січня 2006 р. N 5-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

Питання оплати праці працівників Апарату Верховної Ради України

Відповідно до статті 8 Закону України "Про оплату праці" ( 108/95-ВР ) надати Керівнику Апарату Верховної Ради України право встановлювати працівникам зазначеного Апарату надбавку за особливий характер роботи та інтенсивність праці у розмірі і порядку, визначених розпорядженням Кабінету Міністрів України від 4 липня 1995 р. N 414 ( 414-95-р ).

Прем'єр-міністр України Ю.ЄХАНУРОВ
