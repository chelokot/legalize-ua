Президент України; Указ від 15.11.2006 № 967/2006

Про внесення подання щодо звільнення Н. Гаркавої

Стан: Чинний

Ідентифікатор: 967/2006

Текст документа від 15.11.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення подання щодо звільнення Н. Гаркавої

Указом Президента України від 13 грудня 2005 року N 1742 ( 1742/2005 ) на посаду голови Сумської обласної державної адміністрації було призначено ГАРКАВУ Ніну Миколаївну. 8 листопада 2006 року Н. Гаркава досягла граничного віку перебування на державній службі для жінок, визначеного статтею 23 Закону України "Про державну службу" ( 3723-12 ), що згідно з пунктом 3 частини першої статті 30 цього ж Закону ( 3723-12 ) є підставою для припинення державної служби.

Питання щодо продовження терміну перебування на державній службі щодо Н. Гаркавої в установленому порядку не вирішено.

Таким чином, Н. Гаркава продовжує перебувати на державній службі, виконувати відповідні посадові обов'язки на посаді голови місцевої державної адміністрації в порушення Закону України "Про державну службу" ( 3723-12 ).

Відповідно до частини четвертої статті 118 Конституції України ( 254к/96-ВР ) звільнення з посад голів місцевих державних адміністрацій здійснюється Президентом України за поданням Кабінету Міністрів України.

Однак всупереч Конституції України ( 254к/96-ВР ) подання щодо звільнення Н. Гаркавої із займаної посади, незважаючи на вжиті за дорученням глави держави заходи щодо врегулювання цього питання, Кабінетом Міністрів України досі не внесено.

З метою забезпечення виконання Закону України "Про державну службу" ( 3723-12 ), статті 118 Конституції України ( 254к/96-ВР ), виходячи з норм статті 19 Конституції України ( 254к/96-ВР ), яка зобов'язує органи державної влади діяти на підставі та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України, статті 113 Конституції України ( 254к/96-ВР ), за якою Кабінет Міністрів України керується у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, прийнятими відповідно до них указами Президента України, пункту 1 статті 116 Конституції України ( 254к/96-ВР ), який покладає на Кабінет Міністрів України повноваження щодо забезпечення виконання Конституції ( 254к/96-ВР ) і законів України, постановляю:

1. Кабінету Міністрів України внести у тижневий строк відповідно до статті 118 Конституції України ( 254к/96-ВР ) подання щодо звільнення Н. Гаркавої з посади голови Сумської обласної державної адміністрації у зв'язку з досягненням граничного віку проходження державної служби.

2. Цей Указ набирає чинності з дня опублікування.

Президент України В.ЮЩЕНКО
