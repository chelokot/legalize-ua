( Постанова втратила чинність на підставі Постанови ВР N 3654-XII ( 3654-12 ) від 25.11.93, ВВР, 1993, N 49, ст.468 )

Про утворення Центральної виборчої комісії по виборах народних депутатів Української РСР

( Відомості Верховної Ради УРСР (ВВР), 1989, N 45, ст. 629 )

Розглянувши пропозиції виконавчих комітетів обласних, Київської міської Рад народних депутатів і республіканських органів громадських організацій, на підставі статті 21 Закону Української РСР "Про вибори народних депутатів Української РСР" ( 8304-11 ) Верховна Рада Української Радянської Соціалістичної Республіки постановляє:

Утворити Центральну виборчу комісію по виборах народних депутатів Української РСР у такому складі:

Голова Центральної виборчої комісії

Бойко Віталій Федорович - перший заступник Міністра юстиції Української РСР.

Заступники голови Центральної виборчої комісії

Плюта Ніна Йосипівна - токар заводу "Ірпіньмаш", Київська область.

Тацій Василь Якович - ректор Харківського юридичного інституту імені Ф.Е. Дзержинського.

Секретар Центральної виборчої комісії

Литвин Микола Олексійович - перший заступник завідуючого відділом організаційно-партійної і кадрової роботи ЦК Компартії України.
