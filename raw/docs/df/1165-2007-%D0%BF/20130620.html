ПОСТАНОВА від 26 вересня 2007 р. N 1165 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 414 ( 414-2013-п ) від 12.06.2013 }

Деякі питання Національної комісії з питань Червоної книги України

{ Із змінами, внесеними згідно з Постановою КМ N 924 ( 924-2008-п ) від 16.10.2008 }

Кабінет Міністрів України постановляє:

1. Затвердити склад Національної комісії з питань Червоної книги України, що додається.

2. Внести до Положення про Національну комісію з питань Червоної книги України, затвердженого постановою Кабінету Міністрів України від 8 вересня 2004 р. N 1176 ( 1176-2004-п ) "Про Національну комісію з питань Червоної книги України" (Офіційний вісник України, 2004 р., N 36, ст. 2399; 2006 р., N 7, ст. 360), зміни, що додаються.

3. Міністерству охорони навколишнього природного середовища привести власні акти у відповідність з цією постановою.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 вересня 2007 р. N 1165

ЗМІНИ, що вносяться до Положення про Національну комісію з питань Червоної книги України ( 1176-2004-п )

1. Доповнити пункт 5 абзацом такого змісту:

"У разі потреби голова Комісії може скликати її позапланове засідання.".

2. Пункт 6 викласти у такій редакції:

"6. Рішення Комісії приймається шляхом відкритого або таємного голосування простою більшістю голосів присутніх на засіданні членів Комісії за умови участі у голосуванні не менш як двох третин її складу та оформляється протоколом, який підписує головуючий на засіданні та відповідальний секретар.

Рішення Комісії з питань, що потребують невідкладного розгляду, може бути прийнято шляхом опитування членів Комісії, до яких з використанням електронної пошти та засобів факсимільного зв'язку доводиться зміст питання та відповідний проект рішення. Член Комісії після ознайомлення із змістом проекту рішення письмово (з використанням засобу факсимільного зв'язку) повідомляє голову Комісії про свою позицію щодо його прийняття. У разі рівного розподілу голосів розгляд питання переноситься на наступне засідання.".
