Президент України; Указ від 14.02.2011 № 210/2011

Про заміщення однієї посади першого заступника Керівника Апарату Верховної Ради України

Стан: Втратив чинність

Ідентифікатор: 210/2011

Текст документа від 04.10.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про заміщення однієї посади першого заступника Керівника Апарату Верховної Ради України

{ Назва Указу із змінами, внесеними згідно з Указом Президента N 954/2011 ( 954/2011 ) від 29.09.2011 }

{ Із змінами, внесеними згідно з Указом Президента N 954/2011 ( 954/2011 ) від 29.09.2011 }

1. Установити, що одна посада першого заступника Керівника Апарату Верховної Ради України заміщується особою вищого начальницького складу з граничним спеціальним званням генерал-полковник міліції (на час перебування на цій посаді особи, яка займає її на даний час).

{ Стаття 1 із змінами, внесеними згідно з Указом Президента N 954/2011 ( 954/2011 ) від 29.09.2011 }

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 14 лютого 2011 року N 210/2011
