Про внесення змін і доповнень до положень "Про порядок створення і реєстрації комерційних банків" та "Про порядок ліцензування банків в Україні"

Стан: Втратив чинність

Ідентифікатор: z0629-97

Текст документа від 10.06.1998:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 448 від 22.12.97 Зареєстровано в Міністерстві м.Київ юстиції України 30 грудня 1997 р. vd971222 vn448 за N 629/2433

( Постанова втратила чинність на підставі Постанови Нацбанку N 281 ( z0541-98 ) від 21.07.98 )

Про внесення змін і доповнень до положень "Про порядок створення і реєстрації комерційних банків" та "Про порядок ліцензування банків в Україні"

( Із змінами, внесеними згідно з Постановою Нацбанку N 181 ( z0373-98 ) від 06.05.98 )

Розглянувши пропозиції Департаменту готівково-грошового обігу про необхідність внесення змін і доповнень до положень "Про порядок створення і реєстрації комерційних банків" та "Про порядок ліцензування банків в Україні", затверджених постановою Правління Національного банку України від 27 березня 1996 року N 77 ( v0077500-96 ), Правління ПОСТАНОВЛЯЄ:

1. Абзац п'ятий п.7.3 розділу 7 Положення "Про порядок створення і реєстрації комерційних банків" доповнити словами "при максимальних обсягах цінностей, що знаходяться в установі банку, понад 3000 неоподатковуваних мінімумів доходів громадян".

( Пункт 2 втратив чинність на підставі Постанови Нацбанку N 181 ( z0373-98 ) від 06.05.98 ) 2. Абзац третій п.7.3 розділу 7 Положення "Про порядок ліцензування банків в Україні" викласти у такій редакції:

"- для установ банків з щоденними обсягами зберігання цінностей понад 3000 неоподатковуваних мінімумів доходів громадян відповідність організації охорони банків вимогам "Інструкції по охороні установ банків України підрозділами міліції при органах внутрішніх справ", затвердженої спільним наказом Міністерства внутрішніх справ України та Національного банку України від 12.06.91 р. N 372ДСК/32ДСК".

Голова В.А.Ющенко
