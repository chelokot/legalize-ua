( Наказ втратив чинність на підставі Наказу Мін'юсту N 31/5 ( z0364-99 ) від 09.06.99 )

Про внесення змін та доповнень до Положення про Єдиний реєстр для реєстрації заборон на відчуження нерухомого майна

1. Внести такі зміни та доповнення до Положення про Єдиний реєстр для реєстрації заборон на відчуження нерухомого майна, затвердженого наказом Міністра юстиції України від 27 травня 1997 року N 41/5 ( z0194-97 ):

- пункт 6.5 викласти у такій редакції:

"Довідки про відсутність заборон та арештів виконуються на спеціальних бланках нотаріальних документів за єдиним стандартом (додаток N 1) і посвідчуються печаткою реєструвального органу".

В. о. Міністра юстиції В.Головач
