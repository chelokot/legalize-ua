{ Розпорядження втратило чинність на підставі Указу Президента N 1008/2011 ( 1008/2011 ) від 31.10.2011 }

Про склад української делегації Спільної українсько-молдовської демаркаційної комісії

На часткову зміну Розпорядження Президента України від 13 березня 2006 року N 45 ( 45/2006-рп ) "Про новий склад української делегації Спільної українсько-молдовської демаркаційної комісії" (зі змінами, внесеними Розпорядженнями від 27 серпня 2007 року N 188 ( 188/2007-рп ) та від 24 жовтня 2008 року N 307) ( 307/2008-рп ):

1) увести до складу української делегації Спільної українсько-молдовської демаркаційної комісії ( 45/2006-рп ) БРЕСКАЛЕНКА Геннадія Семеновича - начальника відділу Договірно-правового департаменту Міністерства закордонних справ України, поклавши на нього виконання обов'язків глави української делегації;

2) затвердити у складі української делегації Спільної українсько-молдовської демаркаційної комісії ( 45/2006-рп ) СОФІЄНКА Олександра Миколайовича - начальника відділу - заступника начальника Центрального управління Головного управління оперативного забезпечення Командування сил підтримки Збройних Сил України;

3) вивести зі складу української делегації Спільної українсько-молдовської демаркаційної комісії ( 45/2006-рп ) В. Котика, увільнивши його від виконання обов'язків глави української делегації.

Президент України В.ЮЩЕНКО

м. Київ, 13 жовтня 2009 року N 216/2009-рп
