Про затвердження нового складу Державної надзвичайної протиепізоотичної комісії при Кабінеті Міністрів України

Стан: Втратив чинність

Ідентифікатор: 619-2003-п

Текст документа від 22.10.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 квітня 2003 р. N 619 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1027 ( 1027-2005-п ) від 22.10.2005 )

Про затвердження нового складу Державної надзвичайної протиепізоотичної комісії при Кабінеті Міністрів України

Кабінет Міністрів України постановляє:

1. На часткову зміну пункту 2 постанови кабінету Міністрів України від 20 квітня 1998 р. N 517 ( 517-98-п ) "Про затвердження положень про державні надзвичайні протиепізоотичні комісії" (Офіційний вісник України, 1998 р., N 16, ст. 596) затвердити новий склад Державної надзвичайної протиепізоотичної комісії при Кабінеті Міністрів України, що додається.

2. Визнати таким, що втратив чинність, підпункт 1 постанови Кабінету Міністрів України від 28 березня 2001 р. N 282 ( 282-2001-п ) "Про внесення змін до постанови Кабінету Міністрів України від 20 квітня 1998 р. N 517" (Офіційний вісник України, 2001 р., N 13, ст. 546).
