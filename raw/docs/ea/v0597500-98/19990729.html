Стан: Втратив чинність

Текст документа від 29.07.1999:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 513 від 04.12.98 Зареєстровано в юридичному департаменті Нацбанку 17 грудня 1998 р. за N 597

Про деякі питання регулювання грошово-кредитного ринку

( Із змінами, внесеними згідно з Постановою Нацбанку N 332 ( z0511-99 ) від 09.07.99 )

Проаналізувавши ситуацію на грошово-кредитному ринку України, тенденції його розвитку до кінця 1998 року, стан виконання бюджету в 1998 році та виходячи із прогнозів, що дефіцит Державного бюджету на 1999 рік планується у розмірі не більше 1 відсотка від ВВП, формування комерційними банками обов'язкових резервів та стан ліквідності банківської системи, Правління ПОСТАНОВЛЯЄ:

1. Не для друку.

2. З метою забезпечення виконання Указу Президента України від 10.09.98 N 996/98 "Про заходи щодо захисту прав фізичних осіб" та відповідно до Положення про порядок створення Фонду гарантування вкладів фізичних осіб, формування та використання його коштів, затвердженого цим Указом, комерційним банкам України забезпечити перерахування на рахунок Фонду гарантування вкладів фізичних осіб коштів початкового збору протягом 30 днів після затвердження Положення про Фонд гарантування вкладів фізичних осіб.

3. Встановити порядок, відповідно до якого, починаючи з першої декади січня 1999 р., при визначенні результатів формування комерційними банками обов'язкових резервів не враховується сума мінімальних обов'язкових резервів, розміщених комерційними банками (у визначеному розмірі від суми залучених коштів фізичних осіб) у державні цінні папери та переданих на зберігання до Депозитарію Національного банку України.

( Абзац втратив чинність в частині внесення змін в Положення про порядок формування банківською системою України обов'язкових резервів на підставі Постанови Нацбанку N 332 ( z0511-99 ) від 09.07.99 ) Вважати такими, що втратили чинність, абзац 4 п.10 Положення про порядок формування банківською системою України обов'язкових резервів ( v0410500-96 ), затвердженого постановою Правління від 26.12.96 N 333 ( v0333500-96 ), та пункт 2 постанови Правління від 04.09.98 N 347 ( v6290500-98 ) з цього питання.

4. Не для друку.

5. Не для друку.

Голова В.А.Ющенко
