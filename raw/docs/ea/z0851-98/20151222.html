{ Із змінами, внесеними згідно з Наказом Міністерства економічного розвитку і торгівлі N 1443 ( z1480-15 ) від 13.11.2015 }

На виконання постанови Кабінету Міністрів України від 16.11.98 N 1809 ( 1809-98-п ) "Про додаткові заходи щодо недопущення імпорту неякісних лікеро-горілчаних виробів" НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства економічного розвитку і торгівлі N 1443 ( z1480-15 ) від 13.11.2015 }

2. Внести такі зміни до наказу Державного комітету України по стандартизації, метрології та сертифікації від 29.02.96 N 85 "Про затвердження Порядку проведення атестації виробництва спирту етилового, коньячного і плодового, алкогольних напоїв та тютюнових виробів", зареєстрованого в Міністерстві юстиції України 12 червня 1996 року за N 291/1316 ( z0291-96 ).

Абзац третій пункту 2 наказу Державного комітету України по стандартизації, метрології та сертифікації від 29.02.96 N 85 "Про затвердження Порядку проведення атестації виробництва спирту етилового, коньячного і плодового, алкогольних напоїв та тютюнових виробів" вилучити.

3. Внести такі зміни до Порядку проведення атестації виробництва спирту етилового, коньячного і плодового, алкогольних напоїв та тютюнових виробів, затвердженого наказом Державного комітету України по стандартизації, метрології та сертифікації від 29 лютого 1996 року N 85 ( z0291-96 ) і зареєстрованого в Міністерстві юстиції України 12 червня 1996 року за N 291/1316, із змінами до нього, внесеними наказом Державного комітету України по стандартизації, метрології та сертифікації від 20 серпня 1996 року N 348 ( z0510-96 ), зареєстрованим в Міністерстві юстиції України 10 вересня 1996 року за N 510/1535.

Пункт 1.3 доповнити словами "з обов'язковим залученням представників Держспецмонополії України за їх поданням".

Пункт 2.3 викласти в такій редакції:

"2.3. Підприємство, що має намір атестувати виробництво продукції, здійснює контроль виробів та вхідних матеріалів (при потребі) у власній або сторонній (за договором) випробувальній (вимірювальній) лабораторії, яка акредитована відповідно до вимог статті 32 Закону України "Про метрологію та метрологічну діяльність" ( 113/98-ВР ).

Підпункт 9 пункту 3.4.1 доповнити словами: "(якщо підприємство до моменту проведення атестації проводило виробництво продукції)".

У додатку 1 "Код ОКПО" замінити на "код ЄДРПОУ".

4. Управлінню стандартизації, сертифікації та державного нагляду сировини, товарів народного споживання та харчової продукції (І.Квітко) Державного комітету України по стандартизації, метрології і сертифікації в місячний термін подати цей наказ на державну реєстрацію до Міністерства юстиції України.

5. Контроль за виконанням цього наказу покласти на заступника голови Держстандарту України Є.Верещагу.
