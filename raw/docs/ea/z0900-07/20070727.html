Зареєстровано в Міністерстві юстиції України 7 серпня 2007 р. за N 900/14167

Про внесення змін до наказу Держкомстату від 29.11.2000 N 383

Відповідно до статті 14 Закону України "Про державну статистику" ( 2614-12 ) та з метою подальшого вдосконалення державного статистичного спостереження щодо фінансової діяльності страхових організацій НАКАЗУЮ:

1. Визнати таким, що втратив чинність, з 1 січня 2008 року наказ Державного комітету статистики України від 29.11.2000 N 383 ( z0913-00 ) "Про затвердження форми державної статистичної звітності N 1-СТ та Інструкції щодо її заповнення", зареєстрований у Мін'юсті України 14.12.2000 за N 913/5134, у частині затвердження форми державної статистичної звітності N 1-СТ "Звіт про фінансову діяльність страхової організації".

2. Контроль за виконанням цього наказу покласти на першого заступника Голови Піщейка В.О.

Голова О.Г.Осауленко
