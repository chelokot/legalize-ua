МІНІСТЕРСТВО РЕГІОНАЛЬНОГО РОЗВИТКУ ТА БУДІВНИЦТВА УКРАЇНИ

НАКАЗ

21.11.2008 N 527

Зареєстровано в Міністерстві юстиції України 12 грудня 2008 р. за N 1192/15883

Про визнання деяких наказів такими, що втратили чинність

Відповідно до пункту 8 Положення про Міністерство регіонального розвитку та будівництва України, затвердженого постановою Кабінету Міністрів України від 16.05.2007 N 750 ( 750-2007-п ) "Деякі питання Міністерства регіонального розвитку та будівництва", НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

1.1. Накази Державного комітету України у справах містобудування і архітектури:

від 19.08.94 N 20 ( z0238-94 ) "Про затвердження Типового положення з планування, обліку і калькулювання собівартості будівельно-монтажних робіт", зареєстрований у Міністерстві юстиції України 04.10.94 за N 238/448;

від 04.04.97 N 54 ( z0167-97 ) "Про затвердження Типового положення про розробку та видачу архітектурно-планувальних завдань і технічних умов на проектування об'єктів: нового будівництва, розширення, реконструкції, капітального ремонту та комплексного благоустрою територій", зареєстрований у Міністерстві юстиції України 08.05.97 за N 167/1971.

1.2. Накази Державного комітету будівництва, архітектури та житлової політики України:

від 09.09.98 N 197 ( z0614-98 ) "Про затвердження Правил формування договірних цін та їх уточнення в процесі будівництва", зареєстрований у Міністерстві юстиції України 30.09.98 за N 614/3054;

від 16.09.98 N 206 ( z0632-98 ) "Про затвердження Базових розцінок визначення вартості розроблення архітектурно-планувальних завдань, що надаються забудовникам місцевими органами містобудування та архітектури", зареєстрований у Міністерстві юстиції України 06.10.98 за N 632/3072;

від 18.09.98 N 211 ( z0640-98 ) "Про затвердження Базових розцінок визначення вартості розроблення технічних умов, що видаються забудовникам на проектування об'єктів будівництва, та Методичних вказівок щодо застосування базових розцінок визначення вартості розроблення технічних умов, що видаються забудовникам на проектування об'єктів будівництва", зареєстрований у Міністерстві юстиції України 09.10.98 за N 640/3080;

від 25.05.99 N 125 ( z0384-99 ) "Про затвердження Положення про механізм розгляду документів і надання висновків щодо обґрунтованості причин перевищення термінів, установлених у статтях 1 і 2 Закону України "Про порядок здійснення розрахунків в іноземній валюті", за зовнішньоекономічними договорами (контрактами) з виробничої кооперації, комплексного будівництва та за бартерними договорами", зареєстрований у Міністерстві юстиції України 17.06.99 за N 384/3677;

від 08.10.99 N 247 ( z0705-99 ) "Про затвердження Положення про порядок залучення і використання коштів на фінансування житлового будівництва та додаткове соціальне забезпечення громадян України в рамках експерименту", зареєстрований у Міністерстві юстиції України 15.10.99 за N 705/3998.

2. Контроль за виконанням цього наказу залишаю за собою.
