РОЗПОРЯДЖЕННЯ від 27 червня 2003 р. N 388-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 696 ( 696-2010-п ) від 04.08.2010 }

Про відкриття торговельно-економічної місії у складі Дипломатичного представництва України в Державі Кувейт

Мінекономіки разом з МЗС:

забезпечити у 2003 році відкриття торговельно-економічної місії у складі Дипломатичного представництва України в Державі Кувейт у межах установленої граничної чисельності працівників торговельно-економічних місій у складі дипломатичних представництв України за кордоном і коштів, передбачених у державному бюджеті ( 380-15 ) на функціонування закордонних дипломатичних установ України, а також її розміщення;

вжити заходів для кадрового забезпечення місії, що відкривається згідно з цим розпорядженням.

Перший віце-прем'єр-міністр України М.АЗАРОВ
