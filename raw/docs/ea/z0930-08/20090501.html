Зареєстровано в Міністерстві юстиції України 6 жовтня 2008 р. за N 930/15621

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 317 ( z0340-09 ) від 26.03.2009 }

Про внесення змін до наказу Міністерства транспорту та зв'язку України від 07.07.2008 N 818

Відповідно до розпорядження Кабінету Міністрів України від 30.07.2008 N 1039-р ( 1039-2008-р ) "Про визнання такими, що втратили чинність, пункту 1 розпорядження Кабінету Міністрів України від 8 жовтня 2004 р. N 706 та додатка до нього" НАКАЗУЮ:

1. Унести до пункту 3 наказу Міністерства транспорту та зв'язку України від 07.07.2008 N 818 ( z0667-08 ) "Про встановлення ставок плати за користування вантажними вагонами Укрзалізниці", зареєстрованого в Міністерстві юстиції України 18.07.2008 за N 667/15358, такі зміни:

слова та цифри "пунктів 1 та 2" замінити словом та цифрою "пункту 1", після слів "вантажних вагонів" доповнити словами "та додатка до нього".

2. Державній адміністрації залізничного транспорту України (Мельничук В.О.):

2.1. Довести цей наказ до відома причетних працівників залізниць.

2.2. Подати цей наказ до Міністерства юстиції України на державну реєстрацію в установленому порядку.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Бадагова В.Ф.

Міністр Й.Вінський
