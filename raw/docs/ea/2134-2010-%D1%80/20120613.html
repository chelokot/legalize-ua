Про підписання Угоди між Кабінетом Міністрів України та Урядом Румунії про взаємну охорону інформації з обмеженим доступом

Текст документа від 13.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 листопада 2010 р. N 2134-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 358-р ( 358-2012-р ) від 13.06.2012 }

Про підписання Угоди між Кабінетом Міністрів України та Урядом Румунії про взаємну охорону інформації з обмеженим доступом

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Румунії про взаємну охорону інформації з обмеженим доступом.

Уповноважити заступника Голови Служби безпеки Породька Володимира Михайловича підписати зазначену Угоду.

Прем'єр-міністр України М.АЗАРОВ
