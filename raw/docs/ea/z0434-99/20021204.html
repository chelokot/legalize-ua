Фонд державного майна, Держкомісціннихпаперів, Антимонопольний комітет; Наказ від 18.06.1999 № 1158/161/3

Про обмеження мінімального рівня ціни під час продажу пакетів акцій ВАТ за грошові кошти

Реєстрація: Мін'юст України від 02.07.1999 № 434/3727

Стан: Втратив чинність

Ідентифікатор: z0434-99

Текст документа від 04.12.2002:

ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ АНТИМОНОПОЛЬНИЙ КОМІТЕТ УКРАЇНИ

НАКАЗ

N 1158/161/3 від 18.06.99 Зареєстровано в Міністерстві юстиції України 2 липня 1999 р. за N 434/3727

Про обмеження мінімального рівня ціни під час продажу пакетів акцій ВАТ за грошові кошти

( Із змінами, внесеними згідно з Наказами Фонду державного майна N 1307/193/8 ( z0527-00 ) від 23.06.2000 N 1485 ( z0943-02 ) від 16.08.2002 )

З метою усунення причин і умов порушення закону під час приватизації та керуючись Законом України "Про приватизацію державного майна" ( 2163-12 ), Державною програмою приватизації на 1999 рік ( 1405/98, 209/99 ), НАКАЗУЄМО:

1. Установити мінімальний рівень ціни акцій відкритих акціонерних товариств (далі - ВАТ) під час продажу в ході приватизації за грошові кошти способами, що передбачають конкуренцію покупців, коли пропозиція перевищує попит:

1.1. Щодо ВАТ, статутні фонди яких визначено без урахування індексації основних фондів станом на 01.01.95, то продаж акцій за цінами нижче номінальної їх вартості не проводиться.

1.2. Для ВАТ, що належать до підприємств, які зараховані Державною програмою приватизації до об'єктів групи "Г", зниження ціни акцій нижче їх початкової ціни, встановленої на перших торгах, можливе не більше ніж на 30 відсотків, але не нижче їх номінальної вартості. У випадках, коли на фондових біржах або Першій фондовій торговельній системі продається пакет акцій ВАТ групи "Г", що належать державі, розмір якого менше як 25 відсотків статутного фонду ВАТ плюс одна акція, попиту на які під час їх пропонування до продажу не було, такі обмеження мінімального рівня ціни, встановлені для об'єктів групи "Г", не застосовуються, а застосовуються обмеження, що встановлені пунктами 1.1 та 1.3 цього наказу. ( Пункт 1.2 в редакції Наказів Фонду державного майна N 1307/193/8 ( z0527-00 ) від 23.06.2000, N 1485 ( z0943-02 ) від 16.08.2002 )

( Пункт 1.3 вилучено на підставі Наказу Фонду державного майна N 1307/193/8 ( z0527-00 ) від 23.06.2000 )

1.3. Щодо всіх інших підприємств:

якщо сумарна вартість запропонованого до продажу пакета акцій ВАТ за початковою ціною не перевищує 10000 неоподаткованих мінімумів доходів громадян, то допускається зниження ціни однієї акції до рівня, який не може бути менший за мінімальну номінальну вартість однієї акції, встановлену рішенням Державної комісії з цінних паперів та фондового ринку від 14.05.97 N 6 ( v0006312-97 ) "Про встановлення мінімальної номінальної вартості акції";

в іншому випадку зниження ціни акцій нижче їх початкової вартості можливе не більш ніж на 75%.

2. Дія цього наказу розповсюджується на такі способи продажу:

продаж акцій на фондових біржах;

продаж акцій в Позабіржовій фондовій торговельній системі;

продаж акцій на спеціалізованих аукціонах за грошові кошти в Державній акціонерній компанії "Національна мережа аукціонних центрів";

продаж акцій на відкритих регіональних грошових аукціонах.

3. Департаменту систем продажу акцій (Красовський В.А.) та Департаменту аукціонного продажу і фондових бірж (Яковлєв Ю.В.) Фонду державного майна України привести нормативно-правові документи, що регулюють продаж акцій, у відповідність з вимогами цього наказу, наведеними в пункті 2.

4. Фонду державного майна України забезпечити подання наказу "Про обмеження мінімального рівня ціни під час продажу пакетів акцій ВАТ за грошові кошти" на державну реєстрацію до Міністерства юстиції України.

5. Фонду державного майна України у десятиденний термін з дня державної реєстрації у Міністерстві юстиції України цього наказу забезпечити його опублікування у Державному інформаційному бюлетені "Про приватизацію".

6. Контроль за виконанням цього наказу покласти на Голову Фонду державного майна України О.Бондаря.
