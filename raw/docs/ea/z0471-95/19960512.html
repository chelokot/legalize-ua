НАКАЗ

N 187 від 20.12.95 Зареєстровано в Міністерстві м.Київ юстиції України 21 грудня 1995 р. за N 471/1007

Про нормативи відрахувань за геологорозвідувальні роботи, виконані за рахунок Державного бюджету

( Із змінами, внесеними згідно з Наказами Мінекономіки N 16 ( z0081-96 ) від 02.02.96 N 53 ( z0225-96 ) від 25.04.96 )

На виконання постанови Кабінету Міністрів України від 11 серпня 1995 року N 645 ( 645-95-п ) "Про затвердження Порядку встановлення нормативів відрахувань за геологорозвідувальні роботи, виконані за рахунок Державного бюджету, та їх справляння", НАКАЗУЮ:

1. Затвердити нормативи відрахувань за геологорозвідувальні роботи, виконані за рахунок Державного бюджету (додаються).

2. Вважати такими, що втратили чинність, накази Міністерства економіки України від 20.04.95 р. N 61 ( z0120-95 ) та від 26.05.95 р. N 79 ( z0158-95 ).
