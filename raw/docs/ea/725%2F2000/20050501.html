Текст документа від 01.05.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 625/2005 ( 625/2005 ) від 11.04.2005 )

Про зміни у складі Консультативної ради з питань іноземних інвестицій в Україні

На часткову зміну Указу Президента України від 11 квітня 1997 року N 323 ( 323/97 ) "Про Консультативну раду з питань іноземних інвестицій в Україні" (із змінами, внесеними Указами Президента України від 29 липня 1997 року N 717 ( 717/97 ), від 11 вересня 1997 року N 1006 ( 1006/97 ), від 6 травня 1998 року N 414 ( 414/98 ) та від 21 березня 2000 року N 468 ( 468/2000 ) ввести до складу Консультативної ради з питань іноземних інвестицій в Україні Чарльза ФРЕНКА - першого віце-президента Європейського Банку Реконструкції та Розвитку, Клауді САНТ'ЯГО - голову енергетичної дочірньої компанії "Нуово Піньоне" корпорації "Дженерал електрик" (США), Карла ЙОХАНССОНА - керуючого партнера компанії "Ернст енд Янг" у країнах СНД, Східної Європи та Центральної Азії (США), Герана ЛІНДАЛА - президента "АББ Європа" концерну "АББ" (Швейцарія - Швеція), Норрі СТЕНЛІ - директора відділення Інтернешнл Гез компанії "Бі Пі Амоко" (Великобританія), вивівши зі складу зазначеної Консультативної ради Жака де Ларозьєра, Луччо Луссо, Майкла Хеннінга, Еберхарда фон Кербера, Ієна Л. Рашбі.

Президент України Л.КУЧМА

м. Київ, 29 травня 2000 року N 725/2000
