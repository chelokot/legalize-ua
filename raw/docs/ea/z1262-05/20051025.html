Зареєстровано в Міністерстві юстиції України 25 жовтня 2005 р. за N 1262/11542

Про визнання деяких наказів такими, що втратили чинність

Відповідно до Закону України "Про державну статистику" ( 2614-12 ), з метою приведення нормативно-правових актів у відповідність до чинного законодавства НАКАЗУЮ:

1. Скасувати пункт 9 наказу Державного комітету статистики України від 30.07.2001 N 340 ( v0340202-01 ) "Про затвердження річних та поточних форм державної статистичної звітності щодо промислової діяльності підприємств і організацій".

2. Визнати такими, що втратили чинність:

2.1. Наказ Міністерства статистики України від 12.05.93 N 86 ( z0063-93 ) "Про Зміни і доповнення до Типової інструкції до складання звітів промислових підприємств усіх форм власності по продукції", зареєстрований в Міністерстві юстиції України 08.06.93 за N 63.

2.2. Наказ Міністерства статистики України від 06.09.93 N 198 ( z0130-93 ) "Про Зміни та доповнення до Типової інструкції до складання звітів промислових підприємств усіх форм власності", зареєстрований в Міністерстві юстиції України 10.09.93 за N 130.

2.3. Наказ Міністерства статистики України від 24.11.94 N 254 ( z0290-94 ) "Про внесення змін та доповнень до Типової інструкції до складання звітів промислових підприємств усіх форм власності, затвердженої наказом від 20.07.92 N 123", зареєстрований в Міністерстві юстиції України 05.12.94 за N 290/500.

2.4. Наказ Міністерства статистики України від 22.02.95 N 50 ( z0054-95 ) "Про внесення змін та доповнень до Типової інструкції до складання звітів промислових підприємств усіх форм власності по продукції, затвердженої наказом від 20.07.92 N 123", зареєстрований в Міністерстві юстиції України 06.03.95 за N 54/590.

2.5. Наказ Міністерства статистики України від 03.12.96 N 358 ( z0726-96 ) "Про затвердження Інструкції по складанню статистичного звіту про основні показники діяльності проектно-вишукувальної організації (форма N 4-кб - квартальна, річна)", зареєстрований в Міністерстві юстиції України 19.12.96 за N 726/1751.

2.6. Наказ Міністерства статистики України від 27.11.97 N 61 ( z0582-97 ) "Про внесення змін та доповнень до Типової інструкції до складання звітів промислових підприємств усіх форм власності по продукції, затвердженої наказом Мінстату України від 20.07.92 N 123", зареєстрований в Міністерстві юстиції України 10.12.97 за N 582/2386.

3. Контроль за виконанням цього наказу покласти на першого заступника Голови Головка В.А.

Голова О.Г.Осауленко
