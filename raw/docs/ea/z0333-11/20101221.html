ЗАТВЕРДЖЕНО Наказ Міністерства охорони здоров'я України 21.12.2010 N 1141 ( z0319-11 )

Зареєстровано в Міністерстві юстиції України 14 березня 2011 р. за N 333/19071

ІНСТРУКЦІЯ щодо заповнення форми первинної облікової документації N 498-7/0 "Журнал банку зразків сироваток крові"

1. Інструкція визначає порядок заповнення форми первинної облікової документації N 498-7/0 "Журнал банку зразків сироваток крові" (далі - Журнал).

2. У лівому верхньому куті Журналу зазначають найменування і місцезнаходження закладу, в якому заповнюється форма, та ідентифікаційний код Єдиного державного реєстру підприємств та організацій України (ЄДРПОУ).

3. У графі 1 вказують порядковий номер Журналу. Нумерація Журналу до його закінчення наскрізна.

4. У графі 2 вказують дату надходження зразка в лабораторію для проведення підтверджувальних досліджень.

5. У графі 3 вказують номер зразка відповідно до Журналу реєстрації зразків крові, що надійшли для проведення підтверджувальних досліджень (форма N 498-6/0) ( z0329-11 ).

6. У графі 4 вказують дату знезараження зразка.

7. У графі 5 роблять записи у випадках видачі зразка з лабораторії або в тих випадках, коли зразок використовується для потреб лабораторії.

Голова Комітету з питань протидії ВІЛ-інфекції/СНІДу та іншим соціально небезпечним хворобам С.О.Черенько

Начальник ДЗ "Центр медичної статистики МОЗ" М.В.Голубчиков
