Кабінет Міністрів України; Розпорядження від 21.10.2009 № 1254-р

Про створення галузевого державного архіву Державної служби спеціального зв'язку та захисту інформації

Стан: Чинний

Ідентифікатор: 1254-2009-р

Текст документа від 06.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 жовтня 2009 р. N 1254-р Київ

Про створення галузевого державного архіву Державної служби спеціального зв'язку та захисту інформації

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 187-р ( 187-2010-р ) від 03.02.2010 N 275-р ( 275-2011-р ) від 06.04.2011 }

1. Створити галузевий державний архів Державної служби спеціального зв'язку та захисту інформації у межах граничної чисельності особового складу зазначеної Служби для зберігання документів і матеріалів, що утворюються в процесі службової діяльності Держспецзв'язку.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженнями КМ N 187-р ( 187-2010-р ) від 03.02.2010, N 275-р ( 275-2011-р ) від 06.04.2011 }

2. Держкомархіву і Держспецзв'язку у тримісячний строк розробити та затвердити Положення про галузевий державний архів Державної служби спеціального зв'язку та захисту інформації.

3. Держспецзв'язку забезпечити створений згідно з пунктом 1 цього розпорядження архів приміщеннями, технологічним обладнанням, матеріальними і фінансовими ресурсами та вжити заходів до кадрового укомплектування архіву в межах видатків, передбачених для Держспецзв'язку у Державному бюджеті України на 2009 рік ( 835-17 ).

Прем'єр-міністр України Ю.ТИМОШЕНКО
