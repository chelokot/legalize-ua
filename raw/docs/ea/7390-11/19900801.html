Про затвердження форми нагородного листа для представлення до нагородження державними нагородами Української РСР

Стан: Втратив чинність

Текст документа від 01.08.1990:

ПОСТАНОВА ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

( Постанова втратила чинність на підставі Постанови Президії ВР УРСР

N 109-XII ( 109-12 ) від 01.08.90, ВВР, 1990, N 33, ст.489 )

Про затвердження форми нагородного листа для представлення до нагородження державними нагородами Української РСР

( Відомості Верховної Ради УРСР (ВВР), 1989, N 18, ст. 165 )

Президія Верховної Ради Української РСР постановляє:

1. Затвердити форму нагородного листа для представлення до нагородження державними нагородами Української РСР (додається).

2. Визнати такою, що втратила чинність, постанову Президії Верховної Ради УРСР від 3 жовтня 1980 року "Про нагородний лист по нагородженню Почесною Грамотою, Грамотою Президії Верховної Ради Української РСР, присвоєнню почесних звань Української РСР".
