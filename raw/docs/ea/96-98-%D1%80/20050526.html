Кабінет Міністрів України; Розпорядження від 18.02.1998 № 96-р

Про розміщення Головного обчислювального центру Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування

Стан: Втратив чинність

Ідентифікатор: 96-98-р

Текст документа від 26.05.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 лютого 1998 р. N 96-р Київ

Про розміщення Головного обчислювального центру Єдиної державної автоматизованої паспортної системи

( Із змінами, внесеними згідно з Розпорядженнями КМ N 165-р ( 165-2002-р ) від 29.03.2002 N 935-р ( 935-2004-р ) від 23.12.2004 Постановою КМ N 378 ( 378-2005-п ) від 26.05.2005 )

Прийняти пропозицію Національного агентства з питань інформатизації при Президентові України, погоджену з МВС, Мін'юстом та Держкомсекретів, щодо розміщення на період до 2006 року Головного обчислювального центру Єдиної державної автоматизованої паспортної системи на засадах відшкодування експлуатаційних витрат у будинку по вул. Ф.Пушиної, 30/32 у м. Києві, який належить відкритому акціонерному товариству "КП ОТІ" - головному виконавцеві робіт зі створення цієї системи.

( Розпорядження із змінами, внесеними згідно з Розпорядженнями КМ N 165-р ( 165-2002-р ) від 29.03.2002, N 935-р ( 935-2004-р ) від 23.12.2004, Постановою КМ N 378 ( 378-2005-п ) від 26.05.2005 )
