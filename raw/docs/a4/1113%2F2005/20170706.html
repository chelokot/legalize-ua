Текст документа від 06.07.2017:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про підготовку та участь спортсменів України в Олімпійських,

Паралімпійських і Дефлімпійських іграх, Всесвітніх іграх з неолімпійських видів спорту, Всесвітніх іграх з єдиноборств, Всесвітніх Універсіадах, чемпіонатах світу та Європи

{ Назва Указу в редакції Указу Президента N 174/2017 ( 174/2017 ) від 04.07.2017 }

{ Із змінами, внесеними згідно з Указами Президента N 1553/2005 ( 1553/2005 ) від 07.11.2005 N 517/2009 ( 517/2009 ) від 08.07.2009 N 174/2017 ( 174/2017 ) від 04.07.2017 }

З метою дальшого розвитку олімпійського, паралімпійського, дефлімпійського руху, неолімпійських видів спорту та спорту студентської молоді, створення необхідних умов для підготовки та участі збірних команд України в Олімпійських, Паралімпійських і Дефлімпійських іграх, Всесвітніх іграх з неолімпійських видів спорту, Всесвітніх іграх з єдиноборств, Всесвітніх Універсіадах, чемпіонатах світу та Європи постановляю:

{ Преамбула із змінами, внесеними згідно з Указом Президента N 174/2017 ( 174/2017 ) від 04.07.2017 }

1. Утворити Організаційний комітет з підготовки та участі спортсменів України в Олімпійських, Паралімпійських і Дефлімпійських іграх, Всесвітніх іграх з неолімпійських видів спорту, Всесвітніх іграх з єдиноборств, Всесвітніх Універсіадах, чемпіонатах світу та Європи (далі - Організаційний комітет). { Абзац перший статті 1 із змінами, внесеними згідно з Указом Президента N 174/2017 ( 174/2017 ) від 04.07.2017 }

Установити, що головою Організаційного комітету є Прем'єр-міністр України, який формує та затверджує його персональний склад.

{ Стаття 1 в редакції Указу Президента N 1553/2005 ( 1553/2005 ) від 07.11.2005 }

2. Кабінету Міністрів України:

забезпечити в установленому порядку фінансування витрат з підготовки та участі спортсменів України в Олімпійських, Паралімпійських і Дефлімпійських іграх, Всесвітніх іграх з неолімпійських видів спорту, Всесвітніх іграх з єдиноборств, Всесвітніх Універсіадах, чемпіонатах світу та Європи (далі - ігри, Універсіади і чемпіонати) і проведення всеукраїнських спортивних заходів; { Абзац другий статті 2 із змінами, внесеними згідно з Указом Президента N 174/2017 ( 174/2017 ) від 04.07.2017 }

забезпечити в установленому порядку фінансову підтримку баз олімпійської, паралімпійської підготовки;

сприяти залученню в установленому порядку позабюджетних коштів для підготовки та участі спортсменів України в іграх, Універсіадах та чемпіонатах;

сприяти розвитку та ефективному функціонуванню системи підготовки спортсменів вищої кваліфікації та олімпійського резерву (дитячо-юнацьких спортивних шкіл, спеціалізованих дитячо-юнацьких шкіл олімпійського резерву, училищ олімпійського резерву, шкіл вищої спортивної майстерності, училищ фізичної культури, штатних збірних команд, дитячо-юнацьких спортивних шкіл інвалідів, фізкультурно-спортивних товариств);

сприяти розвитку Національного центру параолімпійської і дефлімпійської підготовки та реабілітації інвалідів; { Абзац шостий статті 2 із змінами, внесеними згідно з Указом Президента N 517/2009 ( 517/2009 ) від 08.07.2009 }

вжити заходів до вдосконалення системи науково-методичного та медико-біологічного забезпечення збірних команд України;

забезпечити висвітлення у засобах масової інформації підготовки та участі спортсменів України в іграх, Універсіадах і чемпіонатах.

3. Покласти на Міністерство молоді та спорту України відповідальність за організаційне і кадрове забезпечення підготовки та участі спортсменів України в іграх, Універсіадах і чемпіонатах.

{ Стаття 3 із змінами, внесеними згідно з Указом Президента N 174/2017 ( 174/2017 ) від 04.07.2017 }

4. Голові Організаційного комітету інформувати Президента України щороку до 1 січня про хід підготовки спортсменів України до ігор, Універсіад і чемпіонатів, а також в місячний строк після їх закінчення про досягнуті результати.

5. Визнати такими, що втратили чинність:

Указ Президента України від 25 червня 2001 року N 470 ( 470/2001 ) "Про підготовку та участь спортсменів України в Олімпійських і Параолімпійських іграх, Всесвітніх іграх глухих, Всесвітніх Універсіадах, чемпіонатах світу та Європи";

Указ Президента України від 30 листопада 2002 року N 1110 ( 1110/2002 ) "Про внесення змін до Указу Президента України від 25 червня 2001 року N 470".
