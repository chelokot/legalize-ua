Про проведення публічного громадського обговорення системних соціально-економічних реформ

Стан: Чинний

Ідентифікатор: 2311-2010-р

Текст документа від 11.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 грудня 2010 р. N 2311-р Київ

Про проведення публічного громадського обговорення системних соціально-економічних реформ

{ Із змінами, внесеними згідно з Постановами КМ N 944 ( 944-2011-п ) від 07.09.2011 N 491 ( 491-2012-п ) від 31.05.2012 }

1. З метою врахування громадської думки та підвищення рівня обізнаності громадян про системні соціально-економічні реформи центральним органам виконавчої влади згідно з компетенцією забезпечити:

проведення за участю фізичних осіб, у тому числі фізичних осіб - підприємців, представників громадських організацій, професійних спілок та їх об'єднань, організацій роботодавців, юридичних осіб, науковців, експертів публічного громадського обговорення (засідань за круглим столом, громадських слухань, зустрічей з громадськістю, конференцій) зазначених реформ;

надання в засобах масової інформації, на веб-сайтах органів виконавчої влади відповідних роз'яснень.

2. Центральним органам виконавчої влади згідно з компетенцією:

затвердити у двотижневий строк відповідні плани заходів;

забезпечити оприлюднення на власних веб-сайтах відповідних актів законодавства, проведення аналізу пропозицій і зауважень, що надійшли під час публічного громадського обговорення системних соціально-економічних реформ, та їх врахування в процесі доопрацювання проектів таких актів.

3. Персональну відповідальність за виконання цього розпорядження покласти на Віце-прем’єр-міністра України - Міністра соціальної політики Тігіпка С.Л., Міністра економічного розвитку і торгівлі Порошенка П.О.

{ Пункт 3 із змінами, внесеними згідно з Постановами КМ N 944 ( 944-2011-п ) від 07.09.2011, N 491 ( 491-2012-п ) від 31.05.2012 }

4. Віце-прем’єр-міністрові України - Міністрові соціальної політики, Міністрові економічного розвитку і торгівлі доповідати щомісяця на засіданні Кабінету Міністрів України про хід виконання цього розпорядження.

{ Пункт 4 із змінами, внесеними згідно з Постановами КМ N 944 ( 944-2011-п ) від 07.09.2011, N 491 ( 491-2012-п ) від 31.05.2012 }
