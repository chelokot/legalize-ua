КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 червня 2010 р. N 1253-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 401-р ( 401-2017-р ) від 14.06.2017 }

Про внесення змін до розпорядження Кабінету Міністрів України від 10 квітня 2008 р. N 610

В абзаці другому розпорядження Кабінету Міністрів України від 10 квітня 2008 р. N 610 ( 610-2008-р ) "Деякі питання розпорядження земельними лісовими ділянками" (Офіційний вісник України, 2008 р., N 31, ст. 1001; 2009 р., N 42, ст. 1417, N 56, ст. 1959; 2010 р., N 5, ст. 211, ст. 212, N 9, ст. 465) слова "видобутку торфу" замінити словами "видобування торфу та розробки родовищ горючих сланців", а після слів "за рішенням Кабінету Міністрів України," доповнити словами "для видобування кварцових та кварцитоподібних пісковиків загальнодержавного значення із родовищ, що включені до Державного фонду родовищ корисних копалин,".

Прем'єр-міністр України М.АЗАРОВ
