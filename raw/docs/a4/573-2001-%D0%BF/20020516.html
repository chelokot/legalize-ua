Про внесення змін до постанови Кабінету Міністрів України від 8 січня 2000 р. N 13

Стан: Втратив чинність

Ідентифікатор: 573-2001-п

Текст документа від 16.05.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 травня 2001 р. N 573 Київ

( Постанова втратила чинність на підставі Постанови КМ N 622 ( 622-2002-п ) від 16.05.2002 )

Про внесення змін до постанови Кабінету Міністрів України від 8 січня 2000 р. N 13

На виконання статті 15 Закону України "Про наукову і науково-технічну діяльність" ( 1977-12 ) Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 8 січня 2000 р. N 13 ( 13-2000-п ) "Про вдосконалення системи головних розпорядників коштів державного бюджету" (Офіційний вісник України, 2000 р., N 2, ст. 36, N 6, ст. 225, N 7, ст. 274, N 12, ст. 468, N 18, ст. 739, N 20, ст. 820, N 23, ст. 940, N 31, ст. 1316, N 36, ст. 1530, N 45, ст. 1925) такі зміни:

доповнити перелік головних розпорядників коштів державного бюджету, затверджений зазначеною постановою, словами "Українська академія аграрних наук" та "Академія медичних наук";

у схемі підпорядкування розпорядників коштів державного бюджету нижчого рівня та їх одержувачів головним розпорядникам цих коштів, затвердженій зазначеною постановою, виключити:

у позиції "Міністерство аграрної політики" слова "Українська академія аграрних наук";

у позиції "Міністерство охорони здоров'я" слова "Академія медичних наук".

Прем'єр-міністр України В.ЮЩЕНКО
