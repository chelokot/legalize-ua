МІНІСТЕРСТВО ЕКОНОМІКИ УКРАЇНИ

НАКАЗ

17.04.2006 N 139

Зареєстровано в Міністерстві юстиції України 5 травня 2006 р. за N 525/12399

Про визнання такими, що втратили чинність, деяких наказів Міністерства економіки України, Міністерства економіки та з питань європейської інтеграції України

Відповідно до Закону України від 15.12.2005 N 3205-IV ( 3205-15 ) "Про внесення змін до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" та інших законодавчих актів України" та на виконання пункту 4 доручення Кабінету Міністрів України від 21.03.2006 N 10224/1/1-06 НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

1.1. Накази Міністерства економіки України:

від 04.12.2000 N 264 ( z0919-00 ) "Про затвердження Порядку розгляду скарг скаржників процедур державних закупівель щодо організації та здійснення процедур закупівель товарів, робіт і послуг за державні кошти", зареєстрований у Міністерстві юстиції України 18.12.2000 за N 919/5140 (із змінами);

від 07.12.2000 N 268 ( z0933-00 ) "Про порядок погодження Міністерством економіки України застосування замовниками окремих процедур державних закупівель", зареєстрований у Міністерстві юстиції України 21.12.2000 за N 933/5154 (із змінами);

від 26.12.2000 N 280 ( z0020-01 ) "Про затвердження Положення про порядок створення та головні функції тендерних комітетів щодо організації та здійснення процедур закупівель товарів, робіт і послуг за державні кошти", зареєстрований у Міністерстві юстиції України 16.01.2001 за N 20/5211 (із змінами).

1.2. Накази Міністерства економіки та з питань європейської інтеграції України:

від 06.08.2002 N 238 ( z0672-02 ) "Про організацію роботи щодо контролю за додержанням чинного законодавства при здійсненні закупівель товарів, робіт і послуг за державні кошти", зареєстрований у Міністерстві юстиції України 16.08.2002 за N 672/6960 (із змінами);

від 20.05.2003 N 128 ( z0438-03 ) "Про затвердження Порядку приймання та публікування оголошень щодо державних закупівель в інформаційно-аналітичному бюлетені "Вісник державних закупівель", зареєстрований в Міністерстві юстиції України 04.06.2003 за N 438/7759 (із змінами);

від 20.05.2003 N 129 ( z0447-03 ) "Про затвердження форм звітів про результати здійснення процедур закупівель товарів, робіт і послуг за державні кошти та інструкцій щодо їх заповнення", зареєстрований в Міністерстві юстиції України 06.06.2003 за N 447/7768 (із змінами);

від 20.05.2003 N 130 ( z0427-03 ) "Про затвердження форм оголошень стосовно державних закупівель та інструкцій щодо їх заповнення", зареєстрований у Міністерстві юстиції України 03.06.2003 за N 427/7748 (із змінами);

від 27.06.2003 N 165 ( z0566-03 ) "Про порядок визначення предмета закупівлі за державні кошти", зареєстрований у Міністерстві юстиції України 09.07.2003 за N 566/7887 (із змінами);

від 18.07.2003 N 193 ( z0672-03 ) "Про вдосконалення роботи з організації навчання та підвищення кваліфікації спеціалістів з питань здійснення процедури закупівлі товарів, робіт і послуг за державні кошти", зареєстрований у Міністерстві юстиції України 04.08.2003 за N 672/7993 (із змінами).
