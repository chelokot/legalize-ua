Про затвердження складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду соціального страхування від нещасних випадків на виробництві та професійних захворювань

Стан: Втратив чинність

Ідентифікатор: 120-2005-р

Текст документа від 15.09.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 квітня 2005 р. N 120-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 488-р ( 488-2006-р ) від 15.09.2006 }

Про затвердження складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду соціального страхування від нещасних випадків на виробництві та професійних захворювань

{ Із змінами, внесеними згідно з Розпорядженням КМ N 252-р ( 252-2006-р ) від 27.04.2006 }

1. Затвердити склад осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду соціального страхування від нещасних випадків на виробництві та професійних захворювань, згідно з додатком.

2. Визнати таким, що втратив чинність, пункт 1 постанови Кабінету Міністрів України від 10 грудня 2003 р. N 1901 ( 1901-2003-п ) "Про затвердження складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів загальнообов'язкового державного соціального страхування" (Офіційний вісник України, 2003 р., N 51, ст. 2677).
