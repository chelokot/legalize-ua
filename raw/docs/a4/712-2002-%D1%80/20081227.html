{ Розпорядження скасовано на підставі Розпорядження КМ N 1608-р ( 1608-2008-р ) від 27.12.2008 }

Про придбання нерухомого майна для розміщення Посольства України в Союзній Республіці Югославія

Погодитися з пропозицією МЗС про придбання у державну власність України нерухомого майна в м. Бєлграді (Союзна Республіка Югославія) вартістю 2,2 млн. доларів США для розміщення Посольства України в Союзній Республіці Югославія.

Мінфіну профінансувати витрати на придбання зазначеного нерухомого майна у сумі 700 тис. доларів США - у грудні поточного року за рахунок коштів, передбачених для МЗС у Державному бюджеті України на 2002 рік ( 2905-14 ) на розширення мережі власності України за кордоном у вигляді нерухомого майна для потреб дипломатичних установ України, та у сумі 1500 тис. доларів США - у першому півріччі наступного року за рахунок коштів, що будуть передбачені для МЗС у Державному бюджеті України на 2003 рік на зазначені цілі.

Прем'єр-міністр України В.ЯНУКОВИЧ
