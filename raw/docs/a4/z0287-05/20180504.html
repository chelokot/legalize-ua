Про затвердження Порядку подання документів, що підтверджують цільове використання коштів фінансової підтримки, наданої фермерським господарствам

{ Із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 135 ( z0526-06 ) від 20.03.2006 }

{ У назві та тексті Наказу слова "новоствореним фермерським господарствам та фермерським господарствам з відокремленими садибами" у всіх відмінках замінено словами "фермерським господарствам" у відповідному відмінку згідно з Наказом Міністерства аграрної політики N 135 ( z0526-06 ) від 20.03.2006 }

На виконання пункту 10 Порядку використання коштів державного бюджету для надання підтримки фермерським господарствам, затвердженого постановою Кабінету Міністрів України від 25 серпня 2004 року N 1102 ( 1102-2004-п ), НАКАЗУЮ:

1. Затвердити Порядок подання документів, що підтверджують цільове використання коштів фінансової підтримки, наданої фермерським господарствам, що додається.

2. Департаменту розвитку сільської місцевості та підприємництва (Антипенко В.І.) в установленому порядку:

2.1. Подати цей наказ на державну реєстрацію до Міністерства юстиції України.

2.2. Довести наказ до відома структурних підрозділів Міністерства аграрної політики України, Міністерства агропромислового комплексу Автономної Республіки Крим, головних управлінь сільського господарства і продовольства обласних державних адміністрацій, Головного управління промисловості та сільського господарства Севастопольської міської державної адміністрації, Українського державного фонду підтримки фермерських господарств та його регіональних відділень.

3. Контроль за виконанням наказу покласти на заступника Міністра аграрної політики України Яковенка В.П.

ЗАТВЕРДЖЕНО Наказ Міністерства аграрної політики України 23.02.2005 N 76

Зареєстровано в Міністерстві юстиції України 4 березня 2005 р. за N 287/10567

ПОРЯДОК подання документів, що підтверджують цільове використання коштів фінансової підтримки, наданої фермерським господарствам

{ У назві та тексті Порядку слова "новоствореним фермерським господарствам та фермерським господарствам з відокремленими садибами" у всіх відмінках замінено словами "фермерським господарствам" у відповідному відмінку згідно з Наказом Міністерства аграрної політики N 135 ( z0526-06 ) від 20.03.2006 }

1. Цей Порядок визначає процедуру подання документів, що підтверджують цільове використання коштів фінансової підтримки, наданих через Український державний фонд підтримки фермерських господарств (далі - Фонд), його регіональні відділення фермерським господарствам (далі - фермерські господарства) на конкурсних засадах на поворотній основі.

2. Фінансова підтримка на поворотній основі надається у розмірі, що не перевищує 100 тис. гривень, на конкурсних засадах із забезпеченням виконання зобов'язання щодо повернення коштів:

новоствореним фермерським господарствам та фермерським господарствам з відокремленими садибами - строком від трьох до п'яти років для виробництва, переробки і збуту виробленої продукції, провадження виробничої діяльності;

іншим фермерським господарствам - строком до п'яти років для придбання техніки, обладнання, поновлення обігових коштів, виробництва та переробки сільськогосподарської продукції, будівництва та реконструкції виробничих і невиробничих приміщень, у тому числі житлових (загальною площею не більш як 125 кв. метрів), для закладення багаторічних насаджень, розвитку кредитної та обслуговуючої кооперації, зрошення та меліорації земель.

Фонд, його регіональні відділення укладають з фермерськими господарствами - переможцями конкурсу договір про надання фінансової підтримки на поворотній основі, в якому зазначаються цілі використання коштів фінансової підтримки.

{ Пункт 2 в редакції Наказу Міністерства аграрної політики N 135 ( z0526-06 ) від 20.03.2006 }

3. Фермерське господарство в місячний термін після отримання фінансової підтримки на поворотній основі подає до Фонду, його регіонального відділення документи, які підтверджують цільове використання зазначених коштів.

4. До Фонду, його регіонального відділення подаються копії документів, що підтверджують цільове використання коштів фінансової підтримки:

рахунок-фактура та (або) договір на виконання підрядних робіт, акт виконаних робіт, видаткова накладна та ін.;

документ, який підтверджує здійснення платежів (платіжне доручення, видатковий касовий ордер та ін.).

5. Копії поданих документів повинні бути завірені підписом голови фермерського господарства та скріплені печаткою фермерського господарства.

6. Голова фермерського господарства несе відповідальність за достовірність наданих документів про цільове використання отриманих коштів.

7. Фонд щомісяця до 10 числа наступного періоду надсилає Міністерству аграрної політики України звіт про використання фінансової підтримки, наданої фермерським господарствам на конкурсних засадах на поворотній основі.

Мінагрополітики аналізує ефективність використання бюджетних коштів і подає звіт Мінфіну до 15 числа зазначеного періоду.

{ Пункт 7 в редакції Наказу Міністерства аграрної політики N 135 ( z0526-06 ) від 20.03.2006 }
