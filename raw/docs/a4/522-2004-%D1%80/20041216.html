1. Затвердити план заходів, спрямованих на забезпечення виконання Послання Президента України до Верховної Ради України "Про внутрішнє і зовнішнє становище України у 2003 році" ( n0001100-04, n0002100-04, n0003100-04 ) та Програми діяльності Кабінету Міністрів України "Послідовність. Ефективність. Відповідальність" ( n0002120-04 ) у 2004 році, що додається.

2. Керівникам центральних органів виконавчої влади, Голові Ради міністрів Автономної Республіки Крим, головам обласних, Київської та Севастопольської міських держадміністрацій забезпечити безумовне виконання Послання Президента України до Верховної Ради України "Про внутрішнє і зовнішнє становище України у 2003 році" ( n0001100-04, n0002100-04, n0003100-04 ) та Програми діяльності Кабінету Міністрів України "Послідовність. Ефективність. Відповідальність" ( n0002120-04 ), розробити та затвердити плани відповідних заходів.

3. Керівникам центральних органів виконавчої влади забезпечити щомісячне оприлюднення в газеті "Урядовий кур'єр", інших засобах масової інформації та розміщення на офіційних веб-сайтах звіту про стан виконання Програми діяльності Кабінету Міністрів України ( n0002120-04 ) у відповідних галузях економіки і соціальній сфері.

4. Центральним органам виконавчої влади щокварталу до 10 числа наступного місяця надсилати інформацію Мінекономіки про стан виконання завдань Програми діяльності Кабінету Міністрів України ( n0002120-04 ) для подання узагальнених матеріалів Кабінетові Міністрів України до 20 числа зазначеного місяця та її використання під час підготовки щоквартальної доповіді про роботу Кабінету Міністрів України згідно з розпорядженням Кабінету Міністрів України від 11 червня 2003 р. N 352 ( 352-2003-р ) (Офіційний вісник України, 2003 р., N 25, ст. 1210).

5. Інформацію про стан виконання Програми діяльності Кабінету Міністрів України ( n0002120-04 ) в першому півріччі ц. р. та постанови Кабінету Міністрів від 11 березня 2004 р. N 315 ( 315-2004-п ) "Про підсумки соціально-економічного розвитку України у 2003 році та хід виконання Програми діяльності Кабінету Міністрів України" заслухати на засіданні Кабінету Міністрів України у серпні поточного року.

6. Визнати такими, що втратили чинність, пункти 3 і 4 розпорядження Кабінету Міністрів України від 11 червня 2003 р. N 327 ( 327-2003-р ) "Про забезпечення виконання Програми діяльності Кабінету Міністрів України" (Офіційний вісник України, 2003 р., N 24, ст. 1137).
