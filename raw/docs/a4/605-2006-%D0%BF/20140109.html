Деякі питання діяльності Національної акціонерної компанії "Нафтогаз України"

Стан: Чинний

Ідентифікатор: 605-2006-п

Текст документа від 09.01.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 квітня 2006 р. N 605 Київ

Деякі питання діяльності Національної акціонерної компанії "Нафтогаз України"

{ Із змінами, внесеними згідно з Постановами КМ N 1697 ( 1697-2006-п ) від 08.12.2006 N 338 ( 338-2007-п ) від 01.03.2007 N 1401 ( 1401-2007-п ) від 19.12.2007 N 346 ( 346-2008-п ) від 09.04.2008 N 585 ( 585-2008-п ) від 25.06.2008 N 938 ( 938-2008-п ) від 25.10.2008 N 998 ( 998-2008-п ) від 30.10.2008 N 36 ( 36-2009-п ) від 28.01.2009 N 951 ( 951-2013-п ) від 30.12.2013 }

Кабінет Міністрів України постановляє:

1. Установлені Національною комісією, що здійснює державне регулювання у сфері енергетики, граничні (максимальні) рівні цін на природний газ, що реалізується установам та організаціям, які фінансуються з державного і місцевих бюджетів, промисловим споживачам та іншим суб’єктам господарювання, можуть коригуватися Комісією в наступному місяці реалізації природного газу Національною акціонерною компанією "Нафтогаз України" в разі зміни середньомісячного курсу гривні до долара США, установленого Національним банком України у місяці реалізації природного газу, до офіційного курсу гривні до долара США, установленого Національним банком України у попередньому місяці, та/або в разі зміни середньозваженої ціни імпортованого природного газу, що закуповується Національною акціонерною компанією "Нафтогаз України" для формування ресурсу природного газу, що використовується для задоволення потреб споживачів України.

{ Пункт 1 в редакції Постанов КМ N 1697 ( 1697-2006-п ) від 08.12.2006, N 36 ( 36-2009-п ) від 28.01.2009, N 951 ( 951-2013-п ) від 30.12.2013 }

1-1. Установити граничні рівні цін на природний газ для суб'єктів господарювання, які виробляють теплову енергію, у тому числі блочних (модульних) котелень, установлених на дахові та прибудованих (виходячи з обсягу природного газу, що використовується для виробництва та надання населенню послуг з опалення та гарячого водопостачання, за умови ведення такими суб'єктами окремого приладового та бухгалтерського обліку тепла і гарячої води), з урахуванням податку на додану вартість, збору до затвердженого тарифу на природний газ у вигляді цільової надбавки, тарифів на його транспортування, розподіл і постачання та витрат із зберігання за умови компенсації Національній акціонерній компанії "Нафтогаз України" з державного бюджету різниці в цінах на природний газ (гривень за 1 тис. куб. метрів):

з 1 червня - 710,01;

з 1 липня - 734,86;

з 1 серпня - 760,58;

з 1 вересня - 787,20;

з 1 жовтня - 814,75;

з 1 листопада - 843,27;

з 1 грудня - 872,78.

{ Постанову доповнено пунктом 1-1 згідно з Постановою КМ N 346 ( 346-2008-п ) від 09.04.2008 }

2. Національній акціонерній компанії "Нафтогаз України" та її дочірнім компаніям і підприємствам: { Абзац перший пункту 2 в редакції Постанови КМ N 346 ( 346-2008-п ) від 09.04.2008 }

дозволити залучати за погодженням з Мінфіном та Мінпаливенерго кредити іноземних фінансових установ; { Абзац другий пункту 2 в редакції Постанови КМ N 346 ( 346-2008-п ) від 09.04.2008 }

погоджувати проекти договорів щодо залучення кредитів іноземних фінансових установ з Міністерством палива та енергетики, Міністерством фінансів та Міністерством економіки.

3. Міністерству палива та енергетики, Міністерству фінансів, Міністерству економіки, Національній акціонерній компанії "Нафтогаз України" доопрацювати та до 15 травня 2006 р. подати Кабінетові Міністрів України проекти постанов щодо затвердження на 2006 рік основних показників консолідованого фінансового плану Компанії, консолідованого фінансового плану Компанії, а також фінансових та інвестиційних планів апарату Компанії, її дочірніх компаній та підприємств і господарських товариств, контрольні пакети акцій яких передані до статутного фонду Компанії.

4. Національній акціонерній компанії "Нафтогаз України", її дочірнім компаніям та підприємствам і господарським товариствам, контрольні пакети акцій яких передані до статутного фонду Компанії, до затвердження Кабінетом Міністрів України фінансових планів на 2006 рік:

здійснювати видатки в обсязі, що не перевищує плановий за відповідний період 2005 року, за винятком видатків, пов'язаних з розрахунками за природний газ, включаючи газ, який буде закачуватися до підземних сховищ, із сплатою податків та виконанням зобов'язань за кредитними угодами;

не розпочинати будівництво нових об'єктів невиробничої сфери;

не вносити кошти до статутних фондів підприємств і господарських товариств, крім її дочірніх компаній та підприємств;

не надавати благодійну допомогу та не здійснювати внески на користь неприбуткових організацій.

5. Міністерству палива та енергетики разом з Міністерством економіки, Міністерством фінансів, Фондом державного майна та Національною акціонерною компанією "Нафтогаз України" провести до 1 липня 2006 р. організаційну роботу з продажу на відкритих аукціонах:

1) об'єктів соціально-культурного призначення, які є власністю Національної акціонерної компанії "Нафтогаз України", її дочірніх компаній та підприємств і господарських товариств, контрольні пакети акцій яких передані до статутного фонду Компанії;

2) пакетів акцій акціонерних товариств, які є власністю Національної акціонерної компанії "Нафтогаз України" (крім акціонерних товариств, що провадять діяльність з видобування, транспортування, постачання, переробки природного газу і нафти), якщо розмір такого пакету менший ніж 50 відсотків статутного фонду товариства.

6. Міністерству палива та енергетики, Національній акціонерній компанії "Нафтогаз України" підготувати пропозиції щодо переходу до здійснення споживачами 100-відсоткової передоплати за природний газ.

7. Міністерству праці та соціальної політики, Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям:

забезпечити проведення перерахунків субсидій для відшкодування витрат на оплату житлово-комунальних послуг у строки та в порядку, встановлених законодавством;

з метою своєчасного призначення та надання населенню субсидій для відшкодування витрат на оплату житлово-комунальних послуг забезпечити щоденно в зручний для населення час прийом громадян з цього питання.

8. Рекомендувати Національній комісії регулювання електроенергетики затвердити в установленому законодавством порядку з 1 липня 2008 року:

тарифи на послуги з розподілу і постачання природного газу, які забезпечуватимуть відшкодування закупівельної вартості імпортованого природного газу, що використовується на технологічні нормовані витрати/втрати та рівня середньої заробітної плати працівників відповідно до вимог галузевої угоди між Національною акціонерною компанією "Нафтогаз України" та профспілки працівників газових господарств України на 2007-2009 роки.
