{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) Міністерству освіти і науки за програмою "Видання, придбання, зберігання і доставка підручників і посібників для студентів вищих навчальних закладів, учнів загальноосвітніх і професійно-технічних навчальних закладів та вихованців дошкільних навчальних закладів", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 379 ( 379-2008-п ) від 17.04.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) на видання, придбання, зберігання та доставку підручників і посібників для студентів вищих навчальних закладів, учнів загальноосвітніх і професійно-технічних навчальних закладів та вихованців дошкільних навчальних закладів, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 березня 2007 р. N 547

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) на видання, придбання, зберігання та доставку підручників і посібників для студентів вищих навчальних закладів, учнів загальноосвітніх і професійно-технічних навчальних закладів та вихованців дошкільних навчальних закладів

{ У тексті Порядку слова "державний контракт" у всіх відмінках замінено словами "договір про закупівлю" у відповідному відмінку згідно з Постановою КМ N 379 ( 379-2008-п ) від 17.04.2008 }

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених МОН у загальному фонді державного бюджету ( 489-16 ) за державною програмою "Видання, придбання, зберігання і доставка підручників і посібників для студентів вищих навчальних закладів, учнів загальноосвітніх і професійно-технічних навчальних закладів та вихованців дошкільних навчальних закладів" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є МОН.

3. Бюджетні кошти спрямовуються на:

видання, придбання, зберігання підручників і посібників, у тому числі серії "Шкільна бібліотека", для забезпечення студентів вищих навчальних закладів, учнів загальноосвітніх і професійно-технічних навчальних закладів та вихованців дошкільних навчальних закладів;

проведення Всеукраїнського конкурсу рукописів підручників для загальноосвітніх навчальних закладів;

доставку підручників і посібників Міністерству освіти і науки Автономної Республіки Крим, головним управлінням (управлінням) освіти і науки обласних, Київської та Севастопольської міських держадміністрацій, вищим навчальним закладам, формування та зберігання МОН резерву підручників і посібників.

4. Бюджетні кошти використовуються МОН у межах відповідних бюджетних призначень згідно із затвердженим ним переліком підручників і посібників для дошкільних, загальноосвітніх, професійно-технічних та вищих навчальних закладів з урахуванням:

заявок, що подані Міністерством освіти і науки Автономної Республіки Крим, головними управліннями (управліннями) освіти і науки обласних, Київської та Севастопольської міських держадміністрацій, вищими навчальними закладами;

необхідності першочергового забезпечення підручниками і посібниками учнів загальноосвітніх навчальних закладів, а також виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державного казначейства, у разі їх відповідності паспорту бюджетної програми.

4-1. Потреба у забезпеченні підручниками і посібниками учнів загальноосвітніх навчальних закладів для дітей, які потребують корекції фізичного та (або) розумового розвитку, та учнів, які навчаються мовами національних меншин, визначається відповідно до кількості таких учнів.

{ Порядок доповнено пунктом 4-1 згідно з Постановою КМ N 379 ( 379-2008-п ) від 17.04.2008 }

4-2. Спрямування бюджетних коштів на видання та придбання підручників і посібників, яким МОН не надало відповідний гриф, забороняється.

{ Порядок доповнено пунктом 4-2 згідно з Постановою КМ N 379 ( 379-2008-п ) від 17.04.2008 }

5. Розподіл підручників і посібників між адміністративно-територіальними одиницями здійснюється в межах бюджетних призначень, передбачених у додатку 5 до розділу I Закону України "Про Державний бюджет України на 2008 рік та про внесення змін до деяких законодавчих актів України" ( 107-17 ).

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 379 ( 379-2008-п ) від 17.04.2008 }

6. Розміщення державного замовлення на видання, придбання, зберігання та доставку підручників і посібників здійснюється МОН у встановленому законодавством порядку.

{ Пункт 6 в редакції Постанови КМ N 379 ( 379-2008-п ) від 17.04.2008 }

7. МОН:

разом з Інститутом інноваційних технологій і змісту освіти - розпорядником бюджетних коштів нижчого рівня (далі - розпорядник бюджетних коштів) укладає з переможцем процедури закупівлі підручників і посібників (далі - виконавець) договір про закупівлю;

подає протягом двох тижнів після укладення договорів про закупівлю Мінфіну інформацію про витрати на кожне видання підручників і посібників та їх тиражі.

8. У тендерній документації та договорі про закупівлю визначаються такі вимоги:

друкування підручників і посібників здійснюється за прямими угодами між видавництвом і поліграфічним підприємством;

сума, визначена у договорі про закупівлю, може коригуватися у разі зменшення бюджетних призначень; { Абзац третій пункту 8 в редакції Постанови КМ N 379 ( 379-2008-п ) від 17.04.2008 }

{ Абзац четвертий пункту 8 виключено на підставі Постанови КМ N 379 ( 379-2008-п ) від 17.04.2008 }

виконавець зобов'язаний забезпечити постачання продукції до закінчення календарного року в повному обсязі відповідно до контракту;

обсяги та строки виготовлення підручників і посібників та звітування про виконання державного замовлення. { Пункт 8 доповнено абзацом згідно з Постановою КМ N 379 ( 379-2008-п ) від 17.04.2008 }

9. Розпорядник бюджетних коштів на підставі договорів про закупівлю може здійснювати попередню оплату робіт (послуг), пов'язаних з виданням, придбанням, зберіганням та доставкою підручників і посібників, у розмірі до 70 відсотків їх вартості, визначеної відповідно до договорів про закупівлю.

Остаточна оплата робіт (послуг) здійснюється розпорядником бюджетних коштів на підставі акта приймання-передачі робіт (послуг) відповідно до договорів про закупівлю.

Попередня оплата робіт (послуг), пов'язаних з виданням, придбанням, зберіганням та доставкою підручників і посібників, здійснюється в установленому законодавством порядку. { Пункт 9 доповнено абзацом згідно з Постановою КМ N 379 ( 379-2008-п ) від 17.04.2008 }

Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством. { Пункт 9 доповнено абзацом згідно з Постановою КМ N 379 ( 379-2008-п ) від 17.04.2008 }

9-1. Виконавець у разі отримання попередньої оплати не пізніше ніж 5 числа місяця, що настає за звітним періодом, подає розпоряднику бюджетних коштів інформаційну довідку про фактично виконані обсяги робіт за затвердженою ним формою.

Для оплати виконаних робіт виконавці подають розпоряднику бюджетних коштів не пізніше останнього дня звітного кварталу акти приймання-передачі робіт (послуг) у вартісному виразі та зведену відомість (звіт) про виконані роботи (послуги) у натуральних показниках за встановленими ним формами.

{ Порядок доповнено пунктом 9-1 згідно з Постановою КМ N 379 ( 379-2008-п ) від 17.04.2008 }

10. Розпорядник бюджетних коштів надсилає МОН щомісяця до 20 числа наступного періоду інформацію про виконання договорів про закупівлю та використання бюджетних коштів для узагальнення і подання Мінфіну до 30 числа зазначеного періоду.

11. МОН затверджує план заходів щодо видання, придбання, зберігання та доставки підручників і посібників для студентів вищих навчальних закладів, учнів загальноосвітніх і професійно-технічних навчальних закладів та вихованців дошкільних навчальних закладів, результативні показники з поквартальною розбивкою та подає Мінфіну у тритижневий строк разом з переліком підручників і посібників, зазначеним у пункті 4 цього Порядку.

12. Інформацію про виконання результативних показників МОН подає Мінфіну у двотижневий строк після закінчення звітного кварталу та одинадцяти місяців.

{ Пункт 13 виключено на підставі Постанови КМ N 379 ( 379-2008-п ) від 17.04.2008 }

14. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
