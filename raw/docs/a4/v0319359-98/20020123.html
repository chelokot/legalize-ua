N 319 від 27.06.1998 м. Київ

( Постанова втратила чинність на підставі Постанови Центрвиборчкому N 63 ( v0063359-02 ) від 23.01.2002 )

Про зразки посвідчень офіційних спостерігачів на повторних виборах народних депутатів України та виборах народних депутатів України замість депутатів, які вибули

Відповідно до пункту 26 статті 14 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ) Центральна виборча комісія постановляє:

1. Встановити зразки посвідчень офіційних спостерігачів від інших держав та міжнародних організацій, громадських організацій України та кандидатів у народні депутати на повторних виборах народних депутатів та виборах народних депутатів України замість депутатів, які вибули (додатки NN 1, 2, 3, 4).

2. Господарському управлінню Секретаріату Центральної виборчої комісії, окружним виборчим комісіям забезпечити виготовлення посвідчень офіційних спостерігачів відповідно до встановлених Центральною виборчою комісією зразків.
