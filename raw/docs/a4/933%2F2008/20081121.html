Стан: Чинний

Ідентифікатор: 933/2008

Текст документа від 21.11.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання таким, що втратив чинність, Указу Президента України від 24 квітня 2007 року N 338

{ Додатково див. Постанову Окружного адміністративного суду N 1/1130 ( v1130805-08 ) від 21.11.2008 }

У зв'язку із завершенням перевірок обставин переведення Колесниченка В.М. на роботу на посаді судді Печерського районного суду міста Києва та призначення його головою цього суду, відновленням дії Указів Президента України від 15 червня 2005 року N 950 ( 950/2005 ) "Про переведення судді Колесниченка В.М." та від 21 червня 2005 року N 977 ( 977/2005 ) "Про призначення голови місцевого загального суду" постановляю:

1. Визнати таким, що втратив чинність, Указ Президента України від 24 квітня 2007 року N 338 ( 338/2007 ) "Про призначення голови місцевого загального суду".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 15 жовтня 2008 року N 933/2008
