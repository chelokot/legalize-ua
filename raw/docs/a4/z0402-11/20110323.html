Про внесення зміни до Інструкції щодо заповнення та видачі медичного свідоцтва про народження (форма N 103/о)

З метою приведення нормативно-правових актів МОЗ у відповідність до Закону України "Про державну реєстрацію актів цивільного стану" ( 2398-17 ) НАКАЗУЮ:

1. Абзац другий пункту 1.2 Інструкції щодо заповнення та видачі медичного свідоцтва про народження (форма N 103/о), затвердженої наказом Міністерства охорони здоров'я України від 08.08.2006 N 545 ( z1150-06 ), зареєстрованої у Міністерстві юстиції України 25.10.2006 за N 1150/13024, викласти в такій редакції:

"У разі народження дитини поза закладом охорони здоров'я при державній реєстрації в органах державної реєстрації актів цивільного стану факт народження дитини підтверджується медичною довідкою про перебування дитини під наглядом лікувального закладу (форма N 103-1/о) ( z1151-06 ) або рішенням суду.".

2. Директору Департаменту материнства, дитинства та санаторного забезпечення забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на першого заступника Міністра Аніщенка О.В.

4. Цей наказ набирає чинності з дня його офіційного опублікування.
