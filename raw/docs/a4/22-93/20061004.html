Текст документа від 04.10.2006:

ДЕКРЕТ КАБІНЕТУ МІНІСТРІВ УКРАЇНИ

{ Декрет втратив чинність на підставі Закону N 139-V ( 139-16 ) від 14.09.2006, ВВР, 2006, N 43, ст.419 }

Про індексацію оборотних коштів підприємств і організацій творчих спілок України

( Відомості Верховної Ради України (ВВР), 1993, N 19, ст.206 )

{ Додатково див. Лист КМ ( 18_5-94-р ) від 15.03.94 }

Кабінет Міністрів України постановляє:

1. Провести індексацію оборотних коштів підприємств і організацій творчих спілок України на умовах, передбачених постановами Верховної Ради України від 15 травня 1992 року "Про кредитну емісію на період до індексації оборотних коштів державних підприємств і організацій" ( 2349-12 ) і від 2 червня 1992 року "Про заходи щодо подолання платіжної кризи підприємств і організацій України" ( 2396-12 ), в межах виділених коштів на зазначені цілі.

Витрати, пов'язані з індексацією оборотних коштів підприємств і організацій творчих спілок України, віднести на державний внутрішній борг.

2. Цей Декрет набуває чинності з дня опублікування.
