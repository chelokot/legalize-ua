Про визнання такими, що втратили чинність, актів Кабінету Міністрів України з питань колегії Міністерства охорони навколишнього природного середовища

Стан: Чинний

Ідентифікатор: 1096-2007-п

Текст документа від 05.09.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 вересня 2007 р. N 1096 Київ

Про визнання такими, що втратили чинність, актів Кабінету Міністрів України з питань колегії Міністерства охорони навколишнього природного середовища

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, акти Кабінету Міністрів України з питань колегії Міністерства охорони навколишнього природного середовища згідно з переліком, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 5 вересня 2007 р. N 1096

ПЕРЕЛІК актів Кабінету Міністрів України з питань колегії Міністерства охорони навколишнього природного середовища, що втратили чинність

1. Постанова Кабінету Міністрів України від 16 жовтня 1991 р. N 274 ( 274-91-п ) "Про членів колегії Міністерства охорони навколишнього природного середовища України".

2. Постанова Кабінету Міністрів України від 13 травня 1994 р. N 307 ( 307-94-п ) "Про членів колегії Міністерства охорони навколишнього природного середовища України".

3. Постанова Кабінету Міністрів України від 23 травня 1995 р. N 358 ( 358-95-п ) "Про затвердження членів колегії Міністерства охорони навколишнього природного середовища та ядерної безпеки України".

4. Постанова Кабінету Міністрів України від 22 жовтня 1997 р. N 1162 ( 1162-97-п ) "Про членів колегії Міністерства охорони навколишнього природного середовища та ядерної безпеки".

5. Постанова Кабінету Міністрів України від 27 лютого 1998 р. N 225 ( 225-98-п ) "Про членів колегії Міністерства охорони навколишнього природного середовища та ядерної безпеки".

6. Постанова Кабінету Міністрів України від 25 липня 2000 р. N 1172 ( 1172-2000-п ) "Про колегію Міністерства екології та природних ресурсів".

7. Постанова Кабінету Міністрів України від 13 вересня 2002 р. N 1376 ( 1376-2002-п ) "Про колегію Міністерства екології та природних ресурсів".

8. Розпорядження Кабінету Міністрів України від 19 січня 2004 р. N 21 ( 21-2004-р ) "Про затвердження членів колегії Міністерства охорони навколишнього природного середовища".

9. Розпорядження Кабінету Міністрів України від 11 травня 2004 р. N 282 ( 282-2004-р ) "Про затвердження Дідківського М.П. членом колегії Мінприроди".

10. Розпорядження Кабінету Міністрів України від 1 червня 2004 р. N 350 ( 350-2004-р ) "Про затвердження Злочевського М.В. членом колегії Мінприроди".
