( Наказ втратив чинність на підставі Наказу Фонду державного майна N 1593 ( z1000-03 ) від 10.09.2003 )

Про внесення змін до Положення про порядок роботи з заявами та сертифікатами, що недопущені до участі в сертифікатному аукціоні

На виконання п.119 Державної програми приватизації на 1998 рік, затвердженої Законом України від 12.02.98 N 124/98-ВР, яким подовжено термін видачі ПМС та КС, та для забезпечення прав інвесторів щодо участі у сертифікатних аукціонах НАКАЗУЮ:

1. Викласти додаток N 1 до Положення про порядок роботи з заявами та сертифікатами, що недопущені до участі в сертифікатному аукціоні, затвердженого наказом ФДМУ від 21.02.96 N 191 ( z0108-96 ) та зареєстрованого в Міністерстві юстиції України 13.03.96 за N 108/1133, у новій редакції (додається).

2. Генеральному директору Українського центру сертифікатних аукціонів Тараторіну Ю.М. впровадити у роботу центрів сертифікатних аукціонів форму дозволу - додаток N 1, у порядку, встановленому чинним законодавством України.

3. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Бабича С.П.

В.о.Голови Фонду О.Бондар
