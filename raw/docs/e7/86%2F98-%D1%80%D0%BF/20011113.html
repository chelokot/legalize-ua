Про персональний склад Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар

Стан: Втратив чинність

Ідентифікатор: 86/98-рп

Текст документа від 13.11.2001:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про персональний склад Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар

( Із змінами, внесеними згідно з Розпорядженнями Президента N 501/98-рп від 22.09.98 N 38/99-рп від 23.02.99 N 192/2000-рп від 10.05.2000 )

На виконання Розпорядження Президента України від 27 березня 1998 року N 67 ( 67/98-рп ) "Про Робочу групу з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар":

1. Затвердити персональний склад Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар (додається).

2. Організаційне забезпечення діяльності Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар, покласти на Адміністрацію Президента України, матеріально-технічне - на Кабінет Міністрів України.

Президент України Л.КУЧМА
