КАБІНЕТ МІНІСТРІВ УКРАЇНИ
РОЗПОРЯДЖЕННЯ

від 21 травня 2014 р. № 528-р
Київ

Про виділення коштів для здійснення невідкладних заходів з ліквідації наслідків надзвичайної ситуації, що склалася 12 травня 2014 р. в житловому будинку по вул. Лазурній, 40, у м. Миколаєві

{Із змінами, внесеними згідно з Розпорядженням КМ
№ 573-р від 18.06.2014}

1. Виділити Миколаївській облдержадміністрації 46743,826 тис. гривень для здійснення невідкладних заходів з ліквідації наслідків надзвичайної ситуації, що склалася 12 травня 2014 р. в житловому будинку по вул. Лазурній, 40, у м. Миколаєві, у тому числі:

2150 тис. гривень - для надання постраждалим грошової допомоги з метою розв’язання соціально-побутових проблем з розрахунку по 10 тис. гривень кожній особі;

{Абзац другий пункту 1 в редакції Розпорядження КМ № 573-р від 18.06.2014 }

950 тис. гривень - для надання матеріальної грошової допомоги постраждалим і сім’ям загиблих з розрахунку 80 тис. гривень - особі, що отримала тяжкі травми, по 42,5 тис. гривень - чотирьом постраждалим, по 100 тис. гривень - за кожного загиблого члена сім’ї;

38478,75 тис. гривень - для придбання квартир мешканцям, які потребують відселення;

5165,076 тис. гривень - для проведення аварійно-відбудовних робіт.

Міністерству фінансів здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету.

2. Миколаївській облдержадміністрації:

затвердити у триденний строк за погодженням з Міністерством регіонального розвитку, будівництва та житлово-комунального господарства, Міністерством економічного розвитку і торгівлі та Міністерством фінансів перелік витрат, пов’язаних із здійсненням невідкладних заходів, передбачених пунктом 1 цього розпорядження;

подати до 20 грудня 2014 р. Міністерству економічного розвитку і торгівлі, Міністерству фінансів та Державній казначейській службі звіт про використання коштів, виділених згідно з цим розпорядженням.
