Стан: Чинний

Текст документа від 14.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 травня 2008 р. N 462 Київ

Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для проведення незалежної експертизи (випробувань) якості товарів, сировини, матеріалів, напівфабрикатів та комплектувальних виробів

{ Із змінами, внесеними згідно з Постановою КМ N 817 ( 817-2010-п ) від 08.09.2010 }

{ Установити, що у 2010 році кошти, передбачені у державному бюджеті ( 2154-17 ) Міністерству економіки за програмою "Проведення незалежної експертизи (випробувань) якості товарів, сировини, матеріалів, напівфабрикатів та комплектуючих виробів", використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 817 ( 817-2010-п ) від 08.09.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для проведення незалежної експертизи (випробувань) якості товарів, сировини, матеріалів, напівфабрикатів та комплектувальних виробів, що додається.

{ Постановляюча частина із змінами, внесеними згідно з Постановою КМ N 817 ( 817-2010-п ) від 08.09.2010 }

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 травня 2008 р. N 462

ПОРЯДОК використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для проведення незалежної експертизи (випробувань) якості товарів, сировини, матеріалів, напівфабрикатів та комплектувальних виробів

{ У назві і тексті Порядку слова "незалежної експертизи" замінено словами "незалежної експертизи (випробувань)" згідно з Постановою КМ N 817 ( 817-2010-п ) від 08.09.2010 }

1. Цей Порядок визначає механізм використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) Мінекономіки за програмою "Проведення незалежної експертизи (випробувань) якості товарів, сировини, матеріалів, напівфабрикатів та комплектуючих виробів" (далі - бюджетні кошти).

2. Розпорядниками бюджетних коштів нижчого рівня є Держспоживстандарт і управління у справах захисту прав споживачів в Автономній Республіці Крим, областях, мм. Києві та Севастополі. { Пункт 2 із змінами, внесеними згідно з Постановою КМ N 817 ( 817-2010-п ) від 08.09.2010 }

3. Бюджетні кошти спрямовуються на оплату:

зразків товарів, сировини, матеріалів, напівфабрикатів та комплектувальних виробів (далі - зразки продукції), наданих суб'єктами господарювання, що провадять діяльність у сфері торгівлі і послуг, зокрема підприємствами ресторанного господарства, для проведення незалежної експертизи (випробувань) їх якості;

послуг з транспортування зразків продукції;

послуг з проведення незалежної експертизи (випробувань) якості зразків продукції. { Абзац четвертий пункту 3 в редакції Постанови КМ N 817 ( 817-2010-п ) від 08.09.2010 }

4. Держспоживстандарт здійснює розподіл бюджетних коштів на підставі затверджених кошторисів та планів асигнувань загального фонду державного бюджету в розрізі управлінь у справах захисту прав споживачів в Автономній Республіці Крим, областях, мм. Києві та Севастополі пропорційно їх штатній чисельності у кожному регіоні.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 817 ( 817-2010-п ) від 08.09.2010 }

5. Закупівля послуг, пов'язаних з проведенням незалежної експертизи (випробувань), за рахунок бюджетних коштів здійснюється у встановленому законодавством порядку.

6. Відбір зразків продукції та проведення незалежної експертизи (випробувань) здійснюються до закінчення календарного року з подальшим складенням відповідних актів та протоколів проведення незалежної експертизи (випробувань) кожного з них.

7. Операції, пов'язані з використанням бюджетних коштів, проводяться у порядку, встановленому Державним казначейством.

{ Пункт 7 із змінами, внесеними згідно з Постановою КМ N 817 ( 817-2010-п ) від 08.09.2010 }

8. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
