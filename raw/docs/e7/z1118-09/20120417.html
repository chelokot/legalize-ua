Зареєстровано в Міністерстві юстиції України 19 листопада 2009 р. за N 1118/17134

Про внесення змін до деяких наказів Міністерства юстиції України

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 512/5 ( z0489-12 ) від 02.04.2012 }

Відповідно до Закону України "Про виконавче провадження" ( 606-14 ) та з метою покращення доступу до інформації про майно, що реалізується органами державної виконавчої служби, НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства юстиції N 512/5 ( z0489-12 ) від 02.04.2012 }

2. Затвердити Зміни до Порядку реалізації арештованого майна, затвердженого наказом Міністерства юстиції України від 15.07.99 N 42/5 ( z0480-99 ), зареєстрованого в Мін'юсті 19.07.99 за N 480/3773 (зі змінами) (додаються) ( z1119-09 ).

3. Затвердити Зміни до Тимчасового положення про порядок проведення прилюдних торгів з реалізації арештованого нерухомого майна, затвердженого наказом Міністерства юстиції України від 27.10.99 N 68/5 ( z0745-99 ), зареєстрованого в Мін'юсті 02.11.99 за N 745/4038 (зі змінами) (додаються) ( z1120-09 ).

4. У Положенні про умови і порядок проведення тендерів (конкурсів) з визначення спеціалізованих організацій для реалізації арештованого державними виконавцями майна, затвердженому наказом Міністерства юстиції України від 11.11.2003 N 136/5 ( z1036-03 ), зареєстрованому у Мін'юсті 11.11.2003 за N 1036/8357 (зі змінами):

4.1. У пункті 2.1 слова "заступника голови комісії - директора Департаменту державної виконавчої служби" виключити, цифри "12" замінити цифрами "13", слова "двох заступників директора Департаменту державної виконавчої служби і чотирьох представників цього Департаменту" замінити словами "семи представників Міністерства юстиції України";

4.2. Доповнити після пункту 3.3 новим пунктом 3.4 такого змісту:

"3.4. Після закінчення термінів подання документів комісія здійснює перевірку поданих претендентами відомостей, зокрема надсилає запити до відділів державної виконавчої служби Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управлінь юстиції в областях, містах Києві та Севастополі щодо перевірки достовірності інформації про філії підприємства та їх технічні можливості.

Така перевірка здійснюється уповноваженим представником органу юстиції за місцезнаходженням філії.

У разі потреби комісія також може надіслати запити до уповноважених державних органів щодо перевірки поданих претендентом відомостей".

У зв'язку з цим пункт 3.4 вважати пунктом 3.5;

4.3. Пункт 3.5 після слів "кінцевого терміну" доповнити словами "або подання недостовірних відомостей про підприємство".

5. Департаменту державної виконавчої служби (Стаднік Г.В.):

5.1. Подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (зі змінами).

5.2. Довести наказ до відома Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управлінь юстиції в областях, містах Києві та Севастополі.

6. Цей наказ набирає чинності з дня його офіційного опублікування.

7. Контроль за виконанням цього наказу залишаю за собою.

Міністр Микола Оніщук
