Про внесення змін до деяких наказів Міністерства юстиції України

{ Із змінами, внесеними згідно з Наказами Міністерства юстиції N 512/5 ( z0489-12 ) від 02.04.2012 N 2710/5 ( z1620-15 ) від 22.12.2015 }

Відповідно до Закону України "Про виконавче провадження" ( 606-14 ) та з метою покращення доступу до інформації про майно, що реалізується органами державної виконавчої служби, НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства юстиції N 512/5 ( z0489-12 ) від 02.04.2012 }

{ Пункт 2 втратив чинність на підставі Наказу Міністерства юстиції N 2710/5 ( z1620-15 ) від 22.12.2015 }

{ Пункт 3 втратив чинність на підставі Наказу Міністерства юстиції N 2710/5 ( z1620-15 ) від 22.12.2015 }

{ Пункт 4 втратив чинність на підставі Наказу Міністерства юстиції N 2710/5 ( z1620-15 ) від 22.12.2015 }

5. Департаменту державної виконавчої служби (Стаднік Г.В.):

5.1. Подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (зі змінами).

5.2. Довести наказ до відома Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управлінь юстиції в областях, містах Києві та Севастополі.

6. Цей наказ набирає чинності з дня його офіційного опублікування.

7. Контроль за виконанням цього наказу залишаю за собою.

Міністр Микола Оніщук
