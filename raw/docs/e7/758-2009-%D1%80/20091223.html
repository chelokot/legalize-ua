Кабінет Міністрів України; Розпорядження від 01.07.2009 № 758-р

Про реорганізацію державного підприємства "Київський авіаційний завод "Авіант"

Стан: Чинний

Ідентифікатор: 758-2009-р

Текст документа від 23.12.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 липня 2009 р. N 758-р Київ

Про реорганізацію державного підприємства "Київський авіаційний завод "Авіант"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1652-р ( 1652-2009-р ) від 23.12.2009 }

1. Погодитися з пропозицією Мінпромполітики щодо реорганізації державного підприємства "Київський авіаційний завод "Авіант" шляхом його приєднання до державного підприємства "Авіаційний науково-технічний комплекс імені О.К.Антонова".

2. Мінпромполітики:

здійснити в установленому порядку заходи, пов'язані з реорганізацією державного підприємства "Київський авіаційний завод "Авіант";

під час реорганізації зазначеного підприємства вирішити питання щодо визначення державного підприємства "Авіаційний науково-технічний комплекс імені О.К. Антонова" його правонаступником із забезпечення виконання зобов'язань за облігаціями, випущеними відповідно до розпорядження Кабінету Міністрів України від 22 квітня 2009 р. N 476 ( 476-2009-р ) "Про заходи щодо фінансового оздоровлення Харківського державного авіаційного виробничого підприємства та державного підприємства "Київський авіаційний завод "Авіант"; { Пункт 2 доповнено новим абзацом згідно з Розпорядженням КМ N 1652-р ( 1652-2009-р ) від 23.12.2009 }

подати у місячний строк після припинення зазначеного підприємства Кабінетові Міністрів України пропозиції про внесення до нормативно-правових актів змін, що випливають з цього розпорядження.

Прем'єр-міністр України Ю.ТИМОШЕНКО
