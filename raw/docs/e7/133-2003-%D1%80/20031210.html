РОЗПОРЯДЖЕННЯ від 12 березня 2003 р. N 133-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 743-р ( 743-2003-р ) від 10.12.2003 )

Про представників Кабінету Міністрів України у Національній раді соціального партнерства

1. Затвердити представниками Кабінету Міністрів України у Національній раді соціального партнерства осіб згідно з додатком.

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 27 грудня 2001 р. N 614 ( 614-2001-р ) "Про затвердження складу представників від Кабінету Міністрів України до Національної ради соціального партнерства";

розпорядження Кабінету Міністрів України від 1 липня 2002 р. N 350 ( 350-2002-р ) "Про внесення змін до складу представників від Кабінету Міністрів України до Національної ради соціального партнерства" (Офіційний вісник України, 2002 р., N 27, ст. 1281).
