КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 серпня 2007 р. N 656-р Київ

Про проведення в м. Києві 21-ї Міжнародної конференції та 26-го засідання Генеральної асамблеї Комітету з даних для науки та технологій (КОДАТА)

{ Із змінами, внесеними згідно з Розпорядженням КМ N 883-р ( 883-2008-р ) від 25.06.2008 }

1. Підтримати пропозицію МОН щодо проведення в м. Києві 5-10 жовтня 2008 р. 21-ї Міжнародної конференції та 26-го засідання Генеральної асамблеї Комітету з даних для науки та технологій (КОДАТА) (далі - Конференція) на базі Національного технічного університету "Київський політехнічний інститут".

2. Утворити Координаційну раду з підготовки та проведення 21-ї Міжнародної конференції та 26-го засідання Генеральної асамблеї Комітету з даних для науки та технологій (КОДАТА) у складі згідно з додатком.

3. МОН, іншим заінтересованим центральним органам виконавчої влади і Національній академії наук відповідно до своїх повноважень вжити заходів для забезпечення підготовки та проведення Конференції.

4. Мінфіну разом з МОН передбачити під час складання проекту Державного бюджету України на 2008 рік видатки з підготовки та проведення Конференції.
