{ Наказ втратив чинність на підставі Наказу Міністерства фінансів N 49 ( z0340-16 ) від 11.02.2016 }

Про затвердження Змін до форм звітів щодо придбання та реалізації алкогольних напоїв і тютюнових виробів та інструкцій щодо їх заповнення, затверджених наказом ДПА України від 27.04.2006 N 228

Відповідно до частини третьої статті 16 Закону України "Про державне регулювання виробництва і обігу спирту етилового, коньячного і плодового, алкогольних напоїв та тютюнових виробів" ( 481/95-ВР ), постанови Кабінету Міністрів України від 24.01.2007 N 58 ( 58-2007-п ) "Про реорганізацію Департаменту з питань адміністрування акцизного збору і контролю за виробництвом та обігом підакцизних товарів" НАКАЗУЮ:

1. Затвердити Зміни до:

Форми звіту N 1-ОА "Звіт про обсяги придбання та реалізації алкогольних напоїв", затвердженої наказом ДПА України від 27.04.2006 N 228 ( z0713-06 ), зареєстрованим у Міністерстві юстиції України 16.06.2006 за N 713/12587;

Форми звіту N 1-ОТ "Звіт про обсяги придбання та реалізації тютюнових виробів" ( z0714-06 ), затвердженої наказом ДПА України від 27.04.2006 N 228 ( z0713-06 ), зареєстрованим у Міністерстві юстиції України 16.06.2006 за N 713/12587;

Інструкції щодо заповнення Форми звіту N 1-ОА "Звіт про обсяги придбання та реалізації алкогольних напоїв", затвердженої наказом ДПА України від 27.04.2006 N 228 ( z0713-06 ), зареєстрованої у Міністерстві юстиції України 16.06.2006 за N 713/12587;

Інструкції щодо заповнення Форми звіту N 1-ОТ "Звіт про обсяги придбання та реалізації тютюнових виробів" ( z0714-06 ), затвердженої наказом ДПА України від 27.04.2006 N 228 ( z0713-06 ), зареєстрованої у Міністерстві юстиції України 16.06.2006 за N 714/12588, що додаються ( z1066-07 ).

2. Департаменту контролю за виробництвом та обігом спирту, алкогольних напоїв і тютюнових виробів (Радченко А.П.) подати цей наказ до Міністерства юстиції України для державної реєстрації.

3. Департаменту масово-роз'яснювальної роботи та звернень громадян (Косарчук В.П.) після державної реєстрації цього наказу довести його через засоби масової інформації до відома платників податків.

4. Контроль за виконанням цього наказу покласти на першого заступника Голови ДПА України Кайзермана В.О.

Голова А.І.Брезвін
