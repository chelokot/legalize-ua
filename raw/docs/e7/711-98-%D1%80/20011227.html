Текст документа від 27.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 вересня 1998 р. N 711-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 614-р ( 614-2001-р ) від 27.12.2001 )

Про внесення змін до розпорядження Кабінету Міністрів України від 3 квітня 1997 р. N 174

( Додатково див. Розпорядження КМ N 767-р ( 767-99-р ) від 03.08.99 N 272-р ( 272-2000-р ) від 26.06.2000 )

На часткову зміну розпорядження Кабінету Міністрів України від 3 квітня 1997 р. N 174 ( 174-97-р ) затвердити новий склад представників від Кабінету Міністрів України до Національної ради соціального партнерства (додається).

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

Інд.26

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 1 вересня 1998 р. N 711-р
