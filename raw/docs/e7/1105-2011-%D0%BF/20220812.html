КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 жовтня 2011 р. N 1105 Київ

Деякі питання надання платних послуг Головним управлінням та підрозділами урядового фельд’єгерського зв’язку Державної служби спеціального зв’язку та захисту інформації

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 161 ( 161-2016-п ) від 02.03.2016 }

{ Із змінами, внесеними згідно з Постановами КМ N 161 ( 161-2016-п ) від 02.03.2016 N 888 ( 888-2022-п ) від 09.08.2022 }

Кабінет Міністрів України постановляє:

1. Затвердити перелік платних послуг, що надаються Головним управлінням та підрозділами урядового фельд’єгерського зв’язку Державної служби спеціального зв’язку та захисту інформації, згідно з додатком.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 161 ( 161-2016-п ) від 02.03.2016 }

2. Взяти до відома, що надання платних послуг Головним управлінням та підрозділами урядового фельд’єгерського зв’язку Державної служби спеціального зв’язку та захисту інформації здійснюється на підставі укладених із юридичними особами договорів, дія яких поширюється на Головне управління та підрозділи урядового фельд’єгерського зв’язку Державної служби спеціального зв’язку та захисту інформації, які задіяні у технологічному процесі доставки кореспонденції.

{ Пункт 2 із змінами, внесеними згідно з Постановами КМ N 161 ( 161-2016-п ) від 02.03.2016, N 888 ( 888-2022-п ) від 09.08.2022 }

3. Адміністрації Державної служби спеціального зв’язку та захисту інформації затвердити порядок визначення вартості та надання платних послуг Головним управлінням та підрозділами урядового фельд’єгерського зв’язку ( z1384-16 ).

{ Пункт 3 в редакції Постанови КМ N 161 ( 161-2016-п ) від 02.03.2016 }

4. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 18 січня 2006 р. N 41 ( 41-2006-п ) "Про затвердження переліку платних послуг, які можуть надаватися Державною фельд'єгерською службою" (Офіційний вісник України, 2006 p., N 3, ст. 96).
