КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 квітня 2005 р. N 313 Київ

Про внесення змін до деяких постанов Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 1140 ( 1140-2007-п ) від 19.09.2007 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України такі зміни:

у пункті 1 постанови Кабінету Міністрів України від 8 жовтня 2004 р. N 1330 ( 1330-2004-п ) "Деякі питання Державної іпотечної установи" (Офіційний вісник України, 2004 р., N 41, ст. 2709) цифри і слова "50000000 (п'ятдесят мільйонів)" замінити цифрами і словами "20000000 (двадцять мільйонів)".

{ Абзац третій постановляючої частини втратив чинність на підставі Постанови КМ N 1140 ( 1140-2007-п ) від 19.09.2007 }
