Про внесення змін до переліку напрямів, за якими здійснюється підготовка фахівців у вищих навчальних закладах за освітньо-кваліфікаційним рівнем бакалавра

Стан: Втратив чинність

Ідентифікатор: 264-2010-п

Текст документа від 02.03.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 березня 2010 р. N 264 Київ

Про внесення змін до переліку напрямів, за якими здійснюється підготовка фахівців у вищих навчальних закладах за освітньо-кваліфікаційним рівнем бакалавра

Кабінет Міністрів України постановляє:

Внести до переліку напрямів, за якими здійснюється підготовка фахівців у вищих навчальних закладах за освітньо-кваліфікаційним рівнем бакалавра, затвердженого постановою Кабінету Міністрів України від 13 грудня 2006 р. N 1719 ( 1719-2006-п ) (Офіційний вісник України, 2006 р., N 50, ст. 3333), такі зміни:

доповнити позицію "0402 Фізико-математичні науки" розділу "Природничі науки" словами і цифрами

------------------------------------------------------------------

| | |"статистика | 6.040205 |

|------+-------------------+-------------------------+-----------|

| | |астрономія | 6.040206";|

------------------------------------------------------------------

у позиції "0701 Транспорт і транспортна інфраструктура" розділу "Транспорт":

слова "залізничний транспорт" замінити словами "рухомий склад залізниць";

доповнити позицію словами і цифрами

------------------------------------------------------------------

| | |"системи забезпечення | 6.070107 |

| | |руху поїздів | |

|------+-------------------+-------------------------+-----------|

| | |залізничні споруди | 6.070108".|
