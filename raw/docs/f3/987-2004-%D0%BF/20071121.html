Про внесення зміни до пункту 3 Положення про Премію Кабінету Міністрів України за внесок молоді у розбудову держави

Текст документа від 21.11.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 липня 2004 р. N 987 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1333 ( 1333-2007-п ) від 21.11.2007 }

Про внесення зміни до пункту 3 Положення про Премію Кабінету Міністрів України за внесок молоді у розбудову держави

Кабінет Міністрів України постановляє:

У пункті 3 Положення про Премію Кабінету Міністрів України за внесок молоді у розбудову держави, затвердженого постановою Кабінету Міністрів України від 13 червня 2000 р. N 951 ( 951-2000-п ) (Офіційний вісник України, 2000 р., N 24, ст. 1005; 2002 р., N 44, ст. 2019; 2003 р., N 30, ст. 1546, N 37, ст. 1981; 2004 р., N 12, ст. 736), слова і цифри "до 28 років" замінити словами і цифрами "до 35 років".
