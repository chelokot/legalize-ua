N 1019 від 03.06.99 Зареєстровано в Міністерстві м.Київ юстиції України 14 червня 1999 р. за N 373/3666

{ Наказ втратив чинність на підставі Наказу Фонду державного майна N 1027 ( z1280-13 ) від 15.07.2013 }

Про втрату чинності Положення про порядок роботи постійної конкурсної комісії по відбору кандидатур на заміщення вакантних посад голів правлінь відкритих акціонерних товариств

На підставі окремого доручення Прем'єр-міністра України від 15.03.99 N 5196/96 НАКАЗУЮ:

1. Вважати таким, що втратило чинність, Положення про порядок роботи постійної конкурсної комісії по відбору кандидатур на заміщення вакантних посад голів правлінь відкритих акціонерних товариств, затверджене наказом ФДМУ від 29.09.97 N 1037 ( z0484-97, z0483-97 ) та зареєстроване в Міністерстві юстиції України 17 жовтня 1997 року за N 484/2288.

2. Контроль за виконанням цього наказу покласти на заступника Голови Фонду С.Глушка.
