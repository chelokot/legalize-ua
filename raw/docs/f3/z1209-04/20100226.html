ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

13.09.2004 N 664

Зареєстровано в Міністерстві юстиції України 23 вересня 2004 р. за N 1209/9808

Про внесення змін до наказу Держмитслужби України від 28.12.99 N 864

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Державної митної служби N 864 ( z0050-00 ) від 28.12.99, до якого вносились зміни }

Відповідно до Положення про Державну митну службу України, затвердженого Указом Президента України від 24.08.2000 N 1022 ( 1022/2000 ) "Питання Державної митної служби", та з метою посилення контролю за повнотою і своєчасністю справляння податків та зборів, забезпечення неухильного дотримання вимог законодавства з питань оподаткування НАКАЗУЮ:

1. Внести до наказу Держмитслужби України від 28.12.99 N 864 ( z0050-00 ) "Про затвердження Положення про відділ митних платежів регіональної митниці, митниці прямого підпорядкування, митниці", зареєстрованого в Міністерстві юстиції України 27.01.2000 за N 50/4271 (зі змінами), такі зміни:

1.1. Пункт 2 наказу викласти у такій редакції:

"2. Підпорядкувати відділ митних платежів регіональної митниці, митниці прямого підпорядкування, митниці першому заступнику начальника регіональної митниці, митниці прямого підпорядкування, митниці".

2. Внести до Положення про відділ митних платежів регіональної митниці, митниці прямого підпорядкування, митниці (далі - Положення), затвердженого наказом Держмитслужби України від 28.12.99 N 864 ( z0050-00 ) та зареєстрованого в Міністерстві юстиції України 27.01.2000 за N 50/4271 (зі змінами), такі зміни:

2.1. У пункті 4.3 Положення слово "начальнику" замінити словами "першому заступнику начальника".

2.2. У підпункті 5.1.4 пункту 5.1 Положення слово "начальника" замінити словами "першого заступника начальника".

3. Департаменту податків та тарифного регулювання (Шейко О.Л.) і Департаменту правового забезпечення (Ступак Ю.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Керівникам регіональних митниць, митниць прямого підпорядкування, митниць внести відповідні зміни до розподілів обов'язків між керівником митниці та його заступниками, а також до посадових інструкцій перших заступників керівників митниць.

5. Контроль за виконанням наказу покласти на заступника Голови Служби Войцещука А.Д.

В.о. Голови Служби М.Іванюк
