Рішення про реалізацію Угоди про створення загального науково-технологічного простору держав - учасниць Співдружності Незалежних Держав

Рада глав урядів Співдружності Незалежних Держав з метою реалізації Угоди про створення загального науково-технологічного простору держав - учасниць Співдружності Незалежних Держав ( 997_149 )

вирішила:

урядам держав-учасниць зазначеної Угоди ( 997_149 ) протягом місяця після підписання цього Рішення визначити представників до складу Міждержавного комітету з науково-технологічного розвитку.

Вчинено в місті Москва 3 листопада 1995 року в одному дійсному примірнику російською мовою. Дійсний примірник зберігається у Виконавчому Секретаріаті Співдружності Незалежних Держав, що направить кожній державі, яка підписала це Рішення, його засвідчену копію.

Решение о реализации Соглашения о создании общего научно-технологического пространства государств-участников Содружества Независимых Государств

3 ноября 1995 года

Совет глав правительств Содружества Независимых Государств в целях реализации Соглашения о создании общего научно-технологического пространства государств-участников Содружества Независимых Государств ( 997_149 ) решил:

правительствам государств-участников указанного Соглашения ( 997_149 ) в течение месяца после подписания настоящего Решения определить представителей в состав Межгосударственного комитета по научно-технологическому развитию.

Совершено в городе Москве 3 ноября 1995 года в одном подлинном экземпляре на русском языке. Подлинный экземпляр хранится в Исполнительном Секретариате Содружества Независимых Государств, который направит каждому государству, подписавшему настоящее Решение, его заверенную копию.
