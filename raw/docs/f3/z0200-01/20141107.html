N 74 від 19.02.2001 Зареєстровано в Міністерстві юстиції України 7 березня 2001 р. за N 200/5391

{ Наказ втратив чинність на підставі Наказу Міністерства освіти і науки N 1060 ( z1205-14 ) від 19.09.2014 }

Про затвердження Умов прийому до вищих навчальних закладів України

( Із змінами, внесеними згідно з Наказом Міністерства освіти і науки N 212 ( z0325-03 ) від 07.04.2003 )

На виконання Закону України "Про освіту" ( 1060-12 ) НАКАЗУЮ:

1. Затвердити Умови прийому до вищих навчальних закладів України (додаються).

2. Ректорам (директорам) вищих навчальних закладів України:

2.1. Розробити й до 01.04.2001 затвердити правила прийому до вищого навчального закладу в 2001 році згідно з Умовами прийому до вищих навчальних закладів України.

2.2. Інформацію про правила прийому до вищого навчального закладу довести до відома вступників.

3. Вважати такими, що втратили чинність, Умови прийому на перший курс вищих навчальних закладів України, затверджені наказом Міністерства освіти і науки України від 29.02.2000 N 37 ( z0169-00 ) "Про затвердження Умов прийому на перший курс вищих навчальних закладів України", зареєстрованим Міністерством юстиції України 16.03.2000 за N 169/4390.

4. Контроль за виконанням наказу покласти на заступника Міністра Степка М.Ф.

Міністр В.Г.Кремень

( Умови прийому до вищих навчальних закладів України втратили чинність на підставі Наказу Міністерства освіти і науки N 212 ( z0325-03 ) від 07.04.2003 )
