Ідентифікатор: z0721-00

Текст документа від 11.12.2004:

ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

N 149 від 29.09.2000 Зареєстровано в Міністерстві юстиції України 18 жовтня 2000 р. за N 721/4942

Про передачу повноважень з реєстрації випусків акцій до територіальних управлінь Комісії

( Із змінами, внесеними згідно з Рішеннями Державної комісії з цінних паперів та фондового ринку N 223 ( z0655-01 ) від 19.07.2001 N 467 ( z1519-04 ) від 17.11.2004 )

Відповідно до статті 7 Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ) та у зв'язку з прийняттям Державною комісією з цінних паперів та фондового ринку рішень від 17.03.2000 N 25 ( z0199-00 ) "Про затвердження Положення про порядок реєстрації випуску акцій акціонерного товариства при збільшенні статутного фонду у зв'язку з індексацією основних фондів (07-04/98)", зареєстрованого в Міністерстві юстиції України 30.03.2000 за N 199/4420, та від 11.04.2000 N 39 ( z0244-00 ) "Про порядок реєстрації випуску акцій відкритих акціонерних товариств, створених із державних підприємств у процесі приватизації та корпоратизації", зареєстрованого в Міністерстві юстиції України 26.04.2000 за N 244/4465, Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Установити, що територіальні управління Комісії відповідно до повноважень здійснюють реєстрацію випусків акцій:

1.1. Закритих акціонерних товариств, крім тих, що створюються згідно з планом санації суб'єктів господарювання усіх форм власності, - відповідно до вимог Положення про порядок реєстрації випуску акцій закритих акціонерних товариств, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 11.06.2002 N 167 ( z0587-02 ) та зареєстрованого в Міністерстві юстиції України 16.07.2002 за N 587/6875. ( Підпункт 1.1 пункту 1 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 467 ( z1519-04 ) від 17.11.2004 )

1.2. Відкритих акціонерних товариств, якщо розмір статутного фонду на дату прийняття рішення про випуск акцій (з урахуванням емісії, щодо якої прийнято рішення) не перевищує 1000000 грн., а також закритих акціонерних товариств - відповідно до вимог Положення про порядок реєстрації випуску акцій акціонерного товариства при збільшенні статутного фонду у зв'язку з індексацією основних фондів (07-04/98), затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 17.03.2000 N 25 ( z0199-00 ), зареєстрованого в Міністерстві юстиції України 30.03.2000 за N 199/4420.

1.3. Відкритих акціонерних товариств - відповідно до вимог Положення про порядок реєстрації випуску акцій відкритих акціонерних товариств, створених із державних підприємств у процесі приватизації та корпоратизації, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 11.04.2000 N 39 ( z0244-00 ), зареєстрованого в Міністерстві юстиції України 26.04.2000 за N 244/4465, - якщо розмір статутного фонду відкритого акціонерного товариства не перевищує 21,5 млн. грн.

1.4. Акціонерних товариств - відповідно до вимог Положення про порядок реєстрації випуску акцій та інформації про їх емісію під час реорганізації товариств, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 30.12.98 N 221 ( z0137-99 ), зареєстрованого в Міністерстві юстиції України 04.03.99 за N 137/3430 (зі змінами та доповненнями):

- у разі реорганізації акціонерного товариства шляхом перетворення закритого акціонерного товариства у відкрите, якщо розмір статутного фонду закритого акціонерного товариства на дату прийняття рішення про реорганізацію не перевищує 500000 грн;

- у разі реорганізації акціонерного товариства шляхом перетворення відкритого акціонерного товариства у закрите.

1.5. Акціонерних товариств - відповідно до вимог Положення про порядок реєстрації випуску акцій акціонерного товариства при зміні номінальної вартості та кількості акцій без зміни розміру статутного фонду, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 14.09.2000 N 125 ( z0671-00 ), зареєстрованого в Міністерстві юстиції України 02.10.2000 за N 671/4892, - якщо попередній випуск акцій було зареєстровано територіальним управлінням Комісії.

1.6. Відкритих акціонерних товариств та інформації про їх емісію, крім тих, що створюються згідно з планом санації суб'єктів господарювання усіх форм власності, - відповідно до вимог Положення про порядок реєстрації випуску акцій і облігацій підприємств та інформації про їх емісію (07-01/98) (у новій редакції), затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 09.02.2001 N 18 ( z0449-01 ) та зареєстрованого в Міністерстві юстиції 25.05.2001 за N 449/5640, - якщо розмір статутного фонду на дату прийняття рішення про випуск акцій (з урахуванням емісії, щодо якої прийнято рішення) не перевищує 500 000 грн. ( Підпункт 1.6 пункту 1 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 467 ( z1519-04 ) від 17.11.2004 )

2. Дія пунктів 1.1, 1.2, 1.4, 1.5 та 1.6 цього рішення не поширюється на реєстрацію випусків акцій банківських установ, страхових компаній, інвестиційних фондів, інвестиційних компаній, фондових бірж, депозитаріїв, торговців цінними паперами, реєстраторів та інших професійних учасників ринку цінних паперів.

3. Реєстрація випусків акцій акціонерних товариств відповідно до Порядку реєстрації додаткового випуску акцій акціонерних товариств на суму реалізованих ДК "Луганськлегінвест" інвестиційних проектів за рахунок державних коштів, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 02.09.99 N 163 ( z0669-99 ), здійснюється Луганським територіальним управлінням Комісії.

4. Рішення про відмову в реєстрації випусків цінних паперів відповідно до повноважень, визначених цим рішенням, оформлюється у вигляді Розпорядження про відмову в реєстрації випуску цінних паперів із зазначенням підстав для відмови в реєстрації випуску цінних паперів і підписується керівником відповідного територіального органу (управління) Комісії або начальником управління корпоративних фінансів згідно з додатком 1. ( Рішення доповнено пунктом 4 згідно з Рішенням Держкомісціннихпаперів N 223 ( z0655-01 ) від 19.07.2001 )

5. Вважати таким, що втратило чинність, рішення Державної комісії з цінних паперів та фондового ринку від 12.09.98 N 118 ( z0672-98 ) "Про передачу повноважень територіальним управлінням".

6. Управлінню корпоративних фінансів (А.Портнов) забезпечити державну реєстрацію цього рішення в Міністерстві юстиції України.

7. Рішення набирає чинності відповідно до чинного законодавства.

8. Управлінню організаційного забезпечення Комісії забезпечити опублікування цього рішення відповідно до чинного законодавства.

9. Контроль за виконанням цього рішення покласти на члена Комісії - заступника Голови М. Пефтієва.

Тимчасово в.о. Голови Комісії М. Волков
