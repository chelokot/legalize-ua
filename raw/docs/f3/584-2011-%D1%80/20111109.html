Про утворення комісії з ліквідації Державної служби зв'язку

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 червня 2011 р. N 584-р Київ

Про утворення комісії з ліквідації Державної служби зв'язку

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1001-р ( 1001-2011-р ) від 12.10.2011 N 1117-р ( 1117-2011-р ) від 09.11.2011 }

1. Утворити комісію з ліквідації Державної служби зв'язку.

Затвердити головою комісії заступника Голови Державної служби спеціального зв'язку та захисту інформації Круглика Ігоря Вікторовича. { Абзац другий пункту 1 в редакції Розпоряджень КМ N 1001-р ( 1001-2011-р ) від 12.10.2011, N 1117-р ( 1117-2011-р ) від 09.11.2011 }

2. Голові комісії:

затвердити її персональний склад;

забезпечити здійснення заходів, пов'язаних з ліквідацією Державної служби зв'язку;

поінформувати у шестимісячний строк Кабінет Міністрів України про результати проведеної роботи.

Прем'єр-міністр України М.АЗАРОВ
