УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 264/2015 ( 264/2015 ) від 12.05.2015 }

Про внесення змін до Положення про дипломатичний паспорт України

Внести до пункту 9 Положення про дипломатичний паспорт України, затвердженого Указом Президента України від 27 жовтня 1992 року N 515 ( 515/92 ) "Про дипломатичний та службовий паспорти України" (в редакції Указу Президента України від 5 червня 1995 року N 424 ( 424/95 ), такі зміни:

абзац п'ятий викласти у такій редакції:

"Голові Конституційного Суду України, заступникам Голови Конституційного Суду України, суддям Конституційного Суду України";

доповнити пункт після абзацу двадцять другого новим абзацом такого змісту:

"керівникові Секретаріату Конституційного Суду України, його заступникам";

у зв'язку з цим абзаци двадцять третій - двадцять дев'ятий вважати відповідно абзацами двадцять четвертим - тридцятим.

Президент України Л.КУЧМА
