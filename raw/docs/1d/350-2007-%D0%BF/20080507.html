Кабінет Міністрів України; Постанова, Порядок від 01.03.2007 № 350

Про затвердження Порядку використання у 2007 році субвенції з державного бюджету місцевим бюджетам на придбання вагонів для комунального електротранспорту (тролейбусів і трамваїв)

Стан: Чинний

Ідентифікатор: 350-2007-п

Текст документа від 07.05.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 2007 р. N 350 Київ

Про затвердження Порядку використання у 2007 році субвенції з державного бюджету місцевим бюджетам на придбання вагонів для комунального електротранспорту (тролейбусів і трамваїв)

{ Із змінами, внесеними згідно з Постановами КМ N 1272 ( 1272-2007-п ) від 31.10.2007 N 438 ( 438-2008-п ) від 07.05.2008 }

{ Установити, що у 2008 році субвенція, передбачена у державному бюджеті ( 107-17 ) місцевим бюджетам на придбання вагонів для комунального електротранспорту (тролейбусів і трамваїв), використовується відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 438 ( 438-2008-п ) від 07.05.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році субвенції з державного бюджету ( 489-16 ) місцевим бюджетам на придбання вагонів для комунального електротранспорту (тролейбусів і трамваїв), що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 1 березня 2007 р. N 350

ПОРЯДОК використання у 2007 році субвенції з державного бюджету ( 489-16 ) місцевим бюджетам на придбання вагонів для комунального електротранспорту (тролейбусів і трамваїв)

1. Цей Порядок визначає механізм використання у 2007 році субвенції з державного бюджету ( 489-16 ) місцевим бюджетам на придбання вагонів для комунального електротранспорту (тролейбусів і трамваїв) (далі - субвенція).

2. Субвенція перераховується місцевим бюджетам згідно з Порядком обслуговування державного бюджету за видатками ( z0716-04 ), затвердженим Державним казначейством, та розподілом, передбаченим додатком N 7 до Закону України "Про Державний бюджет України на 2008 рік та про внесення змін до деяких законодавчих актів України" ( 107-17 ).

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 438 ( 438-2008-п ) від 07.05.2008 }

3. Субвенція надається за умови, що місцевими органами виконавчої влади або органами місцевого самоврядування: { Абзац перший пункту 3 в редакції Постанови КМ N 438 ( 438-2008-п ) від 07.05.2008 }

передбачено виділення з місцевого бюджету та залучення з інших джерел такого самого обсягу коштів для придбання тролейбусів і трамваїв; { Абзац пункту 3 в редакції Постанови КМ N 438 ( 438-2008-п ) від 07.05.2008 }

укладено на 2008 рік договір про організацію надання транспортних послуг відповідно до вимог Закону України "Про міський електротранспорт" ( 1914-15 ). { Абзац пункту 3 в редакції Постанови КМ N 438 ( 438-2008-п ) від 07.05.2008 }

У разі придбання тролейбусів і трамваїв, які є предметом договору лізингу, субвенція може спрямовуватися лише на оплату вартості таких тролейбусів і трамваїв.

4. Рада міністрів Автономної Республіки Крим і облдержадміністрації розподіляють субвенцію між бюджетами міст Автономної Республіки Крим і областей, в яких функціонує міський електротранспорт, з урахуванням наявного парку тролейбусів і трамваїв, рівня його зношеності, протяжності трамвайних і тролейбусних ліній, обсягів транспортної роботи.

5. Субвенція спрямовується на придбання нових тролейбусів і трамваїв вітчизняного виробництва, які повинні відповідати стандартам України. При цьому перевага надається рухомому складу, що має тяговий привід з імпульсним керуванням тяговими двигунами та низький рівень підлоги (для тролейбусів) для перевезення осіб з обмеженими фізичними можливостями.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 438 ( 438-2008-п ) від 07.05.2008 }

5-1. Граничний розмір бюджетних зобов'язань, узятих за загальним фондом державного бюджету, не повинен перевищувати квартального обсягу бюджетних призначень.

Бюджетні зобов'язання за спеціальним фондом державного бюджету беруться лише після надходження коштів до спеціального фонду.

Мінжитлокомунгосп щомісяця до 10 числа наступного періоду повідомляє Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським держадміністраціям про стан надходження коштів до спеціального фонду державного бюджету.

Субвенція спрямовується насамперед на виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державного казначейства.

{ Порядок доповнено пунктом 5-1 згідно з Постановою КМ N 438 ( 438-2008-п ) від 07.05.2008 }

6. Закупівля тролейбусів і трамваїв за рахунок субвенції здійснюється відповідно до законодавства.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 438 ( 438-2008-п ) від 07.05.2008 }

7. Рада міністрів Автономної Республіки Крим, обласні, Київська та Севастопольська міські держадміністрації інформують щомісяця до 20 числа наступного періоду Мінжитлокомунгосп про стан придбання тролейбусів і трамваїв.

{ Пункт 7 із змінами, внесеними згідно з Постановою КМ N 1272 ( 1272-2007-п ) від 31.10.2007 }

8. Складення та подання фінансової звітності про використання субвенції, а також контроль за її цільовим витрачанням здійснюються в установленому законодавством порядку.
