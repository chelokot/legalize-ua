Зареєстровано в Міністерстві юстиції України 27 січня 2004 р. за N 111/8710

Про скасування глави 3 Інструкції, затвердженої наказом МВС України від 22.10.2003 N 1217

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства внутрішніх справ N 1217 ( z0974-03 ) від 22.10.2003, до якого вносились зміни }

На виконання протесту та припису Генеральної прокуратури України на пункти 3.1-3.7 глави 3 Інструкції, затвердженої наказом МВС України від 22 жовтня 2003 року N 1217 ( z0974-03 ), НАКАЗУЮ:

1. Скасувати главу 3 "Затримання транспортних засобів та документів" Інструкції з організації провадження та діловодства у справах про адміністративні порушення правил, норм і стандартів, що стосуються забезпечення дорожнього руху, затвердженої наказом МВС України від 22.10.2003 N 1217 ( z0974-03 ) та зареєстрованої в Міністерстві юстиції України 24.10.2003 за N 974/8295.

2. Департаменту Державної автомобільної інспекції (Каракай С.В.) МВС України підготувати нову редакцію глави 3 відповідно до вимог чинного законодавства.

3. Контроль за виконанням наказу покласти на заступника Міністра внутрішніх справ України генерал-майора міліції Присяжнюка А.Й.

Наказ надіслати за належністю.

Т.в.о. Міністра генерал-лейтенант міліції С.М.Гусаров
