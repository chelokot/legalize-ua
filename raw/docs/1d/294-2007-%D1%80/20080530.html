РОЗПОРЯДЖЕННЯ від 12 травня 2007 р. N 294-р Київ

Про звільнення Апасова С.І. з посади члена Національної комісії з питань регулювання зв'язку України

{ Розпорядження скасовано на підставі Постанови КМ N 1403 ( 1403-2007-п ) від 24.12.2007 - пункт про скасування виключено на підставі Постанови КМ N 490 ( 490-2008-п ) від 28.05.2008 }

{ Дію Розпорядження зупинено згідно з Указом Президента N 708/2007 ( 708/2007 ) від 15.08.2007 - втратив чинність на підставі Указу Президента N 1308/2007 ( 1308/2007 ) від 28.12.2007 }

У зв'язку з порушенням етики поведінки державного службовця (абзац третій та четвертий частини першої статті 5 Закону України "Про державну службу" ( 3723-12 ) та порушенням Присяги державного службовця звільнити Апасова Сергія Івановича з посади члена Національної комісії з регулювання зв'язку України (пункт 6 частини першої статті 30 Закону України "Про державну службу" ( 3723-12 ).
