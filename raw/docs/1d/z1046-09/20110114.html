Про затвердження Положення про зону сервісного обслуговування осіб і транспортних засобів перед пунктами пропуску через державний кордон для міжнародного та міждержавного автомобільного сполучення

{ Із змінами, внесеними згідно з Наказом Адміністрації Державної прикордонної служби N 960 ( z1342-10 ) від 13.12.2010 }

Відповідно до пункту 1 Заходів з розвитку транскордонного співробітництва на 2007 - 2010 роки, наведених у додатку 1 до Державної програми розвитку транскордонного співробітництва на 2007-2010 роки, затвердженої постановою Кабінету Міністрів України від 27.12.2006 N 1819 ( 1819-2006-п ), та пункту 12 Завдань і заходів з виконання Державної цільової правоохоронної програми "Облаштування та реконструкція державного кордону" на період до 2015 року, наведених у додатку 1 до Державної цільової правоохоронної програми "Облаштування та реконструкція державного кордону" на період до 2015 року, затвердженої постановою Кабінету Міністрів України від 13.06.2007 N 831 ( 831-2007-п ), з метою удосконалення порядку створення та функціонування зон обслуговування осіб і транспортних засобів перед пунктами пропуску через державний кордон для міжнародного та міждержавного автомобільного сполучення НАКАЗУЮ:

1. Затвердити Положення про зону сервісного обслуговування осіб і транспортних засобів перед пунктами пропуску через державний кордон для міжнародного та міждержавного автомобільного сполучення (додається).

{ Пункт 1 із змінами, внесеними згідно з Наказом Адміністрації Державної прикордонної служби N 960 ( z1342-10 ) від 13.12.2010 }

2. Управлінню прикордонного контролю та реєстрації Адміністрації Держприкордонслужби України забезпечити подання цього наказу до Міністерства юстиції України на державну реєстрацію.

3. Начальникам регіональних управлінь, начальникам органів охорони державного кордону Державної прикордонної служби України організувати доведення змісту Положення про зону сервісного обслуговування осіб і транспортних засобів перед пунктами пропуску через державний кордон для міжнародного та міждержавного автомобільного сполучення до заінтересованих місцевих органів виконавчої влади, органів місцевого самоврядування та забезпечити контроль за станом його дотримання.

{ Пункт 3 із змінами, внесеними згідно з Наказом Адміністрації Державної прикордонної служби N 960 ( z1342-10 ) від 13.12.2010 }

4. Цей наказ набирає чинності з дня офіційного опублікування.

ЗАТВЕРДЖЕНО Наказ Адміністрації Державної прикордонної служби України 31.08.2009 N 643

Зареєстровано в Міністерстві юстиції України 9 листопада 2009 р. за N 1046/17062

ПОЛОЖЕННЯ про зону сервісного обслуговування осіб і транспортних засобів перед пунктами пропуску через державний кордон для міжнародного та міждержавного автомобільного сполучення

{ У назві та тексті Положення слова "про зону обслуговування" замінено словами "про зону сервісного обслуговування" у відповідних відмінках та числах згідно з Наказом Адміністрації Державної прикордонної служби України N 960 ( z1342-10 ) від 13.12.2010 }

1. Положення про зону сервісного обслуговування осіб і транспортних засобів перед пунктами пропуску через державний кордон для міжнародного та міждержавного автомобільного сполучення розроблено відповідно до Законів України "Про місцеве самоврядування в Україні" ( 280/97-ВР ), "Про місцеві державні адміністрації" ( 586-14 ), "Про охорону навколишнього природного середовища" ( 1264-12 ), "Про забезпечення санітарного та епідемічного благополуччя населення" ( 4004-12 ), Порядку здійснення координації діяльності органів виконавчої влади та органів місцевого самоврядування з питань додержання режимів на державному кордоні, затвердженого постановою Кабінету Міністрів України від 18 січня 1999 року N 48 ( 48-99-п ), Положення про пункти пропуску через державний кордон та пункти контролю, затвердженого постановою Кабінету Міністрів України від 18 серпня 2010 року N 751 ( 751-2010-п ) (далі - Положення про пункти пропуску).

{ Пункт 1 із змінами, внесеними згідно з Наказом Адміністрації Державної прикордонної служби N 960 ( z1342-10 ) від 13.12.2010 }

2. Зона сервісного обслуговування осіб і транспортних засобів перед пунктами пропуску через державний кордон для міжнародного та міждержавного автомобільного сполучення (далі - зона обслуговування) - певна територія перед пунктом пропуску, на якій юридичні та фізичні особи - підприємці надають не заборонені законодавством України послуги.

3. У зоні обслуговування можуть функціонувати підприємства та організації з надання послуг з харчування, медичної допомоги, торговельних, страхових, банківських, поштових, телефонних, юридичних, митно-брокерських, готельних, санітарно-гігієнічних, технічного обслуговування та заправляння паливом автомобільного транспорту, паркувальних та інших, не заборонених законодавством України послуг. Проектування зони обслуговування здійснюється з урахуванням категорії пункту пропуску через державний кордон, його проектної пропускної спроможності, під'їзних шляхів до нього та інших особливостей.

4. Під час розроблення проекту будівництва зони обслуговування потрібно передбачити:

безперешкодний рух осіб і транспортних засобів під'їзними шляхами до пункту пропуску;

єдиний архітектурний стиль та зовнішній вигляд будівель і споруд;

забезпечення належного санітарного й протипожежного стану, освітлення та огородження зони обслуговування;

відповідне інформаційне забезпечення про напрямки руху і межі зони обслуговування, перелік послуг, що надаються, розміщення та графіки роботи підприємств (організацій) у зоні обслуговування, довідкові телефони;

установлення системи гучномовного оповіщення осіб, дорожних знаків, інших пристосувань та обладнання, що забезпечують безпеку дорожнього руху.

5. Проектування зони обслуговування здійснюється з дотриманням вимог Земельного кодексу України ( 2768-14 ), Законів України "Про дорожній рух" ( 3353-12 ), "Про автомобільні дороги" ( 2862-15 ), а також пункту 17 Положення про прикордонний режим, затвердженого постановою Кабінету Міністрів України від 27 липня 1998 року N 1147 ( 1147-98-п ), та Положення про пункти пропуску ( 1203-2000-п ).

6. Не допускається:

розташування зони обслуговування між пунктом пропуску та державним кордоном України;

здійснення будівництва приміщень, споруд та інших об'єктів, не передбачених проектом будівництва (реконструкції) зони обслуговування.

7. Відносини органів місцевого самоврядування з підприємствами та організаціями, які функціонують у зоні обслуговування, будуються відповідно до вимог статей 17, 18 Закону України "Про місцеве самоврядування в Україні" ( 280/97-ВР ).

8. До зони обслуговування можуть входити:

місця стоянки транспортних засобів, у тому числі з небезпечними або великогабаритними вантажами, торговельні точки, готелі, заклади харчування, пункти надання медичної допомоги, станції (пункти) технічного обслуговування, автомобільні заправні станції, будівлі (приміщення), у яких надаються страхові, банківські, телекомунікаційні, митно-брокерські послуги тощо, санітарно-гігієнічні споруди для подорожніх та працівників (туалети, сміттєзбірники).

9. Розміщення та функціонування в зоні обслуговування підприємств і організацій здійснюються відповідно до вимог чинного законодавства. Усі будинки, споруди та об'єкти мають бути пристосовані до використання особами з фізичними вадами.

В'їзд (виїзд) до (із) зони обслуговування здійснюється безкоштовно.
