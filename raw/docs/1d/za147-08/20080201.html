ПРАВЛІННЯ ПЕНСІЙНОГО ФОНДУ УКРАЇНИ

ПОСТАНОВА

01.02.2008 N 4-3

Зареєстровано в Міністерстві юстиції України 22 лютого 2008 р. за N 147/14838

Про визнання такою, що втратила чинність, постанови правління Пенсійного фонду України від 31.12.2003 N 22-1

Відповідно до пункту 12 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261 ( 1261-2007-п ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Визнати такою, що втратила чинність, постанову правління Пенсійного фонду України від 31.12.2003 N 22-1 ( za085-04 ) "Про затвердження Тимчасової методики визначення показників середньої заробітної плати працівників, зайнятих у галузях національної економіки, для призначення пенсій відповідно до Закону України "Про загальнообов'язкове державне пенсійне страхування", зареєстровану в Міністерстві юстиції України 20.01.2004 за N 85/8684.

2. Юридичному управлінню (Рябцева Т.Б.) подати цю постанову для державної реєстрації до Міністерства юстиції України.

3. Контроль за виконанням цієї постанови покласти на першого заступника Голови правління В.О.Кравчука

Голова правління О.Б.Зарудний
