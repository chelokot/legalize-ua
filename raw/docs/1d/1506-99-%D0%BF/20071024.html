КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 серпня 1999 р. N 1506 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову деяких державних комісій та інших органів, утворених Кабінетом Міністрів України

( Із змінами, внесеними згідно з Постановами КМ N 133 ( 133-2000-п ) від 25.01.2000 N 559 ( 559-2000-п ) від 27.03.2000 N 753 ( 753-2005-п ) від 18.08.2005 )

Кабінет Міністрів України постановляє:

Затвердити Першого віце-прем'єр-міністра Кінаха Анатолія Кириловича:

головою Державної комісії з питань транспортних коридорів ( 1324-96-п ); головою Державної комісії з питань запобігання та усунення можливих негативних наслідків комп'ютерної кризи 2000 року;

головою Міжвідомчої координаційної комісії з питань реконструкції житлових будинків перших масових серій;

головою Міжгалузевої комісії з питань навігації і управління транспортними засобами та іншими рухомими об'єктами;

( Абзац шостий втратив чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

головою Державної комісії з питань зв'язку і радіочастот; головою Міжвідомчої комісії із забезпечення виконання контракту N 1346/38 /"Tank"/Т-SOUD/ DGDP /РС-ЗА на постачання спецтехніки;

головою Міжвідомчої комісії з питань координації діяльності міністерств та інших центральних органів виконавчої влади, пов'язаної з реалізацією Концепції державної промислової політики України;

головою Міжвідомчої комісії з питань проведення консервації основних виробничих фондів підприємств, які мають стратегічне значення для економіки і безпеки держави;

головою Міжвідомчої комісії з питань формування промислово-фінансових груп;

керівником групи супроводження проектів програми транспортування нафти та газу до Європи /TACIS - INOGATE/;

головою Міжвідомчої комісії з вивчення комплексу економічних і соціальних проблем, пов'язаних з будівництвом Криворізького гірничо-збагачувального комбінату окислених руд;

головою Ради експортерів при Кабінеті Міністрів України;

головою Української частини Українсько-Туркменської комісії з питань економічного співробітництва;

головою Української частини Спільної міжурядової Українсько-Азербайджанської комісії з питань економічного співробітництва;

головою Української частини спільної Міждержавної Українсько-Казахстанської комісії з економічного співробітництва;

( Абзац сімнадцятий втратив чинність на підставі Постанови КМ N 559 ( 559-2000-п ) від 27.03.2000 ) головою Координаційної ради з питань врегулювання кризових ситуацій у вугільній промисловості;

головою Міжвідомчої координаційної ради з питань реалізації Кредитної угоди (Проект розвитку ринку електроенергетики) між Україною і Міжнародним банком реконструкції та розвитку;

( Абзац дев'ятнадцятий втратив чинність на підставі Постанови КМ N 133 ( 133-2000-п ) від 25.01.2000 ) головою спостережної ради Національної акціонерної компанії "Нафтогаз України";

головою Урядової комісії з питань розрахунків за спожиті енергоносії;

головою робочої групи з аналізу застосування податкового законодавства України та опрацювання проекту Податкового кодексу України;

головою робочої групи з розгляду і опрацювання проектів фінансування і розвитку об'єктів енергетики, металургійної, вугільної та інших галузей промисловості Донецької області, запропонованих діловими колами Німеччини;

головою Організаційного комітету з підготовки та проведення в Україні Європейського енергетичного форуму "Ринкові перетворення в енергетиці. Перспективи на початок третього тисячоліття".

Увільнити Куратченка Володимира Олександровича від обов'язків голови зазначених органів.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
