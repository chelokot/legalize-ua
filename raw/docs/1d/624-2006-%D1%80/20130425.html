Про встановлення строку виконання операцій з ремонту бронетранспортерів на митній території України

Стан: Втратив чинність

Ідентифікатор: 624-2006-р

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 грудня 2006 р. N 624-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання операцій з ремонту бронетранспортерів на митній території України

1. Відповідно до частини третьої статті 232 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити строк виконання операцій з ремонту бронетранспортерів за кодом УКТЗЕД 8710 00 00 00 ( 2371г-14 ) на митній території України 270 днів.

2. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України В.ЯНУКОВИЧ
