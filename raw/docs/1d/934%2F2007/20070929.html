Президент України; Указ від 29.09.2007 № 934/2007

Про зупинення дії розпорядження Кабінету Міністрів України від 11 вересня 2007 року N 714-р

Стан: Втратив чинність

Ідентифікатор: 934/2007

Текст документа від 29.09.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії розпорядження Кабінету Міністрів України від 11 вересня 2007 року N 714-р

{ Додатково див. Конституційне подання Президента ( n0032100-07 ) від 29.09.2007 }

Кабінетом Міністрів України 11 вересня 2007 року видано розпорядження N 714-р ( 714-2007-р ) "Про призначення Шейка А.М. керівником торговельно-економічної місії у складі Посольства України в Сирійській Арабській Республіці". Прийняття Кабінетом Міністрів України цього рішення ( 714-2007-р ) здійснено без погодження Президентом України відповідної кандидатури для призначення на посаду керівника торговельно-економічної місії у складі Посольства України в Сирійській Арабській Республіці.

Таким чином, прийнявши рішення ( 714-2007-р ), про яке йдеться, Кабінет Міністрів України проігнорував норму пункту 3 частини першої статті 106 Конституції України ( 254к/96-ВР ), за якою Президент України здійснює керівництво зовнішньополітичною діяльністю держави.

Назване рішення ( 714-2007-р ) прийнято й усупереч виданому Президентом України в порядку здійснення зазначеного конституційного повноваження Указу від 30 квітня 1994 року N 200 ( 200/94 ) "Про торговельно-економічну місію у складі закордонної дипломатичної установи України" (зі змінами, внесеними Указом від 26 лютого 2007 року N 145) ( 145/2007 ), згідно з яким кандидатура для призначення на посаду керівника торговельно-економічної місії попередньо погоджується з Президентом України.

Тим самим Кабінетом Міністрів України проігноровано і норми частини третьої статті 106, частини третьої статті 113, пункту 1 статті 116 Конституції України ( 254к/96-ВР ), відповідно до яких укази Президента України, видані на основі та на виконання Основного Закону України ( 254к/96-ВР ), є обов'язковими до виконання на території України, Кабінет Міністрів України має керуватися у своїй діяльності Конституцією України ( 254к/96-ВР ) та прийнятими відповідно до Конституції України ( 254к/96-ВР ) указами Президента України, на Кабінет Міністрів України покладено забезпечення виконання, зокрема, актів Президента України.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 11 вересня 2007 року N 714-р ( 714-2007-р ) "Про призначення Шейка А.М. керівником торговельно-економічної місії у складі Посольства України в Сирійській Арабській Республіці".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
