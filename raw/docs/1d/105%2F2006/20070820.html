Президент України; Указ від 03.02.2006 № 105/2006

Про зміни у складі Вищої кваліфікаційної комісії суддів України

Стан: Чинний

Ідентифікатор: 105/2006

Текст документа від 20.08.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зміни у складі Вищої кваліфікаційної комісії суддів України

{ Із змінами, внесеними згідно з Указом Президента N 720/2007 ( 720/2007 ) від 20.08.2007 }

Відповідно до частини третьої статті 76 Закону України "Про судоустрій України" ( 3018-14 ) постановляю:

1. Призначити членами Вищої кваліфікаційної комісії суддів України:

КИРИЛЮКА Руслана Івановича - Керівника Служби з представництва у судах України інтересів Президента України та створених ним консультативних, дорадчих та інших допоміжних органів і служб Секретаріату Президента України;

ПОЛУДЬОННОГО Миколу Миколайовича - Радника Президента України - Керівника Головної служби правової політики Секретаріату Президента України.

{ Пункт 1 із змінами, внесеними згідно з Указом Президента N 720/2007 ( 720/2007 ) від 20.08.2007 }

2. Увільнити Островську М.А. та Коваленка В.В. від виконання обов'язків членів Вищої кваліфікаційної комісії суддів України, у зв'язку з чим визнати такими, що втратили чинність:

Указ Президента України від 6 березня 2003 року N 200 ( 200/2003 ) "Про призначення членів Вищої кваліфікаційної комісії суддів України";

Указ Президента України від 13 серпня 2004 року N 884 ( 884/2004 ) "Про зміни у складі Вищої кваліфікаційної комісії суддів України".

Президент України В.ЮЩЕНКО
