Про спеціально уповноважені органи для визначення та контролю особливих властивостей та інших характеристик товарів

Стан: Втратив чинність

Ідентифікатор: 149-2001-р

Текст документа від 19.06.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 квітня 2001 р. N 149-р Київ

Про спеціально уповноважені органи для визначення та контролю особливих властивостей та інших характеристик товарів

{ Із змінами, внесеними згідно з Розпорядженням КМ N 322-р ( 322-2002-р ) від 13.06.2002 Постановами КМ N 792 ( 792-2004-п ) від 21.06.2004 N 754 ( 754-2006-п ) від 25.05.2006 N 1413 ( 1413-2009-п ) від 23.12.2009 N 200 ( 200-2012-п ) від 22.02.2012 N 379 ( 379-2015-п ) від 27.05.2015 }

Відповідно до статті 10 Закону України "Про охорону прав на зазначення походження товарів" ( 752-14 ) покласти повноваження щодо визначення та контролю особливих властивостей, певних якостей та інших характеристик товарів на:

Мінагрополітики - щодо товарів сільськогосподарського виробництва;

Мінкультури - щодо виробів художніх народних промислів;

Державну службу з питань геодезії, картографії та кадастру - щодо визначення меж географічних місць, з якими пов'язані особливі властивості, певні якості та інші характеристики товарів; { Абзац четвертий із змінами, внесеними згідно з Постановами КМ N 792 ( 792-2004-п ) від 21.06.2004, N 754 ( 754-2006-п ) від 25.05.2006, N 1413 ( 1413-2009-п ) від 23.12.2009, N 200 ( 200-2012-п ) від 22.02.2012, N 379 ( 379-2015-п ) від 27.05.2015 }

МОЗ - щодо продуктів харчування, продовольчої сировини та мінеральних природних вод.

( Розпорядження доповнено абзацом згідно з Розпорядженням КМ N 322-р ( 322-2002-р ) від 13.06.2002 )
