Текст документа від 18.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 квітня 2006 р. N 519 Київ

Про затвердження Порядку використання у 2006 році коштів, передбачених у державному бюджеті для здійснення заходів щодо ліквідації наслідків надзвичайної ситуації на території Мелітопольського району Запорізької області

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2006 році коштів, передбачених у державному бюджеті ( 3235-15 ) для здійснення заходів щодо ліквідації наслідків надзвичайної ситуації на території Мелітопольського району Запорізької області, що додається.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 18 квітня 2006 р. N 519

ПОРЯДОК використання у 2006 році коштів, передбачених у державному бюджеті ( 3235-15 ) для здійснення заходів щодо ліквідації наслідків надзвичайної ситуації на території Мелітопольського району Запорізької області

1. Цей Порядок визначає механізм використання у 2006 році коштів, передбачених у державному бюджеті ( 3235-15 ) для МНС за програмою "Заходи щодо ліквідації наслідків надзвичайної ситуації на території Мелітопольського району Запорізької області" (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються МНС на здійснення заходів, що визначені Програмою ліквідації наслідків надзвичайної ситуації на території 275 артилерійської бази ракет і боєприпасів у с. Новобогданівці Мелітопольського району Запорізької області на 2006-2008 роки, затвердженою постановою Кабінету Міністрів України від 25 січня 2006 р. N 47 ( 47-2006-п ) (Офіційний вісник України, 2006 р., N 4, ст. 161).

3. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

4. Перерахування бюджетних коштів провадиться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

5. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
