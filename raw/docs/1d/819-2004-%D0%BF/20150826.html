Кабінет Міністрів України; Постанова від 29.06.2004 № 819

Про внесення зміни до переліку органів ліцензування та переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності

Стан: Втратив чинність

Ідентифікатор: 819-2004-п

Текст документа від 26.08.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 червня 2004 р. N 819 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 609 ( 609-2015-п ) від 05.08.2015 }

Про внесення зміни до переліку органів ліцензування та переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності

Кабінет Міністрів України постановляє:

Внести до графи "Вид господарської діяльності" переліку органів ліцензування, затвердженого постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001), та переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності, затвердженого постановою Кабінету Міністрів України від 4 липня 2001 р. N 756 ( 756-2001-п ) (Офіційний вісник України, 2001 р., N 27, ст. 1212), зміну, доповнивши відповідно пункти 29 і 47 після слів "надання послуг в галузі криптографічного захисту інформації" словами "(крім послуг електронного цифрового підпису)".

Прем'єр-міністр України В.ЯНУКОВИЧ
