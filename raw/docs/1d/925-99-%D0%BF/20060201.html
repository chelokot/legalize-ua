ПОСТАНОВА від 27 травня 1999 р. N 925 Київ

( Постанова втратила чинність на підставі Постанови КМ N 79 ( 79-2006-п ) від 01.02.2006 )

Про затвердження нового складу Ради у справах інвалідів при Кабінеті Міністрів України

Кабінет Міністрів України постановляє:

1. Прийняти погоджені пропозиції Міністерства праці та соціальної політики, громадських організацій інвалідів про затвердження нового складу Ради у справах інвалідів при Кабінеті Міністрів України, створеної постановою Кабінету Міністрів України від 12 грудня 1994 р. N 837 ( 837-94-п ) (ЗП України, 1995 р., N 2, ст. 46).

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 28 жовтня 1997 р. N 1188 ( 1188-97-п ).
