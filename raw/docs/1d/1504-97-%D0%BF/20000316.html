Стан: Втратив чинність

Текст документа від 16.03.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 грудня 1997 р. N 1504 Київ

( Постанова втратила чинність на підставі Постанови КМ N 501 ( 501-2000-п ) від 16.03.2000 )

Про внесення змін до деяких постанов Кабінету Міністрів України

( Із змінами, внесеними згідно з Постановами КМ N 56 ( 56-98-п ) від 21.01.98 N 677 ( 677-98-п ) від 18.05.98 )

З метою наповнення доходної частини бюджету Кабінет Міністрів України постановляє:

Затвердити зміни, що вносяться до деяких постанов Кабінету Міністрів України, що додаються.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

Інд. 67

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 31 грудня 1997 р. N 1504

ЗМІНИ, що вносяться до деяких постанов Кабінету Міністрів України

1. У пункті 4 постанови Кабінету Міністрів України від 9 грудня 1991 р. N 353 ( 353-91-п ) "Питання Державної інспекції України по контролю за цінами" (ЗП України, 1992 р., N 1, ст.6) цифри "10" замінити цифрою "5".

( Пункт 2 виключено на підставі Постанови КМ N 56 ( 56-98-п ) від 21.01.98 ) 2. У пункті 6 постанови Кабінету Міністрів України від 18 лютого 1993 р. N 125 ( 125-93-п ) "Про умови оплати праці працівників митної системи" цифри "30" замінити цифрою "5".

( Пункт 3 виключено на підставі Постанови КМ N 677 ( 677-98-п ) від 18.05.98 ) 3. У пункті 9 постанови Кабінету Міністрів України від 5 липня 1993 р. N 515 ( 515-93-п ) "Питання державної контрольно-ревізійної служби в Україні" (ЗП України, 1993 р., N 11, ст.253) цифри "15" замінити цифрою "5".
