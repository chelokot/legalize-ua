Текст документа від 14.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 вересня 2011 р. N 963 Київ

Про внесення змін до постанови Кабінету Міністрів України від 27 грудня 2010 р. N 1224

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 27 грудня 2010 р. N 1224 ( 1224-2010-п ) "Про затвердження Порядку обчислення і накопичення електронними контрольно-касовими апаратами сум податку на додану вартість" (Офіційний вісник України, 2011 р., N 1, ст. 9) такі зміни:

у назві та пункті 1 постанови ( 1224-2010-п ) слова "електронними контрольно-касовими апаратами" замінити словами "реєстраторами розрахункових операцій";

у Порядку ( 1224-2010-п ), затвердженому зазначеною постановою:

у назві Порядку ( 1224-2010-п ) слова "електронними контрольно-касовими апаратами" замінити словами "реєстраторами розрахункових операцій";

у пункті 1 слова "Електронний контрольно-касовий апарат (далі - касовий апарат)" замінити словами "Реєстратор розрахункових операцій";

у тексті Порядку ( 1224-2010-п ) слова "касовий апарат" в усіх відмінках замінити словами "реєстратор розрахункових операцій" у відповідному відмінку.

Прем'єр-міністр України М.АЗАРОВ
