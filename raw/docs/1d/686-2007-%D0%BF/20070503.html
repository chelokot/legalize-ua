Стан: Чинний

Ідентифікатор: 686-2007-п

Текст документа від 03.05.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 травня 2007 р. N 686 Київ

Про відновлення дії постанов Кабінету Міністрів України від 11 липня 2001 р. N 788 та від 17 березня 2003 р. N 351 і внесення зміни до постанови Кабінету Міністрів України від 8 червня 1998 р. N 840

Кабінет Міністрів України постановляє:

1. Відновити дію постанов Кабінету Міністрів України від 11 липня 2001 р. N 788 ( 788-2001-п ) "Про доповнення постанови Кабінету Міністрів України від 8 червня 1998 р. N 840" (Офіційний вісник України, 2001 р., N 28, ст. 1250) і від 17 березня 2003 р. N 351 ( 351-2003-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 8 червня 1998 р. N 840" (Офіційний вісник України, 2003 р., N 12, ст. 537).

У зв'язку з цим скасувати пункт 2 постанови Кабінету Міністрів України від 21 липня 2005 р. N 611 ( 611-2005-п ) "Про доповнення постанови Кабінету Міністрів України від 8 червня 1998 р. N 840 та скасування постанов Кабінету Міністрів України від 11 липня 2001 р. N 788 і від 17 березня 2003 р. N 351" (Офіційний вісник України, 2005 р., N 30, ст. 1795).

2. Внести зміну до постанови Кабінету Міністрів України від 8 червня 1998 р. N 840 ( 840-98-п ) "Про утворення лізингової компанії "Укртранслізинг", виключивши пункт 8.
