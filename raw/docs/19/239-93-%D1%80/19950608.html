Кабінет Міністрів України; Розпорядження від 19.04.1993 № 239-р

Про затвердження робочої групи для вирішення питань, пов'язаних із застосуванням контрольно-касових апаратів і товарно-касових книг при розрахунках із споживачами у сфері торгівлі, громадського харчування і послуг

Стан: Втратив чинність

Ідентифікатор: 239-93-р

Текст документа від 08.06.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 квітня 1993 р. N 239-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 398 ( 398-95-п ) від 08.06.95 )

( Із змінами, внесеними згідно з Розпорядженнями КМ N 496-р ( 496-93-р ) від 14.07.93 N 697-р ( 697-93-р ) від 08.09.93 )

З метою подання медичної допомоги і своєчасного вирішення питань, пов'язаних із застосуванням контрольно-касових апаратів і товарно-касових книг при розрахунках із споживачами у сфері торгівлі, громадського харчування і послуг, затвердити робочу групу в такому складі:

ГУРЕЄВ

Василь Миколайович - заступник Міністра економіки (голова робочої групи)

ШИТРЯ - перший заступник голови Головної Олексій Іванович державної податкової інспекції (заступник голови робочої групи)

ПАЗУХА

Микола Дмитрович - начальник відділу Мінекономіки (відповідальний секретар)

БОГДАН - начальник управління Головної Анатолій Володимирович державної податкової інспекції

МОСКАТ - начальник управління Мінстату

Василь Федорович

ПАРХОМЕНКО - начальник управління Мінфіну

Валерій Миколайович

КОЖУРА - начальник управління Державного Іван Васильович комітету у справах захисту прав споживачів

ПРИШЛЯК - начальник управління Української Олег Йосипович спілки споживчих товариств (за згодою)

ХІВРИЧ - начальник відділу Мінфіну

Віра Дмитрівна

ЧЕПУРНИЙ - заступник голови Укрплодоовочпрому Микола Іванович

УХНАЛЬ - заступник голови ЦК профспілки Тамара Миколаївна працівників торгівлі та громадського харчування (за згодою)

ЖОВТУХА - начальник відділу Мінекономіки

Володимир Опанасович

МОЦАР - старший оперуповноважений

Віктор Борисович управління по захисту економіки від злочинних посягань МВС

ВАКУЛЕНКО - заступник начальника управління Михайло Володимирович Мінмашпрому

КОВАЛЬЧУК - заступник генерального директора

Адам Захарович Київського ВО "Електронмаш"

КОВАЛЕНКО - заступник директора науково-

Микола Гнатович дослідного інституту проблем механіки "Ритм" при Київському політехнічному інституті

БАХАНКОВА - заступник генерального директора

Валентина Олександрівна державної комунальної фірми "Київ".
