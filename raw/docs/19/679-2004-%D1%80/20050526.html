РОЗПОРЯДЖЕННЯ від 22 вересня 2004 р. N 679-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 162-р ( 162-2005-р ) від 26.05.2005 )

Про затвердження складу наглядової ради Національної акціонерної компанії "Енергетична компанія України"

На часткову зміну пункту 11 постанови Кабінету Міністрів України від 22 червня 2004 р. N 794 ( 794-2004-п ) (Офіційний вісник України, 2004 р., N 25, ст. 1651) затвердити склад наглядової ради НАК "Енергетична компанія України", що додається.
