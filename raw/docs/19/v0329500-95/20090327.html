ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 329 від 29.12.95 м.Київ

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про затвердження нової редакції Положення "Про порядок

надання резидентам України індивідуальних ліцензій та свідоцтв про реєстрацію на одержання кредитів в іноземній валюті від іноземних кредиторів"

{ Із змінами, внесеними згідно з Постановою Національного банку

N 144 ( v0442500-97 ) від 07.05.97 }

Розглянувши проект нової редакції Положення "Про порядок надання резидентам України індивідуальних ліцензій та свідоцтв про реєстрацію на одержання кредитів в іноземній валюті від іноземних кредиторів", який підготовлено на виконання доручення Президента України від 18 жовтня 1995 року за N 1-14/601 щодо оперативного надання ліцензій на отримання іноземних кредитів банками і підприємствами, Правління ПОСТАНОВЛЯЄ:

1. Затвердити в новій редакції Положення "Про порядок надання резидентам України індивідуальних ліцензій та свідоцтв про реєстрацію на одержання кредитів в іноземній валюті від іноземних кредиторів".

2. Надіслати Положення Кримському республіканському, обласним та по м.Києву управлінням Національного банку України й уповноваженим банкам для керівництва і використання в роботі.

3. Контроль за виконанням цієї постанови покласти на заступника Голови Правління О.І.Кірєєва.

4. З введенням цього Положення втрачає силу Положення "Про порядок надання резидентам України індивідуальних ліцензій на одержання кредитів в іноземній валюті від іноземних кредиторів", затверджене постановою Правління Національного банку України від 28.09.95 N 244 ( v0293500-95 ).

Голова Правління В.А.Ющенко { Положення про порядок надання резидентам України індивідуальних ліцензій та свідоцтв про реєстрацію на одержання кредитів в іноземній валюті від іноземних кредиторів втратило чинність на підставі Постанови Національного банку N 144 ( v0442500-97 ) від 07.05.97 }
