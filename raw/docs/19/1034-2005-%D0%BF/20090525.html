Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 жовтня 2005 р. N 1034 Київ

Деякі питання Міністерства будівництва, архітектури та житлово-комунального господарства

{ Із змінами, внесеними згідно з Постановою КМ N 464 ( 464-2009-п ) від 13.05.2009 }

На виконання Указу Президента України від 1 червня 2005 р. N 898 ( 898/2005 ) "Про Міністерство будівництва, архітектури та житлово-комунального господарства України" Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

2. Взяти до відома, що Міністерство будівництва, архітектури та житлово-комунального господарства розміщується по вул. Великій Житомирській, 9, та вул. Димитрова, 24, у м. Києві.
