КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 вересня 2010 р. N 1932-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Питання виконання Указу Президента України від 2 липня 2010 року N 747 ( 747/2010 )

{ Із змінами, внесеними згідно з Постановою КМ N 285 ( 285-2011-п ) від 23.03.2011 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників, що здійснюють адміністративні та виконавчі функції в Координаційному центрі з упровадження економічних реформ, до таких категорій посад державних службовців:

друга - керівник Координаційного центру, заступник керівника Координаційного центру, координатор упровадження реформ, керівник управління, заступник керівника управління, завідувач відділу у складі управління; { Абзац другий із змінами, внесеними згідно з Постановою КМ N 285 ( 285-2011-п ) від 23.03.2011 }

третя - заступник завідувача відділу у складі управління, головний консультант, старший консультант.

Прем'єр-міністр України М.АЗАРОВ
