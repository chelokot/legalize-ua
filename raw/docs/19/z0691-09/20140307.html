Про внесення змін до деяких наказів Держекспортконтролю

{ Із змінами, внесеними згідно з Наказом Державної служби експортного контролю N 8 ( z0173-10 ) від 26.01.2010 Наказом Міністерства економічного розвитку і торгівлі N 74 ( z0304-14 ) від 27.01.2014 }

Відповідно до Положення про Державну службу експортного контролю України, затвердженого постановою Кабінету Міністрів України від 13.06.2007 N 830 ( 830-2007-п ), та у зв'язку із затвердженням нової структури та штатного розпису Держекспортконтролю НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства економічного розвитку і торгівлі N 74 ( z0304-14 ) від 27.01.2014 }

{ Пункт 2 фактично втратив чинність у зв'язку з втратою чинності Наказу Державної служби експортного контролю N 38 ( z0211-04 ) від 10.02.2004 до якого вносились зміни } 2. У пункті 1.5 Правил розгляду справ про порушення юридичними особами вимог законодавства в галузі державного експортного контролю, затверджених наказом Держекспортконтролю від 10.02.2004 N 38 ( z0211-04 ) та зареєстрованих в Міністерстві юстиції України 19.02.2004 за N 211/8810 (із змінами), слова "відділ політико-правової експертизи та попередження правопорушень" замінити словами "відділ правозастосування".

3. Заступнику начальника управління - начальнику відділу розробки нормативних актів та забезпечення діяльності в міжнародних режимах експортного контролю міжнародно-правового управління Лазаренку Ю.Г. забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України в установленому порядку.

4. Начальнику загального відділу адміністративно-господарського управління Терещенку А.Б. наказ довести до співробітників Держекспортконтролю.

5. Контроль за виконанням цього наказу покласти на заступника Голови Держекспортконтролю Решетілова І.В.

6. Цей наказ набирає чинності з дня його офіційного опублікування.

Голова Держекспортконтролю Ю.А.Петроченко
