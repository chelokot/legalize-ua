Про віднесення посади державного реєстратора до відповідної категорії посад в органах місцевого самоврядування

Стан: Чинний

Ідентифікатор: 673-2004-р

Текст документа від 11.12.2019:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 вересня 2004 р. N 673-р Київ

Про віднесення посади державного реєстратора до відповідної категорії посад в органах місцевого самоврядування

{ Назва Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 1334-р ( 1334-2019-р ) від 11.12.2019 }

{ Із змінами, внесеними згідно з Постановою КМ N 703 ( 703-2013-п ) від 14.08.2013 Розпорядженням КМ N 1334-р ( 1334-2019-р ) від 11.12.2019 }

{ Пункт 1 втратив чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

2. Відповідно до статті 14 Закону України "Про службу в органах місцевого самоврядування" ( 2493-14 ) віднести посаду:

державного реєстратора виконавчого органу міської (міста обласного, республіканського в Автономній Республіці Крим, районного значення), селищної ради до п’ятої категорії посад в органах місцевого самоврядування;

державного реєстратора виконавчого органу сільської ради до шостої категорії посад в органах місцевого самоврядування.

{ Пункт 2 в редакції Розпорядження КМ N 1334-р ( 1334-2019-р ) від 11.12.2019 }
