{ Указ втратив чинність на підставі Указу Президента N 434/2018 ( 434/2018 ) від 21.12.2018 }

Про внесення зміни до Указу Президента України від 26 березня 2002 року N 301

Внести до Переліку посад, приписаних до дипломатичних рангів України, затвердженого Указом Президента України від 26 березня 2002 року N 301 ( 301/2002 ) "Про Перелік посад, приписаних до дипломатичних рангів України" (зі змінами, внесеними Указами від 5 березня 2004 року N 280 ( 280/2004 ), від 28 листопада 2007 року N 1157 ( 1157/2007 ), від 23 січня 2008 року N 46 ( 46/2008 ), від 19 грудня 2008 року N 1186 ( 1186/2008 ) та від 11 жовтня 2010 року N 944) ( 944/2010 ) зміну, доповнивши розділ "Надзвичайний і Повноважний Посланник другого класу" новим абзацом другим такого змісту:

"Надзвичайний і Повноважний Посол України".

У зв'язку з цим абзаци другий - восьмий розділу вважати відповідно абзацами третім - дев'ятим.

Президент України В.ЯНУКОВИЧ
