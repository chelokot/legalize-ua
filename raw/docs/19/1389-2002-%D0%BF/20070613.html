КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 вересня 2002 р. N 1389 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 818 ( 818-2007-п ) від 13.06.2007 }

Про колегію Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

Кабінет Міністрів України постановляє:

1. На зміну пункту 1 постанови Кабінету Міністрів України від 28 серпня 2002 р. N 1309 ( 1309-2002-п ) "Про колегію Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" дозволити Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи мати колегію у кількості 17 осіб.

2. Затвердити членом колегії Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи з правом дорадчого голосу Гошовського Володимира Сергійовича (за згодою).

Прем'єр-міністр України А.КІНАХ
