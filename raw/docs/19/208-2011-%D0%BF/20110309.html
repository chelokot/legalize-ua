Кабінет Міністрів України; Постанова, Перелік від 09.03.2011 № 208

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань власних надходжень бюджетних установ

Стан: Чинний

Ідентифікатор: 208-2011-п

Текст документа від 09.03.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 березня 2011 р. N 208 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань власних надходжень бюджетних установ

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, постанови Кабінету Міністрів України з питань власних надходжень бюджетних установ згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 9 березня 2011 р. N 208

ПЕРЕЛІК постанов Кабінету Міністрів України з питань власних надходжень бюджетних установ, що втратили чинність

1. Постанова Кабінету Міністрів України від 17 травня 2002 р. N 659 ( 659-2002-п ) "Про затвердження переліку груп власних надходжень бюджетних установ, вимог щодо їх утворення та напрямів використання" (Офіційний вісник України, 2002 р., N 21, ст. 1032).

2. Постанова Кабінету Міністрів України від 11 жовтня 2002 р. N 1508 ( 1508-2002-п ) "Про внесення зміни в додаток 1 до постанови Кабінету Міністрів України від 17 травня 2002 р. N 659" (Офіційний вісник України, 2002 р., N 42, ст. 1932).

3. Постанова Кабінету Міністрів України від 27 червня 2003 р. N 1002 ( 1002-2003-п ) "Про доповнення переліку груп власних надходжень бюджетних установ, вимог щодо їх утворення та напрямів використання" (Офіційний вісник України, 2003 р., N 27, ст. 1332).

4. Постанова Кабінету Міністрів України від 26 грудня 2003 р. N 2025 ( 2025-2003-п ) "Про доповнення переліку груп власних надходжень бюджетних установ, вимог щодо їх утворення та напрямів використання" (Офіційний вісник України, 2003 р., N 52, ст. 2799).

5. Пункт 2 постанови Кабінету Міністрів України від 29 квітня 2004 р. N 554 ( 554-2004-п ) "Про затвердження Порядку використання коштів виконавчого провадження" (Офіційний вісник України, 2004 р., N 17, ст. 1184; 2010 р., N 1, ст. 30).

6. Постанова Кабінету Міністрів України від 8 вересня 2004 р. N 1179 ( 1179-2004-п ) "Про доповнення додатка 2 до постанови Кабінету Міністрів України від 17 травня 2002 р. N 659" (Офіційний вісник України, 2004 р., N 36, ст. 2402).

7. Пункт 12 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 17 листопада 2004 р. N 1572 ( 1572-2004-п ) (Офіційний вісник України, 2004 р., N 46, ст. 3055).

8. Пункт 13 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 20 квітня 2005 р. N 305 ( 305-2005-п ) (Офіційний вісник України, 2005 р., N 16, ст. 845).

9. Пункт 25 змін, що вносяться до актів Кабінету Міністрів України з питань діяльності органів і установ виконання покарань, затверджених постановою Кабінету Міністрів України від 1 серпня 2006 р. N 1074 ( 1074-2006-п ) (Офіційний вісник України, 2006 р., N 31, ст. 2233).

10. Пункт 22 змін, що вносяться до актів Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 8 грудня 2006 р. N 1700 ( 1700-2006-п ) (Офіційний вісник України, 2006 р., N 50, ст. 3324).

11. Постанова Кабінету Міністрів України від 11 лютого 2009 р. N 90 ( 90-2009-п ) "Про доповнення додатка 1 до постанови Кабінету Міністрів України від 17 травня 2002 р. N 659" (Офіційний вісник України, 2009 р., N 11, ст. 335).

12. Пункт 1 змін, що вносяться до постанов Кабінету Міністрів України з питань фінансової підтримки підприємств агропромислового комплексу, затверджених постановою Кабінету Міністрів України від 3 вересня 2009 р. N 953 ( 953-2009-п ) (Офіційний вісник України, 2009 р., N 69, ст. 2381).

13. Пункт 9 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 2 грудня 2009 р. N 1290 ( 1290-2009-п ) (Офіційний вісник України, 2009 р., N 93, ст. 3176).
