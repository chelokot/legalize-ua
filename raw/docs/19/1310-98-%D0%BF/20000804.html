Текст документа від 04.08.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 серпня 1998 р. N 1310 Київ

Про порядок оскарження центральними органами виконавчої влади, головами місцевих державних адміністрацій рішень Державного комітету з питань регуляторної політики та підприємництва

( Із змінами, внесеними згідно з Постановою КМ N 1221 ( 1221-2000-п ) від 04.08.2000 )

( У назві, тексті та Положенні слова "Державний комітет з питань розвитку підприємництва", "Міжвідомча рада з питань дерегулювання підприємницької діяльності" та "Рада" в усіх відмінках замінено відповідно словами "Державний комітет з питань регуляторної політики та підприємництва", "Урядовий комітет економічного розвитку" та "Урядовий комітет" у відповідному відмінку згідно з Постановою КМ N 1221 ( 1221-2000-п ) від 04.08.2000 )

Відповідно до Указу Президента України від 3 лютого 1998 р. N 79 ( 79/98 ) "Про усунення обмежень, що стримують розвиток підприємницької діяльності" Кабінет Міністрів України постановляє:

1. Затвердити Положення про порядок оскарження центральними органами виконавчої влади, головами місцевих державних адміністрацій рішень Державного комітету з питань регуляторної політики та підприємництва (додається).

2. Центральним органам виконавчої влади, місцевим державним адміністраціям забезпечити погодження розроблюваних проектів законів та інших нормативно-правових актів з питань підприємницької діяльності з Державним комітетом з питань регуляторної політики та підприємництва.

3. Установити, що керівники центральних органів виконавчої влади, місцевих державних адміністрацій несуть персональну відповідальність за виконання цієї постанови.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

Інд. 25

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 17 серпня 1998 р. N 1310

ПОЛОЖЕННЯ про порядок оскарження центральними органами виконавчої влади, головами місцевих державних адміністрацій рішень Державного комітету з питань регуляторної політики та підприємництва

1. Рішення Держпідприємництва щодо приведення нормативно-правового акта центрального органу виконавчої влади, місцевої державної адміністрації з питань підприємницької діяльності у відповідність з вимогами Указу Президента України від 3 лютого 1998 р. N 79 ( 79/98 ) може бути оскаржено до Урядового комітету економічного розвитку (далі - Урядовий комітет) протягом одного місяця з дня отримання зазначеного рішення. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1221 ( 1221-2000-п ) від 04.08.2000 )

2. Скарга подається в письмовому вигляді та підписується керівником центрального органу виконавчої влади, головою місцевої державної адміністрації або особою, що його заміщає.

У разі оскарження прийнятого Держпідприємництва рішення щодо спільного нормативно-правового акта центральних органів виконавчої влади скарга підписується керівниками цих органів. ( Пункт 2 доповнено абзацом другим згідно з Постановою КМ N 1221 ( 1221-2000-п ) від 04.08.2000 )

До скарги додаються копія рішення Держпідприємництва, яке оскаржується, та матеріали, що обгрунтовують необхідність його скасування.

3. Дія рішення Держпідприємництва щодо приведення нормативно-правового акта у відповідність з вимогами зазначеного Указу Президента України призупиняється з дня надходження до Урядового комітету скарги до прийняття нею рішення про відмову в задоволенні скарги, а у разі задоволення скарги - до скасування рішення Держпідприємництва.

4. Урядовий комітет розглядає скаргу на своєму засіданні і приймає рішення про її задоволення або відмову в задоволенні.

Держпідприємництво може подати на засідання Урядового комітету додаткові матеріали, які обгрунтовують доцільність прийняття рішення.

Під час розгляду скарги на засіданні Урядового комітету заслуховується інформація Голови Держпідприємництва.

Рішення Урядового комітету є обов'язковим для виконання центральними органами виконавчої влади та місцевими державними адміністраціями.

( Пункт 4 в редакції Постанови КМ N 1221 ( 1221-2000-п ) від 04.08.2000 )

5. У разі задоволення скарги Держпідприємництва протягом 5 днів повинно скасувати своє рішення.

У разі відмови в задоволенні скарги центральний орган виконавчої влади, голова місцевої державної адміністрації повинні виконати рішення Держпідприємництва у місячний строк з дня його отримання і поінформувати останнього про виконання.

6. У разі відмови в задоволенні скарги Держпідприємництво повідомляє у засобах масової інформації про відповідне рішення Урядового комітету.

( Пункт 6 в редакції Постанови КМ N 1221 ( 1221-2000-п ) від 04.08.2000 )
