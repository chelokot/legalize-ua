Питання державного оборонного замовлення

{ Із змінами, внесеними згідно з Постановами КМ N 478 ( 478-2000-п ) від 10.03.2000 N 1469 ( 1469-2000-п ) від 27.09.2000 N 386 ( 386-2001-п ) від 23.04.2001 N 158 ( 158-2002-п ) від 15.02.2002 N 281 ( 281-2002-п ) від 13.03.2002 N 1058 ( 1058-2002-п ) від 25.07.2002 N 628 ( 628-2003-п ) від 26.04.2003 N 1402 ( 1402-2003-п ) від 04.09.2003 N 983 ( 983-2004-п ) від 28.07.2004 N 326 ( 326-2006-п ) від 15.03.2006 N 378 ( 378-2006-п ) від 29.03.2006 N 1074 ( 1074-2006-п ) від 01.08.2006 N 1700 ( 1700-2006-п ) від 08.12.2006 }

Відповідно до статей 1 - 4 Закону України "Про державне оборонне замовлення" ( 464-14 ) Кабінет Міністрів України постановляє:

1. Затвердити Порядок формування основних показників державного оборонного замовлення, розміщення та коригування обсягів поставок (закупівлі) продукції, виконання робіт, надання послуг за оборонним замовленням, внесення змін до укладених державних контрактів, а також порядок контролю за виконанням оборонного замовлення та Порядок проведення конкурсів (тендерів) з вибору виконавців державного оборонного замовлення (додаються).

2. Уповноважити Міністерство оборони, Міністерство внутрішніх справ, Державну податкову адміністрацію, Міністерство з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Міністерство промислової політики, Службу безпеки, Службу зовнішньої розвідки, Державну митну службу, Адміністрація Державної прикордонної служби, Міністерство освіти і науки, Національне космічне агентство, Адміністрацію Державної служби спеціального зв'язку та захисту інформації, Державний департамент з питань виконання покарань, Головне управління розвідки Міністерства оборони, Управління державної охорони укладати державні контракти на поставку (закупівлю) продукції, виконання робіт, надання послуг за державним оборонним замовленням.

{ Пункт 2 із змінами, внесеними згідно з Постановами КМ N 478 ( 478-2000-п ) від 10.03.2000, N 386 ( 386-2001-п ) від 23.04.2001, N 158 ( 158-2002-п ) від 15.02.2002, N 281 ( 281-2002-п ) від 13.03.2002, N 1402 ( 1402-2003-п ) від 04.09.2003, N 326 ( 326-2006-п ) від 15.03.2006, N 378 ( 378-2006-п ) від 29.03.2006, N 1700 ( 1700-2006-п ) від 08.12.2006 }

3. Покласти на Міністерство економіки та з питань європейської інтеграції розроблення проекту основних показників державного оборонного замовлення, координацію діяльності державних замовників і виконавців під час формування зазначеного проекту та виконання державних контрактів.

( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 158 ( 158-2002-п ) від 15.02.2002 )

4. Установити, що з метою залучення до фінансування робіт та надання послуг, які належать до державного оборонного замовлення, додаткових коштів державні замовники після вибору на конкурсних засадах його виконавців можуть укладати договори про спільне з виконавцями, а також із суб'єктами здійснення міжнародних передач товарів військового призначення та подвійного використання фінансування на взаємовигідній основі робіт із створення нових або модернізації наявних зразків озброєння і військової техніки.

( Пункт 4 в редакції Постанови КМ N 386 ( 386-2001-п ) від 23.04.2001, із змінами, внесеними згідно з Постановою КМ N 628 ( 628-2003-п ) від 26.04.2003, в редакції Постанови КМ N 983 ( 983-2004-п ) від 28.07.2004 )

5. Міністерству економіки та з питань європейської інтеграції і Міністерству оборони щороку передбачати у проекті основних показників державного оборонного замовлення фінансування пріоритетних напрямів розвитку озброєння і військової техніки в обсягах не менш як 60 відсотків коштів, що призначаються на виконання науково-дослідних та дослідно-конструкторських робіт. ( Постанову доповнено пунктом 5 згідно з Постановою КМ N 386 ( 386-2001-п ) від 23.04.2001, із змінами, внесеними згідно з Постановою КМ N 158 ( 158-2002-п ) від 15.02.2002 )

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 9 грудня 1999 р. N 2244

ПОРЯДОК формування основних показників державного оборонного замовлення, розміщення та коригування обсягів поставок (закупівлі) продукції, виконання робіт, надання послуг за оборонним замовленням, внесення змін до укладених державних контрактів, а також порядок контролю за виконанням оборонного замовлення

Загальні положення

1. Цей Порядок визначає механізм формування основних показників державного оборонного замовлення, розміщення та коригування обсягів поставок (закупівлі) продукції, виконання робіт, надання послуг за державним оборонним замовленням, внесення змін до укладених державних контрактів, а також здійснення контролю за виконанням оборонного замовлення.

2. У цьому Порядку поняття "оборонне замовлення", "державні замовники", "виконавці", "співвиконавці", "державний контракт" вживаються у значеннях, наведених у Законі України "Про державне оборонне замовлення" ( 464-14 ), поняття "суб'єкт здійснення міжнародних передач товарів" - у значенні, наведеному у Законі України "Про державний контроль за міжнародними передачами товарів військового призначення та подвійного використання" ( 549-15 ), а поняття "вітчизняний виробник" - у значенні, наведеному у Законі України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ). Для цілей цього Порядку також використовуються такі поняття: ( Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 983 ( 983-2004-п ) від 28.07.2004 )

координаційні органи - органи виконавчої влади, які відповідно до законодавства координують діяльність підприємств, установ та організацій;

товари військового призначення - товари, роботи та послуги, що можуть належати до оборонного замовлення відповідно до частини шостої статті 1 Закону України "Про державне оборонне замовлення".

3. Закупівля продовольства, речового та медичного майна за оборонним замовленням здійснюється у вітчизняних виробників, а для виготовлення товарів військового призначення використовуються комплектуючі вироби, напівфабрикати, матеріали і сировина вітчизняного походження, крім випадків, коли вони не виробляються підприємствами, установами та організаціями України. ( Пункт 3 в редакції Постанови КМ N 386 ( 386-2001-п ) від 23.04.2001 )

4. Використання державних коштів на закупівлю товарів, робіт і послуг військового призначення іноземного походження здійснюється державними замовниками відповідно до законодавства. ( Пункт 4 в редакції Постанови КМ N 1469 ( 1469-2000-п ) від 27.09.2000 )

5. Ціни на товари військового призначення встановлюються на підставі акцептованих пропозицій переможців конкурсу, що визначені згідно з Порядком проведення конкурсів (тендерів) з вибору виконавців державного оборонного замовлення, затвердженим постановою Кабінету Міністрів України від 9 грудня 1999 р. N 2244.

У разі визначення виконавців згідно з частиною другою статті 3 Закону України "Про державне оборонне замовлення" ( 464-14 ) не на конкурсній основі ціни на товари військового призначення встановлюються виконавцями і державними замовниками у процесі укладання державних контрактів за погодженням з координаційними органами.

( Пункт 5 в редакції Постанови КМ N 983 ( 983-2004-п ) від 28.07.2004 )

6. Заходи з питань формування, розміщення та виконання оборонного замовлення, що становлять державну таємницю, здійснюються з дотриманням законодавства щодо забезпечення охорони державної таємниці.

Формування основних показників оборонного замовлення

7. Державні замовники під час формування бюджетних запитів на наступний бюджетний період визначають у межах бюджетних програм обсяги коштів на фінансування оборонного замовлення за його напрямами та одночасно з поданням до Мінфіну бюджетних запитів вносять до Мінекономіки пропозиції щодо фінансування оборонного замовлення з відповідним обґрунтуванням.

( Пункт 7 в редакції Постанови КМ N 1058 ( 1058-2002-п ) від 25.07.2002, із змінами, внесеними згідно з Постановою КМ N 628 ( 628-2003-п ) від 26.04.2003, в редакції Постанови КМ N 983 ( 983-2004-п ) від 28.07.2004 )

( Пункт 8 виключено на підставі Постанови КМ N 1058 ( 1058-2002-п ) від 25.07.2002 )

9. Державні замовники з урахуванням обсягів коштів на фінансування оборонного замовлення, визначених відповідно до пункту 7 цього Порядку визначають виконавців шляхом проведення конкурсу (тендеру) та у двомісячний термін у межах цих коштів розробляють і подають Мінекономіки за встановленими ним формами пропозиції до проекту основних показників оборонного замовлення на наступний рік щодо номенклатури, кількості продукції, що поставляється (закуповується), обсягів робіт, послуг із зазначенням їх вартості та виконавців, які визначені за результатами проведених конкурсів (тендерів) або пропонуються державними замовниками у разі невизначення їх на конкурсній основі, а також співвиконавців, які можуть бути визначені в установленому порядку як виконавці. До зазначених пропозицій державні замовники додають відповідні розрахунки і обгрунтування, якщо виконавець є єдиним виробником продукції, виконавцем робіт, надавачем послуг, що замовляються, додають підтвердний документ, погоджений з органом виконавчої влади, який відповідно до законодавства координує діяльність цього підприємства, установи, організації. ( Абзац перший пункту 9 із змінами, внесеними згідно з Постановою КМ N 1058 ( 1058-2002-п ) від 25.07.2002 )

У разі коли раніше було укладено договори про спільне з виконавцями та суб'єктами міжнародних передач товарів довгострокове фінансування робіт із створення нових або модернізації наявних зразків озброєння і військової техніки, конкурс не проводиться, а обсяги коштів щороку включаються до основних показників оборонного замовлення із зазначенням його виконавців. ( Пункт 9 доповнено абзацом згідно з Постановою КМ N 983 ( 983-2004-п ) від 28.07.2004 )

Пропозиції на поставку (закупівлю) комплектуючих виробів державні замовники подають окремим рядком із зазначенням їх загальної вартості та додають до них специфікації.

Пропозиції щодо створення нових та нарощування діючих виробничих потужностей для виготовлення товарів військового призначення державні замовники на їх створення подають за погодженням з державними замовниками на поставку (закупівлю) товарів військового призначення.

10. Мінекономіки у місячний термін аналізує і узагальнює пропозиції державних замовників до проекту основних показників оборонного замовлення за його напрямами та у разі потреби запитує додаткові матеріали. ( Абзац перший пункту 10 із змінами, внесеними згідно з Постановою КМ N 983 ( 983-2004-п ) від 28.07.2004 )

( Абзац другий пункту 10 виключено на підставі Постанови КМ N 983 ( 983-2004-п ) від 28.07.2004 )

11. Мінекономіки після одержання всіх матеріалів узагальнює пропозиції до проекту основних показників оборонного замовлення за його напрямами і збалансовує з прогнозними обсягами бюджетних коштів, які передбачаються державними замовниками на ці цілі, та у місячний термін формує проект основних показників оборонного замовлення.

12. Державні замовники після набрання чинності законом про Державний бюджет України на відповідний рік уточнюють раніше подані пропозиції щодо фінансування оборонного замовлення, визначають виконавців і подають у місячний термін Мінекономіки пропозиції до основних показників оборонного замовлення разом з протоколами конкурсних комісій щодо остаточного вибору виконавців.

( Пункт 12 в редакції Постанови КМ N 386 ( 386-2001-п ) від 23.04.2001, із змінами, внесеними згідно з Постановою КМ N 628 ( 628-2003-п ) від 26.04.2003, в редакції Постанови КМ N 983 ( 983-2004-п ) від 28.07.2004 )

13. Мінекономіки у місячний термін після отримання від державних замовників остаточних пропозицій вносить до проекту основних показників оборонного замовлення необхідні зміни і в установленому порядку подає його на затвердження Кабінетові Міністрів України.

14. Кабінет Міністрів України затверджує основні показники оборонного замовлення, які доводяться до державних замовників, координаційних органів, Мінекономіки, Мінфіну та інших заінтересованих центральних органів виконавчої влади.

15. Координаційні органи доводять до відповідних виконавців основні показники оборонного замовлення в частині, що їх стосується.

Розміщення оборонного замовлення та укладення державних контрактів на виконання оборонного замовлення

16. Державні замовники, виходячи із затверджених основних показників оборонного замовлення на відповідний рік, укладають з виконавцями державні контракти за формою, що затверджується Мінекономіки.

17. Укладення відповідно до міжнародних договорів з питань військово-технічного співробітництва державних контрактів щодо експортно-імпортних поставок (закупівлі) озброєння, військової та спеціальної техніки, інших товарів військового призначення, виконання робіт, надання послуг здійснюється державними замовниками з визначеними на конкурсній основі виконавцями, яким в установленому порядку надані повноваження на право здійснення експорту, імпорту відповідних товарів, або з виконавцями, яким такі повноваження надаються в порядку, передбаченому абзацом другим пункту 13 Положення про порядок надання суб'єктам зовнішньоекономічної діяльності повноважень на право здійснення експорту, імпорту товарів військового призначення та товарів, які містять відомості, що становлять державну таємницю, затвердженого постановою Кабінету Міністрів України від 8 червня 1998 р. N 838 ( 838-98-п ) (Офіційний вісник України, 1998 р., N 23, ст. 839; 1999 р., N 24, ст. 1107). Для надання виконавцям повноважень на право здійснення імпорту товарів, технологій, робіт та послуг військового призначення в межах оборонного замовлення, а також відповідних повноважень виконавцям, які імпортують ці товари, технології, роботи та послуги для використання у власному виробництві під час виконання оборонного замовлення, Мінекономіки готує та подає в установленому порядку Кабінетові Міністрів України проект відповідної постанови.

Укладення державних контрактів щодо експортно-імпортних поставок (закупівлі) товарів військового призначення здійснюється згідно з типовими платіжними умовами зовнішньоекономічних договорів (контрактів) і типовими формами захисних застережень до зовнішньоекономічних договорів (контрактів), які передбачають розрахунки в іноземній валюті, затвердженими постановою Кабінету Міністрів України і Національного банку України від 21 червня 1995 р. N 444 ( 444-95-п ) (ЗП України, 1995 р., N 9, ст. 243).

Коригування обсягів поставок (закупівлі) продукції, виконання робіт, надання послуг за оборонним замовленням, внесення змін до укладених державних контрактів

18. У разі зміни ціни на продукцію (роботи, послуги), визначеної державними контрактами, що зумовлено зміною вартості сировини, матеріалів, комплектуючих виробів, енергоносіїв, іншими не залежними від діяльності виконавців причинами, які впливають на витрати з виробництва продукції (виконання робіт, надання послуг), Мінекономіки може за пропозиціями державних замовників, погодженими з виконавцями, вносити зміни до основних показників оборонного замовлення в межах затверджених обсягів коштів на його фінансування. ( Абзац перший пункту 18 в редакції Постанови КМ N 983 ( 983-2004-п ) від 28.07.2004 )

Інформацію про внесення змін до основних показників оборонного замовлення Мінекономіки доводить до Кабінету Міністрів України, Мінфіну, Держкомстату, державних замовників, координаційних органів. ( Абзац другий пункту 18 із змінами, внесеними згідно з Постановами КМ N 1058 ( 1058-2002-п ) від 25.07.2002, N 628 ( 628-2003-п ) від 26.04.2003, в редакції Постанови КМ N 983 ( 983-2004-п ) від 28.07.2004 )

Відкориговані показники оборонного замовлення є підставою для внесення змін до укладених державних контрактів.

Контроль за виконанням оборонного замовлення

19. Контроль за виконанням оборонного замовлення здійснюють державні замовники, Мінекономіки та Мінфін в межах їх повноважень. ( Пункт 19 із змінами, внесеними згідно з Постановами КМ N 386 ( 386-2001-п ) від 23.04.2001, N 628 ( 628-2003-п ) від 26.04.2003 )

20. Контроль за якістю товарів військового призначення на всіх стадіях їх розроблення, виробництва, доробки, монтажу і поставок державним замовникам, своєчасним виконанням державних контрактів, у тому числі правильністю проведення витрат, перевірка і узгодження розрахунково-калькуляційних матеріалів щодо договірних цін здійснюється в установленому порядку військовими представництвами державних замовників.

21. Державні замовники щокварталу до 20 числа місяця, що настає за звітним періодом, подають Мінфіну та Мінекономіки звіт про використання коштів, передбачених для фінансування оборонного замовлення. ( Пункт 21 із змінами, внесеними згідно з Постановами КМ N 1058 ( 1058-2002-п ) від 25.07.2002, N 628 ( 628-2003-п ) від 26.04.2003 )

22. Державні замовники та виконавці подають органам державної статистики звіт про хід виконання державних контрактів з оборонного замовлення у такому порядку:

щомісяця - про поставки (закупівлю) озброєння, військової і спеціальної техніки, продовольства, речового та медичного майна, пально-мастильних матеріалів, виконання робіт і надання послуг;

щокварталу - про виконання науково-дослідних та дослідно-конструкторських робіт, будівництво найважливіших об'єктів і споруд оборонного призначення, створення і нарощення діючих виробничих потужностей для виготовлення нових та модернізації наявних зразків озброєння і військової техніки, а також створення спеціальних виробничих технологій для розвитку науково-технологічного потенціалу промисловості.

23. Держкомстат не пізніше 30 числа місяця, що настає за звітним періодом, подає Кабінетові Міністрів України і Мінекономіки зведену інформацію про хід виконання державних контрактів з оборонного замовлення. ( Пункт 23 із змінами, внесеними згідно з Постановами КМ N 386 ( 386-2001-п ) від 23.04.2001, N 628 ( 628-2003-п ) від 26.04.2003 )

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 9 грудня 1999 р. N 2244

ПОРЯДОК проведення конкурсів (тендерів) з вибору виконавців державного оборонного замовлення

Цей Порядок визначає механізм організації та проведення державними замовниками з державного оборонного замовлення конкурсів (тендерів) (далі - конкурс) з вибору виконавців цього замовлення, крім конкурсів з будівництва об'єктів і споруд оборонного та спеціального призначення, житла для військовослужбовців та осіб рядового і начальницького складу органів внутрішніх справ та Державної кримінально-виконавчої служби.

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

Загальні положення

1. У цьому Порядку поняття "оборонне замовлення", "державні замовники", "державний контракт" вживаються у значеннях, наведених у Законі України "Про державне оборонне замовлення" ( 464-14 ). Для цілей цього Порядку також використовуються такі поняття:

конкурсанти - суб'єкти підприємницької діяльності України всіх форм власності, які підтвердили намір взяти участь у конкурсі та подали чи збираються подати конкурсні пропозиції;

конкурсна документація - документація, що готується державним замовником та передається конкурсантам для підготовки ними конкурсних пропозицій;

конкурсна пропозиція - пропозиція щодо окремої номенклатури оборонного замовлення, яка готується та подається конкурсантом державному замовнику відповідно до вимог конкурсної документації;

конкурсне забезпечення - надання конкурсантом державному замовнику гарантій щодо забезпечення виконання ним фінансових зобов'язань (банківські гарантії, резервні акредитиви, чеки, депозити у готівкових коштах, векселі), які виникають у зв'язку з поданням конкурсної пропозиції;

акцепт конкурсної пропозиції - прийняття державним замовником конкурсної пропозиції та надання згоди на її оплату. Конкурсна пропозиція вважається акцептованою, якщо в установлений у конкурсних документах термін державний замовник не подав письмової відмови конкурсанту в акцепті конкурсної пропозиції після визначення його переможцем конкурсу;

конкурсна комісія - група спеціалістів, що визначається державним замовником і приймає рішення про визначення переможця конкурсу;

переможець конкурсу - конкурсант, конкурсна пропозиція якого визнана кращою та проведено її акцепт; ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 983 ( 983-2004-п ) від 28.07.2004 )

2. Вибір виконавців у сфері будівництва об'єктів і споруд оборонного та спеціального призначення, житла для військовослужбовців та осіб рядового і начальницького складу органів внутрішніх справ та Державної кримінально-виконавчої служби здійснюється відповідно до законодавства про проведення торгів (тендерів) у цій сфері.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

3. Суб'єкти підприємницької діяльності, які на конкурсній основі вибрані виконавцями імпортних поставок (закупівлі) озброєння, військової та спеціальної техніки, інших товарів військового призначення, виконання робіт, надання послуг, здійснюють процедури закупівлі відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ). ( Абзац перший пункту 3 в редакції Постанови КМ N 1469 ( 1469-2000-п ) від 27.09.2000 )

У разі коли закупівля (поставка) товарів (робіт, послуг) за імпортом становить державну таємницю вибір виконавцями іноземних виробників продукції (робіт, послуг) здійснюється з дотриманням вимог нормативно-правових актів, що регулюють питання охорони державних таємниць, відповідно до міжнародних договорів у галузі військово-технічного, економічного та іншого співробітництва, а також про взаємний захист державних таємниць. ( Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 1469 ( 1469-2000-п ) від 27.09.2000 )

4. Останній день термінів, зазначених у цьому Порядку, триває до 24 години. Термін не вважається порушеним, якщо до його закінчення необхідні документи здано на пошту або передано засобами електронного зв'язку.

Загальні умови проведення конкурсів

5. Для виконання організаційної роботи, пов'язаної з проведенням конкурсів, наказом державного замовника утворюється конкурсна комісія.

До складу конкурсної комісії входять не менш як 5 відповідальних працівників державного замовника, працівники заінтересованих міністерств, інших центральних і місцевих органів виконавчої влади, а також група спеціалістів, визначених державним замовником для експертної оцінки конкурсних пропозицій та визначення переможця конкурсу.

Голова конкурсної комісії, який призначається державним замовником, організовує її роботу і несе персональну відповідальність за виконання покладених на комісію функцій.

Рішення конкурсної комісії про визначення переможця приймається на її засіданнях відкритим голосуванням більшістю голосів у присутності не менш як двох третин членів комісії та оформлюється протоколом.

6. Проведення конкурсів може здійснюватися шляхом:

відкритих конкурсів;

конкурсів з обмеженою участю;

двоступеневих конкурсів;

закритих конкурсів.

Вид конкурсу визначається конкурсною комісією.

7. До конкурсантів можуть пред'являтися такі кваліфікаційні вимоги:

наявність відповідного обладнання та впроваджених технологій;

наявність працівників з необхідними знаннями та досвідом;

наявність дозволу (ліцензії) на провадження відповідних видів діяльності;

вступ у правові відносини згідно із своїм Статутом.

Обставинами для відхилення конкурсної пропозиції можуть бути:

невиконання конкурсантом протягом останніх трьох років без поважних причин хоча б одного державного контракту з оборонного замовлення;

визнання конкурсанта в установленому порядку банкрутом чи порушення стосовно нього справи про банкрутство;

наявність у конкурсанта простроченої заборгованості до державного бюджету та з інших обов'язкових платежів.

Про причини відхилення конкурсної пропозиції конкурсанту повідомляється протягом семи календарних днів після прийняття відповідного рішення. ( Пункт 7 доповнено абзацом згідно з Постановою КМ N 983 ( 983-2004-п ) від 28.07.2004 )

8. Про проведення відкритих та двоступеневих конкурсів, а також процедури попередньої кваліфікації у разі проведення конкурсу з обмеженою участю державний замовник дає оголошення у "Віснику державних закупівель" або в інших друкованих засобах масової інформації.

У разі проведення закритих конкурсів державний замовник з дотриманням законодавства про забезпечення охорони державної таємниці надсилає повідомлення про проведення конкурсу центральним органам виконавчої влади, до сфери управління яких належать конкурсанти, або запрошення до участі у конкурсі безпосередньо конкурсантам.

Документи, що стосуються проведення конкурсів, складаються державною мовою.

9. Звіт про результати проведення конкурсів з вибору виконавців оборонного замовлення повинен зберігатися державним замовником протягом трьох років і містити:

стислий опис предмета оборонного замовлення;

найменування та адреси конкурсантів, що подали конкурсні пропозиції;

заявки на участь у процедурі попередньої кваліфікації;

найменування та адресу конкурсанта, з яким укладено державний контракт, і вартість продукції, виконання робіт, надання послуг за контрактом;

ціни і стислий опис основних умов кожної конкурсної пропозиції, запропонованої конкурсантами;

стислий виклад критеріїв порівняння та оцінки конкурсних пропозицій, визначення переможця конкурсу;

у разі відхилення окремих чи всіх конкурсних пропозицій - обгрунтування підстав такого рішення;

виклад причин і обставин, якими керувався державний замовник під час обрання іншого шляху проведення конкурсу, ніж відкритий;

у разі, коли за результатами конкурсу не було укладено державного контракту, - обгрунтоване рішення про це;

дані про:

створення конкурсної комісії;

кваліфікацію конкурсантів, що подали конкурсні пропозиції;

причини застосування процедури попередньої кваліфікації конкурсантів;

подані скарги, рішення державного замовника щодо їх вирішення з відповідними обгрунтуваннями, а також позови до арбітражного суду та результати їх розгляду;

причини призупинення проведення конкурсу в разі прийняття такого рішення.

Інформація, що міститься у звіті, якщо вона не конфіденційна, може надаватися на запит конкурсантів, які подали конкурсні пропозиції або заявки на участь у процедурі попередньої кваліфікації.

Протоколи засідання конкурсних комісій з даними про результати проведення конкурсів подаються державними замовниками до Мінекономіки разом з пропозиціями до проекту основних показників оборонного замовлення на наступний рік, або разом з пропозиціями про внесення змін до основних показників оборонного замовлення. ( Абзац вісімнадцятий пункту 9 із змінами, внесеними згідно з Постановою КМ N 983 ( 983-2004-п ) від 28.07.2004 )

10. Конкурсна комісія, за винятком випадків, передбачених законодавством, не повинна розголошувати інформацію з обмеженим доступом, у тому числі інформацію про розгляд, оцінку та порівняння конкурсних пропозицій, крім зазначеної в пункті 7 цього Порядку.

Проведення відкритих конкурсів і конкурсів з обмеженою участю

11. У разі проведення відкритих конкурсів конкурсні пропозиції подають усі конкурсанти.

12. У разі проведення конкурсів з обмеженою участю конкурсні пропозиції подають ті конкурсанти, які були відібрані за процедурою попередньої кваліфікації та запрошені державним замовником до подальшої участі у конкурсі.

13. Оголошення про проведення процедури попередньої кваліфікації суб'єктів підприємницької діяльності дається в порядку, передбаченому пунктом 8 цього Порядку, не пізніше ніж за 45 днів до дня її проведення. ( Абзац перший пункту 13 із змінами, внесеними згідно з Постановою КМ N 983 ( 983-2004-п ) від 28.07.2004 )

Зазначене оголошення повинне містити такі відомості:

найменування та адресу державного замовника;

номенклатуру та обсяги оборонного замовлення;

терміни виконання оборонного замовлення;

визначення вимог, яким повинен відповідати суб'єкт підприємницької діяльності;

місце та термін подання заявок на участь у процедурі попередньої кваліфікації;

інші необхідні державному замовнику відомості.

Державний замовник не пізніше ніж за 14 днів до початку терміну подання заявок на участь у процедурі попередньої кваліфікації надає всім заінтересованим суб'єктам підприємницької діяльності інформацію про:

порядок підготовки та подання заявок на участь у процедурі попередньої кваліфікації;

встановлені кваліфікаційні вимоги до них та процедуру оцінки відповідності суб'єктів підприємницької діяльності цим вимогам;

документи, необхідні суб'єкту підприємницької діяльності для підтвердження його відповідності встановленим кваліфікаційним вимогам;

прізвища, посади представників державного замовника, відповідальних за проведення процедури попередньої кваліфікації, та способи зв'язку з ними.

14. На підставі отриманих заявок на участь у процедурі попередньої кваліфікації конкурсна комісія оцінює відповідність суб'єктів підприємницької діяльності встановленим кваліфікаційним вимогам, визначає серед них конкурсантів і не пізніше трьох днів після завершення процедури попередньої кваліфікації повідомляє кожного суб'єкта підприємницької діяльності, що брав участь у цій процедурі, про її результати.

До подальшої участі у конкурсі допускаються лише ті суб'єкти підприємницької діяльності, які пройшли відбір за результатами процедури попередньої кваліфікації. Перелік суб'єктів підприємницької діяльності, допущених до подальшої участі у конкурсах, крім закритих, може бути опублікований у "Віснику державних закупівель".

15. В оголошенні про проведення відкритих конкурсів та в запрошенні до участі у конкурсах з обмеженою участю зазначаються:

найменування та адреса державного замовника;

номенклатура та обсяги оборонного замовлення;

терміни виконання оборонного замовлення;

визначення вимог, яким повинен відповідати конкурсант;

способи та місце отримання конкурсної документації, розмір плати за неї (якщо таку плату встановлено державним замовником);

місце та термін подання конкурсних пропозицій;

місце та дата проведення конкурсу.

16. Встановлений державним замовником термін подання конкурсних пропозицій має бути достатнім для їх належної підготовки, але не меншим ніж 45 календарних днів від дати опублікування оголошення про проведення конкурсу або запрошенні до участі в ньому. У разі потреби мінімальний термін подання конкурсних пропозицій може бути скорочено до 15 календарних днів за умови, що обставини, які викликали його скорочення, не спричинені діями державного замовника, спрямованими на послаблення конкуренції між конкурсантами. Причини зміни терміну викладаються у звіті про результати проведення конкурсу з вибору виконавців оборонного замовлення.

( Пункт 16 із змінами, внесеними згідно з Постановою КМ N 983 ( 983-2004-п ) від 28.07.2004 )

17. Державний замовник надсилає конкурсанту конкурсну документацію протягом тижня з дня отримання від нього запиту про надання цих документів.

У разі проведення конкурсів з обмеженою участю конкурсна документація надсилається конкурсантам, які пройшли процедуру попередньої кваліфікації, одночасно із запрошенням до участі у конкурсі.

За надання конкурсної документації державний замовник має право вимагати від конкурсанта плату, яка не повинна перевищувати суми, необхідної для покриття витрат на підготовку та розсилання цієї документації.

18. Конкурсна документація, як правило, повинна містити:

інструкцію щодо підготовки конкурсних пропозицій;

опис критеріїв, які висуваються конкурсною комісією з метою оцінки відповідності конкурсантів установленим кваліфікаційним вимогам;

інформацію про встановлені кваліфікаційні вимоги до конкурсантів та необхідність документального підтвердження відповідності конкурсантів цим вимогам;

інформацію про характер, технічні та якісні характеристики предмета оборонного замовлення, а також конструктивні, технологічні, експлуатаційні та інші вимоги до нього з посиланням на відповідні міжнародні або національні стандарти та норми;

обсяги оборонного замовлення;

терміни виконання оборонного замовлення;

критерії оцінки конкурсних пропозицій, за якими буде визначатись краща конкурсна пропозиція, у тому числі критерії переваги конкурсантів, які використовують у виробництві переважно вітчизняні матеріали і сировину, за винятком випадків, коли необхідні матеріали і сировина не виробляються підприємствами України;

орієнтовну ціну конкурсної пропозиції та методику її розрахунку;

вимоги державного замовника до умов надання конкурсантами конкурсного забезпечення;

прізвища і посади представників державного замовника, уповноважених здійснювати взаємодію з конкурсантами, та способи зв'язку з ними;

інформацію про додаткові умови, необхідні для акцепту конкурсної пропозиції та набрання чинності державним контрактом, а також орієнтовний термін його укладення з урахуванням відправлення повідомлення про акцепт конкурсної пропозиції.

19. Вимоги державного замовника до умов надання конкурсантом конкурсного забезпечення повинні включати його форму, розмір, термін дії, а також випадки, у яких конкурсне забезпечення не повертається конкурсанту.

Розмір конкурсного забезпечення не повинен перевищувати 5 відсотків очікуваної вартості державного контракту.

Державний замовник не повинен претендувати на конкурсне забезпечення і має повернути відповідну суму коштів та інші гарантійні документи конкурсанту протягом 10 календарних днів з моменту виникнення підстави для повернення конкурсного забезпечення, крім випадків:

відкликання або зміни конкурсантом конкурсної пропозиції після закінчення терміну її подання;

відмови переможця конкурсу укладати державний контракт.

Підставами для повернення конкурсного забезпечення є:

закінчення терміну дії конкурсного забезпечення, зазначеного у конкурсній документації;

укладення державного контракту з переможцем конкурсу;

відкликання конкурсної пропозиції до закінчення терміну її подання, якщо це передбачено у конкурсній документації;

закінчення процедури конкурсу без укладення державного контракту з жодним з конкурсантів, що подали конкурсні пропозиції.

20. Конкурсант має право звернутися до державного замовника із запитом про роз'яснення щодо конкурсної документації, який не менше ніж за 3 дні до закінчення терміну подання конкурсної пропозиції повинен дати відповідь у письмовій формі.

21. Державний замовник не пізніше ніж за 3 дні до закінчення терміну подання конкурсної пропозиції має право внести зміни до конкурсної документації та повідомити про зазначені зміни у письмовій формі всіх конкурсантів, яким державний замовник надав конкурсну документацію.

22. У разі несвоєчасного подання роз'яснень щодо конкурсної документації та внесення змін до неї державний замовник повинен продовжити термін подання конкурсної пропозиції не менше ніж на 3 дні.

23. Конкурсна пропозиція подається державному замовнику в письмовій формі в запечатаному конверті. У разі потреби конкурсант може вимагати надання повідомлення про отримання державним замовником зазначеної пропозиції.

До конкурсних пропозицій додаються документи, що підтверджують конкурсне забезпечення конкурсантом.

24. Конкурсні пропозиції, отримані державним замовником після закінчення терміну їх подання, не розглядаються і повертаються конкурсантам.

25. Конкурсант має право внести зміни або відкликати свою конкурсну пропозицію до закінчення терміну подання конкурсних пропозицій без втрати свого конкурсного забезпечення.

26. Розкриття запечатаних конвертів з конкурсними пропозиціями відбувається на засіданні конкурсної комісії не раніше закінчення терміну їх подання та у присутності представників конкурсантів.

27. Державний замовник, виходячи з державних інтересів, визначає переможця конкурсу на основі критеріїв оцінки конкурсних пропозицій, які зазначені у конкурсній документації. Критеріями оцінки конкурсних пропозицій є: ціна, якість, термін виконання, умови розрахунків, підтримка вітчизняного виробника тощо.

Державний замовник відхиляє конкурсну пропозицію, якщо вона не відповідає критеріям оцінки конкурсних пропозицій або конкурсант не відповідає кваліфікаційним вимогам до нього.

28. Державний замовник може вимагати від переможця конкурсу повторного підтвердження відповідності його кваліфікаційним вимогам, до конкурсантів.

У разі відмови переможця конкурсу надати таке підтвердження державний замовник відхиляє його конкурсну пропозицію і повторно визначає кращу з попередньо розглянутих конкурсних пропозицій.

29. Конкурс відміняється чи визнається таким, що не відбувся, у разі коли:

на участь у конкурсі було подано менше ніж дві конкурсні пропозиції; ( Абзац другий пункту 29 із змінами, внесеними згідно з Постановою КМ N 386 ( 386-2001-п ) від 23.04.2001 )

було відхилено всі конкурсні пропозиції відповідно до пункту 27 цього Порядку;

ціна найбільш вигідної конкурсної пропозиції перевищує суму коштів, передбачену державним замовником на фінансування окремої номенклатури оборонного замовлення;

предмет оборонного замовлення перестав відповідати потребам державного замовника.

30. Про відміну конкурсу державний замовник дає оголошення у "Віснику державних закупівель", в якому повідомляє її причину або доводить цю інформацію до конкурсантів, які подали конкурсні пропозиції, не пізніше ніж за 3 дні до дати проведення конкурсу.

31. У разі коли виконавців на конкурсній основі не визначено, Мінекономіки надсилає відповідні пропозиції координаційним органам або безпосередньо виконавцям, запропонованим державними замовниками, для погодження питання щодо можливості розміщення оборонного замовлення.

Координаційні органи разом з державними замовниками і виконавцями або безпосередньо виконавці разом з державними замовниками у двотижневий термін опрацьовують зазначені пропозиції та надсилають Мінекономіки погоджені матеріали щодо визначення виконавців.

( Пункт 31 в редакції Постанови КМ N 983 ( 983-2004-п ) від 28.07.2004 )

32. Державний замовник акцептує конкурсну пропозицію, яка відповідно до пункту 27 цього Порядку визнана кращою.

33. Повідомлення про акцепт конкурсної пропозиції має бути надіслано державним замовником конкурсанту, який її подав, протягом трьох днів з дати визначення його переможцем конкурсу. В тижневий термін з дня закінчення конкурсу державний замовник через оголошення у "Віснику державних закупівель" або повідомлення у разі проведення закритого конкурсу інформує інших конкурсантів про результати конкурсу, найменування та місцезнаходження конкурсанта, конкурсна пропозиція якого визнана кращою.

34. Державний замовник укладає державний контракт з переможцем конкурсу, конкурсну пропозицію якого було акцептовано.

35. У разі відмови переможця конкурсу, конкурсну пропозицію якого було акцептовано, укласти державний контракт державний замовник повторно визначає кращу з попередньо розглянутих конкурсних пропозицій.

Проведення двоступеневих конкурсів

36. Двоступеневі конкурси проводяться, якщо державний замовник на час проведення конкурсу ще не може остаточно визначитися з номенклатурою продукції, робіт, послуг, її очікуваною вартістю та обсягами коштів, які будуть передбачені на фінансування оборонного замовлення.

37. Двоступеневі конкурси здійснюються у два етапи:

на першому етапі - всім конкурсантам пропонується подати попередні конкурсні пропозиції, без зазначення ціни;

на другому етапі - державний замовник пропонує конкурсантам, конкурсні пропозиції яких не було відхилено на першому етапі, надати остаточні конкурсні пропозиції із зазначенням ціни.

У разі поставок (закупівлі) продовольства конкурси на другому етапі можуть проводитися кожного кварталу у місяці, що передує наступному кварталу.

38. Конкурсанти, конкурсні пропозиції яких не було відхилено на першому етапі, для участі у другому етапі конкурсу подають документ, що підтверджує конкурсне забезпечення їх пропозицій.

39. Інші процедури проведення двоступеневих конкурсів здійснюються в порядку, передбаченому для відкритих конкурсів.

Проведення закритих конкурсів

40. Закриті конкурси проводяться у разі, коли закупівля (поставка) товарів (робіт, послуг) становить державну таємницю, і здійснюються відповідно до цього Порядку з дотриманням законодавства щодо забезпечення охорони державної таємниці.

Процедура оскарження

41. Конкурсант, який вважає, що порушується процедура проведення конкурсу, передбачена цим Порядком, має право оскаржувати дії державного замовника.

42. Об'єктом оскарження не може бути:

вибір способу проведення конкурсу;

рішення державного замовника про відхилення всіх конкурсних пропозицій.

43. Скарга з приводу порушення державним замовником процедури проведення конкурсу або оскарження його рішення подається конкурсантом державному замовнику не пізніше ніж через 15 календарних днів з дня порушення державним замовником процедури проведення конкурсу або прийняття ним відповідного рішення.

44. Подання скарги призупиняє проведення конкурсу, якщо це не заподіє збитків державному замовнику. Загальний термін призупинення проведення конкурсу не може перевищувати 15 календарних днів.

Під час розгляду скарги конкурсант має право взяти участь у її розгляді.

Проведення конкурсу не призупиняється, якщо державний замовник підтверджує, що з урахуванням державних інтересів конкурс необхідно продовжувати.

45. Якщо спірне питання не врегульовано шляхом взаємної згоди, державний замовник протягом 15 календарних днів від дня отримання скарги повинен прийняти обгрунтоване рішення, в якому викласти причини незадоволення скарги, та надіслати прийняте рішення конкурсанту, що подав скаргу, а у разі її задоволення - вжити заходів для врегулювання спірного питання.
