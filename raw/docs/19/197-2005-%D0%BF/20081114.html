КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 березня 2005 р. N 197 Київ

Деякі питання Міністерства у справах молоді та спорту

{ Із змінами, внесеними згідно з Постановою КМ N 954 ( 954-2008-п ) від 22.10.2008 }

Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України зміни, що додаються.

2. Надати Міністру у справах молоді та спорту право зберігати в межах затвердженого обсягу видатків на утримання апарату Міністерства за його працівниками, які переводяться у зв'язку з реорганізацією Державного комітету з питань фізичної культури і спорту та Міністерства у справах сім'ї, дітей та молоді за їх згодою на нову посаду з меншим посадовим окладом, умови оплати праці за попередньою посадою.

3. Взяти до відома, що Міністерство у справах молоді та спорту розміщується по вул. Десятинній, 14, та вул. Еспланадній, 42, у м. Києві.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 40

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 березня 2005 р. N 197

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. У додатку 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851, N 52, ст. 2348; 2003 р., N 30, ст. 1548; 2004 р., N 12, ст. 738, N 35, ст. 2339):

1) позицію "Міністерство у справах сім'ї, дітей та молоді 212 8" замінити позицією такого змісту:

"Міністерство у справах 276 4"; молоді та спорту

2) позицію "Державний комітет з питань фізичної культури і спорту 95 5" виключити.

{ Пункт 2 втратив чинність на підставі Постанови КМ N 954 ( 954-2008-п ) від 22.10.2008 }

3. У постанові Кабінету Міністрів України від 27 серпня 2004 р. N 1125 ( 1125-2004-п ) "Про утворення Державної соціальної служби для сім'ї, дітей та молоді" (Офіційний вісник України, 2004 р., N 35, ст. 2339, N 52, ст. 3451):

1) у тексті постанови слова "Міністерство у справах сім'ї, дітей та молоді" в усіх відмінках замінити словами "Міністерство у справах молоді та спорту" у відповідному відмінку;

2) у Положенні про Державну соціальну службу для сім'ї, дітей та молоді, затвердженому зазначеною постановою:

слово "Мінсім'ядітимолоді" замінити словами "Міністерство у справах молоді та спорту" у відповідному відмінку;

слова "Міністр у справах сім'ї, дітей та молоді" в усіх відмінках замінити словами "Міністр у справах молоді та спорту" у відповідному відмінку.
