КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 жовтня 2006 р. N 1442 Київ

Про скасування деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Скасувати як такі, що не реалізовані, постанови Кабінету Міністрів України від 30 червня 2006 р. N 890 ( 890-2006-п ), від 5 липня 2006 р. N 929 ( 929-2006-п ), N 930 ( 930-2006-п ), N 931 ( 931-2006-п ), N 932 ( 932-2006-п ), N 933 ( 933-2006-п ), N 934 ( 934-2006-п ) та абзац третій останнього розділу постанови Кабінету Міністрів України від 7 вересня 2006 р. N 1290 ( 1290-2006-п ) і абзац сьомий останнього розділу постанови Кабінету Міністрів України від 20 вересня 2006 р. N 1343 ( 1343-2006-п ).
