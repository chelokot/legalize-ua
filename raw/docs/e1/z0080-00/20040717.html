ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 39 від 04.02.2000 Зареєстровано в Міністерстві юстиції України 10 лютого 2000 р. за N 80/4301

( Постанова втратила чинність на підставі Постанови Національного банку N 268 ( z0840-04 ) від 17.06.2004 )

Про внесення змін до нормативно-правових актів Національного банку України

Відповідно до статті 32 Закону України "Про банки і банківську діяльність" ( 872-12 ), підпункту 2.1 постанови Правління Національного банку України від 22.12.99 N 601 ( z0004-00 ) "Про внесення змін до нормативно-правових актів Національного банку України з питань кредитування в іноземній валюті", зареєстрованої в Міністерстві юстиції України 10.01.2000 за N 4/4225, та з метою подальшого удосконалення розрахунків за допомогою платіжних карток міжнародних платіжних систем Правління ПОСТАНОВЛЯЄ:

1. Вилучити пункт 3.5 Положення про впровадження пластикових карток міжнародних платіжних систем у розрахунках за товари, надані послуги та при видачі готівки ( z0086-97 ), затвердженого постановою Правління від 24.02.97 N 37 ( za086-97 ) та зареєстрованого Міністерством юстиції України 24.03.97 за N 86/1890 (із змінами і доповненнями).

У зв'язку з цим пункт 3.6 вважати пунктом 3.5.

2. Постанова набуває чинності через десять днів після її державної реєстрації в Міністерстві юстиції України.

Голова В.С.Стельмах
