КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 грудня 2005 р. N 522-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про утворення робочої групи з питань сприяння органам місцевого самоврядування у встановленні меж м. Києва

{ Із змінами, внесеними згідно з Розпорядженням КМ N 521-р ( 521-2006-р ) від 18.10.2006 }

1. Погодитися з пропозицією Київської міськдержадміністрації щодо утворення робочої групи з питань сприяння органам місцевого самоврядування у встановленні меж м. Києва (далі - робоча група).

2. Затвердити керівником робочої групи Віце-прем'єр-міністра України, Міністра будівництва, архітектури та житлово-комунального господарства Рибака Володимира Васильовича. { Абзац перший пункту 2 із змінами, внесеними згідно з Розпорядженням КМ N 521-р ( 521-2006-р ) від 18.10.2006 }

Керівнику робочої групи:

визначити у двотижневий строк її персональний склад;

залучати у разі потреби до роботи групи представників центральних та місцевих органів виконавчої влади, органів місцевого самоврядування, наукових установ і громадських організацій.

3. Робочій групі:

вивчити проблемні питання, пов'язані з узгодженням меж м. Києва з територіями Козинської селищної ради, Старобезрадичівської та Підгірцівської сільських рад Обухівського району, Ходосівської сільської ради Києво-Святошинського району, Гнідинської і Вишеньківської сільських рад Бориспільського району, Зазим'янської Пухівської та Калинівської сільських рад Броварського району та Хотянівської сільської ради Вишгородського району, а також з передачею території Коцюбинської селищної ради, яка відповідно до Закону України "Про державно-правовий експеримент розвитку місцевого самоврядування в місті Ірпені, селищах Буча, Ворзель, Гостомель, Коцюбинське Київської області" ( 2352-14 ) включена до Ірпінського регіону, до відання Київської міської ради;

забезпечити надання практичної допомоги і сприяння органам місцевого самоврядування у встановленні меж м. Києва.

4. Міністерствам, іншим центральним та місцевим органам виконавчої влади забезпечити надання робочій групі необхідних матеріалів та інформації, а також сприяти у вирішенні питань, пов'язаних з виконанням покладених на неї завдань.

Прем'єр-міністр України Ю.ЄХАНУРОВ
