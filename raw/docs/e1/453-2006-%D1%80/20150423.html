Про встановлення строку виконання операцій з капітального ремонту вальцешліфувальних верстатів на митній території України

Стан: Втратив чинність

Текст документа від 23.04.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 серпня 2006 р. N 453-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 198 ( 198-2015-п ) від 15.04.2015 }

Про встановлення строку виконання операцій з капітального ремонту вальцешліфувальних верстатів на митній території України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1631-р ( 1631-2008-р ) від 27.12.2008 }

1. Відповідно до частини третьої статті 232 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити строк виконання операцій з капітального ремонту вальцешліфувальних верстатів за кодом УКТЗЕД 8460 21 19 00 ( 2371г-14 ) на митній території України 970 днів.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 1631-р ( 1631-2008-р ) від 27.12.2008 }

2. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України Ю.ЄХАНУРОВ
