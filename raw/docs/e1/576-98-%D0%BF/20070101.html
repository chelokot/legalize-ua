КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 квітня 1998 р. N 576 Київ

Про затвердження переліку послуг, що належать до побутових і підлягають патентуванню

{ Із змінами, внесеними згідно з Постановою КМ N 659 ( 659-2006-п ) від 11.05.2006 }

На виконання частини другої статті ( 3-1 ) Закону України "Про патентування деяких видів підприємницької діяльності" ( 98/96-ВР ) Кабінет Міністрів України постановляє:

Затвердити перелік послуг, що належать до побутових і підлягають патентуванню (додається).
