Президент України; Указ від 25.12.2009 № 1108/2009

Про зупинення дії окремих положень постанови Кабінету Міністрів України від 11 листопада 2009 року N 1329

Стан: Чинний

Ідентифікатор: 1108/2009

Текст документа від 25.12.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії окремих положень постанови Кабінету Міністрів України від 11 листопада 2009 року N 1329

{ Додатково див. Конституційне подання Президента ( n0053100-09 ) від 25.12.2009 }

Кабінет Міністрів України 11 листопада 2009 року видав постанову N 1329 ( 1329-2009-п ) "Про залучення Національною акціонерною компанією "Украгролізинг" у 2009 році кредитів під державні гарантії для реалізації інвестиційних проектів, пов'язаних із закупівлею вітчизняної сільськогосподарської техніки", якою погодився з пропозицією Міністерства аграрної політики України щодо залучення Національною акціонерною компанією "Украгролізинг" під державні гарантії кредитів у сумі, що не перевищує 1,3 млрд. гривень, із сплатою відсоткової ставки за ними за рахунок коштів Стабілізаційного фонду ( 835-17 ) та вирішив низку інших пов'язаних із цим питань.

Названа постанова Кабінету Міністрів України ( 1329-2009-п ) не відповідає Конституції України ( 254к/96-ВР ), виходячи з такого.

За Основним Законом держави ( 254к/96-ВР ) бюджетна система України будується на засадах справедливого і неупередженого розподілу суспільного багатства між громадянами і територіальними громадами (частина перша статті 95) ( 254к/96-ВР ).

Згідно з Конституцією України ( 254к/96-ВР ) Державний бюджет України і бюджетна система України встановлюються виключно законами (пункт 1 частини другої статті 92) ( 254к/96-ВР ), одним з яких є закон України про Державний бюджет України на кожний рік. Основним Законом України ( 254к/96-ВР ) встановлено, що виключно законом про Державний бюджет України визначаються будь-які видатки держави на загальносуспільні потреби, розмір і цільове спрямування цих видатків (частина друга статті 95) ( 254к/96-ВР ).

Усупереч наведеним приписам Конституції України ( 254к/96-ВР ) Уряд своїми постановами, які є підзаконними актами, надає державні гарантії за іноземними кредитами, що суттєво перевищують передбачений Законом України "Про Державний бюджет України на 2009 рік" ( 835-17 ) граничний обсяг гарантій у сумі 37 млрд. гривень (частина перша статті 14 Закону) ( 835-17 ). Так, після видання зазначеної постанови Кабінету Міністрів України ( 1329-2009-п ) сума зобов'язань щодо надання державних гарантій за кредитами становить понад 60 млрд. гривень.

Такі дії Кабінету Міністрів України призводять до розбалансування бюджету України, а відтак, порушують приписи Конституції України ( 254к/96-ВР ) щодо прагнення держави до збалансованості бюджету України (частина третя статті 95) ( 254к/96-ВР ).

Тож, вирішення названим підзаконним актом питання щодо надання державних гарантій в обсязі, що перевищує встановлений Законом України "Про Державний бюджет України на 2009 рік" ( 835-17 ) граничний обсяг, не відповідає наведеним вище положенням частини другої статті 92, частин другої та третьої статті 95, а також частини третьої статті 113, пункту 10 статті 116, частини першої статті 117 Конституції України ( 254к/96-ВР ), за якими Кабінет Міністрів України у своїй діяльності керується Конституцією ( 254к/96-ВР ) та законами України, здійснює визначені Конституцією та законами України повноваження, видає постанови і розпорядження в межах своєї компетенції.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію пунктів 1-4, 6 постанови Кабінету Міністрів України від 11 листопада 2009 року N 1329 ( 1329-2009-п ) "Про залучення Національною акціонерною компанією "Украгролізинг" у 2009 році кредитів під державні гарантії для реалізації інвестиційних проектів, пов'язаних із закупівлею вітчизняної сільськогосподарської техніки".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
