Кабінет Міністрів України; Постанова від 20.01.2010 № 37

Про внесення змін до постанов Кабінету Міністрів України від 31 серпня 1995 р. N 700 та від 8 листопада 2006 р. N 1555

Стан: Чинний

Ідентифікатор: 37-2010-п

Текст документа від 03.10.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 січня 2010 р. N 37 Київ

Про внесення змін до постанов Кабінету Міністрів України від 31 серпня 1995 р. N 700 та від 8 листопада 2006 р. N 1555

{ Із змінами, внесеними згідно з Постановою КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 31 серпня 1995 р. N 700 ( 700-95-п ) "Про віднесення посад працівників Національної академії державного управління при Президентові України до категорій посад державних службовців та умови оплати їх праці" - із змінами, внесеними постановами Кабінету Міністрів України від 24 січня 2002 р. N 70 ( 70-2002-п ) (Офіційний вісник України, 2002 р., N 4, ст. 134) і від 5 серпня 2009 р. N 816 ( 816-2009-п ) (Офіційний вісник України, 2009 р., N 59, ст. 2078), та від 8 листопада 2006 р. N 1555 ( 1555-2006-п ) "Питання оплати праці, медичного та соціально-побутового забезпечення деяких працівників Національної академії державного управління при Президентові України" (Офіційний вісник України, 2006 р., N 45, ст. 3002) зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 19

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 20 січня 2010 р. N 37

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 31 серпня 1995 р. N 700 ( 700-95-п ) та від 8 листопада 2006 р. N 1555 ( 1555-2006-п )

1. У постанові Кабінету Міністрів України від 31 серпня 1995 р. N 700 ( 700-95-п ):

{ Підпункт 1 пункту 1 втратив чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

2) пункт 2 викласти в такій редакції:

"2. Установити президенту, першому віце-президенту, віце-президентам Академії, науково-педагогічним і науковим працівникам посадові оклади, передбачені для аналогічних посад у вищих навчальних закладах IV рівня акредитації, іншим керівним працівникам, спеціалістам та службовцям - на рівні відповідних посад центрального апарату міністерств.

Інші умови оплати праці науково-педагогічних та наукових працівників Академії визначаються відповідно до постанови Кабінету Міністрів України від 30 серпня 2002 р. N 1298 ( 1298-2002-п ) "Про оплату праці працівників на основі Єдиної тарифної сітки розрядів і коефіцієнтів з оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" (Офіційний вісник України, 2002 р., N 36, ст. 1699), а для працівників Академії, посади яких віднесено до категорій посад державних службовців, відповідно до постанови Кабінету Міністрів України від 9 березня 2006 р. N 268 ( 268-2006-п ) "Про упорядкування структури та умов оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" (Офіційний вісник України, 2006 р., N 10, ст. 632).";

3) у тексті постанови ( 700-95-п ) слова "ректор" і "проректор" у всіх відмінках замінити відповідно словами "президент" і "віце-президент" у відповідному відмінку.

2. В абзаці другому постановляючої частини постанови Кабінету Міністрів України від 8 листопада 2006 р. N 1555 ( 1555-2006-п ) слова "президент, перший віце-президент, віце-президенти," виключити.
