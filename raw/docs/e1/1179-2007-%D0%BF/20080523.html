ПОСТАНОВА від 26 вересня 2007 р. N 1179 Київ

{ Дію Постанови продовжено до 1 липня 2008 р. у частині ліцензування експорту окремих видів сільськогосподарської продукції згідно з Постановою КМ N 418 ( 418-2008-п ) від 23.04.2008 - втратила чинність на підставі Постанови КМ N 470 ( 470-2008-п ) від 21.05.2008 }

Про затвердження обсягів квот на окремі види сільськогосподарської продукції, експорт якої підлягає ліцензуванню до 30 квітня 2008 р., та порядку видачі ліцензії

{ Із змінами, внесеними згідно з Постановами КМ N 1287 ( 1287-2007-п ) від 31.10.2007 N 271 ( 271-2008-п ) від 28.03.2008 N 418 ( 418-2008-п ) від 23.04.2008 }

{ Установити, що не реалізовані суб'єктами господарської діяльності ліцензії на експорт окремих видів сільськогосподарської продукції, визначені у цій Постанові, дійсні до 30 квітня 2008 р., якщо інше не передбачено законодавством, згідно з Постановою КМ N 271 ( 271-2008-п ) від 28.03.2008 }

{ Установити, що не реалізовані суб'єктами господарської діяльності ліцензії на експорт окремих видів сільськогосподарської продукції, визначені у цій Постанові, дійсні до 1 липня 2008 р., якщо інше не передбачено законодавством, згідно з Постановою КМ N 418 ( 418-2008-п ) від 23.04.2008 }

Кабінет Міністрів України постановляє:

1. Затвердити:

обсяги квот на окремі види сільськогосподарської продукції, експорт якої підлягає ліцензуванню до 30 квітня 2008 р., згідно з додатком 1; { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 271 ( 271-2008-п ) від 28.03.2008 }

Порядок видачі ліцензії на експорт окремих видів сільськогосподарської продукції та розподілу квот, що додається.

2. Утворити комісію з питань розгляду заявок на видачу ліцензії на експорт окремих видів сільськогосподарської продукції та розподілу квот у складі згідно з додатком 2.

3. Продовжити до 31 грудня 2007 р. строк ліцензування та квотування товарів, передбачених додатком 12 до постанови Кабінету Міністрів України від 29 грудня 2006 р. N 1852 ( 1852-2006-п ) "Про затвердження переліків товарів, експорт та імпорт яких підлягає ліцензуванню, та обсягів квот у 2007 році" (Офіційний вісник України, 2007 р., N 1, ст. 38, N 46, ст. 1881).

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1287 ( 1287-2007-п ) від 31.10.2007 }

4. Визнати таким, що втратив чинність, останній абзац пункту 1 постанови Кабінету Міністрів України від 8 грудня 2006 р. N 1701 ( 1701-2006-п ) "Про затвердження обсягів квот на окремі види сільськогосподарської продукції, експорт якої підлягає ліцензуванню до 30 червня 2007 р., та порядку видачі ліцензій" (Офіційний вісник України, 2006 р., N 50, ст. 3325).

5. Внести до постанови Кабінету Міністрів України від 29 грудня 2006 р. N 1852 ( 1852-2006-п ) "Про затвердження переліків товарів, експорт та імпорт яких підлягає ліцензуванню, та обсягів квот у 2007 році" (Офіційний вісник України, 2007 р., N 1, ст. 38, N 46, ст. 1881) такі зміни:

останній абзац пункту 1 виключити;

додаток 12 до постанови ( 1852-2006-п ) визнати таким, що втратив чинність.

6. Ця постанова набирає чинності з 31 грудня 2007 р., крім пункту 3, який набирає чинності з 1 жовтня 2007 року.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 вересня 2007 р. N 1179

ПОРЯДОК видачі ліцензії на експорт окремих видів сільськогосподарської продукції та розподілу квот

1. Цей Порядок визначає механізм видачі Мінекономіки ліцензії та здійснення розподілу квот на експорт окремих видів сільськогосподарської продукції до 31 березня 2008 р. згідно з рекомендаціями комісії з питань розгляду заявок на видачу ліцензії на експорт окремих видів сільськогосподарської продукції та розподілу квот (далі - комісія).

2. Розподіл квот для видачі ліцензії на експорт окремих видів сільськогосподарської продукції (далі - ліцензія) здійснюється на підставі заявки суб'єкта господарської діяльності, що подається Мінекономіки протягом 11 календарних днів після опублікування на його офіційному веб-сайті інформації про початок реєстрації заявок.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 418 ( 418-2008-п ) від 23.04.2008 }

3. Для підтвердження достовірності даних, зазначених у заявці на видачу ліцензії (далі - заявка), суб'єкт господарської діяльності подає:

копію контракту з додатками та специфікаціями до нього;

копію свідоцтва про державну реєстрацію;

довідку Мінагрополітики про наявність обсягів сільськогосподарської продукції, заявленої на експорт (оригінал), яка видається протягом одного календарного дня. { Абзац четвертий пункту 3 із змінами, внесеними згідно з Постановою КМ N 418 ( 418-2008-п ) від 23.04.2008 }

{ Абзац п'ятий пункту 3 виключено на підставі Постанови КМ N 418 ( 418-2008-п ) від 23.04.2008 }

Копії завіряються в установленому порядку.

Суб'єкт господарської діяльності несе відповідальність за недостовірність даних, зазначених у заявці.

4. У разі подання суб'єктом господарської діяльності документів, що не відповідають вимогам законодавства та цього Порядку, Мінекономіки відхиляє заявку. Суб'єкт господарської діяльності може повторно подати протягом одного календарного дня з моменту повернення заявки доопрацьовані документи.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 418 ( 418-2008-п ) від 23.04.2008 }

5. Мінекономіки на наступний після завершення приймання заявок від суб'єктів господарської діяльності день подає їх комісії для розгляду та прийняття рішення про розподіл квот.

Загальний обсяг квоти на експорт окремих видів сільськогосподарської продукції розподіляється комісією пропорційно обсягам, зазначеним у заявках суб'єктів господарської діяльності.

{ Пункт 5 в редакції Постанови КМ N 418 ( 418-2008-п ) від 23.04.2008 }

6. Квота, що визначена під час пропорційного розподілу, зменшується на обсяг, визначений за вже виданими суб'єкту господарської діяльності ліцензіями.

Нерозподілений обсяг квот підлягає повторному розподілу відповідно до цього Порядку.

{ Пункт 6 в редакції Постанови КМ N 418 ( 418-2008-п ) від 23.04.2008 }

{ Пункт 7 виключено на підставі Постанови КМ N 418 ( 418-2008-п ) від 23.04.2008 }

8. За результатами розгляду комісією заявок складається протокол. До розгляду заявки можуть залучатися представники суб'єкта господарської діяльності.

9. Рішення комісії оприлюднюються на офіційному веб-сайті Мінекономіки.

10. Мінекономіки видає ліцензію з урахуванням рекомендацій комісії або у письмовій формі повідомляє у семиденний строк після прийняття відповідного рішення суб'єкту господарської діяльності про відмову в її видачі з обґрунтуванням причин.
