( Наказ втратив чинність на підставі Наказу МЗЕЗторгу N 758 ( z0695-96 ) від 20.11.96 )

Про оплату праці працівників Української академії зовнішньої торгівлі

На виконання постанови Кабінету Міністрів України від 25 січня 1993 року N 44 ( 44-93-п ) "Про оплату праці працівників бюджетних установ і організацій на основі Єдиної тарифної сітки" НАКАЗУЮ:

1. Затвердити схему посад і професій працівників Української академії зовнішньої торгівлі за розрядами Єдиної тарифної сітки:

- професорсько-викладацького складу (додаток N 1);

- керівних і наукових працівників (додаток N 2);

- спеціалістів та службовців (додаток N 3);

- робітників (додаток N 4).

2. Посадові оклади (ставки заробітної плати) працівників установлюються з урахуванням кваліфікаційних вимог і тарифних розрядів відповідної кваліфікації на основі атестації або тарифікації та чинного законодавства.

3. Посадові оклади заступників керівників структурних підрозділів установлюються на 5-15 відсотків нижчими від посадового окладу відповідного керівника.

4. Взяти до відома, що ректор академії має право встановлювати доплати і надбавки працівникам відповідно до діючого законодавства.

5. Контроль за виконанням наказу покласти на заступника Міністра Щербатюка А.А.

Міністр С.Г.Осика
