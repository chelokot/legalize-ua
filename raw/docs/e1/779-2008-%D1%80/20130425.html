КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 травня 2008 р. N 779-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання за межами митної території України робіт з ремонту та відновлення головних редукторів

1. Відповідно до статті 240 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити строк виконання за межами митної території України робіт з ремонту та відновлення (зокрема тих, що вже розпочаті) головних редукторів за товарною підкатегорією 8483 40 98 00 згідно з УКТЗЕД ( 2371г-14 ) 160 днів.

2. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України Ю.ТИМОШЕНКО
