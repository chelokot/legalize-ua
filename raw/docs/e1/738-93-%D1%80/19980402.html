КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 вересня 1993 р. N 738-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 315 ( 315-98-п ) від 17.03.1998 )

Відповідно до Декрету Кабінету Міністрів України від 26 грудня 1992 р. N 16-92 ( 16-92 ) "Про встановлення спеціального режиму експорту окремих видів товарів " уповноважити здійснювати експорт товарів за кодами ТН ЗЕД:

Харцизький державний сталедрото-канатний завод - 7614;

державне підприємство "Київське виробниче об'єднання ім. Артема" - 7615, 7616, 8108;

державне підприємство Київський кабельний завод "Укркабель" - 7404, 7408.19100 7408.19900, 7413.00910, 7602, 7604.10100, 7605.19900, 7614.90100;

орендне підприємство "Ізоляція" - 7112.20000;

Черкаське виробниче об'єднання "Азот" - 8112.20100.
