КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 вересня 2011 р. N 949 Київ

Про внесення змін до постанови Кабінету Міністрів України від 13 квітня 2011 р. N 466

{ Із змінами, внесеними згідно з Постановою КМ N 879 ( 879-2015-п ) від 21.10.2015 }

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 13 квітня 2011 р. N 466 ( 466-2011-п ) "Деякі питання виконання підготовчих і будівельних робіт" (Офіційний вісник України, 2011 р., N 34, ст. 1404) такі зміни:

у Порядку виконання підготовчих робіт, затвердженому зазначеною постановою ( 466-2011-п ), абзац другий пункту 8 виключити;

{ Абзац третій постановляючої частини втратив чинність на підставі Постанови КМ N 879 ( 879-2015-п ) від 21.10.2015 }

{ Абзац четвертий постановляючої частини втратив чинність на підставі Постанови КМ N 879 ( 879-2015-п ) від 21.10.2015 }

{ Абзац п'ятий постановляючої частини втратив чинність на підставі Постанови КМ N 879 ( 879-2015-п ) від 21.10.2015 }

{ Абзац шостий постановляючої частини втратив чинність на підставі Постанови КМ N 879 ( 879-2015-п ) від 21.10.2015 }
