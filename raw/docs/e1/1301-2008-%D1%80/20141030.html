Про розміщення Держкомветеранів та приймальні громадян Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 1301-2008-р

Текст документа від 30.10.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 жовтня 2008 р. N 1301-р Київ

Про розміщення Держкомветеранів та приймальні громадян Кабінету Міністрів України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1127-р ( 1127-2014-р ) від 30.10.2014 }

1. Відповідно до розпорядження Кабінету Міністрів України від 27 лютого 2008 р. N 339 ( 339-2008-р ) "Про забезпечення розміщення центральних органів виконавчої влади" розмістити в будинку по Музейному пров., 12, у м. Києві:

{ Абзац другий пункту 1 втратив чинність на підставі Розпорядження КМ N 1127-р ( 1127-2014-р ) від 30.10.2014 }

приймальню громадян Кабінету Міністрів України - у приміщеннях загальною площею 459,8 кв. метра (робоча площа - 291 кв. метр) на першому (кімнати 12-23 і 29) і другому (кімнати 12-16) поверхах.

2. Фондові державного майна забезпечити укладення з Держкомветеранів договору оренди приміщень на умовах відшкодування балансоутримувачеві будинку фактичних витрат, пов'язаних з їх утриманням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
