Текст документа від 10.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 липня 2004 р. N 909 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 567 ( 567-2011-п ) від 01.06.2011 }

Про внесення змін до постанови Кабінету Міністрів України від 20 лютого 1999 р. N 228

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 20 лютого 1999 р. N 228 ( 228-99-п ) "Про порядок оформлення дозволів для в'їзду в Україну", із змінами, внесеними постановами Кабінету Міністрів України від 29 березня 2002 р. N 410 ( 410-2002-п ) і від 28 липня 2003 р. N 1168 ( 1168-2003-п ) (Офіційний вісник України, 2003 р., N 31, ст. 1623), такі зміни:

абзац третій після слова "Одеса" доповнити словом "Донецьк";

абзац четвертий викласти у такій редакції:

"Порядок оформлення у Державному міжнародному аеропорту "Бориспіль", міжнародних аеропортах "Сімферополь", "Одеса", "Донецьк", Одеському морському торговельному порту дозволу для в'їзду в Україну та його зразок затверджуються Міністерством закордонних справ за погодженням з Міністерством внутрішніх справ, Міністерством юстиції, Адміністрацією Державної прикордонної служби і Службою безпеки";

в абзаці п'ятому слова "департаменті консульської служби" замінити словами "управління консульської служби".

Прем'єр-міністр України В.ЯНУКОВИЧ
