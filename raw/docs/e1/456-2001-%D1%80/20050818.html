РОЗПОРЯДЖЕННЯ від 26 вересня 2001 р. N 456-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про голову Міжвідомчої координаційної ради для забезпечення координації та контролю за ходом підготовки і реалізації проекту Програмної системної позики
