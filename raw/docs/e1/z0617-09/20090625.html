ДЕРЖАВНА ПОДАТКОВА АДМІНІСТРАЦІЯ УКРАЇНИ УКРЗАЛІЗНИЦЯ

НАКАЗ

25.06.2009 N 333/373-Ц

Зареєстровано в Міністерстві юстиції України 13 липня 2009 р. за N 617/16633

Про визнання таким, що втратив чинність, наказу Державної податкової адміністрації України та Укрзалізниці від 23 січня 1997 року N 12/8-Ц

З метою приведення нормативно-правових актів у відповідність до Закону України "Про податок на додану вартість" ( 168/97-ВР ) та згідно зі статтею 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ) НАКАЗУЄМО:

1. Визнати таким, що втратив чинність, наказ Державної податкової адміністрації України та Укрзалізниці від 23 січня 1997 року N 12/8-Ц ( z0032-97 ) "Про Порядок сплати податку на добавлену вартість підприємствами залізничного транспорту", зареєстрований у Міністерстві юстиції України 19.02.97 за N 32/1836.

2. Директору Департаменту податку на додану вартість Лапшину Ю.В. подати цей наказ до Міністерства юстиції України для державної реєстрації.

3. В.о. директора Департаменту господарського забезпечення Задорожньому В.К. у п'ятиденний термін після державної реєстрації наказу забезпечити його тиражування та надсилання органам державної податкової служби.

4. Цей наказ набирає чинності через 10 днів після його державної реєстрації в Міністерстві юстиції України.
