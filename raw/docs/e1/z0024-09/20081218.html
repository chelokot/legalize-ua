Держфінпослуг; Розпорядження від 18.12.2008 № 1453

Про визнання таким, що втратило чинність, розпорядження Державної комісії з регулювання ринків фінансових послуг України від 05.12.2003 N 154

Реєстрація: Мін'юст України від 15.01.2009 № 24/16040

Стан: Чинний

Ідентифікатор: z0024-09

Текст документа від 18.12.2008:

ДЕРЖАВНА КОМІСІЯ З РЕГУЛЮВАННЯ РИНКІВ ФІНАНСОВИХ ПОСЛУГ УКРАЇНИ

РОЗПОРЯДЖЕННЯ

18.12.2008 N 1453

Зареєстровано в Міністерстві юстиції України 15 січня 2009 р. за N 24/16040

Про визнання таким, що втратило чинність, розпорядження Державної комісії з регулювання ринків фінансових послуг України від 05.12.2003 N 154

Відповідно до пункту 1 частини першої статті 28 Закону України "Про фінансові послуги та державне регулювання ринків фінансових послуг" ( 2664-14 ), Закону України "Про державну реєстрацію юридичних осіб та фізичних осіб - підприємців" ( 755-15 ) Державна комісія з регулювання ринків фінансових послуг України ПОСТАНОВИЛА:

1. Визнати таким, що втратило чинність, розпорядження Державної комісії з регулювання ринків фінансових послуг України від 05.12.2003 N 154 ( z1199-03 ) "Про порядок справляння і розміри реєстраційного збору за державну реєстрацію кредитних спілок", зареєстроване в Міністерстві юстиції України 22.12.2003 за N 1199/8520.

2. Департаменту нагляду за кредитними установами разом з юридичним департаментом забезпечити подання цього розпорядження до Міністерства юстиції України для державної реєстрації.

3. Управлінню організаційно-аналітичного забезпечення роботи керівника забезпечити опублікування цього розпорядження у засобах масової інформації після його державної реєстрації.

4. Контроль за виконанням цього розпорядження покласти на члена Комісії - директора департаменту нагляду за кредитними установами.

Голова Комісії В.Альошин
