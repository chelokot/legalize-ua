Про визнання такими, що втратили чинність, деяких наказів Держфінмоніторингу та Генеральної прокуратури України

Реєстрація: Мін'юст України від 28.10.2010 № 1002/18297

Стан: Чинний

Ідентифікатор: z1002-10

Текст документа від 12.10.2010:

ДЕРЖАВНИЙ КОМІТЕТ ФІНАНСОВОГО МОНІТОРИНГУ УКРАЇНИ ГЕНЕРАЛЬНА ПРОКУРАТУРА УКРАЇНИ

НАКАЗ

12.10.2010 N 185/72

Зареєстровано в Міністерстві юстиції України 28 жовтня 2010 р. за N 1002/18297

Про визнання такими, що втратили чинність, деяких наказів Держфінмоніторингу та Генеральної прокуратури України

З метою приведення нормативно-правових актів у відповідність із вимогами Конституції України ( 254к/96-ВР ), Законів України "Про прокуратуру" ( 1789-12 ) та "Про запобігання та протидію легалізації (відмиванню) доходів, одержаних злочинним шляхом, або фінансуванню тероризму" ( 249-15 ) НАКАЗУЄМО:

1. Визнати такими, що втратили чинність:

наказ Державного департаменту фінансового моніторингу Міністерства фінансів України, Генеральної прокуратури України від 20.08.2003 N 98/40 ( z0759-03 ) "Про затвердження Порядку надання Держфінмоніторингом України Генеральній прокуратурі України узагальнених матеріалів щодо фінансових операцій, які можуть бути пов'язані з легалізацією (відмиванням) доходів або фінансуванням тероризму, та отримання інформації про хід їх опрацювання", зареєстрований у Міністерстві юстиції України 02.09.2003 за N 759/8080;

накази Державного комітету фінансового моніторингу України, Генеральної прокуратури України від 31.01.2005 N 35/6 ( z0237-05 ) та від 03.08.2005 N 156/35 ( z0894-05 ) "Про внесення змін та доповнень до Порядку надання Держфінмоніторингом України Генеральній прокуратурі України узагальнених матеріалів щодо фінансових операцій, які можуть бути пов'язані з легалізацією (відмиванням) доходів або фінансуванням тероризму, та отримання інформації про хід їх опрацювання", зареєстровані в Міністерстві юстиції України відповідно 16.02.2005 за N 237/10517 та 16.08.2005 за N 894/11174.

2. Управлінню взаємодії з правоохоронними органами (Катеринич А.А.) спільно з Юридичним управлінням (Гаєвський І.М.) Державного комітету фінансового моніторингу України забезпечити подання цього наказу до Міністерства юстиції України для державної реєстрації.

3. Цей наказ набирає чинності через 10 днів після його реєстрації в Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника Голови Державного комітету фінансового моніторингу України Хилюка В.П. та заступника Генерального прокурора України Занфірова В.А.

Голова Державного комітету фінансового моніторингу України С.Г.Гуржій

Генеральний прокурор України О.І.Медведько
