КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 квітня 1995 р. N 285 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 802 ( 802-2006-п ) від 07.06.2006 }

Про внесення змін до постанови Кабінету Міністрів України від 25 жовтня 1991 р. N 282

Кабінет Міністрів України постановляє:

1. Внести зміни до постанови Кабінету Міністрів України від 25 жовтня 1991 р. N 282 ( 282-91-п ) "Про встановлення плати за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів" (ЗП України, 1991 р., N 11, ст. 115), встановивши плату за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів у розмірі п'ятдесяти неоподатковуваних мінімумів доходів громадян.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 12 квітня 1993 р. N 270 ( 270-93-п ) "Про внесення змін до постанови Кабінету Міністрів України від 25 жовтня 1991 р. N 282" (ЗП України, 1994 р., N 2, ст. 26).
