Про доповнення переліку головних розпорядників коштів державного бюджету

Стан: Втратив чинність

Текст документа від 16.05.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 серпня 2000 р. N 1194 Київ

( Постанова втратила чинність на підставі Постанови КМ N 622 ( 622-2002-п ) від 16.05.2002 )

Про доповнення переліку головних розпорядників коштів державного бюджету

Кабінет Міністрів України постановляє:

Доповнити перелік головних розпорядників коштів державного бюджету, затверджений постановою Кабінету Міністрів України від 8 січня 2000 р. N 13 ( 13-2000-п ) "Про вдосконалення системи головних розпорядників коштів державного бюджету" (Офіційний вісник України, 2000 р., N 2, ст. 36, N 6, ст. 225, N 7, ст. 274, N 12, ст. 468, N 18, ст. 739, N 20, ст. 820, N 23, ст. 940), словами "Пенсійний фонд".
