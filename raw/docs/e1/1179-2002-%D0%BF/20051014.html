Текст документа від 14.10.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 серпня 2002 р. N 1179 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1020 ( 1020-2005-п ) від 14.10.2005 )

Про внесення зміни до постанови Кабінету Міністрів України від 17 лютого 2000 р. N 339

Кабінет Міністрів України постановляє:

Доповнити абзац перший пункту 5 Загального положення про Урядовий комітет, затвердженого постановою Кабінету Міністрів України від 17 лютого 2000 р. N 339 ( 339-2000-п ) (Офіційний вісник України, 2000 р., N 7, ст. 283, N 47, ст. 2038; 2001 р., N 37, ст. 1698 ), словами "а також з правом дорадчого голосу народні депутати України (за згодою)".

У зв'язку з цим доповнити додатки 1-5 до зазначеної постанови словами "Народні депутати України (за згодою)".
