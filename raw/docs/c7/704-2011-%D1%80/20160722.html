Про утворення комісії з проведення реорганізації Головного управління державної служби

Стан: Чинний

Ідентифікатор: 704-2011-р

Текст документа від 22.07.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 липня 2011 р. N 704-р Київ

Про утворення комісії з проведення реорганізації Головного управління державної служби

{ Із змінами, внесеними згідно з Розпорядженням КМ N 770-р ( 770-2011-р ) від 17.08.2011 Постановою КМ N 1387 ( 1387-2011-п ) від 28.12.2011 Розпорядженнями КМ N 896-р ( 896-2014-р ) від 01.10.2014 N 515-р ( 515-2016-р ) від 22.07.2016 }

1. Утворити комісію з проведення реорганізації Головного управління державної служби.

Затвердити головою зазначеної комісії Голову Національного агентства з питань державної служби Ващенка Костянтина Олександровича. { Абзац другий пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 770-р ( 770-2011-р ) від 17.08.2011, Постановою КМ N 1387 ( 1387-2011-п ) від 28.12.2011, Розпорядженнями КМ N 896-р ( 896-2014-р ) від 01.10.2014, N 515-р ( 515-2016-р ) від 22.07.2016 }

2. Голові комісії:

затвердити її персональний склад;

забезпечити здійснення заходів, пов'язаних з реорганізацією Головного управління державної служби;

поінформувати у шестимісячний строк Кабінет Міністрів України про результати проведеної роботи.

Прем'єр-міністр України М.АЗАРОВ
