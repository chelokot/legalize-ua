КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 серпня 2002 р. N 1191 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Про внесення зміни до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

На виконання статті 3 Указу Президента України від 20 березня 2002 р. N 271 ( 271/2002 ) "Про Комітет із Державної премії України в галузі архітектури" Кабінет Міністрів України постановляє:

1. Доповнити додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851; 2002 р., N 7, ст. 293) позицією такого змісту:

"Комітет із Державної премії України в галузі архітектури 6 1".

2. Міністерству фінансів передбачити під час підготовки проекту Закону України "Про Державний бюджет України на 2003 рік" видатки на утримання Комітету із Державної премії України в галузі архітектури.
