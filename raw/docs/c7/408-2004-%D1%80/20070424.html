Про підписання Угоди між Кабінетом Міністрів України та Урядом Республіки Узбекистан про співробітництво в галузі запобігання надзвичайним ситуаціям і ліквідації їх наслідків

Стан: Чинний

Ідентифікатор: 408-2004-р

Текст документа від 24.04.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 червня 2004 р. N 408-р Київ

Про підписання Угоди між Кабінетом Міністрів України та Урядом Республіки Узбекистан про співробітництво в галузі запобігання надзвичайним ситуаціям і ліквідації їх наслідків

{ Із змінами, внесеними згідно з Розпорядженням КМ N 216-р ( 216-2007-р ) від 24.04.2007 }

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Республіки Узбекистан про співробітництво в галузі запобігання надзвичайним ситуаціям і ліквідації їх наслідків.

Уповноважити Міністра з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи Шуфрича Нестора Івановича підписати зазначену Угоду. { Абзац другий Розпорядження в редакції Розпорядження КМ N 216-р ( 216-2007-р ) від 24.04.2007 }
