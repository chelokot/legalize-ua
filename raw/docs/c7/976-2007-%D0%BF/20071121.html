Про схвалення основних прогнозних макропоказників економічного і соціального розвитку України на 2008 рік

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 липня 2007 р. N 976 Київ

Про схвалення основних прогнозних макропоказників економічного і соціального розвитку України на 2008 рік

{ Із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

Кабінет Міністрів України постановляє:

Схвалити такі основні прогнозні макропоказники економічного і соціального розвитку України на 2008 рік та покласти їх в основу розроблення проектів Державної програми економічного і соціального розвитку та Державного бюджету України на 2008 рік:

валовий внутрішній продукт:

номінальний - 889,4 млрд. гривень; { Абзац третій постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

відсотків до попереднього року - 106,8; { Абзац четвертий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

індекс споживчих цін (грудень до грудня попереднього року) - 109,6 відсотка; { Абзац п'ятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

індекс цін виробників промислової продукції (грудень до грудня попереднього року) - 115,5 відсотка; { Абзац шостий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

обмінний курс гривні - 4,95-5,25 гривні за 1 долар США;

фінансові результати звичайної діяльності підприємств до оподаткування - 136,5 млрд. гривень; { Абзац восьмий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

прибуток прибуткових підприємств - 193,8 млрд. гривень; { Абзац дев'ятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

збиток збиткових підприємств - 57,3 млрд. гривень; { Абзац десятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

витрати на оплату праці - 290 млрд. гривень; { Абзац одинадцятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

середньомісячна заробітна плата працівників:

номінальна - 1789 гривні; { Абзац тринадцятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

номінальна, скоригована на індекс споживчих цін, відсотків до попереднього року - 118,7; { Абзац чотирнадцятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }

кількість зайнятих економічною діяльністю віком 15-70 років (у середньому за рік) - 20,8-20,9 млн. осіб;

рівень безробіття, визначений за методологією Міжнародної організації праці, - 6,8-6,7 відсотка;

сальдо торговельного балансу, визначене за методологією платіжного балансу, - від'ємне в розмірі 7538 млн. доларів США; { Абзац сімнадцятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1340 ( 1340-2007-п ) від 21.11.2007 }
