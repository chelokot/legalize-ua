Президент України; Указ від 02.10.2001 № 914/2001

Про матеріально-побутове, медичне та інші види забезпечення генералів армії України, генералів внутрішньої служби України та державних радників юстиції України в разі звільнення за вислугою строку служби

Стан: Втратив чинність

Ідентифікатор: 914/2001

Текст документа від 19.12.2001:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Позначку "Опублікуванню не підлягає" знято Указом Президента N 963/2009 ( 963/2009 ) від 24.11.2009 }

Про матеріально-побутове, медичне та інші види забезпечення генералів армії України, генералів внутрішньої служби України та державних радників юстиції України в разі звільнення за вислугою строку служби

{ Назва Указу із змінами, внесеними згідно з Указом Президента N 1238/2001 ( 1238/2001 ) від 19.12.2001 }

{ Із змінами, внесеними згідно з Указом Президента N 1238/2001 ( 1238/2001 ) від 19.12.2001 }

З метою відзначення особистих заслуг перед державою та впорядкування довічного персонального забезпечення генералів армії України, генералів внутрішньої служби України та державних радників юстиції України в разі звільнення за вислугою строку служби, використання їх досвіду постановляю:

{ Преамбула із змінами, внесеними згідно з Указом Президента N 1238/2001 ( 1238/2001 ) від 19.12.2001 }

1. Генерал армії України, генерал внутрішньої служби України в разі звільнення за вислугою строку служби може бути призначений за його згодою на посаду радника відповідно Міністерства оборони України, Міністерства внутрішніх справ України або іншого військового формування, утвореного згідно з законами України, а державний радник юстиції України - на посаду радника Генеральної прокуратури України.

{ Стаття 1 із змінами, внесеними згідно з Указом Президента N 1238/2001 ( 1238/2001 ) від 19.12.2001 }

2. Генералу армії України, генералу внутрішньої служби України, державному раднику юстиції України за рахунок органу, де його призначено радником: { Абзац перший статті 2 із змінами, внесеними згідно з Указом Президента N 1238/2001 ( 1238/2001 ) від 19.12.2001 }

виплачується грошове забезпечення, надається автотранспортне, медичне та інші види обслуговування за останньою посадою та право мати помічника;

забезпечується раз на рік безоплатне санаторно-курортне лікування з відшкодуванням вартості проїзду в межах України до місця лікування і назад;

оплачується 50 відсотків вартості користування житлом (квартирна плата), комунальними послугами (газ, електроенергія та інші види послуг), телефоном.

3. У разі працевлаштування генерала армії України, генерала внутрішньої служби України, державного радника юстиції України після звільнення за вислугою строку служби на інше підприємство, в установу, організацію незалежно від форми власності на нього поширюється чинність абзаців другого (в частині медичного обслуговування), третього і четвертого статті 2 цього Указу.

{ Стаття 3 із змінами, внесеними згідно з Указом Президента N 1238/2001 ( 1238/2001 ) від 19.12.2001 }

4. Цей Указ набирає чинності з дня його підписання.

Президент України Л.КУЧМА

м. Київ, 2 жовтня 2001 року N 914/2001
