РОЗПОРЯДЖЕННЯ від 14 лютого 2007 р. N 44-р Київ

Деякі питання культурно-мистецького та музейного комплексу "Мистецький арсенал"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 699-р ( 699-2007-р ) від 05.09.2007 }

1. Прийняти пропозицію МКТ щодо передачі майнового комплексу колишнього військового містечка N 5 у м. Києві по вул. Січневого повстання, 28-30, із сфери управління Київської міськдержадміністрації до сфери управління МКТ з метою завершення виконання робіт, передбачених пунктом 3 розпорядження Кабінету Міністрів України від 3 березня 2005 р. N 49 ( 49-2005-р ), та інших робіт із створення культурно-мистецького та музейного комплексу "Мистецький арсенал".
