КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 липня 2011 р. N 777 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 771 ( 771-2019-п ) від 21.08.2019}

Про внесення зміни до пункту 2 Технічного регламенту засобів індивідуального захисту

Кабінет Міністрів України постановляє:

1. Внести зміну до пункту 2 Технічного регламенту засобів індивідуального захисту, затвердженого постановою Кабінету Міністрів України від 27 серпня 2008 р. N 761 ( 761-2008-п ) (Офіційний вісник України, 2008 р., N 66, ст. 2216), виключивши у підпункті 3 абзац дев'ятий.

2. Ця постанова набирає чинності через шість місяців з дня опублікування.

Прем'єр-міністр України М.АЗАРОВ
