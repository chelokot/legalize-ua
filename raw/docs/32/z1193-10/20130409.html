N 40 ( z0455-13 ) від 13.03.2013 }

Про внесення змін до наказу Головдержслужби від 26.11.2009 N 351

Відповідно до постанови Кабінету Міністрів України від 11.10.2010 N 915 ( 915-2010-п ) "Деякі питання надання адміністративних послуг" НАКАЗУЮ:

1. У заголовку, пунктах 1 та 2 наказу Головдержслужби від 26.11.2009 N 351 ( z0043-10 ) "Про затвердження Порядку формування та ведення Реєстру державних та адміністративних послуг", зареєстрованого в Міністерстві юстиції 19.01.2010 за N 43/17338, слова "державних та адміністративних" замінити словом "адміністративних".

2. Унести зміни до Порядку формування та ведення Реєстру державних та адміністративних послуг, затвердженого наказом Головдержслужби від 26.11.2009 N 351 ( z0043-10 ), зареєстрованого в Міністерстві юстиції 19.01.2010 за N 43/17338, такі зміни:

2.1. У заголовку та тексті Порядку ( z0043-10 ) слова "державних та адміністративних" замінити словом "адміністративних".

2.2. У додатку до Порядку ( z0043-10 ) слова "державних та адміністративних" в усіх відмінках та числах замінити словом "адміністративних" у відповідному відмінку.

3. Центру адаптації державної служби до стандартів Європейського Союзу подати у встановленому порядку цей наказ на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням цього наказу залишаю за собою.

5. Цей наказ набирає чинності з дня його офіційного опублікування.

Начальник Головдержслужби Т.Мотренко
