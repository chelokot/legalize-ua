ПОСТАНОВА від 22 грудня 1997 р. N 1447 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 657 ( 657-2010-п ) від 28.07.2010 }

Про Голову Української частини Міжурядової Українсько-Румунської Консультативної Ради з питань торговельно-економічного співробітництва

Кабінет Міністрів України постановляє:

Затвердити Першого віце-прем'єр-міністра України Голубченка Анатолія Костянтиновича Головою Української частини Міжурядової Українсько-Румунської Консультативної Ради з питань торговельно-економічного співробітництва, увільнивши від цих обов'язків Мінченка Анатолія Калениковича.
