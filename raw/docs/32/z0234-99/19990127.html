Держстандарт України; Наказ від 27.01.1999 № 37

Про затвердження Правил обов'язкової сертифікації послуг з тимчасового розміщення (проживання) та Правил обов'язкової сертифікації послуг харчування

Реєстрація: Мін'юст України від 15.04.1999 № 234/3527

Стан: Втратив чинність

Ідентифікатор: z0234-99

Текст документа від 27.01.1999:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ПО СТАНДАРТИЗАЦІЇ, МЕТРОЛОГІЇ ТА СЕРТИФІКАЦІЇ

НАКАЗ

N 37 від 27.01.99 Зареєстровано в Міністерстві м.Київ юстиції України 15 квітня 1999 р. vd990127 vn37 за N 234/3527

Про внесення доповнень до Переліку продукції, що підлягає

обов'язковій сертифікації в Україні, до Термінів введення

обов'язкової сертифікації окремих видів продукції в

Україні та затвердження Правил обов'язкової сертифікації готельних послуг та послуг харчування

На виконання Декрету Кабінету Міністрів України "Про стандартизацію і сертифікацію" від 10.05.93 N 46-93, Закону України "Про туризм" ( 324/95-ВР ), постанов Кабінету Міністрів України від 28.07.97 N 702 ( 702-97-п ) "Про Програму розвитку туризму в Україні до 2005 року" та від 07.12.98 N 1931 ( 1931-98-п ) "Про заходи щодо реалізації Програми діяльності Кабінету Міністрів України", з метою підготовки до введення обов'язкової сертифікації готельних послуг та послуг харчування у Системі сертифікації УкрСЕПРО НАКАЗУЮ:

1. Доповнити Перелік продукції, що підлягає обов'язковій сертифікації в Україні, затверджений наказом Держстандарту України від 30.06.93 N 95 ( z0112-93 ), із змінами та доповненнями, внесеними і затвердженими наказами Держстандарту України від: 27.11.96 N 499 ( z0728-96 ), 17.05.97 N 268 ( z0209-97 ), 04.07.97 N 388 ( z0304-97 ), 11.09.97 N 549 ( z0461-97 ), 20.01.98 N 27 ( z0072-98 ) та, відповідно, зареєстрованими в Мін'юсті України 19.12.96 за N 728/1753, 05.06.97 за N 209/2013, 13.08.97 за N 304/2108, 09.10.97 за N 461/2265 та 04.02.98 за N 72/2512, розділом 35 (додається).

2. Затвердити:

Правила обов'язкової сертифікації готельних послуг (додаються) ( z0236-99 );

Правила обов'язкової сертифікації послуг харчування (додаються) ( z0235-99 ).

3. Доповнити Терміни введення обов'язкової сертифікації окремих видів продукції в Україні ( z0729-96 ), затверджені наказом Держстандарту України від 30.06.93 N 95, із змінами та доповненнями, внесеними і затвердженими наказами Держстандарту України від: 27.11.96 N 499, 04.07.97 N 388, 11.09.97 N 549, 20.01.98 N 27 та, відповідно, зареєстрованими в Мін'юсті України 19.12.96 за N 729/1754, 13.08.97 за N 304/2108, 09.10.97 за N 461/2265, 04.02.98 за N 72/2512, таким текстом:

"35. Готельні послуги та послуги харчування, що надаються суб'єктами туристичної діяльності

35.1. Готельні послуги ............... 01.10.99

35.2. Послуги харчування ............. 01.10.99".

4. Відділу стандартизації, сертифікації та державного нагляду в галузі інформаційних технологій, зв'язку, класифікації ТЕСІ та послуг Держстандарту України (Машовець Т.М.) довести цей наказ до відома центральних органів виконавчої влади, державних центрів стандартизації, метрології та сертифікації, органів з сертифікації в місячний термін після реєстрації в Міністерстві юстиції України.

5. Керівникам органів з сертифікації готельних послуг та послуг харчування довести затверджені в пункті 2 цього наказу Правила обов'язкової сертифікації готельних послуг та послуг харчування до відома зацікавлених підприємств, а також до суб'єктів підприємницької діяльності незалежно від форм власності в місячний термін після реєстрації зазначених Правил у Міністерстві юстиції України.

6. Контроль за виконанням цього наказу покласти на заступника Голови Держстандарту України Є.М.Верещагу.

Голова Держстандарту України Т.Кисільова
