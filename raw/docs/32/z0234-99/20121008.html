Держстандарт України; Наказ від 27.01.1999 № 37

Про затвердження Правил обов'язкової сертифікації послуг з тимчасового розміщення (проживання) та Правил обов'язкової сертифікації послуг харчування

Реєстрація: Мін'юст України від 15.04.1999 № 234/3527

Стан: Втратив чинність

Ідентифікатор: z0234-99

Текст документа від 08.10.2012:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ПО СТАНДАРТИЗАЦІЇ, МЕТРОЛОГІЇ ТА СЕРТИФІКАЦІЇ

НАКАЗ

N 37 від 27.01.99 Зареєстровано в Міністерстві м.Київ юстиції України 15 квітня 1999 р. за N 234/3527

{ Наказ втратив чинність на підставі Наказу Міністерства економічного розвитку і торгівлі N 876 ( z1595-12 ) від 30.07.2012 }

Про затвердження Правил обов'язкової сертифікації послуг з

тимчасового розміщення (проживання) та Правил обов'язкової сертифікації послуг харчування

{ Із змінами, внесеними згідно з Наказом Державного комітету стандартизації, метрології та сертифікації

N 498 ( z0782-02 ) від 30.08.2002 Наказом Державного комітету України з питань технічного регулювання та споживчої політики

N 207 ( z1418-07 ) від 03.09.2007 }

На виконання Декрету Кабінету Міністрів України "Про стандартизацію і сертифікацію" від 10.05.93 N 46-93, Закону України "Про туризм" ( 324/95-ВР ), постанов Кабінету Міністрів України від 28.07.97 N 702 ( 702-97-п ) "Про Програму розвитку туризму в Україні до 2005 року" та від 07.12.98 N 1931 ( 1931-98-п ) "Про заходи щодо реалізації Програми діяльності Кабінету Міністрів України", з метою підготовки до введення обов'язкової сертифікації послуг з тимчасового розміщення (проживання) та послуг харчування у Системі сертифікації УкрСЕПРО НАКАЗУЮ:

{ Преамбула із змінами, внесеними згідно з Наказом Державного комітету України з питань технічного регулювання та споживчої політики N 207 ( z1418-07 ) від 03.09.2007 }

{ Пункт 1 втратив чинність на підставі Наказу Державного комітету стандартизації, метрології та сертифікації N 498 ( z0782-02 ) від 30.08.2002 }

2. Затвердити:

Правила обов'язкової сертифікації послуг з тимчасового розміщення (проживання) (додаються) ( z0236-99 ); { Абзац другий пункту 2 із змінами, внесеними згідно з Наказом Державного комітету України з питань технічного регулювання та споживчої політики N 207 ( z1418-07 ) від 03.09.2007 }

Правила обов'язкової сертифікації послуг харчування (додаються) ( z0235-99 ).

( Пункт 2 втратив чинність на підставі Наказу Державного комітету стандартизації, метрології та сертифікації N 498 ( z0782-02 ) від 30.08.2002 )

4. Відділу стандартизації, сертифікації та державного нагляду в галузі інформаційних технологій, зв'язку, класифікації ТЕСІ та послуг Держстандарту України (Машовець Т.М.) довести цей наказ до відома центральних органів виконавчої влади, державних центрів стандартизації, метрології та сертифікації, органів з сертифікації в місячний термін після реєстрації в Міністерстві юстиції України.

5. Керівникам органів з сертифікації готельних послуг та послуг харчування довести затверджені в пункті 2 цього наказу Правила обов'язкової сертифікації послуг з тимчасового розміщення (проживання) та послуг харчування до відома зацікавлених підприємств, а також до суб'єктів підприємницької діяльності незалежно від форм власності в місячний термін після реєстрації зазначених Правил у Міністерстві юстиції України.

{ Пункт 5 із змінами, внесеними згідно з Наказом Державного комітету України з питань технічного регулювання та споживчої політики N 207 ( z1418-07 ) від 03.09.2007 }

6. Контроль за виконанням цього наказу покласти на заступника Голови Держстандарту України Є.М.Верещагу.

Голова Держстандарту України Т.Кисільова
