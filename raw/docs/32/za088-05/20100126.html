НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

25.08.2005 N 694

Зареєстровано в Міністерстві юстиції України 22 вересня 2005 р. за N 1088/11368

{ Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 10 ( z0027-10 ) від 13.01.2010 }

Про затвердження Ліцензійних умов провадження господарської діяльності з постачання природного газу за нерегульованим тарифом

Відповідно до Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ), Положення про Національну комісію регулювання електроенергетики України, затвердженого Указом Президента України від 14.03.95 N 213 ( 213/95 ) (із змінами), та постанови Кабінету Міністрів України від 14.11.2000 N 1698 ( 1698-2000-п ) "Про затвердження переліку органів ліцензування" (із змінами) Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Затвердити Ліцензійні умови провадження господарської діяльності з постачання природного газу за нерегульованим тарифом, що додаються ( z1088-05 ).

2. Управлінню регулювання та цінової політики нафтогазового комплексу у встановленому порядку забезпечити:

надання Ліцензійних умов провадження господарської діяльності з постачання природного газу за нерегульованим тарифом на затвердження до Державного комітету України з питань регуляторної політики та підприємництва;

опублікування цієї постанови відповідно до чинного законодавства.

3. Суб'єктам господарювання, що провадять діяльність на підставі ліцензії на постачання природного газу за нерегульованим тарифом, привести свою діяльність відповідно до вимог Ліцензійних умов провадження господарської діяльності з постачання природного газу за нерегульованим тарифом протягом трьох місяців з дати набрання чинності цієї постанови.

4. Визнати такою, що втратила чинність, постанову НКРЕ від 12.08.1999 N 1042 ( z0609-99 ) "Про затвердження Умов та Правил здійснення підприємницької діяльності (ліцензійних умов) з постачання природного газу за нерегульованим тарифом", зареєстровану в Міністерстві юстиції України 9 вересня 1999 року за N 609/3902 (із змінами і доповненнями, внесеними постановою НКРЕ від 26 грудня 2000 року N 1266 ( z0086-01 ), зареєстрованою в Мін'юсті 30 січня 2001 року за N 86/5277).
