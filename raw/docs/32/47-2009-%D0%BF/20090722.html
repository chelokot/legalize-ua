Про затвердження порядку використання у 2009 році коштів Стабілізаційного фонду для реалізації інвестиційних проектів соціально-економічного розвитку регіонів

Ідентифікатор: 47-2009-п

Текст документа від 22.07.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 січня 2009 р. N 47 Київ

Про затвердження порядку використання у 2009 році коштів Стабілізаційного фонду для реалізації інвестиційних проектів соціально-економічного розвитку регіонів

{ Із змінами, внесеними згідно з Постановами КМ N 300 ( 300-2009-п ) від 02.04.2009 N 390 ( 390-2009-п ) від 08.04.2009 N 584 ( 584-2009-п ) від 13.05.2009 N 726 ( 726-2009-п ) від 01.07.2009 }

Відповідно до пункту 7 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2009 році коштів Стабілізаційного фонду для реалізації інвестиційних проектів соціально-економічного розвитку регіонів, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 42

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 січня 2009 р. N 47

ПОРЯДОК використання у 2009 році коштів Стабілізаційного фонду для реалізації інвестиційних проектів соціально-економічного розвитку регіонів

1. Цей Порядок визначає механізм використання у 2009 році коштів Стабілізаційного фонду для реалізації інвестиційних проектів соціально-економічного розвитку регіонів (далі - кошти Стабілізаційного фонду).

2. Кошти Стабілізаційного фонду спрямовуються за напрямами, визначеними пунктом 7 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ).

Головним розпорядником коштів Стабілізаційного фонду за зазначеними напрямами (крім напрямів "Будівництво льодових спортивних споруд із штучним льодом відповідно до Державної цільової соціальної програми "Хокей України", "Створення бази олімпійської підготовки по стрільбі з лука", "Виконання Державної програми створення єдиної системи надання екстреної медичної допомоги на період до 2010 року", "Будівництво метрополітену у м. Донецьку"), є Мінрегіонбуд, який спрямовує кошти на: { Абзац другий пункту 2 із змінами, внесеними згідно з Постановами КМ N 390 ( 390-2009-п ) від 08.04.2009, N 584 ( 584-2009-п ) від 13.05.2009, N 726 ( 726-2009-п ) від 01.07.2009 - зміна набирає чинності одночасно із Законом України "Про внесення змін до Закону України "Про Державний бюджет України на 2009 рік" (щодо збільшення обсягу нерозподілених коштів Стабілізаційного фонду)}

здійснення заходів з енергозбереження;

реалізацію проектів, спрямованих на поліпшення екологічної ситуації регіону;

виконання Державної програми "Питна вода України" ( 2455-15 );

будівництво та реконструкцію об'єктів соціально-культурного призначення;

здійснення інших заходів, які сприяють соціально-економічному розвитку регіонів.

Головними розпорядниками коштів є: { Абзац восьмий пункту 2 в редакції Постанови КМ N 300 ( 300-2009-п ) від 02.04.2009 }

за напрямами "Будівництво льодових спортивних споруд із штучним льодом відповідно до Державної цільової соціальної програми "Хокей України" та "Створення бази олімпійської підготовки по стрільбі з лука" - Мінсім'ямолодьспорт, яке використовує кошти в установленому ним порядку за погодженням з Мінфіном; { Абзац дев'ятий пункту 2 в редакції Постанови КМ N 300 ( 300-2009-п ) від 02.04.2009; із змінами, внесеними згідно з Постановами КМ N 584 ( 584-2009-п ) від 13.05.2009, N 726 ( 726-2009-п ) від 01.07.2009 - зміна набирає чинності одночасно із Законом України "Про внесення змін до Закону України "Про Державний бюджет України на 2009 рік" (щодо збільшення обсягу нерозподілених коштів Стабілізаційного фонду)}

за напрямом "Будівництво метрополітену у м. Донецьку" - Мінтрансзв'язку, яке використовує кошти в установленому ним порядку за погодженням з Мінфіном; { Пункт 2 доповнено абзацом згідно з Постановою КМ N 390 ( 390-2009-п ) від 08.04.2009 }

за напрямом "Виконання Державної програми створення єдиної системи надання екстреної медичної допомоги на період до 2010 року" - МОЗ, яке використовує кошти в порядку, встановленому Кабінетом Міністрів України. { Абзац пункту 2 в редакції Постанови КМ N 300 ( 300-2009-п ) від 02.04.2009 }

2-1. Нерозподілені кошти Стабілізаційного фонду в обсязі 150000 тис. гривень та кошти Стабілізаційного фонду, передбачені для будівництва метрополітену у м. Донецьку в обсязі 50000 тис. гривень, спрямувати на: { Абзац перший пункту 2-1 в редакції Постанови КМ N 726 ( 726-2009-п ) від 01.07.2009 - зміна набирає чинності одночасно із Законом України "Про внесення змін до Закону України "Про Державний бюджет України на 2009 рік" (щодо збільшення обсягу нерозподілених коштів Стабілізаційного фонду)}

1) реалізацію таких інвестиційних проектів соціально-економічного розвитку регіонів:

реконструкція системи водопостачання м. Львова - 147300 тис. гривень;

реконструкція та реставрація будинку-музею Т.Г. Шевченка (м. Канів) - 22400 тис. гривень;

2) завершення робіт з ліквідації наслідків стихійного лиха, що сталося 23-27 липня 2008 р., у тому числі на проведення капітального ремонту:

обласному бюджету Тернопільської області - 17200 тис. гривень;

обласному бюджету Вінницької області - 13100 тис. гривень.

{ Порядок доповнено пунктом 2-1 згідно з Постановою КМ N 584 ( 584-2009-п ) від 13.05.2009 }

3. Перелік об'єктів, які фінансуються за рахунок коштів Стабілізаційного фонду, формується Мінрегіонбудом на підставі пропозицій, поданих місцевими органами виконавчої влади, органами місцевого самоврядування, народними депутатами України у двотижневий строк після затвердження цього Порядку, і затверджується Кабінетом Міністрів України.

До переліку включаються:

об'єкти державної та комунальної власності, що не перебувають в управлінні, оренді чи концесії;

об'єкти, включені до затверджених в установленому порядку державних, регіональних та місцевих програм розвитку територій;

об'єкти, проектно-кошторисна документація на які оформлена відповідно до Порядку затвердження інвестиційних програм і проектів будівництва та проведення їх комплексної державної експертизи, затвердженого постановою Кабінету Міністрів України від 31 жовтня 2007 р. N 1269 ( 1269-2007-п ) (Офіційний вісник України, 2007 р., N 84, ст. 3106).

4. Для розгляду пропозицій щодо формування переліку об'єктів та їх перевірки на відповідність вимогам, визначеним цим Порядком, Мінрегіонбуд утворює комісію.

Рішення комісії оформлюється протоколом.

На підставі зазначеного рішення головний розпорядник бюджетних коштів готує проект постанови Кабінету Міністрів України про затвердження переліку об'єктів у розрізі регіонів з визначенням розпорядників бюджетних коштів нижчого рівня і подає його у місячний строк після затвердження цього Порядку на розгляд Кабінету Міністрів України.

5. Закупівля товарів, робіт і послуг проводиться в установленому законодавством порядку.

6. Фінансування об'єктів капітального будівництва здійснюється відповідно до Порядку державного фінансування капітального будівництва, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) (Офіційний вісник України, 2001 р., N 52, ст. 2374).

7. Перерахування коштів Стабілізаційного фонду здійснюється в межах установлених обсягів видатків відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

8. Розпорядники бюджетних коштів нижчого рівня щомісяця до 5 числа подають Мінрегіонбуду звіти про виконання робіт та використання коштів у розрізі об'єктів.

9. Мінрегіонбуд узагальнює звіти про виконання робіт та використання коштів у розрізі об'єктів, подані розпорядниками бюджетних коштів нижчого рівня, та інформує щокварталу до 25 числа наступного місяця Мінфін та Кабінет Міністрів України.

10. Державне казначейство інформує щомісяця до 16 числа Мінрегіонбуд, Мінфін і Мінекономіки про обсяги перерахування коштів Стабілізаційного фонду в розрізі регіонів та об'єктів.

11. Основні засоби, придбані за рахунок коштів Стабілізаційного фонду, після введення в експлуатацію зараховуються на баланс балансоутримувача об'єкта державної та комунальної власності.

12. Складення та подання фінансової звітності про використання коштів Стабілізаційного фонду, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
