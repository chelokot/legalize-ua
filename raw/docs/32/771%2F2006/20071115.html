Стан: Втратив чинність

Текст документа від 15.11.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1020/2007 ( 1020/2007 ) від 25.10.2007 }

Про заміщення посади начальника регіонального відділення Фонду державного майна України військовослужбовцем

Установити, що посада начальника регіонального відділення Фонду державного майна України по Донецькій області може бути заміщена військовослужбовцем Служби безпеки України з граничним військовим званням полковника.

Президент України В.ЮЩЕНКО

м. Київ, 21 вересня 2006 року N 771/2006
