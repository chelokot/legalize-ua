ПОСТАНОВА від 17 березня 1998 р. N 318 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Про внесення доповнення до постанови Кабінету Міністрів України від 24 листопада 1997 р. N 1308

Кабінет Міністрів України постановляє:

Підпункт "б" пункту 3 постанови Кабінету Міністрів України від 24 листопада 1997 р. N 1308 ( 1308-97-п ) "Про Міжвідомчу координаційну раду з підготовки другого проекту розвитку підприємств" доповнити абзацом шостим такого змісту:

"Державний комітет з питань розвитку підприємництва - дерегулювання підприємницької діяльності".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
