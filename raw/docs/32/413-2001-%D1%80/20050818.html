КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 вересня 2001 р. N 413-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про внесення змін до розпорядження Кабінету Міністрів України від 27 червня 2001 р. N 261

Доповнити розпорядження Кабінету Міністрів України від 27 червня 2001 р. N 261 ( 261-2001-р ) новим пунктом 2 такого змісту:

"2. Проект нормативно-правового акта, схвалений робочою групою у поданій редакції або з урахуванням за результатами обговорення пропозицій та зауважень, готується (доопрацьовується) відповідним структурним підрозділом Секретаріату Кабінету Міністрів України згідно з протоколом засідання робочої групи і подається для розгляду на засіданні Кабінету Міністрів України".

У зв'язку з цим пункт 2 вважати пунктом 3.
