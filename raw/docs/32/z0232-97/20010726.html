N 178 від 21.04.97 Зареєстровано в Міністерстві м.Київ юстиції України 23 червня 1997 року vd970421 vn178 за N 232/2036

Про затвердження Положення про встановлення надбавок працівникам Державної митної служби України

( Із змінами, внесеними згідно з Наказом Держмитслужби N 484 ( z0639-01 ) від 13.07.2001 )

На виконання постанови Кабінету Міністрів України від 12 березня 1997 року N 225 ( 225-97-п ) "Про умови оплати праці працівників Державної митної служби" НАКАЗУЮ:

1. Затвердити Положення про встановлення надбавок працівникам Державної митної служби.

2. Правовому управлінню провести державну реєстрацію Положення в Міністерстві юстиції України.

3. Ввести в дію Положення про встановлення надбавок працівникам Державної митної служби після реєстрації в Міністерстві юстиції України.

4. Начальникам установ Державної митної служби привести у відповідність до Положення накази про встановлення надбавок працівникам та розрахунки фондів оплати праці.

5. Наказ Держмиткому України від 02.10.96 р. N 458 ( z0594-96 ) вважати таким, що втратив чинність.

6. Контроль за виконанням цього наказу покласти на Фінансово-економічне управління (Грінченко В.М.), Правове управління (Будніков М.П.).

Голова Служби Л.Деркач

Затверджено наказом Державної митної служби України від 21.04.97 р. N 178

Положення про встановлення надбавок працівникам Державної митної служби

Це Положення розроблено з метою запровадження єдиного порядку встановлення надбавок працівникам Державної митної служби України з урахуванням характеру й складності виконуваної роботи та для підвищення рівня їх матеріального забезпечення відповідно до постанови Кабінету Міністрів України від 12.03.97 N 225 ( 225-97-п ) "Про умови оплати праці працівників Державної митної служби", зі змінами, унесеними постановою Кабінету Міністрів України від 21.06.2001 N 666 ( 666-2001-п ) "Про внесення змін до постанови Кабінету Міністрів України від 12 березня 1997 р. N 225. ( Абзац перший в редакції Наказу Держмитслужби N 484 ( z0639-01 ) від 13.07.2001 )

Згідно з вищезгаданими постановами: ( Абзац другий із змінами, внесеними згідно з Наказом Держмитслужби N 484 ( z0639-01 ) від 13.07.2001 )

1. Надбавки у розмірі до 50 відсотків посадового окладу з урахуванням надбавки за персональні звання встановлюються наказом по установі службовим особам, які пропрацювали в митних органах не менш як два роки і здійснюють митний контроль за переміщенням товарів та інших предметів через митний кордон України, виконують обов'язки щодо справляння мита та інших платежів, а також здійснюють контроль за розрахунками по них з Державним бюджетом та обов'язки, пов'язані із забезпеченням виконання зазначених функцій. ( Абзац перший пункту 1 із змінами, внесеними згідно з Наказом Держмитслужби N 484 ( z0639-01 ) від 13.07.2001 )

Коло таких працівників визначається виключно згідно з посадовими інструкціями, в яких повинні бути чітко сформульовані згадані функції.

2. Надбавки в розмірі до 50 відсотків посадового окладу з урахуванням надбавки за персональне звання встановлюються працівникам за високі досягнення в праці й виконання особливо важливих завдань. ( Пункт 2 в редакції Наказу Держмитслужби N 484 ( z0639-01 ) від 13.07.2001 )

3. У разі несвоєчасного, неякісного виконання завдання ці надбавки скасовуються або зменшуються.

4. Зазначені надбавки встановлюються в такому порядку:

- керівникам органів, підпорядкованих Державній митній службі України, - наказом Голови Служби, за поданням відповідних начальників регіональних митниць, заступників Голови Служби;

- працівникам центрального апарату - наказом Голови Служби, за поданням заступників Голови Служби, начальників структурних підрозділів центрального апарату;

- заступникам керівника, іншим працівникам - наказом керівника митного органу.

5. При встановленні зазначених надбавок службовим особам митних органів ураховуються обсяги виконуваної ними роботи, кваліфікація, компетентність, ініціативність, дотримання ними виконавчої та трудової дисципліни.

6. Установлення надбавок та їх перегляд здійснюються щорічно з урахуванням показників роботи працівників митних органів та затверджених лімітів на оплату праці. ( Пункт 6 в редакції Наказу Держмитслужби N 484 ( z0639-01 ) від 13.07.2001 )
