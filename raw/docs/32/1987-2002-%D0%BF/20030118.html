КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 грудня 2002 р. N 1987 Київ

Про затвердження переліку пунктів пропуску для автомобільного сполучення через державний кордон України для переміщення громадянами транспортних засобів та шасі і кузовів до них

( Із змінами, внесеними згідно з Постановою КМ N 92 ( 92-2003-п ) від 18.01.2003 )

Відповідно до частини другої статті 95 Митного кодексу України ( 92-15 ) Кабінет Міністрів України постановляє:

1. Затвердити перелік пунктів пропуску для автомобільного сполучення через державний кордон України для переміщення громадянами транспортних засобів та шасі і кузовів до них (додається).

Через зазначені у переліку пункти пропуску громадянами ввозяться на митну територію України транспортні засоби за кодами згідно з УКТЗЕД ( 2371г-14 ) 8701, 8702, 8703, 8704, 8705, 8711, 8716 та шасі і кузови за кодами 8706 і 8707 для транспортних засобів товарних позицій 8701-8705:

для вільного використання;

у режимі тимчасового ввезення у разі сплати податків і зборів, передбачених законодавством;

з метою транзиту у разі внесення передбаченої законодавством грошової застави.

2. Ця постанова набирає чинності з 1 січня 2004 року.

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 92 ( 92-2003-п ) від 18.01.2003 )
