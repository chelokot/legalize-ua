МІНІСТЕРСТВО РЕГІОНАЛЬНОГО РОЗВИТКУ ТА БУДІВНИЦТВА УКРАЇНИ

НАКАЗ

24.11.2008 N 531

Зареєстровано в Міністерстві юстиції України 9 грудня 2008 р. за N 1175/15866

{ Наказ втратив чинність на підставі Наказу Міністерства регіонального розвитку та будівництва N 341 ( z0977-09 ) від 18.08.2009 }

Про затвердження індексу для обчислення розміру плати за видачу архітектурно-планувального завдання та технічних умов

На виконання постанови Кабінету Міністрів України від 20.12.99 N 2328 ( 2328-99-п ) "Про Порядок надання архітектурно-планувального завдання та технічних умов щодо інженерного забезпечення об'єкта архітектури і визначення розміру плати за їх видачу" НАКАЗУЮ:

1. Затвердити індекс для обчислення розміру плати за видачу архітектурно-планувального завдання та технічних умов, наведених у додатках 2 та 3 до Порядку надання архітектурно-планувального завдання та технічних умов щодо інженерного забезпечення об'єкта архітектури і визначення розміру плати за їх видачу, затвердженого постановою Кабінету Міністрів України від 20.12.99 N 2328 ( 2328-99-п ), у розмірі 7,01.

2. Управлінню планування забудови територій (Сіленко М.В.) подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3. Управлінню планування забудови територій (Сіленко М.В.) і Управлінню ціноутворення, експертизи та контролю вартості у будівництві (Губень П.І.) забезпечити доведення цього наказу до відома заінтересованих організацій.

4. Визнати таким, що втратив чинність, наказ Мінрегіонбуду від 26.11.2007 N 332 ( z1363-07 ), "Про затвердження індексу для визначення розміру плати за виконання робіт", зареєстрований у Міністерстві юстиції України 10.12.2007 за N 1363/14630.

5. Контроль за виконанням цього наказу покласти на першого заступника Міністра А.В.Беркуту.

Міністр В.Куйбіда
