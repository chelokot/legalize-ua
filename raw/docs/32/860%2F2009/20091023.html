Президент України; Указ від 23.10.2009 № 860/2009

Про внесення зміни до Указу Президента України від 22 серпня 2002 року N 746

Стан: Чинний

Ідентифікатор: 860/2009

Текст документа від 23.10.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення зміни до Указу Президента України від 22 серпня 2002 року N 746

Внести до додатка N 1 до Указу Президента України від 22 серпня 2002 року N 746 ( 746/2002 ) "Про Державний Протокол та Церемоніал України" (в редакції Указу від 3 березня 2008 року N 192) ( 192/2008 ) зміну, доповнивши пункт 1 після абзацу "Голова Служби безпеки України" новим абзацом такого змісту:

"Голова Служби зовнішньої розвідки України".

Президент України В.ЮЩЕНКО

м. Київ, 23 жовтня 2009 року N 860/2009
