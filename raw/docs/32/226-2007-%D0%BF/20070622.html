Кабінет Міністрів України; Постанова, Порядок від 14.02.2007 № 226

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для підтримки літакобудування та космічної галузі, спрямованої на створення та впровадження у виробництво сучасної техніки, шляхом здешевлення кредитів

Стан: Чинний

Ідентифікатор: 226-2007-п

Текст документа від 22.06.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 лютого 2007 р. N 226 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для підтримки літакобудування та космічної галузі, спрямованої на створення та впровадження у виробництво сучасної техніки, шляхом здешевлення кредитів

{ Із змінами, внесеними згідно з Постановою КМ N 855 ( 855-2007-п ) від 22.06.2007 }

Кабінет Міністрів України постановляє:

1. Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для підтримки літакобудування та космічної галузі, спрямованої на створення та впровадження у виробництво сучасної техніки, шляхом здешевлення кредитів, що додається.

2. Міністерству промислової політики затвердити в установленому порядку в місячний строк Порядок конкурсного відбору інноваційних та інвестиційних проектів, спрямованих на створення та впровадження у виробництво сучасної техніки у сфері літакобудування та космічної галузі.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 лютого 2007 р. N 226

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для підтримки літакобудування та космічної галузі, спрямованої на створення та впровадження у виробництво сучасної техніки, шляхом здешевлення кредитів

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Мінпромполітики за програмою "Державна підтримка літакобудування та космічної галузі на створення та впровадження у виробництво сучасної техніки через механізм здешевлення кредитів" (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються на відшкодування відсоткових ставок за кредитами, що залучаються підприємствами та організаціями літакобудування та космічної галузі (далі - виконавці проектів) на реалізацію інноваційних та інвестиційних проектів, спрямованих на створення та впровадження у виробництво сучасної техніки на зазначених підприємствах та організаціях, та за кредитами, що надані підприємствам та організаціям літакобудування у попередні роки на створення, впровадження у виробництво і на виробництво авіаційної техніки на зазначених підприємствах та в організаціях, які діють в 2007 році (далі - підприємства літакобудування).

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 855 ( 855-2007-п ) від 22.06.2007 }

3. За рахунок бюджетних коштів виконавцям проектів та підприємствам літакобудування відшкодовується сума фактично сплачених ними відсотків за користування середньостроковими (до трьох років) і довгостроковими (до п'яти років) кредитами, яка не може перевищувати подвійну облікову ставку Національного банку, що діяла на дату їх нарахування.

{ Пункт 3 в редакції Постанови КМ N 855 ( 855-2007-п ) від 22.06.2007 }

4. Бюджетні кошти не можуть бути спрямовані на погашення будь-яких штрафних санкцій та (або) пені за користування кредитами комерційних банків та інших фінансових установ.

5. Відбір інноваційних та інвестиційних проектів здійснюється на конкурсній основі у порядку, затвердженому Мінпромполітики за погодженням з МОН, Мінфіном, Мінекономіки та НКАУ.

6. Порядок конкурсного відбору інноваційних та інвестиційних проектів повинен містити такі вимоги:

1) до інноваційного та інвестиційного проекту:

відповідність проекту критеріям відбору та визначеним пріоритетам;

максимальна ефективність використання бюджетних коштів;

ефективність проекту (обсяг прибутку, строк окупності, створення нових робочих місць, надходження платежів до бюджету);

наявність договору про наміри кредитування проекту, укладеного між виконавцем проекту і банком;

наявність висновку комплексної державної експертизи інвестиційного проекту та/або свідоцтва про реєстрацію інноваційного проекту;

2) до виконавця проекту:

провадження господарської діяльності протягом не менше ніж двох років;

відсутність заборгованості з виплати заробітної плати;

відсутність заборгованості перед державним бюджетом ( 489-16 ) за залученими кредитами, а також із сплати податків, зборів (обов'язкових платежів);

достатність обігових коштів для забезпечення поточної діяльності;

виконання зобов'язань щодо погашення та обслуговування кредиту;

часткове фінансування інноваційного та інвестиційного проекту.

7. Мінпромполітики укладає з виконавцем проекту - переможцем конкурсу договір на здешевлення кредитів, залучених на реалізацію інноваційних та інвестиційних проектів, форма якого затверджується Мінпромполітики за погодженням з Мінекономіки, Мінфіном та НКАУ, і з підприємством літакобудування договір на здешевлення кредитів залучених у попередні роки на створення, впровадження у виробництво і на виробництво авіаційної техніки, форма якого затверджується Мінпромполітики.

{ Пункт 7 із змінами, внесеними згідно з Постановою КМ N 855 ( 855-2007-п ) від 22.06.2007 }

8. Щомісяця до 7 числа наступного звітного періоду виконавець проекту та підприємство літакобудування подають Мінпромполітики документи, зазначені в укладеному згідно з пунктом 7 цього Порядку договором, що підтверджують погашення кредитів та відсотків за користування ними, а у грудні - до 25 грудня.

{ Пункт 8 із змінами, внесеними згідно з Постановою КМ N 855 ( 855-2007-п ) від 22.06.2007 }

9. Мінпромполітики здійснює відшкодування сплачених виконавцем проекту та підприємством літакобудування відсотків за користування кредитом на підставі копії платіжного доручення про сплату відсотків за користування кредитом, нотаріально засвідченої копії кредитного договору, укладеного з банком, довідки банку про надання кредиту, довідки-розрахунку банку про сплату суми відсотків за користування кредитом у відповідний період і довідки-розрахунку банку про сплату суми компенсації за залученим кредитом у відповідний період. { Абзац перший пункту 9 із змінами, внесеними згідно з Постановою КМ N 855 ( 855-2007-п ) від 22.06.2007 }

Операції з бюджетними коштами проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

Видатки на проведення компенсаційних виплат здійснюються Мінпромполітики в установленому порядку на підставі документів, зазначених в абзаці першому цього пункту, шляхом перерахування бюджетних коштів з реєстраційного рахунка Мінпромполітики як головного розпорядника бюджетних коштів на поточний рахунок виконавця проекту та підприємства літакобудування, відкритий в установі банку. { Абзац третій пункту 9 із змінами, внесеними згідно з Постановою КМ N 855 ( 855-2007-п ) від 22.06.2007 }

10. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
