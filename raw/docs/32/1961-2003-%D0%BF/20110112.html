Кабінет Міністрів України; Постанова від 17.12.2003 № 1961

Про внесення зміни до переліку інвестиційних проектів міжнародних фінансових організацій, для реалізації яких при ввезенні (пересиланні) товарів на митну територію України може видаватися податковий вексель із строком погашення до кінця поточного бюджетного року

Стан: Втратив чинність

Ідентифікатор: 1961-2003-п

Текст документа від 12.01.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 грудня 2003 р. N 1961 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1236 ( 1236-2010-п ) від 27.12.2010 }

Про внесення зміни до переліку інвестиційних проектів

міжнародних фінансових організацій, для реалізації яких

при ввезенні (пересиланні) товарів на митну територію

України може видаватися податковий вексель із строком погашення до кінця поточного бюджетного року

Кабінет Міністрів України постановляє:

1. Виключити у переліку інвестиційних проектів міжнародних фінансових організацій, для реалізації яких при ввезенні (пересиланні) товарів на митну територію України може видаватися податковий вексель із строком погашення до кінця поточного бюджетного року, затвердженому постановою Кабінету Міністрів України від 24 жовтня 2001 р. N 1384 ( 1384-2001-п ) "Про внесення зміни до Порядку випуску, обігу та погашення векселів, які видаються на суму податку на додану вартість при ввезенні (пересиланні) товарів на митну територію України" (Офіційний вісник України, 2001 р., N 43, ст. 1928), такі позиції:

"Європейський банк від 8 травня Друга кредитна лінія для реконструкції та 1998 р. N 673 розвитку малих і середніх розвитку підприємств";

"Європейський банк від 6 жовтня Кредит на закупівлю палива реконструкції та 2000 р. N 885 на зимовий період розвитку 2000/2001

Міжнародний банк від 12 грудня Позика на реструктуризацію реконструкції та 1996 р. N 4118 вугільної галузі (кредитні розвитку UA лінії Мінфіну)

Міжнародний банк від 28 вересня Проект реабілітації реконструкції та 1995 р. гідроелектростанцій та розвитку N 3865 UA управління у системі";

"Міжнародний банк від 15 вересня Проект системи реконструкції та 1998 р. казначейства". розвитку N 4285 UA

2. Ця постанова набирає чинності з дня опублікування.
