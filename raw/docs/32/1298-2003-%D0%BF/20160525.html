Про доповнення пункту 5 Порядку встановлення квоти підготовки фахівців для агропромислового комплексу і соціальної сфери сільської місцевості у вищих навчальних закладах

Текст документа від 25.05.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 серпня 2003 р. N 1298 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 333 ( 333-2016-п ) від 11.05.2016 }

Про доповнення пункту 5 Порядку встановлення квоти підготовки фахівців для агропромислового комплексу і соціальної сфери сільської місцевості у вищих навчальних закладах

Кабінет Міністрів України постановляє:

Доповнити пункт 5 Порядку встановлення квоти підготовки фахівців для агропромислового комплексу і соціальної сфери сільської місцевості у вищих навчальних закладах, затвердженого постановою Кабінету Міністрів України від 29 червня 1999 р. N 1159 ( 1159-99-п ) "Про підготовку фахівців для роботи в сільській місцевості" (Офіційний вісник України, 1999 р., N 26, ст. 1239), після слів "у вищих сільськогосподарських" цифрами і словами "50 відсотків - у вищих педагогічних".

Прем'єр-міністр України В.ЯНУКОВИЧ
