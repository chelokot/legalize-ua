Кабінет Міністрів України; Розпорядження від 28.01.2000 № 57-р

Про розміщення ЗАТ "Кредитно-гарантійна установа"

Стан: Втратив чинність

Ідентифікатор: 57-2000-р

Текст документа від 25.02.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 січня 2000 р. N 57-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 115-р ( 115-2003-р ) від 25.02.2003 )

1. Розмістити ЗАТ "Кредитно-гарантійна установа" у приміщеннях п'ятого поверху будинку по вул. Артема, 73, у м. Києві на умовах оренди.

АК "Держінвест України" і корпорації "Укрбудматеріали" забезпечити у місячний термін вивільнення зазначених приміщень і укладення із ЗАТ "Кредитно-гарантійна установа" договору їх оренди.

2. У зв'язку з ліквідацією відповідно до Указу Президента України від 15 грудня 1999 р. N 1573 ( 1573/99 ) "Про зміни у структурі центральних органів виконавчої влади" Національного агентства з управління державними корпоративними правами визнати такими, що втратили чинність:

пункт 7 постанови Кабінету Міністрів України від 31 липня 1998 р. N 1195 ( 1195-98-п ) "Питання Національного агентства з управління державними корпоративними правами" (Офіційний вісник України, 1998 р., N 31, ст. 1167);

постанову Кабінету Міністрів України від 26 квітня 1999 р. N 698 ( 698-99-п ) "Питання Національного агентства з управління державними корпоративними правами";

розпорядження Кабінету Міністрів України від 24 травня 1999 р. N 464 ( 464-99-р ).

Прем'єр-міністр України В.ЮЩЕНКО
