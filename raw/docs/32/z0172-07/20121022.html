20.02.2007 N 62/23

Зареєстровано в Міністерстві юстиції України 28 лютого 2007 р. за N 172/13439

{ Наказ втратив чинність на підставі Наказу Управління державної охорони N 433/1445/5 ( z1676-12 ) від 01.10.2012 }

Про внесення змін до наказу Управління державної охорони України та Державного комітету архівів України від 10.09.2004 N 66/96

Відповідно до Закону України "Про внесення змін до деяких законодавчих актів України щодо посилення протидії незаконному обігу архівних документів" ( 534-16 ) НАКАЗУЄМО:

1. У пункті 3 наказу Управління державної охорони України та Державного комітету архівів України від 10.09.2004 N 66/96 ( z1397-04 ) "Про затвердження Положення про галузевий державний архів Управління державної охорони України", зареєстрованого в Міністерстві юстиції України 01.11.2004 за N 1397/9996 (далі - Наказ), слова "Доброчинського С.Б." замінити на слова "Бабича І.Л.".

2. Підпункт 4 пункту 7 Положення про галузевий державний архів Управління державної охорони України, затвердженого Наказом ( z1397-04 ), виключити.

У зв'язку з цим підпункти 5-12 пункту 7 цього Положення ( z1397-04 ) вважати відповідно підпунктами 4-11.

3. Галузевому державному архіву Управління державної охорони України (Лук'яненко Л.В.) та відділу формування Національного архівного фонду та діловодства управління формування та зберігання Національного архівного фонду Державного комітету архівів України (Кузнєцова М.І.) подати Наказ у встановленому порядку на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника начальника Управління державної охорони України Бабича І.Л. та заступника Голови Державного комітету архівів України Портнова Г.В.

Начальник Управління державної охорони України П.В.Плюта
