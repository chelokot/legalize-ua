Кабінет Міністрів України; Розпорядження від 22.01.1996 № 50-р

Про Комісію для підготовки проектів двосторонніх угод України з Болгарією, Чехією та Федеративною Республікою Німеччина

Стан: Втратив чинність

Ідентифікатор: 50-96-р

Текст документа від 15.11.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 січня 1996 р. N 50-р Київ

( Із змінами, внесеними згідно з Розпорядженням КМ N 727-р ( 727-96-р ) від 15.11.96 )

Для підготовки проектів двосторонніх угод України з Болгарією, Чехією та Федеративною Республікою Німеччини з питань Ямбурзьких угод і проведення переговорів утворити Комісію у складі:

ЛОПАТІН - перший заступник голови Володимир Олексійович Держнафтогазпрому (голова Комісії)

БЄЛКІН - член правління АТ "Укргазпром" Борис Леонідович

ГУДИМА - заступник Міністра закордонних Борис Миколайович справ

ДІДЕНКО - заступник начальника управління Сергій Миколайович МЗЕЗторгу

ДОБРОВОЛЬСЬКИЙ - начальник відділу Мінекономіки Микола Федорович

ЛІСОВЕНКО - заступник начальника управління Віталій Васильович Мінфіну

СКЛЯРЕНКО - заступник начальника управління Юрій Миколайович Мінюсту

ТИМОЩУК - заступник начальника управління Олександр Федорович МЗЕЗторгу

( Склад Комісії в редакції Розпорядження КМ N 727-р ( 727-96-р ) від 15.11.96 )
