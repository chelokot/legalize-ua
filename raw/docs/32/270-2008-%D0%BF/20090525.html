ПОСТАНОВА від 26 березня 2008 р. N 270 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Про внесення змін у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

Кабінет Міністрів України постановляє:

Внести у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851; 2002 р., N 40, ст. 1869, N 47, ст. 2143; 2005 р., N 13, ст. 665; 2006 р., N 5, ст. 219, N 13, ст. 873, N 47, ст. 3134; 2007 р., N 41, ст. 1627) зміни, що додаються.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 березня 2008 р. N 270

ЗМІНИ, що вносяться у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п )

1. У позиції "Міністерство освіти і науки" цифри "407" змінити цифрами з позначкою "433************************".

2. У позиції "Міністерство охорони здоров'я" цифри "316" і "4" замінити відповідно цифрами "336" і "6".

3. Позицію

"Міністерство у 307 4" справах сім'ї, молоді та спорту

замінити такою позицією:

Міністерство у 322************************ 6". справах сім'ї, молоді та спорту

4. У позиції "Головне контрольно-ревізійне управління" цифри "340" і "8540" замінити відповідно цифрами "440" і "8440".
