Стан: Чинний

Ідентифікатор: z1145-09

Текст документа від 22.10.2012:

ДЕРЖАВНИЙ ДЕПАРТАМЕНТ УКРАЇНИ З ПИТАНЬ ВИКОНАННЯ ПОКАРАНЬ

НАКАЗ

20.10.2009 N 235

Зареєстровано в Міністерстві юстиції України 27 листопада 2009 р. за N 1145/17161

Про внесення змін до наказів Державного департаменту України з питань виконання покарань від 03.10.2004 N 190 та від 25.05.2009 N 103

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 1438/5 ( z1663-12 ) від 28.09.2012 }

З метою приведення нормативно-правових актів Державного департаменту України з питань виконання покарань (далі - Департамент) у відповідність до Закону України "Про внесення змін та визнання такими, що втратили чинність, деяких законодавчих актів України щодо діяльності Державної кримінально-виконавчої служби України" ( 1254-17 ) НАКАЗУЮ:

1. Унести до наказу Департаменту від 03.10.2004 N 190 ( z1312-04 ) "Про затвердження Порядку підвищення посадових окладів (тарифних ставок) працівників установ Державної кримінально-виконавчої служби, які не мають спеціальних звань рядового і начальницького складу, за особливі умови праці, пов'язані з роботою із засудженими та особами, що тримаються у слідчих ізоляторах і перебувають у лікувально-трудових профілакторіях", зареєстрованого в Міністерстві юстиції України 14 жовтня 2004 року за N 1312/9911 (далі - Наказ), такі зміни:

у назві, преамбулі, пунктах 1 і 2 Наказу ( z1312-04 ) та у назві і пунктах 1, 2, 4 і 7 Порядку підвищення посадових окладів (тарифних ставок) працівників установ Державної кримінально-виконавчої служби, які не мають спеціальних звань рядового і начальницького складу, за особливі умови праці, пов'язані з роботою із засудженими та особами, що тримаються у слідчих ізоляторах і перебувають у лікувально-трудових профілакторіях (далі - Порядок), затвердженого цим Наказом, слова "і перебувають у лікувально-трудових профілакторіях" виключити;

у пункті 2 Наказу ( z1312-04 ) слова "і лікувально-трудових профілакторіїв" виключити;

абзац п'ятий пункту 3 та підпункт 7.5 Порядку ( z1312-04 ) виключити.

{ Пункт 2 втратив чинність на підставі Наказу Міністерства юстиції N 1438/5 ( z1663-12 ) від 28.09.2012 }

3. Управлінню економіки та оплати праці Департаменту (Стрілецький М.М.) забезпечити подання цього наказу в установленому порядку на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника Голови Департаменту Височанського А.Ф.

5. Цей наказ набирає чинності з дня його офіційного опублікування.

6. Наказ оголосити персоналу Державної кримінально-виконавчої служби України.
