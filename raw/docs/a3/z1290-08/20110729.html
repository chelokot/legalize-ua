НАКАЗ

30.12.2008 N 2325/5

Зареєстровано в Міністерстві юстиції України 30 грудня 2008 р. за N 1290/15981

Про внесення змін до наказу Міністерства юстиції України від 19.12.2005 N 105/5

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства юстиції N 105/5 ( z1540-05 ) від

19.12.2005, до якого вносились зміни }

Відповідно до постанови Кабінету Міністрів України від 30.08.2008 N 1298 ( 1298-2002-п ) "Про оплату праці працівників на основі Єдиної тарифної сітки розрядів і коефіцієнтів з оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Пункт 1 Примітки додатка 1 до наказу Міністерства юстиції України від 19.12.2005 N 105/5 ( z1540-05 ) "Про впорядкування умов оплати праці працівників науково-дослідних установ та Центру перепідготовки та підвищення кваліфікації працівників юстиції Міністерства юстиції України", зареєстрованого в Міністерстві юстиції України 21.12.2005 за N 1540/11820 (зі змінами), викласти в такій редакції:

"1. Посадові оклади (тарифні ставки), які діяли в листопаді 2008 року, установлюються з 1 грудня 2008 року в такому порядку:

для працівників, у яких посадові оклади менші, ніж розмір мінімальної заробітної плати, посадові оклади (тарифні ставки) у штатних розписах установлюються на рівні мінімальної заробітної плати;

для інших працівників посадові оклади не змінюються.

Заробітна плата працівників, визначена з урахуванням зазначених посадових окладів, індексується відповідно до Закону України "Про індексацію грошових доходів населення" ( 1282-12 )".

2. Контроль за виконанням цього наказу покласти на заступника Міністра юстиції В.І.Цоклана.

Заступник Міністра Л.В.Єфіменко
