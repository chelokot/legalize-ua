Про визначення місць митного оформлення окремих видів товарів

( Із змінами, внесеними згідно з Наказами Державної митної служби N 217 ( z0272-03 ) від 04.04.2003 N 711 ( z1005-03 ) від 20.10.2003 N 223 ( z0472-04 ) від 30.03.2004 )

Відповідно до статті 71 Митного кодексу України ( 92-15 ) та з метою забезпечення наповнення доходної частини державного бюджету, посилення контролю за правильністю визначення митної вартості, країни походження товарів, а також їх класифікації НАКАЗУЮ:

( Преамбула із змінами, внесеними згідно з Наказом Державної митної служби N 223 ( z0472-04 ) від 30.03.2004 )

1. Затвердити Перелік товарів, що ввозяться суб'єктами зовнішньоекономічної діяльності на митну територію України та митне оформлення яких здійснюється у визначених митницях (далі - Перелік), що додається, і ввести його в дію з 24.03.2003.

2. Визначити місцями митного оформлення товарів, зазначених у Переліку: Дніпровську, Донбаську, Західну, Карпатську, Київську, Кримську, Північну, Подільську, Східну, Чорноморську регіональні митниці та митниці прямого підпорядкування, а саме: Бориспільську, Луганську, Миколаївську, Севастопольську й Херсонську. ( Пункт 2 із змінами, внесеними згідно з Наказами Держмитслужби N 217 ( z0272-03 ) від 04.04.2003, N 711 ( z1005-03 ) від 20.10.2003 )

3. Установити, що проведення митного оформлення товарів, зазначених у Переліку, в інших митницях допускається лише за погодженням з Державною митною службою України.

4. Управлінню контролю митної вартості та номенклатури (Войцещук А.Д.), Управлінню правової роботи (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

5. Начальникам визначених митниць у місячний термін з дати державної реєстрації цього наказу в Міністерстві юстиції України подати до Управління контролю митної вартості та номенклатури доповіді про результати застосування цього наказу.

6. Управлінню податків та зборів (Околіта М.В.) урахувати наслідки застосування цього наказу при аналізі виконання планових показників у розрізі митниць.

7. Начальникам митниць забезпечити видачу суб'єктам зовнішньоекономічної діяльності листів-узгоджень на товари, зазначені в Переліку.

8. Прес-службі (Гунько С.О.) забезпечити висвітлення цього наказу в засобах масової інформації.

9. Контроль за виконанням наказу покласти на заступника Голови Служби Пашка П.В.

Голова Служби М.М.Каленський
