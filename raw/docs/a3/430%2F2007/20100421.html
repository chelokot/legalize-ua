Текст документа від 21.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 539/2010 ( 539/2010 ) від 14.04.2010 }

Питання наглядової ради відкритого акціонерного товариства "Державний ощадний банк України"

На часткову зміну статті 1 Указу Президента України від 1 березня 2005 року N 390 ( 390/2005 ) "Про членів наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України" (зі змінами, внесеними Указами від 2 березня 2006 року N 182 ( 182/2006 ), від 11 травня 2006 року N 385 ( 385/2006 ), від 22 травня 2006 року N 423 ( 423/2006 ), від 25 вересня 2006 року N 781 ( 781/2006 ), від 4 грудня 2006 року N 1023 ( 1023/2006 ), від 27 лютого 2007 року N 156 ( 156/2007 ) та від 12 березня 2007 року N 200 ( 200/2007 ):

1) призначити членами наглядової ради відкритого акціонерного товариства "Державний ощадний банк України" МОРОЗОВА Олександра Валерійовича та ПИШНОГО Андрія Григоровича;

2) припинити повноваження членів наглядової ради відкритого акціонерного товариства "Державний ощадний банк України" Буци Б.Е., Шандри В.М. згідно з поданими ними заявами.

Президент України В.ЮЩЕНКО

м. Київ, 18 травня 2007 року N 430/2007
