Кабінет Міністрів України; Постанова від 09.08.2001 № 1004

Про керівника деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

Стан: Втратив чинність

Ідентифікатор: 1004-2001-п

Текст документа від 24.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 серпня 2001 р. N 1004 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про керівника деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

{ Із змінами, внесеними згідно з Постановами КМ N 753 ( 753-2005-п ) від 18.08.2005 N 1231 ( 1231-2005-п ) від 21.12.2005 N 926 ( 926-2007-п ) від 11.07.2007 }

{ Додатково див. Постанову КМ N 23 ( 23-2013-п ) від 21.01.2013 }

Кабінет Міністрів України постановляє:

1. Затвердити Віце-прем'єр-міністра України Семиноженка Володимира Петровича:

головою Урядового комітету соціального, науково-технічного та гуманітарного розвитку;

головою Комітету з присудження Премії Кабінету Міністрів України за внесок молоді у розбудову держави;

( Абзац четвертий пункту 1 втратив чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

головою Урядової комісії з профілактики ВІЛ-інфекції/СНІДу;

{ Абзац шостий пункту 1 втратив чинність на підставі Постанови КМ N 926 ( 926-2007-п ) від 11.07.2007 }

головою Міжвідомчої комісії з координації напрямів реформування системи соціального захисту населення;

головою Міжвідомчої комісії з питань охорони дитинства;

головою Міжвідомчої комісії з координації напрямів реформування системи соціального захисту населення;

головою Міжвідомчої комісії з проблем "нацистського золота" та компенсаційних виплат жертвам нацизму;

головою Комісії для розроблення заходів з вшанування пам'яті голови Народного Руху України В.М. Чорновола;

головою Комісії з питань запобігання дитячій бездоглядності та соціальної реабілітації неповнолітніх;

головою Комісії Кабінету Міністрів України з розслідування причин захворюваності населення у Первомайському районі Миколаївської області та надання допомоги потерпілим і їхнім сім'ям;

головою Комісії з питань вручення ветеранам Великої Вітчизняної війни нагород, яких вони у свій час не одержали;

головою Комісії з встановлення пенсій за особливі заслуги перед Україною при Кабінеті Міністрів України;

головою Комісії з питань гуманітарної допомоги при Кабінеті Міністрів України;

головою Української частини спільної Міжурядової українсько-киргизької комісії з економічного співробітництва;

головою Національної ради по туризму;

головою Національної ради з питань безпечної життєдіяльності населення;

головою Національної координаційної ради боротьби з наркоманією при Кабінеті Міністрів України;

головою Всеукраїнської координаційної ради з питань розвитку духовності, захисту моралі та формування здорового способу життя громадян;

головою Організаційного комітету з відзначення 160-річчя від дня заснування Національного медичного університету імені О.О. Богомольця;

головою Організаційного комітету з підготовки та проведення в 2001 році Днів пам'яті жертв Бабиного Яру;

головою Організаційного комітету з підготовки та проведення Всеукраїнського з'їзду працівників освіти;

головою Організаційного комітету з підготовки та проведення загальнодержавного огляду меценатства і спонсорства;

головою Організаційного комітету з підготовки та проведення Всеукраїнської наради з питань дитинства;

головою Організаційного комітету з підготовки та проведення Днів культури України в Республіці Молдова;

заступником голови Організаційного комітету з підготовки та участі спортсменів України в Олімпійських і Параолімпійських іграх, Всесвітніх іграх глухих, Спеціальній Олімпіаді, чемпіонатах світу та Європи;

заступником голови Організаційного комітету з підготовки та проведення III Всесвітнього форуму українців;

головою робочої групи з підготовки та проведення III Всесвітнього форуму українців;

головою робочої групи з доопрацювання Програми реорганізації системи охорони здоров'я України;

керівником міжвідомчої робочої групи з координації роботи та підготовки проектів рішень щодо проведення пенсійної реформи;

керівником Української частини Спільної Українсько-Німецької робочої групи;

головою наглядової ради Національного заповідника "Софія Київська";

головою наглядової ради Українського фонду соціальних інвестицій;

співголовою наглядової ради Національного університету "Острозька академія";

співголовою наглядової ради Всеукраїнського фонду оздоровлення і відпочинку дітей та підлітків;

співголовою наглядової ради Національного університету "Києво-Могилянська академія";

( Абзац тридцять дев'ятий пункту 1 втратив чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

( Абзац сороковий пункту 1 втратив чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

головою Міжвідомчої координаційної ради з питань співробітництва з українською діаспорою;

головою Міжгалузевої ради з професійно-технічної освіти;

головою спостережної ради Українського національного фонду "Взаєморозуміння і примирення".

2. Увільнити Жулинського Миколу Григоровича від обов'язків керівника органів, зазначених у пункті 1 цієї постанови.
