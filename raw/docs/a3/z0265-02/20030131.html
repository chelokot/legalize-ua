N 61 від 28.02.2002 Зареєстровано в Міністерстві м. Київ юстиції України 18 березня 2002 р. за N 265/6553

Про затвердження Порядку отримання лімітів на спирт етиловий

( Із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 7 ( z0041-03 ) від 08.01.2003 )

Відповідно до порядків, затверджених постановами Кабінету Міністрів України від 29 серпня 2002 р. N 1266 ( 1266-2002-п ) "Про затвердження Порядку здійснення контролю за обігом спирту" та від 5 липня 1999 р. N 1197 ( 1197-99-п ) "Про порядок отримання закладами та установами охорони здоров'я, суб'єктами підприємницької діяльності, вітчизняними товаровиробниками спирту етилового і здійснення контролю за його цільовим використанням", та з метою впорядкування механізму отримання лімітів на спирт етиловий НАКАЗУЮ:

( Вступна частина в редакції Наказу Міністерства економіки та з питань європейської інтеграції N 7 ( z0041-03 ) від 08.01.2003 )

1. Затвердити Порядок отримання лімітів на спирт етиловий, що додається. ( Пункт 1 із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 7 ( z0041-03 ) від 08.01.2003 )

2. Управлінню розвитку ринків продовольства та сільськогосподарської продукції забезпечити державну реєстрацію цього наказу в Міністерстві юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Державного секретаря Зубарєва В.В.

4. Наказ набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

Міністр О.Шлапак

ЗАТВЕРДЖЕНО Наказ Міністерства економіки та з питань європейської інтеграції України 28.02.2002 N 61

Зареєстровано в Міністерстві юстиції України 18 березня 2002 р. за N 265/6553

Порядок отримання лімітів на спирт етиловий

( У назві та тексті Порядку слова "фонди (ліміти)" в усіх відмінках замінено словом "ліміти" у відповідному відмінку згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 7 ( z0041-03 ) від 08.01.2003 )

1. Цей Порядок установлює механізм отримання лімітів на спирт етиловий.

2. Ліміти на спирт етиловий визначають на підставі звернень заявників:

міністерств, інших центральних органів виконавчої влади, до сфери управління яких належать суб'єкти підприємницької діяльності (далі - центральні органи виконавчої влади);

суб'єктів підприємницької діяльності, що не належать до сфери управління центральних органів виконавчої влади (далі - суб'єкти підприємницької діяльності).

3. До заявки на отримання лімітів на спирт етиловий додають:

а) центральні органи виконавчої влади:

зведений розрахунок потреби в спирті за напрямами його використання;

копію звіту про надходження та використання спирту;

б) суб'єкт підприємницької діяльності, який виробляє вибухові речовини, парфумерно-косметичну продукцію, нітроцелюлозу, пектин, есенції і оцет харчові та напівфабрикати: спиртовані соки, морси, настої з використанням спирту етилового, у статуті якого передбачена діяльність, пов'язана з виробництвом зазначеної продукції: ( Абзац перший підпункту "б" пункту 3 із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 7 ( z0041-03 ) від 08.01.2003 )

довідку Державного департаменту продовольства Міністерства аграрної політики України, яка підтверджує, що суб'єкт підприємницької діяльності є виробником відповідної продукції, із зазначенням обсягу і мети використання спирту;

копію звіту про надходження та використання спирту етилового з відміткою органу державної податкової служби, засвідчену печаткою суб'єкта підприємницької діяльності;

в) суб'єкт підприємницької діяльності, що використовує спирт етиловий ректифікований для виготовлення алкогольних напоїв:

( Абзац перший підпункту "в" пункту 3 в редакції Наказу Міністерства економіки та з питань європейської інтеграції N 7 ( z0041-03 ) від 08.01.2003 )

розрахунок потреби в спирті за напрямами його використання;

копію ліцензії на виробництво алкогольних напоїв; ( Абзац третій підпункту "в" пункту 3 із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 7 ( z0041-03 ) від 08.01.2003 )

копію документа, що підтверджує реєстрацію місця зберігання спирту етилового ректифікованого; ( Абзац четвертий підпункту "в" пункту 3 із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 7 ( z0041-03 ) від 08.01.2003 )

копію звіту про надходження та використання спирту етилового ректифікованого з відміткою органу державної податкової служби, засвідчену печаткою суб'єкта підприємницької діяльності; ( Абзац п'ятий підпункту "в" пункту 3 із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 7 ( z0041-03 ) від 08.01.2003 )

г) суб'єкт підприємницької діяльності, який використовує спирт етиловий денатурований (спирт технічний) для виготовлення продукції з його вмістом:

розрахунок потреби в спирті за напрямами його використання;

копію статуту підприємства;

копію свідоцтва про державну реєстрацію (перереєстрацію) суб'єкта підприємницької діяльності - юридичної особи;

копію технічних умов на виробництво продукції з вмістом спирту етилового денатурованого (спирту технічного);

копію документа, що підтверджує реєстрацію місця зберігання спирту етилового денатурованого (спирту технічного);

копію звіту про надходження та використання спирту етилового денатурованого (спирту технічного) з відміткою органу державної податкової служби, засвідчену печаткою суб'єкта підприємницької діяльності.

4. Розгляд заявок та підготовку пропозицій щодо отримання лімітів на спирт етиловий здійснює управління розвитку ринків продовольства та сільськогосподарської продукції.

5. Заявку на отримання лімітів на спирт етиловий та документи, зазначені в пункті 3 цього Порядку, подають комплектно в одному пакеті і реєструють в Міністерстві економіки та з питань європейської інтеграції України.

6. Міністерство економіки та з питань європейської інтеграції України визначає ліміти на спирт етиловий в п'ятнадцятиденний термін з дня реєстрації заявки.

7. У разі відсутності одного із зазначених у пункті 3 цього Порядку документів управління розвитку ринків продовольства та сільськогосподарської продукції повідомляє про це замовника протягом десяти днів з дня реєстрації поданих документів.

8. Повторний розгляд документів здійснюють у термін, передбачений пунктом 6 цього Порядку.

9. Ліміти на спирт етиловий визначають щокварталу на підставі балансів виробництва та використання спирту в порядку, установленому чинним законодавством.

10. Згідно з визначеними лімітами кожному замовнику надсилають повідомлення про отримання лімітів на спирт етиловий за підписом начальника управління розвитку ринків продовольства та сільськогосподарської продукції.

Керівник департаменту розвитку ринків А.Кушніренко
