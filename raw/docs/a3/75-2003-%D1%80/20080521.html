{ Розпорядження втратило чинність на підставі Розпорядження КМ N 727-р ( 727-2008-р ) від 21.05.2008 }

Про затвердження складу наглядової ради Національного фармацевтичного університету

1. Затвердити склад наглядової ради Національного фармацевтичного університету з п'ятирічним терміном її повноважень (додається).

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 16 листопада 1999 р. N 2095 ( 2095-99-п ) "Про затвердження складу наглядової ради Національної фармацевтичної академії України".
