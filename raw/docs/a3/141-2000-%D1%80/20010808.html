Кабінет Міністрів України; Розпорядження від 22.03.2000 № 141-р

Про утворення робочої групи для опрацювання питань удосконалення системи реалізації вугільної продукції, зменшення обсягів бартерних операцій, забезпечення прозорості надходження та розподілу коштів

Стан: Втратив чинність

Ідентифікатор: 141-2000-р

Текст документа від 08.08.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 березня 2000 р. N 141-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 946 ( 946-2001-п ) від 08.08.2001 )

1. Для опрацювання питань удосконалення системи реалізації вугільної продукції, зменшення обсягів бартерних операцій, забезпечення прозорості надходження та розподілу коштів утворити робочу групу у складі згідно з додатком.

2. Надати керівникові групи право вносити зміни до її складу та залучати для роботи працівників, інших центральних органів виконавчої влади за погодженням з їх керівниками.

3. Робочій групі в місячний термін подати Кабінетові Міністрів України узгоджені пропозиції.
