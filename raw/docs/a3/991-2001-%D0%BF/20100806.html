КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 серпня 2001 р. N 991 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 638 ( 638-2010-п ) від 28.07.2010 }

Про Уповноваженого Кабінету Міністрів України з виконання Угоди про спільне використання та охорону прикордонних вод між Урядом України та Урядом Республіки Молдова

( Із змінами, внесеними згідно з Постановою КМ N 956 ( 956-2004-п ) від 28.07.2004 )

Кабінет Міністрів України постановляє:

Затвердити заступника Голови Державного комітету по водному господарству Бабича Миколу Яковича Уповноваженим Кабінету Міністрів України з виконання Угоди про спільне використання та охорону прикордонних вод між Урядом України та Урядом Республіки Молдова ( 498_051 ), увільнивши від цих обов'язків Алієва Кемалія Алійовича.

( Постанова із змінами, внесеними згідно з Постановою КМ N 956 ( 956-2004-п ) від 28.07.2004 )
