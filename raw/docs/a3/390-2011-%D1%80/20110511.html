Про залучення позики від Міжнародного банку реконструкції та розвитку для реалізації інвестиційного проекту "Додаткове фінансування для Другого проекту розвитку експорту"

Текст документа від 11.05.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 травня 2011 р. N 390-р Київ

Про залучення позики від Міжнародного банку реконструкції та розвитку для реалізації інвестиційного проекту "Додаткове фінансування для Другого проекту розвитку експорту"

Визнати за доцільне залучення позики від Міжнародного банку реконструкції та розвитку для реалізації інвестиційного проекту "Додаткове фінансування для Другого проекту розвитку експорту" в розмірі 150 млн. доларів США.
