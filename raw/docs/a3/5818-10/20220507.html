Текст документа від 07.05.2022:

УКАЗ ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

{ Указ не застосовується на території України згідно із Законом N 2215-IX ( 2215-20 ) від 21.04.2022 }

Про об'єднання Міністерства сільського господарства Української РСР і Міністерства радгоспів Української РСР в Міністерство сільського господарства Української РСР

{ Указ затверджено Законом УРСР N 6426-X ( 6426-10 ) від 13.01.84, ВВР, 1984, N 4, ст. 83 }

Президія Верховної Ради Української РСР постановляє:

Об'єднати Міністерство сільського господарства Української РСР і Міністерство радгоспів Української РСР в одне союзно-республіканське міністерство - Міністерство сільського господарства Української РСР.
