МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

N 508 від 22.12.93 Зареєстровано в Міністерстві м.Київ юстиції України 31 грудня 1993 р. vd931222 vn508 за N 209

Про затвердження Правил нормування робочого часу та часу відпочинку екіпажів повітряних суден цивільної авіації України

( Із змінами, внесеними згідно з Наказом Мінтрансу N 219 ( z0390-02 ) від 02.04.2002 )

З метою регламентування робочого часу та часу відпочинку членів екіпажів повітряних суден цивільної авіації НАКАЗУЮ:

1. Затвердити Правила нормування робочого часу та часу відпочинку екіпажів повітряних суден цивільної авіації України, що додаються.

2. Керівникам об'єднань, підприємств, організацій, авіакомпаній, що експлуатують цивільні авіаційні повітряні судна:

вивчити з льотним складом Правила нормування робочого часу та часу відпочинку екіпажів повітряних суден цивільної авіації України;

на підставі цих Правил розробити локальні нормативні акти з питань нормування робочого часу та часу відпочинку екіпажів транспортних підрозділів і підрозділів, що виконують авіаційні роботи.

3. Департаменту авіаційного транспорту України зареєструвати Правила в Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника Міністра транспорту - директора Департаменту авіаційного транспорту М.О.Марченка.

Перший заступник Міністра О.М.Артеменко

( Правила нормування робочого часу та часу відпочинку екіпажів повітряних суден цивільної авіації України втратили чинність на підставі Наказу Мінтрансу N 219 ( z0390-02 ) від 02.04.2002 )
