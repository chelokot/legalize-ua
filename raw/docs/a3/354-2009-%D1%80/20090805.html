КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 квітня 2009 р. N 354-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 934-р ( 934-2009-р ) від 05.08.2009 }

Про затвердження проекту та титулу будови реконструкції спортивного комплексу комунального підприємства "Обласний спортивний комплекс "Металіст"

1. Затвердити поданий Харківською облдержадміністрацією проект реконструкції спортивного комплексу комунального підприємства "Обласний спортивний комплекс "Металіст" у м. Харкові по вул. Плеханівській, 65, розроблений ТОВ "Інститут "Харківпроект" та рекомендований до затвердження державним підприємством "Укрдержбудекспертиза" Мінрегіонбуду, з такими основними техніко-економічними показниками:

загальна кількість місць 40784

площа, кв. метрів:

футбольного поля 7686

бігових доріжок 4296

будівництва трибун та багатофункціональної 19058,17

прибудови до західної трибуни

загальна кошторисна вартість будівництва, тис. 442157,448 гривень

у тому числі:

будівельно-монтажних робіт 292862,616

устатковання 59155,428

пусконалагоджувальних робіт 89,615

інших витрат 90049,789

строк будівництва 24 місяці

2. Затвердити титул будови реконструкції спортивного комплексу комунального підприємства "Обласний спортивний комплекс "Металіст" у м. Харкові по вул. Плеханівській, 65, що додається.
