Про впорядкування мережі вищих навчальних закладів, що перебувають у сфері управління Мінфіну

Стан: Чинний

Ідентифікатор: 471-2004-р

Текст документа від 14.03.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 липня 2004 р. N 471-р Київ

Про впорядкування мережі вищих навчальних закладів, що перебувають у сфері управління Мінфіну

{ Із змінами, внесеними згідно з Розпорядженням КМ N 98-р ( 98-2007-р ) від 14.03.2007 }

З метою впорядкування мережі вищих навчальних закладів, що перебувають у сфері управління Мінфіну:

{ Пункт 1 виключено на підставі Розпорядження КМ N 98-р ( 98-2007-р ) від 14.03.2007 }

2. Утворити:

{ Підпункт 1 пункту 2 виключено на підставі Розпорядження КМ N 98-р ( 98-2007-р ) від 14.03.2007 }

2) Буковинську державну фінансову академію на базі Буковинського фінансово-економічного інституту, що ліквідується;

3) Дніпропетровську державну фінансову академію на базі Дніпропетровського державного фінансово-економічного інституту, що ліквідується;

4) Львівську державну фінансову академію на базі Львівського державного фінансово-економічного інституту, що ліквідується.

3. Витрати, пов'язані з впорядкуванням мережі вищих навчальних закладів, здійснити в межах коштів, передбачених Мінфіну в Державному бюджеті України на 2004 рік ( 1344-15 ) на підготовку кадрів.

4. Узяти до відома, що студенти ліквідованих вищих навчальних закладів продовжують навчання у відповідних новоутворених філіях Українського державного університету економіки і фінансів та державних фінансових академіях.

Прем'єр-міністр України В.ЯНУКОВИЧ
