Кабінет Міністрів України; Розпорядження від 12.07.1999 № 671-р

Про віднесення посад голів постійних комісій Верховної Ради Автономної Республіки Крим до першої категорії посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 671-99-р

Текст документа від 11.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 липня 1999 р. N 671-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 493 ( 493-2012-п ) від 23.05.2012 }

На часткову зміну розпорядження Кабінету Міністрів України від 10 травня 1999 р. N 398 ( 398-99-р ) (Офіційний вісник України, 1999 р., N 19, ст. 842) віднести посади голів постійних комісій Верховної Ради Автономної Республіки Крим до першої категорії посад державних службовців.

Перший віце-прем'єр-міністр України В.КУРАТЧЕНКО
