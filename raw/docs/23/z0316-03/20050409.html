НАКАЗ

14.04.2003 N 108

Зареєстровано в Міністерстві юстиції України 21 квітня 2003 р. за N 316/7637

( Наказ втратив чинність на підставі Наказу Міністерства аграрної політики N 60 ( z0340-05 ) від 03.02.2005 )

Про затвердження Тарифів на роботи і послуги, пов'язані з проведенням технічного нагляду за суднами рибного господарства України, що не підлягають нагляду класифікаційного товариства

Відповідно до постанови Кабінету Міністрів України від 27 серпня 1999 р. N 1583 ( 1583-99-п ) "Про технічний нагляд за суднами рибного господарства України, що не підлягають нагляду класифікаційного товариства" НАКАЗУЮ:

1. Затвердити Тарифи на роботи і послуги, пов'язані з проведенням технічного нагляду за суднами рибного господарства України, що не підлягають нагляду класифікаційного товариства, що додаються.

2. Державному департаменту рибного господарства (Алимов С.І.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Наказ Державного комітету рибного господарства України від 22.02.2000 N 16 "Про затвердження Тарифів на роботи і послуги, пов'язані з проведенням технічного нагляду за суднами", скасувати.

4. Контроль за виконанням наказу покласти на заступника Державного секретаря Мельника Ю.Ф.

Міністр С.Рижук

ЗАТВЕРДЖЕНО Наказ Міністерства аграрної політики України 14.04.2003 N 108

Зареєстровано в Міністерстві юстиції України 21 квітня 2003 р. за N 316/7637

ТАРИФИ на роботи і послуги, пов'язані з проведенням технічного нагляду за суднами рибного господарства України, що не підлягають нагляду класифікаційного товариства

1.1. Тарифи на роботи і послуги, пов'язані з проведенням технічного нагляду за суднами рибного господарства України, що не підлягають нагляду класифікаційного товариства (далі - Тарифи), поширюються на судна юридичних та фізичних осіб незалежно від форм власності, які залучаються до вирощування, вилову, обробки, транспортування, зберігання і охорони риби та інших водних живих ресурсів і не підлягають нагляду класифікаційного товариства (далі - судна).

Перелік робіт і послуг, пов'язаних з проведенням технічного нагляду, визначається наказом Міністерства аграрної політики України від 13.11.2000 N 226 ( z0949-00 ) "Про затвердження Інструкції з проведення технічного нагляду за суднами рибного господарства України, що не підлягають нагляду класифікаційного товариства", зареєстрованого в Міністерстві юстиції України 26.11.2000 за N 949/5170.

1.2. Розрахунки за виконання роботи та надання послуг здійснюються у формі попередньої оплати. Кошти, отримані за виконання робіт та надані послуги, зараховуються на поточний рахунок Держрибфлотінспекції.

1.3. Тарифи встановлені в гривнях без урахування податку на додану вартість.
