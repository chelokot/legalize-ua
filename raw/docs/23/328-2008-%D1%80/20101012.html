КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 лютого 2008 р. N 328-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1956-р ( 1956-2010-р ) від 12.10.2010 }

Про внесення змін до складу групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий строк і здійснення контролю за її виконанням

Внести до складу групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий строк і здійснення контролю за її виконанням, затвердженого розпорядженням Кабінету Міністрів України від 5 вересня 2006 р. N 479 ( 479-2006-р ), зміни згідно з додатком.
