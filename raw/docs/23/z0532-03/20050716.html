ВИЩА АТЕСТАЦІЙНА КОМІСІЯ УКРАЇНИ

НАКАЗ

03.06.2003 N 291

Зареєстровано в Міністерстві юстиції України 1 липня 2003 р. за N 532/7853

( Наказ втратив чинність на підставі Наказу Вищої атестаційної комісії N 377 ( z0713-05 ) від 23.06.2005 )

Про внесення змін і доповнень до Переліку спеціальностей, за якими проводяться захист дисертацій на здобуття наукових ступенів кандидата наук і доктора наук, присудження наукових ступенів і присвоєння вчених звань

На виконання пункту 8 постанови Верховної Ради України від 16.01.2003 N 441-IV ( 441-15 ) "Про підсумки парламентських слухань "Суспільство, засоби масової інформації, влада: свобода слова і цензура в Україні" та розглянувши клопотання Академії медичних наук України, Міністерства охорони здоров'я України, звернення наукової громадськості і враховуючи рекомендації експертних рад ВАК України, президія ВАК України постановами від 13.02.2002 N 1-07/2, N 18-09/2 ( vc9_2330-02 ), від 09.04.2003 N 1-02/4 та від 21.05.2003 N 15-09/5, N 28-11/5 внесла зміни і доповнення до Переліку спеціальностей, за якими проводяться захист дисертацій на здобуття наукових ступенів кандидата наук і доктора наук, присудження наукових ступенів і присвоєння вчених звань. Відповідно до Положення про Вищу атестаційну комісію України, затвердженого Указом Президента України від 25 лютого 1999 року N 216/99 ( 216/99 ), НАКАЗУЮ:

1.Унести зміни і доповнення до Переліку спеціальностей, за якими проводяться захист дисертацій на здобуття наукових ступенів кандидата наук і доктора наук, присудження наукових ступенів і присвоєння вчених звань, затвердженого наказом ВАК від 10.06.99 N 288 ( z0425-99 ) і зареєстрованого в Міністерстві юстиції України 01.07.99 за N 425/3718, зі змінами і доповненнями, унесеними наказом ВАК від 07.07.99 N 341 ( z0531-99 ), зареєстрованим у Міністерстві юстиції України 05.08.99 за N 531/3824, наказом ВАК від 29.11.99 N 487 ( z0870-99 ), зареєстрованим у Міністерстві юстиції України 15.12.99 за N 870/4163, наказом ВАК від 12.05.2000 N 252 ( z0319-00 ), зареєстрованим у Міністерстві юстиції України 31.05.2000 за N 319/4540, наказом ВАК від 28.11.2000 N 586 ( z0914-00 ), зареєстрованим у Міністерстві юстиції України 14.12.2000 за N 914/5135, наказом ВАК від 23.05.2001 N 305 ( z0501-01 ), зареєстрованим у Міністерстві юстиції України 12.06.2001 за N 501/5692, наказом ВАК від 27.11.2001 N 573 ( z1025-01 ), зареєстрованим у Міністерстві юстиції України 11.12.2001 за N 1025/6216, наказом ВАК від 09.09.2002 N 368 ( z0772-02 ), зареєстрованим у Міністерстві юстиції України 20.09.2002 за N 772/7060, та наказом ВАК від 21.01.2003 N 30 ( z0106-03 ), зареєстрованим у Міністерстві юстиції України 07.02.2003 за N 106/7427, що додаються.

2. Відділу інспекції та організаційно-аналітичного забезпечення ВАК України забезпечити публікацію змін і доповнень до Переліку спеціальностей, за якими проводяться захист дисертацій на здобуття наукових ступенів кандидата наук і доктора наук, присудження наукових ступенів і присвоєння вчених звань у "Бюлетені Вищої атестаційної комісії України".

Голова ВАК України В.В.Скопенко
