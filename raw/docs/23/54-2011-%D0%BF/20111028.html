ПОСТАНОВА від 19 січня 2011 р. N 54 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1064 ( 1064-2011-п ) від 03.10.2011 }

Про внесення змін до постанови Кабінету Міністрів України від 4 квітня 2000 р. N 599

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 4 квітня 2000 р. N 599 ( 599-2000-п ) "Про запровадження аукціонів з продажу нафти, газового конденсату, природного, скрапленого газу та вугілля" (Офіційний вісник України, 2000 р., N 14, ст. 567, N 20, ст. 1439; 2007 р., N 1, ст. 21; 2010 р., N 55, ст. 1849) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 37

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 19 січня 2011 р. N 54

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 4 квітня 2000 р. N 599 ( 599-2000-п )

1. У пункті 7:

після абзацу другого доповнити пункт новими абзацами такого змісту:

"Продавці, які реалізують скраплений газ для потреб населення на спеціалізованих аукціонах, подають Міністерству енергетики та вугільної промисловості у строки та за формою, визначеними Міністерством, інформацію (щодо кожного аукціону в розрізі суб'єктів підприємницької діяльності, що здійснюють операції з реалізації скрапленого газу для потреб населення) про укладені за результатами проведення спеціалізованих аукціонів договори купівлі-продажу скрапленого газу, обсяги фактичного його відвантаження та стан розрахунків між продавцями та покупцями.

Міністерство енергетики та вугільної промисловості подає Державній податковій службі (щодо кожного аукціону в розрізі суб'єктів підприємницької діяльності, що здійснюють операції з реалізації скрапленого газу для потреб населення):

інформацію про укладені за результатами спеціалізованого аукціону договори купівлі-продажу скрапленого газу - протягом п'яти днів з дня проведення аукціону;

узагальнену інформацію про операції з реалізації скрапленого газу для потреб населення, придбаного на спеціалізованому аукціоні, - протягом п'яти днів з дня останнього надходження інформації від суб'єктів підприємницької діяльності.".

У зв'язку з цим абзаци третій і четвертий вважати відповідно абзацами сьомим та восьмим;

в абзаці восьмому слова "Державна податкова адміністрація" замінити словами "Державна податкова служба".

2. У тексті постанови ( 599-2000-п ) слова "Міністерство палива та енергетики" та "Міністерство економіки" в усіх відмінках замінити відповідно словами "Міністерство енергетики та вугільної промисловості" та "Міністерство економічного розвитку і торгівлі" у відповідному відмінку.
