УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 208/2000 від 11.02.2000 )

Про внесення змін до Указу Президента України від 24 липня 1995 року N 642

На зміну складу Ради по роботі з кадрами, затвердженого Указом Президента України від 24 липня 1995 року N 642 ( 642/95 ) "Про Положення про Раду по роботі з кадрами", постановляю:

Ввести до складу Ради по роботі з кадрами при Президентові України КАРАБАНЯ Володимира Яковича - начальника організаційно-кадрового управління Вищого арбітражного суду України, виключивши зі складу цієї Ради АНДРІЙЧУКА Володимира Васильовича.

Президент України Л.КУЧМА
