Про внесення зміни до Указу Президента України від 22 липня 2000 року N 911

Стан: Втратив чинність

Ідентифікатор: 1336/2000

Текст документа від 12.10.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1433/2005 ( 1433/2005 ) від 12.10.2005 )

Про внесення зміни до Указу Президента України від 22 липня 2000 року N 911

У зв'язку з необхідністю утворення секретаріату Ради представників кримськотатарського народу у складі Представництва Президента України в Автономній Республіці Крим внести зміну до Указу Президента України від 22 липня 2000 року N 911 ( 911/2000 ), замінивши у статті 2 цифри "26" цифрами "28".

Президент України Л.КУЧМА
