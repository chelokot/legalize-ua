26.04.2005 N 74

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 41 ( v0041359-07 ) від 30.05.2007 }

Про внесення змін до структури і чисельності Секретаріату, патронатної служби та автогосподарства Центральної виборчої комісії, затвердженої постановою Центральної виборчої комісії від 22 лютого 2005 року N 45

Керуючись статтею 12, частиною другою статті 33 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

Внести до структури і чисельності Секретаріату, патронатної служби та автогосподарства Центральної виборчої комісії, затвердженої постановою Центральної виборчої комісії від 22 лютого 2005 року N 45 ( v0045359-05 ), такі зміни:

у додатку 1 до зазначеної постанови Комісії:

ввести посаду заступника начальника управління - завідуючого відділом зведеного планування та фінансування управління планово-фінансового управління Секретаріату Центральної виборчої комісії замість посад заступника начальника управління та завідуючого відділом зведеного планування та фінансування цього управління;

виключити посаду головного консультанта відділу забезпечення засідань Комісії управління документального забезпечення Секретаріату Комісії;

ввести посаду головного консультанта сектору моніторингу за виконанням документів відділу роботи з документами управління документального забезпечення Секретаріату Комісії замість посади провідного спеціаліста цього сектору;

ввести додатково посаду провідного спеціаліста сектору архівного діловодства відділу роботи з документами управління документального забезпечення Секретаріату Комісії.
