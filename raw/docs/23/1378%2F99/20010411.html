ЗАТВЕРДЖЕНО Указом Президента України від 23 жовтня 1999 року N 1378/99

ПОЛОЖЕННЯ про Координаційну раду з питань соціального і правового захисту військовослужбовців, працівників міліції, митної служби та членів їх сімей

( Назва Положення із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

1. Координаційна рада з питань соціального і правового захисту військовослужбовців, працівників міліції, митної служби та членів їх сімей (далі - Координаційна рада) є консультативно-дорадчим органом при Президентові України. ( Пункт 1 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

2. У своїй діяльності Координаційна рада керується Конституцією України ( 254к/96-ВР ), законами України, актами Президента України та Кабінету Міністрів України, а також цим Положенням.

3. Основними завданнями Координаційної ради є:

здійснення аналізу стану соціально-правової захищеності військовослужбовців Збройних Сил України та інших утворених відповідно до законодавства військових формувань, осіб рядового і начальницького складу органів внутрішніх справ, податкової міліції, кримінально-виконавчої системи, осіб, звільнених в запас або у відставку, працівників митної служби та членів їх сімей; ( Абзац другий пункту 3 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

внесення пропозицій щодо формування та реалізації єдиної державної політики у цій сфері.

4. Координаційна рада відповідно до покладених завдань:

аналізує стан реалізації державної політики у сфері соціально-правового захисту осіб, зазначених в абзаці другому пункту 3 цього Положення та членів їх сімей; ( Абзац другий пункту 4 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

бере участь у розробленні законопроектів з питань соціального і правового захисту осіб, зазначених в абзаці другому пункту 3 цього Положення; ( Абзац третій пункту 4 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

проводить експертизу проектів законів та інших нормативно-правових актів з питань, що належать до її компетенції;

вносить у встановленому порядку пропозиції щодо одержання цільових кредитів на соціальні програми для осіб, зазначених в абзаці другому пункту 3 цього Положення; ( Абзац п'ятий пункту 4 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

розробляє пропозиції щодо створення додаткових робочих місць для осіб, зазначених в абзаці другому пункту 3 цього Положення, а також системи професійної підготовки та соціальної адаптації осіб, звільнених у запас або у відставку, вживає заходів до координації роботи міністерств, інших центральних органів виконавчої влади у цій сфері; ( Абзац шостий пункту 4 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

вносить пропозиції щодо розроблення проектів програм житлового будівництва для військовослужбовців;

вивчає та аналізує стан матеріального забезпечення осіб, зазначених в абзаці другому пункту 3 цього Положення, їх соціального захисту та за результатами вносить відповідні пропозиції; ( Абзац восьмий пункту 4 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

сприяє роботі громадських об'єднань, релігійних організацій, благодійних фондів, окремих громадян, спрямованій на правовий і соціальний захист осіб, зазначених в абзаці другому пункту 3 цього Положення; ( Абзац дев'ятий пункту 4 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

розглядає звернення громадян з питань соціально-правового захисту осіб, зазначених в абзаці другому пункту 3 цього Положення, вживає заходів до вирішення проблем, що виникають; ( Абзац десятий пункту 4 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

проводить через засоби масової інформації інформаційну та роз'яснювальну роботу з вирішення соціальних проблем осіб, зазначених в абзаці другому пункту 3 цього Положення; ( Абзац одинадцятий пункту 4 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

надає методичну допомогу, координує діяльність відповідних регіональних і місцевих організацій та своїх представників. ( Абзац дванадцятий пункту 4 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

5. Координаційна рада має право:

одержувати в установленому законодавством порядку від міністерств, інших центральних і місцевих органів виконавчої влади інформацію, документи і матеріали з питань, що належать до її компетенції;

утворювати в разі потреби тимчасові робочі та експертні групи;

залучати спеціалістів центральних та місцевих органів виконавчої влади (за погодженням з їх керівниками), вчених до розгляду питань, що належать до її компетенції.

6. Координаційна рада здійснює свою діяльність на громадських засадах.

Організаційною формою роботи Координаційної ради є засідання, які проводяться в міру потреби, але не рідше одного разу на три місяці. Координаційна рада правомочна вирішувати питання, якщо на засіданні присутні більше половини її членів.

Рішення Координаційної ради приймаються більшістю голосів присутніх на засіданні Ради і оформляються протоколом.

6-1. Для розгляду питань, що потребують попереднього обговорення або оперативного вирішення, утворюється президія Координаційної ради, яку обирають із числа членів цієї Ради.

Засідання президії Координаційної ради скликаються Головою Координаційної ради. На засіданнях президії головує Голова Координаційної ради.

Рішення президії Координаційної ради приймаються більшістю голосів присутніх на засіданні членів президії і оформляються протоколом, який підписує Голова Координаційної ради.

( Положення доповнено пунктом 6-1 згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

7. Координаційну раду очолює Голова, якого призначає Президент України. Склад Координаційної ради затверджує Президент України за поданням Голови Координаційної ради.

8. Голова Координаційної ради:

організовує діяльність Координаційної ради, спрямовує роботу її членів;

представляє Координаційну раду у відносинах з центральними і місцевими органами виконавчої влади, підприємствами, установами, організаціями.

9. Координаційна рада використовує в роботі бланки зі своїм найменуванням, має відповідну печатку.

10. Організаційне, технічне та інше забезпечення діяльності Координаційної ради здійснює Адміністрація Президента України, для чого утворюється секретаріат цієї Ради. ( Абзац перший пункту 10 із змінами, внесеними згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )

Положення про секретаріат Координаційної ради, граничну чисельність працівників та штатний розпис секретаріату затверджує Глава Адміністрації Президента України. ( Пункт 10 доповнено абзацом згідно з Указом Президента N 252/2001 ( 252/2001 ) від 11.04.2001 )
