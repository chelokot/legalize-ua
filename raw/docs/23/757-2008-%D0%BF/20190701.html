Про збільшення розміру стипендій Президента України та Кабінету Міністрів України для молодих учених

Текст документа від 01.07.2019:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 серпня 2008 р. N 757 Київ

Про збільшення розміру стипендій Президента України та Кабінету Міністрів України для молодих учених

{ Із змінами, внесеними згідно з Постановами КМ N 872 ( 872-2012-п ) від 19.09.2012 N 442 ( 442-2019-п ) від 15.05.2019 }

Кабінет Міністрів України постановляє:

1. Установити з 1 липня 2019 року: { Абзац перший пункту 1 із змінами, внесеними згідно з Постановами КМ N 872 ( 872-2012-п ) від 19.09.2012, N 442 ( 442-2019-п ) від 15.05.2019 }

щомісячний розмір стипендій Президента України для молодих учених, заснованих Указом Президента України від 22 березня 1994 р. N 100 ( 100/94 ), у розмірі трьох прожиткових мінімумів для працездатних осіб кожна; { Абзац другий пункту 1 із змінами, внесеними згідно з Постановами КМ N 872 ( 872-2012-п ) від 19.09.2012, N 442 ( 442-2019-п ) від 15.05.2019 }

щомісячний розмір стипендій Кабінету Міністрів України для молодих учених, заснованих постановою Кабінету Міністрів України від 16 серпня 1994 р. N 560 ( 560-94-п ) (ЗП України, 1994 p., N 11, ст. 285), у розмірі двох прожиткових мінімумів для працездатних осіб кожна. { Абзац третій пункту 1 із змінами, внесеними згідно з Постановами КМ N 872 ( 872-2012-п ) від 19.09.2012, N 442 ( 442-2019-п ) від 15.05.2019 }

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України від 22 листопада 2005 р. N 1107 ( 1107-2005-п ) "Про збільшення розміру стипендії Президента України для молодих учених" (Офіційний вісник України, 2005 р., N 47, ст. 2946) та від 24 грудня 2005 р. N 1275 ( 1275-2005-п ) "Про розмір стипендій Кабінету Міністрів України для молодих учених" (Офіційний вісник України, 2005 р., N 52, ст. 3313).
