{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Деякі питання Міністерства оборони та Генерального штабу

{ Зміни до Постанови див. в Постанові КМ N 295 ( 295-2005-п ) від 15.04.2005 }

Кабінет Міністрів України постановляє:

1. Установити граничну чисельність працівників:

центрального апарату Міністерства оборони: у 2004 році у кількості 1235 осіб, з них 618 військовослужбовців; у 2005 році у кількості 1235 осіб, з них 247 військовослужбовців;

Генерального штабу Збройних Сил у 2004 році у кількості 700 осіб, з них 583 військовослужбовці.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 24 березня 1999 р. N 446 ( 446-99-п ) "Питання Міністерства оборони".
