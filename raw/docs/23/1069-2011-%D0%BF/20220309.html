Про забезпечення функціонування єдиної системи пошуку і рятування на морі

{ Із змінами, внесеними згідно з Постановами КМ N 407 ( 407-2013-п ) від 03.06.2013 N 227 ( 227-2022-п ) від 06.03.2022 }

Кабінет Міністрів України постановляє:

1. Утворити казенне підприємство "Морська пошуково-рятувальна служба" (далі - казенне підприємство) та віднести його до сфери управління Міністерства інфраструктури.

2. Установити, що основним завданням казенного підприємства є організаційно-технічне забезпечення сталого функціонування та подальшого розвитку Національної системи пошуку і рятування на морі ( 227-2022-п ) у морському пошуково-рятувальному районі України.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 227 ( 227-2022-п ) від 06.03.2022 }

{ Пункт 3 втратив чинність на підставі Постанови КМ N 407 ( 407-2013-п ) від 03.06.2013 }

4. Міністерству інфраструктури:

1) у двомісячний строк:

здійснити організаційні заходи, пов'язані з утворенням казенного підприємства, призначенням його керівника;

розробити і затвердити в установленому порядку статут казенного підприємства;

2) у тримісячний строк після утворення казенного підприємства подати в установленому порядку Кабінетові Міністрів України пропозиції щодо:

включення казенного підприємства до переліку об'єктів права державної власності, що не підлягають приватизації;

внесення змін до переліку підприємств, установ та організацій, що належать до сфери управління Міністерства інфраструктури, затвердженого розпорядженням Кабінету Міністрів України від 21 березня 2011 р. N 265 ( 265-2011-р ) "Питання управління Міністерством інфраструктури об'єктами державної власності".
