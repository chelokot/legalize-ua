N 62 від 20.04.95 Зареєстровано в Міністерстві м.Київ юстиції України 21 квітня 1995 р. vd950420 vn62 за N 121/657

( Наказ втратив чинність на підставі Наказу Мінекономіки N 20 ( z0077-97 ) від 19.02.97 )

Про тарифи на електроенергію

( Із змінами, внесеними згідно з Наказом Мінекономіки N 90 ( z0186-95 ) від 19.06.95 )

( Із змінами, внесеними згідно з Постановою Нацкомелектроенергетики N 14 ( z0315-96 ) від 07.06.96 )

На виконання Указу Президента України від 12 жовтня 1994 року N 591/94 "Про невідкладні заходи щодо забезпечення народного господарства і населення України електричною і тепловою енергією в осінньо-зимовий період 1994-1995 року" (пункт 1, абз.3) та згідно з повноваженнями, затвердженими постановою Кабінету Міністрів України від 13 лютого 1995 року N 109 ( 109-95-п ) "Про уточнення повноважень центральних органів державної виконавчої влади, Уряду Автономної Республіки Крим та виконкомів місцевих Рад у галузі ціноутворення", НАКАЗУЮ:

1. Затвердити Тарифи на електричну енергію виробництва енергооб'єднань Міненерго України згідно з додатком.

2. Вважати такими, що втратили чинність, тарифи на електроенергію виробництва енергооб'єднань Міненерго, затверджені наказом Мінекономіки від 17.02.95 р. N 1 ( z0041-95 ).

Заступник Міністра В.М.Кальник

( Тарифи на електричну енергію виробництва енергооб'єднань Міненерго України втратили чинність на підставі Постанови Нацкомелектроенергетики N 14 ( z0315-96 ) від 07.06.96 )
