РОЗПОРЯДЖЕННЯ від 28 вересня 2006 р. N 496-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1001-р ( 1001-2008-р ) від 23.07.2008 }

Про голову Організаційного комітету з підготовки та проведення міжнародного медіафоруму "Україна на інформаційній карті світу"

Затвердити Віце-прем'єр-міністра України Табачника Дмитра Володимировича головою Організаційного комітету з підготовки та проведення міжнародного медіафоруму "Україна на інформаційній карті світу", утвореного розпорядженням Кабінету Міністрів України від 19 квітня 2006 р. N 221 ( 221-2006-р ), увільнивши від цих обов'язків Кириленка В'ячеслава Анатолійовича.
