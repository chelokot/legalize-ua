ДЕРЖАВНИЙ ДЕПАРТАМЕНТ УКРАЇНИ З ПИТАНЬ ВИКОНАННЯ ПОКАРАНЬ

НАКАЗ

18.09.2007 N 249

Зареєстровано в Міністерстві юстиції України 28 вересня 2007 р. за N 1126/14393

Про внесення змін до наказу Державного департаменту України з питань виконання покарань від 08.07.99 N 80

З метою приведення нормативно-правових актів Державного департаменту України з питань виконання покарань (далі - Департамент) у відповідність до Закону України "Про Державну кримінально-виконавчу службу України" ( 2713-15 ) НАКАЗУЮ:

1. Унести до наказу Департаменту від 08.07.99 N 80 ( z0594-99 ) "Про введення в дію норм належності майна продовольчої служби установ кримінально-виконавчої системи" (із змінами), зареєстрованого в Міністерстві юстиції України 02.09.99 за N 594/3887 (далі - Наказ), такі зміни:

1.1. У назві та преамбулі Наказу ( z0594-99 ) слова "кримінально-виконавчої системи" замінити словами "виконання покарань, слідчих ізоляторів і навчальних закладів Державної кримінально-виконавчої служби".

1.2. У пункті 1 Інструкції про застосування норм належності майна продовольчої служби ( z0597-99 ), затвердженої Наказом ( z0594-99 ), слова "кримінально-виконавчої системи" замінити словами "Державної кримінально-виконавчої служби".

2. Управлінню ресурсного, побутового та комунально-експлуатаційного забезпечення Департаменту (Шепель О.Л.) подати Наказ у встановленому порядку на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням Наказу покласти на заступника Голови Департаменту Височанського А.Ф.

4. Наказ оголосити персоналу Державної кримінально-виконавчої служби України.

Голова В.В.Кощинець
