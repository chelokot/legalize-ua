{ Розпорядження втратило чинність на підставі Розпорядження КМ N 219-р ( 219-2011-р ) від 21.03.2011 }

Про затвердження плану заходів з підготовки проекту Державної програми економічного і соціального розвитку України на 2012 рік

1. Затвердити план заходів з підготовки проекту Державної програми економічного і соціального розвитку України на 2012 рік, що додається.

2. Міністерствам, іншим центральним органам виконавчої влади, Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським держадміністраціям забезпечити виконання затвердженого цим розпорядженням плану заходів.

3. Контроль за виконанням цього розпорядження покласти на Першого віце-прем'єр-міністра України - Міністра економічного розвитку і торгівлі Клюєва А.П.
