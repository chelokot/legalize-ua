На зміну статті 2 Указу Президента України від 21 березня 1995 року N 248 ( 248/95 ) "Про Комісію з питань аграрної та земельної реформи при Президентові України" (із змінами, внесеними Указом Президента України від 27 вересня 1996 року N 889 ( 889/96 ) затвердити новий персональний склад Комісії (додається).
