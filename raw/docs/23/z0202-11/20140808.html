03.02.2011 N 32

Зареєстровано в Міністерстві юстиції України 18 лютого 2011 р. за N 202/18940

{ Наказ втратив чинність на підставі Наказу Міністерства соціальної політики N 465 ( z0852-14 ) від 14.07.2014 }

Про внесення зміни до наказу Міністерства праці та соціальної політики України від 30.09.2005 N 289

Відповідно до постанови Кабінету Міністрів України від 29.12.2010 N 1212 ( 1212-2010-п ) "Про внесення змін до постанов Кабінету Міністрів України від 30 серпня 2002 р. N 1298 і від 25 жовтня 2008 р. N 939" НАКАЗУЮ:

1. Внести до наказу Міністерства праці та соціальної політики України від 30.09.2005 N 289 ( z1197-05 ) "Про умови оплати праці працівників бюджетних науково-дослідних установ Мінпраці України", зареєстрованого в Міністерстві юстиції України 13.10.2005 за N 1197/11477 (зі змінами), таку зміну:

абзац перший примітки 1 додатка 1 до наказу замінити абзацом такого змісту:

"1. У 2011 році посадові оклади (тарифні ставки) розраховуються виходячи з розміру посадового окладу (тарифної ставки) працівника першого тарифного розряду з 1 січня - 613 гривень. Для працівників, у яких посадові оклади менші, ніж розмір мінімальної заробітної плати, посадові оклади (тарифні ставки) у штатних розписах установлюються на рівні мінімальної заробітної плати.".

2. Керівникам державної установи "Науково-дослідний інститут соціально-трудових відносин" С.Мельнику, науково-дослідної установи "Український науково-дослідний інститут протезування, протезобудування та відновлення працездатності" А.Салєєвій забезпечити диференціацію заробітної плати працівників, для яких визначені однакові посадові оклади, за рахунок встановлення доплат, надбавок та премій.

3. Цей наказ набирає чинності з дня його офіційного опублікування та застосовується з 1 січня 2011 року.

Голова Комісії з проведення реорганізації, Перший заступник Міністра Л.Дроздова
