УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 208/2005 ( 208/2005 ) від 08.02.2005 )

Про внесення змін до складу Ради національної безпеки і оборони України

Увести до складу Ради національної безпеки і оборони України, затвердженого Указом Президента України від 7 серпня 2001 року N 605 ( 605/2001 ) (зі змінами, внесеними Указами від 27 грудня 2001 року N 1277 ( 1277/2001 ), від 22 травня 2002 року N 481 ( 481/2002 ), від 15 червня 2002 року N 557 ( 557/2002 ), від 20 червня 2002 року N 574 ( 574/2002 ), від 7 вересня 2002 року N 807 ( 807/2002 ), від 24 грудня 2002 року N 1208 ( 1208/2002 ) та від 29 вересня 2003 року N 1110 ( 1110/2003 ), ДЕРКАЧА Миколу Івановича - Міністра економіки та з питань європейської інтеграції України, вивівши зі складу цієї Ради Хорошковського В.І.

Президент України Л.КУЧМА

м. Київ, 28 січня 2004 року N 108/2004
