КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 липня 1999 р. N 1387 Київ

Про внесення змін до деяких постанов Кабінету Міністрів України з питань установлення мінімальної митної вартості на товари легкої промисловості та сільськогосподарську продукцію

( Із змінами, внесеними згідно з Постановами КМ N 134 ( 134-2000-п ) від 24.01.2000 N 575 ( 575-2000-п ) від 29.03.2000 )

Кабінет Міністрів України постановляє:

1. ( Пункт 1 втратив чинність в частині внесення змін у додаток 1 до постанови Кабінету Міністрів України від 26 травня 1997 р. N 502 на підставі Постанови КМ N 134 ( 134-2000-п ) від 24.01.2000; у частині внесення змін у додаток до постанови Кабінету Міністрів України від 27 липня 1998 р. N 1164 "Про встановлення мінімальної митної вартості окремих видів імпортних товарів на підставі Постанови КМ N 575 ( 575-2000-п ) від 29.03.2000 ) 1. Внести у додаток 1 до постанови Кабінету Міністрів України від 26 травня 1997 р. N 502 ( 502-97-п ) "Про встановлення мінімальної митної вартості на деякі товари, що підлягають обкладенню акцизним збором" (Офіційний вісник України, 1997 р., число 21, с. 78; 1998 р., N 19, ст. 688) та у додаток до постанови Кабінету Міністрів України від 27 липня 1998 р. N 1164 ( 1164-98-п ) "Про встановлення мінімальної митної вартості окремих видів імпортних товарів" (Офіційний вісник України, 1998 р., N 30, ст. 1131) зміни, що додаються.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 3 листопада 1997 р. N 1215 ( 1215-97-п ) "Про встановлення мінімальної митної вартості окремих видів товарів" (Офіційний вісник України, 1997 р., число 45, с. 49; 1999 р., N 27, ст. 1329).

3. Ця постанова набирає чинності через 20 днів після опублікування у газеті "Урядовий кур'єр".
