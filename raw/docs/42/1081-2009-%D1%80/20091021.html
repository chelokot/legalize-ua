Кабінет Міністрів України; Розпорядження, Перелік від 09.09.2009 № 1081-р

Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов

Стан: Чинний

Ідентифікатор: 1081-2009-р

Текст документа від 21.10.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 вересня 2009 р. N 1081-р Київ

Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1176-р ( 1176-2009-р ) від 23.09.2009 N 1401-р ( 1401-2009-р ) від 21.10.2009 }

1. Погодитися з пропозицією Мінрегіонбуду щодо придбання Державною іпотечною установою квартир за переліком згідно з додатком на загальну суму 191799,167 тис. гривень в житлових будинках, прийнятих в експлуатацію, та на об'єктах незавершеного житлового будівництва із строком здачі в експлуатацію не пізніше ніж 25 грудня 2009 р. за наявності відповідної банківської гарантії або іншого виду забезпечення виконання зобов'язань забудовників, що прийматимуться Державною іпотечною установою, або наявності графіка виконання будівельно-монтажних робіт, погодженого з керівником інспекції державного архітектурно-будівельного контролю в Автономній Республіці Крим, областях, мм. Києві та Севастополі, для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов та перебувають на квартирному обліку.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 1401-р ( 1401-2009-р ) від 21.10.2009 }

2. Державній іпотечній установі передати квартири, придбані відповідно до пункту 1 цього розпорядження, головним розпорядникам бюджетних коштів за розподілом Мінпраці, погодженим з Мінсім'ямолодьспортом та Мінфіном.

3. У позиції "м. Бердянськ Запорізької області, вул. Хіміків, 13, "10-поверховий житловий будинок (1 черга) у складі житлового комплексу за адресою: Запорізька область, м. Бердянськ, вул. Хіміків, 13" додатка до розпорядження Кабінету Міністрів України від 3 вересня 2009 р. N 1047 ( 1047-2009-р ) "Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов" слова і цифри "обслуговуючий житлово-будівельний кооператив "Азовський", 34976498" замінити словами і цифрами "ТОВ "Он Лайн Азов-Юг", 36451591".

4. Головним розпорядникам бюджетних коштів разом з Мінфіном під час уточнення показників Державного бюджету України на 2009 рік ( 835-17 ) та складання проектів державного бюджету на наступні роки передбачати кошти для компенсації Державній іпотечній установі витрат, пов'язаних з придбанням квартир відповідно до пункту 1 цього розпорядження.
