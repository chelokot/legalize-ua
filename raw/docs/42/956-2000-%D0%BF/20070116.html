ПОСТАНОВА від 13 червня 2000 р. N 956 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 21 ( 21-2007-п ) від 16.01.2007 }

Про внесення змін і доповнення до постанови Кабінету Міністрів України від 2 липня 1998 р. N 1000

Кабінет Міністрів України постановляє:

1. Внести до постанови Кабінету Міністрів України від 2 липня 1998 р. N 1000 ( 1000-98-п ) "Про утворення Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України" такі зміни і доповнення:

1) затвердити новий склад Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України (додається).

Дозволити голові Міжвідомчої комісії вносити у разі потреби зміни до її складу;

2) пункт 4 виключити;

3) у Положенні про Міжвідомчу комісію з питань місцевого самоврядування при Кабінеті Міністрів України, затвердженому зазначеною постановою, пункт 5 виключити.

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 25 грудня 1998 р. N 2064 ( 2064-98-п ) "Про внесення змін до складу Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України";

постанову Кабінету Міністрів України від 11 травня 1999 р. N 787 ( 787-99-п ) "Про зміни у складі Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України".
