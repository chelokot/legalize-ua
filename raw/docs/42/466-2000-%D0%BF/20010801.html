КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 березня 2000 р. N 466 Київ

Про вдосконалення структури Служби Прем'єр-міністра України та Секретаріату Кабінету Міністрів України

( Із змінами, внесеними згідно з Постановою КМ N 660 ( 660-2001-п ) від 20.06.2001 )

( Щодо змін додатково див. Постанову КМ N 932 ( 932-2001-п ) від 01.08.2001 )

Кабінет Міністрів України постановляє:

1. З метою вдосконалення структури Служби Прем'єр-міністра України, затвердженої постановою Кабінету Міністрів України від 28 грудня 1999 р. N 2381 ( 2381-99-п ), затвердити нову структуру зазначеної Служби (додається).

2. На доповнення структури Кабінету Міністрів України, затвердженої постановою Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) (Офіційний вісник України, 2000 р., N 4, ст. 110), утворити в структурі Секретаріату Кабінету Міністрів України такі підрозділи:

Прес-службу Кабінету Міністрів України

Відділ протокольного забезпечення та прийому офіційних делегацій.

3. У пункті 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88 "Питання Секретаріату Кабінету Міністрів України" цифри "499" та "55" замінити відповідно цифрами "516" та "38".
