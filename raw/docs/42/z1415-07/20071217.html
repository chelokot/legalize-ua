З метою запровадження обігу книжок (карнетів) A.T.A. ( 995_472a ) в Україні відповідно до положень Конвенції про тимчасове ввезення ( 995_472 ), учиненої у м. Стамбулі 26 червня 1990 року, на підставі статті 187 Митного кодексу України ( 92-15 ) та на виконання пункту 2 постанови Кабінету Міністрів України від 29.11.2006 N 1654 ( 1654-2006-п ) "Про затвердження Порядку видачі книжок (карнетів) A.T.A." НАКАЗУЮ:

1. Затвердити Порядок митного оформлення товарів, що переміщуються через митний кордон з використанням книжок (карнетів) A.T.A., що додається.

2. Департаменту декларування та митних режимів (Науменко В.П.) та Юридичному департаменту (Небрат Л.М.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Департаменту декларування та митних режимів (Науменко В.П.) у місячний строк після державної реєстрації цього наказу в Міністерстві юстиції України розробити й подати на затвердження Голові Служби проект нормативно-правового акта, спрямованого на врегулювання особливостей застосування митних режимів до товарів, які переміщуються через митний кордон з використанням книжок (карнетів) A.T.A. ( 995_472a ).

4. Регіональній інформаційній митниці (Копосов С.А.) до набрання чинності цим наказом розробити програмне забезпечення для реалізації положень Порядку митного оформлення товарів, що переміщуються через митний кордон з використанням книжок (карнетів) A.T.A., затвердженого цим наказом.

5. Департаменту митних платежів (Джигалов С.О.), Управлінню бухгалтерського обліку та звітності (Околіта М.В.), Департаменту декларування та митних режимів (Науменко В.П.) та Юридичному департаменту (Небрат Л.М.) до набрання чинності цим наказом розробити спільно із Торгово-промисловою палатою України, як гарантуючою організацією, яка здійснює видачу в Україні книжок (карнетів) A.T.A. ( 995_472a ), механізм безумовного надходження коштів до Державного бюджету у визначених чинним законодавством випадках порушень, пов'язаних з використанням зазначених книжок (карнетів) A.T.A.

6. Начальникам митних органів визначити посадових осіб, уповноважених здійснювати митне оформлення товарів, що переміщуються через митний кордон з використанням книжок (карнетів) A.T.A. ( 995_472a ).

7. Установити, що цей наказ набирає чинності з 1 березня 2008 року.

Контроль за виконанням наказу залишаю за собою.

ПОРЯДОК митного оформлення товарів, що переміщуються через митний кордон з використанням книжок (карнетів) A.T.A.

I. Загальні положення

1. Цей Порядок розроблено відповідно до положень Конвенції про тимчасове ввезення ( 995_472 ), учиненої у м. Стамбулі 26 червня 1990 року (далі - Стамбульська конвенція), Митного кодексу України ( 92-15 ), постанов Кабінету Міністрів України від 12.12.2002 N 1855 ( 1855-2002-п ) "Про допущення товарів до переміщення через митний кордон України в режимі тимчасового ввезення (вивезення)" та від 29.11.2006 N 1654 ( 1654-2006-п ) "Про затвердження Порядку видачі книжок (карнетів) A.T.A.", Угоди про співробітництво між Державною митною службою України та Торгово-промисловою палатою України, підписаної 22 лютого 2007 року в місті Києві, з метою запровадження обігу книжок (карнетів) A.T.A. ( 995_472a ) в Україні.

Дія цього Порядку поширюється на товари, що переміщуються через митний кордон України відповідно до положень Стамбульської конвенції ( 995_472 ) з використанням книжок (карнетів) A.T.A. ( 995_472a ).

2. У цьому Порядку терміни вживаються в значеннях, наведених у Стамбульській конвенції ( 995_472 ) та Митному кодексі України ( 92-15 ).

3. Митному оформленню в митному режимі тимчасового ввезення (вивезення) з використанням книжок (карнетів) A.T.A. ( 995_472a ) підлягають товари, що переміщуються через митний кордон України відповідно до положень Стамбульської конвенції ( 995_472 ) та Додатків B.1-B.9 і D до неї.

4. Митному оформленню в митному режимі транзиту підлягають товари, що переміщуються через митну територію України транзитом з використанням книжок (карнетів) A.T.A. ( 995_472a ) відповідно до положень Стамбульської конвенції ( 995_472 ) та Додатків B.1-B.9 і D до неї і призначені для тимчасового ввезення на територію будь-якої іншої договірної сторони Стамбульської конвенції.

5. Організацією в Україні, що видає та гарантує відповідно до положень Стамбульської конвенції ( 995_472 ) книжки (карнети) A.T.A. ( 995_472a ), є Торгово-промислова палата України (далі - ТПП України).

6. Належним чином оформлена та видана книжка (карнет) A.T.A. ( 995_472a ) приймається митними органами України для митного оформлення товарів, що переміщуються через митний кордон України відповідно до Стамбульської конвенції ( 995_472 ), замість вантажної митної декларації ( za140-07, 910а-2007-п ) та як гарантія сплати сум, зазначених у статті 8 Додатка A до Стамбульської конвенції.

7. Митне оформлення товарів у митних режимах тимчасового ввезення (вивезення) або транзиту, що переміщуються з використанням книжки (карнета) A.T.A. ( 995_472a ), здійснюється уповноваженими посадовими особами:

митного органу, розташованого в пункті пропуску через державний кордон України, якщо товари ввозяться тимчасово, з метою транзиту, зворотно вивозяться, а також якщо зворотно ввозяться громадянами;

митного органу, у зоні діяльності якого розташоване відповідне підприємство-резидент, якщо товари тимчасово вивозяться за межі митної території України або зворотно ввозяться підприємствами;

будь-якого митного органу, якщо товари тимчасово вивозяться за межі митної території України громадянами.

8. Переміщенню через митний кордон України з використанням книжок (карнетів) A.T.A. ( 995_472a ) не підлягають товари:

1) що законами України заборонені до ввезення, вивезення і транзиту територією України;

2) щодо яких не було завершено митне оформлення;

3) які переміщуються через митний кордон України з порушенням вимог Стамбульської конвенції ( 995_472 ), Митного кодексу України ( 92-15 ) та інших законодавчих актів України.

9. Строк дії книжки (карнета) A.T.A. ( 995_472a ) не повинен перевищувати одного року з дати її видачі асоціацією, що видає документи.

10. Товари, тимчасово ввезені на митну територію України (вивезені за межі митної території України) на підставі книжки (карнета) A.T.A. ( 995_472a ), можуть використовуватися тільки з метою, наведеною в графі C першої сторінки обкладинки книжки (карнета) A.T.A.

11. Після видачі ТПП України книжки (карнета) A.T.A. ( 995_472a ) внесення змін до загального списку товарів, наведеного на другій сторінці обкладинки цієї книжки (карнета) A.T.A. або на додаткових аркушах до неї - додатках до загального списку товарів, не допускається.

12. Після прийняття до митного оформлення товарів з використанням книжки (карнета) A.T.A. ( 995_472a ) внесення будь-яких змін до цієї книжки не допускається.

13. Митні органи, приймаючи до митного оформлення товари, що переміщуються через митний кордон України з використанням книжок (карнетів) A.T.A. ( 995_472a ), перевіряють відомості, зазначені в таких книжках, на відповідність положенням Стамбульської конвенції ( 995_472 ) та Додатків A, B.1-B.9 і D до неї.

14. Якщо книжки (карнети) A.T.A. ( 995_472a ) заповнені іншою мовою, ніж українська, російська чи англійська, то на підставі пункту 10 Інструкції з користування карнетом A.T.A., наведеної на третій сторінці обкладинки цієї книжки, митний орган може вимагати переклад такої книжки (карнета) A.T.A. на українську мову, засвідчений у встановленому порядку.

15. Якщо за результатами перевірки, здійсненої відповідно до пункту 13 цього розділу, тимчасове ввезення (вивезення) товарів на підставі книжки (карнета) A.T.A. ( 995_472a ) неможливе (зокрема, якщо товари не підлягають пропуску з умовним повним звільненням від оподаткування), то такі товари можуть бути розміщені згідно з положеннями Митного кодексу України ( 92-15 ) в будь-який митний режим, у тому числі тимчасового ввезення (вивезення).

16. Реєстрація книжок (карнетів) A.T.A. ( 995_472a ) здійснюється в журналі обліку книжок (карнетів) A.T.A., що ведеться митними органами в електронному вигляді.

Журнал обліку книжок (карнетів) A.T.A. повинен містити:

реєстраційний номер книжки (карнета) A.T.A. згідно з журналом обліку;

дату реєстрації;

номер книжки (карнета) A.T.A., присвоєний асоціацією, що видає документи, і наведений у полі "a" графи G першої сторінки обкладинки;

дату видачі книжки (карнета) A.T.A., наведену в графі I першої сторінки обкладинки;

кількість додаткових аркушів до загального списку книжки (карнета) A.T.A., наведену в полі "a" графи G першої сторінки обкладинки;

термін дії книжки (карнета) A.T.A., наведений у полі "c" графи G першої сторінки обкладинки;

кількість порядкових номерів товарів, наведених у загальному списку книжки (карнета) A.T.A. та додатках до нього, короткий опис товарів;

відомості про асоціацію, що видає документи, наведені в полі "b" графи G першої сторінки обкладинки;

відомості про власника книжки (карнета) A.T.A., наведені в графі A першої сторінки обкладинки;

відомості про вповноважену власником книжки (карнета) A.T.A. особу, наведені в графі B першої сторінки обкладинки або у відповідній довіреності (за наявності такої особи);

призначення товарів, що тимчасово переміщуються через митний кордон України, наведене в графі C першої сторінки обкладинки;

митний режим товарів;

відомості про одержувача товарів згідно з товаротранспортними та іншими документами (найменування / П.І.Б., місцезнаходження / місце проживання), а також про місце доставки;

прізвище та ініціали, номер особистої номерної печатки вповноваженої посадової особи митного органу, яка оформила книжку (карнет) A.T.A. для тимчасового ввезення (вивезення) товарів;

прізвище та ініціали, номер особистої номерної печатки вповноваженої посадової особи митного органу, яка оформила книжку (карнет) A.T.A. для зворотного вивезення (увезення) товарів;

дату зворотного вивезення (увезення);

номер вантажної митної декларації ( za140-07, 910а-2007-п ) для випадків зміни митного режиму щодо тимчасово ввезених (вивезених) товарів;

примітки.

18. Гранична дата тимчасового ввезення (вивезення) установлюється митним органом відповідно до положень Стамбульської конвенції ( 995_472 ) та Додатків B.1-B.9 і D до неї та повинна передбачати час, необхідний для транспортних операцій, але не повинна перевищувати термін дії книжки (карнета) A.T.A. ( 995_472a ).

19. Книжка (карнет) A.T.A. ( 995_472a ) подається митному органу разом з іншими документами та відомостями, передбаченими статтею 45 Митного кодексу України ( 92-15 ).

20. Контроль за додержанням строків тимчасового ввезення (вивезення) товарів, переміщених через митний кордон України з використанням книжок (карнетів) A.T.A. ( 995_472a ), здійснюється відповідно до законодавства України, в тому числі цього Порядку, митним органом, посадова особа якого прийняла рішення про можливість допущення товарів до переміщення в митному режимі тимчасового ввезення (вивезення) (далі - митний орган, на контролі якого перебувають тимчасово ввезені /вивезені/ товари).

21. Товари, на які поширюється режим тимчасового ввезення (вивезення), можуть бути зворотно вивезені (увезені):

однією чи декількома партіями, при цьому вся кількість товарів, наведених під одним порядковим номером у загальному списку та в додаткових аркушах до нього книжки (карнета) A.T.A. ( 995_472a ), повинна входити до складу однієї партії;

через інший митний орган, ніж той, через який ці товари було ввезено (вивезено).

22. Власник книжки (карнета) A.T.A. ( 995_472a ) повинен забезпечити наявність у цій книжці достатньої кількості аркушів, виданих асоціацією, що видала зазначену книжку.

23. Посадовою особою митного органу, зазначеного в пункті 7 цього розділу, створюється з використанням засобів програмного забезпечення електронна копія книжки (карнета) A.T.A. ( 995_472a ).

Інформація вноситься до електронної копії книжки (карнета) A.T.A. українською мовою та повинна відповідати інформації, унесеній до оригіналу цієї книжки.

При створенні електронної копії книжки (карнета) A.T.A. на товари, що тимчасово вивозяться за межі митної території України, використовується інформація, одержана від ТПП України відповідно до Угоди про співробітництво між Державною митною службою України та Торгово-промисловою палатою України від 24.02.2007.

II. Тимчасове вивезення товарів з використанням книжок (карнетів) A.T.A. ( 995_472a )

1. Митне оформлення товарів, що тимчасово вивозяться з митної території України з використанням книжки (карнета) A.T.A. ( 995_472a ), здійснюється в установленому порядку з нижченаведеними особливостями.

2. Книжка (карнет) A.T.A. ( 995_472a ) приймається до оформлення митним органом, визначеним у пункті 7 розділу I цього Порядку, якщо вона належним чином заповнена й оформлена ТПП України та власником цієї книжки (його представником).

3. Уповноважена посадова особа митного органу здійснює перевірку книжки (карнета) A.T.A. ( 995_472a ) відповідно до пункту 13 розділу I цього Порядку та встановлює, що графи A-G жовтого відривного документа на вивезення ("exportation") заповнені власником книжки (карнета) A.T.A. (його представником) та асоціацією, що видає документи, правильно.

На підставі позитивних результатів перевірки приймає рішення про можливість допущення до переміщення товарів у митному режимі тимчасового ввезення (вивезення) з використанням книжки (карнета) A.T.A. та вчиняє такі дії:

3.1. Перевіряє відповідність даних, занесених у графи A-G та загальний список відривного документа на вивезення жовтого кольору ("exportation") книжки (карнета) A.T.A. ( 995_472a ), відомостям, наведеним на першій і другій сторінках обкладинки цієї книжки (карнета) A.T.A., а також перевіряє товари, що тимчасово вивозяться, на відповідність товарам, зазначеним у цій книжці.

3.2. Заповнює графу H "Засвідчення митних органів при вивезенні", яка розташована на першій сторінці обкладинки книжки (карнета) A.T.A. ( 995_472a ) (якщо з використанням цієї книжки переміщується перша партія товару), шляхом унесення:

до поля "a" номерів товарів відповідно до загального списку книжки (карнета) A.T.A., щодо яких митним органом застосовано заходи ідентифікації згідно зі статтею 64 Митного кодексу України ( 92-15 );

до поля "b" знака "X" у рамці "Yes/Так", якщо товари оглядалися митним органом, або в рамці "No/Ні", якщо митний огляд товарів не здійснювався;

до поля "c" реєстраційного номера книжки (карнета) A.T.A., сформованого відповідно до пункту 17 розділу I цього Порядку;

до поля "d" назви й місця розташування митного органу, поточної дати у форматі рік/місяць/день, підпису та відбитка особистої номерної печатки.

3.3. Уносить до колонки 7 загального списку, розміщеного на другій сторінці обкладинки книжки (карнета) A.T.A. ( 995_472a ) та на зелених додаткових аркушах до цього списку, номери, знаки та кількість митних забезпечень, застосованих відповідно до статті 64 Митного кодексу України ( 92-15 ) для ідентифікації товарів, що тимчасово вивозяться за межі митної території України.

3.4. Заповнює графу H жовтого відривного документа на вивезення ("exportation") книжки (карнета) A.T.A. ( 995_472a ) шляхом унесення:

до поля "b" граничної дати у форматі рік/місяць/день зворотного ввезення товарів, що визначається згідно з пунктом 18 розділу I цього Порядку;

до поля "c" назви й адреси митного органу, уповноважена посадова особа якого прийняла рішення про можливість допущення до переміщення товарів у митному режимі тимчасового ввезення (вивезення);

до поля "d":

реєстраційного номера відривного документа на вивезення книжки (карнета) A.T.A, який формується шляхом додавання до реєстраційного номера книжки (карнета) A.T.A. через знак "/" порядкового номера відривного документа на вивезення, що відповідає кількості оформлених протягом строку дії цієї книжки документів на вивезення, починаючи з одиниці в порядку зростання;

назви митного органу, через який передбачається фактичне вивезення товарів за межі України.

3.5. Заповнює жовтий невідривний корінець документа на вивезення ("exportation") книжки (карнета) A.T.A. ( 995_472a ) шляхом унесення:

до графи 1 порядкових номерів товарів, що тимчасово вивозяться, наведених у колонці 1 загального списку книжки (карнета) A.T.A.;

до графи 2 граничної дати у форматі рік/місяць/день зворотного ввезення товарів, що відповідає даті, зазначеній у полі "b" графи H жовтого відривного документа на вивезення;

до графи 3 реєстраційного номера відривного документа на вивезення книжки (карнета) A.T.A., що наведений в полі "d" графи H цього документа на вивезення;

до графи 4 назви митного органу, через який передбачається фактичне вивезення товарів за межі України;

до графи 5 місця розташування митного органу, через який передбачається фактичне вивезення товарів за межі України.

3.6. Заповнює графу H жовтого відривного документа на зворотне ввезення ("reimportation") книжки (карнета) A.T.A. ( 995_472a ) шляхом унесення:

до поля "b" назви й адреси митного органу, на контролі якого перебуватимуть товари, що тимчасово вивозяться;

до поля "c" реєстраційного номера відповідного відривного документа на вивезення книжки (карнета) A.T.A, що наведений в полі "d" графи H цього документа на вивезення.

3.7. Уносить до колонки 7 загального списку жовтого відривного документа на вивезення ("exportation") та жовтих додаткових аркушів до загального списку (за наявності) книжки (карнета) A.T.A. ( 995_472a ) номери, знаки та кількість митних забезпечень, застосованих відповідно до статті 64 Митного кодексу України ( 92-15 ) для ідентифікації товарів, що тимчасово вивозяться за межі митної території України.

3.8. Накладає, якщо можливо, митне забезпечення на транспортні засоби, з використанням яких здійснюватиметься вивезення товарів за межі України, та вносить відомості про це забезпечення до кожного поля "Разом або для перенесення на додатковий аркуш" колонки 7 загального списку та додаткових аркушів до нього (за наявності) жовтого відривного документа на вивезення ("exportation") книжки (карнета) A.T.A. ( 995_472a ).

3.9. Заносить за допомогою засобів програмного забезпечення результати дій, учинених відповідно до пунктів 3.2-3.8 цього розділу, до Єдиної автоматизованої інформаційної системи Держмитслужби України (далі - ЄАІС) та роздруковує аркуш журналу обліку книжок (карнетів) A.T.A. ( 995_472a ), сформований ЄАІС.

3.10. Роздруковує з ЄАІС та одержує підпис власника книжки (карнета) A.T.A. ( 995_472a ) (уповноваженої особи) під зобов'язанням про зворотне ввезення такого змісту:

"Зобов'язуюся до закінчення строку тимчасового вивезення здійснити зворотне ввезення товарів або заявити про зміну митного режиму, що допускається щодо цих товарів законодавством України, і надати митному органу передбачені законодавством документи й відомості, потрібні для проведення митного контролю й митного оформлення товарів.

Про відповідальність згідно зі статтями 330, 331, 336, 338, 340, 343, 348, 354, 355 Митного кодексу України попереджений".

3.11. Знімає копії з першої сторінки обкладинки, загального списку та додаткових аркушів до нього (за наявності), жовтого відривного документа на вивезення ("exportation"), жовтого невідривного корінця документа на вивезення ("exportation") книжки (карнета) A.T.A. ( 995_472a ).

3.12. Якщо митний орган, уповноважена посадова особа якого прийняла рішення про можливість допущення до переміщення товарів у митному режимі тимчасового ввезення (вивезення), є одночасно митним органом, через який передбачається фактичне вивезення товарів за межі України, то вповноважена особа цього органу:

уносить до поля "d" графи H жовтого відривного документа на вивезення ("exportation") книжки (карнета) A.T.A. ( 995_472a ) та до граф 6 і 7 його невідривного корінця дату у форматі рік/місяць/день фактичного вивезення товару за межі митної території України та особистий підпис і проставляє відбиток особистої номерної печатки;

вилучає жовтий відривний документ на вивезення ("exportation") та відповідні жовті додаткові аркуші до загального списку (за наявності) з книжки (карнета) A.T.A.;

заносить результати дій, учинених згідно з цим пунктом, до ЄАІС.

3.13. Повертає власнику або його представнику оформлену митним органом книжку (карнет) A.T.A. ( 995_472a ) для переміщення разом з товарами в пункт пропуску через державний кордон України або за межі України.

4. Уповноважена посадова особа митного органу, розташованого в пункті пропуску через державний кордон України, у разі надходження товарів, що тимчасово вивозяться за межі України з використанням книжки (карнета) A.T.A. ( 995_472a ):

4.1. Звіряє відомості, наведені в книжці (карнеті) A.T.A. ( 995_472a ), з даними, які містяться в ЄАІС щодо цієї книжки, та перевіряє цілість і відповідність митного забезпечення, накладеного на транспортний засіб та/або товари.

Якщо митне забезпечення не накладалося або в разі виявлення факту пошкодження чи втрати митного забезпечення, наявності інших передбачених законодавством підстав здійснює повторний митний огляд товарів, що тимчасово вивозяться з використанням книжки (карнета) A.T.A.

4.2. Уносить, якщо за результатами заходів, передбачених пунктом 4.1 цього розділу, не виявлено порушення і розбіжності:

до поля "d" графи H жовтого відривного документа на вивезення ("exportation") книжки (карнета) A.T.A. ( 995_472a ) запис про здійснення повторного митного огляду та відомості про нове митне забезпечення (якщо такий огляд здійснювався і нове забезпечення накладалось);

до поля "d" графи H жовтого відривного документа на вивезення ("exportation") книжки (карнета) A.T.A та до граф 6 і 7 його невідривного корінця дату у форматі рік/місяць/день фактичного вивезення товару за межі митної території України та особистий підпис і проставляє відбиток особистої номерної печатки.

4.3. Заносить за допомогою засобів програмного забезпечення результати дій, учинених відповідно до пункту 4.2 цього розділу, до ЄАІС.

4.4. Вилучає жовтий відривний документ на вивезення ("exportation") та відповідні жовті додаткові аркуші до загального списку (за наявності) з книжки (карнета) A.T.A. ( 995_472a ) і направляє їх завірені копії митному органу, зазначеному в полі "c" графи H цього відривного документа на вивезення.

4.5. Повертає власнику або його представнику оформлену митним органом книжку (карнет) A.T.A. ( 995_472a ) для пропуску разом з товарами через митний кордон України.

5. Якщо в результаті заходів, передбачених пунктом 4.1 цього розділу, виявлено порушення або розбіжності, то вповноважена посадова особа митного органу, розташованого в пункті пропуску через державний кордон України, уживає заходів, передбачених законодавством України.

У разі неможливості відповідно до пункту 8 розділу I цього Порядку пропуску товарів за межі України та необхідності переоформлення ТПП України книжки (карнета) A.T.A. ( 995_472a ), внесення відомостей, що належить до компетенції митних органів, до такої переоформленої книжки (карнета) A.T.A. здійснюється митним органом:

посадова особа якого прийняла рішення про можливість допущення до переміщення товарів у митному режимі тимчасового вивезення, якщо необхідно вносити зміни до першої сторінки обкладинки книжки (карнета) A.T.A. та загального списку, розташованого на другій сторінці обкладинки цієї книжки. Уповноважена посадова особа цього митного органу вчиняє дії, передбачені пунктом 3 цього розділу, без обов'язкового повторного пред'явлення товарів і проставляє в полі "b" графи H першої сторінки обкладинки книжки (карнета) A.T.A. знак "X" у рамці "No/Ні", не вносячи при цьому до відповідних граф цієї книжки відомості про накладене на транспортний засіб митне забезпечення;

розташованим у пункті пропуску через державний кордон України, - у всіх інших випадках. Уповноважена посадова особа вчиняє дії, передбачені пунктом 3 цього розділу, за винятком тих, що вже вчинені митним органом, посадова особа якого прийняла рішення про можливість допущення до переміщення товарів у митному режимі тимчасового вивезення. Уносить відповідні виправлення до ЄАІС, робить запис про зміст переоформлення в графі "Примітки" журналу обліку книжок (карнетів) A.T.A. та вчиняє дії, передбачені пунктами 4.2-4.5 цього розділу.

Уповноважена посадова особа митного органу, розташованого в пункті пропуску через державний кордон України, у разі одержання переоформленої відповідно до абзацу третього цього пункту книжки (карнета) A.T.A. звіряє відомості, наведені в цій книжці, з даними, які містяться в ЄАІС щодо цієї книжки, і за відсутності повторних порушень або розбіжностей вчиняє дії, передбачені пунктами 4.2-4.5 цього розділу.

6. Товари, зазначені в полі "a" графи F жовтого відривного документа на вивезення ("exportation") книжки (карнета) A.T.A. ( 995_472a ) та в графі 1 його невідривного корінця, уважаються тимчасово вивезеними за наявності в полі "d" графи H цього документа на вивезення та в графі 7 його невідривного корінця підпису та відбитка особистої номерної печатки вповноваженої посадової особи митного органу.

III. Декларування тимчасово вивезених товарів до іншого митного режиму з використанням вантажної митної декларації ( za140-07, 910а-2007-п )

1. Якщо товари, тимчасово вивезені за межі митної території України з використанням книжки (карнета) A.T.A. ( 995_472a ), не повертатимуться власником цієї книжки (уповноваженою особою) на митну території України, то такі товари підлягають митному оформленню відповідно до статті 210 Митного кодексу України ( 92-15 ) в митний режим, який допускається щодо таких товарів з додержанням вимог Митного кодексу України та інших законодавчих актів України.

2. Разом з вантажною митною декларацією ( za140-07, 910а-2007-п ) (далі - ВМД), заповненою декларантом згідно з обраним митним режимом, митному органу, на контролі якого перебувають тимчасово вивезені товари, подається книжка (карнет) A.T.A. ( 995_472a ), з використанням якої ці товари тимчасово вивезені за межі України.

3.2. У разі оформлення відповідно до пункту 2 цього розділу всіх найменувань товарів у повному обсязі визнає недійсними жовті відривний документ на зворотне ввезення ("reimportation") та його невідривний корінець книжки (карнета) A.T.A. ( 995_472a ) шляхом унесення:

( 995_472a ) та прикріплює їх до відповідних жовтих документів на вивезення ("exportation") і додаткових аркушів до них (за наявності).

4.12. Повертає власнику чи його представникові оформлену митним органом книжку (карнет) A.T.A. ( 995_472a ).

5. Товари, зазначені в полі "a" графи F білого відривного документа на вивезення раніше ввезених товарів книжки (карнета) A.T.A. ( 995_472a ) та в графі 1 його невідривного корінця, уважаються зворотно вивезеними за наявності в полі "f" графи H цього документа на вивезення раніше ввезених товарів і в графі 8 його невідривного корінця підпису та відбитка особистої номерної печатки вповноваженої посадової особи митного органу.

VIII. Переміщення товарів транзитом з використанням книжки (карнета) A.T.A. ( 995_472a )

1. Книжка (карнет) A.T.A. ( 995_472a ) може використовуватися для митного оформлення товарів, що переміщуються митною територією України транзитом до країни/території їх тимчасового ввезення або в зворотному напрямку.

2. Митне оформлення товарів, що переміщуються транзитом з використанням книжки (карнета) A.T.A. ( 995_472a ), здійснюється в установленому порядку з нижченаведеними особливостями.

3. Гарантування доставки товарів, що перебувають під митним контролем і переміщуються транзитом митною територією України з використанням книжки (карнета) A.T.A. ( 995_472a ), здійснюється на умовах, установлених Стамбульською конвенцією ( 995_472 ).

4. Уповноважена посадова особа митного органу, розташованого в пункті пропуску через державний кордон України, у разі надходження товарів, що переміщуватимуться через митну територію України транзитом з використанням книжки (карнета) A.T.A. ( 995_472a ):

4.1. Здійснює перевірку книжки (карнета) A.T.A. ( 995_472a ) відповідно до пункту 13 розділу I цього Порядку та встановлює, що графи A-G двох примірників блакитних відривних документів на транзит ("transit") заповнені власником книжки (карнета) A.T.A. (його представником) та асоціацією, що видає документи, правильно.

4.2. Заповнює графу H обох блакитних відривних документів на транзит ("transit") шляхом унесення:

до поля "a" назви митного органу, до якого товари повинні бути доставлені;

до поля "b" граничної дати у форматі рік/місяць/день доставки товарів у митний орган, зазначений у полі "a" цього документа;

до поля "c" реєстраційного номера книжки (карнета) A.T.A. ( 995_472a ), що формується відповідно до пункту 17 розділу I цього Порядку;

до поля "d" відомостей про митне забезпечення;

до поля "e" назви й адреси митного органу, у якому розпочалося транзитне переміщення товарів.

4.3. Заповнює верхню частину обох блакитних невідривних корінців документів на транзит книжки (карнета) A.T.A. ( 995_472a ) шляхом унесення:

до графи 1 порядкових номерів товарів, що переміщуються транзитом, відповідно до загального списку та додаткових аркушів до нього книжки (карнета) A.T.A., а також назви митного органу, до якого товари повинні бути доставлені;

до графи 2 граничної дати у форматі рік/місяць/день доставки товарів у митний орган, зазначений у графі 1 цього корінця;

до графи 3 реєстраційного номера книжки (карнета) A.T.A., наведеного в полі "c" графи H документа на транзит ("transit");

до графи 4 назви митного органу, де розпочинається транзитне переміщення товарів;

до графи 5 місця розташування митного органу, де розпочинається транзитне переміщення товарів;

до графи 6 поточної дати у форматі рік/місяць/день, що вважатиметься датою початку транзитного переміщення товарів;

до графи 7 особистого підпису та відбитка особистої номерної печатки.

4.4. Вилучає з книжки (карнета) A.T.A. ( 995_472a ) перший блакитний відривний документ на транзит ("transit") та відповідні додаткові аркуші до нього (за наявності).

4.5. Заносить за допомогою засобів програмного забезпечення до ЄАІС і журналу обліку книжок (карнетів) A.T.A. ( 995_472a ):

результати дій, учинених відповідно до пунктів 4.2 і 4.3 цього розділу;

відомості з першої сторінки обкладинки книжки (карнета) A.T.A.;

стислий опис товарів, що переміщуються транзитом, їх кількість і вартість відповідно до загального списку, розташованого на звороті блакитного аркуша документа на транзит та додаткових аркушів до нього.

4.6. Знімає копії першої сторінки обкладинки книжки (карнета) A.T.A. ( 995_472a ), загального списку та додаткових аркушів до нього (за наявності).

4.7. Повертає власнику чи його представникові оформлену митним органом книжку (карнет) A.T.A. ( 995_472a ).

5. Уповноважена посадова особа митного органу, розташованого в пункті пропуску через державний кордон України, у якому завершується транзитне переміщення через митну територію України товарів з використанням книжки (карнета) A.T.A. ( 995_472a ), учиняє такі дії:

5.1. Заповнює графу H блакитного відривного документа на транзит шляхом унесення до поля "g" назви митного органу, у якому закінчилося транзитне переміщення товарів, поточної дати у форматі рік/місяць/день, особистого підпису та відбитка особистої номерної печатки.

5.2. Заповнює нижню частину обох блакитних невідривних корінців документа на транзит шляхом унесення до граф 3, 4, 5 і 6 відповідно назви митного органу, у якому закінчилося транзитне переміщення товарів, місця розташування цього митного органу, поточної дати у форматі рік/місяць/день, що вважатиметься датою закінчення транзитного переміщення товарів, особистого підпису та відбитка особистої номерної печатки.

5.3. Уносить за допомогою засобів програмного забезпечення результати дій, учинених відповідно до пунктів 5.1 і 5.2 цього розділу, до ЄАІС.

5.4. Вилучає з книжки (карнета) A.T.A. ( 995_472a ) другий блакитний відривний документ на транзит ("transit") і відповідні додаткові аркуші до нього (за наявності) і направляє їх завірені копії на адресу митного органу, зазначеного в полі "e" графи H цього документа.

Якщо транзитне переміщення товарів здійснюється в межах одного пункту пропуску через державний кордон України, то вповноважена посадова особа цього органу прикріплює вилучені з книжки (карнета) A.T.A. аркуші до перших примірників блакитних відривних документів на транзит ("transit") і додаткових аркушів до них (за наявності).

5.5. Повертає власнику або його представнику оформлену митним органом книжку (карнет) A.T.A. ( 995_472a ).

IX. Продовження строків тимчасового ввезення (вивезення) і транзиту товарів, що переміщуються через митний кордон України з використанням книжок (карнетів) A.T.A. ( 995_472a )

1. Строк тимчасового ввезення товарів, увезених на митну територію України з використанням книжки (карнета) A.T.A. ( 995_472a ), може бути продовжений Державною митною службою України на підставі письмового звернення власника книжки (карнета) A.T.A. (його представника) з обґрунтуванням причин необхідності продовження цього строку та акта про проведення митного огляду товарів установленої форми, складеного на прохання власника книжки (карнета) A.T.A. (його представника) посадовою особою митного органу, у зоні діяльності якого перебувають тимчасово ввезені товари.

Строк тимчасового вивезення товарів може бути продовжений в межах строку дії книжки (карнета) A.T.A. митним органом, на контролі якого перебувають тимчасово вивезені товари.

Питання продовження строку тимчасового ввезення або вивезення товарів на строк, що перевищує строк дії книжки (карнета) A.T.A., розглядається Держмитслужбою України на підставі наданої власником нової книжки (карнета) A.T.A.

2. Продовження строку доставки товарів до митного органу призначення здійснюється митними органами в установленому порядку.

3. Відомості про продовження строків тимчасового ввезення, вивезення або доставки товарів уносяться до ЄАІС.

X. Прикінцеві положення

1. Уся кореспонденція, передбачена цим Порядком, повинна направлятися засобами поштового зв'язку з повідомленням про вручення поштового відправлення.

Оригінальні аркуші книжок (карнетів) A.T.A. ( 995_472a ), завірені копії яких направлено засобами поштового зв'язку, зберігаються у відправника.

2. Координація обігу книжок (карнетів) A.T.A. ( 995_472a ) в Україні, інформаційний обмін і взаємодопомога здійснюються відповідно до Угоди про співробітництво, укладеної між Держмитслужбою України та ТПП України 22 лютого 2007 року в м. Києві.

Копії претензій і листів, надісланих на адресу ТПП України відповідно до положень Стамбульської конвенції ( 995_472 ), направляються митними органами в Державну митну службу України.
