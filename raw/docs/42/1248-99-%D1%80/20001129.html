Кабінет Міністрів України; Розпорядження від 16.11.1999 № 1248-р

Про призначення Акціонерно-комерційного банку соціального розвитку уповноваженою особою з управління пакетом акцій ВАТ "Кримський содовий завод"

Стан: Втратив чинність

Ідентифікатор: 1248-99-р

Текст документа від 29.11.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 листопада 1999 р. N 1248-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 473-р ( 473-2000-р ) від 29.11.2000 )

1. Призначити Акціонерно-комерційний банк соціального розвитку уповноваженою особою з управління пакетом акцій ВАТ "Кримський содовий завод" у розмірі 50 відсотків статутного фонду плюс одна акція, що належать державі.

Національному агентству з управління державними корпоративними правами розробити та затвердити умови передачі та завдання з управління державними корпоративними правами ВАТ "Кримський содовий завод".

У зв'язку з цим виключити з додатка 5 до постанови Кабінету Міністрів України від 3 червня 1999 р. N 951 ( 951-99-п ) "Про передачу повноважень з управління державними корпоративними правами Раді міністрів Автономної Республіки Крим, міністерствам, іншим центральним і місцевим органам виконавчої влади" (Офіційний вісник України, 1999 р., N 23, ст. 1053) з доповненнями, внесеними постановою Кабінету Міністрів України від 22 жовтня 1999 р. N 1990 ( 1990-99-п ), позицію:

"5444546 ВАТ "Кримський содовий завод".

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 19 травня 1999 р. N 433 ( 433-99-р ) в частині дострокового продажу акцій ВАТ "Кримський содовий завод" та внесення змін до плану розміщення акцій цього товариства.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
