Про затвердження Правил з питань процедур експлуатаційної сертифікації та інспектування експлуатантів

{ Із змінами, внесеними згідно з Наказом Міністерства транспорту N 204 ( z0552-98 ) від 29.05.98 }

З метою забезпечення безпеки, регулярності та ефективності повітряних перевезень і авіаційних робіт згідно з Повітряним кодексом Укораїни ( 3167-12 ) та Указом Президента України "Про зміни в системі центральних органів виконавчої влади України" від 26 липня 1996 року N 596/96 НАКАЗУЮ:

1. Затвердити Правила з питань процедур експлуатаційної сертифікації та інспектування експлуатантів (додаються).

2. З введенням в дію Правил з питань процедур експлуатаційної сертифікації та інспектування експлуатантів скасувати наказ Державного департаменту авіаційного транспорту України від 17.04.96 N 109.

3. Державному департаменту авіаційного транспорту України (Марченку М.О.):

- у встановленому порядку зареєструвати зазначені Правила в Міністерстві юстиції України;

- довести до експлуатантів інформацію стосовно цих Правил.

5. Контролть за виконанням цього наказу покласти на Голову Державного департаменту авіаційного транспорту України Марченко М.О.

Міністр І.П.Данькевич
