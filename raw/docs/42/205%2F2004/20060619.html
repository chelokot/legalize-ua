УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 470/2006 ( 470/2006 ) від 02.06.2006 }

Про внесення зміни до статті 3 Указу Президента України від 7 лютого 2003 року N 91

Внести зміну до статті 3 Указу Президента України від 7 лютого 2003 року N 91 ( 91/2003 ) "Про заходи щодо поліпшення забезпечення населення лікарськими засобами і виробами медичного призначення, а також підвищення ефективності державного управління у цій сфері", виклавши її в такій редакції:

"3. Установити, що Державну службу лікарських засобів і виробів медичного призначення очолює заступник Міністра охорони здоров'я України, який за посадою є Головним державним інспектором України з контролю якості лікарських засобів".

Президент України Л.КУЧМА

м. Київ, 18 лютого 2004 року N 205/2004
