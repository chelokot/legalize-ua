Питання управління Міністерством інфраструктури об'єктами державної власності

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 355-р ( 355-2011-р ) від 13.04.2011 N 901-р ( 901-2011-р ) від 14.09.2011 }

1. Затвердити переліки:

підприємств, установ та організацій, що належать до сфери управління Міністерства інфраструктури, згідно з додатком 1;

відкритих акціонерних товариств, функції з управління корпоративними правами щодо яких здійснює Міністерство інфраструктури, згідно з додатком 2;

державних підприємств, установ та організацій, що передаються до сфери управління Міністерства інфраструктури, згідно з додатком 3.

2. Міністерству інфраструктури забезпечити здійснення функцій з управління майном, закріпленим за Державною спеціальною службою транспорту.
