Кабінет Міністрів України; Постанова від 25.08.1998 № 1332

Про доповнення переліку територій, на яких у порядку експерименту застосовується спеціальний торговий патент

Стан: Втратив чинність

Ідентифікатор: 1332-98-п

Текст документа від 01.10.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 серпня 1998 р. N 1332 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1439 ( 1439-2003-п ) від 10.09.2003 )

Про доповнення переліку територій, на яких у порядку експерименту застосовується спеціальний торговий патент

Кабінет Міністрів України постановляє:

Доповнити перелік територій, на яких у порядку експерименту застосовується спеціальний торговий патент, затверджений постановою Кабінету Міністрів України від 8 червня 1998 р. N 826 ( 826-98-п ) (Офіційний вісник України, 1998 р., N 23, ст. 833, N 25, ст. 928, N 26, ст. 955), абзацами такого змісту:

"м. Алушта

м. Судак

м. Євпаторія

м. Феодосія

м. Саки".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
