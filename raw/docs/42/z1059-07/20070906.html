МІНІСТЕРСТВО ЕКОНОМІКИ УКРАЇНИ

НАКАЗ

06.09.2007 N 294

Зареєстровано в Міністерстві юстиції України 11 вересня 2007 р. за N 1059/14326

Про визнання таким, що втратив чинність, наказу Міністерства економіки та з питань європейської інтеграції України від 05.04.2005 N 90

Відповідно до рішення Міжвідомчої комісії з міжнародної торгівлі від 31.01.2006 N СП-126/2006/144-33 ( v-126324-06 ) "Про скасування рішення Міжвідомчої комісії з міжнародної торгівлі від 28.01.2005 N СП-108/2005/52-103 "Про застосування спеціальних заходів щодо імпорту в Україну відливок із сірого та надміцного чавуну для виготовлення гідростатичної трансмісії ГСТ-90 незалежно від країни походження та експорту" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства економіки та з питань європейської інтеграції України від 05.04.2005 N 90 ( z0399-05 ) "Про застосування спеціальних заходів щодо імпорту в Україну відливок із сірого та надміцного чавуну для виготовлення гідростатичної трансмісії ГСТ-90 незалежно від країни походження та експорту", зареєстрований у Міністерстві юстиції України 14.04.2005 за N 399/10679.

2. Контроль за виконанням цього наказу покласти на заступника Міністра економіки України Бойцун Н.Є.

Міністр економіки України А.Кінах
