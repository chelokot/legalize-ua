КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 вересня 2008 р. N 803 Київ

Про внесення зміни до порядків, затверджених постановами Кабінету Міністрів України від 14 лютого 2001 р. N 150 та від 14 листопада 2007 р. N 1324

{ Із змінами, внесеними згідно з Постановою КМ N 306 ( 306-2012-п ) від 29.02.2012 }

Кабінет Міністрів України постановляє:

1. У пункті 1-1 Порядку видачі органами державного пожежного нагляду дозволу на початок роботи підприємств та оренду приміщень, затвердженого постановою Кабінету Міністрів України від 14 лютого 2001 р. N 150 ( 150-2001-п ) (Офіційний вісник України, 2001 р., N 7, ст. 285; 2003 р., N 23, ст. 1080; 2006 р., N 1-2, ст. 43; 2007 р., N 52, ст. 2097), літери і цифри "ОНТП 24-86" замінити літерами і цифрами "НАПБ Б.03.002-2007".

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 306 ( 306-2012-п ) від 29.02.2012 }

2. Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи привести у тримісячний строк власні рішення у відповідність з цією постановою.
