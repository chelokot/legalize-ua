Кабінет Міністрів України; Розпорядження від 23.09.2009 № 1231-р

Про заходи щодо повернення у державну власність військового майна

Стан: Чинний

Ідентифікатор: 1231-2009-р

Текст документа від 13.01.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 вересня 2009 р. N 1231-р Київ

Про заходи щодо повернення у державну власність військового майна

{ Із змінами, внесеними згідно з Розпорядженням КМ N 15-р ( 15-2010-р ) від 13.01.2010 }

1. Мін'юсту, Міноборони, Фонду державного майна разом з Генеральною прокуратурою України вжити передбачених законодавством заходів до повернення у державну власність колишніх військових містечок N 7 (м. Дніпропетровськ), N 25, 183 і 226 (м. Харків), які були відчужені Міноборони, для подальшої передачі їх до сфери управління ДСА з метою розміщення судів загальної юрисдикції без права відчуження або передачі зазначеного майна іншим суб'єктам. { Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 15-р ( 15-2010-р ) від 13.01.2010 }

2. Міноборони разом з Головдержслужбою провести службове розслідування щодо посадових осіб, причетних до відчуження зазначених у пункті 1 цього розпорядження військових містечок, та поінформувати в місячний строк про його результати Кабінет Міністрів України.

3. МВС провести перевірку дотримання вимог законодавства під час відчуження зазначених у пункті 1 цього розпорядження військових містечок, вжити за її результатами передбачених законодавством заходів та поінформувати Кабінет Міністрів України.

Прем'єр-міністр України Ю.ТИМОШЕНКО
