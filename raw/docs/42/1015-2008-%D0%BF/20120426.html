Текст документа від 26.04.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 листопада 2008 р. N 1015 Київ

Про внесення змін до постанов Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 та від 29 листопада 2006 р. N 1652

{ Додатково див. Постанову Окружного адміністративного суду міста Києва N 2а-3972/09/2670 ( v3972805-10 ) від 25.02.2010 }

{ Із змінами, внесеними згідно з Постановою КМ N 321 ( 321-2012-п ) від 05.04.2012 }

Кабінет Міністрів України постановляє:

1. Доповнити підпункт 2 пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752, N 44, ст. 2946, N 51, ст. 3406; 2007 р., N 37, ст. 1482, N 43, ст. 1715, N 53, ст. 2157, N 56, ст. 2252, N 59, ст. 2344, ст. 2351, N 91, ст. 3336; 2008 р., N 9, ст. 220, N 63, ст. 2146, N 70, ст. 2355, N 81, ст. 2737) абзацом такого змісту:

"протезно-ортопедичних виробів, ортопедичного взуття, технічних засобів реабілітації інвалідів та інших осіб;".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 321 ( 321-2012-п ) від 05.04.2012 }

3. Ця постанова набирає чинності з 1 січня 2009 року.
