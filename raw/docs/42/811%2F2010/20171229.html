Питання мережі господарських судів України

{ Із змінами, внесеними згідно з Указом Президента N 868/2014 ( 868/2014 ) від 12.11.2014 }

Відповідно до пункту 23 частини першої статті 106 Конституції України ( 254к/96-ВР ), статті 19 Закону України "Про судоустрій і статус суддів" ( 2453-17 ) постановляю:

1. Ліквідувати:

Житомирський апеляційний господарський суд;

Запорізький апеляційний господарський суд;

Київський міжобласний апеляційний господарський суд;

Луганський апеляційний господарський суд.

2. Утворити Рівненський апеляційний господарський суд.

3. Визначити територіальну юрисдикцію апеляційних господарських судів згідно з додатком N 1.

4. Затвердити мережу господарських судів України (додаток N 2).

5. Визнати такими, що втратили чинність:

Указ Президента України від 11 липня 2001 року N 511 ( 511/2001 ) "Про утворення апеляційних господарських судів та затвердження мережі господарських судів України";

Указ Президента України від 30 травня 2002 року N 499 ( 499/2002 ) "Про утворення Житомирського та Запорізького апеляційних господарських судів та внесення змін до мережі та кількісного складу суддів господарських судів України";

Указ Президента України від 25 червня 2003 року N 552 ( 552/2003 ) "Про утворення Київського міжобласного і Луганського апеляційних господарських судів";

Указ Президента України від 23 січня 2004 року N 91 ( 91/2004 ) "Про збільшення кількісного складу суддів Вищого господарського суду України";

Указ Президента України від 9 червня 2004 року N 633 ( 633/2004 ) "Про збільшення кількісного складу суддів місцевих господарських судів";

Указ Президента України від 11 липня 2007 року N 633 ( 633/2007 ) "Про кількісний склад суддів місцевих та апеляційних господарських судів";

Указ Президента України від 25 грудня 2009 року N 1104 ( 1104/2009 ) "Про кількісний склад суддів Вищого господарського суду України та апеляційних господарських судів";

Указ Президента України від 16 лютого 2010 року N 178 ( 178/2010 ) "Про кількісний склад суддів місцевих господарських судів".

6. Кабінету Міністрів України передбачити під час підготовки проекту Закону про Державний бюджет України на 2011 рік видатки на фінансування витрат, пов'язаних з утворенням Рівненського апеляційного господарського суду.

7. Голові Рівненської обласної державної адміністрації вжити невідкладних заходів щодо забезпечення Рівненського апеляційного господарського суду службовим приміщенням.

8. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 12 серпня 2010 року N 811/2010
