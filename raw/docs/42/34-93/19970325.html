Кабінет Міністрів України; Декрет від 09.04.1993 № 34-93

Про ставки податку з власників транспортних засобів та інших самохідних машин і механізмів

Стан: Втратив чинність

Ідентифікатор: 34-93

Текст документа від 25.03.1997:

ДЕКРЕТ КАБІНЕТУ МІНІСТРІВ УКРАЇНИ

( Декрет втратив чинність на підставі Закону N 75/97-ВР від 18.02.97, ВВР, 1997, N 15, ст.117 )

Про ставки податку з власників транспортних засобів та інших самохідних машин і механізмів

( Відомості Верховної Ради України (ВВР), 1993, N 23, ст.251 )

( Додатково див. Закон N 126/95-ВР від 06.04.95, ВВР, 1995, N 16, ст.111 )

( Із змінами, внесеними згідно із Законом N 297/95-ВР від 11.07.95, ВВР, 1995, N 30, ст.229 )

( Додатково див. Закон N 96/96-ВР від 22.03.96, ВВР, 1996, N 16, ст. 71 )

Кабінет Міністрів України постановляє:

1. Установити, що податок з власників транспортних засобів та інших самохідних машин і механізмів сплачується в таких розмірах:

( Про сплату податку з власників транспортних засобів та інших самохідних машин і механізмів на 1995 рік додатково див. ст.18 Закону N 126/95-ВР від 06.04.95; на 1996 рік додатково див. ст.22 Закону N 96/96-ВР від 22.03.96 )

----------------------------------------------------------------

Найменування об'єктів оподаткування : Ставки податку на : рік (у частинах : неоподатковуваного : мінімуму доходів : громадян)

-----------------------------------------------------------------

Автомобілі легкові залежно від потужності двигуна: з кожної кінської сили 0,01 або з кожного кіловата потужності 0,015

Автомобілі вантажні вантажопідйомністю до 7 тонн залежно від потужності двигуна: з кожної кінської сили 0,015 або з кожного кіловата потужності 0,02

Автомобілі вантажні вантажопідйомністю більше 7 тонн та інші самохідні машини і механізми, автобуси залежно від потужності двигуна: з кожної кінської сили 0,02 або з кожного кіловата потужності 0,03

Мотоцикли, моторолери та мотоблоки залежно від потужності двигуна: з кожної кінської сили 0,005 або з кожного кіловата потужності 0,01

( Стаття 1 із змінами, внесеними згідно із Законом N 297/95-ВР від 11.07.95 )

2. Платники податку з власників транспортних засобів та інших самохідних машин і механізмів, які до набуття чинності цим Декретом провели в поточному році технічний огляд згідно з графіком технічного огляду зазначених об'єктів оподаткування і в зв'язку з цим сплатили цей податок, не провадять його перерахунок за встановленими цим Декретом ставками.

3. Зупинити дію частини першої статті 2 Закону України "Про податок з власників транспортних засобів та інших самохідних машин і механізмів" ( 1963-12 ) (Відомості Верховної Ради України, 1992 р., N 11, ст.150).

4. Цей Декрет набуває чинності з дня опублікування.
