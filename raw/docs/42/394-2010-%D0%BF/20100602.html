Текст документа від 02.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 червня 2010 р. N 394 Київ

Про визнання такими, що втратили чинність, постанов Кабінету Міністрів України від 29 серпня 2002 р. N 1274 і від 25 травня 2006 р. N 750

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 29 серпня 2002 р. N 1274 ( 1274-2002-п ) "Про затвердження Порядку пропуску яхт через державний кордон" (Офіційний вісник України, 2002 р., N 36, ст. 1687);

постанову Кабінету Міністрів України від 25 травня 2006 р. N 750 ( 750-2006-п ) "Про внесення змін до Порядку пропуску яхт через державний кордон" (Офіційний вісник України, 2006 р., N 22, ст. 1631).
