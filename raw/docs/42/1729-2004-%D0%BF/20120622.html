КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 грудня 2004 р. N 1729 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 533 ( 533-2012-п ) від 13.06.2012 }

Про внесення змін до Положення про кримінальну міліцію у справах неповнолітніх

Кабінет Міністрів України постановляє:

Внести до Положення про кримінальну міліцію у справах неповнолітніх, затвердженого постановою Кабінету Міністрів України від 8 липня 1995 р. N 502 ( 502-95-п ) "Про створення кримінальної міліції у справах неповнолітніх" (ЗП України, 1995 р., N 9, ст. 237; Офіційний вісник України, 2003 р., N 40, ст. 2111; 2004 р., N 4, ст. 171, N 22, ст. 1503), такі зміни:

абзац третій пункту 1 виключити;

у пункті 7 слова "а приймальників-розподільників для неповнолітніх - Урядом Автономної Республіки Крим, обласними, Київською та Севастопольською державними адміністраціями" виключити.
