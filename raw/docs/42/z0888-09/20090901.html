ГОЛОВНЕ УПРАВЛІННЯ ДЕРЖАВНОЇ СЛУЖБИ УКРАЇНИ

НАКАЗ

01.09.2009 N 235

Зареєстровано в Міністерстві юстиції України 21 вересня 2009 р. за N 888/16904

Про внесення змін до наказу Головдержслужби від 18.05.2000 N 25 "Про затвердження Положення про порядок проведення Головдержслужбою перевірок"

Відповідно до Закону України "Про засади запобігання та протидії корупції" ( 1506-17 ) та з метою приведення нормативно-правових актів Головдержслужби у відповідність до законодавства України НАКАЗУЮ:

1. Унести до наказу Головдержслужби від 18.05.2000 N 25 ( z0318-00 ) "Про затвердження Положення про порядок проведення Головдержслужбою перевірок", зареєстрованого в Міністерстві юстиції України 29.05.2000 за N 318/4539 (із змінами), такі зміни:

у преамбулі наказу слова "Про боротьбу з корупцією" замінити словами "Про засади запобігання та протидії корупції" ( 1506-17 ).

2. Затвердити Зміни до Положення про порядок проведення Головдержслужбою перевірок ( z0318-00 ), затвердженого наказом Головдержслужби від 18.05.2000, зареєстрованого в Міністерстві юстиції України 29.05.2000 за N 318/4539, що додаються.

3. Контрольно-інспекційному управлінню забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Управлінню організаційної роботи, документообігу та контролю ознайомити з цим наказом першого заступника Начальника Головдержслужби України, заступників Начальника Головдержслужби України, директора Центру адаптації державної служби до стандартів Європейського Союзу, директора Школи вищого корпусу державної служби, керівників структурних підрозділів та територіальних органів Головдержслужби України.

5. Контроль за виконанням цього наказу покласти на першого заступника Начальника Головдержслужби Ткача В.Д.

6. Цей наказ набирає чинності з 1 січня 2010 року.

Начальник Головдержслужби Т.Мотренко

ЗМІНИ до Положення про порядок проведення Головдержслужбою перевірок ( z0318-00 )

1. У тексті Положення ( z0318-00 ) слова "Про боротьбу з корупцією" замінити словами "Про засади запобігання та протидії корупції" ( 1506-17 ).

2. У розділі 1:

2.1 у пункті 1.1:

слова та цифри "Указу Президента України від 02.10.99 N 1272 ( 1272/99 ) "Про Положення про Головне управління державної служби України" замінити словами та цифрами "від 26.09.2007 N 1180 ( 1180-2007-п ) "Про затвердження Положення про Головне управління державної служби України".

2.2 у пункті 1.2:

слова "Указом Президента України від 02.10.99 N 1272 ( 1272/99 ) "Про Положення про Головне управління державної служби України," виключити;

слово "постанови" замінити словом "постановами";

після слів "Про утворення управлінь державної служби Головного управління державної служби в Автономній Республіці Крим, областях, мм. Києві та Севастополі," доповнити словами та цифрами "від 26.09.2007 N 1180 ( 1180-2007-п ) "Про затвердження Положення про Головне управління державної служби України".

3. В абзаці третьому пункту 3.1 розділу 3 слова "боротьби з корупцією і запобігання її проявам" замінити словами "запобігання та протидії корупції".

4. У підпункті 4.5.4 пункту 4.5 розділу 4 слова "органи, які ведуть боротьбу з корупцією" замінити словами "спеціально уповноважені суб'єкти у сфері протидії корупції".

5. У розділі 5:

у пункті 5.2 слова "боротьби з корупцією і запобігання її проявам" замінити словами "запобігання та протидії корупції";

у пункті 5.7 слово "Адміністрації" замінити словом "Секретаріату".
