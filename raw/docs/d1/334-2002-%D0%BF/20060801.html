КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 березня 2002 р. N 334 Київ

Про внесення змін до деяких постанов Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

Кабінет Міністрів України постановляє:

1. Доповнити розділ "I. Щомісячні" додаткових видів грошового забезпечення військовослужбовців, затверджених постановою Кабінету Міністрів України від 6 квітня 1998 р. N 452 ( 452-98-п ) "Про упорядкування додаткових видів грошового забезпечення військовослужбовців" (Офіційний вісник України, 1998 р., N 14, ст. 537; 1999 р., N 29, ст. 1489, N 42, ст. 2097; 2000 р., N 30, ст. 1278, N 51, ст. 2210; 2001 р., N 9, ст. 360, N 42, ст. 1886), підрозділом такого змісту:

"Надбавка за почесні від посадового військовослужбовцям, звання України, СРСР, окладу які мають почесні союзних республік СРСР звання:

40 відсотків "народний"

20 відсотків "заслужений".

2. Доповнити позицію "Надбавка до посадового окладу за" переліку підвищень, надбавок і доплат до посадових окладів осіб рядового і начальницького складу за умови проходження служби в кримінально-виконавчій системі, затвердженого постановою Кабінету Міністрів України від 18 серпня 1999 р. N 1510 ( 1510-99-п ) "Про умови грошового забезпечення осіб рядового і начальницького складу та оплати праці працівників кримінально-виконавчої системи" (Офіційний вісник України, 1999 р., N 33, ст. 1736; 2000 р., N 30, ст. 1278), підпозицією такого змісту:

"почесні звання особи рядового і начальницького складу, які мають почесні звання:

40 "народний"

20 "заслужений".

3. Установити особам рядового і начальницького складу органів внутрішніх справ надбавку до посадового окладу за почесні звання у такому розмірі: "народний" - 40 відсотків, "заслужений" - 20 відсотків.

4. Надбавка за почесні звання "народний" і "заслужений" виплачується військовослужбовцям, особам рядового і начальницького складу органів внутрішніх справ та Державної кримінально-виконавчої служби у разі, якщо виконання ними службових обов'язків згідно з посадами збігається за профілем з наявним почесним званням.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

5. Ця постанова набирає чинності з 1 січня 2003 року.
