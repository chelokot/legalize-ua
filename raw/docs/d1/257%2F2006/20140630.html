УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 504/2014 ( 504/2014 ) від 06.06.2014 }

Про внесення зміни до Указу Президента України від 27 грудня 2005 року N 1863

Внести зміну до підпункту 4 пункту 2 Плану заходів щодо забезпечення енергетичної безпеки України, затвердженого Указом Президента України від 27 грудня 2005 року N 1863 ( 1863/2005 ) "Про рішення Ради національної безпеки і оборони України від 9 грудня 2005 року "Про стан енергетичної безпеки України та основні засади державної політики у сфері її забезпечення", замінивши слова "побутових роторних лічильників сучасними засобами вимірювання" словами "застарілих побутових лічильників газу, що вилучені з Державного реєстру засобів вимірювальної техніки, сучасними засобами вимірювання".

Президент України В.ЮЩЕНКО

м. Київ, 24 березня 2006 року N 257/2006
