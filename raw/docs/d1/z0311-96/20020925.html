Стан: Втратив чинність

Текст документа від 25.09.2002:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ПО СТАНДАРТИЗАЦІЇ, МЕТРОЛОГІЇ ТА СЕРТИФІКАЦІЇ

НАКАЗ

N 235 від 11.06.96 Зареєстровано в Міністерстві м.Київ юстиції України 19 червня 1996 р. за N 311/1336

{ Наказ втратив чинність на підставі Наказу Державного комітету стандартизації, метрології та сертифікації N 498 ( z0782-02 ) від 30.08.2002 }

Про внесення змін до наказу Держстандарту України від 19.05.95 N 161 "Про внесення доповнень до Переліку продукції, що підлягає обов'язковій сертифікації в Україні"

Згідно з Декретом Кабінету Міністрів України від 10 травня 1993 року N 46-93 "Про стандартизацію і сертифікацію" на врахування пропозиції Держкоммістобудування України щодо перенесення строку введення сертифікації будматеріалів (лист від 12.05.96 р. N 6/5-102) НАКАЗУЮ:

1. У пункті 2 наказу Держстандарту України від 19.05.95 N 161 ( z0170-95 ) слова та цифри "з 1 липня 1996 року" замінити словами та цифрами "з 1 липня 1997 року".

2. Держстандарту України та Держкоммістобудування України довести вищезазначену зміну до відома міністерств, інших центральних органів державної виконавчої влади, установ та організацій.
