31.03.2007 N 95

Зареєстровано в Міністерстві юстиції України 10 квітня 2007 р. за N 323/13590

{ Наказ втратив чинність на підставі Наказу Міністерства внутрішніх справ N 82 ( z0191-08 ) від 25.02.2008 }

Про внесення змін до наказу МВС України від 13.03.2006 N 239 "Про затвердження Правил відбору та прийому до вищих навчальних закладів Міністерства внутрішніх справ України"

Відповідно до вимог Закону України "Про вищу освіту" ( 2984-14 ) та Умов прийому до вищих навчальних закладів України, затверджених наказом Міністерства освіти і науки України від 05.02.2007 N 84 ( z0118-07 ) та зареєстрованих у Міністерстві юстиції України 13.02.2007 за N 118/13385, НАКАЗУЮ:

1. Унести до наказу МВС України від 13.03.2006 N 239 ( z0359-06 ) "Про затвердження Правил відбору та прийому до вищих навчальних закладів Міністерства внутрішніх справ України", зареєстрованого у Міністерстві юстиції України 30.03.2006 за N 359/12233 (далі - Правила), такі зміни:

1.1. У преамбулі наказу та пунктах 1.2, 1.11 Правил ( z0359-06 ) слова "затверджених наказом Міністерства освіти і науки України від 01.02.2006 N 71 ( z0111-06 ) та зареєстрованих у Міністерстві юстиції України 08.02.2006 за N 111/11985" замінити словами "затверджених наказом Міністерства освіти і науки України від 05.02.2007 N 84 ( z0118-07 ) та зареєстрованих у Міністерстві юстиції України 13.02.2007 за N 118/13385".

1.2. У пункті 2.1.11 Правил ( z0359-06 ) слова "Військового інституту внутрішніх військ МВС України" замінити словами "Академії внутрішніх військ МВС України".

2. Департаменту роботи з персоналом (Стоцька М.М.) у п'ятиденний строк після підписання наказу забезпечити його подання на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням наказу покласти на заступника Міністра Плеханова М.А.

4. Наказ надіслати за належністю.

Міністр В.П.Цушко
