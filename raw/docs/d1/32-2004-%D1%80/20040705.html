Про підписання Угоди між Кабінетом Міністрів України та Урядом Сирійської Арабської Республіки про міжнародні автомобільні перевезення пасажирів і вантажів

Стан: Чинний

Текст документа від 05.07.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 січня 2004 р. N 32-р Київ

Про підписання Угоди між Кабінетом Міністрів України та Урядом Сирійської Арабської Республіки про міжнародні автомобільні перевезення пасажирів і вантажів

( Із змінами, внесеними згідно з Розпорядженням КМ N 446-р ( 446-2004-р ) від 05.07.2004 )

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Сирійської Арабської Республіки про міжнародні автомобільні перевезення пасажирів і вантажів.

Уповноважити першого заступника Міністра транспорту - керівника апарату Корнієнка Володимира Володимировича підписати зазначену Угоду, дозволивши вносити в разі потреби до проекту Угоди зміни, що не мають принципового характеру. ( Абзац другий в редакції Розпорядження КМ N 446-р ( 446-2004-р ) від 05.07.2004 )
