ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 травня 2005 р. N 377

ПОРЯДОК виконання завдань черговими силами з охорони повітряного простору України та протиповітряного прикриття важливих державних та військових об’єктів у мирний час та в особливий період (крім періоду дії воєнного стану)

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 752 ( 752-2021-п ) від 21.07.2021 }

{ У тексті Порядку слова "літаки-перехоплювачі" в усіх відмінках замінено словами "літаки" у відповідному відмінку згідно з Постановою КМ N 752 ( 752-2021-п ) від 21.07.2021 }

1. Цей Порядок визначає завдання чергових сил з охорони повітряного простору України та протиповітряного прикриття важливих державних та військових об’єктів (далі - чергові сили), процедуру застосування ними зброї і бойової техніки у мирний час та в особливий період (крім періоду дії воєнного стану).

{ Пункт 1 в редакції Постанови КМ N 752 ( 752-2021-п ) від 21.07.2021 }

2. Під час бойового чергування з охорони повітряного простору України та протиповітряного прикриття важливих державних та військових об’єктів чергові сили забезпечують: { Абзац перший пункту 2 в редакції Постанови КМ N 752 ( 752-2021-п ) від 21.07.2021 }

ведення розвідки повітряного простору з метою виявлення загроз порушення повітряними суднами в межах чергового радіолокаційного поля державного кордону України, перетинання лінії розмежування та/або адміністративної межі з тимчасово окупованими територіями і порядку використання повітряного простору України такими суднами; { Абзац другий пункту 2 в редакції Постанови КМ N 752 ( 752-2021-п ) від 21.07.2021 }

відбиття ударів засобів повітряного нападу по важливих державних об'єктах, безпосереднє прикриття яких здійснюється черговими силами;

здійснення у взаємодії з відповідними органами управління повітряним рухом контролю за дотриманням порядку використання повітряного простору України та подання допомоги повітряним суднам, що зазнають чи зазнали лиха;

припинення порушення повітряними суднами збройних формувань інших держав державного кордону України, порушень, пов’язаних з перетинанням лінії розмежування та/або адміністративної межі з тимчасово окупованими територіями такими суднами; { Абзац п'ятий пункту 2 в редакції Постанови КМ N 752 ( 752-2021-п ) від 21.07.2021 }

припинення протиправних дій повітряних суден, якщо вони використовуються з метою здійснення терористичного акту в повітряному просторі України, у тому числі в районі проведення антитерористичної операції, в районі здійснення заходів із забезпечення національної безпеки і оборони, відсічі і стримування збройної агресії. { Абзац шостий пункту 2 в редакції Постанов КМ N 1012 ( 1012-2016-п ) від 28.12.2016, N 331 ( 331-2018-п ) від 11.04.2018; із змінами, внесеними згідно з Постановою КМ N 752 ( 752-2021-п ) від 21.07.2021 }

3. Чергові сили застосовують зброю без попередження для:

відбиття ударів засобів повітряного нападу по важливих державних об'єктах, безпосереднє прикриття яких здійснюється черговими силами;

знищення повітряних суден збройних формувань інших держав, які порушили державний кордон України та/або перетнули лінію розмежування та/або адміністративну межу з тимчасово окупованими територіями і застосовують зброю та/або проводять десантування особового складу, бойової техніки, зокрема знищення безпілотних повітряних суден, які порушили державний кордон України, перетнули лінію розмежування та/або адміністративну межу з тимчасово окупованими територіями або застосовуються в повітряному просторі України з метою здійснення терористичного акту, ведення розвідки, створення перешкод, забезпечення зв’язку; { Абзац третій пункту 3 в редакції Постанов КМ N 1012 ( 1012-2016-п ) від 28.12.2016, N 331 ( 331-2018-п ) від 11.04.2018, N 752 ( 752-2021-п ) від 21.07.2021 }

припинення польоту безпілотних повітряних суден, які здійснюють політ над об’єктами у визначених та опублікованих у документах аеронавігаційної інформації України (офіційних веб-порталах) межах (зонах), політ у яких для безпілотних повітряних суден заборонений, а також над територіями важливих державних та військових об’єктів України, військових частин (підрозділів) Збройних Сил та інших складових сектору безпеки і оборони, територію навколо яких позначено відповідними інформаційними знаками про заборону польотів безпілотних повітряних суден. { Пункт 3 доповнено абзацом згідно з Постановою КМ N 752 ( 752-2021-п ) від 21.07.2021 }

4. Чергові сили застосовують зброю і бойову техніку після попереджувального вогню з гарматного озброєння чергових літаків (вертольотів) для:

припинення порушення повітряними суднами збройних формувань інших держав, які не виконують команд (сигналів) чергових літаків (вертольотів), державного кордону України, порушень, пов’язаних з перетинанням лінії розмежування та/або адміністративної межі з тимчасово окупованими територіями такими суднами; { Абзац другий пункту 4 в редакції Постанови КМ N 752 ( 752-2021-п ) від 21.07.2021 }

припинення протиправних дій повітряних суден, крім цивільних повітряних суден із пасажирами на борту, якщо вони використовуються з метою здійснення терористичного акту в повітряному просторі України, у тому числі в районі проведення антитерористичної операції, в районі здійснення заходів із забезпечення національної безпеки і оборони, відсічі і стримування збройної агресії. { Абзац третій пункту 4 в редакції Постанови КМ N 331 ( 331-2018-п ) від 11.04.2018; із змінами, внесеними згідно з Постановою КМ N 752 ( 752-2021-п ) від 21.07.2021 }

{ Пункт 4 в редакції Постанови КМ N 1012 ( 1012-2016-п ) від 28.12.2016 }

5. З метою примушення до посадки захоплених (викрадених) повітряних суден черговим силам надається право відкривати попереджувальний вогонь з гарматного озброєння чергових літаків (вертольотів).

6. Право ухвалення рішення про застосування черговими літаками (вертольотами) зброї, зокрема попереджувального вогню по цілі, надається:

Міністру оборони, Головнокомандувачу Збройних Сил, командувачу Повітряних Сил Збройних Сил або особам, що виконують їх обов’язки;

Командувачу об’єднаних сил - у разі залучення чергових сил до здійснення заходів із забезпечення національної безпеки і оборони, відсічі і стримування збройної агресії;

командувачам об’єднаних сил Збройних Сил, операційного Командування Повітряних Сил Збройних Сил або особам, що виконують їх обов’язки, - у разі настання особливого періоду (після створення угруповань військ (сил) у визначених операційних зонах (районах);

керівнику оперативного штабу з управління антитерористичною операцією, який здійснює безпосереднє управління антитерористичною операцією, або особі, що виконує його обов’язки, - у разі залучення чергових сил до антитерористичної операції.

Для припинення польоту безпілотних повітряних суден, які здійснюють політ у межах (зонах), політ у яких для безпілотних повітряних суден заборонений, а також над територіями важливих державних та військових об’єктів України, військових частин (підрозділів) Збройних Сил та інших складових сектору безпеки і оборони, право на ухвалення рішення про застосування зброї надається особам, які здійснюють безпосереднє управління черговими силами зазначених об’єктів.

У разі коли чергові літаки (вертольоти) не можуть виконати визначені в рішенні про застосування зброї завдання щодо припинення порушень державного кордону України, перетину лінії розмежування та/або адміністративної межі з тимчасово окупованими територіями повітряними суднами збройних формувань інших держав та протиправних дій повітряних суден, якщо вони використовуються з метою здійснення терористичного акту, у повітряному просторі України, для їх знищення за рішенням зазначених в абзацах другому - п’ятому цього пункту посадових осіб застосовуються чергові сили.

Безпосередню команду про застосування зброї і бойової техніки подає особа, яка здійснює управління черговими силами.

{ Пункт 6 в редакції Постанови КМ N 752 ( 752-2021-п ) від 21.07.2021 }

7. Командирам екіпажів чергових літаків (вертольотів), кораблів (катерів), наземних засобів протиповітряної оборони надається право самостійно відкривати вогонь по повітряних суднах збройних формувань інших держав, які порушили державний кордон України, перетнули лінію розмежування та/або адміністративну межу з тимчасово окупованими територіями, та застосовувати зброю.

{ Пункт 7 в редакції Постанов КМ N 1012 ( 1012-2016-п ) від 28.12.2016, N 752 ( 752-2021-п ) від 21.07.2021 }

8. Черговим силам заборонено застосовувати зброю і бойову техніку щодо: { Абзац перший пункту 8 із змінами, внесеними згідно з Постановою КМ N 752 ( 752-2021-п ) від 21.07.2021 }

повітряних суден - порушників державного кордону, які виконують команди чергових сил або відповідних органів управління повітряним рухом щодо виведення їх за межі повітряного простору України та/або посадки на визначений аеродром; { Абзац другий пункту 8 в редакції Постанови КМ N 752 ( 752-2021-п ) від 21.07.2021 }

повітряних суден - порушників порядку використання повітряного простору України;

цивільних повітряних суден із пасажирами на борту. { Пункт 8 доповнено абзацом згідно з Постановою КМ N 752 ( 752-2021-п ) від 21.07.2021 }

9. Види зброї і бойової техніки чергових сил, правила їх утримання і застосування визначаються Міноборони.
