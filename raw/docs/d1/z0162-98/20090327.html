N 65 від 24.02.98 Зареєстровано в Міністерстві м.Київ юстиції України 11 березня 1998 р. vd980224 vn65 за N 162/2602

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про затвердження Положення про організацію торгівлі банківськими металами на валютному ринку України

{ Із змінами, внесеними згідно з Постановами Нацбанку N 133 ( z0280-99 ) від 23.03.99 N 47 ( z0276-01 ) від 07.02.2000 N 102 ( z0226-03 ) від 12.03.2003 N 325 ( z0749-03 ) від 06.08.2003 }

Розглянувши пропозиції Департаменту валютного регулювання про організацію торгівлі банківськими металами на валютному ринку України, Правління ПОСТАНОВЛЯЄ:

1. Затвердити Положення про організацію торгівлі банківськими металами на валютному ринку України (додається).

2. Департаменту валютного регулювання (С.О.Яременко) забезпечити контроль за дотриманням правил торгівлі банківськими металами на валютному ринку України.

3. Подати цю постанову на державну реєстрацію в Міністерство юстиції України в установленому порядку.

В.о.Голови В.С.Стельмах

( Положення про організацію торгівлі банківськими металами на валютному ринку України втратило чинність на підставі Постанови Національного банку N 325 ( z0749-03 ) від 06.08.2003 )
