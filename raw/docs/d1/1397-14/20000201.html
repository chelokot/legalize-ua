Верховна Рада України; Постанова від 21.01.2000 № 1397-XIV

Про утворення тимчасової Лічильної комісії Верховної Ради України

Стан: Втратив чинність

Ідентифікатор: 1397-14

Текст документа від 01.02.2000:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про утворення тимчасової Лічильної комісії Верховної Ради України

( Із змінами, внесеними згідно з Постановою ВР N 1407-XIV ( 1407-14 ) від 01.02.2000 )

З метою створення умов проведення засідання Верховної Ради України Верховна Рада України постановляє:

1. Утворити тимчасову Лічильну комісію Верховної Ради України у складі народних депутатів України:

АЛЬОХІН

Володимир Ілліч.

ГОРБАЧОВ

Віктор Сергійович.

ЗАЄЦЬ

Володимир Володимирович - голова комісії.

ІВАНОВ

Сергій Анатолійович.

КАФАРСЬКИЙ

Володимир Іванович - заступник голови комісії.

КОСТИНЮК

Богдан Іванович.

МАНЧУЛЕНКО

Георгій Манолійович.

ОСТАШ

Ігор Іванович - секретар комісії.

ПАВЛЕНКО

Сергій Григорович.

ПОДГОРНИЙ

Сергій Іванович.

ФУРДИЧКО

Орест Іванович.

2. Відповідно до частини першої статті 2.2.9. Регламенту Верховної Ради України ( 129а/94-ВР ) доручити тимчасовій Лічильній комісії Верховної Ради України проводити підрахунок голосів під час відкритого голосування на пленарних засіданнях Верховної Ради України, що проводяться у приміщенні Національного комплексу "Експоцентр України" ("Український дім").

( Пункт 2 із змінами, внесеними згідно з Постановою ВР N 1407-XIV ( 1407-14 ) від 01.02.2000 )

3. Ця Постанова набирає чинності з моменту її прийняття.

Заступник Голови Верховної Ради України В.МЕДВЕДЧУК
