Про зміну коефіцієнтів, що застосовуються до тарифів Прейскуранта N 10-01

Відповідно до постанови Кабінету Міністрів України від 25 грудня 1996 року N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських Рад щодо регулювання цін (тарифів)", постанови Кабінету Міністрів від 28 березня 1997 року N 280 ( 280-97-п ) "Про хід структурної перебудови вугільної промисловості" НАКАЗУЮ:

1. Затвердити коефіцієнти, що застосовуються до тарифів Прейскуранта N 10-01 "Тарифи на вантажні залізничні перевезення", затвердженого постановою Держкомцін СРСР від 31.01.89 N 328 (додаються).

2. Укрзалізниці (Слободяну А.В.) та начальникам залізниць забезпечити своєчасне доведення цього наказу до вантажовідправників, вантажоодержувачів та населення.

3. Управлінню тарифної та цінової політики (Осадча Т.М.) разом з Головним управлінням правового забезпечення діяльності транспорту (Логінова Л.М.) у встановленому порядку зареєструвати цей наказ у Міністерстві юстиції України.

4. З введенням в дію цього наказу втрачає чинність наказ Міністерства транспорту України від 31.10.96 N 345 ( z0648-96 ).

Контроль за виконанням наказу покласти на заступника генерального директора Укрзалізниці М.В.Макаренко.

В.о.Міністра Л.М.Костюченко

ПОГОДЖЕНО: Заступник Міністра економіки України В.М. Кальник

1. Ці коефіцієнти застосовуються на всіх лініях залізниць України.

2. Коефіцієнти застосовуються для обчислення платні за перевезення вантажів всіх видів відправлень. Коефіцієнти перевезення вантажів диференційовані залежно від роду вантажу та виду відправлення.

3. Умови та порядок виконання перевезення вантажів залізничним транспортом, а також відповідальність сторін при цьому визначаються чинним законодавством.

4. Коефіцієнти затверджені для обчислення вартості перевезення вантажів в національній валюті.

5. Платня за перевезення вантажів визначена без урахування податку на додану вартість.
