Про передачу навчально-оздоровчого комплексу Київського військового ліцею імені Івана Богуна до сфери управління Київської облдержадміністрації

Стан: Втратив чинність

Ідентифікатор: 142-2006-р

Текст документа від 04.07.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 березня 2006 р. N 142-р Київ

{ Розпорядження скасовано на підставі Розпорядження КМ N 378-р ( 378-2006-р ) від 04.07.2006 }

Про передачу навчально-оздоровчого комплексу Київського військового ліцею імені Івана Богуна до сфери управління Київської облдержадміністрації

Прийняти пропозицію Міноборони та Київської облдержадміністрації щодо передачі навчально-оздоровчого комплексу Київського військового ліцею імені Івана Богуна у м. Боярці (Київська область) до сфери управління Київської облдержадміністрації.

Прем'єр-міністр України Ю.ЄХАНУРОВ
