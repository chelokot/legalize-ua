Про відпуск матеріальних цінностей з мобілізаційного резерву

Стан: Чинний

Ідентифікатор: 1653-2009-р

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 грудня 2009 р. N 1653-р Київ

Про відпуск матеріальних цінностей з мобілізаційного резерву

{ Із змінами, внесеними згідно з Постановою КМ N 666 ( 666-2010-п ) від 28.07.2010 }

1. З метою оперативного закладення масок медичних марлевих (масок багаторазового використання марлевих) (далі - маски марлеві) до державного резерву Державному комітетові з державного матеріального резерву відпустити на безоплатній основі 6397 тис. погонних метрів марлі медичної, яка зберігається в мобілізаційному резерві на центральних складах і базах спецмедпостачання Міністерства охорони здоров'я, Державному департаменту з питань виконання покарань.

2. Державному департаменту з питань виконання покарань забезпечити виготовлення на підприємствах установ виконання покарань масок марлевих, які відповідають типовим технічним умовам ТУ У 18.2-31450352-001:2009, та поставити їх до державного резерву за ціною однієї маски, що закуповується до державного резерву, не більш як 0,79 гривні, що включає витрати на доставку.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

4. Державному комітетові з державного матеріального резерву здійснити закупівлю масок марлевих за рахунок невикористаних коштів, перерахованих Міністерством охорони здоров'я на закупівлю марлі відповідно до пункту 2 розпорядження Кабінету Міністрів України від 30 жовтня 2009 р. N 1295 ( 1295-2009-р ) "Про розбронювання матеріальних цінностей мобілізаційного резерву у зв'язку з проведенням заходів, спрямованих на запобігання поширенню грипу типу А/Н1N1/Каліфорнія/04/09 та гострих респіраторних захворювань" і пункту 2 розпорядження від 4 листопада 2009 р. N 1316 ( 1316-2009-р ) "Про розбронювання та відпуск матеріальних цінностей з мобілізаційного резерву".
