{ Із змінами, внесеними згідно з Постановами КМ N 646 ( 646-2007-п ) від 20.04.2007 N 207 ( 207-2008-п ) від 19.03.2008 }

Кабінет Міністрів України постановляє:

1. Внести до актів Кабінету Міністрів України зміни, що додаються.

2. Ця постанова набирає чинності з 1 січня 2007 року.

"час служби в Держспецзв'язку на посадах рядового і начальницького складу.".
