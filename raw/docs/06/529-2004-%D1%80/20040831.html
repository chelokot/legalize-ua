Про утворення комісії з питань здійснення заходів щодо реорганізації МНС

Стан: Чинний

Ідентифікатор: 529-2004-р

Текст документа від 31.08.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 липня 2004 р. N 529-р Київ

Про утворення комісії з питань здійснення заходів щодо реорганізації МНС

( Із змінами, внесеними згідно з Розпорядженням КМ N 630-р ( 630-2004-р ) від 31.08.2004 )

На виконання Указу Президента України від 6 липня 2004 р. N 755 ( 755/2004 ) "Про заходи щодо вдосконалення системи державного управління у сфері подолання наслідків Чорнобильської катастрофи" утворити комісію з питань здійснення заходів щодо реорганізації МНС та затвердити її головою першого заступника Міністра з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи у зв'язках з Верховною Радою України Косолапова А.Г.

Голові комісії:

затвердити, персональний склад комісії та забезпечити здійснення заходів, пов'язаних з реорганізацією МНС;

поінформувати у чотиримісячний строк Кабінет Міністрів України про завершення роботи з реорганізації МНС.

( Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 630-р ( 630-2004-р ) від 31.08.2004 )
