Президент України; Указ від 16.04.2010 № 545/2010

Про членів Ради Національного банку України

Стан: Чинний

Ідентифікатор: 545/2010

Текст документа від 20.12.2014:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про членів Ради Національного банку України

{ Із змінами, внесеними згідно з Указом Президента N 940/2014 ( 940/2014 ) від 18.12.2014 }

Відповідно до пункту 12 частини першої статті 106 Конституції України ( 254к/96-ВР ) та статті 10 Закону України "Про Національний банк України" ( 679-14 ) постановляю:

1. Призначити членами Ради Національного банку України:

АКІМОВУ - Першого заступника Глави Адміністрації Ірину Михайлівну Президента України

ГАЙДУЦЬКОГО - Радника Президента України

Павла Івановича

ФЕДОСОВА - завідувача кафедри фінансів

Віктора Миколайовича Київського національного економічного університету імені Вадима Гетьмана

ШПЕКА - Радника Президента України.

Романа Васильовича

{ Стаття 1 із змінами, внесеними згідно з Указом Президента N 940/2014 ( 940/2014 ) від 18.12.2014 }

2. Звільнити членів Ради Національного банку України: Даниленка А.І., Оніщука М.В., Поляченка В.А., Саблука П.Т., Федоренка А.В., Яценюка А.П.

3. Визнати такими, що втратили чинність, в частині, яка стосується осіб, зазначених у статті 2 цього Указу:

Указ Президента України від 28 лютого 2005 року N 384 ( 384/2005 ) "Про членів Ради Національного банку України";

Указ Президента України від 25 вересня 2006 року N 782 ( 782/2006 ) "Про внесення зміни до Указу Президента України від 28 лютого 2005 року N 384";

Указ Президента України від 16 травня 2008 року N 448 ( 448/2008 ) "Про внесення змін до Указу Президента України від 28 лютого 2005 року N 384".

4. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ
