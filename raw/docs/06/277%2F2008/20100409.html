Текст документа від 09.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 484/2010 ( 484/2010 ) від 02.04.2010 }

Про склад Комісії з опрацювання та комплексного вирішення питань реалізації державної політики у сфері раціонального використання та охорони земель

1. Затвердити персональний склад Комісії з опрацювання та комплексного вирішення питань реалізації державної політики у сфері раціонального використання та охорони земель (додається).

2. Визнати такими, що втратили чинність:

статті 3 і 4 Указу Президента України від 14 лютого 2006 року N 133 ( 133/2006 ) "Питання Комісії з опрацювання та комплексного вирішення питань реалізації державної політики у сфері раціонального використання та охорони земель";

Указ Президента України від 25 липня 2006 року N 637 ( 637/2006 ) "Про внесення змін до Указу Президента України від 14 лютого 2006 року N 133";

статтю 1 Указу Президента України від 27 серпня 2007 року N 793 ( 793/2007 ) "Про внесення змін до Указу Президента України від 14 лютого 2006 року N 133".

3. Цей Указ набирає чинності з дня його опублікування.
