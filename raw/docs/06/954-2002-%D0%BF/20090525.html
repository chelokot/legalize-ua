Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 липня 2002 р. N 954 Київ

Питання Фонду соціального захисту інвалідів

{ Із змінами, внесеними згідно з Постановами КМ N 954 ( 954-2008-п ) від 22.10.2008 N 464 ( 464-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє :

1. Реорганізувати Фонд соціального захисту інвалідів в урядовий орган державного управління у складі Міністерства праці та соціальної політики.

2. Установити, що утримання Фонду соціального захисту інвалідів у 2002 році здійснюється за рахунок видатків, які передбачаються в загальному фонді Державного бюджету України на 2002 рік ( 2905-14 ) за програмою "Керівництво та управління у сфері соціального захисту інвалідів".

3. Міністерству праці та соціальної політики:

у встановленому порядку здійснити заходи щодо реорганізації Фонду соціального захисту інвалідів;

подати у місячний термін проект постанови Кабінету Міністрів України про затвердження Положення про Фонд соціального захисту інвалідів.
