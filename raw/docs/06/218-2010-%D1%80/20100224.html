Питання надання громадянам квартир, що придбані Державною іпотечною установою

Стан: Чинний

Ідентифікатор: 218-2010-р

Текст документа від 24.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 лютого 2010 р. N 218-р Київ

Питання надання громадянам квартир, що придбані Державною іпотечною установою

{ Із змінами, внесеними згідно з Розпорядженням КМ N 293-р ( 293-2010-р ) від 24.02.2010 }

1. Затвердити погоджений Координаційною радою з питань розподілу квартир, що придбані Державною іпотечною установою, при Кабінеті Міністрів України поіменний список громадян, яким надаються придбані у с. Фонтанка Комінтернівського району Одеської області (вул. Центральна, 3, корпуси 1 і 2) квартири (далі - список), що додається до оригіналу.

{ Зміни до поіменного списку див. в Розпорядженні КМ N 293-р ( 293-2010-р ) від 24.02.2010 }

2. Державній іпотечній установі передати Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Генеральній прокуратурі України, Державному департаменту з питань виконання покарань, Службі безпеки, Міністерству внутрішніх справ, Міністерству оборони, Державній прикордонній службі та Фонтанській сільській раді квартири для надання зазначеним у списку громадянам.

3. Виконавчому комітетові Фонтанської сільської ради забезпечити в установленому законодавством порядку видачу зазначеним у списку громадянам ордерів на жилі приміщення.

4. Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Генеральній прокуратурі України, Державному департаменту з питань виконання покарань, Службі безпеки, Міністерству внутрішніх справ, Міністерству оборони, Державній прикордонній службі та Фонтанській сільській раді забезпечити неухильне дотримання встановленого Кабінетом Міністрів України порядку розподілу квартир, що придбані Державною іпотечною установою.

5. Внести зміни до пункту 2 поіменного списку громадян, яким надаються квартири, що придбані Державною іпотечною установою, у смт Солоницівці, затвердженого розпорядженням Кабінету Міністрів України від 8 грудня 2009 р. N 1508 ( 1508-2009-р ) "Питання надання громадянам квартир, що придбані Державною іпотечною установою, у смт Солоницівці", виклавши його в редакції, що додається до оригіналу.

Прем'єр-міністр України Ю.ТИМОШЕНКО
