Про утворення комісії з проведення ліквідації Держкомприродресурсів

Стан: Чинний

Ідентифікатор: 139-2005-р

Текст документа від 05.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 травня 2005 р. N 139-р Київ

Про утворення комісії з проведення ліквідації Держкомприродресурсів

( Із змінами, внесеними згідно з Розпорядженням КМ N 319-р ( 319-2005-р ) від 05.08.2005 )

На виконання Указу Президента України від 20 квітня 2005 р. N 675 ( 675/2005 ) "Про Міністерство охорони навколишнього природного середовища України" утворити комісію з ліквідації Держкомприродресурсів та затвердити першого заступника Міністра охорони навколишнього природного середовища Лизуна Степана Олексійовича її головою.

Голові комісії:

затвердити персональний склад комісії та забезпечити здійснення заходів, пов'язаних з ліквідацією Держкомприродресурсів;

поінформувати у тримісячний строк Кабінет Міністрів України про результати проведеної роботи.

( Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 319-р ( 319-2005-р ) від 05.08.2005 )
