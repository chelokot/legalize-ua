Зареєстровано в Міністерстві юстиції України 15 жовтня 2004 р. за N 1314/9913

( Наказ втратив чинність на підставі Наказу Міністерства фінансів N 683 ( z1252-05 ) від 10.10.2005 )

Про внесення змін до наказу Міністерства фінансів України від 11.07.2001 N 337

Відповідно до постанови Кабінету Міністрів України від 25.08.2004 N 1097 ( 1097-2004-п ) "Про підвищення з 1 вересня 2004 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

Унести зміни до наказу Міністерства фінансів України від 11.07.2001 N 337 ( z0625-01 ) "Про впорядкування умов оплати праці працівників Державного гемологічного центру України", зареєстрованого в Міністерстві юстиції України 23.07.2001 за N 625/5816 (із змінами і доповненнями, унесеними наказами Міністерства фінансів України від 14.05.2002 N 316 ( z0459-02 ), від 15.08.2003 N 501 ( z0719-03 ) та від 24.05.2004 N 347 ( z0708-04 ), зареєстрованими в Міністерстві юстиції України відповідно 28.05.2002 за N 459/6747, 18.08.2003 за N 719/8040 та 09.06.2004 за N 708/9307), виклавши додаток до нього в новій редакції (додається).

Перший віце-прем'єр-міністр України, Міністр фінансів України М.Я.Азаров

ПОГОДЖЕНО:

Перший заступник Міністра праці та соціальної політики України - керівник апарату М.О.Солдатенко

Додаток до наказу Міністерства фінансів України 11.07.2001 N 337 ( z0625-01 ) (у редакції наказу Міністерства фінансів України від 07.10.2004 N 642)
