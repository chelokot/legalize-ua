Кабінет Міністрів України; Постанова від 01.03.2000 № 434

Про внесення змін до переліку підприємств гірничо-металургійного комплексу, які беруть участь у економічному експерименті

Стан: Втратив чинність

Ідентифікатор: 434-2000-п

Текст документа від 14.03.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 2000 р. N 434 Київ

Про внесення змін до переліку підприємств гірничо-металургійного комплексу, які беруть участь у економічному експерименті

( Із змінами, внесеними згідно з Постановою КМ N 481 ( 481-2000-п ) від 14.03.2000 )

Кабінет Міністрів України постановляє:

( Пункт 1 скасовано на підставі Постанови КМ N 481 ( 481-2000-п ) від 14.03.2000 ) 1. Виключити з переліку підприємств гірничо-металургійного комплексу, які беруть участь у економічному експерименті, затвердженого постановою Кабінету Міністрів України від 1 жовтня 1999 р. N 1820 ( 1820-99-п ) (Офіційний вісник України, 1999 р., N 40, ст. 1996, N 41, ст. 2044, N 44, ст. 2190, N 50, ст. 2478), підприємства згідно з додатком.

2. Державній податковій адміністрації у разі, коли підприємства гірничо-металургійного комплексу, які беруть участь у економічному експерименті, що проводиться з 1 липня 1999 р. до 1 січня 2002 р., не виконують умов, на яких надавалася відстрочка у сплаті податків, зборів та інших обов'язкових платежів, скасовувати рішення про надання цієї відстрочки.
