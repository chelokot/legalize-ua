КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 квітня 2006 р. N 206-р Київ

Про затвердження складу Української частини комісій з військово-технічного співробітництва

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 710-р ( 710-2008-р ) від 14.05.2008 N 1382-р ( 1382-2009-р ) від 18.11.2009 }

1. Затвердити:

1) згідно з додатками 1 і 2 оновлений склад Української частини:

Міжурядової українсько-грузинської комісії з питань військово-технічного співробітництва ( 422-2003-р );

Міжурядової українсько-ізраїльської комісії з питань військово-технічного співробітництва ( 90-2001-п );

2) згідно з додатками 3-8 склад Української частини:

Міжурядової українсько-білоруської комісії з питань військово-технічного співробітництва;

Міжурядової українсько-македонської комісії з питань військово-технічного співробітництва;

Міжурядової українсько-монгольської комісії з питань військового і військово-технічного співробітництва;

Спільної українсько-американської комісії про обмін інформацією з питань досліджень та розробок у сфері військово-технічного співробітництва;

Спільної міжурядової українсько-сербсько-чорногорської комісії з питань військово-технічного співробітництва;

Спільної українсько-турецької комісії з питань оборонно-промислового співробітництва; { Абзац підпункту 2 пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 710-р ( 710-2008-р ) від 14.05.2008 }

3) згідно з додатками 9-15 склад Української частини: { Абзац перший підпункту 3 пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 1382-р ( 1382-2009-р ) від 18.11.2009 }

Міжурядової українсько-екваторіально-гвінейської комісії з питань військово-технічного співробітництва;

Спільної міжурядової українсько-казахстанської комісії з питань військово-технічного співробітництва;

Спільної українсько-корейської комісії зі співробітництва у сфері оборонної промисловості та матеріально-технічного забезпечення;

Спільної українсько-пакистанської комісії з питань співробітництва у військовій та оборонно-промисловій галузях;

Українсько-угорської спільної комісії з питань військово-технічного співробітництва;

Спільної українсько-хорватської комісії з питань військово-технічного співробітництва; { Підпункт 3 пункту 1 доповнено абзацом згідно з Розпорядженням КМ N 1382-р ( 1382-2009-р ) від 18.11.2009 }

Міжурядової українсько-азербайджанської комісії з питань військово-технічного співробітництва. { Підпункт 3 пункту 1 доповнено абзацом згідно з Розпорядженням КМ N 1382-р ( 1382-2009-р ) від 18.11.2009 }

{ Пункт 1 доповнено підпунктом 3 згідно з Розпорядженням КМ N 710-р ( 710-2008-р ) від 14.05.2008 }

2. Дозволити голові Української частини зазначених у пункті 1 цього розпорядження комісій вносити у разі потреби зміни до їх складу.
