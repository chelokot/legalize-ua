Про зміну порядку фінансування додаткових витрат, передбачених постановою Кабінету Міністрів України від 29 березня 1999 р. N 470

Стан: Чинний

Ідентифікатор: 1345-99-п

Текст документа від 23.07.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 липня 1999 р. N 1345 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про зміну порядку фінансування додаткових витрат, передбачених постановою Кабінету Міністрів України від 29 березня 1999 р. N 470

На часткову зміну постанови Кабінету Міністрів України від 29 березня 1999 р. N 470 ( 470-99-п ) Кабінет Міністрів України постановляє:

Міністерству фінансів профінансувати залишок витрат у сумі 2000 тис. гривень за рахунок Державного інноваційного фонду з наступним поверненням цих коштів з державних централізованих капітальних вкладень.

Перший віце-прем'єр-міністр України В.КУРАТЧЕНКО
