КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 травня 2008 р. N 692-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про затвердження нового складу Української частини Міжурядової робочої групи для врегулювання правових, фінансових, організаційно-технічних питань, пов'язаних з проектом створення військово-транспортного літака Ан-70

{ Із змінами, внесеними згідно з Розпорядженням КМ N 622-р ( 622-2009-р ) від 10.06.2009 }

На зміну абзацу першого розпорядження Кабінету Міністрів України від 12 травня 2007 р. N 280 ( 280-2007-р ) затвердити новий склад Української частини Міжурядової робочої групи для врегулювання правових, фінансових, організаційно-технічних питань, пов'язаних з проектом створення військово-транспортного літака Ан-70, що додається.
