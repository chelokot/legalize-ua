ПЕНСІЙНИЙ ФОНД УКРАЇНИ МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ МІНІСТЕРСТВО ЕКОНОМІКИ УКРАЇНИ ДЕРЖАВНА ПОДАТКОВА АДМІНІСТРАЦІЯ УКРАЇНИ

НАКАЗ

17.10.2005 N 154/702/347/454

Зареєстровано в Міністерстві юстиції України 2 листопада 2005 р. за N 1327/11607

Про визнання такими, що втратили чинність, деяких наказів Пенсійного фонду України, Міністерства фінансів України, Міністерства економіки України, Державної податкової адміністрації України

Відповідно до пункту 13 Положення про Пенсійний фонд України, затвердженого Указом Президента України від 01.03.2001 N 121 ( 121/2001 ) (із змінами), пункту 7 Положення про Міністерство фінансів України, затвердженого Указом Президента України від 26.08.99 N 1081 ( 1081/99 ) (із змінами), пункту 8 Положення про Міністерство економіки України, затвердженого Указом Президента України від 23.10.2000 N 1159 ( 1159/2000 ) (із змінами), пункту 7 Положення про Державну податкову адміністрацію України, затвердженого Указом Президента України від 13.07.2000 N 886 ( 886/2000 ) (із змінами), НАКАЗУЄМО:

1. Визнати такими, що втратили чинність, наказ Пенсійного фонду України, Міністерства фінансів України, Міністерства економіки України, Державної податкової адміністрації України від 05.11.98 N 142/226/144/530 ( z0776-98 ) "Про порядок передачі та реалізації товарів (послуг), майна і майнових прав у рахунок сплати збору на обов'язкове державне пенсійне страхування через Спеціалізоване державне підприємство Пенсійного фонду України", зареєстрований в Міністерстві юстиції України 02.12.98 за N 776/3216, наказ Пенсійного фонду України, Міністерства фінансів України, Міністерства економіки України, Державної податкової адміністрації України від 05.11.98 N 140/225/145/529 ( z0775-98 ) "Про порядок передачі та реалізації зерна в рахунок сплати збору на обов'язкове державне пенсійне страхування", зареєстрований в Міністерстві юстиції України 02.12.98 за N 775/3215.

2. Юридичному управлінню Пенсійного фонду України (Рябцева Т.Б.) подати цей наказ для державної реєстрації до Міністерства юстиції України.
