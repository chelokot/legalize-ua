{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1828-р ( 1828-2010-р ) від 13.09.2010 }

Про голову Ради підприємців при Кабінеті Міністрів України

На часткову зміну розпорядження Кабінету Міністрів України від 2 березня 2010 р. N 349 ( 349-2010-р ) затвердити президента Української аграрної конфедерації Козаченка Леоніда Петровича головою Ради підприємців при Кабінеті Міністрів України, увільнивши від виконання цих обов'язків Продан Оксану Петрівну.

Прем'єр-міністр України М.АЗАРОВ
