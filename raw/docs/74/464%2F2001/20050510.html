УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 706/2005 ( 706/2005 ) від 26.04.2005 )

Про внесення змін до Указу Президента України від 13 грудня 2000 року N 1331

Внести до Указу Президента України від 13 грудня 2000 року N 1331 ( 1331/2000 ) "Про Національну Раду з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування" (із змінами, внесеними Указами Президента України від 20 грудня 2000 року N 1354 ( 1354/2000 ), від 13 лютого 2001 року N 90 ( 90/2001 ), від 5 березня 2001 року N 148 ( 148/2001 ), від 2 червня 2001 року N 397 ( 397/2001 ) такі зміни:

1) увести до складу Національної Ради з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування КІНАХА Анатолія Кириловича - Прем'єр-міністра України - як заступника Голови Національної Ради, ЄХАНУРОВА Юрія Івановича - Першого заступника Глави Адміністрації Президента України - Керівника Головного управління організаційно-кадрової роботи та взаємодії з регіонами Адміністрації Президента України, КОВАЛЬОВА Василя Олексійовича - голову Чернігівської обласної ради (за згодою), КОЛЕСНІКОВА Бориса Вікторовича - голову Донецької обласної ради (за згодою), МОСКАЛЯ Геннадія Геннадійовича - голову Закарпатської обласної державної адміністрації, вивівши зі складу Національної Ради Ющенка В.А., Балогу В.І., Яковенка О.С.;

2) увести до складу Президії Національної Ради з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування КІНАХА Анатолія Кириловича - Прем'єр-міністра України - як заступника Голови Національної Ради, РАДЧЕНКА Володимира Івановича - Голову Служби безпеки України, вивівши зі складу Президії Національної Ради Ющенка В.А. і Деркача Л.В.

Президент України Л.КУЧМА

м. Київ, 23 червня 2001 року N 464/2001
