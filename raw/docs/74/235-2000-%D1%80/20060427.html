Кабінет Міністрів України; Розпорядження від 15.05.2000 № 235-р

Про створення узгоджувальної робочої групи із завершення підготовки проекту Податкового кодексу України

Стан: Втратив чинність

Ідентифікатор: 235-2000-р

Текст документа від 27.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 травня 2000 р. N 235-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 579 ( 579-2006-п ) від 27.04.2006 }

1. Для завершення підготовки проекту Податкового кодексу України створити узгоджувальну робочу групу у складі згідно з додатком.

2. Узгоджувальній робочій групі в місячний термін подати Кабінетові Міністрів України доопрацьований проект Податкового кодексу України.

3. Надати керівникові узгоджувальної робочої групи право залучати у разі потреби для доопрацювання проекту Податкового кодексу України фахівців міністерств та інших центральних органів виконавчої влади, провідних учених і спеціалістів.

4. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 18 лютого 1998 р. N 92 ( 92-98-р );

розпорядження Кабінету Міністрів України від 17 серпня 1998 р. N 669 ( 669-98-р );

розпорядження Кабінету Міністрів України від 10 квітня 1999 р. N 285 ( 285-99-р ).
