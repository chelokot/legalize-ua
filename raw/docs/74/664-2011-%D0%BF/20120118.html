КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 червня 2011 р. N 664 Київ

Про особливості реалізації продуктів утилізації та оплати робіт з утилізації боєприпасів за договорами, укладеними Міністерством промислової політики у 2009-2010 роках

{ Із змінами, внесеними згідно з Постановою КМ N 1384 ( 1384-2011-п ) від 26.12.2011 }

Кабінет Міністрів України постановляє:

1. Визначити Міністерство оборони правонаступником за договорами про утилізацію боєприпасів, укладеними у 2009-2010 роках Міністерством промислової політики з виконавцями робіт з утилізації боєприпасів, а саме:

Донецьким казенним заводом хімічних виробів;

казенним підприємством "Шосткинський казенний завод "Імпульс";

хімічним казенним об'єднанням імені Г.І. Петровського;

державним науково-дослідним інститутом хімічних продуктів;

казенним підприємством Шосткинський казенний завод "Зірка". { Абзац перший пункту 1 в редакції Постанови КМ N 1384 ( 1384-2011-п ) від 26.12.2011 }

Міністерству промислової політики передати у місячний строк Міністерству оборони продукти утилізації боєприпасів, отримані на підставі зазначених договорів.

Міністерству оборони забезпечити укладення з виконавцями робіт додаткових договорів про оплату виконаних у 2009-2010 роках робіт з утилізації боєприпасів із залученням власних коштів.

2. Установити, що кошти, отримані від реалізації продуктів утилізації боєприпасів, зазначених у пункті 1 цієї постанови, перераховуються у п'ятиденний строк виконавцями робіт до спеціального фонду державного бюджету.

3. Міністерству оборони забезпечити проведення у 2011-2012 роках розрахунків за виконані у 2009-2010 роках роботи з утилізації боєприпасів підприємствами, зазначеними у пункті 1 цієї постанови, у межах бюджетних призначень спеціального фонду державного бюджету за програмою 2101210 "Утилізація звичайних видів боєприпасів та рідинних компонентів ракетного палива".

{ Пункт 3 в редакції Постанови КМ N 1384 ( 1384-2011-п ) від 26.12.2011 }

4. Відображення у первинному та бухгалтерському обліку інформації про отримані (створені) оборотні і необоротні активи, облік бюджетних зобов'язань, а також відкриття рахунків в органах Державної казначейської служби та проведення операцій, пов'язаних з використанням бюджетних коштів, здійснюється в установленому законодавством порядку.

Складення і подання фінансової та бюджетної звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.

{ Постанову доповнено пунктом 4 згідно з Постановою КМ N 1384 ( 1384-2011-п ) від 26.12.2011 }
