Про внесення змін до переліку органів ліцензування та до переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності

Стан: Втратив чинність

Ідентифікатор: 797-2003-п

Текст документа від 26.08.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 червня 2003 р. N 797 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 609 ( 609-2015-п ) від 05.08.2015 }

Про внесення змін до переліку органів ліцензування та до переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності

Кабінет Міністрів України постановляє:

1. Доповнити перелік органів ліцензування, затверджений постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001; 2002 р., N 23, ст. 1103), позицією 33 такого змісту:

"33. Мінагрополітики, оптова торгівля насінням". Держкомлісгосп, Держжитлокомунгосп, Рада міністрів Автономної Республіки Крим, обласні, Київська та Севастопольська міські держадміністрації*

2. Доповнити перелік документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності, затверджений постановою Кабінету Міністрів України від 4 липня 2001 р. N 756 ( 756-2001-п ) (Офіційний вісник України, 2001 р., N 27, ст. 1212; 2002 р., N 21, ст. 1016, N 51, ст. 2294), пунктом 59 такого змісту:

"59. Оптова торгівля засвідчені в установленому порядку копії установчих

насінням документів (для юридичної особи)

засвідчені в установленому порядку копії документів,

що підтверджують право власності суб'єкта

господарської діяльності або оренди ним виробничих

площ

відомості за підписом заявника - суб'єкта

господарської діяльності про наявність

матеріально-технічної бази, необхідної для

провадження відповідного виду господарської

діяльності".

Перший віце-прем'єр-міністр України М.АЗАРОВ
