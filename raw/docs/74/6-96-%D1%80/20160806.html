Кабінет Міністрів України; Розпорядження від 05.01.1996 № 6-р

Про віднесення посади першого заступника Керівника управління Адміністрації Президента України до другої категорії посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 6-96-р

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 січня 1996 р. N 6-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посаду першого заступника Керівника управління Адміністрації Президента України до другої категорії посад державних службовців.
