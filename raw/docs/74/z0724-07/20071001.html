Зареєстровано в Міністерстві юстиції України 22 червня 2007 р. за N 724/13991

Про затвердження Порядку надання Адміністрацією Держприкордонслужби України Мінпраці доступу до інформації про перетинання громадянами України державного кордону України

{ Із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 449/683 ( z1080-07 ) від 28.08.2007 }

З метою врегулювання порядку надання Адміністрацією Держприкордонслужби України Мінпраці відомостей про перетинання громадянами України державного кордону України та відповідно до законів України "Про загальнообов'язкове державне соціальне страхування на випадок безробіття" ( 1533-14 ), "Про державну допомогу сім'ям з дітьми" ( 2811-12 ), "Про державну соціальну допомогу малозабезпеченим сім'ям" ( 1768-14 ), "Про інформацію" ( 2657-12 ), "Про захист інформації в інформаційно-телекомунікаційних системах" ( 80/94-ВР ), "Про Державну прикордонну службу України" ( 661-15 ), постанов Кабінету Міністрів України від 21 жовтня 1995 року N 848 ( 848-95-п ) "Про спрощення порядку надання населенню субсидій для відшкодування витрат на оплату житлово-комунальних послуг, придбання скрапленого газу, твердого та рідкого пічного побутового палива" та від 20 березня 2006 р. N 357 ( 357-2006-п ) "Деякі питання загальнообов'язкового державного соціального страхування на випадок безробіття", а також розпорядження Кабінету Міністрів України від 30 травня 2007 р. N 365-р ( 365-2007-р ) "Про проведення експерименту із запровадження обміну інформацією між Мінпраці та Адміністрацією Держприкордонслужби України стосовно осіб, які в період одержання державних соціальних і страхових виплат перетинали державний кордон або перебували за межами країни" НАКАЗУЄМО:

1. Затвердити Порядок надання Адміністрацією Держприкордонслужби України Мінпраці доступу до інформації про перетинання громадянами України державного кордону України (далі - Порядок), що додається.

2. Департаменту державного соціального захисту населення Мінпраці забезпечити подання цього наказу до Міністерства юстиції України для державної реєстрації.

3. Департаменту державного соціального захисту населення, Державному центру зайнятості, Управлінню справами Мінпраці та Департаменту охорони державного кордону Адміністрації Держприкордонслужби України провести роботу зі створення та запровадження підсистеми віддаленого доступу від автоматизованих робочих місць посадових осіб відповідних структурних підрозділів Мінпраці до інформації про перетинання громадянами України державного кордону України, що зберігається в центральному сховищі даних центральної підсистеми інтегрованої інформаційно-телекомунікаційної системи "Гарт" Державної прикордонної служби, в установленому порядку здійснити забезпечення визначених підрозділів відповідними програмно-технічними засобами та їх технічне обслуговування.

3. Контроль за виконанням цього наказу покласти на першого заступника Міністра праці та соціальної політики України Дроздову Л.М. та першого заступника Голови Державної прикордонної служби України Шишоліна П.А.

Міністр праці та соціальної політики України М.М.Папієв

Голова Державної прикордонної служби України М.Литвин

ЗАТВЕРДЖЕНО Наказ Міністерства праці та соціальної політики України, Адміністрації Державної прикордонної служби України 18.06.2007 N 306/450

Зареєстровано в Міністерстві юстиції України 22 червня 2007 р. за N 724/13991

ПОРЯДОК надання Адміністрацією Держприкордонслужби України Мінпраці доступу до інформації про перетинання громадянами України державного кордону України

1. Цей Порядок визначає механізм надання Адміністрацією Держприкордонслужби України доступу Мінпраці до інформації про перетинання державного кордону України громадянами України під час проведення експерименту у період з 3 липня до 30 вересня 2007 року щодо запровадження системи міжвідомчого обміну інформацією стосовно громадян України, які в період одержання державних соціальних і страхових виплат перетинали державний кордон або перебували за межами країни.

2. Інформація про перетинання державного кордону України громадянами України надається Адміністрацією Держприкордонслужби України за наявності її в обліковій базі даних "2.1 Відомості про осіб, які перетнули державний кордон України" (далі - база даних осіб) центрального сховища даних (далі - ЦСД) центральної підсистеми інтегрованої інформаційно-телекомунікаційної системи (далі - ІІТС) "Гарт" Державної прикордонної служби України шляхом організації віддаленого доступу до цієї бази даних від автоматизованих робочих місць (далі - АРМ) посадових осіб Департаменту державного соціального захисту населення та Державного центру зайнятості Мінпраці (далі - посадові особи Мінпраці) із використанням файлів типу "запит", "відповідь" та "квитанція" (далі - віддалений доступ).

Правила формування зазначених файлів погоджуються Адміністрацією Держприкордонслужби України та Мінпраці. { Пункт 2 доповнено абзацом другим згідно з Наказом Міністерства праці та соціальної політики N 449/683 ( z1080-07 ) від 28.08.2007 }

{ Пункт 2 із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 449/683 ( z1080-07 ) від 28.08.2007 }

3. Інформація надається за принципом "запит-відповідь" згідно з реквізитами, що додаються.

Кожен опис містить відомості про одну або декілька подій щодо перетинання державного кордону громадянами України. { Абзац другий пункту 3 в редакції Наказу Міністерства праці та соціальної політики N 449/683 ( z1080-07 ) від 28.08.2007 }

Формування відповіді здійснюється за часом надходження запиту. { Абзац третій пункту 3 із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 449/683 ( z1080-07 ) від 28.08.2007 }

Запити і відповіді формуються українською мовою.

4. Віддалений доступ посадовим особам Мінпраці до бази даних осіб Адміністрації Держприкордонслужби України забезпечується програмно-технічними засобами підсистеми "Доступ Мінпраці", що створюється до 1 липня 2007 року Адміністрацією Держприкордонслужби України.

5. Мінпраці забезпечує налагодження віддаленого доступу за допомогою міського телефонного зв'язку, надання 2-3 локальних ПЕОМ та аналогових модемів із розрахунку один модем та одна ПЕОМ для одного АРМ, експлуатацію цих АРМів за призначенням з використанням лише визначених телефонних номерів без доступу до комп'ютерних мереж Мінпраці та мережі Інтернет, а також їх антивірусний захист.

6. Інформаційний запит про перетинання громадянами України державного кордону України (далі - запит) до ЦСД центральної підсистеми ІІТС "Гарт" здійснюється за допомогою АРМ, що встановлюються у відповідних службових приміщеннях Мінпраці, Державного підприємства "Інформаційно-обчислювальний центр" та Державного центру зайнятості.

7. Склад програмно-технічного забезпечення АРМ повинен відповідати таким вимогам:

ПЕОМ класу не нижче Р-433 з жорстким диском не менш як 10 Гб,

модем для двопроводової комутованої лінії,

джерело безперебійного живлення,

ОС MS WINDOWS NT 4.0/2000/XP та антивірусне програмне забезпечення,

Веб-браузер Internet Explorer версії не нижче 5.5,

антивірусне програмне забезпечення.

8. Відповідь на запит, що здійснюється з АРМ посадової особи Мінпраці, реалізується за допомогою екранних форм, що відображаються на моніторі АРМ.

Відповіді на запити формуються спеціальним програмним забезпеченням (далі - СПЗ) підсистеми "Доступ Мінпраці" на відповідному сервері Адміністрації Держприкордонслужби України.

На цьому сервері створюються такі папки:

"import" - для обробки інформації з файлів типу "запит";

"export" - для обробки інформації з файлів типу "відповідь";

"kvit" - для обробки інформації з файлів типу "квитанція".

{ Пункт 8 доповнено абзацом третім згідно з Наказом Міністерства праці та соціальної політики N 449/683 ( z1080-07 ) від 28.08.2007 }

Синхронізація системних годинників АРМ здійснюється визначеними посадовими особами Мінпраці у телефонному режимі щотижня або, у разі потреби, після перезавантаження операційної системи ПЕОМ, на якій встановлено СПЗ АРМ.

9. Запити та відповіді до ЦСД центральної підсистеми ІІТС "Гарт" є несекретними і здійснюються із використанням відкритих каналів зв'язку міської телефонної мережі.

10. Усі запити до ЦСД центральної підсистеми ІІТС "Гарт" фіксуються та зберігаються в електронному журналі без можливості несанкціонованого перегляду та зміни даних щодо об'єкта запиту.

11. Допуск посадових осіб Мінпраці до перегляду інформації, отриманої з бази даних осіб надається розпорядчим документом Адміністрації Держприкордонслужби України на підставі списку, що оформлюється на бланку за підписом Міністра праці та соціальної політики України або його заступника і надсилається до Адміністрації Держприкордонслужби України. У списку зазначаються прізвища, ім'я, по батькові, посади фахівців та телефонні номери, з яких буде здійснюватися віддалений доступ до бази даних осіб. Надалі про всі зміни у цих списках Адміністрація Держприкордонслужби України повідомляється письмово.

{ Пункт 11 із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 449/683 ( z1080-07 ) від 28.08.2007 }

12. Права та первинні паролі доступу до підсистеми "Доступ Мінпраці" надаються адміністратором ЦСД центральної підсистеми ІІТС "Гарт" Державної прикордонної служби України. Первинні паролі доступу до сервера надсилаються поштою у запечатаних конвертах визначеним посадовим особам Мінпраці із зазначенням у журналі реєстрації паролів ЦСД центральної підсистеми ІІТС "Гарт" Державної прикордонної служби України. Надалі первинний пароль змінюється посадовою особою, якій надано віддалений доступ.

13. У запитах зазначаються такі обов'язкові реквізити: прізвище та ім'я особи, дата народження, серія та номер паспорта громадянина України (за наявності даних), період перетину кордону, починаючи з 1 січня 2007 року, а також номер справи з документами про призначені соціальні чи страхові виплати.

{ Пункт 13 із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 449/683 ( z1080-07 ) від 28.08.2007 }

14. Відповідь Адміністрації Держприкордонслужби України формується згідно з наявною інформацією з урахуванням реквізитів, визначених у пункті 13 цього Порядку. Додатково до реквізитів указується також назва пункту пропуску через державний кордон України, дата, час та напрямок перетинання (в'їзд чи виїзд) державного кордону України об'єктом запиту, а також вид, серія та номер його паспортного документа.

{ Пункт 14 із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 449/683 ( z1080-07 ) від 28.08.2007 }

15. У разі виникнення збою, аварії або проведення регламентних робіт з боку Адміністрації Держприкордонслужби України черговий по центру АСУ Центрального вузла зв'язку Державної прикордонної служби України негайно сповіщає про це відповідальну особу Мінпраці по телефону.

Збоєм уважається зупинка у функціонуванні підсистеми терміном до 30 хвилин. Зупинка у функціонуванні підсистеми терміном понад 30 хвилин вважається аварією. Сторона, з боку якої виник збій або аварія, негайно сповіщає іншу про її причини, а також про заходи, які вживаються для відновлення роботоздатності. Оповіщення виконують відповідні адміністратори АРМ, а в разі їх відсутності - чергові оператори.

У разі виникнення збою або аварії з боку Мінпраці адміністратор АРМ звертається до чергового по центру АСУ Центрального вузла зв'язку Державної прикордонної служби України за телефоном.

16. На період відновлення роботоздатності підсистеми "Доступ Мінпраці" надання інформації здійснюється за письмовими запитами відповідно до цього Порядку.

17. Здійснюючи запит про перетинання громадянином України державного кордону та надаючи доступ до бази даних осіб, Мінпраці та Адміністрація Держприкордонслужби України керуються Конституцією України ( 254к/96-ВР ), нормативно-правовими актами України та цим Порядком.

18. Інформація, що міститься в запиті Мінпраці та інформація, надана Адміністрацією Держприкордонслужби України, використовується тільки під час перевірки обґрунтованості соціальних чи страхових виплат та здійснення розслідувань страхових випадків. Зазначена інформація не підлягає поширенню та передачі третій стороні без письмової згоди Адміністрації Держприкордонслужби України.

19. Посадові особи Мінпраці несуть відповідальність за порушення законодавства про інформацію стосовно незаконного розголошення інформації, що отримана з бази даних Адміністрації Держприкордонслужби України.
