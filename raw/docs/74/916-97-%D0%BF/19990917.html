( Із змінами, внесеними згідно з Постановами КМ N 1120 ( 1120-97-п ) від 08.10.97 N 150 ( 150-98-п ) від 16.02.98 N 420 ( 420-98-п ) від 02.04.98 N 1212 ( 1212-98-п ) від 03.08.98 N 1401 ( 1401-99-п ) від 30.07.99 )

Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита ( 4а-93 ), ( 4б-93 ), ( 4в-93 ) на окремі види товарів згідно з додатком.

2. Затвердити зміни, що вносяться до деяких постанов Кабінету Міністрів України, щодо ставок ввізного мита на окремі види товарів (додаються).

3. Ця постанова набирає чинності через 10 днів з дня її опублікування у газеті "Урядовий кур'єр".
