УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Указу Президента України від 21 березня 2002 року N 277

1. Внести до додатка N 3 до Указу Президента України від 21 березня 2002 року N 277 ( 277/2002 ) "Про переліки посад військовослужбовців і працівників правоохоронних органів, що підлягають заміщенню особами вищого офіцерського (начальницького) складу, та граничних військових і спеціальних звань за цими посадами" (в редакції Указу від 27 грудня 2005 року N 1846 ( 1846/2005 ), зі змінами, внесеними Указами від 20 листопада 2006 року N 986 ( 986/2006 ), від 9 жовтня 2007 року N 953 ( 953/2007 ), від 16 листопада 2007 року N 1114 ( 1114/2007 ), від 20 серпня 2008 року N 729 ( 729/2008 ) та від 2 квітня 2009 року N 213) ( 213/2009 ) такі зміни:

а) у назві позиції "Директор Інституту підготовки юридичних кадрів для Служби безпеки України Національної юридичної академії України імені Ярослава Мудрого" слово "Директор" замінити словом "Начальник";

б) позицію "Перший заступник начальника Головного слідчого управління" замінити двома позиціями такого змісту:

"Начальник Головного слідчого управління генерал-майор юстиції

Перший заступник начальника Головного -"-". слідчого управління
