Кабінет Міністрів України; Постанова від 13.06.2007 № 827

Про представників від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму

Стан: Втратив чинність

Ідентифікатор: 827-2007-п

Текст документа від 25.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 червня 2007 р. N 827 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 444 ( 444-2010-п ) від 16.06.2010 }

Про представників від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму

Кабінет Міністрів України постановляє:

На зміну пункту 2 постанови Кабінету Міністрів України від 24 вересня 1999 р. N 1767 ( 1767-99-п ) "Про науково-громадську експертизу набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 1999 р., N 39, ст. 1946; 2004 р., N 22, ст. 1499; 2005 р. , N 20, ст. 1074) затвердити представниками від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму Бережнова С.П. - першого заступника Міністра охорони здоров'я, Рибака С.О. - заступника Міністра фінансів, Солдатенка М.О. - заступника Міністра праці та соціальної політики, Челнокова С.Д. - заступника Міністра економіки, увільнивши від цих обов'язків Матвійчука В.М., Паська М.В., Піщейка В.О.
