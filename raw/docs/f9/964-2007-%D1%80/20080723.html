Текст документа від 23.07.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 листопада 2007 р. N 964-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1014-р ( 1014-2008-р ) від 23.07.2008 }

Про затвердження складу спостережної ради НАК "Надра України"

Затвердити склад спостережної ради НАК "Надра України", що додається.

У зв'язку з цим визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 19 червня 2006 р. N 343 ( 343-2006-р ), від 2 листопада 2006 р. N 535 ( 535-2006-р ) та від 19 вересня 2007 р. N 783 ( 783-2007-р ).
