Про віднесення посад вченого секретаря Вищої атестаційної комісії до другої категорії посад державних службовців

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 липня 1998 р. N 532-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Про віднесення посад вченого секретаря Вищої атестаційної комісії до другої категорії посад державних службовців

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посаду вченого секретаря Вищої атестаційної комісії до другої категорії посад державних службовців.
