КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 1999 р. N 281 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 81 ( 81-2021-п ) від 03.02.2021 }

Про утворення Координаційної ради з питань врегулювання кризових ситуацій у вугільній промисловості

{ Із змінами, внесеними згідно з Постановами КМ N 1506 ( 1506-99-п ) від 17.08.99 N 2022 ( 2022-99-п ) від 29.10.99 N 559 ( 559-2000-п ) від 27.03.2000 N 130 ( 130-2003-п ) від 29.01.2003 N 123 ( 123-2004-п ) від 04.02.2004 N 579 ( 579-2005-п ) від 13.07.2005 N 147 ( 147-2006-п ) від 15.02.2006 N 639 ( 639-2008-п ) від 16.07.2008 }

Кабінет Міністрів України постановляє:

Утворити при Кабінеті Міністрів України Координаційну раду з питань врегулювання кризових ситуацій у вугільній промисловості у складі, що додається.

Дозволити голові Координаційної ради з питань врегулювання кризових ситуацій у вугільній промисловості вносити у разі потреби зміни до її складу. ( Постановляючу частину доповнено абзацом згідно з Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 )
