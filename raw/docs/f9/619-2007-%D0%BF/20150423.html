Текст документа від 23.04.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 квітня 2007 р. N 619 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 198 ( 198-2015-п ) від 15.04.2015 }

Про тимчасову заборону ввезення окремих видів давальницької сировини на митну територію України

Відповідно до статті 2 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ) Кабінет Міністрів України постановляє:

1. Заборонити ввезення до 1 вересня 2007 р. на митну територію України товарів групи 02 згідно з УКТЗЕД ( 2371а-14 ) як давальницької сировини.

2. Дія цієї постанови не поширюється на товари групи 02 згідно з УКТЗЕД ( 2371а-14 ), ввезені до набрання нею чинності як давальницька сировина.

3. Ця постанова набирає чинності з дня опублікування.

Прем'єр-міністр України В.ЯНУКОВИЧ
