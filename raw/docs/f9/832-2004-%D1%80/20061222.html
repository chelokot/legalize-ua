Кабінет Міністрів України; Розпорядження від 17.11.2004 № 832-р

Про підписання Угоди між Кабінетом Міністрів України та Урядом Російської Федерації про взаємну охорону прав на результати інтелектуальної діяльності, що використовуються та отримані в ході двостороннього військово-технічного співробітництва

Стан: Чинний

Ідентифікатор: 832-2004-р

Текст документа від 22.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 листопада 2004 р. N 832-р Київ

Про підписання Угоди між Кабінетом Міністрів України та Урядом Російської Федерації про взаємну охорону прав на результати інтелектуальної діяльності, що використовуються та отримані в ході двостороннього військово-технічного співробітництва

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 334-р ( 334-2005-р ) від 10.08.2005 N 629-р ( 629-2006-р ) від 22.12.2006 }

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Російської Федерації про взаємну охорону прав на результати інтелектуальної діяльності, що використовуються та отримані в ході двостороннього військово-технічного співробітництва.

Уповноважити першого заступника Міністра освіти і науки Жебровського Бориса Михайловича підписати зазначену Угоду, дозволивши вносити у разі потреби до проекту Угоди зміни, що не мають принципового характеру. { Абзац другий із змінами, внесеними згідно з Розпорядженнями КМ N 334-р ( 334-2005-р ) від 10.08.2005, N 629-р ( 629-2006-р ) від 22.12.2006 }
