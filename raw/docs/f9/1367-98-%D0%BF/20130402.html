Про внесення змін до складу Міжвідомчої ради у справах співробітництва з Міжнародним агентством по атомній енергії

Стан: Втратив чинність

Ідентифікатор: 1367-98-п

Текст документа від 02.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 вересня 1998 р. N 1367 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про внесення змін до складу Міжвідомчої ради у справах співробітництва з Міжнародним агентством по атомній енергії

( Із змінами, внесеними згідно з Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 )

Кабінет Міністрів України постановляє:

1. Затвердити склад Міжвідомчої ради у справах співробітництва з Міжнародним агентством по атомній енергії згідно з додатком.

2. Визнати такими, що втратили чинність, абзац другий пункту 1 постанови Кабінету Міністрів України від 14 лютого 1994 р. N 90 ( 90-94-п ) "Про Міжвідомчу раду у справах співробітництва з Міжнародним агентством по атомній енергії" та постанову Кабінету Міністрів України від 17 жовтня 1995 р. N 837 ( 837-95-п ) "Про внесення змін до складу Міжвідомчої ради у справах співробітництва з Міжнародним агентством по атомній енергії".
