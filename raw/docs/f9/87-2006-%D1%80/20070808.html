Про голову Української частини комісій з військово-технічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 87-2006-р

Текст документа від 08.08.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 лютого 2006 р. N 87-р Київ

Про голову Української частини комісій з військово-технічного співробітництва

{ Із змінами, внесеними згідно з Розпорядженням КМ N 620-р ( 620-2007-р ) від 08.08.2007 }

Затвердити заступника Міністра оборони, який згідно з розподілом функціональних повноважень відповідає за військово-технічне співробітництво, головою Української частини Спільної українсько-турецької комісії з питань співробітництва в галузі оборонної промисловості ( 1169-99-п ), Спільної українсько-американської комісії про обмін інформацією з питань досліджень та розробок у сфері військово-технічного співробітництва, Міжурядової українсько-монгольської комісії з питань військового і військово-технічного співробітництва, міжурядових українсько-ізраїльської ( 90-2001-п ), українсько-грузинської ( 422-2003-р ), українсько-македонської, українсько-білоруської, українсько-сербсько-чорногорської, українсько-екваторіально-гвінейської, українсько-казахстанської, українсько-угорської комісій з питань військово-технічного співробітництва, увільнивши від обов'язків голови Української частини Спільної українсько-турецької комісії з питань співробітництва у галузі оборонної промисловості Падалка Віктора Григоровича, Міжурядової українсько-ізраїльської комісії з питань військово-технічного співробітництва Горбуліна Володимира Павловича та Міжурядової українсько-грузинської комісії з питань військово-технічного співробітництва Стеценка Олександра Олексійовича. { Абзац перший із змінами, внесеними згідно з Розпорядженням КМ N 620-р ( 620-2007-р ) від 08.08.2007 }

Міноборони подати Кабінетові Міністрів України пропозиції щодо визначення складу Української частини зазначених комісій.

Прем'єр-міністр України Ю.ЄХАНУРОВ
