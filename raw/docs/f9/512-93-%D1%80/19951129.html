Кабінет Міністрів України; Розпорядження від 17.07.1993 № 512-р

Про звільнення від сплати мита спеціальних приладів, техніки, озброєння, що ввозяться для використання Прикордонними військами при охороні державного кордону

Стан: Втратив чинність

Ідентифікатор: 512-93-р

Текст документа від 29.11.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 липня 1993 р. N 512-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 957 ( 957-95-п ) від 29.11.95 )

Звільнити від сплати мита під час переміщення через митний кордон України спеціальних приладів, засобів зв'язку, техніки, озброєння, що ввозяться для використання Прикордонними військами при охороні державного кордону, згідно з деклараціями на ввезення.

В.о. Прем'єр-міністра України Ю.ЗВЯГІЛЬСЬКИЙ
