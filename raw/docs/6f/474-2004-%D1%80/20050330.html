КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 липня 2004 р. N 474-р Київ

( Розпорядження скасовано на підставі Розпорядження КМ N 71-р ( 71-2005-р ) від 30.03.2005 )

Про погодження продажу земельних ділянок

Погодитися з пропозицією Ялтинської міської ради щодо продажу земельних ділянок несільськогосподарського призначення загальною площею 15,1868 гектара, розташованих у межах м. Ялти, ЗАТ "Ялтинська кіностудія", що засноване за участю іноземної юридичної особи, для будівництва та експлуатації виробничо-технологічної бази кіностудії.

Прем'єр-міністр України В.ЯНУКОВИЧ
