Реєстрація: Мін'юст України від 22.04.1999 № 250/3543

Стан: Втратив чинність

Ідентифікатор: z0250-99

Текст документа від 01.01.2002:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 156 від 31.03.99 Зареєстровано в Міністерстві м.Київ юстиції України 22 квітня 1999 р. vd990331 vn156 за N 250/3543

Про затвердження змін та доповнень до Положення про застосування Національним банком України заходів впливу до комерційних банків за порушення банківського законодавства

( Із змінами, внесеними згідно з Постановами Нацбанку N 215 ( z0381-00 ) від 26.05.2000 N 275 ( z0730-01 ) від 17.07.2001 N 368 ( z0841-01 ) від 28.08.2001 - зміни набувають чинності з 01.01.2002 )

З метою удосконалення процедури ліквідації комерційних банків та механізму стягнення штрафу в розмірі неправомірно одержаного доходу, керуючись статтею 48 Закону України "Про банки і банківську діяльність" ( 872-12 ), Правління ПОСТАНОВЛЯЄ:

( Пункт 1 втратив чинність на підставі Постанови Нацбанку N 215 ( z0381-00 ) від 26.05.2000 )

( Пункт 2 втратив чинність з 01.01.2002 на підставі Постанови Національного банку N 368 ( z0841-01 ) від 28.08.2001 )

{ Пункт 3 фактично втратив чинність у зв'язку з втратою чинності Положення, затвердженого Постановою Національного банку N 181 ( z0373-98 ) від 06.05.98, до якого вносились зміни } 3. У Положенні про порядок видачі банкам ліцензії на здійснення банківських операцій, затвердженому постановою Правління Національного банку України від 06.05.98 N 181 ( z0373-98 ) і зареєстрованому в Міністерстві юстиції України 10.06.98 за N 373/2813 (із змінами і доповненнями), вилучити пункт 10.3.

4. Комісії Національного банку України з питань нагляду та регулювання діяльності банків визначити умови, за яких рішення щодо тимчасового зупинення дії окремих пунктів ліцензії, заборони або обмеження проведення операцій, право на здійснення яких дає той чи інший пункт ліцензії, або відкликання ліцензії на здійснення окремих банківських операцій приймається регіональними управліннями Національного банку України, та довести їх до відома регіональних управлінь Національного банку України і комерційних банків до часу набуття постановою чинності.

5. Департаменту пруденційного нагляду (В.О.Зінченко) протягом п'яти робочих днів після набуття постановою чинності внести відповідні зміни до Положення про Комісію Національного банку України з питань нагляду та регулювання діяльності банків, затвердженого постановою Правління Національного банку України від 09.11.98 N 470 ( v0470500-98 ).

6. Довести цю постанову після державної реєстрації в Міністерстві юстиції України до відома самостійних структурних підрозділів Національного банку України, Кримського республіканського, обласних та по м.Києву і Київській області управлінь Національного банку України, а також комерційних банків для керівництва і використання в роботі.

7. Контроль за виконанням цієї постанови покласти на заступника Голови Національного банку України О.І.Кірєєва, Департамент пруденційного нагляду (В.О.Зінченко), Управління реєстрації та ліцензування банків (О.І.Пархоменко), Управління нагляду за великими банками (Ю.О.Герасименко), Управління з питань роботи з проблемними банками (В.І.Ревун) та начальників Кримського республіканського, обласних та по м.Києву і Київській області управлінь Національного банку України.

8. Постанова набуває чинності через 10 днів після державної реєстрації.

Голова В.А.Ющенко

( Зміни і доповнення до Положення про застосування Національним банком України заходів впливу до комерційних банків за порушення банківського законодавства, затвердженого постановою Правління Національного банку України від 04.02.98 N 38 ( z0177-98 ) втратили чинність на підставі Постанови Нацбанку N 215 ( z0381-00 ) від 26.05.2000 )
