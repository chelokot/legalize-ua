Кабінет Міністрів України; Розпорядження від 08.11.2007 № 954-р

Про припинення проходження державної служби Терещенком В.І.

Стан: Чинний

Ідентифікатор: 954-2007-р

Текст документа від 08.11.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 листопада 2007 р. N 954-р Київ

Про припинення проходження державної служби Терещенком В.І.

У зв'язку із зупиненням Указом Президента України від 28 вересня 2007 р. N 925 ( 925/2007 ) дії розпорядження Кабінету Міністрів України від 26 вересня 2007 р. N 762 ( 762-2007-р ) та досягненням Терещенком В.І. граничного віку перебування на державній службі, передбаченого статтею 23 Закону України "Про державну службу" ( 3723-12 ), припинити проходження Терещенком В.І. державної служби.

Прем'єр-міністр України В.ЯНУКОВИЧ
