Текст документа від 13.10.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 червня 2009 р. N 880-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 939 ( 939-2012-п ) від 03.10.2012 }

Про затвердження переліку підприємств - виробників азотних мінеральних добрив, які можуть закуповувати імпортований природний газ у нерезидентів України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1611-р ( 1611-2009-р ) від 18.11.2009 }

{ У назві і тексті Розпорядження та назві додатка до нього слова і цифри "у 2009 році" виключено згідно з Розпорядженням КМ N 1611-р ( 1611-2009-р ) від 18.11.2009 }

Затвердити згідно з додатком перелік підприємств - виробників азотних мінеральних добрив, які можуть закуповувати в обсязі, що не перевищує потреби їх власного споживання, імпортований природний газ у нерезидентів України для використання як технологічної сировини без права реалізації такого газу.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21
