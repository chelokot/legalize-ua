Про розмір плати за видачу та обмін ліцензій на здійснення страхової діяльності

Стан: Втратив чинність

Ідентифікатор: 363-95-п

Текст документа від 29.02.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 травня 1995 р. N 363 Київ

Про розмір плати за видачу та обмін ліцензій на здійснення страхової діяльності

( Із змінами, внесеними згідно з Постановою КМ N 257 ( 257-96-п ) від 29.02.96 )

Кабінет Міністрів України ПОСТАНОВЛЯЄ:

( Пункт 1 втратив чинність на підставі Постанови КМ N 257 ( 257-96-п ) від 29.02.96 )

2. З метою захисту страхувальників та запобігання підробці ліцензій Комітету у справах нагляду за страховою діяльністю здійснити до 1 січня 1996 р. обмін раніше виданих ліцензій на здійснення страхової діяльності на ліцензії нового зразка, що мають необхідні ступені захисту.

( Термін обміну раніше виданих ліцензій на здійснення страхової діяльності продовжено до 31 грудня 1996 року згідно з Постановою КМ N 257 ( 257-96-п ) від 29.02.96 )

( Абзац другий пункту 2 втратив чинність на підставі Постанови КМ N 257 ( 257-96-п ) від 29.02.96 )
