ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

06.12.2005 N 701

Зареєстровано в Міністерстві юстиції України 9 грудня 2005 р. за N 1472/11752

Про реалізацію постанови Кабінету Міністрів України від 14.09.2005 N 909 ( 909-2005-п )

Відповідно до Законів України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ) та "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ) Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити:

Порядок проведення експерименту із створення автоматизованої системи Накопичувального фонду загальнообов'язкового державного пенсійного страхування ( z1472-05 ) (далі - Порядок);

Склад Міжвідомчої робочої групи з питань проведення експерименту із створення автоматизованої системи Накопичувального фонду загальнообов'язкового державного пенсійного страхування ( z1472-05 );

План-графік створення автоматизованої системи Накопичувального фонду загальнообов'язкового державного пенсійного страхування ( z1472-05 ).

2. Керівнику апарату Державної комісії з цінних паперів та фондового ринку (далі - Комісія) М.Непрану проінформувати Пенсійний фонд України про прийняте рішення.

3. Контроль за виконанням цього рішення покласти на Керівника апарату Комісії М.Непрана.

Голова Комісії А.Балюк
