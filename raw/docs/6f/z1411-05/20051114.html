Про визнання такими, що втратили чинність, регуляторних актів, що не відповідають принципам державної регуляторної політики

Реєстрація: Мін'юст України від 23.11.2005 № 1411/11691

Стан: Чинний

Ідентифікатор: z1411-05

Текст документа від 14.11.2005:

МІНІСТЕРСТВО ОХОРОНИ ЗДОРОВ'Я УКРАЇНИ

НАКАЗ

14.11.2005 N 602

Зареєстровано в Міністерстві юстиції України 23 листопада 2005 р. за N 1411/11691

Про визнання такими, що втратили чинність, регуляторних актів, що не відповідають принципам державної регуляторної політики

Відповідно до Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Міністерства охорони здоров'я України, а саме:

- наказ від 09.11.2000 N 294 ( z0856-00 ) "Про затвердження форми Переліку лікарських засобів", зареєстрований у Міністерстві юстиції України 23.11.2000 за N 856/5077;

- наказ від 01.03.96 N 46 ( z0248-96 ) "Про затвердження Переліку лікарських засобів, необхідних до застосування при наданні медичної допомоги населенню України в 1996 році", зареєстрований у Міністерстві юстиції України 24.05.96 за N 248/1273;

- наказ від 16.08.96 N 259 ( z0639-96 ) "Щодо питань створення лікарських засобів", зареєстрований у Міністерстві юстиції України 31.10.96 за N 639/1664 (із змінами та доповненнями);

- наказ від 03.07.2001 N 261 ( z0867-01 ) "Про затвердження форми статистичної звітності N 1-ПФ (квартальна) "Звіт про виробництво й поставку лікарських засобів та виробів медичного призначення" та Інструкції щодо її заповнення", зареєстрований у Міністерстві юстиції України 08.10.2001 за N 867/6058;

- наказ від 18.08.95 N 153 ( z0359-95 ) "Про затвердження нормативних актів-переліків лікарських засобів", зареєстрований у Міністерстві юстиції України від 06.10.95 за N 359/895 (із змінами та доповненнями).

2. Державній службі лікарських засобів і виробів медичного призначення подати цей наказ на державну реєстрацію до Міністерства юстиції України в установленому законодавством порядку.

3. Контроль за виконанням цього наказу залишаю за собою.

Міністр Ю.В.Поляченко
