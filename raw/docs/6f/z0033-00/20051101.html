НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

N 38 від 18.01.2000 Зареєстровано в Міністерстві м.Київ юстиції України 21 січня 2000 р. vd20000118 vn38 за N 33/4254

( Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 856 ( za243-05 ) від 30.09.2005 )

Про внесення змін до Умов та Правил здійснення підприємницької діяльності (ліцензійних умов) з транспортування природного газу магістральними трубопроводами, затверджених постановою НКРЕ від 13.09.99 N 1195

Відповідно до пункту 3 Положення про Національну комісію регулювання електроенергетики України, затвердженого Указом Президента України від 14.03.95 N 213/95 (в редакції Указу Президента України від 21.04.98 N 335/98), із змінами, внесеними Указом Президента України від 01.02.99 N 108/99, та постанови Кабінету Міністрів України від 29.04.99 N 753 ( 753-99-п ) "Про порядок видачі ліцензій Національною комісією регулювання електроенергетики на здійснення окремих видів підприємницької діяльності" Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

Внести зміни до Умов та Правил здійснення підприємницької діяльності (ліцензійних умов) з транспортування природного газу магістральними трубопроводами, затверджених постановою НКРЕ від 13.09.99 N 1195 ( z0668-99 ), зареєстрованою в Міністерстві юстиції України 04.10.99 за N 668/3961, а саме:

пункт 2.3 викласти в такій редакції: "Ліцензіат не повинен займатися діяльністю з постачання природного газу, за винятком постачання газу в обсягах видобутку з родовищ, що перебувають у його користуванні, про що зазначається у графі ліцензії на постачання "Особливі умови та правила здійснення даного виду підприємницької діяльності".
