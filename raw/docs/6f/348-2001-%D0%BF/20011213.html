КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 квітня 2001 р. N 348 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )

Про внесення змін до ставок ввізного мита на окремі види товарів та до постанови Кабінету Міністрів України від 23 лютого 2001 р. N 170

Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита на окремі види товарів ( 4а-93, 4б-93, 4в-93 ) згідно з додатком.

2. У додатку до постанови Кабінету Міністрів України від 23 лютого 2001 р. N 170 ( 170-2001-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів та до постанови Кабінету Міністрів України від 12 січня 2001 р. N 16" (Офіційний вісник України, 2001 р., N 9, ст. 354) в описі товару за кодом згідно з ГС 85.44 11900 слова "поліамідною, поліамідно-фторопластовою" замінити словами "поліімідною, поліімідно-фторопластовою".
