Деякі питання забезпечення проведення новорічних і різдвяних свят для дітей

Стан: Чинний

Ідентифікатор: 1395-2009-п

Текст документа від 23.12.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 грудня 2009 р. N 1395 Київ

Деякі питання забезпечення проведення новорічних і різдвяних свят для дітей

Відповідно до Указу Президента України від 29 жовтня 2009 р. N 880 ( 880/2009 ) "Про заходи щодо проведення новорічних і різдвяних свят для дітей" Кабінет Міністрів України постановляє:

1. Міністерству у справах сім'ї, молоді та спорту забезпечити у грудні 2009 р. - січні 2010 р. проведення новорічних і різдвяних свят для дітей-сиріт, дітей, позбавлених батьківського піклування, дітей-інвалідів, дітей з малозабезпечених і багатодітних сімей, безпритульних дітей, дітей, потерпілих від наслідків Чорнобильської катастрофи, дітей військовослужбовців, журналістів і працівників органів внутрішніх справ, які загинули під час виконання службових обов'язків, та дітей загиблих шахтарів (далі - новорічні свята).

2. Установити, що попередня оплата товарів і послуг, які придбаваються у зв'язку з проведенням новорічних свят, може здійснюватися у розмірі 100 відсотків їх вартості на строк не більш як один місяць.

3. Погодитися з пропозицією Міністерства у справах сім'ї, молоді та спорту щодо здійснення закупівлі подарунків для проведення новорічних свят без застосування вимог Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006).

4. Пункт 2 Порядку використання у 2009 році коштів, передбачених у державному бюджеті для здійснення заходів державної політики з питань молоді, жінок та сім'ї, затвердженого постановою Кабінету Міністрів України від 2 квітня 2009 р. N 295 ( 295-2009-п ) (Офіційний вісник України, 2009 р., N 24, ст. 798, N 37, ст. 1243, N 54, ст. 1870), після абзацу сьомого доповнити новим абзацом такого змісту:

"Указом Президента України від 29 жовтня 2009 р. N 880 ( 880/2009 ) "Про заходи щодо проведення новорічних і різдвяних свят для дітей.".

У зв'язку з цим абзац восьмий вважати абзацом дев'ятим.
