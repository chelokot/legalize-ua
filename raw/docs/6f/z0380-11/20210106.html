НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

17.03.2011 N 344

Зареєстровано в Міністерстві юстиції України 21 березня 2011 р. за N 380/19118

{ Постанова втратила чинність на підставі Постанови Національної комісії, що здійснює державне регулювання у сферах енергетики та комунальних послуг N 15 ( v0015874-21 ) від 06.01.2021 }

Про внесення змін до постанови НКРЕ від 11.03.2010 N 218

Відповідно до Закону України "Про електроенергетику" ( 575/97-ВР ), Указу Президента України від 14.03.95 N 213 ( 213/95 ) "Про заходи щодо забезпечення діяльності Національної комісії з питань регулювання електроенергетики України" (зі змінами) Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. У пункті 1 постанови НКРЕ від 11.03.2010 N 218 ( z0241-10 ) "Про затвердження тарифів на електричну енергію для дитячих центрів "Артек" і "Молода гвардія", релігійних організацій та міського електричного транспорту", зареєстрованої в Міністерстві юстиції України 24.03.2010 за N 241/17536, цифри "26,4" замінити цифрами "30,4".

2. Управлінню цінової політики в електроенергетиці подати цю постанову на державну реєстрацію до Міністерства юстиції України в установленому законодавством порядку.

3. Ця постанова набирає чинності з 1 квітня 2011 року, але не раніше дня її офіційного опублікування.

Голова Комісії С.Тітенко
