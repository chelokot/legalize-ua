Про делегацію України для участі у переговорах з Європейським банком реконструкції та розвитку щодо підготовки проекту "Будівництво лінії електропередачі 330 кВ Аджалик - Усатове"

Стан: Втратив чинність

Ідентифікатор: 1235/2005-рп

Текст документа від 07.02.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у переговорах з Європейським банком реконструкції та розвитку щодо підготовки проекту "Будівництво лінії електропередачі 330 кВ Аджалик - Усатове"

1. Утворити делегацію України для участі у переговорах з Європейським банком реконструкції та розвитку щодо підготовки проекту "Будівництво лінії електропередачі 330 кВ Аджалик - Усатове" (листопад 2005 року, м. Лондон) у такому складі:

ТІТЕНКО Сергій Михайлович - заступник Міністра палива та енергетики України, глава делегації

АНДРІЄВА Тамара Володимирівна - директор департаменту міжнародного співробітництва Міністерства юстиції України

БЕРКУТА Анатолій Всеволодович - перший заступник Міністра будівництва, архітектури та житлово-комунального господарства України

БОРИСОВ Микола Андрійович - заступник директора департаменту стратегічного розвитку та інвестиційної політики Міністерства палива та енергетики України

ГАВРИЛЮК Олена Володимирівна - начальник юридичного управління Національної комісії регулювання електроенергетики України

КОЛОСОВА Вікторія Павлівна - директор департаменту співробітництва з міжнародними фінансовими організаціями Міністерства фінансів України

КУЧЕРЕНКО Олена Василівна - директор департаменту співробітництва з міжнародними фінансовими організаціями Міністерства економіки України

ЛУЧНІКОВ Володимир Андрійович - директор Державного підприємства "Національна енергетична компанія "Укренерго".

ТИШКЕВИЧ Оксана Миколаївна - заступник начальника Управління зовнішньоекономічної політики та міжнародного співробітництва Секретаріату Кабінету Міністрів України.

Дозволити главі делегації вносити в разі потреби за погодженням з Міністерством закордонних справ України зміни до складу делегації.

2. Кабінету Міністрів України затвердити директиви делегації України на переговори з Європейським банком реконструкції та розвитку щодо підготовки проекту "Будівництво лінії електропередачі 330 кВ Аджалик - Усатове".

3. Кабінету Міністрів України виділити кошти в іноземній валюті для забезпечення участі у переговорах Андрієвої Т.В., Беркути А.В., Борисова М.А., Гаврилюк О.В., Колосової В.П., Кучеренко О.В., Тітенка С.М., Тишкевич О.М.

Президент України В.ЮЩЕНКО
