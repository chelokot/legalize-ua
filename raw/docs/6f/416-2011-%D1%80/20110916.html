Про затвердження голів Української частини спільних міжурядових комісій з питань співробітництва

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 773-р ( 773-2011-р ) від 17.08.2011 N 799-р ( 799-2011-р ) від 22.08.2011 Постановою КМ N 944 ( 944-2011-п ) від 07.09.2011 }

1. Затвердити:

Клюєва Андрія Петровича - Першого віце-прем'єр-міністра України - Міністра економічного розвитку і торгівлі головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 1;

Колеснікова Бориса Вікторовича - Віце-прем'єр-міністра України - Міністра інфраструктури головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 2;

Близнюка Анатолія Михайловича - Міністра регіонального розвитку, будівництва та житлово-комунального господарства головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 3; { Абзац четвертий пункту 1 із змінами, внесеними згідно з Постановою КМ N 944 ( 944-2011-п ) від 07.09.2011 }

Тігіпка Сергія Леонідовича - Віце-прем'єр-міністра України - Міністра соціальної політики головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 4;

Бойка Юрія Анатолійовича - Міністра енергетики та вугільної промисловості головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 5;

Грищенка Костянтина Івановича - Міністра закордонних справ головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 6;

Колєснікова Дмитра Валерійовича - Голову Державного агентства України з управління державними корпоративними правами та майном головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 7.

2. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

ПЕРЕЛІК розпоряджень Кабінету Міністрів України, що втратили чинність

1. Розпорядження Кабінету Міністрів України від 24 березня 2010 р. N 686 ( 686-2010-р ) "Про затвердження Митника З.М. головою Української частини міжурядової українсько-кубинської комісії з питань торговельно-економічного та науково-технічного співробітництва".

2. Розпорядження Кабінету Міністрів України від 14 квітня 2010 р. N 889 ( 889-2010-р ) "Про затвердження Клюєва А.П. головою Української частини міжурядової українсько-білоруської змішаної комісії з питань торговельно-економічного співробітництва".

3. Розпорядження Кабінету Міністрів України від 28 квітня 2010 р. N 983 ( 983-2010-р ) "Про затвердження голів Української частини спільних міжурядових комісій з питань співробітництва".

4. Пункт 2 розпорядження Кабінету Міністрів України від 19 травня 2010 р. N 1107 ( 1107-2010-р ) "Про затвердження Азарова М.Я. головою Української частини Українсько-Лівійської двосторонньої комісії по співробітництву".

5. Розпорядження Кабінету Міністрів України від 15 вересня 2010 р. N 1842 ( 1842-2010-р ) "Про внесення зміни у додаток 4 до розпорядження Кабінету Міністрів України від 28 квітня 2010 р. N 983".

6. Пункт 2 розпорядження Кабінету Міністрів України від 15 грудня 2010 р. N 2366 ( 2366-2010-р ) "Про затвердження Бандурова В.В. головою Української частини спільних міжурядових комісій з питань співробітництва".
