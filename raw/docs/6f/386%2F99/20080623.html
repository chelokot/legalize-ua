{ Указ втратив чинність на підставі Указу Президента N 539/2008 ( 539/2008 ) від 11.06.2008 }

Про розміри надбавок до посадових окладів працівників органів прокуратури за класні чини

З метою закріплення кадрів в органах прокуратури України постановляю:

1. Затвердити нові розміри надбавок до посадових окладів працівників органів прокуратури за класні чини згідно з додатком.

2. Визнати такими, що втратили чинність:

Указ Президента України від 1 листопада 1994 року N 653 ( 653/94 ) "Про надбавки до посадових окладів працівників органів прокуратури за класні чини";

абзац другий статті 1 Указу Президента України від 19 січня 1996 року N 71 ( 71/96 ) "Про розміри надбавок до посадових окладів працівників органів прокуратури за класні чини та посадових окладів суддів за кваліфікаційні класи".

3. Цей Указ набирає чинності з 1 липня 1999 року.

Президент України Л.КУЧМА

м. Київ, 16 квітня 1999 року N 386/99
