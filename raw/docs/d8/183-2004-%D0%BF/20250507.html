КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 лютого 2004 р. N 183 Київ

Про управління державними корпоративними правами Національної акціонерної компанії "Надра України" і внесення змін до деяких постанов Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановами КМ N 568 ( 568-2005-п ) від 12.07.2005 N 502 ( 502-2025-п ) від 29.04.2025 }

На виконання Указу Президента України від 15 вересня 2003 р. N 1039 ( 1039/2003 ) "Про заходи щодо підвищення ефективності державного управління у сфері охорони навколишнього природного середовища та використання природних ресурсів" Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 568 ( 568-2005-п ) від 12.07.2005 )

2. Державному комітетові природних ресурсів визначити у місячний строк у встановленому порядку представника Комітету та укласти з ним договір доручення на виконання функцій з управління пакетом акцій Національної акціонерної компанії "Надра України".

3. Внести до постанов Кабінету Міністрів України зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 18 лютого 2004 р. N 183

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. В абзаці четвертому пункту 2 постанови Кабінету Міністрів України від 14 липня 2000 р. N 1128 ( 1128-2000-п ) "Про утворення Національної акціонерної компанії "Надра України" (Офіційний вісник України, 2000 р., N 29, ст. 1222) слова "та члени правління" виключити.

2. У другому реченні пункту 5 постанови Кабінету Міністрів України від 17 серпня 2000 р. N 1273 ( 1273-2000-п ) "Питання Національної акціонерної компанії "Надра України"(Офіційний вісник України, 2000 р., N 34, ст. 1432) слова "або управління будь-яким особам" виключити.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 502 ( 502-2025-п ) від 29.04.2025 }
