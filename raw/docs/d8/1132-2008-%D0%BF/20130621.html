Про межі акваторії морського порту Херсон

Стан: Чинний

Ідентифікатор: 1132-2008-п

Текст документа від 21.06.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 грудня 2008 р. N 1132 Київ

Про межі акваторії морського порту Херсон

{ Назва Постанови в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

{ Із змінами, внесеними згідно з Постановою КМ N 406 ( 406-2013-п ) від 03.06.2013 }

Кабінет Міністрів України постановляє:

1. Визначити межі акваторії морського порту Херсон згідно з додатком.

{ Пункт 1 в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

2. Державному підприємству "Адміністрація морських портів України" забезпечити безпеку мореплавства в межах акваторії, визначених у додатку.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 406 ( 406-2013-п ) від 03.06.2013 }

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

Додаток до постанови Кабінету Міністрів України від 27 грудня 2008 р. N 1132

МЕЖІ акваторії морського порту Херсон

{ Назва додатка в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

Акваторія порту включає:

акваторію рейду, верхня межа якого перетинає р. Дніпро, з'єднуючи точки з такими координатами:

46 град. 38' 03,0" північної широти, 32 град. 38' 02,0" східної довготи;

46 град. 37' 54,0" північної широти, 32 град. 38' 14,0" східної довготи;

водний простір вниз за течією затонів N 1 і 2, рукав р. Кошова до меридіана 32 град. 36' 00,0" східної довготи, акваторії річок Дніпро, Вільховий Дніпро, Рвач до меридіана 32 град. 18' 00,0" східної довготи;

акваторію підхідного каналу завширшки 50 метрів, що простягається від Херсонського морського каналу до кар'єру Рибальче, та власне кар'єр.
