КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 липня 1999 р. N 1394 Київ

( Постанова втратила чинність на підставі Постанови КМ N 946 ( 946-2001-п ) від 08.08.2001 )

Про утворення Координаційної ради з формування мережі регіональних агентств розвитку

З метою поглиблення економічних реформ на регіональному рівні, підтримки розвитку підприємництва та формування ринкової інфраструктури Кабінет Міністрів України постановляє:

1. Створити Координаційну раду з формування мережі регіональних агентств розвитку при Кабінеті Міністрів України.

2. Призначити Міністра Кабінету Міністрів України Толстоухова А.В. головою Координаційної ради з формування мережі регіональних агентств розвитку.

3. Голові Координаційної ради з формування мережі регіональних агентств розвитку в місячний термін:

затвердити персональний склад Координаційної ради;

( Склад ради див. в Розпорядженні КМ N 147-р ( 147-2000-р ) від 28.03.2000 )

забезпечити розроблення проектів Положення про Координаційну раду з формування мережі регіональних агентств розвитку і концепції створення мережі регіональних агентств розвитку та подати їх Кабінетові Міністрів України для затвердження.
