КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 липня 2010 р. N 638 Київ

Про Уповноваженого Кабінету Міністрів України з виконання Угоди між Урядом України та Урядом Республіки Молдова про спільне використання та охорону прикордонних вод та його заступників

{ Із змінами, внесеними згідно з Постановою КМ N 1347 ( 1347-2011-п ) від 28.12.2011 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 1347 ( 1347-2011-п ) від 28.12.2011 }

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 22

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 липня 2010 р. N 638

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 7 квітня 1995 р. N 251 ( 251-95-п ) "Про призначення уповноваженого Уряду України і його заступників з виконання Угоди про спільне використання та охорону прикордонних вод між Урядом України та Урядом Республіки Молдова".

2. Постанова Кабінету Міністрів України від 1 березня 1999 р. N 306 ( 306-99-п ) "Про заступників Уповноваженого Кабінету Міністрів України з виконання Угоди між Урядом України та Урядом Республіки Молдова про спільне використання та охорону прикордонних вод".

3. Постанова Кабінету Міністрів України від 9 серпня 2001 р. N 991 ( 991-2001-п ) "Про Уповноваженого Кабінету Міністрів України з виконання Угоди про спільне використання та охорону прикордонних вод між Урядом України та Урядом Республіки Молдова".

4. Постанова Кабінету Міністрів України від 28 липня 2004 р. N 956 ( 956-2004-п ) "Про Уповноваженого Кабінету Міністрів України з виконання Угоди про спільне використання та охорону прикордонних вод між Урядом України та Урядом Республіки Молдова та його заступника".
