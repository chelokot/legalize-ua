N 519 від 12.08.99 Зареєстровано в Міністерстві м.Київ юстиції України 27 серпня 1999 р. vd990812 vn519 за N 581/3874

( Наказ втратив чинність на підставі Наказу Державної митної служби N 405 ( z0603-00 ) від 26.07.2000 )

Про затвердження Порядку пропуску вантажів, які переміщуються міжнародними кур'єрськими службами між Бориспільською та Київською спеціалізованою митницями

Керуючися статтею 38 Митного кодексу України ( 1970-12 ), на виконання пункту 1.14 розділу 1 Положення про порядок контролю за ввезенням на митну територію України окремих видів товарів, затвердженого наказом Держмитслужби від 04.05.98 N 267 ( z0339-98 ) і зареєстрованого в Міністерстві юстиції України 21.05.98 за N 339/2779 (зі змінами, внесеними наказом Держмитслужби від 11.11.98 N 710 ( z0779-98 ) "Про затвердження змін і доповнень до Положення про порядок контролю за ввезенням на митну територію України окремих видів товарів", зареєстрованим у Міністерстві юстиції України 04.12.98 за N 779/3219), НАКАЗУЮ:

1. Затвердити Порядок пропуску вантажів, які переміщуються міжнародними кур'єрськими службами між Бориспільською та Київською спеціалізованою митницями (додається).

2. Такий же порядок пропуску вантажів, які переміщуються міжнародними кур'єрськими службами, застосовувати в інших митницях, куди надходять ці вантажі.

3. Скасувати листи Держмитслужби від 18.11.98 N 10/1-2798-ЕП ( v2798342-98 ) та від 22.06.99 N 09/1-1875-ЕП. 4. Управлінню організації митного контролю (Більчук О.С.), Правовому управлінню (Тимошенко С.В.) забезпечити в установлений термін державну реєстрацію цього наказу в Міністерстві юстиції України.

5. Контроль за виконанням цього наказу покласти на заступника Голови Служби Соболя І.М.

В.о. Голови Служби О.Б.Єгоров

ЗАТВЕРДЖЕНО наказом Державної митної служби України від 12 серпня 1999 р. N 519

Зареєстровано в Міністерстві юстиції України 27 серпня 1999 р. за N 581/3874

Порядок пропуску вантажів, які переміщуються міжнародними кур'єрськими службами між Бориспільською та Київською спеціалізованою митницями

1. Підрозділи Бориспільської митниці здійснюють пропуск через митний кордон України та направлення вантажів, які переміщуються міжнародними кур'єрськими службами (типу DXL International Ukraine, ELIN Ltd та інші), у Київську спеціалізовану митницю без застосування заходів нетарифного регулювання (подання митниці дозволів, ліцензій, сертифікатів тощо) та без подання попередньої (акцизної) вантажної митної декларації (далі - АД), попередньої вантажної митної декларації (далі - ПД), попереднього повідомлення (далі - ПП) для здійснення митного контролю та митного оформлення в зонах митного контролю, установлених Київською спеціалізованою митницею.

2. Підставою для пропуску вантажів, що переміщуються міжнародними кур'єрськими службами, на митну територію України і направлення в Київську спеціалізовану митницю є подання кур'єрськими службами Бориспільській митниці товаросупровідних документів (авіаційної транспортної накладної та маніфесту, який містить дані про одержувачів, скорочене найменування, кількість та вартість вантажів тощо; у разі надходження поодиноких вантажів - відповідно авіанакладної та інвойсу; при надходженні вантажів документарного характеру - авіанакладної).

3. Відділом оформлення кур'єрських служб Київської спеціалізованої митниці здійснюється митний контроль у частині подання митним органам належних дозвільних документів.

АД, ПД і ПП не застосовуються у разі направлення вантажів з Київської спеціалізованої митниці в митниці призначення для здійснення митного оформлення. Заходи нетарифного регулювання застосовуються в митницях призначення.

4. Митний контроль та митне оформлення вантажів, які вивозяться кур'єрськими службами з України, у частині передбаченого законодавством подання митним органам безпосередньо в пункті пропуску через митний кордон України належних дозвільних документів на вивезення окремих товарів (предметів), здійснювати в зонах митного контролю, визначених Київською спеціалізованою митницею.

5. Контроль за доставкою вантажів у митниці призначення здійснюється із застосуванням провізної відомості.

Заступник начальника Управління організації митного контролю О.В.Мещеряков
