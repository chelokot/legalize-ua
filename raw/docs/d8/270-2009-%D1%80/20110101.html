КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 березня 2009 р. N 270-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1898-р ( 1898-2010-р ) від 29.09.2010 }

Про надання повноважень на здійснення оптової торгівлі спиртом етиловим

1. Уповноважити Державний концерн спиртової та лікеро-горілчаної промисловості (концерн "Укрспирт") здійснювати оптову торгівлю спиртом етиловим за кодом згідно з УКТЗЕД 2207 ( 2371а-14 ).

2. Визнати таким, що втратило чинність з 1 квітня 2009 р., розпорядження Кабінету Міністрів України від 6 вересня 2005 р. N 390 ( 390-2005-р ) "Про надання повноважень на здійснення оптової торгівлі та експорту спирту етилового" (Офіційний вісник України, 2005 р., N 36, ст. 2204).
