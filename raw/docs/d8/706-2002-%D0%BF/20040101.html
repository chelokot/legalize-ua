Кабінет Міністрів України; Постанова від 30.05.2002 № 706

Про звільнення коштів, одержаних у вигляді гранту Президента України для обдарованої молоді, від обкладення прибутковим податком з громадян

Стан: Втратив чинність

Ідентифікатор: 706-2002-п

Текст документа від 01.01.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 травня 2002 р. N 706 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1628 ( 1628-2003-п ) від 15.10.2003 )

Про звільнення коштів, одержаних у вигляді гранту Президента України для обдарованої молоді, від обкладення прибутковим податком з громадян

Відповідно до пункту 5 статті 6 Декрету Кабінету Міністрів України від 26 грудня 1992 р. N 13-92 ( 13-92 ) "Про прибутковий податок з громадян" Кабінет Міністрів України постановляє:

Звільнити кошти, одержані у вигляді гранту Президента України для обдарованої молоді, від обкладення прибутковим податком з громадян.
