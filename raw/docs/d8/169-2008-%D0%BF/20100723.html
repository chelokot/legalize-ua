Кабінет Міністрів України; Постанова, Порядок від 12.03.2008 № 169

Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для виготовлення державних нагород та пам'ятних знаків

Стан: Чинний

Ідентифікатор: 169-2008-п

Текст документа від 23.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 березня 2008 р. N 169 Київ

Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для виготовлення державних нагород та пам'ятних знаків

{ Установити, що кошти, передбачені у державному бюджеті ( 835-17 ) для виготовлення державних нагород та пам'ятних знаків, використовуються у 2009 році відповідно до Порядку, затвердженого цією Постановою, з урахуванням того, що закупівля товарів, робіт і послуг здійснюється в установленому законодавством порядку, згідно з Постановою КМ N 182 ( 182-2009-п ) від 11.03.2009 }

{ Установити, що кошти, передбачені у державному бюджеті ( 2154-17 ) Державному управлінню справами за бюджетною програмою "Виготовлення державних нагород та пам'ятних знаків", використовуються у 2010 році відповідно до Порядку, затвердженого цією Постановою, з урахуванням особливостей, зазначених Постановою КМ N 575 ( 575-2010-п ) від 14.07.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для виготовлення державних нагород та пам'ятних знаків, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 12 березня 2008 р. N 169

ПОРЯДОК використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для виготовлення державних нагород та пам'ятних знаків

1. Цей Порядок визначає механізм використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) Державному управлінню справами за програмою "Виготовлення державних нагород та пам'ятних знаків" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Державне управління справами.

3. Бюджетні кошти спрямовуються на виготовлення державних нагород, визначених статтею 3 Закону України "Про державні нагороди України" ( 1549-14 ) (крім Державної премії України), бланків нагородних документів (орденська книжка, посвідчення, грамота), футлярів для нагород, оформлення бланків грамот (друкування текстів про нагородження державною нагородою) та реставрацію (оновлення) знаків державних нагород.

4. Перерахування бюджетних коштів здійснюється відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

5. Закупівля товарів, робіт і послуг здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

6. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
