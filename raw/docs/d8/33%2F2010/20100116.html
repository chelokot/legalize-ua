Президент України; Указ від 16.01.2010 № 33/2010

Про визнання такими, що втратили чинність, деяких положень Указу Президента України від 16 жовтня 2008 року N 941

Стан: Чинний

Ідентифікатор: 33/2010

Текст документа від 16.01.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання такими, що втратили чинність, деяких положень Указу Президента України від 16 жовтня 2008 року N 941

1. Визнати такими, що втратили чинність, пункт 2 статті 1, абзац другий статті 2, статтю 3, пункти 1, 3, підпункт "а" пункту 5 статті 4 та статтю 7 Указу Президента України від 16 жовтня 2008 року N 941 ( 941/2008 ) "Про вдосконалення мережі адміністративних судів України".

У зв'язку з цим в Указі Президента України від 16 листопада 2004 року N 1417 ( 1417/2004 ) "Про утворення місцевих та апеляційних адміністративних судів, затвердження їх мережі та кількісного складу суддів" (зі змінами, внесеними Указами від 16 травня 2007 року N 417 ( 417/2007 ) та від 16 жовтня 2008 року N 941) ( 941/2008 ):

відновити дію статті 1 та відповідних позицій додатків N 1 і N 3 до названого Указу ( 1417/2004 ) в редакції, що діяла до внесення до них змін положеннями Указу Президента України від 16 жовтня 2008 року N 941 ( 941/2008 ), які цим Указом визнані такими, що втратили чинність;

внести до розділу "Разом" додатка N 3 до названого Указу ( 1417/2004 ) зміну, замінивши цифри "1084" цифрами "1074".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 16 січня 2010 року N 33/2010
