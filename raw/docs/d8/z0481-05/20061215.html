Про встановлення щомісячної додаткової грошової винагороди окремим категоріям військовослужбовців

{ Із змінами, внесеними згідно з Наказами Міністерства оборони N 578 ( z1131-05 ) від 22.09.2005 N 27 ( z0082-06 ) від 24.01.2006 N 282 ( z0659-06 ) від 22.05.2006 N 683 ( z1264-06 ) від 28.11.2006 }

Відповідно до постанови Кабінету Міністрів України від 19 квітня 2005 року N 299 ( 299-2005-п ) "Про встановлення розміру додаткової грошової винагороди деяким категоріям військовослужбовців та іншим особам" з метою підвищення престижу військової служби за контрактом і залучення на військову службу за контрактом найбільш освічених і підготовлених громадян України НАКАЗУЮ:

1. Установити з 1 квітня 2005 року військовослужбовцям, які займають посади, передбачені Переліком посад прапорщиків (мічманів), солдатів (матросів), сержантів, старшин, які проходять військову службу за контрактом у Збройних Силах України, за якими встановлюється щомісячна додаткова грошова винагорода ( z0482-05 ), затвердженим пунктом 3 цього наказу, щомісячну додаткову грошову винагороду в розмірах:

солдатам (матросам), сержантам, старшинам, які проходять військову службу за контрактом, - від 100 до 300 грн;

прапорщикам (мічманам) - 100 грн.

Установити, що військовослужбовцям, які займають посади, передбачені пунктами 1381-1944 Переліку посад прапорщиків (мічманів), солдатів (матросів), сержантів, старшин, які проходять військову службу за контрактом у Збройних Силах України, за якими встановлюється щомісячна додаткова грошова винагорода ( z0482-05 ), щомісячна додаткова грошова винагорода виплачується з 1 січня 2006 року. { Абзац четвертий пункту 1 із змінами, внесеними згідно з Наказами Міністерства оборони N 282 ( z0659-06 ) від 22.05.2006, N 683 ( z1264-06 ) від 28.11.2006 }

З 1 червня 2006 року військовослужбовцям, які займають посади, передбачені пунктами 964, 1462, 1571, 1576 Переліку посад прапорщиків (мічманів), солдатів (матросів), сержантів, старшин, які проходять військову службу за контрактом у Збройних Силах України, за якими встановлюється щомісячна додаткова грошова винагорода ( z0482-05 ), щомісячну додаткову грошову винагороду не виплачувати. { Пункт 1 доповнено абзацом п'ятим згідно з Наказом Міністерства оборони N 282 ( z0659-06 ) від 22.05.2006 }

Установити, що військовослужбовцям, які займають посади, передбачені пунктами 1945-1958 Переліку посад прапорщиків (мічманів), солдатів (матросів), сержантів, старшин, які проходять військову службу за контрактом у Збройних Силах України, за якими встановлюється щомісячна додаткова грошова винагорода, щомісячна додаткова грошова винагорода виплачується з 1 січня 2007 року. { Пункт 1 доповнено абзацом шостим згідно з Наказом Міністерства оборони N 683 ( z1264-06 ) від 28.11.2006 }

( Пункт 1 в редакції Наказів Міністерства оборони N 578 ( z1131-05 ) від 22.09.2005, N 27 ( z0082-06 ) від 24.01.2006 )

2. Затвердити Інструкцію про порядок та умови виплати щомісячної додаткової грошової винагороди прапорщикам (мічманам), солдатам (матросам), сержантам, старшинам, які проходять військову службу за контрактом у Збройних Силах України, що додається.

3. Затвердити Перелік посад прапорщиків (мічманів), солдатів (матросів), сержантів, старшин, які проходять військову службу за контрактом у Збройних Силах України, за якими встановлюється щомісячна додаткова грошова винагорода, що додається ( z0482-05 ).

4. Наказ розіслати до окремої військової частини.

ЗАТВЕРДЖЕНО Наказ Міністра оборони України 25.04.2005 N 242

Зареєстровано в Міністерстві юстиції України 11 травня 2005 р. за N 481/10761

ІНСТРУКЦІЯ про порядок та умови виплати щомісячної додаткової грошової винагороди прапорщикам (мічманам), солдатам (матросам), сержантам, старшинам, які проходять військову службу за контрактом у Збройних Силах України

1. Ця Інструкція визначає порядок і умови виплати щомісячної додаткової грошової винагороди (далі - винагорода) прапорщикам (мічманам), солдатам (матросам), сержантам, старшинам, які проходять військову службу за контрактом у Збройних Силах України.

2. Виплата винагороди здійснюється за час фактичного виконання обов'язків за посадами (основними та тимчасово виконуваними), перелік яких затверджується наказом Міністра оборони України, з дня, з якого військовослужбовець став до виконання обов'язків за посадою, але не раніше дня видання наказу про призначення на посаду (допуску до тимчасового виконання обов'язків за посадою), і до дня звільнення військовослужбовця з посади або зарахування в розпорядження відповідного командира (начальника) включно.

3. Винагорода виплачується за місцем штатної служби за окремою роздавальною відомістю за минулий місяць одночасно з виплатою грошового забезпечення за поточний місяць.

4. Виплата винагороди здійснюється в межах фонду грошового забезпечення, затвердженого в кошторисах військових частин, установ та організацій.

5. Військовослужбовцям, яким виплачується винагорода, допущеним до тимчасового виконання обов'язків за посадами, за якими виплата винагороди не встановлена, за період тимчасового виконання обов'язків за цими посадами винагорода не виплачується.

6. Військовослужбовцям, які тимчасово вибули з військової частини, установи, організації (у відпустку, на лікування, у службове відрядження) із збереженням посад за місцем служби, виплата винагороди не припиняється.

7. Винагорода не включається до складу грошового забезпечення, з якого здійснюється обчислення пенсій та грошової допомоги при звільненні з військової служби.

Винагорода не включається до складу грошового забезпечення для розрахунку щомісячних та одноразових додаткових видів грошового забезпечення, включаючи премію.

8. Військовослужбовцям, які входять до складу: миротворчих контингентів та персоналу, спостерігачів, штабних елементів військових штабів НАТО, за якими зберігається виплата грошового забезпечення в національній валюті, за період виконання ними службових обов'язків за межами України також зберігається і виплата винагороди.

9. Підставою для виплати винагороди є наказ командира (начальника) військової частини (установи, організації).
