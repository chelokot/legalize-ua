Щодо визначення уповноважених організацій

На виконання вимог постанови Кабінету Міністрів України від 26.05.2004 N 687 ( 687-2004-п ) "Про затвердження Порядку проведення огляду, випробування та експертного обстеження (технічного діагностування) машин, механізмів, устатковання підвищеної небезпеки" (далі - Порядок) та з метою забезпечення суцільного технічного контролю за станом машин, механізмів, устатковання підвищеної небезпеки НАКАЗУЮ:

1. Для здійснення функцій, передбачених Порядком ( 687-2004-п ), а саме:

проведення первинного технічного огляду устатковання перед введенням його в експлуатацію;

проведення позачергового технічного огляду у разі закінчення граничного строку експлуатації, виникнення аварії або пошкодження, спричиненої надзвичайною ситуацією природного чи техногенного характеру;

ведення обліку даних про технічний стан устатковання -

визначити уповноважені організації за територіальною належністю, перелік яких додається.

2. Керівникам уповноважених організацій вжити необхідних заходів щодо організації виконання зазначених робіт відповідно до вимог Порядку ( 687-2004-п ).

3. Начальнику управління науково-технічного забезпечення державного нагляду Больману Г.О. подати цей наказ до Міністерства юстиції України для державної реєстрації.

4. Контроль за виконанням цього наказу покласти на заступника Голови Держнаглядохоронпраці України Плетньова В.А.

Голова Комітету С.Сторчак
