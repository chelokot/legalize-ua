N 611 від 21.12.99 Зареєстровано в Міністерстві м.Київ юстиції України 6 січня 2000 р. vd991221 vn611 за N 1/4222

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 1196 ( z0310-07 ) від 27.12.2006 }

Про внесення змін та доповнень до Правил перевезень пасажирів, багажу, вантажобагажу та пошти залізничним транспортом України

З метою поліпшення обслуговування громадян при користуванні залізничним транспортом, відповідно до Закону України "Про залізничний транспорт" ( 273/96-ВР ) та Порядку обслуговування громадян залізничним транспортом, затвердженого постановою Кабінету Міністрів України від 19 березня 1997 року N 252 ( 252-97-п ), НАКАЗУЮ:

1. Унести зміни та доповнення до Правил перевезень пасажирів, багажу, вантажобагажу та пошти залізничним транспортом України, затверджених наказом Міністерства транспорту України від 28 липня 1998 року N 297 ( z0620-98 ) і зареєстрованих Міністерством юстиції 1 жовтня 1998 року за N 620/3060, що додаються.

2. Першому заступнику Міністра транспорту України - Генеральному директору Укрзалізниці Слободяну А.В.:

2.1. Забезпечити подання цього наказу в установленому порядку до Міністерства юстиції України для державної реєстрації.

2.2. Довести наказ до відома працівників залізниць, відділків залізниць, організувати вивчення та виконання вимог цього наказу.

3. З уведенням у дію змін та доповнень до Правил перевезень пасажирів, багажу, вантажобагажу та пошти залізничним транспортом України визнати таким, що втратив чинність, наказ Міністерства транспорту України від 16.02.98 N 47 ( z0144-98 ) "Про встановлення знижки при проїзді залізничним транспортом у внутрішньодержавному сполученні орендованими туристськими поїздами", зареєстрований у Міністерстві юстиції України 03.03.98 за N 144/2584.

4. Контроль за виконанням цього наказу покласти на заступника Міністра транспорту України Демиденка А.Ф.

Міністр Л.М.Костюченко
