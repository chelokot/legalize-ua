Текст документа від 05.06.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 грудня 1999 р. N 2280 Київ

( Постанова втратила чинність на підставі Постанови КМ N 905 ( 905-2000-п ) від 05.06.2000 )

Про внесення зміни до постанови Кабінету Міністрів України від 18 червня 1999 р. N 1080

Кабінет Міністрів України постановляє:

1. Внести зміну до пункту 12 переліку постанов Кабінету Міністрів України про визначення товарів критичного імпорту, що втратили чинність, затвердженого постановою Кабінету Міністрів України від 18 червня 1999 р. N 1080 ( 1080-99-п ) (Офіційний вісник України, 1999 р., N 25, ст. 1167), виклавши його в такій редакції:

"12. Пункт 7 постанови Кабінету Міністрів України від 22 січня 1999 р. N 76 ( 76-99-п ) "Про заходи щодо підвищення ефективності використання закупленої під гарантії Кабінету Міністрів України сільськогосподарської техніки та порядок розрахунків за неї" (Офіційний вісник України, 1999 р., N 4, ст. 135).

2. Ця постанова набирає чинності з дня опублікування.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
