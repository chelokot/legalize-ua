Текст документа від 12.08.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Указу Президента України від 16 листопада 2004 року N 1417

Відповідно до пункту 23 частини першої статті 106 Конституції України ( 254к/96-ВР ) та статті 19 Закону України "Про судоустрій і статус суддів" ( 2453-17 ) постановляю:

1. Внести до додатка N 2 до Указу Президента України від 16 листопада 2004 року N 1417 ( 1417/2004 ) "Про утворення місцевих та апеляційних адміністративних судів, затвердження їх мережі та кількісного складу суддів" (зі змінами, внесеними Указом від 16 жовтня 2008 року N 941) ( 941/2008 ) такі зміни:

1) позицію "Київський апеляційний адміністративний суд" викласти в такій редакції:

"Київський апеляційний Київська, Черкаська, адміністративний суд Чернігівська області, місто Київ";

2) позицію "Львівський апеляційний адміністративний суд" викласти в такій редакції:

"Львівський апеляційний Волинська, Закарпатська, адміністративний суд Івано-Франківська, Львівська, Тернопільська області";

3) у позиції "Вінницький апеляційний адміністративний суд" слово "Черкаська" виключити;

4) у позиції "Житомирський апеляційний адміністративний суд" слово "Волинська" виключити.

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 12 серпня 2010 року N 812/2010
