Про внесення зміни до переліку вищих навчальних закладів, студенти яких проходять військову підготовку за програмою офіцерів запасу

Стан: Втратив чинність

Ідентифікатор: 1062-2003-п

Текст документа від 17.07.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 липня 2003 р. N 1062 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про внесення зміни до переліку вищих навчальних закладів, студенти яких проходять військову підготовку за програмою офіцерів запасу

Кабінет Міністрів України постановляє:

Розділ II переліку вищих навчальних закладів, студенти яких проходять військову підготовку за програмою офіцерів запасу, затвердженого постановою Кабінету Міністрів України від 26 липня 2001 р. N 866 ( 866-2001-п ) "Про військову підготовку студентів вищих навчальних закладів за програмою офіцерів запасу" (у редакції постанови Кабінету Міністрів України від 1 липня 2002 р. N 868) ( 868-2002-п ), після позиції "Дніпродзержинський державний технічний університет" доповнити такою позицією:

"Донбаська державна академія будівництва і архітектури".

Прем'єр-міністр України В.ЯНУКОВИЧ
