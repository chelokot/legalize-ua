Президент України; Указ від 01.03.2005 № 390/2005

Про членів наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України"

Стан: Втратив чинність

Ідентифікатор: 390/2005

Текст документа від 02.03.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про членів наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України"

{ Із змінами, внесеними згідно з Указом Президента N 182/2006 ( 182/2006 ) від 02.03.2006 }

Відповідно до статті 7 Закону України "Про банки і банківську діяльність" ( 2121-14 ) постановляю:

1. Призначити членами наглядової ради відкритого акціонерного товариства "Державний ощадний банк України":

БЕРАДЗЕ - заступника Міністра Кабінету

Георгія Риносійовича Міністрів України

ЗАЙЧУКА - Голову правління Пенсійного фонду

Бориса Олександровича України

РЕЗНІКОВА - керуючого партнера Адвокатської

Олексія Юрійовича компанії "ПРАВІС: Резніков, Власенко та партнери"

РИБАЧУК - Глава Секретаріату Президента

Олег Борисович України

ТРЕТЬЯКОВА - Першого помічника Президента України Олександра Юрійовича

ТОПОЛОВА - першого заступника Міністра палива Віктора Семеновича та енергетики України

ШАПОВАЛОВА - заступника Голови Національного

Анатолія Васильовича банку України { Пункт 1 із змінами, внесеними згідно з Указом Президента N 182/2006 ( 182/2006 ) від 02.03.2006 }

2. Припинити повноваження членів наглядової ради відкритого акціонерного товариства "Державний ощадний банк України": Гуржія С.Г., Дьоміна О.О., Коваленка В.В., Льовочкіна С.В., Першина В.Л., Рогового В.В., Ярошенка Ф.О.

3. Призначити членами наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України":

ГРИЩЕНКА - директора Товариства з обмеженою

Дмитра Івановича відповідальністю "Юридична і патентна фірма "Грищенко та партнери"

КИСЛИНСЬКОГО - координатора проектів Фонду

Андрія Миколайовича "Україна-3000"

ПРОХОРОВА - першого віце-президента Українського Сергія Мефодійовича союзу промисловців і підприємців

РИБАЧУК - Глава Секретаріату Президента

Олег Борисович України

МАКСЮТУ - першого заступника Міністра фінансів Анатолія Аркадійовича України

САВИЦЬКОГО - народного депутата України

Валентина Вікторовича (за згодою)

ЯРЕМЕНКА - заступника Голови Національного

Сергія Олександровича банку України { Пункт 3 із змінами, внесеними згідно з Указом Президента N 182/2006 ( 182/2006 ) від 02.03.2006 }

4. Припинити повноваження членів наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України": Гайдуцького П.І., Гуржія С.Г., Коваленка В.В., Льовочкіна С.В., Першина В.Л., Прутніка Е.А., Рогового В.В.

5. Визнати такими, що втратили чинність:

Указ Президента України від 19 березня 2003 року N 242 ( 242/2003 ) "Про призначення членів наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України";

Указ Президента України від 24 березня 2003 року N 258 ( 258/2003 ) "Питання наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України";

Указ Президента України від 9 вересня 2003 року N 1004 ( 1004/2003 ) "Про внесення змін до Указу Президента України від 19 березня 2003 року N 242".

Президент України В.ЮЩЕНКО
