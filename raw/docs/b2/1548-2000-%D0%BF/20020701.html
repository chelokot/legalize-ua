Текст документа від 01.07.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 жовтня 2000 р. N 1548 Київ

( Постанова втратила чинність на підставі Постанови КМ N 913 ( 913-2002-п ) від 01.07.2002 )

Про внесення змін до складу президії Вищої атестаційної комісії

Кабінет Міністрів України постановляє:

1. Внести до складу президії Вищої атестаційної комісії, затвердженого постановою Кабінету Міністрів України від 9 листопада 1998 р. N 1757 ( 1757-98-п ) (із змінами, внесеними постановами Кабінету Міністрів України від 22 лютого 1999 р. N 240 ( 240-99-п ) та від 2 березня 2000 р. N 444 ( 444-2000-п ), такі зміни:

ввести до складу президії Комісії Артюшина Леоніда Михайловича - доктора технічних наук, професора, вченого секретаря Вищої атестаційної комісії, затвердивши його секретарем президії Комісії;

вивести із складу президії Комісії Іванова Сергія Віталійовича і Степка Михайла Филимоновича;

увільнити від обов'язків секретаря президії Комісії Бойка Романа Володимировича, затвердивши його заступником голови президії Комісії.

2. Не для друку

Прем'єр-міністр України В.ЮЩЕНКО
