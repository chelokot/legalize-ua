Кабінет Міністрів України; Постанова від 17.08.1998 № 1313

Про внесення змін до додатка 1 до постанови Кабінету Міністрів України від 25 травня 1998 р. N 755

Стан: Втратив чинність

Ідентифікатор: 1313-98-п

Текст документа від 07.08.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 серпня 1998 р. N 1313 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1231 ( 1231-2000-п ) від 07.08.2000 )

( Постанова втратила чинність в частині, що стосується Міністерства закордонних справ на підставі Постанови КМ N 662 ( 662-99-п ) від 23.04.99 )

Про внесення змін до додатка 1 до постанови Кабінету Міністрів України від 25 травня 1998 р. N 755

( Із змінами, внесеними згідно з Постановою КМ N 1726 ( 1726-98-п ) від 02.11.98 )

Кабінет Міністрів України постановляє:

На часткову зміну додатка 1 до постанови Кабінету Міністрів України від 25 травня 1998 р. N 755 ( 755-98-п ) (Офіційний вісник України, 1998 р., N 22, ст. 800) затвердити граничну чисельність працівників центрального апарату:

Міністерства закордонних справ - 591 одиниця; ( Абзац із змінами, внесеними згідно з Постановою КМ N 1726 ( 1726-98-п ) від 02.11.98 )

Міністерства промислової політики - 678 одиниць, у тому числі Державного інвестиційно-клірингового комітету - 30 одиниць та Державного департаменту золотовидобувної та золотопереробної промисловості - 25 одиниць;

Головного управління геодезії, картографії та кадастру при Кабінеті Міністрів України - 49 одиниць.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
