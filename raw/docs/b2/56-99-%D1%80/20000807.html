Кабінет Міністрів України; Розпорядження від 28.01.1999 № 56-р

Про зміну додатка 2 до постанови Кабінету Міністрів України від 25 травня 1998 р. N 755

Стан: Втратив чинність

Ідентифікатор: 56-99-р

Текст документа від 07.08.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 січня 1999 р. N 56-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1231 ( 1231-2000-п ) від 07.08.2000 )

На часткову зміну додатка 2 до постанови Кабінету Міністрів України від 25 травня 1998 р. N 755 ( 755-98-п ) (Офіційний вісник України, 1998 р., N 22, ст. 800) встановити ліміт легкових автомобілів, що обслуговують Держспоживзахист, у кількості 3 одиниць.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
