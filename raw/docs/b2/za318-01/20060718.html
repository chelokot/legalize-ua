ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ПИТАНЬ РЕГУЛЯТОРНОЇ ПОЛІТИКИ ТА ПІДПРИЄМНИЦТВА

НАКАЗ

N 49 від 14.03.2001 Зареєстровано в Міністерстві юстиції України 6 квітня 2001 р. за N 318/5509

{ Наказ втратив чинність на підставі Наказу Державного комітету України з питань регуляторної політики та підприємництва N 56 ( za807-06 ) від 23.06.2006 }

Про затвердження Ліцензійних умов провадження професійної діяльності на ринку цінних паперів

{ Щодо змін до Ліцензійних умов ( z0318-01 )див. Накази Державного комітету України з питань регуляторної політики та підприємництва N 117 ( z1095-03 ) від 07.11.2003 N 137 ( z0029-04, za029-04 ) від 24.12.2003 }

Відповідно до Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ) НАКАЗУЮ:

1. Затвердити Ліцензійні умови провадження професійної діяльності на ринку цінних паперів ( z0318-01 ).

2. Управлінню ліцензування видів господарської діяльності Департаменту реєстрації та ліцензування (Єфремов О.В.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Голови Третьякова С.І.
