Кабінет Міністрів України; Постанова від 12.07.2005 № 550

Про утворення урядових органів державного управління у складі Міністерства охорони навколишнього природного середовища

Стан: Втратив чинність

Ідентифікатор: 550-2005-п

Текст документа від 17.03.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 липня 2005 р. N 550 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 200 ( 200-2012-п ) від 22.02.2012 }

Про утворення урядових органів державного управління у складі Міністерства охорони навколишнього природного середовища

{ Із змінами, внесеними згідно з Постановою КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність одночасно з набранням чинності Указом Президента ( 445/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

2. Міністерству охорони навколишнього природного середовища:

подати Кабінетові Міністрів України у двомісячний строк проекти положень про Державну службу геодезії, картографії та кадастру і Державну геологічну службу;

внести у тримісячний строк пропозиції щодо приведення актів Кабінету Міністрів України у відповідність із цією постановою та привести у відповідність з нею власні нормативно-правові акти.

Прем'єр-міністр України Ю.ТИМОШЕНКО
