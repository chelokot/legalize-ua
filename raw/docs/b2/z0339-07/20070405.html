МІНІСТЕРСТВО БУДІВНИЦТВА, АРХІТЕКТУРИ ТА ЖИТЛОВО-КОМУНАЛЬНОГО ГОСПОДАРСТВА УКРАЇНИ

НАКАЗ

05.04.2007 N 112

Зареєстровано в Міністерстві юстиції України 13 квітня 2007 р. за N 339/13606

Про визнання таким, що втратив чинність, наказу Міністерства будівництва, архітектури та житлово-комунального господарства України від 26.04.2006 N 142

У зв'язку з прийняттям наказу Міністерства будівництва, архітектури та житлово-комунального господарства України від 19.02.2007 N 60 ( z0223-07 ) "Про затвердження Порядку використання коштів державного бюджету для фінансової підтримки творчих спілок у сфері архітектури", зареєстрованого у Міністерстві юстиції України 14.03.2007 за N 223/13490, НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства будівництва, архітектури та житлово-комунального господарства України від 26.04.2006 N 142 ( z0555-06 ) "Про затвердження Порядку використання коштів державного бюджету для фінансової підтримки творчих спілок у сфері архітектури", зареєстрований у Міністерстві юстиції України 15.05.2006 за N 555/12429.
