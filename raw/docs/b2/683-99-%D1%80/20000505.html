Кабінет Міністрів України; Розпорядження від 14.07.1999 № 683-р

Про здійснення митного оформлення товарів, які надійшли на адресу ЗАТ "Ворскла" (м. Тростянець Сумської області)

Стан: Втратив чинність

Ідентифікатор: 683-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 липня 1999 р. N 683-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Держмитслужбі здійснити митне оформлення товарів, які надійшли на адресу ЗАТ "Ворскла" (м. Тростянець Сумської області), Головної державної інспекції з карантину рослин (м. Київ) та Української державної насіннєвої інспекції (м. Київ) згідно із зазначеними у додатку контрактами, укладеними в рамках Угоди про надання позики (Проект з розвитку насінництва) між Україною та Міжнародним банком реконструкції і розвитку ( 996_664 ) від 28 вересня 1995 р. N 3891 UA під гарантії Кабінету Міністрів України, ратифікованої Верховною Радою України 3 липня 1996 р., без справляння митного збору за їх перебування під митним контролем.
