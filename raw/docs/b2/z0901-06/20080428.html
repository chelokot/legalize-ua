Про затвердження форм Оголошень про проведення процедур закупівель та Інструкцій щодо їх заповнення

{ Із змінами, внесеними згідно з Розпорядженнями Антимонопольного комітету N 138-р ( z0463-07 ) від 12.04.2007 N 138-р ( z0465-07 ) від 12.04.2007 }

Відповідно до частини третьої статті 3-1, статей 8, 19 та 29-1 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ), Закону України "Про Антимонопольний комітет України" ( 3659-12 ) та з метою забезпечення державного контролю за додержанням законодавства щодо закупівель Антимонопольний комітет України ПОСТАНОВИВ:

1. Затвердити:

форму Оголошення про проведення відкритих торгів із зменшенням ціни, двоступеневих торгів та редукціону на закупівлю товарів, робіт і послуг за державні кошти (додається); { Абзац другий пункту 1 із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0463-07 ) від 12.04.2007 }

Інструкцію щодо заповнення форми Оголошення про проведення відкритих торгів із зменшенням ціни, двоступеневих торгів та редукціону на закупівлю товарів, робіт і послуг за державні кошти (додається); { Абзац третій пункту 1 із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0463-07 ) від 12.04.2007 }

форму Оголошення про проведення попередньої кваліфікації (додається) ( z0902-06 );

Інструкцію щодо заповнення форми Оголошення про проведення попередньої кваліфікації (додається) ( z0902-06 );

Примірну форму Оголошення про результати проведення торгів на закупівлю товарів, робіт і послуг за державні кошти (додається) ( z0903-06 );

Інструкцію щодо заповнення Примірної форми Оголошення про результати проведення торгів на закупівлю товарів, робіт і послуг за державні кошти (додається) ( z0903-06 ).

2. Установити, що оголошення стосовно державних закупівель надаються для публікації за формами та інструкціями щодо їх заповнення, затвердженими цим розпорядженням.

3. Департаменту конкурентної політики забезпечити в установленому порядку реєстрацію цього розпорядження в Міністерстві юстиції України.

ОГОЛОШЕННЯ про проведення відкритих торгів із зменшенням ціни, двоступеневих торгів та редукціону на закупівлю товарів, робіт і послуг за державні кошти

{ Назва Оголошення із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0465-07 ) від 12.04.2007 }

1. Інформація не для друку

1.1. Джерело фінансування закупівлі.

1.2. Розмір бюджетного призначення згідно з кошторисом або очікувана вартість закупівлі.

2. Замовник торгів

2.1. Повне найменування.

2.2. Ідентифікаційний код за ЄДРПОУ (не для друку).

{ Підпункт 2.2 пункту 2 із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0465-07 ) від 12.04.2007 }

2.3. Місцезнаходження.

2.4. Відповідальний за проведення торгів (прізвище, ім'я, по батькові, номер телефону та факсу із зазначенням коду міжміського телефонного зв'язку, E-mail за наявності).

2.5. Реєстраційний рахунок, який відкритий в органах Державного казначейства (для підприємств - найменування, МФО обслуговуючого банку та повний перелік відкритих поточних рахунків). { Пункт 2 доповнено підпунктом 2.5 згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0465-07 ) від 12.04.2007 }

3. Інформація про предмет закупівлі

3.1. Предмет закупівлі.

3.2. Кількість (у разі закупівлі товару).

3.3. Місце і строк (поставки, виконання робіт або надання послуг).

4. Процедура закупівлі.

5. Отримання тендерної документації

5.1. Місце.

5.2. Спосіб.

5.3. Розмір плати за тендерну документацію (якщо таку плату встановлено замовником).

6. Тендерне забезпечення

6.1. Спосіб (форма) надання.

6.2. Розмір.

7. Умови подання тендерних пропозицій

7.1. Місце.

7.2. Спосіб.

7.3. Кінцевий строк.

8. Розкриття тендерних пропозицій

8.1. Місце.

8.2. Дата.

9. Додаткова інформація

Адреса обраної замовником інформаційної системи у мережі Інтернет та код, присвоєний інформаційною системою в мережі Інтернет.

Зареєстровано в Міністерстві юстиції України 1 серпня 2006 р. за N 901/12775

ІНСТРУКЦІЯ щодо заповнення форми Оголошення про проведення відкритих торгів із зменшенням ціни, двоступеневих торгів та редукціону на закупівлю товарів, робіт і послуг за державні кошти

{ Заголовок Інструкції із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0465-07 ) від 12.04.2007 }

1. Оголошення подається лише стосовно одного окремого предмета закупівлі, що зазначається у пункті 3 Оголошення.

2. Оголошення готується державною мовою, засвідчується печаткою замовника.

3. Щодо пункту 1 Оголошення

Джерело фінансування закупівлі визначається відповідно до абзацу п'ятого статті 1 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ). Розмір бюджетного призначення або очікувана вартість закупівлі зазначається у гривнях (цифрами та словами).

4. Щодо пункту 2 Оголошення

Замовник визначається відповідно до абзаців другого, третього і двадцять четвертого статті 1 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ). При цьому замовником вважається суб'єкт, тендерний комітет якого проводить процедуру закупівлі.

У підпункті 2.3 Оголошення зазначаються найменування населеного пункту, району, адміністративно-територіального суб'єкта (область, Автономна Республіка Крим, місто Київ або Севастополь), вулиця, номер будинку, поштовий індекс.

5. Щодо пункту 3 Оголошення

Предмет закупівлі визначається у порядку, затвердженому Міжвідомчою комісією з питань державних закупівель.

У разі поділу предмета закупівлі на частини (лоти) замовник повинен зазначати назву кожної окремої частини предмета закупівлі та їх кількість.

{ Пункт 5 в редакції Розпорядження Антимонопольного комітету N 138-р ( z0465-07 ) від 12.04.2007 }

6. Щодо пункту 5 Оголошення

Щодо підпункту 5.1 Оголошення зазначаються найменування населеного пункту, району, адміністративно-територіального суб'єкта (область, Автономна Республіка Крим, місто Київ або Севастополь), вулиця, номер будинку, поштовий індекс.

Щодо підпункту 5.2 Оголошення зазначається спосіб отримання тендерної документації (особисто або поштою), яка готується замовником та передається учасникам.

Щодо підпункту 5.3 Оголошення розмір плати за тендерну документацію у гривнях (цифрами та словами) зазначається лише в тому випадку, коли така плата вимагається замовником.

Якщо замовник не вимагає плати за тендерну документацію, робиться запис "Плата не вимагається".

7. Щодо пункту 6 Оголошення

Щодо підпункту 6.1 Оголошення спосіб надання тендерного забезпечення визначається замовником відповідно до абзацу вісімнадцятого статті 1 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

Щодо підпункту 6.2 Оголошення розмір тендерного забезпечення визначається відповідно до частин першої та другої статті 23 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ) у гривнях (цифрами та словами), виходячи з очікуваної вартості закупівлі. { Абзац третій пункту 7 із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0465-07 ) від 12.04.2007 }

У разі поділу предмета закупівлі на частини (лоти) замовник повинен зазначити розмір тендерного забезпечення за кожною з частин предмета закупівлі (лотів) з урахуванням умов статті 23 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ). { Пункт 7 доповнено абзацом згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0465-07 ) від 12.04.2007 }

8. Щодо пункту 7 Оголошення

Щодо підпункту 7.1 Оголошення зазначаються назва адміністративно-територіального суб'єкта (область, Автономна Республіка Крим, місто Київ або Севастополь), населений пункт, поштовий індекс, вулиця, номер будинку.

Щодо підпункту 7.2 Оголошення зазначається спосіб подання тендерних пропозицій (особисто та/або поштою).

Щодо підпункту 7.3 Оголошення строк для подання тендерних пропозицій встановлюється згідно з частиною третьою статті 19, статтею 31 (у разі застосування процедури двоступеневих торгів) та статтею 29-3 (у разі застосування процедури редукціону) Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ). { Абзац четвертий пункту 8 в редакції Розпорядження Антимонопольного комітету N 138-р ( z0465-07 ) від 12.04.2007 }

9. Щодо пункту 8 Оголошення

Зазначаються найменування населеного пункту, району, адміністративно-територіального суб'єкта (область, Автономна Республіка Крим, місто Київ або Севастополь), вулиця, номер будинку, поштовий індекс, номер кімнати. Відповідно до частини першої статті 26 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ) розкриття тендерних пропозицій здійснюється у день закінчення строку їх подання у час та в місці, зазначених у тендерній документації.

10. Щодо пункту 9 Оголошення

У цьому пункті замовник зазначає таку інформацію:

способи зв'язку для отримання додаткової інформації;

{ Абзац четвертий пункту 10 виключено на підставі Розпорядження Антимонопольного комітету N 138-р ( z0465-07 ) від 12.04.2007 }

щодо відповідної належності закупівлі, якщо закупівля здійснюється у межах державного замовлення або державного оборонного замовлення;

основні кваліфікаційні вимоги відповідно до статті 15 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ), яким повинні відповідати учасники процедури закупівлі. Детальна інформація зазначається у тендерній документації.
