Вищий арбітражний суд; Постанова від 12.06.2001

Цивільні права і обов'язки не виникають з угод, укладених підприємством, якщо воно не набуло цивільної правоздатності відповідно до вимог закону

Стан: Втратив чинність

Ідентифікатор: n0022800-01

Текст документа від 28.01.2002:

ВИЩИЙ АРБІТРАЖНИЙ СУД УКРАЇНИ

ПОСТАНОВА

12.06.2001

( Постанову скасовано на підставі Постанови Верховного Суду ( n0161700-02 ) від 28.01.2002 )

Судова колегія по перегляду рішень, ухвал, постанов Вищого арбітражного суду України перевірила постанову арбітражного суду Автономної Республіки Крим у справі за позовом підприємства "Юг-Енерго" до ТОВ "Фірма "Гаск" про стягнення 56000 грн. збитків.

Рішенням арбітражного суду Автономної Республіки Крим від 05-16.10.98 позов задоволено.

З відповідача ТОВ "Фірма "Гаск" на користь підприємства "Юг-Енерго" стягнуто 56000 грн. збитків.

В зустрічному позові відмовлено.

Голова арбітражного суду Автономної Республіки Крим, здійснивши ініціативний нагляд у справі (стаття 92 АПК ( 1798-12 ), постановою від 12.01.2000 рішення арбітражного суду у справі скасував, в позові відмовив.

При цьому визнані недійсними угоди N 05 від 07.02.97, що укладались підприємствами "Автоком" та "Сімоптторг", від 22.07.97 - підприємствами "Автоком" та "Юг-Енерго".

При проведенні ініціативного нагляду у справі (стаття 92 АПК ( 1798-12 ) встановлено таке. Рішення арбітражного суду Автономної Республіки Крим у даній справі ухвалено 05-16.10.98.

Відповідно до статті 104 ( 1798-12 ) АПК рішення, ухвала та постанова арбітражного суду можуть бути перевірені в порядку нагляду не пізніше одного року з дня їх прийняття.

Фактично головою арбітражного суду Автономної Республіки Крим нагляд у справі проведено з порушенням вимог статті 104 АПК ( 1798-12 ), тобто за межами одного року.

З урахуванням зазначеного, постанова арбітражного суду Автономної Республіки Крим у даній справі підлягає скасуванню як така, що ухвалена з порушенням процесуального законодавства.

Перевірка постанови арбітражного суду у відповідності зі статтею 104 АПК ( 1798-12 ) проводилась без участі сторін.

Керуючись статтями 106, 108 АПК ( 1798-12 ), судова колегія по перегляду рішень, ухвал, постанов Вищого арбітражного суду України ПОСТАНОВИЛА:

постанову арбітражного суду Автономної Республіки Крим від 12.01.2000 у справі N 5048-5 скасувати.

Рішення у цій справі від 05-16.10.98 залишити без зміни.
