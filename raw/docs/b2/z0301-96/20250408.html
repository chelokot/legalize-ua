{ Наказ скасовано на підставі Розпорядження КМ N 317-р ( 317-2025-р ) від 08.04.2025 }

Про внесення змін до Інструкції по використанню форм документів суворої звітності

Відповідно до листа Антимонопольного комітету України від 18.03.96 N 23-11/10-962 НАКАЗУЮ:

Внести зміни до Інструкції по використанню форм документів суворої звітності, що застосовуються для оформлення замовлень та розрахунків із споживачами за побутові послуги, затверджені наказом Укрсоюзсервісу від 29.09.95 N 8 ( z0389-95 ) (зареєстрована в Мінюсті України 25.10.95 N 389/925), виклавши абзац восьмий пункту 1.4 в такій редакції:

"Бланки цих форм повинні замовлятися та друкуватися в основному на підприємствах "Укрбланковидав" з друкарською нумерацією".

Президент А.Я.Гіль
