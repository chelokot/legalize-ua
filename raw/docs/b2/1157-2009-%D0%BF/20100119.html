Про спрямування коштів Стабілізаційного фонду на підготовку об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

Ідентифікатор: 1157-2009-п

Текст документа від 19.01.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 жовтня 2009 р. N 1157 Київ

Про спрямування коштів Стабілізаційного фонду на підготовку об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

{ Із змінами, внесеними згідно з Постановами КМ N 1388 ( 1388-2009-п ) від 16.12.2009 N 1427 ( 1427-2009-п ) від 29.12.2009 }

Відповідно до статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) Кабінет Міністрів України постановляє:

1. Спрямувати за рахунок коштів Стабілізаційного фонду, передбачених пунктом 22 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) за напрямом "Інші витрати", на підготовку об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу 1494822,5 тис. гривень, у тому числі 701069,5 тис. - Міністерству транспорту та зв'язку, 664101,8 тис. - Міністерству у справах сім'ї, молоді та спорту, 80000 тис. - Міністерству з питань житлово-комунального господарства, 2051,2 тис. - Міністерству культури і туризму, 47600 тис. гривень - Міністерству фінансів.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1388 ( 1388-2009-п ) від 16.12.2009 }

2. Затвердити Порядок використання у 2009 році коштів Стабілізаційного фонду для підготовки об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, що додається.

3. Забезпечити:

Міністерству фінансів - внесення відповідних змін до розпису державного бюджету;

Державному казначейству - перерахування коштів Стабілізаційного фонду, зазначених у пункті 1 цієї постанови.

4. Міністерству транспорту та зв'язку, Міністерству у справах сім'ї, молоді та спорту, Міністерству з питань житлово-комунального господарства, Міністерству культури і туризму, Міністерству фінансів погодити передбачений пунктом 1 цієї постанови розподіл коштів Стабілізаційного фонду з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 1388 ( 1388-2009-п ) від 16.12.2009 }

5. Міністерству фінансів та Державному казначейству забезпечити відповідно внесення змін до розпису державного бюджету та перерахування коштів Стабілізаційного фонду, передбачених у пункті 1 цієї постанови Міністерству культури і туризму, до погодження з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету.

{ Постанову доповнено пунктом 5 згідно з Постановою КМ N 1427 ( 1427-2009-п ) від 29.12.2009 }

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 44

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 жовтня 2009 р. N 1157

ПОРЯДОК використання у 2009 році коштів Стабілізаційного фонду для підготовки об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

1. Цей Порядок визначає механізм використання у 2009 році коштів Стабілізаційного фонду за напрямом, передбаченим пунктом 22 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), для підготовки об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються на виконання завдань і заходів, передбачених пунктами 1-3, 7 і 8 додатка 2 до Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженої постановою Кабінету Міністрів України від 22 лютого 2008 р. N 107 ( 107-2008-п ) (Офіційний вісник України, 2008 р., N 18, ст. 482; 2009 р., N 59, ст. 2067), в таких обсягах (тис. гривень):

504298,3 - на реконструкцію Національного спортивного комплексу "Олімпійський";

50000 - на будівництво стадіону в м. Львові;

106600 - на завершення реконструкції стадіону комунального підприємства "Обласний спортивний комплекс "Металіст";

3203,5 - на реконструкцію стадіону Львівського державного університету фізичної культури;

701069,5 - на проектування, будівництво, реконструкцію і ремонт аеропортів;

47600 - на створення та підготовку об'єктів інфраструктури Національного університету державної податкової служби до проведення фінальної частини чемпіонату Європи 2012 року з футболу;

80000 - на будівництво другої нитки Головного міського каналізаційного колектора в м. Києві (ділянка на території Національного спортивного комплексу "Олімпійський");

2051,2 - на ремонт і реставрацію будівель та приміщень Львівського національного академічного театру опери та балету імені С. Крушельницької. { Пункт 2 доповнено абзацом згідно з Постановою КМ N 1388 ( 1388-2009-п ) від 16.12.2009 }

3. Головними розпорядниками бюджетних коштів є Мінсім'ямолодьспорт, Мінтрансзв'язку, Мінжитлокомунгосп, МКТ і Мінфін.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1388 ( 1388-2009-п ) від 16.12.2009 }

4. Бюджетні кошти виділяються на безповоротній основі та з урахуванням Порядку використання у 2009 році коштів Стабілізаційного фонду, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) "Питання використання у 2009 році коштів Стабілізаційного фонду" (Офіційний вісник України, 2009 р., N 24, ст. 793).

5. Державне казначейство відкриває бюджетне асигнування головним розпорядникам бюджетних коштів відповідно до розпису державного бюджету та за умови відсутності на їх рахунках залишків бюджетних коштів за відповідними бюджетними програмами.

6. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

7. Головні розпорядники бюджетних коштів беруть бюджетні зобов'язання виключно у межах фактично перерахованих на рахунки коштів.

8. Фінансування об'єктів капітального будівництва здійснюється відповідно до Порядку державного фінансування капітального будівництва, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) (Офіційний вісник України, 2001 р., N 52, ст. 2374).

9. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів та їх попередня оплата здійснюється в установленому законодавством порядку.

10. Державне казначейство щомісяця до 16 числа подає Мінфіну інформацію про використання бюджетних коштів у розрізі їх головних розпорядників, бюджетних програм, заходів та об'єктів.

11. Головні розпорядники бюджетних коштів щомісяця до 10 числа подають Мінфіну звіт про використання бюджетних коштів за встановленою ним формою.

12. Після закінчення бюджетного періоду залишки бюджетних коштів, що обліковуються на рахунках головних розпорядників станом на 1 січня 2010 р., повертаються до Стабілізаційного фонду.

13. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням і своєчасним поверненням здійснюються в установленому законодавством порядку.
