ПОСТАНОВА від 18 січня 2003 р. N 52 Київ

( Постанова втратила чинність на підставі Постанови КМ N 790 ( 790-2005-п ) від 22.08.2005 )

Про внесення зміни у додаток до постанови Кабінету Міністрів України від 1 липня 2002 р. N 890

Кабінет Міністрів України постановляє:

Пункт 2 додатка до постанови Кабінету Міністрів України від 1 липня 2002 р. N 890 ( 890-2002-п ) "Про умови оплати праці працівників національних закладів культури" (Офіційний вісник України, 2002 р., N 27, ст. 1267) доповнити позицією такого змісту:

"Національного Одеського філармонійного оркестру".
