Про подальше впорядкування умов оплати праці працівників національних закладів культури

Стан: Втратив чинність

Текст документа від 01.09.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 серпня 2004 р. N 995 Київ

( Постанова втратила чинність на підставі Постанови КМ N 790 ( 790-2005-п ) від 22.08.2005 )

Про подальше впорядкування умов оплати праці працівників національних закладів культури

З метою державної підтримки національних закладів культури Кабінет Міністрів України постановляє:

1. Підвищити з 1 січня 2005 р. у два рази діючі станом на 1 березня 2004 р. максимальні посадові оклади (ставки заробітної плати) керівників, керівників структурних підрозділів, фахівців та робітників, які безпосередньо здійснюють творчі, музейні, бібліотечні, науково-дослідні, культурно-освітні функції, а також функції з охорони культурної спадщини національних закладів, розміри яких визначено відповідно до постанов Кабінету Міністрів України від 15 жовтня 2001 р. N 1345 ( 1345-2001-п ) "Про оплату праці працівників національних закладів культури" (Офіційний вісник України, 2001 р., N 42, ст. 1889; 2004 р., N 16, ст. 115), від 11 квітня 2002 р. N 493 ( 493-2002-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників Національного заповідника "Софія Київська" (Офіційний вісник України, 2002 р., N 15, ст. 810), від 1 липня 2002 р. N 889 ( 889-2002-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників Національного академічного українського драматичного театру імені Марії Заньковецької" (Офіційний вісник України, 2002 р., N 27, ст. 1266), від 1 липня 2002 р. N 890 ( 890-2002-п ) "Про умови оплати праці працівників національних закладів культури" (Офіційний вісник України, 2002 р., N 27, ст. 1267; 2003 р., N 4, ст. 113), від 11 лютого 2004 р. N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" (Офіційний вісник України, 2004 р., N 6, ст. 334).

2. Національним закладам культури передбачати видатки на преміювання своїх працівників у розмірі не менше ніж 3 відсотки планового фонду заробітної плати.

3. Міністерству культури і мистецтв за погодженням з Міністерством праці та соціальної політики, Міністерством фінансів привести власні нормативно-правові акти з питань оплати праці працівників національних закладів культури у відповідність з цією постановою.
