Текст документа від 14.11.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 квітня 2006 р. N 246-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 996-р ( 996-2007-р ) від 14.11.2007 }

Про зміну складу осіб, уповноважених представляти інтереси держави у правлінні Фонду соціального страхування з тимчасової втрати працездатності

Ввести до складу осіб, уповноважених представляти інтереси держави у правлінні Фонду соціального страхування з тимчасової втрати працездатності, затвердженого розпорядженням Кабінету Міністрів України від 13 квітня 2005 р. N 94 ( 94-2005-р ) (Офіційний вісник України, 2005 р., N 15, ст. 780), Антоненка Тараса Володимировича - директора департаменту Мінпраці, вивівши із зазначеного складу Скрипник Олену Петрівну.
