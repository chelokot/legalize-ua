КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 травня 2007 р. N 347-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 19-р ( 19-2012-р ) від 11.01.2012 }

Деякі питання Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття

1. Зупинити дію розпорядження Кабінету Міністрів України від 21 лютого 2007 р. N 59 ( 59-2007-р ) "Про затвердження складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття" (Офіційний вісник України, 2007 р., N 14, ст. 536) на період до проведення першого засідання нового складу правління Фонду.

У зв'язку з цим відновити дію розпоряджень згідно з переліком, що додається.

2. Ввести до складу наглядової ради Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття Богословську Інну Германівну - заступника Міністра юстиції, вивівши з його складу Горбунову Лідію Миколаївну.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 26

Додаток до розпорядження Кабінету Міністрів України від 26 травня 2007 р. N 347-р

ПЕРЕЛІК розпоряджень Кабінету Міністрів України, дія яких відновлюється

1. Розпорядження Кабінету Міністрів України від 28 березня 2005 р. N 70 ( 70-2005-р ) "Про затвердження складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття" (Офіційний вісник України, 2005 р., N 13, ст. 672).

2. Розпорядження Кабінету Міністрів України від 21 грудня 2005 р. N 549 ( 549-2005-р ) "Про зміну складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття" (Офіційний вісник України, 2005 р., N 52, ст. 3346).

3. Розпорядження Кабінету Міністрів України від 27 квітня 2006 р. N 248 ( 248-2006-р ) "Про зміну складу осіб, уповноважених представляти інтереси держави у правлінні Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття" (Офіційний вісник України, 2006 р., N 18, ст. 1354).

4. Пункт 1 розпорядження Кабінету Міністрів України від 15 вересня 2006 р. N 488 ( 488-2006-р ) "Про зміни складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів загальнообов'язкового державного соціального страхування" (Офіційний вісник України, 2006 р., N 38, ст. 2597).
