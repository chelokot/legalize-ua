{ Наказ втратив чинність на підставі Наказу Міністерства економіки N 139 ( z0525-06 ) від 17.04.2006 }

Про затвердження змін та доповнень до Порядку погодження Міністерством економіки та з питань європейської інтеграції України застосування замовниками окремих процедур державних закупівель, затвердженого наказом Міністерства економіки України від 07.12.2000 N 268, зареєстрованого в Міністерстві юстиції України 21.12.2000 за N 933/5154

Відповідно до постанови Кабінету Міністрів України від 27.09.2000 N 1469 ( 1469-2000-п ) "Про організаційні заходи щодо функціонування системи державних закупівель" НАКАЗУЮ:

1. Затвердити зміни та доповнення до Порядку погодження Міністерством економіки та з питань європейської інтеграції України застосування замовниками окремих процедур державних закупівель, затвердженого наказом Міністерства економіки України від 07.12.2000 N 268 ( z0933-00 ), зареєстрованого в Міністерстві юстиції України 21.12.2000 за N 933/5154 (додаються).

2. Управлінню методології, правового забезпечення та контролю у сфері державних закупівель забезпечити:

реєстрацію в установленому порядку цього наказу в Міністерстві юстиції України;

опублікування цього наказу в інформаційно-аналітичному бюлетені "Вісник державних закупівель".

3. Цей наказ набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

Міністр М. Деркач
