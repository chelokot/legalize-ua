ПОРЯДОК складання та передачі за належністю довідки про порушення бюджетного законодавства

{ Заголовок Порядку із змінами, внесеними згідно з Наказом Міністерства фінансів N 483 ( z0532-11 ) від 11.04.2011 }

{ У тексті Порядку слова "орган, що здійснює контроль" у всіх відмінках замінено словами "контролюючий орган" у відповідних відмінках, слова "нецільове використання бюджетних коштів" у всіх відмінках замінено словами "порушення бюджетного законодавства" у відповідних відмінках, слова "місцевого фінансового органу" у всіх відмінках замінено словами "місцевого фінансового органу, головного розпорядника коштів відповідного бюджету" у відповідних відмінках згідно з Наказом Міністерства фінансів N 483 ( z0532-11 ) від 11.04.2011 }

1. Довідка про порушення бюджетного законодавства (далі - довідка) - документ про порушення учасниками бюджетного процесу бюджетного законодавства, в якому зазначаються факти нецільового використання бюджетних коштів розпорядниками бюджетних коштів; здійснення видатків бюджету чи надання кредитів з бюджету без встановлених бюджетних призначень або з їх перевищенням всупереч Бюджетному кодексу України ( 2456-17 ) чи закону про Державний бюджет України на відповідний рік; здійснення видатків на утримання бюджетної установи одночасно з різних бюджетів всупереч Бюджетному кодексу України чи закону про Державний бюджет України на відповідний рік, документально засвідчені в акті ревізії, та інші реквізити, передбачені цим Порядком.

{ Пункт 1 в редакції Наказу Міністерства фінансів N 483 ( z0532-11 ) від 11.04.2011 }

2. Довідка складається посадовою особою органу, уповноваженого здійснювати контроль за дотриманням бюджетного законодавства (далі - контролюючий орган), та підписується керівником відповідного контролюючого органу, в день підписання керівником органу, що здійснює контроль, акта ревізії.

{ Пункт 2 із змінами, внесеними згідно з Наказом Міністерства фінансів N 483 ( z0532-11 ) від 11.04.2011 }

3. Протягом десяти робочих днів з дати реєстрації акта ревізії, а в разі наявності заперечень (зауважень) до акта ревізії - з дати подання письмового висновку щодо таких заперечень (зауважень) довідка разом із копією акта ревізії передаються контролюючим органом до Міністерства фінансів України (місцевого фінансового органу, головного розпорядника коштів відповідного бюджету).

{ Пункт 3 в редакції Наказу Міністерства фінансів N 483 ( z0532-11 ) від 11.04.2011 }

4. У довідці зазначаються:

дата і місце її складання;

відомості про учасника бюджетного процесу, яким здійснено порушення бюджетного законодавства (повна назва, місцезнаходження; прізвище, ім'я, по батькові керівника; реквізити відповідного бюджету; код і назва відомчої класифікації видатків та кредитування державного бюджету); { Абзац третій пункту 4 із змінами, внесеними згідно з Наказом Міністерства фінансів N 483 ( z0532-11 ) від 11.04.2011 }

код і назва програмної класифікації видатків та кредитування державного бюджету (тимчасової класифікації видатків та кредитування місцевих бюджетів), за якою встановлено факт порушення бюджетного законодавства; { Абзац четвертий пункту 4 із змінами, внесеними згідно з Наказом Міністерства фінансів N 483 ( z0532-11 ) від 11.04.2011 }

код економічної класифікації видатків бюджету (загальний та спеціальний фонд) та код класифікації кредитування бюджету, за якими встановлено факт порушення бюджетного законодавства; { Абзац п'ятий пункту 4 із змінами, внесеними згідно з Наказом Міністерства фінансів N 483 ( z0532-11 ) від 11.04.2011 }

період здійснення порушення бюджетного законодавства; { Абзац шостий пункту 4 із змінами, внесеними згідно з Наказом Міністерства фінансів N 483 ( z0532-11 ) від 11.04.2011 }

факт (зміст і характер) порушення бюджетного законодавства із зазначенням положень законодавчих або інших нормативно-правових актів, які порушені;

сума, на яку виявлено факт порушення бюджетного законодавства у поточному бюджетному періоді;

назва контролюючого органу;

посадова особа, яка склала довідку;

керівник контролюючого органу;

місце для печатки контролюючого органу;

керівник відповідного структурного підрозділу Міністерства фінансів України (місцевого фінансового органу, головного розпорядника коштів відповідного бюджету), який прийняв довідку;

місце для печатки Міністерства фінансів України (місцевого фінансового органу, головного розпорядника коштів відповідного бюджету);

дата надходження довідки.

5. До довідки додаються копії документів, що підтверджують факт порушення бюджетного законодавства (рахунки, платіжні доручення, накладні тощо).

6. Керівник контролюючого органу, який підписав довідку, відповідає за своєчасність, достовірність і зміст довідки, поданої Міністерству фінансів України (місцевому фінансовому органу, головному розпоряднику коштів відповідного бюджету).

7. Відповідними структурними підрозділами Міністерства фінансів України (місцевого фінансового органу, головного розпорядника коштів відповідного бюджету) аналізуються зазначені матеріали та в установленому порядку готується проект рішення Міністра (керівника місцевого фінансового органу, головного розпорядника коштів відповідного бюджету) про зменшення бюджетних асигнувань у поточному бюджетному періоді розпоряднику бюджетних коштів, який вчинив порушення бюджетного законодавства.

{ Пункт 7 із змінами, внесеними згідно з Наказом Міністерства фінансів N 483 ( z0532-11 ) від 11.04.2011 }
