Текст документа від 01.01.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 грудня 1992 р. N 695 Київ

Про заходи щодо соціального захисту військовослужбовців, осіб рядового і начальницького складу

( Із змінами, внесеними згідно з Розпорядженням КМ N 102-р ( 102-93-р ) від 17.02.93 з Постановою КМ N 175 ( 175-95-п ) від 14.03.95 )

Кабінет Міністрів України постановляє:

1. Підвищити в 2,55 раза посадові оклади та 1,5 раза оклади за військовими (спеціальними) званнями військовослужбовців, осіб рядового і начальницького складу.

2. Виплачувати:

( Абзац другий пункту 2 втратив чинність на підставі з Розпорядження КМ N 102-р ( 102-93-р ) від 17.02.93)

( Абзац третій пункту 2 втратив чинність на підставі Постанови КМ N 175 ( 175-95-п ) від 14.03.95 )

3. Визнати такими, що втратили чинність, абзац другий пункту 2 постанови Кабінету Міністрів України від 29 лютого 1992р. N 100 ( 100-92-п ), абзаци сьомий і восьмий пункту 1 постанови Кабінету Міністрів України від 31 березня 1992 р. N 161 ( 161-92-п ).

4. Постанову ввести в дію з 1 листопада 1992 року.
