{ Наказ втратив чинність на підставі Наказу Міністерства розвитку економіки, торгівлі та сільського господарства N 788 ( z0593-21 ) від 15.04.2021 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 20.06.2006 N 230

Відповідно до постанови Кабінету Міністрів України від 22.02.2008 N 74 ( 74-2008-п ) "Про запровадження III етапу оплати праці на основі Єдиної тарифної сітки розрядів і коефіцієнтів з оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" (із змінами) НАКАЗУЮ:

1. У додатку 1 до наказу Міністерства праці та соціальної політики України від 20.06.2006 N 230 ( z0739-06 ) "Про впорядкування умов оплати праці працівників Державного камерного ансамблю "Київські солісти", зареєстрованого в Міністерстві юстиції України 22.06.2006 за N 739/12613 (із змінами), слова і цифри "1 листопада 2008 року" замінити словами і цифрами "1 вересня 2008 року".

2. Внесені зміни застосовуються з 1 вересня 2008 року.
