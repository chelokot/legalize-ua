КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 березня 2002 р. N 430 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про внесення змін до постанови Кабінету Міністрів України від 16 грудня 1999 р. N 2303

Кабінет Міністрів України постановляє:

1. Внести у додаток до Програми створення Урядової інформаційно-аналітичної системи з питань надзвичайних ситуацій на 2000-2002 роки, затвердженої постановою Кабінету Міністрів України від 16 грудня 1999 р. N 2303 ( 2303-99-п ) "Про створення Урядової інформаційно-аналітичної системи з питань надзвичайних ситуацій", зміни, що додаються.

2. Координаційній раді із створення та функціонування Урядової інформаційно-аналітичної системи з питань надзвичайних ситуацій підготувати та подати до 1 травня 2002 р. Кабінетові Міністрів України проект Програми розвитку Урядової інформаційно-аналітичної системи з питань надзвичайних ситуацій на 2003-2005 роки.
