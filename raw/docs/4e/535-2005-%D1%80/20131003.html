КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 грудня 2005 р. N 535-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Про внесення змін до розпорядження Кабінету Міністрів України від 29 травня 1995 р. N 301

Внести до розпорядження Кабінету Міністрів України від 29 травня 1995 р. N 301 ( 301-95-р ) такі зміни:

в абзаці третьому слова "військових округів" замінити словами "оперативних командувань";

в абзаці четвертому слово "армій" замінити словами "територіальних і повітряних командувань".

Прем'єр-міністр України Ю.ЄХАНУРОВ
