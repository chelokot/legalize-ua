Текст документа від 26.04.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 квітня 2007 р. N 671 Київ

Про доповнення Переліку категорій працівників, яким може бути надано службові жилі приміщення

Кабінет Міністрів України постановляє:

1. Доповнити Перелік категорій працівників, яким може бути надано службові жилі приміщення, затверджений постановою Ради Міністрів Української РСР від 4 лютого 1988 р. N 37 ( 37-88-п ) "Про службові жилі приміщення" (ЗП УРСР, 1988 р., N 2, ст. 8; 1989 р., N 3, ст. 13, N 7, ст. 42; ЗП України, 1993 р., N 12, ст. 259; 1994 р., N 1, ст. 21, N 4, ст. 99, N 6, ст. 153, N 8, ст. 203, N 10, ст. 262; 1995 р., N 5, ст. 122; Офіційний вісник України, 1997 р., число 35, с. 83, число 51, с. 25; 1998 р., N 27, ст. 995; 1999 р., N 11, ст. 436, N 30, ст. 1545, N 50, ст. 2443; 2003 р., N 37, ст. 1982, N 47, ст. 2436; 2004 р., N 12, ст. 74, N 27, ст. 1777, N 38, ст. 2519; 2006 р., N 14, ст. 1005, N 22, ст. 1618; 2007 р., N 17, ст. 653), пунктом 53 такого змісту:

"53. Особи рядового і начальницького складу Державної служби спеціального зв'язку та захисту інформації до одержання ними постійного жилого приміщення.".

2. Установити, що фонд службових жилих приміщень Державної служби спеціального зв'язку та захисту інформації формується з новозбудованого житла, звільнених жилих приміщень або квартир, придбаних у фізичних чи юридичних осіб.
