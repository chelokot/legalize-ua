ПОСТАНОВА від 17 квітня 2008 р. N 390 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1064 ( 1064-2011-п ) від 03.10.2011 }

Про внесення змін до постанови Кабінету Міністрів України від 4 квітня 2000 р. N 599

Кабінет Міністрів України постановляє:

Зупинити на 2008 рік дію абзацу сьомого підпункту "а" пункту 5 постанови Кабінету Міністрів України від 4 квітня 2000 р. N 599 ( 599-2000-п ) "Про запровадження аукціонів з продажу нафти, газового конденсату, природного, скрапленого газу та вугілля" (Офіційний вісник України, 2000 р., N 14, ст. 567, N 16, ст. 677, N 20, ст. 834, N 33, ст. 1407, N 41, ст. 1746; 2001 р., N 14, ст. 609, N 23, ст. 1032; 2002 р., N 12, ст. 566; 2003 р., N 4, ст. 109; 2004 р., N 9, ст. 529, N 51, ст. 3364; 2007 р., N 1, ст. 21).

Доповнити зазначену постанову ( 599-2000-п ) пунктом 5-3 такого змісту:

"5-3. Установити, що у 2008 році щомісяця продаж нафти сирої і газового конденсату власного видобутку (видобутих на підставі спеціальних дозволів на користування надрами), крім обсягу, що використовується для власних технологічних потреб, та скрапленого газу підприємствами, частка держави у статутному фонді яких перевищує 50 відсотків, а також господарськими товариствами, більш як 50 відсотків акцій (часток, паїв) яких перебуває у статутному фонді інших господарських товариств, в яких держава володіє контрольним пакетом акцій, а також дочірніми підприємствами, представництвами та філіями таких підприємств і товариств, учасниками договорів про спільну діяльність, укладених за участю зазначених підприємств, та/або уповноваженими такими договорами особами здійснюється виключно на аукціонах у порядку, визначеному Положенням, затвердженим цією постановою.".
