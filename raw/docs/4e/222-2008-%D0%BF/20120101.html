КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 березня 2008 р. N 222 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1374 ( 1374-2011-п ) від 28.12.2011 }

Про доповнення постанови Кабінету Міністрів України від 16 березня 2000 р. N 507

Кабінет Міністрів України постановляє:

1. Доповнити постанову Кабінету Міністрів України від 16 березня 2000 р. N 507 ( 507-2000-п ) "Про роз'яснення Указу Президента України від 3 липня 1998 р. N 727" (Офіційний вісник України, 2000 р., N 12, ст. 461) пунктом такого змісту:

"8) суб'єкт малого підприємництва, який згідно з абзацом другим частини першої статті 6 не є платником податку на додану вартість, у разі здійснення операцій з імпорту товарів на митну територію України сплачує податок на додану вартість у визначеному Законом України "Про податок на додану вартість" ( 168/97-ВР ) порядку.".

2. Ця постанова набирає чинності з дня опублікування.
