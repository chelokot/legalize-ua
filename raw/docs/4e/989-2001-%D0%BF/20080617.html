Про призначення заступника Уповноваженого Кабінету Міністрів України по виконанню Угоди між Урядом України та Урядом Угорської Республіки з питань водного господарства на прикордонних водах

Стан: Втратив чинність

Текст документа від 17.06.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 серпня 2001 р. N 989 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 511 ( 511-2008-п ) від 04.06.2008 }

Про призначення заступника Уповноваженого Кабінету Міністрів України по виконанню Угоди між Урядом України та Урядом Угорської Республіки з питань водного господарства на прикордонних водах

На часткову зміну постанови Кабінету Міністрів України від 12 листопада 1993 р. N 920 ( 920-93-п ) (із змінами, внесеними постановою Кабінету Міністрів України від 18 липня 1998 р. N 1118 ( 1118-98-п ) Кабінет Міністрів України постановляє:

Призначити начальника відділу зовнішніх зв'язків Державного комітету по водному господарству Касьянчука Валерія Павловича заступником Уповноваженого Кабінету Міністрів України по виконанню Угоди між Урядом України та Урядом Угорської Республіки з питань водного господарства на прикордонних водах ( 348_059 ), увільнивши від цих обов'язків Леуту Василя Сергійовича.

Прем'єр-міністр України А.КІНАХ
