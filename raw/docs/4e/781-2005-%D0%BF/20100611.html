ПОСТАНОВА від 18 серпня 2005 р. N 781 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про голову Міжвідомчої комісії з питань розвитку транскордонного співробітництва та єврорегіонів

Кабінет Міністрів України постановляє:

1. Установити, що головою Міжвідомчої комісії з питань розвитку транскордонного співробітництва та єврорегіонів, утвореної постановою Кабінету Міністрів України від 29 квітня 2002 р. N 587 ( 587-2002-п ), є перший заступник Міністра економіки.

2. Звільнити від обов'язків голови Міжвідомчої комісії з питань розвитку транскордонного співробітництва та єврорегіонів Хорошковського Валерія Івановича.
