РОЗПОРЯДЖЕННЯ від 14 травня 2008 р. N 710-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 2062-р ( 2062-2010-р ) від 03.11.2010 }

Про внесення змін до розпорядження Кабінету Міністрів України від 17 квітня 2006 р. N 206

Внести до розпорядження Кабінету Міністрів України від 17 квітня 2006 р. N 206 ( 206-2006-р ) "Про затвердження складу Української частини комісій з військово-технічного співробітництва" зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 14 травня 2008 р. N 710-р

ЗМІНИ, що вносяться до розпорядження Кабінету Міністрів України від 17 квітня 2006 р. N 206 ( 206-2006-р )

1. У пункті 1:

1) в останньому абзаці підпункту 2 слова "співробітництва в галузі оборонної промисловості" замінити словами "оборонно-промислового співробітництва";

2) доповнити пункт підпунктом 3 такого змісту:

"3) згідно з додатками 9-13 склад Української частини:

Міжурядової українсько-екваторіально-гвінейської комісії з питань військово-технічного співробітництва;

Спільної міжурядової українсько-казахстанської комісії з питань військово-технічного співробітництва;

Спільної українсько-корейської комісії зі співробітництва у сфері оборонної промисловості та матеріально-технічного забезпечення;

Спільної українсько-пакистанської комісії з питань співробітництва у військовій та оборонно-промисловій галузях;

Українсько-угорської спільної комісії з питань військово-технічного співробітництва.".

2. У назві додатка 8 до розпорядження ( 206-2006-р ) слова "співробітництва в галузі оборонної промисловості" замінити словами "оборонно-промислового співробітництва".

3. Доповнити розпорядження ( 206-2006-р ) додатками 9-13 такого змісту:
