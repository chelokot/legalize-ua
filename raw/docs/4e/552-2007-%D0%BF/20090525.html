КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 березня 2007 р. N 552 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Деякі питання Державного комітету рибного господарства

Кабінет Міністрів України постановляє:

1. Внести у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851; 2005 р., N 34, ст. 2042) такі зміни:

у позиції "Міністерство аграрної політики" цифри "518" замінити цифрами "483";

доповнити додаток такою позицією:

"Державний комітет рибного господарства 105 5".

2. Установити, що у поточному році Державний комітет рибного господарства утримується в межах видатків, передбачених в Державному бюджеті України на 2007 рік ( 489-16 ) Міністерству аграрної політики.
