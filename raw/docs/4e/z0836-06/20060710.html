Зареєстровано в Міністерстві юстиції України 17 липня 2006 р. за N 836/12710

Про визнання наказів такими, що втратили чинність

Відповідно до Закону України "Про державну статистику" ( 2614-12 ) та з метою уникнення дублювання інформаційних потоків щодо підприємств, які змінили форму власності в процесі приватизації, НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Держкомстату:

від 24.10.2005 N 326 ( z1358-05 ) "Про затвердження форми державного статистичного спостереження N 1-приватизація, додатка до форми державного статистичного спостереження N 1-приватизація та Інструкції щодо їх заповнення", зареєстрований в Міністерстві юстиції України 11.11.2005 за N 1358/11638;

від 07.12.2004 N 650 ( z1625-04 ) "Про затвердження форми державного статистичного спостереження N 2-приватизація та Інструкції щодо її заповнення", зареєстрований в Міністерстві юстиції України 22.12.2004 за N 1625/10224.

2. Цей наказ набуває чинності з 11 січня 2007 року.

3. Контроль за виконанням цього наказу покласти на першого заступника Голови Головка В.А.
