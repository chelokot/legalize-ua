Текст документа від 15.02.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 лютого 2006 р. N 145 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань охорони навколишнього природного середовища

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 28 квітня 1999 р. N 715 ( 715-99-п ) "Про проведення еколого-економічного експерименту в містах Кривий Ріг, Дніпродзержинськ, Маріуполь і Запоріжжя" (Офіційний вісник України, 1999 р., N 17, ст. 743);

пункт 1 постанови Кабінету Міністрів України від 11 липня 2002 р. N 1002 ( 1002-2002-п ) "Про внесення зміни та визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України" (Офіційний вісник України, 2002 р., N 29, ст. 1380);

пункт 10 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 16 червня 2004 р. N 769 ( 769-2004-п ) (Офіційний вісник України, 2004 р., N 24, ст. 1588).
