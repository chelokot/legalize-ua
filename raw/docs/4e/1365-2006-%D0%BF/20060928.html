Текст документа від 28.09.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 вересня 2006 р. N 1365 Київ

Про скасування постанови Кабінету Міністрів України від 25 травня 2006 р. N 743

Кабінет Міністрів України постановляє:

1. Скасувати постанову Кабінету Міністрів України від 25 травня 2006 р. N 743 ( 743-2006-п ) "Про утворення Генеральної державної сільськогосподарської інспекції" (Офіційний вісник України, 2006 р., N 22, ст. 1625).

У зв'язку з цим у графі другій додатка 1 до розпорядження Кабінету Міністрів України від 31 травня 2006 р. N 296 ( 296-2006-р ) "Про вдосконалення структури розпорядників бюджетних коштів" (Офіційний вісник України, 2006 р., N 22, ст. 1657) у позиції "Мінагрополітики" слова "Генеральна державна сільськогосподарська інспекція" виключити.

2. Міністерству аграрної політики привести у двомісячний строк власні акти у відповідність з цією постановою.

Прем'єр-міністр України В.ЯНУКОВИЧ
