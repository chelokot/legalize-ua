Кабінет Міністрів України; Постанова від 17.03.2010 № 268

Питання забезпечення функціонування державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів"

Стан: Чинний

Ідентифікатор: 268-2010-п

Текст документа від 17.03.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 березня 2010 р. N 268 Київ

Питання забезпечення функціонування державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів"

Кабінет Міністрів України постановляє:

1. Ліквідувати казенне підприємство "Поліграфічний комбінат "Україна" по виготовленню цінних паперів".

2. Припинити процедуру ліквідації державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" та відновити його діяльність.

3. Установити, що державне підприємство "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" належить до сфери управління Міністерства фінансів.

4. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 17 лютого 2010 р. N 249 ( 249-2010-р ) "Про заходи щодо удосконалення державного регулювання та посилення контролю у сфері виготовлення бланків цінних паперів і документів суворої звітності";

постанову Кабінету Міністрів України від 2 березня 2010 р. N 218 ( 218-2010-п ) "Деякі питання утворення казенного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" (Офіційний вісник України, 2010 р., N 15, ст. 708).

Прем'єр-міністр України М.АЗАРОВ
