Кабінет Міністрів України; Розпорядження від 20.07.1995 № 449-р

Про передачу Держпатенту незавершеного будівництвом будинку

Стан: Втратив чинність

Ідентифікатор: 449-95-р

Текст документа від 26.05.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 липня 1995 р. N 449-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 477-р ( 477-99-р ) від 26.05.99 )

1. Надати в оперативне управління Держпатенту незавершений будівництвом будинок по вул. Солом'янській, 2а, у м. Києві для наступного розміщення його центрального апарату.

Київському інституту серцево-судинної хірургії передати у місячний термін цей будинок Держпатенту.

Держпатенту після завершення будівництва передбачити використання частини приміщень будинку для державних потреб за розподілом Кабінету Міністрів України.

2. Визнати таким, що втратило чинність, розпорядження Ради Міністрів УРСР від 30 листопада 1989 р. N 420.

Прем'єр-міністр України Є.МАРЧУК
