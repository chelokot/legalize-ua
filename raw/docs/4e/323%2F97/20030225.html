УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Консультативну раду з питань іноземних інвестицій в Україні

( Із змінами, внесеними згідно з Указами Президента N 717/97 від 29.07.97 N 1006/97 від 11.09.97 N 414/98 від 06.05.98 N 468/2000 від 21.03.2000 N 725/2000 від 29.05.2000 N 775/2000 від 08.06.2000 N 1146/2000 ( 1146/2000 ) від 19.10.2000 N 1162/2000 ( 1162/2000 ) від 24.10.2000 N 280/2001 ( 280/2001 ) від 25.04.2001 N 429/2001 ( 429/2001 ) від 14.06.2001 N 1036/2001 ( 1036/2001 ) від 01.11.2001 N 1060/2001 ( 1060/2001 ) від 08.11.2001 N 310/2002 ( 310/2002 ) від 01.04.2002 N 1124/2002 ( 1124/2002 ) від 02.12.2002 N 163/2003 ( 163/2003 ) від 25.02.2003 )

З метою забезпечення розроблення та реалізації державної політики щодо залучення іноземних інвестицій в економіку України, використання сучасного світового економічного досвіду та прискорення інтеграції України в систему міжнародних господарських зв'язків постановляю:

1. Утворити при Президентові України Консультативну раду з питань іноземних інвестицій в Україні (далі - Консультативна рада).

2. Установити, що Головою Консультативної ради є Президент України.

3. Затвердити Положення про Консультативну раду з питань іноземних інвестицій в Україні (додається).

4. Затвердити персональний склад Консультативної ради (додається).

5. Для забезпечення діяльності Консультативної ради утворюється секретаріат Консультативної ради у складі шести осіб.

Персональний склад секретаріату Консультативної ради за поданням її секретаря затверджує Голова Консультативної ради.

( Стаття 5 в редакції Указу Президента N 1162/2000 ( 1162/2000 ) від 24.10.2000 )

6. Визнати таким, що втратив чинність, Указ Президента України від 27 січня 1996 року N 90 ( 90/96 ) "Про Консультативну раду з питань іноземних інвестицій в Україні".

Президент України Л.КУЧМА

м. Київ, 11 квітня 1997 року N 323/97

ЗАТВЕРДЖЕНО Указом Президента України від 11 квітня 1997 року N 323/97

ПОЛОЖЕННЯ про Консультативну раду з питань іноземних інвестицій в Україні

1. Консультативна рада з питань іноземних інвестицій в Україні (далі - Консультативна рада) є консультативним органом при Президентові України, утвореним з метою забезпечення розроблення та реалізації державної політики щодо залучення та ефективного використання іноземних інвестицій в економіку України, прискорення її інтеграції у світові економічні процеси.

2. У своїй діяльності Консультативна рада керується Конституцією України ( 254к/96-ВР ), законами України, актами Президента України та Кабінету Міністрів України, а також цим Положенням та Регламентом роботи Консультативної ради.

( Пункт 2 із змінами, внесеними згідно з Указом Президента N 1162/2000 ( 1162/2000 ) від 24.10.2000 )

3. Консультативна рада:

сприяє визначенню основних засад державної політики щодо залучення та ефективного використання іноземних інвестицій в Україні для забезпечення розвитку її економіки;

аналізує та узагальнює проблеми, що стримують іноземне інвестування в економіку України, визначає політичні, організаційні, юридичні, економічні та інформаційні шляхи їх вирішення;

розглядає ключові проблеми інвестиційного процесу, регулювання іноземного інвестування на макроекономічному рівні, проекти державних програм та актів законодавства з цих питань;

розробляє пропозиції щодо вдосконалення форм і методів регулювання економіки і впровадження сучасних міжнародних стандартів управління на підприємствах України;

пропонує державні заходи щодо активізації залучення українських суб'єктів підприємницької діяльності до міжнародних ринків товарів, капіталів і послуг;

сприяє формуванню привабливого іміджу України серед потенційних іноземних інвесторів;

розглядає на прохання іноземних інвесторів, органів виконавчої влади та органів місцевого самоврядування України заяви про виникнення спорів між ними та готує висновки щодо можливих шляхів їх позасудового врегулювання. ( Пункт 3 доповнено абзацом згідно з Указом Президента N 310/2002 ( 310/2002 ) від 01.04.2002 )

4. Консультативна рада для здійснення своїх завдань має право:

одержувати в установленому порядку від міністерств, інших центральних та місцевих органів виконавчої влади, підприємств, установ і організацій інформацію, документи і матеріали;

утворювати свої робочі органи (робочі та експертні групи);

( Абзац третій пункту 4 в редакції Указу Президента N 1162/2000 ( 1162/2000 ) від 24.10.2000 )

залучати для розгляду питань, що належать до її компетенції, керівних працівників відповідних міністерств та інших центральних органів виконавчої влади України, іноземних фахівців (за згодою).

5. Персональний склад Консультативної ради затверджує Президент України.

6. До складу Консультативної ради також залучаються іноземні особи.

Іноземними членами Консультативної ради призначаються керівники (за їх згодою) визнаних авторитетних міжнародних компаній, інвестиційних банків, консультативних фірм, асоціацій та об'єднань інвесторів і підприємців, що відповідають таким критеріям: ( Абзац другий пункту 6 в редакції Указу Президента N 310/2002 ( 310/2002 ) від 01.04.2002 )

вкладення значного обсягу інвестицій в об'єкти інвестиційної діяльності пріоритетних галузей національної економіки чи внесення обгрунтованих пропозиції щодо їх вкладення; ( Абзац третій пункту 6 в редакції Указу Президента N 310/2002 ( 310/2002 ) від 01.04.2002 )

багаторічний досвід роботи у відповідних галузях економіки, визначальний вплив на їх розвиток, широка обізнаність у проблемних питаннях діяльності інвесторів у зазначених галузях; ( Пункт 6 доповнено абзацом четвертим згідно з Указом Президента N 310/2002 ( 310/2002 ) від 01.04.2002 )

сприяння залученню іноземних інвесторів до розвитку економіки України; ( Пункт 6 доповнено абзацом п'ятим згідно з Указом Президента N 310/2002 ( 310/2002 ) від 01.04.2002 )

представництво широких кіл іноземних інвесторів, що активно здійснюють інвестиційну діяльність в Україні, чи ефективність співпраці з вітчизняними суб'єктами господарювання; ( Пункт 6 доповнено абзацом шостим згідно з Указом Президента N 310/2002 ( 310/2002 ) від 01.04.2002 )

активна участь у формуванні позитивного інвестиційного іміджу України. ( Пункт 6 доповнено абзацом сьомим згідно з Указом Президента N 310/2002 ( 310/2002 ) від 01.04.2002 )

При формуванні частини персонального складу Консультативної ради з числа іноземців ураховуються пропозиції відповідних органів та організацій іноземних держав, дипломатичних представництв України за кордоном та міжнародних організацій.

6-1. За рішенням Голови Консультативної ради проводиться періодична ротація її складу, яка передбачає виведення зі складу Консультативної ради іноземних членів, строк перебування яких в її складі перевищив три роки, або членів, результати роботи яких не відповідають ознакам, визначеним цим пунктом.

Ознаками ефективності роботи члена Консультативної ради є: активна участь у роботі Консультативної ради, зокрема на її пленарних засіданнях, та робочих органів;

нарощення обсягів капіталовкладень іноземних інвесторів, яких представляє член Консультативної ради, наявність у цих інвесторів стратегічних планів щодо розширення підприємницької та інвестиційної діяльності в Україні;

сприяння розвитку та модернізації пріоритетних галузей національної економіки, поліпшення інвестиційного іміджу України;

відсутність заборгованості зі сплати податків, зборів (обов'язкових платежів) до бюджетів та державних цільових фондів, а також заборгованості з виплати заробітної плати працівникам підприємств, установ, організацій, що є об'єктами інвестування з боку інвесторів, яких представляє член Консультативної ради.

Іноземного члена Консультативної ради за рішенням Голови Консультативної ради в будь-який час може бути виведено з її складу в разі вчинення таким членом дій, які завдають шкоди міжнародному інвестиційному іміджу України або порушують законодавство України.

Пропозиції щодо ротації іноземних членів Консультативної ради готуються створеною за рішенням Голови Консультативної ради робочою групою з числа членів цієї ради, очолюваною секретарем Консультативної ради.

( Положення доповнено пунктом 6-1 згідно з Указом Президента N 310/2002 ( 310/2002 ) від 01.04.2002 )

7. Формою роботи Консультативної ради є пленарні засідання, які проводяться один раз на рік. У разі потреби Голова Консультативної ради призначає позачергове засідання Консультативної ради.

У період між пленарними засіданнями Консультативної ради її члени, секретаріат, робочі органи можуть ініціювати перед Президентом України проведення міжнародних форумів, конференцій, круглих столів, семінарів, інших заходів з актуальних питань іноземного інвестування в Україні. ( Пункт 7 доповнено абзацом згідно з Указом Президента N 310/2002 ( 310/2002 ) від 01.04.2002 )

( Пункт 7 в редакції Указу Президента N 1162/2000 ( 1162/2000 ) від 24.10.2000 )

8. На запрошення Консультативної ради в її засіданнях можуть брати участь керівники міністерств та інших центральних органів виконавчої влади, установ, організацій та суб'єктів підприємницької діяльності, а також дипломатичних представництв іноземних держав в Україні, іноземних компаній, консультативних фірм, інвестиційних фондів і банків.

9. Голова Консультативної ради:

призначає засідання Консультативної ради;

затверджує порядок денний засідання Консультативної ради;

головує на засіданнях Консультативної ради;

затверджує персональний склад секретаріату Консультативної ради за поданням її секретаря. ( Пункт 9 доповнено абзацом згідно з Указом Президента N 1162/2000 ( 1162/2000 ) від 24.10.2000 )

10. Секретар Консультативної ради очолює її секретаріат. Персональний склад секретаріату Консультативної ради за поданням її секретаря затверджує Голова Консультативної ради.

Секретаріат Консультативної ради здійснює організаційне забезпечення її діяльності, забезпечує координацію діяльності її робочих органів (робочих та експертних груп), за дорученням Голови Консультативної ради вносить до органів виконавчої влади пропозиції з питань діяльності Консультативної ради, одержує від таких органів інформацію, документи та матеріали, необхідні для підготовки пленарних засідань Консультативної ради, забезпечення діяльності її робочих органів.

( Пункт 10 в редакції Указу Президента N 1162/2000 ( 1162/2000 ) від 24.10.2000 )

11. Консультативна рада з питань, що належать до її відання, приймає рішення та рекомендації.

Рішення Консультативної ради приймається більшістю її складу за умови, що за нього проголосував Голова.

За результатами пленарного засідання Консультативної ради приймається меморандум, яким оформлюються прийняті на засіданні рішення та рекомендації. ( Абзац третій пункту 11 в редакції Указу Президента N 1162/2000 ( 1162/2000 ) від 24.10.2000 )

У разі потреби рішення Консультативної ради можуть запроваджуватись актами Президента України.

Рекомендації Консультативної ради приймаються більшістю голосів її членів, присутніх на засіданні.

12. Регламент роботи Консультативної ради визначається Консультативною радою та затверджується її Головою.
