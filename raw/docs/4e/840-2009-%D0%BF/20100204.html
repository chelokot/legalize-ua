Стан: Чинний

Ідентифікатор: 840-2009-п

Текст документа від 04.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 липня 2009 р. N 840 Київ

Про затвердження Порядку проведення розрахунків, пов'язаних з виконанням за рахунок коштів Стабілізаційного фонду Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 73 ( 73-2010-п ) від 28.01.2010 }

{ Із змінами, внесеними згідно з Постановою КМ N 73 ( 73-2010-п ) від 28.01.2010 }

Для забезпечення цільового використання коштів Стабілізаційного фонду, які надійдуть до спеціального фонду державного бюджету від розміщення облігацій внутрішньої державної позики, випущених з метою виконання Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 73 ( 73-2010-п ) від 28.01.2010 }

1. Затвердити Порядок проведення розрахунків, пов'язаних з виконанням за рахунок коштів Стабілізаційного фонду Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, що додається.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 73 ( 73-2010-п ) від 28.01.2010 }

2. Рекомендувати Національному банку врегулювати питання щодо відкриття окремих рахунків недержавним суб'єктам господарювання для зарахування коштів за виконані роботи та надані послуги, пов'язані з підготовкою та проведенням в Україні фінальної частини чемпіонату Європи 2012 року з футболу.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 44

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 29 липня 2009 р. N 840

ПОРЯДОК проведення розрахунків, пов'язаних з виконанням за рахунок коштів Стабілізаційного фонду Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 73 ( 73-2010-п ) від 28.01.2010 }

1. Цей Порядок визначає механізм проведення розрахунків, пов'язаних з виконанням Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу (далі - Програма) за рахунок коштів Стабілізаційного фонду, які надійдуть до спеціального фонду державного бюджету від розміщення облігацій внутрішньої державної позики, випущених з метою виконання Програми (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 73 ( 73-2010-п ) від 28.01.2010 }

2. Бюджетні кошти зараховуються на окремий спеціальний рахунок з обліку коштів, залучених до спеціального фонду державного бюджету, відкритий у Державному казначействі за балансовим рахунком 3212 "Кошти, залучені до спеціального фонду державного бюджету від розміщення цінних паперів та направлені на їх погашення".

3. Бюджетні кошти, що надійшли на окремий спеціальний рахунок відповідно до пункту 2 цього Порядку, виділяються їх розпорядникам у порядку, визначеному постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) "Питання використання коштів Стабілізаційного фонду" (Офіційний вісник України, 2009 р., N 24, ст. 793; 2010 р., N 2, ст. 69).

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 73 ( 73-2010-п ) від 28.01.2010 }

4. Мінфін у разі потреби визначає в установленому порядку окремі бюджетні програми для виконання Програми, видатки за якими здійснюватимуться за рахунок розміщення облігацій внутрішньої державної позики, випущених з метою виконання Програми, закріплює за ними коди програмної та функціональної класифікації видатків і кредитування державного бюджету та вносить у встановленому порядку зміни до розпису державного бюджету.

Для виконання зазначених бюджетних програм в органах Державного казначейства відкриваються розпорядникам та одержувачам бюджетних коштів усіх рівнів спеціальні реєстраційні рахунки для здійснення видатків.

5. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до вимог Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого наказом Державного казначейства.

При цьому розпорядники та одержувачі бюджетних коштів проводять розрахунки за виконані роботи та надані послуги, пов'язані з підготовкою та проведенням фінальної частини чемпіонату Європи 2012 року з футболу в Україні, із суб'єктами господарювання - державними підприємствами шляхом перерахування коштів на рахунки, відкриті таким підприємствам в органах Державного казначейства за балансовим рахунком 3712 "Рахунки інших клієнтів Державного казначейства", а з іншими суб'єктами господарювання - на окремі рахунки, відкриті їм в установах банків.

6. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
