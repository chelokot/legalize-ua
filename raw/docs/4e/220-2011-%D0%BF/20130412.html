Кабінет Міністрів України; Постанова, Порядок від 28.02.2011 № 220

Про затвердження Порядку використання коштів, передбачених у державному бюджеті для консервації виробничих потужностей промислових підприємств

Стан: Чинний

Ідентифікатор: 220-2011-п

Текст документа від 12.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 лютого 2011 р. N 220 Київ

Про затвердження Порядку використання коштів, передбачених у державному бюджеті для консервації виробничих потужностей промислових підприємств

{ Із змінами, внесеними згідно з Постановою КМ N 215 ( 215-2013-п ) від 01.04.2013 }

Відповідно до частини сьомої статті 20 Бюджетного кодексу України ( 2456-17 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання коштів, передбачених у державному бюджеті для консервації виробничих потужностей промислових підприємств, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 лютого 2011 р. N 220

ПОРЯДОК використання коштів, передбачених у державному бюджеті для консервації виробничих потужностей промислових підприємств

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті за програмою "Консервація виробничих потужностей промислових підприємств" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів та відповідальним виконавцем бюджетної програми є Агентство держмайна, а одержувачем бюджетних коштів - державне підприємство "Шахта 2-біс". { Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 215 ( 215-2013-п ) від 01.04.2013 }

Одержувач бюджетних коштів використовує бюджетні кошти згідно з відповідним планом, який погоджується з головним розпорядником бюджетних коштів.

3. Бюджетні кошти з метою консервації ртутного виробництва на державному підприємстві "Шахта 2-біс", забезпечення гідрогеологічного захисту та запобігання виникненню аварійних ситуацій спрямовуються на:

виконання робіт з консервації ртутного виробництва відповідно до проекту переведення державного підприємства "Шахта 2-біс" у режим гідрогеологічного захисту та ліквідації споруд, які не пов'язані з гідрозахистом, а також здійснення заходів, пов'язаних із забезпеченням утримання його цілісного майнового комплексу у режимі сухої консервації; { Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 215 ( 215-2013-п ) від 01.04.2013 }

погашення заборгованості за бюджетними зобов'язаннями минулих років, зареєстрованої в органах Казначейства. { Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 215 ( 215-2013-п ) від 01.04.2013 }

4. Агентство держмайна складає план робіт з консервації виробничих потужностей промислових підприємств з поквартальним розподілом і зазначенням обсягів їх фінансування у бюджетному періоді та подає копію зазначеного плану Мінфіну.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 215 ( 215-2013-п ) від 01.04.2013 }

5. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється у встановленому законом порядку.

Попередня оплата таких товарів, робіт і послуг проводиться з урахуванням положень бюджетного законодавства.

6. Видатки, пов'язані з фінансуванням капітального будівництва, здійснюються відповідно до Порядку державного фінансування капітального будівництва, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) (Офіційний вісник України, 2001 р., N 52, ст. 2374), та Порядку прийняття в експлуатацію закінчених будівництвом об'єктів, затвердженого постановою Кабінету Міністрів України від 13 квітня 2011 р. N 461 ( 461-2011-п ) (Офіційний вісник України, 2011 р., N 32, ст. 1359). { Абзац перший пункту 6 із змінами, внесеними згідно з Постановою КМ N 215 ( 215-2013-п ) від 01.04.2013 }

Пріоритетом капітального будівництва є спрямування бюджетних коштів на об'єкти з високим ступенем будівельної готовності.

7. Відображення у первинному та бухгалтерському обліку інформації про отримані (створені) оборотні і необоротні активи, а також відкриття рахунків, реєстрація, облік зобов'язань в органах Казначейства та проведення операцій, пов'язаних з використанням бюджетних коштів, здійснюються у порядку, встановленому законодавством.

{ Пункт 7 із змінами, внесеними згідно з Постановою КМ N 215 ( 215-2013-п ) від 01.04.2013 }

8. Одержувач бюджетних коштів подає щокварталу не пізніше 10 числа наступного місяця головному розпорядникові бюджетних коштів:

звіт про виконання плану використання бюджетних коштів для затвердження;

звіт про виконання плану заходів з консервації виробничих потужностей промислових підприємств за встановленою головним розпорядником бюджетних коштів формою.

Копії зазначених звітів подаються Мінфіну.

9. Складення та подання фінансової і бюджетної звітності про використання бюджетних коштів, а також звітів про виконання паспорта бюджетної програми (у тому числі стосовно результативних показників) та контроль за їх цільовим та ефективним витрачанням здійснюються у встановленому законодавством порядку.
