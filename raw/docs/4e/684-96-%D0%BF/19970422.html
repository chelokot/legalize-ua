ПОСТАНОВА від 27 червня 1996 р. N 684 Київ

Про затвердження переліку підприємств, які приватизуються за індивідуальними планами

( Із змінами, внесеними згідно з Постановами КМ N 1441 ( 1441-96-п ) від 02.12.96 N 370 ( 370-97-п ) від 22.04.97 )

Кабінет Міністрів України постановляє:

1. Затвердити перелік підприємств, які приватизуються за індивідуальними планами, згідно з додатком.

2. Установити, що внесені до зазначеного переліку підприємства підлягають приватизації за індивідуальними планами, в яких передбачається продаж пакетів акцій на конкурсах. ( Пункт 2 в редакції Постанови КМ N 370 ( 370-97-п ) від 22.04.97 )

3. Визнати такими, що втратили чинність, переліки підприємств, приватизацію майна яких, що перебуває у загальнодержавній власності, доцільно здійснити із залученням іноземних інвестицій, затверджені постановами Кабінету Міністрів України від 12 серпня 1993 р. N 635 ( 635-93-п ), 2 березня 1994 р. N 126 ( 126-94-п ), 17 січня 1995 р. N 32 ( 32-95-п ) та від 1 лютого 1996 р. N 156 ( 156-96-п ).
