Текст документа від 25.07.2018:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 травня 1998 р. N 620 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 551 ( 551-2018-п ) від 11.07.2018 }

Про внесення доповнень до Порядку видачі посвідчень особам, які постраждали внаслідок Чорнобильської катастрофи

( Із змінами, внесеними згідно з Постановою КМ N 1638 ( 1638-98-п ) від 16.10.98 )

( Про продовження терміну дії посвідчень див. Постанову КМ N 979 ( 979-99-п ) від 05.06.99 )

У зв'язку із закінченням перевірки правильності видачі посвідчень "Учасник ліквідації наслідків аварії на Чорнобильській АЕС" Кабінет Міністрів України постановляє:

1. Установити, що посвідчення "Учасник ліквідації наслідків аварії на Чорнобильській АЕС" і "Постраждалий від Чорнобильської катастрофи" (категорії 1, 2, 3 серії А) без відмітки про перереєстрацію, передбачену у абзаці першому пункту 3 постанови Кабінету Міністрів України від 4 лютого 1997 р. N 135 ( 135-97-п ) "Про перевірку правильності видачі посвідчень "Учасник ліквідації наслідків аварії на Чорнобильській АЕС", з 1 жовтня 1998 р. вважаються недійсними.

Посвідчення "Учасник ліквідації наслідків аварії на Чорнобильській АЕС" і "Постраждалий від Чорнобильської катастрофи" (категорії 1, 2, 3 серії А) без відмітки про перереєстрацію, передбачену у абзаці першому пункту 3 постанови Кабінету Міністрів України від 4 лютого 1997 р. N 135 ( 135-97-п ) (Офіційний вісник України, 1997 р., число 6, с. 68, число 34, с. 7; 1998 р., N 19, ст. 681), з тимчасовими вкладками затвердженого цією постановою зразка для осіб, які не отримали станом на 1 жовтня 1998 р. відповідної довідки у Державному галузевому архіві Міністерства оборони, вважаються чинними до 1 травня 1999 року. ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 1638 ( 1638-98-п ) від 16.10.98 ) ( Тимчасову вкладку див. в Постанові КМ N 1638 ( 1638-98-п ) від 16.10.98 )

2. Абзац перший пункту 3 та абзац перший пункту 5 Порядку видачі посвідчень особам, які постраждали внаслідок Чорнобильської катастрофи, затвердженого постановою Кабінету Міністрів України від 20 січня 1997 р. N 51 ( 51-97-п ), доповнити новими реченнями такого змісту: "При цьому у посвідченні на правій стороні по діагоналі зліва направо ставиться штамп фарбою червоного кольору "Перереєстровано" і на вільному місці виконується запис про дату перереєстрації. Починаючи з 1 жовтня 1998 р. зазначене посвідчення без такого штампу вважається недійсним".
