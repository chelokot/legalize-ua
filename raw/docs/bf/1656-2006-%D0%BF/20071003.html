Про утворення міжвідомчої робочої групи з питань координації та контролю за реалізацією проекту "Удосконалення системи соціальної допомоги"

Стан: Втратив чинність

Ідентифікатор: 1656-2006-п

Текст документа від 03.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 листопада 2006 р. N 1656 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1197 ( 1197-2007-п ) від 03.10.2007 }

Про утворення міжвідомчої робочої групи з питань координації та контролю за реалізацією проекту "Удосконалення системи соціальної допомоги"

Кабінет Міністрів України постановляє:

1. Утворити міжвідомчу робочу групу з питань координації та контролю за реалізацією проекту "Удосконалення системи соціальної допомоги", який підтримується Міжнародним банком реконструкції та розвитку, у складі згідно з додатком.

Надати голові міжвідомчої робочої групи право вносити у разі потреби зміни до її складу.

2. Внести зміну до пункту 1 постанови Кабінету Міністрів України від 15 лютого 2006 р. N 147 ( 147-2006-п ) "Про керівників деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України" (Офіційний вісник України, 2006 р., N 7, ст. 360), виклавши останній абзац підпункту 11 у такій редакції:

"головою міжвідомчої робочої групи з питань координації та контролю за реалізацією проекту "Удосконалення системи соціальної допомоги;".

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 31 грудня 2004 р. N 990 ( 990-2004-р ) "Про утворення міжвідомчої робочої групи з питань координації та контролю за підготовкою і реалізацією проекту "Підвищення ефективності управління реформою системи соціального захисту в Україні".

4. Міністерству праці та соціальної політики забезпечити реалізацію проекту "Удосконалення системи соціальної допомоги"
