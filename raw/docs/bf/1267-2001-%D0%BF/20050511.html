КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 вересня 2001 р. N 1267 Київ

( Постанова втратила чинність на підставі Постанови КМ N 328 ( 328-2005-п ) від 11.05.2005 )

Про внесення зміни до постанови Кабінету Міністрів України від 18 травня 2000 р. N 821

Кабінет Міністрів України постановляє:

Абзац одинадцятий розділу II додатка 1 до постанови Кабінету Міністрів України від 18 травня 2000 р. N 821 ( 821-2000-п ) "Про упорядкування структури місцевих державних адміністрацій" (Офіційний вісник України, 2000 р., N 20, ст. 835), після слів "Управління з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" доповнити словами "а у Дніпропетровській, Донецькій, Запорізькій, Луганській, Львівській, Одеській, Рівненській - Головне управління з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи".

Прем'єр-міністр України А.КІНАХ
