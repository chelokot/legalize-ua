Президент України; Указ від 27.10.2010 № 979/2010

Питання Української частини Комісії зі співпраці між Україною та Китайською Народною Республікою

Стан: Втратив чинність

Ідентифікатор: 979/2010

Текст документа від 19.06.2012:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Української частини Комісії зі співпраці між Україною та Китайською Народною Республікою

{ Із змінами, внесеними згідно з Указом Президента N 403/2012 ( 403/2012 ) від 19.06.2012 }

З метою реалізації Спільної заяви України та Китайської Народної Республіки стосовно всебічного підвищення рівня українсько-китайських відносин дружби і співробітництва від 2 вересня 2010 року та відповідно до пункту 3 статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Призначити ХОРОШКОВСЬКОГО Валерія Івановича - Першого віце-прем'єр-міністра України - головою Української частини Комісії зі співпраці між Україною та Китайською Народною Республікою, ГОНЧАРУКА Андрія Івановича - Радника Президента України - Керівника Головного управління з питань міжнародних відносин Адміністрації Президента України першим заступником голови Української частини Комісії зі співробітництва між Україною та Китайською Народною Республікою.

{ Стаття 1 із змінами, внесеними згідно з Указом Президента N 403/2012 ( 403/2012 ) від 19.06.2012 }

2. Голові Української частини Комісії зі співпраці між Україною та Китайською Народною Республікою внести у місячний строк пропозиції щодо персонального складу Української частини Комісії зі співпраці між Україною та Китайською Народною Республікою.

Президент України В.ЯНУКОВИЧ

м. Київ, 27 жовтня 2010 року N 979/2010
