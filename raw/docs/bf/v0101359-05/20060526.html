25.06.2005 N 101

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 1246 ( v1246359-06 ) від 26.05.2006 }

Про внесення змін до постанови Центральної виборчої комісії від 1 березня 2005 року N 52 "Про штатний розпис Центральної виборчої комісії"

Враховуючи наказ Міністерства праці та соціальної політики України від 29 квітня 2005 року N 154 ( z0493-05 ) "Про внесення змін до наказу Міністерства праці України від 02.10.96 N 77", керуючись статтями 12, 33, частиною першою статті 36, частиною першою статті 37 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Внести до штатного розпису Центральної виборчої комісії, затвердженого постановою Центральної виборчої комісії від 1 березня 2005 року N 52 ( v0052359-05 ), такі зміни:

у рядку "Технічний працівник" цифри "279" замінити цифрами "298", а цифри "2232" - цифрами "2384";

у рядку "Усього" цифри "8875" замінити цифрами "9027";

у рядках "Разом" цифри "138712" замінити цифрами "138864", а цифри "158329" - цифрами "158481".

2. Відділу бухгалтерського обліку та звітності Секретаріату Центральної виборчої комісії провести перерахунок заробітної плати технічних працівників з 1 липня 2005 року.
