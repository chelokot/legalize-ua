Кабінет Міністрів України; Постанова від 29.12.2006 № 1851

Про грошове забезпечення деяких категорій військовослужбовців Збройних Сил, Національної гвардії

Стан: Втратив чинність

Ідентифікатор: 1851-2006-п

Текст документа від 21.03.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 грудня 2006 р. N 1851 Київ

Про грошове забезпечення деяких категорій військовослужбовців Збройних Сил

{ Із змінами, внесеними згідно з Постановою КМ N 508 ( 508-2007-п ) від 21.03.2007 }

Кабінет Міністрів України постановляє:

1. Установити посадові оклади у відсотках посадового окладу Прем'єр-міністра України таким категоріям військовослужбовців Збройних Сил:

------------------------------------------------------------------

| Найменування посади | Відсотки |

|-----------------------------------------+----------------------|

|Начальник Генерального штабу Збройних Сил| 80 |

|-----------------------------------------+----------------------|

|Перший заступник начальника Генерального | 70 |

|штабу Збройних Сил, командувач виду | |

|Збройних Сил, начальник Національної | |

|академії оборони | |

|-----------------------------------------+----------------------|

|Заступник начальника Генерального штабу | 65 |

|Збройних Сил, командувач Об'єднаного | |

|оперативного командування, командувач | |

|Сил підтримки | |

------------------------------------------------------------------

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 508 ( 508-2007-п ) від 21.03.2007 }

2. Установити, що грошове забезпечення посадових осіб, зазначених у пункті 1 цієї постанови, складається з посадового окладу, а також окладу за військовим званням та надбавки за вислугу років, установлених у розмірах та порядку, що визначаються законодавством для військовослужбовців.

Інші виплати начальнику Генерального штабу Збройних Сил здійснюються у розмірах та порядку, передбачених для першого заступника Міністра оборони, а першому заступнику, заступникам начальника Генерального штабу Збройних Сил, командувачам видів Збройних Сил, Об'єднаного оперативного командування, Сил підтримки, начальнику Національної академії оборони - у розмірах та порядку, передбачених для заступника Міністра оборони. { Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 508 ( 508-2007-п ) від 21.03.2007 }

Якщо у зв'язку з прийняттям цієї постанови в окремих осіб розмір грошового забезпечення на період їх служби на займаній посаді зменшиться або в разі їх переведення в інтересах служби на рівноцінну або вищу посаду чи здійснення організаційно-штатних заходів, установлюється щомісячна доплата, яка дорівнює різниці між розміром грошового забезпечення, установленим до набрання чинності цією постановою, і розміром грошового забезпечення, визначеним відповідно до цієї постанови.

3. У додатку 1 до постанови Кабінету Міністрів України від 22 травня 2000 р. N 829 ( 829-2000-п ) "Про грошове забезпечення військовослужбовців" (Офіційний вісник України, 2000 р., N 21, ст. 863) позицію "Командувач виду Збройних Сил - 330" виключити.

4. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 7 грудня 2005 р. N 1154 ( 1154-2005-п ) "Про грошове забезпечення начальника Генерального штабу Збройних Сил" (Офіційний вісник України, 2005 р., N 49, ст. 3059).
