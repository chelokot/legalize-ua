Деякі питання Національної акціонерної компанії "Надра України"

Стан: Чинний

Ідентифікатор: 912-2011-п

Текст документа від 07.05.2025:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 серпня 2011 р. N 912 Київ

Деякі питання Національної акціонерної компанії "Надра України"

{ Із змінами, внесеними згідно з Постановою КМ N 502 ( 502-2025-п ) від 29.04.2025 }

Кабінет Міністрів України постановляє:

1. Передати Державній службі геології та надр повноваження з управління державними корпоративними правами Національної акціонерної компанії "Надра України".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 502 ( 502-2025-п ) від 29.04.2025 }

3. Внести до постанов Кабінету Міністрів України такі зміни:

1) пункт 2 постанови Кабінету Міністрів України від 14 липня 2000 р. N 1128 ( 1128-2000-п ) "Про утворення Національної акціонерної компанії "Надра України" (Офіційний вісник України, 2000 р., N 29, ст. 1222; 2004 р., N 7, ст. 402) виключити;

2) у постанові Кабінету Міністрів України від 12 липня 2005 р. N 568 ( 568-2005-п ) "Про управління державними корпоративними правами Національної акціонерної компанії "Надра України" та відкритого акціонерного товариства "Науково-дослідний інститут "Вектор" і визнання таким, що втратив чинність, пункту 1 постанови Кабінету Міністрів України від 18 лютого 2004 р. N 183" (Офіційний вісник України, 2005 р., N 28, ст. 1640):

у назві та пункті 1 постанови ( 568-2005-п ) слова "Національної акціонерної компанії "Надра України" та" виключити;

у пункті 2 слова "пакетом акцій "Національної акціонерної компанії "Надра України" та" виключити.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70
