{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про надання повноважень Міністру фінансів

З метою оперативного вирішення питань щодо забезпечення прав та інтересів України Кабінет Міністрів України постановляє:

Уповноважити Міністра фінансів підписувати документи, необхідні для належного забезпечення захисту прав України, в тому числі за кордоном, у зв'язку з випуском облігацій зовнішньої державної позики 2000 року згідно з постановою Кабінету Міністрів України від 11 лютого 2000 р. N 360 ( 360-2000-п ) "Про випуск облігацій зовнішньої державної позики 2000 року" та обслуговуванням зовнішнього державного боргу України.

Прем'єр-міністр України В.ЮЩЕНКО
