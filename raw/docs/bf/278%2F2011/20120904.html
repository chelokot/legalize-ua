Президент України; Указ від 10.03.2011 № 278/2011

Про Штаб забезпечення міжнародної взаємодії і координації заходів безпеки з підготовки та проведення фінальної частини чемпіонату Європи 2012 року з футболу

Стан: Втратив чинність

Ідентифікатор: 278/2011

Текст документа від 04.09.2012:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 524/2012 ( 524/2012 ) від 30.08.2012 }

Про Штаб забезпечення міжнародної взаємодії і координації заходів безпеки з підготовки та проведення фінальної частини чемпіонату Європи 2012 року з футболу

{ Із змінами, внесеними згідно з Указом Президента N 919/2011 ( 919/2011 ) від 16.09.2011 }

З метою оптимізації міжнародної взаємодії і координації заходів безпеки під час підготовки та проведення фінальної частини чемпіонату Європи 2012 року з футболу, відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Утворити Штаб забезпечення міжнародної взаємодії і координації заходів безпеки з підготовки та проведення фінальної частини чемпіонату Європи 2012 року з футболу (далі - Штаб) як допоміжний орган при Президентові України.

{ Статтю 2 виключено на підставі Указу Президента N 919/2011 ( 919/2011 ) від 16.09.2011 }

3. Керівникові Штабу подати у тримісячний строк проект Положення про Штаб забезпечення міжнародної взаємодії і координації заходів безпеки з підготовки та проведення фінальної частини чемпіонату Європи 2012 року з футболу і пропозиції щодо персонального складу Штабу.

4. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 10 березня 2011 року N 278/2011
