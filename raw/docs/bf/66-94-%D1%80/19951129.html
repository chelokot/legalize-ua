Кабінет Міністрів України; Розпорядження від 08.02.1994 № 66-р

Про звільнення від сплати мита під час переміщення через митний кордон України факсимільних апаратів та спеціальних матеріалів

Стан: Втратив чинність

Ідентифікатор: 66-94-р

Текст документа від 29.11.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 лютого 1994 р. N 66-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 957 ( 957-95-п ) від 29.11.95 )

Звільнити від сплати мита під час переміщення через митний кордон України факсимільних апаратів та спеціальних матеріалів, що ввозяться для використання Господарським управлінням Кабінету Міністрів України згідно з контрактом N К-1793.
