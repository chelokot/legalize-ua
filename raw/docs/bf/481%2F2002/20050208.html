( Указ втратив чинність на підставі Указу Президента N 208/2005 ( 208/2005 ) від 08.02.2005 )

Про внесення змін до складу Ради національної безпеки і оборони України

Внести до складу Ради національної безпеки і оборони України, затвердженого Указом Президента України від 7 серпня 2001 року N 605 ( 605/2001 ) (зі змінами, внесеними Указом від 27 грудня 2001 року N 1277 ( 1277/2001 ), такі зміни:

1. Увести до складу Ради ЛАВРИНОВИЧА Олександра Володимировича - Міністра юстиції України.

2. Вивести зі складу Ради Станік С.Р.

Президент України Л.КУЧМА
