Стан: Втратив чинність

Текст документа від 01.01.2022:

ЗАКОН УКРАЇНИ

{ Закон втратив чинність на підставі Закону N 1089-IX ( 1089-20 ) від 16.12.2020 }

Про внесення змін до Закону України "Про телекомунікації"

( Відомості Верховної Ради України (ВВР), 2012, N 19-20, ст.176 )

Верховна Рада України постановляє:

1. Частину другу статті 38 та пункт 9 частини першої статті 39 Закону України "Про телекомунікації" ( 1280-15 ) (Відомості Верховної Ради України, 2004 р., N 12, ст. 155; 2006 р., N 14, ст. 116, N 30, ст. 258) після слів "спеціально уповноваженого центрального органу виконавчої влади з питань охорони державного кордону" доповнити словами "центрального органу виконавчої влади в галузі митної справи".

2. Цей Закон набирає чинності з дня, наступного за днем його опублікування.

Президент України В.ЯНУКОВИЧ
