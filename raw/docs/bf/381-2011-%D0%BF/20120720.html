Стан: Втратив чинність

Текст документа від 20.07.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 квітня 2011 р. N 381 Київ

Питання Секретаріату Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановами КМ N 896 ( 896-2011-п ) від 08.08.2011 N 1188 ( 1188-2011-п ) від 21.11.2011 N 131 ( 131-2012-п ) від 22.02.2012 N 143 ( 143-2012-п ) від 27.02.2012 N 491 ( 491-2012-п ) від 31.05.2012 N 641 ( 641-2012-п ) від 18.07.2012 }

Кабінет Міністрів України постановляє:

1. Затвердити граничну чисельність працівників Секретаріату Кабінету Міністрів України - 624 одиниць, в тому числі патронатних служб - 66, з них Апарату Прем'єр-міністра України - 51, Служби Першого віце-прем'єр-міністра України - 15 одиниць.

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 896 ( 896-2011-п ) від 08.08.2011, N 1188 ( 1188-2011-п ) від 21.11.2011, N 131 ( 131-2012-п ) від 22.02.2012, N 143 ( 143-2012-п ) від 27.02.2012, N 491 ( 491-2012-п ) від 31.05.2012, N 641 ( 641-2012-п ) від 18.07.2012 }

2. Утворити в структурі Секретаріату Кабінету Міністрів України Службу Першого віце-прем'єр-міністра України - Міністра економічного розвитку і торгівлі.

3. Структуру Секретаріату Кабінету Міністрів України, затверджену постановою Кабінету Міністрів України від 20 грудня 2010 р. N 1151 ( 1151-2010-п ) "Деякі питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2011 р., N 3, ст. 175), після позиції "Апарат Прем'єр-міністра України" доповнити позицією "Служба Першого віце-прем'єр-міністра України - Міністра економічного розвитку і торгівлі".

Прем'єр-міністр України М.АЗАРОВ
