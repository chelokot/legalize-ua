Про затвердження проекту будівництва першої черги метрополітену в м. Дніпропетровську

Стан: Втратив чинність

Ідентифікатор: 1213-2008-р

Текст документа від 14.10.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 вересня 2008 р. N 1213-р Київ

Про затвердження проекту будівництва першої черги метрополітену в м. Дніпропетровську

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1255-р ( 1255-2009-р ) від 14.10.2009 }

Затвердити поданий Мінтрансзв'язку проект будівництва першої черги метрополітену в м. Дніпропетровську, розроблений Дніпропетровською філією "Дніпрометропроект" державного підприємства "Проектний інститут "Укрметротунельпроект" та рекомендований до затвердження Центральною службою Укрдержінвестекспертизи Мінрегіонбуду, з такими основними техніко-економічними показниками:

будівельна протяжність лінії - 11,82 кілометра у двоколійному вимірі

експлуатаційна протяжність - 11,1 кілометра

загальна кошторисна вартість - 2675759,56 будівництва в цінах 2007 року, тис. гривень

у тому числі:

будівельно-монтажних робіт - 1695679,102

устатковання - 114079,507

пусконалагоджувальних робіт - 10662,847

інші витрати - 855338,104

Із загальної кошторисної вартості:

вартість виконаних робіт станом - 290279,612 на 1 січня 2007 р., тис. гривень

у тому числі:

будівельно-монтажних робіт - 166422,316

устатковання - 14561,343

інші витрати - 109295,953

Крім того, кошти на придбання - 179960 сучасного обладнання, тис. гривень

{ Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 1255-р ( 1255-2009-р ) від 14.10.2009 }
