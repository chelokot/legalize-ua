Про порядок застосування знижок до портових зборів та зборів і плат за послуги, що надаються суднам закордонного плавання

Стан: Втратив чинність

Ідентифікатор: z0607-05

Текст документа від 21.04.2008:

МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

27.05.2005 N 266

Зареєстровано в Міністерстві юстиції України 2 червня 2005 р. за N 607/10887

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 370 ( z0293-08 ) від 01.04.2008 }

Про порядок застосування знижок до портових зборів та зборів і плат за послуги, що надаються суднам закордонного плавання

{ Із змінами, внесеними згідно з Наказом Міністерства транспорту та зв'язку N 475 ( z0979-05 ) від 18.08.2005 }

Відповідно до пункту 2 постанови Кабінету Міністрів України від 12.10.2000 N 1544 ( 1544-2000-п ) "Про портові збори" та пункту 1 наказу Міністерства транспорту України від 15.12.2000 N 711 ( z0005-01 ) "Про внесення змін і доповнень до Зборів і плат за послуги, що надаються суднам у морських торговельних портах України", зареєстрованого в Міністерстві юстиції України 10.01.2001 за N 5/5196, та з метою збільшення обсягів перевезень зовнішньоторговельних і транзитних вантажів, підвищення якості транспортних послуг, що надаються судноплавними компаніями на міжнародному ринку, та їх конкурентоспроможності Н А К АЗУЮ:

1. Установити, що для суден закордонного плавання судноплавних компаній, які мають статус національного перевізника, застосовуються знижки в розмірі:

- 30% до ставок портових зборів (крім адміністративного), зборів і плат, що справляються морськими торговельними портами, за винятком портів Ізмаїл, Усть-Дунайськ; ( Абзац другий пункту 1 із змінами, внесеними згідно з Наказом Міністерства транспорту та зв'язку N 475 ( z0979-05 ) від 18.08.2005 )

- 50% до ставок портових зборів (крім адміністративного) та зборів і плат, що справляються морськими торговельними портами Ізмаїл, Усть-Дунайськ та іншими суб'єктами підприємницької діяльності всіх форм власності, які виконують роботи та надають послуги в морських портах (причалах), незалежно від їх підпорядкованості, та на морських судноплавних шляхах України. ( Абзац третій пункту 1 із змінами, внесеними згідно з Наказом Міністерства транспорту та зв'язку N 475 ( z0979-05 ) від 18.08.2005 )

2. Департаменту нормативно-правового забезпечення (Ониськів М.М.) у встановленому порядку подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3. Керівникам морських торговельних портів, державного підприємства "Дельта-лоцман" та інших суб'єктів підприємницької діяльності всіх форм власності, які виконують роботи та надають послуги в морських портах (причалах) України, незалежно від їх підпорядкованості забезпечити нарахування портових зборів та зборів і плат за послуги, що надаються суднам закордонного плавання, відповідно до пункту 1 цього наказу.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Рябікіна П. Б.

Міністр Є.А.Червоненко
