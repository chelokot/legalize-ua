{ Указ втратив чинність на підставі Указу Президента N 487/2010 ( 487/2010 ) від 02.04.2010 }

Про внесення зміни до Указу Президента України від 24 листопада 2005 року N 1647

Внести до Указу Президента України від 24 листопада 2005 року N 1647 ( 1647/2005 ) "Про першочергові заходи щодо збагачення та розвитку культури і духовності українського суспільства" зміну, доповнивши його статтею 7 такого змісту:

"7. Рекомендувати Голові Ради міністрів Автономної Республіки Крим, головам обласних, Київської та Севастопольської міських державних адміністрацій утворити при місцевих державних адміністраціях відповідні ради з питань культури і духовності як консультативно-дорадчі органи".

Президент України В.ЮЩЕНКО

м. Київ, 28 лютого 2006 року N 160/2006
