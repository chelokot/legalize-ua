Про новий склад Міжвідомчої координаційної комісії Антитерористичного центру при Службі безпеки України

Стан: Втратив чинність

Ідентифікатор: 262/2008-рп

Текст документа від 19.08.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про новий склад Міжвідомчої координаційної комісії Антитерористичного центру при Службі безпеки України

1. Затвердити новий персональний склад Міжвідомчої координаційної комісії Антитерористичного центру при Службі безпеки України (додається).

2. Визнати таким, що втратило чинність, Розпорядження Президента України від 16 червня 2006 року N 192 ( 192/2006-рп ) "Про персональний склад Міжвідомчої координаційної комісії Антитерористичного центру при Службі безпеки України".

Президент України В.ЮЩЕНКО

м. Київ, 19 серпня 2008 року N 262/2008-рп
