Президент України; Указ від 07.11.2002 № 995/2002

Про кількість суддів Апеляційного суду України, Касаційного суду України та Вищого адміністративного суду України

Стан: Втратив чинність

Ідентифікатор: 995/2002

Текст документа від 03.02.2004:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність у частині, що стосується Касаційного суду України на підставі Указу Президента

N 7/2004 ( 7/2004 ) від 05.01.2004 )

Про кількість суддів Апеляційного суду України, Касаційного суду України та Вищого адміністративного суду України

Відповідно до пункту 23 статті 106 Конституції України ( 254к/96-ВР ), статті 20 Закону України "Про судоустрій України" ( 3018-14 ) постановляю:

Визначити, що кількість суддів Апеляційного суду України становить 50 одиниць, Касаційного суду України - 96 одиниць, Вищого адміністративного суду України - 65 одиниць.

Президент України Л.КУЧМА

м. Київ, 7 листопада 2002 року N 995/2002
