Кабінет Міністрів України; Постанова від 22.02.2008 № 69

Про порядок використання у 2008 році коштів, передбачених у державному бюджеті для здійснення заходів, пов'язаних з проведенням приватизації державного майна

Стан: Чинний

Ідентифікатор: 69-2008-п

Текст документа від 23.09.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 лютого 2008 р. N 69 Київ

Про порядок використання у 2008 році коштів, передбачених у державному бюджеті для здійснення заходів, пов'язаних з проведенням приватизації державного майна

{ Із змінами, внесеними згідно з Постановою КМ N 833 ( 833-2008-п ) від 17.09.2008 }

Кабінет Міністрів України постановляє:

1. Установити, що у 2008 році кошти, передбачені Фондові державного майна у державному бюджеті ( 107-17 ) за програмою "Заходи, пов'язані з проведенням приватизації державного майна", використовуються відповідно до Порядку, затвердженого постановою Кабінету Міністрів України від 7 лютого 2007 р. N 145 ( 145-2007-п ) (Офіційний вісник України, 2007 р., N 10, ст. 353, N 30, ст. 1204), з урахуванням того, що оплата послуг інших сторонніх осіб та організацій, залучених до робіт, пов'язаних з передприватизаційною підготовкою, реструктуризацією, екологічним аудитом, приватизацією, наданням юридичних послуг, включає в себе оплату послуг, пов'язаних з передприватизаційною підготовкою земельних ділянок, на яких розташовані об'єкти, що підлягають приватизації.

{ Пункт 1 в редакції Постанови КМ N 833 ( 833-2008-п ) від 17.09.2008 }

2. Закупівля товарів, робіт і послуг проводиться відповідно до законодавства.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 833 ( 833-2008-п ) від 17.09.2008 }

3. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.

Прем'єр-міністр України Ю.ТИМОШЕНКО
