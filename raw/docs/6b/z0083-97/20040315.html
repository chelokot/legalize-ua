ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 35 від 17.02.97 Зареєстровано в Міністерстві м.Київ юстиції України 19 березня 1997 р. vd970217 vn35 за N 83/1887

( Постанова втратила чинність на підставі Постанови Національного банку N 54 ( z0296-04 ) від 18.02.2004 )

Про внесення змін до Положення Національного банку України "Про кредитування"

( Зміни в текст не внесені. Додатково див. Постанову Нацбанку N 64 ( v0525500-98 ) від 24.02.98 )

У зв'язку з введенням в дію Закону України "Про відповідальність за несвоєчасне виконання грошових зобов'язань" від 22.11.96 р. N 543/96-ВР, втратою чинності Постанови Верховної Ради України від 24.12.93 р. N 3811-12 з однойменною назвою та пропозицією емісійно-кредитного департаменту щодо внесення змін до Положення "Про кредитування" Правління ПОСТАНОВЛЯЄ:

1. Відповідно до статті 1 Закону України "Про відповідальність за несвоєчасне виконання грошових зобов'язань" від 22.11.96 р. N 543/96-ВР внести такі зміни до Положення "Про кредитування" ( v0246500-95 ), затвердженого постановою Правління від 28.09.95 р. N 246 ( va299500-95 ) (реєстраційний номер 299):

викласти п.49 у такій редакції: "У кредитних угодах передбачається відповідальність позичальника за несвоєчасне повернення кредиту та відсотків за його користування і банку за несвоєчасне перерахування валюти кредиту у вигляді стягнення пені, що встановлюється за згодою сторін";

пункт 50 виключити.

2. Контроль за виконанням цієї постанови покласти на першого заступника Голови Правління В.С.Стельмаха.

В.о. Голови В.С.Стельмах
