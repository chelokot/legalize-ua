НАКАЗ

N 235 від 07.05.99 Зареєстровано в Міністерстві юстиції України 20 травня 1999 р. за N 319/3612

( Наказ втратив чинність на підставі Наказу Мінтрансу N 551 ( z0828-99 ) від 15.11.99 )

Про затвердження Коефіцієнтів, що застосовуються до тарифів Прейскуранта N 10-01, і коефіцієнта зміни тарифів Прейскуранта N 10-01

( Із змінами, внесеними згідно з Наказами Мінтрансу N 184-Ц ( z0447-99 ) від 21.06.99 N 425 ( z0611-99 ) від 27.08.99 )

Відповідно до постанов Кабінету Міністрів України від 25 грудня 1996 року N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" і від 22 лютого 1994 року N 106 ( 106-94-п ) "Про забезпечення охорони вантажів, що перевозяться залізничним транспортом" та п.9 наказу Міністерства транспорту України від 20 січня 1997 року N 18 ( z0036-97 ), зареєстрованого в Міністерстві юстиції України 20 лютого 1997 року за N 36/1840, НАКАЗУЮ:

1. Затвердити Коефіцієнти, що застосовуються до тарифів Прейскуранта N 10-01 "Тарифи на вантажні залізничні перевезення" (далі - Коефіцієнти) та коефіцієнт зміни тарифів Прейскуранта N 10 - 01 для індексації тарифів на супроводження та охорону вантажів особовим складом і засобами відомчої воєнізованої охорони на залізничному транспорті України (додаються).

2. Установити термін дії коефіцієнтів, зазначених у пунктах 5, 6, 7, 8, 15 і 16 таблиці Коефіцієнтів, до 31.12.99. ( Пункт 2 в редакції Наказу Мінтрансу N 425 ( z0611-99 ) від 27.08.99 )

3. Надати право Державній адміністрації залізничного транспорту України, відповідно до економічної ефективності та собівартості перевезень, знижувати не більш як на 25% розмір коефіцієнтів.

4. Укрзалізниці (Слободян А.В.) забезпечити своєчасне доведення цього наказу до відома вантажовідправників, вантажоодержувачів та населення України.

5. Головному управлінню тарифного та страхового регулювання на транспорті (Щербина С.П.) разом з Головним управлінням правового забезпечення (Логінова Л.М.) в установленому порядку зареєструвати цей наказ у Міністерстві юстиції України.

6. Накази Міністерства транспорту від 04.01.99 N 1 ( z0017-99 ) "Про затвердження коефіцієнтів, що застосовуються до тарифів Прейскуранта N 10-01", від 02.02.99 N 54 ( z0100-99 ) "Про внесення доповнень до Коефіцієнтів, що застосовуються до тарифів Прейскуранта N 10-01", зареєстровані в Міністерстві юстиції України від 14 січня 1999 року за N 17/3310 та від 16 лютого 1999 року за N 100/3393, відповідно, визнати такими, що втратили чинність.

7. Контроль за виконанням наказу покласти на заступника Міністра транспорту Демиденка А.Ф.

Міністр І.П.Данькевич

Примітка. ЕМ - які перевозяться на експорт маршрутними відправками; М - які перевозяться маршрутами; Е - які перевозяться на експорт; ЕнМ - які перевозяться на експорт немаршрутними відправками; ІМ - які ввозяться (імпортовані); У - які перевозяться в межах України.

1. Ці коефіцієнти застосовуються на всіх лініях залізниць України.

2. Коефіцієнти застосовуються при розрахуванні плати за перевезення вантажів усіх видів відправлень. Коефіцієнти, що застосовуються до тарифів Прейскуранта N 10-01, диференційовані залежно від роду вантажу та виду відправки.

3. Коефіцієнт, зазначений в пункті 5, застосовується при розрахуванні плати за перевезення щебеню в межах України.

4. Коефіцієнт, зазначений в пункті 6, застосовується при розрахуванні плати за перевезення щебеню, піску, гранвідсіву, шлаків, золи у всіх видах сполучень.

5. Коефіцієнт, зазначений в пункті 7, застосовується при розрахуванні плати за перевезення торфу паливного і торфу для сільського господарства у всіх видах сполучень.

6. Коефіцієнт, зазначений в пункті 8, застосовується при розрахуванні плати за перевезення мінеральних добрив у межах України.

7. Умови та порядок виконання перевезення вантажів залізничним транспортом, а також відповідальність сторін при цьому визначаються чинним законодавством.

8. Коефіцієнти затверджені для визначення вартості перевезення вантажів у національній валюті України.

9. Платня за перевезення вантажів визначається без урахування податку на додану вартість.

10. Коефіцієнт, зазначений в пункті 14, застосовується при розрахуванні плати за перевезення в межах України вантажів для власних потреб профілактично-оздоровчих закладів залізниць України.

11. Коефіцієнт, зазначений в пункті 15, застосовується при розрахуванні плати за перевезення щебеню, що відправляється зі станцій Південно-Західної залізниці на станції Московської залізниці, в обсязі 560 тисяч тонн і при умові обов'язкової оплати за перевезення грошовими коштами.

12. Коефіцієнт, зазначений в пункті 16, застосовується при розрахуванні плати за перевезення клінкера цементного, що відправляється зі станції Шебелинка Південної залізниці в порт "Южний".
