Про затвердження Інструкції "Про стягнення не внесених в строк обов'язкових страхових внесків та інших платежів до Пенсійного фонду України"

Стан: Втратив чинність

Ідентифікатор: z0050-96

Текст документа від 24.09.1996:

ПРАВЛІННЯ ПЕНСІЙНОГО ФОНДУ УКРАЇНИ

ПОСТАНОВА

N 6-5 від 26.09.95 Зареєстровано в Міністерстві м.Київ юстиції України 6 лютого 1996 р. за N 50/1075

Про затвердження Інструкції "Про стягнення не внесених в строк обов'язкових страхових внесків та інших платежів до Пенсійного фонду України"

( Із змінами, внесеними згідно з Постановою Пенсійного фонду N 11-1 ( z0550-96 ) від 06.09.1996 )

Відповідно до Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 01.06.94 N 345 ( 345-94-п ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Затвердити Інструкцію "Про стягнення не внесених в строк обов'язкових страхових внесків та інших платежів до Пенсійного фонду України".

2. Подати Інструкцію для реєстрації до Міністерства юстиції України.

Голова правління В.П.Тентюк ( Інструкція втратила чинність на підставі Постанови Пенсійного фонду N 11-1 ( z0550-96 ) від 06.09.96 )
