Про склад Міжвідомчої комісії з питань ліцензування використання радіочастот

Стан: Втратив чинність

Текст документа від 07.02.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 вересня 1998 р. N 1452 Київ

( Постанова втратила чинність на підставі Постанови КМ N 112 ( 112-2001-п ) від 07.02.2001 )

Про склад Міжвідомчої комісії з питань ліцензування використання радіочастот

( Із змінами, внесеними згідно з Постановою КМ N 1593 ( 1593-99-п ) від 30.08.99 )

Кабінет Міністрів України постановляє:

1. Установити, що до складу Міжвідомчої комісії з питань ліцензування використання радіочастот входять: перший заступник Голови Державного комітету зв'язку та інформатизації (голова Комісії), голова Ліцензійної палати (заступник голови Комісії), начальник Українського державного центру радіочастот та нагляду за зв'язком (заступник голови Комісії), перший заступник генерального директора Національного космічного агентства, начальник зв'язку Збройних Сил - заступник начальника Генерального штабу Збройних Сил, радник Голови Державного комітету зв'язку та інформатизації з питань використання радіочастот, начальник управління радіоелектронної боротьби Генерального штабу Збройних Сил, начальник управління радіотехнологій та використання радіочастот Державного комітету зв'язку та інформатизації. ( Пункт 1 в редакції Постанови КМ N 1593 ( 1593-99-п ) від 30.08.99 )

2. Визнати такими, що втратили чинність, додаток до постанови Кабінету Міністрів України від 12 вересня 1996 р. N 1117 ( 1117-96-п ) "Про ліцензування використання радіочастот" (ЗП України, 1996 р., N 18, ст. 494) та постанову Кабінету Міністрів України від 30 грудня 1997 р. N 1481 ( 1481-97-п ) "Про внесення зміни до складу Міжвідомчої комісії з питань ліцензування використання радіочастот".
