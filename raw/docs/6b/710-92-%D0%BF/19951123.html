Про посилення режиму санкцій Ради Безпеки ООН щодо Союзної Республіки Югославії (Сербії та Чорногорії)

Стан: Втратив чинність

Ідентифікатор: 710-92-п

Текст документа від 23.11.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 грудня 1992 р. N 710 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1016 ( 1016-95-п ) від 23.11.95 )

Про посилення режиму санкцій Ради Безпеки ООН щодо Союзної Республіки Югославії (Сербії та Чорногорії)

У зв'язку з прийняттям Радою Безпеки ООН резолюції N 787 ( 995_a08 ) від 16 листопада 1992 р. (додається*), що передбачає посилення режиму економічних санкцій проти Союзної Республіки Югославії (Сербії та Чорногорії), Кабінет Міністрів України постановляє:

Міністерствам і відомствам, Раді Міністрів Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям, підприємствам, об'єднанням, організаціям і установам, що здійснюють транзитні перевезення через територію Союзної Республіки Югославії (Сербії та Чорногорії) сирової нафти, нафтопродуктів, вугілля, енергетичного обладнання, заліза, сталі, інших металів, хімікатів, гуми, автопокришок, транспортних засобів, літальних апаратів і двигунів усіх типів:

забезпечити виконання відповідних вимог резолюції Ради Безпеки ООН від 16 листопада 1992 р. N 787 ( 995_a08 ) і вжити необхідних заходів для зведення до мінімуму можливих у зв'язку з цим втрат України;

надавати на вимогу Міністерства закордонних справ необхідну інформацію про роботу щодо виконання зазначеної резолюції.
