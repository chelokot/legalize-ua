ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ У СПРАВАХ СІМ'Ї ТА МОЛОДІ

НАКАЗ

09.01.2004 N 1

Зареєстровано в Міністерстві юстиції України 21 січня 2004 р. за N 87/8686

( Наказ втратив чинність на підставі Наказу Міністерства України у справах сім'ї, молоді та спорту N 1886 ( z1103-05 ) від 06.09.2005 )

Про затвердження Типових структури і штатів республіканського (Автономної Республіки Крим), обласних, Київського та Севастопольського міських, районних, міських, районних у містах центрів соціальних служб для молоді

Відповідно до пункту 2 статті 13 Закону України "Про соціальну роботу з дітьми та молоддю" ( 2558-14 ) та на виконання пункту 26 Загального положення про центри соціальних служб для молоді, затвердженого постановою Кабінету Міністрів України від 03.10.2001 N 1291 ( 1291-2001-п ) "Про розвиток центрів соціальних служб для молоді", НАКАЗУЮ:

1. Затвердити Типові структуру і штати республіканського (Автономної Республіки Крим), обласних, Київського та Севастопольського міських, районних, міських, районних у містах центрів соціальних служб для молоді (додаються) ( z0088-04 ).

2. Вважати таким, що втратив чинність, наказ Держкомсім'ямолоді України від 04.02.2002 N 12 ( z0302-02 ) "Про затвердження Типових структури і штатів республіканського (Автономної Республіки Крим), обласних, Київського та Севастопольського міських, районних, міських та районних у містах центрів соціальних служб для молоді", зареєстрований у Міністерстві юстиції України 27.03.2002 за N 302/6590.

3. Контроль за виконанням наказу покласти на директора Державного центру соціальних служб для молоді Толстоухову С.В.

Голова Комітету В.І.Довженко

1. У республіканському (Автономної Республіки Крим) та обласних центрах соціальних служб для молоді, за відсутності міського центру соціальних служб для молоді, відповідними місцевими органами виконавчої влади, відповідно до постанови Кабінету Міністрів України від 03.10.2001 N 1291 ( 1291-2001-п ) "Про розвиток центрів соціальних служб для молоді" (далі - Постанова), кількість штатних працівників може збільшуватись додатково щонайбільше на 8 осіб.

2. У межах установленого фонду заробітної плати до штатного розпису центрів соціальних служб для молоді можуть бути уведені такі посади:

а) завідувача: господарства, копіювально-розмножувального бюро;

б) касира;

в) друкарки і категорії;

г) водія автотранспорту - за наявності автомобіля;

ґ) прибиральниці службових приміщень - відповідно до встановлених нормативів;

д) охоронника.
