Про призначення В. Фатхутдінова керівником Центру з питань безпеки та правопорядку

Стан: Втратив чинність

Текст документа від 08.04.2010:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 470/2010 ( 470/2010 ) від 02.04.2010 }

Про призначення В. Фатхутдінова керівником Центру з питань безпеки та правопорядку

1. Призначити ФАТХУТДІНОВА Василя Гайнуловича керівником Центру з питань безпеки та правопорядку (за згодою).

2. Керівнику Центру з питань безпеки та правопорядку у двотижневий строк подати на затвердження персональний склад Центру з питань безпеки та правопорядку.
