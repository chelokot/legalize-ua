Про визнання таким, що втратив чинність, наказ Департаменту спеціальних телекомунікаційних систем та захисту інформації Служби безпеки України від 30.08.2001 N 53

Реєстрація: Мін'юст України від 29.05.2007 № 549/13816

Стан: Чинний

Ідентифікатор: z0549-07

Текст документа від 23.05.2007:

АДМІНІСТРАЦІЯ ДЕРЖАВНОЇ СЛУЖБИ СПЕЦІАЛЬНОГО ЗВ'ЯЗКУ ТА ЗАХИСТУ ІНФОРМАЦІЇ УКРАЇНИ

НАКАЗ

23.05.2007 N 96

Зареєстровано в Міністерстві юстиції України 29 травня 2007 р. за N 549/13816

Про визнання таким, що втратив чинність, наказ Департаменту спеціальних телекомунікаційних систем та захисту інформації Служби безпеки України від 30.08.2001 N 53

Відповідно до статті 17 пункту 2 розділу IX "Прикінцеві та перехідні положення" Закону України "Про Державну службу спеціального зв'язку та захисту інформації України" ( 3475-15 ), постанови Кабінету Міністрів України від 03.07.2006 N 895 ( 895-2006-п ) "Питання голографічного захисту документів і товарів" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Департаменту спеціальних телекомунікаційних систем та захисту інформації Служби безпеки України від 30.08.2001 N 53 ( z0791-01 ) "Про заснування Єдиного реєстру виготовлення голографічних захисних елементів та затвердження Порядку його ведення", зареєстрований в Міністерстві юстиції України 10.09.2001 за N 791/5982.

2. Начальнику Департаменту регулювання діяльності у сфері криптографічного захисту інформації Державної служби спеціального зв'язку та захисту інформації України забезпечити подання в установленому порядку цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням наказу залишаю за собою.

4. З наказом ознайомити особовий склад Державної служби спеціального зв'язку та захисту інформації України в частині, що стосується.

Голова Служби Ю.Б.Чеботаренко
