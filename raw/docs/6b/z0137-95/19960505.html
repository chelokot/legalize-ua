Про затвердження Тарифів на перевезення пасажирів і багажу залізничним транспортом в міжнародному сполученні

( Із змінами, внесеними згідно з Наказом Мінтранспорту N 345 ( z0381-95 ) від 13.10.95 )

Згідно з Постановою Кабінету Міністрів України від 13.02.95 р. N 109 ( 109-95-п ), Договором про міжнародний пасажирський тариф МПТ та Договором про міжнародний пасажирський тариф "Схід-Захід" НАКАЗУЮ:

1. Затвердити Тарифи на перевезення пасажирів і багажу залізничним транспортом в міжнародному сполученні в межах України, що додаються.

2. Ввести зазначені Тарифи в дію з 28.05.95 р.

3. Першому заступнику Генерального директора Укрзалізниці Слободяну А.В. та начальникам залізниць України забезпечити своєчасне введення в дію Тарифів та правильність їх застосування і проінформувати про це населення в засобах масової інформації та на вокзалах.

4. Управлінню економічної політики та прогнозування (Бурдей В.В.) разом з управлінням нормативних актів та правової роботи (Наапетян М.Р.) в установленому порядку зареєструвати зазначені Тарифи в Міністерстві юстиції.

5. Контроль за виконанням цього наказу залишаю за собою.

Перший заступник Міністра транспорту України - Генеральний директор Укрзалізниці Л.Л.Железняк Затверджено наказом Міністерства транспорту України від 16 травня 1995 року N 193

Тарифи на перевезення пасажирів і багажу залізничним транспортом в міжнародному сполученні

1. Ці Тарифи застосовуються при обчисленні вартості проїзду пасажирів і перевезення багажу по території України в міжнародному сполученні.

2. Тарифи на перевезення пасажирів диференційовані в залежності від відстані поїздки, класу вагона, виду сполучення.

Для сполучення з країнами, які входять в сферу дії Міжнародного тарифу МПТ, дійсні таблиці N 1 та N 2, тарифною валютою є швейцарський франк.

Для сполучення з країнами, які входять в сферу дії тарифу "Схід-Захід", дійсні таблиці N 3 та N 4, тарифною валютою є ЕКЮ.

3. Вартість проїзду по території України в карбованцях визначається шляхом перемноження ставок у швейцарських франках (ЕКЮ), визначених за відповідними таблицями на курс тарифних валют до українського карбованця, встановлений Національним банком України. ( Пункт 3 в редакції Наказу Мінтранспорту N 345 ( z0381-95 ) від 13.10.95 )
