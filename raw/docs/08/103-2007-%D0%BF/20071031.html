Кабінет Міністрів України; Постанова від 31.01.2007 № 103

Про порядок використання у 2007 році коштів, передбачених у державному бюджеті для паспортизації, інвентаризації та реставрації пам'яток архітектури і розроблення схем та проектних рішень масового застосування

Стан: Чинний

Ідентифікатор: 103-2007-п

Текст документа від 31.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 січня 2007 р. N 103 Київ

Про порядок використання у 2007 році коштів, передбачених у державному бюджеті для паспортизації, інвентаризації та реставрації пам'яток архітектури і розроблення схем та проектних рішень масового застосування

{ Із змінами, внесеними згідно з Постановою КМ N 1272 ( 1272-2007-п ) від 31.10.2007 }

Кабінет Міністрів України постановляє:

Установити, що використання у 2007 році коштів, передбачених Міністерству регіонального розвитку та будівництва і Міністерству з питань житлово-комунального господарства у державному бюджеті ( 489-16 ), здійснюється: { Абзац перший постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1272 ( 1272-2007-п ) від 31.10.2007 }

за програмою "Паспортизація, інвентаризація та реставрація пам'яток архітектури" відповідно до Порядку використання у 2006 році коштів, передбачених у державному бюджеті для паспортизації, інвентаризації та реставрації пам'яток архітектури, затвердженого постановою Кабінету Міністрів України від 29 березня 2006 р. N 398 ( 398-2006-п ) (Офіційний вісник України, 2006 р., N 13, ст. 896);

за програмою "Розробка схем та проектних рішень масового застосування" відповідно до постанови Кабінету Міністрів України від 13 вересня 2005 р. N 895 ( 895-2005-п ) "Про порядок використання коштів державного бюджету для розроблення схем та проектних рішень масового застосування" (Офіційний вісник України, 2005 р., N 37, ст. 2291), без дотримання вимог, визначених в абзацах восьмому - десятому зазначеної постанови.
