( Додатково див. Указ Президента N 1475/99 від 22.11.99 )

На зміну статті 2 Указу Президента України від 24 лютого 1997 року N 164 ( 164/97 ) "Про Раду з питань мовної політики" (із змінами внесеними Указом Президента України від 31 грудня 1997 року N 1408 ( 1408/97 ) затвердити новий склад Ради з питань мовної політики при Президентові України (додається).
