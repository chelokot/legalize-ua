Кабінет Міністрів України; Постанова від 26.04.2003 № 601

Про внесення змін до Положення про Українську частину Комітету з питань співробітництва між Україною та Європейськими Співтовариствами (Європейським Союзом)

Стан: Втратив чинність

Ідентифікатор: 601-2003-п

Текст документа від 16.12.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 квітня 2003 р. N 601 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 700 ( 700-2014-п ) від 10.12.2014 }

Про внесення змін до Положення про Українську частину Комітету з питань співробітництва між Україною та Європейськими Співтовариствами (Європейським Союзом)

Кабінет Міністрів України постановляє:

Внести до Положення про Українську частину Комітету з питань співробітництва між Україною та Європейськими Співтовариствами (Європейським Союзом), затвердженого постановою Кабінету Міністрів України від 13 липня 1998 р. N 1074 ( 1074-98-п ) "Питання діяльності Української частини Комітету з питань співробітництва між Україною та Європейськими Співтовариствами (Європейським Союзом)" із змінами внесеними постановами Кабінету Міністрів України від 21 серпня 2000 р. N 1289 ( 1289-2000-п ) (Офіційний вісник України, 2000 р. N 34, ст. 1442), від 6 травня 2001 р. N 424 ( 424-2001-п ) (Офіційний вісник України, 2001 р., N 51, ст. 2278), від 26 квітня 2002 р. N 561 ( 561-2002-п ) (Офіційний вісник України, 2002 р., N 18, ст. 992), від 1 липня 2002 р. N 895 ( 895-2002-п ) (Офіційний вісник України, 2002 р., N 27, ст. 1270) та від 26 вересня 2002 р., N 1441 ( 1441-2002-п ) (Офіційний вісник України, 2002 р., N 39, ст. 1823), такі зміни:

в абзаці сьомому пункту 6 слова "Державний секретар з питань торгівлі Міністерства економіки та з питань європейської інтеграції" замінити словами "Державний секретар з питань європейської інтеграції Міністерства економіки та з питань європейської інтеграції";

в абзаці шостому пункту 7 слова "Уповноваженому України з питань європейської інтеграції" замінити словами "Уповноваженому України з питань європейської і євроатлантичної інтеграції".
