Про затвердження Переліку медичних виробів, що підлягають державній реєстрації (перереєстрації) в Україні

{ Із змінами, внесеними згідно з Наказами Міністерства охорони здоров'я N 229 ( z0543-06 ) від 17.04.2006 N 89 ( z0533-07 ) від 23.02.2007 }

Відповідно до пункту 4, підпункту 10, Положення про Державну службу лікарських засобів і виробів медичного призначення, затвердженого постановою Кабінету Міністрів України від 02.06.2003 N 789 ( 789-2003-п ), з метою забезпечення населення України якісними, ефективними та безпечними медичними виробами НАКАЗУЮ:

1. Затвердити Перелік медичних виробів, що підлягають державній реєстрації (перереєстрації) в Україні (додається).

2. Уважати таким, що втратив чинність, Перелік виробів медичного призначення, які підлягають державній реєстрації в Україні, затверджений наказом МОЗ України від 26.09.2000 N 229 ( z0035-01 ), зареєстрований у Міністерстві юстиції України 17.01.2001 за N 35/5226 (із змінами).

3. Першому заступнику Голови Державної служби лікарських засобів і виробів медичного призначення (Демченко І.Б). забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням наказу покласти на заступника Міністра Рибчука В.О.

Міністр М.Є.Поліщук
