РОЗПОРЯДЖЕННЯ від 23 червня 2010 р. N 1248-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про голову Організаційного комітету з підготовки та відзначення 100-річчя Українського лікарського товариства

Затвердити Міністра охорони здоров'я Митника Зіновія Миколайовича головою Організаційного комітету з підготовки та відзначення 100-річчя Українського лікарського товариства, утвореного розпорядженням Кабінету Міністрів України від 24 лютого 2010 р. N 364 ( 364-2010-р ), звільнивши від цих обов'язків Князевича Василя Михайловича.

Прем'єр-міністр України М.АЗАРОВ
