ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 5 жовтня 2011 р. N 1022

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. У постанові Кабінету Міністрів України від 13 березня 2002 р. N 288 ( 288-2002-п ) "Про затвердження переліків центральних органів виконавчої влади, на які покладаються функції технічного регулювання у визначених сферах діяльності та розроблення технічних регламентів" (Офіційний вісник України, 2002 р., N 11, ст. 521; 2010 р., N 58, ст. 2025):

1) перелік центральних органів виконавчої влади, на які покладається розроблення технічних регламентів ( 288-2002-п ), затверджений зазначеною постановою, доповнити позицією "Мін'юст";

2) у переліку центральних органів виконавчої влади, на які покладаються функції технічного регулювання у визначених сферах діяльності ( 288-2002-п ), затвердженому зазначеною постановою:

у графі "Сфера діяльності, в якій виконуватимуться функції технічного регулювання" у позиції "Держкомінформнауки" слова ", електронний цифровий підпис" виключити;

доповнити перелік ( 288-2002-п ) такою позицією:

"Мін'юст електронний цифровий підпис".

2. У пункті 2 постанови Кабінету Міністрів України від 28 жовтня 2004 р. N 1451 ( 1451-2004-п ) "Про затвердження Положення про центральний засвідчувальний орган" (Офіційний вісник України, 2004 р., N 44, ст. 2893; 2010 р., N 58, ст. 2025) слова "Державний комітет з питань науки, інновацій та інформатизації" замінити словами "Міністерство юстиції".

3. У пункті 6 Порядку застосування електронного цифрового підпису органами державної влади, органами місцевого самоврядування, підприємствами, установами та організаціями державної форми власності, затвердженого постановою Кабінету Міністрів України від 28 жовтня 2004 р. N 1452 ( 1452-2004-п ) (Офіційний вісник України, 2004 р., N 44, ст. 2894; 2006 р., N 50, ст. 3324; 2010 р., N 2, ст. 67, N 58, ст. 2025), слово "Держкомінформнауки" замінити словом "Мін'юстом", а слово "Мінекономіки" - словом "Мінекономрозвитку".
