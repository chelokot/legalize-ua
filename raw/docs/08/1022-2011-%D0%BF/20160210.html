ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

2. У пункті 2 постанови Кабінету Міністрів України від 28 жовтня 2004 р. N 1451 ( 1451-2004-п ) "Про затвердження Положення про центральний засвідчувальний орган" (Офіційний вісник України, 2004 р., N 44, ст. 2893; 2010 р., N 58, ст. 2025) слова "Державний комітет з питань науки, інновацій та інформатизації" замінити словами "Міністерство юстиції".

У пункті 6 Порядку застосування електронного цифрового підпису органами державної влади, органами місцевого самоврядування, підприємствами, установами та організаціями державної форми власності, затвердженого постановою Кабінету Міністрів України від 28 жовтня 2004 р. N 1452 ( 1452-2004-п ) (Офіційний вісник України, 2004 р., N 44, ст. 2894; 2006 р., N 50, ст. 3324; 2010 р., N 2, ст. 67, N 58, ст. 2025), слово "Держкомінформнауки" замінити словом "Мін'юстом", а слово "Мінекономіки" - словом "Мінекономрозвитку".
