{ Преамбула в редакції Наказу Управління державної охорони N 225 ( z0892-07 ) від 23.07.2007 }

2. З наказом ознайомити особовий склад Управління.

ІНСТРУКЦІЯ про порядок польових виплат військовослужбовцям Управління державної охорони України

{ В тексті цієї Інструкції слово (розпорядження) виключено на підставі Наказу Управління державної охорони N 1161 ( z1888-25 ) від 03.12.2025 }

1. Військовослужбовцям Управління державної охорони України (далі — військовослужбовці) за час перебування у навчальних центрах, на полігонах і навчаннях для відпрацювання завдань з бойової (навчально-бойової) підготовки за межами постійного місця служби, проводяться польові виплати (далі — польові) у розмірі 100 відсотків добових, визначених Кабінетом Міністрів України для виплати під час службових відряджень у межах України.

{ Пункт 1 в редакції Наказу Управління державної охорони N 1161 ( z1888-25 ) від 03.12.2025, з урахуванням змін, внесених Наказом Наказом Управління державної охорони N 1245 ( z1917-25 ) від 18.12.2025}

2. Польові, у тому числі за час перебування в дорозі, виплачуються військовослужбовцям, направленим на підставі наказу Управління державної охорони України для відпрацювання завдань з бойової (навчально-бойової) підготовки в навчальні центри, на полігони та навчальні заклади.

{ Пункт 2 в редакції Наказу Управління державної охорони N 182 ( z0976-16 ) від 29.06.2016 }

3. Польові, у тому числі за час перебування в дорозі, також виплачуються військовослужбовцям:

3.1. Направленим для обслуговування військовослужбовців, що відпрацьовують завдання з бойової (навчально-бойової) підготовки в навчальних центрах, на полігонах та навчальних закладах, зазначеним у пункті 2 Інструкції про порядок польових виплат військовослужбовцям Управління державної охорони України (далі - Інструкція).

3.2. Направленим для охорони, обладнання або ремонту навчальних центрів.

3.3. Направленим для виконання робіт та службових завдань, крім поїздок на навчальні заняття, польові виїзди та інших випадків, коли військовослужбовцям згідно з чинним законодавством виплачуються добові.

3.4. Направленим у навчальні центри і табори для складання конкурсних вступних іспитів у військові навчальні заклади, у тому числі на факультети заочного навчання, а також для складання заліків та іспитів екстерном за повний курс військових навчальних закладів.

4. Визначення кількості днів для виплати польових проводиться з урахуванням дня вибуття і дня прибуття до місця постійного розташування (до пункту постійного розквартирування) регіонального підрозділу, що зараховуються як два дні.

5. Польові виплачуються військовослужбовцям за місцем їх штатної служби.

Про виплату польових робиться запис у посвідченні про відрядження із зазначенням, за який період і в якій сумі проведена виплата.

6. У разі направлення військовослужбовців у навчальні центри (навчальні військові заклади) для відпрацювання завдань з бойової (навчально-бойової) підготовки, на полігони, і навчання за межами постійного місця служби строком на один день або в таку місцевість, звідки вони мають можливість щоденно повертатися до місця служби або постійного місця проживання, польове забезпечення виплачується як за повну добу.

{Пункт 6 із змінами, внесеними згідно з Наказом Управління державної охорони N 1161 ( z1888-25 ) від 03.12.2025 }

7. Польові, у тому числі за час перебування у дорозі, не виплачуються:

7.1. Військовослужбовцям, виведеним для відпрацювання завдань з бойової (навчально-бойової) підготовки в навчальні центри, на полігони та навчальні заклади без наказу Управління державної охорони України.

7.2. Військовослужбовцям, виведеним для відпрацювання завдань з бойової (навчально-бойової) підготовки в навчальні центри, на полігони та навчальні заклади, за дні, коли вони забезпечувалися харчуванням за рахунок держави.

7.3. За період перебування військовослужбовців на лікуванні.

7.4. Військовослужбовцям, які відповідно до законодавства мають право на одержання добових.

7.5. За період перебування військовослужбовців під арештом. { Пункт 7 в редакції Наказу Управління державної охорони N 182 ( z0976-16 ) від 29.06.2016 }

8. Утримання аліментів із польових виплат не проводиться.

{ Пункт 8 із змінами, внесеними згідно з Наказом Управління державної охорони N 182 ( z0976-16 ) від 29.06.2016 }
