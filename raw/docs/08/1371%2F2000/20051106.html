Про Всеукраїнську політичну консультативну раду

Стан: Втратив чинність

Ідентифікатор: 1371/2000

Текст документа від 06.11.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президент N 1435/2005 ( 1435/2005 ) від 12.10.2005 )

Про Всеукраїнську політичну консультативну раду

( Із змінами, внесеними згідно з Указами Президента N 547/2001 ( 547/2001 ) від 24.07.2001 N 1365/2003 ( 1365/2003 ) від 27.11.2003 )

( У тексті Указу слова "Політична рада при Президентові України" в усіх відмінках замінено словами "Всеукраїнська політична консультативна рада" у відповідних відмінках згідно з Указом Президента N 547/2001 ( 547/2001 ) від 24.07.2001 )

З метою більш повного врахування позицій політичних сил при виробленні державної політики, пропозицій та рекомендацій партій щодо дальшого вдосконалення політичної системи суспільства, налагодження конструктивної взаємодії між органами державної влади і об'єднаннями громадян для забезпечення стабільності в державі та відповідно до пункту 28 статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Утворити Всеукраїнську політичну консультативну раду як консультативно-дорадчий орган (далі - Політична рада).

Політичну раду очолює Президент України.

До складу Політичної ради входять представники політичних партій.

Персональний склад Політичної ради затверджує Президент України.

2. Призначити КУРАСА Івана Федоровича - народного депутата України - Секретарем Всеукраїнської політичної консультативної ради (за згодою). ( Стаття 2 із змінами, внесеними згідно з Указом Президента N 1365/2003 ( 1365/2003 ) від 27.11.2003 )

3. Секретареві Політичної ради подати у двотижневий строк проект Положення про Всеукраїнську політичну консультативну раду та пропозиції щодо її складу.

4. Організаційні та інші види забезпечення діяльності Політичної ради покласти на Адміністрацію Президента України.

Президент України Л.КУЧМА
