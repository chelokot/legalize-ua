КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 березня 2011 р. N 163-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 5 ( 5-2020-п ) від 15.01.2020 }

Про зміну складу Української частини Спільного комітету експертів з реалізації Угоди між Україною та Європейським Співтовариством про спрощення оформлення віз

Ввести до складу Української частини Спільного комітету експертів з реалізації Угоди між Україною та Європейським Співтовариством про спрощення оформлення віз, утвореної розпорядженням Кабінету Міністрів України від 2 квітня 2008 р. N 556 ( 556-2008-р ), Олефірова Андрія Володимировича - директора департаменту консульської служби Міністерства закордонних справ як голову Української частини зазначеного Комітету, вивівши з її складу Єлісєєва Костянтина Петровича - заступника Міністра закордонних справ.

Прем'єр-міністр України М.АЗАРОВ
