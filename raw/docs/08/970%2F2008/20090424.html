Про зупинення дії пункту 1 розпорядження Кабінету Міністрів України від 17 жовтня 2008 року N 1335-р

{ Додатково див. Конституційне подання Президента ( n0033100-08 ) від 29.10.2008 }

Кабінетом Міністрів України 17 жовтня 2008 року видано розпорядження N 1335-р ( 1335-2008-р ) "Про передачу Мінпромполітики повноважень з управління корпоративними правами держави стосовно деяких господарських товариств".

Пунктом 1 зазначеного розпорядження ( 1335-2008-р ) передбачено передати Міністерству промислової політики України повноваження з управління корпоративними правами держави стосовно низки господарських товариств.

Це рішення прийнято Кабінетом Міністрів України без участі Фонду державного майна України.

Таким чином, розпорядження N 1335-р ( 1335-2008-р ) видано Кабінетом Міністрів України на порушення припису Конституції України ( 254к/96-ВР ) щодо здійснення Кабінетом Міністрів України управління об'єктами державної власності відповідно до закону (пункт 5 статті 116) ( 254к/96-ВР ), адже Законом України "Про управління об'єктами державної власності" ( 185-16 ) встановлено, що рішення про передачу повноважень з управління корпоративними правами держави уповноваженим органам управління приймається Урядом за поданням Фонду державного майна України (пункт 14 частини другої статті 5) ( 185-16 ), чим порушено також вимоги частини другої статті 8, частини другої статті 19 та частини третьої статті 113 Конституції України ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, діяти на підставі та у спосіб, що ними передбачені, а також встановлюють, що нормативно-правові акти повинні прийматися на основі Конституції України ( 254к/96-ВР ) і відповідати їй.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію пункту 1 розпорядження Кабінету Міністрів України від 17 жовтня 2008 року N 1335-р ( 1335-2008-р ) "Про передачу Мінпромполітики повноважень з управління корпоративними правами держави стосовно деяких господарських товариств".

2. Цей Указ набирає чинності з дня його опублікування.
