{ Указ втратив чинність на підставі Указу Президента N 481/2010 ( 481/2010 ) від 02.04.2010 }

Про внесення змін до Указу Президента України від 17 березня 2008 року N 220

На часткову зміну статті 2 Указу Президента України від 17 березня 2008 року N 220 ( 220/2008 ) "Про Координаційну раду з проблем ВІЛ-інфекції/СНІДу, туберкульозу та наркоманії":

затвердити у складі Координаційної ради з проблем ВІЛ-інфекції/СНІДу, туберкульозу та наркоманії НАЛИВАЙЧЕНКА Валентина Олександровича - Голову Служби безпеки України;

вивести зі складу Координаційної ради з проблем ВІЛ-інфекції/СНІДу, туберкульозу та наркоманії В. Кощинця, В. Пинзеника, Е. Прутніка.

Президент України В.ЮЩЕНКО
