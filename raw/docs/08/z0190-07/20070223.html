МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

23.02.2007 N 66

Зареєстровано в Міністерстві юстиції України 5 березня 2007 р. за N 190/13457

Про внесення змін до деяких наказів Міністерства праці та соціальної політики України

Відповідно до постанови Кабінету Міністрів України від 14.08.2006 N 1195 ( 1195-2006-п ) "Про перетворення Державного департаменту промислової безпеки, охорони праці та гірничого нагляду" НАКАЗУЮ:

Унести до наказів Міністерства праці та соціальної політики України такі зміни:

1) у наказі Міністерства праці та соціальної політики України від 31.03.2006 N 97 ( z0407-06 ) "Про умови оплати праці працівників територіальних органів Державного департаменту промислової безпеки, охорони праці та гірничого нагляду", зареєстрованому в Міністерстві юстиції України 10.04.2006 за N 407/12281 (із змінами):

у назві наказу ( z0407-06 ) та додатка до наказу слова "Державного департаменту промислової безпеки, охорони праці та гірничого нагляду" замінити словами "Державного комітету України з промислової безпеки, охорони праці та гірничого нагляду";

у пунктах 1 та 4 наказу ( z0407-06 ) слово "Держпромгірнагляду" замінити словом "Держгірпромнагляду";

2) у наказі Міністерства праці та соціальної політики України від 10.08.2006 N 303 ( z0968-06 ) "Про внесення змін до наказу Міністерства праці та соціальної політики України від 31.03.2006 N 97", зареєстрованому в Міністерстві юстиції України 11.08.2006 за N 968/12842:

у назві додатка до наказу ( z0968-06 ) слова "Державного департаменту промислової безпеки, охорони праці та гірничого нагляду" замінити словами "Державного комітету України з промислової безпеки, охорони праці та гірничого нагляду";

у пункті 3 наказу ( z0968-06 ) слово "Держпромгірнагляду" замінити словом "Держгірпромнагляду".

Міністр М.Папієв
