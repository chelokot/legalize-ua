Стан: Втратив чинність

Ідентифікатор: 168-97-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 березня 1997 р. N 168-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Про звільнення від сплати ввізного мита на двигуни, запасні частини та обладнання до автобусів типу "Ікарус"

( Із змінами, внесеними згідно з Розпорядженням КМ N 281-р ( 281-98-р ) від 05.05.98 )

Прийняти пропозицію Мінтрансу про звільнення від сплати ввізного мита на двигуни, запасні частини, обладнання та акумулятори, що поставляються для ремонту та технічного обслуговування автобусів типу "Ікарус", які здійснюють перевезення пасажирів на міських та приміських маршрутах, відповідно до контрактів (договорів) згідно з додатком.

Держмитслужбі у 10-денний термін забезпечити реєстрацію зазначених контрактів (договорів) разом із специфікаціями до них.

Внесення змін та доповнень до цих контрактів (договорів) не допускається.

Прем'єр-міністр України П.ЛАЗАРЕНКО

Інд.34

Додаток до розпорядження Кабінету Міністрів України від 28 березня 1997 р. N 168-р
