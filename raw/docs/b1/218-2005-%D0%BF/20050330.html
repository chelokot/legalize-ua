Текст документа від 30.03.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 березня 2005 р. N 218 Київ

Про внесення зміни до постанови Кабінету Міністрів України від 27 січня 1997 р. N 55 та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. У назві та тексті постанови Кабінету Міністрів України від 27 січня 1997 р. N 55 ( 55-97-п ) "Про оплату праці працівників центрів підвищення кваліфікації державних службовців і керівників державних підприємств, установ та організацій" (Офіційний вісник України, 1997 р., число 5, с. 124; 2001 р., N 21, ст. 938) слова "центрів підвищення кваліфікації державних службовців і керівників" замінити словами "центрів перепідготовки та підвищення кваліфікації працівників органів державної влади, органів місцевого самоврядування".

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів Укоаїни згідно з переліком, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 19

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 30 березня 2005 р. N 218

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 5 червня 1995 р. N 391 ( 391-95-п ) "Про заходи щодо виконання Указу Президента України від 19 травня 1995 р. N 381".

2. Постанова Кабінету Міністрів України від 28 липня 1995 р. N 560 ( 560-95-п ) "Про заходи щодо підвищення кваліфікації державних службовців органів державної влади".

3. Пункт 4 постанови Кабінету Міністрів України від 9 липня 1997 р N 725 ( 725-97-п ) "Про створення Академії муніципального управління" (Офіційний вісник України, 1997 р., число 28, с. 133).

4. Постанова Кабінету Міністрів України від 18 лютого 1998 р. N 196 ( 196-98-п ) "Про включення Одеської державної юридичної академії до Переліку вищих навчальних закладів з підготовки та перепідготовки фахівців органів виконавчої влади та ринкової економіки" (Офіційний вісник України, 1998 р., N 7, ст. 270).

5. Постанова Кабінету Міністрів України від 3 листопада 2000 р. N 1647 ( 1647-2000-п ) "Про включення Національного аграрного університету до переліку вищих навчальних закладів з підготовки та перепідготовки фахівців органів виконавчої влади та ринкової економіки" (Офіційний вісник України, 2000 р., N 45, ст. 1929).

6. Пункт 1 змін, що вносяться до постанов Кабінету Міністрів України з питань підготовки магістрів в освітній галузі "Державне управління", затверджених постановою Кабінету Міністрів України від 28 грудня 2001 р. N 1812 ( 1812-2001-п ) (Офіційний вісник України, 2002 р., N 1, ст. 24).

7. Пункт 2 постанови Кабінету Міністрів України від 2 червня 2003 р. N 828 ( 828-2003-п ) "Про заходи щодо підвищення кваліфікації працівників органів державної влади та органів місцевого самоврядування з питань боротьби з корупцією" (Офіційний вісник України, 2003 р., N 23, ст. 1056).

8. Постанова Кабінету Міністрів України від 17 липня 2003 р. N 1113 ( 1113-2003-п ) "Про розширення переліку вищих навчальних закладів з підготовки та перепідготовки фахівців органів державної влади та ринкової економіки" (Офіційний вісник України, 2003 р., N 30, ст. 1552).

9. Постанова Кабінету Міністрів України від 4 березня 2004 р. N 278 ( 278-2004-п ) "Про включення Національного університету "Острозька академія" до переліку вищих навчальних закладів з підготовки та перепідготовки фахівців органів виконавчої влади та ринкової економіки" (Офіційний вісник України, 2004 р., N 10, ст. 603).

10. Постанова Кабінету Міністрів України від 2 червня 2004 р. N 743 ( 743-2004-п ) "Про включення Чернігівського державного технологічного університету до переліку вищих навчальних закладів з підготовки та перепідготовки фахівців органів виконавчої влади та ринкової економіки" (Офіційний вісник України, 2004 р., N 22, ст. 1513).

11. Постанова Кабінету Міністрів України від 4 листопада 2004 р. N 1482 ( 1482-2004-п ) "Про включення Миколаївського державного гуманітарного університету імені Петра Могили до переліку вищих навчальних закладів з підготовки та перепідготовки фахівців органів виконавчої влади та ринкової економіки" (Офіційний вісник України, 2004 р., N 44, ст. 2912).
