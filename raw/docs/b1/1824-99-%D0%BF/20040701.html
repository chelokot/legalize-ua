КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 жовтня 1999 р. N 1824 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1821 ( 1821-2003-п ) від 26.11.2003 )

Про внесення доповнення до Положення про державну реєстрацію суб'єктів підприємницької діяльності

Кабінет Міністрів України постановляє:

Доповнити пункт 34 Положення про державну реєстрацію суб'єктів підприємницької діяльності, затвердженого постановою Кабінету Міністрів України від 25 травня 1998 р. N 740 ( 740-98-п ) "Про порядок державної реєстрації суб'єктів підприємницької діяльності" (Офіційній вісник України, 1998 р., N 21, ст. 767; 1999 р., N 18, ст. 790), абзацом такого змісту:

"Інвестиційними фондами та інвестиційними компаніями додатково надсилаються повідомлення Державної комісії з цінних паперів та фондового ринку про скасування реєстрації випуску інвестиційних сертифікатів інвестиційних фондів та інвестиційних компаній".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
