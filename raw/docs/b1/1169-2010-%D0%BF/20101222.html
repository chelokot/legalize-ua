КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 грудня 2010 р. N 1169 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 22 липня 2009 р. N 791 ( 791-2009-п ) "Про утворення Державного комерційного підприємства "Науково-технологічний комплекс "Ресурс" (Офіційний вісник України, 2009 р., N 58, ст. 2032);

постанову Кабінету Міністрів України від 28 жовтня 2009 р. N 1343 ( 1343-2009-п ) "Про спрямування коштів Стабілізаційного фонду для фінансування інвестиційних проектів, які реалізуються на підприємствах авіабудування, оборонно-промислового комплексу і машинобудування, та першочергових заходів щодо державної підтримки відкритого акціонерного товариства "SELMI" (Офіційний вісник України, 2009 р., N 96, ст. 3315);

постанову Кабінету Міністрів України від 17 лютого 2010 р. N 137 ( 137-2010-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 22 липня 2009 р. N 791" (Офіційний вісник України, 2010 р., N 11, ст. 538).
