N 1542 ( 1542-2004-п ) "Деякі питання оплати праці працівників Національної експертної комісії з питань захисту суспільної моралі" (Офіційний вісник України, 2004 р., N 46, ст. 3028; 2007 р., N 81, ст. 3013), виклавши його в редакції, що додається.
