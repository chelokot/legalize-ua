Питання виготовлення бланків посвідчень ветеранів війни і бланків листів талонів на право одержання проїзних квитків

Стан: Чинний

Текст документа від 26.01.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 липня 2006 р. N 1026 Київ

Питання виготовлення бланків посвідчень ветеранів війни і бланків листів талонів на право одержання проїзних квитків

{ Із змінами, внесеними згідно з Постановами КМ N 1720 ( 1720-2006-п ) від 13.12.2006 N 12 ( 12-2009-п ) від 14.01.2009 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 12 ( 12-2009-п ) від 14.01.2009 }

2. Визнати таким, що втратив чинність, абзац другий пункту 1 постанови Кабінету Міністрів України від 2 січня 1995 р. N 1 ( 1-95-п ) "Про доповнення постанови Кабінету Міністрів України від 12 травня 1994 р. N 302" (ЗП України, 1995 р., N 3, ст. 68).

3. Ця постанова набирає чинності з 1 січня 2007 року.
