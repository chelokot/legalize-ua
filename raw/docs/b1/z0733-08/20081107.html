Про затвердження витрат НАК "Нафтогаз України" на реалізацію природного газу

Реєстрація: Мін'юст України від 11.08.2008 № 733/15424

Стан: Втратив чинність

Ідентифікатор: z0733-08

Текст документа від 07.11.2008:

МІНІСТЕРСТВО ПАЛИВА ТА ЕНЕРГЕТИКИ УКРАЇНИ

НАКАЗ

25.07.2008 N 396

Зареєстровано в Міністерстві юстиції України 11 серпня 2008 р. за N 733/15424

Про затвердження витрат НАК "Нафтогаз України" на реалізацію природного газу

{ Із змінами, внесеними згідно з Наказом Міністерства палива та енергетики N 517 ( z1027-08 ) від 21.10.2008 }

На виконання вимог постанови Кабінету Міністрів України від 29.04.2006 N 605 ( 605-2006-п ) "Деякі питання діяльності Національної акціонерної компанії "Нафтогаз України" (зі змінами) НАКАЗУЮ:

1. Затвердити витрати Національної акціонерної компанії "Нафтогаз України" на реалізацію природного газу на рівні 121,00 грн за 1000 куб.м без урахування податку на додану вартість.

{ Пункт 1 із змінами, внесеними згідно з Наказом Міністерства палива та енергетики N 517 ( z1027-08 ) від 21.10.2008 }

2. Визнати таким, що втратив чинність, наказ Мінпаливенерго від 25 квітня 2008 року N 247 ( v0247558-08 ) "Про затвердження витрат НАК "Нафтогаз України" на реалізацію природного газу".

3. Контроль за виконанням цього наказу покласти на першого заступника Міністра Бугайова О.А.

Міністр Ю.Продан
