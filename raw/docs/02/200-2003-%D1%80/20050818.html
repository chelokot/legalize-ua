Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 квітня 2003 року N 200-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про голову робочої групи для опрацювання питань, пов'язаних з подальшим функціонуванням державних холдингових та акціонерних компаній, статутні фонди яких сформовано за рахунок закріплених у державній власності пакетів акцій

Затвердити головою робочої групи для опрацювання питань, пов'язаних з подальшим функціонуванням державних холдингових та акціонерних компаній, статутні фонди яких сформовано за рахунок закріплених у державній власності пакетів акцій, утвореної розпорядженням Кабінету Міністрів України від 5 червня 2000 р. N 250 ( 250-2000-р ), Міністра економіки та з питань європейської інтеграції Хорошковського Валерія Івановича, увільнивши від цих обов'язків Шлапака Олександра Віталійовича.

Перший віце-прем'єр-міністр України М.АЗАРОВ
