МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ МІНІСТЕРСТВО ПАЛИВА ТА ЕНЕРГЕТИКИ УКРАЇНИ ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ДЕРЖАВНОГО МАТЕРІАЛЬНОГО РЕЗЕРВУ ДЕРЖАВНА АКЦІОНЕРНА КОМПАНІЯ "ХЛІБ УКРАЇНИ"

НАКАЗ

15.09.2005 N 471/473/252/68

Зареєстровано в Міністерстві юстиції України 29 вересня 2005 р. за N 1118/11398

Про визнання таким, що втратив чинність, спільного наказу Міністерства агропромислового комплексу України, Міністерства енергетики України, Державного комітету України по матеріальних резервах та Державної акціонерної компанії "Хліб України" від 26.08.98 N 250/145/138/82

Відповідно до Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" та розпорядження Кабінету Міністрів України від 08.08.2005 N 321-р ( 321-2005-р ) "Про першочергові заходи щодо поліпшення стану справ із прискоренного перегляду регуляторних актів та вдосконалення реєстраційної і дозвільної процедури" НАКАЗУЄМО:

1. Визнати таким, що втратив чинність, спільний наказ Міністерства агропромислового комплексу України, Міністерства енергетики України, Державного комітету України по матеріальних резервах та Державної акціонерної компанії "Хліб України" від 26.08.98 N 250/145/138/82 ( z0550-98 ) "Про затвердження порядку погашення сільськогосподарськими товаровиробниками заборгованості за спожиту електроенергію шляхом поставок сільськогосподарської продукції", зареєстрований в Міністерстві юстиції України 07.09.98 за N 550/2990.

2. Департаменту науково-технічної політики Міністерства аграрної політики України (Кульгавий В.Ф.):

2.1. У встановленому порядку подати наказ на державну реєстрацію до Міністерства юстиції України.

2.2. Довести наказ до відома підприємств та організацій.

3. Контроль за виконанням наказу покласти на заступника Міністра аграрної політики України Мельника С.І.

Міністр аграрної політики України О.П.Баранівський

Міністр палива та енергетики України І.В.Плачков
