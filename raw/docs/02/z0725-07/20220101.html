МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

21.06.2007 N 543

Зареєстровано в Міністерстві юстиції України 25 червня 2007 р. за N 725/13992

Про внесення змін до Правил видачі свідоцтв авіаційному персоналу в Україні та Правил сертифікації експлуатантів

{ Із змінами, внесеними згідно з Наказом Державної авіаційної служби N 682 ( z1109-18 ) від 05.07.2018 }

Відповідно до поправки 167 до Міжнародних стандартів та практики, що рекомендується, "Видача свідоцтв авіаційному персоналу" (Додаток 1 ( 995_655 ) до Конвенції про міжнародну цивільну авіацію ( 995_038 ), яка вступила в дію 23.11.2006, НАКАЗУЮ:

1. Унести зміну до пункту 5.1.7 Правил видачі свідоцтв авіаційному персоналу в Україні, затверджених наказом Мінтрансу України від 07.12.98 N 486 ( z0833-98 ), зареєстрованих в Міністерстві юстиції України 29.12.98 за N 833/3273 (із змінами), замінивши цифри "60" цифрами "63".

{ Пункт 2 втратив чинність на підставі Наказу Державної авіаційної служби N 682 ( z1109-18 ) від 05.07.2018 }

3. Заступнику голови Даржавіаадміністрації Ігнат'єву О.М:

3.1. Забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України в установленому законодавством порядку.

3.2. Довести цей наказ до відома всіх зацікавлених підприємств, організацій, експлуатантів та авіаційних навчальних закладів.

4. Контроль за виконанням цього наказу покласти на заступника Міністра - голову Державної авіаційної адміністрації Колісника А.А.

Міністр М.Рудьковський
