Про встановлення строку виконання ремонтно-відновлювальних робіт для деяких металообробних верстатів за межами митної території України

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 квітня 2005 р. N 127-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання ремонтно-відновлювальних робіт для деяких металообробних верстатів за межами митної території України

Відповідно до статті 240 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити для металообробних верстатів моделей W250HC Ob23956, W200 Ob21301, W250T Ob20799, W200T Ob20800, W200 Ob20120, W200G Ob21837, W250G Ob21327 строк виконання ремонтно-відновлювальних робіт за межами митної території України 360 днів.

Прем'єр-міністр України Ю.ТИМОШЕНКО
