ПОСТАНОВА від 13 квітня 2011 р. N 393 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 704 ( 704-2017-п ) від 30.08.2017 з урахуванням змін, внесених Постановами КМ N 1052 ( 1052-2017-п ) від 27.12.2017, N 103 ( 103-2018-п ) від 21.02.2018 }

Про внесення змін до постанови Кабінету Міністрів України від 22 вересня 2010 р. N 889

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 22 вересня 2010 р. N 889 ( 889-2010-п ) "Питання грошового забезпечення окремих категорій військовослужбовців Збройних Сил, Державної прикордонної служби та внутрішніх військ Міністерства внутрішніх справ" (Офіційний вісник України, 2010 р., N 74, ст. 2632) такі зміни:

назву постанови ( 889-2010-п ) викласти в такій редакції:

"Питання грошового забезпечення окремих категорій військовослужбовців Збройних Сил, Державної прикордонної служби, внутрішніх військ Міністерства внутрішніх справ та осіб начальницького складу органів і підрозділів цивільного захисту Міністерства надзвичайних ситуацій";

пункт 1 після слів "та льотного складу внутрішніх військ Міністерства внутрішніх справ," доповнити словами "особам начальницького складу, які проходять службу на посадах льотного складу органів і підрозділів цивільного захисту Міністерства надзвичайних ситуацій,";

у пункті 2 після слів "Міністерством внутрішніх справ" доповнити словами ", Міністерством надзвичайних ситуацій", слова "Міністерством праці та соціальної політики" замінити словами "Міністерством соціальної політики".

Прем'єр-міністр України М.АЗАРОВ
