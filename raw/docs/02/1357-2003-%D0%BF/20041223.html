Текст документа від 23.12.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 серпня 2003 р. N 1357 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1734 ( 1734-2004-п ) від 23.12.2004 )

Про внесення змін до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

Кабінет Міністрів України постановляє:

Внести до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави, затвердженого постановою Кабінету Міністрів України від 29 серпня 2000 р. N 1346 ( 1346-2000-п ) (Офіційний вісник України, 2000 р., N 35, ст. 1498; 2002 р., N 10, ст. 474), зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 25

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 27 серпня 2003 р. N 1357

ЗМІНИ, що вносяться до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави ( 1346-2000-п )

1. Виключити такі позиції:

а) у підрозділі "Харківська область" розділу "Мінпромполітики" позицію:

"00235967 ВАТ "Куп'янський ливарний завод", смт Ківшарівка";

б) у розділі "Мінпаливенерго":

у підрозділі "Закарпатська область" позицію:

"04815271 ВАТ "Закарпатспецкомплектгаз", м. Ужгород";

у підрозділі "Харківська область" позицію:

"21188002 ВАТ "Харківський інститут інженерних вишукувань і досліджень "Енергопроект".

2. Доповнити підрозділ "м. Київ" розділу "Мінтранс" такою позицією:

"21720000 Державна установа "Держгідрографія".
