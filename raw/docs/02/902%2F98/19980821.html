Президент України; Указ від 21.08.1998 № 902/98

Про ліквідацію Державної акціонерної холдингової компанії "Укргаз"

Стан: Чинний

Ідентифікатор: 902/98

Текст документа від 21.08.1998:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про ліквідацію Державної акціонерної холдингової компанії "Укргаз"

У зв'язку із створенням Національної акціонерної компанії "Нафтогаз України" постановляю:

1. Кабінету Міністрів України здійснити у двомісячний строк заходи щодо ліквідації Державної акціонерної холдингової компанії "Укргаз".

2. Визнати такими, що втратили чинність:

Указ Президента України від 5 травня 1996 року N 308 ( 308/96 ) "Про створення Державної акціонерної холдингової компанії "Укргаз";

Указ Президента України від 20 вересня 1997 року N 1052 ( 1052/97 ) "Про часткову зміну статті 3 Указу Президента України від 5 травня 1996 року N 308".

3. Цей Указ набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 21 серпня 1998 року N 902/98
