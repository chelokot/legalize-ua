Про внесення змін до наказу Міністерства праці та соціальної політики України від 31.01.2002 N 78

На виконання постанови Кабінету Міністрів України від 15.01.2005 N 37 ( 37-2005-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 31.01.2002 N 78 ( z0122-02 ) "Про умови оплати праці працівників Секретаріату Комітету з Національної премії України імені Тараса Шевченка", зареєстрованого в Міністерстві юстиції України 08.02.2002 за N 122/6410 (зі змінами), виклавши додаток у новій редакції (додається).

2. Ці умови застосовуються з 1 січня 2005 року.

В. о. Міністра М.Папієв

Заступник Міністра фінансів України О.С.Яременко
