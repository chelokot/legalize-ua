Кабінет Міністрів України; Постанова від 08.02.1999 № 169

Про розмір стипендій Президента України учасникам і призерам міжнародних учнівських олімпіад з базових навчальних предметів

Стан: Втратив чинність

Ідентифікатор: 169-99-п

Текст документа від 01.07.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 лютого 1999 р. N 169 Київ

Про розмір стипендій Президента України учасникам і призерам міжнародних учнівських олімпіад з базових навчальних предметів

( Із змінами, внесеними згідно з Постановами КМ N 577 ( 577-2000-п ) від 29.03.2000 N 882 ( 882-2004-п ) від 12.07.2004 )

На виконання статті 1 Указу Президента України від 30 грудня 1998 р. N 1419 ( 1419/98 ) "Про стипендії Президента України учасникам та призерам міжнародних учнівських олімпіад з базових навчальних предметів" Кабінет Міністрів України постановляє:

1. Установити, що стипендії Президента України учасникам і призерам міжнародних учнівських олімпіад з базових навчальних предметів виплачуються у таких розмірах мінімальної академічної стипендії студентів вищих навчальних закладів III-IV рівня акредитації:

2,5 - для учасників;

4,375 - для призерів.

( Пункт 1 в редакції Постанови КМ N 882 ( 882-2004-п ) від 12.07.2004 )

2. Виплату стипендій Президента України здійснювати відповідно до Положення про порядок призначення стипендій Президента України учасникам і призерам міжнародних учнівських олімпіад з базових навчальних предметів, затвердженого Указом Президента України від 30 грудня 1998 р. N 1419.

Віце-прем'єр-міністр України С.ТІГІПКО
