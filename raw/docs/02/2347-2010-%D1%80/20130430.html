Про передачу державних вищих навчальних закладів до сфери управління Міністерства освіти і науки, молоді та спорту

Стан: Втратив чинність

Ідентифікатор: 2347-2010-р

Текст документа від 30.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 грудня 2010 р. N 2347-р Київ

{ Розпорядження скасовано на підставі Постанови КМ N 296 ( 296-2013-п ) від 27.03.2013 }

Про передачу державних вищих навчальних закладів до сфери управління Міністерства освіти і науки, молоді та спорту

{ Із змінами, внесеними згідно з Розпорядженням КМ N 814-р ( 814-2011-р ) від 31.08.2011 }

1. Погодитися з пропозицією Міністерства надзвичайних ситуацій та Міністерства освіти і науки, молоді та спорту щодо передачі державних вищих навчальних закладів "Національний університет цивільного захисту України" (крім Інституту державного управління у сфері цивільного захисту, що входить до його складу) та "Академія пожежної безпеки імені Героїв Чорнобиля" до сфери управління Міністерства освіти і науки, молоді та спорту.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 814-р ( 814-2011-р ) від 31.08.2011 }

2. Міністерству фінансів, Міністерству надзвичайних ситуацій разом з Міністерством освіти і науки, молоді та спорту забезпечити передачу в установленому законодавством порядку бюджетних призначень, передбачених Міністерству надзвичайних ситуацій для фінансування діяльності державних вищих навчальних закладів "Національний університет цивільного захисту України" та "Академія пожежної безпеки імені Героїв Чорнобиля".

Прем'єр-міністр України М.АЗАРОВ
