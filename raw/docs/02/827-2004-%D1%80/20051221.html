Про затвердження проекту та титулу будови "Реконструкція з розширенням будинку для розміщення адміністративних приміщень по вул. Білоруській, 24, у Шевченківському районі м. Києва"

Стан: Втратив чинність

Ідентифікатор: 827-2004-р

Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 листопада 2004 р. N 827-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 539-р ( 539-2005-р ) від 21.12.2005 )

Про затвердження проекту та титулу будови "Реконструкція з розширенням будинку для розміщення адміністративних приміщень по вул. Білоруській, 24, у Шевченківському районі м. Києва"

1. Затвердити поданий Держфінмоніторингом проект "Реконструкція з розширенням будинку для розміщення адміністративних приміщень по вул. Білоруській, 24, у Шевченківському районі м. Києва", розроблений АТЗТ "АГРО" (м. Київ) та рекомендований до затвердження Центральною службою Укрінвестекспертизи Держбуду, з такими основними техніко-економічними показниками:

загальна площа - 5692,4 кв. метра

будівельний об'єм - 24131,4 куб. метра

загальна кошторисна вартість - 38950,888 тис. гривень

у тому числі вартість будівельно-монтажних робіт - 20664, 373 тис. гривень

Після закінчення реконструкції розташувати у зазначеному будинку Держфінмоніторинг.

2. Затвердити титул будови "Реконструкція з розширенням будинку для розміщення адміністративних приміщень по вул. Білоруській, 24, у Шевченківському районі м. Києва", що додається.
