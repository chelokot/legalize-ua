МІНІСТЕРСТВО УКРАЇНИ У СПРАВАХ СІМ'Ї, МОЛОДІ ТА СПОРТУ

НАКАЗ

09.02.2010 N 284

Зареєстровано в Міністерстві юстиції України 23 лютого 2010 р. за N 178/17473

Про спеціалізовані формування центрів соціальних служб для сім'ї, дітей та молоді

Відповідно до Закону України "Про соціальну роботу з сім'ями, дітьми та молоддю" ( 2558-14 ), постанови Кабінету Міністрів України від 27 серпня 2004 року N 1126 ( 1126-2004-п ) "Про заходи щодо вдосконалення соціальної роботи із сім'ями, дітьми та молоддю" (із змінами) та з метою оптимізації роботи спеціалізованих формувань центрів соціальних служб для сім'ї, дітей та молоді НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази:

1.1. Міністерства України у справах сім'ї, дітей та молоді від 26.11.2004 N 762 ( z1599-04 ) "Про затвердження Типового положення про студентську соціальну службу", зареєстрований в Міністерстві юстиції України 17.12.2004 за N 1599/10198;

1.2. Міністерства України у справах молоді та спорту від 17.08.2005 N 1658 ( z1259-05 ) "Про затвердження Типового положення про Службу соціальної підтримки сімей", зареєстрований в Міністерстві юстиції України 24.10.2005 за N 1259/11539;

1.3. Міністерства України у справах сім'ї, молоді та спорту від 07.12.2005 N 3133 ( z1580-05 ) "Про затвердження Типового положення про службу "Телефон Довіри", зареєстрований в Міністерстві юстиції України 28.12.2005 за N 1580/11860;

1.4. Міністерства України у справах сім'ї, молоді та спорту від 30.01.2006 N 203 ( z0142-06 ) "Про затвердження Типового положення про Інформаційно-ресурсний центр центру соціальних служб для сім'ї, дітей та молоді", зареєстрований в Міністерстві юстиції України 16.02.2006 за N 142/12016;

1.5. Міністерства України у справах сім'ї, молоді та спорту від 30.01.2006 N 204 ( z0141-06 ) "Про затвердження Типового положення про Школу волонтерів центру соціальних служб для сім'ї, дітей та молоді", зареєстрований в Міністерстві юстиції України 16.02.2006 за N 141/12015;

1.6. Міністерства України у справах сім'ї, молоді та спорту від 23.10.2006 N 3545 ( z1187-06 ) "Про затвердження Типового положення про консультаційний пункт центру соціальних служб для сім'ї, дітей та молоді у пологових стаціонарах, жіночих консультаціях та будинках дитини", зареєстрований в Міністерстві юстиції України 02.11.2006 за N 1187/13061;

1.7. Міністерства України у справах сім'ї, молоді та спорту від 23.01.2008 N 120 ( z0085-08 ) "Про затвердження Типового положення про тренінговий центр центру соціальних служб для сім'ї, дітей та молоді", зареєстрований в Міністерстві юстиції України 07.02.2008 за N 85/14776;

1.8. Міністерства України у справах сім'ї, молоді та спорту від 15.10.2008 N 4163 ( z1218-08 ) "Про затвердження Типового положення про службу соціально-профілактичної роботи", зареєстрований в Міністерстві юстиції України 22.12.2008 за N 1218/15909;

1.9. Міністерства України у справах сім'ї, молоді та спорту від 01.07.2009 N 2300 ( z0643-09 ) "Про затвердження Типового положення про спеціалізоване формування "Мобільний консультаційний пункт соціальної роботи", зареєстрований в Міністерстві юстиції України 16.07.2009 за N 643/16659.

2. Державній соціальній службі для сім'ї, дітей та молоді (Лук'янова Н.Л.) подати цей наказ у встановленому порядку на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра України у справах сім'ї, молоді та спорту Кондратюк Т.В.

4. Цей наказ набирає чинності з дня його офіційного опублікування.
