Стан: Чинний

Текст документа від 30.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 квітня 2009 р. N 343 Київ

Про затвердження Порядку використання у 2009 році коштів, передбачених у державному бюджеті для підтримки розвитку інфраструктури наукової діяльності у сфері інформатизації

{ Із змінами, внесеними згідно з Постановою КМ N 478 ( 478-2010-п ) від 23.06.2010 }

{ Установити, що у 2010 році кошти, передбачені у державному бюджеті ( 2154-17 ) для підтримки розвитку інфраструктури наукової діяльності у сфері інформатизації, використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 478 ( 478-2010-п ) від 23.06.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2009 році коштів, передбачених у державному бюджеті для підтримки розвитку інфраструктури наукової діяльності у сфері інформатизації, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 49

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 15 квітня 2009 р. N 343

ПОРЯДОК використання у 2009 році коштів, передбачених у державному бюджеті для підтримки розвитку інфраструктури наукової діяльності у сфері інформатизації

1. Цей Порядок визначає механізм використання у 2009 році коштів, передбачених у державному бюджеті Мінтрансзв'язку за програмою "Фінансова підтримка розвитку інфраструктури наукової діяльності у сфері інформатизації" (далі - бюджетні кошти).

Розпорядником бюджетних коштів нижчого рівня є Держкомінформатизації.

2. Бюджетні кошти спрямовуються на здійснення заходів з підготовки та проведення за участю представників міжнародних і вітчизняних організацій та компаній міжнародного наукового конгресу з розвитку інформаційно-комунікаційних технологій і розбудови інформаційного суспільства в Україні (далі - заходи).

{ Пункт 2 в редакції Постанови КМ N 478 ( 478-2010-п ) від 23.06.2010 }

3. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється в установленому законодавством порядку.

4. З метою недопущення виникнення кредиторської заборгованості на кінець року до тендерної документації та договору про закупівлю товарів, робіт і послуг включається вимога щодо коригування визначеної в договорі суми та зобов'язань сторін договору в разі зменшення обсягів бюджетних призначень під час уточнення показників державного бюджету.

5. Попередня оплата товарів, робіт і послуг проводиться відповідно до постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752).

Остаточні розрахунки здійснюються замовником згідно з умовами договору на підставі відповідних рахунків та актів приймання-передачі товарів, робіт і послуг.

6. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

6-1. Мінтрансзв'язку затверджує заходи і показники їх виконання з поквартальною розбивкою та подає зазначені матеріали Мінфіну у тижневий строк після затвердження паспорта бюджетної програми.

{ Порядок доповнено пунктом 6-1 згідно з Постановою КМ N 478 ( 478-2010-п ) від 23.06.2010 }

6-2. Інформацію про виконання показників Мінтрансзв'язку подає Мінфіну у тижневий строк після закінчення звітного кварталу та одинадцяти місяців.

У разі невиконання показників Мінтрансзв'язку утворює комісію, яка розглядає питання стосовно доцільності подальшого фінансування та письмово повідомляє у триденний строк Мінфін про прийняте рішення.

У разі коли заходи виконуються з істотними порушеннями, Мінфін та Мінтрансзв'язку проводять узгоджувальні наради, за результатами яких вносять на розгляд Міністрові фінансів пропозиції щодо визначення подальшого порядку фінансування.

{ Порядок доповнено пунктом 6-2 згідно з Постановою КМ N 478 ( 478-2010-п ) від 23.06.2010 }

7. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому порядку.
