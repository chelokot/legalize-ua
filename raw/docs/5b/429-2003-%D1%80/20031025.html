Кабінет Міністрів України; Розпорядження від 17.07.2003 № 429-р

Про визнання таким, що втратило чинність, розпорядження Кабінету Міністрів України від 16 травня 2001 р. N 199

Стан: Втратив чинність

Ідентифікатор: 429-2003-р

Текст документа від 25.10.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 липня 2003 р. N 429-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 638-р ( 638-2003-р ) від 25.10.2003 )

Про визнання таким, що втратило чинність, розпорядження Кабінету Міністрів України від 16 травня 2001 р. N 199

Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 16 травня 2001 р. N 199 ( 199-2001-р ) "Про надання допомоги дітям-сиротам, інвалідам, дітям з малозабезпечених і багатодітних сімей, а також тим, що залишилися без піклування батьків" (Офіційний вісник України, 2001 р., N 20, ст. 895).

Прем'єр-міністр України В.ЯНУКОВИЧ
