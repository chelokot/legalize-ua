Про внесення змін до деяких наказів Держмитслужби України

{ Із змінами, внесеними згідно з Наказом Державної митної служби N 933 ( z1329-07 ) від 07.11.2007 }

Відповідно до Положення про Державну митну службу України, затвердженого Указом Президента України від 24.08.2000 N 1022 ( 1022/2000 ), Положення про вантажну митну декларацію, затвердженого постановою Кабінету Міністрів України від 09.06.97 N 574 ( 574-97-п ) (зі змінами й доповненнями), і з метою спрощення процедури декларування для вільного обігу товарів, які перебувають у режимі митного складу, НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Державної митної служби N 933 ( z1329-07 ) від 07.11.2007 }

2. Унести до Класифікатора документів, затвердженого наказом Держмитслужби України від 09.07.97 N 307 ( z0443-97 ) (зі змінами й доповненнями), зареєстрованим у Міністерстві юстиції України 24.09.97 за N 443/2247, такі зміни:

| |операцію |

3. Департаменту інформаційних технологій та митної статистики (Копосов С.А.) допрацювати програмне забезпечення з урахуванням вимог цього наказу.

4. Департаменту декларування та митних режимів (Науменко В.П.) і Юридичному департаменту (Боженко І.Ф.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

5. Начальникам митних органів довести цей наказ до відома юридичних і фізичних осіб.

6. Установити, що цей наказ набирає чинності через 10 днів з дня його офіційного опублікування.

Контроль за виконанням наказу залишаю за собою.

В.о. Голови Державної митної служби України М.М.Салагор
