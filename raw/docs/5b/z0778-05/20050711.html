Про внесення змін до деяких наказів Держмитслужби України

Відповідно до Положення про Державну митну службу України, затвердженого Указом Президента України від 24.08.2000 N 1022 ( 1022/2000 ), Положення про вантажну митну декларацію, затвердженого постановою Кабінету Міністрів України від 09.06.97 N 574 ( 574-97-п ) (зі змінами й доповненнями), і з метою спрощення процедури декларування для вільного обігу товарів, які перебувають у режимі митного складу, НАКАЗУЮ:

1. Унести до Порядку заповнення граф вантажної митної декларації відповідно до митних режимів (далі - Порядок), затвердженого наказом Держмитслужби України від 30.06.98 N 380 ( z0469-98 ) (зі змінами й доповненнями) і зареєстрованого в Міністерстві юстиції України 22.07.98 за N 469/2909, такі зміни:

1.1. Опис особливостей заповнення графи 18 вантажної митної декларації ( 574-97-п ) (далі - ВМД) у пункті 3.1 Порядку ( z0469-98 ) викласти в такій редакції:

"Графа 18 "Транспортний засіб відправлення"

Зазначаються відомості про транспортний засіб, на якому здійснюється доставка товарів у митницю призначення. При митному оформленні в обраному митному режимі товарів, що перебувають у режимі митного складу, заповнення графи здійснюється в такому порядку:

у митниці за місцем розташування митного ліцензійного складу, на якому зберігаються ці товари, графа не заповнюється;

в іншій митниці в графі зазначаються відомості про транспортний засіб, на якому здійснювалося перевезення цих товарів з митниці за місцем розташування митного ліцензійного складу в митницю призначення".

1.2. Опис особливостей заповнення графи 21 ВМД ( 574-97-п ) у пункті 3.1 Порядку ( z0469-98 ) викласти в такій редакції:

"Графа 21 "Транспортний засіб на кордоні"

Зазначаються відомості про транспортний засіб, на якому товари були ввезені на митну територію України. При митному оформленні товарів в обраному митному режимі після перебування їх у режимі митного складу графа не заповнюється".

1.3. Доповнити пункт 3.1 Порядку ( z0469-98 ) після опису особливостей заповнення графи 21 ВМД ( 574-97-п ) таким описом графи 26 ВМД:

"Графа 26 "Вид транспорту в межах країни"

При митному оформленні товарів в обраному митному режимі після перебування їх у режимі митного складу графа не заповнюється".

1.4. В описі особливостей заповнення графи 37 ВМД ( 574-97-п ) у пункті 3.1 Порядку ( z0469-98 ) слова "декларації-зобов'язання" виключити.

1.5. Доповнити пункт 3.1 Порядку ( z0469-98 ) після опису особливостей заповнення графи 37 ВМД ( 574-97-п ) таким описом графи 44 ВМД:

"Графа 44 "Додаткова інформація/подані документи"

При митному оформленні товарів в обраному митному режимі після перебування їх у режимі митного складу до графи не вносяться реквізити документів контролю за доставкою цих товарів з митниці відправлення в митницю за місцем розташування митного ліцензійного складу, на якому зберігалися ці товари".

1.6. У главі 3 Порядку ( z0469-98 ) пункт 3.2 виключити.

1.7. Опис особливостей заповнення графи 1 ВМД ( 574-97-п ) у главі 6 Порядку ( z0469-98 ) викласти в такій редакції:

"Графа 1 "Тип декларації"

У першому підрозділі графи проставляється літерний код напрямку переміщення товарів:

"ІМ" - при розміщенні на МЛС товарів, увезених на митну територію України;

"ЕК" - при розміщенні на МЛС товарів, призначених для вивезення за межі митної території України.

У другому підрозділі графи проставляється код митного режиму "74"; третій підрозділ не заповнюється".

2. Унести до Класифікатора документів, затвердженого наказом Держмитслужби України від 09.07.97 N 307 ( z0443-97 ) (зі змінами й доповненнями), зареєстрованим у Міністерстві юстиції України 24.09.97 за N 443/2247, такі зміни:

2.1. У розділі 1 "Ліцензії" рядок

------------------------------------------------------------------

| 1010 |Індивідуальна ліцензія |

------------------------------------------------------------------

замінити рядком

------------------------------------------------------------------

| 1010 |Разова (індивідуальна) ліцензія на зовнішньоекономічну|

| |операцію |

------------------------------------------------------------------

2.2. У розділі 9 "Інші документи" рядок

------------------------------------------------------------------

| 9105 |Резервна позиція |

------------------------------------------------------------------

замінити рядком

------------------------------------------------------------------

| 9105 |Попереднє рішення щодо класифікації та кодування |

| |товару в УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, |

| |2371г-14 ) |

------------------------------------------------------------------

3. Департаменту інформаційних технологій та митної статистики (Копосов С.А.) допрацювати програмне забезпечення з урахуванням вимог цього наказу.

4. Департаменту декларування та митних режимів (Науменко В.П.) і Юридичному департаменту (Боженко І.Ф.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

5. Начальникам митних органів довести цей наказ до відома юридичних і фізичних осіб.

6. Установити, що цей наказ набирає чинності через 10 днів з дня його офіційного опублікування.

Контроль за виконанням наказу залишаю за собою.

В.о. Голови Державної митної служби України М.М.Салагор
