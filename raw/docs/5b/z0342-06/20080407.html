{ Із змінами, внесеними згідно з Наказами Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

Відповідно до Закону України "Про вищу освіту" ( 1060-12 ), Положення про Міністерство України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, затвердженого Указом Президента України від 10 жовтня 2005 року N 1430 ( 1430/2005 ), та з метою забезпечення належної організації роботи з відбору та прийняття кандидатів на навчання до вищих навчальних закладів МНС України НАКАЗУЮ:

1. Затвердити Умови прийому та порядок відбору на навчання до вищих навчальних закладів МНС України (далі - Умови), що додаються.

2. Начальникам головних управлінь (управлінь) МНС України в Автономній Республіці Крим, областях, містах Києві та Севастополі, ректорам вищих навчальних закладів МНС України, начальникам організаційних структур Оперативно-рятувальної служби, Українського науково-дослідного інституту пожежної безпеки:

2.1. Організувати відбір кандидатів на навчання до вищих навчальних закладів МНС України відповідно до зазначених Умов.

2.2. Довести Умови до відома кандидатів на навчання.

2.3. Забезпечити якісне та повне оформлення документів кандидатів на навчання та їх своєчасне направлення для розгляду приймальними комісіями вищих навчальних закладів МНС України.

3. Департаменту кадрової політики (Шевченко І.О.) забезпечити подання наказу на державну реєстрацію до Міністерства юстиції України в установленому порядку.

4. Ректорам вищих навчальних закладів МНС України після набрання чинності зазначеним наказом з урахуванням цих Умов розробити власні правила прийому на навчання для всіх категорій кандидатів на навчання.

5. Контроль за виконанням цього наказу залишаю за собою.

1. Загальні положення

1.1. Ці Умови визначають умови прийому, порядок відбору, організацію конкурсу та зарахування кандидатів на навчання за державним замовленням.

{ Пункт 1.1 із змінами, внесеними згідно з Наказом Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 168 ( z0256-08 ) від 04.03.2008 }

1.2. Умови розроблені відповідно до Конституції України ( 254к/96-ВР ), Законів України "Про освіту" ( 1060-12 ), "Про вищу освіту" ( 2984-14 ), "Про мови в Українській РСР" ( 8312-11 ), "Про правові засади цивільного захисту" ( 1859-15 ), "Про загальний військовий обов'язок і військову службу" ( 2232-12 ), та постанов Кабінету Міністрів України від 24 травня 1997 року N 507 ( 507-97-п ) "Про перелік напрямів та спеціальностей, за якими здійснюється підготовка фахівців у вищих навчальних закладах за відповідними освітньо-кваліфікаційними рівнями" (із змінами) (далі - Перелік - 1997) і від 13 грудня 2006 року N 1719 ( 1719-2006-п ) "Про перелік напрямів, за якими здійснюється підготовка фахівців у вищих навчальних закладах за освітньо-кваліфікаційним рівнем бакалавра" (із змінами) (далі - Перелік - 2006), від 20 червня 2007 року N 839 ( 839-2007-п ) "Про затвердження переліку спеціальностей, за якими здійснюється підготовка фахівців у вищих навчальних закладах за освітньо-кваліфікаційним рівнем молодшого спеціаліста" (далі - Перелік - 2007).

{ Пункт 1.2 із змінами, внесеними згідно з Наказами Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 421 ( z0642-07 ) від 11.06.2007, N 168 ( z0256-08 ) від 04.03.2008 }

1.3. До вищих навчальних закладів МНС України приймаються громадяни України, які мають документи державного зразка про повну загальну середню освіту або вищу освіту та виявили бажання здобути вищу освіту відповідного освітньо-кваліфікаційного рівня.

1.4. Підготовка фахівців у вищих навчальних закладах МНС України за державним замовленням здійснюється на підставі укладених угод у порядку, установленому чинним законодавством.

1.5. Підготовка фахівців для зарубіжних країн здійснюється згідно із Законом України "Про правовий статус іноземців та осіб без громадянства" ( 3929-12 ) (із змінами), Указом Президента України від 25 березня 1994 року N 112 ( 112/94 ) "Про заходи щодо розвитку економічного співробітництва областей України з суміжними прикордонними областями Російської Федерації", постановами Кабінету Міністрів України від 26 лютого 1993 року N 136 ( 136-93-п ) "Про навчання іноземних громадян в Україні" (із змінами) та від 5 серпня 1998 року N 1238 ( 1238-98-п ) "Про затвердження Положення про прийом іноземців та осіб без громадянства на навчання до вищих навчальних закладів", а також на підставі чинних міжурядових угод та контрактів щодо підготовки спеціалістів, укладених з відповідними установами іноземних держав, з обов'язковим висвітленням в умовах договору питання про медичне обстеження та медичне обслуговування іноземних слухачів вищих навчальних закладів МНС України (далі - ВНЗ МНС України) під час навчання.

{ Пункт 1.5 із змінами, внесеними згідно з Наказом Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 168 ( z0256-08 ) від 04.03.2008 }

1.6. Організацію прийому до ВНЗ МНС України здійснює приймальна комісія, склад якої затверджується наказом керівника вищого навчального закладу, який є її головою.

Приймальна комісія діє згідно з Положенням про приймальну комісію вищого навчального закладу, затвердженим її керівником.

1.7. ВНЗ МНС України самостійно розробляють правила прийому на навчання для усіх категорій осіб на підставі цих Умов та власних статутів.

Правила прийому до професійно-технічних навчальних закладів МНС України розробляються згідно з Типовими правилами прийому до професійно-технічних навчальних закладів України, затвердженими наказом МОН від 06.06.2006 N 441 ( z0790-06 ) та зареєстрованими в Мін'юсті 05.07.2006 за N 790/12664. { Пункт 1.7 доповнено абзацом другим згідно з Наказом Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 168 ( z0256-08 ) від 04.03.2008 }

Правила прийому затверджуються головою приймальної комісії, після чого примірник правил у триденний термін надсилається до Міністерства освіти і науки України та МНС України.

1.8. ВНЗ МНС України повинні оголошувати прийом кандидатів на навчання тільки за наявності ліцензії на здійснення освітньої діяльності за відповідними напрямами підготовки і спеціальностями. Вони зобов'язані створити умови для ознайомлення кандидатів на навчання з ліцензією на здійснення освітньої діяльності, сертифікатом з акредитованих напрямів підготовки (спеціальностей).

Перелік напрямів підготовки (спеціальностей), за якими вищі навчальні заклади МНС України оголошують прийом документів від кандидатів на навчання за рахунок коштів державного бюджету, та перелік предметів, за якими проводиться конкурс щодо зарахування на навчання наведені в додатку 1. { Абзац другий пункту 1.8 із змінами, внесеними згідно з Наказом Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 168 ( z0256-08 ) від 04.03.2008 }

2. Умови прийому на навчання

2.1. Відповідно до освітньо-кваліфікаційного й освітнього рівня, фахової спрямованості та специфіки підготовки кадрів для органів управління та підрозділів МНС України на денну форму навчання приймаються:

2.1.1. Особи рядового та молодшого начальницького складу органів управління та підрозділів МНС України віком до 25 років.

2.1.2. Цивільні особи, які мають повну загальну середню освіту та відповідають вимогам чинного законодавства щодо умов прийняття на службу в органи управління та підрозділи МНС України, віком від 17 до 25 років.

2.1.3. Особи середнього та старшого начальницького складу органів управління та підрозділів МНС України віком до 35 років, які мають повну вищу освіту освітньо-кваліфікаційного рівня "спеціаліст" за спеціальністю 7.092801 "пожежна безпека" або мають повну вищу освіту освітньо-кваліфікаційного рівня "спеціаліст" за спеціальностями в інженерній галузі для сфери цивільного захисту (цивільної оборони) і обіймають посади, що передбачають заміщення фахівцями освітньо-кваліфікаційного рівня "магістр" або перебувають у резерві кадрів на висунення на ці посади та мають стаж практичної роботи не менше 2 років.

2.1.4. Особи рядового та молодшого начальницького складу, які здобули освіту освітньо-кваліфікаційного рівня "бакалавр" за відповідним напрямом (Перелік - 1997 ( 507-97-п ) або Перелік - 2006 ( 1719-2006-п ) у ВНЗ МНС України у поточному році. { Пункт 2.1 доповнено підпунктом 2.1.4 згідно з Наказом Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 421 ( z0642-07 ) від 11.06.2007 }

2.1.5. Особи, які закінчили Вінницьке вище професійне училище цивільного захисту та здобули освіту освітньо-кваліфікаційного рівня молодший спеціаліст за відповідною спеціальністю (Перелік - 1997 або Перелік - 2007) ( 839-2007-п ).

{ Пункт 2.1 доповнено підпунктом 2.1.5 згідно з Наказом Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 168 ( z0256-08 ) від 04.03.2008 }

2.1.6. Умови вступу на денну форму навчання за державним замовленням осіб жіночої статі обумовлюються у власних правилах прийому на навчання ВНЗ МНС України.

2.2. На заочну форму навчання приймаються:

2.2.1. Особи молодшого середнього і старшого начальницького складу органів управління та підрозділів МНС України віком до 30 років, які закінчили вищі навчальні заклади та здобули освіту освітньо-кваліфікаційного рівня "молодший спеціаліст" за спеціальністю 5.092802 (Перелік - 1997) або 5.17020301 (Перелік - 2007) ( 839-2007-п ) "організація та техніка протипожежного захисту", прослужили не менше 1 року після її здобуття і зараховані до резерву кадрів для висунення на вищі посади. { Підпункт 2.2.1 із змінами, внесеними згідно з Наказами Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 421 ( z0642-07 ) від 11.06.2007, N 168 ( z0256-08 ) від 04.03.2008 }

КРИТЕРІЇ виставлення загальної оцінки при складанні випробування з оцінки рівня фізичної підготовки

Загальна оцінка результатів виконання фізичних вправ розраховується за 12-бальною (100-бальною) шкалою як середній бал, одержаний за три вправи.

Середній бал обчислюється як середнє арифметичне число. Якщо це число має десяті частки, то кінцеве значення обчислюється шляхом округлення з точністю до цілої.

При цьому до 0,50 бала округлюється в менший бік, а з 0,51 - у більший.

Результати та кількість балів з кожного виду вправ, а також загальний бал, одержаний під час випробування з оцінки рівня фізичної підготовки, заносяться до відомості та екзаменаційного листа.

Нормативами визначається граничний результат, за який виставляється той чи інший бал.

Якщо хоча б за одну вправу отримано менше 4 балів за 12-бальною шкалою оцінювання або 124 балів за 100-бальною шкалою оцінювання, то випробування з оцінки рівня фізичної підготовки вважається не складеним.

За рішенням приймальної комісії загальна оцінка за підсумками випробування з оцінки рівня фізичної підготовки може бути визначена як "рівень підготовки недостатній" (загальна оцінка за виконання нормативів менше 4 балів за 12-бальною шкалою оцінювання або 124 балів за 100-бальною шкалою оцінювання) або "рівень підготовки достатній" (загальна оцінка за виконання нормативів більше 3 балів за 12-бальною шкалою оцінювання або 123 балів за 100-бальною шкалою оцінювання).
