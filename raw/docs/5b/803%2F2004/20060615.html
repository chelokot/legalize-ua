Президент України; Указ від 15.07.2004 № 803/2004

Про Державну службу України з нагляду за забезпеченням безпеки авіації

Стан: Чинний

Ідентифікатор: 803/2004

Текст документа від 15.06.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Державну службу України з нагляду за забезпеченням безпеки авіації

{ Із змінами, внесеними згідно з Указами Президента N 912/2004 ( 912/2004 ) від 16.08.2004 N 510/2006 ( 510/2006 ) від 09.06.2006 }

З метою вдосконалення державного регулювання у сфері використання повітряного простору і обслуговування повітряного руху, створення умов для здійснення заходів, передбачених Повітряним кодексом України щодо забезпечення безпеки польотів повітряних суден, авіаційної безпеки, якості робіт та послуг у цій галузі та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Утворити Державну службу України з нагляду за забезпеченням безпеки авіації (далі - Державіаслужба) на базі Державного департаменту авіаційного транспорту України, що ліквідується. ( Стаття 1 із змінами, внесеними згідно з Указом Президента N 912/2004 ( 912/2004 ) від 16.08.2004 )

{ Стаття 2 втратила чинність на підставі Указу Президента N 510/2006 ( 510/2006 ) від 09.06.2006 }

3. Кабінету Міністрів України у двомісячний строк:

1) вирішити питання, пов'язані з утворенням Державіаслужби, зокрема: ( Абзац перший пункту 1 статті 3 із змінами, внесеними згідно з Указом Президента N 912/2004 ( 912/2004 ) від 16.08.2004 )

визначити перелік підприємств, установ та організацій державного сектора економіки, які передаються в управління Державіаслужби, і здійснити заходи щодо їх передачі; ( Абзац другий пункту 1 статті 3 із змінами, внесеними згідно з Указом Президента N 912/2004 ( 912/2004 ) від 16.08.2004 )

здійснити заходи щодо передачі Державіаслужбі відповідного майна для забезпечення діяльності цього органу, в тому числі вирішити питання про його матеріально-технічне забезпечення і розміщення; ( Абзац третій пункту 1 статті 3 із змінами, внесеними згідно з Указом Президента N 912/2004 ( 912/2004 ) від 16.08.2004 )

під час складання проекту Державного бюджету України на 2005 рік передбачити кошти на утримання Державної служби України з нагляду за забезпеченням безпеки авіації;

затвердити граничну чисельність працівників Державіаслужби, визначити перелік посад, які підлягають заміщенню військовослужбовцями; ( Абзац п'ятий пункту 1 статті 3 із змінами, внесеними згідно з Указом Президента N 912/2004 ( 912/2004 ) від 16.08.2004 )

подати пропозиції щодо відрядження до Державіаслужби військовослужбовців Збройних Сил України та інших військових формувань; ( Абзац шостий пункту 1 статті 3 із змінами, внесеними згідно з Указом Президента N 912/2004 ( 912/2004 ) від 16.08.2004 )

подати законопроект про внесення змін до Повітряного кодексу України, врахувавши рекомендації Міжнародної організації цивільної авіації (ІКАО) і Європейського Союзу щодо створення державної системи контролю за забезпеченням безпеки авіації та передбачивши, зокрема, створення незалежного органу з розслідування авіаційних подій; ( Пункт 1 статті 3 доповнено абзацом згідно з Указом Президента N 912/2004 ( 912/2004 ) від 16.08.2004 )

2) ліквідувати Державний департамент авіаційного транспорту України; ( Пункт 2 статті 3 в редакції Указу Президента N 912/2004 ( 912/2004 ) від 16.08.2004 )

3) установити порядок взаємодії органів виконавчої влади з нагляду за безпекою польотів повітряних суден;

4) подати в установленому порядку пропозиції щодо внесення змін до нормативно-правових актів, що випливають із цього Указу;

5) привести свої рішення у відповідність із цим Указом;

6) подати нову редакцію Закону України "Про транспорт", врахувавши положення цього Указу. ( Статтю 3 доповнено пунктом 6 згідно з Указом Президента N 912/2004 ( 912/2004 ) від 16.08.2004 )

4. Доповнити розділ II Схеми організації та взаємодії центральних органів виконавчої влади, затвердженої Указом Президента України від 15 грудня 1999 року N 1573 ( 1573/99 ) "Про зміни у структурі центральних органів виконавчої влади" (зі змінами, внесеними Указами від 27 серпня 2000 року N 1031 ( 1031/2000 ), від 5 червня 2001 року N 405 ( 405/2001 ), від 7 серпня 2001 року N 603 ( 603/2001 ), від 13 вересня 2001 року N 836 ( 836/2001 ), від 8 листопада 2001 року N 1056 ( 1056/2001 ), від 22 листопада 2001 року N 1132 ( 1132/2001 ), від 14 грудня 2001 року N 1213 ( 1213/2001 ), від 16 березня 2002 року N 259 ( 259/2002 ), від 18 вересня 2002 року N 834 ( 834/2002 ), від 1 жовтня 2002 року N 887 ( 887/2002 ), від 31 січня 2003 року N 54 ( 54/2003 ), від 31 липня 2003 року N 772 ( 772/2003 ), від 15 вересня 2003 року N 1039 ( 1039/2003 ), від 19 січня 2004 року N 60 ( 60/2004 ) та від 6 лютого 2004 року N 166 ( 166/2004), абзацом такого змісту:
