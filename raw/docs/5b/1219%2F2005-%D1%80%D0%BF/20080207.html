Текст документа від 07.02.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України на X сесію Конференції держав-учасниць Конвенції про заборону розробки, виробництва, накопичення і застосування хімічної зброї та про її знищення

1. Утворити делегацію України для участі у X сесії Конференції держав-учасниць Конвенції про заборону розробки, виробництва, накопичення і застосування хімічної зброї та про її знищення ( 995_182 ) (м. Гаага, Королівство Нідерланди, 7-11 листопада 2005 року) в такому складі:

БЄЛАШОВ Володимир Євгенович - директор Департаменту контролю над озброєннями та військово-технічного співробітництва Міністерства закордонних справ України, глава делегації

ТРЕТЬЯКОВ Валерій Михайлович - заступник Міністра промислової політики України, заступник глави делегації

АНТИПЕНКО Володимир Федорович - начальник штабу - заступник керівника Антитерористичного центру при Службі безпеки України, член делегації

БОЛИЧЕВЦЕВ Олександр Анатолійович - завідувач відділу Департаменту зовнішньополітичної безпеки Апарату Ради національної безпеки і оборони України, член делегації.

2. Міністрові закордонних справ України затвердити Вказівки делегації України на X сесію Конференції держав-учасниць Конвенції про заборону розробки, виробництва, накопичення і застосування хімічної зброї та про її знищення ( 995_182 ).

3. Кабінету Міністрів України виділити кошти в іноземній валюті для забезпечення участі Антипенка В.Ф., Боличевцева О.А. та Третьякова В.М. в роботі X сесії Конференції держав-учасниць Конвенції про заборону розробки, виробництва, накопичення і застосування хімічної зброї та про її знищення ( 995_182 ).

Президент України В.ЮЩЕНКО
