РОЗПОРЯДЖЕННЯ від 17 липня 2003 р. N 422-р Київ

Про затвердження складу української частини Міжурядової українсько-грузинської комісії з питань військово-технічного співробітництва

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 87-р ( 87-2006-р ) від 15.02.2006 N 206-р ( 206-2006-р ) від 17.04.2006 }

Затвердити склад української частини Міжурядової українсько-грузинської комісії з питань військово-технічного співробітництва, що додається.

Дозволити голові комісії вносити в разі потреби зміни до її персонального складу.

Інд. 50

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 17 липня 2003 р. N 422-р

СКЛАД Української частини Міжурядової українсько-грузинської комісії з питань військово-технічного співробітництва

ТЕРЕЩЕНКО - заступник Міністра оборони, голова

Володимир Іванович Української частини Міжурядової комісії

АЛЕКСАНДРОВ - начальник відділу спеціальних програм та Олександр Іванович військово-технічного співробітництва департаменту економіки оборони та безпеки Мінекономіки

БАНДИРСЬКИЙ - спеціаліст першої категорії державного Тарас Стефанович підприємства "Український інститут промислової власності"

БОНДАРЧУК - генеральний директор Державної компанії Сергій Васильович "Укрспецекспорт"

БРАТЧУН - начальник експертно-аналітичного

Сергій Олексійович відділу управління військово-технічного співробітництва Міноборони, відповідальний секретар Комісії

КИЗИМ - радник департаменту контролю над

Ігор Юрійович озброєннями та військово-технічного співробітництва МЗС

КОВАЛЬСЬКА - головний спеціаліст відділу

Марина Петрівна військово-технічного співробітництва департаменту оборонно-промислової політики та військово-технічного співробітництва Мінпромполітики

МІНОГІН - державний експерт управління

Олександр Володимирович військово-технічного співробітництва та експортного контролю департаменту з питань воєнної безпеки Апарату Ради національної безпеки і оборони України

РЕШЕТІЛОВ - заступник Голови Держекспортконтролю

Ігор Валентинович

ФОКІН - начальник відділу СБУ

Єгор Віталійович
