ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 278 від 10.06.99 Зареєстровано в Міністерстві м.Київ юстиції України 21 червня 1999 р. vd990610 vn278 за N 390/3683

( Постанова втратила чинність на підставі Постанови Національного банку N 268 ( z0840-04 ) від 17.06.2004 )

Про внесення змін до Положення про впровадження пластикових карток міжнародних платіжних систем у розрахунках за товари, надані послуги та при видачі готівки

У зв'язку з проханням банків - членів міжнародних платіжних систем та за пропозицією департаментів інформатизації та валютного регулювання про здійснення видачі іноземної готівки за допомогою банкоматів Правління ПОСТАНОВЛЯЄ:

1. У Положенні про впровадження пластикових карток міжнародних платіжних систем у розрахунках за товари, надані послуги та при видачі готівки, затвердженому постановою Правління від 24.02.97 N 37 ( z0086-97 ) і зареєстрованому Міністерством юстиції України 24.03.97 за N 86/1890, зі змінами і доповненнями до нього, які затверджені постановою Правління від 09.11.98 N 468 ( z0754-98 ) і зареєстровані Міністерством юстиції України 26.11.98 за N 754/3194, пункт 3.2 викласти в такій редакції:

"3.2. Уповноважені банки України можуть установлювати комісійну винагороду (за операціями з використанням банківських платіжних карток (БПК) при видачі готівки) у валюті видачі готівки.

За допомогою банкоматів дозволяється видача готівки іноземної валюти лише:

- за власними БПК уповноваженого банку, карткові рахунки яких відкриті в іноземній валюті;

- за БПК банків-нерезидентів України".

2. Постанова набуває чинності через десять днів після її державної реєстрації в Міністерстві юстиції України.
