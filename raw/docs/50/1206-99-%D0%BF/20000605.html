КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 липня 1999 р. N 1206 Київ

( Постанова втратила чинність на підставі Постанови КМ N 905 ( 905-2000-п ) від 05.06.2000 )

Про доповнення переліку товарів критичного імпорту

Кабінет Міністрів України постановляє:

1. Доповнити перелік товарів критичного імпорту, затверджений постановою Кабінету Міністрів України від 18 червня 1999 р. N 1080 ( 1080-99-п ) "Про перелік товарів критичного імпорту", товаром за кодом згідно з ТН ЗЕД 84.33 51000 (комбайни зернозбиральні).

2. Ця постанова набирає чинності з дня опублікування.
