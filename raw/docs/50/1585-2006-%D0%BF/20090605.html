Про затвердження складу наглядової ради Державної акціонерної компанії "Укрмедпром"

Стан: Втратив чинність

Ідентифікатор: 1585-2006-п

Текст документа від 05.06.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 листопада 2006 р. N 1585 Київ

Про затвердження складу наглядової ради Державної акціонерної компанії "Укрмедпром"

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 512 ( 512-2009-п ) від 27.05.2009 }

{ Із змінами, внесеними згідно з Постановою КМ N 512 ( 512-2009-п ) від 27.05.2009 }

Кабінет Міністрів України постановляє:

1. На часткову зміну пункту 5 постанови Кабінету Міністрів України від 5 червня 2000 р. N 897 ( 897-2000-п ) "Про подальше реформування медичної та мікробіологічної промисловості" (Офіційний вісник України, 2000 р., N 23, ст. 945) установити, що склад наглядової ради Державної акціонерної компанії "Укрмедпром" затверджується Кабінетом Міністрів України.

У зв'язку з цим затвердити склад наглядової ради Державної акціонерної компанії "Укрмедпром", що додається.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 512 ( 512-2009-п ) від 27.05.2009 }

2. Міністерству охорони здоров'я привести власні рішення у відповідність із цією постановою.
