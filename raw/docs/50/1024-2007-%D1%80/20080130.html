{ Розпорядження втратило чинність на підставі Розпорядження КМ N 167-р ( 167-2008-р ) від 30.01.2008 }

Про склад представників Кабінету Міністрів України у Національній тристоронній соціально-економічній раді

1. Затвердити склад представників Кабінету Міністрів України у Національній тристоронній соціально-економічній раді, що додається.

Надати співголові Національної тристоронньої соціально-економічної ради від Кабінету Міністрів України право вносити у разі потреби зміни до зазначеного складу.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 24 січня 2006 р. N 28 ( 28-2006-р ) "Про склад представників Кабінету Міністрів України у Національній тристоронній соціально-економічній раді" (Офіційний вісник України, 2006 р., N 4, ст. 174).
