Текст документа від 14.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 травня 2007 р. N 690 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для здійснення державного нагляду за додержанням стандартів, державного метрологічного нагляду

{ Із змінами, внесеними згідно з Постановою КМ N 409 ( 409-2008-п ) від 23.04.2008 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) Міністерству економіки за програмою "Державний нагляд за додержанням стандартів, державний метрологічний нагляд", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 409 ( 409-2008-п ) від 23.04.2008 }

{ Установити, що використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) Міністерству економіки за програмою "Державний нагляд за додержанням стандартів, державний метрологічний нагляд", здійснюється відповідно до Порядку, затвердженого цією Постановою, з урахуванням особливостей, зазначених в Постанові КМ N 342 ( 342-2009-п ) від 15.04.2009 }

{ Установити, що використання у 2010 році коштів, передбачених у державному бюджеті ( 2154-17 ) Міністерству економіки за програмою "Державний нагляд за додержанням стандартів, державний метрологічний нагляд", здійснюється відповідно до Порядку, затвердженого цією Постановою, з урахуванням особливостей, зазначених в Постанові КМ N 816 ( 816-2010-п ) від 08.09.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для здійснення державного нагляду за додержанням стандартів, державного метрологічного нагляду, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 3 травня 2007 р. N 690

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для здійснення державного нагляду за додержанням стандартів, державного метрологічного нагляду

Загальна частина

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) за програмою "Державний нагляд за додержанням стандартів, державний метрологічний нагляд" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Мінекономіки.

Відповідальним за виконання бюджетної програми (розпорядником бюджетних коштів нижчого рівня) є Держспоживстандарт.

Виконавцями (одержувачами бюджетних коштів) є державні центри стандартизації, метрології та сертифікації.

Напрями використання бюджетних коштів

3. Бюджетні кошти спрямовуються на здійснення державного метрологічного нагляду та державного нагляду за додержанням стандартів, норм і правил центральним органом виконавчої влади у сфері технічного регулювання та споживчої політики і його територіальними органами - державними центрами стандартизації, метрології та сертифікації з метою додержання суб'єктами господарювання усіх форм власності стандартів, норм і правил під час виготовлення та випуску продукції, її реалізації (в тому числі оптової та оптово-роздрібної), виконання робіт, надання послуг.

Вимоги щодо використання бюджетних коштів

4. Держспоживстандарт укладає з державними центрами стандартизації, метрології та сертифікації договори про виконання робіт з державного нагляду за додержанням стандартів, норм і правил, вимоги яких є обов'язковими, метрологічного нагляду (далі - договори) згідно із затвердженим ним планом заходів щодо виконання бюджетної програми.

5. Оплата виконаних робіт провадиться на підставі укладених договорів та помісячного розпису асигнувань, затвердженого Мінфіном.

6. Операції з бюджетними коштами здійснюються відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

7. Для недопущення виникнення кредиторської заборгованості на кінець року до договорів обов'язково включається вимога щодо коригування визначеної в них суми та зобов'язань сторін у разі зменшення бюджетних призначень за програмою під час уточнення показників Державного бюджету України на 2007 рік ( 489-16 ).

Звітність про використання бюджетних коштів та контроль за їх витрачанням

8. План заходів щодо виконання бюджетної програми подається Мінфіну у двотижневий строк.

Інформацію про виконання плану заходів Держспоживстандарт подає Мінфіну щокварталу у двотижневий строк після закінчення звітного періоду та одинадцяти місяців.

Держспоживстандарт подає Мінфіну щокварталу до 20 числа наступного місяця звіт про стан виконання результативних показників відповідно до паспорта бюджетної програми разом з результатами аналізу, поясненнями, висновками щодо виконання затверджених показників та пропозиціями стосовно врегулювання проблемних питань.

У разі невиконання результативних показників Держспоживстандарт утворює комісію, яка розглядає питання щодо доцільності продовження фінансування.

Про рішення комісії Держспоживстандарт письмово повідомляє Мінфін у триденний строк.

Рішення про зупинення фінансування приймає Мінфін.

{ Пункт 9 виключено на підставі Постанови КМ N 409 ( 409-2008-п ) від 23.04.2008 }

10. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
