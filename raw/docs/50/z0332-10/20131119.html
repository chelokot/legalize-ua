Відповідно до Положення про Державну архітектурно-будівельну інспекцію України, затвердженого Указом Президента України від 08.04.2011 N 439 ( 439/2011 ), та постанови Кабінету Міністрів України від 13.04.2011 N 461 ( 461-2011-п ) "Питання прийняття в експлуатацію закінчених будівництвом об'єктів" НАКАЗУЮ:

1. Затвердити Порядок акумулювання, перерозподілу та використання коштів спеціального фонду Державної архітектурно-будівельної інспекції України, що додається.

{ Пункт 1 із змінами, внесеними згідно з Наказом Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 130 ( z0959-11 ) від 29.07.2011 }

2. Державній архітектурно-будівельній інспекції України (Бондаренко О.М.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Ісаєнка Д.В.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

ЗАТВЕРДЖЕНО Наказ Міністерства регіонального розвитку та будівництва України 20.04.2010 N 133

Зареєстровано в Міністерстві юстиції України 17 травня 2010 р. за N 332/17627

ПОРЯДОК акумулювання, перерозподілу та використання коштів спеціального фонду Державної архітектурно-будівельної інспекції України

{ У заголовку та тексті слова "Державна архітектурно-будівельна інспекція" та "Держархбудінспекція" в усіх відмінках замінено відповідно словами "Державна архітектурно- будівельна інспекція України" у відповідних відмінках; слова "сертифікат відповідності" в усіх відмінках замінено словом "сертифікат" у відповідних відмінках згідно з Наказом Міністерства регіонального розвитку, будівництва та житлово- комунального господарства N 130 ( z0959-11 ) від 29.07.2011 }

I. Загальні положення

1.1. Цей Порядок визначає механізм акумулювання, перерозподілу та використання коштів спеціального фонду (далі - кошти спеціального фонду), отриманих Державною архітектурно-будівельною інспекцією України за видачу сертифікатів.

1.2. Акумулювання, перерозподіл та використання коштів спеціального фонду здійснюються відповідно до бюджетного законодавства та проводяться у межах бюджетних призначень, що визначені для Державної архітектурно-будівельної інспекції України та її територіальних органів законом про державний бюджет України на відповідний рік за бюджетною програмою "Керівництво та управління у сфері архітектурно-будівельного контролю".

{ Пункт 1.2 розділу I із змінами, внесеними згідно з Наказом Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 130 ( z0959-11 ) від 29.07.2011 }

1.3. Подальший перерозподіл та використання коштів спеціального фонду проводяться з метою покриття витрат, пов'язаних з видачею сертифікатів та створенням, веденням і забезпеченням функціонування реєстру виданих сертифікатів та відмов у їх видачі, Державною архітектурно-будівельною інспекцією України та її територіальними органами.

II. Акумулювання, перерозподіл та використання коштів спеціального фонду

2.1. Кошти, одержані як плата за видачу сертифіката, зараховуються на відповідний рахунок, який призначений для зарахування до спеціального фонду державного бюджету власних надходжень Державної архітектурно-будівельної інспекції України.

2.2. На спеціальний реєстраційний рахунок Державної архітектурно-будівельної інспекції України, відкритий в органі Державної казначейської служби України, зараховуються власні надходження з рахунку, який призначений для зарахування до спеціального фонду державного бюджету власних надходжень, а також кошти, які відносяться на відновлення касових видатків.

{ Пункт 2.2 розділу II із змінами, внесеними згідно з Наказом Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 130 ( z0959-11 ) від 29.07.2011 }

2.3. На спеціальний реєстраційний рахунок кошти зараховуються без конкретного віднесення до кодів економічної класифікації видатків, однак здійснення видатків проводиться відповідно до кошторису за конкретними кодами економічної класифікації видатків шляхом оплати рахунків за надані послуги, виконані роботи, отримані товари з урахуванням довідок про внесення змін.

2.4. Кошти спеціального фонду державного бюджету спрямовуються:

для централізованої закупівлі бланків сертифікатів, придбання комп'ютерів та інших засобів оргтехніки, створення та удосконалення електро- та комп'ютерних мереж, мереж зв'язку, створення, ведення та забезпечення функціонування реєстру виданих сертифікатів, на організацію та проведення конкурсу на кращі будинки і споруди, збудовані та прийняті в експлуатацію в Україні, та інших закупівель;

відшкодування організаційно-технічних витрат: витрат на оплату комунальних послуг, послуг зв'язку, придбання предметів, матеріалів, обладнання, інвентарю, оплати транспортних послуг, поточного ремонту обладнання, інвентарю та технічного обслуговування обладнання, інших видатків.

2.5. Перерахування Державною архітектурно-будівельною інспекцією України коштів спеціального фонду державного бюджету територіальним органам здійснюється лише в межах однієї програми та однієї групи власних надходжень відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04, za716-04 ), зареєстрованого в Міністерстві юстиції України 10.06.2004 за N 716/9315.

2.6. Кошти перераховуються не пізніше 15 числа місяця, наступного за звітним, на підставі наказу Державної архітектурно-будівельної інспекції України.

2.7. Для здійснення видатків за рахунок надходжень, одержаних за видачу сертифіката, складається кошторис відповідно до Порядку складання, розгляду, затвердження та основних вимог до виконання кошторисів бюджетних установ, затвердженого постановою Кабінету Міністрів України від 28.02.2002 N 228 ( 228-2002-п ), та за формами, затвердженими наказом Міністерства фінансів України від 28.01.2002 N 57 ( z0086-02 ) "Про затвердження документів, що застосовуються в процесі виконання бюджету", зареєстрованим у Міністерстві юстиції України 01.02.2002 за N 86/6374.

{ Пункт 2.7 розділу II із змінами, внесеними згідно з Наказом Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 130 ( z0959-11 ) від 29.07.2011 }

2.8. Державною архітектурно-будівельною інспекцію України ведеться облік надходження коштів у розрізі територіальних органів.

2.9. Закупівля товарів, робіт і послуг за кошти спеціального фонду державного бюджету здійснюється в установленому законодавством порядку.

III. Відображення в бухгалтерському обліку та звітності господарських операцій

3.1. Складення та подання фінансової звітності про використання коштів спеціального фонду державного бюджету, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.

3.2. Операції про надходження та використання коштів, отриманих як плата за адміністративні послуги, що надаються бюджетними установами, відображаються у бухгалтерському обліку та фінансовій звітності за формами і в порядку, встановленими Державною казначейською службою України.

{ Пункт 3.2 розділу III із змінами, внесеними згідно з Наказом Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 130 ( z0959-11 ) від 29.07.2011 }

3.3. Облік операцій з акумулювання та перерозподілу коштів спеціального фонду державного бюджету ведеться на субрахунках згідно з Планом рахунків бухгалтерського обліку бюджетних установ, затвердженим наказом Головного управління Державного казначейства України від 10.12.99 N 114 ( z0890-99 ), зареєстрованим у Міністерстві юстиції України 20.12.99 за N 890/4183.

IV. Прикінцеві положення

4.1. Використання коштів, що фактично надійшли на спеціальний реєстраційний рахунок, здійснюється виключно в межах затвердженого кошторису на відповідний рік.

4.2. Кошти, що не були використані у поточному році, переходять на наступний рік і використовуються згідно із затвердженим кошторисом наступного року.

4.3. Бюджетні зобов'язання за спеціальним фондом державного бюджету беруться лише після надходження відповідних коштів до спеціального фонду державного бюджету.

4.4. Після закінчення бюджетного періоду Державна архітектурно-будівельна інспекція України надає Мінрегіону України звіт про обсяги коштів, отриманих за надання платних адміністративних послуг та їх використання.

{ Пункт 4.4 розділу IV із змінами, внесеними згідно з Наказом Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 130 ( z0959-11 ) від 29.07.2011 }
