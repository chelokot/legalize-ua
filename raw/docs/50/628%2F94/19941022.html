Про персональний склад Ради національної безпеки

Стан: Чинний

Ідентифікатор: 628/94

Текст документа від 22.10.1994:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про персональний склад Ради національної безпеки

У зв'язку з Указом Президента України від 23 серпня 1994 року N 469 ( 469/94 ) "Про Положення про Раду національної безпеки при Президентові України" постановляю:

1. Затвердити персональний склад Ради національної безпеки та персональний склад Президії Ради національної безпеки при Президентові України (додаються).

2. Визнати такими, що втратили чинність, статтю 2 Указу Президента України від 1 липня 1992 року N 357 ( 357/92 ) "Про Раду національної безпеки України" та Указ Президента України від 22 листопада 1993 року N 546 ( 546/93 ) "Про зміну персонального складу Ради національної безпеки України".

3. Цей Указ набирає чинності з дня його підписання.
