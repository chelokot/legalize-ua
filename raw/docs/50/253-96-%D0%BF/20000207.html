КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 лютого 1996 р. N 253 Київ

( Постанова втратила чинність на підставі Постанови КМ N 234 ( 234-2000-п ) від 07.02.2000 )

Про розмір стипендії Президента України для найбільш обдарованих молодих митців України

На виконання Указу Президента України від 29 червня 1995 р. N 490 ( 490/95 ) "Про стипендії Президента України для найбільш обдарованих молодих митців України" Кабінет Міністрів України постановляє:

Установити з 1 січня 1996 р. розмір стипендії Президента України для найбільш обдарованих молодих митців України - студентів вищих навчальних та учнів загальноосвітніх навчально-виховних мистецьких закладів України в сумі 2 млн. 680 тис. крб. на місяць.
