Кабінет Міністрів України; Розпорядження від 24.10.1994 № 788-р

Про виділення коштів на придбання будинку для розміщення Постійного Представництва України при ООН

Стан: Втратив чинність

Ідентифікатор: 788-94-р

Текст документа від 20.06.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 жовтня 1994 р. N 788-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 363-р ( 363-95-р ) від 20.06.95 )

Виділити МЗС 2,0 млн. доларів США на придбання будинку для розміщення Постійного Представництва України при ООН в Нью-Йорку.

Мінфіну профінансувати зазначені витрати за рахунок надходжень валютних коштів від експорту продукції за державним контрактом.
