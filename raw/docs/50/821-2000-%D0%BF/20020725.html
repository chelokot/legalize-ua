Про упорядкування структури місцевих державних адміністрацій

( Із змінами, внесеними згідно з Постановами КМ N 1487 ( 1487-2000-п ) від 28.09.2000 N 1853 ( 1853-2000-п ) від 20.12.2000 N 461 ( 461-2001-п ) від 06.05.2001 Указом Президента N 344/2001 ( 344/2001 ) від 28.05.2001 Постановами КМ N 1267 ( 1267-2001-п ) від 26.09.2001 N 918 ( 918-2002-п ) від 02.07.2002 N 1047 ( 1047-2002-п ) від 25.07.2002 )

З метою упорядкування структури місцевих державних адміністрацій та забезпечення ефективного використання бюджетних коштів Кабінет Міністрів України постановляє:

1. Затвердити примірні переліки управлінь, відділів та інших структурних підрозділів обласної, Севастопольської міської, районної, районної у місті Севастополі державних адміністрацій згідно з додатками 1 - 4.

( Пункт 2 втратив чинність на підставі Указу Президента N 344/2001 ( 344/2001 ) від 28.05.2001 )

3. ( Абзац перший пункту 3 втратив чинність на підставі Указу Президента N 344/2001 ( 344/2001 ) від 28.05.2001 )

( Абзац другий пункту 3 втратив чинність на підставі Указу Президента N 344/2001 ( 344/2001 ) від 28.05.2001 )

Кількість посад заступників голів місцевих державних адміністрацій визначається в межах установленої граничної чисельності, фонду оплати праці працівників та видатків на утримання відповідної державної адміністрації. ( Абзац пункту 3 в редакції Постанови КМ N 461 ( 461-2001-п ) від 06.05.2001 )

Головам обласних, Київської та Севастопольської міських державних адміністрацій під час перерозподілу обов'язків між заступниками голови визначити відповідального за організаційну роботу та дотримання законодавства з питань державної служби. Пропозиції щодо призначення відповідального за зазначену роботу в місячний термін подати для погодження Головному управлінню державної служби.

( Пункт 4 втратив чинність на підставі Указу Президента N 344/2001 ( 344/2001 ) від 28.05.2001 )

5. Міністерствам, іншим центральним органам виконавчої влади у місячний термін подати Кабінетові Міністрів України в установленому порядку пропозиції щодо приведення у відповідність з цією постановою типових положень про відповідні управління, відділи, інші структурні підрозділи місцевих державних адміністрацій, які Їм підзвітні та підконтрольні.

постанову Кабінету Міністрів України від 27 серпня 1999 р. N 1570 ( 1570-99-п ) "Про внесення змін і доповнень до постанови Кабінету Міністрів України від 22 червня 1999 р. N 1101" (Офіційний вісник України, 1999 р., N 35, ст. 1793);

постанову Кабінету Міністрів України від 25 листопада 1999 р. N 2142 ( 2142-99-п ) "Про утворення структурних підрозділів місцевих державних адміністрацій з питань туризму" (Офіційний вісник України, 1999 р., N 48, ст. 2347);
