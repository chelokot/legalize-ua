Кабінет Міністрів України; Розпорядження від 25.10.2004 № 771-р

Про виділення коштів на придбання для Донецького обласного протипухлинного центру багатопелюсткового коліматора та комплексу медичного обладнання для брахіотерапії

Стан: Чинний

Ідентифікатор: 771-2004-р

Текст документа від 25.10.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 жовтня 2004 р. N 771-р Київ

Про виділення коштів на придбання для Донецького обласного протипухлинного центру багатопелюсткового коліматора та комплексу медичного обладнання для брахіотерапії

Прийняти пропозицію Мінпаливенерго щодо виділення Донецькому обласному протипухлинному центру у 2004 році з державного бюджету за кодом програмної класифікації видатків державного бюджету 1101180 "Реструктуризація вугільної та торфодобувної промисловості" ( 1344-15 ) 9 млн. гривень на придбання багатопелюсткового коліматора та комплексу медичного обладнання для брахіотерапії.

Мінпаливенерго внести зміни до розподілу коштів державного підприємства "Обласна дирекція "Донвуглереструктуризація", забезпечивши фінансування зазначених витрат за рахунок асигнувань, що передбачені підприємству на витрати з пом'якшення соціально-економічних наслідків ліквідації вугледобувних підприємств.

Прем'єр-міністр України В.ЯНУКОВИЧ
