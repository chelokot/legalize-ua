Кабінет Міністрів України; Постанова від 18.12.1995 № 1020

Про зміну, доповнення та визнання такими, що втратили чинність, деяких рішень Кабінету Міністрів України

Стан: Втратив чинність

Ідентифікатор: 1020-95-п

Текст документа від 10.05.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 грудня 1995 р. N 1020 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 460 ( 460-2011-п ) від 13.04.2011 }

Про зміну, доповнення та визнання такими, що втратили чинність, деяких рішень Кабінету Міністрів України

На виконання статті 6 Указу Президента України від 20 вересня 1995 р. N 852 ( 852/95 ) "Про Положення про Валютно-кредитну раду Кабінету Міністрів України" Кабінет Міністрів України постановляє:

1. Затвердити зміни і доповнення, що вносяться до рішень Уряду (додаються).

2. Визнати такими, що втратили чинність, рішення Уряду України згідно з переліком (додається).

Прем'єр-міністр України Є.МАРЧУК

Міністр Кабінету Міністрів України В.ПУСТОВОЙТЕНКО

Інд.40

ЗАТВЕРДЖЕНІ постановою Кабінету Міністрів України від 18 грудня 1995 р. N 1020

ЗМІНИ І ДОПОВНЕННЯ, що вносяться до рішень Уряду

1. У пункті 1 постанови Кабінету Міністрів України від 16 червня 1992 р. N 337 ( 337-92-п ) "Про створення Валютно-кредитної ради Кабінету Міністрів України" (ЗП України, 1992 р., N 7, ст.158) слова "у складі згідно з додатком" виключити.

2. Абзац перший пункту 1 постанови Кабінету Міністрів України від 17 серпня 1995 р. N 655 ( 655-95-п ) "Про додаткове забезпечення гарантій або інших зобов'язань Уряду України, які надаються іноземним кредиторам щодо погашення кредитів в іноземній валюті, що залучаються українськими юридичними особами" після слів "розглядає питання про" доповнити словом "доцільність".

ЗАТВЕРДЖЕНИЙ постановою Кабінету Міністрів України від 18 грудня 1995 р. N 1020

ПЕРЕЛІК рішень Уряду, що втратили чинність

1. Пункти 2-4 постанови Кабінету Міністрів України від 16 червня 1992 р. N 337 ( 337-92-п ) "Про створення Валютно-кредитної ради Кабінету Міністрів України " (ЗП України, 1992 р., N 7, ст.158).

2. Постанова Кабінету Міністрів України від 12 листопада 1992 р. N 621 ( 621-92-п), "Про голову Валютно-кредитної ради Кабінету Міністрів України".

3. Постанова Кабінету Міністрів України від 17 лютого 1993 р. N 110 ( 110-93-п ) "Про зміни в складі Валютно-кредитної ради Кабінету Міністрів України".

4. Постанова Кабінету Міністрів України від 26 лютого 1993 р. N 134 ( 134-93-п ) "Про введення до складу Валютно-кредитної ради Кабінету Міністрів України Прядка В.В.".

5. Постанова Кабінету Міністрів України від 3 квітня 1993 р. N 239 ( 239-93-п ) "Про виконуючого обов'язки голови Валютно-кредитної ради Кабінету Міністрів України".

6. Постанова Кабінету Міністрів України від 17 вересня 1993 р. N 768 ( 768-93-п ) "Про затвердження Положення про Валютно-кредитну раду Кабінету Міністрів України" (ЗП України, 1994 р., N 2, ст.34).

7. Постанова Кабінету Міністрів України від 19 вересня 1994 р. N 646 ( 646-94-п ) "Про затвердження складу Валютно-кредитної ради Кабінету Міністрів України".
