Про затвердження складу Української частини комісій з військово-технічного співробітництва

{ Із змінами, внесеними згідно з Розпорядженням КМ N 2062-р ( 2062-2010-р ) від 03.11.2010 }

Затвердити згідно з додатками 1-4 склад Української частини Спільної міжурядової українсько-чеської комісії в галузі оборонної промисловості, Українсько-Польської підкомісії з питань співробітництва оборонних галузей промисловості змішаної Українсько-Польської комісії з питань економічного співробітництва і торгівлі та українсько-словацької робочої групи з питань науково-технічного співробітництва в галузі спеціальної техніки. { Абзац перший із змінами, внесеними згідно з Розпорядженням КМ N 2062-р ( 2062-2010-р ) від 03.11.2010 }

Дозволити голові комісій вносити у разі потреби зміни до їх складу.
