Кабінет Міністрів України; Розпорядження від 30.11.2004 № 874-р

Про надання повноважень на реалізацію військового майна Збройних Сил

Стан: Втратив чинність

Ідентифікатор: 874-2004-р

Текст документа від 03.08.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 листопада 2004 р. N 874-р Київ

Про надання повноважень на реалізацію військового майна Збройних Сил

{ Із змінами, внесеними згідно з Розпорядженням КМ N 455-р ( 455-2006-р ) від 03.08.2006 }

Надати державному підприємству "Укроборонлізинг" повноваження на реалізацію на внутрішньому ринку військового майна Збройних Сил (крім всіх видів озброєння, бойової техніки, боєприпасів), яке придатне для подальшого використання, але не може бути застосоване у повсякденній діяльності військ, надлишкового майна Збройних Сил, а також продуктів утилізації звичайних видів боєприпасів.

{ Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 455-р ( 455-2006-р ) від 03.08.2006 }

Прем'єр-міністр України В.ЯНУКОВИЧ
