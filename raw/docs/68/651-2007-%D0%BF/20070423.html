Деякі питання Міністерства з питань житлово-комунального господарства

Стан: Чинний

Ідентифікатор: 651-2007-п

Текст документа від 23.04.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 квітня 2007 р. N 651 Київ

Деякі питання Міністерства з питань житлово-комунального господарства

Кабінет Міністрів України постановляє:

1. Затвердити граничну чисельність працівників центрального апарату Міністерства з питань житлово-комунального господарства у кількості 205 одиниць.

2. Внести у додатки до постанов Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851; 2003 р., N 29, ст. 1474) і від 2 квітня 2001 р. N 314 ( 314-2001-п ) "Про встановлення ліміту легкових автомобілів, що обслуговують державні органи" (Офіційний вісник України, 2001 р., N 14, ст. 602; 2007 р., N 8, ст. 308) зміни, що додаються.

3. Взяти до відома, що Міністерство з питань житлово-комунального господарства розташовується по вул. Димитрова, 24, у м. Києві.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 23 квітня 2007 р. N 651

ЗМІНИ, що вносяться у додатки до постанов Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) і від 2 квітня 2001 р. N 314 ( 314-2001-п )

1. Доповнити додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) після позиції "Міністерство закордонних справ" такою позицією:

"Міністерство з питань 205 5". житлово-комунального господарства

2. Доповнити додаток 1 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314 ( 314-2001-п ) після позиції "Мінвуглепром" такою позицією:

"Міністерство з питань 8". житлово-комунального господарства
