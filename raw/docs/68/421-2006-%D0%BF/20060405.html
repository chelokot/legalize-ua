Кабінет Міністрів України; Постанова, Перелік від 05.04.2006 № 421

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 421-2006-п

Текст документа від 05.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 квітня 2006 р. N 421 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 34

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 5 квітня 2006 р. N 421

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 22 червня 1998 р. N 940 ( 940-98-п ) "Про затвердження Порядку вилучення готівки у платника податків, який має податкову заборгованість" (Офіційний вісник України, 1998 р., N 25, ст. 924).

2. Постанова Кабінету Міністрів України від 22 червня 1998 р. N 941 ( 941-98-п ) "Про затвердження Порядку звернення стягнення на рухоме майно, що перебуває у податковій заставі, для погашення податкової заборгованості платника податків (крім фізичних осіб - суб'єктів підприємницької діяльності) та реалізації такого майна" (Офіційний вісник України, 1998 р., N 25, ст. 926).

3. Постанова Кабінету Міністрів України від 20 жовтня 1998 р. N 1661 ( 1661-98-п ) "Про внесення змін і доповнень до Порядку звернення стягнення на рухоме майно, що перебуває у податковій заставі, для погашення податкової заборгованості платника податків (крім фізичних осіб - суб'єктів підприємницької діяльності) та реалізації такого майна" (Офіційний вісник України, 1998 р., N 42, ст. 1555).

4. Постанова Кабінету Міністрів України від 27 листопада 1998 р. N 1882 ( 1882-98-п ) "Про внесення доповнень до Порядку звернення стягнення на рухоме майно, що перебуває у податковій заставі, для погашення податкової заборгованості платника податків (крім фізичних осіб - суб'єктів підприємницької діяльності) та реалізації такого майна" (Офіційний вісник України, 1998 р., N 48, ст. 1757).

5. Пункт 22 постанови Кабінету Міністрів України від 26 серпня 1999 р. N 1557 ( 1557-99-п ) "Про заходи щодо поліпшення стану справ у виробничій сфері та збільшення надходження коштів до бюджету" (Офіційний вісник України, 1999 р., N 35, ст. 1790).

6. Постанова Кабінету Міністрів України від 31 січня 2000 р. N 176 ( 176-2000-п ) "Про внесення змін до постанови Кабінету Міністрів України від 22 червня 1998 р. N 941" (Офіційний вісник України, 2000 р., N 5, ст. 170).
