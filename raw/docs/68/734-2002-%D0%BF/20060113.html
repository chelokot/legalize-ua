Кабінет Міністрів України; Постанова від 01.06.2002 № 734

Про організацію навчання та підвищення кваліфікації спеціалістів з питань здійснення процедури закупівлі товарів, робіт і послуг за державні кошти

Стан: Втратив чинність

Ідентифікатор: 734-2002-п

Текст документа від 13.01.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 червня 2002 р. N 734 Київ

Про організацію навчання та підвищення кваліфікації спеціалістів з питань здійснення процедури закупівлі товарів, робіт і послуг за державні кошти

( Із змінами, внесеними згідно з Постановами КМ N 819 ( 819-2003-п ) від 02.06.2003 N 1910 ( 1910-2003-п ) від 10.12.2003 N 19 ( 19-2006-п ) від 13.01.2006 )

З метою забезпечення кваліфікованого здійснення процедури закупівлі товарів, робіт і послуг за державні кошти Кабінет Міністрів України постановляє:

1. Міністерству економіки та з питань європейської інтеграції організувати починаючи з 1 вересня 2002 р. роботу постійно діючих курсів з навчання та підвищення кваліфікації спеціалістів з питань організації та здійснення процедури закупівлі товарів, робіт і послуг за державні кошти (далі - курси). ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 819 ( 819-2003-п ) від 02.06.2003 )

2. Керівникам центральних і місцевих органів виконавчої влади, установ і організацій - розпорядників державних коштів забезпечувати підвищення кваліфікації на курсах спеціалістів, які відповідно до покладених на них функцій беруть участь у роботі тендерних комітетів.

( Абзац другий пункту 2 виключено на підставі Постанови КМ N 1910 ( 1910-2003-п ) від 10.12.2003 )

3. Встановити, що починаючи з другого півріччя 2004 року: ( Абзац перший пункту 3 із змінами, внесеними згідно з Постановою КМ N 819 ( 819-2003-п ) від 02.06.2003 )

заступниками голів та секретарями тендерних комітетів організацій-замовників мають право працювати спеціалісти, які пройшли навчання або підвищили кваліфікацію на курсах і отримали сертифікат чи свідоцтво встановленого зразка; ( Абзац другий пункту 3 в редакції Постанов КМ N 819 ( 819-2003-п ) від 02.06.2003, N 1910 ( 1910-2003-п ) від 10.12.2003 )

для надання послуг з організації та здійснення процедури закупівлі товарів, робіт і послуг за державні кошти можуть залучатися згідно із законодавством інші організації (установи, підприємства), спеціалісти яких пройшли навчання на курсах і отримали відповідний сертифікат;

повторне підвищення кваліфікації спеціалістів на курсах здійснюється не пізніше ніж через два роки після отримання сертифіката чи свідоцтва встановленого зразка. ( Пункт 3 доповнено абзацом згідно з Постановою КМ N 1910 ( 1910-2003-п ) від 10.12.2003; із змінами, внесеними згідно з Постановою КМ N 19 ( 19-2006-п ) від 13.01.2006 )

4. Міністерству освіти і науки разом з Міністерством економіки та з питань європейської інтеграції розробити в місячний термін програму навчання з дисципліни "Організація державної закупівлі товарів, робіт і послуг", а також визначити відповідні вищі навчальні заклади, які будуть здійснювати починаючи з 2002/03 навчального року навчання з цієї дисципліни.

5. Міністерству економіки та з питань європейської інтеграції затвердити зразок сертифіката про проходження навчання на курсах. ( Постанову доповнено пунктом 5 згідно з Постановою КМ N 819 ( 819-2003-п ) від 02.06.2003 )
