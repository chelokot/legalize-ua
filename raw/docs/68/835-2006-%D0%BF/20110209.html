Кабінет Міністрів України; Постанова від 15.06.2006 № 835

Про внесення зміни до Статуту Державної акціонерної компанії "Хліб України"

Стан: Втратив чинність

Ідентифікатор: 835-2006-п

Текст документа від 09.02.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 червня 2006 р. N 835 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 63 ( 63-2011-п ) від 02.02.2011 }

Про внесення зміни до Статуту Державної акціонерної компанії "Хліб України"

Кабінет Міністрів України постановляє:

Пункт 31 Статуту Державної акціонерної компанії "Хліб України", затвердженого постановою Кабінету Міністрів України від 14 березня 2001 р. N 240 ( 240-2001-п ) (Офіційний вісник України, 2001 р., N 12, ст. 489), доповнити абзацом такого змісту:

"Відчуження або передача в заставу майна, переданого засновником до статутного фонду Компанії, та інших основних фондів здійснюється за попередньою згодою засновника".

Прем'єр-міністр України Ю.ЄХАНУРОВ
