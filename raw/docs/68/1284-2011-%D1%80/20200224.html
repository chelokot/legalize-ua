{ Розпорядження втратило чинність на підставі Постанови КМ N 1054 ( 1054-2019-п ) від 18.12.2019 }

Про зміну складу наглядової ради Державної іпотечної установи

Ввести до складу наглядової ради Державної іпотечної установи, затвердженого постановою Кабінету Міністрів України від 17 липня 2009 р. N 768 ( 768-2009-п ) "Про Державну іпотечну установу" (Офіційний вісник України, 2009 р., N 55, ст. 1916; 2010 р., N 52, ст. 1742; 2011 р. , N 2, ст. 116), Касіяника Анатолія Васильовича - директора фінансового департаменту Міністерства регіонального розвитку, будівництва та житлово-комунального господарства, Петрашка Олексія Геннадійовича - члена Державної комісії з цінних паперів та фондового ринку, Чекашкіна Сергія Вікторовича - директора департаменту фінансової політики Міністерства економічного розвитку і торгівлі, вивівши з її складу Бандурова Володимира Володимировича, Петренка Володимира Оникійовича, Пивоварова Костянтина Володимировича.

Прем'єр-міністр України М.АЗАРОВ
