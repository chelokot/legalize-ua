24.05.2005 N 86

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 1246 ( v1246359-06 ) від 26.05.2006 }

Про внесення змін до постанови Центральної виборчої комісії від 1 березня 2005 року N 52 "Про штатний розпис Центральної виборчої комісії"

На підставі наказу Міністерства праці та соціальної політики України від 29 квітня 2005 року N 154 ( z0493-05 ) "Про внесення змін до наказу Міністерства праці України від 02.10.96 N 77", керуючись статтями 12, 33, частиною першою статті 36, частиною першою статті 37 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Внести до штатного розпису Центральної виборчої комісії, затвердженого постановою Центральної виборчої комісії від 1 березня 2005 року N 52 ( v0052359-05 ), такі зміни:

у графі "Технічний працівник" цифри "229" замінити цифрами "279", а цифри "1832" - цифрами "2232";

у графі "Усього" цифри "8475" замінити цифрами "8875";

у графах "Разом" цифри "138312" замінити цифрами "138712", а цифри "157075,3" - цифрами "15 8329"

2. Відділу бухгалтерського обліку та звітності Секретаріату Центральної виборчої комісії провести перерахунок заробітної плати технічних працівників з 1 квітня 2005 року.
