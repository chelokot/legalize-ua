Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 29 грудня 2010 р. N 1221 ( 1221-2010-п ) "Про утворення Державного концерну "Укроборонпром" (Офіційний вісник України, 2011 р., N 1, ст. 6, N 7, ст. 234) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 6 квітня 2011 р. N 374

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 29 грудня 2010 р. N 1221 ( 1221-2010-п )

1. Пункт 2 постанови ( 1221-2010-п ) доповнити підпунктом 3 такого змісту:

"3) забезпечити погодження утворення Концерну з Антимонопольним комітетом в установленому законодавством про захист економічної конкуренції порядку.".

2. Додаток до постанови ( 1221-2010-п ) викласти у такій редакції:

"Додаток до постанови Кабінету Міністрів України від 29 грудня 2010 р. N 1221 ( 1221-2010-п ) (у редакції постанови Кабінету Міністрів України від 6 квітня 2011 р. N 374)
