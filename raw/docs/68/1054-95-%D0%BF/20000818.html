Про зміни ставок ввізного мита на окремі види товарів, які не виробляються або виробляються в недостатній кількості в Україні

Стан: Втратив чинність

Ідентифікатор: 1054-95-п

Текст документа від 18.08.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 грудня 1995 р. N 1054 Київ

Про зміни ставок ввізного мита на окремі види товарів, які не виробляються або виробляються в недостатній кількості в Україні

( Із змінами, внесеними згідно з Постановами КМ N 1378 ( 1378-96-п ) від 08.11.96 N 1379 ( 1379-96-п ) від 08.11.96 N 693 ( 693-98-п ) від 18.05.98 N 926 ( 926-2000-п ) від 06.06.2000 )

З метою забезпечення підприємств сільського господарства країни необхідними технікою, обладнанням та матеріалами Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита на товари згідно з додатком.

2. Визнати таким, що втратив чинність, пункт 2 постанови Кабінету Міністрів України від 17 лютого 1995 р. N 124 ( 124-95-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів" (ЗП України, 1995 р., N 5, ст. 123).

3. Виключити із додатку до постанови Кабінету Міністрів України від 18 липня 1995 р. N 531 ( 531-95-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів та до деяких рішень Уряду України" товари за кодом згідно з ГС 84.33 11510.
