Кабінет Міністрів України; Розпорядження від 29.04.2004 № 266-р

Про підписання Угоди між Кабінетом Міністрів України та Урядом Угорської Республіки про будівництво автомагістралі між Україною та Угорською Республікою

Стан: Втратив чинність

Ідентифікатор: 266-2004-р

Текст документа від 25.01.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 квітня 2004 р. N 266-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 36-р ( 36-2006-р ) від 25.01.2006 )

Про підписання Угоди між Кабінетом Міністрів України та Урядом Угорської Республіки про будівництво автомагістралі між Україною та Угорською Республікою

( Із змінами, внесеними згідно з Розпорядженням КМ N 114-р ( 114-2005-р ) від 20.04.2005 )

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Угорської Республіки про будівництво автомагістралі між Україною та Угорською Республікою.

Уповноважити Міністра транспорту та зв'язку Червоненка Євгена Альфредовича підписати зазначену Угоду, дозволивши вносити до проекту Угоди зміни, які не мають принципового характеру. ( Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 114-р ( 114-2005-р ) від 20.04.2005 )
