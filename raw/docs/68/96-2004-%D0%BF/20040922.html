Про затвердження Порядку використання коштів державного бюджету, які виділяються для часткової компенсації витрат сільськогосподарських підприємств з посіву ярих та озимих зернових культур

( Із змінами, внесеними згідно з Постановою КМ N 1223 ( 1223-2004-п ) від 22.09.2004 )

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2004 рік" ( 1344-15 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання коштів державного бюджету, які виділяються для часткової компенсації витрат сільськогосподарських підприємств з посіву ярих та озимих зернових культур (додається).

( Постановляюча частина із змінами, внесеними згідно з Постановою КМ N 1223 ( 1223-2004-п ) від 22.09.2004 )

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 22

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 30 січня 2004 р. N 96

ПОРЯДОК використання коштів державного бюджету, які виділяються для часткової компенсації витрат сільськогосподарських підприємств з посіву ярих та озимих зернових культур

( Назва Порядку із змінами, внесеними згідно з Постановою КМ N 1223 ( 1223-2004-п ) від 22.09.2004 )

1. Цей Порядок визначає механізм використання коштів у сумі 350 млн гривень, передбачених у Державному бюджеті України на 2004 рік ( 1344-15 ) за бюджетною програмою "Часткова компенсація витрат сільськогосподарських підприємств з посіву ярих та озимих зернових культур". ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1223 ( 1223-2004-п ) від 22.09.2004 )

2. Часткова компенсація сільськогосподарським підприємствам витрат з посіву ярих та озимих зернових культур (далі - компенсація) здійснюється пропорційно фактичній площі посіву ярої пшениці, ярого ячменю, вівса, кукурудзи на зерно, гороху, гречки, проса та рису (далі - ярі). ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1223 ( 1223-2004-п ) від 22.09.2004 )

3. Для складення реєстру сільськогосподарських підприємств, які посіяли ярі та озимі зернові культури і мають право на компенсацію, управління сільського господарства і продовольства райдержадміністрацій утворюють комісії у складі начальника районного управління сільського господарства і продовольства райдержадміністрації (голова комісії), начальника районної насіннєвої інспекції, представника місцевого фінансового органу, представника районної ради сільськогосподарських підприємств, голови районної асоціації фермерів або представника Асоціації фермерів та приватних землевласників України (далі - комісія). ( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1223 ( 1223-2004-п ) від 22.09.2004 )

4. Сільськогосподарські підприємства незалежно від організаційно-правової форми та форми власності подають до комісії заяву на отримання компенсації з доданням копій таких підтвердних документів: форми державної статистичної звітності N 3-сг "Звіт про сівбу та наявність насіння ярих культур" та N 4-сг "Заключний звіт про підсумки сівби під урожай 200__ року", затверджені наказами Держкомстату відповідно від 6 червня 2003 р. N 165 ( v0165202-03 ) та від 1 липня 2002 р. N 254 ( v0254202-02 ), а також спеціалізованих бухгалтерських форм первинного обліку N 119 "Акт витрат насіння і садивного матеріалу" та N 118 "Акт про використання мінеральних, органічних і бактеріальних добрив, отрутохімікатів і гербіцидів" та довідки районної державної податкової інспекції щодо відсутності (наявності) заборгованості за податковими зобов'язаннями. ( Абзац перший пункту 4 із змінами, внесеними згідно з Постановою КМ N 1223 ( 1223-2004-п ) від 22.09.2004 )

Комісія розглядає подані документи та приймає рішення щодо включення сільськогосподарських підприємств, які мають право на компенсацію, до реєстру (додаток 1), а у разі потреби обстежує посівні площі з метою перевірки поданих їй матеріалів. Результати перевірки оформляються актом (додаток 2).

Реєстр ведеться управліннями сільського господарства і продовольства райдержадміністрацій.

5. Управління сільського господарства і продовольства райдержадміністрації подає оперативну інформацію (додаток 3) Міністерству агропромислового комплексу Автономної Республіки Крим та головним управлінням сільського господарства і продовольства облдержадміністрацій.

6. Міністерство агропромислового комплексу Автономної Республіки Крим, головні управління сільського господарства і продовольства облдержадміністрацій протягом 5 календарних днів після складення реєстрів сільськогосподарських підприємств, які мають право на компенсацію, подають до Мінагрополітики разом з цими реєстрами зведену оперативну інформацію про обсяги площ, на яких зійшли ярі зернові культури. Остаточна інформація про зазначені обсяги ярої пшениці повинна надійти до Мінагрополітики до 5 травня 2004 року, ярого ячменю, вівса, кукурудзи на зерно, гороху, гречки, проса, рису - до 5 жовтня 2004 року. ( Пункт 6 із змінами, внесеними згідно з Постановою КМ N 1223 ( 1223-2004-п ) від 22.09.2004 )

7. Мінагрополітики на підставі отриманої інформації подає відповідно до бюджетного розпису Державному казначейству розподіл цих коштів між Міністерством агропромислового комплексу Автономної Республіки Крим та головними управліннями сільського господарства і продовольства облдержадміністрацій. Остаточний розподіл коштів на яру пшеницю повинен бути надісланий до Державного казначейства до 15 травня 2004 р., а на ярий ячмінь, овес, кукурудзу на зерно, горох, гречку, просо та рис - до 10 жовтня 2004 року. ( Абзац перший пункту 7 із змінами, внесеними згідно з Постановою КМ N 1223 ( 1223-2004-п ) від 22.09.2004 )

Державне казначейство на підставі отриманих розподілів здійснює видатки, що спрямовуються на компенсацію.

8. Міністерство агропромислового комплексу Автономної Республіки Крим, головні управління сільського господарства і продовольства облдержадміністрацій на підставі реєстрів пропорційно надають у межах перерахованих коштів відповідним територіальним органам Державного казначейства розподіли коштів між управліннями сільського господарства і продовольства райдержадміністрацій.

9. Управління сільського господарства і продовольства райдержадміністрацій надають територіальним органам Державного казначейства платіжні доручення для перерахування коштів, які виділяються для компенсації, на поточні рахунки сільськогосподарських підприємств в установах банків. Перерахування коштів здійснюється на підставі платіжних доручень та підтвердних документів, наданих сільськогосподарськими підприємствами згідно з пунктом 4 цього Порядку. Підтвердні документи зберігаються протягом трьох років в управліннях сільського господарства і продовольства райдержадміністрацій.

10. Сільськогосподарські підприємства спрямовують отримані бюджетні кошти на часткову компенсацію витрат з посіву ярих зернових культур, в тому числі як першочергові платежі на погашення заборгованості з виплати заробітної плати та платежів до бюджетів усіх рівнів, придбання пально-мастильних матеріалів, запасних частин, насіння, мінеральних добрив та засобів захисту рослин. ( Пункт 10 із змінами, внесеними згідно з Постановою КМ N 1223 ( 1223-2004-п ) від 22.09.2004 )

11. Складення та подання звітності про використання коштів державного бюджету здійснюються в установленому законодавством порядку.
