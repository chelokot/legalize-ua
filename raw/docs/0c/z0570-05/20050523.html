23.05.2005 N 139

Зареєстровано в Міністерстві юстиції України 24 травня 2005 р. за N 570/10850

Про внесення зміни до наказу Міністерства економіки та з питань європейської інтеграції України від 14.04.2005 N 95

Відповідно до статті 3 Указу Президента "Про заходи щодо стабілізації ситуації на ринку нафти і нафтопродуктів" від 18.05.2005 N 823 ( 823/2005 ) та пункту 23 додатка до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

В абзаці першому пункту 1 наказу Міністерства економіки та з питань європейської інтеграції України від 14.04.2005 N 95 ( z0407-05 ) "Про встановлення граничних рівнів оптово-відпускних цін на дизельне паливо і бензини моторні", зареєстрованого в Міністерстві юстиції України 15.04.2005 за N 407/10687, цифри "01.06.2005" замінити цифрами "25.05.2005".
