Текст документа від 19.04.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 квітня 2001 р. N 413 Київ

Про внесення змін до постанови Кабінету Міністрів України від 27 січня 1997 р. N 65

{ Із змінами, внесеними згідно з Постановою КМ N 622 ( 622-2007-п ) від 13.04.2007 }

Кабінет Міністрів України постановляє:

1. Внести до постанови Кабінету Міністрів України від 27 січня 1997 р. N 65 ( 65-97-п ) "Про ставки митних зборів" (газета "Урядовий кур'єр" від 1 лютого 1997 р.; Офіційний вісник України, 1998 р., N 10, ст. 381, N 19, ст. 706, N 38, ст. 1392; 1999 р., N 20, ст. 893, N 27, ст. 1332) такі зміни:

а) в абзаці першому пункту 1 слова "згідно з додатком" замінити словами і цифрою "згідно з додатком 1", виклавши назву цього додатка у такій редакції:

"Ставки митних зборів, передбачені Митним кодексом України";

{ Підпункт "б" пункту 1 втратив чинність на підставі Постанови КМ N 622 ( 622-2007-п ) від 13.04.2007 }

2. Ця постанова набирає чинності через 30 днів з дня опублікування.
