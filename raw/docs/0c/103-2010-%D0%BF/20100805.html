{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про внесення зміни до пункту 7 Положення про закупівлю товарів, робіт і послуг за державні кошти

Кабінет Міністрів України постановляє:

Внести зміну до пункту 7 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006; 2009 р., N 1, ст. 17, N 11, ст. 338, N 23, ст. 741, N 55, ст. 1915, N 56, ст. 1955, N 62, ст. 2195, N 65, ст. 2271, N 82, ст. 2770, N 92, ст. 3119), виклавши абзац сімнадцятий у такій редакції:

"товари, роботи і послуги, які закуповуються в установ виконання покарань, слідчих ізоляторів (виробничих майстерень і підсобних господарств таких установ та ізоляторів), підприємств установ виконання покарань, за умови, що зазначені товари, роботи і послуги безпосередньо виробляються (виконуються, надаються) ними і граничний рівень рентабельності їх виробництва (виконання, надання) не перевищує 5 відсотків;".

Прем'єр-міністр України Ю.ТИМОШЕНКО
