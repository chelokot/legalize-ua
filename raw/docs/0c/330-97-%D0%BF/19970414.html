КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 квітня 1997 р. N 330 Київ

Про реорганізацію структури апарату Кабінету Міністрів України

З метою удосконалення системи управління апаратом Кабінету Міністрів України та забезпечення виконання ним функцій, визначених Конституцією України ( 254к/96-ВР), законами України та актами Президента України, Кабінет Міністрів України постановляє:

1. Реорганізувати апарат Кабінету Міністрів України, затвердивши його нову структуру (додається до оригіналу постанови).

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з додатком.

3. Міністру Кабінету Міністрів України здійснити організаційні заходи, пов'язані з реорганізацією та ліквідацією підрозділів апарату Кабінету Міністрів України відповідно до законодавства.

2. Постанова Кабінету Міністрів України від 20 липня 1996 р. N 785 ( 785-96-п ) "Про часткові зміни до постанови Кабінету Міністрів України від 3 липня 1996 р. N 713 "Про реорганізацію структури апарату Кабінету Міністрів України".

3. Постанова Кабінету Міністрів України від 12 вересня 1996 р. N 1102 ( 1102-96-п ) "Про внесення змін до постанови Кабінету Міністрів України від 3 липня 1996 р. N 713".

4. Постанова Кабінету Міністрів України від 30 листопада 1996 р. N 1425 ( 1425-96-п ) "Про зміну пункту 4 постанови Кабінету Міністрів України від 3 липня 1996 р. N 713".

5. Постанова Кабінету Міністрів України від 28 грудня 1996 р. N 1564 ( 1564-96-п ) "Про часткову зміну структури апарату Кабінету Міністрів України, затвердженої постановою Кабінету Міністрів України від 3 липня 1996 р. N 713".

6. Постанова Кабінету Міністрів України від 29 січня 1997 р. N 80 "Про зміну пункту 4 постанови Кабінету Міністрів України від 3 липня 1996 р. N 713".
