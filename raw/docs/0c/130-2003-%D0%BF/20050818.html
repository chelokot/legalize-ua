КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 січня 2003 р. N 130 Київ

Про затвердження Віце-прем'єр-міністра України Гайдука В.А. керівником деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

( Із змінами, внесеними згідно з Постановою КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Кабінет Міністрів України постановляє:

1. Затвердити Віце-прем'єр-міністра України Гайдука Віталія Анатолійовича:

( Абзац другий пункту 1 втратив чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

головою Державної комісії з питань техногенно-екологічної безпеки та надзвичайних ситуацій;

головою Координаційної ради з питань врегулювання кризових ситуацій у вугільній промисловості;

головою Координаційної ради із створення та функціонування Урядової інформаційно-аналітичної системи з питань надзвичайних ситуацій;

головою міжвідомчої робочої групи з розроблення Концепції розвитку та ефективної експлуатації газотранспортної системи України;

головою Міжвідомчої комісії з питань транспортних коридорів та транзитної політики;

головою Міжвідомчої комісії з питань забезпечення ефективного і безпечного функціонування авіаційного транспорту, авіаційної промисловості, авіації загального призначення та системи використання повітряного простору України;

( Абзац дев'ятий пункту 1 втратив чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

головою Ради стандартизації;

керівником робочої групи для проведення аналізу комплексу питань щодо організації функціонування нафтопроводу Одеса - Броди;

координатором програми INOGATE.

2. Увільнити Дубину Олега Вікторовича, Єханурова Юрія Івановича, Рогового Василя Васильовича, Тимошенко Юлію Володимирівну від обов'язків керівників органів, зазначених у пункті 1 цієї постанови.
