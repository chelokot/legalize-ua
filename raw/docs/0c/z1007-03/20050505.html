ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

20.10.2003 N 707

Зареєстровано в Міністерстві юстиції України 4 листопада 2003 р. за N 1007/8328

Про внесення змін і доповнень до Переліку, затвердженого наказом Держмитслужби України від 31.01.2002 N 57

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Державної митної служби

N 57 ( z0150-02 ) від 31.01.2002, до якого вносились зміни }

На виконання вимог статті 38 Митного кодексу України ( 1970-12 ), з урахуванням уточнених даних про спроможність пунктів пропуску через митний кордон України, ситуації, що склалася в пунктах пропуску для автомобільного сполучення, і з метою вдосконалення порядку здійснення митного контролю та митного оформлення транспортних засобів за кодами 8701, 8702, 8703, 8704, 8705 згідно з Українською класифікацією товарів зовнішньоекономічної діяльності ( 2371г-14 ) (УКТЗЕД), що ввозяться громадянами в Україну для вільного використання, переміщуються транзитом через територію України, а також тимчасово ввозяться на митну територію України громадянами-резидентами, НАКАЗУЮ:

1. Виключити з Переліку пунктів пропуску через митний кордон України, через які здійснюється переміщення транспортних засобів за кодами 8701, 8702, 8703, 8704, 8705 згідно з Українською класифікацією товарів зовнішньоекономічної діяльності ( 2371г-14 ) (УКТЗЕД), що переміщуються громадянами з метою вільного використання на митній території України, транзиту через територію України, а також тимчасово ввозяться на митну територію України громадянами-резидентами, затвердженого наказом Державної митної служби України від 31.01.2002 N 57 ( z0150-02 ) і зареєстрованого в Міністерстві юстиції України 15.02.2002 за N 150/6438, міжнародний пункт пропуску для автомобільного сполучення:

на кордоні з Республікою Молдова - "Тірас (Маяки, Удобне - Паланка)" Білгород-Дністровської митниці.

2. Доповнити Перелік, затверджений наказом Державної митної служби України від 31.01.2002 N 57 ( z0150-02 ), міжнародними пунктами пропуску для автомобільного сполучення:

на кордоні з Республікою Молдова - "Старокозаче - Тудора" Білгород-Дністровської митниці;

на кордоні з Угорською Республікою - "Лужанка - Берегшурань" Закарпатської митниці.

3. Управлінню технологій митного контролю (Сьомка С.М.) та Управлінню правової роботи (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Відділу з питань взаємодії із засобами масової інформації та зв'язків з громадськістю (Гунько С.О.) забезпечити висвітлення цього наказу в засобах масової інформації.

5. Управлінню міжнародного митного співробітництва (Мароха В.М.) інформувати митні органи суміжних з Україною держав про вимоги цього наказу.

6. Цей наказ набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

7. Контроль за виконанням наказу покласти на заступника Голови Служби Іванюка М.М.
