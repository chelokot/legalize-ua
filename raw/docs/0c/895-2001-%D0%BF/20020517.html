КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 липня 2001 р. N 895 Київ

Про затвердження переліку галузей (підгалузей) виробництва, які є пріоритетними для реалізації інвестиційних проектів на територіях пріоритетного розвитку в Луганській області

( Із змінами, внесеними згідно з Постановою КМ N 658 ( 658-2002-п ) від 17.05.2002 )

Кабінет Міністрів України постановляє:

1. Затвердити перелік галузей (підгалузей) виробництва, які є пріоритетними для реалізації інвестиційних проектів на територіях пріоритетного розвитку в Луганській області (додається).

2. Визнати такими, що втратили чинність:

пункт 1 (у частині затвердження переліку галузей (підгалузей) виробництва, які є пріоритетними для реалізації інвестиційних проектів на територіях пріоритетного розвитку в Луганській області) постанови Кабінету Міністрів України від 25 жовтня 1999 р. N 1968 ( 1968-99-п ) (Офіційний вісник України, 1999 р., N 43, ст. 2145);

пункт 2 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 26 липня 2000 р. N 1175 ( 1175-2000-п ) "Про деякі питання інвестиційної діяльності на територіях пріоритетного розвитку та спеціальних економічних зон" (Офіційний вісник України, 2000 р., N 30, ст. 1281).
