Про внесення змін до деяких наказів Держмитслужби України

{ Із змінами, внесеними згідно з Наказом Державної митної служби

N 933 ( z1329-07 ) від 07.11.2007 }

Відповідно до Положення про Державну митну службу України, затвердженого Указом Президента України від 24.08.2000 N 1022 ( 1022/2000 ), Положення про вантажну митну декларацію, затвердженого постановою Кабінету Міністрів України від 09.06.97 N 574 ( 574-97-п ) (зі змінами), і з метою спрощення процедури декларування товарів різних найменувань, що входять до однієї партії, НАКАЗУЮ:

1. Доповнити опис графи 44 "Додаткова інформація/подані документи" глави 2 Інструкції про порядок заповнення вантажної митної декларації, затвердженої наказом Держмитслужби України від 09.07.97 N 307 ( z0443-97 ) і зареєстрованої в Міністерстві юстиції України 24.09.97 за N 443/2247 (у редакції наказу Держмитслужби України від 18.04.2002 N 207 ( z0462-02 ), після абзацу шостого новим абзацом такого змісту:

"У разі використання при декларуванні додаткових аркушів форми МД-3 ( 574-97-п ) або формулярів-специфікацій форми МД-8 реквізити документів, які подані при митному оформленні та стосуються всіх товарів, що декларуються в цій ВМД, наводяться в цій графі тільки в основному аркуші ВМД форми МД-2 ( 574-97-п ) і в додаткових аркушах або формулярах-специфікаціях цієї ВМД не дублюються".

{ Пункт 2 втратив чинність на підставі Наказу Державної митної служби N 933 ( z1329-07 ) від 07.11.2007 }

3. Департаменту декларування та митних режимів (Науменко В.П.) і Юридичному департаменту (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Департаменту інформаційних технологій та митної статистики (Копосов С.А.) доопрацювати програмне забезпечення з урахуванням вимог цього наказу.

5. Начальникам митних органів довести цей наказ до відома юридичних і фізичних осіб.

6. Установити, що цей наказ набирає чинності через 10 днів з дня його офіційного опублікування.

7. Контроль за виконанням наказу покласти на першого заступника Голови Держмитслужби України Федорова О.О.
