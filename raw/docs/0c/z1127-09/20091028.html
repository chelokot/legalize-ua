Про внесення змін до деяких наказів Держкомзему

Відповідно до пунктів 7 та 10 Положення про Державний комітет України із земельних ресурсів, затвердженого постановою Кабінету Міністрів України від 19.03.2008 N 224 ( 224-2008-п ), НАКАЗУЮ:

1. Затвердити такі, що додаються:

Зміни до Положення про головне управління Держкомзему в області, затвердженого наказом Державного комітету України із земельних ресурсів від 17.06.2008 N 123 ( z0623-08 ), зареєстрованого в Міністерстві юстиції України 10.07.2008 за N 623/15314 (із змінами);

Зміни до Положення про головні управління Держкомзему в містах Києві та Севастополі ( z0624-08 ), затвердженого наказом Державного комітету України із земельних ресурсів від 17.06.2008 N 123 ( z0623-08 ), зареєстрованого в Міністерстві юстиції України 10.07.2008 за N 624/15315 (із змінами) ( z1128-09 );

Зміни до Положення про управління (відділ) Держкомзему в районі ( z0625-08 ), затвердженого наказом Державного комітету України із земельних ресурсів від 17.06.2008 N 123 ( z0623-08 ), зареєстрованого в Міністерстві юстиції України 10.07.2008 за N 625/15316 (із змінами) ( z1129-09 );

Зміни до Положення про управління (відділ) Держкомзему в місті (обласного та районного значення) ( z0626-08 ), затвердженого наказом Державного комітету України із земельних ресурсів від 17.06.2008 N 123 ( z0623-08 ), зареєстрованого в Міністерстві юстиції України 10.07.2008 за N 626/15317 (із змінами) ( z1130-09 );

Зміни до Положення про міжрайонне управління (відділ) Держкомзему, затвердженого наказом Державного комітету України із земельних ресурсів від 03.06.2009 N 281 ( z0509-09 ), зареєстрованого в Міністерстві юстиції України 12.06.2009 за N 509/16525 ( z1131-09 );

Зміни до Положення про міжміське управління (відділ) Держкомзему ( z0510-09 ), затвердженого наказом Державного комітету України із земельних ресурсів від 03.06.2009 N 281 ( z0509-09 ), зареєстрованого в Міністерстві юстиції України 12.06.2009 за N 510/16526 ( z1132-09 );

Зміни до Положення про міськрайонне управління (відділ) Держкомзему ( z0511-09 ), затвердженого наказом Державного комітету України із земельних ресурсів від 03.06.2009 N 281 ( z0509-09 ), зареєстрованого в Міністерстві юстиції України 12.06.2009 за N 511/16527 ( z1133-09 ).

2. Управлінню правового забезпечення (Юрець О.І.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності з дня його офіційного опублікування.

4. Контроль за виконанням цього наказу залишаю за собою.

Заступник Голови С.В.Бєльчик

ЗАТВЕРДЖЕНО Наказ Держкомзему 28.10.2009 N 559

Зареєстровано в Міністерстві юстиції України 24 листопада 2009 р. за N 1127/17143

ЗМІНИ до Положення про головне управління Держкомзему в області ( z0623-08 )

1. Пункт 3 доповнити новим абзацом такого змісту:

"здійснення державного контролю за використанням та охороною земель.".

2. Пункт 4 після підпункту 37 доповнити новими підпунктами 38 та 39 такого змісту:

"38) здійснює державний контроль за використанням та охороною земель відповідно до Закону України "Про державний контроль за використанням та охороною земель" ( 963-15 ) та інших законів;

39) обстежує земельні ділянки та видає спеціальні дозволи на зняття та перенесення ґрунтового покриву земельних ділянок відповідно до проектів, затверджених в установленому порядку, а також обстежує земельні ділянки, яким заподіяно шкоду внаслідок їх самовільного зайняття, використання не за цільовим призначенням зняття ґрунтового покриву (родючого шару ґрунту) без спеціального дозволу;".

У зв'язку з цим підпункт 38 вважати підпунктом 40.

3. Пункт 8 доповнити новим абзацом такого змісту:

"Першого заступника або заступника начальника головного управління в області - Головного державного інспектора з контролю за використанням та охороною земель області призначає на посаду та звільняє з посади Головний державний інспектор України з контролю за використанням та охороною земель за поданням керівника Державної інспекції з контролю за використанням та охороною земель Держкомзему.".

Начальник Управління правового забезпечення О.І.Юрець
