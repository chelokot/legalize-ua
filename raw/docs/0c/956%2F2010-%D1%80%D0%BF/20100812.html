Про створення міжвідомчої робочої групи з аналізу стану додержання законодавства у сфері земельних відносин

Стан: Втратив чинність

Ідентифікатор: 956/2010-рп

Текст документа від 12.08.2010:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про створення міжвідомчої робочої групи з аналізу стану додержання законодавства у сфері земельних відносин

{ Із змінами, внесеними згідно з Розпорядженням Президента N 1036/2010-рп ( 1036/2010-рп ) від 12.08.2010 }

З метою захисту конституційних прав власності громадян на землю, забезпечення проведення аналізу додержання законодавства у сфері земельних відносин, а також підготовки пропозицій Президентові України стосовно врегулювання проблемних питань у цій сфері відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ):

1. Утворити міжвідомчу робочу групу з аналізу стану додержання законодавства у сфері земельних відносин (далі - міжвідомча робоча група).

2. Призначити ВАСИЛЬЄВА Геннадія Андрійовича - заступника Глави Адміністрації Президента України - керівником міжвідомчої робочої групи.

3. Затвердити персональний склад міжвідомчої робочої групи (додається).

4. Міжвідомчій робочій групі у шестимісячний строк:

1) забезпечити комплексне вивчення, у тому числі з виїздом на місце, діяльності місцевих органів виконавчої влади при здійсненні ними повноважень щодо:

розпорядження землями оздоровчого, рекреаційного, історико-культурного, природно-заповідного та іншого природоохоронного призначення, землями водного та лісового фонду;

регулювання земельних відносин, раціонального використання та охорони земель, забезпечення прав громадян на землю;

2) підготувати за результатами проведеної роботи пропозиції щодо усунення виявлених порушень та вдосконалення чинного законодавства у сфері земельних відносин, у тому числі запобігання тіньовій приватизації особливо цінних земель.

Президент України В.ЯНУКОВИЧ
