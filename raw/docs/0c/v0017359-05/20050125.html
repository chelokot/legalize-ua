11.01.2005 N 17

( Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 22 ( v0022359-05 ) від 25.01.2005 )

Про штатні розписи Центральної виборчої комісії та автогосподарства Центральної виборчої комісії

Керуючись частиною третьою статті 6, статтями 12, 13, 33, 35 та частиною першою статті 36 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), відповідно до постанови Кабінету Міністрів України від 13 грудня 1999 року N 2288 ( 2288-99-п ) "Про впорядкування умов оплати праці працівників апарату органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів", постанови Центральної виборчої комісії від 6 серпня 2004 року N 332 ( v0332359-04 ) "Про структуру і чисельність Секретаріату Центральної виборчої комісії та автогосподарства Центральної виборчої комісії", наказу Міністерства праці України від 2 жовтня 1996 року N 77 ( z0593-96 ) "Про умови оплати праці робітників, зайнятих обслуговуванням органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів" та Угоди між Міністерством транспорту України і профспілками працівників автомобільного транспорту України по галузі автомобільного транспорту на 2002-2003 роки із змінами та доповненнями Центральна виборча комісія постановляє:

1. Ввести з 1 січня 2005 року штатні розписи Центральної виборчої комісії та автогосподарства Центральної виборчої комісії (додатки 1, 2)*.

2. Постанову Центральної виборчої комісії від 11 серпня 2004 року N 374 ( v0374359-04 ) "Про штатні розписи Центральної виборчої комісії та автогосподарства Центральної виборчої комісії" вважати такою, що втратила чинність.

3. Постанову Центральної виборчої комісії від 13 грудня 2004 року N 1293 ( v1293359-04 ) "Про штатні розписи Центральної виборчої комісії та автогосподарства Центральної виборчої комісії" вважати такою, що втратила чинність.
