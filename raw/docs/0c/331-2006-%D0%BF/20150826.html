ПОСТАНОВА від 15 березня 2006 р. N 331 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 609 ( 609-2015-п ) від 05.08.2015 }

Про внесення зміни до переліку органів ліцензування

Кабінет Міністрів України постановляє:

У пункті 13 переліку органів ліцензування, затвердженого постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001; 2004 р., N 10, ст. 597), слово "Держтурадміністрація" замінити словом "Держтуризмкурортів".
