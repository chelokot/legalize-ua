КАБІНЕТ МІНІСТРІВ УКРАЇНИ
ПОСТАНОВА

від 3 грудня 2009 р. № 1312
Київ

Про заснування академічної стипендії Кабінету Міністрів України обдарованим студентам із числа осіб з інвалідністю

{Назва Постанови із змінами, внесеними згідно з Постановою КМ № 369 від 25.03.2026 }

{Із змінами, внесеними згідно з Постановою КМ
№ 369 від 25.03.2026}

З метою створення більш сприятливих умов для здобуття молоддю із числа осіб з інвалідністю освіти і заохочення обдарованих студентів зазначеної категорії Кабінет Міністрів України постановляє :

{Вступна частина із змінами, внесеними згідно з Постановою КМ № 369 від 25.03.2026 }

1. Заснувати академічну стипендію Кабінету Міністрів України обдарованим студентам із числа осіб з інвалідністю (далі - академічна стипендія):

100 академічних стипендій для студентів закладів вищої освіти;

50 академічних стипендій для студентів закладів фахової передвищої освіти;

{Абзац третій пункту 1 в редакції Постанови КМ № 369 від 25.03.2026 - набирає чинності з 01.09.2026 }

30 академічних стипендій для студентів закладів професійної освіти.

{Абзац четвертий пункту 1 в редакції Постанови КМ № 369 від 25.03.2026 - набирає чинності з 01.09.2026 }

{Пункт 1 в редакції Постанови КМ № 369 від 25.03.2026 }

2. Установити, що:

академічна стипендія виплачується на навчальний рік студентам, які навчаються на рівнях професійної освіти, фахової передвищої освіти, першому (бакалаврському), другому (магістерському) рівні вищої освіти;

студентам із числа осіб з інвалідністю I групи академічна стипендія збільшується на 50 відсотків.

Академічна стипендія виплачується у межах відповідних бюджетних асигнувань, передбачених у державному (відповідному місцевому) бюджеті.

{Пункт 2 в редакції Постанови КМ № 369 від 25.03.2026 }

{Пункт 3 виключено на підставі Постанови КМ № 369 від 25.03.2026 }
