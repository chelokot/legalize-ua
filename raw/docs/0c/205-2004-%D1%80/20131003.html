Текст документа від 03.10.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 березня 2004 р. N 205-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Про віднесення посад працівників апарату організаційного забезпечення діяльності Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників апарату організаційного забезпечення діяльності Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України до таких категорій посад державних службовців:

друга категорія - посада керівника апарату;

третя категорія - посади завідувача відділу, головного консультанта;

четверта категорія - посада провідного спеціаліста.

Прем'єр-міністр України В.ЯНУКОВИЧ
