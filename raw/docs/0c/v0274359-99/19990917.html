Про зразок штампу з позначкою "вибув" для дільничних виборчих комісій по виборах Президента України

Відповідно до частини сьомої статті 40 Закону України "Про вибори Президента України" ( 474-14 ) та статей 11, 12, пункту 9 статті 13 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ) Центральна виборча комісія ПОСТАНОВЛЯЄ:

1. Встановити зразок штампу з позначкою "вибув" для дільничних виборчих комісій по виборах Президента України (додається).

2. Територіальним виборчим комісіям по виборах Президента України забезпечити організацію виготовлення штампів з позначкою "вибув" для дільничних виборчих комісій.
