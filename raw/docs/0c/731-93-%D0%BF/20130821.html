Текст документа від 21.08.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 вересня 1993 р. N 731 Київ

Про видачу іноземним громадянам диплома доктора філософії

{ Із змінами, внесеними згідно з Постановою КМ N 538 ( 538-2013-п ) від 07.08.2013 }

З метою розширення міжнародних наукових зв'язків і забезпечення підготовки наукових кадрів для інших країн світу Кабінет Міністрів України постановляє:

1. Тимчасово дозволити Міністерству освіти і науки видавати дипломи (англійською мовою) доктора філософії іноземним громадянам відповідно до міжурядових угод та домовленостей за наявності рішення спеціалізованої вченої ради про присудження їм наукового ступеня кандидата наук та підтвердження країною постійного місця проживання здобувача еквівалентності наукових ступенів кандидата наук і доктора філософії. Форма і опис диплома затверджуються Міністерством освіти і науки.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 538 ( 538-2013-п ) від 07.08.2013 }

2. Міністерству освіти і науки в шестимісячний термін привести у відповідність із загальновстановленими міжнародними вимогами систему підготовки здобувачів наукових ступенів, а також розробити і внести на розгляд Кабінету Міністрів України проект законодавчого акта, яким передбачити запровадження наукового ступеня доктора філософії з відповідної галузі наук замість наукового ступеня кандидата наук.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 538 ( 538-2013-п ) від 07.08.2013 }
