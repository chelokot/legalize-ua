{ Позначку "Не для друку" знято Розпорядженням КМ N 1632-р ( 1632-2010-р ) від 04.08.2010 }

Про введення додатково штатних одиниць в Секретаріаті Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Ввести в Секретаріаті Кабінету Міністрів України додатково 9 штатних одиниць, відповідно збільшивши чисельність працівників Управління моніторингу та ринкових перетворень в енергетичному секторі економіки.

Міністерству фінансів під час уточнення показників Державного бюджету на 2000 рік ( 1458-14 ) передбачити необхідні зміни до кошторису видатків на утримання Секретаріату Кабінету Міністрів України.
