Кабінет Міністрів України; Розпорядження від 23.12.2009 № 1616-р

Деякі питання забезпечення закладів охорони здоров'я транспортними засобами для надання медичної допомоги населенню

Стан: Чинний

Ідентифікатор: 1616-2009-р

Текст документа від 10.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 2009 р. N 1616-р Київ

Деякі питання забезпечення закладів охорони здоров'я транспортними засобами для надання медичної допомоги населенню

{ Із змінами, внесеними згідно з Розпорядженням КМ N 29-р ( 29-2010-р ) від 13.01.2010 }

{ Додатково див. Постанову Окружного адміністративного суду міста Києва

N 2а-4919/10/2670 ( v4919805-10 ) від 10.09.2010 }

1. З метою забезпечення закладів охорони здоров'я транспортними засобами для надання медичної допомоги населенню, що проживає у віддалених, важкодоступних районах, підтримати погоджену з Державною митною службою пропозицію Міністерства охорони здоров'я щодо надання Державною податковою адміністрацією державному підприємству для постачання медичних установ "Укрмедпостач" відстрочення сплати податкових зобов'язань (податків, зборів, інших обов'язкових платежів), які виникають у 2009-2010 роках у зв'язку з виконанням договору поставки транспортних засобів, укладеного 14 вересня 2009 р. між зазначеним підприємством та компанією "Vamed Engineering GmbH&CO KG", згідно з вимогами статті 14 Закону України "Про порядок погашення зобов'язань платників податків перед бюджетами та державними цільовими фондами" ( 2181-14 ) з перенесенням строків сплати необхідних платежів за розстроченими зобов'язаннями на IV квартал 2010 року.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 29-р ( 29-2010-р ) від 13.01.2010 }

2. Міністерству внутрішніх справ вжити заходів до безоплатної реєстрації та постановки на облік зазначених у пункті 1 цього розпорядження транспортних засобів.

3. Державній комісії з регулювання ринків фінансових послуг разом з Моторним (транспортним) страховим бюро забезпечити укладення договорів обов'язкового страхування цивільно-правової відповідальності з відстроченням сплати страхових платежів з власниками транспортних засобів, зазначених у пункті 1 цього розпорядження.

4. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України Ю.ТИМОШЕНКО
