Текст документа від 15.08.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 листопада 2006 р. N 1562 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 585 ( 585-2015-п ) від 12.08.2015 }

Про внесення змін до постанови Кабінету Міністрів України від 22 лютого 2006 р. N 190

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 22 лютого 2006 р. N 190 ( 190-2006-п ) "Про утворення Міжвідомчої комісії з погашення заборгованості підприємств паливно-енергетичного комплексу" (Офіційний вісник України, 2006 р., N 8, ст. 447) такі зміни:

на часткову зміну абзацу другого пункту 1 постанови затвердити заступника Міністра палива та енергетики Тітенка Сергія Михайловича головою Комісії;

в абзаці першому пункту 5 Положення, затвердженого зазначеною постановою, слова "перший заступник Міністра палива та енергетики (голова Комісії)" замінити словами "заступник Міністра палива та енергетики (голова Комісії)".

Прем'єр-міністр України В.ЯНУКОВИЧ
