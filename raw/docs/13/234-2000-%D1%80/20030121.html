КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 травня 2000 р. N 234-р Київ

( Із змінами, внесеними згідно з Постановами КМ N 1004 ( 1004-2001-п ) від 09.08.2001 N 106 ( 106-2003-п ) від 21.01.2003 )

Затвердити склад наглядової ради Українського фонду соціальних інвестицій згідно з додатком.

Прем'єр-міністр України В.ЮЩЕНКО

Інд. 26

Додаток до розпорядження Кабінету Міністрів України від 12 травня 2000 р. N 234-р

СКЛАД наглядової ради Українського фонду соціальних інвестицій

ТАБАЧНИК - Віце-прем'єр-міністр України, Дмитро Володимирович голова наглядової ради

САХАНЬ - Міністр праці та соціальної Іван Якович політики, заступник голови наглядової ради

КРАВЧУК - заступник Міністра праці та Ігор Іванович соціальної політики, відповідальний секретар наглядової ради

БОГОМОЛОВ - заступник Міністра освіти і науки Анатолій Григорович

ГЕРМАНЧУК - перший заступник Міністра фінансів Петро Кузьмович

ГРИГОРЕНКО - перший заступник керівника Євген Миколайович Головного управління з питань економічної політики Адміністрації Президента України (за згодою)

ІВАНКЕВИЧ - начальник Управління стратегії Віктор Вікторович реформування соціальних відносин Департаменту внутрішньої політики Секретаріату Кабінету Міністрів України

СТОЯН - голова Федерації профспілок Олександр Миколайович України, народний депутат України (за згодою)

СУШКЕВИЧ - голова Комітету Верховної Ради Валерій Михайлович України у справах пенсіонерів, ветеранів та інвалідів (за згодою)

ШУМИЛО - заступник Міністра економіки Ігор Анатолійович

( Склад із змінами, внесеними згідно з Постановами КМ N 1004 ( 1004-2001-п ) від 09.08.2001, N 106 ( 106-2003-п ) від 21.01.2003 )
