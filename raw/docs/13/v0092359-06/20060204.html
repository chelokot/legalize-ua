Про скаргу Манчук І.К., зареєстровану в Центральній виборчій комісії 3 січня 2006 року за N 21-34-68

До Центральної виборчої комісії 3 січня 2006 року надійшла скарга Манчук Ірини Клавдіївни на постанову Центральної виборчої комісії від 31 грудня 2005 року N 347 ( v0347359-05 ) "Про відмову в реєстрації кандидатів у народні депутати України, включених до виборчого списку "Всеукраїнської політичної партії - Екологія та соціальний захист".

У скарзі суб'єкт звернення просить визнати документ, зазначений у пункті 8 довідки Центральної виборчої комісії про прийняття документів для реєстрації кандидатів у народні депутати України, як "текст", передвиборною програмою, витребувати з переліку поданих до Центральної виборчої комісії документи, залучити до розгляду цієї скарги заінтересованих осіб, скасувати постанову Центральної виборчої комісії від 31 грудня 2005 року N 347 ( v0347359-05 ) "Про відмову в реєстрації кандидатів у народні депутати України, включених до виборчого списку "Всеукраїнської політичної партії - Екологія та Соціальний захист", поновити іншим способом порушені виборчі права громадян Баришовець О.М., Тирон А.І., Кудіна В.А., а також дозволити "Всеукраїнській політичній партії - Екологія та Соціальний захист" зробити виправлення в документах.

Викладені в скарзі вимоги Манчук І.К. обґрунтовує тим, що документи, подані до Центральної виборчої комісії для реєстрації кандидатів у народні депутати України відповідають вимогам Закону ( 1665-15 ) та є належно оформленими.

При розгляді цієї скарги Центральна виборча комісія виходить, зокрема, з такого. Статтею 103 Закону України "Про вибори народних депутатів України" ( 1665-15 ) (далі - Закон) встановлено, хто може бути суб'єктом звернення із скаргою, що стосується процесу виборів депутатів. Пунктом 2 вказаної статті Закону ( 1665-15 ) визначено, що суб'єктом звернення із скаргою, що стосується процесу виборів депутатів, може бути партія (блок) - суб'єкт виборчого процесу в особі її керівника (керівників блоку), представника партії (блоку) у Центральній виборчій комісії, уповноваженої особи партії (блоку) чи іншої особи, уповноваженої рішенням центрального керівного органу партії (керівного органу блоку).

Скарга на постанову Центральної виборчої комісії від 31 грудня 2005 року N 347 ( v0347359-05 ) "Про відмову в реєстрації кандидатів у народні депутати України, включених до виборчого списку "Всеукраїнської політичної партії - Екологія та Соціальний захист" надіслана, як зазначено у скарзі, "представником "Всеукраїнської політичної партії - Екологія та Соціальний захист" Манчук Іриною Клавдіївною, Посвідчення N 019 від 28.12.2005 р."

За змістом частини четвертої статті 72 Закону ( 1665-15 ) у разі втрати партією (блоком) статусу суб'єкта виборчого процесу повноваження представника партії (блоку) у Центральній виборчій комісії вважаються припиненими з моменту настання зазначених обставин.

Таким чином, Центральна виборча комісія виходить з того, що оскільки Манчук Ірина Клавдіївна на час звернення зі скаргою до Центральної виборчої комісії не мала статусу представника партії (блоку), то скаргу подано неналежним суб'єктом звернення зі скаргою. В такому разі відповідно до частини дванадцятої статті 108 Закону ( 1665-15 ) суб'єкт розгляду скарги приймає рішення про залишення скарги без розгляду.

Крім того, відповідно до частини четвертої статті 116 Закону ( 1665-15 ) скарга щодо рішення, дії чи бездіяльності Центральної виборчої комісії, члена Центральної виборчої комісії подається до Верховного Суду України.

На порушення зазначеної вимоги Закону скаргу Манчук І.К. на постанову Центральної виборчої комісії від 31 грудня 2005 року N 347 ( v0347359-05 ) було подано до Центральної виборчої комісії.

Враховуючи викладене, відповідно до частини другої статті 64, частини четвертої статті 72, пункту 2 частини першої статті 103, частин другої, п'ятої, десятої, дванадцятої статті 108, частин першої, третьої, десятої статті 110, частини четвертої статті 116 Закону України "Про вибори народних депутатів України" ( 1665-15 ), керуючись частиною другою статті 3, частиною першою статті 11, статтями 12, 13, 15, пунктом 19 статті 19 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Скаргу Манчук Ірини Клавдіївни на постанову Центральної виборчої комісії від 31 грудня 2005 року N 347 ( v0347359-05 ) "Про відмову в реєстрації кандидатів у народні депутати України, включених до виборчого списку "Всеукраїнської політичної партії - Екологія та Соціальний захист" залишити без розгляду по суті.

2. Копії цієї постанови надіслати Манчук Ірині Клавдіївні та "Всеукраїнській політичній партії - Екологія та Соціальний захист".
