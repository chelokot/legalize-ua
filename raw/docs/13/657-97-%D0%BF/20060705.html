ПОСТАНОВА від 28 червня 1997 р. N 657 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 833 ( 833-2006-п ) від 15.06.2006 }

Про внесення зміни до постанови Кабінету Міністрів України від 8 лютого 1995 р. N 108

Кабінет Міністрів України постановляє:

У пункті 12 Порядку заняття торговельною діяльністю і правил торговельного обслуговування населення, затверджених постановою Кабінету Міністрів України від 8 лютого 1995 р. N 108 ( 108-95-п ) (ЗП України, 1995 р., N 5, ст. 118), слова "націночної категорії" виключити.
