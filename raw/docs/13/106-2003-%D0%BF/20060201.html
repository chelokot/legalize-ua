Про керівника деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

Текст документа від 01.02.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 січня 2003 р. N 106 Київ

Про керівника деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

( Із змінами, внесеними згідно з Постановами КМ N 876 ( 876-2003-п ) від 04.06.2003 N 2016 ( 2016-2003-п ) від 26.12.2003 N 352 ( 352-2005-п ) від 16.05.2005 N 753 ( 753-2005-п ) від 18.08.2005 N 1231 ( 1231-2005-п ) від 21.12.2005 N 79 ( 79-2006-п ) від 01.02.2006 )

Кабінет Міністрів України постановляє:

1. Затвердити Віце-прем'єр-міністра України Табачника Дмитра Володимировича:

головою Національної ради з питань безпечної життєдіяльності населення;

головою Національної координаційної ради боротьби з наркоманією при Кабінеті Міністрів України;

головою Національної ради по туризму;

( Абзац п'ятий втратив чинність на підставі Постанови КМ N 79 ( 79-2006-п ) від 01.02.2006 )

( Абзац шостий пункту 1 втратив чинність на підставі Постанови КМ N 2016 ( 2016-2003-п ) від 26.12.2003 )

( Абзац сьомий пункту 1 втратив чинність на підставі Постанови N 753 ( 753-2005-п ) від 18.08.2005 )

( Абзац восьмий пункту 1 втратив чинність на підставі Постанови N 753 ( 753-2005-п ) від 18.08.2005 )

( Постанова втратила чинність в частині, що стосується Міжвідомчої комісії з проблем "нацистського золота" та компенсаційних виплат жертвам нацизму на підставі Постанови КМ N 876 ( 876-2003-п ) від 04.06.2003 )

( Абзац десятий пункту 1 втратив чинність на підставі Постанови N 753 ( 753-2005-п ) від 18.08.2005 )

головою Комісії з питань гуманітарної допомоги при Кабінеті Міністрів України;

головою Міжвідомчої комісії з питань охорони дитинства;

головою Міжвідомчої комісії по боротьбі з туберкульозом;

( Абзац чотирнадцятий пункту 1 втратив чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

головою Комісії з встановлення пенсій за особливі заслуги перед Україною при Кабінеті Міністрів України;

головою Комісії з організації діяльності технологічних парків та інноваційних структур інших типів:

головою Міжвідомчої ради запитань захисту прав споживачів;

головою Міжвідомчої комісії з підготовки проекту Концепції розвитку санаторно-курортної галузі та здійснення заходів щодо захисту майнових інтересів держави під час приватизації оздоровчих закладів;

головою Координаційного центру з питань здійснення пенсійної реформи;

( Абзац двадцятий пункту 1 втратив чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

( Абзац двадцять перший пункту 1 втратив чинність на підставі Постанови N 753 ( 753-2005-п ) від 18.08.2005 )

( Абзац двадцять другий пункту 1 втратив чинність на підставі Постанови N 753 ( 753-2005-п ) від 18.08.2005 )

головою Координаційного комітету з підготовки та забезпечення участі України у Всесвітній виставці "Експо 2005" (Японія);

головою Міжгалузевої ради з професійно-технічної освіти;

головою Міжвідомчої координаційної ради з питань співробітництва з українською діаспорою;

головою Комітету з присудження Премії Кабінету Міністрів України за внесок молоді у розбудову держави;

головою наглядової ради з питань реалізації спільного із Світовим банком проекту "Контроль за туберкульозом та ВІЛ/СНІДом в Україні";

головою Координаційного центру з питань впровадження загальнообов'язкового державного соціального медичного страхування;

головою наглядової ради Українського фонду соціальних інвестицій;

головою спостережної ради Українського національного фонду "Взаєморозуміння і примирення" при Кабінеті Міністрів України;

( Абзац тридцять перший пункту 1 втратив чинність на підставі Постанови КМ N 352 ( 352-2005-п ) від 16.05.2005 )

головою спостережної ради Українського фонду боротьби з ВІЛ-інфекцією і СНІДом.

2. Увільнити Жулинського Миколу Григоровича, Рогового Василя Васильовича, Саханя Івана Яковича, Семиноженка Володимира Петровича, Смолія Валерія Андрійовича від обов'язків керівників органів, зазначених у пункті 1 цієї постанови.
