Текст документа від 10.06.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 червня 2009 р. N 570 Київ

Про доповнення постанов Кабінету Міністрів України від 29 березня 2004 р. N 399 і від 9 жовтня 2006 р. N 1404

Кабінет Міністрів України постановляє:

1. Назву і пункт 1 постанови Кабінету Міністрів України від 29 березня 2004 р. N 399 ( 399-2004-п ) "Деякі питання здійснення попередньої оплати робіт (послуг) замовниками будівництва магістральних електричних мереж, атомних, гідроакумулюючих та вітрових електростанцій" (Офіційний вісник України, 2004 р., N 13, ст. 891; 2008 р., N 95, ст. 3142) після слова "будівництва" доповнити словами "підприємств уранодобувної промисловості,".

2. Підпункт 7 пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752, N 44, ст. 2946, N 51, ст. 3406; 2007 р., N 43, ст. 1715, N 53, ст. 2157, N 56, ст. 2252, N 59, ст. 2344, ст. 2351, N 91, ст. 3336; 2008 р., N 9, ст. 220, N 63, ст. 2146, N 69, ст. 2322, N 70, ст. 2355, N 81, ст. 2737, N 90, ст. 3004, N 95, ст. 3142; 2009 р., N 5, ст. 128) після слів "електричних мереж" доповнити словами ", а також технологічного та гірничо-шахтного обладнання для будівництва підприємств уранодобувної промисловості".

Прем'єр-міністр України Ю.ТИМОШЕНКО
