КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 січня 2007 р. N 22 Київ

Про приєднання до Угоди про спільне фінансування Постійного секретаріату Міжурядової комісії ТРАСЕКА (ПС МУК ТРАСЕКА) між урядами Сторін Основної багатосторонньої угоди про міжнародний транспорт щодо розвитку коридору Європа - Кавказ - Азія

{ Із змінами, внесеними згідно з Постановами КМ N 474 ( 474-2011-п ) від 11.05.2011 N 416 ( 416-2023-п ) від 28.04.2023 }

Кабінет Міністрів України постановляє:

1. Приєднатися до Угоди про спільне фінансування Постійного секретаріату Міжурядової комісії ТРАСЕКА (ПС МУК ТРАСЕКА) між урядами Сторін Основної багатосторонньої угоди про міжнародний транспорт щодо розвитку коридору Європа - Кавказ - Азія, підписаної в м. Баку 21 квітня 2005 р., з таким застереженням:

Українська Сторона залишає за собою право здійснення сплати членського внеску до бюджету Постійного секретаріату Міжурядової комісії ТРАСЕКА в межах видатків, передбачених актами законодавства України.

2. Міністерству розвитку громад, територій та інфраструктури забезпечити щорічну сплату членського внеску до бюджету Постійного секретаріату Міжурядової комісії ТРАСЕКА за рахунок коштів, передбачених Міністерству розвитку громад, територій та інфраструктури в державному бюджеті на відповідний рік, та інших джерел.

{ Пункт 2 із змінами, внесеними згідно з Постановами КМ N 474 ( 474-2011-п ) від 11.05.2011, N 416 ( 416-2023-п ) від 28.04.2023 }

3. Міністерству закордонних справ надіслати депозитарію повідомлення про приєднання до зазначеної Угоди.
