ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

ПОСТАНОВА

N 234 від 05.02.2002 м. Київ

( Постанова втратила чинність на підставі Постанови Центрвиборчкому N 279 ( v0279359-02 ) від 11.02.2002 )

Про реєстрацію представника політичної партії "Жінки України" в Центральній виборчій комісії з правом дорадчого голосу

Розглянувши заяву політичної партії "Жінки України" про реєстрацію її представника в Центральній виборчій комісії з правом дорадчого голосу та документи, що додаються до неї, відповідно до частин першої, другої, третьої, четвертої статті 57 Закону України "Про вибори народних депутатів України" ( 2766-14 ) та керуючись статтею 11 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ), Центральна виборча комісія постановляє:

1. Зареєструвати представником політичної партії "Жінки України" в Центральній виборчій комісії з правом дорадчого голосу Супруненко Анну Петрівну.

2. Видати представнику політичної партії "Жінки України" в Центральній виборчій комісії і правом дорадчого голосу Супруненко Анні Петрівні посвідчення встановленого зразка.
