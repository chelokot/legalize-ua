УКАЗ ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

Про відділи і управління виконавчих комітетів обласних, районних, міських, районних у містах Рад народних депутатів Української РСР

( Відомості Верховної Ради (ВВР), 1982, N 40, ст. 657 )

( Указ затверджено Законом УРСР N 4399-X ( 4399-10 ) від 30.11.82, ВВР, 1982, N 50, ст. 834 )

( Із змінами, внесеними згідно з Указами Президії ВР УРСР N 8563-X ( 8563-10 ) від 07.03.85, ВВР, 1985, N 12, ст. 264 N 2277-XI ( 2277-11 ) від 27.05.86, ВВР, 1986, N 23, ст. 457 N 4453-XI ( 4453-11 ) від 21.08.87, ВВР, 1987, N 35, ст. 675 N 9021-XI ( 9021-11 ) від 30.03.90, ВВР, 1990, N 15, ст. 235 - набуває чинності з 01.04.90 )

Президія Верховної Ради Української РСР постановляє:

1. Відповідно до статті 138 Конституції Української РСР ( 888-09 ) встановити Перелік відділів і управлінь виконавчих комітетів обласних, районних, міських, районних у містах Рад народних депутатів Української РСР, що утворюються відповідними Радами народних депутатів, згідно з додатком.

Київська і Севастопольська міські Ради народних депутатів утворюють відділи і управління виконавчих комітетів стосовно до розділу I цього Переліку.

2. З урахуванням особливостей області, району, міста, району в місті можуть утворюватись й інші відділи і управління виконавчих комітетів відповідних Рад народних депутатів, не передбачені Переліком, якщо інше не встановлено законодавством Союзу РСР:

за згодою Ради Міністрів Української РСР - відділи і управління виконавчих комітетів обласних, Київської і Севастопольської міських Рад народних депутатів;

за згодою виконавчого комітету обласної, Київської і Севастопольської міських Рад народних депутатів - відділи і управління виконавчих комітетів районних, міських, районних у містах Рад народних депутатів.

3. Відділи і управління виконавчих комітетів обласних, районних, міських, районних у містах Рад народних депутатів, створені до видання цього Указу і не передбачені встановленим Переліком, діють відповідно до раніше прийнятих Радами народних депутатів рішень про їх утворення.

4. Визнати такою, що втратила чинність, частину сьому статті 19 Закону Української РСР від 19 грудня 1978 року "Про Раду Міністрів Української РСР" ( 4157-09 ) (Відомості Верховної Ради УРСР, 1979 р., N 1, ст. 7).
