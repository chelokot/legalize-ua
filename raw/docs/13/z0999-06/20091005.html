Стан: Втратив чинність

ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

01.08.2006 N 635

Зареєстровано в Міністерстві юстиції України 22 серпня 2006 р. за N 999/12873

{ Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 989 ( z0903-09 ) від 03.09.2009 }

Про внесення змін до рішення Державної комісії з цінних паперів та фондового ринку від 04.09.2003 N 364 "Про затвердження Положення про державну реєстрацію фондових бірж та торговельно-інформаційних систем"

Відповідно до пункту 3 статті 21 Закону України "Про цінні папери та фондовий ринок" ( 3480-15 ) Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Унести до рішення Державної комісії з цінних паперів та фондового ринку від 04.09.2003 N 364 ( z1083-03 ) "Про затвердження Положення про державну реєстрацію фондових бірж та торговельно-інформаційних систем", зареєстрованого в Міністерстві юстиції України 26.11.2003 за N 1083/8404, такі зміни:

1.1. Заголовок викласти в такій редакції: "Про затвердження змін до Положення про реєстрацію фондових бірж та торговельно-інформаційних систем і регулювання їх діяльності".

1.2. Пункт 1 виключити. У зв'язку з цим пункти 2-6 уважати відповідно пунктами 1-5.

2. Визнати таким, що втратило чинність, Положення про державну реєстрацію фондових бірж та торговельно-інформаційних систем ( z1083-03 ), затверджене зазначеним рішенням, зареєстроване в Міністерстві юстиції України 26.11.2003 за N 1083/8404.

3. Фондовим біржам та торговельно-інформаційним системам протягом двох місяців з дати набрання чинності цим рішенням подати до Державної комісії з цінних паперів та фондового ринку бланки Свідоцтв про державну реєстрацію (перереєстрацію) фондової біржі або торговельно-інформаційної системи - юридичної особи для визнання їх недійсними.

4. Керівнику апарату Державної комісії з цінних паперів та фондового ринку М.Непрану забезпечити:

подання цього рішення до Міністерства юстиції України;

опублікування цього рішення відповідно до законодавства.

5. Рішення набирає чинності відповідно до законодавства України.

6. Контроль за виконанням цього рішення покласти на Керівника апарату Державної комісії з цінних паперів та фондового ринку М.Непрана.
