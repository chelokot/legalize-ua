Про внесення змін до деяких актів Кабінету Міністрів України з питань національностей та релігій

Стан: Чинний

Ідентифікатор: 960-2007-п

Текст документа від 19.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 липня 2007 р. N 960 Київ

Про внесення змін до деяких актів Кабінету Міністрів України з питань національностей та релігій

{ Із змінами, внесеними згідно з Постановою КМ N 207 ( 207-2008-п ) від 19.03.2008 }

Кабінет Міністрів України постановляє:

Внести до актів Кабінету Міністрів України з питань національностей та релігій зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 25 липня 2007 р. N 960

ЗМІНИ, що вносяться до актів Кабінету Міністрів України з питань національностей та релігій

1. У Положенні про Комісію у справах осіб, депортованих за національною ознакою, затвердженому постановою Кабінету Міністрів України від 13 серпня 1999 р. N 1493 ( 1493-99-п ) "Про утворення Комісії у справах осіб, депортованих за національною ознакою" (Офіційний вісник України, 1999 р., N 33, ст. 1733; 2004 р., N 30, ст. 2009; 2006 р., N 40, ст. 2683):

у пункті 10 слова "Державного комітету у справах національностей та міграції" замінити словами "Державного комітету у справах національностей та релігій";

у пункті 12 слово "Держкомнацміграції" замінити словом "Держкомнацрелігій".

2. У тексті Положення про проїзний документ біженця для виїзду за кордон, затвердженого постановою Кабінету Міністрів України від 11 жовтня 2002 р. N 1526 ( 1526-2002-п ) (Офіційний вісник України, 2002 р., N 42, ст. 1939), слово "Держкомнацміграції" замінити словом "Держкомнацрелігій".

3. У тексті Положення про посвідчення біженця, затвердженого постановою Кабінету Міністрів України від 11 жовтня 2002 р. N 1527 ( 1527-2002-п ) (Офіційний вісник України, 2002 р., N 42, ст. 1940; 2003 р., N 37, ст. 1981), слово "Держкомнацміграції" замінити словом "Держкомнацрелігій".

4. У постановляючій частині постанови Кабінету Міністрів України від 25 грудня 2002 р. N 2005 ( 2005-2002-п ) "Про голову Української частини міжурядових комісій з питань національних меншин" - із змінами, внесеними постановою Кабінету Міністрів України від 15 лютого 2006 р. N 147 ( 147-2006-п ) (Офіційний вісник України, 2006 р., N 7, ст. 360), слова "Голову Державного комітету у справах національностей та міграції" замінити словами "Голову Державного комітету у справах національностей та релігій".

{ Пункт 5 втратив чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

6. У тексті Порядку забезпечення депортованих осіб та членів їх сімей, які повернулися в Україну, житлом, збудованим або придбаним за рахунок бюджетних коштів, затвердженого постановою Кабінету Міністрів України від 17 грудня 2003 р. N 1952 ( 1952-2003-п ) (Офіційний вісник України, 2003 р., N 51, ст. 2693), слово "Держкомнацміграції" замінити словом "Держкомнацрелігій".

7. У постанові Кабінету Міністрів України від 13 травня 2004 р. N 626 ( 626-2004-п ) "Про заходи щодо задоволення соціальних потреб депортованих кримських татар та осіб інших національностей, які повернулися в Україну на постійне проживання" (Офіційний вісник України, 2004 р., N 19, ст. 1338):

у пункті 2 постанови ( 626-2004-п ) слова "Державному комітетові у справах національностей та міграції" замінити словами "Державному комітетові у справах національностей та релігій";

у пункті 4 Порядку ( 626-2004-п ) постачання питної води у місця компактного проживання депортованих кримських татар та осіб інших національностей в Автономній Республіці Крим, затвердженого зазначеною постановою, слово "Держкомнацміграції" замінити словом "Держкомнацрелігій".

8. У постанові Кабінету Міністрів України від 17 листопада 2004 р. N 1573 ( 1573-2004-п ) "Про затвердження Програми облаштування осіб з числа закордонних українців, що повертаються в Україну, на період до 2010 року" (Офіційний вісник України, 2004 р., N 46, ст. 3056):

в абзаці другому пункту 1 і пункті 2 постанови ( 1573-2004-п ) слова "Державний комітет у справах національностей та міграції" у всіх відмінках замінити словами "Державний комітет у справах національностей та релігій" у відповідному відмінку;

у тексті Програми ( 1573-2004-п ), затвердженої зазначеною постановою, слово "Держкомнацміграції" замінити словом "Держкомнацрелігій".

9. У постанові Кабінету Міністрів України від 11 травня 2006 р. N 637 ( 637-2006-п ) "Про затвердження Програми розселення та облаштування депортованих кримських татар і осіб інших національностей, що повернулися на проживання в Україну, їх адаптації та інтеграції в українське суспільство на період до 2010 року" (Офіційний вісник України, 2006 р., N 20, ст. 1456):

у пунктах 2 і 3 постанови ( 637-2006-п ) слова "Державному комітетові у справах національностей та міграції" замінити словами "Державному комітетові у справах національностей та релігій";

у тексті Програми ( 637-2006-п ), затвердженої зазначеною постановою, слово "Держкомнацміграції" замінити словом "Держкомнацрелігій".

10. У пунктах 1, 4, 6, 7, 9 і 17 графи "Відповідальні за виконання" додатка до Державної програми співпраці із закордонними українцями на період до 2010 року, затвердженої постановою Кабінету Міністрів України від 26 липня 2006 р. N 1034 ( 1034-2006-п ) (Офіційний вісник України, 2006 р., N 31, ст. 2209), слово "Держкомнацміграції" замінити словом "Держкомнацрелігій".
