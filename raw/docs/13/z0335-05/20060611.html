ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

02.03.2005 N 80

Зареєстровано в Міністерстві юстиції України 28 березня 2005 р. за N 335/10615

{ Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку

N 293 ( z0650-06 ) від 12.05.2006 }

Про порядок застосування пункту 1 рішення Державної комісії з цінних паперів та фондового ринку від 11 лютого 2003 року N 62 "Щодо упорядкування депозитарної діяльності" ( z0168-03 )

Відповідно до Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ), частини 1 статті 15 Закону України "Про Національну депозитарну систему та особливості електронного обігу цінних паперів в Україні" ( 710/97-ВР ) та з метою захисту прав учасників інвестиційних фондів та взаємних фондів інвестиційних компаній, створених відповідно до Положення про інвестиційні фонди та інвестиційні компанії, затвердженого Указом Президента України від 19.02.94 N 55 ( 55/94 ), недопущення порушень у разі припинення їх діяльності, передбаченої чинним законодавством, Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Визначити, що обслуговування обігу цінних паперів у Національній депозитарній системі здійснюється виключно за умови наявності у відповідних цінних паперах міжнародного ідентифікаційного номера (коду ISIN), призначеного Національним депозитарієм України, за винятком операцій з цінними паперами, пов'язаних з припиненням діяльності інвестиційних фондів та взаємних фондів інвестиційних компаній, які були створені відповідно до Положення про інвестиційні фонди та інвестиційні компанії, затвердженого Указом Президента України від 19.02.94 N 55 ( 55/94 ).

2. Керівнику апарату Державної комісії з цінних паперів та фондового ринку (далі - Керівник апарату Комісії) забезпечити:

подання на державну реєстрацію цього рішення до Міністерства юстиції України;

опублікування цього рішення відповідно до чинного законодавства.

3. Рішення набирає чинності відповідно до чинного законодавства.

4. Контроль за виконанням цього рішення покласти на Керівника апарату Комісії.

Голова Комісії А.Балюк
