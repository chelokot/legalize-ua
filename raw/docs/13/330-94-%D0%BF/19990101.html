Кабінет Міністрів України; Постанова від 23.05.1994 № 330

Про підвищення розміру державної допомоги дітям, інфікованим вірусом імунодефіциту людини або хворим на СНІД

Стан: Втратив чинність

Ідентифікатор: 330-94-п

Текст документа від 01.01.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 травня 1994 р. N 330 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1051 ( 1051-98-п ) від 10.07.98 )

Про підвищення розміру державної допомоги дітям, інфікованим вірусом імунодефіциту людини або хворим на СНІД

( Із змінами, внесеними згідно з Постановою КМ N 356 ( 356-95-п ) від 23.05.95 )

На виконання постанови Президії Верховної Ради України від 22 квітня 1994 р. N 4089-12 Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. З метою посилення соціального захисту дітей віком до 16 років, інфікованим вірусом імунодефіциту людини або хворих на СНІД, виплачувати їм щомісячно державну допомогу в розмірі одного неоподатковуваного мінімуму доходів громадян. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 356 ( 356-95-п ) від 23.05.95 )

2. Національному комітету боротьби із захворюванням на СНІД провадити додаткові витрати, пов'язані із зазначеними виплатами, за рахунок асигнувань, передбачених в державному бюджеті на фінансування Національної програми профілактики СНІДу в Україні.
