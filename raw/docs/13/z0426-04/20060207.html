Про внесення змін до наказу Міністерства праці та соціальної політики України від 25.05.2001 N 240

На виконання постанови Кабінету Міністрів України від 11 лютого 2004 року N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 25.05.2001 N 240 ( z0479-01 ) "Про впорядкування умов оплати праці працівників притулків для неповнолітніх служб у справах неповнолітніх", зареєстрованого в Міністерстві юстиції України 06.06.2001 за N 479/5670 (зі змінами), виклавши додатки 1-5 у новій редакції (додаються).

2. Ці зміни застосовуються з 1 березня 2004 року.
