Про утворення Тимчасової слідчої комісії Верховної Ради України з питань перевірки ситуації із забезпеченням природним газом українських споживачів, розрахунками за поставлений природний газ та можливими порушеннями діючого законодавства на енергетичному ринку України

Стан: Чинний

Ідентифікатор: 72-16

Текст документа від 20.02.2007:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про утворення Тимчасової слідчої комісії Верховної Ради України з питань перевірки ситуації із забезпеченням природним газом українських споживачів, розрахунками за поставлений природний газ та можливими порушеннями діючого законодавства на енергетичному ринку України

( Відомості Верховної Ради України (ВВР), 2006, N 41, ст.364 )

{ Із змінами, внесеними згідно з Постановою ВР N 85-V ( 85-16 ) від 04.08.2006, ВВР, 2006, N 41, ст.373 }

{ Додатково див. Постанову ВР N 296-V ( 296-16 ) від 02.11.2006, ВВР, 2006, N 50, ст.511 }

{ Із змінами, внесеними згідно з Постановами ВР N 674-V ( 674-16 ) від 20.02.2007, ВВР, 2007, N 16, ст.221 N 675-V ( 675-16 ) від 20.02.2007, ВВР, 2007, N 16, ст.222 }

Відповідно до статті 89 Конституції України ( 254к/96-ВР ), статті 82 Регламенту Верховної Ради України ( 3547-15 ) Верховна Рада України постановляє:

1. Утворити Тимчасову слідчу комісію Верховної Ради України з питань перевірки ситуації із забезпеченням природним газом українських споживачів, розрахунками за поставлений природний газ та можливими порушеннями діючого законодавства на енергетичному ринку України (далі - Тимчасова слідча комісія).

2. Тимчасовій слідчій комісії провести перевірку обґрунтування списання боргів ЗАТ "Єдині енергетичні системи. Україна" та господарської діяльності "Українського газотранспортного консорціуму", які були посередниками на ринку газу.

{ Постанову доповнено пунктом згідно з Постановою ВР N 674-V ( 674-16 ) від 20.02.2007 }

3. Обрати головою Тимчасової слідчої комісії народного депутата України Александровську Аллу Олександрівну, заступником голови - народного депутата України Кисельова Василя Олексійовича. { Пункт із змінами, внесеними згідно з Постановою ВР N 674-V ( 674-16 ) від 20.02.2007 }

5. Депутатським фракціям у Верховній Раді України, які не внесли пропозиції щодо своїх представників у складі Тимчасової слідчої комісії, у дводенний строк після прийняття цієї Постанови подати пропозиції щодо своїх представників у складі Тимчасової слідчої комісії виходячи із забезпечення такого представництва в її складі: один представник від тридцяти народних депутатів України, але не менш як по одному народному депутату України від кожної депутатської фракції.

6. Матеріально-технічне, кадрове, інформаційне та організаційне забезпечення діяльності Тимчасової слідчої комісії покласти на апарат Верховної Ради України.

7. Генеральній прокуратурі України, Службі безпеки України, Фонду державного майна України забезпечити додержання законів України "Про статус народного депутата України" ( 2790-12 ), "Про комітети Верховної Ради України" ( 116/95-ВР ), "Про державну таємницю" ( 3855-12 ) щодо доступу членів Тимчасової слідчої комісії до інформації, матеріалів і документів, у тому числі договорів, що стосуються предмета діяльності Тимчасової слідчої комісії та можливих ознак корупції в діях посадових і службових осіб.

8. Визначити термін діяльності Тимчасової слідчої комісії - один рік з дня прийняття цієї Постанови.

{ Пункт 8 в редакції Постанови ВР N 674-V ( 674-16 ) від 20.02.2007 }

9. Звіт Тимчасової слідчої комісії про виконану роботу заслухати не пізніше місячного терміну з дня прийняття цієї Постанови.

{ Пункт 9 в редакції Постанови ВР N 674-V ( 674-16 ) від 20.02.2007 }

10. Ця Постанова набирає чинності з дня її прийняття.
