Про Міністерство України у справах сім'ї, дітей та молоді

Стан: Чинний

Ідентифікатор: 166/2004

Текст документа від 09.12.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Міністерство України у справах сім'ї, дітей та молоді

{ Із змінами, внесеними згідно з Указом Президента N 1085/2010 ( 1085/2010 ) від 09.12.2010 }

З метою підвищення ефективності реалізації основних завдань державної політики України з питань сім'ї, дітей та молоді, конституційного обов'язку держави щодо охорони сім'ї, дитинства, материнства і батьківства, забезпечення соціального становлення і розвитку молоді та відповідно до пункту 15 статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Перетворити Державний комітет України у справах сім'ї та молоді у Міністерство України у справах сім'ї, дітей та молоді.

2. У зв'язку з цим внести до Указів Президента України такі зміни:

{ Пункт "а" статті 2 втратив чинність на підставі Указу Президента N 1085/2010 ( 1085/2010 ) від 09.12.2010 }

б) статтю 1 Указу Президента України від 15 грудня 1999 року N 1574 ( 1574/99 ) "Про склад Кабінету Міністрів України" (зі змінами, внесеними Указами від 29 травня 2001 року N 345 ( 345/2001 ), від 5 червня 2001 року N 405 ( 405/2001 ), від 21 серпня 2001 року N 724 ( 724/2001 ), від 25 березня 2003 року N 267 ( 267/2003 ), від 3 червня 2003 року N 464 ( 464/2003 ) після абзацу "Міністр транспорту України" доповнити абзацом "Міністр України у справах сім'ї, дітей та молоді".

3. Кабінету Міністрів України:

подати в двомісячний строк у встановленому порядку проект Положення про Міністерство України у справах сім'ї, дітей та молоді;

затвердити граничну чисельність працівників Міністерства України у справах сім'ї, дітей та молоді та вирішити питання, пов'язані із забезпеченням його функціонування;

подати пропозиції щодо приведення актів Президента України у відповідність із цим Указом;

привести свої рішення у відповідність із цим Указом.

Президент України Л.КУЧМА
