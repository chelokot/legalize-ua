Кабінет Міністрів України; Постанова, Порядок від 19.05.2006 № 698

Про затвердження Порядку повернення безвідсоткових бюджетних позик, наданих у 2005 році підприємствам та організаціям вугільної промисловості (крім вугледобувних) для погашення заборгованості з виплати заробітної плати

Стан: Чинний

Ідентифікатор: 698-2006-п

Текст документа від 20.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 травня 2006 р. N 698 Київ

Про затвердження Порядку повернення у 2009 році безвідсоткових бюджетних позик, наданих у 2005 році підприємствам та організаціям вугільної промисловості (крім вугледобувних) для погашення заборгованості з виплати заробітної плати

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 456 ( 456-2009-п ) від 13.05.2009 }

{ Із змінами, внесеними згідно з Постановами КМ N 637 ( 637-2007-п ) від 20.04.2007 N 507 ( 507-2008-п ) від 04.06.2008 N 456 ( 456-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє:

1. Затвердити Порядок повернення у 2009 році безвідсоткових бюджетних позик, наданих у 2005 році підприємствам та організаціям вугільної промисловості (крім вугледобувних) для погашення заборгованості з виплати заробітної плати, що додається.

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 637 ( 637-2007-п ) від 20.04.2007, N 507 ( 507-2008-п ) від 04.06.2008, N 456 ( 456-2009-п ) від 13.05.2009 }

2. Міністерству вугільної промисловості забезпечити вжиття заходів до своєчасного повернення у повному обсязі підприємствами та організаціями вугільної промисловості (крім вугледобувних) бюджетних позик, наданих для погашення заборгованості, яка утворилася на 1 квітня 2005 р. з виплати заробітної плати.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 37

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 19 травня 2006 р. N 698

ПОРЯДОК повернення у 2009 році безвідсоткових бюджетних позик, наданих у 2005 році підприємствам та організаціям вугільної промисловості (крім вугледобувних) для погашення заборгованості з виплати заробітної плати

{ Назва Порядку із змінами, внесеними згідно з Постановами КМ N 637 ( 637-2007-п ) від 20.04.2007, N 507 ( 507-2008-п ) від 04.06.2008, N 456 ( 456-2009-п ) від 13.05.2009 }

1. Цей Порядок визначає механізм повернення у 2009 році до державного бюджету ( 835-17 ) безвідсоткових бюджетних позик, наданих у 2005 році підприємствам та організаціям вугільної промисловості (далі - позичальники) для погашення заборгованості з виплати заробітної плати відповідно до Порядку надання безвідсоткової бюджетної позики для підприємств та організацій вугільної промисловості (крім вугледобувних) на погашення заборгованості, яка утворилася на 1 квітня 2005 р. з виплати заробітної плати, затвердженого постановою Кабінету Міністрів України від 22 серпня 2005 р. N 794 ( 794-2005-п ) (Офіційний вісник України, 2005 р., N 34, ст. 2068).

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 637 ( 637-2007-п ) від 20.04.2007, N 507 ( 507-2008-п ) від 04.06.2008, N 456 ( 456-2009-п ) від 13.05.2009 }

2. Позичальники перераховують кошти для погашення зазначеної безвідсоткової бюджетної позики на рахунок Мінвуглепрому, відкритий у Державному казначействі за балансовим рахунком 3711 "Інші рахунки клієнтів Державного казначейства", згідно з планом рахунків бухгалтерського обліку виконання державного та місцевих бюджетів, затвердженим Державним казначейством.

3. Після внесення на рахунок Мінвуглепрому, відкритий за балансовим рахунком 3711, кошти протягом трьох робочих днів на підставі платіжного доручення Міністерства перераховуються на рахунок, відкритий за балансовим рахунком 3123 "Рахунок для зарахування до спеціального фонду державного бюджету повернення бюджетних кредитів" відповідно до пункту 8 статті 33 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ).

{ Пункт 3 в редакції Постанови КМ N 507 ( 507-2008-п ) від 04.06.2008; із змінами, внесеними згідно з Постановою КМ N 456 ( 456-2009-п ) від 13.05.2009 }

{ Пункт 4 виключено на підставі Постанови КМ N 507 ( 507-2008-п ) від 04.06.2008 }

5. Кошти, зараховані на рахунок, відкритий за балансовим рахунком 3123, є джерелом формування спеціального фонду державного бюджету в частині кредитування та спрямовуються на заходи, передбачені пунктом 6 статті 34 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ).

{ Пункт 5 із змінами, внесеними згідно з Постановами КМ N 637 ( 637-2007-п ) від 20.04.2007, N 507 ( 507-2008-п ) від 04.06.2008, N 456 ( 456-2009-п ) від 13.05.2009 }

6. Пеня за несвоєчасне повернення позичальниками бюджетної позики перераховується на рахунок, відкритий в Державному казначействі за балансовим рахунком 3111 "Надходження до загального фонду державного бюджету", кодом класифікації доходів 24060300 "Інші надходження", символом звітності 115.

7. Мінвуглепром подає щомісяця до 15 числа наступного періоду Мінфіну звіт про повернення бюджетної позики у розрізі підприємств.
