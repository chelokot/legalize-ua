Про Уповноваженого Уряду України в Українсько-Словацькій комісії по прикордонних водах та Уповноваженого Кабінету Міністрів України з питань співпраці на прикордонних водах

Стан: Втратив чинність

Ідентифікатор: 599-2003-п

Текст документа від 05.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 квітня 2003 р. N 599 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1347 ( 1347-2011-п ) від 28.12.2011 }

Про Уповноваженого Уряду України в Українсько-Словацькій комісії по прикордонних водах та Уповноваженого Кабінету Міністрів України з питань співпраці на прикордонних водах

Кабінет Міністрів України постановляє:

На часткову зміну постанов Кабінету Міністрів України від 18 серпня 1994 р. N 569 ( 569-94-п ) та від 29 квітня 1999 р. N 749 ( 749-99-п ) затвердити першого заступника Голови Державного комітету по водному господарству Гадзала Ярослава Михайловича Уповноваженим Уряду України в Українсько-Словацькій комісії по прикордонних водах та Уповноваженим Кабінету Міністрів України з питань співпраці на прикордонних водах, увільнивши від цих обов'язків відповідно Хорєва Віктора Максимовича та Вельбика Анатолія Сергійовича.

Прем'єр-міністр України В.ЯНУКОВИЧ
