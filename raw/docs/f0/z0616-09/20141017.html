МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

28.05.2009 N 367

Зареєстровано в Міністерстві юстиції України 13 липня 2009 р. за N 616/16632

{ Наказ втратив чинність на підставі Наказу Міністерства аграрної політики та продовольства N 343 ( z1159-14 ) від 10.09.2014 }

Про внесення змін до Положення про порядок справляння і використання коштів, одержаних за виконання робіт, пов'язаних із сертифікацією зерна, продуктів його переробки, насіння олійних культур випробувальними лабораторіями державної хлібної інспекції Автономної Республіки Крим та обласних державних хлібних інспекцій

Відповідно до Порядку участі центральних органів виконавчої влади у діяльності міжнародних організацій, членом яких є Україна, затвердженого постановою Кабінету Міністрів України від 13.09.2002 N 1371 ( 1371-2002-п ), НАКАЗУЮ:

1. Пункт 4 Положення про порядок справляння і використання коштів, одержаних за виконання робіт, пов'язаних із сертифікацією зерна, продуктів його переробки, насіння олійних культур випробувальними лабораторіями державної хлібної інспекції Автономної Республіки Крим та обласних державних хлібних інспекцій затвердженого наказом Міністерства агропромислового комплексу України від 18.01.99 N 9 ( z0286-99 ), зареєстрованого в Міністерстві юстиції України 06.05.99 за N 286/3579, доповнити новим підпунктом 4.5 такого змісту:

"4.5. Кошти спеціального фонду можуть використовуватись на сплату внесків до бюджетів міжнародних організацій, представником України в яких є Міністерство аграрної політики України".

2. Державній інспекції з контролю якості сільськогосподарської продукції та моніторингу її ринку (Мельник В.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності з дня його офіційного опублікування.

4. Контроль за виконанням наказу покласти на заступника Міністра Демчака І.М.

Міністр Ю.Ф.Мельник
