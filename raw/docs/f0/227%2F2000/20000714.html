Президент України; Указ від 11.02.2000 № 227/2000

Про Голову Національної ради з питань статистики при Президентові України

Стан: Втратив чинність

Ідентифікатор: 227/2000

Текст документа від 14.07.2000:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 889/2000 ( 889/2000 ) від 14.07.2000 )

Про Голову Національної ради з питань статистики при Президентові України

1. На зміну статті 3 Указу Президента України від 14 січня 1997 року N 17 ( 17/97 ) "Про внесення змін до деяких Указів Президента України" затвердити ЄХАНУРОВА Юрія Івановича - Першого віце-прем'єр-міністра України - Головою Національної ради з питань статистики при Президентові України, звільнивши від цих обов'язків Тігіпка С.Л.

2. Визнати таким, що втратив чинність, Указ Президента України від 13 травня 1997 року N 429 ( 429/97 ) "Про внесення змін до Указу Президента України від 14 січня 1997 року N 17".

Президент України Л.КУЧМА
