КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 березня 1999 р. N 369 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 390 ( 390-2013-п ) від 29.05.2013 }

Про внесення змін і доповнень до деяких постанов Кабінету Міністрів України

( Із змінами, внесеними згідно з Постановою КМ N 1089 ( 1089-2003-п ) від 17.07.2003 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 1089 ( 1089-2003-п ) від 17.07.2003 )

2. Доповнити розділ "Для повітряного сполучення" переліку пунктів пропуску на митному кордоні України, через які ввозяться з метою імпорту та транзиту, а також вивозяться алкогольні напої та тютюнові вироби за кодами згідно з ГС 22.03 00, 22.04-22.08, 24.02 10000, 24.02 20000, 24.03 10000, 24.03 99100, на які встановлено акцизний збір, затвердженого постановою Кабінету Міністрів України від 12 серпня 1996 р. N 938 ( 938-96-п ) "Про подальше посилення контролю за ввезенням, вивезенням та переміщенням транзитом через територію України алкогольних напоїв і тютюнових виробів, на які встановлено акцизний збір" (ЗП України, 1996 р., N 16, ст. 443, N 20, ст. 566; Офіційний вісник України, 1997 р., число 5, с. 143, число 18, с. 106, число 28, с. 111, число 52, с. 154; 1998 р., N 1, ст.11, N 42, ст. 1550), із доповненнями, внесеними постановами Кабінету Міністрів України від 11 грудня 1996 р. N 1473 ( 1473-96-п ) та від 12 січня 1999 р. N 29 ( 29-99-п ), словами "аеропорти Бориспіль, Сімферополь, Одеса, Харків, Львів, Донецьк, Дніпропетровськ (тільки для переміщення товарів, призначених для споживання пасажирами та екіпажем суден міжнародного класу, і зразків товарів на міжнародні виставки)".
