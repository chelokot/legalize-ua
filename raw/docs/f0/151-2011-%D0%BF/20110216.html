Кабінет Міністрів України; Постанова, Порядок від 16.02.2011 № 151

Про затвердження Порядку використання коштів, передбачених у державному бюджеті для здійснення заходів з імплементації Бюджетного та Податкового кодексів України

Стан: Чинний

Ідентифікатор: 151-2011-п

Текст документа від 16.02.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 лютого 2011 р. N 151 Київ

Про затвердження Порядку використання коштів, передбачених у державному бюджеті для здійснення заходів з імплементації Бюджетного та Податкового кодексів України

Відповідно до частини сьомої статті 20 Бюджетного кодексу України ( 2456-17 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання коштів, передбачених у державному бюджеті для здійснення заходів з імплементації Бюджетного ( 2456-17 ) та Податкового ( 2755-17 ) кодексів України, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 16 лютого 2011 р. N 151

ПОРЯДОК використання коштів, передбачених у державному бюджеті для здійснення заходів з імплементації Бюджетного ( 2456-17 ) та Податкового кодексів України ( 2755-17 )

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті Мінфіну за програмою "Заходи по імплементації Бюджетного та Податкового кодексів" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Мінфін.

Розпорядником бюджетних коштів нижчого рівня та відповідальним виконавцем бюджетної програми є державна навчально-наукова установа "Академія фінансового управління", що включена до мережі головного розпорядника бюджетних коштів відповідно до його рішення з урахуванням функцій зазначеної установи, передбачених статутом.

3. Бюджетні кошти спрямовуються на:

наукове супроводження імплементації Бюджетного ( 2456-17 ) та Податкового ( 2755-17 ) кодексів України (далі - Кодекси), проведення науково-дослідних робіт та наукове обґрунтування пропозицій до проектів нормативно-правових актів про внесення змін до актів законодавства у зв'язку з прийняттям Кодексів ( 2456-17, 2755-17 );

здійснення заходів щодо забезпечення діалогу влади, бізнесу та громадськості в процесі реалізації норм Кодексів ( 2456-17, 2755-17 ), узагальнення практики їх застосування з метою дотримання принципів прозорості бюджетної системи, справедливості оподаткування, а також забезпечення соціальної відповідальності бізнесу;

створення інформаційно-аналітичної бази для поширення серед керівників, спеціалістів та інших працівників бюджетних установ, суб'єктів господарювання всіх форм власності, широких верств населення відомостей з основних питань бюджетного та податкового законодавства;

підготовку наукових, аналітичних, навчальних, методичних, довідкових та інших матеріалів, науково-практичних коментарів норм Кодексів ( 2456-17, 2755-17 ), їх редакційно-видавниче опрацювання та поліграфічне виготовлення, зокрема з використанням дисків для лазерних систем зчитування;

здійснення перекладу норм Кодексів ( 2456-17, 2755-17 ) іноземними мовами і їх видання;

підготовку та оприлюднення у засобах масової інформації матеріалів з питань імплементації Кодексів ( 2456-17, 2755-17 );

проведення за участю науковців, фахівців та представників громадськості семінарів, конференцій, симпозіумів тощо з питань застосування норм Кодексів ( 2456-17, 2755-17 );

інформаційно-технічну підтримку розпорядника бюджетних коштів нижчого рівня, зокрема оновлення його офіційного веб-сайту;

матеріально-технічне забезпечення заходів з імплементації Кодексів ( 2456-17, 2755-17 ).

4. Бюджетні кошти використовуються у межах бюджетних асигнувань відповідно до плану заходів, затвердженого наказом головного розпорядника бюджетних коштів, в якому, зокрема, визначаються відповідальні за їх виконання та обсяги витрат.

5. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється розпорядником бюджетних коштів нижчого рівня в установленому законом порядку.

Попередня оплата товарів, робіт і послуг, що закуповуються за рахунок бюджетних коштів, проводиться відповідно до Бюджетного кодексу України ( 2456-17 ) та постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752).

6. Розпорядник бюджетних коштів нижчого рівня подає щокварталу до 5 числа місяця, що настає за звітним періодом, головному розпорядникові бюджетних коштів інформацію про їх використання в розрізі заходів, зазначених у пункті 4 цього Порядку.

7. Реєстрація, облік бюджетних зобов'язань, відкриття рахунків в органах Державної казначейської служби, інші операції, пов'язані з використанням бюджетних коштів, складення та подання фінансової і бюджетної звітності, звітів про виконання паспорта бюджетної програми, а також контроль за цільовим та ефективним витрачанням бюджетних коштів здійснюються в установленому законодавством порядку.
