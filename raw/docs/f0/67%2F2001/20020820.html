Про внесення змін до Указу Президента України від 29 грудня 1999 року N 1625

Стан: Втратив чинність

Ідентифікатор: 67/2001

Текст документа від 20.08.2002:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 729/2002 ( 729/2002 ) від 20.08.2002 )

Про внесення змін до Указу Президента України від 29 грудня 1999 року N 1625

Реорганізувати Управління прес-служби Президента України в Управління інформації та зв'язків з громадськістю.

У зв'язку з цим внести до Указу Президента України від 29 грудня 1999 року N 1625 ( 1625/99 ) "Питання Адміністрації Президента України" (із змінами, внесеними Указами Президента України від 23 лютого 2000 року N 278 ( 278/2000 ), від 9 березня 2000 року N 397 ( 397/2000 ) та від 25 грудня 2000 року N 1370 ( 1370/2000 ) такі зміни:

абзац 19 статті 1 викласти у такій редакції:

"Управління інформації та зв'язків з громадськістю";

внести відповідні зміни до додатка, зазначеного у статті 2 Указу.

Президент України Л.КУЧМА

м. Київ, 1 лютого 2001 року N 67/2001
