Про затвердження Порядку встановлення і використання офіційного обмінного курсу гривні до іноземних валют

Стан: Втратив чинність

Ідентифікатор: v0129500-99

Текст документа від 18.04.2001:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 129 від 18.03.99 Зареєстровано в юридичному м.Київ департаменті Нацбанку 18 березня 1999 р. vd990318 vn129 за N 630

Про затвердження Порядку встановлення і використання офіційного обмінного курсу гривні до іноземних валют

( Із змінами, внесеними згідно з Постановами Нацбанку N 141 ( v0636500-99 ) від 24.03.99 N 308 ( z0563-00 ) від 08.08.2000 N 98 ( z0355-01 ) від 06.03.2001 )

З метою лібералізації валютного ринку та керуючись статтею 8 Закону України "Про банки та банківську діяльність" ( 872-12 ), Правління ПОСТАНОВЛЯЄ:

1. Затвердити Порядок встановлення і використання офіційного обмінного курсу гривні до іноземних валют (додається).

2. Департаменту валютного регулювання (С.О.Яременко) довести затверджений Порядок встановлення і використання офіційного обмінного курсу гривні до іноземних валют до відома Кримського республіканського, Головного, обласних та по м.Києву і Київській області управлінь Національного банку України, ОПЕРУ НБУ, комерційних банків, Асоціації українських банків.

3. Визнати такими, що втратили чинність, Порядок встановлення і використання курсу українського карбованця від 30.03.98 N 128 ( v0535500-98 ), постанови Правління від 29.12.98 N 558 ( v0599500-98 ), від 30.12.98 N 560 ( v0600500-98 ), від 30.12.98 N 562 ( v0602500-98 ).

4. Постанова набуває чинності в установленому чинним законодавством порядку.

В.о. Голови В.С.Стельмах

( Порядок встановлення і використання офіційного обмінного курсу гривні до іноземних валют втратив чинність на підставі Постанови Нацбанку N 98 ( z0355-01 ) від 06.03.2001 )
