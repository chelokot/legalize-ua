Текст документа від 01.09.2005:

МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

16.09.2004 N 332

Зареєстровано в Міністерстві юстиції України 20 вересня 2004 р. за N 1183/9782

( Наказ втратив чинність на підставі Наказу Міністерства аграрної політики N 592 ( z1346-05 ) від 01.11.2005 )

Про внесення змін до наказу Міністерства аграрної політики України від 11 квітня 2001 року N 102 "Про впорядкування умов оплати праці працівників наукових установ і організацій, підпорядкованих міністерству"

Відповідно до постанови Кабінету Міністрів України від 1 липня 2002 року N 873 ( 873-2002-п ) "Про реорганізацію науково-дослідних центрів нормативів праці", розпорядження Кабінету Міністрів України від 26 грудня 2003 року N 813-р ( 813-2003-р ) "Про присвоєння Українському науково-дослідному інституту по прогнозуванню та випробуванню техніки і технологій для сільськогосподарського виробництва імені Л.В. Погорілого", наказів Міністерства аграрної політики України від 24 січня 2002 року N 16 ( v0016555-02 ) "Про ліквідацію Спеціального конструкторського, проектного та технологічного бюро "Агроприлад" з дослідним виробництвом", від 30 серпня 2002 року N 243 ( v0243555-02 ) "Про ліквідацію науково-виробничої фірми "Sanos", від 17 травня 2002 року N 133 ( v0133555-02 ) "Про Державний центр ветеринарної медицини птахівництва", від 25 грудня 2001 року N 377 ( v0377555-01 ) "Про упорядкування мережі науково-дослідних, проектно-конструкторських установ", від 29 липня 2002 року N 212 ( v0212555-02 ) "Про реорганізацію науково-дослідних центрів нормативів праці", із змінами, від 25 травня 2002 року N 120 ( v0120555-02 ) "Про перейменування Агрокомбінату "Пуща-Водиця", розпорядження Міністерства аграрної політики України від 26 грудня 2002 року N 342 "Про затвердження Статуту Державного науково-дослідного і проектно-конструкторського інституту "Консервпромкомплекс" НАКАЗУЮ:

1. Унести до наказу Міністерства аграрної політики України від 11 квітня 2001 року N 102 ( z0425-01 ) "Про впорядкування умов оплати праці працівників наукових установ і організацій, підпорядкованих міністерству", зареєстрованого в Міністерстві юстиції України 17 травня 2001 року за N 425/5616, із змінами і доповненнями, такі зміни:

1.1. У додатку 2 "Перелік науково-дослідних інститутів відповідно до груп за оплатою праці":

1.1.1. Вилучити позиції такого змісту:

"Науково-виробниче об'єднання "Сільгоспмашсистема" - Український науково-дослідний інститут по прогнозуванню та випробуванню техніки і технології сільськогосподарського виробництва - I";

"Науково-дослідний і проектно-конструкторський інститут "Консервпромкомплекс" - I".

1.1.2. Додати позиції такого змісту:

"Науково-виробниче об'єднання "Сільгоспмашсистема" - Український науково-дослідний інститут прогнозування та випробування техніки і технологій для сільськогосподарського виробництва імені Леоніда Погорілого - I";

"Державний науково-дослідний і проектно-конструкторський інститут "Консервпромкомплекс" - I";

"Український науково-дослідний інститут продуктивності агропромислового комплексу - I";

"Науково-дослідний і навчальний центр закритого ґрунту державного підприємства "Науково-дослідний виробничий агрокомбінат "Пуща-Водиця" - II".

1.2. У додатку 3 "Перелік установ і організацій, які за умовами оплати праці віднесені до інших наукових організацій":

1.2.1. Вилучити позиції такого змісту:

"Державний науково-експериментальний центр по розведенню, вирощуванню і утриманню піддослідних тварин";

"Державний науково-виробничий центр ветеринарної медицини птахівництва України";

"Спеціальне конструкторське, проектне і технологічне бюро "Агроприлад";

"Науково-виробнича фірма "Sanos";

"Науково-дослідний центр нормативів праці";

"Науково-дослідний центр нормативів праці на нову техніку";

"Зональні та обласні науково-дослідні центри нормативів праці";

"Науково-дослідний і навчальний центр закритого ґрунту агрокомбінату "Пуща-Водиця".

1.2.2. Додати позиції такого змісту:

"Державний центр ветеринарної медицини птахівництва";

"Зональні і регіональні науково-дослідні центри продуктивності агропромислового комплексу";

"Південно-Українська державна зональна машиновипробувальна станція";

"Львівська державна зональна машиновипробувальна станція";

"Миргородська державна машиновипробувальна станція";

"Харківська державна машиновипробувальна станція".

2. Контроль за виконанням наказу покласти на заступника Міністра Яковенка В.П.

Міністр В.А.Слаута
