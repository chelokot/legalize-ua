Про затвердження критеріїв формування державного замовлення на поставку продукції для державних потреб

{ Із змінами, внесеними згідно з Наказом Міністерства економіки N 1024 ( z0962-09 ) від 17.09.2009 }

З метою вдосконалення критеріїв формування державного замовлення та відповідно до постанови Кабінету Міністрів України від 29.02.96 N 266 ( 266-96-п ) "Про Порядок формування та розміщення державних замовлень на поставку продукції для державних потреб і контролю за їх формуванням" НАКАЗУЮ:

1. Затвердити критерії формування державного замовлення на поставку продукції для державних потреб, що додаються.

2. Департаменту державних закупівель:

забезпечити реєстрацію цього наказу в установленому порядку в Міністерстві юстиції України;

довести до відома потенційних державних замовників зміст критеріїв формування державного замовлення на поставку продукції для державних потреб, затверджених цим наказом;

разом з департаментом стратегічного планування розвитку економіки, департаментом розвитку соціальної та гуманітарної сфери та департаментом реформування публічної адміністрації та управління змінами забезпечити підготовку проекту державного замовлення на поставку продукції для державних потреб в установлені законодавством терміни відповідно до затверджених цим наказом критеріїв.

{ Пункт 2 в редакції Наказу Міністерства економіки N 1024 ( z0962-09 ) від 17.09.2009 }

3. Скасувати накази Міністерства економіки та з питань європейської інтеграції України від 14.06.2002 N 179 ( v0179569-02 ) "Про затвердження критеріїв формування державного замовлення на поставку продукції для державних потреб", від 28.04.2004 N 165 ( v0165569-04 ) "Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 14.06.2002 N 179" та від 22.07.2005 N 218 ( v0218665-05 ) "Про внесення змін до наказу Міністерства економіки України від 14.06.2002 N 179 (із змінами, внесеними згідно з наказом від 28.04.2004 N 165)".
