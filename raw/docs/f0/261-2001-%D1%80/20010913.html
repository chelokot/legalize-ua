Кабінет Міністрів України; Розпорядження від 27.06.2001 № 261-р

Про затвердження складу робочої групи з питань приватизації підприємств та ефективного управління корпоративними правами

Стан: Втратив чинність

Ідентифікатор: 261-2001-р

Текст документа від 13.09.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 червня 2001 р. N 261-р Київ

Про затвердження складу робочої групи з питань приватизації підприємств та ефективного управління корпоративними правами

( Із змінами, внесеними згідно з Розпорядженням КМ N 413-р ( 413-2001-р ) від 13.09.2001 )

1. Затвердити склад робочої групи з питань приватизації підприємств та ефективного управління корпоративними правами за посадою згідно з додатком.

Зміни до складу робочої групи вносяться її головою або заступником голови.

2. Проект нормативно-правового акта, схвалений робочою групою у поданій редакції або з урахуванням за результатами обговорення пропозицій та зауважень, готується (доопрацьовується) відповідним структурним підрозділом Секретаріату Кабінету Міністрів України згідно з протоколом засідання робочої групи і подається для розгляду на засіданні Кабінету Міністрів України. ( Розпорядження доповнено пунктом 2 згідно з Розпорядженням КМ N 413-р ( 413-2001-р ) від 13.09.2001 )

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 19 січня 2001 р. N 10 ( 10-2001-р ).
