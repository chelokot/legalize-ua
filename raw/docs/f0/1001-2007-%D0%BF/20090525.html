КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 серпня 2007 р. N 1001 Київ

Про внесення змін у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 та постанови Кабінету Міністрів України від 17 березня 2006 р. N 347

{ Із змінами, внесеними згідно з Постановою КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

2. Пункт 1 постанови Кабінету Міністрів України від 17 березня 2006 р. N 347 ( 347-2006-п ) "Деякі питання Державного агентства з інвестицій та інновацій" (Офіційний вісник України, 2006 р., N 12, ст. 808) виключити.

3. Ця постанова набирає чинності з 1 січня 2008 року.
