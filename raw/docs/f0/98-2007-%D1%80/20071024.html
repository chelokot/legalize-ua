Кабінет Міністрів України; Розпорядження від 14.03.2007 № 98-р

Про реорганізацію вищих навчальних закладів і наукових установ, що перебувають у сфері управління Міністерства фінансів та Міністерства економіки

Стан: Чинний

Ідентифікатор: 98-2007-р

Текст документа від 24.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 березня 2007 р. N 98-р Київ

Про реорганізацію вищих навчальних закладів і наукових установ, що перебувають у сфері управління Міністерства фінансів та Міністерства економіки

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 513-р ( 513-2007-р ) від 11.07.2007 N 910-р ( 910-2007-р ) від 24.10.2007 }

1. Погодитися з пропозицією:

1) Мінфіну щодо реорганізації:

Українського державного університету економіки і фінансів шляхом виділення із складу Університету Навчально-наукового інституту післядипломної освіти та утворення на його базі Державної навчально-наукової установи "Академія фінансового управління" (далі - Академія фінансового управління), яку віднести до сфери управління Мінфіну;

Науково-дослідного фінансового інституту при Мінфіні шляхом його приєднання до Академії фінансового управління та утворення у складі Академії на його базі Науково-дослідного фінансового інституту із збереженням за працівниками Інституту умов оплати праці відповідно до пункту 3 постанови Кабінету Міністрів України від 7 червня 1993 р. N 424 ( 424-93-п ) (ЗП України, 1993 р., N 11, ст. 231; 1994 р., N 12, ст. 295);

2) Мінфіну і Мінекономіки щодо реорганізації Українського державного університету економіки і фінансів та Української академії зовнішньої торгівлі шляхом їх злиття з утворенням Українського державного університету фінансів та міжнародної торгівлі, який віднести до сфери управління Мінфіну.

{ Пункт 1 в редакції Розпорядження КМ N 513-р ( 513-2007-р ) від 11.07.2007 }

2. Утворити:

{ Абзац другий пункту 2 виключено на підставі Розпорядження КМ N 910-р ( 910-2007-р ) від 24.10.2007 }

Одеський інститут фінансів Українського державного університету фінансів та міжнародної торгівлі на базі Одеського інституту фінансів Українського державного університету економіки і фінансів, що реорганізується;

Харківський інститут фінансів Українського державного університету фінансів та міжнародної торгівлі на базі Харківської філії Українського державного університету економіки і фінансів, що реорганізується;

Донецьку філію Українського державного університету фінансів та міжнародної торгівлі на базі Донецької філії Українського державного університету економіки і фінансів, що реорганізується;

Центр наукових фінансово-економічних експертиз і Центр впровадження результатів фінансово-економічних досліджень у складі Академії фінансового управління.

{ Пункт 2 в редакції Розпорядження КМ N 513-р ( 513-2007-р ) від 11.07.2007 }

3. Витрати, пов'язані з реорганізацією вищих навчальних закладів, здійснити в межах коштів, передбачених Мінфіну та Мінекономіки в Державному бюджеті України на 2007 рік ( 489-16 ) для підготовки кадрів.

Фінансування Академії фінансового управління здійснювати в межах коштів, передбачених Мінфіну в Державному бюджеті України на 2007 рік ( 489-16 ) для наукового забезпечення реалізації пріоритетних напрямів фінансово-бюджетної політики. { Пункт 3 доповнено абзацом згідно з Розпорядженням КМ N 513-р ( 513-2007-р ) від 11.07.2007 }

4. Взяти до відома, що студенти і слухачі реорганізованих згідно з цим розпорядженням вищих навчальних закладів продовжують навчання відповідно в Українському державному університеті фінансів та міжнародної торгівлі, його відокремлених структурних підрозділах та Академії фінансового управління.

{ Пункт 4 в редакції Розпорядження КМ N 513-р ( 513-2007-р ) від 11.07.2007 }

5. У розпорядженні Кабінету Міністрів України від 13 липня 2004 р. N 471 ( 471-2004-р ) "Про впорядкування мережі вищих навчальних закладів, що перебувають у сфері управління Мінфіну" (Офіційний вісник України, 2004 р., N 28, ст. 1907) пункт 1 і підпункт 1 пункту 2 виключити.
