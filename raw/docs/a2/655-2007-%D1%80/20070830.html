Кабінет Міністрів України; Розпорядження від 15.08.2007 № 655-р

Про виділення коштів для проведення невідкладних заходів з ліквідації наслідків надзвичайної ситуації, що сталася 13 серпня 2007 р. у Новоодеському районі Миколаївської області

Стан: Чинний

Ідентифікатор: 655-2007-р

Текст документа від 30.08.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 серпня 2007 р. N 655-р Київ

Про виділення коштів для проведення невідкладних заходів з ліквідації наслідків надзвичайної ситуації, що сталася 13 серпня 2007 р. у Новоодеському районі Миколаївської області

{ Із змінами, внесеними згідно з Розпорядженням КМ N 683-р ( 683-2007-р ) від 30.08.2007 }

1. Виділити Миколаївській облдержадміністрації 6311 тис. гривень для проведення невідкладних заходів з ліквідації наслідків надзвичайної ситуації, що сталася 13 серпня 2007 р. у Новоодеському районі. { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 683-р ( 683-2007-р ) від 30.08.2007 }

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 489-16 ).

2. Миколаївській облдержадміністрації:

затвердити у тижневий строк за погодженням з Мінекономіки, Мінфіном і Мінрегіонбудом перелік витрат, пов'язаних з проведенням невідкладних заходів з ліквідації наслідків надзвичайної ситуації, що сталася у Новоодеському районі;

подати до кінця 2007 року Мінекономіки, Мінфіну, Мінрегіонбуду і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.
