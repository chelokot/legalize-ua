Пенсійний фонд; Постанова від 11.03.2008 № 7-1

Про затвердження Порядку розслідування страхових випадків та обґрунтованості виплат матеріального забезпечення безробітним

Реєстрація: Мін'юст України від 26.03.2008 № 255/14946

Стан: Втратив чинність

Ідентифікатор: za255-08

Текст документа від 13.09.2008:

ПРАВЛІННЯ ПЕНСІЙНОГО ФОНДУ УКРАЇНИ

ПОСТАНОВА

11.03.2008 N 7-1

Зареєстровано в Міністерстві юстиції України 26 березня 2008 р. за N 255/14946

{ Постанова втратила чинність на підставі Постанови Пенсійного фонду N 16-1 ( za809-08 ) від 13.08.2008 }

Про затвердження Порядку розслідування страхових випадків та обґрунтованості виплати матеріального забезпечення безробітним

Відповідно до пункту 12 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261 ( 1261-2007-п ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Затвердити Порядок розслідування страхових випадків та обґрунтованості виплат матеріального забезпечення безробітним ( z0255-08 ), що додається.

2. Юридичному управлінню (Рябцева Т.Б.) подати цю постанову для державної реєстрації до Міністерства юстиції України.

3. Контроль за виконанням цієї постанови покласти на першого заступника Голови правління В.О.Кравчука.
