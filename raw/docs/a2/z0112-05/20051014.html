Про внесення змін до наказу Міністерства освіти і науки України від 29.03.2001 N 161

На виконання постанови Кабінету Міністрів України від 15.01.2005 N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів ( ставок заробітної плати ) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства освіти і науки України від 29.03.2001 N 161 ( z0303-01 ) "Про затвердження розмірів посадових окладів (ставок заробітної плати) працівників навчальних закладів, установ освіти та наукових установ", зареєстрованого Міністерством юстиції України 03.04.2001 за N 303/5494, із змінами та доповненнями, унесеними наказами Міністерства освіти і науки України: від 22.10.2001 N 697 ( z0925-01 ) "Про внесення змін та доповнень до наказу Міністерства освіти і науки України від 29.03.2001 N 161", зареєстрованим у Міністерстві юстиції України 02.11.2001 за N 925/6116, від 25.02.2002 N 145 ( z0234-02 ) "Про внесення змін до наказу Міністерства освіти і науки України від 29.03.2001 N 161", зареєстрованим у Міністерстві юстиції України 07.03.2002 за N 234/6522, від 30.05.2003 N 338 ( z0465-03 ) "Про внесення змін до наказу Міністерства освіти і науки України від 29.03.2001 N 161", зареєстрованим у Міністерстві юстиції України 10.06. 2003 за N 465/7786, від 26.02.2004 N 160 ( z0300-04 ) "Про внесення змін до наказу Міністерства освіти і науки України від 29.03.2001 N 161", зареєстрованим у Міністерстві юстиції України 09.03. 2004 за N 300/8899, та від 08.09.2004 N 712 ( z1130-04 ) "Про внесення змін до наказу Міністерства освіти і науки України від 29.03.2001 N 161", зареєстрованим у Міністерстві юстиції України 13.09.2004 за N 1130/9729, - виклавши додатки 1-19 в редакції, що додається.

2. Керівникам навчальних закладів, установ освіти та наукових установ у межах затвердженого фонду заробітної плати встановити з 1 січня 2005 року посадові оклади (ставки заробітної плати) працівникам навчальних закладів, установ освіти та наукових установ у розмірах, визначених у додатках 1-19.

3. Контроль за виконанням наказу покласти на заступника Міністра Богомолова А.Г.
