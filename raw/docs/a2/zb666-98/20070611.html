{ Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку

N 956 ( za560-07 ) від 15.05.2007 }

Про затвердження Положення про особливості здійснення депозитарної діяльності з державними цінними паперами

Відповідно до вимог Закону України "Про Національну депозитарну систему та особливості електронного обігу цінних паперів в Україні" ( 710/97-ВР ) Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Положення про особливості здійснення депозитарної діяльності з державними цінними паперами, що додається ( z0666-98 ).

2. Рішення набуває чинності через 10 днів після його державної реєстрації у Міністерстві юстиції України.

3. Контроль за виконанням цього рішення покласти на Члена Комісії Головка А.Т.

В.о.Голови Комісії О.Ромашко
