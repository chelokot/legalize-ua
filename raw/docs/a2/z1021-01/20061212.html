{ Наказ втратив чинність на підставі Наказу Міністерства культури і туризму N 911 ( z1255-06 ) від 20.11.2006 }

Про внесення змін до наказу Мінкультури від 17.04.2001 N 187

З метою забезпечення планового функціонування державної циркової галузі у 2001 році НАКАЗУЮ:

1. Визнати таким, що втратив чинність пункт 1 наказу Мінкультури від 17.04.2001 N 187 ( z0361-01 ) "Про впорядкування окремих питань фінансово-господарської діяльності державних циркових підприємств", зареєстрованого в Міністерстві юстиції України від 20.04.2001 за N 361/5552.

2. Контроль за виконанням наказу покласти на Першого заступника Державного секретаря В.Г.Романчишина та начальника управління мистецтв Г.П.Кириліну.
