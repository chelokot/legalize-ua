Про скасування постанови НКРЕ від 19.03.2009 N 311

Відповідно до Закону України "Про електроенергетику" ( 575/97-ВР ), Указу Президента України від 14.03.95 N 213 ( 213/95 ) "Про заходи щодо забезпечення діяльності Національної комісії з питань регулювання електроенергетики України" (із змінами) і постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Скасувати постанову НКРЕ від 19.03.2009 N 311 ( z0260-09, z0261-09 ) "Про зміну тарифів на електричну енергію, що відпускається населенню і населеним пунктам, та затвердження Змін до Порядку застосування тарифів на електроенергію, що відпускається населенню і населеним пунктам", зареєстровану в Міністерстві юстиції України 20.03.2009 за N 260/16276.

2. Установити, що з 01.04.2009 діють:

Тарифи на електроенергію, що відпускається населенню і населеним пунктам, затверджені постановою НКРЕ від 10.03.99 N 309 ( z0151-99 ) (у редакції постанови НКРЕ від 20.07.2006 N 926 ( z0918-06 ), зареєстровані в Міністерстві юстиції України 10.03.99 за N 151/3444;

Порядок застосування тарифів на електроенергію, що відпускається населенню і населеним пунктам ( z0152-99 ), затверджений постановою НКРЕ від 10.03.99 N 309 ( z0151-99 ) (у редакції постанови НКРЕ від 10.07.2002 N 758 ( z0626-02 ) та із змінами від 25.02.2004 N 188 ( z0308-04 ), від 30.03.2006 N 401 ( z0413-06 ), від 20.07.2006 N 926 ( z0918-06 ), зареєстрований в Міністерстві юстиції України 10.03.99 за N 152/3445.

3. Управлінню цінової політики в електроенергетиці подати цю постанову на державну реєстрацію до Міністерства юстиції України в установленому законодавством порядку.
