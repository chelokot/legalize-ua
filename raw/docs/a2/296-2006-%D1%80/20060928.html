Про вдосконалення структури розпорядників бюджетних коштів

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 406-р ( 406-2006-р ) від 17.07.2006 N 464-р ( 464-2006-р ) від 03.08.2006 N 465-р ( 465-2006-р ) від 03.08.2006 N 469-р ( 469-2006-р ) від 17.08.2006 Постановою КМ N 1365 ( 1365-2006-п ) від 28.09.2006 }

З метою посилення контролю за використанням бюджетних коштів та упорядкування структури розпорядників бюджетних коштів Мінфіну:

врахувати під час підготовки проекту Державного бюджету України на 2007 рік схему та переліки згідно з додатками 1-3;

подати у місячний строк разом з іншими центральними органами виконавчої влади Кабінетові Міністрів України пропозиції щодо внесення відповідних змін до Бюджетного кодексу України ( 2542-14 ), інших актів законодавства.
