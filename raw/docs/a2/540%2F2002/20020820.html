Про внесення змін до Указу Президента України від 29 грудня 1999 року N 1625

Стан: Втратив чинність

Ідентифікатор: 540/2002

Текст документа від 20.08.2002:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 729/2002 ( 729/2002 ) від 20.08.2002 )

Про внесення змін до Указу Президента України від 29 грудня 1999 року N 1625

З метою підвищення ефективності діяльності Адміністрації Президента України постановляю:

1. Внести до Указу Президента України від 29 грудня 1999 року N 1625 ( 1625/99 ) "Питання Адміністрації Президента України" (зі змінами, внесеними Указами від 23 лютого 2000 року N 278 ( 278/2000 ), від 9 березня 2000 року N 397 ( 397/2000 ), від 25 грудня 2000 року N 1370 ( 1370/2000 ), від 1 лютого 2001 року N 67 ( 67/2001 ), від 25 квітня 2001 року N 281 ( 281/2001 ), від 19 червня 2001 року N 453 ( 453/2001 ), від 21 липня 2001 року N 538 ( 538/2001 ), від 25 жовтня 2001 року N 1017 ( 1017/2001 ), від 3 червня 2002 року N 505 ( 505/2002 ) такі зміни:

1) у статті 1 абзац "два Перших заступники та заступники Глави Адміністрації Президента України, Прес-секретар Президента України" замінити двома абзацами такого змісту:

"Перший помічник Президента України;

Перший заступник та заступники Глави Адміністрації Президента України, Прес-секретар Президента України";

2) у статті 2 слова "двома Першими заступниками" замінити словами "Першим помічником Президента України, Першим заступником".

2. Главі Адміністрації Президента України та Першому помічникові Президента України внести у двотижневий строк пропозиції щодо зміни закріплення за Главою Адміністрації Президента України, Першим помічником Президента України, Першим заступником і заступниками Глави Адміністрації Президента України структурних підрозділів, визначених у додатку до статті 2 Указу Президента України від 29 грудня 1999 року N 1625 ( 1625/99 ).

Президент України Л.КУЧМА
