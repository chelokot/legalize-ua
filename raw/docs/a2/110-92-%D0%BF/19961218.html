( Постанова втратила чинність на підставі Постанови КМ N 1518 ( 1518-96-п ) від 18.12.96 )

Про призначення представників України в Міждержавній науково-технічній раді

Відповідно до Угоди про міждержавне науково-технічне співробітництво, підписаної 27 грудня 1991 р. у м.Мінську (Білорусь), Кабінет Міністрів України постановляє:

1. Призначити повноважним представником України в Міждержавній науково-технічній раді Рябченка Сергія Михайловича, голову Комітету по науково-технічному прогресу при Кабінеті Міністрів України.

2. Призначити постійним представником України в Секретаріаті Міждержавної науково-технічної ради Свіженка Віктора Олексійовича, заступника голови Комітету по науково-технічному прогресу при Кабінеті Міністрів України.
