ПОСТАНОВА від 23 червня 2010 р. N 494 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 539 ( 539-2012-п ) від 31.05.2012 }

Про внесення змін до постанови Кабінету Міністрів України від 7 березня 2007 р. N 414

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 7 березня 2007 р. N 414 ( 414-2007-п ) "Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для збирання, оброблення та розповсюдження офіційної інформаційної продукції" (Офіційний вісник України, 2007 p., N 8, ст. 722) такі зміни:

у назві і постановляючій частині постанови ( 414-2007-п ) слова і цифри "у 2007 році" виключити;

у Порядку ( 414-2007-п ), затвердженому зазначеною постановою:

у назві і пункті 1 слова і цифри "у 2007 році" виключити;

пункт 5 викласти у такій редакції:

"5. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.";

доповнити Порядок ( 414-2007-п ) пунктом 6-1 такого змісту:

"6-1. Одержувач бюджетних коштів надсилає щомісяця до 20 числа наступного періоду Держкомтелерадіо інформацію про використання бюджетних коштів для її узагальнення та подання відомостей Мінфіну до 30 числа зазначеного періоду.".
