N 628-р ( v0628500-08 ) від 10.11.2008 }

Про окремі питання регулювання грошово-кредитного ринку

(Витяг)

Відповідно до вимог Положення про регулювання Національним банком України ліквідності банків України, затвердженого постановою Правління Національного банку України від 26.09.2006 N 378 ( z1120-06 ), зі змінами, (далі - Положення), та постанови Правління Національного банку України від 14.11.2006 N 434 ( v0434500-06 ) "Про терміни та можливі обсяги проведення Національним банком України окремих операцій з банками, передбачених у Положенні про регулювання Національним банком України ліквідності банків України та вимоги щодо забезпечення, що пропонується банками", зі змінами, а також керуючись пунктом 3 постанови Правління Національного банку України від 21.04.2008 N 107 ( v0107500-08 ) "Про регулювання грошово-кредитного ринку":

1. Установити, що з 22 квітня 2008 року:

кредит овернайт бланковий може надаватися відповідно до пункту 3.7 глави 3 розділу II Положення ( z1120-06 ) не більше 10 разів протягом календарного місяця в розмірі не більше 40 процентів від суми визначеного та сформованого банком обсягу обов'язкових резервів за попередній звітний період резервування.
