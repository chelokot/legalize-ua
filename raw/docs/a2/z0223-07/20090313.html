Зареєстровано в Міністерстві юстиції України 14 березня 2007 р. за N 223/13490

ПОРЯДОК використання коштів, передбачених у державному бюджеті для фінансової підтримки творчих спілок у сфері архітектури

{ У тексті Порядку слова "Міністерство будівництва, архітектури та житлово-комунального господарства України" та "Мінбуд України" замінено відповідно словами "Міністерство регіонального розвитку та будівництва України" та "Мінрегіонбуд" у відповідних відмінках згідно з Наказом Міністерства регіонального розвитку та будівництва N 90 ( z0855-07 ) від 06.07.2007 }

1. Загальні положення

1.1. Цей Порядок визначає механізм використання коштів, передбачених Міністерству регіонального розвитку та будівництва України (далі - Мінрегіонбуд) у Державному бюджеті України по загальному фонду для фінансової підтримки творчих спілок у сфері архітектури.

1.2. Основні терміни, що вживаються в цьому Порядку:

бюджетні кошти - кошти, які передбачені Мінрегіонбуду у Державному бюджеті України по загальному фонду для фінансової підтримки творчих спілок у сфері архітектури;

головний розпорядник коштів - Мінрегіонбуд (головний розпорядник бюджетних коштів);

одержувачі коштів - творчі спілки у сфері архітектури.

2. Мета Порядку та напрями спрямування бюджетних коштів

2.1. Основною метою Порядку є сприяння розвитку та популяризації архітектури.

2.2. Бюджетні кошти спрямовуються на фінансову підтримку творчих спілок у сфері архітектури та використовуються для організації проведення виставок членів Національної спілки архітекторів України.

{ Пункт 2.2 в редакції Наказу Міністерства регіонального розвитку та будівництва N 72 ( z0298-08 ) від 13.02.2008 }

3. Вимоги щодо використання бюджетних коштів

3.1. Бюджетні кошти використовуються Мінрегіонбудом в межах бюджетних призначень, установлених законом України про Державний бюджет України на відповідний рік, згідно із затвердженим Мінрегіонбудом планом заходів з урахуванням необхідності виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державного казначейства України, та в разі їх відповідності до паспорта бюджетної програми.

3.2. Операції з коштами державного бюджету здійснюються відповідно до Порядку обслуговування державного бюджету за видатками, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04, za716-04 ), зареєстрованого в Міністерстві юстиції України 10.06.2004 N 716/9315.

4. Звітність про використання бюджетних коштів та контроль за їх витрачанням

4.1. Мінрегіонбуд до вказаного плану заходів затверджує результативні показники щодо їх виконання з поквартальною розбивкою. Указані матеріали подаються до Міністерства фінансів у двотижневий термін після затвердження розпису державного бюджету.

Інформація щодо виконання поквартальних показників подається Мінрегіонбудом Міністерству фінансів у тижневий термін після завершення звітного кварталу та за результатами виконання показників за одинадцять місяців.

4.2. Відповідальність за цільове використання бюджетних коштів покладається на головного розпорядника та одержувачів бюджетних коштів.

{ Пункт 4.3 глави 4 виключено на підставі Наказу Міністерства регіонального розвитку та будівництва N 66 ( z0188-09 ) від 11.02.2009 }

4.3. Складання та подання фінансової звітності про використання коштів, а також контроль за їх цільовим витрачанням здійснюється у встановленому законодавством порядку.
