ПОСТАНОВА від 12 листопада 2008 р. N 996 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про внесення змін до постанови Кабінету Міністрів України від 14 жовтня 2008 р. N 925

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 14 жовтня 2008 р. N 925 ( 925-2008-п ) "Про першочергові заходи щодо стабілізації ситуації, що склалася в гірничо-металургійному та хімічному комплексі" (Офіційний вісник України, 2008 р., N 81, ст. 2731) зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21
