КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 2004 р. N 953-р Київ

( Розпорядження скасовано на підставі Розпорядження КМ N 71-р ( 71-2005-р ) від 30.03.2005 )

Про погодження продажу земельної ділянки

Погодитися з пропозицією Алуштинської міської ради щодо продажу земельної ділянки несільськогосподарського призначення площею 3,82 гектара, яка розташована в межах м. Алушти, іноземній юридичній особі - Об'єднаному інституту ядерних досліджень для експлуатації та обслуговування об'єктів пансіонату "Дубна".
