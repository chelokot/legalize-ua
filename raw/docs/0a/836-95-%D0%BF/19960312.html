Текст документа від 12.03.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 жовтня 1995 р. N 836 Київ

( Постанова втратила чинність на підставі Постанови КМ N 308 ( 308-96-п ) від 12.03.96 )

Про розміри державних стипендій для підтримки діячів літератури і мистецтва, особливо обдарованих учнів і студентів спеціалізованих навчальних закладів у галузі культури

На виконання Розпорядження Президента України від 5 червня 1995 р. N 96 ( 96/95-рп ) "Про соціальний захист населення у зв'язку з підвищенням цін і тарифів" Кабінет Міністрів України постановляє:

1. Установити з 1 жовтня 1995 р. такі розміри державних стипендій:

для підтримки діячів літератури і мистецтва - 8 млн. 420 тис. крб. на місяць;

для підтримки особливо обдарованих учнів і студентів спеціалізованих навчальних закладів у галузі культури - 2 млн. 390 тис. крб. на місяць.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 29 травня 1995 р. N 361 ( 361-95-п ) "Про розміри державних стипендій для підтримки діячів літератури і мистецтва, особливо обдарованих учнів і студентів спеціалізованих навчальних закладів у галузі культури".
