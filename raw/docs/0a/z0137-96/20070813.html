НАКАЗ

N 24/32 від 12.03.96 Зареєстровано в Міністерстві м.Київ юстиції України 22 березня 1996 р. vd960312 vn24/32 за N 137/1162

{ Наказ втратив чинність на підставі Наказу Міністерства охорони навколишнього природного середовища N 332/262 ( z0878-07 ) від 18.07.2007 }

Про затвердження такс нарахування розміру стягнення за

збитки, заподіяні незаконним добуванням або знищенням

диких звірів і птахів (крім видів, занесених до

Червоної книги України), їх жител, біотехнічних споруд

З метою посилення боротьби з браконьєрством, збереження державного мисливського фонду НАКАЗУЄМО:

1. Затвердити такси для нарахування розміру стягнення за збитки, заподіяні незаконним добуванням або знищенням диких звірів і птахів (крім видів, занесених до Червоної книги України), їх жител, біотехнічних споруд, що додаються.

2. Генеральним директорам державних лісогосподарських об'єднань, начальникам обласних управлінь лісового господарства, голові державного комітету охорони навколишнього природного середовища та природних ресурсів Автономної Республіки Крим, начальникам держуправлінь екологічної безпеки в областях, містах Києві та Севастополі:

2.1. Довести цей наказ до відома підвідомчих підприємств і організацій, а також мисливських товариств області, провести широку роз'яснювальну роботу серед населення.

2.2. При притягненні до відповідальності винних у порушенні правил полювання користуватись цими таксами.

3. Наказ від 15.06.95 р. N 60/61 ( z0316-95 ) "Про затвердження такс нарахування розміру стягнення за збитки, заподіяні незаконним добуванням або знищенням диких звірів і птахів (крім видів, занесених до "Червоної книги України"), їх жител, біотехнічних споруд", визнати таким, що втратив чинність.
