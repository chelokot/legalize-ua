КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 жовтня 2009 р. N 1045 Київ

Про спрямування коштів Стабілізаційного фонду для компенсації Українському державному підприємству поштового зв'язку "Укрпошта" витрат, пов'язаних з наданням послуг на пільгових умовах

{ Із змінами, внесеними згідно з Постановою КМ N 1229 ( 1229-2009-п ) від 21.10.2009 }

Кабінет Міністрів України постановляє:

1. Виділити Міністерству транспорту та зв'язку за рахунок нерозподілених коштів Стабілізаційного фонду 38 млн. гривень для компенсації Українському державному підприємству поштового зв'язку "Укрпошта" витрат, пов'язаних з наданням послуг на пільгових умовах.

Визначити джерелом покриття зазначених видатків кошти, що надійшли від приватизації державного майна та з інших джерел, передбачених Законом України "Про Державний бюджет України на 2009 рік" ( 835-17 ).

{ Пункт 1 в редакції Постанови КМ N 1229 ( 1229-2009-п ) від 21.10.2009 }

2. Затвердити Порядок використання у 2009 році коштів Стабілізаційного фонду для компенсації Українському державному підприємству поштового зв'язку "Укрпошта" витрат, пов'язаних з наданням послуг на пільгових умовах, що додається.

3. Міністерству фінансів забезпечити внесення відповідних змін до розпису державного бюджету без попереднього погодження з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету.

4. Міністерству транспорту та зв'язку вжити заходів до погодження перерозподілу коштів Стабілізаційного фонду ( 835-17 ), передбаченого пунктом 1 цієї постанови, з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету.

5. Державному казначейству забезпечити перерахування виділених відповідно до цієї постанови коштів.

{ Постанову доповнено пунктом 5 згідно з Постановою КМ N 1229 ( 1229-2009-п ) від 21.10.2009 }

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 жовтня 2009 р. N 1045

ПОРЯДОК використання у 2009 році коштів Стабілізаційного фонду для компенсації Українському державному підприємству поштового зв'язку "Укрпошта" витрат, пов'язаних з наданням послуг на пільгових умовах

1. Цей Порядок визначає механізм використання у 2009 році коштів Стабілізаційного фонду за напрямом, передбаченим пунктом 22 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), для компенсації Українському державному підприємству поштового зв'язку "Укрпошта" витрат, пов'язаних з наданням послуг на пільгових умовах (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Мінтрансзв'язку.

Розпорядниками бюджетних коштів нижчого рівня є філіали Українського державного підприємства поштового зв'язку "Укрпошта" за переліком згідно з додатком.

3. Бюджетні кошти виділяються на безповоротній основі з урахуванням Порядку використання у 2009 році коштів Стабілізаційного фонду, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) (Офіційний вісник України, 2009 р., N 24, ст. 793), на покриття витрат, пов'язаних з підвищенням не менш як на 50 відсотків посадових окладів листонош та здійсненням нарахувань на фонд оплати праці.

4. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

5. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим використанням здійснюються в установленому законодавством порядку.
