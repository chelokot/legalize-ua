КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 січня 2010 р. N 59 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про внесення змін до постанови Кабінету Міністрів України від 29 грудня 2009 р. N 1416

Кабінет Міністрів України постановляє:

Абзац другий постановляючої частини постанови Кабінету Міністрів України від 29 грудня 2009 р. N 1416 ( 1416-2009-п ) "Про закупівлю енергетичного вугілля" (Офіційний вісник України, 2010 р., N 1, ст. 9) замінити абзацами такого змісту:

"відповідно до пункту 6 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006), у 2010 році за процедурою закупівлі в одного учасника без погодження з Міністерством економіки здійснюється закупівля за державні кошти:

- вугілля кам'яного державним підприємством "Вугілля України" у постачальників;

- енергетичного вугілля для виробництва електричної та теплової енергії енергогенеруючими компаніями, які провадять ліцензовану діяльність з виробництва електричної та/або теплової енергії, у державного підприємства "Вугілля України;".

У зв'язку з цим абзац третій вважати абзацом п'ятим.

Прем'єр-міністр України Ю.ТИМОШЕНКО
