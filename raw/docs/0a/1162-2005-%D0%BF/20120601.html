Текст документа від 01.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 грудня 2005 р. N 1162 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 445 ( 445-2012-п ) від 21.05.2012 }

Питання митного оформлення транспортних засобів, призначених для офіційного (службового) користування представництв та консульських установ іноземних держав, представництв міжнародних організацій в Україні, а також для особистого користування їх посадовими особами та членами сімей

Кабінет Міністрів України постановляє:

1. Державній митній службі здійснювати митне оформлення транспортних засобів, призначених для офіційного (службового) користування представництв та консульських установ іноземних держав, представництв міжнародних організацій в Україні, а також для особистого користування їх посадовими особами та членами сімей, у порядку, визначеному законодавством, виходячи з принципу взаємності щодо кожної окремої держави.

2. Міністерству закордонних справ подавати Державній митній службі інформацію про митні, податкові та інші пільги, що надаються закордонним дипломатичним установам України, працівникам цих установ та членам їх сімей у кожній окремій державі.

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 27 серпня 1999 р. N 1569 ( 1569-99-п ) "Про відчуження на митній території України транспортних засобів, що належать іноземним дипломатичним представництвам, консульським установам іноземних держав, представництвам міжнародних організацій, їх персоналу та членам сімей персоналу" (Офіційний вісник України, 1999 р., N 35, ст. 1792).
