Кабінет Міністрів УРСР; Розпорядження від 31.07.1991 № 145-р

Про внесення змін до розпорядження Кабінету Міністрів УРСР від 8 липня 1991 р. N 99

Стан: Втратив чинність

Ідентифікатор: 145-91-р

Текст документа від 25.08.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНСЬКОЇ РСР

РОЗПОРЯДЖЕННЯ від 31 липня 1991 р. N 145-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1109 ( 1109-2004-п ) від 25.08.2004 )

Викласти абзац п'ятий пункту 1 розпорядження Кабінету Міністрів УРСР від 8 липня 1991 р. N 99 ( 99-91-р ) в такій редакції:

"підприємствами громадського харчування, дитячими, оздоровчими, лікувальними та іншими установами - за роздрібними цінами за вирахуванням відповідних торговельних знижок".

Перший віце-прем'єр-міністр УРСР К.МАСИК
