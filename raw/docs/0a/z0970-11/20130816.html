Про затвердження Розмірів плати за надання платних послуг Лівобережним відділом державної реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 1160/5 ( z1348-12 ) від 03.08.2012 }

Відповідно до частини третьої статті 20 Закону України "Про державну реєстрацію актів цивільного стану" ( 2398-17 ), Переліку платних послуг, які можуть надаватися відділами державної реєстрації актів цивільного стану, затвердженого постановою Кабінету Міністрів України від 22.12.2010 N 1168 ( 1168-2010-п ), та Порядку надання платних послуг відділами державної реєстрації актів цивільного стану, затвердженого наказом Міністерства юстиції України від 27.12.2010 N 3335/5 ( z1380-10 ), зареєстрованого в Міністерстві юстиції України 29.12.2010 за N 1380/18675, НАКАЗУЮ:

1. Затвердити Розміри плати за надання платних послуг Лівобережним відділом державної реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї, що додається.

2. Визнати такими, що втратили чинність, накази Міністерства юстиції України:

від 09.09.2004 N 103/5 ( z1155-04 ) "Про затвердження Положення про порядок надання Лівобережним відділом реєстрації шлюбів м. Києва з державним Центром розвитку сім'ї додаткових платних послуг правового та технічного характеру громадянам та організаціям", зареєстрований у Міністерстві юстиції України 15.09.2004 за N 1155/9754;

від 27.05.2008 N 895/5 ( z0468-08 ) "Про затвердження Тарифів за надання додаткових послуг правового і технічного характеру в Лівобережному відділі реєстрації шлюбів міста Києва з Державним центром розвитку сім'ї", зареєстрований у Міністерстві юстиції України 28.05.2008 за N 468/15159;

від 24.12.2008 N 2259/5 ( z1243-08 ) "Про внесення змін до Тарифів за надання додаткових послуг правового і технічного характеру у Лівобережному відділі реєстрації шлюбів міста Києва з Державним центром розвитку сім'ї", зареєстрований у Міністерстві юстиції України 25.12.2008 за N 1243/15934.

3. Контроль за виконанням цього наказу покласти на Голову Державної реєстраційної служби України Єфіменка Л.В.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр Олександр Лавринович
