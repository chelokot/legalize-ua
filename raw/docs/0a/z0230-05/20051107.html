( Наказ втратив чинність на підставі Наказу Державного комітету лісового господарства N 412 ( z1274-05 ) від 07.09.2005 )

Про внесення змін до наказу Держкомлісгоспу України від 02.06.2003 N 91

На виконання постанови Кабінету Міністрів України від 15 січня 2005 року N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести до наказу Державного комітету лісового господарства України від 02.06.2003 N 91 ( z0634-03 ) "Про впорядкування умов оплати праці працівників Української державної лісонасіннєвої інспекції Державного комітету лісового господарства України", зареєстрованого в Міністерстві юстиції України 23.07.2003 за N 634/7955 (із змінами), виклавши додатки 1, 2 у новій редакції, що додається.

2. Контроль за виконанням цього наказу залишаю за собою.

3. Ці зміни застосовуються з 1 січня 2005 року.

В.о. Голови Комітету Ю.М.Марчук
