Кабінет Міністрів України; Постанова, Порядок від 04.03.2004 № 260

Стан: Чинний

Ідентифікатор: 260-2004-п

Текст документа від 08.10.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 березня 2004 р. N 260 Київ

Про затвердження Порядку спрямування коштів Фонду загальнообов'язкового державного соціального страхування на випадок безробіття для створення нових робочих місць працівникам вугільної промисловості, які вивільняються у зв'язку із закриттям шахт, членам їх сімей (дружина (чоловік), повнолітні діти) та членам сімей загиблих шахтарів (дружина (чоловік), повнолітні діти)

( Із змінами, внесеними згідно з Постановою КМ N 1328 ( 1328-2004-п ) від 08.10.2004 )

Відповідно до статті 36 Закону України "Про Державний бюджет України на 2004 рік" ( 1344-15 ) Кабінет Міністрів України постановляє:

Затвердити Порядок спрямування коштів Фонду загальнообов'язкового державного соціального страхування на випадок безробіття для створення нових робочих місць працівникам вугільної промисловості, які вивільняються у зв'язку із закриттям шахт, членам їх сімей (дружина (чоловік), повнолітні діти) та членам сімей загиблих шахтарів (дружина (чоловік), повнолітні діти), що додається.

Установити, що працевлаштування працівників вугільної промисловості, які вивільняються у зв'язку із закриттям шахт, членів їх сімей (дружина (чоловік), повнолітні діти) та членів сімей загиблих шахтарів (дружина (чоловік), повнолітні діти) здійснюється на нові робочі місця, створені за рахунок коштів, спрямованих Фондом загальнообов'язкового державного соціального страхування на випадок безробіття на ці цілі у 2003 та 2004 роках.

( Постановляюча частина в редакції Постанови КМ N 1328 ( 1328-2004-п ) від 08.10.2004 )

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 4 березня 2004 р. N 260

ПОРЯДОК спрямування коштів Фонду загальнообов'язкового державного соціального страхування на випадок безробіття для створення нових робочих місць працівникам вугільної промисловості, які вивільняються у зв'язку із закриттям шахт

1. Цей Порядок визначає механізм спрямування у 2004 році коштів Фонду загальнообов'язкового державного соціального страхування на випадок безробіття (далі - Фонд) для створення нових робочих місць працівникам вугільної промисловості, які вивільняються у зв'язку із закриттям шахт, членам їх сімей (дружина (чоловік), повнолітні діти) та членам сімей загиблих шахтарів (дружина (чоловік), повнолітні діти) (далі - працівники, які вивільняються, члени їх сімей та члени сімей загиблих шахтарів). ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1328 ( 1328-2004-п ) від 08.10.2004 )

2. Фонд перераховує кошти в обсягах, визначених у Законі України "Про Державний бюджет України на 2004 рік" ( 1344-15 ), на рахунки облдержадміністрацій, відкриті в органах Державного казначейства за балансовим рахунком 3711 "Інші кошти розпорядників коштів державного бюджету" плану рахунків бухгалтерського обліку виконання державного та місцевих бюджетів.

Кошти Фонду перераховуються щомісяця до 25 числа в межах сум, що визначаються рівними частинами з урахуванням річного обсягу, відповідно до розробленого облдержадміністрацією графіка після погодження у період до 20 березня з правлінням Фонду та затвердження облдержадміністрацією Програми створення нових робочих місць працівникам вугільної промисловості, які вивільняються у зв'язку із закриттям шахт, членам їх сімей (дружина (чоловік), повнолітні діти) та членам сімей загиблих шахтарів (дружина (чоловік), повнолітні діти) (далі - Програма). ( Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 1328 ( 1328-2004-п ) від 08.10.2004 )

3. У Програмі визначається:

перелік підприємств, установ та організацій (далі - підприємства), на яких створюються нові робочі місця, що складається відповідно до Порядку створення нових робочих місць для працевлаштування працівників, які вивільняються з вугледобувних, вуглепереробних та торфодобувних підприємств, що ліквідуються за рахунок коштів державного бюджету на реструктуризацію вугільної і торфодобувної промисловості, затвердженого постановою Кабінету Міністрів України від 25 грудня 2002 р. N 1954 ( 1954-2002-п ) (Офіційний вісник України, 2002 р., N 52, ст. 2375), - із змінами, внесеними постановою Кабінету Міністрів України від 28 січня 2004 р. N 90 ( 90-2004-п );

кількість нових робочих місць із зазначенням професій (спеціальностей), що передбачається створити для працівників, які вивільняються, членів їх сімей та членів сімей загиблих шахтарів, з розподілом за кварталами в розрізі підприємств; ( Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 1328 ( 1328-2004-п ) від 08.10.2004 )

обсяг коштів Фонду, необхідних для створення нових робочих місць, з розподілом за кварталами в розрізі підприємств;

чисельність працівників, яких передбачено працевлаштувати, в розрізі підприємств та із зазначенням шахт, з яких вони вивільняються, і періодів вивільнення;

графік перерахування облдержадміністрації коштів Фонду.

4. Перерахування коштів визначеним в Програмі підприємствам здійснюється облдержадміністрацією у місячний строк після їх надходження на рахунок облдержадміністрації за умови подання підприємствами таких документів:

титул будови (об'єкта) або титул перехідної будови (об'єкта);

внутрішньобудівельний титул будови (об'єкта);

титул на виконання проектно-вишукувальних робіт для будівництва;

договір підряду (контракту) з визначенням вартості будівництва, форм розрахунків за виконані роботи та майнової відповідальності за порушення умов договору підряду (контракту). У разі здійснення будівництва кількома генеральними підрядниками договір підряду (контракт) подається окремо щодо кожного виконавця, а для перехідних об'єктів - додатковий договір до договору підряду (контракту) на виконання робіт у поточному році;

наказ (рішення) про затвердження проектно-кошторисної документації на відповідну чергу будівництва, пусковий комплекс, об'єкт або створення нових робочих місць.

5. Підприємства, на яких створюються за рахунок коштів Фонду нові робочі місця, подають облдержадміністраціям квартальні і річний звіти про використання зазначених коштів до 15 числа місяця, що настає за звітним періодом.

Облдержадміністрації подають Фонду, Мінфіну, Мінекономіки, Мінпраці звіти щокварталу до 20 числа першого місяця наступного періоду та в цілому за рік - до 1 лютого 2005 р. за формою, затвердженою Фондом.

6. Контроль за цільовим використанням облдержадміністраціями коштів Фонду здійснюється ГоловКРУ.
