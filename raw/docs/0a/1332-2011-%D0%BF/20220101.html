КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 грудня 2011 р. N 1332 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1167 ( 1167-2021-п ) від 10.11.2021 }

Про внесення змін до постанов Кабінету Міністрів України від 21 грудня 2005 р. N 1251 і від 28 квітня 2009 р. N 425

{ Із змінами, внесеними згідно з Постановою КМ N 580 ( 580-2019-п ) від 26.06.2019 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 21 грудня 2005 р. N 1251 ( 1251-2005-п ) "Про затвердження Порядку організації виїзду дітей за кордон на відпочинок та оздоровлення" (Офіційний вісник України, 2005 р., N 52, ст. 3294; 2007 р., N 12, ст. 430; 2008 р., N 68, ст. 2268) і від 28 квітня 2009 р. N 425 ( 425-2009-п ) "Про затвердження Порядку ведення Державного реєстру дитячих закладів оздоровлення та відпочинку" (Офіційний вісник України, 2009 р., N 33, ст. 1141; 2010 р., N 94, ст. 3346; 2011 р., N 61, ст. 2435) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 грудня 2011 р. N 1332

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 21 грудня 2005 р. N 1251 ( 1251-2005-п ) і від 28 квітня 2009 р. N 425 ( 425-2009-п )

1. У постанові Кабінету Міністрів України від 21 грудня 2005 р. N 1251 ( 1251-2005-п ):

1) у пункті 3 слова "Державним комітетом статистики" замінити словами "Державною службою статистики";

2) у тексті постанови ( 1251-2005-п ) слова "Міністерству у справах сім'ї, молоді та спорту" замінити словами "Міністерству соціальної політики";

3) у Порядку організації виїзду дітей за кордон на відпочинок та оздоровлення ( 1251-2005-п ), затвердженому зазначеною постановою:

в абзаці четвертому підпункту 8 пункту 6 слова "Міністерством освіти і науки Автономної Республіки Крим" і "МОН" замінити відповідно словами "Міністерством освіти і науки, молоді та спорту Автономної Республіки Крим" і "МОНмолодьспортом";

у пункті 13 слово "Держкомстат" замінити словом "Держстат";

у тексті Порядку ( 1251-2005-п ) слова "Міністерство у справах сім'ї, молоді та спорту" в усіх відмінках замінити словом "Мінсоцполітики", а слова "Міністерство у справах молоді, сім'ї та гендерної політики Автономної Республіки Крим" в усіх відмінках - словами "Міністерство освіти і науки, молоді та спорту Автономної Республіки Крим" у відповідному відмінку.
