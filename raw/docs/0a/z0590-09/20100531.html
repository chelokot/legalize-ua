НАКАЗ

16.06.2009 N 2026

Зареєстровано в Міністерстві юстиції України 2 липня 2009 р. за N 590/16606

{ Наказ втратив чинність на підставі Наказу Міністерства України у справах сім'ї, молоді та спорту N 1070 ( z0328-10 ) від 26.04.2010 }

Про внесення змін до наказу Міністерства України у справах сім'ї, молоді та спорту від 18.04.2006 N 1228

Відповідно до постанови Кабінету Міністрів України від 21.12.2005 N 1251 ( 1251-2005-п ) "Про затвердження Порядку організації виїзду дітей за кордон на відпочинок та оздоровлення" (зі змінами) НАКАЗУЮ:

1. Унести до Інструкції щодо заповнення Форми звітності N 1-озк "Звіт про виїзд організованих груп дітей за кордон на відпочинок та оздоровлення", затвердженої наказом Мінсім'ямолодьспорту від 18.04.2006 N 1228 ( z0503-06 ), зареєстрованої у Міністерстві юстиції України 28.04.2006 за N 503/12377, такі зміни:

слово "дозволів" замінити відповідно словом "згод".

2. Забезпечити державну реєстрацію цього наказу в Міністерстві юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Драпушка Р.Г.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр Ю.О.Павленко
