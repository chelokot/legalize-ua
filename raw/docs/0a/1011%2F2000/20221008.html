УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 682/2022 ( 682/2022 ) від 01.10.2022 }

Про внесення змін до Указу Президента України від 23 липня 1998 року N 817

Відповідно до Указу Президента України від 15 грудня 1999 року N 1573 ( 1573/99 ) "Про зміни у структурі центральних органів виконавчої влади" постановляю:

У статтях 7 і 8 Указу Президента України від 23 липня 1998 року N 817 ( 817/98 ) "Про деякі заходи з дерегулювання підприємницької діяльності" слова "Державним комітетом України з питань розвитку підприємництва" замінити словами "Державним комітетом України з питань регуляторної політики та підприємництва".

Президент України Л.КУЧМА
