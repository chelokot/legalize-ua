{ Наказ втратив чинність на підставі Наказу Фонду державного майна N 522 ( z0516-17 ) від 04.04.2017 }

Про внесення змін в додаток до наказу ФДМ України від 20.08.96 N 961

У зв'язку з технічною помилкою, що допущена у додатку до наказу Фонду державного майна України від 20.08.96 N 961 ( z0470-96 ) "Про затвердження коефіцієнтів індексації вартості оборотних засобів, зданих в оренду", НАКАЗУЮ:

1. В додаток до наказу Фонду державного майна від 20.08.96 N 961 ( z0470-96 ) внести такі зміни: слова "до 1 липня 1992 року" замінити на слова "до 1 жовтня 1992 року".

2. Управлінню нормативно-методичного забезпечення оцінки майна зареєструвати наказ у Міністерстві юстиції.

3. Контроль за виконанням цього наказу покласти на заступника Голови Фонду О.Бондаря.
