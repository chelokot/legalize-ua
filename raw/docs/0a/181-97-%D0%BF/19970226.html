Про врегулювання окремих питань взаєморозрахунків із належних до бюджетів платежів

Стан: Втратив чинність

Ідентифікатор: 181-97-п

Текст документа від 26.02.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 лютого 1997 р. N 181 Київ

( Постанова втратила чинність на підставі Постанови КМ N 255 ( 255-97-п ) від 21.03.97 )

Про врегулювання окремих питань взаєморозрахунків із належних до бюджетів платежів

( Із змінами, внесеними згідно з Постановою КМ N 191 ( 191-97-п ) від 26.02.97 )

З метою врегулювання окремих питань взаєморозрахунків із належних до бюджетів платежів Кабінет Міністрів України постановляє:

1. На виняток з постанови Кабінету Міністрів України від 31 грудня 1996 р. N 1578 ( 1578-96-п ) "Про припинення взаємозаліку коштів з фінансування видатків на погашення недоїмки із належних до бюджету платежів" проводити в особливих випадках прямі бездисконтні взаємозаліки коштів на погашення недоїмки із належних до бюджетів платежів згідно з Тимчасовими методичними вказівками про порядок проведення взаємозаліку коштів по фінансуванню видатків в рахунок погашення недоїмки по належних до бюджету платежах, затвердженими наказом Міністерства фінансів і Національного банку від 23 вересня 1996 р N 200/84 ( v0200201-96 ). ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 191 ( 191-97-п ) від 26.02.97 )

Взаємозалік із заборгованості бюджетних установ проводити в межах передбачених обсягів фінансування за відповідною статтею кошторису.

2. Міністру фінансів України, Голові Ради міністрів Автономної Республіки Крим, головам обласних, Київської та Севастопольської міських державних адміністрацій у десятиденний термін після прийняття рішення про проведення взаємозаліків інформувати Кабінет Міністрів України про підстави та обсяги їх проведення стосовно кожного заліку окремо.

3. Міністерству фінансів забезпечити ведення зведеного реєстру заліків та щомісячно подавати його Кабінетові Міністрів України.
