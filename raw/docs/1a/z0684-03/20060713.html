ЗАТВЕРДЖЕНО Рішення Державної комісії з цінних паперів та фондового ринку 08.07.2003 N 304

Зареєстровано в Міністерстві юстиції України 5 серпня 2003 р. за N 684/8005

ПОЛОЖЕННЯ про порядок реорганізації інвестиційних фондів та інвестиційних компаній, створених відповідно до Указу Президента України від 19.02.94 N 55 ( 55/94 ) "Про інвестиційні фонди та інвестиційні компанії", в інститути спільного інвестування

Це Положення розроблено відповідно до Цивільного кодексу УРСР ( 1540-06 ), Законів України "Про господарські товариства" ( 1576-12 ), "Про інститути спільного інвестування (пайові та корпоративні інвестиційні фонди)" ( 2299-14 ), "Про підприємства в Україні" ( 887-12 ), "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ), "Про Національну депозитарну систему та особливості електронного обігу цінних паперів в Україні" ( 710/97-ВР ), Указів Президента України від 19 лютого 1994 року N 55 ( 55/94 ) "Про інвестиційні фонди та інвестиційні компанії", від 7 серпня 1999 року N 968 ( 968/99 ) "Про заходи щодо забезпечення захисту прав учасників інвестиційних фондів та інвестиційних компаній", постанови Кабінету Міністрів України від 25 травня 1998 року N 740 ( 740-98-п ) "Про порядок державної реєстрації суб'єкта підприємницької діяльності" та нормативно-правових актів Державної комісії з цінних паперів та фондового ринку (далі - Комісія).

1. Загальні положення

1.1. Відповідно до цього Положення визначається послідовність дій та організаційних заходів, які потрібно здійснити в процесі реорганізації інвестиційних фондів та інвестиційних компаній, що створені відповідно до Указу Президента України від 19.02.94 N 55 ( 55/94 ) "Про інвестиційні фонди та інвестиційні компанії" (далі - інвестиційний фонд, інвестиційна компанія), в інститути спільного інвестування (пайові та корпоративні інвестиційні фонди) (далі - ІСІ), з метою забезпечення захисту прав їх учасників як інвесторів на ринку цінних паперів в Україні.

1.2. Це Положення застосовується виключно в разі реорганізації інвестиційних фондів, інвестиційних компаній, що здійснювали спільне інвестування до набуття чинності Законом України "Про інститути спільного інвестування (пайові та корпоративні інвестиційні фонди)" ( 2299-14 ), в ІСІ.

1.3. Реорганізація інвестиційних фондів, інвестиційних компаній в ІСІ здійснюється:

після закінчення заявленого терміну діяльності закритого інвестиційного фонду або закритого взаємного фонду інвестиційної компанії;

до закінчення заявленого терміну діяльності закритого інвестиційного (взаємного) фонду за умови скорочення його терміну діяльності та реєстрації відповідних змін до інвестиційної декларації та інформації про випуск інвестиційних сертифікатів і їх публікації згідно з вимогами чинного законодавства України;

{ Абзац четвертий пункту 1.3 розділу 1 виключено на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

1.4. Реорганізація інвестиційних фондів та інвестиційних компаній в інститути спільного інвестування можлива за умови стовідсоткової згоди учасників інвестиційних фондів або взаємних фондів інвестиційних компаній, наданої в письмовому вигляді. { Розділ 1 доповнено пунктом 1.4 згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

1.5. Реорганізація інвестиційних фондів та інвестиційних компаній в ІСІ здійснюється за рішенням вищого органу інвестиційного фонду або інвестиційної компанії, яке приймається відповідно до статуту та згідно з вимогами Закону України "Про господарські товариства" ( 1576-12 ), з обов'язковим повідомленням Комісії протягом 3 робочих днів з дати прийняття цього рішення. Таке рішення оформлюється протоколом засідання загальних зборів, до якого обов'язково додається баланс інвестиційного фонду або інвестиційної компанії (у тому числі баланс взаємного фонду), довідка про вартість чистих активів інвестиційного фонду або взаємного фонду інвестиційної компанії, звіт про фінансові результати та їх вкладення, що складені за станом на дату прийняття рішення про таку реорганізацію, текст повідомлення про реорганізацію, документи, що підтверджують згоду учасників інвестиційних фондів або взаємних фондів інвестиційних компаній, а також план реорганізації. { Абзац перший пункту 1.5 розділу 1 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

План реорганізації погоджується Комісією. { Пункт 1.5 розділу 1 доповнено абзацом другим згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

1.6. План реорганізації повинен бути складений за формою, передбаченою додатком 1 до цього Положення. За результатами виконання кожного етапу заходів щодо реорганізації керівник інвестиційного фонду, інвестиційної компанії зобов'язаний інформувати Комісію протягом 3 робочих днів з дати закінчення етапу реорганізації з обов'язковим наданням відповідних документів (копій документів), що підтверджують виконання заходів щодо реорганізації.

1.7. Комісія розглядає документи, що подаються відповідно до пунктів 1.5 та 1.6 цього Положення, протягом 5 робочих днів з дати їх отримання. { Пункт 1.7 розділу 1 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

1.8. Реорганізація інвестиційних фондів та інвестиційних компаній провадиться без зупинення їх діяльності.

1.9. Реорганізація інвестиційного фонду, інвестиційної компанії у пайовий інвестиційний фонд без створення компанії з управління активами заборонена.

1.10. Інвестиційні фонди з метою створення ІСІ можуть реорганізуватися в:

корпоративний інвестиційний фонд;

компанію з управління активами (далі - КУА) з подальшим створенням цією КУА пайового інвестиційного фонду.

1.11. Інвестиційні компанії з метою створення ІСІ можуть реорганізуватися в:

корпоративний інвестиційний фонд;

КУА з подальшим створенням цією КУА пайового інвестиційного фонду за рахунок активів (майна) взаємного фонду інвестиційної компанії, що реорганізовується.

1.12. Реорганізація двох або декількох інвестиційних фондів (взаємних фондів інвестиційних компаній) з метою створення за рахунок майна (активів) цих фондів одного здійснюється за умови попередньої реорганізації цих фондів шляхом приєднання/злиття одного або декількох фондів до іншого інвестиційного (взаємного) фонду відповідно до вимог чинного законодавства України.

{ Пункт 1.13 розділу 1 виключено на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

1.13. Унаслідок реорганізації закритих інвестиційних фондів (закритих взаємних фондів інвестиційних компаній) можуть створюватись ІСІ будь-якого типу.

1.14. У разі, якщо хоча б одним з учасників інвестиційного фонду, інвестиційної компанії є фізична особа, можлива реорганізація в ІСІ лише диверсифікованого виду або корпоративний інвестиційний фонд недиверсифікованого виду.

{ Пункт 1.15 розділу 1 виключено на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

1.15. З дати прийняття рішення про реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ до активів такого інвестиційного фонду або взаємного фонду інвестиційної компанії не застосовується обмеження п. 17 Положення про інвестиційні фонди та інвестиційні компанії, затвердженого Указом Президента України від 19.02.94 N 55 ( 55/94 ), щодо утримання в цінних паперах не менше ніж 70 % активів фонду.

1.16. У разі реорганізації інвестиційного фонду, інвестиційної компанії в КУА необхідно додержуватися вимог чинного законодавства України щодо мінімального розміру статутного фонду (капіталу) компаній з управління активами та співвідношення між статутним фондом (капіталом) і вартістю активів інвестиційного фонду, що перебувають в управлінні КУА. Приведення статутного фонду (капіталу) у відповідність до вимог законодавства здійснюється (у разі необхідності) шляхом збільшення статутного фонду (капіталу):

інвестиційного фонду, інвестиційної компанії, що реорганізуються, - до дати прийняття відповідного рішення про реорганізацію;

КУА, створеної в процесі реорганізації, - після її державної реєстрації.

1.17. Документи на скасування реєстрації випуску інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії при реорганізації інвестиційного фонду або інвестиційної компанії в ІСІ подаються до Комісії відповідно до розділу 3 цього Положення.

1.18. Загальний термін реорганізації інвестиційного фонду, інвестиційної компанії в ІСІ не повинен перевищувати 1 (одного) року з моменту прийняття відповідного рішення.

1.19. Процес реорганізації інвестиційного фонду, інвестиційної компанії в ІСІ передбачає здійснення заходів, передбачених цим Положенням.

2. Реорганізація інвестиційних фондів, інвестиційних компаній в ІСІ

2.1. При реорганізації інвестиційного фонду, інвестиційної компанії усі їх майнові права та зобов'язання переходять до корпоративного інвестиційного фонду або до компанії з управління активами, які утворюються внаслідок реорганізації. У разі створення ІСІ шляхом виділення з інвестиційного фонду, інвестиційної компанії до корпоративного інвестиційного фонду або компанії з управління активами, що створюються, переходять майнові права та зобов'язання, пов'язані із здійсненням діяльності із спільного інвестування таким інвестиційним фондом (інвестиційною компанією).

2.2. Учасник інвестиційного фонду, інвестиційної компанії у зв'язку з реорганізацією інвестиційного фонду, інвестиційної компанії в ІСІ має право:

у разі небажання бути учасником новоствореного ІСІ пред'явити для викупу належні йому на праві власності інвестиційні сертифікати в терміни та за ціною, що визначені в підпункті 2.3.7 цього Положення;

стати власником цінних паперів новоствореного ІСІ за умови заміни належних йому на праві власності інвестиційних сертифікатів на цінні папери новоствореного ІСІ відповідно до вимог підпункту 2.3.14.3 пункту 2.3 цього Положення.

2.3. Реорганізація інвестиційних фондів, інвестиційних компаній передбачає проведення таких дій та організаційних заходів:

2.3.1. Прийняття вищим органом інвестиційного фонду, інвестиційної компанії рішення про:

а) реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ;

б) затвердження балансу, довідки про вартість чистих активів, звіту про фінансові результати та їх вкладення на дату прийняття рішення про реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ;

в) затвердження тексту повідомлення про реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ та викуп їх інвестиційних сертифікатів. Зазначене повідомлення повинно містити відомості про:

реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ (із зазначенням їх повної назви, ідентифікаційного коду та місцезнаходження, повної назви ІСІ, що створюється внаслідок реорганізації, та причин, що обумовили прийняття рішення про реорганізацію);

право учасників інвестиційного фонду, інвестиційної компанії замінити належні їм інвестиційні сертифікати на цінні папери ІСІ (після настання дати початку заміни інвестиційних сертифікатів) або в разі небажання стати учасником новоствореного ІСІ пред'явити до викупу належні їм інвестиційні сертифікати (протягом терміну, установленого для викупу інвестиційних сертифікатів);

термін, установлений для прийняття заяв про викуп інвестиційних сертифікатів учасників, які не бажають стати учасниками новоствореного ІСІ;

термін, установлений для викупу інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії, що реорганізовується, у власників цих інвестиційних сертифікатів, які не бажають стати учасниками новоствореного ІСІ;

місце та ціну викупу інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії, що реорганізовується;

умови заміни інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії на цінні папери новоствореного ІСІ;

місце заміни інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії на цінні папери новоствореного ІСІ із зазначенням, що дату початку заміни сертифікатів буде повідомлено в окремій публікації;

г) затвердження установчих документів товариства, яке має намір отримати ліцензію на здійснення професійної діяльності з управління активами ІСІ;

ґ) затвердження установчих документів (для корпоративного інвестиційного фонду).

2.3.2. Здійснення публікації повідомлення про реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ та викуп їх інвестиційних сертифікатів. Зазначена публікація повинна бути здійснена протягом 5 робочих днів з дати прийняття відповідного рішення в одному з офіційних видань Верховної Ради України, Кабінету Міністрів України або Державної комісії з цінних паперів та фондового ринку. Зазначену публікацію слід повторити не менше ніж двічі протягом терміну, установленого для прийняття заяв про викуп інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії відповідно до підпункту 2.3.3 пункту 2.3 цього Положення. Здійснення публікації такого повідомлення забезпечується уповноваженою особою інвестиційного фонду, інвестиційної компанії.

2.3.3. Прийняття та опрацювання заяв від учасників інвестиційного фонду, інвестиційної компанії про викуп належних їм інвестиційних сертифікатів. Термін прийняття зазначених заяв повинен становити не більше трьох місяців з дати першої публікації, здійсненої відповідно до підпункту 2.3.2 цього Положення. Термін опрацювання заяв від учасників інвестиційного фонду інвестиційної компанії про викуп належних їм інвестиційних сертифікатів не повинен перевищувати одного місяця з дати закінчення прийняття таких заяв. У разі отримання заяв від усіх учасників інвестиційного фонду, інвестиційної компанії терміни прийняття та опрацювання таких заяв можуть бути скорочені. { Підпункт 2.3.3 пункту 2.3 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

2.3.4. Державна реєстрація товариства, яке має намір отримати ліцензію на здійснення професійної діяльності з управління активами ІСІ.

2.3.5. Реєстрація випуску акцій товариства, яке має намір отримати ліцензію на здійснення професійної діяльності з управління активами ІСІ в разі прийняття рішення про збільшення статутного фонду відповідно до абзацу другого пункту 1.16 цього Положення в порядку, передбаченому нормативно-правовими актами Комісії. { Підпункт 2.3.5 пункту 2.3 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

2.3.6. Отримання ліцензії на здійснення професійної діяльності з управління активами ІСІ у разі реорганізації, передбачених абзацом другим пункту 1.10 та абзацом другим пункту 1.11 цього Положення. { Підпункт 2.3.6 пункту 2.3 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

2.3.7. Здійснення викупу інвестиційних сертифікатів, пред'явлених їх власниками, які не бажають стати учасниками новоствореного ІСІ протягом двох місяців з дати закінчення опрацювання заяв від учасників.

2.3.7.1. Такий викуп здійснюється за ціною, розрахованою відповідно до вартості чистих активів на дату прийняття рішення про реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ (згідно з вимогами нормативно-правових актів Комісії).

2.3.7.2. Якщо вартість чистих активів у розрахунку на один інвестиційний сертифікат на дату прийняття рішення про реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ менша за номінальну вартість інвестиційного сертифіката, різниця учасникам покривається за рахунок коштів засновників інвестиційного фонду, інвестиційної компанії.

Відшкодування такої різниці учасникам провадиться за рахунок частки коштів в активах фонду, належної засновникам цього фонду як акціонерам. Засновники інвестиційного фонду відповідають за зобов'язаннями фонду перед його учасниками тільки в межах кількості належних їм акцій.

Відшкодування зазначеної різниці учасникам взаємного фонду інвестиційної компанії провадиться за рахунок частки коштів в активах взаємного фонду, яка припадає на належні інвестиційній компанії інвестиційні сертифікати (у разі передачі компанією майна у взаємний фонд). У разі недостатності цих коштів для розрахунків з учасниками взаємного фонду різниця відшкодовується за рахунок майна (коштів) компанії як засновника взаємного фонду. Засновники інвестиційної компанії несуть відповідальність перед учасниками в межах кількості належних їм акцій (корпоративних прав) статутного фонду.

2.3.7.3. Розрахунок з учасниками може бути здійснений грошовими коштами та/або цінними паперами (за письмовою згодою учасника) з урахуванням вимог Положення про порядок розрахунків з учасниками при ліквідації інвестиційних фондів або взаємних фондів інвестиційних компаній, затвердженого наказом Фонду державного майна України, Державної комісії з цінних паперів та фондового ринку від 17.11.99 N 2167/321 ( z0920-99 ). Після завершення терміну викупу, установленого підпунктом 2.3.7 пункту 2.3 цього Положення, інвестиційні сертифікати інвестиційного фонду, інвестиційної компанії не підлягають викупу, а замінюються на цінні папери новоствореного ІСІ.

2.3.7.4. До викупу та для заміни учасниками інвестиційних фондів, інвестиційних компаній пред'являються інвестиційні сертифікати, сертифікати інвестиційних сертифікатів або виписки з рахунку власника в зберігача.

2.3.7.5. Інвестиційні сертифікати (сертифікати інвестиційних сертифікатів або виписки з рахунку власника в зберігача) учасників, які подали заявки про викуп належних їм інвестиційних сертифікатів, але протягом установленого терміну не звернулись в інвестиційних фонд, інвестиційну компанію за належними їм коштами, підлягають заміні на цінні папери новоствореного ІСІ.

2.3.7.6. Викуплені інвестиційні сертифікати (сертифікати інвестиційних сертифікатів) передаються до КУА, де зберігаються протягом трьох років до моменту їх передачі до її архіву.

2.3.8. Прийняття вищим органом корпоративного інвестиційного фонду або компанії з управління активами рішення про:

а) результати проведення викупу інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії;

б) затвердження передавального балансу (акта), який надає інвестиційний фонд, інвестиційна компанія до компанії з управління активами пайового інвестиційного фонду (для пайового інвестиційного фонду) або корпоративного інвестиційного фонду (для корпоративного інвестиційного фонду);

в) затвердження регламенту ІСІ;

г) затвердження проспекту емісії цінних паперів ІСІ;

ґ) затвердження договорів з компанією з управління активами (для корпоративного інвестиційного фонду), реєстратором, зберігачем, аудитором, незалежним оцінювачем майна, торговцем цінними паперами (у разі необхідності);

д) створення спостережної (наглядової) ради (для корпоративного інвестиційного фонду);

е) затвердження тексту повідомлення про початок заміни інвестиційних сертифікатів інвестиційних фондів, інвестиційних компаній на цінні папери новоствореного ІСІ;

є) скасування випуску інвестиційних сертифікатів.

{ Підпункт 2.3.8 пункту 2.3 розділу 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

2.3.9. Реєстрація випуску акцій з метою формування початкового статутного фонду (капіталу) відповідно до вимог чинного законодавства України - для корпоративного інвестиційного фонду. При реєстрації випуску акцій з метою формування початкового статутного фонду (капіталу) корпоративного венчурного інвестиційного фонду публікація інформації про випуск акцій не здійснюється.

2.3.10. Укладання договорів з компанією з управління активами (у разі створення корпоративного інвестиційного фонду), реєстратором (у разі необхідності), зберігачем, аудитором, незалежним оцінювачем майна, торговцем цінними паперами (у разі необхідності).

2.3.11. Реєстрація регламенту ІСІ відповідно до вимог чинного законодавства України.

2.3.12. Реєстрація проспекту емісії цінних паперів ІСІ відповідно до вимог чинного законодавства України.

2.3.13. Здійснення публікації проспекту емісії цінних паперів ІСІ (при їх розміщенні шляхом прилюдної пропозиції) та повідомлення про заміну інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії на цінні папери новоствореного ІСІ.

2.3.14. Заміна інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії на цінні папери новоствореного ІСІ.

2.3.14.1. Дата початку заміни інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії на цінні папери новоствореного ІСІ встановлюється з дати закінчення розрахунків з учасниками, які пред'явили до викупу належні їм інвестиційні сертифікати.

2.3.14.2. Обмеження терміну заміни інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії на цінні папери новоствореного ІСІ не допускається.

2.3.14.3. Заміна інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії на цінні папери новоствореного ІСІ здійснюється у співвідношенні один до одного (за умови їх однакової номінальної вартості) або у відповідному співвідношенні (за умови випуску інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії номінальною вартістю, кратною номінальній вартості цінного папера ІСІ). При цьому повинно бути забезпечено виконання умов неподільності інвестиційного сертифіката та заміни інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії на цілу кількість цінних паперів новостворених ІСІ.

2.3.14.4. Цінні папери новостворених ІСІ у кількості, яку не замінили учасникам інвестиційних фондів, інвестиційних компаній, що реорганізовуються, не підлягають розміщенню та вважаються такими, що перебувають в обігу. Такі цінні папери зберігаються компанією з управління активами, що здійснює управління активами відповідного ІСІ (у разі випуску в документарній формі), або зараховуються на рахунок учасників у зберігача (у разі випуску в бездокументарній формі). Такі цінні папери враховуються при визначенні вартості чистих активів у розрахунку на 1 цінний папір ІСІ, а також при визначенні кворуму для визнання загальних зборів інвестиційного фонду правомочними та нарахуванні дивідендів.

2.3.15. Скасування реєстрації випуску інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії та інформації про їх випуск відповідно до пункту 3 цього Положення.

2.3.16. Скасування реєстрації випуску акцій інвестиційного фонду, інвестиційної компанії та інформації про їх випуск відповідно до нормативно-правових актів Комісії.

3. Порядок подання документів для скасування реєстрації випуску інвестиційних сертифікатів та інформації про їх випуск інвестиційного фонду, інвестиційної компанії при реорганізації їх в ІСІ

3.1. Для скасування реєстрації випуску інвестиційних сертифікатів та інформації про їх випуск документи, визначені пунктами 3.2, 3.3 цього Положення, подаються до Комісії компанією з управління активами (у випадку реорганізації, передбаченому абзацом другим пункту 1.10 та абзацом другим пункту 1.11 цього Положення) або керівником корпоративного інвестиційного фонду (у випадку реорганізації, передбаченому абзацом першим пункту 1.10 та абзацом першим пункту 1.11 цього Положення). { Пункт 3.1 розділу 3 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

3.2. Якщо інвестиційний фонд, інвестиційна компанія не здійснювали розміщення інвестиційних сертифікатів при реорганізації їх в ІСІ, для скасування реєстрації випуску інвестиційних сертифікатів до Комісії подаються такі документи:

а) заява про скасування реєстрації випуску інвестиційних сертифікатів, підписана уповноваженою особою компанії з управління активами або уповноваженою особою корпоративного інвестиційного фонду та скріплена печаткою компанії з управління активами або корпоративного інвестиційного фонду (згідно з додатком 2 до цього Положення);

б) протокол рішення вищого органу інвестиційного фонду, інвестиційної компанії щодо прийняття рішення про реорганізацію із зазначенням повної назви ІСІ, що буде створюватись у результаті перетворення інвестиційного фонду, інвестиційної компанії. Цей протокол повинен містити рішення про:

реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ із зазначенням повної назви ІСІ, що виникає внаслідок реорганізації, та причин, що обумовили прийняття рішення про реорганізацію;

затвердження балансу, довідки про вартість чистих активів, звіт про фінансові результати, на дату прийняття рішення про реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ;

в) баланс, звіт про фінансові результати, засвідчені висновком аудитора (аудиторської фірми) інвестиційного фонду, взаємного фонду інвестиційної компанії на дату прийняття рішення про реорганізацію; { Підпункт "в" пункту 3.2 розділу 3 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

г) засвідчені підписом та печаткою уповноваженої особи інвестиційного фонду, інвестиційної компанії, депозитарію довідка про розрахунок вартості чистих активів, довідку про фінансові вкладення, на дату прийняття рішення про реорганізацію, розраховані відповідно до вимог чинного законодавства України; { Підпункт "г" пункту 3.2 розділу 3 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

ґ) оригінал (оригінали) свідоцтва про реєстрацію випуску (випусків) інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії;

д) текст зареєстрованої в установленому порядку інформації про випуск інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії;

е) довідка від депозитарію, зберігача, аудитора про те, що розміщення інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії не здійснювалося;

є) засвідчений підписом та печаткою уповноваженої особи інвестиційного фонду, інвестиційної компанії та компанії з управління активами або корпоративного інвестиційного фонду, а також аудитора (аудиторської фірми) передавальний баланс (акт).

3.3. У разі, якщо інвестиційний фонд, інвестиційна компанія здійснювали розміщення інвестиційних сертифікатів для скасування реєстрації випуску інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії та інформації про їх випуск при реорганізації їх в ІСІ, до Комісії подаються такі документи:

а) заява про скасування реєстрації випуску інвестиційних сертифікатів, підписана уповноваженою особою компанії з управління активами або уповноваженою особою корпоративного інвестиційного фонду та засвідчена печаткою компанії з управління активами або корпоративного інвестиційного фонду (згідно з додатком 2 до цього Положення);

б) протокол рішення вищого органу інвестиційного фонду, інвестиційної компанії щодо прийняття рішення про реорганізацію із зазначенням повної назви ІСІ, що буде створюватись у результаті перетворення інвестиційного фонду, інвестиційної компанії. Цей протокол повинен містити рішення про:

реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ;

затвердження балансу, довідки про вартість чистих активів, звіту про фінансові результати та їх вкладення на дату прийняття рішення про реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ;

затвердження текстів повідомлення про реорганізацію інвестиційного фонду, інвестиційної компанії в ІСІ та викуп їх інвестиційних сертифікатів відповідно до абзацу "в" п 2.3.1 Положення;

в) копії публікацій, здійснених відповідно до вимог пункту 2.3.2 цього Положення;

г) баланс, звіт про фінансові результати, засвідчені висновком аудитора (аудиторської фірми) інвестиційного фонду, взаємного фонду інвестиційної компанії на дату прийняття рішення про реорганізацію; { Підпункт "г" пункту 3.3 розділу 3 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

ґ) засвідчені підписом та печаткою уповноваженої особи інвестиційного керуючого, депозитарію довідка про розрахунок вартості чистих активів, довідку про фінансові вкладення на дату прийняття рішення про реорганізацію розраховані відповідно до вимог чинного законодавства України; { Підпункт "ґ" пункту 3.3 розділу 3 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 540 ( z0979-06 ) від 13.07.2006 }

д) оригінал (оригінали) свідоцтва про реєстрацію випуску (випусків) інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії;

е) текст зареєстрованої в установленому порядку інформації про випуск інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії;

є) засвідчений підписом та печаткою уповноваженої особи інвестиційного фонду, інвестиційної компанії та компанії з управління активами або корпоративного інвестиційного фонду, а також аудитора (аудиторської фірми) передавальний баланс (акт);

ж) засвідчений підписом та печаткою депозитарію, компанії з управління активами або корпоративного інвестиційного фонду звіт про розрахунки з учасниками, який надається за кожним взаємним фондом інвестиційної компанії окремо. Звіт про розрахунки з учасниками повинен містити відомості про:

дату та місце складання звіту;

відомості про випуск інвестиційних сертифікатів;

кількість розміщених інвестиційних сертифікатів серед юридичних осіб;

кількість розміщених інвестиційних сертифікатів серед фізичних осіб;

кількість викуплених інвестиційних сертифікатів;

ціну та спосіб розрахунків з учасниками;

реквізити документів, що підтверджують перехід права власності на цінні папери;

кількість інвестиційних сертифікатів, що залишились не викупленими.

3.4. Документи, які подаються для скасування реєстрації випуску інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії відповідно до пунктів 3.2, 3.3 цього Положення, подаються до Комісії одним пакетом документів за всіма випусками інвестиційних сертифікатів.

3.5. Скасування реєстрації випуску інвестиційних сертифікатів та інформації про їх випуск проводиться протягом 30 днів з моменту надходження до Комісії документів, наданих відповідно до пункту 3.1 або пункту 3.2 Положення. Висновок щодо скасування реєстрації випуску інвестиційних сертифікатів та інформації про їх випуск здійснює уповноважена особа Комісії.

3.6. У разі відповідності поданих документів вимогам чинного законодавства України заявнику видається розпорядження про скасування реєстрації випуску інвестиційних сертифікатів та інформації про їх випуск відповідно до додатка 3 цього Положення (якщо розміщення інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії не здійснювалося) або додатка 4 цього Положення (у разі здійснення розміщення інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії).

3.7. Відмова в скасуванні реєстрації випуску інвестиційних сертифікатів та інформації про їх випуск надається у разі невідповідності поданих документів вимогам чинного законодавства України.

3.8. Повідомлення про відмову в скасуванні реєстрації випуску інвестиційних сертифікатів та інформації про їх випуск доводиться до заявника письмово. У разі відмови документи, подані на скасування реєстрації випуску інвестиційних сертифікатів та інформації про їх випуск, заявнику не повертаються, за винятком оригіналу (оригіналів) свідоцтва про реєстрацію випуску (випуски) інвестиційних сертифікатів інвестиційного фонду, інвестиційної компанії.

3.9. У разі, коли скасування реєстрації випуску інвестиційних сертифікатів та інформації про їх випуск у встановлений термін не проведено або в ній відмовлено з мотивів, які заявник вважає необгрунтованими, він може звернутися до господарського суду.

4. Прикінцеві положення

4.1. Контроль за дотриманням процедури реорганізації інвестиційного фонду, інвестиційної компанії в ІСІ здійснюється Комісією в межах компетенції, визначеної чинним законодавствам України.

4.2. Порушення вимог та обмежень, установлених цим Положенням, передбачає відповідальність відповідно до Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ).
