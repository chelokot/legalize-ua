Кабінет Міністрів України; Постанова від 16.02.1998 № 160

Про заходи щодо посилення контролю за обгрунтованістю проектів інформатизації діяльності центральних органів виконавчої влади

Стан: Втратив чинність

Ідентифікатор: 160-98-п

Текст документа від 03.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 лютого 1998 р. N 160 Київ

Про заходи щодо посилення контролю за обгрунтованістю проектів інформатизації діяльності центральних органів виконавчої влади

{ Із змінами, внесеними згідно з Постановами КМ N 1758 ( 1758-2001-п ) від 27.12.2001 N 738 ( 738-2009-п ) від 17.07.2009 N 675 ( 675-2010-п ) від 21.07.2010 N 915 ( 915-2011-п ) від 31.08.2011 }

На виконання Указу Президента України від 21 липня 1997 р. N 663 ( 663/97 ) Кабінет Міністрів України постановляє:

1. Установити, що питання бюджетного фінансування проектів інформатизації діяльності центральних органів виконавчої влади розглядаються лише після погодження цих проектів (за результатами їх експертизи) з Державним агентством з питань науки, інновацій та інформатизації за наявності обгрунтувань кінцевої ефективності створюваних засобів та мереж, вимог до функцій і складу програмно-технічного забезпечення, його нормативно-правових, організаційно-функціональних та інформаційно-лінгвістичних елементів, а закупівля зазначеними органами комп'ютерного та мережного обладнання, інших засобів інформатизації за рахунок бюджетних коштів провадиться лише за наявності відповідних проектів.

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 1758 ( 1758-2001-п ) від 27.12.2001, N 738 ( 738-2009-п ) від 17.07.2009, N 675 ( 675-2010-п ) від 21.07.2010, N 915 ( 915-2011-п ) від 31.08.2011 }

2. Контроль за виконанням цієї постанови покласти на Віце-прем'єр-міністра України Смолія В.А.
