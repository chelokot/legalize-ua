КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 травня 2002 р. N 639 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 609 ( 609-2015-п ) від 05.08.2015 }

Про внесення змін до переліку органів ліцензування

Кабінет Міністрів України постановляє:

1. Внести до переліку органів ліцензування, затвердженого постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001; 2001 р., N 18, ст. 827, N 29, ст. 144), такі зміни:

1) позицію 4 доповнити абзацом такого змісту:

"експорт, імпорт дисків для лазерних систем зчитування, обладнання для їх виробництва";

2) позицію 5 викласти у такій редакції:

"5. Державний виробництво дисків для лазерних департамент систем зчитування"; інтелектуальної власності МОН

3) у позиції 31 виключити абзац:

"надання освітніх послуг загальноосвітніми навчальними закладами".

2. Ця постанова набирає чинності з 21 квітня 2002 року.
