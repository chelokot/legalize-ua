Зареєстровано в Міністерстві юстиції України 26 березня 2009 р. за N 275/16291

{ Постанова втратила чинність на підставі Постанови Національної комісії, що здійснює державне регулювання у сфері енергетики N 1259 ( z1827-12 ) від 04.10.2012 }

Про внесення змін до постанови НКРЕ від 23.11.2005 N 1044

Відповідно до Закону України "Про електроенергетику" ( 575/97-ВР ), Положення про Національну комісію регулювання електроенергетики України, затвердженого Указом Президента України від 14.03.95 N 213 ( 213/95 ) (зі змінами), Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Унести до постанови НКРЕ від 23.11.2005 N 1044 ( z0179-06 ) "Про затвердження форм звітності НКРЕ", зареєстрованої в Міністерстві юстиції України 27.02.2006 за N 179/12053 (зі змінами), такі зміни:

абзац дванадцятий пункту 1 виключити. У зв'язку з цим абзаци тринадцятий - двадцять третій вважати відповідно абзацами дванадцятим - двадцять другим;

у графі 3 пунктів 2 і 3 додатка до постанови цифри і слово "13-НКРЕ" вилучити.

2. Визнати такими, що втратили чинність, форму звітності 13-НКРЕ "Звіт про надходження грошових коштів від ліцензованої діяльності", затверджену постановою НКРЕ від 23.11.2005 N 1044 ( z0179-06, zl179-06 ), зареєстрованою в Міністерстві юстиції України 27.02.2006 за N 179/12053, та Інструкцію щодо заповнення форми звітності 13-НКРЕ "Звіт про надходження грошових коштів від ліцензованої діяльності" ( z0189-06 ), затверджену постановою НКРЕ від 23.11.2005 N 1044, зареєстровану в Міністерстві юстиції України 27.02.2006 за N 189/12063.

3. Управлінню ліцензійного контролю та територіальних представництв НКРЕ забезпечити подання цієї постанови на державну реєстрацію до Міністерства юстиції України.

Голова Комісії В.Кальченко
