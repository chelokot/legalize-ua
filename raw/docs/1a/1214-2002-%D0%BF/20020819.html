Про внесення зміни до переліку посад, що можуть бути заміщені військовослужбовцями Збройних Сил, Служби безпеки, інших військових формувань в органах виконавчої влади, інших цивільних установах, та граничних військових звань за цими посадами

Стан: Втратив чинність

Ідентифікатор: 1214-2002-п

Текст документа від 19.08.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 серпня 2002 р. N 1214 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Реєстраційний код акта : 44030/2008

Дата внесення до реєстру : 15.08.2008

Про внесення зміни до переліку посад, що можуть бути заміщені військовослужбовцями Збройних Сил, Служби безпеки, інших військових формувань в органах виконавчої влади, інших цивільних установах, та граничних військових звань за цими посадами

Кабінет Міністрів України постановляє:

У переліку посад, що можуть бути заміщені військовослужбовцями Збройних Сил, Служби безпеки, інших військових формувань в органах виконавчої влади, інших цивільних установах, та граничних військових звань за цими посадами, затвердженому постановою Кабінету Міністрів України від 7 лютого 2001 р. N 105 ( 105-2001-п ) (із змінами, внесеними постановою Кабінету Міністрів України від 12 квітня 2002 р. N 512) ( 512-2002-п ), розділ "Укрспецекспорт" виключити.
