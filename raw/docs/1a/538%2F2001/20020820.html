Питання організації проведення в Україні адміністративної реформи

Стан: Втратив чинність

Ідентифікатор: 538/2001

Текст документа від 20.08.2002:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання організації проведення в Україні адміністративної реформи

( Із змінами, внесеними згідно з Указами Президента N 1046/2001 ( 1046/2001 ) від 05.11.2001 N 729/2002 ( 729/2002 ) від 20.08.2002 )

З метою забезпечення більш динамічного здійснення заходів, пов'язаних із проведенням адміністративної реформи, своєчасного вирішення конкретних питань, що виникають у цій сфері, постановляю:

( Стаття 1 втратила чинність на підставі Указу Президента N 729/2002 ( 729/2002 ) від 20.08.2002 )

( Стаття 2 втратила чинність на підставі Указу Президента N 729/2002 ( 729/2002 ) від 20.08.2002 )

3. На часткову зміну статті 2 Указу Президента України від 7 липня 1997 року N 620 ( 620/97 ) "Про Державну комісію з проведення в Україні адміністративної реформи" (із змінами, внесеними Указами Президента України від 29 серпня 1997 року N 923 ( 923/97 ), від 9 січня 1999 року N 5 ( 5/99 ) та від 18 грудня 1999 року N 1587 ( 1587/99 ) затвердити новий персональний склад Державної комісії з проведення в Україні адміністративної реформи (додається).

4. Ліквідувати Секретаріат Державної комісії з проведення в Україні адміністративної реформи, утворений відповідно до Указу Президента України від 2 жовтня 1997 року N 1089 ( 1089/97 ) "Про Положення про Державну комісію з проведення в Україні адміністративної реформи".

( Стаття 5 втратила чинність на підставі Указу Президента N 729/2002 ( 729/2002 ) від 20.08.2002 )

6. Кабінету Міністрів України:

вирішити разом з Главою Адміністрації Президента України питання передачі штатної чисельності працівників ліквідованого Секретаріату Державної комісії з проведення в Україні адміністративної реформи та бюджетних асигнувань на його утримання відповідно до Адміністрації Президента України та Державного управління справами;

ліквідувати робочу групу з проведення реформи центральних органів виконавчої влади, утворену відповідно до Указу Президента України від 22 липня 1998 року N 810 ( 810/98 ) "Про заходи щодо впровадження Концепції адміністративної реформи в Україні";

передбачати в проектах законів про Державний бюджет України на 2002 та наступні роки кошти на фінансування заходів із проведення адміністративної реформи в Україні;

привести в місячний строк свої рішення у відповідність із цим Указом.

7. Главі Адміністрації Президента України:

затвердити в місячний строк Положення про Управління з питань адміністративної реформи;

ліквідувати робочу групу з проведення реформи місцевих органів виконавчої влади, органів місцевого самоврядування та державної служби, утворену відповідно до Указу Президента України від 22 липня 1998 року N 810 "Про заходи щодо впровадження Концепції адміністративної реформи в Україні".

8. Внести до Указів Президента України такі зміни:

а) статтю 7 Указу Президента України від 7 липня 1997 року N 620 ( 620/97 ) "Про Державну комісію з проведення в Україні адміністративної реформи" виключити;

б) у Положенні про Державну комісію з проведення в Україні адміністративної реформи, затвердженому Указом Президента України від 2 жовтня 1997 року N 1089 ( 1089/97 ) (із змінами, внесеними Указами Президента України від 9 січня 1999 року N 5 ( 5/99 ) та від 21 квітня 1999 року N 403 ( 403/99 ):

підпункт 2 пункту 3 виключити.

У зв'язку з цим підпункти 3 - 5 вважати відповідно підпунктами 2 - 4;

абзац другий пункту 6 викласти в такій редакції:

"Голова Комісії має першого заступника та заступників. Першим заступником Голови Комісії є за посадою Уповноважений Президента України з питань адміністративної реформи. Заступників Голови Комісії призначає за його поданням Президент України";

пункт 8 викласти в такій редакції:

"У разі відсутності Голови Комісії його обов'язки виконує перший заступник або один із заступників Голови Комісії";

пункти 11 і 12 викласти в такій редакції:

"11. Організаційне, інформаційне, аналітичне та інше забезпечення роботи Комісії здійснює Управління з питань адміністративної реформи Адміністрації Президента України.

12. Матеріально-технічне та фінансове забезпечення діяльності Комісії здійснює Державне управління справами";

у пункті 14 слова "та працівники її Секретаріату" виключити;

в) частини першу та другу статті 2 Указу Президента України від 22 липня 1998 року N 810 ( 810/98 ) "Про заходи щодо впровадження Концепції адміністративної реформи в Україні" (із змінами, внесеними Указами Президента України від 10 вересня 1998 року N 1000 ( 1000/98 ), від 9 січня 1999 року N 5 ( 5/99 ) та від 18 грудня 1999 року N 1588 ( 1588/99 ) визнати такими, що втратили чинність;

( Пункт "г" статті 8 втратив чинність на підставі Указу Президента N 729/2002 ( 729/2002 ) від 20.08.2002 )

9. Визнати такими, що втратили чинність:

Указ Президента України від 10 вересня 1998 року N 1001 ( 1001/98 ) "Про Положення про робочу групу з проведення реформи місцевих органів виконавчої влади, органів місцевого самоврядування та державної служби";

Указ Президента України від 6 жовтня 1998 року N 1114 ( 1114/98 ) "Про Положення про робочу групу з проведення реформи центральних органів виконавчої влади";

Положення про Секретаріат Державної комісії з проведення в Україні адміністративної реформи, затверджене Указом Президента України від 21 квітня 1999 року N 403 ( 403/99 ).
