ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

30.06.2006 N 290

Зареєстровано в Міністерстві юстиції України 6 липня 2006 р. за N 800/12674

{ Наказ втратив чинність на підставі Наказу Державного комітету статисти N 313 ( z0840-09 ) від 18.08.2009 }

Про внесення змін та доповнень до Інструкції щодо заповнення форми державного статистичного спостереження N 1-П (термінова) "Терміновий звіт про виробництво промислової продукції (робіт, послуг)"

Відповідно до статті 14 Закону України "Про державну статистику" ( 2614-12 ), з метою удосконалення державних статистичних спостережень щодо промислової діяльності НАКАЗУЮ:

1. Унести зміни та доповнення до пункту 3 Інструкції щодо заповнення форми державного статистичного спостереження N 1-П (термінова) "Терміновий звіт про виробництво промислової продукції (робіт, послуг)", затвердженої наказом Держкомстату України від 30.04.2004 N 261 ( z0674-04 ) та зареєстрованої в Міністерстві юстиції України 27.05.2004 за N 674/9273 (зі змінами ) (далі - Інструкція), а саме:

1.1. Вилучити підпункт 3.7.

1.2. Підпункти 3.8, 3.9 уважати підпунктами 3.7, 3.8, при цьому в підпункті 3.7 у словах "за графами 1, 3, 4, 5, 6, 7" виключити цифри "6, 7", у підпункті 3.8 слова "у графі 8" замінити на слова "у графі 6".

2. Зазначені зміни та доповнення ввести в дію, починаючи зі звіту за січень 2007 року.

3. Адміністративно-господарському департаменту (Царський В.І.) забезпечити контроль за своєчасним виготовленням та доставкою цієї Інструкції ( z0674-04 ) зі змінами та доповненнями, унесеними пунктом 1 цього наказу, на адреси головних управлінь статистики в Автономній Республіці Крим, областях, місті Києві та Управління статистики у місті Севастополі.

4. Департаменту фінансового забезпечення, бухгалтерського обліку та звітності (Кучіна І.Ю.) забезпечити фінансування робіт з виготовлення та доставки Інструкції ( z0674-04 ) зі змінами та доповненнями, унесеними пунктом 1 цього наказу.

5. Контроль за виконанням цього наказу покласти на першого заступника Голови Головка В.А.
