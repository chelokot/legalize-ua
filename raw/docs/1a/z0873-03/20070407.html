Про затвердження Положення про сертифікацію аудиторів банків

{ Із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

З метою забезпечення виконання банками вимог Закону України "Про банки і банківську діяльність" ( 2121-14 ) щодо проведення аудиту їх фінансової звітності аудиторами, що мають сертифікат Національного банку України, створення умов для організації проведення сертифікації Національним банком України аудиторів, які матимуть право на здійснення аудиту банків, та сприяння підвищенню професійного рівня зовнішніх аудиторів банків відповідно до вимог Міжнародних стандартів аудиту Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити Положення про сертифікацію аудиторів банків, що додається.

2. Визнати таким, що втратило чинність, Положення про сертифікацію аудиторів банківських установ, затверджене постановою Правління Національного банку України від 16.07.2001 N 271 ( z0662-01 ) та зареєстроване в Міністерстві юстиції України 03.08.2001 за N 662/5853 (із змінами).

3. Генеральному департаменту банківського нагляду (В.В.Пушкарьов) після державної реєстрації в Міністерстві юстиції України довести зміст цієї постанови до відома структурних підрозділів центрального апарату, територіальних управлінь Національного банку України, а також банків та Аудиторської палати України для використання в роботі.

4. Зобов'язати Господарсько-експлуатаційне управління (О.П.Руденко) у місячний термін з дня набрання чинності цією постановою забезпечити в потрібній кількості виготовлення бланків сертифікатів за встановленою формою.

5. Контроль за виконанням цієї постанови покласти на заступника Голови О.В.Шлапака, Генеральний департамент банківського нагляду (В.В.Пушкарьов).

6. Постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

Голова С.Л.Тігіпко

ЗАТВЕРДЖЕНО Постанова Правління Національного банку України 09.09.2003 N 388

Зареєстровано в Міністерстві юстиції України 29 вересня 2003 р. за N 873/8194

ПОЛОЖЕННЯ про сертифікацію аудиторів банків

Це Положення розроблено відповідно до вимог статті 7 Закону України "Про Національний банк України" ( 679-14 ), статті 69 Закону України "Про банки і банківську діяльність" ( 2121-14 ), Закону України "Про аудиторську діяльність" ( 3125-12 ) та нормативно-правових актів Національного банку України (далі - Національний банк).

Цим Положенням Національний банк установлює єдині умови та порядок сертифікації аудиторів банків.

1. Загальні положення

1.1. Положення регламентує порядок та умови надання Комітетом з питань сертифікації аудиторів банків (далі - Комітет) сертифіката особам, які мають намір здійснювати або проводять аудит банків (далі - аудитори), а також визначає умови, за яких Комітет може відмовити аудиторам у проходженні сертифікації та застосувати до них відповідних заходів впливу.

1.2. Сертифікація - це визначення кваліфікаційної придатності аудитора шляхом складання кваліфікаційного іспиту на знання Міжнародних стандартів аудиту, надання впевненості та етики, інших знань з банківської справи та процедура надання аудиторам сертифіката на право здійснення аудиту банків (далі - сертифікат) згідно з вимогами законодавства України. { Пункт 1.2 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

1.3. Аудитори мають право здійснювати аудит банків лише після отримання відповідного сертифіката (додаток 1).

1.4. Термін чинності сертифіката становить три роки.

1.5. Умови продовження терміну чинності сертифіката та видачі його дубліката визначаються цим Положенням. { Пункт 1.5 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

1.6. Розмір оплати за сертифікацію та продовження терміну чинності сертифіката визначається Національним банком за поданням Комітету. У разі відмови аудитора від проходження сертифікації або його відсутності з неповажних причин на кваліфікаційному іспиті, а також якщо він не склав іспиту, сплата за проходження сертифікації не повертається. { Пункт 1.6 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

2. Кваліфікаційні вимоги та порядок подання аудиторами документів для отримання сертифіката

2.1. Право на отримання сертифіката мають фізичні особи, які мають вищу економічну та/або юридичну освіту (не нижче освітнього рівня спеціаліста та магістра), досвід роботи за фахом не менше ніж три роки поспіль на посадах аудитора, бухгалтера, ревізора, юриста, фінансиста або економіста та не мають непогашеної або не знятої в установленому порядку судимості, а також склали кваліфікаційний іспит. { Пункт 2.1 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

2.2. Для отримання сертифіката вперше аудитор повинен мати трирічний досвід роботи у банківській сфері, або протягом трьох років брати участь у наданні банкам будь-яких послуг чи консультацій, пов'язаних з бухгалтерським обліком у банках, банківським аудитом, консультацій з банківського менеджменту, консультацій з фінансової діяльності банків, оподаткування банків. { Пункт 2.2 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

2.3. Для отримання дозволу на складання кваліфікаційного іспиту аудитор подає до Комітету такі документи: { Абзац перший пункту 2.3 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

заяву за встановленою формою (додаток 2);

копію диплома про освіту, засвідчену нотаріально (або на останньому місці роботи);

виписку з трудової книжки, засвідчену в установленому порядку;

підтвердження про участь у наданні послуг чи консультацій банкам (у разі потреби); { Пункт 2.3 доповнено абзацом згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

копію платіжного документа про внесення плати за сертифікацію.

Аудитор відповідає за достовірність поданих відомостей, які викладені в заяві та інших поданих ним документів.

2.4. Не розглядаються заяви про отримання дозволу на складання кваліфікаційного іспиту від осіб, яким згідно з вимогами законодавства України заборонено займатися аудиторською діяльністю. { Пункт 2.4 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

2.5. Якщо немає хоча б одного з документів, зазначених у пункті 2.3 цього Положення, чи неналежного їх оформлення, то заява до розгляду не приймається.

2.6. Члени Комітету несуть відповідальність за розголошення інформації з обмеженим доступом про аудитора відповідно до вимог законодавства України. { Пункт 2.6 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

3. Порядок роботи з документами, що подаються для отримання сертифіката

3.1. Розгляд відповідних документів аудиторів, надання дозволу на складання аудиторами кваліфікаційного іспиту, видачу сертифікатів та їх дублікатів здійснює Комітет. { Пункт 3.1 в редакції Постанови Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

3.2. Отримання документів, ведення поточних справ з проведення сертифікації, складання реєстру відповідних сертифікатів тощо здійснюються відповідальним секретарем Комітету.

3.3. Документи, що подаються аудиторами для проходження сертифікації, Комітет розглядає протягом 15 робочих днів з дня їх надходження. { Пункт 3.3 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

3.4. Якщо немає зауважень щодо поданих документів та аудитор склав іспит, то Комітет приймає рішення про видачу аудитору сертифіката.

3.5. Якщо Комітет має документальне підтвердження непогашеної або не знятої в установленому порядку судимості аудитора, небездоганної ділової репутації, фактів подання недостовірної інформації в документах аудитора, які було виявлено під час проведення сертифікації, то Комітет відмовляє у видачі сертифіката з обґрунтуванням зазначеного рішення. { Пункт 3.5 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

3.6. Якщо Комітет прийняв рішення про відмову в наданні аудитору сертифіката, то він повідомляє про це письмово в 10-денний термін із зазначенням підстав відмови.

3.7. Рішення про відмову у видачі аудитору сертифіката надсилається рекомендованим листом або надається йому особисто чи його уповноваженому представнику в установленому порядку.

4. Порядок складання кваліфікаційного іспиту

4.1. Перевірка знань аудитора в галузі бухгалтерського обліку в банках, Міжнародних стандартів аудиту, надання впевненості та етики та з інших предметів, які Комітет може визначати обов'язковими, здійснюється шляхом складання аудиторами іспиту, який проводиться в порядку, що затверджується Комітетом. { Пункт 4.1 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

4.2. Комітет установлює обов'язкові процедури подання заяви та проведення іспиту, включаючи способи оцінювання та визначення оцінки, що потрібна для отримання сертифіката.

4.3. Аудитори мають продемонструвати, що вони:

мають відповідні знання з конкретних предметів;

здатні застосовувати знання практично;

здатні застосовувати свої знання для розв'язання комплексних завдань з різних предметів;

здатні брати до уваги наявність альтернативних рішень;

можуть ефективно спілкуватись з користувачем аудиторських послуг;

обізнані з Міжнародними стандартами аудиту, надання впевненості та етики. { Абзац сьомий пункту 4.3 в редакції Постанови Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

5. Порядок отримання сертифікатів та їх дублікатів { Заголовок глави 5 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

5.1. Комітет розглядає підсумки проведення кваліфікаційного іспиту та приймає рішення про видачу або відмову у видачі сертифікатів аудиторам.

5.2. Сертифікат - це офіційний документ, що засвідчує право аудитора на аудит банків. Сертифікат не підлягає передаванню для його використання іншими аудиторами. { Пункт 5.2 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

5.3. Бланки сертифікатів є бланками суворого обліку, що обліковуються та підлягають зберіганню в установленому порядку.

5.4. Сертифікат містить такі реквізити:

номер; { Абзац другий пункту 5.4 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

прізвище, ім'я та по батькові аудитора;

дату, номер рішення Комітету про видачу сертифіката; { Абзац четвертий пункту 5.4 в редакції Постанови Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

термін чинності або подовження терміну чинності.

5.5. Датою видачі сертифіката вважається дата прийняття Комітетом відповідного рішення.

5.6. Сертифікат підписується головою Комітету та його відповідальним секретарем. Підписи засвідчуються гербовою печаткою Національного банку України.

5.7. Сертифікат реєструється в Книзі реєстрації сертифікатів на право здійснення аудиту банків (далі - Книга реєстрації сертифікатів аудиторів) (додаток 3), і його дані заносяться в комп'ютерну базу даних. Отримання аудитором сертифіката засвідчується його підписом у Книзі реєстрації сертифікатів аудиторів або підписом уповноваженої ним особи. { Пункт 5.7 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

5.8. Аудитор має звернутися до Комітету за сертифікатом протягом 15 робочих днів з дня прийняття Комітетом відповідного рішення.

5.9. Рішення Комітету про те, що аудитор не склав кваліфікаційного іспиту, може бути оскаржене (подання відповідної заяви Голові Національного банку).

5.10. Аудитори, які не склали кваліфікаційного іспиту, мають право повторно скласти його не раніше ніж через рік.

5.11. У разі втрати або пошкодження аудитором сертифіката, термін чинності якого не закінчився, Комітет може видати аудитору дублікат сертифіката. { Главу 5 доповнено пунктом 5.11 згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

5.12. У разі втрати сертифіката його дублікат видається на підставі звернення аудитора до Комітету із відповідною заявою та інформацією про публікацію оголошення про втрату сертифіката та визнання його недійсним в офіційному виданні Національного банку - журналі "Вісник Національного банку України" або офіційному виданні Аудиторської палати України та Спілки аудиторів України - журналі "Аудитор України". { Главу 5 доповнено пунктом 5.12 згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

5.13. Якщо сертифікат значно пошкоджений та є не придатним для його пред'явлення, то аудитор має звернутися до Комітету із відповідною заявою про отримання дубліката та надати пошкоджений сертифікат. { Главу 5 доповнено пунктом 5.13 згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

5.14. Комітет протягом десяти робочих днів з дати отримання відповідної заяви видає аудитору дублікат сертифіката замість втраченого або пошкодженого. За видачу дубліката стягується плата в розмірі, що встановлюється Національним банком за поданням Комітету. { Главу 5 доповнено пунктом 5.14 згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

5.15. Після видачі дубліката сертифіката Комітет приймає рішення про визнання недійсним оригіналу сертифіката, що був утрачений або пошкоджений, про що здійснюється відповідний запис у Книзі реєстрації сертифікатів аудиторів. { Главу 5 доповнено пунктом 5.15 згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

5.16. Перелік аудиторів, які отримали сертифікат, публікується на офіційному веб-сайті Національного банку та/або в офіційному виданні Національного банку - журналі "Вісник Національного банку України". { Пункт 5.16 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

6. Продовження терміну чинності сертифіката

6.1. Організація продовження терміну чинності сертифікатів аудиторів покладається на Комітет.

{ Пункт 6.2 виключено на підставі Постанови Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

6.2. Комітет має право продовжити термін чинності сертифіката аудитора не більше ніж на три роки. За продовження терміну чинності сертифіката стягується плата в розмірі 50 відсотків від суми, що встановлена за проведення сертифікації.

6.3. Аудитори не пізніше ніж за один місяць після закінчення чинності сертифіката та не раніше ніж за два місяці до дати припинення його чинності мають подати до Комітету на продовження терміну чинності сертифіката такі документи:

клопотання встановленого зразка (додаток 4);

витяг з трудової книжки, засвідчений в установленому порядку;

сертифікат, термін чинності якого закінчується;

звіт про здійснення аудиторської діяльності за період володіння сертифікатом;

свідоцтва (сертифікати), установленого законодавством України зразка про щорічне підвищення кваліфікації за фахом; { Абзац шостий пункту 6.3 в редакції Постанови Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

документ про внесення плати за продовження чинності сертифіката.

6.4. Після отримання від аудитора клопотання про продовження терміну чинності сертифіката та інших документів Комітет має право призначити вдруге складання аудитором кваліфікаційного іспиту в разі:

застосування до аудитора відповідних заходів впливу щодо обмеження здійснення аудиторської діяльності;

значних змін до законодавства України щодо ведення бухгалтерського обліку, порядку проведення аудиторських перевірок тощо;

несвоєчасного подання до Комітету документів на продовження терміну чинності сертифіката. { Пункт 6.4 доповнено абзацом згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

6.5. Якщо Комітет має документальне підтвердження непогашеної або не знятої в установленому порядку судимості аудитора, претензії до нього з боку Національного банку, Аудиторської палати України або інших державних органів контролю щодо здійснення аудиторської діяльності, то Комітет відмовляє такому аудитору в продовженні терміну дії сертифіката відповідно до порядку, установленому в главі 3 цього Положення.

6.6. Комітет розглядає подані аудитором документи щодо їх відповідності вимогам цього Положення і приймає відповідне рішення.

6.7. Комітет приймає рішення щодо продовження терміну чинності сертифіката без додаткових умов (у тому числі складання аудитором кваліфікаційного іспиту), якщо немає підстав, зазначених у пункті 6.4 цього Положення, якщо аудитор щороку протягом терміну чинності сертифіката надавав аудиторські послуги банкам та до нього не застосовувались заходи впливу. { Пункт 6.7 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

6.8. У разі прострочення терміну подання Комітету клопотання щодо продовження терміну чинності сертифіката та інших потрібних документів аудитори, термін чинності сертифікатів яких закінчився, проходять сертифікацію згідно з установленим порядком.

6.9. Видача сертифікатів, термін чинності яких продовжено, здійснюється відповідальним секретарем Комітету після прийняття Комітетом відповідного рішення. У сертифікатах зазначаються номер, дата рішення Комітету та термін, до якого продовжено строк чинності сертифіката. { Пункт 6.9 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

6.10. Сертифікат, термін чинності якого продовжено, підписується головою Комітету та його відповідальним секретарем. Запис про продовження чинності сертифіката здійснюється у Книзі реєстрації сертифікатів на право здійснення аудиту банків, а його отримання засвідчується підписом аудитора або уповноваженої ним особи. { Пункт 6.10 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

6.11. Якщо Комітет прийняв рішення про відмову аудитору в продовженні терміну дії сертифіката, то таке рішення доводиться до його відома рекомендованим листом із зазначенням підстав відмови в 10-денний термін з дня його прийняття.

7. Заходи впливу, що застосовуються до аудиторів, які мають сертифікат

7.1. Заходи впливу застосовуються до аудитора Комітетом на підставі:

виявлення протягом трьох років з дати підписання аудитором висновку про перевірку річної фінансової звітності банку фактів невідповідності цього висновку дійсному фінансовому стану банку, що встановлені службою банківського нагляду Національного банку за результатами інспектування банку; { Абзац другий пункту 7.1 в редакції Постанови Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

розглянутих аудиторських звітів та висновків про перевірку банків, що подаються до Національного банку;

інформації від Аудиторської палати України або державних контрольних і правоохоронних органів про неналежне виконання аудиторами своїх професійних обов'язків.

7.2. Комітет розглядає питання про вжиття до аудитора заходів впливу та може застосувати їх протягом трьох місяців після виявлення допущених ним порушень законодавства України, Міжнародних стандартів аудиту, надання впевненості та етики, а також отримання від нього звіту або пояснень. { Пункт 7.2 в редакції Постанови Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

7.3. За неналежне виконання своїх професійних обов'язків Комітет застосовує до аудитора такі заходи впливу:

попередження;

зупинення чинності сертифіката на строк до одного року;

анулювання сертифіката.

7.4. Попередження як захід впливу застосовується до аудитора в разі:

одноразового порушення вимог нормативно-правових актів Національного банку щодо порядку проведення аудиту банків;

невідповідності аудиторских звітів вимогам законодавства України, у тому числі нормативно-правових актів Національного банку щодо порядку оформлення результатів аудиту банків; { Абзац третій пункту 7.4 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

подання до Національного банку неперевіреної інформації та відомостей про порушення чи недоліки в діяльності банків, які безпосередньо не вплинули на їх фінансовий стан;

надходження від Аудиторської палати України або державних контрольних і правоохоронних органів інформації про наявність порушення аудитором вимог законодавства України та нормативно-правових актів України, що регулюють аудиторську діяльність. { Абзац п'ятий пункту 7.4 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

7.5. Зупинення чинності сертифіката на строк до одного року як захід впливу застосовується до аудитора в разі:

систематичного порушення ним вимог законодавства України, Міжнародних стандартів аудиту, надання впевненості та етики; { Абзац другий пункту 7.5 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

повторного порушення аудитором вимог, що зазначені в пункті 7.4 цього Положення;

установлення Національним банком, Аудиторською палатою України або державними контрольними органами неодноразових фактів проведення аудиту низької якості;

виявлення фактів, за яких законодавством України забороняється здійснення аудиторської діяльності. { Абзац п'ятий пункту 7.5 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

7.6. Зупинення чинності сертифіката на строк до одного року передбачає заборону аудиторові проводити аудит банків та надавати їм аудиторські послуги на визначений Комітетом термін.

7.7. Анулювання сертифіката аудитора здійснюється на підставі рішення Комітету в разі:

грубого порушення вимог законодавства України, Міжнародних стандартів аудиту, надання впевненості та етики, а також невиконання вимог з усунення порушень, на підставі яких було прийнято рішення про зупинення чинності сертифіката на термін до одного року; { Абзац другий пункту 7.7 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

проведення аудиту банків і надання їм позитивного висновку про підтвердження фінансової звітності, після результатів якого Національним банком протягом півріччя було прийнято рішення про відкликання ліцензії або розпочата процедура ліквідації банку; { Абзац третій пункту 7.7 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

установлення фактів надання недостовірної інформації в документах, що подавалися для отримання сертифіката;

рішення суду, на підставі якого аудитору забороняється здійснення аудиторської діяльності;

ініціативи аудитора (особистого повернення сертифіката);

інших підстав згідно з законодавством України. { Абзац сьомий пункту 7.7 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

7.8. Анулювання сертифіката аудитора здійснюється шляхом відкликання сертифіката та заборони (крім випадків здійснення анулювання за ініціативою аудитора) аудиторові проводити аудит банків на території України протягом чотирьох років.

7.9. Рішення Комітету про застосування до аудитора відповідного заходу впливу має бути надіслано рекомендованим листом або вручено персонально аудиторові в 10-денний термін з дати його прийняття.

7.10. Аудитор, щодо якого прийнято рішення про анулювання сертифіката, зобов'язаний у 15-денний термін з дня отримання рішення Комітету повернути його до Комітету.

7.11. Перелік аудиторів, щодо яких Комітет прийняв рішення про зупинення чинності сертифіката на певний термін або його анулювання, підлягає опублікуванню на офіційному веб-сайті Національного банку та/або в офіційному виданні Національного банку - журналі "Вісник Національного банку України". { Пункт 7.11 із змінами, внесеними згідно з Постановою Національного банку N 53 ( z0206-06 ) від 17.02.2006 }

7.12. Рішення Комітету про зупинення чинності або анулювання сертифіката аудитора може бути оскаржено в судовому порядку.
