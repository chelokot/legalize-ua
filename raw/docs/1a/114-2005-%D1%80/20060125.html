КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 квітня 2005 р. N 114-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 36-р ( 36-2006-р ) від 25.01.2006 )

Про часткову зміну розпорядження Кабінету Міністрів України від 29 квітня 2004 р. N 266

На часткову зміну абзацу другого розпорядження Кабінету Міністрів України від 29 квітня 2004 р. N 266 ( 266-2004-р ) уповноважити Міністра транспорту та зв'язку Червоненка Євгена Альфредовича підписати Угоду між Кабінетом Міністрів України та Урядом Угорської Республіки про будівництво автомагістралі між Україною та Угорською Республікою, дозволивши вносити до проекту Угоди зміни, що не мають принципового характеру.

Прем'єр-міністр України Ю.ТИМОШЕНКО
