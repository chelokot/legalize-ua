Текст документа від 04.10.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 жовтня 2006 р. N 1394 Київ

Про внесення зміни до постанови Кабінету Міністрів України від 28 вересня 2006 р. N 1372

Кабінет Міністрів України постановляє:

Постановляючу частину постанови Кабінету Міністрів України від 28 вересня 2006 р. N 1372 ( 1372-2006-п ) "Про поновлення Демішкана В.Ф. на посаді Голови Державної служби автомобільних доріг України" викласти в такій редакції:

"Вважати поновленим згідно з постановою Голосіївського районного суду м. Києва від 13 вересня 2006 р. Демішкана Володимира Федоровича, призначеного постановою Кабінету Міністрів України від 10 серпня 2006 р. N 1155 ( 1155-2006-п ) на посаду Голови Державної служби автомобільних доріг України, який раніше був звільнений з цієї посади Указом Президента України від 27 грудня 2003 р. N 1530 ( 1530/2003 ), на зазначеній посаді з 28 грудня 2003 року".

Прем'єр-міністр України В.ЯНУКОВИЧ
