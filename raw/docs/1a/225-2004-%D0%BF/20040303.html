ПОСТАНОВА від 3 березня 2004 р. N 225 Київ

Про затвердження складу Митно-тарифної ради України

Кабінет Міністрів України постановляє:

1. Затвердити склад Митно-тарифної ради України, що додається.

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 30 серпня 2002 р. N 1297 ( 1297-2002-п ) "Про затвердження складу Митно-тарифної ради України" (Офіційний вісник України, 2002 р., N 36, ст. 1698);

постанову Кабінету Міністрів України від 24 лютого 2003 р. N 197 ( 197-2003-п ) "Про внесення змін до складу Митно-тарифної ради України" (Офіційний вісник України, 2003 р., N 9, ст. 369);

розпорядження Кабінету Міністрів України від 27 червня 2003 р. N 392 ( 392-2003-р ) "Про зміну складу Митно-тарифної ради України".
