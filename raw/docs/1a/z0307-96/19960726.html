( Наказ втратив чинність на підставі Наказу Мінекономіки N 100 ( z0397-96 ) від 26.07.96 )

Про граничний розмір роздрібних цін на газ сітьовий

Згідно з повноваженнями, затвердженими постановою Кабінету Міністрів України від 13.02.95 N 109 ( 109-95-п ) "Про уточнення повноважень центральних органів державної виконавчої влади, Уряду Автономної Республіки Крим та виконкомів місцевих Рад у галузі ціноутворення", та відповідно до Програми діяльності Кабінету Міністрів України на 1996 рік ( 412/96-ВР ), схваленої Верховною Радою України, з метою подальшого відшкодування витрат, пов'язаних з реалізацією сітьового газу населенню НАКАЗУЮ:

1. Затвердити граничні роздрібні ціни на сітьовий газ, що споживається населенням на комунально-побутові потреби (додаються)*.

2. Вважати такими, що втратили чинність, граничні розміри роздрібних цін на газ сітьовий, вугілля та вугільні брикети для населення, затверджені наказом Мінекономіки України від 20.12.95 N 185 ( z0470-95 ).

Міністр В.М.Гуреєв
