Президент України; Указ від 02.07.2009 № 505/2009

Питання наглядової ради відкритого акціонерного товариства "Державний ощадний банк України"

Стан: Втратив чинність

Ідентифікатор: 505/2009

Текст документа від 21.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 539/2010 ( 539/2010 ) від 14.04.2010 }

Питання наглядової ради відкритого акціонерного товариства "Державний ощадний банк України"

Відповідно до статті 7 Закону України "Про банки і банківську діяльність" ( 2121-14 ) постановляю:

1. На часткову зміну статті 1 Указу Президента України від 1 березня 2005 року N 390 ( 390/2005 ) "Про членів наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України" (зі змінами, внесеними Указами від 2 березня 2006 року N 182 ( 182/2006 ), від 11 травня 2006 року N 385 ( 385/2006 ), від 22 травня 2006 року N 423 ( 423/2006 ), від 25 вересня 2006 року N 781 ( 781/2006 ), від 4 грудня 2006 року N 1023 ( 1023/2006 ), від 27 лютого 2007 року N 156 ( 156/2007 ), від 12 березня 2007 року N 200 ( 200/2007 ), від 18 травня 2007 року N 430 ( 430/2007 ) та від 27 березня 2008 року N 272) ( 272/2008 ):

1) призначити членами наглядової ради відкритого акціонерного товариства "Державний ощадний банк України":

ГОЛОВКА - заступника Голови Правління Анатолія Терентійовича Національного депозитарію України (за згодою)

САДИКОВА - помічника Глави Секретаріату Президента Олександра Валерійовича України Головної служби організаційного забезпечення Секретаріату Президента України

СТАВНІЙЧУК - заступника Глави Секретаріату Президента Марину Іванівну України - Представника Президента України у Конституційному Суді України;

2) припинити повноваження членів наглядової ради відкритого акціонерного товариства "Державний ощадний банк України" Я. Берназюка, А. Пишного, І. Пукшина.

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 2 липня 2009 року N 505/2009
