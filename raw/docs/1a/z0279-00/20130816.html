НАКАЗ

N 695 від 06.04.2000 Зареєстровано в Міністерстві м.Київ юстиції України 16 травня 2000 р. vd20000406 vn695 за N 279/4500

{ Наказ втратив чинність на підставі Наказу Фонду державного майна N 986 ( z1243-13 ) від 08.07.2013 }

Про затвердження Положення про порядок укладання або переукладання контракту з головою правління відкритого акціонерного товариства, холдингової компанії та державної акціонерної компанії і Типової форми контракту з головою правління ВАТ

( Із змінами, внесеними згідно з Наказами Фонду державного майна N 1066 ( z0588-01 ) від 15.06.2001 N 662 ( z0901-04 ) від 05.04.2004 )

На підставі Законів України "Про господарські товариства" ( 1576-12 ), "Про власність" ( 697-12 ), "Про приватизацію майна державних підприємств" ( 2163-12 ), Указу Президента України від 15.12.99 N 1573/99 "Про зміни у структурі центральних органів виконавчої влади" та постанови Кабінету Міністрів України від 11.09.96 N 1099 ( 1099-96-п ) "Про затвердження Порядку перетворення у процесі приватизації державних, орендних підприємств і підприємств із змішаною формою власності у відкриті акціонерні товариства" НАКАЗУЮ:

1. Затвердити Положення про порядок укладання або переукладання контракту з головою правління відкритого акціонерного товариства, холдингової компанії та державної акціонерної компанії (додається).

2. Затвердити Типову форму контракту з головою правління ВАТ ( z0280-00 ) (додається).

3. Визнати такими, що втратили чинність, Положення про порядок укладення контракту з головою правління ВАТ ( z0369-99 ), Типову форму контракту з Головою правління відкритого акціонерного товариства ( z0371-99 ) і Положення про порядок роботи постійної конкурсної комісії з проведення конкурсів на заміщення вакантних посад голів правлінь ВАТ ( z0370-99 ), затверджені наказом Національного агентства України з управління державними корпоративними правами від 08.04.99 N 51.

4. Директору Департаменту корпоративного управління Войцеховському Й.В. у п'ятиденний термін подати на реєстрацію вищезазначені документи до Міністерства юстиції України.

5. Контроль за виконанням цього наказу покласти на першого заступника Голови Фонду Чечетова М.В.

Голова Фонду О.Бондар
