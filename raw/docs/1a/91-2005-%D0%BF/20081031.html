{ Постанова втратила чинність на підставі Постанови КМ N 912 ( 912-2008-п ) від 16.10.2008 }

Про генерального державного замовника і керівника Національної програми інформатизації

Відповідно до статей 10 і 11 Закону України "Про Національну програму інформатизації" ( 74/98-ВР ) Кабінет Міністрів України постановляє:

1. Покласти на Міністерство транспорту та зв'язку функції генерального державного замовника Національної програми інформатизації.

2. Затвердити заступника Міністра транспорту та зв'язку Нетудихату Леоніда Івановича керівником Національної програми інформатизації.

3. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 29 липня 1999 р. N 1377 ( 1377-99-п ) "Про генерального державного замовника і керівника Національної програми інформатизації";

розпорядження Кабінету Міністрів України від 13 грудня 2001 р. N 571 ( 571-2001-р ) "Про керівника Національної програми інформатизації";

розпорядження Кабінету Міністрів України від 26 травня 2004 р. N 325 ( 325-2004-р ) "Про керівника Національної програми інформатизації".
