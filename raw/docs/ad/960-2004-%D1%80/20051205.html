Про підписання Угоди між Кабінетом Міністрів України та Урядом Республіки Таджикистан про повітряне сполучення

Стан: Чинний

Ідентифікатор: 960-2004-р

Текст документа від 05.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 2004 р. N 960-р Київ

Про підписання Угоди між Кабінетом Міністрів України та Урядом Республіки Таджикистан про повітряне сполучення

( Із змінами, внесеними згідно з Розпорядженням КМ N 494-р ( 494-2005-р ) від 05.12.2005 )

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Республіки Таджикистан про повітряне сполучення.

Уповноважити Голову Державіаслужби Марченка Миколу Олександровича підписати зазначену Угоду, дозволивши вносити в разі потреби до проекту Угоди зміни, що не мають принципового характеру.

( Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 494-р ( 494-2005-р ) від 05.12.2005 )
