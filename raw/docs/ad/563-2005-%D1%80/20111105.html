КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 2005 р. N 563-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1118 ( 1118-2011-п ) від 02.11.2011 }

Про віднесення посади Керівника апарату Державної комісії з цінних паперів та фондового ринку до другої категорії посад державних службовців

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посаду Керівника апарату Державної комісії з цінних паперів та фондового ринку до другої категорії посад державних службовців.
