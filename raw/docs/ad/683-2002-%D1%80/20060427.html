Текст документа від 27.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 листопада 2002 р. N 683-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 579 ( 579-2006-п ) від 27.04.2006 }

Про утворення робочої групи з удосконалення податкової системи, розширення бази оподаткування та доопрацювання законопроектів, спрямованих на збільшення доходів бюджету

З метою підготовки пропозицій щодо удосконалення податкової системи, розширення бази оподаткування та доопрацювання законопроектів, спрямованих на збільшення доходів бюджету, утворити робочу групу у складі згідно з додатком.

Співголові робочої групи Ярошенку Ф.О. у тижневий термін доповісти про результати роботи.
