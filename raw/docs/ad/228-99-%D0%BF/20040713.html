Текст документа від 13.07.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 лютого 1999 р. N 228 Київ

Реєстраційний код акта : 6925/199

Дата внесення до реєстру : 01.08.2003

Про порядок оформлення дозволів для в'їзду в Україну

( Із змінами, внесеними згідно з Постановами КМ N 410 ( 410-2002-п ) від 29.03.2002 N 1168 ( 1168-2003-п ) від 28.07.2003 N 909 ( 909-2004-п ) від 13.07.2004 )

Кабінет Міністрів України постановляє:

Установити, що у період до утворення служби з питань імміграційного контролю: ( Абзац перший в редакції Постанови КМ N 410 ( 410-2002-п ) від 29.03.2002 )

іноземцям та особам без громадянства, які в'їжджають в Україну у службових справах на запрошення державних органів, а також на запрошення фізичних та юридичних осіб, у виняткових випадках може бути оформлено у Державному міжнародному аеропорту "Бориспіль" дозвіл для в'їзду в Україну терміном до 5 діб за окремим письмовим рішенням Міністерства закордонних справ; ( Постанову доповнено абзацом другим згідно з Постановою КМ N 410 ( 410-2002-п ) від 29.03.2002 )

громадянам країн - членів Європейського Союзу, Канади, Сполучених Штатів Америки, Турецької Республіки, Швейцарської Конфедерації та Японії, які в'їжджають в Україну з метою туризму, може бути оформлено у Державному міжнародному аеропорту "Бориспіль", міжнародних аеропортах "Сімферополь", "Одеса", "Донецьк", Одеському морському торговельному порту дозвіл на в'їзд в Україну терміном до 14 діб за наявності документів, що підтверджують туристичний характер поїздки. ( Постанову доповнено абзацом третім згідно з Постановою КМ N 410 ( 410-2002-п ) від 29.03.2002, в редакції Постанови КМ N 1168 ( 1168-2003-п ) від 28.07.2003, із змінами, внесеними згідно з Постановою КМ N 909 ( 909-2004-п ) від 13.07.2004 )

Порядок оформлення у Державному міжнародному аеропорту "Бориспіль", міжнародних аеропортах "Сімферополь", "Одеса", "Донецьк", Одеському морському торговельному порту дозволу для в'їзду в Україну та його зразок затверджуються Міністерством закордонних справ за погодженням з Міністерством внутрішніх справ, Міністерством юстиції, Адміністрацією Державної прикордонної служби і Службою безпеки. ( Абзац четвертий із змінами, внесеними згідно з Постановою КМ N 410 ( 410-2002-п ) від 29.03.2002, в редакції Постанови КМ N 909 ( 909-2004-п ) від 13.07.2004 )

Документи, на підставі яких оформлено зазначений дозвіл, зберігаються окремо у управління консульської служби Міністерства закордонних справ. ( Абзац п'ятий із змінами, внесеними згідно з Постановами КМ N 410 ( 410-2002-п ) від 29.03.2002, N 909 ( 909-2004-п ) від 13.07.2004 )
