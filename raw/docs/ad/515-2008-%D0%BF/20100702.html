Кабінет Міністрів України; Постанова, Порядок від 04.06.2008 № 515

Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для розроблення схем та проектних рішень масового застосування

Стан: Чинний

Ідентифікатор: 515-2008-п

Текст документа від 02.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 червня 2008 р. N 515 Київ

Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для розроблення схем та проектних рішень масового застосування

{ Із змінами, внесеними згідно з Постановою КМ N 486 ( 486-2010-п ) від 23.06.2010 }

{ Установити, що кошти, передбачені у державному бюджеті ( 835-17 ) Міністерству регіонального розвитку та будівництва за програмою "Розробка схем та проектних рішень масового застосування", використовуються у 2009 році відповідно до Порядку, затвердженого цією Постановою, без урахування сум, зазначених у пункті 6 Порядку, згідно з Постановою КМ N 177 ( 177-2009-п ) від 05.03.2009 }

{ Установити, що у 2010 році кошти, передбачені у державному бюджеті ( 2154-17 ) Міністерству регіонального розвитку та будівництва за програмою "Розробка схем та проектних рішень масового застосування", використовуються відповідно до Порядку, затвердженого цією Постановою, без урахування сум, зазначених у пункті 6 Порядку, згідно з Постановою КМ N 486 ( 486-2010-п ) від 23.06.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для розроблення схем та проектних рішень масового застосування, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 4 червня 2008 р. N 515

ПОРЯДОК використання у 2008 році коштів, передбачених у державному бюджеті для розроблення схем та проектних рішень масового застосування

1. Цей Порядок визначає механізм використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) Мінрегіонбуду за програмою "Розробка схем та проектних рішень масового застосування" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Мінрегіонбуд.

3. Виконавці робіт визначаються головним розпорядником відповідно до законодавства.

4. Закупівля робіт проводиться в установленому законодавством порядку.

5. Головний розпорядник здійснює розрахунки в межах установлених бюджетних коштів на підставі актів фактичного виконання робіт та їх кошторисної вартості відповідно до умов договору.

6. Бюджетні кошти спрямовуються на розроблення:

схем планування територій загальнодержавного значення та спільних проектів транскордонного співробітництва - 820 тис. гривень;

типових проектів будинків доступного житла та об'єктів соціальної сфери - 620 тис. гривень.

7. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету, затвердженого Державним казначейством.

{ Пункт 7 в редакції Постанови КМ N 486 ( 486-2010-п ) від 23.06.2010 }

8. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
