НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

03.08.2006 N 1034

Зареєстровано в Міністерстві юстиції України 18 серпня 2006 р. за N 986/12860

Про роздрібні ціни на газ природний, що використовується для потреб населення смт Солотвина Закарпатської області безпосередньо із Солотвинського родовища, та внесення змін до постанови НКРЕ від 08.06.2006 N 739

{ Із змінами, внесеними згідно з Постановою Національної комісії регулювання електроенергетики N 1345 ( z1129-06 ) від 19.10.2006 }

Відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", у зв'язку із затвердженням постановою НКРЕ від 08.06.2006 N 739 ( z0720-06 ) "Про роздрібні ціни на газ природний, що використовується для потреб населення" нових роздрібних цін на газ природний, що використовується для потреб населення, ураховуючи звернення ВАТ "Закарпатгаз" та погодження Міністерством економіки України роздрібних цін на газ природний, що використовується для потреб населенням смт Солотвина Закарпатської області безпосередньо із Солотвинського родовища (лист від 21.07.2006 N 89-24/59), Національна комісія регулювання електроенергетики України

ПОСТАНОВЛЯЄ:

1. Затвердити роздрібні ціни на газ природний, що використовується для потреб населення смт Солотвина Закарпатської області безпосередньо із Солотвинського родовища (додаються).

{ Пункт 2 фактично втратив чинність у зв'язку з втратою чинності Постанови Національної комісії регулювання електроенергетики N 739 ( z0720-06 ) від 08.06.2006, до якої вносились зміни } 2. Пункт 1 постанови НКРЕ від 08.06.2006 N 739 ( z0720-06 ) "Про роздрібні ціни на газ природний, що використовується для потреб населення", зареєстрованої у Міністерстві юстиції України 16.06.2006 за N 720/12594, викласти в такій редакції:

"1. Затвердити роздрібні ціни на газ природний, що використовується для потреб населення, що додаються, крім населення смт Солотвина Закарпатської області, яке споживає газ природний безпосередньо із Солотвинського родовища".

3. Управлінню регулювання та цінової політики нафтогазового комплексу в установленому порядку забезпечити подання цієї постанови на державну реєстрацію до Міністерства юстиції України.

4. Постанову НКРЕ від 24.10.2001 N 1080 ( z0961-01 ) "Про роздрібні ціни на газ природний, що використовується населенням смт Солотвина Закарпатської області безпосередньо із Солотвинського родовища на комунально-побутові потреби", зареєстровану в Міністерстві юстиції України 19.11.2001 за N 961/6152, визнати такою, що втратила чинність.

5. Ця постанова набуває чинності з 1 вересня 2006 року.

Голова Комісії В.Кальченко
