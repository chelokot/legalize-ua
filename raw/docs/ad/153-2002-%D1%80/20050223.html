Про митне оформлення тепловізійних камер, що ввозяться на митну територію України для виробництва броньованих бойових машин і комплектуючих виробів

Стан: Втратив чинність

Ідентифікатор: 153-2002-р

Текст документа від 23.02.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 березня 2002 р. N 153-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 143 ( 143-2005-п ) від 23.02.2005 )

Про митне оформлення тепловізійних камер, що ввозяться

на митну територію України для виробництва броньованих бойових машин і комплектуючих виробів

Держмитслужбі здійснити відповідно до пункту "н" статті 19 Закону України "Про Єдиний митний тариф" ( 2097-12 ), пункту 11.31 статті 11 Закону України "Про податок на додану вартість" ( 168/97-ВР ) митне оформлення двох тепловізійних камер (код згідно з УКТ ЗЕД 9013909000) ( 2371г-14 ), що ввозяться на митну територію України на адресу казенного підприємства "Харківське конструкторське бюро з машинобудування імені О.О. Морозова" концерну "Бронетехніка України" (код згідно з ЄДРПОУ 14310299) за контрактом від 25 жовтня 2001 р. N 3264, укладеним зазначеним підприємством з французькою фірмою "Thales Optronique SA", загальною вартістю 162 тис. євро для виробництва броньованих бойових машин і комплектуючих виробів.

Прем'єр-міністр України А.КІНАХ
