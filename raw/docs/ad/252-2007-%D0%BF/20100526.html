Текст документа від 26.05.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 лютого 2007 р. N 252 Київ

Про спостережну раду Державного фонду сприяння молодіжному житловому будівництву

{ Із змінами, внесеними згідно з Постановами КМ N 317 ( 317-2008-п ) від 09.04.2008 N 349 ( 349-2010-п ) від 19.05.2010 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 349 ( 349-2010-п ) від 19.05.2010 }

2. Внести до постанови Кабінету Міністрів України від 26 жовтня 2000 р. N 1604 ( 1604-2000-п ) "Про Державний фонд сприяння молодіжному житловому будівництву" (Офіційний вісник України, 2000 р., N 43, ст. 1846; 2003 р., N 9, ст. 390; 2005 р., N 29, ст. 1714) зміни, що додаються.

3. Пункт 2 постанови Кабінету Міністрів України від 15 липня 2005 р. N 592 ( 592-2005-п ) "Про внесення змін до деяких актів Кабінету Міністрів України з питань забезпечення молоді житлом" (Офіційний вісник України, 2005 р., N 29, ст. 1714) визнати таким, що втратив чинність.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

{ Склад втратив чинність на підставі Постанови КМ N 349 ( 349-2010-п ) від 19.05.2010 }

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 19 лютого 2007 р. N 252

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 26 жовтня 2000 р. N 1604 ( 1604-2000-п )

1. У пункті 1 постанови слова "та склад спостережної ради Фонду (додаються)" замінити словом "(додається)".

2. Абзац перший пункту 11 Положення про Державний фонд сприяння молодіжному житловому будівництву, затвердженого зазначеною постановою, виключити.
