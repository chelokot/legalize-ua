Про доповнення переліку запасів, які використовуються з метою виробництва електроенергії, податковий облік приросту (убутку) балансової вартості яких здійснюється за наслідками звітного (податкового) року

Текст документа від 28.01.2017:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 листопада 2009 р. N 1171 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1059 ( 1059-2016-п ) від 23.11.2016 }

Про доповнення переліку запасів, які використовуються з метою виробництва електроенергії, податковий облік приросту (убутку) балансової вартості яких здійснюється за наслідками звітного (податкового) року

Кабінет Міністрів України постановляє:

Доповнити перелік запасів, які використовуються з метою виробництва електроенергії, податковий облік приросту (убутку) балансової вартості яких здійснюється за наслідками звітного (податкового) року, затверджений постановою Кабінету Міністрів України від 16 червня 2005 р. N 472 ( 472-2005-п ) (Офіційний вісник України, 2005 р., N 25, ст. 1428), після позиції "Ядерне паливо для реакторів типу ВВЕР-100, ВВЕР-440, РВПК-1000" такою позицією:

"Ядерні матеріали, які закуповуються для виготовлення ядерного палива, що використовується для виробництва електроенергії, у тому числі:

урановий оксидний концентрат ТУУ 13.2-14309787-095-2002, (концентрат природного урану у код згідно вигляді U O ) з масовою часткою з УКТЗЕД 2844 10 90 00 3 8 ( 2371б-14 )

урану не менш як 65 відсотків

гексафторид природного урану код згідно (UF ) з УКТЗЕД 2844 10 90 00 6 ( 2371б-14 )

гексафторид урану (UF ) із код згідно 6 з УКТЗЕД 2844 20 35 00".

збагаченням урану-235 не більш ( 2371б-14 ) як 5 відсотків
