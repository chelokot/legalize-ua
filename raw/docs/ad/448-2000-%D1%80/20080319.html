{ Розпорядження втратило чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

Про заходи щодо реалізації програми INOGATE

( Із змінами, внесеними згідно з Розпорядженням КМ N 328-р ( 328-2002-р ) від 14.06.2002 Постановами КМ N 130 ( 130-2003-п ) від 29.01.2003 N 123 ( 123-2004-п ) від 04.02.2004 N 579 ( 579-2005-п ) від 13.07.2005 N 147 ( 147-2006-п ) від 15.02.2006 )

1. Затвердити Віце-прем'єр-міністра України відповідно до функціональних повноважень координатором програми INOGATE (далі - Програма), Державного секретаря з питань європейської інтеграції МЗС Чалого Олександра Олександровича - першим заступником координатора Програми, заступника Державного секретаря Мінпаливенерго Клюка Богдана Олексійовича, заступника Державного секретаря Мінпаливенерго, голову правління НАК "Нафтогаз України" Бойка Юрія Анатолійовича, заступника Державного секретаря Мінекономіки Безрученка Володимира Олексійовича - заступниками координатора Програми.

Дозволити координатору програми у разі потреби самостійно затверджувати своїх заступників. ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 )

( Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 328-р ( 328-2002-р ) від 14.06.2002, Постановами КМ N 130 ( 130-2003-п ) від 29.01.2003, N 123 ( 123-2004-п ) від 04.02.2004, N 579 ( 579-2005-п ) від 13.07.2005, N 147 ( 147-2006-п ) від 15.02.2006 )

2. Центральним органам виконавчої влади забезпечити попереднє узгодження з координатором Програми заходів, що здійснюються в рамках її реалізації.

3. Мінпаливенерго, НАК "Нафтогаз України" забезпечити у тижневий термін розміщення на безоплатній основі технічного секретаріату програми INOGATE у м. Києві.

4. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 28 жовтня 1998 р. N 862 ( 862-98-р ) та від 2 березня 1999 р. N 161 ( 161-99-р ).
