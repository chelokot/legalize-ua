ПОСТАНОВА від 23 квітня 2003 р. N 579 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 626 ( 626-2008-п ) від 09.07.2008 }

Про внесення зміни до постанови Кабінету Міністрів України від 5 червня 1995 р. N 392

Кабінет Міністрів України постановляє:

Абзац третій пункту 2 постанови Кабінету Міністрів України від 5 червня 1995 р. N 392 ( 392-95-п ) "Про розміри грошових зборів за видачу телерадіоорганізаціям ліцензій на право користування каналами мовлення" (ЗП України, 1995 р., N 8, ст. 204) доповнити словами "а також мовлення, спрямоване на підвищення рівня правової культури населення".
