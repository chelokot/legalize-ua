КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 квітня 1999 р. N 662 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1231 ( 1231-2000-п ) від 07.08.2000 )

Про граничну чисельність працівників центрального апарату Міністерства закордонних справ

Кабінет Міністрів України постановляє:

1. Затвердити граничну чисельність працівників центрального апарату Міністерства закордонних справ 773 одиниці.

2. Визнати такими, що втратили чинність постанову Кабінету Міністрів України від 17 серпня 1998 р. N 1313 ( 1313-98-п ) "Про внесення змін до додатка 1 до постанови Кабінету Міністрів України від 25 травня 1998 р. N 755" (Офіційний вісник України, 1998 р., N 33, ст. 1247) в частині, що стосується Міністерства закордонних справ, та постанову Кабінету Міністрів України від 2 листопада 1998 р. N 1726 ( 1726-98-п ) "Про додаткове збільшення чисельності центрального апарату Міністерства закордонних справ" (Офіційний вісник України, 1998 р., N 44, ст. 1630).
