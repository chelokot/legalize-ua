Про внесення зміни до розпорядження Кабінету Міністрів України від 10 квітня 2008 р. N 610

Внести зміну до розпорядження Кабінету Міністрів України від 10 квітня 2008 р. N 610 ( 610-2008-р ) "Деякі питання розпорядження земельними лісовими ділянками" (Офіційний вісник України, 2008 р., N 31, ст. 1001; 2009 р., N 42, ст. 1417, N 56, ст. 1959; 2010 р., N 5, ст. 211, ст. 212, N 9, ст. 465, N 48, ст. 1586), доповнивши абзац другий після слів "їх розміщення" словами ", а також для забезпечення функціонування та відбудови монастирів".
