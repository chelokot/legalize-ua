РОЗПОРЯДЖЕННЯ від 8 вересня 2004 р. N 632-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання ремонтно-відновлювальних робіт для деяких видів верстатів на митній території України

Відповідно до статті 232 Митного кодексу України ( 92-15 ) з урахуванням технологічних особливостей встановити для верстатів спеціальних колесотокарних і верстатів спеціальних колесофрезерних за кодами згідно з УКТЗЕД 8458 19 80 00 і 8459 69 90 00 ( 2371г-14 ) відповідно строк виконання ремонтно-відновлювальних робіт на митній території України 240 днів.
