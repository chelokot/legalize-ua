КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 липня 2007 р. N 925 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 259 ( 259-2010-п ) від 03.02.2010 }

Про внесення зміни до постанови Кабінету Міністрів України від 17 листопада 2004 р. N 1570

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 17 листопада 2004 р. N 1570 ( 1570-2004-п ) "Про затвердження Правил торгівлі лікарськими засобами в аптечних закладах" (Офіційний вісник України, 2004 р., N 47, ст. 3105) зміну, виключивши із вступної частини слова "Відповідно до статті 19 Закону України "Про лікарські засоби" ( 123/96-ВР ).
