Кабінет Міністрів України; Розпорядження від 29.10.1999 № 1177-р

Про внесення змін до переліку, затвердженого постановою Кабінету Міністрів України від 18 червня 1999 р. N 1065

Стан: Втратив чинність

Ідентифікатор: 1177-99-р

Текст документа від 11.08.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 жовтня 1999 р. N 1177-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1255 ( 1255-2000-п ) від 11.08.2000 )

Виключити у переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку в Донецькій області, для яких встановлено спеціальний режим інвестиційної діяльності, затвердженому постановою Кабінету Міністрів України від 18 червня 1999 р. N 1065 ( 1065-99-п ) (Офіційний вісник України, 1999 р., N 25, ст. 1165), у позиції "Харчова промисловість" цифри "15.84".
