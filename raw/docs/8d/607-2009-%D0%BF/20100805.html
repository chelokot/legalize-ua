Кабінет Міністрів України; Постанова від 10.06.2009 № 607

Про особливості закупівлі товарів, необхідних для запобігання виникненню серед населення захворювання на свинячий грип

Стан: Втратив чинність

Ідентифікатор: 607-2009-п

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 червня 2009 р. N 607 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про особливості закупівлі товарів, необхідних для запобігання виникненню серед населення захворювання на свинячий грип

Кабінет Міністрів України постановляє:

1. Відповідно до пункту 6 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006; 2009 р., N 20, ст. 628), установити, що передбачена планом заходів щодо запобігання виникненню серед населення захворювання на свинячий грип, затвердженим розпорядженням Кабінету Міністрів України від 28 квітня 2009 р. N 446 ( 446-2009-р ), закупівля обладнання, діагностикумів, сироваток, культуральних середовищ, діагностичних тест-систем, дезінфекційних засобів, антивірусних препаратів, засобів індивідуального захисту, діагностичних та витратних матеріалів для проведення лабораторних досліджень здійснюється Міністерством охорони здоров'я за процедурою закупівлі в одного учасника за погодженням з Міністерством економіки.

2. Міністерству охорони здоров'я подати протягом трьох робочих днів після укладення договорів про закупівлю товарів, зазначених у пункті 1 цієї постанови, Міністерству економіки та Головному контрольно-ревізійному управлінню копії зазначених договорів.

Прем'єр-міністр України Ю.ТИМОШЕНКО
