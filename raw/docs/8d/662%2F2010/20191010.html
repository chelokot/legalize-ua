Про деякі питання Національного інституту стратегічних досліджень

Стан: Чинний

Ідентифікатор: 662/2010

Текст документа від 10.10.2019:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про деякі питання Національного інституту стратегічних досліджень

{ Із змінами, внесеними згідно з Указами Президента N 747/2010 ( 747/2010 ) від 02.07.2010 N 760/2010 ( 760/2010 ) від 07.07.2010 N 120/2015 ( 120/2015 ) від 03.03.2015 N 737/2019 ( 737/2019 ) від 07.10.2019 }

З метою створення належних умов для забезпечення реалізації Національним інститутом стратегічних досліджень науково-аналітичного і прогнозного супроводження діяльності Президента України постановляю:

1. Покласти на Національний інститут стратегічних досліджень реалізацію основних завдань, у тому числі за напрямами фундаментальних та прикладних наукових досліджень, Інституту проблем національної безпеки та Національного інституту проблем міжнародної безпеки, що ліквідуються.

{ Стаття 2 втратила чинність на підставі Указу Президента N 737/2019 ( 737/2019 ) від 07.10.2019 }

3. Кабінету Міністрів України вирішити в установленому порядку питання щодо:

забезпечення Національного інституту стратегічних досліджень додатковими службовими приміщеннями, розглянувши можливість передачі йому приміщень Інституту проблем національної безпеки, Національного інституту проблем міжнародної безпеки, що ліквідуються;

передачі Державному управлінню справами бюджетних призначень на фундаментальні дослідження, прикладні розробки та підготовку науково-педагогічних і наукових кадрів у сфері національної безпеки.

{ Стаття 4 втратила чинність на підставі Указу Президента N 737/2019 ( 737/2019 ) від 07.10.2019 }

5. Визнати такими, що втратили чинність:

статтю 3 Указу Президента України від 4 лютого 2008 року N 83 ( 83/2008 ) "Про деякі питання Центру нормопроектного забезпечення діяльності Президента України";

абзац шостий статті 4 та пункт 5 статті 5 Указу Президента України від 4 листопада 2008 року N 997 ( 997/2008 ) "Про деякі заходи щодо забезпечення скорочення видатків Державного бюджету України на утримання органів управління";

пункт 3 Розпорядження Президента України від 15 квітня 1992 року N 58 ( 58/92-рп ) "Про Статут, організаційну структуру, чисельність, фонд заробітної плати та матеріально-технічне забезпечення Національного інституту стратегічних досліджень";

абзац третій пункту 1 Розпорядження Президента України від 22 квітня 1998 року N 92 ( 92/98-рп ) "Питання Національного інституту стратегічних досліджень".

6. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ
