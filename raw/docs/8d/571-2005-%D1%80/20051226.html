Кабінет Міністрів України; Розпорядження від 26.12.2005 № 571-р

Про скасування деяких розпоряджень Кабінету Міністрів України з питань передприватизаційної підготовки та приватизації

Стан: Чинний

Ідентифікатор: 571-2005-р

Текст документа від 26.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 грудня 2005 р. N 571-р Київ

Про скасування деяких розпоряджень Кабінету Міністрів України з питань передприватизаційної підготовки та приватизації

Скасувати розпорядження Кабінету Міністрів України:

від 12 липня 2005 р. N 256 ( 256-2005-р ) "Про затвердження переліку об'єктів для першочергової передприватизаційної підготовки та приватизації у 2005 році";

від 25 липня 2005 р. N 284 ( 284-2005-р ) "Про затвердження переліку додаткових об'єктів для першочергової передприватизаційної підготовки та приватизації у 2005 році";

від 25 липня 2005 р. N 285 ( 285-2005-р ) "Про погодження планів-графіків підготовки та проведення продажу об'єктів приватизації";

від 9 серпня 2005 р. N 324 ( 324-2005-р ) "Про внесення зміни до розпорядження Кабінету Міністрів України від 25 липня 2005 р. N 285";

від 18 серпня 2005 р. N 343 ( 343-2005-р ) "Про внесення зміни до розпорядження Кабінету Міністрів України від 25 липня 2005 р. N 285";

від 23 серпня 2005 р. N 357 ( 357-2005-р ) "Про внесення зміни до розпорядження Кабінету Міністрів України від 25 липня 2005 р. N 285";

від 5 вересня 2005 р. N 386 ( 386-2005-р ) "Про внесення зміни до розпорядження Кабінету Міністрів України від 25 липня 2005 р. N 285".
