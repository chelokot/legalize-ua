{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 76/5 ( z1061-06 ) від 20.09.2006 }

Про затвердження тарифів за надання додаткових послуг правового та технічного характеру в Центральному відділі реєстрації шлюбів м.Києва з державним Центром розвитку сім'ї

Відповідно до статей 6, 17 Закону України "Про органи реєстрації актів громадянського стану" ( 3807-12 ) та постанови Кабінету Міністрів України від 17 серпня 2002 року N 1136 ( 1136-2002-п ) "Про забезпечення дотримання законодавства під час надання послуг іноземцям та особам без громадянства" НАКАЗУЮ:

1. Затвердити тарифи за надання додаткових послуг правового та технічного характеру в Центральному відділі реєстрації шлюбів м.Києва з державним Центром розвитку сім'ї, що додаються, та ввести їх у дію з 10.12.2002.

2. Визнати таким, що втратив чинність, наказ Міністра юстиції України від 08.05.97 N 38/5 ( z0242-97 ) "Про затвердження тарифів за надання додаткових платних послуг правового та технічного характеру в Центральному відділі реєстрації шлюбів м.Києва з Державним Центром розвитку сім'ї", зареєстрований у Мін'юсті 02.07.97 за N 242/2046.

3. Контроль за виконанням цього наказу покласти на заступника Державного секретаря Міністерства юстиції України Єфіменка Л.В

Міністр О.В.Лавринович
