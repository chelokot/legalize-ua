Текст документа від 19.11.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 липня 2002 р. N 978 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1026 ( 1026-2010-п ) від 10.11.2010 }

Про заходи щодо підготовки та реалізації проекту "Розширення доступу до ринків фінансових послуг"

{ Із змінами, внесеними згідно з Постановами КМ N 603 ( 603-2003-п ) від 26.04.2003 N 35 ( 35-2005-п ) від 15.01.2005 N 147 ( 147-2006-п ) від 15.02.2006 N 207 ( 207-2008-п ) від 19.03.2008 }

{ У назві і тексті Постанови та назві додатка до неї слова "Проекту фінансування розвитку села" замінити словами "проекту "Розширення доступу до ринків фінансових послуг" згідно з Постановою КМ N 35 ( 35-2005-п ) від 15.01.2005 }

З метою підготовки та реалізації проекту "Розширення доступу до ринків фінансових послуг", що підтримується Міжнародним банком реконструкції і розвитку, Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

2. Визначити Міністерство фінансів відповідальним за підготовку і реалізацію проекту "Розширення доступу до ринків фінансових послуг".

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 5 листопада 1999 р. N 2060 ( 2060-99-п ) "Питання підготовки та реалізації Експериментального проекту фінансування села" (Офіційний вісник України, 1999 р., N 45, ст. 2237).
