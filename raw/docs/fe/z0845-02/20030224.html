09.10.2002 N 326/856

Зареєстровано в Міністерстві юстиції України 24 жовтня 2002 р. за N 845/7133

( Наказ втратив чинність на підставі Наказу Міністерства аграрної політики N 12/71 ( z0148-03 ) від 23.01.2003 )

Про внесення змін до Порядку використання бюджетних коштів для формування державного насіннєвого страхового фонду, затвердженого наказом Мінагрополітики і Мінфіну від 28 січня 2002 р. N 24/56 "Про затвердження Порядку використання бюджетних коштів для формування державного насіннєвого страхового фонду"

Відповідно до Законів України "Про насіння" ( 3690-12 ), "Про Державний бюджет України на 2002 рік" ( 2905-14 ), Указу Президента України від 3 грудня 1999 р. N 1529/99 ( 1529/99 ) "Про невідкладні заходи щодо прискорення реформування аграрного сектора економіки" та з метою поповнення державного насіннєвого страхового фонду насінням цукрових буряків НАКАЗУЄМО:

1. Унести до Порядку використання бюджетних коштів для формування державного насіннєвого страхового фонду (далі - Порядок), затвердженого наказом Міністерства аграрної політики України та Міністерством фінансів України від 28 січня 2002 р. N 24/56 ( z0115-02 ), зареєстрованого в Міністерстві юстиції України 7 лютого 2002 р. за N 115/6403, такі зміни:

1.1. Пункт 1.3 після слова "насіння" доповнити словами "цукрових буряків", слово "виключно" - вилучити.

1.2. Пункт 3 додатка до пункту 4.3 Порядку після слова "насіння" доповнити словами "цукрових буряків".

2. Департаменту ринків продукції рослинництва та розвитку насінництва (Сорока В.І.) Міністерства аграрної політики України забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням наказу покласти на заступника Державного секретаря Міністерства аграрної політики України Яковенка В.П. та заступника Державного секретаря Міністерства фінансів України Бауліна С.О.
