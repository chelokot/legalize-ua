Про Державну комісію з проведення в Україні грошової реформи

{ Із змінами, внесеними згідно з Указами Президента N 606/95 ( 606/95 ) від 11.07.95 N 758/95 ( 758/95 ) від 18.08.95 }

Виходячи з необхідності здійснення в Україні глибоких економічних перетворень, проведення з цією метою грошової реформи, постановляю:

1. Утворити Державну комісію з проведення в Україні грошової реформи (далі - Державна комісія) згідно з переліком (додаток N 1).

2. Основними завданнями Державної комісії з проведення в Україні грошової реформи є розробка проектів нормативних актів з питань проведення грошової реформи та післяреформенної стабілізації грошової одиниці України, керівництво та координація здійснюваних органами державної виконавчої влади та місцевого самоврядування, банківськими установами заходів щодо грошової реформи, а також контроль за виконанням указів та розпоряджень Президента України, актів Кабінету Міністрів України та Національного банку України з цих питань.

{ Стаття 2 в редакції Указу Президента N 606/95 ( 606/95 ) від 11.07.95 }

3. Установити, що Державна комісія в межах своєї компетенції приймає рішення, що є обов'язковими для виконання державними органами, банківськими установами, підприємствами, установами та організаціями усіх форм власності.

{ Стаття 3 в редакції Указу Президента N 606/95 ( 606/95 ) від 11.07.95 }

4. Утворити Робочу групу з розробки проектів нормативних актів з питань здійснення грошової реформи згідно з переліком (додаток N 2).

Утворити Групу оперативного забезпечення проведення грошової реформи (додаток N 3).

{ Статтю 4 доповнено частиною другою згідно з Указом Президента N 606/95 ( 606/95 ) від 11.07.95 }

4-1. Прем'єр-міністрові Автономної Республіки Крим, головам обласних, Київської та Севастопольської міських, районних, районних у містах Києві та Севастополі державних адміністрацій та головам міських Рад (міст обласного підпорядкування) утворити у тижневий строк відповідні комісії з проведення грошової реформи та вирішити питання щодо матеріального та інших видів забезпечення діяльності цих комісій.

{ Указ доповнено статтею 4-1 згідно з Указом Президента N 606/95 ( 606/95 ) від 11.07.95 }

5. Державна комісія має право залучати до розробки окремих нормативних актів висококваліфікованих спеціалістів, учених, в тому числі іноземних експертів.

{ Статтю 6 виключено на підставі Указу Президента N 606/95 ( 606/95 ) від 11.07.95 }

7. Кабінету Міністрів України вирішити питання про матеріальне та фінансове забезпечення діяльності Державної комісії з проведення в Україні грошової реформи.

8. Визнати такими, що втратили чинність:

статтю 11 Указу Президента України від 7 листопада 1992 року N 549 ( 549/92 ) "Про реформу грошової системи України";

Указ Президента України від 11 червня 1993 року N 201 ( 201/93 ) "Про зміни у складі Державної комісії по проведенню грошової реформи в Україні".

9. Цей Указ набирає чинності з дня його підписання.
