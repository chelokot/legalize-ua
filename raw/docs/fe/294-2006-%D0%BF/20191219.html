{ Постанова втратила чинність на підставі Постанови КМ N 1047 ( 1047-2019-п ) від 04.12.2019 }

Про внесення змін до Переліку об'єктів права державної власності, які можуть надаватися в концесію

Кабінет Міністрів України постановляє:

Внести до Переліку об'єктів права державної власності, які можуть надаватися в концесію, затвердженого постановою Кабінету Міністрів України від 11 грудня 1999 р. N 2293 ( 2293-99-п ) (Офіційний вісник України, 1999 р., N 50, ст. 2473; 2003 р., N 17, ст. 765; 2004 р., N 43, ст. 2838), такі зміни:

розділ "Майно підприємств, які є цілісними майновими комплексами або системою цілісних майнових комплексів, що забезпечують комплексне надання послуг" виключити;

доповнити розділ "Об'єкти, які можуть бути спеціально збудовані відповідно до умов концесійного договору для задоволення громадських потреб" позицією такого змісту:

"Сиваська вітрова електростанція Херсонська потужністю 20 МВт, облдерж- Херсонська область (Чаплинський район, адміністрація". с. Григорівка)
