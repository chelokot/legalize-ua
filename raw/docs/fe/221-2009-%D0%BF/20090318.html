Інд. 52

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 18 березня 2009 р. N 221

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. У пункті 6 Положення про Українську частину Комітету з питань співробітництва між Україною та Європейськими Співтовариствами (Європейським Союзом), затвердженого постановою Кабінету Міністрів України від 13 липня 1998 р. N 1074 ( 1074-98-п ) "Питання діяльності Української частини Комітету з питань співробітництва між Україною та Європейськими Співтовариствами (Європейським Союзом)", - із змінами, внесеними постановами Кабінету Міністрів України від 13 грудня 2001 р. N 1664 ( 1664-2001-п ) (Офіційний вісник України, 2001 р., N 51, ст. 2278), від 3 березня 2005 р. N 174 ( 174-2005-п ) (Офіційний вісник України, 2005 р., N 9, ст. 475), від 13 квітня 2005 р. N 291 ( 291-2005-п ) (Офіційний вісник України, 2005 р., N 15, ст. 778) і від 13 квітня 2007 р. N 625 ( 625-2007-п ) (Офіційний вісник України, 2007 р., N 28, ст. 1114):

в абзаці першому слово "чотирьох" замінити словом "п'ятьох";

після абзацу одинадцятого доповнити новим абзацом такого змісту:

"з питань загальної координації та моніторингу співробітництва між Україною та ЄС - директор Координаційного бюро європейської та євроатлантичної інтеграції Секретаріату Кабінету Міністрів України.".

У зв'язку з цим абзаци дванадцятий - двадцять другий вважати відповідно абзацами тринадцятим - двадцять третім.

2. У складі Координаційної ради з адаптації законодавства України до законодавства Європейського Союзу, утвореної постановою Кабінету Міністрів України від 15 жовтня 2004 р. N 1365 ( 1365-2004-п ) (Офіційний вісник України, 2004 р., N 42, ст. 2763; 2005 р., N 9, ст. 475), слова "Секретар Координаційної ради" замінити словами "Директор Координаційного бюро європейської та євроатлантичної інтеграції Секретаріату Кабінету Міністрів України - секретар Координаційної ради".

3. В абзаці першому пункту 3 постанови Кабінету Міністрів України від 3 березня 2005 р. N 174 ( 174-2005-п ) "Деякі питання координації діяльності органів виконавчої влади у сфері європейської інтеграції" (Офіційний вісник України, 2005 р., N 9, ст. 475, N 15, ст. 778) слова "Управління з питань європейської інтеграції Секретаріату Кабінету Міністрів України" замінити словами "відповідний структурний підрозділ Секретаріату Кабінету Міністрів України".
