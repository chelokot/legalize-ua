Кабінет Міністрів України; Постанова, Порядок від 16.11.2011 № 1168

Про затвердження Порядку визначення різниці між розміром пенсії, призначеної відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб", і розміром пенсії із солідарної системи відповідно до Закону України "Про загальнообов'язкове державне пенсійне страхування"

Стан: Чинний

Ідентифікатор: 1168-2011-п

Текст документа від 29.01.2022:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2011 р. N 1168 Київ

Про затвердження Порядку визначення різниці між розміром пенсії, призначеної відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб", і розміром пенсії із солідарної системи відповідно до Закону України "Про загальнообов'язкове державне пенсійне страхування"

{ Із змінами, внесеними згідно з Постановою КМ N 61 ( 61-2022-п ) від 26.01.2022 }

{ Установити, що у 2013 році різниця між розміром пенсії, призначеної відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб" ( 2262-12 ), і подвійним розміром пенсії, визначеної згідно з пунктом 2 або пунктом 3 Порядку, затвердженого цією Постановою, виплачується за рахунок коштів державного бюджету згідно з Постановою КМ N 101 ( 101-2013-п ) від 11.02.2013 }

Відповідно до статті 7 Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб" ( 2262-12 ) Кабінет Міністрів України постановляє:

Затвердити Порядок визначення різниці між розміром пенсії, призначеної відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб" ( 2262-12 ), і розміром пенсії із солідарної системи відповідно до Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ), що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 16 листопада 2011 р. N 1168

ПОРЯДОК визначення різниці між розміром пенсії, призначеної відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб" ( 2262-12 ), і розміром пенсії із солідарної системи відповідно до Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 )

1. Цей Порядок встановлює механізм визначення різниці між розміром пенсії, призначеної відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб" ( 2262-12 ), і розміром пенсії із солідарної системи відповідно до Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ).

2. Для осіб, яким пенсія призначається відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб" ( 2262-12 ), Пенсійний фонд України визначає розмір пенсії, на яку зазначені особи мають право із солідарної системи відповідно до Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ) на підставі виданих військовими частинами, територіальними центрами комплектування та соціальної підтримки та іншими уповноваженими на це органами довідок про вислугу років, грошове забезпечення та інших документів. { Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 61 ( 61-2022-п ) від 26.01.2022 }

При цьому обчислений розмір пенсії із солідарної системи не може бути менший, ніж мінімальний розмір пенсії, визначений відповідно до абзацу першого частини першої статті 28 Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ), і не більший, ніж розмір пенсії, призначеної відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб" ( 2262-12 ).

3. Для осіб, яким пенсія призначена відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб" ( 2262-12 ) до 1 жовтня 2011 р. і які мають право на пенсію відповідно до Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ), розмір пенсії із солідарної системи не може бути менший, ніж мінімальний розмір пенсії, визначений відповідно до абзацу першого частини першої статті 28 Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ), і не більший, ніж розмір пенсії, призначеної відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб" ( 2262-12 ).

4. Різниця між розміром пенсії, призначеної особі відповідно до Закону України "Про пенсійне забезпечення осіб, звільнених з військової служби, та деяких інших осіб" ( 2262-12 ), і розміром пенсії, визначеної згідно з пунктом 2 або 3 цього Порядку, виплачується за рахунок коштів державного бюджету.
