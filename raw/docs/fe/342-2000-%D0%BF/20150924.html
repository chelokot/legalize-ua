{ Постанова втратила чинність на підставі Постанови КМ N 692 ( 692-2015-п ) від 08.09.2015 }

Про внесення змін до переліку харчових добавок, дозволених для використання у харчових продуктах

Кабінет Міністрів України постановляє:

У переліку харчових добавок, дозволених для використання у харчових продуктах, затвердженому постановою Кабінету Міністрів України від 4 січня 1999 р. N 12 ( 12-99-п ) (Офіційний вісник України, 1999 р., N 1, ст. 19), слова і цифри "Е 1400 Декстрин харчовий Dextrin" замінити словами і цифрами "Е 1400 Декстрин харчовий та його похідні Dextrin".

Внести до зазначеного переліку доповнення, що додаються.
