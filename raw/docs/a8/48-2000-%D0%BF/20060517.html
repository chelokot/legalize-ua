{ Постанова втратила чинність на підставі Постанови КМ N 686 ( 686-2006-п ) від 17.05.2006 }

Про визначення родовищ з важковидобувними та виснаженими запасами

Відповідно до Указу Президента України від 17 червня 1996 р. N 433 ( 433/96 ) "Про заходи щодо залучення інвестицій для дорозробки нафтових родовищ з важковидобувними та виснаженими запасами" Кабінет Міністрів України постановляє:

Визначити родовища газоконденсатне Кавердинське (Полтавська область) та газові Дебеславицьке, Струпків-Черемхівське і Пилипівське (Івано-Франківська область) такими, що належать до родовищ з важковидобувними та виснаженими запасами, встановивши на 2000 - 2008 роки нульові базові обсяги видобутку.

Прем'єр-міністр України В.ЮЩЕНКО
