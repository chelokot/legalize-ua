КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 січня 2009 р. N 64-р Київ

Про внесення змін у додаток до розпорядження Кабінету Міністрів України від 23 травня 2007 р. N 342

Внести зміни у додаток до розпорядження Кабінету Міністрів України від 23 травня 2007 р. N 342 ( 342-2007-р ) "Про роздрібний тариф на електричну енергію для вугледобувних підприємств", виклавши його в редакції, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 37

Додаток до розпорядження Кабінету Міністрів України від 23 травня 2007 р. N 342 ( 342-2007-р ) (у редакції розпорядження Кабінету Міністрів України від 28 січня 2009 р. N 64-р)

ПЕРЕЛІК вугледобувних підприємств, для яких рекомендується встановити роздрібний тариф на електричну енергію як для споживачів 1 класу напруги
