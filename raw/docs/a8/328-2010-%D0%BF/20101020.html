КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 квітня 2010 р. N 328 Київ

Про затвердження складу Міжвідомчої комісії з міжнародної торгівлі

{ Із змінами, внесеними згідно з Розпорядженням КМ N 2003-р ( 2003-2010-р ) від 20.10.2010 }

Кабінет Міністрів України постановляє:

1. Затвердити склад Міжвідомчої комісії з міжнародної торгівлі, що додається.

2. Визнати такими, що втратили чинність, постанову Кабінету Міністрів України від 17 квітня 2008 р. N 384 ( 384-2008-п ) "Про затвердження складу Міжвідомчої комісії з міжнародної торгівлі" та розпорядження Кабінету Міністрів України від 12 серпня 2009 р. N 942 ( 942-2009-р ) "Про зміну складу Міжвідомчої комісії з міжнародної торгівлі".
