Кабінет Міністрів України; Постанова від 12.04.2006 № 504

Про проведення ґендерно-правової експертизи

Стан: Втратив чинність

Ідентифікатор: 504-2006-п

Текст документа від 18.07.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 квітня 2006 р. N 504 Київ

Про проведення ґендерно-правової експертизи

{ Із змінами, внесеними згідно з Постановою КМ N 950 ( 950-2007-п ) від 18.07.2007 }

Відповідно до статті 4 Закону України "Про забезпечення рівних прав та можливостей жінок і чоловіків" ( 2866-15 ) Кабінет Міністрів України постановляє:

1. Установити, що:

ґендерно-правову експертизу чинного законодавства та проектів нормативно-правових актів в усіх сферах законодавства, що стосуються прав і свобод людини, проводить Міністерство юстиції;

ґендерно-правова експертиза проектів нормативно-правових актів проводиться як складова частина правової експертизи.

{ Пункт 2 втратив чинність на підставі Постанови КМ N 950 ( 950-2007-п ) від 18.07.2007 }

3. Міністерству юстиції розробити та затвердити форму висновку ґендерно-правової експертизи актів законодавства.

Прем'єр-міністр України Ю.ЄХАНУРОВ
