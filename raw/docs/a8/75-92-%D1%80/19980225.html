КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 лютого 1992 р. N 75-р Київ

Про затвердження складу Комісії з питань координації приймання, транспортування, охорони та розподілу гуманітарної допомоги, що надходить із зарубіжних країн, при Кабінеті Міністрів України

( Зміни в текст не внесені. Додатково див. Розпорядження КМ N 501-р ( 501-92-р ) від 01.08.92 N 857-р ( 857-92-р ) від 28.12.92 )

( Із змінами, внесеними згідно з Розпорядженнями КМ N 65-р ( 65-95-р ) від 08.02.95 N 173-р ( 173-97-р ) від 03.04.97 N 113-р ( 113-98-р ) від 25.02.98 )

1. На виконання Указу Президента України від 15 січня 1992 р. N 37 ( 37/92 ) "Про організацію роботи по прийманню та розподілу міжнародної гуманітарної допомоги на території України" затвердити Комісію з питань координації приймання, транспортування, охорони та розподілу гуманітарної допомоги, що надходить із зарубіжних країн, при Кабінеті Міністрів України у складі:

БІЛОБЛОЦЬКИЙ - Віце-прем'єр-міністр України, голова Микола Петрович Комісії

КОВАЛЬ - заступник завідуючого Відділом з питань Анатолій Дмитрович соціального захисту та трудових відносин Кабінету Міністрів України, перший заступник голови Комісії

БОГАТИРЬОВА - заступник Міністра охорони здоров'я, Раїса Василівна заступник голови Комісії

БУРЯК - перший заступник голови Леонід Васильович Держспоживзахисту

ГАМАЧЕК - заступник Міністра праці та соціальної Валентин Анатолійович політики

МОВЧАН - заступник Міністра охорони навколишнього Ярослав Іванович природного середовища та ядерної безпеки

ОПЕРЕНКО - заступник Голови Державної податкової Григорій Миколайович адміністрації

СОЛОВКОВ - заступник Голови Держмитслужби Юрій Петрович

ТЕРЕЩУК - заступник Міністра внутрішніх справ Олександр Васильович

РИНКА - заступник Міністра з питань надзвичайних Анатолій Андрійович ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

УСІЧЕНКО - голова Національного комітету Товариства Іван Гнатович Червоного Хреста (за згодою)

ХАНДОГІЙ - заступник Міністра закордонних справ Володимир Дмитрович

ШАПОВАЛ - заступник голови Держкомрелігій Георгій Олександрович

ШЕВАЛЬОВ - заступник Міністра зовнішніх економічних Валентин Миколайович зв'язків і торгівлі

( Склад комісії в редакції Розпоряджень КМ N 65-р ( 65-95-р ) від 08.02.95, N 173-р ( 173-97-р ) від 03.04.97, N 113-р ( 113-98-р ) від 25.02.98 ) Вважати за доцільну участь у роботі Комісії на правах спостерігачів представників урядів закордонних держав, а також громадських та благодійних організацій, фірм і ділових кіл, які надають гуманітарну допомогу Україні.

2. Для забезпечення оперативного вирішення питань, пов'язаних з доставкою і розподілом гуманітарної допомоги, утворити постійно діючу робочу групу у складі:

КОВАЛЬ - заступник завідуючого Відділом з питань Анатолій Дмитрович соціального захисту та трудових відносин Кабінету Міністрів України, керівник групи

АВРАМЕНКО - головний інспектор управління Олександр Миколайович Держмитслужби

БОРЩЕВСЬКИЙ - перший секретар управління МЗС Сергій Юхимович

ДРОЗДОВ - заступник генерального директора Володимир Петрович державного українського об'єднання "Політехмед"

ЗАГРЕБЕЛЬНИЙ - завідуючий відділом Національного Анатолій Дмитрович комітету Товариства Червоного Хреста (за згодою)

ІЖЕВСЬКА - виконуючий обов'язки начальника Тетяна Іванівна управління МЗС

КЛИМЕНКО - начальник відділу Мінпраці Надія Іванівна

МАТКОВСЬКИЙ - заступник начальника управління ДАІ Володимир Володимирович МВС

МІНЬКО - виконуючий обов'язки начальника відділу Тамара Андріївна об'єднання "Укрфармація"

МУЛЯВКА - головний спеціаліст управління Державної Вікторія Євгенівна податкової адміністрації

ПАВЛЮК - начальник головної екологічної інспекції Анатолій Миколайович Мінекобезпеки

ПЕТРОВА - головний інспектор управління Тетяна Костянтинівна Держмитслужби

ТОМКО - начальник відділу МНС Петро Федорович

( Склад робочої групи в редакції Розпоряджень КМ N 65-р ( 65-95-р ) від 08.02.95, N 173-р ( 173-97-р ) від 03.04.97, N 113-р ( 113-98-р ) від 25.02.98 )

Звільнити членів робочої групи від виконання службових обов'язків за основним місцем роботи на строк до 6 місяців.

Дозволити робочій групі залучати спеціалістів (з тимчасовим звільненням від виконання обов'язків за основним місцем роботи) для підготовки необхідних матеріалів з питань приймання, обліку, транспортування, охорони, складування та розподілу продовольства і медикаментів, що надходить із зарубіжних країн у вигляді гуманітарної допомоги, а також представників громадських, релігійних, добродійних та інших організацій і фондів.

Рекомендувати відповідним міністерствам і відомствам України, Раді Міністрів Кримської АРСР, облвиконкомам, Київському та Севастопольському міськвиконкомам, громадським організаціям утворити з відповідальних працівників свої робочі групи (штаби), поклавши на них оперативне вирішення зазначених питань.

Робочій групі, утвореній цим розпорядженням, забезпечити у своїй діяльності тісний контакт із указаними робочими групами (штабами).

3. Установити, що витрати, пов'язані з доставкою, отриманням і складуванням гуманітарної допомоги на місцях, провадяться за рахунок коштів місцевих бюджетів.

4. Прес-службі Прем'єр-міністра України разом з Укртелерадіокомпанією та Укрінформом забезпечити своєчасне інформування громадськості про надходження і розподіл гуманітарної допомоги.

5. Секретаріату Кабінету Міністрів України:

здійснювати матеріально-технічне забезпечення й автотранспортне обслуговування робочої групи, утвореної відповідно до цього розпорядження;

вирішити питання про виділення для зазначеної робочої групи службових приміщень.

6. Держкомзв'язку України невідкладно встановити у виділених для робочої групи службових приміщеннях телексний зв'язок і пряму факсимільну лінію.

7. Держнафтопродукту України забезпечити першочергове заправлення пально-мастильними матеріалами автотранспорту, який використовується для перевезення вантажів, що надходять із зарубіжних країн у вигляді гуманітарної допомоги.

Прем'єр-міністр України В.ФОКІН
