ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

28.05.2008 N 160

Зареєстровано в Міністерстві юстиції України 19 червня 2008 р. за N 543/15234

Про визнання наказу Держкомстату України від 16.06.2000 N 196 "Про затвердження форми державної статистичної звітності N 12-НКРЕ та Інструкції щодо її заповнення" таким, що втратив чинність

Відповідно до Законів України "Про державну статистику" ( 2614-12 ), "Про інформацію" ( 2657-12 ) та з метою приведення нормативно-правових актів Держкомстату України у відповідність до чинного законодавства НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Держкомстату України від 16.06.2000 N 196 ( z0387-00 ) "Про затвердження форми державної статистичної звітності N 12-НКРЕ та Інструкції щодо її заповнення", зареєстрований у Міністерстві юстиції України 04.07.2000 за N 387/4608.

2. Контроль за виконанням цього наказу покласти на першого заступника Голови Піщейка В.О.

Голова О.Г.Осауленко
