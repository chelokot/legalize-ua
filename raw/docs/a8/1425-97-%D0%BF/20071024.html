ПОСТАНОВА від 20 грудня 1997 р. N 1425 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про Голову Української частини Міжурядової Українсько-Югославської комісії з питань торговельно-економічного та науково-технічного співробітництва

Кабінет Міністрів України постановляє:

Затвердити Першого віце-прем'єр-міністра України Голубченка Анатолія Костянтиновича Головою Української частини Міжурядової Українсько-Югославської комісії з питань торговельно-економічного та науково-технічного співробітництва, увільнивши від цих обов'язків Мінченка Анатолія Калениковича.
