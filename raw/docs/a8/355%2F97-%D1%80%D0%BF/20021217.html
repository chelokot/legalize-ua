Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 355/97-рп

Текст документа від 17.12.2002:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва

( Із змінами, внесеними згідно з Розпорядженнями Президента N 231/2000-рп ( 231/2000-рп ) від 22.06.2000 N 175/2001-рп ( 175/2001-рп ) від 05.07.2001 N 400/2002-рп ( 400/2002-рп ) від 17.12.2002 )

1. Призначити ЯНУКОВИЧА Віктора Федоровича - Прем'єр-міністра України - головою Української частини Спільної українсько-узбецької комісії з всебічного співробітництва. ( Пункт 1 із змінами, внесеними згідно з Розпорядженнями Президента N 231/2000-рп від 22.06.2000, N 175/2001-рп від 05.07.2001, N 400/2002-рп ( 400/2002-рп ) від 17.12.2002 )

2. Міністерству закордонних справ України погодити з узбецькою стороною питання про затвердження В.Пустовойтенка Співголовою Спільної українсько-узбецької комісії з всебічного співробітництва.

Президент України Л.КУЧМА
