Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 12 березня 2008 р. N 175

ПОРЯДОК використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) для реструктуризації та ліквідації об'єктів підприємств гірничої хімії і здійснення невідкладних природоохоронних заходів у зоні їх діяльності

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 109 ( 109-2009-п ) від 18.02.2009 }

1. Цей Порядок визначає механізм використання у 2009 році коштів, передбачених Мінпромполітики у державному бюджеті ( 835-17 ) за програмою "Реструктуризація та ліквідація об'єктів підприємств гірничої хімії і здійснення невідкладних природоохоронних заходів в зоні їх діяльності" (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 109 ( 109-2009-п ) від 18.02.2009 }

2. Бюджетні кошти спрямовуються на виконання затвердженого Мінпромполітики за погодженням з Мінфіном плану робіт з реструктуризації та ліквідації об'єктів підприємств гірничої хімії і здійснення невідкладних природоохоронних заходів у зоні їх діяльності, який складається з урахуванням: { Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 109 ( 109-2009-п ) від 18.02.2009 }

плану заходів з ліквідації екологічних наслідків діяльності дочірнього підприємства "Калійний завод" ВАТ "Оріана" (м. Калуш) на 2003-2012 роки, затвердженого розпорядженням Кабінету Міністрів України від 19 серпня 2002 р. N 485 ( 485-2002-р );

проекту відновлення екологічної рівноваги та рекультивації порушених гірничими роботами земель Яворівського державного гірничо-хімічного підприємства "Сірка", затвердженого розпорядженням Кабінету Міністрів України від 24 лютого 2003 р. N 87 ( 87-2003-р );

проекту ліквідації сірчаних кар'єрів, відновлення екологічної рівноваги і ландшафту в зоні діяльності Роздільського ДГХП "Сірка", затвердженого розпорядженням Кабінету Міністрів України від 15 жовтня 2003 р. N 622 ( 622-2003-р );

комплексного проекту консервації рудника N 2 і рекультивації порушених земель Стебницького державного гірничо-хімічного підприємства "Полімінерал", затвердженого розпорядженням Кабінету Міністрів України від 24 березня 2004 р. N 166 ( 166-2004-р );

проекту закриття сірчаного кар'єру і відновлення ландшафту в зоні діяльності державного госпрозрахункового підприємства "Подорожненський рудник", затвердженого Мінпромполітики.

3. Одержувачами бюджетних коштів є дочірнє підприємство "Калійний завод" ВАТ "Оріана", Роздільське державне гірничо-хімічне підприємство "Сірка", Стебницьке державне гірничо-хімічне підприємство "Полімінерал", державне госпрозрахункове підприємство "Подорожненський рудник", державне підприємство "Новояворівське державне підприємство "Екотрансенерго".

4. Оплата рахунків за виконані роботи та надані послуги здійснюється одержувачами бюджетних коштів на підставі зареєстрованих в органах Державного казначейства бюджетних зобов'язань.

5. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

{ Пункт 5 в редакції Постанови КМ N 109 ( 109-2009-п ) від 18.02.2009 }

6. Відкриття Мінпромполітики та одержувачам бюджетних коштів рахунків в органах Державного казначейства, перерахування бюджетних коштів, а також відображення проведених операцій, пов'язаних з використанням бюджетних коштів, у бухгалтерському обліку та фінансовій звітності про виконання державного бюджету здійснюється у порядку, встановленому Державним казначейством.

{ Пункт 6 в редакції Постанови КМ N 109 ( 109-2009-п ) від 18.02.2009 }

7. Мінпромполітики складає та подає фінансову звітність про використання бюджетних коштів, а також здійснює контроль за їх цільовим та ефективним витрачанням в установленому законодавством порядку.

8. Оплата виконаних робіт здійснюється розпорядником бюджетних коштів або їх одержувачами на підставі актів фактично виконаних робіт за їх кошторисною вартістю відповідно до умов договорів.

9. Виконавці робіт у разі отримання попередньої оплати не пізніше ніж 5 числа місяця, що настає за звітним періодом, подають розпоряднику бюджетних коштів або їх одержувачам інформаційну довідку про фактично виконані обсяги робіт за формою, що затверджується головним розпорядником бюджетних коштів.

10. Одержувач бюджетних коштів щомісяця не пізніше ніж 5 числа наступного звітного періоду подає Мінпромполітики звіт про виконання робіт.
