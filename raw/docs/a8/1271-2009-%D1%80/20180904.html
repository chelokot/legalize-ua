{ Розпорядження втратило чинність на підставі Постанови КМ N 666 ( 666-2018-п ) від 29.08.2018 }

Про обов'язкову сертифікацію продукції шкільного асортименту

З метою врегулювання діяльності у сфері випуску друкованої продукції шкільного асортименту з дотриманням вимог Законів України "Про охорону дитинства" ( 2402-14 ) та "Про захист суспільної моралі" ( 1296-15 ) Держспоживстандарту включити з 1 листопада 2009 р. зошити шкільні, зошити загальні, щоденники шкільні, зошити для нот, альбоми для малювання, папки для зошитів шкільних, папки для праці, фарби, клей, інше учнівське приладдя, що використовується під час навчально-виховного процесу, до переліку продукції, що підлягає обов'язковій сертифікації МОН.

Прем'єр-міністр України Ю.ТИМОШЕНКО
