Кабінет Міністрів України; Постанова від 23.09.2009 № 1014

Питання добудови Національною акціонерною компанією "Нафтогаз України" підвідних газопроводів з високим рівнем будівельної готовності

Стан: Втратив чинність

Ідентифікатор: 1014-2009-п

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 вересня 2009 р. N 1014 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Питання добудови Національною акціонерною компанією "Нафтогаз України" підвідних газопроводів з високим рівнем будівельної готовності

{ Із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010 }

Кабінет Міністрів України постановляє:

Установити, що Національна акціонерна компанія "Нафтогаз України" та її дочірнє підприємство "Нафтогазмережі" здійснюють фінансування робіт з добудови підвідних газопроводів з високим рівнем будівельної готовності, які можуть бути введені в експлуатацію до 1 липня 2010 року та на будівництво яких замовниками проведено процедури закупівлі відповідно до законодавства, без застосування процедур закупівлі, визначених Положенням про закупівлю товарів, робіт і послуг за державні кошти, затвердженим постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006).

{ Постановляюча частина із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010 }

Прем'єр-міністр України Ю.ТИМОШЕНКО
