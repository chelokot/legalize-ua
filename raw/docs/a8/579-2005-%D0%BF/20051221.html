Про керівників деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 липня 2005 р. N 579 Київ

Про керівників деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

( Із змінами, внесеними згідно з Постановами КМ N 753 ( 753-2005-п ) від 18.08.2005 N 1231 ( 1231-2005-п ) від 21.12.2005 )

Кабінет Міністрів України постановляє:

1. Затвердити:

1) Першого віце-прем'єр-міністра України Кінаха Анатолія Кириловича:

головою Української частини Спільного комітету "Уряд/ЮНІДО";

головою Координаційної ради з питань аграрної політики;

головою Державної комісії з питань техногенно-екологічної безпеки та надзвичайних ситуацій;

головою Координаційної ради з питань врегулювання кризових ситуацій у вугільній промисловості;

головою Міжвідомчої комісії з реалізації реформи житлово-комунального господарства;

головою Міжвідомчої комісії з питань транспортних коридорів та транзитної політики;

головою Міжвідомчої комісії з комплексного розв'язання проблем Чорнобильської АЕС;

головою Комісії з організації діяльності технологічних парків та інноваційних структур інших типів;

( Абзац десятий підпункту 1 пункту 1 втратив чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

2) Віце-прем'єр-міністра України Безсмертного Романа Петровича:

головою ради Всеукраїнського конкурсу проектів та програм розвитку місцевого самоврядування;

3) Віце-прем'єр-міністра України Рибачука Олега Борисовича:

координатором співробітництва Кабінету Міністрів України з міжнародними фінансовими організаціями;

( Абзац третій підпункту 3 пункту 1 втратив чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

( Абзац четвертий підпункту 3 пункту 1 втратив чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

координатором програми INOGATE;

4) Віце-прем'єр-міністра України Томенка Миколу Володимировича:

головою Національної координаційної ради боротьби з наркоманією при Кабінеті Міністрів України;

головою Комісії з питань гуманітарної допомоги при Кабінеті Міністрів України;

головою Комітету з присудження Премії Кабінету Міністрів України за внесок молоді у розбудову держави;

головою Міжвідомчої комісії по боротьбі з туберкульозом ( 1480-2000-п );

( Абзац шостий підпункту 4 пункту 1 втратив чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

головою Комісії з встановлення пенсій за особливі заслуги перед Україною при Кабінеті Міністрів України;

головою Міжвідомчої ради з питань вивезення, ввезення та повернення культурних цінностей;

головою спостережної ради Українського фонду боротьби з ВІЛ-інфекцією і СНІДом;

головою Міжвідомчої ради з питань захисту прав споживачів;

головою Ради з питань реклами;

2. Увільнити Азарова Миколу Яновича, Кириленка Івана Григоровича, Клюєва Андрія Петровича, Табачника Дмитра Володимировича, Януковича Віктора Федоровича від обов'язків керівників органів, зазначених у пункті 1 цієї постанови.

3. Внести до постанов Кабінету Міністрів України зміни, що додаються.
