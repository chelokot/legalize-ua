Кабінет Міністрів України; Розпорядження від 26.05.2007 № 345-р

Про відкриття пункту пропуску через державний кордон на території ТОВ "Іллічівський судноремонтний завод"

Стан: Чинний

Ідентифікатор: 345-2007-р

Текст документа від 15.06.2018:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 травня 2007 р. N 345-р Київ

Про відкриття пункту пропуску через державний кордон на території ТОВ "Іллічівський судноремонтний завод"

{ Із змінами, внесеними згідно з Постановою КМ N 455 ( 455-2018-п ) від 06.06.2018 }

Відкрити на території ТОВ "Іллічівський судноремонтний завод" пункт пропуску через державний кордон "Чорноморський судноремонтний завод" для міжнародного морського вантажного сполучення (перевалка вантажів та заходження для ремонту невійськових суден) з постійним і цілодобовим режимом функціонування.

{ Текст Розпорядження із змінами, внесеними згідно з Постановою КМ N 455 ( 455-2018-п ) від 06.06.2018 }
