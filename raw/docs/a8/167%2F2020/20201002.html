Про делегацію України для участі у Тристоронній контактній групі

{Із змінами, внесеними згідно з Указами Президента
№ 302/2020 від 30.07.2020
№ 327/2020 від 18.08.2020
№ 414/2020 від 30.09.2020}

З метою забезпечення представництва України у Тристоронній контактній групі з мирного врегулювання ситуації в Донецькій і Луганській областях постановляю:

1. Утворити делегацію України для участі у Тристоронній контактній групі.

2. Затвердити склад делегації України для участі у Тристоронній контактній групі (додається).

3. Главі делегації України, першим заступникам глави делегації для участі у Тристоронній контактній групі забезпечувати організацію належної роботи делегації, визначати заступників представників України в робочих підгрупах та залучати в установленому порядку народних депутатів України, представників державних органів, радників, експертів і технічних працівників до роботи делегації.

{Стаття 3 із змінами, внесеними згідно з Указом Президента № 327/2020 від 18.08.2020 }

4. Організаційне, інформаційне, консультативне, аналітичне та інше забезпечення діяльності делегації України для участі у Тристоронній контактній групі покласти на Міністерство закордонних справ України.

5. Кабінету Міністрів України забезпечити фінансування витрат, пов'язаних з участю делегації України у Тристоронній контактній групі.

6. Визнати такими, що втратили чинність:

Указ Президента України від 19 червня 2019 року № 414 "Питання забезпечення представництва України у Тристоронній контактній групі";

Указ Президента України від 9 липня 2019 року № 504 "Про внесення зміни до Указу Президента України від 19 червня 2019 року № 414";

Указ Президента України від 13 серпня 2019 року № 596 "Про внесення зміни до Указу Президента України від 19 червня 2019 року № 414";

Указ Президента України від 18 вересня 2019 року № 701 "Про внесення зміни до Указу Президента України від 19 червня 2019 року № 414";

Указ Президента України від 11 лютого 2020 року № 51 "Про внесення зміни до Указу Президента України від 19 червня 2019 року № 414".
