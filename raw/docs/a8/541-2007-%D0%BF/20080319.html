Стан: Чинний

Ідентифікатор: 541-2007-п

Текст документа від 19.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 березня 2007 р. N 541 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для реконструкції та ремонту гуртожитків для учнів професійно-технічних і студентів вищих навчальних закладів

{ Із змінами, внесеними згідно з Постановою КМ N 228 ( 228-2008-п ) від 19.03.2008 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для реконструкції та ремонту гуртожитків для учнів професійно-технічних і студентів вищих навчальних закладів, здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 228 ( 228-2008-п ) від 19.03.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для реконструкції та ремонту гуртожитків для учнів професійно-технічних і студентів вищих навчальних закладів, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 березня 2007 р. N 541

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для реконструкції та ремонту гуртожитків для учнів професійно-технічних і студентів вищих навчальних закладів

Загальна частина

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених МОН у державному бюджеті ( 107-17 ) за програмою "Реконструкція та ремонт гуртожитків для учнів професійно-технічних та студентів вищих навчальних закладів" (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 228 ( 228-2008-п ) від 19.03.2008 }

2. Головним розпорядником бюджетних коштів є МОН.

Мета Порядку та напрями використання бюджетних коштів

3. Мета Порядку полягає у визначенні послідовності дій головного розпорядника бюджетних коштів при їх використанні на реконструкцію та ремонт гуртожитків для учнів професійно-технічних і студентів вищих навчальних закладів (далі - навчальні заклади), забезпеченні прозорої та ефективної процедури використання бюджетних коштів.

4. Бюджетні кошти спрямовуються на реконструкцію та ремонт гуртожитків навчальних закладів, насамперед тих, що перебувають у аварійному стані, та гуртожитків навчальних закладів, зазначених у додатку 2 до Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженої постановою Кабінету Міністрів України від 22 лютого 2008 р. N 107 ( 107-2008-п ).

{ Пункт 4 і редакції Постанови КМ N 228 ( 228-2008-п ) від 19.03.2008 }

Вимоги щодо використання бюджетних коштів

5. МОН за погодженням з Мінфіном формує згідно із заявками навчальних закладів перелік гуртожитків, реконструкція та ремонт яких здійснюються за рахунок бюджетних коштів.

6. Бюджетні кошти спрямовуються МОН у межах бюджетних призначень, встановлених Законом України "Про Державний бюджет України на 2008 рік та про внесення змін до деякх законодавчих актів України" ( 107-17 ), з урахуванням необхідності виконання взятих на облік в органах Державного казначейства бюджетних зобов'язань минулих років у разі їх відповідності паспорту бюджетної програми.

{ Пункт 6 із змінами, внесеними згідно з Постановою КМ N 228 ( 228-2008-п ) від 19.03.2008 }

7. Операції, пов'язані з бюджетними коштами, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

8. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється навчальними закладами відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

З метою недопущення виникнення кредиторської заборгованості на кінець року до договору про закупівлю товарів, робіт і послуг включається вимога щодо коригування визначеної в договорі суми та зобов'язань сторін договору у разі зменшення бюджетних призначень під час уточнення показників Державного бюджету України на 2007 рік ( 489-16 ).

9. Попередня оплата товарів, робіт і послуг за рахунок бюджетних коштів може здійснюватися у розмірі 30 відсотків їх вартості, визначеної у договорі, відповідно до постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752).

10. Остаточні розрахунки згідно з договором здійснюються навчальними закладами на підставі актів приймання-передачі відповідних рахунків.

Звітність про використання бюджетних коштів та контроль за їх витрачанням

11. Навчальні заклади надсилають МОН щомісяця до 15 числа наступного періоду звіт про використання бюджетних коштів за напрямами, передбаченими бюджетною програмою, для подання Мінфіну щомісяця до 25 числа.

12. МОН готує план заходів щодо реконструкції та ремонту гуртожитків навчальних закладів та затверджує відповідні результативні показники його виконання з поквартальною розбивкою.

Зазначені матеріали разом із затвердженим переліком гуртожитків та витрат, пов'язаних з їх реконструкцією та ремонтом, подаються Мінфіну у двотижневий строк.

Інформацію про виконання результативних показників МОН подає Мінфіну у тижневий строк після закінчення звітного кварталу та одинадцяти місяців.

{ Абзац четвертий пункту 12 виключено на підставі Постанови КМ N 228 ( 228-2008-п ) від 19.03.2008 }

13. За нецільове використання бюджетних коштів відповідальність несе головний розпорядник бюджетних коштів.

14. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
