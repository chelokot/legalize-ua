КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 вересня 2010 р. N 877 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 65 ( 65-2014-п ) від 01.03.2014 }

Про внесення змін до заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

Кабінет Міністрів України постановляє:

Внести до заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів, затверджених постановою Кабінету Міністрів України від 22 жовтня 2008 р. N 943 ( 943-2008-п ) "Про економію бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів" (Офіційний вісник України, 2008 р., N 84, ст. 2816; 2009 р., N 45, ст. 1507, N 83, ст. 2823, N 95, ст. 3269; 2010 р., N 5, ст. 200, N 60, ст. 2094), зміни, що додаються.
