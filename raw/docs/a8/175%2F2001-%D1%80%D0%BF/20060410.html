Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 175/2001-рп

Текст документа від 10.04.2006:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 299/2006 ( 299/2006 ) від 10.04.2006 }

Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва

1. На зміну Розпорядження Президента України від 18 жовтня 1997 року N 355 ( 355/97-рп ) (із змінами, внесеними Розпорядженням Президента України від 22 червня 2000 року N 231 ( 231/2000-рп ) призначити КІНАХА Анатолія Кириловича - Прем'єр-міністра України - головою Української частини Спільної українсько-узбецької комісії з всебічного співробітництва, увільнивши від цих обов'язків Ющенка В.А.

2. Голові Української частини Спільної українсько-узбецької комісії спільно з узбецькою стороною вжити заходів щодо активізації роботи Комісії, в тому числі щодо проведення чергового засідання Комісії в липні 2001 року.

Президент України Л.КУЧМА

м. Київ, 5 липня 2001 року N 175/2001-рп
