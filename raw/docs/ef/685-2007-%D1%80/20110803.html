Кабінет Міністрів України; Розпорядження від 30.08.2007 № 685-р

Про встановлення строку виконання на митній території України операцій з переробки товарів для виготовлення комплектів проводів, що використовуються в автомобілях

Стан: Втратив чинність

Ідентифікатор: 685-2007-р

Текст документа від 03.08.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 серпня 2007 р. N 685-р Київ

Про встановлення строку виконання на митній території України операцій з переробки товарів для виготовлення комплектів проводів, що використовуються в автомобілях

{ Із змінами, внесеними згідно з Розпорядженням КМ N 722-р ( 722-2011-р ) від 27.07.2011 }

Відповідно до частини третьої статті 232 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей виробництва встановити строк виконання на митній території України операцій з переробки товарів для виготовлення комплектів проводів за кодом 8544 30 00 98 згідно з УКТЗЕД ( 2371г-14 ), що використовуються в автомобілях, 360 днів.

Установити, що розпочаті та не завершені на момент набрання чинності цим розпорядженням операції виконуються у строк, передбачений цим розпорядженням.

{ Текст Розпорядження в редакції Розпорядження КМ N 722-р ( 722-2011-р ) від 27.07.2011 }
