Текст документа від 14.04.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 грудня 2000 р. N 485-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 461 ( 461-2004-п ) від 14.04.2004 )

Про встановлення днів засідань урядових комітетів

1. Установити, що засідання урядових комітетів проводяться у такі дні тижня (у міру готовності матеріалів для розгляду відповідних питань):

Урядового комітету з реформування аграрного сектору та з питань екології і надзвичайних ситуацій - понеділок;

Урядового комітету соціального та гуманітарного розвитку - вівторок;

Урядового комітету економічного розвитку - четвер;

Урядового комітету з питань оборони, оборонно-промислового комплексу та правоохоронної діяльності - п'ятниця;

Урядового комітету з реформування паливно-енергетичного комплексу - п'ятниця.

Засідання урядових комітетів проводяться, як правило, у першій половині дня.

2. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 2 березня 2000 р. N 109 ( 109-2000-р ) та від 8 листопада 2000 р. N 445 ( 445-2000-р ).
