Про заходи щодо забезпечення сільгосптоваровиробників нафтопродуктами для проведення весняно-польових робіт у 2010 році

Стан: Чинний

Ідентифікатор: 1590-2009-р

Текст документа від 11.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 2009 р. N 1590-р Київ

Про заходи щодо забезпечення сільгосптоваровиробників нафтопродуктами для проведення весняно-польових робіт у 2010 році

{ Із змінами, внесеними згідно з Розпорядженням КМ N 241-р ( 241-2010-р ) від 11.02.2010 }

1. Міністерству палива та енергетики, НАК "Нафтогаз України" з метою стабілізації цін на ринку пально-мастильних матеріалів та створення умов для накопичення сільгосптоваровиробниками нафтопродуктів для проведення весняно-польових робіт у 2010 році визначити дочірню компанію "Укргазвидобування" НАК "Нафтогаз України" підприємством, яке забезпечить протягом січня - травня 2010 р. постачання 55 тис. тонн дизельного палива та 85 тис. тонн бензину для потреб сільгосптоваровиробників.

Розподіл нафтопродуктів здійснити пропорційно посівним площам згідно з додатком.

2. Раді міністрів Автономної Республіки Крим та обласним держадміністраціям:

визначити протягом п'яти днів операторів-постачальників для постачання та реалізації нафтопродуктів сільгосптоваровиробникам за цінами, які встановлені з урахуванням відпускних цін виробника, вартості транспортування і зберігання та рівня рентабельності не більш як 5 відсотків;

здійснювати розподіл виділених обсягів нафтопродуктів між сільськогосподарськими підприємствами, фермерськими та особистими селянськими господарствами з урахуванням поданих ними заявок та в межах технологічної потреби у нафтопродуктах для проведення весняно-польових робіт;

проводити щомісяця аналіз стану постачання нафтопродуктів сільгосптоваровиробникам та подавати Міністерству аграрної політики і Міністерству палива та енергетики відповідну інформацію.

3. Міністерству аграрної політики разом з дочірньою компанією "Укргазвидобування" НАК "Нафтогаз України" у разі потреби здійснювати з урахуванням результатів аналізу стану постачання нафтопродуктів сільгосптоваровиробникам перерозподіл обсягів нафтопродуктів між регіонами на поточний та наступний місяці.

{ Пункт 3 в редакції Розпорядження КМ N 241-р ( 241-2010-р ) від 11.02.2010 }

4. Дочірній компанії "Укргазвидобування" НАК "Нафтогаз України" забезпечити відпуск визначених пунктом 1 цього розпорядження обсягів дизельного палива та бензину за ціною з урахуванням податку на додану вартість відповідно не вище 4900 гривень за тонну та 5500 гривень за тонну без урахування витрат, передбачених абзацом другим пункту 2 цього розпорядження.
