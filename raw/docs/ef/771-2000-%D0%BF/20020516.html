Текст документа від 16.05.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 травня 2000 р. N 771 Київ

( Постанова втратила чинність на підставі Постанови КМ N 622 ( 622-2002-п ) від 16.05.2002 )

Про уточнення переліку головних розпорядників коштів державного бюджету

Кабінет Міністрів України постановляє:

Зміни, внесені постановою Кабінету Міністрів України від 28 квітня 2000 р. N 725 ( 725-2000-п ) до переліку головних розпорядників коштів державного бюджету та схеми підпорядкування розпорядників коштів державного бюджету нижчого рівня та їх одержувачів головним розпорядникам цих коштів, затверджених постановою Кабінету Міністрів України від 8 січня 2000 р. N 13 ( 13-2000-п ) "Про вдосконалення системи головних розпорядників коштів державного бюджету" (Офіційний вісник України, 2000 р., N 2, ст. 36, N 6, ст. 225, N 7, ст. 274, N 8, ст. 321, N 12, ст. 468), викласти у новій редакції, що додається.
