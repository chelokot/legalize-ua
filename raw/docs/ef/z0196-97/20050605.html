( Постанова втратила чинність на підставі Постанови Національного банку N 163 ( z0572-05 ) від 12.05.2005 )

Про затвердження Порядку сплати платниками заборгованості за внесками до Пенсійного фонду України

( Із змінами, внесеними згідно з Постановами Нацбанку N 194 ( z0356-98 ) від 14.05.98 N 194 ( z0454-01 ) від 17.05.2001 )

На виконання статті 11 Указу Президента України від 28 лютого 1997 року N 187/97 "Про заходи щодо забезпечення наповнення державного бюджету та посилення фінансово-бюджетної дисципліни" Правління ПОСТАНОВЛЯЄ:

1. Скасувати постанову Правління Національного банку України від 24 березня 1997 року N 73.

2. Затвердити доопрацьований з урахуванням наданих Міністерством юстиції України зауважень Порядок сплати платниками заборгованості за внесками до Пенсійного фонду України (далі - Порядок).

3. Надіслати в установленому порядку постанову та Порядок для державної реєстрації до Міністерства юстиції України.

4. Управлінню платіжних систем та касового виконання Держбюджету (Л.В. Письменна) після державної реєстрації у Міністерстві юстиції України надіслати Порядок регіональним управлінням Національного банку України та комерційним банкам для керівництва в роботі.

5. Зобов'язати установи банків довести зміст цього Порядку до відома своїх клієнтів.

Голова В.А.Ющенко

ЗАТВЕРДЖЕНО постановою Правління Національного банку України від 30 квітня 1997 р. N 135

Зареєстровано в Міністерстві юстиції України 28 травня 1997 р. за N 196/2000

Положення про сплату заборгованості за зборами на обов'язкове державне пенсійне страхування ( Назва в редакції Постанов Нацбанку N 194 ( z0356-98 ) від 14.05.98 N 194 ( z0454-01 ) від 17.05.2001 )

( У тексті Порядку слова "внески" та "за внесками до Пенсійного фонду України" замінено на слова "збори" та "за зборами на обов'язкове державне пенсійне страхування" у відповідних відмінках згідно з Постановою Нацбанку N 194 ( z0356-98 ) від 14.05.98 )

На виконання Указу Президента України від 28 лютого 1997 року N 187/97 "Про заходи щодо забезпечення наповнення державного бюджету та посилення фінансово-бюджетної дисципліни" і з метою недопущення подальшого погіршення ситуації з виплатою пенсій, грошових допомог і зростання соціальної напруги встановлюється такий порядок сплати платниками заборгованості за зборами на обов'язкове державне пенсійне страхування:

1. Районні (міські) відділи Пенсійного фонду подають до установ банків за місцем відкриття платником поточних рахунків списки боржників за зборами на обов'язкове державне пенсійне страхування, затверджені керівником та завірені печаткою. Ці дані надаються установі банку не пізніше тридцятого числа звітного місяця. ( Пункт 1 із змінами, внесеними згідно з Постановами Нацбанку N 194 ( z0356-98 ) від 14.05.98, N 194 ( z0454-01 ) від 17.05.2001 )

2. При кожному отриманні коштів на виплату заробітної плати за чеком або при перерахуванні її платіжними дорученнями на рахунки працівників в установи банків боржник, який зазначений у списку (пункт 1), надає установі банку довідку про сплату зборів на обов'язкове державне пенсійне страхування, затверджену

органом Пенсійного фонду ( додаток N 1 ). Довідка готується у трьох примірниках. Перший примірник після його затвердження подається до установи банку, другий - залишається у районному (міському) відділі Пенсійного фонду, третій - у боржника.

У разі наявності у списку боржників платника зборів, який на час отримання коштів на виплату заробітної плати погасив заборгованість, він разом з чеком на отримання коштів на виплату заробітної плати (платіжними дорученнями на перерахування заробітної плати на рахунки працівників в установи банків) надає установі банку вищезазначену довідку з відміткою органу Пенсійного фонду про відсутність такої заборгованості на дату виплати заробітної плати.

3. При видачі коштів на виплату заробітної плати боржникам за зборами на обов'язкове державне пенсійне страхування відповідно до Постанови Верховної Ради України від 17.06.1993 р. N 3290-12 "Про порядок введення в дію Закону України "Про внесення змін і доповнень до Закону України "Про пенсійне забезпечення" (зі змінами, внесеними згідно з постановами Верховної Ради від 22.10.93 р. N 3550-12, від 07.02.96 р. N 36/96-ВР і Законом України від 13.07.95 р. N 305/95-ВР та Законом України "Про збір на обов'язкове державне пенсійне страхування" ( 400/97-ВР ) установи банків повинні вимагати від боржників одночасно з чеком на отримання готівки (платіжними дорученнями на перерахування заробітної плати на рахунки працівників в установи банків) платіжне доручення на перерахування суми зборів на обов'язкове державне пенсійне страхування. ( Абзац перший пункту 3 із змінами, внесеними згідно з Постановою Нацбанку N 194 ( z0356-98 ) від 14.05.98 )

У разі недостатності коштів видача їх на виплату заробітної плати і перерахування зборів на обов'язкове державне пенсійне страхування проводяться у пропорційних сумах. При цьому сума доручення на сплату зборів на обов'язкове державне пенсійне

страхування має відповідати сумі, зазначеній у рядку 6 довідки. 4. У разі, якщо комерційні банки не забезпечують перерахування боржниками зборів на обов'язкове державне пенсійне страхування під час видачі їм коштів на виплату заробітної плати відповідно до цього Положення, то згідно із статтею 11 Указу Президента України від 28.02.97 р. N 187/97 "Про заходи щодо забезпечення наповнення державного бюджету та посилення фінансово-бюджетної дисципліни" вони сплачують до Пенсійного фонду суму, яка дорівнює не сплаченому боржником збору, що підлягав сплаті пропорційно виданим коштам на заробітну плату.

У разі, якщо комерційні банки добровільно не перерахують вказану суму, то органи Пенсійного фонду стягують її у претензійно-позовному порядку.
