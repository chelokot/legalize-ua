{ Із змінами, внесеними згідно з Наказами Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 N 847/1520 ( z1245-08 ) від 22.12.2008 }

З метою раціонального та ефективного використання коштів, передбачених у Державному бюджеті України на відповідний рік на фінансову підтримку агропромислових підприємств, що знаходяться в особливо складних кліматичних умовах, НАКАЗУЄМО:

1. Затвердити Порядок використання коштів Державного бюджету України для надання фінансової підтримки агропромисловим підприємствам, що знаходяться в особливо складних кліматичних умовах, який додається.

2. Департаменту ринків рослинництва, садівництва, виноградарства та виноробства (Демидов О.А.) Міністерства аграрної політики України:

2.1. Забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

2.2. Довести цей наказ до відома Міністерства аграрної політики Автономної Республіки Крим, головних управлінь агропромислового розвитку обласних державних адміністрацій і Управління промисловості та агропромислового розвитку Севастопольської міської державної адміністрації.

3. Визнати таким, що втратив чинність, спільний наказ Міністерства аграрної політики України та Міністерства фінансів України від 27.02.2002 N 60/138 ( z0339-02 ) "Про затвердження Порядку використання коштів Державного бюджету України на фінансову підтримку агропромислових підприємств, що знаходяться в особливо складних кліматичних умовах", зареєстрований в Міністерстві юстиції України 5 квітня 2002 року за N 339/6627.

4. Контроль за виконанням цього наказу покласти на заступника Міністра аграрної політики України Мельника С.І. та заступника Міністра фінансів України Мярковського А.І.

ПОРЯДОК використання коштів Державного бюджету України для надання фінансової підтримки агропромисловим підприємствам, що знаходяться в особливо складних кліматичних умовах

1. Порядок використання коштів Державного бюджету України для надання фінансової підтримки агропромисловим підприємствам, що знаходяться в особливо складних кліматичних умовах (далі - Порядок), визначає механізм використання коштів, передбачених Міністерству аграрної політики України (далі - Мінагрополітики) у державному бюджеті, за бюджетною програмою КПКВ 2801280 "Фінансова підтримка агропромислових підприємств, що знаходяться в особливо складних кліматичних умовах", які спрямовуються на фінансову підтримку агропромислових підприємств, що знаходяться в особливо складних кліматичних умовах (далі - підтримка).

2. Підтримка надається агропромисловим підприємствам - одержувачам бюджетних коштів незалежно від організаційно-правової форми і форми власності (далі - сільгосппідприємства), які займаються виробництвом сільськогосподарської продукції і розміщені:

на територіях, які належать до поліських, відповідно до Переліку територій, що належать до поліських, затвердженого постановою Кабінету Міністрів України від 25.12.98 N 2068 ( 2068-98-п ) "Про визначення поліських територій України" (далі - Перелік);

у гірській місцевості і відповідають критеріям Закону України "Про статус гірських населених пунктів в Україні" ( 56/95-ВР ).

3. Бюджетні кошти використовуються сільгосппідприємствами на закупівлю мінеральних добрив, засобів захисту рослин, насіння не нижче третьої репродукції, запасних частин для сільськогосподарської техніки, регуляторів росту рослин та пально-мастильних матеріалів для власної виробничої діяльності. { Пункт 3 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 }

4. Головні управління агропромислового розвитку облдержадміністрацій, на території яких знаходяться райони, віднесені до поліських відповідно до Переліку ( 2068-98-п ), та райони, у складі яких є території, що відповідають критеріям Закону України "Про статус гірських населених пунктів в Україні" ( 56/95-ВР ), до 25 березня відповідного року за формою 6-зем ( za788-98 ) надають Мінагрополітики інформацію про наявну площу сільгоспугідь у сільгосппідприємствах, які знаходяться на територіях, що віднесені до поліських та мають статус гірських, за станом на 1 січня відповідного року за формою 6-зем ( za788-98 ). { Пункт 4 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 }

5. Мінагрополітики після отримання інформації від головних управлінь агропромислового розвитку облдержадміністрацій протягом п'яти робочих днів здійснює за погодженням з Міністерством фінансів України (далі - Мінфін) розподіл бюджетних коштів між областями пропорційно до наявної площі сільгоспугідь за станом на 1 січня відповідного року за формою 6-зем ( za788-98 ) у сільгосппідприємствах, які передбачені пунктом 2 Порядку. { Абзац перший пункту 5 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 }

Головні управління агропромислового розвитку облдержадміністрацій протягом трьох робочих днів після отримання розподілу бюджетних коштів від Мінагрополітики здійснюють розподіл коштів між районами пропорційно до наявної площі сільгоспугідь за станом на 1 січня відповідного року за формою 6-зем ( za788-98 ) у сільгосппідприємствах, які передбачені пунктом 2 Порядку. { Абзац другий пункту 5 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 }

Управління агропромислового розвитку райдержадміністрацій протягом трьох робочих днів після надходження інформації про розподіл бюджетних коштів від головних управлінь агропромислового розвитку облдержадміністрацій, але не пізніше ніж за 20 днів до засідання відповідних комісій розміщують у друкованих засобах масової інформації оголошення із зазначенням переліку необхідних для отримання підтримки документів, строків та умов їх подання. { Абзац третій пункту 5 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 }

Після затвердження розподілу бюджетних коштів Мінагрополітики протягом трьох робочих днів подає Державному казначейству України реєстр змін розподілу показників зведених кошторисів та планів асигнувань у розрізі регіонів пропорційно до затвердженого розподілу бюджетних коштів.

Головні управління агропромислового розвитку облдержадміністрацій протягом трьох робочих днів після надходження від Мінагрополітики інформації про розподіл бюджетних коштів затверджують кошториси та плани асигнувань у розрізі районів та передають їх регіональним управлінням Державного казначейства України.

6. Бюджетні кошти розподіляються Мінагрополітики, головними управліннями агропромислового розвитку облдержадміністрацій та управліннями агропромислового розвитку райдержадміністрацій пропорційно до сум, затверджених у планах асигнувань на відповідний період.

7. Для прийняття рішення щодо надання підтримки управління агропромислового розвитку райдержадміністрацій утворюють комісії, до складу яких включаються начальник управління (голова комісії), представник районного фінансового управління, органу державної контрольно-ревізійної служби, державної податкової інспекції (далі - комісії).

8. Сільгосппідприємства подають на розгляд районної комісії такі документи: { Абзац перший пункту 8 в редакції Наказу Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 }

звернення про виділення бюджетних коштів з визначенням напрямів їх використання;

копію довідки про включення до Єдиного державного реєстру підприємств і організацій України;

звіт про фінансові результати за попередній рік згідно з Положенням (стандартом) бухгалтерського обліку 3 "Звіт про фінансові результати", затвердженим наказом Міністерства фінансів України від 31.03.99 N 87 ( z0397-99 ), зареєстрованим в Міністерстві юстиції України 21 червня 1999 року за N 397/3690;

довідку Центру державного земельного кадастру щодо наявної площі земель сільськогосподарського призначення, які знаходяться у власності, постійному користуванні чи оренді, та/або довідку органу, який зареєстрував договір оренди земельної частки (паю) відповідно до постанови Кабінету Міністрів України від 24.01.2000 N 119 ( 119-2000-п ) "Про затвердження Порядку реєстрації договорів оренди земельної частки (паю); { Абзац п'ятий пункту 8 в редакції Наказу Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 }

довідки відповідних органів державної податкової служби та Пенсійного фонду України щодо відсутності (наявності) заборгованості з податкових зобов'язань та платежів до Пенсійного фонду, а також письмове зобов'язання сільгосппідприємства повернути у місячний строк до бюджету отримані бюджетні кошти у разі встановлення контрольними органами факту їх незаконного одержання та/або нецільового використання (у разі неповернення коштів у зазначений строк нараховується пеня у розмірі 120 відсотків річних облікової ставки Національного банку України за кожний день прострочення).

При цьому в разі виявлення зазначених фактів такому сільгосппідприємству припиняється надання будь-якої державної підтримки протягом цього та трьох наступних бюджетних періодів.

Копії поданих документів мають бути завірені в установленому порядку.

Бюджетні кошти не надаються підприємствам, що визнані банкрутами, проти яких порушено справу про банкрутство, що перебувають у стадії ліквідації або мають прострочену більше як півроку заборгованість перед державним і місцевими бюджетами (податкові платежі, позички) та Пенсійним фондом України. { Абзац пункту 8 в редакції Наказу Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 }

Комісія до першого травня розглядає подані документи та приймає рішення про включення сільгосппідприємства до реєстру сільгосппідприємств, що мають право на отримання фінансової підтримки з державного бюджету (далі - реєстр) (додаток 1). { Абзац пункту 8 в редакції Наказу Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 }

Комісія в межах доведеного до району обсягу бюджетних коштів визначає усереднений показник підтримки на 1 га сільгоспугідь по району пропорційно до наявної площі сільгоспугідь станом на 1 січня відповідного року в сільгосппідприємствах, по яких прийнято рішення про включення їх до реєстру. На підставі усередненого показника комісія визначає суму підтримки по кожному сільгосппідприємству та вносить їх до реєстру (додаток 1). { Абзац пункту 8 в редакції Наказу Міністерства аграрної політики N 149/396 ( z0218-08 ) від 13.03.2008 }

Комісія може здійснювати за підсумками дев'яти місяців, а надалі у разі потреби щомісяця, перерозподіл бюджетних коштів між сільськогосподарськими підприємствами, які мають право на фінансову підтримку, пропорційно потребі, визначеній у їх пропозиціях щодо зменшення обсягів бюджетних коштів, у разі неможливості їх використання або необхідності збільшення обсягів в межах загального річного ліміту асигнувань. { Пункт 8 доповнено абзацом згідно з Наказом Міністерства аграрної політики N 847/1520 ( z1245-08 ) від 22.12.2008 }

У разі відмови у наданні підтримки комісія надсилає сільгосппідприємству у триденний строк після прийняття відповідного рішення письмове повідомлення із зазначенням причин відмови.

Звернення, що надходять від сільгосппідприємств для отримання підтримки, розглядаються комісією в порядку черговості надходження та реєструються у журналі обліку, оформленому в установленому порядку.

Документи, подані сільгосппідприємствами, реєстри та журнал обліку зберігаються протягом трьох років в управліннях агропромислового розвитку райдержадміністрацій.

8-1. Мінагрополітики за погодженням з Мінфіном може здійснювати за підсумками дев'яти місяців, а надалі у разі потреби щомісяця, перерозподіл невикористаних бюджетних коштів між головними управліннями агропромислового розвитку обласних державних адміністрацій пропорційно потребі, визначеній у їх пропозиціях щодо зменшення обсягів бюджетних коштів, у разі неможливості їх використання або необхідності збільшення обсягів у межах загального річного ліміту асигнувань.

Головні управління агропромислового розвитку обласних держадміністрацій можуть здійснювати за підсумками дев'яти місяців, а надалі у разі потреби щомісяця, перерозподіл невикористаних бюджетних коштів між управліннями агропромислового розвитку районних державних адміністрацій пропорційно потребі, визначеній у їх пропозиціях щодо зменшення обсягів бюджетних коштів, у разі неможливості їх використання або необхідності збільшення обсягів у межах загального річного ліміту асигнувань. { Порядок доповнено пунктом 8-1 згідно з Наказом Міністерства аграрної політики N 847/1520 ( z1245-08 ) від 22.12.2008 }

9. Управління агропромислового розвитку райдержадміністрацій протягом п'яти робочих днів після завершення роботи комісії на підставі реєстрів подають районним відділенням Державного казначейства України розподіл асигнувань у розрізі сільгосппідприємств - одержувачів бюджетних коштів. Перерахування бюджетних коштів проводиться відповідно до Порядку обслуговування державного бюджету за видатками, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04 ), зареєстрованого в Міністерстві юстиції України 10 червня 2004 року за N 716/9315.

10. Управління агропромислового розвитку райдержадміністрацій звітують перед головними управліннями агропромислового розвитку облдержадміністрацій раз на місяць до 10 числа місяця, наступного за звітним, у розрізі сільгосппідприємств щодо обсягів наданої підтримки та напрямів використання коштів.

Головні управління агропромислового розвитку облдержадміністрацій за узагальненими показниками подають до Мінагрополітики один раз у квартал до 15 числа місяця, що настає за звітним, звіт про кількість сільгосппідприємств, яким надано підтримку, її обсяги та напрями використання коштів за формою згідно із додатком 2.

Мінагрополітики щоквартально подає Мінфіну до 20 числа місяця, що настає за звітним, узагальнену інформацію щодо кількості сільгосппідприємств, яким надано підтримку, її обсягів та напрямів використання бюджетних коштів.
