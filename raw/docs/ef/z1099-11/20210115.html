Про затвердження Порядку внесення плати за проведення професійної атестації відповідальних виконавців окремих видів робіт (послуг), пов'язаних із створенням об'єктів архітектури, та її розмірів

{ Із змінами, внесеними згідно з Наказом Міністерства розвитку громад та територій

N 282 ( z0012-21 ) від 19.11.2020 }

Відповідно до статті 17 Закону України "Про архітектурну діяльність" ( 687-14 ) та пункту 14 Порядку проведення професійної атестації відповідальних виконавців окремих видів робіт (послуг), пов'язаних із створенням об'єктів архітектури, затвердженого постановою Кабінету Міністрів України від 23.05.2011 N 554 ( 554-2011-п ), НАКАЗУЮ:

1. Затвердити Порядок внесення плати за проведення професійної атестації відповідальних виконавців окремих видів робіт (послуг), пов'язаних із створенням об'єктів архітектури, та її розміри, що додається.

2. Визнати таким, що втратив чинність, наказ Міністерства регіонального розвитку та будівництва України від 19.11.2009 N 498 ( z0281-10 ) "Про затвердження Розміру і порядку справляння плати за видачу кваліфікаційного сертифіката архітектора (його дубліката)", зареєстрований у Міністерстві юстиції України 08.04.2010 за N 281/17576.

3. Заступнику Міністра Ісаєнку Д.В. забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Цей наказ набирає чинності з дня офіційного опублікування.

5. Контроль за виконанням цього наказу покласти на заступника Міністра Д.В.Ісаєнка.

Міністр А.М.Близнюк

ЗАТВЕРДЖЕНО Наказ Міністерства регіонального розвитку, будівництва та житлово-комунального господарства України 01.09.2011 N 172

Зареєстровано в Міністерстві юстиції України 19 вересня 2011 р. за N 1099/19837

ПОРЯДОК внесення плати за проведення професійної атестації відповідальних виконавців окремих видів робіт (послуг), пов'язаних із створенням об'єктів архітектури, та її розміри

1. Цей Порядок визначає механізм внесення плати за проведення професійної атестації відповідальних виконавців окремих видів робіт (послуг), пов'язаних із створенням об'єктів архітектури, та її розміри.

2. Відповідальний виконавець окремих видів робіт (послуг), пов’язаних із створенням об’єктів архітектури (далі - відповідальний виконавець), вносить плату за проведення професійної атестації перед проведенням іспиту в розмірі 1,5 прожиткового мінімуму для працездатних осіб, встановленого станом на 01 січня поточного року.

{ Пункт 2 в редакції Наказу Міністерства розвитку громад та територій N 282 ( z0012-21 ) від 19.11.2020 }

3. Відповідальним виконавцям, які не склали іспит, плата за його проведення не повертається.

4. У разі прийняття Атестаційною архітектурно-будівельною комісією рішення про відмову у видачі кваліфікаційного сертифіката плата за видачу кваліфікаційного сертифіката не справляється.

5. Плата за проведення професійної атестації вноситься відповідальним виконавцем шляхом перерахування коштів через банки, платіжні пристрої чи відділення поштового зв’язку, або через мережу Інтернет з використанням платіжних систем та/або програмних засобів Єдиної державної електронної системи у сфері будівництва або іншої державної інформаційної системи, інтегрованої з Єдиною державною електронною системою у сфері будівництва.

{ Пункт 5 в редакції Наказу Міністерства розвитку громад та територій N 282 ( z0012-21 ) від 19.11.2020 }

6. Підтвердженням внесення плати за проведення професійної атестації є документ або інформація (реквізити платежу) про внесення плати в будь-якій формі.

{ Пункт 6 в редакції Наказу Міністерства розвитку громад та територій N 282 ( z0012-21 ) від 19.11.2020 }

7. Плата за проведення професійної атестації зараховується до доходів Державного бюджету України, крім випадку, передбаченого пунктом 8 цього Порядку.

{ Пункт 7 в редакції Наказу Міністерства розвитку громад та територій N 282 ( z0012-21 ) від 19.11.2020 }

8. У разі проведення професійної атестації на підставі делегованих повноважень саморегулівними організаціями у сфері архітектурної діяльності вноситься плата до таких організацій у розмірі, визначеному пунктом 2 цього Порядку.

{ Порядок доповнено новим пунктом 8 в редакції Наказу Міністерства розвитку громад та територій N 282 ( z0012-21 ) від 19.11.2020 }

9. Облік коштів, одержаних за проведення професійної атестації, а також контроль за їх використанням здійснюються відповідно до законодавства.

{ Пункт 9 із змінами, внесеними згідно з Наказом Міністерства розвитку громад та територій N 282 ( z0012-21 ) від 19.11.2020 }
