Стан: Втратив чинність

Текст документа від 29.04.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про новий склад Комісії при Президентові України у питаннях помилування

1. На зміну Указу Президента України від 6 грудня 1999 року N 1532 ( 1532/99 ) "Про Комісію при Президентові України у питаннях помилування" (зі змінами, внесеними Указом від 15 грудня 2001 року N 1220 ( 1220/2001 ) затвердити новий персональний склад Комісії при Президентові України у питаннях помилування (додається).

2. Визнати такими, що втратили чинність:

Указ Президента України від 9 грудня 1994 року N 745 ( 745/94 ) "Про Комісію при Президентові України у питаннях помилування";

Указ Президента України від 22 січня 1997 року N 64 ( 64/97 ) "Про зміни у складі Комісії при Президентові України у питаннях помилування";

Указ Президента України від 5 листопада 1998 року N 1215 ( 1215/98 ) "Про внесення змін до Указу Президента України від 9 грудня 1994 року N 745".
