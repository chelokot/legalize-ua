КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 грудня 2001 р. N 1626 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про внесення змін до структури Секретаріату Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Утворити у структурі Секретаріату Кабінету Міністрів України, затвердженій постановою Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) (Офіційний вісник України, 2000 р., N 4, ст. 110; 2001 р., N 25, ст. 1113), Управління з питань взаємодії з місцевими органами влади замість Управління експертизи та аналізу розвитку територій, що ліквідується.

Прем'єр-міністр України А.КІНАХ
