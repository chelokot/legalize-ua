Стан: Втратив чинність

Ідентифікатор: 1052-2000-п

Текст документа від 02.04.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 липня 2000 р. N 1052 Київ

Про внесення змін до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

( Із змінами, внесеними згідно з Постановою КМ N 314 ( 314-2001-п ) від 02.04.2001 )

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339, N 11, ст. 419, N 13, ст. 519) такі зміни:

1) у додатку 1:

у позиції "Державний комітет зв'язку та інформатизації" цифри "162" замінити цифрами "198";

у позиції "Державний комітет у справах релігій" цифру "1" замінити цифрою "2";

у позиції "Усього" цифри "12134" замінити цифрами "12170", а цифри "154"- цифрами "155";

( Пункт 2 втратив чинність на підставі Постанови КМ N 314 ( 314-2001-п ) від 02.04.2001 )
