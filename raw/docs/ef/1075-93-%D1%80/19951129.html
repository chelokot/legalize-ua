Про звільнення МВС від сплати ввізного мита

Стан: Втратив чинність

Ідентифікатор: 1075-93-р

Текст документа від 29.11.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 грудня 1993 р. N 1075-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 957 ( 957-95-п ) від 29.11.95 )

З метою забезпечення спеціальних підрозділів по боротьбі з організованою злочинністю органів внутрішніх справ засобами оперативної та спеціальної техніки звільнити МВС від сплати ввізного мита при поставці зазначених технічних засобів згідно з контрактами N 040-81135 і ПП-1330/3365/933-Д.
