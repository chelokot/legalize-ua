Верховна Рада України; Закон від 13.01.2005 № 2340-IV

Про внесення змін до деяких законів України (щодо розроблення, виготовлення, реалізації, ремонту, модернізації та утилізації озброєння, військової техніки, військової зброї і боєприпасів до неї)

Стан: Чинний

Ідентифікатор: 2340-15

Текст документа від 01.01.2021:

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України (щодо розроблення, виготовлення, реалізації, ремонту, модернізації та утилізації озброєння, військової техніки, військової зброї і боєприпасів до неї)

( Відомості Верховної Ради України (ВВР), 2005, N 9, ст.183 )

{ Із змінами, внесеними згідно із Законами N 222-VIII ( 222-19 ) від 02.03.2015, ВВР, 2015, N 23, ст.158 N 808-IX ( 808-20 ) від 17.07.2020 }

Верховна Рада України постановляє:

I. Внести зміни до таких законів України:

1. У частині другій статті 4 Закону України "Про підприємництво" ( 698-12 ) (Відомості Верховної Ради УРСР, 1991 р., N 14, ст. 168; Відомості Верховної Ради України, 2000 р., N 36, ст. 299) слова "виготовленням і реалізацією військової зброї та боєприпасів до неї" виключити.

{ Пункт 2 розділу I втратив чинність на підставі Закону N 808-IX ( 808-20 ) від 17.07.2020 }

{ Пункт 3 розділу I втратив чинність на підставі Закону N 222-VIII ( 222-19 ) від 02.03.2015 }

II. Прикінцеві положення

1. Цей Закон набирає чинності через шість місяців з дня його опублікування.

2. Кабінету Міністрів України протягом трьох місяців з дня опублікування цього Закону:

подати до Верховної Ради України пропозиції щодо внесення змін до законів України, що випливають із цього Закону;

прийняти нормативно-правові акти, необхідні для реалізації цього Закону;

забезпечити перегляд і скасування міністерствами та іншими центральними органами виконавчої влади їх нормативно-правових актів, що суперечать цьому Закону.
