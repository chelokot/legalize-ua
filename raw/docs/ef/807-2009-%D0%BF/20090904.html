Деякі питання організації діяльності Державної міграційної служби

Текст документа від 04.09.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 липня 2009 р. N 807 Київ

Деякі питання організації діяльності Державної міграційної служби

{ Додатково див. Указ Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }

Кабінет Міністрів України постановляє:

1. Внести у додаток до постанови Кабінету Міністрів України від 13 травня 2009 р. N 464 ( 464-2009-п ) "Про затвердження граничної чисельності працівників апарату центральних органів виконавчої влади і підпорядкованих їм територіальних органів та інших державних органів" (Офіційний вісник України, 2009 р., N 36, ст. 1226) такі зміни:

у позиції "Держкомнацрелігій" цифри "123" замінити цифрами "96", а цифри "150" виключити;

доповнити додаток позицією:

"ДМС 102/224* 6133/6633*".

{ Дію пункту 2 зупинено згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }

2. У пункті 1 постанови Кабінету Міністрів України від 7 березня 2007 р. N 418 ( 418-2007-п ) "Про затвердження граничної чисельності працівників центрального апарату Міністерства внутрішніх справ" (Офіційний вісник України, 2007 р., N 18, ст. 726; 2008 р., N 68, ст. 2272) цифри "3900" замінити цифрами "3825".

3. Міністерству внутрішніх справ подати у двомісячний строк Кабінетові Міністрів України законопроект стосовно зменшення загальної чисельності Міністерства внутрішніх справ на 5983 особи.

{ Дію пункту 4 зупинено щодо передачі відповідних бюджетних призначень від Міністерства внутрішніх справ України до Державної міграційної служби України у зв'язку з перерозподілом функцій згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }

4. Міністерству внутрішніх справ, Державному комітетові у справах національностей та релігій разом з Міністерством фінансів вирішити питання щодо передачі в установленому порядку відповідних бюджетних призначень від Міністерства внутрішніх справ та Державного комітету у справах національностей та релігій до Державної міграційної служби у зв'язку з перерозподілом функцій.

5. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським, районним у мм. Києві та Севастополі державним адміністраціям сприяти Державній міграційній службі у вирішенні організаційно-технічних та інших питань, пов'язаних з утворенням і функціонуванням її територіальних органів та підрозділів.

Прем'єр-міністр України Ю.ТИМОШЕНКО
