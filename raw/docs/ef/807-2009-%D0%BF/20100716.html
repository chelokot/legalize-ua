{ Додатково див. Указ Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }

{ Припинено конституційне провадження у справі за конституційним поданням Президента України ( n0029100-09 ) щодо відповідності Конституції України ( 254к/96-ВР ) (конституційності) пункту 4 цієї Постанови згідно з Рішенням Конституційного Суду N 6-рп/2010 ( v006p710-10 ) від 17.02.2010 }

{ Із змінами, внесеними згідно з Постановою КМ N 559 ( 559-2010-п ) від 07.07.2010 }

Кабінет Міністрів України постановляє:

1. Внести у додаток до постанови Кабінету Міністрів України від 13 травня 2009 р. N 464 ( 464-2009-п ) "Про затвердження граничної чисельності працівників апарату центральних органів виконавчої влади і підпорядкованих їм територіальних органів та інших державних органів" (Офіційний вісник України, 2009 р., N 36, ст. 1226) такі зміни:

у позиції "Держкомнацрелігій" цифри "123" замінити цифрами "96", а цифри "150" виключити;

доповнити додаток позицією:

"ДМС 102/224* 6133/6633*".

{ Дію пункту 2 зупинено згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }

2. У пункті 1 постанови Кабінету Міністрів України від 7 березня 2007 р. N 418 ( 418-2007-п ) "Про затвердження граничної чисельності працівників центрального апарату Міністерства внутрішніх справ" (Офіційний вісник України, 2007 р., N 18, ст. 726; 2008 р., N 68, ст. 2272) цифри "3900" замінити цифрами "3825".
