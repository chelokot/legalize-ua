КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 січня 2007 р. N 12-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 570-р ( 570-2007-р ) від 25.07.2007 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 16 червня 2003 р. N 365

1. У розділі "На кордоні з Республікою Польща" переліку пунктів пропуску через митний кордон України для автомобільного сполучення, через які здійснюється ввезення на її митну територію та переміщення транзитом товарів 1-24 груп (крім підакцизних) згідно з УКТЗЕД, затвердженого розпорядженням Кабінету Міністрів України від 16 червня 2003 р. N 365 ( 365-2003-р ) (Офіційний вісник України, 2003 р., N 25, ст. 1215), виключити таку позицію:

"Рава-Руська Рава-Руська - Хребенне".

2. Це розпорядження набирає чинності через сім днів після опублікування.

Прем'єр-міністр України В.ЯНУКОВИЧ
