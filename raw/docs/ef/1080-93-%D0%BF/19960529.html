Про прискорення темпів створення потужностей по видобуванню та переробці бурштину

Стан: Втратив чинність

Ідентифікатор: 1080-93-п

Текст документа від 29.05.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 грудня 1993 р. N 1080 Київ

Про прискорення темпів створення потужностей по видобуванню та переробці бурштину

( Із змінами, внесеними згідно з Постановами КМ N 957 ( 957-95-п ) від 29.11.95 N 576 ( 576-96-п ) від 29.05.96 )

З метою прискорення темпів створення потужностей по видобуванню та переробці бурштину в Рівненській області Кабінет Міністрів України постановляє:

1. Корпорації "Укрбуд" забезпечити у I кварталі 1994 р. за замовленням державного підприємства "Укрбурштин" розроблення проектної документації на будівництво фабрики переробки бурштину на базі недобудованої фабрики дитячої іграшки у м. Рівному.

Корпораціям "Укрбуд" та "Укрмонтажспецбуд" забезпечити будівництво і введення в експлуатацію першої черги фабрики переробки бурштину в IV кварталі 1994 року.

2. Міністерству економіки, Міністерству фінансів передбачати виділення державному підприємству "Укрбурштин" фінансових ресурсів для створення виробничих потужностей по видобуванню та переробці бурштину. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 576 ( 576-96-п ) від 29.05.96 )

3. Виділити державному підприємству "Укрбурштин" 800 тис. німецьких марок на закупівлю імпортного каменеобробного та ювелірного обладнання.

Міністерству фінансів профінансувати зазначені витрати за рахунок надходжень валютних коштів від експорту продукції за державними контрактами.

( Абзац третій пункту 3 втратив чинність у частині звільнення від сплати ввізного мита на підставі Постанови КМ N 957 ( 957-95-п ) від 29.11.95 )

4. Державному комітету по геології і використанню надр забезпечити виконання у 1994 році пошукових та геологорозвідувальних робіт у межах Дубровицького і Володимирського родовищ бурштину та на дільниці "Меліоративне" Клесівського родовища.

5. Міністерству внутрішніх справ забезпечити надійну охорону об'єктів видобування і переробки бурштину, родовищ, на яких проводяться пошукові та геологорозвідувальні роботи. Дозволити державному підприємству "Укрбурштин" створення воєнізованого підрозділу для охорони бурштину і виробів з нього під час їх транспортування.

6. Міністерству внутрішніх справ, Державному митному комітетові разом із Службою безпеки вжити заходів до припинення незаконного вивезення за межі України бурштину в сировинному і обробленому вигляді та у разі вилучення забезпечити їх передачу державному підприємству "Укрбурштин".

7. Київській міській державній адміністрації до 1 лютого 1994 р. вирішити питання про надання державному підприємству "Укрбурштин" приміщення у центральній частині м. Києва для створення спеціалізованого магазину по продажу ювелірно-художніх виробів із бурштину.
