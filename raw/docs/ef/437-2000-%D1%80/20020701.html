Текст документа від 01.07.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 листопада 2000 р. N 437-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 876 ( 876-2002-п ) від 01.07.2002 )

Про зміни у складі осіб, уповноважених представляти інтереси держави у правлінні Фонду загальнообов'язкового державного соціального страхування на випадок безробіття

Ввести до складу осіб, уповноважених представляти інтереси держави у правлінні Фонду загальнообов'язкового державного соціального страхування на випадок безробіття, затвердженого розпорядженням Кабінету Міністрів України від 5 липня 2000 р. N 283 ( 283-2000-р ), Савенка Олександра Леонідовича - заступника начальника управління Департаменту економічної стратегії Мінекономіки, вивівши з нього Латік Валентину Вікторівну.

Перший віце-прем'єр-міністр України Ю.ЄХАНУРОВ
