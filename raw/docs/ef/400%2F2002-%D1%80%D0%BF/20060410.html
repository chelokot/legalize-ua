РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 299/2006 ( 299/2006 ) від 10.04.2006 }

Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва

На зміну Розпорядження Президента України від 18 жовтня 1997 року N 355 ( 355/97-рп ) (зі змінами, внесеними Розпорядженнями від 22 червня 2000 року N 231 ( 231/2000-рп ) та від 5 липня 2001 року N 175 ( 175/2001-рп ) призначити ЯНУКОВИЧА Віктора Федоровича - Прем'єр-міністра України - головою Української частини Спільної українсько-узбецької комісії з всебічного співробітництва, увільнивши від виконання цих обов'язків Кінаха А.К.

Президент України Л.КУЧМА

м. Київ, 17 грудня 2002 року N 400/2002-рп
