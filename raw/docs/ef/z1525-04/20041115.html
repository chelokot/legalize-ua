Текст документа від 15.11.2004:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З НАГЛЯДУ ЗА ОХОРОНОЮ ПРАЦІ

НАКАЗ

15.11.2004 N 254

Зареєстровано в Міністерстві юстиції України 1 грудня 2004 р. за N 1525/10124

Про визнання наказу від 02.07.98 N 135 "Про затвердження Типового положення про територіальне управління Комітету по нагляду за охороною праці України" таким, що втратив чинність

На виконання Указу Президента України від 16.01.2003 N 29 ( 29/2003 ) "Питання Державного комітету України з нагляду за охороною праці", НАКАЗУЮ:

1. Наказ Держнаглядохоронпраці від 02.07.98 N 135 ( z0504-98 ) "Про затвердження Типового положення про територіальне управління Комітету по нагляду за охороною праці України", зареєстрований в Міністерстві юстиції України 10.08.98 за N 504/2944, визнати таким, що втратив чинність.

2. Управлінню нормативно-правового та юридичного забезпечення (Кубієвич М.В.):

подати цей наказ на державну реєстрацію до Міністерства юстиції України;

внести відповідні зміни до державного реєстру нормативно-правових актів з питань охорони праці;

3. Загальному відділу (Дєньгін А.П.) у тижневий термін, після реєстрації у Міністерстві юстиції України, довести цей наказ до відома територіальних управлінь.

4. Контроль за виконанням цього наказу покласти на заступника Голови Комітету Семка О.П.
