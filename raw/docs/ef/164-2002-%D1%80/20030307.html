Кабінет Міністрів України; Розпорядження від 29.03.2002 № 164-р

Про передачу МВС повноважень з управління державними корпоративними правами ВАТ "КП ОТІ"

Стан: Втратив чинність

Ідентифікатор: 164-2002-р

Текст документа від 07.03.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 березня 2002 р. N 164-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 301 ( 301-2003-п ) від 07.03.2003 )

Про передачу МВС повноважень з управління державними корпоративними правами ВАТ "КП ОТІ"

На зміну пункту 1 розпорядження Кабінету Міністрів України від 12 квітня 2000 р. N 178 ( 178-2000-р ) (Офіційний вісник України, 2000 р., N 15, ст. 631) прийняти пропозицію МВС, погоджену з Фондом державного майна та Мін'юстом, про передачу МВС повноважень з управління державними корпоративними правами ВАТ "КП ОТІ".

Прем'єр-міністр України А.КІНАХ
