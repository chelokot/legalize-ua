Кабінет Міністрів України; Розпорядження від 12.04.2000 № 178-р

Про передачу Мін'юсту повноважень з управління державним пакетом акцій ВАТ "КП ОТІ"

Стан: Втратив чинність

Ідентифікатор: 178-2000-р

Текст документа від 07.03.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 квітня 2000 р. N 178-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 301 ( 301-2003-п ) від 07.03.2003 )

( Із змінами, внесеними згідно з Розпорядженням КМ N 164-р ( 164-2002-р ) від 29.03.2002 )

1. Прийняти пропозицію Мін'юсту, погоджену з Фондом державного майна та Київською міськдержадміністрацією, про передачу Мін'юсту повноважень з управління державним пакетом акцій ВАТ "КП ОТІ" у розмірі 25 відсотків статутного фонду плюс одна акція.

( На зміну пункту 1 прийняти пропозицію МВС, погоджену з Фондом державного майна та Мін'юстом, про передачу МВС повноважень з управління державними корпоративними правами ВАТ "КП ОТІ" згідно з Розпорядженням КМ N 164-р ( 164-2002-р ) від 29.03.2002 )

2. Виключити з додатка 42 до постанови Кабінету Міністрів України від 3 червня 1999 р. N 951 ( 951-99-п ) "Про передачу повноважень з управління державними корпоративними правами Раді міністрів Автономної Республіки Крим, міністерствам, іншим центральним і місцевим органам виконавчої влади" (Офіційний вісник України, 1999 р., N 23, ст. 1053) таку позицію:

"21502504 ВАТ "Колективне підприємство ОТІ".

Прем'єр-міністр України В.ЮЩЕНКО
