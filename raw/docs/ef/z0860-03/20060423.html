{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 104 ( z0424-06 ) від 05.04.2006 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 04.02.2000 N 29

На виконання постанови Кабінету Міністрів України від 6 серпня 2003 року N 1207 ( 1207-2003-п ) "Про підвищення посадових окладів працівників органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести до наказу Міністерства праці та соціальної політики України від 04.02.2000 N 29 ( z0086-00 ) "Про умови оплати праці працівників соціальних служб для молоді", зареєстрованого в Міністерстві юстиції України 11.02.2000 за N 86/4307 (зі змінами), такі зміни:

1) у назві наказу слова "соціальних служб для молоді" замінити на слова "центрів соціальних служб для молоді";

2) додатки 1-6 викласти в новій редакції (додаються).

2. Ці умови набирають чинності з 1 вересня 2003 року.
