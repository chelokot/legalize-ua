КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 серпня 2005 р. N 797 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 609 ( 609-2015-п ) від 05.08.2015 }

Про внесення зміни до переліку органів ліцензування

Кабінет Міністрів України постановляє:

У пункті 32 переліку органів ліцензування, затвердженого постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001; 2002 р., N 23, ст. 1103), слово "Держкомспорт" замінити словом "Мінсім'ямолодьспорт".
