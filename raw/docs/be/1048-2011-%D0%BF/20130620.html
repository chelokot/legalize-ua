з питань діяльності Міністерства екології та природних ресурсів та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 414 ( 414-2013-п ) від 12.06.2013 }

Кабінет Міністрів України постановляє:

1. Внести до актів Кабінету Міністрів України з питань діяльності Міністерства екології та природних ресурсів зміни, що додаються.

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.
