N 205 ( 205-2009-п ) "Про затвердження Порядку використання у 2009 році коштів Стабілізаційного фонду для виконання Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу та внесення змін до постанови Кабінету Міністрів України від 22 лютого 2008 р. N 107" (Офіційний вісник України, 2009 р., N 19, ст. 601, N 59, ст. 2067) зміни, що додаються.

2. Затвердити Порядок використання у 2010 році коштів Стабілізаційного фонду для підготовки об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, що додається.

3. Виділити за рахунок залишків коштів Стабілізаційного фонду ( 2154-17 ) станом на 1 січня 2010 р., а у разі їх недостатності - за рахунок надходжень від цільового розміщення державних цінних паперів для підготовки об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу 4494352 тис. гривень, зокрема Національному агентству з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу - 3934134,8 тис., Міністерству фінансів - 239668,2 тис., Міністерству економіки - 1200 тис., Міністерству внутрішніх справ - 3070 тис., Службі безпеки - 6000 тис., Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи - 77700 тис., Міністерству охорони здоров'я - 27800 тис., Міністерству культури і туризму - 48834 тис., Міністерству регіонального розвитку та будівництва - 945 тис., Міністерству освіти і науки - 155000 тис. гривень (далі - кошти Стабілізаційного фонду).

Розпорядником бюджетних коштів нижчого рівня за напрямом, передбаченим абзацом двадцять шостим пункту 2 цього Порядку, є Національна телекомпанія. { Абзац другий пункту 3 із змінами, внесеними згідно з Постановами КМ N 73 ( 73-2010-п ) від 28.01.2010, N 239 ( 239-2010-п ) від 01.03.2010, N 301 ( 301-2010-п ) від 12.04.2010 }

4. Бюджетні кошти виділяються на безповоротній основі та з урахуванням Порядку використання у 2010 році коштів Стабілізаційного фонду для виконання Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженого постановою Кабінету Міністрів України від 2 червня 2010 р. N 419 ( 419-2010-п ), та Порядку використання коштів Стабілізаційного фонду, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) (Офіційний вісник України, 2009 р., N 24, ст. 793), - із змінами, внесеними постановою Кабінету Міністрів України від 13 січня 2010 р. N 33 ( 33-2010-п ).

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }

5. Державне казначейство відкриває бюджетне асигнування головним розпорядникам бюджетних коштів відповідно до розпису державного бюджету та за умови відсутності на їх рахунках залишків бюджетних коштів за відповідними бюджетними програмами.

6. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

7. Головні розпорядники бюджетних коштів беруть бюджетні зобов'язання виключно у межах фактично перерахованих на рахунки коштів.

8. Фінансування об'єктів капітального будівництва здійснюється відповідно до Порядку державного фінансування капітального будівництва, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) (Офіційний вісник України, 2001 р., N 52, ст. 2374).

9. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів та їх попередня оплата здійснюються в установленому законодавством порядку.

10. Державне казначейство подає щомісяця до 16 числа Мінфіну інформацію про використання бюджетних коштів у розрізі їх головних розпорядників, бюджетних програм, заходів та об'єктів.

11. Головні розпорядники бюджетних коштів подають щомісяця до 10 числа Мінфіну звіт про використання бюджетних коштів за встановленою ним формою.

12. Після закінчення бюджетного періоду залишки бюджетних коштів, що обліковуються на рахунках їх розпорядників станом на 1 січня 2011 р., повертаються до державного бюджету.

{ Пункт 12 із змінами, внесеними згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }

13. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням і своєчасним поверненням здійснюються в установленому законодавством порядку.
