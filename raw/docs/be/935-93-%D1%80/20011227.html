Кабінет Міністрів України; Розпорядження від 04.11.1993 № 935-р

Про надання обов'язків голови центральної комісії з питань координації роботи, пов'язаної із приватизаційними паперами, Ландику В.І.

Стан: Втратив чинність

Ідентифікатор: 935-93-р

Текст документа від 27.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 листопада 1993 р. N 935-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1758 ( 1758-2001-п ) від 27.12.2001 )

Покласти обов'язки голови центральної комісії з питань координації роботи, пов'язаної із складанням та уточненням списків громадян, які мають право на одержання приватизаційних паперів, утвореної відповідно до постанови Кабінету Міністрів України від 25 листопада 1992 р. N 656 ( 656-92-п ) "Про порядок складання та уточнення списків громадян, які мають право на одержання приватизаційних паперів", на Віце-прем'єр-міністра України Ландика В.І.

Виконуючий обов'язки Прем'єр-міністра України Ю.ЗВЯГІЛЬСЬКИЙ
