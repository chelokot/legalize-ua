УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанов Кабінету Міністрів України від 16 січня 2007 року N 35 та від 14 березня 2007 року N 443

{ Додатково див. Конституційне подання Президента ( n0024100-08 ) від 07.07.2008 }

Кабінетом Міністрів України 16 січня 2007 року видано постанову N 35 ( 35-2007-п ), "Питання Київського національного університету імені Тараса Шевченка".

Відповідно до зазначеної постанови Кабінет Міністрів України, з посиланням на статтю 5 Закону України "Про управління об'єктами державної власності" ( 185-16 ) та Закон України "Про вищу освіту" ( 2984-14 ), погодився з рішенням конференції трудового колективу Київського національного університету імені Тараса Шевченка та установив, що зазначений Університет підпорядковується Кабінету Міністрів України (абзац перший пункту 1), а також підтвердив повноваження В. Скопенка як ректора Київського національного університету імені Тараса Шевченка та доручив Віце-прем'єр-міністрові України Д. Табачнику підписати з В. Скопенком контракт (абзац другий пункту 1).

14 березня 2007 року Кабінет Міністрів України постановою N 443 ( 443-2007-п ) затвердив Статут Київського національного університету імені Тараса Шевченка, за яким до повноважень Кабінету Міністрів України віднесено, зокрема, питання призначення за поданням конференції трудового колективу ректора названого Університету (пункти 15, 16).

Названі акти Кабінету Міністрів України ( 35-2007-п, 443-2007-п ) не відповідають Конституції України ( 254к/96-ВР ).

Конституція України ( 254к/96-ВР ) наділяє Кабінет Міністрів України повноваженням здійснювати управління об'єктами державної власності відповідно до закону (пункт 5 статті 116).

Законами, що визначають засади управління об'єктами державної власності, функціонування системи вищої освіти та здійснення управління у цій сфері, є Закони України "Про управління об'єктами державної власності" ( 185-16 ), "Про освіту" ( 1060-12 ) та "Про вищу освіту" ( 2984-14 ). Ці Закони ( 185-16, 1060-12, 2984-14 ) не відносять до повноважень Кабінету Міністрів України здійснення таких функцій з управління вищими навчальними закладами державної форми власності, як призначення керівників та затвердження статутів таких закладів, не передбачають підпорядкування вищих навчальних закладів державної форми власності Кабінету Міністрів України та призначення керівників таких закладів шляхом підтвердження їх повноважень. За Законом України "Про вищу освіту" ( 2984-14 ), що є спеціальним законом, який регулює питання управління вищими навчальними закладами державної форми власності, зазначені повноваження здійснюються уповноваженим центральним органом виконавчої влади у галузі освіти і науки, а також іншими центральними органами виконавчої влади (статті 1, 18, 29, 37 і 39).

За таких обставин, видавши постанови від 16 січня 2007 року N 35 ( 35-2007-п ) та від 14 березня 2007 року N 443 ( 443-2007-п ), Кабінет Міністрів України діяв усупереч пункту 5 статті 116 Конституції України ( 254к/96-ВР ).

Конституція України ( 254к/96-ВР ) проголосила Україну правовою державою (стаття 1), в якій визнається і діє принцип верховенства права (стаття 8). Згідно із закріпленими Конституцією України ( 254к/96-ВР ) основами правового порядку в Україні органи державної влади зобов'язані діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України (частина друга статті 19); організація, повноваження і порядок діяльності Кабінету Міністрів України, інших центральних та місцевих органів виконавчої влади визначаються Конституцією ( 254к/96-ВР ) і законами України (частина друга статті 120).

Конституцією України ( 254к/96-ВР ) також установлено, що Кабінет Міністрів України є вищим органом у системі органів виконавчої влади (частина перша статті 113), спрямовує і координує роботу міністерств, інших органів виконавчої влади (пункт 9 статті 116).

За Законом України "Про Кабінет Міністрів України" ( 279-17 ) Кабінет Міністрів України здійснює виконавчу владу безпосередньо та через міністерства, інші центральні органи виконавчої влади, Раду міністрів Автономної Республіки Крим та місцеві державні адміністрації, спрямовує, координує та контролює діяльність цих органів (частина друга статті 1). Цим Законом ( 279-17 ) також передбачено можливість передачі Кабінетом Міністрів України у випадках, передбачених законами України, для тимчасового виконання окремих власних повноважень, окремих повноважень центральних органів виконавчої влади іншим органам виконавчої влади (стаття 21).

Однак ні Конституція України ( 254к/96-ВР ), ні Закони України "Про Кабінет Міністрів України" ( 279-17 ), "Про вищу освіту" ( 2984-14 ) не передбачають здійснення Кабінетом Міністрів України повноважень, які віднесені законами до повноважень міністерств, інших центральних органів виконавчої влади.

Таким чином, вирішивши питання, про які йдеться, Кабінет Міністрів України діяв поза межами власних повноважень та у спосіб, що не передбачений Конституцією ( 254к/96-ВР ) та законами України, чим порушено наведені норми Конституції ( 254к/96-ВР ).

У зв'язку з викладеним названі постанови не відповідають також нормам частини третьої статті 113, частини першої статті 117 Основного Закону держави ( 254к/96-ВР ), які є нормами прямої дії і зобов'язують Кабінет Міністрів України керуватися, зокрема, Конституцією ( 254к/96-ВР ) та законами України, видавати постанови і розпорядження в межах своєї компетенції.

Крім того, запровадження актом Кабінету Міністрів України інституту підтвердження повноважень керівника вищого навчального закладу замість його обрання загальними зборами (конференцією) трудового колективу та затвердження за процедурами, визначеними Законом України "Про вищу освіту" ( 2984-14 ), є обмеженням підзаконним актом прав педагогічних та науково-практичних працівників вищого навчального закладу, що порушує конституційне визначені засади поваги і непорушності прав та свобод (стаття 22 Конституції України) ( 254к/96-ВР ).

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію:

постанови Кабінету Міністрів України від 16 січня 2007 року N 35 ( 35-2007-п ) "Питання Київського національного університету імені Тараса Шевченка";

постанови Кабінету Міністрів України від 14 березня 2007 року N 443 ( 443-2007-п ) "Про затвердження Статуту Київського національного університету імені Тараса Шевченка".

2. Визнати таким, що втратив чинність, Указ Президента України від 8 квітня 2008 року N 313 ( 313/2008 ) "Про зупинення дії постанов Кабінету Міністрів України від 16 січня 2007 року N 35 та від 14 березня 2007 року N 443".

3. Цей Указ набирає чинності з дня його опублікування.
