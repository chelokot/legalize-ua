Про внесення змін до наказу Міністра оборони України від 20.04.2001 N 125

Відповідно до постанови Кабінету Міністрів України від 17 березня 1993 року N 195 ( 195-93-п ) "Про впорядкування охорони об'єктів Збройних Сил" та з метою подальшого поліпшення організації охорони об'єктів Збройних Сил України підрозділами воєнізованої охорони НАКАЗУЮ:

1. Унести до наказу Міністра оборони України від 20 квітня 2001 року N 125 ( z0390-01 ) "Про затвердження Положення про воєнізовану охорону об'єктів Збройних Сил України та Інструкції з організації та несення служби воєнізованою охороною на об'єктах Збройних Сил України", зареєстрованого в Міністерстві юстиції України 05.05.2001 за N 390/5581 (далі - наказ), такі зміни:

пункт 3 наказу ( z0390-01 ) викласти в такій редакції:

"3. Контроль за виконанням наказу покласти на начальника Генерального штабу Збройних Сил України".

2. Абзац перший пункту 1.7 Положення про воєнізовану охорону об'єктів Збройних Сил України ( z0390-01 ) (далі - Положення), затвердженого наказом, викласти в такій редакції:

"1.7. Особовий склад воєнізованої охорони озброюється вогнепальною нарізною зброєю. Забезпечення підрозділів воєнізованої охорони зброєю та боєприпасами здійснюється постачальними органами Міністерства оборони України".

3. Пункт 1.8 Положення ( z0390-01 ) викласти в такій редакції:

"1.8. Особовий склад воєнізованої охорони забезпечується формою одягу за встановленими нормами через постачальні органи Міністерства оборони України за рахунок коштів, виділених на утримання воєнізованої охорони. Носіння спеціальної форми одягу особовим складом під час виконання службових обов'язків обов'язкове".

4. Контроль за виконанням наказу покласти на начальника Генерального штабу Збройних Сил України.

5. Наказ розіслати до окремої військової частини.

Міністр оборони України А.С.Гриценко
