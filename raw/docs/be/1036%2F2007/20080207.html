Текст документа від 07.02.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у міжнародних заходах у рамках Конвенції про заборону або обмеження застосування конкретних видів звичайної зброї, які можуть вважатись такими, що завдають надмірних ушкоджень або мають невибіркову дію

1. Утворити делегацію України для участі у міжнародних заходах у рамках Конвенції про заборону або обмеження застосування конкретних видів звичайної зброї, які можуть вважатись такими, що завдають надмірних ушкоджень або мають невибіркову дію ( 995_266 ), які відбуватимуться у м. Женеві, Швейцарська Конфедерація, зокрема у 1-й щорічній зустрічі держав - учасниць Протоколу V до зазначеної Конвенції ( 995_266 ) (5 листопада 2007 року), у 9-й щорічній зустрічі держав - учасниць Протоколу II до зазначеної Конвенції ( 995_266 ) (6 листопада 2007 року) та у Четвертій Конференції з розгляду дії названої Конвенції ( 995_266 ) (7-13 листопада 2007 року), в такому складі:

БЕРШЕДА - Постійний представник України при

Євген Романович Відділенні ООН та інших міжнародних організаціях у Женеві, глава делегації

МОСКВІТІН - заступник Постійного представника України Олександр Олексійович при Відділенні ООН та інших міжнародних організаціях у Женеві, заступник глави делегації

МАРЧЕНКО - директор Департаменту сил цивільного

Григорій Борисович захисту Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

СИРОТЕНКО - старший офіцер Центрального управління

Василь Володимирович Інженерних військ Головного управління оперативного забезпечення командування сил підтримки Збройних Сил України

ШЛЯКОТІНА - головний консультант Головної служби

Антоніна Віталіївна зовнішньої політики Секретаріату Президента України.

2. Міністрові закордонних справ України затвердити вказівки делегації України на міжнародні заходи, зазначені у статті 1 цього Указу.

3. Кабінету Міністрів України вирішити питання про виділення коштів в іноземній валюті для забезпечення участі у міжнародних заходах у рамках Конвенції ( 995_266 ) Г. Марченка, В. Сиротенка та А. Шлякотіної (відряджаються з 4 до 14 листопада 2007 року).

Президент України В.ЮЩЕНКО
