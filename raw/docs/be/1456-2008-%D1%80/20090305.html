Кабінет Міністрів України; Розпорядження від 19.11.2008 № 1456-р

Про схвалення техніко-економічного обґрунтування реконструкції Національного спортивного комплексу "Олімпійський" (м. Київ)

Стан: Чинний

Ідентифікатор: 1456-2008-р

Текст документа від 05.03.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 листопада 2008 р. N 1456-р Київ

Про схвалення техніко-економічного обґрунтування реконструкції Національного спортивного комплексу "Олімпійський" (м. Київ)

{ Із змінами, внесеними згідно з Розпорядженням КМ N 275-р ( 275-2009-р ) від 05.03.2009 }

1. Схвалити подане Мінсім'ямолодьспортом техніко-економічне обґрунтування реконструкції Національного спортивного комплексу "Олімпійський" (м. Київ), розроблене компанією GMP (Німеччина) та рекомендоване до схвалення Центральною службою Укрдержбудекспертизи Мінрегіонбуду з такими орієнтовними основними техніко-економічними показниками, що підлягають уточненню під час затвердження проектно-кошторисної документації:

площа ділянки, кв. метрів 168800

у тому числі:

площа забудови 55957

площа доріг і пішохідних доріжок 56469

площа озеленення 39970

площа для автомобільних стоянок 15578

кількість ярусів 2

кількість місць для глядачів 72214

загальна кошторисна вартість будівництва, 2114726,997 тис. гривень

у тому числі:

будівельно-монтажні роботи 1398505,483

обладнання 114593,393

пусконалагоджувальні роботи 7341,772

інші витрати 594286,349

у тому числі консультативний супровід 15553,5

строки будівництва 2008-2011 роки { Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 275-р ( 275-2009-р ) від 05.03.2009 }

2. Надати Мінсім'ямолодьспорту право затверджувати за погодженням з Мінфіном, Мінекономіки і Мінрегіонбудом проектну документацію на стадіях проектування "проект" і "робочий проект" на окремі об'єкти, черги, пускові комплекси, етапи реконструкції Національного спортивного комплексу "Олімпійський".

Прем'єр-міністр України Ю.ТИМОШЕНКО
