08.12.2004 N 542

Зареєстровано в Міністерстві юстиції України 30 грудня 2004 р. за N 1676/10275

( Рішення скасовано на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 501 ( vr501312-05 ) від 07.09.2005 )

Про запровадження системи обов'язкового рейтингування суб'єктів та інструментів фондового ринку

( Рішення про державну реєстрацію Рішення скасовано на підставі Висновку Міністерства юстиції N 10/42 ( v10_4323-05 ) від 29.06.2005 )

На виконання Концепції створення системи рейтингової оцінки регіонів, галузей національної економіки, суб'єктів господарювання, схваленої розпорядженням Кабінету Міністрів України від 01.04.2004 N 208-р ( 208-2004-р ), та Заходів щодо реалізації Концепції створення системи рейтингової оцінки регіонів, галузей національної економіки, суб'єктів господарювання, затверджених рішенням Державної комісії з цінних паперів та фондового ринку від 01.06.2004 N 236 ( z0945-04 ), зареєстрованих в Міністерстві юстиції України 29.07.2004 за N 945/9544, з метою розвитку інфраструктури фондового ринку та розкриття інформації на фондовому ринку Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Унести зміни та доповнення до Положення про надання регулярної інформації відкритими акціонерними товариствами та підприємствами-емітентами облігацій, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 09.06.98 N 72 ( z0431-98 ), зареєстрованого в Міністерстві юстиції України 08.07.98 за N 431/2871 (у редакції рішення Державної комісії з цінних паперів та фондового ринку від 17.01.2000 N 3 ( z0063-00 ), зареєстрованого в Міністерстві юстиції України 03.02.2000 за N 63/4284), із змінами та доповненнями, а саме:

пункт 2.1 доповнити підпунктом 2.1.7 такого змісту:

"2.1.7. Відкриті акціонерні товариства, у статутних фондах яких є державна частка, підприємства, що мають стратегічне значення для економіки та безпеки держави, та підприємства, які займають монопольне (домінуюче) становище (у разі випуску облігацій), у складі звіту подають звіт уповноваженого рейтингового агентства, визначеного відповідно до Концепції створення системи рейтингової оцінки регіонів, галузей національної економіки, суб'єктів господарювання, схваленої розпорядженням Кабінету Міністрів України від 01.04.2004 N 208-р ( 208-2004-р ), та Положення про умови конкурсу з визначення агентств, уповноважених на проведення рейтингової оцінки, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 01.06.2004 N 236 ( z0945-04 ) та зареєстрованого в Міністерстві юстиції України 29.07.2004 за N 945/9544, щодо рівня кредитного рейтингу суб'єкта господарювання, визначеного або поновленого протягом календарного року, що передує поданню звіту";

підпункти 2.1.7-2.1.8 пункту 2.1 вважати відповідно підпунктами 2.1.8-2.1.9.

2. Унести зміни та доповнення до Положення про порядок випуску облігацій підприємств, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 17.07.2003 N 322 ( z0706-03 ), зареєстрованого в Міністерстві юстиції України 13.08.2003 за N 706/8027, а саме:

пункт 4.5 доповнити підпунктом "і" такого змісту:

"і) звіт уповноваженого рейтингового агентства щодо рівня кредитного рейтингу відповідного випуску облігацій";

підпункт 11 пункту 6.1 доповнити абзацом такого змісту:

"рівень кредитного рейтингу відповідного випуску облігацій, дата його визначення або останнього поновлення та найменування уповноваженого рейтингового агентства".

3. Управлінню корпоративних фінансів (Борисенко А.М.), управлінню звітності емітентів на ринку цінних паперів (Величко О.Г.) у місячний строк привести відповідні нормативно-правові акти у відповідність до цього рішення.

4. Т.в.о. Виконавчого секретаря Прядку В.В. забезпечити:

державну реєстрацію цього рішення в Міністерстві юстиції України;

опублікування цього рішення відповідно до чинного законодавства.

5. Рішення набуває чинності відповідно до діючого законодавства.

6. Контроль за виконанням цього рішення покласти на заступника Виконавчого секретаря Петрашка О.Г.
