{ Указ втратив чинність на підставі Указу Президента N 1060/2007 ( 1060/2007 ) від 02.11.2007 }

Про внесення зміни до Указу Президента України від 29 жовтня 2003 року N 1226

Внести до розділу "Рада національної безпеки і оборони України" Переліку посад в органах виконавчої влади та інших цивільних установах, які можуть бути заміщені особами вищого офіцерського складу Збройних Сил України, Служби безпеки України, інших військових формувань і особами вищого начальницького складу органів внутрішніх справ, та граничних військових і спеціальних звань за цими посадами, затвердженого Указом Президента України від 29 жовтня 2003 року N 1226 ( 1226/2003 ) (зі змінами, внесеними Указами від 22 грудня 2005 року N 1819 ( 1819/2005 ), від 23 травня 2007 року N 462) ( 462/2007 ), зміну, доповнивши його новим абзацом такого змісту:

"заступник Керівника генерал-майор міліції одна". Департаменту з питань (на час перебування діяльності правоохоронних на цій посаді особи, органів - керівник яка її обіймає) управління координації правоохоронних органів

Президент України В.ЮЩЕНКО
