ПОСТАНОВА від 22 березня 2001 р. N 263 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1047 ( 1047-2019-п ) від 04.12.2019 }

Про внесення зміни до постанови Кабінету Міністрів України від 11 грудня 1999 р. N 2293

Кабінет Міністрів України постановляє:

У розділі "Об'єкти, які можуть бути спеціально збудовані відповідно до умов концесійного договору для задоволення громадських потреб" Переліку об'єктів права державної власності, які можуть надаватися в концесію, затвердженого постановою Кабінету Міністрів України від 11 грудня 1999 р. N 2293 ( 2293-99-п ) (Офіційний вісник України, 1999 р., N 50, ст. 2473; 2000 р., N 42, ст. 1778) позицію:

"Південна транс'європейська автомагістраль Мінтранс" Західний кордон - м. Київ на ділянці Вінниця - Київ протяжністю 146 км (міжнародний транспортний коридор N 3)

замінити позицією та приміткою такого змісту:

"Південна транс'європейська автомагістраль Мінтранс" Західний кордон України (с. Косини) - м. Київ протяжністю 735 км (міжнародні транспортні коридори N 5, 3)

Примітка. Об'єкт може надаватися в концесію окремими ділянками за рішенням концесієдавця.

Прем'єр-міністр України В.ЮЩЕНКО
