МІНІСТЕРСТВО ОСВІТИ І НАУКИ УКРАЇНИ

НАКАЗ

N 37 від 29.02.2000 Зареєстровано в Міністерстві м.Київ юстиції України 16 березня 2000 р. vd20000229 vn37 за N 169/4390

Про затвердження Умов прийому на перший курс вищих навчальних закладів України

( Із змінами, внесеними згідно з Наказ МОН N 74 ( z0200-01 ) від 19.02.2001 )

На виконання Закону України "Про освіту" ( 1060-12 ) НАКАЗУЮ:

1. Затвердити Умови прийому на перший курс вищих навчальних закладів України (додаються).

2. Ректорам (директорам) вищих навчальних закладів України:

2.1. Розробити й до 01.04.2000 затвердити Правила прийому на перший курс вищого навчального закладу в 2000 році згідно з Умовами прийому на перший курс вищих навчальних закладів України.

2.2. Інформацію про Правила прийому на перший курс вищого навчального закладу довести до відома вступників через засоби масової інформації.

3. Уважати такими, що втратили чинність, Умови прийому на перший курс вищих навчальних закладів України, затверджені наказом Міністерства освіти України від 29.01.96 N 21 ( z0072-96 ) "Про затвердження Умов прийому на перший курс вищих навчальних закладів України", зареєстрованим Міністерством юстиції України 13.02.96 за N 72/1097, зі змінами й доповненнями, внесеними наказом Міністерства освіти України від 09.01.97 N 4 ( z0084-97 ) "Про внесення змін і доповнень до Умов прийому на перший курс вищих навчальних закладів України", зареєстрованим Міністерством юстиції України 19.03.97 за N 84/1888.

4. Контроль за виконанням наказу покласти на заступника Міністра Холода Б.І.

Міністр В.Г.Кремень

( Умови прийому на перший курс вищих навчальних закладів України втратили чинність на підставі Наказу МОН N 74 ( z0200-01 ) від 19.02.2001 )
