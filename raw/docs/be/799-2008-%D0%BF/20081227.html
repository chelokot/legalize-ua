КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 вересня 2008 р. N 799 Київ

Про схвалення основних прогнозних макропоказників економічного і соціального розвитку України на 2009 рік

{ Із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2008-п ) від 17.12.2008 }

Кабінет Міністрів України постановляє:

Схвалити такі основні прогнозні макропоказники економічного і соціального розвитку України на 2009 рік та покласти їх в основу розроблення проектів Державної програми економічного і соціального розвитку та Державного бюджету України на 2009 рік:

валовий внутрішній продукт:

номінальний - 1046,5 млрд. гривень; { Абзац третій постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2008-п ) від 17.12.2008 }

відсотків до попереднього року - 100,4; { Абзац четвертий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2008-п ) від 17.12.2008 }

індекс споживчих цін (грудень до грудня попереднього року) - 109,5 відсотка;

індекс цін виробників промислової продукції (грудень до грудня попереднього року) - 112 відсотків; { Абзац шостий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2008-п ) від 17.12.2008 }

фінансові результати звичайної діяльності підприємств до оподаткування - 171,1 млрд. гривень; { Абзац сьомий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2008-п ) від 17.12.2008 }

прибуток прибуткових підприємств - 247,6 млрд. гривень; { Абзац восьмий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2008-п ) від 17.12.2008 }

збиток збиткових підприємств - 76,5 млрд. гривень; { Абзац дев'ятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2008-п ) від 17.12.2008 }

номінальна, скоригована на індекс споживчих цін, відсотків до попереднього року - 100,9; { Абзац тринадцятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2008-п ) від 17.12.2008 }
