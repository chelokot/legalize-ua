( Розпорядження втратило чинність на підставі Постанови КМ N 734 ( 734-94-п ) від 24.10.94 )

Про доповнення переліку уповноважених організацій які здійснюють експорт вугілля, аміаку ...

Доповнити перелік уповноважених організацій, які здійснюють експорт вугілля, аміаку, етилену, бензолу, метанолу, мінеральних добрив і чорних металів у 1994 році, затверджений розпорядженням Кабінету Міністрів України від 22 грудня 1993 р. N 1129, ( 1129-93-р ) пунктом 6 такого змісту: "6. Державні управління чорні метали, 72.01, 72.02, по забезпеченню продук- аміак, етилен, 72.04, 72.06- цією: "Укрметал", "Укр- бензол, метанол, 72.15, 72.18- хім", "Укрвогнетривкок- мінеральні добрива, 72.22, 72.24- сохім" (лише на експорт кокс, смоли 72.28, 28.14, до країн СНД і Балтії) кам'яновугільні 29.01 21000, 29.02 20100, 29.05 11000, 31.02-31.05, 29.02 20900, 27.08, 27.04, 27.06"
