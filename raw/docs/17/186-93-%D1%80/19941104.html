Про уповноваження на здійснення експорту товарів за кодами ТН ЗЕД

Ідентифікатор: 186-93-р

Текст документа від 04.11.1994:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 березня 1993 р. N 186-р Київ

( Із змінами, внесеними згідно з Постановою КМ N 754 ( 754-94-п ) від 04.11.94 )

Відповідно до Декрету Кабінету Міністрів України від 26 грудня 1992 р. N 16-92 ( 16-92 ) "Про встановлення спеціального режиму експорту окремих видів товарів" за поданням МЗЕЗ уповноважити здійснювати експорт товарів за кодами ТН ЗЕД:

завод "Символ" - 7402, 7403.11000, 7403.12000, 7404, 7407.10000, 7408.11000, 7408.19000, 7409.11000, 7409.19000;

Артемівський завод по обробці кольорових металів - 7401-7419;

Світловодський державний комбінат твердих сплавів і тугоплавких металів - 8101, 8113;

спільне підприємство "Інтерсплав" - 7601.20900, 7602;

( Дію абзацу шостого призупинено в частині експорту вугілля за кодами ТН ЗЕД 27.01-27.04 згідно з Постановою КМ N 754 ( 754-94-п ) від 04.11.94 ) Українське об'єднання по збуту вугілля "Укрвуглезбут" - 2701-2704;

( Дію абзацу сьомого призупинено в частині експорту вугілля за кодами ТН ЗЕД 27.01-27.04 згідно з Постановою КМ N 754 ( 754-94-п ) від 04.11.94 ) зовнішньоторговельну фірму "Донецьквугілляімпекс" - 2701, 2704, 2707.10900.
