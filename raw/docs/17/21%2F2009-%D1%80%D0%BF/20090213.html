Про призначення довічних державних стипендій видатним діячам культури і мистецтва

Стан: Чинний

Ідентифікатор: 21/2009-рп

Текст документа від 13.02.2009:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про призначення довічних державних стипендій видатним діячам культури і мистецтва

Відповідно до Указу Президента України від 20 жовтня 1998 року N 1152 ( 1152/98 ) (зі змінами, внесеними Указами від 21 лютого 2000 року N 263 ( 263/2000 ), від 25 січня 2002 року N 71 ( 71/2002 ), від 23 січня 2006 року N 58 ( 58/2006 ) та від 16 травня 2008 року N 444) ( 444/2008 ) призначити щомісячні довічні державні стипендії видатним діячам культури і мистецтва, які досягли сімдесятирічного віку:

БАКАЛЬЧУКУ Михайлу Іллічу - 1938 року народження, народному артистові України

ГАЙДЕНКУ Анатолію Павловичу - 1937 року народження, заслуженому діячеві мистецтв України

КОНДРАТЮКУ Андрію Івановичу - 1938 року народження, письменникові

КОНЬКОВІЙ Галині Вікторівні - 1938 року народження, музикознавцеві

КУХАРЄВУ Альфреду Вячеславовичу - 1925 року народження, народному артистові України

ТУЛІНУ Борису Леонідовичу - 1938 року народження, народному художникові України.

Президент України В.ЮЩЕНКО

м. Київ, 13 лютого 2009 року N 21/2009-рп
