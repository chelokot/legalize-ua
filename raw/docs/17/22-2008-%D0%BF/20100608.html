{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про вдосконалення структури Секретаріату Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Скоротити одну посаду першого заступника Міністра Кабінету Міністрів України та ліквідувати у структурі Секретаріату Кабінету Міністрів України Департамент з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу.

У зв'язку з цим визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 14 лютого 2007 р. N 188 ( 188-2007-п ) "Деякі питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2007 р., N 12, ст. 414);

пункт 1 постанови Кабінету Міністрів України від 1 серпня 2007 р. N 979 ( 979-2007-п ) "Питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2007 р., N 57, ст. 2280).

2. В абзаці першому пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) "Питання Секретаріату Кабінету Міністрів України" ( Офіційний вісник України, 2000 р., N 4, ст. 110; 2006 р., N 52, ст. 3498; 2007 р., N 19, ст. 760, N 57, ст. 2280) цифри "83" замінити цифрами "90", а слова і цифру "Міністра у зв'язках з Верховною Радою України та іншими органами державної влади України - 7" виключити.
