Про зміни у складі колегії Міністерства юстиції

Відповідно до пункту 6 Загального положення про колегію центрального органу виконавчої влади і місцевої державної адміністрації, затвердженого постановою Кабінету Міністрів України від 2 жовтня 2003 року N 1569 ( 1569-2003-п ) (із змінами і доповненнями), та пункту 10 Положення про Міністерство юстиції України, затвердженого постановою Кабінету Міністрів України від 14 листопада 2006 року N 1577 ( 1577-2006-п ), НАКАЗУЮ:

Ввести до складу колегії, затвердженого наказом Міністерства юстиції України від 28 січня 2008 року N 70/7 ( v0070323-08 ) "Про затвердження складу колегії Міністерства юстиції України", зі змінами, внесеними наказами Мін'юсту від 01.02.2008 N 94/7 ( v94_7323-08 ), 19.02.2008 N 166/7 ( v166_323-08 ), від 26.02.2008 N 206/7 ( v06_7323-08 ) та від 11.03.2008 N 283/7 ( v0283323-08 ), Голову Державного департаменту України з питань виконання покарань Кощинця Василя Васильовича (за згодою).
