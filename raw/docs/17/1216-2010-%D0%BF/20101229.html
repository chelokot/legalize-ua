КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 грудня 2010 р. N 1216 Київ

Про внесення змін до Положення про дозвільну систему

Кабінет Міністрів України постановляє:

Внести зміни до Положення про дозвільну систему, затвердженого постановою Кабінету Міністрів України від 12 жовтня 1992 р. N 576 ( 576-92-п ), - із змінами, внесеними постановами Кабінету Міністрів України від 31 травня 1995 р. N 373 ( 373-95-п ), від 22 лютого 1999 р. N 256 ( 256-99-п ) (Офіційний вісник України, 1999 р., N 8, ст. 297), від 21 липня 1999 р. N 1326 ( 1326-99-п ) (Офіційний вісник України, 1999 р., N 30, ст. 1526), від 1 вересня 2000 р. N 1381 ( 1381-2000-п ) (Офіційний вісник України, 2000 р., N 36, ст. 1536), від 28 травня 2001 р. N 575 ( 575-2001-п ) (Офіційний вісник України, 2001 р., N 22, ст. 991), від 25 грудня 2002 р. N 1953 ( 1953-2002-п ) (Офіційний вісник України, 2002 р., N 52, ст. 2374) і від 20 квітня 2007 р. N 648 ( 648-2007-п ) (Офіційний вісник України, 2007 р., N 30, ст. 1216), виключивши у пункті 2 та абзаці другому пункту 9 слова ", штемпельно-граверні майстерні, печатки і штампи".
