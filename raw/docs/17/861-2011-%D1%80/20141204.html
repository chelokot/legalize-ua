Про поховання Героя України, академіка Національної академії наук, колишнього заступника Голови Ради Міністрів УРСР Тронька П.Т.

Стан: Чинний

Ідентифікатор: 861-2011-р

Текст документа від 04.12.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 вересня 2011 р. N 861-р Київ

Про поховання Героя України, академіка Національної академії наук, колишнього заступника Голови Ради Міністрів УРСР Тронька П.Т.

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1065-р ( 1065-2011-р ) від 17.10.2011 Постановою КМ N 673 ( 673-2014-п ) від 26.11.2014 }

1. Для організації похорону Героя України, академіка Національної академії наук, колишнього заступника Голови Ради Міністрів УРСР Тронька Петра Тимофійовича утворити комісію у складі Табачника Д.В. (голова комісії), Гейця В.М. (заступник голови комісії), Аністратенка Ю.С., Гінзбург О.П., Добкіна М.М., Дубляна О.В., Кулиняка М.А., Лозового В.М., Олійника Б.І., Патона Б.Є., Попова О.П., Рибака С.О., Толочка П.П.

2. Поховати Тронька П.Т. на Байковому кладовищі.

3. Витрати, пов'язані з похованням Тронька П.Т., у сумі 25 тис. гривень здійснити за рахунок держави.

4. Київській міськдержадміністрації забезпечити спорудження на могилі Тронька П.Т. надгробка вартістю до 10 тис. гривень.

5. Видати одноразову допомогу в сумі 8 тис. гривень вдові Тронька П.Т. - Тронько Валентині Іванівні.

{ Пункт 5-1 втратив чинність на підставі Постанови КМ N 673 ( 673-2014-п ) від 26.11.2014 }

6. Міністерству фінансів профінансувати зазначені у пунктах 3-5 цього розпорядження витрати Національної академії наук за рахунок коштів резервного фонду державного бюджету ( 2857-17 ).

7. Національній академії наук подати до кінця 2011 року Міністерству фінансів, Міністерству економічного розвитку і торгівлі та Державній казначейській службі звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України М.АЗАРОВ
