Про встановлення знижки вартості проїзду у поїздах міжнародного сполучення N 673/672, N 671/674 Щорс - Гомель

Згідно з постановою Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та з метою збереження пасажиропотоку НАКАЗУЮ:

1. Установити знижку в розмірі 50 відсотків від вартості проїзду (квитка та плацкарти) у поїзді міжнародного сполучення N 671/674 Щорс - Гомель та квитка у поїзді N 673/672 Гомель - Щорс, визначеної Тарифами на перевезення пасажирів і багажу залізничним транспортом у міжнародному сполученні, затвердженими наказом Міністерства транспорту України від 03.12.97 N 409 ( z0584-97 ) і зареєстрованими в Міністерстві юстиції України 11.12.97 за N 584/2388 (із змінами і доповненнями, унесеними наказами Міністерства транспорту України від 10.11.98 N 439 ( z0722-98 ), від 04.01.99 N 2 ( z0030-99 ) та від 15.09.99 N 454 ( z0648-99 ), зареєстрованими в Міністерстві юстиції України відповідно 12.11.98 за N 722/3162, 20.01.99 за N 30/3323 та 27.09.99 за N 648/3941).

2. Укрзалізниці (Луханін М.І.) забезпечити своєчасне введення у дію цього наказу, правильність застосування зазначеної знижки та поінформування пасажирів на вокзалах та в пунктах продажу проїзних документів.

3. Контроль за виконанням цього наказу покласти на заступника Державного секретаря Міністерства транспорту України Дунаєва Л.Ф.
