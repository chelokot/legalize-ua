( Розпорядження втратило чинність на підставі Розпорядження КМ N 364-р ( 364-2000-р ) від 13.09.2000 )

Про закріплення у державній власності пакету акцій ВАТ "Затисянський хімічний завод"

Відповідно до пункту 14 Державної програми приватизації на 1998 рік ( 124/98-ВР ) закріпити у державній власності пакет акцій у розмірі 25 відсотків статутного фонду плюс одна акція ВАТ "Затисянський хімічний завод" на 3 роки.
