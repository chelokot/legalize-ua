Стан: Втратив чинність

Текст документа від 04.12.2002:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

N 209 від 04.05.2000 Зареєстровано в Міністерстві м.Київ юстиції України 18 травня 2000 р. vd20000504 vn209 за N 290/4511

Про затвердження Тарифів на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід - Захід

( Із змінами, внесеними згідно з Наказами Мінтрансу N 327 ( z0469-01 ) від 28.05.2001 N 853 ( z0947-02 ) від 02.12.2002 )

Згідно з постановою Кабінету Міністрів України від 25 грудня 1996 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів місцевих рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

1. Затвердити Тарифи на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід - Захід, що додаються.

2. Ввести зазначені Тарифи в дію з 28 травня 2000 р.

3. Укрзалізниці (Макаренко М.В.) та начальникам залізниць України забезпечити своєчасне введення в дію цих Тарифів та правильність їх застосування і поінформувати про це населення (на вокзалах та пунктах продажу квитків).

4. Із введенням у дію цього наказу втрачають чинність Тарифи на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід - Захід, затверджені наказом Міністерства транспорту від 28 квітня 1999 р. N 218 ( z0307-99 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід - Захід" і зареєстровані Міністерством юстиції 14 травня 1999 р. за N 307/3600.

5. Контроль за виконанням цього наказу покласти на першого заступника Генерального директора Укрзалізниці Ю.М.Федюшина.

Міністр Л.М.Костюченко

( Тарифи на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід - Захід втратили чинність на підставі Наказу Міністерства транспорту N 853 ( z0947-02 ) від 02.12.2002 )
