Про утворення координаційної ради у зв'язках з Організацією економічного співробітництва та розвитку (ОЕСР)

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 353-р ( 353-2004-р ) від 02.06.2004 N 249-р ( 249-2005-р ) від 12.07.2005 Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 Наказами Міністерства економіки N 647 ( v0647665-08 ) від 06.11.2008 N 652 ( v0652665-08 ) від 07.11.2008 N 661 ( v0661665-08 ) від 10.11.2008 }

Утворити координаційну раду у зв'язках з Організацією економічного співробітництва та розвитку (ОЕСР) у складі згідно з додатком.

Дозволити голові координаційної ради вносити у разі потреби зміни до її складу.
