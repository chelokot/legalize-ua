15.09.2008 N 331

Зареєстровано в Міністерстві юстиції України 10 жовтня 2008 р. за N 958/15649

Про внесення змін до наказу Держкомстату від 27.10.2005 N 331

Відповідно до статей 4, 14, 18 Закону України "Про державну статистику" ( 2614-12 ), з метою подальшого вдосконалення державних статистичних спостережень зі статистики товарних ринків та отримання повної, усебічної та об'єктивної статистичної інформації НАКАЗУЮ:

1. Затвердити:

1.1. Зміни до Інструкції щодо заповнення форми державного статистичного спостереження N 3-мтп "Звіт про залишки і витрати матеріалів", затвердженої наказом Держкомстату від 27.10.2005 N 331 ( z1277-05 ), зареєстрованої у Міністерстві юстиції України 27.10.2005 за N 1277/11557, що додаються, та ввести їх у дію, починаючи зі звіту за 2008 рік.

1.2. Зміни до Інструкції щодо заповнення форми державного статистичного спостереження N 4-мтп "Звіт про залишки і використання енергетичних матеріалів та продуктів перероблення нафти" ( z1278-05 ), затвердженої наказом Держкомстату від 27.10.2005 N 331 ( z1277-05 ), зареєстрованої у Міністерстві юстиції України 27.10.2005 за N 1278/11558, що додаються ( z0959-08 ), та ввести їх у дію, починаючи зі звіту за 2008 рік.

1.3. Зміни до Інструкції щодо заповнення форми державного статистичного спостереження N 11-мтп "Звіт про результати використання палива, теплоенергії та електроенергії" ( z1279-05 ), затвердженої наказом Держкомстату від 27.10.2005 N 331 ( z1277-05 ), зареєстрованої у Міністерстві юстиції України 27.10.2005 за N 1279/11559, що додаються ( z0960-08 ), та ввести їх у дію, починаючи зі звіту за 2008 рік.

1.4. Зміни до Інструкції щодо заповнення форми державного статистичного спостереження N 14-мтп "Звіт про утворення, використання і поставку вторинної сировини і відходів виробництва" ( z1280-05 ), затвердженої наказом Держкомстату від 27.10.2005 N 331 ( z1277-05 ), зареєстрованої у Міністерстві юстиції України 27.10.2005 за N 1280/11560, що додаються ( z0961-08 ), та ввести їх у дію, починаючи зі звіту за 2008 рік.

1.5. Зміни до Інструкції щодо заповнення форми державного статистичного спостереження N 1-опт "Звіт про продаж і запаси товарів (продукції) в оптовій торгівлі" ( z1281-05 ), затвердженої наказом Держкомстату від 27.10.2005 N 331 ( z1277-05 ), зареєстрованої у Міністерстві юстиції України 27.10.2005 за N 1281/11561, що додаються ( z0962-08 ), та ввести їх у дію, починаючи зі звіту за 2008 рік.

2. Департаменту статистики торгівлі (Фризоренко А.О.) підготувати і передати адміністративно-господарському департаменту оригінали інструкцій зі змінами, затвердженими цим наказом, для їх виготовлення.

3. Департаменту фінансового забезпечення, бухгалтерського обліку та звітності (Кучіна І.Ю.) забезпечити фінансування робіт з виготовлення та доставки інструкцій зі змінами, затвердженими цим наказом.

4. Адміністративно-господарському департаменту (Кобзар О.К.) забезпечити контроль за своєчасним виготовленням та доставкою інструкцій зі змінами, затвердженими цим наказом, на адресу головних управлінь статистики в Автономній Республіці Крим, областях, місті Києві та Управління статистики в місті Севастополі.

5. Контроль за виконанням цього наказу покласти на першого заступника Голови Піщейка В.О.

Голова О.Г.Осауленко

1. У пункті 1.1 розділу 1 слова "за півріччя та", "форм власності" виключити.
