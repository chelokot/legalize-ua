{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 606 ( 606-2011-п ) від 01.06.2011 }

1. Затвердити тарифи на проведення органом державного пожежного нагляду експертизи (обстеження) протипожежного стану підприємства, об'єкта, приміщення згідно з додатком 1.

2. Установити, що експертиза (обстеження) протипожежного стану підприємства, об'єкта, приміщення органом державного пожежного нагляду може проводитися виключно на добровільних засадах за заявою юридичних або фізичних осіб, що оформляється згідно з додатком 2.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 1102 ( 1102-2011-п ) від 26.10.2011 }

4. Міністерству надзвичайних ситуацій разом з Міністерством економічного розвитку і торгівлі, Міністерством фінансів і Міністерством регіонального розвитку, будівництва та житлово-комунального господарства розробити та затвердити методику розрахунку витрат часу та вартості проведення органом державного пожежного нагляду експертизи (обстеження) протипожежного стану підприємства, об'єкта, приміщення.
