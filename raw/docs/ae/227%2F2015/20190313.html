{Указ втратив чинність на підставі Указу Президента № 65/2019 від 11.03.2019 }

Питання Конкурсної комісії з добору кандидатів для здійснення Президентом України призначення членів Вищої ради юстиції

На виконання Закону України "Про Вищу раду юстиції" та відповідно до пункту 28 частини першої статті 106 Конституції України постановляю:

1. Утворити Конкурсну комісію з добору кандидатів для здійснення Президентом України призначення членів Вищої ради юстиції.

2. Призначити ВАСИЛЕНКА Володимира Андрійовича - професора кафедри міжнародного права і спеціальних правових наук Національного університету "Києво-Могилянська академія" - головою Конкурсної комісії з добору кандидатів для здійснення Президентом України призначення членів Вищої ради юстиції (за згодою).

3. Затвердити персональний склад Конкурсної комісії з добору кандидатів для здійснення Президентом України призначення членів Вищої ради юстиції (додається).

4. Цей Указ набирає чинності з дня його опублікування.
