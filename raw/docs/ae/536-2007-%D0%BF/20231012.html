КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 березня 2007 р. N 536 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1064 ( 1064-2023-п ) від 10.10.2023 }

Деякі питання реалізації статті 11 Закону України "Про управління об'єктами державної власності"

{ Із змінами, внесеними згідно з Постановами КМ N 968 ( 968-2011-п ) від 07.09.2011 N 950 ( 950-2016-п ) від 14.12.2016 }

{ У тексті постанови слова "Державної фінансової інспекції" замінено словами "Державної аудиторської служби", а слова "Державна фінансова інспекція та її територіальні органи" у всіх відмінках замінено словами "Державна аудиторська служба та її міжрегіональні територіальні органи" у відповідному відмінку згідно з Постановою КМ N 950 ( 950-2016-п ) від 14.12.2016 }

З метою реалізації частини одинадцятої статті 11 Закону України "Про управління об'єктами державної власності" ( 185-16 ) Кабінет Міністрів України постановляє:

1. Установити, що до складу ревізійних комісій господарських організацій, у яких корпоративні права держави перевищують 50 відсотків статутного капіталу (далі - господарські організації), включаються представники Державної аудиторської служби у разі наявності одного з таких критеріїв: { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 968 ( 968-2011-п ) від 07.09.2011 }

господарська організація має стратегічне значення для економіки та безпеки держави та/або займає монопольне становище на ринку товарів (робіт, послуг);

господарська організація має непогашений кредит, залучений державою або під державні гарантії;

дохід господарської організації за результатами останнього звітного року перевищує 5 млн. гривень.

В усіх інших випадках до складу зазначених комісій включаються представники Державної податкової адміністрації.

2. Представники Державної податкової служби та Державної аудиторської служби, яких включено до складу ревізійних комісій господарських організацій, у межах наданих Законами України "Про державну податкову службу в Україні" ( 509-12 ) та "Про основні засади здійснення державного фінансового контролю в Україні" ( 2939-12 ) повноважень: { Абзац перший пункту 2 із змінами, внесеними згідно з Постановами КМ N 968 ( 968-2011-п ) від 07.09.2011, N 950 ( 950-2016-п ) від 14.12.2016 }

сприяють в організації проведення Державною аудиторською службою та її міжрегіональними територіальними органами або органами державної податкової служби контрольних заходів в господарських організаціях за ініціюванням органів господарських організацій, до компетенції яких віднесено зазначене питання; { Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 968 ( 968-2011-п ) від 07.09.2011 }

вносять обґрунтовані пропозиції керівництву Державної аудиторської служби та її міжрегіональних територіальних органів або органів державної податкової служби щодо необхідності проведення контрольних заходів в господарських організаціях з певного комплексу або окремих питань їх фінансово-господарської діяльності; { Абзац третій пункту 2 із змінами, внесеними згідно з Постановою КМ N 968 ( 968-2011-п ) від 07.09.2011 }

забезпечують урахування у звітах ревізійних комісій господарських організацій результатів контрольних заходів, проведених Державною аудиторською службою та її міжрегіональними територіальними органами або органами державної податкової служби; { Абзац четвертий пункту 2 із змінами, внесеними згідно з Постановою КМ N 968 ( 968-2011-п ) від 07.09.2011 }

сприяють реалізації господарськими організаціями матеріалів контрольних заходів, проведених Державною аудиторською службою та її міжрегіональними територіальними органами або органами державної податкової служби. { Абзац п'ятий пункту 2 із змінами, внесеними згідно з Постановою КМ N 968 ( 968-2011-п ) від 07.09.2011 }

3. Органам, що здійснюють управління об'єктами державної власності, забезпечити включення до складу ревізійних комісій господарських організацій представників Державної податкової служби або Державної аудиторської служби відповідно до визначених цією постановою критеріїв.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 968 ( 968-2011-п ) від 07.09.2011 }
