Кабінет Міністрів України; Розпорядження від 10.05.1999 № 398-р

Про віднесення виборних посад Верховної Ради Автономної Республіки Крим до категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 398-99-р

Текст документа від 11.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 травня 1999 р. N 398-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 493 ( 493-2012-п ) від 23.05.2012 }

( Із змінами, внесеними згідно з Розпорядженням КМ N 671-р ( 671-99-р ) від 12.07.99 )

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести виборні посади Верховної Ради Автономної Республіки Крим до таких категорій посад державних службовців:

перша категорія - посади Голови Верховної Ради Автономної Республіки Крим, першого заступника та заступника Голови Верховної Ради Автономної Республіки Крим, посади голів постійних комісій Верховної Ради Автономної Республіки Крим; ( Абзац із змінами, внесеними згідно з Розпорядженням КМ N 671-р ( 671-99-р ) від 12.07.99 )

друга категорія - посади голів постійних комісій Верховної Ради Автономної Республіки Крим.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
