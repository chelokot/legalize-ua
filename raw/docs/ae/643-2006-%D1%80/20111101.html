Про внесення зміни до розпорядження Кабінету Міністрів України від 29 березня 2000 р. N 152 та визнання таким, що втратило чинність, розпорядження Кабінету Міністрів України від 4 лютого 2004 р. N 45

Стан: Втратив чинність

Ідентифікатор: 643-2006-р

Текст документа від 01.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 грудня 2006 р. N 643-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1097 ( 1097-2011-п ) від 26.10.2011 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 29 березня 2000 р. N 152 та визнання таким, що втратило чинність, розпорядження Кабінету Міністрів України від 4 лютого 2004 р. N 45

1. Внести до розпорядження Кабінету Міністрів України від 29 березня 2000 р. N 152 ( 152-2000-р ) (Офіційний вісник України, 2000 р., N 13, ст. 531; 2004 р., N 5, ст. 246) зміну, виключивши абзаци другий, третій та сьомий.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 4 лютого 2004 р. N 45 ( 45-2004-р ) "Про доповнення розпорядження Кабінету Міністрів України від 29 березня 2000 р. N 152" (Офіційний вісник України, 2004 р., N 5, ст. 246).

Прем'єр-міністр України В.ЯНУКОВИЧ
