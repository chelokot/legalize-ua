Питання Національної ради з питань охорони здоров'я населення

Стан: Втратив чинність

Ідентифікатор: 123/2007

Текст документа від 19.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 489/2010 ( 489/2010 ) від 02.04.2010 }

Питання Національної ради з питань охорони здоров'я населення

1. На часткову зміну Указу Президента України від 26 травня 2006 року N 442 ( 442/2006 ) "Про склад Національної ради з питань охорони здоров'я населення" призначити ПОЛІЩУКА Миколу Єфремовича - Радника Президента України - головою Національної ради з питань охорони здоров'я населення, увільнивши від виконання цих обов'язків Поляченка Ю.В.

2. Статтю 2 Указу Президента України від 26 травня 2006 року N 443 ( 443/2006 ) "Про Національну раду з питань охорони здоров'я населення" виключити.

Президент України В.ЮЩЕНКО
