Президент України; Указ від 31.07.2009 № 579/2009

Про зупинення дії положень постанов Кабінету Міністрів України від 11 березня 2009 року N 237 та від 24 липня 2009 року N 767

Стан: Чинний

Ідентифікатор: 579/2009

Текст документа від 31.07.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії положень постанов Кабінету Міністрів України від 11 березня 2009 року N 237 та від 24 липня 2009 року N 767

{ Додатково див. Конституційне подання Президента ( n0026100-09 ) від 31.07.2009 }

Кабінетом Міністрів України 11 березня 2009 року видано постанову N 237 ( 237-2009-п ) "Деякі питання стабілізації фінансового стану Національної акціонерної компанії "Нафтогаз України" у 2009 році".

Пунктом 2 цієї постанови ( 237-2009-п ) встановлено, що закупівля Національною акціонерною компанією "Нафтогаз України" фінансових послуг з надання кредитів для проведення розрахунків за природний газ у межах показників фінансового плану Компанії, включаючи газ, який буде закачуватися до підземних сховищ, та послуги з його транспортування, закачування і зберігання у зазначених сховищах, а також рефінансування кредитів, які залучались для фінансування зазначених витрат у минулих роках, здійснюється за процедурою закупівлі в одного учасника без погодження з Міністерством економіки України.

Водночас постановою Кабінету Міністрів України від 24 липня 2009 року N 767 ( 767-2009-п ) "Про внесення змін до деяких постанов Кабінету Міністрів України" запроваджено порядок, за яким механізм здійснення закупівлі товарів, робіт і послуг за державні кошти не поширюється на фінансові та інші пов'язані з ними послуги, які закуповуються Національною акціонерною компанією "Нафтогаз України" (пункт 3 затверджених названою постановою ( 767-2009-п ) змін, що вносяться до постанов Кабінету Міністрів України).

Зазначені положення постанов Кабінету Міністрів України від 11 березня 2009 року N 237 ( 237-2009-п ) та від 24 липня 2009 року N 767 ( 767-2009-п ) не відповідають Конституції України ( 254к/96-ВР ), виходячи з такого.

Конституцією України ( 254к/96-ВР ) встановлено, що закони та інші нормативно-правові акти приймаються на основі Конституції України і повинні відповідати їй (частина друга статті 8) ( 254к/96-ВР ), органи виконавчої влади зобов'язано здійснювати свої повноваження у встановлених Конституцією межах і відповідно до законів України (частина друга статті 6) ( 254к/96-ВР ), діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією та законами України (частина друга статті 19) ( 254к/96-ВР ), а також зобов'язано Кабінет Міністрів України керуватися у своїй діяльності Конституцією та законами України (частина третя статті 113) ( 254к/96-ВР ).

У той же час Конституцією України ( 254к/96-ВР ) встановлено обов'язок держави щодо забезпечення захисту прав усіх суб'єктів права власності і господарювання, їх рівність перед законом (частина четверта статті 13) ( 254к/96-ВР ), а також обов'язок держави забезпечувати захист конкуренції у підприємницькій діяльності (частина третя статті 42) ( 254к/96-ВР ). При цьому, гарантуючи право на підприємницьку діяльність та захищаючи конкуренцію у підприємницькій діяльності, Конституція України ( 254к/96-ВР ) не виключає можливості обмеження конкуренції, однак містить заборону на неправомірне обмеження конкуренції у підприємницькій діяльності (частини перша, третя статті 42) ( 254к/96-ВР ).

Відтак, надавши Національній акціонерній компанії "Нафтогаз України" право здійснювати закупівлю названих вище фінансових послуг без застосування процедур, що передбачають конкуренцію учасників, Кабінет Міністрів України порушив зазначені конституційні приписи.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію пункту 2 постанови Кабінету Міністрів України від 11 березня 2009 року N 237 ( 237-2009-п ) "Деякі питання стабілізації фінансового стану Національної акціонерної компанії "Нафтогаз України" у 2009 році" та пункту 3 затверджених постановою Кабінету Міністрів України від 24 липня 2009 року N 767 ( 767-2009-п ) змін, що вносяться до постанов Кабінету Міністрів України.

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 31 липня 2009 року N 579/2009
