{ Постанова втратила чинність на підставі Постанови КМ N 567 ( 567-2011-п ) від 01.06.2011 }

Про внесення змін до Правил оформлення візових документів для в'їзду в Україну

Кабінет Міністрів України постановляє:

Внести до Правил оформлення візових документів для в'їзду в Україну, затверджених постановою Кабінету Міністрів України від 20 лютого 1999 р. N 227 ( 227-99-п ) (Офіційний вісник України, 1999 р., N 8, ст. 285; 2000 р., N 18, ст. 753, N 36, ст. 1534; 2001 р., N 6, ст. 231, N 9, ст. 265), такі зміни:

1) в абзаці четвертому пункту 10 слова "одного року" замінити словами "п'яти років";

2) у пункті 11:

в абзаці п'ятому літеру і цифру "П-2" виключити;

доповнити пункт новим абзацом шостим такого змісту:

"П-2 - п'ять років".

У зв'язку з цим абзаци шостий і сьомий вважати відповідно абзацами сьомим і восьмим.

Прем'єр-міністр України А.КІНАХ
