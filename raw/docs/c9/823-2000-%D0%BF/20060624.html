Кабінет Міністрів України; Постанова від 18.05.2000 № 823

Про визначення акціонерного банку "Укргазпромбанк" банком-агентом Кабінету Міністрів України з обслуговування Іноземних кредитних ліній, що залучаються під державні гарантії

Стан: Втратив чинність

Ідентифікатор: 823-2000-п

Текст документа від 24.06.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 травня 2000 р. N 823 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 857 ( 857-2006-п ) від 24.06.2006 }

Про визначення акціонерного банку "Укргазпромбанк" банком-агентом Кабінету Міністрів України з обслуговування Іноземних кредитних ліній, що залучаються під державні гарантії

Кабінет Міністрів України постановляє:

1. Визначити акціонерний банк "Укргазпромбанк" банком-агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під державні гарантії.

2. Уповноважити Міністра фінансів Мітюкова І.О. підписати від імені Кабінету Міністрів України агентську угоду з акціонерним банком "Укргазпромбанк".

Прем'єр-міністр України В.ЮЩЕНКО
