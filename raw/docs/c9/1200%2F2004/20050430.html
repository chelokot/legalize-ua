УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 740/2005 ( 740/2005 ) від 30.04.2005 )

Про зміни у складі Комісії при Президентові України з питань громадянства

1. Увести до складу Комісії при Президентові України з питань громадянства, затвердженого Указом Президента України від 9 грудня 1994 року N 746 ( 746/94 ) (зі змінами, внесеними Указами від 22 квітня 1996 року N 275 ( 275/96 ), від 6 листопада 1997 року N 1254 ( 1254/97 ), від 13 жовтня 1998 року N 1135 ( 1135/98 ), від 6 березня 1999 року N 238 ( 238/99 ), від 7 червня 2000 року N 770 ( 770/2000 ), від 28 лютого 2001 року N 120 ( 120/2001 ), від 15 листопада 2001 року N 1094 ( 1094/2001 ), від 8 жовтня 2002 року N 911 ( 911/2002 ) та від 27 квітня 2004 року N 488 ( 488/2004 ), ТУЗА Сергія Івановича - заступника Голови Служби безпеки України.

2. Вивести зі складу цієї Комісії Землянського Ю.В.
