МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ

НАКАЗ

06.05.2008 N 659

Зареєстровано в Міністерстві юстиції України 2 червня 2008 р. за N 494/15185

Про визнання такими, що втратили чинність, деяких наказів Міністерства фінансів України

З метою уникнення дублювання положень наказу Міністерства культури і туризму України від 18.10.2005 N 745 ( z1285-05 ) "Про впорядкування умов оплати праці працівників культури на основі Єдиної тарифної сітки", зареєстрованого в Міністерстві юстиції України 27 жовтня 2005 року за N 1285/11565, наказом Міністерства фінансів України від 08.12.2005 N 858 ( z1555-05 ) "Про умови оплати праці працівників Музею коштовного та декоративного каміння", зареєстрованого в Міністерстві юстиції України 26 грудня 2005 року за N 1555/11835, НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Міністерства фінансів України:

від 08.12.2005 N 858 ( z1555-05 ) "Про умови оплати праці працівників Музею коштовного та декоративного каміння", зареєстрований в Міністерстві юстиції України 26 грудня 2005 року за N 1555/11835;

від 24 березня 2006 року N 310 ( z0361-06 ) "Про внесення змін до наказу Міністерства фінансів України від 08.12.2005 N 858", зареєстрований в Міністерстві юстиції України 31 березня 2006 року за N 361/12235;

від 29 березня 2007 року N 418 ( z0329-07 ) "Про внесення змін до наказу Міністерства фінансів України від 08.12.2005 N 858", зареєстрований в Міністерстві юстиції України 12 квітня 2007 року за N 329/13596;

від 4 квітня 2007 року N 449 ( z0407-07 ) "Про внесення змін до наказу Міністерства фінансів України від 08.12.2005 N 858", зареєстрований в Міністерстві юстиції України 23 квітня 2007 року за N 407/13674;

від 11 червня 2007 року N 704 ( z0658-07 ) "Про внесення змін до наказу Міністерства фінансів України від 08.12.2005 N 858", зареєстрований в Міністерстві юстиції України 18 червня 2007 року за N 658/13925.

2. Департаменту державного регулювання операцій з дорогоцінними металами і дорогоцінним камінням та пробірного нагляду (Мельник В.П.) забезпечити подання цього наказу в установленому порядку на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра фінансів України Фудашкіна Д.О.

Міністр В.Пинзеник
