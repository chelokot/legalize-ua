МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

19.06.2009 N 226

Зареєстровано в Міністерстві юстиції України 13 липня 2009 р. за N 620/16636

Про внесення змін до наказу Міністерства праці та соціальної політики України від 05.04.2006 N 106

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства праці та соціальної політики N 106 ( z0423-06 ) від 05.04.2006, до якого вносились зміни }

На виконання пункту 2 постанови Кабінету Міністрів України від 20.05.2009 N 482 ( 482-2009-п ) "Деякі питання оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів, що фінансуються з бюджету" та з метою впорядкування умов оплати праці працівників Фонду сприяння місцевому самоврядуванню України НАКАЗУЮ:

1. Доповнити пункт 1 наказу Міністерства праці та соціальної політики України від 05.04.2006 N 106 ( z0423-06 ) "Про умови оплати праці працівників Фонду сприяння місцевому самоврядуванню України", зареєстрованого в Міністерстві юстиції України 12.04.2006 за N 423/12297 (зі змінами), абзацом другим такого змісту:

"Установити, що у разі, коли розміри посадових окладів працівників, зазначені у додатку, нижчі ніж визначений законом розмір мінімальної заробітної плати, посадові оклади установлюються на рівні відповідного розміру мінімальної заробітної плати.".

2. Директору департаменту з питань державного регулювання заробітної плати та умов праці Товстенку О.П. у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності з дня його офіційного опублікування.
