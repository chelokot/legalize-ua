Текст документа від 07.04.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 вересня 2008 р. N 1243-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 821-р ( 821-2010-р ) від 07.04.2010 }

Про внесення зміни до титулу будови (об'єкта), будівництво якої розпочалося в 2007 році

У титулі будови (об'єкта), будівництво якої розпочалося в 2007 році, затвердженого розпорядженням Кабінету Міністрів України від 23 липня 2008 р. N 998 ( 998-2008-р ), позицію "Проектно-кошторисну документацію затверджено розпорядженням Кабінету Міністрів України від 18 липня 2007 р. N 541" ( 541-2007-р ) замінити такою позицією:

"Проектно-кошторисну документацію затверджено розпорядженням Кабінету Міністрів України від 23 липня 2008 р. N 998" ( 998-2008-р ).
