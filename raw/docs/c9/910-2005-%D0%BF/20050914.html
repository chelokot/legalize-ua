Кабінет Міністрів України; Постанова, Перелік від 14.09.2005 № 910

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 910-2005-п

Текст документа від 14.09.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 вересня 2005 р. N 910 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

Виконуючий обов'язки Прем'єр-міністра України Ю.ЄХАНУРОВ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 вересня 2005 р. N 910

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 7 березня 2001 р. N 216 ( 216-2001-п ) "Про організаційне забезпечення проведення у Запорізькій, Луганській та Львівській областях експерименту з підвищення ефективності роботи державних цільових фондів" (Офіційний вісник України, 2001 р., N 11, ст. 430).

2. Постанова Кабінету Міністрів України від 21 червня 2001 р. N 687 ( 687-2001-п ) "Про внесення змін до постанови Кабінету Міністрів України від 7 березня 2001 р. N 225" (Офіційний вісник України, 2001 р., N 26, ст. 1175).

3. Постанова Кабінету Міністрів України від 15 лютого 2002 р. N 146 ( 146-2002-п ) "Про додаткові заходи щодо проведення експерименту з підвищення ефективності роботи державних цільових фондів" (Офіційний вісник України, 2002 р., N 8, ст. 338).

4. Постанова Кабінету Міністрів України від 28 березня 2002 р. N 381 ( 381-2002-п ) "Про проведення експерименту з використання даних персоніфікованого обліку відомостей у системі загальнообов'язкового державного пенсійного страхування для призначення страхових виплат, державної допомоги сім'ям з дітьми, державної соціальної допомоги малозабезпеченим сім'ям та житлових субсидій" (Офіційний вісник України, 2002 р., N 13, ст. 666).

5. Постанова Кабінету Міністрів України від 11 квітня 2002 р. N 494 ( 494-2002-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 7 березня 2001 р. N 225" (Офіційний вісник України, 2002 р., N 15, ст. 811).

6. Постанова Кабінету Міністрів України від 30 травня 2002 р. N 702 ( 702-2002-п ) "Про продовження експерименту з підвищення ефективності роботи державних цільових фондів" (Офіційний вісник України, 2002 р., N 23, ст. 1089).

7. Постанова Кабінету Міністрів України від 26 квітня 2003 р. N 605 ( 605-2003-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 7 березня 2001 р. N 225" (Офіційний вісник України, 2003 р., N 18-19, ст. 823).

8. Постанова Кабінету Міністрів України від 15 травня 2003 р. N 699 ( 699-2003-п ) "Про внесення змін до постанови Кабінету Міністрів України від 28 березня 2002 р. N 381" (Офіційний вісник України, 2003 р., N 21, ст. 930).

9. Постанова Кабінету Міністрів України від 4 червня 2003 р. N 858 ( 858-2003-п ) "Про організаційне забезпечення проведення в Луганській та Чернівецькій областях експерименту з надання застрахованим особам допомоги по частковому безробіттю" (Офіційний вісник України, 2003 р., N 23, ст. 1068).

10. Постанова Кабінету Міністрів України від 10 грудня 2003 р. N 1903 ( 1903-2003-п ) "Про внесення змін до деяких постанов Кабінету Міністрів України" (Офіційний вісник України, 2003 р., N 51, ст. 2678).

11. Постанова Кабінету Міністрів України від 13 грудня 2004 р. N 1646 ( 1646-2004-п ) "Про внесення змін до постанови Кабінету Міністрів України від 7 березня 2001 р. N 225" (Офіційний вісник України, 2004 р., N 50, ст. 3274).
