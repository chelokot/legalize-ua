ПОСТАНОВА від 11 лютого 2004 р. N 143 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 692 ( 692-2015-п ) від 08.09.2015 }

Про доповнення переліку харчових добавок, дозволених для використання у харчових продуктах

Кабінет Міністрів України постановляє:

1. Доповнити перелік харчових добавок, дозволених для використання у харчових продуктах, затверджений постановою Кабінету Міністрів України від 4 січня 1999 р. N 12 ( 12-99-п ) (Офіційний вісник України, 1999 р., N 1, ст. 19; 2000 р., N 8, ст. 311, N 30, ст. 1262, N 45, ст. 1935; 2001 р., N 26, ст. 1166), позиціями такого змісту:

"Е 917 Йодат калію (KIO(3)

Potassium jodate

Йодистий калій (KI) Potassium jodide

Е 536 Фороціанід калію Potassium jerrgyanide

Е 539 Натрій сіркуватистокислий Sodium thiosulphate".

2. Ця постанова набирає чинності з дня опублікування.
