ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

30.06.2010 N 305

Зареєстровано в Міністерстві юстиції України 14 липня 2010 р. за N 517/17812

{ Постанова втратила чинність на підставі Постанови Національного банку N 143 ( v0143500-19 ) від 29.11.2019 }

Про зняття позначки "Не для друку" з деяких нормативно-правових актів Національного банку України

{ Із змінами, внесеними згідно з Постановою Національного банку N 101 ( v0101500-19 ) від 31.07.2019 }

Відповідно до статті 56 Закону України "Про Національний банк України" ( 679-14 ), статті 30 Закону України "Про інформацію" ( 2657-12 ) Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Зняти позначку "Не для друку" з таких нормативно-правових актів Національного банку України:

{ Абзац другий пункту 1 втратив чинність на підставі Постанови Національного банку N 101 ( v0101500-19 ) від 31.07.2019 }

постанови Правління Національного банку України від 17.09.2003 N 405 ( z0895-03 ) "Про затвердження Положення про порядок управління Національним банком України грошово-кредитним ринком в особливий період", зареєстрованої в Міністерстві юстиції України 03.10.2003 за N 895/8216;

{ Абзац четвертий пункту 1 втратив чинність на підставі Постанови Національного банку N 101 ( v0101500-19 ) від 31.07.2019 }

постанови Правління Національного банку України від 18.02.2004 N 60 ( z0306-04 ) "Про затвердження Положення про порядок валютного регулювання та валютного контролю в особливий період", зареєстрованої в Міністерстві юстиції України 10.03.2004 за N 306/8905;

{ Абзац шостий пункту 1 втратив чинність на підставі Постанови Національного банку N 101 ( v0101500-19 ) від 31.07.2019 }

постанови Правління Національного банку України від 16.09.2004 N 444 ( z1265-04 ) "Про затвердження Положення про порядок припинення, зупинення, обмеження діяльності банків в особливий період" (зі змінами), зареєстрованої в Міністерстві юстиції України 05.10.2004 за N 1265/9864;

постанови Правління Національного банку України від 24.01.2007 N 20 ( z0102-07 ) "Про внесення зміни до Положення про порядок припинення, зупинення, обмеження діяльності банків в особливий період", зареєстрованої в Міністерстві юстиції України 7.02.2007 за N 102/13369.

2. Контроль за виконанням цієї постанови залишаю за собою.

3. Ця постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.
