РОЗПОРЯДЖЕННЯ від 7 травня 2008 р. N 693-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1457-р ( 1457-2008-р ) від 24.11.2008 }

{ Дію Розпорядження зупинено згідно з Указом Президента N 450/2008 ( 450/2008 ) від 19.05.2008 }

Про надання Держкомрезерву розстрочки із сплати ввізного мита стосовно товарів 02 і 17 груп згідно з УКТЗЕД

Держмитслужбі протягом 2008 року надавати Держкомрезерву розстрочку із сплати ввізного мита під час митного оформлення товарів 02 і 17 груп згідно з УКТЗЕД ( 2371а-14 ) на умовах податкового кредиту відповідно до статті 17 Закону України "Про Єдиний митний тариф України" ( 2097-12 ) і статті 14 Закону України "Про порядок погашення зобов'язань платників податків перед бюджетами та державними цільовими фондами" ( 2181-14 ) до загального фонду державного бюджету ( 107-17 ) протягом IV кварталу поточного року.

Прем'єр-міністр України Ю.ТИМОШЕНКО
