Кабінет Міністрів України; Постанова, Порядок від 01.07.2009 № 662

Про використання у 2009 році коштів Стабілізаційного фонду, передбачених для фінансування проектів, пов'язаних з утилізацією боєприпасів

Стан: Чинний

Ідентифікатор: 662-2009-п

Текст документа від 01.07.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 липня 2009 р. N 662 Київ

Про використання у 2009 році коштів Стабілізаційного фонду, передбачених для фінансування проектів, пов'язаних з утилізацією боєприпасів

Відповідно до частини другої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) Кабінет Міністрів України постановляє:

1. Затвердити Порядок використання у 2009 році коштів Стабілізаційного фонду, передбачених для фінансування проектів, пов'язаних з утилізацією боєприпасів, що додається.

2. Виділити Національному космічному агентству на безповоротній основі 27 700 тис. гривень за рахунок коштів Стабілізаційного фонду ( 835-17 ), передбачених для фінансування проектів, пов'язаних з утилізацією боєприпасів.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 1 липня 2009 р. N 662

ПОРЯДОК використання у 2009 році коштів Стабілізаційного фонду ( 835-17 ), передбачених для фінансування проектів, пов'язаних з утилізацією боєприпасів

1. Цей Порядок визначає механізм використання коштів Стабілізаційного фонду ( 835-17 ), передбачених пунктом 2 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) для фінансування проектів, пов'язаних з утилізацією боєприпасів (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є НКАУ.

3. Бюджетні кошти використовуються з урахуванням Порядку, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) (Офіційний вісник України, 2009 р., N 24, ст. 793), на виконання зобов'язань, визначених Конвенцією про заборону застосування, накопичення запасів, виробництва і передачі протипіхотних мін та про їхнє знищення ( 995_379 ), ратифікованою Законом України від 18 травня 2005 р. N 2566-IV ( 2566-15 ), та заходів Державної цільової оборонної програми утилізації звичайних видів боєприпасів, не придатних для подальшого використання і зберігання, на 2008-2017 роки, затвердженої постановою Кабінету Міністрів України від 22 жовтня 2008 р. N 940 ( 940-2008-п ) (Офіційний вісник України, 2008 р., N 82, ст. 2765), зокрема за проектами:

розроблення технології та створення виробничих потужностей - 8,3 млн. гривень;

проведення утилізації звичайних видів боєприпасів, не придатних для подальшого використання і зберігання, - 19,4 млн. гривень.

4. Бюджетні кошти спрямовуються за передбаченою у державному бюджеті ( 835-17 ) НКАУ програмою "Утилізація звичайних видів боєприпасів, непридатних для подальшого використання та зберігання".

Мінфін в установленому порядку вносить відповідні зміни до розпису державного бюджету ( 835-17 ) за бюджетною програмою в межах фактичного надходження коштів на зазначені цілі.

5. Товари, роботи і послуги закуповуються за бюджетні кошти в установленому законодавством порядку.

6. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

7. Оплата виконаних робіт проводиться у межах установлених обсягів бюджетних асигнувань на підставі актів фактично виконаних робіт.

8. По закінченні бюджетного періоду залишки бюджетних коштів, що обліковуються на рахунку їх головного розпорядника станом на 1 січня відповідного року за зазначеною в пункті 4 цього Порядку бюджетною програмою, після розподілу коштів Стабілізаційного фонду ( 835-17 ) обов'язково повертаються до Фонду.

9. НКАУ подає щомісяця до 5 числа наступного періоду Мінфіну звіт про використання бюджетних коштів за встановленою зазначеним міністерством формою.

10. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
