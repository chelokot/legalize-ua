КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 квітня 2007 р. N 623 Київ

Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України

Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 29

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 13 квітня 2007 р. N 623

ПЕРЕЛІК актів Кабінету Міністрів України, що втратили чинність

1. Розпорядження Кабінету Міністрів України від 19 жовтня 1998 р. N 844 ( 844-98-р ).

2. Постанова Кабінету Міністрів України від 9 вересня 1999 р. N 1661 ( 1661-99-п ) "Про додаткові заходи щодо погашення заборгованості з грошового забезпечення та інших соціальних виплат у Збройних Силах" (Офіційний вісник України, 1999 р., N 37, ст. 1853).

3. Розпорядження Кабінету Міністрів України від 23 листопада 2000 р. N 467 ( 467-2000-р ).

4. Розпорядження Кабінету Міністрів України від 30 листопада 2004 р. N 874 ( 874-2004-р ) "Про надання повноважень на реалізацію військового майна Збройних Сил" (Офіційний вісник України, 2004 р., N 49, ст. 3215).

5. Розпорядження Кабінету Міністрів України від 3 серпня 2006 р. N 455 ( 455-2006-р ) "Про внесення зміни до розпорядження Кабінету Міністрів України від 30 листопада 2004 р. N 874" (Офіційний вісник України, 2006 р., N 31, ст. 2244).

6. Розпорядження Кабінету Міністрів України від 3 серпня 2006 р. N 457 ( 457-2006-р ) "Про внесення зміни до розпорядження Кабінету Міністрів України від 23 листопада 2000 р. N 467".
