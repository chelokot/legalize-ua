{ Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку

N 1450 ( z0879-10 ) від 14.09.2010 }

Про затвердження Змін до Порядку видачі Дозволу депозитаріям цінних паперів на здійснення професійної депозитарної діяльності, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 08.05.98 N 59

Відповідно до Закону України "Про Національну депозитарну систему та особливості електронного обігу цінних паперів в Україні" ( 710/97-ВР ), Положення про Державну комісію з цінних паперів та фондового ринку, затвердженого Указом Президента України від 14.02.97 N 142/97 ( 142/97 ), та з метою удосконалення Порядку видачі Дозволу депозитаріям цінних паперів на здійснення професійної депозитарної діяльності ( vr059312-98 ) Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Зміни до Порядку видачі Дозволу депозитаріям цінних паперів на здійснення професійної депозитарної діяльності, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 08.05.98 N 59 ( vr059312-98 ) (додаються).

2. Управлінню ліцензування діяльності професійних учасників ринку цінних паперів забезпечити державну реєстрацію цього рішення у Міністерстві юстиції України.

3. Доручити управлінню організаційного забезпечення Комісії опублікувати рішення відповідно до чинного законодавства.

4. Рішення набирає чинності відповідно до чинного законодавства.

5. Контроль за виконанням цього рішення покласти на члена Комісії - заступника Голови В.Івченка.

Член Комісії - перший заступник Голови М. Волков
