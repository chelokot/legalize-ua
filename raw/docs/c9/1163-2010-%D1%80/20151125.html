Кабінет Міністрів України; Розпорядження від 02.06.2010 № 1163-р

Про заходи щодо реконструкції стадіону Львівського державного університету фізичної культури

Стан: Втратив чинність

Ідентифікатор: 1163-2010-р

Текст документа від 25.11.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 червня 2010 р. N 1163-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1303-р ( 1303-2015-р ) від 25.11.2015 }

Про заходи щодо реконструкції стадіону Львівського державного університету фізичної культури

{ Із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2010-п ) від 06.12.2010 }

1. Погодитися з пропозицією Міністерства у справах сім'ї, молоді та спорту і Національного агентства з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу та реалізації інфраструктурних проектів (далі - Агентство) щодо передачі Львівським державним університетом фізичної культури функцій замовника реконструкції стадіону зазначеного університету, розміщеного по вул. Черемшини, 17 (далі - стадіон), державному підприємству "Дирекція з будівництва об'єктів до ЄВРО 2012 у м. Львові" (далі - підприємство).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1105 ( 1105-2010-п ) від 06.12.2010 }

2. Агентству забезпечити невідкладне проведення підприємством процедури визначення генерального підрядника на виконання робіт з реконструкції стадіону.

3. Міністерству у справах сім'ї, молоді та спорту разом з Агентством та іншими заінтересованими органами виконавчої влади вирішити в установленому порядку питання стосовно переоформлення документів дозвільного характеру на реконструкцію стадіону.

Прем'єр-міністр України М.АЗАРОВ
