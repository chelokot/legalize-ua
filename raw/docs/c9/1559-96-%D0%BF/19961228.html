ПОСТАНОВА від 28 грудня 1996 р. N 1559 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про звільнення Харківського державного підприємства "Завод імені Малишева" від сплати земельного податку в 1996 році

Відповідно до статті 16 Закону України "Про Державний бюджет України на 1996 рік" ( 96/96-ВР ) Кабінет Міністрів України постановляє:

Звільнити Харківське державне підприємство "Завод імені Малишева" від сплати земельного податку в 1996 році на земельну ділянку в розмірі 1257 гектарів, на якій розміщені полігони, дослідно-випробувальні станції, а також склади державного та мобілізаційного резервів.

Прем'єр-міністр України П.ЛАЗАРЕНКО
