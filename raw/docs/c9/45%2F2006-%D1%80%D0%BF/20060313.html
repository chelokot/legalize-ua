РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про новий склад української делегації Спільної українсько-молдовської демаркаційної комісії

1. Затвердити новий склад української делегації Спільної українсько-молдовської демаркаційної комісії (додається).

2. Визнати такими, що втратили чинність:

абзац перший пункту 1 Розпорядження Президента України від 5 жовтня 2001 року N 265 ( 265/2001-рп ) "Про демаркацію державного кордону між Україною і Республікою Молдова";

Розпорядження Президента України від 3 червня 2002 року N 144 ( 144/2002-рп ) "Про зміни у складі української делегації Спільної українсько-молдовської демаркаційної комісії";

Розпорядження Президента України від 4 березня 2003 року N 63 ( 63/2003-рп ) "Про зміни у складі української делегації Спільної українсько-молдовської демаркаційної комісії".
