ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

20.08.2003 N 352

Зареєстровано в Міністерстві юстиції України 8 вересня 2003 р. за N 775/8096

( Постанова втратила чинність на підставі Постанови Національного банку N 172 ( z0595-04 ) від 21.04.2004 )

Про внесення зміни до Положення про порядок формування обов'язкових резервів для банків України та визнання таким, що втратив чинність, пункту 1 постанови Правління Національного банку України від 25.11.2002 N 447

Відповідно до статті 15 Закону України "Про Національний банк України" ( 679-14 ), пункту 1.10 Положення про порядок формування обов'язкових резервів для банків України, затвердженого постановою Правління Національного банку України від 27.06.2001 N 244 ( z0586-01 ) та зареєстрованого в Міністерстві юстиції України 11.07.2001 за N 586/5777 (із змінами), та враховуючи стан грошово-кредитного ринку і ліквідність банківської системи України, Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Визнати таким, що втратив чинність, пункт 1 постанови Правління Національного банку України від 25.11.2002 N 447 ( z0931-02 ) "Про внесення зміни до Положення про порядок формування обов'язкових резервів для банків України" (зареєстрована в Міністерстві юстиції України 29.11.2002 за N 931/7219) із змінами, унесеними постановою Правління Національного банку України від 18.06.2003 N 266 ( z0528-03 ) "Про внесення змін до постанови Правління Національного банку України від 25.11.2002 N 447 та Положення про порядок формування обов'язкових резервів для банків України" (зареєстрована в Міністерстві юстиції України 27.06.2003 за N 528/7849).

2. Пункти 4-5 таблиці додатка 1 до Положення про порядок формування обов'язкових резервів для банків України, затвердженого постановою Правління Національного банку України від 27.06.2001 N 244 ( z0586-01 ) та зареєстрованого в Міністерстві юстиції України 11.07.2001 за N 586/5777 (із змінами), замінити новим пунктом такого змісту:

"4. Відхилення (+, - ) (рядки 3-2)".

3. Департаменту монетарної політики (Н.І. Гребеник) після державної реєстрації довести зміст цієї постанови до відома територіальних управлінь Національного банку України та банків для використання в роботі.

4. Контроль за виконанням цієї постанови покласти на першого заступника Голови А.П. Яценюка.

Голова С.Л.Тігіпко
