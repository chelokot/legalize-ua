{ Постанова втратила чинність на підставі Постанови КМ N 752 ( 752-2012-п ) від 15.08.2012 }

Про внесення змін у додаток 1 до Положення про спеціальні звання працівників і курсантів навчальних закладів митної служби

Кабінет Міністрів України постановляє:

Внести у додаток 1 до Положення про спеціальні звання працівників і курсантів навчальних закладів митної служби, затвердженого постановою Кабінету Міністрів України від 16 червня 2003 р. N 900 ( 900-2003-п ) (Офіційний вісник України, 2003 р., N 25, ст. 1190; 2004 р., N 17, ст. 1190; 2005 р., N 20, ст. 1080; 2006 р., N 20, ст. 1434), зміни, що додаються.
