Текст документа від 22.09.2005:

МІНІСТЕРСТВО ЕКОНОМІКИ УКРАЇНИ

НАКАЗ

22.09.2005 N 296

Зареєстровано в Міністерстві юстиції України 2 листопада 2005 р. за N 1325/11605

Про визнання таким, що втратив чинність, наказу Міністерства зовнішніх економічних зв'язків України від 05.06.95 N 104

На виконання Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" НАКАЗУЮ:

Визнати таким, що втратив чинність, наказ Міністерства зовнішніх економічних зв'язків України від 05.06.95 N 104 ( z0205-95 ) "Про проведення попередньої експертизи матеріалів з питань поставок енергоносіїв за міжурядовими угодами", зареєстрований у Міністерстві юстиції України 06.07.95 за N 205/741.

Міністр С.Терьохін
