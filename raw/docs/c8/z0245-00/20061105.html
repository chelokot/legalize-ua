{ Наказ втратив чинність на підставі Наказу Міністерства охорони здоров'я N 545 ( z1150-06 ) від 08.08.2006 }

Про внесення змін та доповнень до наказу МОЗ України від 03.07.95 N 124

У зв'язку з введенням у дію Закону України "Про внесення змін до деяких законодавчих актів України з питань реєстрації актів громадянського стану" ( 1366-14 ) та впровадженням з 01.01.99 в закладах охорони здоров'я Міжнародної статистичної класифікації хвороб десятого перегляду (МКХ-10) НАКАЗУЮ:

1. Внести зміни й доповнення до облікових форм "Лікарське свідоцтво про перинатальну смерть" (форма N 106-2/о-95), "Лікарське свідоцтво про смерть" (форма N 106/о-95), затверджених наказом МОЗ України від 03.07.95 N 124 ( z0266-95 ) та зареєстрованим у Міністерстві юстиції України 01.08.95 за N 266/802, а саме:

1.1. Графу 3 облікової форми 106-2/о-95 ( z0266-95 ) "Лікарське свідоцтво про перинатальну смерть" після слова "місяць" доповнити словами "число ______ година _______".

1.2. Графу 12 облікової форми 106-2/о-95 ( z0266-95 ) "Лікарське свідоцтво про перинатальну смерть" викласти в такій редакції:

"12. Кількість попередніх вагітностей _____, з них пологи живим плодом ______, пологи мертвим плодом ______, аборти ______".

1.3. Графу 11 п. II облікової форми "Лікарське свідоцтво про смерть" (форми N 106/о-95 ( z0266-95 ) доповнити рядком такого змісту:

"У разі смерті жінок під час вагітності або після пологів у період до одного року зазначити тиждень вагітності _____, день післяпологового періоду _____, тиждень після пологів _____".

2. Внести зміни й доповнення до інструкцій: про порядок заповнення та видачі медичного свідоцтва про народження ( z0266-95 ), про порядок заповнення та видачі лікарського свідоцтва про смерть ( z0267-95 ), про порядок заповнення та видачі фельдшерської довідки про смерть ( z0268-95 ), про порядок заповнення та реєстрації випадків смерті дітей в перинатальному періоді ( z0269-95 ) (затверджених наказом МОЗ України від 03.07.95 N 124 та зареєстрованих у Мін'юсті 01.08.95 відповідно за NN 266/802, 267/803, 268/804, 269/805), а саме: абзац другий пункту 1 розділу 1 зазначених інструкцій викласти у такій редакції:

"У статті 159 Кодексу ( 2006-07 ) визначено, що акти громадянського стану реєструються у відділах реєстрації актів громадянського стану районних, районних у містах, міських (міст обласного значення) управлінь юстиції, у виконавчих органах сільських, селищних, міських (крім міст обласного значення) рад, у консульських установах та дипломатичних представництвах України".

3. Абзац четвертий пункту 6 розділу 3 Інструкції про порядок заповнення та видачі лікарського свідоцтва про смерть ( z0267-95 ) викласти в такій редакції:

"- у всіх випадках смерті жінок під час вагітності та в післяпологовому періоді в межах 42 днів після пологів у частині II пункту 11 Лікарського свідоцтва про смерть ( z0266-95 ) робиться запис: "_______ тиждень вагітності", "______ день післяпологового періоду", а якщо смерть жінки настала внаслідок причини, пов'язаної з пологами, після 42-го дня до одного року, то робиться запис: "___ тиждень після пологів".

4. Центру медичної статистики МОЗ України в п'ятиденний термін з дня затвердження цього наказу забезпечити його подання на державну реєстрацію до Міністерства юстиції України.

5. Центру медичної статистики МОЗ України довести наказ до відома працівників обласних та міських центрів медичної статистики, оргметодвідділів обласних лікарень.

6. Контроль за виконанням наказу покласти на першого заступника Міністра Бобильову О.О.

Міністр В.Ф.Москаленко
