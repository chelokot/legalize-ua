Текст документа від 22.09.2005:

ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

22.09.2005 N 894

Зареєстровано в Міністерстві юстиції України 27 вересня 2005 р. за N 1108/11388

Про визнання такими, що втратили чинність, деяких наказів Держмитслужби України

На виконання вимог Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики", з метою приведення нормативно-правових актів Держмитслужби України у відповідність до законодавства України НАКАЗУЮ:

1. Визнати такими, що втратили чинність, такі накази Держмитслужби України:

від 29.03.93 N 73 ( z0186-94 ) "Про митний контроль на державному кордоні України", зареєстрований у Міністерстві юстиції України 10.08.94 за N 186/395;

від 23.04.93 N 105 ( z0039-93 ) "Про затвердження Інструкції про порядок розгляду пропозицій, заяв, скарг і організацію прийому громадян у митних органах України", зареєстрований у Міністерстві юстиції України 06.05.93 за N 39;

від 15.11.93 N 291 ( z0190-93 ) "Про затвердження Тимчасового порядку обліку, оцінки і використання конфіскованого митними органами України майна, валюти та цінностей, безхазяйного майна, товарів та інших предметів, за якими не звернувся власник до кінця строку зберігання", зареєстрований у Міністерстві юстиції України 22.12.93 за N 190;

від 18.11.96 N 516 ( z0675-96 ) "Про затвердження Порядку митного контролю за товарами (предметами) у разі зміни транспортного засобу та умов, яким мають відповідати декларанти алкогольних напоїв та тютюнових виробів, на які встановлено акцизний збір", зареєстрований у Міністерстві юстиції України 21.11.96 за N 675/1700;

від 25.04.97 N 189 ( z0210-97 ) "Про затвердження Положення про порядок переміщення через митний кордон України та обліку продукції, що поставляється згідно з міжвідомчими угодами", зареєстрований у Міністерстві юстиції України 05.06.97 за N 210/2014;

від 29.05.97 N 238 ( z0214-97 ) "Про терміни зберігання товарів на митних ліцензійних складах", зареєстрований у Міністерстві юстиції України 10.06.97 за N 214/2018;

від 09.06.99 N 347 ( z0376-99 ) "Про затвердження Порядку маркування вантажних митних декларацій, погашення марок гербового збору та нанесення позначок про належне маркування", зареєстрований у Міністерстві юстиції України 14.06.99 за N 376/3669;

від 16.02.2000 N 83 ( z0158-00 ) "Про затвердження Порядку митного оформлення об'єктів лізингу (оренди), що переміщуються через митний кордон України", зареєстрований у Міністерстві юстиції України 13.03.2000 за N 158/4379;

від 26.07.2000 N 406 ( z0492-00 ) "Про затвердження Порядку митного оформлення транспортних засобів, увезених на територію України громадянами для тимчасового користування під зобов'язання про зворотне вивезення", зареєстрований у Міністерстві юстиції України 10.08.2000 за N 492/4713;

від 16.02.2001 N 99 ( z0202-01 ) "Про спрощення митного оформлення целюлозно-паперової продукції та поліграфічного обладнання", зареєстрований у Міністерстві юстиції України 16.02.2001 за N 202/5393;

від 14.11.2001 N 725 ( z0996-01 ) "Про внесення змін та доповнень до деяких наказів Держмитслужби України та затвердження уніфікованої форми Акта про проведення митного огляду", зареєстрований у Міністерстві юстиції України 29.11.2001 за N 996/6187;

від 13.01.2004 N 14 ( z0131-04 ) "Про затвердження Порядку митного оформлення товарів, що ввозяться на митну територію України за інвестиційними та інноваційними проектами технологічних парків, та про внесення зміни до наказу Держмитслужби України від 30.06.98 N 380", зареєстрований у Міністерстві юстиції України 30.01.2004 за N 131/8730.

2. Скасувати наказ Державної митної служби України від 11.08.2005 N 742 "Про визнання такими, що втратили чинність, деяких наказів Держмитслужби".

3. Юридичному департаменту (Ступак Ю.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Начальникам митних органів і спеціалізованих митних установ довести цей наказ до відома фізичних та юридичних осіб.

5. Установити, що наказ набирає чинності через 10 днів з дня його офіційного опублікування.

6. Контроль за виконанням наказу покласти на заступника Голови Державної митної служби України Пашка П.В.
