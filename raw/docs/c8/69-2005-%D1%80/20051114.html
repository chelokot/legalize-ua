Кабінет Міністрів України; Розпорядження від 28.03.2005 № 69-р

Про затвердження керівника групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий строк і здійснення контролю за її виконанням

Стан: Втратив чинність

Ідентифікатор: 69-2005-р

Текст документа від 14.11.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 березня 2005 р. N 69-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 453-р ( 453-2005-р ) від 14.11.2005 )

Про затвердження керівника групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий строк і здійснення контролю за її виконанням

Затвердити Міністра праці та соціальної політики Кириленка В'ячеслава Анатолійовича керівником групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий строк і здійснення контролю за її виконанням, увільнивши від цих обов'язків Папієва Михайла Миколайовича ( 814-2003-р ).

Прем'єр-міністр України Ю.ТИМОШЕНКО
