ПОСТАНОВА від 26 березня 2008 р. N 233 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 3 ( 3-2012-п ) від 11.01.2012 }

Про доповнення пункту 4 Положення про Міністерство з питань житлово-комунального господарства України

Кабінет Міністрів України постановляє:

Доповнити пункт 4 Положення про Міністерство з питань житлово-комунального господарства України, затвердженого постановою Кабінету Міністрів України від 12 травня 2007 р. N 717 ( 717-2007-п ) (Офіційний вісник України, 2007 р., N 37, ст. 1471), підпунктом 3-1 такого змісту:

"3-1) здійснює в межах своїх повноважень координацію заходів з підготовки до проведення фінальної частини чемпіонату Європи 2012 року з футболу об'єктів житлово-комунального господарства міст - учасників зазначеного чемпіонату;".

Прем'єр-міністр України Ю.ТИМОШЕНКО
