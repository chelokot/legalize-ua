Стан: Втратив чинність

Ідентифікатор: 549-2005-р

Текст документа від 11.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 грудня 2005 р. N 549-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 19-р ( 19-2012-р ) від 11.01.2012 }

{ Дію Розпорядження відновлено згідно з Розпорядженням КМ N 347-р ( 347-2007-р ) від 26.05.2007 }

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 59-р ( 59-2007-р ) від 21.02.2007 }

Про зміну складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття

1. Внести до складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття, затвердженого розпорядженням Кабінету Міністрів України від 28 березня 2005 р. N 70 ( 70-2005-р ) (Офіційний вісник України, 2005 р., N 13, ст. 672), зміни, що додаються.

2. Координатору діяльності осіб, уповноважених представляти інтереси держави у правлінні Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття, забезпечити їх активну участь у засіданнях правління Фонду та інформувати Кабінет Міністрів України за підсумками кожного півріччя про роботу, проведену зазначеними особами.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 26

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 21 грудня 2005 р. N 549-р

ЗМІНИ, що вносяться до складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття ( 70-2005-р )

1. Ввести до складу правління Фонду Дончук Тетяну Василівну - заступника директора департаменту Мінпаливенерго, Топорову Олену Володимирівну - директора департаменту Мін'юсту, Солових Наталію Григорівну - начальника відділу Мінфіну, вивівши із складу членів правління Квітко Наталію Олександрівну, Крижановську Ніну Василівну, Нижегородову Людмилу Олексіївну.

2. Ввести до складу наглядової ради Саханя Івана Яковича - Міністра праці та соціальної політики, вивівши із складу членів наглядової ради Фонду Кириленка В'ячеслава Анатолійовича.

3. Зазначити нову посаду члена правління Фонду Діденка Сергія Олексійовича - директор департаменту Мінфіну.
