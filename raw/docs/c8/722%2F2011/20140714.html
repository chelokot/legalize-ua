УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Адміністрації Президента України

{ Із змінами, внесеними згідно з Указом Президента N 592/2014 ( 592/2014 ) від 14.07.2014 }

1. Внести до указів Президента України такі зміни:

1) в Указі Президента України від 5 квітня 2011 року N 352 ( 352/2011 ) "Деякі питання Адміністрації Президента України":

{ Підпункт "а" пункту 1 статті 1 втратив чинність на підставі Указу Президента N 592/2014 ( 592/2014 ) від 14.07.2014 }

{ Підпункт "б" пункту 1 статті 1 втратив чинність на підставі Указу Президента N 592/2014 ( 592/2014 ) від 14.07.2014 }

2) абзац п'ятий пункту 7 Положення про Адміністрацію Президента України, затвердженого Указом Президента України від 2 квітня 2010 року N 504 ( 504/2010 ) (зі змінами, внесеними Указом від 5 квітня 2011 року N 352) ( 352/2011 ), після слів "Радник Президента України - Керівник Головного управління з питань діяльності правоохоронних органів" доповнити словами "Радник Президента України - Керівник Головного контрольного управління".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 30 червня 2011 року N 722/2011

{ Схема розподілу обов'язків між Главою Адміністрації Президента України, його Першим заступником і заступниками, радниками Президента України та закріплення за ними структурних підрозділів Адміністрації Президента України втратила чинність на підставі Указу Президента N 592/2014 ( 592/2014 ) від 14.07.2014 }
