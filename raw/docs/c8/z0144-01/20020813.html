ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 44 від 05.02.2001 Зареєстровано в Міністерстві м. Київ юстиції України 19 лютого 2001 р. за N 144/5335

Про затвердження Правил організації розрахунково-касового обслуговування комерційними банками клієнтів і взаємовідносин з цього питання між територіальними управліннями Національного банку України та комерційними банками в національній валюті

( Із змінами, внесеними згідно з Постановами Національного банку N 187 ( z0447-02 ) від 21.05.2002 N 277 ( z0656-02 ) від 31.07.2002 )

Відповідно до статті 7 Закону України "Про Національний банк України" ( 679-14 ) та з метою подальшого вдосконалення організації розрахунково-касового обслуговування комерційними банками клієнтів і взаємовідносин з цього питання між територіальними управліннями Національного банку України та комерційними банками Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити Правила організації розрахунково-касового обслуговування комерційними банками клієнтів і взаємовідносин з цього питання між територіальними управліннями Національного банку України та комерційними банками в національній валюті (додаються).

2. Після реєстрації цієї постанови в Міністерстві юстиції України Департаменту готівково-грошового обігу (Н.В.Дорофєєва) довести її до відома Кримського республіканського, Головного управління Національного банку України по м. Києву і Київській області, територіальних управлінь та комерційних банків для керівництва і використання в роботі.

3. Визнати такою, що втратила чинність, постанову Правління Національного банку України від 30.06.95 N 166 ( v0166500-95 ) "Про Порядок організації розрахунково-касового обслуговування комерційними банками клієнтів і взаємовідносин з цього питання між установами Національного банку України та комерційними банками" (зі змінами).

4. Контроль за виконанням цієї постанови покласти на заступника Голови Я.Ф.Солтиса та директора Департаменту готівково-грошового обігу Н.В.Дорофєєву.

5. Ця постанова набирає чинності через 10 днів після державної реєстрації у Міністерстві юстиції України.

Голова В.С.Стельмах

ЗАТВЕРДЖЕНО Постанова Правління Національного банку України 05.02.2001 N 44

Зареєстровано в Міністерстві юстиції України 19 лютого 2001 р. за N 144/5335

ПРАВИЛА організації розрахунково-касового обслуговування комерційними банками клієнтів і взаємовідносин з цього питання між територіальними управліннями Національного банку України та комерційними банками в національній валюті

1. Взаємовідносини між комерційними банками та їх клієнтами ґрунтуються на договірних засадах і здійснюються на платній основі.

2. У договорі на здійснення розрахунково-касового обслуговування, який комерційний банк укладає з клієнтами, рекомендується передбачити взаємні зобов'язання щодо користування коштами і банківськими послугами, а саме:

користування тимчасово вільними коштами клієнта;

здійснення розрахункових операцій;

касове обслуговування;

транспортне обслуговування перевезень готівки.

Плата за кожний вид розрахунково-касового обслуговування встановлюється окремо.

3. Комерційні банки встановлюють плату за касове обслуговування клієнтів у розмірі, передбаченому договором про розрахунково-касове обслуговування.

( Абзац другий пункту 3 виключено на підставі Постанови Національного банку N 187 ( z0447-02 ) від 21.05.2002 )

( Абзац третій пункту 3 виключено на підставі Постанови Національного банку N 187 ( z0447-02 ) від 21.05.2002 )

( Абзац четвертий пункту 3 виключено на підставі Постанови Національного банку N 187 ( z0447-02 ) від 21.05.2002 )

Комерційні банки встановлюють плату за касове обслуговування бюджетних установ та організацій, що обслуговуються Державним казначейством України і отримують готівку за рахунками групи 257 з урахуванням того, що вони одержують готівку на ці операції від Національного банку України на безоплатній основі. ( Пункт 3 доповнено абзацом згідно з Постановою Національного банку N 277 ( z0656-02 ) від 31.07.2002 )

Касове обслуговування бюджетних установ та організацій, які не обслуговуються Державним казначейством України, здійснюють комерційні банки на підставі укладених договорів. ( Пункт 3 доповнено абзацом згідно з Постановою Національного банку N 277 ( z0656-02 ) від 31.07.2002 )

4. Для проведення інкасації виручки клієнтів і перевезення її в комерційні банки інкасаторами територіального управління Національного банку України укладається окремий договір між комерційним банком, територіальним управлінням Національного банку України і клієнтом.

5. Територіальні управління Національного банку України при проведенні підкріплення кас комерційних банків установлюють плату за касове обслуговування відповідно до Переліку і тарифів банківських операцій, що надаються установами та територіальними управліннями Національного банку України їх клієнтам і банкам - кореспондентам Національного банку України з розрахунково-касового обслуговування, затверджених постановою Правління Національного банку України від 08.08.2000 N 311 ( z0606-00 ) "Про затвердження переліків і тарифів банківських операцій (послуг), що надаються установами та територіальними управліннями Національного банку України за операціями (послугами), пов'язаними з діяльністю клієнтів і банків - кореспондентів Національного банку України", зареєстрованою Міністерством юстиції України 14.09.2000 за N 606/4827.

( Абзац другий пункту 5 виключено на підставі Постанови Національного банку N 187 ( z0447-02 ) від 21.05.2002 )

( Абзац третій пункту 5 виключено на підставі Постанови Національного банку N 187 ( z0447-02 ) від 21.05.2002 )

( Абзац четвертий пункту 5 виключено на підставі Постанови Національного банку N 187 ( z0447-02 ) від 21.05.2002 )

Обмін не придатних до обігу банкнот (монет) на придатні до обігу банкноти (монети) проводиться установами банків юридичним та фізичним особам безкоштовно. ( Абзац другий пункту 5 в редакції Постанови Національного банку N 187 ( z0447-02 ) від 21.05.2002 )

( Абзац шостий пункту 5 виключено на підставі Постанови Національного банку N 187 ( z0447-02 ) від 21.05.2002 )

Територіальні управління безкоштовно здійснюють підкріплення комерційних банків готівкою для виплат бюджетним установам та організаціям, що обслуговуються Державним казначейством України і отримують готівку за рахунками групи 257. ( Пункт 5 доповнено абзацом згідно з Постановою Національного банку N 277 ( z0656-02 ) від 31.07.2002 )

6. Приймання територіальними управліннями Національного банку України від установ комерційних банків надлишків готівки, не придатних до обігу банкнот (монет) і банкнот, що вилучаються з обігу, та комерційними банками готівки від клієнтів здійснюється безкоштовно.

Послуги, що пов'язані з перевезенням готівки для підкріплення операційних кас комерційних банків і вивезенням надлишків операційних кас, а також не придатних до обігу банкнот і монет та банкнот, що вилучаються з обігу, які надаються територіальними управліннями Національного банку України, оплачуються відповідно до Переліку і тарифів на послуги з інкасації та перевезення банкнот, монет, інших цінностей, що здійснюються установами та територіальними управліннями Національного банку України для клієнтів і банків - кореспондентів Національного банку України ( z0609-00 ), затверджених постановою Правління Національного банку України від 08.08.2000 N 311 ( z0606-00 ) "Про затвердження переліків і тарифів банківських операцій (послуг), що надаються установами та територіальними управліннями Національного банку України за операціями (послугами), пов'язаними з діяльністю клієнтів і банків - кореспондентів Національного банку України", зареєстрованих у Міністерстві юстиції України 14.09.2000 за N 609/4830.
