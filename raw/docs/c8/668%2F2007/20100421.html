Питання наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України"

Відповідно до статті 7 Закону України "Про банки і банківську діяльність" ( 2121-14 ) постановляю:

На часткову зміну статті 3 Указу Президента України від 1 березня 2005 року N 390 ( 390/2005 ) "Про членів наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України" (зі змінами, внесеними Указами від 2 березня 2006 року N 182 ( 182/2006 ), від 25 вересня 2006 року N 781 ( 781/2006 ), від 4 грудня 2006 року N 1023 ( 1023/2006 ), від 27 лютого 2007 року N 156 ( 156/2007 ), від 12 березня 2007 року N 200 ( 200/2007 ) та від 25 квітня 2007 року N 352) ( 352/2007 ):

призначити членом наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України" ТОПОЛОВА Віктора Семеновича;

припинити повноваження члена наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України" Р. Жуковського.

Президент України В.ЮЩЕНКО
