Про доповнення розпорядження Кабінету Міністрів України від 12 квітня 2008 р. N 592

Доповнити розпорядження Кабінету Міністрів України від 12 квітня 2008 р. N 592 ( 592-2008-р ) "Питання стабілізації продовольчого ринку" - з доповненням, внесеним розпорядженням Кабінету Міністрів України від 18 червня 2008 р. N 848 ( 848-2008-р ), після слів "сплаченого ввізного мита" словами і цифрами ", або на аукціоні відповідно до Порядку реалізації матеріальних цінностей державного резерву, затвердженого постановою Кабінету Міністрів України від 25 серпня 2004 р. N 1078 ( 1078-2004-п ) (Офіційний вісник України, 2004 р., N 34, ст. 2246; 2008 р., N 26, ст. 820)".
