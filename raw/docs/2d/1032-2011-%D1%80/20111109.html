Кабінет Міністрів України; Розпорядження від 20.10.2011 № 1032-р

Про передачу цілісних майнових комплексів історико-культурних заповідників до сфери управління Міністерства культури

Стан: Чинний

Ідентифікатор: 1032-2011-р

Текст документа від 09.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 жовтня 2011 р. N 1032-р Київ

Про передачу цілісних майнових комплексів історико-культурних заповідників до сфери управління Міністерства культури

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1114-р ( 1114-2011-р ) від 09.11.2011 }

1. Прийняти пропозицію Міністерства культури та Міністерства регіонального розвитку, будівництва та житлово-комунального господарства про передачу до сфери управління Міністерства культури цілісних майнових комплексів Національного заповідника "Глухів", Національного заповідника "Замки Тернопілля", Національного історико-архітектурного заповідника "Кам'янець", Національного архітектурно-історичного заповідника "Чернігів стародавній", Державного історико-архітектурного заповідника у м. Жовкві, Державного історико-культурного заповідника у м. Белзі, Кременецько-Почаївського державного історико-архітектурного заповідника, Державного історико-архітектурного заповідника у м. Бережанах, Державного історико-архітектурного заповідника "Стара Умань", Державного історико-архітектурного заповідника "Хотинська фортеця".

2. Відповідно до частини шостої статті 23 Бюджетного кодексу України ( 2456-17 ) передати бюджетні призначення, передбачені Міністерству регіонального розвитку, будівництва та житлово-комунального господарства за програмою 2751080 "Збереження архітектурної спадщини в заповідниках" ( 2857-17 ), у сумі 16614,7 тис. гривень (загальний фонд - видатки споживання - 14396,3 тис. гривень, з них оплата праці - 10400,3 тис. гривень, комунальні послуги та енергоносії - 210,7 тис. гривень; спеціальний фонд - 2218,4 тис. гривень, з них видатки споживання - 1886,7 тис. гривень (оплата праці - 332,8 тис. гривень, комунальні послуги та енергоносії - 428,4 тис. гривень), видатки розвитку - 331,7 тис. гривень) Міністерству культури за програмою 1802030 "Збереження історико-культурної спадщини в заповідниках" ( 2857-17 ) для фінансування діяльності зазначених у пункті 1 цього розпорядження історико-культурних заповідників.

{ Пункт 3 втратив чинність на підставі Розпорядження КМ N 1114-р ( 1114-2011-р ) від 09.11.2011 }

4. Забезпечити:

1) Міністерству культури - погодження передачі бюджетних призначень, передбаченої пунктом 2 цього розпорядження, з Комітетом Верховної Ради України з питань бюджету;

2) Міністерству фінансів - внесення після зазначеного погодження відповідних змін до розпису державного бюджету.

Прем'єр-міністр України М.АЗАРОВ
