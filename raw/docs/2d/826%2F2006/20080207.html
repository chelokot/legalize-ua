УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Питання укладення нового базового договору між Україною та Європейським Союзом

Виходячи з необхідності укладення нового базового договору між Україною та Європейським Союзом, який замінить Угоду про партнерство та співробітництво між Україною і Європейськими Співтовариствами та їх державами - членами ( 998_012 ), відповідно до пункту 3 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

Кабінету Міністрів України забезпечити в місячний термін опрацювання питання та внесення відповідно до статті 5 Закону України "Про міжнародні договори України" ( 1906-15 ) пропозицій щодо персонального складу делегації України на переговори з Європейською Комісією щодо укладення нового базового договору між Україною та Європейським Союзом та проект Генеральних директив делегації України на зазначені переговори.

Президент України В.ЮЩЕНКО

м. Київ, 9 жовтня 2006 року N 826/2006
