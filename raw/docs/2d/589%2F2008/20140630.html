Президент України; Указ від 26.06.2008 № 589/2008

Про рішення Ради національної безпеки і оборони України від 16 травня 2008 року "Про стан виконання рішень Ради національної безпеки і оборони України щодо ситуації в Автономній Республіці Крим"

Стан: Втратив чинність

Ідентифікатор: 589/2008

Текст документа від 30.06.2014:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 504/2014 ( 504/2014 ) від 06.06.2014 }

Про рішення Ради національної безпеки і оборони України від 16 травня 2008 року "Про стан виконання рішень Ради національної безпеки і оборони України щодо ситуації в Автономній Республіці Крим"

Відповідно до статті 107 Конституції України ( 254к/96-ВР ) постановляю:

1. Увести в дію рішення Ради національної безпеки і оборони України від 16 травня 2008 року "Про стан виконання рішень Ради національної безпеки і оборони України щодо ситуації в Автономній Республіці Крим" ( n0018525-08 ) (додається).

2. Визнати такими, що втратили чинність:

Указ Президента України від 27 лютого 2006 року N 153 ( 153/2006 ) "Про проведення комплексного аналізу стану виконання Конституції та законів України, актів Президента України в Автономній Республіці Крим";

Указ Президента України від 11 вересня 2006 року N 751 ( 751/2006 ) "Про внесення змін до Указу Президента України від 27 лютого 2006 року N 153".

3. Контроль за виконанням цього Указу покласти на Секретаря Ради національної безпеки і оборони України.

4. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 26 червня 2008 року N 589/2008
