МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

16.08.2005 N 90/5

Зареєстровано в Міністерстві юстиції України 16 серпня 2005 р. за N 884/11164

Про втрату чинності Положення про порядок оплати праці адвокатів за подання юридичної допомоги громадянам у кримінальних справах

Відповідно до Положення про Міністерство юстиції України, затвердженого Указом Президента України від 30.12.97 N 1396 ( 1396/97 ) (із змінами), та у зв'язку з втратою чинності постанови Кабінету Міністрів України від 15.11.91 N 315 ( 315-91-п ) "Про порядок оплати праці адвокатів по наданню юридичної допомоги у кримінальних справах" НАКАЗУЮ:

1. Визнати таким, що втратило чинність, Положення про порядок оплати праці адвокатів за подання юридичної допомоги громадянам у кримінальних справах, затверджене Міністерством юстиції України та Міністерством фінансів України 27 листопада 1991 року N 9-396-1255/16-209 ( v1255323-91 ) (із змінами і доповненнями, унесеними спільними листами Міністерства юстиції України і Міністерства фінансів України від 20 січня 1992 року N 9-19-1/16-209 ( v19-1323-92 ), від 19 лютого 1993 року N 8-46/16-209 ( z0191-93 ), від 1 липня 1993 року N 8-93-1/16-209 ( z0192-93 ), від 10 серпня 1993 року N 8-111/16-209 ( z0193-93 ), від 22 лютого 1995 року N 12-90-106/16-209 ( z0056-95 ), від 1 березня 1996 року N 12-90-162/16-209 ( z0151-96 ), наказом Міністерства юстиції України і Міністерства фінансів України від 1 жовтня 1995 року N 12-90-522/16-209 ( z0151-96 ).

2. Департаменту державної реєстрації нормативних актів (Бутрименко В.В.) забезпечити державну реєстрацію цього наказу в установленому законодавством порядку.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Л.В.Єфіменка.

Міністр Р.М.Зварич
