ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

ПОСТАНОВА

10.11.2004 N 1164

( Постанову скасовано на підставі Рішення Верховного Суду ( n0107700-04 ) від 16.11.2004 )

Про неможливість достовірно встановити результати волевиявлення виборців у територіальному виборчому окрузі N 100 (м. Кіровоград)

Центральна виборча комісія 2 листопада 2004 року отримала протокол територіальної виборчої комісії територіального виборчого округу N 100 про підсумки голосування в межах цього територіального виборчого округу.

Відповідно до частини першої статті 84 Закону України "Про вибори Президента України" ( 474-14 ) (далі - Закон) Центральна виборча комісія на своєму засіданні на підставі протоколів територіальних виборчих комісій про підсумки голосування в межах відповідних територіальних виборчих округів, які містять відомості, зазначені в пунктах 1-12 частини першої цієї статті, не пізніш як на десятий день з дня виборів встановлює результати голосування у день виборів Президента України.

Постановою Центральної виборчої комісії від 14 жовтня 2004 року N 870 ( v0870359-04 ) встановлено форму протоколу територіальної виборчої комісії про підсумки голосування в межах територіального виборчого округу. Такий протокол на сторінці N 3 обов'язково має містити відомості, зазначені у пунктах 3-10 протоколу по кожній виборчій дільниці, що входить до складу округу.

Відповідно до частини четвертої статті 28 Закону ( 474-14 ) засідання виборчої комісії є повноважним, якщо в ньому бере участь не менш як дві третини складу комісії. Згідно постанов Центральної виборчої комісії від 11 серпня 2004 року N 375 ( v0375359-04 ) та від 20 вересня 2004 року N 623 ( v0623359-04 ) до складу територіальної виборчої комісії територіального виборчого округу N 100 входять 43 члени комісії. Низка членів територіальної виборчої комісії неправомірно залишили безперервне засідання ТВК 31 жовтня 2004 року, що продовжувалося 1 листопада 2004 року, присвячене встановленню підсумків голосування в територіальному виборчому окрузі, чим порушили вимоги частини першої статті 82, частини шостої статті 29 Закону ( 474-14 ).

Внаслідок таких дій територіальною виборчою комісією не було забезпечено виконання вимог статей 82, 83 Закону ( 474-14 ) щодо порядку прийняття та розгляду документів дільничних виборчих комісій, встановлення підсумків голосування з виборів Президента України в межах територіального виборчого округу на безперервному засіданні територіальної виборчої комісії, на якому відповідно до положень Закону мають бути присутніми не менш як дві третини членів комісії.

Крім того, відповідно до частини четвертої статті 84 Закону ( 474-14 ) Центральна виборча комісія встановлює результати голосування у день виборів Президента України лише на підставі протоколів територіальних виборчих комісій про підсумки голосування в межах відповідних територіальних виборчих округів. Такі протоколи має бути оформлено відповідно до вимог статті 83 Закону ( 474-14 ) та складено на повноважному засіданні територіальної виборчої комісії відповідно до вимог частини четвертої статті 28, частини першої статті 82 Закону.

Отже, за результатами опрацювання протоколу територіальної виборчої комісії територіального виборчого округу N 100 про підсумки голосування в день виборів Президента України 31 жовтня 2004 року в межах цього територіального виборчого округу Центральна виборча комісія вважає неможливим достовірно встановити результати волевиявлення виборців у територіальному виборчому окрузі N 100 та не вбачає підстав для врахування при встановленні результатів голосування у день виборів Президента України протоколу про встановлення результатів голосування в межах територіального виборчого округу N 100, що складений на неповноважному засіданні територіальної виборчої комісії та оформлений без дотримання вимог, передбачених статтею 83 Закону ( 474-14 ).

Враховуючи викладене, відповідно до частини першої статті 25, статей 28, 82, 83, частини першої статті 84 Закону України "Про вибори Президента України" ( 474-14 ), керуючись частиною першою статті 10, частинами першою та третьою статті 11, статтями 12, 13, пунктом 13 статті 17, пунктами 1, 3, 17 статті 18 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Визнати протокол територіальної виборчої комісії територіального виборчого округу N 100 про підсумки голосування в межах цього територіального виборчого округу таким, на підставі якого неможливо достовірно встановити результати волевиявлення виборців у територіальному виборчому окрузі N 100.

2. При встановленні Центральною виборчою комісією результатів голосування у день виборів Президента України не враховувати протокол про підсумки голосування в межах територіального виборчого округу N 100 як такий, що складений на неповноважному засіданні територіальної виборчої комісії та оформлений без дотримання вимог, передбачених статтею 83 Закону України "Про вибори Президента України" ( 474-14 ).

3. Копію цієї постанови надіслати територіальній виборчій комісії територіального виборчого округу N 100.
