Держатомрегулювання України; Наказ, Перелік від 18.11.2005 № 131

Про затвердження Переліку посад працівників центрального апарату Державного комітету ядерного регулювання України, які безпосередньо виконують функції державного регулювання

Реєстрація: Мін'юст України від 30.11.2005 № 1440/11720

Стан: Втратив чинність

Ідентифікатор: z1440-05

Текст документа від 04.03.2006:

ДЕРЖАВНИЙ КОМІТЕТ ЯДЕРНОГО РЕГУЛЮВАННЯ УКРАЇНИ

НАКАЗ

18.11.2005 N 131

Зареєстровано в Міністерстві юстиції України 30 листопада 2005 р. за N 1440/11720

( Наказ втратив чинність на підставі Наказу Державного комітету ядерного регулювання N 22 ( z0155-06 ) від 09.02.2006 )

Про затвердження Переліку посад працівників центрального апарату Державного комітету ядерного регулювання України, які безпосередньо виконують функції державного регулювання

У зв'язку зі зміною структури Державного комітету ядерного регулювання України та змінами, що сталися у штатному розписі з 1 травня 2005 року, з метою забезпечення виконання абзацу 1 пункту 3 постанови Кабінету Міністрів України від 02.04.2001 N 313 ( 313-2001-п ) "Деякі питання Державного комітету ядерного регулювання", із змінами, НАКАЗУЮ :

1. Затвердити Перелік посад працівників центрального апарату Держатомрегулювання України, які безпосередньо виконують функції державного регулювання ядерної та радіаційної безпеки, що додається.

2. Наказ Держатомрегулювання України від 28.08.2003 N 113 ( z0804-03 ) "Про затвердження Переліку посад працівників центрального апарату Державного комітету ядерного регулювання України, які безпосередньо виконують функції державного регулювання ядерної та радіаційної безпеки", зареєстрований в Міністерстві юстиції України 15.09.2003 за N 804/8125, та наказ Держатомрегулювання України від 03.12.2003 N 149 ( z0041-04 ) "Про доповнення Переліку посад працівників центрального апарату Державного комітету ядерного регулювання України, які безпосередньо виконують функції державного регулювання ядерної та радіаційної безпеки", зареєстрований в Міністерстві юстиції України 14.01.2004 за N 41/8640, уважати такими, що втратили чинність.
