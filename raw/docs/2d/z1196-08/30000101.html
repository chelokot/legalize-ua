Зареєстровано в Міністерстві юстиції України 15 грудня 2008 р. за N 1196/15887

{ Наказ втратив чинність на підставі Наказу Державної авіаційної служби N 700 ( z0991-21 ) від 30.04.2021 }

Про затвердження Змін до Правил сертифікації суб'єктів, що надають послуги з аеронавігаційного обслуговування

Відповідно до вимог Повітряного кодексу України ( 3167-12 ), а також Положення про Державну авіаційну адміністрацію, затвердженого постановою Кабінету Міністрів України від 02.11.2006 N 1526 ( 1526-2006-п ), та з метою забезпечення умов і оптимізації термінів для ефективної підготовки та проведення сертифікаційного процесу НАКАЗУЮ:

1. Затвердити Зміни до Правил сертифікації суб'єктів, що надають послуги з аеронавігаційного обслуговування, затверджених наказом Міністерства транспорту та зв'язку України від 22.01.2007 N 42 ( z0104-07 ), зареєстрованих в Міністерстві юстиції України 07.02.2007 за N 104/13371, що додаються.

2. Державній авіаційній адміністрації:

2.1. Забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України в установленому порядку.

2.2. Довести цей наказ до відома керівників підприємств, діяльність яких пов'язана з наданням аеронавігаційного обслуговування.

3. Контроль за виконанням цього наказу покласти на заступника Міністра - голову Державної авіаційної адміністрації Давидова О.М.

Міністр Й.Вінський
