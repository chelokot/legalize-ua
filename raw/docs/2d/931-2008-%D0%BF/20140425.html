КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 жовтня 2008 р. N 931 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 117 ( 117-2014-п ) від 23.04.2014 }

Про доповнення пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404

Кабінет Міністрів України постановляє:

Доповнити підпункт 5 пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752, N 44, ст. 2946, N 51, ст. 3406; 2007 р., N 43, ст. 1715, N 53, ст. 2157, N 56, ст. 2252, N 59, ст. 2344, ст. 2351, N 91, ст. 3336; 2008 р., N 9, ст. 220, N 63, ст. 2146, N 70, ст. 2355) абзацом такого змісту:

"науково-дослідних та дослідно-конструкторських робіт з розроблення та виготовлення ракетно-космічної техніки;".
