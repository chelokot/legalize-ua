( Зупинено дію Постанови згідно з Декретом N 14-92 від 26.12.92, ВВР, 1993, N 10, ст.78 )

Про порядок введення в дію Закону України "Про податок на добавлену вартість"

( Відомості Верховної Ради України (ВВР), 1992, N 14, ст.185 )

Верховна Рада України постановляє:

1. Ввести в дію Закон України "Про податок на добавлену вартість" ( 2007-12 ) з 1 січня 1992 року.

2. Кабінету Міністрів України забезпечити широке роз'яснення цього Закону через засоби масової інформації та правильне його застосування.
