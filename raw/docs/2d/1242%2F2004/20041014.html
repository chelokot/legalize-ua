Про внесення зміни до статті 1 Указу Президента України від 26 листопада 2001 року N 1147

Стан: Чинний

Ідентифікатор: 1242/2004

Текст документа від 14.10.2004:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення зміни до статті 1 Указу Президента України від 26 листопада 2001 року N 1147

На часткову зміну частини першої статті 1 Указу Президента України від 26 листопада 2001 року N 1147 ( 1147/2001 ) "Про довічні державні іменні стипендії громадянам України, які зазнали переслідувань за правозахисну діяльність" (зі змінами, внесеними Указом від 2 грудня 2002 року N 1113 ( 1113/2002 ) збільшити з 1 січня 2005 року до 100 кількість довічних державних іменних стипендій для громадян України, які зазнали переслідувань за правозахисну діяльність.

Президент України Л.КУЧМА

м. Київ, 14 жовтня 2004 року N 1242/2004
