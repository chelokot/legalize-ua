Про внесення зміни до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

Стан: Втратив чинність

Ідентифікатор: 1828-2003-п

Текст документа від 23.12.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 листопада 2003 р. N 1828 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1734 ( 1734-2004-п ) від 23.12.2004 )

Про внесення зміни до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

Кабінет Міністрів України постановляє:

У підрозділі "Київська область" розділу "Мінпромполітики" переліку підприємств, які мають стратегічне значення для економіки і безпеки держави, затвердженого постановою Кабінету Міністрів України від 29 серпня 2000 р. N 1346 ( 1346-2000-п ) (Офіційний вісник України, 2000 р., N 35, ст. 1498), виключити позицію:

"00152269 ВАТ "Росава", м. Біла Церква".
