КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 липня 2010 р. N 672 Київ

Про утворення Державного підприємства спиртової та лікеро-горілчаної промисловості

{ Із змінами, внесеними згідно з Постановами КМ N 61 ( 61-2011-п ) від 02.02.2011 N 627 ( 627-2015-п ) від 26.08.2015 N 611 ( 611-2016-п ) від 08.09.2016 N 521 ( 521-2019-п ) від 19.06.2019 }

{ У тексті Постанови слова "Міністерство аграрної політики" в усіх відмінках замінено словами "Міністерство аграрної політики та продовольства" у відповідному відмінку згідно з Постановою КМ N 627 ( 627-2015-п ) від 26.08.2015 }

З метою підвищення ефективності функціонування державних підприємств спиртової та лікеро-горілчаної промисловості, вдосконалення системи управління у зазначеній галузі Кабінет Міністрів України постановляє:

1. Ліквідувати Державний концерн спиртової та лікеро-горілчаної промисловості (концерн "Укрспирт").

2. Погодитися з пропозицією Міністерства аграрної політики та продовольства щодо:

утворення Державного підприємства спиртової та лікеро-горілчаної промисловості (далі - Державне підприємство "Укрспирт") на базі майна Державного концерну спиртової та лікеро-горілчаної промисловості (концерн "Укрспирт"), державних підприємств і об'єднань спиртової та лікеро-горілчаної промисловості, зазначених в абзаці третьому цього пункту, з віднесенням Підприємства до сфери управління Міністерства аграрної політики та продовольства;

реорганізації державних підприємств і об'єднань спиртової та лікеро-горілчаної промисловості, що належать до сфери управління Міністерства аграрної політики та продовольства, згідно з додатками 1 і 2 шляхом приєднання до Державного підприємства "Укрспирт" та шляхом виділу майна, з використанням якого виготовляється підакцизна продукція, і передачі такого майна до Державного підприємства "Укрспирт".

3. Установити, що Державне підприємство "Укрспирт" є правонаступником Державного концерну спиртової та лікеро-горілчаної промисловості (концерн "Укрспирт").

Уповноважити Державне підприємство "Укрспирт" здійснювати експорт спирту етилового, спирту етилового ректифікованого виноградного, спирту етилового ректифікованого плодового (код згідно з УКТЗЕД 2207 і 2208) ( 584а-18 ) та оптову торгівлю спиртом етиловим, спиртом етиловим ректифікованим виноградним, спиртом етиловим ректифікованим плодовим (код згідно з УКТЗЕД 2207 і 2208). { Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 521 ( 521-2019-п ) від 19.06.2019 }

4. Призначити головою комісії з ліквідації Державного концерну спиртової та лікеро-горілчаної промисловості (концерн "Укрспирт") заступника директора Державного підприємства “Укрспирт” Ільчишина Ігоря Анатолійовича. { Абзац перший пункту 4 із змінами, внесеними згідно з Постановами КМ N 61 ( 61-2011-п ) від 02.02.2011, N 627 ( 627-2015-п ) від 26.08.2015, N 611 ( 611-2016-п ) від 08.09.2016 }

Голові комісії:

затвердити її персональний склад та забезпечити здійснення заходів з ліквідації зазначеного Державного концерну;

поінформувати у шестимісячний строк Кабінет Міністрів України про результати проведеної роботи.

5. Міністерству аграрної політики та продовольства:

1) затвердити Статут Державного підприємства спиртової та лікеро-горілчаної промисловості та здійснити в установленому порядку заходи, пов'язані з його утворенням і реорганізацією державних підприємств і об'єднань спиртової та лікеро-горілчаної промисловості;

2) внести на розгляд Кабінету Міністрів України:

у місячний строк пропозиції щодо приведення актів Кабінету Міністрів України у відповідність з цією постановою;

у тримісячний строк законопроект про включення Державного підприємства "Укрспирт" до переліку об'єктів права державної власності, що не підлягають приватизації;

3) привести власні акти у відповідність з цією постановою.

6. Визнати таким, що втратив чинність, пункт 3 постанови Кабінету Міністрів України від 27 грудня 2008 р. N 1127 ( 1127-2008-п ) "Деякі питання діяльності Державного концерну спиртової та лікеро-горілчаної промисловості (концерн "Укрспирт")" (Офіційний вісник України, 2008 р., N 100, ст. 3318).
