КАБІНЕТ МІНІСТРІВ УКРАЇНИ
РОЗПОРЯДЖЕННЯ

від 12 червня 2019 р. № 416-р
Київ

Про передачу деяких бюджетних призначень, передбачених Господарсько-фінансовому департаменту Секретаріату Кабінету Міністрів України у 2019 році на підтримку реалізації комплексної реформи державного управління

1. Відповідно до частини шостої статті 23 Бюджетного кодексу України та розпорядження Кабінету Міністрів України від 24 червня 2016 р. № 474 “Деякі питання реформування державного управління України” (Офіційний вісник України, 2016 р., № 55, ст. 1919; 2019 р., № 14, ст. 509) передати частину бюджетних призначень, передбачених у 2019 році Господарсько-фінансовому департаменту Секретаріату Кабінету Міністрів України у загальному фонді державного бюджету (загальнодержавні витрати) за програмою 0421060 “Підтримка реалізації комплексної реформи державного управління” в сумі 17000 тис. гривень (видатки розвитку):

Міністерству соціальної політики для Державної служби з питань праці за програмою 2502010 “Керівництво та управління у сфері промислової безпеки, охорони та гігієни праці, нагляду за додержанням законодавства про працю” для впровадження системи електронного документообігу - в сумі 2000 тис. гривень (видатки розвитку - 2000 тис. гривень);

Міністерству аграрної політики та продовольства для Державної служби з питань геодезії, картографії та кадастру за програмою 2803010 “Керівництво та управління у сфері геодезії, картографії та кадастру” для подальшого впровадження системи електронного документообігу - в сумі 5000 тис. гривень (видатки розвитку - 5000 тис. гривень) та за новою бюджетною програмою для модернізації Автоматизованої системи державного земельного кадастру та її підключення до системи електронної взаємодії державних електронних інформаційних ресурсів - в сумі 2500 тис. гривень (видатки розвитку - 2500 тис. гривень);

Міністерству екології та природних ресурсів для Державного агентства водних ресурсів за програмою 2407010 “Керівництво та управління у сфері водного господарства” для подальшого впровадження системи електронного документообігу - в сумі 2000 тис. гривень (видатки розвитку - 2000 тис. гривень);

Державному космічному агентству за програмою 6381010 “Керівництво та управління у сфері космічної діяльності” для впровадження системи електронного документообігу - в сумі 2000 тис. гривень (видатки розвитку - 2000 тис. гривень);

Міністерству енергетики та вугільної промисловості за програмою 1101010 “Загальне керівництво та управління у сфері паливно-енергетичного комплексу та вугільної промисловості” для модернізації та приведення офіційного веб-сайту у відповідність з вимогами Порядку оприлюднення у мережі Інтернет інформації про діяльність органів виконавчої влади, затвердженого постановою Кабінету Міністрів України від 4 січня 2002 р. № 3 (Офіційний вісник України, 2002 р., № 2, ст. 57) (далі - Порядок), - в сумі 700 тис. гривень (видатки розвитку - 700 тис. гривень);

Міністерству культури за програмою 1801010 “Загальне керівництво та управління у сфері культури” для модернізації та приведення офіційного веб-сайту у відповідність з вимогами Порядку - в сумі 700 тис. гривень (видатки розвитку - 700 тис. гривень);

Міністерству аграрної політики та продовольства для Державного агентства лісових ресурсів за програмою 2805010 “Керівництво та управління в сфері лісового господарства” для модернізації та приведення офіційного веб-сайту у відповідність з вимогами Порядку - в сумі 700 тис. гривень (видатки розвитку - 700 тис. гривень);

Господарсько-фінансовому департаменту Секретаріату Кабінету Міністрів України для Державної аудиторської служби за програмою 0417010 “Керівництво та управління у сфері контролю за витрачанням бюджетних коштів” для модернізації та приведення офіційного веб-сайту у відповідність з вимогами Порядку - в сумі 700 тис. гривень (видатки розвитку - 700 тис. гривень);

Державному комітету телебачення і радіомовлення за програмою 1701010 “Керівництво та управління у сфері телебачення і радіомовлення” для модернізації та приведення офіційного веб-сайту у відповідність з вимогами Порядку - в сумі 700 тис. гривень (видатки розвитку - 700 тис. гривень).

2. Забезпечити:

Державному агентству з питань електронного урядування - погодження передачі бюджетних призначень, передбаченої пунктом 1 цього розпорядження, з Комітетом Верховної Ради України з питань бюджету;

Міністерству фінансів - відкриття у разі потреби відповідних бюджетних програм для здійснення видатків, передбачених пунктом 1 цього розпорядження, і внесення відповідних змін до розпису державного бюджету;

Державній казначейській службі - перерахування після зазначеного погодження бюджетних коштів відповідно до переданих бюджетних призначень.
