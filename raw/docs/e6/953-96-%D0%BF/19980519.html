Кабінет Міністрів України; Постанова від 14.08.1996 № 953

Про заходи щодо посилення контролю за ввезенням в Україну алкогольних напоїв та тютюнових виробів, що імпортуються суб'єктами підприємницької діяльності

Стан: Втратив чинність

Ідентифікатор: 953-96-п

Текст документа від 19.05.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 серпня 1996 р. N 953 Київ

( Постанова втратила чинність на підставі Постанови КМ N 460 ( 460-98-п ) від 02.04.98 )

Про заходи щодо посилення контролю за ввезенням в Україну алкогольних напоїв та тютюнових виробів, що імпортуються суб'єктами підприємницької діяльності

( Додатково див. Постанову ВР N 363/96-ВР від 12.09.96 )

( Із змінами, внесеними згідно з Постановою КМ N 1495 ( 1495-97-п ) від 30.12.97 )

З метою посилення контролю за ввезенням в Україну алкогольних напоїв та тютюнових виробів, що імпортуються суб'єктами підприємницької діяльності, Кабінет Міністрів України постановляє:

1. Установити, що умовою пропуску через митний кордон України алкогольних напоїв та тютюнових виробів за кодами згідно з ГС 22.03 00, 22.04-22.08, 24.02 10000, 24.02 20000, 24.03 10000, 24.03 99100, які ввозяться суб'єктами підприємницької діяльності та на які встановлено акцизний збір, є подання митниці у пункті пропуску на митному кордоні України копії платіжного доручення, авізованого митницею за місцем державної реєстрації суб'єкта підприємницької діяльності, на загальну суму обов'язкових платежів до державного бюджету (мито, акцизний збір, податок на добавлену вартість). Зазначені кошти повинні бути перераховані на депозитні рахунки митниць за місцем реєстрації суб'єктів підприємницької діяльності. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1495 ( 1495-97-п ) від 30.12.97 )

2. Державному митному комітетові:

забезпечити митне оформлення товарів, зазначених у пункті 1 цієї постанови, в митницях за місцем реєстрації суб'єктів підприємницької діяльності;

посилити контроль за ввезенням в Україну алкогольних напоїв та тютюнових виробів, на які встановлено акцизний збір.

3. Покласти персональну відповідальність за виконання цієї постанови на Голову Державного митного комітету Деркача Л.В.
