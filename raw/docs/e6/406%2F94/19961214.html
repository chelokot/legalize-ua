ДОДАТОК до Указу Президента України від 21 липня 1994 року N 406/94

ПЕРЕЛІК указів і розпоряджень Президента України, що втратили чинність

1. Указ Президента України від 13 грудня 1991 року N 6 ( 6/91 ) "Про Адміністрацію Президента України".

2. Розпорядження Президента України від 23 вересня 1992 року N 146 ( 146/92-рп ) "Про затвердження Положення про Службу Президента України з питань територій".

3. Указ Президента України від 7 листопада 1992 року N 552 ( 552/92 ) "Про внесення змін і доповнень до Указу Президента України від 13 грудня 1991 року N 6 "Про Адміністрацію Президента України".

4. Розпорядження Президента України від 7 листопада 1992 року N 173 ( 173/92-рп ) "Про введення посади Радника Президента України".

5. Розпорядження Президента України від 30 листопада 1992 року N 189 ( 189/92-рп ) "Про Положення про Соціально-економічну раду Президента України та її склад".

6. Розпорядження Президента України від 30 листопада 1992 року N 190 ( 190/92-рп ) "Про затвердження Положення про Радника Президента України".

7. Розпорядження Президента України від 15 грудня 1992 року N 197 ( 197/92-рп ) "Про Положення про Комісію Президента України з питань науки та її склад".

8. Розпорядження Президента України від 25 грудня 1992 року N 204 ( 204/92-рп ) "Про Положення про Комісію Президента України по зв'язках з міжнародними фінансовими установами та контролю за зовнішньоекономічною діяльністю".

9. Розпорядження Президента України від 29 січня 1993 року N 10 ( 10/93-рп ) "Про затвердження Положення про Службу Президента України з міжнародних питань".

10. Розпорядження Президента України від 25 червня 1993 року N 67 ( 67/93-рп ) "Питання Адміністрації Президента України".

11. Розпорядження Президента України від 12 липня 1993 року N 72 ( 72/93-рп ) "Про зміни в структурі та штатах Адміністрації Президента України".

12. Розпорядження Президента України від 14 липня 1993 року N 75 ( 75/93-рп ) "Про Групу контролю Президента України".

13. Указ Президента України від 28 вересня 1993 року N 395 ( 395/93 ) "Про інформаційні служби Президента України та Кабінету Міністрів України".

14. Указ Президента України від 29 вересня 1993 року N 411 ( 411/93 ) "Про реорганізацію управління фінансово-господарською діяльністю Адміністрації Президента України і апарату Кабінету Міністрів України".

15. Указ Президента України від 13 жовтня 1993 року N 455 ( 455/93 ) "Про деякі зміни в структурі Адміністрації Президента України".

16. Розпорядження Президента України від 1 грудня 1993 року N 127 ( 127/93-рп ) "Про Групу консультантів з питань ринкової економіки".

17. Розпорядження Президента України від 1 грудня 1993 року N 128 ( 128/93-рп ) "Питання Групи консультантів з питань ринкової економіки Адміністрації Президента України".
