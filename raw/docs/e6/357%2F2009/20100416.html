УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 506/2010 ( 506/2010 ) від 06.04.2010 }

Про внесення змін до Указу Президента України від 21 січня 2008 року N 43

Відповідно до частини четвертої статті 107 Конституції України ( 254к/96-ВР ) постановляю:

На часткову зміну Указу Президента України від 21 січня 2008 року N 43 ( 43/2008 ) "Про склад Ради національної безпеки і оборони України" (зі змінами, внесеними Указами від 4 вересня 2008 року N 810 ( 810/2008 ), від 21 листопада 2008 року N 1060 ( 1060/2008 ), від 12 грудня 2008 року N 1157 ( 1157/2008 ) та від 18 березня 2009 року N 165) ( 165/2009 ):

увести до складу Ради національної безпеки і оборони України УЛЬЯНЧЕНКО Віру Іванівну - Главу Секретаріату Президента України;

вивести зі складу Ради національної безпеки і оборони України В. Балогу.

Президент України В.ЮЩЕНКО

м. Київ, 26 травня 2009 року N 357/2009
