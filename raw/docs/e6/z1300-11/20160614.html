{ Наказ втратив чинність на підставі Наказу Міністерства оборони N 270 ( z0785-16 ) від 20.05.2016 }

Про затвердження Зміни до Переліку органів військового управління, прирівняних до управлінь видів Збройних Сил України

Відповідно до Закону України "Про державну службу" ( 3723-12 ), постанови Кабінету Міністрів України від 19.06.96 N 658 ( 658-96-п ) "Про затвердження Положення про ранги державних службовців" (із змінами), розпорядження Кабінету Міністрів України від 29.05.95 N 301-р ( 301-95-р ) та у зв'язку з проведенням організаційних заходів у Збройних Силах України НАКАЗУЮ:

1. Затвердити Зміну до Переліку органів військового управління, прирівняних до управлінь видів Збройних Сил України, затвердженого наказом Міністра оборони України від 15.12.98 N 455 ( z0832-98 ), зареєстрованого в Міністерстві юстиції України 28.12.98 за N 832/3272 (із змінами) (у редакції наказу Міністра оборони України від 27.04.2005 N 246 ( z0476-05), що додається.

2. Цей наказ набирає чинності з дня його офіційного опублікування.

3. Наказ розіслати згідно з розрахунком розсилки.

Міністр оборони України М.Б.Єжель
