Кабінет Міністрів України; Розпорядження від 17.08.1995 № 525-р

Про внесення змін до постанови Кабінету Міністрів України від 8 серпня 1995 р. N 617

Стан: Втратив чинність

Ідентифікатор: 525-95-р

Текст документа від 03.04.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 серпня 1995 р. N 525-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 294 ( 294-97-п ) від 03.04.97 )

Включити до складу Комісії з проведення приватизації об'єктів незавершеного будівництва, затвердженого постановою Кабінету Міністрів України від 8 серпня 1995 р. N 617 ( 617-95-п ), заступника Міністра економіки Мариніна Валерія Івановича (заступник голови Комісії), заступника Міністра фінансів Буковинського Станіслава Альбіновича, увільнивши від обов'язків члена цієї Комісії Соболєва Бориса Володимировича.
