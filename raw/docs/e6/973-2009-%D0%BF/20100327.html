КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 вересня 2009 р. N 973 Київ

Про схвалення основних прогнозних макропоказників економічного і соціального розвитку України на 2010 рік

{ Із змінами, внесеними згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }

Кабінет Міністрів України постановляє:

Схвалити такі основні прогнозні макропоказники економічного і соціального розвитку України на 2010 рік та покласти їх в основу розроблення проектів Державної програми економічного і соціального розвитку та Державного бюджету України на 2010 рік:

валовий внутрішній продукт:

номінальний - 1083,1 млрд. гривень; { Абзац третій постановляючої частини із змінами, внесеними згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }

відсотків до попереднього року - 103,7;

індекс споживчих цін (грудень до грудня попереднього року) - 113,1 відсотка; { Абзац п'ятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }

індекс цін виробників промислової продукції (грудень до грудня попереднього року) - 114,4 відсотка; { Абзац шостий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }

прибуток прибуткових підприємств - 174,2 млрд. гривень; { Абзац сьомий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }

фонд оплати праці найманих працівників і грошового забезпечення військовослужбовців - 338,9 млрд. гривень; { Абзац восьмий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }

середньомісячна заробітна плата працівників:

номінальна - 2245 гривень; { Абзац десятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }

номінальна, скоригована на індекс споживчих цін, відсотків до попереднього року - 105; { Абзац одинадцятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }

продуктивність праці, відсотків до попереднього року - 102,9; { Постановляючу частину доповнено новим абзацом згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }

кількість зайнятих економічною діяльністю віком 15-70 років (у середньому за рік) - 20,4 млн. осіб; { Абзац тринадцятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }

сальдо торговельного балансу, визначене за методологією платіжного балансу, - від'ємне в розмірі 1903 млн. доларів США; { Абзац п'ятнадцятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 281 ( 281-2010-п ) від 24.03.2010 }
