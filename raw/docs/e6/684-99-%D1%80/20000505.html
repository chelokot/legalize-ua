Кабінет Міністрів України; Розпорядження від 14.07.1999 № 684-р

Про здійснення митного оформлення автобуса "Мерседес-Бенц", що переданий Корсунь-Шевченківському ВАТ "АТП 17144" як гуманітарна допомога

Стан: Втратив чинність

Ідентифікатор: 684-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 липня 1999 р. N 684-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Держмитслужбі здійснити митне оформлення автобуса "Мерседес-Бенц" (номер шассі 30300013006484), виготовленого понад п'ять років тому, що переданий Корсунь-Шевченківському ВАТ "АТП 17144" як гуманітарна допомога містом-побратимом Гіфгорн (Німеччина), без сплати митних зборів за перебування цього вантажу під митним контролем.

МВС зареєструвати зазначений автобус в установленому порядку.

Перший віце-прем'єр-міністр України В.КУРАТЧЕНКО
