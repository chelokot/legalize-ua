Текст документа від 05.07.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 квітня 2005 р. N 300 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 833 ( 833-2006-п ) від 15.06.2006 }

Про внесення зміни до пункту 39 Порядку заняття торговельною діяльністю і правил торговельного обслуговування населення та скасування деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Пункт 39 Порядку заняття торговельною діяльністю і правил торговельного обслуговування населення, затверджених постановою Кабінету Міністрів України від 8 лютого 1995 р. N 108 ( 108-95-п ) (ЗП України, 1995 р., N 5, ст. 118; Офіційний вісник України, 1997 р., число 51, с. 27; 1998 р., N 28, ст. 1037, N 46, ст. 1697; 1999 р., N 42, ст. 2096; 2001 р., N 20, ст. 856; 2002 р., N 34, ст. 1588; 2003 р., N 42, ст. 2211), викласти в такій редакції:

"39. У документах, згідно з якими надійшли товари, що підлягають обов'язковій сертифікації, повинні зазначатися реєстраційні номери сертифіката відповідності чи свідоцтва про визнання відповідності та/або декларації про відповідність, якщо це встановлено технічним регламентом з підтвердження відповідності на відповідний товар".

2. Скасувати постанови Кабінету Міністрів України від 15 жовтня 2003 р. N 1611 ( 1611-2003-п ) "Про внесення зміни до Порядку заняття торговельною діяльністю і правил торговельного обслуговування населення" (Офіційний вісник України, 2003 р., N 42, ст. 2211) і від 29 січня 2004 р. N 95 ( 95-2004-п ) "Про внесення змін до постанови Кабінету Міністрів України від 15 жовтня 2003 р. N 1611 та скасування постанови Кабінету Міністрів України від 28 листопада 2003 р. N 1860" (Офіційний вісник України, 2004 р., N 174).
