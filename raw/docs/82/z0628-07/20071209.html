УПРАВЛІННЯ ДЕРЖАВНОЇ ОХОРОНИ УКРАЇНИ

НАКАЗ

11.06.2007 N 161

Зареєстровано в Міністерстві юстиції України 14 червня 2007 р. за N 628/13895

Про внесення змін до деяких нормативно-правових актів

{ Із змінами, внесеними згідно з Наказами Управління державної охорони N 211 ( z0822-07 ) від 12.07.2007 N 353 ( z1323-07 ) від 22.11.2007 }

Відповідно до Закону України "Про військовий обов'язок і військову службу" ( 2232-12 ), Указу Президента України від 29 жовтня 2003 року N 1227 ( 1227/2003 ) "Про внесення змін до деяких указів Президента України" НАКАЗУЮ:

1. Унести зміни до наступних нормативно-правових актів:

{ Підпункт 1.1 пункту 1 виключено на підставі Наказу Управління державної охорони N 211 ( z0822-07 ) від 12.07.2007 }

{ Підпункт 1.2 пункту 1 фактично втратив чинність у зв'язку з втратою чинності Наказу Управління державної охорони N 23 ( z0335-04 ) від 28.02.2004, до якого вносились зміни } 1.2. У преамбулі наказу Управління державної охорони України від 28.02.2004 N 23 ( z0335-04 ) "Про затвердження Інструкції про проходження військової служби в Управлінні державної охорони України", зареєстрованого в Міністерстві юстиції України 17.03.2004 за N 335/8934, слова "Закону України "Про загальний військовий обов'язок і військову службу" замінити словами "Закону України "Про військовий обов'язок і військову службу" ( 2232-12 )".

2. З наказом ознайомити особовий склад Управління державної охорони України.

Начальник Управління В.Гелетей
