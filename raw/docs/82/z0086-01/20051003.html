НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

N 1266 від 26.12.2000 Зареєстровано в Міністерстві юстиції України 30 січня 2001 р. за N 86/5277

( Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 694 ( za088-05 ) від 25.08.2005 )

Про внесення змін до постанови НКРЕ від 12.08.99 N 1042

У зв'язку з прийняттям постанови Кабінету Міністрів України від 11.12.2000 N 1800 ( 1800-2000-п ) "Про порядок забезпечення галузей національної економіки і населення природним газом у 2001 році" та відповідно до пункту 3 Положення про Національну комісію регулювання електроенергетики України, затвердженого Указом Президента України від 14.03.95 N 213/95 ( 213/95 ) (в редакції Указу Президента України від 21.04.98 N 335/98 ( 335/98 ), із змінами, внесеними Указом Президента України від 01.02.99 N 108/99 ( 108/99 ), Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Вилучити пункт 3.4.4 з Умов та Правил здійснення підприємницької діяльності (ліцензійних умов) з постачання природного газу за нерегульованим тарифом, які затверджені постановою НКРЕ від 12.08.99 N 1042 ( z0609-99 ) "Про затвердження Умов та Правил здійснення підприємницької діяльності з постачання природного газу за нерегульованим тарифом".
