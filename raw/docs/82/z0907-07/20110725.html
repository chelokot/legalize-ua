Про внесення змін до деяких нормативно-правових актів Міністерства юстиції України

{ Із змінами, внесеними згідно з Наказами Міністерства юстиції N 1094/5 ( z0572-08 ) від 27.06.2008 N 1812/5 ( z0840-11 ) від 07.07.2011 }

Відповідно до Закону України "Про нотаріат" ( 3425-12 ), підпункту 24 пункту 4 Положення про Міністерство юстиції України, затвердженого постановою Кабінету Міністрів України від 14.11.2006 N 1577 ( 1577-2006-п ), та з метою оволодіння стажистами нотаріуса, нотаріусами та їх працівниками практичними навичками роботи з єдиними та державними реєстрами, держателем яких є Міністерство юстиції України, НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства юстиції N 1812/5 ( z0840-11 ) від 07.07.2011 }

{ Пункт 2 втратив чинність на підставі Наказу Міністерства юстиції N 1094/5 ( z0572-08 ) від 27.06.2008 }

3. Установити, що:

завідувачі державними нотаріальними конторами, державними нотаріальними архівами та приватні нотаріуси повинні забезпечити проходження навчання щодо роботи з єдиними та державними реєстрами, адміністратором яких є Держінформ'юст, своїх працівників, які працюють з цими реєстрами (у тому числі у разі суттєвих змін (модернізації) у програмному забезпеченні реєстру або впровадження нового реєстру);

нотаріуси, які не пройшли навчання щодо роботи з єдиними та державними реєстрами, адміністратором яких є Держінформ'юст, отримують доступ до інформаційної мережі Міністерства юстиції України після проходження навчання щодо роботи з єдиними та державними реєстрами, адміністратором яких є Держінформ'юст;

нотаріуси повинні пройти навчання щодо роботи з єдиними та державними реєстрами (реєстром), адміністратором яких є Держінформ'юст, у разі суттєвих змін (модернізації) у програмному забезпеченні реєстру або впровадження нового реєстру;

нотаріуси та працівники державних нотаріальних контор, державних нотаріальних архівів та приватних нотаріусів, які працюють з єдиними та державними реєстрами, адміністратором яких є Держінформ'юст, направляються на додаткове навчання щодо роботи з зазначеними реєстрами у разі встановлення Міністерством юстиції України або його територіальними органами порушень при роботі з ними.

4. Установити, що програма навчання щодо роботи з єдиними та державними реєстрами (реєстром), адміністратором яких є Держінформ'юст, узгоджується Держінформ'юстом з Департаментом нотаріату та реєстрації адвокатських об'єднань Міністерства юстиції України.

5. Департаменту нотаріату та реєстрації адвокатських об'єднань (Ященко Н.В.), Держінформ'юсту (Добжанський В.Б.):

подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади";

довести цей наказ до відома начальників Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управлінь юстиції в областях, містах Києві та Севастополі, регіональних філій державного підприємства "Інформаційний центр" Міністерства юстиції України та забезпечити його належне виконання.

6. Начальникам Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управлінь юстиції в областях, містах Києві та Севастополі довести цей наказ до відома нотаріусів.

7. Контроль за виконанням цього наказу покласти на першого заступника Міністра Бондика В.А.
