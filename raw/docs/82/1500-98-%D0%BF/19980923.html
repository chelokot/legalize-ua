КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 вересня 1998 р. N 1500 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про проведення експериментальної утилізації авіаційних засобів ураження, непридатних для подальшого використання і зберігання

З метою прискорення виконання Державної програми утилізації звичайних видів боєприпасів, непридатних для подальшого використання та зберігання, а також підвищення ефективності робіт за рахунок впровадження новітніх технологій Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Міністерства оборони щодо проведення українсько-канадським спільним підприємством - Товариством з обмеженою відповідальністю "Галев Лтд" за його технологіями експериментальної утилізації авіаційних засобів ураження, непридатних для подальшого використання і зберігання.

2. Взяти до відома, що роботи з експериментальної утилізації проводяться на умовах самофінансування без залучення коштів з Державного бюджету України.

3. Міністерству оборони визначити обсяги і місця проведення експериментальної утилізації та забезпечити дотримання необхідних заходів безпеки робіт.

4. Уповноважити українсько-канадське спільне підприємство - Товариство з обмеженою відповідальністю "Галев Лтд" здійснювати реалізацію продуктів експериментальної утилізації на зовнішньому ринку згідно із законодавством.

5. Міністерству фінансів разом з Міністерством оборони розробити порядок взаєморозрахунків за виконані з експериментальної утилізації роботи.
