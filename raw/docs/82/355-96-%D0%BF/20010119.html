( Постанова втратила чинність на підставі Постанови КМ N 16 ( 16-2001-п ) від 12.01.2001 )

Про внесення змін до ставок ввізного мита на окремі види товарів

З метою забезпечення виробництва спеціальної техніки Кабінет Міністрів України постановляє:

Встановити на товари за кодами ГС 85.43 80900 такі ставки ввізного мита (у відсотках до їх митної вартості): пільгова - 0, повна - 10.
