Про затвердження плану заходів щодо реалізації Концепції реформування кримінальної юстиції України

{ Із змінами, внесеними згідно з Постановами КМ N 1109 ( 1109-2011-п ) від 20.10.2011 N 1180 ( 1180-2011-п ) від 21.11.2011 }

1. Затвердити план заходів щодо реалізації Концепції реформування кримінальної юстиції України ( 311/2008 ) (далі - план заходів), що додається.

2. Центральним органам виконавчої влади, відповідальним за виконання плану заходів:

передбачати починаючи з 2009 року в межах доведеного граничного обсягу видатків державного бюджету кошти для здійснення заходів;

надсилати щороку до 20 січня та до 20 липня Мін'юсту інформацію про стан виконання плану для узагальнення та подання Кабінетові Міністрів України разом з пропозиціями щодо внесення у разі потреби до нього змін.

3. Фінансування плану заходів у поточному році здійснювати в межах видатків, передбачених центральним органам виконавчої влади у Державному бюджеті України на 2008 рік ( 107-17 ).
