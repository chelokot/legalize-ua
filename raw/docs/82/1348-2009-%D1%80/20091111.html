Кабінет Міністрів України; Розпорядження від 11.11.2009 № 1348-р

Питання реалізації проекту реконструкції енергоблока N 8 Зміївської ТЕС ВАТ "Державна енергогенеруюча компанія "Центренерго"

Стан: Чинний

Ідентифікатор: 1348-2009-р

Текст документа від 11.11.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 листопада 2009 р. N 1348-р Київ

Питання реалізації проекту реконструкції енергоблока N 8 Зміївської ТЕС ВАТ "Державна енергогенеруюча компанія "Центренерго"

З метою реалізації проекту реконструкції енергоблока N 8 Зміївської ТЕС ВАТ "Державна енергогенеруюча компанія "Центренерго" та забезпечення погашення зобов'язань відповідно до постанови Кабінету Міністрів України від 4 листопада 1997 р. N 1212 ( 1212-97-п ) "Про надання гарантій Кабінету Міністрів України щодо забезпечення погашення кредиту ФРН, що залучається Державною акціонерною енергогенеруючою компанією "Центренерго" для фінансування проекту реконструкції енергоблока N 8 Зміївської ТЕС" рекомендувати НКРЕ врахувати в інвестиційній складовій оптового тарифу на електричну енергію ВАТ "Державна енергогенеруюча компанія "Центренерго" обсяг коштів, необхідних для погашення зобов'язань за кредитами, залученими для реалізації проекту реконструкції енергоблока N 8 Зміївської ТЕС, згідно з додатком.
