( Наказ втратив чинність на підставі Наказу Міністерства фінансів N 565 ( z0993-05 ) від 18.08.2005 )

Про зміну розмірів відрахувань до централізованих страхових резервних фондів

У зв'язку із внесенням наглядовою радою Моторного (транспортного) страхового бюро подання від 12.01.2001 N 18/04 ( v8_04699-01 ) та відповідно до пункту 5 Положення про Моторне (транспортне) страхове бюро, затвердженого постановою Кабінету Міністрів України від 28.09.96 N 1175 ( 1175-96-п ), НАКАЗУЮ:

Установити щомісячні (до 20 числа) відрахування до:

фонду страхових гарантій - у розмірі 2 відсотків страхових платежів за додатковими договорами обов'язкового страхування цивільної відповідальності, одержаних протягом попереднього місяця;

фонду захисту потерпілих у дорожньо-транспортних пригодах - у розмірі 5 відсотків страхових платежів за звичайними договорами обов'язкового страхування цивільної відповідальності, одержаних протягом попереднього місяця.
