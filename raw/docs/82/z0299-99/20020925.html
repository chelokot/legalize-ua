Про внесення доповнень до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, та до термінів введення обов'язкової сертифікації окремих видів продукції в Україні

На виконання пункту 14 Декрету Кабінету Міністрів України від 10.05.93 N 46-93 "Про стандартизацію і сертифікацію", з метою підготовки до введення обов'язкової сертифікації послуг автомобільного транспорту в Системі сертифікації УкрСЕПРО НАКАЗУЮ:

1. Доповнити Перелік продукції, що підлягає обов'язковій сертифікації в Україні, затверджений наказом Держстандарту України від 30.06.93 N 95 ( z0112-93 ) і зареєстрований в Мін'юсті України 19.08.93 за N 112 із змінами та доповненнями, внесеними та затвердженими наказами Держстандарту України: від 27.11.96 N 499 ( z0728-96 ), від 17.05.97 N 268 ( z0209-97 ), від 04.07.97 N 388 ( z0304-97 ), від 11.09.97 N 549 ( z0461-97 ), від 20.01.98 N 27 ( z0072-98 ), від 27.01.99 N 37 ( z0234-99 ) та зареєстрованими в Мін'юсті України відповідно 19.12.96 за N 728/1753, 05.06.97 за N 209/2013, 13.08.97 за N 304/2108, 09.10.97 за N 461/2265, 04.02.98 за N 72/2512 та 15.04.99 за N 234/3527, розділом 36 (додається).

2. Установити, що послуги, наведені в розділі 36 Переліку продукції, що підлягають обов'язковій сертифікації в Україні, підлягають обов'язковій сертифікації з 1 вересня 1999 р.

3. Доповнити Терміни введення обов'язкової сертифікації окремих видів продукції в Україні, затверджені наказом Держстандарту України від 30.06.93 N 95 ( z0729-96 ) і зареєстровані в Мін'юсті України 19.08.93 за N 112, із змінами та доповненнями, внесеними та затвердженими наказами Держстандарту України: від 27.11.96 N 499, від 04.07.97 N 388, від 11.09.97 N 549, від 20.01.98 N 27, від 27.01.99 N 37 та зареєстрованими в Мін'юсті України відповідно 19.12.96 за N 729/1754, 13.08.97 за N 304/2108, 09.10.97 за N 461/2265, 04.02.98 за N 72/2512, 15.04.99 за N 234/3527, таким текстом:

"36. Послуги автомобільного транспорту..... 01.09.99".

4. Управлінню стандартизації, сертифікації та державного нагляду продукції в галузі промисловості Держстандарту України (Нелепов А.А.) довести цей наказ до відома центральних органів виконавчої влади, державних центрів стандартизації, метрології та сертифікації, органів із сертифікації в місячний термін після реєстрації в Міністерстві юстиції України.

5. Організаційно-методичному центру з сертифікації автотранспортних послуг (Редзюк А.М.) довести цей наказ до зацікавлених підприємств, організацій, установ, а також до інших суб'єктів підприємницької діяльності незалежно від форм власності в місячний термін після реєстрації в Міністерстві юстиції України.
