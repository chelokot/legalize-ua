Текст документа від 02.06.2004:

МІНІСТЕРСТВО ВНУТРІШНІХ СПРАВ УКРАЇНИ

НАКАЗ

02.06.2004 N 608

Зареєстровано в Міністерстві юстиції України 15 червня 2004 р. за N 734/9333

Про внесення змін до Порядку відбору та направлення працівників органів внутрішніх справ, військовослужбовців внутрішніх військ МВС України для участі в міжнародних миротворчих операціях

З метою вдосконалення організації забезпечення миротворчого персоналу МВС України майном та приведення нормативно-правових актів МВС України у відповідність до вимог Митного кодексу України ( 92-15 ) НАКАЗУЮ:

1. Доповнити пункт 3.3 розділу 3 Порядку відбору та направлення працівників органів внутрішніх справ, військовослужбовців внутрішніх військ МВС України для участі в міжнародних миротворчих операціях ( z0278-04 ), затвердженого наказом МВС України від 7 грудня 2003 року N 1490 ( z0277-04 ), зареєстрованого в Міністерстві юстиції 3 березня 2004 року за N 277/8876 (далі - Порядок), таким підпунктом:

"3.3.9. Забезпечує митне оформлення майна миротворчого персоналу та контролює терміни його тимчасового вивезення за митну територію України".

2. Виключити з Порядку ( z0278-04 ) підпункт 3.6.4, відповідно підпункт 3.6.5 вважати підпунктом 3.6.4.

3. Контроль за виконанням наказу покласти на заступника Міністра генерал-майора міліції Любара М.Г.
