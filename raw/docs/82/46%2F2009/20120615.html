{ Указ втратив чинність на підставі Указу Президента N 365/2012 ( 365/2012 ) від 30.05.2012 }

Про внесення зміни до Указу Президента України від 18 листопада 1996 року N 1094

На часткову зміну статті 1 Указу Президента України від 18 листопада 1996 року N 1094 ( 1094/96 ) "Про відомчі заохочувальні відзнаки" (зі змінами, внесеними Указом від 28 листопада 2007 року N 1158) ( 1158/2007 ) надати право начальнику Управління державної охорони України встановлювати відомчі заохочувальні відзнаки Управління державної охорони України.
