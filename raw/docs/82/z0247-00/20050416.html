Фонд державного майна; Наказ від 17.04.2000 № 807

Про затвердження Примірного договору купівлі-продажу пакета акцій відкритого акціонерного товариства за некомерційним конкурсом

Реєстрація: Мін'юст України від 27.04.2000 № 247/4468

Стан: Втратив чинність

Ідентифікатор: z0247-00

Текст документа від 16.04.2005:

ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

N 807 від 17.04.2000 Зареєстровано в Міністерстві м.Київ юстиції України крім пунктів 2 та 3 27 квітня 2000 р. vd20000417 vn807 за N 247/4468

( Наказ втратив чинність на підставі Наказу Фонду державного майна N 689 ( z0358-05 ) від 28.03.2005 )

Про затвердження Примірного договору купівлі-продажу пакета акцій відкритого акціонерного товариства за некомерційним конкурсом

Керуючись Законом України "Про приватизацію державного майна" ( 2163-12 ), розділом IV Закону України "Про приватизацію невеликих державних підприємств (малу приватизацію)" ( 2171-12 ), НАКАЗУЮ:

1. Наказ ФДМУ від 21.08.97 N 910 ( z0402-97 ) "Про затвердження Типового договору купівлі-продажу пакета акцій відкритого акціонерного товариства, створеного у процесі приватизації, за некомерційним конкурсом" вважати таким, що втратив чинність.

Департаменту підготовки та проведення конкурсів (І.Білоцерковець) підготувати зміни до п. 51 Положення про порядок проведення конкурсів з продажу пакетів акцій відкритих акціонерних товариств, створених у процесі приватизації, затвердженого спільним наказом Фонду державного майна України, Антимонопольного комітету України, Державної комісії з цінних паперів та фондового ринку від 04.08.97 N 821/55/01/204 ( z0299-97 ) та зареєстрованого в Міністерстві юстиції України 08.08.97 за N 299/2103, із змінами та доповненнями до нього, затвердженими наказами Фонду державного майна України, Антимонопольного комітету України, Державної комісії з цінних паперів та фондового ринку від 05.03.98 N 408/2/63 ( z0167-98 ), від 21.04.98 N 792/4/108 ( z0262-98 ), від 12.08.98 N 1603/7/213 ( z0548-98 ), від 02.02.2000 N 192/2/18 ( z0081-00 ), від 29.02.2000 N 406/3/62 ( z0168-00 ).

2. Затвердити Примірний договір купівлі-продажу пакета акцій відкритого акціонерного товариства за некомерційним конкурсом, що додається*.

___________ * Відсутній не зареєстрований в Мін'юсті.

3. Затвердити акт прийому-передачі пакета акцій ВАТ, що додається*.

___________ * Відсутній не зареєстрований в Мін'юсті.

4. Департаменту підготовки та проведення конкурсів (І.Білоцерковець) у п'ятиденний термін з дня затвердження цього наказу забезпечити його подання на державну реєстрацію до Міністерства юстиції України.

5. Редакційно-видавничому відділу (Путівська Н.А.) у десятиденний термін з дня державної реєстрації цього наказу у Міністерстві юстиції України забезпечити опублікування у газеті "Відомості приватизації" Примірного договору купівлі-продажу пакета акцій відкритого акціонерного товариства за некомерційним конкурсом.

Контроль за виконанням цього наказу залишаю за собою.

В.о.Голови Фонду М.Чечетов
