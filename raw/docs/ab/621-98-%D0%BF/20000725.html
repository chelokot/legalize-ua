Текст документа від 25.07.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 травня 1998 р. N 621 Київ

Про умови оплати праці працівників виборчої комісії Автономної Республіки Крим

( Із змінами, внесеними згідно з Постановою КМ N 1161 ( 1161-2000-п ) від 25.07.2000 )

Відповідно до статті 17 Закону України "Про вибори депутатів Верховної Ради Автономної Республіки Крим" ( 118/98-ВР ) Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 1161 ( 1161-2000-п ) від 25.07.2000 )

2. Віднести посади голови виборчої комісії Автономної Республіки Крим та його заступника до другої категорії, секретаря комісії - до третьої категорії, референта-консультанта цієї комісії - до четвертої категорії, спеціалістів апарату виборчої комісії - до шостої категорії посад державних службовців.

3. Установити надбавки за особливий характер роботи та інтенсивність праці голові, заступнику голови та секретарю виборчої комісії Автономної Республіки Крим у розмірі 90 відсотків посадового окладу з урахуванням доплати за ранг.

( Пункт 4 втратив чинність на підставі Постанови КМ N 1161 ( 1161-2000-п ) від 25.07.2000 )

5. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 22 вересня 1994 р. N 697 ( 697-94-р ) та від 22 квітня 1997 р. N 226 ( 226-97-р ).
