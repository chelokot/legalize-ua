ПОСТАНОВА від 2 червня 2010 р. N 389 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про доповнення пункту 7 Положення про закупівлю товарів, робіт і послуг за державні кошти

Кабінет Міністрів України постановляє:

Доповнити пункт 7 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006; 2009 р., N 1, ст. 17, N 11, ст. 338, N 23, ст. 741, N 55, ст. 1915, N 56, ст. 1955, N 62, ст. 2195, N 65, ст. 2271, N 82, ст. 2770, N 92, ст. 3119; 2010 р., N 11, ст. 540, N 26, ст. 1033), абзацом такого змісту:

"товари, роботи і послуги, які закуповуються Національним агентством з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу для здійснення заходів з підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу.".

Прем'єр-міністр України М.АЗАРОВ
