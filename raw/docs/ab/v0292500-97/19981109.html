( Постанова втратила чинність на підставі Постанови Нацбанку N 470 ( v0470500-98, v0613500-99 ) від 09.11.98 )

Про затвердження нового складу Комісії з питань нагляду та регулювання діяльності банків

( Із змінами, внесеними згідно з Постановою Нацбанку N 432 ( va432500-97 ) від 12.12.97 )

Розглянувши клопотання Комісії з питань нагляду та регулювання діяльності банків (далі Комісія) про затвердження нового складу Комісії у зв'язку з реорганізацією служби банківського нагляду, Правління ПОСТАНОВЛЯЄ:

1. Вважати таким, що втратив чинність, п.2 постанови Правління від 23 липня 1996 року N 184 ( va184500-96 ) "Про Комісію з питань нагляду та регулювання діяльності банків".

2. Затвердити такий склад Комісії з питань нагляду та регулювання діяльності банків:

1. Бондар В.О. - голова Комісії

2. Кіреєв О.І. - заступник голови Комісії

3. Савченко А.С.

4. Герасименко Ю.О.

5. Степаненко А.І.

6. Дорофєєва Н.В.

7. Кротюк В.Л.

8. Гребеник Н.І.

9. Яременко С.О.

10. Сенищ П.М.

11. Брагін С.О.

12. Ревун В.І.

13. Пархоменко О.І.

14. Сізіков О.І.

15. Зінченко В.О.

16. Горячек І.Ю.

17. Каземир О.О.

( Пункт 2 із змінами, внесеними згідно з Постановою Нацбанку N 432 ( va432500-97 ) від 12.12.97 )
