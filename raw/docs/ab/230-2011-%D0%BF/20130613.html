{ Постанова втратила чинність на підставі Постанови КМ N 407 ( 407-2013-п ) від 03.06.2013 }

Про внесення зміни до пункту 11 Положення про портові збори

Кабінет Міністрів України постановляє:

Внести зміну до пункту 11 Положення про портові збори, затвердженого постановою Кабінету Міністрів України від 12 жовтня 2000 р. N 1544 ( 1544-2000-п ) (Офіційний вісник України, 2000 р., N 42, ст. 1784; 2001 р., N 48, ст. 2142; 2002 р., N 14, ст. 721; 2003 р., N 29, ст. 1465; 2004 р., N 52, ст. 3452; 2008 р., N 67, ст. 2233, N 68, ст. 2286; 2009 р., N 93, ст. 3159, N 89, ст. 3007, N 94, ст. 3215), виклавши його в такій редакції:

"11. На суми портових зборів нараховується податок на додану вартість відповідно до законодавства.".
