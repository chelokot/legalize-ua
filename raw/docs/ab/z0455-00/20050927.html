Стан: Втратив чинність

Ідентифікатор: z0455-00

Текст документа від 27.09.2005:

МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

N 130 від 21.07.2000 Зареєстровано в Міністерстві м.Київ юстиції України від 28 липня 2000 р. vd20000721 vn130 за N 455/4676

( Наказ втратив чинність на підставі Наказу Міністерства аграрної політики N 393 ( z1065-05 ) від 18.08.2005 )

Про Особливий порядок відкриття спеціальних рахунків цукровим заводам та використання коштів, що накопичуються на цих рахунках

На виконання постанови Кабінету Міністрів України від 2 червня 2000 року N 868 ( 868-2000-п ) "Про деякі питання державного регулювання виробництва і реалізації цукру" та з метою забезпечення поточних рахунків, пов'язаних з постачанням та переробкою цукрової сировини НАКАЗУЮ:

1. Затвердити Особливий порядок відкриття спеціальних рахунків цукровим заводам та використання коштів, що накопичуються на цих рахунках, погоджений з Міністерством фінансів, Міністерством економіки, Національним банком та Державною податковою адміністрацією України (додається).

2. Державному департаменту продовольства (Сватков Л.Б.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Рижука С.М. та голову Державного департаменту продовольства Сваткова Л.Б.

Міністр І.Кириленко

Затверджено Наказ Міністерства аграрної політики України 21.07.2000 N 130

Зареєстровано в Міністерстві юстиції України від 28 липня 2000 р. за N 455/4676

Особливий порядок відкриття спеціальних рахунків цукровим заводам та використання коштів, що накопичуються на цих рахунках

1. Для забезпечення поточних рахунків, пов'язаних з постачанням та переробкою цукрової сировини, своєчасної сплати поточних податкових платежів, погашення кредитів банку цукрові заводи відкривають спеціальний рахунок згідно з вимогами Інструкції про порядок відкриття та використання рахунків у національній та іноземній валюті, затвердженої постановою Правління НБУ від 18.12.98 N 527 ( z0819-98 ) (із змінами і доповненнями, внесеними постановами від 22.07.99 N 364 ( z0538-99 ) та від 14.04.2000 N 146 ( z0263-00 ), на який зараховуються кошти, отримані за рахунок кредитів банків, виручки від реалізації цукру, жому, меляси, попередня оплата, пов'язана з реалізацією цукрових буряків, цукру, жому, меляси, а також попередня оплата, пов'язана з відвантаженням цієї продукції (вартість залізничного тарифу, оренди цистерн тощо).

2. Кошти, що надходять на спеціальний рахунок цукрових заводів, спрямовуються на підставі їх платіжних доручень виключно для таких цілей :

розрахунків з товаровиробниками за цукросировину та закупівлі насіння цукрових буряків;

сплати поточних податкових платежів;

погашення кредитів банку, одержаних для розрахунків з товаровиробниками, та відсотків за користування ними;

закупівлі енергоносіїв, електроенергії, запасних частин, допоміжних матеріалів, оплати залізничного тарифу.

3. Залишки коштів із спеціальних рахунків на підставі платіжних доручень власників рахунків перераховуються на їх поточні рахунки.

Цей Порядок діє до 1 червня 2001 року.

Голова Державного департаменту продовольства Л.Б.Сватков
