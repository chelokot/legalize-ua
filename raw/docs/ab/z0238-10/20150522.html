ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

03.03.2010 N 191

Зареєстровано в Міністерстві юстиції України 23 березня 2010 р. за N 238/17533

{ Наказ втратив чинність на підставі Наказу Міністерства фінансів N 271 ( z0484-15 ) від 02.03.2015 }

Про внесення змін до Порядку розгляду звернень та особистого прийому громадян у Державній митній службі України, інших митних органах, спеціалізованих митних установах і організаціях

З метою забезпечення виконання вимог постанови Кабінету Міністрів України від 08.12.2009 N 1338 ( 1338-2009-п ) "Про заходи щодо посилення протидії корупції" НАКАЗУЮ:

1. Доповнити пункт 3.3 розділу III Порядку розгляду звернень та особистого прийому громадян у Державній митній службі України, інших митних органах, спеціалізованих митних установах і організаціях, затвердженого наказом Державної митної служби України від 14.09.2009 N 855 ( z0935-09 ) і зареєстрованого в Міністерстві юстиції України 06.10.2009 за N 935/16951, новою позицією "240 Факти корупції".

У зв'язку з цим позицію "240 Інше" вважати позицією "250 Інше".

2. Управлінню справами (Погорєлова Т.В.) та Юридичному департаменту (Бабюк В.Л.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Установити, що цей наказ набирає чинності з дня його офіційного опублікування.

4. Контроль за виконанням цього наказу покласти на першого заступника Голови Служби Піковського І.О.

Голова Служби А.В.Макаренко
