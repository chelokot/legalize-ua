Президент України; Указ від 17.06.2008 № 549/2008

Питання Міжвідомчої комісії з політики військово-технічного співробітництва та експортного контролю

Стан: Втратив чинність

Ідентифікатор: 549/2008

Текст документа від 17.06.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Міжвідомчої комісії з політики військово-технічного співробітництва та експортного контролю

1. На часткову зміну статті 3 Указу Президента України від 5 березня 2007 року N 180 ( 180/2007 ) "Про Міжвідомчу комісію з політики військово-технічного співробітництва та експортного контролю" (зі змінами, внесеними Указами від 27 червня 2007 року N 571 ( 571/2007 ) та від 24 березня 2008 року N 263) ( 263/2008 ) увести до складу Міжвідомчої комісії з політики військово-технічного співробітництва та експортного контролю ГОРІНА Олександра Олеговича - заступника Міністра закордонних справ України, призначивши його заступником голови Комісії.

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 17 червня 2008 року N 549/2008
