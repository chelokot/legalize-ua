МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

17.06.2009 N 711

Зареєстровано в Міністерстві юстиції України 15 липня 2009 р. за N 640/16656

Про затвердження Змін до наказу Мінтрансу від 17.07.2001 N 447

Відповідно до вимог розпорядження Кабінету Міністрів України від 20.11.2003 N 690-р ( 690-2003-р ) "Про вдосконалення механізму здійснення контролю за міжнародними повітряними перевезеннями товарів військового призначення та подвійного використання" НАКАЗУЮ:

1. Затвердити Зміни до Порядку оформлення вильоту повітряного судна для перевезення товарів військового та подвійного призначення, затвердженого наказом Міністерства транспорту України від 17.07.2001 N 447 ( z0979-01 ), зареєстрованого в Міністерстві юстиції України 21.11.2001 за N 979/6170, що додаються.

2. Державній авіаційній адміністрації (Овчинников О.В.):

2.1. Забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України у встановленому порядку.

2.2. Довести цей наказ до відома керівників підприємств, діяльність яких пов'язана з повітряними перевезеннями товарів військового та подвійного призначення.

3. Цей наказ набирає чинності через десять днів після державної реєстрації у Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника Міністра - голову Державної авіаційної адміністрації Давидова О.М.

ЗАТВЕРДЖЕНО Наказ Міністерства транспорту та зв'язку України 17.06.2009 N 711

Зареєстровано в Міністерстві юстиції України 15 липня 2009 р. за N 640/16656

ЗМІНИ до Порядку оформлення вильоту повітряного судна для перевезення товарів військового та подвійного призначення ( z0979-01 )

1. У тексті Порядку ( z0979-01 ) слово "Укравіатранс" і слова та цифри "розпорядження Кабінету Міністрів України від 09.12.99 N 1376-р ( 1376-99-р )" у всіх відмінках замінити відповідно словом "Державіаадміністрація" і словами та цифрами "розпорядження Кабінету Міністрів України від 20.11.2003 N 690-р ( 690-2003-р )" у відповідному відмінку.

2. Абзац сьомий пункту 1.3 викласти у такій редакції:

"постанову Кабінету Міністрів України від 02.11.2006 N 1526 ( 1526-2006-п ) "Про утворення Державної авіаційної адміністрації;".

3. Абзац дев'ятий пункту 1.3 викласти у такій редакції:

"Правила сертифікації експлуатантів, затверджені наказом Державної служби України з нагляду за забезпеченням безпеки авіації від 20.09.2005 N 684 ( z1545-05 ), зареєстровані в Міністерстві юстиції України 22.12.2005 за N 1545/11825;".

4. Абзац п'ятий підпункту 2.3.1 пункту 2.3 викласти у такій редакції:

"маршрут перевезення (аеропорти відправлення, призначення, запасні та проміжні аеродроми, аеродроми технічних посадок чи перевантаження/зберігання);".

5. Абзац восьмий підпункту 2.3.1 пункту 2.3 викласти у такій редакції:

"засвідчена печаткою заявника копія дозволу чи висновку Державної служби експортного контролю України (у разі виконання перевезень іноземними експлуатантами заявник додатково надає інформацію про доцільність виконання такого перевезення іноземним експлуатантом та письмове погодження Державної служби експортного контролю України);".

6. Абзац п'ятий підпункту 2.3.2 пункту 2.3 викласти у такій редакції:

"маршрут перевезення (аеропорти відправлення, призначення, запасні та проміжні аеродроми, аеродроми технічних посадок чи перевантаження/зберігання);".

7. Підпункт 2.3.2 пункту 2.3 після абзацу сьомого доповнити новим абзацом восьмим такого змісту:

"засвідчена печаткою заявника копія дозволу чи висновку Державної служби експортного контролю України;".

У зв'язку з цим абзаци восьмий - тринадцятий вважати відповідно абзацами дев'ятим - чотирнадцятим.

8. Пункт 2.4 виключити.

У зв'язку з цим пункти 2.5-2.10 вважати відповідно пунктами 2.4-2.9.

9. Пункт 2.4 викласти у такій редакції:

"2.4. Розгляд заяв і доданих до них документів проводиться на закритих засіданнях Комісії.".

10. У пункті 2.6 слова та цифри "перелічених в пункті 2.4" виключити.

11. Пункт 4.3 викласти у такій редакції:

"4.3. До перевірок у разі потреби можуть залучатися фахівці СБУ відповідно до пункту 8 розпорядження Кабінету Міністрів України від 20.11.2003 N 690-р ( 690-2003-р ).".
