МІНІСТЕРСТВО НАДЗВИЧАЙНИХ СИТУАЦІЙ УКРАЇНИ

06.06.2011 N 567

Зареєстровано в Міністерстві юстиції України 23 червня 2011 р. за N 756/19494

Про визнання такими, що втратили чинність, деяких наказів МНС

На виконання вимог Закону України "Про регулювання містобудівної діяльності" ( 3038-17 ) НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази:

Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи від 05.07.2004 N 297 ( z0905-04 ) "Про затвердження Положення про порядок державного пожежного нагляду за будівництвом об'єктів іноземними фірмами", зареєстрований у Міністерстві юстиції України 21.07.2004 за N 905/9504;

Міністерства України з питань надзвичайних ситуацій від 15.11.2004 N 170 ( z1467-04 ) "Про затвердження Положення про порядок погодження з органами державного пожежного нагляду проектних рішень, на які не встановлено норми та правила, обґрунтованих відхилень від обов'язкових вимог нормативних документів", зареєстрований у Міністерстві юстиції України 22.11.2004 за N 1467/10066;

Міністерства України з питань надзвичайних ситуацій від 23.11.2004 N 186 ( z1515-04 ) "Про проведення державної експертизи щодо пожежної безпеки проектів будівництва та іншої документації", зареєстрований у Міністерстві юстиції України 30.11.2004 за N 1515/10114;

Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи від 03.07.2007 N 462 ( z0831-07 ) "Про внесення змін та доповнень до наказу МНС від 23.11.2004 N 186", зареєстрований у Міністерстві юстиції України 19.07.2007 за N 831/14098.

2. Начальникам головних управлінь (управлінь) МНС України в Автономній Республіці Крим, областях, містах Києві та Севастополі у десятиденний строк з дня набрання чинності цим наказом привести у відповідність власні акти.

3. Державній інспекції техногенної безпеки України (Улинець Е.М.) спільно з Управлінням правового забезпечення (Поворозник Р.Р.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням цього наказу покласти на Голову Державної інспекції техногенної безпеки України Улинця Е.М.

5. Цей наказ набирає чинності з дня офіційного опублікування.
