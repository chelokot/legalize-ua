Верховна Рада України; Постанова від 17.04.2007 № 937-V

Про внесення змін до Постанови Верховної Ради України "Про заснування соціальних стипендій Верховної Ради України для студентів вищих навчальних закладів з числа дітей-сиріт та дітей з малозабезпечених сімей"

Стан: Втратив чинність

Ідентифікатор: 937-16

Текст документа від 01.01.2026:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

{ Постанова втратила чинність на підставі Постанови ВР N 4712-IX ( 4712-20 ) від 04.12.2025 }

Про внесення змін до Постанови Верховної Ради України "Про заснування соціальних стипендій Верховної Ради України для студентів вищих навчальних закладів з числа дітей-сиріт та дітей з малозабезпечених сімей"

{ Відомості Верховної Ради України (ВВР), 2007, N 25, ст.350 }

Верховна Рада України постановляє:

Внести до Постанови Верховної Ради України від 24 жовтня 2002 року "Про заснування соціальних стипендій Верховної Ради України для студентів вищих навчальних закладів з числа дітей-сиріт та дітей з малозабезпечених сімей" ( 218-15 ) (Відомості Верховної Ради України, 2002 р., N 47, ст. 358) такі зміни:

1. Пункт 4 викласти в такій редакції:

"4. Доручити Комітету Верховної Ради України з питань науки і освіти розподілити соціальні стипендії Верховної Ради України між міністерствами та іншими центральними органами виконавчої влади, яким підпорядковані вищі навчальні заклади, у межах кількості стипендій, встановленої Верховною Радою України".

2. Пункт 3 Положення про порядок призначення стипендій Верховної Ради України студентам вищих навчальних закладів з числа дітей-сиріт та дітей з малозабезпечених сімей ( 218-15 ), затвердженого Постановою Верховної Ради України від 24 жовтня 2002 року, викласти в такій редакції:

"3. Призначення стипендій Верховної Ради України проводиться щорічно з 1 вересня на один навчальний рік розпорядженням Голови Верховної Ради України за поданням Комітету Верховної Ради України з питань науки і освіти згідно з відповідними пропозиціями міністерств та інших центральних органів виконавчої влади, яким підпорядковані вищі навчальні заклади".
