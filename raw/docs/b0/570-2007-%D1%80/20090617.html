перелік пунктів пропуску на митному кордоні України, через які здійснюється ввезення на її митну територію, вивезення за її межі та переміщення транзитом товарів позицій 0201-0210, 0302-0307, 1601 00-1605 згідно з УКТЗЕД ( 2371а-14 ). { Абзац третій пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 646-р ( 646-2008-р ) від 17.04.2008 }
