Про квартальну бухгалтерську звітність підприємств

( Із змінами, внесеними згідно з Наказом Мінфіну N 37 ( z0151-98 ) від 19.02.98 )

Відповідно до Положення про Міністерство фінансів України, затвердженого постановою Кабінету Міністрів України від 27 лютого 1993 року N 147 ( 147-93-п ), НАКАЗУЮ:

1. Затвердити:

( Пункт 1.1 втратив чинність на підставі Наказу Мінфіну N 37 ( z0151-98 ) від 19.02.98 ) 1.1. Типові форми квартальної бухгалтерської звітності, які складаються підприємствами і організаціями, що є юридичними особами, та виділеними на окремий баланс філіями, представництвами, відділеннями та іншими відособленими підрозділами підприємств і організацій (крім банків і бюджетних установ), незалежно від видів діяльності та форм власності у складі Балансу підприємства (форма N 1) і Звіту про фінансові результати та їх використання (форма N 2), зразки яких наведено у додатку N 1.

( Пункт 1.2 втратив чинність на підставі Наказу Мінфіну N 37 ( z0151-98 ) від 19.02.98 ) 1.2. Зміни і доповнення до Інструкції про порядок заповнення форм річного бухгалтерського звіту підприємства, затвердженої наказом Міністерства фінансів України від 18 серпня 1995 року N 139 ( z0321-95 ) (із змінами і доповненнями), для застосування разом з указаною Інструкцією при заповненні форм квартальної бухгалтерської звітності (додаються).

2. Передбачити, що органи, у віданні яких перебувають юридичні особи, зведену квартальну бухгалтерську звітність складають і подають за видами діяльності, наведеними в додатку N 3 до наказу Міністерства фінансів України від 18 серпня 1995 року N 139 ( z0321-95 ).

3. Визнати такими, що втратили чинність, пункти 1 та 2 наказу Міністерства фінансів України від 23 січня 1996 року N 13 ( z0045-96 ) "Про квартальну бухгалтерську звітність підприємств".

4. Абзац другий пункту 2 листа Міністерства фінансів України від 12 серпня 1992 року N 18-4116 ( v4116201-92 ) "Про бухгалтерський облік вексельного обігу" із змінами і доповненнями, внесеними наказами Міністерства фінансів України від 26 липня 1994 року N 65 ( z0183-94 ) та від 23 січня 1996 року N 13 ( z0045-96 ), доповнити таким реченням: "Якщо отримані векселі переказані іншій юридичній особі або дисконтовані, то в даному звітному періоді ця відвантажена продукція відображається у складі виручки від реалізації продукції (товарів, робіт, послуг) з одночасним списанням вексельної суми з позабалансового рахунку 006".
