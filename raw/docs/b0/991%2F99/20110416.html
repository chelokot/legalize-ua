Президент України; Указ від 16.08.1999 № 991/99

Про внесення зміни до пункту 1 Порядку складення присяги суддею, вперше призначеним на посаду

Стан: Втратив чинність

Ідентифікатор: 991/99

Текст документа від 16.04.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 380/2011 ( 380/2011 ) від 06.04.2011 }

Про внесення зміни до пункту 1 Порядку складення присяги суддею, вперше призначеним на посаду

У пункті 1 Порядку складення присяги суддею, вперше призначеним на посаду, затвердженого Указом Президента України від 11 травня 1999 року N 493 ( 493/99 ), слова "не пізніше місяця з дня призначення" виключити.

Президент України Л.КУЧМА

м. Київ, 16 серпня 1999 року N 991/99
