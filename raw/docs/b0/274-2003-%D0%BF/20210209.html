КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 2003 р. N 274 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 81 ( 81-2021-п ) від 03.02.2021 }

Про затвердження нового складу Міжвідомчого центру з організації перепідготовки управлінських кадрів для сфери підприємництва та нового складу наглядової ради цього Центру

{ Щодо змін додатково див. Постанову КМ N 809 ( 809-2005-п ) від 23.08.2005 }

Кабінет Міністрів України постановляє:

На часткову зміну постанови Кабінету Міністрів України від 30 серпня 2000 р. N 1358 ( 1358-2000-п ) "Про реалізацію Указу Президента України від 3 липня 2000 р. N 849 "Про сприяння підготовці управлінських кадрів для сфери підприємництва" (Офіційний вісник України, 2000 р., N 35, ст. 1510; 2002 р., N 8, ст. 344) затвердити новий склад Міжвідомчого центру з організації перепідготовки управлінських кадрів для сфери підприємництва та новий склад наглядової ради цього Центру, що додаються.
