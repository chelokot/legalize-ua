Про внесення доповнення до наказу Мінтрансу від 13.10.95 р. N 342

У зв'язку з утворенням на Південно-Західній залізниці спеціалізованого підприємства по обслуговуванню пасажирів в поїздах "Укрвагонсервіс", НАКАЗУЮ:

Внести до пункту 2 наказу Міністерства транспорту України від 13.10.95 р. N 342 ( z0380-95 ) "Про внесення змін та доповнень до наказу від 21.07.95 р. N 273 "Про встановлення платних послуг по обслуговуванню пасажирів на вокзалах та в поїздах на залізницях України" таке доповнення:

абзац другий після слова: "...шостий..." доповнити словами: "...та десятий..." і далі по тексту.
