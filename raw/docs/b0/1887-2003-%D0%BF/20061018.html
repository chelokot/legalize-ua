{ Постанова втратила чинність на підставі Постанови КМ N 1427 ( 1427-2006-п ) від 18.10.2006 }

1. Таємно.

2. Таємно.

3. Визнати такими, що втратили чинність:

пункти 1 і 2 постанови Кабінету Міністрів України від 14 серпня 1998 р. N 1266 ( 1266-98-п ) "Питання державних номерних знаків для транспортних засобів" (Офіційний вісник України, 1998 р., N 33, ст. 1225);

пункт 7 змін та доповнень, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 27 вересня 2000 р. N 1469 ( 1469-2000-п ) (Офіційний вісник України, 2000 р., N 39, ст 1659).
