Про доповнення Правил обчислення загального трудового стажу для призначення працівникам допомоги по тимчасовій непрацездатності

Стан: Втратив чинність

Текст документа від 11.07.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 квітня 2000 р. N 697 Київ

( Постанова втратила чинність на підставі Постанови КМ N 807 ( 807-2001-п ) від 11.07.2001 )

Про доповнення Правил обчислення загального трудового стажу для призначення працівникам допомоги по тимчасовій непрацездатності

Кабінет Міністрів України постановляє:

Доповнити Правила обчислення загального трудового стажу для призначення працівникам допомоги по тимчасовій непрацездатності, затверджені постановою Кабінету Міністрів України від 19 жовтня 1998 р. N 1658 ( 1658-98-п ) (Офіційний вісник України, 1998 р., N 42, ст. 1556), пунктом 7-1 такого змісту:

"7-1. Суб'єктам підприємницької діяльності - фізичним особам, які обрали спрощену систему оподаткування, зараховується до загального трудового стажу весь період сплати ними єдиного податку, фіксованого сільськогосподарського податку, здійснення підприємницької та виробничої діяльності на підставі придбання спеціального торгового патенту".

Прем'єр-міністр України В.ЮЩЕНКО
