Текст документа від 09.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 серпня 2000 р. N 1309 Київ

Про нову редакцію додатка 14 до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288 та про віднесення до категорії посад державних службовців керівних працівників головних управлінь обласної, Київської міської державних адміністрацій

{ Із змінами, внесеними згідно з Постановою КМ N 268 ( 268-2006-п ) від 09.03.2006 }

У зв'язку з упорядкуванням структури місцевих державних адміністрацій Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

2. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади начальника головного управління обласної, Київської міської державних адміністрацій та його заступників до четвертої категорії, начальника управління у складі головного управління обласної, Київської міської державних адміністрацій та його заступника - до п'ятої категорії посад державних службовців.
