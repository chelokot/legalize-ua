{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про внесення змін до складу Міжвідомчої комісії із забезпечення виконання контракту N 1346/38/"Tank"/T-80UD/DGDP/PC-ЗА на постачання спецтехніки

Кабінет Міністрів України постановляє:

Затвердити головою Міжвідомчої комісії із забезпечення виконання контракту N 1346/38/"Tank"/T-80UD/DGDP/PC-ЗА на постачання спецтехніки, утвореної постановою Кабінету Міністрів України від 25 листопада 1996 р. N 1412 ( 1412-96-п ), Першого віце-прем'єр-міністра України Голубченка Анатолія Костянтиновича, увільнивши від цих обов'язків Мінченка Анатолія Калениковича.
