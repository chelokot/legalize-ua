НАКАЗ

N 32 від 26.01.99 Зареєстровано в Міністерстві м.Київ юстиції України 3 лютого 1999 р. за N 61/3354

( Наказ втратив чинність на підставі Наказу Мінекономіки N 136 ( z0420-00 ) від 29.06.2000 )

Про внесення доповнень до наказу МЗЕЗторгу від 24.02.96 N 133-а

Відповідно до Указу Президента України від 07.11.94 N 659/94 "Про облік окремих видів зовнішньоекономічних договорів (контрактів) в Україні" та з метою усунення загрози запровадження відповідних санкцій до українського експорту у зв'язку з порушенням антидемпінгових розслідувань НАКАЗУЮ:

1. Перелік товарів, експорт яких здійснюється відповідно до конкретних заходів з метою запобігання антидемпінгових процедур, затверджений наказом МЗЕЗторгу України від 24.02.96 N 133-а ( z0125-96 ) і зареєстрований в Міністерстві юстиції України 19.03.96 за N 125/1150, зі змінами та доповненнями, доповнити товарними позиціями та кодами ТН ЗЕД: "прутки гарячекатані у вільно змотаних бухтах із заліза та нелегованої сталі (тільки на ринки країн Латинської Америки, Азії та Африки) 7213 прутки інші із заліза та нелегованої сталі, без подальшої обробки після кування, гарячої прокатки, гарячого пресування, включаючи прутки зігнуті після прокатки (тільки на ринки країн Латинської Америки, Азії та Африки) 7214"

2. Управлінню правового забезпечення (Сервинський А.Ю.) забезпечити реєстрацію цього наказу в Міністерстві юстиції України у встановленому порядку.

3. Управлінню справами (Дробний В.В.) довести цей наказ до відома регіональних підрозділів МЗЕЗторгу, до відома Мінекономіки, Держмитслужби, Мінпромполітики та забезпечити його публікацію в засобах масової інформації.

4. Контроль за виконанням цього наказу покласти на заступника Міністра В.І.Олійника.

Перший заступник Міністра А.І.Гончарук
