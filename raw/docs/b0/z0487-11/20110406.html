ПРАВЛІННЯ ПЕНСІЙНОГО ФОНДУ УКРАЇНИ

ПОСТАНОВА

06.04.2011 N 10-2

Зареєстровано в Міністерстві юстиції України 20 квітня 2011 р. за N 487/19225

Про визнання такими, що втратили чинність, деяких постанов правління Пенсійного фонду України

Відповідно до пункту 12 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261 ( 1261-2007-п ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Визнати такими, що втратили чинність:

постанову правління Пенсійного фонду України від 13.12.94 N 11-4 ( z0046-95 ) "Про затвердження Інструкції по бухгалтерському обліку та звітності в органах Пенсійного фонду України", зареєстровану в Міністерстві юстиції України 23.02.95 за N 46/582;

постанову правління Пенсійного фонду України від 04.07.96 N 8-1 ( z0371-96 ) "Про внесення змін та доповнень до Інструкції по бухгалтерському обліку та звітності в органах Пенсійного фонду України, затвердженої постановою правління Пенсійного фонду України від 13.12.94 р. N 11-4", зареєстровану в Міністерстві юстиції України 22.07.96 за N 371/1396;

постанову правління Пенсійного фонду України від 23.02.98 N 2-1 ( z0157-98 ) "Про внесення змін та доповнень до Інструкції по бухгалтерському обліку та звітності в органах Пенсійного фонду України", зареєстровану в Міністерстві юстиції України 10.03.98 за N 157/2597.

2. Департаменту зведеного бюджету (Придня Т.Г.) разом з юридичним управлінням (Рябцева Т.Б.) подати цю постанову для державної реєстрації до Міністерства юстиції України.

3. Ця постанова набирає чинності з дня її офіційного опублікування.

4. Контроль за виконанням цієї постанови покласти на заступника Голови правління Короневського В.М.

Голова правління Б.Зайчук
