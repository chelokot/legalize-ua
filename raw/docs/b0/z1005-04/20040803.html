МІНІСТЕРСТВО ВНУТРІШНІХ СПРАВ УКРАЇНИ

НАКАЗ

03.08.2004 N 866

Зареєстровано в Міністерстві юстиції України 12 серпня 2004 р. за N 1005/9604

Про визнання такими, що втратили чинність, деяких наказів МВС України

На виконання пункту 5 доручення Прем'єр-міністра України від 30.01.2003 N 5265 щодо реалізації вимог Указу Президента України від 27 січня 2003 року N 47 ( 47/2003 ) "Про заходи щодо вдосконалення державного управління у сфері пожежної безпеки, захисту населення і територій від наслідків надзвичайних ситуацій" НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

1.1. Наказ МВС України від 03.10.94 N 555 ( z0253-94 ) "Про затвердження Типового договору про організацію Державної пожежної охорони МВС України на об'єктах", зареєстрований в Міністерстві юстиції України 18.10.94 за N 253/463.

1.2. Наказ МВС України від 17.11.94 N 626 ( z0296-94 ) "Про затвердження Положення про сільську пожежну охорону", зареєстрований в Міністерстві юстиції України 07.12.94 за N 296/506.

1.3. Наказ МВС України від 22.06.95 N 400 ( z0219-95 ) "Про введення в дію Правил пожежної безпеки в Україні" (зі змінами), зареєстрований в Міністерстві юстиції України 14.07.95 за N 219/755.

1.4. Наказ МВС України від 02.10.95 N 657 ( z0409-95 ) "Про затвердження Настанови по організації роботи підрозділів Державної пожежної охорони, що охороняють об'єкти на договірних засадах" (зі змінами та доповненнями), зареєстрований в Міністерстві юстиції України 09.11.95 за N 409/945.

1.5. Наказ МВС України від 05.09.98 N 651 ( z0612-98 ) "Про затвердження Переліку об'єктів та промислових підприємств з підвищеним рівнем вибухопожежонебезпеки, які підлягають щорічному пожежно-технічному обстеженню", зареєстрований в Міністерстві юстиції України 30.09.98 за N 612/3052.

1.6. Наказ МВС України від 01.10.98 N 690 ( z0815-98 ) "Про затвердження Положення про порядок державного пожежного нагляду за будівництвом об'єктів іноземними фірмами", зареєстрований в Міністерстві юстиції України 23.12.98 за N 815/3255.

1.7. Наказ МВС України від 29.10.98 N 794 ( z0713-98 ) "Про затвердження Тимчасового положення про професійну пожежну охорону МВС України", зареєстрований в Міністерстві юстиції України 09.11.98 за N 713/3153.

1.8. Наказ МВС України від 29.07.2000 N 507 ( z0662-00 ) "Про затвердження Правил технічного утримування установок пожежної автоматики", зареєстрований в Міністерстві юстиції України 28.09.2000 за N 662/4883.

1.9. Наказ МВС України від 19.11.2002 N 1194 ( z0946-02 ) "Про введення в дію Правил пожежної безпеки на ринках України", зареєстрований в Міністерстві юстиції України 04.12.2002 за N 946/7234.

2. Контроль за виконанням наказу покласти на першого заступника Міністра - начальника Головного штабу МВС України генерал-лейтенанта міліції Гусарова С.М.

Наказ надіслати за належністю.
