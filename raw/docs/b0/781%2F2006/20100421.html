Президент України; Указ від 25.09.2006 № 781/2006

Питання наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України"

Стан: Втратив чинність

Ідентифікатор: 781/2006

Текст документа від 21.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 539/2010 ( 539/2010 ) від 14.04.2010 }

{ Дію Указу відновлено згідно з Указом Президента N 200/2007 ( 200/2007 ) від 12.03.2007 }

{ Указ втратив чинність на підставі Указу Президента N 156/2007 ( 156/2007 ) від 27.02.2007 }

Питання наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України"

Відповідно до статті 7 Закону України "Про банки і банківську діяльність" ( 2121-14 ) постановляю:

На часткову зміну статей 1 і 3 Указу Президента України від 1 березня 2005 року N 390 ( 390/2005 ) "Про членів наглядових рад відкритого акціонерного товариства "Державний ощадний банк України" та відкритого акціонерного товариства "Державний експортно-імпортний банк України" (зі змінами, внесеними Указами від 2 березня 2006 року N 182 ( 182/2006 ), від 11 травня 2006 року N 385 ( 385/2006 ) та від 22 травня 2006 року N 423 ( 423/2006 ):

призначити членом наглядової ради відкритого акціонерного товариства "Державний ощадний банк України" та членом наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України" ЯЦЕНЮКА Арсенія Петровича - Першого заступника Глави Секретаріату Президента України - Представника Президента України у Кабінеті Міністрів України;

припинити повноваження члена наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України" В. Савицького.

Президент України В.ЮЩЕНКО
