Кабінет Міністрів України; Постанова від 29.11.2006 № 1650

Про внесення змін до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів, та постанови Кабінету Міністрів України від 2 листопада 2006 р. N 1523

Стан: Чинний

Ідентифікатор: 1650-2006-п

Текст документа від 01.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 листопада 2006 р. N 1650 Київ

Про внесення змін до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів, та постанови Кабінету Міністрів України від 2 листопада 2006 р. N 1523

{ Із змінами, внесеними згідно з Постановою КМ N 283 ( 283-2011-п ) від 21.03.2011 }

Кабінет Міністрів України постановляє:

Внести до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів, затвердженого постановою Кабінету Міністрів України від 23 лютого 2006 р. N 207 ( 207-2006-п ) (Офіційний вісник України, 2006 р., N 8, ст. 458), та постанови Кабінету Міністрів України від 2 листопада 2006 р. N 1523 ( 1523-2006-п ) "Про утворення Державного комітету рибного господарства України" (Офіційний вісник України, 2006 р., N 44, ст. 2948) зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 22

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 29 листопада 2006 р. N 1650

ЗМІНИ, що вносяться до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів ( 207-2006-п ), та постанови Кабінету Міністрів України від 2 листопада 2006 р. N 1523 ( 1523-2006-п )

{ Пункт 1 втратив чинність на підставі Постанови КМ N 283 ( 283-2011-п ) від 21.03.2011 }

2. У постанові Кабінету Міністрів України від 2 листопада 2006 р. N 1523 ( 1523-2006-п ):

1) доповнити пункт 1 словами ", діяльність якого спрямовується і координується Кабінетом Міністрів України через Міністра аграрної політики.";

2) пункт 2 викласти у такій редакції:

"2. Установити, що Комітет є правонаступником Міністерства аграрної політики з питань рибного господарства.";

3) доповнити постанову пунктом 4 такого змісту:

"4. Взяти до відома, що Комітет розміщується по вул. Артема, 45а, у м. Києві.".
