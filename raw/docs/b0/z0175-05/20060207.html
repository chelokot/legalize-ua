Про внесення змін до наказу Міністерства праці та соціальної політики України від 10.09.2004 N 207

На виконання постанови Кабінету Міністрів України від 15.01.2005 N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 10.09.2004 N 207 ( z1171-04 ) "Про умови оплати праці працівників центрів соціально-психологічної допомоги", зареєстрованого в Міністерстві юстиції України 16.09.2004 за N 1171/9770, виклавши додатки 1, 2 у новій редакції (додаються).

2. Ці зміни застосовуються з 1 січня 2005 року.

В.о. Міністра М.Папієв
