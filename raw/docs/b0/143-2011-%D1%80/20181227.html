КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 лютого 2011 р. N 143-р Київ

Про віднесення держав до переліку офшорних зон

{ Назва Розпорядження в редакції Розпорядження КМ N 1079-р ( 1079-2018-р ) від 27.12.2018 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1079-р ( 1079-2018-р ) від 27.12.2018 }

1. Відповідно до пункту 1 частини першої статті 15 Закону України "Про запобігання та протидію легалізації (відмиванню) доходів, одержаних злочинним шляхом, фінансуванню тероризму та фінансуванню розповсюдження зброї масового знищення" ( 1702-18 ) віднести до переліку офшорних зон держави згідно з додатком.

{ Пункт 1 в редакції Розпорядження КМ N 1079-р ( 1079-2018-р ) від 27.12.2018 }

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 24 лютого 2003 р. N 77 ( 77-2003-р ) "Про перелік офшорних зон" (Офіційний вісник України, 2003 р., N 9, ст. 401);

розпорядження Кабінету Міністрів України від 1 квітня 2005 р. N 82 ( 82-2005-р ) "Про внесення змін у додаток до розпорядження Кабінету Міністрів України від 24 лютого 2003 р. N 77" (Офіційний вісник України, 2005 р., N 14, ст. 722);

розпорядження Кабінету Міністрів України від 1 лютого 2006 р. N 44 ( 44-2006-р ) "Про внесення зміни у додаток до розпорядження Кабінету Міністрів України від 24 лютого 2003 р. N 77" (Офіційний вісник України, 2006 р., N 5, ст. 239).

3. Це розпорядження набирає чинності з 1 квітня 2011 року.
