Кабінет Міністрів України; Розпорядження від 29.10.2009 № 1285-р

Про додаткові заходи з протидії туберкульозу

Стан: Чинний

Ідентифікатор: 1285-2009-р

Текст документа від 03.01.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 жовтня 2009 р. N 1285-р Київ

Про додаткові заходи з протидії туберкульозу

{ Із змінами, внесеними згідно з Розпорядженням КМ N 3-р ( 3-2013-р ) від 03.01.2013 }

Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським держадміністраціям забезпечити утворення у складі протитуберкульозних диспансерів (лікарень) у межах штатної чисельності їх працівників та видатків на функціонування таких диспансерів (лікарень) відділень (палат) для хворих на заразну форму туберкульозу, щодо яких судом ухвалено рішення про примусову госпіталізацію, а також їх охорону.

{ Текст Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 3-р ( 3-2013-р ) від 03.01.2013 }

Прем'єр-міністр України Ю.ТИМОШЕНКО
