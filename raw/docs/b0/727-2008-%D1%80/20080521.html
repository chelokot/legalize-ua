Про визнання такими, що втратили чинність, деяких розпоряджень Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 727-2008-р

Текст документа від 21.05.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 травня 2008 р. N 727-р Київ

Про визнання такими, що втратили чинність, деяких розпоряджень Кабінету Міністрів України

Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України:

від 25 липня 2002 р. N 402 ( 402-2002-р ) "Про затвердження складу наглядової ради Вінницького національного медичного університету імені М.І. Пирогова";

від 24 лютого 2003 р. N 75 ( 75-2003-р ) "Про затвердження складу наглядової ради Національного фармацевтичного університету";

від 24 лютого 2003 р. N 76 ( 76-2003-р ) "Про затвердження нового складу наглядової ради Національного медичного університету імені О.О. Богомольця";

від 14 січня 2004 р. N 3 ( 3-2004-р ) "Про затвердження складу наглядової ради Львівського національного медичного університету імені Данила Галицького".

Прем'єр-міністр України Ю.ТИМОШЕНКО
