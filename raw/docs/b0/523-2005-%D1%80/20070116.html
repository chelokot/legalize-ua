Текст документа від 16.01.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 грудня 2005 р. N 523-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 21 ( 21-2007-п ) від 16.01.2007 }

Про голову Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України

1. Затвердити головою Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України, утвореної постановою Кабінету Міністрів України від 2 липня 1998 р. N 1000 ( 1000-98-п ), Прем'єр-міністра України.

2. Увільнити від виконання обов'язків голови Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України Безсмертного Романа Петровича.
