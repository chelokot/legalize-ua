Кабінет Міністрів України; Постанова від 28.07.2010 № 641

Про внесення змін до складу Міжвідомчої комісії сприяння проведенню Першого всеукраїнського загального сільськогосподарського перепису та Положення про неї

Стан: Втратив чинність

Ідентифікатор: 641-2010-п

Текст документа від 07.11.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 липня 2010 р. N 641 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 582 ( 582-2014-п ) від 30.10.2014 }

Про внесення змін до складу Міжвідомчої комісії сприяння проведенню Першого всеукраїнського загального сільськогосподарського перепису та Положення про неї

Кабінет Міністрів України постановляє:

Внести до складу Міжвідомчої комісії сприяння проведенню Першого всеукраїнського загального сільськогосподарського перепису та Положення про неї, затверджених постановою Кабінету Міністрів України від 17 липня 2009 р. N 769 ( 769-2009-п ) (Офіційний вісник України, 2009 р., N 56, ст. 1953), такі зміни:

у складі Міжвідомчої комісії сприяння проведенню Першого всеукраїнського загального сільськогосподарського перепису ( 769-2009-п ) слова "Перший віце-прем'єр-міністр України", "Української академії аграрних наук", "президії Ради сільських і селищних голів при Кабінеті Міністрів України" замінити відповідно словами "Віце-прем'єр-міністр України (відповідно до розподілу функціональних повноважень)", "Національної академії аграрних наук", "Всеукраїнської асоціації сільських і селищних рад - керівник виконавчої дирекції";

в абзаці третьому пункту 7 Положення про Міжвідомчу комісію сприяння проведенню Першого всеукраїнського загального сільськогосподарського перепису ( 769-2009-п ) слова "Перший віце-прем'єр-міністр України" замінити словами "Віце-прем'єр-міністр України (відповідно до розподілу функціональних повноважень)".

Прем'єр-міністр України М.АЗАРОВ
