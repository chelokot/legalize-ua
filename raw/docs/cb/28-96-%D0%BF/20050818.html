( Постанова втратила чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про Державну міжвідомчу комісію з виробництва і впровадження приладів обліку споживання паливно-енергетичних ресурсів

( Із змінами, внесеними згідно з Постановами КМ N 290 ( 290-99-п ) від 01.03.99 N 799 ( 799-2000-п ) від 12.05.2000 Розпорядженням КМ N 528-р ( 528-2001-р ) від 17.11.2001 )

Кабінет Міністрів України постановляє:

1. Утворити Державну міжвідомчу комісію з виробництва і впровадження приладів обліку споживання паливно-енергетичних ресурсів у складі згідно з додатком. ( На часткову зміну пункту 1 додатково див. Постанову КМ N 799 ( 799-2000-п ) від 12.05.2000 )
