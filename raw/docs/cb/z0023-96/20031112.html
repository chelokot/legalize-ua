( Наказ втратив чинність на підставі Наказу Міністерства освіти і науки N 729 ( z1038-03 ) від 31.10.2003 )

Про затвердження нормативних актів

( Із змінами, внесеними згідно з Наказами МОН N 738 ( z0964-01 ) від 14.11.2001 N 739 ( z0965-01 ) від 14.11.2001 )

Відповідно до Положення про порядок оформлення та використання прав на винаходи, корисні моделі і промислові зразки, що становлять державну таємницю, затвердженого Постановою Верховної Ради України від 19 січня 1995 року N 4/95-ВР, НАКАЗУЮ:

( Пункт 1 втратив чинність на підставі Наказу МОН N 739 ( z0965-01 ) від 14.11.2001 )

2. Затвердити Положення про Державний реєстр посвідчень України на промислові зразки, що становлять державну таємницю, та порядок видачі посвідчень ( z0024-96 ).

( Пункт 3 втратив чинність на підставі Наказу МОН N 738 ( z0964-01 ) від 14.11.2001 )

4. Опублікувати Положення зазначені в пп.1-3 цього наказу в офіційному бюлетені Держпатенту "Промислова власність".

Перший заступник голови Держпатенту України В.О.Жаров

( Положення про Державний реєстр посвідчень України на винаходи, що становлять державну таємницю, та порядок видачі посвідчень втратило чинність на підставі Наказу МОН N 739 ( z0965-01 ) від 14.11.2001 )
