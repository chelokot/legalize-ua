РОЗПОРЯДЖЕННЯ від 8 грудня 2009 р. N 1536-р Київ

{ Розпорядження скасовано на підставі Постанови КМ N 254 ( 254-2011-п ) від 17.03.2011 }

Про реєстрацію автомобілів для надання медичної допомоги як виробів медичного призначення

Погодитися з пропозицією Міністерства охорони здоров'я щодо внесення до Державного реєстру виробів медичного призначення придбаних за бюджетні кошти адаптованих автомобілів спеціалізованих марки "Opel Combo" за кодом згідно з УКТЗЕД 8705 90 90 90 ( 2371г-14 ) для надання медичної допомоги як виробів медичного призначення.

Прем'єр-міністр України Ю.ТИМОШЕНКО
