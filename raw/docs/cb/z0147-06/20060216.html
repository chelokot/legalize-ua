Зареєстровано в Міністерстві юстиції України 17 лютого 2006 р. за N 147/12021

Про втрату чинності деяких наказів Міністерства транспорту України

Відповідно до Положення про Міністерство транспорту та зв'язку України, затвердженого Указом Президента України від 27.08.2004 N 1009 ( 1009/2004 ), НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Міністерства транспорту України:

від 07.09.99 N 434 ( z0637-99 ) "Про затвердження Правил реєстрації цивільних повітряних суден в Україні", зареєстрований в Міністерстві юстиції України 22.09.99 за N 637/3930;

від 05.07.2004 N 569 ( z0924-04 ) "Про затвердження Правил сертифікації аеропортів", зареєстрований в Міністерстві юстиції України 26.07.2004 за N 924/9523.

2. Юридичному управлінню (Тарасова Л.О.) забезпечити подання цього наказу в установленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконання цього наказу покласти на заступника Міністра Рябікіна П.Б.

Міністр В.Бондар
