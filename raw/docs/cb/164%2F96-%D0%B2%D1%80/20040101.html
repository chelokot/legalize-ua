Про введення в дію Закону України "Про звільнення від обкладення митом предметів, які вивозяться (пересилаються) громадянами за митний кордон України"

Стан: Втратив чинність

Ідентифікатор: 164/96-вр

Текст документа від 01.01.2004:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

( Постанова втратила чинність на підставі Кодексу N 92-IV ( 92-15 ) від 11.07.2002, ВВР, 2002, N 38-39, ст.288 )

Про введення в дію Закону України "Про звільнення від обкладення митом предметів, які вивозяться (пересилаються) громадянами за митний кордон України"

( Відомості Верховної Ради України (ВВР), 1996, N 26, ст. 115 )

Верховна Рада України постановляє:

1. Ввести в дію Закон України "Про звільнення від обкладення митом предметів, які вивозяться (пересилаються) громадянами за митний кордон України" ( 163/96-ВР ) з дня опублікування.

2. Кабінету Міністрів України в десятиденний термін привести рішення Уряду у відповідність із зазначеним Законом.

3. Визнати такими, що втратили чинність:

1) Закон України "Про порядок обкладення митом предметів, які вивозяться (пересилаються) громадянами за митний кордон України" ( 3894-12 ) (Відомості Верховної Ради України, 1994 р., N 20, ст. 118);

2) пункт 6 Закону України "Про внесення змін і доповнень до деяких законодавчих актів України" ( 297/95-ВР ) (Відомості Верховної Ради України, 1995 р., N 30, ст.229).
