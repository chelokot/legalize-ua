Текст документа від 21.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 травня 2008 р. N 711-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1240-р ( 1240-2010-р ) від 21.06.2010 }

Про генерального конструктора із створення Єдиної автоматизованої системи управління Збройними Силами

1. Прийняти пропозицію Міноборони та МОН щодо надання ректорові Національного технічного університету України "Київський політехнічний інститут" Згуровському Михайлу Захаровичу повноважень генерального конструктора із створення Єдиної автоматизованої системи управління Збройними Силами, увільнивши від їх виконання Морозова Анатолія Олексійовича.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 15 липня 1998 р. N 597 ( 597-98-р ).
