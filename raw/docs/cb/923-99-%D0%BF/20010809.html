Відповідно до частини третьої статті 24 Закону України "Про наукову і науково-технічну діяльність" ( 1977-12 ) Кабінет Міністрів України постановляє:

( Вступна частина в редакції Постанови КМ N 1191 ( 1191-2000-п ) від 02.08.2000 )

1. Затвердити перелік посад наукових (науково-педагогічних) працівників державних підприємств, установ, організацій, перебування на яких дає право на призначення пенсій та виплату грошової допомоги у разі виходу на пенсію відповідно до Закону України "Про наукову і науково-технічну діяльність", що додається. ( Пункт 1 в редакції Постанови N 1191 ( 1191-2000-п ) від 02.08.2000 )

2. До стажу наукової роботи зараховується робота в наукових установах та вищих навчальних закладах колишніх Української РСР, інших республік СРСР, а також СРСР на посадах, зазначених у переліку. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1191 ( 1191-2000-п ) від 02.08.2000, Рішенням Конституційного Суду N 9-рп/2001 ( v009p710-01 )від 19.06.2001, в редакції Постанови КМ N 976 ( 976-2001-п ) від 09.08.2001 )

( Пункт 3 втратив чинність на підставі Постанови КМ N 1191 ( 1191-2000-п ) від 02.08.2000 )

2. Науково-дослідні керівник (директор), заступник керівника установи, організації (директора) з наукової роботи, радник (їхні філії) при дирекції, учений секретар установи, організації (їхніх філій); керівник (завідувач, начальник тощо), заступник керівника (завідувача, начальника тощо), головний науковий співробітник, провідний науковий співробітник, старший науковий співробітник, науковий співробітник, молодший науковий співробітник підрозділу (відділення, відділу, лабораторії, сектору, групи тощо), інженерно-технічні працівники та інші спеціалісти, які виконують наукову, науково-технічну або науково-організаційну роботу.

Посади інженерно-технічних працівників, які мають науковий ступінь або вчене звання і працюють за спеціальністю.

3. Посади інженерно-технічних працівників, які мають науковий ступінь або вчене звання і працюють за спеціальністю.

4. Дослідні, проектні, головний науковий співробітник, пошукові, провідний науковий співробітник, старший проектно- науковий співробітник, науковий конструкторські, співробітник, молодший науковий технологічні, співробітник підрозділу (відділення, проектно-технологічні, відділу, лабораторії, сектору, групи конструкторські тощо), які виконують наукову, організації; науково-технічну або науково-технічні, науково-організаційну обчислювальні центри; роботу. науково-технічні комплекси; заклади Посади інженерно-технічних охорони здоров'я; працівників, які мають науковий підприємства, ступінь або вчене звання і працюють виробничі об'єднання за спеціальністю. тощо
