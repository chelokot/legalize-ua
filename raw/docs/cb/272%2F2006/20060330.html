Президент України; Указ від 30.03.2006 № 272/2006

Про визнання такими, що втратили чинність, деяких указів Президента України з питань оплати праці

Стан: Чинний

Ідентифікатор: 272/2006

Текст документа від 30.03.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання такими, що втратили чинність, деяких указів Президента України з питань оплати праці

З метою впорядкування умов оплати праці працівників органів державної влади постановляю:

Визнати такими, що втратили чинність:

Указ Президента України від 19 грудня 1995 року N 1162 ( 1162/95 ) "Про додаткові заходи щодо матеріального забезпечення працівників органів юстиції";

абзац третій статті 3 Указу Президента України від 4 жовтня 1996 року N 925 ( 925/96 ) "Про грошове забезпечення військовослужбовців та умови оплати праці працівників Служби безпеки України" (зі змінами, внесеними Указом від 31 липня 2000 року N 939 ( 939/2000 ) у частині встановлення щомісячної надбавки працівникам;

статтю 2-1 Указу Президента України від 4 жовтня 1996 року N 926 ( 926/96 ) "Про умови грошового забезпечення осіб рядового і начальницького складу та оплати праці працівників органів внутрішніх справ" (зі змінами, внесеними Указами від 31 серпня 2001 року N 771 ( 771/2001 ), від 7 листопада 2001 року N 1052 ( 1052/2001 ) та від 22 березня 2002 року N 289 ( 289/2002 ) у частині встановлення щомісячної надбавки працівникам;

абзац перший статті 2 Указу Президента України від 4 жовтня 1996 року N 927 ( 927/96 ) "Питання Апарату Ради національної безпеки і оборони України" (в редакції Указу від 12 грудня 1996 року N 1192 ( 1192/96 );

абзац третій статті 7 Указу Президента України від 29 листопада 1996 року N 1145 ( 1145/96 ) "Про Державну митну службу України" (в редакції Указу від 23 березня 1998 року N 216 ( 216/98 );

статтю 3 Указу Президента України від 17 листопада 1998 року N 1258 ( 1258/98 ) "Про утворення Національної служби посередництва і примирення" в частині прирівняння за умовами оплати праці голови Національної служби посередництва і примирення до голів державних комітетів, його заступника - до заступника голови державного комітету, інших працівників - до відповідних категорій працівників державних комітетів;

статтю 2 Указу Президента України від 11 грудня 2001 року N 1207 ( 1207/2001 ) "Про деякі заходи щодо зміцнення юридичних служб державних органів";

Указ Президента України від 22 березня 2002 року N 288 ( 288/2002 ) "Про посилення соціального захисту осіб начальницького складу податкової міліції органів державної податкової служби";

Указ Президента України від 18 квітня 2002 року N 349 "Про деякі заходи щодо матеріального забезпечення працівників прокуратури у зв'язку з додатковим навантаженням";

Указ Президента України від 20 червня 2002 року N 575 ( 575/2002 ) "Про посилення соціального захисту працівників органів державної податкової служби";

абзац третій статті 8 Указу Президента України від 25 вересня 2002 року N 860 ( 860/2002 ) "Питання Державного управління справами" в частині встановлення розмірів посадових окладів працівникам Державного управління справами, виходячи з посадових окладів працівників Адміністрації Президента України;

Указ Президента України від 11 грудня 2002 року N 1141 ( 1141/2002 ) "Про надбавки до посадових окладів працівників органів державної судової адміністрації";

Указ Президента України від 24 грудня 2002 року N 1213 ( 1213/2002 ) "Про додаткові заходи щодо матеріального забезпечення працівників Вищої ради юстиції";

пункт 2 статті 2 Указу Президента України від 24 жовтня 2003 року N 1209 ( 1209/2003 ) "Про заходи щодо підвищення ефективності діяльності митної служби України";

статтю 4 Указу Президента України від 14 листопада 2005 року N 1599 ( 1599/2005 ) "Про деякі питання Комітету з Національної премії України імені Тараса Шевченка" щодо умов оплати праці голови Комітету з Національної премії України імені Тараса Шевченка та його заступника, виходячи з умов забезпечення керівника державного комітету та його заступника.
