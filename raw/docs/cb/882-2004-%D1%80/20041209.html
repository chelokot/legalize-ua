Кабінет Міністрів України; Розпорядження від 02.12.2004 № 882-р

Про забезпечення виплати пенсій та інших соціальних виплат, що відповідно до законодавства здійснюється з Пенсійного фонду України

Стан: Чинний

Ідентифікатор: 882-2004-р

Текст документа від 09.12.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 грудня 2004 р. N 882-р Київ

Про забезпечення виплати пенсій та інших соціальних виплат, що відповідно до законодавства здійснюється з Пенсійного фонду України

( Із змінами, внесеними згідно з Розпорядженням КМ N 887-р ( 887-2004-р ) від 09.12.2004 )

Державному казначейству надати Пенсійному фонду України позичку у розмірі 1100 млн. гривень на умовах згідно з постановою Кабінету Міністрів України від 2 листопада 2004 р. N 1477 ( 1477-2004-п ) "Про заходи щодо підвищення ефективності управління державними коштами" (Офіційний вісник України, 2004 р., N 44, ст. 2908). ( Абзац перший із змінами, внесеними згідно з Розпорядженням КМ N 887-р ( 887-2004-р ) від 09.12.2004 )

Пенсійному фонду України забезпечити безумовне погашення позички із застосуванням механізму, визначеного згідно із зазначеною постановою.

Прем'єр-міністр України В.ЯНУКОВИЧ
