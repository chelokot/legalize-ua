Про затвердження Нормативів відбору проб і зразків товарів для проведення досліджень (аналізу, експертизи) митними лабораторіями

{ Із змінами, внесеними згідно з Наказом Державної митної служби N 760 ( z1153-07 ) від 14.09.2007 }

На виконання вимог статті 75 Митного кодексу України від 11.07.2002 N 92-IV ( 92-15 ) та з метою посилення митного контролю, визначення мінімальної кількості проб і зразків товарів, що беруться для проведення контрольної перевірки їх митними лабораторіями, НАКАЗУЮ:

1. Затвердити Нормативи відбору проб і зразків товарів для проведення досліджень (аналізу, експертизи) митними лабораторіями, що додаються.

2. Скасувати наказ Держмитслужби України від 15.07.97 N 324 ( v0324342-97 ) "Про затвердження Інструкції про порядок і процедуру відбору зразків (проб) нафтопродуктів в митній системі України".

3. Митним органам з метою здійснення митного контролю та митного оформлення товару відбирати проби й зразки товарів для проведення лабораторних досліджень (аналізу, експертизи) у кількостях, визначених Нормативами відбору проб і зразків товарів для проведення досліджень (аналізу, експертизи) митними лабораторіями, затвердженими цим наказом.

4. Центральній митній лабораторії (Венгель П.Ф.) і Управлінню правової роботи (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

5. Установити, що цей наказ застосовується з дня набрання чинності Митним кодексом України ( 92-15 ).

6. Секретаріату забезпечити тиражування та розсилку цього наказу регіональним митницям, митницям після його державної реєстрації.

7. Контроль за виконанням цього наказу покласти на заступника Голови Служби Дьоміна Ю.М.
