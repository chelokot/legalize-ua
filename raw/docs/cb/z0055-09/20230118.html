Зареєстровано в Міністерстві юстиції України 22 січня 2009 р. за N 55/16071

Про внесення змін до деяких наказів Державної митної служби України

{ Із змінами, внесеними згідно з Наказом Державної митної служби N 409 ( z0705-11 ) від 23.05.2011 Наказами Міністерства фінансів N 610 ( z0955-12 ) від 28.05.2012 N 6 ( z0046-23 ) від 04.01.2023 }

З метою приведення нормативно-правових актів Державної митної служби України у відповідність до законодавства та відповідно до статті 71 Митного кодексу України ( 92-15 ), постанови Кабінету Міністрів України від 18.01.2003 N 93 ( 93-2003-п ) "Про справляння плати за митне оформлення товарів і транспортних засобів поза місцем розташування митних органів або поза робочим часом, установленим для митних органів" НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства фінансів N 610 ( z0955-12 ) від 28.05.2012 }

{ Пункт 2 втратив чинність на підставі Наказу Міністерства фінансів N 6 ( z0046-23 ) від 04.01.2023 }

{ Пункт 3 втратив чинність на підставі Наказу Державної митної служби N 409 ( z0705-11 ) від 23.05.2011 }

4. Визнати таким, що втратив чинність, наказ Державної митної служби України від 23.06.98 N 363 ( z0443-98 ) "Про затвердження Порядку справляння митних зборів, які нараховуються за вантажною митною декларацією", зареєстрований в Міністерстві юстиції України 14.07.98 за N 443/2883.

5. Департаменту митних платежів (Джигалов С.О.) і Юридичному департаменту (Бабюк В.Л.) Державної митної служби України в установленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

6. Начальникам митних органів довести цей наказ до відома юридичних і фізичних осіб.

7. Установити, що цей наказ набирає чинності через 10 днів після його офіційного опублікування.

8. Контроль за виконанням цього наказу покласти на першого заступника Голови Служби Гутника А.Є.

Голова Державної митної служби України В.І.Хорошковський
