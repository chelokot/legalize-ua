Про граничний розмір роздрібних цін на газ природний

( Із змінами, внесеними згідно з Наказом Мінекономіки N 71 ( z0264-97 ) від 26.06.97 )

Згідно з повноваженнями, затвердженими постановою Кабінету Міністрів України від 25.12.96 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", та відповідно до Програми дій Уряду України на 1997 рік, схваленої Верховною Радою України, з метою повного відшкодування витрат, пов'язаних з реалізацією природного газу населенню НАКАЗУЮ:

1. Затвердити граничні розміри роздрібних цін на газ природний, що споживається населенням на комунально-побутові потреби (додаються).

2. Вважати такими, що втратили чинність, граничні розміри роздрібних цін на газ природний, затверджені наказом Мінекономіки від 05.09.96 р. N 118 ( z0522-96 ).

Міністр Ю.І.Єхануров

( Граничні розміри роздрібних цін на газ природний втратили чинність на підставі Наказу Мінекономіки N 71 ( z0264-97 ) від 26.06.97 )
