УКАЗ ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

{ Указ не застосовується на території України згідно із Законом N 2215-IX ( 2215-20 ) від 21.04.2022 }

Про перетворення Державного комітету Ради Міністрів Української РСР по використанню трудових ресурсів у союзно-республіканський Державний комітет Ради Міністрів Української РСР по праці

( Відомості Верховної Ради (ВВР), 1976, N 43, ст. 391 )

{ Указ затверджено Законом УРСР N 1486-IX ( 1486-09 ) від 19.11.76, ВВР, 1976, N 48, ст. 448 }

Президія Верховної Ради Української РСР постановляє:

Перетворити Державний комітет Ради Міністрів Української РСР по використанню трудових ресурсів у союзно-республіканський Державний комітет Ради Міністрів Української РСР по праці.
