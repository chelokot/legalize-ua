Нормативні вимоги
до приміщень територіальних і дільничних виборчих комісій з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів і приміщень для голосування

1. Приміщення, що надаються територіальним виборчим комісіям для забезпечення їх роботи, повинні мати не менше 3 робочих кімнат, дві з яких площею не менше 20 кв.м кожна, а третя (приміщення для засідань комісії) - не менше 80 кв.м.

Приміщення територіальної виборчої комісії повинно бути обладнано не менш як чотирма встановленими телефонними лініями.

2. Приміщення, що надаються дільничним виборчим комісіям для забезпечення їх роботи, повинні мати не менше двох робочих кімнат, одна з яких площею не менше 20 кв.м, друга (приміщення для засідань комісії) - не менше 50 кв.м. Приміщення комісії повинні бути обладнані не менш як однією встановленою телефонною лінією.

На одній виборчій дільниці облаштовується лише одне приміщення для голосування, як правило, на першому поверсі будівлі. Приміщення для голосування для малої виборчої дільниці повинно мати площу не менше 50 кв.м, середньої - не менше 75 кв.м, великої - не менше 90 кв.м.

У разі відсутності в межах виборчої дільниці приміщення з відповідною площею за погодженням з територіальною виборчою комісією, яка утворює виборчу дільницю, приміщення для голосування на виборчій дільниці може надаватися меншого розміру, але не більше ніж на 50 відсотків.

Голосування проводиться у спеціально відведеному приміщенні, в якому обладнуються у достатній кількості кабіни для таємного голосування та визначаються місця видачі виборчих бюлетенів.

Для малих виборчих дільниць кількість таких кабін повинна бути не менше двох, для середніх - не менше чотирьох, для великих - не менше шести. Стаціонарні виборчі скриньки для голосування встановлюються так, щоб виборці при підході до них мали можливість проходити через кабіни для таємного голосування.

Приміщення для голосування повинно забезпечувати можливість його обладнання таким чином, щоб місця видачі виборчих бюлетенів, кабіни для таємного голосування, виборчі скриньки для голосування знаходилися у полі зору членів дільничної виборчої комісії та осіб, які відповідно до Закону мають право бути присутніми у приміщенні для голосування.

Приміщення для голосування облаштовуються з урахуванням потреб для громадян з обмеженими фізичними можливостями, зокрема, пандусом з безперешкодним входом і виходом з приміщення та однією кабіною для голосування з шириною входу 110 см, у виняткових випадках - не менше 85 см, усередині якої встановлюється столик або поличка висотою не більше 75 см із простором знизу не менше 67 см для інвалідного візка громадянина з обмеженими фізичними можливостями тощо.

У приміщенні для голосування або безпосередньо перед ним дільнична виборча комісія розміщує плакати, що роз’яснюють порядок голосування та відповідальність за порушення законодавства про вибори.

Приміщення, якими забезпечується дільнична виборча комісія, та приміщення для голосування, як правило, повинні бути розташовані в одній будівлі.

На будинку, де розташовано таке приміщення, встановлюється Державний Прапор України та вивіска відповідної виборчої комісії.

Приміщення дільничної виборчої комісії спеціальної виборчої дільниці та приміщення для голосування на цій дільниці повинні мати відкритий доступ для осіб, які відповідно до Закону України "Про вибори депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів" мають право бути присутніми на засіданнях дільничної виборчої комісії та під час голосування і підрахунку голосів виборців.

3. Приміщення територіальних та дільничних виборчих комісій повинні відповідати встановленим вимогам щодо санітарних і технічних норм, а також бути забезпеченими телефонним зв’язком та електропостачанням, засобами протипожежної безпеки.

4. Контроль за облаштуванням приміщення для голосування покладається на відповідні територіальні та дільничні виборчі комісії.

Для територіальної виборчої комісії:

1) послуги із транспортного обслуговування;

2) послуги фіксованого телефонного зв'язку (місцевого, міжміського, факсимільного, абонентна плата);

3) оренда та утримання приміщень;

4) послуги місцевих державних архівних установ;

5) залучення відповідних спеціалістів, технічних працівників.

Для дільничної виборчої комісії:

1) послуги із транспортного обслуговування;

2) послуги фіксованого телефонного зв'язку (місцевого, міжміського, абонентна плата);

3) оренда та утримання приміщень.
