ПОСТАНОВА від 21 січня 2004 р. N 64 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 26 ( 26-2010-п ) від 13.01.2010 }

Про затвердження нового складу наглядових рад Національної кіностудії художніх фільмів імені Олександра Довженка та Національної кінематеки України

Кабінет Міністрів України постановляє:

На часткову зміну постанови Кабінету Міністрів України від 2 серпня 1996 р. N 913 ( 913-96-п ) затвердити новий склад наглядових рад Національної кіностудії художніх фільмів імені Олександра Довженка та Національної кінематеки України, що додаються.
