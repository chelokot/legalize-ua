Кабінет Міністрів України; Постанова від 14.01.2009 № 35

Питання розрахунків за паливо для потреб енергогенеруючих компаній

Стан: Втратив чинність

Ідентифікатор: 35-2009-п

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 січня 2009 р. N 35 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Питання розрахунків за паливо для потреб енергогенеруючих компаній

{ Із змінами, внесеними згідно з Постановою КМ N 205 ( 205-2010-п ) від 24.02.2010 }

{ У назві та тесті Постанови слова "мазут і вугілля" замінено словом "паливо" згідно з Постановою КМ N 205 ( 205-2010-п ) від 24.02.2010 }

Кабінет Міністрів України постановляє:

1. Установити, що у 2010 році закупівля послуги з надання кредиту уповноваженим банком - відкритим акціонерним товариством "Державний ощадний банк України" у розмірі до 650 млн. гривень для проведення розрахунків енергогенеруючими компаніями, пакети акцій яких, що належать державі, передані до статутного фонду Національної акціонерної компанії "Енергетична компанія України", а також компаніями, що безпосередньо належать до сфери управління Міністерства палива та енергетики та використовують паливо для виробництва електричної енергії, здійснюється державним підприємством "Енергоринок" без погодження з Міністерством економіки застосування процедури закупівлі в одного учасника.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 205 ( 205-2010-п ) від 24.02.2010 }

2. Взяти до відома, що кошти, які надійдуть відповідно до пункту 1 цієї постанови, використовуються виключно для проведення розрахунків за паливо.

3. Рекомендувати Національній комісії регулювання електроенергетики встановити алгоритм розподілу коштів, що надходитимуть з поточного рахунка із спеціальним режимом використання державного підприємства "Енергоринок" за електричну енергію, що закуповується, з урахуванням необхідності погашення кредиту, отриманого відповідно до пункту 1 цієї постанови, та сплати за ним відсотків.
