Про Порядок реєстрації (обліку) зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою

( Із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 72 ( z0273-04 ) від 26.02.2004 )

Відповідно до Указу Президента України від 07.11.1994 N 659/94 ( 659/94 ) "Про облік окремих видів зовнішньоекономічних договорів (контрактів)", зі змінами і доповненнями, постанови Кабінету Міністрів України від 16.09.2003 N 1457 ( 1457-2003-п ) "Про затвердження Порядку реєстрації зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою" та з метою здійснення реєстрації (обліку) зовнішньоекономічних контрактів (договорів) на експорт нафти НАКАЗУЮ:

1. Затвердити Порядок реєстрації (обліку) зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою за кодом згідно з УКТЗЕД 2709009000 ( 2371а-14 ), що додається. ( Пункт 1 із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 72 ( z0273-04 ) від 26.02.2004 )

2. Покласти функції щодо здійснення реєстрації (обліку) зовнішньоекономічних контрактів (договорів) та видачі карток реєстрації-обліку на здійснення експортних операцій з нафтою на управління нетарифного регулювання.

3. Управлінню нетарифного регулювання разом з юридичним департаментом забезпечити реєстрацію цього наказу в Міністерстві юстиції України в установлений законодавством термін.

4. Контроль за виконанням цього наказу покласти на першого заступника Міністра економіки та з питань європейської інтеграції України Пятницького В.Т.

Виконуючий обов'язки Міністра економіки та з питань європейської інтеграції України В.Вощевський

ЗАТВЕРДЖЕНО Наказ Міністерства економіки та з питань європейської інтеграції України 29.09.2003 N 263

Зареєстровано в Міністерстві юстиції України 2 жовтня 2003 р. за N 887/8208

ПОРЯДОК реєстрації (обліку) зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою

( У назві та тексті Порядку слова "та нафтопродукти" у всіх відмінках виключено згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 72 ( z0273-04 ) від 26.02.2004 )

1. Цей Порядок визначає єдиний механізм реєстрації (обліку) зовнішньоекономічних договорів (контрактів) та видачі карток реєстрації-обліку зовнішньоекономічних договорів (контрактів) на здійснення експортних операцій з нафтою за кодом згідно з УКТЗЕД 2709009000 ( 2371а-14 ) (далі - картки реєстрації-обліку). ( Пункт 1 із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 72 ( z0273-04 ) від 26.02.2004 )

2. Картки реєстрації-обліку видаються згідно з постановою Кабінету Міністрів України від 16.09.2003 N 1457 ( 1457-2003-п ) "Про затвердження Порядку реєстрації зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою" за кодом згідно з УКТЗЕД 2709009000 ( 2371а-14 ) та цим Порядком. ( Пункт 2 із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 72 ( z0273-04 ) від 26.02.2004 )

3. Для реєстрації (обліку) зовнішньоекономічних договорів (контрактів) (далі - контракти) подаються такі документи:

супровідний лист;

інформаційна картка контракту за формою, встановленою Міністерством економіки та з питань європейської інтеграції України (далі - Міністерство);

оригінал контракту з усіма чинними на дату подання додатками, специфікаціями, додатковими угодами та іншими документами, які є частинами контракту, та його копія, завірена керівником суб'єкта зовнішньоекономічної діяльності України;

копія свідоцтва про державну реєстрацію суб'єкта підприємницької діяльності, завірена керівником;

копія витягу з торговельного, банківського чи судового реєстру або реєстраційного посвідчення, виданого компетентним органом іноземної держави, про реєстрацію іноземного суб'єкта господарської діяльності, завірена керівником суб'єкта зовнішньоекономічної діяльності України;

документ про оплату послуг за реєстрацію контракту;

лист-погодження контракту Міністерства палива та енергетики України.

4. Відповідальність за достовірність інформації, наведеної в документах, поданих для реєстрації, несе суб'єкт зовнішньоекономічної діяльності України.

5. Документи на реєстрацію контрактів подаються до Міністерства в установлений час згідно з графіком і приймаються у спеціально визначеному приміщенні Міністерства.

6. Датою подання документів на реєстрацію контрактів уважається день реєстрації заяви (супровідного листа) в Міністерстві, що підтверджується відповідним записом у журналі реєстрації.

7. Розгляд документів та реєстрація контракту здійснюється згідно з цим Порядком та в межах компетенції управлінням нетарифного регулювання, управлінням контролю за зовнішньоекономічною діяльністю, управлінням правового забезпечення зовнішньоекономічної політики та Державним інформаційно-аналітичним центром моніторингу зовнішніх товарних ринків "Держзовнішінформ" (далі - Держзовнішінформ).

8. Управління нетарифного регулювання забезпечує:

приймання та реєстрацію документів;

розгляд документів на предмет відповідності даних контракту даним інформаційної картки контракту та додержання встановлених вимог до порядку заповнення інформаційної картки контракту;

підготовку проекту картки реєстрації-обліку та листа для експертних висновків відповідних підрозділів;

подання документів на розгляд відповідних підрозділів;

узагальнення експертних висновків;

оформлення та видачу карток реєстрації-обліку або листів з відмовою в реєстрації контрактів.

Строк опрацювання документів в управлінні нетарифного регулювання становить не більше 4 годин після їх прийняття.

9. Управління контролю за зовнішньоекономічною діяльністю розглядає документи на предмет:

відповідності платіжних умов чинному законодавству України у сфері зовнішньоекономічної діяльності;

відповідності даних контракту з питань платежів даним інформаційної картки контракту;

застосування спеціальних санкцій, передбачених статтею 37 Закону України "Про зовнішньоекономічну діяльність" ( 959-12 ), до сторін контракту, поданого для реєстрації.

10. Управління правового забезпечення зовнішньоекономічної політики розглядає документи на предмет визначення характеру угоди згідно з інформаційною карткою контракту, а також на предмет відповідності умов контракту чинному законодавству України та міжнародним договорам України.

11. Держзовнішінформ розглядає документи на предмет відповідності контрактних цін кон'юнктурі ринку залежно від умов здійснення контракту.

12. Строк розгляду документів у кожному підрозділі згідно з пунктами 9, 10, 11 цього Порядку становить не більше 2 годин після надходження документів.

13. Відмова в реєстрації контракту допускається в разі:

подання не всіх документів, передбачених пунктом 3 цього Порядку;

невідповідності умов контракту законодавству України у сфері зовнішньоекономічної діяльності;

застосування до суб'єкта зовнішньоекономічної діяльності України або до його іноземного контрагента спеціальних санкцій, передбачених статтею 37 Закону України "Про зовнішньоекономічну діяльність" ( 959-12 ), що діють на момент звернення суб'єкта зовнішньоекономічної діяльності України про реєстрацію контракту;

порушення суб'єктом зовнішньоекономічної діяльності України або його іноземним контрагентом законодавства у сфері зовнішньоекономічної діяльності.

14. За результатами експертних висновків у разі відсутності підстав для відмови в реєстрації контрактів управління нетарифного регулювання оформлює та видає картку реєстрації-обліку протягом трьох робочих днів після подання документів суб'єктом зовнішньоекономічної діяльності України.

15. У разі виявлення під час розгляду документів підстав для відмови в реєстрації контракту заявнику надсилається лист з обгрунтуванням мотивів відмови в реєстрації контракту протягом трьох робочих днів після прийняття рішення про відмову.

16. Заявник має право доопрацювати документи згідно з вимогами Порядку реєстрації зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою за кодом згідно з УКТЗЕД 2709009000 ( 2371а-14 ), затвердженого постановою Кабінету Міністрів України від 16.09.2003 N 1457 ( 1457-2003-п ). У цьому разі строк розгляду документів продовжується до внесення заявником доопрацьованих документів. ( Пункт 16 із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 72 ( z0273-04 ) від 26.02.2004 )

17. Підтвердженням реєстрації контракту є картка реєстрації-обліку за формою, встановленою Міністерством.

18. Оригінал контракту повертається суб'єкту зовнішньоекономічної діяльності України разом з карткою реєстрації-обліку або з листом про відмову в реєстрації контракту.

19. Картки реєстрації-обліку або листи з відмовою в реєстрації мають право підписувати перший заступник Міністра, заступник Міністра, яким безпосередньо підпорядкований департамент державної політики у сфері зовнішньої торгівлі, торговельних обмежень та контролю за зовнішньоекономічною діяльністю, директор департаменту державної політики у сфері зовнішньої торгівлі, торговельних обмежень та контролю за зовнішньоекономічною діяльністю та його заступник, начальник управління нетарифного регулювання та його заступник.

20. Картки реєстрації-обліку видаються заявникові у двох примірниках (один для митного органу, другий для заявника) разом з оригіналом контракту при пред'явленні документа, що засвідчує особу, та доручення на їх отримання.

21. У разі перереєстрації контракту заявником подаються документи згідно з пунктом 3 цього Порядку, а також один примірник оригіналу картки реєстрації-обліку з відмітками митних органів про фактичне відвантаження продукції і зобов'язанням про призупинення відвантаження продукції на час перереєстрації контракту.

22. Картка реєстрації-обліку дійсна для митного оформлення експортної продукції протягом 12 місяців з дати її оформлення.

За бажанням суб'єкта зовнішньоекономічної діяльності строк дії картки реєстрації-обліку може бути скорочено, про що в ній робиться відповідний запис.

23. Картка реєстрації-обліку контракту втрачає чинність для митного оформлення експортної продукції в разі:

закінчення строку дії картки реєстрації-обліку;

закінчення строку дії контракту;

перетину митного кордону експортної продукції в повному обсязі згідно з умовами контракту.

24. У разі втрати картки реєстрації-обліку вона не поновлюється.

Переоформлення картки реєстрації-обліку проводиться в порядку, встановленому для її видачі.

25. Заявник має право оскаржити відмову в реєстрації контракту в порядку, встановленому законодавством України.

26. Картки реєстрації-обліку та копії документів, поданих для реєстрації, зберігаються в управлінні нетарифного регулювання.

Заступник директора департаменту державної політики у сфері зовнішньої торгівлі, торговельних обмежень та контролю за зовнішньоекономічною діяльністю - начальник управління нетарифного регулювання В.Богданов
