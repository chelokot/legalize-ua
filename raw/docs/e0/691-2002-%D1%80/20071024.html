{ Розпорядження втратило чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Міжвідомчої комісії з реалізації реформи житлово-комунального господарства

Затвердити головою Міжвідомчої комісії з реалізації реформи житлово-комунального господарства, утвореної постановою Кабінету Міністрів України від 1 грудня 1999 р. N 2194 ( 2194-99-п ) (Офіційний вісник України, 1999 р., N 48, ст. 2374), Віце-прем'єр-міністра України Гайдука Віталія Анатолійовича, увільнивши від цих обов'язків Дубину Олега Вікторовича.
