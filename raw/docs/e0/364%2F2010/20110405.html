УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Адміністрації Президента України

{ Із змінами, внесеними згідно з Указом Президента N 347/2011 ( 347/2011 ) від 02.04.2011 }

Відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

{ Стаття 1 втратила чинність на підставі Указу Президента N 352/2011 ( 352/2011 ) від 05.04.2011 }

{ Стаття 2 втратила чинність на підставі Указу Президента N 352/2011 ( 352/2011 ) від 05.04.2011 }

{ Стаття 3 втратила чинність на підставі Указу Президента N 352/2011 ( 352/2011 ) від 05.04.2011 }

4. Установити, що штатний розпис Адміністрації Президента України в межах граничної чисельності працівників Адміністрації Президента України затверджується в установленому порядку Главою Адміністрації Президента України.

5. Кабінету Міністрів України:

визначити умови оплати праці працівників Адміністрації Президента України;

вирішити в установленому порядку питання віднесення відповідних посад працівників Адміністрації Президента України до категорій посад державних службовців.

6. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 18 березня 2010 року N 364/2010
