Кабінет Міністрів України; Розпорядження від 24.05.1999 № 464-р

Про надання в оренду приміщень Національному агентству з управління державними корпоративними правами

Стан: Втратив чинність

Ідентифікатор: 464-99-р

Текст документа від 28.01.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 травня 1999 р. N 464-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 57-р ( 57-2000-р ) від 28.01.2000 )

Держінвесту надати в оренду Національному агентству з управління державними корпоративними правами приміщення, розташовані в будинку по вул. Артема, 73, згідно з постановою Кабінету Міністрів України від 26 квітня 1999 р. N 698 ( 698-99-п ) за рахунок зменшення площі приміщень, закріплених за Укрбудматеріалами.
