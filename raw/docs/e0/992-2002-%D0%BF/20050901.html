Кабінет Міністрів України; Постанова від 11.07.2002 № 992

Про умови оплати праці працівників вищих навчальних закладів, що мають статус національних

Стан: Втратив чинність

Ідентифікатор: 992-2002-п

Текст документа від 01.09.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 липня 2002 р. N 992 Київ

( Постанова втратила чинність на підставі Постанови КМ N 790 ( 790-2005-п ) від 22.08.2005 )

Про умови оплати праці працівників вищих навчальних закладів, що мають статус національних

( Із змінами, внесеними згідно з Постановами КМ N 199 ( 199-2004-п ) від 23.02.2004 N 542 ( 542-2004-п ) від 29.04.2004 )

З метою упорядкування оплати праці працівників вищих навчальних закладів, що мають статус національних, Кабінет Міністрів України постановляє:

1. Надати право керівникам вищих навчальних закладів, що мають статус національних, підвищувати порівняно з розмірами посадових окладів (ставок заробітної плати) відповідних категорій працівників вищих навчальних закладів та ставок погодинної оплати праці, затвердженими постановою Кабінету Міністрів України від 7 лютого 2001 р. N 134 ( 134-2001-п ) "Про впорядкування умов оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" (Офіційний вісник України, 2001 р., N 7, ст. 278), з урахуванням їх підвищення відповідно до постанови Кабінету Міністрів України від 14 серпня 2001 р. N 1045 ( 1045-2001-п ) "Про підвищення посадових окладів (ставок заробітної плати) та погодинної оплати праці працівників установ і закладів освіти" (Офіційний вісник України, 2001 р., N 33, ст. 1547):

посадові оклади науково-педагогічних і наукових працівників - до 100 відсотків;

ставки погодинної оплати праці - до 100 відсотків.

Надати право начальникам Національної академії оборони України і Військового інституту Київського національного університету імені Тараса Шевченка підвищувати до 100 відсотків посадові оклади, науково-педагогічним та науковим працівникам Академії та Інституту з числа військовослужбовців. ( Пункт 1 доповнено абзацом четвертим згідно з Постановою КМ N 199 ( 199-2004-п ) від 23.02.2004, із змінами, внесеними згідно з Постановою КМ N 542 ( 542-2004-п ) від 29.04.2004 )

Зазначене підвищення проводити в межах фондів оплати праці, затверджених кошторисами цих закладів, не допускаючи при цьому заборгованості з виплати заробітної плати.

2. Установити, що посадові оклади (ставки заробітної плати) працівників Київського національного університету імені Тараса Шевченка встановлюються у межах фонду оплати праці, затвердженого кошторисом, на умовах, визначених Указом Президента України від 25 листопада 1999 р. N 1496 ( 1496/99 ) "Про Київський національний університет імені Тараса Шевченка".

3. Тимчасово припинити дію пункту 2 постанови Кабінету Міністрів України від 1 березня 2001 р. N 202 ( 202-2001-п ) "Про Національний аграрний університет" (Офіційний вісник України, 2001 р., N 10, ст. 408) у частині підвищення у два рази оплати праці працівників Університету (включаючи погодинну).
