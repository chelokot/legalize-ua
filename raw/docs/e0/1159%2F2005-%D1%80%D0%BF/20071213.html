Президент України; Розпорядження від 12.09.2005 № 1159/2005-рп

Про делегацію України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї 1948 року

Стан: Втратив чинність

Ідентифікатор: 1159/2005-рп

Текст документа від 13.12.2007:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність крім пункту 1 в частині, що стосується рішення про утворення делегації України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї 1948 року ( 995_175 ), на підставі Указу Президент України N 1218/2007 ( 1218/2007 ) від 13.12.2007 }

Про делегацію України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї 1948 року

1. Утворити делегацію України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї ( 995_175 ) 1948 року в такому складі:

МУШКА - Надзвичайний і Повноважний Посол України Юрій Юрійович в Угорській Республіці, Представник України в Дунайській Комісії, глава делегації

ГОРОБЕЦЬ - директор Державного департаменту

Ігор Анатолійович морського і річкового транспорту, заступник глави делегації

БЕШТА - головний консультант Головної служби

Петро Петрович зовнішньої політики Секретаріату Президента України, член делегації

БЄЛОВ - помічник президента із

Ігор Робертович зовнішньоекономічних зв'язків Акціонерної судноплавної компанії "Укррічфлот" (за згодою), експерт делегації

БІЛЛЯР - перший секретар Договірно-правового

Костянтин Леонідович департаменту Міністерства закордонних справ України, член делегації

ЗИРЯНОВ - старший лоцман Ізмаїльської філії

В'ячеслав Олексійович державного підприємства "Дельта-лоцман" (за згодою), експерт делегації

РАЮ - заступник директора департаменту

Валерій Миколайович річкових, пасажирських та транзитних перевезень відкритого акціонерного товариства "Українське Дунайське пароплавство" (за згодою), експерт делегації.

Дозволити главі делегації Ю. Мушці за погодженням з Міністерством закордонних справ України вносити зміни до персонального складу делегації України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї ( 995_175 ) 1948 року та в разі потреби залучати експертів до участі в роботі делегації.

2. Міністрові закордонних справ України затверджувати вказівки делегації України на всі заходи, пов'язані з діяльністю Підготовчого комітету Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї ( 995_175 ) 1948 року.

3. Кабінету Міністрів України вирішити питання стосовно виділення коштів в іноземній валюті для забезпечення участі І. Горобця та П. Бешти у роботі Підготовчого комітету Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї ( 995_175 ) 1948 року.

Президент України В.ЮЩЕНКО

м. Київ, 12 вересня 2005 року N 1159/2005-рп
