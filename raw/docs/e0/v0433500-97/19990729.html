Про внесення змін і доповнень до Положення "Про порядок формування банківською системою України обов'язкових резервів"

Ідентифікатор: v0433500-97

Текст документа від 29.07.1999:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 76 від 31.03.97 Зареєстровано в юридичному м.Київ департаменті Нацбанку 4 квітня 1997 р. за N 433

Про внесення змін і доповнень до Положення "Про порядок формування банківською системою України обов'язкових резервів"

( Із змінами, внесеними згідно з Постановами Нацбанку N 64 ( v0525500-98 ) від 24.02.98 N 286 ( v0558500-98 ) від 23.07.98 N 332 ( z0511-99 ) від 09.07.99 )

Заслухавши інформацію директора емісійно-кредитного департаменту (Н.І.Гребеник) про необхідність внесення змін і доповнень до Положення "Про порядок формування банківською системою України обов'язкових резервів" у зв'язку з введенням його в дію з 01.04.97 р., Правління ПОСТАНОВЛЯЄ:

( Пункт 1 втратив чинність на підставі Постанови Нацбанку N 332 ( z0511-99 ) від 09.07.99 ) 1. Внести зміни і доповнення до Положення "Про порядок формування банківською системою України обов'язкових резервів" ( v0410500-96 ), затвердженого постановою Правління Національного банку України від 26.12.96 р. N 333.

( Пункт 1.1 втратив чинність на підставі Постанови Нацбанку N 286 ( v0558500-98 ) від 23.07.98 ) 1.1. У пункті 11 в абзаці 7 замість слів "декада (10 днів)" слід записати слова "15 днів".

( Пункт 1.2 втратив чинність на підставі Постанови Нацбанку N 286 ( v0558500-98 ) від 23.07.98 ) 1.2. Пункт 12 викласти в такій редакції: "Обсяг обов'язкових резервів визначається комерційним банком кожні 15 днів (1-15 числа кожного місяця) у розмірі встановленого відсотка від середньоарифметичних залишків залучених банком коштів".

1.3. Пункт 10 доповнити текстом такого змісту: "Комерційні банки мають розмістити суму обов'язкових мінімальних резервів у розмірі 11% від залучених коштів фізичних осіб у державні цінні папери та передати їх на зберігання Національному банку України".

1.4. До пункту 10 затвердити додаток N 3 "Порядок блокування, заміни та погашення державних цінних паперів, які зберігаються у Національному банку України".

( Пункт 1.5 втратив чинність на підставі Постанови Нацбанку N 64 ( v0525500-98 ) від 24.02.98 ) 1.5. З пункту 10 вилучити балансові рахунки N 794 "Кредити у валюті України, отримані від банків-нерезидентів" та N 078 "Кредитори за акредитивами з іноземних операцій".

( Пункт 1.6 втратив чинність на підставі Постанови Нацбанку N 64 ( v0525500-98 ) від 24.02.98 ) 1.6. Пункт 10 доповнити балансовими рахунками:

N 320 "Невиплачені перекази із-за кордону у вільно конвертованій валюті резидентів",

N 225 "Рахунки фізичних осіб-резидентів у вільно конвертованій валюті за операціями з використанням дебетних банківських пластикових карток",

N 227 "Депоновані кошти фізичних осіб-резидентів у вільно конвертованій валюті для розрахунків з використанням банківських платіжних карток строком від 6 місяців до 1 року",

N 228 "Депоновані кошти юридичних осіб-резидентів у вільно конвертованій валюті для розрахунків з використанням банківських платіжних карток строком від 6 місяців до 1 року".

1.7. Пункт 15 доповнити словами "і виписку з депо-рахунка N 9835 про фактичну кількість заблокованих державних цінних паперів".

2. Відповідно до пункту 1.4 цієї постанови призупинити дію "Тимчасового порядку формування комерційними банками фонду страхування вкладів фізичних осіб", затвердженого постановою Правління Національного банку України від 28.05.96 р. N 125 ( v0125500-96 ).

3. З введенням у дію Положення "Про порядок формування банківською системою України обов'язкових резервів" визнати такими, що втратили чинність, вказівки Національного банку України від 06.07.95 р. N 26013/743-3265 ( v3265500-95 ) та від 22.06.95 р. N 26013/639-2982 ( v2982500-95 ).

4. Контроль за виконанням цієї постанови покласти на Першого заступника Голови Правління В.С.Стельмаха.

Додаток N 3

Порядок блокування, заміни та погашення державних цінних паперів, які зберігаються у Національному банку України

1. З метою використання коштів обов'язкового резервування, залучених від фізичних осіб як гарантії щодо їх вкладів, комерційні банки з 01.04.97 р. вкладають суму коштів, яка визначена у розмірі 11% від суми вкладів фізичних осіб, у державні цінні папери і передають їх на зберігання Національному банку України.

Сума переданих на зберігання державних цінних паперів за номінальною вартістю має дорівнювати 11% залучених коштів від фізичних осіб.

2. Передання комерційними банками державних цінних паперів на зберігання Національному банку України у розмірі 11% від суми залучених коштів від фізичних осіб здійснюється на підставі двостороннього договору між Національним банком України та комерційним банком і депо-розпорядження. Строк дії договору визначається сторонами відповідно до строку випуску державних цінних паперів. Для передання державних цінних паперів подальших випусків на зберігання Національному банку України укладається додаткова угода.

3. Державні цінні папери, що придбані комерційними банками під забезпечення вкладів фізичних осіб, обліковуються:

- у кількісному вираженні - окремо за кодами випусків державних цінних паперів на рахунку депозитарного обліку N 9835 "Облігації державних позик, що знаходяться у власності комерційного банку та заблоковані для створення резерву для компенсації вкладів фізичних осіб";

- за цінами придбання - на балансовому рахунку N 194 "Вкладення в державні боргові зобов'язання";

- за номінальною вартістю - на позабалансовому рахунку N 9960 "Різні цінності і документи".

4. Зарахування державних цінних паперів на рахунок N 9835 здійснюється депозитарієм Національного банку України на підставі депо-розпорядження комерційного банку.

5. Контроль за своєчасним формуванням обов'язкових резервів, розміщених у державні цінні папери під забезпечення вкладів фізичних осіб, здійснюється регіональними управліннями Національного банку України на підставі:

- щоденного бухгалтерського балансу комерційного банку;

- виписок з рахунка депозитарного обліку N 9835, які надаються депозитарієм Національного банку України засобами телекомунікаційного зв'язку;

- повідомлень про проведення аукціонів з розміщення державних цінних паперів, які містять дані про номінальну вартість цих цінних паперів.

6. У разі коливання залишків коштів фізичних осіб комерційний банк здійснює коригування кількості державних цінних паперів, переданих на зберігання Національному банку України.

7. Оплата доходів комерційним банкам за державними цінними паперами, переданими на зберігання Національному банку України, та їх погашення здійснюються у встановленому порядку згідно з Положенням "Про порядок бухгалтерського та депозитарного обліку, розміщення, обігу, сплати відсотків і погашення облігацій внутрішньої державної позики в банківських установах", затвердженим постановою Правління Національного банку України від 26.01.96 р. N 15 ( v0347500-96 ) (із змінами та доповненнями).

8. Комерційні банки зобов'язані забезпечити своєчасну заміну та передання Національному банку України на зберігання державних цінних паперів подальших випусків для відновлення погашених державних цінних паперів попереднього випуску не пізніше наступного дня від настання строку погашення у розмірі для забезпечення 11% резервування залишків коштів фізичних осіб.

9. Регіональні управління Національного банку України кожного 1 і 16 числа місяця здійснюють контроль за своєчасністю та повнотою передання на зберігання Національному банку України державних цінних паперів на підставі даних балансу комерційного банку і виписок з рахунка депозитарного обліку.

10. У разі зменшення суми вкладів фізичних осіб у комерційних банках на підставі листів регіональних управлінь державні цінні папери, що знаходяться на рахунку депозитарного обліку N 9835, розблоковуються депозитарієм Національного банку України з наступним зарахуванням на рахунок депозитарного обліку N 9831 "Облігації державних позик, що знаходяться у власності комерційних банків".

11. У разі відмови комерційного банку від придбання державних цінних паперів для цілей резервування та передання їх на зберігання до депозитарію Національного банку України комерційний банк повинен визначену суму обов'язкових резервів щодо залучених коштів фізичних осіб тримати на кореспондентському рахунку.

12. У разі ліквідації комерційного банку кошти, що надходять від сплати доходу та погашення державних цінних паперів, зараховуються на рахунок N 154904101 "Кошти від погашення державних цінних паперів, що знаходились у інвесторів на непризначених для погашення блокувальних рахунках" у Національному банку України. Подальше перерахування цих коштів здійснюється за рішенням ліквідаційної комісії.
