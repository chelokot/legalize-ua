УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про новий склад Комісії державних нагород та геральдики

На зміну частини другої статті 3 Указу Президента України від 11 квітня 2000 року N 583 ( 583/2000 ) "Про Комісію державних нагород та геральдики" (зі змінами, внесеними Указами від 23 травня 2000 року N 706 ( 706/2000 ), від 14 липня 2000 року N 897 ( 897/2000 ), від 26 червня 2002 року N 585 ( 585/2002 ), від 29 серпня 2002 року N 782 ( 782/2002 ) затвердити новий персональний склад Комісії державних нагород та геральдики (додається).
