Про розміри посадових окладів працівників закладів Лікувально-оздоровчого об'єднання при Кабінеті Міністрів України

НАКАЗ

N 78 від 07.10.96 Зареєстровано в Міністерстві м.Київ юстиції України 15 жовтня 1996 р. vd961007 vn78 за N 601/1626

( Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики

N 240 ( z1275-04 ) від 28.09.2004 )

Про розміри посадових окладів працівників закладів Лікувально-оздоровчого об'єднання при Кабінеті Міністрів України

Відповідно до постанови Кабінету Міністрів України від 29.05.96 N 565 ( 565-96-п ) "Про упорядкування умов оплати праці працівників окремих галузей бюджетної сфери", постанови Кабінету Міністрів України від 26.07.96 N 834 ( 834-96-п ) "Про підвищення заробітної плати працівників бюджетних установ і організацій" та Указу Президента від 28.05.96 N 762 ( 762/96 ) "Про грошову реформу в Україні" НАКАЗУЮ:

1. Затвердити розміри посадових окладів керівникам закладів Лікувально-оздоровчого об'єднання при Кабінеті Міністрів України:

- Республіканської клінічної лікарні та поліклінік об'єднання - 191 грн.;

- станції швидкої медичної допомоги, санепідемстанції, санаторію - 187 грн.;

- будинку відпочинку - 187 грн.

2. Із запровадженням посадових окладів, зазначених в п.1 даного наказу, за працівниками закладів Лікувально-оздоровчого об'єднання при Кабінеті Міністрів України зберігаються умови оплати праці, визначені для працівників закладів охорони здоров'я.

3. Вважати таким, що втратив чинність наказ Міністерства праці України від 26.06.93 N 44 ( z0083-93 ) "Про встановлення посадових окладів та умов оплати праці працівникам закладів Лікувально-оздоровчого об'єднання при Кабінеті Міністрів України".
