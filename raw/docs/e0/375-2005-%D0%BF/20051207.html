( Постанова втратила чинність на підставі Постанови КМ N 1180 ( 1180-2005-п ) від 07.12.2005 )

Про затвердження складу Ради підприємців України при Кабінеті Міністрів України

Кабінет Міністрів України постановляє:

1. Затвердити склад Ради підприємців України при Кабінеті Міністрів України згідно з додатком.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 14 жовтня 2004 р. N 1350 ( 1350-2004-п ) "Про затвердження складу Ради підприємців України при Кабінеті Міністрів України" (Офіційний вісник України, 2004 р., N 41, ст. 2717).
