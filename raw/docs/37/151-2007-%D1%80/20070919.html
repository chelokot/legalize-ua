Кабінет Міністрів України; Розпорядження від 04.04.2007 № 151-р

Про відпуск зерна з державного резерву у 2007 році

Стан: Чинний

Ідентифікатор: 151-2007-р

Текст документа від 19.09.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 квітня 2007 р. N 151-р Київ

Про відпуск зерна з державного резерву у 2007 році

{ Із змінами, внесеними згідно з Розпорядженням КМ N 749-р ( 749-2007-р ) від 19.09.2007 }

З метою стабілізації ситуації на внутрішньому ринку зерна і борошна Держкомрезерву:

здійснити відпуск у 2007 році підприємствам системи державного резерву для подальшої переробки на борошно 570,5 тис. тонн зерна, що підлягає освіженню, шляхом проведення конкурсу з обмеженою участю відповідно до Порядку реалізації матеріальних цінностей державного резерву, затвердженого постановою Кабінету Міністрів України від 25 серпня 2004 р. N 1078 ( 1078-2004-п ) (Офіційний вісник України, 2004 р., N 34, ст. 2246; 2006 р., N 52, ст. 3515); { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 749-р ( 749-2007-р ) від 19.09.2007 }

щомісяця інформувати Мінекономіки про стан виконання цього розпорядження.
