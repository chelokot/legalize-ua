Кабінет Міністрів України; Розпорядження від 03.09.1993 № 656-р

Про звільнення від обкладання ввізним митом деяких товарів, що поставляються Рівненському товариству з обмеженою відповідальністю "Пластик"

Стан: Втратив чинність

Ідентифікатор: 656-93-р

Текст документа від 29.11.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 вересня 1993 р. N 656-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 957 ( 957-95-п ) від 29.11.1995 )

З метою впровадження полімерних матеріалів у будівництві та економії лісоматеріалів, що використовуються для виробництва столярних виробів, звільнити від обкладання ввізним митом технологічне обладнання, системи автоматизації та комп'ютеризації виробництва, комплектуючі вироби, фурнітуру та хімічні компоненти для виробництва будівельних конструкцій, що поставляються Рівненському товариству з обмеженою відповідальністю "Пластик" інофірмами згідно з контрактами від 16 грудня 1992 р. N 1-Р та від 28 квітня 1993 р. N 93/8799.

Перший віце-прем'єр-міністр України Ю.ЗВЯГІЛЬСЬКИЙ
