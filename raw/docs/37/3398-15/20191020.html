Про внесення змін до Закону України "Про перелік об'єктів права державної власності, що не підлягають приватизації"

( Відомості Верховної Ради України (ВВР), 2006, N 22, ст.196 )

Верховна Рада України постановляє:

1. Внести зміни до переліку об'єктів права державної власності, що не підлягають приватизації, затвердженого Законом України "Про перелік об'єктів права державної власності, що не підлягають приватизації" ( 847-14 ) (Відомості Верховної Ради України, 1999 р., N 37, ст. 332; 2001 р., N 48, ст. 255; 2002 р., N 11, ст. 82, N 14, ст. 94, N 29, ст. 196, ст. 197; 2003 р., N 39, ст. 337, ст. 338, ст. 339; 2004 р., N 22, ст. 310, ст. 311; 2005 р., N 1, ст. 16, ст. 17, ст. 18, N 2, ст. 29, N 9, ст. 171, N 48, ст. 484, ст. 485, ст. 486, ст. 487; 2006 р., N 8, ст.86, ст.87, N 16, ст.142), згідно з додатком.

2. Цей Закон набирає чинності з дня його опублікування.
