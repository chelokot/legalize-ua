КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 серпня 2002 р. N 1257 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 5 ( 5-2023-п ) від 03.01.2023 }

Про внесення зміни до пункту 2 постанови Кабінету Міністрів України від 2 листопада 1998 р. N 1725

Кабінет Міністрів України постановляє:

Абзац перший пункту 2 постанови Кабінету Міністрів України від 2 листопада 1998 р. N 1725 ( 1725-98-п ) "Про проведення обстеження умов життя у домогосподарствах" (Офіційний вісник України, 1998 р., N 44, ст. 1627; 1999 р., N 37, ст. 1855) викласти у такій редакції:

"2. З метою заохочення громадян до участі в обстеженні умов їх життя встановити з 1 січня 2003 р. щоквартальну плату за ведення записів доходів, витрат та інших відомостей для одного домогосподарства у розмірі 10 відсотків прожиткового мінімуму на одну особу".

Прем'єр-міністр України А.КІНАХ
