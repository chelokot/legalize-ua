Про внесення зміни до Положення про дипломатичний паспорт України

Внести до пункту 7 Положення про дипломатичний паспорт України, затвердженого Указом Президента України від 26 лютого 1998 року N 153 ( 153/98 ) "Про дипломатичний та службовий паспорти України" (зі змінами, внесеними Указами від 14 квітня 1998 року N 296 ( 296/98 ), від 18 травня 1998 року N 481 ( 481/98 ), від З липня 2001 року N 481 ( 481/2001 ), від 2 липня 2002 року N 599 ( 599/2002 ), від 29 жовтня 2003 року N 1227 ( 1227/2003 ), від 5 березня 2004 року N 280 ( 280/2004 ), від 3 липня 2007 року N 586 ( 586/2007 ), від 4 грудня 2007 року N 1178 ( 1178/2007 ) та від 11 квітня 2008 року N 333 ( 333/2008 ), зміну, доповнивши його після абзацу "Голові Центральної виборчої комісії" новим абзацом такого змісту:

"Голові Рахункової палати".
