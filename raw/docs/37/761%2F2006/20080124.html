Стан: Втратив чинність

Текст документа від 24.01.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 43/2008 ( 43/2008 ) від 21.01.2008 }

Про внесення змін до Указу Президента України від 11 вересня 2006 року N 749

Відповідно до частини четвертої статті 107 Конституції України ( 254к/96-ВР ) постановляю:

На часткову зміну Указу Президента України від 11 вересня 2006 року N 749 ( 749/2006 ) "Про склад Ради національної безпеки і оборони України":

1) затвердити у складі Ради національної безпеки і оборони України БАЛОГУ Віктора Івановича - Главу Секретаріату Президента України;

2) вивести зі складу Ради національної безпеки і оборони України О. Рибачука.

Президент України В.ЮЩЕНКО

м. Київ, 20 вересня 2006 року N 761/2006
