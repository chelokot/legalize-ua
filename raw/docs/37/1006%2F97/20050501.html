УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 625/2005 ( 625/2005 ) від 11.04.2005 )

Про зміни у складі Консультативної ради з питань іноземних інвестицій в Україні

На часткову зміну Указу Президента України від 11 квітня 1997 року N 323 ( 323/97 ) "Про Консультативну раду з питань іноземних інвестицій в Україні" ( із змінами, внесеними Указом Президента України від 29 липня 1997 року N 717 ( 717/97 ) ввести до складу Консультативної ради з питань іноземних інвестицій в Україні СУСЛОВА Віктора Івановича - Міністра економіки України, ЮЩЕНКА Віктора Андрійовича - Голову Національного банку України, Джеймса ТЕМЕРТІ - президента компанії "Нортленд Пауер" (Канада), виключивши зі складу цієї Ради Ю.Єханурова.

Президент України Л.КУЧМА

м. Київ, 11 вересня 1997 року N 1006/97
