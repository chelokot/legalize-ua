Кабінет Міністрів України; Постанова від 26.09.2001 № 1239

Про надбавки за особливий характер роботи та інтенсивність праці Голові та заступникам Голови Державної податкової служби

Стан: Втратив чинність

Ідентифікатор: 1239-2001-п

Текст документа від 10.09.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 вересня 2001 р. N 1239 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 597 ( 597-2013-п ) від 07.08.2013 }

Про надбавки за особливий характер роботи та інтенсивність праці Голові та заступникам Голови Державної податкової служби

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 395 ( 395-2011-п ) від 13.04.2011 }

{ Із змінами, внесеними згідно з Постановою КМ N 395 ( 395-2011-п ) від 13.04.2011 }

Кабінет Міністрів України постановляє:

Установити, що Голові Державної податкової служби та його заступникам надбавка за особливий характер роботи та інтенсивність праці призначається відповідно до пункту 2 постанови Кабінету Міністрів України від 4 липня 1995 р. N 488 ( 488-95-п ) "Про деякі зміни щодо матеріального забезпечення працівників прокуратури, судів, податкової служби, органів державної виконавчої влади та інших органів".

{ Постановляюча частина із змінами, внесеними згідно з Постановою КМ N 395 ( 395-2011-п ) від 13.04.2011 }

Прем'єр-міністр України А.КІНАХ
