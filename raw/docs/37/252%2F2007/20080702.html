{ Указ втратив чинність на підставі Указу Президента N 610/2008 ( 610/2008 ) від 02.07.2008 }

Про призначення виконуючого обов'язки першого заступника Голови Вищого господарського суду України

Призначити на період до призначення судді на адміністративну посаду в порядку, передбаченому частиною п'ятою статті 20 Закону України "Про судоустрій України" ( 3018-14 ), ЯЦЕНКО Олену Василівну виконуючим обов'язки першого заступника Голови Вищого господарського суду України.
