Про збільшення штатної чисельності працівників органів державної податкової служби

{ Із змінами, внесеними згідно з Постановою КМ N 1419 ( 1419-99-п ) від 04.08.99 }

З метою підвищення ефективності діяльності державної податкової служби і збільшення надходжень коштів до державного бюджету Кабінет Міністрів України постановляє:

1. Збільшити штатну чисельність працівників податкової міліції на 3000 одиниць.

У зв'язку з цим затвердити граничну чисельність працівників місцевих органів державної податкової служби 66716 одиниць та працівників Державної податкової адміністрації 860 одиниць. { Абзац другий пункту 1 в редакції Постанови КМ N 1419 ( 1419-99-п ) від 04.08.99 }

2. Міністерству фінансів забезпечити фінансування утримання зазначеної чисельності податкової міліції в межах видатків, передбачених у державному бюджеті на утримання органів державної податкової служби.

3. Міністерству внутрішніх справ направити у 1999 році 500 випускників вищих навчальних закладів для подальшого проходження служби в податковій міліції.
