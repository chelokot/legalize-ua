ПОСТАНОВА від 24 вересня 2008 р. N 853 Київ

Про межі акваторії морського порту Маріуполь

{ Назва Постанови в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

{ Із змінами, внесеними згідно з Постановами КМ N 406 ( 406-2013-п ) від 03.06.2013 N 896 ( 896-2019-п ) від 28.10.2019 N 40 ( 40-2021-п ) від 20.01.2021 }

Кабінет Міністрів України постановляє:

1. Визначити межі акваторії морського порту Маріуполь згідно з додатком.

{ Пункт 1 в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

2. Державному підприємству "Адміністрація морських портів України" забезпечити безпеку мореплавства в межах акваторії, визначених у додатку, а також безоплатно забезпечити місце для базування катерів морської охорони Державної прикордонної служби та їх безперешкодне проходження.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 406 ( 406-2013-п ) від 03.06.2013 }

МЕЖІ акваторії морського порту Маріуполь

{ Назва додатка в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

Акваторія порту (у системі координат WGS-84) включає:

частину водного об’єкта Азовського моря, обмежену лінією, що з'єднує навігаційний знак на краю східного пірсу (точка з координатами 47 град. 03' 43,9'' північної широти, 37 град. 30' 56,4'' східної довготи) з навігаційним знаком на краю східної захисної дамби, далі проходить по внутрішньому краю північного молу до його головної частини (точка з координатами 47 град. 03' 03,6'' північної широти, 37 град. 31' 22,9'' східної довготи), потім прямує у точку з координатами 47 град. 01' 49,0'' північної широти, 37 град. 29' 53,2'' східної довготи, далі в точку з координатами 47 град. 02' 06,7'' північної широти, 37 град. 29' 33,8'' східної довготи, потім у точку, розташовану на урізі берегової лінії, з координатами 47 град. 02' 31,8'' північної широти, 37 град. 29' 23,6'' східної довготи, далі по урізу води і кордону причалів порту до навігаційного знака краю східного пірсу;

частину водного об’єкта підхідний канал Вугільної гавані завширшки 100 метрів, з охоронною зоною завширшки 100 метрів від правої та лівої бровок каналу, з повною довжиною штучного прорізу 17,5 кілометра від буїв N 1 (точка з координатами 46 град. 53' 44,7'' північної широти, 37 град. 27' 23,5'' східної довготи) та N 2 (точка з координатами 46 град. 53' 44,1'' північної широти, 37 град. 27' 23,7'' східної довготи) до нульового кілометра осі каналу, розташованого в акваторії внутрішнього рейду при вході у Вугільну гавань, на відстані 7 метрів від краю східного молу у напрямку вхідних вогнів (точка з координатами 47 град. 02' 59,7'' північної широти, 37 град. 29' 54,6'' східної довготи);

частину водного об’єкта підхідний канал до закритої акваторії майнового комплексу “Азовсталь” завширшки 100 метрів, з охоронною зоною завширшки 100 метрів від правої та лівої бровок каналу, з повною довжиною штучного прорізу 9,192 кілометра від буя поділу каналів N 17 у місці перетину з 3-ім кілометром підхідного каналу Вугільної гавані (точка з координатами 47 град. 01' 25,5'' північної широти, 37 град. 29' 46,8'' східної довготи) до нульового кілометра осі каналу, розташованого у вхідних воротах до закритої акваторії майнового комплексу “Азовсталь”, на відстані 62 метри від краю Південної дамби по створу вхідних вогнів (точка з координатами 47 град. 04' 59,7'' північної широти, 37 град. 34' 54,6'' східної довготи);

частину водного об’єкта Азовського моря в районі ділянки рекомендованого шляху № 32, з охоронною зоною завширшки 100 метрів від осі шляху, від лінії вхідних воріт аванпорту до перетину з охоронною зоною підхідного каналу до закритої акваторії майнового комплексу "Азовсталь" на відстані 5,75 кілометра;
