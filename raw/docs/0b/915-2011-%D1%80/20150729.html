Кабінет Міністрів України; Розпорядження від 28.09.2011 № 915-р

Про розміщення Українського науково-технологічного центру

Стан: Втратив чинність

Ідентифікатор: 915-2011-р

Текст документа від 29.07.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 вересня 2011 р. N 915-р Київ

Про розміщення Українського науково-технологічного центру

{ Із змінами, внесеними згідно з Розпорядженням КМ N 717-р ( 717-2014-р ) від 17.07.2014 Постановою КМ N 29 ( 29-2015-п ) від 28.01.2015 Розпорядженням КМ N 773-р ( 773-2015-р ) від 29.07.2015 }

1. Погодитися з пропозицією Державного агентства з питань науки, інновацій та інформатизації щодо розміщення у 2011-2020 роках Українського науково-технологічного центру у приміщеннях загальною площею 746 кв. метрів на першому та четвертому поверхах будинку по вул. Металістів, 7а, та підвальних приміщеннях загальною площею 86 кв. метрів будинку по вул. Металістів, 5, у м. Києві.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженнями КМ N 717-р ( 717-2014-р ) від 17.07.2014, N 773-р ( 773-2015-р ) від 29.07.2015 }

2. Фондові державного майна забезпечити укладення з Міністерством освіти і науки договору оренди приміщень, зазначених у пункті 1 цього розпорядження, на умовах відшкодування балансоутримувачу будівель - Національному технічному університету України "Київський політехнічний інститут" фактичних витрат, пов'язаних з їх утриманням.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 29 ( 29-2015-п ) від 28.01.2015 }

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 4 лютого 2009 р. N 119 ( 119-2009-р ) "Про розташування Українського науково-технологічного центру".

Прем'єр-міністр України М.АЗАРОВ
