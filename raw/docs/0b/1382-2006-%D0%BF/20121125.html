Про внесення зміни до переліку джерел іонізуючого випромінювання, діяльність з використання яких звільняється від ліцензування

Стан: Втратив чинність

Текст документа від 25.11.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 жовтня 2006 р. N 1382 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1174 ( 1174-2011-п ) від 16.11.2011 }

Про внесення зміни до переліку джерел іонізуючого випромінювання, діяльність з використання яких звільняється від ліцензування

Кабінет Міністрів України постановляє:

Внести до переліку джерел іонізуючого випромінювання, діяльність з використання яких звільняється від ліцензування, затвердженого постановою Кабінету Міністрів України від 1 липня 2002 р. N 912 ( 912-2002-п ) (Офіційний вісник України, 2002 р., N 27, ст. 1276; 2005 р., N 4, ст. 211), зміну, що додається.
