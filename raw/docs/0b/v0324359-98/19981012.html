N 324 від 06.08.98 м. Київ

vd980806 vn324

( Постанова втратила чинність на підставі Постанови Центрвиборчкому N 537 ( v0537359-98 ) від 12.10.98 )

Про визнання недійсними виборів народного депутата України в одномандатному виборчому окрузі N 63 та призначення повторних виборів народного депутата України в цьому виборчому окрузі

Рішенням Печерського районного суду м. Києва від 4 травня 1998 року скасовано протокол окружної виборчої комісії одномандатного виборчого округу N 63 (Донецька область) від 30 березня 1998 року про визнання обраним народним депутатом України в одномандатному виборчому окрузі N 63 Богатиренка А.А., а також постанови Центральної виборчої комісії від 16 квітня 1998 року N 200 про відмову у визнанні недійсними виборів у цьому виборчому окрузі та від 17 квітня 1998 року N 209 ( v0209359-98 ) щодо реєстрації обраного народним депутатом України в одномандатному виборчому окрузі N 63 Богатиренка А.А.

На підставі викладеного та згідно з пунктом 32 статті 14 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ), частиною першою статті 47 Закону України "Про вибори народних депутатів України" ( 541/97-ВР ) Центральна виборча комісія ПОСТАНОВЛЯЄ:

1. Визнати недійсними вибори 29 березня 1998 року народного депутата України в одномандатному виборчому окрузі N 63 (Донецька область).

2. Призначити повторні вибори народного депутата України в одномандатному виборчому окрузі N 63 на неділю, 29 листопада 1998 року.

3. Доручити підготовку та проведення повторних виборів народного депутата України у зазначеному виборчому окрузі окружній та дільничним виборчим комісіям, які були утворені для проведення чергових виборів 29 березня 1998 року.

4. Постанову опублікувати в газеті "Голос України", оприлюднити у місцевих засобах інформації та надіслати Донецькій обласній раді.
