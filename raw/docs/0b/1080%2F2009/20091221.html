Президент України; Указ від 21.12.2009 № 1080/2009

Про зупинення дії постанов Кабінету Міністрів України від 24 вересня 2008 року N 854 та від 22 жовтня 2008 року N 934

Стан: Втратив чинність

Ідентифікатор: 1080/2009

Текст документа від 21.12.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанов Кабінету Міністрів України від 24 вересня 2008 року N 854 та від 22 жовтня 2008 року N 934

{ Додатково див. Конституційне подання Президента ( n0050100-09 ) від 21.12.2009 }

Кабінетом Міністрів України 24 вересня 2008 року видано постанову N 854 ( 854-2008-п ) "Про надання акваторії у користування державному підприємству "Спеціалізований морський порт "Октябрьск", відповідно до якої державному підприємству "Спеціалізований морський порт "Октябрьск" надано у постійне користування акваторію в межах, визначених у системі координат WSG-84 (згідно з додатком), за умови недопущення в подальшому передачі зазначеної акваторії або її частини іншим суб'єктам господарювання.

Постановою Кабінету Міністрів України від 22 жовтня 2008 року N 934 ( 934-2008-п ) "Про надання акваторії у користування державному підприємству "Миколаївський морський торговельний порт" державному підприємству "Миколаївський морський торговельний порт" надано у постійне користування акваторію в межах, визначених у системі координат WSG-84 (згідно з додатком), за умови недопущення в подальшому передачі зазначеної акваторії або її частини іншим суб'єктам господарювання.

Зазначені постанови Кабінету Міністрів України ( 854-2008-п, 934-2008-п ) не відповідають Конституції України ( 254к/96-ВР ), виходячи з такого.

Конституцією України ( 254к/96-ВР ) встановлено, що закони та інші нормативно-правові акти приймаються на основі Конституції України ( 254к/96-ВР ) і повинні відповідати їй (частина друга статті 8) ( 254к/96-ВР ), органи виконавчої влади зобов'язано здійснювати свої повноваження у встановлених Конституцією ( 254к/96-ВР ) межах і відповідно до законів України (частина друга статті 6) ( 254к/96-ВР ), діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України (частина друга статті 19) ( 254к/96-ВР ), а також зобов'язано Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України (частина третя статті 113) ( 254к/96-ВР ).

Зазначені ж постанови Кабінету Міністрів України ( 854-2008-п, 934-2008-п ) не погоджені з органами місцевого самоврядування, як того вимагає частина перша статті 12 Кодексу торговельного мореплавства України ( 176/95-ВР ).

Унаслідок цього постановою Кабінету Міністрів України від 24 вересня 2008 року N 854 ( 854-2008-п ) до акваторії державного підприємства "Спеціалізований морський порт "Октябрьск" віднесено земельні ділянки водного фонду та суходільні земельні ділянки, надані у користування та у власність іншим суб'єктам господарювання.

Постановою Кабінету Міністрів України від 22 жовтня 2008 року N 934 ( 934-2008-п ) до акваторії державного підприємства "Миколаївський морський торговельний порт" віднесено транзитні судноплавні шляхи: тринадцяте коліно Бузько-Дніпровсько-Лиманського каналу та перше коліно каналу акваторії порту Миколаїв. Внаслідок такого рішення державне підприємство "Миколаївський морський торговельний порт" заволоділо транзитним судноплавним шляхом, зруйнувавши його цілісність, здобуло монопольне становище на ринку спеціалізованих послуг портів і отримало можливість зловживати таким становищем, неналежним чином виконуючи обов'язок щодо утримання судноплавного шляху та обмежуючи інших суб'єктів господарювання у можливості здійснювати перевалку вантажів на торговельні судна водотоннажністю понад 50 тисяч тонн.

Конституцією України ( 254к/96-ВР ) встановлено обов'язок держави щодо забезпечення захисту прав усіх суб'єктів права власності і господарювання, їх рівність перед законом (частина четверта статті 13) ( 254к/96-ВР ). Держава зобов'язується забезпечувати захист конкуренції у підприємницькій діяльності, не допускаються зловживання монопольним становищем на ринку, неправомірне обмеження конкуренції та недобросовісна конкуренція, а види і межі монополії визначаються законом (частина третя статті 42) ( 254к/96-ВР ).

Відтак, прийнявши рішення про надання державним підприємствам "Миколаївський морський торговельний порт" і "Спеціалізований морський порт "Октябрьск" у користування акваторій у визначених постановами ( 854-2008-п, 934-2008-п ) межах, Кабінет Міністрів України порушив зазначені конституційні приписи.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанов Кабінету Міністрів України від 24 вересня 2008 року N 854 ( 854-2008-п ) "Про надання акваторії у користування державному підприємству "Спеціалізований морський порт "Октябрьск" та від 22 жовтня 2008 року N 934 ( 934-2008-п ) "Про надання акваторії у користування державному підприємству "Миколаївський морський торговельний порт".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
