КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 лютого 2009 р. N 97 Київ

Про внесення зміни у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 та визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

2. Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 18 лютого 2009 р. N 97

ПЕРЕЛІК актів Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 10 серпня 2006 р. N 1150 ( 1150-2006-п ) "Про введення додатково посади заступника Голови Державної митної служби України" (Офіційний вісник України, 2006 р., N 33, ст. 2381).

2. Постанова Кабінету Міністрів України від 15 листопада 2006 р. N 1580 ( 1580-2006-п ) "Про введення додатково посади заступника Голови Державної митної служби України" (Офіційний вісник України, 2006 р., N 46, ст. 3070).

3. Постанова Кабінету Міністрів України від 22 листопада 2006 р. N 1639 ( 1639-2006-п ) "Про введення додатково посади заступника Голови Державної митної служби України" (Офіційний вісник України, 2006 р., N 47, ст. 3132).

4. Розпорядження Кабінету Міністрів України від 30 травня 2007 р. N 367 ( 367-2007-р ) "Про введення додатково посади заступника Голови Державної митної служби України" (Офіційний вісник України, 2007 р., N 41, ст. 1632).

5. Розпорядження Кабінету Міністрів України від 9 січня 2008 р. N 50 ( 50-2008-р ) "Про скорочення посад заступників Голови Державної митної служби України" (Офіційний вісник України, 2008 р., N 2, ст. 56).

6. Розпорядження Кабінету Міністрів України від 9 січня 2008 р. N 51 ( 51-2008-р ) "Про введення додатково посади першого заступника Голови Державної митної служби України" (Офіційний вісник України, 2008 р., N 2, ст. 57).
