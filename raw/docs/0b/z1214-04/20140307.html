ДЕРЖАВНА СЛУЖБА ЕКСПОРТНОГО КОНТРОЛЮ УКРАЇНИ

НАКАЗ

13.09.2004 N 273

Зареєстровано в Міністерстві юстиції України 24 вересня 2004 р. за N 1214/9813

Про внесення змін до деяких наказів Держекспортконтролю України

{ Із змінами, внесеними згідно з Наказом Державної служби експортного контролю N 8 ( z0173-10 ) від 26.01.2010 Наказом Міністерства економічного розвитку і торгівлі N 74 ( z0304-14 ) від 27.01.2014 }

З метою забезпечення ефективної роботи, враховуючи кадрові зміни в апараті Держекспортконтролю України, НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства економічного розвитку і торгівлі N 74 ( z0304-14 ) від 27.01.2014 }

{ Пункт 2 фактично втратив чинність у зв'язку з втратою чинності Наказу Державної служби експортного контролю N 38 ( z0211-04 ) від 10.02.2004, до якого вносились зміни } 2. У пунктах 3, 4 наказу від 10.02.2004 N 38 ( z0211-04 ) "Про затвердження Правил розгляду справ про порушення юридичними особами вимог законодавства в галузі державного експортного контролю", зареєстрованого Міністерством юстиції України 19.02.2004 за N 211/8810, прізвище та ініціали "Мякушку О.В." замінити словами "Заступнику Голови Держекспортконтролю відповідно до функціональних обов'язків".

3. Начальнику управління міжнародного співробітництва забезпечити подання на державну реєстрацію до Міністерства юстиції України цього наказу в установленому порядку.

4. Контроль за виконанням цього наказу покласти на першого заступника Голови Держекспортконтролю України.
