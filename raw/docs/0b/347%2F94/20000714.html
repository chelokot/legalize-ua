Про Фонд соціального захисту населення України

Стан: Втратив чинність

Ідентифікатор: 347/94

Текст документа від 14.07.2000:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 888/2000 ( 888/2000 ) від 14.07.2000 )

Про Фонд соціального захисту населення України

( Із змінами, внесеними згідно з Указом Президента N 405/95 ( 405/95 ) від 31.05.95 )

З метою поліпшення соціального захисту малозабезпечених верств населення та відповідно до пункту 7-4 статті 114-5 Конституції України ( 888-09 ) постановляю:

1. Підтримати ініціативу державного зовнішньоекономічного об'єднання "Концерн "Укрзовнішторг" і ряду іноземних суб'єктів підприємницької діяльності та утворити благодійний фонд - Фонд соціального захисту населення України (далі - Фонд), установивши особливий порядок його утворення та діяльності.

2. Кошти Фонду формуються за рахунок добровільних внесків українських та іноземних суб'єктів підприємницької діяльності, а також інших надходжень, одержаних на підставах, не заборонених законодавством України.

( Частина друга статті 2 втратила чинність на підставі Указу Президента N 405/95 ( 405/95 ) від 31.05.95 )

3. Призначити ПЛОТКІНА Вадима Григоровича головою Фонду соціального захисту населення України.

4. Голові Фонду подати у місячний строк проект Положення про Фонд соціального захисту населення України.

5. Рекомендувати органам, уповноваженим управляти майном, що перебуває у державній власності, вирішувати питання виділення приміщень для Фонду.

Президент України Л.КРАВЧУК
