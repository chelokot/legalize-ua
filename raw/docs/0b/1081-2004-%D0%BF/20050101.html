Кабінет Міністрів України; Постанова від 25.08.2004 № 1081

Деякі питання Державного департаменту фінансового моніторингу

Стан: Чинний

Ідентифікатор: 1081-2004-п

Текст документа від 01.01.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 серпня 2004 р. N 1081 Київ

Деякі питання Державного департаменту фінансового моніторингу

( Із змінами, внесеними згідно з Постановою КМ N 1460 ( 1460-2004-п ) від 28.10.2004 )

Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України такі зміни:

( Підпункт 1 пункту 1 втратив чинність на підставі Постанови КМ N 1460 ( 1460-2004-п ) від 28.10.2004 )

2) у позиції "Міністерство фінансів" додатка 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851, ст. 875, N 32, ст. 1469, N 47, ст. 2096; 2002 р., N 8, ст. 339; 2003 р., N 9, ст. 362, N 42, ст. 2217) цифри "1066" замінити цифрами "1304***********".

2. Міністерству фінансів під час підготовки проекту Державного бюджету України на 2005 та наступні роки передбачати кошти, необхідні для реалізації завдань, покладених на Державний департамент фінансового моніторингу та його структурні підрозділи в регіонах.

3. Державному департаменту фінансового моніторингу здійснити до 1 січня 2005 р. організаційні заходи щодо утворення структурних підрозділів у регіонах в межах бюджетних асигнувань ( 1344-15 ), передбачених Державному департаменту фінансового моніторингу на 2004 рік.

4. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям разом з Фондом державного майна забезпечити службовими приміщеннями структурні підрозділи Державного департаменту фінансового моніторингу в регіонах.
