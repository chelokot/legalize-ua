Деякі питання Державного департаменту фінансового моніторингу

Стан: Чинний

Ідентифікатор: 1081-2004-п

Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 серпня 2004 р. N 1081 Київ

Деякі питання Державного департаменту фінансового моніторингу

{ Із змінами, внесеними згідно з Постановами КМ N 1460 ( 1460-2004-п ) від 28.10.2004 N 464 ( 464-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

2. Міністерству фінансів під час підготовки проекту Державного бюджету України на 2005 та наступні роки передбачати кошти, необхідні для реалізації завдань, покладених на Державний департамент фінансового моніторингу та його структурні підрозділи в регіонах.

3. Державному департаменту фінансового моніторингу здійснити до 1 січня 2005 р. організаційні заходи щодо утворення структурних підрозділів у регіонах в межах бюджетних асигнувань ( 1344-15 ), передбачених Державному департаменту фінансового моніторингу на 2004 рік.

4. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям разом з Фондом державного майна забезпечити службовими приміщеннями структурні підрозділи Державного департаменту фінансового моніторингу в регіонах.
