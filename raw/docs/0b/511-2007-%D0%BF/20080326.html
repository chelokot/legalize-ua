Про затвердження Порядку використання у 2007 році субвенції з державного бюджету місцевим бюджетам на придбання шкільних автобусів для перевезення дітей, які проживають у сільській місцевості

Стан: Чинний

Ідентифікатор: 511-2007-п

Текст документа від 26.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 березня 2007 р. N 511 Київ

Про затвердження Порядку використання у 2007 році субвенції з державного бюджету місцевим бюджетам на придбання шкільних автобусів для перевезення дітей, які проживають у сільській місцевості

{ Із змінами, внесеними згідно з Постановою КМ N 240 ( 240-2008-п ) від 26.03.2008 }

{ Установити, що у 2008 році субвенція з державного бюджету ( 107-17 ) місцевим бюджетам на придбання шкільних автобусів для перевезення дітей, що проживають у сільській місцевості, використовується відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 240 ( 240-2008-п ) від 26.03.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році субвенції з державного бюджету ( 489-16 ) місцевим бюджетам на придбання шкільних автобусів для перевезення дітей, які проживають у сільській місцевості, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 березня 2007 р. N 511

ПОРЯДОК використання у 2007 році субвенції з державного бюджету ( 489-16 ) місцевим бюджетам на придбання шкільних автобусів для перевезення дітей, які проживають у сільській місцевості

Загальна частина

1. Цей Порядок визначає механізм використання у 2007 році субвенції з державного бюджету ( 489-16 ) місцевим бюджетам на придбання шкільних автобусів для перевезення дітей, які проживають у сільській місцевості (далі - субвенція).

2. Головним розпорядником субвенції є МОН.

Вимоги щодо використання субвенції

3. Субвенція спрямовується виключно на придбання шкільних автобусів для перевезення дітей, які проживають у сільській місцевості (далі - автобуси).

4. Субвенція перераховується бюджетам Автономної Республіки Крим, областей, м. Севастополя в межах установлених бюджетних призначень згідно з розподілом, передбаченим додатком 7 до Закону України "Про Державний бюджет України на 2008 рік та про внесення змін до деяких законодавчих актів України" ( 107-17 ). { Пункт 4 із змінами, внесеними згідно з Постановою КМ N 240 ( 240-2008-п ) від 26.03.2008 }

5. Розпорядниками субвенції за відповідними місцевими бюджетами є Міністерство освіти і науки Автономної Республіки Крим, головні управління (управління) освіти і науки обласних та Севастопольської міської держадміністрацій (далі - розпорядники).

6. Державне казначейство перераховує субвенцію згідно з помісячним розписом асигнувань загального фонду державного бюджету на рахунки місцевих бюджетів відповідно до Порядку перерахування дотації вирівнювання, додаткової дотації на вирівнювання фінансової забезпеченості місцевих бюджетів та субвенцій з державного бюджету місцевим бюджетам, коштів, що передаються до державного бюджету з місцевих бюджетів, а також міжбюджетних трансфертів між місцевими бюджетами, затвердженого постановою Кабінету Міністрів України від 11 квітня 2002 р. N 490 ( 490-2002-п ) (Офіційний вісник України, 2002 р., N 15, ст. 807; 2003 р., N 14, ст. 617; 2007 р., N 6, ст. 226). { Пункт 6 із змінами, внесеними згідно з Постановою КМ N 240 ( 240-2008-п ) від 26.03.2008 }

7. Обсяг закупівлі автобусів визначається МОН згідно із заявками розпорядників, що складаються в межах бюджетних призначень, передбачених у відповідних місцевих бюджетах, з урахуванням потреби та подаються розпорядниками Міністерству в установленому ним порядку.

8. МОН проводить на умовах міжвідомчої координації відповідно до статті 14-1 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ) як генеральний замовник процедуру закупівлі автобусів, за результатами якої надсилає розпорядникам повідомлення.

{ Пункт 9 виключено на підставі Постанови КМ N 240 ( 240-2008-п ) від 26.03.2008 }

10. Розпорядники за результатами процедури закупівлі автобусів укладають в установленому порядку з переможцями такої процедури договори про закупівлю автобусів та інформують про це МОН у тижневий строк. { Пункт 10 із змінами, внесеними згідно з Постановою КМ N 240 ( 240-2008-п ) від 26.03.2008 }

11. Розпорядники можуть здійснювати попередню оплату у розмірі до 30 відсотків вартості автобусів, визначеної у договорах про їх закупівлю.

Остаточна сплата вартості автобусів здійснюється на підставі актів приймання-передачі.

12. Розпорядники здійснюють розподіл автобусів пропорційно кількості районів (з урахуванням районів у містах, в сільській місцевості яких розташовані школи) згідно із затвердженим МОН переліком виходячи із загальної кількості, яку планується поставити, а також з урахуванням кількості автобусів, придбаних за рахунок бюджетних коштів у попередні роки. Контроль за виконанням умов договорів про закупівлю автобусів і взяттям їх на облік в установленому порядку, а також за зберіганням і раціональним використанням здійснює МОН.

Звітність про використання субвенції та контроль за її витрачанням

13. Розпорядники подають МОН щомісяця до 15 числа наступного періоду інформацію про використання субвенції для узагальнення та подання щомісяця до 25 числа наступного періоду Мінфіну.

14. МОН готує план заходів щодо придбання автобусів та затверджує результативні показники його виконання з поквартальною розбивкою. Зазначені матеріали та затверджений МОН графік постачання автобусів до районів подаються Мінфіну у двотижневий строк.

15. Інформацію про виконання зазначених показників МОН подає Мінфіну в тижневий строк після закінчення звітного кварталу та одинадцяти місяців.

{ Пункт 16 виключено на підставі Постанови КМ N 240 ( 240-2008-п ) від 26.03.2008 }

{ Пункт 17 виключено на підставі Постанови КМ N 240 ( 240-2008-п ) від 26.03.2008 }

18. Складення та подання фінансової звітності про використання субвенції, а також контроль за її цільовим витрачанням здійснюються в установленому законодавством порядку.
