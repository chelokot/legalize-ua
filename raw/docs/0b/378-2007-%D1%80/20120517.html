Про проведення Київської міжнародної книжкової виставки

Стан: Чинний

Ідентифікатор: 378-2007-р

Текст документа від 17.05.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 червня 2007 р. N 378-р Київ

Про проведення Київської міжнародної книжкової виставки

{ Із змінами, внесеними згідно з Розпорядженням КМ N 278-р ( 278-2012-р ) від 17.05.2012 }

{ У назві та тексті Розпорядження слово "виставки-ярмарку" замінено словом "виставки" згідно з Розпорядженням КМ N 278-р ( 278-2012-р ) від 17.05.2012 }

Погодитися з пропозицією Держкомтелерадіо щодо проведення щороку у квітні - травні Київської міжнародної книжкової виставки. { Абзац перший із змінами, внесеними згідно з Розпорядженням КМ N 278-р ( 278-2012-р ) від 17.05.2012 }

Фінансування заходів з проведення зазначеної виставки здійснювати в установленому порядку за рахунок коштів, передбачених Держкомтелерадіо за відповідною бюджетною програмою.

Прем'єр-міністр України В.ЯНУКОВИЧ
