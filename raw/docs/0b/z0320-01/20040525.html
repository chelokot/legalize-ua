НАКАЗ

N 452 від 21.03.2001 Зареєстровано в Міністерстві юстиції України 9 квітня 2001 р. за N 320/5511

( Наказ втратив чинність на підставі Наказу Фонду державного майна N 848 ( z0616-04 ) від 27.04.2004 )

Про внесення змін та доповнень до Заяви про включення

об'єкта до переліку об'єктів, що підлягають приватизації, та до наказу ФДМУ від 17.04.98 N 772

На виконання Закону України від 21.12.2000 N 2182-III ( 2182-14 ) "Про внесення змін до деяких законів України щодо передачі об'єктів права державної власності у комунальну власність" НАКАЗУЮ:

1. Заяву про включення об'єкта до переліку об'єктів, що підлягають приватизації, затверджену наказом Фонду державного майна України від 11.07.2000 N 1431 ( z0449-00 ) та зареєстровану у Міністерстві юстиції України 27.07.2000 за N 449/4670, викласти в редакції, що додається.

2. У тексті наказу Фонду державного майна України від 17.04.98 N 772 ( z0400-98 ) "Про затвердження Порядку подання та розгляду заяв на приватизацію об'єктів груп А, Д, а також групи Ж (які підлягають приватизації способами, встановленими для об'єктів малої приватизації)" та в тексті Порядку подання та розгляду заяв на приватизацію об'єктів груп А, Д, а також групи Ж (які підлягають приватизації способами, встановленими для об'єктів малої приватизації) слова "заява на приватизацію" в усіх відмінках замінити словами "заява про приватизацію" у відповідному відмінку.

3. Додаток до Порядку подання та розгляду заяв на приватизацію об'єктів груп А, Д, а також групи Ж (які підлягають приватизації способами, встановленими для об'єктів малої приватизації), затвердженого наказом Фонду державного майна України від 17.04.98 N 772 ( z0400-98 ) та зареєстрованим у Міністерстві юстиції України 26.06.98 за N 400/2840, викласти в редакції, що додається.

4. Управлінню індивідуального продажу у триденний термін із дня прийняття цього наказу забезпечити подання зазначених змін та доповнень на державну реєстрацію до Міністерства юстиції України.

5. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Л.Кальніченка.
