МІНІСТЕРСТВО ВНУТРІШНІХ СПРАВ УКРАЇНИ ДЕРЖАВНЕ КАЗНАЧЕЙСТВО УКРАЇНИ

05.12.2005 N 983/224

Зареєстровано в Міністерстві юстиції України 20 січня 2006 р. за N 49/11923

Про внесення змін до спільного наказу МВС України та Державного казначейства України від 26 квітня 2004 року N 440/81

{ Із змінами, внесеними згідно з Наказом Міністерства внутрішніх справ N 815/1012 ( z1698-12 ) від 20.09.2012 }

У зв'язку зі зміною умов контракту про виготовлення та постачання спеціальної продукції (номерних знаків для транспортних засобів), яка використовується при реєстрації, перереєстрації транспортних засобів підрозділами Державтоінспекції МВС України, НАКАЗУЄМО:

{ Пункт 1 фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства внутрішніх справ N 440/81 ( z0556-04 ) від 26.04.2004, до якого вносились зміни } 1. Пункт 2.3 спільного наказу МВС України та Державного казначейства України від 26 квітня 2004 року N 440/81 ( z0556-04 ) "Про розрахунки за спеціальну бланкову продукцію та номерні знаки", зареєстрованого в Міністерстві юстиції України 29.04.2004 за N 556/9155, викласти в такій редакції:

"2.3. Щотижневе перерахування на відповідні рахунки Департаменту ресурсного забезпечення МВС України та Департаменту Державної автомобільної інспекції МВС України коштів за бланкову продукцію та номерні знаки, які надійшли на рахунки, визначені в п. 1 цього наказу".

2. Скасувати спільний наказ МВС України та Державного казначейства України від 10.05.2005 N 316/85 "Про внесення змін до спільного наказу МВС України та Державного казначейства України від 26 квітня 2004 року N 440/81".

3. Контроль за виконанням наказу покласти на заступника Міністра внутрішніх справ України Поречкіну Л.С. та заступника Голови Державного казначейства України Чечуліну О.О.

Міністр внутрішніх справ України Ю.В.Луценко
