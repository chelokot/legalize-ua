Про реорганізацію структури апарату Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановами КМ N 785 ( 785-96-п ) від 20.07.96 N 1102 ( 1102-96-п ) від 12.09.96 }

{ Зміни до Постанови див. в Постанові КМ N 1425 ( 1425-96-п ) від 30.11.96 }

{ Із змінами, внесеними згідно з Постановами КМ N 1564 ( 1564-96-п ) від 28.12.96 N 264 ( 264-97-п ) від 25.03.97 N 849 ( 849-97-п ) від 06.08.97 N 1167 ( 1167-97-п ) від 27.10.97 N 1294 ( 1294-97-п ) від 19.11.97 N 1298 ( 1298-97-п ) від 20.11.97 }

З метою удосконалення системи управління апаратом Уряду та забезпечення виконання ним функцій, визначених Конституцією України ( 254к/96-ВР ), законами України та актами Президента України, Кабінет Міністрів України постановляє:

1. Реорганізувати структуру апарату Кабінету Міністрів України. У зв'язку з цим:

1) ліквідувати головні управління та відділи апарату Кабінету Міністрів України згідно з додатками N 1 і 2;

2) реорганізувати структурні підрозділи апарату Кабінету Міністрів України згідно з додатком N 3;

3) утворити структурні підрозділи апарату Кабінету Міністрів України згідно з додатком N 4;

4) покласти на структурні підрозділи апарату Кабінету Міністрів України додатково функції згідно з додатком N 5.

2. Затвердити нову структуру апарату Кабінету Міністрів України (додається).

3. Установити, що структурні підрозділи апарату Кабінету Міністрів України в межах покладених на них функцій забезпечують діяльність Уряду, працюють за дорученням Прем'єр-міністра України, відповідних віце-прем'єр-міністрів України, Міністра Кабінету Міністрів України та його заступників. Керівництво апаратом Уряду покладається на Міністра Кабінету Міністрів України в межах функціональних повноважень згідно з додатком N 6.

4. Провести скорочення працівників апарату Кабінету Міністрів України, установивши його граничну чисельність у кількості 733 чоловік, у тому числі патронатних служб Прем'єр-міністра України, віце-прем'єр-міністрів України і Міністра Кабінету Міністрів України у кількості 76 чоловік. Дозволити Міністру Кабінету Міністрів України мати п'ятьох заступників, у тому числі одного першого.

Міністру Кабінету Міністрів України відповідно до функціональних повноважень у двотижневий термін розробити штатний розпис апарату Уряду в межах граничної чисельності працівників і затвердити його.

{ Збільшити на 7 одиниць граничну чисельність апарату Кабінету Міністрів України для утворення апарату організаційно-технічного забезпечення діяльності Державної комісії з проведення в Україні адміністративної реформи; установити, що створюваний апарат перебуває у структурі апарату Кабінету Міністрів України згідно з Постановою КМ N 1167 ( 1167-97-п ) від 27.10.97 } { На часткову зміну Постанови ввести до структури Служби Прем'єр-міністра України додатково посаду радника Прем'єр-міністра України, відповідно збільшивши граничну чисельність апарату Кабінету Міністрів України на одну штатну одиницю, згідно з Постановою КМ N 1294 ( 1294-97-п ) від 19.11.97 }

5. Міністерству фінансів профінансувати витрати на утримання апарату Кабінету Міністрів України у межах асигнувань, уточнених під час розгляду показників Державного бюджету України на 1996 рік.

6. Визнати такою, що втратила чинність, структуру апарату Кабінету Міністрів України, затверджену постановою Кабінету Міністрів України від 11 грудня 1995 р. N 992 ( 992-95-п ), з наступними змінами.

ФУНКЦІОНАЛЬНІ ПОВНОВАЖЕННЯ МІНІСТРА КАБІНЕТУ МІНІСТРІВ УКРАЇНИ

1. Міністр Кабінету Міністрів України:

а) забезпечує в межах функціональних повноважень керівництво структурними підрозділами апарату Кабінету Міністрів України, безпосередньо підпорядкованого Прем'єр-міністру України, щодо здійснення функцій Уряду, несе відповідальність за належне виконання завдань, покладених на Кабінет Міністрів України Конституцією України та Президентом України;

б) забезпечує взаємодію Кабінету Міністрів України із Верховною Родою України, Адміністрацією Президента України у процесі поточної діяльності Уряду, Прем'єр-міністра України та віце-прем'єр-міністрів України;

в) формує проект плану засідань Кабінету Міністрів України та його Президії на наступний квартал, а також проект порядку денного засідань зазначених органів, подає їх для погодження Прем'єр-міністру України. Здійснює підготовку засідань Кабінету Міністрів України та його Президії;

г) бере участь у розгляді питань на засіданнях Кабінету Міністрів України та його Президії;

д) організовує матеріальне, технічне та побутове забезпечення діяльності Кабінету Міністрів України та інщих центральних органів державної виконавчої влади;

е) видає накази, інші акти з питань діяльності структурних підрозділів, що входять до його компетенції;

є) вносить Прем'єр-міністру України подання щодо призначення на посади і звільнення з посад заступників Міністра Кабінету Міністрів України, за погодженням з відповідними віце-прем'єр-міністрами України - керівників структурних підрозділів апарату: начальників управлінь, їх заступників, завідуючих відділами, погоджує призначення та звільнення заступників завідуючих відділами та завідуючих секторами;

ж) розробляє штатний розпис апарату Уряду і після погодження з Прем'єр-міністром України та Президією Кабінету Міністрів України затверджує його, призначає на посади і звільнює з посад працівників апарату Уряду, в тому числі на умовах трудового договору (контракту), крім тих, які призначаються Президентом України та Кабінетом Міністрів України;

з) координує роботу, пов'язану з підготовкою проектів законодавчих актів, що вносяться Кабінетом Міністрів України Президентові України та до Верховної Ради України в порядку законодавчої ініціативи;

и) здійснює в межах покладених на нього повноважень контроль за виконанням органами державної виконавчої влади рішень Кабінету Міністрів України;

і) забезпечує дотримання Правил внутрішнього трудового розпорядку для працівників апарату Кабінету Міністрів України;

ї) бере участь у проведенні єдиної державної кадрової політики, вживає заходів для забезпечення ефективної діяльності державної служби України;

й) готує і організовує протокольні заходи Прем'єр-міністра України, а також засідання і наради, що ним проводяться;

к) має інші повноваження, надані йому рішеннями Уряду України, Прем'єр-міністром України.

2. Для здійснення своїх повноважень Міністр Кабінету Міністрів України має право:

а) залучати в установленому порядку (в тому числі шляхом утворення робочих груп, надсилання матеріалів для проведення експертного висновку) з метою опрацювання питань, що розглядаються в Кабінеті Міністрів України, працівників міністерств, інших органів державної виконавчої влади, державних установ і організацій, провідних учених і спеціалістів;

б) вимагати від органів державної виконавчої влади, підприємств, установ і організацій інформацію, необхідну для Уряду України і здійснення контролю за виконанням прийнятих рішень;

в) надсилати органам державної виконавчої влади на експертизу проекти рішень, інші документи і матеріали, що подаються на розгляд Уряду України;

г) повертати органам державної виконавчої влади документи, внесені до Кабінету Міністрів України з порушенням установленого порядку.
