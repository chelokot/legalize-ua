РОЗПОРЯДЖЕННЯ від 26 грудня 2003 р. N 802-р Київ

( Розпорядження скасовано на підставі Указу Президента N 126/2004 ( 126/2004 ) від 03.02.2004 )

Про передачу майнового комплексу військового містечка N 26 до сфери управління Держкомнацміграції

Прийняти пропозицію Держкомнацміграції і Міноборони про передачу майнового комплексу військового містечка N 26 (м. Сторожинець Чернівецької області) до сфери управління Держкомнацміграції.
