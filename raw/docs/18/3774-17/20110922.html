Верховна Рада України; Закон від 22.09.2011 № 3774-VI

Про внесення зміни до статті 28 Закону України "Про землеустрій" щодо скорочення строку складання документації із землеустрою

Стан: Чинний

Ідентифікатор: 3774-17

Текст документа від 22.09.2011:

ЗАКОН УКРАЇНИ

Про внесення зміни до статті 28 Закону України "Про землеустрій" щодо скорочення строку складання документації із землеустрою

( Відомості Верховної Ради України (ВВР), 2012, N 21, ст.193 )

Верховна Рада України постановляє:

1. Частину другу статті 28 Закону України "Про землеустрій" ( 858-15 ) (Відомості Верховної Ради України, 2003 р., N 36, ст. 282) доповнити пунктом "г" такого змісту:

"г) виконувати роботи із складання документації із землеустрою у строк, передбачений договором. Максимальний строк складання документації із землеустрою не повинен перевищувати шести місяців з моменту укладення договору".

2. Цей Закон набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 22 вересня 2011 року N 3774-VI
