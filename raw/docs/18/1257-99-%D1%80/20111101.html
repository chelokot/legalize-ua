Кабінет Міністрів України; Розпорядження від 20.11.1999 № 1257-р

Про покладення на Державний департамент з питань виконання покарань функцій уповноваженого органу Кабінету Міністрів України із забезпечення взаємодії із Європейським комітетом з питань запобігання катуванням чи нелюдському або такому, що принижує гідність, поводженню чи покаранню

Стан: Втратив чинність

Ідентифікатор: 1257-99-р

Текст документа від 01.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 листопада 1999 р. N 1257-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1109 ( 1109-2011-п ) від 20.10.2011 }

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 609-р ( 609-2002-р ) від 25.10.2002 N 76-р ( 76-2006-р ) від 08.02.2006 N 774-р ( 774-2008-р ) від 28.05.2008 }

1. Покласти на Державний департамент з питань виконання покарань функції уповноваженого органу Кабінету Міністрів України із забезпечення взаємодії з Європейським комітетом з питань запобігання катуванням чи нелюдському або такому, що принижує гідність, поводженню чи покаранню (далі - Комітет).

Зв'язки Державного департаменту з питань виконання покарань з Комітетом реалізуються через МЗС.

2. Покласти на першого заступника Голови Державного департаменту з питань виконання покарань виконання функцій уповноваженої особи з підтримання зв'язків з Комітетом.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 774-р ( 774-2008-р ) від 28.05.2008 }

3. Утворити робочу групу щодо взаємодії з Європейським комітетом з питань запобігання катуванням чи нелюдському або такому, що принижує гідність, поводженню чи покаранню у складі, що додається.

{ Пункт 3 в редакції Розпорядження КМ N 609-р ( 609-2002-р ) від 25.10.2002; із змінами, внесеними згідно з Розпорядженням КМ N 774-р ( 774-2008-р ) від 28.05.2008 }
