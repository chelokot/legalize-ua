{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 673/5 ( z0528-15 ) від 13.05.2015 }

Про внесення змін до наказу Міністерства юстиції України від 29.09.2010 N 2338/5

Відповідно до статті 14 Закону України "Про запобігання та протидію легалізації (відмиванню) доходів, одержаних злочинним шляхом, або фінансуванню тероризму" ( 249-15 ) НАКАЗУЮ:

1. Заголовок та пункт 1 наказу Міністерства юстиції України від 29.09.2010 N 2338/5 ( z0859-10 ) "Про затвердження Порядку проведення перевірок Міністерством юстиції України суб'єктів первинного фінансового моніторингу", зареєстрованого в Міністерстві юстиції України 29.09.2010 за N 859/18154 (далі - Наказ), після слів "Міністерством юстиції України" доповнити словами "та його територіальними органами".

2. Унести до Порядку проведення перевірок Міністерством юстиції України суб'єктів первинного фінансового моніторингу, затвердженого Наказом ( z0859-10 ), такі зміни:

2.1. Назву заголовка після слів "Міністерством юстиції України" доповнити словами "та його територіальними органами".

2.2. У тексті Порядку ( z0859-10 ) після слова "Мін'юст" у всіх відмінках доповнити словом "України".

2.3. Абзац четвертий пункту 1.4 розділу I після слів "Мін'юст України" доповнити словами "(управління юстиції)".

2.4. У розділі II:

2.4.1. Абзац другий пункту 2.1 після слів "Мін'юсту України" доповнити словами "(управління юстиції) про проведення перевірки".

2.4.2. Пункт 2.6 доповнити реченням такого змісту: "З метою реалізації наказу Мін'юсту України про проведення позапланової перевірки управлінням юстиції видається відповідний наказ".

2.5. Розділ V доповнити пунктом 5.14 такого змісту:

"5.14. Матеріали позапланових перевірок, проведених за дорученням Мін'юсту України, надсилаються відповідними управліннями юстиції до Мін'юсту України протягом 10-ти календарних днів після їх проведення.".

2.6. У додатках 2, 4, 7, 8 після слів "МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ" доповнити словами "(Головне управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головні управління юстиції в областях, містах Києві та Севастополі)".

3. Департаменту нотаріату, банкрутства та функціонування центрального засвідчувального органу (Чижмарь К.І.):

3.1. Подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади".

3.2. Довести цей наказ до відома начальника Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, начальників головних управлінь юстиції в областях, містах Києві та Севастополі.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

5. Контроль за виконанням цього наказу покласти на директора Департаменту нотаріату, банкрутства та функціонування центрального засвідчувального органу Чижмарь К.І.

Міністр Олександр Лавринович
