Про затвердження Змін до деяких нормативно-правових актів Національного банку України

{ Із змінами, внесеними згідно з Постановою Національного банку N 89 ( v0089500-17 ) від 11.09.2017 }

Відповідно до статті 41 Закону України "Про Національний банк України" ( 679-14 ) та статті 68 Закону України "Про банки і банківську діяльність" ( 2121-14 ) Правління Національного банку України ПОСТАНОВЛЯЄ:

{ Пункт 1 втратив чинність на підставі Постанови Національного банку N 89 ( v0089500-17 ) від 11.09.2017 }

2. У пункті 2.5 глави 2 розділу IX Інструкції з бухгалтерського обліку основних засобів і нематеріальних активів банків України, затвердженої постановою Правління Національного банку України від 20.12.2005 N 480 ( z0040-06 ), зареєстрованої в Міністерстві юстиції України 18.01.2006 за N 40/11914, проводку викласти в такій редакції:

"Дебет рахунку

3409;

Кредит рахунку

6499".

3. Департаменту бухгалтерського обліку (Ричаківська В.І.) після державної реєстрації в Міністерстві юстиції України довести зміст цієї постанови до відома структурних підрозділів центрального апарату, територіальних управлінь Національного банку України та банків для керівництва й використання в роботі.

4. Контроль за виконанням цієї постанови покласти на територіальні управління Національного банку України.

5. Постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

Голова В.С.Стельмах
