Про віднесення посад працівників Державного фонду сприяння місцевому самоврядуванню в Україні до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 422-2011-р

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 травня 2011 р. N 422-р Київ

{ Розпорядження втратило чинність на підставі Постанов КМ N 336 ( 336-2015-п ) від 27.05.2015 N 465 ( 465-2016-п ) від 22.07.2016 }

Про віднесення посад працівників Державного фонду сприяння місцевому самоврядуванню в Україні до відповідних категорій посад державних службовців

1. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Державного фонду сприяння місцевому самоврядуванню в Україні до таких категорій посад державних службовців:

перша категорія - голова Фонду;

друга категорія - перший заступник та заступник голови Фонду;

третя категорія - начальник управління, завідувач самостійного відділу;

четверта категорія - заступник начальника управління, завідувач відділу у складі управління;

п'ята категорія - головний консультант.

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 5 липня 1994 р. N 508 ( 508-94-р );

розпорядження Кабінету Міністрів України від 20 липня 1996 р. N 463 ( 463-96-р );

розпорядження Кабінету Міністрів України від 17 листопада 2010 р. N 2104 ( 2104-2010-р ) "Про внесення зміни до розпорядження Кабінету Міністрів України від 5 липня 1994 р. N 508" (Офіційний вісник України, 2010 р., N 89, ст. 3156).
