Про склад експертної групи з питань підготовки проектів міждержавних договорів про правові відносини та правову допомогу у цивільних, шлюбно-сімейних та кримінальних справах

Стан: Втратив чинність

Ідентифікатор: 290/2000-рп

Текст документа від 01.06.2004:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 476/2004 ( 476/2004 ) від 24.04.2004 )

Про склад експертної групи з питань підготовки проектів

міждержавних договорів про правові відносини та правову допомогу у цивільних, шлюбно-сімейних та кримінальних справах

1. Затвердити новий персональний склад експертної групи з питань підготовки проектів міждержавних договорів про правові відносини та правову допомогу у цивільних, шлюбно-сімейних та кримінальних справах (додається), утвореної відповідно до Розпорядження Президента України від 4 січня 1995 року N 3 ( 3/95-рп ) "Про підготовку проектів міждержавних договорів про правові відносини та правову допомогу".

2. Визнати такими, що втратили чинність:

пункт 2 Розпорядження Президента України від 4 січня 1995 року N 3 ( 3/95-рп ) "Про підготовку проектів міждержавних договорів про правові відносини та правову допомогу";

Розпорядження Президента України від 17 жовтня 1996 року N 399 ( 399/96-рп ) "Про склад експертної групи з питань підготовки проектів міждержавних договорів про правові відносини та правову допомогу у цивільних, шлюбно-сімейних та кримінальних справах";

Розпорядження Президента України від 23 листопада 1996 року N 610 ( 610/96-рп ) "Про зміни у складі експертної групи, затвердженому Розпорядженням Президента України від 4 січня 1995 року N 3";

Розпорядження Президента України від 15 вересня 1998 року N 491 ( 491/98-рп ) "Про зміни у складі експертної групи з питань підготовки проектів міждержавних договорів про правові відносини та правову допомогу у цивільних, шлюбно-сімейних та кримінальних справах".

Президент України Л.КУЧМА

м. Київ, 22 вересня 2000 року N 290/2000-рп

МАРКЄЄВА - начальник договірно-правового відділу Оксана Дмитрівна управління міжнародних зв'язків Головного Штабу Міністерства внутрішніх справ України
