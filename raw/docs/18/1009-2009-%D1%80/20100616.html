КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 серпня 2009 р. N 1009-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1161-р ( 1161-2010-р ) від 02.06.2010 }

Про заходи щодо забезпечення розвитку Міжнародного аеропорту "Львів"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1236-р ( 1236-2010-р ) від 16.06.2010 }

{ Дію пункту 1 відновлено до 20 липня 2010 р. згідно з Розпорядженням КМ N 1236-р ( 1236-2010-р ) від 16.06.2010}

1. Погодитися з пропозицією Львівської облдержадміністрації щодо передачі державним підприємством "Міжнародний аеропорт "Львів" (далі - Міжнародний аеропорт "Львів") функцій замовника будівництва та реконструкції Міжнародного аеропорту "Львів" Управлінню капітального будівництва Львівської облдержадміністрації.

2. Надати Львівській облдержадміністрації право затвердити проект першого етапу (підготовчі роботи) будівництва нового аеровокзалу Міжнародного аеропорту "Львів".

3. Львівській облдержадміністрації невідкладно забезпечити проведення процедури визначення генерального підрядника на виконання підготовчих робіт з будівництва нового аеровокзалу Міжнародного аеропорту "Львів".

4. Мінтрансзв'язку, Львівській облдержадміністрації разом з іншими заінтересованими органами виконавчої влади забезпечити у тижневий строк укладення договорів про заміну сторін у зобов'язаннях щодо будівництва та реконструкції Міжнародного аеропорту "Львів" (у разі потреби за погодженням з відповідними контрагентами) з урахуванням того, що всі права та обов'язки переходять до Управління капітального будівництва Львівської облдержадміністрації, та вирішити в установленому порядку питання стосовно переоформлення документів дозвільного характеру, виданих Міжнародному аеропорту "Львів", або правонаступництва за ними.

Прем'єр-міністр України Ю.ТИМОШЕНКО
