Кабінет Міністрів України; Розпорядження від 26.12.2011 № 1324-р

Про надання права на довічне користування приміщенням у будинку відпочинку "Конча-Заспа" Державного управління справами

Стан: Втратив чинність

Ідентифікатор: 1324-2011-р

Текст документа від 04.07.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 грудня 2011 р. N 1324-р Київ

Про надання права на довічне користування приміщенням у будинку відпочинку "Конча-Заспа" Державного управління справами

{ Із змінами, внесеними згідно з Розпорядженням КМ N 746-р ( 746-2012-р ) від 04.07.2012 }

Прийняти пропозицію Міністерства культури, погоджену з Державним управлінням справами, щодо надання народному артисту України Ступці Б.С. та членам його сім’ї права на довічне користування приміщенням (будинок 49) у будинку відпочинку "Конча-Заспа" Державного управління справами, яке він займає, на умовах оплати, визначених абзацом другим розпорядження Кабінету Міністрів України від 19 січня 1994 р. N 31 ( 31-94-р ), - із змінами, внесеними розпорядженням Кабінету Міністрів України від 22 травня 2003 р. N 285 ( 285-2003-р ).

{ Текст Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 746-р ( 746-2012-р ) від 04.07.2012 }

Прем'єр-міністр України М.АЗАРОВ
