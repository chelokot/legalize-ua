КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 березня 2004 р. N 293 Київ

Про нагородження Почесною грамотою Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 746 ( 746-2023-п ) від 21.07.2023 }

Кабінет Міністрів України постановляє:

За вагомий внесок у зміцнення співробітництва між Україною і Російською Федерацією в галузі сільського господарства та з нагоди відзначення 50-річчя від початку освоєння цілинних і перелогових земель нагородити Почесною грамотою Кабінету Міністрів України з врученням пам'ятного знака:

{ Позицію виключено на підставі Постанови КМ N 746 ( 746-2023-п ) від 21.07.2023 }
