КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 січня 2001 р. N 48 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 622 ( 622-2016-п ) від 14.09.2016 }

Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 31 травня 2000 р. N 865

{ Додатково див. Постанову КМ N 426 ( 426-2013-п ) від 19.06.2013 }

У зв'язку з прийняттям Закону України від 5 жовтня 2000 р. N 2015-III ( 2015-14 ) "Про внесення змін до статті 32 Закону України "Про статус народного депутата України" Кабінет Міністрів України постановляє:

У пункті 1 постанови Кабінету Міністрів України від 31 травня 2000 р. N 865 ( 865-2000-п ) "Про деякі питання вдосконалення визначення розмірів заробітку для обчислення пенсії" (Офіційний вісник України, 2000 р., N 22, ст. 906) слова "Про статус народного депутата" виключити.
