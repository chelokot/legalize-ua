КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 жовтня 1996 р. N 1236 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1008 ( 1008-2010-п ) від 03.11.2010 }

Про затвердження складу наглядової ради Меморіального комплексу "Національний музей історії Великої Вітчизняної війни 1941-1945 років"

На виконання Указу Президента України від 21 червня 1996 р. N 459 ( 459/96 ) "Про надання статусу національного Меморіальному комплексу "Український державний музей історії Великої Вітчизняної війни 1941-1945 років" Кабінет Міністрів України постановляє:

Затвердити склад наглядової ради Меморіального комплексу "Національний музей історії Великої Вітчизняної війни 1941-1945 років" згідно з додатком.
