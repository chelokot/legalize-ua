Про внесення доповнень до наказу Міністра оборони України від 14.08.95 N 200

Відповідно до вимог Закону України "Про державну службу" ( 3723-12 ) та розпорядження Кабінету Міністрів України від 29 травня 1995 р. N 301-р ( 301-95-р ) НАКАЗУЮ:

1. Внести такі доповнення до додатка N 3 наказу Міністра оборони України від 14.08.95 N 200 ( z0406-95 ) "Про заходи щодо реалізації Закону України "Про державну службу" в органах військового управління та військових комісаріатах":

"10.57 інформаційний центр Управління виду (Головного управління кадрів) Збройних Сил України

11. Управління ветеринарної медицини Управління виду Тилу Міністерства оборони України Збройних Сил України".

2. Контроль за виконанням наказу покласти на начальника Генерального штабу Збройних Сил України - першого заступника Міністра оборони України.

3. Наказ розіслати згідно з розрахунком розсилки.
