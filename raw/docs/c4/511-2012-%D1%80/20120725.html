КАБІНЕТ МІНІСТРІВ УКРАЇНИ
РОЗПОРЯДЖЕННЯ

від 25 липня 2012 р. № 511-р
Київ

Про відкриття пункту контролю через державний  кордон на залізничній станції “Київ-Пасажирський”

З метою впорядкування діяльності пунктів пропуску для залізничного сполучення відкрити на території залізничної станції “Київ-Пасажирський” самостійний пункт контролю через державний кордон для міжнародних пасажирських перевезень постійного функціонування з цілодобовим режимом роботи.

Прем'єр-міністр України

М.АЗАРОВ
