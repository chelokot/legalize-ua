Про затвердження Положення про державний нотаріат Української РСР та Переліку документів, на підставі яких вчиняються нотаріальні виконавчі написи на стягнення грошей і майна

( Із змінами, внесеними згідно з Постановами Ради Міністрів УРСР N 42 ( 42-66-п ) від 12.01.66 N 144 ( 144-66-п ) від 07.02.66 N 307 ( 307-66-п ) від 12.04.66 N 832 ( 832-66-п ) від 09.11.66 N 310 ( 310-68-п ) від 21.06.68 N 492 ( 492-69-п ) від 20.08.69 N 55 ( 55-70-п ) від 29.01.70 N 578 ( 578-70-п ) від 10.11.70 N 124 ( 124-72-п ) від 10.03.72 N 271 ( 271-72-п ) від 08.06.72 N 146 ( 146-73-п ) від 26.03.73 N 580 ( 580-74-п ) від 30.12.74 N 175 ( 175-75-п ) від 09.04.75 )

Рада Міністрів Української РСР постановляє:

1. Затвердити додані до цього:

а) Положення про державний нотаріат Української РСР;

б) Перелік документів, на підставі яких вчиняються нотаріальні виконавчі написи на стягнення грошей і майна.

2. Вважати такими, що втратили силу, постанови Ради Міністрів Української РСР згідно з переліком, що додається.

ЗАТВЕРДЖЕНИЙ постановою Ради Міністрів УРСР від 31 серпня 1964 р. N 941

ПЕРЕЛІК документів, на підставі яких вчиняються нотаріальні виконавчі написи на стягнення грошей і майна

I.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ЗА НОТАРІАЛЬНО ПОСВІДЧЕНИМИ ДОГОВОРАМИ

1. СТЯГНЕННЯ ГРОШОВИХ СУМ ТА ІНШОГО МАЙНА, ВИПЛАТА, ПЕРЕДАЧА АБО ПОВЕРНЕННЯ ЯКИХ ПЕРЕДБАЧЕНІ НОТАРІАЛЬНО ПОСВІДЧЕНИМИ УГОДАМИ, ПРОВАДИТЬСЯ

на підставі:

а) оригіналу угоди;

б) документа, що встановлює прострочку виконання.

II.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ НА ПІДСТАВАХ, ЩО ВИПЛИВАЮТЬ З ГОСПРОЗРАХУНКОВИХ І КРЕДИТНИХ ВЗАЄМОВІДНОСИН

2. СТЯГНЕННЯ ПРОСТРОЧЕНИХ ПЛАТЕЖІВ ПО ПОЗИЧКАХ, ВИДАНИХ БАНКАМИ ТА ГОСПРОЗРАХУНКОВИМИ ПІДПРИЄМСТВАМИ І ОРГАНІЗАЦІЯМИ В ПОРЯДКУ КРЕДИТНИХ ОПЕРАЦІЙ, ПРОВАДИТЬСЯ

на підставі:

а) виписки з засвідченого рахунку боржника з зазначенням в ній дати і номера зобов'язання, а також строку і суми несплаченого за цим зобов'язанням чергового платежу;

б) довідки банку (якщо боржник має в банку рахунок) про те, що сума чергового платежу з рахунку не списана через відсутність на ньому коштів.

3. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ПО ПОЗИЧКАХ, ВИДАНИХ КАСАМИ ДОПОМОГИ, ПРОВАДИТЬСЯ

на підставі:

а) оригіналу зобов'язання боржника,

б) довідки, підписаної керівництвом каси, про суму заборгованості, яку слід стягнути.

4. СТЯГНЕННЯ З ПОКУПЦЯ ВАРТОСТІ ТОВАРУ, ЗДАНОГО НА ВІДПОВІДАЛЬНЕ ЗБЕРІГАННЯ, В РАЗІ ВІДМОВИ ПОКУПЦЯ ПОВЕРНУТИ ТОВАР НА ВИМОГУ ПОСТАВЩИКА, ПРОВАДИТЬСЯ

на підставі:

а) рахунку-фактури поставщика;

б) довідки транспортного підприємства про здачу товару покупцеві;

в) довідки банку про несплату покупцем рахунку-фактури з зазначенням в довідці, що банком було, за дорученням поставщика, пред'явлено покупцеві вимогу повернути або перевідправити товар, але цю вимогу в установлений банком строк покупець не виконав.

5. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ПО НЕОПЛАЧЕНИХ ЧЕКАХ ПРОВАДИТЬСЯ

на підставі:

чека, несплата якого посвідчена платником або розрахунковою установою шляхом відповідного напису.

6. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ДЕРЖБАНКУ СРСР ЗА СПЕЦІАЛЬНИМИ ПОЗИЧКАМИ ПРОВАДИТЬСЯ

на підставі:

а) засвідченої установою Держбанку СРСР копії заяви-зобов'язання боржника;

б) засвідченої установою Держбанку СРСР виписки особового рахунку боржника в Держбанку СРСР про суму заборгованості.

6-а. Стягнення правлінням житлово-будівельного кооперативу заборгованості членів кооперативу по прострочених платежах по позичках провадиться на підставі:

а) копії зобов'язання боржника, засвідченої правлінням житлово-будівельного кооперативу;

б) засвідченої правлінням житлово-будівельного кооперативу виписки особового рахунку боржника.

( Перелік доповнено пунктом 6-а згідно з Постановою Ради Міністрів УРСР N 144 ( 144-66-п ) від 07.02.66 )

III.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ЗА ТОВАРИ, ВІДПУЩЕНІ З РОЗСТРОЧКОЮ ПЛАТЕЖУ

7. СТЯГНЕННЯ З ПОКУПЦІВ СУМИ ЗАБОРГОВАНОСТІ ПО ЧЕРГОВИХ ПЛАТЕЖАХ ЗА ТОВАРИ, ВІДПУЩЕНІ З РОЗСТРОЧКОЮ ПЛАТЕЖУ, ТА ПЕНІ ЗА НЕСВОЄЧАСНУ СПЛАТУ ЗАБОРГОВАНОСТІ ПРОВАДИТЬСЯ

на підставі:

а) засвідченої копії зобов'язання боржника з його розпискою про одержання товару;

б) засвідченої стягувачем виписки з особового рахунку боржника з зазначенням суми заборгованості та пені.

8. СТЯГНЕННЯ З ПОКУПЦІВ ВСІЄЇ СУМИ ЗАБОРГОВАНОСТІ (КРЕДИТУ) ЗА ТОВАРИ, ВІДПУЩЕНІ З РОЗСТРОЧКОЮ ПЛАТЕЖУ, ТА ПЕНІ В РАЗІ НЕСПЛАТИ ПОКУПЦЯМИ БЕЗ ПОВАЖНИХ ПРИЧИН ТРЬОХ ЧЕРГОВИХ ПЛАТЕЖІВ ПРОВАДИТЬСЯ на підставі:

а) засвідченої копії зобов'язання боржника з його розпискою про одержання товару;

б) засвідченої стягувачем виписки з особового рахунку боржника з зазначенням суми заборгованості та пені, і відміткою про вжиті стягувачем до боржника заходи щодо добровільної сплати суми заборгованості; ( Підпункт "б" пункту 8 із змінами, внесеними згідно з Постановою Ради Міністрів УРСР N 578 ( 578-70-п ) від 10.11.70 )

( Підпункт "в" пункту 8 виключено на підставі Постанови Ради Міністрів УРСР N 578 ( 578-70-п ) від 10.11.70 )

9. СТЯГНЕННЯ ВАРТОСТІ НЕПОВЕРНЕНИХ АБО ЗІПСОВАНИХ ПРЕДМЕТІВ, ОДЕРЖАНИХ ДЛЯ ТИМЧАСОВОГО КОРИСТУВАННЯ - НАПРОКАТ, А ТАКОЖ СТЯГНЕННЯ ПЛАТИ ЗА ПРОКАТ І ПЕНІ ЗА НЕСВОЄЧАСНЕ ПОВЕРНЕННЯ ПРЕДМЕТІВ, ОДЕРЖАНИХ НАПРОКАТ, ПРОВАДИТЬСЯ

на підставі:

( Абзац перший пункту 9 із змінами, внесеними згідно з Постановою Ради Міністрів УРСР N 578 ( 578-70-п ) від 10.11.70 )

а) розписки-зобов'язання одержувача предмета;

б) акта про неповернення, зіпсування або несвоєчасне повернення предмета, одержаного напрокат, за підписами керівника та бухгалтера магазину-складу і одержувача предмета або з відміткою про відмову одержувача розписатися на акті;

в) рахунку про вартість незданого або зіпсованого предмета чи про суму пені за несвоєчасне повернення предмета, за підписами керівника і бухгалтера магазину-складу.

9-а. Стягнення заборгованості за надання населенню послуг по ремонту побутової радіотелевізійної апаратури провадиться на підставі:

а) копії повідомлення радіотелевізійного ательє на ім'я власника побутового радіотелевізійного апарата про оплату останнім вартості ремонту апарата за підписами механіка, який провадив ремонт, і власника апарата з зобов'язанням останнього протягом одного місяця оплатити вартість ремонту;

б) копії нагадування радіотелевізійного ательє власнику апарата, надісланого після закінчення одного місяця з дня ремонту, про необхідність оплатити заборгованість за ремонт апарата або акта про відмову власника апарата від одержання нагадування.

( Перелік доповнено пунктом 9-а згідно з Постановою Ради Міністрів УРСР N 42 ( 42-66-п ) від 12.01.66 )

IV.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ, ЩО ВИПЛИВАЄ З ПЕРЕВОЗОК ВАНТАЖІВ, І СУМ, ЩО НАЛЕЖАТЬ ПО НЕОСПОРЕНІЙ ДИСПАШІ

10. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ, ЩО ВИПЛИВАЄ З ПЕРЕВОЗОК ВАНТАЖІВ, З УПРАВЛІНЬ ЗАЛІЗНИЦЬ, МОРСЬКИХ І РІЧКОВИХ ПАРОПЛАВСТВ ПО ЗАДОВОЛЕНИХ ПРЕТЕНЗІЯХ КЛІЄНТІВ ПРОВАДИТЬСЯ

на підставі:

оригіналу повідомлення залізниці, морського чи річкового пароплавства, надісланого клієнтові, з зазначенням суми, на яку залізниця або пароплавство претензію задовольнили.

11. СТЯГНЕННЯ СУМИ ПО ДИСПАШІ, НЕ ОСПОРЕНІЙ ПРОТЯГОМ ВСТАНОВЛЕНОГО СТРОКУ, ПРОВАДИТЬСЯ

на підставі:

а) диспаші;

б) довідки диспашера про те, що диспаша не оспорена.

V.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ЗА НЕПОВЕРНЕНУ МІШКОВУ ТАРУ ТА ШТРАФУ ЗА ПРОСТРОЧКУ ЇЇ ПОВЕРНЕННЯ

12. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ЗА НЕПОВЕРНЕНУ МІШКОВУ ТАРУ З-ПІД ХЛІБОПРОДУКТІВ, ЦУКРУ ТА НАСІННЯ СІЛЬСЬКОГОСПОДАРСЬКИХ КУЛЬТУР І ШТРАФУ ЗА ПРОСТРОЧКУ ЇЇ ПОВЕРНЕННЯ ПРОВАДИТЬСЯ

на підставі:

а) особового рахунку споживача (покупця) або здавальника про стан заборгованості по мішках;

б) колії акта, складеного споживачем (покупцем) або здавальником разом з поставщиком по наслідках звірки взаєморозрахунків по наявній заборгованості по мішках, або довідки поставщика про неявку представника споживача (покупця) чи здавальника для складання зазначеного акта;

в) копії повідомлення, надісланого поставщиком споживачеві (покупцю) або здавальникові про накладення на них штрафу за несвоєчасне повернення мішків.

VI.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ПО КВАРТИРНІЙ ПЛАТІ І ЗА КОМУНАЛЬНІ ПОСЛУГИ

13. СТЯГНЕННЯ ЗА ВИМОГАМИ ДОМОУПРАВЛІНЬ НЕ СПЛАЧЕНОЇ В УСТАНОВЛЕНІ ЗАКОНОМ СТРОКИ КВАРТИРНОЇ ПЛАТИ, ПЛАТИ ЗА ЦЕНТРАЛЬНЕ ОПАЛЕННЯ, КОМУНАЛЬНІ ПОСЛУГИ (ВОДУ, КАНАЛІЗАЦІЮ, ГАЗ) ПРОВАДИТЬСЯ

на підставі:

а) копії надісланого боржникові рахунку, підписаного керівництвом і бухгалтером, з відміткою стягувача про те, що після вручення рахунку заборгованість не погашена;

б) розписки боржника про одержання рахунку, або акта про відмову боржника одержати рахунок.

14. СТЯГНЕННЯ ЗА ВИМОГАМИ ЕНЕРГОЗБУТІВ ТА ІНШИХ ПОСТАВЩИКІВ ЕЛЕКТРОЕНЕРГІЇ ЗАБОРГОВАНОСТІ ЗА КОРИСТУВАННЯ ЕЛЕКТРОЕНЕРГІЄЮ, НЕ СПЛАЧЕНОЇ В УСТАНОВЛЕНІ ЗАКОНОМ СТРОКИ, ПРОВАДИТЬСЯ

на підставі:

а) копії надісланого боржникові рахунку, підписаного керівництвом і бухгалтером, з відміткою стягувача про те, що після вручення рахунку заборгованість не погашена;

б) розписки боржника про одержання рахунку, або акта про відмову боржника одержати рахунок.

15. СТЯГНЕННЯ ЗА ВИМОГАМИ ВІДОМСТВ НЕ СПЛАЧЕНОЇ ВЛАСНИКАМИ І ОРЕНДАРЯМИ БУДИНКІВ ПЛАТИ ЗА КОРИСТУВАННЯ ВОДОЮ, ОЧИЩЕННЯ ДИМОХОДІВ, ВИГРІБНИХ ЯМ, ЗА ДЕЗІНФЕКЦІЮ, ДЕРАТИЗАЦІЮ ТОЩО ПРОВАДИТЬСЯ

на підставі:

копії надісланого боржникові рахунку, підписаного керівництвом і бухгалтером, з відміткою стягувача про те, що після вручення рахунку заборгованість не погашена, або з відміткою про відмову боржника одержати рахунок.

16. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ПО ОРЕНДНІЙ ПЛАТІ, КОМУНАЛЬНИХ ТА ЕКСПЛУАТАЦІЙНИХ ВИДАТКАХ ЗА НЕЖИЛІ ПРИМІЩЕННЯ В БУДИНКАХ, ЩО НАЛЕЖАТЬ МІСЦЕВИМ РАДАМ ДЕПУТАТІВ ТРУДЯЩИХ, УСТАНОВАМ, ПІДПРИЄМСТВАМ І ОРГАНІЗАЦІЯМ, А ТАКОЖ СТЯГНЕННЯ ОРЕНДНОЇ ПЛАТИ ЗА КОРИСТУВАННЯ ВІДКРИТИМИ СТОЯНКАМИ ДЛЯ ЛЕГКОВИХ АВТОМОБІЛІВ, МОТОЦИКЛІВ ТА ІНШИХ ТРАНСПОРТНИХ ЗАСОБІВ ПРОВАДИТЬСЯ

на підставі:

а) засвідченої стягувачем копії орендного договору або зобов'язання;

б) копії надісланого боржникові рахунку, підписаного керівництвом і бухгалтером, з відміткою стягувача про те, що після вручення рахунку заборгованість не погашена, або з відміткою про відмову боржника одержати рахунок.

17. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ІНВЕНТАРИЗАЦІЙНИМИ ОРГАНАМИ КОМУНАЛЬНОГО ГОСПОДАРСТВА ЗА ОЦІНОЧНІ ТА ІНВЕНТАРИЗАЦІЙНІ РОБОТІ, А ТАКОЖ ЗА РОБОТИ ПО ОБМІРУ ТА СКЛАДАННЮ ПЛАНІВ ЗЕМЕЛЬНИХ ДІЛЯНОК ПРОВАДИТЬСЯ

на підставі:

а) копії надісланого боржникові рахунку, підписаного керівництвом і бухгалтером, з відміткою стягувача про те, що після вручення рахунку заборгованість не погашена або з актом про відмову боржника одержати рахунок;

б) копії акта з зазначенням адреси будинків (будинку), по яких провадились оціночні та інвентаризаційні роботи або роботи по обміру та складанню плану земельної ділянки, назви та обсягу проведених робіт, їх загальної вартості і суми заборгованості.

18. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ЧЛЕНІВ ЖИТЛОВО-БУДІВЕЛЬНИХ І ДАЧНО-БУДІВЕЛЬНИХ КООПЕРАТИВІВ ПО ПРОСТРОЧЕНИХ БІЛЬШЕ ДВОХ МІСЯЦІВ ПЛАТЕЖАХ В РАХУНОК ПОКРИТТЯ ВИДАТКІВ ПО ВОЛОДІННЮ БУДИНКОМ ПРОВАДИТЬСЯ

на підставі:

а) копії надісланого боржникові рахунку, підписаного керівництвом і бухгалтером;

б) копії письмового попередження домоуправління члену кооперативу про потребу сплатити в установлений строк платежі на покриття видатків по володінню будинком з розпискою члена кооперативу про одержання попередження або з актом про його відмову одержати попередження.

19. СТЯГНЕННЯ З САМОВІЛЬНОГО ЗАБУДОВНИКА ВИДАТКІВ, ЗВ'ЯЗАНИХ З ЗНЕСЕННЯМ БУДИНКІВ, ПРОВАДИТЬСЯ

на підставі:

а) копії рішення виконкому місцевої Ради депутатів трудящих про знесення самовільно збудованого будинку;

б) копії надісланого боржникові рахунку, підписаного керівництвом і бухгалтером, про вартість робіт по знесенню будинку, з зазначенням в рахунку прізвища, імені та по батькові самовільного забудовника, адреси будинку і не сплаченої боржником суми вартості робіт по знесенню будинку, з відміткою стягувача про те, що після вручення рахунку заборгованість не погашена або з актом про відмову боржника прийняти рахунок.

VII.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ЗА ПІДСТАВАМИ, ЩО ВИПЛИВАЮТЬ З ТРУДОВИХ ВІДНОСИН

20. СТЯГНЕННЯ НЕСПЛАЧЕНОЇ ЗАРОБІТНОЇ ПЛАТИ ПРОВАДИТЬСЯ

на підставі:

довідки установи, підприємства або організації про те, що працівник роботу виконав, а заробітної плати (з зазначенням за який час і в якій сумі) не одержав.

21. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ПО НЕВІДРОБЛЕНИХ АВАНСАХ, ВИДАНИХ ДЕРЖАВНИМИ, КООПЕРАТИВНИМИ І ГРОМАДСЬКИМИ УСТАНОВАМИ, ПІДПРИЄМСТВАМИ ТА ОРГАНІЗАЦІЯМИ В РАХУНОК ЗАРОБІТНОЇ ПЛАТИ, А ТАКОЖ ЗАБОРГОВАНОСТІ ПО СУМАХ, ВИДАНИХ НА ПЕРЕЇЗД ДО МІСЦЯ РОБОТИ РОБІТНИКАМ І СЛУЖБОВЦЯМ, СТЯГУВАНИХ У ЗВ'ЯЗКУ З ТИМ, ЩО ВОНИ НЕ ПРИСТУПИЛИ ДО РОБОТИ АБО ЗАЛИШИЛИ ЇЇ, НЕ ВІДРОБИВШИ ОДЕРЖАНОГО АВАНСУ, ЧИ РАНІШЕ СТРОКУ, ОБУМОВЛЕНОГО ТРУДОВИМ ДОГОВОРОМ, АБО ЯКЩО ВОНИ ЗВІЛЬНЕНІ ЗА ПОРУШЕННЯ ТРУДОВОЇ ДИСЦИПЛІНИ ЧИ ЗА ПОРУШЕННЯ ПРИЙНЯТИХ НА СЕБЕ ЗА ДОГОВОРОМ ЗОБОВ'ЯЗАНЬ, ПРОВАДИТЬСЯ

на підставі:

а) документа, що стверджує наявність трудового договору з робітником або службовцем; ( Підпункт "а" пункту 21 в редакції Постанови Ради Міністрів УРСР N 578 ( 578-70-п ) від 10.11.70 )

б) документа з розпискою робітника або службовця про одержання ним суми, яка стягується;

в) довідки адміністрації підприємства - у зв'язку з чим з робітника або службовця стягується видана раніше сума.

В разі звільнення працівника з роботи стягувач, крім зазначених документів, повинен подати довідку або копію наказу про звільнення з зазначенням кількості проробленого часу та про належну і виплачену звільненому суму заробітної плати і суму, відраховану із заробітної плати на покриття боргу і про решту цього боргу, а в разі неприбуття працівника до місця роботи - довідку про це адміністрації підприємства.

22. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ, ЯКА ЗАЛИШАЛАСЬ ЗА ЗВІЛЬНЕНИМИ ПРАЦІВНИКАМИ ДЕРЖАВНИХ, КООПЕРАТИВНИХ І ГРОМАДСЬКИХ УСТАНОВ, ПІДПРИЄМСТВ ТА ОРГАНІЗАЦІЙ ЗА ПРИВЛАСНЕНЕ, ВТРАЧЕНЕ АБО ЗІПСОВАНЕ МАЙНО, СПЕЦОДЯГ, ІНСТРУМЕНТ, ПРИЛАДДЯ ТА ІНШЕ, А ТАКОЖ ЗА ОДЕРЖАНЕ НИМИ І НЕ ПОВЕРНЕНЕ СПЕЦІАЛЬНЕ ОБМУНДИРУВАННЯ, ПРОВАДИТЬСЯ

на підставі:

підписаної керівництвом установи або підприємства довідки про суму, яку слід стягти, і доданої до неї:

а) розписки працівника про те, що він дійсно одержав майно, вартість якого з нього стягується, або

б) засвідченої місцевою профорганізацією виписки з книги підприємства або установи про видані спецодяг, обмундирування, інструмент, прилади.

23. СТЯГНЕННЯ ШКОДИ, ЯКА ЗАВДАНА ОЩАДНИМ КАСАМ ЇХ ПРАЦІВНИКАМИ І ЗАЛИШИЛАСЬ НЕПОКРИТОЮ ПРИ ЇХ ЗВІЛЬНЕННІ, ПІСЛЯ ЗРОБЛЕНИХ АДМІНІСТРАЦІЄЮ КАСИ ВІДРАХУВАНЬ З НАЛЕЖНИХ ЇМ ПРИ ЗВІЛЬНЕННІ СУМ ПРОВАДИТЬСЯ

на підставі:

підписаної адміністрацією ощадної каси довідки з зазначенням суми, яку слід стягнути.

24. СТЯГНЕННЯ ОРГАНАМИ ЗВ'ЯЗКУ З СВОЇХ ПРАЦІВНИКІВ ЗБИТКІВ ЗА ВТРАТУ, НЕДОСТАЧУ, ПОШКОДЖЕННЯ І ПРОСТРОЧКУ ДОСТАВКИ ПОШТОВИХ ВІДПРАВЛЕНЬ, ЯКІ СТАЛИСЯ З ЇХ ВИНИ, ПРОВАДИТЬСЯ

на підставі:

підписаної адміністрацією органу зв'язку довідки з зазначенням суми, яку слід стягнути.

25. СТЯГНЕННЯ З МАТЕРІАЛЬНО ВІДПОВІДАЛЬНИХ ПРАЦІВНИКІВ ДЕРЖАВНИХ, КООПЕРАТИВНИХ І ГРОМАДСЬКИХ ОРГАНІЗАЦІЙ, ПІДПРИЄМСТВ І УСТАНОВ ЗАБОРГОВАНОСТІ ЗА ДРІБНІ НЕДОСТАЧІ В РАЗІ ЗВІЛЬНЕННЯ ЦИХ ПРАЦІВНИКІВ І ВИДАЧІ НИМИ ЗОБОВ'ЯЗАНЬ ПРО ПОГАШЕННЯ ЗАЗНАЧЕНОЇ ЗАБОРГОВАНОСТІ ПРОВАДИТЬСЯ

на підставі:

а) підписаної адміністрацією організації, підприємства або установи довідки про суму, яку належить стягнути;

б) письмового зобов'язання працівника.

VIII.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ, ЩО ВИПЛИВАЄ З ВІДНОСИН, ЗВ'ЯЗАНИХ З АВТОРСЬКИМ ПРАВОМ

26. СТЯГНЕННЯ АВТОРСЬКОГО ГОНОРАРУ ЗА ПРИЛЮДНЕ ВИКОНАННЯ ДРАМАТИЧНИХ, МУЗИЧНИХ І МУЗИЧНО-ДРАМАТИЧНИХ ТВОРІВ ПРОВАДИТЬСЯ

на підставі:

розрахункової відомості, підписаної керівництвом і головним (старшим) бухгалтером видовищного підприємства та за його печаттю, з зазначенням суми нарахованого авторського гонорару.

26-а. Стягнення заборгованості Управлінню захисту авторських прав по сплаченому авторському гонорару за видання літературно-художніх творів, праць з літературознавства і критики, а також за перше прилюдне виконання неопублікованого твору й за написані на замовлення літературні сценарії, провадиться на підставі розрахункової довідки, підписаної керівником і головним (старшим) бухгалтером видавництва, кіностудії, студії радіомовлення і телебачення та за їх печаттю, з зазначенням сум нарахованого авторського гонорару.

( Перелік доповнено пунктом 26-а згідно з Постановою Ради Міністрів УРСР N 310 ( 310-68-п ) від 21.06.68 )

27. СТЯГНЕННЯ АВТОРСЬКОГО ГОНОРАРУ ЗА ВІДТВОРЕННЯ І ВИДАННЯ ТВОРІВ ОБРАЗОТВОРЧОГО МИСТЕЦТВА (ЖИВОПИСУ, СКУЛЬПТУРИ, ГРАФІКИ), ЩО ПІДЛЯГАЄ ВНЕСЕННЮ УПРАВЛІННЮ ОХОРОНИ АВТОРСЬКИХ ПРАВ СПІЛКИ ХУДОЖНИКІВ СРСР, ПРОВАДИТЬСЯ

на підставі:

розрахункової відомості, підписаної керівництвом і головним (старшим) бухгалтером установи (підприємства, організації) і за її печаттю, з зазначенням суми заборгованості.

28. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ЛІТЕРАТУРНОМУ ФОНДУ ПРОВАДИТЬСЯ

на підставі:

розрахункової відомості, підписаної керівництвом і головним (старшим) бухгалтером видавництва (чи видовищного підприємства) і за його печаттю, з зазначенням суми заборгованості.

28-а. Стягнення заборгованості Журналістському фонду СРСР провадиться на підставі розрахункової відомості, підписаної керівництвом і головним (старшим) бухгалтером установи (організації) і за її печаттю, з зазначенням суми заборгованості. ( Перелік доповнено пунктом 28-а згідно з Постановою Ради Міністрів УРСР N 124 ( 124-72-п ) від 10.03.72 )

29. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ МУЗИЧНОМУ ФОНДУ СРСР ПРОВАДИТЬСЯ

на підставі:

розрахункової відомості, підписаної керівництвом і головним (старшим) бухгалтером видавництва (чи видовищного підприємства) і за його печаттю, з зазначенням суми заборгованості.

30. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ХУДОЖНЬОМУ ФОНДУ СРСР ПРОВАДИТЬСЯ

на підставі:

розрахункової відомості, підписаної керівництвом і головним (старшим) бухгалтером установи (організації або підприємства), для якої виконано художню роботу, і за її печаттю, з зазначенням суми заборгованості.

31. СТЯГНЕННЯ НАРАХУВАНЬ І ВНЕСКІВ В ДОХОД АРХІТЕКТУРНОГО ФОНДУ СПІЛКИ АРХІТЕКТОРІВ СРСР ПРОВАДИТЬСЯ

на підставі:

розрахункової відомості, підписаної керівництвом і головним (старшим) бухгалтером Архітектурного фонду Спілки архітекторів СРСР, та за його печаттю, з зазначенням суми заборгованості.

IX.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ПО АБОНЕНТНІЙ ПЛАТІ ЗА КОРИСТУВАННЯ ТРАНСЛЯЦІЙНИМИ РАДІОТОЧКАМИ І ПО ШТРАФАХ ЗА САМОВІЛЬНЕ ВЛАШТУВАННЯ РАДІОТОЧОК ТА ПЕНІ ЗА ПРОСТРОЧКУ ВНЕСЕННЯ АБОНЕНТНОЇ ПЛАТИ, А ТАКОЖ СТЯГНЕННЯ ПРОСТРОЧЕНОЇ АБОНЕНТНОЇ ПЛАТИ ЗА КОРИСТУВАННЯ ТЕЛЕФОНОМ

32. СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ПО АБОНЕНТНІЙ ПЛАТІ ЗА КОРИСТУВАННЯ ТРАНСЛЯЦІЙНИМИ РАДІОТОЧКАМИ, А ТАКОЖ ПО ШТРАФАХ ЗА САМОВІЛЬНЕ ВЛАШТУВАННЯ РАДІОТОЧОК І ПЕНІ ЗА ПРОСТРОЧКУ ВНЕСЕННЯ АБОНЕНТНОЇ ПЛАТИ ПРОВАДИТЬСЯ

на підставі:

а) копії надісланого боржникові повідомлення про суму заборгованості по абонентній платі та про строки її уплати;

б) відмітки органу зв'язку про вручення повідомлення боржникові або про відмову боржника прийняти повідомлення;

в) копії акта про порушення боржником встановленого порядку користування радіоточкою і

г) копії постанови органу зв'язку про накладення штрафу.

_______________ Примітка. Копії акта і постанови, передбачені пунктами "в" і "г", подаються нотаріусу тільки у випадках стягнення штрафу за несвоєчасну реєстрацію або самовільне влаштування радіоточки.

33. СТЯГНЕННЯ ПРОСТРОЧЕНОЇ АБОНЕНТНОЇ ПЛАТИ ЗА КОРИСТУВАННЯ ТЕЛЕФОНОМ ПРОВАДИТЬСЯ

на підставі:

а) підписаної адміністрацією телефонної станції виписки з рахунку (картки) абонента про суму заборгованості;

б) розписки боржника про одержання рахунку, або акта про відмову боржника від одержання рахунку.

X.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ПО ЧЕРГОВИХ ПЛАТЕЖАХ З БАТЬКІВ ЗА УТРИМАННЯ ДІТЕЙ В ДИТЯЧИХ ЗАКЛАДАХ

34. СТЯГНЕННЯ З БАТЬКІВ АБО З ОСІБ, ЩО ЇХ ЗАМІНЯЮТЬ, ЗАБОРГОВАНОСТІ ПО ЧЕРГОВИХ ПЛАТЕЖАХ ЗА УТРИМАННЯ ДІТЕЙ В ДИТЯЧИХ ЯСЛАХ, ДИТЯЧИХ САДКАХ, БУДИНКАХ ДИТИНИ, ШКОЛАХ-ІНТЕРНАТАХ І СПЕЦІАЛЬНИХ ШКОЛАХ ПРОВАДИТЬСЯ

на підставі:

виписки з особового рахунку на ім'я батька чи особи, яка його заміняє, з відміткою про непогашення заборгованості після письмового попередження про потребу погашення заборгованості в двотижневий строк або з актом про відмову батька чи особи, яка його заміняє, від прийняття попередження.

35. СТЯГНЕННЯ З БАТЬКІВ СУМ ЗАБОРГОВАНОСТІ ПО ЧЕРГОВИХ ПЛАТЕЖАХ ЗА УТРИМАННЯ ЇХ ДІТЕЙ У ВИХОВНИХ КОЛОНІЯХ ДЛЯ НЕПОВНОЛІТНІХ ПРОВАДИТЬСЯ

на підставі:

а) копії постанови комісії в справах неповнолітніх про встановлення розміру щомісячної плати батьків;

б) довідки районного (міського) фінансового відділу про суму заборгованості;

в) розписки одного з батьків про одержання рахунку, або акта про відмовлення цієї особи прийняти рахунок.

XI.

Стягнення заборгованості за вимогами державних або громадських бібліотек за неповернуті чи зіпсовані книги

36. Стягнення за вимогами державних або громадських бібліотек п'ятикратної вартості неповернутих чи зіпсованих читачами книг провадиться

на підставі:

а) документа, який встановлює, що читач одержав книгу з бібліотеки;

б) підписаної керівником бібліотеки довідки про зазначену в інвентарній книзі номінальну вартість неповернутої чи зіпсованої книги та про відмову читача повернути до бібліотеки таку ж саму або іншу рівноцінну книгу чи сплатити її п'ятикратну вартість.

( Розділ XI в редакції Постанови Ради Міністрів УРСР N 146 ( 146-73-п ) від 26.03.73 )

XII.

СТЯГНЕННЯ ЗАБОРГОВАНОСТІ ЗА ВИМОГАМИ ОРГАНІВ МІНІСТЕРСТВА ОХОРОНИ ГРОМАДСЬКОГО ПОРЯДКУ

37. СТЯГНЕННЯ ВИПРАВНО-ТРУДОВИМИ ОРГАНАМИ СУМ, ВІДРАХОВАНИХ ПІДПРИЄМСТВАМИ, УСТАНОВАМИ І ОРГАНІЗАЦІЯМИ ІЗ ЗАРОБІТНОЇ ПЛАТИ ОСІБ, ЯКІ ВІДБУВАЮТЬ ВИПРАВНІ РОБОТИ ПО МІСЦЮ ЇХ ПРАЦІ (СЛУЖБИ), ЯКЩО ЦІ СУМИ НЕ ПЕРЕРАХОВАНІ ВИПРАВНО-ТРУДОВИМ ОРГАНАМ ПРОТЯГОМ 10 ДНІВ З ДНЯ ВИПЛАТИ ЗАСУДЖЕНОМУ ЗАРОБІТНОЇ ПЛАТИ, ПРОВАДИТЬСЯ

на підставі:

а) рахунку виправно-трудового органу на належну суму відрахувань;

б) копії листа підприємства, установи або організації з підтвердженням, що засуджений дійсно працює в даному підприємстві, установі, організації, з зазначенням розміру одержуваного ним місячного заробітку, проценту відрахувань з його зарплати і номера розрахункового рахунку підприємства, установи, організації в банку.

38. Стягнення з громадян вартості медичної допомоги, наданої у витверезнику, провадиться на підставі:

копії рахунку витверезника на суму, яку боржник повинен сплатити за подану йому медичну допомогу, з його розпискою про одержання рахунку або з відміткою про його відмову від одержання такого.

( Пункт 38 в редакції Постанови Ради Міністрів УРСР N 578 ( 578-70-п ) від 10.11.70 )

XIII.

Стягнення заборгованості за вимогами органів військового управління

( Назва розділу XIII в редакції Постанови Ради Міністрів УРСР N 271 ( 271-72-п ) від 08.06.72 )

39. Стягнення залишку заборгованості з військовослужбовця, притягнутого до матеріальної відповідальності, який на день звільнення в запас чи відставку не відшкодував заподіяної ним державі шкоди, провадиться на підставі: довідки командування військової частини, з'єднання, установи або учбового закладу про суму, яку слід стягнути з військовослужбовця.

39-а. Стягнення з прапорщиків і мічманів при звільненні їх з дійсної військової служби у зв'язку з засудженням за скоєні злочини (в тому числі у зв'язку з засудженням умовно) і за проступки, які дискредитують звання військовослужбовця, раніше строку, на який вони зараховані на дійсну військову службу, одноразової допомоги на первісне обзаведення і вартості виданого їм обмундирування в сумі, обчисленій пропорціонально часу, що залишився до закінчення строку служби (строків носіння обмундирування), провадиться на підставі:

довідки командування військової частини, з'єднання, установи або учбового закладу про суму, яку слід стягнути з прапорщика чи мічмана.

( Перелік доповнено пунктом 39-а згідно з Постановою Ради Міністрів УРСР N 271 ( 271-72-п ) від 08.06.72 )

40. Стягнення заборгованості з військовозобов'язаного, призваного на учбові збори, який не відшкодував заподіяної ним державі шкоди, провадиться на підставі: довідки командування військової частини, з'єднання, установи або учбового закладу про суму, яку слід стягнути з військовозобов'язаного, та письмової згоди військовозобов'язаного на стягнення з нього заборгованості в безспірному порядку.

( Перелік доповнено розділом XIII згідно з Постановою Ради Міністрів УРСР N 832 ( 832-66-п ) від 09.11.66 )

XIV.

Стягнення заборгованості за вимогами лікувальних закладів

( Назва розділу XIV в редакції Постанови Ради Міністрів УРСР N 580 ( 580-74-п ) від 30.12.74 )

41. Стягнення заборгованості за вимогами лікувальних закладів за лікування осіб, яким з метою присікання їх хуліганських чи інших злочинних дій заподіяно тілесні ушкодження, провадиться на підставі:

а) виписки з постанови органів дізнання або попереднього слідства, або вироку чи ухвали суду, що підтверджує вчинення боржником хуліганських чи інших злочинних дій;

б) довідки лікувального закладу про суму заборгованості, підписаної його керівником і головним (старшим) бухгалтером.

( Перелік доповнено розділом XIV згідно з Постановою Ради Міністрів УРСР N 492 ( 492-69-п ) від 20.08.69 )

41-а. Стягнення заборгованості за медичне обслуговування у спеціалізованих прийомних відділеннях з осіб, які дістали травми в стані алкогольного сп'яніння або гострого алкогольного психозу, а також осіб, які знаходилися у стані гострого алкогольного отруєння, провадиться на підставі виданої спеціалізованим прийомним відділенням копії рахунку на суму, яку боржник повинен сплатити за медичне обслуговування, з його розпискою про одержання рахунку або з відміткою про його відмову від одержання такого.

( Перелік доповнено пунктом 41-а згідно з Постановою Ради Міністрів УРСР N 580 ( 580-74-п ) від 30.12.74 )

XV.

Стягнення заборгованості за вимогами театрально-видовищних підприємств і театральних кас.

42. Стягнення заборгованості з позаштатних уповноважених по розповсюдженню квитків театрально-видовищних підприємств (театрів, концертних організацій, цирків, художніх колективів тощо) і театральних кас за одержані для реалізації квитки, в разі видачі зобов'язання про погашення заборгованості, провадиться

на підставі:

а) довідки театрально-видовищного підприємства або театральної каси про суму заборгованості, підписаної керівництвом і головним (старшим) бухгалтером;

б) виписки з особового рахунку позаштатного уповноваженого по розповсюдженню театральних квитків, підписаного головним (старшим) бухгалтером театрально-видовищного підприємства або театральної каси;

в) виписки з договору між театрально-видовищним підприємством або театральною касою і позаштатним уповноваженим про матеріальну відповідальність уповноваженого;

г) письмового зобов'язання уповноваженого про погашення заборгованості.

( Перелік доповнено розділом XV згідно з Постановою Ради Міністрів УРСР N 578 ( 578-70-п ) від 10.11.70 )
