КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 лютого 2010 р. N 277-р Київ

Про проведення комплексної перевірки Київської міської державної адміністрації

Зважаючи на численні скарги суб'єктів господарювання щодо недотримання посадовими особами Київської міської державної адміністрації вимог Конституції ( 254к/96-ВР ) та законів України, актів Президента України, Кабінету Міністрів України, інших органів виконавчої влади під час прийняття рішень, пов'язаних з реалізацією регуляторної політики, будівництвом, розвитком транспорту, забезпеченням надання ритуальних послуг, розміщенням реклами, малих архітектурних форм, орендою комунального майна, землі, здійсненням дозвільних процедур, благоустроєм міста, регулюванням цін та ціноутворенням, керуючись статтею 30 Закону України "Про місцеві державні адміністрації" ( 586-14 ) та статтями 19 і 20, частиною четвертою статті 24 Закону України "Про Кабінет Міністрів України" ( 279-17 ):

Міністерству економіки, Міністерству з питань житлово-комунального господарства, Міністерству регіонального розвитку та будівництва, Міністерству транспорту та зв'язку, Державному комітету з питань регуляторної політики та підприємництва, Державному комітету із земельних ресурсів разом з іншими заінтересованими центральними органами виконавчої влади провести з 1 березня по 31 березня 2010 р. комплексну перевірку діяльності Київської міської державної адміністрації щодо виконання вимог Земельного кодексу України ( 2768-14 ); Законів України "Про засади державної регуляторної політики у сфері господарської діяльності" ( 1160-15 ), "Про рекламу" ( 270/96-ВР ), "Про автомобільний транспорт" ( 2344-14 ), "Про дозвільну систему у сфері господарської діяльності" ( 2806-15 ), "Про благоустрій населених пунктів" ( 2807-15 ), "Про архітектурну діяльність" ( 687-14 ), "Про планування і забудову територій" ( 1699-14 ), "Про основи містобудування" ( 2780-12 ), "Про поховання та похоронну справу" ( 1102-15 ), "Про оренду державного та комунального майна" ( 2269-12 ), "Про оренду землі" ( 161-14 ), "Про плату за землю" ( 2535-12 ), "Про ціни і ціноутворення" ( 507-12 ), "Про житлово-комунальні послуги" ( 1875-15 ), "Про внесення змін до деяких законів України щодо спрощення умов ведення бізнесу в Україні" ( 1759-17 ); Указу Президента України від 24 квітня 2009 р.
