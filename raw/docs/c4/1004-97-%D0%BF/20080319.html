Про Урядову комісію з вивчення діяльності ОУН-УПА

{ Із змінами, внесеними згідно з Постановою КМ N 1160 ( 1160-2001-п ) від 13.09.2001 Розпорядженням КМ N 473-р ( 473-2005-р ) від 22.11.2005 Постановою КМ N 1694 ( 1694-2006-п ) від 08.12.2006 }

Кабінет Міністрів України постановляє:

1. Утворити Урядову комісію з вивчення діяльності ОУН-УПА у складі Міністра юстиції (голова Комісії), Міністра закордонних справ, Міністра внутрішніх справ, Міністра фінансів, Міністра освіти і науки, Міністра праці та соціальної політики, Голови Служби безпеки, Голови Державного комітету телебачення і радіомовлення, Голови Українського інституту національної пам'яті, Генерального прокурора України (за згодою), Президента Національної академії наук, директора Інституту історії України Національної академії наук, директора Інституту стратегічних досліджень, голови ради Організації ветеранів України (за згодою), голови Організації українських націоналістів (за згодою), голови Конгресу українських націоналістів (за згодою), голови Всеукраїнського об'єднання ветеранів (за згодою). { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1160 ( 1160-2001-п ) від 13.09.2001, Розпорядженням КМ N 473-р ( 473-2005-р ) від 22.11.2005; в редакції Постанови КМ N 1694 ( 1694-2006-п ) від 08.12.2006 }

Функції робочого апарату Комісії покласти на Міністерство юстиції.

2. Установити, що завданням Комісії є вивчення питань, пов'язаних з діяльністю ОУН-УПА, і підготовка історично та юридичне обгрунтованих висновків щодо її діяльності.

3. Надати голові Комісії право:

створювати в разі потреби за поданням Міністерства юстиції експертні та робочі групи;

залучати до роботи в комісії спеціалістів міністерств, інших органів виконавчої влади, а також представників громадських організацій (за згодою);

одержувати в установленому порядку від центральних та місцевих органів виконавчої влади, інших державних органів, підприємств, установ і організацій необхідні інформацію, документи і матеріали.

4. Фінансове та матеріально-технічне забезпечення роботи з вивчення діяльності ОУН-УПА здійснюється за рахунок коштів, передбачених державним бюджетом.

5. Урядовій комісії з вивчення діяльності ОУН-УПА подати Кабінетові Міністрів України пропозиції про визначення офіційної позиції щодо діяльності ОУН-УПА.

6. Контроль за виконанням цієї постанови покласти на Віце-прем'єр-міністра України Смолія В.А.

Прем'єр-міністр України В. ПУСТОВОЙТЕНКО
