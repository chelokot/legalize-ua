ПОСТАНОВА від 12 травня 2010 р. N 338 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про голову Координаційної ради з питань аграрної політики

Кабінет Міністрів України постановляє:

Затвердити Віце-прем'єр-міністра України Слауту Віктора Андрійовича головою Координаційної ради з питань аграрної політики, утвореної постановою Кабінету Міністрів України від 29 листопада 2001 р. N 1605 ( 1605-2001-п ) (Офіційний вісник України, 2001 р., N 49, ст. 2193; 2008 р., N 21, ст. 599), увільнивши від виконання цих обов'язків Тимошенко Юлію Володимирівну.
