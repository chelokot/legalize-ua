РОЗПОРЯДЖЕННЯ від 4 серпня 2010 р. N 1595-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 77 ( 77-2015-п ) від 04.03.2015 }

Про утворення Міжвідомчої робочої групи з питань будівництва транспортного мостового переходу через Керченську протоку

Утворити Міжвідомчу робочу групу з питань будівництва транспортного мостового переходу через Керченську протоку у складі згідно з додатком.

Надати голові робочої групи право вносити зміни до її складу.

Голові робочої групи затвердити план заходів щодо організації будівництва транспортного мостового переходу через Керченську протоку.
