ПРАВЛІННЯ ПЕНСІЙНОГО ФОНДУ УКРАЇНИ

ПОСТАНОВА

10.01.2007 N 1-2

Зареєстровано в Міністерстві юстиції України 19 січня 2007 р. за N 43/13310

Про внесення змін до постанови правління Пенсійного фонду України від 14.01.2005 N 1-1

{ Із змінами, внесеними згідно з Наказом Міністерства аграрної політики та продовольства

N 601 ( z1314-11 ) від 07.11.2011 Постановою Пенсійного фонду

N 34-1 ( za314-11 ) від 07.11.2011 }

Відповідно до статті 92 Закону України "Про Державний бюджет України на 2007 рік" ( 489-16 ) правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

{ Пункт 1 фактично втратив чинність у зв'язку з втратою чинності Постанови правління Пенсійного фонду N 1-1 ( za127-05 ) від 14.01.2005, до якої вносились зміни } 1. Унести до постанови правління Пенсійного фонду України від 14.01.2005 N 1-1 ( za127-05 ) "Про затвердження Порядку компенсації Пенсійному фонду України різниці між сумою страхових внесків, сплачених за спеціальною ставкою платниками фіксованого сільськогосподарського податку, та страховими внесками, які були б сплачені при застосуванні ставки, визначеної в абзаці другому пункту 1 статті 4 Закону України "Про збір на обов'язкове державне пенсійне страхування", зареєстрованої у Міністерстві юстиції України 01.02.2005 за N 127/10407, такі зміни:

1.1. У преамбулі цифри "2006" замінити цифрами "2007".

{ Пункт 2 фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства аграрної політики N 10 ( z0127-05 ) від 14.01.2005, до якого вносились зміни } 2. Унести до Порядку компенсації Пенсійному фонду України різниці між сумою страхових внесків, сплачених за спеціальною ставкою платниками фіксованого сільськогосподарського податку, та страховими внесками, які були б сплачені при застосуванні ставки, визначеної в абзаці другому пункту 1 статті 4 Закону України "Про збір на обов'язкове державне пенсійне страхування", затвердженого наказом Міністерства аграрної політики України від 14.01.2005 N 10 ( z0127-05 ) та постановою правління Пенсійного фонду України від 14.01.2005 N 1-1 ( za127-05 ) (далі - Порядок), такі зміни:

2.1. У пункті 1 Порядку ( z0127-05 ) цифри "2006" замінити цифрами "2007".

2.2. У додатку 1 до пункту 4 Порядку ( z0127-05 ):

у назві графи 4 цифри "6,46" замінити цифрами "13,28";

у назві графи 5 цифри "31,8" замінити цифрами "33,2".

2.3. У додатку 2 до пункту 5 Порядку ( z0127-05 ):

у рядку 2 цифри "6,46" замінити цифрами "13,28";

у рядку 3 цифри "31,8" замінити цифрами "33,2".

2.4. У додатку 3 до пункту 5 Порядку ( z0127-05 ):

у рядку 2 цифри "6,46" замінити цифрами "13,28";

у рядку 3 цифри "31,8" замінити цифрами "33,2".

3. Департаменту надходження доходів (Литвиненко В.В.) та юридичному управлінню (Рябцева Т.Б.) подати цю постанову на державну реєстрацію до Міністерства юстиції України.
