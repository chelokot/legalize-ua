{ Наказ втратив чинність на підставі Наказу Міністерства охорони здоров'я N 897 ( z0051-07 ) від 27.12.2006 }

Про внесення доповнень до Переліку лікарських засобів, дозволених для застосування в Україні, які відпускаються без рецептів з аптек та їх структурних підрозділів

Відповідно до статей 11 та 21 Закону України "Про лікарські засоби" ( 123/96-ВР ) та з метою упорядкування відпуску лікарських засобів з аптек та їх структурних підрозділів НАКАЗУЮ:

1. Затвердити доповнення до Переліку лікарських засобів, дозволених до застосування в Україні, які відпускаються без рецептів з аптек та їх структурних підрозділів, затвердженого наказом Міністерства охорони здоров'я України від 02.09.2005 N 441 ( z1020-05 ), зареєстрованого в Міністерстві юстиції України 09.09.2005 за N 1020/11300, що додаються.

2. Установити, що відпуск перереєстрованих та нових зареєстрованих лікарських засобів, які не увійшли до доповнення, визначеного в п. 1 цього наказу, здійснюється відповідно до умов відпуску, визначених в інструкціях для медичного застосування та/або листках-вкладишах цих лікарських засобів.

3. Директору Державного фармакологічного центру МОЗ України Чумаку В.Т. забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням наказу покласти на першого заступника Міністра Весельського В.Л.

Міністр Ю.В.Поляченко
