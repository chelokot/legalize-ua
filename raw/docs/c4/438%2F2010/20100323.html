Президент України; Указ, Склад колегіального органу від 23.03.2010 № 438/2010

Про оновлення складу Української частини Українсько-Російської міждержавної комісії

Стан: Втратив чинність

Ідентифікатор: 438/2010

Текст документа від 23.03.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про оновлення складу Української частини Українсько-Російської міждержавної комісії

1. Затвердити персональний склад Української частини Українсько-Російської міждержавної комісії (додається).

2. Секретареві Української частини Українсько-Російської міждержавної комісії внести до 15 квітня 2010 року на затвердження оновлені персональні склади українських частин робочих органів Українсько-Російської міждержавної комісії.

3. Визнати такими, що втратили чинність:

Указ Президента України від 29 січня 2008 року N 58 ( 58/2008 ) "Про оновлення складу Української частини Українсько-Російської міждержавної комісії";

Указ Президента України від 5 травня 2008 року N 415 ( 415/2008 ) "Про оновлення складу Української частини Робочої групи (Секретаріату) з організаційного забезпечення діяльності Українсько-Російської міждержавної комісії";

Указ Президента України від 5 травня 2008 року N 416 ( 416/2008 ) "Про оновлення складу українських частин робочих органів Українсько-Російської міждержавної комісії";

Указ Президента України від 18 грудня 2009 року N 1074 ( 1074/2009 ) "Питання Української частини Українсько-Російської міждержавної комісії";

Указ Президента України від 15 лютого 2010 року N 171 ( 171/2010 ) "Про новий склад Української частини Підкомісії з питань функціонування Чорноморського флоту Російської Федерації та його перебування на території України Українсько-Російської міждержавної комісії".
