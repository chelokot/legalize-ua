14.12.2010 N 545

{ Постанова втратила чинність на підставі Рішення Національного банку N 103-рш ( vr103500-19 ) від 05.02.2019 }

Про внесення змін до постанови Правління Національного банку України від 02.06.2008 N 152

Відповідно до статей 44 і 45 Закону України "Про Національний банк України" ( 679-14 ), розділів II і III Декрету Кабінету Міністрів України від 19.02.93 N 15-93 ( 15-93 ) "Про систему валютного регулювання і валютного контролю" та з метою впорядкування операцій з купівлі-продажу іноземної валюти на міжбанківському валютному ринку України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Унести до постанови Правління Національного банку України від 02.06.2008 N 152 ( v0152500-08 ) "Про встановлення часу функціонування Системи підтвердження угод на міжбанківському валютному ринку України Національного банку України та зміну терміну подання заявки на участь у цій Системі" (зі змінами) такі зміни:

1.1. Пункт 1 доповнити двома новими абзацами такого змісту:

"Уповноважені банки (уповноважені фінансові установи) здійснюють операції в межах самого уповноваженого банку (уповноваженої фінансової установи) з 10.00 до 14.00 за київським часом.

Уповноважені банки (уповноважені фінансові установи) здійснюють операції між собою з 10.00 до 17.00 за київським часом".

1.2. У пункті 2:

цифри "16.00" замінити цифрами "17.00";

доповнити пункт новим абзацом такого змісту:

"Уповноважені банки подають розгорнуту заявку (для проведення операцій з купівлі-продажу безготівкової іноземної валюти з Національним банком України) до Національного банку України до 15.00 за київським часом".

2. Визнати такими, що втратили чинність:

постанову Правління Національного банку України від 18.12.2008 N 435 ( v0435500-08 ) "Про функціонування безготівкового міжбанківського валютного ринку України";

постанову Правління Національного банку України від 09.01.2009 N 4 ( v0004500-09 ) "Про внесення зміни до постанови Правління Національного банку України від 18.12.2008 N 435";

постанову Правління Національного банку України від 16.09.2010 N 427 ( v0427500-10 ) "Про внесення зміни до постанови Правління Національного банку України від 18.12.2008 N 435".

3. Департаменту валютного регулювання (О.А.Щербакова) довести зміст цієї постанови до відома Операційного і територіальних управлінь Національного банку України та банків України для використання в роботі.

4. Контроль за виконанням цієї постанови покласти на Департамент валютного контролю та ліцензування (О.Г.Біланенко).

5. Постанова набирає чинності з 28 грудня 2010 року.

Голова В.С.Стельмах
