Стан: Втратив чинність

Текст документа від 02.11.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 листопада 1998 р. N 1731 Київ

Про доповнення переліку товарів критичного імпорту

Кабінет Міністрів України постановляє:

Доповнити перелік товарів критичного імпорту, затверджений постановою Кабінету Міністрів України від 27 липня 1998 р. N 1145 ( 1145-98-п ) "Про перелік товарів критичного імпорту" (Офіційний вісник України, 1998 р., N 30, ст. 1126) (із змінами і доповненнями, внесеними постановами Кабінету Міністрів України від 30 вересня 1998 р. N 1554 ( 1554-98-п ) та від 1 жовтня 1998 р. N 1569 ( 1569-98-п ) товарами за кодом згідно з ТН ЗЕД 87.03 (транспортні засоби тільки для підрозділів органів внутрішніх справ та податкової міліції, що придбаваються для власних потреб).
