КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 листопада 1993 р. N 945 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1109 ( 1109-2004-п ) від 25.08.2004 )

Питання Міністерства зовнішніх економічних зв'язків

( Із змінами, внесеними згідно з Постановою КМ N 151 ( 151-95-п ) від 28.02.95 )

Відповідно до Указу Президента України від 30 вересня 1993 р. N 412/93 "Про Міністра зовнішніх економічних зв'язків України" Кабінет Міністрів України постановляє:

1. Покласти на Міністерство зовнішніх економічних зв'язків функції забезпечення реалізації державної політики в сфері внутрішньої торгівлі та розроблення механізмів її державного регулювання.

2. ( Пункт 2 втратив чинність на підставі Постанови КМ N 151 ( 151-95-п ) від 28.02.95 ) У зв'язку з покладенням на Міністерство зовнішніх економічних зв'язків додаткових функцій збільшити чисельність його центрального апарату, установивши її у кількості 340 одиниць.

3. ( Пункт 3 втратив чинність на підставі Постанови КМ N 151 ( 151-95-п ) від 28.02.95 ) Дозволити Міністерству зовнішніх економічних зв'язків мати сімох заступників Міністра, в тому числі трьох перших, а також колегію в кількості 11 чоловік.

4. Визнати такими, що втратили чинність, пункти 2 і 3 постанови Кабінету Міністрів України від 10 липня 1993 р. N 530 ( 530-93-п ) "Про вдосконалення структури управління зовнішньоекономічною діяльністю".
