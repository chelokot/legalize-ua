Кабінет Міністрів України; Постанова від 17.06.2009 № 684

Про заходи із забезпечення житлом окремих категорій громадян, які відповідно до законодавства мають право на його отримання

Стан: Дію відновлено

Ідентифікатор: 684-2009-п

Текст документа від 18.11.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 червня 2009 р. N 684 Київ

Про заходи із забезпечення житлом окремих категорій громадян, які відповідно до законодавства мають право на його отримання

{ Дію Постанови зупинено згідно з Указом Президента N 565/2009 ( 565/2009 ) від 22.07.2009 }

{ Відмовлено у відкритті конституційного провадження у справі за конституційним поданням Президента України ( n0021100-09 ) щодо відповідності Конституції України ( 254к/96-ВР ) (конституційності) цієї Постанови Ухвалою Конституційного Суду N 57-у/2009 ( v057u710-09 ) від 18.11.2009 }

З метою забезпечення житлом окремих категорій громадян, які відповідно до законодавства мають право на його отримання, з використанням аукціонного механізму визначення найменшої собівартості 1 квадратного метра новозбудованого житла та здійснення заходів із зменшення впливу світової фінансової кризи на розвиток будівельної галузі Кабінет Міністрів України постановляє:

1. Державній іпотечній установі здійснювати за рахунок коштів, залучених зазначеною Установою під державні гарантії 2007-2008 років:

фінансування у 2009 році завершення будівництва житлових об'єктів із ступенем готовності більш як 70 відсотків та строком здачі в експлуатацію не пізніше 25 грудня 2009 р. шляхом придбання такого житла;

викуп готового житла з подальшою його передачею головним розпорядникам бюджетних коштів для забезпечення житлом окремих категорій громадян, які відповідно до законодавства мають право на його отримання.

2. Головним розпорядникам бюджетних коштів і Міністерству фінансів передбачати під час складання проекту Державного бюджету України на відповідний рік кошти на будівництво (придбання) житла для окремих категорій громадян, які відповідно до законодавства мають право на його отримання, та на компенсаційні виплати Державній іпотечній установі, пов'язані з виконанням пункту 1 цієї постанови.

3. Доповнити пункт 4 Порядку надання державних гарантій за зобов'язаннями Державної іпотечної установи, затвердженого постановою Кабінету Міністрів України від 3 серпня 2006 р. N 1094 ( 1094-2006-п ) (Офіційний вісник України, 2006 р., N 32, ст. 2319; 2007 р., N 26, ст. 1049, N 78, ст. 2893; 2008 р., N 18, ст. 509), абзацом такого змісту:

"Допускається використання Установою запозичень для фінансування заходів із забезпечення житлом окремих категорій громадян, які відповідно до законодавства мають право на його отримання, з використанням аукціонного механізму визначення найменшої собівартості 1 квадратного метра новозбудованого житла або шляхом придбання готового житла з подальшою його передачею головним розпорядникам бюджетних коштів для забезпечення зазначених категорій громадян.".
