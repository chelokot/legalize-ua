Кабінет Міністрів України; Розпорядження від 31.12.1993 № 1202-р

Про утворення міжвідомчої комісії з питань санації державних підприємств

Стан: Втратив чинність

Ідентифікатор: 1202-93-р

Текст документа від 17.10.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 грудня 1993 р. N 1202-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1272 ( 1272-96-п ) від 17.10.96 )

( Із змінами, внесеними згідно з Розпорядженнями КМ N 127-р ( 127-94-р ) від 02.03.94 N 570-р ( 570-95-р ) від 13.09.95 )

З метою координації роботи щодо санації державних підприємств утворити міжвідомчу комісію у складі згідно з додатком.

Міжвідомчій комісії:

разом з Мінекономіки і Мінфіном у двотижневий термін розробити і подати на затвердження Кабінету Міністрів України проект положення про комісію;

розглянути подані міністерствами і відомствами пропозиції про державну підтримку окремих підприємств, визначити її обсяги та форми у погодженні з Планом економічного і соціального розвитку України та Державним бюджетом України на 1994 рік ( 3898-12 ).

Виконуючий обов'язки Прем'єр-міністра України Ю.ЗВЯГІЛЬСЬКИЙ

( Додаток втратив чинність на підставі Розпорядження КМ N 570-р ( 570-95-р ) від 13.09.95 )
