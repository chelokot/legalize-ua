КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 січня 1996 р. N 22 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1294 ( 1294-2011-п ) від 14.12.2011 }

Про внесення змін до постанови Кабінету Міністрів України від 30 листопада 1994 р. N 801

Кабінет Міністрів України постановляє:

Визнати таким, що втратив чинність, пункт 2 постанови Кабінету Міністрів України від 30 листопада 1994 р. N 801 ( 801-94-п ) "Про затвердження Положення про державний геологічний контроль за веденням робіт по геологічному вивченню надр України" (ЗП України, 1995 р., N 2, ст. 34).
