ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 135 від 23.03.99 Зареєстровано в Міністерстві юстиції України 7 квітня 1999 р. за N 217/3510

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про організацію розрахунків за банківськими платіжними картками

{ Із змінами, внесеними згідно з Постановою Національного банку N 268 ( z0840-04 ) від 17.06.2004 }

Відповідно до ст.32 Закону України "Про банки і банківську діяльність" ( 872-12 ) та з метою забезпечення нормативного регулювання порядку здійснення розрахунків за операціями з використанням банківських платіжних карток міжнародних платіжних систем Правління ПОСТАНОВЛЯЄ:

( Пункт 1 втратив чинність на підставі Постанови Національного банку N 268 ( z0840-04 ) від 17.06.2004 )

2. Пункт 4 постанови Правління Національного банку України від 09.11.98 N 468 ( z0754-98 ) "Про авторизацію операцій банківських платіжних карток" викласти в такій редакції:

"Уповноважені банки - члени міжнародних платіжних систем зобов'язані в місячний строк після набуття чинності цією постановою забезпечити авторизацію операцій з використанням банківських платіжних карток (крім AMERICAN EXPRESS, DINERS CLUB та JCB) в грошовій одиниці України. З дати набуття чинності цією постановою уповноваженим банкам України та комерсантам (торговцям) забороняється укладати нові договори (угоди), в яких передбачається авторизація в іноземній валюті.

Вимоги цієї постанови поширюються на здійснення авторизації операцій та розрахунків у грошовій одиниці України за пластиковими картками платіжних систем AMERICAN EXPRESS, DINERS CLUB та JCB з 1 серпня 1999 року. Виручка в іноземній валюті, яка отримана резидентами від здійснення операцій з використанням платіжних карток цих систем, підлягає попередньому зарахуванню на розподільчий рахунок та продажу у повному обсязі згідно із Правилами здійснення операцій на міжбанківському валютному ринку України, затвердженими постановою Правління Національного банку України від 18.03.99 N 127 ( z0171-99 ) та зареєстрованими у Міністерстві юстиції України 18.03.99 за N 171/3464. Якщо надходять кошти в іноземній валюті на користь комерсантів (торговців) за операціями за платіжними картками цих систем, то на поточні рахунки комерсантів (торговців) зараховуються кошти лише в грошовій одиниці України".

3. Постанова набуває чинності через десять днів після її державної реєстрації в Міністерстві юстиції України.
