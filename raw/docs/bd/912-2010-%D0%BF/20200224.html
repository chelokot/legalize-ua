Текст документа від 24.02.2020:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 жовтня 2010 р. N 912 Київ

Про збільшення статутного капіталу Державної іпотечної установи

{ Із змінами, внесеними згідно з Постановою КМ N 1054 ( 1054-2019-п ) від 18.12.2019 }

Відповідно до статті 75 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) Кабінет Міністрів України постановляє:

1. Збільшити статутний капітал Державної іпотечної установи на суму 2000000000 (два мільярди) гривень за рахунок надходжень від державних запозичень.

2. Внести до постанов Кабінету Міністрів України такі зміни:

у пункті 1 постанови Кабінету Міністрів України від 8 жовтня 2004 р. N 1330 ( 1330-2004-п ) "Деякі питання Державної іпотечної установи" (Офіційний вісник України, 2004 р., N 41, ст. 2709; 2009 р., N 50, ст. 1707) цифри і слова "200000000 (двісті мільйонів)" замінити цифрами і словами "2200000000 (два мільярди двісті мільйонів)".

{ Абзац третій пункту 2 втратив чинність на підставі Постанови КМ N 1054 ( 1054-2019-п ) від 18.12.2019 }

3. Міністерству фінансів для забезпечення виконання цієї постанови здійснити:

випуск облігацій внутрішньої державної позики в розмірі 2000000000 (два мільярди) гривень понад обсяги, встановлені додатком N 2 до Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ), з відповідним коригуванням граничного обсягу державного боргу, визначеного статтею 10 зазначеного Закону ( 2154-17 );

на обсяг випущених облігацій внутрішньої державної позики та суму надходжень від державних запозичень коригування відповідних показників фінансування та видатків державного бюджету понад обсяги, встановлені у додатках N 2 і N 3 до зазначеного Закону ( 2154-17 ).

4. Державному казначейству перерахувати кошти, необхідні для збільшення статутного капіталу Державної іпотечної установи відповідно до цієї постанови.
