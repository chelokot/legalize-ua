РОЗПОРЯДЖЕННЯ від 14 січня 2009 р. N 16-р Київ

Про підписання Угоди між Кабінетом Міністрів України та Урядом Чорногорії про взаємну допомогу в митних справах

{ Із змінами, внесеними згідно з Розпорядженням КМ N 621-р ( 621-2009-р ) від 10.06.2009 }
