Про Раду з питань розвитку Національного культурно-мистецького та музейного комплексу "Мистецький арсенал"

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Раду з питань розвитку Національного культурно-мистецького та музейного комплексу "Мистецький арсенал"

{ Указ втратив чинність на підставі Указу Президента N 223/2026 ( 223/2026 ) від 05.03.2026 }

{ Із змінами, внесеними згідно з Указом Президента N 24/2015 ( 24/2015 ) від 19.01.2015 }

Ураховуючи важливу роль Національного культурно-мистецького та музейного комплексу "Мистецький арсенал" у популяризації національного культурного надбання та з метою формування стратегії дальшого розвитку цього культурного закладу, відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Утворити Раду з питань розвитку Національного культурно-мистецького та музейного комплексу "Мистецький арсенал" (далі - Рада) як консультативно-дорадчий орган при Президентові України.

2. Основними завданнями Ради є підготовка та подання Президентові України пропозицій щодо консолідації зусиль мистецької громадськості, забезпечення здійснення узгоджених заходів, спрямованих на дальший розвиток Національного культурно-мистецького та музейного комплексу "Мистецький арсенал" як сучасного загальнонаціонального культурно-просвітницького центру, в тому числі на вирішення в установленому порядку питань стосовно залучення з цією метою інвестицій.
