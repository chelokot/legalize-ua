КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 травня 1993 р. N 321 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 260 ( 260-2019-п ) від 06.03.2019 }

Про зміну цін і тарифів на вугілля, електро- і теплоенергію та послуги зв'язку

( Із змінами, внесеними згідно з Постановами КМ N 416 ( 416-93-п ) від 05.06.93 N 676 ( 676-93-п ) від 30.08.93 )

У зв'язку із зростанням цін на енергоносії, що надходять з інших країн, Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 676 ( 676-93-п ) від 30.08.93 )

2. Дозволити Міністерству економіки вносити зміни (не частіше одного разу на місяць) до тарифів на електро- і теплоенергію, що постачаються споживачам (крім населення), за умови підвищення цін на органічне та ядерне паливо більш як на 20 відсотків.

( Пункт 2 в редакції Постанови КМ N 676 ( 676-93-п ) від 30.08.93 )

3. Установити, що всі споживачі електроенергії за погодженням з енергопостачальником при наявності технічних можливостей мають право переходити на розрахунки за одноставочним тарифом, диференційованим за зонами доби. Зонний тариф визначається виходячи з тарифу групи за прейскурантом, до якої належить споживач.

Міністерству енергетики і електрифікації за погодженням з Міністерством економіки розробити і затвердити до 1 червня 1993 р. порядок розрахунків із споживачами електроенергії за одноставочним тарифом, диференційованим за зонами доби.

4. Ця постанова набуває чинності з 6 травня 1993 року.

( Пункт 4 із змінами, внесеними згідно з Постановою КМ N 416 ( 416-93-п ) від 05.06.93 )
