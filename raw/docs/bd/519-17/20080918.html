Верховна Рада України; Постанова від 18.09.2008 № 519-VI

Про внесення змін до Постанови Верховної Ради України "Про встановлення іменних стипендій Верховної Ради України для найталановитіших молодих учених"

Стан: Чинний

Ідентифікатор: 519-17

Текст документа від 18.09.2008:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про внесення змін до Постанови Верховної Ради України "Про встановлення іменних стипендій Верховної Ради України для найталановитіших молодих учених"

( Відомості Верховної Ради України (ВВР), 2009, N 6, ст.58 )

Верховна Рада України постановляє:

1. Внести до Постанови Верховної Ради України "Про встановлення іменних стипендій Верховної Ради України для найталановитіших молодих учених" ( 774-16 ) (Відомості Верховної Ради України, 2007 р., N 17, ст. 257) такі зміни:

1) пункт 1 викласти у такій редакції:

"1. Заснувати з 2008 року 30 іменних стипендій Верховної Ради України для найталановитіших молодих учених віком до 35 років, які успішно пройшли захист докторської дисертації або підготували матеріали докторської дисертації, що прийняті до розгляду спеціалізованою вченою радою для захисту докторських дисертацій, у розмірі 2 тис. гривень щомісяця кожна.

Стипендії призначаються щороку терміном на один рік";

2) абзаци другий - четвертий пункту 2 Положення про іменні стипендії Верховної Ради України для найталановитіших молодих учених, затвердженого Постановою Верховної Ради України "Про встановлення іменних стипендій Верховної Ради України для найталановитіших молодих учених" ( 774-16 ), замінити одним абзацом такого змісту:

"Щороку призначаються 30 іменних стипендій Верховної Ради України для найталановитіших молодих учених віком до 35 років, які успішно пройшли захист докторської дисертації або підготували матеріали докторської дисертації, що прийняті до розгляду спеціалізованою вченою радою для захисту докторських дисертацій, у розмірі 2 тис. гривень щомісяця кожна".

У зв'язку з цим абзаци п'ятий та шостий вважати відповідно абзацами третім та четвертим.

2. Ця Постанова набирає чинності з дня її прийняття.
