Президент України; Указ від 02.04.2010 № 482/2010

Про ліквідацію Міжвідомчої робочої групи з питань протидії корупції

Стан: Чинний

Ідентифікатор: 482/2010

Текст документа від 02.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про ліквідацію Міжвідомчої робочої групи з питань протидії корупції

Відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Ліквідувати Міжвідомчу робочу групу з питань протидії корупції.

У зв'язку з цим визнати такими, що втратили чинність:

Указ Президента України від 17 квітня 2008 року N 370 ( 370/2008 ) "Про Міжвідомчу робочу групу з питань протидії корупції";

Указ Президента України від 23 січня 2009 року N 35 ( 35/2009 ) "Про внесення змін до складу Міжвідомчої робочої групи з питань протидії корупції".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 2 квітня 2010 року N 482/2010
