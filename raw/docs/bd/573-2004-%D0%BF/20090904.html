ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 29 квітня 2004 р. N 573

ПОЛОЖЕННЯ про Головний обчислювальний центр Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування

{ У назві та тексті Положення слова "Єдиної державної автоматизованої паспортної системи" і абревіатуру "ЄДАПС" замінено відповідно словами "Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування" і абревіатурою "ДІС" згідно з Постановою КМ N 327 ( 327-2006-п ) від 15.03.2006 }

1. Головний обчислювальний центр Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування (далі - Головний обчислювальний центр) є структурним підрозділом ДМС.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 810 ( 810-2009-п ) від 29.07.2009 - дію змін зупинено згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }

2. Основними завданнями Головного обчислювального центру є:

забезпечення автоматизованих процесів оформлення документів, що підтверджують громадянство України;

забезпечення функціонування та адміністрування інтегрованої бази даних центрального рівня Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування (далі - інтегрована база даних);

впровадження комплексної системи захисту інформації Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування (далі - ДІС) і здійснення постійного контролю за дотриманням у ній інформаційної безпеки;

дотримання технологічної дисципліни і вжиття своєчасних заходів для недопущення її порушення;

оновлення нормативно-довідкової інформації ДІС.

3. Головний обчислювальний центр відповідно до покладених на нього завдань забезпечує:

1) функціонування комунікаційної мережі зв'язку ДІС та локальної мережі Головного обчислювального центру;

2) копіювання та збереження копій елементів інтегрованої бази даних центрального рівня;

3) інформаційну взаємодію з вузлами регіонального рівня ДІС та автоматизованими інформаційними системами органів державної влади;

4) взаємодію з Державною податковою адміністрацією у частині визначення/перевірки достовірності ідентифікаційного номера заявника на оформлення документів, що посвідчують особу та підтверджують громадянство України;

5) підготовку персональних даних фізичних осіб для передачі до Державного підприємства "Державний центр персоналізації документів", які після виготовлення документів повертаються до Головного обчислювального центру, та оброблення отриманих від нього повідомлень про виготовлені документи; { Підпункт п'ятий пункту 3 із змінами, внесеними згідно з Постановами КМ N 1723 ( 1723-2004-п ) від 23.12.2004, N 378 ( 378-2005-п ) від 26.05.2005, N 858 ( 858-2007-п ) від 26.06.2007 }

6) оброблення інформаційних повідомлень, що надходять з вузлів регіонального рівня ДІС, стосовно отримання та видачі громадянам документів, що посвідчують особу та підтверджують громадянство України;

7) інформаційне обслуговування зовнішніх користувачів ДІС на їх запити;

8) розроблення плану технічного захисту інформації, здійснення організаційно-технічних заходів захисту інформації;

9) здійснення контролю за дотриманням працівниками Головного обчислювального центру встановленого порядку захисту інформації;

10) організацію і проведення розслідувань випадків порушень інформаційної безпеки та аналіз їх причин, а також вжиття заходів щодо запобігання таким випадкам;

11) функціонування та експлуатацію системи управління комунікаційною мережею зв'язку ДІС;

12) взаємодію та обмін інформацією з вузлами регіонального рівня ДІС;

13) підтримання працездатності комплексу технічних засобів Центру;

14) адміністрування загальносистемного програмного забезпечення Центру;

15) здійснення контролю за використанням операційних систем та загальносистемного програмного забезпечення вузлів регіонального рівня ДІС;

16) організацію підготовки працівників міграційної служби для роботи з підсистемами ДІС на базі навчального центру Системи.

{ Підпункт 16 пункту 3 із змінами, внесеними згідно з Постановою КМ N 810 ( 810-2009-п ) від 29.07.2009 - дію змін зупинено згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }

4. Головний обчислювальний центр має право:

брати участь у вирішенні питань розроблення, впровадження та експлуатації ДІС, систем телекомунікації і зв'язку та технічного захисту інформації;

отримувати в установленому порядку від центральних і місцевих органів виконавчої влади інформацію, необхідну для виконання покладених на нього завдань;

розробляти пропозиції з питань удосконалення технології проектування та управління, впровадження його результатів;

залучати спеціалістів центральних і місцевих органів виконавчої влади, органів місцевого самоврядування, підприємств, установ та організацій (за погодженням з їх керівниками) для розгляду питань, що належать до його компетенції;

представляти ДМС в органах державної влади та інших органах з питань, що стосуються його діяльності. { Абзац шостий пункту 4 із змінами, внесеними згідно з Постановою КМ N 810 ( 810-2009-п ) від 29.07.2009 - дію змін зупинено згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }

5. Головний обчислювальний центр очолює начальник.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 810 ( 810-2009-п ) від 29.07.2009 - дію змін зупинено згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }

6. Структура Головного обчислювального центру і положення про його структурні підрозділи затверджує Голова ДМС.

{ Пункт 6 із змінами, внесеними згідно з Постановою КМ N 810 ( 810-2009-п ) від 29.07.2009 - дію змін зупинено згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }
