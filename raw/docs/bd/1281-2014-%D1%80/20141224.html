КАБІНЕТ МІНІСТРІВ УКРАЇНИ
РОЗПОРЯДЖЕННЯ

від 24 грудня 2014 р. № 1281-р
Київ

Деякі питання діяльності Національної акціонерної компанії “Нафтогаз України” у 2014 році

1. Затвердити фінансовий план та основні показники руху коштів Національної акціонерної компанії “Нафтогаз України” як окремої юридичної особи на 2014 рік, що додаються до оригіналу.

2. Міністерству енергетики та вугільної промисловості, Міністерству фінансів вжити заходів, необхідних для перенесення строку погашення боргових зобов’язань Національної акціонерної компанії “Нафтогаз України” перед публічними акціонерними товариствами “Державний ощадний банк України” та “Державний експортно-імпортний банк України” з 2014 року на майбутні періоди без зменшення суми таких зобов’язань.

3. Рекомендувати публічним акціонерним товариствам “Державний ощадний банк України” та “Державний експортно-імпортний банк України” перенести строк погашення боргових зобов’язань Національної акціонерної компанії “Нафтогаз України” з 2014 року на майбутні періоди без зменшення суми таких зобов’язань.

4. Рекомендувати Національному банку сприяти в реалізації положень пунктів 2 і 3 цього розпорядження.

Прем'єр-міністр України

А.ЯЦЕНЮК
