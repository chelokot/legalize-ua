Стан: Чинний

Ідентифікатор: z1161-07

Текст документа від 03.10.2007:

МІНІСТЕРСТВО ПРОМИСЛОВОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

03.10.2007 N 558

Зареєстровано в Міністерстві юстиції України 11 жовтня 2007 р. за N 1161/14428

Про внесення змін до наказу Міністерства промислової політики України від 15.03.2007 N 104 "Про затвердження Порядку конкурсного відбору інвестиційних проектів підприємств суднобудівної промисловості"

На виконання постанови Кабінету Міністрів України від 14.02.2007 N 221 ( 221-2007-п ) "Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для підтримки підприємств суднобудівної промисловості шляхом здешевлення кредитів", зі змінами, НАКАЗУЮ:

1. Внести до наказу Міністерства промислової політики України від 15.03.2007 N 104 ( z0241-07 ) "Про затвердження Порядку конкурсного відбору інвестиційних проектів підприємств суднобудівної промисловості", зареєстрованого в Міністерстві юстиції України 20.03.2007 за N 241/13508, такі зміни:

1.1. У назві наказу ( z0241-07 ) після слів "інвестиційних проектів" доповнити словами "та бізнес-проектів";

1.2. Пункт 1 наказу ( z0241-07 ) після слів "інвестиційних проектів" доповнити словами "та бізнес-проектів";

1.3. Пункт 2.2 наказу ( z0241-07 ) після слів "інвестиційних проектів" доповнити словами "та бізнес-проектів";

1.4. У Порядку ( z0241-07 ):

1.4.1. У назві Порядку після слів "інвестиційних проектів" доповнити словами "та бізнес-проектів";

1.4.2. Пункт 1 після слів "фондів підприємств суднобудівної промисловості" доповнити словами "та бізнес-проектів, в яких міститься уся інформація про заплановану ними комерційну діяльність щодо будівництва морських, річкових та інших плавучих засобів, очікувані позитивні фінансові результати";

1.4.3. Пункт 2 після слів "Інвестиційні проекти" доповнити словами "та бізнес-проекти";

1.4.4. В абзаці вісім пункту п'ять після слів "інвестиційний проект" доповнити словами "або бізнес-проект";

1.4.5. В абзаці дев'ять пункту п'ять після слів "інвестиційного проекту" доповнити словами "або бізнес-проекту";

1.4.6. Пункт 18 після слів "інвестиційних проектів" доповнити словами "або бізнес-проектів".

2. У встановленому порядку подати наказ на державну реєстрацію до Міністерства юстиції України.

3. Департаменту адміністративно-господарського забезпечення (Горник В.Г.) забезпечити публікацію цього наказу в засобах масової інформації.

4. Контроль за виконанням наказу залишаю за собою.
