Текст документа від 19.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 липня 2010 р. N 1446-р Київ

Про скасування розпоряджень Кабінету Міністрів України від 28 січня 2010 р. N 119, 122 і 124

На виконання постанови Окружного адміністративного суду м. Києва від 23 червня 2010 р. скасувати розпорядження Кабінету Міністрів України від 28 січня 2010 р. N 119 ( 119-2010-р ) "Про введення додатково посади першого заступника Міністра внутрішніх справ України" (Офіційний вісник України, 2010 р., N 11, ст. 551), N 122 ( 122-2010-р ) "Про призначення Луценка Ю.В. першим заступником Міністра внутрішніх справ України", N 124 ( 124-2010-р ) "Про тимчасове покладення виконання обов'язків Міністра внутрішніх справ України на Луценка Ю.В.".

Прем'єр-міністр України М.АЗАРОВ
