Кабінет Міністрів України; Розпорядження від 29.05.1995 № 301-р

Про віднесення посад керівних працівників та спеціалістів апарату органів управління військових формувань до категорій державних службовців

Стан: Втратив чинність

Ідентифікатор: 301-95-р

Текст документа від 03.10.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 травня 1995 p. N 301-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Про віднесення посад керівних працівників та спеціалістів апарату органів управління військових формувань до категорій державних службовців

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 535-р ( 535-2005-р ) від 21.12.2005 N 214-р ( 214-2011-р ) від 23.03.2011 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади керівних працівників та спеціалістів апарату органів управління військових формувань, військових комісаріатів та військових прокуратур до таких категорій державних службовців:

посади начальників управлінь, відділів, відділень, груп та інших структурних підрозділів, їх заступників, головних бухгалтерів та їх заступників помічників начальників управлінь, відділів, відділень, груп та інших структурних підрозділів, спеціалістів управлінь видів Збройних Сил та інших прирівняних до них органів військового управління - до п'ятої категорії; { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 214-р ( 214-2011-р ) від 23.03.2011 }

посади начальників відділів, відділень, груп та інших структурних підрозділів, головних бухгалтерів та їх заступників, помічників начальників відділів, відділень і спеціалістів управлінь оперативних командувань та інших прирівняних до них органів військового управління; спеціалістів військових прокуратур регіонів; начальників відділень, частин, груп, старших помічників, помічників та спеціалістів військового комісаріату Автономної Республіки Крим, обласних, Київського та Севастопольського міських військових комісаріатів - до шостої категорії; ( Абзац третій із змінами, внесеними згідно з Розпорядженням КМ N 535-р ( 535-2005-р ) від 21.12.2005 )

посади начальників відділів, відділень, груп та інших структурних підрозділів, головних бухгалтерів та їх заступників, помічників начальників управлінь, відділів, відділень, груп та інших структурних підрозділів, спеціалістів управлінь територіальних і повітряних командувань, корпусів; спеціалістів військових прокуратур гарнізонів; начальників відділень, частин, груп та інших структурних підрозділів, старших помічників, помічників начальників відділів, відділень, груп та спеціалістів міських і районних військових комісаріатів - до сьомої категорії. ( Абзац четвертий із змінами, внесеними згідно з Розпорядженням КМ N 535-р ( 535-2005-р ) від 21.12.2005 )
