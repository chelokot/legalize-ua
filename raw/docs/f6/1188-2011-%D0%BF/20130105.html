КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 листопада 2011 р. N 1188 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 5 ( 5-2013-п ) від 03.01.2013 }

Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 11 квітня 2011 р. N 381

Кабінет Міністрів України постановляє:

1. Внести зміну до пункту 1 постанови Кабінету Міністрів України від 11 квітня 2011 р. N 381 ( 381-2011-п ) "Питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2011 р., N 27, ст. 1131, N 66, ст. 2548), замінивши цифри "592" цифрами "607".

2. Міністерству фінансів під час доопрацювання проекту Державного бюджету України на 2012 рік передбачити асигнування на утримання працівників Секретаріату Кабінету Міністрів України виходячи із затвердженої граничної чисельності.

Прем'єр-міністр України М.АЗАРОВ
