N 9 від 04.02.2002 Зареєстровано в Міністерстві м.Київ юстиції України 19 лютого 2002 р. за N 161/6449

( Наказ втратив чинність на підставі Наказу Державного комітету архівів N 138 ( z1469-05 ) від 21.11.2005 )

Про нову редакцію додатків до наказу Держкомархіву України від 05.05.2001 N 37

Відповідно до постанови Кабінету Міністрів України від 10.01.2002 N 18 ( 18-2002-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Додатки 1-6 до наказу Держкомархіву України від 05.05.2001 N 37 ( z0410-01 ) "Про впорядкування умов оплати праці працівників архівних установ", зареєстрованого в Міністерстві юстиції України 14.05.2001 за N 410/5601, викласти в новій редакції, що додається.

2. Керівникам архівних установ привести штатні розписи у відповідність до цього наказу та ліміту бюджетних коштів на оплату праці.

3. Ці умови застосовуються з 01.02.2002.

Голова Державного комітету Р.Я.Пиріг
