КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 2007 р. N 343 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для погашення зобов'язань Державною службою з охорони прав на сорти рослин за кредитами, наданими з державного бюджету за рахунок коштів, залучених від міжнародних фінансових організацій на розвиток насінництва

{ Установити, що кошти, передбачені у державному бюджеті ( 107-17 ) Міністерству аграрної політики за програмою "Погашення зобов'язань Державною службою з охорони прав на сорти рослин за кредитами, наданими з державного бюджету за рахунок коштів, залучених від міжнародних фінансових організацій на розвиток насінництва", використовуються у 2008 році відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 50 ( 50-2008-п ) від 13.02.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для погашення зобов'язань Державною службою з охорони прав на сорти рослин за кредитами, наданими з державного бюджету за рахунок коштів, залучених від міжнародних фінансових організацій на розвиток насінництва, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 22

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 1 березня 2007 р. N 343

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для погашення зобов'язань Державною службою з охорони прав на сорти рослин за кредитами, наданими з державного бюджету за рахунок коштів, залучених від міжнародних фінансових організацій на розвиток насінництва

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Мінагрополітики за програмою "Погашення зобов'язань Державною службою з охорони прав на сорти рослин за кредитами, наданими з державного бюджету за рахунок коштів, залучених від міжнародних фінансових організацій на розвиток насінництва" (далі - бюджетні кошти).

2. Мінагрополітики перераховує відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством, Держсортслужбі бюджетні кошти для виконання зобов'язань за кредитом, наданим згідно із Законом України "Про ратифікацію Угоди про надання позики (Проект з розвитку насінництва) між Україною та Міжнародним банком реконструкції та розвитку" ( 265/96-ВР ) на оснащення установ Держсортслужби лабораторним обладнанням і селекційною технікою.

Бюджетні кошти спрямовуються Держсортслужбі для погашення основного боргу та виконання зобов'язань з виплати відсотків за користування кредитом і плати за надання гарантій та позик, отриманих за рахунок коштів, що залучені державою для реалізації проекту. { Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 50 ( 50-2008-п ) від 13.02.2008 }

3. Держсортслужба складає акт звірення даних щодо заборгованості перед державним бюджетом з погашення та обслуговування кредиту.

4. На підставі акта звірення Держсортслужба погашає зобов'язання за кредитом шляхом перерахування бюджетних коштів на відповідні рахунки, відкриті у Державному казначействі.

5. Держсортслужба звітує Мінагрополітики про використання бюджетних коштів за період, в якому відповідно до умов Угоди ( 996_664 ), зазначеної в пункті 2 цього Порядку, передбачено погашення зобов'язань за кредитом.

6. Мінагрополітики подає до 20 числа місяця, наступного за звітним періодом, передбаченим пунктом 5 цього Порядку, інформацію Мінфіну про стан виконання результативних показників відповідно до паспорта бюджетної програми.

7. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
