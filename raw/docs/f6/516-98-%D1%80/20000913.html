Текст документа від 13.09.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 липня 1998 р. N 516-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 356-р ( 356-2000-р ) від 13.09.2000 )

Про закріплення у державній власності пакету акцій ДАЕК "Кіровоградобленерго"

Відповідно до пункту 14 Державної програми приватизації на 1998 рік ( 124/98-ВР ) закріпити у державній власності на 3 роки пакет акцій у розмірі 25 відсотків статутного фонду плюс одна акція ДАЕК "Кіровоградобленерго".
