Кабінет Міністрів України; Постанова від 11.10.2006 № 1420

Про ціни на природний газ, що використовується підприємствами комунальної теплоенергетики для надання послуг з опалення та гарячого водопостачання населенню, та запровадження соціально орієнтованих диференційованих цін на природний газ для населення

Стан: Втратив чинність

Ідентифікатор: 1420-2006-п

Текст документа від 01.01.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 жовтня 2006 р. N 1420 Київ

Про ціни на природний газ, що використовується підприємствами комунальної теплоенергетики для надання послуг з опалення та гарячого водопостачання населенню, та запровадження соціально орієнтованих диференційованих цін на природний газ для населення

{ Із змінами, внесеними згідно з Постановою КМ N 1697 ( 1697-2006-п ) від 08.12.2006 }

{ У тексті постанови слово "оптової" виключено згідно з Постановою КМ N 1697 ( 1697-2006-п ) від 08.12.2006 }

З метою надійного забезпечення населення природним газом та послугами з опалення та гарячого водопостачання, посилення соціального захисту малозабезпечених верств населення у зв'язку із зростанням вартості імпортованого природного газу Кабінет Міністрів України постановляє:

1. Міністерству палива та енергетики, Міністерству економіки, Міністерству будівництва, архітектури та житлово-комунального господарства, Міністерству фінансів, Національній комісії регулювання електроенергетики, Національному агентству з питань забезпечення використання енергетичних ресурсів, НАК "Нафтогаз України" підготувати:

1) до 20 листопада 2006 р. вичерпну інформацію про обсяги споживання природного газу для встановлення граничного рівня ціни на природний газ, що використовується підприємствами комунальної теплоенергетики для надання послуг з опалення та гарячого водопостачання населенню, та соціально орієнтованих роздрібних цін на природний газ для населення, диференційованих залежно від обсягів споживання;

2) до 1 грудня 2006 р. пропозиції стосовно внесення змін до нормативно-правових актів з урахуванням запровадження:

{ Абзац другий підпункту 2 пункту 1 виключено на підставі Постанови КМ N 1697 ( 1697-2006-п ) від 08.12.2006 }

роздрібних цін на природний газ для населення, диференційованих залежно від обсягів споживання;

граничного рівня ціни на природний газ, що використовується підприємствами комунальної теплоенергетики для надання послуг з опалення та гарячого водопостачання населенню.

{ Пункт 2 виключено на підставі Постанови КМ N 1697 ( 1697-2006-п ) від 08.12.2006 }

{ Пункт 3 виключено на підставі Постанови КМ N 1697 ( 1697-2006-п ) від 08.12.2006 }

4. Рекомендувати Національній комісії регулювання електроенергетики за погодженням з Міністерством економіки на підставі інформації про обсяги споживання природного газу, підготовленої відповідно до пункту 1 цієї постанови, установити:

{ Абзац другий пункту 4 виключено на підставі Постанови КМ N 1697 ( 1697-2006-п ) від 08.12.2006 }

роздрібні ціни на природний газ для населення, диференційовані залежно від обсягів споживання, починаючи з граничного рівня ціни 339 гривень за 1000 куб. метрів для населення, яке споживає найменші встановлені річні обсяги газу. { Абзац третій пункту 4 із змінами, внесеними згідно з Постановою КМ N 1697 ( 1697-2006-п ) від 08.12.2006 }

{ Абзац пункту 4 виключено на підставі Постанови КМ N 1697 ( 1697-2006-п ) від 08.12.2006 }

5. Міністерству праці та соціальної політики, Міністерству економіки, Міністерству будівництва, архітектури та житлово-комунального господарства разом з іншими заінтересованими органами виконавчої влади опрацювати питання щодо:

встановлення з 1 жовтня 2007 р. соціальних норм користування житлово-комунальними послугами, природним газом та електроенергією;

запровадження упереджувальних заходів щодо соціального захисту населення з питань оплати житлово-комунальних послуг для сімей, що складаються тільки з пенсіонерів, шляхом встановлення для таких сімей розміру витрат на оплату житлово-комунальних послуг, придбання скрапленого газу, твердого палива на рівні 15 відсотків їх сукупного доходу.

{ Пункт 6 виключено на підставі Постанови КМ N 1697 ( 1697-2006-п ) від 08.12.2006 }
