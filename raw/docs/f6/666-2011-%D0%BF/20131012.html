ПОСТАНОВА від 22 червня 2011 р. N 666 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 718 ( 718-2013-п ) від 11.09.2013 }

Про внесення змін до постанови Кабінету Міністрів України від 11 жовтня 2010 р. N 947

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 11 жовтня 2010 р., N 947 ( 947-2010-п ) "Про запровадження електронної соціальної картки" (Офіційний вісник України, 2010 р., N 79, ст. 2802, N 86, ст. 3019, N 94, ст. 3343) такі зміни:

пункт 3 викласти в такій редакції:

"3. Чернівецькій обласній державній адміністрації забезпечити проведення протягом 2011 року експерименту із створення інформаційно-аналітичної системи регіонального управління.";

пункти 4 і 5 виключити.
