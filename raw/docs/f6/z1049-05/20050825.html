Про визнання такою, що втратила чинність, постанови НКРЕ від 25.02.97 N 100

Реєстрація: Мін'юст України від 15.09.2005 № 1049/11329

Стан: Чинний

Ідентифікатор: z1049-05

Текст документа від 25.08.2005:

НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

25.08.2005 N 696

Зареєстровано в Міністерстві юстиції України 15 вересня 2005 р. за N 1049/11329

Про визнання такою, що втратила чинність, постанови НКРЕ від 25.02.97 N 100

Відповідно до Законів України "Про електроенергетику" ( 575/97-ВР ), "Про засади державної регуляторної політики у сфері господарської діяльності" ( 1160-15 ), Указу Президента України від 21.04.98 N 335 ( 335/98 ) "Питання Національної комісії регулювання електроенергетики України", Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення регуляторної політики" Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Визнати такою, що втратила чинність, постанову НКРЕ від 25.02.97 N 100 ( z0073-97 ) "Про встановлення тарифу на транспортування електричної енергії", зареєстровану в Міністерстві юстиції України 07.03.97 за N 73/1877.

2. Управлінню цінової політики в електроенергетиці забезпечити подання цієї постанови до Міністерства юстиції України в установленому законодавством порядку.

Голова Комісії В.Кальченко

ПОГОДЖЕНО:

В.о. Голови Державного комітету України з питань регуляторної політики та підприємництва К.О.Ващенко
