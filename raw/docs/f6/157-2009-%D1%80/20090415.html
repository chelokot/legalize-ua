Кабінет Міністрів України; Розпорядження від 11.02.2009 № 157-р

Деякі питання переробки та реалізації військового майна

Стан: Чинний

Ідентифікатор: 157-2009-р

Текст документа від 15.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 лютого 2009 р. N 157-р Київ

Деякі питання переробки та реалізації військового майна

{ Із змінами, внесеними згідно з Розпорядженням КМ N 414-р ( 414-2009-р ) від 15.04.2009 }

1. Погодитися з пропозицією МВС та Міноборони щодо відчуження в установленому порядку за залишковою вартістю казенному науково-виробничому об'єднанню "Форт" МВС України військового майна Збройних Сил (стрілецької зброї), що придатне для подальшого використання, але не може бути застосоване в повсякденній діяльності військ, для проведення робіт з модернізації такого майна, переробки його в мисливську зброю, пристрої для відстрілу патронів, споряджених гумовими чи аналогічними за своїми властивостями метальними снарядами несмертельної дії, і масогабаритні макети.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 414-р ( 414-2009-р ) від 15.04.2009 }

2. Надати казенному науково-виробничому об'єднанню "Форт" МВС України повноваження щодо реалізації масогабаритних макетів на внутрішньому ринку.

Прем'єр-міністр України Ю.ТИМОШЕНКО
