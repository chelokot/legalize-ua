Кабінет Міністрів України; Розпорядження від 15.12.2010 № 2233-р

Про встановлення строку виконання операцій з капітального ремонту машин колійних самохідних рейкозварювальних ПРСМ-3 на митній території України

Стан: Втратив чинність

Ідентифікатор: 2233-2010-р

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 грудня 2010 р. N 2233-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання операцій з капітального ремонту машин колійних самохідних рейкозварювальних ПРСМ-3 на митній території України

1. Відповідно до частини третьої статті 232 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити строк виконання операцій з капітального ремонту машин колійних самохідних рейкозварювальних ПРСМ-3 за кодом згідно з УКТЗЕД 8604 00 00 00 ( 2371г-14 ) на митній території України 270 днів.

2. Установити, що розпочаті та не завершені на момент набрання чинності цим розпорядженням операції з капітального ремонту виконуються у строк, передбачений пунктом 1 цього розпорядження.

3. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України М.АЗАРОВ
