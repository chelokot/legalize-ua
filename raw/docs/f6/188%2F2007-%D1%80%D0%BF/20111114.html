Президент України; Розпорядження від 27.08.2007 № 188/2007-рп

Про внесення змін до складу української делегації Спільної українсько-молдовської демаркаційної комісії

Стан: Втратив чинність

Ідентифікатор: 188/2007-рп

Текст документа від 14.11.2011:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 1008/2011 ( 1008/2011 ) від 31.10.2011 }

Про внесення змін до складу української делегації Спільної українсько-молдовської демаркаційної комісії

Увести до складу української делегації Спільної українсько-молдовської демаркаційної комісії, затвердженого Розпорядженням Президента України від 13 березня 2006 року N 45 ( 45/2006-рп ) "Про новий склад української делегації Спільної українсько-молдовської демаркаційної комісії", МАКАРЕНКА Івана Дмитровича - голову Державної служби геодезії, картографії та кадастру та ОЛЕКСІЄНКА Юрія Олександровича - першого заступника Голови Державного агентства земельних ресурсів України, вивівши з її складу К. Радченка та Р. Соссу.

Президент України В.ЮЩЕНКО

м. Київ, 27 серпня 2007 року N 188/2007-рп
