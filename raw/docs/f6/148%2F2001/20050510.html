Президент України; Указ від 05.03.2001 № 148/2001

Про зміну у складі Національної Ради з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування

Стан: Втратив чинність

Ідентифікатор: 148/2001

Текст документа від 10.05.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 706/2005 ( 706/2005 ) від 26.04.2005 )

Про зміну у складі Національної Ради з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування

Увести до складу Національної Ради з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування, затвердженого Указом Президента України від 13 грудня 2000 року N 1331 ( 1331/2000 ) (із змінами, внесеними Указами від 20 грудня 2000 року N 1354 ( 1354/2000 ) та від 13 лютого 2001 року N 90 ( 90/2001 ), РАДЧЕНКА Володимира Івановича - Голову Служби безпеки України, вивівши зі складу Національної Ради Деркача Л.В.

Президент України Л.КУЧМА

м. Київ, 5 березня 2001 року N 148/2001
