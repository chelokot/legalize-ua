Про доповнення переліку населених пунктів, яким надається статус гірських

Стан: Чинний

Текст документа від 01.02.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 лютого 2006 р. N 85 Київ

Про доповнення переліку населених пунктів, яким надається статус гірських

Кабінет Міністрів України постановляє:

1. Доповнити перелік населених пунктів, яким надається статус гірських, затверджений постановою Кабінету Міністрів України від 11 серпня 1995 р. N 647 ( 647-95-п ) (ЗП України, 1996 р., N 1, ст. 1, N 4, ст. 130, N 6, ст. 206, N 10, ст. 285; Офіційний вісник України, 2001 р., N 4, ст. 128, N 13, ст. 536; 2002 р., N 3, ст. 93; 2004 р., N 44, ст. 2880), такими населеними пунктами:

"Івано-Франківська область

Долинський район

Раківська сільська рада с. Раків

Тростянецька сільська рада с. Слобода-Долинська".

2. Ця постанова набирає чинності з 1 січня 2007 року.
