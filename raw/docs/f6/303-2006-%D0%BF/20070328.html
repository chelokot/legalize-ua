КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 березня 2006 р. N 303 Київ

Про введення додатково посади заступника Міністра внутрішніх справ України

{ Ввести дві посади заступників Міністра внутрішніх справ України замість посад, введених цією Постановою та Постановою КМ N 429 ( 429-2007-п ) від 14.03.2007 р. згідно з Постановою КМ N 589 ( 589-2007-п ) від 28.03.2007 }

Кабінет Міністрів України постановляє:

Ввести додатково посаду заступника Міністра внутрішніх справ України з питань кадрової роботи та внутрішньої безпеки.
