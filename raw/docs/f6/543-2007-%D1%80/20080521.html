Кабінет Міністрів України; Розпорядження від 18.07.2007 № 543-р

Про делегування представників Кабінету Міністрів України до складу адміністративної ради Фонду гарантування вкладів фізичних осіб

Стан: Чинний

Ідентифікатор: 543-2007-р

Текст документа від 21.05.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 липня 2007 р. N 543-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 730-р ( 730-2008-р ) від 21.05.2008 }

Про делегування представників Кабінету Міністрів України до складу адміністративної ради Фонду гарантування вкладів фізичних осіб

1. Делегувати до складу адміністративної ради Фонду гарантування вкладів фізичних осіб представників Кабінету Міністрів України:

Кравця Андрія Миколайовича - заступника Міністра фінансів;

Мунтіяна Валерія Івановича - заступника Міністра економіки.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 5 квітня 2006 р. N 179 ( 179-2006-р ) "Про делегування представників Кабінету Міністрів України до складу адміністративної ради Фонду гарантування вкладів фізичних осіб".

Прем'єр-міністр України В.ЯНУКОВИЧ
