МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

25.12.2009 N 2570/5

Зареєстровано в Міністерстві юстиції України 29 грудня 2009 р. за N 1269/17285

{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 1418/5 ( z1651-12 ) від 25.09.2012 }

Про внесення змін до наказу Міністерства юстиції України від 11.09.2007 N 757/5 "Про організацію роботи з питань проставлення апостиля на офіційних документах, призначених для використання на території інших держав"

Відповідно до постанови Кабінету Міністрів України від 18.01.2003 N 61 ( 61-2003-п ) "Про надання повноважень на проставлення апостиля, передбаченого Конвенцією, що скасовує вимогу легалізації іноземних офіційних документів" та з метою вдосконалення роботи з питань проставлення апостиля на офіційних документах, призначених для використання на території інших держав, НАКАЗУЮ:

1. Доповнити пункт 1 наказу Міністерства юстиції України від 11.09.2007 N 757/5 ( z1069-07 ) "Про організацію роботи з питань проставлення апостиля на офіційних документах, призначених для використання на території інших держав", зареєстрованого у Міністерстві юстиції України 13.09.2007 за N 1069/14336 (із змінами), після абзацу третього абзацами четвертим і п'ятим такого змісту:

"Термін розгляду документів про реєстрацію актів цивільного стану, поданих для проставлення апостиля до відділу проставлення апостиля Департаменту у справах цивільного стану громадян, - один робочий день.

У виняткових випадках (хвороба, звільнення, довготривала відпустка працівників відділу проставлення апостиля Департаменту у справах цивільного стану громадян) термін розгляду документів про реєстрацію актів цивільного стану - до трьох робочих днів".

У зв'язку з цим абзаци четвертий та п'ятий вважати відповідно абзацами шостим та сьомим.

2. Наказ набирає чинності з 11.01.2010.

3. Департаменту у справах цивільного стану громадян (В.В.Кунда) забезпечити належне виконання цього наказу.

4. Контроль за виконанням цього наказу покласти на заступника Міністра юстиції Л.В.Єфіменка.
