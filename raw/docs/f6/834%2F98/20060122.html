( Указ втратив чинність на підставі Указу Президента N 1871/2005 ( 1871/2005 ) від 29.12.2005 )

Про співголову Національної ради соціального партнерства

На часткову зміну Указу Президента України від 8 лютого 1993 року N 34 ( 34/93 ) "Про Національну раду соціального партнерства" (із зміною, внесеною Указом Президента України від 15 листопада 1996 року N 1083 ( 1083/96 ) ввести до складу Національної ради соціального партнерства САХАНЯ Івана Яковича - Міністра праці та соціальної політики України, призначивши його співголовою цієї Ради від Кабінету Міністрів України. Вивести зі складу Національної ради соціального партнерства Білоблоцького М.П.

Президент України Л.КУЧМА
