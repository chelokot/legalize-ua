Про внесення змін до статті 19 Закону України "Про Єдиний митний тариф"

( Відомості Верховної Ради України (ВВР), 2002, N 5, ст.34 )

Верховна Рада України постановляє:

1. У пункті "о" статті 19 Закону України "Про Єдиний митний тариф" ( 2097-12 ) (Відомості Верховної Ради України, 1992 р., N 19, ст. 259; 1993 р., N 24, ст. 270; 1996 р., N 41, ст. 192; 1999 р., N 31, ст. 253; 2000 р., N 3, ст. 20, N 21, ст. 163, N 35, ст. 283, N 38, ст. 318, N 48, ст. 406; 2001 р., N 11, ст. 46, N 30, ст. 143) цифри і слова "3208 Фарби та лаки (включаючи емалі та політури)" виключити.

2. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА
