Президент України; Указ від 28.04.2010 № 585/2010

Про визнання таким, що втратив чинність, Указу Президента України від 3 квітня 2008 року N 297

Стан: Чинний

Ідентифікатор: 585/2010

Текст документа від 28.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання таким, що втратив чинність, Указу Президента України від 3 квітня 2008 року N 297

Керуючись частиною п'ятою статті 124 Конституції України ( 254к/96-ВР ) та у зв'язку з ухвалою Вищого адміністративного суду України від 27 січня 2010 року ( v3117760-10 ) постановляю:

1. Визнати таким, що втратив чинність, Указ Президента України від 3 квітня 2008 року N 297 ( 297/2008 ) "Про скасування Указу Президента України від 25 березня 2004 року N 368".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 28 квітня 2010 року N 585/2010
