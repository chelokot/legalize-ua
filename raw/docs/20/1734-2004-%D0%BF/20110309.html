Про затвердження переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

{ Із змінами, внесеними згідно з Постановами КМ N 272 ( 272-2005-п ) від 13.04.2005 N 1696 ( 1696-2006-п ) від 08.12.2006 N 244 ( 244-2008-п ) від 26.03.2008 N 744 ( 744-2008-п ) від 27.08.2008 N 1 ( 1-2010-п ) від 06.01.2010 N 332 ( 332-2010-п ) від 05.05.2010 N 413 ( 413-2010-п ) від 09.06.2010 N 162 ( 162-2011-п ) від 23.02.2011 }

Кабінет Міністрів України постановляє:

1. Затвердити перелік підприємств, які мають стратегічне значення для економіки і безпеки держави (далі - перелік підприємств), що додається.

2. Міністерствам та іншим центральним органам виконавчої влади систематично переглядати перелік підприємств та подавати у разі потреби щороку до 10 січня і 10 липня Міністерству економіки та з питань європейської інтеграції пропозиції з обґрунтуваннями по кожному об'єкту для прийняття Кабінетом Міністрів України рішення про внесення змін до переліку.

3. Фонду державного майна у планах розміщення акцій підприємств, що не увійшли до переліку підприємств, не передбачати залишення акцій у державній власності, крім випадків, визначених законодавством.

4. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.
