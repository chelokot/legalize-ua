ПОСТАНОВА від 25 грудня 1998 р. N 2072 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1080 ( 1080-99-п ) від 18.06.99 )

Про доповнення переліку товарів критичного імпорту

Кабінет Міністрів України постановляє:

Доповнити перелік товарів, затверджений постановою Кабінету Міністрів України від 27 липня 1998 р. N 1145 ( 1145-98-п ) "Про перелік товарів критичного імпорту" (Офіційний вісник України, 1998 р., N 30, ст. 1126), з наступними змінами і доповненнями, такою позицією:

"84.33. 53300 Комбайни гичкозбиральні і бурякозбиральні причепні та комплектуючі вироби до них".
