Кабінет Міністрів України; Постанова від 28.04.2009 № 431

Про особливості закупівлі автобусів для забезпечення оздоровлення та відпочинку дітей у державному підприємстві "Міжнародний дитячий центр "Артек"

Стан: Втратив чинність

Ідентифікатор: 431-2009-п

Текст документа від 03.04.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 квітня 2009 р. N 431 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 285 ( 285-2010-п ) від 31.03.2010 }

Про особливості закупівлі автобусів для забезпечення оздоровлення та відпочинку дітей у державному підприємстві "Міжнародний дитячий центр "Артек"

Кабінет Міністрів України постановляє:

1. Відповідно до пункту 6 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006; 2009 р., N 20, ст. 628), установити, що закупівля автобусів для забезпечення оздоровлення та відпочинку дітей у державному підприємстві "Міжнародний дитячий центр "Артек" здійснюється зазначеним підприємством за процедурою закупівлі в одного учасника без погодження з Міністерством економіки.

2. Державному підприємству "Міжнародний дитячий центр "Артек" подати протягом трьох робочих днів після укладення договорів про закупівлю автобусів для забезпечення оздоровлення та відпочинку дітей у зазначеному підприємстві Міністерству економіки та Головному контрольно-ревізійному управлінню копії зазначених договорів.

Прем'єр-міністр України Ю.ТИМОШЕНКО
