Кабінет Міністрів України; Розпорядження від 11.08.2010 № 1642-р

Про виділення коштів для придбання квартир мешканцям будинків на території військової частини А0829 у м. Лозовій Харківської області, які потребують відселення

Стан: Чинний

Ідентифікатор: 1642-2010-р

Текст документа від 22.11.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 серпня 2010 р. N 1642-р Київ

Про виділення коштів для придбання квартир мешканцям будинків на території військової частини А0829 у м. Лозовій Харківської області, які потребують відселення

{ Назва в редакції Розпорядження КМ N 2177-р ( 2177-2010-р ) від 22.11.2010 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 2177-р ( 2177-2010-р ) від 22.11.2010 }

1. Виділити Харківській облдержадміністрації 31 426,5 тис. гривень для придбання квартир мешканцям будинків по вул. Блюхера, 1 і 2, та по вул. Інженерній, 1, 2, 3 і 4, у м. Лозовій, які потребують відселення. { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 2177-р ( 2177-2010-р ) від 22.11.2010 }

Міністерству фінансів здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 2154-17 ).

2. Дозволити Харківській облдержадміністрації здійснювати попередню оплату вартості квартир у розмірі 100 відсотків. { Пункт 2 в редакції Розпорядження КМ N 2177-р ( 2177-2010-р ) від 22.11.2010 }

3. Харківській облдержадміністрації:

затвердити у тижневий строк за погодженням з Міністерством економіки, Міністерством фінансів, Міністерством регіонального розвитку та будівництва перелік витрат, пов'язаних з відселенням мешканців із зазначених у пункті 1 цього розпорядження будинків;

подати до кінця 2010 року Міністерству економіки, Міністерству фінансів, Міністерству регіонального розвитку та будівництва і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.
