Текст документа від 30.04.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 березня 2003 р. N 122-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 579 ( 579-2004-п ) від 30.04.2004 )

Про утворення міжвідомчого конкурсного комітету з визначення підприємств, що мають стратегічне значення для економіки та безпеки держави, інноваційне інвестування яких здійснюватиметься за рахунок частини коштів, отриманих від приватизації державного майна

Утворити міжвідомчий конкурсний комітет з визначення підприємств, що мають стратегічне значення для економіки та безпеки держави, інноваційне інвестування яких здійснюватиметься за рахунок частини коштів, отриманих від приватизації державного майна, у складі згідно з додатком.

Надати право голові міжвідомчого конкурсного комітету вносити у разі потреби зміни до його складу та залучати до розгляду питань про інноваційне інвестування підприємств представників органів, уповноважених управляти майном відповідних підприємств.
