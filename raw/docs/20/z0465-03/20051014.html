Про внесення змін до наказу Міністерства освіти і науки України від 29.03.2001 N 161

Відповідно до постанови Кабінету Міністрів України від 19.05.2003 N 740 ( 740-2003-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів і організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести до наказу Міністерства освіти і науки України від 29.03.2001 N 161 ( z0303-01 ) "Про затвердження розмірів посадових окладів (ставок заробітної плати) працівників навчальних закладів, установ освіти та наукових установ", зареєстрованого Міністерством юстиції України 3 квітня 2001 р. за N 303/5494, із змінами та доповненнями, унесеними наказами Міністерства освіти і науки України від 22.10.2001 N 697 ( z0925-01 ) "Про внесення змін та доповнень до наказу Міністерства освіти і науки України від 29.03.2001 N 161", зареєстрованим у Міністерстві юстиції України 2 листопада 2001 р. за N 925/6116, та від 25.02.2002 N 145 ( z0234-02 ) "Про внесення змін до наказу Міністерства освіти і науки України від 29.03.2001 р. N 161", зареєстрованим у Міністерстві юстиції України 7 березня 2002 р. за N 234/6522, такі зміни:

1.1. Викласти додатки 1-19 в редакції, що додається.

2. Керівникам навчальних закладів, установ освіти та наукових установ у межах затвердженого фонду заробітної плати встановити посадові оклади (ставки заробітної плати) працівникам навчальних закладів, установ освіти та наукових установ у розмірах і терміни, визначені у додатках 1-19.

3. Контроль за виконанням наказу покласти на заступника Державного секретаря Богомолова А.Г.
