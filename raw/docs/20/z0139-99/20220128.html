{ Наказ втратив чинність на підставі Наказу Міністерства інфраструктури N 724 ( z0050-22 ) від 29.12.2021 }

Про внесення доповнень до Положення про сертифікаційну

діяльність на залізничному транспорті України,

затвердженого наказом Міністерства транспорту України від 01.06.98 N 207

З метою забезпечення виконання вимог Закону України "Про транспорт" ( 232/94-ВР ), Закону України "Про залізничний транспорт" ( 273/96-ВР ) та Декрету Кабінету Міністрів України "Про стандартизацію і сертифікацію" ( 46-93 ) щодо обов'язкової та добровільної сертифікації на залізничному транспорті НАКАЗУЮ:

1. Внести доповнення до Положення про сертифікаційну діяльність на залізничному транспорті України, затвердженого наказом Міністерства транспорту України від 01.06.98 N 207 ( z0525-98 ) та зареєстрованого в Міністерстві юстиції України від 19.08.98 за N 525/2965:

1.1. Доповнити пункт 5.4 підпунктом 5.4.4 в такій редакції:

"5.4.4. Орган із сертифікації "Дортранстелеком" (адреса: 310050, м.Харків, майдан Фейєрбаха, 7).

Сертифікація:

- телекомунікаційних мереж для залізничного транспорту та їхніх складових частин;

- мереж радіозв'язку для залізничного транспорту та їхніх складових частин".

1.2. Додаток до пункту 5.1 викласти, з урахуванням доповнення до пункту 5.4, у новій редакції (додається).

2. Головному управлінню науково-технічної політики і безпеки транспорту (Петрашевський О.Л.), Головному управлінню правового забезпечення (Логінова Л.М.) у 5-денний термін подати зазначені доповнення на державну реєстрацію до Міністерства юстиції України.

3. Державній адміністрації залізничного транспорту України довести до відома всіх зацікавлених установ доповнення до Положення про сертифікаційну діяльність на залізничному транспорті України.

4. Скасувати наказ Міністерства транспорту України від 24.12.98 N 537 "Щодо внесення доповнень до наказу Міністерства транспорту України від 01.06.98 р. N 207".

5. Контроль за виконанням цього наказу покласти на першого заступника генерального директора Укрзалізниці Федюшина Ю.М.

Перший заступник Міністра Л.М.Костюченко

Додаток до пункту 5.1 Положення про сертифікаційну діяльність на залізничному транспорті України (в редакції наказу Мінтрансу України від 21.01.99 N 28)
