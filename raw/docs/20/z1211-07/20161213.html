Держгірпромнагляд; Наказ від 01.10.2007 № 232

Зміни до Типової інструкції з безпечного ведення робіт для стропальників (зачіплювачів), які обслуговують вантажопідіймальні крани, затвердженої наказом Держнаглядохоронпраці України від 25.09.95 N 135, зареєстрованої у Міністерстві юстиції України 10.10.95 за N 372/908

Реєстрація: Мін'юст України від 25.10.2007 № 1211/14478

Стан: Втратив чинність

Ідентифікатор: z1211-07

Текст документа від 13.12.2016:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ПРОМИСЛОВОЇ БЕЗПЕКИ, ОХОРОНИ ПРАЦІ ТА ГІРНИЧОГО НАГЛЯДУ

ЗАТВЕРДЖЕНО Наказ Держгірпромнагляду 01.10.2007 N 232 ( z1207-07 )

Зареєстровано в Міністерстві юстиції України 25 жовтня 2007 р. за N 1211/14478

{ Документ втратив чинність на підставі Наказу Міністерства соціальної політики N 1231 ( z1494-16 ) від 27.10.2016 }

ЗМІНИ до Типової інструкції з безпечного ведення робіт для стропальників (зачіплювачів), які обслуговують вантажопідіймальні крани, затвердженої наказом Держнаглядохоронпраці України від 25.09.95 N 135, зареєстрованої у Міністерстві юстиції України 10.10.95 за N 372/908 ( z0371-95, z0372-95 )

1. Пункт 1.1 Типової інструкції ( z0372-95 ) викласти в такій редакції: "1.1. Ця Інструкція розроблена на основі Правил будови і безпечної експлуатації вантажопідіймальних кранів, затверджених наказом Держгірпромнагляду від 18.06.2007 N 132 ( z0784-07 ), зареєстрованих в Міністерстві юстиції України 09.07.2007 за N 784/14051 (далі - Правила)".

2. Пункт 1.2 Типової інструкції ( z0372-95 ) викласти в такій редакції: "1.2. На кожній дільниці робіт вантажопідіймальних кранів, для обв'язування, зачіплювання або підвішування вантажів суб'єкт господарювання повинен призначити стропальників із числа працівників, які досягли 18 років та пройшли навчання в установленому порядку".

3. Пункти 1.4 та 1.5 Типової інструкції ( z0372-95 ) вилучити. У зв'язку з цим пункти 1.6-1.11 Типової інструкції вважати пунктами 1.4-1.9 відповідно.

4. Пункт 1.4 Типової інструкції ( z0372-95 ) викласти в такій редакції: "1.4. Перед допуском до роботи стропальників проводиться перевірка знань нормативно-правових актів з охорони праці у порядку, встановленому Типовим положенням про порядок проведення навчання і перевірки знань з питань охорони праці, затвердженим наказом Держнаглядохоронпраці України від 26.01.2005 N 15 ( z0231-05 ) "Про затвердження Типового положення про порядок проведення навчання і перевірки знань з питань охорони праці та Переліку робіт з підвищеною небезпекою", зареєстрованим в Міністерстві юстиції України 15.02.2005 за N 231/10511".

5. У пункті 1.5 Типової інструкції ( z0372-95 ) слова "адміністрацією підприємства" замінити словами "суб'єктом господарювання".

6. У пункті 1.6 Типової інструкції ( z0372-95 ) і далі за текстом слова "особою, відповідальною за безпечне проведення робіт з переміщення вантажів кранами" замінити словами "працівником, відповідальним за безпечне проведення робіт вантажопідіймальними кранами".

7. У абзаці дев'ятому пункту 3.3 Типової інструкції ( z0372-95 ) цифри "30" замінити цифрами "40".

8. Пункт 6.1 Типової інструкції ( z0372-95 ) викласти в такій редакції: "6.1. Стропальник несе відповідальність відповідно до чинного законодавства України".

Начальник управління організації державного нагляду у металургії, машинобудуванні, енергетиці, будівництві та котлонагляду В.І.Іванченко
