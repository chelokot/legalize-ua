РОЗПОРЯДЖЕННЯ від 15 квітня 2009 р. N 418-р Київ

Про затвердження переліків об'єктів будівництва, реконструкції та капітального ремонту автомобільних доріг загального користування державного і місцевого значення у 2009 році та обсягів їх фінансування

{ Із змінами, внесеними згідно з Наказами Державної служби автомобільних доріг N 278 ( v0278466-09 ) від 11.06.2009 N 410 ( v0410466-09 ) від 10.09.2009 N 415 ( v0415466-09 ) від 17.09.2009 N 459 ( v0459466-09 ) від 12.10.2009 }

1. Відповідно до статті 26 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) затвердити такі, що додаються:

перелік об'єктів будівництва та реконструкції автомобільних доріг загального користування державного і місцевого значення у 2009 році та обсяги їх фінансування;

перелік об'єктів капітального ремонту автомобільних доріг загального користування державного і місцевого значення у 2009 році та обсяги їх фінансування.

2. Дозволити Укравтодору здійснювати у разі потреби перерозподіл коштів, передбачених у державному бюджеті ( 835-17 ) для будівництва, реконструкції та капітального ремонту автомобільних доріг загального користування державного і місцевого значення, в межах загальних обсягів фінансування, затверджених цим розпорядженням.
