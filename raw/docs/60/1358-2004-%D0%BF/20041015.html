Інд. 27

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 15 жовтня 2004 р. N 1358

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. Доповнити перелік пріоритетних видів економічної діяльності на території Закарпатської області, для яких встановлено спеціальний режим інвестиційної діяльності, затверджений постановою Кабінету Міністрів України від 6 квітня 1999 р. N 548 ( 548-99-п ) (Офіційний вісник України, 1999 р., N 14, ст. 575; 2000 р., N 30, ст. 1281; 2001 р., N 6, ст. 233; 2002 р., N 21, ст. 1029, N 44, ст. 2030; 2003 р., N 27, ст. 1316), такою позицією:

"14.4 Видобування солі".

2. У переліку пріоритетних видів економічної діяльності на території м. Харкова, для яких встановлено спеціальний режим інвестиційної діяльності, затвердженому постановою Кабінету Міністрів України від 11 листопада 1999 р. N 2076 ( 2076-99-п ) (Офіційний вісник України, 1999 р., N 46, ст. 2267; 2000 р., N 30, ст. 1281; 2001 р.. N 39, ст. 1774; 2002 р., N 21, ст. 1031, N 23, ст. 1112; 2003 р., N 27, ст. 1316):

1) доповнити перелік такими позиціями:

"23.1 Виробництво коксопродуктів

25.21 Виробництво пластин, труб та профілів з пластмаси

26.63 Виробництво бетонних сумішей, готових для використання

27.22 Виробництво сталевих труб

27.32 Холодне катання листової сталі";

2) виключити у переліку такі позиції:

"15.84 Виробництво какао

15.86.2 Виробництво кави (із сировини для промислової переробки за кодами згідно з УКТЗЕД 0901 11 00 10; 0901 12 00 10; 0901 90 10 10 ( 2371а-14 )";

"15.89.2 Виробництво дріжджів (виключно з вітчизняної сировини)

15.89.9 Виробництво решти харчових продуктів (поліпшувачів хліба та хлібобулочних виробів) виключно з вітчизняної сировини";

"21.22 Виробництво санітарно-гігієнічних виробів та паперових виробів для побутового користування".

3. У переліку пріоритетних видів економічної діяльності на території пріоритетного розвитку у Волинській області, затвердженому постановою Кабінету Міністрів України від 6 грудня 1999 р. N 2210 ( 2210-99-п ) (Офіційний вісник України, 1999 р., N 49, ст. 2407; 2000 р., N 30, ст. 1281; 2001 р.. N 41, ст. 1851; 2002 р., N 21, ст. 1031; 2003 р., N 27, ст. 1316):

1) доповнити перелік такими позиціями:

"26.22 Виробництво керамічних санітарно- технічних виробів (до початку пусконалагоджувальних робіт)

27.51 Чавунне лиття (до початку пусконалагоджувальних робіт)

27.52 Сталеве лиття (до початку пусконалагоджувальних робіт)

28.11 Виробництво металевих конструкцій (до початку пусконалагоджувальних робіт)

36.15 Виробництво матраців (до початку пусконалагоджувальних робіт)";

2) виключити у переліку такі позиції:

"22.22 Поліграфічна діяльність, не віднесена до інших угруповань (друкування іншої друкованої продукції, виготовленої за іншою технологією (способом флексографії))";

"27.32 Холодне катання листової сталі

27.33 Холодне оброблення штампуванням або вальцюванням";

"40.10.1 Виробництво електроенергії тепловими електростанціями";

"40.3 Виробництво та розподілення тепла".

4. У розділі "Житомирська область" переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку Житомирської, Чернігівської областей, м. Шостки Сумської області, на території спеціальної економічної зони "Миколаїв", де встановлено спеціальний режим інвестиційної діяльності, затвердженого постановою Кабінету Міністрів України від 26 липня 2000 р. N 1175 ( 1175-2000-п ) (Офіційний вісник України, 2000 р., N 30, ст. 1281, N 52, ст. 2271; 2001 р., N 40, ст. 1800, N 47, ст. 2063, ст. 2064; 2002 р., N 21, ст. 1031, N 28, ст. 1329, N 30, ст. 1419; 2003 р., N 27, ст. 1316):

1) доповнити перелік такими позиціями:

"15.41 Виробництво неочищеної

олії та жирів (у частині виробництва олії з ріпаку для виробництва біодизельного палива (виключно з вітчизняної

сировини))

24.66 Виробництво хімічної продукції для промислових цілей (у частині виробництва біодизельного палива на

основі рапсової олії)

29.11.1 Виробництво двигунів та

турбін (у частині виробництва дизельних

двигунів для тракторів)";

2) позицію "01.11 Вирощування картоплі, прядильних культур (льону)

та шишок хмелю, первинне оброблення прядильних культур (виключно з

вітчизняної сировини)" викласти в такій редакції:

"01.11.0 Вирощування картоплі,

прядильних культур (льону) та шишок хмелю, первинне оброблення прядильних

культур; вирощування насіння олійних культур

(рапсу) для продовольчих і технічних цілей, а також на насіння (виключно з вітчизняної сировини)".
