Реєстрація: Мін'юст України від 01.12.2005 № 1447/11727

Стан: Втратив чинність

Ідентифікатор: z1447-05

Текст документа від 15.11.2005:

ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

15.11.2005 N 645

Зареєстровано в Міністерстві юстиції України 1 грудня 2005 р. за N 1447/11727

Про внесення змін до Положення про порядок реєстрації випуску акцій акціонерного товариства при зміні номінальної вартості та кількості акцій без зміни розміру статутного фонду

З метою вдосконалення порядку реєстрації випуску (випусків) акцій акціонерного товариства при зміні номінальної вартості та кількості акцій без зміни розміру статутного фонду, відповідно до Законів України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ), "Про господарські товариства" ( 1576-12 ) та "Про цінні папери і фондову біржу" ( 1201-12 ) та у зв'язку з прийняттям рішення Державної комісії з цінних паперів та фондового ринку від 19.07.2005 N 414 ( z1001-05 ) "Про внесення змін та доповнень до рішення Державної комісії з цінних паперів та фондового ринку від 29 вересня 2000 року N 149", зареєстрованого в Міністерстві юстиції України 07.09.2005 за N 1001/11281, Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Скасувати рішення Державної комісії з цінних паперів та фондового ринку від 19.07.2005 N 397 "Про затвердження змін до Положення про порядок реєстрації випуску акцій акціонерного товариства при зміні номінальної вартості та кількості акцій без зміни розміру статутного фонду, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 14.09.2000 N 125, зареєстрованого в Міністерстві юстиції України 02.10.2000 за N 671/4892".

2. Унести зміни до Положення про порядок реєстрації випуску акцій акціонерного товариства при зміні номінальної вартості та кількості акцій без зміни розміру статутного фонду, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 14.09.2000 N 125 ( z0671-00 ), зареєстрованого в Міністерстві юстиції України 02.10.2000 за N 671/4892, а саме:

пункт 2 розділу I вилучити, у зв'язку з цим пункти 3 - 20 зазначеного Положення вважати відповідно пунктами 2 - 19.

3. Керівнику апарату Державної комісії з цінних паперів та фондового ринку М.Непрану забезпечити:

державну реєстрацію цього рішення в Міністерстві юстиції України;

опублікування рішення відповідно до вимог чинного законодавства України.

4. Контроль за виконанням цього рішення покласти на Керівника апарату Державної комісії з цінних паперів та фондового ринку М.Непрана.

Голова Комісії А.Балюк
