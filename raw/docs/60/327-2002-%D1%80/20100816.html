КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 червня 2002 р. N 327-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 696 ( 696-2010-п ) від 04.08.2010 }

Про відкриття торговельно-економічної місії у складі Представництва України при Європейських Співтовариствах (Європейському Союзі)

Мінекономіки:

забезпечити разом з МЗС у 2002 році відкриття торговельно-економічної місії у складі Представництва України при Європейських Співтовариствах (Європейському Союзі) у межах установленої граничної чисельності працівників торговельно-економічних місій у складі дипломатичних представництв України за кордоном та коштів, передбачених у державному бюджеті на функціонування закордонних дипломатичних установ України;

вжити разом з МЗС і Державною податковою адміністрацією заходів для кадрового забезпечення та розміщення торговельно-економічної місії у складі Представництва України при Європейських Співтовариствах (Європейському Союзі).

Прем'єр-міністр України А.КІНАХ
