Кабінет Міністрів України; Постанова від 27.11.1998 № 1882

Про внесення доповнень до Порядку звернення стягнення на рухоме майно, що перебуває у податковій заставі, для погашення податкової заборгованості платника податків (крім фізичних осіб - суб'єктів підприємницької діяльності) та реалізації такого майна

Стан: Втратив чинність

Ідентифікатор: 1882-98-п

Текст документа від 05.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 листопада 1998 р. N 1882 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 421 ( 421-2006-п ) від 05.04.2006 }

Про внесення доповнень до Порядку звернення стягнення на рухоме майно, що перебуває у податковій заставі, для погашення податкової заборгованості платника податків (крім фізичних осіб - суб'єктів

підприємницької діяльності) та реалізації такого майна

( Із змінами, внесеними згідно з Постановами КМ N 1557 ( 1557-99-п ) від 26.08.99 N 532 ( 532-2001-п ) від 17.05.2001 N 684 ( 684-2001-п ) від 21.06.2001 )

Кабінет Міністрів України постановляє:

1. Внести до Порядку звернення стягнення на рухоме майно, що перебуває у податковій заставі, для погашення податкової заборгованості платника податків (крім фізичних осіб - суб'єктів підприємницької діяльності) та реалізації такого майна, затвердженого постановою Кабінету Міністрів України від 22 червня 1998 р. N 941 ( 941-98-п ) (Офіційний вісник України, 1998 р., N 25, ст. 926, N 42, ст. 1555), такі доповнення:

1) абзац сьомий пункту 1 доповнити словами "або через організації, уповноважені Кабінетом Міністрів України";

2) пункт 9 доповнити абзацом такого змісту:

"Виділення майна, що реалізується через уповноважену Кабінетом Міністрів України організацію, провадиться без участі експерта";

3) пункт 12 доповнити абзацом такого змісту:

"Оцінка майна, що реалізується через уповноважені Кабінетом Міністрів України організації, здійснюється виходячи з оптових цін, які діють на час реалізації, кон'юнктури ринку, якості продукції, а в разі проведення конкурсу - за цінами конкурсу на кожну партію конкретної продукції";

4) пункт 14 доповнити словами "або через організації, уповноважені Кабінетом Міністрів України";

5) перше речення пункту 20 після слів "аукціону (торгів)" доповнити словами "або організацію, уповноважену Кабінетом Міністрів України";

6) додаток 3 до Порядку доповнити приміткою такого змісту:

"Примітка. Вилучення майна, що реалізується через уповноважену Кабінетом Міністрів України організацію, провадиться без участі експерта";

7) додаток 4 до Порядку доповнити приміткою такого змісту:

"Примітка. Опис майна, що реалізується через уповноважену Кабінетом Міністрів України організацію, провадиться без участі експерта".

2. Визначити Державний комітет по матеріальних резервах та Державну акціонерну компанію "Укрресурси", підприємство "Центр комерційних проектів "Професіонал" (м. Київ) уповноваженими Кабінетом Міністрів України організаціями з реалізації рухомого майна, що перебуває у податковій заставі. ( Пункт 2 із змінами, внесеними згідно з Постановами КМ N 1557 ( 1557-99-п ) від 26.08.99, N 532 ( 532-2001-п ) від 17.05.2001, N 684 ( 684-2001-п ) від 21.06.2001 )
