N 619 від 19.09.2001 Зареєстровано в Міністерстві м.Київ юстиції України 3 жовтня 2001 р. за N 859/6050

Про внесення змін та доповнень до деяких наказів Держмитслужби

{ Із змінами, внесеними згідно з Наказом Державної митної служби N 678 ( z1286-04 ) від 17.09.2004 }

З метою приведення нормативно-правових актів Держмитслужби у відповідність до чинного законодавства України НАКАЗУЮ:

{ Пункт 1 фактично втратив чинність у зв'язку з втратою чинності Наказу Державної митної служби N 26 ( z0119-01 ) від 23.01.2001, до якого вносились зміни } 1. Унести до Порядку здійснення митного контролю за переміщенням через митний кордон України товарів та інших предметів з використанням морського, річкового й поромного видів транспорту, затвердженого наказом Держмитслужби від 23.01.2001 N 26 ( z0119-01 ) і зареєстрованого в Міністерстві юстиції України 07.02.2001 за N 119/5310, такі зміни й доповнення:

а) пункт 1.5 доповнити абзацом такого змісту:

"У передбачених законодавством випадках на судно закордонного плавання надається вантажна митна декларація";

б) другий абзац підпункту 3.1.6 викласти в такій редакції:

"митного оформлення товарів та інших предметів у відповідний митний режим".

2. Абзац перший пункту 2.4 Порядку митного оформлення автотранспортних засобів, що здійснюють міжнародні перевезення, затвердженого наказом Держмитслужби від 10.11.2000 N 637 ( z0892-00 ) і зареєстрованого в Міністерстві юстиції України 06.12.2000 за N 892/5113, викласти в такій редакції:

"2.4. До закінчення терміну дії ВМД АТЗ суб'єкт, який використовує АТЗ, з метою оформлення наступної ВМД АТЗ має:".

3. Управлінню організації митного контролю (Терещенко С.С.) та Правовому управлінню (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Управлінню справами (Карпенко В.П.) після державної реєстрації цього наказу в Міністерстві юстиції України забезпечити його тиражування та розсилку до митних органів.

5. Начальникам регіональних митниць, митниць довести наказ до відома суб'єктів ЗЕД.

6. Контроль за виконанням цього наказу покласти на заступника Голови Служби Пашка П.В.
