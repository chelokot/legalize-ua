Про затвердження Інструкції з бухгалтерського обліку основних засобів і нематеріальних активів установ Національного банку України

Стан: Чинний

Ідентифікатор: v0123500-01

Текст документа від 01.01.2003:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

23.03.2001 N 123

Про затвердження Інструкції з бухгалтерського обліку основних засобів і нематеріальних активів установ Національного банку України

{ Із змінами, внесеними згідно з Постановою Національного банку N 521 ( v0521500-02 ) від 20.12.2002 }

З метою приведення обліку операцій з основними засобами та нематеріальними активами у відповідність до вимог національних положень (стандартів) бухгалтерського обліку Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити Інструкцію з бухгалтерського обліку основних засобів і нематеріальних активів установ Національного банку України (додається).

{ Інструкція з бухгалтерського обліку основних засобів і нематеріальних активів установ Національного банку України втратила чинність на підставі Постанови Національного банку N 521 ( v0521500-02 ) від 20.12.2002 }

2. Визнати такою, що втратила чинність, Інструкцію з бухгалтерського обліку основних засобів і нематеріальних активів установ Національного банку України, затверджену постановою Правління Національного банку України від 21.04.98 N 155 ( v0543500-98 ), в редакції постанови Правління Національного банку України від 30.12.99 N 632.

3. Постанова набирає чинності з дня її підписання.

4. Контроль за виконанням цієї постанови покласти на керівників територіальних управлінь та установ Національного банку України, Департамент бухгалтерського обліку (В.І.Ричаківська).

Голова В.С.Стельмах
