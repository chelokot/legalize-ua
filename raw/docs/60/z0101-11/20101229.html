Про скасування частини шостої пункту 8 Типового положення про комісії для розгляду питань, пов'язаних із встановленням статусу учасника війни відповідно до Закону України "Про статус ветеранів війни, гарантії їх соціального захисту"

Реєстрація: Мін'юст України від 24.01.2011 № 101/18839

Стан: Чинний

Ідентифікатор: z0101-11

Текст документа від 29.12.2010:

МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

29.12.2010 N 419

Зареєстровано в Міністерстві юстиції України 24 січня 2011 р. за N 101/18839

Про скасування частини шостої пункту 8 Типового положення про комісії для розгляду питань, пов'язаних із встановленням статусу учасника війни відповідно до Закону України "Про статус ветеранів війни, гарантії їх соціального захисту"

На виконання постанови Окружного адміністративного суду м. Києва від 18.02.2010 N 15/371 НАКАЗУЮ:

Скасувати частину шосту пункту 8 Типового положення про комісії для розгляду питань, пов'язаних із встановленням статусу учасника війни відповідно до Закону України "Про статус ветеранів війни, гарантії їх соціального захисту", затвердженого наказом Міністерства соціального захисту населення України від 30.05.96 N 79 ( z0264-96 ) (у редакції наказу Мінпраці від 06.08.2003 N 218) ( z0891-03 ), зареєстрованого в Міністерстві юстиції України 04.06.96 за N 264/1289.

Голова комісії з питань реорганізації, перший заступник Міністра Л.Дроздова
