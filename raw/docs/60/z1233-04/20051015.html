Про встановлення вартості проїзду в поїздах міжнародного сполучення N 816/815 Харків - Бєлгород - Харків та N 817/818 Бєлгород - Харків - Бєлгород

Стан: Втратив чинність

Текст документа від 15.10.2005:

МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

28.09.2004 N 857

Зареєстровано в Міністерстві юстиції України 29 вересня 2004 р. за N 1233/9832

( Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 559 ( z1133-05 ) від 16.09.2005 )

Про встановлення вартості проїзду в поїздах міжнародного сполучення N 816/815 Харків - Бєлгород - Харків та N 817/818 Бєлгород - Харків - Бєлгород

Відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

1. Установити, що вартість проїзду пасажирів у вагонах 1-го, 2-го та 3-го класів поїздів міжнародного сполучення N 816/815 Харків - Бєлгород - Харків та N 817/818 Бєлгород - Харків - Бєлгород визначається за тарифами відповідно жорсткого вагона із 4-місними купе, місце для лежання (купейний), жорсткого вагона, місце для лежання (плацкартний), та жорсткого вагона, місце для сидіння (загальний) швидкого поїзда, затвердженими наказом Міністерства транспорту України від 03.12.97 N 409 ( z0584-97 ) "Про затвердження Тарифів на перевезення пасажирів і багажу залізничним транспортом у міжнародному сполученні" і зареєстрованими в Міністерстві юстиції України 11.12.97 за N 584/2388 (із змінами і доповненнями, унесеними наказами Міністерства транспорту України від 10.11.98 N 439, від 04.01.99 N 2 ( z0030-99 ) та від 15.09.99 N 454 ( z0648-99 ), зареєстрованими в Міністерстві юстиції України відповідно 12.11.98 за N 722/3162, 20.01.99 за N 30/3323 та 27.09.99 за N 648/3941), із застосуванням коефіцієнтів індексації: для 1-го класу - 0,39, 2-го - 0,49, 3-го - 0,52.

2. Державній адміністрації залізничного транспорту України (Федюшин Ю.М.):

2.1. Подати наказ для державної реєстрації в Міністерство юстиції України в установленому порядку.

2.2. Забезпечити своєчасне введення у дію цього наказу та правильність його застосування і поінформувати про це населення на вокзалах та пунктах продажу проїзних документів.

3. Контроль за виконанням цього наказу покласти на заступника Міністра транспорту та зв'язку України Дунаєва Л.Ф.

Міністр Г.Кірпа
