ЗАТВЕРДЖЕНО Наказ Державної податкової адміністрації України 23.06.2010 N 457 ( z0458-10 )

Зареєстровано в Міністерстві юстиції України 2 липня 2010 р. за N 459/17754

{ Документ втратив чинність на підставі Наказу Міністерства фінансів N 734 ( z1121-12 ) від 18.06.2012 }

ЗМІНИ до Положення про державну податкову інспекцію в місті з районним поділом (крім міст Києва та Севастополя) ( z0632-08 )

У пункті 2.2 глави 2:

1. Підпункт 2.2.19 викласти у такій редакції:

"2.2.19 забезпечує безпеку діяльності ДПІ та районних ДПІ та їх працівників, а також захист працівників від протиправних посягань, пов'язаних з виконанням ними службових обов'язків;".

2. Підпункт 2.2.22 викласти у такій редакції:

"2.2.22 запобігає, виявляє, припиняє корупційні діяння або інші правопорушення, пов'язані з корупцією, працівників ДПІ та районних ДПІ;".

Директор Організаційно-розпорядчого департаменту Державної податкової адміністрації України Л.Г.Клочкова
