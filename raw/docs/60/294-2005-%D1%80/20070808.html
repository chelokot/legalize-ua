{ Розпорядження скасовано на підставі Розпорядження КМ N 614-р ( 614-2007-р ) від 08.08.2007 }

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 184-р ( 184-2006-р ) від 05.04.2006 }

Про затвердження нового складу Національної експертної комісії з питань захисту суспільної моралі

1. Затвердити новий склад Національної експертної комісії з питань захисту суспільної моралі, що додається.

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 17 листопада 2004 р. N 862 ( 862-2004-р ) "Про затвердження складу Національної експертної комісії з питань захисту суспільної моралі";

розпорядження Кабінету Міністрів України від 23 грудня 2004 р. N 950 ( 950-2004-р ) "Про зміну складу Національної експертної комісії з питань захисту суспільної моралі".
