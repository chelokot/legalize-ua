КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 жовтня 1997 р. N 1120 Київ

( Постанова втратила чинність на підставі Постанови КМ N 16 ( 16-2001-п ) від 12.01.2001 )

Про внесення змін до ставок ввізного мита на окремі види товарів

( Із змінами, внесеними згідно з Постановами КМ N 150 ( 150-98-п ) від 16.02.98 N 420 ( 420-98-п ) від 02.04.98 N 1401 ( 1401-99-п ) від 30.07.99 N 121 ( 121-2000-п ) від 24.01.2000 N 751 ( 751-2000-п ) від 04.05.2000 )

Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита ( 4а-93, 4б-93, 4в-93 ) на окремі види товарів за переліком згідно з додатком.

2. Затвердити зміни, що вносяться до деяких постанов Кабінету Міністрів України (додаються).

3. Ця постанова набирає чинності через 45 днів з дня її опублікування в газеті "Урядовий кур'єр".
