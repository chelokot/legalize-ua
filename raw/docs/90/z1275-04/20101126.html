МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

28.09.2004 N 240

Зареєстровано в Міністерстві юстиції України 7 жовтня 2004 р. за N 1275/9874

Про удосконалення умов оплати праці працівників закладів охорони здоров'я, що перебувають в управлінні Державного управління справами

{ Про поширення умов оплати праці на працівників будинку відпочинку "Межигір'я" див. Наказ Міністерства праці та соціальної політики N 101 ( z0379-05 ) від 04.04.2005 }

{ Із змінами, внесеними згідно з Наказами Міністерства праці та соціальної політики

N 360 ( z1110-06 ) від 04.10.2006

N 328 ( z0714-07 ) від 21.06.2007

N 404 ( z1060-09 ) від 28.10.2009

N 328 ( z1043-10 ) від 21.10.2010 }

З метою удосконалення умов оплати праці працівників лікувально-оздоровчих закладів, що перебувають в управлінні Державного управління справами, НАКАЗУЮ:

1. Установити, що:

посадові оклади керівних, медичних та фармацевтичних працівників закладів охорони здоров'я, державної наукової установи "Науково-практичний центр профілактичної та клінічної медицини Державного управління справами" (далі - Центр), що перебувають в управлінні Державного управління справами, визначені виходячи з тарифних розрядів, передбачених для відповідних категорій працівників наказом Міністерства праці та соціальної політики України, Міністерства охорони здоров'я України від 05.10.2005 N 308/519 ( z1209-05 ) "Про впорядкування умов оплати праці працівників закладів охорони здоров'я та установ соціального захисту населення", зареєстрованим у Міністерстві юстиції України 17.10.2005 за N 1209/11489, підвищуються на 100 відсотків;

посадові оклади керівних та наукових працівників Центру, визначені виходячи з тарифних розрядів, передбачених для працівників інших наукових установ наказом Міністерства освіти і науки України від 26.09.2005 N 557 ( z1130-05 ) "Про впорядкування умов оплати праці та затвердження схем тарифних розрядів працівників навчальних закладів, установ освіти та наукових установ", зареєстрованим у Міністерстві юстиції України 03.10.2005 за N 1130/11410, підвищуються на 100 відсотків;

посадові оклади інших категорій працівників закладів охорони здоров'я та Центру, визначені виходячи з тарифних розрядів, передбачених для відповідних категорій працівників закладів охорони здоров'я та установ освіти, підвищуються на 80 відсотків.

Зазначені підвищення посадових окладів поширюються на працівників Головного управління санаторно-курортних закладів в Автономній Республіці Крим, оплата праці яких здійснюється за умовами оплати праці працівників закладів охорони здоров'я.

{ Пункт 1 із змінами, внесеними згідно з Наказами Міністерства праці та соціальної політики N 328 ( z0714-07 ) від 21.06.2007, N 404 ( z1060-09 ) від 28.10.2009 - застосовується з 1 вересня 2009 року, N 328 ( z1043-10 ) від 21.10.2010 }

2. Установити, що керівні працівники Центру, оплата праці яких здійснюється за умовами оплати праці працівників закладів охорони здоров'я, відносяться до першої групи з оплати праці керівних працівників.

Зберегти за керівними працівниками закладів охорони здоров'я (клінічна лікарня "Феофанія", державний заклад "Поліклініка N 2") першу групу з оплати праці керівних працівників, за керівниками інших закладів охорони здоров'я - другу групу з оплати праці керівних працівників.

Віднести будинок відпочинку "Конча-Заспа" до першої групи з оплати праці керівних працівників, комплекс відпочинку "Пуща-Водиця" - до другої групи з оплати праці керівних працівників.

{ Пункт 2 із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 360 ( z1110-06 ) від 04.10.2006; в редакції Наказу Міністерства праці та соціальної політики N 404 ( z1060-09 ) від 28.10.2009 - застосовується з 1 вересня 2009 року }

3. Вважати такими, що втратили чинність, накази Міністерства праці України: від 06.04.95 N 19 ( z0100-95 ) "Про підвищення посадових окладів працівникам лікувальних закладів Лікувально-оздоровчого об'єднання при Кабінеті Міністрів України", зареєстрований в Міністерстві юстиції України 11.04.95 за N 100/636, від 16.01.96 N 3 ( z0089-96 ) "Про підвищення посадових окладів працівникам лікувально-оздоровчих установ господарського управління Кабінету Міністрів України", зареєстрований в Міністерстві юстиції України 21.02.96 за N 89/1114, від 07.10.96 N 78 ( z0601-96 ) "Про розміри посадових окладів працівників закладів лікувально-оздоровчого об'єднання при Кабінеті Міністрів України", зареєстрований в Міністерстві юстиції України 15.10.96 за N 601/1626.

4. Цей наказ набирає чинності з 1 січня 2005 року.
