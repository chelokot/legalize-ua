Мінпраці України; Наказ від 28.09.2004 № 240

Про удосконалення умов оплати праці працівників закладів охорони здоров'я, що перебувають в управлінні Державного управління справами

Реєстрація: Мін'юст України від 07.10.2004 № 1275/9874

Стан: Чинний

Ідентифікатор: z1275-04

Текст документа від 03.07.2007:

МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

28.09.2004 N 240

Зареєстровано в Міністерстві юстиції України 7 жовтня 2004 р. за N 1275/9874

Про удосконалення умов оплати праці працівників лікувально-оздоровчих закладів, що перебувають в управлінні Державного управління справами

{ Про поширення на працівників будинку відпочинку "Межигір'я" умов оплати праці див. Наказ Міністерства праці

та соціальної політики N 101 ( z0379-05 ) від 04.04.2005 }

{ Із змінами, внесеними згідно з Наказами Міністерства праці та соціальної політики

N 360 ( z1110-06 ) від 04.10.2006

N 328 ( z0714-07 ) від 21.06.2007 }

З метою удосконалення умов оплати праці працівників лікувально-оздоровчих закладів, що перебувають в управлінні Державного управління справами, НАКАЗУЮ:

1. Установити з 1 січня 2005 року керівним, медичним та фармацевтичним працівникам лікувально-оздоровчих закладів, що перебувають в управлінні Державного управління справами, схемні посадові оклади, підвищені на 100 відсотків, а іншим працівникам цих закладів - на 80 відсотків порівняно з розмірами схемних посадових окладів відповідних категорій працівників закладів охорони здоров'я. { Абзац перший пункту 1 із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 328 ( z0714-07 ) від 21.06.2007 }

Зазначені підвищення посадових окладів поширюються на працівників Управління санаторно-курортних закладів в Автономній Республіці Крим, оплата праці яких здійснюється за умовами оплати праці працівників закладів охорони здоров'я.

2. Зберегти за керівниками закладів охорони здоров'я (Клінічна лікарня "Феофанія", Поліклініка N 1, Поліклініка N 2) першу групу за оплатою праці, за керівниками інших лікувально-оздоровчих закладів - другу групу за оплатою праці.

Віднести комплекс відпочинку "Пуща-Водиця" та будинок відпочинку "Конча-Заспа" до першої групи з оплати праці керівних працівників. { Пункт 2 доповнено абзацом згідно з Наказом Міністерства праці та соціальної політики N 360 ( z1110-06 ) від 04.10.2006 }

3. Вважати такими, що втратили чинність, накази Міністерства праці України: від 06.04.95 N 19 ( z0100-95 ) "Про підвищення посадових окладів працівникам лікувальних закладів Лікувально-оздоровчого об'єднання при Кабінеті Міністрів України", зареєстрований в Міністерстві юстиції України 11.04.95 за N 100/636, від 16.01.96 N 3 ( z0089-96 ) "Про підвищення посадових окладів працівникам лікувально-оздоровчих установ господарського управління Кабінету Міністрів України", зареєстрований в Міністерстві юстиції України 21.02.96 за N 89/1114, від 07.10.96 N 78 ( z0601-96 ) "Про розміри посадових окладів працівників закладів лікувально-оздоровчого об'єднання при Кабінеті Міністрів України", зареєстрований в Міністерстві юстиції України 15.10.96 за N 601/1626.

4. Цей наказ набирає чинності з 1 січня 2005 року.

Міністр М.Папієв
