{ Наказ втратив чинність на підставі Наказу Міністерства соціальної політики N 465 ( z0852-14 ) від 14.07.2014 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 30.09.2005 N 289

Відповідно до постанови Кабінету Міністрів України від 20 лютого 2006 року N 172 ( 172-2006-п ) "Про встановлення посадового окладу (тарифної ставки) працівника I тарифного розряду Єдиної тарифної сітки та внесення змін у додаток 2 до постанови Кабінету Міністрів України від 30 серпня 2002 р. N 1298" НАКАЗУЮ:

1. Унести зміну до наказу Міністерства праці та соціальної політики України від 30.09.2005 N 289 ( z1197-05 ) "Про умови оплати праці працівників бюджетних науково-дослідних установ Мінпраці України", зареєстрованого в Міністерстві юстиції України 13.10.2005 за N 1197/11477, виклавши додаток 1 у новій редакції (додається).

2. У разі, якщо після запровадження нових умов оплати праці в окремих працівників розмір заробітної плати (без урахування премій) зменшується, працівникам виплачується різниця між діючим та новим розміром заробітної плати.

3. Директору Науково-дослідного інституту соціально-трудових відносин (С.Мельник), директору Українського науково-дослідного інституту протезування, протезобудування та відновлення працездатності (А.Салєєва) установити працівникам місячні посадові оклади (тарифні ставки, оклади) згідно з встановленими їм тарифними розрядами, виходячи з розмірів посадових окладів (тарифних ставок), що визначені додатком 1.

4. Ці зміни застосовуються в терміни, що визначені додатком 1.

Міністр І.Сахань

ПОГОДЖЕНО:

Міністерство фінансів України Заступник Міністра В.Матвійчук

Додаток 1 до наказу Міністерства праці та соціальної політики України 30.09.2005 N 289 ( z1197-05 ) (у редакції наказу Міністерства праці та соціальної політики України від 07.03.2006 N 58)
