РОЗПОРЯДЖЕННЯ від 9 жовтня 2004 р. N 729-р Київ

Про переліки автомобільних доріг комунальної власності, будівництво і капітальний ремонт яких здійснюється у 2004 році за рахунок коштів державного бюджету

( Із змінами, внесеними згідно з Розпорядженням КМ N 885-р ( 885-2004-р ) від 04.12.2004 )

1. Відповідно до статті 36 Закону України "Про Державний бюджет України на 2004 рік" ( 1344-15 ) затвердити перелік автомобільних доріг комунальної власності, будівництво і капітальний ремонт яких здійснюється у 2004 році за рахунок коштів державного бюджету у сумі 155000 тис. гривень, згідно з додатком. ( Пункт 1 в редакції Розпорядження КМ N 885-р ( 885-2004-р ) від 04.12.2004 )

( Пункт 2 виключено на підставі Розпорядженн КМ N 885-р ( 885-2004-р ) від 04.12.2004 )
