КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 грудня 2005 р. N 1275 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 757 ( 757-2008-п ) від 27.08.2008 }

Про розмір стипендій Кабінету Міністрів України для молодих учених

Кабінет Міністрів України постановляє:

1. Установити з 1 січня 2006 р. розмір стипендій Кабінету Міністрів України для молодих учених, заснованих постановою Кабінету Міністрів України від 16 серпня 1994 р. N 560 ( 560-94-п ) (ЗП України, 1994 р., N 11, ст. 285), у сумі 270 гривень кожна.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 24 лютого 2003 р. N 215 ( 215-2003-п ) "Про розмір стипендій Кабінету Міністрів України для молодих учених" (Офіційний вісник України, 2003 р., N 9, ст. 383).
