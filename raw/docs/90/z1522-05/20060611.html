Реєстрація: Мін'юст України від 16.12.2005 № 1522/11802

Стан: Чинний

Ідентифікатор: z1522-05

Текст документа від 11.06.2006:

ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

05.12.2005 N 3098

Зареєстровано в Міністерстві юстиції України 16 грудня 2005 р. за N 1522/11802

Про внесення змін до Положення про порядок здійснення конкурсного відбору радників для підготовки та проведення конкурентних способів продажу об'єктів приватизації, затвердженого наказом Фонду державного майна України від 21 серпня 2000 року N 1745 та зареєстрованого в Міністерстві юстиції України 7 вересня 2000 року за N 590/4811

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Фонду державного майна N 1745 ( z0590-00 ) від 21.08.2000, до якого вносились зміни }

У зв'язку з набранням чинності Законом України "Про внесення змін до деяких законів України" від 6 вересня 2005 року N 2801-IV ( 2801-15 ) НАКАЗУЮ:

1. Абзац шостий пункту 3 Положення про порядок здійснення конкурсного відбору радників для підготовки та проведення конкурентних способів продажу об'єктів приватизації, затвердженого наказом Фонду державного майна України від 21 серпня 2000 року N 1745 ( z0590-00 ) та зареєстрованого в Міністерстві юстиції України 7 вересня 2000 року за N 590/4811, викласти в такій редакції:

"проведення незалежної оцінки з метою визначення початкової вартості пакетів акцій (згідно із чинною Методикою оцінки майна) та підготовка звіту про оцінку для затвердження державним органом приватизації оцінки пакета акцій".

2. Департаменту підготовки та проведення конкурсів (Є.Філозоп) в установленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Департаменту підготовки та проведення конкурсів (Є.Філозоп) у десятиденний строк з дня державної реєстрації цього наказу забезпечити його публікацію у газеті "Відомості приватизації" та "Державному інформаційному бюлетені про приватизацію".

4. Департаменту взаємодії з Верховною Радою України та зв'язків з громадськістю (А.Гриненко) у десятиденний термін з дня державної реєстрації цього наказу забезпечити його розміщення на Web-сторінці Фонду.

5. Контроль за виконанням цього наказу залишаю за собою.

Голова Фонду В.Семенюк
