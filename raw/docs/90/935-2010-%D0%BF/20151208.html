Текст документа від 08.12.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 жовтня 2010 р. N 935 Київ

Про внесення змін до деяких постанов Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 1002 ( 1002-2015-п ) від 05.12.2015 }

Кабінет Міністрів України постановляє:

1. Внести зміну до постанови Кабінету Міністрів України від 23 грудня 2009 р. N 1408 ( 1408-2009-п ) "Про збільшення статутного капіталу Національної акціонерної компанії "Нафтогаз України" (Офіційний вісник України, 2009 р., N 101, ст. 3535), замінивши у пункті 1 та абзаці першому пункту 4 цифри "12000000" цифрами "5776191".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 1002 ( 1002-2015-п ) від 05.12.2015 }

3. Міністерству палива та енергетики вжити заходів для державної реєстрації змін, внесених цією постановою до Статуту Національної акціонерної компанії "Нафтогаз України".

Прем'єр-міністр України М.АЗАРОВ

Інд. 37

{ Зміни, що вносяться до Статуту Національної акціонерної компанії "Нафтогаз України", втратили чинність на підставі Постанови КМ N 1002 ( 1002-2015-п ) від 05.12.2015 }
