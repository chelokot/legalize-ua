ПОСТАНОВА від 2 грудня 2009 р. N 1289 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 548 ( 548-2011-п ) від 25.05.2011 }

Про доповнення пункту 7 Порядку надання вихідних даних для проектування об'єктів містобудування

Кабінет Міністрів України постановляє:

Доповнити абзац перший пункту 7 Порядку надання вихідних даних для проектування об'єктів містобудування, затвердженого постановою Кабінету Міністрів України від 20 травня 2009 р. N 489 ( 489-2009-п ) (Офіційний вісник України, 2009 р., N 37, ст. 1260), реченням такого змісту: "У завданні на проектування обов'язково передбачається створення страхового фонду документації відповідно до ДСТУ 33.201:2004 "Страховий фонд документації. Страховий фонд документації на об'єкти будівництва. Порядок створення.".".
