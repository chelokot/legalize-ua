Про внесення змін до Положення про Національну академію державного управління при Президентові України

Внести до Положення про Національну академію державного управління при Президентові України, затвердженого Указом Президента України від 21 вересня 2001 року N 850 ( 850/2001 ) "Питання Національної академії державного управління при Президентові України" (зі змінами, внесеними Указами від 6 жовтня 2003 року N 1153 ( 1153/2003 ), від 2 червня 2006 року N 474 ( 474/2006 ) та від 2 серпня 2006 року N 668 ( 668/2006 ), такі зміни:

абзац третій пункту 8 виключити. У зв'язку з цим абзац четвертий вважати абзацом третім;

пункт 9 виключити.

Президент України В.ЮЩЕНКО
