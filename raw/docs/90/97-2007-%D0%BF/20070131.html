Текст документа від 31.01.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 січня 2007 р. N 97 Київ

Про визнання такими, що втратили чинність, актів Кабінету Міністрів України з питань затвердження та увільнення членів колегії Міністерства праці та соціальної політики

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, акти Кабінету Міністрів України з питань затвердження та увільнення членів колегії Міністерства праці та соціальної політики згідно з переліком, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 31 січня 2007 р. N 97

ПЕРЕЛІК актів Кабінету Міністрів України з питань затвердження та увільнення членів колегії Міністерства праці та соціальної політики, що втратили чинність

1. Постанова Кабінету Міністрів України від 12 жовтня 1992 р. N 582 ( 582-92-п ) "Про затвердження Грошиліна Г.О. членом колегії Міністерства праці України та увільнення від цих обов'язків Коверзнєва А.М.".

2. Постанова Кабінету Міністрів України від 19 вересня 1997 р. N 1043 ( 1043-97-п ) "Про затвердження членів колегії Міністерства праці та соціальної політики".

3. Постанова Кабінету Міністрів України від 21 жовтня 1998 р. N 1676 ( 1676-98-п ) "Про колегію Міністерства праці та соціальної політики України" (Офіційний вісник України, 1998 р., N 42, ст. 1560).

4. Постанова Кабінету Міністрів України від 22 грудня 1998 р. N 2051 ( 2051-98-п ) "Про колегію Міністерства праці та соціальної політики України" (Офіційний вісник України, 1998 р., N 51, ст. 1900).

5. Постанова Кабінету Міністрів України від 11 липня 2000 р. N 1106 ( 1106-2000-п ) "Про членів колегії Міністерства праці та соціальної політики".

6. Розпорядження Кабінету Міністрів України від 4 червня 2002 р. N 302 ( 302-2002-р ) "Про членів колегії Мінпраці".

7. Постанова Кабінету Міністрів України від 28 серпня 2002 р. N 1306 ( 1306-2002-п ) "Про колегію Міністерства праці та соціальної політики" (Офіційний вісник України, 2002 р., N 36, ст. 1703).

8. Постанова Кабінету Міністрів України від 15 жовтня 2002 р. N 1547 ( 1547-2002-п ) "Про колегію Міністерства праці та соціальної політики" (Офіційний вісник України, 2002 р., N 42, ст. 1948).

9. Розпорядження Кабінету Міністрів України від 23 травня 2003 р. N 292 ( 292-2003-р ) "Про членів колегії Мінпраці".

10. Розпорядження Кабінету Міністрів України від 27 жовтня 2003 р. N 641 ( 641-2003-р ) "Про зміну складу колегії Мінпраці".

11. Розпорядження Кабінету Міністрів України від 14 червня 2004 р. N 373 ( 373-2004-р ) "Про зміну складу колегії Мінпраці".
