Про затвердження Положення про Апеляційну раду Держпатенту України

( Із змінами, внесеними згідно з Наказом МОН N 390 ( z0576-00 ) від 16.08.2000 )

( Положення про Апеляційну раду Держпатенту України застосовується при розгляді справ по спорах щодо сортів рослин згідно з Наказом МОН N 47 ( z0120-02 ) від 28.01.2002 )

( Із змінами, внесеними згідно з Наказом Міністерства освіти і науки N 622 ( z0877-03 ) від 15.09.2003 )

Відповідно до законів України "Про охорону прав на винаходи і корисні моделі" ( 3687-12 ), "Про охорону прав на промислові зразки" ( 3688-12 ), "Про охорону прав на знаки для товарів і послуг" ( 3689-12 ), "Про охорону прав на сорти рослин" ( 3116-12 ) та на виконання доручення Кабінету Міністрів України від 04.03.94 N 3032/46 НАКАЗУЮ:

1. Затвердити Положення про Апеляційну раду Держпатенту України, що додається.

2. Скасувати дію Положення про Апеляційну раду Держпатенту України від 7 квітня 1994 року.

3. Опублікувати Положення, зазначене в п.1, в офіційному бюлетені Держпатенту України.

Голова Держпатенту України В.Л.Петров

( Положення про Апеляційну раду Державного департаменту інтелектуальної власності України втратило чинність на підставі Наказу Міністерства освіти і науки N 622 ( z0877-03 ) від 15.09.2003 )
