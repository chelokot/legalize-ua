НАКАЗ

N 171-а від 26.03.96 Зареєстровано в Міністерстві м.Київ юстиції України 7 травня 1996 р. vd960326 vn171-а за N 222/1247

( Наказ втратив чинність на підставі Наказу Мінекономіки, європ. інтеграції

N 70 ( z0286-02 ) від 11.03.2002 )

Про заходи МЗЕЗторгу України щодо забезпечення виконання постанови Кабінету Міністрів України від 19 лютого 1996 року N 229

( Із змінами, внесеними згідно з Наказом Мінекономіки N 240 ( z0089-01 ) від 07.11.2000 )

Відповідно до постанови Кабінету Міністрів України від 19 лютого 1996 року N 229 ( 229-96-п ) "Про затвердження Положення про порядок видачі індивідуальних ліцензій на здійснення резидентами майнових інвестицій за межами України і Положення про порядок контролю та звітності щодо використання майнових цінностей, які інвестуються за межами України", НАКАЗУЮ:

1. Покласти обов'язки по видачі індивідуальних ліцензій на здійснення резидентами майнових інвестицій за межами України на управління інвестиційного співробітництва спільно з Головним договірно-правовим управлінням, економічним управлінням, управлінням експортно-імпортного контролю та управлінням кон'юнктури та цінової інформації.

2. Затвердити "Порядок прийняття та розгляду МЗЕЗторгом документів для отримання індивідуальних ліцензій на здійснення резидентами майнових інвестицій за межами України" (додається).

3. Головному договірно-правовому управлінню забезпечити реєстрацію цього наказу в Міністерстві юстиції України.

4. Управлінню інформації та інформатики разом з Головним управлінням з питань зовнішньої торгівлі у тижневий термін після реєстрації цього наказу у Міністерстві юстиції України довести його до відома регіональних управлінь зовнішніх економічних зв'язків і в триденний термін забезпечити публікацію наказу в засобах масової інформації.

5. Управлінню інформації та інформатики в двотижневий термін забезпечити управління, зазначені в п.1 цього наказу, необхідним для видачі індивідуальних ліцензій програмним та інформаційним забезпеченням.

6. Управлінню праці та соціального захисту в двотижневий термін розглянути питання щодо введення додаткових одиниць в штатний розклад управління інвестиційного співробітництва.

7. Управлінню справами організувати в двотижневий термін виготовлення необхідної кількості бланків індивідуальних ліцензій та забезпечити управління інвестиційного співробітництва персональним комп'ютером РС-486 для виконання робіт по видачі ліцензій.

8. Управлінню фінансування, обліку та контролю разом з управлінням справами, економічним управлінням скласти кошторис витрат на видачу індивідуальних ліцензій, погодити його з Міністерством фінансів України.

9. Контроль за виконанням цього наказу покласти на Першого заступника Міністра Подолєва І.В.

Міністр С.Г.Осика

( Порядок прийняття та розгляду МЗЕЗторгом документів для отримання індивідуальних ліцензій на здійснення резидентами майнових інвестицій за межами України втратив чинність на підставі Наказу Мінекономіки N 240 ( z0089-01 ) від 07.11.2000 )
