{ Із змінами, внесеними згідно з Постановами Національного банку

N 230 ( z1093-12 ) від 11.06.2012 }

{ У заголовку та тексті Постанови слова "власних підрозділів" замінено словами "відокремлених підрозділів і банкоматів" згідно з Постановою Національного банку N 446 ( z0976-10 ) від 30.09.2010 }

Відповідно до статті 69 Закону України "Про банки і банківську діяльність" ( 2121-14 ) та з метою забезпечення формування операційної та звітної інформації банку як на консолідованій основі, так і в розрізі кожного підрозділу Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити Положення про порядок ведення банками реєстраційної кодифікації відокремлених підрозділів і банкоматів (додається).

2. Департаменту інформатизації (А.С.Савченко) до 01.10.2002 внести відповідні зміни до програмного забезпечення з метою здійснення доступу Національного банку України, територіальних управлінь Національного банку України до відповідної звітної інформації банків у розрізі їх структурних підрозділів за індивідуально встановленими внутрішньобанківськими реєстраційними кодами і за територіальною ознакою.

3. Зобов'язати банки розробити відповідно до Положення про порядок ведення банками реєстраційної кодифікації відокремлених підрозділів і банкоматів систему реєстраційної кодифікації відокремлених підрозділів і банкоматів, надати їм внутрішньобанківські реєстраційні коди та забезпечити формування і подання звітності в розрізі структурних підрозділів банку, починаючи з 01.01.2003.

4. Генеральному департаменту банківського нагляду (О.І.Кірєєв) довести цю постанову до відома і використання в роботі самостійних структурних підрозділів Національного банку України, територіальних управлінь Національного банку України, а також банків.

5. Ця постанова набирає чинності через десять днів після державної реєстрації в Міністерстві юстиції України.

6. Контроль за виконанням цієї постанови покласти на заступника Голови В.Л.Кротюка, Генеральний департамент банківського нагляду (О.І.Кірєєв), Операційне управління (В.Д.Щуцький) та начальників територіальних управлінь Національного банку України.

ПОЛОЖЕННЯ про порядок ведення банками реєстраційної кодифікації відокремлених підрозділів і банкоматів

{ Назва Положення із змінами, внесеними згідно з Постановою Національного банку N 446 ( z0976-10 ) від 30.09.2010 }

{ У тексті Положення слово "область" в усіх відмінках замінено словом "регіон" у відповідних відмінках згідно з Постановою Національного банку N 230 ( z1093-12 ) від 11.06.2012 }

Це Положення розроблено відповідно до Законів України "Про Національний банк України" ( 679-14 ), "Про банки і банківську діяльність" ( 2121-14 ), "Про платіжні системи та переказ коштів в Україні" ( 2346-14 ) та визначає порядок ведення банками реєстраційної кодифікації відокремлених підрозділів, пунктів обміну іноземної валюти (далі - обмінні пункти) і банкоматів (банкомата та/або банкоматів банку, які розміщуються на території одного регіону) та порядок ведення філіями іноземних банків реєстраційної кодифікації банкоматів і обмінних пунктів.

{ Преамбула в редакції Постанов Національного банку N 446 ( z0976-10 ) від 30.09.2010, N 230 ( z1093-12 ) від 11.06.2012 }

1. Це Положення розроблено з метою забезпечення формування операційної та звітної інформації банку як на консолідованій основі, так і в розрізі кожного відокремленого підрозділу за індивідуально встановленим внутрішньобанківським реєстраційним кодом і за територіальною ознакою.

{ Пункт 1 в редакції Постанови Національного банку N 446 ( z0976-10 ) від 30.09.2010 }

2. Банки зобов'язані розробити внутрішню систему реєстраційної кодифікації всіх відокремлених підрозділів обмінних пунктів, банкоматів відповідно до цього Положення та формувати операційну та звітну інформацію із зазначенням внутрішньобанківського реєстраційного коду відокремленого підрозділу обмінного пункту, банкомата.

Філії іноземних банків зобов'язані розробити внутрішню систему реєстраційної кодифікації банкоматів, обмінних пунктів відповідно до цього Положення та формувати операційну та звітну інформацію із зазначенням внутрішньобанківського реєстраційного коду банкомата, обмінного пункту. { Пункт 2 доповнено абзацом згідно з Постановою Національного банку N 230 ( z1093-12 ) від 11.06.2012 }

{ Пункт 2 із змінами, внесеними згідно з Постановами Національного банку N 446 ( z0976-10 ) від 30.09.2010, N 230 ( z1093-12 ) від 11.06.2012 }

3. У разі відкриття відокремленого підрозділу його внутрішньобанківський реєстраційний код повідомляється Національному банку України чи територіальному управлінню Національного банку України за місцезнаходженням банку/відокремленого підрозділу.

{ Пункт 3 в редакції Постанови Національного банку N 446 ( z0976-10 ) від 30.09.2010 }

4. Запровадження системи кодифікації відокремлених підрозділів обмінних пунктів, банкоматів банку має забезпечити доступ:

Національного банку України - до звітної інформації банку в цілому та в розрізі його філій, відділень, власних обмінних пунктів, банкоматів як на території України, так і за її межами, а також має забезпечити групування інформації за територіальною ознакою;

територіального управління Національного банку України за місцезнаходженням головного банку - до звітної інформації банку в цілому, а також у розрізі його відокремлених підрозділів обмінних пунктів, банкоматів, у тому числі за територіальною ознакою;

територіального управління Національного банку України за місцезнаходженням філії, відділення, обмінного пункту, банкомату - до інформації філії, відділення за територіальною ознакою.

Національного банку України та територіального управління Національного банку України за місцезнаходженням філії іноземного банку - до звітної інформації філії іноземного банку в цілому, а також у розрізі її банкоматів, обмінних пунктів за територіальною ознакою. { Пункт 4 доповнено абзацом згідно з Постановою Національного банку N 230 ( z1093-12 ) від 11.06.2012 }

{ Пункт 4 із змінами, внесеними згідно з Постановами Національного банку N 446 ( z0976-10 ) від 30.09.2010, N 230 ( z1093-12 ) від 11.06.2012 }

5. Система кодифікації відокремлених підрозділів, обмінних пунктів, банкоматів ведеться у вигляді числового ряду (двадцять символів):

N сегмента 1 2 3 4 5 6 7 8

Розрядність 000 00 000 0 00 000 00 0000 сегмента

Символьний NKB KOB KK TP KOF NF KOP NP, код сегмента

де: сегмент 1 - NKB - цифровий код банку - юридичної особи або філії іноземного банку (відповідає значенню поля PRKB довідника банків України);

сегмент 2 - KOB - цифровий код області за місцезнаходженням банку або філії іноземного банку (відповідає значенню поля KO довідника банків України);

сегмент 3 - KK - цифровий код країни за класифікатором держав світу (відповідає значенню поля K040 довідника банків України);

сегмент 4 - TP - тип відокремленого підрозділу, банкомата:

0 - банк (головний банк) або філія іноземного банку;

1 - філія, відкрита на території України;

2 - відділення;

3 - представництво, відкрите на території України;

4 - обмінний пункт;

5 - філія, відкрита за межами України;

6 - представництво, відкрите за межами України;

7 - банкомат;

сегмент 5 - KOF - цифровий код області за місцезнаходженням філії (відповідає значенню поля KU довідника банків України);

сегмент 6 - NF - номер філії:

при значенні сегмента TP = 1 номер відповідає значенню поля KB довідника банків України;

при значенні сегмента TP = 5 номер заповнюється за погодженням з Національним банком України;

сегмент 7 - KOP - цифровий код області за місцезнаходженням відокремленого підрозділу, банкомата, що відповідає сегменту TP = 2, або 3, або 4, або 7 (відповідно до довідника облуправлінь Національного банку України):

00 при значенні сегмента TP = 0, або 1, або 5, або 6;

цифровий код області за місцезнаходженням відділення при значенні сегмента TP = 2;

цифровий код області за місцезнаходженням представництва при значенні сегмента TP = 3 - представництво, відкрите на території України (сегмент KK = 804);

цифровий код області за місцезнаходженням обмінного пункту при значенні сегмента TP = 4. Якщо обмінний пункт відкрито філією, то значення KOP відповідає значенню сегмента KOF;

цифровий код області за місцезнаходженням банкомата при значенні сегмента TP = 7;

сегмент 8 - NP - номер відокремленого підрозділу банку, банкомата:

0000 при значенні сегмента TP = 0, або 1, або 5;

0000 при значенні сегмента TP = 7, якщо це банкомати, які розміщені на території однієї області (група банкоматів);

номер банкомата при значенні сегмента TP = 7, якщо це один банкомат, розміщений на території області;

номер відділення при значенні сегмента TP = 2 заповнюється за погодженням з Національним банком України;

номер представництва при значенні сегмента TP = 3 або 6;

номер обмінного пункту при значенні сегмента TP = 4".

{ Пункт 5 в редакції Постанов Національного банку N 446 ( z0976-10 ) від 30.09.2010, N 230 ( z1093-12 ) від 11.06.2012 }

6. У разі припинення філії, представництва, відділення, закриття обмінного пункту, банкомата внутрішньобанківський реєстраційний код, що належав припиненому відокремленому підрозділу, закритому обмінному пункту, банкомату, не може бути присвоєний іншому відокремленому підрозділу, обмінному пункту, банкомату, крім випадків зміни банком внутрішньої системи реєстраційної кодифікації.

{ Пункт 6 в редакції Постанови Національного банку N 446 ( z0976-10 ) від 30.09.2010 }
