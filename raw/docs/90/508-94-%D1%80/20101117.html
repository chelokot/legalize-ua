Кабінет Міністрів України; Розпорядження від 05.07.1994 № 508-р

Про віднесення деяких посад державних службовців до певних категорій

Стан: Втратив чинність

Ідентифікатор: 508-94-р

Текст документа від 17.11.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 липня 1994 р. N 508-р Київ

Про віднесення деяких посад державних службовців до певних категорій

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 463-р ( 463-96-р ) від 20.07.96 N 2104-р ( 2104-2010-р ) від 17.11.2010 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади голови Державного фонду сприяння місцевому самоврядуванню в Україні до першої категорії, його першого заступника та заступника до другої категорії посад державних службовців. { Абзац перший із змінами, внесеними згідно з Розпорядженнями КМ N 463-р ( 463-96-р ) від 20.07.96, N 2104-р ( 2104-2010-р ) від 17.11.2010 }

Посади інших працівників апарату зазначеного Фонду, які здійснюють організаційно-розпорядчі та консультативно-дорадчі функції, за категоріями прирівнюються до відповідних посад працівників міністерств.

Прем'єр-міністр України В.МАСОЛ
