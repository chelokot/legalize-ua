Президент України; Указ від 03.03.2007 № 172/2007

Про внесення змін до Указу Президента України від 29 травня 2006 року N 451

Стан: Чинний

Ідентифікатор: 172/2007

Текст документа від 03.03.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Указу Президента України від 29 травня 2006 року N 451

Внести до Указу Президента України від 29 травня 2006 року N 451 ( 451/2006 ) "Про визнання таким, що втратив чинність, Указу Президента України від 26 травня 1998 року N 511" зміни, виклавши його в такій редакції:

"Про скасування Указу Президента України від 26 травня 1998 року N 511

Керуючись частиною другою статті 102 Конституції України ( 254к/96-ВР ), постановляю:

Скасувати Указ Президента України від 26 травня 1998 року N 511 ( 511/98 ) "Про заходи щодо забезпечення конституційних прав громадян, а також керівництва процесами життєдіяльності міста Одеси" як такий, що виданий усупереч Конституції ( 254к/96-ВР ) і законам України".

Президент України В.ЮЩЕНКО

м. Київ, 3 березня 2007 року N 172/2007
