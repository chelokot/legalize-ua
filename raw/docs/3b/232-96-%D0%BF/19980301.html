Кабінет Міністрів України; Постанова від 21.02.1996 № 232

Про надбавки до грошового забезпечення працівників слідчих підрозділів органів внутрішніх справ, Служби безпеки і прокуратури

Стан: Втратив чинність

Ідентифікатор: 232-96-п

Текст документа від 01.03.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 лютого 1996 р. N 232 Київ

Про надбавки до грошового забезпечення працівників слідчих підрозділів органів внутрішніх справ, Служби безпеки і прокуратури

( Із змінами, внесеними згідно з Постановою КМ N 603 ( 603-96-п ) від 31.05.96 )

( Постанова втратила чинність у частині, що стосується осіб начальницького складу слідчих підрозділів органів внутрішніх справна на підставі Постанови КМ N 177 ( 177-97-п ) від 18.02.97 - набирає чинності з 1 грудня 1996 року )

( Із змінами, внесеними згідно з Постановою КМ N 322 ( 322-98-п ) від 17.03.98 )

З метою закріплення висококваліфікованих слідчих на службі в органах внутрішніх справ, Служби безпеки і прокуратури Кабінет Міністрів України постановляє:

1. Установити особам начальницького складу слідчих підрозділів органів внутрішніх справ, слідчим співробітникам Служби безпеки, начальникам слідчих підрозділів, їх заступникам, прокурорам-криміналістам і слідчим органів прокуратури та військових прокуратур: ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановами КМ N 603 ( 603-96-п ) від 31.05.96, N 322 ( 322-98-п ) від 17.03.98 )

щомісячну надбавку до окладів грошового утримання (для працівників органів прокуратури - до посадових окладів з урахуванням надбавок за класні чини) за службу на посадах слідчих і прокурорів - криміналістів у розмірах згідно з додатком; ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 603 ( 603-96-п ) від 31.05.96 )

щомісячну доплату за вислугу 20 і більше років на посадах начальницького складу в слідчих підрозділах органів внутрішніх справ, слідчих співробітників Служби безпеки, начальників слідчих підрозділів, їх заступників, прокурорів-криміналістів і слідчих органів прокуратури та військових прокуратур у розмірі 100 відсотків суми пенсії, яка може бути їм нарахована у разі виходу на пенсію. ( Абзац третій пункту 1 із змінами, внесеними згідно з Постановами КМ N 603 ( 603-96-п ) від 31.05.96, N 322 ( 322-98-п ) від 17.03.98 )

Доплата за вислугу 20 і більше років виплачується без урахування встановленої цією постановою щомісячної надбавки.

2. Витрати, пов'язані із запровадженням зазначених надбавок і доплат, здійснювати в межах коштів, що виділяються на утримання органів внутрішніх справ, Служби безпеки і прокуратури.

3. Ця постанова вводиться в дію з 1 січня 1996 року.
