Про надбавки до грошового забезпечення працівників слідчих підрозділів органів внутрішніх справ, Служби безпеки і прокуратури

Стан: Втратив чинність

Ідентифікатор: 232-96-п

Текст документа від 04.02.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 лютого 1996 р. N 232 Київ

Про надбавки до грошового забезпечення працівників слідчих підрозділів органів внутрішніх справ, Служби безпеки і прокуратури

{ Із змінами, внесеними згідно з Постановою КМ N 603 ( 603-96-п ) від 31.05.96

{ Постанова втратила чинність у частині, що стосується осіб начальницького складу слідчих підрозділів органів внутрішніх справ на підставі Постанови КМ N 177 ( 177-97-п ) від 18.02.97 }

{ Із змінами, внесеними згідно з Постановами КМ N 322 ( 322-98-п ) від 17.03.98 N 1440 ( 1440-2002-п ) від 26.09.2002 }

{ Постанова втратила чинність у частині, що стосується слідчих співробітників Служби безпеки України на підставі Постанови КМ N 1294 ( 1294-2007-п ) від 07.11.2007 }

{ Із змінами, внесеними згідно з Постановами КМ N 75 ( 75-2013-п ) від 04.02.2013 N 26 ( 26-2015-п ) від 28.01.2015 }

З метою закріплення висококваліфікованих слідчих на службі в органах внутрішніх справ, Служби безпеки і прокуратури Кабінет Міністрів України постановляє:

1. Установити особам начальницького складу слідчих підрозділів органів внутрішніх справ, слідчим співробітникам Служби безпеки, начальникам слідчих підрозділів, їх заступникам, прокурорам-криміналістам і слідчим органів прокуратури, а також військовослужбовцям військової прокуратури: { Абзац перший пункту 1 із змінами, внесеними згідно з Постановами КМ N 603 ( 603-96-п ) від 31.05.96, N 322 ( 322-98-п ) від 17.03.98, N 75 ( 75-2013-п ) від 04.02.2013, N 26 ( 26-2015-п ) від 28.01.2015 }

щомісячну надбавку до посадового окладу з урахуванням надбавки за класний чин (для працівників органів прокуратури) або з урахуванням окладу за військовим званням (для військовослужбовців військової прокуратури) за службу на посадах слідчих і прокурорів-криміналістів у розмірах згідно з додатком. { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 603 ( 603-96-п ) від 31.05.96; в редакції Постанови КМ N 26 ( 26-2015-п ) від 28.01.2015 }

{ Абзац третій пункту 1 виключено на підставі Постанови КМ N 26 ( 26-2015-п ) від 28.01.2015 }

{ Абзац четвертий пункту 1 виключено на підставі Постанови КМ N 26 ( 26-2015-п ) від 28.01.2015 }

2. Витрати, пов'язані із запровадженням зазначених надбавок і доплат, здійснювати в межах коштів, що виділяються на утримання органів внутрішніх справ, Служби безпеки і прокуратури.

3. Ця постанова вводиться в дію з 1 січня 1996 року.
