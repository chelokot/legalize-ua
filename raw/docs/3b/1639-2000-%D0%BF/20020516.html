Кабінет Міністрів України; Постанова від 03.11.2000 № 1639

Про внесення змін до постанови Кабінету Міністрів України від 8 січня 2000 р. N 13

Стан: Втратив чинність

Ідентифікатор: 1639-2000-п

Текст документа від 16.05.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 листопада 2000 р. N 1639 Київ

( Постанова втратила чинність на підставі Постанови КМ N 622 ( 622-2002-п ) від 16.05.2002 )

Про внесення змін до постанови Кабінету Міністрів України від 8 січня 2000 р. N 13

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 8 січня 2000 р. N 13 ( 13-2000-п ) "Про вдосконалення системи головних розпорядників коштів державного бюджету" (Офіційний вісник України, 2000 р., N 2, ст. 36, N 6, ст. 225, N 7, ст. 274, N 12, ст. 468, N 18, ст. 739, N 20, ст. 820, N 23, ст. 940, N 31, ст. 1316, N 36, ст. 1530) такі зміни:

1) доповнити перелік головних розпорядників коштів державного бюджету, затверджений зазначеною постановою, словами "Державний комітет промислової політики";

2) у позиції "Міністерство економіки" Схеми підпорядкування розпорядників коштів державного бюджету нижчого рівня та їх одержувачів головним розпорядникам цих коштів, затвердженої зазначеною постановою, слова "Державний комітет промислової політики" виключити.

Перший віце-прем'єр-міністр України Ю.ЄХАНУРОВ
