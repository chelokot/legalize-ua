Кабінет Міністрів України; Розпорядження від 16.12.1999 № 1411-р

Про віднесення посади Урядового Секретаря Кабінету Міністрів України до першої категорії посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 1411-99-р

Текст документа від 03.10.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 грудня 1999 р. N 1411-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посаду Урядового Секретаря Кабінету Міністрів України до першої категорії посад державних службовців.
