Кабінет Міністрів України; Розпорядження від 14.10.2009 № 1222-р

Про зміни складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів соціального страхування

Стан: Втратив чинність

Ідентифікатор: 1222-2009-р

Текст документа від 11.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 жовтня 2009 р. N 1222-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 19-р ( 19-2012-р ) від 11.01.2012 }

Про зміни складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів соціального страхування

Внести до складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах Фонду соціального страхування від нещасних випадків на виробництві та професійних захворювань, затвердженого розпорядженням Кабінету Міністрів України від 15 вересня 2006 р. N 488 ( 488-2006-р ) (Офіційний вісник України, 2006 р., N 38, ст. 2597; 2008 р., N 15, ст. 395, N 87, ст. 2924), та Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття, затвердженого розпорядженням Кабінету Міністрів України від 21 лютого 2007 р. N 59 ( 59-2007-р ) (Офіційний вісник України, 2007 р., N 14, ст. 536, N 39, ст. 1567, N 91, ст. 3341; 2008 р., N 15, ст. 396, N 87, ст. 2924), зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 26

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 14 жовтня 2009 р. N 1222-р

ЗМІНИ, що вносяться до складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів соціального страхування ( 488-2006-р, 59-2007-р )

1. Ввести до складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду соціального страхування від нещасних випадків на виробництві та професійних захворювань ( 488-2006-р ):

1) у правлінні:

СОЛОДКУ - заступника директора департаменту

Інну Василівну Мін'юсту

Вивести із складу правління Фонду Топорову Олену Володимирівну;

2) у наглядовій раді:

ДЄНЬГІНА - першого заступника Голови

Анатолія Петровича Держгірпромнагляду

Вивести із складу наглядової ради Фонду Суслова Геннадія Михайловича;

3) зазначити нові посади таких членів правління Фонду:

ГАВРИЛЮК - завідуюча сектором Мінагрополітики

Валентина Іванівна

СУМОВСЬКИЙ - директор Держнаглядпраці -

Володимир Васильович Головний державний інспектор праці

ЯЩЕНКО - директор департаменту Мінвуглепрому

Ігор Олексійович

2. Ввести до складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття ( 59-2007-р ):

1) у правлінні:

ПРИСТУПУ - заступника Голови Держкомпідприємництва Миколу Івановича

ЩЕГЛОВУ - заступника директора департаменту МОН

Ольгу Миколаївну

Вивести із складу правління Фонду Сахненко Ольгу Михайлівну та Кулікова Петра Мусійовича;

2) зазначити нову посаду члена правління Фонду:

САВЕНКО - директор департаменту Мінекономіки

Олександр Леонідович
