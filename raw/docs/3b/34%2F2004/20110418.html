Про внесення змін до деяких указів Президента України та визнання таким, що втратив чинність, Указу Президента України від 25 травня 1998 року N 506

Стан: Чинний

Ідентифікатор: 34/2004

Текст документа від 18.04.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до деяких указів Президента України та визнання таким, що втратив чинність, Указу Президента України від 25 травня 1998 року N 506

{ Із змінами, внесеними згідно з Указом Президента N 384/2011 ( 384/2011 ) від 06.04.2011 }

У зв'язку з прийняттям Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ) постановляю:

1. Внести до указів Президента України такі зміни:

1) абзац другий статті 10 Указу Президента України від 28 лютого 1997 року N 187 ( 187/97 ) "Про заходи щодо забезпечення наповнення державного бюджету та посилення фінансово-бюджетної дисципліни" (зі змінами, внесеними Указом від 29 березня 2001 року N 219 ( 219/2001 ) після слова "бюджетів" доповнити словами "страхових внесків на загальнообов'язкове державне пенсійне страхування".

{ Пункт 2 статті 1 втратив чинність на підставі Указу Президента N 384/2011 ( 384/2011 ) від 06.04.2011 }

2. Визнати таким, що втратив чинність, Указ Президента України від 25 травня 1998 року N 506 ( 506/98 ) "Про обмеження максимальної величини фактичних витрат суб'єктів господарювання на оплату праці працівників, суми оподатковуваного доходу (прибутку), сукупного оподатковуваного доходу, з яких справляються збори (внески) до соціальних фондів".

Президент України Л.КУЧМА

м. Київ, 12 січня 2004 року N 34/2004
