Про визначення місць митного оформлення окремих видів товарів

( Із змінами, внесеними згідно з Наказами Державної митної служби N 745 ( z1028-03 ) від 04.11.2003 N 96 ( z0253-04 ) від 13.02.2004 N 32 ( z0123-05 ) від 20.01.2005 )

З метою посилення митного контролю товарів, що потребують особливих умов зберігання, у тому числі контролю за правильністю визначення митної вартості, країни походження товарів, а також їх класифікації, відповідно до статті 71 Митного кодексу України ( 1970-12 ), та з метою забезпечення наповнення доходної частини Державного бюджету України НАКАЗУЮ: ( Вступна частина Наказу із змінами, внесеними згідно з Наказом Державної митної служби N 96 ( z0253-04 ) від 13.02.2004 )

1. Визначити місцями митного оформлення товарів, що класифікуються в товарних позиціях 0302-0307, 1604 та 1605 УКТ ЗЕД ( 2371а-14 ), Кримську, Донбаську, Київську, Чорноморську регіональні митниці та Бердянську, Бориспільську, Житомирську, Миколаївську й Севастопольську митниці.

( Пункт 1 із змінами, внесеними згідно з Наказом Державної митної служби N 745 ( z1028-03 ) від 04.11.2003, в редакції Наказу Державної митної служби N 96 ( z0253-04 ) від 13.02.2004, із змінами, внесеними згідно з Наказом Державної митної служби N 32 ( z0123-05 ) від 20.01.2005 )

2. Установити, що в окремих випадках проведення митного оформлення товарів, визначених у п. 1 цього наказу, в інших митницях, крім визначених, допускається за погодженням з Державною митною службою України.

3. Дія цього наказу не поширюється на товари, митне оформлення яких здійснюється в митному режимі імпорту з особливостями переміщення як гуманітарної допомоги, як дару, як подання безоплатної допомоги й (або) на благодійні потреби по лінії держав, урядів, міжнародних організацій, а також митне оформлення яких здійснюється в митних режимах експорту й транзиту. ( Пункт 3 в редакції Наказу Державної митної служби N 96 ( z0253-04 ) від 13.02.2004 )

4. Управлінню контролю митної вартості та номенклатури (Войцещук А.Д.), Управлінню правової роботи (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

5. Начальникам визначених вище митних органів в місячний термін з дати набрання чинності цим наказом подати до Управління контролю митної вартості та номенклатури звіти про результати застосування цього наказу.

6. Управлінню податків та зборів (Ліпіхіна Т.Д.) урахувати наслідки застосування цього наказу при встановленні й аналізі виконання планових показників у розрізі митних органів.

7. Начальникам митних органів забезпечити видачу суб'єктам зовнішньоекономічної діяльності листів-узгоджень щодо товарів, визначених у п. 1 цього наказу.

8. Інформаційно-аналітичному митному управлінню (Шуляк В.П.) внести необхідні зміни до відповідного програмного забезпечення.

9. Відділу з питань взаємодії із засобами масової інформації та зв'язків із громадськістю (Гунько С.О.) забезпечити висвітлення цього наказу в засобах масової інформації після його державної реєстрації.

10. Контроль за виконанням наказу покласти на заступника Голови Служби Дьоміна Ю.М.

11. Наказ набирає чинності через 30 днів після його державної реєстрації в Міністерстві юстиції України.
