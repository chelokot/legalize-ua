Про імпорт та експорт продукції у 1992 - 1993 роках

Стан: Дію відновлено

Ідентифікатор: 559-92-р

Текст документа від 05.11.1992:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 вересня 1992 р. N 559-р Київ

( Дію Розпорядження відновлено згідно з Розпорядженням КМ N 730-р ( 730-92-р ) від 05.11.92 )

( Розпорядження втратило чинність на підставі Розпорядження КМ N 689-р ( 689-92-р ) від 21.10.92 )

( Із змінами, внесеними згідно з Розпорядженням КМ N 730-р ( 730-92-р ) від 05.11.92 )

З метою запобігання зупиненню ряду підприємств по виробництву будівельних матеріалів, електронних приладів, хімічної та електротехнічної продукції прийняти пропозицію Міндержресурсів про закупівлю по імпорту капролактаму, полімерного компаунду, пластикату кабельного, меламіну, ацетону, соди кальцинованої, титанового шлаку в обсягах згідно з додатком N 1.

Для одержання необхідної валюти дозволити Міндержресурсів реалізувати у 1992 - 1993 роках в установленому порядку на експорт хімічну продукцію, вироблену в межах державного замовлення, в тому числі на основі бартерних угод, згідно з додатком N 2.
