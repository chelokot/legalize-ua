ДЕРЖАВНИЙ КОМІТЕТ У СПРАВАХ ОХОРОНИ ДЕРЖАВНОГО КОРДОНУ УКРАЇНИ

НАКАЗ

N 546 від 21.12.96 Зареєстровано в Міністерстві м.Київ юстиції України 25 грудня 1996 р. за N 740/1765

( Наказ втратив чинність на підставі Наказу Адміністрації Державної прикордонної служби

N 450 ( z0756-04 ) від 07.06.2004 )

Про доповнення додатку до Інструкції про порядок виплати військовослужбовцям Прикордонних військ України посадових окладів, підвищених на 25 відсотків, за службу в підрозділах, які підпадають під статус гірських

Відповідно до постанов Кабінету Міністрів України від 11 серпня 1995 року N 648 ( 648-95-п ) "Про умови оплати праці осіб, які працюють в гірських районах", від 3 квітня 1996 року N 392 ( 392-96-п ) "Про часткову зміну постанови Кабінету Міністрів України від 11 серпня 1995 року N 648" НАКАЗУЮ:

Розділ "Чернівецький прикордонний загін" Переліку підрозділів Прикордонних військ України, які підпадають під статус гірських, у додатку до Інструкції про порядок виплати військовослужбовцям Прикордонних військ України посадових окладів, підвищених на 25 відсотків, за службу в підрозділах, які підпадають під статус гірських, затвердженої наказом Голови Держкомкордону від 26 листопада 1996 року N 508 ( z0700-96 ) після слів "прикордонна застава Чимірний" доповнити словами "прикордонна застава Перкалаб".

2. Наказ довести до усіх зацікавлених посадових осіб.
