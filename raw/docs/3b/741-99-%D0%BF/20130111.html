Про Сорочинський ярмарок

{ Із змінами, внесеними згідно з Постановами КМ N 2082 ( 2082-99-п ) від 13.11.99 N 1202 ( 1202-2002-п ) від 19.08.2002 N 1214 ( 1214-2003-п ) від 06.08.2003 N 1005 ( 1005-2007-п ) від 08.08.2007 }

З метою пропаганди здобутків вітчизняних товаровиробників, сприяння розширенню економічних зв'язків між регіонами України та розвитку підприємництва Кабінет Міністрів України постановляє:

1. Прийняти пропозицію Полтавської обласної державної адміністрації щодо розширення участі підприємств, установ і організацій різних регіонів України та зарубіжних країн у щорічному Сорочинському ярмарку, який проводити в передостанній тиждень серпня.

Взяти до відома, що місце проведення Сорочинського ярмарку визначає Великосорочинська сільська рада Миргородського району Полтавської області.

2. Утворити Координаційний комітет з підготовки та проведення щорічного Сорочинського ярмарку. { Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 1202 ( 1202-2002-п ) від 19.08.2002; в редакції Постанови КМ N 1005 ( 1005-2007-п ) від 08.08.2007 }

Встановити, що до складу цього Комітету входять посадові особи згідно з додатком. ( Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 2082 ( 2082-99-п ) від 13.11.99, в редакції Постанови КМ N 1202 ( 1202-2002-п ) від 19.08.2002 )

Голові Координаційного комітету затвердити положення про цей Комітет, його персональний склад. Надати голові Координаційного комітету право вносити зміни до складу Комітету і затверджувати секретаріат.

Координаційному комітетові разом із заінтересованими центральними та місцевими органами виконавчої влади внести у двомісячний термін до Кабінету Міністрів України проект Положення про Сорочинський ярмарок.

3. Виділити Полтавській обласній державній адміністрації 500 тис. гривень на здійснення заходів, пов'язаних з проведенням Сорочинського ярмарку у 1999 році.

Міністерству фінансів профінансувати зазначені витрати за рахунок коштів резервного фонду Кабінету Міністрів України,

4. Міністерству фінансів у процесі формування проекту Державного бюджету України на 2000 і наступні роки передбачати кошти Полтавській обласній державній адміністрації для фінансування заходів з організації та проведення Сорочинського ярмарку у межах бюджетних можливостей.

5. Центральним органам виконавчої влади, Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям:

щороку до 1 червня подавати секретаріату Координаційного комітету з підготовки та проведення щорічного Сорочинського ярмарку заявку щодо участі у ярмарку підприємств, установ і організацій регіонів (галузей);

забезпечувати своєчасну підготовку експонатів для формування галузевих і регіональних експозицій на ярмарку;

вжити заходів до розширення участі у ярмарку підприємств різних форм власності (із залученням їхніх коштів).

6. Полтавській обласній державній адміністрації разом з Міністерством культури і мистецтв щороку передбачати проведення естрадно-концертних та інших заходів під час Сорочинського ярмарку.

7. Державному комітетові телебачення і радіомовлення та Державному комітетові інформаційної політики сприяти висвітленню в засобах масової інформації ходу підготовки та проведення щорічного Сорочинського ярмарку.

( Пункт 8 втратив чинність на підставі Постанови КМ N 1214 ( 1214-2003-п ) від 06.08.2003 )
