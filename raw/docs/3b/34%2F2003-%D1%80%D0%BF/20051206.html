Про голову Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 34/2003-рп

Текст документа від 06.12.2005:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Розпорядження Президента

N 1262/2005-рп ( 1262/2005-рп ) від 06.12.2005 )

Про голову Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва

На зміну Розпорядження Президента України від 20 серпня 2001 року N 205 ( 205/2001-рп ) призначити ЯНУКОВИЧА Віктора Федоровича - Прем'єр-міністра України - головою Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва, увільнивши від виконання цих обов'язків Кінаха А.К.

Президент України Л.КУЧМА
