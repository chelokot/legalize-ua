Про затвердження вартості користування даними ЄДРПОУ

На виконання пунктів 7 та 8 Положення про Єдиний державний реєстр підприємств та організацій України, затвердженого постановою Кабінету Міністрів України від 22.01.96 N 118 ( 118-96-п ) (із змінами, внесеними постановами Кабінету Міністрів України від 17.08.98 N 1298 ( 1298-98-п ) та від 25.08.98 N 1336 ( 1336-98-п ), і пункту 5 Положення про виконання статистичних робіт та надання органами державної статистики послуг на платній основі, затвердженого постановою Кабінету Міністрів України від 03.08.98 N 1214 ( 1214-98-п ), НАКАЗУЮ:

1. Затвердити вартість користування даними Єдиного державного реєстру підприємств та організацій України (додається).

2. Вважати таким, що втратив чинність, наказ Міністерства статистики України від 29.02.96 N 63 ( z0127-96 ), зареєстрований Міністерством юстиції України 20.03.96 за N 127/1152.

3. Скасувати наказ Міністерства статистики України від 30.08.96 N 256.

4. Контроль за виконанням цього наказу покласти на заступника Голови комітету Шишкіну К.М.

Голова комітету О.Г.Осауленко
