Деякі питання розпорядження земельними лісовими ділянками

Стан: Втратив чинність

Ідентифікатор: 610-2008-р

Текст документа від 02.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 квітня 2008 р. N 610-р Київ

Деякі питання розпорядження земельними лісовими ділянками

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 598-р ( 598-2009-р ) від 03.06.2009 N 848-р ( 848-2009-р ) від 08.07.2009 N 96-р ( 96-2010-р ) від 20.01.2010 N 107-р ( 107-2010-р ) від 13.01.2010 N 188-р ( 188-2010-р ) від 03.02.2010 N 1253-р ( 1253-2010-р ) від 23.06.2010 N 1958-р ( 1958-2010-р ) від 12.10.2010 N 153-р ( 153-2011-р ) від 23.02.2011 N 1090-р ( 1090-2011-р ) від 02.11.2011 }

З метою недопущення фактів порушення інтересів держави і суспільства під час відчуження та зміни цільового призначення земельних лісових ділянок (далі - ділянки) Міністерству екології та природних ресурсів, Міністерству аграрної політики та продовольства, Міністерству оборони, Державному агентству лісових ресурсів та Державному агентству земельних ресурсів до законодавчого врегулювання питань запобігання зловживанням у цій сфері: { Абзац перший із змінами, внесеними згідно з Розпорядженням КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

зупинити прийняття рішень про надання згоди на вилучення ділянок, їх передачу у власність та оренду із зміною цільового призначення, крім випадків, коли за умови обґрунтування неможливості реалізації альтернативних варіантів вирішення питання ділянки вилучаються і передаються у постійне користування та/або в оренду: { Абзац другий із змінами, внесеними згідно з Розпорядженнями КМ N 598-р ( 598-2009-р ) від 03.06.2009, N 848-р ( 848-2009-р ) від 08.07.2009, N 96-р ( 96-2010-р ) від 20.01.2010, N 107-р ( 107-2010-р ) від 13.01.2010, N 188-р ( 188-2010-р ) від 03.02.2010, N 1253-р ( 1253-2010-р ) від 23.06.2010, N 1958-р ( 1958-2010-р ) від 12.10.2010; в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

- для будівництва, реконструкції та капітального ремонту залізничних ліній та автомобільних доріг загального користування; { Абзац в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

- для розміщення кладовищ; { Абзац в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

- за рішенням Кабінету Міністрів України - для: { Абзац в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

будівництва та обслуговування об'єктів енергетичної інфраструктури (газо-, нафтопроводів, газових та нафтових терміналів, газових та нафтових свердловин, ліній електропередачі, електростанцій, електропідстанцій, розподільних пунктів, ядерних установок); { Абзац в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

видобування корисних копалин відповідно до спеціальних дозволів на користування надрами; { Абзац в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

облаштування державного кордону та будівництва пунктів пропуску через нього; { Абзац в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

забезпечення відбудови та функціонування монастирів на місцях їх історичного заснування; { Абзац в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

будівництва, реконструкції та капітального ремонту об'єктів, визначених Державною цільовою програмою підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу ( 357-2010-п ); { Абзац в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

розміщення інфраструктури оптових ринків сільськогосподарської продукції; { Розпорядження доповнено новим абзацом згідно з Розпорядженням КМ N 1090-р ( 1090-2011-р ) від 02.11.2011 }

створення та забезпечення функціонування об'єктів природно-заповідного фонду і виробничо-соціальних об'єктів, необхідних для ведення лісового господарства; { Абзац в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

розміщення інших об'єктів, вилучення і надання ділянок для яких здійснюється за рішенням Кабінету Міністрів України; { Абзац в редакції Розпорядження КМ N 153-р ( 153-2011-р ) від 23.02.2011 }

відкликати раніше надану згоду на вилучення ділянок, їх передачу у власність та оренду із зміною цільового призначення у разі, коли місцевими органами виконавчої влади чи органами місцевого самоврядування не прийнято відповідні рішення або коли за результатами перевірки встановлено, що такі рішення прийняті з порушенням вимог законодавства;

подати у триденний строк Кабінетові Міністрів України пропозиції про внесення змін до Земельного ( 2768-14 ) та Лісового ( 3852-12 ) кодексів України стосовно удосконалення процедури розпорядження ділянками.

Прем'єр-міністр України Ю.ТИМОШЕНКО
