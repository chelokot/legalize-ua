ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про зміну меж міста Алушта Автономної Республіки Крим

( Відомості Верховної Ради України (ВВР), 2005, N 32, ст.424 )

{ Додатково див. Ухвалу Севастопольського апеляційного господарського суду N 2-6/14203-2006А ( v2-6_805-07 ) від 07.06.2007 }

Верховна Рада України постановляє:

1. Включити у межі міста Алушта Автономної Республіки Крим 110,0 гектара земель, які знаходяться у віданні Алуштинської міської ради, і затвердити загальну площу міста 698,3 гектара.

2. Встановити межі міста Алушта згідно з додатком.

3. Контроль за виконанням цієї Постанови покласти на Комітет Верховної Ради України з питань державного будівництва та місцевого самоврядування, зобов'язавши його звернути особливу увагу на використання включених у межі міста Алушта цією Постановою земель.
