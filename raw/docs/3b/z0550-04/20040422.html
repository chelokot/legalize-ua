НАКАЗ

22.04.2004 N 333

Зареєстровано в Міністерстві юстиції України 28 квітня 2004 р. за N 550/9149

Про внесення зміни до Положення про порядок видання Держфлотінспекцією України обов'язкових для виконання посадовими особами приписів щодо усунення порушень вимог нормативних актів з питань безпеки судноплавства та контроль за їх виконанням

З метою приведення Положення про порядок видання Держфлотінспекцією України обов'язкових для виконання посадовими особами приписів щодо усунення порушень вимог нормативних актів з питань безпеки судноплавства та контроль за їх виконанням ( z0700-03 ) до вимог Кодексу торговельного мореплавства України ( 176/95-ВР ) та Положення про Головну державну інспекцію України з безпеки судноплавства, затвердженого постановою Кабінету Міністрів України від 30.12.1998 N 2098 ( 2098-98-п ), НАКАЗУЮ:

1. Внести зміну до Положення про порядок видання Держфлотінспекцією України обов'язкових для виконання посадовими особами приписів щодо усунення порушень вимог нормативних актів з питань безпеки судноплавства та контроль за їх виконанням, затвердженого наказом Міністерства транспорту України від 09.06.2003 N 428 ( z0700-03 ) та зареєстрованого в Міністерстві юстиції України 08.08.2003 за N 700/8021, що додається.

2. Департаменту нормативно-правового забезпечення (Ониськів М.М.) подати цей наказ на державну реєстрацію до Міністерства юстиції України у встановленому порядку.

3. Головній державній інспекції України з безпеки судноплавства (Щипцов О.А.) довести цей наказ до відома морських та річкових портів, судноплавних компаній, інших піднаглядних підприємств, установ та організацій.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Кроля С.С.

Міністр Г.Кірпа
