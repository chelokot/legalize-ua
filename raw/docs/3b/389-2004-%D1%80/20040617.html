Кабінет Міністрів України; Розпорядження від 17.06.2004 № 389-р

Деякі питання реалізації Закону України "Про Державну спеціальну службу транспорту"

Стан: Чинний

Ідентифікатор: 389-2004-р

Текст документа від 17.06.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 червня 2004 р. N 389-р Київ

Деякі питання реалізації Закону України "Про Державну спеціальну службу транспорту"

1. Міноборони і Мінтрансу відповідно до пункту 2 розділу VIII Закону України "Про Державну спеціальну службу транспорту" ( 1449-15 ) здійснити заходи, пов'язані з передачею залізничних військ Збройних Сил у підпорядкування Мінтрансу та їх перетворенням у Державну спеціальну службу транспорту.

2. Міноборони:

1) вирішити в установленому порядку питання щодо направлення військовослужбовців залізничних військ Збройних Сил до Державної спеціальної служби транспорту для подальшого проходження військової служби;

2) передати у двомісячний строк до сфери управління Мінтрансу закріплені за залізничними військами:

озброєння, боєприпаси, техніку, військове майно, інші матеріально-технічні засоби, в тому числі тривалого зберігання, та радіочастотний ресурс;

майнові комплекси (військових містечок N 35, м. Червоноград Львівської області), N 49 (м. Чоп Закарпатської області), N 86 (м. Дніпропетровськ), N 50 (м. Кривий Ріг Дніпропетровської області), N 54, 55, 56 і 58 (м. Чернігів), N 85 (м. Новомосковськ Дніпропетровської області), N 403 (м. Львів), 239 і 244 (м. Харків), N 291 (м. Київ), N 3 (м. Конотоп Сумської області), N 6 (м. Лозова Харківської області), N 73 (м. Полтава), N 243 (смт Манченки Харківського району Харківської області), N 16 (с. Ніжиловичі Макарівського району Київської області);

матеріально-технічні засоби та військове майно служб тилу поточного забезпечення та тривалого зберігання;

нерухоме майно (об'єкти незавершеного будівництва) - 40-квартирний будинок (шифр 137-у) в м. Ужгороді та 18-квартирний будинок (шифр 26/96) у м. Чопі;

3) забезпечити на момент передачі залізничних військ погашення кредиторської заборгованості їх військових частин.

3. Міноборони і Мінтрансу разом з Мінфіном вирішити питання щодо передачі Мінтрансу бюджетних призначень, передбачених для Міноборони у Державному бюджеті України на 2004 рік ( 1344-15 ) для утримання залізничних військ.

4. Мінтрансу у шестимісячний строк розробити і подати Кабінетові Міністрів України проект Програми формування та розвитку Державної спеціальної служби транспорту на 2005-2015 роки.

Прем'єр-міністр України В.ЯНУКОВИЧ
