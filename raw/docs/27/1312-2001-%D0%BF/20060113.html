Про затвердження Порядку міжвідомчої координації закупівлі товарів за кошти державного бюджету

Стан: Втратив чинність

Ідентифікатор: 1312-2001-п

Текст документа від 13.01.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 жовтня 2001 р. N 1312 Київ

Про затвердження Порядку міжвідомчої координації закупівель окремих товарів за кошти державного бюджету

( Із змінами, внесеними згідно з Постановами КМ N 1493 ( 1493-2002-п ) від 11.10.2002 N 819 ( 819-2003-п ) від 02.06.2003 N 845 ( 845-2004-п ) від 05.07.2004 N 19 ( 19-2006-п ) від 13.01.2006 )

( У назві і тексті постанови слова "груп товарів" замінено словами "товарів та послуг" згідно з Постановою КМ N 845 ( 845-2004-п ) від 05.07.2004 )

( У назві та тексті постанови слова "та послуг" виключено згідно з Постановою КМ N 19 ( 19-2006-п ) від 13.01.2006 )

Кабінет Міністрів України постановляє:

1. Затвердити Порядок міжвідомчої координації закупівлі окремих товарів за кошти державного бюджету (додається).

Установити, що закупівля товарів на засадах міжвідомчої координації здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ) з урахуванням особливостей, визначених Порядком, затвердженим цією постановою. ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 19 ( 19-2006-п ) від 13.01.2006 )

2. Рекомендувати Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям, іншим розпорядникам державних коштів застосовувати Порядок, затверджений цією постановою, при закупівлі за рахунок коштів місцевих бюджетів чи інших державних коштів.

( Пункт 2 в редакції Постанови КМ N 19 ( 19-2006-п ) від 13.01.2006 )

3. Ця постанова набирає чинності з 1 квітня 2002 року.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 10 жовтня 2001 р. N 1312

ПОРЯДОК міжвідомчої координації закупівель окремих товарів за кошти державного бюджету

( У назві і тексті Порядку слова "груп товарів" замінено словами "товарів та послуг" згідно з Постановою КМ N 845 ( 845-2004-п ) від 05.07.2004 )

( Порядок доповнено після слова "товар" в усіх відмінках і формах числа словами "та послуг" у відповідному відмінку і числі згідно з Постановою КМ N 845 ( 845-2004-п ) від 05.07.2004 )

( У назві та тексті Порядку і додатку до нього слова "та послуг" виключено згідно з Постановою КМ N 19 ( 19-2006-п ) від 13.01.2006 )

1. Цей Порядок визначає механізм координації роботи, пов'язаної із закупівлею окремих товарів міністерствами, іншими центральними органами виконавчої влади, установами та організаціями - головними розпорядниками коштів державного бюджету, крім Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських держадміністрацій і розпорядників коштів нижчого рівня.

2. Метою цього Порядку є підвищення ефективності державних закупівель, раціональне використання коштів, забезпечення оптимального рівня цін та зменшення витрат, пов'язаних з організацією і проведенням процедур закупівель.

Міжвідомча координація закупівель товарів між головними розпорядниками коштів державного бюджету та підпорядкованими їм розпорядниками коштів нижчого рівня і одержувачами коштів

( Назва розділу із змінами, внесеними згідно з Постановою КМ N 819 ( 819-2003-п ) від 02.06.2003 )

3. Головні розпорядники коштів державного бюджету (далі - головні розпорядники) у двомісячний термін після затвердження Державного бюджету України складають річний план закупівлі товарів з урахуванням закупівель, які здійснюватимуть підпорядковані їм розпорядники коштів нижчого рівня і одержувачі коштів, і подають його Міністерству економіки та з питань європейської інтеграції за встановленою ним формою.

Під час складання цього плану розмежовуються закупівлі товарів, що будуть здійснюватися головним розпорядником та розпорядниками коштів нижчого рівня і одержувачами коштів, з урахуванням вимог пункту 4 цього Порядку.

( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 819 ( 819-2003-п ) від 02.06.2003 )

4. Процедури закупівлі товарів на засадах координації з урахуванням потреб розпорядників коштів нижчого рівня (одержувачів коштів) може здійснювати головний розпорядник бюджетних коштів або уповноважений ним розпорядник коштів нижчого рівня (одержувач коштів).

Розпорядники коштів нижчого рівня і одержувачі коштів укладають договори про поставку товарів з виконавцем, визначеним головним розпорядником (або уповноваженим ним розпорядником коштів нижчого рівня (одержувачем коштів) переможцем за результатами здійсненої ним процедури закупівлі.

( Пункт 4 із змінами, внесеними згідно з Постановами КМ N 819 ( 819-2003-п ) від 02.06.2003, N 845 ( 845-2004-п ) від 05.07.2004; в редакції Постанови КМ N 19 ( 19-2006-п ) від 13.01.2006 )

5. У разі коли очікувана вартість товару нижча від суми, зазначеної у пункті 4 цього Порядку, процедуру його закупівлі здійснює розпорядник коштів нижчого рівня і одержувач коштів за умови, що інше не передбачено окремим рішенням головного розпорядника. ( Пункт 5 із змінами, внесеними згідно з Постановою КМ N 819 ( 819-2003-п ) від 02.06.2003 )

Міжвідомча координація закупівель товарів між головними розпорядниками коштів державного бюджету

6. Мінекономіки узагальнює та опрацьовує подані головними розпорядниками річні плани закупівель, зазначені в пункті 3 цього Порядку, затверджує та доводить до генерального замовника, визначеного Кабінетом Міністрів України за поданням Мінекономіки, план закупівлі товарів на засадах міжвідомчої координації, до якого включаються зазначені у додатку до цього Порядку товари, що заплановані до закупівлі двома чи більше головними розпорядниками, у разі, коли загальна очікувана вартість відповідного товару перевищує 700 тис. гривень. Генеральним замовником може бути визначений один з головних розпорядників, обсяг закупівлі товару якого є найбільшим, або державна установа (підприємство, організація).

( Пункт 6 із змінами, внесеними згідно з Постановою КМ N 845 ( 845-2004-п ) від 05.07.2004; в редакції Постанови КМ N 19 ( 19-2006-п ) від 13.01.2006 )

7. Генеральний замовник:

утворює тендерний комітет, затверджує його склад;

здійснює процедури закупівлі відповідних товарів згідно із законодавством та визначає переможця;

інформує всіх заінтересованих головних розпорядників про результати процедур закупівлі;

подає Мінекономіки і всім заінтересованим головним розпорядникам звіт про результати здійснення процедур закупівлі за формою та в порядку, визначеними Мінекономіки.

( Пункт 7 в редакції Постанови КМ N 19 ( 19-2006-п ) від 13.01.2006 )

8. Головні розпорядники укладають договори про закупівлю товарів з визначеними генеральним замовником переможцем за результатами процедури закупівлі, крім випадків, коли товар не відповідає вимогам головного розпорядника щодо його технічних характеристик, якості, умов поставки, ціни тощо. У цьому разі розпорядник має право відмовитися від укладення договору закупівлі, поінформувати про це генерального замовника і самостійно здійснити процедуру закупівлі такого товару.

( Пункт 8 із змінами, внесеними згідно з Постановою КМ N 845 ( 845-2004-п ) від 05.07.2004; в редакції Постанови КМ N 19 ( 19-2006-п ) від 13.01.2006 )

9. Рішення про внесення змін у додаток, зазначений у пункті 6 цього Порядку, приймається у разі потреби Кабінетом Міністрів України за поданням Міністерства економіки та з питань європейської інтеграції один раз на рік не пізніше 1 грудня року, що передує рокові, з якого це рішення набирає чинності.

10. Органи Державного казначейства здійснюють оплату договорів про закупівлю у разі надання розпорядником (одержувачем) коштів звіту, затвердженого генеральним замовником за встановленою Мінекономіки формою.

( Порядок доповнено пунктом 10 згідно з Постановою КМ N 19 ( 19-2006-п ) від 13.01.2006 )
