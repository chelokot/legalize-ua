Текст документа від 21.11.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 2009 р. N 1632-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 938-р ( 938-2012-р ) від 21.11.2012 }

Про затвердження проекту та титулу будови (об'єкта) "Будівництво 1-ої черги (гідротехнічні споруди) контейнерного термінала на Карантинному молу державного підприємства "Одеський морський торговельний порт" за рахунок штучно створеної території"

1. Затвердити поданий Міністерством транспорту та зв'язку проект "Будівництво 1-ої черги (гідротехнічні споруди) контейнерного термінала на Карантинному молу державного підприємства "Одеський морський торговельний порт" за рахунок штучно створеної території", розроблений ТОВ "ГТ Проект-Україна" та рекомендований до затвердження державним підприємством "Укрдержбудекспертиза" Міністерства регіонального розвитку та будівництва, з такими основними техніко-економічними показниками:

потужність (пропускна спроможність) - 6000 тис. тонн або 600 тис. TEU

кількість причалів - два

протяжність причалів, метрів - 650

берегоукріплення, метрів - 920

захисні споруди, метрів - 900

площа території, гектарів - 19,3

площа складських майданчиків з - 112,4 технологічними проїздами, тис. кв. метрів

місткість складів в один ярус, TEU - 3623

чисельність працівників, чоловік - 405

річні витрати електроенергії, МВт*г - 8600

річні витрати питної води, - 66795 куб. метрів

загальна кошторисна вартість, - 4443895,63 тис. гривень

у тому числі:

будівельно-монтажні роботи - 3092472,473

устатковання - 559273,463

інші витрати - 792149,694

тривалість будівництва - 36 місяців.

2. Затвердити титул будови (об'єкта) "Будівництво 1-ої черги (гідротехнічні споруди) контейнерного термінала на Карантинному молу державного підприємства "Одеський морський торговельний порт" за рахунок штучно створеної території", спорудження якої розпочинається у 2010 році, що додається.
