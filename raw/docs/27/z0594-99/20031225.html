Про введення в дію норм належності майна продовольчої служби установ кримінально-виконавчої системи

( Із змінами, внесеними згідно з Наказом Державного департаменту України з питань виконання покарань N 228 ( z1226-03 ) від 02.12.2003 )

На виконання Указу Президента України від 12 березня 1999 року N 248/99 "Про виведення Державного департаменту України з питань виконання покарань з підпорядкування Міністерству внутрішніх справ України" та з метою впорядкування забезпечення майном продовольчої служби установ кримінально-виконавчої системи НАКАЗУЮ:

1. Затвердити та ввести в дію такі документи (додаються):

1.1. Норму належності майна продовольчої служби слідчих ізоляторів, установ виконання покарань і лікувально-трудових профілакторіїв. ( Пункт 1.1 в редакції Наказу Держдепартаменту вик. покарань N 228 ( z1226-03 ) від 02.12.2003 )

1.2. Норму належності майна продовольчої служби навчальних закладів ( z0595-99 ).

1.3. Норму належності майна продовольчої служби дитячих закладів ( z0596-99 ).

1.4. Норму належності майна продовольчої служби для кухонь розплідників службових собак ( z0596-99 ).

1.5. Інструкцію про застосування норм належності майна продовольчої служби ( z0597-99 ).

2. Начальникам управлінь (відділів) Державного департаменту України з питань виконання покарань в Автономній Республіці Крим та областях, начальникам установ виконання покарань, слідчих ізоляторів, лікувально-трудових профілакторіїв, навчальних та дитячих закладів: ( Пункт 2 із змінами, внесеними згідно з Наказом Держдепартаменту вик. покарань N 228 ( z1226-03 ) від 02.12.2003 )

2.1. Організувати вивчення норм належності працівниками інтендантських і господарчих служб.

2.2. Забезпечити дотримання норм належності, організацію експлуатації та утримання майна.

2.3. При проектуванні і будівництві нових їдалень керуватись нормами належності технологічного і холодильного устаткування.

3. Накази МВС України від 13 червня 1995 року N 438 "Про введення в дію Норм забезпечення майном продовольчої служби", від 6 березня 1996 року N 144 "Про внесення змін до наказу МВС України від 13.06.95 N 438" та від 19 травня 1997 року N 316 "Про внесення змін до наказів МВС України від 13.06.95 N 438 та від 06.03.96 N 144" в органах та установах Державного департаменту України з питань виконання покарань не застосовуються.
