Стан: Втратив чинність

Ідентифікатор: z1272-08

МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

27.11.2008 N 560

Зареєстровано в Міністерстві юстиції України 30 грудня 2008 р. за N 1272/15963

Про внесення змін до наказу Міністерства праці та соціальної політики України від 27.02.2006 N 49

{ Із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 173 ( z0519-10 ) від 29.06.2010 }

Відповідно до постанови Кабінету Міністрів України від 25 жовтня 2008 року N 939 ( 939-2008-п ) "Питання оплати праці працівників установ, закладів та організацій бюджетної сфери" (із змінами) НАКАЗУЮ:

1. У додатку до наказу Міністерства праці та соціальної політики України від 27.02.2006 N 49 ( z0233-06 ) "Про умови оплати праці працівників Українського центру сприяння іноземному інвестуванню", зареєстрованого в Міністерстві юстиції України 06.03.2006 за N 233/12107 (із змінами), графу "з 01.12.2008" виключити.

2. Установити, що розміри посадових окладів, визначені додатком до наказу ( z0233-06 ), змінюються у 2010 році в установленому порядку пропорційно підвищенню посадового окладу (тарифної ставки) працівника I тарифного розряду, розмір якого визначено у примітці 1 додатка 1 до постанови Кабінету Міністрів України від 30 серпня 2002 р. N 1298 ( 1298-2002-п ) "Про оплату праці працівників на основі Єдиної тарифної сітки розрядів і коефіцієнтів з оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери. { Абзац пункту 2 в редакції Наказу Міністерства праці та соціальної політики N 173 ( z0519-10 ) від 29.06.2010 - застосовується з 1 січня 2010 року }

Для працівників, у яких посадові оклади менші ніж розмір мінімальної заробітної плати, посадові оклади (тарифні ставки) у штатному розписі установлюються на рівні мінімальної заробітної плати. { Абзац пункту 2 в редакції Наказу Міністерства праці та соціальної політики N 173 ( z0519-10 ) від 29.06.2010 - застосовується з 1 січня 2010 року }

Заробітна плата працівників, визначена з урахуванням зазначених посадових окладів, індексується відповідно до Закону України "Про індексацію грошових доходів населення" ( 1282-12 ).

3. Директору департаменту з питань державного регулювання заробітної плати та умов праці Товстенку О.П. у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.
