Про передачу повноважень з управління державними корпоративними правами Раді міністрів Автономної Республіки Крим, міністерствам, іншим центральним і місцевим органам виконавчої влади

( Із змінами, внесеними згідно з Розпорядженням КМ N 546-р ( 546-99-р ) від 09.06.99 Постановою КМ N 1280 ( 1280-99-п ) від 16.07.99 Розпорядженням КМ N 801-р ( 801-99-р ) від 13.08.99 )

( Із змінами, внесеними згідно з Постановами КМ N 1990 ( 1990-99-п ) від 22.10.99 N 2070 ( 2070-99-п ) від 11.11.99 Розпорядженнями КМ N 1248-р ( 1248-99-р ) від 16.11.99 N 1256-р ( 1256-99-р ) від 20.11.99 N 1262-р ( 1262-99-р ) від 22.11.99 N 1296-р ( 1296-99-р ) від 26.11.99 N 1311-р ( 1311-99-р ) від 29.11.99 N 1333-р ( 1333-99-р ) від 03.12.99 N 1406-р ( 1406-99-р ) від 13.12.99 N 178-р ( 178-2000-р ) від 12.04.2000 )

З метою подальшого впровадження системи управління державними корпоративними правами Кабінет Міністрів України постановляє:

Передати безпосередньо Раді міністрів Автономної Республіки Крим, міністерствам, іншим центральним і місцевим органам виконавчої влади повноваження з управління державними корпоративними правами господарських товариств згідно з переліками, що додаються.

Національному агентству з управління державними корпоративними правами:

розробити і затвердити умови такої передачі та завдання з управління державними корпоративними правами зазначених господарських товариств відповідно до графіків, узгоджених з Радою міністрів Автономної Республіки Крим, міністерствами, іншими центральними і місцевими органами виконавчої влади;

провести в установленому порядку конкурси з визначення уповноважених осіб на управління державними корпоративними правами господарських товариств, не включених до зазначених переліків.
