Кабінет Міністрів України; Розпорядження від 16.05.1996 № 356-р

Про заходи щодо виконання Указу Президента України від 19 жовтня 1995 р. N 980 "Про створення умов для роботи Української Академії державного управління"

Стан: Чинний

Ідентифікатор: 356-96-р

Текст документа від 25.11.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 травня 1996 р. N 356-р Київ

{ Із змінами, внесеними згідно з Розпорядженням КМ N 746-р ( 746-96-р ) від 25.11.96 }

Відповідно до Указу Президента України від 19 жовтня 1995 р. N 980 ( 980/95 ) "Про створення умов для роботи Української Академії державного управління":

1. Передати в оперативне управління Українській Академії державного управління при Президентові України новозбудований гуртожиток готельного типу по вул. Мельникова, 36, у м. Києві.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 746-р ( 746-96-р ) від 25.11.96 }

2. Київському університету імені Тараса Шевченка та Українській Академії державного управління при Президентові України здійснювати утримання будинку по вул. Мельникова, 36/1, у м. Києві і прибудинкової території на умовах, передбачених розпорядженням Кабінету Міністрів України від 5 червня 1993 р. N 374 ( 374-93-р ).

3. Київській міській державній адміністрації вирішити до 1 січня 1997 р. питання вивільнення приміщень у будинку по вул. Пугачова, 12, у м. Києві, в яких тимчасово розміщується середня школа N 70.

4. Фонду державного майна, Національній академії наук разом з Київською міською державною адміністрацією внести до 1 січня 1997 р. Кабінетові Міністрів України узгоджені пропозиції щодо вивільнення займаних Інститутом української археографії та джерелознавства імені М.С. Грушевського приміщень у будинку по вул. Пугачова, 12, у м. Києві з наданням зазначеному Інститутові інших приміщень, необхідних для забезпечення належних умов роботи.
