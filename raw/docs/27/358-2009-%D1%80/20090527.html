Кабінет Міністрів України; Розпорядження від 02.04.2009 № 358-р

Питання виплати заробітної плати шахтарям

Стан: Чинний

Ідентифікатор: 358-2009-р

Текст документа від 27.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 квітня 2009 р. N 358-р Київ

Питання виплати заробітної плати шахтарям

{ Із змінами, внесеними згідно з Розпорядженням КМ N 678-р ( 678-2009-р ) від 27.05.2009 }

1. Спрямовувати кошти Стабілізаційного фонду відповідно до пункту 3 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) на реалізацію проектів, пов'язаних з підтримкою діючих потужностей вугледобувних підприємств (на часткове покриття витрат із собівартості продукції), в обсязі не менш як 350 000 тис. гривень щомісяця починаючи з березня 2009 року.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 678-р ( 678-2009-р ) від 27.05.2009 }

1-1. Здійснити додатковий перерозподіл коштів Стабілізаційного фонду в сумі 2450 млн. гривень шляхом збільшення обсягу видатків, передбачених пунктом 22 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), за рахунок зменшення обсягу видатків за напрямами, передбаченими пунктом 3 частини першої статті 76 зазначеного Закону.

Мінвуглепрому погодити перерозподіл коштів, визначений абзацом першим цього пункту, з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету.

{ Розпорядження доповнено пунктом 1-1 згідно з Розпорядженням КМ N 678-р ( 678-2009-р ) від 27.05.2009 }

2. Мінвуглепрому зазначені в пункті 1 і 1-1 цього розпорядження кошти виділяти для виконання бюджетної програми КПКВК 1301090 "Державна підтримка вугледобувних підприємств (включаючи підприємства з видобутку бурого вугілля) на часткове покриття витрат із собівартості продукції. { Абзац перший пункту 2 в редакції Розпорядження КМ N 678-р ( 678-2009-р ) від 27.05.2009 }

Мінвуглепрому спрямовувати зазначені кошти лише на виплату заробітної плати (з нарахуваннями) шахтарям відповідно до Порядку використання у 2009 році коштів, передбачених у державному бюджеті для надання державної підтримки вугледобувним підприємствам (включаючи підприємства з видобутку бурого вугілля) на часткове покриття витрат із собівартості продукції, затвердженого постановою Кабінету Міністрів України від 28 січня 2009 р. N 69 ( 69-2009-п ) (Офіційний вісник України, 2009 р., N 11, ст. 314).

3. Мінфіну на підставі пропозицій Мінвуглепрому та з урахуванням пунктів 1, 1-1 і 2 цього розпорядження внести в установленому порядку зміни до розпису державного бюджету.

{ Пункт 3 із змінами, внесеними згідно з Розпорядженням КМ N 678-р ( 678-2009-р ) від 27.05.2009 }
