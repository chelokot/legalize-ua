Про затвердження Порядку казначейського обслуговування позабюджетних коштів установ і організацій, що утримуються за рахунок коштів державного бюджету

Реєстрація: Мін'юст України від 01.04.1999 № 202/3495

Стан: Втратив чинність

Ідентифікатор: z0202-99

Текст документа від 05.02.2001:

МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ ГОЛОВНЕ УПРАВЛІННЯ ДЕРЖАВНОГО КАЗНАЧЕЙСТВА УКРАЇНИ

НАКАЗ

N 27 від 25.03.99 Зареєстровано в Міністерстві м.Київ юстиції України 1 квітня 1999 р. vd990325 vn27 за N 202/3495

Про затвердження Порядку казначейського обслуговування

позабюджетних коштів установ і організацій, що утримуються за рахунок коштів державного бюджету

( Із змінами, внесеними згідно з Наказами Держказначейства N 87 ( z0736-99 ) від 14.10.99 N 127 ( z0961-00 ) від 13.12.2000 N 3 ( z0104-01 ) від 22.01.2001 )

З метою запровадження ефективного контролю за витрачанням позабюджетних коштів установ і організацій, що утримуються за рахунок коштів державного бюджету, та на виконання Указу Президента України від 15 лютого 1999 N 173/99 "Про внесення змін до Указу Президента України від 27 квітня 1995 року N 335" і постанови Кабінету Міністрів України від 17 лютого 1999 N 180 ( 180-99-п ) "Про деякі питання діяльності Державного казначейства України" НАКАЗУЮ:

1. Затвердити Порядок казначейського обслуговування позабюджетних коштів установ і організацій, що утримуються за рахунок коштів державного бюджету (додається).

2. Казначейське обслуговування позабюджетних коштів установ і організацій, що утримуються за рахунок коштів державного бюджету, проводити згідно з затвердженим Порядком.

Заступник Міністра фінансів - начальник Головного управління Державного казначейства України П.Г.Петрашко

( Порядок казначейського обслуговування позабюджетних коштів установ і організацій, що утримуються за рахунок коштів державного бюджету втратив чинність на підставі Наказу Держказначейства N 3 ( z0104-01 ) від 22.01.2001 )
