ПОСТАНОВА від 27 травня 2002 р. N 696 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1256 ( 1256-2005-п ) від 21.12.2005 )

Про внесення змін до постанови Кабінету Міністрів України від 16 червня 2000 р. N 978

Кабінет Міністрів України постановляє:

Внести до переліку суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості, затвердженого постановою Кабінету Міністрів України від 16 червня 2000 р. N 978 ( 978-2000-п ) (Офіційний вісник України, 2000 р., N 25, ст. 1047; 2001 р., N 34, ст. 1593), такі зміни:

1. Позиції:

"14308339 ВО "Зоря", м. Миколаїв",

"23664154 ТОВ "Севморверф"

замінити відповідно позиціями:

"31821381 Державне підприємство "Науково-виробничий комплекс газотурбобудування "Зоря" - "Машпроект", м. Миколаїв",

"23664754 ТОВ "Севморверф".

2. Позиції:

"30283535 ТОВ "Океанремтранш", м. Миколаїв",

"14307498 Наково-виробниче підприємство "Машпроект", м. Миколаїв"

виключити.
