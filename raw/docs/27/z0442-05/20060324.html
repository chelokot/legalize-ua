{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Державного казначейства

N 3 ( z0059-05 ) від 10.01.2005, до якого вносились зміни }

Відповідно до пункту 1 постанови Кабінету Міністрів України від 01.03.2001 N 200 ( 200-2001-п ) "Деякі питання касового виконання Державного бюджету України" та результатів торгів (тендерів) з визначення банків, які залучатимуться до касового обслуговування з метою оплати готівкою чеків органів Державного казначейства України, НАКАЗУЮ:

1. Унести зміни до Переліку банків України та умов, на яких ці банки залучаються до касового обслуговування з метою оплати готівкою чеків органів Державного казначейства України, затвердженого наказом Державного казначейства України від 10.01.2005 N 3 ( z0059-05 ), зареєстрованим у Міністерстві юстиції України 19.01.2005 за N 59/10339, виклавши їх у редакції, що додається.

2.Управлінню фінансових ресурсів Державного казначейства України (Репік В.М.) подати цей наказ на державну реєстрацію до Міністерства юстиції України.
