( Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 326 ( z1239-05 ) від 14.10.2005 )

Про внесення змін до наказу Міністерства праці та соціальної політики України від 30.11.2001 N 511

На виконання постанови Кабінету Міністрів України від 15.01.2005 N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 30.11.2001 N 511 ( z1012-01 ) "Про умови оплати праці працівників Всеукраїнського центру професійної реабілітації інвалідів", зареєстрованого в Міністерстві юстиції України 07.12.2001 за N 1012/6203 (із змінами), виклавши додатки 1-6 у новій редакції (додаються).

2. Ці зміни застосовуються з 1 січня 2005 року.

В. о. Міністра М.Папієв
