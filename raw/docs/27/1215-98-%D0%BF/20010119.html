Кабінет Міністрів України; Постанова від 03.08.1998 № 1215

Про внесення змін до ставок ввізного мита на окремі види сільськогосподарської техніки та обладнання до неї

Стан: Втратив чинність

Ідентифікатор: 1215-98-п

Текст документа від 19.01.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 серпня 1998 р. N 1215 Київ

( Постанова втратила чинність на підставі Постанови КМ N 16 ( 16-2001-п ) від 12.01.2001 )

Про внесення змін до ставок ввізного мита на окремі види сільськогосподарської техніки та обладнання до неї

( Із змінами, внесеними згідно з Постановою КМ N 5 ( 5-99-п ) від 04.01.99 )

Кабінет Міністрів України постановляє:

1. Установити терміном до 31 грудня 1998 року:

1) на часткову зміну додатка до постанови Кабінету Міністрів України від 22 лютого 1995 р. N 139 ( 139-95-п ) "Про внесення змін до ставок ввізного мита на товари, яких достатньо виробляється у країні" (ЗП України, 1995 р., N 5, ст. 128) ставки ввізного мита (у відсотках до митної вартості товару) на товар за кодом згідно з ГС 84.32 10100 (тільки плуги обертові): пільгову - 0,2, повну - 30; на товар за кодом згідно з ГС 87.01 90390 (тільки трактори для сільськогосподарських робіт та колісні трактори для лісового господарства: нові з потужністю двигуна понад 130 кВт): пільгову - 0,2, повну - 40; ( Підпункт 1 пункту 1 в редакції Постанови КМ N 5 ( 5-99-п ) від 04.01.99 )

2) на часткову зміну додатка до постанови Кабінету Міністрів України від 18 липня 1995 р. N 531 ( 531-95-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів та до деяких рішень Уряду України" (ЗП України, 1995 р., N 10, ст. 246) ставки ввізного мита (у відсотках до митної вартості товару) на товар за кодом згідно з ГС 84.32 29900 (тільки універсальні обертові агрегати для обробітку грунту): пільгову - 0,2, повну - 10;

3) на часткову зміну додатка до постанови Кабінету Міністрів України від 3 квітня 1997 р. N 306 ( 306-97-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів" (Офіційний вісник України, 1997 р., число 14, с. 64) ставки ввізного мита (у відсотках до митної вартості товару) на товар за кодом згідно з ГС 84.33 51000 (комбайни зернозбиральні): пільгову - 0,2, повну - 10.

2. Ця постанова набирає чинності через 10 днів з дня опублікування в газеті "Урядовий кур'єр".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
