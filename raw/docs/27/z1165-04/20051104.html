МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

13.09.2004 N 217

Зареєстровано в Міністерстві юстиції України 16 вересня 2004 р. за N 1165/9764

Про внесення змін до наказу Міністерства праці та соціальної політики України від 29.01.2002 N 69

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства праці та соціальної політики

N 69 ( z0129-02 ) від 29.01.2002, до якого вносились зміни }

На виконання постанови Кабінету Міністрів України від 25 серпня 2004 року N 1097 ( 1097-2004-п ) "Про підвищення з 1 вересня 2004 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 29.01.2002 N 69 ( z0129-02 ) "Про впорядкування умов оплати праці працівників окремих підрозділів, створених при органах виконавчої влади, їх самостійних управліннях і відділах та при виконавчих органах рад", зареєстрованого в Міністерстві юстиції України 12.02.2002 за N 129/6417 (зі змінами), виклавши додаток у новій редакції (додається).

2. Ці зміни застосовуються з 1 вересня 2004 року.

Міністр М.Папієв

ПОГОДЖЕНО:

Міністерство фінансів України Заступник Міністра О.С.Яременко
