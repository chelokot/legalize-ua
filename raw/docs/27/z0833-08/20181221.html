МІНІСТЕРСТВО ВНУТРІШНІХ СПРАВ УКРАЇНИ

НАКАЗ

07.08.2008 N 391

Зареєстровано в Міністерстві юстиції України 10 вересня 2008 р. за N 833/15524

{ Наказ втратив чинність на підставі Наказу Міністерства внутрішніх справ N 885 ( z1314-18 ) від 06.11.2018 }

Про внесення змін до Переліку посад працівників експертної служби МВС України, які залучаються Антитерористичним центром та його координаційними групами при регіональних органах Служби безпеки України до проведення заходів щодо запобігання терористичним проявам та їх припинення, затвердженого наказом МВС від 30.11.2006 N 1183

На виконання частини другої статті 5 Закону України "Про боротьбу з тероризмом" ( 638-15 ), Указу Президента України від 14 квітня 1999 року N 379 ( 379/99 ) "Про Положення про Антитерористичний центр та його координаційні групи при регіональних органах Служби безпеки України", у зв'язку зі змінами в штатній структурі науково-дослідного експертно-криміналістичного центру при головних управліннях, управліннях МВС України в Автономній Республіці Крим, областях, містах Києві та Севастополі, на залізничному транспорті, НАКАЗУЮ:

1. Унести до Переліку посад працівників експертної служби МВС України, які залучаються Антитерористичним центром та його координаційними групами при регіональних органах Служби безпеки України до проведення заходів щодо запобігання терористичним проявам та їх припинення, затвердженого наказом МВС від 30.11.2006 N 1183 ( z1293-06 ), зареєстрованого в Міністерстві юстиції України 08.12.2006 за N 1293/13167, такі зміни:

після слів "технік-сапер" доповнити словом "експерт";

після слів "експерт-вибухотехнік" доповнити словами "старший експерт";

після слів "старший експерт-вибухотехнік" доповнити словами "головний експерт";

після слів "головний спеціаліст" доповнити словами "головний експерт-вибухотехнік".

2. ДНДЕКЦ (Красюк І.П.) МВС у п'ятиденний строк після підписання наказу забезпечити його подання на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням наказу покласти на заступника Міністра Коляду П.В.

4. Наказ надіслати за належністю.

Міністр Ю.В.Луценко
