Про організаційне забезпечення діяльності єдиної системи військової освіти

Стан: Чинний

Ідентифікатор: 1588-98-п

Текст документа від 07.02.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 жовтня 1998 р. N 1588 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про організаційне забезпечення діяльності єдиної системи військової освіти

{ Із змінами, внесеними згідно з Постановами КМ N 576 ( 576-99-п ) від 13.04.99 N 1231 ( 1231-2000-п ) від 07.08.2000 N 105 ( 105-2001-п ) від 07.02.2001 }

З метою організаційного забезпечення діяльності єдиної системи військової освіти Кабінет Міністрів України постановляє:

1. Підтримати пропозицію Міністерства освіти, Міністерства оборони, Міністерства внутрішні справ, Державного комітету у справах охорони державного кордону та інших військових формувань про утворення у структурі центрального апарату Міністерства освіти відділу підготовки військових фахівців у вищих навчальних закладах єдиної системи військової освіти з чисельністю працівників 7 осіб.

{ Абзац другий пункту 1 втратив чинність на підставі Постанови КМ N 1231 ( 1231-2000-п ) від 07.08.2000 }

{ Пункт 2 втратив чинність на підставі Постанови КМ N 105 ( 105-2001-п ) від 07.02.2001 }

3. Установити, що:

посадові оклади офіцерського складу, осіб начальницького складу органів внутрішніх справ відділу підготовки військових фахівців Міністерства освіти визначаються відповідно до Указів Президента України від 4 жовтня 1996 р. N 923 ( 923/96 ), від 4 жовтня 1996 р. N 925 ( 925/96 ) та від 4 жовтня 1996 р. N 926 ( 926/96 ) з наступними змінами і доповненнями до них, виходячи з того, що за розміром посадового окладу посада начальника відділу - заступника начальника Головного управління прирівнюється до посади начальника самостійного управління, посада заступника начальника відділу - до посади начальника відділу у складі управління, посада головного спеціаліста - до посади старшого офіцера;

виплата окладів за військовими та спеціальними званнями, надбавок за вислугу років, матеріальної допомоги, преміювання та інших видів грошового забезпечення офіцерського складу, осіб начальницького складу органів внутрішніх справ відділу підготовки військових фахівців Міністерства освіти здійснюється у розмірах, визначених відповідно для військовослужбовців Збройних Сил, Служби безпеки, інших військових формувань, осіб начальницького складу органів внутрішніх справ.

{ Постанову доповнено пунктом 3 згідно з Постановою КМ N 576 ( 576-99-п ) від 13.04.99 }

4. Міністерству освіти вжити у місячний термін необхідних заходів до забезпечення діяльності відділу підготовки військових фахівців у вищих навчальних закладах єдиної системи військової освіти.

Міністерству оборони, Міністерству внутрішніх справ і Державному комітетові у справах охорони державного кордону забезпечити відрядження в установленому порядку осіб офіцерського складу для комплектування відділу підготовки військових фахівців у вищих навчальних закладах єдиної системи військової освіти Міністерства освіти.

5. Контроль за виконанням цієї постанови покласти на Першого віце-прем'єр-міністра України Голубченка А.К.
