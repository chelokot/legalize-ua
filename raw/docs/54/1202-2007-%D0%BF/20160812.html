КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 жовтня 2007 р. N 1202 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 477 ( 477-2016-п ) від 27.07.2016 }

Про затвердження переліку посад, що підлягають заміщенню особами вищого начальницького складу, і граничних спеціальних звань за цими посадами у Державній службі спеціального зв'язку та захисту інформації

{ Із змінами, внесеними згідно з Постановою КМ N 788 ( 788-2011-п ) від 25.07.2011 }

Кабінет Міністрів України постановляє:

Затвердити перелік посад, що підлягають заміщенню особами вищого начальницького складу, і граничних спеціальних звань за цими посадами у Державній службі спеціального зв'язку та захисту інформації, що додається.
