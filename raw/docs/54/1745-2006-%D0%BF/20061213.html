Текст документа від 13.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 грудня 2006 р. N 1745 Київ

Про ліквідацію Ради підприємців України при Кабінеті Міністрів України

Кабінет Міністрів України постановляє:

Ліквідувати Раду підприємців України при Кабінеті Міністрів України.

У зв'язку з цим визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 25

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 13 грудня 2006 р. N 1745

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 22 березня 1993 р. N 210 ( 210-93-п ) "Про створення Ради підприємців України при Кабінеті Міністрів України" (ЗП України, 1993 р., N 9, ст. 173).

2. Постанова Кабінету Міністрів України від 11 вересня 1997 р. N 1018 ( 1018-97-п ) "Про створення Ради підприємців України при Кабінеті Міністрів України".

3. Постанова Кабінету Міністрів України від 16 лютого 2000 р. N 315 ( 315-2000-п ) "Питання Ради підприємців України при Кабінеті Міністрів України" (Офіційний вісник України, 2000 р., N 7, ст. 276).

4. Постанова Кабінету Міністрів України від 7 грудня 2005 р. N 1180 ( 1180-2005-п ) "Про затвердження складу Ради підприємців України при Кабінеті Міністрів України" (Офіційний вісник України, 2005 р., N 50, ст. 3118).
