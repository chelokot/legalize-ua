Про зупинення дії постанови Кабінету Міністрів України від 16 січня 2007 року N 31

Стан: Втратив чинність

Ідентифікатор: 552/2007

Текст документа від 25.06.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанови Кабінету Міністрів України від 16 січня 2007 року N 31

{ Додатково див. Конституційне подання Президента ( n0011100-07 ) від 25.06.2007 }

Кабінетом Міністрів України 16 січня 2007 року видано постанову N 31 ( 31-2007-п ) "Про внесення змін до постанови Кабінету Міністрів України від 27 грудня 2001 р. N 1729", якою внесено, зокрема, зміни до Порядку забезпечення споживачів природним газом, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 року N 1729 ( 1729-2001-п ) "Про забезпечення споживачів природним газом".

Цими змінами, зокрема, постачальників природного газу - Національну акціонерну компанію "Нафтогаз України", товариства (підприємства), утворені за участю Національної акціонерної компанії "Нафтогаз України", які закуповують природний газ за зовнішньоекономічними контрактами та договорами купівлі-продажу, зобов'язано укладати з газотранспортними підприємствами Національної акціонерної компанії "Нафтогаз України" та/або із суб'єктами господарювання, що мають ліцензію на розподіл природного і нафтового газу, договори на транспортування природного газу до споживачів без посередників (підпункт 2, абзац третій підпункту 3 пункту 2 змін) ( 31-2007-п ).

Зазначене є нічим іншим, як намаганням усунути з ринку газу відповідних суб'єктів господарювання.

Таким чином, нормативно-правовим актом Кабінету Міністрів України ( 31-2007-п ) обмежено гарантоване статтею 42 Конституції України ( 254к/96-ВР ) право названих суб'єктів на підприємницьку діяльність, яка не заборонена законом.

Діючи у такий спосіб, Кабінет Міністрів України також порушив конституційні норми щодо забезпечення захисту державою прав усіх суб'єктів господарювання, конкуренції у підприємницькій діяльності та недопущення неправомірного обмеження конкуренції (частина четверта статті 13, частина третя статті 42 Основного Закону України) ( 254к/96-ВР ).

Відтак, постановою Кабінету Міністрів України від 16 січня 2007 року N 31 ( 31-2007-п ) порушуються й положення частини другої статті 8, за якою нормативно-правові акти приймаються на основі Конституції України ( 254к/96-ВР ) і повинні відповідати їй, а також частини другої статті 6, частини другої статті 19 та частини третьої статті 113 Конституції України ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, діяти на підставі та у спосіб, що ними передбачені.

Враховуючи викладене, відповідно до пункту 15 статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 16 січня 2007 року N 31 ( 31-2007-п ) "Про внесення змін до постанови Кабінету Міністрів України від 27 грудня 2001 р. N 1729" в частині внесення до затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 року N 1729 ( 1729-2001-п ) Порядку забезпечення споживачів природним газом змін, передбачених підпунктом 2 та абзацом третім підпункту 3 пункту 2 змін, що вносяться до постанови Кабінету Міністрів України від 27 грудня 2001 року N 1729 ( 1729-2001-п ).

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 25 червня 2007 року N 552/2007
