ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 19 серпня 2009 р. N 886

ПОРЯДОК використання у 2010 році коштів Стабілізаційного фонду для будівництва, реконструкції та ремонту автомобільних доріг комунальної власності у містах проведення фінальної частини чемпіонату Європи 2012 року з футболу

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }

{ У тексті Порядку слово "Мінекономіки" замінено словами і цифрами "Національне агентство з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" у відповідному відмінку, а слова "коштів Стабілізаційного фонду" - словами "бюджетних коштів" згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }

{ У тексті Порядку слова і цифри "Національне агентство з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" в усіх відмінках замінено словом "Укрєвроінфрапроект" у відповідному відмінку згідно з Постановою КМ N 1105 ( 1105-2010-п ) від 06.12.2010 }

1. Цей Порядок визначає механізм використання у 2010 році коштів Стабілізаційного фонду, передбачених пунктом 4 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ), які спрямовуються (на безповоротній основі на умовах співфінансування з місцевими бюджетами) на будівництво, реконструкцію та ремонт автомобільних доріг комунальної власності у містах проведення фінальної частини чемпіонату Європи 2012 року з футболу (далі - бюджетні кошти).

{ Пункт 1 в редакції Постанови КМ N 419 ( 419-2010-п ) від 02.06.2010 }

2. Бюджетні кошти використовуються за умови спрямування коштів місцевих бюджетів на будівництво, реконструкцію та ремонт автомобільних доріг комунальної власності у містах проведення фінальної частини чемпіонату Європи 2012 року з футболу (далі - чемпіонат), що передбачені на зазначені цілі згідно з пунктом 7 додатка 2 до Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженої постановою Кабінету Міністрів України від 14 квітня 2010 р. N 357 ( 357-2010-п ) (Офіційний вісник України, 2010 р., N 39, ст. 1297) (далі - Програма).

{ Пункт 2 в редакції Постанови КМ N 419 ( 419-2010-п ) від 02.06.2010 }

3. Головним розпорядником бюджетних коштів є Укрєвроінфрапроект.

4. Виділення бюджетних коштів здійснюється з урахуванням Порядку використання у 2010 році коштів Стабілізаційного фонду для виконання Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженого постановою Кабінету Міністрів України від 2 червня 2010 р. N 419 ( 419-2010-п ).

{ Пункт 4 в редакції Постанови КМ N 419 ( 419-2010-п ) від 02.06.2010 }

5. Бюджетні кошти використовуються відповідно до переліку об'єктів будівництва, реконструкції та ремонту автомобільних доріг комунальної власності в розрізі міст проведення чемпіонату із зазначенням їх розпорядників нижчого рівня та одержувачів і обсягу фінансування, визначеного Укрєвроінфрапроектом за погодженням з Віце-прем'єр-міністром України. { Абзац перший пункту 5 в редакції Постанови КМ N 419 ( 419-2010-п ) від 02.06.2010 }

Перелік об'єктів формується Укрєвроінфрапроектом на підставі пропозицій, поданих місцевими органами виконавчої влади, органами місцевого самоврядування міст проведення чемпіонату, та погоджується Мінфіном і Укравтодором. { Абзац другий пункту 5 із змінами, внесеними згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }

У зазначених пропозиціях перелічуються роботи, товари, послуги і обсяги коштів для їх оплати в розрізі об'єктів будівництва, реконструкції та ремонту автомобільних доріг комунальної власності у містах проведення чемпіонату виходячи з розрахунку витрат, установлених норм, нормативів, діючих цін, тарифів, штатної чисельності та умов оплати праці працівників, переліку необхідного обладнання, а також строків здійснення закупівель та умов договорів, укладених між розпорядниками бюджетних коштів нижчого рівня, їх одержувачами і підрядниками. { Абзац третій пункту 5 із змінами, внесеними згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }

До переліку об'єктів включаються ті, що забезпечують транспортне сполучення у містах проведення чемпіонату, зокрема між спортивними спорудами, аеропортами, вокзалами, за наявності проектно-кошторисної документації, затвердженої відповідно до Порядку затвердження інвестиційних програм і проектів будівництва та проведення їх державної експертизи, що затверджений постановою Кабінету Міністрів України від 31 жовтня 2007 р. N 1269 ( 1269-2007-п ) (Офіційний вісник України, 2007 р., N 84, ст. 3106), та підтвердження фінансування об'єктів, передбаченого відповідним місцевим бюджетом на 2010 рік у визначених Програмою обсягах. { Абзац четвертий пункту 5 із змінами, внесеними згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }

6. Фінансування будівництва, реконструкції та ремонту автомобільних доріг комунальної власності у містах проведення чемпіонату здійснюється відповідно до Порядку державного фінансування капітального будівництва, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) (Офіційний вісник України, 2001 р., N 52, ст. 2374), на підставі:

проектно-кошторисної документації, затвердженої в установленому порядку;

титулу будови (об'єкта), розробленого та затвердженого відповідно до Порядку затвердження титулів будов (об'єктів), будівництво яких здійснюється із залученням бюджетних коштів або коштів підприємств державної власності, затвердженого постановою Кабінету Міністрів України від 8 вересня 1997 р. N 995 ( 995-97-п ) (Офіційний вісник України, 1997 р., число 37, с. 17).

7. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

Розпорядники бюджетних коштів нижчого рівня та їх одержувачі погоджують з Укрєвроінфрапроектом генерального підрядника та субпідрядників, граничні ціни на будівельні матеріали, устаткування та обладнання. { Пункту 7 доповнено абзацом згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }

8. Перерахування бюджетних коштів здійснюється в межах установлених обсягів видатків відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), що затверджений Державним казначейством.

9. Розпорядники бюджетних коштів нижчого рівня та їх одержувачі подають щомісяця до 5 числа Укрєвроінфрапроекту звіти за визначеною ним формою про виконання робіт, зокрема введені в експлуатацію автомобільні дороги, та використання бюджетних коштів в розрізі об'єктів. { Абзац перший пункту 9 із змінами, внесеними згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }

Укрєвроінфрапроект узагальнює зазначені звіти у розрізі об'єктів та інформує щокварталу до 25 числа наступного місяця Мінфін і Кабінет Міністрів України.

10. Державне казначейство інформує щомісяця до 16 числа Укрєвроінфрапроект і Мінфін про обсяги перерахування бюджетних коштів в розрізі регіонів та об'єктів.

11. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.

12. Після закінчення бюджетного періоду залишки бюджетних коштів, що обліковуються на рахунку головного розпорядника станом на 1 січня 2011 р., повертаються до державного бюджету.

{ Порядок доповнено пунктом 12 згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }

13. Відповідальність за нецільове використання бюджетних коштів покладається на Укрєвроінфрапроект, їх розпорядників нижчого рівня та одержувачів.

{ Порядок доповнено пунктом 13 згідно з Постановою КМ N 419 ( 419-2010-п ) від 02.06.2010 }
