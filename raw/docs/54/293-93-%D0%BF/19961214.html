КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 квітня 1993 р. N 293 Київ

( Постанову скасовано на підставі Указу Президента N 1228/96 ( 1228/96 ) від 14.12.96 )

Про склад Президії Кабінету Міністрів України

( Із змінами, внесеними згідно з Постановами КМ N 494 ( 494-93-п ) від 01.07.93 N 752 ( 752-96-п ) від 17.07.96 N 1242 ( 1242-96-п ) від 07.10.96 )

Кабінет Міністрів України постановляє:

1. Установити, що до складу Президії Кабінету Міністрів України входять:

Прем'єр-міністр України (голова), Перший віце-прем'єр-міністр України, віце-прем'єр-міністри України, Міністр Кабінету Міністрів України, Міністр економіки України і Міністр фінансів України, Голова Правління Національного банку і Голова Фонду державного майна до складу Президії Кабінету Міністрів України, Міністр вугільної промисловості і Міністр енергетики та електрифікації.

( Пункт 1 із змінами, внесеними згідно з Постановами КМ N 494 ( 494-93-п ) від 01.07.93, N 752 ( 752-96-п ) від 17.07.96, N 1242 ( 1242-96-п ) від 07.10.96 )

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 23 листопада 1992 р. N 635 ( 635-92-п ).
