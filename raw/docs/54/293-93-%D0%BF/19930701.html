Текст документа від 01.07.1993:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 квітня 1993 р. N 293 Київ

Про склад Президії Кабінету Міністрів України

( Із змінами, внесеними згідно з Постановою КМ N 494 ( 494-93-п ) від 01.07.93 )

Кабінет Міністрів України постановляє:

1. Установити, що до складу Президії Кабінету Міністрів України входять:

Прем'єр-міністр України (голова), Перший віце-прем'єр-міністр України, віце-прем'єр-міністри України, Міністр Кабінету Міністрів України, Міністр економіки України і Міністр фінансів України, Голова Правління Національного банку і Голова Фонду державного майна до складу Президії Кабінету Міністрів України.

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 494 ( 494-93-п ) від 01.07.93 )

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 23 листопада 1992 р. N 635.
