МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ

НАКАЗ

N 88 від 25.04.2000 Зареєстровано в Міністерстві м.Київ юстиції України 18 травня 2000 р. за N 287/4508

( Наказ втратив чинність на підставі Наказу Міністерства фінансів N 716 ( z1593-04 ) від 16.11.2004 )

Про внесення змін до Порядку зарахування до Державного бюджету дивідендів, одержаних від акцій, що належать

державі в акціонерних товариствах, створених у процесі приватизації та корпоратизації підприємств загальнодержавної власності, затвердженого наказом Міністерства фінансів України від 21.08.96 N 172

З метою приведення у відповідність до Закону України "Про господарські товариства" від 19 вересня 1991 року N 1576 ( 1576-12 ) із змінами, внесеними згідно з Законом України "Про внесення змін до Закону України "Про господарські товариства" від 23 грудня 1997 року N 769 ( 769/97-ВР ) Порядку зарахування до Державного бюджету України дивідендів, одержаних від акцій, що належать державі в акціонерних товариствах, створених у процесі приватизації та корпоратизації підприємств загальнодержавної власності, затвердженого наказом Міністерства фінансів України від 21 серпня 1996 N 172 ( z0485-96 ) і зареєстрованого в Міністерстві юстиції України 28 серпня 1996 року за N 485/1510, НАКАЗУЮ:

Частину восьму Порядку ( z0485-96 ) викласти в такій редакції:

"На підставі прийнятого за підсумками календарного року рішення про розподіл прибутку, строк та порядок виплати частки прибутку (дивідендів) акціонерні товариства визначають суму дивідендів, що підлягає внесенню до бюджету в 5-денний термін, починаючи з першого дня виплати дивідендів, за формою згідно з додатком".
