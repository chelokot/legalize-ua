Верховна Рада України; Закон від 12.05.2011 № 3323-VI

Про внесення змін до деяких законодавчих актів України щодо клінічних випробувань лікарських засобів

Стан: Чинний

Ідентифікатор: 3323-17

Текст документа від 01.01.2027:

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законодавчих актів України щодо клінічних випробувань лікарських засобів

( Відомості Верховної Ради України (ВВР), 2011, N 45, ст.479 )

{ Із змінами, внесеними згідно із Законом N 2469-IX ( 2469-20 ) від 28.07.2022 }

Верховна Рада України постановляє:

1. Внести зміни до таких законодавчих актів України:

1) частину третю статті 281 Цивільного кодексу України ( 435-15 ) (Відомості Верховної Ради України, 2003 р., NN 40-44, ст. 356) доповнити абзацом другим такого змісту:

"Клінічні випробування лікарських засобів проводяться відповідно до закону".

{ Підпункт 2 пункту 1 втратив чинність на підставі Закону N 2469-IX ( 2469-20 ) від 28.07.2022 }

2. Цей Закон набирає чинності з дня, наступного за днем його опублікування.

Президент України В.ЯНУКОВИЧ
