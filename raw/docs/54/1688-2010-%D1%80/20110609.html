РОЗПОРЯДЖЕННЯ від 18 серпня 2010 р. N 1688-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 515-р ( 515-2011-р ) від 09.06.2011 }

Про підписання Угоди між Урядом України, Урядом Республіки Білорусь та Урядом Республіки Польща про створення транскордонного біосферного резервату "Західне Полісся"

Схвалити проект Угоди між Урядом України, Урядом Республіки Білорусь та Урядом Республіки Польща про створення транскордонного біосферного резервату "Західне Полісся".

Уповноважити Міністра охорони навколишнього природного середовища Злочевського Миколу Владиславовича підписати зазначену Угоду.
