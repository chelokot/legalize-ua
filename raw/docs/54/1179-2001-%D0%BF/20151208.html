КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 вересня 2001 р. N 1179 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1002 ( 1002-2015-п ) від 05.12.2015 }

Про внесення зміни до постанови Кабінету Міністрів України від 25 травня 1998 р. N 747

Кабінет Міністрів України постановляє:

Внести зміну до Статуту Національної акціонерної компанії "Нафтогаз України", затвердженого постановою Кабінету Міністрів України від 25 травня 1998 р. N 747 ( 747-98-п ) "Про утворення Національної акціонерної компанії "Нафтогаз України", доповнивши пункт 6.3 абзацом такого змісту:

"Державні пакети акцій відкритих акціонерних товариств та державне майно, які були передані до статутного фонду Компанії, не можуть бути відчужені або перебувати в заставі без рішення засновника".

Прем'єр-міністр України А.КІНАХ
