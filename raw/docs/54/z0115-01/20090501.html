Мінтранс України; Наказ, Коефіцієнти від 05.02.2001 № 68

Про затвердження Коефіцієнтів, що застосовуються до тарифів Збірника тарифів на перевезення вантажів залізничним транспортом України, змін і доповнень до цього Збірника

Реєстрація: Мін'юст України від 05.02.2001 № 115/5306

Стан: Втратив чинність

Ідентифікатор: z0115-01

Текст документа від 01.05.2009:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

N 68 від 05.02.2001 Зареєстровано в Міністерстві юстиції України 5 лютого 2001 р. за N 115/5306

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 317 ( z0340-09 ) від 26.03.2009 }

Про затвердження Коефіцієнтів, що застосовуються до тарифів Збірника тарифів на перевезення вантажів залізничним транспортом України, змін і доповнень до цього Збірника

{ Із змінами, внесеними згідно з Наказами Міністерства транспорту N 302 ( z0460-01 ) від 21.05.2001 N 24 ( z0053-02 ) від 21.01.2002 N 934 ( z1015-02 ) від 27.12.2002 }

Відповідно до постанови Кабінету Міністрів України від 25 грудня 1996 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Мінтрансу N 934 ( z1015-02 ) від 27.12.2002 }

2. Затвердити Зміни і доповнення до Збірника тарифів на перевезення вантажів залізничним транспортом України, затвердженого наказом Міністерства транспорту від 15.11.99 N 551 ( z0828-99 ) і зареєстрованого в Міністерстві юстиції України 01.12.99 за N 828/4121 ( z0116-01 ).

3. Департаменту транспортної політики (Легенький Г.М.) разом з Департаментом нормативно-правового забезпечення (Логінова Л.М.) у встановленому порядку зареєструвати цей наказ у Міністерстві юстиції України.

4. Укрзалізниці (Кірпа Г.М.) після реєстрації цього наказу в Міністерстві юстиції України забезпечити своєчасне його доведення до відома вантажовідправників, вантажоодержувачів та населення України.

5. Пункт 1 наказу Міністерства транспорту України від 19.07.2000 N 377 ( z0461-00 ) "Про затвердження Коефіцієнтів, що застосовуються до тарифів Збірника тарифів на перевезення вантажів залізничним транспортом України та змін і доповнень до цього Збірника", зареєстрованого в Міністерстві юстиції України 31.07.2000 за N 461/4682, вважати таким, що втратив чинність.

6. Контроль за виконанням наказу покласти на заступника Міністра Демиденка А.Ф.

Міністр Л.М.Костюченко

Погоджено: Перший заступник Міністра економіки України В.М.Кальник

{ Коефіцієнти, що застосовуються до тарифів Збірника тарифів на перевезення вантажів залізничним транспортом України втратили чинність на підставі Наказу Мінтрансу N 934 ( z1015-02 ) від 27.12.2002 }
