КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 жовтня 2002 р. N 1505 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про внесення зміни до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2289

Кабінет Міністрів України постановляє:

1. У пункті 1 постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2289 ( 2289-99-п ) "Про умови оплати праці вищих посадових осіб України" слова "Голова Вищого арбітражного суду України" виключити.

2. Зберегти за Головою Вищого господарського суду України Притикою Д.М. заробітну плату у розмірі 2400 гривень на місяць на час його роботи на цій посаді.
