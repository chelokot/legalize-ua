Кабінет Міністрів України; Розпорядження від 21.08.1997 № 465-р

Про віднесення посад працівників апарату Представництва Президента України в Автономній Республіці Крим до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 465-97-р

Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 серпня 1997 р. N 465-р Київ

Про віднесення посад працівників апарату Представництва Президента України в Автономній Республіці Крим до відповідних категорій посад державних службовців

( Із змінами, внесеними згідно з Розпорядженнями КМ N 122-р ( 122-99-р ) від 15.02.99 N 534-р ( 534-2005-р ) від 21.12.2005 )

1. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників апарату Представництва Президента України в Автономній Республіці Крим до таких категорій посад державних службовців:

третя категорія - посади керівників служб та головного бухгалтера, радники Представництва Президента України в Автономній Республіці Крим; ( Абзац другий пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 534-р ( 534-2005-р ) від 21.12.2005 )

четверта категорія - посади заступників керівників служб, помічників Постійного Представника Президента України в Автономній Республіці Крим, прес-секретаря, головних консультантів; ( Абзац пункту 1 із змінами, внесеними згідно з Розпорядженнями КМ N 122-р ( 122-99-р ) від 15.02.99, N 534-р ( 534-2005-р ) від 21.12.2005 )

п'ята категорія - посади інших спеціалістів.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 17 жовтня 1994 р. N 759 ( 759-94-р ).
