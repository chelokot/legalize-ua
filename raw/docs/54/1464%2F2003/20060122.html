УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1871/2005 ( 1871/2005 ) від 29.12.2005 )

Про внесення змін до Указу Президента України від 8 лютого 1993 року N 34

На часткову зміну Указу Президента України від 8 лютого 1993 року N 34 ( 34/93 ) "Про Національну раду соціального партнерства" (зі змінами, внесеними Указами від 29 січня 1996 року N 97 ( 97/96 ), від 15 листопада 1996 року N 1083 ( 1083/96 ), від 19 червня 1997 року N 560 ( 560/97 ), від 31 липня 1998 року N 834 ( 834/98 ) та від 30 січня 2003 року N 51 ( 51/2003 ):

увести до складу Національної ради соціального партнерства ГРИЩЕНКА Володимира Олександровича - першого заступника Голови Федерації роботодавців України, призначивши його заступником співголови цієї Ради від об'єднань підприємців;

вивести зі складу Національної ради соціального партнерства Мірошниченка О.В.

Президент України Л.КУЧМА

м. Київ, 19 грудня 2003 року N 1464/2003
