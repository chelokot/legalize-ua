УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 486/2021 ( 486/2021 ) від 27.09.2021 }

Про внесення зміни до статті 2 Указу Президента України від 7 листопада 2001 року N 1053

Внести зміну до статті 2 Указу Президента України від 7 листопада 2001 року N 1053 ( 1053/2001 ) "Про положення про проходження військової служби відповідними категоріями військовослужбовців", замінивши слова "Служби безпеки України" словами "Управління державної охорони України, на яких поширюється чинність положень, зазначених в абзацах п'ятому і сьомому цієї статті".

Президент України Л.КУЧМА

м. Київ, 5 січня 2004 року N 9/2004
