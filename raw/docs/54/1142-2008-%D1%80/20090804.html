Про встановлення строку переробки авіаційних агрегатів, обладнання та їх складових частин на митній території України

Стан: Втратив чинність

Текст документа від 04.08.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 серпня 2008 р. N 1142-р Київ

Про встановлення строку переробки авіаційних агрегатів, обладнання та їх складових частин на митній території України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 882-р ( 882-2009-р ) від 29.07.2009 }

1. Відповідно до статті 232 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей установити для переробки частин літальних апаратів, авіаційних агрегатів, обладнання та їх складових частин за кодами згідно з УКТЗЕД 8803301000 ( 2371г-14 ), 4016931000 ( 2371б-14 ) і 8302491000 ( 2371в-14 ) строк 360 днів від дня завершення митного оформлення товарів, що ввозяться із зазначеною метою.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 882-р ( 882-2009-р ) від 29.07.2009 }

2. Це розпорядження набирає чинності з дня опублікування.
