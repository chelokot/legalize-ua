Про внесення змін до деяких нормативно-правових актів Державного департаменту України з питань виконання покарань

{ Із змінами, внесеними згідно з Наказами Міністерства юстиції N 222/5 ( z0213-12 ) від 08.02.2012 N 2186/5 ( z1656-14 ) від 29.12.2014 }

Відповідно до норм Кримінально-виконавчого кодексу України ( 1129-15 ) та з метою вдосконалення порядку зміни умов тримання засуджених шляхом їх переведення до виправних колоній іншого рівня безпеки та з виховних колоній до виправних колоній мінімального рівня безпеки із загальними умовами тримання НАКАЗУЮ:

1. Затвердити зміни, що вносяться до деяких нормативно-правових актів Державного департаменту України з питань виконання покарань (додаються).

2. Начальникам територіальних органів управління Державного департаменту України з питань виконання покарань (далі - Департамент) організувати вивчення цього наказу відповідними категоріями посадових осіб територіальних органів управління, установ виконання покарань і слідчих ізоляторів та у двотижневий термін прийняти у них заліки.

3. Управлінню по контролю за виконанням судових рішень Департаменту (Двойнос О.Г.) забезпечити подання цього наказу в установленому порядку на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням цього наказу покласти на першого заступника Голови Департаменту Пташинського О.Б.

Голова генерал-полковник внутрішньої служби В.А.Льовочкін
