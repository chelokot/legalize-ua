Механізм контролю за використанням бюджетних коштів, виділених для проведення робіт, пов'язаних із закладенням виноградників сільськогосподарськими підприємствами Держсадвинпрому України

Держсадвинпром та Мінфін України встановлюють такий механізм контролю за використанням бюджетних коштів, виділених для проведення робіт, пов'язаних із закладенням виноградників сільськогосподарськими підприємствами Держсадвинпрому.

Відшкодування витрат по закладанню виноградників сільськогосподарськими підприємствами провадиться у межах коштів, виділених із державного бюджету для цих цілей.

Вказані кошти перераховуються Міністерством фінансів України на бюджетний рахунок Державного комітету України з питань садівництва, виноградарства та виноробної промисловості, який, виходячи з визначеної потреби, перераховує їх на бюджетні рахунки обласних формувань з питань садівництва, виноградарства та виноробної промисловості, останні - на бюджетні рахунки сільськогосподарських підприємств.

Одержувачами коштів можуть бути сільськогоподарські підприємства Держсадвинпрому України. ( Абзац четвертий в редакції Наказу Мінфіну N 151/168 ( z0448-95 ) від 22.09.95 )

Суми відшкодувань визначаються відповідно до документів, поданих сільськогосподарськими підприємствами (додаток N 1, N 2) але не більше:

200.0 млн.крб. за 1 гектар закладки нових виноградників;

100.0 млн.крб. за ремонт виноградників у перерахунку на 1 гектар суцільної площі:

70.0 млн.крб. за встановлення шпалери у перерахунку на 1 гектар суцільної площі.

У разі зміни національної валюти обсяги фінансування визначаються відповідно до діючого законодавства.

Для одержання коштів по відшкодуванню витрат обласні формування з питань садівництва, виноградарства та виноробної промисловості подають Держсадвинпрому реєстри актів і копії актів на закладення виноградників у двох примірниках, з яких один надається Мінфіну.

Одержувачі коштів подають щомісячну (форма 2МДБ), квартальну та щорічну звітність (форма 2) про використання бюджетних асигнувань.

Контроль за цільовим використанням бюджетних коштів покладається на Держсадвинпром, обласні формування з питань садівництва, виноградарства та виноробної промисловості і місцеві фінансові органи.
