Про умови оплати праці працівників регіональних державних інспекцій пробірного контролю

Стан: Втратив чинність

Текст документа від 16.03.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 травня 1999 р. N 856 Київ

( Постанова втратила чинність на підставі Постанови КМ N 250 ( 250-2001-п ) від 16.03.2001 )

Про умови оплати праці працівників регіональних державних інспекцій пробірного контролю

( Із змінами, внесеними згідно з Постановою КМ N 207 ( 207-2000-п ) від 02.02.2000 )

Кабінет Міністрів України постановляє:

1. Прирівняти керівних працівників, спеціалістів і службовців регіональних державних інспекцій пробірного контролю за умовами оплати праці, матеріально-побутового забезпечення, медичного та транспортного обслуговування до відповідних категорій працівників управлінь, самостійних відділів обласних державних адміністрацій, областей, віднесених за оплатою праці поза групою.

2. Інші умови оплати праці працівників регіональних державних інспекцій пробірного контролю встановити відповідно до постанови Кабінету Міністрів України від 21 січня 1993 р. N 35 ( 35-93-п ) "Про умови оплати праці працівників апарату органів державної виконавчої влади та інших органів", також до постанови Кабінету Міністрів України від 4 жовтня 1995 р. N 783 ( 783-95-п ) "Про надбавки до посадових окладів за особливий характер роботи та інтенсивність праці".

3. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади начальників регіональних державних інспекцій пробірного контролю до четвертої категорії, їх заступників, начальників відділів та заступників начальників відділів - до п'ятої категорії, спеціалістів, експертів - до шостої категорії посад державних службовців.

( Пункт 4 втратив чинність на підставі Постанови КМ N 207 ( 207-2000-п ) від 02.02.2000 ) 4. Установити керівним працівникам і спеціалістам регіональних державних інспекцій пробірного контролю надбавки за особливі умови роботи з дорогоцінними металами у розмірі 30 відсотків посадового окладу з урахуванням доплати за ранг державного службовця.
