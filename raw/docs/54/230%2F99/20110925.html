Президент України; Указ від 04.03.1999 № 230/99

Про довічні стипендії Президента України видатним діячам науки та освіти

Стан: Втратив чинність

Ідентифікатор: 230/99

Текст документа від 25.09.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 906/2011 ( 906/2011 ) від 10.09.2011 }

Про довічні стипендії Президента України видатним діячам науки та освіти

{ Із змінами, внесеними згідно з Указом Президента N 58/2006 ( 58/2006 ) від 23.01.2006 N 444/2008 ( 444/2008 ) від 16.05.2008 }

З метою посилення державної підтримки науки та освіти постановляю:

1. Установити з 1 березня 1999 року по сто довічних державних стипендій для видатних діячів науки та видатних діячів освіти, які досягли сімдесятирічного віку, в розмірі п'ятнадцяти неоподатковуваних мінімумів доходів громадян.

{ На часткову зміну статті 1 установити з 1 січня 2006 року розмір державних стипендій, у тому числі довічних, видатним діячам науки, освіти, культури та мистецтва 385 гривень кожна згідно з Указом Президента N 58/2006 ( 58/2006 ) від 23.01.2006 } { На часткову зміну статті 1 установити розмір державних стипендій, у тому числі довічних, видатним діячам науки, освіти, культури та мистецтва у розмірі 1,5 прожиткового мінімуму для осіб, які втратили працездатність, кожна згідно з Указом Президента N 444/2008 ( 444/2008 ) від 16.05.2008 }

2. Внести до Указів Президента України такі зміни:

1) частину другу статті 1 Указу Президента України від 14 лютого 1996 року N 128 ( 128/96 ) "Про державні стипендії видатним діячам науки, освіти та культури" (в редакції Указу від 19 січня 1999 року N 36 ( 36/99 ) викласти в такій редакції:

"У межах цієї кількості стипендій установити по 100 довічних державних стипендій для видатних діячів культури і мистецтва, видатних діячів науки та видатних діячів освіти, які досягли сімдесятирічного віку";

2) абзац другий пункту 6 Положення про державні стипендії видатним діячам науки, освіти та культури, затвердженого Указом Президента України від 13 травня 1996 року N 341 ( 341/96 ) (в редакції Указу від 19 січня 1999 року N 36 ( 36/99 ), викласти в такій редакції:

"У межах цієї кількості стипендій Президент України призначає по 100 довічних щомісячних державних стипендій для видатних діячів культури і мистецтва, видатних діячів науки та видатних діячів освіти, які досягли сімдесятирічного віку".

Президент України Л.КУЧМА
