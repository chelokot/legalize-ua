Про внесення змін до Переліку продукції, що підлягає обов'язковій сертифікації в Україні

Відповідно до статті 14 Декрету Кабінету Міністрів України від 10.05.93 N 46-93 "Про стандартизацію і сертифікацію" та на виконання Указу Президента України від 22.01.2000 N 89/2000 і доручення Кабінету Міністрів України від 26.01.2000 N 1090/1 НАКАЗУЮ:

1. Унести до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, затвердженого наказом Держстандарту України від 30.06.93 N 95 ( z0112-93 ) і зареєстрованого в Міністерстві юстиції України 19.08.93 за N 112, зі змінами та доповненнями, внесеними наказами Держстандарту України від 27.11.96 N 499 ( z0728-96, za728-96 ), від 17.05.97 N 268 ( z0209-97 ), від 04.07.97 N 388 ( z0304-97 ), від 11.09.97 N 549 ( z0461-97 ), від 20.01.98 N 27 ( z0072-98 ), від 27.01.99 N 37 ( z0234-99 ), від 05.05.99 N 205 ( z0299-99 ), від 14.06.99 N 322 ( z0404-99 ), від 14.06.99 N 323 ( z0416-99 ), від 10.12.99 N 389 ( z0897-99 ), від 29.12.99 N 418 ( z0013-00 ) та зареєстрованими в Міністерстві юстиції України відповідно 19.12.96 за N 728/1753, 05.06.97 за N 209/2013, 13.08.97 за N 304/2108, 09.10.97 за N 461/2265, 04.02.98 за N 72/2512, 15.04.99 за N 234/3527, 11.05.99 за N 299/3592, 22.06.99 за N 404/3697, 24.06.99 за N 416/3709, 22.12.99 за N 897/4190, 13.01.2000 за N 13/4234, такі зміни:

2. Управлінню аналізу, стратегічного планування та міжнародного співробітництва (Віткін Л.М.) у п'ятиденний термін забезпечити подання на державну реєстрацію до Міністерства юстиції України наказу "Про внесення змін до Переліку продукції, що підлягає обов'язковій сертифікації в Україні".

3. Українському науково-дослідному інституту стандартизації, сертифікації та інформатики (Угаров Б.М.) після державної реєстрації в Міністерстві юстиції України наказу "Про внесення змін до Переліку продукції, що підлягає обов'язковій сертифікації в Україні" у місячний термін забезпечити його публікацію в бюлетені зі стандартизації, метрології та сертифікації.

4. Наказ "Про внесення змін до Переліку продукції, що підлягає обов'язковій сертифікації в Україні" набуває чинності через один місяць після реєстрації в Міністерстві юстиції України.

5. Контроль за виконанням цього наказу залишаю за собою.
