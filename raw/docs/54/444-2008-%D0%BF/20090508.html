Питання ввезення на митну територію України енергозберігаючих матеріалів, обладнання, устаткування та комплектуючих

Стан: Втратив чинність

Ідентифікатор: 444-2008-п

Текст документа від 08.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 травня 2008 р. N 444 Київ

Питання ввезення на митну територію України енергозберігаючих матеріалів, обладнання, устаткування та комплектуючих

{ Із змінами, внесеними згідно з Постановами КМ N 1001 ( 1001-2008-п ) від 10.11.2008 N 132 ( 132-2009-п ) від 18.02.2009 N 399 ( 399-2009-п ) від 10.04.2009 }

Відповідно до статті 19 Закону України "Про Єдиний митний тариф" ( 2097-12 ) Кабінет Міністрів України постановляє:

1. Установити, що:

суб'єкти господарювання, які ввозять на митну територію України енергозберігаючі матеріали, обладнання, устаткування та комплектуючі та які відповідно до підпунктів "ч" і "щ" частини першої статті 19 Закону України "Про Єдиний митний тариф" ( 2097-12 ) звільняються від сплати мита (далі - товар), подають митному органу щомісяця до 5 числа наступного періоду звіт про цільове використання товарів у двох примірниках за встановленою Державною митною службою формою. Другий примірник звіту з відміткою митного органу подається зазначеними суб'єктами щомісяця до 13 числа наступного періоду Національному агентству з питань забезпечення ефективного використання енергетичних ресурсів;

у разі виявлення нецільового використання товарів митний орган в установленому порядку вживає заходів до стягнення несплачених сум ввізного мита в порядку та розмірах, визначених законом.

2. Затвердити перелік та обсяги енергозберігаючих матеріалів, обладнання, устаткування та комплектуючих, що звільняються від ввізного мита (додається).

3. Ця постанова набирає чинності з дня опублікування.
