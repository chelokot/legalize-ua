КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 червня 2006 р. N 877 Київ

Про затвердження державного замовлення на підготовку фахівців, науково-педагогічних та робітничих кадрів, підвищення кваліфікації та перепідготовку кадрів (післядипломна освіта) для державних потреб у 2006 році

{ Із змінами, внесеними згідно з Наказами Міністерства економіки N 316 ( v0316665-06 ) від 17.10.2006 N 397 ( v0397665-06 ) від 29.12.2006 N 398 ( v0398665-06 ) від 29.12.2006 }

Кабінет Міністрів України постановляє:

1. Затвердити обсяги державного замовлення на підготовку фахівців, науково-педагогічних та робітничих кадрів, підвищення кваліфікації та перепідготовку кадрів (післядипломна освіта) для державних потреб у 2006 році (далі - обсяги державного замовлення), що додаються.

2. Дозволити Міністерству економіки вносити за поданням державних замовників, погодженим з Міністерством освіти і науки, зміни до обсягів державного замовлення у межах бюджетних асигнувань.

3. Установити, що державні замовники подають не пізніше ніж до 15 листопада ц. р. Міністерству економіки пропозиції стосовно внесення змін до обсягів державного замовлення.
