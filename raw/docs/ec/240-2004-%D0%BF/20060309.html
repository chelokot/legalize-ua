Стан: Втратив чинність

Текст документа від 09.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 березня 2004 р. N 240 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

Про внесення змін у додатки до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288 та до пункту 3 Державної програми організаційного забезпечення діяльності судів на 2003-2005 роки

Кабінет Міністрів України постановляє:

Внести у додатки до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288 ( 2288-99-п ) "Про впорядкування умов оплати праці працівників апарату органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів" (Офіційний вісник України, 1999 р., N 50, ст. 2469; 2000 р., N 22, ст. 905; 2003 р., N 10, ст. 443) та до пункту 3 Державної програми організаційного забезпечення діяльності судів на 2003-2005 роки, затвердженої постановою Кабінету Міністрів України від 16 червня 2003 р. N 907 ( 907-2003-п ) (Офіційний вісник України, 2003 р., N 25, ст. 1197), зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 3 березня 2004 р. N 240

ЗМІНИ, що вносяться у додатки до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288 ( 2288-99-п ) та до пункту 3 Державної програми організаційного забезпечення діяльності судів на 2003-2005 роки ( 907-2003-п )

1. У додатках до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288 ( 2288-99-п ):

у назві додатка 42 слова "Касаційного суду України" виключити;

у додатку 46 слова "Касаційний суд України та" виключити.

2. У пункті 3 Державної програми організаційного забезпечення діяльності судів на 2003-2005 роки ( 907-2003-п ):

у першому реченні слова "та Касаційного суду України" виключити;

у другому реченні слова "зазначених судів" замінити словами "зазначеного суду".
