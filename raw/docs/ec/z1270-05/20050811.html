Мінекономіки (з 2005 р.); Наказ від 11.08.2005 № 243

Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 08.08.2002 N 244

Реєстрація: Мін'юст України від 26.10.2005 № 1270/11550

Стан: Втратив чинність

Ідентифікатор: z1270-05

Текст документа від 11.08.2005:

МІНІСТЕРСТВО ЕКОНОМІКИ УКРАЇНИ

НАКАЗ

11.08.2005 N 243

Зареєстровано в Міністерстві юстиції України 26 жовтня 2005 р. за N 1270/11550

Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 08.08.2002 N 244

Відповідно до Закону України від 06.07.2005 N 2734-IV ( 2734-15 ) "Про внесення змін до деяких законодавчих актів України (щодо впорядкування операцій, пов'язаних з виробництвом, експортом, імпортом дисків для лазерних систем зчитування, обладнання та сировини для їх виробництва)" НАКАЗУЮ:

1. Унести до наказу Міністерства економіки та з питань європейської інтеграції України від 08.08.2002 N 244 ( z0704-02 ) "Про Порядок видачі ліцензій на вид господарської діяльності - експорт, імпорт обладнання та дисків для лазерних систем зчитування", зареєстрованого в Міністерстві юстиції України 23.08.2002 за N 704/6992, та Порядку, затвердженого цим наказом, такі зміни:

у назві і тексті наказу та Порядку ( z0704-02 ), затвердженого зазначеним наказом, слова "обладнання та" у всіх відмінках виключити;

у пункті 2.1 розділу 2 Порядку ( z0704-02 ), затвердженого зазначеним наказом, вилучити останній абзац;

у назві і тексті наказу та Порядку ( z0704-02 ), затвердженого зазначеним наказом, після слів "дисків для лазерних систем зчитування" доповнити словом "матриць" у відповідних відмінках;

у тексті наказу та Порядку ( z0704-02 ) слова "Міністерство економіки та з питань європейської інтеграції України" в усіх відмінках замінити словами "Міністерство економіки України" у відповідному відмінку.

2. Контроль за виконанням цього наказу покласти на заступника Міністра економіки України Березного А.В.

Виконуючий обов'язки Міністра економіки України С.Романюк
