Кабінет Міністрів України; Розпорядження від 20.03.1996 № 200-р

Про віднесення посад працівників Секретаріату Верховної Ради до відповідних категорій державних службовців

Стан: Втратив чинність

Ідентифікатор: 200-96-р

Текст документа від 28.08.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 березня 1996 р. N 200-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 663-р ( 663-2013-р ) від 28.08.2013 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посаду першого заступника завідуючого відділом Секретаріату Верховної Ради України до другої категорії посад державних службовців.
