Кабінет Міністрів України; Постанова від 04.03.2004 № 278

Про включення Національного університету "Острозька академія" до переліку вищих навчальних закладів з підготовки та перепідготовки фахівців органів державної влади та ринкової економіки

Стан: Втратив чинність

Ідентифікатор: 278-2004-п

Текст документа від 30.03.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 березня 2004 р. N 278 Київ

( Постанова втратила чинність на підставі Постанови КМ N 218 ( 218-2005-п ) від 30.03.2005 )

Про включення Національного університету "Острозька академія" до переліку вищих навчальних закладів з підготовки та перепідготовки фахівців органів державної влади та ринкової економіки

Кабінет Міністрів України постановляє:

Включити Національний університет "Острозька академія" до переліку вищих навчальних закладів з підготовки та перепідготовки фахівців органів державної влади та ринкової економіки, затвердженого постановою Кабінету Міністрів України від 28 липня 1995 р. N 560 ( 560-95-п ), із змінами, внесеними постановою Кабінету Міністрів України від 28 грудня 2001 р. N 1812 ( 1812-2001-п ) (Офіційний вісник України, 2002 р., N 1, ст. 4).

Прем'єр-міністр України В.ЯНУКОВИЧ
