КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 лютого 2003 р. N 117-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Про віднесення посади директора Національного інституту стратегічних досліджень до першої категорії посад державних службовців

На часткову зміну абзацу першого розпорядження Кабінету Міністрів України від 23 грудня 1994 р. N 933 ( 933-94-р ) (із змінами, внесеними розпорядженням Кабінету Міністрів України від 25 травня 1999 р. N 471 ( 471-99-р ) віднести посаду директора Національного інституту стратегічних досліджень до першої категорії посад державних службовців.
