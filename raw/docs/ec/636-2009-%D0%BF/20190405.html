{ Постанова втратила чинність на підставі Постанови КМ N 260 ( 260-2019-п ) від 06.03.2019 }

Про доповнення переліку об'єктів державного цінового регулювання з визначенням періодів такого регулювання у 2009-2010 роках

Кабінет Міністрів України постановляє:

1. Доповнити перелік об'єктів державного цінового регулювання з визначенням періодів такого регулювання у 2009-2010 роках, затверджений постановою Кабінету Міністрів України від 21 січня 2009 р. N 33 ( 33-2009-п ) (Офіційний вісник України, 2009 р., N 6, ст. 170), такою позицією:

------------------------------------------------------------------

|"Ячмінь |1003 00 |з 1 липня 2009 р. |

| | |до 30 червня 2010 р.". |

------------------------------------------------------------------

2. Установити мінімальну закупівельну ціну на ячмінь першого класу 1050 гривень за 1 тонну з урахуванням податку на додану вартість.
