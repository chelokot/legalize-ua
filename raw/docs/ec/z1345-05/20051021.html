НАКАЗ

21.10.2005 N 572/719/363

Зареєстровано в Міністерстві юстиції України 7 листопада 2005 р. за N 1345/11625

Про визнання таким, що втратив чинність, наказу Державного комітету України по харчовій промисловості, Міністерства сільського господарства і продовольства України, Міністерства фінансів України та Міністерства економіки України від 28 березня 1996 року N 20/96/49/38

На виконання статті 3 Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" НАКАЗУЄМО:

1. Визнати таким, що втратив чинність, наказ Державного комітету України по харчовій промисловості, Міністерства сільського господарства і продовольства України, Міністерства фінансів України, Міністерства економіки України від 28.03.96 N 20/96/49/38 ( z0157-96 ) "Про Механізм стимулювання виробництва та реалізації насіння буряків", зареєстрований в Міністерстві юстиції України 5 квітня 1996 року за N 157/1182.

2. Державному департаменту продовольства (Кіщак Ю.П.) в установленому порядку подати наказ на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням наказу покласти на заступника Міністра аграрної політики України Мельника С.І., заступника Міністра фінансів України Регурецького В.В., першого заступника Міністра економіки України Романюка С.А.
