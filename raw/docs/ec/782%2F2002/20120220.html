Про внесення змін до складу Комісії державних нагород та геральдики

На зміну Указу Президента України від 11 квітня 2000 року N 583 ( 583/2000 ) "Про Комісію державних нагород та геральдики" (зі змінами, внесеними Указами від 23 травня 2000 року N 706 ( 706/2000 ), від 14 липня 2000 року N 897 ( 897/2000 ) та 26 червня 2002 року N 585 ( 585/2002 ) ввести до складу зазначеної Комісії ШАРОВА Ігоря Федоровича - народного депутата України (за згодою), вивівши з її складу Шуляка П.І.

Президент України Л.КУЧМА
