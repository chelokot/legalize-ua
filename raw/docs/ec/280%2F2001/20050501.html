УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 625/2005 ( 625/2005 ) від 11.04.2005 )

Про зміни у складі Консультативної ради з питань іноземних інвестицій в Україні

На часткову зміну Указу Президента України від 11 квітня 1997 року N 323 ( 323/97 ) "Про Консультативну раду з питань іноземних інвестицій в Україні" (із змінами, внесеними Указами Президента України від 29 липня 1997 року N 717 ( 717/97 ), від 11 вересня 1997 року N 1006 ( 1006/97 ), від 6 травня 1998 року N 414 ( 414/98 ), від 21 березня 2000 року N 468 ( 468/2000 ), від 29 травня 2000 року N 725 ( 725/2000 ), від 8 червня 2000 року N 775 ( 775/2000 ) та від 19 жовтня 2000 року N 1146 ( 1146/2000):

ввести до складу Консультативної ради з питань іноземних інвестицій в Україні ПЛЮЩА Івана Степановича - Голову Верховної Ради України (за згодою), Йоргена СЕНТЕРМАНА - президента, головного виконавчого директора групи "АББ", Майкла БЛЕЙЗЕРА - президента компанії СігмаБлейзер, директора-розпорядника, Маттіаса КЛЯЙНЕРТА - головного уповноваженого, члена директорії концерну "Даймлер-Крайслер" та Ретсу ІМАІЗУМІ - головного виконавчого директора-розпорядника компанії Міцуі енд Ко., Лтд., відповідального за угоди з країнами СНД;

вивести зі складу зазначеної Консультативної ради Клауса Мангольда, Герана Ліндала, Наохіко Кумагаі.

Президент України Л.КУЧМА

м. Київ, 25 квітня 2001 року N 280/2001
