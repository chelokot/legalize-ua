Про межі акваторії спеціалізованого морського порту Октябрьск

{ Назва Постанови в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

{ Із змінами, внесеними згідно з Постановою КМ N 406 ( 406-2013-п ) від 03.06.2013 }

Кабінет Міністрів України постановляє:

1. Визначити межі акваторії спеціалізованого морського порту Октябрьск згідно з додатком.

{ Пункт 1 в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013 }

2. Державному підприємству "Адміністрація морських портів України" забезпечити безпеку судноплавства в межах акваторії, визначених у додатку.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 406 ( 406-2013-п ) від 03.06.2013 }
