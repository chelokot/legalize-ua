Кабінет Міністрів України; Розпорядження від 21.07.1992 № 468-р

Про поширення чинності пункту 2 розпорядження Кабінету Міністрів України від 4 червня 1992 р. N 329

Стан: Втратив чинність

Ідентифікатор: 468-92-р

Текст документа від 07.07.1993:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 липня 1992 р. N 468-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 469 ( 469-93-п ) від 23.06.93 )

( Дію Розпорядження відновлено згідно з Постановою КМ N 307 ( 307-93-п ) від 29.04.93 )

( Розпорядження втратило чинність на підставі Постанови КМ N 232 ( 232-93-п ) від 27.03.93 )

З метою створення сприятливих умов для розвитку підприємництва в торгівлі поширити чинність пункту 2 розпорядження Кабінету Міністрів України від 4 червня 1992 р. N 329 ( 329-92-р ) на всі недержавні підприємства торгівлі незалежно від їхніх організаційних форм, а також на громадян-підприємців, які здійснюють торговельну діяльність.

Перший віце-прем'єр-міністр України В.СИМОНЕНКО
