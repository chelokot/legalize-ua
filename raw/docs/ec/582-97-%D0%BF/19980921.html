КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 червня 1997 р. N 582 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1145 ( 1145-98-п ) від 27.07.98 )

Про внесення зміни до переліку товарів, щодо яких не застосовуються пільги, встановлені статтею 1 Указу Президента України від 30 червня 1995 р. N 499

Кабінет Міністрів України постановляє:

Перелік товарів, щодо яких не застосовуються пільги, встановлені статтею 1 Указу Президента України від 30 червня 1995 р. N 499 ( 499/95 ), який затверджений постановою Кабінету Міністрів України від 31 травня 1996 р. N 602 ( 602-96-п ) (із змінами та доповненнями, внесеними постановами Кабінету Міністрів України від 2 серпня 1996 р. N 907, від 14 серпня 1996 р. N 967, від 23 вересня 1996 р. N 1165, від 8 листопада 1996 р. N 1356, від 17 січня 1997 р. N 23, від 23 січня 1997 р. N 53, від 28 березня 1997 р. N 282, від 5 травня 1997 р. N 415 та розпорядженням Кабінету Міністрів України від 12 грудня 1996 р. N 799), після цифр і слів "09.02.30000 Чай чорний, ферментований або частково ферментований, у безпосередніх упаковках чистою ємкістю не більше 3 кг" доповнити словами "(крім обсягів цієї продукції, що ввозиться на митну територію України для закладення до державного резерву)".

Прем'єр-міністр України П.ЛАЗАРЕНКО
