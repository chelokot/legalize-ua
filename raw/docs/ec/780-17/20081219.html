Верховна Рада України; Постанова від 19.12.2008 № 780-VI

Про звернення Верховної Ради України щодо Указу Президента України "Про призначення Т. Дурдинця заступником Голови Служби безпеки України - начальником Головного управління по боротьбі з корупцією та організованою злочинністю"

Стан: Чинний

Ідентифікатор: 780-17

Текст документа від 19.12.2008:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про звернення Верховної Ради України щодо Указу Президента України "Про призначення Т. Дурдинця заступником Голови Служби безпеки України - начальником Головного управління по боротьбі з корупцією та організованою злочинністю"

( Відомості Верховної Ради України (ВВР), 2009, N 23, ст.286 )

Зважаючи на вимоги частини третьої статті 106 щодо підстав для видання Президентом України указів і частини п'ятої статті 124 Конституції України ( 254к/96-ВР ) про обов'язкове виконання судових рішень, Верховна Рада України постановляє:

Запропонувати Президенту України скасувати Указ Президента України від 19 жовтня 2007 року N 985/2007 ( 985/2007 ) "Про призначення Т. Дурдинця заступником Голови Служби безпеки України начальником Головного управління по боротьбі з корупцією та організованою злочинністю".
