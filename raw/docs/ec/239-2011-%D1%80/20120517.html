Кабінет Міністрів України; Розпорядження від 30.03.2011 № 239-р

Про проведення Міжнародного дитячого фестивалю "Змінимо світ на краще!"

Стан: Втратив чинність

Ідентифікатор: 239-2011-р

Текст документа від 17.05.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 березня 2011 р. N 239-р Київ

Про проведення Міжнародного дитячого фестивалю "Змінимо світ на краще!"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 289-р ( 289-2012-р ) від 17.05.2012 }

1. Підтримати пропозицію Міністерства освіти і науки, молоді та спорту та Всеукраїнського благодійного фонду Надії і Добра щодо проведення щороку в липні - серпні в державному підприємстві "Міжнародний дитячий центр "Артек" Міжнародного дитячого фестивалю "Змінимо світ на краще!" (далі - Фестиваль), зокрема в 2011 році ювілейного (десятого) Фестивалю, та в його рамках сесії генеральної асамблеї Міжнародної громадської організації "Всесвітня Дитяча Ліга Націй".

2. Міністерству закордонних справ сприяти участі іноземних учасників Фестивалю та за поданням Міністерства соціальної політики забезпечувати їм оформлення віз на в'їзд в Україну за нульовою тарифною ставкою консульського збору.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 289-р ( 289-2012-р ) від 17.05.2012 }

3. Міністерству соціальної політики здійснювати видатки, пов'язані з проведенням Фестивалю, відповідно до бюджетних призначень, передбачених у Державному бюджеті України на відповідний рік.

{ Пункт 3 із змінами, внесеними згідно з Розпорядженням КМ N 289-р ( 289-2012-р ) від 17.05.2012 }

Прем'єр-міністр України М.АЗАРОВ
