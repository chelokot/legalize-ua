Кабінет Міністрів України; Розпорядження від 20.09.2001 № 439-р

Про утворення робочої групи з представниками ЄБРР щодо підготовки спільних проектів з енергозбереження

Стан: Втратив чинність

Ідентифікатор: 439-2001-р

Текст документа від 08.11.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 вересня 2001 р. N 439-р Київ

Про утворення робочої групи з представниками ЄБРР щодо підготовки спільних проектів з енергозбереження

{ Із змінами, внесеними згідно з Постановами КМ N 746 ( 746-2005-п ) від 16.08.2005 N 1571 ( 1571-2006-п ) від 08.11.2006 }

Утворити робочу групу з представниками ЄБРР щодо підготовки спільних проектів з енергозбереження. ( Абзац перший із змінами, внесеними згідно з Постановою КМ N 746 ( 746-2005-п ) від 16.08.2005 )

Затвердити керівником робочої групи заступника Голови НАЕР. { Розпорядження доповнено абзацом згідно з Постановою КМ N 746 ( 746-2005-п ) від 16.08.2005; із змінами, внесеними згідно з Постановою КМ N 1571 ( 1571-2006-п ) від 08.11.2006 }

Надати керівникові робочої групи право затверджувати склад робочої групи, вносити зміни до її складу та у разі необхідності залучати до її роботи представників центральних і місцевих органів виконавчої влади, установ та організацій (за погодженням з їх керівниками). ( Абзац третій із змінами, внесеними згідно з Постановою КМ N 746 ( 746-2005-п ) від 16.08.2005 )
