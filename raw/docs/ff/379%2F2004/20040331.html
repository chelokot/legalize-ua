Текст документа від 31.03.2004:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення зміни до статті 1 Указу Президента України від 26 лютого 2002 року N 181

На зміну статті 1 Указу Президента України від 26 лютого 2002 року N 181 ( 181/2002 ) "Про забезпечення членства України у Чорноморському банку торгівлі та розвитку" (зі змінами, внесеними Указом від 3 червня 2003 року N 473 ( 473/2003 ) призначити ДЕРКАЧА Миколу Івановича - Міністра економіки та з питань європейської інтеграції України - керуючим у Правлінні Чорноморського банку торгівлі та розвитку, увільнивши від виконання цих обов'язків Хорошковського В.І.

Президент України Л.КУЧМА

м. Київ, 31 березня 2004 року N 379/2004
