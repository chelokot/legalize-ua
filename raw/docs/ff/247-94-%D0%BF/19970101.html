Кабінет Міністрів України; Постанова від 26.04.1994 № 247

Про розмір плати за використання прісних водних ресурсів сільськогосподарськими товаровиробниками

Стан: Втратив чинність

Ідентифікатор: 247-94-п

Текст документа від 01.01.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 квітня 1994 р. N 247 Київ

( Постанова втратила чинність на підставі Постанови КМ N 164 ( 164-97-п ) від 08.02.97 )

Про розмір плати за використання прісних водних ресурсів сільськогосподарськими товаровиробниками

( Продовжити на 1995 рік чинність Постанови у частині звільнення виробників сільськогосподарської продукції, включаючи тих, що здійснюють зрошення, від сплати постачальникам - підприємствам (організаціям) Державного комітету по водному господарству вартості послуг, пов'язаних з подачею води на зрошення згідно з Постановою КМ N 174 ( 174-95-п ) від 14.03.95 )

На часткову зміну постанови Кабінету Міністрів України від 8 лютого 1994 р. N 75 ( 75-94-п ) "Про затвердження Порядку справляння плати за спеціальне використання прісних водних ресурсів і тимчасових нормативів плати за їх спеціальне використання" Кабінет Міністрів України ПОСТАНОВЛЯЄ:

Установити на 1994 рік для виробників сільськогосподарської продукції, включаючи тих, що здійснюють зрошення, пільговий коефіцієнт до тимчасових нормативів плати за спеціальне використання прісних водних ресурсів 0,01, та звільнити їх від сплати постачальникам - підприємствам (організаціям) Державного комітету по водному господарству у цьому році вартості послуг, пов'язаних з подачею води на зрошення.
