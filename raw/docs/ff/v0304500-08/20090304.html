{ Постанова втратила чинність на підставі Постанови Національного банку N 116 ( v0116500-09 ) від 04.03.2009 }

Про встановлення мінімального розміру регулятивного капіталу банків у гривнях

Відповідно до статті 58 Закону України "Про Національний банк України" ( 679-14 ) та глави 2 розділу II Інструкції про порядок регулювання діяльності банків в Україні, затвердженої постановою Правління Націнального банку України від 28.08.2001 N 368 ( z0841-01 ), зареєстрованої в Міністерстві юстиції України 26.09.2001 за N 841/6032 (зі змінами), Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Установити на 2008 рік мінімальний розмір регулятивного капіталу (Н1) у гривнях, еквівалентний розміру нормативного значення, установленого в євро, - 74194 тис. грн.

2. Установити, що в 2008 році для отримання письмового дозволу на проведення операцій або розширення переліку операцій, спеціальні вимоги щодо здійснення яких установлені главою 5 Положення про порядок видачі банкам банківських ліцензій, письмових дозволів та ліцензій на виконання окремих операцій, затвердженого постановою Правління Національного банку України від 17.07.2001 N 275 ( z0730-01 ), зареєстрованого в Міністерстві юстиції України 21.08.2001 за N 730/5921 (зі змінами), банки та банківські корпорації зобов'язані дотримуватися розміру регулятивного капіталу в гривнях, еквівалентному розміру, установленому в євро:

10 млн. євро - 74194 тис. грн.;

15 млн. євро - 111291 тис. грн.;

20 млн. євро - 148389 тис. грн.

3. Визнати такими, що втратили чинність:

постанову Правління Національного банку України від 29.03.2005 N 91 ( v0091500-05 ) "Про встановлення мінімального розміру регулятивного капіталу банків у гривнях";

постанову Правління Національного банку України від 07.11.2005 N 411 ( v0411500-05 ) "Про внесення змін до постанови Правління Національного банку України від 29.03.2005 N 91";

постанову Правління Національного банку України від 27.10.2006 N 416 ( v0416500-06 ) "Про внесення зміни до постанови Правління Національного банку України від 29.03.2005 N 91";

постанову Правління Національного банку України від 15.02.2006 N 50 ( v0050500-06 ) "Про встановлення мінімального розміру регулятивного капіталу банків у гривнях".

4. Постанова набирає чинності з 11 жовтня 2008.

5. Департаменту нормативно-методологічного забезпечення банківського регулювання та нагляду (Н.В.Іваненко) довести зміст цієї постанови до відома структурних підрозділів центрального апарату, територіальних управлінь Національного банку України, а також банків для керівництва в роботі.

6. Контроль за виконанням цієї постанови покласти на заступника Голови В.Л.Кротюка, виконавчого директора - директора Дирекції з банківського регулювання та нагляду О.І.Кірєєва, департаменти безвиїзного банківського нагляду (В.І.Мазепа), інспектування банків (С.В.Фабер), реєстрації та ліцензування банків (О.І.Пархоменко) і начальників територіальних управлінь Національного банку України.

Голова В.С.Стельмах
