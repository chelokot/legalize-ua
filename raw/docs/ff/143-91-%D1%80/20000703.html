Кабінет Міністрів УРСР; Розпорядження від 31.07.1991 № 143-р

Про створення лікувально-оздоровчого об'єднання при Кабінеті Міністрів УРСР

Стан: Втратив чинність

Ідентифікатор: 143-91-р

Текст документа від 03.07.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНСЬКОЇ РСР

РОЗПОРЯДЖЕННЯ від 31 липня 1991 р. N 143-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1054 ( 1054-2000-п ) від 03.07.2000 )

1. Створити на базі об'єднання, організованого розпорядженням Ради Міністрів УРСР від 3 січня 1990 р. N 8 ( 8-90-р ), лікувально-оздоровче об'єднання при Кабінеті Міністрів УРСР у складі лікувально-профілактичних і оздоровчих закладів згідно з додатком.

2. Установити, що об'єднання фінансується за рахунок пайової участі міністерств, відомств УРСР, Ради Міністрів Кримської АРСР, облвиконкомів, Київського і Севастопольського міськвиконкомів, інших організацій, працівники яких ним обслуговуватимуться, а також бюджетних коштів.

3. Не для друку

4. Начальникові Лікувально-оздоровчого об'єднання при Кабінеті Міністрів УРСР подати в місячний строк Уряду УРСР проект Положення про об'єднання, а також погоджені з Мінфіном УРСР пропозиції про чисельність працівників об'єднання і витрати на їх утримання.

Прем'єр-міністр УРСР В.ФОКІН
