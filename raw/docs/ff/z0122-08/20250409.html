Про затвердження посадових окладів осіб офіцерського складу Державної спеціальної служби транспорту

{ Із змінами, внесеними згідно з Наказами Міністерства транспорту та зв'язку N 466 ( z0436-09 ) від 28.04.2009 N 1339 ( z0052-10 ) від 24.12.2009 }

Відповідно до постанови Кабінету Міністрів України від 7 листопада 2007 року N 1294 ( 1294-2007-п ) "Про упорядкування структури та умов грошового забезпечення військовослужбовців, осіб рядового і начальницького складу" НАКАЗУЮ:

1. Затвердити з 1 січня 2008 року:

посадові оклади осіб офіцерського складу Адміністрації Державної спеціальної служби транспорту за основними типовими посадами в розмірах згідно з додатком 1;

посадові оклади осіб офіцерського складу управління об'єднаного загону Державної спеціальної служби транспорту за основними типовими посадами в розмірах згідно з додатком 2;

посадові оклади осіб офіцерського складу окремих загонів Державної спеціальної служби транспорту за основними типовими посадами в розмірах згідно з додатком 3;

посадові оклади осіб офіцерського складу понтонно-мостового загону Державної спеціальної служби транспорту за основними типовими посадами в розмірах згідно з додатком 4;

посадові оклади осіб офіцерського складу центральної бази Державної спеціальної служби транспорту за основними типовими посадами в розмірах згідно з додатком 5;

посадові оклади осіб офіцерського складу кафедри військової підготовки спеціалістів Державної спеціальної служби транспорту Дніпропетровського національного університету залізничного транспорту імені академіка В.Лазаряна за основними типовими посадами в розмірах згідно з додатком 6; { Абзац сьомий пункту 1 із змінами, внесеними згідно з Наказом Міністерства транспорту та зв'язку N 1339 ( z0052-10 ) від 24.12.2009 }

посадові оклади осіб офіцерського складу навчального центру Державної спеціальної служби транспорту за основними типовими посадами в розмірах згідно з додатком 7.

2. Адміністрації Держспецтрансслужби (Мальков М.І.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Визнати таким, що втратив чинність, наказ Міністерства транспорту та зв'язку України від 29 червня 2005 року N 341 ( z0743-05 ) "Про встановлення щомісячної додаткової грошової винагороди окремим категоріям військовослужбовців Держспецтрансслужби", зареєстрований у Міністерстві юстиції України 12 липня 2005 року за N 743/11023.

4. Контроль за виконанням наказу покласти на першого заступника Міністра Шевченка В.В.
