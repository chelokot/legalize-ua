Про призначення Уповноваженого Уряду України в Українсько-Словацькій комісії по прикордонних водах і його заступників

Текст документа від 05.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 серпня 1994 р. N 569 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1347 ( 1347-2011-п ) від 28.12.2011 }

Про призначення Уповноваженого Уряду України в Українсько-Словацькій комісії по прикордонних водах і його заступників

{ Із змінами, внесеними згідно з Постановами КМ N 599 ( 599-2003-п ) від 26.04.2003 N 512 ( 512-2008-п ) від 04.06.2008 N 555 ( 555-2010-п ) від 07.07.2010 }

Кабінет Міністрів України постановляє:

Призначити:

заступника Голови Державного комітету по водному господарству Яцюка Михайла Васильовича Уповноваженим Уряду України в Українсько-Словацькій комісії по прикордонних водах; { Абзац другий із змінами, внесеними згідно з Постановами КМ N 599 ( 599-2003-п ) від 26.04.2003, N 512 ( 512-2008-п ) від 04.06.2008, N 555 ( 555-2010-п ) від 07.07.2010 }

начальника відділу міжнародного співробітництва Державного комітету України по водному господарству Касьянчука Валерія Павловича і головного інженера Закарпатського облводгоспу цього Комітету Чіпака Володимира Петровича заступниками Уповноваженого Уряду України у зазначеній Комісії.

{ Абзац третій із змінами, внесеними згідно з Постановою N 512 ( 512-2008-п ) від 04.06.2008 }
