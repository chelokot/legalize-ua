КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 серпня 1994 р. N 569 Київ

Про призначення Уповноваженого Уряду України в Українсько-Словацькій комісії по прикордонних водах і його заступників

( Із змінами, внесеними згідно з Постановою КМ N 599 ( 599-2003-п ) від 26.04.2003 )

Кабінет Міністрів України постановляє:

Призначити:

першого заступника Голови Державного комітету по водному господарству Гадзала Ярослава Михайловича Уповноваженим Уряду України в Українсько-Словацькій комісії по прикордонних водах; ( Абзац другий із змінами, внесеними згідно з Постановою КМ N 599 ( 599-2003-п ) від 26.04.2003 )

начальника управління науково-технічного прогресу Державного комітету України по водному господарству Лелявського Віталія Володимировича і головного інженера Закарпатського облводгоспу цього Комітету Чіпака Володимира Петровича заступниками Уповноваженого Уряду України у зазначеній Комісії.
