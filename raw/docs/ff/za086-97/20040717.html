ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 37 від 24.02.97 Зареєстровано в Міністерстві м.Київ юстиції України 24 березня 1997 р. vd970224 vn37 за N 86/1890

( Постанова втратила чинність на підставі Постанови Національного банку N 268 ( z0840-04 ) від 17.06.2004 )

Про впровадження пластикових карток міжнародних платіжних систем у розрахунках за товари, надані послуги та при видачі готівки

З метою подальшого впровадження нових форм розрахунків у безготівковій формі за продаж товарів, надання послуг та при видачі готівки у вільно конвертованій валюті Правління ПОСТАНОВЛЯЄ:

1. Затвердити Положення про впровадження пластикових карток міжнародних платіжних систем у розрахунках за товари, надані послуги та при видачі готівки ( z0086-97 ).

2. Департаменту бухгалтерського обліку (П.М.Сенищ) в "Плані рахунків бухгалтерського обліку банків України" ( v0332500-95 ) передбачити рахунки для обліку операцій за пластиковими картками міжнародних платіжних систем.

3. Контроль за виконанням цієї постанови покласти на першого заступника Голови Правління В.О.Бондаря та департамент валютного регулювання (С.О.Яременко).

В.о. Голови В.О.Бондар
