КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 травня 2008 р. N 713-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про участь України у Міжнародній виставці "Експо - 2012"

{ Із змінами, внесеними згідно з Постановами КМ N 1041 ( 1041-2011-п ) від 12.10.2011 N 230 ( 230-2012-п ) від 12.03.2012 }

{ У тексті розпорядження слово "Мінекономіки" замінено словами "Міністерство економічного розвитку і торгівлі" у відповідному відмінку згідно з Постановою КМ N 1041 ( 1041-2011-п ) від 12.10.2011 }

1. Підтримати пропозицію Міністерства економічного розвитку і торгівлі щодо участі України у Міжнародній виставці "Експо - 2012" (далі - Виставка), яка відбудеться у період з травня по серпень 2012 р. у м. Йосу (Республіка Корея).

2. Утворити Координаційний комітет з підготовки та забезпечення участі України у Виставці (далі - Координаційний комітет).

Очолює Координаційний комітет Міністр економічного розвитку і торгівлі, який є генеральним комісаром України на Виставці (далі - генеральний комісар). { Абзац другий пункту 2 із змінами, внесеними згідно з Постановами КМ N 1041 ( 1041-2011-п ) від 12.10.2011, N 230 ( 230-2012-п ) від 12.03.2012 }

Генеральний комісар має трьох заступників.

До складу Координаційного комітету входять заступники Міністра економічного розвитку і торгівлі, Міністра культури, Міністра фінансів, Міністра закордонних справ, Міністра інфраструктури, Міністра аграрної політики та продовольства, Міністра енергетики та вугільної промисловості, Голови Державного агентства з управління державними корпоративними правами та майном, Голови Державного космічного агентства, представник Секретаріату Кабінету Міністрів України, перший віце-президент - головний учений секретар Національної академії наук, начальник відділу Мінекономіки, а також можуть входити представники інших заінтересованих органів виконавчої влади, підприємств, установ та організацій. { Абзац четвертий пункту 2 із змінами, внесеними згідно з Постановою КМ N 1041 ( 1041-2011-п ) від 12.10.2011 }

3. Визначити Міністерство економічного розвитку і торгівлі головним органом, відповідальним за підготовку та забезпечення участі України у Виставці.

4. Міністерству економічного розвитку і торгівлі:

вжити заходів до визначення в установленому законодавством порядку розпорядника експозиції України на Виставці;

розробити концепцію та тематико-експозиційний план експозиції України з урахуванням пропозицій центральних органів виконавчої влади, Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських держадміністрацій щодо представлення на Виставці експонатів та інформаційно-рекламних матеріалів.

5. Генеральному комісарові:

затвердити персональний склад Координаційного комітету, концепцію та тематико-експозиційний план експозиції України на Виставці;

подати Організаційному комітетові Міжнародної виставки "Експо - 2012" заявку на виділення виставкової площі для експозиції України та підписати з ним Угоду про участь України у Виставці.

6. Міністерству культури разом з Міністерством економічного розвитку і торгівлі розробити програму проведення на Виставці культурних заходів, зокрема Дня України.

{ Пункт 6 із змінами, внесеними згідно з Постановою КМ N 1041 ( 1041-2011-п ) від 12.10.2011 }

7. Міністерству економічного розвитку і торгівлі, іншим центральним органам виконавчої влади під час формування проекту Державного бюджету України на відповідний рік передбачати кошти для забезпечення підготовки та участі України у Виставці.
