Текст документа від 09.09.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання таким, що втратив чинність, Указу Президента України від 10 червня 2008 року N 534

1. Визнати таким, що втратив чинність, Указ Президента України від 10 червня 2008 року N 534 ( 534/2008 ) "Про зупинення дії розпоряджень Кабінету Міністрів України від 28 травня 2008 року N 744-р, N 745-р, N 746-р, N 747-р, N 756-р, N 757-р, N 758-р, N 759-р, N 760-р, N 761-р, N 762-р і N 763-р".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
