Про затвердження Порядку митного оформлення несупроводжуваного багажу, що переміщується через митний кордон України

( Із змінами, внесеними згідно з Наказом Держмитслужби N 763 ( z1020-01 ) від 22.11.2001 )

( У тексті Порядку слова "пасажирська митна декларація" у всіх відмінках замінено словами "митна декларація" у відповідному відмінку згідно з Наказом Держмитслужби N 763 ( z1020-01 ) від 22.11.2001 )

З метою встановлення єдиного порядку митного оформлення несупроводжуваного багажу, що переміщується через митний кордон України, НАКАЗУЮ:

1. Затвердити Порядок митного оформлення несупроводжуваного багажу, що переміщується через митний кордон України (далі - Порядок), який додається.

2. Управлінню організації митного контролю (Більчук О.С.) та Правовому управлінню (Будаков А.Ю.) забезпечити подання наказу на реєстрацію до Міністерства юстиції України.

3. Управлінню справами (Максимов Ю.Ю.) після державної реєстрації в Міністерстві юстиції України забезпечити тиражування та розсилку наказу в митні органи.

4. Начальникам митниць інформувати громадян про затверджений Порядок, зокрема шляхом його висвітлення в місцевих засобах масової інформації та на наочних інформаційних стендах у місцях розташування відповідних підрозділів митниці.

5. Прес-центру Держмитслужби (Старостін А.А.) забезпечити висвітлення цього Порядку в засобах масової інформації.

6. Вважати такими, що втратили чинність, підпункти 1.2.11, 1.4.3 Тимчасових правил митного контролю за переміщенням через митний кордон України предметів, валюти і цінностей громадян, затверджених наказом Державного митного комітету України від 31.12.91 N 9 ( v0009234-91 ) (зі змінами та доповненнями).

7. Контроль за виконанням цього наказу покласти на начальника Управління організації митного контролю Більчука О.С.

Порядок митного оформлення несупроводжуваного багажу, що переміщується через митний кордон України

1. Загальні положення

Цей Порядок регламентує митне оформлення несупроводжуваного багажу, який належить громадянам України, іноземцям та особам без громадянства.

До несупроводжуваного багажу (далі - НСБ) відносяться предмети, що відправляються їх власником (або за його дорученням іншою фізичною чи юридичною особою) і перетинають митний кордон України окремо від власника.

2. Порядок митного оформлення при ввезенні НСБ в Україну

2.1. Факт відправлення НСБ із-за кордону зазначається в митній декларації, яка заповнюється власником в 1 примірнику на прикордонній митниці при в'їзді в Україну.

Митна декларація, засвідчена відтиском особистої номерної печатки посадової особи митного органу, залишається у власника НСБ.

( Пункт 2.1 в редакції Наказу Держмитслужби N 763 ( z1020-01 ) від 22.11.2001 )

2.2. При отриманні НСБ власник подає митниці митну декларацію, у якій заявлено про НСБ, предмети, валюту та цінності, пропущені при в'їзді в Україну.

2.3. У разі отримання НСБ особою, яка діє за дорученням власника, ця особа подає митниці митну декларацію власника НСБ та відповідне нотаріально засвідчене доручення.

2.4. Предмети та цінності, що містяться в НСБ, декларуються на окремому бланку митної декларації. ( Пункт 2.4 в редакції Наказу Держмитслужби N 763 ( z1020-01 ) від 22.11.2001 )

3. Порядок митного оформлення при вивезенні НСБ за межі України

3.1. Митне оформлення НСБ здійснюється в митниці за місцезнаходженням його власника (за місцем постійного проживання). ( Пункт 3.1 із змінами, внесеними згідно з Наказом Держмитслужби N 763 ( z1020-01 ) від 22.11.2001 )

3.2. При відправленні НСБ за межі України його власник або інша особа, яка діє за нотаріально засвідченим дорученням власника цього багажу, заповнює митну декларацію у 2 примірниках, у кожному з яких зазначає відомості про вміст НСБ. ( Пункт 3.2 в редакції Наказу Держмитслужби N 763 ( z1020-01 ) від 22.11.2001 )

3.3. Після оформлення НСБ перший примірник митної декларації залишається в справах митного органу, другий - додається до товаросупровідних документів на НСБ. ( Пункт 3.3 в редакції Наказу Держмитслужби N 763 ( z1020-01 ) від 22.11.2001 )
