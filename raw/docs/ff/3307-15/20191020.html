Про внесення зміни до статті 1 Закону України "Про перелік об'єктів права державної власності, що не підлягають приватизації"

Стан: Втратив чинність

Ідентифікатор: 3307-15

Текст документа від 20.10.2019:

ЗАКОН УКРАЇНИ

{ Закон втратив чинність на підставі Закону N 145-IX ( 145-20 ) від 02.10.2019, ВВР, 2019, N 46, ст.302 }

Про внесення зміни до статті 1 Закону України "Про перелік об'єктів права державної власності, що не підлягають приватизації"

( Відомості Верховної Ради України (ВВР), 2006, N 16, ст.142 )

Верховна Рада України постановляє:

1. Статтю 1 Закону України "Про перелік об'єктів права державної власності, що не підлягають приватизації" ( 847-14 ) (Відомості Верховної Ради України, 1999 р., N 37, ст. 332; 2001 р., N 48, ст. 255) доповнити новою частиною такого змісту:

"Заборонити на 2006 рік приватизацію пакета акцій, що належить державі у статутному фонді ВАТ "Турбоатом".

2. Цей Закон набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 11 січня 2006 року N 3307-IV
