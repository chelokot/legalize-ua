Головдержслужба України; Наказ від 23.02.2004 № 35

Про внесення змін до наказу Головдержслужби від 18.05.2000 N 25 "Про затвердження Положення про порядок проведення Головдержслужбою перевірок"

Реєстрація: Мін'юст України від 11.03.2004 № 311/8910

Стан: Втратив чинність

Ідентифікатор: z0311-04

Текст документа від 23.02.2004:

ГОЛОВНЕ УПРАВЛІННЯ ДЕРЖАВНОЇ СЛУЖБИ УКРАЇНИ

НАКАЗ

23.02.2004 N 35

Зареєстровано в Міністерстві юстиції України 11 березня 2004 р. за N 311/8910

Про внесення змін до наказу Головдержслужби від 18.05.2000 N 25 "Про затвердження Положення про порядок проведення Головдержслужбою перевірок"

Відповідно до Закону України "Про службу в органах місцевого самоврядування" ( 2493-14 ), НАКАЗУЮ:

1. Внести до наказу Головдержслужби від 18.05.2000 N 25 ( z0318-00 ) та до Положення про порядок проведення Головдержслужбою перевірок, затвердженого наказом Головдержслужби України від 18.05.2000 N 25, зареєстрованих Міністерством юстиції України 29.05.2000 за N 318/4539, зміни, що додаються.

2. Контрольно-інспекційному управлінню Головдержслужби забезпечити в установленому порядку реєстрацію цього наказу у Міністерстві юстиції України.

3. Інформаційно-аналітичному управлінню Головдержслужби після реєстрації в Міністерстві юстиції України наказу Головдержслужби забезпечити опублікування змін до Положення у "Віснику державної служби України" та розміщення на Web-сторінці Головдержслужби.

4. Контроль за виконанням цього наказу покладаю на заступників Начальника Головдержслужби за розподілом обов'язків.

Начальник Головдержслужби Т.Мотренко

ЗАТВЕРДЖЕНО Наказ Головдержслужби 23.02.2004 N 35

Зареєстровано в Міністерстві юстиції України 11 березня 2004 р. за N 311/8910

ЗМІНИ до наказу Головдержслужби від 18.05.2000 N 25 ( z0318-00 ) та до Положення про порядок проведення Головдержслужбою перевірок, затвердженого наказом Головдержслужби України від 18.05.2000 N 25, зареєстрованих Міністерством юстиції України 29.05.2000 за N 318/4539

1. В преамбулі наказу Головдержслужби від 29.05.2000 N 25 ( z0318-00 ) та пункті 1.1 Положення слова "та органах місцевого самоврядування" вилучити.

2. З абзацу другого пункту 2.1 Положення ( z0318-00 ) вилучити слова "та органів місцевого самоврядування", "та службу в органах місцевого самоврядування".

3. Пункт 2.2 Положення ( z0318-00 ) викласти у такій редакції:

"2.2. Об'єктами перевірок є органи державної влади".

4. З підпункту 2.4.1 та абзацу десятого підпункту 4.3.3 Положення ( z0318-00 ) вилучити слова "органів місцевого самоврядування".

5. Вилучити з абзацу другого пункту 3.1, абзацу другого пункту 3.2 Положення ( z0318-00 ) слова "та органами місцевого самоврядування".

6. З абзацу другого пункту 3.1 вилучити слова "та участь у місцевому самоврядуванні".

7. З абзацу третього пункту 3.1, абзаців другого та третього пункту 3.2 та пункту 5.2 Положення ( z0318-00 ) вилучити слова "та місцевого самоврядування".

Начальник контрольно-інспекційного управління С.Курман
