Про внесення змін до Положення про Державний центр соціальних служб для молоді

Реєстрація: Мін'юст України від 19.09.2002 № 769/7057

Стан: Втратив чинність

Ідентифікатор: z0769-02

Текст документа від 07.03.2005:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ У СПРАВАХ СІМ'Ї ТА МОЛОДІ

НАКАЗ

N 606 від 05.09.2002 Зареєстровано в Міністерстві м. Київ юстиції України 19 вересня 2002 р. за N 769/7057

( Наказ втратив чинність на підставі Наказу Міністерства у справах сім'ї, дітей та молоді N 72 ( z0266-05 ) від 18.02.2005 )

Про внесення змін до Положення про Державний центр соціальних служб для молоді

З метою приведення статутних документів Державного центру соціальних служб для молоді у відповідність до Закону України "Про оподаткування прибутку підприємств" ( 334/94-ВР ) НАКАЗУЮ:

1. Унести зміни до Положення про Державний центр соціальних служб для молоді, затвердженого наказом Державного комітету України у справах сім'ї та молоді від 04.02.2002 N 10 ( z0185-02 ) і зареєстрованого в Міністерстві юстиції України 26.02.2002 за N 185/6473, а саме:

підпункти 10, 11 пункту 7 виключити;

пункт 12 виключити;

у пункті 17 слова "а також коштів від надання Центром платних послуг" виключити;

доповнити пункт 22 реченням такого змісту: "У разі ліквідації Центру його активи передаються Держкомсім'їмолоді або зараховуються до доходу бюджету";

пункти 13-22 вважати пунктами 12-21.

2. Контроль за виконанням цього наказу залишаю за собою.

Голова Комітету В.І.Довженко
