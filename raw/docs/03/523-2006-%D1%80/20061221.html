Про підписання Угоди між Кабінетом Міністрів України та Урядом Російської Федерації про реадмісію

Стан: Чинний

Ідентифікатор: 523-2006-р

Текст документа від 21.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 жовтня 2006 р. N 523-р Київ

Про підписання Угоди між Кабінетом Міністрів України та Урядом Російської Федерації про реадмісію

{ Із змінами, внесеними згідно з Розпорядженням КМ N 628-р ( 628-2006-р ) від 21.12.2006 }

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Російської Федерації про реадмісію.

Уповноважити Міністра внутрішніх справ Цушка Василя Петровича підписати зазначену Угоду, дозволивши йому вносити в разі потреби до проекту Угоди зміни, що не мають принципового характеру. { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 628-р ( 628-2006-р ) від 21.12.2006 }
