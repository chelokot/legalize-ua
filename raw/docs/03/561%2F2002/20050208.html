Президент України; Указ від 19.06.2002 № 561/2002

Питання Координаційного комітету по боротьбі з корупцією і організованою злочинністю

Стан: Втратив чинність

Ідентифікатор: 561/2002

Текст документа від 08.02.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 208/2005 ( 208/2005 ) від 08.02.2005 )

Питання Координаційного комітету по боротьбі з корупцією і організованою злочинністю

( Із змінами, внесеними згідно з Указами Президента N 402/2003 ( 402/2003 ) від 13.05.2003 N 362/2004 ( 362/2004 ) від 24.03.2004 )

( Стаття 1 втратила чинність на підставі Указу Президента N 402/2003 ( 402/2003 ) від 13.05.2003 )

2. Утворити для підготовки матеріалів до засідань Координаційного комітету по боротьбі з корупцією і організованою злочинністю та здійснення контролю за реалізацією прийнятих рішень апарат організаційного забезпечення діяльності Координаційного комітету в кількості 16 осіб. ( Частина перша статті 2 із змінами, внесеними згідно з Указом Президента N 362/2004 ( 362/2004 ) від 24.03.2004 )

Установити, що оплата праці, матеріально-побутове забезпечення і медичне обслуговування працівників апарату організаційного забезпечення діяльності Координаційного комітету здійснюються виходячи з умов, установлених для працівників відповідних категорій апарату Ради національної безпеки і оборони України. ( Статтю 2 доповнено частиною другою згідно з Указом Президента N 362/2004 ( 362/2004 ) від 24.03.2004 )

Установити, що структуру і Положення про зазначений апарат затверджує Глава Адміністрації Президента України.

Фінансове забезпечення діяльності Координаційного комітету здійснюється Державним управлінням справами. ( Частина четверта статті 2 в редакції Указу Президента N 362/2004 ( 362/2004 ) від 24.03.2004 )

3. Голові Координаційного комітету вжити невідкладних заходів щодо підвищення рівня роботи Комітету.

Президент України Л.КУЧМА
