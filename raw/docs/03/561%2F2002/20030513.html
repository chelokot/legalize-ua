Президент України; Указ від 19.06.2002 № 561/2002

Питання Координаційного комітету по боротьбі з корупцією і організованою злочинністю

Стан: Втратив чинність

Ідентифікатор: 561/2002

Текст документа від 13.05.2003:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Координаційного комітету по боротьбі з корупцією і організованою злочинністю

( Із змінами, внесеними згідно з Указом Президента N 402/2003 ( 402/2003 ) від 13.05.2003 )

( Стаття 1 втратила чинність на підставі Указу Президента N 402/2003 ( 402/2003 ) від 13.05.2003 )

2. Утворити для підготовки матеріалів до засідань Координаційного комітету по боротьбі з корупцією і організованою злочинністю та здійснення контролю за реалізацією прийнятих рішень апарат організаційного забезпечення діяльності Координаційного комітету в кількості 9 осіб.

Установити, що структуру і Положення про зазначений апарат затверджує Глава Адміністрації Президента України.

Матеріально-технічне та інше забезпечення діяльності апарату здійснюється Адміністрацією Президента України.

3. Голові Координаційного комітету вжити невідкладних заходів щодо підвищення рівня роботи Комітету.

Президент України Л.КУЧМА

м. Київ, 19 червня 2002 року N 561/2002
