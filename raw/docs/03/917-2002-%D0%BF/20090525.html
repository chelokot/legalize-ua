КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 липня 2002 р. N 917 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Про внесення зміни до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

Кабінет Міністрів України постановляє:

У додатку 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851, N 33, ст. 1526) у позиції "Міністерство закордонних справ" цифри "768" замінити цифрами "790".

Збільшення чисельності працівників провести у межах асигнувань, передбачених у Державному бюджеті України на 2002 рік ( 2905-14 ) для утримання Міністерства закордонних справ.
