Про внесення змін до наказу МВС України від 04.05.2011 N 177 "Про організацію діяльності стаціонарних постів дорожньо-патрульної служби Державної автомобільної інспекції МВС"

Відповідно до Законів України "Про міліцію" ( 565-12 ), "Про дорожній рух" ( 3353-12 ), постанови Кабінету Міністрів України від 10.10.2001 N 1306 ( 1306-2001-п ) "Про Правила дорожнього руху" та з метою вдосконалення організації несення служби нарядами дорожньо-патрульної служби Державтоінспекції МВС, активізації боротьби зі злочинністю на автотранспорті, а також надання допомоги учасникам дорожнього руху НАКАЗУЮ:

1. Внести до наказу МВС України від 04.05.2011 N 177 ( z0626-11 ) "Про організацію діяльності стаціонарних постів дорожньо-патрульної служби Державної автомобільної інспекції МВС", зареєстрованого в Міністерстві юстиції України 24.05.2011 за N 626/19364 (із змінами) такі зміни:

1.1. Дислокацію стаціонарних постів дорожньо-патрульної служби Державної автомобільної інспекції Міністерства внутрішніх справ України, затверджену наказом МВС України від 04.05.2011 N 177 ( z0626-11 ), зареєстрованим у Міністерстві юстиції України 24.05.2011 за N 626/19364, викласти в новій редакції, що додається.

1.2. У підпункті 3.4 додатка 1 до Положення про стаціонарні пости дорожньо-патрульної служби Державної автомобільної інспекції Міністерства внутрішніх справ України, затвердженого наказом МВС України від 04.05.2011 N 177 ( z0626-11 ), зареєстрованого в Міністерстві юстиції України 24.05.2011 за N 626/19364, слово "мобільний" виключити.

2. Управлінню Державтоінспекції МВС (Лозовий В.М.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України у визначений законодавством строк.

3. Контроль за виконанням цього наказу покласти на першого заступника Міністра генерал-лейтенанта міліції Попкова С.Є.

4. Цей наказ надіслати за належністю.

5. Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр генерал-лейтенант міліції А.В.Могильов
