РІШЕННЯ

14.10.2008 N 1162

Зареєстровано в Міністерстві юстиції України 31 жовтня 2008 р. за N 1062/15753

Про внесення зміни до Граничних тарифів на загальнодоступні телекомунікаційні послуги

{ Рішення фактично втратило чинність у зв'язку з втратою чинності Рішення Національної комісії з питань регулювання зв'язку N 1110 ( z0872-08 ) від 12.09.2008, до якого вносились зміни }

Відповідно до статей 18 та 66 Закону України "Про телекомунікації" ( 1280-15 ) Національна комісія з питань регулювання зв'язку України ВИРІШИЛА:

1. Внести таку зміну до пункту 3 примітки до статті 5 розділу II Граничних тарифів на загальнодоступні телекомунікаційні послуги, затверджених рішенням НКРЗ від 12.09.2008 N 1110 ( z0872-08 ), зареєстрованих у Міністерстві юстиції України 18.09.2008 за N 872/15563: цифри "0,6" замінити на цифри "0,5".

2. Управлінню організаційно-аналітичного забезпечення діяльності розмістити рішення на веб-сайті НКРЗ.

3. Економічному управлінню та Юридичному управлінню в установленому законодавством порядку подати це рішення на державну реєстрацію до Міністерства юстиції України.
