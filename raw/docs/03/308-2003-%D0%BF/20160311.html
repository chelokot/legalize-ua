Кабінет Міністрів України; Постанова від 12.03.2003 № 308

Про повноважного представника від України в Міждержавній координаційній раді з науково-технічної інформації

Стан: Втратив чинність

Ідентифікатор: 308-2003-п

Текст документа від 11.03.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 березня 2003 р. N 308 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 121 ( 121-2016-п ) від 24.02.2016 }

Про повноважного представника від України в Міждержавній координаційній раді з науково-технічної інформації

{ Із змінами, внесеними згідно з Постановою КМ N 754 ( 754-2012-п ) від 15.08.2012 }

Кабінет Міністрів України постановляє:

Призначити повноважним представником від України в Міждержавній координаційній раді з науково-технічної інформації Гриньова Бориса Вікторовича - першого заступника Голови Державного агентства з питань науки, інновацій та інформатизації, увільнивши від цих обов’язків Пархоменка Володимира Дмитровича.

{ Постанова із змінами, внесеними згідно з Постановою КМ N 754 ( 754-2012-п ) від 15.08.2012 }
