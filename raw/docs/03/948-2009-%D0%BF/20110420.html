Кабінет Міністрів України; Постанова від 08.07.2009 № 948

Про часткове зупинення дії постанови Кабінету Міністрів України від 5 березня 2009 р. N 227

Стан: Втратив чинність

Ідентифікатор: 948-2009-п

Текст документа від 20.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 липня 2009 р. N 948 Київ

Про часткове зупинення дії постанови Кабінету Міністрів України від 5 березня 2009 р. N 227

{ Із змінами, внесеними згідно з Постановами КМ N 1426 ( 1426-2009-п ) від 23.12.2009 N 1162 ( 1162-2010-п ) від 22.12.2010 }

{ Постанова втратила чинність одночасно з набранням чинності Указом Президента ( 447/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011, крім зупинення на період до 1 січня 2012 р. пунктів 3 і 4 Постанови КМ N 227 ( 227-2009-п ) від 05.03.2009 та затверджених зазначеною постановою пункту 1 змін, що вносяться до Постанов КМ N 204 ( 204-97-п ) від 04.03.97 і N 403 ( 403-2000-п ) від 26.02.2000, і пункту 1 переліку Постанов КМ, що втратили чинність }

Кабінет Міністрів України постановляє:

Зупинити на період до 1 січня 2012 р. з урахуванням того, що в державному бюджеті будуть визначені видатки, пов'язані із забезпеченням діяльності додаткової чисельності працівників Міністерства транспорту та зв'язку, встановленої постановою Кабінету Міністрів України від 13 травня 2009 р. N 464 ( 464-2009-п ) "Про затвердження граничної чисельності працівників апарату центральних органів виконавчої влади і підпорядкованих їм територіальних органів та інших державних органів" (Офіційний вісник України, 2009 р., N 36, ст. 1226), дію пунктів 3 і 4 постанови Кабінету Міністрів України від 5 березня 2009 р. N 227 ( 227-2009-п ) "Питання Державної адміністрації морського і річкового транспорту" (Офіційний вісник України, 2009 р., N 20, ст. 647, N 36, ст. 1226) та затверджених зазначеною постановою ( 227-2009-п ): { Абзац перший постановляючої частини із змінами, внесеними згідно з Постановами КМ N 1426 ( 1426-2009-п ) від 23.12.2009, N 1162 ( 1162-2010-п ) від 22.12.2010 }

Положення про Державну адміністрацію морського і річкового транспорту ( 227-2009-п ) в частині виконання завдань і функцій, що покладались на Головну державну інспекцію з безпеки судноплавства;

пункту 1 змін ( 227-2009-п ), що вносяться до постанов Кабінету Міністрів України від 4 березня 1997 р. N 204 ( 204-97-п ) і від 26 лютого 2000 р. N 403 ( 403-2000-п );

пункту 1 ( 227-2009-п ) переліку постанов Кабінету Міністрів України, що втратили чинність.

У зв'язку з цим відновити дію пункту 2 Порядку здійснення нагляду за забезпеченням безпеки руху на транспорті, затвердженого постановою Кабінету Міністрів України від 4 березня 1997 р. N 204 ( 204-97-п ) (Офіційний вісник України, 1997 р., число 11, с. 85), пункту 1 постанови Кабінету Міністрів України від 30 грудня 1998 р. N 2098 ( 2098-98-п ) "Питання безпеки судноплавства" (Офіційний вісник України, 1998 р., N 52, ст. 1953) та Положення про Головну державну інспекцію України з безпеки судноплавства, затвердженого зазначеною постановою, у редакції, що діяла на день набрання чинності постановою Кабінету Міністрів України від 5 березня 2009 р. N 227 ( 227-2009-п ) "Питання Державної адміністрації морського і річкового транспорту".
