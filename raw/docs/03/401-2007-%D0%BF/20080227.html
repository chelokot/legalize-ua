Кабінет Міністрів України; Постанова, Порядок від 07.03.2007 № 401

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф

Стан: Чинний

Ідентифікатор: 401-2007-п

Текст документа від 27.02.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 березня 2007 р. N 401 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф

{ Із змінами, внесеними згідно з Постановою КМ N 105 ( 105-2008-п ) від 27.02.2008 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф, здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 105 ( 105-2008-п ) від 27.02.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 березня 2007 р. N 401

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) МОЗ для виконання плану заходів щодо поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф, на 2007-2009 роки, затвердженого розпорядженням Кабінету Міністрів України від 29 листопада 2006 р. N 587 ( 587-2006-р ), у складі програми "Забезпечення медичних заходів окремих державних програм та комплексних заходів програмного характеру, в тому числі на умовах фінансового лізингу" (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 105 ( 105-2008-п ) від 27.02.2008 }

2. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється МОЗ або визначеними ним розпорядниками бюджетних коштів нижчого рівня чи їх одержувачами відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

3. Направлення дітей за медичними показаннями для лікування та оздоровлення у Республіці Куба, а також матеріально-технічне і побутове забезпечення кубинських фахівців та оплата праці на договірній основі у період їх перебування в Україні здійснюються МОЗ у встановленому ним порядку.

Відбір кандидатур на посади працівників української адміністрації, педагогів та вихователів для роботи в Республіці Куба з укладенням трудового договору проводиться у порядку, затвердженому МОЗ у місячний строк після набрання чинності цим Порядком.

{ Пункт 4 виключено на підставі Постанови КМ N 105 ( 105-2008-п ) від 27.02.2008 }

{ Пункт 5 виключено на підставі Постанови КМ N 105 ( 105-2008-п ) від 27.02.2008 }

6. Перерахування бюджетних коштів здійснюється відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 7 виключено на підставі Постанови КМ N 105 ( 105-2008-п ) від 27.02.2008 }

8. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
