ПОСТАНОВА від 15 травня 2001 р. N 493 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про внесення зміни до постанови Кабінету Міністрів України від 11 серпня 2000 р. N 1264

Кабінет Міністрів України постановляє:

На часткову зміну абзацу першого постанови Кабінету Міністрів України від 11 серпня 2000 р. N 1264 ( 1264-2000-п ) "Про утворення Центру інформаційних ресурсів у структурі Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2000 р., N 33, ст. 1411) установити, що Центр інформаційних ресурсів є структурним підрозділом Управління інформаційних ресурсів Департаменту внутрішньої політики Секретаріату Кабінету Міністрів України.

Перший віце-прем'єр-міністр України Ю.ЄХАНУРОВ
