Про внесення змін до наказу Міністерства праці та соціальної політики України від 04.04.2000 N 75

Відповідно до підпункту 13 пункту 4 Положення про Міністерство праці та соціальної політики України, затвердженого Указом Президента України від 30.08.2000 N 1035 ( 1035/2000 ), та у зв'язку з прийняттям постанов Кабінету Міністрів України від 07.02.2001 N 134 ( 134-2001-п ) "Про впорядкування умов оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" (із змінами), від 10.01.2002 N 18 ( 18-2002-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери", від 19.05.2003 N 740 ( 740-2003-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів і організацій окремих галузей бюджетної сфери", від 11.02.2004 N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

Унести до наказу Міністерства праці та соціальної політики України від 04.04.2000 N 75 ( z0220-00 ) "Про умови оплати праці працівників (невійськовослужбовців) льотного, інженерно-технічного складу авіації та авіаційних рятувальників Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи", зареєстрованого у Міністерстві юстиції України 11.04.2000 за N 220/4441, такі зміни:

1) підпункт 1 "б" та 1 "в" пункту 4 викласти у такій редакції:

"б) умови оплати праці окремих працівників, посади яких не передбачені цим наказом, визначити згідно з умовами оплати праці відповідних категорій працівників бюджетної сфери, затвердженими постановою Кабінету Міністрів України від 07.02.2001 N 134 ( 134-2001-п ), з урахуванням наступних підвищень;

в) працівникам (невійськовослужбовцям) льотного, інженерно-технічного складу авіації та авіаційним рятувальникам:

- доплати у розмірі до 50 відсотків посадового окладу відсутнього працівника або за вакантною посадою:

за виконання обов'язків тимчасово відсутніх працівників;

за суміщення професій (посад);

за розширення зони обслуговування або збільшення обсягу виконуваних робіт;

- надбавки у розмірі до 50 відсотків посадового окладу:

за високі досягнення у праці;

за виконання особливо важливої роботи (на термін її виконання);

за складність, напруженість у роботі.

Граничний розмір зазначених надбавок для одного працівника не повинен перевищувати 50 відсотків посадового окладу";

2) додатки 1-3 викласти в новій редакції (додаються).

Міністр М.Папієв
