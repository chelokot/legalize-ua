Про затвердження Порядку надання державної фінансової підтримки виданням літературно-художнього напрямку

{ Із змінами, внесеними згідно з Наказом Міністерства культури і туризму N 842 ( z1173-06 ) від 24.10.2006 }

На виконання Закону України "Про державну підтримку засобів масової інформації та соціальний захист журналістів" ( 540/97-ВР ) НАКАЗУЮ:

1. Затвердити Порядок надання державної фінансової підтримки виданням літературно-художнього напрямку (додається). { Пункт 1 із змінами, внесеними згідно з Наказом Міністерства культури і туризму N 842 ( z1173-06 ) від 24.10.2006 }

2. Управлінню з питань оплати праці та бюджетних програм (Солодченко Н.Ю.) протягом 5 днів з дня підписання наказу зареєструвати його в Міністерстві юстиції України.

3. Контроль за виконанням наказу покласти на першого заступника Міністра В.В.Корнієнка.

Міністр І.Д.Ліховий

ЗАТВЕРДЖЕНО Наказ Міністерства культури і туризму України 12.12.2005 N 1023

Зареєстровано в Міністерстві юстиції України 10 січня 2006 р. за N 2/11876

ПОРЯДОК надання державної фінансової підтримки виданням літературно-художнього напрямку

{ Назва Порядку в редакції Наказу Міністерства культури і туризму N 842 ( z1173-06 ) від 24.10.2006 }

1. Загальні положення

1.1. Порядок надання державної фінансової підтримки виданням літературно-художнього напрямку (незалежно від форм власності) розроблено відповідно до статті 3 Закону України "Про державну підтримку засобів масової інформації та соціальний захист журналістів" ( 540/97-ВР ) (далі - Закон). { Пункт 1.1 із змінами, внесеними згідно з Наказом Міністерства культури і туризму N 842 ( z1173-06 ) від 24.10.2006 }

1.2. Фінансова підтримка є однією з форм державної підтримки виданням літературно-художнього напрямку. { Пункт 1.2 із змінами, внесеними згідно з Наказом Міністерства культури і туризму N 842 ( z1173-06 ) від 24.10.2006 }

1.3. Джерелом фінансової підтримки виданням літературно-художнього напрямку є асигнування, що передбачені Міністерству культури і туризму України в Державному бюджеті України на відповідний рік у розділі "Фінансова підтримка культурологічних видань та видань літературно-художнього напрямку". { Пункт 1.3 в редакції Наказу Міністерства культури і туризму N 842 ( z1173-06 ) від 24.10.2006 }

1.4. Державна фінансова підтримка не поширюється на періодичні видання літературно-художнього напрямку, що зазначені в частині третій статті 2 Закону ( 540/97-ВР ), а саме: видання рекламного та еротичного характеру; засновані за участю юридичних або фізичних осіб, до сфери діяльності яких входять виробництво та постачання паперу, поліграфічного обладнання, технічних засобів мовлення; засновані в Україні міжнародними організаціями або за участю юридичних чи фізичних осіб інших держав, осіб без громадянства; а також тих, у яких понад 50% загального обсягу випуску становлять матеріали зарубіжних засобів масової інформації.

1.5. Державна фінансова підтримка виданням літературно-художнього напрямку надається виключно на поліграфічні послуги та закупівлю паперу як найбільш витратні складові частини виробничого процесу. { Пункт 1.5 із змінами, внесеними згідно з Наказом Міністерства культури і туризму N 842 ( z1173-06 ) від 24.10.2006 }

1.6. Підставами для надання державної фінансової підтримки виданням літературно-художнього напрямку є їх економічний стан, підтверджений відповідними документами, перелік яких подається в пункті 2.1. { Пункт 1.6 із змінами, внесеними згідно з Наказом Міністерства культури і туризму N 842 ( z1173-06 ) від 24.10.2006 }

2. Розгляд питання про надання державної фінансової підтримки виданням літературно-художнього напрямку

2.1. Для одержання державної фінансової підтримки заявники - видання літературно-художнього напрямку подають до Міністерства культури і туризму України:

1) заяву, у якій наводяться аргументи на користь отримання такої підтримки, а також мету її використання і банківські реквізити заявника;

2) копію свідоцтва про державну реєстрацію видання;

3) інші документи, що підтверджують право на видання (угоду між співзасновниками, договір між видавцем (редакцією) і засновником тощо);

4) фінансово-економічні документи, які підтверджують підстави для надання підтримки (кошторис доходів і видатків за звітний рік, балансовий звіт про фінансові результати роботи в поточному році, підтвердження банків про наявність коштів на рахунку заявника на момент звернення).

{ Пункт 2.1 із змінами, внесеними згідно з Наказом Міністерства культури і туризму N 842 ( z1173-06 ) від 24.10.2006 }

2.2. Для розгляду заяви про надання фінансової підтримки в Міністерстві культури і туризму України утворюється робоча група, до якої входять представники відповідних функціональних підрозділів.

2.3. Робоча група здійснює попередній розгляд документів, поданих заявниками, і готує матеріали для колегії Міністерства культури і туризму України, яка приймає остаточне рішення про надання заявнику фінансової підтримки, що затверджується наказом.

2.4. Розмір державної фінансової підтримки визначається в межах коштів, виділених Міністерству культури і туризму України, згідно із Законом України про державний бюджет на відповідний рік та відповідно до наданих фінансово-економічних документів.

2.5. Виділені кошти перераховуються на рахунок заявника, щодо якого прийнято рішення про надання підтримки відповідно до чинного законодавства.

2.6. Отримані бюджетні кошти, їх використання відображаються в бухгалтерському обліку та фінансовій звітності у відповідності до чинного законодавства.

2.7. Звіт про використання виділених коштів одержувач підтримки подає Міністерству культури і туризму України відповідно до форм і термінів, визначених Державним казначейством України.

{ Розділ 2 із змінами, внесеними згідно з Наказом Міністерства культури і туризму N 842 ( z1173-06 ) від 24.10.2006 }

3. Прикінцеві положення

3.1. Відповідальність за нецільове використання бюджетних коштів несуть одержувачі коштів у встановленому законодавством України порядку.

3.2. Контроль за цільовим використанням бюджетних коштів здійснює Міністерство культури і туризму України.

Начальник управління з питань оплати праці та бюджетних програм Н.Ю.Солодченко
