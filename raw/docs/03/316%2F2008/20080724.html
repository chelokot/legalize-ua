Президент України; Указ від 11.04.2008 № 316/2008

Про зупинення дії постанови Кабінету Міністрів України від 19 березня 2008 року N 196, розпоряджень Кабінету Міністрів України від 22 лютого 2008 року N 367-р та від 19 березня 2008 року N 478-р

Стан: Чинний

Ідентифікатор: 316/2008

Текст документа від 24.07.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 637/2008 ( 637/2008 ) від 21.07.2008 }

Про зупинення дії постанови Кабінету Міністрів України від 19 березня 2008 року N 196, розпоряджень Кабінету Міністрів України від 22 лютого 2008 року N 367-р та від 19 березня 2008 року N 478-р

{ Додатково див. Конституційне подання Президента ( n0005100-08 ) від 11.04.2008 }

Кабінетом Міністрів України 19 березня 2008 року видано постанову N 196 ( 196-2008-п ) "Про передачу Фондові державного майна пакетів акцій відкритих акціонерних товариств", якою Міністерству палива та енергетики України доручено передати Фонду державного майна України пакети акцій відкритих акціонерних товариств "Дніпроенерго", "Донбасенерго", "Західенерго", "Державна енергогенеруюча компанія "Центренерго" та вжити заходів до виключення в установленому порядку зі статутного фонду Національної акціонерної компанії "Енергетична компанія України" зазначених пакетів акцій, а також розпорядження N 478-р ( 478-2008-р ) "Про внесення змін у додаток 1 до розпорядження Кабінету Міністрів України від 22 лютого 2008 р. N 367", за яким зазначені об'єкти включені до переліку господарських товариств і холдингових компаній, державні пакети акцій (частки) яких підлягають продажу в 2008 році.

При цьому Кабінетом Міністрів України залишено поза увагою, що названі акціонерні товариства належать до об'єктів, які відповідно до пункту "г" частини другої статті 5 Закону України "Про приватизацію державного майна" ( 2163-12 ) та Закону України "Про електроенергетику" ( 575/97-ВР ) забезпечують життєдіяльність держави в цілому і постановою Кабінету Міністрів України від 23 грудня 2004 року N 1734 ( 1734-2004-п ) "Про затвердження переліку підприємств, які мають стратегічне значення для економіки і безпеки держави" (з наступними змінами) визначені як такі, що мають стратегічне значення для економіки і безпеки держави.

Позбавлення Національної акціонерної компанії "Енергетична компанія України", метою діяльності якої є створення умов для надійного та ефективного функціонування і розвитку електроенергетичного комплексу, забезпечення економічної та енергетичної безпеки держави, зазначених активів призведе до недоотримання цією Компанією економічних вигод, погіршення її платоспроможності, унеможливить виконання взятих нею зобов'язань, зокрема, перед своїми кредиторами, що може мати наслідком порушення справи про її банкрутство, що в свою чергу стане загрозою економічній безпеці держави.

Відтак, зазначені постанова ( 196-2008-п ) і розпорядження ( 478-2008-р ) Кабінету Міністрів України не відповідають частині першій статті 17 Конституції України ( 254к/96-ВР ), за якою забезпечення економічної безпеки держави є однією з найважливіших функцій держави.

Ураховуючи викладене, та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію:

постанови Кабінету Міністрів України від 19 березня 2008 року N 196 ( 196-2008-п ) "Про передачу Фондові державного майна пакетів акцій відкритих акціонерних товариств";

розпорядження Кабінету Міністрів України від 22 лютого 2008 року N 367-р ( 367-2008-р ) "Про затвердження переліків господарських товариств і холдингових компаній, державні пакети акцій (частки) яких підлягають продажу, державних підприємств, холдингових компаній і відкритих акціонерних товариств, які підлягають підготовці до продажу в 2008 році" (зі змінами, внесеними розпорядженням від 19 березня 2008 року N 478-р) ( 478-2008-р ) в частині включення до переліку господарських товариств і холдингових компаній, державні пакети акцій (частки) яких підлягають продажу в 2008 році (додаток 1), пакетів акцій відкритих акціонерних товариств "Дніпроенерго", "Донбасенерго", "Західенерго", "Державна енергогенеруюча компанія "Центренерго";

розпорядження Кабінету Міністрів України від 19 березня 2008 року N 478-р ( 478-2008-р ) "Про внесення змін у додаток 1 до розпорядження Кабінету Міністрів України від 22 лютого 2008 р. N 367".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 11 квітня 2008 року N 316/2008
