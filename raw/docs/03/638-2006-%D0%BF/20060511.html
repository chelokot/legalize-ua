Кабінет Міністрів України; Постанова від 11.05.2006 № 638

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для здійснення заходів Українською Всесвітньою Координаційною Радою

Стан: Чинний

Ідентифікатор: 638-2006-п

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 травня 2006 р. N 638 Київ

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для здійснення заходів Українською Всесвітньою Координаційною Радою

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Установити, що кошти, передбачені у державному бюджеті ( 3235-15 ) для здійснення заходів Українською Всесвітньою Координаційною Радою, використовуються у 2006 році відповідно до Порядку використання у 2005 році коштів державного бюджету на здійснення заходів Української Всесвітньої Координаційної Ради, затвердженого постановою Кабінету Міністрів України від 22 липня 2005 р. N 628 ( 628-2005-п ) (Офіційний вісник України, 2005 р., N 30, ст. 1809).

Прем'єр-міністр України Ю.ЄХАНУРОВ
