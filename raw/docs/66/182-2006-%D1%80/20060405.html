РОЗПОРЯДЖЕННЯ від 5 квітня 2006 р. N 182-р Київ

Про передачу будівель у м. Горлівці у державну власність

Прийняти пропозицію МОН та Горлівської міської ради щодо передачі з власності територіальної громади м. Горлівки у державну власність з віднесенням до сфери управління зазначеного Міністерства таких будівель:

літер "A-V" по вул. Нестерова,124а

літер "А-III" по вул. Комсомольській,20

літер "Б-II" по вул. Пушкінській,13а

літер "А-III" по вул. Гагаріна,33.

Прем'єр-міністр України Ю.ЄХАНУРОВ
