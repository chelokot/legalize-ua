КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 листопада 2003 р. N 1815 Київ

( Постанову скасовано на підставі Указу Президента N 1394/2003 ( 1394/2003 ) від 01.12.2003 )

Про умови оплати праці вищих посадових осіб України та членів Кабінету Міністрів України

Відповідно до статті 8 Закону України "Про оплату праці" ( 108/95-ВР ) Кабінет Міністрів України постановляє:

1. Не для друку.

2. Не для друку.

3. Внести до постанов Кабінету Міністрів України зміни, що додаються.

4. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 13 грудня 1999 р. N 2289 ( 2289-99-п ).

5. Ця постанова набирає чинності з 1 вересня 2003 року.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 листопада 2003 р. N 1815

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. У додатках 2 і 6 до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288 ( 2288-99-п ) "Про впорядкування умов оплати праці працівників апарату органів виконавчої влади, місцевого самоврядування та їх виконавчих органів" (Офіційний вісник України, 1999 р., N 50, ст. 2469, N 51, ст. 2550; 2000 р., N 30, ст. 1277):

у додатку 2 позиції "Перший віце-прем'єр-міністр - 400, Віце-прем'єр-міністр - 390, Міністр Кабінету Міністрів - 380" виключити;

у додатку 6 позицію "Міністр - 380" виключити.

2. Пункт 2 постанови Кабінету Міністрів України від 28 серпня 2001 р. N 1119 ( 1119-2001-п ) "Про внесення змін до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288" (Офіційний вісник України, 2001 р., N 35, ст. 1627) - із змінами, внесеними постановою Кабінету Міністрів України від 1 листопада 2003 р. N 1711 ( 1711-2003-п ), викласти у такій редакції:

"2. Установити надбавку за особливий характер роботи та інтенсивність праці Главі Адміністрації Президента України, Керівнику Державного управління справами, Керівнику Апарату Верховної Ради України, Їх першим заступникам та заступникам, першому заступнику та заступникам Міністра Кабінету Міністрів України у розмірі 90 відсотків у порядку, визначеному розпорядженням Кабінету Міністрів України від 4 липня 1995 р. N 414 ( 414-95-р )".
