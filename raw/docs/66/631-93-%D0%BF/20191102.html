КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 серпня 1993 р. N 631 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 893 ( 893-2019-п ) від 23.10.2019 }

Про представництва іноземних суб'єктів господарської діяльності в Україні

{ Із змінами, внесеними згідно з Постановою КМ N 970 ( 970-2004-п ) від 28.07.2004 }

Відповідно до Закону України "Про зовнішньоекономічну діяльність" ( 959-12 ) Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 970 ( 970-2004-п ) від 28.07.2004 }

1. Установити розмір плати, що стягується Міністерством економіки та з питань європейської інтеграції за реєстрацію представництв іноземних суб'єктів господарської діяльності, у сумі 2500 доларів США.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 970 ( 970-2004-п ) від 28.07.2004 )

2. Установити, що свідоцтва про акредитацію представництв іноземних фірм, які були видані раніше Торгово-промисловою палатою за дорученням Уряду України, є дійсними до закінчення визначеного у них терміну акредитації.

3. Міністерству економіки та з питань європейської інтеграції щорічно у лютому подавати Кабінетові Міністрів України перелік зареєстрованих представництв іноземних суб'єктів господарської діяльності, а також узагальнену інформацію про їх діяльність. { Пункт 3 із змінами, внесеними згідно з Постановою КМ N 970 ( 970-2004-п ) від 28.07.2004 }
