МІНІСТЕРСТВО ЕКОНОМІКИ ТА З ПИТАНЬ ЄВРОПЕЙСЬКОЇ ІНТЕГРАЦІЇ УКРАЇНИ

29.11.2002 N 353

Зареєстровано в Міністерстві юстиції України 19 грудня 2002 р. за N 983/7271

Про внесення змін до деяких наказів Міністерства щодо державних закупівель

{ Із змінами, внесеними згідно з Наказом Міністерства економіки N 139 ( z0525-06 ) від 17.04.2006 }

Відповідно до постанови Кабінету Міністрів України від 27 вересня 2000 року N 1469 ( 1469-2000-п ) "Про організаційні заходи щодо функціонування системи державних закупівель" НАКАЗУЮ:

1. Унести до деяких наказів Міністерства щодо державних закупівель зміни, що додаються.

2. Управлінню державних закупівель та юридичному департаменту забезпечити в установленому порядку реєстрацію цього наказу в Міністерстві юстиції України.

3. Управлінню державних закупівель забезпечити опублікування цього наказу в інформаційно-аналітичному бюлетені "Вісник державних закупівель".

4. Цей наказ набирає чинності через 10 днів після реєстрації в Міністерстві юстиції України.

Виконуючий обов'язки Міністра В.Першин
