КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 грудня 1998 р. N 2093 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1080 ( 1080-99-п ) від 18.06.99 )

Про внесення доповнень до постанови Кабінету Міністрів України від 27 липня 1998 р. N 1145

Кабінет Міністрів України постановляє:

1. Доповнити перелік товарів критичного імпорту, затверджений постановою Кабінету Міністрів України від 27 липня 1998 р. N 1145 ( 1145-98-п ) "Про перелік товарів критичного імпорту" (Офіційний вісник України, 1998 р., N 30, ст. 1126), з наступними доповненнями, згідно з додатком.

2. Ця постанова набирає чинності з дня опублікування.
