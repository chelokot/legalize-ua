Рада Міністрів УРСР; Розпорядження від 01.02.1991 № 21-р

Про внесення змін до постанови Ради Міністрів УРСР від 1 жовтня 1990 року N 296

Стан: Втратив чинність

Ідентифікатор: 21-91-р

Текст документа від 25.08.2004:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

РОЗПОРЯДЖЕННЯ від 1 лютого 1991 р. N 21-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1109 ( 1109-2004-п ) від 25.08.2004 )

( Із змінами, внесеними згідно з Постановою КМ N 236 ( 236-91-п ) від 03.10.91 )

1. Погодитися з пропозицією Держагропрому УРСР та Комітету цін при Раді Міністрів УРСР, підтриманою Мінфіном УРСР:

( Абзац другий пункту 1 втратив чинність на підставі Постанови КМ N 236 ( 236-91-п ) від 03.10.91 )

про доповнення переліку продукції, на яку застосовуються договірні ціни (додаток N 23 до постанови Ради Міністрів УРСР від 1 жовтня 1990 р. N 296), такими видами сільськогосподарської продукції: фрукти, ягоди, столовий виноград, сухофрукти, горіхоплідні, овочі, картопля, баштанні культури, цикорій, клоччя конопляне, козячі вовна і пух, дикі, декоративні, лабораторні тварини й птахи, акваріумні риби, земноводні, плазуни, акваріумні рослини та біокорми.

2. Встановити, що порядок розрахунків за продукцію, крім винограду технічних сортів, яка закуповується колгоспами, радгоспами та іншими сільськогосподарськими підприємствами у населення для реалізації в рахунок державного замовлення, визначається облвиконкомами в межах державних закупівельних цін.

3. Визнати таким, що втратило чинність, розпорядження Ради Міністрів УРСР від 1 вересня 1990 р. N 401 ( 401-90-р ).

Заступник Голови
