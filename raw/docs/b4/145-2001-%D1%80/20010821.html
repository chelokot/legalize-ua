КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 квітня 2001 р. N 145-р Київ

Про утворення Координаційної ради з розроблення пропозицій щодо передачі земель із державної у комунальну власність у мм. Києві, Севастополі та Дніпропетровську

( Із змінами, внесеними згідно з Розпорядженням КМ N 385-р ( 385-2001-р ) від 21.08.2001 )

З метою ефективного проведення робіт з розмежування земель державної та комунальної власності за результатами пілотних проектів у мм. Києві, Севастополі та Дніпропетровську утворити Координаційну раду з розроблення пропозицій щодо передачі земель із державної у комунальну власність у мм. Києві, Севастополі та Дніпропетровську у складі згідно з додатком.

Надати право голові Координаційної ради залучати в установленому порядку до роботи фахівців центральних та місцевих органів виконавчої влади, а також у разі потреби вносити зміни до її складу. ( Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 385-р ( 385-2001-р ) від 21.08.2001 )

Головою Координаційної ради є Віце-прем'єр-міністр України згідно з розподілом функціональних повноважень. ( Розпорядження доповнено абзацом згідно з Розпорядженням КМ N 385-р ( 385-2001-р ) від 21.08.2001 )
