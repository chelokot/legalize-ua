Про внесення зміни до Положення про торговельно-економічну місію у складі закордонної дипломатичної установи України

Стан: Втратив чинність

Ідентифікатор: 145/2007

Текст документа від 20.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 522/2010 ( 522/2010 ) від 08.04.2010 }

Про внесення зміни до Положення про торговельно-економічну місію у складі закордонної дипломатичної установи України

Внести до абзацу першого пункту 9 Положення про торговельно-економічну місію у складі закордонної дипломатичної установи України, затвердженого Указом Президента України від 30 квітня 1994 року N 200 ( 200/94 ) (зі змінами, внесеними Указами від 22 вересня 2000 року N 1082 ( 1082/2000 ), від 25 березня 2003 року N 266 ( 266/2003 ), від 5 квітня 2004 року N 390 ( 390/2004 ) та від 25 липня 2006 року N 645 ( 645/2006 ), зміну, доповнивши його після першого речення новим реченням такого змісту: "Кандидатура для призначення на посаду керівника торговельно-економічної місії попередньо погоджується з Президентом України".
