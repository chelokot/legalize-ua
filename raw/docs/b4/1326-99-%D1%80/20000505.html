Кабінет Міністрів України; Розпорядження від 01.12.1999 № 1326-р

Про дозвіл Держмитслужбі на здійснення митного оформлення авіаційно-технічного майна, поставленого Міністерством оборони Російської Федерації військовій частині А2526 (м. Вінниця)

Стан: Втратив чинність

Ідентифікатор: 1326-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 грудня 1999 р. N 1326-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення авіаційно-технічного майна, поставленого Міністерством оборони Російської Федерації військовій частині А2526 (м. Вінниця) 20 травня 1998 р. для потреб Військово-Повітряних Сил України відповідно до Угоди між Урядом України та Урядом Російської Федерації про використання полігону злітно-посадкових систем "Нитка" від 7 лютого 1997 р. ( 643_198 ), за переліком згідно з додатком без сплати додаткового збору, встановленого постановою Кабінету Міністрів України від 19 травня 1999 р. N 840 ( 840-99-п ).
