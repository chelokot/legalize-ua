Текст документа від 16.07.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 листопада 2007 р. N 1038-р Київ

Про передачу нерухомого майна до сфери управління Харківської облдержадміністрації

{ Із змінами, внесеними згідно з Розпорядженням КМ N 966-р ( 966-2008-р ) від 16.07.2008 }

Прийняти пропозицію Міноборони та Харківської облдержадміністрації щодо передачі нерухомого майна згідно з додатком до сфери управління Харківської облдержадміністрації для подальшої передачі його у власність релігійної організації Харківської єпархії Української православної церкви.

Прем'єр-міністр України В.ЯНУКОВИЧ
