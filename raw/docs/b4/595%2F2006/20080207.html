Текст документа від 07.02.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у переговорах між Україною та Спеціальним Адміністративним Районом Гонконг Китайської Народної Республіки щодо підготовки проекту Угоди між Україною та Спеціальним Адміністративним Районом Гонконг Китайської Народної Республіки про видачу правопорушників

1. Утворити делегацію України для участі у переговорах між Україною та Спеціальним Адміністративним Районом Гонконг Китайської Народної Республіки щодо підготовки проекту Угоди між Україною та Спеціальним Адміністративним Районом Гонконг Китайської Народної Республіки про видачу правопорушників (м. Гонконг) у такому складі:

ГОРБУНОВА - заступник Міністра юстиції України,

Лідія Миколаївна глава делегації

ГАЛУЩЕНКО - завідувач відділу Головної служби

Герман Валерійович зовнішньої політики Секретаріату Президента України

КРАВЧУК - начальник управління міжнародних

Сергій Федорович зв'язків Генеральної прокуратури України

МАРЧЕНКО - завідувач відділу Головної державно-

Людмила Іванівна правової служби Секретаріату Президента України

СИБІГА - заступник директора Договірно-правового

Андрій Іванович департаменту Міністерства закордонних справ України

ФІЛАТОВ - суддя Верховного Суду України (за

Василь Миколайович згодою)

ШЕВЧЕНКО - заступник директора Департаменту

Катерина Георгіївна міжнародного співробітництва Міністерства юстиції України.

Дозволити главі делегації вносити в разі потреби зміни до її складу, залучаючи до роботи делегації членів Експертної групи з підготовки проектів міжнародних договорів України про правові відносини та правову допомогу у цивільних і кримінальних справах, утвореної Указом Президента України від 24 квітня 2004 року N 476 ( 476/2004 ).

2. Міністерству юстиції України за погодженням з Міністерством закордонних справ України затвердити вказівки делегації України на переговори.

3. Кабінету Міністрів України вирішити питання щодо виділення коштів в іноземній валюті для забезпечення участі у переговорах делегації України.

Президент України В.ЮЩЕНКО
