Кабінет Міністрів України; Постанова від 21.09.1998 № 1484

Про встановлення терміну виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах під час виготовлення частин гідротурбін

Стан: Втратив чинність

Ідентифікатор: 1484-98-п

Текст документа від 13.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 вересня 1998 р. N 1484 Київ

Про встановлення терміну виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах під час виготовлення частин гідротурбін

( Із змінами, внесеними згідно з Постановами КМ N 421 ( 421-2001-п ) від 06.05.2001 N 1648 ( 1648-2001-п ) від 13.12.2001 )

Відповідно до статті 2 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ), враховуючи тривалий технологічний цикл виготовлення частин гідротурбін, Кабінет Міністрів України постановляє:

Установити термін виконання операцій з давальницькою сировиною, що ввозиться на митну територію України, під час виготовлення частин гідротурбін (код згідно з УКТ ЗЕД 8410 90 90 00) 960 календарних днів з моменту оформлення ввізної вантажної митної декларації.

( Постанова із змінами, внесеними згідно з Постановами КМ N 421 ( 421-2001-п ) від 06.05.2001, N 1648 ( 1648-2001-п ) від 13.12.2001 )
