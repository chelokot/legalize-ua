Про правління Пенсійного фонду України

Кабінет Міністрів України постановляє:

1. Дозволити Пенсійному фондові України мати правління у кількості 19 осіб.

2. Затвердити правління Пенсійного фонду України у складі Биковця В'ячеслава Михайловича (за згодою), Вернигори Надії Федорівни, Гарячої Олени Василівни, Герасимова Івана Олександровича (за згодою), Діденка Сергія Олексійовича, Другова Олександра Олексійовича, Зарудного Олексія Борисовича, Кабанченка Григорія Володимировича (за згодою), Колбуна Віктора Андрійовича, Короневського Валентина Максимовича, Кравчука Василя Олексійовича, Макарової Олени Володимирівни (за згодою), Максимчука Володимира Спиридоновича (за згодою), Надраги Василя Івановича (за згодою), Никитенко Валентини Степанівни, Осового Григорія Васильовича, Павелка Миколи Петровича, Ривака Івана Миколайовича (за згодою), Рябцевої Тетяни Борисівни.

3. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 18 грудня 1996 р. N 1522 ( 1522-96-п ) "Про внесення змін до складу правління Пенсійного фонду";

постанову Кабінету Міністрів України від 8 лютого 1999 р. N 176 ( 176-99-п ) "Про внесення змін до складу правління Пенсійного фонду України";

пункти 1 та 2 постанови Кабінету Міністрів України від 24 червня 2003 р. N 960 ( 960-2003-п ) "Про правління Пенсійного фонду" (Офіційний вісник України, 2003 р., N 26, ст. 1281);

постанову Кабінету Міністрів України від 31 березня 2004 р. N 418 ( 418-2004-п ) "Про членів правління Пенсійного фонду" (Офіційний вісник України, 2004 р., N 13, ст. 901).
