( Наказ втратив чинність на підставі Наказу Мінекономіки N 132 ( z0296-95 ) від 09.08.95 )

Про встановлення оптових цін і рентної плати на газ природний та тарифів на його транспортування

( Із змінами, внесеними згідно з Наказом Мінекономіки N 105 ( z0218-95 ) від 10.07.95 )

На виконання Указів Президента України від 21 грудня 1994 року N 785/94 "Про встановлення рентної плати за нафту і природний газ, що видобуваються в Україні" та від 9 березня 1995 року N 198/95 "Про внесення змін до Указу Президента України від 21 грудня 1994 року N 785" та згідно з повноваженнями, затвердженими постановою Кабінету Міністрів України від 13 лютого 1995 року N 109 ( 109-95-п ) "Про уточнення повноважень центральних органів державної виконавчої влади, Уряду Автономної Республіки Крим та виконкомів місцевих Рад у галузі ціноутворення", НАКАЗУЮ:

1. Затвердити оптову ціну та рентну плату на газ природний, що видобувається державним виробничим підприємством "Чорноморнафтогаз", згідно з додатком N 1.

2. Затвердити оптову ціну на газ природний, який закуповується в акціонерному товаристві "Укргазпром" і реалізується споживачам державним виробничим підприємством "Чорноморнафтогаз", згідно з додатком N 2.

Заступник Міністра В.М.Кальник Додаток N 1 до наказу Мінекономіки України від 5 квітня 1995 року N 51

( Тарифи відмінено на підставі Наказу Мінекономіки N 105 ( z0218-95 ) від 10.07.95 )

Оптова ціна і рентна плата на газ природний власного видобутку, що реалізується споживачам державним виробничим підприємством "Чорноморнафтогаз"
