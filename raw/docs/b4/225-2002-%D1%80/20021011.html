Кабінет Міністрів України; Розпорядження від 26.04.2002 № 225-р

Про надання ТОВ "Співдружність ініціативних працездатних інвалідів" відстрочки на умовах податкового кредиту у сплаті податку на додану вартість, акцизного збору та податку на прибуток із застосуванням нульової ставки за користування цим кредитом

Стан: Втратив чинність

Ідентифікатор: 225-2002-р

Текст документа від 11.10.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 квітня 2002 р. N 225-р Київ

Про надання ТОВ "Співдружність ініціативних працездатних інвалідів" відстрочки на умовах податкового кредиту у сплаті податку на додану вартість, акцизного збору та податку на прибуток із застосуванням нульової ставки за користування цим кредитом

( Із змінами, внесеними згідно з Розпорядженнями КМ N 386-р ( 386-2002-р ) від 11.07.2002 N 580-р ( 580-2002-р ) від 11.10.2002 )

Державній податковій адміністрації надати ТОВ "Співдружність ініціативних працездатних інвалідів" (м. Херсон) відстрочку у сплаті податку на додану вартість, акцизного збору та податку на прибуток на період з 20 лютого 2002 р. до 25 грудня 2004 р. на умовах податкового кредиту із застосуванням нульової ставки за користування цим кредитом.

( Розпорядження із змінами, внесеними згідно з Розпорядженнями КМ N 386-р ( 386-2002-р ) від 11.07.2002, N 580-р ( 580-2002-р ) від 11.10.2002 )
