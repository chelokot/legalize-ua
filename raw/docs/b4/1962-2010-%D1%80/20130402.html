КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 жовтня 2010 р. N 1962-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про голову міжвідомчої робочої групи з питань підготовки до забезпечення сталого проходження опалювального сезону 2010/11 року

Затвердити головою міжвідомчої робочої групи з питань підготовки до забезпечення сталого проходження опалювального сезону 2010/11 року, утвореної розпорядженням Кабінету Міністрів України від 21 квітня 2010 р. N 998 ( 998-2010-р ), Міністра з питань житлово-комунального господарства Хіврича Юрія Єгоровича, увільнивши від цих обов'язків Попова Олександра Павловича.

Прем'єр-міністр України М.АЗАРОВ
