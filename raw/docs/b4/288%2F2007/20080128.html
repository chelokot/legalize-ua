Президент України; Указ від 10.04.2007 № 288/2007

Про зупинення дії постанов Кабінету Міністрів України від 14 березня 2007 року N 431, N 432 і N 433

Стан: Втратив чинність

Ідентифікатор: 288/2007

Текст документа від 28.01.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1307/2007 ( 1307/2007 ) від 28.12.2007 }

Про зупинення дії постанов Кабінету Міністрів України від 14 березня 2007 року N 431, N 432 і N 433

{ Додатково див. Конституційне подання Президента ( n0006100-07 ) від 10.04.2007 }

Верховною Радою України 22 грудня 2006 року прийнято Закон України "Про внесення змін до статті 7 Закону України "Про банки і банківську діяльність" ( 532-16 ).

Названим Законом ( 532-16 ) докорінно змінено існуючий порядок здійснення державою повноважень власника державного банку. Зокрема, Кабінету Міністрів України надається право призначати п'ятьох членів наглядової ради державного банку та припиняти своїм рішенням їх повноваження, водночас з семи до п'яти осіб зменшено кількість членів наглядових рад, які призначаються Президентом України та Верховною Радою України.

Зі зменшенням кількості членів наглядових рад, які призначаються Президентом України, обмежуються і можливості Президента України, який за Конституцією України ( 254к/96-ВР ) є гарантом додержання прав громадян (частина друга статті 102), здійснює керівництво у сфері національної безпеки (пункт 17 частини першої статті 106), впливати на вирішення питань, здійснення контролю за якими Законом України "Про банки і банківську діяльність" ( 2121-14 ) віднесено до компетенції наглядових рад державних банків, а саме: захист інтересів держави як акціонера державного банку, збереження грошових коштів вкладників державних банків, у тому числі громадян, забезпечення повернення цих коштів вкладникам.

Зазначене не тільки обмежує можливості Президента України щодо реалізації конституційного статусу гаранта додержання прав громадян, а й не відповідає частині другій статті 3 Основного Закону України ( 254к/96-ВР ), якою проголошено, що права і свободи людини та їх гарантії визначають зміст і спрямованість діяльності держави, держава відповідає перед людиною за свою діяльність, а утвердження і забезпечення прав і свобод людини є головним обов'язком держави.

Наведений вище порядок призначення членів наглядових рад державних банків не відповідає також частині першій статті 17 Конституції України ( 254к/96-ВР ), якою забезпечення економічної безпеки визнано однією з найважливіших функцій держави, та призводить до порушення конституційних повноважень Президента України із забезпечення національної безпеки держави (пункт 1 частини першої статті 106 Конституції України ( 254к/96-ВР ), адже захист інтересів вкладників Законом України "Про основи національної безпеки України" ( 964-15 ) визначено одним з основних напрямів державної політики з питань національної безпеки (стаття 8).

Законом України "Про внесення змін до статті 7 Закону України "Про банки і банківську діяльність" ( 532-16 ) також передбачено можливість здійснення Кабінетом Міністрів України управління державним банком у випадках, установлених статутом державного банку, який за Законом України "Про банки і банківську діяльність" ( 2121-14 ) затверджується постановою Кабінету Міністрів України. Це суперечить пункту 5 статті 116 Конституції України ( 254к/96-ВР ), за яким Кабінет Міністрів України здійснює управління об'єктами державної власності виключно відповідно до закону.

На виконання Закону України "Про внесення змін до статті 7 Закону України "Про банки і банківську діяльність" ( 532-16 ) Кабінет Міністрів України видав постанови від 14 березня 2007 року N 431 ( 431-2007-п ) "Про призначення членів наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України", від 14 березня 2007 року N 432 ( 432-2007-п ) "Про призначення членів наглядової ради відкритого акціонерного товариства "Державний ощадний банк України" та від 14 березня 2007 року N 433 ( 433-2007-п ) "Про внесення змін до Статуту відкритого акціонерного товариства "Державний ощадний банк України".

Названі постанови ( 431-2007-п, 432-2007-п, 433-2007-п ), якими Кабінетом Міністрів України призначено по п'ять членів наглядових рад зазначених державних банків та внесено відповідні зміни до Статуту відкритого акціонерного товариства "Державний ощадний банк України", не відповідають з наведених вище підстав частині другій статті 3, частині першій статті 17, частині другій статті 102, пункту 17 частини першої статті 106 та пункту 5 статті 116 Конституції України ( 254к/96-ВР ).

Ураховуючи викладене, відповідно до пункту 15 статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію як таких, що не відповідають Конституції України ( 254к/96-ВР ):

постанови Кабінету Міністрів України від 14 березня 2007 року N 431 ( 431-2007-п ) "Про призначення членів наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України";

постанови Кабінету Міністрів України від 14 березня 2007 року N 432 ( 432-2007-п ) "Про призначення членів наглядової ради відкритого акціонерного товариства "Державний ощадний банк України";

постанови Кабінету Міністрів України від 14 березня 2007 року N 433 ( 433-2007-п ) "Про внесення змін до Статуту відкритого акціонерного товариства "Державний ощадний банк України".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
