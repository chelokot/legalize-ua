{ Розпорядження втратило чинність на підставі Розпорядження КМ N 706-р ( 706-2008-р ) від 14.05.2008 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 31 грудня 2004 р. N 991

На часткову зміну абзацу другого розпорядження Кабінету Міністрів України від 31 грудня 2004 р. N 991 ( 991-2004-р ) уповноважити Міністра оборони Гриценка Анатолія Степановича підписати Меморандум про взаєморозуміння між Кабінетом Міністрів України та Урядом Його Величності Султана і Янг Ді-Пертуана Брунею Даруссаламу щодо співробітництва у сфері оборони.
