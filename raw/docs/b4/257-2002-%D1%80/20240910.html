{ Розпорядження втратило чинність на підставі Постанови КМ N 1023 ( 1023-2024-п ) від 06.09.2024 }

Про Головного Прикордонного Уповноваженого на українсько-польській, українсько-словацькій, українсько-угорській ділянках державного кордону

Призначити Головним Прикордонним Уповноваженим на українсько-польській, українсько-словацькій, українсько-угорській ділянках державного кордону генерал-полковника Литвина Миколу Михайловича, Голову Державного комітету у справах охорони державного кордону - Командувача Прикордонних військ, увільнивши від цих обов'язків Олексієнка Бориса Миколайовича ( 1047-2000-п ).
