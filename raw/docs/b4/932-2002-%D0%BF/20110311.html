Про затвердження переліків документів і груп товарів, які підлягають захисту голографічними елементами

{ Із змінами, внесеними згідно з Постановами КМ N 369 ( 369-2004-п ) від 24.03.2004 N 963 ( 963-2004-п ) від 28.07.2004 N 324 ( 324-2006-п ) від 15.03.2006 N 1427 ( 1427-2006-п ) від 18.10.2006 N 85 ( 85-2010-п ) від 27.01.2010 N 1167 ( 1167-2010-п ) від 22.12.2010 }

На виконання Указу Президента України від 15 листопада 2000 р. N 1239 ( 1239/2000 ) "Про захист документів і товарів голографічними захисними елементами" Кабінет Міністрів України постановляє:

1. Затвердити такі, що додаються:

перелік документів, які підлягають захисту голографічними елементами, та їх державних замовників;

перелік груп товарів, які рекомендується захищати голографічними елементами.

2. Державним замовникам бланків документів, що підлягають захисту голографічними елементами, згідно із затвердженим цією постановою переліком забезпечити проведення інвентаризації залишків бланків документів суворої звітності (обліку), які підлягають захисту голографічними елементами, а також таких, що вже захищаються голографічними елементами, станом на 1 серпня 2002 року.

3. Центральним органам виконавчої влади відповідно до їх компетенції затвердити до 1 серпня 2002 р. перелік товарів, які підлягають захисту голографічними елементами, визначений згідно із затвердженим цією постановою переліком груп товарів, забезпечити проведення інвентаризації залишків цих товарів станом на 1 серпня 2002 р. та разом із Службою безпеки і Національною академією наук установити до 1 вересня 2002 р. порядок їх використання.

4. Службі безпеки разом із заінтересованими центральними органами виконавчої влади та Національною академією наук подати у місячний термін проект постанови Кабінету Міністрів України "Про порядок запровадження захисту документів і товарів голографічними елементами", підготовлений з урахуванням необхідності захисту марок акцизного збору на алкогольну та тютюнову продукцію.
