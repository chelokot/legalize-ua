КАБІНЕТ МІНІСТРІВ УКРАЇНИ
ПОСТАНОВА

від 28 листопада 2012 р. № 1139
Київ

Про надання у 2012 році державних гарантій для забезпечення виконання боргових зобов’язань за запозиченнями, залученими з метою реалізації проекту з модернізації компресорної станції Бар магістрального газопроводу “Союз”

Відповідно до статті 6 Закону України “Про Державний бюджет України на 2012 рік” Кабінет Міністрів України постановляє :

1. Погодитися з пропозицією Міністерства енергетики та вугільної промисловості щодо надання у 2012 році державних гарантій для забезпечення виконання боргових зобов’язань за запозиченнями, залученими дочірньою компанією “Укртрансгаз” Національної акціонерної компанії “Нафтогаз України” з метою реалізації проекту з модернізації компресорної станції Бар магістрального газопроводу “Союз” відповідно до Меморандуму про взаєморозуміння між Національною акціонерною компанією “Нафтогаз України” та “Ferrostaal Industrieanlagen GmbH” від 2 липня 2012 р. (далі - запозичення).

2. Затвердити Порядок та умови надання у 2012 році державних гарантій для забезпечення виконання боргових зобов’язань за запозиченнями, залученими дочірньою компанією “Укртрансгаз” Національної акціонерної компанії “Нафтогаз України” з метою реалізації проекту з модернізації компресорної станції Бар магістрального газопроводу “Союз”, що додаються.

3. Уповноважити Міністра фінансів підписувати документи щодо надання державних гарантій для забезпечення виконання боргових зобов’язань за запозиченнями.

4. Міністерству енергетики та вугільної промисловості здійснювати контроль за реалізацією проекту з модернізації компресорної станції Бар магістрального газопроводу “Союз”, цільовим використанням запозичень та фінансовим станом дочірньої компанії “Укртрансгаз” Національної акціонерної компанії “Нафтогаз України”.

ПОРЯДОК ТА УМОВИ
надання у 2012 році державних гарантій для забезпечення виконання боргових зобов’язань за запозиченнями, залученими дочірньою компанією “Укртрансгаз” Національної акціонерної компанії “Нафтогаз України” з метою реалізації проекту з модернізації компресорної станції Бар магістрального газопроводу “Союз”

1. Ці Порядок та умови визначають механізм надання у 2012 році державних гарантій для забезпечення виконання боргових зобов’язань за запозиченнями, залученими дочірньою компанією “Укртрансгаз” Національної акціонерної компанії “Нафтогаз України” від “Deutsche Bank AG” з метою реалізації проекту з модернізації компресорної станції Бар магістрального газопроводу “Союз” відповідно до Меморандуму про взаєморозуміння між Національною акціонерною компанією “Нафтогаз України” та “Ferrostaal Industrieanlagen GmbH” від 2 липня 2012 р. (далі - запозичення).

2. Державні гарантії надаються для забезпечення виконання боргових зобов’язань за запозиченнями у розмірі, що не перевищує суму, еквівалентну 560000000 гривень.

3. Плата за надання державних гарантій становить 0,01 відсотка річних залишку суми гарантійних зобов’язань, яка сплачується в строк, передбачений для сплати відсотків за запозиченнями.

4. Забезпеченням виконання боргових зобов’язань за запозиченнями перед Кабінетом Міністрів України як гарантом є застава природного газу, який належить дочірній компанії “Укртрансгаз” Національної акціонерної компанії “Нафтогаз України” (далі - позичальник), оціночна вартість якого становить не менш як 100 відсотків суми таких боргових зобов’язань.

5. Для надання державних гарантій позичальник подає Мінфіну:

1) проект кредитного договору;

2) відомості про запозичення разом з графіками їх погашення та обслуговування;

3) проектну (інвестиційну) пропозицію щодо реалізації проекту з модернізації компресорної станції Бар магістрального газопроводу “Союз”, стосовно якої проведено оцінку економічної ефективності.

6. Мінфін та позичальник до надання державних гарантій укладають договір про погашення заборгованості перед державою за виконання гарантійних зобов’язань.

7. Державні гарантії надаються на строк виконання боргових зобов’язань за запозиченнями.
