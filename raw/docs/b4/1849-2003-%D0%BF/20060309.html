КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 листопада 2003 р. N 1849 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

Про внесення доповнення до пункту 2-1 постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288

Кабінет Міністрів України постановляє:

Пункт 2-1 постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288 ( 2288-99-п ) "Про впорядкування умов оплати праці працівників апарату органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів" (Офіційний вісник України, 1999 р., N 50, ст. 2469), із змінами, внесеними постановою Кабінету Міністрів України від 1 листопада 2003 р. N 1711 ( 1711-2003-п ), після слів "центральних органів виконавчої влади" доповнити словами "Генеральному прокурору України", а після слів "за ранг державного службовця" - словами "класний чин".

Прем'єр-міністр України В.ЯНУКОВИЧ
