РОЗПОРЯДЖЕННЯ від 6 грудня 2007 р. N 1104-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 50-р ( 50-2008-р ) від 09.01.2008 }

Про введення посад заступників Голови Державної митної служби України

Ввести у Державній митній службі України дві посади заступника Голови замість посади заступника Голови - начальника Західної регіональної митниці та заступника Голови - начальника Південної регіональної митниці.

У зв'язку з цим визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 17 жовтня 2007 р. N 895 ( 895-2007-р ) "Про введення нових посад у Державній митній службі України" (Офіційний вісник України, 2007 р., N 80, ст. 2978).

Прем'єр-міністр України В.ЯНУКОВИЧ
