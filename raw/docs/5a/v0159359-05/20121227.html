Про форму підписного листа для збирання підписів на підтримку всеукраїнського референдуму за народною ініціативою

Відповідно до статті 18 Закону України "Про всеукраїнський та місцеві референдуми" ( 1286-12 ), керуючись статтями 12, 13, пунктом 3 статті 20 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Встановити форму підписного листа для збирання підписів на підтримку всеукраїнського референдуму за народною ініціативою (додається).

2. Секретаріату Центральної виборчої комісії забезпечити видачу зареєстрованим ініціативним групам всеукраїнського референдуму за народною ініціативою зразків підписних листів для збирання підписів за затвердженою цією постановою формою.

3. Визнати такою, що втратила чинність, постанову Центральної виборчої комісії від 24 грудня 1999 року N 451 ( v0451359-99 ) "Про затвердження форми підписного листа для збирання підписів з вимогою про проведення всеукраїнського референдуму за народною ініціативою".
