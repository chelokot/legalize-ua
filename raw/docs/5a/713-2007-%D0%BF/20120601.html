Кабінет Міністрів України; Постанова від 12.05.2007 № 713

Про внесення змін у додаток 2 до Порядку декларування митної вартості товарів, які переміщуються через митний кордон України, та подання відомостей для її підтвердження

Стан: Втратив чинність

Ідентифікатор: 713-2007-п

Текст документа від 01.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 травня 2007 р. N 713 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 444 ( 444-2012-п ) від 21.05.2012 }

Про внесення змін у додаток 2 до Порядку декларування митної вартості товарів, які переміщуються через митний кордон України, та подання відомостей для її підтвердження

Кабінет Міністрів України постановляє:

1. Внести у додаток 2 до Порядку декларування митної вартості товарів, які переміщуються через митний кордон України, та подання відомостей для її підтвердження, затвердженого постановою Кабінету Міністрів України від 20 грудня 2006 р. N 1766 ( 1766-2006-п ) (Офіційний вісник України, 2006 р., N 51, ст. 3417), такі зміни:

у графі 8 слово "застосування" замінити словом "незастосування";

у графі 16 цифри "11" та "14" замінити відповідно цифрами "12" та "15".

2. Ця постанова набирає чинності з дня опублікування.
