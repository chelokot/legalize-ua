Про зміни у складі Комісії при Президентові України з питань громадянства

Стан: Втратив чинність

Ідентифікатор: 770/2000

Текст документа від 30.04.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 740/2005 ( 740/2005 ) від 30.04.2005 )

Про зміни у складі Комісії при Президентові України з питань громадянства

1. Увести до складу Комісії при Президентові України з питань громадянства, затвердженого Указом Президента України від 9 грудня 1994 року N 746 ( 746/94 ) (із змінами, внесеними Указами від 22 квітня 1996 року N 275 ( 275/96 ), від 6 листопада 1997 року N 1254 ( 1254/97 ), від 13 жовтня 1998 року N 1135 ( 1135/98 ) та від 6 березня 1999 року N 238 ( 238/99 ), таких осіб:

КОРНІЄНКО - заступник Міністра внутрішніх справ Михайло Васильович України - начальник міліції громадської безпеки

СЕРЕДА - директор Державного департаменту у справах Григорій Порфирович національностей та міграції.

2. Вивести зі складу Комісії Трощинського В.П., Чернишова В.С.

Президент України Л.КУЧМА

м. Київ, 7 червня 2000 року N 770/2000
