Кабінет Міністрів України; Постанова від 18.12.1995 № 1014

Про підвищення розміру стипендій для молодих учених

Стан: Втратив чинність

Ідентифікатор: 1014-95-п

Текст документа від 28.12.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 грудня 1995 р. N 1014 Київ

Про підвищення розміру стипендій для молодих учених

( Із змінами, внесеними згідно з Постановами КМ N 698 ( 698-98-п ) від 18.05.98 N 2083 ( 2083-98-п ) від 28.12.98 )

Кабінет Міністрів України постановляє:

1. Відповідно до Указу Президента України від 21 березня 1995 р. N 246 ( 246/95 ) "Про визначення розмірів стипендій Президента України для найбільш талановитих молодих учених та для талановитих перспективних спортсменів України" установити розмір стипендій Президента України для молодих учених у сумі 100 гривень

кожна. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 698 ( 698-98-п ) від 18.05.98 )

2. Установити розмір стипендії Кабінету Міністрів України для молодих учених, заснованих постановою Кабінету Міністрів України від 16 серпня 1994 р. N 560 ( 560-94-п ), у сумі 6,7 млн.крб.кожна.

( На зміну пункту 2 збільшити розмір стипендії Кабінету Міністрів України для молодих учених, установивши її з 1 січня 1999 р. у розмірі 90 гривень згідно з Постановою КМ N 2083 ( 2083-98-п ) від 28.12.98 )

3. Визнати такими, що втратили чинність:

пункт 1 постанови Кабінету Міністрів України від 16 серпня 1994 р. N 560 ( 560-94-п ) "Про стипендії Кабінету Міністрів України для молодих учених" (ЗП України, 1994 р., N 11, ст.285) та абзац перший пункту 2 Положення, затвердженого цією постановою, у частині розміру стипендій;

постанову Кабінету Міністрів України від 19 квітня 1995 р. N 296 ( 296-95-п ) "Про розмір стипендій для молодих учених" (ЗП України, 1995 р., N 7, ст.175).

4. Ця постанова набирає чинності з 1 жовтня 1995 р.
