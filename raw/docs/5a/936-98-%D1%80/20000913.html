Кабінет Міністрів України; Розпорядження від 13.11.1998 № 936-р

Про закріплення у державній власності пакету акцій ДАЕК "Херсонобленерго"

Стан: Втратив чинність

Ідентифікатор: 936-98-р

Текст документа від 13.09.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 листопада 1998 р. N 936-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 350-р ( 350-2000-р ) від 13.09.2000 )

Про закріплення у державній власності пакету акцій ДАЕК "Херсонобленерго"

1. Відповідно до пункту 16 Державної програми приватизації на 1998 рік ( 124/98-ВР ) закріпити у державній власності на 3 роки пакет акцій у розмірі 50 відсотків статутного фонду плюс одна акція ДАЕК "Херсонобленерго".

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 20 жовтня 1997 р. N 596 ( 596-97-р ).

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
