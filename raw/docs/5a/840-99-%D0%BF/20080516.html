Про внесення доповнення до постанови Кабінету Міністрів України від 27 січня 1997 р. N 65

Стан: Втратив чинність

Ідентифікатор: 840-99-п

Текст документа від 16.05.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 травня 1999 р. N 840 Київ

{ Постанова втрачає чинність на підставі Постанови КМ N 93 ( 93-2003-п ) від 18.01.2003 з дати набрання чинності частиною тринадцятою статті 71 Митного кодексу України ( 92-15 ), яка набирає чинності з моменту набуття Україною членства у Світовій організації торгівлі }

Про внесення доповнення до постанови Кабінету Міністрів України від 27 січня 1997 р. N 65

З метою вишукання додаткових джерел для своєчасної виплати заробітної плати, стипендій, пенсій та інших соціальних виплат Кабінет Міністрів України постановляє:

Доповнити пункт 1 постанови Кабінету Міністрів України від 27 січня 1997 р. N 65 ( 65-97-п ) "Про ставки митних зборів" (із змінами, внесеними постановами Кабінету Міністрів України від 7 березня 1998 р. N 285 ( 285-98-п ), від 13 травня 1998 р. N 670 ( 670-98-п ), від 18 вересня 1998 р. N 1460 ( 1460-98-п ), від 21 вересня 1998 р. N 1477 ( 1477-98-п ) та від 8 жовтня 1998 р. N 1625 ( 1625-98-п ) абзацом такого змісту:

"Установити, що на період з 1 липня до 31 грудня 1999 р. до митного збору за митне оформлення товарів, які імпортуються на митну територію України, додатково включається збір у розмірі 2 відсотків митної вартості товарів із спрямуванням одержаних коштів до Державного бюджету України".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
