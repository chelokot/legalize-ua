Про співголову Національної ради соціального партнерства

На часткову зміну статті 3 Указу Президента України від 8 лютого 1993 року N 34 ( 34/93 ) "Про Національну раду соціального партнерства" (зі змінами, внесеними Указами від 15 листопада 1996 року N 1083 ( 1083/96 ), від 19 червня 1997 року N 560 ( 560/97 ), від 31 липня 1998 року N 834 ( 834/98 ) та від 30 січня 2003 року N 51 ( 51/2003 ):

Призначити КИРИЛЕНКА В'ячеслава Анатолійовича - Міністра праці та соціальної політики України - співголовою Національної ради соціального партнерства від Кабінету Міністрів України, увільнивши від виконання цих обов'язків Папієва М.М.
