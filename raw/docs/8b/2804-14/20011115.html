Верховна Рада України; Закон від 15.11.2001 № 2804-III

Про рішення Президента України про допуск на територію України підрозділів миротворчих контингентів збройних сил Російської Федерації для їх транзитного переміщення залізничним транспортом

Стан: Чинний

Ідентифікатор: 2804-14

Текст документа від 15.11.2001:

ЗАКОН УКРАЇНИ

Про рішення Президента України про допуск на територію України підрозділів миротворчих контингентів збройних сил Російської Федерації для їх транзитного переміщення залізничним транспортом

( Відомості Верховної Ради України (ВВР), 2002, N 7, ст.61 )

Верховна Рада України постановляє:

Рішення Президента України про допуск на територію України підрозділів миротворчих контингентів збройних сил Російської Федерації для їх транзитного переміщення залізничним транспортом у Російську Федерацію ( 1003/2001 ) схвалити.

Президент України Л.КУЧМА

м. Київ, 15 листопада 2001 року N 2804-III
