Про затвердження індексу для визначення розміру плати за виконання робіт

Відповідно до підпунктів 29, 30 пункту 4 Положення про Державний комітет України з будівництва та архітектури, затвердженого Указом Президента України від 20.08.2002 N 725/2002 ( 725/2002 ), НАКАЗУЮ:

1. Затвердити індекс для визначення розміру плати за виконання робіт, зазначених у таблицях Базових показників вартості проектно-планувальних та інших робіт із надання платних послуг замовникам, затверджених постановою колегії Держбуду від 26.06.91 N 24, у розмірі 1,38.

2. Уважати таким, що втратив чинність, наказ Держбуду від 28.05.2001 N 128 ( z0512-01 ) "Про затвердження індексу для визначення розміру плати за виконання робіт", зареєстрований у Міністерстві юстиції України 15.06.2001 за N 512/5703.

3. Управлінню містобудівної політики (Економов А.О.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Управлінню містобудівної політики (Економов А.О.) та Управлінню цінової політики, експертизи та контролю вартості в будівництві (Губень П.І.) забезпечити доведення наказу до відома зацікавлених організацій.

5. Контроль за виконанням цього наказу покласти на заступника Голови Комітету Присяжнюка В.Ф.

Голова Комітету В.І.Череп
