НАКАЗ

28.02.2003 N 135

Зареєстровано в Міністерстві юстиції України 18 березня 2003 р. за N 212/7533

Про внесення змін до деяких наказів Держмитслужби України

( Із змінами, внесеними згідно з Наказом Державної митної служби

N 30 ( z0109-06 ) від 23.01.2006 )

Відповідно до Положення про Державну митну службу України, затвердженого Указом Президента України від 24.08.2000 N 1022 ( 1022/2000 ), і з метою вдосконалення нормативної бази з питань справляння ввізного мита НАКАЗУЮ:

( Пункт 1 втратив чинність на підставі Наказу Державної митної служби N 30 ( z0109-06 ) від 23.01.2006 )

2. У підпункті 3.2.5 пункту 3 "Особливості заповнення окремих граф вантажної митної декларації при здійсненні митного оформлення товарів із застосуванням пільг в оподаткуванні" Порядку подання документів, які підтверджують право суб'єктів підприємницької діяльності на користування встановленими чинним законодавством податковими пільгами під час митного оформлення товарів та інших предметів, що ввозяться на митну територію України або вивозяться з митної території України, затвердженого наказом Держмитслужби України від 22.12.99 N 845 ( z0210-00 ) і зареєстрованого в Міністерстві юстиції України 05.04.2000 за N 210/4431, замінити цифри "06" словами "згідно з Класифікатором способів розрахунку".

3. Управлінню податків та зборів (Околіта М.В.) та Управлінню правової роботи (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Секретаріату після державної реєстрації в Міністерстві юстиції України цього наказу забезпечити тиражування та розсилку його в митниці.

Контроль за виконанням наказу залишаю за собою.

В.о. Голови Служби О.Єгоров
