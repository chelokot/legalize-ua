ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

Про внесення змін до додатків 3 та 4 до Положення про

реєстрацію фондових бірж та торговельно-інформаційних систем і регулювання їх діяльності

{ Із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку

N 1542 ( z0035-07 ) від 19.12.2006 }

Відповідно до Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ) Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

{ Пункт 1 втратив чинність у частині, що регулює діяльність фондових бірж на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 1542 ( z0035-07 ) від 19.12.2006 } 1. Внести зміни до додатків 3 та 4 до Положення про реєстрацію фондових бірж та торговельно-інформаційних систем і регулювання їх діяльності, затвердженого рішенням Комісії від 15.01.97 N 9 ( z0020-97 ) (із змінами та доповненнями), виклавши їх в новій редакції (додаються).

2. Управлінню ліцензування діяльності професійних учасників ринку цінних паперів (К.Отченаш) та юридичному управлінню (Л.Волохов) забезпечити реєстрацію цього рішення в Міністерстві юстиції України.

3. Сектору по роботі з громадськістю забезпечити опублікування цього рішення в засобах масової інформації відповідно до чинного законодавства.

4. Контроль за виконанням рішення покласти на Члена Комісії - заступника Голови Волкова М.Ф.

Т.в.о. Голови Комісії М.Пефтієв
