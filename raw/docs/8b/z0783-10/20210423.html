Зареєстровано в Міністерстві юстиції України 7 вересня 2010 р. за N 783/18078

{ Наказ втратив чинність на підставі Наказу Міністерства соціальної політики N 142 ( z0480-21 ) від 23.03.2021 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 01.10.2007 N 507

Відповідно до розпорядження Кабінету Міністрів України від 30.06.2010 N 1289-р ( 1289-2010-р ) "Про перейменування регіональних центрів інноваційного розвитку" НАКАЗУЮ:

1. Внести до наказу Міністерства праці та соціальної політики України від 01.10.2007 N 507 ( z1139-07 ) "Про умови оплати праці працівників регіональних центрів інноваційного розвитку", зареєстрованого в Міністерстві юстиції України 03.10.2007 за N 1139/14406 (зі змінами), такі зміни:

у назві та по тексту наказу, у назві додатків до наказу слова "центрів інноваційного розвитку" замінити словами "центрів з інвестицій та розвитку".

2. Цей наказ набирає чинності з дня його офіційного опублікування.
