Питання оформлення документа, що дає право на спрощене перетинання іноземцями та особами без громадянства державного кордону України

Стан: Чинний

Ідентифікатор: 64-2008-п

Текст документа від 13.07.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 лютого 2008 р. N 64 Київ

Питання оформлення документа, що дає право на спрощене перетинання іноземцями та особами без громадянства державного кордону України

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 677 ( 677-2009-п ) від 01.07.2009 }

{ Із змінами, внесеними згідно з Постановою КМ N 677 ( 677-2009-п ) від 01.07.2009 }

Кабінет Міністрів України постановляє:

1. Запровадити оформлення документа, що дає право на спрощене перетинання іноземцями та особами без громадянства державного кордону України відповідно до міжнародних договорів України про правила місцевого прикордонного руху.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 677 ( 677-2009-п ) від 01.07.2009 }

{ Пункт 2 виключено на підставі Постанови КМ N 677 ( 677-2009-п ) від 01.07.2009 }

3. Установити, що порядок оформлення документа, що дає право на спрощене перетинання іноземцями та особами без громадянства державного кордону України здійснюється відповідно до Правил оформлення візових документів для в'їзду в Україну, затверджених постановою Кабінету Міністрів України від 20 лютого 1999 р. N 227 ( 227-99-п ) "Про запровадження нового порядку оформлення візових документів для в'їзду в Україну" (Офіційний вісник України, 1999 р., N 8, ст. 285), та з використанням візової етикетки, технічний опис зразка бланка якої затверджено постановою Кабінету Міністрів України від 8 листопада 1996 р. N 1363 ( 1363-96-п ).

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 677 ( 677-2009-п ) від 01.07.2009 }

4. Ця постанова набирає чинності з дня опублікування.
