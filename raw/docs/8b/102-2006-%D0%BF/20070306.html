Кабінет Міністрів України; Постанова від 02.02.2006 № 102

Про внесення змін до деяких постанов Кабінету Міністрів України з питань державної підтримки вугільної галузі

Стан: Чинний

Ідентифікатор: 102-2006-п

Текст документа від 06.03.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 лютого 2006 р. N 102 Київ

Про внесення змін до деяких постанов Кабінету Міністрів України з питань державної підтримки вугільної галузі

{ Із змінами, внесеними згідно з Постановою КМ N 378 ( 378-2007-п ) від 06.03.2007 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України з питань державної підтримки вугільної галузі зміни, що додаються.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 37

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 2 лютого 2006 р. N 102

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України з питань державної підтримки вугільної галузі

{ Пункт 1 втратив чинність на підставі Постанови КМ N 378 ( 378-2007-п ) від 06.03.2007 }

2. У постанові Кабінету Міністрів України від 10 серпня 2005 р. N 734 ( 734-2005-п ) "Про порядок використання у 2005 році коштів державного бюджету, що спрямовуються за програмою "Гірничорятувальні заходи на вугледобувних підприємствах" (Офіційний вісник України, 2005 р., N 32, ст. 1947):

у назві постанови слова та цифри "у 2005 році" виключити;

вступну частину та абзац перший постановляючої частини викласти у такій редакції:

"Кабінет Міністрів України постановляє:

Установити, що кошти, передбачені у державному бюджеті для проведення гірничорятувальних заходів на вугледобувних підприємствах, спрямовуються на";

доповнити постанову після абзацу п'ятого новим абзацом такого змісту:

"відшкодування безвідсоткової бюджетної позики, наданої для погашення заборгованості з виплати заробітної плати та компенсації за її несвоєчасну виплату".

У зв'язку з цим абзац шостий вважати абзацом сьомим.

3. У вступній частині постанови Кабінету Міністрів України від 18 серпня 2005 р. N 749 ( 749-2005-п ) "Про затвердження Порядку використання коштів, передбачених у державному бюджеті для реструктуризації вугільної та торфодобувної промисловості" (Офіційний вісник України, 2005 р., N 34, ст. 2032) слова та цифри "Відповідно до статті 27 Закону України "Про Державний бюджет України на 2005 рік" виключити.

4. У постанові Кабінету Міністрів України від 13 жовтня 2005 р. N 1014 ( 1014-2005-п ) "Про порядок використання коштів, передбачених у державному бюджеті для придбання компресорного та електротехнічного обладнання" (Офіційний вісник України, 2005 р., N 42, ст. 2655):

у вступній частині слова та цифри "Відповідно до статті 27 Закону України "Про Державний бюджет України на 2005 рік" виключити;

у першому реченні абзацу другого постановляючої частини слова та цифри "у 2005 році" виключити.

5. У постанові Кабінету Міністрів України від 13 жовтня 2005 р. N 1015 ( 1015-2005-п ) "Про порядок використання коштів, передбачених у державному бюджеті на придбання експериментальної партії азотно-мембранних станцій для гасіння пожеж на вугледобувних шахтах" (Офіційний вісник України, 2005 р., N 42, ст. 2656):

у вступній частині слова та цифри "Відповідно до статті 27 Закону України "Про Державний бюджет України на 2005 рік" виключити;

в абзаці першому постановляючої частини слова та цифри "у 2005 році" виключити.

6. У постанові Кабінету Міністрів України від 16 листопада 2005 р. N 1091 ( 1091-2005-п ) "Про затвердження Порядку використання коштів, передбачених у державному бюджеті для здійснення заходів щодо передачі об'єктів соціальної інфраструктури, які перебувають на балансі вугледобувних підприємств, у комунальну власність" (Офіційний вісник України, 2005 р., N 46, ст. 2889):

у вступній частині слова та цифри "Відповідно до статті 27 Закону України "Про Державний бюджет України на 2005 рік" виключити;

абзац перший пункту 1 Порядку, затвердженого зазначеною постановою, викласти у такій редакції:

"1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті для передачі об'єктів соціальної інфраструктури, які перебувають на балансі вугледобувних підприємств, у комунальну власність (далі - бюджетні кошти)".
