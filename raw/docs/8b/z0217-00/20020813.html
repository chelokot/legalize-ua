ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

N 116 від 22.03.2000 Зареєстровано в Міністерстві м.Київ юстиції України 7 квітня 2000 р. vd20000322 vn116 за N 217/4438

Про затвердження Положення про порядок здійснення установами банківської системи операцій на ринку облігацій внутрішньої державної позики

( Із змінами, внесеними згідно з Постановою Національного банку N 286 ( z0655-02 ) від 05.08.2002 )

У зв'язку з приведенням нормативних актів Національного банку України з питань функціонування ринку облігацій внутрішньої державної позики у відповідність до Закону України "Про Національний банк України" ( 679-14 ) та інших нормативно-правових актів України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити Положення про порядок здійснення установами банківської системи операцій на ринку облігацій внутрішньої державної позики (додається).

2. Уважати таким, що втратило чинність, Положення про порядок функціонування ринку облігацій внутрішньої державної позики ( v0350500-96 ), затверджене постановою Правління Національного банку України від 26.01.96 N 15 ( v0015500-96 ).

3. Контроль за виконанням цієї постанови покласти на Департамент монетарної політики, Кримське республіканське, територіальні та по м.Києву і Київській області управління Національного банку України.

4. Постанова набуває чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

Голова В.С.Стельмах

( Положення про порядок здійснення установами банківської системи операцій на ринку облігацій внутрішньої державної позики втратило чинність на підставі Постанови Національного банку N 286 ( z0655-02 ) від 05.08.2002 )
