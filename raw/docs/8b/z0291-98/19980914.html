N 235-а від 21.04.98 Зареєстровано в Міністерстві м.Київ юстиції України 7 травня 1998 р. vd980421 vn235-а за N 291/2731

Про деякі питання видачі документів дозвільного характеру на експорт товарів

( Із змінами, внесеними згідно з Наказом МЗЕЗторгу N 576а ( z0564-98 ) від 10.09.98 )

Відповідно до пункту 3 Положення про порядок реєстрації окремих видів зовнішньоекономічних договорів (контрактів), затвердженого Указом Президента України від 07.11.94 N 659/94 "Про облік окремих видів зовнішньоекономічних договорів (контрактів) в Україні", з метою безумовного виконання вимог наказу МЗЕЗторгу України від 27.07.96 N 467 ( z0412-96 ) "Про особливості укладання деяких видів угод суб'єктами зовнішньоекономічної діяльності у зв'язку із застосуванням спеціальних санкцій, передбачених статтею 37 Закону України "Про зовнішньоекономічну діяльність" ( 959-12 ), а також з метою виконання міжнародних угод НАКАЗУЮ:

1. Пункт 2.2 Положення про порядок оформлення та видачі ліцензій на експорт окремих категорій чорних металів та виробів з них до країн-членів Європейського Співтовариства з вугілля та сталі ( z0111-98 ), пункт 2.2 Положення про порядок оформлення та видачі ліцензій на експорт феросилікомарганцю походженням з України до США та до країн-членів Європейського Союзу ( z0109-98 ), пункт 2.2 Положення про порядок оформлення та видачі ліцензій на експорт окремих категорій текстильної продукції до країн-членів Європейського Союзу ( z0113-98 ), пункт 2.2 Положення про порядок оформлення та видачі ліцензій на експорт магнію походженням з України до країн-членів Європейського Союзу ( z0116-98 ) (затверджених наказом МЗЕЗторгу України від 23.01.98 N 42 ( z0108-98 ) "Про заходи МЗЕЗторгу України щодо виконання вимог постанови Кабінету Міністрів України від 05.01.98 N 7) після абзацу шостого доповнити абзацом сьомим такого змісту:

"- завірені керівником підприємства копії договорів, на підставі яких вони отримали ці товари, що поставляються на експорт (крім підприємств - виробників цих товарів)".

Абзаци сьомий, восьмий цього пункту вважати відповідно восьмим і дев'ятим.

( Пункт 2 вилучено на підставі Наказу МЗЕЗторгу N 576а ( z0564-98 ) від 10.09.98 ) 2. Встановити, що при подачі документів для здійснення обліку (реєстрації) зовнішньоекономічних договорів до них необхідно додавати завірені керівником підприємства копії договорів, на підставі яких вони отримали товари, що поставляються на експорт (крім підприємств - виробників цих товарів).

3. Управлінню правового забезпечення (Сервінський А.Ю.) забезпечити реєстрацію цього наказу в Міністерстві юстиції України.

4. Управлінню інформаційних мереж та технічного захисту інформації (Сторожук Є.Л.) довести цей наказ до відома регіональних управлінь ЗЕЗ у дводенний термін після реєстрації його в Міністерстві юстиції України.

5. Управлінню справами (Дробний В.В.) забезпечити публікацію цього наказу у засобах масової інформації у дводенний термін після його державної реєстрації в Міністерстві юстиції.

6. Контроль за виконанням цього наказу покласти на заступника міністра Олійника В.І.
