КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 квітня 2009 р. N 367 Київ

Про затвердження Порядку використання у 2009 році коштів, передбачених у державному бюджеті для забезпечення службовим житлом молодих спеціалістів державних підприємств космічної галузі

{ Із змінами, внесеними згідно з Постановою КМ N 1265 ( 1265-2009-п ) від 25.11.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) для забезпечення службовим житлом молодих спеціалістів державних підприємств космічної галузі, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 10 квітня 2009 р. N 367

ПОРЯДОК використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) для забезпечення службовим житлом молодих спеціалістів державних підприємств космічної галузі

1. Цей Порядок визначає механізм використання у 2009 році коштів, передбачених НКАУ у державному бюджеті ( 835-17 ) за програмою "Забезпечення службовим житлом молодих спеціалістів державних підприємств космічної галузі" (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються на будівництво житла на умовах пайової участі та придбання житла на вторинному ринку. { Пункт 2 в редакції Постанови КМ N 1265 ( 1265-2009-п ) від 25.11.2009 }

3. Договір про будівництво житла на умовах пайової участі складається щодо об'єкта незавершеного будівництва із ступенем готовності більш як 70 відсотків, який відповідно до титулу будови передбачається ввести в експлуатацію у 2009 році.

{ Пункт 3 в редакції Постанови КМ N 1265 ( 1265-2009-п ) від 25.11.2009 }

4. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

5. Вартість 1 кв. метра загальної площі житла, що будується на умовах пайової участі, не повинна перевищувати опосередковану вартість його будівництва, визначену Мінрегіонбудом.

{ Пункт 5 в редакції Постанови КМ N 1265 ( 1265-2009-п ) від 25.11.2009 }

6. Придбання житла на вторинному ринку здійснює головний розпорядник бюджетних коштів за результатами проведення відкритих торгів. При цьому вартість 1 кв. метра загальної площі житла визначається виходячи з найменшої ціни, яка склалася у регіоні, та повинна бути найнижчою з пропозицій, що надійшли від учасників торгів.

Видатки, пов'язані з придбанням житла на вторинному ринку, здійснюються на підставі договору купівлі-продажу житла, рішення власника житла про його продаж (якщо учасник процедури закупівлі є представником власника житла).

Під час визначення загальної вартості придбаного житла враховуються витрати, пов'язані з переоформленням права власності та сплатою передбачених законодавством податків і зборів (обов'язкових платежів).

Попередня оплата за договорами про придбання житла на вторинному ринку здійснюється у розмірі до 90 відсотків його вартості згідно з графіком фінансування на строк не більше одного місяця. { Пункт 6 доповнено абзацом згідно з Постановою КМ N 1265 ( 1265-2009-п ) від 25.11.2009 }

7. Операції, пов'язані з використанням бюджетних коштів, проводяться у порядку, встановленому Державним казначейством.

8. Побудоване та придбане житло використовується як службове в установленому законодавством порядку.

9. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
