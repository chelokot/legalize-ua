КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 серпня 1993 р. N 656 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про призначення Черненка Д.О. головою Української частини Постійної українсько-баварської робочої комісії

Кабінет Міністрів України постановляє:

1. Призначити Міністра машинобудування, військово-промислового комплексу і конверсії України Черненка Дмитра Олексійовича головою Української частини Постійної українсько-баварської робочої комісії.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 13 березня 1992 р. N 127 ( 127-92-п ).
