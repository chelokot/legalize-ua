{ Наказ втратив чинність на підставі Наказу Міністерства оборони N 164 ( z0386-06 ) від 30.03.2006 }

Про внесення змін до наказу Міністра оборони України від 28.02.2000 N 55

Відповідно до постанови Кабінету Міністрів України від 13 грудня 1999 року N 2288 ( 2288-99-п ) "Про впорядкування умов оплати праці працівників апарату органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів" (зі змінами та доповненнями) НАКАЗУЮ:

1. У першому абзаці таблиці 4 додатка 1 до пункту 2 Умов оплати праці працівників (невійськовослужбовців) апарату органів військового управління та військових комісаріатів, затверджених наказом Міністра оборони України від 28 лютого 2000 року N 55 ( z0123-00 ) "Про затвердження умов оплати праці працівників (невійськовослужбовців) апарату органів військового управління та військових комісаріатів", зареєстрованим у Міністерстві юстиції України 2 березня 2000 року за N 123/4344, слова "Начальник відділу, самостійного відділення (групи) у складі військового комісаріату" замінити словами "Начальник відділу, самостійного відділення (групи, частини) у складі військового комісаріату".

2. Наказ розіслати згідно з розрахунком розсилки.

Міністр оборони України генерал армії України В.П.Шкідченко
