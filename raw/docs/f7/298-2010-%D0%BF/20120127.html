Про заходи щодо удосконалення системи управління підготовкою та проведенням в Україні фінальної частини чемпіонату Європи 2012 року з футболу

Ідентифікатор: 298-2010-п

Текст документа від 27.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 квітня 2010 р. N 298 Київ

Про заходи щодо удосконалення системи управління підготовкою та проведенням в Україні фінальної частини чемпіонату Європи 2012 року з футболу

{ Із змінами, внесеними згідно з Постановами КМ N 355 ( 355-2010-п ) від 19.05.2010 N 517 ( 517-2010-п ) від 30.06.2010 N 871 ( 871-2010-п ) від 15.09.2010 N 937 ( 937-2011-п ) від 07.09.2011 N 32 ( 32-2012-п ) від 23.01.2012 }

З метою удосконалення системи управління підготовкою та проведенням в Україні чемпіонату Європи 2012 року з футболу, забезпечення цільового і ефективного використання коштів, що виділяються з державного бюджету для підготовки та проведення чемпіонату, Кабінет Міністрів України постановляє:

1. На час здійснення заходів, пов'язаних з підготовкою та проведенням в Україні фінальної частини чемпіонату Європи 2012 року з футболу, утворити:

Управління з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу у структурі Секретаріату Кабінету Міністрів України, ліквідувавши Координаційне бюро з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу;

Національне агентство з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу та реалізації інфраструктурних проектів (далі - Агентство) як центральний орган виконавчої влади, діяльність якого спрямовується і координується Кабінетом Міністрів України через Віце-прем'єр-міністра України. { Абзац третій пункту 1 із змінами, внесеними згідно з Постановою КМ N 871 ( 871-2010-п ) від 15.09.2010 }

{ Пункт 2 виключено на підставі Постанови КМ N 32 ( 32-2012-п ) від 23.01.2012 }

{ Пункт 3 втратив чинність на підставі Постанови КМ N 937 ( 937-2011-п ) від 07.09.2011 }

4. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

5. Міністерству фінансів передбачити у проекті Закону України "Про Державний бюджет України на 2010 рік" видатки на утримання Агентства та виконання Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу.

6. Дозволити розміщення Агентства на умовах договору оренди у будівлі (літер А) по вул. Хотівській, 4, у м. Києві за рахунок відповідних бюджетних призначень, передбачених у державному бюджеті.
