Національний банк; Постанова від 02.06.2008 № 152

Про встановлення часу функціонування Системи підтвердження угод на міжбанківському валютному ринку України Національного банку України та зміну терміну подання заявки на участь у цій Системі

Стан: Втратив чинність

Ідентифікатор: v0152500-08

Текст документа від 28.12.2010:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

02.06.2008 N 152

Про встановлення часу функціонування Системи підтвердження угод на міжбанківському валютному ринку України Національного банку України та зміну терміну подання заявки на участь у цій Системі

{ Із змінами, внесеними згідно з Постановою Національного банку

N 545 ( v_545500-10 ) від 14.12.2010 }

Відповідно до статей 44 і 45 Закону України "Про Національний банк України" ( 679-14 ), розділів II і III Декрету Кабінету Міністрів України від 19.02.93 N 15-93 ( 15-93 ) "Про систему валютного регулювання і валютного контролю" та з метою подальшого впорядкування операцій суб'єктів ринку з купівлі-продажу іноземної валюти та банківських металів на міжбанківському валютному ринку України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Установити час функціонування Системи підтвердження угод на міжбанківському валютному ринку України Національного банку України (далі - Система підтвердження угод) з 10.00 до 17.00 за київським часом у робочі дні.

Уповноважені банки (уповноважені фінансові установи) здійснюють операції в межах самого уповноваженого банку (уповноваженої фінансової установи) з 10.00 до 14.00 за київським часом. { Пункт 1 доповнено абзацом згідно з Постановою Національного банку N 545 ( v_545500-10 ) від 14.12.2010 }

Уповноважені банки (уповноважені фінансові установи) здійснюють операції між собою з 10.00 до 17.00 за київським часом. { Пункт 1 доповнено абзацом згідно з Постановою Національного банку N 545 ( v_545500-10 ) від 14.12.2010 }

2. Установити, що заявки на участь у Системі підтвердження угод уповноважені банки (уповноважені фінансові установи) мають подавати до Національного банку України в день функціонування Системи підтвердження угод до 17.00 за київським часом.

Уповноважені банки подають розгорнуту заявку (для проведення операцій з купівлі-продажу безготівкової іноземної валюти з Національним банком України) до Національного банку України до 15.00 за київським часом. { Пункт 2 доповнено абзацом згідно з Постановою Національного банку N 545 ( v_545500-10 ) від 14.12.2010 }

{ Пункт 2 із змінами, внесеними згідно з Постановою Національного банку N 545 ( v_545500-10 ) від 14.12.2010}

3. Визнати такими, що втратили чинність, пункти 1 та 2 постанови Правління Національного банку України від 10.02.2005 N 40 "Про встановлення часу проведення Торговельної сесії та зміну терміну подання заявки на участь у Торговельній сесії".

4. Департаменту валютного регулювання (О.А.Щербакова) довести зміст цієї постанови до відома банків для використання в роботі.

5. Контроль за виконанням цієї постанови покласти на Департамент валютного регулювання (О.А.Щербакова) та Департамент з управління валютним резервом та здійснення операцій на відкритому ринку (М.О.Мельничук).

6. Постанова набирає чинності з 4 листопада 2008 року.

Голова В.С.Стельмах
