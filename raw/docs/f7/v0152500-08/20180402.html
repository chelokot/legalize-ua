Національний банк; Постанова від 02.06.2008 № 152

Про встановлення часу функціонування Системи підтвердження угод на міжбанківському валютному ринку України Національного банку України та зміну терміну подання заявки на участь у цій Системі

Стан: Втратив чинність

Ідентифікатор: v0152500-08

Текст документа від 02.04.2018:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

02.06.2008 N 152

Про встановлення часу функціонування Системи підтвердження угод на міжбанківському валютному ринку України Національного банку України та зміну терміну подання заявки на участь у цій Системі

{ Із змінами, внесеними згідно з Постановами Національного банку

N 545 ( v_545500-10 ) від 14.12.2010

N 45 ( v_045500-11 ) від 25.02.2011

N 703 ( v0703500-14 ) від 03.11.2014 Рішенням Національного банку

N 185-рш ( vr185500-18 ) від 29.03.2018 }

Відповідно до статей 44 і 45 Закону України "Про Національний банк України" ( 679-14 ), розділів II і III Декрету Кабінету Міністрів України від 19.02.93 N 15-93 ( 15-93 ) "Про систему валютного регулювання і валютного контролю" та з метою подальшого впорядкування операцій суб'єктів ринку з купівлі-продажу іноземної валюти та банківських металів на міжбанківському валютному ринку України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Установити час функціонування Системи підтвердження угод на міжбанківському валютному ринку України Національного банку України (далі - Система підтвердження угод) у робочі дні:

{ Абзац другий пункту 1 виключено на підставі Рішення Національного банку N 185-рш ( vr185500-18 ) від 29.03.2018 }

у п'ятницю та передсвяткові дні - з 9.00 до 16.00 за київським часом. { Абзац третій пункту 1 із змінами, внесеними згідно з Постановою Національного банку N 703 ( v0703500-14 ) від 03.11.2014 }

Уповноважені банки (уповноважені фінансові установи) здійснюють операції з купівлі, продажу іноземної валюти та/або банківських металів за гривні в межах самого уповноваженого банку (уповноваженої фінансової установи), а також між собою протягом часу функціонування Системи підтвердження угод.

{ Пункт 1 в редакції Постанови Національного банку N 45 ( v_045500-11 ) від 25.02.2011 }

2. Національний банк України встановлює час подачі уповноваженими банками заявок на участь у Системі підтвердження угод до Національного банку України в повідомленні про здійснення валютної інтервенції, яке надсилається уповноваженим банкам засобами електронної пошти Національного банку України.

{ Пункт 2 із змінами, внесеними згідно з Постановою Національного банку N 545 ( v_545500-10 ) від 14.12.2010; в редакції Рішення Національного банку N 185-рш ( vr185500-18 ) від 29.03.2018 }

3. Визнати такими, що втратили чинність, пункти 1 та 2 постанови Правління Національного банку України від 10.02.2005 N 40 "Про встановлення часу проведення Торговельної сесії та зміну терміну подання заявки на участь у Торговельній сесії".

4. Департаменту валютного регулювання (О.А.Щербакова) довести зміст цієї постанови до відома банків для використання в роботі.

5. Контроль за виконанням цієї постанови покласти на Генеральний департамент грошово-кредитної політики (О.А.Щербакова) та Департамент з управління валютним резервом та здійснення операцій на відкритому ринку (О.А.Дубихвіст).

{ Пункт 5 в редакції Постанови Національного банку N 45 ( v_045500-11 ) від 25.02.2011 }

6. Постанова набирає чинності з 4 листопада 2008 року.

Голова В.С.Стельмах
