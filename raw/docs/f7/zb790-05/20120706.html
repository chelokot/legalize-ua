Реєстрація: Мін'юст України від 22.07.2005 № 790/11070

Стан: Втратив чинність

Ідентифікатор: zb790-05

Текст документа від 06.07.2012:

ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

07.07.2005 N 374

Зареєстровано в Міністерстві юстиції України 22 липня 2005 р. за N 790/11070

{ Рішення втратило чинність на підставі Рішення Національної комісії з цінних паперів та фондового ринку N 674 ( zb940-12 ) від 10.05.2012 }

Про затвердження Змін та доповнень до Положення про порядок проведення конкурсів з продажу пакетів акцій акціонерних товариств

Відповідно до пункту 16 статті 7 Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ), з метою забезпечення виконання абзацу другого пункту 3 розпорядження Кабінету Міністрів України від 23.06.2005 N 215-р ( 215-2005-р ) "Про заходи, пов'язані з підготовкою до продажу пакета акцій ВАТ "Криворіжсталь" та на підставі документів, наданих до Державної комісії з цінних паперів та фондового ринку листом Фонду державного майна України від 25.06.2005 N 10-33-9372, Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Зміни та доповнення ( z0790-05 ) до Положення про порядок проведення конкурсів з продажу пакетів акцій акціонерних товариств, затвердженого наказом Фонду державного майна України від 31.08.2004 N 1800 ( z1634-04 ), розпорядженням Антимонопольного комітету України від 31.08.2004 N 330-р ( za634-04 ), рішенням Державної комісії з цінних паперів та фондового ринку від 17.11.2004 N 489 ( zb634-04 ), зареєстрованого в Міністерстві юстиції України 23.12.2004 за N 1634/10233, надані на розгляд до Державної комісії з цінних паперів та фондового ринку листом Фонду державного майна України від 25.06.2005 N 10-33-9372.

2. Керівнику апарату Державної комісії з цінних паперів та фондового ринку М. Непрану поінформувати Фонд державного майна України про прийняте рішення.

3. Контроль за виконанням цього рішення покласти на Керівника апарату Державної комісії з цінних паперів та фондового ринку М. Непрана.

Голова Комісії А. Балюк

Протокол засідання Комісії від 7 липня 2005 року N 24
