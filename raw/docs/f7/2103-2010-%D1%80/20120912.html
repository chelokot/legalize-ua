РОЗПОРЯДЖЕННЯ від 17 листопада 2010 р. N 2103-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 667-р ( 667-2012-р ) від 12.09.2012 }

Про зміну складу Української частини Спільного комітету з питань реадмісії

Ввести до складу Української частини Спільного комітету з питань реадмісії, утвореної розпорядженням Кабінету Міністрів України від 2 квітня 2008 р. N 557 ( 557-2008-р ) - із зміною, внесеною розпорядженням Кабінету Міністрів України від 26 листопада 2008 р. N 1481 ( 1481-2008-р ), Ворону Дмитра Миколайовича - заступника Міністра внутрішніх справ як голову Української частини зазначеного Комітету, вивівши з її складу Мармазова Василя Євгеновича - заступника Міністра внутрішніх справ.

Прем'єр-міністр України М.АЗАРОВ
