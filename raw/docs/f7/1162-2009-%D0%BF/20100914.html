Про внесення змін до постанови Кабінету Міністрів України від 30 жовтня 2009 р. N 1152

Текст документа від 14.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 листопада 2009 р. N 1162 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 819 ( 819-2010-п ) від 08.09.2010 }

Про внесення змін до постанови Кабінету Міністрів України від 30 жовтня 2009 р. N 1152

{ Із змінами, внесеними згідно з Постановою КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 30 жовтня 2009 р. N 1152 ( 1152-2009-п ) "Про запобігання поширенню грипу типу А/H1N1/ Каліфорнія/04/09 і гострих респіраторних захворювань серед населення" такі зміни:

пункт 5 доповнити абзацом такого змісту:

"включати до переліку витрат, пов'язаних із запобіганням поширенню пандемічного грипу та інших гострих респіраторних захворювань серед населення, витрати, які здійснюються закладами охорони здоров'я, що фінансуються за рахунок державного та місцевих бюджетів, та в установленому порядку перераховувати кошти на зазначену мету за рахунок коштів, що виділені Міністерству охорони здоров'я для фінансування невідкладних заходів, спрямованих на запобігання поширенню інфекційних захворювань серед населення.";

у пункті 6:

{ Абзац п'ятий постановляючої частини втратив чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

доповнити пункт абзацом такого змісту:

{ Абзац сьомий постановляючої частини втратив чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }
