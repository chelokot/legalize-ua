Інд. 19

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 5 серпня 2009 р. N 816

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

Слова "Українська Академія" в усіх відмінках замінити словами "Національна академія" у відповідному відмінку:

{ Абзац другий втратив чинність на підставі Постанови КМ N 229 ( 229-2016-п ) від 25.03.2016 }

у назві, вступній частині та пункті 1 постанови Кабінету Міністрів України від 31 серпня 1995 р. N 700 ( 700-95-п ) "Про віднесення посад працівників Української Академії державного управління при Президентові України до категорій посад державних службовців та умови оплати їх праці" - із змінами, внесеними постановою Кабінету Міністрів України від 24 січня 2002 р. N 70 ( 70-2002-п ) (Офіційний вісник України, 2002 р., N 4, ст. 134);

у пунктах 3 і 4 постанови Кабінету Міністрів України від 8 лютого 2000 р. N 251 ( 251-2000-п ) "Про заходи щодо підвищення кваліфікації керівників і спеціалістів центральних та місцевих органів виконавчої влади, органів місцевого самоврядування з питань національної безпеки та оборони держави" (Офіційний вісник України, 2000 р., N 6, ст. 222, N 40, ст. 1705; 2002 р., N 47, ст. 2137) та абзаці другому пункту 4 Положення ( 251-2000-п ), затвердженого цією постановою.
