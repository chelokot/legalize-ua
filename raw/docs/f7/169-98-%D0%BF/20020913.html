Текст документа від 13.09.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 лютого 1998 р. N 169 Київ

Про створення Національної комісії України із зводу харчових продуктів Кодекс аліментаріус

( Із змінами, внесеними згідно з Постановами КМ N 1371 ( 1371-2002-п ) від 13.09.2002 )

Кабінет Міністрів України постановляє:

1. Створити на громадських засадах Національну комісію України із зводу харчових продуктів Кодекс аліментаріус з представників Міністерства агропромислового комплексу, Міністерства охорони здоров'я і Державного комітету по стандартизації, метрології та сертифікації.

2. Міністерству агропромислового комплексу, Міністерству охорони здоров'я і Державному комітетові по стандартизації, метрології та сертифікації розробити та подати у двомісячний термін до Кабінету Міністрів України проект Положення про Національну комісію України із зводу харчових продуктів Кодекс аліментаріус та її персональний склад.

( Пункт 3 втратив чинність на підставі Постанови КМ N 1371 ( 1371-2002-п ) від 13.09.2002 )
