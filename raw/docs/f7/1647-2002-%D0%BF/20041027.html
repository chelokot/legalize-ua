ПОСТАНОВА від 1 листопада 2002 р. N 1647 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1191 ( 1191-2004-п ) від 08.09.2004 )

Про внесення зміни до Правил ввезення транспортних засобів на територію України

Кабінет Міністрів України постановляє:

Пункт 7 Правил ввезення транспортних засобів на територію України, затверджених постановою Кабінету Міністрів України від 31 травня 1994 р. N 341 ( 341-94-п ) (ЗП України, 1994 р., N 9, ст. 227; 1995 р., N 4, ст. 109; 1996 р., N 3, ст. 107; Офіційний вісник України, 1998 р., N 7, ст. 246, N 27, ст. 996; 2000 р., N 6, ст. 211, N 13, ст. 524), доповнити абзацом такого змісту:

"Ввезення на територію України для постійного використання механічних транспортних засобів, виготовлених 8 і більше років тому, у випадках, не передбачених цим пунктом, здійснюється за рішенням Кабінету Міністрів України".

Прем'єр-міністр України А.КІНАХ
