РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 22 лютого 1991 р. N 36

( Постанова втратила чинність на підставі Постанови КМ N 136 ( 136-92-п ) від 17.03.92 )

Про призначення т. Удовенка Г.Й. заступником Міністру закордонних справ УРСР

Рада Міністрів Української РСР постановляє:

1. Встановити посаду заступника Міністра закордонних справ УРСР.

2. Призначити Постійного представника УРСР при ООН т. Удовенка Геннадія Йосиповича заступником Міністра закордонних справ УРСР.
