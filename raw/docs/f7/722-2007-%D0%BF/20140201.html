Про заходи щодо підвищення рівня безпеки на морському та річковому транспорті

Стан: Чинний

Текст документа від 01.02.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 травня 2007 р. N 722 Київ

Про заходи щодо підвищення рівня безпеки на морському та річковому транспорті

{ Із змінами, внесеними згідно з Постановою КМ N 25 ( 25-2014-п ) від 22.01.2014 }

Кабінет Міністрів України постановляє:

1. Установити, що відповідно до глави XI-2 Міжнародної конвенції з охорони людського життя на морі (СОЛАС) ( 995_251 ) та Міжнародного кодексу з охорони суден та портових засобів ( 896_035 ) Міністерство інфраструктури є Призначеним органом.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 25 ( 25-2014-п ) від 22.01.2014 }

2. Призначити визнаними організаціями у сфері охорони суден та портових засобів на морі державне підприємство "Класифікаційне товариство Регістр судноплавства України" та державне підприємство "Адміністрація морських портів України".

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 25 ( 25-2014-п ) від 22.01.2014 }

3. Міністерству транспорту та зв'язку:

подати у тримісячний строк пропозиції щодо приведення актів Кабінету Міністрів України у відповідність із цією постановою;

привести власні нормативно-правові акти у відповідність із цією постановою.

Прем'єр-міністр України В.ЯНУКОВИЧ
