МЗС України, Держкоммолодьспорттуризм; Наказ від 15.11.2000 № 183/2241

Про визнання таким, що втратив чинність, наказу МЗС і Держкомтуризму від 25.10.99 N 183/48 "Про порядок підтвердження туристичного характеру поїздки іноземців з країн, у яких діють представництва Державного комітету України по туризму, та про внесення доповнень до Положення про порядок видачі референсу суб'єктам туристичної діяльності України, затвердженого спільним наказом МЗС та Держкомтуризму від 25.12.96 N 164-09/61"

МІНІСТЕРСТВО ЗАКОРДОННИХ СПРАВ УКРАЇНИ ДЕРЖАВНИЙ КОМІТЕТ МОЛОДІЖНОЇ ПОЛІТИКИ, СПОРТУ І ТУРИЗМУ УКРАЇНИ

N 183/2241 від 15.11.2000 Зареєстровано в Міністерстві м.Київ юстиції України 22 листопада 2000 р. N 852/5073

{ Наказ втратив чинність на підставі Наказу Міністерства закордонних справ N 65/916 ( z0384-01 ) від 09.04.2001 }

Про визнання таким, що втратив чинність, наказу МЗС і

Держкомтуризму від 25.10.99 N 183/48 "Про порядок

підтвердження туристичного характеру поїздки

іноземців з країн, у яких діють представництва

Державного комітету України по туризму, та про

внесення доповнень до Положення про порядок видачі

референсу суб'єктам туристичної діяльності України,

затвердженого спільним наказом МЗС та Держкомтуризму від 25.12.96 N 164-09/61"

З метою приведення у відповідність до чинного законодавства та враховуючи висновки Держкомпідприємництва від 30.12.99 N 17-56/12, Антимонопольного комітету України від 28.01.2000 N 23.29.1/01-369, Головдержслужби від 27.01.2000 N 30/400, НАКАЗУЄМО:

1. Визнати таким, що втратив чинність, наказ Міністерства закордонних справ України та Державного комітету України по туризму від 25.10.99 N 183/48 ( z0778-99 ) "Про порядок підтвердження туристичного характеру поїздки іноземців з країн, у яких діють представництва Державного комітету України по туризму, та про внесення доповнень до Положення про порядок видачі референсу суб'єктам туристичної діяльності України, затвердженого спільним наказом Міністерства закордонних справ України та Державного комітету України по туризму від 25.12.96 N 164-09/61", зареєстрований в Міністерстві юстиції України 11.11.99 за N 778/4071.

2. Звернути увагу начальників департаментів та управлінь на необхідність суворого дотримання норм чинного законодавства при підготовці нормативно-правових актів.

3. Управлінню нормативно-правового та кадрового забезпечення Держкоммолодьспорттуризму подати цей наказ у встановленому законом порядку на державну реєстрацію до Міністерства юстиції України.
