Про встановлення строку виконання робіт з ремонту та модернізації компресорного обладнання за межами митної території України

Стан: Втратив чинність

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 червня 2008 р. N 868-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання робіт з ремонту та модернізації компресорного обладнання за межами митної території України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 830-р ( 830-2009-р ) від 17.07.2009 }

1. Відповідно до статті 240 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити строк виконання робіт з ремонту та модернізації компресорного обладнання (компресора у комплекті з редуктором) за кодом згідно з УКТЗЕД 8414 80 60 90 ( 2371г-14 ) за межами митної території України 270 днів, а обладнання (турбокомпресорів багатоступінчастих) за кодом згідно з УКТЗЕД 8414 80 29 00 ( 2371г-14 ) - 180 днів.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 830-р ( 830-2009-р ) від 17.07.2009 }

2. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України Ю.ТИМОШЕНКО
