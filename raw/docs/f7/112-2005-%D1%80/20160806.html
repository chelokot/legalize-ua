Стан: Втратив чинність

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 квітня 2005 р. N 112-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Про віднесення деяких посад до першої та другої категорій посад державних службовців

{ Розпорядження втратило чинність у частині віднесення посад перших помічників та заступників керівників служб Першого віце-прем'єр-міністра України та віце-прем'єр-міністрів України до другої категорії посад державних службовців на підставі Постанови КМ N 654 ( 654-2013-п ) від 28.08.2013 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади заступників Міністра Кабінету Міністрів України до першої категорії, перших помічників та заступників керівників служб Першого віце-прем'єр-міністра України та віце-прем'єр-міністрів України - до другої категорії посад державних службовців.

Прем'єр-міністр України Ю.ТИМОШЕНКО
