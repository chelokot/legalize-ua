КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 лютого 1996 р. N 247 Київ

Про склад Урядової комісії з експортного контролю

( Із змінами, внесеними згідно з Постановами КМ N 554 ( 554-96-п ) від 22.05.96 N 1255 ( 1255-96-п ) від 17.10.96 )

Кабінет Міністрів України постановляє:

1. Затвердити склад Урядової комісії з експортного контролю, що додається. ( Склад Урядової комісії змінено згідно з Постановою КМ N 554 ( 554-96-п ) від 22.05.96 )

2. Визнати таким, що втратив чинність, абзац другий пункту 1 постанови Кабінету Міністрів України від 4 березня 1993 р. N 160 ( 160-93-п ) щодо затвердження персонального складу Урядової комісії з експортного контролю.
