Текст документа від 18.03.2002:

ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

ПОСТАНОВА

N 563 від 18.03.2002 м. Київ

Про внесення змін до постанови Центральної виборчої комісії від 11 березня 2002 року N 470 "Про Порядок передачі виборчим комісіям виборчих бюлетенів для голосування в багатомандатному загальнодержавному та одномандатних виборчих округах по виборах народних депутатів України"

Відповідно до статті 64 Закону України "Про вибори народних депутатів України" ( 2766-14 ) та керуючись статтями 11, 12 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ), Центральна виборча комісія постановляє:

1. У додатку 3 до постанови Центральної виборчої комісії від 11 березня 2002 року N 470 ( v0470359-02 ) "Про Порядок передачі виборчим комісіям виборчих бюлетенів для голосування в багатомандатному загальнодержавному та одномандатних виборчих округах по виборах народних депутатів України" назву протоколу після слів "для голосування у багатомандатному загальнодержавному" доповнити словами "виборчому окрузі".

2. Цю постанову надіслати окружним виборчим комісіям по виборах народних депутатів України.
