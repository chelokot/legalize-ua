Кабінет Міністрів України; Розпорядження від 31.12.1999 № 1471-р

Про митне оформлення технологічного обладнання для монолітного бетонування, що надійшло на адресу концерну "Укрмонолітспецбуд"

Стан: Втратив чинність

Ідентифікатор: 1471-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 грудня 1999 р. N 1471-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Держмитслужбі здійснити митне оформлення технологічного обладнання для монолітного бетонування, що надійшло на адресу концерну "Укрмонолітспецбуд" (м. Київ) для власних виробничих потреб за договором оренди від 16 листопада 1998 р. N ДЕМ-1/А, укладеним з фірмою "Demir Eurusiam Investments Limited" (м. Тортола, Віргінські острови, Великобританія), як товарів критичного імпорту.

Прем'єр-міністр України В.ЮЩЕНКО
