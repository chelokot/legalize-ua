Зареєстровано в Міністерстві юстиції України 2 вересня 1997 р. за N 371/2175

Порядок цільового кредитування приватизованих підприємств

Цей Порядок розроблено відповідно до Закону України "Про приватизацію державного майна" ( 2163-12 ), Закону України "Про Державну програму приватизації" ( 294/97-ВР ) з метою забезпечення цільового кредитування технічного переозброєння і післяприватизаційної фінансової підтримки приватизованих підприємств через банківську систему України за рахунок коштів Державного позабюджетного фонду приватизації.

1. Цільове кредитування технічного переозброєння, реконструкції та післяприватизаційної підтримки приватизованих підприємств здійснюється Фондом державного майна України (надалі - Фонд) на термін до п'яти років через уповноважені комерційні банки на умовах забезпеченості, повернення, платності та цільового характеру використання.

2. Джерелом кредитування є кошти Державного позабюджетного фонду приватизації в частині, яка, у відповідності з Державною програмою приватизації на відповідний рік, призначена для надання цільових кредитів підприємствам у порядку їх рефінансування.

3. Приватизоване підприємство, яке може отримати кредит за рахунок коштів Державного позабюджетного фонду приватизації (надалі - підприємство) - це підприємство, за яким завершено виконання плану приватизації, а також ВАТ, у статутному фонді якого державна частка не перевищує 25 відсотків плюс одна акція. ( Пункт 3 в редакції Постанови Національного банку N 236 ( z0436-98 ) від 18.06.98 )

4. Розмір плати за кредит встановлюється на рівні облікової ставки Національного банку України.

5. Загальний обсяг кредиту, наданого Фондом, не може перевищувати 100 відсотків коштів, що надійшли до Державного позабюджетного фонду приватизації від продажу майна відповідного підприємства, незалежно від його вартості.

( Пункт 5 в редакції Постанови Національного банку N 236 ( z0436-98 ) від 18.06.98 )

6. Для отримання цільових кредитів підприємства-претенденти подають до Фонду такі документи:

- заяву на отримання кредиту із зазначенням обсягів, цілей його використання та пропонованих умов повернення;

- копії установчих документів;

- довідку комерційного банку про залишок коштів на рахунку підприємства та наявність заборгованості за раніше отриманими позиками;

- довідку органу Державної податкової адміністрації про своєчасність сплати податків;

- баланс (копію) на останню звітну дату, засвідчений податковою інспекцією;

- висновки останньої аудиторської перевірки фінансового стану підприємства;

- техніко-економічне обгрунтування використання кредиту у вигляді бізнес-плану;

- перелік майна, яке віддається під заставу і знаходиться у приватній власності;

- інші необхідні документи для уточнення наданої інформації за вимогою Фонду.

7. Порядок проведення експертизи наданих документів, критерії відбору підприємств-позичальників визначаються окремим Положенням, яке затверджується Фондом.

8. Після експертизи наданих документів Фонд повідомляє підприємства-претенденти про згоду та умови кредитування, перелік уповноважених комерційних банків, які на підставі вивчення кредитоспроможності позичальників, здійснюють кредитування за дорученням Фонду.

9. Уповноважені комерційні банки визначаються Фондом на конкурсній основі відповідно до Положення, яке затверджується Фондом. З метою забезпечення цільового використання коштів Державного позабюджетного фонду приватизації та своєчасного їх повернення між уповноваженими комерційними банками та Фондом укладаються відповідні угоди.

10. Підприємство після отримання повідомлення Фонду про включення його до списків підприємств-позичальників звертається до уповноваженого комерційного банку для здійснення кредитування у визначених Фондом розмірах.

11. Комерційні банки після вивчення кредитоспроможності підприємств-позичальників мають право відмовитись від укладення договору кредитування, якщо позичальник не має достатнього забезпечення гарантій повернення кредиту.

12. Згода уповноваженого комерційного банку є підставою для Фонду на укладення угоди з комерційним банком і перерахування коштів Державного позабюджетного фонду приватизації у визначених обсягах.

13. Кошти для цільового кредитування акумулюються на балансовому рахунку N 2560 "Позабюджетні рахунки Державного

позабюджетного фонду приватизації" Фонду державного майна України в комерційному банку, уповноваженому Фондом накопичувати і розподіляти кошти Державного позабюджетного фонду приватизації. ( Пункт 13 із змінами, внесеними згідно з Постановою Національного банку N 236 ( z0436-98 ) від 18.06.98 )

14. Для кредитування підприємств-позичальників Фонд перераховує кошти з балансового рахунка N 2560 на балансовий рахунок N 2565 "Кошти Державного позабюджетного фонду приватизації для цільового кредитування приватизованих підприємств".

( Пункт 14 із змінами, внесеними згідно з Постановою Національного банку N 236 ( z0436-98 ) від 18.06.98 )

15. Після отримання коштів для кредитування відповідно до цього Порядку між уповноваженим комерційним банком і підприємством-позичальником укладається договір кредитування.

16. Для забезпечення гарантії повернення кредиту та відсотків за його користування між уповноваженим комерційним банком та підприємством-позичальником укладається договір застави. Предметом застави виступають ліквідні активи позичальника. Вартість заставленого майна повинна покривати суму основного боргу та відсотків за його користування, а також відшкодування витрат у разі необхідності реалізації застави.

17. Кредитування підприємств-позичальників здійснюється комерційним банком з балансового рахунка N 2567 "Кредити, що надані приватизованим підприємствам за рахунок коштів Державного позабюджетного фонду приватизації" в межах коштів, що заакумульовані на балансовому рахунку N 2565. Підставою для видачі є платіжне доручення підприємства-позичальника.

( Пункт 17 із змінами, внесеними згідно з Постановою Національного банку N 236 ( z0436-98 ) від 18.06.98 )

18. Погашення кредитів здійснюється з розрахункового рахунка підприємства-позичальника шляхом повернення основного боргу на рахунок N 2567 комерційного банку. Сплата відсотків за користування кредитом та комісійних комерційному банку здійснюється позичальником відповідно до умов, передбачених договором кредитування.

( Пункт 18 із змінами, внесеними згідно з Постановою Національного банку N 236 ( z0436-98 ) від 18.06.98 )

19. Контроль за цільовим використанням та своєчасним погашенням отриманого кредиту та відсотків за його користування здійснюється комерційним банком.

20. У разі несплати підприємством суми кредиту та відсотків за його користування, а також комісійних комерційному банку, перерахування відповідних сум на рахунки Фонду здійснюється в межах вартості заставленого майна позичальника, реалізованого банком.

21. Фонд державного майна за результатами відбору підприємств щомісяця, не пізніше 15 числа наступного за звітним місяця, направляє до Кабінету Міністрів України перелік підприємств, яким надано кредити із зазначенням обсягів, цілей використання та термінів повернення.

( Порядок доповнено пунктом 21 згідно з Постановою Національного банку N 236 ( z0436-98 ) від 18.06.98 )
