{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про виділення Господарському управлінню додаткових коштів для проведення капітального і поточного ремонту об'єктів

Кабінет Міністрів України постановляє:

Виділити Господарському управлінню Кабінету Міністрів України додатково на 1996 рік 15,81 млн. гривень для фінансування капітального і поточного ремонту об'єктів підвідомчих організацій.

Міністерству фінансів профінансувати зазначені видатки у III кварталі 1996 р. за рахунок резервного фонду Кабінету Міністрів України.

Прем'єр-міністр України П.ЛАЗАРЕНКО
