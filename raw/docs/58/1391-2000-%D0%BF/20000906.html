КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 вересня 2000 р. N 1391 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про визнання такою, що втратила чинність, постанови Кабінету Міністрів України від 17 травня 1999 р. N 824

Кабінет Міністрів України постановляє:

Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 17 травня 1999 р. N 824 ( 824-99-п ) "Про випуск ощадних сертифікатів, номінованих у іноземній валюті".
