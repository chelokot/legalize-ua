КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 вересня 1994 р. N 615 Київ

Про внесення змін до постанови Кабінету Міністрів України від 8 лютого 1994 р. N 75

( Із змінами, внесеними згідно з Постановою КМ N 164 ( 164-97-п ) від 08.02.97 )

Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. Внести до постанови Кабінету Міністрів України від 8 лютого 1994 р. N 75 ( 75-94-п ) "Про затвердження Порядку справляння плати за спеціальне використання прісних водних ресурсів і тимчасових нормативів плати за їх спеціальне використання" (ЗП України, 1994 р., N 5, ст.134) такі зміни:

а) у пункті 10 Порядку справляння плати за спеціальне використання прісних водних ресурсів, затвердженого зазначеною постановою, слова "Комунальне господарство" замінити словами "Житлово-комунальне господарство";

( Підпункт "б" пункту 1 втратив чинність на підставі Постанови КМ N 164 ( 164-97-п ) від 08.02.97 )

( Пункт 2 втратив чинність на підставі Постанови КМ N 164 ( 164-97-п ) від 08.02.97 )
