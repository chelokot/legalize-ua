Питання Державного комітету у справах сім'ї та молоді

Стан: Втратив чинність

Текст документа від 07.08.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 квітня 1999 р. N 618 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1231 ( 1231-2000-п ) від 07.08.2000 )

Питання Державного комітету у справах сім'ї та молоді

( Із змінами, внесеними згідно з Постановою КМ N 1712 ( 1712-99-п ) від 15.09.99 )

Відповідно до Указу Президента України від 13 березня 1999 р. N 250 ( 250/99 ) "Про зміни в системі центральних органів виконавчої влади України" Кабінет Міністрів України постановляє:

1. Установити граничну чисельність працівників центрального апарату Державного комітету у справах сім'ї та молоді у кількості 90 одиниць.

Дозволити Державному комітетові у справах сім'ї та молоді мати чотирьох заступників Голови, в тому числі одного першого, а також колегію у кількості одинадцяти чоловік. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1712 ( 1712-99-п ) від 15.09.99 )

Установити ліміт автомобілів, що обслуговують Державний комітет у справах сім'ї та молоді, у кількості 5 одиниць.

2. Міністерству фінансів профінансувати витрати на утримання Державного комітету у справах сім'ї та молоді в 1999 році за рахунок асигнувань, передбачених у Державному бюджеті України Міністерству у справах сім'ї та молоді.

3. Установити, що:

Фонд сприяння молодіжному житловому будівництву, Український інститут соціальних досліджень, Український державний центр соціальних служб для молоді, Міжнародний дитячий центр "Артек", Український молодіжний центр перебувають у сфері управління Державного комітету у справах сім'ї та молоді;

розпорядником коштів державного фонду сприяння соціальному становленню та розвитку молоді, Українського фонду сприяння соціальному захисту неповнолітніх є Державний комітет у справах сім'ї та молоді.

4. Розмістити Державний комітет у справах сім'ї та молоді в будинку по вул. Десятинній, 14, у м. Києві на умовах оренди та закріпити за ним господарські споруди у дворі будинку.

5. Визнати такими, що втратили чинність:

пункти 1 та 3 постанови Кабінету Міністрів України від 4 жовтня 1996 р. N 1215 ( 1215-96-п ) "Питання Міністерства у справах сім'ї та молоді";

постанову Кабінету Міністрів України від 19 вересня 1997 р. N 1029 ( 1029-97-п ) "Про граничну чисельність працівників центрального апарату Міністерства у справах сім'ї та молоді" (Офіційний вісник України, 1997 р., число 39, с. 10);

постанову Кабінету Міністрів України від 22 жовтня 1997 р. N 1163 ( 1163-97-п ) "Про колегію Міністерства у справах сім'ї та молоді";

постанову Кабінету Міністрів України від 15 грудня 1998 р. N 1993 ( 1993-98-п ) "Про встановлення посади заступника Міністра України у справах сім'ї та молоді - директора Українського державного центру соціальних служб для молоді".
