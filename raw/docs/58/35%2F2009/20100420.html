{ Указ втратив чинність на підставі Указу Президента N 482/2010 ( 482/2010 ) від 02.04.2010 }

Про внесення змін до складу Міжвідомчої робочої групи з питань протидії корупції

На часткову зміну статті 3 Указу Президента України від 17 квітня 2008 року N 370 ( 370/2008 ) "Про Міжвідомчу робочу групу з питань протидії корупції" ввести до складу Міжвідомчої робочої групи з питань протидії корупції ХАВАНСЬКУ Тетяну Сергіївну - радника проекту "Розвиток спеціалізованих служб з боротьби проти корупції" (за згодою), вивівши з її складу Г. Салімову.

Президент України В.ЮЩЕНКО
