Про підписання Протоколу між Кабінетом Міністрів України та Урядом Республіки Казахстан про скасування вилучень з режиму вільної торгівлі

Текст документа від 13.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 травня 2006 р. N 305-р Київ

Про підписання Протоколу між Кабінетом Міністрів України та Урядом Республіки Казахстан про скасування вилучень з режиму вільної торгівлі

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 550-р ( 550-2006-р ) від 08.11.2006 N 616-р ( 616-2006-р ) від 13.12.2006 }

Схвалити проект Протоколу між Кабінетом Міністрів України та Урядом Республіки Казахстан про скасування вилучень з режиму вільної торгівлі.

Уповноважити Міністра палива та енергетики Бойка Юрія Анатолійовича підписати зазначений Протокол, дозволивши вносити у разі потреби до його проекту зміни, що не мають принципового характеру. { Абзац другий із змінами, внесеними згідно з Розпорядженнями КМ N 550-р ( 550-2006-р ) від 08.11.2006, N 616-р ( 616-2006-р ) від 13.12.2006 }
