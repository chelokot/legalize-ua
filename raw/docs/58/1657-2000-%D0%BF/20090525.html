Кабінет Міністрів України; Постанова від 08.11.2000 № 1657

Про внесення зміни до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

Стан: Втратив чинність

Ідентифікатор: 1657-2000-п

Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 листопада 2000 р. N 1657 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

{ Постанова втратила чинність в частині встановлення ліміту легкових автомобілів, що обслуговують центральні органи виконавчої влади та підпорядковані їм територіальні органи, на підставі Постанови КМ N 314 ( 314-2001-п ) від 02.04.2001 }

Про внесення зміни до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

Кабінет Міністрів України постановляє:

У додатку 2 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339, N 11, ст. 419, N 13, ст. 519, N 26, ст. 1097, N 27, ст. 1129, N 35, ст. 1495) у позиції "Державний комітет промислової політики" цифру "6" замінити цифрою "8".

Прем'єр-міністр України В.ЮЩЕНКО
