Президент України; Указ від 03.03.1997 № 200/97

Про Палату незалежних експертів з питань іноземних інвестицій

Стан: Втратив чинність

Ідентифікатор: 200/97

Текст документа від 04.11.2000:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Палату незалежних експертів з питань іноземних інвестицій

( Із змінами, внесеними згідно з Указом Президента N 1208/2000 ( 1208/2000 ) від 04.11.2000 )

З метою запобігання спорам між іноземними інвесторами та органами виконавчої влади і місцевого самоврядування, сприяння їх оперативному позасудовому врегулюванню постановляю:

1. Утворити Палату незалежних експертів з питань іноземних інвестицій при Президентові України (далі - Палата експертів).

Палата експертів є постійно діючим консультативно-дорадчим органом, який здійснює діяльність на підставі Положення, що затверджується Президентом України.

2. Установити, що основним завданням Палати експертів є підготовка та внесення Президентові України або за його дорученням органам виконавчої влади і місцевого самоврядування пропозицій щодо запобігання виникненню спорів між іноземними інвесторами та органами виконавчої влади і місцевого самоврядування та визначення шляхів їх позасудового врегулювання.

3. Установити, що Головою Палати незалежних експертів з питань іноземних інвестицій є за посадою Міністр економіки України. ( Стаття 3 в редакції Указу Президента N 1208/2000 ( 1208/2000 ) від 04.11.2000 )

4. Голові Палати експертів подати у місячний строк проект Положення про Палату незалежних експертів з питань іноземних інвестицій та пропозиції щодо її персонального складу.

5. Покласти здійснення організаційного та матеріально-технічного забезпечення Палати експертів на Міністерство економіки України. ( Стаття 5 в редакції Указу Президента N 1208/2000 ( 1208/2000 ) від 04.11.2000 )
