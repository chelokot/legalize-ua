{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про внесення зміни до пункту 3 розпорядження Кабінету Міністрів України від 18 лютого 2009 р. N 183

Пункт 3 розпорядження Кабінету Міністрів України від 18 лютого 2009 р. N 183 ( 183-2009-р ) "Про утворення міжвідомчих робочих груп з підготовки пропозицій щодо активізації українсько-японського співробітництва", викласти у такій редакції:

"3. Затвердити керівника групи радників Прем'єр-міністра України Гайдука В.А. координатором міжурядового українсько-японського співробітництва, а його заступником директора Інституту проблем екології та енергозбереження Єрмілова С.Ф.

Гайдуку В.А. забезпечити координацію діяльності міжвідомчих робочих груп відповідно до покладених на них завдань.".

Прем'єр-міністр України Ю.ТИМОШЕНКО
