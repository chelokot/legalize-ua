Зареєстровано в Міністерстві юстиції України 15 листопада 2011 р. за N 1301/20039

Про визнання такими, що втратили чинність, деяких наказів Міністерства фінансів України

З метою приведення нормативно-правових актів Міністерства фінансів України у відповідність із законодавством НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Міністерства фінансів України:

від 19.04.94 N 36 ( z0087-94 ) "Про затвердження Положення "Про порядок оцінки чистих активів інвестиційних фондів і взаємних фондів інвестиційної компанії", зареєстрований в Міністерстві юстиції України 04.05.94 за N 87/296;

від 15.05.95 N 80 ( z0153-95 ) "Про затвердження Інструкції про службові відрядження", зареєстрований в Міністерстві юстиції України 23.05.95 за N 153/689;

від 27.02.98 N 45 ( z0146-98 ) "Про затвердження механізму обмеження витрачання бюджетних коштів", зареєстрований в Міністерстві юстиції України 04.03.98 за N 146/2586;

від 16.11.99 N 279 ( z0838-99 ) "Про затвердження Положення про порядок проведення операцій зменшення зовнішніх державних боргових зобов'язань з використанням казначейських векселів", зареєстрований в Міністерстві юстиції України 06.12.99 за N 838/4131;

від 01.02.2000 N 21 ( z0094-00 ) "Про внесення змін до наказу Міністерства фінансів України від 16 листопада 1999 року N 279 та затвердженого ним Положення про порядок проведення операцій зменшення зовнішніх державних боргових зобов'язань з використанням казначейських векселів", зареєстрований в Міністерстві юстиції України 15.02.2000 за N 94/4315.

2. Юридичному департаменту (Матузка Я.В.) в установленому порядку подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності з дня його офіційного опублікування.

4. Контроль за виконанням цього наказу покласти на першого заступника Міністра Мярковського А.І.
