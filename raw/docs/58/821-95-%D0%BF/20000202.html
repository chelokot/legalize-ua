Кабінет Міністрів України; Постанова від 16.10.1995 № 821

Про підвищення посадових окладів керівних працівників і спеціалістів державної податкової служби та державної контрольно-ревізійної служби

Стан: Втратив чинність

Ідентифікатор: 821-95-п

Текст документа від 02.02.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 жовтня 1995 р. N 821 Київ

( Постанова втратила чинність на підставі Постанови КМ N 207 ( 207-2000-п ) від 02.02.2000 )

Про підвищення посадових окладів керівних працівників і спеціалістів державної податкової служби та державної контрольно-ревізійної служби

( Із змінами, внесеними згідно з Постановами КМ N 1043 ( 1043-95-п ) від 25.12.95 N 828 ( 828-97-п ) від 04.08.97 )

Кабінет Міністрів України постановляє:

1. ( Пункт 1 втратив чинність у частині, що стосується працівників державної податкової служби на підставі Постанови КМ N 828 ( 828-97-п ) від 04.08.97 ) Підвищити на коефіцієнт 15 посадові оклади керівних працівників і спеціалістів державної податкової служби та державної контрольно-ревізійної служби, виходячи з мінімального розміру заробітної плати (60 тис. крб.) і коефіцієнтів співвідношень посадових окладів з мінімальним розміром заробітної плати, затверджених постановами Кабінету Міністрів України від 23 вересня 1993 р. N 782 ( 782-93-п ), від 5 липня 1993 р. N 515 ( 515-93-п ) та від 21 січня 1993 р. N 35 ( 35-93-п ) без урахування постанови Кабінету Міністрів України від 2 жовтня 1995р. N 778 ( 778-95-п ). ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1043 ( 1043-95-п ) від 25.12.95 )

2. ( Пункт 2 втратив чинність у частині, що стосується працівників державної податкової служби на підставі Постанови КМ N 828 ( 828-97-п ) від 04.08.97 ) Установити керівним працівникам і спеціалістам державної податкової служби та державної контрольно-ревізійної служби, які пропрацювали в цих органах не менш як два роки і виконують роботу з перевірки платників щодо справляння з них податків та інших платежів, а також підприємств, установ і організацій, надбавки за особливі умови праці у розмірі 50 відсотків посадового окладу з урахуванням доплати відповідно за спеціальне звання і ранг державного службовця.

( Пункт 3 втратив чинність на підставі Постанови КМ N 1043 ( 1043-95-п ) від 25.12.95 )

4. Ця постанова набуває чинності з 1 жовтня 1995 року.
