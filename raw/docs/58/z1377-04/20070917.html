ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

14.10.2004 N 558

Зареєстровано в Міністерстві юстиції України 27 жовтня 2004 р. за N 1377/9976

{ Наказ втратив чинність починаючи зі звіту за 2007 рік на підставі Наказу Державного комітету статистики N 306 ( z1035-07 ) від 20.08.2007 }

Про затвердження форм державних статистичних спостережень із статистики науки й інновацій та Інструкцій щодо їх складання

{ Із змінами, внесеними згідно з Наказами Державного комітету статистики N 382 ( z1494-05 ) від 28.11.2005 N 336 ( z0932-06 ) від 19.07.2006 N 337 ( z1008-06 ) від 19.07.2006 }

Відповідно до статті 14 Закону України "Про державну статистику" ( 2614-12 ) та з метою подальшого вдосконалення державних статистичних спостережень із статистики науки та інновацій НАКАЗУЮ:

1. Затвердити:

1.1. Форми державних статистичних спостережень (додаються) і ввести їх у дію, починаючи зі звіту

за 2004 рік:

{ Абзац 3 підпункту 1.1 втратив чинність на підставі Наказу Державного комітету статистики N 336 ( z0932-06 ) від 19.07.2006 }

{ Наказ втратив чинність у частині затвердження форми N 4-нт на підставі Наказу Державного комітету статистики N 337 ( z1008-06 ) від 19.07.2006 } Форма N 4-нт ( z1378-04 ) "Звіт про набуття прав інтелектуальної власності та використання об'єктів права інтелектуальної власності", річна;

{ Наказ втратив чинність у частині затвердження форми N 7-нт (ліцензії) на підставі Наказу Державного комітету статистики N 337 ( z1008-06 ) від 19.07.2006 } Форма N 7-нт (ліцензії) ( z1379-04 ) "Звіт про укладання договорів стосовно розпоряджання майновими правами інтелектуальної власності", річна;

Форма N 2-програми ( z1380-04 ) "Виконання завдань програм та державного замовлення за пріоритетними напрямами інноваційної діяльності", квартальна;

за I квартал 2005 року:

( Абзац 8 підпункту 1.1 втрачає чинність на підставі Наказу Державного комітету статистики N 382 ( z1494-05 ) від 28.11.2005 - з моменту подання звіту за 2005 рік ) Форма N 2-пром (інновація) ( z1381-04 ) "Звіт про інноваційну активність промислового підприємства", квартальна.

1.2. Інструкції щодо складання форм державних статистичних спостережень (додаються):

{ Абзац 2 підпункту 1.2 втратив чинність на підставі Наказу Державного комітету статистики N 336 ( z0932-06 ) від 19.07.2006 }

{ Наказ втратив чинність у частині затвердження Інструкції щодо заповнення форми N 4-нт на підставі Наказу Державного комітету статистики N 337 ( z1008-06 ) від 19.07.2006 } N 4-нт "Звіт про набуття прав інтелектуальної власності та використання об'єктів права інтелектуальної власності" ( z1378-04 );

{ Наказ втратив чинність у частині затвердження Інструкції щодо заповнення форми N 7-нт (ліцензії) на підставі Наказу Державного комітету статистики N 337 ( z1008-06 ) від 19.07.2006 } N 7-нт (ліцензії) "Звіт про укладання договорів стосовно розпоряджання майновими правами інтелектуальної власності" ( z1379-04 );

N 2-програми "Виконання завдань програм та державного замовлення за пріоритетними напрямами інноваційної діяльності" ( z1380-04 );

( Абзац 6 підпункту 1.2 втрачає чинність на підставі Наказу Державного комітету статистики N 382 ( z1494-05 ) від 28.11.2005 - з моменту подання звіту за 2005 рік ) N 2-пром (інновація) "Звіт про інноваційну активність промислового підприємства" ( z1381-04 )

2. Установити, що звіти за формами державних статистичних спостережень, затвердженими пунктом 1 цього наказу, подають організації, підприємства, установи всіх форм власності та організаційно-правових форм господарювання.

3. Департаменту статистики послуг (Калачова І.В.):

3.1. Визначити необхідний тираж, підготувати і передати для виготовлення Адміністративно-господарському департаменту (Сенкевич-Давидець Н.М.) оригінали бланків форм державних статистичних спостережень та Інструкцій щодо їх складання, затверджених пунктом 1 цього наказу.

3.2. Спільно з Головним міжрегіональним управлінням статистики у м. Києві (Сидоренко М.М.) підготувати пропозиції щодо внесення відповідних змін до Плану розробки та експлуатації комплексів електронної обробки статистичної інформації на 2004 рік та надати їх в управління інформатизації (Моісеєв Л.І.).

3.3. Здійснювати методологічне керівництво збором та розробкою звітів за формами, затвердженими пунктом 1 цього наказу.

4. Управлінню планування та аналізу використання фінансових ресурсів Департаменту фінансового забезпечення, бухгалтерського обліку та звітності (Кучіна І.Ю.) забезпечити фінансування виготовлення та доставки бланків форм державних статистичних спостережень та Інструкцій щодо їх складання, затверджених пунктом 1 цього наказу.

5. Адміністративно-господарському департаменту (Сенкевич-Давидець Н.М.) забезпечити контроль за своєчасним тиражуванням та доставкою бланків форм державної статистичної звітності та Інструкцій про порядок їх складання на адресу Головних управлінь статистики в Автономній Республіці Крим, областях, м. Києві та Управління статистики у м. Севастополі.

6. Головному міжрегіональному управлінню статистики у м. Києві (Сидоренко М.М.) забезпечити збір та розробку даних за формами державних статистичних спостережень, затвердженими пунктом 1 цього наказу.

7. Начальникам Головних управлінь статистики в Автономній Республіці Крим, областях, м. Києві та Управлінні статистики у м. Севастополі забезпечити в установленому порядку збір, розробку і подання Держкомстату України звітів у встановлені терміни.

8. Уважати таким, що втратив чинність з 1 січня 2005 року:

наказ Мінстату України від 06.07.95 N 168 ( z0235-95 ) "Про затвердження форм державної статистичної звітності по статистиці науки, інформатики і інновацій та Інструкцій про порядок їх заповнення", зареєстрований Міністерством юстиції України 24.07.95 за N 235/771;

пункт 1 наказу Держкомстату України від 09.09.2003 N 290 ( z0850-03 ) "Про затвердження форм державних статистичних спостережень із статистики науки й інновацій та Інструкцій про порядок їх складання", зареєстрований Міністерством юстиції України 25.09.2003 за N 850/8171, у частині затвердження Інструкції про порядок заповнення форми державного статистичного спостереження N 3-наука.

9. Контроль за виконанням наказу покласти на заступника Голови Комітету Власенко Н.С.

Голова Комітету О.Г.Осауленко
