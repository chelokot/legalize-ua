Текст документа від 16.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2011 р. N 1208 Київ

Про внесення зміни в додаток до постанови Кабінету Міністрів України від 8 грудня 2010 р. N 1256

Кабінет Міністрів України постановляє:

1. Внести зміну в додаток до постанови Кабінету Міністрів України від 8 грудня 2010 р. N 1256 ( 1256-2010-п ) "Про затвердження переліку проектів із пріоритетних напрямів соціально-економічного та культурного розвитку (національні проекти)" (Офіційний вісник України, 2011 р., N 3, ст. 177, N 24, ст. 1000), доповнивши його такими позиціями:

------------------------------------------------------------------

|"Збільшення обсягів виробництва |"Зерно України" - зростання |

|конкурентоспроможної |внутрішнього валового продукту,|

|сільськогосподарської продукції |модернізація галузі |

| |зерновиробництва та нарощування|

| |її експортного потенціалу; |

| | |

| |"Відроджене скотарство" - |

| |забезпечення продовольчої |

| |безпеки в частині виробництва |

| |молочної продукції та |

| |яловичини, збільшення |

| |експортного потенціалу галузі |

| |тваринництва |

|--------------------------------+-------------------------------|

|Розвиток аграрного ринку |"Зелені ринки" - розбудова |

| |мережі оптових ринків |

| |сільськогосподарської продукції|

| |та задоволення споживчого |

| |попиту населення". |

------------------------------------------------------------------

2. Державному агентству з інвестицій та управління національними проектами розробити у двотижневий строк попереднє техніко-економічне обґрунтування національних проектів, зазначених у пункті 1 цієї постанови, та подати на розгляд Кабінету Міністрів України.
