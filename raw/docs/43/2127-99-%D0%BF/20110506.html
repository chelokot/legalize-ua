ПОСТАНОВА від 23 листопада 1999 р. N 2127 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 444 ( 444-2011-п ) від 27.04.2011 }

Про затвердження Шнипка О.С. членом колегії Державної податкової адміністрації України

( Із змінами, внесеними згідно з Постановами КМ N 854 ( 854-2002-п ) від 18.06.2002 N 1404 ( 1404-2002-п ) від 23.09.2002 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 1404 ( 1404-2002-п ) від 23.09.2002 )

Визнати таким, що втратив чинність, пункт 1 постанови Кабінету Міністрів України від 31 грудня 1998 р. N 2111 ( 2111-98-п ).

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 854 ( 854-2002-п ) від 18.06.2002 )

2. Відповідно до розпорядження Президента України від 25 травня 1999 р. N 113 ( 113/99-рп ) затвердити членом колегії Державної податкової адміністрації України Шнипка Олександра Сергійовича як представника Українського союзу промисловців і підприємців, із правом дорадчого голосу.
