Кабінет Міністрів України; Розпорядження від 09.06.2011 № 552-р

Про передачу цілісного майнового комплексу Національного заповідника "Софія Київська" до сфери управління Міністерства культури

Стан: Чинний

Ідентифікатор: 552-2011-р

Текст документа від 09.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 червня 2011 р. N 552-р Київ

Про передачу цілісного майнового комплексу Національного заповідника "Софія Київська" до сфери управління Міністерства культури

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1114-р ( 1114-2011-р ) від 09.11.2011 }

1. Прийняти пропозицію Міністерства культури та Міністерства регіонального розвитку, будівництва та житлово-комунального господарства щодо передачі цілісного майнового комплексу Національного заповідника "Софія Київська" до сфери управління Міністерства культури.

{ Пункт 2 втратив чинність на підставі Розпорядження КМ N 1114-р ( 1114-2011-р ) від 09.11.2011 }

3. Передати бюджетні призначення, передбачені в 2011 році Міністерству регіонального розвитку, будівництва та житлово-комунального господарства для фінансування діяльності Національного заповідника "Софія Київська" у державному бюджеті ( 2857-17 ) за програмою 2751080 "Збереження архітектурної спадщини в заповідниках", у сумі 19973,5 тис. гривень Міністерству культури за програмою 1802030 "Збереження історико-культурної спадщини в заповідниках" (загальний фонд - видатки споживання - 11527 тис. гривень, з них - оплата праці 8308,1 тис. гривень, комунальні послуги та енергоносії - 194,8 тис. гривень; спеціальний фонд - 8446,5 тис. гривень, з них видатки споживання - 8353,5 тис. гривень (оплата праці - 4884,4 тис. гривень, комунальні послуги та енергоносії - 614,1 тис. гривень), видатки розвитку - 93 тис. гривень).

4. Міністерству культури забезпечити погодження передачі бюджетних призначень, передбачених пунктом 3 цього розпорядження, з Комітетом Верховної Ради України з питань бюджету.

Міністерству фінансів внести після зазначеного погодження відповідні зміни до розпису державного бюджету.

Прем'єр-міністр України М.АЗАРОВ
