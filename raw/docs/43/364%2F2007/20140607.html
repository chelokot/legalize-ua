Питання Представництва Президента України в Автономній Республіці Крим

Стан: Втратив чинність

Ідентифікатор: 364/2007

Текст документа від 07.06.2014:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 487/2014 ( 487/2014 ) від 24.05.2014 }

Питання Представництва Президента України в Автономній Республіці Крим

1. Внести до Указу Президента України від 12 жовтня 2005 року N 1433 ( 1433/2005 ) "Питання Представництва Президента України в Автономній Республіці Крим" (зі змінами, внесеними Указом від 27 грудня 2006 року N 1134 ( 1134/2006 ) такі зміни:

1) на часткову зміну статті 1 затвердити нову структуру Представництва Президента України в Автономній Республіці Крим (додається);

2) у статті 2 слова "у тому числі двох перших" замінити словами "у тому числі одного першого".

2. Постійному Представникові Президента України в Автономній Республіці Крим затвердити в десятиденний строк новий штатний розпис Представництва Президента України в Автономній Республіці Крим, положення про відповідні структурні підрозділи, визначити посадові обов'язки працівників та забезпечити в установленому порядку вирішення інших питань, пов'язаних із затвердженням нової структури Представництва.

3. Кабінету Міністрів України привести у місячний строк свої рішення у відповідність із цим Указом.
