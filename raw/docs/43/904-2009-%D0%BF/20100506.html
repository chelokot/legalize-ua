Деякі питання фінансування у 2009 році технічного переоснащення вугледобувних підприємств

Стан: Чинний

Ідентифікатор: 904-2009-п

Текст документа від 06.05.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 серпня 2009 р. N 904 Київ

Деякі питання фінансування у 2009 році технічного переоснащення вугледобувних підприємств

{ Із змінами, внесеними згідно з Постановою КМ N 324 ( 324-2010-п ) від 28.04.2010 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 324 ( 324-2010-п ) від 28.04.2010 }

2. Виділити Міністерству вугільної промисловості на безповоротній основі 108 млн. гривень за рахунок нерозподілених коштів Стабілізаційного фонду за напрямом, визначеним у пункті 22 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), з метою закупівлі 30 бурошнекових комплексів для технічного переоснащення вугледобувних підприємств згідно з додатком.

3. Міністерству вугільної промисловості:

використовувати виділені згідно з пунктом 2 цієї постанови кошти відповідно до Порядку використання у 2009 році коштів Стабілізаційного фонду, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) (Офіційний вісник України, 2009 р., N 24, ст. 793);

подати до кінця 2009 року Міністерству фінансів та Державному казначейству звіт про використання зазначених коштів.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21
