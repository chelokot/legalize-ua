УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 559/2011 ( 559/2011 ) від 07.05.2011 }

Про внесення змін до Положення про Державний комітет телебачення і радіомовлення України

У зв'язку з прийняттям Закону України "Про захист суспільної моралі" ( 1296-15 ) постановляю:

Внести до Положення про Державний комітет телебачення і радіомовлення України, затвердженого Указом Президента України від 27 серпня 2003 року N 920 ( 920/2003 ), такі зміни:

1) абзац другий пункту 3 доповнити словами "державної політики у сфері захисту суспільної моралі";

2) в пункті 4:

підпункт 1 доповнити словами "державної політики у сфері захисту суспільної моралі";

підпункт 14 доповнити словами "здійснює в межах своєї компетенції державний нагляд за додержанням законодавства у сфері захисту суспільної моралі";

доповнити пункт підпунктом 22-1 такого змісту:

"22-1) здійснює ліцензування і реєстрацію спеціалізованих засобів масової інформації сексуального чи еротичного характеру, контроль за наявністю ліцензій у суб'єктів господарювання, додержання ними ліцензійних умов".

Президент України Л.КУЧМА

м. Київ, 30 червня 2004 року N 696/2004
