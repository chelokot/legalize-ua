Стан: Втратив чинність

Текст документа від 03.06.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 липня 1994 р. N 462 Київ

( Постанова втратила чинність на підставі Постанови КМ N 954 ( 954-99-п ) від 03.06.99 )

Питання Державного комітету по стандартизації, метрології та сертифікації

( Із змінами, внесеними згідно з Постановами КМ N 623 ( 623-96-п ) від 10.06.96 N 1113 ( 1113-96-п ) від 12.09.96 N 1227 ( 1227-96-п ) від 05.10.96 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 1227 ( 1227-96-п ) від 05.10.96 )

2. Установити граничну чисельність працівників центрального апарату Державного комітету по стандартизації, метрології та сертифікації у кількості 140 одиниць.

Дозволити Державному комітетові по стандартизації, метрології та сертифікації мати трьох заступників голови, у тому числі одного першого, а також колегію у кількості 13 чоловік.

( На часткову зміну пункту 2 дозволити Державному комітету по стандартизації, метрології та сертифікації мати колегію у кількості 9 чоловік згідно з Постановою КМ N 623 ( 623-96-п ) від 10.06.96 ) ( На часткову зміну пункту 2 дозволити Державному комітету по стандартизації, метрології та сертифікації мати колегію у кількості 11 чоловік згідно з Постановою КМ N 1113 ( 1113-96-п ) від 12.09.96 )

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 25 травня 1992 р. N 268 ( 268-92-п ) "Питання Державного комітету України по стандартизації, метрології та сертифікації" (ЗП України, 1992 р., N 6, ст.136).
