КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 жовтня 1995 р. N 846 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1890 ( 1890-2003-п ) від 10.12.2003 )

Про Міжвідомчу комісію щодо погодження питань правової охорони знаків для товарів і послуг

( Із змінами, внесеними згідно з Постановами КМ N 468 ( 468-97-п ) від 20.05.97 N 151 ( 151-2001-п ) від 14.02.2001 )

На виконання постанови Президії Верховної Ради України від 22 травня 1995 р. "Про визначення компетентного органу для погодження питань правової охорони знаків для товарів і послуг" ( 296/95-ПВ ) Кабінет Міністрів України постановляє:

Утворити Міжвідомчу комісію щодо погодження питань правової охорони знаків для товарів і послуг (далі - Комісія).

Затвердити Положення про цю Комісію та її склад (додаються).

Перший віце-прем'єр-міністр України П.ЛАЗАРЕНКО

Перший заступник Міністра Кабінету Міністрів України М.СЕЛІВОН

Додаток до постанови Кабінету Міністрів України від 20 жовтня 1995 р. N 846

( Додаток в редакції Постанови КМ N 468 ( 468-97-п ) від 20.05.97 )

СКЛАД Міжвідомчої комісії щодо погодження питань правової охорони знаків для товарів і послуг

ЖАРОВ - перший заступник голови Держпатенту Володимир Олександрович (голова Комісії)

АНДРОЩУК - старший консультант Комісії з питань Геннадій Олександрович науки та народної освіти Верховної Ради України (заступник голови Комісії (за згодою)

БІЛОУС - заступник начальника управління, Віталій Степанович начальник відділу з питань недобросовісної конкуренції п'ятого управління досліджень і розслідувань Антимонопольного комітету (за згодою)

ВЕРЕЩАГА - заступник голови Держстандарту Євген Михайлович

ПАНЧЕНКО - перший заступник начальника управління Аліна Михайлівна цивільного права департаменту проектування нормативних актів Мінюсту

КІСТЕРСЬКА - начальник відділу управління права і Світлана Михайлівна патентної політики Держпатенту

ШЕВЕЛЄВА - радник першого заступника голови Тетяна Михайлівна Держпатенту (відповідальний секретар Комісії)
