Кабінет Міністрів України; Розпорядження від 27.06.2007 № 492-р

Про пенсійне забезпечення колишніх членів Ради Міністрів УРСР, Кабінету Міністрів УРСР та членів їх сімей

Стан: Втратив чинність

Ідентифікатор: 492-2007-р

Текст документа від 09.12.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 червня 2007 р. N 492-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1294-р ( 1294-2015-р ) від 09.12.2015 }

Про пенсійне забезпечення колишніх членів Ради Міністрів УРСР, Кабінету Міністрів УРСР та членів їх сімей

{ Установити, що пенсійне забезпечення колишніх Голови Президії Верховної Ради УРСР і його заступника здійснюється на умовах, передбачених цим Розпорядженням, згідно з Розпорядженням КМ N 617-р ( 617-2007-р ) від 08.08.2007 }

1. Установити, що пенсії колишнім членам Ради Міністрів УРСР, Кабінету Міністрів УРСР та членам їх сімей призначаються на умовах та у порядку, передбаченому статтею 61 Закону України "Про Кабінет Міністрів України" ( 514-16 ).

2. Мінпраці разом з Мінфіном, Мін'юстом, Мінекономіки та Пенсійним фондом України подати Кабінетові Міністрів України пропозиції стосовно внесення до Закону України "Про Кабінет Міністрів України" ( 514-16 ) змін, що випливають з цього розпорядження.

Прем'єр-міністр України В.ЯНУКОВИЧ
