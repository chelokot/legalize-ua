Про затвердження Переліку власних надходжень бюджетних установ та організацій

( Із змінами, внесеними згідно з Наказом Мінфіну N 347 ( z0128-01 ) від 25.12.2000 )

На виконання постанови Кабінету Міністрів України від 06.05.2000 N 774 ( 774-2000-п ) "Про заходи щодо організації виконання Закону України "Про Державний бюджет України на 2000 рік" ( 1458-14 ) та з метою уточнення переліку видів власних надходжень бюджетних установ та організацій, які, починаючи з 2000 року, включені до спеціального фонду бюджетів усіх рівнів, НАКАЗУЮ:

1. Затвердити Перелік власних надходжень бюджетних установ та організацій, що додається.

2. Скасувати наказ Міністерства фінансів України від 24 січня 2000 р. N 12 "Про Перелік спеціальних коштів бюджетних установ та організацій" у зв'язку з відмовою в державній реєстрації.

3. Визнати таким, що не застосовується, наказ Міністерства фінансів Української РСР від 28 вересня 1981 р. N 112 "Про уточнений перелік спеціальних коштів установ, що перебувають на Державному бюджеті Української РСР, та про порядок затвердження по них кошторисів."

Міністр І.О.Мітюков
