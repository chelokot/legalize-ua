МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

08.06.2007 N 487

Зареєстровано в Міністерстві юстиції України 25 червня 2007 р. за N 726/13993

{ Наказ втратив чинність на підставі Наказу Міністерства інфраструктури N 356 ( z0960-20 ) від 17.06.2020 }

Про внесення змін та до наказу Міністерства транспорту та зв'язку України від 11.05.2007 N 390 "Про затвердження Інструкції з оцінки рівня загрози безпеці цивільної авіації України", зареєстрованого у Міністерстві юстиції 25.05.2007 за N 542/13809

На виконання п. 2.1.4 Додатка 17 ( 995_655 ) до "Конвенції про міжнародну цивільну авіацію" ( 995_038 ) та з метою забезпечення надійного захисту інформації стосовно заходів авіаційної безпеки НАКАЗУЮ:

1. Надати наказу Міністерства транспорту та зв'язку України від 11.05.2007 N 390 ( z0542-07 ) "Про затвердження Інструкції з оцінки рівня загрози безпеці цивільної авіації України", зареєстрованого у Міністерстві юстиції України 25.05.2007 N 542/13809, гриф "Для службового користування".

2. Першому заступнику Голови Державіаадміністрації Лісняку О.І.:

2.1. Забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

2.2. Довести цей наказ до відома керівників аеропортів та авіапідприємств всіх форм власності, а також до заінтересованих центральних органів виконавчої влади.

3. Контроль за виконанням цього наказу залишаю за собою.

Міністр М.Рудьковський
