Текст документа від 31.01.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 березня 2007 р. N 414 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для збирання, оброблення та розповсюдження офіційної інформаційної продукції

{ Із змінами, внесеними згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) за програмою "Збирання, обробка та розповсюдження офіційної інформаційної продукції", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для збирання, оброблення та розповсюдження офіційної інформаційної продукції, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 51

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 березня 2007 р. N 414

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для збирання, оброблення та розповсюдження офіційної інформаційної продукції

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених Держкомтелерадіо у загальному фонді державного бюджету ( 489-16 ) за програмою "Збирання, обробка та розповсюдження офіційної інформаційної продукції" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Держкомтелерадіо, а їх одержувачем Українське національне інформаційне агентство "Укрінформ".

3. Бюджетні кошти спрямовуються одержувачу бюджетних коштів для виконання робіт, пов'язаних із збиранням, обробленням, перекладом і розповсюдженням інформації про діяльність Президента України, Верховної Ради України, Кабінету Міністрів України та інших органів державної влади; забезпеченням засобів масової інформації та передплатників інформацією з найважливіших політичних, соціальних та інших питань; створенням та утриманням кореспондентських пунктів в іноземних державах.

Видатки одержувача бюджетних коштів здійснюються на підставі плану їх використання, затвердженого в установленому законодавством порядку.

4. Бюджетні кошти використовуються Держкомтелерадіо у межах бюджетних асигнувань, визначених кошторисом, з урахуванням необхідності виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державного казначейства, у разі їх відповідності паспортові бюджетної програми.

5. Операції, пов'язані з обслуговуванням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 6 виключено на підставі Постанови КМ N 127 ( 127-2008-п ) від 05.03.2008 }

7. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
