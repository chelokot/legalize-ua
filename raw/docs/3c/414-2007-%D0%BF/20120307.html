ПОСТАНОВА від 7 березня 2007 р. N 414 Київ

Про затвердження Порядку використання коштів, передбачених у державному бюджеті для збирання, оброблення та розповсюдження офіційної інформаційної продукції

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 494 ( 494-2010-п ) від 23.06.2010 }

{ Із змінами, внесеними згідно з Постановами КМ N 127 ( 127-2008-п ) від 05.03.2008 N 494 ( 494-2010-п ) від 23.06.2010 N 163 ( 163-2012-п ) від 29.02.2012 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) за програмою "Збирання, обробка та розповсюдження офіційної інформаційної продукції", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання коштів, передбачених у державному бюджеті для збирання, оброблення та розповсюдження офіційної інформаційної продукції, що додається.

{ Постановляюча частина із змінами, внесеними згідно з Постановою КМ N 494 ( 494-2010-п ) від 23.06.2010 }

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 51

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 березня 2007 р. N 414

ПОРЯДОК використання коштів, передбачених у державному бюджеті для збирання, оброблення та розповсюдження офіційної інформаційної продукції

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 494 ( 494-2010-п ) від 23.06.2010 }

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті за програмою "Виробництво та трансляція телерадіопрограм для державних потреб, збирання, обробка та розповсюдження офіційної інформаційної продукції, створення та функціонування україномовної версії міжнародного каналу "EuroNews", для збирання, оброблення та розповсюдження офіційної інформаційної продукції (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 494 ( 494-2010-п ) від 23.06.2010; в редакції Постанови КМ N 163 ( 163-2012-п ) від 29.02.2012 }

2. Головним розпорядником бюджетних коштів є Держкомтелерадіо, а їх одержувачем Українське національне інформаційне агентство "Укрінформ".

3. Бюджетні кошти спрямовуються одержувачу бюджетних коштів для виконання робіт, пов'язаних із збиранням, обробленням, перекладом і розповсюдженням інформації про діяльність Президента України, Верховної Ради України, Кабінету Міністрів України та інших органів державної влади; забезпеченням засобів масової інформації та передплатників інформацією з найважливіших політичних, соціальних та інших питань; створенням та утриманням кореспондентських пунктів в іноземних державах.

Видатки одержувача бюджетних коштів здійснюються на підставі плану їх використання, затвердженого в установленому законодавством порядку.

4. Бюджетні кошти використовуються Держкомтелерадіо у межах бюджетних асигнувань, визначених кошторисом, з урахуванням необхідності виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державного казначейства, у разі їх відповідності паспортові бюджетної програми.

5. Відображення у первинному та бухгалтерському обліку інформації про отримані (створені) оборотні і необоротні активи, а також відкриття рахунків, реєстрація, облік бюджетних зобов’язань в органах Казначейства та проведення операцій, пов'язаних з використанням бюджетних коштів, здійснюються в установленому законодавством порядку.

{ Пункт 5 в редакції Постанов КМ N 494 ( 494-2010-п ) від 23.06.2010, N 163 ( 163-2012-п ) від 29.02.2012 }

{ Пункт 6 виключено на підставі Постанови КМ N 127 ( 127-2008-п ) від 05.03.2008 }

6-1. Одержувач бюджетних коштів надсилає щомісяця до 20 числа наступного періоду Держкомтелерадіо інформацію про використання бюджетних коштів для її узагальнення та подання відомостей Мінфіну до 30 числа зазначеного періоду.

{ Порядок доповнено пунктом 6-1 згідно з Постановою КМ N 494 ( 494-2010-п ) від 23.06.2010 }

7. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
