{ Постанова втратила чинність на підставі Постанови КМ N 96 ( 96-2008-п ) від 27.02.2008 }

Про членів правління Пенсійного фонду

Кабінет Міністрів України постановляє:

1. У пункті 1 постанови Кабінету Міністрів України від 24 червня 2003 р. N 960 ( 960-2003-п ) "Про правління Пенсійного фонду" (Офіційний вісник України, 2003 р., N 26, ст. 1281) цифри "14" замінити цифрами "19".

2. Затвердити членами правління Пенсійного фонду Богуславського Юрія Антоновича, Грищенка Володимира Олександровича, Кабанченка Григорія Володимировича, Кудріна Анатолія Павловича, Максимчука Володимира Спиридоновича.
