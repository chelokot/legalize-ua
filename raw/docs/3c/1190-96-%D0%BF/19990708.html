КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 вересня 1996 р. N 1190 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1208 ( 1208-99-п ) від 08.07.99 )

Питання Міністерства у справах науки і технологій

( Із змінами, внесеними згідно з Постановами КМ N 4 ( 4-97-п ) від 11.01.97 N 537 ( 537-97-п ) від 06.06.97 N 239 ( 239-98-п ) від 02.03.98 )

На виконання Указу Президента України від 26 липня 1996 р. N 596 ( 596/96 ) "Про зміни в системі центральних органів виконавчої влади України" Кабінет Міністрів України постановляє:

1. Установити, що Міністерство у справах науки і технологій є правонаступником Державного комітету з питань науки, техніки та промислової політики, Національного агентства морських досліджень і технологій, Державної служби з питань спеціальної інформації та критичних технологій щодо їх зобов'язань, прав та обов'язків.

( Пункт 1 в редакції Постанови КМ N 537 ( 537-97-п ) від 06.06.97 )

2. Дозволити Міністерству у справах науки і технологій мати п'ятьох заступників Міністра, у тому числі одного першого, і колегію в складі 27 чоловік. ( Пункт 2 в редакції Постанови КМ N 4 ( 4-97-п ) від 11.01.97, із змінами, внесеними згідно з Постановами КМ N 537 ( 537-97-п ) від 06.06.97, N 239 ( 239-98-п ) від 02.03.98 )

3. Установити граничну чисельність працівників центрального апарату Міністерства у справах науки і технологій у кількості 190 одиниць.

Міністерству фінансів передбачати під час уточнення показників Державного бюджету України на 1996 рік асигнування для утримання Міністерства у справах науки і технологій, закупівлі обладнання і оргтехніки, необхідних для забезпечення його діяльності, та кошти на утримання трьох службових автомобілів.

4. Міністерству зв'язку забезпечити Міністерство у справах науки і технологій за його заявкою сучасними засобами зв'язку, телефонним міжміським та міжнародним зв'язком.

5. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 31 жовтня 1995 р. N 863 ( 863-95-п ) "Питання Державного комітету з питань науки, техніки та промислової політики".
