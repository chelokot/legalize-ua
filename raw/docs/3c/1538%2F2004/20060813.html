УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 619/2006 ( 619/2006 ) від 17.07.2006 }

Про проходження військової служби у Службі зовнішньої розвідки України

З метою визначення правових засад проходження військової служби у Службі зовнішньої розвідки України постановляю:

Установити, що до внесення змін до відповідних законів України проходження військової служби у Службі зовнішньої розвідки України здійснюється у порядку, встановленому Положенням про проходження військової служби за контрактом та кадрової військової служби у Службі безпеки України, затвердженим Указом Президента України від 7 листопада 2001 року N 1053 ( 1053/2001 ) "Про положення про проходження військової служби відповідними категоріями військовослужбовців".

Президент України Л.КУЧМА
