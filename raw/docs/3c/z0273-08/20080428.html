Антимонопольний комітет; Розпорядження від 04.03.2008 № 120-р

Зміни до форми Звіту про результати здійснення процедури редукціону щодо закупівлі товарів і послуг за державні кошти

Реєстрація: Мін'юст України від 31.03.2008 № 273/14964

Стан: Втратив чинність

Ідентифікатор: z0273-08

Текст документа від 28.04.2008:

АНТИМОНОПОЛЬНИЙ КОМІТЕТ УКРАЇНИ

ЗАТВЕРДЖЕНО Розпорядження Антимонопольного комітету України 04.03.2008 N 120-р ( z0271-08 )

{ Документ втратив чинність на підставі Розпорядження Антимонопольного комітету N 200-р ( z0323-08 ) від 08.04.2008 }

ЗМІНИ до форми Звіту про результати здійснення процедури редукціону щодо закупівлі товарів і послуг за державні кошти ( z0908-06 )

1. Пункт 5 форми ( z0908-06 ) доповнити підпунктом 5.7 такого змісту:

"5.7. Найменування, код за ЄДРПОУ та адреси учасників, що подали тендерні пропозиції".

2. Пункт 14 форми ( z0908-06 ) доповнити абзацом такого змісту:

"(за рішенням тендерного комітету від ________ N_________)".

Державний уповноважений М.Бараш

Зареєстровано в Міністерстві юстиції України 31 березня 2008 р. за N 273/14964

ЗМІНИ до Інструкції щодо заповнення форми Звіту про результати здійснення процедури редукціону щодо закупівлі товарів і послуг за державні кошти ( z0908-06 )

1. У другому реченні абзацу другого пункту 2.1 Інструкції ( z0908-06 ) слово "п'ятого" замінити словом "шостого".

2. В абзаці другому пункту 2.7 Інструкції ( z0908-06 ) цифру "8" замінити цифрами "10".
