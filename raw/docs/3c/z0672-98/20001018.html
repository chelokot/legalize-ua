ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

N 118 від 12.09.98 Зареєстровано в Міністерстві м.Київ юстиції України 20 жовтня 1998 р. vd980912 vn118 за N 672/3112

( Рішення втратило чинність на підставі Рішення Держкомісціннихпаперів N 149 ( z0721-00 ) від 29.09.2000 )

Про передачу повноважень територіальним управлінням

З метою вдосконалення порядку реєстрації випуску акцій акціонерних товариств Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Передати територіальним управлінням Комісії наступні повноваження:

1.1. З реєстрації випуску акцій закритих акціонерних товариств (крім банків, страхових компаній, інвестиційних фондів, інвестиційних компаній, бірж, клірингових установ, депозитаріїв, торговців цінними паперами, реєстраторів та інших професійних учасників ринку цінних паперів) відповідно до Положення про порядок реєстрації випуску акцій закритими акціонерними товариствами (07-06/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку від 12.02.98 N 41 ( vr041312-98 ), та Положення про порядок збільшення статутного фонду акціонерного товариства у зв'язку з індексацією основних фондів (07-04/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку від 12.02.98 N 39 ( vr039312-98 ).

1.2. З реєстрації випуску акцій відкритих акціонерних товариств та інформації про їх емісію відповідно до Положення про порядок реєстрації випуску акцій та інформації про емісію акцій відкритих акціонерних товариств, створених у процесі корпоратизації підприємств (07-03/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку 12.02.98 N 38 ( vr038312-98 ), Положення про порядок реєстрації випуску акцій та інформації про емісію акцій відкритих акціонерних товариств, створених із державних підприємств у процесі приватизації (07-02/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку від 12.02.98 N 37 ( vr037312-98 ), Положення про порядок реєстрації випуску акцій та інформації про емісію акцій відкритих акціонерних товариств, створених відповідно до Указу Президента України від 26.11.94 N 699 "Про заходи щодо забезпечення прав громадян на використання приватизаційних майнових сертифікатів" (07-05/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку від 12.02.98 N 40 ( vr040312-98 ) - якщо розмір статутного фонду відкритого акціонерного товариства не перевищує 21,5 млн.грн.

1.3. З реєстрації випуску акцій відкритих акціонерних товариств та інформації про їх емісію відповідно до Положення про порядок реєстрації випуску акцій і облігацій підприємств та інформації про їх емісію (07-01/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку від 12.02.98 N 36 ( vr036312-98 ), та Положення про порядок збільшення статутного фонду акціонерного товариства у зв'язку з індексацією основних фондів (07-04/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку від 12.02.98 N 39 - ( vr039312-98 ) якщо розмір статутного фонду на момент прийняття рішення про випуск акцій (з урахуванням емісії, щодо якої прийняте рішення) не перевищує 200 000 грн. (крім банків, страхових компаній, інвестиційних фондів, інвестиційних компаній, бірж, клірингових установ, депозитаріїв, торговців цінними паперами, реєстраторів та інших професійних учасників ринку цінних паперів).

2. У випадку реорганізації акціонерного товариства шляхом злиття, приєднання, поділу та виділення акціонерні товариства одночасно подають до Державної комісії з цінних паперів та фондового ринку документи, передбачені Положенням про порядок реєстрації випуску акцій і облігацій підприємств та інформації про їх емісію (07-01/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку від 12.02.98 N 36, для відкритих акціонерних товариств, або Положенням про порядок реєстрації випуску акцій закритими акціонерними товариствами (07-06/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку від 12.02.98 N 41 ( vr041312-98 ) - для закритих акціонерних товариств.

3. У випадку реорганізації акціонерного товариства шляхом перетворення, акціонерне товариство для реєстрації випуску акцій та інформації про емісію акцій згідно повноважень, встановлених пунктами 1.1, 1.3 цього Рішення, подає документи, передбачені Положенням про порядок реєстрації випуску акцій і облігацій підприємств та інформації про їх емісію (07-01/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку від 12.02.98 N 36, для відкритих акціонерних товариств, або Положенням про порядок реєстрації випуску акцій закритими акціонерними товариствами (07-06/98), що затверджене рішенням Державної комісії з цінних паперів та фондового ринку від 12.02.98 N 41 - для закритих акціонерних товариств.

4. Вважати такими, що втратили чинність, рішення Державної комісії з цінних паперів та фондового ринку від 18.04.97 N 1 ( v0001312-97 ), від 11.12.97 N 63 ( v0063312-97 ) та наказ Державної комісії з цінних паперів та фондового ринку від 06.11.96 N 267 ( z0674-96 ).

5. Управлінню корпоративних фінансів - надавати постійну методичну допомогу територіальним управлінням Комісії та здійснювати координацію діяльності територіальних органів Комісії щодо реєстрації випуску акцій акціонерних товариств відповідно до переданих повноважень.

6. Рішення набуває чинності відповідно до чинного законодавства.

7. Прес-центру Комісії забезпечити опублікування цього рішення у встановленому порядку.

8. Контроль за виконанням цього рішення покласти на Члена Комісії О.Бойка.

Т.в.о.Голови Комісії О.Ромашко
