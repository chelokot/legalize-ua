Деякі питання використання у 2011 році державних капітальних видатків

Текст документа від 11.05.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 травня 2011 р. N 414-р Київ

Деякі питання використання у 2011 році державних капітальних видатків

1. Здійснити у межах загального обсягу бюджетних призначень, передбачених у 2011 році Міністерству фінансів у загальному фонді державного бюджету ( 2857-17 ), перерозподіл видатків розвитку в сумі 97523 тис. гривень шляхом зменшення їх обсягу за програмою 3501430 "Створення єдиної інформаційно-аналітичної системи обліку та управління коштами соціальної сфери та пенсійного забезпечення і запровадження електронної соціальної картки" та збільшення їх обсягу за програмою 3511090 "Державні капітальні видатки, що розподіляються Кабінетом Міністрів України".

2. Передати бюджетні призначення, передбачені у 2011 році Міністерству фінансів у загальному фонді державного бюджету ( 2857-17 ) (загальнодержавні витрати) за програмою 3511090 "Державні капітальні видатки, що розподіляються Кабінетом Міністрів України", у сумі 97523 тис. гривень головним розпорядникам бюджетних коштів, у тому числі:

1) Міністерству освіти і науки, молоді та спорту - 5000 тис. гривень для проведення капітального ремонту будівель і споруд баз олімпійської підготовки державної форми власності та розроблення проектно-кошторисної документації для будівництва зазначених баз;

2) Державній судовій адміністрації - 1500 тис. гривень для придбання Вищою кваліфікаційною комісією суддів технічного обладнання та програмного забезпечення з метою проведення тестування (іспиту) для кандидатів на посаду судді вперше;

3) Державному управлінню справами - 69611 тис. гривень для завершення будівництва Всеукраїнського центру радіохірургії;

4) Національній академії наук - 2700 тис. гривень для створення інформаційно-аналітичної підсистеми стратегічного планування з метою формування прогнозного енергетичного балансу;

5) Національній академії медичних наук - 3012 тис. гривень для проведення реконструкції та капітального ремонту будівель Національного інституту фтизіатрії і пульмонології імені Ф.Г. Яновського Національної академії медичних наук;

6) Волинській облдержадміністрації - 700 тис. гривень для технічного оснащення та проведення капітального ремонту приміщень державного архіву області;

7) Луганській облдержадміністрації - 15000 тис. гривень для проведення капітального ремонту футбольного поля та реконструкції систем освітлення Луганського обласного фізкультурно-оздоровчого центру "Авангард".

Передачу бюджетних призначень здійснити в межах видатків розвитку.

3. Забезпечити:

1) головним розпорядникам бюджетних коштів:

погодження перерозподілу видатків та передачі бюджетних призначень, передбачених цим розпорядженням, з Комітетом Верховної Ради України з питань бюджету;

подання щомісяця до 5 числа Міністерству фінансів звіту про використання бюджетних коштів;

2) після зазначеного погодження:

Міністерству фінансів - відкриття у разі потреби нових бюджетних програм та внесення відповідних змін до розпису державного бюджету;

Державній казначейській службі - перерахування бюджетних коштів відповідно до переданих бюджетних призначень.

Прем'єр-міністр України М.АЗАРОВ
