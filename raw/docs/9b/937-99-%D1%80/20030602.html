Кабінет Міністрів України; Розпорядження від 08.09.1999 № 937-р

Про передачу в безпосереднє управління облдержадміністрації належних державі пакетів акцій ВАТ "Перещепинський елеватор", "Губиниський елеватор" та "Губиниський цукровий завод".

Стан: Втратив чинність

Ідентифікатор: 937-99-р

Текст документа від 02.06.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 вересня 1999 р. N 937-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 818 ( 818-2003-п ) від 02.06.2003 )

1. Прийняти пропозицію Дніпропетровської облдержадміністрації, погоджену з Національним агентством з управління державними корпоративними правами про передачу в безпосереднє управління облдержадміністрації належних державі пакетів акцій відкритих акціонерних товариств "Перещепинський елеватор", "Губиниський елеватор" та "Губиниський цукровий завод".

2. Національному агентству з управління державними корпоративними правами розробити та затвердити умови передачі та завдання з управління державними корпоративними правами зазначених відкритих акціонерних товариств.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
