Кабінет Міністрів України; Постанова від 01.07.2009 № 659

Питання наглядової ради публічного акціонерного товариства "Державний експортно-імпортний банк України" та відкритого акціонерного товариства "Державний ощадний банк України"

Стан: Втратив чинність

Ідентифікатор: 659-2009-п

Текст документа від 18.03.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 липня 2009 р. N 659 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 70 ( 70-2014-п ) від 12.03.2014 }

Питання наглядової ради публічного акціонерного товариства "Державний експортно-імпортний банк України" та відкритого акціонерного товариства "Державний ощадний банк України"

{ Із змінами, внесеними згідно з Постановами КМ N 304 ( 304-2010-п ) від 29.03.2010 N 359 ( 359-2010-п ) від 26.05.2010 N 907 ( 907-2010-п ) від 04.10.2010 }

1. Відповідно до статті 7 Закону України "Про банки і банківську діяльність" ( 2121-14 ) Кабінет Міністрів України постановляє:

Призначити членами наглядової ради публічного акціонерного товариства "Державний експортно-імпортний банк України":

КУШНІРЕНКА - керівника Апарату Прем'єр-міністра

Олександра Миколайовича України

ЛЮБЧЕНКА - першого заступника Міністра Кабінету Костянтина Валерійовича Міністрів України

МЯРКОВСЬКИЙ - заступник Міністра фінансів

Анатолій Іванович

РИБАКА - заступника Міністра фінансів

Сергія Олександровича

ХАРЧЕНКА - Голову Державного казначейства.

Сергія Івановича

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 304 ( 304-2010-п ) від 29.03.2010, N 359 ( 359-2010-п ) від 26.05.2010, N 907 ( 907-2010-п ) від 04.10.2010 }

2. На часткову зміну пункту 1 постанови Кабінету Міністрів України від 16 січня 2008 р. N 12 ( 12-2008-п ) "Про призначення членів наглядової ради відкритого акціонерного товариства "Державний ощадний банк України" - із змінами, внесеними постановою Кабінету Міністрів України від 16 липня 2008 р. N 648 ( 648-2008-п ) (Офіційний вісник України, 2008 р., N 53, ст. 1780):

призначити членом наглядової ради відкритого акціонерного товариства "Державний ощадний банк України" Мярковського Анатолія Івановича - заступника Міністра фінансів;

припинити повноваження члена наглядової ради відкритого акціонерного товариства "Державний ощадний банк України" Морозова Олександра Валерійовича.
