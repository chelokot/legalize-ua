Кабінет Міністрів України; Розпорядження від 29.10.2005 № 439-р

Про затвердження керівника групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий строк і здійснення контролю за її виконанням

Стан: Втратив чинність

Ідентифікатор: 439-2005-р

Текст документа від 14.11.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 жовтня 2005 р. N 439-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 453-р ( 453-2005-р ) від 14.11.2005 )

Про затвердження керівника групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий строк і здійснення контролю за її виконанням

Затвердити Міністра праці та соціальної політики Саханя Івана Яковича керівником групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий строк і здійснення контролю за її виконанням ( 814-2003-р ), увільнивши від цих обов'язків Кириленка В'ячеслава Анатолійовича.

Прем'єр-міністр України Ю.ЄХАНУРОВ
