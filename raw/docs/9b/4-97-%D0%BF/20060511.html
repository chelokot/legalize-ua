Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 січня 1997 р. N 4 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Про внесення зміни до постанови Кабінету Міністрів України від 28 вересня 1996 р. N 1190 "Питання Міністерства у справах науки і технологій"

( Постанова втратила чинність в частині кількості заступників Міністра на підставі Постанови КМ N 537 ( 537-97-п ) від 06.06.97 )

Кабінет Міністрів України постановляє:

Пункт 2 постанови Кабінету Міністрів України від 28 вересня 1996 р. N 1190 ( 1190-96-п ) "Питання Міністерства у справах науки і технологій" викласти у такій редакції:

"2. Дозволити Міністерству у справах науки і технологій мати п'ятьох заступників Міністра, у тому числі одного першого, і колегію в складі 27 чоловік".

Прем'єр-міністр України П.ЛАЗАРЕНКО
