НАКАЗ Міністра оборони України

27.11.2006 N 679

Зареєстровано в Міністерстві юстиції України 8 грудня 2006 р. за N 1295/13169

{ Наказ втратив чинність на підставі Наказу Міністерства оборони N 360 ( z0704-14 ) від 05.06.2014 }

Про затвердження Змін до Інструкції про проведення військово-професійної орієнтації молоді та вступних випробувань у вищих військових навчальних закладах Міністерства оборони України та військових навчальних підрозділах вищих навчальних закладів України

Відповідно до Закону України "Про вищу освіту" ( 2984-14 ) та з метою створення цілісної системи професійного росту офіцерів, подальшого вдосконалення роботи щодо організації прийому осіб офіцерського складу Збройних Сил України для навчання на оперативно-стратегічному рівні в Національній академії оборони України НАКАЗУЮ:

1. Затвердити Зміни до Інструкції про проведення військово-професійної орієнтації молоді та вступних випробувань у вищих військових навчальних закладах Міністерства оборони України та військових навчальних підрозділах вищих навчальних закладів України, затвердженої наказом Міністра оборони України від 14 квітня 1998 року N 152 ( z0398-98 ), зареєстрованої у Міністерстві юстиції України 25 червня 1998 року за N 398/2838 (зі змінами), що додаються.

2. Наказ розіслати до з'єднання та військових комісаріатів.

Міністр оборони України А.С.Гриценко

ЗАТВЕРДЖЕНО Наказ Міністра оборони України 27.11.2006 N 679

Зареєстровано в Міністерстві юстиції України 8 грудня 2006 р. за N 1295/13169

ЗМІНИ до Інструкції про проведення військово-професійної орієнтації молоді та вступних випробувань у вищих військових навчальних закладах Міністерства оборони України та військових навчальних підрозділах вищих навчальних закладів України ( z0398-98 )

Підпункт 3.2.1 доповнити абзацом четвертим такого змісту:

"віком до 40 років - зі штатно-посадовою категорією підполковник (капітан 2-го рангу) з посад заступників командирів бригад";

абзаци четвертий - шостий уважати абзацами п'ятим - сьомим відповідно.
