Питання укладення деяких договорів

Стан: Втратив чинність

Текст документа від 20.04.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 травня 2008 р. N 703-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 296 ( 296-2012-п ) від 11.04.2012 }

Питання укладення деяких договорів

{ Із змінами, внесеними згідно з Постановою КМ N 530 ( 530-2009-п ) від 17.04.2009 }

Для підвищення ефективності управління об'єктами державної власності, забезпечення прозорої процедури їх відчуження та недопущення порушення інтересів держави центральним органам виконавчої влади, іншим суб'єктам управління об'єктами державної власності, у тому числі Національній та галузевим академіям наук:

забезпечити укладення підприємствами, установами та організаціями, що належать до сфери їх управління (віднесені до їх відання), господарськими товариствами, у статутному фонді яких частка держави перевищує 50 відсотків, договорів про спільну діяльність, договорів комісії, доручення, управління майном виключно на підставі відповідних рішень Кабінету Міністрів України; { Абзац другий із змінами, внесеними згідно з Постановою КМ N 530 ( 530-2009-п ) від 17.04.2009 }

вжити заходів до припинення договорів про спільну (зокрема інвестиційну) діяльність, раніше укладених суб'єктами, зазначеними в абзаці другому цього розпорядження, наслідком яких може бути відчуження державного майна.

Прем'єр-міністр України Ю.ТИМОШЕНКО
