Кабінет Міністрів України; Розпорядження від 25.11.1999 № 1290-р

Про продовження терміну перебування машинокомплектів для промислового складання автомобілів, що надійшли за контрактом між "Укрінмаш" та "Хенде Корпорейшн" (Корея)

Стан: Втратив чинність

Ідентифікатор: 1290-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 листопада 1999 р. N 1290-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі продовжити термін перебування машинокомплектів для промислового складання автомобілів, які надійшли за контрактом від 21 вересня 1996 р. N ЛС-96092101М/9-ТК, укладеним між корпорацією "Укрінмаш" та фірмою "Хенде Корпорейшн" (Корея), на відповідальному зберіганні на території корпорації "Укрінмаш" до 31 березня 2000 р. без нарахування митного збору за їх перебування під митним контролем.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
