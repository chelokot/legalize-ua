МІНІСТЕРСТВО ЕКОЛОГІЇ ТА ПРИРОДНИХ РЕСУРСІВ УКРАЇНИ

НАКАЗ

17.06.2011 N 202

Зареєстровано в Міністерстві юстиції України 4 липня 2011 р. за N 808/19546

Про визнання такими, що втратили чинність, деяких наказів Міністерства екології та природних ресурсів України і Державного комітету України по водному господарству

Відповідно до статті 4 Закону України "Про основні засади державного нагляду (контролю) у сфері господарської діяльності" ( 877-16 ), Указів Президента України від 09.12.2010 N 1085 ( 1085/2010 ) "Про оптимізацію системи центральних органів виконавчої влади", від 13.04.2011 N 452 ( 452/2011 ) "Про Положення про Міністерство екології та природних ресурсів України", від 13.04.2011 N 453 ( 453/2011 ) "Про Положення про Державне агентство водних ресурсів України" та з метою приведення нормативно-правових актів у відповідність до вимог чинного законодавства України НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

наказ Державного комітету України по водному господарству від 29.01.2001 N 20 ( z0124-01 ) "Про затвердження Положення про здійснення органами Держводгоспу України контролю за раціональним використанням, охороною та відтворенням водних ресурсів", зареєстрований у Міністерстві юстиції України 09.02.2001 за N 124/5315;

наказ Міністерства екології та природних ресурсів України, Державного комітету України по водному господарству від 29.01.2001 N 13/21 ( z0125-01 ) "Про затвердження Порядку взаємодії органів Державного комітету України по водному господарству і Міністерства екології та природних ресурсів України з питань здійснення контролю за раціональним використанням, охороною та відтворенням водних ресурсів", зареєстрований у Міністерстві юстиції України 09.02.2001 за N 125/5316;

наказ Державного комітету України по водному господарству від 29.12.2001 N 290 ( z0044-02 ) "Про затвердження Методики розрахунку розмірів відшкодування збитків, заподіяних державі внаслідок порушення правил охорони водних ресурсів на землях водного фонду, пошкодження водогосподарських споруд і пристроїв, порушення правил їх експлуатації", зареєстрований у Міністерстві юстиції України 18.01.2002 за N 44/6332;

наказ Державного комітету України по водному господарству від 07.12.2009 N 223 ( z1271-09 ) "Про затвердження Порядку організації та проведення перевірок суб'єктів господарювання, що використовують водні ресурси або здійснюють господарську діяльність у межах земель водного фонду", зареєстрований у Міністерстві юстиції України 30.12.2009 за N 1271/17287.

2. Начальникові управління комплексного використання водних ресурсів Державного агентства водних ресурсів України О.Лисюк в установленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Д.Мормуля.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

Перший заступник Міністра М.І.Романов
