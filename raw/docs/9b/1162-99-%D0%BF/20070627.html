КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 червня 1999 р. N 1162 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 879 ( 879-2007-п ) від 27.06.2007 }

Про внесення доповнення до Порядку збору та використання коштів для фінансування витрат, пов'язаних з будівництвом, реконструкцією, ремонтом і утриманням автомобільних доріг загального користування

Кабінет Міністрів України постановляє:

Доповнити пункт 14 Порядку збору та використання коштів для фінансування витрат, пов'язаних з будівництвом, реконструкцією, ремонтом і утриманням автомобільних доріг загального користування, затвердженого постановою Кабінету Міністрів України від 2 лютого 1993 р. N 83 ( 83-93-п ) (ЗП України, 1993 р., N 4 - 5, ст. 83, N 11, ст. 225; 1994 р., N 4, ст. 104, N 10, ст. 237; 1995 р., N 5, ст. 133; Офіційний вісник України, 1997 р., N 21, ст. 22), абзацом такого змісту:

"Збір за проїзд по автомобільних дорогах транспортних засобів, вагові або габаритні параметри яких перевищують нормативні, не справляється з Міноборони за транспортування міжконтинентальних балістичних ракет РС-22 маршрутами від місць постійної дислокації (зберігання) до місць ліквідації. Відповідальність за підготовку та підтримання у безаварійному стані ділянок автомобільних доріг та штучних споруд під час транспортування ними зазначених вантажів, а також їх відновлення в разі виявлення пошкоджень, що виникли внаслідок транспортування цих вантажів, покладається на Міноборони".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
