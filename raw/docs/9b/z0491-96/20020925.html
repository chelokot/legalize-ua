ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ПО СТАНДАРТИЗАЦІЇ, МЕТРОЛОГІЇ ТА СЕРТИФІКАЦІЇ

НАКАЗ

N 345 від 16.08.96 Зареєстровано в Міністерстві м.Київ юстиції України 30 серпня 1996 р. за N 491/1516

{ Наказ втратив чинність на підставі Наказу Державного комітету стандартизації, метрології та сертифікації N 498 ( z0782-02 ) від 30.08.2002 }

Про внесення доповнень до Переліку продукції, що підлягає

обов'язковій сертифікації в Україні, затвердженого наказом Держстандарту України від 30.06.93 р. N 95

Відповідно до Декрету Кабінету Міністрів України від 10 травня 1993 року N 46-93 "Про стандартизацію і сертифікацію" та на виконання постанови Кабінету Міністрів України від 14 серпня 1996 року N 946 ( 946-96-п ) "Про подальше вдосконалення контролю за якістю тютюнових виробів, що імпортуються в Україну" НАКАЗУЮ:

1. Доповнити розділ 30 Переліку продукції, що підлягає обов'язковій сертифікації в Україні, затверджений наказом Держстандарту від 30 червня 1993 року N 95 ( z0112-93 ) зі змінами і доповненнями, внесеними наказами від 21 лютого 1994 року N 35 ( z0069-94 ), від 6 лютого 1995 року N 44 ( z0040-95 ), від 19 травня 1995 року N 161 ( z0170-95 ), від 26 червня 1995 року N 215 ( z0203-95 ), від 22 грудня 1995 року N 437 ( z0479-95 ), від 3 січня 1996 року N 1 ( z0026-96 ), від 26 березня 1996 року N 132 ( z0156-96 ), від 11 червня 1996 року N 230 ( z0323-96 ), від 11 червня 1996 року N 235 ( z0311-96 ), підрозділом 30.34 (додається).

2. Встановити, що тютюнові вироби підлягають обов'язковій сертифікації в Україні у відповідності з вимогами нормативних документів державної системи сертифікації УкрСЕПРО з 10 вересня 1996 року.

3. Призначити органами з сертифікації тютюнових виробів Український центр стандартизації, метрології та сертифікації, Кримський центр стандартизації, метрології та сертифікації, Черкаський центр стандартизації, метрології та сертифікації.

4. Призначеним органам до 1 грудня 1996 року підготувати і подати до Держстандарту документи, необхідні для акредитації.

5. Управлінню стандартизації, сертифікації та держнагляду сировини, матеріалів, харчової продукції та послуг забезпечити до 1 січня 1997 року підготовку необхідних нормативних документів, атестацію випробувальних лабораторій та акредитацію органів з сертифікації, а також довести цей наказ до відома країн-членів СНД, зацікавлених міністерств, відомств та суб'єктів підприємницької діяльності України.

Перший заступник Голови Держстандарту України Ю.Рубан
