Кабінет Міністрів України; Постанова від 15.09.1997 № 1017

Питання Міністерства енергетики

Стан: Втратив чинність

Ідентифікатор: 1017-97-п

Текст документа від 19.05.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 вересня 1997 р. N 1017 Київ

Питання Міністерства енергетики

( Із змінами, внесеними згідно з Постановою КМ N 844 ( 844-99-п ) від 19.05.99 )

На виконання Указу Президента України від 6 травня 1997 р. N 388 ( 388/97 ) "Про утворення Міністерства енергетики України" Кабінет Міністрів України постановляє:

1. Установити граничну чисельність працівників центрального апарату Міністерства енергетики у кількості 430 одиниць. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 844 ( 844-99-п ) від 19.05.99 )

2. Дозволити Міністерству енергетики мати 7 заступників Міністра, у тому числі одного першого, а також колегію у кількості 23 осіб. ( Пункт 2 в редакції Постанови КМ N 844 ( 844-99-п ) від 19.05.99 )

3. Дозволити Міністерству енергетики здійснювати витрати на утримання центрального апарату Міністерства за рахунок централізованого галузевого фонду, який утворюється за згодою підприємств, установ та організацій, що належать до сфери управління Міністерства, в межах кошторису, затвердженого Міністерством фінансів.

Прем'єр-міністр України В. ПУСТОВОЙТЕНКО
