Про затвердження нормативних актів-переліків лікарських засобів

( Із змінами, внесеними згідно з Наказами Міністерства охорони здоров'я N 46 ( z0248-96 ) від 01.03.96 N 211 ( z0439-03 ) від 14.05.2003 )

З метою координації лікарського забезпечення населення, НАКАЗУЮ:

1. Затвердити:

1.1. Перелік лікарських засобів, які дозволені до застосування при наданні медичної допомоги населенню України в 1995 році (додаток N 1);

1.2. Перелік ліків обов'язкового асортименту для аптечної мережі (додаток N 2) ( z0360-95 );

1.3. Перелік препаратів, що відпускаються за рецептом (додаток N 3) ( z0361-95 );

1.4. Перелік препаратів, що відпускаються без рецепта (додаток N 4) ( z0362-95 );

1.5. Перелік отруйних лікарських засобів, які зареєстровані та дозволені до використання (додаток N 5) ( z0363-95 );

1.6. Перелік сильнодіючих речовин, які зареєстровані та дозволені до використання (додаток N 6) ( z0364-95 ).

2. Надіслати зазначені переліки до Міністерства юстиції України для державної реєстрації.

3. Після державної реєстрації надіслати зазначені документи в установи охорони здоров'я за переліком (додається).

4. Контроль за виконанням наказу покласти на заступника Міністра Юрченка В.Д.
