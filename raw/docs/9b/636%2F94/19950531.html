Президент України; Указ від 22.10.1994 № 636/94

Про Фонд підтримки досліджень у сфері національної безпеки

Стан: Втратив чинність

Ідентифікатор: 636/94

Текст документа від 31.05.1995:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Фонд підтримки досліджень у сфері національної безпеки

( Із змінами, внесеними згідно з Указом Президента N 405/95 ( 405/95 ) від 31.05.95 )

З метою підтримки розвитку фундаментальних наукових досліджень у сфері національної безпеки та відповідно до пункту 7-4 статті 114-5 Конституції України ( 888-09 ) постановляю:

1. Підтримати ініціативу ряду комерційних банків та інших суб'єктів підприємницької діяльності, зокрема АБ "Inko", АКБ "Аваль", АБ "Ліга", КБ "Приватбанк", Українського клубу "Б.А.Н.К.", фірми "Еланда", "Київської енергетичної компанії", і утворити благодійний фонд - Фонд підтримки досліджень у сфері національної безпеки (далі - Фонд), установивши особливий порядок його утворення та діяльності.

2. Кошти Фонду формуються за рахунок благодійних пожертвувань і добровільних внесків фізичних і юридичних осіб, а також інших надходжень, одержаних на підставах, не заборонених законодавством України.

( Частина друга статті 2 втратила чинність на підставі Указу Президента N 405/95 ( 405/95 ) від 31.05.95 )

( Частина третя статті 2 втратила чинність на підставі Указу Президента N 405/95 ( 405/95 ) від 31.05.95 )

3. Призначити КРИВОРОГА Валерія Леонідовича головою Фонду підтримки досліджень у сфері національної безпеки.

4. В.Криворогу подати у місячний строк проект Положення про Фонд підтримки досліджень у сфері національної безпеки.

5. Для визначення основних напрямків діяльності Фонду та здійснення контролю за цільовим використанням коштів Фонду створюються Експертна рада Фонду підтримки досліджень у сфері національної безпеки та Наглядова рада Фонду підтримки досліджень у сфері національної безпеки.

Призначити Горбуліна Володимира Павловича головою Експертної ради Фонду підтримки досліджень у сфері національної безпеки, Марчука Євгена Кириловича - головою Наглядової ради Фонду підтримки досліджень у сфері національної безпеки.

6. Рекомендувати органам, уповноваженим управляти майном, що перебуває у державній власності, вирішувати питання виділення приміщень для Фонду.

Президент України Л.КУЧМА
