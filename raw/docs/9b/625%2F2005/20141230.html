Президент України; Указ, Перелік від 11.04.2005 № 625/2005

Про додаткові заходи щодо підвищення ефективності діяльності Консультативної ради з питань іноземних інвестицій в Україні

Стан: Втратив чинність крім окремих положень

Ідентифікатор: 625/2005

Текст документа від 30.12.2014:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність, крім пункту 1 статті 4, на підставі Указу Президента

N 892/2010 ( 892/2010 ) від 01.09.2010 }

Про додаткові заходи щодо підвищення ефективності діяльності Консультативної ради з питань іноземних інвестицій в Україні

{ Із змінами, внесеними згідно з Указами Президента N 1332/2005 ( 1332/2005 ) від 23.09.2005 N 950/2014 ( 950/2014 ) від 24.12.2014 }

З метою поліпшення інвестиційного клімату, активізації іноземного інвестування, усунення перешкод у здійсненні іноземними інвесторами діяльності в Україні постановляю:

1. Визначити одним із головних завдань Консультативної ради з питань іноземних інвестицій в Україні сприяння поліпшенню інвестиційного клімату в Україні.

2. Встановити, що для розроблення пропозицій щодо вдосконалення законодавства про інвестиційну діяльність, спрощення процедур здійснення інвестицій та їх повернення, реінвестування, утворюється експертна комісія Консультативної ради з питань іноземних інвестицій в Україні.

( Стаття 2 із змінами, внесеними згідно з Указом Президента N 1332/2005 ( 1332/2005 ) від 23.09.2005 )

3. Визначити одним із критеріїв добору іноземних осіб для залучення до складу Консультативної ради з питань іноземних інвестицій в Україні багаторічний досвід роботи в інноваційній сфері та визначальний вплив на світові тенденції її розвитку.

4. Внести до Указу Президента України від 11 квітня 1997 року N 323 ( 323/97 ) "Про Консультативну раду з питань іноземних інвестицій в Україні" (зі змінами, внесеними Указами від 24 жовтня 2000 року N 1162 ( 1162/2000 ) та від 1 квітня 2002 року N 310 ( 310/2002 ) такі зміни:

{ Пункт 1 статті 4 втратив чинність на підставі Указу Президента N 950/2014 ( 950/2014 ) від 24.12.2014 }

2) у Положенні про Консультативну раду з питань іноземних інвестицій в Україні, затвердженому зазначеним Указом Президента України:

а) у пункті 3:

абзац другий після слів "сприяє визначенню основних засад державної політики щодо" доповнити словами "поліпшення інвестиційного клімату в Україні";

після абзацу п'ятого доповнити абзацом такого змісту:

"готує пропозиції щодо стимулювання інвестиційної діяльності, зокрема з урахуванням досвіду інших держав у сфері залучення іноземних інвестицій, та щодо усунення перешкод, які негативно впливають на інвестиційний клімат в Україні".

У зв'язку з цим абзаци шостий - восьмий вважати відповідно абзацами сьомим - дев'ятим;

б) абзац третій пункту 4 викласти в такій редакції:

"утворювати робочі, експертні групи та комісії";

в) у пункті 6:

абзац четвертий викласти в такій редакції:

"багаторічний досвід роботи в інноваційній сфері, визначальний вплив на світові тенденції її розвитку";

абзац шостий викласти в такій редакції:

"представництво широких кіл іноземних інвесторів, що активно здійснюють інвестиційну діяльність в Україні";

г) у першому реченні абзацу першого пункту 7 слова "один раз" замінити словами "не рідше одного разу";

д) в абзаці другому пункту 10 слова "робочих органів (робочих та експертних груп)" замінити словами "робочих, експертних груп та комісій";

е) доповнити Положення пунктом 13 такого змісту:

"13. Для розроблення пропозицій щодо вдосконалення законодавства про інвестиційну діяльність, спрощення процедур здійснення інвестицій та їх повернення, реінвестування, сприяння у позасудовому врегулюванні спорів, які виникають між іноземними інвесторами, органами виконавчої влади та органами місцевого самоврядування у зв'язку з іноземним інвестуванням в економіку України, у підготовці інвестиційних проектів, надання консультативної допомоги іноземним інвесторам утворюється експертна комісія Консультативної ради".

5. Визнати такими, що втратили чинність, акти Президента України згідно з переліком (додається).

Президент України В.ЮЩЕНКО

м. Київ, 11 квітня 2005 року N 625/2005
