МІНІСТЕРСТВО УКРАЇНИ З ПИТАНЬ НАДЗВИЧАЙНИХ СИТУАЦІЙ ТА У СПРАВАХ ЗАХИСТУ НАСЕЛЕННЯ ВІД НАСЛІДКІВ ЧОРНОБИЛЬСЬКОЇ КАТАСТРОФИ

НАКАЗ

11.07.2006 N 436

Зареєстровано в Міністерстві юстиції України 31 липня 2006 р. за N 897/12771

Про внесення змін до наказів МНС України від 19.06.2003 N 201, від 17.11.2003 N 441

{ Із змінами, внесеними згідно з Наказом Міністерства внутрішніх справ N 161 ( z0205-15 ) від 16.02.2015 }

Відповідно до вимог статті 11 Закону України "Про аварійно-рятувальні служби" ( 1281-14 ) та Положення про Міністерство України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, затвердженого Указом Президента України від 10.10.2005 N 1430 ( 1430/2005 ), (із змінами), з метою визначення порядку атестації аварійно-рятувальних служб та рятувальників, ведення реєстру аварійно-рятувальних служб і тимчасового зупинення діяльності неатестованих аварійно-рятувальних служб та рятувальників НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства внутрішніх справ N 161 ( z0205-15 ) від 16.02.2015 }

2. Затвердити Зміни до наказу МНС України від 17.11.2003 N 441 ( z1120-03 ) "Про затвердження Положення про Центральну міжвідомчу атестаційну комісію", зареєстрованого в Міністерстві юстиції України 04.12.2003 за N 1120/8441 (із змінами), та Положення про Центральну міжвідомчу атестаційну комісію з атестації аварійно-рятувальних служб та рятувальників, затвердженого цим наказом, що додаються ( z0898-06 ).

3. Державній інспекції цивільного захисту та техногенної безпеки (Стоєцький В.Ф.) та Управлінню правового забезпечення (Сухар А.В.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Державному підприємству "Чорнобильінтерінформ" (Кір'якову Д.М.) після реєстрації цього наказу в Міністерстві юстиції України опублікувати його у журналах "Надзвичайна ситуація", "Пожежна безпека".

5. Контроль за виконанням цього наказу покласти на заступника Міністра Романченка В.О.

Міністр В.І.Балога
