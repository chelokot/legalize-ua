КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 червня 2009 р. N 839-р Київ

Про затвердження проекту та титулу будови "Реконструкція існуючих та будівництво нових об'єктів Національного спортивного комплексу "Олімпійський" (м. Київ)", реконструкція та будівництво якої розпочалося у 2008 році, та внесення змін до розпорядження Кабінету Міністрів України від 20 серпня 2008 р. N 1128

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1586-р ( 1586-2010-р ) від 28.07.2010 }

1. Затвердити поданий Мінсім'ямолодьспортом проект "Реконструкція існуючих та будівництво нових об'єктів Національного спортивного комплексу "Олімпійський" (м. Київ)" (архітектурно-конструктивні, інженерні та технологічні рішення), розроблений компанією GMP Generelplanungsgesellschaft (Німеччина) та рекомендований до затвердження державним підприємством "Укрдержбудекспертиза" Мінрегіонбуду з такими техніко-економічними показниками:

реконструкція стадіону, у тому числі трибун верхнього та нижнього ярусів, vip-корпусу, підземного паркингу тощо;

демонтаж окремих споруд;

перенесення інженерних мереж з-під зони забудови;

будівництво естакади, об'їзної дороги, підпірних стін, зони для вболівальників;

влаштування інженерних мереж та упорядження стадіону;

відновлення після проведення фінальної частини чемпіонату Європи 2012 року з футболу легкоатлетичних секторів та доріжок, з такими технічними показниками:

площа ділянки, кв. метрів - 168800

у тому числі:

площа озеленення - 20332

площа доріг і пішохідних доріжок - 71755

площа забудови, кв. метрів - 76691

у тому числі:

vip-сектор - 21368

підземний паркинг - 12070

будівельний об'єм, куб. метрів - 276366

кількість ярусів - 2

кількість місць для глядачів - 69004

у тому числі:

для інвалідів - 125

у vip-секторі - 10221

2. Затвердити титул будови "Реконструкція існуючих та будівництво нових об'єктів Національного спортивного комплексу "Олімпійський" (м. Київ)", реконструкція та будівництво якої розпочалося у 2008 році, що додається.

{ Пункт 3 виключено на підставі Розпорядження КМ N 1586-р ( 1586-2010-р ) від 28.07.2010 }

4. Внести зміни до титулу на виконання проектно-вишукувальних робіт для реконструкції Національного спортивного комплексу "Олімпійський", затвердженого розпорядженням Кабінету Міністрів України від 20 серпня 2008 р. N 1128 ( 1128-2008-р ), виклавши його в редакції, що додається.

5. Мінсім'ямолодьспорту забезпечити зменшення вартості робіт з реконструкції існуючих та будівництва нових об'єктів Національного спортивного комплексу "Олімпійський" шляхом переважного залучення до таких робіт національних товаровиробників.

6. Затвердити на підставі скоригованого позитивного висновку державного підприємства "Укрдержбудекспертиза" Мінрегіонбуду такі показники проекту "Реконструкція існуючих та будівництво нових об'єктів Національного спортивного комплексу "Олімпійський" (м. Київ)":

загальна кошторисна вартість, - 3005977,591 тис. гривень

у тому числі:

будівельно-монтажних робіт - 1736783,933

устатковання - 349051,07

пусконалагоджувальних робіт - 4370,441

інші витрати - 915772,147. { Розпорядження доповнено пунктом 6 згідно з Розпорядженням КМ N 1586-р ( 1586-2010-р ) від 28.07.2010 }

7. Київ)", реконструкція та будівництво якої розпочалися у 2008 році, подати на затвердження Кабінету Міністрів України проект відповідного рішення.
