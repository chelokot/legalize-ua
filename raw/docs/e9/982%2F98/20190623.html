Президент України; Указ від 07.09.1998 № 982/98

Про регулювання розміру плати за користування тимчасово вільними залишками бюджетних коштів і коштів державних позабюджетних фондів

Стан: Втратив чинність

Ідентифікатор: 982/98

Текст документа від 23.06.2019:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 418/2019 ( 418/2019 ) від 20.06.2019 }

Про регулювання розміру плати за користування тимчасово вільними залишками бюджетних коштів і коштів державних позабюджетних фондів

{ Із змінами, внесеними згідно із Законом N 2473-VIII ( 2473-19 ) від 21.06.2018, ВВР, 2018, N 30, ст.239 }

1. Кабінету Міністрів України разом з Національним банком України встановити у двотижневий строк порядок внесення комерційними банками плати за користування тимчасово вільними залишками бюджетних коштів і коштів державних позабюджетних фондів та визначати розмір цієї плати залежно від ситуації на фінансовому ринку.

{ Дію статті 2 припинено в частині внесення змін до Указу Президента N 41 ( 41/98 ) від 21.01.98 згідно із Законом N 2473-VIII ( 2473-19 ) від 21.06.2018 }

2. Визнати такими, що втратили чинність, статтю 6 Указу Президента України від 1 травня 1995 року N 343 ( 343/95 ) "Про заходи щодо зміцнення фінансової дисципліни при виконанні Державного бюджету України" та статтю 12 Указу Президента України від 21 січня 1998 року N 41 ( 41/98 ) "Про запровадження режиму жорсткого обмеження бюджетних видатків та інших державних витрат, заходи щодо забезпечення надходження доходів до бюджету і запобігання фінансовій кризі".

Президент України Л.КУЧМА

м. Київ, 7 вересня 1998 року N 982/98
