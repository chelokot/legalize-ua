Про призупинення дії наказу Державного комітету зв'язку та інформатизації України від 04.01.2003 N 1

Відповідно до Закону України "Про зв'язок" ( 160/95-ВР ), з метою врахування вимог щодо вступу України до Європейського Союзу та Світової Організації Торгівлі у сфері електрозв'язку, більш повного врахування рекомендацій Міжнародного Союзу Електрозв'язку щодо взаєморозрахунків між операторами за проведені міжнародні та міжміські телефонні розмови, а також з метою доопрацювання ряду техніко-економічних положень та усунення технічних помилок у Порядку взаєморозрахунків між операторами за проведені міжнародні та міжміські телефонні розмови, затвердженому наказом Державного комітету зв'язку та інформатизації України від 04.01.2003 N 1 ( z0108-03 ), НАКАЗУЮ:

1. Призупинити дію наказу Державного комітету зв'язку та інформатизації України від 04.01.2003 N 1 ( z0108-03 ), зареєстрованого в Міністерстві юстиції України 10.02.2003 за N 108/7429.

2. На період призупинення дії зазначеного наказу є чинним і застосовується наказ Міністерства зв'язку України від 30.10.96 N 234 ( z0673-96 ) "Про Порядок взаєморозрахунків між операторами міжміського, міжнародного та місцевого телефонного зв'язку різних форм власності", зареєстрований в Міністерстві юстиції України 21.11.96 за N 673/1698.

3. Для доопрацювання Порядку взаєморозрахунків між операторами за проведені міжнародні та міжміські телефонні розмови ( z0108-03 ) створити робочу групу на чолі з першим заступником Голови Державного комітету зв'язку та інформатизації України М. Лобуновим.

4. Доручити першому заступнику Голови Державного комітету зв'язку та інформатизації України М. Лобунову підготувати проект наказу про склад робочої групи для доопрацювання Порядку взаєморозрахунків між операторами за проведені міжнародні та міжміські телефонні розмови ( z0108-03 ) з уключенням до неї представників операторів зв'язку.

5. Контроль за виконанням даного наказу залишаю за собою.

Голова М.Гончар
