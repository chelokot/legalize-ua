Текст документа від 16.01.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 серпня 2006 р. N 1266 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 13 ( 13-2008-п ) від 16.01.2008 }

Про затвердження складу наглядової ради Національного спортивного комплексу "Олімпійський"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 288-р ( 288-2007-р ) від 16.05.2007 }

Кабінет Міністрів України постановляє:

1. Затвердити склад наглядової ради Національного спортивного комплексу "Олімпійський", що додається.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 31 травня 2006 р. N 765 ( 765-2006-п ) "Про затвердження складу наглядової ради Національного спортивного комплексу "Олімпійський".
