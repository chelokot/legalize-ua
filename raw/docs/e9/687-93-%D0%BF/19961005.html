( Постанова втратила чинність на підставі Постанови КМ N 1245 ( 1245-96-п ) від 05.10.96 )

Про скасування акцизного збору на телевізори

Кабінет Міністрів України постановляє:

Виключити з переліку товарів (продукції), на які встановлюється акцизний збір, затвердженого постановою Кабінету Міністрів України від 26 грудня 1992 р. N 741 ( 741-92-п ) (ЗП України, 1993 р., N 1-2, ст. 27; N 6, ст. 116), телевізори кольорові та телевізори чорно-білого зображення.
