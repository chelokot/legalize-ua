Про обслуговування будинками відпочинку "Конча-Заспа" та "Пуща-Водиця" окремих категорій посадових осіб і пенсіонерів

Стан: Втратив чинність

Ідентифікатор: 1210-2003-п

Текст документа від 12.07.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 серпня 2003 р. N 1210 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про обслуговування будинками відпочинку "Конча-Заспа" та "Пуща-Водиця" окремих категорій посадових осіб і пенсіонерів

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 825-р ( 825-2004-р ) від 12.11.2004 N 166-р ( 166-2005-р ) від 28.05.2005 N 254-р ( 254-2005-р ) від 12.07.2005 }

Кабінет Міністрів України постановляє:

1. Затвердити перелік посадових осіб та категорій пенсіонерів, яким надається право користуватися приміщеннями в будинках відпочинку Державного управління справами, згідно з додатком. Оплату за користування приміщеннями проводити відповідно до розпорядження Кабінету Міністрів України від 19 січня 1994 р. N 31 ( 31-94-р ), із змінами, внесеними розпорядженням Кабінету Міністрів України від 22 травня 2003 р. N 285 ( 285-2003-р ).

2. У постанові Кабінету Міністрів України від 28 жовтня 1992 р. N 602 ( 602-92-п ) "Про медичне та матеріально-побутове обслуговування членів Кабінету Міністрів України у зв'язку з припиненням їх повноважень" слова і цифри "Господарського управління Кабінету Міністрів України на умовах, передбачених розділом II додатка до постанови Ради Міністрів УРСР від 18 жовтня 1990 р. N 314 ( 314-90-п )" замінити словами і цифрами "Державного управління справами на умовах, передбачених розділом II переліку, затвердженого постановою Кабінету Міністрів України від 6 серпня 2003 р. N 1210 ( 1210-2003-п )".

3. Визнати такими, що втратили чинність:

постанову Ради Міністрів УРСР від 18 жовтня 1990 р. N 314 ( 314-90-п ) "Про обслуговування будинками відпочинку Управління Справами Ради Міністрів УРСР окремих категорій службових осіб і пенсіонерів";

розпорядження Кабінету Міністрів України від 14 вересня 1993 р. N 714 ( 714-93-р ).

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 19

Додаток до постанови Кабінету Міністрів України від 6 серпня 2003 р. N 1210

ПЕРЕЛІК посадових осіб та категорій пенсіонерів, яким надається право на користування приміщеннями в будинках відпочинку Державного управління справами

I. Посадові особи

Прем'єр-міністр України - державна дача

Перший віце-прем'єр-міністр - державна дача

Віце-прем'єр-міністри - державна дача

Члени Кабінету Міністрів, - державна дача Генеральний прокурор України

Керівники інших центральних органів - дві кімнати виконавчої влади, заступники Генерального прокурора України

Перший заступник та заступники Міністра Кабінету - дві кімнати Міністрів, керівник Служби Прем'єр-міністра України

Директори департаментів, начальники управлінь - одна кімната Секретаріату Кабінету Міністрів

II. Категорія пенсіонерів

Прем'єр-міністр України, - окремий будинок Голова Ради Міністрів за рішенням Уряду

Перший віце-прем'єр-міністр, - окремий будинок перший заступник Голови за рішенням Ради Міністрів, Генеральний Уряду прокурор України, Прокурор УРСР

Віце-прем'єр-міністри, перший - дві кімнати заступник, заступники Голови Ради Міністрів, члени Президії Ради Міністрів

Члени Кабінету Міністрів, члени - одна кімната Ради Міністрів, заступники Генерального прокурора України, заступники Прокурора УРСР

Державний міністр, Урядовий - одна кімната Секретар Кабінету Міністрів, перший заступник та заступники Міністра Кабінету Міністрів, перший заступник, заступники керуючого справами Ради Міністрів, директори департаментів Секретаріату Кабінету Міністрів

{ Перелік із змінами, внесеними згідно з Розпорядженнями КМ N 825-р ( 825-2004-р ) від 12.11.2004, N 166-р ( 166-2005-р ) від 28.05.2005, N 254-р ( 254-2005-р ) від 12.07.2005 }
