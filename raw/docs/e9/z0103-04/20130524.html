Про затвердження Переліку посад льотного складу, який має право виконувати польоти у складі екіпажів повітряних суден, авіації Збройних Сил України, військова служба на яких зараховується до вислуги років для призначення пенсії на пільгових умовах, і Єдиних річних норм нальоту годин для нарахування вислуги років на пенсію на пільгових

умовах льотному складу авіації, який має право виконувати польоти у складі екіпажів повітряних суден авіації Збройних Сил України

{ Із змінами, внесеними згідно з Наказами Міністерства оборони N 407 ( z0817-07 ) від 10.07.2007 N 221 ( z0666-13 ) від 01.04.2013 }

Згідно з вимогами підпунктів "б", "в" пункту 3 постанови Кабінету Міністрів України від 17 липня 1992 року N 393 ( 393-92-п ) "Про порядок обчислення вислуги років, призначення та виплати пенсій і грошової допомоги особам офіцерського складу, прапорщикам, мічманам, військовослужбовцям надстрокової служби та військової служби за контрактом, особам начальницького і рядового складу органів внутрішніх справ та членам їхніх сімей" НАКАЗУЮ:

{ Преамбула із змінами, внесеними згідно з Наказом Міністерства оборони N 407 ( z0817-07 ) від 10.07.2007 }

1. Затвердити Перелік посад льотного складу, який має право виконувати польоти у складі екіпажів повітряних суден, авіації Збройних Сил України, військова служба на яких зараховується до вислуги років для призначення пенсії на пільгових умовах, що додається. { Абзац перший пункту 1 в редакції Наказу Міністерства оборони N 407 ( z0817-07 ) від 10.07.2007 }

Генералам, офіцерам, прапорщикам, мічманам, сержантам і старшинам, солдатам і матросам, які проходять військову службу за контрактом і звільнені у запас або відставку, до набрання чинності цим наказом Міністра оборони України вислуга років на пенсію, що була нарахована згідно з раніше діючими положеннями, не перераховується.

2. Затвердити Єдині річні норми нальоту годин для нарахування вислуги років на пенсію на пільгових умовах льотному складу авіації Збройних Сил України, що додаються ( z0104-04 ).

3. Дію наказу поширити на льотний склад згідно з Переліком посад на період з 1 січня 2002 року.

4. Наказ Міністра оборони СРСР від 14 серпня 1983 року N 0186 вважати таким, що не застосовується у Збройних Силах України.

5. Наказ розіслати згідно з розрахунком розсилки.

ПЕРЕЛІК посад льотного складу, який має право виконувати польоти у складі екіпажів повітряних суден, авіації Збройних Сил України, військова служба на яких зараховується до вислуги років для призначення пенсії на пільгових умовах

{ Назва Переліку в редакції Наказу Міністерства оборони N 407 ( z0817-07 ) від 10.07.2007 }

До льотного складу відносяться особи офіцерського складу, особи рядового, сержантського і старшинського складу, які проходять службу за контрактом, та строкової військової служби, які займають посади льотного складу за відповідною спеціальністю та виконують польоти за планами бойової (навчально-льотної) підготовки у складі екіпажів повітряних суден авіації Збройних Сил України.

У цьому Переліку ( z0103-04 ) під найменуванням "ланка - Повітряне командування" маються на увазі також військові підрозділи: загін, ескадрилья, група, полк, база, бригада, авіаційне крило, дивізія; під словом "літак" маються на увазі також вертоліт, дирижабль, планер, аероплан, лабораторія інструментального обльоту системи посадки, корабель, літак-ретранслятор, літальна лабораторія, лабораторія (літакова), повітряний командний пункт, повітряний пункт управління, радіотехнічний комплекс, авіаційний комплекс радіолокаційного нагляду та наведення, інші літальні апарати.

II. Загальні положення

1. Військовослужбовцям, які займають посади, що визначені в цьому Переліку, у разі виконання ними річних норм нальоту годин вислуга років на пенсію підлягає обчисленню для призначення пенсії на пільгових умовах.

2. Служба на посадах із подвійним найменуванням (наприклад, "повітряний стрілець-радист", "начальник відділу - льотчик" та інші) зараховується до вислуги років для призначення пенсії на пільгових умовах за однією з посад, указаною у цьому Переліку.

3. До військових навчальних закладів Збройних Сил України належать:

Національний університет оборони України імені Івана Черняховського;

військові університети, академії, інститути, коледжі;

навчальні авіаційні полки, бригади;

центри бойової підготовки, перенавчання;

навчальні центри.

{ Пункт 3 розділу II із змінами, внесеними згідно з Наказами Міністерства оборони N 407 ( z0817-07 ) від 10.07.2007, N 221 ( z0666-13 ) від 01.04.2013 }

4. До навчально-випробувальних (дослідницьких) установ Збройних Сил України належать: навчальні центри; авіаційні науково(навчально)-випробувальні центри, Державний науково-випробувальний центр; спеціальні випробувальні полігони; льотно-випробувальні комплекси; станції льотних випробувань.
