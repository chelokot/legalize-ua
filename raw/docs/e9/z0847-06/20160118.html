Ідентифікатор: z0847-06

Текст документа від 18.01.2016:

МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

13.07.2006 N 59/5

Зареєстровано в Міністерстві юстиції України 17 липня 2006 р. за N 847/12721

{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 2710/5 ( z1620-15 ) від 22.12.2015 }

Про внесення змін до Положення про умови і порядок проведення тендерів (конкурсів) з визначення спеціалізованих організацій для реалізації арештованого державними виконавцями майна

Відповідно до Законів України "Про державну виконавчу службу" ( 202/98-ВР ) та "Про виконавче провадження" ( 606-14 ) і з метою удосконалення порядку проведення тендерів (конкурсів) з визначення спеціалізованих організацій для реалізації арештованого майна НАКАЗУЮ:

1. Пункт 2.1 Положення про умови і порядок проведення тендерів (конкурсів) з визначення спеціалізованих організацій для реалізації арештованого державними виконавцями майна, затвердженого наказом Міністерства юстиції України від 11 листопада 2003 року N 136/5 ( z1036-03 ), зареєстрованого в Міністерстві юстиції України 11 листопада 2003 року за N 1036/8357 (із змінами і доповненнями), викласти в новій редакції:

"2.1. Для організації і проведення тендера (конкурсу) Міністерством юстиції України створюється тендерна (конкурсна) комісія (далі - комісія) у складі:

голова комісії - перший заступник Міністра юстиції Крупко П.М.,

заступник голови комісії - заступник Міністра юстиції Єфіменко Л.В.,

член комісії - радник Міністра юстиції Білак Д.Я.,

член комісії - в.о. директора Департаменту державної виконавчої служби Стаднік Г.В.,

член комісії - директор Департаменту планово-фінансової діяльності, бухгалтерського обліку і звітності Которобай С.В.,

член комісії - директор Департаменту цивільного законодавства та підприємництва Завальна І.І.,

член комісії - директор Департаменту законодавства про правосуддя, правоохоронну діяльність та боротьбу із злочинністю Рябошапка Р.Г.,

член комісії - начальник контрольно-ревізійного відділу Шинкарук Ю.М.,

член комісії - директор Департаменту фінансового законодавства Стрекалова О.С.,

член комісії - начальник відділу представництва інтересів Президента України, Кабінету Міністрів України, Міністерства юстиції в судах України Островська О.В.,

секретар комісії - завідувач сектором організації роботи керівництва Департаменту державної виконавчої служби Ботезат О.П."

2. Першому заступнику директора Департаменту державної виконавчої служби Б.Я.Бачуку:

2.1. Забезпечити подання на державну реєстрацію наказу відповідно до Указу Президента України від 3 жовтня 1992 року N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами і доповненнями).

2.2. Довести цей наказ до відома начальників державної виконавчої служби Автономної Республіки Крим, областей, міст Києва і Севастополя.

3. Контроль за виконанням цього наказу покласти на першого заступника Міністра юстиції П.М.Крупка.
