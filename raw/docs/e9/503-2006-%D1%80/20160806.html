КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 жовтня 2006 р. N 503-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Про внесення змін до розпорядження Кабінету Міністрів України від 13 липня 1994 р. N 521

Внести до розпорядження Кабінету Міністрів України від 13 липня 1994 р. N 521 ( 521-94-р ) такі зміни:

в абзаці першому слова "(Київського об'єднаного)" замінити словами "та Київського міського";

в абзацах першому та другому слова "і виплаті пенсій та допомоги" замінити словами "та здійсненню соціальних виплат".

Прем'єр-міністр України В.ЯНУКОВИЧ
