ПОСТАНОВА від 30 червня 2010 р. N 520 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 171 ( 171-2013-п ) від 20.03.2013 }

Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 26 грудня 2000 р. N 1888

Кабінет Міністрів України постановляє:

1. На часткову зміну пункту 1 постанови Кабінету Міністрів України від 26 грудня 2000 р. N 1888 ( 1888-2000-п ) "Про утворення Комісії з питань діяльності підприємств та організацій громадських організацій інвалідів" (Офіційний вісник України, 2000 р., N 52, ст. 2265; 2008 р., N 24, ст. 737) затвердити новий склад Комісії з питань діяльності підприємств та організацій громадських організацій інвалідів, що додається.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 26 березня 2008 р. N 235 ( 235-2008-п ) "Про затвердження складу Комісії з питань діяльності підприємств та організацій громадських організацій інвалідів" (Офіційний вісник України, 2008 р., N 24, ст. 737).
