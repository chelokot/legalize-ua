ПОСТАНОВА від 12 травня 2007 р. N 703 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки Національного комплексу "Експоцентр України"

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) Державному управлінню справами за програмою "Фінансова підтримка Національного комплексу "Експоцентр України", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 368 ( 368-2008-п ) від 17.04.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки Національного комплексу "Експоцентр України", що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 27

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 12 травня 2007 р. N 703

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки Національного комплексу "Експоцентр України"

Загальна частина

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених Державному управлінню справами у державному бюджеті ( 489-16 ) за програмою "Фінансова підтримка Національного комплексу "Експоцентр України" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Державне управління справами.

Одержувачем бюджетних коштів є Національний комплекс "Експоцентр України".

Напрями використання бюджетних коштів

3. Бюджетні кошти спрямовуються Державному управлінню справами на фінансову підтримку господарської діяльності їх одержувача, пов'язаної з ремонтом теплових мереж, будівель, споруд, відкритих виставкових площ, витратами з оплати енергоносіїв та послуг з водопостачання.

{ Пункт 3 в редакції Постанови КМ N 368 ( 368-2008-п ) від 17.04.2008 }

Вимоги щодо використання бюджетних коштів

4. Бюджетні кошти спрямовуються у межах бюджетних призначень, встановлених Законом України "Про Державний бюджет України на 2008 рік та про внесення змін до деяких законодавчих актів України" ( 107-17 ), згідно з планом заходів, затвердженим Державним управлінням справами, з урахуванням необхідності виконання взятих на облік в органах Державного казначейства бюджетних зобов'язань минулих років у разі їх відповідності паспорту бюджетної програми. { Пункт 4 із змінами, внесеними згідно з Постановою КМ N 368 ( 368-2008-п ) від 17.04.2008 }

5. Закупівля товарів, робіт і послуг здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

Одержувач бюджетних коштів укладає договори про закупівлю товарів, робіт і послуг з переможцем процедури закупівлі.

6. Під час укладання договорів про закупівлю товарів, робіт і послуг враховуються такі вимоги:

сума, визначена в договорах, повинна коригуватися у разі уточнення показників державного бюджету;

переможець процедури закупівлі зобов'язаний здійснити поставку товарів, виконати роботи та надати послуги до закінчення календарного року в повному обсязі відповідно до укладених договорів.

7. Операції, пов'язані з бюджетними коштами, проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

8. У разі зменшення бюджетних призначень головний розпорядник бюджетних коштів з метою недопущення виникнення кредиторської заборгованості на кінець року здійснює відповідне коригування суми видатків для фінансової підтримки одержувача бюджетних коштів.

11. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
