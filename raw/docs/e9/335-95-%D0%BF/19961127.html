Про внесення змін до ставок ввізного мита на окремі види товарів

( Додатково див. Постанову КМ N 583 ( 583-96-п ) від 30.05.96 )

З метою захисту індустрії вітчизняного виробництва електронних контрольно-касових апаратів та вдосконалення тарифного регулювання зовнішньоекономічної діяльності Кабінет Міністрів України ПОСТАНОВЛЯЄ:

Внести зміни до ставок ввізного мита на товари ( 285-94-п ) згідно з додатком.
