{ Постанова втратила чинність на підставі Постанови Національного банку N 543 ( v_543500-10 ) від 14.12.2010 }

Про внесення зміни до постанови Правління Національного банку України від 04.12.2008 N 413

Відповідно до статті 99 Конституції України ( 254к/96-ВР ), статей 7, 30, 44 Закону України "Про Національний банк України" ( 679-14 ), статті 11 Декрету Кабінету Міністрів України від 19.02.93 N 15-93 ( 15-93 ) "Про систему валютного регулювання і валютного контролю" та з метою забезпечення стабільності грошової одиниці України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Підпункт 3.4 пункту 3 постанови Правління Національного банку України від 04.12.2008 N 413 ( v0413500-08 ) "Про окремі питання діяльності банків" (зі змінами) виключити.

У зв'язку з цим підпункти 3.5-3.7 уважати відповідно підпунктами 3.4-3.6.

2. Департаменту валютного регулювання (О.А.Щербакова) довести зміст цієї постанови до відома структурних підрозділів центрального апарату, територіальних управлінь Національного банку України і банків України для використання в роботі.

3. Контроль за виконанням цієї постанови покласти на Службу банківського нагляду (О.М.Бережний), Операційне управління Національного банку України (В.Д.Щуцький), Департамент валютного регулювання (О.А.Щербакова) та начальників територіальних управлінь Національного банку України.

4. Постанова набирає чинності з 01.10.2010.

Голова В.С.Стельмах
