{ Із змінами, внесеними згідно з Постановами КМ N 406 ( 406-2013-п ) від 03.06.2013 N 341 ( 341-2019-п ) від 17.04.2019 N 44 ( 44-2021-п ) від 20.01.2021 }

Кабінет Міністрів України постановляє:

1. Визначити межі акваторії морського порту Південний згідно з додатком.

{ Пункт 1 в редакції Постанови КМ N 406 ( 406-2013-п ) від 03.06.2013; із змінами, внесеними згідно з Постановою КМ N 341 ( 341-2019-п ) від 17.04.2019 }

2. Державному підприємству "Адміністрація морських портів України" забезпечити безпеку мореплавства в межах акваторії, визначених у додатку.
