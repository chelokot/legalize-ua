ПОСТАНОВА від 6 березня 1992 р. N 115 Київ

Про відкриття річкових портів України для заходу іноземних невійськових суден

{ Із змінами, внесеними згідно з Постановами КМ N 959 ( 959-97-п ) від 01.09.97 N 446 ( 446-98-п ) від 06.04.98 N 1402 ( 1402-2003-п ) від 04.09.2003 N 155 ( 155-2012-п ) від 29.02.2012 }

{ У тексті Постанови слова "Державний комітет у справах охорони державного кордону" в усіх відмінках замінено словами "Адміністрація Державної прикордонної служби" у відповідному відмінку згідно з Постановою КМ N 1402 ( 1402-2003-п ) від 04.09.2003 }

Відповідно до Закону України "Про державний кордон України" ( 1777-12 ) Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією об'єднання "Укррічфлот" про відкриття річкових портів Запоріжжя, Дніпропетровськ, Київ, Кременчук, Миколаїв, Нова Каховка, Херсон та Черкаси для заходу іноземних невійськових суден.

{ Абзац другий пункту 1 втратив чинність на підставі Постанови КМ N 155 ( 155-2012-п ) від 29.02.2012 }

{ Абзац третій пункту 1 втратив чинність на підставі Постанови КМ N 155 ( 155-2012-п ) від 29.02.2012 }

2. Установити, що прикордонний, митний, санітарно-карантинний, ветеринарний, фітосанітарний контроль та контроль за вивезенням з території України культурних цінностей організується і здійснюється в установленому порядку в пунктах пропуску річкових портів Миколаїв і Херсон.

3. Об'єднанню "Укррічфлот":

{ Абзац третій пункту 3 втратив чинність на підставі Постанови КМ N 155 ( 155-2012-п ) від 29.02.2012 }
