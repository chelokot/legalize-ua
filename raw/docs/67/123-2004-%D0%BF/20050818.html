КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 лютого 2004 р. N 123 Київ

Про затвердження Віце-прем'єр-міністра України Клюєва А.П. керівником деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

( Із змінами, внесеними згідно з Постановами КМ N 1244 ( 1244-2004-п ) від 22.09.2004 N 753 ( 753-2005-п ) від 18.08.2005 )

Кабінет Міністрів України постановляє:

1. Затвердити Віце-прем'єр-міністра України Клюєва Андрія Петровича:

( Абзац другий пункту 1 втратив чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

головою Державної комісії з питань техногенно-екологічної безпеки та надзвичайних ситуацій;

головою Державної надзвичайної протиепідемічної комісії при Кабінеті Міністрів України;

головою Координаційної ради з питань врегулювання кризових ситуацій у вугільній промисловості;

( Абзац шостий пункту 1 виключено на підставі Постанови КМ N 1244 ( 1244-2004-п ) від 22.09.2004 )

головою Міжвідомчої комісії з організації укладення та виконання угод про розподіл продукції;

головою Міжвідомчої комісії з питань транспортних коридорів та транзитної політики;

головою Міжвідомчої комісії з питань забезпечення ефективного і безпечного функціонування авіаційного транспорту, авіаційної промисловості, авіації загального призначення та системи використання повітряного простору України;

головою Міжвідомчої комісії з визначення переможців конкурсів на отримання спеціальних дозволів на користування нафтогазоносними надрами;

головою Міжвідомчої комісії із забезпечення виконання Рамкової конвенції ООН про зміну клімату;

головою Міжвідомчої комісії з комплексного розв'язання проблем Чорнобильської АЕС;

головою Міжвідомчої комісії з реалізації реформи житлово-комунального господарства;

головою Ради стандартизації;

координатором програми INOGATE.

2. Увільнити Гайдука Віталія Анатолійовича та Азарова Миколу Яновича від обов'язків керівників органів, зазначених у пункті 1 цієї постанови.
