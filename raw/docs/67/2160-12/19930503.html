ПОСТАНОВА ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНИ

( Постанова втратила чинність на підставі Постанови Президії ВР N 3158-XII ( 3158-12 ) від 03.05.93, ВВР, 1993, N 23, ст.246 )

Про організацію бібліотечного обслуговування народних депутатів України

( Відомості Верховної Ради України (ВВР), 1992, N 22, ст. 323 )

З метою удосконалення інформаційно-бібліотечного обслуговування народних депутатів України Президія Верховної Ради України постановляє:

1. Покласти на Державну бібліотеку України і Центральну наукову бібліотеку імені В. Вернадського АН України оперативне бібліотечно-бібліографічне, інформаційно-аналітичне, прогностичне обслуговування народних депутатів України.

2. Секретаріату Верховної Ради України здійснювати заходи по організації та координації робіт.
