Текст документа від 23.02.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 лютого 2005 р. N 39-р Київ

Про скасування розпорядження Кабінету Міністрів України від 17 листопада 2004 р. N 828

Скасувати розпорядження Кабінету Міністрів України від 17 листопада 2004 р. N 828 ( 828-2004-р ) "Про внесення змін до деяких розпоряджень Кабінету Міністрів України" (Офіційний вісник України, 2004 р., N 46, ст. 3061).

У зв'язку з цим:

відновити дію пункту 3 розпорядження Кабінету Міністрів України від 18 жовтня 2000 р. N 405 ( 405-2000-р ) "Про затвердження Умов проведення конкурсу з продажу пакета акцій ВАТ "Херсонобленерго" (Офіційний вісник України, 2000 р., N 43, ст. 1850; 2001 р., N 6, ст. 243) у редакції станом на 16 листопада 2004 року ( 828-2004-р );

в абзаці третьому підпункту "б" пункту 4 розпорядження Кабінету Міністрів України від 7 квітня 2001 р. N 133 ( 133-2001-р ) "Про систему заходів, спрямованих на створення сприятливих умов для розвитку електроенергетичної галузі" (Офіційний вісник України, 2001 р., N 15, ст. 657; 2004 р., N 46, ст. 3061) слова "крім ВАТ "Херсонобленерго" виключити.
