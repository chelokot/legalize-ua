N 448 від 21.07.2000 Зареєстровано в Міністерстві м.Київ юстиції України 28 липня 2000 р. vd20000721 vn448 за N 454/4675

( Наказ втратив чинність на підставі Наказу Державного комітету стандартизації, метрології та сертифікації N 498 ( z0782-02 ) від 30.08.2002 )

Про внесення доповнень до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, і до Термінів введення обов'язкової сертифікації окремих видів продукції в Україні

Відповідно до статті 14 Декрету Кабінету Міністрів України від 10.05.93 N 46-93 "Про стандартизацію і сертифікацію" та на виконання вимог статей 6 і 10 Закону України від 11.01.2000 N 1370-XIV ( 1370-14 ) "Про дозвільну діяльність в сфері використання ядерної енергії" і доручення Кабінету Міністрів України від 11.05.2000 N 8145/16 НАКАЗУЮ:

1. Унести до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, затвердженого наказом Держстандарту України від 30.06.93 N 95 ( z0112-93 ) і зареєстрованого в Міністерстві юстиції України 19.08.93 за N 112, зі змінами та доповненнями, унесеними наказами Держстандарту України від 27.11.96 N 499 ( z0728-96, za728-96 ), від 17.05.97 N 268 ( z0209-97 ), від 04.07.97 N 388 ( z0304-97 ), від 11.09.97 N 549 ( z0461-97 ), від 20.01.98 N 27 ( z0072-98 ), від 27.01.99 N 37 ( z0234-99 ), від 05.05.99 N 205 ( z0299-99 ), від 14.06.99 N 322 ( z0404-99 ), від 14.06.99 N 323 ( z0416-99 ), від 10.12.99 N 389 ( z0897-99 ), від 29.12.99 N 418 ( z0013-00 ), від 27.03.2000 N 241 ( z0223-00 ) та зареєстрованими в Міністерстві юстиції України відповідно 19.12.96 за N 728/1753, 05.06.97 за N 209/2013, 13.08.97 за N 304/2108, 09.10.97 за N 461/2265, 04.02.98 за N 72/2512, 15.04.99 за N 234/3527, 11.05.99 за N 299/3592, 22.06.99 за N 404/3697, 24.06.99 за N 416/3709, 22.12.99 за N 897/4190, 13.01.2000 за N 13/4234, 11.04.2000 за N 223/4444, розділ "39. Техніка радіаційна" (додається).

2. Унести до Термінів введення обов'язкової сертифікації окремих видів продукції в Україні, затверджених наказом Держстандарту України від 30.06.93 N 95 ( z0112-93, z0729-96 ) і зареєстрованих у Міністерстві юстиції України 19.08.93 за N 112, із змінами та доповненнями, унесеними наказами Держстандарту України від 27.11.96 N 499 ( z0728-96, za728-96 ), від 04.04.97 N 388 ( z0304-97 ), від 11.09.97 N 549 ( z0461-97 ), від 20.01.98 N 27 ( z0072-98 ), від 27.01.99 N 37 ( z0234-99 ), від 05.05.99 N 205 ( z0299-99 ), від 14.06.99 N 322 ( z0404-99 ), від 10.12.99 N 389 ( z0897-99 ), від 29.12.99 N 418 ( z0013-00 ) та зареєстрованими в Міністерстві юстиції України відповідно 19.12.96 за N 728/1753, 13.08.97 за N 304/2108, 09.10.97 за N 461/2265, 04.02.98 за N 72/2512, 15.04.99 за N 234/3527, 11.05.99 за N 299/3592, 22.06.99 за N 404/3697, 22.12.99 за N 897/4190, 13.01.2000 за N 13/4234, рядок "39. Техніка радіаційна ... 01.09.2000".

3. Управлінню аналізу, стратегічного планування та міжнародного співробітництва (Віткін Л.М.) у п'ятиденний термін забезпечити подання на державну реєстрацію до Міністерства юстиції України наказу "Про внесення доповнень до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, і до Термінів введення обов'язкової сертифікації окремих видів продукції в Україні".

4. Українському науково-дослідному інституту стандартизації, сертифікації та інформатики (Б. Угаров) після державної реєстрації в Міністерстві юстиції України наказу "Про внесення доповнень до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, і до Термінів введення обов'язкової сертифікації окремих видів продукції в Україні" забезпечити його публікацію в черговому виданні щомісячного інформаційного покажчика "Стандарти".

5. Управлінню аналізу, стратегічного планування та міжнародного співробітництва (Віткін Л.М.) у місячний термін після державної реєстрації в Міністерстві юстиції України наказу "Про внесення доповнень до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, і до Термінів введення обов'язкової сертифікації окремих видів продукції в Україні" довести до відома:

Міністерства економіки України та Міністерства закордонних справ України для подальшого інформування посольств та торговельно-економічних місій країн, які мають дипломатичні представництва в Україні;

національних органів країн, з якими укладено угоди про співробітництво в галузі стандартизації, метрології та сертифікації.

6. Управлінню державного нагляду та підтвердження відповідності (Баб'як О.М.) у місячний термін після державної реєстрації в Міністерстві юстиції України наказу "Про внесення доповнень до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, і до Термінів введення обов'язкової сертифікації окремих видів продукції в Україні" довести наказ до відома центральних органів виконавчої влади.

7. Контроль за виконанням цього наказу покласти на Першого заступника Голови Г.І.Миронюка.

Голова П. Кабан
