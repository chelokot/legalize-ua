КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 травня 1996 р. N 360-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 841-р ( 841-98-р ) від 19.10.98 )

Про зміни в складі офіційної урядової делегації для проведення міжнародних переговорів з питань Чорнобильської АЕС

Включити до складу офіційної урядової делегації для проведення міжнародних переговорів з питань Чорнобильської АЕС, затвердженого розпорядженням Кабінету Міністрів України від 20 квітня 1995 р. N 242 ( 242-95-р ), КУХАРЯ Валерія Павловича - голову Комісії з питань ядерної політики та екологічної безпеки при Президентові України (за згодою), КРОХМАЛЯ Володимира Георгійовича - завідуючого відділом МЗС та РЯБЦЕВА Володимира Євгеновича - радника МЗС.
