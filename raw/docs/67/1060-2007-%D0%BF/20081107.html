ПОСТАНОВА від 22 серпня 2007 р. N 1060 Київ

Про внесення змін до постанови Кабінету Міністрів України від 19 грудня 2001 р. N 1708

{ Із змінами, внесеними згідно з Постановою КМ N 939 ( 939-2008-п ) від 25.10.2008 }

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 19 грудня 2001 р. N 1708 ( 1708-2001-п ) "Про умови оплати праці працівників апарату президій галузевих академій наук" (Офіційний вісник України, 2001 р., N 51, ст. 2304; 2005 р., N 4, ст. 219) такі зміни:

{ Абзац другий постановляючої частини втратив чинність на підставі Постанови КМ N 939 ( 939-2008-п ) від 25.10.2008 }

{ Абзац третій постановляючої частини втратив чинність на підставі Постанови КМ N 939 ( 939-2008-п ) від 25.10.2008 }

додатки 1 - 3 до постанови ( 1708-2001-п ) викласти в редакції, що додається.
