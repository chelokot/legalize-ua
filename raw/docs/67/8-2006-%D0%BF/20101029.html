Ідентифікатор: 8-2006-п

Текст документа від 29.10.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 січня 2006 р. N 8 Київ

Деякі питання відшкодування витрат в іноземній валюті працівникам дипломатичної служби, направленим у довготермінове відрядження

{ Зміни до Постанови див. в Постанові КМ N 1053 ( 1053-2007-п ) від 15.08.2007 }

{ Із змінами, внесеними згідно з Постановою КМ N 954 ( 954-2010-п ) від 20.10.2010 }

Кабінет Міністрів України постановляє:

1. Затвердити в іноземній валюті для працівників дипломатичної служби, направлених у довготермінове відрядження:

базовий показник визначення норми відшкодування витрат та коефіцієнт його поетапного запровадження згідно з додатком 1;

норму відшкодування витрат послам України, главам місій, представникам та постійним представникам України при міжнародних організаціях згідно з додатком 2;

розмір відшкодування витрат працівникам дипломатичної служби згідно з додатком 3;

розмір надбавок до норми відшкодування витрат згідно з додатком 4.

2. Внести до постанови Кабінету Міністрів України від 17 листопада 2004 р. N 1575 ( 1575-2004-п ) "Про упорядкування норм та розміру відшкодування витрат в іноземній валюті працівникам дипломатичної служби України, направленим у довготермінове відрядження" (Офіційний вісник України, 2004 р., N 46, ст. 3058), такі зміни:

1) пункти 1 і 2 визнати такими, що втратили чинність;

2) абзац третій пункту 3 після слів "в країні перебування" доповнити словами "або в третіх країнах".

3. Міністерству закордонних справ, Міністерству економіки і Міністерству оборони привести власні нормативно-правові акти у відповідність із цією постановою.

4. Ця постанова набирає чинності з 1 січня 2006 року.
