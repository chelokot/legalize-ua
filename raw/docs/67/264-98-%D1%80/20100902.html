РОЗПОРЯДЖЕННЯ від 24 квітня 1998 р. N 264-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1766-р ( 1766-2010-р ) від 02.09.2010 }

Про віднесення посад помічника Глави Адміністрації Президента України та помічника Першого заступника Глави Адміністрації Президента України до категорій посад державних службовців

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади помічника Глави Адміністрації Президента України та помічника Першого заступника Глави Адміністрації Президента України до другої категорії посад державних службовців.
