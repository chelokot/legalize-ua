Стан: Втратив чинність

Ідентифікатор: z1113-03

Текст документа від 16.08.2005:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

19.11.2003 N 897

Зареєстровано в Міністерстві юстиції України 3 грудня 2003 р. за N 1113/8434

( Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 400 ( z0862-05 ) від 02.08.2005 )

Про затвердження Тарифів на перевезення пасажирів та багажу залізничним транспортом у міжнародному сполученні Схід-Захід

( Із змінами, внесеними згідно з Наказом Міністерства транспорту та зв'язку N 1090 ( z1578-04 ) від 10.12.2004 )

Згідно з постановою Кабінету Міністрів України від 25 грудня 1996 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

1. Затвердити Тарифи на перевезення пасажирів та багажу залізничним транспортом у міжнародному сполученні Схід-Захід (Тарифи та таблиці до них додаються).

2. Ввести зазначені Тарифи в дію з 14 грудня 2003 р.

3. Укрзалізниці (Федюшин Ю.М.) забезпечити своєчасне введення в дію цих Тарифів та правильність їх застосування і поінформувати про це населення (на вокзалах та пунктах продажу проїзних документів).

4. З уведенням у дію цього наказу втрачають чинність Тарифи на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід-Захід, затверджені наказом Міністерства транспорту України від 2 грудня 2002 р. N 853 ( z0947-02 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід-Захід" і зареєстровані в Міністерстві юстиції України 4 грудня 2002 р. за N 947/7235.

5. Контроль за виконанням цього наказу покласти на заступника Міністра Дунаєва Л.Ф.

Міністр Г.Кірпа

ПОГОДЖЕНО:

Міністр економіки та з питань європейської інтеграції України В.Хорошковський

Голова ради профспілки залізничників і транспортних будівельників України В.Ткачов
