МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

02.10.2009 N 371

Зареєстровано в Міністерстві юстиції України 10 грудня 2009 р. за N 1180/17196

Про визнання наказу Мінпраці від 07.04.2004 N 82 таким, що втратив чинність

Відповідно до вимог Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" НАКАЗУЮ:

1. Визнати наказ Мінпраці від 07.04.2004 N 82 ( z0530-04 ) "Про облік осіб, які з 01.01.2004 набули статусу інвалідів війни, для забезпечення автомобілями", зареєстрований у Міністерстві юстиції України 23.04.2004 за N 530/9129, таким, що втратив чинність.

2. Цей наказ набирає чинності з дня його офіційного опублікування.
