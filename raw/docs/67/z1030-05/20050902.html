МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

02.09.2005 N 451

Зареєстровано в Міністерстві юстиції України 12 вересня 2005 р. за N 1030/11310

Про визнання таким, що втратив чинність, наказу Комітету харчової промисловості України Міністерства агропромислового комплексу України від 31.08.99 N 64

На виконання статті 3 Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" та розпорядження Кабінету Міністрів України від 08.08.2005 N 321-р ( 321-2005-р ) "Про першочергові заходи щодо поліпшення стану справ із прискореного перегляду регуляторних актів та вдосконалення реєстраційної і дозвільної процедури" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Комітету харчової промисловості України Міністерства агропромислового комплексу України від 31.08.99 N 64 ( z0733-99 ) "Про затвердження Інструкції з планування, обліку й калькулювання собівартості продукції на підприємствах олійно-жирової промисловості України", зареєстрований у Міністерстві юстиції України 28.10.99 за N 733/4026.

2. Державному департаменту продовольства (Кіщак Ю.П.) в установленому порядку подати наказ на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням наказу покласти на першого заступника Міністра Демчака І.М.

Міністр О.П.Баранівський
