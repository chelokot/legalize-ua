РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 9 лютого 1989 р. N 51 Київ

( Постанова втратила чинність на підставі Постанови Ради Міністрів УРСР N 65 ( 65-96-п ) від 12.01.96 )

Про Комісію Президії Ради Міністрів УРСР по вдосконаленню господарського механізму

( Із змінами, внесеними згідно з Постановою Ради Міністрів УРСР N 54 ( 54-91-п ) від 13.03.91 )

З метою посилення роботи по здійсненню радикальної економічної реформи, розвитку і поглибленню господарського механізму в основній ланці суспільного виробництва, формуванню та реалізації принципів самофінансування і самоуправління республіки, областей, районів, міст Рада Міністрів Української РСР постановляє:

1. Перетворити Комісію Президії Ради Міністрів УРСР по вдосконаленню управління і підвищенню ефективності народного господарства, створену постановою Ради Міністрів УРСР від 28 травня 1985 р. N 222 ( 222-85-п ), в Комісію Президії Ради Міністрів УРСР по вдосконаленню господарського механізму. Мати при Комісії наукову секцію.

( Абзац другий пункту 1 втратив чинність на підставі Постанови Ради Міністрів УРСР N 54 ( 54-91-п ) від 13.03.91 )

2. Пункт 2 не наводиться.
