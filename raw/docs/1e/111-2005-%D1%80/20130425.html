КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 квітня 2005 р. N 111-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку переробки товарів на митній території України, необхідних для виконання робіт з ремонту і відновлення газотурбінних агрегатів та їх складових частин

З урахуванням технологічних особливостей установити строк переробки товарів на митній території України, необхідних для виконання робіт з ремонту і відновлення газотурбінних агрегатів та їх складових частин за кодами згідно з УКТЗЕД ( 2371г-14 ) 8411819000, 8411829100, 8411829300, 8411999000, 8413199000, 8413309100, 8413309900, 8416209000, 8483409400, 8483409800, 9026105900, 9032899000 і 9033000000, 250 днів від дня завершення митного оформлення товарів, що ввозяться для переробки.
