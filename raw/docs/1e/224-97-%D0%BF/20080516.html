Текст документа від 16.05.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 березня 1997 р. N 224 Київ

{ Постанова втрачає чинність на підставі Постанови КМ N 93 ( 93-2003-п ) від 18.01.2003 з дати набрання чинності частиною тринадцятою статті 71 Митного кодексу України ( 92-15 ), яка набирає чинності з моменту набуття Україною членства у Світовій організації торгівлі }

Про внесення змін до постанови Кабінету Міністрів України від 27 січня 1997 р. N 65

Кабінет Міністрів України постановляє:

Визнати таким, що втратив чинність, пункт 3 постанови Кабінету Міністрів України від 27 січня 1997 р. N 65 ( 65-97-п ) "Про ставки митних зборів".
