Кабінет Міністрів України; Постанова від 22.02.1992 № 78

Про зміни порядку відрахувань із заробітної плати засуджених, що утримуються в установах Державної пенітенціарної служби

Стан: Втратив чинність

Ідентифікатор: 78-92-п

Текст документа від 01.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 лютого 1992 р. N 78 Київ

Про зміни порядку відрахувань із заробітної плати засуджених, що утримуються в установах Державної пенітенціарної служби

{ Назва Постанови із змінами, внесеними згідно з Постановами КМ N 1290 ( 1290-2009-п ) від 02.12.2009 N 1109 ( 1109-2011-п ) від 20.10.2011 }

{ Із змінами, внесеними згідно з Постановами КМ N 1988 ( 1988-99-п ) від 27.10.99 N 1290 ( 1290-2009-п ) від 02.12.2009 N 1109 ( 1109-2011-п ) від 20.10.2011 }

{ У назві та тексті постанови слова "Міністерства внутрішніх справ України" та "Міністерством внутрішніх справ України" замінено відповідно словами "Державного департаменту з питань виконання покарань" та "Державним департаментом з питань виконання покарань" згідно з Постановою КМ N 1988 ( 1988-99-п ) від 27.10.99 }

З метою подальшої гуманізації умов відбування покарання відповідно до Основних напрямів реформи кримінально-виконавчої системи України ( 88а-91-п ) Кабінет Міністрів України постановляє:

1. Установити, що заробітна плата засудженим, які відбувають покарання в місцях позбавлення волі Державної пенітенціарної служби, з 1 січня 1992 р. нараховується в повному обсязі за діючими у відповідних галузях народного господарства тарифними ставками і посадовими окладами. { Абзац перший пункту 1 із змінами, внесеними згідно з Постановами КМ N 1290 ( 1290-2009-п ) від 02.12.2009, N 1109 ( 1109-2011-п ) від 20.10.2011 }

Із заробітної плати указаних осіб відраховуються прибутковий податок, вартість гарантованого харчування, одягу, взуття і спеціальних медикаментів, фактично наданих їм послуг. Інші відрахування із заробітної плати провадяться на загальних підставах відповідно до чинного законодавства.

Витрати, пов'язані з зазначеними змінами порядку відрахувань із заробітної плати засуджених в 1992 році, провадяться Державною пенітенціарною службою за рахунок власних джерел фінансування. { Абзац третій пункту 1 із змінами, внесеними згідно з Постановами КМ N 1290 ( 1290-2009-п ) від 02.12.2009, N 1109 ( 1109-2011-п ) від 20.10.2011 }

2. Визнати такими, що втратили чинність:

постанову Ради Міністрів УРСР від 30 грудня 1961 р. N 1733-109;

підпункти 1 і 5 пункту 3 постанови Ради Міністрів УРСР від 25 вересня 1971 р. N 458-8;

абзац перший пункту 27 Положення про лікувально-трудові профілакторії для примусового лікування і трудового перевиховання хронічних алкоголіків і наркоманів, затвердженого постановою Ради Міністрів УРСР від 25 липня 1972 р. N 346.
