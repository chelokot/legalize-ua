Про затвердження складу Міжвідомчої робочої групи з питань запровадження зовнішнього незалежного оцінювання та моніторингу якості освіти

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 лютого 2007 р. N 289 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про затвердження складу Міжвідомчої робочої групи з питань запровадження зовнішнього незалежного оцінювання та моніторингу якості освіти

Кабінет Міністрів України постановляє:

Внести до пункту 3 постанови Кабінету Міністрів України від 31 грудня 2005 р. N 1312 ( 1312-2005-п ) "Про невідкладні заходи щодо запровадження зовнішнього незалежного оцінювання та моніторингу якості освіти" (Офіційний вісник України, 2006 р., N 1-2, ст. 34) такі зміни:

на часткову зміну абзацу першого затвердити склад Міжвідомчої робочої групи з питань запровадження зовнішнього незалежного оцінювання та моніторингу якості освіти, що додається;

абзац другий викласти у такій редакції:

"Голові Міжвідомчої робочої групи затвердити її персональний склад та вносити у разі потреби до нього зміни.".
