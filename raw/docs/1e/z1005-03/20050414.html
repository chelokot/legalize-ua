НАКАЗ

20.10.2003 N 711

Зареєстровано в Міністерстві юстиції України 4 листопада 2003 р. за N 1005/8326

( Наказ втратив чинність на підставі Наказу Державної митної служби N 169 ( z0310-05 ) від 14.03.2005 )

Про внесення доповнення до наказу Державної митної служби України від 04.02.2003 N 74 "Про визначення місць митного оформлення окремих видів товарів"

Відповідно до статті 38 Митного кодексу України ( 1970-12 ) та з метою вдосконалення механізму застосування наказу Державної митної служби України від 04.02.2003 N 74 ( z0124-03 ) "Про визначення місць митного оформлення окремих видів товарів" НАКАЗУЮ:

1. У пункті 2 наказу Державної митної служби України від 04.02.2003 N 74 ( z0124-03 ) "Про визначення місць митного оформлення окремих видів товарів" слова "Бориспільську й Севастопольську" замінити словами:

"Бориспільську, Луганську, Миколаївську, Севастопольську й Херсонську".

2. Управлінню контролю митної вартості та номенклатури (Войцещук А.Д.) й Управлінню правової роботи (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Управлінню справами (Карпенко В.П.) після державної реєстрації цього наказу забезпечити тиражування та розсилку його до митних органів.

4. Контроль за виконанням наказу покласти на заступника Голови Служби Дьоміна Ю.М.

Голова Служби М.М.Каленський
