Про внесення змін до постанов Кабінету Міністрів України від 24 січня 1998 р. N 75 та від 27 листопада 1998 р. N 1875

Стан: Втратив чинність

Текст документа від 14.02.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 березня 1999 р. N 449 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 229 ( 229-2007-п ) від 14.02.2007 }

Про внесення змін до постанов Кабінету Міністрів України від 24 січня 1998 р. N 75 та від 27 листопада 1998 р. N 1875

( Із змінами, внесеними згідно з Постановою КМ N 1733 ( 1733-2001-п ) від 27.12.2001 )

Кабінет Міністрів України постановляє:

1. Внести до Порядку погашення заборгованості підприємств, установ та організацій із збору на обов'язкове державне пенсійне страхування шляхом оформлення її векселями та внесення авансових платежів із збору на обов'язкове державне пенсійне страхування шляхом вексельних розрахунків, затвердженого постановою Кабінету Міністрів України від 24 січня 1998 р. N 75 ( 75-98-п ) (Офіційний вісник України, 1998 р., N 4, ст. 138, N 32, ст. 1207, N 48, ст. 1753), такі зміни:

у абзаці другому пункту 2 слова "а для вугледобувних, вуглепереробних, шахто- та вуглебудівних підприємств збір на обов'язкове державне пенсійне страхування з поточної заробітної плати" виключити;

у пункті 5 після цифр і слів "90 днів" слова і цифри "а для вугледобувних, вуглепереробних, шахто- та вуглебудівних підприємств - 180 днів" виключити.

( Пункт 2 втратив чинність на підставі Постанови КМ N 1733 ( 1733-2001-п ) від 27.12.2001 )
