МІНІСТЕРСТВО ЕКОНОМІКИ УКРАЇНИ

НАКАЗ

N 94 від 19.07.96 Зареєстровано в Міністерстві м.Київ юстиції України 1 серпня 1996 р. vd960719 vn94 за N 413/1438

( Наказ втратив чинність з 01.01.98 на підставі Наказу Мінекономіки N 142 ( v0142200-97 ) від 26.12.97 )

Про внесення доповнень до наказу Міністерства економіки від 14.06.96 N 76

( Із змінами, внесеними згідно з Наказом Мінекономіки N 119 ( z0523-97 ) від 27.10.97 )

Для більш чіткого розподілу виручки при розрахунках за транспортування природного газу власного видобутку, НАКАЗУЮ:

Внести доповнення до наказу Мінекономіки від 14.06.96 N 76 ( z0317-96 ) "Про встановлення оптових цін на газ природний та тарифів на його транспортування":

( Пункт 1 втратив чинність на підставі Наказу Мінекономіки N 119 ( z0523-97 ) від 27.10.97 ) 1. У додатку N 2:

примітку після слів "за 1000 куб.м газу" доповнити словами "без ПДВ на газ власного видобутку".

2. У додатку N 4:

графу "імпортованого" доповнити словами "і власного видобутку, крім того, що реалізується за прямими договорами";

графу "власного видобутку, що реалізується самостійно" доповнити словами "за прямими договорами".
