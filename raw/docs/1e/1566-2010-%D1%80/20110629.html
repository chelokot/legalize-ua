Кабінет Міністрів України; Розпорядження від 28.07.2010 № 1566-р

Про проведення пробного перепису населення

Стан: Чинний

Ідентифікатор: 1566-2010-р

Текст документа від 29.06.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 липня 2010 р. N 1566-р Київ

Про проведення пробного перепису населення

{ Із змінами, внесеними згідно з Розпорядженням КМ N 613-р ( 613-2011-р ) від 29.06.2011 }

1. Державній службі статистики:

провести у грудні 2010 року у Дергачівському районі Харківської області пробний перепис населення;

здійснити у другому півріччі 2010 р. та 2011 році комплекс робіт з підготовки, проведення пробного перепису населення та оброблення матеріалів за його результатами.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 613-р ( 613-2011-р ) від 29.06.2011 }

2. Харківській обласній та Дергачівській районній держадміністраціям надавати в межах своїх повноважень органам державної статистики всебічне сприяння і допомогу у підготовці та проведенні пробного перепису населення.

3. Передати бюджетні призначення, передбачені Міністерству фінансів за бюджетною програмою 3511090 "Державні капітальні видатки" ( 2154-17 ), в обсязі 5019,8 тис. гривень Державній службі статистики за програмою 3001020 "Статистичні спостереження та переписи", спрямувавши їх на видатки споживання в сумі 2825,2 тис., з них на оплату праці - 1483 тис., та видатки розвитку - 2194,6 тис. гривень" ( 2154-17 ).

{ Пункт 3 із змінами, внесеними згідно з Розпорядженням КМ N 613-р ( 613-2011-р ) від 29.06.2011 }

Прем'єр-міністр України М.АЗАРОВ
