КАБІНЕТ МІНІСТРІВ УКРАЇНИ
ПОСТАНОВА

від 7 листопада 2014 р. № 596
Київ

Про порядок закупівлі природного газу промисловими, енергогенеруючими та теплогенеруючими (в частині промислових обсягів газу) підприємствами

{Із змінами, внесеними згідно з Постановою КМ
№ 599 від 12.11.2014}

Кабінет Міністрів України постановляє :

1. Установити, що з дня набрання чинності цією постановою по 28 лютого 2015 р. промислові, енергогенеруючі та теплогенеруючі (в частині промислових обсягів газу) підприємства за переліком згідно з додатком зобов’язані здійснювати закупівлю природного газу виключно у гарантованого постачальника Національної акціонерної компанії “Нафтогаз України”.

{Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ № 599 від 12.11.2014 }

Закупівля природного газу у інших постачальників природного газу забороняється.

2. Газорозподільним та газотранспортним підприємствам у період з дня набрання чинності цією постановою по 28 лютого 2015 р. здійснювати відповідно до законодавства транспортування природного газу промисловим, енергогенеруючим та теплогенеруючим (в частині промислових обсягів газу) підприємствам лише з ресурсів Національної акціонерної компанії “Нафтогаз України”.

{Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ № 599 від 12.11.2014 }

Оператору Єдиної газотранспортної системи України приймати відповідно до законодавства планові розподіли природного газу лише від Національної акціонерної компанії “Нафтогаз України” для промислових, енергогенеруючих та теплогенеруючих (в частині промислових обсягів газу) підприємств на період його постачання з дня набрання чинності цією постановою по 28 лютого 2015 року.

{Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ № 599 від 12.11.2014 }

3. Міністерству енергетики та вугільної промисловості, обласним державним адміністраціям вжити відповідно до законодавства заходів для укладення промисловими, енергогенеруючими та теплогенеруючими (в частині промислових обсягів газу) підприємствами договорів купівлі-продажу природного газу виключно з Національною акціонерною компанією “Нафтогаз України”.

{Пункт 3 із змінами, внесеними згідно з Постановою КМ № 599 від 12.11.2014 }

4. Центральним органам виконавчої влади привести власні нормативно-правові акти у відповідність з цією постановою.

5. Рекомендувати Антимонопольному комітету та Національній комісії, що здійснює державне регулювання у сферах енергетики та комунальних послуг, внести необхідні зміни до власних нормативно-правових актів з метою приведення їх у відповідність з цією постановою.

{Пункт 5 із змінами, внесеними згідно з Постановою КМ № 599 від 12.11.2014 }
