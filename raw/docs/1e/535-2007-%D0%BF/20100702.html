{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) за програмою "Фінансова підтримка преси", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

{ Установити, що у 2010 році кошти, передбачені у державному бюджеті ( 2154-17 ) за програмою "Фінансова підтримка преси", використовуються відповідно до Порядку, затвердженого цією Постановою, з урахуванням особливостей, зазначених в Постанові КМ N 498 ( 498-2010-п ) від 23.06.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки преси, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 51

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 березня 2007 р. N 535

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки преси

Загальна частина

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Держкомтелерадіо за програмою "Фінансова підтримка преси" (далі - бюджетні кошти).

Одержувачами бюджетних коштів є редакції періодичних друкованих видань.

Напрями використання бюджетних коштів

2. Мета Порядку полягає у забезпеченні прозорої та ефективної процедури використання бюджетних коштів.

3. Бюджетні кошти спрямовуються на фінансову підтримку відповідно до статті 3 Закону України "Про державну підтримку засобів масової інформації та соціальний захист журналістів" ( 540/97-ВР ) періодичних друкованих видань для дітей та юнацтва, для інвалідів, спеціалізованих наукових періодичних видань, що випускаються науковими установами та навчальними закладами не нижче III рівня акредитації, і друкованих засобів масової інформації, які цілеспрямовано сприяють розвиткові мов та культур національних меншин України, у частині отримання поліграфічних послуг та закупівлі паперу.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

Вимоги щодо використання бюджетних коштів

4. Для одержання бюджетних коштів редакції періодичних друкованих видань подають Держкомтелерадіо документи згідно з переліком та в порядку, встановленими ним.

Бюджетні кошти перераховуються на підставі їх розподілу між редакціями періодичних друкованих видань, затвердженого наказом Держкомтелерадіо згідно з рішенням колегії Комітету.

5. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється відповідно до вимог Закону України "Про закупівлю товарів, робіт та послуг за державні кошти" ( 1490-14 ).

Операції, пов'язані з бюджетними коштами, проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

Попередня оплата товарів, робіт і послуг здійснюється відповідно до постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752).

8. Відповідальність за цільове витрачання бюджетних коштів покладається на Держкомтелерадіо та одержувачів бюджетних коштів.

9. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
