Про затвердження індексу для визначення розміру плати за виконання робіт

Відповідно до підпункту 26 пункту 4 Положення про Міністерство будівництва, архітектури та житлово-комунального господарства України, затвердженого Указом Президента України від 19 грудня 2005 року N 1801 ( 1801/2005 ), НАКАЗУЮ:

1. Затвердити індекс для визначення розміру плати за виконання робіт, зазначених у таблицях Базових показників вартості проектно-планувальних та інших робіт із надання платних послуг замовникам, затверджених постановою колегії Держбуду України від 26.06.91 N 24, у розмірі 2,74.

2. Скасувати наказ Держбуду України від 28.02.2005 N 44 ( z0302-05 ) "Про затвердження індексу для визначення розміру плати за виконання робіт", зареєстрований в Міністерстві юстиції України 16.03.2005 за N 302/10582, державну реєстрацію якого скасовано (висновок Міністерства юстиції України від 30.01.2006 N 1/59 ( v1_59323-06 ).

3. Управлінню містобудування та архітектури (Вашкулат О.М.) подати даний наказ на державну реєстрацію до Міністерства юстиції України.

4. Управлінню містобудування та архітектури (Вашкулат О.М.) та Управлінню ціноутворення, експертизи та контролю вартості у будівництві (Губень П.І.) забезпечити доведення наказу до відома зацікавлених організацій.

5. Контроль за виконанням цього наказу покласти на заступника Міністра Казмірука Ю.Й.

Міністр П.С.Качур
