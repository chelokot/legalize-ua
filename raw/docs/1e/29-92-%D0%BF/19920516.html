КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 січня 1992 р. N 29 Київ

Про створення Державного патентного відомства

( Із змінами, внесеними згідно з Постановою КМ N 248 ( 248-92-п ) від 16.05.1992 )

На виконання Постанови Президії Верховної Ради України від 2 грудня 1991 р. "Про деякі організаційні заходи щодо забезпечення охорони промислової власності" ( 1897-12 ) Кабінет Міністрів України постановляє:

1. Перетворити патентний фонд України у Державне патентне відомство Комітету по науково-технічному прогресу при Кабінеті Міністрів України (Держпатент України).

Покласти на Держпатент України забезпечення правової охорони об'єктів промислової власності, видачі патентів та інших охоронних документів на винаходи, промислові зразки, а також функціонування єдиної патентної системи на території України.

2. Установити, що голова Держпатенту України призначається Кабінетом Міністрів України і за посадою є членом колегії Комітету по науково-технічному прогресу при Кабінеті Міністрів України.

Заступники голови цього Відомства призначаються головою Комітету по науково-технічному прогресу при Кабінеті Міністрів України.

( Пункт 3 втратив чинність на підставі Постанови КМ N 248 ( 248-92-п ) від 16.05.1992 )

4. Комітетові по науково-технічному прогресу при Кабінеті Міністрів України разом з Держпатентом України розробити і подати у місячний строк до Кабінету Міністрів України погоджені з Міністерством фінансів України пропозиції щодо структури і граничної чисельності працівників апарату Відомства, а також проект положення про нього.

5. Секретаріатові Кабінету Міністрів України вирішити питання про надання приміщення для апарату Держпатенту України.
