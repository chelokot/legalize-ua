Текст документа від 18.09.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 серпня 1996 р. N 526-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 514-р ( 514-97-р ) від 18.09.97 )

Про передачу будинку по вулиці М.Грушевського, 10, у м. Києві Кабінету Міністрів України

1. Передати будинок по вул. М.Грушевського, 10, у м. Києві в оперативне управління Господарському управлінню Кабінету Міністрів України.

Мінсільгосппроду у двомісячний термін забезпечити переміщення із зазначеного будинку організацій, що займають його в даний час, на інші площі Міністерства та в установленому порядку здійснити передачу будинку Господарському управлінню.

2. Визнати такими, що втратили чинність, пункт 4 постанови Кабінету Міністрів України від 22 червня 1992 р. N 345 ( 345-92-п ) "Питання Державного комітету України по земельних ресурсах" та розпорядження Кабінету Міністрів України від 26 січня 1994 р. N 40 ( 40-94-р ).
