Кабінет Міністрів України; Постанова від 27.12.2008 № 1155

Про представників від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму

Стан: Втратив чинність

Ідентифікатор: 1155-2008-п

Текст документа від 27.12.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 грудня 2008 р. N 1155 Київ

Про представників від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму

Кабінет Міністрів України постановляє:

1. На зміну пункту 2 постанови Кабінету Міністрів України від 24 вересня 1999 р. N 1767 ( 1767-99-п ) "Про науково-громадську експертизу набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму" (Офіційний вісник України, 1999 р., N 39, ст. 1946; 2007 р., N 44, ст. 1800) затвердити представниками від центральних органів виконавчої влади в експертній комісії для проведення науково-громадської експертизи набору продуктів харчування, набору непродовольчих товарів і набору послуг для встановлення прожиткового мінімуму Крючкову І.В. - заступника Міністра економіки, Матвійчука В.М. - заступника Міністра фінансів, Пономаренка А.М. - першого заступника головного державного санітарного лікаря України, Розенка П.В. - першого заступника Міністра праці та соціальної політики, увільнивши від цих обов'язків Бережнова С.П., Рибака С.О., Солдатенка М.О., Челнокова С.Д.

2. Визначити Крючкову І.В. - заступника Міністра економіки відповідальною за координацію роботи представників від центральних органів виконавчої влади в експертній комісії, зазначеній у пункті 1 цієї постанови.
