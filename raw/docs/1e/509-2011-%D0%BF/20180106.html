КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 травня 2011 р. N 509 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1085 ( 1085-2017-п ) від 20.12.2017 }

Про внесення змін до постанови Кабінету Міністрів України від 5 листопада 2003 р. N 1731

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 5 листопада 2003 р. N 1731 ( 1731-2003-п ) "Про затвердження Порядку спрямування коштів спеціального фонду державного бюджету, призначених для фінансування розвитку мережі і утримання автомобільних доріг загального користування" (Офіційний вісник України, 2003 р., N 45, ст. 2363; 2005 р., N 48, ст. 3006) такі зміни:

у назві і пункті 1 постанови ( 1731-2003-п ) слова "спеціального фонду" виключити;

у назві і тексті Порядку спрямування коштів спеціального фонду державного бюджету, призначених для фінансування розвитку мережі і утримання автомобільних доріг загального користування, затвердженому зазначеною постановою ( 1731-2003-п ), слова "спеціальний фонд" у всіх відмінках виключити.

Прем'єр-міністр України М.АЗАРОВ
