ПОСТАНОВА від 16 вересня 1993 р. N 817 Київ

Питання Національного космічного агентства України при Кабінеті Міністрів України

( Із змінами, внесеними згідно з Постановою КМ N 682 ( 682-98-п ) від 18.05.98 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 682 ( 682-98-п ) від 18.05.98 )

2. Дозволити Національному космічному агентству мати трьох заступників генерального директора, в тому числі одного першого, а також колегію у складі дев'яти чоловік.

3. Установити умови оплати праці, матеріально-побутового забезпечення, медичного і транспортного обслуговування генерального директора та інших працівників Національного космічного агентства на рівні умов, визначених для відповідних категорій працівників міністерств.
