КАБІНЕТ МІНІСТРІВ УКРАЇНИ
ПОСТАНОВА

від 28 листопада 2012 р. № 1102
Київ

Про затвердження Порядку використання у 2012 році коштів, передбачених у державному бюджеті для державної підтримки вітчизняного машинобудування для агропромислового комплексу, в тому числі через механізм здешевлення кредитів (для погашення кредиторської заборгованості, яка виникла у 2009 році)

Відповідно до частини сьомої статті 20 Бюджетного кодексу України Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2012 році коштів, передбачених у державному бюджеті для державної підтримки вітчизняного машинобудування для агропромислового комплексу, в тому числі через механізм здешевлення кредитів (для погашення кредиторської заборгованості, яка виникла у 2009 році), що додається.

ЗАТВЕРДЖЕНО
постановою Кабінету Міністрів України
від 28 листопада 2012 р. № 1102

ПОРЯДОК
використання у 2012 році коштів, передбачених у державному бюджеті для державної підтримки вітчизняного машинобудування для агропромислового комплексу, в тому числі через механізм здешевлення кредитів (для погашення кредиторської заборгованості, яка виникла у 2009 році)

1. Цей Порядок визначає механізм використання у 2012 році коштів, передбачених у державному бюджеті за програмою “Державна підтримка вітчизняного машинобудування для агропромислового комплексу, в тому числі через механізм здешевлення кредитів (для погашення кредиторської заборгованості, яка виникла у 2009 році)” (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів та відповідальним виконавцем бюджетної програми є Агентство держмайна.

3.  Бюджетні кошти спрямовуються на погашення кредиторської заборгованості, яка виникла в 2009 році за бюджетною програмою “Державна підтримка вітчизняного машинобудування для агропромислового комплексу, в тому числі через механізм здешевлення кредитів”.

4. Перелік підприємств та організацій, щодо яких утворилася кредиторська заборгованість, формується Агентством держмайна на підставі фінансової звітності та зареєстрованої станом на 31 грудня 2011 р. в органах Казначейства кредиторської заборгованості за бюджетною програмою “Державна підтримка вітчизняного машинобудування для агропромислового комплексу, в тому числі через механізм здешевлення кредитів”.

5. Відображення у первинному та бухгалтерському обліку інформації про отримані (створені) оборотні та необоротні активи, а також відкриття рахунків, реєстрація, облік бюджетних зобов’язань в органах Казначейства та проведення операцій, пов’язаних з використанням бюджетних коштів, здійснюються в установленому законодавством порядку.

6. Складення та подання фінансової та бюджетної звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
