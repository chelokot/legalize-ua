{ Указ втратив чинність на підставі Указу Президента N 591/2011 ( 591/2011 ) від 20.05.2011 }

Про внесення змін до Мережі та кількісного складу суддів апеляційних судів

Відповідно до пункту 23 статті 106 Конституції України ( 254к/96-ВР ) та частини четвертої статті 20 Закону України "Про судоустрій України" ( 3018-14 ) постановляю:

Внести до Мережі та кількісного складу суддів апеляційних судів, затверджених Указом Президента України від 20 серпня 2001 року N 642 ( 642/2001 ) (зі змінами, внесеними Указами від 30 січня 2002 року N 80 ( 80/2002 ) та від 4 березня 2004 року N 268 ( 268/2004 ), такі зміни:

1) у пункті 7 цифри "42" замінити цифрами "36";

2) у пункті 11 цифри "57" замінити цифрами "54";

3) у пункті 13 цифри "71" замінити цифрами "66";

4) у пункті 15 цифри "87" замінити цифрами "85";

5) у пункті 17 цифри "38" замінити цифрами "33";

6) у пункті 23 цифри "51" замінити цифрами "46";

7) цифри "1739" замінити цифрами "1713".

Президент України В.ЮЩЕНКО
