Про зупинення дії постанов Кабінету Міністрів України від 16 січня 2007 року N 35 та від 14 березня 2007 року N 443

{ Додатково див. Конституційне подання Президента ( n0004100-08 ) від 08.04.2008 }

Кабінетом Міністрів України 16 січня 2007 року видано постанову N 35 ( 35-2007-п ) "Питання Київського національного університету імені Тараса Шевченка".

Відповідно до зазначеної постанови ( 35-2007-п ) Кабінет Міністрів України, з посиланням на статтю 5 Закону України "Про управління об'єктами державної власності" ( 185-16 ) та Закон України "Про вищу освіту" ( 2984-14 ):

погодився з рішенням конференції трудового колективу Київського національного університету імені Тараса Шевченка та установив, що зазначений Університет підпорядковується Кабінету Міністрів України (абзац перший пункту 1) ( 35-2007-п );

підтвердив повноваження В.Скопенка як ректора Київського національного університету імені Тараса Шевченка та доручив Віце-прем'єр-міністрові України Д.Табачнику підписати з В.Скопенком контракт (абзац другий пункту 1) ( 35-2007-п ).

Пунктом 2 названої постанови ( 35-2007-п ) Міністерству освіти і науки України разом з іншими заінтересованими центральними органами виконавчої влади доручено розглянути прийнятий конференцією трудового колективу Статут Київського національного університету імені Тараса Шевченка та подати його в установленому порядку Кабінету Міністрів України.

14 березня 2007 року Кабінет Міністрів України постановою N 443 ( 443-2007-п ) затвердив Статут Київського національного університету імені Тараса Шевченка, за яким до повноважень Кабінету Міністрів України віднесено, зокрема, питання призначення за поданням конференції трудового колективу ректора названого Університету (пункти 15, 16) ( 443-2007-п ).

Зазначені нормативно-правові акти Кабінету Міністрів України ( 35-2007-п, 443-2007-п ) не відповідають пункту 5 статті 116 Конституції України ( 254к/96-ВР ), за яким Кабінет Міністрів України здійснює управління об'єктами державної власності відповідно до закону.

Закони України "Про управління об'єктами державної власності" ( 185-16 ) та "Про вищу освіту" ( 2984-14 ), які регулюють відповідні питання, не відносять до повноважень Кабінету Міністрів України функції з управління вищими навчальними закладами державної форми власності, зокрема призначення керівників таких закладів та затвердження їх статутів.

Крім того, Закон України "Про вищу освіту" ( 2984-14 ) не передбачає підпорядкування державного вищого навчального закладу у спосіб, передбачений абзацом першим пункту 1 постанови від 16 січня 2007 року N 35 ( 35-2007-п ), та призначення керівника зазначеного закладу шляхом підтвердження його повноважень.

Відтак, видавши постанови від 16 січня 2007 року N 35 ( 35-2007-п ) та від 14 березня 2007 року N 443 ( 443-2007-п ), Кабінет Міністрів України порушив і положення частини другої статті 6, частини другої статті 19 та частини третьої статті 113 Основного Закону ( 254к/96-ВР ) держави, які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, а також діяти в межах повноважень, на підставі та у спосіб, що ними передбачені.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанов Кабінету Міністрів України від 16 січня 2007 року N 35 ( 35-2007-п ) "Питання Київського національного університету імені Тараса Шевченка" та від 14 березня 2007 року N 443 ( 443-2007-п ) "Про затвердження Статуту Київського національного університету імені Тараса Шевченка".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
