КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 травня 2005 р. N 166-р Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

{ Розпорядження втратило чинність на підставі Постанови КМ N 673 ( 673-2014-п ) від 26.11.2014 }

Про внесення змін у додаток до постанови Кабінету Міністрів України від 6 серпня 2003 р. N 1210

У розділі II додатка до постанови Кабінету Міністрів України від 6 серпня 2003 р. N 1210 ( 1210-2003-п ) "Про обслуговування будинками відпочинку "Конча-Заспа" та "Пуща-Водиця" окремих категорій посадових осіб і пенсіонерів" - із змінами, внесеними розпорядженням Кабінету Міністрів України від 12 листопада 2004 р. N 825 ( 825-2004-р ), абзац другий доповнити словами "перший заступник Голови Ради Міністрів", а в абзаці третьому слова "перший заступник" виключити.

Прем'єр-міністр України Ю.ТИМОШЕНКО
