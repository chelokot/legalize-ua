Текст документа від 10.04.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 квітня 2000 р. N 641 Київ

Про граничну чисельність працівників центрального апарату Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

( Із змінами, внесеними згідно з Постановами КМ N 1023 ( 1023-2000-п ) від 27.06.2000 N 481 ( 481-2002-п ) від 10.04.2002 )

Відповідно до Указу Президента України від 15 грудня 1999 р. N 1572 ( 1572/99 ) "Про систему центральних органів виконавчої влади" Кабінет Міністрів України постановляє:

1. Затвердити граничну чисельність працівників центрального апарату Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи з урахуванням працівників Головного управління сил Цивільної оборони у кількості 512 особи.

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1023 ( 1023-2000-п ) від 27.06.2000 )

2. Дозволити Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи мати чотирьох заступників Міністра, в тому числі одного першого, та колегію Міністерства у кількості 15 чоловік.

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 481 ( 481-2002-п ) від 10.04.2002 )

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 3 серпня 1999 р. N 1414 ( 1414-99-п ) "Питання Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" (Офіційний вісник України, 1999 р., N 31, ст. 1623).
