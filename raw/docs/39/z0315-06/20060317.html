17.03.2006 N 244

Зареєстровано в Міністерстві юстиції України 23 березня 2006 р. за N 315/12189

Про втрату чинності наказу Міністерства транспорту України від 29.12.97 N 459

Відповідно до Положення про Міністерство транспорту та зв'язку України, затвердженого Указом Президента України від 27.08.2004 N 1009 ( 1009/2004 ), та постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства транспорту України від 29.12.97 N 459 ( z0127-98 ) "Про затвердження аеропортових зборів за обслуговування повітряних суден у Міжнародному аеропорту "Бориспіль", зареєстрований у Міністерстві юстиції України 20.02.98 за N 127/2567.

2. Департаменту фінансового регулювання та соціально-економічної політики (Демчук А.І.) забезпечити подання цього наказу в установленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Рябікіна П.Б.

Міністр В.Бондар
