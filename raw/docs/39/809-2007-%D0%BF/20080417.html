КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 червня 2007 р. N 809 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 381 ( 381-2008-п ) від 17.04.2008 }

Про доповнення додатка до постанови Кабінету Міністрів України від 19 квітня 1993 р. N 283

Кабінет Міністрів України постановляє:

1. Доповнити абзац п'ятий розділу II додатка до постанови Кабінету Міністрів України від 19 квітня 1993 р. N 283 ( 283-93-п ) "Про встановлення порядку виготовлення бланків цінних паперів і документів суворого обліку" - із змінами, внесеними розпорядженням Кабінету Міністрів України від 4 листопада 1993 р. N 936 ( 936-93-р ) та постановами Кабінету Міністрів України від 17 червня 2004 р. N 786 ( 786-2004-п ) (Офіційний вісник України, 2004 р., N 24, ст. 1599) і від 15 жовтня 2004 р. N 1376 ( 1376-2004-п ) (Офіційний вісник України, 2004 р., N 42, ст. 2765), після слова "ліцензії" словами "; ордери касові (прибуткові та видаткові)".

2. Ця постанова набирає чинності з 1 січня 2008 року.
