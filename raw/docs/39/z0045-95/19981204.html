Про квартальну бухгалтерську звітність підприємств

( Із змінами, внесеними згідно з Роз'ясненням Мінфіну N 18-448 ( v-448201-95 ) від 07.04.95 Наказами Мінфіну N 13 ( z0045-96 ) від 23.01.96 N 29 ( z0082-96 ) від 14.02.96 N 238 ( z0777-98 ) від 18.11.98 )

Відповідно до Положення про організацію бухгалтерського обліку і звітності в Україні, затвердженого постановою Кабінету Міністрів України від 3 квітня 1993 р. N 250 ( 250-93-п ), НАКАЗУЮ :

1. ( Пункт 1 втратив чинність на підставі Наказу Мінфіну N 13 ( z0045-96 ) від 23.01.96 ) Встановити, що квартальна бухгалтерська звітність складається і подається підприємствами й організаціями в обсязі Балансу підприємства (форма N 1) і Звіту про фінансові результати та їх використання (форма N 2), зразки яких наведено у додатку N 1.

2. ( Пункт 2 втратив чинність на підставі Наказу Мінфіну N 13 ( z0045-96 ) від 23.01.96 ) Затвердити Зміни і доповнення до

Інструкції про порядок заповнення форм річного бухгалтерського звіту підприємства, затвердженої наказом Міністерства фінансів України від 9 серпня 1993 р. N 55 ( z0143-93 ) (додаток N 4), з урахуванням змін і доповнень до неї, затверджених наказом Міністерства фінансів України від 26 липня 1994 р. N 65 ( z0183-94 ) (додаються).

3. ( Пункт 3 втратив чинність на підставі Наказу Мінфіну N 13 ( z0045-96 ) від 23.01.96 ) Передбачити, що органи, у віданні яких перебувають підприємства й організації, зведену квартальну бухгалтерську звітність складають і подають за видами діяльності, наведеними у додатку N 3 до наказу Міністерства фінансів України від 9 серпня 1993 р. N 55 ( z0143-93 ).

4. ( Пункт 4 втратив чинність на підставі Наказу Мінфіну N 238 ( z0777-98 ) від 18.11.98 ) У листі Міністерства фінансів України від 12 листопада 1992 р. N 18-4141 ( v4141201-92 ) "Про плату за землю":

а) замість четвертого та п'ятого абзаців включити абзац четвертий такого змісту:

"використання прибутку (рахунок 81 "Використання прибутку") - в частині податку на землю, що використовується у сільськогосподарському або виробничому обороті";

б) абзац шостий вважати абзацом п'ятим, доповнивши його словами "з включенням до інших капітальних робіт і затрат";

в) останній абзац виключити.

5. ( Пункт 5 втратив чинність на підставі Наказу Мінфіну N 29 ( z0082-96 ) від 14.02.96 ) У листі Міністерства фінансів України від 16 квітня 1992 р. N 18-445 ( v-445201-92 ) "Про бухгалтерський облік операцій в іноземних валютах":

а) абзац шостий доповнити реченням такого змісту:

"Курсова різниця з іноземної валюти підприємства, що відповідно до статті 5 Закону України "Про порядок здійснення розрахунків в іноземній валюті" ( 185/94-ВР ) продана уповноваженим банком, відображається по дебету рахунку 52 "Валютний рахунок" і кредиту рахунку 68 "Розрахунки з бюджетом" - у випадках утворення позитивної різниці, та по дебету рахунку 80 "Прибутки і збитки" і кредиту рахунку 52 - у випадках утворення негативної різниці." ;

б) абзаци дев'ятий і десятий визнати такими, що втратили чинність.

6. Визнати такими, що втратили чинність:

а) пункти 1-6, 8 листа Міністерства фінансів України від 3 лютого 1993 р. N 18-408 ( z0003-93 ) "Про обсяг, форми і порядок складання квартальної бухгалтерської звітності підприємствами й організаціями";

б) наказ Міністерства фінансів України від 1 лютого 1994 р. N 10 ( z0021-94 ), "Про затвердження обсягу, форм і порядку складання квартальної бухгалтерської звітності

підприємствами й організаціями"; в) наказ Міністерства фінансів України від 20 грудня 1993 р. N 110 ( z0195-93 ) "Про затвердження Особливостей складу витрат виробництва та обігу для підприємств з іноземними інвестиціями".

7. Зміни і доповнення в бухгалтерському обліку застосовуються з 1 січня 1995 р.

"В розділі IV "Затрати і витрати, що враховуються при обчисленні пільг по податку на прибуток" показуються суми затрат, що враховуються при обчисленні пільг по податку на прибуток, а саме: на придбання спецобладнання та устаткування для забезпечення роботи інвалідів I та II групи (рядок 500); на утримання об'єктів соціальної сфери, що перебувають на балансі підприємства (рядок 510); на реконструкцію і модернізацію активної частини основних фондів (рядок 520); прибуток, що перераховано до фондів, установ, закладів, громадських, релігійних та інших організацій, метою діяльності яких не є одержання прибутку, для провадження екологічної, оздоровчої, аматорської спортивної, культурної, освітньої, наукової та благодійної діяльності (рядок 540)".
