Про внесення змін до порядків, затверджених постановами Кабінету Міністрів України від 27 грудня 2001 р. N 1751 та від 11 січня 2007 р. N 13

Стан: Чинний

Текст документа від 01.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 липня 2007 р. N 900 Київ

Про внесення змін до порядків, затверджених постановами Кабінету Міністрів України від 27 грудня 2001 р. N 1751 та від 11 січня 2007 р. N 13

{ Із змінами, внесеними згідно з Постановою КМ N 57 ( 57-2008-п ) від 22.02.2008 }

Кабінет Міністрів України постановляє:

Внести до Порядку призначення і виплати державної допомоги сім'ям з дітьми, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1751 ( 1751-2001-п ) (Офіційний вісник України, 2001 р., N 52, ст. 2365; 2002 р., N 12, ст. 601, N 52, ст. 2372; 2003 р., N 37, ст. 1981, N 51, ст. 2691; 2004 р., N 16, ст. 1110; 2005 р., N 17, ст. 902; 2006 р., N 22, ст. 1609, N 31, ст. 2233), та Порядку призначення і виплати допомоги при народженні дитини та допомоги по догляду за дитиною до досягнення нею трирічного віку особам, застрахованим в системі загальнообов'язкового державного соціального страхування, затвердженого постановою Кабінету Міністрів України від 11 січня 2007 р. N 13 ( 13-2007-п ) "Деякі питання призначення і виплати допомоги сім'ям з дітьми" (Офіційний вісник України, 2007 р., N 2, ст. 72), зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 11 липня 2007 р. N 900

ЗМІНИ, що вносяться до порядків, затверджених постановами Кабінету Міністрів України від 27 грудня 2001 р. N 1751 ( 1751-2001-п ) та від 11 січня 2007 р. N 13 ( 13-2007-п )

1. У Порядку призначення і виплати державної допомоги сім'ям з дітьми, затвердженому постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1751 ( 1751-2001-п ):

1) доповнити пункт 3 абзацом такого змісту:

"жінки, зареєстровані як суб'єкти підприємницької діяльності, які не сплачують страхові внески до Фонду соціального страхування з тимчасової втрати працездатності.";

2) доповнити підпункт 5 пункту 7 після слів "непрацюючим жінкам" словами "та жінкам, зареєстрованим як суб'єкти підприємницької діяльності,";

3) у пункті 11 виключити:

підпункти 3 - 5 абзацу першого;

абзац третій;

друге речення абзацу дванадцятого пункту 13;

абзац другий пункту 15;

підпункти 4 і 8 абзацу першого пункту 20;

4) в абзаці першому пункту 55 слова і цифри "абзаці дев'ятому пункту 33" замінити словами і цифрами "абзаці десятому пункту 35".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 57 ( 57-2008-п ) від 22.02.2008 }
