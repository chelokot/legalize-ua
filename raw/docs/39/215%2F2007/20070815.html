Президент України; Указ, Склад колегіального органу від 17.03.2007 № 215/2007

Про склад Української частини Робочої групи (Секретаріату) з організаційного забезпечення діяльності Українсько-Російської міждержавної комісії

Стан: Втратив чинність

Ідентифікатор: 215/2007

Текст документа від 15.08.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 711/2007 ( 711/2007 ) від 15.08.2007 }

Про склад Української частини Робочої групи (Секретаріату) з організаційного забезпечення діяльності Українсько-Російської міждержавної комісії

З метою організаційного забезпечення діяльності Української частини Українсько-Російської міждержавної комісії постановляю:

1. Затвердити персональний склад Української частини Робочої групи (Секретаріату) з організаційного забезпечення діяльності Українсько-Російської міждержавної комісії (додається).

2. Надати право секретареві Української частини Українсько-Російської міждержавної комісії вносити в разі потреби зміни до складу Української частини Робочої групи (Секретаріату) з організаційного забезпечення діяльності Українсько-Російської міждержавної комісії.
