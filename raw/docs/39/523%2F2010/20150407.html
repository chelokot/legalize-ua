Питання забезпечення Президентом України керівництва у сферах національної безпеки та оборони

Стан: Чинний

Ідентифікатор: 523/2010

Текст документа від 07.04.2015:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання забезпечення Президентом України керівництва у сферах національної безпеки та оборони

{ Із змінами, внесеними згідно з Указом Президента N 197/2015 ( 197/2015 ) від 03.04.2015 }

Відповідно до пунктів 1 і 17 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Міністерству оборони України погоджувати з Президентом України терміни відправлення, повернення та чисельність військовослужбовців Збройних Сил України, тип і склад озброєння та військової техніки, які направляються для участі у заходах, передбачених затвердженими планами військового співробітництва відповідно до міжнародних договорів України на відповідний період, планом проведення багатонаціональних навчань за участю підрозділів Збройних Сил України на території України та їх участі у багатонаціональних навчаннях поза межами України на відповідний рік, - не пізніше ніж за 10 днів до відправлення.

{ Стаття 1 в редакції Указу Президента N 197/2015 ( 197/2015 ) від 03.04.2015 }

2. Дія статті 1 цього Указу не поширюється на випадки направлення у відрядження військовослужбовців Збройних Сил України за межі України самостійно або у складі військового підрозділу (команди) чисельністю до 30 осіб без озброєння і військової техніки.

{ Стаття 2 із змінами, внесеними згідно з Указом Президента N 197/2015 ( 197/2015 ) від 03.04.2015 }

3. Контроль за виконанням цього Указу покласти на Главу Адміністрації Президента України.

4. Цей Указ набирає чинності з дня його опублікування.
