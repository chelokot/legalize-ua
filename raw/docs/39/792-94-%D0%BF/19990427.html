Питання Міністерства вугільної промисловості

Стан: Втратив чинність

Ідентифікатор: 792-94-п

Текст документа від 27.04.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 листопада 1994 р. N 792 Київ

Питання Міністерства вугільної промисловості

( Із змінами, внесеними згідно з Постановою КМ N 1040 ( 1040-98-п ) від 10.07.98 )

( Додатково див. Постанову КМ N 719 ( 719-99-п ) від 27.04.99 )

Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. Установити граничну чисельність працівників центрального апарату Міністерства вугільної промисловості у кількості 278 чоловік.

2. Дозволити Міністерству вугільної промисловості мати шістьох заступників Міністра, у тому числі одного першого, і колегію в кількості 13 чоловік.

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1040 ( 1040-98-п ) від 10.07.98 )

3. Міністерству фінансів профінансувати витрати на утримання зазначеного Міністерства у межах асигнувань, затверджених у Державному бюджеті України на 1994 рік на утримання органів державної виконавчої влади.

4. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 16 червня 1992 р. N 330 ( 330-92-п ) "Питання Державного комітету по вугільній промисловості";

постанову Кабінету Міністрів України від 28 липня 1992 р. N 430 "Питання Державного комітету по вугільній промисловості;

розпорядження Кабінету Міністрів України від 2 лютого 1993 р. N 71 ( 71-93-р );

постанову Кабінету Міністрів України від 27 грудня 1993 р. N 1062.
