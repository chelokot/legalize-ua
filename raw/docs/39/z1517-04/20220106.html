Про внесення змін до наказу Міністра оборони України від 06.02.2001 N 36

{ Із змінами, внесеними згідно з Наказом Міністерства оборони N 332 ( z1667-21 ) від 27.10.2021 }

Відповідно до постанови Кабінету Міністрів України від 25.08.2004 N 1112 ( 1112-2004-п ) "Деякі питання розслідування та ведення обліку нещасних випадків, професійних захворювань і аварій на виробництві" НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства оборони N 332 ( z1667-21 ) від 27.10.2021 }

2. Наказ Міністра оборони України від 28 січня 2002 року N 49 ( z0128-02 ) "Про внесення змін до наказу Міністра оборони України від 06.02.2001 N 36", зареєстрований в Мін'юсті України 11 лютого 2002 року за N 128/6416, уважати таким, що втратив чинність.

3. Наказ розіслати до окремої військової частини.
