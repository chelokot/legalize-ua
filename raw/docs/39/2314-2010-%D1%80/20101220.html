Про перерозподіл окремих бюджетних призначень, передбачених Національному космічному агентству на 2010 рік

Стан: Чинний

Ідентифікатор: 2314-2010-р

Текст документа від 20.12.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 грудня 2010 р. N 2314-р Київ

Про перерозподіл окремих бюджетних призначень, передбачених Національному космічному агентству на 2010 рік

1. Відповідно до частини другої статті 26 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) здійснити перерозподіл бюджетних призначень загального фонду державного бюджету, передбачених Національному космічному агентству, у межах їх загального обсягу шляхом зменшення обсягу видатків розвитку за програмою 6381130 "Обслуговування кредитів, залучених для реалізації проекту "Циклон-4" ( 2154-17 ) на 37231,3 тис. гривень та збільшення обсягу видатків розвитку за програмою 6381040 "Загальнодержавна цільова науково-технічна космічна програма України" ( 2154-17 ) на таку ж суму.

Міністерству фінансів внести відповідні зміни до розпису державного бюджету ( 2154-17 ).

2. Зазначені у пункті 1 бюджетні кошти використовуються відповідно до Порядку використання у 2010 році коштів, передбачених у державному бюджеті для виконання Загальнодержавної цільової науково-технічної космічної програми, затвердженого постановою Кабінету Міністрів України від 14 липня 2010 р. N 583 ( 583-2010-п ) "Про використання у 2010 році коштів, передбачених у державному бюджеті для виконання Загальнодержавної цільової науково-технічної космічної програми" (Офіційний вісник України, 2010 р., N 53, ст. 1777).

Прем'єр-міністр України М.АЗАРОВ
