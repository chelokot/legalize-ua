Текст документа від 05.07.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії Указу Президента України від 10 червня 1997 року N 503

1. Зупинити на період до відкриття першого засідання Верховної Ради України VI скликання дію Указу Президента України від 10 червня 1997 року N 503 ( 503/97 ) "Про порядок офіційного оприлюднення нормативно-правових актів та набрання ними чинності" (зі змінами, внесеними Указами від 4 грудня 1997 року N 1327 ( 1327/97 ), від 10 листопада 1998 року N 1235 ( 1235/98 ), від 8 квітня 2004 року N 399 ( 399/2004 ), від 28 травня 2004 року N 589 ( 589/2004 ), від 19 травня 2005 року N 824 ( 824/2005 ), від 12 лютого 2007 року N 102 ( 102/2007 ) та 12 березня 2007 року N 199) ( 199/2007 ) в частині, що стосується офіційного оприлюднення законів та інших актів Верховної Ради України.

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 5 липня 2007 року N 607/2007
