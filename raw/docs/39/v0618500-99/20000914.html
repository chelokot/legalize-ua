ПОСТАНОВА

N 46 від 03.02.99 Зареєстровано в юридичному м.Київ департаменті Нацбанку 3 лютого 1999 р. vd990203 vn46 за N 618

Про подальше упорядкування та введення єдиних тарифів за використання засобів захисту та інших послуг, що надаються регіональними управліннями Національного банку України з питань захисту електронної банківської інформації

( Із змінами, внесеними згідно з Постановами Нацбанку N 621 ( z0053-00 ) від 27.12.99 N 311 ( z0606-00 ) від 08.08.2000 )

У зв'язку зі змінами умов надання засобів захисту Національного банку України для використання в інформаційно-обчислювальній мережі, які затверджені постановою Правління Національного банку України від 8.10.98 "Про затвердження Положення про міжбанківські розрахунки в Україні" ( v0579500-98 ), та з метою подальшого упорядкування і введення єдиних тарифів за використання засобів захисту та інших послуг, що надаються регіональними управліннями та установами Національного банку України комерційним банкам з питань захисту електронної банківської інформації, Правління ПОСТАНОВЛЯЄ:

( Пункт 1 втратив чинність на підставі Постанови Нацбанку N 311 ( z0606-00 ) від 08.08.2000 )

( Пункт 2 втратив чинність на підставі Постанови Нацбанку N 621 ( z0053-00 ) від 27.12.99 )

3. Зобов'язати начальників Кримського республіканського, Головного, обласних та по місту Києву і Київській області управлінь і установ Національного банку України протягом місяця переукласти договори з клієнтами "Про використання криптографічних засобів захисту інформації в інформаційно-обчислювальній мережі Національного банку України" і встановити постійний контроль за їх виконанням.

4. Контроль за виконанням цієї постанови покласти на Департамент інформатизації (А.С.Савченко), Фінансовий департамент (О.М.Кандибка), Управління внутрішніх ревізій (М.Р.Романик).
