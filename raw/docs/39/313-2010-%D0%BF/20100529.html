Кабінет Міністрів України; Постанова від 24.03.2010 № 313

Про внесення змін до постанов Кабінету Міністрів України від 22 лютого 2008 р. N 107 і від 20 січня 2010 р. N 36

Стан: Втратив чинність

Ідентифікатор: 313-2010-п

Текст документа від 29.05.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 березня 2010 р. N 313 Київ

Про внесення змін до постанов Кабінету Міністрів України від 22 лютого 2008 р. N 107 і від 20 січня 2010 р. N 36

{ Із змінами, внесеними згідно з Постановою КМ N 357 ( 357-2010-п ) від 14.04.2010 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 22 лютого 2008 р. N 107 ( 107-2008-п ) "Про затвердження Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" (Офіційний вісник України, 2008 р., N 18, ст. 482, N 82, ст. 2763; 2009 р., N 59, ст. 2067; 2010 р., N 16, ст. 758) і від 20 січня 2010 р. N 36 ( 36-2010-п ) "Питання фінансування підготовки об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу за рахунок коштів Стабілізаційного фонду" (Офіційний вісник України, 2010 р., N 3, ст. 98, N 7, ст. 329, N 16, ст. 758) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 44

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 24 березня 2010 р. N 313

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 22 лютого 2008 р. N 107 ( 107-2008-п ) і від 20 січня 2010 р. N 36 ( 36-2010-п )

{ Пункт 1 втратив чинність на підставі Постанови КМ N 357 ( 357-2010-п ) від 14.04.2010 }

2. У постанові Кабінету Міністрів України від 20 січня 2010 р. N 36 ( 36-2010-п ):

1) у пункті 3 постанови ( 36-2010-п ) цифри "1056782" і "21000" замінити відповідно цифрами "1116782" і "81000";

2) у пункті 2 Порядку використання у 2010 році коштів Стабілізаційного фонду для підготовки об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженого зазначеною постановою ( 36-2010-п ):

в абзаці двадцять другому слово "гривень" виключити;

доповнити пункт абзацом такого змісту:

"60000 тис. гривень - на будівництво другої нитки Головного міського каналізаційного колектора в м. Києві (ділянка на території НСК "Олімпійський").".
