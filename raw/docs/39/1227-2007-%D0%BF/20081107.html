КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 жовтня 2007 р. N 1227 Київ

Про внесення змін до постанови Кабінету Міністрів України від 8 травня 2001 р. N 488

{ Із змінами, внесеними згідно з Постановою КМ N 939 ( 939-2008-п ) від 25.10.2008 }

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 8 травня 2001 р. N 488 ( 488-2001-п ) "Про умови оплати праці працівників президії Національної академії наук та її апарату" (Офіційний вісник України, 2001 р., N 20, ст. 871; 2002 р., N 12, ст. 578, N 15, ст. 796) такі зміни:

{ Абзац другий постановляючої частини втратив чинність на підставі Постанови КМ N 939 ( 939-2008-п ) від 25.10.2008 }

{ Абзац третій постановляючої частини втратив чинність на підставі Постанови КМ N 939 ( 939-2008-п ) від 25.10.2008 }

додатки 1-3 до постанови ( 488-2001-п ) викласти в редакції, що додається.
