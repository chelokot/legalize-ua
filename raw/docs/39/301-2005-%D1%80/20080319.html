{ Розпорядження втратило чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

Про внесення змін до розпорядження Кабінету Міністрів України від 4 лютого 1998 р. N 62

Внести до розпорядження Кабінету Міністрів України від 4 лютого 1998 р. N 62 ( 62-98-р ) такі зміни:

в абзаці першому пункту 1 слова "і Європейським банком реконструкції та розвитку" виключити;

додаток до розпорядження викласти в редакції, що додається.
