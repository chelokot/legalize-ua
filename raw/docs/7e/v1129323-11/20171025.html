Про затвердження складу редакційної ради інформаційного бюлетеня "Офіційний вісник України" та внесення змін до його Концепції

Стан: Втратив чинність

Ідентифікатор: v1129323-11

Текст документа від 25.10.2017:

МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

15.04.2011 N 1129/5

{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 3325/5 ( v3325323-17 ) від 25.10.2017 }

Про затвердження складу редакційної ради інформаційного бюлетеня "Офіційний вісник України" та внесення змін до його Концепції

{ Із змінами, внесеними згідно з Наказами Міністерства юстиції N 729/5 ( v0729323-12 ) від 15.05.2012 N 1386/5 ( v1386323-13 ) від 11.07.2013 }

З метою офіційного оприлюднення нормативно-правових актів в інформаційному бюлетені "Офіційний вісник України" та відповідно до наказу Міністерства юстиції України від 08.04.2011 N 367/к ( v367_323-11 ) "Про затвердження структури та чисельності працівників центрального апарату Міністерства юстиції" НАКАЗУЮ:

1. Затвердити редакційну раду інформаційного бюлетеня "Офіційний вісник України" у складі, що додається.

2. Унести до Концепції інформаційного бюлетеня "Офіційний вісник України", затвердженої наказом Міністерства юстиції України від 22 грудня 2006 року N 102/5 ( v0102323-06 ), такі зміни:

пункт 12 викласти у такій редакції:

"12. Унесення нормативно-правових актів до "Офіційного вісника України" здійснюється на підставі рішення, погодженого заступником керівника відповідного структурного підрозділу та затвердженого керівником Департаменту чи його заступником";

пункт 13 викласти у такій редакції:

"13. Оригінал-макет кожного номера "Офіційного вісника України" підписується до друку посадовою особою, яка відповідно до розподілу обов'язків, затвердженого наказом Міністерства юстиції, координує та контролює діяльність державного підприємства "Українська правова інформація" або, за її дорученням, керівником Департаменту чи його заступником".

3. Визнати таким, що втратив чинність, наказ Міністерства юстиції України від 25 березня 2010 року N 605/5 "Про склад редакційної ради інформаційного бюлетеня "Офіційний вісник України".

4. Контроль за виконанням цього наказу покласти на директора Департаменту реєстрації та систематизації нормативних актів, правоосвітньої діяльності Н.А.Железняк.
