КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 грудня 1999 р. N 2193 Київ

( Постанова втратила чинність на підставі Постанови КМ N 905 ( 905-2000-п ) від 05.06.2000 )

Про доповнення переліку товарів критичного імпорту

Кабінет Міністрів України постановляє:

1. Доповнити перелік товарів критичного імпорту, затверджений постановою Кабінету Міністрів України від 18 червня 1999 р. N 1080 ( 1080-99-п ) "Про перелік товарів критичного імпорту" (Офіційний вісник України, 1999 р., N 25, ст. 1167, N 27, ст. 1337, N 44, ст. 2180), із змінами, внесеними постановою Кабінету Міністрів України від 25 листопада 1999 р. N 2113 ( 2133-99-п ), товаром за кодом згідно з ТН ЗЕД 2701 12 100 (вугілля коксівне).

2. Ця постанова набирає чинності з дня її опублікування.
