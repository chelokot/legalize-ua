НАКАЗ Міністра оборони України

22.11.2005 N 694

Зареєстровано в Міністерстві юстиції України 29 листопада 2005 р. за N 1434/11714

{ Наказ втратив чинність на підставі Наказу Міністерства оборони N 164 ( z0386-06 ) від 30.03.2006 }

Про внесення змін та доповнень до Умов оплати праці працівників (невійськовослужбовців) апарату органів військового управління та військових комісаріатів, затверджених наказом Міністра оборони України від 28.02.2000 N 55

З метою упорядкування умов оплати праці працівників (невійськовослужбовців) апарату органів військового управління та військових комісаріатів, на виконання вимог постанов Кабінету Міністрів України від 15 січня 2005 року N 37 ( 37-2005-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів", від 8 червня 2005 року N 433 ( 433-2005-п ) "Про внесення змін у додатки до деяких постанов Кабінету Міністрів України" та у зв'язку з проведеними організаційними заходами відповідно до постанови Кабінету Міністрів України від 15 квітня 2005 року N 295 ( 295-2005-п ) "Про утворення Державного департаменту адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів" НАКАЗУЮ:

1. Затвердити Зміни та доповнення до Умов оплати праці працівників (невійськовослужбовців) апарату органів військового управління та військових комісаріатів, затверджених наказом Міністра оборони України від 28 лютого 2000 року N 55 ( z0123-00 ) "Про затвердження Умов оплати праці працівників (невійськовослужбовців) апарату органів військового управління та військових комісаріатів", зареєстрованим у Міністерстві юстиції України 2 березня 2000 року за N 123/4344 (зі змінами та доповненнями), що додаються.

2. Контроль за виконанням наказу покласти на директора Департаменту фінансів Міністерства оборони України.

3. Наказ розіслати згідно з розрахунком розсилки.

Міністр оборони України А.С.Гриценко

Центральний комітет Всеукраїнської профспілки працівників Збройних Сил України Д.Мірошниченко

ЗАТВЕРДЖЕНО Наказ Міністра оборони України 22.11.2005 N 694

Зареєстровано в Міністерстві юстиції України 29 листопада 2005 р. за N 1434/11714

ЗМІНИ ТА ДОПОВНЕННЯ до Умов оплати праці працівників (невійськовослужбовців) апарату органів військового управління та військових комісаріатів, затверджених наказом Міністра оборони України від 28 лютого 2000 року N 55 "Про затвердження Умов оплати праці працівників (невійськовослужбовців) апарату органів військового управління та військових комісаріатів", зареєстрованим у Міністерстві юстиції України 2 березня 2000 року за N 123/4344 (зі змінами та доповненнями)

1. Пункти 1, 2 та 6-1 Умов оплати праці працівників (невійськовослужбовців) апарату органів військового управління та військових комісаріатів, затверджених наказом Міністра оборони України від 28 лютого 2000 року N 55 "Про затвердження Умов оплати праці працівників (невійськовослужбовців) апарату органів військового управління та військових комісаріатів", зареєстрованим у Міністерстві юстиції України 2 березня 2000 року за N 123/4344 ( z0123-00 ) (зі змінами та доповненнями) (далі - Умови), після слів "Генерального штабу Збройних Сил України" доповнити словами "Державного департаменту адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів".

2. Додаток 1 до пункту 2 Умов викласти в редакції, що додається.

Тимчасово виконуючий обов'язки директора Департаменту фінансів Міністерства оборони України В.В.Гагурін
