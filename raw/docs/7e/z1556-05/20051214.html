МІНІСТЕРСТВО ОХОРОНИ НАВКОЛИШНЬОГО ПРИРОДНОГО СЕРЕДОВИЩА УКРАЇНИ

НАКАЗ

14.12.2005 N 459

Зареєстровано в Міністерстві юстиції України 26 грудня 2005 р. N 1556/11836

Про визнання деяких наказів Мінекобезпеки такими, що втратили чинність

На виконання Указу Президента України від 1 червня 2005 року N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Мінекобезпеки України від 27.05.96 N 49 ( z0289-96 ) "Про затвердження Методики індексації нормативів плати за забруднення навколишнього природного середовища", зареєстрований в Мін'юсті 11.06.96 за N 289/1314 та від 29.12.96 N 157 ( z0018-97 ) "Про затвердження Базових нормативів плати за забруднення навколишнього природного середовища", зареєстрований в Мін'юсті 31.01.97 за N 18/1822.

2. Департаменту стратегічного планування, економіки природокористування та екологічного менеджменту забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України в установленому порядку.

3. Контроль за виконанням наказу покладаю на першого заступника Міністра С.Лизуна.

Міністр П.Ігнатенко
