{ Постанова втратила чинність на підставі Постанови КМ N 723 ( 723-2016-п ) від 19.10.2016 }

Про доповнення пункту 4 Положення про порядок визначення наукових об'єктів, що становлять національне надбання

Кабінет Міністрів України постановляє:

Доповнити пункт 4 Положення про порядок визначення наукових об'єктів, що становлять національне надбання, затвердженого постановою Кабінету Міністрів України від 18 лютого 1997 р. N 174 ( 174-97-п ) (Офіційний вісник України, 1997 р., число 8, с. 140; 1998 р., N 39, ст. 1439; 1999 р., N 14, ст. 562; 2001 р., N 51, ст. 2305), після слів "(далі - реєстр)" словами ", веде зазначений реєстр і видає свідоцтва про включення об'єктів до реєстру".
