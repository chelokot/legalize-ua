{ Наказ втратив чинність на підставі Наказу Національного банку N 37 ( v0037500-11 ) від 28.02.2011 }

Про внесення зміни до наказу Національного банку України від 12.05.2009 N 78

У зв'язку з кадровими змінами в центральному апараті Національного банку України НАКАЗУЮ:

1. П'ятий абзац пункту 1 наказу Національного банку України від 12.05.2009 N 78 ( v0078500-09 ) "Про затвердження складу Комітету з питань аудиту банків" викласти в такій редакції:

"К.В.Рожкова - директор Департаменту безвиїзного банківського нагляду;"

2. Контроль за виконанням цього наказу покласти на виконавчого директора - директора Дирекції з банківського регулювання та нагляду В.В.Пасічника.
