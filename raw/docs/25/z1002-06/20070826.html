{ Наказ втратив чинність на підставі Наказу Міністерства аграрної політики N 586 ( z0935-07 ) від 10.08.2007 }

Про затвердження Розмірів бюджетних видатків для здійснення заходів з відтворення водних живих ресурсів внутрішніх водойм та Азово-Чорноморського басейну

З метою забезпечення виконання бюджетної програми "Відтворення та охорона водних живих ресурсів і регулювання рибальства" в частині здійснення заходів з відтворення водних живих ресурсів внутрішніх водойм та Азово-Чорноморського басейну, відповідно до постанови Кабінету Міністрів України від 07.03.2006 N 255 ( 255-2006-п ) "Про використання у 2006 році коштів державного бюджету для здійснення заходів з відтворення водних живих ресурсів внутрішніх водойм та Азово-Чорноморського басейну" НАКАЗУЮ:

1. Затвердити Розміри бюджетних видатків для здійснення заходів з відтворення водних живих ресурсів внутрішніх водойм та Азово-Чорноморського басейну, що додаються.

2. Контроль за виконанням наказу покласти на заступника Міністра Скорченка А.Ф.

Міністр О.П. Баранівський

ПОГОДЖЕНО:

Заступник Міністра фінансів України А.І.Мярковський
