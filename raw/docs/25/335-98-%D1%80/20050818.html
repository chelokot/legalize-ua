Стан: Втратив чинність

Ідентифікатор: 335-98-р

Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 травня 1998 р. N 335-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про склад Української частини Координаційної ради з питань реалізації Програми економічного співробітництва між Україною та Російською Федерацією на 1998-2007 роки

( Із змінами, внесеними згідно з Розпорядженнями КМ N 407-р ( 407-98-р ) від 16.06.98 N 280-р ( 280-2000-р ) від 03.07.2000 )

Для виконання рішень третього засідання Змішаної Українсько-Російської комісії по співробітництву від 20 лютого 1998 р. утворити у рамках цієї Комісії Українську частину Координаційної ради з питань реалізації Програми економічного співробітництва між Україною та Російською Федерацією на 1998-2007 роки і затвердити її склад, що додається.

Голові Української частини Координаційної ради у двотижневий термін узгодити з Російською Стороною та затвердити Положення про Координаційну раду з питань реалізації Програми економічного співробітництва між Україною та Російською Федерацією на 1998 - 2007 роки і план роботи Ради на 1998 рік.
