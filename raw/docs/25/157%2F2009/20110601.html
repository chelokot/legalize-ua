{ Указ втратив чинність на підставі Указу Президента N 591/2011 ( 591/2011 ) від 20.05.2011 }

Про внесення зміни до Мережі та кількісного складу суддів місцевих судів

Внести зміну до розділу "Луганська область" Мережі та кількісного складу суддів місцевих судів, затвердженої Указом Президента України від 20 серпня 2001 року N 641 ( 641/2001 ) (зі змінами, внесеними Указами від 22 жовтня 2002 року N 938 ( 938/2002 ), від 15 березня 2004 року N 328 ( 328/2004 ), від 31 серпня 2006 року N 729 ( 729/2006 ) та від 18 травня 2007 року N 424) ( 424/2007 ), виклавши пункт 25 в такій редакції:

"25. Сєвєродонецький міський 12 м. Сєвєродонецьк".

Президент України В.ЮЩЕНКО

м. Київ, 16 березня 2009 року N 157/2009
