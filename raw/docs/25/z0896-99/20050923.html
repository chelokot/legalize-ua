( Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку

N 423 ( z1035-05 ) від 19.07.2005 )

Щодо можливості використання фондових деривативів у процесі приватизації

З метою створення умов для розвитку ринку фондових деривативів в Україні Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Установити, що дія пункту 1 рішення Державної комісії з цінних паперів та фондового ринку від 14.09.98 N 109 ( z0570-98 ), зареєстрованого в Міністерстві юстиції України 15.09.98 за N 570/3010, не поширюється на фондові деривативи, базовим активом яких є акції, що перебувають у державній власності.

2. Установити, що це рішення набуває чинності в установленому законодавством порядку.

3. Доручити управлінню регулювання випуску та обігу цінних паперів забезпечити реєстрацію цього рішення в Міністерстві юстиції України.

4. Доручити прес-центру забезпечити публікацію цього рішення в установленому порядку.

5. Контроль за виконанням цього рішення покласти на члена Комісії О.Бойка.

Голова Комісії О.Мозговий
