{ Наказ втратив чинність на підставі Наказу Міністерства економіки N 385 ( z0900-08 ) від 26.08.2008 }

Про граничний розмір роздрібних цін на газ природний

{ Із змінами, внесеними згідно з Наказом Мінекономіки N 112 ( z0459-97 ) від 06.10.97 }

{ Щодо втрати чинності Наказу додатково див. Наказ Міністерства економіки N 230 ( v0230665-07 ) від 19.07.2007 - Наказ скасовано на підставі Наказу Міністерства економіки N 270 ( v0270665-08 ) від 10.07.2008 }

Згідно з повноваженнями, затвердженими постановою Кабінету Міністрів України від 25.12.96 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", та у зв'язку з набранням чинності Закону України "Про податок на додану вартість" ( 168/97-ВР ) НАКАЗУЮ:

1. Затвердити граничні розміри роздрібних цін на газ природний, що споживається населенням на комунально-побутові потреби, з урахуванням сплати податку на додану вартість (додаються).

2. Вважати такими, що втратили чинність, граничні розміри роздрібних цін на газ природний, затверджені наказом Мінекономіки від 19.05.97 р. N 57 ( z0200-97 ), зареєстровані 28.05.97 р. N 200/2004.

Міністр Ю.І.Єхануров

( Граничні розміри роздрібних цін на газ природний втратили чинність на підставі Наказу Мінекономіки N 112 ( z0459-97 ) від 06.10.97 )
