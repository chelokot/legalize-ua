Президент України; Указ від 25.04.2001 № 281/2001

Про Постійного представника Президента України на Чорнобильській АЕС

Стан: Втратив чинність

Ідентифікатор: 281/2001

Текст документа від 25.04.2001:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Постійного представника Президента України на Чорнобильській АЕС

1. Увести до складу Адміністрації Президента України посаду Постійного представника Президента України на Чорнобильській АЕС.

У зв'язку з цим статтю 1 Указу Президента України від 29 грудня 1999 року N 1625 ( 1625/99 ) "Питання Адміністрації Президента України" (із змінами, внесеними Указами Президента України від 23 лютого 2000 року N 278 ( 278/2000 ), від 9 березня 2000 року N 397 ( 397/2000 ), від 25 грудня 2000 року N 1370 ( 1370/2000 ) та від 1 лютого 2001 року N 67) ( 67/2001 ) після слів "Постійний представник Президента України в Кабінеті Міністрів України" доповнити словами "Постійний представник Президента України на Чорнобильській АЕС".

2. Призначити АНТРОПОВА Олександра Степановича Постійним представником Президента України на Чорнобильській АЕС.

3. Кабінету Міністрів України подати у двотижневий строк проект Положення про Постійного представника Президента України на Чорнобильській АЕС.

Президент України Л.КУЧМА
