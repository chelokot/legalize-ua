( Із змінами, внесеними згідно з Розпорядженнями КМ N 1074 ( 1074-93-п ) від 29.12.93 N 74-р ( 74-94-р ) від 08.02.94 N 158-р ( 158-94-р ) від 05.03.94 )

N 1046 ( 1046-93-п ) затвердити перелік уповноважених організацій, які здійснюють експорт вугілля (коди ТН ЗЕД 27.01, 27.02, 27.04, 27.06), аміаку, етилену, бензолу, метанолу, мінеральних добрив (коди ТН ЗЕД 28.14, 29.01 21000, 29.02 20100, 29.02 20900, 29.05 11000, 31.02-31.05), чорних металів (коди ТН ЗЕД 72.01, 72.02, 72.04, 72.06-72.15, 72.18-72.22, 72.24-72.28), згідно з додатком.
