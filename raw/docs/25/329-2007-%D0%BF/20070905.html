Кабінет Міністрів України; Постанова, Порядок від 01.03.2007 № 329

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки інноваційних та інвестиційних проектів

Стан: Чинний

Ідентифікатор: 329-2007-п

Текст документа від 05.09.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 2007 р. N 329 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки інноваційних та інвестиційних проектів

{ Із змінами, внесеними згідно з Постановами КМ N 988 ( 988-2007-п ) від 01.08.2007 N 1093 ( 1093-2007-п ) від 05.09.2007 }

Кабінет Міністрів України постановляє:

1. Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки інноваційних та інвестиційних проектів, що додається.

2. Державному агентству з інвестицій та інновацій за погодженням з Міністерством фінансів, Міністерством економіки та Міністерством освіти і науки розробити у тижневий строк з урахуванням умов, визначених у Порядку, затвердженому цією постановою, механізм з визначенням чітких та прозорих критеріїв конкурсного відбору інноваційних та інвестиційних проектів, спрямованих на впровадження у виробництво передових технологій у галузях промисловості, для компенсації відсоткової ставки за кредитами, залученими на фінансування зазначених проектів. { Пункт 2 із змінами, внесеними згідно з Постановою КМ N 988 ( 988-2007-п ) від 01.08.2007 }

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 42

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 1 березня 2007 р. N 329

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки інноваційних та інвестиційних проектів

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Держінвестицій за програмою "Фінансова підтримка інноваційних та інвестиційних проектів, у першу чергу з впровадження передових технологій, що реалізуються в галузях промисловості, у тому числі технологічними парками, через механізм здешевлення кредитів" (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються на відшкодування сплачених у 2007 році відсотків за кредитами, залученими для фінансування інноваційних та інвестиційних проектів, у першу чергу з впровадження у виробництво передових технологій, що реалізуються в галузях промисловості, зокрема технологічними парками (далі - компенсація).

Компенсація надається за фактично сплачені відсотки за користування кредитами і не може перевищувати подвійну облікову ставку Національного банку, що діяла на дату їх нарахування.

3. Бюджетні кошти не можуть бути спрямовані на погашення будь-яких штрафних санкцій та(або) пені за порушення умов користування кредитами.

4. Право на компенсацію суб'єктам господарювання, які залучили кредити (далі - позичальники), надається на конкурсних засадах.

5. Компенсація виплачується в першу чергу позичальникам, які не мають простроченої більш як за два місяці заборгованості із заробітної плати, податків і зборів (обов'язкових платежів) перед державним і місцевими бюджетами та Пенсійним фондом.

Компенсація не виплачується позичальникам, які одержують фінансову підтримку за іншими бюджетними програмами або кошти міжнародних фінансових організацій, передбачені для зазначених у пункті 2 цього Порядку цілей.

6. Конкурсний відбір проводиться у порядку, визначеному Держінвестицій за погодженням з Мінфіном, Мінекономіки та МОН, з урахуванням таких умов:

до складу конкурсної комісії, затвердженого Держінвестицій, повинні входити представники Мінфіну, Мінекономіки, МОН, Мінпромполітики, НАЕР і Національної академії наук;

обов'язковою вимогою до проекту, який подається на розгляд конкурсної комісії, є визначення планового обсягу прибутку від реалізації проекту, строку його окупності, кількості створених нових робочих місць, планових надходжень платежів до бюджетів;

для участі у конкурсі позичальники подають по два примірники нотаріально засвідченої копії кредитного договору, довідки фінансової установи про надання позичальникам кредитів, довідки-розрахунка фінансової установи про розмір та строки сплати відсотків за користування кредитами, бізнес-плану інноваційного або інвестиційного проекту, копій платіжних доручень з відміткою фінансової установи про сплату відсотків за користування кредитом.

7. Держінвестицій подає Міжвідомчій раді з питань інвестицій та інноваційного розвитку до 10 числа місяця, що передує місяцю, в якому планується виплата компенсації, висновки конкурсної комісії, за результатами розгляду яких приймається рішення рекомендаційного характеру щодо доцільності виділення бюджетних коштів на реалізацію проекту.

З урахуванням рекомендацій Міжвідомчої ради конкурсна комісія приймає остаточне рішення щодо виплати компенсації. Рішення конкурсної комісії оформлюється протоколом, який надсилається Міжвідомчій раді в порядку інформації.

8. Позичальники - переможці конкурсу укладають з Держінвестицій та Державною інноваційною фінансово-кредитною установою тристоронній договір на виплату компенсації за формою, затвердженою Держінвестицій.

{ Пункт 8 із змінами, внесеними згідно з Постановою КМ N 1093 ( 1093-2007-п ) від 05.09.2007 }

9. Державна інноваційна фінансово-кредитна установа на підставі платіжних доручень, поданих позичальниками, з урахуванням розпису за бюджетною програмою складає графік перерахування коштів і подає його Держінвестицій до 20 числа місяця, що передує місяцю, в якому планується перерахування бюджетних коштів.

{ Пункт 9 із змінами, внесеними згідно з Постановою КМ N 1093 ( 1093-2007-п ) від 05.09.2007 }

10. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 10 в редакції Постанови КМ N 1093 ( 1093-2007-п ) від 05.09.2007 }

11. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
