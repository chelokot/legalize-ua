{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про утворення комітету з проведення у 2010 році аукціонів з продажу спеціальних дозволів на користування надрами

1. Утворити комітет з проведення у 2010 році аукціонів з продажу спеціальних дозволів на користування надрами у складі згідно з додатком.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 28 січня 2009 р. N 92 ( 92-2009-р ) "Про утворення комітету з проведення у 2009 році аукціонів з продажу спеціальних дозволів на користування надрами".
