УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Указів Президента України від 15 грудня 1999 року N 1573 та від 5 квітня 2001 року N 233

( Із змінами, внесеними згідно з Указом Президента N 1811/2005 ( 1811/2005 ) від 19.12.2005 )

У зв'язку з утворенням Державного комітету України у справах національностей та міграції постановляю:

1. Визнати таким, що втратив чинність, абзац другий пункту "б" статті 1 Указу Президента України від 15 грудня 1999 року N 1573 ( 1573/99 ) "Про зміни у структурі центральних органів виконавчої влади".

( Стаття 2 втратила чинність на підставі Указу Президента N 1811/2005 ( 1811/2005 ) від 19.12.2005 )

Президент України Л.КУЧМА

м. Київ, 3 січня 2002 року N 10/2002
