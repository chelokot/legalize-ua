Кабінет Міністрів України; Постанова від 31.12.1999 № 2406

Про внесення зміни до постанови Кабінету Міністрів України від 7 грудня 1999 р. N 2212

Стан: Втратив чинність

Ідентифікатор: 2406-99-п

Текст документа від 20.06.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 грудня 1999 р. N 2406 Київ

( Постанова втратила чинність на підставі Постанови КМ N 997 ( 997-2000-п ) від 20.06.2000 )

Про внесення зміни до постанови Кабінету Міністрів України від 7 грудня 1999 р. N 2212

Кабінет Міністрів України постановляє:

Внести зміну до постанови Кабінету Міністрів України від 7 грудня 1999 р. N 2212 ( 2212-99-п ) "Про утворення Державного агентства України з охорони промислової власності", виклавши абзац другий пункту 2 у такій редакції:

"Державному комітетові з питань науки та інтелектуальної власності ліквідувати державне підприємство "Інститут промислової власності" та передати його майно Агентству для утворення на базі цього майна відповідного структурного підрозділу Агентства".

Прем'єр-міністр України В.ЮЩЕНКО
