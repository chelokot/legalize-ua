Кабінет Міністрів України; Розпорядження від 19.07.2006 № 407-р

Про завершення реконструкції з розширенням комплексу будівель по вул. Червоноармійській, 50/23, у м. Києві

Стан: Чинний

Ідентифікатор: 407-2006-р

Текст документа від 31.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 липня 2006 р. N 407-р Київ

Про завершення реконструкції з розширенням комплексу будівель по вул. Червоноармійській, 50/23, у м. Києві

{ Із змінами, внесеними згідно з Розпорядженням КМ N 939-р ( 939-2007-р ) від 31.10.2007 }

1. Підтримати пропозицію Мінсім'ямолодьспорту щодо завершення реконструкції з розширенням комплексу будівель для розміщення Національного олімпійського комітету по вул. Червоноармійській, 50/23, у м. Києві за рахунок коштів інвестора, визначеного Мінсім'ямолодьспортом на конкурсних засадах, та Національного олімпійського комітету.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 939-р ( 939-2007-р ) від 31.10.2007 }

2. Мінсім'ямолодьспорту передбачити у договорі, який укладається з інвестором та Національним олімпійським комітетом, вимогу щодо залишення після реконструкції з розширенням у власності держави та Національного олімпійського комітету 1/2 корисної площі будівель (споруд), в тому числі із закріпленням у державній власності не менш як 3522 кв. метри, з урахуванням цілісності їх розташування та 100-відсоткової готовності до експлуатації. { Абзац перший пункту 2 із змінами, внесеними згідно з Розпорядженням КМ N 939-р ( 939-2007-р ) від 31.10.2007 }

Взяти до відома, що проект реконструкції та договір з інвестором та Національним олімпійським комітетом в обов'язковому порядку погоджуються з Мінсім'ямолодьспортом. { Абзац другий пункту 2 із змінами, внесеними згідно з Розпорядженням КМ N 939-р ( 939-2007-р ) від 31.10.2007 }
