Текст документа від 08.09.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 вересня 2004 р. N 653-р Київ

Про встановлення строку виконання ремонтно-відновлювальних робіт для деяких видів авіаційного обладнання за межами митної території України

Відповідно до статті 240 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити для авіаційного обладнання за кодом згідно з УКТЗЕД 8543 90 10 00 ( 2371г-14 ) строк виконання ремонтно-відновлювальних робіт за межами митної території України 180 днів.

Прем'єр-міністр України В.ЯНУКОВИЧ
