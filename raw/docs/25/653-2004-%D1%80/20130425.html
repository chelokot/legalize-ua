КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 вересня 2004 р. N 653-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання ремонтно-відновлювальних робіт для деяких видів авіаційного обладнання за межами митної території України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 881-р ( 881-2008-р ) від 25.06.2008 }

Відповідно до статті 240 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити для авіаційного обладнання за кодами згідно з УКТЗЕД 8414591000, 8418699900, 8419501000, 8421391000, 8424899500, 8481401000, 8481805100, 8481805900, 8481806300, 8504401000, 8537109100, 8543901000, 8803101000, 8803109000, 8803301000, 9014201800, 9014901000, 9025191000, 9026201000, 9026209000, 9032891000, 9032909090 ( 2371г-14 ) строк виконання ремонтно-відновлювальних робіт за межами митної території України 180 днів.

{ Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 881-р ( 881-2008-р ) від 25.06.2008 }
