Текст документа від 23.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 листопада 2009 р. N 1371-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1188-р ( 1188-2011-р ) від 23.11.2011 }

Питання Інституту дослідження проблем державної безпеки

1. Прийняти пропозицію СБУ щодо утворення державної науково-дослідної установи СБУ - Інституту дослідження проблем державної безпеки (далі - Інститут) на базі Наукового координаційного центру "Інститут оперативної діяльності та державної безпеки", який ліквідується.

2. Взяти до відома, що:

Інститут здійснює координацію спільних з Національною академією наук досліджень у сфері державної безпеки;

фінансування Інституту здійснюється в межах видатків, передбачених у державному бюджеті для СБУ.

3. СБУ розробити і затвердити у тримісячний строк Статут Інституту та привести власні акти у відповідність з цим розпорядженням.
