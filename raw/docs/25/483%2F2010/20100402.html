Президент України; Указ від 02.04.2010 № 483/2010

Про ліквідацію Національної ради з питань благодійництва "Зігрій любов'ю дитину"

Стан: Чинний

Ідентифікатор: 483/2010

Текст документа від 02.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про ліквідацію Національної ради з питань благодійництва "Зігрій любов'ю дитину"

Відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Ліквідувати Національну раду з питань благодійництва "Зігрій любов'ю дитину".

У зв'язку з цим визнати такими, що втратили чинність:

Указ Президента України від 19 грудня 2007 року N 1238 ( 1238/2007 ) "Про Національну раду з питань благодійництва "Зігрій любов'ю дитину";

Указ Президента України від 29 січня 2008 року N 61 ( 61/2008 ) "Про склад Національної ради з питань благодійництва "Зігрій любов'ю дитину";

Указ Президента України від 11 вересня 2009 року N 733 ( 733/2009 ) "Про внесення змін до Указу Президента України від 29 січня 2008 року N 61";

Указ Президента України від 30 вересня 2009 року N 782 ( 782/2009 ) "Про внесення змін до Указу Президента України від 29 січня 2008 року N 61".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 2 квітня 2010 року N 483/2010
