КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 квітня 2011 р. N 435 Київ

Про внесення зміни до пункту 15.10 Правил дорожнього руху

Кабінет Міністрів України постановляє:

Внести зміну до пункту 15.10 Правил дорожнього руху, затверджених постановою Кабінету Міністрів України від 10 жовтня 2001 р. N 1306 ( 1306-2001-п ) (Офіційний вісник України, 2001 р., N 41, ст. 1852; 2005 р., N 2, ст. 86, N 27, ст. 1569; 2007 р., N 14, ст. 522, N 48, ст. 1978; 2008 р., N 52, ст. 1740, N 75, ст. 2526; 2009 р., N 11, ст. 321, N 14, ст. 420, N 31, ст. 1053, N 68, ст. 2350), доповнивши його підпунктом "е" такого змісту:

"е) ближче 5 м від контейнерних майданчиків та/або контейнерів для збирання побутових відходів, місце розміщення або облаштування яких відповідає вимогам законодавства.".

Прем'єр-міністр України М.АЗАРОВ
