статистиці науки, інформатики і інновацій та інструкцій про порядок їх заповнення

( Із змінами, внесеними згідно з Наказами Мінстату N 207 ( z0391-96 ) від 09.07.96 N 10 ( z0441-97 ) від 27.08.97 Наказами Державного комітету статистики

Згідно з наказом Мінстату України "Про порядок затвердження форм державної статистичної звітності" від 30.04.93 N 76 ( z0054-93 ) НАКАЗУЮ:

1. ( Наказ втратив чинність в частині затвердження форм державної статистичної звітності та інструкцій про порядок їх заповнення NN 5-нт (ліцензії) ( z0235-95 ), 5-нт (сертифікація) ( z0239-95 ), 2-інф ( z0241-95 ), 3-інф ( z0242-95 ), 4-інф ( z0243-95 ), 6-наука ( z0235-95 ), додаток N 3 до форми N1-КМП ( z0235-95 ) на підставі Наказу Мінстату N 207 ( z0391-96 ) від 09.07.96; відносно форм державної статистичної звітності NN 1-наука, 2-наука, 3-наука, 1-нк, 18-нт, 1-інф, ДН, 1-інновація на підставі Наказу Держкомстатистики N 10 ( z0441-97 ) від 27.08.97 ) Затвердити форми державної статистичної звітності, розробка яких централізована в органах державної статистики, по статистиці науки, інформатики та інновацій, а також інструкції про порядок їх заповнення, що додаються, і ввести їх у дію, починаючи зі звіту за 1995 рік:

- річні:

N 1-наука "Звіт про виконання науково-технічних робіт";

N 1-нк "Звіт про роботу аспірантури та докторантури" ( z0236-95 );

N 4-нт "Звіт про надходження та використання об'єктів промислової власності" ( z0237-95 );

( Наказ втратив чинність в частині затвердження форми N 5-нт(оновлення)-річна державної статистичної звітності та інструкції про порядок її заповнення на підставі Наказу Державного комітету статистики N 290 ( z0850-03 ) від 09.09.2003 ) N 5-нт (оновлення) "Звіт про оновлення продукції машинобудування" ( z0238-95 );

N 5-нт (сертифікація) "Звіт про виробництво та поставку на експорт сертифікованої продукції" ( z0239-95 );

( Наказ втратив чинність в частині дії форми державної статистичної звітності N 6-нт (ліцензії) на підставі Наказу Держкомстатистики N 252 ( z0664-98 ) від 14.07.98 ) N 6-нт (ліцензії) "Звіт про продаж за кордон ліцензій на об'єкти промислової власності" ( z0240-95 );

N 2-інф "Звіт про поповнення парку обчислювальної техніки" ( z0241-95 );

N 3-інф одноразова "Звіт про використання програмних продуктів і обчислювальних мереж" ( z0242-95 );

N 4-інф одноразова "Звіт про наявність і використання банків даних" ( z0243-95 ).

2. Затвердити форми державної статистичної звітності, розробка яких централізована в органах державної статистики, по статистиці науки, інформатики та інновацій і ввести їх у дію, починаючи зі звіту за 1995 рік:

- річні:

N 3-наука "Показники наукової діяльності";

N 6-наука "Звіт про хід конверсії в НДІ і КБ";

N ДН "Картка обліку доктора наук";

Додаток N 3 до форми N 1-КМП "Основні показники діяльності малого підприємства (кооперативу) галузі "Наука і наукове обслуговування";

N 1-інновація "Звіт про інноваційну діяльність промислового підприємства";

( Наказ втратив чинність в частині затвердження форми державної статистичної звітності N 5-нт (зразки) та інструкції щодо її заповнення на підставі Наказу Держкомстату N 352 ( z0827-02 ) від 30.09.2002 ) N 5-нт (зразки) "Звіт про створені вперше в Україні зразки нових типів машин, устаткування, апаратів і приладів";

N 5-нт (ліцензії) "Звіт про освоєння закуплених за кордоном ліцензій";

N 18-нт "Звіт про витрати на використання науково-технічних робіт та їх ефективність";

N 1-інф "Звіт про діяльність обчислювальних центрів";

- періодичні:

N 2-наука квартальна "Звіт про виконання науково-технічних робіт";

( Наказ втратив чинність в частині затвердження форми N 5-наука-квартальна державної статистичної звітності на підставі Наказу Державного комітету статистики N 290 ( z0850-03 ) від 09.09.2003 ) N 5-наука квартальна "Звіт про виконання завдань науково-технічних програм";

( Наказ втратив чинність в частині затвердження форми N 2/5-нт-піврічна державної статистичної звітності на підставі Наказу Державного комітету статистики N 290 ( z0850-03 ) від 09.09.2003 ) N 2/5-нт піврічна "Звіт про хід виконання найважливіших робіт з питань науки та технологій";

( Наказ втратив чинність в частині затвердження форми державної статистичної звітності N 12-нтз квартальна та інструкції щодо її заповнення на підставі Наказу Держкомстату N 352 ( z0827-02 ) від 30.09.2002 ) N 12-нтз квартальна "Звіт про впровадження інновацій".

3. Розповсюдити форми, затверджені в пунктах 1, 2 цього наказу, на об'єднання, підприємства, установи, організації незалежно від відомчої підпорядкованості та форм власності.

4. Залишити без змін додатки до форми державної статистичної звітності N ДН, затверджені наказом Мінстату України N 88 від 08.06.92:

додаток N 1 "Список змін до картки ДН";

додаток N 2 "Список докторів наук, які вибули";

додаток N 3 "Показники науково-педагогічної діяльності доктора наук".

5. Економічному управлінню (Єрофеєва Н.В., Пишнюк М.І.) забезпечити фінансування статистичних робіт та необхідну кількість паперу для виготовлення бланків форм звітності та інструкцій по їх заповненню з питань статистики науки, інформатики та інновацій.

6. ГОЦ Мінстату України (Крамарєв В.Г.) забезпечити збір і розробку затверджених форм державної статистичної звітності.

7. Управлінню статистики науки, інформатики та інновацій (Жукович В.П.) своєчасно забезпечити орендне підприємство "Укрбланковидав" затвердженими оригіналами форм державної статистичної звітності та інструкцій щодо їх заповнення.

8. Визнати такими, що не застосовуються:

- в частині затверджених форм державної статистичної звітності та інструкцій по їх заповненню:

8.1. Наказ N 24 від 13.08.91 р. відносно форми державної статистичної звітності N НТП (будівництво);

8.2. Наказ N 88 від 08.06.92 р. відносно форми державної статистичної звітності N 5-нт (оновлення);

8.3. Наказ N 127 від 19.06.93 р. відносно форм державної статистичної звітності: N НТП (зварювання), N 5-нт (сертифікація), N 2-інф;

8.4. Наказ N 142 від 24.06.94 р. відносно форм державної статистичної звітності: N 1-наука, N 1-нк, N 4-нт, N 3-інф, додаток до форми N 3-інф;

- в частині затверджених форм державної статистичної звітності:

8.5. Наказ N 88 від 08.06.92 р. відносно форм державної статистичної звітності: N ДН, N 5-нт (ліцензії), N 2/5-нт;

8.6. Наказ N 127 від 19.06.93 р. відносно форм державної статистичної звітності: N 5-нт (зразки), N 1-інф, N 2-наука, N 5-наука, N 12-нтз;

8.7. Наказ N 242 від 09.11.93 р. відносно форми державної статистичної звітності N 6-наука;

8.8. Наказ N 142 від 24.06.94 р. відносно форм державної статистичної звітності: N 3-наука, додаток N 3 до форми N 1-КМП, N 18-нт;

8.9. Наказ N 273 від 16.12.94 р. відносно форми державної статистичної звітності N 1-інновація.

Звіт за формою N 1-наука подається всіма госпрозрахунковими і бюджетними науковими і конструкторськими організаціями, які мають самостійний баланс, а також об'єднаннями, підприємствами, вищими учбовими закладами, проектними, проектно-пошуковими, пошуковими та іншими організаціями, що займались у звітному році науково-технічною діяльністю.*

________________________ *) Далі організації

До науково-технічної належать всі види діяльності, що пов'язані з розвитком, поширенням та використанням наукових і технічних знань у всіх галузях науки і техніки, тобто в галузях природничих, технічних, суспільних та гуманітарних наук тощо.

У разі, якщо організація має підпорядковані їй філії, відділення або інші підрозділи, які діють як структурні одиниці і не мають власного балансу, дані по них включаються у звіт головної організації. Якщо такі філії, відділення та інші підрозділи мають власний баланс, вони звітують самостійно за формою N 1-наука.

Організації подають звіт не пізніше 5 лютого наступного за звітним року:

- статистичному органу за місцем знаходження;

- міністерству (відомству) за підпорядкуванням. Коди у правому верхньому куті форми організації не заповнюють.

Розділ 1

1. Науково-технічні роботи розподіляються на науково-дослідні, проектно-конструкторські і технологічні роботи, проектні роботи для будівництва, виготовлення дослідних зразків (партій) виробів (продукції), науково-технічні послуги.

2. У графах 1 і 3 показують загальний обсяг робіт з урахуванням вартості робіт, виконаних співвиконавцями, у графах 2 і 4 - у тому числі обсяг робіт, які виконані власними силами. При цьому по роботах, які фінансуються за рахунок держбюджету, у графах 1-4 враховується кошторисна вартість робіт, а по госпдоговірних темах - у графах 1 і 2 вказують договірну ціну, а у графах 3 і 4 - фактичні витрати на виконання робіт (собівартість робіт) згідно з кошторисом.

3. У рядках 01 і 02 показується повний обсяг фактично закінчених і прийнятих замовником робіт незалежно від року початку робіт з урахуванням витрат минулих років.

4. У рядках 03 і 04 наводяться дані про обсяг як закінчених, так і незавершених робіт, які виконані у звітному році згідно з державними замовленнями, замовленнями міністерств (відомств), науково-технічними програмами, укладеними госпдоговорами.

Обсяг робіт визначається як сума договорів з замовниками на проведення науково-дослідних робіт, створення, виробництво і поставку нової техніки і технології, матеріалів, тощо, а також надання науково-технічних послуг. У зазначений обсяг робіт разом з науково-технічними включають роботи (послуги), які виконані для інших підприємств, організацій і не входять до складу науково-технічних, а також платні послуги населенню.

Робота вважається виконаною, якщо виконані всі умови, викладені у договорі, і підписаний акт здачі-приймання незалежно від надходження на рахунок організації фінансових коштів від замовника.

5. У рядках 02 і 04 із загального обсягу робіт виділяється обсяг науково-технічних робіт.

6. У науково-дослідні (рядок 05) включають роботи, які направлені на одержання нових наукових знань і визначення шляхів їх практичного застосування.

7. До фундаментальних робіт належать експериментальні або теоретичні дослідження, які спрямовані на одержання нових знань без будь-якої конкретної мети, пов'язаної з використанням цих знань. Їх наслідок - гіпотези, теорії, методи і т.ін. Фундаментальні дослідження можуть закінчуватися рекомендаціями щодо постановки прикладних досліджень для визначення можливостей практичного використання одержаних наукових наслідків, науковими публікаціями і т.ін.

8. Прикладні дослідження спрямовані на одержання нових знань з метою практичного їх використання для розробки технічних нововведень. Кінцевим наслідком прикладних досліджень є рекомендації по створенню технічних нововведень. Обсяг прикладних досліджень визначається як різниця рядків 05 і 06.

9. До проектно-конструкторських і технологічних робіт (рядок 07) належать роботи, які направлені на розробку нових видів матеріалів, продуктів, процесів, пристроїв, документів, методик або їх створення у вигляді прототипів. Ці роботи можуть бути направлені на істотне удосконалення існуючих об'єктів.

До цієї групи належать такі види діяльності: розробка певної конструкції інженерного об'єкта або технічної системи (конструкторські роботи); розробка ідей та варіантів нового об'єкта, в т.ч. нетехнічного, на рівні креслення або іншої системи знакових засобів (проектні роботи); розробка технологічних процесів.

До цієї групи належать також: створення прототипів (оригінальних моделей, які мають принципові особливості нововведення, що створюється), їх випробування протягом часу, необхідного для одержання даних та накопичення досвіду, що повинно знайти відображення в технічній документації, підготовка робочих інструкцій, керівництв і т.ін. по застосуванню нововведень; інженерна діяльність, яка необхідна для удосконалення продукції або процесу до приведення їх у відповідність з функціональними та економічними вимогами і готовність до передачі у виробництво, в тому числі підготовка креслень, специфікацій, інструкцій, керівництв, які використовуються при передачі нововведень у виробничі підрозділи. Не відноситься підготовка детальних креслень ("синьок") для виробництва, передвиробниче планування, поточний контроль, інженерне обслуговування поточного виробництва. До цієї групи науково-технічних робіт не відносяться також роботи з будівельного проектування.

10. Роботи включають в обсяг виготовлення дослідних зразків (партій) виробів (продукції) (рядок 08), якщо таке виготовлення є основним змістом договору (замовлення), а виготовлені зразки або партії реалізуються споживачу.

11. До проектних робіт для будівництва (рядок 09) належать роботи по складанню схем та інших матеріалів щодо розвитку та розміщення галузей народного господарства і галузей промисловості, техніко-економічних обгрунтувань проектування і будівництва підприємств (споруд), по експериментальному проектуванню, вивченню та узагальненню вітчизняного та зарубіжного досвіду проектування та будівництва, розробці нових нормативних документів та державних стандартів по проектуванню, будівництву, архітектурі, кошторисних нормативів, схем генеральних планів промислових вузлів; по складанню схем та проектів районного планування, проектів планування та забудови міст, селищ міського типу, сільських населених пунктів, роботи по проектуванню для впровадження у виробництво прогресивних технологічних процесів.

Проектні та проектно-пошукові організації заповнюють звіт, якщо мають у своєму складі підрозділи, що виконують науково-дослідні, конструкторські роботи і проектні роботи для будівництва, які перелічені у попередньому абзаці цієї Інструкції.

Проектні і проектно-пошукові організації у звіт за формою N 1-наука не включають дані про виконання робіт по проектуванню нестандартизованого устаткування за замовленнями заводів-виготовлювачів, підготовці документації для капітального ремонту будинків і споруд; по розробці проектів і кошторисів на реконструкцію і технічне переозброєння цехів, дільниць; проектні роботи, пов'язані з прив'язкою до місця будівництва типових проектів нескладних будинків та споруд і т.ін.

12. До науково-технічних послуг (рядок 10) належить діяльність в галузі науково-технічної інформації, патентів, ліцензій, науково-технічне консультування і впроваджувальна діяльність, інші види діяльності, які сприяють одержанню, поширенню та використанню наукових знань.

Дані рядка 04 повинні дорівнювати сумі даних рядків 05, 07, 08, 09 і 10.

13. У рядках 12 і 13 приводять середньорічну вартість всіх основних засобів за звітний період. Вона визначається як частка від ділення на 12 суми, що одержана від складання половини вартості основних засобів на 1 січня звітного року, половини їх вартості на 1 січня наступного за звітним року і вартості основних засобів на 1 число всіх місяців звітного року.

Розділ II

14. Дані у рядках 15 і 16 розділу II "Надходження і використання фінансових коштів" заповнюються на підставі даних бухгалтерського обліку. У графі 1 вказують загальний обсяг коштів у звітному році з урахуванням залишків минулого року, у графі 2 - сума коштів, які надійшли у звітному році, з розподілом за джерелами фінансування у графах 3-10.

Розділ III

15. У графі 1 розділу III "Чисельність спеціалістів, що виконують НДДКР" показується:

- для самостійних науково-дослідних, проектно-конструкторських і технологічних організацій, для проектних організацій будівництва, для комплексних організацій, які мають у своєму складі будь-які частини вищеперелічених категорій наукових організацій, організацій наукового обслуговування - чисельність працівників основної діяльності;

- для підприємств (об'єднань) - чисельність персоналу структурних одиниць, які виконують науково-технічні роботи;

- для вищих учбових закладів - чисельність їх науково-дослідних підрозділів (НДС, НДЧ, НДЛ);

- для інших організацій - чисельність структурних підрозділів, які виконують науково-технічні роботи.

16. У графі 2 приводять дані про чисельність спеціалістів, включаючи аспірантів, які безпосередньо беруть участь у виконанні робіт, що враховані у рядку 04 цієї форми, а також керівників наукових організацій та підрозділів, що виконують науково-технічні роботи.

У графі 2 не враховуються керівники та спеціалісти планово-економічних, фінансових підрозділів, підрозділів матеріально-технічного забезпечення тощо, які безпосередньо не брали участь у виконанні науково-технічних робіт.

17. У графах 3 і 4 чисельність спеціалістів, що наведені у графі 2, розподіляється на групи в залежності від освіти: у графі 3 - із закінченою вищою освітою, у графі 4 - із закінченою середньою спеціальною освітою і незакінченою вищою освітою.

Дані у графі 2 повинні дорівнювати сумі даних у графах 3 і 4.

18. У графі 6 вказують чисельність спеціалістів, які виконують науково-технічні роботи за сумісництвом: науково-педагогічні працівники вузів, які поряд з педагогічною займаються науковою діяльністю, працівники котрі працюють за сумісництвом на 0,5 (0,25) ставки.

19. У графі 7 розраховується чисельність спеціалістів, вказаних у графі 6, в еквіваленті повної зайнятості. Еквівалент повного робочого дня (ЕПРД) - це одиниця, яка відповідає одній особі, зайнятій виконанням науково-технічних робіт повний робочий день. Так, наприклад, якщо з 3 наукових працівників два працюють на 0,25 ставки, а один - на 0,5 ставки, то еквівалент повного робочого дня цих працівників буде: 0,25 + 0,25 + 0,5 = 1 науковому працівнику.

20. У рядках 25-28 загальна чисельність працівників розподіляється за категоріями персоналу. До категорії дослідників (рядок 25) відносяться працівники, які професійно займаються виконанням наукових досліджень і розробок, а також здійснюють безпосереднє керівництво науково-технічним процесом. Дослідники, як правило, мають закінчену вищу освіту. До категорії техніків (рядок 26) відносяться працівники, які беруть участь у виконанні наукових досліджень і розробок, виконуючи технічні функції, як правило, під керівництвом дослідників (експлуатацію та обслуговування наукового та лабораторного обладнання, обчислювальної техніки, підготовку матеріалів, креслень, проведення експериментів, дослідів, аналізів, тощо). Допоміжний персонал (рядок 27) - це працівники, які виконують допоміжні функції, пов'язані з проведенням досліджень і розробок: працівники планово-економічних, фінансових підрозділів, патентних служб, підрозділів науково-технічної інформації, науково-технічних бібліотек, робітники, які здійснюють монтаж, наладку, обслуговування наукового устаткування та приладів, робітники дослідних (експериментальних) виробництв, лаборанти, які не мають вищої та середньої спеціальної освіти. Всі інші працівники, які здійснюють господарське обслуговування та виконують функції загального характеру, пов'язані з діяльністю організаціі в цілому, враховуються у рядку 28. Це - працівники бухгалтерії, кадрової служби, канцелярії, підрозділів матеріально-технічного постачання, друкарки, тощо.

21. У графі 1 у рядку 24 вказують про середньоспискову чисельність працівників, які безпосередньо зайняті виконанням науково-технічних робіт; у графі 2 - розмір фонду споживання в цілому по організації, у графі 3 - суму коштів, направлених на оплату праці спеціалістів, які безпосередньо виконують наукові дослідження і розробки.

Розділ IV

22. У розділі IV проводиться розподіл спеціалістів з вищою освітою, які виконують НДДКР, за галузями наук і спеціальностями. При цьому слід мати на увазі, що дані граф 1, 4, 7 у рядку 01 повинні дорівнювати відповідним даним графи 3 по рядках 21, 22, 23 розділу II звіту. При цьому вищі учбові заклади у графах 1, 4, 7 у рядку 01 розділу IV показують чисельність спеціалістів з урахуванням науково-педагогічних працівників-сумісників.
