КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 травня 2004 р. N 322-р Київ { Розпорядження втратило чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про співголову Експертно-консультаційної комісії з питань державного регулювання виробництва і обігу спирту, алкогольних напоїв та тютюнових виробів

Затвердити заступника Голови Державної податкової адміністрації Мокрієва Володимира Миколайовича співголовою Експертно-консультаційної комісії з питань державного регулювання виробництва і обігу спирту, алкогольних напоїв та тютюнових виробів ( 1206-2002-п ), увільнивши від цих обов'язків Шитрю Олексія Івановича.
