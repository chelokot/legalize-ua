Кабінет Міністрів України; Розпорядження від 23.12.1994 № 933-р

Про віднесення посад керівних працівників і спеціалістів Національного інституту стратегічних досліджень до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 933-94-р

Текст документа від 25.02.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 1994 р. N 933-р Київ

( Із змінами, внесеними згідно з Розпорядженнями КМ N 471-р ( 471-99-р ) від 25.05.99 N 117-р ( 117-2003-р ) від 25.02.2003 )

На виконання Указу Президента України від 10 жовтня 1994 р. N 585 ( 585/94 ) "Про Національний інститут стратегічних досліджень" та відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади директора Національного інституту стратегічних досліджень, його перших заступників, заступників, посаду вченого секретаря Національного інституту стратегічних досліджень та керівників відділів до другої категорії посад державних службовців.

( На часткову зміну абзацу першого віднести посаду директора Національного інституту стратегічних досліджень до першої категорії посад державних службовців згідно з Розпорядженням КМ N 117-р ( 117-2003-р ) від 25.02.2003 )

Посади інших керівних працівників і спеціалістів зазначеного інституту за категоріями прирівнюються до відповідних категорій посад державних службовців Адміністрації Президента України.

( Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 471-р ( 471-99-р ) від 25.05.99 )

Прем'єр-міністр України В.МАСОЛ
