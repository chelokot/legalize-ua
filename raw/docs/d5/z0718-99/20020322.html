МЗЕЗторг України; Наказ, Положення від 05.10.1999 № 754

Про затвердження Положення про порядок застосування до суб'єктів зовнішньоекономічної діяльності України та іноземних суб'єктів господарської діяльності спеціальних санкцій, передбачених статтею 37 Закону України "Про зовнішньоекономічну діяльність"

Реєстрація: Мін'юст України від 21.10.1999 № 718/4011

Стан: Втратив чинність

Ідентифікатор: z0718-99

Текст документа від 22.03.2002:

МІНІСТЕРСТВО ЗОВНІШНІХ ЕКОНОМІЧНИХ ЗВ'ЯЗКІВ І ТОРГІВЛІ УКРАЇНИ

НАКАЗ

N 754 від 05.10.99 Зареєстровано в Міністерстві м.Київ юстиції України 21 жовтня 1999 р. vd991005 vn754 за N 718/4011

( Наказ втратив чинність на підставі Наказу Мінекономіки, європ. інтеграції

N 70 ( z0286-02 ) від 11.03.2002 )

Про затвердження Положення про порядок застосування до суб'єктів зовнішньоекономічної діяльності України та іноземних суб'єктів господарської діяльності спеціальних санкцій, передбачених статтею 37 Закону України "Про зовнішньоекономічну діяльність"

( Із змінами, внесеними згідно з Наказом Мінекономіки N 52 ( z0260-00 ) від 17.04.2000 )

У зв'язку з прийняттям Закону України від 22.12.98 N 335-XIV ( 335-14 ) "Про внесення змін до Закону Української РСР "Про зовнішньоекономічну діяльність", з метою вдосконалення процедури застосування та скасування спеціальних санкцій, передбачених статтею 37 Закону України "Про зовнішньоекономічну діяльність" ( 959-12 ), НАКАЗУЮ:

1. Затвердити Положення про порядок застосування до суб'єктів зовнішньоекономічної діяльності України та іноземних суб'єктів господарської діяльності спеціальних санкцій, передбачених статтею 37 Закону України "Про зовнішньоекономічну діяльність", що додається.

2. Визнати такими, що втратили чинність, накази МЗЕЗторгу України від 05.06.95 N 103 ( z0192-95 ) "Про затвердження Положення про порядок застосування до суб'єктів зовнішньоекономічної діяльності спеціальних санкцій - тимчасового зупинення ЗЕД та застосування індивідуального режиму ліцензування за порушення діючого законодавства України у сфері зовнішньоекономічних відносин та валютного регулювання" (із змінами та доповненнями, внесеними наказами МЗЕЗторгу від 23.06.96 N 348-а ( z0343-96 ), від 23.07.96 N 410 ( z0381-96 ), від 31.03.97 N 197 ( z0150-97 ), від 28.04.98 ( z0274-98 ) N 248), від 27.07.96 N 467 ( z0412-96 ) "Про особливості укладання деяких видів угод суб'єктами зовнішньоекономічної діяльності у зв'язку із застосуванням спеціальних санкцій, передбачених статтею 37 Закону України "Про зовнішньоекономічну діяльність" та від 29.12.98 N 853 ( z0013-99 ) "Про посилення контролю за зовнішньоекономічною діяльністю суб'єктів підприємництва, що порушили терміни розрахунків за експортно-імпортними операціями, встановлені Законом України "Про порядок здійснення розрахунків в іноземній валюті".

3. Управлінню правового забезпечення (Сервинський А.Ю.) забезпечити реєстрацію цього наказу в Міністерстві юстиції України в установлений законодавством термін.

4. Управлінню справами (Дробний В.В.) забезпечити публікацію цього наказу в газеті "Урядовий кур'єр" після державної реєстрації в Міністерстві юстиції України та довести цей наказ до відома Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських державних адміністрацій.

5. Контроль за виконанням цього наказу покласти на заступника Міністра Олійника В.І.

Міністр А.І.Гончарук
