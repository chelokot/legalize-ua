Кабінет Міністрів України; Розпорядження від 07.12.2011 № 1230-р

Про віднесення посад працівників Державної судової адміністрації до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 1230-2011-р

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 грудня 2011 р. N 1230-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Про віднесення посад працівників Державної судової адміністрації до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 506-р ( 506-2014-р ) від 27.05.2014 N 430-р ( 430-2015-р ) від 29.04.2015 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Державної судової адміністрації до таких категорій посад державних службовців:

перша - Голова Державної судової адміністрації, перший заступник Голови;

друга - заступник Голови Державної судової адміністрації;

третя - начальник управління, начальник самостійного відділу Державної судової адміністрації;

четверта - радник, помічник Голови Державної судової адміністрації, заступник начальника управління, заступник начальника управління - начальник відділу, заступник начальника самостійного відділу, начальник відділу у складі управління, заступник начальника відділу у складі управління, завідувач самостійного сектору Державної судової адміністрації, начальник територіального управління Державної судової адміністрації; { Абзац п'ятий із змінами, внесеними згідно з Розпорядженнями КМ N 506-р ( 506-2014-р ) від 27.05.2014, N 430-р ( 430-2015-р ) від 29.04.2015 }

п'ята - завідувач сектору у складі управління, головний спеціаліст, провідний спеціаліст, спеціаліст, спеціаліст 1 категорії, спеціаліст 2 категорії Державної судової адміністрації, перший заступник, заступник начальника, начальник відділу, завідувач сектору, головний спеціаліст територіального управління Державної судової адміністрації;

шоста - провідний спеціаліст, спеціаліст, спеціаліст 1 категорії, спеціаліст 2 категорії територіального управління Державної судової адміністрації.
