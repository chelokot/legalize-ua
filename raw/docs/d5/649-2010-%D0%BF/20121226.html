Кабінет Міністрів України; Постанова від 28.07.2010 № 649

Про внесення змін до Порядку проведення органами державної контрольно-ревізійної служби державного фінансового аудиту окремих господарських операцій

Стан: Втратив чинність

Ідентифікатор: 649-2010-п

Текст документа від 26.12.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 липня 2010 р. N 649 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1182 ( 1182-2012-п ) від 19.12.2012 }

Про внесення змін до Порядку проведення органами державної контрольно-ревізійної служби державного фінансового аудиту окремих господарських операцій

Кабінет Міністрів України постановляє:

Внести до Порядку проведення органами державної контрольно-ревізійної служби державного фінансового аудиту окремих господарських операцій, затвердженого постановою Кабінету Міністрів України від 20 травня 2009 р. N 506 ( 506-2009-п ) (Офіційний вісник України, 2009 р., N 39, ст. 1307), такі зміни:

абзац другий пункту 3 виключити;

доповнити Порядок ( 506-2009-п ) пунктом 9-1 такого змісту:

"9-1. У разі встановлення факту порушення законодавства під час проведення операційного аудиту державний аудитор невідкладно інформує про це керівника органу служби.

За результатами розгляду поданої державним аудитором інформації орган служби надсилає керівнику суб'єкта господарювання та/або його органу управління письмові вимоги щодо усунення виявлених фактів порушення законодавства із зазначенням строку зворотного інформування про вжиті заходи щодо їх усунення.

Для підтвердження виявлених в ході операційного аудиту фактів порушення законодавства та належного їх документування орган служби забезпечує проведення ревізії відповідно до Порядку проведення інспектування державною контрольно-ревізійною службою, затвердженого постановою Кабінету Міністрів України від 20 квітня 2006 р. N 550 ( 550-2006-п ) (Офіційний вісник України, 2006 р., N 16, ст. 1206, N 46, ст. 3085; 2008 р., N 80, ст. 2689).".
