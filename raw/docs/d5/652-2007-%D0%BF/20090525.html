Про створення веб-порталу з питань державних закупівель

Стан: Чинний

Ідентифікатор: 652-2007-п

Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 квітня 2007 р. N 652 Київ

Про створення веб-порталу з питань державних закупівель

{ Із змінами, внесеними згідно з Постановою КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє:

1. Антимонопольному комітетові:

створити веб-портал з питань державних закупівель (далі - веб-портал) та забезпечити його функціонування;

разом з Міністерством фінансів і Державною службою спеціального зв'язку та захисту інформації забезпечити оприлюднення на веб-порталі документів та інформації про державні закупівлі з урахуванням положень Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

{ Пункт 2 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

3. Міністерству фінансів під час внесення змін до Закону України "Про Державний бюджет України на 2007 рік" ( 489-16 ) передбачити Антимонопольному комітетові видатки із створення та функціонування веб-порталу.

Прем'єр-міністр України В.ЯНУКОВИЧ
