Текст документа від 26.12.2005:

ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

ПОСТАНОВА

26.12.2005 N 267

Про форми посвідчень суб'єктів та інших учасників виборчого процесу з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів 26 березня 2006 року

Відповідно до частини одинадцятої статті 39, частини сьомої статті 40, частини сьомої статті 41, частин п'ятої та восьмої статті 57, частини четвертої статті 59, частини шостої статті 61 Закону України "Про вибори депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів" ( 1667-15 ), керуючись статтями 12, 13, пунктом 7 статті 21 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Встановити форми:

посвідчення кандидата у депутати в багатомандатному виборчому окрузі (додаток 1) ( va267359-05 );

посвідчення кандидата у депутати в одномандатному виборчому окрузі (додаток 2) ( va267359-05 );

посвідчення кандидата на посаду сільського, селищного, міського голови (додаток 3) ( va267359-05 );

посвідчення представника місцевої організації політичної партії (виборчого блоку місцевих організацій політичних партій) в територіальній виборчій комісії з правом дорадчого голосу (додаток 4) ( va267359-05 );

посвідчення уповноваженої особи місцевої організації політичної партії (виборчого блоку місцевих організацій політичних партій), кандидати у депутати від якої зареєстровані в багатомандатному виборчому окрузі (додаток 5) ( va267359-05 );

посвідчення довіреної особи кандидата на посаду сільського, селищного, міського голови (додаток 6) ( va267359-05 );

посвідчення довіреної особи кандидата у депутати в одномандатному виборчому окрузі (додаток 7) ( va267359-05 );

посвідчення офіційного спостерігача від місцевої організації політичної партії (виборчого блоку місцевих організацій політичних партій), кандидати у депутати від якої зареєстровані в багатомандатному виборчому окрузі (додаток 8) ( va267359-05 );

посвідчення офіційного спостерігача від кандидата на посаду сільського, селищного, міського голови (додаток 9) ( va267359-05 );

посвідчення офіційного спостерігача від кандидата у депутати в одномандатному виборчому окрузі (додаток 10) ( va267359-05 ).

2. Цю постанову надіслати Верховній Раді Автономної Республіки Крим, обласним, Київській та Севастопольській міським радам.
