Кабінет Міністрів України; Розпорядження від 05.10.2000 № 395-р

Про забезпечення діяльності Координаційної ради з питань розвитку Українського козацтва

Стан: Втратив чинність

Ідентифікатор: 395-2000-р

Текст документа від 25.12.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 жовтня 2000 р. N 395-р Київ

Про забезпечення діяльності Координаційної ради з питань розвитку Українського козацтва

( Із змінами, внесеними згідно з Розпорядженням КМ N 715-р ( 715-2002-р ) від 25.12.2002 )

Взяти до відома, що організаційно-технічне забезпечення діяльності Координаційної ради з питань розвитку Українського козацтва здійснюватиме Товариство сприяння обороні України.

( Абзац другий виключено на підставі Розпорядження КМ N 715-р ( 715-2002-р ) від 25.12.2002 )

Державному комітету інформаційної політики, телебачення та радіомовлення забезпечувати висвітлення діяльності Координаційної ради з питань розвитку Українського козацтва у засобах масової інформації.

Прем'єр-міністр України В.ЮЩЕНКО
