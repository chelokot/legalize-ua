МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

18.08.2005 N 475

Зареєстровано в Міністерстві юстиції України 2 вересня 2005 р. за N 979/11259

Про внесення змін до наказу Міністерства транспорту та зв'язку України від 27.05.2005 N 266

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства транспорту та зв'язку N 266 ( z0607-05 ) від 27.05.2005, до якого вносились зміни }

Відповідно до пункту 2 постанови Кабінету Міністрів України від 12.10.2000 N 1544 ( 1544-2000-п ) "Про портові збори" НАКАЗУЮ:

1. Абзаци другий та третій пункту 1 наказу Міністерства транспорту та зв'язку України від 27.05.2005 N 266 ( z0607-05 ) "Про порядок застосування знижок до портових зборів та зборів і плат за послуги, що надаються суднам закордонного плавання", зареєстрованого в Міністерстві юстиції України 02.06.2005 за N 607/10887, після слів "портових зборів" доповнити словами "(крім адміністративного)".

2. Департаменту нормативно-правового забезпечення (Ониськів М.М.) в установленому порядку подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3. Директору Державного департаменту морського і річкового транспорту (Горобець І.А.) довести цей наказ до відома зацікавлених підприємств.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Рябікіна П.Б.

Міністр Є.А.Червоненко
