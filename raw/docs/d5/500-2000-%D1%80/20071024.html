{ Розпорядження втратило чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про затвердження голови Міжвідомчої комісії з реалізації реформи житлово-комунального господарства

Затвердити головою Міжвідомчої комісії з реалізації реформи житлово-комунального господарства, утвореної відповідно до постанови Кабінету Міністрів України від 1 грудня 1999 р. N 2194 ( 2194-99-п ) (Офіційний вісник України, 1999 р., N 48, ст. 2374; 2000 р., N 19, ст. 784), Першого віце-прем'єр-міністра України Єханурова Юрія Івановича, увільнивши від виконання цих обов'язків Тігіпка Сергія Леонідовича.

Прем'єр-міністр України В.ЮЩЕНКО
