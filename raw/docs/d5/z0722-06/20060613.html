МІНІСТЕРСТВО УКРАЇНИ У СПРАВАХ СІМ'Ї, МОЛОДІ ТА СПОРТУ

НАКАЗ

13.06.2006 N 1961

Зареєстровано в Міністерстві юстиції України 20 червня 2006 р. за N 722/12596

Про внесення змін до наказу Мінмолодьспорту від 28.04.2005 N 76

Відповідно до постанов Кабінету Міністрів України від 19 квітня 2006 року N 523 ( 523-2006-п ) "Про звільнення Бринзака В.М. з посади заступника Міністра України у справах сім'ї, молоді та спорту", від 11 травня 2006 року N 644 ( 644-2006-п ) "Про призначення Дутчака М.В. заступником Міністра України у справах сім'ї, молоді та спорту" НАКАЗУЮ:

1. Унести до наказу Міністерства України у справах молоді та спорту від 28.04.2005 N 76 ( z0602-05 ) "Про порядок визнання в Україні видів спорту", зареєстрованого в Міністерстві юстиції України 01.06.2005 за N 602/10882 (далі - Наказ), такі зміни:

1.1. Абзац другий пункту 2 Наказу викласти у редакції:

"Призначити головою Комісії Дутчака Мирослава Васильовича - заступника Міністра".

1.2. У додатку "Склад Комісії з визнання в Україні видів спорту" до Наказу прізвище "Бринза Володимир Михайлович" замінити прізвищем "Дутчак Мирослав Васильович".

2. Департаменту фізичної культури забезпечити державну реєстрацію цього наказу відповідно до Указу Президента України від 3 жовтня 1992 року N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (зі змінами).

3. Контроль за виконанням цього наказу залишаю за собою.

Міністр Юрій Павленко
