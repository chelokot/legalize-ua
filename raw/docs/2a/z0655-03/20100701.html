ЗАТВЕРДЖЕНО Рішення Державної комісії з цінних паперів та фондового ринку 24.06.2003 N 290

Зареєстровано в Міністерстві юстиції України 29 липня 2003 р. за N 655/7976

ПОЛОЖЕННЯ про складання адміністративних даних щодо здійснення діяльності з ведення реєстрів власників іменних цінних паперів та подання відповідних документів до Державної комісії з цінних паперів та фондового ринку

Це Положення розроблено відповідно до Законів України "Про інформацію" ( 2657-12 ), "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ), "Про Національну депозитарну систему та особливості електронного обігу цінних паперів в Україні" ( 710/97-ВР ) та з урахуванням повноважень Державної комісії з цінних паперів та фондового ринку (далі - Комісія) як суб'єкта державного фінансового моніторингу, визначених Законом України "Про запобігання та протидію легалізації (відмиванню) доходів, одержаних злочинним шляхом" ( 249-15 ). { Абзац перший преамбули в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 1186 ( z0737-07 ) від 12.06.2007 }

Дія цього Положення поширюється на професійних учасників, які на підставі ліцензії, виданої Державною комісією з цінних паперів та фондового ринку, мають право на провадження професійної діяльності на фондовому ринку - депозитарної діяльності, а саме діяльності з ведення реєстру власників іменних цінних паперів (далі - Реєстратори), а також емітентів, які на підставі ліцензії, виданої Державною комісією з цінних паперів та фондового ринку, мають право на провадження професійної діяльності на фондовому ринку - депозитарної діяльності, а саме діяльності з ведення власного реєстру власників іменних цінних паперів (далі - Емітенти). { Преамбулу доповнено абзацом згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

Це Положення визначає порядок складання адміністративних даних (далі - Інформація) щодо здійснення діяльності з ведення реєстрів власників іменних цінних паперів Реєстраторами та Емітентами, терміни та порядок подання відповідних документів до Комісії. { Абзац преамбули в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

1. Визначення термінів

1.1. Терміни "випуск цінних паперів", "номінальний утримувач", "реєстр власників іменних цінних паперів", "Реєстратор" уживаються у цьому Положенні згідно з визначеннями, що наведені в Законі України "Про Національну депозитарну систему та особливості електронного обігу цінних паперів в Україні" ( 710/97-ВР ).

1.2. Терміни "власник пакета акцій", "номінальний утримувач пакета акцій", "нерегулярна Інформація", "дата виникнення нерегулярної Інформації", "прийнята Інформація" уживаються виключно для потреб цього Положення.

{ Пункт 1.2 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

1.3. Власник пакета акцій - юридична або фізична особа (резидент або нерезидент), на особовому рахунку в цінних паперах якого в Реєстратора (Емітента) обліковуються акції певного емітента в кількості, що становить 10 і більше відсотків статутного капіталу емітента.

Номінальний утримувач пакета акцій - депозитарій або зберігач цінних паперів, зареєстрований у реєстрі власників іменних цінних паперів як юридична особа, на рахунку якої обліковується інформація про акції певного емітента в кількості, що становить 10 і більше відсотків статутного капіталу емітента. { Пункт 1.3 доповнено абзацом згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

Нерегулярна Інформація - інформація про зміни на особовому рахунку власника пакета акцій та/або номінального утримувача пакета акцій. { Пункт 1.3 доповнено абзацом згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

{ Пункт 1.3 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

1.4. Дата виникнення нерегулярної Інформації - дата виникнення змін на особовому рахунку власника пакета акцій та/або номінального утримувача пакета акцій у Реєстратора (Емітента).

{ Пункт 1.4 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

1.5. Документ - матеріальна форма одержання, зберігання, використання і поширення Інформації, зафіксованої на папері, магнітному диску, оптичному диску або іншому носієві.

{ Пункт 1.6 виключено на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

1.6. Прийнята Інформація - Інформація, яка подана (надіслана) до Комісії в електронній та паперовій формах в терміни та в обсязі, що встановлені цим Положенням. Інформація з паперової форми документа за складом даних відповідає електронній формі та містить усі визначені цим Положенням реквізити.

{ Пункт 1.6 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

2. Порядок складання Інформації

2.1. Інформація складається у вигляді документів, передбачених цим Положенням, у електронній та паперовій формах. Документи в електронній формі складаються шляхом заповнення українською мовою таблиць та форм, передбачених цим Положенням, за допомогою програмних засобів, які забезпечують формування файлів у форматі, визначеному Комісією.

2.2. За термінами складання Інформація поділяється на:

щоквартальну Інформацію;

нерегулярну Інформацію.

{ Пункт 2.2 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

2.3. Щоквартальна Інформація Реєстратора складається за станом на останній день кварталу. Щокварталу Реєстратор складає такі документи:

- дані про Реєстратора (додаток 1);

- дані про підпорядковані Реєстратору відокремлені підрозділи, які здійснюють ведення реєстру (додаток 2);

- дані про укладені з емітентами договори про ведення реєстрів власників іменних цінних паперів (додаток 3);

- баланси випусків іменних цінних паперів (додаток 4).

2.4. Щоквартальна Інформація Емітента складається за станом на останній день кварталу. Щокварталу Емітент складає такі документи:

- дані про Емітента (додаток 1, форма "Перелік випусків цінних паперів емітента"- додаток 3);

- баланси випусків іменних цінних паперів (додаток 4).

{ Пункт 2.5 виключено на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

2.5. Нерегулярна Інформація складається за фактом її виникнення у таких випадках:

зміни на особовому рахунку (відкриття або закриття) власника пакета акцій та/або номінального утримувача пакета акцій, унаслідок яких пакет акцій становить 10 і більше відсотків статутного капіталу емітента або став меншим ніж 10 відсотків статутного капіталу емітента;

зміни на особовому рахунку (збільшення або зменшення) власника пакета акцій та/або номінального утримувача пакета акцій, унаслідок яких пакет акцій збільшився в обсязі від 10 до 100 відсотків статутного капіталу емітента або зменшився в обсязі від 100 до 10 відсотків статутного капіталу емітента;

передача системи реєстру власників іменних цінних паперів;

прийняття (отримання або формування) системи реєстру власників іменних цінних паперів;

проведення корпоративної операції, внаслідок якої відбулися зміни на особовому рахунку власника пакета акцій та/або номінального утримувача пакета акцій (пов'язаних з анулюванням, змінами номінальної вартості іменних цінних паперів, а також інших операцій емітента, які пов'язані зі зміною умов випуску іменних цінних паперів).

2.5.1. Якщо на особовому рахунку в цінних паперах кілька змін відбувалось протягом одного операційного дня, нерегулярна Інформація складається станом на час закриття операційного дня.

2.5.2. У разі набуття державою прав власності на пакет акцій відповідно до законодавства (за рішенням суду тощо) Реєстратор (Емітент) протягом трьох робочих днів з дати внесення відповідних змін на особовому рахунку зобов'язаний повідомити про це Комісію. { Пункт 2.5 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

3. Порядок подання документів

3.1. Реєстратори подають документи, передбачені цим Положенням, до центрального апарату Комісії, Емітенти - до територіальних управлінь Комісії за їх місцезнаходженням. Документи подаються в електронній та паперовій формах. Інформація повинна містити всі визначені цим Положенням форми документів, усі форми документів мають бути заповнені, містити достовірну та повну інформацію

3.2. Документи, які містять щоквартальну Інформацію, подаються до 15-го числа місяця, наступного за звітним кварталом, включно.

3.3. Документи, які містять нерегулярну Інформацію, подаються протягом трьох робочих днів після виникнення змін, які передбачені цим Положенням.

3.4. У тому разі, коли останній день подання документів є неробочим, термін подання подовжується до першого, після неробочого, робочого дня, включно.

{ Пункт 3.5 виключено на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

{ Пункт 3.6 виключено на підставі Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

3.5. Усі документи в паперовій формі, подання яких передбачено цим Положенням, зшиваються, сторінки нумеруються, засвідчуються підписом керівника та печаткою Реєстратора (Емітента).

3.6. Електронна форма документів, які містять нерегулярну Інформацію, на дату виникнення подається (надсилається) електронною поштою на адресу, визначену наказом Голови Комісії. Після прийняття Інформації Комісія надсилає відправнику електронною поштою реєстраційний номер, за яким документ, яким надано Інформацію, прийнятий Комісією, із зазначенням дати його прийняття. У разі відсутності такого номера Інформація вважається неприйнятою.

{ Пункт 3.6 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 380 ( z0317-10 ) від 07.04.2010 }

3.7. Реєстратори та відокремлені підрозділи Реєстраторів, які мають право консолідації реєстрів, подають документи, які містять нерегулярну Інформацію, до центрального апарату Комісії, Емітенти - до територіальних управлінь Комісії за місцезнаходженням.

3.8. Паперова форма щоквартальних документів (додатки 1-4) за складом даних має відповідати електронній формі таких документів.
