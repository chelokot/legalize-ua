Про затвердження складу ради Всеукраїнського конкурсу проектів та програм розвитку місцевого самоврядування

Стан: Чинний

Ідентифікатор: 1290-2011-п

Текст документа від 24.03.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 грудня 2011 р. N 1290 Київ

Про затвердження складу ради Всеукраїнського конкурсу проектів та програм розвитку місцевого самоврядування

{ Із змінами, внесеними згідно з Постановами КМ N 230 ( 230-2012-п ) від 12.03.2012 N 353 ( 353-2013-п ) від 22.05.2013 N 477 ( 477-2014-п ) від 27.08.2014 N 92 ( 92-2015-п ) від 11.03.2015 }

Кабінет Міністрів України постановляє:

1. Затвердити склад ради Всеукраїнського конкурсу проектів та програм розвитку місцевого самоврядування згідно з додатком.

2. Абзац другий пункту 7 Положення про Всеукраїнський конкурс проектів та програм розвитку місцевого самоврядування, затвердженого постановою Кабінету Міністрів України від 18 січня 2003 р. N 64 ( 64-2003-п ) (Офіційний вісник України, 2003 р., N 4, ст. 123, N 51, ст. 2672; 2004 р., N 28, ст. 1883; 2005 р., N 16, ст. 843; 2010 р., N 75, ст. 2665), викласти в такій редакції:

"Головою ради Конкурсу є Перший віце-прем'єр-міністр України - Міністр економічного розвитку і торгівлі.".

3. Визнати таким, що втратив чинність, пункт 2 постанови Кабінету Міністрів України від 15 вересня 2010 р. N 899 ( 899-2010-п ) "Про внесення змін до постанови Кабінету Міністрів України від 18 січня 2003 р. N 64" (Офіційний вісник України, 2010 р., N 75, ст. 2665).
