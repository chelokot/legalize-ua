Текст документа від 16.09.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 вересня 2009 р. N 1150 Київ

Про внесення зміни до пункту 3 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

Кабінет Міністрів України постановляє:

1. Пункт 3 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів, затверджених постановою Кабінету Міністрів України від 22 жовтня 2008 р. N 943 ( 943-2008-п ) "Про економію бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів" (Офіційний вісник України, 2008 р., N 84, ст. 2816; 2009 р., N 45, ст. 1507), після слів "органів виконавчої влади" доповнити словами "(крім органів державної виконавчої служби)".

2. Міністерству юстиції забезпечити фінансування закупівлі форменого одягу для державних виконавців за рахунок перевищення надходжень виконавчого збору, стягнутого органами державної виконавчої служби, до спеціального фонду державного бюджету порівняно з плановими показниками, врахованими у бюджеті на відповідний рік.

Прем'єр-міністр України Ю.ТИМОШЕНКО
