КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 березня 2008 р. N 526-р Київ

Про затвердження граничної чисельності військовослужбовців та працівників Генерального штабу Збройних Сил

{ Щодо граничної чисельності див. Розпорядженням КМ N 207-р ( 207-2009-р ) від 25.02.2009 }

Затвердити граничну чисельність Генерального штабу Збройних Сил на 2008 рік у кількості 566 військовослужбовців та 134 працівники.
