Про тарифи на електричну енергію, що відпускається енергопостачальними компаніями Міненерго України

{ Додатково див. Постанову Національної комісії регулювання електроенергетики N 658 ( v0658227-98 ) від 22.05.98 }

Згідно з Законом України "Про електроенергетику" ( 575/97-ВР ), Указом Президента України від 14 березня 1995 р. N 213 ( 213/95 ) "Про заходи щодо забезпечення діяльності Національної комісії з питань регулювання електроенергетики" та постановою Кабінету Міністрів України від 28 листопада 1997 року N 1323 ( 1323-97-п ) "Про фінансове забезпечення будівництва енергоблоків N 2 Хмельницької та N 4 Рівненської АЕС" Національна комісія з питань регулювання електроенергетики України (НКРЕ) ПОСТАНОВЛЯЄ:

1. Затвердити тарифи на електричну енергію, що відпускається енергопостачальними компаніями Міненерго України (додаються).

2. Встановити, що ця постанова набуває чинності з 1 січня 1998 року.

3. Визнати такою, що втратила чинність, постанову НКРЕ від 04.03.97 р. N 140 ( z0078-97 ) "Про тарифи на електричну енергію для сільськогосподарських споживачів-виробників".

Примітки: 1. Тарифи на електричну енергію, яка відпускається на потреби опалення та гарячого водопостачання: 2,4 цента США за 1 кВт.год - в години нічного мінімуму електричних навантажень; 10,0 центів США за 1 кВт.год - в інші години доби. 2. Розрахунки за електричну енергію здійснюються підприємствами України в гривнях, виходячи з тарифів за електричну енергію, встановлених в доларах США і перерахованих за курсом Національного банку України на обумовлений договором день розрахунків за використану електричну енергію і потужність.
