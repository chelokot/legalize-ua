ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

10.12.2003 N 556

Зареєстровано в Міністерстві юстиції України 13 січня 2004 р. за N 29/8628

{ Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку

N 433 ( z0807-06 ) від 23.06.2006 }

Про затвердження Змін та доповнень до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів

( Із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 64 ( z0560-04 ) від 04.03.2004 )

У зв'язку з прийняттям Законів України "Про недержавне пенсійне забезпечення" ( 1057-15 ) та "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ), Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Зміни та доповнення до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів, затверджених наказом Державного комітету України з питань регуляторної політики та підприємництва від 14.03.2001 N 49 ( za318-01 ) та рішенням Державної комісії з цінних паперів та фондового ринку від 14.03.2001 N 60 ( z0318-01 ), зареєстрованих у Міністерстві юстиції України 06.04.2001 за N 318/5509 (зі змінами та доповненнями), що додаються ( z0029-04 ).

2. Умова щодо сплати статутного фонду (капіталу) на день державної реєстрації для юридичних осіб, які мають намір отримати ліцензію на здійснення професійної діяльності на ринку цінних паперів - діяльності з управління активами інститутів спільного інвестування, поширюється лише на юридичних осіб, які зареєстровані в установленому законодавством порядку після набрання чинності цим рішенням. ( Рішення доповнено пунктом 2 згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 64 ( z0560-04 ) від 04.03.2004 )

3. Виконавчому секретарю М.Каскевичу забезпечити:

надання зазначених Змін та доповнень до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів на затвердження до Державного комітету України з питань регуляторної політики та підприємництва;

реєстрацію цього рішення в Міністерстві юстиції України;

опублікування цього рішення відповідно до чинного законодавства України.

4. Рішення набирає чинності відповідно до чинного законодавства України.

5. Контроль за виконанням цього рішення покласти на Виконавчого секретаря М.Каскевича.

Т.в.о. Голови Комісії С.Бірюк
