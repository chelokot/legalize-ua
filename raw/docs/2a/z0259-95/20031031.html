Фонд державного майна; Наказ від 21.07.1995 № 952

Про внесення доповнень до Порядку заповнення приватизаційного майнового сертифіката при продажу акцій відкритих акціонерних товариств, затвердженого наказом Фонду державного майна України від 29.03.95 N 343

Реєстрація: Мін'юст України від 27.07.1995 № 259/795

Стан: Втратив чинність

Ідентифікатор: z0259-95

Текст документа від 31.10.2003:

ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

N 952 від 21.07.95 Зареєстровано в Міністерстві м.Київ юстиції України 27 липня 1995 р. vd950721 vn952 за N 259/795

( Наказ втратив чинність на підставі Наказу Фонду державного майна N 1593 ( z1000-03 ) від 10.09.2003 )

Про внесення доповнень до Порядку заповнення приватизаційного майнового сертифіката при продажу акцій відкритих акціонерних товариств, затвердженого наказом Фонду державного майна України від 29.03.95 N 343

З метою упорядкування діяльності органів приватизації при продажу державного майна іншими способами приватизації, НАКАЗУЮ:

1. Внести доповнення до Порядку заповнення приватизаційного майнового сертифіката при продажу акцій відкритих акціонерних товариств, затвердженого наказом Фонду державного майна України від 29.03.95 N 343 ( z0104-95 ), додається.

2. Департаменту малої приватизації та оцінки майна зареєструвати доповнення в Міністерстві юстиції України.

3. Після реєстрації зазначених доповнень Департаменту малої приватизації та оцінки майна забезпечити передачу документа регіональним відділенням ФДМУ.

4. Контроль за виконанням цього наказу покласти на заступника Голови Фонду державного майна України О.Бондаря.

Голова Фонду Ю.Єхануров

Затверджено наказом Фонду державного майна України від 21.07.95 N 952

Доповнення до Порядку заповнення приватизаційного майнового сертифіката при продажу акцій відкритих акціонерних товариств, затвердженого наказом ФДМУ від 29.03.95 N 343 ( z0104-95 )

1. Назву Порядку доповнити словами "та при продажу державного майна іншими способами приватизації".

2. Перше речення Порядку після слів "вносять відповідальні особи" доповнити слідуючими словами:

"ФДМ України (регіонального відділення ФДМУ, Представництва)".

3. Друге речення після слів "наказом відповідного регіонального відділення ФДМУ при продажу пакетів акцій" доповнити словами "чи при продажу державного майна іншими способами приватизації;".

4. Пункт 1 доповнити таким реченням: "При продажу державного майна іншими способами приватизації - номер і дату нотаріального посвідчення договору купівлі-продажу: "Дог-р N 0000: хх.хх.9х".

5. Пункт 2 доповнити реченням: "При продажу державного майна - назву об'єкта приватизації та його місцезнаходження".

6. Пункт 3 після слів "акціонерного товариства" доповнити слідуючими словами "при продажу державного майна іншими способами приватизації - код за ЗКПО об'єкта приватизації".
