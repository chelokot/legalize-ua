Стан: Чинний

Текст документа від 11.07.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 липня 2008 р. N 957-р Київ

Про будівництво комплексу Посольства України в Грузії

{ Із змінами, внесеними згідно з Розпорядженням КМ N 442-р ( 442-2012-р ) від 11.07.2012 }

1. Погодитися з пропозицією МЗС щодо будівництва протягом 2008-2013 років комплексу Посольства України в Грузії по просп. І. Чавчавадзе, 2/8, у м. Тбілісі вартістю 33694,295 тис. гривень відповідно до проектно-кошторисної документації.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 442-р ( 442-2012-р ) від 11.07.2012 }

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 21 січня 2004 р. N 27 ( 27-2004-р ) "Про будівництво комплексу Посольства України в Грузії".
