{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 2007 ( v2007359-12 ) від 27.12.2012 }

Про форми свідоцтва про реєстрацію ініціативної групи всеукраїнського референдуму за народною ініціативою та посвідчення члена ініціативної групи всеукраїнського референдуму за народною ініціативою

Відповідно до частини шостої статті 17 Закону України "Про всеукраїнський та місцеві референдуми" ( 1286-12 ), керуючись статтями 12, 13, пунктом 8 статті 20 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Встановити форму свідоцтва про реєстрацію ініціативної групи всеукраїнського референдуму за народною ініціативою (додаток 1).

2. Встановити форму посвідчення члена ініціативної групи всеукраїнського референдуму за народною ініціативою (додаток 2) ( va158359-05 ).

3. Визнати такою, що втратила чинність, постанову Центральної виборчої комісії від 23 грудня 1999 року N 449 ( v0449359-99 ) "Про форми свідоцтва про реєстрацію ініціативної групи з всеукраїнського референдуму за народною ініціативою та посвідчення члена ініціативно групи з всеукраїнського референдуму за народною ініціативою".
