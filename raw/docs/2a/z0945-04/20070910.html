{ Із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 1040 ( z1233-06 ) від 19.10.2006 }

{ Додатково див. Постанову Окружного адміністративного суду міста Києва N 8/18 ( v8_18805-07 ) від 10.09.2007 }

На виконання пункту 2 розпорядження Кабінету Міністрів України від 1 квітня 2004 року N 208-р ( 208-2004-р ) "Про схвалення Концепції створення системи рейтингової оцінки регіонів, галузей національної економіки, суб'єктів господарювання" Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Встановити Заходи щодо реалізації Концепції створення системи рейтингової оцінки регіонів, галузей національної економіки, суб'єктів господарювання (згідно з додатком).

2. Затвердити Положення про умови конкурсу щодо визначення агентств, уповноважених на проведення рейтингової оцінки (додається).

3. Скасувати рішення Державної комісії з цінних паперів та фондового ринку від 27.04.2004 N 154 "Про заходи щодо реалізації Концепції створення системи рейтингової оцінки регіонів, галузей національної економіки, суб'єктів господарювання та Положення про умови конкурсу щодо визначення агентств, уповноважених на проведення рейтингової оцінки".

4. Заступнику Виконавчого секретаря Петрашку О.Г. забезпечити опублікування рішення відповідно до чинного законодавства.

5. Контроль за виконанням цього рішення покласти на заступника Виконавчого секретаря Петрашка О.Г.
