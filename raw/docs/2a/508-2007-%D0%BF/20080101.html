КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 березня 2007 р. N 508 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1294 ( 1294-2007-п ) від 07.11.2007 }

Про доповнення постанови Кабінету Міністрів України від 29 грудня 2006 р. N 1851

Кабінет Міністрів України постановляє:

У постанові Кабінету Міністрів України від 29 грудня 2006 р. N 1851 ( 1851-2006-п ) "Про грошове забезпечення деяких категорій військовослужбовців Збройних Сил" (Офіційний вісник України, 2007 р., N 1, ст. 37) доповнити:

у пункті 1 графу "Найменування посади" після слів "Перший заступник начальника Генерального штабу Збройних Сил, командувач виду Збройних Сил" словами ", начальник Національної академії оборони";

абзац другий пункту 2 після слів "Сил підтримки" словами ", начальнику Національної академії оборони".

Прем'єр-міністр України В.ЯНУКОВИЧ
