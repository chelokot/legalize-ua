Кабінет Міністрів України; Розпорядження, Перелік від 22.12.1999 № 1454-р

Про передачу Мінвуглепрому повноважень з управління державними корпоративними правами господарських товариств

Стан: Втратив чинність

Ідентифікатор: 1454-99-р

Текст документа від 07.03.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 грудня 1999 р. N 1454-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 301 ( 301-2003-п ) від 07.03.2003 )

Прийняти пропозицію Національного агентства з управління державними корпоративними правами про передачу безпосередньо Мінвуглепрому повноважень з управління державними корпоративними правами господарських товариств згідно з переліком, що додається.

Національному агентству з управління державними корпоративними правами розробити та затвердити умови такої передачі та визначити завдання з управління державними корпоративними правами зазначених господарських товариств.

Перший віце-прем'єр-міністр України А.КІНАХ
