Про внесення змін до деяких наказів Міністерства праці та соціальної політики України

{ Із змінами, внесеними згідно з Наказами Міністерства соціальної політики N 123 ( z0566-13 ) від 18.03.2013 N 613 ( z0821-15 ) від 15.06.2015 }

Відповідно до Закону України "Про загальнообов'язкове державне соціальне страхування на випадок безробіття" ( 1533-14 ) НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства соціальної політики N 613 ( z0821-15 ) від 15.06.2015 }

{ Пункт 2 втратив чинність на підставі Наказу Міністерства соціальної політики N 123 ( z0566-13 ) від 18.03.2013 }

3. Державному центру зайнятості забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Цей наказ набирає чинності з дня його офіційного опублікування.
