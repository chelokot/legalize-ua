Текст документа від 14.02.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 липня 2005 р. N 632 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 202 ( 202-2007-п ) від 14.02.2007 }

Деякі питання приватизації об'єктів права державної власності

Кабінет Міністрів України постановляє:

Погодитися з пропозицією Фонду державного майна про незастосування обмежень на приватизацію об'єктів права державної власності, встановлених постановою Кабінету Міністрів України від 28 лютого 2005 р. N 158 ( 158-2005-п ) "Про часткове зняття обмежень щодо розпорядження об'єктами права державної власності" (Офіційний вісник України, 2005 р., N 9, ст. 472), для об'єктів, приватизація яких проводитиметься за рішеннями Кабінету Міністрів України, прийнятими у 2005 році.

Прем'єр-міністр України Ю.ТИМОШЕНКО
