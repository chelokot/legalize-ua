КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 листопада 2000 р. N 1736 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1438 ( 1438-2003-п ) від 10.09.2003 )

Про затвердження спостережної ради Національної акціонерної компанії "Нафтогаз України"

Кабінет Міністрів України постановляє:

1. Затвердити новий склад спостережної ради Національної акціонерної компанії "Нафтогаз України", що додається.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 25 січня 2000 р. N 133 ( 133-2000-п ) (Офіційний вісник України, 2000 р., N 4, ст. 120).
