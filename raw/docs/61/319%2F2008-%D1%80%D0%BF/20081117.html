Стан: Чинний

Текст документа від 17.11.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про призначення грантів Президента України для обдарованої молоді на 2009 рік

З метою реалізації значущих творчих проектів у соціальній та гуманітарній сферах призначити на 2009 рік гранти Президента України для обдарованої молоді:

БАРАНУ Сергію Володимировичу для реалізації проекту "Розробка автоматизованої системи геолого-маркшейдерського забезпечення для рудних кар'єрів" - 26 тис. гривень;

БРОВКУ Роману Олеговичу для реалізації проекту "Художній короткометражний фільм "Бумеранг" - 74 тис. гривень;

ГАЙДУЧИК Ірині Іванівні для реалізації проекту "Твоя майбутня професійна кар'єра" - 57 тис. гривень;

ГОРБАНЮ Валерію Віталійовичу для реалізації проекту "Оцінка санітарно-епідеміологічної та екологічної ситуації рекреаційних зон північно-західного Приазов'я" - 39 тис. гривень;

ГОРОХУ Сергію Миколайовичу для реалізації проекту "Четвертий молодіжний рок-фестиваль "ПРО РОК" - 64 тис. гривень;

ГРЕКОВУ Олександру Миколайовичу для реалізації проекту "Система автоматичного контролю фізико-хімічних і біологічних показників плавальних басейнів" - 20 тис. гривень;

ДАВІДОВУ Альберту Оганезовичу для реалізації проекту "Метод імпульсної експрес-діагностики електрохімічних акумуляторів" - 33 тис. гривень;

ЗАБОЛОТНІЙ Наталії Михайлівні для реалізації проекту "Впровадження інноваційних форм роботи з багатодітними сім'ями на місцях "Від родинної зернини - до квітучої України" - 57 тис. гривень;

ЗЛОБІНІЙ Катерині Сергіївні, ОГАР Тетяні Вікторівні для реалізації проекту "Еколого-геохімічна оцінка якості підземних вод, що використовуються для бюветного водопостачання міста Києва" - 12 тис. гривень;

ІВАНІВСЬКІЙ Тетяні Степанівні, УКРАЇНСЬКІЙ Наталії Іванівні для реалізації проекту "Розробка і впровадження в клінічну практику імуноцитохімічних методів діагностики злоякісних пухлин у дітей" - 72 тис. гривень;

КАМІНСЬКОМУ Данилу Володимировичу для реалізації проекту "Розробка нових протипухлинних агентів для терапії метастазуючих пухлин молочної залози" - 64 тис. гривень;

КОЛИБУ Денису Володимировичу для реалізації проекту "Отримання токсин-нейтралізуючих рекомбінантних одноланцюгових варіабельних фрагментів антитіл проти дифтерійного токсину" - 70 тис. гривень;

КАРАМУШЦІ Ользі Олександрівні для реалізації проекту "Розробка методики прогнозування зон порушеності вугільних пластів для підвищення безпеки виконання гірничих робіт" - 47 тис. гривень;

КОНСТАНТІНОВІЙ Вікторії Миколаївні для реалізації проекту "Усна історія Голодомору 1932-1933 років у Північному Приазов'ї (за матеріалами історико-археографічних експедицій)" - 50 тис. гривень;

КУПРІЯНОВІЙ Ларисі Сергіївні для реалізації проекту "Патоморфологія тимусу плодів від матерів із цукровим діабетом І типу" - 20 тис. гривень;

МАЛИНОВСЬКОМУ Євгенію Вікторовичу для реалізації проекту "Створення макета Давньоруського літописного міста Дорогобуж (XII ст.)" - 52 тис. гривень;

МЕЛЬНИКУ Роману Олександровичу для реалізації проекту "Служба молодіжного сервісу" - 69 тис. гривень;

ПАВЛЕНКУ Віталію Миколайовичу для реалізації проекту "Побудова єдиного інформаційного середовища управління навчальною діяльністю університету" - 16 тис. гривень;

ПЕТРИЧЕНКО Тетяні Миколаївні для реалізації проекту "Моє покоління "Профілактична діяльність в навчальних закладах з метою запобігання розповсюдженню ВІЛ/СНІДу та наркоманії" - 62 тис. гривень;

ПОЛЯКОВІЙ Тетяні Василівні для реалізації проекту "Перспективна технологія підготовки високоякісної питної води" - 35 тис. гривень;

РОМАНЮК Надії Ігорівні для реалізації проекту "Мультимедійний онлайн-клуб молодих підприємців" - 65 тис. гривень;

СЕМЕНЮК Марії Володимирівні, СЕРГЕЄВІЙ Катерині Володимирівні, ТОВСТЕНКО Аліні Олегівні для реалізації проекту "Школа добрих звичок" для вихованців притулків для дітей м. Києва та Київської області" - 33 тис. гривень;

СУХОРУКОВІЙ Тетяні В'ячеславівні для реалізації проекту "Дослідження імунологічних механізмів та типу імунних реакцій у розвитку розсіяного склерозу" - 74 тис. гривень;

ТОКАРЮ Геннадію Анатолійовичу для реалізації проекту "Оцінка екологічного стану дунайських плавнів з різною проточністю за показниками біологічних індикаторів" - 73 тис. гривень;

ТОЛСТАНОВІЙ Ганні Миколаївні для реалізації проекту "Розробка методів лікування запальних захворювань кишечника на основі виявлення нових патогенетичних механізмів" - 67 тис. гривень;

ФЕСЕНКУ Антону Ігоровичу для реалізації проекту "Розвиток соціальної інфраструктури створенням основних вузлів екіпажної частини високошвидкісного локомотива на основі експертної системи прийняття рішень" - 30 тис. гривень;

ФІЛЯКУ Євгену Зеновійовичу для реалізації проекту "Написання та видання (друк) принципово нового посібника по медичній паразитології для студентів медичних ВНЗ" - 40 тис. гривень;

ХОСІ Юрію Володимировичу для реалізації проекту "Газифікація вуглецьвмісної сировини методом зовнішнього обігріву з отриманням синтез-газу" - 19 тис. гривень.
