Стан: Чинний

Текст документа від 04.11.2004:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до деяких указів Президента України

{ Зі статей 3, 4, 5 цього Указу позначку "Опублікуванню не підлягає" знято Указом Президента N 293/2015 ( 293/2015 ) від 28.05.2015 }

Внести зміни до таких указів Президента України:

1. У Переліку посадових осіб органів державної влади, на яких покладається виконання функцій державного експерта з питань таємниць, затвердженому Указом Президента України від 18 жовтня 2000 року N 1144 ( 1144/2000 ) (в редакції Указу від 19 січня 2004 року N 58 ( 58/2004 ):

у розділі "Служба безпеки України" позицію "Начальник Головного управління розвідки" виключити;

доповнити Перелік після розділу "Служба безпеки України" новим розділом такого змісту:

"Служба зовнішньої розвідки України"

Голова

Перший заступник Голови

Заступники Голови".

2. Статтю 4 Указу Президента України від 20 березня 2002 року N 276 ( 276/2002 ) "Про розмежування повноважень центральних органів виконавчої влади у сфері військово-технічного співробітництва з іноземними державами" доповнити пунктом 5-1 такого змісту:

"5-1) Служба зовнішньої розвідки України:

виявляє зовнішні загрози національній безпеці, політичним та економічним інтересам України у сфері військово-технічного співробітництва;

бере участь у підготовці проектів міжнародних договорів України з питань взаємного захисту секретної інформації;

здійснює забезпечення розвідувальною інформацією визначених Президентом України суб'єктів військово-технічного співробітництва;

бере участь у заходах експортного контролю, а також контролю за виконанням міжнародних зобов'язань щодо заборони або обмеження військово-технічного співробітництва з окремими державами згідно з резолюціями Ради Безпеки ООН, рішеннями інших міжнародних органів та організацій, та щодо заборони поширення зброї масового ураження, а також технологій і компонентів її виготовлення;

сприяє спеціальними силами і засобами реалізації продукції військового призначення іноземними замовниками".

{ Знято позначку "Опублікуванню не підлягає" Указом Президента N 293/2015 ( 293/2015 ) від 28.05.2015 }

3. У Положенні про Антитерористичний центр та його координаційні групи при регіональних органах Служби безпеки України, затвердженому Указом Президента України від 14 квітня 1999 року N 379 ( 379/99 ) (зі змінами, внесеними Указами від 14 липня 2000 року N 894, від 1 квітня 2002 року N 311 і від 13 квітня 2004 року N 426):

у пункті 9 слова "та у справах захисту населення від наслідків Чорнобильської катастрофи, Генерального штабу Збройних Сил України" замінити словами "Генерального штабу Збройних Сил України, Служби зовнішньої розвідки України";

пункт 16 після слів "Служби безпеки України" доповнити словами "Служби зовнішньої розвідки України".

{ Знято позначку "Опублікуванню не підлягає" Указом Президента N 293/2015 ( 293/2015 ) від 28.05.2015 }

4. У статті 4 Указу Президента України від 26 липня 2001 року N 570 ( 570/2001 ) "Про порядок взаємодії з міжнародними антитерористичними організаціями" слова "разом з" замінити словами "разом із Службою зовнішньої розвідки України і".

{ Знято позначку "Опублікуванню не підлягає" Указом Президента N 293/2015 ( 293/2015 ) від 28.05.2015 }

5. Абзац четвертий пункту 7 Положення про державну систему урядового зв'язку України, затвердженого Указом Президента України від 5 березня 2002 року N 206 ( 206/2002 ), після слів "органів державної влади" доповнити словами "Служби зовнішньої розвідки України".
