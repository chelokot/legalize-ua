КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 лютого 2003 р. N 76-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 727-р ( 727-2008-р ) від 21.05.2008 }

Про затвердження нового складу наглядової ради Національного медичного університету імені О.О. Богомольця

1. Затвердити новий склад наглядової ради Національного медичного університету імені О.О. Богомольця з п'ятирічним терміном її повноважень (додається).

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 11 грудня 1996 р. N 1506 ( 1506-96-п ) "Про затвердження складу наглядової ради Національного медичного університету імені О.О. Богомольця";

постанову Кабінету Міністрів України від 22 червня 1999 р. N 1088 ( 1088-99-п ) "Про зміни у складі наглядової ради Національного медичного університету імені О.О. Богомольця".
