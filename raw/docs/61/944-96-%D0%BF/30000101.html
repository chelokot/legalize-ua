ПОСТАНОВА від 14 серпня 1996 р. N 944 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про створення Державної компанії з експорту та імпорту продукції і послуг військового та спеціального призначення

{ Із змінами, внесеними згідно з Постановами КМ N 1247 ( 1247-96-п ) від 09.10.96 N 1782 ( 1782-99-п ) від 25.09.99 }

{ Змінюється Постановою КМ N 1336 ( 1336-2006-п ) від 20.09.2006 }

{ Із змінами, внесеними згідно з Постановою КМ N 862 ( 862-2012-п ) від 19.09.2012 }

З метою впорядкування діяльності у сфері експорту та імпорту озброєння, боєприпасів, військової техніки і спеціальних комплектуючих виробів для їх виробництва, вибухових речовин, робіт і послуг військового та спеціального призначення Кабінет Міністрів України постановляє:

1. Утворити Державну компанію з експорту та імпорту продукції і послуг військового та спеціального призначення (компанія "Укрспецекспорт") на базі спеціалізованої зовнішньоторгівельної фірми "Прогрес", Державної госпрозрахункової зовнішньоторгівельної та інвестиційної фірми "Укрінмаш" і Державного підприємства з експорту-імпорту продукції та послуг військового призначення "Укроборонсервіс".

2. Основним завданням компанії "Укрспецекспорт" є здійснення операцій з експорту та імпорту озброєння, боєприпасів, військової техніки і спеціальних комплектуючих виробів для їх виробництва, вибухових речовин, робіт і послуг військового та спеціального призначення.

{ Абзац другий пункту 2 виключено на підставі Постанови КМ N 1782 ( 1782-99-п ) від 25.09.99 }

{ Пункт 3 втратив чинність на підставі Постанови КМ N 862 ( 862-2012-п ) від 19.09.2012 }

4. Міністерству машинобудування, військово-промислового комплексу і конверсії, Міністерству зовнішніх економічних зв'язків і торгівлі, Міністерству закордонних справ разом з Службою безпеки подати у місячний термін Кабінетові Міністрів України проект статуту компанії "Укрспецекспорт" та пропозиції про внесення змін і доповнень до відповідних актів законодавства у зв'язку із створенням компанії "Укрспецекспорт".
