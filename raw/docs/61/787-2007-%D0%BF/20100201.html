КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 травня 2007 р. N 787 Київ

Про проведення у м. Києві експерименту щодо запровадження інноваційної форми влаштування дітей

{ Із змінами, внесеними згідно з Постановами КМ N 367 ( 367-2008-п ) від 17.04.2008 N 1421 ( 1421-2009-п ) від 29.12.2009 }

{ У тексті Постанови слово "безпритульних" виключено згідно з Постановою КМ N 367 ( 367-2008-п ) від 17.04.2008 }

Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Міністерства у справах сім'ї, молоді та спорту і Київської міської державної адміністрації стосовно проведення до 2011 року в м. Києві експерименту щодо запровадження інноваційної форми влаштування дітей у центр захисту дітей "Наші діти", утворений структурним осередком Німецько-Польсько-Українського товариства в Україні.

2. Затвердити Типове положення про центр захисту дітей "Наші діти", що додається.

3. Міністерству у справах сім'ї, молоді та спорту:

здійснювати координацію та методичне забезпечення функціонування у м. Києві центру захисту дітей "Наші діти";

після закінчення експерименту подати пропозиції Кабінетові Міністрів України щодо доцільності його проведення в інших регіонах.

Прем'єр-міністр України В.ЯНУКОВИЧ
