ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

29.09.2009 N 567

{ Постанова втратила чинність на підставі Постанови Національного банку N 820 ( v0820500-14 ) від 18.12.2014 }

Про деякі питання регулювання грошово-кредитного ринку

{ Із змінами, внесеними згідно з Постановою Національного банку

N 210 ( v0210500-10 ) від 20.04.2010 }

Відповідно до пунктів 1.1 та 1.10 глави 1 Положення про порядок формування обов'язкових резервів для банків України, затвердженого постановою Правління Національного банку України від 16.03.2006 N 91 ( z0312-06 ), зареєстрованого в Міністерстві юстиції України 23.03.2006 за N 312/12186 (зі змінами), Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Установити, що з 2 жовтня 2009 року за залишками коштів обов'язкових резервів, що перераховані банками на окремий рахунок у Національному банку України, Національний банк нараховує проценти в розмірі 30% від облікової ставки Національного банку України за умови дотримання банком порядку формування та зберігання обов'язкових резервів.

2. Дозволити банкам:

не враховувати вкладення в державні цінні папери, випущені для фінансування заходів, пов'язаних з підготовкою і проведенням чемпіонату Європи 2012 року з футболу в Україні, під час розрахунку суми розбалансованості між активами та пасивами більше року;

{ Абзац третій пункту 2 втратив чинність на підставі Постанови Національного банку N 210 ( v0210500-10 ) від 20.04.2010 }

{ Абзац четвертий пункту 2 втратив чинність на підставі Постанови Національного банку N 210 ( v0210500-10 ) від 20.04.2010 }

3. Визнати такою, що втратила чинність, постанову Правління Національного банку України від 21.07.2009 N 414 ( va414500-09 ) "Про деякі питання регулювання грошово-кредитного ринку".

4. Департаменту монетарної політики (Н.І.Гребеник) довести зміст цієї постанови до відома територіальних управлінь Національного банку України та банків для використання в роботі.

5. Постанова набирає чинності з 2 жовтня 2009 року, крім абзацу третього пункту 2, який набирає чинності з 10 жовтня 2009 року.

6. Контроль за виконанням цієї постанови покласти на першого заступника Голови Національного банку України А.В.Шаповалова.

В.о. Голови А.В.Шаповалов
