Про внесення змін до наказу Міністерства праці та соціальної політики України від 04.02.2000 N 29

На виконання постанов Кабінету Міністрів України від 27.08.2004 N 1126 ( 1126-2004-п ) "Про заходи щодо вдосконалення соціальної роботи із сім'ями, дітьми та молоддю" та від 15.01.2005 N 37 ( 37-2005-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести такі зміни до наказу Міністерства праці та соціальної політики України від 04.02.2000 N 29 ( z0086-00 ) "Про умови оплати праці працівників центрів соціальних служб для молоді", зареєстрованого в Міністерстві юстиції України 11 лютого 2000 року за N 86/4307 (зі змінами):

1) доповнити назву наказу після слова "для" словами та знаком "сім'ї, дітей та";

2) замінити у тексті наказу слова "центри соціальних служб для молоді" словами "центри соціальних служб для сім'ї, дітей та молоді" у відповідних відмінках;

3) викласти додатки 1-6 у новій редакції (додаються).

2. Ці умови застосовуються з 1 січня 2005 року.

В.о. Міністра М.Папієв
