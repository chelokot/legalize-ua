Про свято День прикордонника

( Із змінами, внесеними згідно з Указом Президента N 431/2003 ( 431/2003 ) від 21.05.2003 )

Враховуючи заслуги Прикордонних військ у справі охорони і постановляю:

Установити професійне свято - День прикордонника, яке відзначати щорічно 28 травня. ( Частина перша Указу в редакції Указу Президента N 431/2003 ( 431/2003 ) від 21.05.2003 )

У День прикордонника у містах Києві, Сімферополі, Севастополі та обласних центрах проводити урочисті заходи.

Президент України Л. КРАВЧУК
