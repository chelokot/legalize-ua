ЗАТВЕРДЖЕНО Розпорядження Антимонопольного комітету України 04.03.2008 N 120-р ( z0271-08 )

Зареєстровано в Міністерстві юстиції України 31 березня 2008 р. за N 272/14963

{ Документ втратив чинність на підставі Розпорядження Антимонопольного комітету N 200-р ( z0323-08 ) від 08.04.2008 }

ЗМІНИ до Інструкції щодо заповнення форми Звіту про результати здійснення процедур відкритих торгів із зменшенням ціни і двоступеневих торгів щодо закупівлі товарів, робіт і послуг за державні кошти ( z0907-06 )

1. У другому реченні абзацу другого пункту 2.1 Інструкції ( z0907-06 ) слово "п'ятого" замінити словом "шостого".

2. В абзаці другому пункту 2.5 Інструкції ( z0907-06 ):

у першому реченні цифри "45" замінити цифрами "30";

у другому реченні цифри "21" замінити цифрами "15", цифри "11" замінити цифрами "13".

3. В абзаці другому пункту 2.7 Інструкції ( z0907-06 ) цифру "9" замінити цифрами "11".
