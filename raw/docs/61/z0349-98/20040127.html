Стан: Втратив чинність

Ідентифікатор: z0349-98

Текст документа від 27.01.2004:

МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ

НАКАЗ

N 111 від 08.05.98 Зареєстровано в Міністерстві м.Київ юстиції України 27 травня 1998 р. vd980508 vn111 за N 349/2789

( Наказ втратив чинність на підставі Наказу Міністерства фінансів N 6 ( z0113-04 ) від 12.01.2004 )

Про затвердження змін і доповнень до Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик

У зв'язку з переходом Національного банку України та комерційних банків з 1 січня 1998 року на новий План рахунків бухгалтерського обліку ( va493500-97 ) НАКАЗУЮ:

Затвердити зміни і доповнення до Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик, затвердженого постановою Правління Національного банку України від 23.07.97 N 246 ( za373-97 ) і наказом Міністерства фінансів України від 10.07.97 N 149 ( z0373-97 ) та зареєстрованого в Міністерстві юстиції України 02.09.97 за N 373/2177 (додаються).

Міністр І.О.Мітюков

Затверджено Наказ Міністерства фінансів України 08.05.98 N 111

Постанова Правління Національного банку України 05.05.98 N 174 ( za349-98 )

Зареєстровано в Міністерстві юстиції України 27 травня 1998 р. за N 349/2789

Зміни і доповнення до Положення про порядок здійснення нерезидентами операцій з облігаціями внутрішніх державних позик ( z0373-97 )

У пунктах 3.5, 3.6, 3.9, 5.6 замість рахунку N 076 "Дебітори і кредитори банку за операціями клієнтів у вільно конвертованій валюті" ввести новий мультивалютний рахунок N 2901 "Кредиторська заборгованість за розрахунками за цінними паперами для клієнтів".

У пунктах 3.6, 3.7, 3.8, 5.4, 5.6 замість рахунку N 903 "Дебітори і кредитори банку за операціями з клієнтами" ввести новий мультивалютний рахунок N 2901 "Кредиторська заборгованість за розрахунками за цінними паперами для клієнтів".
