Мінпраці України (до1997р.); Наказ від 18.10.1995 № 42

Про внесення змін до наказу Міністерства праці України від 20.08.93 N 66 "Про умови оплати праці працівників Українського державного центру соціальних служб для молоді"

Реєстрація: Мін'юст України від 02.11.1995 № 398/934

Стан: Втратив чинність

Ідентифікатор: z0398-95

Текст документа від 28.01.2000:

МІНІСТЕРСТВО ПРАЦІ УКРАЇНИ

НАКАЗ

N 42 від 18.10.95 Зареєстровано в Міністерстві м.Київ юстиції України 2 листопада 1995 р. vd951018 vn42 за N 398/934

( Наказ втратив чинність на підставі Наказу Мінпраці N 7 ( z0054-00 ) від 20.01.2000 )

Про внесення змін до наказу Міністерства праці України від 20.08.93 N 66 "Про умови оплати праці працівників Українського державного центру соціальних служб для молоді"

( Із змінами, внесеними згідно з Наказом Мінпраці N 17 ( z0091-96 ) від 15.02.96 )

Відповідно до доручення Кабінету Міністрів України від 21.09.95 N 17251/30 за погодженням з Міністерством фінансів України та Міністерством України у справах молоді і спорту, НАКАЗУЮ:

1. Внести такі зміни до наказу Міністерства праці України від 20.08.93 N 66 ( z0127-93 ) "Про умови оплати праці працівників Українського державного центру соціальних служб для молоді":

1.1. В абзаці шостому підпункту "б" пункту 2 слова "до 0,5 мінімального розміру заробітної плати" замінити на слова "до 10 відсотків посадового окладу".

1.2. В абзаці першому підпункт "г" пункту 2 викласти у такій редакції:

"г) надавати працівникам матеріальну допомогу, спрямовуючи на цю мету кошти у розмірі середньомісячного заробітку".

1.3. У пункті 3 слова "0,5 і 1,0 мінімальної заробітної плати" замінити на слова "15 і 20 відсотків посадового окладу".

1.4. ( Пункт 1.4 втратив чинність на підставі Наказу Мінпраці N 17 ( z0091-96 ) від 15.02.96 ) У пункті 4 замість крапки в кінці речення поставити кому і доповнити словами "викладеному у редакції постанови Кабінету Міністрів України від 8 лютого 1995 року N 102 ( 102-95-п ) та у порядку, передбаченому постановою Кабінету Міністрів України від 13 червня 1995 року N 409 ( 409-95-п ) "Про підвищення заробітної плати на державних підприємствах, в установах і організаціях" і постановою Кабінету Міністрів України від 2 жовтня 1995 року N 778 ( 778-95-п ) "Про підвищення з 1 жовтня 1995 року заробітної плати працівників бюджетних установ і організацій".

2. Цей наказ набуває чинності через 10 днів після державної реєстрації.

Міністр М.Г.Каскевич
