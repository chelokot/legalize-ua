Кабінет Міністрів України; Розпорядження від 20.11.1999 № 1256-р

Про внесення змін до постанови Кабінету Міністрів України від 3 червня 1999 р. N 951 та розпорядження Кабінету Міністрів України від 22 червня 1999 р. N 604

Стан: Втратив чинність

Ідентифікатор: 1256-99-р

Текст документа від 07.03.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 листопада 1999 р. N 1256-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 301 ( 301-2003-п ) від 07.03.2003 )

1. Виключити з додатка 3 та включити у додаток 42 до постанови Кабінету Міністрів України від 3 червня 1999 р. N 951 ( 951-99-п ) "Про передачу повноважень з управління державними корпоративними правами Раді міністрів Автономної Республіки Крим, міністерствам, іншим центральним і місцевим органам виконавчої влади" (Офіційний вісник України, 1999 р., N 23, ст. 1053, N 33, ст. 1744) позицію:

"00131305 АТ "Енергопостачальна компанія "Київенерго".

2. У розпорядженні Кабінету Міністрів України від 22 червня 1999 р. N 604 ( 604-99-р ) (Офіційний вісник України, 1999 р., N 25, ст. 1193):

з пункту 2 виключити абзац другий;

пункт 3 викласти в такій редакції:

"3. Міненерго під час здійснення повноважень з управління державним майном теплоелектроцентралей і теплових мереж, яке не увійшло до статутного фонду АК "Київенерго", та Київській міськдержадміністрації під час здійснення повноважень з управління державним пакетом акцій цієї компанії забезпечити ефективне використання та відновлення державного майна, спрямування частини прибутку, який залишається у розпорядженні АК "Київенерго", на утримання майна теплоелектроцентралей і теплових мереж та погашення у повному обсязі кредитних коштів відповідно до Угоди про позику "Проект реабілітації та розширення централізованого теплопостачання м. Києва" ( 996_017 ), укладеної між Україною та Міжнародним банком реконструкції та розвитку".

3. Київській міськдержадміністрації укласти з Міненерго відповідний договір про спільні дії із забезпечення надійного функціонування АК "Київенерго" як складової частини єдиної енергосистеми держави.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
