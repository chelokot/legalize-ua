Президент України; Указ від 11.05.2004 № 512/2004

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

Стан: Втратив чинність

Ідентифікатор: 512/2004

Текст документа від 08.02.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 208/2005 ( 208/2005 ) від 08.02.2005 )

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

Увести до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України, затвердженого Указом Президента України від 24 березня 2004 року N 362 ( 362/2004 ), СМИРНОВА Юрія Олександровича - Радника Президента України.

Президент України Л.КУЧМА
