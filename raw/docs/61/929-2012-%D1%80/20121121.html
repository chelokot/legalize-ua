КАБІНЕТ МІНІСТРІВ УКРАЇНИ
РОЗПОРЯДЖЕННЯ

від 21 листопада 2012 р. № 929-р
Київ

Про використання лікарських засобів, передбачених для забезпечення здійснення підрозділами спеціального призначення Служби безпеки заходів з антитерористичної діяльності під час підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

Погодитися з пропозицією Служби безпеки щодо використання лікарських засобів, що закуплені за рахунок бюджетних коштів, виділених у 2012 році для забезпечення здійснення підрозділами спеціального призначення Служби безпеки заходів з антитерористичної діяльності під час підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, для медичного забезпечення військовослужбовців і працівників Служби безпеки.

Прем'єр-міністр України

М.АЗАРОВ
