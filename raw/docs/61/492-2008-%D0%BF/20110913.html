Текст документа від 13.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 травня 2008 р. N 492 Київ

Про внесення змін до постанови Кабінету Міністрів України від 24 червня 2006 р. N 869

{ Із змінами, внесеними згідно з Постановою КМ N 937 ( 937-2011-п ) від 07.09.2011 }

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 24 червня 2006 р. N 869 ( 869-2006-п ) "Деякі питання організації діяльності Державної служби спеціального зв'язку та захисту інформації" (Офіційний вісник України, 2006 р., N 26, ст. 1890, N 46, ст. 3075) зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 49

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 травня 2008 р. N 492

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 24 червня 2006 р. N 869 ( 869-2006-п )

1. У пункті 1 постанови ( 869-2006-п ):

1) в абзаці першому цифри "7400" замінити цифрами "7246";

{ Підпункт 2 пункту 1 втратив чинність на підставі Постанови КМ N 937 ( 937-2011-п ) від 07.09.2011 }

3) абзац третій викласти у такій редакції:

"регіональних органів та територіальних підрозділів - 5709 осіб, з них 4990 осіб рядового і начальницького складу.";

4) абзац четвертий виключити.

2. У додатку до постанови ( 869-2006-п ):

1) виключити такі позиції:

"Департамент господарського та матеріально-технічного забезпечення"; "Відділ військових представництв";

"Сектор метрології";

2) доповнити додаток після позиції "Управління з питань використання радіочастотного ресурсу" такими позиціями:

"Управління документального забезпечення та архіву

Управління логістики".
