Кабінет Міністрів України; Розпорядження, План від 28.11.2006 № 595-р

Про ліквідацію наслідків надзвичайної ситуації на території Мелітопольського району Запорізької області на період до 2008 року

Стан: Чинний

Ідентифікатор: 595-2006-р

Текст документа від 31.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 листопада 2006 р. N 595-р Київ

Про ліквідацію наслідків надзвичайної ситуації на території Мелітопольського району Запорізької області на період до 2008 року

{ Із змінами, внесеними згідно з Розпорядженням КМ N 937-р ( 937-2007-р ) від 31.10.2007 }

1. Затвердити комплексний план заходів з ліквідації наслідків надзвичайної ситуації на території Мелітопольського району Запорізької області, спричиненої пожежею та вибухами на 275 артилерійській базі ракет і боєприпасів Міноборони, на період до 2008 року (далі - комплексний план), що додається.

2. Виділити у 2006 році Запорізькій облдержадміністрації 4544,841 тис. гривень для виконання визначених комплексним планом заходів, пов'язаних з ліквідацією наслідків надзвичайної ситуації, що склалася у п'ятикілометровій зоні навколо 275 артилерійської бази ракет і боєприпасів Міноборони.

Мінфіну здійснити зазначені видатки за рахунок резервного фонду державного бюджету ( 3235-15 ).

3. Мінфіну, Мінекономіки передбачити видатки на виконання заходів, визначених комплексним планом, у Державному бюджеті України на 2007 і 2008 роки для Запорізької облдержадміністрації.

4. Запорізькій облдержадміністрації подати до кінця 2006 року Мінекономіки, Мінфіну, Державному казначейству та Держбуду звіти про використання коштів, виділених згідно з цим розпорядженням.
