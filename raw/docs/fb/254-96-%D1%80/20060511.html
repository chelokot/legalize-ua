Про затвердження складу Української частини Міждержавної українсько-болгарської комісії з військово-технічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 254-96-р

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 квітня 1996 р. N 254-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Про затвердження складу Української частини Міждержавної українсько-болгарської комісії з військово-технічного співробітництва

1. Затвердити Українську частину Міждержавної українсько-болгарської комісії з військово-технічного співробітництва згідно із статтею IV Угоди між Урядом України та Урядом Республіки Болгарія про співробітництво у військово-технічній галузі та спеціальному виробництві ( 100_068 ) від 8 грудня 1994 р. у такому складі:

ЗАБАРА перший заступник Міністра машинобу- Віктор Миколайович дування, військово-промислового комплексу і конверсії (голова Укра- їнської частини Комісії)

МІНІН заступник Міністра економіки (зас- Леонід Васильович тупник голови Української частини Комісії)

СИДОРСЬКИЙ завідуючий сектором Відділу з пи- Володимир Леонідович тань машинобудування та конверсії Кабінету Міністрів України

ЧЕРНИХ заступник начальника Головного уп- Володимир Митрофанович равління по науці, розробках і вип- робування озброєння Збройних Сил України

АЛЄКСЄЄВ другий секретар МЗС Ігор Вікторович

ЗАРИЦЬКИЙ начальник управління військово-тех- Володимир Іванович нічного торговельного співробіт- ництва МЗЕЗторгу

ЮРЧЕНКО начальник відділу експортного конт- Юрій Петрович ролю Експертно-технічного комітету при Кабінеті Міністрів України

ЄРЬОМІНСЬКИЙ заступник начальника Головного уп- Сергій Клавдійович равління зовнішньоекономічних зв'язків Мінмашпрому (відповідаль- ний секретар Української частини Комісії)

2. Голові Української частини Міждержавної українсько-болгарської комісії Забарі В.М. підготувати проект Положення про Міждержавну українсько-болгарську комісію і матеріали для проведення її першого засідання.

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 22 березня 1995 р. N 165 ( 165-95-р ).
