ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ПО ЗЕМЕЛЬНИХ РЕСУРСАХ

12.04.2005 N 85

Зареєстровано в Міністерстві юстиції України 28 квітня 2005 р. за N 448/10728

( Наказ втратив чинність на підставі Наказу Державного комітету по земельних ресурсах N 286 ( z1234-05 ) від 28.09.2005 )

Про внесення змін до наказу Держкомзему України від 02.07.2003 N 174

Відповідно до постанови Кабінету Міністрів України від 19.04.93 N 283 ( 283-93-п ) "Про встановлення порядку виготовлення бланків цінних паперів і документів суворого обліку" НАКАЗУЮ:

1. Унести до Тимчасового порядку ведення державного реєстру земель, затвердженого наказом Держкомзему України від 02.07.2003 N 174 ( z0641-03 ), зареєстрованого в Мін'юсті України 25.07.2003 за N 641/7962, такі зміни:

1.1. В абзаці восьмому підпункту 1.2 пункту 1 слова "суворого обліку" виключити;

1.2. У підпунктах 1.8, 1.9 пункту 1 слова "та є бланками, які виготовляються відповідно до вимог постанови Кабінету Міністрів України від 19.04.93 N 283 ( 283-93-п ) "Про встановлення порядку виготовлення бланків цінних паперів і документів суворого обліку" (із змінами)" виключити;

1.3. У підпункті 12.7.5 пункту 12 слова "та виготовляються відповідно до вимог постанови Кабінету Міністрів України від 19.04.93 N 283 ( 283-93-п ) "Про встановлення порядку виготовлення бланків цінних паперів і документів суворого обліку" (із змінами)" виключити.

2. Управлінню державного земельного кадастру та державного реєстру прав на землю та нерухоме майно (Ненахов І.В.) та Юридичному управлінню (Кальніченко А.Г.) подати цей наказ на державну реєстрацію до Мін'юсту України в установленому порядку.

3. Контроль за виконанням цього наказу покласти на першого заступника Голови Комітету Кулініча В.В.

Голова Комітету А.С.Даниленко
