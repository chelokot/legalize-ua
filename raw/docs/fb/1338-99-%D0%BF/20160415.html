КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 липня 1999 р. N 1338 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 252 ( 252-2016-п ) від 30.03.2016 }

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про доповнення переліку, затвердженого постановою Кабінету Міністрів України від 26 січня 1994 р. N 26

Кабінет Міністрів України постановляє:

Доповнити абзац третій розділу "У центральному апараті Міністерства" переліку посад, що заміщуються вищим начальницьким складом у системі Міністерства внутрішніх справ, та граничних спеціальних звань за цими посадами, затвердженому постановою Кабінету Міністрів України від 26 січня 1994 р. N 26 ( 26-94-п ) "Про перелік посад, що заміщуються вищим начальницьким складом в органах внутрішніх справ", словами "керівник апарату Міністра".
