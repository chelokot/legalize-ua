Текст документа від 14.02.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 липня 2006 р. N 946 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 202 ( 202-2007-п ) від 14.02.2007 }

Питання реорганізації, ліквідації та реструктуризації державних підприємств

Кабінет Міністрів України постановляє:

Установити, що реорганізація, ліквідація та реструктуризація державних підприємств, які мають стратегічне значення для економіки та безпеки держави, займають монопольне становище на ринку, не підлягають приватизації, міністерствами та іншими органами виконавчої влади здійснюються за погодженням з Кабінетом Міністрів України.

Прем'єр-міністр України Ю.ЄХАНУРОВ
