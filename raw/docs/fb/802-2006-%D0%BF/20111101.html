Про встановлення строку дії ліцензій на провадження професійної діяльності на ринку цінних паперів

Стан: Втратив чинність

Ідентифікатор: 802-2006-п

Текст документа від 01.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 червня 2006 р. N 802 Київ

Про встановлення строку дії ліцензій на провадження професійної діяльності на ринку цінних паперів

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 1097 ( 1097-2011-п ) від 26.10.2011 }

{ Із змінами, внесеними згідно з Постановою КМ N 1097 ( 1097-2011-п ) від 26.10.2011 }

Відповідно до статті 4 Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ) Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 1097 ( 1097-2011-п ) від 26.10.2011 }

1. Установити, що строк дії ліцензій на провадження професійної діяльності на ринку цінних паперів, які видаються Національною комісією з цінних паперів та фондового ринку відповідно до частини першої статті 4 Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ), є необмеженим.

{ Пункт 1 в редакції Постанови КМ N 1097 ( 1097-2011-п ) від 26.10.2011 }

{ Пункт 2 виключено на підставі Постанови КМ N 1097 ( 1097-2011-п ) від 26.10.2011 }

3. Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 червня 2006 р. N 802

ПЕРЕЛІК актів Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 25 жовтня 1991 р. N 282 ( 282-91-п ) "Про встановлення плати за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів" (ЗП України, 1991 р., N 11, ст. 115).

2. Постанова Кабінету Міністрів України від 17 квітня 1995 р. N 285 ( 285-95-п ) "Про внесення змін до постанови Кабінету Міністрів України від 25 жовтня 1991 р. N 282" (ЗП України, 1995 р., N 7, ст. 172).

3. Постанова Кабінету Міністрів України від 29 червня 1996 р. N 693 ( 693-96-п ) "Про розміри плати за видачу дозволів на депозитарну діяльність і на здійснення діяльності щодо ведення реєстру власників іменних цінних паперів" (ЗП України, 1996 р., N 14, ст. 384).

4. Постанова Кабінету Міністрів України від 28 жовтня 1996 р. N 1318 ( 1318-96-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 25 жовтня 1991 р. N 282 "Про встановлення плати за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів" (ЗП України, 1996 р., N 19, ст. 542).

5. Розпорядження Кабінету Міністрів України від 18 червня 1999 р. N 574 ( 574-99-р ) (Офіційний вісник України, 1999 р., N 25, ст. 1187).
