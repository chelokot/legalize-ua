Про реалізацію зерна державного інтервенційного фонду

Стан: Чинний

Ідентифікатор: 62-2009-п

Текст документа від 21.08.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 лютого 2009 р. N 62 Київ

Про реалізацію зерна державного інтервенційного фонду

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 847 ( 847-2009-п ) від 23.07.2009 }

{ Із змінами, внесеними згідно з Постановою КМ N 847 ( 847-2009-п ) від 23.07.2009 }

Відповідно до Закону України "Про державну підтримку сільського господарства України" ( 1877-15 ) Кабінет Міністрів України постановляє:

Дозволити Аграрному фонду здійснювати у 2009 році в установленому порядку реалізацію зерна з державного інтервенційного фонду врожаю 2006-2008 років за середньозваженими цінами рівноваги (фіксингу), що склалися протягом останніх трьох торгових сесій на Аграрній біржі та сертифікованих нею акредитованих товарних біржах, але не нижче ціни закупівлі з урахуванням витрат, пов'язаних із зберіганням зерна.
