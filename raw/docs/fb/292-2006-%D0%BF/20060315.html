Кабінет Міністрів України; Постанова, Перелік від 15.03.2006 № 292

Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України з питань приватизації відкритого акціонерного товариства "Укртелеком"

Стан: Чинний

Ідентифікатор: 292-2006-п

Текст документа від 15.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 березня 2006 р. N 292 Київ

Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України з питань приватизації відкритого акціонерного товариства "Укртелеком"

Кабінет Міністрів України постановляє:

1. Визнати такими, що втратили чинність, акти Кабінету Міністрів України з питань приватизації відкритого акціонерного товариства "Укртелеком", згідно з переліком, що додається.

2. Фонду державного майна разом з Міністерством транспорту та зв'язку, Міністерством економіки, Міністерством фінансів, Національною комісією регулювання зв'язку і відкритим акціонерним товариством "Укртелеком" підготувати та подати Кабінетові Міністрів України заходи, спрямовані на забезпечення ефективної роботи та підвищення інвестиційної привабливості відкритого акціонерного товариства "Укртелеком".

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 25

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 15 березня 2006 р. N 292

ПЕРЕЛІК актів Кабінету Міністрів України з питань приватизації відкритого акціонерного товариства "Укртелеком", що втратили чинність

1. Постанова Кабінету Міністрів України від 26 лютого 2001 р. N 174 ( 174-2001-п ) "Про затвердження Порядку проведення конкурсу з визначення уповноважених осіб, радників та експертів для підготовки і здійснення продажу акцій відкритого акціонерного товариства "Укртелеком" (Офіційний вісник України, 2001 р., N 10, ст. 404).

2. Розпорядження Кабінету Міністрів України від 16 листопада 2000 р. N 454 ( 454-2000-р ) "Про приватизацію ВАТ "Укртелеком".

3. Розпорядження Кабінету Міністрів України від 26 липня 2001 р. N 306 ( 306-2001-р ) "Про затвердження плану розміщення акцій ВАТ "Укртелеком".

4. Розпорядження Кабінету Міністрів України від 21 серпня 2001 р. N 397 ( 397-2001-р ) "Про внесення зміни до плану розміщення акцій ВАТ "Укртелеком".

5. Розпорядження Кабінету Міністрів України від 29 листопада 2001 р. N 540 ( 540-2001-р ) "Про внесення зміни до плану розміщення акцій ВАТ "Укртелеком".

6. Розпорядження Кабінету Міністрів України від 1 червня 2002 р. N 289 ( 289-2002-р ) "Про затвердження уточненого плану розміщення акцій ВАТ "Укртелеком".

7. Розпорядження Кабінету Міністрів України від 28 липня 2004 р. N 513 ( 513-2004-р ) "Про затвердження рішення Комісії з приватизації ВАТ "Укртелеком" про умови приватизації ВАТ "Укртелеком".

8. Розпорядження Кабінету Міністрів України від 28 липня 2004 р. N 514 ( 514-2004-р ) "Про затвердження уточненого плану розміщення акцій ВАТ "Укртелеком" (Офіційний вісник України, 2005 р., N 4, ст. 231).
