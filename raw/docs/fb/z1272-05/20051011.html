Про втрату чинності деяких наказів Міністерства транспорту України

Відповідно до Положення про Міністерство транспорту та зв'язку України, затвердженого Указом Президента України від 27.08.2004 N 1009 ( 1009/2004 ), та Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регулярної політики" НАКАЗУЮ:

1. Уважати такими, що втратили чинність, накази Міністерства транспорту України:

від 28.09.94 N 506 ( z0240-94 ) "Про затвердження Правил реєстрації аеродромів цивільної авіації", зареєстрований в Міністерстві юстиції України 05.10.94 за N 240/450;

від 26.03.2003 N 238 ( z0277-03 ) "Про затвердження Правил надання адрес повітряних суден", зареєстрований в Міністерстві юстиції України 09.04.2003 за N 277/7598;

від 29.03.2004 N 252 ( z0785-04 ) "Про затвердження Правил сертифікації цивільних аеродромів України", зареєстрований в Міністерстві юстиції України 25.06.2004 за N 785/9384.

2. Юридичному департаменту (Ониськів М.М.) забезпечити подання цього наказу в установленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Рябікіна П.Б.

Міністр В.Бондар
