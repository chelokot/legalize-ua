Про доповнення розпорядження Кабінету Міністрів України від 9 липня 2004 р. N 452

Стан: Втратив чинність

Ідентифікатор: 795-2004-р

Текст документа від 24.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 жовтня 2004 р. N 795-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 367-р ( 367-2010-р ) від 24.02.2010 }

Про доповнення розпорядження Кабінету Міністрів України від 9 липня 2004 р. N 452

Доповнити розпорядження Кабінету Міністрів України від 9 липня 2004 р. N 452 ( 452-2004-р ) "Про передачу будинку в оперативне управління Центрвиборчкому" абзацом такого змісту:

"Дозволити Центрвиборчкому компенсувати незаплановані витрати Українського науково-дослідного інституту цукрової промисловості на ремонтні роботи у зв'язку з переїздом в інше приміщення в сумі до 2,5 млн. гривень".

Прем'єр-міністр України В.ЯНУКОВИЧ
