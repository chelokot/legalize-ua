Питання надання громадянам квартир, що придбані Державною іпотечною установою, у с. Сад

Стан: Чинний

Ідентифікатор: 64-2010-р

Текст документа від 24.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 січня 2010 р. N 64-р Київ

Питання надання громадянам квартир, що придбані Державною іпотечною установою, у с. Сад

{ Із змінами, внесеними згідно з Розпорядженням КМ N 293-р ( 293-2010-р ) від 24.02.2010 }

1. Затвердити погоджені Координаційною радою з питань розподілу квартир, що придбані Державною іпотечною установою, при Кабінеті Міністрів України поіменні списки громадян, яким надаються придбані у с. Сад Сумської області (вулиці Київська, 26, і Зелена, За) квартири (далі - списки), що додаються до оригіналу. { Зміни до поіменного списку див. в Розпорядженні КМ N 293-р ( 293-2010-р ) від 24.02.2010 }

2. Державній іпотечній установі передати державним органам та Садівській сільській раді квартири для надання зазначеним у списках громадянам.

3. Виконавчому комітетові Садівської сільської ради забезпечити в установленому законодавством порядку видачу зазначеним у списках громадянам ордерів на жилі приміщення.

4. Державним органам та Садівській сільській раді забезпечити неухильне дотримання встановленого Кабінетом Міністрів України порядку розподілу квартир, що придбані Державною іпотечною установою.

Прем'єр-міністр України Ю.ТИМОШЕНКО
