Кабінет Міністрів України; Постанова від 01.02.2006 № 89

Про внесення змін до деяких актів Кабінету Міністрів України з питань оплати праці працівників Секретаріату Президента України

Стан: Втратив чинність

Ідентифікатор: 89-2006-п

Текст документа від 09.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 лютого 2006 р. N 89 Київ

Про внесення змін до деяких актів Кабінету Міністрів України з питань оплати праці працівників Секретаріату Президента України

{ Із змінами, внесеними згідно з Постановою КМ N 268 ( 268-2006-п ) від 09.03.2006 }

Кабінет Міністрів України постановляє:

Внести до актів Кабінету Міністрів України з питань оплати праці працівників Секретаріату Президента України зміни, що додаються.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 1 лютого 2006 р. N 89

ЗМІНИ, що вносяться до актів Кабінету Міністрів України з питань оплати праці працівників Секретаріату Президента України

{ Пункт 1 втратив чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

2. У пункті 2 постанови Кабінету Міністрів України від 28 серпня 2001 р. N 1119 ( 1119-2001-п ) "Про внесення змін до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288" (Офіційний вісник України, 2001 р., N 35, ст. 1627; 2003 р., N 45, ст. 2358; 2005 р., N 9, ст. 469, N 27, ст. 1550) слова "Державному секретареві України" замінити словами "Главі Секретаріату Президента України".

3. У пункті 1 постанови Кабінету Міністрів України від 30 червня 2005 р. N 510 ( 510-2005-п ) "Про оплату праці керівних працівників державних органів" (Офіційний вісник України, 2005 р., N 27, ст. 1545, N 35, ст. 2118, N 44, ст. 2772, N 50, ст. 3119) у графі "Найменування посади" слова

"Державний секретар України",

"Перший заступник Державного секретаря України",

"Заступник Державного секретаря України"

замінити словами

"Глава Секретаріату Президента України",

"Перший заступник Глави Секретаріату Президента України",

"Заступник Глави Секретаріату Президента України".

{ Пункт 4 втратив чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }
