Кабінет Міністрів України; Розпорядження від 28.07.2008 № 1009-р

Про забезпечення надання допомоги громадянам, які постраждали внаслідок стихійного лиха, що сталося 23-27 липня 2008 року

Стан: Втратив чинність

Ідентифікатор: 1009-2008-р

Текст документа від 11.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 липня 2008 р. N 1009-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про забезпечення надання допомоги громадянам, які постраждали внаслідок стихійного лиха, що сталося 23-27 липня 2008 року

1. Утворити Комісію з питань забезпечення надання допомоги громадянам, які постраждали внаслідок стихійного лиха, що сталося 23-27 липня 2008 року (далі - Комісія).

2. Затвердити головою Комісії Першого віце-прем'єр-міністра України Турчинова О.В.

Включити до складу Комісії представників Мінпраці, Мінфіну, МНС, Міноборони, Мінпаливенерго, Мінагрополітики, Мінприроди, МВС, МОЗ, Мінтрансзв'язку, Держводгоспу, Держкомлісгоспу, Державного казначейства, голів Вінницької, Закарпатської, Івано-Франківської, Львівської, Тернопільської та Чернівецької обласних держадміністрацій.

3. Голові Комісії:

1) затвердити:

персональний склад Комісії;

порядок розподілу коштів, що надійшли від фізичних та юридичних осіб для надання допомоги громадянам,які постраждали внаслідок стихійного лиха, що сталося 23-27 липня 2008 року (далі - кошти);

2) забезпечити:

здійснення Комісією контролю за цільовим використанням коштів;

інформування громадськості через засоби масової інформації про цільове використання коштів.

4. Державному казначейству:

відкрити Мінпраці за балансовим рахунком 3711 "Інші рахунки клієнтів Державного казначейства" небюджетний рахунок для зарахування коштів;

забезпечити перерахування коштів обласним держадміністраціям відповідно до розподілів, визначених Комісією.

5. Мінпраці забезпечити 28-29 липня 2008 р. інформування громадськості через засоби масової інформації про відкриття небюджетного рахунка для зарахування коштів.

6. Обласним держадміністраціям забезпечити цільове використання коштів та інформування громадськості про їх цільове використання.
