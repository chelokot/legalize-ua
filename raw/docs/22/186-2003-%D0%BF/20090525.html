Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 лютого 2003 р. N 186 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

{ Постанова втратила чинність в частині встановлення ліміту легкових автомобілів, що обслуговують державні органи на підставі Постанови КМ N 954 ( 954-2008-п ) від 22.10.2008 }

Про внесення змін у додатки до постанов Кабінету Міністрів України від 26 лютого 2000 р. N 403 і від 2 квітня 2001 р. N 314

Кабінет Міністрів України постановляє:

У додатку 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів. що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851, ст. 875, N 32, ст. 1469, N 47, ст. 2096; 2002 р., N 8, ст. 339) у позиції "Міністерство фінансів" цифри "966" і "8464" замінити відповідно цифрами "1026" і "8404", а у додатку 1 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314 ( 314-2001-п ) "Про встановлення ліміту легкових автомобілів, що обслуговують державні органи" (Офіційний вісник України, 2001 р., N 14, ст. 602; 2002 р., N 8, ст. 339) у позиції "Мінфін" цифри "22" замінити цифрами "28".
