Кабінет Міністрів України; Розпорядження від 11.02.2010 № 365-р

Про виділення коштів Стабілізаційного фонду для здешевлення кредитів та підтримки окремих проектів в агропромисловому комплексі

Стан: Втратив чинність

Ідентифікатор: 365-2010-р

Текст документа від 11.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 лютого 2010 р. N 365-р Київ

Про виділення коштів Стабілізаційного фонду для здешевлення кредитів та підтримки окремих проектів в агропромисловому комплексі

1. Виділити Міністерству аграрної політики у 2010 році за рахунок коштів Стабілізаційного фонду ( 835-17 ) 1629474 тис. гривень для здешевлення кредитів та підтримки окремих проектів в агропромисловому комплексі, зокрема:

1) на безповоротній основі - 1326198 тис. гривень, у тому числі для:

фінансової підтримки підприємств агропромислового комплексу через механізм здешевлення кредитів - 716660 тис. гривень, з них 43000 тис. гривень - на здешевлення кредитів, залучених для реалізації інноваційних проектів, що пройшли державну реєстрацію в установленому законодавством порядку;

підтримки виробництва продукції тваринництва згідно з постановою Кабінету Міністрів України від 1 березня 2007 р. N 348 ( 348-2007-п ) "Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для розвитку тваринництва" (Офіційний вісник України, 2007 р., N 17, ст. 651) - 86655 тис. гривень;

виплати бюджетної тваринницької дотації за вирощений та проданий на забій у 2009 році молодняк великої рогатої худоби - 170000 тис. гривень;

підтримки виробництва продукції рослинництва (часткова компенсація сільськогосподарським підприємствам витрат на посів ярих культур цукрового буряку, льону-довгунця) - 219111 тис. гривень;

фінансування заходів із захисту, відтворення та підвищення родючості ґрунтів - 101965 тис. гривень;

проведення державних виставкових заходів у сфері агропромислового комплексу - 2528 тис. гривень;

запобігання розповсюдженню збудників інфекційних хвороб тварин - 9000 тис. гривень;

державної підтримки сільськогосподарських обслуговуючих кооперативів - 12063 тис. гривень;

консервації шахти N 9 державного підприємства "Солотвинський солерудник" Тячівського району Закарпатської області - 7930 тис. гривень;

відзначення 20-річчя фермерського руху - 286 тис. гривень;

2) на поворотній основі - у розмірі 303276 тис. гривень для підтримки окремих проектів в агропромисловому комплексі, у тому числі:

надання кредитів фермерським господарствам - 129714 тис. гривень;

фінансування заходів по операціях фінансового лізингу вітчизняної сільськогосподарської техніки - 173562 тис. гривень.

Зазначені кошти Стабілізаційного фонду використовуються відповідно до Порядку використання коштів Стабілізаційного фонду, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) "Питання використання коштів Стабілізаційного фонду" (Офіційний вісник України, 2009 р., N 24, ст. 793; 2010 р., N 2, ст. 69), та Порядку використання у 2009 році коштів Стабілізаційного фонду для здешевлення кредитів, фінансування інвестиційних проектів та підтримки окремих проектів в агропромисловому комплексі, затвердженого постановою Кабінету Міністрів України від 13 травня 2009 р. N 463 ( 463-2009-п ) (Офіційний вісник України, 2009 р., N 36, ст. 1225).

2. Визначити джерелом покриття витрат, зазначених у пункті 1 цього розпорядження, кошти, отримані від приватизації державного майна, продажу земельних ділянок несільськогосподарського призначення або прав на них, що перебувають у державній власності, на яких розташовані об'єкти, що підлягають приватизації, та від цільового розміщення цінних паперів.
