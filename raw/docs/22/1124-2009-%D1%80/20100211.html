Кабінет Міністрів України; Розпорядження від 23.09.2009 № 1124-р

Про передачу цілісного майнового комплексу комунального закладу "Львівська обласна державна стоматологічна поліклініка" у державну власність

Стан: Чинний

Ідентифікатор: 1124-2009-р

Текст документа від 11.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 вересня 2009 р. N 1124-р Київ

Про передачу цілісного майнового комплексу комунального закладу "Львівська обласна державна стоматологічна поліклініка" у державну власність

{ Назва Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 205-р ( 205-2010-р ) від 11.02.2010 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 205-р ( 205-2010-р ) від 11.02.2010 }

Прийняти пропозицію Львівської обласної ради та МОЗ про передачу з 1 січня 2010 р. у державну власність цілісного майнового комплексу комунального закладу "Львівська обласна державна стоматологічна поліклініка", розташованого по вул. Пекарській, 69а, у м. Львові, з віднесенням до сфери управління зазначеного Міністерства з подальшим приєднанням до складу Львівського національного медичного університету імені Данила Галицького.

МОЗ разом з Мінфіном передбачати під час доопрацювання проекту Державного бюджету України на 2010 рік та складання проекту Державного бюджету України на наступні роки кошти, необхідні для фінансування зазначеного закладу.

{ Текст Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 205-р ( 205-2010-р ) від 11.02.2010 }
