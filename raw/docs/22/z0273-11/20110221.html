21.02.2011 N 590

Зареєстровано в Міністерстві юстиції України 3 березня 2011 р. за N 273/19011

Про втрату чинності наказів Мінсім'ямолоді від 27.03.97 N 6/5 та від 04.03.98 N 73

Відповідно до постанови Кабінету Міністрів України від 27.08.2004 N 1125 ( 1125-2004-п ) "Про утворення Державної соціальної служби для сім'ї, дітей та молоді" (із змінами) та з метою приведення у відповідність до чинного законодавства НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Мінсім'ямолоді від 27.03.97 N 6/5 ( z0305-97 ) "Про Український державний центр соціальних служб для молоді", зареєстрований в Міністерстві юстиції України 14.08.97 за N 305/2109 (із змінами), та від 04.03.98 N 73 ( z0677-98 ) "Про затвердження Положення про Український державний центр соціальних служб для молоді", зареєстрований в Міністерстві юстиції України 21.10.98 за N 677/3117 (із змінами).

2. Державній соціальній службі для сім'ї, дітей та молоді (Лук'янова Н.Л.) подати цей наказ у встановленому порядку на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу залишаю за собою.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

Заступник Міністра, Голова комісії з проведення реорганізації А.В.Домашенко
