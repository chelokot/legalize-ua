Кабінет Міністрів України; Постанова від 13.01.1995 № 21

Про призупинення дії постанов Кабінету Міністрів України з питань обов'язкового страхування цивільної відповідальності власників транспортних засобів

Стан: Втратив чинність

Ідентифікатор: 21-95-п

Текст документа від 28.09.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 січня 1995 р. N 21 Київ

Про призупинення дії постанов Кабінету Міністрів України з питань обов'язкового страхування цивільної відповідальності власників транспортних засобів

( Із змінами, внесеними згідно з Постановою КМ N 1175 ( 1175-96-п ) від 28.09.96 )

На виконання постанови Верховної Ради України від 28 грудня 1994 р. "Про страхування цивільної відповідальності власників транспортних засобів" ( 333/94-ВР ) Кабінет Міністрів України постановляє:

1. ( Пункт 1 втратив чинність на підставі Постанови КМ N 1175 ( 1175-96-п ) від 28.09.96 у частині призупинення дії постанови Кабінету Міністрів України від 7 червня 1994 р. N 372 ( 372-94-п ) Призупинити з 1 січня 1995 р. дію постанов Кабінету Міністрів України від 7 червня 1994 р. N 372 ( 372-94-п ) "Про затвердження Положення про порядок і умови обов'язкового страхування цивільної відповідальності власників транспортних засобів" та від 6 грудня 1994 р. N 816 ( 816-94-п ) "Про внесення доповнень до Правил дорожнього руху".

2. Установити, що попередньо внесені страхувальниками страхові платежі за договорами обов'язкового страхування цивільної відповідальності власників транспортних засобів повертаються страховиками в місячний термін з дня набуття чинності цієї постанови, якщо між ними не буде досягнуто згоди про інше.

Прем'єр-міністр України В. МАСОЛ

Перший заступник Міністра
