( Наказ втратив чинність на підставі Наказу Міністерства економіки N 520 ( z1592-05 ) від 20.12.2005 )

Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 21.12.2001 N 317

Відповідно до постанови Кабінету Міністрів України від 19.05.2003 N 740 ( 740-2003-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів і організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства економіки та з питань європейської інтеграції України від 21.12.2001 N 317 ( z1084-01 ) "Про встановлення розмірів посадових окладів (ставок заробітної плати) працівників Вищих курсів іноземних мов при Міністерстві економіки та з питань європейської інтеграції України", зареєстрованого Міністерством юстиції України 27.12.2001 за N 1084/6275, виклавши додатки 1-3 в редакції, що додається.

2. Установити керівним, науково-педагогічним, педагогічним та іншим працівникам Вищих курсів іноземних мов при Міністерстві економіки та з питань європейської інтеграції України посадові оклади (ставки заробітної плати), виходячи з розмірів і в терміни, передбачені додатками 1-3 цього наказу.

3. Контроль за виконанням цього наказу покласти на директора адміністративного департаменту Дробного В.В.

Міністр економіки та з питань європейської інтеграції України В.Хорошковський к Міністра А.Мярковський
