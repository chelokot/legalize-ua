{ Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку

N 1478 ( z1246-09 ) від 24.11.2009 }

Про затвердження Змін до Положення про порядок реєстрації випуску інвестиційних сертифікатів пайового інвестиційного фонду при їх розміщенні шляхом прилюдної пропозиції

Відповідно до статей 7, 8 Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ) та Закону України "Про інститути спільного інвестування (пайові та корпоративні інвестиційні фонди)" ( 2299-14 ) Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Зміни до Положення про порядок реєстрації випуску інвестиційних сертифікатів пайового інвестиційного фонду при їх розміщенні шляхом прилюдної пропозиції, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 08.01.2002 N 10 ( z0072-02 ), зареєстрованого в Міністерстві юстиції України 29.01.2002 за N 72/6360 (у редакції рішення Державної комісії з цінних паперів та фондового ринку від 27.06.2007 N 1485) ( z1047-07 ) (додаються).

2. Керівнику апарату Державної комісії з цінних паперів та фондового ринку Ю.Назаренку забезпечити:

подання цього рішення на державну реєстрацію до Міністерства юстиції України;

опублікування цього рішення відповідно до законодавства.

3. Це рішення набирає чинності відповідно до законодавства.

4. Контроль за виконанням цього рішення покласти на Керівника апарату Державної комісії з цінних паперів та фондового ринку Ю.Назаренка.

ЗАТВЕРДЖЕНО Рішення Державної комісії з цінних паперів та фондового ринку 06.08.2008 N 879

Зареєстровано в Міністерстві юстиції України 12 вересня 2008 р. за N 842/15533

ЗМІНИ до Положення про порядок реєстрації випуску інвестиційних сертифікатів пайового інвестиційного фонду при їх розміщенні шляхом прилюдної пропозиції ( z0072-02 )

1. У пункті 2 розділу II:

1.1. Підпункти "й", "л" виключити.

У зв'язку з цим підпункт "к" уважати підпунктом "й".

1.2. Доповнити підпунктом "к" такого змісту:

"к) копію платіжного документа, який підтверджує сплату державного мита відповідно до Декрету Кабінету Міністрів України від 21.01.93 N 7-93 ( 7-93 ) "Про державне мито".

2. У розділі III:

2.1. Пункт 2 викласти в такій редакції:

"2. У разі, якщо сталися зміни однакових відомостей, що містяться відповідно у проспекті емісії інвестиційних сертифікатів фонду та у регламенті фонду, то такі зміни подаються для реєстрації до Комісії одночасно окремими комплектами документів та протягом 7 днів з дня їх виникнення".

2.2. У підпунктах "е", "є", "ж" пункту 6 слова "відкритого або інтервального типу" виключити.

2.3. У абзаці першому пункту 7 літери "е", "є", "ж" виключити.

3. У тексті Положення ( z0072-02 ) слова "статутний капітал" у всіх відмінках замінити словами "статутний (складений) капітал" у відповідних відмінках.

4. У додатку 3 назву заяви після слів "сертифікатів фонду"

доповнити словами "_____________________________________________". (спосіб розміщення інвестиційних сертифікатів)

5. У додатку 4 назву заяви після слів "свідоцтва про випуск інвестиційних сертифікатів фонду" доповнити словами

"________________________________________________". (спосіб розміщення інвестиційних сертифікатів)

6. У додатку 6:

у назві Звіту про активи фонду відкритого або інтервального типу за попередній рік слова "відкритого або інтервального типу" виключити;

слова "статутному капіталі" замінити словами "статутному (складеному) капіталі".

7. У додатку 7 у назві Звіту про вартість чистих активів фонду відкритого або інтервального типу за попередній рік слова "відкритого або інтервального типу" виключити.
