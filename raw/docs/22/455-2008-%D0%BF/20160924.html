КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 травня 2008 р. N 455 Київ

Про внесення доповнень до постанов Кабінету Міністрів України від 28 серпня 2001 р. N 1119 і від 30 червня 2005 р. N 510

{ Із змінами, внесеними згідно з Постановою КМ N 521 ( 521-2016-п ) від 23.08.2016 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 28 серпня 2001 р. N 1119 ( 1119-2001-п ) "Про внесення змін до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288" (Офіційний вісник України, 2001 р., N 35, ст. 1627; 2003 р., N 45, ст. 2358; 2005 р., N 9, ст. 469, N 27, ст. 1550; 2006 р., N 5, ст. 230; 2007 р., N 79, ст. 2959) і від 30 червня 2005 р. N 510 ( 510-2005-п ) "Про оплату праці керівних працівників державних органів" (Офіційний вісник України, 2005 р, N 27, ст. 1545, N 35, ст. 2118; 2006 р., N 15, ст. 1083; 2007 р., N 1, ст. 28, N 78, ст. 2892) доповнення, що додаються.
