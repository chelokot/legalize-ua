{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 405/5 ( z0680-07 ) від 20.06.2007 }

Про затвердження тарифів за надання додаткових послуг правового та технічного характеру в Лівобережному відділі реєстрації шлюбів м. Києва з Державним центром розвитку сім'ї

Відповідно до статей 6, 17 Закону України "Про органи реєстрації актів громадянського стану" ( 3807-12 ) та постанови Кабінету Міністрів України від 17 серпня 2002 року N 1136 ( 1136-2002-п ) "Про забезпечення дотримання законодавства під час надання послуг іноземцям та особам без громадянства" НАКАЗУЮ:

1. Затвердити тарифи за надання додаткових послуг правового та технічного характеру в Лівобережному відділі реєстрації шлюбів м. Києва з Державним центром розвитку сім'ї, що додаються, та ввести їх у дію з 10.01.2003.

2. Визнати таким, що втратив чинність, наказ Міністерства юстиції України від 08.04.97 N 34/5 ( z0158-97 ) "Про затвердження тарифів за надання додаткових послуг правового та технічного характеру в Лівобережному відділі реєстрації шлюбів м. Києва з Філією Державного Центру розвитку сім'ї", зареєстрований у Міністерстві юстиції 24.04.97 за N 158/1962.

3. Контроль за виконанням цього наказу покласти на заступника Державного секретаря Міністерства юстиції України Єфіменка Л.В.

Міністр О.В.Лавринович
