19.12.2011 N 38-1

Зареєстровано в Міністерстві юстиції України 13 січня 2012 р. за N 35/20348

Про внесення змін до постанови правління Пенсійного фонду України від 31.08.2009 N 21-2

Відповідно до Указу Президента України від 09.12.2010 N 1085 ( 1085/2010 ) "Про оптимізацію системи центральних органів виконавчої влади" та пунктів 9, 11 Положення про Пенсійний фонд України, затвердженого Указом Президента України від 06.04.2011 N 384 ( 384/2011 ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Унести до постанови правління Пенсійного фонду України від 31.08.2009 N 21-2 ( z0897-09 ) "Про затвердження Порядку розроблення, затвердження та виконання бюджету Пенсійного фонду України", зареєстрованої в Міністерстві юстиції України 23.09.2009 за N 897/16913, такі зміни:

у преамбулі слова та цифри "пункту 12 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261" замінити словами та цифрами "пункту 11 Положення про Пенсійний фонд України, затвердженого Указом Президента України від 06.04.2011 N 384 ( 384/2011 )".

2. Затвердити Зміни до Порядку розроблення, затвердження та виконання бюджету Пенсійного фонду України, затвердженого постановою правління Пенсійного фонду України від 31.08.2009 N 21-2 ( z0897-09 ), зареєстрованого в Міністерстві юстиції України 23.09.2009 за N 897/16913, що додаються.

3. Юридичному управлінню Пенсійного фонду України (Рябцева Т.Б.) подати цю постанову на державну реєстрацію до Міністерства юстиції України.

4. Ця постанова набирає чинності з дня її офіційного опублікування.

5. Контроль за виконанням цієї постанови покласти на першого заступника Голови правління Пенсійного фонду України Кравчука В.О.

ЗАТВЕРДЖЕНО Постанова правління Пенсійного фонду України 19.12.2011 N 38-1

Зареєстровано в Міністерстві юстиції України 13 січня 2012 р. за N 35/20348

ЗМІНИ до Порядку розроблення, затвердження та виконання бюджету Пенсійного фонду України, затвердженого постановою правління Пенсійного фонду України від 31.08.2009 N 21-2 ( z0897-09 ), зареєстрованого в Міністерстві юстиції України 23.09.2009 за N 897/16913

1. У пункті 1.4 розділу I слова та цифри "Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261" замінити словами та цифрами "Положення про Пенсійний фонд України, затвердженого Указом Президента України від 06.04.2011 N 384 ( 384/2011 )".

2. У розділі II:

у пункті 2.1:

у підпункті 2.1.9:

в абзаці першому слова та цифри "у редакції постанови Кабінету Міністрів України від 08.07.2009 N 712" замінити словами та цифрами "у редакції постанови Кабінету Міністрів України від 09.11.2011 N 1156 ( 1156-2011-п )";

в абзаці другому слова "Міністру праці та соціальної політики" замінити словами "Віце-прем'єр-міністру України - Міністру соціальної політики";

в абзаці першому підпункту 2.1.10 слова "департамент зведеного бюджету Пенсійного фонду" замінити словами "структурний підрозділ Пенсійного фонду, відповідальний за процес формування бюджету Пенсійного фонду";

у пункті 2.3:

у підпункті 2.3.6 слова "до Міністерства фінансів України" замінити словами "головному розпоряднику коштів Державного бюджету України, які передаються на фінансування пенсійних програм";

у підпункті 2.3.7 слова "Міністерством фінансів України" замінити словами "головним розпорядником коштів Державного бюджету України, які передаються на фінансування пенсійних програм".

3. У розділі III:

підпункт 3.3.4 пункту 3.3 виключити.

У зв'язку з цим підпункт 3.3.5 цього пункту вважати підпунктом 3.3.4 цього пункту;

у підпункті 3.4.2 пункту 3.4 слова "Державного казначейства України" замінити словами "Державної казначейської служби України", слова "праці та" виключити.
