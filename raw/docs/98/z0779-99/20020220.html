Держдепартамент вик.покарань, МВС України; Наказ, Інструкція від 17.07.1999 № 91/565

Про затвердження: Тимчасової інструкції про порядок виконання кримінального покарання у вигляді виправних робіт без позбавлення волі; Тимчасової інструкції про організацію роботи органів внутрішніх справ та органів виконання покарань, що не пов'язані з позбавленням волі, щодо контролю за поведінкою осіб, які засуджені до позбавлення волі умовно, з іспитовим строком або з відстрочкою виконання вироку; Тимчасової інструкції про порядок виконання кримінального покарання у вигляді позбавлення права займати певні посади або займатись певною діяльністю

Реєстрація: Мін'юст України від 11.11.1999 № 779/4072

Стан: Втратив чинність

Ідентифікатор: z0779-99

Текст документа від 20.02.2002:

ДЕРЖАВНИЙ ДЕПАРТАМЕНТ УКРАЇНИ З ПИТАНЬ ВИКОНАННЯ ПОКАРАНЬ МІНІСТЕРСТВО ВНУТРІШНІХ СПРАВ УКРАЇНИ

НАКАЗ

N 91/565 від 17.07.99 Зареєстровано в Міністерстві м.Київ юстиції України 11 листопада 1999 р. vd990717 vn91/565 за N 779/4072

Про затвердження: Тимчасової інструкції про порядок виконання кримінального покарання у вигляді виправних робіт без позбавлення волі; Тимчасової інструкції про організацію роботи органів внутрішніх справ та органів виконання покарань, що не пов'язані з позбавленням волі, щодо контролю за поведінкою осіб, які засуджені до позбавлення волі умовно, з іспитовим строком або з відстрочкою виконання вироку; Тимчасової інструкції про порядок виконання кримінального покарання у вигляді позбавлення права займати певні посади або займатись певною діяльністю

( Із змінами, внесеними згідно з Наказом Державного департаменту України з питань виконання покарань N 3/4 ( z0168-02 ) від 03.01.2002 )

Відповідно до Указу Президента України від 12 березня 1999 р. N 248/99 "Про виведення Державного департаменту України з питань виконання покарань з підпорядкування Міністерству внутрішніх справ України" та у зв'язку з тим, що питання контролю за засудженими умовно, а також з відстрочкою виконання вироку не врегульовано, та беручи до уваги актуальність завдань, покладених на органи виконання покарань, що не пов'язані з позбавленням волі, НАКАЗУЄМО:

1. Затвердити:

( Пункт 1.1 втратив чинність на підставі Наказу Державного департаменту України з питань виконання покарань N 3/4 ( z0168-02 ) від 03.01.2002 )

( Пункт 1.2 втратив чинність на підставі Наказу Державного департаменту України з питань виконання покарань N 3/4 ( z0168-02 ) від 03.01.2002 )

1.3. Тимчасову інструкцію про порядок виконання кримінального покарання у вигляді позбавлення права займати певні посади або займатися певною діяльністю ( z0780-99 ).

2. Начальникам управлінь та відділів Державного департаменту України з питань виконання покарань у Автономній Республіці Крим та областях, ГУМВС України у Автономній Республіці Крим, місті Києві та Київській області, УМВС України в областях, м.Севастополі - забезпечити вивчення інструкцій працівниками органів виконання покарань та відповідними службами органів внутрішніх справ і прийняти від них заліки.

3. Визнати таким, що втратив чинність, наказ МВС України від 3 березня 1992 р. N 52.

Директор Державного департаменту України з питань виконання покарань генерал-лейтенант внутрішньої служби І.В.Штанько

Міністр внутрішніх справ України генерал внутрішньої служби Ю.Ф.Кравченко

( Тимчасова інструкція про порядок виконання кримінального покарання у вигляді виправних робіт без позбавлення волі втратила чинність на підставі Наказу Державного департаменту України з питань виконання покарань N 3/4 ( z0168-02 ) від 03.01.2002 )
