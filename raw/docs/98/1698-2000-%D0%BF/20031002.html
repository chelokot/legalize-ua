Про затвердження переліку органів ліцензування

( Із змінами, внесеними згідно з Постановами КМ N 410 ( 410-2001-п ) від 28.04.2001 N 832 ( 832-2001-п ) від 11.07.2001 N 940 ( 940-2001-п ) від 07.08.2001 N 639 ( 639-2002-п ) від 17.05.2002 N 717 ( 717-2002-п ) від 01.06.2002 N 730 ( 730-2002-п ) від 01.06.2002 N 907 ( 907-2002-п ) від 01.07.2002 N 1068 ( 1068-2002-п ) від 25.07.2002 N 204 ( 204-2003-п ) від 24.02.2003 N 717 ( 717-2003-п ) від 15.05.2003 N 797 ( 797-2003-п ) від 02.06.2003 N 871 ( 871-2003-п ) від 04.06.2003 N 873 ( 873-2003-п ) від 04.06.2003 N 990 ( 990-2003-п ) від 27.06.2003 N 1146 ( 1146-2003-п ) від 24.07.2003 N 1548 ( 1548-2003-п ) від 02.10.2003 )

Відповідно до Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ) Кабінет Міністрів України постановляє:

1. Затвердити перелік органів ліцензування, що додається.

2. Органам ліцензування разом з Державним комітетом з питань регуляторної політики та підприємництва затвердити у місячний термін ліцензійні умови провадження господарської діяльності за видами, зазначеними у затвердженому цією постановою переліку.

3. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.
