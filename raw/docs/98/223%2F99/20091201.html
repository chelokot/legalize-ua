УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 924/2009 ( 924/2009 ) від 12.11.2009 }

Про внесення змін до Указу Президента України від 3 грудня 1995 року N 1129

Внести до Указу Президента України від 3 грудня 1995 року N 1129 ( 1129/95 ) (зі змінами, внесеними Указом від 3 березня 1997 року N 201 ( 201/97 ) такі зміни:

1. Увести до складу Національної ради з питань молодіжної політики при Президентові України МЕДВЕДЧУКА Віктора Володимировича - заступника Голови Верховної Ради України (за згодою).

2. Призначити МЕДВЕДЧУКА Віктора Володимировича Головою Національної ради з питань молодіжної політики при Президентові України (за згодою), звільнивши від цих обов'язків Кушнарьова Є.П.

Президент України Л.КУЧМА
