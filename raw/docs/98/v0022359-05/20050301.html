25.01.2005 N 22

( Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 52 ( v0052359-05 ) від 01.03.2005 )

Про штатні розписи Центральної виборчої комісії та автогосподарства Центральної виборчої комісії

Відповідно до постанов Кабінету Міністрів України від 15 січня 2005 року N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 року посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери", від 15 січня 2005 року N 37 ( 37-2005-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів", від 13 грудня 1999 року N 2288 ( 2288-99-п ) "Про впорядкування умов оплати праці працівників апарату органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів" та постанови Центральної виборчої комісії від 6 серпня 2004 року N 332 ( v0332359-04 ) "Про структуру і чисельність Секретаріату Центральної виборчої комісії та автогосподарства Центральної виборчої комісії", наказу Міністерства праці України від 2 жовтня 1996 року N 77 ( z0593-96 ) "Про умови оплати праці робітників, зайнятих обслуговуванням органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів" та Угоди між Міністерством транспорту України і профспілками працівників автомобільного транспорту України по галузі автомобільного транспорту на 2002-2003 роки із змінами та доповненнями, керуючись частиною третьою статті 6, статтями 12, 13, 33, 35, частиною першою статті 36, частиною першою статті 37 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Ввести з 1 січня 2005 року штатні розписи Центральної виборчої комісії та автогосподарства Центральної виборчої комісії (додатки 1, 2)*.

2. Постанову Центральної виборчої комісії від 11 січня 2005 року N 17 ( v0017359-05 ) "Про штатні розписи Центральної виборчої комісії та автогосподарства Центральної виборчої комісії" вважати такою, що втратила чинність.
