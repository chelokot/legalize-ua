Стан: Чинний

Ідентифікатор: 1060/2007

Текст документа від 02.11.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання такими, що втратили чинність, деяких указів Президента України

1. Визнати такими, що втратили чинність:

Указ Президента України від 21 лютого 2001 року N 107 ( 107/2001 ) "Про посади в органах виконавчої влади та інших цивільних установах, які можуть бути заміщені особами вищого офіцерського (начальницького) складу";

Указ Президента України від 29 жовтня 2003 року N 1226 ( 1226/2003 ) "Про внесення змін до Указу Президента України від 21 лютого 2001 року N 107";

Указ Президента України від 17 вересня 2004 року N 1099 ( 1099/2004 ) "Про внесення зміни до Указу Президента України від 29 жовтня 2003 року N 1226";

Указ Президента України від 13 грудня 2004 року N 1475 ( 1475/2004 ) "Про внесення зміни до Указу Президента України від 29 жовтня 2003 року N 1226";

Указ Президента України від 18 березня 2005 року N 491 ( 491/2005 ) "Про внесення змін до Указу Президента України від 29 жовтня 2003 року N 1226";

Указ Президента України від 9 жовтня 2006 року N 824 ( 824/2006 ) "Про внесення зміни до Указу Президента України від 29 жовтня 2003 року N 1226";

Указ Президента України від 23 травня 2007 року N 462 ( 462/2007 ) "Про внесення зміни до Указу Президента України від 29 жовтня 2003 року N 1226";

Указ Президента України від 20 червня 2007 року N 547 ( 547/2007 ) "Про внесення змін до Указу Президента України від 29 жовтня 2003 року N 1226";

Указ Президента України від 21 серпня 2007 року N 756 ( 756/2007 ) "Про внесення зміни до Указу Президента України від 29 жовтня 2003 року N 1226";

Указ Президента України від 17 вересня 2007 року N 880 ( 880/2007 ) "Про внесення зміни до Указу Президента України від 29 жовтня 2003 року N 1226".

2. Кабінету Міністрів України привести свої рішення у відповідність із цим Указом.

3. Керівникам центральних органів виконавчої влади, інших державних органів, установ і організацій повернути з відряджень осіб вищого начальницького складу, які займають посади в органах виконавчої влади та інших цивільних установах, до правоохоронних органів, в яких їх залишено на службі.

Президент України В.ЮЩЕНКО
