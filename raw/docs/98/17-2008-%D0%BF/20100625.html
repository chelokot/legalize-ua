Кабінет Міністрів України; Постанова від 16.01.2008 № 17

Про вилучення із статутного фонду Державної акціонерної компанії "Україна туристична" пакетів акцій відкритих акціонерних товариств

Стан: Чинний

Ідентифікатор: 17-2008-п

Текст документа від 25.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 січня 2008 р. N 17 Київ

Про вилучення із статутного фонду Державної акціонерної компанії "Україна туристична" пакетів акцій відкритих акціонерних товариств

{ Із змінами, внесеними згідно з Постановою КМ N 456 ( 456-2010-п ) від 16.06.2010 }

Кабінет Міністрів України постановляє:

1. Фонду державного майна вжити заходів до вилучення в установленому порядку із статутного фонду Державної акціонерної компанії "Україна туристична" пакета акцій відкритого акціонерного товариства "Готельний комплекс "Братислава-Десна", правонаступником якого є відкрите акціонерне товариство "Готельний комплекс "Братислава", у розмірі 51 відсотка його статутного фонду. { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 456 ( 456-2010-п ) від 16.06.2010 }

У зв'язку з цим у додатку 2 до постанови Кабінету Міністрів України від 20 липня 1999 р. N 1290 ( 1290-99-п ) "Про утворення Державної акціонерної компанії "Україна туристична" (Офіційний вісник України, 1999 р., N 29, ст. 1487) позицію другу виключити. { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 456 ( 456-2010-п ) від 16.06.2010 }

2. Міністерству культури і туризму разом з Фондом державного майна вжити у разі потреби заходів для внесення відповідних змін до Статуту Державної акціонерної компанії "Україна туристична".

3. Фонду державного майна забезпечити в установленому порядку продаж вилученого згідно з пунктом 1 цієї постанови пакета акцій відкритого акціонерного товариства "Готельний комплекс "Братислава" разом із земельною ділянкою, на якій він розташований, за конкурсом з використанням відкритості пропонування ціни за принципом аукціону.

{ Пункт 3 в редакції Постанови КМ N 456 ( 456-2010-п ) від 16.06.2010 }
