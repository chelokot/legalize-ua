Текст документа від 11.09.2005:

ДЕРЖАВНИЙ КОМІТЕТ РИБНОГО ГОСПОДАРСТВА УКРАЇНИ

НАКАЗ

N 126 від 21.09.98 Зареєстровано в Міністерстві м.Київ юстиції України 19 листопада 1998 р. за N 735/3175

( Наказ втратив чинність на підставі Наказу Міністерства аграрної політики N 413 ( z0959-05 ) від 23.08.2005 )

Про затвердження Інструкції про порядок проведення робіт з відтворення водних живих ресурсів

( Із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 215 ( z1142-04 ) від 08.06.2004 )

Відповідно до постанови Кабінету Міністрів України від 28.09.96 N 1192 ( 1192-96-п ) "Про затвердження Тимчасового порядку ведення рибного господарства і здійснення рибальства", а також з метою удосконалення управління в галузі охорони і відтворення водних живих ресурсів НАКАЗУЮ:

1. Затвердити Інструкцію про порядок проведення робіт з відтворення водних живих ресурсів (додається).

2. "Временную инструкцию о порядке учета рыбоводной продукции, выпускаемой предприятиями Минрыбхоза СССР в естественные водоемы и водохранилища", затверджену Мінрибгоспом СРСР 06.02.85, не застосовувати на території України.

3. Управлінню справами (В.М.Денисяко) довести цю Інструкцію до відома всіх структурних підрозділів Держкомрибгоспу та заінтересованих міністерств, відомств, установ, підприємств, організацій.

4. Контроль за виконанням даного наказу покласти на заступника Голови Держкомрибгоспу України О.М.Степаненка.

Голова комітету М.М.Шведенко

( Інструкція про порядок проведення робіт з відтворення водних живих ресурсів втратила чинність на підставі Наказу Міністерства аграрної політики N 215 ( z1142-04 ) від 08.06.2004 )
