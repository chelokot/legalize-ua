УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 706/2005 ( 706/2005 ) від 26.04.2005 )

Про внесення змін до Указу Президента України від 13 грудня 2000 року N 1331

Внести до Указу Президента України від 13 грудня 2000 року N 1331 ( 1331/2000 ) "Про Національну Раду з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування" (із змінами, внесеними Указами від 20 грудня 2000 року N 1354 ( 1354/2000 ), від 13 лютого 2001 року N 90 ( 90/2001 ) та від 5 березня 2001 року N 148 ( 148/2001 ) такі зміни:

1) увести до складу Національної Ради з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування таких осіб: ГЛАДІЯ Михайла Васильовича - голову Львівської обласної державної адміністрації, КАРТАШОВА Євгена Григоровича - голову Запорізької обласної державної адміністрації та СМИРНОВА Юрія Олександровича - Міністра внутрішніх справ України, вивівши зі складу Ради Кравченка Ю.Ф. і Пеньковського В.П.;

2) увести СМИРНОВА Юрія Олександровича до складу Президії Національної Ради з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування, вивівши з її складу Кравченка Ю.Ф.

Президент України Л.КУЧМА

м. Київ, 2 червня 2001 року N 397/2001
