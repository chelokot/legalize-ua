Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 386-2005-п

Текст документа від 26.05.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 травня 2005 р. N 386 Київ

Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України

У зв'язку з прийняттям Закону України "Про внесення змін до Закону України "Про Державний бюджет України на 2005 рік" та деяких інших законодавчих актів України" ( 2505-15 ) Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 травня 2005 р. N 386

ПЕРЕЛІК актів Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 5 серпня 1997 р. N 835 ( 835-97-п ) "Про переліки санаторно-курортних закладів і закладів відпочинку, операції з продажу путівок до яких на санаторно-курортне лікування та відпочинок дітей не підлягають обкладенню податком на додану вартість" (Офіційний вісник України, 1997 р., число 32, с. 12).

2. Розпорядження Кабінету Міністрів України від 24 листопада 1997 р. N 662 ( 662-97-р ) (Офіційний вісник України, 1997 р., число 48, с. 429).

3. Розпорядження Кабінету Міністрів України від 2 березня 1998 р. N 129 ( 129-98-р ) (Офіційний вісник України, 1998 р., N 9, ст. 354).

4. Розпорядження Кабінету Міністрів України від 16 червня 1998 р. N 414 ( 414-98-р ) (Офіційний вісник України, 1998 р., N 24, ст. 894).

5. Розпорядження Кабінету Міністрів України від 27 червня 1998 р. N 456 ( 456-98-р ) (Офіційний вісник України, 1998 р., N 26, ст. 958).

6. Розпорядження Кабінету Міністрів України від 10 липня 1998 р. N 553 ( 553-98-р ) (Офіційний вісник України, 1998 р., N 28, ст. 1064).

7. Розпорядження Кабінету Міністрів України від 17 серпня 1998 р. N 676 ( 676-98-р ) (Офіційний вісник України, 1998 р., N 33, ст. 1260).

8. Пункт 3 постанови Кабінету Міністрів України від 22 березня 1999 р. N 430 ( 430-99-п ) "Про утворення Національного центру здоров'я" (Офіційний вісник України, 1999 р., N 12, ст. 475).

9. Розпорядження Кабінету Міністрів України від 15 вересня 1999 р. N 965 ( 965-99-р ) (Офіційний вісник України, 1999 р., N 37, ст. 1871).

10. Постанова Кабінету Міністрів України від 13 грудня 2001 р. N 1654 ( 1654-2001-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 22 березня 1999 р. N 430" (Офіційний вісник України, 2001 р., N 50, ст. 2234).
