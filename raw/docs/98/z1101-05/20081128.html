НАКАЗ Міністра оборони України

21.09.2005 N 566

Зареєстровано в Міністерстві юстиції України 26 вересня 2005 р. за N 1101/11381

{ Наказ втратив чинність на підставі Наказу Міністерства оборони N 402 ( z1109-08 ) від 14.08.2008 }

Про внесення змін до наказу Міністра оборони України від 04.01.94 N 2

Згідно з Розпорядженням Президента України від 16 травня 2005 року N 1043/2005-рп ( 1043/2005-рп ) "Про заходи щодо переходу підрозділів Збройних Сил України до комплектування військовослужбовцями за контрактом" НАКАЗУЮ:

1. Унести до Положення про військово-лікарську експертизу та медичний огляд у Збройних Силах України, затвердженого наказом Міністра оборони України від 4 січня 1994 року N 2 ( z0177-94 ), зареєстрованого в Міністерстві юстиції України 29 липня 1994 року за N 177/386 (із змінами), такі зміни:

рядки 2, 3 графи 3 таблиці пункту 77 розділу II викласти в такій редакції: "ВЛК військових комісаріатів, гарнізонні, госпітальні ВЛК".

2. Наказ розіслати до окремої військової частини.

Міністр оборони України А.С.Гриценко
