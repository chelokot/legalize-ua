НАКАЗ

N 121 від 09.06.98 Зареєстровано в Міністерстві м.Київ юстиції України 26 червня 1998 р. vd980609 vn121 за N 399/2839

{ Наказ втратив чинність на підставі Наказу Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 327 ( z1216-12 ) від 02.07.2012 }

Про затвердження Інструкції про порядок державної реєстрації права власності на об'єкти нерухомого майна, що перебувають у власності юридичних та фізичних осіб

( Із змінами, внесеними згідно з Наказами Держбуду N 251 ( z0755-99 ) від 18.10.99 N 8 ( z0036-01 ) від 09.01.2001 N 86 ( z0395-01 ) від 04.04.2001 N 36 ( z0209-02 ) від 15.02.2002 )

Указом Президента України від 09.12.97 N 1342/97 затверджено Положення про Державний комітет будівництва, архітектури та житлової політики України, яким на Комітет покладено здійснення функцій координації і нормативно-методичного забезпечення діяльності бюро технічної інвентаризації та впровадження системи державної реєстрації права власності на нерухоме майно, у зв'язку з чим НАКАЗУЮ:

1. Затвердити Інструкцію про порядок державної реєстрації права власності на об'єкти нерухомого майна, що перебувають у власності юридичних та фізичних осіб (додається).

2. Правила державної реєстрації об'єктів нерухомого майна, що знаходяться у власності юридичних та фізичних осіб, затверджені Держжитлокомунгоспом України від 13.12.95 N 56 ( z0031-96 ) і зареєстровані Міністерством юстиції України 19.01.96 N 31/1056, вважати такими, що втратили чинність.

3. Українській асоціації "Центральне бюро технічної інвентаризації" (Кошер А.Ю.) видати Інструкцію про порядок державної реєстрації права власності на об'єкти нерухомого майна, що перебувають у власності юридичних та фізичних осіб.

4. Контроль за виконанням наказу покласти на Управління житлової політики (Чернявський В.П.).

Голова Комітету В.М.Гусаков

( Інструкція про порядок державної реєстрації права власності на об'єкти нерухомого майна, що перебувають у власності юридичних та фізичних осіб втратила чинність на підставі Наказу Держбуду N 36 ( z0209-02 ) від 15.02.2002 )
