Текст документа від 17.06.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 грудня 1997 р. N 1495 Київ

Про внесення доповнень до деяких постанов Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 601 ( 601-2011-п ) від 09.06.2011 }

Кабінет Міністрів України постановляє:

1. Доповнити пункт 1 постанови Кабінету Міністрів України від 12 серпня 1996 р. N 938 ( 938-96-п ) "Про подальше посилення контролю за ввезенням, вивезенням та переміщенням транзитом через територію України алкогольних напоїв і тютюнових виробів, на які встановлено акцизний збір" (ЗП України, 1996 р., N 16, ст. 443) після слів "тютюнові вироби" словами та цифрами "за кодами згідно з ГС 22.03 00, 22.04-22.08, 24.02 10000, 24.02 20000, 24.03 10000, 24.03 99100".

2. Доповнити пункт 1 постанови Кабінету Міністрів України 14 серпня 1996 р. N 953 ( 953-96-п ) "Про заходи щодо посилення контролю за ввезенням в Україну алкогольних напоїв та тютюнових виробів, що імпортуються суб'єктами підприємницької діяльності" (ЗП України, 1997 р., N 16, ст. 450) після слів "тютюнових виробів" словами та цифрами "за кодами згідно з ГС 22.03 00, 22.04-22.08, 24.02 10000, 24.02 20000, 24.03 10000, 24.03 99100".

{ Пункт 3 втратив чинність на підставі Постанови КМ N 601 ( 601-2011-п ) від 09.06.2011 }

4. Ця постанова набирає чинності з дня її опублікування.
