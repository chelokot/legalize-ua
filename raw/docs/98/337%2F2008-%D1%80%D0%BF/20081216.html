Президент України; Розпорядження від 16.12.2008 № 337/2008-рп

Про призначення грантів Президента України для випускників професійно-технічних навчальних закладів на 2009 рік

Стан: Чинний

Ідентифікатор: 337/2008-рп

Текст документа від 16.12.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про призначення грантів Президента України для випускників професійно-технічних навчальних закладів на 2009 рік

Відповідно до Указів Президента України від 18 вересня 2004 року N 1102 ( 1102/2004 ) та від 28 грудня 2004 року N 1561 ( 1561/2004 ) призначити на 2009 рік гранти Президента України для випускників професійно-технічних навчальних закладів:

БІЛОМУ Сергію Олександровичу - випускнику вищого професійного училища N 36 с. Балин Хмельницької області для реалізації проекту "Технологія вирощування гречки в післяукісних посівах в умовах південно-західного лісостепу України"

ГОРОБЦЮ Юрію Сергійовичу - випускнику Грицівського вищого професійного училища N 38 Хмельницької області для реалізації проекту "Розведення шиншил"

ЦИЦАРКОВСЬКОМУ Сергію Петровичу - випускнику Снігурівського професійного ліцею Миколаївської області для реалізації проекту "Інтенсивна технологія вирощування озимого ріпаку".

Президент України В.ЮЩЕНКО

м. Київ, 16 грудня 2008 року N 337/2008-рп
