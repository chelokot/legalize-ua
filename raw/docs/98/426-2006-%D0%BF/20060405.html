Про використання у 2006 році коштів державного бюджету в інформаційній сфері

Стан: Чинний

Ідентифікатор: 426-2006-п

Текст документа від 05.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 квітня 2006 р. N 426 Київ

Про використання у 2006 році коштів державного бюджету в інформаційній сфері

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Установити, що кошти, передбачені у державному бюджеті ( 3235-15 ), використовуються:

за програмою "Технічне переоснащення обласних державних телерадіокомпаній" - відповідно до постанови Кабінету Міністрів України від 9 серпня 2005 р. N 717 ( 717-2005-п ) "Про затвердження Порядку використання у 2005 році коштів державного бюджету для технічного переоснащення обласних державних телерадіокомпаній" (Офіційний вісник України, 2005 р., N 32, ст. 1932);

за програмою "Випуск книжкової продукції за програмою "Українська книга" - відповідно до постанови Кабінету Міністрів України від 18 серпня 2005 р. N 761 ( 761-2005-п ) "Про затвердження Порядку використання коштів державного бюджету для випуску книжкової продукції за програмою "Українська книга" (Офіційний вісник України, 2005 р., N 34, ст. 2043);

за програмою "Фінансова підтримка творчих спілок у сфері засобів масової інформації" - відповідно до постанови Кабінету Міністрів України від 18 серпня 2005 р. N 778 ( 778-2005-п ) "Про порядок використання коштів державного бюджету для фінансової підтримки творчих спілок у сфері засобів масової інформації" (Офіційний вісник України, 2005 р., N 34, ст. 2053);

за програмою "Трансляція телерадіопрограм, вироблених для державних потреб" - відповідно до постанови Кабінету Міністрів України від 18 серпня 2005 р. N 779 ( 779-2005-п ) "Про порядок використання коштів державного бюджету для трансляції телерадіопрограм, вироблених для державних потреб" (Офіційний вісник України, 2005 р., N 34, ст. 2054);

за програмою "Фінансова підтримка преси" - відповідно до постанови Кабінету Міністрів України від 31 серпня 2005 р. N 843 ( 843-2005-п ) "Про порядок використання коштів державного бюджету на фінансову підтримку преси" (Офіційний вісник України, 2005 р., N 36, ст. 2184);

за програмою "Інформаційне та організаційне забезпечення участі України у міжнародних форумах, конференціях, виставках" - відповідно до постанови Кабінету Міністрів України від 31 серпня 2005 р. N 847 ( 847-2005-п ) "Про порядок використання коштів державного бюджету для інформаційного та організаційного забезпечення участі України у міжнародних форумах, конференціях і виставках" (Офіційний вісник України, 2005 р., N 36, ст. 2188);

за програмою "Збирання, обробка та розповсюдження офіційної інформаційної продукції" - відповідно до постанови Кабінету Міністрів України від 12 вересня 2005 р. N 883 ( 883-2005-п ) "Про використання коштів державного бюджету для збирання, обробки та розповсюдження офіційної інформаційної продукції" (Офіційний вісник України, 2005 р., N 37, ст. 2281).
