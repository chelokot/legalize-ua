( Наказ втратив чинність на підставі Наказу Міністерства культури і туризму N 783 ( z1354-05 ) від 31.10.2005 )

Про внесення змін до наказу Міністерства культури і мистецтв України від 19.04.2001 N 205

Відповідно до постанови Кабінету Міністрів України від 19.05.2003 N 740 ( 740-2003-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів і організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства культури і мистецтв України від 19.04.2001 N 205 ( z0365-01 ) "Про впорядкування умов оплати праці працівників бюджетних науково-дослідних установ Міністерства культури і мистецтв України", зареєстрованого в Міністерстві юстиції України 24.04.2001 за N 365/5556 (із змінами, унесеними наказом Міністерства культури і мистецтв України від 07.02.2002 N 68 ( z0143-02 ), зареєстрованим в Міністерстві юстиції України 13.02.2002 за N 143/6431), виклавши додатки 1-7 у новій редакції, що додаються.

2. Керівникам науково-дослідних бюджетних установ у межах затвердженого фонду заробітної плати встановити працівникам посадові оклади (ставки заробітної плати) виходячи з розмірів та у терміни, передбачені додатками 1-7.

3. Контроль за виконанням наказу покласти на заступника Державного секретаря І.В. Ніколайка.

Міністр Ю.П.Богуцький
