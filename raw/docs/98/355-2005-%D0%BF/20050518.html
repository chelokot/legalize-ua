Про скасування додаткового збору за митне оформлення нафтопродуктів

Стан: Чинний

Ідентифікатор: 355-2005-п

Текст документа від 18.05.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 травня 2005 р. N 355 Київ

Про скасування додаткового збору за митне оформлення нафтопродуктів

Кабінет Міністрів України постановляє:

1. Скасувати додатковий збір за митне оформлення нафтопродуктів, що імпортуються на митну територію України і підлягають обкладенню акцизним збором.

У зв'язку з цим:

визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 18 вересня 1998 р. N 1460 ( 1460-98-п ) "Про внесення доповнення до постанови Кабінету Міністрів України від 27 січня 1997 р. N 65" (Офіційний вісник України, 1998 р., N 38, ст. 1392);

пункт 5 переліку постанов Кабінету Міністрів України, що втратили чинність, затвердженого постановою Кабінету Міністрів України від 18 січня 2003 р. N 93 ( 93-2003-п ) "Про справляння плати за митне оформлення товарів і транспортних засобів поза місцем розташування митних органів або поза робочим часом, установленим для митних органів" (Офіційний вісник України, 2003 р., N 4, ст. 139), та абзац третій пункту 1 постанови Кабінету Міністрів України від 27 січня 1997 р. N 65 ( 65-97-п ) "Про ставки митних зборів" - (із змінами, внесеними постановами Кабінету Міністрів України від 13 травня 1998 р., N 670 ( 670-98-п ) (Офіційний вісник України, 1998 р., N 38, ст. 1392), від 19 травня 1999 р. N 840 ( 840-99-п ) (Офіційний вісник України, 1999 р., N 20, ст. 893), від 5 липня 1999 р. N 1187 ( 1187-99-п ) (Офіційний вісник України, 1999 р., N 27, ст. 1332) та від 28 квітня 2001 р. N 413 ( 413-2001-п ) (Офіційний вісник України, 2001 р., N 18, ст. 791) виключити.

2. Ця постанова набирає чинності з дня опублікування.
