Кабінет Міністрів України; Розпорядження від 19.11.2007 № 999-р

Про виділення додаткових коштів для проведення першочергових робіт з ліквідації наслідків аварії, що сталася 18 листопада 2007 р. на орендному підприємстві "Шахта імені О.Ф. Засядька"

Стан: Чинний

Ідентифікатор: 999-2007-р

Текст документа від 23.01.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 листопада 2007 року N 999-р Київ

Про виділення додаткових коштів для проведення першочергових робіт з ліквідації наслідків аварії, що сталася 18 листопада 2007 р. на орендному підприємстві "Шахта імені О.Ф. Засядька"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 92-р ( 92-2008-р ) від 23.01.2008 }

1. На додаток до розпорядження Кабінету Міністрів України від 18 листопада 2007 р. N 998 ( 998-2007-р ) виділити додатково Донецькій облдержадміністрації 4 млн. гривень для проведення першочергових робіт з ліквідації наслідків аварії, що сталася 18 листопада 2007 р. на орендному підприємстві "Шахта імені О.Ф.Засядька", на умовах повернення та 3,5 млн. гривень для надання допомоги потерпілим та сім'ям загиблих. { Абзац перший пункту 1 в редакції Розпорядження КМ N 92-р ( 92-2008-р ) від 23.01.2008 }

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 489-16 ).

2. Донецькій облдержадміністрації:

затвердити у тижневий строк за погодженням з Мінекономіки, Мінфіном і Мінрегіонбудом перелік витрат, пов'язаних з проведенням першочергових робіт з ліквідації наслідків аварії і наданням допомоги потерпілим та сім'ям загиблих;

подати до кінця грудня поточного року Мінекономіки, Мінфіну, Мінрегіонбуду та Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням;

забезпечити повернення до 1 липня 2008 р. зазначених коштів до державного бюджету. { Пункт 2 доповнено абзацом згідно з Розпорядженням КМ N 92-р ( 92-2008-р ) від 23.01.2008 }
