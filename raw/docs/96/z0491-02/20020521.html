N 95/454 від 21.05.2002 Зареєстровано в Міністерстві м.Київ юстиції України 11 червня 2002 р. за N 491/6779

Про умови оплати праці начальницького складу Держфельдслужби України при Державному комітеті зв'язку та інформатизації

На виконання Указу Президента України від 4 жовтня 1996 року N 926/96 ( 926/96 ) "Про умови грошового забезпечення осіб рядового і начальницького складу та оплати праці працівників органів внутрішніх справ" (із змінами, внесеними Указами Президента України від 18 вересня 1998 року N 1036/98 ( 1036/98 ), від 29 січня 1999 року N 98/99 ( 98/99 ), від 16 червня 1999 року N 650/99 ( 650/99 ), від 31 серпня 2001 року N 771/2001 ( 771/2001 ), від 7 листопада 2001 року N 1052/2001 ( 1052/2001 ), від 22 березня 2002 року N 289/2002 ( 289/2002 ) та постанови Кабінету Міністрів України від 8 липня 1999 року N 1223 ( 1223-99-п ) "Про заходи щодо виконання статті 2 Указу Президента України від 16 червня 1999 року N 650" НАКАЗУЄМО :

1. Затвердити схеми посадових окладів осіб начальницького складу Держфельдслужби України згідно з додатками 1, 2.

2. Поширити умови оплати праці, передбачені Указом Президента України від 4 жовтня 1996 року N 926/96 ( 926/96 ) "Про умови грошового забезпечення осіб рядового і начальницького складу та оплати праці працівників органів внутрішніх справ" (із змінами, внесеними Указами Президента України від 18 вересня 1998 року N 1036/98 ( 1036/98 ), від 29 січня 1999 року N 98/99 ( 98/99 ), від 16 червня 1999 року N 650/99 ( 650/99 ), від 31 серпня 2001 року N 771/2001 ( 771/2001 ), від 7 листопада 2001 року N 1052/2001 ( 1052/2001 ), від 22 березня 2002 року N 289/2002 ( 289/2002 ) та постановою Кабінету Міністрів України від 8 липня 1999 року N 1223 ( 1223-99-п ) "Про заходи щодо виконання статті 2 Указу Президента України від 16 червня 1999 року N 650", на начальницький склад Державної фельд'єгерської служби України при Державному комітеті зв'язку та інформатизації України, який перебуває в кадрах Міністерства внутрішніх справ України.

3. Начальнику Головного управління Державної фельд'єгерської служби України:

3.1. У межах затвердженого фонду грошового утримання встановлювати посадові оклади особам начальницького складу, відповідно до розмірів, передбачених додатками 1-2, з урахуванням професійної підготовки осіб, досвіду, результатів оперативно-службової діяльності.

3.2. У межах асигнувань, що виділяються на утримання Держфельдслужби:

3.2.1. Установлювати особам начальницького складу надбавки за особливі умови служби, кваліфікацію, професійний ризик та виконання особливо важливих завдань - до 50 відсотків - персонально, з розрахунку посадового окладу за основною штатною посадою та окладу за спеціальним званням з урахуванням особистого внеску працівника в загальні результати оперативно-службової діяльності.

3.2.2. Установлювати особам начальницького складу, які мають право на пенсію за вислугу років згідно із законодавством і залишені за їхньою згодою та в інтересах справи на службі, - щомісячну доплату в розмірі від 25 до 50 відсотків суми пенсії, яка б могла бути їм нарахована.

3.2.3. Преміювати осіб начальницького складу відповідно до їх особистого вкладу в загальні результати роботи в межах фонду преміювання, створеного в розмірі чотиримісячного фонду грошового забезпечення, без обмеження індивідуальних премій максимальними розмірами.

4. Вважати такими, що втратили чинність, спільний наказ Міністерства внутрішніх справ України та Міністерства зв'язку України від 4 грудня 1996 року N 831/257 ( z0701-96 ) "Про умови оплати праці начальницького складу Держфельдслужби України при Міністерстві зв'язку", зареєстрований у Міністерстві юстиції України 9 грудня 1996 року за N 701/1726, і спільний наказ Міністерства внутрішніх справ України та Державного комітету зв'язку та інформатизації України від 10 серпня 1999 року N 618/42 ( z0563-99 ) "Про заходи щодо виконання статей 2 та 3 Указу Президента від 16 червня 1999 року N 650 та постанови Кабінету Міністрів України від 8 липня 1999 року N 1223 щодо грошового забезпечення осіб рядового і начальницького складу органів внутрішніх справ", зареєстрований в Міністерстві юстиції України 16 серпня 1999 року за N 563/3856.

5. Контроль за виконанням цього наказу покласти на заступника Голови Коляденка В.А.
