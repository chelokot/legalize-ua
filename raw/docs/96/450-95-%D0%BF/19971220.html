ПОСТАНОВА від 23 червня 1995 р. N 450 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1431 ( 1431-97-п ) від 20.12.97 )

Про доповнення постанови Кабінету Міністрів України від 21 січня 1993 р. N 36

Кабінет Міністрів України ПОСТАНОВЛЯЄ:

Доповнити пункт 3 постанови Кабінету Міністрів України від 21 січня 1993 р. N 36 ( 36-93-п ) "Про грошове забезпечення військовослужбовців та умови оплати праці працівників Управління державної охорони" словами: "а також преміювати військовослужбовців Управління відповідно до їхнього особистого вкладу в загальні результати роботи, спрямовуючи для цього кошти у розмірі 0,5 місячного фонду грошового утримання за посадовими окладами на рік, без обмеження індивідуальних премій максимальними розмірами".
