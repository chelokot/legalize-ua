МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

16.01.2006 N 1/5

Зареєстровано в Міністерстві юстиції України 16 січня 2006 р. за N 28/11902

{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 2710/5 ( z1620-15 ) від 22.12.2015 }

Про внесення змін до Положення про умови і порядок проведення тендерів (конкурсів) з визначення спеціалізованих організацій для реалізації арештованого державними виконавцями майна

Відповідно до Законів України "Про державну виконавчу службу" ( 202/98-ВР ) та "Про виконавче провадження" ( 606-14 ) і з метою удосконалення порядку проведення конкурсів (тендерів) з визначення спеціалізованих організацій для реалізації арештованого майна НАКАЗУЮ:

1. У пункті 4.1 Положення про умови і порядок проведення тендерів (конкурсів) з визначення спеціалізованих організацій для реалізації арештованого державними виконавцями майна, затвердженого наказом Міністерства юстиції України від 11 листопада 2003 р. N 136/5 ( z1036-03 ) та зареєстрованого в Мін'юсті України 11 листопада 2003 р. за N 1036/8357 (із змінами і доповненнями), слова "один раз на рік" виключити, а після слів "поточного року" додати слова "або в першому кварталі наступного року", перед прийменником "у" та після слова "року" виключити дужки.

2. Директору Департаменту державної виконавчої служби (О.Р.Кузь):

2.1. Забезпечити державну реєстрацію наказу відповідно до Указу Президента України від 3 жовтня 1992 р. N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами і доповненнями).

2.2. Довести цей наказ до відома начальників державної виконавчої служби Автономної Республіки Крим, областей, міст Києва і Севастополя та забезпечити належне його виконання.

3. Контроль за виконанням наказу покласти на заступника Міністра юстиції України М.М.Шупеню.
