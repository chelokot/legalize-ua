КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 червня 2009 р. N 683 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 324 ( 324-2010-п ) від 28.04.2010 }

Про внесення зміни до пункту 4 постанови Кабінету Міністрів України від 26 листопада 2008 р. N 1036

Кабінет Міністрів України постановляє:

Підпункт 6 пункту 4 постанови Кабінету Міністрів України від 26 листопада 2008 р. N 1036 ( 1036-2008-п ) "Деякі питання організації бюджетного процесу" (Офіційний вісник України, 2008 р., N 92, ст. 3053, N 95, ст. 3133, N 98, ст. 3244, N 100, ст. 3328; 2009 р., N 7, ст. 218, N 11, ст. 338, N 20, ст. 633, N 42, ст. 1407) після слів "реалізації проектів, що підтримуються міжнародними фінансовими організаціями," доповнити словами "та проектів розвитку транспортної інфраструктури відповідно до пунктів 3-5 і 7 додатка 2 до Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженої постановою Кабінету Міністрів України від 22 лютого 2008 р. N 107 ( 107-2008-п ) (Офіційний вісник України, 2008 р., N 18, ст. 482), передбачивши попередню оплату робіт в розмірі не більш як 30 відсотків вартості проекту, але не більш як на 90 днів".

Прем'єр-міністр України Ю.ТИМОШЕНКО
