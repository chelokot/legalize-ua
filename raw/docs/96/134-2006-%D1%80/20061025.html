Про поховання двічі Героя Соціалістичної Праці Буркацької Г.Є.

Стан: Чинний

Текст документа від 25.10.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 березня 2006 р. N 134-р Київ

Про поховання двічі Героя Соціалістичної Праці Буркацької Г.Є.

{ Із змінами, внесеними згідно з Постановою КМ N 1474 ( 1474-2006-п ) від 25.10.2006 }

1. Для організації похорону двічі Героя Соціалістичної Праці Буркацької Галини Євгенівни утворити комісію в складі Крючкова Г.К. (голова комісії), Павлюк Н.А., Анастасієва В.О., Бондаря М.Г., Гайдара М.В., Зайчука В.О., Матвійчука О.М., Стичинського Б.С. і Цибенка П.С.

2. Витрати, пов'язані з похованням Буркацької Г.Є., у сумі 11,942 тис. гривень здійснити за рахунок держави.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1474 ( 1474-2006-п ) від 25.10.2006 }

3. Київській міськдержадміністрації спорудити на могилі Буркацької Г.Є. надгробок вартістю до 8 тис. гривень.

4. Видати одноразову допомогу в сумі 3 тис. гривень дочці Буркацької Г.Є.- Синельник Вірі Василівні.

5. Мінфіну профінансувати зазначені в пунктах 2-4 цього розпорядження витрати Управління справами Апарату Верховної Ради України за рахунок коштів резервного фонду державного бюджету ( 3235-15 ).

6. Управлінню справами Апарату Верховної Ради України подати до кінця 2006 року Мінфіну, Мінекономіки та Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.
