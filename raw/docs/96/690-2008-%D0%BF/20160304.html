{ Постанова втратила чинність на підставі Постанови КМ N 91 ( 91-2016-п ) від 04.02.2016 }

Про внесення зміни у додаток до постанови Кабінету Міністрів України від 23 липня 2008 р. N 680

Кабінет Міністрів України постановляє:

У позиції "Олімпійські ігри (літні, зимові)" розділу "Спортсменам" додатка до постанови Кабінету Міністрів України від 23 липня 2008 р. N 680 ( 680-2008-п ) "Про заохочення спортсменів і тренерів з олімпійських видів спорту" цифри "500000", "350000" і "250000" замінити відповідно цифрами "700000", "500000" і "350000".
