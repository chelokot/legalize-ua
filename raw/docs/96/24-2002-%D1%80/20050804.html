Стан: Втратив чинність

Ідентифікатор: 24-2002-р

Текст документа від 04.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 січня 2002 р. N 24-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 305-р ( 305-2005-р ) від 04.08.2005 )

Про утворення експертно-аналітичної групи для опрацювання пропозицій та заходів стосовно забезпечення умов стабільного функціонування ринку нафти і нафтопродуктів

( Із змінами, внесеними згідно з Розпорядженнями КМ N 124-р ( 124-2003-р ) від 06.03.2003 N 105-р ( 105-2004-р ) від 04.03.2004 N 67-р ( 67-2005-р ) від 28.03.2005 )

1. Для опрацювання пропозицій та заходів стосовно забезпечення умов стабільного функціонування ринку нафти і нафтопродуктів утворити експертно-аналітичну групу (далі - група) у складі згідно з додатком.

2. Дозволити керівникові групи у разі потреби вносити зміни до її складу, залучати до роботи фахівців центральних і місцевих органів виконавчої влади, підприємств, установ та організацій (за погодженням з їх керівниками), одержувати необхідні для роботи документи та матеріали.
