Про внесення змін до наказу Міністерства праці та соціальної політики України від 26.12.2000 N 353

На виконання постанови Кабінету Міністрів України від 11.02.2004 N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 26.12.2000 N 353 ( z0965-00 ) "Про окремі умови оплати праці працівників Національної опери України", зареєстрованого в Міністерстві юстиції України 29.12.2000 за N 965/5186 (зі змінами), виклавши додатки 1-5 у редакції, що додається.

2. Ці зміни застосовуються з 1 березня 2004 року.

Міністр М.Папієв
