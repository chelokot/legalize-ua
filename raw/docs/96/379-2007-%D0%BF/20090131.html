Стан: Чинний

Текст документа від 31.01.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 березня 2007 р. N 379 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для підвищення якості атмосферного повітря

{ Із змінами, внесеними згідно з Постановою КМ N 383 ( 383-2008-п ) від 17.04.2008 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для підвищення якості атмосферного повітря, здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 383 ( 383-2008-п ) від 17.04.2008 }

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для підвищення якості атмосферного повітря.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 6 березня 2007 р. N 379

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для підвищення якості атмосферного повітря

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Мінприроди за програмою "Підвищення якості атмосферного повітря" (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються у межах бюджетних призначень з урахуванням необхідності виконання взятих на облік в органах Державного казначейства бюджетних зобов'язань минулих років у разі їх відповідності паспортові бюджетної програми відповідно до плану природоохоронних заходів, затвердженого Міністром охорони навколишнього природного середовища та погодженого з Міністром фінансів і Віце-прем'єр-міністром України у місячний строк після набрання чинності цим Порядком, на: { Абзац перший пункту 2 в редакції Постанови КМ N 383 ( 383-2008-п ) від 17.04.2008 }

розроблення та виготовлення систем і приладів контролю, оснащення ними стаціонарних джерел викиду забруднюючих речовин в атмосферу та постів контролю і спостереження за забрудненням атмосферного повітря;

проведення робіт з інвентаризації забруднюючих речовин та парникових газів;

створення та ведення кадастрів і реєстрів зазначених речовин та газів;

розроблення нормативів і стандартів у галузі охорони атмосферного повітря та методик розрахунку викидів;

проведення науково-дослідних і дослідно-конструкторських робіт, експертиз проектів спільного впровадження відповідно до положень Кіотського протоколу до Рамкової конвенції ООН про зміну клімату ( 995_801 );

виготовлення, установлення та реконструкція обладнання для очищення газопилового потоку від забруднюючих речовин хімічного та біологічного походження, зниження рівня впливу фізичних і біологічних факторів на атмосферне повітря;

розроблення та впровадження технологій щодо запобігання забрудненню атмосферного повітря.

3. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

{ Абзац перший пункту 3 із змінами, внесеними згідно з Постановою КМ N 383 ( 383-2008-п ) від 17.04.2008 }

Попередня оплата товарів, робіт і послуг провадиться відповідно до постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752).

4. Перерахування бюджетних коштів здійснюється відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

5. Інформація про використання бюджетних коштів їх одержувачами надсилається до Мінприроди щокварталу до 15 числа наступного місяця за формою, встановленою Мінприроди за погодженням з Мінфіном, для узагальнення та подання Мінфіну до 20 числа зазначеного місяця.

6. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим і ефективним витрачанням здійснюються в установленому законодавством порядку.
