Про перелік суб'єктів підприємницької діяльності - виробників ювелірних та побутових виробів з дорогоцінних металів, які мають право на клеймування власних виробів державним пробірним клеймом

Стан: Втратив чинність

Ідентифікатор: 238-98-п

Текст документа від 06.12.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 березня 1998 р. N 238 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1080 ( 1080-2012-п ) від 03.10.2012 }

Про перелік суб'єктів підприємницької діяльності - виробників ювелірних та побутових виробів з дорогоцінних металів, які мають право на клеймування власних виробів державним пробірним клеймом

{ Із змінами, внесеними згідно з Постановою КМ N 157 ( 157-2002-п ) від 15.02.2002 }

Відповідно до частини третьої статті 15 Закону України "Про державне регулювання видобутку, виробництва і використання дорогоцінних металів і дорогоцінного каміння та контроль за операціями з ними" ( 637/97-ВР ) Кабінет Міністрів України постановляє: ( Вступна частина із змінами, внесеними згідно з Постановою КМ N 157 ( 157-2002-п ) від 15.02.2002 )

Затвердити Перелік суб'єктів підприємницької діяльності, що виготовляють ювелірні та побутові вироби з дорогоцінних металів і мають право (за наявності акредитованої у встановленому Державним комітетом по стандартизації, метрології та сертифікації порядку лабораторії) на клеймування виробів власного виробництва державним пробірним клеймом, згідно з додатком.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

Інд. 43

Додаток до постанови Кабінету Міністрів України від 2 березня 1998 р. N 238

ПЕРЕЛІК суб'єктів підприємницької діяльності, що виготовляють ювелірні та побутові вироби з дорогоцінних металів і мають право на клеймування виробів власного виробництва державним пробірним клеймом

1. Львівський державний ювелірний завод

2. Вінницьке державне підприємство "Кристал"

3. Відкрите акціонерне товариство "Київський ювелірний завод", м. Київ

4. Акціонерне товариство "Харківський ювелірний завод"

( Додаток із змінами, внесеними згідно з Постановою КМ N 157 ( 157-2002-п ) від 15.02.2002 )
