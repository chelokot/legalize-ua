УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 338/2008 ( 338/2008 ) від 11.04.2008 }

Про голову Української частини Спільної українсько-узбецької комісії з всебічного співробітництва

1. Призначити ЯНУКОВИЧА Віктора Федоровича - Прем'єр-міністра України - головою Української частини Спільної українсько-узбецької комісії з всебічного співробітництва.

2. Визнати таким, що втратив чинність, Указ Президента України від 10 квітня 2006 року N 299 ( 299/2006 ) "Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва".

Президент України В.ЮЩЕНКО
