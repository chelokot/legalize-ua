Про затвердження переліку товарів належної якості, що не підлягають обміну (поверненню) споживачами (покупцями)

Стан: Втратив чинність

Ідентифікатор: 216-91-п

Текст документа від 19.03.1994:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 вересня 1991 р. N 216 Київ

( Постанова втратила чинність на підставі Постанови КМ N 172 ( 172-94-п ) від 19.03.94 )

Про затвердження переліку товарів належної якості, що не підлягають обміну (поверненню) споживачами (покупцями)

Відповідно до статті 14 Закону УРСР "Про захист прав споживачів" ( 1023-12 ) Кабінет Міністрів України постановляє:

Затвердити перелік товарів належної якості (додається), що не підлягають обміну (поверненню) споживачами (покупцями), якщо товари не задовольняють їх з будь-яких причин.
