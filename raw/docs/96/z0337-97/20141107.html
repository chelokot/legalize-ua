Про затвердження Тимчасового положення про класного керівника середнього закладу освіти

( Із змінами, внесеними згідно з Наказом Міністерства освіти і науки N 434 ( z0659-00 ) від 06.09.2000 )

З метою визначення та підвищення ролі класного керівника у виконанні основних завдань, покладених на середні заклади освіти Законом України "Про освіту" ( 1060-12 ), НАКАЗУЮ:

1. Затвердити Тимчасове положення про класного керівника середнього закладу освіти (додається).

2. Вважати Положення про класного керівника восьмирічної школи і середньої загальноосвітньої трудової політехнічної школи з виробничим навчанням, затверджене Міністерством освіти УРСР 25.11.60 р. таким, що втратило чинність.

3. Міністрові освіти Автономної Республіки Крим, начальникам управлінь освіти обласних, Київської та Севастопольської міських держадміністрацій:

довести Тимчасове положення про класного керівника середнього закладу освіти до відома керівників закладів освіти.

4. Контроль за виконанням наказу покласти на управління гуманітарної освіти та виховання (Лукашевич М.П.) і Головне управління загальної середньої освіти (Романенко В.П.).

Міністр М.З.Згуровський

( Тимчасове положення про класного керівника середнього закладу освіти втратило чинність на підставі Наказу Міністерства освіти і науки N 434 ( z0659-00 ) від 06.09.2000 )
