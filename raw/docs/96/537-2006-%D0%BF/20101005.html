{ Установити, що використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) Міністерству економіки за програмою "Гармонізація національних стандартів з міжнародними та європейськими", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 254 ( 254-2009-п ) від 25.03.2009 }

{ Установити, що використання у 2010 році коштів, передбачених у державному бюджеті ( 2154-17 ) Міністерству економіки за програмою "Гармонізація національних стандартів з міжнародними та європейськими", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 883 ( 883-2010-п ) від 29.09.2010 }

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2006 році коштів, передбачених у державному бюджеті для гармонізації національних стандартів з міжнародними та європейськими, що додається.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 19 квітня 2006 р. N 537

ПОРЯДОК використання у 2006 році коштів, передбачених у державному бюджеті ( 3235-15 ) для гармонізації національних стандартів з міжнародними та європейськими

1. Цей Порядок визначає механізм використання у 2006 році коштів, передбачених у державному бюджеті ( 3235-15 ) Мінекономіки за програмою "Гармонізація національних стандартів з міжнародними та європейськими" (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 638 ( 638-2007-п ) від 20.04.2007 }

1-1. Головним розпорядником бюджетних коштів є Мінекономіки. Розпорядником бюджетних коштів нижчого рівня є Держспоживстандарт, а їх одержувачем - державне підприємство "Український науково-дослідний і навчальний центр проблем стандартизації, сертифікації та якості".

{ Порядок доповнено пунктом 1-1 згідно з Постановою КМ N 254 ( 254-2009-п ) від 25.03.2009; в редакції Постанови КМ N 883 ( 883-2010-п ) від 29.09.2010 }

2. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 2 із змінами, внесеними згідно з Постановами КМ N 638 ( 638-2007-п ) від 20.04.2007, N 259 ( 259-2008-п ) від 26.03.2008; в редакції Постанов КМ N 254 ( 254-2009-п ) від 25.03.2009, N 883 ( 883-2010-п ) від 29.09.2010 }

3. Замовлення робіт із стандартизації за бюджетні кошти здійснюється в установленому законодавством порядку.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 254 ( 254-2009-п ) від 25.03.2009 }

4. Бюджетні кошти використовуються відповідно до плану національної стандартизації на 2010 рік, затвердженого Держспоживстандартом за погодженням з Мінекономіки та Мінфіном, для розроблення проектів національних стандартів, гармонізованих з міжнародними та європейськими, згідно з ДСТУ 1.2:2003 "Національна стандартизація. Правила розроблення національних нормативних документів" та ДСТУ 1.7:2001 "Національна стандартизація. Правила і методи прийняття та застосування міжнародних і регіональних стандартів", а також для здійснення координації робіт, пов'язаних з їх розробленням.

{ Пункт 4 із змінами, внесеними згідно з Постановами КМ N 638 ( 638-2007-п ) від 20.04.2007, N 259 ( 259-2008-п ) від 26.03.2008, N 254 ( 254-2009-п ) від 25.03.2009, N 883 ( 883-2010-п ) від 29.09.2010 }

5. Договори з розробниками проектів стандартів укладаються безпосередньо одержувачем бюджетних коштів.

5-1. Правила визначення вартості робіт з гармонізації національних стандартів з міжнародними та європейськими затверджуються Держспоживстандартом за погодженням з Мінекономіки та Мінфіном.

{ Порядок доповнено пунктом 5-1 згідно з Постановою КМ N 638 ( 638-2007-п ) від 20.04.2007; із змінами, внесеними згідно з Постановою КМ N 259 ( 259-2008-п ) від 26.03.2008 }

6. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються відповідно до законодавства.

Щокварталу до 20 числа наступного місяця Держспоживстандарт подає Мінфіну інформацію про стан виконання результативних показників відповідно до паспорта бюджетної програми разом з аналізом, поясненнями, висновками щодо виконання затверджених показників. { Пункт 6 доповнено абзацом згідно з Постановою КМ N 638 ( 638-2007-п ) від 20.04.2007 }

Відповідальним за виконання бюджетної програми "Гармонізація національних стандартів з міжнародними та європейськими" є Держспоживстандарт. { Пункт 6 доповнено абзацом згідно з Постановою КМ N 638 ( 638-2007-п ) від 20.04.2007 }
