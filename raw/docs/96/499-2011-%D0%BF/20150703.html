Кабінет Міністрів України; Постанова від 27.04.2011 № 499

Деякі питання реалізації проекту організації залізничного пасажирського сполучення м. Київ - міжнародний аеропорт "Бориспіль"

Стан: Чинний

Ідентифікатор: 499-2011-п

Текст документа від 03.07.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 квітня 2011 р. N 499 Київ

Деякі питання реалізації проекту організації залізничного пасажирського сполучення м. Київ - міжнародний аеропорт "Бориспіль"

{ Із змінами, внесеними згідно з Постановою КМ N 418 ( 418-2015-п ) від 17.06.2015 }

Кабінет Міністрів України постановляє:

1. Внести до постанови Кабінету Міністрів України від 28 березня 2011 р. N 335 ( 335-2011-п ) "Деякі питання підготовки до реалізації проекту організації залізничного пасажирського сполучення м. Київ - міжнародний аеропорт "Бориспіль" і будівництва інших інфраструктурних об'єктів Київського регіону" (Офіційний вісник України, 2011 р., N 24, ст. 1000) зміни, що додаються.

2. Міністерству інфраструктури: { Абзац перший пункту 2 в редакції Постанови КМ N 418 ( 418-2015-п ) від 17.06.2015 }

1) забезпечити:

невідкладну передачу в установленому порядку від державного підприємства "Міжнародний аеропорт "Бориспіль" державному підприємству "Дирекція з будівництва та управління національного проекту "Повітряний експрес" та інших інфраструктурних об'єктів Київського регіону" функцій замовника реалізації проекту організації залізничного пасажирського сполучення м. Київ - міжнародний аеропорт "Бориспіль" (далі - проект); { Абзац другий підпункту 1 пункту 2 із змінами, внесеними згідно з Постановою КМ N 418 ( 418-2015-п ) від 17.06.2015 }

проведення аудиту проектно-кошторисної документації проекту згідно з вимогами міжнародних стандартів;

уточнення під час затвердження проекту будівництва техніко-економічних показників, зазначених у пункті 1 постанови Кабінету Міністрів України від 28 березня 2011 р. N 335 ( 335-2011-п ) "Деякі питання підготовки до реалізації проекту організації залізничного пасажирського сполучення м. Київ - міжнародний аеропорт "Бориспіль" і будівництва інших інфраструктурних об'єктів Київського регіону" (Офіційний вісник України, 2011 р., N 24, ст. 1000);

2) затвердити заходи щодо реалізації проекту.

3. Київській міській та Київській обласній державним адміністраціям, Міністерству інфраструктури, Державному агентству земельних ресурсів і державному підприємству "Дирекція з будівництва та управління національного проекту "Повітряний експрес" та інших інфраструктурних об'єктів Київського регіону" вирішити в установленому порядку питання щодо виділення земельних ділянок, необхідних для реалізації проекту.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 418 ( 418-2015-п ) від 17.06.2015 }

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 27 квітня 2011 р. N 499

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 28 березня 2011 р. N 335 ( 335-2011-п )

1. У постанові ( 335-2011-п ):

1) в абзаці першому пункту 1 слова "(далі - державне підприємство)" виключити;

2) у пункті 2 слова "Міжнародний аеропорт "Бориспіль" замінити словами "Дирекція з будівництва та управління національного проекту "Повітряний експрес" та інших інфраструктурних об'єктів Київського регіону";

3) пункт 3 після слів "державному підприємству" доповнити словами "Дирекція з будівництва та управління національного проекту "Повітряний експрес" та інших інфраструктурних об'єктів Київського регіону" (далі - державне підприємство)";

4) абзаци другий, четвертий і п'ятий пункту 7 виключити;

5) додаток до постанови ( 335-2011-п ) виключити.

2. У Порядку та умовах, затверджених зазначеною постановою ( 335-2011-п ):

1) у назві і пункті 1 Порядку та умов ( 335-2011-п ) слова "Міжнародний аеропорт "Бориспіль" замінити словами "Дирекція з будівництва та управління національного проекту "Повітряний експрес" та інших інфраструктурних об'єктів Київського регіону";

2) в абзаці п'ятому пункту 5 слова "копію річного балансу за минулий рік разом з додатками та" виключити.
