Текст документа від 23.02.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 листопада 2004 р. N 828-р Київ

( Розпорядження скасовано на підставі Розпорядження КМ N 39-р ( 39-2005-р ) від 23.02.2005 )

Про внесення змін до деяких розпоряджень Кабінету Міністрів України

1. Внести до розпоряджень Кабінету Міністрів України такі зміни:

1) пункт 3 розпорядження Кабінету Міністрів України від 18 жовтня 2000 р. N 405 ( 405-2000-р ) "Про затвердження Умов проведення конкурсу з продажу пакета акцій ВАТ "Херсонобленерго" (Офіційний вісник України, 2000 р., N 43, ст. 1850; 2001 р., N 6, ст. 243) викласти у такій редакції:

"3. Взяти до відома, що державне підприємство "Енергоринок" укладе в місячний строк угоду з ВАТ "Херсонобленерго" про реструктуризацію заборгованості зазначеного товариства перед державним підприємством у сумі 501185 тис. гривень, яка проводитиметься протягом сімнадцяти років, шляхом її погашення щокварталу рівними частинами";

2) абзац третій підпункту "б" пункту 4 розпорядження Кабінету Міністрів України від 7 квітня 2001 р. N 133 ( 133-2001-р ) "Про систему заходів, спрямованих на створення сприятливих умов для розвитку електроенергетичної галузі" (Офіційний вісник України, 2001 р., N 15, ст. 657) доповнити словами "крім ВАТ "Херсонобленерго".

2. Фонду державного майна вжити в установленому порядку заходів для внесення до договору купівлі-продажу пакета акцій ВАТ "Херсонобленерго" змін, що випливають з цього розпорядження.

Прем'єр-міністр України В.ЯНУКОВИЧ
