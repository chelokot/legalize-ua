Про внесення змін до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

Кабінет Міністрів України постановляє:

Внести до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави, затвердженого постановою Кабінету Міністрів України від 23 грудня 2004 р. N 1734 ( 1734-2004-п ) (Офіційний вісник України, 2004 р., N 52, ст. 3443; 2005 р., N 15, ст. 762; 2006 р., N 50, ст. 3320; 2008 р., N 25, ст. 766), зміни, що додаються.
