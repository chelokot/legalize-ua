Про зупинення дії розпорядження Кабінету Міністрів України від 8 квітня 2009 року N 369-р

{ Додатково див. Конституційне подання Президента ( n0012100-09 ) від 05.05.2009 }

Кабінетом Міністрів України 8 квітня 2009 року видано розпорядження N 369-р ( 369-2009-р ), яким Бухаленкова Сергія Олександровича призначено заступником Голови Фонду державного майна України.

Цей акт видано Кабінетом Міністрів України всупереч Конституції України ( 254к/96-ВР ).

Згідно з Конституцією України ( 254к/96-ВР ) державна влада в Україні здійснюється на засадах її поділу на законодавчу, виконавчу і судову (частина перша статті 6) ( 254к/96-ВР ). Органи законодавчої, виконавчої та судової влади здійснюють свої повноваження у встановлених Конституцією України ( 254к/96-ВР ) межах і відповідно до законів України, органи державної влади зобов'язані діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України (частина друга статті 6, частина друга статті 19 Конституції України) ( 254к/96-ВР ).

Основним Законом держави ( 254к/96-ВР ) повноваження Кабінету Міністрів України щодо вирішення кадрових питань діяльності Фонду державного майна України зводяться до внесення Прем'єр-міністром України до Верховної Ради України подання щодо кандидатури на посаду Голови цього Фонду (пункт 12 частини першої статті 85) ( 254к/96-ВР ).

Повноваженнями ж щодо призначення заступників Голови Фонду державного майна України Конституція ( 254к/96-ВР ) та закони України Кабінет Міністрів України не наділяють.

Конституційний Суд України в Ухвалі від 17 вересня 2008 року N 46-уп/2008 ( va46u710-08 ) відзначив, що у чинному законодавстві України відсутній нормативно-правовий акт, який визначив би належність Фонду державного майна України до будь-яких із гілок державної влади, зазначених у статті 6 Конституції України ( 254к/96-ВР ).

За таких обставин застосування до Фонду державного майна України положень Закону України "Про Кабінет Міністрів України" ( 279-17 ), які визначають повноваження Кабінету Міністрів України щодо призначення на посади та звільнення з посад заступників керівників центральних органів виконавчої влади (стаття 22) ( 279-17 ), є неправомірним.

Таким чином, вирішивши питання призначення заступника Голови Фонду державного майна України, Кабінет Міністрів України вийшов за межі своїх повноважень та діяв у спосіб, не передбачений Конституцією ( 254к/96-ВР ) та законами України, чим порушив наведені норми Конституції України ( 254к/96-ВР ).

У зв'язку з викладеним розпорядження Кабінету Міністрів України N 369-р ( 369-2009-р ) не відповідає також нормам частини третьої статті 113, частини першої статті 117 Основного Закону держави ( 254к/96-ВР ), які є нормами прямої дії і зобов'язують Кабінет Міністрів України керуватися, зокрема, Конституцією ( 254к/96-ВР ) та законами України, видавати постанови і розпорядження в межах своєї компетенції.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 8 квітня 2009 року N 369-р ( 369-2009-р ) "Про призначення Бухаленкова С.О. заступником Голови Фонду державного майна України".

2. Цей Указ набирає чинності з дня його опублікування.
