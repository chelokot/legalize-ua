Президент України; Указ від 12.09.2007 № 850/2007

Про зупинення дії розпорядження Кабінету Міністрів України від 8 серпня 2007 року N 641-р

Стан: Втратив чинність

Ідентифікатор: 850/2007

Текст документа від 12.09.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії розпорядження Кабінету Міністрів України від 8 серпня 2007 року N 641-р

{ Додатково див. Конституційне подання Президента ( n0023100-07 ) від 12.09.2007 }

Кабінетом Міністрів України 8 серпня 2007 року видано розпорядження N 641-р ( 641-2007-р ) "Про затвердження Умов проведення конкурсу з продажу пакета акцій ВАТ "Одеський припортовий завод", яким Фонду державного майна України доручено провести в установленому порядку конкурс з продажу пакета акцій відкритого акціонерного товариства "Одеський припортовий завод" та визначено умови проведення цього конкурсу.

Як вбачається з розпорядження ( 641-2007-р ), приватизація відкритого акціонерного товариства "Одеський припортовий завод", яке займає монопольне становище на ринку послуг із перевантаження хімічної продукції в Україні, зокрема аміаку, здійснюється разом із відповідним майновим комплексом (цехом перевантаження аміаку). Таке рішення за відсутності в Україні механізму узгодження тарифів у сфері перевантаження хімічної продукції, у тому числі й аміаку, та без запровадження заходів щодо протидії монополізації у сфері перевантаження продукції може призвести до необґрунтованого завищення покупцем товариства тарифів на ці послуги, що негативно позначиться, зокрема, на діяльності підприємств хімічної промисловості України.

Слід також ураховувати, що відкрите акціонерне товариство "Одеський припортовий завод" здійснює виробництво, приймання, зберігання та відвантаження рідкого аміаку, тобто є об'єктом підвищеної техногенної та екологічної небезпеки, і потребує здійснення відповідного контролю за його діяльністю. Між тим необхідних механізмів такого контролю розпорядженням ( 641-2007-р ), про яке йдеться, не передбачено.

Відтак затверджені розпорядженням Кабінету Міністрів України від 8 серпня 2007 року N 641-р ( 641-2007-р ) умови відчуження зазначеного об'єкта державної власності не відповідають Закону України "Про основи національної безпеки України" ( 964-15 ), за яким вдосконалення антимонопольної політики визначено одним із основних напрямів державної політики з питань національної безпеки в економічній сфері (стаття 8) ( 964-15 ), неефективність антимонопольної політики, зростання ризиків виникнення надзвичайних ситуацій техногенного характеру визначено загрозами національній безпеці України (стаття 7) ( 964-15 ), забезпечення екологічно та техногенно безпечних умов життєдіяльності громадян і суспільства, збереження навколишнього природного середовища та раціональне використання природних ресурсів є одним із основних пріоритетів національних інтересів України (стаття 6) ( 964-15 ).

Отже, назване розпорядження ( 641-2007-р ) Кабінету Міністрів України не відповідає Конституції України ( 254к/96-ВР ), зокрема її статті 16 ( 254к/96-ВР ), за якою забезпечення екологічної безпеки і підтримання екологічної рівноваги на території України є обов'язком держави, статті 17 ( 254к/96-ВР ), згідно з якою забезпечення економічної безпеки держави є однією з її найважливіших функцій, статті 42 ( 254к/96-ВР ), за якою держава забезпечує захист конкуренції, недобросовісна конкуренція не допускається, а також частині другій статті 8 ( 254к/96-ВР ), якою встановлено, що нормативно-правові акти приймаються на основі Конституції України ( 254к/96-ВР ) і повинні відповідати їй, частині другій статті 6 ( 254к/96-ВР ), частині другій статті 19 ( 254к/96-ВР ) та частині третій статті 113 ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватись у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, діяти на підставі та у спосіб, що ними передбачені.

Ураховуючи наведене та відповідно до пунктів 15, 17 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 8 серпня 2007 року N 641-р ( 641-2007-р ) "Про затвердження Умов проведення конкурсу з продажу пакета акцій ВАТ "Одеський припортовий завод".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
