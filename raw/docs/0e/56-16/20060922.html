Верховна Рада України; Постанова від 31.07.2006 № 56-V

Про персональний склад Тимчасової слідчої комісії Верховної Ради України з питань розслідування звинувачень у підкупі народних депутатів України

Стан: Чинний

Ідентифікатор: 56-16

Текст документа від 22.09.2006:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про персональний склад Тимчасової слідчої комісії Верховної Ради України з питань розслідування звинувачень у підкупі народних депутатів України

( Відомості Верховної Ради України (ВВР), 2006, N 37, ст.321 )

{ Із змінами, внесеними згідно з Постановою ВР N 106-V ( 106-16 ) від 12.09.2006, ВВР, 2006, N 42, ст.389 }

{ Пповноваження Тимчасової слідчої комісії припинено згідно з Постановою ВР N 188-V ( 188-16 ) від 22.09.2006 }

У зв'язку з прийняттям Верховною Радою України Постанови від 25 липня 2006 року "Про утворення Тимчасової слідчої комісії Верховної Ради України з питань розслідування звинувачень у підкупі народних депутатів України" ( 29-16 ) Верховна Рада України постановляє:

1. Встановити, що до складу Тимчасової слідчої комісії Верховної Ради України з питань розслідування звинувачень у підкупі народних депутатів України входять такі народні депутати України:

2. Залишити для фракції "Блок Юлії Тимошенко" квоту в кількості одного народного депутата України для представництва у складі Тимчасової слідчої комісії Верховної Ради України з питань розслідування звинувачень у підкупі народних депутатів України.

3. Ця Постанова набирає чинності з дня її прийняття.
