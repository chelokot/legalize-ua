ВІДКРИТЕ АКЦІОНЕРНЕ ТОВАРИСТВО "УКРТЕЛЕКОМ"

НАКАЗ

20.09.2005 N 348

Зареєстровано в Міністерстві юстиції України 23 вересня 2005 р. за N 1097/11377

Про втрату чинності наказу УДПЕЗ "Укртелеком" від 20.04.99 N 115

З метою приведення актів, що застосовуються ВАТ "Укртелеком" при наданні послуг INTERNET, FRAME RELAY та ISDN, у відповідність до Статуту товариства та Закону України "Про телекомунікації" ( 1280-15 ) НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Українського державного підприємства електрозв'язку "Укртелеком" від 20.04.99 N 115 ( z0296-99 ) "Про затвердження тарифів на додаткові послуги INTERNET, FRAME RELAY та ISDN, що надаються Українським державним підприємством електрозв'язку "Укртелеком", зареєстрований в Міністерстві юстиції України 11 травня 1999 року за N 296/3589.

2. Директорам філій, крім філій "Центр післядипломної освіти ВАТ "Укртелеком", "Дирекція первинної мережі ВАТ "Укртелеком" та Філії спеціалізованого електрозв'язку ВАТ "Укртелеком", довести цей наказ до керівників підпорядкованих структурних підрозділів.

3. Контроль за виконанням цього наказу залишаю за собою.

В.о. Голови Правління А.П.Русінський
