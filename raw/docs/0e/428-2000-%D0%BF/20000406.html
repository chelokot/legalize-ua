Текст документа від 06.04.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 2000 р. N 428 Київ

Про виділення коштів з резервного фонду Кабінету Міністрів України

( Про поширення дії Постанови додатково див. Постанову КМ N 620 ( 620-2000-п ) від 06.04.2000 )

( Поширити дію Постанови щодо використання коштів державного бюджету на проведення компенсації сільськогосподарським товаровиробникам частини плати за користування кредитами комерційних банків, що надаються для закупівлі пально-мастильних матеріалів, також на закупівлю мінеральних добрив, засобів захисту рослин, насіння та запасних частин для проведення комплексу весняно-польових робіт у 2000 році згідно з Постановою КМ N 620 ( 620-2000-п ) від 06.04.2000 )

З метою створення сприятливих умов для підготовки до весняно-польових робіт сільськогосподарських підприємств, що реформовані згідно з Указом Президента України від 3 грудня 1999 р. N 1529 ( 1529/99 ) "Про невідкладні заходи щодо прискорення реформування аграрного сектора економіки", Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Міністерства аграрної політики та Міністерства фінансів щодо виділення з резервного фонду Кабінету Міністрів України 50 млн. гривень на проведення протягом поточного року компенсації сільськогосподарським товаровиробникам частини плати за користування кредитами комерційних банків, залученими виключно для закупівлі пально-мастильних матеріалів.

Установити, що:

зазначені кошти використовуються відповідно до угод, укладених між сільськогосподарськими товаровиробниками та постачальниками пально-мастильних матеріалів, а також на умовах, передбачених постановою Кабінету Міністрів України від 25 лютого 2000 р. N 398 ( 398-2000-п );

кошти, виділені відповідно до цієї постанови, відновлюються у резервному фонді Кабінету Міністрів України за рахунок джерел, визначених постановою Кабінету Міністрів України від 25 лютого 2000 р. N 398.

2. Кошти, що виділяються відповідно до пункту 1 цієї постанови, розподілити по регіонах згідно з додатком.

3. Контроль за виконанням цієї постанови покласти на Віце-прем'єр-міністра України Гладія М.В.

Прем'єр-міністр України В.ЮЩЕНКО
