Текст документа від 23.10.2008:

ДЕРЖАВНА ПОДАТКОВА АДМІНІСТРАЦІЯ УКРАЇНИ МІНІСТЕРСТВО ОХОРОНИ НАВКОЛИШНЬОГО ПРИРОДНОГО СЕРЕДОВИЩА УКРАЇНИ ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ПРОМИСЛОВОЇ БЕЗПЕКИ, ОХОРОНИ ПРАЦІ ТА ГІРНИЧОГО НАГЛЯДУ

НАКАЗ

23.10.2008 N 666/544/224

Зареєстровано в Міністерстві юстиції України 11 листопада 2008 р. за N 1095/15786

Про визнання таким, що втратив чинність, наказу від 13.05.94 N 38/57/45

Відповідно до пункту 3 наказу Міністерства охорони навколишнього природного середовища та ядерної безпеки України, Міністерства праці та соціальної політики України, Державної податкової адміністрації України, Державного комітету України по геології і використанню надр від 30.12.97 N 207/472/51/157 ( z0020-98 ) "Про затвердження Інструкції про порядок обчислення і справляння платежів за користування надрами для видобування корисних копалин", зареєстрованого в Міністерстві юстиції України 16.01.98 за N 20/2460 (із змінами), НАКАЗУЄМО:

1. Визнати таким, що втратив чинність, наказ Головної державної податкової інспекції України, Державного комітету України по геології і використанню надр, Державного комітету України по нагляду за охороною праці від 13.05.94 N 38/57/45 ( z0122-94 ) "Про затвердження Інструкції про порядок обчислення і сплати платежів за спеціальне використання надр при видобуванні корисних копалин", зареєстрований у Міністерстві юстиції України 03.06.94 за N 122/331.

2. Скасувати наказ Державної податкової адміністрації України, Державної геологічної служби України, Державного комітету України з промислової безпеки, охорони праці та гірничого нагляду від 03.09.2008 N 564/102/195 "Про визнання таким, що втратив чинність, наказу від 13.05.94 N 38/57/45".

3. Державній податковій адміністрації України забезпечити:

3.1 в установленому порядку подання цього наказу на державну реєстрацію до Міністерства юстиції України;

3.2 після державної реєстрації в Міністерстві юстиції України доведення цього наказу до відома платників податків через веб-сайт Державної податкової адміністрації України та засоби масової інформації.

4. Контроль за виконанням цього наказу покласти на заступників керівників центральних органів виконавчої влади згідно з розподілом функціональних обов'язків.
