Кабінет Міністрів України; Постанова, Перелік від 17.08.2011 № 883

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань діяльності Адміністрації Державної служби спеціального зв'язку та захисту інформації

Стан: Чинний

Ідентифікатор: 883-2011-п

Текст документа від 17.08.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 серпня 2011 р. N 883 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань діяльності Адміністрації Державної служби спеціального зв'язку та захисту інформації

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, постанови Кабінету Міністрів України з питань діяльності Адміністрації Державної служби спеціального зв'язку та захисту інформації згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 24

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 17 серпня 2011 р. N 883

ПЕРЕЛІК постанов Кабінету Міністрів України з питань діяльності Державної служби спеціального зв'язку та захисту інформації, що втратили чинність

1. Постанова Кабінету Міністрів України від 24 червня 2006 р. N 868 ( 868-2006-п ) "Про затвердження Положення про Адміністрацію Державної служби спеціального зв'язку та захисту інформації" (Офіційний вісник України, 2006 р., N 26, ст. 1889).

2. Пункт 4 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 23 липня 2008 р. N 664 ( 664-2008-п ) (Офіційний вісник України, 2008 р., N 56, ст. 1867).

3. Постанова Кабінету Міністрів України від 6 серпня 2008 р. N 697 ( 697-2008-п ) "Про доповнення пункту 4 Положення про Адміністрацію Державної служби спеціального зв'язку та захисту інформації" (Офіційний вісник України, 2008 р., N 59, ст. 1981).

4. Пункт 1 змін, що вносяться до постанов Кабінету Міністрів України від 24 червня 2006 р. N 868 ( 868-2006-п ) і від 27 грудня 2006 р. N 1828 ( 1828-2006-п ), затверджених постановою Кабінету Міністрів України від 17 лютого 2010 р. N 136 ( 136-2010-п ) "Деякі питання організації виконання завдань особовим складом Державної служби спеціального зв'язку та захисту інформації" (Офіційний вісник України, 2010 р., N 11, ст. 537).

5. Пункт 2 змін, що вносяться до постанов Кабінету Міністрів України від 27 травня 1999 р. N 920 ( 920-99-п ) і від 24 червня 2006 р. N 868 ( 868-2006-п ), затверджених постановою Кабінету Міністрів України від 21 липня 2010 р. N 602 ( 602-2010-п ) (Офіційний вісник України, 2010 р., N 55, ст. 1850).
