Текст документа від 13.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 грудня 2006 р. N 1716 Київ

Про внесення змін до постанови Кабінету Міністрів України від 3 серпня 2006 р. N 1091

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 3 серпня 2006 р. N 1091 ( 1091-2006-п ) "Про виплату у 2006 році громадянам України компенсації втрат від знецінення грошових заощаджень і страхових внесків, вкладених до 2 січня 1992 р. в установи Ощадного банку СРСР та державного страхування СРСР, що діяли на території України" (Офіційний вісник України, 2006 р., N 32, ст. 2316, N 33, ст. 2389) зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 34

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 13 грудня 2006 р. N 1716

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 3 серпня 2006 р. N 1091 ( 1091-2006-п )

1. Доповнити назву постанови словами і цифрами "та викуп облігацій Державної цільової безпроцентної позики 1990 року і державних казначейських зобов'язань СРСР".

2. У пункті 1:

абзац перший після слова "Астарта," доповнити словами і цифрами "а також викуп облігацій Державної цільової безпроцентної позики 1990 року, державних казначейських зобов'язань СРСР,";

у підпункті 1 цифри і слова "350 млн. гривень" замінити цифрами і словами "33 млн. гривень";

у підпункті 4 цифри і слова "220 млн. гривень" замінити цифрами і словами "260 млн. гривень";

доповнити пункт підпунктами 7 і 8 такого змісту:

"7) 140 млн. гривень - на викуп облігацій Державної цільової безпроцентної позики 1990 року за видами товарів, що не були викуплені відповідно до постанов Кабінету Міністрів України від 31 жовтня 1995 р. N 862 ( 862-95-п ) (ЗП України, 1996 р., N 3, ст. 81), від 1 грудня 1995 р. N 961 ( 961-95-п ) (ЗП України, 1996 р., N 4, ст. 113), від 8 травня 1996 р. N 485 ( 485-96-п ) (ЗП України, 1996 р., N 10, ст. 317), від 25 березня 1999 р. N 457 ( 457-99-п ) (Офіційний вісник України, 1999 р., N 13, ст. 515), від 17 травня 2000 р. N 817 ( 817-2000-п ) (Офіційний вісник України, 2000 р., N 20, ст. 833), від 26 березня 2001 р. N 275 ( 275-2001-п ) (Офіційний вісник України, 2001 р., N 13, ст. 545, N 36, ст. 1661, N 50, ст. 2233), від 11 березня 2004 р. N 306 ( 306-2004-п ) (Офіційний вісник України, 2004 р., N 10, ст. 610, N 38, ст. 2509) і від 30 травня 2005 р. N 409 ( 409-2005-п ) (Офіційний вісник України, 2005 р., N 22, ст. 1223), а саме: мікрохвильових печей, холодильників "Мінськ", "Бірюса" та "ЗІЛ", швейних машин "Зіг-заг", пральних машин "Вятка", персональних побутових комп'ютерів, телевізорів кольорового зображення, мотоциклів з коляскою, відеомагнітофонів та мінітракторів, автомобілів "Таврія ЗАЗ-1102";

8) 137 млн. гривень - на викуп державних казначейських зобов'язань СРСР.".

3. Абзац перший пункту 2 після слів і цифри "у пункті 1 цієї постанови виплат" доповнити словами "та викупу".

4. У пункті 4:

слова і цифри "за підсумками дев'яти місяців 2006 року" виключити;

доповнити пункт словами "та викупу".

5. У пункті 5 доповнити:

абзац другий після слів "проведення виплат" словами "та викупу";

абзац третій після слів "зазначених виплат" словами "та викупу".
