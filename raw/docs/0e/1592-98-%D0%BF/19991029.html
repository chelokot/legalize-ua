Про умови оплати праці працівників районних, районних у містах, міських (міст обласного значення) управлінь юстиції

Текст документа від 29.10.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 жовтня 1998 р. N 1592 Київ

Про умови оплати праці працівників районних, районних у містах, міських (міст обласного значення) управлінь юстиції

( Із змінами, внесеними згідно з Постановою КМ N 2014 ( 2014-99-п ) від 29.10.99 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 2014 ( 2014-99-п ) від 29.10.99 )

2. Інші умови оплати праці працівників районних, районних у містах, міських (міст обласного значення) управлінь юстиції визначаються відповідно до Закону України "Про державну службу" ( 3723-12 ) та постанови Кабінету Міністрів України від 21 січня 1993 р. N 35 ( 35-93-п ) "Про умови праці працівників апарату органів державної виконавчої влади та інших органів" з відповідними змінами і доповненнями.

3. Групи за оплатою праці працівників міських (міст обласного значення) управлінь юстиції установлюються відповідно до показників, затверджених постановою Кабінету Міністрів України від 10 червня 1992 р. N 320 ( 320-92-п ) "Про віднесення областей та міст до груп за оплатою праці".
