Кабінет Міністрів України; Постанова від 27.04.2006 № 596

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для придбання житла інвалідам по слуху та зору

Стан: Чинний

Ідентифікатор: 596-2006-п

Текст документа від 27.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 квітня 2006 р. N 596 Київ

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для придбання житла інвалідам по слуху та зору

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Установити, що використання у 2006 році коштів, передбачених Міністерству праці та соціальної політики за бюджетною програмою ( 3235-15 ) "Придбання житла для інвалідів-сліпих та інвалідів глухих", здійснюється відповідно до Порядку використання коштів, передбачених у державному бюджеті для придбання житла інвалідам по слуху та зору, затвердженого постановою Кабінету Міністрів України від 5 листопада 2005 р. N 1060 ( 1060-2005-п ) (Офіційний вісник України, 2005 р., N 45, ст. 2843), з урахуванням того, що у вартості закуповуваного житла враховуються включені учасником процедури закупівлі в тендерну пропозицію передбачені законодавством або тендерними умовами податки та інші обов'язкові платежі до бюджетів, вартість послуг нотаріуса, посередницьких послуг, що надаються підприємствами, які здійснюють операції з нерухомістю, а також витрати, пов'язані з переоформленням права власності на продане житло.

Прем'єр-міністр України Ю.ЄХАНУРОВ
