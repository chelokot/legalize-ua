ДЕРЖАВНА ПОДАТКОВА АДМІНІСТРАЦІЯ УКРАЇНИ

НАКАЗ

02.06.2003 N 265

Зареєстровано в Міністерстві юстиції України 6 червня 2003 р. за N 454/7775

Про визнання такими, що втратили чинність, наказів Державної податкової адміністрації України від 28.07.97 N 256 та від 31.07.97 N 275

У зв'язку з прийняттям Закону України від 24.12.2002 N 349-IV ( 349-15 ) "Про внесення змін до Закону України "Про оподаткування прибутку підприємств" та наказу Державної податкової адміністрації України від 29.03.2003 N 143 ( z0271-03 ) "Про затвердження форми декларації з податку на прибуток підприємства та Порядку її складання", зареєстрованого у Міністерстві юстиції України 08.04.2003 за N 271/7592, а також відповідно до статті 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ) (із змінами та доповненнями) НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Державної податкової адміністрації України від 28.07.97 N 256 ( z0312-97 ) "Про затвердження Порядку повідомлення про зменшення валового доходу по операціях, пов'язаних із реалізацією товарів (виконанням робіт, наданням послуг)", зареєстрований у Міністерстві юстиції України 14.08.97 за N 312/2116, і від 31.07.97 N 275 ( z0318-97 ) "Щодо затвердження форм податкового звіту про результати виконання підприємством довгострокових договорів (контрактів) та Порядку їх ведення і складання", зареєстрований у Міністерстві юстиції України 15.08.97 за N 318/2122.

2. Департаменту методології (Піхоцький В.Ф.) в установлений термін подати цей наказ до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Голови Державної податкової адміністрації України Лекаря С.І.
