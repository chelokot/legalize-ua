КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 серпня 2010 р. N 1635-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 293-р ( 293-2019-р ) від 08.05.2019 }

Про внесення змін до розпорядження Кабінету Міністрів України від 11 січня 2007 р. N 5

Внести до розпорядження Кабінету Міністрів України від 11 січня 2007 р. N 5 ( 5-2007-р ) "Про схвалення Концепції Державної програми розвитку міжнародного аеропорту "Бориспіль" на період до 2020 року" (Офіційний вісник України, 2007 р., N 2, ст. 75) такі зміни:

абзац другий пункту 1 виключити;

пункт 2 викласти в такій редакції:

"2. Міністерству транспорту та зв'язку врахувати положення Концепції, схваленої цим розпорядженням, під час підготовки проекту Державної цільової програми розвитку аеропортів на період до 2020 року.".

Прем'єр-міністр України М.АЗАРОВ
