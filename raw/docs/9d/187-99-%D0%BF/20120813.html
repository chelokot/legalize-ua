Кабінет Міністрів України; Постанова від 15.02.1999 № 187

Про порядок надання щорічної додаткової відпустки із збереженням матеріального забезпечення за особливий характер служби військовослужбовцям Прикордонних військ

Стан: Втратив чинність

Ідентифікатор: 187-99-п

Текст документа від 13.08.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 лютого 1999 р. N 187 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 702 ( 702-2012-п ) від 01.08.2012 }

Про порядок надання щорічної додаткової відпустки із збереженням матеріального забезпечення за особливий характер служби військовослужбовцям Прикордонних військ

{ Із змінами, внесеними згідно з Постановами КМ N 1258 ( 1258-2001-п ) від 26.09.2001 N 1455 ( 1455-2002-п ) від 26.09.2002 }

Відповідно до абзацу другого пункту 4 статті 10 Закону України "Про соціальний і правовий захист військовослужбовців та членів їх сімей" ( 2011-12 ) Кабінет Міністрів України постановляє:

1. Установити, що щорічна додаткова відпустка із збереженням матеріального забезпечення військовослужбовцям Прикордонних військ - офіцерам, прапорщикам, мічманам, а також солдатам, матросам, сержантам і старшинам, які проходять службу за контрактом, надається за особливий характер служби на прикордонних заставах і постах, у прикордонних оперативних відділеннях, оперативних пунктах, у підрозділах прикордонного контролю та авіації, а також на кораблях і катерах, що безпосередньо несуть службу з охорони державного кордону, за переліком посад, що визначається Державним комітетом у справах охорони державного кордону. ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1455 ( 1455-2002-п ) від 26.09.2002 )

Зазначена відпустка встановлюється тривалістю 15 діб і надається одночасно із черговою щорічною відпусткою.

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1258 ( 1258-2001-п ) від 26.09.2001 )

2. Ця постанова набирає чинності з 1 березня 1999 року.
