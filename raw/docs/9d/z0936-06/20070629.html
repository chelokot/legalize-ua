ДСА України; Наказ від 03.08.2006 № 78

Про механізм перерахування коштів для оплати витрат з інформаційно-технічного забезпечення розгляду цивільних справ

Реєстрація: Мін'юст України від 04.08.2006 № 936/12810

Стан: Втратив чинність

Ідентифікатор: z0936-06

Текст документа від 29.06.2007:

ДЕРЖАВНА СУДОВА АДМІНІСТРАЦІЯ УКРАЇНИ

НАКАЗ

03.08.2006 N 78

Зареєстровано в Міністерстві юстиції України 4 серпня 2006 р. за N 936/12810

{ Наказ втратив чинність на підставі Наказу Державної судової адміністрації N 39 ( z0661-07 ) від 18.05.2007 }

Про механізм перерахування коштів для оплати витрат з інформаційно-технічного забезпечення розгляду цивільних справ

З метою визначення механізму перерахування коштів для оплати витрат з інформаційно-технічного забезпечення розгляду цивільних справ відповідно до вимог постанови Кабінету Міністрів України від 21.12.2005 N 1258 ( 1258-2005-п ) "Про затвердження Порядку оплати витрат з інформаційно-технічного забезпечення розгляду цивільних справ та їх розмірів" НАКАЗУЮ:

1. Установити, що оплата витрат з інформаційно-технічного забезпечення розгляду цивільних справ (далі - витрати) у визначених розмірах здійснюється шляхом перерахування коштів на спеціальні реєстраційні рахунки апеляційних загальних судів та територіальних управлінь державної судової адміністрації, відкриті в органах Державного казначейства, та використовуються згідно з їх відповідними кошторисами, затвердженими в установленому порядку.

2. Для перерахування коштів на оплату витрат у платіжному документі зазначається призначення платежу - "інформаційно-технічне забезпечення розгляду цивільної справи", а також найменування суду, до якого особа звертається із позовною заявою, скаргою, заявою про відкриття справи окремого провадження, клопотанням про надання дозволу на примусове виконання рішення іноземного суду, клопотанням про визнання рішення іноземного суду, що не підлягає примусовому виконанню.

3. Визнати таким, що втратив чинність, наказ Державної судової адміністрації України від 23 лютого 2006 року N 17 ( z0215-06 ) "Про визначення Механізму перерахування коштів для оплати витрат з інформаційно-технічного забезпечення розгляду цивільних справ", зареєстрований в Мін'юсті України 1 березня 2006 року за N 215/12089.

4. Юридичному управлінню Державної судової адміністрації України (Мягкоход Ю.В.) подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами і доповненнями).

5. Управлінню організаційно-аналітичної роботи, документування та контролю Державної судової адміністрації України (Бровко Т.В.) довести цей наказ до відома начальників територіальних управлінь державної судової адміністрації та голів апеляційних і місцевих загальних судів України.

6. Контроль за виконанням цього наказу покласти на заступника Голови Державної судової адміністрації України Богданова Л.В.

7. Цей наказ набирає чинності з 1 вересня 2006 року.

Голова І.Балаклицький
