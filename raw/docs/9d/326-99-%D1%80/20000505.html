Кабінет Міністрів України; Розпорядження від 23.04.1999 № 326-р

Про митне оформлення автоматичної лінії шовкографії для виробництва автомобільного скла, що ввозиться фірмою "Лоск"

Стан: Втратив чинність

Ідентифікатор: 326-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 квітня 1999 р. N 326-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення автоматичної лінії шовкографії для виробництва автомобільного скла, що ввозиться фірмою "Лоск" (с. Пісочин Харківського району Харківської області) для власних виробничих потреб за контрактом від 12 січня 1998 р. N LOSK 1/98, укладеним з фірмою "IANUA S.P.A." (Італія), за рахунок коштів кредитної лінії Європейського банку реконструкції та розвитку для малих та середніх підприємств за Кредитною угодою між Європейським банком реконструкції та розвитку і Національним банком України, у порядку, що діяв на дату укладення контракту.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
