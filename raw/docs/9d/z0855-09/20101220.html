25.08.2009 N 321

Зареєстровано в Міністерстві юстиції України 10 вересня 2009 р. за N 855/16871

Про внесення змін до наказу Міністерства праці та соціальної політики України від 22.06.2009 N 241

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства праці та соціальної політики України N 241 ( z0573-09 ) від 22.06.2009, до якого вносились зміни }

Відповідно до підпункту 13 пункту 4 Положення про Міністерство праці та соціальної політики України, затвердженого постановою Кабінету Міністрів України від 02.11.2006 N 1543 ( 1543-2006-п ), та з метою упорядкування умов оплати праці працівників державної установи "Соціальний контактний центр" НАКАЗУЮ:

1. Внести зміни до наказу Міністерства праці та соціальної політики України від 22.06.2009 N 241 ( z0573-09 ) "Про умови оплати праці працівників державної установи "Соціальний контактний центр", зареєстрованого у Міністерстві юстиції України 26.06.2009 за N 573/16589, виклавши додаток у редакції, що додається.

2. Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр Л.Денісова
