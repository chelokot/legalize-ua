КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 листопада 2001 р. N 1554 Київ

( Постанова втратила чинність на підставі Постанови КМ N 16 ( 16-2005-п ) від 06.01.2005 )

Про внесення змін до Положення про Моторне (транспортне) страхове бюро

З метою підвищення ефективності здійснення контролю за діяльністю Моторного (транспортного) страхового бюро Кабінет Міністрів України постановляє:

Внести до абзацу другого пункту 3 Положення про Моторне (транспортне) страхове бюро, затвердженого постановою Кабінету Міністрів України від 28 вересня 1996 р. N 1175 ( 1175-96-п ) "Про порядок і умови проведення обов'язкового страхування цивільної відповідальності власників транспортних засобів" (ЗП України, 1996 р., N 18, ст. 510; Офіційний вісник України, 1998 р., N 27, ст. 1002, N 49, ст. 1797; 1999 р., N 14, ст. 557; 2000 р., N 22, ст. 897), такі зміни:

доповнити абзац після слова "МВС" словами "Міністерства економіки та з питань європейської інтеграції";

слово "Укрстрахнагляду" виключити.
