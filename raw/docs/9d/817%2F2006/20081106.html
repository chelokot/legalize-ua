Про граничну чисельність працівників Секретаріату Президента України

Стан: Втратив чинність

Ідентифікатор: 817/2006

Текст документа від 06.11.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 997/2008 ( 997/2008 ) від 04.11.2008 }

Про граничну чисельність працівників Секретаріату Президента України

1. Затвердити граничну чисельність працівників Секретаріату Президента України у кількості 595 штатних одиниць.

2. Визнати такою, що втратила чинність, статтю 2 Указу Президента України від 4 листопада 2005 року N 1548 ( 1548/2005 ) "Питання Секретаріату Президента України".
