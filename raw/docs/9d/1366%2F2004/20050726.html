Про зміну у складі Антикризового центру

Увести до складу Антикризового центру, затвердженого Указом Президента України від 5 листопада 2002 року N 991 ( 991/2002 ) (зі змінами, внесеними Указами від 18 березня 2003 року N 228 ( 228/2003 ) і від 22 листопада 2003 року N 1338 ( 1338/2003 ), СИНЯНСЬКОГО Олега Григоровича - Голову Служби зовнішньої розвідки України.
