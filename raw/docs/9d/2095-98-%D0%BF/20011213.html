Кабінет Міністрів України; Постанова від 30.12.1998 № 2095

Про внесення доповнень до деяких постанов Кабінету Міністрів України з питань кадрової служби

Стан: Втратив чинність

Ідентифікатор: 2095-98-п

Текст документа від 13.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 грудня 1998 р. N 2095 Київ

Про внесення доповнень до деяких постанов Кабінету Міністрів України з питань кадрової служби

( Із змінами, внесеними згідно з Постановами КМ N 1369 ( 1369-99-п ) від 29.07.99 N 1658 ( 1658-2001-п ) від 13.12.2001 )

Кабінет Міністрів України постановляє:

Внести доповнення до деяких постанов Кабінету Міністрів України з питань кадрової служби, що додаються.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

Інд. 49

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 30 грудня 1998 р. N 2095

ДОПОВНЕННЯ, що вносяться до деяких постанов Кабінету Міністрів України

1. Пункт 9 Типового положення про кадрову службу органу виконавчої влади, затвердженого постановою Кабінету Міністрів України від 2 серпня 1996 р. N 912 ( 912-96-п ) (ЗП України, 1996 р., N 16, ст. 434), доповнити абзацом такого змісту:

"Призначення на посаду та звільнення з посади керівника кадрової служби здійснюється за наявності висновку Головдержслужби".

( Пункт 2 втратив чинність на підставі Постанови КМ N 1369 ( 1369-99-п ) від 29.07.99 )

( Пункт 3 втратив чинність на підставі Постанови КМ N 1658 ( 1658-2001-п ) від 13.12.2001 )
