КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 листопада 2007 р. N 1054-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 19-р ( 19-2012-р ) від 11.01.2012 }

Про зміну складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття

Ввести до складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття, затвердженого розпорядженням Кабінету Міністрів України від 21 лютого 2007 р. N 59 ( 59-2007-р ) (Офіційний вісник України, 2007 р., N 14, ст. 536, N 39, ст. 1567):

у правлінні Фонду Слободяна Ярослава Дмитровича - заступника директора департаменту Мінагрополітики, вивівши із складу члена правління Гайдара Миколу Васильовича;

у наглядовій раді Фонду Шашкевича Любомира Михайловича - директора департаменту ГоловКРУ, вивівши із складу члена наглядової ради Байбекову Олену Олексіївну.

Прем'єр-міністр України В.ЯНУКОВИЧ
