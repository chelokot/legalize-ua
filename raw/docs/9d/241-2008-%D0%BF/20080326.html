Кабінет Міністрів України; Постанова від 26.03.2008 № 241

Про порядок використання у 2008 році коштів, передбачених у державному бюджеті для обслуговування кредитів, залучених для реалізації проекту "Циклон-4"

Стан: Чинний

Ідентифікатор: 241-2008-п

Текст документа від 26.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 березня 2008 р. N 241 Київ

Про порядок використання у 2008 році коштів, передбачених у державному бюджеті для обслуговування кредитів, залучених для реалізації проекту "Циклон-4"

Кабінет Міністрів України постановляє:

Установити, що у 2008 році кошти, передбачені у державному бюджеті ( 107-17 ) Національному космічному агентству за бюджетною програмою "Обслуговування кредитів, залучених для реалізації проекту "Циклон-4", використовуються відповідно до Порядку, затвердженого постановою Кабінету Міністрів України від 14 березня 2007 р. N 451 ( 451-2007-п ) (Офіційний вісник України, 2007 р., N 21, ст. 830).

Внести до зазначеного Порядку ( 451-2007-п ) такі зміни:

в абзаці другому пункту 3 і абзаці першому пункту 4 цифри "2007" замінити цифрами "2008";

пункт 5 викласти в такій редакції:

"5. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.".

Прем'єр-міністр України Ю.ТИМОШЕНКО
