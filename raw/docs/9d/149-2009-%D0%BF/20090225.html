ПОСТАНОВА від 25 лютого 2009 р. N 149 Київ

Про затвердження складу Державної акредитаційної комісії

Кабінет Міністрів України постановляє:

1. Затвердити склад Державної акредитаційної комісії, що додається.

2. Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

ПЕРЕЛІК актів Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 1 серпня 2006 р. N 1073 ( 1073-2006-п ) "Про затвердження складу Державної акредитаційної комісії" (Офіційний вісник України, 2006 р., N 31, ст. 2232).

2. Розпорядження Кабінету Міністрів України від 20 квітня 2007 р. N 210 ( 210-2007-р ) "Про зміну складу Державної акредитаційної комісії" (Офіційний вісник України, 2007 р., N 30, ст. 1222).

3. Розпорядження Кабінету Міністрів України від 26 травня 2007 р. N 348 ( 348-2007-р ) "Про зміну складу Державної акредитаційної комісії" (Офіційний вісник України, 2007 р., N 39, ст. 1568).

4. Розпорядження Кабінету Міністрів України від 10 жовтня 2007 р. N 862 ( 862-2007-р ) "Про зміну складу Державної акредитаційної комісії" (Офіційний вісник України, 2007 р., N 78, ст. 2904).

5. Розпорядження Кабінету Міністрів України від 17 квітня 2008 р. N 640 ( 640-2008-р ) "Про зміну складу Державної акредитаційної комісії" (Офіційний вісник України, 2008 р., N 31, ст. 1007).
