21.04.2011 N 147

Зареєстровано в Міністерстві юстиції України 13 травня 2011 р. за N 572/19310

{ Наказ втратив чинність на підставі Наказу Міністерства соціальної політики N 465 ( z0852-14 ) від 14.07.2014 }

Про внесення зміни до наказу Міністерства праці та соціальної політики України від 30.09.2005 N 289

Відповідно до постанови Кабінету Міністрів України від 30.03.2011 N 310 ( 310-2011-п ) "Про внесення зміни в додаток 1 до постанови Кабінету Міністрів України від 30 серпня 2002 р. N 1298" НАКАЗУЮ:

1. Доповнити перше речення примітки 1 додатка 1 до наказу Міністерства праці та соціальної політики України від 30.09.2005 N 289 ( z1197-05 ) "Про умови оплати праці працівників бюджетних науково-дослідних установ Мінпраці України", зареєстрованого в Міністерстві юстиції України 13.10.2005 за N 1197/11477 (зі змінами), після цифр і слова "613 гривень" словами і цифрами "; з 1 квітня - 625 гривень.".

2. Керівникам державної установи "Науково-дослідний інститут соціально-трудових відносин" С.Мельнику, науково-дослідної установи "Український науково-дослідний інститут протезування, протезобудування та відновлення працездатності" А.Салєєвій забезпечити диференціацію заробітної плати працівників, для яких визначені однакові посадові оклади, за рахунок встановлення доплат, надбавок та премій.

3. Цей наказ набирає чинності з дня його офіційного опублікування та застосовується з 01.04.2011.

Голова Комісії з проведення реорганізації, перший заступник Міністра Л.Дроздова
