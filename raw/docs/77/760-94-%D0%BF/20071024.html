ПОСТАНОВА від 10 листопада 1994 р. N 760 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Української частини Міжурядової Українсько-Словацької комісії по торговельно-економічному та науково-технічному співробітництву

Кабінет Міністрів України постановляє:

Призначити заступника Міністра зовнішніх економічних зв'язків України Щербатюка Анатолія Антоновича головою Української частини Міжурядової Українсько-Словацької комісії по торговельно- економічному та науково-технічному співробітництву, звільнивши від цих обов'язків Резника Михайла Борисовича.
