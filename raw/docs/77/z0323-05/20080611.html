{ Наказ втратив чинність на підставі Наказу Міністерства України у справах сім'ї, молоді та спорту N 1278 ( z0486-08 ) від 31.03.2008 }

Про внесення змін до наказу Державного комітету України у справах сім'ї та молоді від 4 лютого 2002 року N 11

Відповідно до Закону України від 18 січня 2005 року N 2353 ( 2353-15 ) "Про внесення змін до деяких законів України" та статті 1 Закону України "Про соціальні послуги" ( 966-15 ) НАКАЗУЮ:

1. Унести до наказу Державного комітету України у справах сім'ї та молоді від 4 лютого 2002 року N 11 ( z0319-02 ) "Про затвердження Порядку здійснення працівниками центрів соціальних служб для молоді соціального інспектування з метою забезпечення супроводу неблагополучних сімей", зареєстрованого в Міністерстві юстиції України 1 квітня 2002 року за N 319/6607, такі зміни:

у назві, текстах наказу та Порядку:

1.1. Слова "центри соціальних служб для молоді" в усіх відмінках та числах замінити словами "центри соціальних служб для сім'ї, дітей та молоді" у відповідних відмінках та числах.

1.2. Слова "неблагополучна сім'я" в усіх відмінках та числах замінити словами "сім'я у складних життєвих обставинах" у відповідних відмінках та числах.

2. Державній соціальній службі для сім'ї, дітей та молоді подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 3 жовтня 1992 року N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами).

3. Контроль за виконанням наказу покласти на заступника Міністра, директора Державної соціальної служби для сім'ї, дітей та молоді Толстоухову С.В.

Міністр Ю.О.Павленко
