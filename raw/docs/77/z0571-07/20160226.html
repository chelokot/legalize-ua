{ Наказ втратив чинність на підставі Наказу Міністерства соціальної політики N 35 ( z0186-16 ) від 22.01.2016 }

Про внесення зміни до наказу Міністерства праці та соціальної політики України від 06.04.2006 N 109

Відповідно до підпункту 13 пункту 4 Положення про Міністерство праці та соціальної політики України, затвердженого постановою Кабінету Міністрів України від 02.11.2006 N 1543 ( 1543-2006-п ), та з метою впорядкування умов оплати праці працівників Українського центру оцінювання якості освіти та регіональних центрів оцінювання якості освіти НАКАЗУЮ:

1. Доповнити пункт 2 наказу Міністерства праці та соціальної політики України від 06.04.2006 N 109 ( z0411-06 ) "Про умови оплати праці працівників Українського центру оцінювання якості освіти та регіональних центрів оцінювання якості освіти", зареєстрованого в Міністерстві юстиції України 10.04.2006 за N 411/12285, підпунктом такого змісту:

"2.4. Установлювати посадовий оклад працівників на рівні відповідного розміру мінімальної заробітної плати в разі, коли розмір посадового окладу нижчий від визначеного законодавством розміру мінімальної заробітної плати".

2. Ця зміна застосовується з 1 квітня 2007 року.
