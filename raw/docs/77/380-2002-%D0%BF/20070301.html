Текст документа від 01.03.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 березня 2002 р. N 380 Київ

Про внесення змін до деяких актів Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 317 ( 317-2007-п ) від 01.03.2007 }

У зв'язку з прийняттям Указу Президента України від 15 січня 2002 р. N 22 ( 22/2002 ) "Про внесення змін до деяких указів Президента України" Кабінет Міністрів України постановляє:

Внести до актів Кабінету Міністрів України зміни, що додаються.

Прем'єр-міністр України А.КІНАХ

Інд. 40

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 березня 2002 р. N 380

ЗМІНИ, що вносяться до актів Кабінету Міністрів України

{ Пункт 1 втратив чинність на підставі Постанови КМ N 317 ( 317-2007-п ) від 01.03.2007 }

2. Абзац четвертий пункту 3 Порядку розгляду питань, пов'язаних з призначенням на посади та звільненням з посад керівників, заступників керівників центральних органів виконавчої влади, урядових органів державного управління, державних підприємств та їх об'єднань, а також голів місцевих державних адміністрацій, затвердженого постановою Кабінету Міністрів України від 13 грудня 2001 р. N 1658 ( 1658-2001-п ) (Офіційний вісник України, 2001 р., N 51, ст. 2275), замінити абзацами такого змісту:

"перших заступників та заступників державних секретарів міністерств - міністрами за поданням державних секретарів міністерств;

першого заступника та заступників керівників урядових органів державного управління - міністрами, керівниками інших центральних органів виконавчої влади за погодженням з керівником урядового органу державного управління".
