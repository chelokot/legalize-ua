Кабінет Міністрів України; Розпорядження від 23.12.2004 № 935-р

Про внесення зміни до розпорядження Кабінету Міністрів України від 18 лютого 1998 р. N 96 і визнання такими, що втратили чинність, деяких розпоряджень Кабінету Міністрів України

Стан: Втратив чинність

Ідентифікатор: 935-2004-р

Текст документа від 26.05.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 2004 р. N 935-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 378 ( 378-2005-п ) від 26.05.2005 )

Про внесення зміни до розпорядження Кабінету Міністрів України від 18 лютого 1998 р. N 96 і визнання такими, що втратили чинність, деяких розпоряджень Кабінету Міністрів України

1. У розпорядженні Кабінету Міністрів України від 18 лютого 1998 р. N 96 ( 96-98-р ) слова і цифри "на період до 2003 року" виключити.

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 3 липня 2000 р. N 274 ( 274-2000-р );

розпорядження Кабінету Міністрів України від 29 березня 2002 р. N 165 ( 165-2002-р ) "Про внесення змін до розпоряджень Кабінету Міністрів України з питань створення Єдиної державної автоматизованої паспортної системи".

Виконуючий обов'язки Прем'єр-міністра України М.АЗАРОВ
