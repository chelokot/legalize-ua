Про колегію Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

Текст документа від 13.06.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 серпня 2002 р. N 1309 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 818 ( 818-2007-п ) від 13.06.2007 }

Про колегію Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

( Із змінами, внесеними згідно з Постановою КМ N 1389 ( 1389-2002-п ) від 16.09.2002 )

Кабінет Міністрів України постановляє:

1. Дозволити Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи мати колегію у кількості 17 осіб.

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1389 ( 1389-2002-п ) від 16.09.2002 )

2. Затвердити членом колегії Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи з правом дорадчого голосу Папієва Михайла Миколайовича (за згодою).

3. Визнати такими, що втратили чинність:

пункт 2 постанови Кабінету Міністрів України від 12 квітня 2000 р. N 641 ( 641-2000-п ) "Про граничну чисельність працівників центрального апарату Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" (Офіційний вісник України, 2000 р., N 15, ст. 624);

пункт 1 постанови Кабінету Міністрів України від 10 квітня 2002 р. N 481 ( 481-2002-п ) "Про колегію Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" (Офіційний вісник України, 2002 р., N 15, ст. 799).
