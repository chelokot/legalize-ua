МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

31.03.2006 N 97

Зареєстровано в Міністерстві юстиції України 10 квітня 2006 р. за N 407/12281

Про умови оплати праці працівників територіальних органів Державного комітету України з промислової безпеки, охорони праці та гірничого нагляду

{ Із змінами, внесеними згідно з Наказами Міністерства праці та соціальної політики

N 303 ( z0968-06 ) від 10.08.2006

N 66 ( z0190-07 ) від 23.02.2007

N 271 ( z0591-07 ) від 30.05.2007 - зміни застосовуються з 01.05.2007 }

На виконання постанови Кабінету Міністрів України від 9 березня 2006 року N 268 ( 268-2006-п ) "Про упорядкування структури та умов оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Затвердити схему посадових окладів керівних працівників і спеціалістів територіальних органів Держгірпромнагляду згідно з додатком.

Установити умови оплати праці працівників територіальних органів Держгірпромнагляду згідно з умовами оплати праці, затвердженими постановою Кабінету Міністрів України від 9 березня 2006 року N 268 ( 268-2006-п ) "Про упорядкування структури та умов оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів".

Установити посадові оклади службовців територіальних органів Держгірпромнагляду згідно з додатком 55 до постанови Кабінету Міністрів України від 9 березня 2006 року N 268 ( 268-2006-п ) як для службовців апарату обласних державних адміністрацій.

{ Пункт 1 із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 66 ( z0190-07 ) від 23.02.2007 }

2. Установити, що посадові оклади державних гірничотехнічних інспекторів, які безпосередньо здійснюють нагляд за охороною праці на вугільних шахтах, небезпечних за раптовими викидами, надкатегорійних і 3-ї категорії з газу, підвищуються на 20 відсотків; на підприємствах з розвідки, видобутку і переробки уранових руд, атомних електростанціях та дослідних ядерних реакторах - на 10 відсотків; державних інспекторів, які безпосередньо здійснюють нагляд за охороною праці в хімічній промисловості з виробництва вибухових речовин і виробів на їх основі, - на 12 відсотків.

3. Зберегти за державними інспекторами, які здійснюють нагляд за охороною праці на вугільних шахтах, підприємствах з розвідки видобутку і переробки уранових руд, у хімічній промисловості з виробництва вибухових речовин і виробів на їх основі, діючий порядок і розміри виплати одноразової винагороди за вислугу років відповідно до положення, затвердженого Держнаглядохоронпраці за погодженням з Міністерством праці України від 27 жовтня 1992 року.

4. Установити, що начальники територіальних управлінь Держгірпромнагляду відносяться за оплатою праці до тих груп, до яких віднесені відповідні області за показниками, затвердженими постановою Кабінету Міністрів України від 21 липня 2005 року N 614 ( 614-2005-п ) "Деякі питання віднесення областей та міст до груп за оплатою праці" (із змінами). { Пункт 4 із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 66 ( z0190-07 ) від 23.02.2007 }

5. Уважати таким, що втратив чинність, наказ Міністерства праці та соціальної політики України від 3 вересня 2002 року N 473 ( z0744-02 ) "Про умови оплати праці працівників територіальних органів Держнаглядохоронпраці України", зареєстрований в Міністерстві юстиції України 10 вересня 2002 року за N 744/7032 (із змінами).

6. Умови оплати праці, затверджені цим наказом, застосовуються з 1 січня 2006 року.

Міністр І.Сахань
