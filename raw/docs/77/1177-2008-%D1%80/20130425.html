Про встановлення строку переробки на митній території України радіолокаційних станцій і запасних та складових частин до них

Стан: Втратив чинність

Ідентифікатор: 1177-2008-р

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 вересня 2008 р. N 1177-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку переробки на митній території України радіолокаційних станцій і запасних та складових частин до них

1. Відповідно до статті 232 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей установити для переробки на митній території України радіолокаційних станцій і запасних та складових частин до них за кодами згідно з УКТЗЕД 8526 10. 8529 10 45 00, 8529 90 72 10, 8529 90 72 90, 8529 90 88 00 ( 2371г-14 ) строк 270 днів від дня завершення митного оформлення товарів, що ввозяться із зазначеною метою.

2. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України Ю.ТИМОШЕНКО
