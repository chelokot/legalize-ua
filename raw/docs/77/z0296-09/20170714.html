Зареєстровано в Міністерстві юстиції України 2 квітня 2009 р. за N 296/16312

{ Наказ втратив чинність на підставі Наказу Міністерства аграрної політики та продовольства N 273/749 ( z0724-17 ) від 24.05.2017 }

Про внесення змін до спільного наказу Міністерства аграрної політики України та Міністерства економіки та з питань європейської інтеграції України від 23.08.2002 N 240/257

Відповідно до пункту 2 постанови Кабінету Міністрів України від 17.05.2002 N 647 ( 647-2002-п ) "Про затвердження переліку платних послуг, які можуть надаватися державними насіннєвими інспекціями Міністерства аграрної політики" НАКАЗУЄМО:

1. Наказ Міністерства аграрної політики України та Міністерства економіки та з питань європейської інтеграції України від 23.08.2002 N 240/257 ( z0729-02 ) "Про затвердження розмірів плати за надання послуг державними насіннєвими інспекціями Міністерства аграрної політики", зареєстрований в Міністерстві юстиції України 04.09.2002 за N 729/7017, після пункту 2 доповнити новим пунктом 3 такого змісту:

"3. Установити, що розмір плати за послуги, які надаються державними насіннєвими інспекціями Міністерства аграрної політики, підлягає щорічній індексації на рівень інфляційних змін на підставі даних Державного комітету статистики України".

У зв'язку з цим пункти 3, 4 наказу уважати відповідно пунктами 4, 5.

2. Українській державній насіннєвій інспекції (Чмирь С.М.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням наказу покласти на заступника Міністра Мельника С.І.
