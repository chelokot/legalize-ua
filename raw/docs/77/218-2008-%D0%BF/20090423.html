Кабінет Міністрів України; Постанова, Порядок від 19.03.2008 № 218

Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для розроблення схем та проектних рішень масового застосування

Стан: Чинний

Ідентифікатор: 218-2008-п

Текст документа від 23.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 березня 2008 р. N 218 Київ

Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для розроблення схем та проектних рішень масового застосування

{ Установити, що використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) Міністерству з питань житлово-комунального господарства за програмою "Розробка схем та проектних рішень масового застосування", здійснюється відповідно до Порядку, затвердженого цією Постановою, з урахуванням особливостей, зазначених в Постанові КМ N 352 ( 352-2009-п ) від 15.04.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для розроблення схем та проектних рішень масового застосування, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 19 березня 2008 р. N 218

ПОРЯДОК використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для розроблення схем та проектних рішень масового застосування

1. Цей Порядок визначає механізм використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) за програмою "Розробка схем та проектних рішень масового застосування" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Мінжитлокомунгосп.

3. Закупівля робіт здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

4. Головний розпорядник спрямовує бюджетні кошти на розроблення схем та проектних рішень масового застосування з комплексної реконструкції будинків застарілого житлового фонду на підставі актів фактичного виконання робіт відповідно до умов договору.

5. Перерахування бюджетних коштів проводиться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженими Державним казначейством.

6. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
