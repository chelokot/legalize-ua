КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 березня 2004 р. N 386 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 543 ( 543-2017-п ) від 19.07.2017 }

Про створення галузевого державного архіву документів, пов'язаних із захистом прав та інтересів України в закордонних юрисдикційних органах

Кабінет Міністрів України постановляє:

Створити галузевий державний архів документів, пов'язаних із захистом прав та інтересів України в закордонних юрисдикційних органах, в межах граничної чисельності працівників Міністерства юстиції.

Прем'єр-міністр України В.ЯНУКОВИЧ
