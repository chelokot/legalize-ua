Кабінет Міністрів України; Розпорядження від 17.09.1996 № 582-р

Про безоплатну передачу майна у державну власність

Стан: Втратив чинність

Ідентифікатор: 582-96-р

Текст документа від 25.12.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 вересня 1996 р. N 582-р Київ

( Розпорядження скасовано на підставі Розпорядження КМ N 752-р ( 752-97-р ) від 25.12.97 )

Прийняти пропозицію МОЗ, узгоджену з Мінекономіки, Мінфіном, Мінсільгосппродом, Фондом державного майна і підтриману Зміївською райдержадміністрацією та районною радою, Лиманською селищною радою, про безоплатну передачу радгоспу "Лиманський" (смт Лиман Харківської області) у державну власність, з віднесенням його до сфери управління МОЗ, для утворення лікувально-господарського комплексу "Занки".

Передачу зазначеного майна здійснити у місячний термін у порядку, передбаченому постановою Кабінету Міністрів України від 26 червня 1996 р. N 678 ( 678-96-п ) "Про порядок передачі державного майна".

Прем'єр-міністр України П.ЛАЗАРЕНКО
