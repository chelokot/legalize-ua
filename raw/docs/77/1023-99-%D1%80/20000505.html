Кабінет Міністрів України; Розпорядження від 27.09.1999 № 1023-р

Про здійснення митного оформлення поліграфічної продукції (альманах "Золота книга українського підприємництва")

Стан: Втратив чинність

Ідентифікатор: 1023-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 вересня 1999 р. N 1023-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення поліграфічної продукції (альманах "Золота книга українського підприємництва"), що надійшла на адресу Асоціації ділової інформації "Бізнес в Україні" (м. Київ) за договором з підприємством "Poligrafika" (м. Пряшів, Словаччина) від 3 серпня 1999 р. N 45/99, як товарів критичного імпорту, встановивши ставку ввізного мита в розмірі 0,1 відсотка митної вартості цієї продукції.

Перший віце-прем'єр-міністр України А.КІНАХ
