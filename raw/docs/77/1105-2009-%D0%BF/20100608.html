КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 жовтня 2009 р. N 1105 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про внесення змін до пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88

Кабінет Міністрів України постановляє:

Абзац перший пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) "Питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2000 р., N 4, ст. 110; 2006 р., N 52, ст. 3498; 2007 р., N 19, ст. 760; 2008 р., N 6, ст. 147, N 67, ст. 2234; 2009 р., N 45, ст. 1514, N 65, ст. 2265) викласти у такій редакції:

"2. Установити граничну чисельність працівників Секретаріату Кабінету Міністрів України - 1060 одиниць, патронатних служб керівництва Кабінету Міністрів України - 184, з них Прем'єрміністра України - 80, Першого віце-прем'єр-міністра - 25, віцепрем'єр-міністрів - 69, Міністра Кабінету Міністрів України - 10 одиниць.".
