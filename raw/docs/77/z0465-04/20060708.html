Про внесення змін до наказу Міністерства праці та соціальної політики України від 07.08.2003 N 222

На виконання постанови Кабінету Міністрів України від 11 лютого 2004 року N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ :

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 07.08.2003 N 222 ( z0713-03 ) "Про умови оплати праці працівників центрів фізичного здоров'я населення "Спорт для всіх", зареєстрованого в Міністерстві юстиції України 15.08.2003 за N 713/8034, виклавши додатки 1-3 в новій редакції (додаються).

2. Ці зміни застосовуються з 1 березня 2004 року.
