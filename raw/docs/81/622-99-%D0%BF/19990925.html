Кабінет Міністрів України; Постанова від 19.04.1999 № 622

Про впорядкування розрахунків на оптовому ринку електричної енергії

Стан: Втратив чинність

Ідентифікатор: 622-99-п

Текст документа від 25.09.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 квітня 1999 р. N 622 Київ

Про впорядкування розрахунків на оптовому ринку електричної енергії

( Із змінами, внесеними згідно з Постановами КМ N 917 ( 917-99-п ) від 27.05.99 N 975 ( 975-99-п ) від 04.06.99 N 1837 ( 1837-99-п ) від 25.09.99 )

З метою впорядкування розрахунків на оптовому ринку електричної енергії Кабінет Міністрів України постановляє:

1. Установити, що для проведення розрахунків за електричну енергію, придбану на оптовому ринку електричної енергії, можуть використовуватися векселі лише Державного казначейства, Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських державних адміністрацій.

Міністерству енергетики, Національній акціонерній компанії "Нафтогаз України" терміново забезпечити оформлення актів звіряння даних про заборгованість енергогенеруючих компаній за спожитий газ перед підприємствами акціонерного товариства "Укргазпром" та Державної акціонерної холдингової компанії "Укргаз" за 1996 - 1998 роки. ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 917 ( 917-99-п ) від 27.05.99 )

Дозволити енергогенеруючим компаніям Міністерства енергетики провести на підставі оформлених актів звіряння розрахунки векселями в межах існуючої заборгованості перед Національною акціонерною компанією "Нафтогаз України" станом на 1 квітня 1999 р. з одноразовим їх використанням на оптовому ринку електричної енергії. ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 917 ( 917-99-п ) від 27.05.99 )

Національній акціонерній компанії "Нафтогаз України" за погодженням з Міністерством енергетики забезпечити використання цих векселів для зменшення заборгованості споживачів за електричну енергію. ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 917 ( 917-99-п ) від 27.05.99 )

Обмеження, передбачені абзацом першим цього пункту, не поширюються на розрахунки із застосуванням векселів, які емітовані до набрання чинності цією постановою і внесені до реєстру інвентаризації, затвердженого Міністерством енергетики 30 квітня 1999 року. ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 975 ( 975-99-п ) від 04.06.99 )

Дозволити використання на оптовому ринку електроенергії векселів, емітованих енергопостачальними компаніями, за умови, що ці компанії проводять попереднє внесення на розподільчий рахунок Національної енергетичної компанії "Укренерго" банківськими коштами 30 відсотків вартості емітованих векселів. ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 1837 ( 1837-99-п ) від 25.09.99 )

2. Ця постанова набирає чинності з дня її опублікування.
