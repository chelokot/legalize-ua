( Наказ втратив чинність на підставі Наказу Мінпраці та соцполітики N 29 ( z0086-00 ) від 04.02.2000 )

Про внесення змін до наказу Міністерства праці України

від 07.10.93 N 78 "Про умови оплати праці працівників соціальних служб для молоді"

Відповідно до доручення Кабінету Міністрів України від 29.01.96 N 1836/30 за погодженням з Міністерством фінансів України та Міністерством України у справах молоді і спорту НАКАЗУЮ:

1. Внести такі зміни до наказу Міністерства праці України від 07.10.93 N 78 ( z0160-93 ) "Про умови оплати праці працівників соціальних служб для молоді":

1.1. Пункт 4 викласти у такій редакції:

"4. Посадові оклади керівних працівників, спеціалістів і службовців соціальних служб для молоді, визначені цим наказом, обчислюються за шкалою співвідношень посадових окладів до установленого мінімального розміру заробітної плати і підвищуються за коефіцієнтами, затвердженими постановою Кабінету Міністрів України від 25 грудня 1995 року N 1043 ( 1043-95-п ) "Про упорядкування оплати праці працівників апарату органів державної виконавчої влади, прокуратури, судів, митної служби та інших органів".

2. Вважати таким, що втратив чинність, підпункт 1.6 наказу Міністерства праці України від 18.10.95 N 43 ( z0397-95 ) "Про внесення змін і доповнень до наказу Міністерства праці України від 07.10.93 N 78 "Про умови оплати праці працівників соціальних служб для молоді".
