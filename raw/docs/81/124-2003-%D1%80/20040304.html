КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 березня 2003 р. N 124-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 105-р ( 105-2004-р ) від 04.03.2004 )

Про затвердження нового складу експертно-аналітичної групи для опрацювання пропозицій та заходів стосовно забезпечення умов стабільного функціонування ринку нафти і нафтопродуктів

На часткову зміну пункту 1 розпорядження Кабінету Міністрів України від 24 січня 2002 р. N 24 ( 24-2002-р ) затвердити новий склад експертно-аналітичної групи для опрацювання пропозицій та заходів стосовно забезпечення умов стабільного функціонування ринку нафти і нафтопродуктів, що додається.
