Про здійснення виконавчими комітетами місцевих Рад народних депутатів республіки повноважень президій Рад народних депутатів

Стан: Не застосовується на території України

Ідентифікатор: 8357-11

Текст документа від 07.05.2022:

ПОСТАНОВА ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

{ Постанова не застосовується на території України згідно із Законом N 2215-IX ( 2215-20 ) від 21.04.2022 }

Про здійснення виконавчими комітетами місцевих Рад народних депутатів республіки повноважень президій Рад народних депутатів

( Відомості Верховної Ради УРСР (ВВР), 1989, N 46, ст. 649 )

Президія Верховної Ради Української РСР постановляє:

Встановити, що до формування президій місцевих Рад народних депутатів їх повноваження, визначені законами Української РСР "Про вибори народних депутатів Української РСР" ( 8304-11 ) і "Про вибори депутатів місцевих Рад народних депутатів Української РСР" ( 8305-11 ), здійснюють виконавчі комітети місцевих Рад народних депутатів.
