Кабінет Міністрів України; Постанова від 16.10.1998 № 1638

Про продовження терміну перевірки правильності видачі посвідчень "Учасник ліквідації наслідків аварії на Чорнобильській АЕС"

Стан: Втратив чинність

Ідентифікатор: 1638-98-п

Текст документа від 25.07.2018:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 жовтня 1998 р. N 1638 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 551 ( 551-2018-п ) від 11.07.2018 }

Про продовження терміну перевірки правильності видачі посвідчень "Учасник ліквідації наслідків аварії на Чорнобильській АЕС"

( Із змінами, внесеними згідно з Постановою КМ N 979 ( 979-99-п ) від 05.06.99 )

Кабінет Міністрів України постановляє:

Погодитися з пропозицією Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи про продовження до 1 травня 1999 р. терміну чинності посвідчень "Учасник ліквідації наслідків аварії на Чорнобильській АЕС" і "Постраждалий від Чорнобильської катастрофи" (категорії 1, 2, 3 серії А) без відмітки про перереєстрацію для осіб, які станом на 1 жовтня 1998 р. не отримали відповідної довідки у Державному галузевому архіві Міністерства оборони.

Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям забезпечити своєчасну видачу зазначеним особам тимчасових вкладок відповідно до зразка, що додається.

( Продовжено термін дії посвідчення до 1 січня 2000 р. згідно з Постановою КМ N 979 ( 979-99-п ) від 05.06.99 )

У зв'язку з цим:

а) пункт 1 постанови Кабінету Міністрів України від 7 травня 1998 р. N 620 ( 620-98-п ) "Про внесення доповнень до Порядку видачі посвідчень особам, які постраждали внаслідок Чорнобильської катастрофи" (Офіційний вісник України, 1998 р., N 19, ст. 681) доповнити абзацом такого змісту:

"Посвідчення "Учасник ліквідації наслідків аварії на Чорнобильській АЕС" і "Постраждалий від Чорнобильської катастрофи" (категорії 1, 2, 3 серії А) без відмітки про перереєстрацію, передбачену у абзаці першому пункту 3 постанови Кабінету Міністрів України від 4 лютого 1997 р. N 135 ( 135-97-п ) (Офіційний вісник України, 1997 р., число 6, с. 68, число 34, с. 7; 1998 р., N 19, ст. 681), з тимчасовими вкладками затвердженого цією постановою зразка для осіб, які не отримали станом на 1 жовтня 1998 р. відповідної довідки у Державному галузевому архіві Міністерства оборони, вважаються чинними до 1 травня 1999 року";

б) доповнити абзац перший пункту 3 та абзац перший пункту 5 Порядку видачі посвідчень особам, які постраждали внаслідок Чорнобильської катастрофи, затвердженого постановою Кабінету Міністрів України від 20 січня 1997 р, N 51 ( 51-97-п ) (Офіційний вісник України, 1997 р., число 5, с. 71; 1998 р., N 19, ст. 681), реченням такого змісту: "Посвідчення "Учасник ліквідації наслідків аварії на Чорнобильській АЕС" і "Постраждалий від Чорнобильської катастрофи" (категорії 1, 2, З серії А) без відмітки про перереєстрацію, передбачену у абзаці першому пункту 3 постанови Кабінету Міністрів України від 4 лютого 1997 р. N 135 ( 135-97-п ) (Офіційний вісник України, 1997 р., число 6, с. 68, число 34, с. 7; 1998 р., N 19, ст. 681), з тимчасовими вкладками затвердженого цією постановою зразка для осіб, які станом на 1 жовтня 1998 р. не отримали відповідної довідки у Державному галузевому архіві Міністерства оборони, вважаються чинними до 1 травня 1999 року".
