Про внесення змін до складу Комісії при Президентові України з питань громадянства

На часткову зміну статті 1 Указу Президента України від 30 квітня 2005 року N 740 ( 740/2005 ) "Про Комісію при Президентові України з питань громадянства" (зі змінами, внесеними Указом від 28 лютого 2008 року N 183) ( 183/2008 ) увести до складу Комісії при Президентові України з питань громадянства КУПЧИШИНА Олександра Михайловича - заступника Міністра закордонних справ України, вивівши з її складу Ю. Костенка.
