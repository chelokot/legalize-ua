ПОРЯДОК
допущення транспортних засобів та контейнерів до перевезення товарів під митними пломбами в режимі спільного транзиту

1. Транспортні засоби та контейнери вважаються придатними до перевезення товарів під митними пломбами в режимі спільного транзиту за умови, що їх конструкція та обладнання відповідають таким основним вимогам:

місця для накладення пломб сконструйовано для надійного та легкого накладання запірно-пломбувальних засобів та пломб;

конструкцію транспортного засобу чи контейнера спроєктовано та реалізовано так, щоб виключити можливість доступу, вилучення, заміни та/або підміни товарів або їх частини в опломбованій частині без залишення слідів несанкціонованого втручання чи спроби втручання без порушення цілісності пломб або без реєстрації такої події електронними системами реєстрації доступу чи проникнення;

конструкція транспортного засобу чи контейнера не містить прихованих порожнин та відсіків, які могли б бути використані для приховування товарів;

конструкція вантажного відсіку транспортного засобу чи контейнера, у якому безпосередньо розміщуються товари під час їх транспортування, забезпечує вільний доступ для проведення митного контролю;

складові конструктивні елементи вантажного відсіку транспортного засобу мають з'єднуватися за допомогою конструкцій, які не можуть бути зняті зовні та знову поставлені на місце без залишення видимих слідів, або з'єднуються у спосіб, що забезпечує таку конструкцію, яка не може бути змінена без залишення видимих слідів.

2. У разі якщо вантажний відсік транспортного засобу покрито тентом, такий тент має бути виготовлено з брезенту зі щільної тканини, міцного полотна чи нерозтяжної прогумованої тканини, просоченої водонепроникним розчином. Тент має бути у справному стані і виготовлений таким чином, щоб під час закріплення пристосування для закривання доступ до вантажного відсіку транспортного засобу був неможливий без залишення видимих слідів.

Трос для закріплення тенту має складатися з одного елемента і мати металеві наконечники на обох кінцях. Пристосування для кріплення кожного металевого наконечника має включати заклепку, що проходить через трос або мотузку і через яку може бути протягнено мотузку або стрічку для митних пломб. Трос має залишатися видимим по обидва боки порожньої заклепки, щоб можна було впевнитися в тому, що вони дійсно складаються виключно з одного елемента.

3. Можливість накладання запірно-пломбувальних засобів та пломб на пристрої для пломбування дверей, завантажувальних та розвантажувальних люків, інших конструктивних отворів на залізничних транспортних засобах (вагонах, цистернах, хоперах тощо) з метою контролю доступу чи проникнення до опломбованого вантажного відсіку визначається технічною документацією заводу виробника цих транспортних засобів.

4. У разі якщо придатність транспортних засобів для опломбування офіційно затверджено згідно з міжнародними Конвенціями, такі транспортні засоби вважаються допущеними для перевезення товарів під митними пломбами.

5. Дорожні транспортні засоби та контейнери, що відповідають міжнародним технічним вимогам, наведеним у додатках 2, 7 до Митної конвенції про міжнародне перевезення вантажів із застосуванням книжки МДП (Конвенція МДП) 1975 року, додатку 4 до Митної конвенції, що стосується контейнерів, 1972 року, вважаються допущеними для перевезення товарів під митними пломбами.
