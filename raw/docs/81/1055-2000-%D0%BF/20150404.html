Про створення галузевого державного архіву фінансових посередників Фонду державного майна

Стан: Втратив чинність

Ідентифікатор: 1055-2000-п

Текст документа від 04.04.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 липня 2000 р. N 1055 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 145 ( 145-2015-п ) від 25.03.2015 }

Про створення галузевого державного архіву фінансових посередників Фонду державного майна

{ Із змінами, внесеними згідно з Постановою КМ N 330 ( 330-2001-п ) від 04.04.2001 }

Відповідно до статті 9 Закону України "Про Національний архівний фонд і архівні установи" ( 3814-12 ) Кабінет Міністрів України постановляє:

1. Утворити галузевий державний архів фінансових посередників Фонду державного майна для постійного зберігання документів Національного архівного фонду, що оформлюються у процесі приватизації державної власності.

2. Державному комітетові архівів та Фондові державного майна у місячний термін затвердити положення про галузевий державний архів фінансових посередників Фонду державного майна та про порядок передачі документів щодо укладених та виконаних фінансовими посередниками угод з приватизаційними паперами.

3. Взяти до відома, що забезпечення галузевого державного архіву фінансових посередників Фонду державного майна технологічним обладнанням та матеріальними ресурсами, а також комплектування штату його працівників здійснюватиметься Державною акціонерною компанією "Національна мережа аукціонних центрів".

Фондові державного майна відповідно до договорів, укладених з Державною акціонерною компанією "Національна мережа аукціонних центрів", здійснювати в установленому порядку фінансування створення, функціонування та забезпечення приміщеннями зазначеного архіву.

4. Прийняти пропозицію Фонду державного майна, погоджену з Державним управлінням справами, про розміщення галузевого державного архіву фінансових посередників Фонду державного майна у приміщеннях павільйону N 16 Національного комплексу "Експоцентр України" загальною площею до 1200 кв. метрів по просп. Академіка Глушкова, 1, у м. Києві на умовах оренди. ( Пункт 4 в редакції Постанови КМ N 330 ( 330-2001-п ) від 04.04.2001 )
