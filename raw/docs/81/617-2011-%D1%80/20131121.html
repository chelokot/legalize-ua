Про призначення повноважних представників від Уряду України у Міждержавній раді з антимонопольної політики

Стан: Чинний

Ідентифікатор: 617-2011-р

Текст документа від 21.11.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 червня 2011 р. N 617-р Київ

Про призначення повноважних представників від Уряду України у Міждержавній раді з антимонопольної політики

{ Із змінами, внесеними згідно з Розпорядженням КМ N 927-р ( 927-2013-р ) від 21.11.2013 }

Призначити Голову Антимонопольного комітету Цушка Василя Петровича та заступника Голови Антимонопольного комітету - державного уповноваженого Влада Федора Івановича повноважними представниками від Уряду України у Міждержавній раді з антимонопольної політики, заснованій для реалізації Договору про проведення узгодженої антимонопольної політики ( 997_502 ), підписаного 25 січня 2000 р. у м. Москві, увільнивши від цих обов'язків Костусєва Олексія Олексійовича та Черненка Сергія Олександровича.

{ Текст Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 927-р ( 927-2013-р ) від 21.11.2013 }
