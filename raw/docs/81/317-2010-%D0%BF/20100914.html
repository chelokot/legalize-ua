Про видатки, пов'язані з проведенням святкування 65-ї річниці Перемоги у Великій Вітчизняній війні 1941-1945 років

Стан: Чинний

Ідентифікатор: 317-2010-п

Текст документа від 14.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 квітня 2010 р. N 317 Київ

Про видатки, пов'язані з проведенням святкування 65-ї річниці Перемоги у Великій Вітчизняній війні 1941-1945 років

{ Із змінами, внесеними згідно з Постановами КМ N 694 ( 694-2010-п ) від 04.08.2010 N 811 ( 811-2010-п ) від 02.09.2010 }

З метою забезпечення фінансування заходів, пов'язаних з проведенням святкування 65-ї річниці Перемоги у Великій Вітчизняній війні 1941-1945 років, Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 694 ( 694-2010-п ) від 04.08.2010 }

2. Затвердити Порядок використання коштів для здійснення заходів, пов'язаних з проведенням святкування 65-ї річниці Перемоги у Великій Вітчизняній війні 1941-1945 років, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 19 квітня 2010 р. N 317

ПОРЯДОК використання коштів для здійснення заходів, пов'язаних з проведенням святкування 65-ї річниці Перемоги у Великій Вітчизняній війні 1941-1945 років

1. Цей Порядок визначає механізм використання коштів у сумі 2500 тис. гривень за окремою бюджетною програмою КПКВК 2505040 ( 835-17 ) для здійснення заходів, пов'язаних з проведенням святкування 65-ї річниці Перемоги у Великій Вітчизняній війні 1941-1945 років (далі - бюджетні кошти).

Головним розпорядником бюджетних коштів є Мінпраці, а розпорядником бюджетних коштів нижчого рівня - Держкомветеранів.

2. Бюджетні кошти спрямовуються на:

оплату відряджень у межах України та за кордон членів офіційних українських делегацій із числа ветеранів війни та медичних працівників, що їх супроводжують (придбання квитків, страхових полісів, оплата вартості проживання, сплата зборів та оформлення візових документів, відшкодування добових витрат);

обслуговування на території України членів іноземних делегацій (обслуговування в залах офіційних делегацій, аеропортах та на залізничних вокзалах, транспортне обслуговування, відшкодування витрат на проїзд, оплата вартості проживання та харчування, здійснення видатків, пов'язаних з проведенням прийомів);

оплату послуг із синхронного та послідовного перекладу, що здійснюється під час проведення заходів за участю іноземних делегацій, оренду обладнання, необхідного для надання таких послуг;

придбання сувенірної, книжкової та квіткової продукції для членів іноземних делегацій і ветеранів війни України;

здійснення видатків, пов'язаних з обслуговуванням урочистої зустрічі з Героями Радянського Союзу, повними кавалерами ордену Слави, особами, нагородженими чотирма і більше медалями "За відвагу", Героями Соціалістичної Праці, що отримали це звання в період Великої Вітчизняної війни 1941-1945 років, та представниками громадських організацій ветеранів (відшкодування витрат на проїзд, оплата вартості проживання та харчування);

проведення урочистих зборів та святкових концертів за участю ветеранів війни та праці. { Пункт 2 доповнено абзацом згідно з Постановою КМ N 811 ( 811-2010-п ) від 02.09.2010 }

3. Видатки, пов'язані з відшкодуванням витрат на проїзд, добових витрат, оплатою вартості проживання та харчування, придбанням сувенірів, книжкової продукції та квітів, здійснюються у розмірах, визначених Мінпраці.

4. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється в одного виконавця без погодження з Мінекономіки.

5. Перерахування бюджетних коштів проводиться відповідно до Порядку обслуговування державного бюджету, затвердженого Державним казначейством.

6. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому порядку.
