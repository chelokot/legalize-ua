Кабінет Міністрів України; Розпорядження від 17.08.1998 № 689-р

Про закріплення у державній власності пакету акцій ВАТ "Олімп", м. Світловодськ

Стан: Втратив чинність

Ідентифікатор: 689-98-р

Текст документа від 13.09.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 серпня 1998 р. N 689-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 358-р ( 358-2000-р ) від 13.09.2000 )

Відповідно до пункту 14 Державної програми приватизації на 1998 рік ( 124/98-ВР ) закріпити у державній власності на 3 роки пакет акцій у розмірі 25 відсотків статутного фонду плюс одна акція ВАТ "Олімп", м. Світловодськ.
