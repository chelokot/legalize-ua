РОЗПОРЯДЖЕННЯ від 30 березня 2005 р. N 75-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Міжвідомчої координаційної комісії з питань підтримки індивідуального житлового будівництва на селі

Затвердити Першого віце-прем'єр-міністра України Кінаха Анатолія Кириловича головою Міжвідомчої координаційної комісії з питань підтримки індивідуального житлового будівництва на селі ( 376-97-п ), увільнивши від цих обов'язків Кириленка Івана Григоровича.

Дозволити голові Комісії вносити у разі потреби зміни до її складу.

Прем'єр-міністр України Ю.ТИМОШЕНКО
