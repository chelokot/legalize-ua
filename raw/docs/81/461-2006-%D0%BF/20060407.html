Текст документа від 07.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 квітня 2006 р. N 461 Київ

Про затвердження Порядку використання у 2006 році коштів, передбачених у державному бюджеті на придбання плавзасобів для територіальних органів Міністерства охорони навколишнього природного середовища

На виконання статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2006 році коштів, передбачених у державному бюджеті ( 3235-15 ) на придбання плавзасобів для територіальних органів Міністерства охорони навколишнього природного середовища, що додається.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 квітня 2006 р. N 461

ПОРЯДОК використання у 2006 році коштів, передбачених у державному бюджеті ( 3235-15 ) на придбання плавзасобів для територіальних органів Міністерства охорони навколишнього природного середовища

1. Цей Порядок визначає механізм використання у 2006 році коштів, передбачених у державному бюджеті ( 3235-15 ) Мінприроди за програмою "Придбання плавзасобів для територіальних органів" (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються на придбання плавзасобів (морських та річкових катерів, трейлерів до них, човнів надувних з двигунами) для оснащення територіальних органів Мінприроди.

3. Перелік плавзасобів, які планується придбати за рахунок бюджетних коштів, затверджується Мінприроди.

4. Мінприроди доводить перелік плавзасобів та відомості про обсяги бюджетних асигнувань Державній екологічній інспекції як розпоряднику бюджетних коштів нижчого рівня.

5. Закупівля плавзасобів здійснюється Державною екологічною інспекцією згідно із Законом України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

6. Видатки з проведення закупівлі плавзасобів здійснюються відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

7. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
