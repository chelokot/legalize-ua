ПОСТАНОВА

21.07.2004 N 337

{ Постанова втратила чинність на підставі Постанови Національного банку N 434 ( v0434500-06 ) від 14.11.2006 }

( Із змінами, внесеними згідно з Постановою Національного банку N 571 ( v_571500-04 ) від 28.11.2004 )

(Витяг)

1. ( Пункт 1 втратив чинність на підставі Постанови Національного банку N 571 ( v_571500-04 ) від 28.11.2004 )

2. З 26 липня 2004 року Національний банк України може залучати кошти банків і проводити з ними депозитні операції за умови, що сума депозитів на вимогу в загальній сумі залучених банком коштів від юридичних та фізичних осіб становить не більше 60 процентів.
