Кабінет Міністрів України; Розпорядження від 28.04.2000 № 201-р

Про затвердження нового складу міжвідомчої робочої групи з координації роботи та підготовки проектів рішень щодо проведення пенсійної реформи

Стан: Втратив чинність

Ідентифікатор: 201-2000-р

Текст документа від 11.04.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 квітня 2000 р. N 201-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 496 ( 496-2002-п ) від 11.04.2002 )

1. Затвердити новий склад міжвідомчої робочої групи з координації роботи та підготовки проектів рішень щодо проведення пенсійної реформи та новий склад міжвідомчої експертної робочої групи з розроблення пропозицій та проектів законодавчих актів щодо проведення пенсійної реформи, утворених розпорядженням Кабінету Міністрів України від 6 квітня 1999 р. N 272 ( 272-99-р ) (додаються).

Надати право керівнику міжвідомчої робочої групи з координації роботи та підготовки проектів рішень щодо проведення пенсійної реформи вносити зміни до складу цієї міжвідомчої групи, а також до складу міжвідомчої експертної робочої групи з розроблення пропозицій та проектів законодавчих актів щодо проведення пенсійної реформи.

2. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 10 листопада 1999 р. N 1222 ( 1222-99-р ) та від 1 лютого 2000 р. N 65 ( 65-2000-р ).
