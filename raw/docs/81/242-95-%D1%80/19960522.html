Текст документа від 22.05.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 квітня 1995 p. N 242-р Київ

Про склад офіційної урядової делегації для проведення міжнародних переговорів з питань Чорнобильської АЕС

( Із змінами, внесеними згідно з Розпорядженням КМ N 360-р ( 360-96-р ) від 22.05.96 )

Для проведення переговорів з делегаціями і представниками Урядів іноземних держав і міжнародних організацій з питань розв'язання проблем Чорнобильської АЕС затвердити склад офіційної урядової делегації згідно з додатком N 1, а також склад Спеціальної робочої групи експертів для підготовки та опрацювання спільно з іноземними експертами пропозицій щодо комплексного розв'язання Чорнобильської проблеми згідно з додатком N 2.

Виконуючий обов'язки Прем'єр-міністра України Є. МАРЧУК

КУХАРЬ - - голова Комісії з питань ядерної Валерій Павлович політики та екологічної безпеки при Президентові України (за згодою)
