Зареєстровано в Міністерстві юстиції України 1 березня 2004 р. за N 264/8863

Про втрату чинності наказу Фонду державного майна України від 28.04.2001 N 763

Відповідно до абзацу шостого пункту 75 Методики оцінки майна, затвердженої постановою Кабінету Міністрів України від 10.12.2003 N 1891 ( 1891-2003-п ), НАКАЗУЮ:

1. Вважати таким, що втратив чинність, наказ Фонду державного майна України від 28.04.2001 N 763 ( z0432-01 ) "Про затвердження Положення про порядок експертної оцінки цілісних майнових комплексів під час їх приватизації шляхом викупу та конкурентними способами", зареєстрований у Міністерстві юстиції України 21.05.2001 за N 432/5623.

2. Департаменту оцінки майна, майнових прав та професійної оціночної діяльності (Н.Лебідь) подати цей наказ у встановленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Д.Парфененка.
