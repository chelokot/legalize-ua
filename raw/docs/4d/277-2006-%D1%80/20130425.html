КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 травня 2006 р. N 277-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про внесення змін до пункту 1 розпорядження Кабінету Міністрів України від 8 жовтня 2004 р. N 712

1. Внести допункту 1 розпорядження Кабінету Міністрів України від 8 жовтня 2004 р. N 712 ( 712-2004-р ) "Про встановлення строку виконання операцій з ремонту та будівництва (складання) залізничних пасажирських вагонів"(Офіційний вісник України, 2004 р., N 51, ст. 3365) такі зміни:

доповнити пункт після слова "вагонів" словами і цифрами "за кодом згідно з УКТЗЕД ( 2371г-14 ) 8605 00 00 00";

цифри "180" замінити цифрами "360".

2. Це розпорядження набирає чинності з дня опублікування.
