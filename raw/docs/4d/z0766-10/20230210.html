МІНІСТЕРСТВО УКРАЇНИ У СПРАВАХ СІМ'Ї, МОЛОДІ ТА СПОРТУ

НАКАЗ

06.08.2010 N 2659

Зареєстровано в Міністерстві юстиції України 1 вересня 2010 р. за N 766/18061

Про затвердження Вимог до змісту положення (регламенту) про офіційні фізкультурно-оздоровчі, спортивні заходи або спортивні змагання

{ Заголовок із змінами, внесеними згідно з Наказом Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }

{ Із змінами, внесеними згідно з Наказом Міністерства України у справах сім'ї, молоді та спорту N 141 ( z0182-11 ) від 25.01.2011 Наказом Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }

Відповідно до Закону України від 17 листопада 2009 року N 1724-VI ( 1724-17 ) "Про внесення змін до Закону України "Про фізичну культуру і спорт" та інших законодавчих актів України" НАКАЗУЮ:

1. Затвердити Вимоги до змісту положення (регламенту) про офіційні фізкультурно-оздоровчі, спортивні заходи або спортивні змагання, що додаються.

{ Пункт 1 із змінами, внесеними згідно з Наказом Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }

2. Департаментам олімпійського спорту, фізичної культури та неолімпійських видів спорту, Республіканському комітету з фізичної культури і спорту Ради міністрів Автономної Республіки Крим, структурним підрозділам з фізичної культури і спорту обласних, Київської та Севастопольської міських державних адміністрацій спільно з громадськими об'єднаннями з видів спорту при проведенні офіційних фізкультурно-оздоровчих, спортивних заходів або спортивних змагань дотримуватись зазначених Вимог.

{ Пункт 2 із змінами, внесеними згідно з Наказом Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }

3. Департаменту фізичного виховання та масового спорту забезпечити державну реєстрацію цього наказу у Міністерстві юстиції України у встановленому порядку.

4. Контроль за виконанням цього наказу покласти на заступників Міністра молоді та спорту України відповідно до розподілу функціональних обов’язків.

{ Пункт 4 із змінами, внесеними згідно з Наказом Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }

5. Цей наказ набирає чинності з 1 січня 2011 року.

ЗАТВЕРДЖЕНО Наказ Міністерства України у справах сім'ї, молоді та спорту 06.08.2010 N 2659

Зареєстровано в Міністерстві юстиції України 1 вересня 2010 р. за N 766/18061

ВИМОГИ до змісту положення (регламенту) про офіційні фізкультурно-оздоровчі, спортивні заходи або спортивні змагання

{ Заголовок із змінами, внесеними згідно з Наказом Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }

{ У тексті Вимог слово "захід" у всіх відмінках та числах замінено словами "захід та/або змагання" у відповідних відмінках та числах згідно з Наказом Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }

1. Ці Вимоги стосуються складання положення (регламенту) про офіційні фізкультурно-оздоровчі, спортивні заходи або спортивні змагання (далі - положення про захід або змагання), що включені до Єдиного календарного плану фізкультурно-оздоровчих, спортивних заходів та спортивних змагань України, календарних планів фізкультурно-оздоровчих, спортивних заходів та спортивних змагань Автономної Республіки Крим, областей, міст Києва та Севастополя, календарних планів фізкультурно-оздоровчих, спортивних заходів та спортивних змагань районів, міст, селищ та сіл.

{ Пункт 1 в редакції Наказу Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }

2. Положення про захід та/або змагання - документ, що визначає умови його проведення і включає такі розділи:

цілі і завдання заходу та/або змагання;

строки і місце проведення заходу та/або змагання;

організація та керівництво проведенням заходу та/або змагання;

учасники заходу та/або змагання;

характер заходу та/або змагання (змагання особисті, командні, особисто-командні);

програма проведення заходу та/або змагань; { Абзац сьомий пункту 2 із змінами, внесеними згідно з Наказом Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }

безпека та підготовка місць проведення заходу та/або змагання;

умови визначення першості та нагородження переможців і призерів;

умови фінансування заходу та/або змагання та матеріального забезпечення учасників;

строки та порядок подання заявок на участь у заході та/або змагання;

інші умови, які забезпечують якісне проведення конкретного заходу та/або змагання.

3. Положення про захід та/або змагання розробляється на підставі правил спортивних змагань з видів спорту, затверджених в установленому порядку.

4. Положення про захід та/або змагання розробляється на календарний рік або, у разі потреби, на кожний окремий захід та/або змагання та затверджується організатором цього заходу та/або змагання не пізніше ніж за два місяці до початку його проведення.

5. Положення про захід та/або змагання, затверджене організатором цього заходу та/або змагання, погоджується відповідною спортивною федерацією (асоціацією, спілкою, об'єднанням тощо) з виду спорту, яка має всеукраїнський або місцевий статус, у разі покладення на цю спортивну федерацію за її згодою певних функцій або в разі здійснення цією спортивною федерацією фінансових витрат на проведення цього заходу та/або змагання.

6. Відповідно до частини одинадцятої статті 20 Закону України "Про фізичну культуру і спорт" ( 3808-12 ) положення про проведення відповідних всеукраїнських спортивних змагань центральний орган виконавчої влади, що забезпечує формування державної політики у сфері фізичної культури і спорту затверджує з урахуванням пропозицій національних спортивних федерацій.

{ Вимоги доповнено новим пунктом 6 згідно з Наказом Міністерства України у справах сім'ї, молоді та спорту N 141 ( z0182-11 ) від 25.01.2011; із змінами, внесеними згідно з Наказом Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }

7. У разі проведення фізкультурно-оздоровчого, спортивного заходу та/або змагання або спортивного змагання громадським об’єднанням фізкультурно-спортивної спрямованості положення про захід та/або змагання затверджується організатором за погодженням із структурним підрозділом з фізичної культури і спорту відповідної місцевої державної адміністрації або органу місцевого самоврядування.

{ Пункт 7 із змінами, внесеними згідно з Наказом Міністерства молоді та спорту N 5272 ( z0095-23 ) від 31.12.2022 }
