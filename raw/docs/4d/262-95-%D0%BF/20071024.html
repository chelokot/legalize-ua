{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Української частини Українсько-Білоруської комісії з питань торговельно-економічного співробітництва

Кабінет Міністрів України ПОСТАНОВЛЯЄ:

Призначити заступника Міністра машинобудування, військово-промислового комплексу і конверсії Тимощенкова Володимира Георгійовича головою Української частини Українсько-Білоруської комісії з питань торговельно-економічного співробітництва, звільнивши від цих обов'язків Колісніченка Леоніда Миколайовича.
