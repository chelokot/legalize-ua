УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 259/2009 ( 259/2009 ) від 22.04.2009 }

Про зупинення дії розпорядження Кабінету Міністрів України від 7 травня 2008 року N 693-р

{ Додатково див. Конституційне подання Президента ( n0014100-08 ) від 19.05.2008 }

Кабінетом Міністрів України 7 травня 2008 року видано розпорядження N 693-р ( 693-2008-р ) "Про надання Держкомрезерву розстрочки із сплати ввізного мита стосовно товарів 02 і 17 груп згідно з УКТЗЕД".

Цим розпорядженням Кабінет Міністрів України доручив Державній митній службі України надавати Державному комітету України з державного матеріального резерву протягом 2008 року розстрочку із сплати ввізного мита під час митного оформлення товарів 02 і 17 груп згідно з Українською класифікацією товарів зовнішньоекономічної діяльності (УКТЗЕД) ( 2371а-14 ) на умовах податкового кредиту до загального фонду державного бюджету ( 107-17 ) протягом IV кварталу поточного року. Таким чином, у розпорядженні фактично йдеться про запровадження відстрочення термінів сплати ввізного мита під час митного оформлення зазначених товарів.

Розпорядження N 693-р ( 693-2008-р ) видано Кабінетом Міністрів України всупереч Конституції України ( 254к/96-ВР ), яка зобов'язує Кабінет Міністрів України забезпечувати виконання Конституції ( 254к/96-ВР ) і законів України (пункт 1 статті 116), із перевищенням наданих йому повноважень.

Законом України "Про Державний бюджет України на 2008 рік та про внесення змін до деяких законодавчих актів України" ( 107-17 ) заборонено у 2008 році надання відстрочок щодо термінів сплати податкових зобов'язань за податками, зборами, обов'язковими платежами (стаття 63) і при цьому не передбачено повноважень для Кабінету Міністрів України запроваджувати інше, встановлювати винятки з цього правила.

Відтак, видавши назване розпорядження, Кабінет Міністрів України вийшов за межі своїх повноважень, визначених Конституцією ( 254к/96-ВР ) і законами України, чим порушив, крім зазначеної, також вимоги положень частини другої статті 6, частини другої статті 19 та частини третьої статті 113 Основного Закону України ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, а також діяти в межах повноважень, на підставі та у спосіб, що ними передбачені.

Ураховуючи наведене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 7 травня 2008 року N 693-р ( 693-2008-р ) "Про надання Держкомрезерву розстрочки із сплати ввізного мита стосовно товарів 02 і 17 груп згідно з УКТЗЕД".

2. Цей Указ набирає чинності з дня його опублікування.
