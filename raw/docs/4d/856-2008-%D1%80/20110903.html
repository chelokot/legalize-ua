Текст документа від 03.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 червня 2008 р. N 856-р Київ

Про визначення компетентного органу з виконання Угоди між Україною та Грузією про взаємну правову охорону географічних зазначень для вин, спиртних напоїв та мінеральних вод

{ Із змінами, внесеними згідно з Постановою КМ N 904 ( 904-2011-п ) від 31.08.2011 }

Визначити Державну службу інтелектуальної власності компетентним органом з виконання Угоди між Україною та Грузією про взаємну правову охорону географічних зазначень для вин, спиртних напоїв та мінеральних вод ( 268_078 ), учиненої 1 березня 2007 р. у м. Тбілісі.

{ Текст Розпорядження із змінами, внесеними згідно з Постановою КМ N 904 ( 904-2011-п ) від 31.08.2011 }
