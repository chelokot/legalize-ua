Держнаглядохоронпраці; Наказ від 03.02.1994 № 8

Про доповнення до Типового положення про комісію з питань охорони праці підприємства

Реєстрація: Мін'юст України від 24.02.1994 № 31/240

Стан: Втратив чинність

Ідентифікатор: z0031-94

Текст документа від 15.04.2007:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ПО НАГЛЯДУ ЗА ОХОРОНОЮ ПРАЦІ

НАКАЗ

N 8 від 03.02.94 Зареєстровано в Міністерстві м.Київ юстиції України 24 лютого 1994 р. за N 31/240

{ Наказ втратив чинність на підставі Наказу Державного комітету України з промислової безпеки, охорони праці та гірничого нагляду N 55 ( z0311-07 ) від 21.03.2007 }

Про доповнення до Типового положення про комісію з питань охорони праці підприємства

На виконання Закону України "Про пожежну безпеку" ( 3745-12 ) НАКАЗУЮ:

1. Доповнити Типове положення про комісію з питань охорони праці підприємства, затверджене наказом Держнаглядохоронпраці від 03.08.93 N 72 ( z0141-93 ), пунктом 16 у такій редакції:

"п.16. У виняткових випадках комісія з питань охорони праці може виконувати функції пожежно-технічної комісії".
