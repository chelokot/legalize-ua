Про проведення у Волинській області експерименту з надання пільг у грошовій формі з оплати електроенергії

Стан: Чинний

Ідентифікатор: 866-2010-п

Текст документа від 19.12.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 вересня 2010 р. N 866 Київ

Про проведення у Волинській області експерименту з надання пільг у грошовій формі з оплати електроенергії

{ Із змінами, внесеними згідно з Постановами КМ N 23 ( 23-2011-п ) від 19.01.2011 N 1339 ( 1339-2011-п ) від 21.12.2011 N 1153 ( 1153-2012-п ) від 14.12.2012 }

Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Волинської обласної державної адміністрації про проведення в області у другому півріччі 2010 р. та у 2011-2013 роках експерименту з надання пільг у грошовій формі з оплати електроенергії громадянам, які мають відповідне право згідно із законом (далі - експеримент).

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 23 ( 23-2011-п ) від 19.01.2011, N 1339 ( 1339-2011-п ) від 21.12.2011, N 1153 ( 1153-2012-п ) від 14.12.2012 }

2. Затвердити Порядок надання громадянам пільг у грошовій формі з оплати електроенергії під час проведення експерименту у Волинській області, що додається.

3. Фінансування витрат, пов'язаних з наданням громадянам пільг у грошовій формі з оплати електроенергії під час проведення експерименту, здійснюється за рахунок визначеної законами України про державний бюджет на відповідний рік субвенції з державного бюджету місцевим бюджетам на надання передбачених законодавством пільг та житлових субсидій населенню на оплату електроенергії, природного газу, послуг тепло-, водопостачання і водовідведення, квартирної плати (утримання будинків і споруд та прибудинкових територій), вивезення побутового сміття та рідких нечистот згідно з Порядком фінансування видатків місцевих бюджетів на здійснення заходів з виконання державних програм соціального захисту населення за рахунок субвенцій з державного бюджету, затвердженим постановою Кабінету Міністрів України від 4 березня 2002 р. N 256 ( 256-2002-п ) (Офіційний вісник України, 2002 р., N 10, ст. 482; 2003 р., N 44, ст. 2399).

{ Пункт 3 із змінами, внесеними згідно з Постановами КМ N 23 ( 23-2011-п ) від 19.01.2011, N 1339 ( 1339-2011-п ) від 21.12.2011, N 1153 ( 1153-2012-п ) від 14.12.2012 }

4. Міністерству фінансів, Державній казначейській службі забезпечити своєчасне перерахування зазначеної у пункті 3 цієї постанови субвенції.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 1339 ( 1339-2011-п ) від 21.12.2011 }

5. Міністерству соціальної політики надати Волинській обласній державній адміністрації методичну допомогу у проведенні експерименту та розробити відповідне програмне забезпечення.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 1153 ( 1153-2012-п ) від 14.12.2012 }

6. Волинській обласній державній адміністрації:

забезпечити проведення експерименту на території області;

організувати інформаційно-роз'яснювальну роботу серед населення;

інформувати щокварталу до 20 числа місяця, що настає за звітним періодом, Кабінет Міністрів України і Міністерство соціальної політики про хід експерименту. { Абзац четвертий пункту 6 із змінами, внесеними згідно з Постановою КМ N 1153 ( 1153-2012-п ) від 14.12.2012 }

Прем'єр-міністр України М.АЗАРОВ

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 22 вересня 2010 р. N 866

ПОРЯДОК надання громадянам пільг у грошовій формі з оплати електроенергії під час проведення експерименту у Волинській області

1. Цей Порядок визначає механізм надання пільг у грошовій формі з оплати електроенергії під час проведення експерименту у Волинській області (далі - грошова виплата).

2. Дія цього Порядку поширюється на громадян та членів їх сімей, які мають право на пільги з оплати електроенергії, установлені законами.

Громадянину, який має право на пільги згідно з кількома законами, призначається грошова виплата згідно з одним законом за його вибором.

Дія Порядку не поширюється на осіб, які мають особливі заслуги та особливі трудові заслуги перед Батьківщиною.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 23 ( 23-2011-п ) від 19.01.2011 }

3. Надання пільг у грошовій формі з оплати електроенергії здійснюється органами праці та соціального захисту населення на підставі заяви громадянина, який має право на відповідні пільги (далі - пільговик), і даних Єдиного державного автоматизованого реєстру осіб, які мають право на пільги.

4. Сума грошової виплати визначається виходячи з розміру знижки, на яку пільговик має право згідно із законом, з урахуванням встановленої норми споживання електроенергії та тарифів на неї.

Сума грошової виплати пільговикам, які проживають у 30-кілометровій зоні атомних електростанцій, визначається з урахуванням частини третьої статті 17 Закону України "Про електроенергетику" ( 575/97-ВР ).

У разі затвердження нових тарифів на електроенергію органи праці та соціального захисту населення проводять перерахунок сум грошових виплат.

5. Грошові виплати здійснюються щомісяця через державні підприємства поштового зв'язку або перераховуються на особистий рахунок пільговика в банку (за його вибором).

Грошова виплата може здійснюватися уповноваженій пільговиком особі на підставі виданої ним довіреності.

6. Органи праці та соціального захисту населення подають органам Казначейства реєстри пільговиків із зазначенням сум грошових виплат та платіжні доручення.

{ Пункт 6 із змінами, внесеними згідно з Постановою КМ N 1339 ( 1339-2011-п ) від 21.12.2011 }

7. У випадку смерті пільговика недоотримані кошти можуть бути виплачені одному з повнолітніх дієздатних членів його сім'ї на підставі поданої ним заяви до закінчення бюджетного періоду.

Грошова виплата за місяць, в якому настала смерть пільговика, здійснюється в повному обсязі у разі, коли заява надійшла не пізніше шести місяців з дня смерті.

8. Операції, пов'язані з використанням коштів державного та місцевого бюджетів, здійснюються в установленому законодавством порядку.

{ Пункт 8 із змінами, внесеними згідно з Постановою КМ N 1339 ( 1339-2011-п ) від 21.12.2011 }

9. Складення та подання фінансової та бюджетної звітності про використання бюджетних коштів, а також контроль за їх цільовим і ефективним витрачанням, здійснюються в установленому законодавством порядку.

{ Пункт 9 із змінами, внесеними згідно з Постановою КМ N 1339 ( 1339-2011-п ) від 21.12.2011 }
