КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 липня 2001 р. N 304-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову міжвідомчої координаційної комісії з питань підтримки індивідуального житлового будівництва на селі

Затвердити Віце-прем'єр-міністра України Козаченка Леоніда Петровича головою міжвідомчої координаційної комісії з питань підтримки індивідуального житлового будівництва на селі ( 376-97-п ), увільнивши від цих обов'язків Гладія Михайла Васильовича.
