Про внесення змін до деяких розпоряджень Кабінету Міністрів України

Стан: Втратив чинність

Ідентифікатор: 785-99-р

Текст документа від 17.04.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 серпня 1999 р. N 785-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 187-р ( 187-2000-р ) від 17.04.2000 )

( Додатково див. Розпорядження КМ N 1116-р ( 1116-99-р ) від 20.10.99 )

1. Внести зміни в додаток до розпорядження Кабінету Міністрів України від 28 жовтня 1997 р. N 611 ( 611-97-р ) про закріплення регіонів України за керівниками міністерств, інших центральних органів виконавчої влади, виклавши його у редакції згідно з додатком.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 30 квітня 1999 р. N 359 ( 359-99-р ).
