Кабінет Міністрів України; Постанова від 02.03.2010 № 218

Деякі питання утворення казенного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів"

Стан: Втратив чинність

Ідентифікатор: 218-2010-п

Текст документа від 20.03.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 березня 2010 р. N 218 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 268 ( 268-2010-п ) від 17.03.2010 }

Деякі питання утворення казенного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів"

Кабінет Міністрів України постановляє:

1. Утворити Комісію з питань здійснення організаційних заходів щодо ліквідації державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" та утворення казенного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" (далі - Комісія).

2. Установити, що Комісія здійснює провадження щодо управління справами державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" у період його ліквідації.

3. Затвердити головою Комісії Першого віце-прем'єр-міністра України.

4. Голові Комісії затвердити:

персональний склад Комісії та у разі потреби вносити до нього зміни;

план заходів з ліквідації державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів".

5. Комісії:

забезпечити ліквідацію державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" та утворення казенного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" у встановлений строк;

поінформувати до 3 червня 2010 р. Кабінет Міністрів України про проведену роботу.

6. Внести до актів Кабінету Міністрів України зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 2 березня 2010 р. N 218

ЗМІНИ, що вносяться до актів Кабінету Міністрів України

1. У розпорядженні Кабінету Міністрів України від 17 лютого 2010 р. N 249 ( 249-2010-р ) "Про заходи щодо удосконалення державного регулювання та посилення контролю у сфері виготовлення бланків цінних паперів і документів суворої звітності":

у пункті 1 слова "реорганізувати державне підприємство "Поліграфічний комбінат "Україна" по виготовленню цінних паперів", що належить до сфери управління Міністерства фінансів, шляхом його перетворення у" замінити словами "утворити на базі майна державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів", що ліквідується,";

в абзаці третьому пункту 3 слова "до перетворення" замінити словами "до ліквідації".

2. У пункті 1 Статуту казенного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів", затвердженого постановою Кабінету Міністрів України від 24 лютого 2010 р. N 187 ( 187-2010-п ):

слова "шляхом перетворення державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів" виключити;

доповнити пункт абзацом такого змісту:

"Підприємство є правонаступником державного підприємства "Поліграфічний комбінат "Україна" по виготовленню цінних паперів.".
