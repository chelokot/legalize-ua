{ Указ втратив чинність на підставі Указу Президента N 48/2021 ( 48/2021 ) від 05.02.2021 }

Про внесення доповнення до складу Редакційної колегії з видання збірників актів законодавства України

Увести СІРЕНКА Василя Федоровича - Голову Комітету Верховної Ради України з питань правової реформи до складу Редакційної колегії з видання збірників актів законодавства України, затвердженого Указом Президента України від 31 липня 1998 року N 826 ( 826/98 ) (за згодою).

Президент України Л.КУЧМА
