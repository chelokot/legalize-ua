Про генерального конструктора із створення двигунів для бронетанкової техніки

Стан: Чинний

Текст документа від 15.02.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 лютого 2006 р. N 91-р Київ

Про генерального конструктора із створення двигунів для бронетанкової техніки

1. Надати Альохіну Сергію Олексійовичу повноваження генерального конструктора із створення двигунів для бронетанкової техніки.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 13 грудня 2001 р. N 581 ( 581-2001-р ) "Про генерального конструктора із створення двигунів для бронетанкової техніки".

Прем'єр-міністр України Ю.ЄХАНУРОВ
