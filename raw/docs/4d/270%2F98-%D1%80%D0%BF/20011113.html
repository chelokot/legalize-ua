РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про стратегію розвитку експорту електричної енергії

З метою створення умов для використання експортного потенціалу електроенергетики України та його розвитку:

1. Кабінету Міністрів України затвердити у двомісячний строк стратегію розвитку експорту електричної енергії та на її основі розробити програму реалізації експортного потенціалу електроенергетики.

2. Утворити постійно діючу Міжвідомчу робочу групу з координації заходів, спрямованих на реалізацію та розширення експортного потенціалу електроенергетики України (далі - Міжвідомча робоча група).

3. Призначити ШЕБЕРСТОВА Олексія Миколайовича - Міністра енергетики України керівником Міжвідомчої робочої групи.

4. Затвердити персональний склад Міжвідомчої робочої групи (додається).

Дозволити керівникові Міжвідомчої робочої групи в разі потреби вносити зміни до її персонального складу.

5. Визнати таким, що втратило чинність, Розпорядження Президента України від 30 квітня 1997 року N 188 ( 188/97-рп ) "Про Міжвідомчу робочу групу з розробки пропозицій щодо стимулювання експорту електричної енергії з України".
