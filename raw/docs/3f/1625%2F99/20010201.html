Президент України; Указ від 29.12.1999 № 1625/99

Питання Адміністрації Президента України

Стан: Втратив чинність

Ідентифікатор: 1625/99

Текст документа від 01.02.2001:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Адміністрації Президента України

{ Із змінами, внесеними згідно з Указами Президента N 278/2000 ( 278/2000 ) від 23.02.2000 N 397/2000 ( 397/2000 ) від 09.03.2000 N 1370/2000 ( 1370/2000 ) від 25.12.2000 N 67/2001 ( 67/2001 ) від 01.02.2001 }

З метою більш повного забезпечення здійснення Президентом України своїх конституційних повноважень та підвищення ефективності діяльності Адміністрації Президента України постановляю:

1. Здійснити реорганізацію Адміністрації Президента Україні, встановивши, що до її складу входять:

Глава Адміністрації Президента України,

Перший заступник та заступники Глави Адміністрації Президента України, Прес-секретар Президента України,

Постійний представник Президента України у Верховній Раді України,

Постійний представник Президента України в Конституційному Суді України,

Постійний представник Президента України в Кабінеті Міністрів України,

Служба Президента України,

Секретаріат Адміністрації Президента України,

Секретаріат Національної Ради з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування,

Головне управління організаційно-кадрової роботи та взаємодії регіонами,

Головне контрольне управління,

Головне управління з питань внутрішньої політики,

Головне управління з питань економічної політики,

Головне управління з питань зовнішньої політики,

Головне державно-правове управління,

Управління з питань забезпечення зв'язків з Верховною Радою України, Конституційним Судом України та Кабінетом Міністрів України,

Управління по роботі правоохоронних органів,

Управління документального забезпечення,

Управління інформації та зв'язків з громадськістю, { Абзац 19 статті 1 в редакції Указу Президента N 67/2001 ( 67/2001 ) від 01.02.2001 }

Управління Протоколу Президента України,

Управління державних нагород та геральдики, { Абзац статті 1 в редакції Указу Президента N 397/2000 ( 397/2000 ) від 09.03.2000 }

Управління з питань громадянства,

Управління з питань помилування,

Управління з питань звернень громадян.

{ Стаття 1 із змінами, внесеними згідно з Указом Президента N 278/2000 ( 278/2000 ) від 23.02.2000, N 1370/2000 ( 1370/2000 ) від 25.12.2000 }

2. Розподіл обов'язків між Главою Адміністрації Президента України, Першим заступником і заступниками Глави Адміністрації Президента України, закріплення за ними структурних підрозділів Адміністрації Президента України визначаються згідно з додатком (додано до оригіналу).

3. Главі Адміністрації Президента України у місячний строк:

подати пропозиції щодо граничної чисельності працівників та штатного розпису Адміністрації Президента України, передбачивши скорочення штатної чисельності працівників до 30 відсотків;

забезпечити в установленому порядку вирішення питань, пов'язаних з реорганізацією Адміністрації Президента України та звільненням працівників, посади яких скорочуються;

подати пропозиції щодо внесення змін до Положення про Адміністрацію Президента України, які випливають з цього Указу.

4. Визнати таким, що втратив чинність, Указ Президента України від 4 січня 1999 року N 2 ( 2/99 ) "Питання Адміністрації Президента України".

Президент України Л.КУЧМА
