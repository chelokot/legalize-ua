Зареєстровано в Міністерстві юстиції України 25 листопада 2003 р. за N 1075/8396

Про Порядок формування статутного капіталу страховика цінними паперами

{ Із змінами, внесеними згідно з Розпорядженнями Державної комісії з регулювання ринків фінансових послуг

N 606 ( z0835-09 ) від 06.08.2009

N 413 ( z0923-11 ) від 30.06.2011 }

{ У заголовку та тексті Розпорядження слова "статутного фонду" замінено словами "статутного капіталу" згідно з Розпорядженням Державної комісії з регулювання ринків фінансових послуг N 413 ( z0923-11 ) від 30.06.2011 }

Відповідно до підпункту 5 статті 27 Закону України "Про фінансові послуги та державне регулювання ринків фінансових послуг" ( 2664-14 ), підпункту 22 пункту 4 Положення про Державну комісію з регулювання ринків фінансових послуг України, затвердженого Указом Президента України від 04.04.2003 N 292/2003 ( 292/2003 ), Закону України "Про страхування" ( 85/96-ВР ) Державна комісія з регулювання ринків фінансових послуг України (далі - Комісія) ПОСТАНОВИЛА:

{ Преамбула із змінами, внесеними згідно з Розпорядженням Державної комісії з регулювання ринків фінансових послуг N 606 ( z0835-09 ) від 06.08.2009 }

1. При створенні страховика або збільшенні зареєстрованого статутного капіталу дозволяється формування статутного капіталу страховика державними облігаціями України за їх номінальною вартістю, але не більше 25 відсотків загального розміру статутного капіталу.

{ Пункт 1 в редакції Розпорядження Державної комісії з регулювання ринків фінансових послуг N 606 ( z0835-09 ) від 06.08.2009 }

{ Пункт 2 виключено на підставі Розпорядження Державної комісії з регулювання ринків фінансових послуг N 606 ( z0835-09 ) від 06.08.2009 }

2. Сума, отримана страховиком при погашенні облігацій, повинна бути розміщена в порядку, встановленому законодавством щодо формування статутного капіталу фінансових установ.

3. Департаменту державного регулювання та розвитку ринків фінансових послуг (Хоружий С.Г.) забезпечити подання цього розпорядження до Міністерства юстиції України для державної реєстрації.

4. Відділу взаємодії із засобами масової інформації та зв'язків з громадськістю (Нагорняк М.В.) забезпечити опублікування цього розпорядження у засобах масової інформації після державної реєстрації.

Голова Комісії В.Суслов
