Про заходи щодо забезпечення виконання деяких положень Закону України "Про Державний реєстр виборців"

Стан: Чинний

Ідентифікатор: 895-2009-р

Текст документа від 01.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 липня 2009 р. N 895-р Київ

Про заходи щодо забезпечення виконання деяких положень Закону України "Про Державний реєстр виборців"

{ Із змінами, внесеними згідно з Постановами КМ N 559 ( 559-2010-п ) від 07.07.2010 N 1109 ( 1109-2011-п ) від 20.10.2011 }

1. МВС, МОЗ, Мінпраці, Мін'юсту, Державній пенітенціарній службі вирішити питання щодо кадрового забезпечення своїх територіальних органів для ефективної взаємодії з відділами ведення Державного реєстру виборців під час здійснення заходів, передбачених Законом України "Про Державний реєстр виборців" ( 698-16 ).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1109 ( 1109-2011-п ) від 20.10.2011 }

2. МВС, МОЗ, Мінпраці, Державній пенітенціарній службі забезпечити ведення підпорядкованими органами, закладами, установами електронних баз даних з метою забезпечення надання відомостей про виборців відповідно до Закону України "Про Державний реєстр виборців" ( 698-16 ) та рішень Центральної виборчої комісії.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1109 ( 1109-2011-п ) від 20.10.2011 }

3. МВС вжити заходів для забезпечення ведення системи реєстраційного обліку фізичних осіб відповідно до Закону України "Про свободу пересування та вільний вибір місця проживання в Україні" ( 1382-15 ) в електронному вигляді.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 559 ( 559-2010-п ) від 07.07.2010 }

4. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським держадміністраціям вжити заходів для неухильного виконання постанови Кабінету Міністрів України від 18 липня 2007 р. N 943 ( 943-2007-п ) "Деякі питання утворення органів (відділів) ведення та регіональних органів (відділів) адміністрування Державного реєстру виборців" (Офіційний вісник України, 2007 р., N 53, ст. 2166).

5. Рекомендувати міським міст обласного (республіканського в Автономній Республіці Крим) значення без районного поділу та районним у містах обласного (республіканського в Автономній Республіці Крим) значення з районним поділом радам вжити заходів для кадрового забезпечення відділів ведення Державного реєстру виборців відповідно до встановлених вимог стосовно їх чисельності.

6. Мінтрансзв'язку, ВАТ "Укртелеком" вжити заходів для забезпечення належного функціонування мережі передачі даних автоматизованої інформаційно-телекомунікаційної системи "Державний реєстр виборців", а також забезпечити високоякісний, стабільний, високошвидкісний цифровий зв'язок у зазначеній системі.

7. МОЗ, Мінпраці, Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським держадміністраціям забезпечити подання до органів ведення Державного реєстру виборців відомостей про виборців відповідно до Закону України "Про Державний реєстр виборців" ( 698-16 ) і рішень Центральної виборчої комісії та вжити заходів для кадрового забезпечення органів опіки і піклування, спеціалізованих закладів, які ведуть облік бездомних громадян, кваліфікованими працівниками, а також забезпечити ведення баз даних для подання органам ведення Державного реєстру виборців відомостей про виборців.

Прем'єр-міністр України Ю.ТИМОШЕНКО
