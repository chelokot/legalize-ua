ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 9 вересня 2009 р. N 956

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. В абзаці другому пункту 1 та абзаці першому пункту 2 постанови Кабінету Міністрів України від 21 липня 1995 р. N 541 ( 541-95-п ) "Про державний історико-культурний заповідник у м. Кам'янці Черкаської області" (ЗП України, 1995 р., N 10, ст. 250) слова "Міністерство охорони навколишнього природного середовища та ядерної безпеки" в усіх відмінках замінити словами "Міністерство охорони навколишнього природного середовища" у відповідному відмінку.

2. У постанові Кабінету Міністрів України від 29 лютого 1996 р. N 269 ( 269-96-п ) "Про затвердження Правил охорони внутрішніх морських вод і територіального моря від забруднення та засмічення" (ЗП України, 1996 р., N 8, ст. 241; Офіційний вісник України, 2002 р., N 14, ст. 741):

1) у пункті 2 постанови ( 269-96-п ) слова "Міністерству охорони навколишнього природного середовища та ядерної безпеки" замінити словами "Міністерству охорони навколишнього природного середовища";

2) у тексті Правил, затверджених зазначеною постановою ( 269-96-п ), слово "Мінекоресурсів" замінити словом "Мінприроди".

3. В абзаці третьому пункту 1 та пункті 6 постанови Кабінету Міністрів України від 23 квітня 1996 р. N 450 ( 450-96-п ) "Про заходи щодо запобігання забрудненню водосховищ дніпровського каскаду у зв'язку з масовою загибеллю риби у Кременчуцькому водосховищі" слова "Міністерство охорони навколишнього природного середовища та ядерної безпеки" в усіх відмінках замінити словами "Міністерство охорони навколишнього природного середовища" у відповідному відмінку.

4. У пункті 3 постанови Кабінету Міністрів України від 17 вересня 1996 р. N 1139 ( 1139-96-п ) "Про деякі питання ввезення імпортних автомобілів" (ЗП України, 1996 р., N 18, ст. 502; Офіційний вісник України, 1997 р., число 37, с. 47) слова "Міністерство охорони навколишнього природного середовища та ядерної безпеки" замінити словами "Міністерство охорони навколишнього природного середовища".

5. В абзаці другому пункту 1 та абзаці першому пункту 2 постанови Кабінету Міністрів України від 5 серпня 1997 р. N 844 ( 844-97-п ) "Про Державний історико-культурний заповідник "Самчики" (Хмельницька область)" (Офіційний вісник України, 1997 р., число 32, с. 27) слова "Міністерство охорони навколишнього природного середовища та ядерної безпеки" в усіх відмінках замінити словами "Міністерство охорони навколишнього природного середовища" у відповідному відмінку.

6. У постанові Кабінету Міністрів України від 11 листопада 1999 р. N 2071 ( 2071-99-п ) "Про утворення Національної координаційної ради з питань транспорту, здоров'я та довкілля" (Офіційний вісник України, 1999 р., N 45, ст. 2242):

1) в абзаці другому пункту 1 постанови ( 2071-99-п ) слова "Міністр охорони навколишнього природного середовища та ядерної безпеки" замінити словами "Міністр охорони навколишнього природного середовища", а слова "Міністерства охорони навколишнього природного середовища та ядерної безпеки" - словами "Міністерства охорони навколишнього природного середовища";

2) у пункті 8 Положення про Національну координаційну раду з питань транспорту, здоров'я та довкілля, затвердженого зазначеною постановою ( 2071-99-п ), слово "Мінекобезпеки" замінити словом "Мінприроди".

7. У постанові Кабінету Міністрів України від 14 липня 2000 р. N 1127 ( 1127-2000-п ) "Про службу державної охорони природно-заповідного фонду України" (Офіційний вісник України, 2000 р., N 29, ст. 1221):

1) в абзаці першому пункту 2 постанови ( 1127-2000-п ) слова "Міністерства екології та природних ресурсів" замінити словами "Міністерства охорони навколишнього природного середовища";

2) у тексті Положення про службу державної охорони природно-заповідного фонду України, затвердженого зазначеною постановою ( 1127-2000-п ), слово "Мінекоресурсів" замінити словом "Мінприроди".

8. В абзаці другому пункту 10 та останньому абзаці пункту 23 Положення про пункти пропуску через державний кордон, затвердженого постановою Кабінету Міністрів України від 3 серпня 2000 р. N 1203 ( 1203-2000-п ) (Офіційний вісник України, 2000 р., N 32, ст. 1350; 2001 р., N 47, ст. 2065; 2007 р., N 6, ст. 229), слово "Мінекоресурсів" замінити словом "Мінприроди".

9. У постанові Кабінету Міністрів України від 21 серпня 2000 р. N 1291 ( 1291-2000-п ) "Про затвердження Концепції зменшення обсягів викидів важких металів в атмосферне повітря" (Офіційний вісник України, 2000 р., N 34, ст. 1444):

1) в абзаці другому постановляючої частини постанови ( 1291-2000-п ) слова "Міністерству екології та природних ресурсів" замінити словами "Міністерству охорони навколишнього природного середовища";

2) у пункті "б" розділу 3 Концепції, затвердженої зазначеною постановою ( 1291-2000-п ), слово "Мінекоресурсів" замінити словом "Мінприроди".

10. У постанові Кабінету Міністрів України від 31 січня 2001 р. N 87 ( 87-2001-п ) "Про порядок використання земель у зонах їх можливого затоплення внаслідок повеней і паводків" (Офіційний вісник України, 2001 р., N 5, ст. 188; 2004 р., N 25, ст. 1650):

1) у пункті 2 постанови ( 87-2001-п ) слова "Міністерством екології та природних ресурсів" замінити словами "Міністерством охорони навколишнього природного середовища";

2) у пункті 4 Порядку використання земель у зонах їх можливого затоплення внаслідок повеней та паводків, затвердженого зазначеною постановою ( 87-2001-п ), слово "Мінекоресурсів" замінити словом "Мінприроди".

11. У постанові Кабінету Міністрів України від 17 листопада 2001 р. N 1551 ( 1551-2001-п ) "Про утворення Міжвідомчої комісії з питань моніторингу довкілля" (Офіційний вісник України, 2001 р., N 47, ст. 2095; 2003 р., N 21, ст. 937, N 30, ст. 1546; 2006 р., N 7, ст. 360, N 40, ст. 2683):

1) у пункті 3 постанови ( 1551-2001-п ) слова "Міністерству екології та природних ресурсів" замінити словами "Міністерству охорони навколишнього природного середовища";

2) у пункті 8 Положення про Міжвідомчу комісію з питань моніторингу довкілля, затвердженого зазначеною постановою ( 1551-2001-п ), слово "Мінекоресурсів" замінити словом "Мінприроди".

12. У постанові Кабінету Міністрів України від 28 грудня 2001 р. N 1781 ( 1781-2001-п ) "Про затвердження Положення про регіональні кадастри природних ресурсів" (Офіційний вісник України, 2002 р., N 1, ст. 10):

1) абзац перший пункту 2 постанови ( 1781-2001-п ) викласти в такій редакції:

"2. Міністерству охорони навколишнього природного середовища:";

2) в абзаці другому пункту 2 та другому реченні пункту 4 Положення, затвердженого зазначеною постановою ( 1781-2001-п ), слово "Мінекоресурсів" замінити словом "Мінприроди".

13. У Порядку і правилах проведення обов'язкового страхування відповідальності експортера та особи, яка відповідає за утилізацію (видалення) небезпечних відходів, щодо відшкодування шкоди, яку може бути заподіяно здоров'ю людини, власності та навколишньому природному середовищу під час транскордонного перевезення та утилізації (видалення) небезпечних відходів, затверджених постановою Кабінету Міністрів України від 19 серпня 2002 р. N 1219 ( 1219-2002-п ) (Офіційний вісник України, 2002 р., N 34, ст. 1614):

1) у пункті 13 слово "Мінекоресурсів" замінити словом "Мінприроди";

2) у підпункті 8 пункту 8 додатка до зазначеного Порядку і правил слово "Мінекоресурсів" замінити словом "Мінприроди".

14. У тексті Положення про Зелену книгу України, затвердженого постановою Кабінету Міністрів України від 29 серпня 2002 р. N 1286 ( 1286-2002-п ) (Офіційний вісник України, 2002 р., N 36, ст. 1692), слово "Мінекоресурсів" замінити словом "Мінприроди".
