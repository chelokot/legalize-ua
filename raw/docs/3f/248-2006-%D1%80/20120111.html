Кабінет Міністрів України; Розпорядження від 27.04.2006 № 248-р

Про зміну складу осіб, уповноважених представляти інтереси держави у правлінні Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття

Стан: Втратив чинність

Ідентифікатор: 248-2006-р

Текст документа від 11.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 квітня 2006 р. N 248-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 19-р ( 19-2012-р ) від 11.01.2012 }

{ Дію Розпорядження відновлено згідно з Розпорядженням КМ N 347-р ( 347-2007-р ) від 26.05.2007 }

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 59-р ( 59-2007-р ) від 21.02.2007 }

Про зміну складу осіб, уповноважених представляти інтереси держави у правлінні Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття

Внести до складу осіб, уповноважених представляти інтереси держави у правлінні Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття, затвердженого розпорядженням Кабінету Міністрів України від 28 березня 2005 р. N 70 ( 70-2005-р ) (Офіційний вісник України, 2005 р., N 13, ст. 672), такі зміни:

ввести до складу правління Фонду Антоненка Тараса Володимировича - директора департаменту Мінпраці, вивівши з його складу Скрипник Олену Петрівну;

зазначити нову посаду члена правління Фонду Савенка Олександра Леонідовича - заступник директора департаменту-начальник відділу Мінекономіки.

Прем'єр-міністр України Ю.ЄХАНУРОВ
