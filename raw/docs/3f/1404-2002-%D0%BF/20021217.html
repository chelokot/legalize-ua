Про колегію Державної податкової адміністрації

Стан: Втратив чинність

Текст документа від 17.12.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 вересня 2002 р. N 1404 Київ

Про колегію Державної податкової адміністрації

( Із змінами, внесеними згідно з Постановою КМ N 1925 ( 1925-2002-п ) від 17.12.2002 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 1925 ( 1925-2002-п ) від 17.12.2002 )

2. Затвердити членами колегії Державної податкової адміністрації з правом дорадчого голосу Бондаренка Григорія Івановича, Буряка Сергія Васильовича, Кальниченка Ігоря Вікторовича, Самофалова Геннадія Григоровича (за згодою).

3. Визнати такими, що втратили чинність:

пункт 1 постанови Кабінету Міністрів України від 23 листопада 1999 р. N 2127 ( 2127-99-п ) "Про затвердження Шнипка О.С. членом колегії Державної податкової адміністрації України";

пункт 1 постанови Кабінету Міністрів України від 18 червня 2002 р. N 854 ( 854-2002-п ) "Про колегію Державної податкової адміністрації України" (Офіційний вісник України, 2002 р., N 25, ст. 1212).
