Про Порядок організаційно-правової підготовки і виконання дій щодо ведення Державного реєстру виборців

{ Із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 155 ( v0155359-09 ) від 15.10.2009 }

З метою забезпечення дотримання органами ведення Державного реєстру виборців вимог Закону України "Про Державний реєстр виборців" ( 698-16 ) при веденні Державного реєстру виборців, відповідно до статей 3, 5-9, 14, 16-20, 22, 23, частини дев'ятої статті 24, статті 32 зазначеного Закону ( 698-16 ), керуючись статтями 12, 13, пунктом 8 статті 17, пунктом 2 частини другої статті 27 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Затвердити Порядок організаційно-правової підготовки і виконання дій щодо ведення Державного реєстру виборців (додаток 1).

2. Встановити форми:

наказу про внесення запису до бази даних Державного реєстру виборців (додаток 2);

наказу про внесення змін до персональних даних виборця в Державному реєстрі виборців (додаток 3);

наказу про знищення запису Державного реєстру виборців (додаток 4);

Журналу реєстрації наказів керівника органу ведення Державного реєстру виборців (додаток 5);

Журналу реєстрації звернень виборців (осіб) (додаток 6);

Журналу реєстрації подань з відомостями про виборців (осіб), на підставі яких здійснюється періодичне поновлення персональних даних Державного реєстру виборців (додаток 7).

{ Пункт 2 в редакції Постанови Центральної виборчої комісії N 155 ( v0155359-09 ) від 15.10.2009 }

3. Цю постанову надіслати Міністерству закордонних справ України, регіональним органам адміністрування Державного реєстру виборців для доведення до відома відповідних органів ведення Державного реєстру виборців та контролю за її виконанням, а також Державному комітету архівів України.

ПОРЯДОК організаційно-правової підготовки і виконання дій щодо ведення Державного реєстру виборців

{ У тексті Порядку слово "розпорядження" в усіх відмінках і числах замінено словом "наказ" у відповідному відмінку і числі згідно з Постановою Центральної виборчої комісії N 155 ( v0155359-09 ) від 15.10.2009 }

1. ЗАГАЛЬНІ ПОЛОЖЕННЯ

1.1. Цей Порядок відповідно до Закону України "Про Державний реєстр виборців" ( 698-16 ) (далі - Закон) регулює питання здійснення організаційно-правової підготовки і виконання дій щодо ведення Державного реєстру виборців (далі - Реєстр).

1.2. Організаційно-правова підготовка і виконання дій щодо ведення Реєстру здійснюються працівниками органів ведення Державного реєстру виборців (далі - органи ведення) на підставах та у спосіб, встановлених Законом ( 698-16 ), а також рішеннями Центральної виборчої комісії, прийнятими відповідно до Закону ( 698-16 ) з використанням візуального та автоматизованого контролю повноти і коректності персональних даних Реєстру.

{ Пункт 1.2 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 155 ( v0155359-09 ) від 15.10.2009 }

1.3. Організаційно-правова підготовка здійснюється з метою забезпечення дотримання органами ведення вимог Закону ( 698-16 ) при веденні Реєстру, а також внесення до Реєстру документально підтверджених відомостей про виборців та виконання дій щодо ведення Реєстру лише на підставах, встановлених Законом ( 698-16 ).

1.4. Діями щодо ведення Реєстру є виконання працівниками органів ведення, які мають доступ до бази даних Реєстру, в режимі записування засобами програмного забезпечення автоматизованої інформаційно-телекомунікаційної системи "Державний реєстр виборців" (далі - АІТС Реєстру) таких операцій:

1) внесення до бази даних Реєстру нового запису;

2) внесення змін до персональних даних Реєстру;

3) знищення запису бази даних Реєстру.

1.5. Організаційно-правова підготовка до виконання дій щодо ведення Реєстру включає:

- прийняття органом ведення документів (їх копій), які є підставою для видання наказу про виконання дій щодо ведення Реєстру (в тому числі перевірка правильності і повноти їх оформлення, а також їх облік);

- візуальний та автоматизований контроль повноти та коректності отриманих відомостей про виборця;

- перевірку персональних даних виборця шляхом звернення до відповідних органів, закладів, установ, організацій, зазначених у статті 22 Закону ( 698-16 ), та/або безпосередньо до виборця;

- видання наказу про внесення запису про виборця до бази даних Реєстру, внесення змін до персональних даних виборців у Реєстрі, знищення запису та облік таких наказів;

- звернення до розпорядника Державного реєстру виборців (далі - розпорядник Реєстру) щодо доручення органу ведення за попередньою виборчою адресою виборця внести до Реєстру зміни стосовно виборчої адреси виборця.

1.6. Організаційно-правова підготовка до виконання дій щодо ведення Реєстру здійснюється з використанням програмних засобів та функцій відповідних підсистем АІТС Реєстру.

1.7. Дії щодо ведення Реєстру здійснюються виключно на виконання письмового наказу керівника органу ведення.

1.8. Наказ про виконання дій щодо ведення Реєстру (далі - наказ) - це акт розпорядчого характеру, яким встановлюється завдання стосовно виконання дій щодо ведення Реєстру, визначаються зміст цих дій та їх виконавці, а також записи про виборця (виборців), які підлягають внесенню до бази даних Реєстру або знищенню, зміни персональних даних виборця, що підлягають внесенню до бази даних Реєстру.

1.9. Підставою для видання наказу є документи, подані до відповідного органу ведення в порядку:

- звернення особи за власною ініціативою;

- періодичного поновлення персональних даних Реєстру;

- уточнення персональних даних Реєстру;

- перевірки відомостей про виборця, яка здійснюється органом ведення шляхом звернення до відповідних органів, закладів, установ, організацій, зазначених у статті 22 Закону ( 698-16 ), або до виборця; { Пункт 1.9 доповнено абзацом п'ятим згідно з Постановою Центральної виборчої комісії N 155 ( v0155359-09 ) від 15.10.2009 }

До таких документів належать:

- подані до органу ведення в порядку, встановленому статтями 19 та 20 Закону ( 698-16 ), документи, що підтверджують набуття особою права голосу, зміни персональних даних виборця, включеного до бази даних Реєстру;

- подання з відомостями про виборців (осіб), форми яких встановлені постановою Центральної виборчої комісії від 27 грудня 2007 року N 578 ( v0578359-07 );

- відомості, подані згідно з частиною дванадцятою статті 22 Закону ( 698-16 ) сільським, селищним, міським головою;

- рішення відповідного органу про зміни в адміністративно-територіальному устрої, про перейменування адміністративно-територіальної одиниці;

- рішення розпорядника Реєстру щодо доручення органу ведення внести зміни до персональних даних виборця стосовно виборчої адреси, а також усунення кратного включення виборця до Реєстру;

- рішення суду;

- заява політичної партії про виявлені порушення порядку ведення Реєстру;

- матеріали перевірки відомостей про виборця, які підтверджують відповідні зміни, в тому числі матеріали перевірки відомостей про виборця, включеного до Реєстру, неповноту або некоректність яких виявлено в результаті візуального та автоматизованого контролю. { Пункт 1.9 доповнено абзацом чотирнадцятим згідно з Постановою Центральної виборчої комісії N 155 ( v0155359-09 ) від 15.10.2009 }

1.10. Проект наказу формується програмними засобами із використанням функцій підсистем АІТС Реєстру.

1.11. Наказ видається на паперовому носії за встановленими формами (додатки 2-4), підписується керівником органу ведення та засвідчується печаткою цього органу.

Наказ містить облікові записи документів, на підставі яких воно видано, та обов'язкові реквізити (дату видання, номер тощо).

1.12. Орган ведення здійснює автоматизований облік наказів програмними засобами підсистеми АІТС Реєстру обліку рішень розпорядника Реєстру та наказів керівника органу ведення Реєстру з виконання дій щодо ведення Реєстру, а також облік у Журналі реєстрації наказів керівника органу ведення Державного реєстру виборців, який ведеться за встановленою формою (додаток 5).

1.13. Приймання документів, які є підставою для видання наказу про виконання дій щодо ведення Реєстру, видання та облік наказів, а також систематизація і зберігання зазначених документів здійснюються з дотриманням вимог інструкції з діловодства у відповідному органі, в якому утворено орган ведення, та цього Порядку.

1.14. Візуальний та автоматизований контроль повноти та коректності відомостей про виборця, що надійшли до органу ведення, здійснюється у порядку, встановленому постановою Центральної виборчої комісії від 11 березня 2009 року N 14 ( v0014359-09 ).

1.15. Виборча адреса виборця визначається відповідно до статті 8 Закону ( 698-16 ).

1.16. Органам ведення забороняється збирати, вносити до Реєстру та зберігати в базі даних Реєстру відомості (персональні дані виборців), не передбачені Законом ( 698-16 ).

1.17. Строки розгляду звернень виборців (осіб) до органів ведення визначаються відповідно до Закону України "Про звернення громадян" ( 393/96-ВР ).

Звернення, подані до органу ведення під час виборчого процесу чи процесу референдуму, розглядаються цим органом у строки, що дозволяють забезпечити дотримання вимог статей 27, 28 Закону ( 698-16 ).

1.18. Звернення виборців, які надійшли до органу ведення в процесі щорічного уточнення персональних даних Реєстру відповідно до частини п'ятої статті 23 Закону ( 698-16 ), опрацьовуються згідно з розділами 2 та 3 цього Порядку.

1.19. Опрацьовані звернення виборців (осіб) щодо включення до Реєстру та стосовно зміни персональних даних виборців у Реєстрі разом з доданими до них документами (їх копіями), матеріали перевірки, подання з відомостями про виборців (осіб), виконані постанови Центральної виборчої комісії, виконані накази систематизуються та формуються у відповідні справи і зберігаються органом ведення відповідно до цього Порядку та Примірної номенклатури справ ( v0122560-04 ), затвердженої центральним органом виконавчої влади у сфері архівної справи і діловодства.

1.20. Керівник органу ведення здійснює контроль за дотриманням працівниками органу ведення вимог цього Порядку.

2. ОРГАНІЗАЦІЙНО-ПРАВОВА ПІДГОТОВКА ДО ВИКОНАННЯ ДІЙ ЩОДО ВЕДЕННЯ РЕЄСТРУ ПРИ ЗВЕРНЕННІ ОСОБИ ЗА ВЛАСНОЮ ІНІЦІАТИВОЮ ПРО ВКЛЮЧЕННЯ ДО РЕЄСТРУ

2.1. Заява щодо включення до Реєстру особи, яка проживає на території України, подається до органу ведення за формою, встановленою постановою Центральної виборчої комісії від 17 квітня 2008 року N 19 ( v0019359-08 ).

Заява щодо включення до Реєстру особи, яка проживає чи перебуває за межами України, подається до дипломатичного представництва чи консульської установи України за формою ( va059359-08 ), встановленою постановою Центральної виборчої комісії від 28 жовтня 2008 року N 59 ( v0059359-08 ).

2.2. Працівник органу ведення (дипломатичного представництва чи консульської установи України - при зверненні особи, яка проживає або перебуває за межами України) під час приймання вказаної заяви здійснює перевірку зазначених у ній відомостей щодо їх повноти та відповідності даним документа, що посвідчує особу і громадянство.

Для виборця, який проживає на території України, документом, що посвідчує особу і громадянство, є паспорт громадянина України або (якщо особа недавно набула громадянства України) тимчасове посвідчення громадянина України, а для виборця, який проживає чи перебуває за межами України, - паспорт громадянина України для виїзду за кордон, дипломатичний паспорт, службовий паспорт або тимчасове посвідчення громадянина України (якщо особа недавно набула громадянства України).

2.3. Працівник органу ведення (дипломатичного представництва чи консульської установи України), який прийняв заяву, перевіряє, чи є особа, яка звернулася із заявою, виборцем (з'ясовується належність до громадянства України, досягнення вісімнадцятирічного віку).

2.4. Працівник органу ведення (дипломатичного представництва чи консульської установи України) робить на звороті заяви відповідний запис про додані до неї документи або належно засвідчені їх копії, а також, у разі необхідності, проставляє інші відмітки, зазначає дату прийняття заяви та ставить свій підпис.

2.5. Керівник відповідного дипломатичного представництва чи консульської установи України невідкладно передає заяву щодо включення особи до Реєстру до органу ведення в Міністерстві закордонних справ України.

2.6. Заява щодо включення до Реєстру в день її надходження до органу ведення обліковується програмними засобами підсистеми АІТС Реєстру взаємодії з виборцями, а також у Журналі реєстрації звернень виборців (осіб), який ведеться за встановленою формою (додаток 6).

2.7. Якщо із заявою щодо включення до Реєстру звернулася особа, яка є виборцем, працівник органу ведення, який прийняв заяву, перевіряє у порядку здійснення візуального та автоматизованого контролю повноти і коректності персональних даних Реєстру, чи включений цей виборець до Реєстру.

Така перевірка здійснюється по всьому масиву бази даних Реєстру.

2.8. У разі якщо виборець не включений до Реєстру, орган ведення перевіряє зазначені у заяві відомості, які необхідно внести до Реєстру.

У ході перевірки зазначених у заяві виборця відомостей орган ведення звертається до відповідних органів, закладів, установ, організацій із запитом щодо перевірки чи уточнення необхідних даних про виборця.

2.9. За результатами розгляду заяви особи щодо включення до Реєстру та на підставі поданих документів і матеріалів перевірки керівник органу ведення невідкладно приймає одне з двох рішень:

1) про видання наказу щодо внесення запису до бази даних Реєстру;

2) про відмову в задоволенні заяви (на підставах і у спосіб, визначених частинами восьмою - десятою статті 19 Закону) ( 698-16 ).

2.10. Про перевірку відомостей, зазначених у заяві особи, відповідними органами, закладами, установами, організаціями, а також про включення виборця до Реєстру або відмову в задоволенні заяви працівник органу ведення, який прийняв заяву, робить на її звороті відповідні відмітки.

3. ОРГАНІЗАЦІЙНО-ПРАВОВА ПІДГОТОВКА ДО ВИКОНАННЯ ДІЙ ЩОДО ВЕДЕННЯ РЕЄСТРУ ПРИ ЗВЕРНЕННІ ВИБОРЦЯ ЗА ВЛАСНОЮ ІНІЦІАТИВОЮ ЩОДО ЗМІНИ ЙОГО ПЕРСОНАЛЬНИХ ДАНИХ

3.1. Заява про внесення змін до персональних даних виборця у Реєстрі подається виборцем до органу ведення за своєю виборчою адресою (у разі проживання або перебування виборця за межами України - до дипломатичного представництва чи консульської установи України).

Заява про зміну виборчої адреси подається виборцем за новою виборчою адресою до органу ведення, повноваження якого поширюються на відповідну територію.

3.2. Від імені виборця, у персональних даних якого в Реєстрі зазначено про його постійну нездатність пересуватися самостійно, може звернутися інша особа, уповноважена на здійснення таких дій в установленому законом порядку (нотаріально чи посадовою особою, уповноваженою здійснювати нотаріальні дії: в населених пунктах, де немає нотаріусів, - посадовою особою відповідної місцевої ради; в стаціонарних лікувальних закладах - головним лікарем; у військових частинах (формуваннях) - командиром військової частини (формування).

3.3. Працівник органу ведення (працівник дипломатичного представництва чи консульської установи України - у разі звернення особи, яка проживає або перебуває за межами України) під час прийняття заяви здійснює перевірку зазначених у ній відомостей щодо їх повноти та відповідності доданим до заяви документам (належно засвідченим копіям документів), які підтверджують такі зміни.

3.4. Працівник органу ведення (дипломатичного представництва чи консульської установи України) робить, у разі необхідності, на звороті заяви відповідні відмітки, зазначає дату прийняття заяви та ставить свій підпис.

Заява про внесення змін до персональних даних виборця у Реєстрі розглядається органом ведення незалежно від надання виборцем довідки про включення виборця до Реєстру.

3.5. Керівник відповідного дипломатичного представництва чи консульської установи України невідкладно передає заяву про внесення змін до персональних даних виборця у Реєстрі та додані до неї документи (належно засвідчені копії документів) до органу ведення в Міністерстві закордонних справ України.

3.6. Заява про внесення змін до персональних даних виборця у Реєстрі в день її надходження до органу ведення обліковується програмними засобами підсистеми АІТС Реєстру взаємодії з виборцями, а також у Журналі реєстрації звернень виборців (осіб), який ведеться за встановленою формою (додаток 6).

3.7. Працівник органу ведення, який прийняв заяву, шляхом здійснення візуального та автоматизованого контролю повноти і коректності персональних даних Реєстру перевіряє (звіряє) персональні дані виборця, зазначені у заяві, з відомостями про виборця, включеними до Реєстру.

У ході такої перевірки орган ведення може провести перевірку зміни персональних даних виборця шляхом звернення до відповідних органів, закладів, установ, організацій, визначених статтею 22 Закону ( 698-16 ).

У разі звернення політичної партії щодо виправлення недостовірних відомостей Реєстру чи виборця стосовно невідповідностей чи неточностей у персональних даних інших осіб, така перевірка здійснюється в обов'язковому порядку.

3.8. За результатами розгляду заяви (крім заяви щодо зміни виборчої адреси), на підставі поданих документів та матеріалів перевірки керівник органу ведення приймає одне з таких рішень:

1) про видання наказу про внесення відповідних змін до персональних даних виборця у Реєстрі;

2) про відмову в задоволенні заяви виборця (на підставах і у спосіб, визначених частинами шостою та сьомою статті 20 Закону) ( 698-16 ).

3.9. У разі звернення виборця із заявою щодо зміни виборчої адреси, (незалежно від того, чи пов'язана така зміна із зміною реєстрації місця проживання відповідно до Закону України "Про свободу пересування та вільний вибір місця проживання в Україні") ( 1382-15 ), працівник органу ведення вивчає обґрунтованість заяви та робить відповідний запис на звороті заяви, а також, у разі необхідності, проставляє інші відмітки щодо поданої заяви.

3.10. За результатами вивчення обґрунтованості заяви виборця щодо зміни виборчої адреси керівник органу ведення приймає одне з таких рішень:

1) про видання наказу про внесення до Реєстру зміни щодо виборчої адреси виборця (якщо зміна виборчої адреси виборця відбувається в межах території, на яку поширюються повноваження цього органу ведення);

2) про звернення до розпорядника Реєстру стосовно доручення органові ведення за попередньою виборчою адресою виборця внести до Реєстру зміни щодо виборчої адреси виборця (якщо попередня виборча адреса виборця не належить до території, на яку поширюються повноваження цього органу ведення);

3) про відмову виборцю у внесенні зміни до його виборчої адреси.

У зверненні керівника органу ведення до розпорядника Реєстру стосовно доручення органові ведення за попередньою виборчою адресою виборця внести до Реєстру зміни щодо виборчої адреси такого виборця обов'язково зазначаються персональні дані виборця: прізвище, власне ім'я (всі власні імена), по батькові, дата народження, місце народження, а також попередня та нова виборчі адреси.

Таке звернення підписується керівником органу ведення та засвідчується печаткою цього органу. { Пункт 3.10 доповнено абзацом шостим згідно з Постановою Центральної виборчої комісії N 155 ( v0155359-09 ) від 15.10.2009 }

3.11. Зміна виборчої адреси виборця за дорученням розпорядника Реєстру здійснюється відповідно до розділу 5 цього Порядку.

3.12. Якщо виборця, який звернувся із заявою щодо зміни його персональних даних у Реєстрі, не включено до Реєстру, працівник органу ведення виконує дії, передбачені пунктами 2.8-2.10 цього Порядку.

Виборець, щодо якого здійснюється відповідна перевірка, обов'язково попереджається органом ведення про її проведення.

4. ОРГАНІЗАЦІЙНО-ПРАВОВА ПІДГОТОВКА ДО ВИКОНАННЯ ДІЙ ЩОДО ВЕДЕННЯ РЕЄСТРУ ПРИ ПЕРІОДИЧНОМУ ПОНОВЛЕННІ ПЕРСОНАЛЬНИХ ДАНИХ РЕЄСТРУ

4.1. Відомості про виборців (осіб), на підставі яких здійснюється періодичне поновлення персональних даних Реєстру, подаються за формами ( va578359-07 ), встановленими постановою Центральної виборчої комісії від 27 грудня 2007 року N 578 ( v0578359-07 ), на паперових носіях та в електронному вигляді.

Відомості про виборців (осіб) в електронному файлі повинні відповідати відомостям, поданим на паперових носіях.

4.2. Працівник органу ведення здійснює конвертацію електронних файлів вхідних документів у "xml-формат" з використанням програмних засобів підсистеми АІТС Реєстру обліку документів періодичного поновлення персональних даних Реєстру.

4.3. Шляхом здійснення візуального та автоматизованого контролю повноти і коректності орган ведення перевіряє подані відомості про виборців (осіб) щодо їх повноти та коректності.

4.4. У разі виявлення недоліків у наданих відомостях про виборців (осіб) керівник органу ведення звертається до відповідних органів, закладів, установ, організацій щодо їх усунення.

4.5. Подання з відомостями про виборців (осіб), на підставі яких здійснюється періодичне поновлення персональних даних Реєстру, в день їх надходження до органу ведення обліковуються програмними засобами підсистеми АІТС Реєстру обліку документів періодичного поновлення персональних даних Реєстру, а також у Журналі реєстрації подань з відомостями про виборців (осіб), на підставі яких здійснюється періодичне поновлення персональних даних Державного реєстру виборців, який ведеться за встановленою формою (додаток 7).

4.6. За результатами опрацювання подань з відомостями про виборців (осіб), які надаються органами, закладами, установами, організаціями, визначеними частинами третьою - дев'ятою статті 22 Закону ( 698-16 ), засобами програмного забезпечення підсистеми АІТС Реєстру періодичного поновлення та уточнення персональних даних Реєстру керівник органу ведення стосовно кожного виборця (особи) приймає передбачене Законом ( 698-16 ) рішення (видає відповідний наказ чи звертається до розпорядника Реєстру). { Пункт 4.6 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 155 ( v0155359-09 ) від 15.10.2009 }

4.6.1. Наказ про внесення запису до бази даних Реєстру видається у зв'язку із:

- досягненням особою 18 років;

- набуттям особою громадянства України;

- поновленням дієздатності особи, не включеної до Реєстру;

- виявленням не включеної до Реєстру особи, яка має право голосу.

4.6.2. Наказ про внесення змін до персональних даних виборця у Реєстрі видається у зв'язку із:

- зміною прізвища, імені, по батькові, дати або місця народження;

- зміною виборчої адреси в межах території, на яку поширюються повноваження органу ведення;

- смертю виборця;

- припиненням або набуттям громадянства України;

- визнанням судом особи недієздатною чи поновленням судом дієздатності особи;

- вибуттям з відповідної території (без внесення змін до виборчої адреси).

4.6.3. Стосовно виборців, попередня виборча адреса яких знаходилася за межами території, на яку поширюються повноваження органу ведення, керівник цього органу звертається до розпорядника Реєстру щодо доручення органу ведення за попередньою виборчою адресою такого виборця внести до Реєстру зміни щодо його виборчої адреси.

Таке звернення оформляється відповідно до пункту 3.10 цього Порядку.

4.7. На підставі відомостей, які згідно з частиною дванадцятою статті 22 Закону ( 698-16 ) подаються сільським, селищним, міським головою або іншою посадовою особою, яка відповідно до закону здійснює його повноваження, про найменування нових та перейменування вулиць (проспектів, бульварів, площ, провулків, кварталів, кутків тощо), присвоєння номерів новим будинкам і зміну нумерації існуючих будинків у відповідному населеному пункті керівник органу ведення видає наказ щодо внесення змін до виборчої адреси кожного виборця, якого стосуються такі відомості.

4.8. На підставі акта про зміни в адміністративно-територіальному устрої чи перейменування адміністративно-територіальної одиниці керівник органу ведення видає наказ про внесення відповідних змін щодо місця народження або виборчої адреси кожного виборця, якого стосуються такі зміни.

5. ЗМІНА ВИБОРЧОЇ АДРЕСИ ВИБОРЦЯ ЗА ДОРУЧЕННЯМ РОЗПОРЯДНИКА РЕЄСТРУ

5.1. Керівник органу ведення за попередньою виборчою адресою виборця на підставі постанови Центральної виборчої комісії, якою доручено цьому органу внести зміни до персональних даних виборця щодо виборчої адреси, видає наказ про внесення змін до персональних даних такого виборця у Реєстрі.

5.2. Виборча адреса, яка була змінена органом ведення за дорученням розпорядника Реєстру, зберігається в попередній редакції як службові персональні дані Реєстру із зазначенням дати внесення змін.

5.3. Наказ про внесення до персональних даних виборця у Реєстрі змін щодо нової виборчої адреси видається не пізніш як у триденний термін з дня надходження до органу ведення відповідної постанови Центральної виборчої комісії.

6. ОРГАНІЗАЦІЙНО-ПРАВОВА ПІДГОТОВКА ЩОДО ЗНИЩЕННЯ ЗАПИСУ РЕЄСТРУ

6.1. Підставами для видання керівником органу ведення наказу про знищення запису Реєстру є:

- закінчення встановленого Законом ( 698-16 ) строку збереження запису про виборця, який помер або громадянство України якого припинено (15 років після настання відповідних обставин);

- рішення Центральної виборчої комісії з дорученням усунути кратне включення виборця до Реєстру.

6.2. Наказ про знищення запису Реєстру видається не пізніш як у триденний термін з дня закінчення 15-річного строку збереження запису про виборця, який помер або громадянство України якого припинено, або надходження до органу ведення відповідної постанови Центральної виборчої комісії з дорученням цьому органу ведення усунути кратне включення виборця до Реєстру.

7. ВИКОНАННЯ ДІЙ ЩОДО ВЕДЕННЯ РЕЄСТРУ

7.1. Персональні дані виборця вносяться до бази даних Реєстру у формі запису - сукупності всіх персональних даних виборця, передбачених статтями 5-9 Закону ( 698-16 ).

7.2. Виконання у режимі записування дій щодо ведення Реєстру здійснюється на підставі та відповідно до наказу керівника органу ведення уповноваженим працівником цього органу, який має у встановленому порядку доступ до бази даних Реєстру, невідкладно (але не пізніш як на наступний робочий день) після видання наказу.

Одночасно з внесенням до бази даних Реєстру записів про виборців, внесенням змін до персональних даних виборців у Реєстрі вносяться відповідні службові відмітки, передбачені статтею 9 Закону ( 698-16 ).

{ Пункт 7.2 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 155 ( v0155359-09 ) від 15.10.2009 }

7.3.
