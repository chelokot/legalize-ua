КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 березня 1994 р. N 158 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про створення у складі військ внутрішньої та конвойної охорони військових частин спеціального призначення

{ Із змінами, внесеними згідно з Постановою КМ N 744 ( 744-2002-п ) від 01.06.2002 }

3 метою реалізації заходів, передбачених пунктом 8 розділу VII Державної програми боротьби із злочинністю, затвердженої постановою Верховної Ради України від 25 червня 1993 р. ( 3325-12 ), і пунктом 6 рішення Координаційного комітету з питань боротьби зі злочинністю від 5 липня 1993 р., та оперативного реагування на дії злочинних угрупувань Кабінет Міністрів України постановляє:

1. Прийняти пропозицію Міністерства внутрішніх справ, погоджену з відповідними міськими Радами народних депутатів, про створення протягом 1994-1995 років у складі військ внутрішньої та конвойної охорони трьох військових частин спеціального призначення з дислокацією у містах Києві, Вінниці та Запоріжжі.

{ Абзац другий пункту 1 втратив чинність на підставі Постанови КМ N 744 ( 744-2002-п ) від 01.06.2002 }

2. Міністерству оборони передати безоплатно в установленому порядку Міністерству внутрішніх справ придатні для використання чотири вертольоти МІ-8 МТ.

3. Міністерству економіки передбачити на 1994-1995 роки цільове виділення ліміту капітальних вкладень на будівництво 108-квартирного житлового будинку у м. Києві і 72-квартирних будинків у містах Вінниці та Запоріжжі для особового складу зазначених військових частин.

4. Міністерству оборони, Київській міській та Вінницькій і Запорізькій обласним державним адміністраціям протягом 1994 року вирішити питання щодо розміщення військових частин спеціального призначення.

5. Рекомендувати виконкомам Вінницької і Запорізької міських Рад народних депутатів передбачати починаючи з 1994 року в проектах планів і програм економічного і соціального розвитку територій і проектах бюджетів виділення житла для військовослужбовців зазначених військових частин.
