АНТИМОНОПОЛЬНИЙ КОМІТЕТ УКРАЇНИ

НАКАЗ

14.04.2004 N 27

Зареєстровано в Міністерстві юстиції України 12 травня 2004 р. за N 594/9193

( Наказ втратив чинність на підставі Наказу Антимонопольного комітету

N 6 ( z0103-06 ) від 26.01.2006 )

Про внесення змін до наказу Антимонопольного комітету України від 28.11.2003 N 121 "Про умови оплати праці працівників Центру комплексних досліджень з питань антимонопольної політики"

На виконання постанови Кабінету Міністрів України від 11 лютого 2004 року N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Внести зміни до наказу Антимонопольного комітету України від 28.11.2003 N 121 ( z1149-03 ) "Про умови оплати праці працівників Центру комплексних досліджень з питань антимонопольної політики", зареєстрованого в Міністерстві юстиції України 12 грудня 2003 року за N 1149/8470, виклавши додаток до наказу в редакції, що додається.

2. Директору Центру комплексних досліджень з питань антимонопольної політики (Самойленко В.О.) установити посадові оклади (ставки заробітної плати) працівникам згідно з додатком.

3. Директору Центру (Самойленко В.О.) подати цей наказ на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням наказу покласти на першого заступника Голови Комітету С.О.Черненка.

Голова Комітету О.Костусєв

Додаток до наказу Антимонопольного комітету України 28.11.2003 N 121 ( z1149-03 ) (у редакції наказу Антимонопольного комітету України 14.04.2004 N 27)
