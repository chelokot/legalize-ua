1. Затвердити Порядок взаємодії митних і податкових органів при організації та проведенні планових і позапланових виїзних перевірок суб'єктів зовнішньоекономічної діяльності (додається).

2. 3. Визначити, що вповноваженими підрозділами Державної митної служби України та Державної податкової адміністрації України, які координують діяльність митних та податкових органів при плануванні, проведенні перевірок та реалізації їх матеріалів, є Центральне бюро аналізу ризиків та аудиту Державної митної служби України (Конєв О.І.), Департамент контрольно-перевірочної роботи (Джигалов С.О.), Департамент оподаткування фізичних осіб (Дубель В.С.) Державної податкової адміністрації України. { Пункт 3 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

4. У разі службової необхідності структурним підрозділам Державної митної служби України та Державної податкової адміністрації України в межах власної компетенції надавати уповноваженим підрозділам, що визначені цим наказом як такі, що координують діяльність митних та податкових органів при плануванні, проведенні одночасних перевірок та реалізації їх матеріалів, необхідну практичну та методичну допомогу. { Пункт 4 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

Державної податкової адміністрації України зареєструвати цей наказ у встановленому порядку в Міністерстві юстиції України.

8. Контроль за виконанням цього наказу покласти на першого заступника Голови Державної митної служби України Іванюка М.М. та заступника Голови Державної податкової адміністрації України Копилова В.А.

ПОРЯДОК взаємодії митних і податкових органів при організації та проведенні планових і позапланових виїзних перевірок суб'єктів зовнішньоекономічної діяльності

{ Назва Порядку із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

1. Загальні положення

1.1. Цей порядок визначає взаємодію митних і податкових органів при організації та проведенні планових і позапланових виїзних перевірок суб'єктів зовнішньоекономічної діяльності (далі - суб'єкти). Порядок розроблено відповідно до вимог Митного кодексу України, Закону України "Про державну податкову службу в Україні" ( 509-12 ), Указу Президента України від 23 липня 1998 року N 817 ( 817/98 ) "Про деякі заходи з дерегулювання підприємницької діяльності", Указу Президента України від 23.06.2004 N 671 ( 671/2004 ) "Про невідкладні заходи щодо підвищення ефективності справляння податку на додану вартість", Порядку координації проведення планових виїзних перевірок органами виконавчої влади, уповноваженими здійснювати контроль за нарахуванням і сплатою податків та зборів (обов'язкових платежів), який затверджено постановою Кабінету Міністрів України від 21 липня 2005 року N 619 ( 619-2005-п ), та інших нормативно-правових актів України. { Пункт 1.1 розділу 1 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

1.2. Зазначений Порядок розроблений з метою взаємодії митних та податкових органів при організації та проведенні планових і позапланових виїзних перевірок суб'єктів зовнішньоекономічної діяльності, забезпечення належного контролю з боку податкових та митних органів за дотриманням вимог чинного законодавства зазначеними суб'єктами шляхом проведення перевірок. { Абзац перший пункту 1.2 розділу 1 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

Запровадження зазначеного Порядку надасть можливість удосконалити контроль за суб'єктами зовнішньоекономічної діяльності, установити єдиний підхід до відбору зазначених суб'єктів для підготовки та проведення виїзних планових та позапланових перевірок їх діяльності. { Абзац другий пункту 1.2 розділу 1 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

2.Форми взаємодії митних та податкових органів:

обмін інформацією, яка становить взаємний інтерес, про обсяги експортно-імпортних операцій, джерела придбання товарів, іншою інформацією щодо діяльності суб'єктів;

створення спільних груп для відпрацювання конкретних фактів, пов'язаних з незаконним обігом товарів, завищенням (заниженням) вартості товарів при їх ввезенні (вивезенні) на митну територію України, безпідставним застосуванням пільг із сплати податків при імпорті та експорті товарів;

проведення одночасних планових та позапланових виїзних перевірок суб'єктів зовнішньоекономічної діяльності, обмін інформативними листами щодо стану взаємодії між податковими і митними органами, а також проблемних питань, що виникають при здійсненні одночасних планових та позапланових виїзних перевірок суб'єктів зовнішньоекономічної діяльності; { Абзац четвертий розділу 2 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

аналіз умов і причин, що сприяють порушенню законодавства, внесення пропозицій щодо їх усунення до відповідних міністерств та інших центральних органів виконавчої влади;

узагальнення підсумків виконання спільних завдань.

3. Планування одночасних планових виїзних перевірок суб'єктів зовнішньоекономічної діяльності

{ Назва розділу 3 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

3.1. Уповноважений підрозділ Державної митної служби України в термін до 3 числа другого місяця кварталу надає Державній податковій адміністрації України пропозиції щодо включення суб'єктів зовнішньоекономічної діяльності до плану-графіка на наступний квартал.

Державною податковою адміністрацією України аналізуються отримані пропозиції та в термін до 10 числа другого місяця кварталу надсилаються до регіональних органів державної податкової служби для розгляду питання щодо включення останніх до плану-графіка на наступний квартал та визначення термінів проведення перевірок суб'єктів зовнішньоекономічної діяльності, які включені до плану-графіка.

Регіональні митниці, митниці до 5 числа останнього місяця поточного кварталу погоджують з відповідними органами державної податкової служби плани-графіки на наступний квартал щодо одночасного проведення планових виїзних перевірок суб'єктів зовнішньоекономічної діяльності.

{ Пункт 3.1 розділу 3 в редакції Наказу Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

3.2. Відбір суб'єктів, які потребують включення до планів-графіків планових виїзних перевірок, здійснюється податковими та митними органами на підставі попереднього аналізу інформації щодо їх зовнішньоекономічної діяльності шляхом застосування критеріїв ризику, наявності певної інформації, яка свідчить про порушення вимог чинного законодавства.

Визначення переліку критеріїв ризику щодо зовнішньоекономічних операцій суб'єктів та їх постійне поновлення і корегування здійснюють уповноважені підрозділи.

3.3. З метою якісного планування одночасних планових виїзних перевірок, забезпечення включення до планів-графіків планових виїзних перевірок суб'єктів, що потребують перевірки, наказами митних та податкових органів визначаються посадові особи, які відповідають за своєчасне погодження зазначених планів-графіків. { Пункт 3.3 розділу 3 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

3.4. Уповноваженими підрозділами в межах звітного періоду можуть надсилатись пропозиції митним та податковим органам щодо включення до планів-графіків планових виїзних перевірок визначених суб'єктів, критеріїв оцінки ризиків, які використовуються при визначенні об'єктів контролю.

{ Пункт 3.5 розділу 3 вилучено на підставі Наказу Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

4. Проведення одночасних планових виїзних перевірок суб'єктів зовнішньоекономічної діяльності

{ Назва розділу 4 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

4.1. Податковим органом одночасно з повідомленням суб'єкта зовнішньоекономічної діяльності не пізніше ніж за десять днів до дня проведення перевірки проводиться інформування митного органу. { Пункт 4.1 розділу 4 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

4.2. У разі отримання від податкового органу повідомлення про початок проведення перевірки суб'єкта, керівник митного органу повинен забезпечити одночасне проведення перевірки посадовими особами митних органів. { Пункт 4.2 розділу 4 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

4.3. При внесенні змін до планів-графіків планових виїзних перевірок податковим органом інформується відповідний митний орган. { Пункт 4.3 розділу 4 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

4.4. У разі неможливості одночасного проведення планових перевірок митними і податковими органами (відсутність умов праці для всіх перевіряючих, неможливість спільної роботи суб'єкта зовнішньоекономічної діяльності (його посадових осіб), діяльність якого підлягає перевірці, одночасно з усіма перевіряючими) вони проводяться за згодою суб'єкта зовнішньоекономічної діяльності в погоджені з ним строки, що не перешкоджають провадженню його господарської діяльності. { Розділ 4 доповнено пунктом 4.4 згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

4.5. За результатами проведених одночасних планових виїзних перевірок службовими особами митного та податкового органів складаються окремі акти (довідки) відповідно до компетенції, які підписуються суб'єктом зовнішньоекономічної діяльності або його посадовими особами (для юридичних осіб), чи в яких ставиться відмітка про складення акта щодо відмови від підпису, і службовими особами контролюючих органів, та один примірник яких вручається суб'єкту зовнішньоекономічної діяльності. За результатами розгляду матеріалів перевірок у встановленому порядку в межах компетенції кожного контролюючого органу приймаються відповідні рішення, які надсилаються (вручаються) суб'єкту зовнішньоекономічної діяльності, та вживаються заходи в порядку, встановленому законодавством. { Пункт 4.5 розділу 4 в редакції Наказу Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

5. Порядок взаємодії при проведенні планових та позапланових виїзних перевірок суб'єктів зовнішньоекономічної діяльності

{ Назва розділу 5 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

5.1. Митні та податкові органи у встановленому законодавством порядку здійснюють у необхідному обсязі обмін наявною інформацією стосовно діяльності суб'єктів зовнішньоекономічної діяльності та в разі потреби вживають заходів щодо організації і проведення позапланових виїзних перевірок зазначених суб'єктів з дотриманням вимог законодавства. { Пункт 5.1 розділу 5 в редакції Наказу Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

5.2. У разі встановлення митними та податковими органами під час здійснення планових та позапланових виїзних перевірок суб'єктів зовнішньоекономічної діяльності порушень законодавства щодо своєчасності, достовірності, повноти нарахування та сплати податків і зборів (обов'язкових платежів), стосовно яких вони не є контролюючими органами, про зазначені порушення вони повідомляють відповідні контролюючі органи, до компетенції яких належить контроль, для вжиття ними заходів відповідно до законодавства. { Пункт 5.2 розділу 5 в редакції Наказу Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

{ Пункт 5.3 розділу 5 вилучено на підставі Наказу Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

6. Прикінцеві положення

6.1. Уповноваженими підрозділами постійно здійснюється взаємообмін інформацією щодо необхідності проведення контрольних заходів певної спрямованості, у тому числі спільних, стосовно визначення конкретних об'єктів контролю, якості матеріалів проведених перевірок, їх результатів та вжиття необхідних заходів.

6.2. Керівництвом уповноважених підрозділів щоквартально проводяться робочі зустрічі, метою яких є визначення подальших напрямів співпраці, унесення в межах компетенції пропозицій керівництву Державної митної служби України та Державної податкової адміністрації України щодо поліпшення службової діяльності податкових та митних органів, проведення перевірок суб'єктів. { Пункт 6.2 розділу 6 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }

6.3. У разі службової необхідності уповноваженими підрозділами за погодженням з керівництвом Державної митної служби України та Державної податкової адміністрації України можуть створюватися спільні робочі групи, метою діяльності яких може бути опрацювання інформації зовнішньоекономічної діяльності суб'єктів, розробка критеріїв ризику і нормативно-правових актів, проведення спільних контрольних заходів тощо.

6.4. Захист даних щодо погоджених планів-графіків планових виїзних перевірок суб'єктів, які є інформацією з обмеженим доступом, здійснюється податковими та митними органами в установленому нормативно-правовими актами порядку. При обміні інформацією сторони впроваджують організаційно-технічні заходи, які забезпечують захист інформації з обмеженим доступом, що передається. інформація може бути використана виключно для цілей, викладених в цьому Порядку, і не може бути передана третім особам. { Пункт 6.4 розділу 6 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 758/1105 ( z1365-06 ) від 11.12.2006 }
