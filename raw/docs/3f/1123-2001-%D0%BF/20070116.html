ПОСТАНОВА від 28 серпня 2001 р. N 1123 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 21 ( 21-2007-п ) від 16.01.2007 }

Про голову Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України

Кабінет Міністрів України постановляє:

1. Установити, що головою Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України, утвореної постановою Кабінету Міністрів України від 2 липня 1998 р. N 1000 ( 1000-98-п ), є за посадою Прем'єр-міністр України.

2. Звільнити від обов'язків голови Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України Єханурова Юрія Івановича.
