Текст документа від 02.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 грудня 2009 р. N 1396 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 375 ( 375-2010-п ) від 19.05.2010 }

Про внесення зміни до пункту 2 Порядку використання коштів, передбачених у державному бюджеті для реструктуризації вугільної та торфодобувної промисловості

Кабінет Міністрів України постановляє:

В абзаці шостому пункту 2 Порядку використання коштів, передбачених у державному бюджеті для реструктуризації вугільної та торфодобувної промисловості, затвердженого постановою Кабінету Міністрів України від 18 серпня 2005 р. N 749 ( 749-2005-п ) (Офіційний вісник України, 2005 р., N 34, ст. 2032; 2007 р., N 20, ст. 801; 2009 р., N 18, ст. 576, N 19, ст. 597), цифри "150" замінити цифрами "182,667".
