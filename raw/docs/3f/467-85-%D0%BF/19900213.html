Про затвердження складу колегії Державного агропромислового комітету УРСР

Стан: Втратив чинність

Текст документа від 13.02.1990:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 30 грудня 1985 р. N 467 Київ

( Постанова втратила чинність на підставі Постанови Ради Міністрів УРСР N 33 ( 33-90-п ) від 13.02.90 )

Про затвердження складу колегії Державного агропромислового комітету УРСР

Рада Міністрів Української РСР постановляє:

Затвердити колегію Державного агропромислового комітету УРСР у такому складі:

тт. КОЛОМІЄЦЬ Ю.П. - Голова Держагропрому УРСР (голова)

СИТНИК В.П. - перший заступник Голови Держагропрому УРСР

ТКАЧЕНКО О.М. - перший заступник Голови Держагропрому УРСР

БОГДАНОВ Г.О. - Заступник Голови Держагропрому УРСР, голова президії Українського відділення ВАСГНІЛ

ДЕНИСЕНКО О.Г. - заступник Голови Держагропрому УРСР - начальник Головного управління по виробництву і переробці продукції рослинництва

ЗАГОРОДНІЙ Г.Д. - заступник Голови Держагропрому УРСР - начальник Головного управління харчової промисловості

КУЯНОВ В.В. - заступник Голови Держагропрому УРСР - начальник Головного управління по матеріально-технічному постачанню

ЛИСЕНКО В.Г. - заступник Голови Держагропрому УРСР - начальник Головного управління по по кадрах і зовнішніх зв'язках

ЛИСИЦИН В.О. - заступник Голови Держагропрому УРСР - начальник Головного управління плодоовочевого господарства і картоплі

СОЛОМАХА В.К. - заступник Голови Держагропрому УРСР - начальник Головного управління по виробництву, заготівлях і переробці продуктів тваринництва

ФІЛОНЕНКО В.Л. - заступник Голови Держагропрому УРСР - начальник Головного управління по механізації і електрифікації

ЧЕРЕП В.І. - заступник Голови Держагропрому УРСР - начальник Головного управління по капітальному будівництву і реконструкції

ГРЕВЦОВ В.Д. - начальник Головного управління планування, економічного і соціального розвитку галузей агропромислового комплексу Держагропрому УРСР

ЗАЄЦЬ О.С. - начальник Республіканського аграрно-промислового об'єднання по виробництву, заготівлях і переробці цукрових буряків

ЗІНЕВИЧ Л.Л. - заступник начальника Головного управління по виробництву і переробці продукції рослинництва Держагропрому УРСР

ЛИТВИНЕНКО М.Г. - начальник Державної інспекції по заготівлях і якості сільськогосподарських продуктів Держагропрому УРСР

ПИЛЬНИКОВ М.О. - голова республіканського кооперативно-державного об'єднання по агропромисловому будівництву

САХНЕНКО В.І. - начальник Республіканського виробничо-наукового об'єднання по агрохімічному обслуговуванню сільського господарства

ТАРАНЕНКО О.Т. - заступник начальника Головного управління по виробництву, заготівлях і переробці продуктів тваринництва Держагропрому УРСР
