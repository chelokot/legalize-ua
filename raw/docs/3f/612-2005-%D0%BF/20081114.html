{ Постанова втратила чинність на підставі Постанови КМ N 954 ( 954-2008-п ) від 22.10.2008 }

Про доповнення додатка 1 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314

Кабінет Міністрів України постановляє:

Додаток 1 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314 ( 314-2001-п ) "Про встановлення ліміту легкових автомобілів, що обслуговують державні органи" (Офіційний вісник України, 2001 р., N 14, ст. 602) після позиції

"Державний комітет фінансового моніторингу 6"

доповнити позицією такого змісту:

"Національна комісія з питань регулювання зв'язку 4".
