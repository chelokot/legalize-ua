Про внесення змін до переліку будівельних робіт, на виконання яких не вимагається дозвіл

Стан: Втратив чинність

Ідентифікатор: 665-2010-п

Текст документа від 13.05.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 липня 2010 р. N 665 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 466 ( 466-2011-п ) від 13.04.2011 }

Про внесення змін до переліку будівельних робіт, на виконання яких не вимагається дозвіл

Кабінет Міністрів України постановляє:

Внести до переліку будівельних робіт, на виконання яких не вимагається дозвіл, затвердженого постановою Кабінету Міністрів України від 30 вересня 2009 р. N 1104 ( 1104-2009-п ) (Офіційний вісник України, 2009 р., N 80, ст. 2719; 2010 р., N 12, ст. 583), такі зміни:

назву розділу "Об'єкти житлово-громадського призначення" після слова "призначення" доповнити словами ", об'єкти установ для попереднього ув'язнення та виконання покарань";

пункт 5 викласти у такій редакції:

"5. Перепланування квартир у багатоквартирних житлових будинках, кімнат у гуртожитках, об'єктів громадського призначення, а також будівель установ для попереднього ув'язнення та виконання покарань із збереженням несучої конструкції, без перевищення допустимих навантажень на перекриття, стіни та фундамент за умови дотримання існуючих архітектурно-планувальних вимог, державних будівельних норм, місцевих правил забудови.".

Прем'єр-міністр України М.АЗАРОВ
