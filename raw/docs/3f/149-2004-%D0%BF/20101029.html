Кабінет Міністрів України; Постанова від 11.02.2004 № 149

Деякі питання пенсійного забезпечення працівників дипломатичної служби

Стан: Чинний

Ідентифікатор: 149-2004-п

Текст документа від 29.10.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 лютого 2004 р. N 149 Київ

Деякі питання пенсійного забезпечення працівників дипломатичної служби

{ Із змінами, внесеними згідно з Постановою КМ N 954 ( 954-2010-п ) від 20.10.2010 }

Кабінет Міністрів України постановляє:

Установити, що у разі виходу на пенсію відповідно до Закону України "Про державну службу" ( 3723-12 ) працівників дипломатичної служби, які направлені у довготермінове відрядження, визначення заробітної плати, з якої обчислюється пенсія цим працівникам, здійснюється виходячи з заробітної плати (посадового окладу, надбавок за ранг і вислугу років, доплат, премій та інших надбавок) за відповідними прирівняними посадами працівників центрального апарату Міністерства закордонних справ.

{ Текст Постанови із змінами, внесеними згідно з Постановою КМ N 954 ( 954-2010-п ) від 20.10.2010 }
