Кабінет Міністрів України; Розпорядження від 03.12.1999 № 1332-р

Про здійснення митного оформлення автотранспортних засобів, що надійшли на адресу Головного управління військового та матеріально-технічного забезпечення МВС і головного Управління МВС в Автономній Республіці Крим

Стан: Втратив чинність

Ідентифікатор: 1332-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 грудня 1999 р. N 1332-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

( Із змінами, внесеними згідно з Розпорядженням КМ N 1433-р ( 1433-99-р ) від 21.12.99 )

Дозволити Держмитслужбі здійснити митне оформлення автотранспортних засобів, що надійшли на адресу Головного управління військового та матеріально-технічного забезпечення МВС і Головного управління МВС в Автономній Республіці Крим за контрактами від 23 липня 1999 р. N 3/198-ім, укладеним з фірмою "AUTOTRADING CORPORATION" (США); від 23 липня 1999 р. N 3/199-ім, укладеним з фірмою "DELINVEST ENTERPRISES CORPORATION" (США); від 18 жовтня 1999 р. N 3/256-ім, укладеним з фірмою "STRAND INDUSTRIES LIMITED" (Великобританія); від 18 жовтня 1999 р. N 3/257-ім, укладеним з фірмою "BEEHIVE HOLDINGS LIMITED" (Кіпр); від 4 жовтня 1999 р. N 14/99, укладеним з фірмою "CAMELOT MARKETING ASSOCIATES LIMITED" (Британські Віргінські Острови), від 13 травня 1999 р. N 3/154ім, укладеним з Державним дослідно-експериментальним спеціалізованим підприємством МВС Російської Федерації, та від 20 серпня 1999 р. N 3/217ім, укладеним з ТОВ "Біоте" (Росія), як товарів критичного імпорту.

( Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 1433-р ( 1433-99-р ) від 21.12.99 )
