Верховна Рада України; Закон від 05.07.2005 № 2729-IV

Про зупинення дії Закону України "Про особливості приватизації відкритого акціонерного товариства "Укртелеком"

Стан: Втратив чинність

Ідентифікатор: 2729-15

Текст документа від 01.02.2007:

ЗАКОН УКРАЇНИ

{ Закон втратив чинність на підставі Закону N 580-V ( 580-16 ) від 11.01.2007, ВВР, 2007, N 13, ст.132 }

Про зупинення дії Закону України "Про особливості приватизації відкритого акціонерного товариства "Укртелеком"

( Відомості Верховної Ради України (ВВР), 2005, N 34, ст.433 )

1. Зупинити дію Закону України "Про особливості приватизації відкритого акціонерного товариства "Укртелеком" ( 1869-14 ) (Відомості Верховної Ради України, 2000 р., N 41, ст. 341; 2003 р., N 37, ст. 300; 2004 р., N 12, ст. 155) до прийняття нової Державної програми приватизації.

2. Цей Закон набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 5 липня 2005 року N 2729-IV
