{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 99 ( z0422-06 ) від 03.04.2006 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 03.02.2000 N 28

На виконання постанови Кабінету Міністрів України від 15.01.2005 N 37 ( 37-2005-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 03.02.2000 N 28 ( z0072-00 ) "Про умови оплати праці працівників секретаріату Національної ради соціального партнерства", зареєстрованого в Міністерстві юстиції України 07.02.2000 за N 72/4293 (зі змінами), виклавши додаток у новій редакції (додається).

2. Ці умови застосовуються з 1 січня 2005 року.

В.о. Міністра М.ПАПІЄВ

Заступник Міністра фінансів України О.С.Яременко
