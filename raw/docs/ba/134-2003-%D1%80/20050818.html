Кабінет Міністрів України; Розпорядження від 12.03.2003 № 134-р

Про голову Міжвідомчої групи з розроблення заходів щодо виведення ВАТ "Авіакомпанія "Авіалінії України" з кризового стану

Стан: Втратив чинність

Ідентифікатор: 134-2003-р

Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 березня 2003 р. N 134-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про голову Міжвідомчої групи з розроблення заходів щодо виведення ВАТ "Авіакомпанія "Авіалінії України" з кризового стану

Затвердити головою Міжвідомчої групи з розроблення заходів щодо виведення ВАТ "Авіакомпанія "Авіалінії України" з кризового стану, утвореної розпорядженням Кабінету Міністрів України від 28 грудня 2000 р. N 527 ( 527-2000-р ), Міністра транспорту Кірпу Георгія Миколайовича, увільнивши від цих обов'язків Дубину Олега Вікторовича.

Прем'єр-міністр України В.ЯНУКОВИЧ
