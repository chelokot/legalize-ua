НАЦІОНАЛЬНА КОМІСІЯ З ПИТАНЬ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

N 428 від 01.07.97 Зареєстровано в Міністерстві м.Київ юстиції України 17 липня 1997 р. vd970701 vn428 за N 261/2065

Щодо внесення доповнення до постанови НКРЕ від 15.05.97 р. N 337 "Про тарифи на електроенергію для населення"

З метою виконання Програми діяльності Кабінету Міністрів України, схваленої Постановою Верховної Ради України від 15.10.96 р. N 412 ( 412/96-ВР ), щодо більш повного відшкодування споживачами вартості енергетичних ресурсів, у зв'язку із збитковістю постачання електроенергії для населення та згідно з Положенням про Національну комісію з питань регулювання електроенергетики України, затвердженим Указом Президента України від 14 березня 1995 року N 213 ( 213/95 ), Національна комісія з питань регулювання електроенергетики України (НКРЕ) ПОСТАНОВЛЯЄ:

Доповнити постанову НКРЕ від 15.05.97 N 337 ( z0203-97 ) "Про тарифи на електроенергію для населення" пунктом 4 такого змісту:

"4. Ввести в дію постанову НКРЕ від 15.05.97 р. N 337 "Про тарифи на електроенергію для населення" з 1 серпня 1997 року."

Голова Комісії З.Буцьо
