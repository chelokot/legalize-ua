Текст документа від 24.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 липня 2002 р. N 880 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 350 ( 350-2009-п ) від 15.04.2009 }

Про затвердження нових граничних розмірів плати за проходження суден шлюзами Дніпровського каскаду

{ Із змінами, внесеними згідно з Постановами КМ N 852 ( 852-2003-п ) від 04.06.2003 N 670 ( 670-2004-п ) від 26.05.2004 N 672 ( 672-2006-п ) від 15.05.2006 }

Кабінет Міністрів України постановляє:

1. На часткову зміну пункту 1 постанови Кабінету Міністрів України від 22 лютого 1999 р. N 236 ( 236-99-п ) (Офіційний вісник України, 1999 р., N 8, ст. 288; 2000 р., N 25, ст. 1058) затвердити нові граничні розміри плати за проходження суден шлюзами Дніпровського каскаду, що додаються.

2. Установити, що:

у період навігації 2002 року при проходженні вантажів в каравані усіма шлюзами Дніпровського каскаду плата стягується за кожний рейс за пільговою ставкою, встановленою для суден у закордонному плаванні (без оплати модуля буксира); { Дію абзацу другого пункту 2 продовжено до 31 грудня 2003 року згідно з Постановою КМ N 852 ( 852-2003-п ) від 04.06.2003; строк дії абзацу другого пункту 2 продовжено до 31 грудня 2005 року згідно з Постановою КМ N 670 ( 670-2004-п ) від 26.05.2004; строк дії абзацу другого пункту 2 продовжено до 31 грудня 2006 року згідно з Постановою КМ N 672 ( 672-2006-п ) від 15.05.2006 }

звільняються від плати за проходження шлюзами судна спеціального та технічного флоту, які належать Державному підприємству водних шляхів "Укрводшлях".

3. Ця постанова набирає чинності з дня опублікування.
