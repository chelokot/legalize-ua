Про внесення змін до постанов Кабінету Міністрів України від 20 лютого 1999 р. N 227 і від 22 лютого 2008 р. N 64

Стан: Чинний

Ідентифікатор: 677-2009-п

Текст документа від 10.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 липня 2009 р. N 677 Київ

Про внесення змін до постанов Кабінету Міністрів України від 20 лютого 1999 р. N 227 і від 22 лютого 2008 р. N 64

{ Із змінами, внесеними згідно з Постановою КМ N 567 ( 567-2011-п ) від 01.06.2011 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 20 лютого 1999 р. N 227 ( 227-99-п ) "Про запровадження нового порядку оформлення візових документів для в'їзду в Україну" (Офіційний вісник України, 1999 р., N 8, ст. 285; 2000 р., N 18, ст. 753, N 36, ст. 1534; 2001 р., N 6, ст. 231, N 9, ст. 365, N 33, ст. 1543; 2002 р., N 52, ст. 2388; 2003 р., N 31, ст. 1617; 2004 р., N 32, ст. 2152; 2007 р., N 86, ст. 3163) і від 22 лютого 2008 р. N 64 ( 64-2008-п ) "Питання оформлення дозволу на спрощене перетинання іноземцями та особами без громадянства державного кордону України" (Офіційний вісник України, 2008 р., N 15, ст. 371) зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 1 липня 2009 р. N 677

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 20 лютого 1999 р. N 227 ( 227-99-п ) і від 22 лютого 2008 р. N 64 ( 64-2008-п )

{ Пункт 1 втратив чинність на підставі Постанови КМ N 567 ( 567-2011-п ) від 01.06.2011 }

2. У постанові Кабінету Міністрів України від 22 лютого 2008 р. N 64 ( 64-2008-п ):

1) у назві та пункті 1 постанови слово "дозволу" замінити словами "документа, що дає право";

2) пункт 2 виключити;

3) у пункті 3 слова і цифру "до затвердження зазначених у пункті 2 цієї постанови Правил та опису оформлення дозволу" замінити словами "порядок оформлення документа, що дає право".
