Рада Міністрів УРСР; Постанова від 13.03.1991 № 54

Про затвердження складу Комісії Президії Ради Міністрів УРСР по вдосконаленню господарського механізму

Стан: Втратив чинність

Ідентифікатор: 54-91-п

Текст документа від 12.01.1996:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 13 березня 1991 р. N 54 Київ

( Постанова втратила чинність на підставі Постанови КМ N 65 ( 65-96-п ) від 12.01.96 )

Про затвердження складу Комісії Президії Ради Міністрів УРСР по вдосконаленню господарського механізму

Рада Міністрів Української РСР постановляє:

1. Затвердити Головою Комісії Президії Ради Міністрів УРСР по вдосконаленню господарського механізму Заступника Голови Ради Міністрів УРСР т. Урчукіна В.Г., а також персональний склад Комісії та наукової секції, що додається.

2. Визнати таким, що втратив чинність, абзац другий пункту 1 постанови Ради Міністрів УРСР від 9 лютого 1989 р. N 51 ( 51-91-п ) "Про Комісію Президії Ради Міністрів УРСР по вдосконаленню господарського механізму" (ЗП УРСР, 1989 р., N 3, ст. 12).
