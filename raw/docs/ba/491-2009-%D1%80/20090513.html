Кабінет Міністрів України; Розпорядження від 07.05.2009 № 491-р

Про виділення коштів для ліквідації наслідків аварії на державному підприємстві "Шахта "Новодзержинська"

Стан: Чинний

Ідентифікатор: 491-2009-р

Текст документа від 13.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 травня 2009 р. N 491-р Київ

Про виділення коштів для ліквідації наслідків аварії на державному підприємстві "Шахта "Новодзержинська"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 522-р ( 522-2009-р ) від 13.05.2009 }

1. Виділити Мінвуглепрому 9722,6 тис. гривень для ліквідації наслідків аварії, що сталася 4 травня 2009 р. на державному підприємстві "Шахта "Новодзержинська", у тому числі для надання допомоги потерпілим на лікування та для забезпечення виплати матеріальної допомоги сім'ям загиблих з розрахунку по 200 тис. гривень на кожного загиблого члена сім'ї. { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 522-р ( 522-2009-р ) від 13.05.2009 }

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 835-17 ).

Мінфіну та Державному казначейству забезпечити перерахування коштів Мінвуглепрому згідно з кошторисом витрат, затвердженим головою Урядової комісії з розслідування причин та ліквідації наслідків аварії на державному підприємстві "Шахта "Новодзержинська".

2. Мінвуглепрому подати до 1 липня 2009 р. Мінекономіки, Мінфіну і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
