Про затвердження переліку підприємств-монополістів, щодо яких запроваджується регулювання фондів оплати праці

{ Із змінами, внесеними згідно з Наказами Мінекономіки N 146/118/95/01 ( z0068-98 ) від 29.12.97 N 4/66/1 ( z0148-99 ) від 12.01.99 N 160/422/16 ( z0096-00 ) від 29.12.99 }

На виконання постанови Кабінету Міністрів України від 5 травня 1997 року 428 ( 428-97-п ) "Про регулювання фондів оплати праці працівників підприємств-монополістів" НАКАЗУЄМО:

{ Пункт 1 втратив чинність на підставі Наказу Мінекономіки N 160/422/16 ( z0096-00 ) від 29.12.99 }

2. Перегляд цього переліку та внесення до нього відповідних змін здійснювати один раз на квартал при потребі.

3. Встановити, що регулювання фондів оплати праці здійснюється лише на підприємствах-монополістах, включених до переліку.
