{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 1/5 ( z0017-05 ) від 10.01.2005 }

Про внесення змін до форм реєстрів для реєстрації нотаріальних дій, нотаріальних свідоцтв, посвідчувальних написів на угодах і засвідчуваних документах

Відповідно до статті 34 Закону України "Про нотаріат" ( 3425-12 ), статті 61 Закону України "Про виконавче провадження" ( 606-14 ) та наказу Міністерства юстиції України від 27 жовтня 1999 року N 68/5 ( z0745-99 ) "Про затвердження Тимчасового положення про порядок проведення прилюдних торгів з реалізації арештованого нерухомого майна", зареєстрованого в Міністерстві юстиції України 2 листопада 1999 року за N 745/4038, НАКАЗУЮ:

1. Доповнити форми реєстрів для реєстрації нотаріальних дій, нотаріальних свідоцтв, посвідчувальних написів на угодах і засвідчуваних документах, затверджені наказом Міністерства юстиції України від 7 лютого 1994 року N 7/5 ( z0038-94 ), зареєстрованим у Міністерстві юстиції України 2 березня 1994 року за N 38/247 (зі змінами і доповненнями), формою 15-2, що додається.

2. Департаменту нотаріату та реєстрації адвокатських об'єднань (Круковес Н.В.) подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 3 жовтня 1992 року N 493/92 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (зі змінами, внесеними Указом Президента України від 21 травня 1998 року N 493/98)( 493/98 ) та довести його до відома начальника Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, начальників обласних, Київського та Севастопольського міських управлінь юстиції.

3. Контроль за виконанням цього наказу покласти на заступника Державного секретаря Л.В.Єфіменка.

Міністр О.В.Лавринович
