Кабінет Міністрів України; Постанова від 07.03.2000 № 450

Про тимчасове використання коштів, передбачених у державному бюджеті, на проведення весняно-польових робіт у 2000 році

Стан: Втратив чинність

Ідентифікатор: 450-2000-п

Текст документа від 09.06.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 березня 2000 р. N 450 Київ

( Постанова втратила чинність на підставі Постанови КМ N 935 ( 935-2000-п ) від 09.06.2000 )

Про тимчасове використання коштів, передбачених у державному

бюджеті, на проведення весняно-польових робіт у 2000 році

( Про поширення дії Постанови додатково див. Постанову КМ N 620 ( 620-2000-п ) від 06.04.2000 )

( Поширити дію Постанови щодо використання коштів державного бюджету на проведення компенсації сільськогосподарським товаровиробникам частини плати за користування кредитами комерційних банків, що надаються для закупівлі пально-мастильних матеріалів, також на закупівлю мінеральних добрив, засобів захисту рослин, насіння та запасних частин для проведення комплексу весняно-польових робіт у 2000 році згідно з Постановою КМ N 620 ( 620-2000-п ) від 06.04.2000 )

З метою створення сприятливих умов для підготовки до весняно-польових робіт сільськогосподарських підприємств, що реформовані згідно з Указом Президента України від 3 грудня 1999 р. N 1529 ( 1529/99 ) "Про невідкладні заходи щодо прискорення реформування аграрного сектора економіки", Кабінет Міністрів України постановляє:

1. Дозволити Міністерству аграрної політики тимчасово використати кошти, передбачені у державному бюджеті на фінансування робіт з докорінного поліпшення земель у сумі 3 млн. гривень, протиепізоотичних заходів - 25 млн. гривень та державної програми селекції у тваринництві та птахівництві - 7 млн. гривень, на проведення компенсації у поточному році сільськогосподарським товаровиробникам частини плати за користування кредитами комерційних банків, залученими виключно для закупівлі пально-мастильних матеріалів, та розподілити їх за регіонами згідно з додатком.

Установити, що:

зазначені кошти використовуються на підставі угод, укладених між сільськогосподарськими товаровиробниками та постачальниками пально-мастильних матеріалів, а також на умовах, передбачених постановою Кабінету Міністрів України від 25 лютого 2000 р. N 398 ( 398-2000-п );

кошти, виділені відповідно до цієї постанови, відновлюються у державному бюджеті за рахунок сум, передбачених для проведення компенсації сільськогосподарським товаровиробникам, згідно з постановою Кабінету Міністрів України від 25 лютого 2000 р. N 398.

2. Міністерству аграрної політики встановити контроль за цільовим використанням виділених коштів і щокварталу інформувати Кабінет Міністрів України.

3. Контроль за виконанням цієї постанови покласти на Віце-прем'єр-міністра України Гладія М.В.

Прем'єр-міністр України В.ЮЩЕНКО

Інд. 22

Додаток до постанови Кабінету Міністрів України від 7 березня 2000 р. N 450
