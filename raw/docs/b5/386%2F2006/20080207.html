Про делегацію України для участі у переговорах між Україною та Республікою Індія щодо підготовки проекту Договору між Україною та Республікою Індія про правову допомогу та правові відносини у цивільних справах

Стан: Втратив чинність

Ідентифікатор: 386/2006

Текст документа від 07.02.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у переговорах між Україною та Республікою Індія щодо підготовки проекту Договору між Україною та Республікою Індія про правову допомогу та правові відносини у цивільних справах

1. Утворити делегацію України для участі у переговорах між Україною та Республікою Індія щодо підготовки проекту Договору між Україною та Республікою Індія про правову допомогу та правові відносини у цивільних справах (м. Київ) у такому складі:

ГОРБУНОВА - заступник Міністра юстиції України,

Лідія Миколаївна глава делегації

ГАЛУЩЕНКО - заступник керівника департаменту -

Герман Валерійович завідувач відділу Головної служби зовнішньої політики Секретаріату Президента України

МАРЧЕНКО - завідувач відділу Головної

Людмила Іванівна державно-правової служби Секретаріату Президента України

СИБІГА - заступник директора Департаменту -

Андрій Іванович начальник відділу Міністерства закордонних справ України

ТЕРЛЕЦЬКИЙ - суддя Верховного Суду України (за

Олександр Олександрович згодою)

ШЕВЧЕНКО - заступник директора Департаменту

Катерина Георгіївна Міністерства юстиції України.

Дозволити главі делегації вносити в разі потреби зміни до складу делегації України, залучаючи до її роботи членів Експертної групи з підготовки проектів міжнародних договорів України про правові відносини та правову допомогу у цивільних і кримінальних справах, утвореної Указом Президента України від 24 квітня 2004 року N 476 ( 476/2004 ).

2. Міністерству юстиції України за погодженням з Міністерством закордонних справ України затвердити вказівки делегації України на переговори.

3. Кабінету Міністрів України вирішити питання фінансування проведення переговорів щодо підготовки проекту Договору між Україною та Республікою Індія про правову допомогу та правові відносини у цивільних справах.

Президент України В.ЮЩЕНКО
