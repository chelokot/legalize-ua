04.03.2008 N 332/5

Зареєстровано в Міністерстві юстиції України 5 березня 2008 р. за N 170/14861

{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 1529/5 ( z0603-17 ) від 11.05.2017 }

Про затвердження Порядку організації Міністерством юстиції України підвищення кваліфікації працівників юридичних служб міністерств, інших центральних органів виконавчої влади

{ Із змінами, внесеними згідно з Наказами Міністерства юстиції N 3291/5 ( z1383-10 ) від 24.12.2010 N 1616/5 ( z0732-11 ) від 16.06.2011 }

Відповідно до постанов Кабінету Міністрів України від 27 серпня 1995 року N 690 ( 690-95-п ) "Про Загальне положення про юридичну службу міністерства, іншого центрального органу виконавчої влади, державного підприємства, установи, організації" (із змінами), від 14 грудня 2001 року N 1693 ( 1693-2001-п ) "Про вдосконалення організації правової роботи в міністерствах, інших центральних органах виконавчої влади", від 13 грудня 2004 року N 1657 ( 1657-2004-п ) "Деякі питання підвищення кваліфікації працівників юридичних служб центральних органів виконавчої влади" та з метою створення умов для системного підвищення професійного рівня працівників юридичних служб міністерств, інших центральних органів виконавчої влади НАКАЗУЮ:

1. Затвердити Порядок організації Міністерством юстиції України підвищення кваліфікації працівників юридичних служб міністерств, інших центральних органів виконавчої влади, що додається.

2. Управлінню координації правової роботи та правової освіти (Богачов С.В.) подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 3 жовтня 1992 року N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами) та організувати його виконання.

3. Структурним підрозділам Мін'юсту протягом 5 днів з дня проведення заходів, передбачених пунктом 2 цього Порядку, надавати інформацію щодо їх проведення Управлінню координації правової роботи та правової освіти.

4. Управлінню координації правової роботи та правової освіти щоквартально узагальнювати інформацію щодо підвищення кваліфікації працівників юридичних служб міністерств, інших центральних органів виконавчої влади.

5. Контроль за виконанням наказу покласти на першого заступника Міністра юстиції України Корнійчука Є.В.

Міністр М.В.Оніщук

ЗАТВЕРДЖЕНО Наказ Міністерства юстиції України 04.03.2008 N 332/5

Зареєстровано в Міністерстві юстиції України 5 березня 2008 р. за N 170/14861

ПОРЯДОК організації Міністерством юстиції України підвищення кваліфікації працівників юридичних служб міністерств, інших центральних органів виконавчої влади

{ У тексті Порядку слова "заступник Міністра" у всіх відмінках замінено словами "заступник Міністра юстиції України - керівник апарату" у відповідних відмінках згідно з Наказом Міністерства юстиції N 1616/5 ( z0732-11 ) від 16.06.2011 }

1. Необхідність кваліфікованого підходу та швидкого реагування на динамічні зміни у законодавстві вимагає формування системи підвищення професійного рівня працівників юридичних служб міністерств, інших центральних органів виконавчої влади (далі-міністерства), яка здатна забезпечити підвищення рівня правової культури працівників юридичних служб міністерств та їх готовність до компетентної участі у правовому забезпеченні діяльності відповідних міністерств.

2. Підвищення кваліфікації працівників юридичних служб міністерств полягає в навчанні з метою оновлення та розвитку умінь і знань, необхідних для ефективного вирішення завдань, поставлених перед юридичною службою.

Основними видами підвищення кваліфікації працівників юридичних служб міністерств є:

тематичні постійно діючі семінари;

тематичні короткотермінові семінари, зокрема тренінги; { Абзац четвертий пункту 2 із змінами, внесеними згідно з Наказом Міністерства юстиції N 3291/5 ( z1383-10 ) від 24.12.2010 }

стажування керівників юридичних служб міністерств та їх заступників у Міністерстві юстиції України. { Абзац п'ятий пункту 2 із змінами, внесеними згідно з Наказом Міністерства юстиції N 3291/5 ( z1383-10 ) від 24.12.2010 }

Тематичні постійно діючі та тематичні короткотермінові семінари, тренінги для працівників юридичних служб міністерств проводяться у Центрі перепідготовки та підвищення кваліфікації працівників юстиції (далі - Центр) на підставі річного плану-графіка підвищення кваліфікації, до якого у разі потреби вносяться зміни наказом Міністерства юстиції України. { Абзац шостий пункту 2 із змінами, внесеними згідно з Наказом Міністерства юстиції N 3291/5 ( z1383-10 ) від 24.12.2010 }

Плани-графіки підвищення кваліфікації працівників юридичних служб міністерств на кожен рік розробляються структурним підрозділом Мін'юсту, який відповідає за методичне керівництво правовою роботою в міністерствах (далі - підрозділ з правової роботи), разом з Центром з урахуванням пропозицій інших структурних підрозділів Мін'юсту та затверджуються наказом.

Після затвердження план-графік доводиться до відома керівників міністерств.

3. Мета, зміст, терміни, види підвищення кваліфікації визначаються у програмах та планах проведення відповідних заходів.

4. Пропозиції на наступний рік щодо підвищення кваліфікації працівників юридичних служб міністерств вносяться відповідними міністерствами щороку до 15 квітня Мін'юсту (із зазначенням орієнтовної кількості працівників, яким необхідно підвищити кваліфікацію) та узагальнюються підрозділом з правової роботи.

Відповідний структурний підрозділ Мін'юсту, який займається питаннями фінансового забезпечення, спільно з Центром та підрозділом з правової роботи формує заявку на включення до проекту державного замовлення на підвищення кваліфікації зазначеної категорії працівників у наступному році і подає до 15 липня Міністерству економічного розвитку і торгівлі України у порядку, установленому постановою Кабінету Міністрів України від 14 липня 1999 року N 1262 ( 1262-99-п ) "Про фінансове забезпечення підготовки і підвищення кваліфікації працівників органів державної влади, органів місцевого самоврядування та органів військового управління Збройних Сил". { Абзац другий пункту 4 із змінами, внесеними згідно з Наказом Міністерства юстиції N 3291/5 ( z1383-10 ) від 24.12.2010 }

Центр спільно з підрозділом з правової роботи після затвердження Міністерством економічного розвитку і торгівлі України забезпечують виконання державного замовлення на підвищення кваліфікації працівників юридичних служб міністерств. { Абзац третій пункту 4 із змінами, внесеними згідно з Наказом Міністерства юстиції N 3291/5 ( z1383-10 ) від 24.12.2010 }

5. Загальна організація підвищення кваліфікації працівників юридичних служб міністерств здійснюється підрозділом з правової роботи, який, зокрема:

разом з Центром розробляє та в установленому порядку подає на затвердження річні плани-графіки підвищення кваліфікації працівників юридичних служб міністерств, до яких у разі потреби вносяться зміни наказом Міністерства юстиції України; { Абзац другий пункту 5 із змінами, внесеними згідно з Наказом Міністерства юстиції N 3291/5 ( z1383-10 ) від 24.12.2010 }

формує пропозиції до програм, планів тематичних постійно діючих та тематичних короткотермінових семінарів;

контролює фактичне проходження стажування;

узагальнює інформацію щодо підвищення кваліфікації працівників юридичних служб міністерств;

вносить пропозиції щодо проведення позапланових заходів. { Пункт 5 доповнено абзацом шостим згідно з Наказом Міністерства юстиції N 3291/5 ( z1383-10 ) від 24.12.2010 }

6. Тематичні постійно діючі семінари проводяться за програмами та планами, що розробляються Центром на підставі пропозицій підрозділу з правової роботи, інших структурних підрозділів Мін'юсту і затверджуються заступником Міністра юстиції України - керівником апарату. { Абзац перший пункту 6 в редакції Наказу Міністерства юстиції N 1616/5 ( z0732-11 ) від 16.06.2011 }

Термін навчання визначається програмою семінару.

7. Тематичні короткотермінові семінари проводяться за ініціативою підрозділу з правової роботи або інших структурних підрозділів Мін'юсту на підставі планів (програм), які затверджуються заступником Міністра юстиції України - керівником апарату.

Термін навчання на тематичних короткотермінових семінарах визначається програмою семінару. { Абзац другий пункту 7 із змінами, внесеними згідно з Наказом Міністерства юстиції N 3291/5 ( z1383-10 ) від 24.12.2010 }

8. Навчальний процес у Центрі здійснюється за такими основними формами: навчальні заняття (лекція, семінарське заняття, практичне заняття, тренінг), самостійна робота, контрольні заходи (підсумковий контроль).

Підсумковий контроль застосовується з метою оцінки результатів навчання та здійснюється шляхом складання диференційованого заліку або написання реферату.

Диференційований залік - це форма підсумкового контролю, що полягає в оцінці засвоєння слухачем навчального матеріалу на підставі результатів виконаних індивідуальних завдань.

Організаційні питання щодо проведення диференційованих заліків визначаються Центром за погодженням з підрозділом з правової роботи та заступником Міністра юстиції України - керівником апарату.

Для прийняття диференційованого заліку Міністерством юстиції створюється відповідна комісія у складі голови комісії, заступника голови комісії - уповноваженої особи Центру, членів комісії та секретаря (уповноваженої особи Центру).

Складання диференційованого заліку проводиться на відкритому засіданні комісії.

Орієнтовний перелік питань для винесення на диференційований залік затверджується головою комісії, інші питання щодо порядку проведення диференційованих заліків вирішуються Центром.

Результати складання диференційованих заліків або захисту рефератів оцінюються за чотирибальною шкалою оцінок ("відмінно", "добре", "задовільно", "незадовільно") і вносяться до залікової відомості, яка підписується всіма присутніми членами комісії.

Особи, які пройшли навчання та успішно здали диференційований залік або захистили реферат, отримують свідоцтво про підвищення кваліфікації за зразком, встановленим постановою Кабінету Міністрів України від 12.11.97 N 1260 ( 1260-97-п ), або відповідний документ про підвищення кваліфікації установленого Міністерством юстиції України зразка.

{ Пункт 8 в редакції Наказу Міністерства юстиції N 3291/5 ( z1383-10 ) від 24.12.2010 }

9. Стажування керівників юридичних служб міністерств та їх заступників проводиться в структурних підрозділах Мін'юсту на підставі звернень міністерств або подання Мін'юсту до відповідного міністерства.

Необхідність проведення стажування визначається керівниками структурних підрозділів Мін'юсту за погодженням із заступником Міністра юстиції України - керівником апарату або за його дорученням та за результатами:

моніторингу нормопроектувальної діяльності міністерств, який кожного місяця проводиться підрозділом з правової роботи на підставі даних структурних підрозділів Мін'юсту, які займаються правовою експертизою проектів нормативно-правових актів;

матеріалів перевірок у міністерствах питань, пов'язаних з діяльністю юридичних служб;

узагальнень інших форм діяльності юридичних служб міністерств, які здійснюють структурні підрозділи Мін'юсту тощо;

розгляду звернень міністерств щодо проведення стажування.

Зарахування на стажування, терміни та порядок його проходження оформлюються наказом Мін'юсту.

Підготовка проекту відповідного наказу та контроль за його виконанням здійснюються підрозділом з правової роботи.

Зміст стажування визначається індивідуальним планом, що затверджується керівником відповідного структурного підрозділу Мін'юсту.

Після закінчення стажування стажист подає заступнику Міністра юстиції України - керівнику апарату звіт про стажування з висновками керівника відповідного структурного підрозділу Мін'юсту.

За результатами стажування кадровою службою Мін'юсту видається довідка для подання особою, яка проходила стажування, за основним місцем роботи.

10. З метою розширення обсягу професійної підготовки спеціалістів юридичних служб міністерств у сфері правозастосування та нормопроектної діяльності можливе запровадження інших форм підвищення їх кваліфікації, не передбачених цим Порядком, за умови їх належного організаційного, навчально-методичного та інформаційного забезпечення.
