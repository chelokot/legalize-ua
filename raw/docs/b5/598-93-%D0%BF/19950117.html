КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 серпня 1993 р. N 598 Київ

Про проведення індексації основних фондів у народному господарстві України

( Із змінами, внесеними згідно з Постановами КМ N 327 ( 327-94-п ) від 20.05.94 N 519 ( 519-94-п ) від 30.07.94 N 682 ( 682-94-п ) від 04.10.94 N 34 ( 34-95-п ) від 17.01.95 )

З метою подолання негативних явищ в економіці та створення сприятливих умов для поліпшення фінансового стану підприємств, установ та організацій всіх форм власності Кабінет Міністрів України постановляє:

1. ( Дію пункту 1 призупинено на підставі Постанови КМ N 682 ( 682-94-п ) від 04.10.94 ) ( Дію пункту 1 відновлено на підставі Постанови КМ N 34 ( 34-95-п ) від 17.01.95 ) Підприємствам, установам та організаціям всіх форм власності здійснювати щорічно станом на 1 січня індексацію балансової вартості основних фондів згідно з порядком, що затверджується Міністерством статистики, Міністерством економіки, Міністерством фінансів та Фондом державного майна.

Проведення індексації в поточному році здійснити до 10 вересня за станом на 1 серпня 1993 року.

( На часткову зміну пункту 1 додатково див. Постанови КМ N 327 ( 327-94-п ) від 20.05.94, N 519 (519-94-п ) від 30.07.94; N 682 ( 682-94-п ) від 04.10.94; N 34 ( 34-95-п ) від 17.01.95 )

2. Міністерствам і відомствам, об'єднанням підприємств, які здійснюють функції з управління майном, що є у загальнодержавній власності, Раді Міністрів Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям подавати методичну допомогу підприємствам, установам та організаціям всіх форм власності у проведенні вказаної роботи.

3. Міністерству статистики для індексації основних фондів та амортизаційних відрахувань здійснювати періодичну розробку індексів цін і забезпечувати ними підприємства, установи та організації.

4. Фонду державного майна до 10 серпня 1993 р. розробити порядок індексації номінальної вартості приватизаційних майнових сертифікатів і визначення розміру їх загальної емісії у зв'язку з індексацією основних фондів.
