КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 вересня 2005 р. N 869 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1294 ( 1294-2007-п ) від 07.11.2007 }

Про внесення зміни до постанови Кабінету Міністрів України від 6 квітня 1998 р. N 452

Кабінет Міністрів України постановляє:

У графі третій підрозділу "Одноразова допомога на початкове обзаведення" розділу "II. Одноразові виплати" додаткових видів грошового забезпечення військовослужбовців, затверджених постановою Кабінету Міністрів України від 6 квітня 1998 р. N 452 ( 452-98-п ) "Про упорядкування додаткових видів грошового забезпечення військовослужбовців" (Офіційний вісник України, 1998 р., N 14, ст. 537; 1999 р., N 42, ст. 2097; 2000 р., N 30, ст. 1278, N 51, ст. 2210; 2001 р., N 9, ст. 360, N 42 ст. 1886; 2002 р., N 12, ст. 597; 2003 р., N 9, ст. 395, N 37, ст. 1981; 2004 р., N 44, ст. 2907), слова "одного року" замінити словами "шести місяців".
