Про присвоєння рангів державним службовцям

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 вересня 2006 р. N 1290 Київ

Про присвоєння рангів державним службовцям

{ Із змінами, внесеними згідно з Постановою КМ N 1442 ( 1442-2006-п ) від 18.10.2006 }

Відповідно до статті 26 Закону України "Про державну службу" ( 3723-12 ) Кабінет Міністрів України постановляє:

Присвоїти третій ранг державного службовця

БАРАШУ - державному уповноваженому

Миколі Яковичу Антимонопольного комітету України

БОРОВИКУ - заступнику начальника Управління

Євгену Герасимовичу контролю Секретаріату Кабінету Міністрів України, завідуючому сектором контролю виконання документів цього Управління

ВАКАРАШУ - першому заступнику голови Київської

Віктору Михайловичу обласної державної адміністрації

КРИВОШЕЇ - начальнику управління документального Галині Василівні забезпечення секретаріату Центральної виборчої комісії

ПЛЕХАНОВУ - начальнику Управління з питань

Миколі Антоновичу діяльності органів юстиції та правоохоронних органів Секретаріату Кабінету Міністрів України

ШАРОВУ - завідувачу відділу інтеграції та

Євгену Павловичу стратегічного партнерства Національного інституту стратегічних досліджень

Присвоїти четвертий ранг державного службовця

ЗАЙЧУКУ - керівнику Служби Віце-прем'єр-міністра Василю Васильовичу України

НЕСТЕРОВИЧ - завідувачу

Ганні Тихонівні адміністративно-господарського відділу Національного інституту стратегічних досліджень

ПРІМИШЕВУ - начальнику головного управління

Ігорю Миколайовичу зовнішніх зв'язків і міжрегіонального співробітництва Ради міністрів Автономної Республіки Крим

ТОПОРОВІЙ - директору департаменту соціального,

Олені Володимирівні трудового та гуманітарного законодавства Міністерства юстиції України

ФІСЮН - заступнику керівника Служби

Людмилі Іванівні Віце-прем'єр-міністра України

Присвоїти п'ятий ранг державного службовця

ДОНЧЕНКУ - заступнику начальника управління

Анатолію Івановичу транспортного забезпечення Державного управління справами

ЖУКОВСЬКОМУ - першому заступнику голови

Анатолію Петровичу Рівненської обласної державної адміністрації

{ Абзац третій розділу скасовано на підставі Постанови КМ N 1442 ( 1442-2006-п ) від 18.10.2006 }

КАРАНДЄЄВУ - директору департаменту фізичної

Ростиславу Володимировичу культури Міністерства України у справах сім'ї, молоді та спорту

КОВАЛЕНКУ - директору департаменту забезпечення

Володимиру Миколайовичу діяльності Державного комітету України з державного матеріального резерву

МИТЧЕНКУ - завідувачу відділу макроекономіки та Олександру Олександровичу аналізу регіонального розвитку департаменту макроекономічної політики Головної служби соціально-економічної політики Секретаріату Президента України

СІРЕНКУ - директору департаменту розвитку та

Володимиру Євгенійовичу функціонування оборонно-промислового комплексу Міністерства промислової політики України
