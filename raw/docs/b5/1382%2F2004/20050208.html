( Указ втратив чинність на підставі Указу Президента N 208/2005 ( 208/2005 ) від 08.02.2005 )

Про внесення зміни до складу Ради національної безпеки і оборони України

Увести до складу Ради національної безпеки і оборони України, затвердженого Указом Президента України від 7 серпня 2001 року N 605 ( 605/2001 ) (зі змінами, внесеними Указами від 27 грудня 2001 року N 1277 ( 1277/2001 ), від 22 травня 2002 року N 481 ( 481/2002 ), від 15 червня 2002 року N 557 ( 557/2002 ), від 20 червня 2002 року N 574 ( 574/2002 ), від 7 вересня 2002 року N 807 ( 807/2002 ), від 24 грудня 2002 року N 1208 ( 1208/2002 ), від 29 вересня 2003 року N 1110 ( 1110/2003 ), від 28 січня 2004 року N 108 ( 108/2004 ), від 3 червня 2004 року N 613 ( 613/2004 ) та від 8 жовтня 2004 року N 1195 ( 1195/2004 ), СИНЯНСЬКОГО Олега Григоровича - Голову Служби зовнішньої розвідки України.
