НАКАЗ

N 66/438/177 від 18.06.2002 Зареєстровано в Міністерстві м.Київ юстиції України 10 липня 2002 р. за N 574/6862

Про внесення змін до Розмірів оплати земельно-кадастрових робіт та послуг

З метою приведення Розмірів оплати земельно-кадастрових робіт та послуг, затверджених спільним наказом Держкомзему, Мінфіну та Мінекономіки від 15.06.2001 N 97/298/124 ( z0579-01 ), зареєстрованих Мін'юстом України 10.07.2001 за N 579/5770, у відповідність до Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ) та постанови Кабінету Міністрів України від 04.07.2001 N 756 ( 756-2001-п ) "Про затвердження переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності" НАКАЗУЄМО:

1. Пункт 6 таблиці 6.1 Розмірів оплати земельно-кадастрових робіт та послуг, затверджених спільним наказом Держкомзему, Мінфіну та Мінекономіки від 15.06.2001 N 97/298/124 ( z0579-01 ), який зареєстровано Міністерством юстиції України 10.07.2001 за N 579/5770, вилучити.

2. Голові Республіканського комітету Автономної Республіки Крим по земельних ресурсах, начальникам обласних, Київського та Севастопольського міських управлінь земельних ресурсів забезпечити виконання цього наказу.

Голова Державного комітету України по земельних ресурсах А.Даниленко

Міністр фінансів України І.Юшко
