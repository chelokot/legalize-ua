Текст документа від 15.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 листопада 2005 р. N 1104 Київ

Питання розподілу смуг радіочастот України

( Із змінами, внесеними згідно з Постановою КМ N 1208 ( 1208-2005-п ) від 15.12.2005 )

З метою удосконалення розподілу смуг радіочастот України Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 1208 ( 1208-2005-п ) від 15.12.2005 )

2. Міністерству оборони і Міністерству транспорту та зв'язку забезпечити у місячний строк виконання заходів щодо вивільнення смуг радіочастот 1935-1950 МГц, 2015-2020 МГц, 2125-2140 МГц для впровадження радіотехнології мобільного радіозв'язку третього покоління.

3. Національній комісії з питань регулювання зв'язку і Міністерству оборони забезпечити проведення натурних випробувань щодо електромагнітної сумісності з радіонавігаційним обладнанням літальних апаратів у смузі радіочастот 2015-2020 МГц.

Прем'єр-міністр України Ю.ЄХАНУРОВ
