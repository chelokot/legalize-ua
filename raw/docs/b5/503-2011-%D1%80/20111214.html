Текст документа від 14.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 червня 2011 р. N 503-р Київ

Про затвердження переліку об'єктів будівництва автомобільних доріг комунальної власності (включаючи проектно-вишукувальні роботи) та обсягів бюджетних коштів для їх фінансування

{ Із змінами, внесеними згідно з Розпорядження КМ N 1277-р ( 1277-2011-р ) від 14.12.2011 }

Відповідно до статті 29 Закону України "Про Державний бюджет України на 2011 рік" ( 2857-17 ) затвердити перелік об'єктів будівництва автомобільних доріг комунальної власності (включаючи проектно-вишукувальні роботи) та обсяги бюджетних коштів для їх фінансування, що додається.
