ПОСТАНОВА від 10 вересня 2008 р. N 806 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1189 ( 1189-2021-п ) від 17.11.2021 }

Про доповнення пункту 29 Статуту Державного концерну "Укрторф"

Кабінет Міністрів України постановляє:

Доповнити пункт 29 Статуту Державного концерну "Укрторф", затвердженого постановою Кабінету Міністрів України від 3 травня 2007 р. N 689 ( 689-2007-п ) "Про утворення Державного концерну "Укрторф" (Офіційний вісник України, 2007 р., N 33, ст. 1335, N 79, ст. 2952), абзацом такого змісту:

"Контракт з генеральним директором Концерну укладає Міністр вугільної промисловості.".

Прем'єр-міністр України Ю.ТИМОШЕНКО
