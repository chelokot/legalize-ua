Про закупівлю імунобіологічних препаратів (вакцин) для здійснення заходів щодо імунопрофілактики дітей

Стан: Втратив чинність

Ідентифікатор: 1855-2010-р

Текст документа від 20.12.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 вересня 2010 р. N 1855-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 2275-р ( 2275-2010-р ) від 20.12.2010 }

Про закупівлю імунобіологічних препаратів (вакцин) для здійснення заходів щодо імунопрофілактики дітей

1. Виділити Міністерству охорони здоров'я 71091,5 тис. гривень з метою закупівлі імунобіологічних препаратів (вакцин) для здійснення заходів щодо імунопрофілактики дітей.

Міністерству фінансів здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 2154-17 ) на умовах повернення.

2. Міністерству охорони здоров'я:

затвердити у тижневий строк за погодженням з Міністерством економіки та Міністерством фінансів перелік витрат, пов'язаних з здійсненням заходів щодо імунопрофілактики дітей;

повернути до кінця 2010 р. до державного бюджету виділені згідно з цим розпорядженням кошти, в тому числі за рахунок залишку невикористаних коштів державного бюджету;

подати до кінця 2010 року Міністерству економіки, Міністерству фінансів і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України М.АЗАРОВ
