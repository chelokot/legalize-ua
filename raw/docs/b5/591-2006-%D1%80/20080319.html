КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 листопада 2006 р. N 591-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

Про утворення Міжвідомчої комісії з питань забезпечення реалізації міжнародних домовленостей щодо врегулювання ситуації у Придністровському регіоні Республіки Молдова

Утворити Міжвідомчу комісію з питань забезпечення реалізації міжнародних домовленостей щодо врегулювання ситуації у Придністровському регіоні Республіки Молдова у складі згідно з додатком.

Надати право голові Міжвідомчої комісії вносити у разі потреби зміни до її складу.
