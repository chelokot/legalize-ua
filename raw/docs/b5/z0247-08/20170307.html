{ Наказ втратив чинність на підставі Наказу Міністерства соціальної політики N 1629 ( z0096-17 ) від 28.12.2016 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 10.05.2006 N 173

Відповідно до постанови Кабінету Міністрів України від 06.02.2008 N 34 ( 34-2008-п ) "Про внесення зміни до деяких постанов Кабінету Міністрів України" та з метою впорядкування умов оплати праці працівників органів Державної служби з карантину рослин, віднесених до категорій посад державних службовців, НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 10.05.2006 N 173 ( z0544-06 ) "Про умови оплати праці працівників органів Державної служби з карантину рослин, віднесених до категорій посад державних службовців", зареєстрованого в Міністерстві юстиції України 11.05.2006 за N 544/12418, виклавши додаток у новій редакції (додається).

2. Ці зміни застосовуються, починаючи з 1 лютого 2008 року.

Міністр Л.Денісова
