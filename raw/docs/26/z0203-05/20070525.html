01.02.2005 N 23

Зареєстровано в Міністерстві юстиції України 10 лютого 2005 р. за N 203/10483

{ Наказ втратив чинність на підставі Наказу Державного комітету України з промислової безпеки, охорони праці та гірничого нагляду N 91 ( z0501-07 ) від 28.04.2007 }

Про внесення змін до наказу Держнаглядохоронпраці України від 02.04.2004 N 93

Відповідно до постанови Кабінету Міністрів України від 15 січня 2005 р. N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Держнаглядохоронпраці України від 02.04.2004 N 93 ( z0506-04 ) "Про умови оплати праці працівників Національного науково-дослідного інституту охорони праці", зареєстрованого в Міністерстві юстиції України 20.04.2004 за N 506/9105 (із змінами, унесеними наказом Держнаглядохоронпраці України від 27.05.2004 N 135 ( z0707-04 ), зареєстрованим у Міністерстві юстиції України 09.06.2004 за N 707/9306, наказом Держнаглядохоронпраці України від 17.09.2004 N 210 ( z1198-04 ), зареєстрованим у Міністерстві юстиції України 22.09.2004 за N 1198/9797), виклавши додатки 1-3 у новій редакції (додаються).

2. Управлінню бухгалтерського обліку і звітності (Кулікова О.Л.) погодити цей наказ з Міністерством праці та соціальної політики України і Міністерством фінансів України та подати на державну реєстрацію до Міністерства юстиції України.

3. Директору Національного науково-дослідного інституту охорони праці (Лисюк М.О.) запровадити ці зміни у встановлений термін у межах фонду заробітної плати, передбаченого кошторисом.

Голова Комітету С.Сторчак
