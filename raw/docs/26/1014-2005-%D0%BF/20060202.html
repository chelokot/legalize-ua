Кабінет Міністрів України; Постанова від 13.10.2005 № 1014

Про порядок використання коштів, передбачених у державному бюджеті для придбання компресорного та електротехнічного обладнання

Стан: Чинний

Ідентифікатор: 1014-2005-п

Текст документа від 02.02.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 жовтня 2005 р. N 1014 Київ

Про порядок використання коштів, передбачених у державному бюджеті для придбання компресорного та електротехнічного обладнання

( Із змінами, внесеними згідно з Постановою КМ N 102 ( 102-2006-п ) від 02.02.2006 )

Кабінет Міністрів України постановляє:

( Вступна частина із змінами, внесеними згідно з Постановою КМ N 102 ( 102-2006-п ) від 02.02.2006 )

Установити, що:

кошти, передбачені за бюджетною програмою "Участь у придбанні високопродуктивного енергозберігаючого компресорного та електротехнічного обладнання для оснащення вугільних шахт", спрямовуються на придбання зазначеного обладнання державним підприємствам вугільної промисловості за критеріями та переліком, що визначаються спеціально уповноваженим центральним органом виконавчої влади у галузі вугільної промисловості, з урахуванням їх потреби у такому обладнанні з метою технічного переоснащення та забезпечення ведення робіт згідно з вимогами правил техніки безпеки. Обладнання придбавається у порядку, встановленому Законом України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ); ( Абзац із змінами, внесеними згідно з Постановою КМ N 102 ( 102-2006-п ) від 02.02.2006 )

перерахування зазначених коштів проводиться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

Прем'єр-міністр України Ю.ЄХАНУРОВ
