{ Указ втратив чинність на підставі Указу Президента N 418/2019 ( 418/2019 ) від 20.06.2019 }

Питання застосування Указу Президента України від 30 червня 1995 року N 497

У зв'язку з неоднозначним тлумаченням Указу Президента України "Про Північнокримську експериментальну економічну зону "Сиваш" щодо дати початку експерименту в Північнокримській експериментальній зоні "Сиваш" постановляю:

При застосуванні статті 1 Указу Президента України від 30 червня 1995 року N 497 ( 497/95 ) "Про Північнокримську експериментальну економічну зону "Сиваш" датою початку експерименту в Північнокримській експериментальній зоні "Сиваш" вважати 18 вересня 1996 року - день державної реєстрації Адміністрації Північнокримської експериментальної економічної зони "Сиваш".

Президент України Л.КУЧМА
