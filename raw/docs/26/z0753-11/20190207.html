ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

22.06.2011 N 204

Зареєстровано в Міністерстві юстиції України 23 червня 2011 р. за N 753/19491

Про внесення змін до деяких нормативно-правових актів Національного банку України

{ Із змінами, внесеними згідно з Постановами Національного банку N 346 ( z1590-12 ) від 17.08.2012 N 31 ( v0031500-19 ) від 05.02.2019 }

Відповідно до вимог статей 44 і 56 Закону України "Про Національний банк України" ( 679-14 ) та статті 11 Декрету Кабінету Міністрів України від 19.02.93 N 15-93 ( 15-93 ) "Про систему валютного регулювання і валютного контролю" Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Пункт 3 постанови Правління Національного банку України від 12.08.2005 N 290 ( z0946-05 ) "Про внесення змін до деяких нормативно-правових актів Національного банку України та встановлення лімітів відкритої валютної позиції банку", зареєстрованої в Міністерстві юстиції України 29.08.2005 за N 946/11226 (зі змінами), виключити.

У зв'язку з цим пункти 4-8 уважати відповідно пунктами 3-7.

2. Унести до Положення про порядок встановлення Національним банком України лімітів відкритої валютної позиції та контроль за їх дотриманням уповноваженими банками, затвердженого постановою Правління Національного банку України від 12.08.2005 N 290 ( z0946-05 ), зареєстрованого в Міністерстві юстиції України 29.08.2005 за N 946/11226 (зі змінами), такі зміни:

2.1. Пункти 6 та 7 викласти в такій редакції:

"6. Національний банк установлює ліміти окремим розпорядчим документом та доводить його зміст до відома банків не пізніше ніж за 10 днів до дати введення їх у дію.

7. Банк зобов'язаний щоденно дотримуватися лімітів".

2.2. Абзац другий пункту 9 викласти в такій редакції:

"Банк здійснює розрахунок величини відкритих валютних позицій в іноземних валютах і банківських металах та розрахунок регулятивного капіталу банку згідно з нормативно-правовими актами Національного банку".

2.3. Пункт 10 виключити.

У зв'язку з цим пункти 11-12 уважати відповідно пунктами 10-11.

{ Пункт 3 втратив чинність на підставі Постанови Національного банку N 346 ( z1590-12 ) від 17.08.2012 }

{ Пункт 4 втратив чинність на підставі Постанови Національного банку N 31 ( v0031500-19 ) від 05.02.2019 }

5. Генеральному департаменту грошово-кредитної політики (Щербакова О.А.), Юридичному департаменту (Новіков В.В.) подати цю постанову на державну реєстрацію до Міністерства юстиції України.

6. Контроль за виконанням цієї постанови покласти на Генеральний департамент банківського нагляду (Ткаченко О.О.), Департамент контролю, методології та ліцензування валютних операцій (Пасенова Н.О.) та начальників територіальних управлінь Національного банку України.

7. Постанова набирає чинності з дня її офіційного опублікування.
