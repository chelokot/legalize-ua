Зареєстровано в Міністерстві юстиції України 23 травня 2005 р. за N 555/10835

Про втрату чинності наказу Міністерства транспорту України від 11.11.2003 N 873

Відповідно до Положення про Державну службу України з нагляду за забезпеченням безпеки авіації, затвердженого Указом Президента України від 16.08.2004 N 912 ( 912/2004 ), та Положення про Міністерство транспорту та зв'язку України, затвердженого Указом Президента України від 27.08.2004 N 1009 ( 1009/2004 ), НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства транспорту України від 11.11.2003 N 873 ( z1104-03 ) "Про затвердження Інструкції про порядок визначення дальності та оцінки якості авіаційного повітряного електрозв'язку", зареєстрований в Міністерстві юстиції України 02.12.2003 за N 1104/8425.

2. Департаменту нормативно-правового забезпечення (М.М. Ониськів) забезпечити подання цього наказу в установленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Рябікіна П.Б.

Міністр Є.А.Червоненко
