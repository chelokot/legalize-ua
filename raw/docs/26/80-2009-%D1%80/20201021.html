КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 січня 2009 р. N 80-р Київ

Про підписання Угоди про створення Спільної комісії з двостороннього співробітництва між Урядом України

та Урядом Алжирської Народної Демократичної Республіки

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1280-р ( 1280-2020-р ) від 21.10.2020 }

Схвалити проект Угоди про створення Спільної комісії з двостороннього співробітництва між Урядом України та Урядом Алжирської Народної Демократичної Республіки.

Уповноважити заступника Міністра закордонних справ з питань цифрового розвитку, цифрових трансформацій і цифровізації Сеніка Дмитра Юрійовича підписати зазначену Угоду. { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 1280-р ( 1280-2020-р ) від 21.10.2020 }
