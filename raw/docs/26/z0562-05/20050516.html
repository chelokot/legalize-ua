МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

16.05.2005 N 202

Зареєстровано в Міністерстві юстиції України 23 травня 2005 р. за N 562/10842

Про втрату чинності наказу Держкомзв'язку України від 01.02.99 N 16

Відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

1. Наказ Державного комітету зв'язку України від 01.02.99 N 16 ( z0172-99 ) "Про затвердження тарифів на пересилання відправлень міжнародної прискореної пошти", зареєстрований у Міністерстві юстиції України 19.03.99 за N 172/3465, визнати таким, що втратив чинність.

2. Директору Державного департаменту з питань зв'язку та інформатизації (Кравець І.В.):

2.1. Подати цей наказ на державну реєстрацію до Міністерства юстиції України.

2.2. Забезпечити інформування споживачів щодо втрати чинності наказу через Web-сайт Мінтрансзв'язку України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Нетудихату Л.І.

Міністр Є.А.Червоненко
