Кабінет Міністрів України; Розпорядження від 25.11.1996 № 751-р

Про утворення Міжвідомчої комісії для вирішення питання про доцільність консервації Горлівського хімічного заводу

Стан: Втратив чинність

Ідентифікатор: 751-96-р

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 листопада 1996 р. N 751-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

1. З метою вирішення питання про доцільність збереження виробництва лускованого тротилу на Горлівському хімічному заводі, фінансування витрат на утримання зазначеного виробництва під час його неповного завантаження або консервації утворити Міжвідомчу комісію для вирішення питання про доцільність консервації Горлівського хімічного заводу у складі згідно з додатком.

2. Міжвідомчій комісії для вирішення питання про доцільність консервації Горлівського хімічного заводу підготувати пропозиції щодо подальшої діяльності заводу.

Прем'єр-міністр України П.ЛАЗАРЕНКО
