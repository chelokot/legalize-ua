КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 жовтня 2006 р. N 1473 Київ

Про управління корпоративними правами держави в агропромисловому комплексі

{ Із змінами, внесеними згідно з Постановою КМ N 764 ( 764-2010-п ) від 11.08.2010 }

Кабінет Міністрів України постановляє:

1. Установити, що повноваження з управління корпоративними правами держави стосовно Національної акціонерної компанії "Украгролізинг" здійснює Кабінет Міністрів України.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 764 ( 764-2010-п ) від 11.08.2010 }

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 14 липня 2006 р. N 978 ( 978-2006-п ) "Питання підвищення ефективності управління корпоративними правами держави в агропромисловому комплексі" (Офіційний вісник України, 2006 р., N 29, ст. 2088).

3. Міністерству аграрної політики у двомісячний строк:

підготувати за поданням Державної акціонерної компанії "Хліб України" та Національної акціонерної компанії "Украгролізинг" пропозиції щодо внесення змін до статутів зазначених компаній, затверджених постановами Кабінету Міністрів України від 14 березня 2001 р. N 240 ( 240-2001-п ) "Про затвердження Статуту Державної акціонерної компанії "Хліб України" (Офіційний вісник України, 2001 р., N 12, ст. 489) та від 11 квітня 2001 р. N 354 ( 354-2001-п ) "Про утворення Національної акціонерної компанії "Украгролізинг" (Офіційний вісник України, 2001 р., N 15, ст. 656);

привести власні нормативно-правові акти у відповідність із цією постановою.

Прем'єр-міністр України В.ЯНУКОВИЧ
