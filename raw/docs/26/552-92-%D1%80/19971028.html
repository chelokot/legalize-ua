Кабінет Міністрів України; Розпорядження від 31.08.1992 № 552-р

Про часткову зміну постанови Кабінету Міністрів України від 25 травня 1992 р. N 266

Стан: Втратив чинність

Ідентифікатор: 552-92-р

Текст документа від 28.10.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 серпня 1992 р. N 552-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1185 ( 1185-97-п ) від 28.10.97 )

На часткову зміну пункту 2 постанови Кабінету Міністрів України від 25 травня 1992 р. N 266 ( 266-92-п ) збільшити граничну чисельність працівників центрального апарату Держжитлокомунгоспу на 25 одиниць для зміцнення підрозділів Комітету, що здійснюють координацію робіт, пов'язаних із забезпеченням населення питною водою, поліпшенням комунального і транспортного обслуговування його.

Прем'єр-міністр України В.ФОКІН
