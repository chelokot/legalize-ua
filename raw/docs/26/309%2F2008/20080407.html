Президент України; Указ від 07.04.2008 № 309/2008

Про зупинення дії положення постанови Кабінету Міністрів України від 22 лютого 2008 року N 90

Стан: Втратив чинність

Ідентифікатор: 309/2008

Текст документа від 07.04.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії положення постанови Кабінету Міністрів України від 22 лютого 2008 року N 90

{ Додатково див. Конституційне подання Президента ( n0003100-08 ) від 07.04.2008 }

Кабінетом Міністрів України 22 лютого 2008 року видано постанову N 90 ( 90-2008-п ) "Деякі питання проведення земельних аукціонів".

Названою постановою ( 90-2008-п ) Кабінет Міністрів України з метою реалізації статті 82 Закону України "Про Державний бюджет України на 2008 рік та про внесення змін до деяких законодавчих актів України" ( 107-17 ) та статті 124 Земельного кодексу України ( 2768-14 ), зокрема, затвердив Порядок проведення земельних аукціонів (пункт 1) ( 90-2008-п ). Цим Порядком ( 90-2008-п ) визначено процедуру підготовки, організації та проведення земельних аукціонів для продажу земельних ділянок державної та комунальної власності або права на їх оренду, крім земельних ділянок, на яких розташовані об'єкти, що підлягають приватизації.

За Основним Законом ( 254к/96-ВР ) держави Кабінет Міністрів України здійснює повноваження, визначені Конституцією ( 254к/96-ВР ) та законами України (пункт 10 частини першої статті 116).

Проте ні Конституцією України ( 254к/96-ВР ), ні зазначеними у постанові ( 90-2008-п ) Кабінету Міністрів України, про яку йдеться, законодавчими актами повноважень щодо затвердження порядку проведення земельних аукціонів із продажу земельних ділянок Кабінету Міністрів України не надано.

До того ж відповідно до частини п'ятої статті 137 Земельного кодексу України ( 2768-14 ) земельні торги, якими за статтею 134 цього Кодексу ( 2768-14 ) є продаж на конкурентних засадах земельних ділянок державної або комунальної власності, призначених для продажу суб'єктам підприємницької діяльності, крім викупу земельних ділянок, на яких розташовані об'єкти нерухомого майна, що є власністю покупців цих ділянок, в яких відсутні акції (частки, паї), що належать державі, проводяться у порядку, встановленому законом.

Відтак, Кабінет Міністрів України, видавши постанову від 22 лютого 2008 року за N 90 ( 90-2008-п ), діяв у спосіб, не передбачений Конституцією ( 254к/96-ВР ) та законами України, чим порушив вимоги частини другої статті 6 Конституції України ( 254к/96-ВР ), за якими органи виконавчої влади здійснюють свої повноваження у встановлених Конституцією України ( 254к/96-ВР ) межах і відповідно до законів України, частини другої статті 19 та частини третьої статті 113 Конституції України ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України діяти на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України, керуватися ними у своїй діяльності.

Ураховуючи наведене та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію пункту 1 постанови Кабінету Міністрів України від 22 лютого 2008 року N 90 ( 90-2008-п ) "Деякі питання проведення земельних аукціонів".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
