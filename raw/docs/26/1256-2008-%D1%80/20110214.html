Кабінет Міністрів України; Розпорядження від 24.09.2008 № 1256-р

Про звільнення Крутя О.А. з посади першого заступника Голови Національного агентства України з питань забезпечення ефективного використання енергетичних ресурсів - начальника Державної інспекції з енергозбереження - головного державного інспектора з енергозбереження

Стан: Чинний

Ідентифікатор: 1256-2008-р

Текст документа від 14.02.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 вересня 2008 р. N 1256-р Київ

Про звільнення Крутя О.А. з посади першого заступника Голови Національного агентства України з питань забезпечення ефективного використання енергетичних ресурсів - начальника Державної інспекції з енергозбереження - головного державного інспектора з енергозбереження

{ Додатково див. Постанову Окружного адміністративного суду міста Києва N 5/514 ( v_514805-09 ) від 26.01.2009 }

{ Вважати КРУТЯ Олександра Анатолійовича поновленим на посаді з 29 вересня 2008 року та звільненим із зазначеної посади згідно з поданою ним заявою з дня набрання чинності Указом Президента N 213/2011 ( 213/2011 ) від 14.02.2011 }

Звільнити Крутя Олександра Анатолійовича з посади першого заступника Голови Національного агентства України з питань забезпечення ефективного використання енергетичних ресурсів - начальника Державної інспекції з енергозбереження - головного державного інспектора з енергозбереження.
