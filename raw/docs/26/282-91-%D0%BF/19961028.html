Кабінет Міністрів України; Постанова від 25.10.1991 № 282

Про встановлення плати за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів

Стан: Втратив чинність

Ідентифікатор: 282-91-п

Текст документа від 28.10.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 жовтня 1991 р. N 282 Київ

Про встановлення плати за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів

( Із змінами, внесеними згідно з Постановами КМ N 270 ( 270-93-п ) від 12.04.93 N 285 ( 285-95-п ) від 17.04.95 N 1318 ( 1318-96-п ) від 28.10.96 )

Відповідно до статті 27 Закону УРСР "Про цінні папери і фондову біржу" ( 1201-12 ) Кабінет Міністрів України постановляє:

Установити плату за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів у розмірі 1000 карбованців.

( На зміну Постанови установити плату за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів у розмірі трьох мінімальних заробітних плат згідно з Постановою КМ N 270 ( 270-93-п ) від 12.04.93 ) ( Встановити плату за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів у розмірі п'ятдесяти неоподатковуваних мінімумів доходів громадян згідно з Постановою КМ N 285 ( 285-95-п ) від 17.04.95 )

Уся сума плати зараховується до Державного бюджету України. ( Абзац третій в редакції Постанови КМ N 1318 ( 1318-96-п ) від 28.10.96 )
