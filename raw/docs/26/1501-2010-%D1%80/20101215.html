Деякі питання проведення розрахунків за пакет акцій ВАТ "Холдингова компанія "Луганськтепловоз"

Стан: Чинний

Ідентифікатор: 1501-2010-р

Текст документа від 15.12.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 липня 2010 р. N 1501-р Київ

Деякі питання проведення розрахунків за пакет акцій ВАТ "Холдингова компанія "Луганськтепловоз"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 2261-р ( 2261-2010-р ) від 15.12.2010 }

1. Погодитися з пропозицією Фонду державного майна щодо припинення взаємних зобов'язань Фонду та закритого акціонерного товариства "Керуюча компанія "Брянський машинобудівний завод" (Російська Федерація), що випливають з постанови Київського апеляційного господарського суду від 6 грудня 2010 р. у справі N 40/140-2/223 та пункту 3 договору купівлі-продажу пакета акцій ВАТ "Холдингова компанія "Луганськтепловоз" від 29 червня 2010 р., шляхом укладення між Фондом державного майна та закритим акціонерним товариством "Керуюча компанія "Брянський машинобудівний завод" договору про зарахування зустрічних однорідних вимог.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 2261-р ( 2261-2010-р ) від 15.12.2010 }

2. Фонду державного майна забезпечити укладення мирової угоди, умови якої передбачатимуть припинення в повному обсязі зобов'язань Фонду, що випливають з постанови Київського апеляційного господарського суду від 6 грудня 2010 р. у справі N 40/140-2/223, та зобов'язань закритого акціонерного товариства "Керуюча компанія "Брянський машинобудівний завод" щодо оплати пакета акцій відповідно до пункту 3 договору купівлі-продажу пакета акцій ВАТ "Холдингова компанія "Луганськтепловоз" від 29 червня 2010 року.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 2261-р ( 2261-2010-р ) від 15.12.2010 }

Прем'єр-міністр України М.АЗАРОВ
