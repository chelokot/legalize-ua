Президент України; Розпорядження від 18.03.2009 № 42/2009-рп

Про призначення довічної державної іменної стипендії Семенюк С.С.

Стан: Чинний

Ідентифікатор: 42/2009-рп

Текст документа від 18.03.2009:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про призначення довічної державної іменної стипендії Семенюк С.С.

Відповідно до Указу Президента України від 26 листопада 2001 року N 1147 ( 1147/2001 ) (зі змінами, внесеними Указами від 2 грудня 2002 року N 1113 ( 1113/2002 ), від 14 жовтня 2004 року N 1242 ( 1242/2004 ), від 10 жовтня 2005 року N 1431 ( 1431/2005 ), від 13 липня 2006 року N 612 ( 612/2006 ) та від 11 квітня 2008 року N 327) ( 327/2008 ) призначити довічну державну іменну стипендію СЕМЕНЮК Стефанії Степанівні - висланій у 1949 році на спецпоселення у Хабаровський край РРФСР і реабілітованій у 1991 році (Житомирська область).

Президент України В.ЮЩЕНКО

м. Київ, 18 березня 2009 року N 42/2009-рп
