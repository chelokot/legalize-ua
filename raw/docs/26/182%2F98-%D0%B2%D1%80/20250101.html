Про внесення змін до деяких законів України щодо виробництва та реалізації алкогольних напоїв

Стан: Чинний

Ідентифікатор: 182/98-вр

Текст документа від 01.01.2025:

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України щодо виробництва та реалізації алкогольних напоїв

( Відомості Верховної Ради України (ВВР), 1998, N 26, ст.168 )

{ Із змінами, внесеними згідно з Кодексом N 2755-VI ( 2755-17 ) від 02.12.2010, ВВР, 2011, N 13-14, N 15-16, N 17, ст.112 Законом N 3817-IX ( 3817-20 ) від 18.06.2024 }

Верховна Рада України постановляє:

I. Внести зміни до таких законів України:

{ Пункт 1 розділу I втратив чинність на підставі Кодексу N 2755-VI ( 2755-17 ) від 02.12.2010 }

{ Пункт 2 розділу I втратив чинність на підставі Закону N 3817-IX ( 3817-20 ) від 18.06.2024 }

II. Прикінцеві положення

1. Цей Закон набирає чинності з дня його опублікування.

2. Встановити, що маркування алкогольних напоїв з вмістом спирту етилового від 1,2 до 8,5 відсотка об'ємних одиниць, які вироблені в Україні, не провадиться.

3. Кабінету Міністрів України у місячний термін привести свої нормативно-правові акти у відповідність з цим Законом.
