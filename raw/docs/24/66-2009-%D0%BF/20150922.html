ПОСТАНОВА від 4 лютого 2009 р. N 66 Київ

{ Постанова втратила чинність на підставі Постанов КМ N 645 ( 645-2015-п ) від 22.07.2015 N 656 ( 656-2015-п ) від 19.08.2015 }

Про внесення зміни до пункту 2 постанови Кабінету Міністрів України від 12 листопада 1997 р. N 1260

Кабінет Міністрів України постановляє:

В абзаці сьомому пункту 2 постанови Кабінету Міністрів України від 12 листопада 1997 р. N 1260 ( 1260-97-п ) "Про документи про освіту та вчені звання" (Офіційний вісник України, 1997 р., число 46, с. 84; 2000 р., N 13, ст. 520; 2004 р., N 13, ст. 902) слова "півтора неоподатковуваного мінімуму" замінити словами "двох неоподатковуваних мінімумів".
