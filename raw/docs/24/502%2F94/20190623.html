Про заходи щодо впорядкування цін на окремі періодичні видання

( Із змінами, внесеними згідно з Указами Президента N 685/94 ( 685/94 ) від 18.11.94 N 405/95 ( 405/95 ) від 31.05.95 N 500/95 ( 500/95 ) від 30.06.95 )

З метою стримування у 1995 році зростання цін на окремі друковані засоби масової інформації (пресу) та забезпечення державної підтримки періодичних видань та відповідно до пункту 7-4 статті 114-5 Конституції України ( 888-09 ) постановляю:

1. Установити, що від податку на добавлену вартість звільняється передплата на 1995 рік за газети і журнали, засновниками яких є Верховна Рада України, Кабінет Міністрів України, центральні органи державної виконавчої влади України, органи місцевого самоврядування, творчі спілки України та інші громадські організації, трудові та журналістські колективи редакцій і які зареєстровані до 1 серпня 1994 року.

( Чинність статті 1 поширена в частині звільнення від податку на добавлену вартість на папір, картон та інші поліграфічні матеріали вітчизняного виробництва, а також послуги підприємств поліграфії, зв'язку, транспорту, які забезпечують друкування та розповсюдження газет і журналів згідно з Указом Президента N 685/94 ( 685/94 ) від 18.11.94 ) ( Пункт 1 втратив чинність згідно з Указом Президента N 405/95 ( 405/95 ) від 31.05.95 - дію пункту 1 відновлено згідно з Указом Президента N 500/95 ( 500/95 ) від 30.06.95 )

2. Затвердити перелік товарів, які звільняються від обкладання ввізним митом (додається).

( Пункт 2 втратив чинність згідно з Указом Президента N 405/95 ( 405/95 ) від 31.05.95 - дію пункту 2 відновлено згідно з Указом Президента N 500/95 ( 500/95 ) від 30.06.95 )

3. Установити граничний розмір рентабельності 3 відсотки до собівартості при визначенні тарифів на розповсюдження періодичних видань.

4. Цей Указ набирає чинності з дня його підписання.

Президент України Л.КУЧМА
