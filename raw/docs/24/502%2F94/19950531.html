Про заходи щодо впорядкування цін на окремі періодичні видання

Стан: Втратив чинність

Ідентифікатор: 502/94

Текст документа від 31.05.1995:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про заходи щодо впорядкування цін на окремі періодичні видання

( Із змінами, внесеними згідно з Указами Президента N 685/94 ( 685/94 ) від 18.11.94 N 405/95 ( 405/95 ) від 31.05.95 )

З метою стримування у 1995 році зростання цін на окремі друковані засоби масової інформації (пресу) та забезпечення державної підтримки періодичних видань та відповідно до пункту 7-4 статті 114-5 Конституції України ( 888-09 ) постановляю:

( Стаття 1 втратила чинність на підставі Указу Президента N 405/95 ( 405/95 ) від 31.05.95 )

( Стаття 2 втратила чинність на підставі Указу Президента N 405/95 ( 405/95 ) від 31.05.95 )

3. Установити граничний розмір рентабельності 3 відсотки до собівартості при визначенні тарифів на розповсюдження періодичних видань.

4. Цей Указ набирає чинності з дня його підписання.

Президент України Л.КУЧМА

м. Київ, 7 вересня 1994 року N 502/94
