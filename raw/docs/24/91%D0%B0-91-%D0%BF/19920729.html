КАБІНЕТ МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 18 липня 1991 р. N 91 Київ

Про внесення змін і доповнень до рішень Уряду УРСР з питань соціального розвитку села та агропромислового комплексу

( Із змінами, внесеними згідно з Постановою КМ N 423 ( 423-92-п ) від 29.07.92 )

На виконання постанови Верховної Ради УРСР від 25 квітня 1991 р. "Про проведену роботу та заходи по забезпеченню виконання вимог Закону Української РСР "Про пріоритетність соціального розвитку села та агропромислового комплексу в народному господарстві України" ( 997-12 ) Кабінет Міністрів Української РСР постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 423 ( 423-92-п ) від 29.07.92 )

2. На часткову зміну пункту 4 постанови Ради Міністрів УРСР від 15 грудня 1990 р. N 368 ( 368-90-п ) "Про постачання сільського населення товарами народного споживання" Раді Міністрів Кримської АРСР, облвиконкомам забезпечити протягом 1991 - 1993 років вирівнювання споживання товарів, вказаних у додатку N 2 до зазначеної постанови, у сільській і міській місцевості.
