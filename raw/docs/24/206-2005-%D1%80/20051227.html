Текст документа від 27.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 червня 2005 р. N 206-р Київ

( Розпорядження скасовано на підставі Указу Президента N 1844/2005 ( 1844/2005 ) від 27.12.2005 )

Про відновлення дії пункту 3 розпорядження Кабінету Міністрів України від 22 жовтня 2004 р. N 772

Відновити дію пункту 3 розпорядження Кабінету Міністрів України від 22 жовтня 2004 р. N 772 ( 772-2004-р ) "Про затвердження проекту та титулу будови "Реконструкція та надбудова будинку по вул. Солом'янській, 2а, для розміщення Апеляційного суду м. Києва".

У зв'язку з цим визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 15 січня 2005 р. N 7 ( 7-2005-р ) "Про внесення зміни до розпорядження Кабінету Міністрів України від 22 жовтня 2004 р. N 772".

Прем'єр-міністр України Ю.ТИМОШЕНКО
