04.04.2003 N 50

Зареєстровано в Міністерстві юстиції України 23 квітня 2003 р. за N 322/7643

Про затвердження Вимог та умов безпеки (ліцензійних умов) під час провадження діяльності з проектування ядерної установки або сховища для захоронення радіоактивних відходів (НП 306.5.02/2.069-2003)

( Із змінами, внесеними згідно з Наказом Державного комітету ядерного регулювання N 97 ( z1019-05 ) від 31.08.2005 )

Відповідно до Закону України "Про дозвільну діяльність у сфері використання ядерної енергії" ( 1370-14 ) та на виконання постанови Кабінету Міністрів України від 6 грудня 2000 року N 1782 ( 1782-2000-п ) (із змінами та доповненнями) "Про затвердження Порядку ліцензування окремих видів діяльності у сфері використання ядерної енергії" НАКАЗУЮ:

1. Затвердити Вимоги та умови безпеки (ліцензійні умови) під час провадження діяльності з проектування ядерної установки або сховища для захоронення радіоактивних відходів (НП 306.5.02/2.069-2003) (далі - Вимоги та умови), що додаються.

2. Начальнику Управління регулювання безпеки ядерних установок Семенову О.Ф. у 5-денний строк після підписання наказу забезпечити його подання на державну реєстрацію до Міністерства юстиції України.

3. Директору Державного науково-технічного центру з ядерної та радіаційної безпеки Васильченку В.М. у місячний строк після державної реєстрації наказу забезпечити тиражування Вимог та умов.

4. Начальнику Управління регулювання безпеки ядерних установок Семенову О.Ф. у 10-денний строк після тиражування Вимог та умов забезпечити його розсилку згідно з розрахунком розсилки.

5. Контроль за виконанням наказу покласти на першого заступника Голови Миколайчук О.А.

Голова В.Грищенко

ЗАТВЕРДЖЕНО Наказ Державного комітету ядерного регулювання України 04.04.2003 N 50

Зареєстровано в Міністерстві юстиції України 23 квітня 2003 р. за N 322/7643

ВИМОГИ ТА УМОВИ БЕЗПЕКИ (ЛІЦЕНЗІЙНІ УМОВИ) ПІД ЧАС ПРОВАДЖЕННЯ ДІЯЛЬНОСТІ З ПРОЕКТУВАННЯ ЯДЕРНОЇ УСТАНОВКИ АБО СХОВИЩА ДЛЯ ЗАХОРОНЕННЯ РАДІОАКТИВНИХ ВІДХОДІВ (НП 306.5.02/2.069-2003)

1. Загальні положення

1.1. Ці Вимоги та умови розроблено відповідно до Закону України "Про дозвільну діяльність у сфері використання ядерної енергії" ( 1370-14 ) та на виконання постанови Кабінету Міністрів України від 6 грудня 2000 року N 1782 ( 1782-2000-п ) "Про затвердження Порядку ліцензування окремих видів діяльності у сфері використання ядерної енергії".

1.2. Вимоги та умови є обов'язковими для суб'єктів діяльності у сфері використання ядерної енергії, які здійснюють проектування ядерної установки або сховища для захоронення радіоактивних відходів (далі - сховища).

1.3. До діяльності з проектування ядерної установки або сховища належать роботи з розроблення проектної документації (та змін до неї) на ядерну установку або сховище, включаючи усі об'єкти, що розташовані на майданчику даної ядерної установки або сховища і технологічно з ними пов'язані. ( Пункт 1.3 в редакції Наказу Державного комітету ядерного регулювання N 97 ( z1019-05 ) від 31.08.2005 )

1.4. Термін "проектна документація" використовується в значенні, наведеному у Додатку Б Державних будівельних норм "Проектування. Склад, порядок розроблення, погодження та затвердження проектної документації для будівництва" ДБН А.2.2-3-2004 ( v0008509-04 ), затверджених наказом Держбуду України від 20 січня 2004 року N 8 ( va008509-04 ). ( Пункт 1.4 в редакції Наказу Державного комітету ядерного регулювання N 97 ( z1019-05 ) від 31.08.2005 )

2. Вимоги та умови безпеки (ліцензійні умови) під час провадження діяльності з проектування ядерної установки або сховища

2.1. Діяльність з проектування ядерної установки або сховища у сфері використання ядерної енергії дозволяється за умови наявності ліцензії, виданої згідно з Порядком ліцензування окремих видів діяльності у сфері використання ядерної енергії, затвердженим постановою Кабінету Міністрів України від 6 грудня 2000 року N 1782 ( 1782-2000-п ).

2.2. Ліцензіат здійснює свою діяльність відповідно до чинного законодавства України та норм, правил і стандартів з ядерної та радіаційної безпеки, перелік яких (з урахуванням специфіки діяльності) затверджується наказом по підприємству.

2.3. Ліцензіат повинен мати організаційну структуру підприємства з розподілом обов'язків, повноважень та відповідальності персоналу.

2.4. Ліцензіат повинен мати фінансове забезпечення, достатнє для якісного виконання запланованого обсягу проектних робіт.

2.5. Ліцензіат забезпечує процес розробки проектної документації технічними (обчислювальними, розмножувальними), програмними засобами, відповідною нормативною документацію, необхідною для виконання запланованого обсягу проектних робіт.

2.6. Ліцензіат повинен мати персонал відповідної кваліфікації, достатньої для якісного виконання запланованого обсягу робіт. Відповідальність та вимоги щодо кваліфікації персоналу, включаючи відповідальність та вимоги щодо кваліфікації тих, що виконують роботи, які впливають на безпеку ядерної установки або сховища, встановлюються ліцензіатом.

2.7. Ліцензіат проводить навчання та перевірку знань персоналу підприємства відповідно до Типового положення про порядок проведення навчання і перевірки знань з питань охорони праці, затвердженого наказом Державного комітету України з нагляду за охороною праці від 26 січня 2005 року N 15 ( z0231-05 ), зареєстрованого в Міністерстві юстиції України 15 лютого 2005 року за N 231/10511. ( Абзац перший пункту 2.7 в редакції Наказу Державного комітету ядерного регулювання N 97 ( z1019-05 ) від 31.08.2005 )

Перевірка має проводитися згідно з Положенням про порядок перевірки знань персоналом підприємства норм і правил з ядерної та радіаційної безпеки, відповідно до переліку питань, узгодженого з Держатомрегулювання України, за обов'язковою участю його представника.

2.8. Ліцензіат забезпечує проведення спеціальної перевірки персоналу з метою надання допусків до особливих робіт згідно з Порядком проведення спеціальної перевірки для надання допуску фізичним особам до роботи на ядерних установках та з ядерними матеріалами, затвердженим постановою Кабінету Міністрів України від 25 грудня 1997 року N 1471 ( 1471-97-п ).

2.9. Ліцензіат забезпечує захист інформації, яка містить державну таємницю.

2.10. Ліцензіат організовує планування, розробку, затвердження, уведення у дію проектної документації та внесення змін до неї на всіх етапах проведення робіт з проектування та контролю якості, включаючи облік, звітність, зберігання проектної документації, забезпечує проведення ефективного контролю проектної документації.

2.11. Ліцензіат упроваджує та забезпечує функціонування системи якості відповідно до стандартів серії ДСТУ ISO 9000.

2.12. Ліцензіат несе відповідальність за якість виконаних робіт та дотримання ним вимог чинного законодавства, норм, правил і стандартів з ядерної та радіаційної безпеки. Конкретні умови та межі відповідальності ліцензіата та замовника проектних робіт обумовлюються у контракті.

Замовником проектних робіт може бути будь-який суб'єкт діяльності у сфері використання ядерної енергії, тобто юридична особа (підприємство, установа або організація будь-якої форми господарювання) або фізична особа, яка здійснює діяльність у сфері використання ядерної енергії.

2.13. Ліцензіат в 10-денний строк інформує Держатомрегулювання України про зміни умов провадження діяльності та про зміни в документах, на підставі яких видана ліцензія.

2.14. У разі, якщо ліцензіат має намір припинити ліцензовану діяльність, він сповіщає про це Держатомрегулювання України не пізніше ніж за місяць.

2.15. За наявності підстав для внесення змін до ліцензії, визначених Порядком ліцензування окремих видів діяльності у сфері використання ядерної енергії, затвердженим постановою Кабінету Міністрів України від 6 грудня 2000 року N 1782 ( 1782-2000-п ), ліцензіат подає відповідну заяву до Держатомрегулювання України.
