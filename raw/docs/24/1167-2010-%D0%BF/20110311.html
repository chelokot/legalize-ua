КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 грудня 2010 р. N 1167 Київ

Про внесення змін до постанов Кабінету Міністрів України від 19 квітня 1993 р. N 283 і від 5 липня 2002 р. N 932

{ Із змінами, внесеними згідно з Постановою КМ N 86 ( 86-2011-п ) від 09.02.2011 }

Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України від 19 квітня 1993 р. N 283 ( 283-93-п ) "Про встановлення порядку виготовлення бланків цінних паперів і документів суворого обліку" - із змінами, внесеними розпорядженням Кабінету Міністрів України від 4 листопада 1993 р. N 936 ( 936-93-р ), постановами Кабінету Міністрів України від 18 жовтня 1999 р. N 1919 ( 1919-99-п ) (Офіційний вісник України, 1999 р., N 42, ст. 2096), від 17 червня 2004 р. N 786 ( 786-2004-п ) (Офіційний вісник України, 2004 р., N 24, ст. 1599), від 21 лютого 2007 р. N 286 ( 286-2007-п ) (Офіційний вісник України, 2007 р., N 14, ст. 534), від 17 квітня 2008 р. N 381 ( 381-2008-п ) (Офіційний вісник України, 2008 р., N 31, ст. 991), від 21 травня 2009 р. N 560 ( 560-2009-п ) (Офіційний вісник України, 2009 р., N 42, ст. 1411), і від 5 липня 2002 р. N 932 ( 932-2002-п ) "Про затвердження переліків документів і груп товарів, які підлягають захисту голографічними елементами" (Офіційний вісник України, 2002 р., N 28, ст. 1314; 2004 р., N 12, ст. 741, N 30, ст. 2016) зміни, що додаються.

2. Міністерству інфраструктури, Міністерству фінансів, Міністерству економічного розвитку і торгівлі привести власні нормативно-правові акти у відповідність з цією постановою.

3. Ця постанова набирає чинності з 1 січня 2011 року.

Прем'єр-міністр України М.АЗАРОВ

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 22 грудня 2010 р. N 1167

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 19 квітня 1993 р. N 283 ( 283-93-п ) і від 5 липня 2002 р. N 932 ( 932-2002-п )

1. Абзац третій розділу II додатка до постанови Кабінету Міністрів України від 19 квітня 1993 р. N 283 ( 283-93-п ) після слів "документи на перевезення вантажів" доповнити словами ", крім перевізних документів на перевезення вантажу залізничним транспортом".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 86 ( 86-2011-п ) від 09.02.2011 }
