Про затвердження обов'язкового мінімального асортименту лікарських засобів для аптек

{ Із змінами, внесеними згідно з Наказами Міністерства охорони здоров'я N 602 ( z1411-05 ) від 14.11.2005 N 992 ( z1188-10 ) від 16.11.2010 }

Відповідно до Положення про Міністерство охорони здоров'я України, затвердженого Указом Президента України від 24.07.2000 N 918 ( 918/2000 ) та з метою удосконалення медикаментозного забезпечення населення НАКАЗУЮ:

{ Преамбула із змінами, внесеними згідно з Наказом Міністерства охорони здоров'я N 992 ( z1188-10 ) від 16.11.2010 }

1. Затвердити обов'язковий мінімальний асортимент лікарських засобів для аптек (додається).

{ Пункт 2 втратив чинність на підставі Наказу Міністерства охорони здоров'я N 602 ( z1411-05 ) від 14.11.2005 }

3. Державній службі лікарських засобів і виробів медичного призначення забезпечити в установленому порядку реєстрацію наказу в Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника Міністра - голову Державної служби лікарських засобів і виробів медичного призначення Пасічника М.Ф.

Міністр А.В.Підаєв

Лікарські засоби наведені за міжнародними непатентованими назвами.

У разі відсутності міжнародних непатентованих назв наведені загальноприйняті назви (позначка "*").

Назви виробів медичного призначення наведені згідно з Державним реєстром медичної техніки і виробів медичного призначення.
