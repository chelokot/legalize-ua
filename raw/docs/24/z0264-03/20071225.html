Про затвердження Порядку погодження Міністром юстиції України кандидатур для призначення на посади керівників юридичних служб міністерств, інших центральних органів виконавчої влади

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 1233/5 ( z1371-07 ) від 11.12.2007 }

Відповідно до пункту 10 Положення про Міністерство юстиції України, затвердженого постановою Кабінету Міністрів України від 14 листопада 2006 року N 1577 ( 1577-2006-п ), та з метою залучення висококваліфікованих фахівців до роботи в юридичних службах міністерств, інших центральних органів виконавчої влади НАКАЗУЮ:

{ Преамбула із змінами, внесеними згідно з Наказом Міністерства юстиції N 1233/5 ( z1371-07 ) від 11.12.2007 }

1. Затвердити Порядок погодження Міністром юстиції України кандидатур для призначення на посади керівників юридичних служб міністерств, інших центральних органів виконавчої влади, що додається.

2. Департаменту координації правової роботи та правової освіти юридичних служб міністерств, інших центральних органів виконавчої влади, підприємств, установ та організацій (Марченко Л.О.) подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" та забезпечити його виконання.

3. Контроль за виконанням наказу покласти на заступника Державного секретаря Л.М.Горбунову.

Міністр О.В.Лавринович ЗАТВЕРДЖЕНО Наказ Міністерства юстиції України 04.04.2003 N 27/5

Зареєстровано в Міністерстві юстиції України 4 квітня 2003 р. за N 264/7585

ПОРЯДОК погодження Міністром юстиції України кандидатур для призначення на посади керівників юридичних служб міністерств, інших центральних органів виконавчої влади

1. Цей Порядок розроблено відповідно до пункту 10 Положення про Міністерство юстиції України, затвердженого постановою Кабінету Міністрів України від 14 листопада 2006 року N 1577 ( 1577-2006-п ), та визначає процедуру погодження Міністром юстиції України кандидатур для призначення на посади керівників юридичних служб міністерств, інших центральних органів виконавчої влади (далі - керівники юридичних служб).

{ Пункт 1 із змінами, внесеними згідно з Наказом Міністерства юстиції N 1233/5 ( z1371-07 ) від 11.12.2007 }

2. Подання щодо погодження Міністром юстиції України кандидатури на посаду керівника юридичної служби робиться керівником відповідного міністерства, іншого центрального органу виконавчої влади до проведення іспиту та відбору кандидатів на заміщення вакантної посади державного службовця або після проходження стажування, або після висування з кадрового резерву, або за іншою процедурою, визначеною чинним законодавством для прийняття на посаду державного службовця.

3. У поданні щодо кандидатури на посаду керівника юридичної служби, викладеному в довільній формі, зазначаються прізвище, ім'я, по батькові, дата народження, громадянство, займана посада, стаж роботи за фахом, ділові та інші якості, відомості про перебування в кадровому резерві, проходження стажування чи про іншу процедуру, визначену для прийняття на посаду державного службовця. До подання також додаються копії трудової книжки та диплома, засвідчені в установленому порядку.

4. Відповідний структурний підрозділ Міністерства юстиції України попередньо розглядає документи, що надійшли на погодження, організовує проведення співбесіди заступника Міністра з кандидатами, під час якої з'ясовується рівень знань вимог нормопроектної техніки, Загального положення про юридичну службу міністерства, іншого центрального органу виконавчої влади, державного підприємства, установи, організації, затвердженого постановою Кабінету Міністрів України від 27 серпня 1995 року N 690 ( 690-95-п ) (із змінами і доповненнями), нормативно-правових актів з питань, що належать до компетенції відповідного міністерства, іншого центрального органу виконавчої влади. За результатами співбесіди з заступником Міністра відповідний структурний підрозділ Міністерства юстиції України готує висновок щодо погодження кандидатури для призначення на посаду керівника юридичної служби, який візується відповідним заступником Міністра та подається на розгляд Міністру юстиції України.

{ Пункт 4 із змінами, внесеними згідно з Наказом Міністерства юстиції N 1233/5 ( z1371-07 ) від 11.12.2007 }

5. За результатами розгляду висновку щодо погодження кандидатур для призначення на посаду керівника юридичної служби відповідним структурним підрозділом Міністерства юстиції України заповнюється картка погодження кандидатури для призначення на посаду керівника юридичної служби міністерства, іншого центрального органу виконавчої влади, за формою, наведеною у додатку до цього Порядку, яку підписує Міністр юстиції України.

Картка погодження кандидатури для призначення на посаду керівника юридичної служби міністерства, іншого центрального органу виконавчої влади разом з копіями трудової книжки та диплома направляються протягом семи робочих днів, з дня отримання подання, зазначеного у пункті 2, керівнику міністерства, іншого центрального органу виконавчої влади, який здійснює призначення на цю посаду.

Директор Департаменту координації правової роботи та правової освіти юридичних служб міністерств, інших центральних органів виконавчої влади, підприємств, установ та організацій Л.О.Марченко
