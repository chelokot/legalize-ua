МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

19.06.2006 N 228

Зареєстровано в Міністерстві юстиції України 27 червня 2006 р. за N 759/12633

Про втрату чинності деяких наказів Міністерства праці та соціальної політики України

Відповідно до постанови Кабінету Міністрів України від 20.02.2006 N 172 ( 172-2006-п ) "Про встановлення посадового окладу (тарифної ставки) працівника I тарифного розряду Єдиної тарифної сітки та внесення змін у додаток 2 до постанови Кабінету Міністрів України від 30 серпня 2002 р. N 1298" НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

1.1. Наказ Міністерства праці та соціальної політики України від 22.06.2000 N 142 ( z0478-00 ) "Про умови оплати праці працівників апарату Центральної ради, Кримської республіканської, обласних, Київської та Севастопольської міських рад фізкультурно-спортивного товариства "Динамо" України", зареєстрований у Міністерстві юстиції України 04.08.2000 за N 478/4699 (із змінами).

1.2. Наказ Міністерства праці та соціальної політики України від 28.12.2000 N 367 ( z0032-01 ) "Про впорядкування умов оплати праці працівників центрів з фізичної культури і спорту інвалідів "Інваспорт", зареєстрований у Міністерстві юстиції України 17.01.2001 за N 32/5223 (із змінами).

1.3. Наказ Міністерства праці та соціальної політики України від 13.02.2001 N 52 ( z0140-01 ) "Про упорядкування умов оплати праці працівників управління "Укрспортзабезпечення", зареєстрований у Міністерстві юстиції України 15.02.2001 за N 140/5331 (із змінами).

1.4. Наказ Міністерства праці та соціальної політики України від 21.11.2002 N 588 ( z0926-02 ) "Про умови оплати праці працівників Національного антидопінгового центру", зареєстрований у Міністерстві юстиції України 28.11.2002 за N 926/7214 (із змінами).

1.5. Наказ Міністерства праці та соціальної політики України від 07.08.2003 N 222 ( z0713-03 ) "Про умови оплати праці працівників центрів фізичного здоров'я населення "Спорт для всіх", зареєстрований у Міністерстві юстиції України 15.08.2003 за N 713/8034 (із змінами).

1.6. Наказ Міністерства праці та соціальної політики України від 12.01.2004 N 4 ( z0128-04 ) "Про умови оплати праці працівників апарату Центральної, Кримської республіканської рад, обласних, Київської і Севастопольської міських, міських, районних і районних у містах організацій фізкультурно-спортивного товариства "Україна", зареєстрований у Міністерстві юстиції України 29.01.2004 за N 128/8727 (із змінами).

1.7. Наказ Міністерства праці та соціальної політики України від 12.01.2004 N 5 ( z0127-04 ) "Про умови оплати праці працівників апарату Центральної, Кримської республіканської рад, обласних, Київської і Севастопольської міських, міських, районних і районних у містах організацій фізкультурно-спортивного товариства "Спартак", зареєстрований у Міністерстві юстиції України 29.01.2004 за N 127/8726 (із змінами).
