{ Закон втратив чинність на підставі Закону N 1798-VIII ( 1798-19 ) від 21.12.2016, ВВР, 2017, N 7-8, ст.50 }

Про внесення зміни до статті 6 Закону України "Про Вищу раду юстиції"

( Відомості Верховної Ради України (ВВР), 2004, N 29, ст.369 )

Верховна Рада України постановляє:

1. Частину першу статті 6 Закону України "Про Вищу раду юстиції" ( 22/98-ВР ) (Відомості Верховної Ради України, 1998 р., N 25, ст. 146) викласти в такій редакції:

"На посаду члена Вищої ради юстиції може бути рекомендований громадянин України, не молодший тридцяти п'яти років і не старший шістдесяти п'яти років, який проживає в Україні не менш як десять останніх років, володіє державною мовою, має вищу юридичну освіту та стаж роботи в галузі права не менше десяти років".

2. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА
