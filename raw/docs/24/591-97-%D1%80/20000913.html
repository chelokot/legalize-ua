( Розпорядження втратило чинність на підставі Розпорядження КМ N 352-р ( 352-2000-р ) від 13.09.2000 )

Про закріплення у державній власності пакету акцій ДАЕК "Миколаївобленерго"

Відповідно до підпункту 5.1.1 розділу 5 частини II Державної програми приватизації на 1997 рік ( 294/97-ВР ) закріпити у державній власності пакет акцій у розмірі 26 відсотків статутного фонду ДАЕК "Миколаївобленерго" на 3 роки.
