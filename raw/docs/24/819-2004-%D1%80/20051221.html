( Розпорядження втратило чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

Про затвердження нового складу Координаційної ради з питань запобігання зникненню людей

Затвердити новий склад Координаційної ради з питань запобігання зникненню людей, утвореної постановою Кабінету Міністрів України від 3 лютого 2001 р. N 99 ( 99-2001-п ) (Офіційний вісник України, 2001 р., N 6, ст. 223), що додається.

Дозволити голові Ради вносити у разі потреби зміни до її складу.
