Кабінет Міністрів України; Розпорядження від 06.09.2007 № 700-р

Про виділення коштів для проведення першочергових аварійно-відбудовних робіт в Ожидівській середній загальноосвітній школі I-III ступеня та на території Ожидівської сільської ради Буського району Львівської області

Стан: Чинний

Ідентифікатор: 700-2007-р

Текст документа від 24.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 вересня 2007 р. N 700-р Київ

Про виділення коштів для проведення першочергових аварійно-відбудовних робіт в Ожидівській середній загальноосвітній школі I-III ступеня та на території Ожидівської сільської ради Буського району Львівської області

{ Із змінами, внесеними згідно з Розпорядженням КМ N 914-р ( 914-2007-р ) від 24.10.2007 }

1. Виділити Львівській облдержадміністрації 897,7 тис. гривень для проведення першочергових аварійно-відбудовних робіт в Ожидівській середній загальноосвітній школі I-III ступеня та на території Ожидівської сільської ради Буського району Львівської області. { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 914-р ( 914-2007-р ) від 24.10.2007 }

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 489-16 ).

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 914-р ( 914-2007-р ) від 24.10.2007 }

2. Львівській облдержадміністрації:

затвердити у тижневий строк за погодженням з Мінекономіки, Мінфіном і Мінрегіонбудом перелік витрат, пов'язаних з проведенням першочергових аварійно-відбудовних робіт, зазначених у пункті 1 цього розпорядження;

подати до кінця 2007 року Мінекономіки, Мінфіну, Мінрегіонбуду і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.
