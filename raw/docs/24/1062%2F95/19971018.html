Президент України; Указ від 17.11.1995 № 1062/95

Про заходи щодо проведення експерименту у Північнокримській експериментальній економічній зоні "Сиваш"

Стан: Втратив чинність

Ідентифікатор: 1062/95

Текст документа від 18.10.1997:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про заходи щодо проведення експерименту у Північнокримській експериментальній економічній зоні "Сиваш"

( Із змінами, внесеними згідно з Указами Президента N 134/96 ( 134/96 ) від 19.02.96 N 1263/96 ( 1263/96 ) від 20.12.96 N 1165/97 ( 1165/97 ) від 18.10.97 )

З метою створення належних умов для проведення експерименту у Північнокримській експериментальній економічній зоні "Сиваш" та відповідно до статті 25 Конституційного Договору між Президентом України та Верховною Радою України "Про основні засади організації та функціонування державної влади і місцевого самоврядування в Україні на період до прийняття нової Конституції України" ( 1к/95-ВР ) постановляю:

( Стаття 1 втратила чинність на підставі Указу Президента N 1165/97 ( 1165/97 ) від 18.10.97 )

2. Установити, що платники податків, зареєстровані в установленому порядку як суб'єкти Північнокримської експериментальної економічної зони "Сиваш", які реалізують інвестиційні проекти в її межах (далі - суб'єкти зони "Сиваш"), сплачують податок на прибуток та податок на добавлену вартість на продукцію власного виробництва у розмірі 50 відсотків установлених чинним законодавством ставок.

При здійсненні імпорту товарів (робіт, послуг) для потреб власного виробництва суб'єкти зони "Сиваш" звільняються від сплати ввізного мита, податку на добавлену вартість та акцизного збору.

Експорт суб'єктами зони "Сиваш" товарів власного виробництва, перелік яких установлюється Кабінетом Міністрів України, не підлягає квотуванню та ліцензуванню.

Надходження в іноземній валюті на користь суб'єктів зони "Сиваш" не підлягають обов'язковому продажу на міжбанківському валютному ринку.

3. Кабінету Міністрів України:

визначити перелік майна, що перебуває у загальнодержавній власності та знаходиться на території зони "Сиваш" і необхідне для проведення експерименту, та передати його до сфери управління Адміністрації Північнокримської експериментальної економічної зони;

передбачити в проектах Державного бюджету України на 1996 та наступні роки видатки, пов'язані з проведенням експерименту;

подати у місячний строк до Верховної Ради України проекти законодавчих актів щодо застосування законодавства з питань оподаткування, валютного регулювання, бюджетної політики під час проведення локальних економічних експериментів. ( Абзац четвертий статті 3 із змінами, внесеними згідно з Указом Президента N 134/96 ( 134/96 ) від 19.02.96 )

Президент України Л.КУЧМА

м. Київ, 17 листопада 1995 року N 1062/95
