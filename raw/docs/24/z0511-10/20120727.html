Зареєстровано в Міністерстві юстиції України 13 липня 2010 р. за N 511/17806

ВИМОГИ до екзаменаційних білетів

{ Із змінами, внесеними згідно з Наказом Міністерства аграрної політики та продовольства N 347 ( z1135-12 ) від 13.06.2012 }

1. Іспит зі знань правил дорожнього руху та правил технічної експлуатації машин приймається за екзаменаційними білетами з використанням комп'ютерної техніки та у разі відсутності можливості її застосування у письмовій формі.

2. Екзаменаційні білети повинні включати всі розділи правил дорожнього руху та правил технічної експлуатації машин.

3. Кожний екзаменаційний білет повинен містити 20 питань, які повинні мати порядкові номери від 1 до 20. На кожне питання повинно пропонуватися від 2 до 5 відповідей, з яких правильною і найбільш повною є одна.

4. Для виключення випадків запам'ятовування екзаменаційних білетів державними інспекціями сільського господарства в Автономній Республіці Крим, областях, містах Києві та Севастополі повинно використовуватися не менше двох варіантів білетів.

{ Пункт 4 із змінами, внесеними згідно з Наказом Міністерства аграрної політики та продовольства N 347 ( z1135-12 ) від 13.06.2012 }
