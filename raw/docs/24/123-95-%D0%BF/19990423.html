ПОСТАНОВА від 16 лютого 1995 р. N 123 Київ

( Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-99-п ) від 23.04.99 )

Про призначення Гончарука А.І. головою Української частини Українсько-Датської консультативної групи з питань розвитку економічного, промислового та науково-технічного співробітництва

Кабінет Міністрів України постановляє:

Призначити заступника Міністра зовнішніх економічних зв'язків України Гончарука Андрія Івановича головою Української частини Українсько-Датської консультативної групи з питань розвитку економічного, промислового та науково-технічного співробітництва.
