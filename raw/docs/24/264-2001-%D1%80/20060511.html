Про утворення міжвідомчої робочої групи для сприяння розв'язанню проблем Акціонерного комерційного агропромислового банку "Україна"

Стан: Втратив чинність

Ідентифікатор: 264-2001-р

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 червня 2001 р. N 264-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Про утворення міжвідомчої робочої групи для сприяння розв'язанню проблем Акціонерного комерційного агропромислового банку "Україна"

( Із змінами, внесеними згідно з Розпорядженнями КМ N 292-р ( 292-2001-р ) від 24.07.2001 N 36-р ( 36-2002-р ) від 29.01.2002 N 238-р ( 238-2003-р ) від 23.04.2003 )

1. З метою координації зусиль органів виконавчої влади щодо забезпечення захисту інтересів вкладників Акціонерного комерційного агропромислового банку "Україна", забезпечення безперебійного кредитно - касового обслуговування клієнтів банку утворити міжвідомчу робочу групу для сприяння розв'язанню його проблем у складі згідно з додатком.

2. Міжвідомчій робочій групі:

систематично інформувати Кабінет Міністрів України, Національний банк та громадськість про проведену роботу;

з питань, що потребують нормативно-правового врегулювання, вносити відповідні пропозиції.

3. Дозволити керівникові міжвідомчої робочої групи у разі потреби вносити зміни до її складу. ( Розпорядження доповнено пунктом 3 згідно з Розпорядженням КМ N 36-р ( 36-2002-р ) від 29.01.2002 )
