ПОСТАНОВА від 8 листопада 2007 р. N 1299 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1236 ( 1236-2010-п ) від 27.12.2010 }

Про внесення зміни у додаток 2 до постанови Кабінету Міністрів України від 7 березня 2000 р. N 456

Кабінет Міністрів України постановляє:

У додатку 2 до постанови Кабінету Міністрів України від 7 березня 2000 р. N 456 ( 456-2000-п ) "Про затвердження нормативів плати за користування надрами для видобування мінеральних підземних вод" (Офіційний вісник України, 2000 р., N 10, ст. 383) слова "Регіна (Мурованокуриловецьке)" замінити словом "Мурованокуриловецьке".
