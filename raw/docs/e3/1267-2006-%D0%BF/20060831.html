Кабінет Міністрів України; Постанова від 31.08.2006 № 1267

Про зупинення дії постанови Кабінету Міністрів України від 26 липня 2006 р. N 1007 та визнання такою, що втратила чинність, постанови Кабінету Міністрів України від 3 серпня 2006 р. N 1082

Стан: Чинний

Ідентифікатор: 1267-2006-п

Текст документа від 31.08.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 серпня 2006 р. N 1267 Київ

Про зупинення дії постанови Кабінету Міністрів України від 26 липня 2006 р. N 1007 та визнання такою, що

втратила чинність, постанови Кабінету Міністрів України від 3 серпня 2006 р. N 1082

Кабінет Міністрів України постановляє:

1. Зупинити дію постанови Кабінету Міністрів України від 26 липня 2006 р. N 1007 ( 1007-2006-п ) "Про будівництво залізничної лінії Ізмаїл - Рені".

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 3 серпня 2006 р. N 1082 ( 1082-2006-п ) "Про внесення змін до постанови Кабінету Міністрів України від 26 липня 2006 р. N 1007".

Перший віце-прем'єр-міністр України М.АЗАРОВ
