( Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 699 ( z1050-05 ) від 25.08.2005 )

Про формування роздрібного тарифу на спожиту електричну енергію

( Із змінами, внесеними згідно з Постановою Нацкомелектроенергетики N 140 ( z0078-97 ) від 04.03.97 )

Згідно з Указом Президента України від 14 березня 1995 року N 213/95, на виконання Закону України від 18.12.96 р. "Про ратифікацію Кредитної угоди (Проект розвитку ринку електроенергетики) між Україною і Міжнародним банком реконструкції та розвитку" ( 612/96-ВР ), постанови Кабінету Міністрів України від 19.02.96 р. N 207 ( 207-96-п ) "Про забезпечення роботи оптового ринку електричної енергії України", згідно з Договором між членами Оптового ринку електричної енергії України, Умовами та Правилами здійснення підприємницької діяльності з постачання електричної енергії за регульованим тарифом ( z0433-96 ) і Умовами та Правилами здійснення підприємницької діяльності з передачі електричної енергії місцевими (локальними) електричними мережами ( z0408-96 ), Національна комісія з питань регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Встановити, що з 1 лютого 1997 р. роздрібний тариф на електричну енергію для споживачів (за винятком населення, населених пунктів та сільськогосподарських споживачів-виробників) розраховується енергопостачальними компаніями, які отримали ліцензії на право здійснення підприємницької діяльності з постачання електричної енергії за регульованим тарифом, згідно з формулою, наведеною в Умовах та Правилах здійснення підприємницької діяльності з постачання електричної енергії за регульованим тарифом ( z0433-96 ).

2. На період до 30 червня 1997 року тарифи на електричну енергію, що відпускається на комунально-побутові потреби населенню та населеним пунктам, визначаються відповідно до постанови НКРЕ від 29.08.96 р. N 62 ( z0513-96 ).

3. ( Пункт 3 втратив чинність на підставі Постанови Нацкомелектроенергетики N 140 ( z0078-97 ) від 04.03.97 ) На період до 1 квітня 1997 року тарифи на електричну енергію для сільськогосподарських споживачів-виробників визначаються відповідно до наказу Міністерства економіки України від 20.04.95 р. N 62 ( z0121-95 ).

4. До 20 березня 1997 р. енергопостачальним компаніям, які отримали ліцензію на право здійснення підприємницької діяльності з постачання електричної енергії за регульованим тарифом надати НКРЕ розрахунок обсягу необхідних дотацій за спожиту у лютому електричну енергію:

- для населення, що споживає електричну енергію на комунально-побутові потреби і має право на пільги щодо оплати за електричну енергію згідно з чинним законодавством України;

- для сільськогосподарських споживачів-виробників, - для покриття витрат енергопостачальних компаній, які виникають внаслідок різниці між діючим тарифом та тарифом, розрахованим згідно з п. 1 цієї постанови;

- для населення, що споживає електричну енергію на комунально-побутові потреби та населених пунктів - для покриття витрат енергопостачальних компаній, які виникають внаслідок різниці між діючим тарифом та тарифом, розрахованим згідно з п.1 цієї постанови.

5. Зобов'язати НДЦ України при розрахунку оптової ринкової ціни враховувати обсяги дотацій згідно з дотаційними сертифікатами, які НКРЕ надає енергопостачальним компаніям.
