Про затвердження форм заявок-розрахунків на виготовлення та придбання марок акцизного податку, звіту про використання марок акцизного податку та журналів для обліку марок акцизного податку

Відповідно до статті 226 розділу VI Податкового кодексу України ( 2755-17 ) НАКАЗУЮ:

1. Затвердити такі форми:

1.1. Попередня заявка-розрахунок про потребу в марках акцизного податку (додається).

1.2. Заявка-розрахунок на придбання марок акцизного податку для маркування алкогольних напоїв (додається).

1.3. Заявка-розрахунок на придбання марок акцизного податку для маркування тютюнових виробів (додається).

1.4. Звіт про використання марок акцизного податку (додається).

1.5. Журнал реєстрації імпортера (замовника) алкогольних напоїв, тютюнових виробів (додається).

1.6. Журнал обліку видачі марок акцизного податку для маркування алкогольних напоїв вітчизняного виробництва (додається).

1.7. Журнал обліку видачі марок акцизного податку для маркування алкогольних напоїв імпортного виробництва (додається).

1.8. Журнал обліку видачі марок акцизного податку для маркування тютюнових виробів вітчизняного виробництва (додається).

1.9. Журнал обліку видачі марок акцизного податку для маркування тютюнових виробів імпортного виробництва (додається).

1.10. Реєстр повернутих марок акцизного податку (додається).

2. Головам Державних податкових адміністрацій в Автономній Республіці Крим, областях, містах Києві та Севастополі і начальникам регіональних управлінь Департаменту контролю за виробництвом та обігом спирту, алкогольних напоїв і тютюнових виробів Державних податкових адміністрацій в Автономній Республіці Крим, областях, містах Києві та Севастополі забезпечити доведення до відома суб'єктів господарювання форм попередньої заявки-розрахунку про потребу в марках акцизного податку, заявок-розрахунків на придбання марок акцизного податку для маркування алкогольних напоїв, заявок-розрахунків на придбання марок акцизного податку для маркування тютюнових виробів, звіту про використання марок акцизного податку, придбаних у попередньому місяці, та журналів для обліку марок акцизного податку.

3. Визнати таким, що втратив чинність, наказ Державної податкової адміністрації України від 22.04.2008 N 273 ( z0375-08 ) "Про затвердження форм заявок-розрахунків на виготовлення та придбання марок акцизного збору, звіту про використання марок акцизного збору та журналів для обліку марок акцизного збору", зареєстрований у Міністерстві юстиції України 25.04.2008 за N 375/15066 (із змінами).

4. Департаменту контролю за виробництвом та обігом спирту, алкогольних напоїв і тютюнових виробів подати цей наказ до Міністерства юстиції України для державної реєстрації.

5. Департаменту масово-роз'яснювальної роботи та звернень громадян після державної реєстрації цього наказу довести його через засоби масової інформації до відома платників податків.

6. Цей наказ набирає чинності з дня його офіційного опублікування.
