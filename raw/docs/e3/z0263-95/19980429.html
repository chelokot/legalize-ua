( Із змінами, внесеними згідно з Наказом МЗЕЗторгу N 207 ( z0279-98 ) від 14.04.98 )

2. Затвердити склад комісії з питань добору керівних працівників та фахівців для роботи в торговельно-економічних місіях у складі дипломатичних представництв України за кордоном (додається). ( Пункт 2 в редакції Наказу МЗЕЗторгу N 207 ( z0279-98 ) від 14.04.98 )

3. Управлінню кадрів (Кузьменко Л.І.), Головному довірено-правовому управлінню (Нестр Л.Д.) зареєструвати цей наказ у Міністерстві юстиції України.

4. Наказ від 12.11.93 N 199 "Про порядок добору і стажування фахівців для роботи в торговельних представництвах України за кордоном" скасувати.

Міністр С.Г.Осика

Затверджено наказом Міністерства зовнішніх економічних зв'язків України від 03.07.95 N 127

Положення про порядок добору, призначення та деякі інші питання трудових відносин керівних працівників і фахівців торговельно-економічних місій у складі дипломатичних представництв України за кордоном

1. На роботу до торговельно-економічних місій у складі дипломатичних представництв України за кордоном приймаються на конкурсній основі громадян України з урахуванням таких вимог.

1.1. Вища освіта за фахом економіста, юриста, бухгалтера, товарознавця, інженера;

1.2. Досвід роботи за фахом на посади керівника та заступника керівника до 5 років, фахівців - не менше 2 років;

1.3. Володіння мовою країни, в яку рекомендується фахівець або однією з офіційних мов ООН;

1.4. Висновок медкомісії;

1.5. Граничний вік становить 55 років для жінок і 60 років для чоловіків;

1.6. Відсутність судимості, що є несумісною із зайняттям посади.

2. Особи, які мають вищу освіту за іншими спеціальностями, можуть бути рекомендовані та прийняті на вказану роботу після проходження відповідної перепідготовки в Українській академії зовнішньої торгівлі.

3. За інших рівноцінних умов конкурсною комісією при рекомендації кандидатур надається пріоритет особам, які працюють, як правило, в апараті Міністерства зовнішніх економічних зв'язків і торгівлі України та обласних, Київського, Севастопольського міських управліннях зовнішніх економічних зв'язків. ( Пункт 3 із змінами, внесеними згідно з Наказом МЗЕЗторгу N 207 ( z0279-98 ) від 14.04.98 )

4. Створена в МЗЕЗ України спеціальна комісія по добору керівних працівників та фахівців для роботи в торговельно-економічних місіях у складі дипломатичних представництв України за кордоном розглядає всі подані документи на заміщення посад у торговельно-економічних місіях.

5. Керівник торговельно-економічної місії та його заступник (заступники) є членами дипломатичного персоналу, інші співробітники торговельно-економічної місії - членами адміністративно-технічного або обслуговуючого персоналу дипломатичного представництва.

6. Керівник торговельно-економічної місії та його заступник (заступники) призначається та звільняється з посади наказом Міністра зовнішніх економічних зв'язків і торгівлі України за погодженням із Міністерством закордонних справ України; інші співробітники торговельно-економічної місії - наказом Міністра зовнішніх економічних зв'язків і торгівлі України без такого погодження. ( Пункт 6 в редакції Наказу МЗЕЗторгу N 207 ( z0279-98 ) від 14.04.98 )

( Пункт 7 виключено на підставі Наказу МЗЕЗторгу N 207 ( z0279-98 ) від 14.04.98 ) 7. Керівник тоговельно-економічної місії призначається та звільняється з посади наказом Міністра зовнішніх економічних зв'язків України за погодженням з Міністерством закордонних справ України. Зокрема призначення керівника торговельно-економічної місії здійснюється після погодження також з Комісією Верховної Ради України у закордонних справах і зв'язках з СНД.

( Пункт 8 виключено на підставі Наказу МЗЕЗторгу N 207 ( z0279-98 ) від 14.04.98 ) 8. Заступника керівника торговельно-економічної місії призначає та звільняє з посади Міністр зовнішніх економічних зв'язків України за погодженням з Міністерством закордонних справ України, інших співробітників торговельно-економічної місії - Міністр зовнішніх економічних зв'язків України без такого погодження.

7. Керівник торговельно-економічної місії у складі дипломатичного представництва України за кордоном за посадою є радником - посланником або радником дипломатичного представництва.

8. При прийнятті на посади керівників, заступників керівників та посади адміністративно-технічного персоналу працівникам торговельно-економічних місій може встановлюватися випробування терміном до шести місяців. Особи, які не витримали випробування, звільняються з роботи згідно з чинним законодавством.

9. Переведення працівника торговельно-економічної місії на вищу посаду здійснюється з урахуванням рівня його професійної підготовки і ефективності роботи та відгуку про його роботу керівника торговельно-економічної місії. ( Пункт 9 в редакції Наказу МЗЕЗторгу N 207 ( z0279-98 ) від 14.04.98 )

10. Тривалість роботи керівників та заступників керівників торговельно-економічних місій у складі дипломатичних представництв України за кордоном складає, як правило, 3 роки, інших фахівців - 2 роки. Термін роботи за кордоном відраховується з дати призначення фахівця на посаду наказом Міністра зовнішніх економічних зв'язків і торгівлі України. ( Пункт 10 в редакції Наказу МЗЕЗторгу N 207 ( z0279-98 ) від 14.04.98 )

11. Працівники торговельно-економічних місій несуть дисциплінарну відповідальність згідно з чинним законодавством України.

Керівники торговельно-економічних місій та їх заступники, які є членами дипломатичного персоналу, можуть бути достроково відкликані в Україну у випадках невиконання або неналежного виконання службових обов'язків, вчинення проступків, які їх порочать, а також вчинення членами їх сімей дій, що можуть призвести до негативних наслідків при подальшому виконанні ними службових обов'язків.

12. Керівники підприємств, установ та організацій після повернення працівника торговельно-економічної місії в Україну надають йому, за умови наявності вакантної посади, попередню роботу (посаду) або іншу рівноцінну роботу (посаду), за згодою працівника, у тому самому підприємстві, установі, організації.

13. Час роботи за кордоном не пририває трудового стажу, що дає право на одержання надбавки за вислугу років або надбавок за стаж роботи за фахом, якщо до направлення за кордон працівник займав посаду або виконував роботу, яка дає право на отримання винагороди або надбавок.
