Про приведення системи управління внутрішніми військами у відповідність із Конституцією України

Стан: Чинний

Ідентифікатор: 474/2007

Текст документа від 28.05.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 480/2008 ( 480/2008 ) від 26.05.2008 }

Про приведення системи управління внутрішніми військами у відповідність із Конституцією України

{ Додатково див. Постанову ВР N 1092-V ( 1092-16 ) від 25.05.2007, ВВР, 2007, N 34, ст.452 }

З метою забезпечення запобігання і нейтралізації реальних та потенційних загроз національним інтересам, недопущення використання внутрішніх військ Міністерства внутрішніх справ України (далі - внутрішні війська) в інтересах певних політичних сил, що створює загрозу національній безпеці України, приведення системи керівництва внутрішніми військами як військовим формуванням у відповідність із Конституцією України ( 254к/96-ВР ),

на виконання частини другої статті 102, пунктів 1 і 17 частини першої, частини третьої статті 106, пункту 1 розділу XV "Перехідні положення" Конституції України ( 254к/96-ВР ) постановляю:

1. Вивести внутрішні війська з підпорядкування Міністра внутрішніх справ України.

2. Визначити, що внутрішні війська є підпорядкованими Президентові України.

3. Командувачу внутрішніх військ О. Кіхтенку невідкладно довести цей Указ до відома командування та особового складу внутрішніх військ.

4. Покласти персональну відповідальність за неухильне виконання цього Указу на командувача внутрішніх військ.

5. Контроль за виконанням цього Указу здійснює Секретар Ради національної безпеки і оборони України.

6. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
