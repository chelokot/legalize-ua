Кабінет Міністрів України; Розпорядження, Бланк від 24.06.2009 № 720-р

Питання виготовлення ювілейної медалі "65 лет Победы в Великой Отечественной войне 1941-1945 гг."

Стан: Чинний

Ідентифікатор: 720-2009-р

Текст документа від 07.04.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 червня 2009 р. N 720-р Київ

Питання виготовлення ювілейної медалі "65 лет Победы в Великой Отечественной войне 1941-1945 гг."

{ Із змінами, внесеними згідно з Розпорядженням КМ N 817-р ( 817-2010-р ) від 07.04.2010 }

{ В тексті Розпорядження слово "посвідчень" замінено словами "посвідчень і футлярів", а слово "Держкомветеранів" - словами "Державному комітету у справах ветеранів" згідно з Розпорядженням КМ N 817-р ( 817-2010-р ) від 07.04.2010 }

На виконання Указу Президента України від 26 березня 2009 р. N 190 ( 190/2009 ) "Про нагородження ювілейною медаллю "65 лет Победы в Великой Отечественной войне 1941-1945 гг.":

{ Пункт 1 виключено на підставі Розпорядження КМ N 817-р ( 817-2010-р ) від 07.04.2010 }

2. Міністерству фінансів під час доопрацювання проекту Закону України "Про Державний бюджет України на 2010 рік" передбачити для Державного управління справами видатки на виготовлення ювілейних медалей "65 лет Победы в Великой Отечественной войне 1941-1945 гг." та бланків посвідчень і футлярів до них.

{ Пункт 2 в редакції Розпорядження КМ N 817-р ( 817-2010-р ) від 07.04.2010 }

3. Державному комітету у справах ветеранів, Міністерству фінансів і Державному управлінню справами забезпечити виготовлення ювілейних медалей та бланків посвідчень і футлярів до них.

Державному управлінню справами укласти договір з Банкнотно-монетним двором Національного банку на виготовлення ювілейних медалей "65 лет Победы в Великой Отечественной войне 1941-1945 гг." в кількості 1826020 комплектів, у якому передбачити здійснення оплати після виділення бюджетних коштів для зазначених цілей. { Пункт 3 доповнено абзацом згідно з Розпорядженням КМ N 817-р ( 817-2010-р ) від 07.04.2010 }

{ Пункт 3 із змінами, внесеними згідно з Розпорядженням КМ N 817-р ( 817-2010-р ) від 07.04.2010 }

4. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським держадміністраціям підготувати списки осіб, що підлягають нагородженню ювілейною медаллю, та подати Державному комітету у справах ветеранів відповідну заявку.

Державному комітету у справах ветеранів і Державному управлінню справами забезпечити Раду міністрів Автономної Республіки Крим, обласні, Київську та Севастопольську міські держадміністрації комплектами ювілейних медалей та бланками посвідчень і футлярів до них згідно із заявкою.

5. Взяти до відома, що виготовлення ювілейних медалей та бланків посвідчень і футлярів до них здійснюється на Банкнотно-монетному дворі Національного банку згідно з описом ювілейної медалі, затвердженим Рішенням Ради глав держав Співдружності Незалежних Держав про єдину ювілейну медаль "65 лет Победы в Великой Отечественной войне 1941-1945 гг." від 10 жовтня 2008 р. (м. Бішкек).

6. Визначити постачальниками матеріалів і комплектувальних виробів для виготовлення ювілейних медалей Львівське державне спеціальне конструкторське бюро "Топаз", м. Львів (дисків), ВАТ "Меридіан" імені С.П. Корольова", м. Київ (колодок у складеному вигляді та футлярів), ВАТ "Львівська фабрика паперово-білових виробів "Бібльос", м. Львів (футлярів).

{ Пункт 6 в редакції Розпорядження КМ N 817-р ( 817-2010-р ) від 07.04.2010 }
