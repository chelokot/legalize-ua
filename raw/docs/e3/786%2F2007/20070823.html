Про внесення зміни до Указу Президента України від 21 березня 2002 року N 277

Текст документа від 23.08.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення зміни до Указу Президента України від 21 березня 2002 року N 277

Внести до додатка N 4 до Указу Президента України від 21 березня 2002 року N 277 ( 277/2002 ) "Про переліки посад військовослужбовців і працівників правоохоронних органів, що підлягають заміщенню особами вищого офіцерського (начальницького) складу, та граничних військових і спеціальних звань за цими посадами" (зі змінами, внесеними Указами від 27 червня 2003 року N 562 ( 562/2003 ) та від 17 липня 2006 року N 616 ( 616/2006 ) зміну, доповнивши його після позиції "Заступник начальника Управління - начальник відділу охорони Президента України" позицією такого змісту:

"Заступник начальника Управління - генерал-майор". начальник відділу охорони Прем'єр-міністра України

Президент України В.ЮЩЕНКО

м. Київ, 23 серпня 2007 року N 786/2007
