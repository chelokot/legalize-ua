МІНІСТЕРСТВО З ПИТАНЬ ЖИТЛОВО-КОМУНАЛЬНОГО ГОСПОДАРСТВА УКРАЇНИ

НАКАЗ

24.02.2009 N 43

Зареєстровано в Міністерстві юстиції України 16 березня 2009 р. за N 236/16252

Про внесення змін до Положення про Українську державну квітково-декоративну насіннєву інспекцію

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства будівництва, архітектури та житлово- комунального господарства N 344 ( z1254-06 ) від 18.10.2006, до якого вносились зміни }

Відповідно до Закону України "Про насіння і садивний матеріал" ( 411-15 ), постанови Кабінету Міністрів України від 12.05.2007 N 717 ( 717-2007-п ) "Про затвердження Положення про Міністерство з питань житлово-комунального господарства України" та розпорядження Кабінету Міністрів України від 12.05.2007 N 273-р ( 273-2007-р ) "Про віднесення до сфери управління Міністерства з питань житлово-комунального господарства підприємств, установ та організацій" НАКАЗУЮ:

1. Унести до Положення про Українську державну квітково-декоративну насіннєву інспекцію, затвердженого наказом Міністерства будівництва, архітектури та житлово-комунального господарства України від 18.10.2006 N 344 ( z1254-06 ), зареєстрованого в Міністерстві юстиції України 01.12.2006 за N 1254/13128, такі зміни:

1.1. У пункті 11 слова та знаки "та інших джерел фінансування, не заборонених законодавством" виключити.

1.2. Доповнити Положення ( z1254-06 ) новим пунктом 13 такого змісту:

"13. Укрдержквітнасінінспекція припиняє свою діяльність у порядку, передбаченому чинним законодавством".

2. Начальникові Української державної квітково-декоративної насіннєвої інспекції Ю.І.Косенку забезпечити державну реєстрацію цього наказу відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади".

3. Контроль за виконанням цього наказу покласти на заступника Міністра Р.М.Крамаренка.

Міністр О.Ю.Кучеренко
