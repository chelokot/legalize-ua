{ Із змінами, внесеними згідно з Наказом Адміністрації Державної служби спеціального зв'язку та захисту інформації N 246 ( z0583-14 ) від 22.05.2014 }

На виконання постанови Кабінету Міністрів України від 19.08.2002 N 1194 ( 1194-2002-п ) "Про польові виплати військовослужбовцям і працівникам військових частин Збройних Сил, інших військових формувань та особовому складу Державної служби спеціального зв'язку та захисту інформації, Державної спеціальної служби транспорту" НАКАЗУЮ:

1. Затвердити Інструкцію про порядок виплати польового забезпечення особовому складу Державної служби спеціального зв'язку та захисту інформації України (додається).

2. Контроль за виконанням цього наказу покласти на начальника Департаменту кадрового забезпечення та начальника Фінансово-економічного департаменту Адміністрації Держспецзв'язку.

ЗАТВЕРДЖЕНО Наказ Адміністрації Державної служби спеціального зв'язку та захисту інформації України 14.04.2008 N 57

Зареєстровано в Міністерстві юстиції України 12 травня 2008 р. за N 392/15083

ІНСТРУКЦІЯ про порядок виплати польового забезпечення особовому складу Державної служби спеціального зв'язку та захисту інформації України

1. Особам рядового і начальницького складу, державним службовцям та іншим працівникам Державної служби спеціального зв'язку та захисту інформації України (далі - співробітники Держспецзв'язку), які виконують службові обов'язки на території України, за час перебування за межами постійного розташування Адміністрації, регіональних органів, територіальних підрозділів, навчальних, медичних, санаторно-курортних та інших закладів, науково-дослідних та науково-виробничих установ Держспецзв'язку (далі - органи, підрозділи Держспецзв'язку) для відпрацювання завдань з бойової (навчально-бойової) підготовки виплачується польове забезпечення (далі - польові) у розмірі 100 відсотків добових, що виплачуються при службових відрядженнях у межах України.

2. Польові, у тому числі за час перебування в дорозі, виплачуються співробітникам Держспецзв'язку:

Адміністрації Держспецзв'язку, які залучаються до участі в комплексно-польових і командно-штабних навчаннях, що проводяться за планами Адміністрації Держспецзв'язку;

призначеним для виконання завдань щодо підтримання бойової готовності (перевірка підрозділів постійної готовності, перевірка пунктів прив'язки тощо);

виведеним для відпрацювання завдань з бойової (навчально-бойової) підготовки відповідно до плану службової діяльності органу, підрозділу Держспецзв'язку на навчальний рік;

навчальних закладів, виведених в навчальний центр (на полігон) для відпрацювання завдань відповідно до програми навчання курсантів (слухачів).

3. Польові, у тому числі за час перебування в дорозі, також виплачуються співробітникам Держспецзв'язку, направленим:

для здійснення контролю заходів, зазначених у пункті 2 цієї Інструкції;

у складі команд на рекогносцировку місць розгортання засобів зв'язку;

у складі команд для виконання будівельних і ремонтних робіт на об'єктах зв'язку;

для обслуговування тимчасово законсервованих об'єктів зв'язку;

у складі підрозділу на ліквідацію стихійного лиха;

для виконання робіт та службових завдань, крім випадків, коли співробітники Держспецзв'язку згідно з чинним законодавством мають право на виплату добових.

4. Особам рядового і начальницького складу із числа курсантів, направлених на навчальну практику та стажування, а також особам рядового і начальницького складу за дні, коли вони забезпечуються харчуванням за рахунок держави, польові не виплачуються.

{ Пункт 4 із змінами, внесеними згідно з Наказом Адміністрації Державної служби спеціального зв'язку та захисту інформації N 246 ( z0583-14 ) від 22.05.2014 }

5. Визначення кількості днів для виплати польових проводиться з урахуванням днів вибуття та прибуття до місця постійного розташування органів, підрозділів Держспецзв'язку.

6. Польові виплачуються співробітникам Держспецзв'язку за місцем їх служби за минулий місяць одночасно з виплатою грошового забезпечення (заробітної плати) за поточний місяць на підставі наказу начальника органу, підрозділу Держспецзв'язку про виплату польових, в якому зазначається:

посада, спеціальне звання, прізвище, ім'я та по батькові співробітника Держспецзв'язку, який був направлений для виконання завдань, передбачених цією Інструкцією;

дата та номер наказу про направлення співробітника Держспецзв'язку для виконання завдань;

місце виконання завдань та фактична кількість діб перебування співробітника Держспецзв'язку поза межами постійного розташування органу, підрозділу Держспецзв'язку.

Начальник Фінансово-економічного департаменту Адміністрації О.М.Мніщенко
