Мінтранс України; Наказ, Тариф від 14.02.2000 № 53

Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні

Реєстрація: Мін'юст України від 29.02.2000 № 113/4334

Стан: Втратив чинність

Ідентифікатор: z0113-00

Текст документа від 04.06.2007:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

N 53 від 14.02.2000 Зареєстровано в Міністерстві м.Київ юстиції України 29 лютого 2000 р. vd20000214 vn53 за N 113/4334

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 405 ( z0537-07 ) від 15.05.2007 }

Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні

{ Із змінами, внесеними згідно з Наказом Мінтрансу N 103 ( z0191-01 ) від 19.02.2001 }

Згідно з постановою Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та з метою більш повного відшкодування витрат, пов'язаних із забезпеченням якісного обслуговування пасажирів у поїздах, НАКАЗУЮ:

1. Затвердити Тарифи на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні, що додаються.

2. Укрзалізниці (Макаренко М.В.) та начальникам залізниць України забезпечити своєчасне введення у дію цих Тарифів та правильність їх застосування і проінформувати про це населення (на вокзалах та пунктах продажу квитків).

3. Із введенням у дію цього наказу втрачають чинність Тарифи на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні, затверджені наказом Міністерства транспорту від 28 вересня 1998 р. N 386 ( z0639-98 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні" і зареєстровані Міністерством юстиції 9 жовтня 1998 р. за N 639/3079.

4.Контроль за виконанням цього наказу покласти на першого заступника Міністра транспорту України - Генерального директора Укрзалізниці А.В.Слободяна.

Міністр Л.М.Костюченко

( Тарифи на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні втратили чинність на підставі Наказу Мінтрансу N 103 ( z0191-01 ) від 19.02.2001 )
