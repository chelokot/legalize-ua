КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 липня 2006 р. N 412-р Київ

Про підписання Угоди між Кабінетом Міністрів України та Урядом Соціалістичної Республіки В'єтнам про реадмісію громадян обох держав

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 24-р ( 24-2007-р ) від 31.01.2007 N 789-р ( 789-2007-р ) від 26.09.2007 }

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Соціалістичної Республіки В'єтнам про реадмісію громадян обох держав.

Міністру закордонних справ Яценюку Арсенію Петровичу підписати зазначену Угоду, дозволивши вносити у разі потреби до її проекту зміни, що не мають принципового характеру. { Абзац другий із змінами, внесеними згідно з Розпорядженнями КМ N 24-р ( 24-2007-р ) від 31.01.2007, N 789-р ( 789-2007-р ) від 26.09.2007 }
