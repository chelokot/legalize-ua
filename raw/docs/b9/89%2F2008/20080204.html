Президент України; Указ від 04.02.2008 № 89/2008

Про невідкладні заходи щодо розв'язання проблеми забезпечення житлом інвесторів, які зазнали збитків внаслідок діяльності групи будівельних компаній "Еліта-центр"

Стан: Чинний

Ідентифікатор: 89/2008

Текст документа від 04.02.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про невідкладні заходи щодо розв'язання проблеми забезпечення житлом інвесторів, які зазнали збитків внаслідок діяльності групи будівельних компаній "Еліта-центр"

Указом Президента України від 3 березня 2006 року N 185 ( 185/2006 ) "Про заходи щодо вдосконалення державного регулювання у сфері будівництва житла та стабілізації ситуації на первинному ринку житла" з метою гарантування захисту прав громадян, постраждалих внаслідок діяльності групи будівельних компаній "Еліта-центр", було передбачено низку заходів щодо розв'язання проблеми забезпечення житлом зазначених громадян. Виконання цих заходів було покладено на Київську міську державну адміністрацію.

Однак до цього часу Київською міською державною адміністрацією не вжито достатніх адекватних заходів, спрямованих на забезпечення реалізації прав постраждалих громадян на житло.

Ураховуючи наведене, керуючись статтею 47, частиною другою статті 102, частиною п'ятою статті 118 Конституції України ( 254к/96-ВР ), постановляю:

1. Визнати незадовільною роботу Київської міської державної адміністрації з виконання статті 2 Указу Президента України від 3 березня 2006 року N 185 ( 185/2006 ) "Про заходи щодо вдосконалення державного регулювання у сфері будівництва житла та стабілізації ситуації на первинному ринку житла" щодо вжиття заходів, спрямованих на розв'язання проблеми забезпечення житлом інвесторів, які зазнали збитків внаслідок діяльності групи будівельних компаній "Еліта-центр".

2. За значні недоліки в роботі із забезпечення виконання статті 2 Указу Президента України від 3 березня 2006 року N 185 ( 185/2006 ) "Про заходи щодо вдосконалення державного регулювання у сфері будівництва житла та стабілізації ситуації на первинному ринку житла" та послаблення виконавської дисципліни оголосити догану ЧЕРНОВЕЦЬКОМУ Леоніду Михайловичу - голові Київської міської державної адміністрації.

3. Кабінету Міністрів України:

1) створити у триденний строк комісію для вирішення питань забезпечення житлом громадян, постраждалих внаслідок діяльності групи будівельних компаній "Еліта-центр", включивши до складу цієї комісії представників постраждалих громадян;

2) забезпечити:

визначення переліку інвесторів, постраждалих внаслідок діяльності групи будівельних компаній "Еліта-центр";

вирішення в установленому порядку питання виділення земельних ділянок для будівництва житла з метою виконання інвестиційних зобов'язань перед інвесторами, які зазнали збитків внаслідок діяльності групи будівельних компаній "Еліта-центр";

3) доповісти про хід виконання цього Указу до 14 лютого 2008 року, в подальшому доповідати кожні два тижні.

4. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 4 лютого 2008 року N 89/2008
