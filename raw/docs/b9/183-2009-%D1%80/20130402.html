Кабінет Міністрів України; Розпорядження, Склад колегіального органу від 18.02.2009 № 183-р

Про утворення міжвідомчих робочих груп з підготовки пропозицій щодо активізації українсько-японського співробітництва

Стан: Втратив чинність

Ідентифікатор: 183-2009-р

Текст документа від 02.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 лютого 2009 р. N 183-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про утворення міжвідомчих робочих груп з підготовки пропозицій щодо активізації українсько-японського співробітництва

{ Із змінами, внесеними згідно з Розпорядженням КМ N 226-р ( 226-2009-р ) від 05.03.2009 }

1. Утворити міжвідомчі робочі групи з підготовки пропозицій щодо активізації українсько-японського співробітництва, зокрема в частині застосування механізмів Кіотського протоколу до Рамкової конвенції ООН про зміну клімату ( 995_801 ), у складі згідно з додатками 1-10.

Надати головам міжвідомчих робочих груп право вносити зміни до їх складу.

2. Міжвідомчим робочим групам забезпечити підготовку та подання у двотижневий строк пропозицій, спрямованих на реалізацію спільних українсько-японських проектів енергозбереження, модернізації виробництва в паливно-енергетичному, промисловому, житлово-комунальному та агропромисловому секторах економіки, зменшення негативного впливу на навколишнє природне середовище, зумовленого виробничою діяльністю суб'єктів господарювання, зокрема тих, що реалізуються із застосуванням механізмів Кіотського протоколу ( 995_801 ).

3. Затвердити керівника групи радників Прем'єр-міністра України Гайдука В.А. координатором міжурядового українсько-японського співробітництва, а його заступником директора Інституту проблем екології та енергозбереження Єрмілова С.Ф.

Гайдуку В.А. забезпечити координацію діяльності міжвідомчих робочих груп відповідно до покладених на них завдань.

{ Пункт 3 в редакції Розпорядження КМ N 226-р ( 226-2009-р ) від 05.03.2009 }
