КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 червня 2008 р. N 889-р Київ

Про передачу державного майна в управління Мінтрансзв'язку

{ Із змінами, внесеними згідно з Розпорядженням КМ N 124-р ( 124-2009-р ) від 28.01.2009 }

1. Прийняти пропозицію Міноборони і Мінтрансзв'язку щодо передачі майна військового містечка N 58, розташованого у смт Скнилів Львівської області, згідно з додатком від Міноборони в управління Мінтрансзв'язку.

{ Пункт 2 виключено на підставі Розпорядження КМ N 124-р ( 124-2009-р ) від 28.01.2009 }
