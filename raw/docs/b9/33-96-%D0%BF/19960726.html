Кабінет Міністрів України; Постанова від 10.01.1996 № 33

Про підвищення розміру цільової грошової допомоги непрацездатним громадянам з мінімальними доходами

Стан: Втратив чинність

Ідентифікатор: 33-96-п

Текст документа від 26.07.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 січня 1996 р. N 33 Київ

Про підвищення розміру цільової грошової допомоги непрацездатним громадянам з мінімальними доходами

( Із змінами, внесеними згідно з Постановами КМ N 342 ( 342-96-п ) від 19.03.96 N 833 ( 833-96-п ) від 26.07.96 )

Відповідно до Програми діяльності Кабінету Міністрів України, схваленої постановою Верховної Ради України від 11 жовтня 1995 року ( 373/95-ВР ), Кабінет Міністрів України постановляє:

1. ( Пункт 1 втратив чинність на підставі Постанови КМ N 833 ( 833-96-п ) від 26.07.96 )

2. ( Пункт 2 втратив чинність на підставі Постанови КМ N 833 ( 833-96-п ) від 26.07.96 )

3. Відповідно до доручення Президента України від 19 грудня 1995 р. про створення служб адресної соціальної допомоги Міністерству фінансів передбачити в бюджеті на 1996 рік витрати на створення зазначених служб.

4. Міністерству соціального захисту населення разом з Міністерством юстиції, Міністерством економіки та Міністерством фінансів у тижневий термін підготувати пропозиції щодо подвійного підпорядкування служб житлових субсидій Міністерству соціального захисту населення і місцевим державним адміністраціям, виконкомам Рад.

5. Міністерству економіки, Міністерству фінансів, Міністерству соціального захисту населення, Міністерству праці та Пенсійному фонду внести Кабінетові Міністрів України пропозиції щодо наближення розміру мінімальної пенсії з урахуванням надбавок, підвищень, щомісячних компенсаційних виплат та додаткової пенсії до межі малозабезпеченості.

6. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 16 жовтня 1995 р. N 825 ( 825-95-п ) "Про підвищення розміру цільової грошової допомоги непрацездатним громадянам з мінімальними доходами" (ЗП України, 1996 р., N 2, ст.67).
