Про затвердження складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття

Стан: Втратив чинність

Ідентифікатор: 59-2007-р

Текст документа від 28.11.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 лютого 2007 р. N 59-р Київ

{ Дію Розпорядження зупинено на період до проведення першого засідання нового складу правління Фонду згідно з Розпорядженням КМ N 347-р ( 347-2007-р ) від 26.05.2007 }

Про затвердження складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 347-р ( 347-2007-р ) від 26.05.2007 N 1054-р ( 1054-2007-р ) від 28.11.2007 }

1. Відповідно до статей 10 і 13 Закону України "Про загальнообов'язкове державне соціальне страхування на випадок безробіття" ( 1533-14 ) затвердити склад осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття, згідно з додатком.

2. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України згідно з переліком, що додається.

2. Розпорядження Кабінету Міністрів України від 21 грудня 2005 р. N 549 ( 549-2005-р ) "Про зміну складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття" (Офіційний вісник України, 2005 р., N 52, ст. 3346).

3. Розпорядження Кабінету Міністрів України від 27 квітня 2006 р. N 248 ( 248-2006-р ) "Про зміну складу осіб, уповноважених представляти інтереси держави у правлінні Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття" (Офіційний вісник України, 2006 р., N 18, ст. 1354).

4. Пункт 1 розпорядження Кабінету Міністрів України від 15 вересня 2006 р. N 488 ( 488-2006-р ) "Про зміни складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів загальнообов'язкового державного соціального страхування" (Офіційний вісник України, 2006 р., N 38, ст. 2597).
