{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 191 ( z0641-06 ) від 22.05.2006 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 10.05.2000 N 100

На виконання постанови Кабінету Міністрів України від 06.08.2003 N 1207 ( 1207-2003-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 10.05.2000 N 100 ( z0463-00 ) "Про умови оплати праці членів виборчої комісії Автономної Республіки Крим та працівників її апарату", зареєстрованого в Міністерстві юстиції України 31.07.2000 за N 463/4684, виклавши додаток у новій редакції (додається).

2. Ці умови набирають чинності з 1 вересня 2003 року.

Міністр М.Папієв

Додаток до наказу Міністерства праці та соціальної політики України 10.05.2000 N 100 ( z0463-00 ) (у редакції наказу Міністерства праці та соціальної політики України від 02.09.2003 N 246)
