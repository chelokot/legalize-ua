Президент України; Розпорядження від 23.02.1999 № 38/99-рп

Про зміни у складі Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар

Стан: Втратив чинність

Ідентифікатор: 38/99-рп

Текст документа від 13.11.2001:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про зміни у складі Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар

На зміну пункту 2 Розпорядження Президента України від 27 березня 1998 року N 67 ( 67/98-рп ) та пункту 1 Розпорядження Президента України від 15 квітня 1998 року N 86 ( 86/98-рп ) (із змінами, внесеними Розпорядженням від 22 вересня 1998 року N 501 ( 501/98-рп ):

1. Призначити МАТВІЄНКА Валерія Яковича - заступника Глави Адміністрації Президента України - Керівника Головного управління з аналізу та прогнозування внутрішньополітичних питань керівником Робочої групи з підготовки пропозицій щодо вирішення питань, пов'язаних з поверненням депортованих кримських татар.

2. Увести до складу зазначеної Робочої групи таких осіб:

ГОЛУБЧЕНКО - перший заступник Голови Фонду

Анатолій Костянтинович Державного майна України

ДРИГУС - завідувач відділу духовного розвитку Ігор Петрович Управління гуманітарної політики Адміністрації Президента України

РОМАНЮК - заступник Міністра економіки України Сергій Андрійович

ХАВАДЖИ - заступник Постійного Представника

Ремзі Фемійович Президента України в Автономній Республіці Крим.

3. Вивести зі складу Робочої групи Горенка О.М., Крюкова В.І., Кушнарьова Є.П., Мініна Л.В.

Президент України Л.КУЧМА

м. Київ, 23 лютого 1999 року N 38/99-рп
