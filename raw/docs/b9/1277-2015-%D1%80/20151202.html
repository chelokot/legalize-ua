КАБІНЕТ МІНІСТРІВ УКРАЇНИ
РОЗПОРЯДЖЕННЯ

від 2 грудня 2015 р. № 1277-р
Київ

Про делегацію Кабінету Міністрів України для участі у засіданні Ради асоціації між Україною та ЄС

1. Утворити делегацію Кабінету Міністрів України для участі у засіданні Ради асоціації між Україною та ЄС у складі згідно з додатком.

2. Затвердити директиви для участі делегації Кабінету Міністрів України у засіданні Ради асоціації між Україною та ЄС (додаються, для службового користування).
