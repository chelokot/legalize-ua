ПОЛОЖЕННЯ про Службу розпорядника Державного реєстру виборців

{ У тексті Положення слово "заступників" замінено словом "заступника" згідно з Постановою Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013 }

I. Загальні положення

1. Служба розпорядника Державного реєстру виборців (далі - Служба) утворюється для забезпечення виконання Центральною виборчою комісією (далі - Комісія) функцій розпорядника Державного реєстру виборців (далі - розпорядник Реєстру) відповідно до Закону України "Про Державний реєстр виборців" ( 698-16 ) (далі - Закон).

Служба є самостійним структурним утворенням (апаратом) Комісії, діяльність якого спрямовується на забезпечення організаційного та технологічного функціонування Державного реєстру виборців (далі - Реєстр). { Абзац другий пункту 1 із змінами, внесеними згідно з Постановами Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013, N 351 ( v0351359-16 ) від 29.07.2016 }

2. Служба у своїй діяльності керується Конституцією України ( 254к/96-ВР ), Законами України "Про Державний реєстр виборців" ( 698-16 ), "Про Центральну виборчу комісію" ( 1932-15 ), "Про державну службу" ( 3723-12 ) та іншими законами України, рішеннями розпорядника Реєстру, Регламентом Комісії ( v0072359-05 ), цим Положенням, постановами Комісії та розпорядженнями Голови Комісії, наказами керівника Служби.

{ Пункт 2 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

3. Положення про Службу, структура, штатний розпис затверджуються Комісією за пропозицією Голови Комісії.

4. Для забезпечення виконання Службою функцій можуть залучатися на умовах цивільно-правової угоди відповідні фахівці, а також особи, відряджені з інших державних органів.

5. У межах затверджених Комісією структури та штатного розпису у складі Служби для здійснення покладених на неї функцій і завдань утворюються управління та інші структурні підрозділи.

{ Пункт 5 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

6. Службу очолює керівник. Керівник Служби має заступника.

Керівник та інші працівники Служби є державними службовцями. Керівник Служби та його заступник призначаються на посаду Головою Комісії на підставі пропозицій Комісії з питань вищого корпусу державної служби згідно із законодавством про державну службу та звільняються з посади Головою Комісії. Керівник Служби здійснює повноваження керівника державної служби (з питань державної служби та організації роботи інших працівників Служби). { Абзац другий пункту 6 в редакції Постанов Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016, N 1937 ( v1937359-19 ) від 25.10.2019 }

Керівник Служби в межах своїх повноважень видає накази та дає доручення. { Пункт 6 доповнено абзацом згідно з Постановою Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

{ Пункт 6 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 25 ( v0025359-09 ) від 23.04.2009 }

7. На працівників Служби поширюється законодавство України про працю та державну службу.

Права та обов’язки працівників Служби визначаються Законом України "Про державну службу" ( 889-19 ), цим Положенням і відповідними посадовими інструкціями. { Абзац другий пункту 7 в редакції Постанови Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

Умови оплати праці, соціально-побутового забезпечення працівників Служби визначаються відповідно до законодавства України. { Абзац третій пункту 7 в редакції Постанови Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

8. Витрати, пов'язані із забезпеченням діяльності Служби, фінансуються за рахунок коштів Державного бюджету України, що виділяються на утримання Комісії.

9. Документальне, фінансове, матеріально-технічне забезпечення діяльності Служби, а також забезпечення реалізації керівником Служби повноважень з питань управління персоналом та державної служби здійснюється Секретаріатом Комісії.

{ Пункт 9 в редакції Постанови Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

II. Основні завдання Служби

10. Основними завданнями Служби є забезпечення виконання Комісією функцій розпорядника Реєстру щодо:

1) забезпечення та здійснення контролю за дотриманням вимог Закону ( 698-16 ) при створенні та веденні Реєстру;

2) забезпечення організаційного та технологічного функціонування Реєстру;

3) підготовки пропозицій стосовно закупівлі товарів, робіт та послуг для функціонування інформаційно-телекомунікаційної системи Реєстру;

{ Пункт 10 доповнено новим підпунктом 3 згідно з Постановою Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013 }

4) забезпечення контролю цілісності бази даних Реєстру, повноти та коректності персональних даних Реєстру та ініціювання проведення органами ведення Реєстру перевірки виявлених некоректних відомостей Реєстру;

{ Підпункт 4 пункту 10 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013 }

5) надання доступу до бази даних Реєстру та встановлення порядку такого доступу;

{ Підпункт 5 пункту 10 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 128 ( v0128359-20 ) від 25.06.2020 }

6) ведення системних класифікаторів, необхідних для функціонування Реєстру.

{ Підпункт 6 пункту 10 в редакції Постанови Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013 }

{ Підпункт 1 пункту 11 виключено на підставі Постанови Центральної виборчої комісії N 128 ( v0128359-20 ) від 25.06.2020 }

2) забезпечує в передбаченому Законом ( 698-16 ) порядку реалізацію заходів щодо первинного формування бази даних Реєстру та первинного уточнення персональних даних Реєстру;

3) забезпечує установлювання та актуалізацію системних класифікаторів, необхідних для функціонування Реєстру;

{ Підпункт пункту 11 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013 }

5) забезпечує надання особам, які мають доступ до бази даних Реєстру, програмних та інших засобів доступу;

{ Підпункт пункту 11 виключено на підставі Постанови Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013 }

7) забезпечує достовірність даних Реєстру, захисту Реєстру від знищення, несанкціонованого доступу, незаконного використання та копіювання в процесі їх зберігання, обробки та передачі каналами зв'язку;

{ Підпункт пункту 11 із змінами, внесеними згідно з Постановами Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013, N 351 ( v0351359-16 ) від 29.07.2016, N 128 ( v0128359-20 ) від 25.06.2020 }

{ Підпункт пункту 11 виключено на підставі Постанови Центральної виборчої комісії N 128 ( v0128359-20 ) від 25.06.2020 }

8) забезпечує складення та надання статистичних відомостей Реєстру відповідно до вимог Закону ( 698-16 ), а також розміщує зазначені відомості на офіційному сайті розпорядника Реєстру у формі відкритих даних згідно із Законом України "Про доступ до публічної інформації" ( 2939-17 );

10) забезпечує розробку та реалізацію заходів щодо навчання та підвищення кваліфікації працівників органів ведення та адміністрування Реєстру;

{ Підпункт пункту 11 виключено на підставі Постанови Центральної виборчої комісії N 128 ( v0128359-20 ) від 25.06.2020 }

11) забезпечує контроль діяльності органів ведення та адміністрування Реєстру;

12) готує пропозиції щодо закупівлі товарів, робіт та послуг для функціонування інформаційно-телекомунікаційної системи Реєстру;

{ Пункт 11 доповнено підпунктом згідно з Постановою Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013 }

13) організовує виконання рішень розпорядника Реєстру та здійснює контроль за їх виконанням.

IV. Повноваження керівника, заступника керівника Служби

{ Назва розділу IV в редакції Постанови Центральної виборчої комісії N 25 ( v0025359-09 ) від 23.04.2009 }

12. Керівник Служби:

1) здійснює безпосереднє керівництво Службою, організовує роботу її працівників;

2) організовує та забезпечує належне та своєчасне виконання покладених на Службу завдань;

3) забезпечує взаємодію Служби з органами ведення Реєстру, регіональними органами адміністрування Реєстру, органами виконавчої влади, органами місцевого самоврядування, їх посадовими і службовими особами, політичними партіями, підприємствами, закладами, установами, організаціями всіх форм власності;

4) організовує виконання рішень розпорядника Реєстру, розпоряджень Голови Комісії;

{ Підпункт 5 пункту 12 виключено на підставі Постанови Центральної виборчої комісії N 128 ( v0128359-20 ) від 25.06.2020 }

5) складає плани роботи Служби та контролює їх виконання;

6) вносить пропозиції щодо організації навчання працівників органів ведення та регіональних органів адміністрування Реєстру;

7) надає Голові Комісії пропозиції щодо залучення в установленому порядку до виконання окремих робіт і завдань, участі у вивченні окремих питань відповідних спеціалістів, у тому числі на договірній основі;

8) виконує інші завдання, визначені розпорядником Реєстру.

{ Пункт 12 в редакції Постанови Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

12-1. Керівник Служби як керівник державної служби (з питань державної служби та організації роботи інших працівників Служби):

1) затверджує положення про структурні підрозділи та посадові інструкції працівників Служби;

2) призначає громадян України, які пройшли конкурсний відбір, на вакантні посади державної служби категорій "Б" і "В", звільняє з таких посад відповідно до Закону України "Про державну службу" ( 889-19 );

3) здійснює інші повноваження згідно із Законом України "Про державну службу" та іншими законами України.

{ Положення доповнено новим пунктом 12-1 згідно з Постановою Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

12-2. Заступник керівника Служби:

1) виконує окремі обов'язки, що випливають із повноважень керівника Служби;

2) у разі відсутності керівника Служби виконує його обов'язки;

{ Підпункт 2 пункту із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013 }

3) забезпечує координацію роботи з окремих напрямків діяльності Служби, включаючи забезпечення кібербезпеки, кіберзахисту та безпеки інформаційних технологій інформаційно-телекомунікаційної системи Реєстру;

{ Підпункт 3 пункту 12-2 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 12 ( v0012359-18 ) від 29.01.2018 }

4) виконує інші завдання, визначені розпорядником Реєстру та керівником Служби.

{ Розділ IV доповнено пунктом згідно з Постановою Центральної виборчої комісії N 25 ( v0025359-09 ) від 23.04.2009 }

V. Повноваження керівників структурних підрозділів Служби

13. Керівники структурних підрозділів Служби:

1) здійснюють керівництво діяльністю відповідних структурних підрозділів Служби, організовують і забезпечують належне та своєчасне виконання завдань, покладених на підрозділи;

2) вживають заходів щодо підвищення кваліфікації та навчання працівників Служби;

{ Підпункт 2 пункту 13 в редакції Постанови Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

3) готують та подають керівнику Служби на затвердження положення про відповідні структурні підрозділи Служби, посадові інструкції їх працівників;

{ Підпункт 3 пункту 13 в редакції Постанови Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

4) подають керівнику Служби пропозиції щодо структури і штатного розпису відповідних структурних підрозділів Служби;

{ Підпункт 4 пункту 13 в редакції Постанови Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

5) складають плани роботи відповідних структурних підрозділів та контролюють їх виконання;

6) розподіляють обов'язки між працівниками відповідних структурних підрозділів;

7) забезпечують додержання працівниками відповідних структурних підрозділів Служби правил внутрішнього службового розпорядку і відповідних посадових інструкцій;

{ Підпункт 7 пункту 13 із змінами, внесеними згідно з Постановами Центральної виборчої комісії N 68 ( v0068359-13 ) від 09.04.2013, N 351 ( v0351359-16 ) від 29.07.2016 }

8) організовують ведення діловодства, здійснення контролю, взаємодію з підрозділами Секретаріату Комісії;

9) візують проекти відповідних документів, підготовлених безпосередньо або працівниками відповідного структурного підрозділу Служби;

10) беруть участь у засіданнях розпорядника Реєстру, нарадах Голови та членів Комісії;

11) виконують інші функції згідно з положеннями про відповідні структурні підрозділи Служби.

{ Підпункт 11 пункту 13 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

VI. Повноваження інших працівників Служби

14. Працівники Служби:

1) забезпечують своєчасне та якісне виконання доручень, завдань відповідно до функціональних обов'язків, несуть за це відповідальність у порядку, передбаченому законодавством України;

2) виконують окремі завдання і доручення керівника відповідного структурного підрозділу Служби, керівника Служби, Голови Комісії;

3) у разі необхідності можуть бути присутні на засіданні розпорядника Реєстру при розгляді питань, у підготовці яких вони брали участь;

4) мають право вносити керівнику Служби, керівнику відповідного структурного підрозділу пропозиції з питань, що стосуються їх роботи;

5) здійснюють інші повноваження, передбачені законами України, іншими нормативно-правовими актами, рішеннями Розпорядника Реєстру, а також відповідними посадовими інструкціями, цим Положенням.

{ Підпункт 5 пункту 14 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }

VII. Відповідальність працівників Служби

15. Працівники Служби несуть відповідальність за:

1) невиконання чи неналежне виконання без поважних причин своїх службових обов'язків;

2) порушення обмежень, пов'язаних з проходженням державної служби, а також скоєння вчинку, що порочить державного службовця та дискредитує Комісію;

3) недотримання правил з охорони праці та пожежної безпеки, а також правил внутрішнього службового розпорядку.

{ Підпункт 3 пункту 15 із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 351 ( v0351359-16 ) від 29.07.2016 }
