Стан: Втратив чинність

Ідентифікатор: 86-96-п

Текст документа від 22.01.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 січня 1996 р. N 86 Київ

( Постанова втратила чинність на підставі Постанови КМ N 34 ( 34-2001-п ) від 22.01.2001 )

Про утворення Міжвідомчої ради з впровадження програми економічних реформ

( Із змінами, внесеними згідно з Постановами КМ N 1001 ( 1001-96-п ) від 22.08.96 N 455 ( 455-97-п ) від 17.05.97 N 652 ( 652-97-п ) від 28.06.97 )

( Із змінами, внесеними згідно з Постановою КМ N 511 ( 511-99-п ) від 31.03.99 )

З метою забезпечення ефективності реалізації програми економічних реформ в Україні, підтриманої міжнародними фінансовими організаціями, та підвищення рівня координації здійснюваних заходів з цих питань Кабінет Міністрів України постановляє:

1. Утворити Міжвідомчу раду з впровадження програми економічних реформ.

Затвердити новий склад Міжвідомчої ради згідно з додатком.

( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 455 ( 455-97-п ) від 17.05.97 )

2. Міжвідомчій раді в місячний термін подати Кабінетові Міністрів України проект Положення про Міжвідомчу раду з впровадження програми економічних реформ.
