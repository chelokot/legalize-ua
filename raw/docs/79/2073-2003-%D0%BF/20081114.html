Про встановлення граничної чисельності працівників Комітету з контролю за наркотиками та внесення зміни у додаток 1 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 грудня 2003 р. N 2073 Київ

Про встановлення граничної чисельності працівників Комітету з контролю за наркотиками та внесення зміни у додаток 1 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314

{ Із змінами, внесеними згідно з Постановою КМ N 954 ( 954-2008-п ) від 22.10.2008 }

Кабінет Міністрів України постановляє:

1. Затвердити граничну чисельність працівників Комітету з контролю за наркотиками в кількості 30 одиниць.

{ Пункт 2 втратив чинність на підставі Постанови КМ N 954 ( 954-2008-п ) від 22.10.2008 }
