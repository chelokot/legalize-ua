ПОСТАНОВА від 16 січня 1996 р. N 85 Київ

Питання Державного комітету по матеріальних резервах

З метою поліпшення організації роботи з матеріальними цінностями державного резерву Кабінет Міністрів України постановляє:

1. Створити у складі Державного комітету по матеріальних резервах Дніпропетровську, Донецьку, Київську, Львівську, Одеську, Харківську міжобласні інспекції для здійснення контролю за збереженням матеріальних цінностей державного і мобілізаційного резерву та збільшити у зв'язку з цим граничну чисельність працівників центрального апарату Комітету на 60 одиниць.

2. Установити посадові оклади начальників зазначених міжобласних інспекцій на рівні посадових окладів начальників управлінь Державного комітету по матеріальних резервах, інших працівників інспекцій - на рівні посадових окладів відповідних спеціалістів Комітету.

Міністерству фінансів профінансувати видатки на утримання додаткової чисельності працівників Державного комітету по матеріальних резервах за рахунок бюджетних коштів, передбачених на утримання органів державної виконавчої влади.

3. Державному комітету по матеріальних резервах ліквідувати в установленому порядку територіальні управління, створені відповідно до постанови Кабінету Міністрів України від 11 червня 1994 р. N 383.

4. Визнати таким, що втратив чинність, пункт 2 постанови Кабінету Міністрів України від 11 червня 1994 р. N 383 ( 383-94-п ).
