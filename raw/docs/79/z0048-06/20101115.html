МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ МІНІСТЕРСТВО ВНУТРІШНІХ СПРАВ УКРАЇНИ

НАКАЗ

10.01.2006 N 1/6

Зареєстровано в Міністерстві юстиції України 20 січня 2006 р. за N 48/11922

Про забезпечення безпеки пасажирських перевезень

{ Із змінами, внесеними згідно з Наказом Міністерства транспорту та зв'язку N 765/504 ( z1008-10 ) від 19.10.2010 }

Відповідно до Порядку здійснення державного контролю на автомобільному транспорті, затвердженого постановою Кабінету Міністрів України від 08.11.2006 N 1567 ( 1567-2006-п ), НАКАЗУЄМО:

{ Преамбула в редакції Наказу Міністерства транспорту та зв'язку N 765/504 ( z1008-10 ) від 19.10.2010 }

1. Головній державній інспекції на автомобільному транспорті Міністерства транспорту та зв'язку України (Майборода Ю.М.), Департаменту державної автомобільної інспекції Міністерства внутрішніх справ України (Лозовий В.М.) ужити заходів щодо заборони:

{ Пункт 1 із змінами, внесеними згідно з Наказом Міністерства транспорту та зв'язку N 765/504 ( z1008-10 ) від 19.10.2010 }

1.1. Здійснення перевезень пасажирів автобусами у нічний час (з 10 години вечора до 6 години ранку), за винятком тих, що здійснюватимуться на маршрутах загального користування в режимі регулярних пасажирських перевезень, а також тих перевезень пасажирів, що виконуватимуться автобусами, обладнаними тахографами;

{ Підпункт 1.1 пункту 1 в редакції Наказу Міністерства транспорту та зв'язку N 765/504 ( z1008-10 ) від 19.10.2010 }

1.2. Використання на маршрутах у гірській місцевості автобусів та вантажопасажирських автомобілів з пробігом більше понад 200 тис. кілометрів з початку їх експлуатації та ступеня зносу протектора автомобільних шин більше 50 відсотків від нормативного, згідно з пунктом 3.2 Порядку і умов організації перевезень пасажирів та багажу автомобільним транспортом, затверджених наказом Мінтрансу від 21.01.98 N 21 ( z0257-98 ) та зареєстрованим в Мін'юсті 22.04.98 за N 257/2697.

2. Головній державній інспекції на автомобільному транспорті Мінтрансзв'язку, керівникам головних управлінь МВС України в Автономній Республіці Крим, місті Києві та Київській області, управлінь МВС України в областях та місті Севастополі:

2.1. У тижневий термін переглянути склад спільних мобільних груп для перевірки дотримання перевізниками та водіями автобусів вимог безпеки дорожнього руху. До їх складу залучити працівників Державної служби боротьби з економічною злочинністю для забезпечення контролю за дотриманням чинного законодавства під час надання послуг з перевезення пасажирів автомобільним транспортом;

2.2. Перевірки здійснювати на автовокзалах, автостанціях, автодорогах, залізничних переїздах, у місцях відстою автобусів, у тому числі на великих оптових ринках, а також у місцях їх зберігання та обслуговування;

2.3. Під час проведення перевірок водіїв автобусів особливу увагу звертати на виконання вимог щодо:

2.3.1. Пунктів 3.1-3.7 Порядку і умов організації перевезень пасажирів та багажу автомобільним транспортом, затверджених наказом Мінтрансу від 21.01.98 N 21 ( z0257-98 ), зареєстрованим в Мін'юсті 22.04.98 за N 257/2697;

2.3.2. Ліцензійних умов провадження господарської діяльності з надання послуг з перевезення пасажирів і вантажів автомобільним транспортом відповідно до видів робіт, визначених Законом України "Про автомобільний транспорт", затверджених наказом Міністерства транспорту та зв'язку України від 02.07.2010 N 427 ( z0562-10 ), зареєстрованих в Міністерстві юстиції України 27.07.2010 за N 562/17857;

{ Підпункт 2.3.2 пункту 2.3 в редакції Наказу Міністерства транспорту та зв'язку N 765/504 ( z1008-10 ) від 19.10.2010 }

2.3.3. Розділів II - V Положення про робочий час і час відпочинку водіїв колісних транспортних засобів, затвердженого наказом Міністерства транспорту та зв'язку України від 07.06. 2010 N 340 ( z0811-10 ), зареєстрованого в Міністерстві юстиції України 14.09. 2010 за N 811/18106;

{ Підпункт 2.3.3 пункту 2.3 в редакції Наказу Міністерства транспорту та зв'язку N 765/504 ( z1008-10 ) від 19.10.2010 }

2.3.4. Проходження водіями передрейсових медичних оглядів;

2.3.5. Відповідності типу і марки автобуса, виду перевезень та кількості пасажирів в автобусі;

2.3.6. Справності основних та аварійних виходів;

2.3.7. Наявності дозволу замовника на перевезення, ліцензійної картки, дорожнього листа, квитково-облікового листа;

2.3.8. Забезпечення водіїв автобусів інформацією про умови руху та роботи на маршруті;

2.3.9. Екіпірування автобусів противідкотними упорами, засобами пожежогасіння, медичними аптечками.

3. Зобов'язати територіальні органи Головної державної інспекції на автомобільному транспорті (Головавтотрансінспекції) та Державної автомобільної інспекції (Державтоінспекції):

3.1. До 20 числа кожного місяця, наступного за звітним, розробляти та затверджувати спільні графіки перевірок;

{ Підпункт 3.1 пункту 3 в редакції Наказу Міністерства транспорту та зв'язку N 765/504 ( z1008-10 ) від 19.10.2010 }

3.2. Надавати Головавтотрансінспекції та Державтоінспекції звіти про результати перевірок до 5 числа наступного місяця, що слідує за звітним періодом.

4. Головній державній інспекції на автомобільному транспорті Міністерства транспорту та зв'язку України (Сінько В.О.) забезпечити подання зазначеного наказу на державну реєстрацію до Міністерства юстиції України.

5. Скасувати наказ Міністерства внутрішніх справ України та Міністерства транспорту України від 14.06.2002 N 574/390 "Про посилення контролю за дотриманням перевізниками правил безпеки перевезень пасажирів автобусами".

6. Контроль за виконанням наказу покласти на заступника Міністра транспорту та зв'язку України Кроля С.С. та заступника Міністра внутрішніх справ України Рудіка В.М.
