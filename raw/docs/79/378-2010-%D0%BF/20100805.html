Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 червня 2010 р. N 378 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про особливості закупівлі нафти, нафтової сировини та нафтопродуктів

Кабінет Міністрів України постановляє:

Відповідно до пункту 6 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006), установити, що закупівля нафти, нафтової сировини та нафтопродуктів публічним акціонерним товариством "Національна акціонерна компанія "Нафтогаз України" здійснюється без застосування процедур закупівель, встановлених зазначеним Положенням.

Прем'єр-міністр України М.АЗАРОВ
