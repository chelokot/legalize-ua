КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 червня 2004 р. N 786 Київ

Про внесення змін у додаток до постанови Кабінету Міністрів України від 19 квітня 1993 р. N 283

{ Із змінами, внесеними згідно з Постановами КМ N 1032 ( 1032-2004-п ) від 10.08.2004 N 1209 ( 1209-2004-п ) від 16.09.2004 N 1367 ( 1367-2004-п ) від 15.10.2004 N 1479 ( 1479-2004-п ) від 03.11.2004 N 456 ( 456-2012-п ) від 14.05.2012 N 1054 ( 1054-2012-п ) від 31.10.2012 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 456 ( 456-2012-п ) від 14.05.2012 }

2. Міністерству транспорту та зв'язку затвердити за погодженням з Міністерством фінансів, Державною податковою адміністрацією, Міністерством аграрної політики і Державним комітетом статистики форми товарно-транспортних накладних на переміщення спирту етилового, високооктанових кисневмісних домішок та алкогольних напоїв.

{ Пункт 2 в редакції Постанови КМ N 1367 ( 1367-2004-п ) від 15.10.2004 }

3. Установити, що затверджені форми товарно-транспортних накладних на переміщення спирту етилового, високооктанових кисневмісних домішок та алкогольних напоїв застосовуються починаючи з 1 січня 2005 року.
