Стан: Чинний

Ідентифікатор: 786-2004-п

Текст документа від 03.11.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 червня 2004 р. N 786 Київ

Про внесення змін у додаток до постанови Кабінету Міністрів України від 19 квітня 1993 р. N 283

( Із змінами, внесеними згідно з Постановами КМ N 1032 ( 1032-2004-п ) від 10.08.2004 N 1209 ( 1209-2004-п ) від 16.09.2004 N 1367 ( 1367-2004-п ) від 15.10.2004 N 1479 ( 1479-2004-п ) від 03.11.2004 )

Кабінет Міністрів України постановляє:

1. Внести у розділ II додатка до постанови Кабінету Міністрів України від 19 квітня 1993 р. N 283 ( 283-93-п ) "Про встановлення порядку виготовлення бланків цінних паперів і документів суворого обліку" (із змінами, внесеними розпорядженням Кабінету Міністрів України від 4 листопада 1993 р. N 936 ( 936-93-р ) такі зміни:

абзац третій після слів "документи на перевезення вантажів" доповнити словами "товарно-транспортні накладні на переміщення спирту етилового, високооктанових кисневмісних домішок та алкогольних напоїв";

абзац п'ятий після слів "доручення на видачу коштів, пенсій, майна" доповнити словами "накладні на відпуск спирту етилового, високооктанових кисневмісних домішок та алкогольних напоїв".

2. Міністерству транспорту та зв'язку затвердити за погодженням з Міністерством фінансів, Державною податковою адміністрацією, Міністерством аграрної політики і Державним комітетом статистики форми товарно-транспортних накладних на переміщення спирту етилового, високооктанових кисневмісних домішок та алкогольних напоїв. ( Пункт 2 в редакції Постанови КМ N 1367 ( 1367-2004-п ) від 15.10.2004 )

3. Установити, що затверджені форми товарно-транспортних накладних на переміщення спирту етилового, високооктанових кисневмісних домішок та алкогольних напоїв застосовуються починаючи з 1 січня 2005 року. ( Пункт 3 із змінами, внесеними згідно з Постановами КМ N 1032 ( 1032-2004-п ) від 10.08.2004, N 1209 ( 1209-2004-п ) від 16.09.2004, N 1367 ( 1367-2004-п ) від 15.10.2004, N 1479 ( 1479-2004-п ) від 03.11.2004 )

4. Міністерству аграрної політики забезпечити формування щоквартальних заявок на виготовлення бланків товарно-транспортних накладних на переміщення спирту етилового, високооктанових кисневмісних домішок та алкогольних напоїв згідно із замовленнями суб'єктів підприємницької діяльності, які мають відповідні ліцензії на виробництво та торгівлю зазначеною продукцією. ( Постанову доповнено пунктом 4 згідно з Постановою КМ N 1367 ( 1367-2004-п ) від 15.10.2004 )

5. Міністерству фінансів разом з Міністерством аграрної політики в тижневий строк визначити в установленому порядку виготовлювача бланків товарно-транспортних накладних на переміщення спирту етилового, високооктанових кисневмісних домішок та алкогольних напоїв, забезпечити до 25 грудня 2004 р. їх доставку суб'єктам, зазначеним у пункті 4 цієї постанови. ( Постанову доповнено пунктом 5 згідно з Постановою КМ N 1367 ( 1367-2004-п ) від 15.10.2004; із змінами, внесеними згідно з Постановою КМ N 1479 ( 1479-2004-п ) від 03.11.2004 )
