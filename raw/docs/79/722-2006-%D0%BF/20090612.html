Про утворення Всеукраїнського центру охорони здоров'я матері і дитини

Текст документа від 12.06.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 травня 2006 р. N 722 Київ

Про утворення Всеукраїнського центру охорони здоров'я матері і дитини

{ Із змінами, внесеними згідно з Постановою КМ N 537 ( 537-2009-п ) від 03.06.2009 }

Відповідно до Указу Президента України від 6 грудня 2005 р. N 1694 ( 1694/2005 ) "Про невідкладні заходи щодо реформування системи охорони здоров'я населення" Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Міністерства охорони здоров'я та Державного управління справами щодо утворення Всеукраїнського центру охорони здоров'я матері і дитини (далі - Центр) та будівництва його об'єктів на території клінічної лікарні "Феофанія".

Взяти до відома, що функції замовника будівництва Центру здійснюватиме клінічна лікарня "Феофанія" Державного управління справами. { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 537 ( 537-2009-п ) від 03.06.2009 }

2. Київській міській державній адміністрації сприяти Державному управлінню справами у будівництві Центру, відведенні додаткових земельних ділянок з метою спорудження житла для працівників Центру та інших його об'єктів.

3. Міністерству економіки разом з Міністерством охорони здоров'я та Державним управлінням справами вживати заходів до активного залучення коштів для будівництва Центру.

Прем'єр-міністр України Ю.ЄХАНУРОВ
