МІНІСТЕРСТВО КУЛЬТУРИ І МИСТЕЦТВ УКРАЇНИ

НАКАЗ

24.02.2005 N 96

Зареєстровано в Міністерстві юстиції України 28 лютого 2005 р. за N 270/10550

Про внесення змін до наказу Міністерства культури і мистецтв України від 19.04.2001 N 204

( Із змінами, внесеними згідно з Наказом Міністерства культури і туризму N 745 ( z1285-05 ) від 18.10.2005 )

На виконання постанов Кабінету Міністрів України від 15.01.2005 N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери", від 28.07.2004 N 968 ( 968-2004-п ) "Про впорядкування оплати праці працівників державних академічних театрів" (із змінами) НАКАЗУЮ:

( Пункт 1 втратив чинність на підставі Наказу Міністерства культури і туризму N 745 ( z1285-05 ) від 18.10.2005 )

2. Виключити з Переліку установ культури і мистецтва, працівникам яких встановлюються підвищені на 20 відсотків посадові оклади, затвердженого Міністерством культури України за погодженням з Міністерством праці України, Міністерством фінансів України, Спілкою театральних діячів України та Українським комітетом профспілки працівників культури України, державні академічні театри, визначені додатком до постанови Кабінету Міністрів України від 28.07.2004 N 968 ( 968-2004-п ) "Про впорядкування оплати праці працівників державних академічних театрів" (із змінами).

3. Скасувати наказ Мінкультури Української РСР від 23.12.91 N 741-к "Про перелік установ мистецтва, працівникам яких встановлюються підвищені посадові оклади" в частині встановлення підвищених посадових окладів (ставок заробітної плати) працівникам державних академічних театрів.

4. Скасувати накази Мінкультури України від 28.12.93 N 626-к "Про підвищення посадових окладів працівникам Київського державного театру оперети", від 15.12.94 N 65 "Про підвищення посадових окладів", від 27.04.94 N 140-к "Про підвищення посадових окладів", від 28.04.94 N 141-к "Про підвищення посадових окладів", від 14.07.94 N 269-к "Про підвищення посадових окладів", від 14.09.94 N 415-к "Про підвищення посадових окладів", від 20.12.94 N 571-к "Про підвищення посадових окладів працівникам Донецького державного академічного театру опери та балету", від 25.01.95 N 33 "Про підвищення посадових окладів Кримськотатарському музично-драматичному театру", від 14.11.2000 N 442-к "Про внесення доповнень до наказу Мінкультури України від 23.12.91 N 741-к".

5. Контроль за виконанням наказу покласти на заступника Міністра І.В. Ніколайка.

6. Ці зміни застосовуються з 1 січня 2005 року.
