Про залучення інвестицій для фінансування проектів, спрямованих на зменшення обсягу викидів парникових газів

Стан: Втратив чинність

Ідентифікатор: 549-2009-р

Текст документа від 30.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 травня 2009 р. N 549-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1714-р ( 1714-2010-р ) від 30.08.2010 }

Про залучення інвестицій для фінансування проектів, спрямованих на зменшення обсягу викидів парникових газів

Нацекоінвестагентству:

укласти договір про продаж 100000000 одиниць (частин) установленої кількості з компанією Дайтон Карбон СА (Швейцарія);

укласти договір про продаж 50000000 одиниць (частин) установленої кількості з компанією Тавхакі Інтернешнл ЛП (Нова Зеландія);

здійснити передачу 150000000 одиниць (частин) установленої кількості з рахунка України в Національному електронному реєстрі антропогенних викидів та абсорбції парникових газів на рахунки зазначених компаній відповідно до умов договорів про продаж;

укласти з компанією Номура Інтернешнл плс (Великобританія) договір про залучення інвестицій.

Прем'єр-міністр України Ю.ТИМОШЕНКО
