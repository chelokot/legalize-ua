КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 липня 1999 р. N 1293 Київ

{ Постанова втрачає чинність на підставі Постанови КМ N 93 ( 93-2003-п ) від 18.01.2003 з дати набрання чинності частиною тринадцятою статті 71 Митного кодексу України ( 92-15 ), яка набирає чинності з моменту набуття Україною членства у Світовій організації торгівлі }

Про деякі заходи щодо спрощення митного оформлення нафти та нафтопродуктів

( Із змінами, внесеними згідно з Постановою КМ N 1493 ( 1493-2002-п ) від 11.10.2002 )

З метою спрощення митного оформлення нафти та нафтопродуктів, які ввозяться на митну територію України, Кабінет Міністрів України постановляє:

Установити, що дія абзаців третього та четвертого пункту 1 постанови Кабінету Міністрів України від 27 січня 1997 р. N 65 ( 65-97-п ) "Про ставки митних зборів" (із змінами, внесеними постановами Кабінету Міністрів України від 7 березня 1998 р. N 285 ( 285-98-п ), від 13 травня 1998 р. N 670 ( 670-98-п ), від 18 вересня 1998 р. N 1460 ( 1460-98-п ), від 21 вересня 1998 р. N 1477 ( 1477-98-п ), від 8 жовтня 1998 р. N 1625 ( 1625-98-п ), від 19 травня 1999 р. N 840 ( 840-99-п ), від 27 травня 1999 р. N 920 ( 920-99-п ), від 23 червня 1999 р. N 1116 ( 1116-99-п ) не поширюється:

на нафтопродукти, що вироблені в Україні з нафти, поставленої на давальницьких умовах, і реалізуються в Україні, - у частині справляння додаткового митного збору за митне оформлення у розмірі 0,01 євро за 1 кілограм;

на імпортні нафту сиру та нафтопродукти за кодами згідно з УКТ ЗЕД 2709 00 90 00, 2710 00 65 00, 2710 00 27 11, 2710 00 32 09, 2710 00 34 11, 2710 00 36 09, 2710 00 61 00, 2710 00 69 00 - у частині справляння збору у розмірі 2 відсотків митної вартості. ( Абзац третій із змінами, внесеними згідно з Постановою КМ N 1493 ( 1493-2002-п ) від 11.10.2002 )
