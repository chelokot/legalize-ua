Про внесення змін до Інструкції про проведення виконавчих дій

У відповідності до Законів України "Про внесення змін до деяких законодавчих актів України щодо призначення тимчасової державної допомоги дітям" від 08.09.2005 N 2853-IV ( 2853-15 ) та "Про виконавче провадження" ( 606-14 ) НАКАЗУЮ:

1. Пункт 4.5 Інструкції про проведення виконавчих дій, затвердженої наказом Міністерства юстиції України від 15.12.99 N 74/5 ( z0865-99 ), зареєстрованим у Мін'юсті України 15.12.99 за N 865/4158 (із змінами і доповненнями), доповнити новим абзацом шістнадцятим такого змісту:

"призначення тимчасової державної допомоги відповідно до частини п'ятої статті 181 Сімейного кодексу України ( 2947-14 )".

2. В.о. директора Департаменту державної виконавчої служби (Гавдьо Б.Р.):

2.1. Забезпечити державну реєстрацію наказу відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами і доповненнями).

2.2. Довести цей наказ до відома начальників Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, обласних, Київського та Севастопольського міських управлінь юстиції та забезпечити належне його виконання.

3. Контроль за виконанням наказу покласти на заступника Міністра юстиції України М.М.Шупеню.

4. Цей наказ набирає чинності з 1 січня 2006 року.

Міністр С.Головатий
