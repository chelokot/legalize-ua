Президент України; Указ від 03.10.2008 № 896/2008

Про Представника України у Спільній комісії по виконанню та інспекціях

Стан: Чинний

Ідентифікатор: 896/2008

Текст документа від 03.10.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Представника України у Спільній комісії по виконанню та інспекціях

1. Призначити НИКОНЕНКА Олександра Миколайовича Представником України у Спільній комісії по виконанню та інспекціях (СКВІ), створеній відповідно до Договору між Союзом Радянських Соціалістичних Республік та Сполученими Штатами Америки про скорочення та обмеження стратегічних наступальних озброєнь ( 840_050 ) від 31 липня 1991 року.

2. Визнати таким, що втратив чинність, Указ Президента України від 19 жовтня 2005 року N 1462 ( 1462/2005 ) "Про Представника України у Спільній комісії по виконанню та інспекціях".

Президент України В.ЮЩЕНКО

м. Київ, 3 жовтня 2008 року N 896/2008
