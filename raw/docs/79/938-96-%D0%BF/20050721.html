КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 серпня 1996 р. N 938 Київ

Про подальше посилення контролю за ввезенням, вивезенням та переміщенням транзитом через територію України алкогольних напоїв і тютюнових виробів, на які встановлено акцизний збір

( Із змінами, внесеними згідно з Постановами КМ N 1428 ( 1428-96-п ) від 30.11.96 N 1473 ( 1473-96-п ) від 11.12.96 N 68 ( 68-97-п ) від 27.01.97 N 398 ( 398-97-п ) від 25.04.97 N 697 ( 697-97-п ) від 01.07.97 N 1473 ( 1473-97-п ) від 29.12.97 N 1495 ( 1495-97-п ) від 30.12.97 N 1639 ( 1639-98-п ) від 16.10.98 N 29 ( 29-99-п ) від 12.01.99 N 327 ( 327-99-п ) від 09.03.99 N 369 ( 369-99-п ) від 15.03.99 N 384 ( 384-99-п ) від 15.03.99 N 484 ( 484-99-п ) від 31.03.99 N 668 ( 668-99-п ) від 23.04.99 N 1286 ( 1286-99-п ) від 19.07.99 N 1516 ( 1516-99-п ) від 18.08.99 N 1922 ( 1922-99-п ) від 18.10.99 N 963 ( 963-2001-п ) від 09.08.2001 N 1259 ( 1259-2002-п ) від 29.08.2002 N 1874 ( 1874-2002-п ) від 12.12.2002 N 577 ( 577-2004-п ) від 29.04.2004 N 1370 ( 1370-2004-п ) від 15.10.2004 N 1605 ( 1605-2004-п ) від 30.11.2004 N 400 ( 400-2005-п ) від 26.05.2005 )

З метою посилення контролю за ввезенням, вивезенням та переміщенням транзитом через територію України алкогольних напоїв і тютюнових виробів, на які встановлено акцизний збір, Кабінет Міністрів України постановляє:

1. Затвердити перелік пунктів пропуску через державний кордон України, через які ввозяться з метою імпорту та транзиту, а також вивозяться алкогольні напої та тютюнові вироби за кодами згідно з УКТ ЗЕД 2203 00, 2204 - 2208, 2402 10 00 00, 2402 20 10 00, 2402 20 90, 2403 10 10 00, 24 03 10 90 00, 2403 99 10 00, на які встановлено акцизний збір (додається).

( Пункт 1 із змінами, внесеними згідно з Постановами КМ N 1495 ( 1495-97-п ) від 30.12.97, N 1259 ( 1259-2002-п ) від 29.08.2002, N 1370 ( 1370-2004-п ) від 15.10.2004 )

2. Установити, що ввезення та переміщення по території України товарів (предметів), зазначених у пункті 1 цієї постанови, здійснюється без зміни виду транспорту і транспортного засобу, крім випадків, пов'язаних з використанням морського транспорту у пунктах перетину митного кордону.

Порядок митного контролю за товарами (предметами) у разі зміни транспортного засобу визначається Державним митним комітетом.

3. Державному митному комітетові розробити й затвердити умови, яким мають відповідати декларанти алкогольних напоїв і тютюнових виробів, на які встановлено акцизний збір.

4. Скасувати постанову Кабінету Міністрів України від 30 липня 1996 р. N 856 ( 856-96-п ) "Про внесення змін до постанови Кабінету Міністрів України від 6 травня 1996 р. N 484".
