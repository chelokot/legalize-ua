МІНІСТЕРСТВО КУЛЬТУРИ УКРАЇНИ

НАКАЗ

26.04.2011 N 31

Зареєстровано в Міністерстві юстиції України 12 травня 2011 р. за N 571/19309

Про внесення змін до деяких наказів Міністерства культури і туризму України

{ Із змінами, внесеними згідно з Наказом Міністерства культури N 421 ( z0677-17 ) від 16.05.2017 }

Відповідно до постанови Кабінету Міністрів України від 30.03.2011 N 310 ( 310-2011-п ) "Про внесення зміни в додаток 1 до постанови Кабінету Міністрів України від 30 серпня 2002 р. N 1298" НАКАЗУЮ:

1. Унести зміну в додаток 1 до наказу Міністерства культури і туризму України від 18.10.2005 N 745 ( z1285-05 ) "Про впорядкування умов оплати праці працівників культури на основі Єдиної тарифної сітки", зареєстрованого в Міністерстві юстиції України 27.10.2005 за N 1285/11565 (зі змінами), доповнивши абзац перший примітки 1 після цифр і слова "613 гривень" словами і цифрами "; з 1 квітня - 625 гривень".

{ Пункт 2 втратив чинність на підставі Наказу Міністерства культури N 421 ( z0677-17 ) від 16.05.2017 }

3. Керівникам установ, закладів та організацій культури і науково-дослідних установ культури забезпечити диференціацію заробітної плати працівників, для яких визначені однакові посадові оклади, за рахунок встановлення доплат, надбавок та премій.

4. Цей наказ набирає чинності з дня його офіційного опублікування та застосовується з 1 квітня 2011 року.

Міністр М.А.Кулиняк
