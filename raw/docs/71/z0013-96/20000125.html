НАКАЗ

N 1 від 03.01.96 Зареєстровано в Міністерстві м.Київ юстиції України 9 січня 1996 р. vd960103 vn1 за N 13/1038

( Наказ втратив чинність на підставі Наказу Державної митної служби N 865 ( z0041-00 ) від 28.12.99 )

Про порядок митного оформлення товарів, що імпортуються в Україну суб'єктами підприємницької діяльності, які користуються податковими пільгами

( Із змінами, внесеними згідно з Наказом Митного комітету N 149 ( z0211-96 ) від 17.04.96 )

( Додатково див. Лист Державної митної служби N 11/1-2943 ( v2943342-97 ) від 04.04.97 )

Верховною Радою України прийнято та вводиться в дію з 1 січня 1996 року Закон України "Про деякі питання оподаткування підакцизних товарів" ( 432/95-ВР ). Цим Законом внесено зміни в умови оподаткування товарів при переміщенні їх через митний кордон України. У зв'язку з необхідністю внесення змін в порядок митного оформлення товарів, що ввозяться суб'єктами підприємницької діяльності на митну територію України, керуючись статтями 25, 37 та 73 Митного кодексу України ( 1970-12 ), НАКАЗУЮ :

1. Затвердити Порядок митного оформлення товарів, що імпортуються (ввозяться) в Україну суб'єктами підприємницької діяльності, які користуються пільгами щодо оподаткування, який додається.

2. Інформаційно-обчислювальному центру митної системи (Сидоренко В.Ф.) спільно з митно-тарифним управлінням (Шейко О.П.) до 31 січня 1996 року розробити програму обробки даних граф 12, 20, 36, 45, 47 вантажної митної декларації.

3. Правовому відділу (Рибалко О.М.) забезпечити державну реєстрацію цього наказу у Міністерстві юстиції України.

4. Управлінню справами (Ящук В.І.) забезпечити тиражування та доведення цього наказу до митних установ та засобів масової інформації після його реєстрації у Міністерстві юстиції України.

5. Контроль за виконанням цього наказу покласти на заступника Голови Державного митного комітету України Єгорова О.Б.

Голова Державного митного комітету України Л.Деркач

Затверджено наказом Державного митного комітету України від 03.01.96 р. N 1

Порядок митного оформлення товарів, що імпортуються (ввозяться) в Україну суб'єктами підприємницької діяльності, які користуються податковими пільгами

У зв'язку зі змінами умов оподаткування імпортних товарів, внесеними Законом України "Про деякі питання оподаткування підакцизних товарів" ( 432/95-ВР ), митне оформлення імпортних товарів здійснюється наступним чином:

1. Підакцизні товари, що імпортуються в Україну суб'єктами підприємницької діяльності, які користуються пільгами на підставі законодавчих актів України, зазначених у переліку, визначеному Законом України від 22 грудня 1995 року N 498/95-ВР "Про визнання такими, що втратили чинність, деяких законодавчих актів з питань оподаткування підакцизних товарів", підлягають пропуску для вільного використання за умови сплати ввізного мита, акцизного збору, податку на добавлену вартість та митних зборів, встановлених чинним законодавством України. ( Пункт 1 в редакції Наказу Митного комітету N 149 ( z0211-96 ) від 17.04.96 )

2. Непідакцизні товари, що ввозяться суб'єктами підприємницької діяльності, які користуються податковими пільгами відповідно до законодавства України, підлягають митному оформленню із застосуванням пільг щодо обкладення ввізним митом та податком на добавлену вартість та пропуску для вільного використання за наступних умов:

а) імпортером на день оформлення подано митниці звіт про використання товарів, які були оформлені митницею із застосуванням пільг по оподаткуванню за попередніми імпортними поставками;

б) імпортером згідно зі статтею 73 Митного кодексу України ( 1970-12 ) заявлено про мету ввезення та подальшого використання товарів, що ввозяться на митну територію України та надано митниці зобов'язання про використання таких товарів виключно з тією метою, що передбачає пільговий режим оподаткування, та про подання на протязі двох тижнів звіту про фактичне використання таких товарів.

При цьому заповнення вантажної митної декларації має такі особливості:

- у графі 47 нараховуються всі суми податків (мито, ПДВ ) з позначенням після виду платежу літери "У" - умовно нараховано (наприклад 20У, 27У і т.д.) незалежно від звільнення суб'єкта від їх фактичної сплати, Інформація заноситься в базу даних: але не включається в звітність по митним платежам.

Інформація про нараховані суми податків передається до податкових інспекцій за адресою отримувача вантажів та до Державного митного комітету відразу після випуску товарів у вільне використання.

Інформація передається за наступною формою:

1. Отримувач/імпортер, адреса, код ЗКПО (графа 8);

2. Код товару згідно ТН ЗЕД (графа 33);

3. Митна вартість товару (графа 12);

4. Сума умовно нарахованих податків (графа 47) окремо:

- мито;

- ПДВ;

5. Довідковий номер ВМД;

6. Назва та адреса податкової інспекції, якій передається інформація (за місцем розташування імпортера).

Неподання суб'єктом підприємницької діяльності митній установі звіту про використання товарів, які були оформлені митницею з застосуванням пільг по оподаткуванню, тягне за собою припинення пільгового митного оформлення експортно-імпортних вантажів цього суб'єкта до з'ясування обставин та вирішення питання про притягнення такого суб'єкта, при наявності підстав, до відповідальності згідно зі статтею 119 Митного кодексу України ( 1970-12 ).
