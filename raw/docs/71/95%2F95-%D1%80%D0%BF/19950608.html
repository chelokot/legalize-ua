РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 431/95 ( 431/95 ) від 08.06.95 )

Про склад Центральної комісії з проведення опитування громадської думки з питання довіри громадян України Президентові України та Верховній Раді України

Відповідно до Указу Президента України від 31 травня 1995 року N 413 ( 413/95 ) затвердити персональний склад Центральної комісії з проведення опитування громадської думки з питання довіри громадян України Президентові України та Верховній Раді України (додається).
