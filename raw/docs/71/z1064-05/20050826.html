МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

26.08.2005 N 428

Зареєстровано в Міністерстві юстиції України 16 вересня 2005 р. за N 1064/11344

Про визнання такими, що втратили чинність, деяких наказів Міністерства аграрної політики України

На виконання статті 3 Указу Президента України від 1 червня 2005 року N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" та розпорядження Кабінету Міністрів України від 8 серпня 2005 року N 321-р ( 321-2005-р ) "Про першочергові заходи щодо поліпшення стану справ із прискореного перегляду регуляторних актів та вдосконалення реєстраційної і дозвільної процедури" НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

1.1. Наказ Державного комітету України по харчовій промисловості України від 11 березня 1997 року N 16 ( z0225-97 ) "Про затвердження Порядку перевірки технологічних умов виробництва у суб'єктів підприємницької діяльності", зареєстрований в Міністерстві юстиції України 23 червня 1997 року за N 225/2029.

1.2. Наказ Міністерства аграрної політики України від 27 серпня 2001 року N 257 ( z0815-01 ) "Про здійснення контролю за дотриманням підприємствами - виробниками тютюнової продукції показників щодо кількісного вмісту ферментованого тютюну, вирощеного в Україні", зареєстрований в Міністерстві юстиції України 13 вересня 2001 року за N 815/6006.

2. Вилучити абзаци 3 та 4 пункту 1 наказу Міністерства аграрної політики України від 21 липня 2005 року N 332 ( v0332555-05 ) "Про скасування деяких наказів Мінагрополітики України".

3. Державному департаменту продовольства (Кіщак Ю.П.):

3.1. У встановленому порядку подати наказ на державну реєстрацію до Міністерства юстиції України.

3.2. Довести наказ до відома підприємств, установ та організацій.

4. Контроль за виконанням наказу покласти на першого заступника Міністра Демчака І.М.

Міністр О.П.Баранівський
