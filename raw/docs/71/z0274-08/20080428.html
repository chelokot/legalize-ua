Зміни до форми Звіту про результати здійснення процедури запиту цінових пропозицій (котирувань) щодо закупівлі товарів і послуг за державні кошти

Реєстрація: Мін'юст України від 31.03.2008 № 274/14965

Стан: Втратив чинність

Ідентифікатор: z0274-08

Текст документа від 28.04.2008:

АНТИМОНОПОЛЬНИЙ КОМІТЕТ УКРАЇНИ

ЗАТВЕРДЖЕНО Розпорядження Антимонопольного комітету України 04.03.2008 N 120-р ( z0271-08 )

{ Документ втратив чинність на підставі Розпорядження Антимонопольного комітету N 200-р ( z0323-08 ) від 08.04.2008 }

ЗМІНИ до форми Звіту про результати здійснення процедури запиту цінових пропозицій (котирувань) щодо закупівлі товарів і послуг за державні кошти ( z0909-06 )

1. У заголовку форми ( z0909-06 ) слова "запиту цінових пропозицій (котирувань) щодо закупівлі товарів і послуг" замінити словами "запиту цінових пропозицій (котирувань) щодо закупівлі товарів, робіт і послуг".

2. Пункт 14 форми ( z0909-06 ) доповнити абзацом такого змісту:

"(за рішенням тендерного комітету від ________ N ________)".

Державний уповноважений М.Бараш

ЗМІНИ до Інструкції щодо заповнення форми Звіту про результати здійснення процедури запиту цінових пропозицій (котирувань) щодо закупівлі товарів і послуг за державні кошти ( z0909-06 )

1. У заголовку Інструкції ( z0909-06 ) слова "запиту цінових пропозицій (котирувань) щодо закупівлі товарів і послуг" замінити словами "запиту цінових пропозицій (котирувань) щодо закупівлі товарів, робіт і послуг".

2. У другому реченні абзацу другого пункту 2.1 Інструкції ( z0909-06 ) слово "п'ятого" замінити словом "шостого".

3. В абзаці другому пункту 2.7 Інструкції ( z0909-06 ) цифру "8" замінити цифрами "10".
