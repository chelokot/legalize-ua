ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

N 35 від 05.04.2000 Зареєстровано в Міністерстві м.Київ юстиції України 23 травня 2000 р. за N 298/4519

( Рішення втратило чинність на підставі Рішення Держкомісціннихпаперів N 279 ( z1122-04 ) від 08.06.2004 )

Про внесення змін до Порядку подання звітності торговцями

цінними паперами, затвердженого рішенням Комісії від 10.06.97 N 11/1 (зі змінами та доповненнями)

Відповідно до статі 7 Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ) та з метою удосконалення контролю за діяльністю торговців цінними паперами Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Унести зміни до Порядку подання звітності торговцями цінними паперами, затвердженого рішенням Комісії від 10.06.97 N 11/1 ( v11_1312-97 ) (зі змінами та доповненнями), а саме:

пункт 2.3 - вилучити.

2. Управлінню регулювання ринку цінних паперів спільно з юридичним управлінням забезпечити реєстрацію цього рішення у Міністерстві юстиції України;

3. Рішення набуває чинності відповідно до чинного законодавства.

4. Прес-центру опублікувати рішення відповідно до чинного законодавства.

5. Контроль за виконанням цього рішення покласти на члена Комісії - першого заступника Голови М.Волкова.

Т.в.о.Голови Комісії О.Ромашко
