ПОСТАНОВА від 5 березня 2008 р. N 133 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 771 ( 771-2008-п ) від 03.09.2008 }

Про внесення зміни до Положення про Державний департамент автомобільного транспорту

Кабінет Міністрів України постановляє:

В абзаці другому пункту 7 Положення про Державний департамент автомобільного транспорту, затвердженого постановою Кабінету Міністрів України від 30 березня 2000 р. N 586 ( 586-2000-п ) (Офіційний вісник України, 2000 р., N 14, ст. 561; 2003 р., N 30, ст. 1546; 2005 р., N 20, ст. 1064; 2008 р., N 8, ст. 200), слова "має заступників" замінити словами "має чотирьох заступників, у тому числі одного першого".
