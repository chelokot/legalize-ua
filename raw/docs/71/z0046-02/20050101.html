Про оплату праці працівників національних закладів культури (мистецьких)

( Із змінами, внесеними згідно з Наказами Міністерства культури і мистецтв N 453 ( z0617-02 ) від 18.07.2002 N 161 ( z0293-03 ) від 24.03.2003 N 177 ( z0442-04 ) від 30.03.2004 N 689 ( z1272-04 ) від 06.10.2004 N 95 ( z0272-05 ) від 24.02.2005 )

На виконання постанови Кабінету Міністрів України від 15.10.2001 N 1345 ( 1345-2001-п ) "Про оплату праці працівників національних закладів культури" НАКАЗУЮ:

1. Затвердити схеми посадових окладів (ставок заробітної плати) керівних працівників, художнього, артистичного персоналу, фахівців, службовців, робітників національних закладів культури згідно з додатками 1-4.

2. Надати право керівникам національних закладів культури в межах фонду заробітної плати, затвердженого в кошторисах доходів і видатків, установлювати:

1) працівникам цих закладів конкретні розміри посадових окладів (ставок заробітної плати) в межах схем, наведених у додатках 1-4;

2) підвищені в 2 рази посадові оклади (ставки заробітної плати) працівникам національних закладів, посади яких визначені відповідними наказами по інших галузях народного господарства.

Перерахування посадових окладів (ставок заробітної плати) у гривні здійснюється з дотриманням такого порядку їх заокруглення: цифри в розряді до 0,5 відкидаються, від 0,5 і вище заокруглюються до однієї гривні.

3. Установити, що інші умови оплати праці працівників національних закладів визначаються згідно з умовами оплати праці відповідних категорій працівників галузі.

4. Скасувати накази Мінкультури від 23.12.1991 N 741-к "Про перелік установ мистецтва, працівникам яких встановлюються підвищені посадові оклади", від 20.07.1993 N 326-к "Про підвищення посадових окладів працівникам Республіканського будинку органної і камерної музики", від 01.12.1998 N 436-к "Про внесення доповнень до наказу Міністерства культури України від 20.07.1993 N 326-к", від 15.11.1993 N 309 "Про підвищення посадових окладів працівникам Державного ансамблю солістів "Київська камерата", від 25.11.1993 N 326 "Про підвищення посадових окладів працівникам Київської державної філармонії", від 03.01.1996 N 1-к "Про оплату праці в творчому об'єднанні цирків Укрдержцирк", від 01.07.1993 N 266-к "Про доповнення до наказу Міністерства культури України від 23.12.91 р. N 741-к, від 24.11.1999 N 630-к "Про внесення доповнень до наказу Міністерства культури і мистецтв від 03.01.1996 N 1-к" в частині оплати праці працівників національних закладів культури, посадові оклади (ставки заробітної плати) яких затверджені цим наказом.

5. Контроль за виконанням цього наказу покласти на заступника Державного секретаря В.В. Корнієнка.
