Президент України; Указ від 22.02.2006 № 150/2006

Про делегацію України для участі у переговорах між Україною та Республікою Білорусь щодо підготовки проекту Договору між Україною та Республікою Білорусь про передачу осіб, засуджених до позбавлення волі, для подальшого відбування покарання

Стан: Втратив чинність

Ідентифікатор: 150/2006

Текст документа від 07.02.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у переговорах між Україною та Республікою Білорусь щодо підготовки проекту Договору між Україною та Республікою Білорусь про передачу осіб, засуджених до позбавлення волі, для подальшого відбування покарання

1. Утворити делегацію України для участі у переговорах між Україною та Республікою Білорусь щодо підготовки проекту Договору між Україною та Республікою Білорусь про передачу осіб, засуджених до позбавлення волі, для подальшого відбування покарання (м. Мінськ, Республіка Білорусь) у такому складі:

ГОРБУНОВА - заступник Міністра юстиції України, глава

Лідія Миколаївна делегації

ДВОЙНІС - начальник управління Державного

Олексій Григорович департаменту України з питань виконання покарань

МАРЧЕНКО - завідувач відділу Головної

Людмила Іванівна державно-правової служби Секретаріату Президента України

СИБІГА - начальник відділу Договірно-правового

Андрій Іванович управління Міністерства закордонних справ України

ШЕВЧЕНКО - начальник управління - заступник директора Катерина Георгіївна Департаменту міжнародного співробітництва Міністерства юстиції України.

Дозволити главі делегації України вносити в разі потреби зміни до складу делегації, залучаючи до її роботи членів Експертної групи з підготовки проектів міжнародних договорів України про правові відносини та правову допомогу у цивільних і кримінальних справах, утвореної Указом Президента України від 24 квітня 2004 року N 476 ( 476/2004 ).

2. Міністерству юстиції України за погодженням з Міністерством закордонних справ України затвердити вказівки делегації України на переговори.

3. Кабінету Міністрів України вирішити питання щодо виділення коштів в іноземній валюті для забезпечення участі у переговорах делегації України.

Президент України В.ЮЩЕНКО

м. Київ, 22 лютого 2006 року N 150/2006
