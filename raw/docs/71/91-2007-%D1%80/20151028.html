Кабінет Міністрів України; Розпорядження від 07.03.2007 № 91-р

Про утворення загальноосвітнього навчального закладу "Міжнародна українська школа"

Стан: Чинний

Ідентифікатор: 91-2007-р

Текст документа від 28.10.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 березня 2007 р. N 91-р Київ

Про утворення загальноосвітнього навчального закладу "Міжнародна українська школа"

{ Назва Розпорядження в редакції Розпорядження КМ N 1144-р ( 1144-2015-р ) від 28.10.2015 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1144-р ( 1144-2015-р ) від 28.10.2015 }

1. З метою створення умов для реалізації права на повну загальну середню освіту громадян України, які тимчасово або постійно проживають за кордоном та в Автономній Республіці Крим і м. Севастополі, погодитися з пропозицією МОН щодо утворення цим Міністерством загальноосвітнього навчального закладу "Міжнародна українська школа" (далі - навчальний заклад) для надання освітніх послуг зазначеним громадянам за індивідуальним навчальним планом. { Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 1144-р ( 1144-2015-р ) від 28.10.2015 }

2. МОН:

затвердити статут навчального закладу та за погодженням з Мінфіном його штатний розпис;

забезпечити фінансування навчального закладу з 1 вересня 2007 р. та передбачати щороку кошти на його утримання під час підготовки проекту державного бюджету на відповідний рік.

Прем'єр-міністр України В.ЯНУКОВИЧ
