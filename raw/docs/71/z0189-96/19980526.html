Про затвердження Положення про порядок ведення реєстру власників іменних цінних паперів

Реєстрація: Мін'юст України від 17.04.1996 № 189/1214

Стан: Втратив чинність

Ідентифікатор: z0189-96

Текст документа від 26.05.1998:

ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

НАКАЗ

N 58 від 01.04.96 Зареєстровано в Міністерстві м.Київ юстиції України 17 квітня 1996 р. vd960401 vn58 за N 189/1214

Про затвердження Положення про порядок ведення реєстру власників іменних цінних паперів

( Із змінами, внесеними згідно з Рішеннями Держкомціннихпаперів N 14 ( va014312-97 ) від 24.06.97 N 60 ( vr060312-98 ) від 26.05.98 )

На виконання Указу Президента України від 2 березня 1996 року N 160/96 на підставі розгляду Державної комісії з цінних паперів та фондового ринку протокол від 01.04.96 р. НАКАЗУЮ:

1. Затвердити "Положення про порядок ведення реєстру власників іменних цінних паперів" (додається).

2. Встановити, що вимоги цього Положення є обов'язковими для виконання всіма особами, які ведуть реєстри іменних цінних паперів.

3. Порядок видачі Дозволів на здійснення діяльності щодо ведення реєстру власників іменних цінних паперів визначається Порядком ( z0190-96 ), затвердженим Державною комісією з цінних паперів та фондового ринку.

4. Контроль за дотриманням вимог цього Положення особами, які проводять реєстрацію власників іменних цінних паперів, покласти на члена Державної комісії А.Головка.

Голова Комісії О.Мозговий ( Положення втратило чинність на підставі Рішення Держкомісціннихпаперів N 60 ( vr060312-98 ) від 26.05.98 )
