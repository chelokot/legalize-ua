Про відкриття пункту контролю через державний кордон "Визирка"

Стан: Чинний

Ідентифікатор: 591-2011-р

Текст документа від 22.06.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 червня 2011 р. N 591-р Київ

Про відкриття пункту контролю через державний кордон "Визирка"

Для впорядкування діяльності пункту пропуску через державний кордон в морському торговельному порту "Южний" відкрити пункт контролю через державний кордон "Визирка" для міжнародного морського вантажного сполучення.

Прем'єр-міністр України М.АЗАРОВ
