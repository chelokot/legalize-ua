Про затвердження складу представників від Кабінету Міністрів України до Національної ради соціального партнерства

( Із змінами, внесеними згідно з Розпорядженням КМ N 350-р ( 350-2002-р ) від 01.07.2002 )

1. Затвердити новий склад представників від Кабінету Міністрів України до Національної ради соціального партнерства (додається).

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 1 вересня 1998 р. N 711 ( 711-98-р );

розпорядження Кабінету Міністрів України від 3 серпня 1999 р. N 767 ( 767-99-р );

розпорядження Кабінету Міністрів України від 26 червня 2000 р. N 272 ( 272-2000-р ).
