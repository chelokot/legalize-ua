Держкомсім'ямолодь України; Наказ від 16.07.1999 № 108

Про внесення змін до Положення про Український державний центр соціальних служб для молоді

Реєстрація: Мін'юст України від 19.07.1999 № 475/3768

Стан: Втратив чинність

Ідентифікатор: z0475-99

Текст документа від 16.08.2000:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ У СПРАВАХ СІМ'Ї ТА МОЛОДІ

НАКАЗ

N 108 від 16.07.99 Зареєстровано в Міністерстві м.Київ юстиції України 19 липня 1999 р. vd990716 vn108 за N 475/3768

( Наказ втратив чинність на підставі Наказу Держкоммолодьполітики і спорту N 1255 ( z0508-00 ) від 20.07.2000 )

Про внесення змін до Положення про Український державний центр соціальних служб для молоді

Відповідно до Указу Президента України від 13.03.99 N 250 ( 250/99 ) "Про зміни в системі центральних органів виконавчої влади України" НАКАЗУЮ:

Унести до Положення про Український державний центр соціальних служб для молоді, затвердженого наказом Міністерства України у справах сім'ї та молоді від 04.03.98 N 73 ( z0677-98 ), зареєстрованого в Міністерстві юстиції України за N 677/3117, такі зміни:

слова "Міністерство України у справах сім'ї та молоді" замінити словами "Державний комітет України у справах сім'ї та молоді" у відповідних відмінках.

Голова В.І.Довженко
