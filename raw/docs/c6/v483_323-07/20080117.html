НАКАЗ

17.04.2007 N 483/7

Про утворення тендерної (конкурсної) комісії

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 33/7 ( v33_7323-08 ) від 17.01.2008 }

Відповідно до пунктів 2.1 - 2.3 Положення про умови і порядок проведення тендерів (конкурсів) з визначення спеціалізованих організацій для реалізації арештованого державними виконавцями майна, затвердженого наказом Міністерства юстиції України від 11 листопада 2003 року N 136/5 ( z1036-03 ), зареєстрованого в Мін'юсті України 11 листопада 2003 року за N 1036/8357 (із змінами і доповненнями), та з метою організації та проведення тендера (конкурсу) НАКАЗУЮ:

1. Утворити тендерну (конкурсну) комісію у складі згідно додатка.

2. Скасувати наказ Міністерства юстиції України від 19.12.2006 N 1581/7 "Про утворення тендерної (конкурсної) комісії".

3. Департаменту державної виконавчої служби (В.В.Тісногуз) довести цей наказ до відома складу тендерної (конкурсної) комісії.

4. Контроль за виконанням цього наказу покласти на заступника Міністра І.І.Ємельянову.

Міністр О.Лавринович
