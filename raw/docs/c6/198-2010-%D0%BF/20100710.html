Кабінет Міністрів України; Постанова від 24.02.2010 № 198

Про використання у 2010 році коштів Стабілізаційного фонду для здійснення заходів з утилізації твердого ракетного палива

Стан: Втратив чинність

Ідентифікатор: 198-2010-п

Текст документа від 10.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 лютого 2010 р. N 198 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 526 ( 526-2010-п ) від 30.06.2010 }

Про використання у 2010 році коштів Стабілізаційного фонду для здійснення заходів з утилізації твердого ракетного палива

Кабінет Міністрів України постановляє:

1. Виділити Національному космічному агентству на безповоротній основі 35 млн. гривень за рахунок залишку коштів Стабілізаційного фонду ( 835-17 ) станом на 1 січня 2010 р. для здійснення заходів з утилізації твердого ракетного палива (далі - кошти Стабілізаційного фонду).

2. Установити, що:

кошти Стабілізаційного фонду ( 835-17 ) спрямовуються відповідно до постанови Кабінету Міністрів України від 22 червня 2005 р. N 500 ( 500-2005-п ) "Про порядок використання коштів державного бюджету, які виділяються для утилізації твердого ракетного палива" - із змінами, внесеними постановою Кабінету Міністрів України від 10 квітня 2009 р. N 337 ( 337-2009-п ), на оплату фактично виконаних робіт з реалізації проектів, що визначені Порядком використання у 2009 році коштів Стабілізаційного фонду, передбачених для фінансування проектів, пов'язаних з утилізацією твердого ракетного палива, затвердженим постановою Кабінету Міністрів України від 10 квітня 2009 р. N 335 ( 335-2009-п );

головним розпорядником коштів Стабілізаційного фонду ( 835-17 ) є Національне космічне агентство.

3. Забезпечити після погодження з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету:

Міністерству фінансів - внесення відповідних змін до тимчасового розпису Державного бюджету України на I квартал 2010 року;

Державному казначейству - перерахування коштів Стабілізаційного фонду ( 835-17 ).
