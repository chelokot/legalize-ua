Кабінет Міністрів України; Постанова від 23.02.1999 № 255

Про посилення контролю за доставкою до митниць призначення вантажів, які переміщуються під митним контролем

Стан: Втратив чинність

Ідентифікатор: 255-99-п

Текст документа від 01.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 лютого 1999 р. N 255 Київ

Про посилення контролю за доставкою до митниць призначення вантажів, які переміщуються під митним контролем

{ Із змінами, внесеними згідно з Постановами КМ N 390 ( 390-2002-п ) від 29.03.2002 N 1016 ( 1016-2011-п ) від 05.10.2011 }

З метою посилення контролю за доставкою до митниць призначення вантажів, які переміщуються під митним контролем, та забезпечення поповнення дохідної частини державного бюджету Кабінет Міністрів України постановляє:

Установити, що вивезення за межі митної території України, а також транзит через цю територію окремих видів товарів, перелік яких визначається Державною митною службою, здійснюються за умови надання митним органам фінансових гарантій, передбачених постановами Кабінету Міністрів України від 29 червня 1996 р. N 700 ( 700-96-п ) і від 4 жовтня 1996 р. N 1216 ( 1216-96-п ), чи за умови їх охорони і супроводження силами митних органів із залученням у необхідних випадках підрозділів Міністерства внутрішніх справ або податкової міліції Державної податкової адміністрації відповідно до постанови Кабінету Міністрів України від 29 червня 1996 р. N 699 ( 699-96-п ). ( Абзац другий із змінами, внесеними згідно з Постановою КМ N 390 ( 390-2002-п ) від 29.03.2002 )

Порядок надання фінансових гарантій та порядок охорони і супроводження зазначених вантажів визначаються Міністерством фінансів залежно від митного режиму, виду товарів і виду транспорту, який використовується для переміщення цих вантажів. { Абзац другий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1016 ( 1016-2011-п ) від 05.10.2011 }
