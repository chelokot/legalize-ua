РОЗПОРЯДЖЕННЯ від 30 січня 2008 р. N 195-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 460-р ( 460-2010-р ) від 17.03.2010 }

Про перелік урядових комітетів та їх посадовий склад

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 688-р ( 688-2008-р ) від 07.05.2008 N 816-р ( 816-2008-р ) від 11.06.2008 }

1. Затвердити такий перелік урядових комітетів:

Урядовий комітет з питань економічної політики;

Урядовий комітет з питань правової політики, оборони та правоохоронної діяльності;

Урядовий комітет з питань гуманітарної та соціальної політики;

Урядовий комітет європейської інтеграції та міжнародного співробітництва.

2. Затвердити посадовий склад урядових комітетів згідно з додатками 1 - 4.

3. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України згідно з переліком, що додається.

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 30 січня 2008 р. N 195-р

ПЕРЕЛІК розпоряджень Кабінету Міністрів України, що втратили чинність

1. Розпорядження Кабінету Міністрів України від 28 березня 2007 р. N 109 ( 109-2007-р ) "Про перелік урядових комітетів та їх посадовий склад" (Офіційний вісник України, 2007 р., N 24, ст. 995).

2. Розпорядження Кабінету Міністрів України від 4 квітня 2007 р. N 131 ( 131-2007-р ) "Про доповнення додатка 2 до розпорядження Кабінету Міністрів України від 28 березня 2007 р. N 109" (Офіційний вісник України, 2007 р., N 26, ст. 1058).

3. Розпорядження Кабінету Міністрів України від 12 квітня 2007 р. N 183 ( 183-2007-р ) "Про доповнення додатка 1 до розпорядження Кабінету Міністрів України від 28 березня 2007 р. N 109" (Офіційний вісник України, 2007 р., N 28, ст. 1123).

4. Розпорядження Кабінету Міністрів України від 26 квітня 2007 р. N 225 ( 225-2007-р ) "Про доповнення додатка 1 до розпорядження Кабінету Міністрів України від 28 березня 2007 р. N 109" (Офіційний вісник України, 2007 р., N 32, ст. 1314).

5. Розпорядження Кабінету Міністрів України від 8 серпня 2007 р. N 616 ( 616-2007-р ) "Про доповнення додатка 3 до розпорядження Кабінету Міністрів України від 28 березня 2007 р. N 109" (Офіційний вісник України, 2007 р., N 59, ст. 2356).
