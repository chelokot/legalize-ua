Кабінет Міністрів України; Розпорядження від 11.11.1994 № 833-р

Про віднесення посад працівників Головної державної інспекції по нагляду за радіаційною безпекою Держатомнагляду до відповідних категорій державних службовців

Стан: Втратив чинність

Ідентифікатор: 833-94-р

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 листопада 1994 р. N 833-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади начальника Головної державної інспекції по нагляду за радіаційною безпекою Держатомнагляду, його заступників та начальників інспекцій до третьої категорії; посади начальників відділів, державних інспекторів Інспекції до четвертої категорії державних службовців.

Посади інших працівників Інспекції відносяться до відповідних категорій державних службовців міністерств.

Прем'єр-міністр України В.МАСОЛ
