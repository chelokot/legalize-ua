Про затвердження членів спостережної ради Української державної акціонерної холдингової компанії "Укрпапірпром"

Текст документа від 18.03.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 грудня 2000 р. N 1865 Київ

( Постанова втратила чинність на підставі Постанови КМ N 337 ( 337-2004-п ) від 18.03.2004 )

Про затвердження членів спостережної ради Української державної акціонерної холдингової компанії "Укрпапірпром"

Кабінет Міністрів України постановляє:

На зміну постанови Кабінету Міністрів України від 8 лютого 1997 р. N 156 ( 156-97-п ) (із змінами, внесеними постановами Кабінету Міністрів України від 22 червня 1998 р. N 938 ( 938-98-п ) та від 30 листопада 1998 р. N 1891 ( 1891-98-п ) затвердити членами спостережної ради Української державної акціонерної холдингової компанії "Укрпапірпром" Глушка Сергія Миколайовича - заступника Голови Фонду державного майна, Кальніченка Ігоря Вікторовича - заступника Голови Державної податкової адміністрації, Макацарію Сергія Мегоновича - начальника департаменту зовнішніх економічних зв'язків Міністерства фінансів, Романюка Сергія Андрійовича - керівника департаменту регіональної політики Міністерства економіки, Яковину Миколу Михайловича - радника Прем'єр-міністра України, увільнивши від цих обов'язків Войцеховського Йосипа Валентиновича, Куксенко Катерину Олексіївну, Ліпашова Віктора Олексійовича, Мирводу Володимира Дмитровича, Медведєва Юрія Серафимовича.

Прем'єр-міністр України В.ЮЩЕНКО
