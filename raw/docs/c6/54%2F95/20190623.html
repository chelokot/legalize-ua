{ Указ втратив чинність на підставі Указу Президента N 418/2019 ( 418/2019 ) від 20.06.2019 }

Про зупинення дії абзацу третього статті 2 Указу Президента України від 28 грудня 1994 року N 812

Зупинити дію абзацу третього статті 2 Указу Президента України від 28 грудня 1994 року N 812 ( 812/94 ) "Про деякі заходи щодо підтримки підприємств, установ, організацій в умовах лібералізації цін" до прийняття відповідного рішення Верховною Радою України.
