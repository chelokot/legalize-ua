Реєстрація: Мін'юст України від 24.02.2005 № 266/10546

Стан: Чинний

Текст документа від 18.02.2005:

МІНІСТЕРСТВО УКРАЇНИ У СПРАВАХ СІМ'Ї, ДІТЕЙ ТА МОЛОДІ

НАКАЗ

18.02.2005 N 72

Зареєстровано в Міністерстві юстиції України 24 лютого 2005 р. за N 266/10546

Про визнання такими, що втратили чинність, деяких наказів

Відповідно до Закону України від 18.01.2005 N 2353 ( 2353-15 ) "Про внесення змін до деяких законів України" та постанови Кабінету Міністрів України від 27.08.2004 N 1126 ( 1126-2004-п ) "Про заходи щодо вдосконалення соціальної роботи із сім'ями, дітьми та молоддю" (із змінами) НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

1.1. Наказ Міністерства України у справах молоді і спорту від 13.07.93 N 2083 ( z0192-94 ) "Про створення Українського державного центру соціальних служб для молоді", зареєстрований у Міністерстві юстиції України 11.08.94 за N 192/402.

1.2. Наказ Міністерства України у справах сім'ї та молоді від 19.05.98 N 186 ( z0367-98 ) "Про затвердження Переліку платних послуг, Положення про порядок та умови надання платних послуг", зареєстрований у Міністерстві юстиції України 05.06.98 за N 367/2807.

1.3. Наказ Державного комітету України у справах сім'ї та молоді від 04.02.2002 N 10 ( z0185-02 ) "Про затвердження Положення про Державний центр соціальних служб для молоді", зареєстрований у Міністерстві юстиції України 26.02.2002 за N 185/6473 (із змінами і доповненнями).

2. Державній соціальній службі для сім'ї, дітей та молоді:

2.1. Подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами).

2.2 Довести цей наказ до відома директорів Республіканського (Автономної Республіки Крим), обласних, Київського та Севастопольського міських, районних, районних у містах Києві та Севастополі центрів соціальних служб для сім'ї, дітей та молоді.

3. Контроль за виконанням наказу покласти на заступника Міністра, директора Державної соціальної служби для сім'ї, дітей та молоді Толстоухову С.В.
