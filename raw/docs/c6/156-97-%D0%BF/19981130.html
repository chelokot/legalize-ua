Про затвердження спостережної ради Української державної акціонерної холдингової компанії "Укрпапірпром"

( Із змінами, внесеними згідно з Постановами КМ N 811 ( 811-97-п ) від 30.07.97 N 938 ( 938-98-п ) від 22.06.98 N 1891 ( 1891-98-п ) від 30.11.98 )

Кабінет Міністрів України постановляє:

Затвердити членами спостережної ради Української державної акціонерної холдингової компанії "Укрпапірпром":

ЄМЦЯ О.І. - народного депутата України (голова ради)

МИРВОДУ В. Д. - завідуючого сектором відділу розвитку національної економіки Кабінету Міністрів України

ЛІПАШОВА В. О. - начальника управління фінансів матеріального виробництва Мініс- терства фінансів

КУКСЕНКО К. О. - начальника управління кредитування підприємств Промінвестбанку

ВОЙЦЕХОВСЬКИЙ Й. В. - директор Департаменту корпоративного управління Фонду державного майна

МЕДВЕДЄВ Ю.С. - заступник начальника Головного управління агропромислової політики - начальник відділу лісогосподарського і лісопромислового комплексів Мінекономіки

( Постанова із змінами, внесеними згідно з Постановами КМ N 811 ( 811-97-п ) від 30.07.97, N 938 ( 938-98-п ) від 22.06.98, N 1891 ( 1891-98-п ) від 30.11.98 )
