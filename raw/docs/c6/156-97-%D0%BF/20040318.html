Про затвердження спостережної ради Української державної акціонерної холдингової компанії "Укрпапірпром"

( Із змінами, внесеними згідно з Постановами КМ N 811 ( 811-97-п ) від 30.07.97 N 938 ( 938-98-п ) від 22.06.98 N 1891 ( 1891-98-п ) від 30.11.98 N 1212 ( 1212-99-п ) від 08.07.99 N 794 ( 794-2000-п ) від 15.05.2000 N 1865 ( 1865-2000-п ) від 20.12.2000 )

Кабінет Міністрів України постановляє:

Затвердити членами спостережної ради Української державної акціонерної холдингової компанії "Укрпапірпром":

САРНАЦЬКОГО Є.В. - голова ради

ГЛУШКА С.М. - заступника Голови Фонду державного майна

КАЛЬНІЧЕНКА І.В. - заступника Голови Державної податкової адміністрації

МАКАЦАРІЮ С.М. - начальника департаменту зовнішніх економічних зв'язків Міністерства фінансів

РОМАНЮКА С.А. - керівника департаменту регіональної політики Міністерства економіки

ЯКОВИНУ М.М. - радника Прем'єр-міністра України.

( Постанова із змінами, внесеними згідно з Постановами КМ N 811 ( 811-97-п ) від 30.07.97, N 938 ( 938-98-п ) від 22.06.98, N 1891 ( 1891-98-п ) від 30.11.98, N 1212 ( 1212-99-п ) від 08.07.99, N 794 ( 794-2000-п ) від 15.05.2000, N 1865 ( 1865-2000-п ) від 20.12.2000 )
