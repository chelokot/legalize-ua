{ Розпорядження скасовано на підставі Розпорядження КМ N 461-р ( 461-2010-р ) від 17.03.2010 }

Про звільнення Гончара М.В. з посади заступника Міністра транспорту та зв'язку України - голови Державної адміністрації зв'язку

Звільнити Гончара Миколу Вікторовича з посади заступника Міністра транспорту та зв'язку України - голови Державної адміністрації зв'язку ( 749-2009-р ) за одноразове грубе порушення трудових обов'язків (пункт 1 частини першої статті 41 Кодексу законів про працю України) ( 322-08 ) та за порушення Присяги державного службовця (пункт 6 частини першої статті 30 Закону України "Про державну службу") ( 3723-12 ).

Прем'єр-міністр України Ю.ТИМОШЕНКО
