Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 серпня 2006 р. N 454-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 10 липня 2006 р. N 394

1. У назві та абзаці першому пункту 1 розпорядження Кабінету Міністрів України від 10 липня 2006 р. N 394 ( 394-2006-р ) "Про встановлення строку виконання ремонтно-відновлювальних робіт для газотурбінних двигунів за межами митної території України" (Офіційний вісник України, 2006 р., N 28, ст. 2034) слова "газотурбінних двигунів" замінити словами "турбореактивних, турбогвинтових двигунів та інших газових турбін".

2. Це розпорядження набирає чинності з дня опублікування.

Прем'єр-міністр України Ю.ЄХАНУРОВ
