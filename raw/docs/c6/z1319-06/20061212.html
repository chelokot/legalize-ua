МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

12.12.2006 N 473

Зареєстровано в Міністерстві юстиції України 18 грудня 2006 р. за N 1319/13193

Про визнання такими, що втратили чинність, накази Мінпраці від 04.01.2000 N 1 та від 02.07.2004 N 147

У зв'язку із запровадженням Порядку використання коштів державного бюджету для виконання програм, пов'язаних із соціальним захистом громадян, які постраждали внаслідок Чорнобильської катастрофи, затвердженого постановою Кабінету Міністрів України від 20.09.2005 N 936 ( 936-2005-п ), та з метою уникнення дублювання нормативно-правових актів НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

наказ Міністерства праці та соціальної політики України від 04.01.2000 N 1 ( z0048-00 ) "Про затвердження Порядку виплати органами соціального захисту населення щорічної допомоги на оздоровлення громадян, які постраждали внаслідок Чорнобильської катастрофи", зареєстрований в Міністерстві юстиції України 26.01.2000 за N 48/4269;

наказ від 02.07.2004 N 147 ( z0926-04 ) "Про затвердження Порядку використання коштів Державного бюджету України на виконання програм, пов'язаних із соціальним захистом громадян, постраждалих внаслідок Чорнобильської катастрофи", зареєстрований в Міністерстві юстиції України 26.07.2004 за N 926/9525.

2. Фінансово-економічному департаменту (Л.Мосіневич) забезпечити доведення цього наказу до розпорядників бюджетних коштів нижчого рівня.

3. Контроль за виконанням цього наказу покласти на заступника Міністра К.Крищенка.
