Кабінет Міністрів України; Постанова від 16.11.2000 № 1714

Про голову української частини Міжурядової українсько-ізраїльської комісії з питань військово-технічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 1714-2000-п

Текст документа від 24.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2000 р. N 1714 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову української частини Міжурядової українсько-ізраїльської комісії з питань військово-технічного співробітництва

Кабінет Міністрів України постановляє:

Затвердити Голову Державної комісії з питань оборонно-промислового комплексу України Горбуліна Володимира Павловича головою української частини Міжурядової українсько-ізраїльської комісії з питань військово-технічного співробітництва, увільнивши від цих обов'язків Падалка Віктора Григоровича.
