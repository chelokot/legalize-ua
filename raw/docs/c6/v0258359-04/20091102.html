{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 246 ( v0246359-09 ) від 02.11.2009 }

Про норми забезпечення виборчих комісій з виборів Президента України транспортними засобами, засобами зв'язку, обладнанням, інвентарем, оргтехнікою, що підлягають поверненню органам виконавчої влади та органам місцевого самоврядування після припинення їх повноважень

З метою забезпечення належних умов діяльності виборчих комісій, відповідно до пункту 4 частини другої статті 25, частини першої статті 39 Закону України "Про вибори Президента України" ( 474-14 ), керуючись статтями 12, 13, пунктами 1, 7, 17 статті 18 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Затвердити норми забезпечення виборчих комісій з виборів Президента України транспортними засобами, засобами зв'язку, обладнанням, інвентарем, оргтехнікою, що підлягають поверненню органам виконавчої влади та органам місцевого самоврядування після припинення їх повноважень (додаються).

2. Встановити, що:

- обладнання та інвентар, придбані за рахунок коштів Державного бюджету України ( 1344-15 ), виділених на підготовку і проведення виборів Президента України, зберігаються в порядку, встановленому Центральною виборчою комісією;

- транспортні засоби, засоби зв'язку, обладнання, інвентар, оргтехніка, надані органами виконавчої влади та органами місцевого самоврядування, після припинення повноважень виборчих комісій з виборів Президента України підлягають поверненню органам виконавчої влади та органам місцевого самоврядування.

2. Цю постанову надіслати Верховній Раді Автономної Республіки Крим, обласним, Київській та Севастопольській міським радам, а також територіальним виборчим комісіям після їх утворення.

НОРМИ ЗАБЕЗПЕЧЕННЯ виборчих комісій з виборів Президента України транспортними засобами, засобами зв'язку, обладнанням, інвентарем, оргтехнікою, що підлягають поверненню органам виконавчої влади та органам місцевого самоврядування після припинення їх повноважень

1. Для територіальної виборчої комісії (одиниць):

легкові автомобілі -;

письмові столи - не менше 5;

стільці - не менше 15;

телефонні апарати - не менше 3;

факсовий апарат - 1;

ксерокс - 1;

комп'ютери - не менше 2;

друкарська машинка - 1;

сейф або металева шафа для - 1; зберігання виборчої документації

калькулятори - не менше 5;

медична аптечка - 1;

сейф або металева шафа для - 1; зберігання виборчої документації

калькулятори - не менше 3;

столи для офіційних спостерігачів - не менше 2;
