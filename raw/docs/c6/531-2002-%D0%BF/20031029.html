Стан: Втратив чинність

Текст документа від 29.10.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 квітня 2002 р. N 531 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1691 ( 1691-2003-п ) від 29.10.2003 )

Про затвердження складу Національної ради з питань безпечної життєдіяльності населення

( Щодо змін додатково див. Постанову КМ N 578 ( 578-2003-п ) від 23.04.2003 )

Кабінет Міністрів України постановляє:

1. Затвердити посадовий склад Національної ради з питань безпечної життєдіяльності населення, створеної постановою Кабінету Міністрів України від 15 вересня 1993 р. N 733 ( 733-93-п ), що додається.

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 30 березня 2000 р. N 593 ( 593-2000-п ) "Про затвердження нового складу Національної ради з питань безпечної життєдіяльності населення" (Офіційний вісник України, 2000 р., N 14, ст. 565);

пункт 2 постанови Кабінету Міністрів України від 6 червня 2000 р. N 925 ( 925-2000-п ) "Про затвердження Положення про Державний департамент з нагляду за охороною праці та включення голови зазначеного департаменту до складу Бюро Національної ради з питань безпечної життєдіяльності населення" (Офіційний вісник України, 2000 р., N 23, ст. 965).
