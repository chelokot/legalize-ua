Про медичне та матеріально-побутове обслуговування членів Кабінету Міністрів України у зв'язку з припиненням їх повноважень

Стан: Втратив чинність

Ідентифікатор: 602-92-п

Текст документа від 04.12.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 жовтня 1992 р. N 602 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 673 ( 673-2014-п ) від 26.11.2014 }

Про медичне та матеріально-побутове обслуговування членів Кабінету Міністрів України у зв'язку з припиненням їх повноважень

{ Із змінами, внесеними згідно з Постановами КМ N 357 ( 357-2000-п ) від 18.02.2000 N 1210 ( 1210-2003-п ) від 06.08.2003 }

Кабінет Міністрів України постановляє:

1. Установити, що за членами Кабінету Міністрів України у разі відставки або припинення повноважень з інших причин (крім звільнення з посади в порядку дисциплінарного стягнення) зберігається медичне та санаторно-курортне обслуговування їх і дружин, а також право користування приміщеннями в будинках відпочинку Державного управління справами на умовах, передбачених розділом II переліку, затвердженого постановою Кабінету Міністрів України від 6 серпня 2003 р. N 1210 ( 1210-2003-п ).

( Пункт 2 втратив чинність на підставі Постанови КМ N 357 ( 357-2000-п ) від 18.02.2000 )

{ Постанова із змінами, внесеними згідно з Постановою КМ N 1210 ( 1210-2003-п ) від 06.08.2003 }
