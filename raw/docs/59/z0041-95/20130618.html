Про рівень роздрібних та оптових цін і тарифів на паливно-енергетичні ресурси

( Із змінами, внесеними згідно з Наказами Мінекономіки N 62 ( z0121-95 ) від 20.04.95 N 135 ( z0307-95 ) від 14.08.95 )

З метою часткового відшкодування витрат, пов'язаних з реалізацією палива населенню, та на виконання постанови Кабінету Міністрів України від 13.02.95 р. N 109 ( 109-95-п ) "Про уточнення повноважень центральних органів державної виконавчої влади, Уряду Автономної Республіки Крим та виконкомів місцевих Рад у галузі ціноутворення", НАКАЗУЮ:

1. Затвердити Граничні розміри роздрібних цін на енергоносії і тарифи на електроенергію, що відпускаються на комунально-побутові потреби населенню, згідно з додатком 1.

2. Затвердити Тарифи на електричну енергію виробництва енергооб'єднань Міненерго України згідно з додатком 2.

Заступник Міністра В.М.Кальник
