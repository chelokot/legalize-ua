Текст документа від 24.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 лютого 2003 р. N 215 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1275 ( 1275-2005-п ) від 24.12.2005 )

Про розмір стипендій Кабінету Міністрів України для молодих учених

Кабінет Міністрів України постановляє:

1. Установити з 1 січня 2003 р. розмір стипендій Кабінету Міністрів України для молодих учених, заснованих постановою Кабінету Міністрів України від 16 серпня 1994 р. N 560 ( 560-94-п ) (ЗП України, 1994 р., N 11, ст. 285), у сумі 180 гривень.

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 18 грудня 1995 р. N 1014 ( 1014-95-п ) "Про підвищення розміру стипендій для молодих учених" (ЗП України, 1996 р., N 4, ст. 128).

постанову Кабінету Міністрів України від 28 грудня 1998 р. N 2083 ( 2083-98-п ) "Про розмір стипендії Кабінету Міністрів України для молодих учених" (Офіційний вісник України, 1998 р., N 52, ст. 1946).
