Президент України; Розпорядження, Склад колегіального органу від 20.04.2007 № 82/2007-рп

Про робочу групу з вивчення стану додержання законодавства з питань кадрового забезпечення дипломатичної служби України

Стан: Втратив чинність

Ідентифікатор: 82/2007-рп

Текст документа від 06.08.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 693/2008 ( 693/2008 ) від 06.08.2008 }

Про робочу групу з вивчення стану додержання законодавства з питань кадрового забезпечення дипломатичної служби України

1. Утворити робочу групу з вивчення стану додержання законодавства з питань кадрового забезпечення дипломатичної служби України (далі - робоча група).

2. Затвердити персональний склад робочої групи (додається).

3. Робочій групі доповісти у місячний строк про результати роботи.

4. Міністерству закордонних справ України забезпечити надання робочій групі необхідних матеріалів та документів.

Президент України В.ЮЩЕНКО

м. Київ, 20 квітня 2007 року N 82/2007-рп
