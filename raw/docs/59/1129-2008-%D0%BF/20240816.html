Про порядок придбання кондиційного і репродуктивного насіння для культивування рослин, що містять малі кількості наркотичних речовин, для промислових цілей

Стан: Втратив чинність

Ідентифікатор: 1129-2008-п

Текст документа від 16.08.2024:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 грудня 2008 р. N 1129 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 776 ( 776-2024-п ) від 21.06.2024 }

Про порядок придбання кондиційного і репродуктивного насіння для культивування рослин, що містять малі кількості наркотичних речовин, для промислових цілей

Відповідно до статті 15 Закону України "Про наркотичні засоби, психотропні речовини і прекурсори" ( 60/95-ВР ) Кабінет Міністрів України постановляє:

Установити, що кондиційне і репродуктивне насіння маку снотворного та рослин роду конопель, внесених до Реєстру сортів рослин України, відповідно не нижче першої та другої репродукції придбавається суб'єктами господарювання у суб'єктів насінництва та розсадництва, занесених до Державного реєстру виробників насіння і садивного матеріалу, для культивування включених до списку N 3 таблиці I переліку наркотичних засобів, психотропних речовин і прекурсорів, затвердженого постановою Кабінету Міністрів України від 6 травня 2000 р. N 770 ( 770-2000-п ) (Офіційний вісник України, 2000 р., N 19, ст. 789), рослин, що містять малі кількості наркотичних речовин, для промислових цілей на договірних умовах.

Прем'єр-міністр України Ю.ТИМОШЕНКО
