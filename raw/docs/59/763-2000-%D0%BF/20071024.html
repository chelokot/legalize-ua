{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про затвердження складу Міжвідомчої комісії з реалізації реформи житлово-комунального господарства

Кабінет Міністрів України постановляє:

На часткову зміну пункту 1 постанови Кабінету Міністрів України від 1 грудня 1999 р. N 2194 ( 2194-99-п ) "Про створення Міжвідомчої комісії з реалізації реформи житлово-комунального господарства" (Офіційний вісник України, 1999 р., N 48, ст. 2374) затвердити склад Міжвідомчої комісії з реалізації реформи житлово-комунального господарства, що додається.
