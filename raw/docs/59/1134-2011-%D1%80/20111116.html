Про надання гуманітарної допомоги Турецькій Республіці

Стан: Чинний

Ідентифікатор: 1134-2011-р

Текст документа від 16.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 жовтня 2011 р. N 1134-р Київ

Про надання гуманітарної допомоги Турецькій Республіці

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1218-р ( 1218-2011-р ) від 16.11.2011 }

З метою сприяння в подоланні наслідків надзвичайної ситуації, що сталася в Турецькій Республіці внаслідок землетрусу, на виконання Указу Президента України від 24 жовтня 2011 р. N 1002 ( 1002/2011 ) "Про надання гуманітарної допомоги Турецькій Республіці":

1. Міністерству надзвичайних ситуацій:

надати як гуманітарну допомогу Турецькій Республіці матеріальні цінності відповідно до наказу Міністерства надзвичайних ситуацій;

забезпечити доставку вантажу гуманітарної допомоги до Турецької Республіки літаком Міністерства надзвичайних ситуацій.

2. Виділити Міністерству надзвичайних ситуацій 3272,397 тис. гривень для закупівлі матеріальних цінностей, що будуть надаватись як гуманітарна допомога, та відшкодування витрат, пов'язаних з її наданням.

Міністерству фінансів здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 1218-р ( 1218-2011-р ) від 16.11.2011 }

3. Міністерству надзвичайних ситуацій узгодити з Міністерством фінансів та Міністерством економічного розвитку і торгівлі перелік витрат, пов'язаних з наданням гуманітарної допомоги.

4. Міністерству закордонних справ узгодити з відповідними органами Турецької Республіки організаційні питання, пов'язані з наданням гуманітарної допомоги.

5. Державній митній службі забезпечити оперативне митне оформлення вантажу гуманітарної допомоги, а Адміністрації Державної прикордонної служби - першочергове здійснення контролю під час його перевезення через державний кордон.

6. Міністерству надзвичайних ситуацій подати до 28 грудня 2011 р. Міністерству економічного розвитку і торгівлі, Міністерству фінансів та Державній казначейській службі звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України М.АЗАРОВ
