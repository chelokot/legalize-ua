Кабінет Міністрів України; Розпорядження від 28.10.1999 № 1156-р

Про дозвіл Держмитслужбі здійснити митне оформлення обладнання, що надходить для Луганської обласної державної телерадіокомпанії та Київської державної регіональної телерадіокомпанії

Стан: Втратив чинність

Ідентифікатор: 1156-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 жовтня 1999 р. N 1156-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення обладнання, що надходить:

для Луганської обласної державної телерадіокомпанії згідно з контрактом від 1 липня 1999 р. N PBDS-99-6-22-3/1, укладеним з фірмою "Панасонік Бродкаст Європа Лтд.", та Кіровоградської обласної державної телерадіокомпанії згідно з контрактом від 20 серпня 1999 р. N PBDS-99-6-22-3/11, укладеним з фірмою "Панасонік Бродкаст Європа Лтд.", як товарів критичного імпорту без справляння митних зборів з нарахуванням ввізного мита за ставкою 0,01 відсотка митної вартості;

для Київської державної регіональної телерадіокомпанії згідно з контрактом від 13 вересня 1999 р. N SYS-1309, укладеним з фірмою "Систек Інтернейшнл Інк.", як товарів критичного імпорту без справляння митних зборів.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
