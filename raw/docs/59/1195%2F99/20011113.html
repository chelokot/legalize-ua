Президент України; Указ від 17.09.1999 № 1195/99

Про зміни у складі Всеукраїнської координаційної ради з питань розвитку духовності, захисту моралі та формування здорового способу життя громадян

Стан: Втратив чинність

Ідентифікатор: 1195/99

Текст документа від 13.11.2001:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про зміни у складі Всеукраїнської координаційної ради з питань розвитку духовності, захисту моралі та формування здорового способу життя громадян

Увести до складу Всеукраїнської координаційної ради з питань розвитку духовності, захисту моралі та формування здорового способу життя громадян, затвердженого Указом Президента України від 27 квітня 1999 року N 456 ( 456/99 ), СЕМИНОЖЕНКА Володимира Петровича - Віце-прем'єр-міністра України та призначити його головою Ради, увільнивши від виконання цих обов'язків В. Смолія.

Президент України Л.КУЧМА

м. Київ, 17 вересня 1999 року N 1195/99
