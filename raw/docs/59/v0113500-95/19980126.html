НАЦІОНАЛЬНИЙ БАНК УКРАЇНИ Правління Національного банку України

ПОСТАНОВА

N 113 від 15.05.95 м.Київ

( Постанова втратила чинність на підставі Постанови Нацбанку N 22 ( v0518500-98 ) від 26.01.98 )

Про внесення змін і доповнень до нормативних актів Національного банку України

( Зміни в текст не внесено. Додатково див. Постанову Нацбанку N 168 ( v0168500-95 ) від 30.06.95 Лист Нацбанку N 14-011/66-257 ( v-257500-97 ) від 14.01.97 Документ Нацбанку N 31 ( v0423500-97 ) від 10.02.97 )

Розглянувши доповідну записку юридичного департаменту щодо внесення змін і доповнень до окремих нормативних актів Національного банку України, Правління ПОСТАНОВЛЯЄ:

1. У Положенні про економічні нормативи регулювання діяльності комерційних банків, затвердженому постановою Правління Національного банку України N 114 від 21.12.93 р.:

виключити абзац другий пункту 11;

виключити друге речення у пунктах 12 і 13;

виключити пункт 14.

2. Скасувати лист Національного банку України від 11.11.94 р. N 209 ( v0209500-94 ).

3. Абзац десятий Порядку формування комерційними банками обов'язкових резервів, затвердженого постановою Правління Національного банку України 22.02.94 р. N 34 ( v-900500-94 ), викласти в такій редакції:

"При тимчасовому запозиченні комерційним банком коштів із резервних вимог для здійснення безперебійних платежів за вимогами клієнтітв, коли фактична середньоарифметична сума залишків коштів на коррахунку за визначений період (декаду) буде меншою від розміру встановленої норми обов'язкових резервів відносно залучених комерційним банком коштів, Національний банк України встановлює для комерційних банків таку плату:

- при попередньому узгодженні запозичення з регіональним управлінням Національного банку України - в розмірі діючої ставки рефінансування Національного банку України;

- без узгодження або систематичному порушенні - в розмірі подвійної ставки рефінансування Національного банку України".

Скасувати абзац шостий листа від 23.02.94 р. N 105-900 ( v-900500-94 ), яким згаданий Порядок доведений до обласних управлінь Національного банку України і комерційних банків.

4. Пункт 16 Тимчасового порядку довгострокового рефінансування Національним банком України комерційних банків від 15.09.92 р. викласти в такій редакції:

"Республіканському банку Криму, регіональним управлінням Національного банку України передбачати в кредитних угодах, що у разі нецільового використання централізованих кредитів, з комерційного банку стягується штраф в розмірі 5% від суми нецільового використання кредиту".

Голова Правління В.А.Ющенко
