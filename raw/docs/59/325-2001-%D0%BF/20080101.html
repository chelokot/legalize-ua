Про встановлення надбавок до посадових окладів державних експертів з питань таємниць

Стан: Втратив чинність

Ідентифікатор: 325-2001-п

Текст документа від 01.01.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 квітня 2001 р. N 325 Київ

Про встановлення надбавок до посадових окладів державних експертів з питань таємниць

{ Із змінами, внесеними згідно з Постановою КМ N 1294 ( 1294-2007-п ) від 07.11.2007 }

Кабінет Міністрів України постановляє:

1. Установити державним експертам з питань таємниць надбавки у розмірі 20 відсотків посадового окладу.

2. Витрати на виплату визначених у пункті 1 цієї постанови надбавок здійснювати в межах коштів, передбачених на оплату праці працівників відповідних державних органів, підприємств, установ і організацій.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 1294 ( 1294-2007-п ) від 07.11.2007 }

4. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

Перший віце-прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 29

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 4 квітня 2001 р. N 325

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 28 грудня 1995 р. N 1067 ( 1067-95-п ) "Про встановлення надбавок до посадових окладів державних експертів з питань таємниць".

2. Постанова Кабінету Міністрів України від 20 грудня 1997 р. N 1429 ( 1429-97-п ) "Про внесення змін і доповнень до постанови Кабінету Міністрів України від 28 грудня 1995 р. N 1067".

3. Постанова Кабінету Міністрів України від 7 квітня 1998 р. N 467 ( 467-98-п ) "Про внесення змін до постанови Кабінету Міністрів України від 28 грудня 1995 р. N 1067".

4. Постанова Кабінету Міністрів України від 7 червня 1999 р. N 990 ( 990-99-п ) "Про внесення змін до постанови Кабінету Міністрів України від 28 грудня 1995 р. N 1067".

5. Постанова Кабінету Міністрів України від 20 жовтня 1999 р. N 1940 ( 1940-99-п ) "Про внесення змін в додаток до постанови Кабінету Міністрів України від 28 грудня 1995 р. N 1067".
