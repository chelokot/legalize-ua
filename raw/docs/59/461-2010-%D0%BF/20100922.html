ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 16 червня 2010 р. N 461

ПОРЯДОК використання у 2010 році коштів Стабілізаційного фонду ( 2154-17 ), передбачених для реалізації Загальнодержавної програми реформування і розвитку житлово-комунального господарства на 2009-2014 роки ( 1869-15 ) та Загальнодержавної програми "Питна вода України" на 2006-2020 роки ( 2455-15 )

1. Цей Порядок визначає механізм використання у 2010 році коштів Стабілізаційного фонду, передбачених пунктом 8 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) для реалізації Загальнодержавної програми реформування і розвитку житлово-комунального господарства на 2009-2014 роки ( 1869-15 ) та Загальнодержавної програми "Питна вода України" на 2006-2020 роки ( 2455-15 ) (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Мінжитлокомунгосп.

3. Мінжитлокомунгосп спрямовує бюджетні кошти на безповоротній основі структурним підрозділам з питань житлово-комунального господарства Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських держадміністрацій як розпорядникам бюджетних коштів нижчого рівня та суб'єктам господарювання державної або комунальної форми власності як одержувачам бюджетних коштів.

Джерелами покриття бюджетних коштів є надходження від цільового розміщення державних цінних паперів, приватизації державного майна та інші надходження, безпосередньо пов'язані з процесом приватизації та кредитування підприємств, а також кошти, які надходитимуть від сплати штрафів, пені та неустойки за невиконання власниками приватизованих об'єктів умов договорів купівлі-продажу, а у разі їх недостатності - кошти, отримані від продажу земельних ділянок несільськогосподарського призначення, що перебувають у державній власності, на яких розміщено об'єкти, що підлягають приватизації, або від повернення коштів, які надавалися на поворотній основі. { Пункт 3 доповнено абзацом згідно з Постановою КМ N 582 ( 582-2010-п ) від 14.07.2010 }

4. Бюджетні кошти спрямовуються на реалізацію Загальнодержавної програми "Питна вода України" на 2006-2020 роки ( 2455-15 ), зокрема на здійснення заходів щодо розвитку та реконструкції систем водопостачання та водовідведення, у тому числі впровадження колективних установок (пристроїв) доочищення води для питних потреб, в Автономній Республіці Крим в сумі 11228 тис. гривень, Луганській області - 11610,7 тис. гривень. { Абзац перший пункту 4 із змінами, внесеними згідно з Постановою КМ N 761 ( 761-2010-п ) від 18.08.2010; в редакції Постанови КМ N 853 ( 853-2010-п ) від 08.09.2010 }

Рада міністрів Автономної Республіки Крим та Луганська облдержадміністрація вносять до 15 вересня 2010 р. Мінжитлокомунгоспу пропозиції щодо потреби в коштах у розрізі інвестиційних проектів, спрямованих на доведення якості питної води до нормативних вимог та/або забезпечення цілодобового її постачання. { Абзац другий пункту 4 із змінами, внесеними згідно з Постановою КМ N 761 ( 761-2010-п ) від 18.08.2010; в редакції Постанови КМ N 853 ( 853-2010-п ) від 08.09.2010 }

Основними критеріями відбору інвестиційних проектів є:

наявність затвердженої в установленому порядку проектно-кошторисної документації;

відхилення в якості питної води у конкретному населеному пункті від вимог державного стандарту на питну воду, підтверджене в установленому законодавством порядку;

завершення реалізації інвестиційного проекту (етапу проекту) в 2010 році;

співфінансування з місцевих бюджетів та/або інших джерел;

{ Абзац восьмий пункту 4 виключено на підставі Постанови КМ N 761 ( 761-2010-п ) від 18.08.2010 }

Мінжитлокомунгосп з урахуванням поданих пропозицій затверджує за погодженням з Мінфіном розподіл бюджетних коштів між структурними підрозділами з питань житлово-комунального господарства Ради міністрів Автономної Республіки Крим та Луганської облдержадміністрації. { Пункт 4 доповнено абзацом згідно з Постановою КМ N 853 ( 853-2010-п ) від 08.09.2010 }

5. Бюджетні кошти спрямовуються на реалізацію Загальнодержавної програми реформування і розвитку житлово-комунального господарства на 2009-2014 роки ( 1869-15 ), зокрема на здійснення заходів щодо:

1) погашення бюджетної кредиторської заборгованості за виконані роботи, що виникла у 2007-2009 роках за бюджетними програмами "Ремонт і реконструкція теплових мереж та котелень", "Загальнодержавна програма реформування і розвитку житлово-комунального господарства" та "Відшкодування відсоткової ставки по кредитах, спрямованих на реалізацію проектів з енергозбереження в житлово-комунальному господарстві", - у сумі 41350 тис. гривень;

2) реконструкції та капітального ремонту житлових будинків із застосуванням енергозберігаючих технологій і обладнання (ремонт або заміна ліфтів, які перебувають в аварійному стані) - у сумі 43653 тис. гривень;

{ Підпункт 2 пункту 5 із змінами, внесеними згідно з Постановою КМ N 761 ( 761-2010-п ) від 18.08.2010 }

3) реконструкції централізованих систем водопостачання і водовідведення з використанням енергоощадного обладнання та технологій - у сумі 84755,3 тис. гривень;

{ Підпункт 3 пункту 5 в редакції Постанови КМ N 761 ( 761-2010-п ) від 18.08.2010 }

4) енергозбереження, розвитку та реконструкції систем теплопостачання - у сумі 151712 тис. гривень;

{ Підпункт 4 пункту 5 із змінами, внесеними згідно з Постановою КМ N 761 ( 761-2010-п ) від 18.08.2010 }

{ Підпункт 5 пункту 5 виключено на підставі Постанови КМ N 761 ( 761-2010-п ) від 18.08.2010 }

{ Підпункт 6 пункту 5 виключено на підставі Постанови КМ N 761 ( 761-2010-п ) від 18.08.2010 }

7) надання державної підтримки для реалізації інвестиційних проектів:

з технічного переоснащення та капітального ремонту житлових будинків (зданих в експлуатацію до 1 січня 1989 р.), в яких утворюються нові або вже функціонують об'єднання співвласників багатоквартирних будинків, - у сумі 105742,5 тис. гривень; { Абзац другий підпункту 7 пункту 5 із змінами, внесеними згідно з Постановою КМ N 761 ( 761-2010-п ) від 18.08.2010 }

{ Абзац третій підпункту 7 пункту 5 виключено на підставі Постанови КМ N 761 ( 761-2010-п ) від 18.08.2010 }

з технічного переоснащення та капітального ремонту ліфтів у житлових будинках, в яких утворюються нові або вже функціонують об'єднання співвласників багатоквартирних будинків, - у сумі 40909,2 тис. гривень; { Абзац четвертий підпункту 7 пункту 5 із змінами, внесеними згідно з Постановою КМ N 761 ( 761-2010-п ) від 18.08.2010 }

{ Підпункт 8 пункту 5 виключено на підставі Постанови КМ N 761 ( 761-2010-п ) від 18.08.2010 }

9) забезпечення широкої громадської підтримки державної політики реформування і розвитку житлово-комунального господарства - у сумі 650 тис. гривень;

{ Підпункт 9 пункту 5 із змінами, внесеними згідно з Постановою КМ N 761 ( 761-2010-п ) від 18.08.2010 }

10) реалізації пілотних проектів у сфері житлово-комунального господарства, спрямованих на удосконалення системи управління житловим фондом, скорочення питомих показників використання енергетичних і матеріальних ресурсів, у тому числі щодо впровадження використання альтернативних джерел енергії та видів палива, - у сумі 20000 тис. гривень, з яких до 10 відсотків - на виготовлення проектно-кошторисної документації (стадія "робочий проект").

6. Бюджетні кошти спрямовуються на реалізацію Загальнодержавної програми реформування і розвитку житлово-комунального господарства на 2009-2014 роки ( 1869-15 ), зокрема на здійснення заходів, зазначених в підпунктах 2-7 пункту 5 цього Порядку, з урахуванням розподілу згідно з додатком 2.

Рада міністрів Автономної Республіки Крим, обласні, Київська та Севастопольська міські держадміністрації вносять до 20 липня 2010 р. Мінжитлокомунгоспу пропозиції щодо потреби в коштах у розрізі заходів, населених пунктів та інвестиційних проектів або об'єктів.

Мінжитлокомунгосп з урахуванням зазначених пропозицій затверджує за погодженням з Мінфіном розподіл бюджетних коштів між структурними підрозділами з питань житлово-комунального господарства Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських держадміністрацій.

7. Рішення про виділення бюджетних коштів для здійснення заходів, зазначених у підпунктах 2-6 і 10 пункту 5 цього Порядку, приймається Мінжитлокомунгоспом у разі, коли підтверджено співфінансування з місцевих бюджетів та/або інших джерел (подано завірені в установленому порядку копії виписок з рахунків, відкритих в органах Державного казначейства чи установах банків, та/або первинних бухгалтерських документів з урахуванням витрат, пов'язаних з виготовленням проектно-кошторисної документації), у такому співвідношенні:

для інвестиційних проектів, що реалізуються у мм. Києві, Севастополі, Сімферополі та обласних центрах, - не менш як 70 відсотків суми бюджетних коштів;

для інвестиційних проектів, що реалізуються в містах республіканського Автономної Республіки Крим та обласного значення, - не менш як 40 відсотків суми бюджетних коштів;

для інвестиційних проектів, що реалізуються в інших населених пунктах, - не менш як 10 відсотків суми бюджетних коштів.

8. Обов'язковими умовами виділення бюджетних коштів є:

1) для здійснення заходів, зазначених у підпункті 3 пункту 5 цього Порядку:

наявність регіональних та/або місцевих програм (заходів) щодо забезпечення населення якісною питною водою в достатній кількості;

наявність затвердженої в установленому порядку проектно-кошторисної документації;

завершення реалізації інвестиційного проекту (етапу проекту) в 2010 році;

період окупності інвестиційного проекту не більш як чотири роки;

2) для здійснення заходів, зазначених у підпункті 4 пункту 5 цього Порядку:

наявність регіональних програм модернізації систем теплозабезпечення;

наявність схем теплопостачання;

наявність затвердженої в установленому порядку проектно-кошторисної документації;

завершення реалізації інвестиційного проекту (етапу проекту) в 2010 році;

період окупності інвестиційного проекту не більш як чотири роки.

9. Конкурсний відбір інвестиційних проектів відповідно до заходів, зазначених у підпунктах 8 і 10 пункту 5 цього Порядку, проводиться міжвідомчими комісіями, які утворюються Мінжитлокомунгоспом з представників Мінфіну, Мінекономіки, НАЕР та Національної академії наук.

Порядок конкурсного відбору інвестиційних проектів затверджується міжвідомчою комісією.

Мінжитлокомунгосп затверджує на підставі рішень міжвідомчих комісій перелік інвестиційних проектів (техніко-економічних обґрунтувань у разі спрямування бюджетних коштів на виготовлення проектно-кошторисної документації) та обсяги їх фінансування за рахунок бюджетних коштів.

{ Пункт 10 виключено на підставі Постанови КМ N 761 ( 761-2010-п ) від 18.08.2010 }

11. До конкурсного відбору допускаються суб'єкти господарювання державної та комунальної форми власності, які реалізують інвестиційні проекти відповідно до заходу, зазначеного у підпункті 10 пункту 5 цього Порядку, та отримали позитивний експертний висновок НАЕР про відповідність інвестиційного проекту вимогам законодавства про енергозбереження.

До конкурсного відбору не допускаються суб'єкти господарювання:

які отримують кошти для реалізації інвестиційних проектів відповідно до інших бюджетних програм та субвенцій;

які реалізують інвестиційні проекти з періодом окупності більш як п'ять років.

Мінжитлокомунгосп у межах бюджетних коштів, передбачених для здійснення зазначеного заходу, укладає із суб'єктом господарювання, який є переможцем конкурсу, договір про надання бюджетних коштів на умовах співфінансування з місцевих бюджетів та/або інших джерел, в якому зазначаються:

частка співфінансування;

період реалізації інвестиційного проекту;

механізм повернення бюджетних коштів у разі невиконання суб'єктом господарювання умов договору;

зобов'язання суб'єкта господарювання щодо завершення у 2011 році реалізації інвестиційного проекту (етапу проекту) за рахунок власних коштів у разі, коли він не забезпечує завершення реалізації інвестиційного проекту (етапу проекту) до 31 грудня 2010 року.

Перерахування бюджетних коштів Мінжитлокомунгоспом здійснюється на підставі укладеного договору.

12. Технічний нагляд під час будівництва (реконструкції) об'єктів за рахунок бюджетних коштів здійснюється за погодженням з Мінжитлокомунгоспом.

13. Мінфін визначає за Мінжитлокомунгоспом бюджетні програми і закріплює за ними коди програмної та функціональної класифікації видатків і кредитування бюджету та вносить в установленому порядку зміни до розпису державного бюджету.

14. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

15. Основні фонди, придбані (модернізовані) за рахунок бюджетних коштів, в обов'язковому порядку вводяться в експлуатацію та зараховуються на баланс балансоутримувача об'єкта.

16. Бюджетні кошти не виділяються суб'єктам господарювання, яких визнано банкрутами, щодо яких порушено справу про банкрутство, проводиться санація або які ліквідуються.

17. Бюджетні кошти, що обліковуються на відкритих в органах Державного казначейства рахунках головного розпорядника або одержувачів бюджетних коштів і не використані станом на 1 січня 2011 р., підлягають поверненню до Стабілізаційного фонду.

18. Мінжитлокомунгосп подає щомісяця до 5 числа Мінфіну звіт про використання бюджетних коштів за формою, встановленою Мінфіном.

19. Контроль за цільовим та ефективним використанням бюджетних коштів здійснюється відповідно до законодавства.
