Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для забезпечення житлом учених Національної академії наук

Стан: Чинний

Ідентифікатор: 652-2008-п

Текст документа від 17.10.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 липня 2008 р. N 652 Київ

Про затвердження Порядку використання у 2008 році коштів, передбачених у державному бюджеті для забезпечення житлом учених Національної академії наук

{ Із змінами, внесеними згідно з Постановою КМ N 896 ( 896-2008-п ) від 08.10.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для забезпечення житлом учених Національної академії наук, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 16 липня 2008 р. N 652

ПОРЯДОК використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для забезпечення житлом учених Національної академії наук

1. Цей Порядок визначає механізм використання у 2008 році коштів, передбачених Національній академії наук у державному бюджеті ( 107-17 ) за програмою "Забезпечення житлом для вчених Національної академії наук України" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Національна академія наук, розпорядниками бюджетних коштів нижчого рівня - наукові установи, що належать до відання Національної академії наук.

3. Бюджетні кошти спрямовуються на будівництво житла на умовах пайової участі та придбання житла на ринку.

{ Пункт 3 в редакції Постанови КМ N 896 ( 896-2008-п ) від 08.10.2008 }

4. Побудоване житло використовується як службове в установленому законодавством порядку.

5. Національна академія наук здійснює розподіл бюджетних коштів між їх розпорядниками.

6. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється відповідно до законодавства.

7. Договір про будівництво житла укладається щодо об'єкта незавершеного будівництва за умови введення його в експлуатацію у 2008-2009 роках.

8. Рішення про будівництво житла на умовах пайової участі та придбання житла на ринку приймають розпорядники коштів за результатами відкритих торгів. Вартість 1 кв. метра загальної площі житла повинна включати витрати з будівництва житлового будинку, облаштування внутрішньомайданчикових інженерних мереж і упорядження території.

{ Пункт 8 в редакції Постанови КМ N 896 ( 896-2008-п ) від 08.10.2008 }

9. Операції, пов'язані з використанням бюджетних коштів, проводяться у порядку, встановленому Державним казначейством.

10. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
