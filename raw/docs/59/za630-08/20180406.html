Стан: Втратив чинність

Ідентифікатор: za630-08

Текст документа від 06.04.2018:

МІНІСТЕРСТВО ВНУТРІШНІХ СПРАВ УКРАЇНИ

НАКАЗ

10.06.2008 N 283

Зареєстровано в Міністерстві юстиції України 10 липня 2008 р. за N 630/15321

{ Наказ втратив чинність на підставі Наказу Міністерства внутрішніх справ N 147 ( za325-18 ) від 27.02.2018 }

Про затвердження Інструкції про порядок взаємодії Державної інспекції зв'язку, Українського державного центру радіочастот та органів внутрішніх справ України з питань запобігання, виявлення та припинення порушень законодавства в галузі зв'язку

Відповідно до статей 10,11 Закону України "Про міліцію" ( 565-12 ), статті 265 Кодексу України про адміністративні правопорушення ( 80731-10 ) та з метою вдосконалення порядку взаємодії Державної інспекції зв'язку та її регіональних підрозділів, Українського державного центру радіочастот та його філій з органами внутрішніх справ України НАКАЗУЮ:

1. Затвердити Інструкцію про порядок взаємодії Державної інспекції зв'язку, Українського державного центру радіочастот та органів внутрішніх справ України щодо запобігання, виявлення та припинення порушень законодавства в галузі зв'язку ( z0630-08 ) (далі - Інструкція) (додається).

2. Начальникам головних управлінь, управлінь МВС України в Автономній Республіці Крим, областях, містах Києві та Севастополі:

2.1. Організувати вивчення Інструкції ( z0630-08 ) в системі службової підготовки та забезпечити контроль за її виконанням.

2.2. Забезпечити протягом місяця від дня реєстрації Інструкції ( z0630-08 ) в Міністерстві юстиції України створення координаційних комісій щодо запобігання порушенням законодавства в галузі зв'язку.

3. Департаменту зв'язку (Деконенко С.О.) спільно з Міністерством транспорту та зв'язку України підготувати наказ про втрату чинності спільного наказ від 25.11.2002 N 223/1205 ( z0968-02 ), зареєстрованого в Міністерстві юстиції України 13.12.2002 за N 968/7256.

4. Контроль за виконанням наказу покласти на заступника Міністра Хоменка В.П.

5. Наказ надіслати за належністю.

Т.в.о. Міністра генерал-лейтенант міліції М.М.Клюєв
