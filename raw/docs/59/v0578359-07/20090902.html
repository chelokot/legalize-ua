Про форми подань відомостей про виборців (осіб), на підставі яких здійснюється періодичне поновлення персональних даних Державного реєстру виборців

Стан: Втратив чинність

Ідентифікатор: v0578359-07

Текст документа від 02.09.2009:

ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

ПОСТАНОВА

27.12.2007 N 578

Про форми подань відомостей про виборців (осіб), на підставі яких здійснюється періодичне поновлення персональних даних Державного реєстру виборців

{ Із змінами, внесеними згідно з Постановами Центральної виборчої комісії N 117 ( v0117359-09 ) від 19.08.2009 N 122 ( v0122359-09 ) від 02.09.2009 }

З метою забезпечення здійснення щоквартального поновлення бази даних Державного реєстру виборців, відповідно до пунктів 2, 6 частини другої, частин третьої, п'ятої - одинадцятої статті 14, частин першої - одинадцятої статті 22 Закону України "Про Державний реєстр виборців" ( 698-16 ), керуючись статтею 12, пунктом 8 статті 17 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Встановити форми подань відомостей про виборців (осіб), на підставі яких здійснюється періодичне поновлення персональних даних Державного реєстру виборців органами ведення Реєстру (додатки 1-23 ( va578359-07 ).

2. Встановити зразок супровідного листа до подань відомостей про виборців (осіб) (додаток 24 ( va578359-07 ).

3. Подання з відомостями про виборців (осіб) за вказаними формами подань здійснюється на паперовому носії формату А-4 з одностороннім друком, до якого додається диск CD-R із електронним файлом зазначеного документа, сформованим програмними засобами Microsoft Excel із застосуванням таблиці кодування символів WIN1251.

У супровідному листі (додаток 24) до органу Державного реєстру виборців, повноваження якого поширюються на територію, де розташовані суб'єкти подання відомостей про виборців (осіб), визначені статтею 22 Закону України "Про Державний реєстр виборців" ( 698-16 ), зазначається про відсутність інших відомостей, які мають бути подані за відповідний період.

У разі відсутності відомостей про виборців (осіб) суб'єкти подання відомостей письмово повідомляють орган ведення Державного реєстру виборців, повноваження якого поширюються на територію, де розташовані зазначені суб'єкти, про відсутність відомостей про виборців (осіб).

{ Пункт 3 в редакції Постанови Центральної виборчої комісії N 122 ( v0122359-09 ) від 02.09.2009 }

4. Керівник відповідного районного (міського, районного у місті) органу Міністерства юстиції України подає відомості про виборців до органу ведення Державного реєстру виборців, повноваження якого поширюються на територію району, міста, району в місті, де зареєстровано місце проживання (адреса житла) виборців відповідно до Закону України "Про свободу пересування та вільний вибір місця проживання в Україні" ( 1382-15 ), і який відповідно до частини другої статті 15 Закону України "Про Державний реєстр виборців" ( 698-16 ) має доступ в режимі записування до записів Державного реєстру виборців щодо таких виборців.

{ Постанову доповнено пунктом 4 згідно з Постановою Центральної виборчої комісії N 122 ( v0122359-09 ) від 02.09.2009 }

5. Міністерству внутрішніх справ України, Міністерству закордонних справ України, Міністерству юстиції України, Міністерству оборони України, Міністерству праці та соціальної політики України, Державному департаменту України з питань виконання покарань цю постанову довести до відома відповідних підрозділів, закладів і установ та забезпечити контроль за її дотриманням.

6. Виборчій комісії Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям цю постанову довести до відома відповідних органів ведення Державного реєстру виборців та забезпечити контроль за її дотриманням.

7. Цю постанову надіслати Міністерству внутрішніх справ України, Міністерству закордонних справ України, Міністерству юстиції України, Міністерству оборони України, Міністерству праці та соціальної політики України, Державному департаменту України з питань виконання покарань, виборчій комісії Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям.
