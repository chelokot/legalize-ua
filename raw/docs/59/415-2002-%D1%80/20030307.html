Кабінет Міністрів України; Розпорядження від 25.07.2002 № 415-р

Про передачу повноважень з управління державними корпоративними правами ВАТ "Миколаївська ТЕЦ" Миколаївській міській раді

Стан: Втратив чинність

Ідентифікатор: 415-2002-р

Текст документа від 07.03.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 липня 2002 р. N 415-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 301 ( 301-2003-п ) від 07.03.2003 )

Про передачу повноважень з управління державними корпоративними правами ВАТ "Миколаївська ТЕЦ" Миколаївській міській раді

1. Прийняти пропозицію Миколаївської міської ради, погоджену з Мінпаливенерго, Миколаївською облдержадміністрацією, Фондом державного майна, Мінекономіки, Мінфіном та Держкомстатом, про передачу повноважень з управління державними корпоративними правами ВАТ "Миколаївська ТЕЦ" Миколаївській міській раді.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 14 лютого 2002 р. N 114 ( 114-2002-р ) "Про передачу Миколаївської ТЕЦ у користування територіальній громаді м. Миколаєва".

Прем'єр-міністр України А.КІНАХ
