МІНІСТЕРСТВО ЕКОЛОГІЇ ТА ПРИРОДНИХ РЕСУРСІВ УКРАЇНИ МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ ДЕРЖАВНА ПОДАТКОВА АДМІНІСТРАЦІЯ УКРАЇНИ

НАКАЗ

20.01.2011 N 23/8/34

Зареєстровано в Міністерстві юстиції України 31 січня 2011 р. за N 126/18864

Про визнання такими, що втратили чинність, деяких наказів Міністерства охорони навколишнього природного середовища та ядерної безпеки України, Міністерства праці та соціальної політики України, Державної податкової адміністрації України, Державного комітету України по геології і використанню надр

З метою приведення нормативно-правових актів у відповідність до Податкового кодексу України ( 2755-17 ) НАКАЗУЄМО:

1. Визнати такими, що втратили чинність, накази Міністерства охорони навколишнього природного середовища та ядерної безпеки України, Міністерства праці та соціальної політики України, Державної податкової адміністрації України, Державного комітету України по геології і використанню надр від 30.12.97 N 207/472/51/157 ( z0020-98 ) "Про затвердження Інструкції про порядок обчислення і справляння платежів за користування надрами для видобування корисних копалин", зареєстрований у Міністерстві юстиції України 16.01.98 за N 20/2460; від 07.04.99 N 79/187/51/57 ( z0263-99 ) "Про затвердження Методики розрахунку платежів за користування надрами для видобування урану, сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння), виробної (виробне каміння) та облицьовувальних матеріалів і внесення змін до Інструкції про порядок обчислення та справляння платежів за користування надрами для видобування корисних копалин, затвердженої наказом Мінекобезпеки, ДПА, Держкомгеології, Мінпраці від 30.12.97 N 207/472/51/157 та зареєстрованої в Мін'юсті 16.01.98 за N 20/2460", зареєстрований в Міністерстві юстиції України 27.04.99 за N 263/3556; накази Міністерства екології та природних ресурсів України, Міністерства фінансів України, Державної податкової адміністрації України, Міністерства праці та соціальної політики України від 13.06.2000 N 51/128/307/128 ( z0383-00 ) "Про внесення змін та доповнень до Інструкції про порядок обчислення і справляння платежів за користування надрами для видобування корисних копалин", зареєстрований в Міністерстві юстиції України 03.07.2000 за N 383/4604; від 09.01.2002 N 8/9/13/10 ( z0076-02 ) "Про внесення змін і доповнень до Інструкції про порядок обчислення і справляння плати за користування надрами для видобування корисних копалин", зареєстрований в Міністерстві юстиції України 29.01.2002 за N 76/6364; від 26.11.2002 N 467/998/578/478 ( z0971-02 ) "Про внесення змін і доповнень до Інструкції про порядок обчислення і справляння плати за користування надрами для видобування корисних копалин", зареєстрований в Міністерстві юстиції України 16.12.2002 за N 971/7259.

2. Юридичному департаменту Міністерства (Роменський Д.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України в установленому порядку.

3. Контроль за виконанням цього наказу залишаємо за собою.

4. Цей наказ набирає чинності з дня його офіційного опублікування.
