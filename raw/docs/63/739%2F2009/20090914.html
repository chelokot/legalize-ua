Президент України; Указ від 14.09.2009 № 739/2009

Питання Міжвідомчої комісії з політики військово-технічного співробітництва та експортного контролю

Стан: Втратив чинність

Ідентифікатор: 739/2009

Текст документа від 14.09.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Міжвідомчої комісії з політики військово-технічного співробітництва та експортного контролю

1. На часткову зміну статті 3 Указу Президента України від 5 березня 2007 року N 180 ( 180/2007 ) "Про Міжвідомчу комісію з політики військово-технічного співробітництва та експортного контролю" (зі змінами, внесеними Указами від 27 червня 2007 року N 571 ( 571/2007 ), від 24 березня 2008 року N 263 ( 263/2008 ), від 17 червня 2008 року N 549 ( 549/2008 ), від 6 березня 2009 року N 130 ( 130/2009 ) та від 4 червня 2009 року N 400) ( 400/2009 ):

увести до складу Міжвідомчої комісії з політики військово-технічного співробітництва та експортного контролю ПЯСКОВСЬКОГО Дмитра Володимировича - першого заступника Генерального директора Національного космічного агентства України;

вивести зі складу Міжвідомчої комісії з політики військово-технічного співробітництва та експортного контролю В. Комарова.

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 14 вересня 2009 року N 739/2009
