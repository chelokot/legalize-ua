Верховна Рада України; Закон від 31.07.2008 № 338-VI

Про затвердження Указу Президента України "Про оголошення окремих територій Вінницької, Івано-Франківської, Закарпатської, Львівської, Тернопільської та Чернівецької областей зонами надзвичайної екологічної ситуації"

Стан: Чинний

Ідентифікатор: 338-17

Текст документа від 31.07.2008:

ЗАКОН УКРАЇНИ

Про затвердження Указу Президента України "Про оголошення окремих територій Вінницької, Івано-Франківської, Закарпатської, Львівської, Тернопільської та Чернівецької областей зонами надзвичайної екологічної ситуації"

( Відомості Верховної Ради України (ВВР), 2008, N 35, ст.275 )

Відповідно до пункту 31 частини першої статті 85 Конституції України ( 254к/96-ВР ) та статті 6 Закону України "Про зону надзвичайної екологічної ситуації" ( 1908-14 ) Верховна Рада України постановляє:

1. Затвердити Указ Президента України від 28 липня 2008 року N 682 ( 682/2008 ) "Про оголошення окремих територій Вінницької, Івано-Франківської, Закарпатської, Львівської, Тернопільської та Чернівецької областей зонами надзвичайної екологічної ситуації".

2. Цей Закон набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 31 липня 2008 року N 338-VI
