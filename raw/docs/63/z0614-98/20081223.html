Держбуд України; Наказ, Правила від 09.09.1998 № 197

Про затвердження Правил формування договірних цін та їх уточнення в процесі будівництва

Реєстрація: Мін'юст України від 30.09.1998 № 614/3054

Стан: Втратив чинність

Ідентифікатор: z0614-98

Текст документа від 23.12.2008:

ДЕРЖАВНИЙ КОМІТЕТ БУДІВНИЦТВА, АРХІТЕКТУРИ ТА ЖИТЛОВОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

N 197 від 09.09.98 Зареєстровано в Міністерстві м.Київ юстиції України 30 вересня 1998 р. за N 614/3054

{ Наказ втратив чинність на підставі Наказу Міністерства регіонального розвитку та будівництва N 527 ( z1192-08 ) від 21.11.2008 }

Про затвердження Правил формування договірних цін та їх уточнення в процесі будівництва

{ Із змінами, внесеними згідно з Наказом Держбуду N 215 ( z0720-00 ) від 29.09.2000 }

{ Щодо втрати чинності Наказу див. Наказ Міністерства регіонального розвитку та будівництва N 374 ( v0374661-08 ) від 20.08.2008 }

Виходячи з Положення про Державний комітет будівництва, архітектури та житлової політики, затвердженого Указом Президента України від 09.12.97 N 1342/97, та Положення про державну реєстрацію нормативних актів міністерств, інших органів державної виконавчої влади, органів господарського управління та контролю, що зачіпають права, свободи і законні інтереси громадян або мають міжвідомчий характер, затвердженого постановою Кабінету Міністрів України від 28.12.92 N 731 ( 731-92-п ), із змінами та доповненнями від 15.06.94 N 420 ( 420-94-п ), НАКАЗУЮ:

1. Затвердити Правила формування договірних цін та їх уточнення в процесі будівництва, що додаються.

2. Управлінню кошторисних норм, ціноутворення та експертизи (Губень) довести інформацію про затвердження Правил формування договірних цін та їх уточнення в процесі будівництва до відома зацікавлених організацій.

Голова Комітету В.М.Гусаков

( Правила формування договірних цін та їх уточнення в процесі будівництва втратили чинність на підставі Наказу Держбуду N 215 ( z0720-00 ) від 29.09.2000 )
