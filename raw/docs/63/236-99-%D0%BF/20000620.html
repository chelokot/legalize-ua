Про затвердження розмірів плати за проходження суден шлюзами Дніпровського каскаду

Стан: Втратив чинність

Ідентифікатор: 236-99-п

Текст документа від 20.06.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 лютого 1999 р. N 236 Київ

Про затвердження розмірів плати за проходження суден шлюзами Дніпровського каскаду

( Із змінами, внесеними згідно з Постановою КМ N 994 ( 994-2000-п ) від 20.06.2000 )

( У назві і тексті постанови слово "граничних" виключено на підставі Постанови КМ N 994 ( 994-2000-п ) від 20.06.2000 )

З метою залучення коштів з додаткових джерел для забезпечення необхідного рівня технічного стану дніпровських судноплавних гідротехнічних споруд (шлюзів) Кабінет Міністрів України постановляє:

1. Затвердити розміри плати за проходження суден шлюзами Дніпровського каскаду (додаються).

( Абзац другий пункту 1 виключено на підставі Постанови КМ N 994 ( 994-2000-п ) від 20.06.2000 )

2. Міністерству транспорту за погодженням з Міністерством економіки і Міністерством фінансів затвердити порядок справляння плати за проходження суден шлюзами Дніпровського каскаду.
