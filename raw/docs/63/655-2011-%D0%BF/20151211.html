Кабінет Міністрів України; Постанова від 09.06.2011 № 655

Про внесення зміни до пункту 2 Порядку формування та розміщення державних замовлень на поставку продукції для державних потреб і контролю за їх виконанням

Стан: Втратив чинність

Ідентифікатор: 655-2011-п

Текст документа від 11.12.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 червня 2011 р. N 655 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 984 ( 984-2015-п ) від 25.11.2015 }

Про внесення зміни до пункту 2 Порядку формування та розміщення державних замовлень на поставку продукції для державних потреб і контролю за їх виконанням

Кабінет Міністрів України постановляє:

Внести зміну до абзацу шостого пункту 2 Порядку формування та розміщення державних замовлень на поставку продукції для державних потреб і контролю за їх виконанням, затвердженого постановою Кабінету Міністрів України від 29 лютого 1996 р. N 266 ( 266-96-п ) (ЗП України, 1996 р., N 8, ст. 239; Офіційний вісник України, 2001 р., N 51, ст. 2271; 2003 р., N 37, ст. 1991; 2004 р., N 49, ст. 3206; 2006 р., N 31, ст. 2233), доповнивши його словами "створення нових вистав, концертних та циркових програм".

Прем'єр-міністр України М.АЗАРОВ
