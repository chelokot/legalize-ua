{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про затвердження Положення про порядок випуску та обіг депозитних сертифікатів Національного банку України

{ Із змінами, внесеними згідно з Постановою Нацбанку N 499 ( z0734-99 ) від 07.10.99 }

З метою оперативного регулювання грошово-кредитним ринком, вилучення у відповідний період надлишкової ліквідності банківської системи та у зв'язку з введенням в дію Інструкції з бухгалтерського обліку операцій з цінними паперами установ комерційних банків ( v0510500-97 ) Правління ПОСТАНОВЛЯЄ:

1. ( Пункт 1 втратив чинність на підставі Постанови Нацбанку N 499 ( z0734-99 ) від 07.10.99 ) Затвердити Положення про порядок випуску та обіг депозитних сертифікатів Національного банку України ( v0616500-99 ).

2. Визнати такою, що втратила чинність, постанову Правління Національного банку України від 05.12.94 N 209 ( va209500-94 ) "Про запровадження в практичну діяльність банківської системи відповідних механізмів з регулювання обсягів грошової маси в обігу".

3. Емісійно-кредитному департаменту (Н.І.Гребеник) надіслати цю постанову Кримському республіканському, обласним та по місту Києву і Київській області управлінням Національного банку України, комерційним банкам для керівництва і використання в роботі.
