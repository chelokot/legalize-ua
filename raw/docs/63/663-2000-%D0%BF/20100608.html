КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 квітня 2000 р. N 663 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про внесення змін до структури Секретаріату Кабінету Міністрів України

З метою удосконалення структури Секретаріату Кабінету Міністрів України Кабінет Міністрів України постановляє:

Утворити у структурі Секретаріату Кабінету Міністрів України, затвердженій постановою Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) (Офіційний вісник України, 2000 р., N 4, ст. 110), Управління моніторингу та ринкових перетворень в енергетичному секторі економіки замість Управління експертизи та аналізу розвитку паливно-енергетичного комплексу, що ліквідується.

Прем'єр-міністр України В.ЮЩЕНКО
