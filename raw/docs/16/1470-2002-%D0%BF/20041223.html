Про внесення зміни до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

Стан: Втратив чинність

Ідентифікатор: 1470-2002-п

Текст документа від 23.12.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 вересня 2002 р. N 1470 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1734 ( 1734-2004-п ) від 23.12.2004 )

Про внесення зміни до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

Кабінет Міністрів України постановляє:

У переліку підприємств, які мають стратегічне значення для економіки і безпеки держави, затвердженому постановою Кабінету Міністрів України від 29 серпня 2000 р. N 1346 ( 1346-2000-п ) (Офіційний вісник України, 2000 р., N 35, ст. 1498; 2002 р., N 10, ст. 474), позицію "01056729 Артемівський електротехнічний завод" підрозділу "Донецька область" розділу "Мінтранс" виключити.

Прем'єр-міністр України А.КІНАХ
