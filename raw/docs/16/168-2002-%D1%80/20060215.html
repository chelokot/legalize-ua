Текст документа від 15.02.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 березня 2002 р. N 168-р Київ

Про утворення Міжвідомчої робочої групи з координації роботи, спрямованої на здійснення заходів щодо виконання Програми розвитку інвестиційної діяльності на 2002-2010 роки

( Із змінами, внесеними згідно з Розпорядженнями КМ N 23-р ( 23-2003-р ) від 18.01.2003 N 168-р ( 168-2004-р ) від 24.03.2004 Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 )

1. Утворити Міжвідомчу робочу групу з координації роботи, спрямованої на здійснення заходів щодо виконання Програми розвитку інвестиційної діяльності на 2002-2010 роки (далі - Програма), затвердженої постановою Кабінету Міністрів України від 28 грудня 2001 р. N 1801 ( 1801-2001-п ), у складі згідно з додатком.

Надати право керівнику Міжвідомчої робочої групи вносити в разі потреби зміни до її складу.

2. Установити, що основними завданнями Міжвідомчої робочої групи з координації роботи, спрямованої на здійснення заходів щодо виконання Програми (далі - Міжвідомча робоча група), є:

участь у розробленні плану заходів щодо виконання Програми, проектів необхідних для цієї мети нормативно-правових актів та методичних матеріалів;

розгляд інформації міністерств, інших центральних органів виконавчої влади, Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських держадміністрацій, установ, організацій, об'єднань підприємців та інвесторів про хід виконання Програми, її узагальнення, підготовка пропозицій щодо поліпшення інвестиційної діяльності;

аналіз кожного півріччя ходу реалізації плану заходів щодо виконання Програми, підготовка в разі потреби пропозицій стосовно його коригування;

популяризація через засоби масової інформації позитивного досвіду роботи із залучення інвестицій в національну економіку.

3. Відповідно до основних завдань Міжвідомча робоча група має право:

одержувати в установленому порядку від міністерств, інших центральних органів виконавчої влади, Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських держадміністрацій, установ, організацій, об'єднань підприємців та інвесторів інформацію, необхідну для виконання покладених на неї завдань;

проводи з питань, що належать до її компетенції, засідання, наради, семінари, конференції із залучанням представників органів виконавчої влади, підприємств, установ та організацій.
