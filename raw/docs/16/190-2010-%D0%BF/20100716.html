ПОСТАНОВА від 24 лютого 2010 р. N 190 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 559 ( 559-2010-п ) від 07.07.2010 }

Про забезпечення виконання функцій з реєстрації фізичних осіб

З метою забезпечення виконання функцій з реєстрації фізичних осіб та з урахуванням вимог статті 11 Закону України "Про свободу пересування та вільний вибір місця проживання в Україні" ( 1382-15 ) Кабінет Міністрів України постановляє:

Покласти на Державну міграційну службу функції з реєстрації місця проживання та перебування фізичних осіб в Україні.
