УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Комісію при Президентові України з питань громадянства

{ Із змінами, внесеними згідно з Указами Президента N 942/2006 ( 942/2006 ) від 10.11.2006 N 183/2008 ( 183/2008 ) від 28.02.2008 N 486/2008 ( 486/2008 ) від 30.05.2008 N 840/2009 ( 840/2009 ) від 20.10.2009 N 826/2010 ( 826/2010 ) від 19.08.2010 }

З метою забезпечення виконання повноважень, передбачених пунктом 26 частини першої статті 106 Конституції України ( 254к/96-ВР ), постановляю:

1. Утворити Комісію при Президентові України з питань громадянства у складі, що додається.

2. Визнати такими, що втратили чинність:
