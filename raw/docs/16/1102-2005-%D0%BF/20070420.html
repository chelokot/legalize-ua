Про затвердження складу Міжвідомчої аналітично-консультативної ради з питань розвитку продуктивних сил і виробничих відносин

Стан: Втратив чинність

Ідентифікатор: 1102-2005-п

Текст документа від 20.04.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2005 р. N 1102 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 646 ( 646-2007-п ) від 20.04.2007 }

Про затвердження складу Міжвідомчої аналітично-консультативної ради з питань розвитку продуктивних сил і виробничих відносин

( Із змінами, внесеними згідно з Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 )

Кабінет Міністрів України постановляє:

1. Затвердити склад Міжвідомчої аналітично-консультативної ради питань розвитку продуктивних сил і виробничих відносин, що додається.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрі України від 24 лютого 2003 р. N 210 ( 210-2003-п ) "Про затвердження нового склад Міжвідомчої аналітично-консультативної ради з питань розвити продуктивних сил і виробничих відносин" (Офіційний вісник, Україні 2003 р., N 9, ст. 379).
