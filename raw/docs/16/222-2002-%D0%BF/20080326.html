Про затвердження диференційованих нормативів плати за користування надрами для видобування бурштинової, титанової та титано-цирконієвої руди

Текст документа від 26.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 лютого 2002 р. N 222 Київ

Про затвердження диференційованих нормативів плати за користування надрами для видобування бурштинової, титанової та титано-цирконієвої руди

{ Із змінами, внесеними згідно з Постановою КМ N 264 ( 264-2008-п ) від 26.03.2008 }

Відповідно до статті 30 Кодексу України про надра ( 132/94-ВР ) Кабінет Міністрів України постановляє:

1. Затвердити диференційовані нормативи плати за користування надрами для видобування бурштинової, титанової та титано-цирконієвої руди згідно з додатком.

2. Внести до постанови Кабінету Міністрів України від 12 вересня 1997 р. N 1014 ( 1014-97-п ) "Про затвердження базових нормативів плати за користування надрами для видобування корисних копалин та Порядку справляння плати за користування надрами для видобування корисних копалин" (Офіційний вісник України, 1997 р., число 38, с. 8; 1998 р., N 3, ст. 98; 2000 р., N 10, ст. 383; 2001 р., N 29, ст. 1310, N 32, ст. 1480) такі зміни:

{ Підпункт 1 пункту 2 втратив чинність на підставі Постанови КМ N 264 ( 264-2008-п ) від 26.03.2008 }

2) у додатку до постанови:

у групі "Металеві корисні копалини" виключити такі позиції:

"Титанова руда** -"- 0,32 Титано-цирконієва руда -"- 0,62";

у групі "Сировина ювелірна (дорогоцінне каміння)" у переліку корисних копалин слово "бурштин" виключити.

3. Міністерству екології та природних ресурсів, Міністерству фінансів, Міністерству праці та соціальної політики і Державній податковій адміністрації за погодженням з Міністерством економіки та з питань європейської інтеграції внести відповідні зміни до Інструкції про порядок обчислення і справляння платежів за користування надрами для видобування корисних копалин.
