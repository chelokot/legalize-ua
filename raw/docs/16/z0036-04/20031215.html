Про визнання наказів такими, що втратили чинність

На підставі Указу Президента України від 22 серпня 2003 р. N 880 ( 880/2003 ) "Про внесення зміни до Указу Президента України від 20 березня 2001 р. N 183" та рішення Державного комітету України з питань розвитку підприємництва від 31 березня 1999 р. N 17-24/3 ( v24_3276-99 ) "Про необхідність усунення порушень вимог Указу Президента України від 03.02.1998 р. N 79 "Про усунення обмежень, що стримують розвиток підприємницької діяльності" НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Державного комітету статистики України:

- від 27 липня 1998 р. N 263 ( z0508-98 ) "Про затвердження типових форм первинного обліку та Інструкції про порядок їх виготовлення, зберігання і застосування", зареєстрований в Міністерстві юстиції України 12 серпня 1998 р. за N 508/2948;

- від 25 лютого 1999 р. N 76 ( z0135-99 ) "Про внесення змін до наказу Держкомстату від 27.07.1998 р. N 263 "Про затвердження типових форм первинного обліку та Інструкції про порядок їх виготовлення, зберігання і застосування", зареєстрований в Міністерстві юстиції України 03 березня 1999 р. за N 135/3428;

- від 31 березня 1999 р. N 119 ( z0324-99 ) "Про внесення змін та доповнень до наказу Держкомстату від 27.07.1998 р. N 263 "Про затвердження типових форм первинного обліку та Інструкції про порядок їх виготовлення, зберігання і застосування", зареєстрований в Міністерстві юстиції України 21 травня 1999 р. за N 324/3617.

2. Контроль за виконанням наказу покласти на Першого заступника Голови Держкомстату Головка В.А.

Голова Державного комітету статистики України О.Г.Осауленко
