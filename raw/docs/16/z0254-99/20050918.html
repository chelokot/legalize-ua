{ Наказ втратив чинність на підставі Наказу Міністерства фінансів N 581 ( z1010-05 ) від 23.08.2005 }

Про внесення змін до наказу Міністерства фінансів України від 26 лютого 1998 року N 43

Відповідно до пункту 22.14 статті 22 Закону України "Про оподаткування прибутку підприємств" ( 334/94-ВР ) НАКАЗУЮ:

Внести такі зміни до наказу Міністерства фінансів України від 26 лютого 1998 року N 43 ( z0169-98 ) "Про включення до валових витрат" (зареєстрований у Міністерстві юстиції України 13 березня 1998 року за N 169/2609):

1. Абзац другий пункту 2 викласти в такій редакції:

"Вартість залишків готової продукції, які були відвантажені з 1 липня 1997 року, включається до валових витрат того звітного (податкового) періоду, на який припадає дата відвантаження залишків такої готової продукції".

2. У пунктах 3, 4, 5 слова "першого звітного (податкового) періоду набрання чинності цим наказом" вилучити.
