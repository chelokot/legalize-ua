{ Постанова втратила чинність на підставі Постанови КМ N 1251 ( 1251-2010-п ) від 27.12.2010 }

N 926 ( 926-2003-п ) "Про розміри плати за марки акцизного збору для алкогольних напоїв та тютюнових виробів" (Офіційний вісник України, 2003 р., N 26, ст. 1277; 2008 р., N 38, ст. 1268), виключивши абзац четвертий.
