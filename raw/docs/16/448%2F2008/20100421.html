УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Указу Президента України від 28 лютого 2005 року N 384

{ Указ втратив чинність в частині призначення Поляченка В.А. на підставі Указу Президента N 545/2010 ( 545/2010 ) від 16.04.2010 }

Відповідно до пункту 12 частини першої статті 106 Конституції України ( 254к/96-ВР ) та статті 10 Закону України "Про Національний банк України" ( 679-14 ) постановляю:

На часткову зміну статті 1 Указу Президента України від 28 лютого 2005 року N 384 ( 384/2005 ) "Про членів Ради Національного банку України" (зі зміною, внесеною Указом від 25 вересня 2006 року N 782) ( 782/2006 ) призначити членом Ради Національного банку України ПОЛЯЧЕНКА Володимира Аврумовича - народного депутата України (за згодою), звільнивши члена цієї Ради Г. Шемшученка.
