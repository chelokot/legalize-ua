Текст документа від 20.07.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 липня 2011 р. N 762 Київ

Про внесення змін до постанов Кабінету Міністрів України від 3 грудня 2009 р. N 1301 і 1317

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 3 грудня 2009 р. N 1301 ( 1301-2009-п ) "Про затвердження Порядку забезпечення інвалідів і дітей-інвалідів технічними та іншими засобами" (Офіційний вісник України, 2009 р., N 94, ст. 3210) і N 1317 ( 1317-2009-п ) "Питання медикосоціальної експертизи" (Офіційний вісник України, 2009 р., N 95, ст. 3265; 2010 р., N 65, ст. 2266) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 20 липня 2011 р. N 762

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 3 грудня 2009 р. N 1301 ( 1301-2009-п ) і 1317 ( 1317-2009-п )

1. У тексті Порядку забезпечення інвалідів і дітей-інвалідів технічними та іншими засобами, затвердженого постановою Кабінету Міністрів України від 3 грудня 2009 р. N 1301 ( 1301-2009-п ), слова "бездомних громадян" замінити словами "бездомних осіб".

2. У затверджених постановою Кабінету Міністрів України від 3 грудня 2009 р. N 1317 ( 1317-2009-п ):

1) у Положенні про медико-соціальну експертизу ( 1317-2009-п ):

в абзаці першому пункту 15 слова "за місцем тимчасового проживання у закладах соціального захисту для бездомних громадян" замінити словами "за місцем їх проживання або місцем перебування у закладах соціального захисту для бездомних осіб";

у першому реченні абзацу першого пункту 23 слова "бездомних громадян" замінити словами "бездомних осіб";

2) у пункті 5 Положення про порядок, умови та критерії встановлення інвалідності ( 1317-2009-п ) слова "тимчасового проживання у закладах соціального захисту для безпритульних громадян" замінити словами "закладах соціального захисту для бездомних осіб".
