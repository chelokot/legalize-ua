16.02.2009 N 126

Зареєстровано в Міністерстві юстиції України 23 лютого 2009 р. за N 169/16185

Щодо затвердження Порядку розрахування роздрібних цін на електроенергію, використану підприємствами з виробництва титану губчастого виключно для технологічних потреб

Відповідно до пункту 1 розпорядження Кабінету Міністрів України від 10.12.2008 N 1566-р ( 1566-2008-р ) "Питання підприємств з виробництва первинного алюмінію та титану губчастого в період фінансово-економічної кризи" НАКАЗУЮ:

1. Затвердити Порядок розрахування роздрібних цін на електроенергію, використану підприємствами з виробництва титану губчастого виключно для технологічних потреб (додається).

2. Генеральному директору казенного підприємства "Запорізький титаномагнієвий комбінат" (Кучук В.В.) забезпечити щомісячне надання Мінпромполітики форми державного статистичного спостереження N 1-П (термінова) "Терміновий звіт про виробництво промислової продукції (робіт, послуг)" ( vd215202-07 ), затвердженої наказом Державного комітету статистики України від 12.07.2007 N 215 ( v0215202-07 ), та інформації щодо проценту сортності різних марок титану губчастого від загального обсягу виробництва.

3. Начальнику управління 7-1 (Шинкаренко П.С.) забезпечити розрахунки середньовиваженої ціни титану губчастого з урахуванням цін на світовому ринку та фактичного обсягу споживання електроенергії для технологічних потреб за звітний місяць, своєчасне узагальнення розрахункових даних та їх передачу НКРЕ.

4. Наказ Мінпромполітики від 10.07.2002 N 312 ( z0618-02 ) "Щодо затвердження Порядку визначення рівнів роздрібних цін на електроенергію для забезпечення конкурентоспроможності підприємств з виробництва первинного алюмінію, його сплавів і титану", зареєстрований в Мін'юсті 30.07.2002 за N 618/6906, визнати таким, що втратив чинність.

5. Контроль за виконанням цього наказу покласти на заступника Міністра В.В.Севернюка.

ЗАТВЕРДЖЕНО Наказ Мінпромполітики 16.02.2009 N 126

Зареєстровано в Міністерстві юстиції України 23 лютого 2009 р. за N 169/16185

ПОРЯДОК розрахування роздрібних цін на електроенергію, використану підприємствами з виробництва титану губчастого виключно для технологічних потреб

1. Цей Порядок розроблено відповідно до пункту 1 розпорядження Кабінету Міністрів України від 10.12.2008 N 1566-р ( 1566-2008-р ) "Питання підприємств з виробництва первинного алюмінію та титану губчастого в період фінансово-економічної кризи".

Єдиним виробником титану губчастого в Україні є казенне підприємство "Запорізький титаномагнієвий комбінат" (далі - КП "ЗТМК").

2. Роздрібні тарифи на електричну енергію, яка використовується КП "ЗТМК" виключно на технологічні потреби, визначаються щомісяця залежно від коливання цін на титан губчастий марки TG - TV на світовому ринку за даними журналу "Metall Pages".

3. Обов'язковою умовою застосування роздрібних тарифів на електроенергію згідно з цим Порядком є відсутність заборгованості за спожиту електроенергію у минулі періоди або наявність графіка реструктуризації боргу та повна (100-відсоткова) поточна подекадна сплата за спожиту електроенергію плановими платежами у розрахунковому місяці. У разі неповної поточної сплати за спожиту електроенергію розрахунки проводяться за єдиним роздрібним тарифом на відповідному класі напруги, що затверджується Національною комісією регулювання електроенергетики України згідно з чинним законодавством.

4. Рівні роздрібних тарифів на електричну енергію, що буде спожита КП "ЗТМК" у розрахунковому місяці, визначаються у місяці, що йому передує, та встановлюються на підставі середньовиваженої ціни на титан губчастий залежно від питомої ваги сортності різних марок титану губчастого у загальному обсязі виробництва за звітний місяць.

5. Для визначення середньовиваженої ціни титану губчастого у звітному місяці:

5.1. КП "ЗТМК" щомісяця до 5-го числа місяця, що передує розрахунковому, надає Управлінню 7-1 Мінпромполітики звітні дані щодо питомої ваги різних марок титану губчастого у загальному обсязі виробництва.

5.2. Мінпромполітики (Управління 7-1) щомісяця розраховує середньовиважену ціну титану губчастого за формулою

6. Для визначення фактичного обсягу електричної енергії, спожитої виключно на технологічні потреби:

6.1. КП "ЗТМК" щомісяця до 5-го числа місяця, що передує розрахунковому, надає Управлінню 7-1 Мінпромполітики форму державного статистичного спостереження N 1-П (термінова) "Терміновий звіт про виробництво промислової продукції (робіт, послуг)" ( vd215202-07 ), затверджену наказом Державного комітету статистики України від 12.07.2007 N 215 ( v0215202-07 ) (далі - форма N 1-П), за звітний місяць.

6.2. Мінпромполітики (Управління 7-1) за даними форми N 1-П ( vd215202-07 ) та з використанням норми наскрізних питомих витрат електричної енергії для виробництва 1 тонни титану губчастого (яка розраховується Інститутом титану, погоджується Національним агентством України з питань забезпечення ефективного використання енергетичних ресурсів та затверджується Мінпромполітики) розраховує фактичний обсяг споживання електроенергії для технологічних потреб за звітний місяць.

7. Мінпромполітики (Управління 7-1) до 15-го числа місяця, що передує розрахунковому, надає Національній комісії регулювання електроенергетики України (далі - НКРЕ) інформацію за звітний місяць за підписом Заступника Міністра за напрямом:

- щодо рівня ціни на титан губчастий марки TG - TV на світовому ринку за даними журналу "Metall Pages";

- розрахунок середньовиваженої світової ціни на титан губчастий;

- копію форми державної статистичної звітності N 1-П ( vd215202-07 ) "Звіт про виробництво промислової продукції" КП "ЗТМК";

- розрахунок фактичного обсягу споживання електроенергії для технологічних потреб.

8. Рівні роздрібних тарифів на електричну енергію, що буде використовуватися на технологічні потреби у розрахунковому місяці, визначаються залежно від середньовиваженої ціни на титан губчастий, розрахованої відповідно до пункту 5.2 цього Порядку, наведені у таблиці.

9. При відхиленні офіційного курсу гривні до долара США більше ніж на 10% та у разі зміни кон'юнктури на світовому ринку титану губчастого рівні зазначених тарифів переглядаються за ініціативою НКРЕ.

10. У разі перевищення встановлених норм наскрізних питомих витрат електроенергії на виробництво 1 тонни титану губчастого та відповідного перевищення фактичного обсягу електроенергії, що має бути використаний виключно на технологічні потреби, оплата понаднормативного споживання електроенергії здійснюється за єдиним роздрібним тарифом на відповідному класі напруги, що затверджується Національною комісією регулювання електроенергетики України згідно з чинним законодавством.
