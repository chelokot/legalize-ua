Президент України; Указ від 01.10.2002 № 887/2002

Про Державний комітет України з питань технічного регулювання та споживчої політики

Стан: Втратив чинність

Ідентифікатор: 887/2002

Текст документа від 01.10.2002:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Державний комітет України з питань технічного регулювання та споживчої політики

З метою підвищення ефективності реалізації державної політики у сфері захисту прав споживачів та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Перетворити Державний комітет стандартизації, метрології та сертифікації України у Державний комітет України з питань технічного регулювання та споживчої політики.

Установити, що Державний комітет України з питань технічного регулювання та споживчої політики є центральним органом виконавчої влади зі спеціальним статусом.

2. Визначити, що основними завданнями Державного комітету України з питань технічного регулювання та споживчої політики є забезпечення реалізації державної політики у сфері захисту прав споживачів, стандартизації, метрології та сертифікації, здійснення управління в цій сфері, а також міжгалузевої координації та функціонального регулювання питань захисту прав споживачів, стандартизації, метрології та сертифікації.

3. Внести до Схеми організації та взаємодії центральних органів виконавчої влади, затвердженої Указом Президента України від 15 грудня 1999 року N 1573 ( 1573/99 ) "Про зміни у структурі центральних органів виконавчої влади" (зі змінами, внесеними Указами від 14 липня 2000 року N 902 ( 902/2000 ), від 27 серпня 2000 року N 1031 ( 1031/2000 ), від 23 жовтня 2000 року N 1159 ( 1159/2000 ), від 5 грудня 2000 року N 1303 ( 1303/2000 ), від 5 червня 2001 року N 405 ( 405/2001 ), від 7 серпня 2001 року N 603 ( 603/2001 ), від 13 вересня 2001 року N 836 ( 836/2001 ), від 29 вересня 2001 року N 907 ( 907/2001 ), від 8 листопада 2001 року N 1056 ( 1056/2001 ), від 22 листопада 2001 року N 1132 ( 1132/2001 ), від 14 грудня 2001 року N 1213 ( 1213/2001 ), від 27 грудня 2001 року N 1265 ( 1265/2001 ), від 16 березня 2002 року N 259 ( 259/2002 ), від 29 серпня 2002 року N 780 ( 780/2002 ) і від 18 вересня 2002 року N 834 ( 834/2002 ), такі зміни:

а) у розділі II абзац "Державний комітет стандартизації, метрології та сертифікації України" виключити;

б) доповнити розділ III новим абзацом такого змісту:

"Державний комітет України з питань технічного регулювання та споживчої політики";

в) у підрозділі "через Міністра економіки та з питань європейської інтеграції України" розділу IV абзац "Державний комітет стандартизації, метрології та сертифікації України" виключити.

4. Кабінету Міністрів України у двомісячний строк:

а) здійснити заходи, пов'язані з перетворенням Державного комітету стандартизації, метрології та сертифікації України;

б) подати в установленому порядку проект Положення про Державний комітет України з питань технічного регулювання та споживчої політики;

в) привести свої акти у відповідність із цим Указом.

Президент України Л.КУЧМА
