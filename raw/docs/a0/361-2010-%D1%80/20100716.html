КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 березня 2010 р. N 361-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 559 ( 559-2010-п ) від 07.07.2010 }

Про передачу цілісних майнових комплексів пунктів тимчасового перебування іноземців та осіб без громадянства, які незаконно перебувають в Україні, до сфери управління Державної міграційної служби

Прийняти пропозицію Міністерства внутрішніх справ та Державної міграційної служби щодо передачі розташованих у с. Журавичі Ківерцівського району Волинської області та с. Розсудів Ріпкинського району Чернігівської області цілісних майнових комплексів пунктів тимчасового перебування іноземців та осіб без громадянства, які незаконно перебувають в Україні, до сфери управління Державної міграційної служби.

Прем'єр-міністр України Ю.ТИМОШЕНКО
