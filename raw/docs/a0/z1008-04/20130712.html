ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ПИТАНЬ РЕГУЛЯТОРНОЇ ПОЛІТИКИ ТА ПІДПРИЄМНИЦТВА МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

05.08.2004 N 90/284

Зареєстровано в Міністерстві юстиції України 12 серпня 2004 р. за N 1008/9607

{ Наказ втратив чинність на підставі Наказу Міністерства економічного розвитку і торгівлі N 531/340 ( z0985-13 ) від 31.05.2013 }

Про внесення доповнень до Ліцензійних умов провадження господарської діяльності, пов'язаної з промисловим виловом риби на промислових ділянках рибогосподарських водойм, крім внутрішніх водойм (ставків) господарств

У зв'язку з упровадженням в Україні системи дистанційного моніторингу суден рибопромислового флоту, відповідно до наказу Міністерства аграрної політики України від 25 грудня 2003 року N 466 ( z1258-03 ) "Про утворення системи дистанційного моніторингу суден рибопромислового флоту", зареєстрованого в Міністерстві юстиції України 30.12.2003 за N 1258/8579, та перегляду нормативних документів НАКАЗУЄМО:

1. Доповнити пункт 5.1.4 Ліцензійних умов провадження господарської діяльності, пов'язаної з промисловим виловом риби на промислових ділянках рибогосподарських водойм, крім внутрішніх водойм (ставків) господарств, затверджених наказом Державного комітету України з питань регуляторної політики та підприємництва і Міністерства аграрної політики України від 14 листопада 2001 року N 132/336 ( z0995-01 ), зареєстрованим в Міністерстві юстиції України 29 листопада 2001 року за N 995/6186, новими абзацами такого змісту:

"Положення про систему дистанційного моніторингу суден рибопромислового флоту, затвердженого наказом Міністерства аграрної політики України від 25 грудня 2003 року N 466 ( z1258-03 ) та зареєстрованого в Міністерстві юстиції України 30 грудня 2003 року за N 1258/8579";

"Положення про підготовку та підвищення кваліфікації стернових-мотористів маломірних суден Держкомрибгоспу України, затвердженого наказом Державного комітету рибного господарства України від 23.09.98 N 129 ( z0006-99 ) та зареєстрованого в Міністерстві юстиції України 5 січня 1999 року за N 6/3299".

2. Департаменту реєстрації та ліцензування Держпідприємництва України (Єфремов О.В.), Державному департаменту рибного господарства (Алимов С.І.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Державній інспекції з безпеки мореплавства флоту рибного господарства (Туровський А.І.) забезпечити публікацію цього наказу в засобах масової інформації.

4. Контроль за виконанням наказу покласти на заступника Голови Держпідприємництва України Третьякова С.І. та Голову Укрдержрибгоспу Алимова С.І.
