ПОСТАНОВА від 19 грудня 1994 р. N 854 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 657 ( 657-2010-п ) від 28.07.2010 }

Про призначення Гончарука А.І. головою Української частини Українсько-Грецької Міжурядової Спільної Робочої Групи з економічного, промислового, технічного та наукового співробітництва

Кабінет Міністрів України постановляє:

Призначити заступника Міністра зовнішніх економічних зв'язків України Гончарука Андрія Івановича головою Української частини Українсько-Грецької Міжурядової Спільної Робочої Групи з економічного, промислового, технічного та наукового співробітництва.
