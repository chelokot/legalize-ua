Текст документа від 05.07.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 липня 2004 р. N 837 Київ

Про доповнення Переліку категорій працівників, яким може бути надано службові жилі приміщення

Кабінет Міністрів України постановляє:

1. Доповнити Перелік категорій працівників, яким може бути надано службові жилі приміщення, затверджений постановою Ради Міністрів УРСР від 4 лютого 1988 р. N 37 ( 37-88-п ) "Про службові жилі приміщення" (ЗП УРСР, 1988 р., N 2, ст. 8; 1989 р., N 3, ст. 13, N 7, ст. 42; ЗП України, 1993 р., N 12, ст. 259; 1994 р., N 1, ст. 21, N 4, ст. 99, N 6, ст. 153, N 8, ст. 203, N 10, ст. 262; 1995 р., N 5, ст. 122; Офіційний вісник України, 1997 р., число 35, с. 83, число 38, с. 1, число 51, с. 25; 1998 р., N 27, ст. 995; 1999 р., N 11, ст. 436, N 30, ст. 1545, N 50, ст. 2443; 2003 р., N 37, ст. 1982, N 47, ст. 2436; 2004 р., N 12, ст. 74), пунктом 46 такого змісту:

"46. Військовослужбовці Головного управління розвідки Міноборони та підпорядкованих йому військових частин (крім військовослужбовців строкової служби) за переліком, що визначається керівником цього органу, до одержання ними постійного жилого приміщення".

2. Установити, що військовослужбовці Головного управління розвідки Міністерства оборони та підпорядкованих йому військових частин (крім військовослужбовців строкової служби) до одержання ними постійного жилого приміщення можуть забезпечуватися службовим жилим приміщенням за рахунок фонду службових жилих приміщень, який формується з новозбудованого житла, звільнених жилих приміщень або квартир, придбаних у фізичних чи юридичних осіб.
