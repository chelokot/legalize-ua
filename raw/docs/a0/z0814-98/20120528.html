Текст документа від 28.05.2012:

ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

N 2321 від 10.12.98 Зареєстровано в Міністерстві м.Київ юстиції України 23 грудня 1998 р. за N 814/3254

{ Наказ втратив чинність на підставі Наказу Фонду державного майна N 439 ( z0753-12 ) від 02.04.2012 }

Про внесення змін до Положення про порядок визначення та застосування способів приватизації щодо об'єктів малої приватизації, затвердженого наказом ФДМУ від 30.07.98 N 1511

У зв'язку з прийняттям Кабінетом Міністрів України 22 липня 1998 р. постанови N 1114 ( 1114-98-п ) "Про затвердження Методики оцінки вартості майна під час приватизації" НАКАЗУЮ:

1. Внести зміни до Положення про порядок визначення та застосування способів приватизації щодо об'єктів малої приватизації, затвердженого наказом Фонду державного майна України від 30.07.98 N 1511 ( z0558-98 ):

перше речення пункту 3.5 вилучити, далі - за текстом.

2. Департаменту малої приватизації та незавершеного будівництва забезпечити реєстрацію цього наказу в Міністерстві юстиції України.

3. Відповідальність за виконання наказу покласти на начальників регіональних відділень ФДМУ та директора Департаменту малої приватизації та незавершеного будівництва.

4. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Л.Кальніченка.
