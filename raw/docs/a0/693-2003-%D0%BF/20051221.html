Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 травня 2003 р. N 693 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

Про склад Української частини Спільного комітету "Уряд/ЮНІДО"

Кабінет Міністрів України постановляє:

1. Затвердити склад Української частини Спільного комітету "Уряд/ЮНІДО" (додається).

2. Дозволити голові Української частини Спільного комітету "Уряд/ЮНІДО" вносити у разі потреби зміни до її складу.

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 27 вересня 2002 р. N 1466 ( 1466-2002-п ) "Про затвердження нового складу Української частини Спільного комітету "Уряд/ЮНІДО" (Офіційний вісник України, 2002 р., N 40, ст. 1865).
