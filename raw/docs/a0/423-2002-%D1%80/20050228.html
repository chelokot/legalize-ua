КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 липня 2002 р. N 423-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 41-р ( 41-2005-р ) від 28.02.2005 )

Про митне оформлення сідельних тягачів

Дозволити Держмитслужбі здійснювати в установленому порядку митне оформлення великовагових автотранспортних засобів - сідельних тягачів (код згідно з УКТ ЗЕД 8701 201000), які ввозяться суб'єктами господарювання на митну територію України для власних потреб на умовах фінансового лізингу, з видачею цими суб'єктами податкового векселя на суму податку на додану вартість з терміном погашення не більше 240 днів.

Прем'єр-міністр України А.КІНАХ
