Текст документа від 12.01.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 листопада 2003 р. N 1847 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1236 ( 1236-2010-п ) від 27.12.2010 }

Про затвердження диференційованих нормативів плати за користування надрами для видобування уранової руди

{ Із змінами, внесеними згідно з Постановою КМ N 264 ( 264-2008-п ) від 26.03.2008 }

Відповідно до статті 30 Кодексу України про надра ( 132/94-ВР ) Кабінет Міністрів України постановляє:

1. Затвердити диференційовані нормативи плати за користування надрами для видобування уранової руди (додаються).

2. Внести до постанови Кабінету Міністрів України від 12 вересня 1997 р. N 1014 ( 1014-97-п ) "Про затвердження базових нормативів плати за користування надрами для видобування корисних копалин та Порядку справляння плати за користування надрами для видобування корисних копалин" (Офіційний вісник України, 1997 р., число 38, с. 8; 1998 р., N 3, ст. 98; 2000 р., N 10, ст. 383; 2001 р., N 29, ст. 1310, N 32, ст. 1480; 2002 р., N 9, ст. 408) такі зміни:

{ Підпункт 1 пункту 2 втратив чинність на підставі Постанови КМ N 264 ( 264-2008-п ) від 26.03.2008 }

2) у групі "Металеві корисні копалини" додатка до постанови виключити позицію "Уранова руда - 3".
