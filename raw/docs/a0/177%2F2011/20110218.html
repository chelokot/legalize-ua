Президент України; Указ від 02.02.2011 № 177/2011

Про направлення миротворчого контингенту для участі України в наданні підтримки Операції ООН у Кот-д'Івуарі

Стан: Чинний

Ідентифікатор: 177/2011

Текст документа від 18.02.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про направлення миротворчого контингенту для участі України в наданні підтримки Операції ООН у Кот-д'Івуарі

{ Указ схвалено Законом N 3001-VI ( 3001-17 ) від 04.02.2011, ВВР, 2011, N 33, ст.337 }

Ураховуючи зобов'язання України як держави - члена Організації Об'єднаних Націй,

беручи до уваги Резолюції Ради Безпеки ООН N 1609 ( 995_d44 ) від 24 червня 2005 року, N 1865 ( 995_h84 ) від 27 січня 2009 року, N 1880 ( 995_i06 ) від 30 липня 2009 року, N 1933 ( 995_i89 ) від 30 червня 2010 року, N 1951 ( 995_j04 ) від 24 листопада 2010 року, N 1962 від 20 грудня 2010 року та N 1967 від 19 січня 2011 року,

вважаючи, що участь України в наданні підтримки Операції ООН у Кот-д'ІвуарІ відповідає національним інтересам України, сприятиме підтриманню міжнародного миру і безпеки,

на підставі пропозиції Ради національної безпеки і оборони України, відповідно до Закону України "Про участь України в міжнародних миротворчих операціях" ( 613-14 ) постановляю:

1. Направити для участі України в наданні підтримки Операції ООН у Кот-д'Івуарі миротворчий контингент загальною чисельністю до 60 осіб з числа миротворчого контингенту України, який діє у складі Місії ООН у Ліберії, у строки, визначені Радою Безпеки ООН, на період до трьох місяців.

2. Кабінету Міністрів України забезпечити направлення миротворчого контингенту, зазначеного у статті 1 цього Указу.

Президент України В.ЯНУКОВИЧ

м. Київ, 2 лютого 2011 року N 177/2011
