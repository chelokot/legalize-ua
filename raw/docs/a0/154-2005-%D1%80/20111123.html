Кабінет Міністрів України; Розпорядження від 18.05.2005 № 154-р

Про віднесення посад працівників Генерального штабу Збройних Сил до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 154-2005-р

Текст документа від 23.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 травня 2005 р. N 154-р Київ

Про віднесення посад працівників Генерального штабу Збройних Сил до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 214-р ( 214-2011-р ) від 23.03.2011 N 1186-р ( 1186-2011-р ) від 23.11.2011 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Генерального штабу Збройних Сил до таких категорій посад державних службовців:

третя - начальник головного управління, управління, самостійного відділу; { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 1186-р ( 1186-2011-р ) від 23.11.2011 }

четверта - заступник начальника управління, начальник відділу та його заступник;

п'ята - начальник групи, спеціаліст. { Абзац четвертий Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 214-р ( 214-2011-р ) від 23.03.2011 }
