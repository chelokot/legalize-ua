{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 1554/5 ( z1290-13 ) від 30.07.2013 }

Про затвердження Розмірів плати за надання платних послуг Центральним відділом державної реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї

Відповідно до Переліку платних послуг, які можуть надаватися відділами державної реєстрації актів цивільного стану, затвердженого постановою Кабінету Міністрів України від 22.12.2010 N 1168 ( 1168-2010-п ) (із змінами), та пункту 7 наказу Міністерства юстиції України від 27.12.2010 N 3335/5 ( z1380-10 ) "Про затвердження Порядку надання платних послуг відділами державної реєстрації актів цивільного стану", зареєстрованого в Міністерстві юстиції України 29.12.2010 за N 1380/18675, НАКАЗУЮ:

1. Затвердити Розміри плати за надання платних послуг Центральним відділом державної реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї, що додаються.

2. Визнати таким, що втратив чинність, наказ Міністерства юстиції України від 23.06.2011 N 1708/5 ( z0761-11 ) "Про затвердження Розмірів плати за надання платних послуг Центральним відділом державної реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї", зареєстрований у Міністерстві юстиції України 23.06.2011 за N 761/19499.

3. Контроль за виконанням цього наказу покласти на директора Департаменту взаємодії з органами влади Зеркаль О.В.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр Олександр Лавринович
