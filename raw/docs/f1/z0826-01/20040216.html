НАКАЗ

N 528 від 31.07.2001 Зареєстровано в Міністерстві м.Київ юстиції України 18 вересня 2001 р. за N 826/6017

( Наказ втратив чинність на підставі Наказу Державної митної служби N 39 ( z0160-04 ) від 23.01.2004 )

Про затвердження змін і доповнень до наказу Держмитслужби від 17.08.98 N 511

З метою вдосконалення порядку здійснення операцій з митного контролю та митного оформлення природного газу, що переміщується через митний кордон України трубопровідним транспортом, НАКАЗУЮ:

1. Затвердити зміни й доповнення до Порядку митного контролю та митного оформлення природного газу, що переміщується через митний кордон України трубопровідним транспортом, затвердженого наказом Держмитслужби від 17.08.98 N 511 ( z0768-98 ) і зареєстрованого в Міністерстві юстиції 01.12.98 за N 768/3208 (додаються).

2. Управлінню нетарифного регулювання (Пашинний О.І.), Правовому управлінню (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію в Міністерство юстиції України.

3. Управлінню справами (Карпенко В.П.) забезпечити тиражування наказу та розсилку його до митних органів.

4. Контроль за виконанням наказу покласти на першого заступника Голови Служби Єгорова О.Б.

В.о. Голови Служби О.Б.Єгоров

Затверджено Наказ Державної митної служби України 31.07.2001 N 528

Зареєстровано в Міністерстві юстиції України 18 вересня 2001 р. за N 826/6017

Зміни й доповнення до Порядку митного контролю та митного оформлення природного газу, що переміщується через митний кордон України трубопровідним транспортом

Унести до пункту 3.9 Порядку митного контролю та митного оформлення природного газу, що переміщується через митний кордон України трубопровідним транспортом, затвердженого наказом Держмитслужби від 17.07.98 N 511 ( z0768-98 ) і зареєстрованого в Міністерстві юстиції України 01.12.98 за N 768/3208, такі зміни й доповнення:

а) доповнити частину "У режимі тимчасового ввезення газу" абзацом такого змісту:

"акт про прийняття-передання газу для зберігання його в ПСГ, підписаний сторонами зовнішньоекономічного договору (контракту) та завірений українським перевізником";

б) до частини "У разі зворотного вивезення газу" унести такі зміни й доповнення:

вилучити абзац 2;

доповнити частину абзацом такого змісту:

"акт про прийняття-передання газу при відборі його з ПСГ, підписаний сторонами зовнішньоекономічного договору (контракту) та завірений українським перевізником".

Начальник Управління нетарифного регулювання О.І.Пашинний
