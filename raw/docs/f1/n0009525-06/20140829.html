РАДА НАЦІОНАЛЬНОЇ БЕЗПЕКИ І ОБОРОНИ УКРАЇНИ

РІШЕННЯ

Про Комітет з політики військово-технічного співробітництва та експортного контролю при Президентові України

{ Рішення введено в дію Указом Президента N 1149/2006 ( 1149/2006 ) від 28.12.2006 }

{ Із змінами, внесеними згідно з Рішенням Ради національної безпеки і оборони ( n0010525-14 ) від 27.08.2014 }

Рада національної безпеки і оборони України вирішила:

1. Констатувати, що міжнародне військово-технічне співробітництво та державний експортний контроль залишаються важливими складовими зовнішньої і оборонної політики України.

2. Визнати за необхідне вжити додаткових заходів щодо підвищення ефективності реалізації державної політики у сфері міжнародного військово-технічного співробітництва та державного експортного контролю.

У зв'язку з цим:

1) визнати за доцільне ліквідувати Комітет з політики військово-технічного співробітництва та експортного контролю при Президентові України;

2) утворити відповідно до статті 14 Закону України "Про Раду національної безпеки і оборони України" ( 183/98-ВР ) Міжвідомчу комісію з політики військово-технічного співробітництва та експортного контролю як робочий орган при Раді національної безпеки і оборони України;

{ Підпункт 3 пункту 2 виключено на підставі Рішення Ради національної безпеки і оборони ( n0010525-14 ) від 27.08.2014 }

4) Секретареві Ради національної безпеки і оборони України подати у місячний строк на затвердження Президентові України проект Положення про Міжвідомчу комісію з політики військово-технічного співробітництва та експортного контролю і пропозиції щодо її персонального складу.

Це рішення прийнято одноголосно.
