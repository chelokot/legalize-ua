КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 жовтня 2008 р. N 1376-р Київ

Про затвердження плану заходів з реалізації Концепції формування енергетичного балансу

{ Із змінами, внесеними згідно з Постановою КМ N 77 ( 77-2015-п ) від 04.03.2015 }

1. Затвердити план заходів з реалізації Концепції формування енергетичного балансу, схваленої розпорядженням Кабінету Міністрів України від 28 листопада 2007 р. N 1058 ( 1058-2007-р ) (Офіційний вісник України, 2007 p., N 91, ст. 3343) (далі - план заходів), що додається.

2. Фінансове забезпечення виконання плану заходів здійснювати в межах коштів, передбачених відповідним центральним органам виконавчої влади в Державному бюджеті України на відповідний рік.

3. Міністерствам та іншим центральним органам виконавчої влади надсилати щокварталу до 10 числа наступного місяця Мінекономіки інформацію про стан виконання плану заходів для її узагальнення і подання Кабінетові Міністрів України.
