Президент України; Указ від 15.03.1996 № 192/96

Про додаткові заходи щодо фінансування потреб національної оборони, правоохоронної діяльності та забезпечення безпеки держави

Стан: Втратив чинність

Ідентифікатор: 192/96

Текст документа від 05.12.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Позначку "Опублікуванню не підлягає" знято Указом Президента N 963/2009 ( 963/2009 ) від 24.11.2009 }

Про додаткові заходи щодо фінансування потреб національної оборони, правоохоронної діяльності та забезпечення безпеки держави

З метою поліпшення фінансування національної оборони, правоохоронної діяльності та забезпечення безпеки держави, на часткову зміну статті 1 Указу Президента України від 18 червня 1993 року N 219 ( 219/93 ) "Про порядок виконання Державного бюджету України" постановляю:

Міністерству фінансів України забезпечити стабільне і гарантоване фінансування видатків на виплату грошового утримання та заробітної плати, оплату продовольства, озброєння, військової техніки та інших видів матеріально-технічного забезпечення Збройних Сил України, Прикордонних військ України, Національної гвардії України, Служби безпеки України, органів внутрішніх справ щодекадне в обсягах не менше третини планових призначень на місяць, використовуючи в разі потреби кредити Національного банку України та інші джерела фінансування дефіциту Державного бюджету України.

Президент України Л.КУЧМА

м. Київ, 15 березня 1996 року N 192/96
