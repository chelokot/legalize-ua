{ Із змінами, внесеними згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

Відповідно до статей 15 та 18 Закону України "Про радіочастотний ресурс України" ( 1770-14 ) Національна комісія з питань регулювання зв'язку України ВИРІШИЛА:

2. Начальнику Державної інспекції зв'язку Звєрєву В.П. у встановленому порядку забезпечити подання цього рішення на державну реєстрацію до Міністерства юстиції України.

3. Розмістити Порядок здійснення державного нагляду за користуванням радіочастотним ресурсом України в смугах радіочастот загального користування на веб-сайті НКРЗ та у наступному випуску офіційного бюлетеня НКРЗ у тижневий строк після державної реєстрації.

4. Контроль за виконанням цього рішення покласти на Голову НКРЗ.

ЗАТВЕРДЖЕНО Рішення Національної комісії з питань регулювання зв'язку України 27.10.2006 N 427

Зареєстровано в Міністерстві юстиції України 15 листопада 2006 р. за N 1204/13078

ПОРЯДОК здійснення державного нагляду за користуванням радіочастотним ресурсом України в смугах радіочастот загального користування

1. Загальні положення

1.1. Цей Порядок, розроблений відповідно до Законів України "Про радіочастотний ресурс України" ( 1770-14 ), "Про основні засади державного нагляду (контролю) у сфері господарської діяльності" ( 877-16 ), інших нормативно-правових актів у сфері користування радіочастотним ресурсом України (далі - РЧР), визначає механізм здійснення державного нагляду за користуванням радіочастотним ресурсом України в смугах радіочастот загального користування.

{ Пункт 1.1 в редакції Рішення Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

1.2. Метою державного нагляду за користуванням радіочастотним ресурсом України є забезпечення дотримання користувачами РЧР встановленого порядку користування РЧР, інтересів та безпеки держави і громадян України, забезпечення електромагнітної сумісності радіоелектронних засобів (далі - РЕЗ) та випромінювальних пристроїв (далі - ВП) будь-якого призначення та запобігання правопорушенням при користуванні РЧР.

1.3. Основними завданнями державного нагляду за користуванням РЧР є:

нагляд за додержанням законодавства про РЧР;

контроль за додержанням користувачами РЧР ліцензійних умов користування РЧР, умов ліцензій на користування РЧР та дозволів на експлуатацію РЕЗ та ВП;

контроль за додержанням встановлених законодавством умов ввезення з-за кордону, реалізації та експлуатації РЕЗ та ВП на території України;

запобігання, виявлення та усунення правопорушень при користуванні РЧР.

1.4. Координацію та контроль за здійсненням державного нагляду за користуванням радіочастотним ресурсом України здійснює Національна комісія з питань регулювання зв'язку України (далі - НКРЗ).

Державний нагляд за користуванням РЧР у смугах частот загального користування здійснює Державна інспекція зв'язку (далі - ДІЗ).

1.5. Для участі в здійсненні заходів державного нагляду за користуванням РЧР може залучатися Український державний центр радіочастот (далі - УДЦР) за дорученням НКРЗ на підставі письмового звернення ДІЗ.

У разі необхідності ДІЗ має право залучати до участі в перевірках фахівців центральних та місцевих органів виконавчої влади, органів місцевого самоврядування, органів державної податкової служби, правоохоронних органів, науково - дослідних установ, інших установ та організацій (за погодженням з їх керівниками) як технічних консультантів, експертів.

1.6. Для здійснення державного нагляду за користуванням РЧР ДІЗ має право безоплатно отримувати від користувачів РЧР відповідну інформацію.

1.7. Об'єктом державного нагляду (перевірок) за користуванням РЧР є діяльність користувачів РЧР у смугах радіочастот загального користування, їх філій, інших відокремлених структурних підрозділів, суб'єктів господарювання, що здійснюють ввезення з-за кордону, реалізацію РЕЗ та ВП, а також юридичних та фізичних осіб, що користуються РЧР без ліцензій на користування РЧР, дозволів на експлуатацію РЕЗ та ВП у разі, якщо необхідність отримання ними таких ліцензій та дозволів передбачена Законом України "Про радіочастотний ресурс України" ( 1770-14 ).

1.8. ДІЗ здійснює аналіз результатів державного нагляду за користуванням РЧР та інформує щоквартально НКРЗ про його результати. Інформація щодо результатів державного нагляду ДІЗ публікується в офіційному бюлетені НКРЗ та на веб-сайті ДІЗ.

2. Організація державного нагляду за користуванням РЧР

2.1. Державний нагляд за користуванням РЧР здійснюється шляхом проведення планових, позапланових перевірок та комплексу відповідних заходів, у тому числі спрямованих на усунення виявлених порушень та недоліків щодо користування РЧР.

{ Абзац другий пункту 2.1 виключено на підставі Рішення Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

2.2. При здійсненні планових, позапланових перевірок враховуються результати радіочастотного моніторингу. { Абзац перший пункту 2.2 із змінами, внесеними згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

У випадку виявлення під час здійснення радіочастотного моніторингу порушень законодавства про РЧР УДЦР направляє матеріали радіочастотного моніторингу до ДІЗ з висновками щодо порушених норм законодавства.

УДЦР на запит ДІЗ надає результати радіочастотного моніторингу, необхідні для проведення планових, позапланових перевірок конкретних користувачів РЧР, іншу інформацію за результатами радіочастотного моніторингу. { Абзац третій пункту 2.2 із змінами, внесеними згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

2.3. Планові перевірки користувачів РЧР здійснюються з періодичністю, що залежить від ступеня ризику їх господарської діяльності, передбаченого постановою Кабінету Міністрів України від 09.04.2008 N 315 ( 315-2008-п ) "Про затвердження критерію оцінки ступеня ризику діяльності суб'єктів господарювання у сфері телекомунікацій та надання послуг поштового зв'язку" та з урахуванням вимог постанови Кабінету Міністрів України від 21.05.2009 N 502 ( 502-2009-п ) "Про тимчасові обмеження щодо здійснення заходів державного нагляду (контролю) у сфері господарської діяльності на період до 31 грудня 2010 року".

Планові перевірки проводяться відповідно до квартальних планів перевірок (додаток 1), які затверджуються ДІЗ до 25 числа останнього місяця кварталу, що передує плановому.

{ Пункт 2.3 в редакції Рішення Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

2.4. Позапланові перевірки користувачів РЧР проводяться за наказом ДІЗ, виданим на підставі:

подання користувачем РЧР письмової заяви до НКРЗ та/або ДІЗ про здійснення перевірки за його бажанням;

письмового звернення фізичної або юридичної особи, звернення правоохоронних органів та інших органів державної влади про порушення користувачем РЧР законодавства (стандартів та інших нормативних документів у сфері користування радіочастотним ресурсом України у смугах радіочастот загального користування, ліцензійних умов користування РЧР, особливих умов ліцензій та/або умов дозволів на експлуатацію), що надійшло до ДІЗ та/або НКРЗ. Позаплановий захід у цьому разі здійснюється за погодженням з Головою НКРЗ;

надходження повідомлення УДЦР або його філій, підтвердженого засвідченими в установленому порядку копіями протоколів технічного радіоконтролю, про виявлені порушення користувачем радіочастотного ресурсу законодавства в сфері користування РЧР. Позаплановий захід у цьому разі здійснюється за погодженням з Головою НКРЗ.

Позапланова перевірка здійснюється лише з питань, що стали підставою для здійснення цієї перевірки, з обов'язковим зазначенням їх у посвідченні на проведення перевірки.

Користувач РЧР повинен ознайомитися з підставою проведення позапланової перевірки з наданням йому копії відповідного документа.

{ Пункт 2.4 в редакції Рішення Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

2.5. Для здійснення планової, позапланової перевірки користувачів РЧР ДІЗ видає наказ, який повинен містити найменування користувача РЧР, що має перевірятися, предмет перевірки та строки її проведення.

На підставі наказу створюється комісія ДІЗ та оформляється посвідчення на проведення перевірки користувача РЧР (додаток 2) (далі - посвідчення), яке підписується керівником ДІЗ або його заступником (із зазначенням його прізвища, ім'я та по батькові) та засвідчується печаткою ДІЗ.

Посвідчення є чинним лише протягом зазначеного в ньому строку здійснення перевірки.

{ Пункт 2.5 в редакції Рішення Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

2.6. Посвідчення реєструються в журналі обліку посвідчень на проведення перевірок (додаток 3), сторінки якого мають бути пронумеровані, прошнуровані та скріплені печаткою ДІЗ.

2.7. Строк здійснення планової перевірки не може перевищувати п'ятнадцяти робочих днів, а для суб'єктів малого підприємництва - п'яти робочих днів.

Строк здійснення позапланової перевірки не може перевищувати десяти робочих днів, а для суб'єктів малого підприємництва - двох робочих днів.

Продовження строку здійснення планової та позапланової перевірок не допускається.

{ Пункт 2.7 в редакції Рішення Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

3. Порядок проведення перевірок

3.1. ДІЗ здійснює планові перевірки за умови письмового повідомлення користувача РЧР про проведення перевірки не пізніше ніж за десять днів до дня здійснення цієї перевірки. Повідомлення надсилається рекомендованим листом чи телефонограмою за рахунок коштів ДІЗ або вручається особисто керівнику чи уповноваженій особі користувача РЧР під розписку.

У разі проведення перевірки філій, інших відокремлених підрозділів користувача РЧР ДІЗ повідомляє в установленому законодавством порядку користувача РЧР, а також його відповідні філії, інші відокремлені підрозділи.

Про проведення позапланової перевірки користувач радіочастотного ресурсу України та його філії, інші відокремлені підрозділи повідомляються безпосередньо перед її початком.

{ Пункт 3.1 в редакції Рішення Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

3.2. На початку здійснення перевірки голова комісії ДІЗ зобов'язаний пред'явити керівнику користувача РЧР (його філії, іншого відокремленого підрозділу) або уповноваженій ним особі посвідчення на перевірку та службові посвідчення, що засвідчують особу голови та членів комісії, і надати суб'єкту господарювання копію такого посвідчення.

Перед проведенням позапланової перевірки голова комісії, крім цього, повинен ознайомити керівника користувача РЧР з підставою для проведення позапланової перевірки та зобов'язаний надати йому копію документа, що став підставою для проведення відповідної перевірки.

У разі відмови користувача РЧР у допуску комісії ДІЗ до проведення перевірки, а також при вчиненні перешкод у здійсненні перевірки комісія складає відповідний акт, який підписують голова та члени комісії.

{ Пункт 3.2 в редакції Рішення Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

3.3. Керівник (уповноважений представник) юридичної особи чи фізична особа на зворотному боці посвідчення робить запис про ознайомлення з посвідченням, про призначення особи, відповідальної за забезпечення перевірки та підписання акта перевірки, засвідчує цей запис підписом та печаткою.

3.4. Голова комісії перед початком перевірки повинен зробити запис у журналі реєстрації перевірок (за його наявності), заповнюючи всі передбачені графи, та засвідчити його своїм підписом. У разі відсутності журналу реєстрації перевірок комісія повинна відобразити цей факт в акті перевірки.

3.5. При проведенні планової та позапланової перевірки комісія перевіряє:

3.5.1. У разі перевірки користувачів РЧР, які користуються РЧР на підставі ліцензії на користування РЧР та дозволів на експлуатацію РЕЗ:

наявність оригіналів ліцензій на користування РЧР у ліцензіата, їх копій у кожній філії або іншому відокремленому підрозділі та дозволів на експлуатацію на всі РЕЗ, що експлуатуються користувачем РЧР;

відповідність даних ліцензії на користування РЧР свідоцтву про державну реєстрацію;

додержання користувачем РЧР вимог законодавства про РЧР, в тому числі ліцензійних умов користування РЧР, умов ліцензій на користування РЧР та умов дозволів на експлуатацію РЕЗ, що експлуатуються;

відповідність створених телекомунікаційних мереж наданим дозволам на експлуатацію РЕЗ;

достовірність відомостей у документах, наданих суб'єктом господарювання для отримання ліцензії та/або дозволу на експлуатацію РЕЗ;

відповідність типів та параметрів РЕЗ, що використовуються в телекомунікаційній мережі, зазначеним у дозволах на експлуатацію РЕЗ;

додержання користувачем РЧР параметрів випромінювання і допустимих норм радіозавад, визначених дозволами на експлуатацію РЕЗ;

своєчасність подання повідомлення про зміну даних у документах, що додавались до заяв про видачу ліцензії на користування РЧР та відповідних дозволів на експлуатацію РЕЗ;

додержання умов застосування РЕЗ на території України;

забезпечення організаційних заходів стосовно захисту телекомунікаційних мереж користувача РЧР від несанкціонованого доступу;

своєчасність виконання користувачем РЧР рішень НКРЗ та розпоряджень (приписів) ДІЗ про усунення порушень законодавства щодо користування РЧР, в тому числі ліцензійних умов, умов ліцензій на користування РЧР та умов дозволів на експлуатацію РЕЗ;

своєчасність та повноту здійснення платежів та зборів за користування РЧР, за роботи, пов'язані з користуванням РЧР.

3.5.2. У разі перевірки користувачів РЧР, які користуються РЧР для розповсюдження телерадіопрограм на підставі ліцензій на мовлення, виданих Національною радою України з питань телебачення і радіомовлення, та дозволів на експлуатацію РЕЗ:

наявність у користувача РЧР копій ліцензій на мовлення, виданих Національною радою України з питань телебачення і радіомовлення, дозволів на експлуатацію РЕЗ;

достовірність відомостей у документах, поданих для отримання дозволу на експлуатацію РЕЗ;

наявність у користувача РЧР договору на розповсюдження телерадіопрограм з власником ліцензії на мовлення;

відповідність даних дозволу на експлуатацію РЕЗ свідоцтву про державну реєстрацію користувача РЧР;

додержання користувачем РЧР умов дозволів на експлуатацію РЕЗ;

відповідність типів та параметрів РЕЗ, що використовуються для розповсюдження телерадіопрограм, зазначеним у дозволах на експлуатацію;

додержання користувачем РЧР параметрів випромінювання і норм на допустимі відхилення радіопередавачів;

своєчасність подання повідомлення про зміну даних у документах, що додавались до заяви про видачу дозволів на експлуатацію РЕЗ;

забезпечення організаційних заходів стосовно захисту телекомунікаційних мереж користувача РЧР від несанкціонованого доступу;

своєчасність виконання користувачем РЧР рішень НКРЗ та розпоряджень (приписів) ДІЗ про усунення порушень законодавства щодо користування РЧР та умов дозволів на експлуатацію РЕЗ;

своєчасність та повноту сплати збору за користування РЧР та платежів за роботи, пов'язані з користуванням РЧР.

3.5.3. У разі перевірки технологічних користувачів РЧР:

наявність дозволів на експлуатацію на всі РЕЗ та ВП, що використовуються користувачем РЧР;

відповідність дозволів на експлуатацію РЕЗ та ВП свідоцтву про державну реєстрацію користувача РЧР;

додержання користувачем РЧР умов законодавства та дозволів на експлуатацію РЕЗ та ВП;

відповідність складу телекомунікаційних мереж отриманим дозволам на експлуатацію РЕЗ;

відповідність типів та параметрів РЕЗ та ВП, що використовуються користувачем РЧР, зазначеним у дозволах на експлуатацію РЕЗ та ВП;

додержання користувачем РЧР параметрів випромінювання і допустимих норм радіозавад;

додержання користувачем РЧР законодавства щодо приєднання радіомережі та РЕЗ до телекомунікаційних мереж загального користування;

своєчасність виконання користувачем РЧР рішень НКРЗ та розпоряджень (приписів) ДІЗ про усунення порушень законодавства щодо користування РЧР, умов дозволів на експлуатацію РЕЗ та ВП;

своєчасність та повноту сплати збору за користування РЧР та платежів за роботи, пов'язані з користуванням РЧР;

своєчасність подання користувачем РЧР повідомлення про зміну даних у документах, що додавались до заяви про видачу дозволів на експлуатацію РЕЗ та ВП;

забезпечення організаційних заходів стосовно захисту телекомунікаційних мереж користувача РЧР від несанкціонованого доступу.

3.5.4. У разі перевірки суб'єктів господарювання, які здійснюють ввезення з-за кордону та реалізацію РЕЗ та ВП:

наявність передбачених Законом України "Про радіочастотний ресурс України" ( 1770-14 ) дозволів на ввезення з-за кордону і реалізацію РЕЗ та ВП;

додержання інших вимог законодавства щодо ввезення з-за кордону та реалізації РЕЗ та ВП.

4. Порядок оформлення результатів перевірок

4.1. За результатами перевірки комісією складається акт перевірки додержання законодавства про радіочастотний ресурс (далі - акт перевірки) згідно з додатком 4 у двох примірниках, які підписуються головою і членами комісії не пізніше останнього дня перевірки, зазначеного у посвідченні, та передаються для ознайомлення керівнику юридичної особи (уповноваженому представнику ) чи фізичній особі.

4.1.1. Керівник (уповноважений представник) юридичної особи чи фізична особа на одному примірнику акта перевірки засвідчує, що ознайомлений з актом перевірки і отримав один примірник, ставить свій підпис, дату, печатку (за наявності) і того ж дня повертає цей примірник голові комісії, а також може додати зауваження та/або пояснення до акта перевірки, про що зазначає в ньому під час ознайомлення з актом перевірки.

Якщо для подання письмових зауважень та/або пояснень через їх значний обсяг або складність недостатньо останнього дня перевірки, керівник (уповноважений представник) юридичної особи чи фізична особа зазначає в акті перевірки перед своїм підписом конкретну дату їх надання та надсилає їх у формі листа на адресу ДІЗ протягом трьох робочих днів від дня підписання акта перевірки.

4.1.2. У разі відмови керівника (уповноваженого представника) юридичної особи чи фізичної особи від ознайомлення з актом перевірки або його підписання (у тому числі з зауваженнями) голова комісії робить відповідний запис в обох примірниках акта перевірки про те, що ця особа відмовилася від ознайомлення з актом перевірки або з актом ознайомлена, але підписувати відмовилася. Цей запис засвідчується підписами голови та членів комісії.

Один примірник акта перевірки з відповідним записом протягом трьох робочих днів після підписання акта перевірки ДІЗ направляє рекомендованим листом з повідомленням про вручення юридичній чи фізичній особі, що перевірялась.

У цьому випадку зауваження (пояснення) до акта перевірки не приймаються.

4.2. Порушення, викладені в акті перевірки, повинні мати посилання на конкретні пункти, частини, статті законів, нормативно-правових актів, умов ліцензій на користування РЧР та дозволів на експлуатацію РЕЗ та ВП.

Забороняється включати до акта перевірки відомості та порушення, які не було виявлено під час перевірки, та раніше виявлені порушення, які було усунуто.

4.3. У разі виявлення порушень законодавства щодо користування РЧР, в тому числі ліцензійних умов, з боку користувача, який користується РЧР на підставі ліцензії на користування РЧР, за результатами перевірки здійснюються такі дії:

голова комісії складає протокол про вчинення адміністративного правопорушення відповідно до Кодексу України про адміністративні правопорушення ( 80731-10, 80732-10 ) (додаток 5);

уповноважена посадова особа ДІЗ оформлює розпорядження про усунення порушень ліцензійних умов користування радіочастотним ресурсом України (додаток 6) або припис про усунення порушень законодавства про радіочастотний ресурс України (додаток 7);

уповноважена посадова особа ДІЗ розглядає справу та виносить постанову за справою про адміністративне правопорушення, пов'язане з порушенням законодавства про радіочастотний ресурс України (додаток 8).

Розпорядження (припис) щодо усунення виявлених порушень протягом двадцяти робочих днів з дати підписання акта перевірки ДІЗ надсилає рекомендованим листом з повідомленням про вручення користувачеві РЧР.

Розпорядження (припис) може бути вручено представнику юридичної особи чи фізичній особі, діяльність якої перевірялась, з обов'язковим зазначенням на зворотному боці другого примірника дати отримання, прізвища, ініціалів представника юридичної особи чи фізичної особи, засвідчених його підписом.

За наявності підстав комісія складає акти, визначені пунктами 2-6 частини першої статті 38 Закону України "Про радіочастотний ресурс України" ( 1770-14 ).

У разі виявлення за наслідками перевірки підстав для анулювання ліцензії, визначених Законом України "Про радіочастотний ресурс України" ( 1770-14 ), ДІЗ передає до НКРЗ пропозиції щодо анулювання ліцензії та копії відповідних актів.

4.4. У разі виявлення порушень з боку користувача РЧР законодавства про РЧР, умов дозволів на експлуатацію РЕЗ та ВП за результатами перевірки здійснюються такі дії:

голова комісії складає протокол про вчинення адміністративного правопорушення відповідно до Кодексу України про адміністративні правопорушення ( 80731-10, 80732-10 );

уповноважена посадова особа ДІЗ оформлює припис про усунення порушень законодавства про радіочастотний ресурс України (додаток 7);

уповноважена посадова особа ДІЗ розглядає справу та виносить постанову за справою про адміністративне правопорушення, пов'язане з порушенням законодавства про радіочастотний ресурс України (додаток 8).

Приписи (розпорядження) протягом п'яти робочих днів з дати складання акта перевірки ДІЗ вручаються користувачеві РЧР або уповноваженій ним особі. { Абзац п'ятий пункту 4.4 в редакції Рішення Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

Один примірник припису (розпорядження) вручається користувачу РЧР або уповноваженій ним особі. { Пункт 4.4 доповнено абзацом шостим згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

Другий примірник припису (розпорядження) з підписом користувача РЧР або уповноваженої ним особи щодо погоджених термінів усунення порушень вимог законодавства залишається в ДІЗ. { Пункт 4.4 доповнено абзацом сьомим згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

Особа, що отримала припис (розпорядження), повинна зазначити свою посаду, прізвище, ініціали та дату отримання припису (розпорядження). Підпис засвідчується печаткою користувача РЧР (за наявності). { Пункт 4.4 доповнено абзацом восьмим згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

У разі відмови користувача РЧР або уповноваженої ним особи від отримання припису (розпорядження) він направляється рекомендованим листом, а на копії документа, який залишається в ДІЗ, проставляються відповідний вихідний номер і дата такого листа. { Пункт 4.4 доповнено абзацом дев'ятим згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

Припис (розпорядження) ДІЗ можуть бути оскаржені до НКРЗ або до суду в установленому законом порядку. { Пункт 4.4 доповнено абзацом десятим згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

За наявності підстав комісія складає акти, визначені пунктами 3-5 частини другої статті 45 Закону України "Про радіочастотний ресурс України" ( 1770-14 ).

У разі виявлення з боку користувача РЧР порушень законодавства про РЧР, умов дозволів на експлуатацію РЕЗ та ВП, які є підставою для анулювання дозволу на експлуатацію РЕЗ та ВП, ДІЗ відповідно до законодавства приймає рішення про анулювання дозволу або звертається до НКРЗ щодо прийняття рішення про анулювання дозволу на експлуатацію РЕЗ та ВП.

4.5. Юридична, фізична особа, яка одержала розпорядження (припис) ДІЗ, зобов'язана в установлений в розпорядженні (приписі) ДІЗ строк усунути виявлені порушення та в письмовій формі повідомити про це ДІЗ.

4.6. У разі невиконання розпорядження (припису) ДІЗ складається протокол про адміністративне правопорушення відповідно до статті 188-7 Кодексу України про адміністративні правопорушення ( 80731-10 ).

5. Права та обов'язки осіб, діяльність яких перевіряється

5.1. Під час здійснення в установленому законодавством порядку державного нагляду за користуванням РЧР користувачі РЧР мають право:

5.1.1 вимагати від посадових осіб ДІЗ додержання вимог законодавства;

5.1.2 перевіряти наявність у посадових осіб ДІЗ службового посвідчення і одержувати копії посвідчення (направлення) на проведення планового або позапланового заходу;

5.1.3 не допускати посадових осіб ДІЗ до здійснення державного нагляду, якщо:

він здійснюється з порушенням вимог щодо періодичності проведення заходів державного нагляду, передбачених законодавством;

комісією ДІЗ не надано копії документів, передбачених пунктом 3.2 цього Порядку, або якщо надані документи не відповідають вимогам законодавства;

5.1.4 бути присутніми під час здійснення перевірки;

5.1.5 вимагати нерозголошення інформації, що є комерційною таємницею користувача РЧР;

5.1.6 одержувати та знайомитися з актами перевірки;

5.1.7 надавати в письмовій формі свої пояснення, зауваження або заперечення до акта перевірки;

5.1.8 оскаржувати дії голови та членів комісії, розпорядження (приписи) ДІЗ до НКРЗ чи до суду в установленому законом порядку. { Пункт 5.1 в редакції Рішення Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

5.2. Юридичні, фізичні особи, діяльність яких перевіряється, згідно з цим Положенням під час здійснення державного нагляду зобов'язані:

допускати голову та членів комісії на територію та в приміщення для проведення перевірки;

визначати особу, відповідальну за проведення перевірки;

надавати комісії усі необхідні для проведення перевірки документи або засвідчені в установленому порядку копії документів, що перевіряються, письмові пояснення, засвідчені підписом та печаткою керівника (уповноваженого представника) юридичної особи чи фізичної особи, та забезпечувати умови для її проведення;

надавати на вимогу комісії засвідчені в установленому порядку, у тому числі печаткою (за наявності) та підписом керівника (уповноваженого представника) юридичної особи чи фізичної особи, копії документів, що підтверджують факти, викладені в акті перевірки;

виконувати розпорядження (приписи) ДІЗ про усунення порушень, виявлених під час перевірки;

одержувати примірник акта перевірки, припису (розпорядження). { Пункт 5.2 доповнено абзацом згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

6. Права та обов'язки комісії

6.1. При здійсненні в установленому порядку державного нагляду за користуванням РЧР голова та члени комісії мають право:

доступу в установленому порядку відповідно до законодавства України на територію і в приміщення користувачів РЧР для з'ясування питань, що є предметом перевірки;

доступу в установленому порядку на територію і в приміщення користувачів РЧР з метою перевірки використання розташованих у них РЕЗ та ВП, в тому числі, коли вказані РЕЗ та ВП створюють радіозавади, з метою припинення використання РЕЗ та ВП, що використовуються без дозволів на експлуатацію, а також суб'єктів господарювання, що здійснюють ввезення з-за кордону та реалізацію РЕЗ та ВП;

знайомитись з необхідними для проведення перевірки документами, отримувати їх засвідчені копії;

безоплатно отримувати від юридичних та фізичних осіб, діяльність яких перевіряється, необхідну інформацію, пояснення, у тому числі письмові, підписані керівником юридичної особи (уповноваженим представником) чи фізичною особою, засвідчені печаткою (за наявності);

застосовувати при проведенні перевірки користувача РЧР засоби фото-, відео- та аудіозапису;

вимагати від користувача РЧР (його філій, інших відокремлених підрозділів) усунення виявлених порушень вимог законодавства; { Пункт 6.1 доповнено абзацом згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

вимагати припинення дій, які перешкоджають здійсненню перевірки; { Пункт 6.1 доповнено абзацом згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

надавати (надсилати) обов'язкові для виконання приписи (розпорядження); { Пункт 6.1 доповнено абзацом згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

накладати штрафні санкції та вживати заходів, передбачених законом. { Пункт 6.1 доповнено абзацом згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

6.2. Голова та члени комісії зобов'язані:

керуватись у своїй роботі законодавством України;

об'єктивно відображати в акті перевірки стан справ щодо додержання законодавства про РЧР, в тому числі ліцензійних умов, умов ліцензій та дозволів на експлуатацію РЕЗ та ВП;

забезпечувати збереження державної, комерційної таємниці, конфіденційної та іншої інформації з обмеженим доступом;

повно, об'єктивно та неупереджено здійснювати державний нагляд у межах повноважень, передбачених законом; { Пункт 6.2 доповнено абзацом згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

дотримуватися ділової етики у взаємовідносинах з користувачем РЧР; { Пункт 6.2 доповнено абзацом згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

не втручатися і не перешкоджати здійсненню господарської діяльності під час здійснення перевірки, якщо це не загрожує життю та здоров'ю людей, не спричиняє небезпеки виникнення техногенних ситуацій і пожеж; { Пункт 6.2 доповнено абзацом згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

забезпечувати нерозголошення комерційної таємниці користувача РЧР, що стає доступною посадовим особам під час здійснення державного нагляду. { Пункт 6.2 доповнено абзацом згідно з Рішенням Національної комісії з питань регулювання зв'язку N 1501 ( z0499-09 ) від 14.05.2009 }

6.3. У разі виявлення під час здійснення державного нагляду правопорушень, що можуть містити ознаки злочину, ДІЗ передає матеріали до правоохоронних органів відповідно до законодавства.
