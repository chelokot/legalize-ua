Про затвердження типових договорів купівлі-продажу

Відповідно до Закону України "Про приватизацію невеликих державних підприємств (малу приватизацію)" ( 2171-12 ) та на виконання доручення Кабінету Міністрів України від 19 липня 1996 р. N 8558/32 НАКАЗУЮ:

1. Затвердити типові договори купівлі-продажу об'єктів малої приватизації:

- типовий договір купівлі-продажу цілісного майнового комплексу за конкурсом ( z0767-96 );

- типовий договір купівлі-продажу цілісного майнового комплексу на аукціоні ( z0768-96 );

- типовий договір купівлі-продажу цілісного майнового комплексу при викупі ( z0769-96 );

- типовий договір купівлі-продажу будівлі (споруди, приміщення), яка підлягає продажу за конкурсом ( z0770-96 );

- типовий договір купівлі-продажу будівлі (споруди, приміщення), яка підлягає продажу на аукціоні ( z0771-96 );

- типовий договір купівлі-продажу будівлі (споруди, приміщення) шляхом викупу ( z0772-96 );

- типовий договір купівлі-продажу патенту на право оренди будівлі (споруди, приміщення), який підлягає продажу за конкурсом ( z0773-96 );

- типовий договір купівлі-продажу патенту на право оренди будівлі (споруди, приміщення), який підлягає продажу на аукціоні ( z0774-96 );

- типовий договір купівлі-продажу патенту на право оренди будівлі (споруди, приміщення) ( z0775-96 );

- типовий договір купівлі-продажу об'єкта незавершеного будівництва, що підлягає продажу за конкурсом ( z0776-96 );

- типовий договір купівлі-продажу об'єкта незавершеного будівництва, що підлягає продажу на аукціоні ( z0777-96 );

- типовий договір купівлі-продажу об'єкта незавершеного будівництва, що підлягає продажу шляхом викупу ( z0778-96 ).

2. Фонду державного майна України, його регіональним відділенням та органам приватизації Автономної Республіки Крим посилити контроль за виконанням покупцями умов договорів купівлі-продажу державного майна.

3. Якщо до розділу "Права і обов'язки сторін" в умовах продажу включено внесення інвестицій, то до розділу "Відповідальність покупця" потрібно вносити пункт такої редакції:

При повному або частковому невиконанні умов договорів купівлі-продажу встановлюється така відповідальність покупців:

За порушення встановлених умовами договору купівлі-продажу строків внесення інвестицій покупцями сплачується пеня у розмірі 0,1 відсотка від загального обсягу невнесених інвестицій за кожний день просрочки;

При відмові від інвестування об'єкта приватизації в термін дії договору купівлі-продажу, відповідно до взятих покупцем зобов'язань, продавець порушує питання про розірвання договору.

4. Сторони мають право встановлювати додаткові умови укладання договорів купівлі-продажу, які не суперечать законодавчим і нормативним актам.

5. Департаменту правового забезпечення зареєструвати типові договори купівлі-продажу об'єктів малої приватизації у Міністерстві юстиції України.

6. Відповідальність за виконання наказу покласти на начальників регіональних відділень та представництв Фонду державного майна України, органів приватизації Автономної Республіки Крим.

В.о. Голови Фонду Є.Григоренко
