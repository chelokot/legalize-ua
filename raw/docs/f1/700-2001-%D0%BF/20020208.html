Про запровадження мінімальних цін на вітчизняні та імпортні алкогольні напої

Стан: Втратив чинність

Ідентифікатор: 700-2001-п

Текст документа від 08.02.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 червня 2001 р. N 700 Київ

Про запровадження мінімальних цін на вітчизняні та імпортні горілку і лікеро-горілчані вироби

( Із змінами, внесеними згідно з Постановою КМ N 124 ( 124-2002-п ) від 08.02.2002 )

З метою забезпечення надходження коштів до бюджетів усіх рівнів Кабінет Міністрів України постановляє:

1. Затвердити розміри мінімальних цін на вітчизняні та імпортні горілку і лікеро-горілчані вироби, що реалізуються в Україні підприємствами оптової і роздрібної торгівлі, громадського харчування, підприємствами - виробниками незалежно від форми власності та фізичними особами - суб'єктами підприємницької діяльності (додаються). ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 124 ( 124-2002-п ) від 08.02.2002 )

Установити, що порядок визначення та застосування мінімальних цін на вітчизняні та імпортні горілку і лікеро-горілчані вироби і зміни до них затверджує Міністерство економіки та з питань європейської інтеграції разом з Міністерством аграрної політики та Державною податковою адміністрацією. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 124 ( 124-2002-п ) від 08.02.2002 )

2. Раді міністрів Автономної Республіки Крим, обласним, Київській і Севастопольській міським державним адміністраціям забезпечити у п'ятиденний термін проведення інвентаризації на підприємствах торгівлі, що реалізують вітчизняні та імпортні горілку і лікеро-горілчані вироби, і у разі застосування ними цін у розмірі, нижчому від мінімального, організувати проведення дооцінки продукції відповідно до законодавства.

3. Міністерству економіки та з питань європейської інтеграції, Державній податковій адміністрації, Раді міністрів Автономної Республіки Крим, обласним, Київській і Севастопольській міським державним адміністраціям установити контроль за дотриманням державної дисципліни цін та правил торгівлі у сфері реалізації (продажу) горілки і лікеро-горілчаних виробів.

( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 124 ( 124-2002-п ) від 08.02.2002 )

4. Контроль за виконанням цієї постанови покласти на Голову Державної податкової адміністрації.

( Пункт 4 із змінами, внесеними згідно з Постановою КМ N 124 ( 124-2002-п ) від 08.02.2002 )

5. Ця постанова набирає чинності через 10 днів з дня опублікування.
