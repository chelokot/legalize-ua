Про внесення змін до постанови Кабінету Міністрів України від 28 вересня 1996 р. N 1177 та Порядку використання коштів Фонду для здійснення заходів щодо ліквідації наслідків Чорнобильської катастрофи та соціального захисту населення

Стан: Втратив чинність

Ідентифікатор: 85-2004-п

Текст документа від 05.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 січня 2004 р. N 85 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 388 ( 388-2009-п ) від 22.04.2009 }

Про внесення змін до постанови Кабінету Міністрів України від 28 вересня 1996 р. N 1177 та Порядку використання коштів Фонду для здійснення заходів щодо ліквідації наслідків Чорнобильської катастрофи та соціального захисту населення

( Із змінами, внесеними згідно з Постановою КМ N 931 ( 931-2005-п ) від 16.09.2005 )

Кабінет Міністрів України постановляє:

1. Внести до постанови Кабінету Міністрів України від 28 вересня 1996 р. N 1177 ( 1177-96-п ) "Питання Чорнобильського центру з проблем ядерної безпеки, радіоактивних відходів та радіоекології" (ЗП України, 1996 р., N 18, ст. 512; Офіційний вісник України, 2002 р., N 8, ст. 342) та Порядку використання коштів Фонду для здійснення заходів щодо ліквідації наслідків Чорнобильської катастрофи та соціального захисту населення, затвердженого постановою Кабінету Міністрів України від 20 червня 2000 р. N 987 ( 987-2000-п ) (Офіційний вісник України, 2000 р., N 25, ст. 1054; 2001 р., N 32, ст. 148; 2002 р., N 15, ст. 814, N 27, ст. 1265), зміни, що додаються;

2. Ця постанова набирає чинності з дня опублікування.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 січня 2004 р. N 85

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 28 вересня 1996 р. N 1177 ( 1177-96-п ) та Порядку використання коштів Фонду для здійснення заходів щодо ліквідації наслідків Чорнобильської катастрофи та соціального захисту населення ( 987-2000-п )

1. У постанові Кабінету Міністрів України від 28 вересня 1996 р. N 1177 ( 1177-96-п ):

1) пункт 3 виключити;

пункт 4 викласти в такій редакції:

"4. Міністерству охорони навколишнього природного середовища разом з Міністерством фінансів під час складання проекту державного бюджету передбачати починаючи з 2005 року кошти для забезпечення діяльності Центру";

у пункті 6 слова "Міністерство з питань надзвичайних ситуацій" замінити словами "Міністерство охорони навколишнього природного середовища";

2) у Статуті Чорнобильського центру з проблем ядерної безпеки, радіоактивних відходів та радіоекології, затвердженому зазначеною постановою, абзац сьомий пункту 8 та абзац третій пункту 13 виключити.

( Пункт 2 втратив чинність на підставі Постанови КМ N 931 ( 931-2005-п ) від 16.09.2005 )
