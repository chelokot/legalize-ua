Текст документа від 23.04.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 грудня 2003 р. N 1901 Київ

Про затвердження складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів загальнообов'язкового державного соціального страхування

( Із змінами, внесеними згідно з Розпорядженнями КМ N 857-р ( 857-2004-р ) від 17.11.2004 N 70-р ( 70-2005-р ) від 28.03.2005 N 94-р ( 94-2005-р ) від 13.04.2005 N 120-р ( 120-2005-р ) від 23.04.2005 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Розпорядження КМ N 120-р ( 120-2005-р ) від 23.04.2005 )

2. Координаторам діяльності осіб, уповноважених представляти інтереси держави у правліннях фондів загальнообов'язкового державного соціального страхування, забезпечити їх активну участь у засіданнях цих правлінь; інформувати Кабінет Міністрів України за підсумками року про роботу, проведену уповноваженими особами.

3. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 1 липня 2002 р. N 876 ( 876-2002-п ) "Про затвердження складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів загальнообов'язкового державного соціального страхування" (Офіційний вісник України, 2002 р., N 27, ст. 1258);

постанову Кабінету Міністрів України від 24 лютого 2003 р. N 203 ( 203-2003-п ) "Про зміну складу осіб, уповноважених представляти інтереси держави у наглядових радах фондів загальнообов'язкового державного соціального страхування" (Офіційний вісник України, 2003 р., N 9, ст. 374).
