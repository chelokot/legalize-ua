Президент України; Розпорядження від 15.04.2005 № 961/2005-рп

Про делегацію України для участі у переговорах між Україною та Федеративною Республікою Бразилія щодо підготовки проекту Договору між Україною та Федеративною Республікою Бразилія про передачу засуджених осіб

Стан: Втратив чинність

Ідентифікатор: 961/2005-рп

Текст документа від 07.02.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у переговорах між Україною та Федеративною Республікою Бразилія щодо підготовки проекту Договору між Україною та Федеративною Республікою Бразилія про передачу засуджених осіб

1. Утворити делегацію України для участі у переговорах між Україною та Федеративною Республікою Бразилія щодо підготовки проекту Договору між Україною та Федеративною Республікою Бразилія про передачу засуджених осіб в такому складі:

ГОРБУНОВА - заступник Міністра юстиції України,

Лідія Миколаївна глава делегації

ДВОЙНІС - начальник управління по контролю за

Олексій Григорович виконанням судових рішень Державного департаменту України з питань виконання покарань

МАРЧЕНКО - завідувач відділу Головного

Людмила Іванівна державно-правового управління Адміністрації Президента України

РУДА - начальник відділу - заступник

Людмила Романівна начальника управління Департаменту міжнародного співробітництва Міністерства юстиції України

СИБІГА - начальник відділу Договірно-правового Андрій Іванович управління Міністерства закордонних справ України

ФІЛАТОВ - суддя Верховного Суду України (за

Василь Миколайович згодою)

ШЕВЧЕНКО - начальник управління - заступник

Катерина Георгіївна директора Департаменту міжнародного співробітництва Міністерства юстиції України.

Дозволити главі делегації вносити в разі потреби зміни до складу делегації України, залучаючи до її роботи членів Експертної групи з підготовки проектів міжнародних договорів України про правові відносини та правову допомогу у цивільних і кримінальних справах, утвореної Указом Президента України від 24 квітня 2004 року N 476 ( 476/2004 ).

2. Міністерству юстиції України за погодженням з Міністерством закордонних справ України затвердити вказівки делегації України на переговори.

3. Кабінету Міністрів України вирішити питання фінансування проведення у місті Києві переговорів щодо підготовки тексту Договору між Україною та Федеративною Республікою Бразилія про передачу засуджених осіб.

Президент України В.ЮЩЕНКО
