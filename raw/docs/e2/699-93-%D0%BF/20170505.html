Про заходи щодо ефективного використання газу та інших паливно-енергетичних ресурсів в народному господарстві

Стан: Втратив чинність

Ідентифікатор: 699-93-п

Текст документа від 05.05.2017:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 вересня 1993 р. N 699 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 282 ( 282-2017-п ) від 26.04.2017 }

Про заходи щодо ефективного використання газу та інших паливно-енергетичних ресурсів в народному господарстві

{ Із змінами, внесеними згідно з Постановами КМ N 1308 ( 1308-96-п ) від 28.10.96 N 1071 ( 1071-2000-п ) від 07.07.2000 N 841 ( 841-2011-п ) від 03.08.2011 }

З метою забезпечення раціонального і ефективного використання газу та інших паливно-енергетичних ресурсів в народному господарстві Кабінет Міністрів України п остановляє: { Преамбула із змінами, внесеними згідно з Постановою КМ N 1071 ( 1071-2000-п ) від 07.07.2000 }

1. Створити при Державному комітетові по нафті і газу Державну інспекцію з ефективного використання газу на базі Управління по контролю за використанням газу, що ліквідується.

{ Абзац другий пункту 1 виключено на підставі Постанови КМ N 1071 ( 1071-2000-п ) від 07.07.2000 }

Покласти на Державне агентство з енергоефективності та енергозбереження здійснення державного контролю за раціональним і ефективним використанням газу та інших паливно-енергетичних ресурсів підприємствами (електростанціями). { Пункт 1 доповнено абзацом третім згідно з Постановою КМ N 1308 ( 1308-96-п ) від 28.10.96; із змінами, внесеними згідно з Постановами КМ N 1071 ( 1071-2000-п ) від 07.07.2000, N 841 ( 841-2011-п ) від 03.08.2011 }

2. Затвердити розміри плати за газ, що тимчасово споживається на виробничі потреби понад встановлені середньодобові норми з дозволу газозбутових і газотранспортних організацій, а також у разі неефективного використання газу та інших паливно-енергетичних ресурсів підприємствами (електростанціями) згідно з додатком. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1071 ( 1071-2000-п ) від 07.07.2000 )

3. Державному комітетові по нафті і газу:

за погодженням з Міністерством економіки, Міністерством фінансів і Національним банком розробити та затвердити порядок використання коштів, одержаних за газ, що споживається підприємствами (електростанціями) понад середньодобові норми; ( Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 1308 ( 1308-96-п ) від 28.10.96 )

у двотижневий термін затвердити за погодженням з Міністерством економіки, Міністерством юстиції, Міністерством фінансів і Державним комітетом по нагляду за охороною праці Положення про Державну інспекцію з ефективного використання газу.

РОЗМІРИ ПЛАТИ за газ, що тимчасово споживається на виробничі потреби понад встановлені середньодобові норми, а також у разі неефективного використання газу та інших паливно-енергетичних ресурсів підприємствами (електростанціями)

( Назва із змінами, внесеними згідно з Постановою КМ N 1071 ( 1071-2000-п ) від 07.07.2000 )

I. Розміри плати за газ, що тимчасово споживається підприємствами (електростанціями) понад встановлені середньодобові норми з дозволу газозбутових і газотранспортних організацій

У разі потреби тимчасового споживання природного газу підприємствами (електростанціями) понад встановлені середньодобові норми подача його здійснюється за узгодженими з газозбутовими і газотранспортними організаціями графіками.

II. Плата за перевитрати газу та інших паливно-енергетичних ресурсів у разі неефективного їх використання. { Назва розділу II із змінами, внесеними згідно з Постановою КМ N 1071 ( 1071-2000-п ) від 07.07.2000 }

За перевитрати газу та інших паливно-енергетичних ресурсів внаслідок неефективного його використання, виявлені органами Держенергоефективності, сплачується підвищена плата. { Абзац перший додатка із змінами, внесеними згідно з Постановами КМ N 1308 ( 1308-96-п ) від 28.10.96, N 1071 ( 1071-2000-п ) від 07.07.2000, N 841 ( 841-2011-п ) від 03.08.2011 }

Якщо перевитрати газу та інших паливно-енергетичних ресурсів викликані недодержанням технологічної дисципліни (незадовільний стан устаткування, відсутність або недотримання роботи устаткування за режимними або технологічними картками, відсутність теплоутилізаційного устаткування, систем автоматики), споживач сплачує за річний обсяг перевитрат газу та інших паливно-енергетичних ресурсів у двократному розмірі встановленої на них ціни. Плата вноситься одразу після обстеження підприємства Держенергоефективності. { Абзац другий додатка із змінами, внесеними згідно з Постановами КМ N 1308 ( 1308-96-п ) від 28.10.96, N 1071 ( 1071-2000-п ) від 07.07.2000, N 841 ( 841-2011-п ) від 03.08.2011 }

Якщо перевитрати газу та інших паливно-енергетичних ресурсів викликані технологічною недосконалістю процесів і на виконання робіт потрібні значні матеріальні і фінансові ресурси, то за погодженням із споживачем встановлюється термін для їх виконання. У разі невиконання робіт у зазначений термін споживач надалі до їх завершення сплачує за перевитрачений обсяг газу та інших паливно-енергетичних ресурсів в подвійному розмірі встановленої на них ціни. ( Абзац третій додатка із змінами, внесеними згідно з Постановою КМ N 1071 ( 1071-2000-п ) від 07.07.2000 )

Одержані від підприємств (електростанцій) кошти за газ, спожитий понад середньодобові норми, і невикористані Держкомнафтогазом у поточному (звітному) році, вилученню не підлягають. ( Абзац четвертий додатка із змінами, внесеними згідно з Постановою КМ N 1308 ( 1308-96-п ) від 28.10.96 )
