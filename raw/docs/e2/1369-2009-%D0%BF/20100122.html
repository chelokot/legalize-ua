Стан: Чинний

Ідентифікатор: 1369-2009-п

Текст документа від 22.01.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 грудня 2009 р. N 1369 Київ

Питання придбання об'єкта незавершеного будівництва - другої черги багатоквартирного житлового будинку N 26 в першому мікрорайоні житлового масиву "Масани" в м. Чернігові

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 35 ( 35-2010-п ) від 06.01.2010 }

{ Із змінами, внесеними згідно з Постановою КМ N 35 ( 35-2010-п ) від 06.01.2010 }

Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Державного департаменту з питань виконання покарань щодо придбання Державною іпотечною установою об'єкта незавершеного будівництва - другої черги багатоквартирного житлового будинку N 26 в першому мікрорайоні житлового масиву "Масани" в м. Чернігові (54 квартири загальною площею 3279,7 кв. метра) на загальну суму 12462,86 тис. гривень з вартістю 1 кв. метра житла 3800 гривень та строком здачі в експлуатацію не пізніше ніж 30 січня 2010 р. для забезпечення житлом осіб рядового і начальницького складу та працівників Державної кримінально-виконавчої служби, у тому числі пенсіонерів, які відповідно до законодавства потребують поліпшення житлових умов.

{ Пункт 1 в редакції Постанови КМ N 35 ( 35-2010-п ) від 06.01.2010 }

2. Установити, що закупівля робіт із завершення будівництва зазначеного у пункті 1 цієї постанови об'єкта здійснюється без застосування процедур, визначених Положенням про закупівлю товарів, робіт і послуг за державні кошти, затвердженим постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006).

3. Державній іпотечній установі передати Державному департаменту з питань виконання покарань квартири, придбані відповідно до пункту 1 цієї постанови, згідно з розподілом Державного департаменту з питань виконання покарань.

4. Міністерству фінансів передбачити під час доопрацювання проекту Державного бюджету України на 2010 рік кошти для компенсації Державній іпотечній установі витрат, пов'язаних з фінансуванням зазначених у пункті 2 цієї постанови робіт.
