ДЕРЖАВНА ПОДАТКОВА АДМІНІСТРАЦІЯ УКРАЇНИ

НАКАЗ

26.09.2005 N 414

Зареєстровано в Міністерстві юстиції України 4 жовтня 2005 р. за N 1141/11421

Про визнання таким, що втратив чинність, наказу ДПА України від 04.08.97 N 279 "Про затвердження Порядку та форми повідомлення про результати розрахунків авансових внесків податку на прибуток"

На виконання Указу Президента України від 1 червня 2005 року N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" та з метою приведення нормативно-правових актів у відповідність до Указу Президента України від 3 жовтня 1992 року N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Державної податкової адміністрації України від 04.08.97 N 279 ( z0301-97 ) "Про затвердження Порядку та форми повідомлення про результати розрахунків авансових внесків податку на прибуток", зареєстрований в Міністерстві юстиції України 08.08.97 за N 301/2105 (із змінами).

2. Департаменту обслуговування платників податків (Косарчук В.П.) після державної реєстрації цього наказу забезпечити розміщення його на веб-сайті Державної податкової адміністрації України.

3. Управлінню інформаційної політики (Штолько О.В.) після державної реєстрації цього наказу організувати розміщення його у засобах масової інформації.

4. Контроль за виконанням цього наказу покласти на заступника Голови Лекаря С.І.

В.о. Голови Г.М.Оперенко
