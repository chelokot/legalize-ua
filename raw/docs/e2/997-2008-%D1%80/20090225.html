КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 липня 2008 р. N 997-р Київ

Про погодження місця розташування об'єкта

{ Із змінами, внесеними згідно з Розпорядженням КМ N 214-р ( 214-2009-р ) від 25.02.2009 }

Відповідно до статті 151 Земельного кодексу України ( 2768-14 ) погодити місце розташування лінії електропередачі напругою 330 кВ Аджалик - Усатове за межами населених пунктів на території Одеської області згідно з додатком.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 22

Додаток до розпорядження Кабінету Міністрів України від 23 липня 2008 р. N 997-р

ЗЕМЕЛЬНІ ДІЛЯНКИ, розташовані за межами населених пунктів Біляївського, Іванівського, Комінтернівського та Роздільнянського районів Одеської області, що вилучаються і надаються у постійне користування державного підприємства НЕК "Укренерго" для встановлення опор повітряної лінії електропередачі напругою 330 кВ Аджалик - Усатове
