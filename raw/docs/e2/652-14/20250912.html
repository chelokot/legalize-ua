Верховна Рада України; Закон від 13.05.1999 № 652-XIV

Про внесення змін до статті 16 Закону України "Про професійно-технічну освіту"

Стан: Втратив чинність

Ідентифікатор: 652-14

Текст документа від 12.09.2025:

ЗАКОН УКРАЇНИ

{ Закон втратив чинність на підставі Закону N 4574-IX ( 4574-20 ) від 21.08.2025 }

Про внесення змін до статті 16 Закону України "Про професійно-технічну освіту"

( Відомості Верховної Ради України (ВВР), 1999, N 26, ст.218 )

Верховна Рада України постановляє:

Статтю 16 Закону України "Про професійно-технічну освіту" ( 103/98-ВР ) (Відомості Верховної Ради України, 1998 р., N 32, ст. 215) доповнити частиною п'ятою такого змісту:

"Виготовлення документів про освіту, зазначених у цій статті, здійснюється за рахунок видатків Державного бюджету України на освіту".

Президент України Л.КУЧМА
