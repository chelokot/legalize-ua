КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 лютого 2011 р. N 78 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 382 ( 382-2019-п ) від 08.05.2019 }

Про внесення змін до постанови Кабінету Міністрів України від 28 червня 1995 р. N 471

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 28 червня 1995 р. N 471 ( 471-95-п ) "Про організацію складання балансу фінансових ресурсів України" зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 18

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 лютого 2011 р. N 78

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 28 червня 1995 р. N 471 ( 471-95-п )

1. У пункті 1 слова "Міністерством економіки" та "Міністерством статистики" замінити відповідно словами "Міністерством економічного розвитку і торгівлі" та "Державною службою статистики".

2. Пункт 3 викласти у такій редакції:

"3. Установити, що Міністерство економічного розвитку і торгівлі подає прогнозний баланс фінансових ресурсів України на розгляд:

Кабінету Міністрів України - у складі Державної програми економічного і соціального розвитку;

Міністерству фінансів - для підготовки матеріалів, що додаються до проекту закону про Державний бюджет України на відповідний рік.

Для складання зазначеного балансу міністерства, інші центральні органи виконавчої влади подають Міністерству економічного розвитку і торгівлі та Міністерству фінансів необхідні показники за формами, визначеними методологічними вказівками щодо його складання.".

3. В абзаці першому пункту 4 слова "Міністерству статистики" та "Міністерству економіки" замінити відповідно словами "Державній службі статистики" та "Міністерству економічного розвитку і торгівлі".
