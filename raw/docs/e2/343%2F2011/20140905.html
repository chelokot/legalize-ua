Питання складу Координаційної ради з питань підготовки та відзначення 20-ї річниці незалежності України

Стан: Втратив чинність

Ідентифікатор: 343/2011

Текст документа від 05.09.2014:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 701/2014 ( 701/2014 ) від 02.09.2014 }

Питання складу Координаційної ради з питань підготовки та відзначення 20-ї річниці незалежності України

1. На часткову зміну статті 2 Указу Президента України від 1 листопада 2010 року N 990 ( 990/2010 ) "Про відзначення 20-ї річниці незалежності України" затвердити новий персональний склад Координаційної ради з питань підготовки та відзначення 20-ї річниці незалежності України (додається).

2. Цей Указ набирає чинності з дня його опублікування.

м. Київ, 2 квітня 2011 року N 343/2011
