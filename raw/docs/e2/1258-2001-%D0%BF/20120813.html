ПОСТАНОВА від 26 вересня 2001 р. N 1258 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 702 ( 702-2012-п ) від 01.08.2012 }

Про внесення зміни до постанови Кабінету Міністрів України від 15 лютого 1999 р. N 187

Кабінет Міністрів України постановляє:

Доповнити пункт 1 постанови Кабінету Міністрів України від 15 лютого 1999 р. N 187 ( 187-99-п ) "Про порядок надання щорічної додаткової відпустки із збереженням матеріального забезпечення за особливий характер служби військовослужбовцям Прикордонних військ" (Офіційний вісник України, 1999 р., N 7, ст. 238) після слів "на прикордонних заставах і постах" словами "у прикордонних оперативно-розшукових відділеннях, оперативних пунктах".
