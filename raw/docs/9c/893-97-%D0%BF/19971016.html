Текст документа від 16.10.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 серпня 1997 р. N 893 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1141 ( 1141-97-п ) від 16.10.97 )

Про внесення змін до складу тимчасової комісії з питань забезпечення своєчасності сплати податків, зборів, інших обов'язкових платежів та ефективного використання бюджетних коштів

Кабінет Міністрів України постановляє:

Затвердити новий склад тимчасової комісії з питань забезпечення своєчасності сплати податків, зборів, інших обов'язкових платежів та ефективного використання бюджетних коштів, утвореної постановою Кабінету Міністрів України від 26 березня 1997 р. N 266 ( 266-97-п ) (додається).
