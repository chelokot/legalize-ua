Текст документа від 09.01.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 грудня 1998 р. N 2089 Київ

( Постанова втратила чинність на підставі Постанови КМ N 2067 ( 2067-2003-п ) від 29.12.2003 )

Про внесення зміни до постанови Кабінету Міністрів України від 23 вересня 1998 р. N 1511

Кабінет Міністрів України постановляє:

Внести зміну до постанови Кабінету Міністрів України від 23 вересня 1998 р. N 1511 ( 1511-98-п ) "Про затвердження Типових правил розміщення зовнішньої реклами" (Офіційний вісник України, 1998 р. N 38, ст. 1408), виклавши пункт 4 у такій редакції:

"4. Установити, що плата за видачу місцевими органами виконавчої влади та органами місцевого самоврядування дозволів на розміщення зовнішньої реклами не справляється".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
