КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 серпня 1996 р. N 1032 Київ

( Постанова втратила чинність на підставі Постанови КМ N 856 ( 856-2002-п ) від 19.06.2002 )

Про гарячі обіди дітям-сиротам та дітям із малозабезпечених сімей

Кабінет Міністрів України постановляє:

На зміну пункту 3 постанови Кабінету Міністрів України від 23 вересня 1991 р. N 215 ( 215-91-п ) "Про додаткові заходи щодо посилення соціального захисту населення" (ЗП УРСР, 1991 р., N 9, ст. 87) установити, що з 1 вересня 1996 р. безплатні обіди у загальноосвітніх школах надаються дітям-сиротам та дітям із сімей, які отримують допомогу відповідно до статей 52 і 53 Закону України "Про державну допомогу сім'ям з дітьми" ( 2811-12 ).

Міністерству освіти за погодженням з Міністерством фінансів у двотижневий термін затвердити порядок надання безплатних обідів для зазначених категорій дітей.
