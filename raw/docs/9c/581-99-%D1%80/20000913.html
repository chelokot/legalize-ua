Кабінет Міністрів України; Розпорядження від 18.06.1999 № 581-р

Про закріплення у державній власності пакету акцій ВАТ "Бориславський експериментальний ливарно-механічний завод"

Стан: Втратив чинність

Ідентифікатор: 581-99-р

Текст документа від 13.09.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 червня 1999 р. N 581-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 357-р ( 357-2000-р ) від 13.09.2000 )

Відповідно до пункту 23 Державної програми приватизації на 1999 рік ( 209/99 ) закріпити у державній власності на 3 роки пакет акцій у розмірі 25 відсотків статутного фонду плюс одна акція ВАТ "Бориславський експериментальний ливарно-механічний завод".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

Інд. 25
