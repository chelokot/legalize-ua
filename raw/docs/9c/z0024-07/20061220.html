МІНІСТЕРСТВО УКРАЇНИ У СПРАВАХ СІМ'Ї, МОЛОДІ ТА СПОРТУ

НАКАЗ

20.12.2006 N 4273

Зареєстровано в Міністерстві юстиції України 16 січня 2007 р. за N 24/13291

Про затвердження Типових нормативів оснащення центру для ВІЛ-інфікованих дітей та молоді та харчування осіб, які перебувають у ньому

З метою реалізації постанови Кабінету Міністрів України від 15 лютого 2006 року N 148 ( 148-2006-п ) "Про затвердження Типового положення про центр для ВІЛ-інфікованих дітей та молоді" НАКАЗУЮ:

1. Затвердити Типові нормативи оснащення центру для ВІЛ-інфікованих дітей та молоді та харчування осіб, які перебувають у ньому (додаються).

2. Республіканському (Автономна Республіка Крим), обласним, Київському та Севастопольському міським центрам соціальних служб для сім'ї, дітей та молоді під час створення зазначених закладів забезпечити контроль за їх укомплектуванням відповідно до затверджених Типових нормативів оснащення.

3. Державній соціальній службі для сім'ї, дітей та молоді (Толстоухова С.В.) подати цей наказ у встановленому порядку на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням наказу покласти на директора Державної соціальної служби для сім'ї, дітей та молоді Толстоухову С.В.

1. Норма на одну особу вказана відповідно до постанови Кабінету Міністрів України від 27 грудня 2001 року N 1752 ( 1752-2001-п ) "Про норми харчування для осіб, хворих на туберкульоз та інфікованих мікобактеріями туберкульозу".

2. Продукти щоденного споживання (молоко, хліб, масло) використовуються у межах добових норм ( + 5 відсотків). Такі продукти, як сир, риба, дріжджі видаються кілька разів на тиждень.

3. У разі відсутності необхідних продуктів харчування можна проводити їх заміну згідно з нормами заміни продуктів (додаток 2 до постанови Кабінету Міністрів України від 27 грудня 2001 року N 1752 ( 1752-2001-п ).

4. Для квашення овочів (огірків, помідорів, капусти тощо) та консервування овочів та фруктів використовують сіль і цукор згідно з рецептурними понад добову норму.

5. Оснащення центру кухонним обладнанням та інвентарем здійснюється за умови потреби та за наявності харчоблоку.
