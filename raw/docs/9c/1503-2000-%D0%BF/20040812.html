Питання Національної ради по туризму

Стан: Втратив чинність

Ідентифікатор: 1503-2000-п

Текст документа від 12.08.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 вересня 2000 р. N 1503 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1045 ( 1045-2004-п ) від 12.08.2004 )

Питання Національної ради по туризму

Кабінет Міністрів України постановляє:

1. Внести до Положення про Національну раду по туризму, затвердженого постановою Кабінету Міністрів України від 13 березня 1996 р. N 322 ( 322-96-п ) (ЗП України, 1996 р., N 8, ст. 261), зміни згідно з додатком.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 18 грудня 1998 р. N 2023 ( 2023-98-п ) "Про затвердження нового персонального складу Національної ради по туризму".
