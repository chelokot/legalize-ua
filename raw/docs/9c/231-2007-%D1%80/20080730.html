Про затвердження складу Організаційного комітету з підготовки та проведення форуму "Паливно-енергетичний комплекс України: сьогодення та майбутнє"

Стан: Втратив чинність

Ідентифікатор: 231-2007-р

Текст документа від 30.07.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 квітня 2007 р. N 231-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1026-р ( 1026-2008-р ) від 30.07.2008 }

Про затвердження складу Організаційного комітету з підготовки та проведення форуму "Паливно-енергетичний комплекс України: сьогодення та майбутнє"

1. На часткову зміну абзацу першого пункту 2 розпорядження Кабінету Міністрів України від 10 серпня 2004 р. N 570 ( 570-2004-р ) затвердити склад Організаційного комітету з підготовки та проведення форуму "Паливно-енергетичний комплекс України: сьогодення та майбутнє", що додається.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 11 травня 2006 р. N 262 ( 262-2006-р ) "Про затвердження складу Організаційного комітету з підготовки та проведення форуму "Паливно-енергетичний комплекс України: сьогодення та майбутнє".
