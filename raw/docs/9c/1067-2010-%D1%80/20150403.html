РОЗПОРЯДЖЕННЯ від 19 травня 2010 р. N 1067-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 122 ( 122-2015-п ) від 18.03.2015 }

Про голову координаційної ради у зв'язках з Організацією економічного співробітництва та розвитку (ОЕСР)

Затвердити Віце-прем'єр-міністра України Тігіпка Сергія Леонідовича головою координаційної ради у зв'язках з Організацією економічного співробітництва та розвитку (ОЕСР), утвореної розпорядженням Кабінету Міністрів України від 19 листопада 2003 р. N 679 ( 679-2003-р ), увільнивши від цих обов'язків Немирю Григорія Михайловича.

Прем'єр-міністр України М.АЗАРОВ
