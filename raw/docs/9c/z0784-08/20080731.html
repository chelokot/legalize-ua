Зареєстровано в Міністерстві юстиції України 27 серпня 2008 р. за N 784/15475

Про внесення змін до наказу Держмитслужби України від 29.07.2002 N 408

Відповідно до Порядку проведення службового розслідування стосовно державних службовців, затвердженого постановою Кабінету Міністрів України від 13.06.2000 N 950 ( 950-2000-п ) (із змінами), та Закону України від 06.09.2005 N 2805-IV ( 2805-15 ) "Про Дисциплінарний статут митної служби України" НАКАЗУЮ:

1. Унести до наказу Державної митної служби України від 29.07.2002 N 408 ( z0665-02 ) "Про затвердження Порядку проведення службових розслідувань у митних органах України" (далі - Наказ), зареєстрованого в Міністерстві юстиції України 15.08.2002 за N 665/6953, такі зміни:

1.1. Заголовок Наказу ( z0665-02 ) та пункти 1 і 5 після слів "митних органах України" у всіх відмінках доповнити словами "спеціалізованих митних установах та організаціях" у відповідних відмінках.

1.2. Пункт 3 Наказу ( z0665-02 ) після слів "митних органів" доповнити словами "України, спеціалізованих митних установ та організацій".

2. Унести до Порядку проведення службових розслідувань у митних органах України, затвердженого наказом Державної митної служби України від 29.07.2002 N 408 ( z0665-02 ) (далі - Порядок), зареєстрованого в Міністерстві юстиції України 15.08.2002 за N 665/6953, такі зміни:

2.1. У назві та тексті Порядку ( z0665-02 ) слова "посадові особи митного органу", "керівник митного органу" у всіх відмінках замінити відповідно словами "посадові особи митної служби України", "керівник митного органу або спеціалізованої митної установи та організації" у відповідних відмінках.

2.2. Пункт 6.3 Порядку ( z0665-02 ) після слів "ознаки злочину" доповнити словами "корупційних діянь та інших правопорушень, пов'язаних з корупцією".

2.3. У пункті 7.1 Порядку ( z0665-02 ):

в абзац другий після слів "службове розслідування" доповнити словами "результати щорічної оцінки виконання посадовою особою митної служби покладених на неї завдань та обов'язків, інформація про застосовані до неї заохочення, дисциплінарні стягнення, ступінь участі у виконанні окремих доручень, завдань";

доповнити пункт після абзацу третього новими абзацами такого змісту:

"обґрунтовані пропозиції щодо усунення виявлених порушень та притягнення у разі необхідності винних осіб до відповідальності згідно із законодавством.

У разі прийняття рішення щодо притягнення посадової особи митної служби до відповідальності комісія пропонує вид дисциплінарного стягнення згідно з Дисциплінарним статутом митної служби України ( 2805-15 ).

Під час визначення виду дисциплінарного стягнення члени комісії повинні враховувати ступінь тяжкості вчиненого правопорушення і заподіяну ним шкоду, обставини, за яких учинено правопорушення, і попередню роботу працівника".

2.4. Абзац другий пункту 7.3 Порядку ( z0665-02 ) після слів "проводилося розслідування" доповнити словами "та керівника підрозділу, у якому вона працює".

2.5. В абзаці другому пункту 7.4 Порядку ( z0665-02 ) слова "з яким голова комісії ознайомлює посадову особу" замінити словами "з яким ознайомлюється посадова особа".

2.6. Абзац третій пункту 7.4 Порядку ( z0665-02 ) виключити.

3. Керівникам структурних підрозділів Державної митної служби України, начальникам митних органів, спеціалізованих митних установ і організацій забезпечити неухильне дотримання вимог цього наказу.

4. Департаменту власної безпеки (Бриль К.І.) і Юридичному департаменту (Небрат Л.М.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

Контроль за виконанням наказу залишаю за собою.

Голова Державної митної служби України В.І.Хорошковський
