УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1507/2004 ( 1507/2004 ) від 20.12.2004 )

Про внесення змін до Указу Президента України від 13 березня 2003 року N 214

На зміну Указу Президента України від 13 березня 2003 року N 214 ( 214/2003 ) ввести додаткову посаду заступника Голови Державної митної служби України - начальника Західної регіональної митниці.
