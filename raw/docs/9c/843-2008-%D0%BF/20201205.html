КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 вересня 2008 р. N 843 Київ

Про затвердження критерію, за яким оцінюється ступінь ризику від провадження діяльності у сфері охорони здоров'я для безпеки життя і здоров'я населення та визначається періодичність здійснення планових заходів державного нагляду (контролю)

{ Із змінами, внесеними згідно з Постановами КМ N 1090 ( 1090-2011-п ) від 26.10.2011 N 543 ( 543-2014-п ) від 16.10.2014 N 615 ( 615-2014-п ) від 12.11.2014 N 69 ( 69-2016-п ) від 11.02.2016 N 465 ( 465-2019-п ) від 05.06.2019 N 1185 ( 1185-2020-п ) від 02.12.2020 }

Відповідно до статті 5 Закону України "Про основні засади державного нагляду (контролю) у сфері господарської діяльності" ( 877-16 ) Кабінет Міністрів України постановляє:

Затвердити критерій, за яким оцінюється ступінь ризику від провадження діяльності у сфері охорони здоров'я для безпеки життя і здоров'я населення та визначається періодичність здійснення планових заходів державного нагляду (контролю), згідно з додатком.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Додаток до постанови Кабінету Міністрів України від 10 вересня 2008 р. N 843

КРИТЕРІЙ, за яким оцінюється ступінь ризику від провадження діяльності у сфері охорони здоров'я для безпеки життя і здоров'я населення та визначається періодичність здійснення планових заходів державного нагляду (контролю)

1. Критерієм, за яким оцінюється ступінь ризику від провадження діяльності у сфері охорони здоров'я для безпеки життя і здоров'я населення, є можливість завдання шкоди здоров'ю, працездатності та життю людини чи здоров'ю майбутніх поколінь, що обумовлено:

{ Підпункт 1 пункту 1 виключено на підставі Постанови КМ N 543 ( 543-2014-п ) від 16.10.2014 }

{ Підпункт 2 пункту 1 виключено на підставі Постанови КМ N 615 ( 615-2014-п ) від 12.11.2014 }

3) порушенням технологічного процесу переробки донорської крові та її компонентів, виготовлення з них препаратів;

4) порушенням спеціальних умов зберігання, реалізації донорської крові та її компонентів, виготовлення з них препаратів.

{ Підпункт 5 пункту 1 виключено на підставі Постанови КМ N 69 ( 69-2016-п ) від 11.02.2016 }

{ Підпункт 6 пункту 1 виключено на підставі Постанови КМ N 465 ( 465-2019-п ) від 05.06.2019 }

{ Підпункт 7 пункту 1 виключено на підставі Постанови КМ N 465 ( 465-2019-п ) від 05.06.2019 }

{ Підпункт 8 пункту 1 виключено на підставі Постанови КМ N 1185 ( 1185-2020-п ) від 02.12.2020 }

2. Установлюються три ступені ризику - високий, середній та незначний.

3. До суб'єктів господарювання з високим ступенем ризику належать суб'єкти, що провадять такі види господарської діяльності:

{ Абзац другий пункту 3 виключено на підставі Постанови КМ N 543 ( 543-2014-п ) від 16.10.2014 }

переробка донорської крові та її компонентів, виготовлення з них препаратів, крім діяльності банків пуповинної крові, інших тканин і клітин людини. { Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 1090 ( 1090-2011-п ) від 26.10.2011 }

{ Абзац четвертий пункту 3 виключено на підставі Постанови КМ N 69 ( 69-2016-п ) від 11.02.2016 }

{ Абзац п'ятий пункту 3 виключено на підставі Постанови КМ N 465 ( 465-2019-п ) від 05.06.2019 }

{ Абзац шостий пункту 3 виключено на підставі Постанови КМ N 465 ( 465-2019-п ) від 05.06.2019 }

{ Абзац сьомий пункту 3 виключено на підставі Постанови КМ N 1185 ( 1185-2020-п ) від 02.12.2020 }

{ Пункт 4 виключено на підставі Постанови КМ N 615 ( 615-2014-п ) від 12.11.2014 }

5. До суб'єктів господарювання з незначним ступенем ризику належать суб'єкти, що не віднесені до суб'єктів господарювання з високим та середнім ступенем ризику.

6. Планові заходи державного нагляду (контролю) за діяльністю суб'єктів господарювання здійснюються з такою періодичністю:

з високим ступенем ризику - не частіше одного разу на рік;

із середнім ступенем ризику - не частіше одного разу на три роки;

з незначним ступенем ризику - не частіше одного разу на п'ять років.
