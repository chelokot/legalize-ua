Про внесення змін до структури Секретаріату Кабінету Міністрів України та структури Служби Прем'єр-міністра України

Стан: Втратив чинність

Ідентифікатор: 660-2001-п

Текст документа від 02.10.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 червня 2001 р. N 660 Київ

Про внесення змін до структури Секретаріату Кабінету Міністрів України та структури Служби Прем'єр-міністра України

( Із змінами, внесеними згідно з Постановами КМ N 932 ( 932-2001-п ) від 01.08.2001 N 1288 ( 1288-2001-п ) від 02.10.2001 )

З метою вдосконалення структури Секретаріату Кабінету Міністрів України та структури Служби Прем'єр-міністра України Кабінет Міністрів України постановляє:

1. Внести у структуру Секретаріату Кабінету Міністрів України, затверджену постановою Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) (Офіційний вісник України, 2000 р., N 4, ст. 110), такі зміни:

( Підпукт 1 пункту 1 втратив чинність в частині ліквідації Прес-служби Кабінету Міністрів України на підставі Постанови КМ N 932 ( 932-2001-п ) від 01.08.2001 ) 1) ліквідувати Прес-службу Кабінету Міністрів України та Управління інформаційних технологій;

2) у Департаменті внутрішньої політики:

а) ліквідувати Управління гуманітарного розвитку, Управління інформаційних ресурсів і Управління забезпечення зв'язків з Верховною Радою України та громадськістю;

б) утворити Управління зв'язків з громадськістю, Управління науково-технічного та гуманітарного розвитку, Управління стратегії розвитку інформаційних ресурсів та технологій і Управління забезпечення зв'язків з Верховною Радою України;

в) вивести із складу Департаменту Управління експертизи та аналізу розвитку територій;

3) утворити у структурі Господарського управління Відділ технічного супроводження обчислювальної техніки та комп'ютерних мереж.

( На часткову зміну пункту 1 додатково див. Постанову КМ N 1288 ( 1288-2001-п ) від 02.10.2001 )

( Пункт 2 втратив чинність на підставі Постанови КМ N 932 ( 932-2001-п ) від 01.08.2001 )

3. Державному Секретарю Кабінету Міністрів України внести в установленому порядку зміни до штатного розпису Секретаріату Кабінету Міністрів України відповідно до цієї постанови.

Прем'єр-міністр України А.КІНАХ
