( Наказ втратив чинність на підставі Наказу Міністерства фінансів N 683 ( z1252-05 ) від 10.10.2005 )

Про внесення змін до наказу Міністерства фінансів України від 11.07.2001 N 337

Відповідно до постанови Кабінету Міністрів України від 19.05.2003 N 740 ( 740-2003-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів і організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

Унести зміни до наказу Міністерства фінансів України від 11.07.2001 N 337 ( z0625-01 ) "Про впорядкування умов оплати праці працівників Державного гемологічного центру України", зареєстрованого в Міністерстві юстиції України 23.07.2001 за N 625/5816 (із змінами і доповненнями, внесеними наказом Міністерства фінансів України від 14.05.2002 N 316 ( z0459-02 ), зареєстрованим у Міністерстві юстиції України 28.05.2002 за N 459/6747), виклавши додаток до нього у новій редакції (додається).

Перший віце-прем'єр-міністр України, Міністр фінансів України М.Я.Азаров

ПОГОДЖЕНО:

Заступник Міністра праці та соціальної політики України В.Тьоткін

Додаток до наказу Міністерства фінансів України 11.07.2001 N 337 ( z0625-01 ) (у редакції наказу Міністерства фінансів України 15.08.2003 N 501)
