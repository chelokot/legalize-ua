Текст документа від 28.03.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 березня 2007 р. N 564 Київ

Про внесення змін до постанов Кабінету Міністрів України від 28 грудня 1995 р. N 1062 і від 15 лютого 2006 р. N 147

Кабінет Міністрів України постановляє:

1. У постанові Кабінету Міністрів України від 28 грудня 1995 р. N 1062 ( 1062-95-п ) "Про організацію виконання Монреальського протоколу по речовинах, що руйнують озоновий шар" (ЗП України, 1996 р., N 4, ст. 144; Офіційний вісник України, 2002 р., N 14, ст. 743, ст. 747; 2005 р., N 45, ст. 2847; 2006 р., N 7, ст. 360):

1) у пункті 3 постанови слова "- Головного державного інспектора України з охорони навколишнього природного середовища" виключити;

2) у Положенні про Міжвідомчу координаційну комісію з питань організації виконання вимог Монреальського протоколу по речовинах, що руйнують озоновий шар ( 1062-95-п ), затвердженому зазначеною постановою, слово "Мінекоресурсів" замінити словом "Мінприроди".

2. У підпункті 41 пункту 1 постанови Кабінету Міністрів України від 15 лютого 2006 р. N 147 ( 147-2006-п ) "Про керівників деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України" (Офіційний вісник України, 2006 р., N 7, ст. 360) слова "- головного державного інспектора України з охорони навколишнього природного середовища" виключити.
