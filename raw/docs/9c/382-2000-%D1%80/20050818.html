Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 вересня 2000 р. N 382-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про внесення змін до складу робочої групи для опрацювання питань, пов'язаних з подальшим функціонуванням державних холдингових та акціонерних компаній, статутні фонди яких сформовано за рахунок закріплених у державній власності пакетів акцій

1. Ввести до складу робочої групи для опрацювання питань, пов'язаних з подальшим функціонуванням державних холдингових та акціонерних компаній, статутні фонди яких сформовано за рахунок закріплених у державній власності пакетів акцій, утвореної відповідно до розпорядження Кабінету Міністрів України від 5 червня 2000 р. N 250 ( 250-2000-р ), Портнова Андрія Володимировича - начальника управління корпоративних фінансів Державної комісії з цінних паперів та фондового ринку, Лисенка Григорія Івановича - начальника Головного управління форм власності та організаційних структур Мінпаливенерго, Юрсу Михайла Яковича - керівника підрозділу СБУ, вивівши з її складу Бойка Олександра Івановича і Турчаніна Геннадія Івановича.

2. Дозволити голові робочої групи для опрацювання питань, пов'язаних з подальшим функціонуванням державних холдингових та акціонерних компаній, статутні фонди яких сформовано за рахунок закріплених у державній власності пакетів акцій, у разі потреби вносити зміни до її складу.

Перший віце-прем'єр-міністр України Ю.ЄХАНУРОВ
