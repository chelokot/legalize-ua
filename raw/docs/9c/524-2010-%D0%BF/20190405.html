Про закупівлю об'єктів державного цінового регулювання для формування державного інтервенційного фонду

Текст документа від 05.04.2019:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 червня 2010 р. N 524 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 260 ( 260-2019-п ) від 06.03.2019 }

Про закупівлю об'єктів державного цінового регулювання для формування державного інтервенційного фонду

Кабінет Міністрів України постановляє:

Дозволити Аграрному фонду в маркетинговому періоді 2010-2011 років здійснювати закупівлю врожаю 2010 року пшениці твердої та м'якої, зерна суміші пшениці та жита (меслин), кукурудзи, ячменю та жита озимого і ярового, не пов'язану з державним ціновим регулюванням, за середньозваженими цінами рівноваги (фіксингу), що склалися протягом останніх трьох торгових сесій на Аграрній біржі та сертифікованих нею акредитованих товарних біржах, але не вище 20 відсотків мінімальної інтервенційної ціни, встановленої на зазначений маркетинговий період для таких видів сільськогосподарської продукції.

Прем'єр-міністр України М.АЗАРОВ
