Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 серпня 2009 р. N 1161-р Київ

Про виділення Чернівецькій облдержадміністрації коштів Стабілізаційного фонду для завершення у 2009-2010 роках будівництва мостів, берегоукріплювальних споруд, об'єктів соціально-культурного призначення та водовідведення, що перебувають у комунальній власності

{ Назва Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 104-р ( 104-2010-р ) від 06.01.2010 }

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1190-р ( 1190-2009-р ) від 07.10.2009 N 1227-р ( 1227-2009-р ) від 14.10.2009 N 104-р ( 104-2010-р ) від 06.01.2010 Постановою КМ N 666 ( 666-2010-п ) від 28.07.2010 }

1. Здійснити перерозподіл коштів Стабілізаційного фонду в сумі 59 085,319 тис. гривень шляхом зменшення обсягу видатків, передбачених пунктом 12 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) за напрямом "Придбання для Державної митної служби України рентгенотелевізійних скануючих систем", і збільшення обсягу видатків, передбачених пунктом 22 частини першої статті 76 зазначеного Закону ( 835-17 ) за напрямом "Інші витрати", для завершення у 2009-2010 роках будівництва мостів, берегоукріплювальних споруд, об'єктів соціально-культурного призначення та водовідведення, що перебувають у комунальній власності, згідно з додатками 1-3.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 104-р ( 104-2010-р ) від 06.01.2010 }

2. Мінфіну до погодження з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету забезпечити внесення змін до розпису державного бюджету та спрямувати на безповоротній основі зазначені у пункті 1 цього розпорядження кошти у вигляді субвенції з державного бюджету обласному бюджету Чернівецької області, а Державному казначейству невідкладно перерахувати зазначені кошти.

Джерелом покриття зазначених витрат визначити надходження коштів від цільового розміщення державних цінних паперів, а у разі їх недостатності - коштів, отриманих від продажу земельних ділянок несільськогосподарського призначення, що перебувають у державній власності, на яких розташовані об'єкти, які підлягають приватизації, або прав на такі ділянки, та залишку коштів Стабілізаційного фонду станом на 1 січня 2009 року.

Чернівецькій облдержадміністрації здійснити розподіл субвенції між розпорядниками коштів місцевого бюджету нижчого рівня за напрямами та об'єктами, зазначеними у пункті 1 цього розпорядження, та затвердити його на сесії Чернівецької обласної ради. { Пункт 2 доповнено абзацом згідно з Розпорядженням КМ N 1227-р ( 1227-2009-р ) від 14.10.2009 }

3. Чернівецькій облдержадміністрації:

забезпечити погодження перерозподілених відповідно до цього розпорядження коштів Стабілізаційного фонду з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету;

подавати щомісяця до 1 числа наступного періоду Мінрегіонбуду звіт про використання коштів, виділених згідно з пунктом 1 цього розпорядження, для узагальнення і подання в установленому порядку Мінфіну.
