УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про склад Ради національної безпеки і оборони України

{ Із змінами, внесеними згідно з Указами Президента N 761/2006 ( 761/2006 ) від 20.09.2006 N 884/2006 ( 884/2006 ) від 17.10.2006 N 966/2006 ( 966/2006 ) від 15.11.2006 N 1000/2006 ( 1000/2006 ) від 24.11.2006 N 1074/2006 ( 1074/2006 ) від 14.12.2006 }

Відповідно до частини четвертої статті 107 Конституції України ( 254к/96-ВР ) постановляю:

1. Затвердити персональний склад Ради національної безпеки і оборони України (додається).

2. Визнати такими, що втратили чинність:

статтю 2 Указу Президента України від 8 лютого 2005 року N 208 ( 208/2005 ) "Про деякі питання організації діяльності Ради національної безпеки і оборони України";

Указ Президента України від 5 жовтня 2005 року N 1414 ( 1414/2005 ) "Про внесення змін до складу Ради національної безпеки і оборони України";

Указ Президента України від 6 грудня 2005 року N 1695 ( 1695/2005 ) "Про внесення змін до Указу Президента України від 8 лютого 2005 року N 208";

Указ Президента України від 13 лютого 2006 року N 127 ( 127/2006 ) "Про внесення змін до Указу Президента України від 8 лютого 2005 року N 208";

Указ Президента України від 2 червня 2006 року N 465 ( 465/2006 ) "Про внесення змін до Указу Президента України від 8 лютого 2005 року N 208".
