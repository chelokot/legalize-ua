Про затвердження переліку галузей науки, з яких може бути присуджений науковий ступінь

Стан: Втратив чинність

Ідентифікатор: 1328-97-п

Текст документа від 24.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 листопада 1997 р. N 1328 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1183 ( 1183-2011-п ) від 21.11.2011 }

Про затвердження переліку галузей науки, з яких може бути присуджений науковий ступінь

{ Із змінами, внесеними згідно з Постановою КМ N 1718 ( 1718-2006-п ) від 13.12.2006 }

Кабінет Міністрів України постановляє:

На зміну пункту 2 постанови Кабінету Міністрів України від 17 березня 1993 р. N 199 ( 199-93-п ) "Про затвердження описів дипломів доктора і кандидата наук та атестата старшого наукового співробітника і переліку галузей науки, з яких може бути присуджений науковий ступінь" (ЗП України, 1993 р., N 9, ст. 169) затвердити новий перелік галузей науки, з яких може бути присуджений науковий ступінь (додається).

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 29 листопада 1997 р. N 1328
