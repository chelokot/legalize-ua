ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

11.11.2004 N 812

Зареєстровано в Міністерстві юстиції України 22 листопада 2004 р. за N 1469/10068

Про внесення зміни до наказу Держмитслужби України від 27.01.2003 N 49

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Державної митної служби

N 49 ( z0087-03 ) від 27.01.2003, до якого вносились зміни }

Відповідно до постанови Кабінету Міністрів України від 23.02.99 N 255 ( 255-99-п ) "Про посилення контролю за доставкою до митниць призначення вантажів, які переміщуються під митним контролем" (зі змінами й доповненнями) і з метою вдосконалення механізму контролю за транзитним переміщенням через митну територію України окремих видів товарів НАКАЗУЮ:

1. Унести до наказу Держмитслужби України від 27.01.2003 N 49 ( z0087-03 ) "Про посилення контролю за доставкою в митниці призначення окремих видів товарів", зареєстрованого в Міністерстві юстиції України 04.02.2003 за N 87/7408 (зі змінами й доповненнями), таку зміну:

1.1. Пункт 1 наказу викласти в такій редакції:

"1. Установити, що транзитні переміщення через митну територію України автомобільним транспортом товарів 02 - 04, 07 - 09, 12, 15 - 21, 2201, 2202, 3302, 3402, 4011, 4202, 4303, 4901, 6101, 6102, 6103, 6104, 6105, 6106, 6107, 6108, 6109, 6110, 6111, 6112, 6113, 6114, 6115, 6116, 6117, 6201, 6202, 6203, 6204, 6205, 6206, 6207, 6208, 6209, 6210, 6211, 6212, 6213, 6214, 6215, 6216, 6217, 6401, 6402, 6403, 6404, 6405, 6406, 8415, 8418, 8450, 8452, 8471, 8473 30, 8509, 8510, 8516, 8517, 8518, 8519, 8520, 8521, 8524, 8525, 8527, 8528, 8536, 9303, 9401, 9403 груп, товарних позицій та підкатегорії 6309 00 00 00 згідно з УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) здійснюються за умови застосування одного із заходів гарантування доставки товарів, установлених статтею 161 Митного кодексу України ( 92-15 )".

2. Департаменту організації митного контролю (Мальнов В.С.) і Департаменту правового забезпечення (Ступак Ю.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Департаменту правового забезпечення (Мароха В.М.) проінформувати Міністерство закордонних справ України про дату набрання чинності цим наказом для надання інформації іноземним суб'єктам зовнішньоекономічної діяльності.

4. Начальникам митних органів довести цей наказ до відома особового складу, фізичних і юридичних осіб.

5. Установити, що наказ набирає чинності через 20 днів з дня його офіційного опублікування.

6. Контроль за виконанням наказу покласти на першого заступника Голови Служби Іванюка М.М.
