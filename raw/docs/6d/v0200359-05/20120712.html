14.12.2005 N 200

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 111 ( v0111359-12 ) від 12.07.2012 }

Про форми посвідчень голів, заступників голів, секретарів та членів окружної та дільничної виборчих комісій

Відповідно до пунктів 2, 3 частини першої статті 24, пунктів 1, 2, 14 частини другої статі 30 Закону України "Про вибори народних депутатів України" ( 1665-15 ) та керуючись статтями 12, 13, пунктом 10 статті 19 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Встановити форми посвідчень:

голови, заступника голови, секретаря, члена окружної виборчої комісії (додаток 1) ( va200359-05 );

голови, заступника голови, секретаря, члена дільничної виборчої комісії (додатки 2, 3, 4) ( va200359-05 ).

2. Секретаріату Центральної виборчої комісії забезпечити виготовлення бланків посвідчень відповідно до встановлених форм.
