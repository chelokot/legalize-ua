Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 липня 2005 р. N 616

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. У додатку до постанови Кабінету Міністрів України від 22 березня 2000 р. N 539 ( 539-2000-п ) "Про встановлення винагород спортсменам України - чемпіонам, призерам спортивних змагань міжнародного рівня та їх тренерам" (Офіційний вісник України, 2000 р., N 12, ст. 477; 2002 р., N 14, ст. 735; 2003 р., N 51, ст. 1953; 2004 р., N 31, ст. 2069) слово "Параолімпійських" замінити словом "Паралімпійських".

2. У пункті 1 переліку типів позашкільних навчальних закладів, затвердженого постановою Кабінету Міністрів України від 6 травня 2001 р. N 433 ( 433-2001-п ) (Офіційний вісник України, 2001 р., N 20, ст. 847), слово "параолімпійського" замінити словом "паралімпійського".

( Пункт 3 втратив чинність на підставі Постанови КМ N 30 ( 30-2006-п ) від 18.01.2006 )

4. У пункті 2 Положення про стипендію Кабінету Міністрів України для видатних спортсменів, тренерів та діячів фізичної культури і спорту, затвердженого постановою Кабінету Міністрів України від 24 січня 2002 р. N 80 ( 80-2002-п ) (Офіційний вісник України, 2002 р., N 4, ст. 141), слова "Параолімпійських" замінити словом "Паралімпійських".
