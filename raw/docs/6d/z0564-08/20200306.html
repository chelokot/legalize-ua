Про внесення змін до наказу Адміністрації Державної прикордонної служби України від 04.09.2003 N 70, зареєстрованого в Міністерстві юстиції України 22.09.2003 за N 832/8153

Відповідно до наказу Міністерства охорони здоров'я України від 12.12.2006 N 818 ( z1366-06 ) "Про вдосконалення атестації провізорів та фармацевтів", зареєстрованого в Міністерстві юстиції України 26.12.2006 за N 1366/13240, наказу Міністерства охорони здоров'я України від 23.11.2007 N 742 ( z1368-07 ) "Про атестацію молодших спеціалістів з медичною освітою", зареєстрованого в Міністерстві юстиції України 12.12.2007 за N 1368/14635, з метою подальшого підвищення фахового рівня та вдосконалення атестації провізорів та фармацевтів, молодших спеціалістів з медичною освітою НАКАЗУЮ:

1. Унести до наказу Адміністрації Державної прикордонної служби України від 04.09.2003 N 70 ( z0832-03 ) "Про затвердження Інструкції про порядок присвоєння кваліфікаційних категорій військовослужбовцям, службовцям медичних і фармацевтичних спеціальностей", зареєстрованого в Міністерстві юстиції України 22.09.2003 за N 832/8153, такі зміни:

1.1. У преамбулі слова і цифри "наказу Міністерства охорони здоров'я України від 31.07.98 N 231 ( z0513-98 ) "Про вдосконалення провізорів та фармацевтів", зареєстрованого в Міністерстві юстиції України 17.08.98 за N 513/2953" виключити.

1.2. Преамбулу доповнити перед словами "з метою подальшого вдосконалення системи атестації військовослужбовців, службовців медичних і фармацевтичних спеціальностей" словами і цифрами такого змісту:

"наказу Міністерства охорони здоров'я України від 12.12.2006 N 818 ( z1366-06 ) "Про вдосконалення атестації провізорів та фармацевтів", зареєстрованого в Міністерстві юстиції України 26.12.2006 за N 1366/13240, наказу Міністерства охорони здоров'я України від 23.11.2007 N 742 ( z1368-07 ) "Про атестацію молодших спеціалістів з медичною освітою", зареєстрованого в Міністерстві юстиції України 12.12.2007 за N 1368/14635".

2. Унести до Інструкції про порядок присвоєння кваліфікаційних категорій військовослужбовцям, службовцям медичних і фармацевтичних спеціальностей, затвердженої наказом Адміністрації Державної прикордонної служби України від 04.09.2003 N 70 ( z0832-03 ), зареєстрованої у Міністерстві юстиції України 22.09.2003 за N 832/8153, такі зміни:

2.1. У тексті Інструкції слово "лазарет" у всіх відмінках замінити словами "медико-санітарна частина" у відповідних відмінках.

2.2. В абзаці першому пункту 1:

слова і цифри "наказу Міністерства охорони здоров'я України від 31.07.98 N 231 ( z0513-98 ) "Про вдосконалення провізорів та фармацевтів", зареєстрованого в Міністерстві юстиції України 17.08.98 за N 513/2953" виключити;

слова і цифри "наказу Міністерства охорони здоров'я України від 23.10.91 N 146 ( v0146282-91 ) "Про атестацію середніх медичних працівників" замінити словами і цифрами "наказу Міністерства охорони здоров'я України від 12.12.2006 N 818 ( z1366-06 ) "Про вдосконалення атестації провізорів та фармацевтів", зареєстрованого в Міністерстві юстиції України 26.12.2006 за N 1366/13240, наказу Міністерства охорони здоров'я України від 23.11.2007 N 742 ( z1368-07 ) "Про атестацію молодших спеціалістів з медичною освітою", зареєстрованого в Міністерстві юстиції України 12.12.2007 за N 1368/14635".

2.3. У пункті 2 слова і цифри "Номенклатурою провізорських спеціальностей ( z0515-98 ), затвердженою наказом Міністерства охорони здоров'я України від 31.07.98 N 231 ( z0513-98 ) та зареєстрованою в Міністерстві юстиції України 17.08.98 за N 515/2955, а також Номенклатурою спеціальностей середніх медичних працівників, затвердженою наказом Міністерства охорони здоров'я України від 23.10.91 N 146 ( v0146282-91 )" замінити словами і цифрами "Номенклатурою провізорських спеціальностей ( z1367-06 ), затвердженою наказом Міністерства охорони здоров'я України від 12.12.2006 N 818 ( z1366-06 ), зареєстрованою у Міністерстві юстиції України 26.12.2006 за N 1367/13241, Положенням про порядок проведення атестації фармацевтів ( z1368-06 ), затвердженим наказом Міністерства охорони здоров'я України від 12.12.2006 N 818, зареєстрованою у Міністерстві юстиції України 26.12.2006 за N 1368/13242, а також Номенклатурою спеціальностей молодших спеціалістів з медичною освітою (додаток 1 до Положення про атестацію молодших спеціалістів з медичною освітою, затвердженого наказом Міністерства охорони здоров'я України від 23.11.2007 N 742 ( z1368-07 ), зареєстрованим в Міністерстві юстиції України 12.12.2007 за N 1368/14635").

2.4. Пункт 4 викласти в такій редакції:

"4. Атестація на присвоєння або підтвердження кваліфікаційних категорій професіоналам (фахівцям) проводиться у добровільному порядку атестаційною комісією, що створюється при управлінні охорони здоров'я Департаменту забезпечення".

2.5. Пункт 5 виключити.
