КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 квітня 2009 р. N 430-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 858-р ( 858-2011-р ) від 12.09.2011 }

Про затвердження складу президії ВАК та її секції

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1464-р ( 1464-2009-р ) від 02.12.2009 N 237-р ( 237-2010-р ) від 17.02.2010 }

1. Затвердити склад президії ВАК та її секції згідно з додатками 1 і 2.

2. Надати секції президії права президії ВАК в частині розгляду атестаційних справ та матеріалів, що становлять державну таємницю.

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 31 жовтня 2007 р. N 931 ( 931-2007-р ) "Про зміну складу президії ВАК та її секції" (Офіційний вісник України, 2007 р., N 83, ст. 3089).
