МІНІСТЕРСТВО РЕГІОНАЛЬНОГО РОЗВИТКУ ТА БУДІВНИЦТВА УКРАЇНИ

НАКАЗ

18.08.2009 N 341

Зареєстровано в Міністерстві юстиції України 23 жовтня 2009 р. за N 977/16993

Про втрату чинності наказу Мінрегіонбуду від 24.11.2008 N 531

У зв'язку з втратою чинності постанови Кабінету Міністрів України від 20.12.99 N 2328 ( 2328-99-п ) "Про Порядок надання архітектурно-планувального завдання та технічних умов щодо інженерного забезпечення об'єкта архітектури і визначення розміру плати за їх видачу" (згідно з постановою Кабінету Міністрів України від 20.05.2009 N 489) ( 489-2009-п ) НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства регіонального розвитку та будівництва України від 24.11.2008 N 531 ( z1175-08 ) "Про затвердження індексу для обчислення розміру плати за видачу архітектурно-планувального завдання та технічних умов", зареєстрований у Міністерстві юстиції України 09.12.2008 за N 1175/15866.

2. Управлінню містобудування та архітектури (Сіленко М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності через десять днів з дня його офіційного опублікування.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Негоду В.А.

Т.в.о. Міністра А.Ф.Ткачук
