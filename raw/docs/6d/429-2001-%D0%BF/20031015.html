Про затвердження опису перехідного кубка Кабінету Міністрів України для нагородження переможців щорічного всеукраїнського конкурсу "Місто найкращого благоустрою"

Кабінет Міністрів України постановляє:

Затвердити опис перехідного кубка Кабінету Міністрів України для нагородження учасників щорічного всеукраїнського конкурсу "Місто найкращого благоустрою", які зайняли перше місце у конкурсі за відповідною категорією міст (додається).

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 6 травня 2001 р. N 429

ОПИС перехідного кубка Кабінету Міністрів України для нагородження переможців щорічного всеукраїнського конкурсу "Місто найкращого благоустрою"

Перехідний кубок Кабінету Міністрів України для нагородження переможців щорічного всеукраїнського конкурсу "Місто найкращого благоустрою" являє собою бронзову фігуру чоловіка, який у піднятих руках тримає земну кулю. Розміри кубка: висота - 40, діаметр - 15 сантиметрів.

Кубок для переможців конкурсу виготовляється в трьох варіантах із тонкого литва на воскових модулях з такими відмінностями в ручній обробці:

для I категорії міст - полірування з ручним тонуванням під золото;

для II категорії міст - чеканення з ручним тонуванням під золото;

для III категорії міст - патинування з ручною обробкою під золото.
