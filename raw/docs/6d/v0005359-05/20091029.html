ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

ПОСТАНОВА

05.01.2005 N 5

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 209 ( v0209359-09 ) від 29.10.2009 }

Про внесення змін до Порядку виділення асигнувань, обліку надходження та використання коштів Державного бюджету України, що виділяються територіальним виборчим комісіям на підготовку і проведення виборів Президента України, затвердженого постановою Центральної виборчої комісії від 9 листопада 2004 року N 1119

Відповідно до частини сьомої статті 38 Закону України "Про вибори Президента України" ( 474-14 ) та частини другої статті 2 Закону України "Про особливості застосування Закону України "Про вибори Президента України" при повторному голосуванні 26 грудня 2004 року" ( 2221-15 ), керуючись пунктом 7 статті 18, частинами другою - четвертою статті 23 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Пункт 3 розділу I Порядку виділення асигнувань, обліку надходження та використання коштів Державного бюджету України, що виділяються територіальним виборчим комісіям на підготовку і проведення виборів Президента України, затвердженого постановою Центральної виборчої комісії від 9 листопада 2004 року N 1119 ( v1119359-04 ) (далі - Порядок) викласти в новій редакції:

"Розпорядження коштами Державного бюджету України в територіальній виборчій комісії покладається на голову цієї комісії, а в разі його відсутності - секретаря виборчої комісії".

2. У пункті 11 розділу II Порядку слова "його заступника" замінити словом "секретаря".

3. У додатку N 1 до Порядку після слова "голова" доповнити словом "(секретар)".

4. У додатку N 3 до Порядку після слова "голова" доповнити словом "(секретар)".

5. Цю постанову надіслати територіальним виборчим комісіям.
