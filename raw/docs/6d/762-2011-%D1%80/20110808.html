Про передачу у 2011 році деяких бюджетних призначень

Текст документа від 08.08.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 серпня 2011 р. N 762-р Київ

Про передачу у 2011 році деяких бюджетних призначень

1. Передати бюджетні призначення, передбачені у 2011 році Міністерству фінансів у загальному фонді державного бюджету ( 2857-17 ) за програмою 3511090 "Державні капітальні видатки, що розподіляються Кабінетом Міністрів України" (загальнодержавні видатки), у сумі 126931 тис. гривень, зокрема:

1) Міністерству інфраструктури - 16000 тис. гривень для придбання двох пасажирських катерів для державного підприємства "Севастопольський морський торговельний порт";

2) Міністерству охорони здоров'я - 5000 тис. гривень для реалізації першого етапу будівництва у м. Вінниці міжрегіональної університетської клініки на базі Вінницького національного медичного університету імені М.І. Пирогова;

3) Вінницькій облдержадміністрації - 3000 тис. гривень для реконструкції дитячого дошкільного навчального закладу "Пролісок" в смт Сутиски Тиврівського району;

4) Волинській облдержадміністрації - 1460 тис. гривень для здійснення заходів з упорядкування пам'ятників, пам'ятних знаків, місць поховань жертв війни (україно-польського конфлікту 1943 року);

5) Донецькій облдержадміністрації - 20000 тис. гривень для будівництва хірургічного корпусу комунальної медичної установи "Клінічна Руднична лікарня" у м. Макіївці;

6) Київській облдержадміністрації - 15000 тис. гривень для коригування робочого проекту та реконструкції плавального басейну "Купава" по вул. Шевченка, 10, у м. Броварах;

7) Луганській облдержадміністрації - 35476 тис. гривень, з них:

15476 тис. для реконструкції системи водопостачання м. Суходільська Краснодонського району Луганської області;

20000 тис. для капітального ремонту, реконструкції та придбання обладнання для опікового відділення Луганської обласної клінічної лікарні;

8) Полтавській облдержадміністрації - 4995 тис. гривень для реконструкції дитячого садка "Пролісок" в смт Котельва Котелевського району Полтавської області;

9) Херсонській облдержадміністрації - 11000 тис. гривень для придбання для Центру серця Херсонської міської клінічної лікарні імені О.С. Луначарського сучасного ангіографа;

10) Севастопольській міськдержадміністрації - 15000 тис. гривень для реконструкції комунального закладу "Міська лікарня N 1 імені Пирогова" у м. Севастополі, у тому числі на проектно-вишукувальні роботи.

Передачу бюджетних призначень здійснити в межах видатків розвитку.

2. Забезпечити:

1) головним розпорядникам бюджетних коштів:

погодження передачі бюджетних призначень, передбаченої пунктом 1 цього розпорядження, з Комітетом Верховної Ради України з питань бюджету;

розроблення та затвердження у разі потреби порядків використання відповідних бюджетних коштів;

подання щомісяця до 5 числа Міністерству фінансів звіту про використання бюджетних коштів;

2) після зазначеного погодження:

Міністерству фінансів - відкриття у разі потреби нових бюджетних програм та внесення відповідних змін до розпису державного бюджету;

Державній казначейській службі - перерахування бюджетних коштів відповідно до переданих бюджетних призначень.

Прем'єр-міністр України М.АЗАРОВ
