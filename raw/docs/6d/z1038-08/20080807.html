Текст документа від 07.08.2008:

МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ

НАКАЗ

07.08.2008 N 1031

Зареєстровано в Міністерстві юстиції України 28 жовтня 2008 р. за N 1038/15729

Про визнання таким, що втратив чинність, наказу Міністерства фінансів України від 30.05.2003 N 384

Відповідно до постанови Кабінету Міністрів України від 12.07.2006 N 967 ( 967-2006-п ) "Про визнання такою, що втратила чинність, постанови Кабінету Міністрів України від 26 березня 2003 р. N 385" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства фінансів України від 30.05.2003 N 384 ( z0421-03 ) "Про порядок закупівлі послуг, пов'язаних із здійсненням державних зовнішніх запозичень, обслуговуванням і погашенням державного боргу", зареєстрований у Міністерстві юстиції України 02.06.2003 за N 421/7742.

2. Департаменту державного боргу (Висоцький В.В.) у встановленому порядку подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Литвина В.М.

Виконуючий обов'язки Міністра В.Матвійчук
