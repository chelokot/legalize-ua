Кабінет Міністрів України; Постанова, Порядок від 14.02.2007 № 206

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті на придбання літаків Ан-148 через державне лізингове підприємство

Стан: Чинний

Ідентифікатор: 206-2007-п

Текст документа від 26.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 лютого 2007 р. N 206 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті на придбання літаків Ан-148 через державне лізингове підприємство

{ Із змінами, внесеними згідно з Постановою КМ N 232 ( 232-2008-п ) від 26.03.2008 }

{ Установити, що кошти, передбачені у державному бюджеті ( 107-17 ) Міністерству транспорту та зв'язку за програмою "Придбання літаків Ан-148 через державне лізингове підприємство", використовуються у 2008 році відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 232 ( 232-2008-п ) від 26.03.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) на придбання літаків Ан-148 через державне лізингове підприємство, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 лютого 2007 р. N 206

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) на придбання літаків Ан-148 через державне лізингове підприємство

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених Мінтрансзв'язку у державному бюджеті ( 489-16 ) за програмою "Придбання літаків Ан-148 через державне лізингове підприємство" (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються одержувачу - державному лізинговому підприємству (далі - лізингове підприємство) для замовлення будівництва літаків Ан-148.

3. Використання бюджетних коштів здійснюється відповідно до договору поставки літаків Ан-148, укладеного між лізинговим підприємством та вітчизняним підприємством, що виробляє літаки на замовлення лізингоодержувача згідно з установленими ним специфікаціями та умовами.

Обов'язковою умовою при цьому є залучення в межах бюджетного року лізинговим підприємством власних та/або позикових коштів для придбання літаків. Частка зазначених коштів не може бути менш як 25 відсотків суми, зазначеної в договорі поставки, про що лізингове підприємство інформує орган Державного казначейства з поданням копій відповідних документів, які підтверджують зобов'язання лізингового підприємства.

{ Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 232 ( 232-2008-п ) від 26.03.2008 }

4. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

Закупівля лізинговим підприємством літаків Ан-148 за рахунок бюджетних коштів здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти ( 1490-14 ). { Пункт 4 доповнено абзацом згідно з Постановою КМ N 232 ( 232-2008-п ) від 26.03.2008 }

5. Оплата рахунків здійснюється з реєстраційного рахунку лізингового підприємства, відкритого в органах Державного казначейства, на підставі платіжних доручень та підтвердних документів у рамках зареєстрованих в органах Державного казначейства зобов'язань лізингового підприємства, передбачених пунктом 3 цього Порядку.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 232 ( 232-2008-п ) від 26.03.2008 }

6. Літаки, придбані лізинговим підприємством з використанням бюджетних коштів згідно з цим Порядком за договором фінансового лізингу, передаються лізингоодержувачу за тристороннім актом приймання-передачі, що укладається між лізинговим підприємством, лізингоодержувачем та вітчизняним підприємством - виробником літаків.

Літаки, що є предметом лізингу, можуть переходити у власність лізингоодержувача на підставі договору купівлі-продажу та двостороннього акта приймання-передачі із зазначенням результатів виконання договору фінансового лізингу.

7. Літаки, придбані лізинговим підприємством з використанням бюджетних коштів згідно з цим Порядком та надані у фінансовий лізинг, не можуть бути передані лізингоодержувачем у суборенду, сублізинг, заставлені, відчужені, що зазначається у договорі фінансового лізингу, в який також включаються вимоги до лізингоодержувача щодо виведення літаків із складу його майна в тижневий строк з моменту виникнення обставин, пов'язаних з порушенням справ про банкрутство, ліквідацією, арештом чи конфіскацією майна лізингоодержувача та повернення їх лізинговому підприємству. При цьому про застосування зазначених заходів лізингоодержувач письмово повідомляє лізинговому підприємству не пізніше ніж через три робочі дні.

У договорі фінансового лізингу, предметом якого є літаки, придбані з використанням бюджетних коштів згідно з цим Порядком, передбачається відповідальність за невиконання або несвоєчасне виконання зобов'язань щодо сплати лізингових платежів - неустойка (штраф, пеня).

8. Кошти, що надходять лізинговому підприємству від лізингоодержувача як складова лізингових платежів у частині відшкодування вартості літаків (пропорційно обсягу залучених бюджетних коштів на їх будівництво), та суми неустойки (штрафу, пені) за неналежне виконання договору фінансового лізингу лізингове підприємство спрямовує виключно на будівництво вітчизняних літаків з метою їх подальшої передачі у лізинг.

9. Контроль за витрачанням бюджетних коштів лізинговим підприємством здійснює Мінтрансзв'язку.

10. Складення та подання фінансової звітності про використання бюджетних коштів здійснюється в установленому законодавством порядку.
