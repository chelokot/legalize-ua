ПОСТАНОВА від 14 січня 1999 р. N 58 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1231 ( 1231-2000-п ) від 07.08.2000 )

Про введення додатково однієї посади заступника Міністра економіки України

Кабінет Міністрів України постановляє:

Ввести додатково одну посаду заступника Міністра економіки України у межах граничної чисельності працівників апарату Міністерства.
