ГОЛОВНЕ УПРАВЛІННЯ ДЕРЖАВНОЇ СЛУЖБИ УКРАЇНИ

НАКАЗ

30.03.2007 N 97

Зареєстровано в Міністерстві юстиції України 24 квітня 2007 р. за N 421/13688

Про визнання таким, що втратив чинність, наказу Головного управління Державної служби при Кабінеті Міністрів України від 11.11.97 N 28 "Про затвердження Порядку надання інформації для занесення до Генерального реєстру контрактів"

Відповідно до пункту 2 постанови Кабінету Міністрів України від 28.12.92 N 731 ( 731-92-п ) "Про затвердження Положення про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" ( із змінами) та пункту 2 постанови Кабінету Міністрів України від 12.07.2005 N 553 ( 553-2005-п ) "Про внесення змін до деяких постанов Кабінету Міністрів України з питань державної служби" та з метою приведення у відповідність до чинного законодавства нормативно-правових актів Головдержслужби України НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Головного управління Державної служби при Кабінеті Міністрів України від 11.11.97 N 28 ( z0569-97 ) "Про затвердження Порядку надання інформації для занесення до Генерального реєстру контрактів", зареєстрований у Міністерстві юстиції України 02.12.97 за N 569/2373 (із змінами).

2. Контроль за виконанням цього наказу покласти на начальника інформаційно-аналітичного управління Дунаєва В.М.

В.о. Начальника Головного управління державної служби України М.Борсук
