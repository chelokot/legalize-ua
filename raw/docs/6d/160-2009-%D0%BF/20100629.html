Кабінет Міністрів України постановляє:

Затвердити Порядок використання коштів, передбачених у державному бюджеті для проведення соціальної роботи із сім'ями, дітьми та молоддю, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 5 березня 2009 р. N 160

ПОРЯДОК використання коштів, передбачених у державному бюджеті для проведення соціальної роботи із сім'ями, дітьми та молоддю

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 475 ( 475-2010-п ) від 21.06.2010 }

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті на відповідний рік Держсоцслужбі за програмою "Реалізація програм та здійснення заходів Державної соціальної служби для сім'ї, дітей та молоді" (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 475 ( 475-2010-п ) від 21.06.2010 }

2. Бюджетні кошти використовуються для:

здійснення освітніх, науково-методичних та навчально-роз'яснювальних заходів з різних аспектів проведення соціальної роботи із сім'ями, дітьми та молоддю для працівників центрів соціальних служб для сім'ї, дітей та молоді, закладів соціального обслуговування та волонтерів;

підготовки, розроблення і видання інформаційних та методичних матеріалів, посібників з питань проведення соціальної роботи із сім'ями, дітьми та молоддю;

розроблення, виготовлення та розміщення соціальної реклами з питань підтримки сім'ї, дітей та молоді, які опинилися у складних життєвих обставинах, толерантного ставлення до ВІЛ-інфікованих дітей, розвитку сімейних форм виховання дітей-сиріт та дітей, позбавлених батьківського піклування;

здійснення інших заходів у сфері соціальної роботи із сім'ями, дітьми та молоддю.

{ Пункт 2 в редакції Постанови КМ N 475 ( 475-2010-п ) від 21.06.2010 }

3. Розподіл бюджетних коштів здійснює Держсоцслужба згідно з календарним планом виконання державних програм та проведення соціальної роботи із сім'ями, дітьми та молоддю на відповідний рік, який затверджує Мінсім'ямолодьспорт, виходячи з потреби в коштах, визначеної на підставі розрахунків видатків за кожною категорією витрат, діючих цін та тарифів з урахуванням принципу економного витрачання бюджетних коштів та отримання максимального ефекту від їх використання, а також необхідності виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державного казначейства, у разі їх відповідності паспорту бюджетної програми. { Абзац перший пункту 3 із змінами, внесеними згідно з Постановою КМ N 475 ( 475-2010-п ) від 21.06.2010 }

Зазначена робота організовується та проводиться Держсоцслужбою у встановленому Мінсім'ямолодьспортом порядку.

4. Не допускається спрямування бюджетних коштів на:

виконання програм і здійснення заходів, що розробляються громадськими організаціями;

утримання установ та організацій, у тому числі громадських, або надання їм фінансової підтримки;

оплату послуг посередників;

витрати, які безпосередньо не пов'язані з проведенням соціальної роботи із сім'ями, дітьми та молоддю.

5. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

6. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

Держсоцслужба укладає договори про надання послуг, необхідних для організації та проведення соціальної роботи із сім'ями, дітьми та молоддю безпосередньо з їх надавачами, а договори про оренду (експлуатацію) приміщень, обладнання та оргтехніки - безпосередньо з власниками (балансоутримувачами) зазначеного майна.

7. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
