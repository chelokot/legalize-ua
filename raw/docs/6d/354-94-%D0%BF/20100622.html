Кабінет Міністрів України; Постанова від 04.06.1994 № 354

Про затвердження зразка бланка паспорта громадянина України для виїзду за кордон

Стан: Втратив чинність

Ідентифікатор: 354-94-п

Текст документа від 22.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 червня 1994 р. N 354 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 858 ( 858-2007-п ) від 26.06.2007 }

{ Дію Постанови відновлено згідно з Постановою КМ N 378 ( 378-2005-п ) від 26.05.2005 }

{ Постанова втратила чинність на підставі Постанови КМ N 1725 ( 1725-2004-п ) від 23.12.2004 }

Про затвердження зразка бланка паспорта громадянина України для виїзду за кордон

{ Із змінами, внесеними згідно з Постановами КМ N 1184 ( 1184-2009-п ) від 29.10.2009 N 191 ( 191-2010-п ) від 17.02.2010 N 430 ( 430-2010-п ) від 16.06.2010 }

Відповідно до Указу Президента України від 28 жовтня 1993 р. N 491/93 "Про паспорт громадянина України для виїзду за кордон" Кабінет Міністрів України постановляє:

{ Дію пункту 1 відновлено на період до 15 липня 2010 р. згідно з Постановою КМ N 430 ( 430-2010-п ) від 16.06.2010 }

{ Дію пункту 1 відновлено на період до 15 березня 2010 р. згідно з Постановою КМ N 191 ( 191-2010-п ) від 17.02.2010 }

{ Дію пункту 1 відновлено на період до 1 січня 2010 р. згідно з Постановою КМ N 1184 ( 1184-2009-п ) від 29.10.2009 }

1. Затвердити зразок бланка паспорта громадянина України для виїзду за кордон згідно з додатком.

2. Головному управлінню по організації виготовлення цінних паперів і документів суворої звітності Міністерства фінансів забезпечити виготовлення у 1994 році бланків паспорта громадянина України для виїзду за кордон за технічним описом і захисними характеристиками, погодженими з Міністерством внутрішніх справ, Міністерством закордонних справ і Службою безпеки.
