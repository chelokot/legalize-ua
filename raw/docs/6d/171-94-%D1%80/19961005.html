Про уповноваження здійснювати експорт товарів за кодами ТН ЗЕД

Стан: Втратив чинність

Ідентифікатор: 171-94-р

Текст документа від 05.10.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 березня 1994 р. N 171-р Київ

( Розпорядження втратило чинність в частині надання повноважень на здійснення експорту спирту за кодом ТН ЗЕД 22.07 на підставі Розпорядження КМ N 647-р ( 647-96-р ) від 05.10.96 )

Уповноважити колективне сільськогосподарське підприємство імені С.М. Кірова Чернігівської області здійснювати експорт товарів за кодом ТН ЗЕД 22.07, 22.08 ( n0001410-92 ).
