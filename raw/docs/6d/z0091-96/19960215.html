НАКАЗ

N 17 від 15.02.96 Зареєстровано в Міністерстві м.Київ юстиції України 21 лютого 1996 р. за N 91/1116

Про внесення змін до наказу Міністерства праці України

від 20.08.93 N 66 "Про умови оплати праці працівників

Українського державного центру соціальних служб для молоді"

Відповідно до доручення Кабінету Міністрів України від 29.01.96 N 1836/30 за погодженням з Міністерством фінансів України та Міністерством України у справах молоді і спорту НАКАЗУЮ:

1. Внести такі зміни до наказу Міністерства праці України від 20.08.93 N 66 ( z0127-93 ) "Про умови оплати праці працівників Українського державного центру соціальних служб для молоді":

1.1. Пункт 4 викласти в такій редакції:

"4. Посадові оклади керівних працівників, спеціалістів і службовців Українського державного центру соціальних служб для молоді, визначені цим наказом, обчислюються за шкалою співвідношень посадових окладів до установленого мінімального розміру заробітної плати і підвищуються за коефіцієнтами, затвердженими постановою Кабінету Міністрів України від 25 грудня 1995 року N 1043 ( 1043-95-п ) "Про упорядкування оплати праці працівників апарату органів державної виконавчої влади, прокуратури, судів, митної служби та інших органів".

2. Вважати таким, що втратив чинність, підпункт 1.4 наказу Міністерства праці України від 18.10.95 N 42 ( z0398-95 ) "Про внесення змін до наказу Міністерства праці України від 20.08.93 N 66 "Про умови оплати праці працівників Українського державного центру соціальних служб для молоді".
