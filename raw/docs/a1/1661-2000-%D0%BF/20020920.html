КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 листопада 2000 р. N 1661 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1266 ( 1266-2002-п ) від 29.08.2002 )

Про внесення зміни до постанови Кабінету Міністрів України від 9 березня 1999 р. N 342

Кабінет Міністрів України постановляє:

Доповнити додаток 3 до Порядку отримання суб'єктами підприємницької діяльності спирту етилового денатурованого (спирту технічного), який використовується для виготовлення продукції з його вмістом, затвердженого постановою Кабінету Міністрів України від 9 березня 1999 р. N 342 ( 342-99-п ) (Офіційний вісник України, 1999 р., N 10, ст. 392, N 35, ст. 1812), позицією такого змісту:

"130213000 Екстракт хмелю харчова промисловість".
