{ Розпорядження втратило чинність на підставі Указу Президента N 299/2006 ( 299/2006 ) від 10.04.2006 }

Про голову Української частини Спільної українсько-узбецької комісії з всебічного співробітництва

На зміну Розпорядження Президента України від 18 жовтня 1997 року N 355 ( 355/97-рп ) призначити Прем'єр-міністра України ЮЩЕНКА Віктора Андрійовича головою Української частини Спільної українсько-узбецької комісії з всебічного співробітництва, увільнивши від цих обов'язків В. Пустовойтенка.

Президент України Л.КУЧМА
