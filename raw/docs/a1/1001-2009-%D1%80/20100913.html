Кабінет Міністрів України; Розпорядження від 26.08.2009 № 1001-р

Про добудову підвідних газопроводів

Стан: Чинний

Ідентифікатор: 1001-2009-р

Текст документа від 13.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 серпня 2009 р. N 1001-р Київ

Про добудову підвідних газопроводів

{ Назва Розпорядження із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010 Розпорядженням КМ N 1881-р ( 1881-2010-р ) від 13.09.2010 }

{ Із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010 Розпорядженням КМ N 1881-р ( 1881-2010-р ) від 13.09.2010 }

1. Погодитися з пропозицією Міністерства палива та енергетики та Національної акціонерної компанії "Нафтогаз України" щодо фінансування Компанією робіт з добудови підвідних газопроводів (далі - газопроводи) відповідно до затвердженого Національною акціонерною компанією "Нафтогаз України" переліку.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010, Розпорядженням КМ N 1881-р ( 1881-2010-р ) від 13.09.2010 }

2. Узяти до відома, що для забезпечення добудови газопроводів Національна акціонерна компанія "Нафтогаз України" укладає відповідні договори із замовниками їх будівництва на загальну суму фінансування, визначену фінансовим планом Національної акціонерної компанії "Нафтогаз України".

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010; в редакції Розпорядження КМ N 1881-р ( 1881-2010-р ) від 13.09.2010 }

3. Замовник будівництва газопроводів здійснює за державні кошти закупівлю товарів, робіт і послуг, пов'язаних із завершенням їх будівництва, згідно із законодавством.

{ Пункт 3 в редакції Розпорядження КМ N 1881-р ( 1881-2010-р ) від 13.09.2010 }

4. Раді міністрів Автономної Республіки Крим, обласним та Севастопольській міській держадміністраціям сприяти відведенню земельних ділянок для добудови газопроводів та підготовці необхідних дозвільних документів, а також введенню добудованих газопроводів в експлуатацію та передачі їх у державну власність. { Пункт 4 із змінами, внесеними згідно з Розпорядженням КМ N 1881-р ( 1881-2010-р ) від 13.09.2010 }

5. Міністерству палива та енергетики забезпечити передачу профінансованих за рахунок коштів Національної акціонерної компанії "Нафтогаз України" та її дочірніх підприємств об'єктів незавершеного будівництва газопроводів або їх часток у державну власність з подальшим введенням в установленому законодавством порядку цілісних об'єктів в експлуатацію.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010; в редакції Розпорядження КМ N 1881-р ( 1881-2010-р ) від 13.09.2010 }

6. Міністерству палива та енергетики забезпечити контроль за обґрунтованістю та цільовим використанням коштів, виділених на добудову зазначених газопроводів.

{ Розпорядження доповнено пунктом 6 згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010; із змінами, внесеними згідно з Розпорядженням КМ N 1881-р ( 1881-2010-р ) від 13.09.2010 }

7. Міністерству палива та енергетики забезпечити включення до фінансових планів Національної акціонерної компанії "Нафтогаз України" видатків на добудову газопроводів відповідно до затвердженого Компанією переліку.

{ Розпорядження доповнено пунктом 7 згідно з Розпорядженням КМ N 1881-р ( 1881-2010-р ) від 13.09.2010 }

Прем'єр-міністр України Ю.ТИМОШЕНКО
