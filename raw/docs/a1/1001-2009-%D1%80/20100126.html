Кабінет Міністрів України; Розпорядження від 26.08.2009 № 1001-р

Про добудову підвідних газопроводів

Стан: Чинний

Ідентифікатор: 1001-2009-р

Текст документа від 26.01.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 серпня 2009 р. N 1001-р Київ

Про добудову підвідних газопроводів з високим рівнем будівельної готовності

{ Назва Розпорядження із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010 }

{ Із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010 }

1. Погодитися з пропозицією Мінпаливенерго та НАК "Нафтогаз України" щодо фінансування Компанією робіт з добудови підвідних газопроводів з високим рівнем будівельної готовності, які можуть бути введені в експлуатацію до 1 липня 2010 року (далі - газопроводи), відповідно до затвердженого НАК "Нафтогаз України" переліку.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010 }

2. Узяти до відома, що для забезпечення добудови газопроводів НАК "Нафтогаз України" укладає тристоронні договори з дочірнім підприємством "Нафтогазмережі" НАК "Нафтогаз України" або дочірньою компанією "Укртрансгаз" НАК "Нафтогаз України" відповідно до сфер діяльності та замовниками їх будівництва на загальну суму фінансування, визначену фінансовим планом НАК "Нафтогаз України".

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010 }

3. Установити, що відповідно до пункту 6 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006), замовник будівництва газопроводів здійснює за державні кошти закупівлю товарів, робіт і послуг, пов'язаних із завершенням їх будівництва, за процедурою закупівлі у одного учасника.

Мінекономіки забезпечити надання висновків щодо закупівлі зазначених товарів, робіт і послуг протягом двох днів з моменту подання замовником будівництва відповідних документів.

4. Раді міністрів Автономної Республіки Крим, обласним та Севастопольській міській держадміністраціям сприяти відведенню земельних ділянок для добудови газопроводів та підготовці необхідних дозвільних документів.

5. Мінпаливенерго, Мінекономіки, Фонду державного майна, НАК "Нафтогаз України" забезпечити передачу в установленому законом порядку зазначених газопроводів у державну власність і на баланс дочірнього підприємства "Нафтогазмережі" НАК "Нафтогаз України" або дочірньої компанії "Укртрансгаз" НАК "Нафтогаз України" відповідно до сфер діяльності.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010 }

6. Мінпаливенерго забезпечити контроль за обґрунтованістю та цільовим використанням коштів, виділених на добудову зазначених газопроводів.

{ Розпорядження доповнено пунктом 6 згідно з Постановою КМ N 43 ( 43-2010-п ) від 20.01.2010 }

Прем'єр-міністр України Ю.ТИМОШЕНКО
