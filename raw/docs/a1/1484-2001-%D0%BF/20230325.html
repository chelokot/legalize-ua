КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2001 р. N 1484 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 242 ( 242-2023-п ) від 17.03.2023 }

Про внесення змін до постанови Кабінету Міністрів України від 26 липня 2000 р. N 1175

Кабінет Міністрів України постановляє:

Внести до розділу "Чернігівська область" переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку Житомирської, Чернігівської областей, м. Шостки Сумської області, на території спеціальної економічної зони "Миколаїв", де встановлено спеціальний режим інвестиційної діяльності, затвердженого постановою Кабінету Міністрів України від 26 липня 2000 р. N 1175 ( 1175-2000-п ) "Про деякі питання інвестиційної діяльності на територіях пріоритетного розвитку та спеціальних економічних зон" (Офіційний вісник України, 2000 р., N 30, 1281) такі зміни:

1) позицію 01.11 викласти у такій редакції:

"01.11 Вирощування зернових культур на зерно для продовольчих цілей, на корм, на насіння; картоплі; прядильних культур (льону)";

2) доповнити перелік:

після позиції "15.51 Виробництво молочних продуктів"

позицією "15.62 Виробництво крохмалю та крохмальних продуктів (виключно з вітчизняної сировини)";

після позиції "17.14 Підготовка та прядіння лляної пряжі" позицією, "17.40.1 Виробництво виробів з текстилю".

Прем'єр-міністр України А.КІНАХ
