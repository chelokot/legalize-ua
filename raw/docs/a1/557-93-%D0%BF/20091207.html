ПОСТАНОВА від 19 липня 1993 р. N 557 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1259 ( 1259-2009-п ) від 25.11.2009 }

Про затвердження зразків посвідчення тракториста-машиніста та документів, необхідних для реєстрації тракторів та інших машин

( Із змінами, внесеними згідно з Постановами КМ N 885 ( 885-2002-п ) від 01.07.2002 N 1615 ( 1615-2004-п ) від 30.11.2004 )

Кабінет Міністрів України постановляє:

1. Затвердити зразки посвідчення тракториста-машиніста, талона попереджень до нього та перелік порушень, за які робиться відмітка про попередження, згідно з додатками 1 і 2.

( Пункт 1 в редакції Постанови КМ N 1615 ( 1615-2004-п ) від 30.11.2004 )

2. Покласти на Державну інспекцію по нагляду за технічним станом машин і обладнання Міністерства аграрної політики та інспекції на місцях державну реєстрацію тракторів, самохідних шасі, самохідних меліоративних, дорожньобудівних машин і тракторних причепів, що є на підприємствах, в установах, організаціях і господарствах незалежно від форм власності та у власності громадян, і видачу посвідчень тракториста-машиніста. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 885 ( 885-2002-п ) від 01.07.2002 )

В.о. Прем'єр-міністра України Ю.ЗВЯГІЛЬСЬКИЙ

Примітки:

1. Бланк посвідчення тракториста-машиніста виготовляється розміром 105 х 70 міліметрів з цупкого світлого паперу з кольоровою сіткою.

2. Бланки посвідчень, що виготовляються централізовано на замовлення Мінагрополітики, є документами суворої звітності, пронумеровані друкарським способом, захищені голограмою.

3. Серія посвідчення складається з двох великих букв, які мають відповідники в латинському алфавіті.

4. Номер посвідчення шестизначний.

5. Після заповнення посвідчення ламінується.

ПЕРЕЛІК порушень, за які робиться відмітка про попередження

1. Робота без дорожнього листа, свідоцтва про реєстрацію машини (технічного талона, технічного паспорта), номерного знака.

2. Використання машин не за призначенням.

3. Порушення правил дорожнього руху.

4. Керування машиною з несправностями, що загрожують безпеці руху.

5. Порушення правил технічної експлуатації.
