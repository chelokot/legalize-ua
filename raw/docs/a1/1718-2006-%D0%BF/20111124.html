ПОСТАНОВА від 13 грудня 2006 р. N 1718 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1183 ( 1183-2011-п ) від 21.11.2011 }

Про доповнення переліку галузей науки, з яких може бути присуджений науковий ступінь

Кабінет Міністрів України постановляє:

Доповнити перелік галузей науки, з яких може бути присуджений науковий ступінь, затверджений постановою Кабінету Міністрів України від 29 листопада 1997 р. N 1328 ( 1328-97-п ) (Офіційний вісник України, 1997 р., число 49, с. 36), такими абзацами:

"культурологія

соціальні комунікації".

Прем'єр-міністр України В.ЯНУКОВИЧ
