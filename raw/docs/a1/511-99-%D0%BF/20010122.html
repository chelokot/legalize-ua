КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 березня 1999 р. N 511 Київ

( Постанова втратила чинність на підставі Постанови КМ N 34 ( 34-2001-п ) від 22.01.2001 )

Про склад Міжвідомчої ради з впровадження програми економічних реформ

( Із змінами, внесеними згідно з Постановою КМ N 691 ( 691-99-п ) від 23.04.99 )

Кабінет Міністрів України постановляє:

1. Затвердити новий склад Міжвідомчої ради з впровадження програми економічних реформ ( 86-96-п ) (додається).

2. Визнати такими, що втратили чинність, пункт 1 постанови Кабінету Міністрів України від 17 травня 1997 р. N 455 ( 455-97-п ) "Питання Міжвідомчої ради з впровадження програми економічних реформ" (Офіційний вісник України 1997 р., число 21, с. 17) та постанову Кабінету Міністрів України від 15 грудня 1997 р. N 1400 ( 1400-97-п ) "Про зміну у складі Міжвідомчої ради з впровадження програми економічних реформ".
