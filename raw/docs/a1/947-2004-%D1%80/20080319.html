КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 2004 р. N 947-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

Про утворення робочої групи з підготовки пропозицій щодо удосконалення законодавства з питань видавничої справи та діяльності друкованих засобів масової інформації

( Із змінами, внесеними згідно з Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 )

Утворити робочу групу з підготовки пропозицій щодо удосконалення законодавства з питань видавничої справи та діяльності друкованих засобів масової інформації у складі згідно з додатком.

Дозволити керівнику робочої групи вносити в разі потреби зміни до її складу та залучати до роботи фахівців центральних органів виконавчої влади, підприємств, установ та організацій (за погодженням з їх керівниками).
