{Постанова втратила чинність на підставі Постанови Центральної виборчої комісії № 561 від 10.12.2020 }

{Постанова втратила чинність у частині організації підготовки та проведення чергових, позачергових, перших місцевих виборів на підставі Постанови Центральної виборчої комісії № 124 від 25.06.2020 }

Про форми списків виборців та інших виборчих документів для підготовки та проведення голосування з місцевих виборів

Відповідно до пункту 4 частини першої статті 24, частини тринадцятої статті 27, частин першої, другої статті 30, частини другої статті 32, частин першої, другої статті 34, частини другої статті 78, частин десятої - дванадцятої статті 87 Закону України "Про місцеві вибори", частин п’ятої - восьмої статті 27, частин сьомої, восьмої статті 28 Закону України "Про Державний реєстр виборців", керуючись статтями 11 - 13, пунктом 7 статті 21 Закону України "Про Центральну виборчу комісію", Центральна виборча комісія постановляє :

1. Встановити форми:

попереднього списку виборців на звичайній виборчій дільниці (додаток 1);

уточненого списку виборців на звичайній виборчій дільниці (додаток 2);

списку виборців на спеціальній виборчій дільниці (додаток 3);

списку виборців для повторного голосування на звичайній виборчій дільниці (додаток 4);

списку виборців для повторного голосування на спеціальній виборчій дільниці (додаток 5);

витягу із списку виборців на звичайній виборчій дільниці для голосування за місцем перебування виборців, не здатних пересуватися самостійно (додаток 6);

витягу із списку виборців на спеціальній виборчій дільниці для голосування за місцем перебування виборців, не здатних пересуватися самостійно (додаток 7);

подання з відомостями про громадян України, які мають право голосу на місцевих виборах та на день їх проведення перебуватимуть у стаціонарному закладі охорони здоров’я (додаток 8);

акта про передачу органом ведення Державного реєстру виборців дільничній виборчій комісії попереднього списку виборців на звичайній виборчій дільниці (додаток 9);

акта про передачу органом ведення Державного реєстру виборців дільничній виборчій комісії уточненого списку виборців на звичайній виборчій дільниці (додаток 10);

акта про передачу органом ведення Державного реєстру виборців дільничній виборчій комісії списку виборців для повторного голосування на звичайній виборчій дільниці (додаток 11).

2. Списки виборців (додатки 1 - 5), витяги із списку виборців (додатки 6, 7) виготовляються на аркушах формату А3 з обох боків.

3. Визнати такою, що втратила чинність, постанову Центральної виборчої комісії від 23 квітня 2014 року № 343 "Про форми списків виборців на виборчих дільницях та інших виборчих документів для підготовки та проведення голосування з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів".

4. Цю постанову надіслати Міністерству охорони здоров’я України для доведення до відома керівників стаціонарних закладів охорони здоров’я, а також обласним та Київській міській державним адміністраціям для доведення до відома відповідних органів ведення Державного реєстру виборців та територіальних виборчих комісій.
