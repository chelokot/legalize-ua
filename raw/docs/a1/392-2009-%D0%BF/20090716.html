Кабінет Міністрів України; Постанова від 22.04.2009 № 392

Деякі питання фінансування розрахунків за природний газ суб'єктів господарювання, що виробляють теплову енергію, яка споживається населенням

Стан: Чинний

Ідентифікатор: 392-2009-п

Текст документа від 16.07.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 квітня 2009 р. N 392 Київ

Деякі питання фінансування розрахунків за природний газ суб'єктів господарювання, що виробляють теплову енергію, яка споживається населенням

{ Із змінами, внесеними згідно з Постановами КМ N 402 ( 402-2009-п ) від 28.04.2009 N 617 ( 617-2009-п ) від 24.06.2009 N 703 ( 703-2009-п ) від 08.07.2009 }

Кабінет Міністрів України постановляє:

1. Установити, що у 2009 році зобов'язання за запозиченнями (кредитами), що здійснюються в установленому законодавством порядку суб'єктами господарювання, які виробляють теплову енергію (далі - суб'єкти господарювання), у відкритому акціонерному товаристві "Державний ощадний банк України" та інших банках для погашення заборгованості за спожитий природний газ перед Національною акціонерною компанією "Нафтогаз України", що утворилася станом на 1 квітня 2009 р., оформлюються шляхом укладення відповідного договору між суб'єктом господарювання та відповідним банком.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 402 ( 402-2009-п ) від 28.04.2009; в редакції Постанови N 617 ( 617-2009-п ) від 24.06.2009, із змінами, внесеними згідно з Постановою КМ N 703 ( 703-2009-п ) від 08.07.2009 }

2. НАК "Нафтогаз України" забезпечити спрямування коштів, отриманих відповідно до пункту 1 цієї постанови, на сплату до загального фонду державного бюджету податку на додану вартість під час здійснення митного оформлення природного газу, ввезеного на митну територію України у 2009 році, та на розрахунки за імпортований природний газ.

{ Пункт 2 із змінами, внесеними згідно з Постановами КМ N 402 ( 402-2009-п ) від 28.04.2009, N 617 ( 617-2009-п ) від 24.06.2009 }

{ Пункт 3 виключено на підставі Постанови КМ N 617 ( 617-2009-п ) від 24.06.2009 }

4. Державному казначейству забезпечити відкриття у своїх органах окремих рахунків для зарахування запозичень та проведення розрахунків учасниками відповідно до цієї постанови.

5. Міністерству фінансів під час складання проектів Державного бюджету України на 2010-2012 роки передбачати видатки для погашення основної суми боргу за кредитами, отриманими суб'єктами господарювання відповідно до пункту 1 цієї постанови, та 50 відсотків витрат на обслуговування такого боргу.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 402 ( 402-2009-п ) від 28.04.2009; в редакції Постанови N 617 ( 617-2009-п ) від 24.06.2009 }

6. Рекомендувати відкритому акціонерному товариству "Державний ощадний банк України" розробити типовий договір про надання ним кредитів суб'єктам господарювання для погашення заборгованості за спожитий природний газ перед Національною акціонерною компанією "Нафтогаз України", що утворилася станом на 1 квітня 2009 року.

{ Постанову доповнено пунктом 6 згідно з Постановою КМ N 617 ( 617-2009-п ) від 24.06.2009; із змінами, внесеними згідно з Постановою КМ N 703 ( 703-2009-п ) від 08.07.2009 }
