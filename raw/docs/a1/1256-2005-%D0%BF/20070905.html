Про затвердження переліку суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості

Стан: Чинний

Ідентифікатор: 1256-2005-п

Текст документа від 05.09.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 грудня 2005 р. N 1256 Київ

Про затвердження переліку суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості

{ Із змінами, внесеними згідно з Постановою КМ N 1102 ( 1102-2007-п ) від 05.09.2007 }

Відповідно до частини другої статті 1 Закону України "Про заходи щодо державної підтримки суднобудівної промисловості в Україні" ( 1242-14 ) Кабінет Міністрів України постановляє:

1. Затвердити перелік суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості, що додається.

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 грудня 2005 р. N 1256

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 16 червня 2000 р. N 978 ( 978-2000-п ) "Про затвердження переліку суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості" (Офіційний вісник України, 2000 р., N 25, ст. 1047).

2. Постанова Кабінету Міністрів України від 21 серпня 2001 р. N 1106 ( 1106-2001-п ) "Про внесення змін до постанови Кабінету Міністрів України від 16 червня 2000 р. N 978" (Офіційний вісник України, 2001 р., N 34, ст. 1593).

3. Постанова Кабінету Міністрів України від 27 травня 2002 р. N 696 ( 696-2002-п ) "Про внесення змін до постанови Кабінету Міністрів України від 16 червня 2000 р. N 978" (Офіційний вісник України, 2002 р., N 22, ст. 1065).

4. Постанова Кабінету Міністрів України від 23 грудня 2004 р. N 1720 ( 1720-2004-п ) "Про внесення зміни до переліку суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості" (Офіційний вісник України, 2004 р., N 51, ст. 3358).
