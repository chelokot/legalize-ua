Президент України; Указ від 05.10.2009 № 798/2009

Питання Наглядової ради Національної академії державного управління при Президентові України

Стан: Втратив чинність

Ідентифікатор: 798/2009

Текст документа від 01.01.2012:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1110/2011 ( 1110/2011 ) від 09.12.2011 }

Питання Наглядової ради Національної академії державного управління при Президентові України

1. На зміну статті 1 Указу Президента України від 24 лютого 2004 року N 215 ( 215/2004 ) "Про Наглядову раду Національної академії державного управління при Президентові України" (зі змінами, внесеними Указом від 22 грудня 2008 року N 1189) ( 1189/2008 ):

увести до складу Наглядової ради Національної академії державного управління при Президентові України ЄХАНУРОВА Юрія Івановича - Першого заступника Глави Секретаріату Президента України, призначивши його головою цієї Наглядової ради;

вивести зі складу Наглядової ради Національної академії державного управління при Президентові України Р. Безсмертного, увільнивши його від виконання обов'язків голови цієї Наглядової ради.

2. Визнати такою, що втратила чинність, статтю 1 Указу Президента України від 4 листопада 2008 року N 988 ( 988/2008 ) "Питання Наглядової ради Національної академії державного управління при Президентові України".

3. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 5 жовтня 2009 року N 798/2009
