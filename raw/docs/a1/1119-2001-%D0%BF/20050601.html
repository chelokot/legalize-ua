Текст документа від 01.06.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 серпня 2001 р. N 1119 Київ

Про внесення змін до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288

( Із змінами, внесеними згідно з Постановами КМ N 1562 ( 1562-2003-п ) від 02.10.2003 N 1711 ( 1711-2003-п ) від 01.11.2003 N 1815 ( 1815-2003-п ) від 21.11.2003 - скасовано на підставі Указу Президента N 1394/2003 ( 1394/2003 ) від 01.12.2003 N 146 ( 146-2005-п ) від 25.02.2005 N 224 ( 224-2005-п ) від 30.03.2005 N 515 ( 515-2005-п ) від 30.06.2005 )

Кабінет Міністрів України постановляє:

1. Внести у додатки 2 і 6 до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288 ( 2288-99-п ) "Про впорядкування умов оплати праці працівників апарату органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів" (Офіційний вісник України, 1999 р., N 50, ст. 2469, N 51, ст. 2550; 2000 р., N 30, ст. 1277) зміни, що додаються.

2. Установити надбавку за особливий характер роботи та інтенсивність праці Державному секретареві України, Керівнику Державного управління справами, Керівнику апарату Верховної Ради України, їх першим заступникам та заступникам, першим заступникам та заступникам Міністра у розмірі 90 відсотків, а членам Кабінету Міністрів України 100 відсотків у порядку, визначеному розпорядженням Кабінету Міністрів України від 4 липня 1995 р. N 414 ( 414-95-р ).

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1562 ( 1562-2003-п ) від 02.10.2003, в редації Постанов КМ N 1711 ( 1711-2003-п ) від 01.11.2003; N 1815 ( 1815-2003-п ) від 21.11.2003 - редакцію скасовано на підставі Указу Президента N 1394/2003 ( 1394/2003 ) від 01.12.2003; із змінами, внесеними згідно з Постановами КМ N 146 ( 146-2005-п ) від 25.02.2005, N 515 ( 515-2005-п ) від 30.06.2005 )

3. Визнати таким, що втратив чинність, пункт 2 постанови Кабінету Міністрів України від 4 липня 1995 р. N 488 ( 488-95-п ) в частині встановлення міністрам надбавки за особливий характер роботи та інтенсивність праці.

Прем'єр-міністр України А.КІНАХ

( Пункт 1 втратив чинність на підставі Постанови КМ N 224 ( 224-2005-п ) від 30.03.2005 )

2. У додатку 6:

після позиції "Міністр" доповнити позицією "Державний секретар міністерства - 370";

позиції "Перший заступник Міністра - 340", "Заступник Міністра - 330" доповнити позиціями "Перший заступник державного секретаря міністерства - 340", "Заступник державного секретаря міністерства - 330".
