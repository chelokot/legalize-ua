Кабінет Міністрів України; Розпорядження від 12.10.2001 № 480-р

Про утворення робочої групи з координації дій центральних органів виконавчої влади щодо забезпечення податкових та інших надходжень, передбачених Державним бюджетом України на 2001 рік

Стан: Втратив чинність

Ідентифікатор: 480-2001-р

Текст документа від 26.03.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 жовтня 2001 р. N 480-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 383 ( 383-2003-п ) від 26.03.2003 )

Про утворення робочої групи з координації дій центральних органів виконавчої влади щодо забезпечення податкових та інших надходжень, передбачених Державним бюджетом України на 2001 рік

( Із змінами, внесеними згідно з Розпорядженням КМ N 505-р ( 505-2001-р ) від 07.11.2001 )

( Дію Розпорядження продовжено на 2002 рік згідно з Постановою КМ N 21 ( 21-2002-п ) від 10.01.2002 )

1. Утворити робочу групу з координації дій центральних органів виконавчої влади щодо забезпечення податкових та інших надходжень, передбачених Державним бюджетом України на 2001 рік ( 2120-14 ), у складі згідно з додатком.

2. Голові Ради міністрів Автономної Республіки Крим, головам обласних, Київської та Севастопольської міських держадміністрацій утворити відповідні робочі групи та встановити контроль за їх діяльністю, пов'язаною із забезпеченням сплати податкових та інших надходжень у повному обсязі підприємствами, установами та організаціями, розташованими на відповідних територіях.
