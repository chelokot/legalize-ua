Про внесення змін до наказу Міністерства праці та соціальної політики України від 05.04.2006 N 104

Відповідно до постанови Кабінету Міністрів України від 06.02.2008 N 34 ( 34-2008-п ) "Про внесення зміни до деяких постанов Кабінету Міністрів України" та з метою впорядкування умов оплати праці працівників центрів соціальних служб для сім'ї, дітей та молоді НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 05.04.2006 N 104 ( z0424-06 ) "Про умови оплати праці працівників центрів соціальних служб для сім'ї, дітей та молоді", зареєстрованого в Міністерстві юстиції України 12.04.2006 за N 424/12298 (зі змінами), виклавши додатки 1-7 у новій редакції (додаються).

2. Зміни, внесені у додатки 1-6, застосовуються, починаючи з 1 лютого 2008 року, а у додаток 7 - у терміни, зазначені у цьому додатку.
