Про використання довідок за формами N 377 та 06

Стан: Чинний

Ідентифікатор: v0109500-03

Текст документа від 08.05.2003:

НАЦІОНАЛЬНИЙ БАНК УКРАЇНИ

ПОСТАНОВА

14.03.2003 N 109

Про використання довідок за формами N 377 та 06

(Витяг)

{ Із змінами, внесеними згідно з Постановою Національного банку

N 176 ( v0176500-03 ) від 08.05.2003 }

У зв'язку із затримкою погодження відповідними державними органами бланків довідок суворого обліку за формою N 377 нового зразка та формою 06 Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Дозволити уповноваженим банкам та уповноваженим фінансовим установам під час здійснення валютно-обмінних операцій у касах та пунктах обміну іноземної валюти використовувати довідки за формою N 377 старого зразка до 1 липня 2003 року. { Пункт 1 із змінами, внесеними згідно з Постановою Національного банку N 176 ( v0176500-03 ) від 08.05.2003 }

2. Встановити, що до 1 травня 2003 року замість довідок за формою 06 видаються довідки за формою 01 лише касами уповноважених банків за усними заявами фізичних осіб-резидентів під час продажу цим особам готівкової іноземної валюти 2 або 3 груп Класифікатора іноземних валют, затвердженого постановою Правління Національного банку України від 04.02.98 N 34 ( v0521500-98 ), у редакції постанови Правління Національного банку України від 02.10.2002 N 378 ( z0841-02 ) та зареєстрованого у Міністерстві юстиції України 24.10.2002 за N 841/7129.

6. Постанова набирає чинності з 16 березня 2003 року.
