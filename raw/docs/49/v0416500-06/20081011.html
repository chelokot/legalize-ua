{ Постанова втратила чинність на підставі Постанови Національного банку N 304 ( v0304500-08 ) від 03.10.2008 }

Про внесення зміни до постанови Правління Національного банку України від 29.03.2005 N 91

Відповідно до Закону України "Про банки і банківську діяльність" ( 2121-14 ) та з метою вдосконалення порядку контролю за дотриманням банками мінімального розміру регулятивного капіталу, встановленого главою 5 Положення про порядок видачі банкам банківських ліцензій, письмових дозволів та ліцензій на виконання окремих операцій, затвердженого постановою Правління Національного банку України від 17.07.2001 N 275 ( z0730-01 ) та зареєстрованого в Міністерстві юстиції України 21.08.2001 за N 730/5921 (із змінами), Правління Національного банку України ПОСТАНОВЛЯЄ:

1. У пунктах 3.1, 3.2, 3.5 і 3.7 постанови Правління Національного банку України від 29.03.2005 N 91 ( v0091500-05 ) "Про встановлення мінімального розміру регулятивного капіталу банків у гривнях" (із змінами) цифри "39696" замінити цифрами "36087".

2. Департаменту методології банківського регулювання та нагляду (Н.В.Іваненко) довести зміст цієї постанови до відома структурних підрозділів, територіальних управлінь Національного банку України, а також банків для керівництва в роботі.

3. Постанова набирає чинності з дня її підписання.

4. Контроль за виконанням цієї постанови покласти на заступника Голови В.Л.Кротюка, Департамент банківського регулювання і нагляду (В.О.Зінченко), Департамент реєстрації та ліцензування (О.І.Пархоменко) та начальників територіальних управлінь Національного банку України.

В.о. Голови А.В.Шаповалов
