05.09.2005 N 254

Зареєстровано в Міністерстві юстиції України 21 вересня 2005 р. за N 1078/11358

Про визнання наказів такими, що втратили чинність

Відповідно до Закону України "Про державну статистику" ( 2614-12 ) та з метою приведення у відповідність нормативно-правових актів до чинного законодавства НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

1.1. Наказ від 16 лютого 2004 року N 103 ( z0265-04 ) "Про затвердження форми державного статистичного спостереження N 1-ДТ (річна) "Звіт про фінансову діяльність довірчого товариства" та інструкції щодо її заповнення", зареєстрований у Міністерстві юстиції України 1 березня 2004 року за N 265/8864;

1.2. Наказ від 25 червня 1999 року N 223 ( z0522-99 ) "Про затвердження форм державної статистичної звітності із статистики фінансів та внесення змін до інструкцій щодо їх заповнення", зареєстрований у Міністерстві юстиції України 3 серпня 1999 року за N 522/3815 (із змінами).

2. Наказ набирає чинності з 1 січня 2006 року.

3. Контроль за виконанням наказу покласти на першого заступника Голови Головка В.А.
