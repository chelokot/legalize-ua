Про затвердження голів Української частини спільних міжурядових комісій з питань співробітництва

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1107-р ( 1107-2010-р ) від 19.05.2010 }

1. Затвердити:

Клюєва Андрія Петровича - Першого віце-прем'єр-міністра України головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 1;

Тігіпка Сергія Леонідовича - Віце-прем'єр-міністра України головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 2;

Тихонова Віктора Миколайовича - Віце-прем'єр-міністра України головою Української частини міжурядової українсько-ізраїльської комісії з питань торгівлі та економічного співробітництва;

Бойка Юрія Анатолійовича - Міністра палива та енергетики головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 3;

Єфименка Костянтина Олексійовича - Міністра транспорту та зв'язку головою Української частини міжурядової українсько-литовської комісії з питань торговельно-економічного та науково-технічного співробітництва;

Колєснікова Дмитра Валерійовича - Міністра промислової політики головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 4;

Цушка Василя Петровича - Міністра економіки головою Української частини спільних міжурядових комісій з питань співробітництва згідно з додатком 5;

Яцубу Володимира Григоровича - Міністра регіонального розвитку та будівництва головою Української частини спільної міжурядової українсько-таджицької комісії з питань економічного співробітництва.

2. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України згідно з переліком, що додається.

ПЕРЕЛІК розпоряджень Кабінету Міністрів України, що втратили чинність

2. Розпорядження Кабінету Міністрів України від 17 червня 2009 р. N 646 ( 646-2009-р ) "Про затвердження голови Української частини Українсько-Лівійської двосторонньої комісії із співробітництва".

3. Розпорядження Кабінету Міністрів України від 9 вересня 2009 р. N 1147 ( 1147-2009-р ) "Про затвердження Немирі Г.М. головою Української частини міжурядової українсько-китайської комісії з питань торговельно-економічного співробітництва".

4. Розпорядження Кабінету Міністрів України від 14 жовтня 2009 р. N 1223 ( 1223-2009-р ) "Про затвердження Данилишина Б.М. головою Української частини Міжурядової українсько-марокканської комісії з питань торговельно-економічного, науково-технічного та культурного співробітництва".

5. Розпорядження Кабінету Міністрів України від 29 жовтня 2009 р. N 1336 ( 1336-2009-р ) "Про затвердження Продана Ю.В. головою Української частини міжурядової українсько-молдавської змішаної комісії з питань торговельно-економічного співробітництва".
