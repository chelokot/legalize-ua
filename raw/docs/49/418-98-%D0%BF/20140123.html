Кабінет Міністрів України; Постанова від 02.04.1998 № 418

Про встановлення показників питомої ваги давальницької сировини у загальній вартості готової продукції за окремими видами операцій у зовнішньоекономічних відносинах

Стан: Втратив чинність

Ідентифікатор: 418-98-п

Текст документа від 23.01.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 квітня 1998 р. N 418 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 879 ( 879-2013-п ) від 04.12.2013 }

Про встановлення показників питомої ваги давальницької сировини у загальній вартості готової продукції за окремими видами операцій у зовнішньоекономічних відносинах

( Із змінами, внесеними згідно з Постановами КМ N 1889 ( 1889-99-п ) від 13.10.99 N 1648 ( 1648-2001-п ) від 13.12.2001 )

Відповідно до частини другої статті 7 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ) Кабінет Міністрів України постановляє:

1. Установити, що вартість давальницької сировини, яка вивозиться з митної території України для переробки у готову продукцію, що класифікується за кодами товарних груп 39, 48 і 49, 72 - 76 УКТ ЗЕД, повинна становити не менш як 80 відсотків вартості готової продукції.

Дія цього пункту не поширюється на вивезену з митної території України давальницьку сировину, митне оформлення якої здійснено до набрання чинності цією постановою та на папір для пакування жировмісних харчових продуктів, що класифікується за кодом УКТ ЗЕД 4806 20 00 00, який вивозиться з митної території України як давальницька сировина з метою виготовлення та ввезення готової продукції - паперу металізованого для харчових продуктів відповідно до коду УКТ ЗЕД 4811 90 90 00. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1889 ( 1889-99-п ) від 13.10.99 )

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )

2. Контроль за виконанням даної постанови покласти на Державну митну службу.

3. Ця постанова набирає чинності з дня її опублікування.
