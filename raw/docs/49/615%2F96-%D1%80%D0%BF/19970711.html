РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про склад Міжвідомчої комісії з питань демонополізації економіки

( Із змінами, внесеними згідно з Розпорядженнями Президента N 63/97-рп від 04.02.97 N 194/97-рп від 06.05.97 N 254/97-рп від 11.07.97 )

1. Затвердити персональний склад Міжвідомчої комісії з питань демонополізації економіки (додається).

2. Визнати такими, що втратили чинність, Розпорядження Президента України:

від 14 квітня 1995 року N 71 ( 71/95-рп ) "Про персональний склад Міжвідомчої комісії з питань демонополізації економіки";

від 26 вересня 1995 року N 248 ( 248/95-рп ) "Про внесення змін до Розпорядження Президента України від 14 квітня 1995 року N 71".
