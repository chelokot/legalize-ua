{ Постанова втратила чинність одночасно з набранням чинності Указом Президента ( 500/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Про внесення змін до постанов Кабінету Міністрів України від 5 травня 2000 р. N 758 і від 3 серпня 2000 р. N 1210

Відповідно до Указу Президента України від 5 червня 2001 р. N 405 ( 405/2001 ) "Про Міністерство промислової політики України" Кабінет Міністрів України постановляє:

1. У пункті 1 постанови Кабінету Міністрів України від 5 травня 2000 р. N 758 ( 758-2000-п ) "Про утворення Державного департаменту тракторного і сільськогосподарського машинобудування" (Офіційний вісник України, 2000 р., N 19, ст. 781) слова "Державного комітету промислової політики" замінити словами "Міністерства промислової політики".

2. У постанові Кабінету Міністрів України від 3 серпня 2000 р. N 1210 ( 1210-2000-п ) "Про затвердження Положення про Державний департамент тракторного і сільськогосподарського машинобудування" (Офіційний вісник України, 2000 р., N 32, ст. 1354):

у пункті 4 слова "Державного комітету промислової політики" замінити словами "Міністерства промислової політики";

у тексті Положення, затвердженого зазначеною постановою, слово "Держпромполітики" замінити словом "Мінпромполітики".
