Про зупинення дії розпорядження Кабінету Міністрів України від 18 червня 2008 року N 855-р

Стан: Втратив чинність

Ідентифікатор: 618/2008

Текст документа від 04.07.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії розпорядження Кабінету Міністрів України від 18 червня 2008 року N 855-р

{ Додатково див. Конституційне подання Президента ( n0022100-08 ) від 04.07.2008 }

Кабінет Міністрів України 18 червня 2008 року видав розпорядження N 855-р ( 855-2008-р ) "Про призначення Іллічова М.О. заступником Міністра внутрішніх справ України - начальником головного управління МВС України в Автономній Республіці Крим". Цим розпорядженням ( 855-2008-р ) Кабінет Міністрів України здійснив призначення заступника Міністра внутрішніх справ України - начальника головного управління МВС України в Автономній Республіці Крим.

Назване розпорядження ( 855-2008-р ) видано Кабінетом Міністрів України всупереч Конституції України ( 254к/96-ВР ).

За Конституцією України ( 254к/96-ВР ) Кабінет Міністрів України призначає на посаду та звільняє з посади за поданням Прем'єр-міністра України керівників центральних органів виконавчої влади, які не входять до складу Кабінету Міністрів України (пункт 9-2 статті 116), здійснює інші повноваження, визначені Конституцією ( 254к/96-ВР ) та законами України (пункт 10 статті 116). Законом України "Про Кабінет Міністрів України" ( 279-17 ), яким відповідно до Конституції України ( 254к/96-ВР ) визначаються повноваження Кабінету Міністрів України, до компетенції Кабінету Міністрів України віднесено призначення на посаду та звільнення з посади перших заступників і заступників міністрів (стаття 22). Реалізуючи названі повноваження, Кабінет Міністрів України зобов'язаний діяти у спосіб, що передбачений Конституцією ( 254к/96-ВР ) та законами України (частина друга статті 19 Основного Закону ( 254к/96-ВР ) держави).

За статтею 134 Конституції України ( 254к/96-ВР ) Автономна Республіка Крим є невід'ємною складовою частиною України і в межах повноважень, визначених Конституцією України ( 254к/96-ВР ), вирішує питання, віднесені до її відання. Перелік цих питань закріплено статтями 137 та 138 Конституції України ( 254к/96-ВР ). За частиною другою статті 138 Основного Закону ( 254к/96-ВР ) держави законами України Автономній Республіці Крим можуть бути делеговані також інші повноваження. Зокрема, Конституцією Автономної Республіки Крим ( rb239k002-98 ), затвердженою Законом України від 23 грудня 1998 року N 350-XIV ( 350-14 ), установлено погодження Верховною Радою Автономної Республіки Крим призначення на посаду і звільнення з посади начальника Головного управління Міністерства внутрішніх справ України в Автономній Республіці Крим (стаття 26).

Верховною Радою Автономної Республіки Крим 18 червня 2008 року відповідно до наданих Конституцією Автономної Республіки Крим ( rb239k002-98 ), затвердженою Законом N 350-XIV ( 350-14 ), повноважень ухвалено рішення N 902-5/08 ( rb0902002-08 ) про відмову в погодженні призначення Іллічова М.О. на посаду начальника Головного управління Міністерства внутрішніх справ України в Автономній Республіці Крим.

За таких обставин призначення Кабінетом Міністрів України заступника Міністра внутрішніх справ України - начальника головного управління Міністерства внутрішніх справ України в Автономній Республіці Крим без погодження з Верховною Радою Автономної Республіки Крим здійснено всупереч вищезазначеним нормам, а отже, на порушення частини третьої статті 113 Основного Закону ( 254к/96-ВР ) держави, яка зобов'язує Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України і яка за частиною третьою статті 8 Основного Закону ( 254к/96-ВР ) держави є нормою прямої дії.

Ураховуючи викладене та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 18 червня 2008 року N 855-р ( 855-2008-р ) "Про призначення Іллічова М.О. заступником Міністра внутрішніх справ України - начальником головного управління МВС України в Автономній Республіці Крим".

2. Цей Указ набирає чинності з дня опублікування.

Президент України В.ЮЩЕНКО
