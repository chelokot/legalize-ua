Про визнання такими, що втратили чинність, деяких розпоряджень Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 1001-2008-р

Текст документа від 23.07.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 липня 2008 р. N 1001-р Київ

Про визнання такими, що втратили чинність, деяких розпоряджень Кабінету Міністрів України

Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України:

від 19 квітня 2006 р. N 221 ( 221-2006-р ) "Про підготовку та проведення міжнародного медіафоруму "Україна на інформаційній карті світу";

від 28 вересня 2006 р. N 496 ( 496-2006-р ) "Про голову Організаційного комітету з підготовки та проведення міжнародного медіафоруму "Україна на інформаційній карті світу";

від 18 жовтня 2006 р. N 522 ( 522-2006-р ) "Про внесення зміни до розпорядження Кабінету Міністрів України від 19 квітня 2006 р. N 221";

від 30 травня 2007 р. N 360 ( 360-2007-р ) "Деякі питання підготовки та проведення міжнародного медіафоруму "Україна на інформаційній карті світу".
