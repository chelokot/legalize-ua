Кабінет Міністрів України; Постанова від 31.03.2003 № 411

Про голову Ради з дизайну

Стан: Втратив чинність

Ідентифікатор: 411-2003-п

Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 березня 2003 р. N 411 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

Про голову Ради з дизайну

( Із змінами, внесеними згідно з Постановою КМ N 1106 ( 1106-2003-п ) від 17.07.2003 )

Кабінет Міністрів України постановляє:

1. Установити, що головою Ради з дизайну при Кабінеті Міністрів України, створеною постановою Кабінету Міністрів України від 30 липня 1996 р. N 876 ( 876-96-п ) "Про Раду з дизайну", є за посадою перший заступник Міністра промислової політики. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1106 ( 1106-2003-п ) від 17.07.2003 )

2. Увільнити Новицького Володимира Станіславовича від обов'язків голови Ради з дизайну при Кабінеті Міністрів України.

Прем'єр-міністр України В.ЯНУКОВИЧ
