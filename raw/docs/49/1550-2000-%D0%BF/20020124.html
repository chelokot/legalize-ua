Текст документа від 24.01.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 жовтня 2000 р. N 1550 Київ

( Постанова втратила чинність на підставі Постанови КМ N 65 ( 65-2002-п ) від 24.01.2002 )

Про внесення змін до постанови Кабінету Міністрів України від 28 жовтня 1998 р. N 1707

Кабінет Міністрів України постановляє:

На часткову зміну пункту 1 постанови Кабінету Міністрів України від 28 жовтня 1998 р. N 1707 ( 1707-98-п ) затвердити склад Міжвідомчої координаційної ради з підготовки та реалізації проекту розвитку приватного сектору, що додається.

У зазначеній постанові:

у пункті 2 слова "Державний комітет з питань розвитку підприємництва" замінити словами "Державний комітет з питань регуляторної політики та підприємництва";

пункт 3 доповнити новим другим абзацом такого змісту:

"голова Ради має право вносити в разі потреби зміни до її персонального складу".
