Зареєстровано в Міністерстві юстиції України 4 серпня 2006 р. за N 937/12811

Про внесення змін до наказу Держкомстату України від 27.08.2001 N 365

Відповідно до статті 14 Закону України "Про державну статистику" ( 2614-12 ), з метою подальшого вдосконалення державних статистичних спостережень та у зв'язку з упровадженням нової форми звітності із статистики основних засобів НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Держкомстату України від 27.08.2001 N 365 ( z0799-01 ) "Про затвердження форми державної статистичної звітності із статистики основних засобів та Інструкції про порядок її складання" (у редакції наказу Держкомстату від 28.07.2003 N 235 ( z0712-03 ), зареєстрований у Міністерстві юстиції України 10.09.2001 за N 799/5990, в частині затвердження форми державної статистичної звітності N 11-ОЗ ( z0799-01 ) "Звіт про наявність та рух основних засобів, амортизацію (знос)".

2. Цей наказ набирає чинності з 1 січня 2007 року.

3. Контроль за виконанням цього наказу покласти на першого заступника Голови Головка В.А.
