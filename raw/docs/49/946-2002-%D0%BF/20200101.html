КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 липня 2002 р. N 946 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 419 ( 419-2019-п ) від 22.05.2019 }

Про внесення змін до деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Відновити дію постанови Кабінету Міністрів України від 20 липня 1996 р. N 830 ( 830-96-п ) "Про затвердження Типового положення з планування, обліку і калькулювання собівартості науково-дослідних та дослідно-конструкторських робіт" (ЗП України, 1996 р., N 15, ст. 405).

2. Внести до постанов Кабінету Міністрів України такі зміни:

1) пункт 5 переліку постанов Кабінету Міністрів України, що втратили чинність, затвердженого постановою Кабінету Міністрів України від 16 травня 2002 р. N 630 ( 630-2002-п ) (Офіційний вісник України, 2002 р., N 20, ст. 987), виключити;

2) доповнити постанову Кабінету Міністрів України від 20 липня 1996 р. N 830 ( 830-96-п ) "Про затвердження Типового положення з планування, обліку і калькулювання собівартості науково-дослідних та дослідно-конструкторських робіт" (ЗП України, 1996 р., N 15, ст. 405) пунктом 3 такого змісту:

"3. Дія цієї постанови не поширюється на госпрозрахункові підприємства і організації".

Прем'єр-міністр України А.КІНАХ
