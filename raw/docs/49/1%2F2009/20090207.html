УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії розпорядження Кабінету Міністрів України від 27 грудня 2008 року N 1599-р

{ Додатково див. Конституційне подання Президента ( n0001100-09 ) від 02.01.2009 }

Кабінетом Міністрів України 27 грудня 2008 року видано розпорядження N 1599-р ( 1599-2008-р ) "Про тимчасове покладення виконання обов'язків Голови Фонду державного майна України на Парфененка Д.М.", яким покладено тимчасово, до призначення в установленому порядку Голови Фонду державного майна України, виконання обов'язків Голови цього Фонду на заступника Голови Фонду державного майна України Парфененка Дмитра Миколайовича.

Названий акт ( 1599-2008-р ) видано Кабінетом Міністрів України всупереч Конституції України ( 254к/96-ВР ).

Відповідно до частини другої статті 6 Основного Закону держави ( 254к/96-ВР ) органи законодавчої, виконавчої та судової влади здійснюють свої повноваження у встановлених Конституцією України ( 254к/96-ВР ) межах і відповідно до законів України.

Згідно з частиною другою статті 19 Конституції України ( 254к/96-ВР ) органи державної влади зобов'язані діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України.

Відповідно до частини третьої статті 113 Конституції України ( 254к/96-ВР ) Кабінет Міністрів України у своїй діяльності керується, зокрема, Конституцією ( 254к/96-ВР ) та законами України.

За Основним Законом держави ( 254к/96-ВР ) Голова Фонду державного майна України призначається Верховною Радою України за поданням Прем'єр-міністра України (пункт 12 частини першої статті 85) ( 254к/96-ВР ).

Питання тимчасового виконання обов'язків, зокрема, Голови Фонду державного майна України до внесення змін до Конституції України ( 254к/96-ВР ) Законом України від 8 грудня 2004 року N 2222-IV ( 2222-15 ) було врегульовано Законом України "Про тимчасове виконання обов'язків посадових осіб, яких призначає на посаду за згодою Верховної Ради України Президент України або Верховна Рада України за поданням Президента України" ( 709/97-ВР ). Після внесення змін до Конституції України ( 254к/96-ВР ) питання тимчасового виконання обов'язків Голови Фонду державного майна України на законодавчому рівні не врегульовано. Згідно з абзацом другим пункту 8 Тимчасового положення про Фонд державного майна України, затвердженого Постановою Верховної Ради України від 7 липня 1992 року N 2558-XII ( 2558-12 ), у разі коли кандидат на посаду Голови Фонду державного майна України не отримав, відповідно до Конституції України ( 254к/96-ВР ), згоди Верховної Ради України на призначення на посаду Голови Фонду, повноваження Голови Фонду державного майна України тимчасово виконує перший заступник Голови Фонду державного майна України.

Конституційний Суд України наголосив на відсутності в чинному законодавстві України нормативно-правового акта, який визначив би належність Фонду державного майна України до будь-яких із гілок державної влади, зазначених у статті 6 Конституції України ( 254к/96-ВР ) (Ухвала від 17 вересня 2008 року N 46-уп/2008) ( va46u710-08 ). Це свідчить про неправомірність застосування до цього органу положень законодавства України, що стосуються центральних органів виконавчої влади, зокрема пункту 9-2 статті 116 Конституції України ( 254к/96-ВР ).

Таким чином, ні Конституція України ( 254к/96-ВР ), ні закони України не відносять до повноважень Кабінету Міністрів України вирішення питання щодо тимчасового покладення виконання обов'язків Голови Фонду державного майна України.

Тож, видавши розпорядження від 27 грудня 2008 року N 1599-р ( 1599-2008-р ) "Про тимчасове покладення виконання обов'язків Голови Фонду державного майна України на Парфененка Д.М.", Кабінет Міністрів України вийшов за межі своїх повноважень та діяв у спосіб, що не передбачені Конституцією ( 254к/96-ВР ) та законами України, чим порушив положення частини другої статті 6, частини другої статті 19 та частини третьої статті 113 Основного Закону держави ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, на підставі та у спосіб, що ними передбачені.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 27 грудня 2008 року N 1599-р ( 1599-2008-р ) "Про тимчасове покладення виконання обов'язків Голови Фонду державного майна України на Парфененка Д.М.".

2. Цей Указ набирає чинності з дня його опублікування.
