Ідентифікатор: 12-2008-п

Текст документа від 18.03.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 січня 2008 р. N 12 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 70 ( 70-2014-п ) від 12.03.2014 }

Про призначення членів наглядової ради відкритого акціонерного товариства "Державний ощадний банк України"

{ Із змінами, внесеними згідно з Постановами КМ N 648 ( 648-2008-п ) від 16.07.2008 N 613 ( 613-2009-п ) від 22.06.2009 N 659 ( 659-2009-п ) від 01.07.2009 N 304 ( 304-2010-п ) від 29.03.2010 N 359 ( 359-2010-п ) від 26.05.2010 }

З метою забезпечення належного представлення інтересів держави як єдиного акціонера відкритого акціонерного товариства "Державний ощадний банк України" у його вищому органі управління та відповідно до статті 7 Закону України "Про банки і банківську діяльність" ( 2121-14 ) Кабінет Міністрів України постановляє:

1. Призначити членами наглядової ради відкритого акціонерного товариства "Державний ощадний банк України":

КУШНІРЕНКА - керівника Апарату Прем'єр-міністра

Олександра Миколайовича України

ЛЮБЧЕНКА - першого заступника Міністра Кабінету Костянтина Валерійовича Міністрів України

РИБАКА - заступника Міністра фінансів

Сергія Олександровича

СОТУЛЕНКО - голова наглядової ради публічного

Ігор Миколайович акціонерного товариства "Державний експортно-імпортний банк України"

ХАРЧЕНКА - Голову Державного казначейства.

Сергія Івановича

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 648 ( 648-2008-п ) від 16.07.2008, N 613 ( 613-2009-п ) від 22.06.2009, N 659 ( 659-2009-п ) від 01.07.2009, N 304 ( 304-2010-п ) від 29.03.2010, N 359 ( 359-2010-п ) від 26.05.2010 }

2. Міністерству фінансів подати пропозиції щодо внесення змін до Статуту відкритого акціонерного товариства "Державний ощадний банк України".
