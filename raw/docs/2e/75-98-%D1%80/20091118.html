Кабінет Міністрів України; Розпорядження від 14.02.1998 № 75-р

Про віднесення посад членів Центральної виборчої комісії та працівників секретаріату Комісії до категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 75-98-р

Текст документа від 18.11.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 лютого 1998 р. N 75-р Київ

Про віднесення посад членів Центральної виборчої комісії та працівників секретаріату Комісії до категорій посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 1120-р ( 1120-99-р ) від 22.10.99 N 784-р ( 784-2004-р ) від 28.10.2004 N 736-р ( 736-2008-р ) від 21.05.2008 N 1378-р ( 1378-2009-р ) від 18.11.2009 }

1. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади членів Центральної виборчої комісії працівників секретаріату та патронатної служби Комісії до таких категорій посад державних службовців: { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 784-р ( 784-2004-р ) від 28.10.2004 }

перша категорія - посади Голови, заступників Голови, секретаря, членів Центральної виборчої комісії; { Абзац другий пункту 1 із змінами, внесеними згідно з Розпорядженнями КМ N 784-р ( 784-2004-р ) від 28.10.2004, N 1378-р ( 1378-2009-р ) від 18.11.2009 }

друга категорія - посади радників, помічників Голови Центральної виборчої комісії, прес-секретаря, начальників управлінь, завідуючих самостійними відділами секретаріату Центральної виборчої комісії; { Абзац третій пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 1120-р ( 1120-99-р ) від 22.10.99 }

третя категорія - посади помічників заступників Голови, секретаря і членів Центральної виборчої комісії, заступників начальників управлінь, заступників завідуючих самостійними відділами, завідуючих відділами у складі управлінь, завідуючих секторами, головних спеціалістів, головних консультантів; { Абзац четвертий пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 736-р ( 736-2008-р ) від 21.05.2008 }

четверта категорія - посади спеціалістів;

п'ята категорія - посади секретарів, які входять до складу патронатної служби Комісії. { Пункт 1 доповнено абзацом згідно з Розпорядженням КМ N 784-р ( 784-2004-р ) від 28.10.2004 }

2. Визнати таким, що втратило чинність розпорядження Кабінету Міністрів України від 28 квітня 1994 р. N 291 ( 291-94-р ).
