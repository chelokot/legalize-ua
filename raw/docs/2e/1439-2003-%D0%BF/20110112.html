Кабінет Міністрів України; Постанова, Перелік від 10.09.2003 № 1439

Про внесення змін та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань застосування спеціального торгового патенту

Стан: Чинний

Ідентифікатор: 1439-2003-п

Текст документа від 12.01.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 вересня 2003 р. N 1439 Київ

Про внесення змін та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань застосування спеціального торгового патенту

{ Із змінами, внесеними згідно з Постановою КМ N 1236 ( 1236-2010-п ) від 27.12.2010 }

Відповідно до розділу XIV Закону України "Про внесення змін до Закону України "Про Державний бюджет України на 2003 рік" та деяких інших законодавчих актів" ( 849-15 ) Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 1236 ( 1236-2010-п ) від 27.12.2010 }

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

3. Надміру сплачені на день набрання чинності цією постановою суми вартості спеціального торгового патенту підлягають поверненню в установленому порядку суб'єкту підприємницької діяльності, а сам патент - органу державної податкової служби, що його видав.

4. Ця постанова набирає чинності з 1 жовтня 2003 року.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 34

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 10 вересня 2003 р. N 1439

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 18 травня 1998 р. N 688 ( 688-98-п ) "Про затвердження Порядку ведення бухгалтерського обліку суб'єктами підприємницької діяльності, які придбали спеціальний торговий патент" (Офіційний вісник України, 1998 р., N 20, ст. 730).

2. Постанова Кабінету Міністрів України від 4 червня 1998 р. N 801 ( 801-98-п ) "Про затвердження Порядку зарахування коштів, одержаних від продажу спеціальних торгових патентів" (Офіційний вісник України, 1998 р., N 23, ст. 824).

3. Постанова Кабінету Міністрів України від 8 червня 1998 р. N 826 ( 826-98-п ) "Про затвердження переліку територій, на яких у порядку експерименту застосовується спеціальний торговий патент" (Офіційний вісник України, 1998 р., N 23, ст. 833).

4. Постанова Кабінету Міністрів України від 23 червня 1998 р. N 950 ( 950-98-п ) "Про внесення доповнення до постанови Кабінету Міністрів України від 8 червня 1998 р. N 826" (Офіційний вісник України, 1998 р., N 25, ст. 928).

5. Постанова Кабінету Міністрів України від 1 липня 1998 р. N 994 ( 994-98-п ) "Про доповнення переліку територій, на яких у порядку експерименту застосовується спеціальний торговий патент" (Офіційний вісник України, 1998 р., N 26, ст. 955).

6. Постанова Кабінету Міністрів України від 25 серпня 1998 р. N 1332 ( 1332-98-п ) "Про доповнення переліку територій, на яких у порядку експерименту застосовується спеціальний торговий патент" (Офіційний вісник України, 1998 р., N 34, ст. 1278).

7. Постанова Кабінету Міністрів України від 22 жовтня 1999 р. N 1957 ( 1957-99-п ) "Про доповнення переліку територій, на яких у порядку експерименту застосовується спеціальний торговий патент" (Офіційний вісник України, 1999 р., N 43, ст. 2140).

8. Постанова Кабінету Міністрів України від 25 листопада 1999 р. N 2143 ( 2143-99-п ) "Про внесення змін до Порядку зарахування коштів, одержаних від продажу спеціальних торгових патентів" (Офіційний вісник України, 2000 р., N 6, ст. 209).

9. Постанова Кабінету Міністрів України від 6 травня 2001 р. N 471 ( 471-2001-п ) "Про доповнення переліку територій, на яких у порядку експерименту застосовується спеціальний торговий патент" (Офіційний вісник України, 2001 р., N 20, ст. 863).

10. Постанова Кабінету Міністрів України від 1 червня 2002 р. N 735 ( 735-2002-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 6 травня 2001 р. N 471" (Офіційний вісник України, 2002 р., N 23, ст. 1108).
