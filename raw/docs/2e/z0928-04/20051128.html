Про затвердження переліків отруйних та сильнодіючих лікарських засобів

{ Із змінами, внесеними згідно з Наказами Міністерства охорони здоров'я N 440 ( z1166-04 ) від 02.09.2004 N 360 ( z0782-05 ) від 19.07.2005 }

{ Щодо змін додатково див. Наказ Міністерства охорони здоров'я N 644 ( v0644282-05 ) від 28.11.2005 }

На виконання статті 2 Закону України "Про лікарські засоби" ( 123/96-ВР ) (із змінами) та з метою упорядкування обігу отруйних та сильнодіючих лікарських засобів НАКАЗУЮ:

1. Затвердити Перелік отруйних лікарських засобів (додається).

2. Затвердити Перелік сильнодіючих лікарських засобів (додається) ( z0929-04 ).

3. Вважати такими, що втратили чинність:

- Перелік отруйних лікарських засобів, які зареєстровані та дозволені до використання, затверджений наказом МОЗ України від 18.08.95 N 153 ( z0363-95 ), зареєстрованим у Мін'юсті України 06.10.95 за N 363/899, із змінами і доповненнями;

( Абзац другий пунтку 3 втратив чинність на підставі Наказу Міністерства охорони здоров'я N 360 ( z0782-05 ) від 19.07.2005 )

4. Затвердити Перелік лікарських засобів за міжнародними непатентованими назвами, які підлягають предметно-кількісному обліку в закладах охорони здоров'я, що додається.

( Пункт 4 в редакції Наказу Міністерства охорони здоров'я N 440 ( z1166-04 ) від 02.09.2004 )

5. Державній службі лікарських засобів і виробів медичного призначення, Державній інспекції з контролю якості лікарських засобів, ДП "Державний фармакологічний центр МОЗ України" у тримісячний термін внести пропозиції щодо приведення нормативних актів МОЗ у відповідність до цього наказу.

6. Державній службі лікарських засобів і виробів медичного призначення забезпечити в установленому порядку реєстрацію наказу у Міністерстві юстиції України.

7. Контроль за виконанням наказу покласти на заступника Міністра - голову Державної служби лікарських засобів і виробів медичного призначення Пасічника М.Ф.

В.о. Міністра О.М.Орда
