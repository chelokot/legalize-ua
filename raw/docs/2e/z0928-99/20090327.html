Національний банк; Постанова від 30.11.1999 № 573

Про затвердження Змін до Положення про застосування Національним банком України заходів впливу до комерційних банків за порушення банківського законодавства

Реєстрація: Мін'юст України від 31.12.1999 № 928/4221

Стан: Втратив чинність

Ідентифікатор: z0928-99

Текст документа від 27.03.2009:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 573 від 30.11.99 Зареєстровано в Міністерстві м.Київ юстиції України 31 грудня 1999 р. vd991130 vn573 за N 928/4221

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про затвердження Змін до Положення про застосування Національним банком України заходів впливу до комерційних банків за порушення банківського законодавства

{ Із змінами, внесеними згідно з Постановами Нацбанку N 215 ( z0381-00 ) від 26.05.2000 N 244 ( z0586-01 ) від 27.06.2001 }

З метою удосконалення системи заходів впливу до комерційних банків за порушення банківського законодавства та у зв'язку з прийняттям Закону України "Про Національний банк України" ( 679-14 ) Правління ПОСТАНОВЛЯЄ:

( Пункт 1 втратив чинність на підставі Постанови Нацбанку N 215 ( z0381-00 ) від 26.05.2000 )

2. Департаменту пруденційного нагляду (В.О.Зінченко) протягом десяти робочих днів після набуття постановою чинності внести відповідні зміни до Положення про Комісію Національного банку України з питань нагляду та регулювання діяльності банків, затвердженого постановою Правління Національного банку України від 09.11.98 N 470 ( v0470500-98 ).

( Пункт 3 втратив чинність на підставі Постанови Нацбанку N 244 ( z0586-01 ) від 27.06.2001 )

4. Постанова набуває чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

5. Довести цю постанову після державної реєстрації в Міністерстві юстиції України до відома самостійних структурних підрозділів Національного банку України, Кримського республіканського, територіальних та по м.Києву і Київській області управлінь Національного банку України, а також комерційних банків для керівництва і використання в роботі.

6. Контроль за виконанням цієї постанови покласти на заступника Голови Правління Національного банку України О.І.Кірєєва, Департамент пруденційного нагляду (В.О.Зінченко), Управління реєстрації та ліцензування банків (О.І.Пархоменко), Управління нагляду за великими банками (Ю.О.Герасименко), Управління з питань роботи з проблемними банками (В.І.Ревун) та начальників Кримського республіканського, територіальних та по м.Києву і Київській області управлінь Національного банку України.

Голова В.А.Ющенко

( Зміни до Положення про застосування Національним банком України заходів впливу до комерційних банків за порушення банківського законодавства ( z0177-98 ) втратили чинність на підставі Постанови Нацбанку N 215 ( z0381-00 ) від 26.05.2000 )
