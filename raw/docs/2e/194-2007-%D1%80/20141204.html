{ Розпорядження втратило чинність на підставі Постанови КМ N 673 ( 673-2014-п ) від 26.11.2014 }

Про відновлення дії розпорядження Кабінету Міністрів України від 19 січня 2005 р. N 15

Відновити дію розпорядження Кабінету Міністрів України від 19 січня 2005 р. N 15 ( 15-2005-р ).

У зв'язку з цим визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 28 лютого 2005 р. N 42 ( 42-2005-р ) "Про скасування розпорядження Кабінету Міністрів України від 19 січня 2005 р. N 15".
