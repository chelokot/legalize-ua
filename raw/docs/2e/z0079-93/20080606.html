Про затвердження Інструкції про порядок установлення лімітів використання рибних ресурсів загальнодержавного значення

Реєстрація: Мін'юст України від 01.07.1993 № 79

Стан: Втратив чинність

Ідентифікатор: z0079-93

Текст документа від 06.06.2008:

МІНІСТЕРСТВО ОХОРОНИ НАВКОЛИШНЬОГО ПРИРОДНОГО СЕРЕДОВИЩА УКРАЇНИ

НАКАЗ

N 52 від 18.06.93 Зареєстровано в Міністерстві м.Київ юстиції України 1 липня 1993 р. за N 79

{ Наказ втратив чинність на підставі Наказу Міністерства охорони навколишнього природного середовища N 241 ( z0459-08 ) від 12.05.2008 }

Про затвердження Інструкції про порядок установлення лімітів використання рибних ресурсів загальнодержавного значення

( Із змінами, внесеними згідно з Наказом Міністерства охорони навколишнього природного середовища та ядерної безпеки N 53/69 ( z0314-95 ) від 06.06.95 )

Відповідно до Законів України "Про охорону навколишнього природного середовища" ( 1264-12 ), "Про тваринний світ" ( 3041-12 ), на виконання постанови Кабінету Міністрів України від 10 серпня 1992 року N 459 ( 459-92-п ) "Про порядок видачі дозволів на спеціальне використання природних ресурсів і встановлення лімітів використання ресурсів республіканського значення" НАКАЗУЮ:

1. Затвердити погоджену з Міністерством економіки України і Державним комітетом України по рибному господарству і рибній промисловості Інструкцію про порядок установлення лімітів використання рибних ресурсів загальнодержавного значення, що додається.

2. Секретаріату (Михайлов С.Н.) довести інструкцію до заінтересованих міністерств, інших органів державної виконавчої влади, держуправлінь охорони навколишнього природного середовища по Республіці Крим, областях, містах Києву і Севастополю, державних інспекцій охорони Чорного та Азовського морів, Головної державної інспекції екологічного контролю.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Шевчука В.Я.

Міністр Ю.Костенко

( Інструкція про порядок установлення лімітів використання рибних ресурсів загальнодержавного значення втратила чинність на підставі Наказу Міністерства охорони навколишнього природного середовища та ядерної безпеки N 53/69 ( z0314-95 ) від 06.06.95 )
