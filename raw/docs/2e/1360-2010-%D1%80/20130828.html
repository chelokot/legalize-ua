Про віднесення деяких посад працівників Апарату Верховної Ради України до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 1360-2010-р

Текст документа від 28.08.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 липня 2010 р. N 1360-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 663-р ( 663-2013-р ) від 28.08.2013 }

Про віднесення деяких посад працівників Апарату Верховної Ради України до відповідних категорій посад державних службовців

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Апарату Верховної Ради України до таких категорій посад державних службовців:

перша категорія - посади першого заступника Керівника Апарату Верховної Ради України - Керуючого справами, заступника Керівника Апарату Верховної Ради України;

друга категорія - посада першого заступника Керуючого справами Апарату Верховної Ради України.

Прем'єр-міністр України М.АЗАРОВ
