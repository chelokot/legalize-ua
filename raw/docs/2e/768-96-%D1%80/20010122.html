Кабінет Міністрів України; Розпорядження від 02.12.1996 № 768-р

Про міжвідомчу робочу групу для координації робіт з підготовки проекту реабілітації Криворізької теплової електростанції

Стан: Втратив чинність

Ідентифікатор: 768-96-р

Текст документа від 22.01.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 грудня 1996 р. N 768-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 34 ( 34-2001-п ) від 22.01.2001 )

1. Відповідно до постанови Кабінету Міністрів України від 18 квітня 1996 р. N 440 ( 440-96-п ) "Про порядок підготовки та реалізації проектів розвитку економіки України, що підтримуються Міжнародним банком реконструкції та розвитку" утворити міжвідомчу робочу групу для координації робіт з підготовки проекту реабілітації Криворізької теплової електростанції у складі згідно з додатком.

Дозволити голові міжвідомчої робочої групи вносити зміни до її персонального складу.

2. Рішення міжвідомчої робочої групи для координації робіт з підготовки проекту реабілітації Криворізької теплової електростанції, прийняті в межах її компетенції, є обов'язковими для учасників проекту і доводяться до виконавців у вигляді протоколів засідань групи.

Прем'єр-міністр України П.ЛАЗАРЕНКО

Інд. 62

Додаток до розпорядження Кабінету Міністрів України від 2 грудня 1996 р. N 768-р

СКЛАД міжвідомчої робочої групи для координації робіт з підготовки проекту реабілітації Криворізької теплової електростанції

КУЗЬМЕНКО - заступник Міністра енергетики та Сергій Олександрович електрифікації (голова робочої групи)

БОРИСОВ - заступник начальника управління Микола Андрійович інвестицій та іноземних кредитів Міненерго (відповідальний секретар робочої групи)

ЄРМАКОВ - начальник управління проектів Владислав Кузьмич міжнародних фінансових організацій Національного агентства з реконструкції та розвитку

КОЗЛОВ - головний спеціаліст Управління з Володимир Олександрович питань паливно-енергетичного комплексу Кабінету Міністрів України

КОЛОСОВА - начальник відділу по зв'язках із Вікторія Павлівна Світовим банком управління зв'язків з міжнародними організаціями Мінфіну

ЛИТВИНЕНКО - начальник відділу координації Микола Миколайович виробничої діяльності Мінмашпрому

ПАРХОМЕНКО - начальник відділу економіки Віктор Петрович енергетики та енергозбереження Мінекономіки

ТЕРЯЄВА - головний спеціаліст Відділу Раїса Гаврилівна взаємодії з міжнародними фінансовими організаціями, іноземних інвестицій та вільних економічних зон Кабінету Міністрів України

ШОВКАЛЮК - начальник відділу іноземних Віктор Степанович інвестицій та кредитів Мінекономіки
