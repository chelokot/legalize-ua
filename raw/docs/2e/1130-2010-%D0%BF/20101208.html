КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 грудня 2010 р. N 1130 Київ

Про затвердження Порядку використання у 2010 році коштів, передбачених у державному бюджеті для розроблення техніко-економічних обґрунтувань національних проектів

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2010 році коштів, передбачених у державному бюджеті ( 2154-17 ) для розроблення техніко-економічних обґрунтувань національних проектів, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 42

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 8 грудня 2010 р. N 1130

ПОРЯДОК використання у 2010 році коштів, передбачених у державному бюджеті ( 2154-17 ) для розроблення техніко-економічних обґрунтувань національних проектів

1. Цей Порядок визначає механізм використання у 2010 році коштів, передбачених у державному бюджеті ( 2154-17 ) за програмою "Розробка техніко-економічних обґрунтувань національних проектів" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Укрнацпроект.

3. Бюджетні кошти використовуються для розроблення техніко-економічних обґрунтувань національних проектів за процедурою, що передбачає спрямування:

головним розпорядником бюджетних коштів - державним підприємствам, які належать до сфери управління Укрнацпроекту і утворені з метою забезпечення реалізації національних проектів, для поповнення їх статутних фондів;

державними підприємствами - отриманих коштів у повному обсязі виключно на забезпечення розроблення техніко-економічних обґрунтувань національних проектів.

4. Перелік державних підприємств, визначених пунктом 3 цього Порядку, встановлюється Укрнацпроектом.

5. Для здійснення операцій, передбачених у пункті 3 цього Порядку, державні підприємства відкривають за своїм місцезнаходженням в органах Державного казначейства балансовий рахунок 3712 "Рахунки інших клієнтів Державного казначейства".

6. Закупівля послуг з розроблення техніко-економічних обґрунтувань національних проектів проводиться в установленому законодавством порядку.

7. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
