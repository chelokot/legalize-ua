N 185 від 20.12.95 Зареєстровано в Міністерстві м.Київ юстиції України 21 грудня 1995 р. vd951220 vn185 за N 470/1006

{ Наказ втратив чинність на підставі Наказу Міністерства економічного розвитку і торгівлі N 433 ( z0804-13 ) від 29.04.2013 }

Про рівень роздрібних цін на газ сітьовий, вугілля та вугільні брикети

( Із змінами, внесеними згідно з Наказами Мінекономіки N 75 ( z0307-96 ) від 14.06.96 N 101 ( z0398-96 ) від 26.07.96 )

З метою подальшого відшкодування витрат, пов'язаних з реалізацією енергоносіїв населенню, та згідно з повноваженнями, затвердженими постановою Кабінету Міністрів України від 13.02.95 N 109 ( 109-95-п ) "Про уточнення повноважень центральних органів державної виконавчої влади, Уряду Автономної Республіки Крим та виконкомів місцевих Рад у галузі ціноутворення", НАКАЗУЮ:

1. Затвердити граничні розміри роздрібних цін на енергоносії, що відпускаються на комунально-побутові потреби населення (додаються).

2. Вважати такими, що втратили чинність, граничні розміри роздрібних цін на газ сітьовий, вугілля та вугільні брикети, затверджені наказом Мінекономіки України від 14.08.95 р. N 135 ( z0307-95 ).

Міністр В.М.Гуреєв

Затверджено наказом Мінекономіки України від 20 грудня 1995 року N 185

Граничні розміри роздрібних цін на газ сітьовий, вугілля та вугільні брикети для населення, крб.
