ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

19.07.2006 N 337

Зареєстровано в Міністерстві юстиції України 23 серпня 2006 р. за N 1008/12882

Про затвердження інструкцій щодо заповнення форм державних статистичних спостережень N 4-нт і N 7-нт (ліцензії)

{ Із змінами, внесеними згідно з Наказом Державного комітету статистики N 306 ( z1035-07 ) від 20.08.2007 }

Відповідно до статей 4, 14, 18 Закону України "Про державну статистику" ( 2614-12 ), ураховуючи положення статей 80, 81 Цивільного кодексу України ( 435-15 ), з метою отримання повної, всебічної та об'єктивної статистичної інформації та подальшого вдосконалення державних статистичних спостережень зі статистики науки та інновацій НАКАЗУЮ:

1. Затвердити інструкції щодо заповнення форм державних статистичних спостережень (додаються) і ввести їх у дію, починаючи зі звіту за 2006 рік:

1.1. N 4-нт "Звіт про набуття прав інтелектуальної власності та використання об'єктів права інтелектуальної власності", річна.

1.2. N 7-нт (ліцензії) "Звіт про укладання договорів стосовно розпоряджання майновими правами інтелектуальної власності", річна ( z1009-06 ).

2. Респондентам при заповненні форм державних статистичних спостережень N 4-нт та N 7-нт (ліцензії) використовувати інструкції, затверджені цим наказом.

3. Департаменту статистики послуг (Калачова І.В.) визначити необхідний тираж, підготувати і передати для виготовлення адміністративно-господарському департаменту (Царський В.І.) оригінали інструкцій щодо заповнення форм державних статистичних спостережень, затверджених цим наказом.

4. Департаменту фінансового забезпечення, бухгалтерського обліку та звітності (Кучіна І.Ю.) забезпечити фінансування послуг з виготовлення та доставки інструкцій щодо заповнення форм державних статистичних спостережень, затверджених цим наказом.

5. Адміністративно-господарському департаменту (Царський В.І.) забезпечити контроль за своєчасним виготовленням та доставкою інструкцій щодо заповнення форм державної статистичної звітності, затверджених цим наказом, на адресу головних управлінь статистики в Автономній Республіці Крим, областях, місті Києві та Управління статистики в місті Севастополі.

6. Визнати таким, що втратив чинність, наказ Держкомстату України від 14.10.2004 N 558 ( z1377-04 ) "Про затвердження форм державних статистичних спостережень із статистики науки й інновацій та Інструкцій щодо їх складання", зареєстрований в Міністерстві юстиції України 27.10.2004 за N 1377/9976, у частині затвердження форм державних статистичних спостережень N 4-нт "Звіт про набуття прав інтелектуальної власності та використання об'єктів права інтелектуальної власності" ( z1378-04 ) і N 7-нт (ліцензії) "Звіт про укладання договорів стосовно розпоряджання майновими правами інтелектуальної власності" ( z1379-04 ) та інструкцій щодо їх заповнення.

7. Контроль за виконанням цього наказу покласти на заступника Голови Власенко Н.С.

Голова О.Г.Осауленко
