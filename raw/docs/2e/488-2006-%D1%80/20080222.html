Кабінет Міністрів України; Розпорядження, Склад колегіального органу від 15.09.2006 № 488-р

Про зміни складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів загальнообов'язкового державного соціального страхування

Стан: Втратив чинність

Ідентифікатор: 488-2006-р

Текст документа від 22.02.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 вересня 2006 р. N 488-р Київ

Про зміни складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів загальнообов'язкового державного соціального страхування

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 59-р ( 59-2007-р ) від 21.02.2007 N 347-р ( 347-2007-р ) від 26.05.2007 N 996-р ( 996-2007-р ) від 14.11.2007 N 318-р ( 318-2008-р ) від 22.02.2008 }

1. Ввести до складу осіб, уповноважених представляти інтереси держави у наглядовій раді Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття, затвердженого розпорядженням Кабінету Міністрів України від 28 березня 2005 р. N 70 ( 70-2005-р ) (Офіційний вісник України, 2005 р., N 13, ст. 672, N 52, ст. 3346), Папієва Михайла Миколайовича - Міністра праці та соціальної політики, Рибака Сергія Олександровича - заступника Міністра фінансів, вивівши з його складу Саханя Івана Яковича і Матвійчука Володимира Макаровича.

{ Пункт 1 втратив чинність на підставі Розпорядження КМ N 59-р ( 59-2007-р ) від 21.02.2007; дію пункту 1 відновлено згідно з Розпорядженням КМ N 347-р ( 347-2007-р ) від 26.05.2007 }

{ Пункт 2 втратив чинність на підставі Розпорядження КМ N 996-р ( 996-2007-р ) від 14.11.2007 }

3. Затвердити склад осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду соціального страхування від нещасних випадків на виробництві та професійних захворювань, згідно з додатком.

У зв'язку з цим визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 23 квітня 2005 р. N 120 ( 120-2005-р ) "Про затвердження складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду соціального страхування від нещасних випадків на виробництві та професійних захворювань" (Офіційний вісник України, 2005 р., N 17, ст. 908);

розпорядження Кабінету Міністрів України від 27 квітня 2006 р. N 252 ( 252-2006-р ) "Про зміну складу осіб, уповноважених представляти інтереси держави у правлінні та наглядовій раді Фонду соціального страхування від нещасних випадків на виробництві та професійних захворювань" (Офіційний вісник України, 2006 р., N 18, ст. 1356).
