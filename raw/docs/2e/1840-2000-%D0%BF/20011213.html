Кабінет Міністрів України; Постанова від 13.12.2000 № 1840

Про внесення зміни до пункту 3 постанови Кабінету Міністрів України від 27 серпня 1996 р. N 1010

Стан: Втратив чинність

Ідентифікатор: 1840-2000-п

Текст документа від 13.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 грудня 2000 р. N 1840 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1652 ( 1652-2001-п ) від 13.12.2001 )

Про внесення зміни до пункту 3 постанови Кабінету Міністрів України від 27 серпня 1996 р. N 1010

Кабінет Міністрів України постановляє:

Пункт 3 постанови Кабінету Міністрів України від 27 серпня 1996 р. N 1010 ( 1010-96-п ) "Про вдосконалення порядку ввезення (пересилання) громадянами предметів (товарів) в Україну" (ЗП України, 1996 р., N 17, ст. 465; Офіційний вісник України, 1998 р., N 3, ст. 99, N 27, ст. 992) доповнити абзацом такого змісту:

"сільськогосподарську продукцію, отриману громадянами-резидентами як натуральна плата за виконану роботу в країнах - учасницях СНД, з якими Україна уклала угоди про вільну торгівлю".

Прем'єр-міністр України В.ЮЩЕНКО
