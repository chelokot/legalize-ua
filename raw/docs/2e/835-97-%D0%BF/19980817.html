КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 серпня 1997 р. N 835 Київ

Про переліки санаторно-курортних закладів і закладів відпочинку, операції з продажу путівок до яких на санаторно-курортне лікування та відпочинок дітей не підлягають обкладенню податком на додану вартість

( Із змінами, внесеними згідно з Розпорядженнями КМ N 662-р ( 662-97-р ) від 24.11.97 N 129-р ( 129-98-р ) від 02.03.98 N 414-р ( 414-98-р ) від 16.06.98 N 456-р ( 456-98-р ) від 27.06.98 N 553-р ( 553-98-р ) від 10.07.98 N 676-р ( 676-98-р ) від 17.08.98 )

Відповідно до статті 5 Закону України "Про податок на додану вартість" ( 168/97-ВР ) і з метою здешевлення вартості путівок на санаторно-курортне лікування та відпочинок дітей Кабінет Міністрів України постановляє:

Затвердити переліки санаторно-курортних закладів, закладів відпочинку загальнодержавного значення та закладів відпочинку за типами, операції з продажу путівок до яких на санаторно-курортне лікування та відпочинок дітей не підлягають обкладенню податком на додану вартість (додаються).
