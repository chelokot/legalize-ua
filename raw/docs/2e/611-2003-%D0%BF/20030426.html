Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 611-2003-п

Текст документа від 26.04.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 квітня 2003 р. N 611 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 16 вересня 2002 р. N 539 ( 539-2002-р ) "Про утворення Урядової комісії з реформування та розвитку Збройних Сил України, інших військових формувань, озброєння та військової техніки";

постанову Кабінету Міністрів України від 5 листопада 2002 р. N 1665 ( 1665-2002-п ) "Про затвердження Положення про Урядову комісію з реформування та розвитку Збройних Сил України, інших військових формувань, озброєння та військової техніки".

Прем'єр-міністр України В.ЯНУКОВИЧ
