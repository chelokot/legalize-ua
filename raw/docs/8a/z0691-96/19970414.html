( Наказ втратив чинність на підставі Наказу Держкомзв'язку N 52/30 ( z0028-98 ) від 19.12.97 )

Про затвердження ставок плати за використання радіочастот на 1996-1997 роки

( Із змінами, внесеними згідно з Наказом Мінзв'язку N 8/4 ( z0130-97 ) від 20.01.97 )

Відповідно до п.1 постанови Кабінету Міністрів України від 17.09.96 р. N 1135 ( 1135-96-п ) "Про вдосконалення механізму використання радіочастотного ресурсу" НАКАЗУЄМО:

1. Затвердити ставки плати за використання радіочастот на 1996-1997 роки (додаток).

2. Затверджені ставки плати за використання радіочастот на 1996-1997 роки ввести в дію через 10 днів після державної реєстрації у Мінюсті України.

3. Установити, що щорічна ставка плати за використання радіочастот вноситься користувачами щомісячно рівними частинами до 15 числа місяця, що настає за звітним, і надходить до Державного бюджету України на розділ 12, параграф 25, символ 62.

4. Ставки плати за використання радіочастот визначаються та затверджуються щорічно до 25 грудня.

5. Першому заступнику Міністра зв'язку - голові Міжвідомчої комісії з питань ліцензування використання радіочастот - Гнелецькому О.О. забезпечити контроль за надходженням коштів за використання радіочастот до бюджету та за виконанням цього наказу.

Міністр зв'язку України Д.А.Худолій

Перший заступник Начальника Головного Управління з питань радіочастот при Кабінеті Міністрів України О.Т.Сітало

Примітки: 1. За радіочастоти, які використовуються для задоволення потреб населення сільської місцевості, плата стягується у розмірі 10 відсотків від встановленої ставки плати.

2. Користувачі, що утримуються за рахунок бюджету, сплачують плату за використання радіочастот у розмірі 10% від затвердженої ставки плати залежно від виду застосування РЕЗ за умов надання довідки про фінансування з бюджету.

( Пункт 2 Приміток в редакції Наказу Мінзв'язку N 8/4 ( z0130-97 ) від 20.01.97 )

3. Оплаті підлягає кожний МГц смуги частот всіх видів зв'язку, що використовується в Автономній Республіці Крим, кожній області, містах Києві та Севастополі.

( Примітки доповнено пунктом 3 згідно з Наказом Мінзв'язку N 8/4 ( z0130-97 ) від 20.01.97 )

4. При застосуванні радіоелектронних засобів для аматорського зв'язку школярі, інваліди дитинства, інваліди війни звільняються від плати за умов надання відповідної довідки.

( Примітки доповнено пунктом 4 згідно з Наказом Мінзв'язку N 8/4 ( z0130-97 ) від 20.01.97 )

5. За використання радіоелектронних засобів зв'язку для охорони та рятування життя людини (швидка та невідкладна медична допомога Міністерства охорони здоров'я; протипожежна допомога; аварійна та аварійно-рятувальна служба всіх видів; терміновий зв'язок на рухомому наземному, підземному, морському, повітряному транспорті) плата не стягується.

( Примітки доповнено пунктом 5 згідно з Наказом Мінзв'язку N 8/4 ( z0130-97 ) від 20.01.97 )
