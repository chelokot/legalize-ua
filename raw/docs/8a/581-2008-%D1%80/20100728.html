Кабінет Міністрів України; Розпорядження від 09.04.2008 № 581-р

Про проведення у 2020 році Всеукраїнського перепису населення

Стан: Втратив чинність

Ідентифікатор: 581-2008-р

Текст документа від 28.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 квітня 2008 р. N 581-р Київ

Про проведення у 2012 році Всеукраїнського перепису населення

{ Назва Розпорядження в редакції Розпорядження КМ N 1565-р ( 1565-2010-р ) від 28.07.2010 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1565-р ( 1565-2010-р ) від 28.07.2010 }

1. Прийняти пропозицію Держкомстату щодо проведення у 2012 році Всеукраїнського перепису населення.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 1565-р ( 1565-2010-р ) від 28.07.2010 }

2. Провести у 2010 році пробний перепис населення з метою відпрацювання програми Всеукраїнського перепису населення, його методологічних та організаційних питань, технології автоматизованого оброблення отриманих матеріалів та підбиття підсумків.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 1565-р ( 1565-2010-р ) від 28.07.2010 }

3. Визначити Держкомстат відповідальним за підготовку і проведення пробного та Всеукраїнського перепису населення, оброблення, узагальнення і поширення його результатів.

4. Держкомстату підготувати та внести проекти актів Кабінету Міністрів України з питань організації і проведення пробного та Всеукраїнського перепису населення.

5. Мінпраці за пропозицією Держкомстату та за погодженням з Мінфіном затвердити до 1 червня 2008 р. умови оплати праці осіб, що залучатимуться до виконання робіт з підготовки і проведення пробного та Всеукраїнського перепису населення, оброблення, узагальнення і поширення його результатів ( z0860-08 ).

Прем'єр-міністр України Ю.ТИМОШЕНКО
