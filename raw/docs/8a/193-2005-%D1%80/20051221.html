КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 червня 2005 р. N 193-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

Про утворення міжвідомчої робочої групи для координації дій із забезпечення стабільної господарської діяльності ВАТ "Криворіжсталь"

Утворити міжвідомчу робочу групу для координації дій із забезпечення стабільної господарської діяльності ВАТ "Криворіжсталь" у складі згідно з додатком.

Контроль за роботою міжвідомчої робочої групи покласти на Першого віце-прем'єр-міністра України Кінаха А.К.
