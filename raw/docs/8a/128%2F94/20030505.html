Про військову форму одягу військовослужбовців Збройних Сил та інших військових формувань України

Стан: Втратив чинність

Текст документа від 05.05.2003:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 390/2003 ( 390/2003 ) від 05.05.2003 )

Про військову форму одягу військовослужбовців Збройних Сил та інших військових формувань України

( Зміни в текст не внесено. Додатково див. Указ Президента N 453/96 від 20.06.96 )

( Із змінами, внесеними згідно з Указом Президента N 70/99 від 27.01.99 )

( Указ втратив чинність в частині, що стосується військової форми одягу військовослужбовців Національної гвардії України на підставі Указу Президента N 228/2000 від 11.02.2000 )

Відповідно до статті 7 Закону України "Про загальний військовий обов'язок і військову службу" ( 2232-12 ) постановляю:

1. Затвердити військову форму одягу військовослужбовців Збройних Сил України, Національної гвардії України, Служби безпеки України, Прикордонних військ України, Цивільної оборони України, Управління державної охорони та інших військових формувань, створених відповідно до законів України, зразки (малюнки) та описи якої додаються. (Додано до оригіналу). ( Частина перша статті 1 із змінами, внесеними згідно з Указом Президента N 70/99 від 27.01.99 )

Перехід на нову форму одягу військовослужбовців здійснити в 1994-1995 роках у міру її виготовлення.

2. Міністру оборони України, Командуючому Національною гвардією України, Голові Служби безпеки України, Командуючому Прикордонними військами України, Начальникові штабу Цивільної оборони України, Начальникові Управління державної охорони, Міністрові внутрішніх справ України визначити конкретні строки і порядок переходу на військову форму одягу, затверджену цим Указом, та правила її носіння військовослужбовцями відповідного військового формування.

Президент України Л.КРАВЧУК
