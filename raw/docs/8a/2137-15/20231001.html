Про внесення змін до Закону України "Про забезпечення санітарного та епідемічного благополуччя населення"

Стан: Втратив чинність

Ідентифікатор: 2137-15

Текст документа від 01.10.2023:

ЗАКОН УКРАЇНИ

{ Закон втратив чинність на підставі Закону N 2573-IX ( 2573-20 ) від 06.09.2022 }

Про внесення змін до Закону України "Про забезпечення санітарного та епідемічного благополуччя населення"

( Відомості Верховної Ради України (ВВР), 2005, N 2, ст.38 )

Верховна Рада України постановляє:

1. У тексті Закону України "Про забезпечення санітарного та епідемічного благополуччя населення" ( 4004-12 ) (Відомості Верховної Ради України, 1994 р., N 27, ст. 218; 1997 р., N 6, ст. 49, N 31, ст. 199; 1998 р., N 10, ст. 36; 1999 р., N 34, ст. 274; 2000 р., N 5, ст. 34; 2001 р., N 9, ст. 38; 2002 р., N 7, ст. 52, N 29, ст. 190; 2003 р., N 37, ст. 300; 2004 р., N 36, ст. 434) слова "Державного лікувально-оздоровчого управління" замінити словами "Державного управління справами".

2. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА
