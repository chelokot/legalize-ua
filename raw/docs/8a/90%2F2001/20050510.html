УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 706/2005 ( 706/2005 ) від 26.04.2005 )

Про внесення зміни до Указу Президента України від 13 грудня 2000 р. N 1331

Увести до складу Національної Ради з узгодження діяльності загальнодержавних і регіональних органів та місцевого самоврядування, затвердженого Указом Президента України від 13 грудня 2000 року N 1331 ( 1331/2000 ) (із змінами, внесеними Указом від 20 грудня 2000 року N 1354) ( 1354/2000 ) КРАВЧУКА Леоніда Макаровича - народного депутата України (за згодою).
