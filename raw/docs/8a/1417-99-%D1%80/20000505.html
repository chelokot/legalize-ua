Кабінет Міністрів України; Розпорядження від 17.12.1999 № 1417-р

Про дозвіл Держмитслужбі здійснити митне оформлення вантажів, що надходять на адресу ВО "Південний машинобудівний завод"

Стан: Втратив чинність

Ідентифікатор: 1417-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 грудня 1999 р. N 1417-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Для забезпечення успішної реалізації міжнародного проекту "Морський старт" дозволити Держмитслужбі здійснити митне оформлення вантажів, що надходять на адресу ВО "Південний машинобудівний завод" для виготовлення ракет-носіїв "Зеніт" за контрактом від 1 грудня 1997 р. N 58/505Д/132, укладеним з НВЦ імені академіка М.О. Пилюгіна (Російська Федерація), без сплати додаткового збору, встановленого постановою Кабінету Міністрів України від 19 травня 1999 р. N 840 ( 840-99-п ), та митного збору за перебування цих вантажів під митним контролем.

Перший віце-прем'єр-міністр України А.КІНАХ
