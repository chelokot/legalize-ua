КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 квітня 2004 р. N 482 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

{ Постанова втратила чинність на підставі Постанови КМ N 1107 ( 1107-2009-п ) від 21.10.2009 }

Про доповнення пункту 2 Положення про військові представництва на підприємствах, в установах і організаціях

Кабінет Міністрів України постановляє:

Абзац третій пункту 2 Положення про військові представництва на підприємствах, в установах і організаціях, затвердженого постановою Кабінету Міністрів України від 1 березня 1999 р. N 279 ( 279-99-п ), доповнити реченням такого змісту: "Військові представництва Міноборони обов'язково залучаються до здійснення контролю за якістю озброєння і військової техніки, що виробляються підприємствами України на експорт".

Прем'єр-міністр України В.ЯНУКОВИЧ
