Про затвердження Опису зразків спеціального одягу виробничого персоналу майданчиків для паркування транспортних засобів

На виконання пункту 24 Правил паркування транспортних засобів, затверджених постановою Кабінету Міністрів України від 03.12.2009 N 1342 ( 1342-2009-п ), з метою забезпечення безпеки виробничого персоналу майданчиків для паркування транспортних засобів під час виконання ними службових обов'язків, а також безпеки дорожнього руху НАКАЗУЮ:

1. Затвердити Опис зразків спеціального одягу виробничого персоналу майданчиків для паркування транспортних засобів, що додається.

2. Департаменту благоустрою, комунального обслуговування та міського електротранспорту (Ігнатенко О.П.) спільно з Юридичним управлінням (Ніконов А.А.) забезпечити в установленому порядку подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Департаменту благоустрою, комунального обслуговування та міського електротранспорту (Ігнатенко О.П.) забезпечити розміщення цього наказу на веб-сайті Мінжитлокомунгоспу та надіслати його до Ради міністрів Автономної Республіки Крим, обласних, Київської і Севастопольської міських державних адміністрацій для використання в роботі та подальшого доведення до відома інших місцевих органів виконавчої влади і органів місцевого самоврядування.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

5. Контроль за виконанням цього наказу покласти на заступника Міністра Зіміна С.Г.

ОПИС зразків спеціального одягу виробничого персоналу майданчиків для паркування транспортних засобів

I. Опис зразків спеціального сигнального одягу підвищеної видимості

1.1. Одяг спеціальний сигнальний підвищеної видимості призначений для захисту паркувальника під час виконання ним службових обов'язків.

1.2. Сорочка бавовняна з короткими рукавами з настроченими помаранчевими смугами з білими накладками із світловідбивального (світлоповертального) матеріалу, призначеними для візуального позначення виробничого персоналу майданчиків для паркування транспортних засобів (далі - майданчик для паркування) під час денного освітлення і вночі у світлі автомобільних фар згідно з вимогами ДСТУ EN 471-2001 "Одяг спеціальний сигнальний підвищеної видимості. Технічні вимоги" (далі - ДСТУ EN 471-2001). На сорочку наноситься логотип оператора.

Колір - блакитний.

Графічний вигляд сорочки бавовняної з короткими рукавами наведений у додатку 1 ( za306-10 ).

1.3. Сорочка бавовняна з довгими рукавами з настроченими помаранчевими смугами з білими накладками із світловідбивального (світлоповертального) матеріалу, призначеними для візуального позначення виробничого персоналу майданчиків для паркування під час денного освітлення і вночі у світлі автомобільних фар згідно з вимогами ДСТУ EN 471-2001.

Колір - блакитний.

На сорочку наноситься логотип оператора.

Графічний вигляд сорочки бавовняної з довгими рукавами наведений у додатку 2 ( za306-10 ).

1.4. Куртка літня непромокальна з прорезиненої плащової тканини призначена для роботи паркувальника за несприятливих погодних умов (дощ, туман, вітер, вологість повітря) згідно з вимогами ДСТУ ENV 343-2001 "Одяг спеціальний для захисту від непогоди" (далі - ДСТУ ENV 343-2001). На куртку настрочуються накладки із світловідбивального (світлоповертального) матеріалу, призначені для візуального позначення виробничого персоналу майданчиків для паркування під час денного або штучного освітлення і вночі у світлі автомобільних фар згідно з вимогами ДСТУ EN 471-2001.

Кольори - помаранчевий та синій.

На куртку наноситься логотип оператора.

Графічний вигляд куртки літньої непромокальної наведений у додатку 3 ( za306-10 ).

1.5. Напівкомбінезон літній непромокальний з прорезиненої плащової тканини призначений для захисту паркувальника від несприятливих погодних умов (дощ, туман, вітер, вологість повітря) згідно з вимогами ДСТУ ENV 343-2001. На напівкомбінезон настрочуються помаранчеві смуги з білими накладками із світловідбивального (світлоповертального) матеріалу, призначені для візуального позначення виробничого персоналу майданчиків для паркування під час денного або штучного освітлення і вночі у світлі автомобільних фар згідно з вимогами ДСТУ EN 471-2001.

Колір - синій.

Графічний вигляд напівкомбінезона літнього непромокального наведений у додатку 4 ( za306-10 ).

1.6. Куртка на утеплювальній прокладці з капюшоном непромокальна з прорезиненої плащової тканини з настроченими помаранчевими смугами з білими накладками із світловідбивального (світлоповертального) матеріалу, призначеними для візуального позначення виробничого персоналу майданчиків для паркування взимку під час денного або штучного освітлення і вночі у світлі автомобільних фар згідно з вимогами ДСТУ EN 471-2001.

Кольори - помаранчевий і синій.

На куртку наноситься логотип оператора.

Графічний вигляд куртки на утеплювальній прокладці наведений у додатку 5 ( za306-10 ).

1.7. Напівкомбінезон на утеплювальній прокладці непромокальний з прорезиненої плащової тканини з настроченими помаранчевими смугами з білими накладками із світловідбивального (світлоповертального) матеріалу, призначеними для візуального позначення виробничого персоналу майданчиків для паркування взимку під час денного або штучного освітлення і вночі у світлі автомобільних фар згідно з вимогами ДСТУ EN 471-2001.

Кольори - помаранчевий і синій.

Графічний вигляд напівкомбінезона на утеплювальній прокладці наведений у додатку 6 ( za306-10 ).

1.8. Кепі літнє з козирком виготовляється з бавовняної тканини.

Колір - помаранчевий.

На кепі наноситься логотип оператора.

Графічний вигляд кепі літнього наведений у додатку 7 ( za306-10 ).

1.9. Кепі зимове з козирком та одворотом виготовляється з бавовняної тканини і має утеплену прокладку.

Колір - помаранчевий.

На кепі наноситься логотип оператора.

Графічний вигляд кепі зимового наведений у додатку 8 ( za306-10 ).

1.10. Для виготовлення спеціального одягу виробничого персоналу майданчиків для паркування транспортних засобів допускається можливість застосування, окрім бавовняних, інших тканин і матеріалів, сертифікованих в установленому порядку.

II. Опис зразків спеціального одягу для захисту під час виконання виробничим персоналом робіт, пов'язаних із забрудненням, та спеціальних робіт

2.1. Одяг спеціальний для захисту під час виконання виробничим персоналом робіт, пов'язаних із забрудненням, та спеціальних робіт призначений для таких категорій виробничого персоналу майданчиків для паркування:

прибиральника територій майданчиків для паркування під час виконання робіт із систематичного очищення території майданчиків для паркування від пилу, сміття та листя шляхом їх підмітання, миття, своєчасного очищення від снігу і криги та обробки їх фрикційними та іншими протиожеледними матеріалами;

дорожнього робітника, що виконує роботи з очищення, миття, відновлення дорожніх знаків та інформаційних стендів (щитів), утримання схем розміщення місць для паркування, в'їздів та виїздів, а також транспортних або пішохідних огорож (у разі наявності), нанесення та відновлення дорожньої розмітки, утримання та поточний ремонт дорожнього покриття території та під'їзних шляхів до них, а також систем поверхневого водовідведення у межах таких майданчиків (у разі наявності);

слюсаря з контрольно-вимірювальних приладів та автоматики (електроніки) під час виконання робіт із забезпечення функціонування паркувальних автоматів або в'їзних та виїзних терміналів (очищення, миття, фарбування, відновлення їх роботи, заміна окремих деталей, планові обстеження, нагляд за справністю, їх технічна підтримка та програмне забезпечення), а також функціонування на спеціально обладнаних майданчиках для паркування систем відеоспостереження за рухом транспортних засобів на їх території і табло із змінною інформацією про наявність вільних місць для паркування, що установлюються на в'їзді (у разі їх наявності);

електромонтажника з освітлення та освітлювальних мереж під час виконання робіт із забезпечення утримання та належного функціонування засобів та обладнання зовнішнього освітлення території майданчиків для паркування;

фахівця з протипожежної безпеки під час виконання робіт з утримання автоматичних установок пожежогасіння та пожежної сигналізації на підземних та багаторівневих спеціально обладнаних майданчиках для паркування.

2.2. Халат бавовняний призначений для захисту від забруднень прибиральників службових приміщень під час виконання робіт з утримання на спеціально обладнаних майданчиках для паркування контрольно-пропускного пункту, приміщення для обслуговувального персоналу, туалету, побутових приміщень (у разі наявності).

Колір - блакитний.

Графічний вигляд халата бавовняного наведений у додатку 9 ( za306-10 ).

2.3. Рукавички комбіновані згідно з ДСТУ EN 388:2005 "Рукавички для захисту від механічних ушкоджень. Загальні технічні вимоги та методи випробування (EN 388:2003, IDT)" та ДСТУ EN 420-2001 "Загальні вимоги до рукавиць" призначені для захисту від забруднень прибиральників службових приміщень під час виконання робіт з утримання на спеціально обладнаних майданчиках для паркування контрольно-пропускного пункту, приміщення для обслуговувального персоналу, туалету, побутових приміщень (у разі наявності), а також прибиральників територій майданчиків для паркування під час виконання робіт із систематичного очищення території майданчиків для паркування від пилу, сміття та листя шляхом їх підмітання.

2.4. Рукавички утеплені згідно з ДСТУ EN 388:2005 "Рукавички для захисту від механічних ушкоджень. Загальні технічні вимоги та методи випробування (EN 388:2003, IDT)" та ДСТУ EN 420-2001 "Загальні вимоги до рукавиць" призначені для захисту від забруднень під час виконання виробничим персоналом майданчиків для паркування службових обов'язків узимку.

2.5. Рукавички гумові згідно з ГОСТ 12.4.010-75 УССБТ. Средства индивидуальной защиты. Рукавицы специальные. Технические условия" та ГОСТ 12.4.020-82 УССБТ. Средства индивидуальной защиты рук. Номенклатура показателей качества" призначені для електромонтажника з освітлення та освітлювальних мереж під час виконання робіт із забезпечення утримання та належного функціонування засобів та обладнання зовнішнього освітлення території майданчиків для паркування.
