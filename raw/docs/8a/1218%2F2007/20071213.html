Президент України; Указ, Склад колегіального органу від 13.12.2007 № 1218/2007

Про делегацію України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї 1948 року

Стан: Втратив чинність

Ідентифікатор: 1218/2007

Текст документа від 13.12.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про делегацію України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї 1948 року

1. Затвердити новий склад делегації України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї 1948 року ( 995_175 ) (додається).

2. Дозволити главі делегації за погодженням з Міністерством закордонних справ України вносити зміни до персонального складу делегації України та в разі потреби залучати експертів до участі в роботі делегації України.

3. Затвердити Директиви делегації України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї 1948 року ( 995_175 ).

4. Кабінету Міністрів України вирішити питання стосовно виділення коштів в іноземній валюті для забезпечення участі делегації України у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї 1948 року ( 995_175 ).

5. Визнати таким, що втратило чинність, Розпорядження Президента України від 12 вересня 2005 року N 1159 ( 1159/2005-рп ) "Про делегацію України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї 1948 року" (крім пункту 1 в частині, що стосується рішення про утворення делегації України для участі у Підготовчому комітеті Дипломатичної конференції з питань перегляду Конвенції про режим судноплавства на Дунаї 1948 року) ( 995_175 ).
