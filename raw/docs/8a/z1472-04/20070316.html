Про внесення змін до наказу Міністерства праці та соціальної політики України від 04.04.2000 N 76

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства праці та соціальної політики

N 76 ( z0221-00 ) від 04.04.2000, до якого вносились зміни }

На виконання постанови Кабінету Міністрів України від 04.11.2004 N 1481 ( 1481-2004-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 04.04.2000 N 76 ( z0221-00 ) "Про умови оплати праці працівників Національної служби посередництва і примирення" (зі змінами), зареєстрованого в Міністерстві юстиції України 11.04.2000 за N 221/4442, виклавши додатки 1-2 у новій редакції (додаються).

2. Ці умови застосовуються з 1 листопада 2004 року.

Міністр М.Папієв
