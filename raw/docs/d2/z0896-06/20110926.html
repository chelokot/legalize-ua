НАКАЗ

20.07.2006 N 722

Зареєстровано в Міністерстві юстиції України 31 липня 2006 р. за N 896/12770

{ Наказ втратив чинність на підставі Наказу Міністерства внутрішніх справ N 546 ( z1024-11 ) від 12.08.2011 }

Про затвердження Переліку посад начальницького складу підрозділів боротьби з економічною злочинністю органів внутрішніх справ, за якими зараховується час проходження служби на пільгових умовах з розрахунку один місяць служби за півтора місяця

На виконання вимог постанови Кабінету Міністрів України від 22 червня 2005 року N 497 ( 497-2005-п ) "Про доповнення пункту 3 постанови Кабінету Міністрів України від 17 липня 1992 р. N 393", а також з метою посилення соціального захисту працівників Державної служби боротьби з економічною злочинністю МВС України НАКАЗУЮ:

1. Затвердити Перелік посад начальницького складу підрозділів боротьби з економічною злочинністю органів внутрішніх справ, за якими зараховується час проходження служби на пільгових умовах з розрахунку один місяць служби за півтора місяця (додається).

2. Вислуга років для призначення пенсій на пільгових умовах зараховується особам, зазначеним у пункті 1 цього наказу, які перебували на службі після набрання чинності постановою Кабінету Міністрів України від 22 червня 2005 року N 497 ( 497-2005-п ) , при цьому таким особам на пільгових умовах зараховується весь час проходження служби на відповідних посадах.

3. ДДСБЕЗ (Скалозуб Л.П.) МВС України в п'ятиденний строк після підписання наказу забезпечити його подання на державну реєстрацію до Міністерства юстиції України.

4. Скасувати наказ МВС України від 1 липня 2005 року N 510 "Про затвердження Переліку посад начальницького складу підрозділів Державної служби боротьби з економічною злочинністю, за якими зараховується час проходження служби на пільгових умовах один місяць служби за півтора місяця".

5. Контроль за виконанням наказу покласти на заступника Міністра генерал-майора міліції Євдокимова В.М.

6. Наказ оголосити особовому складу органів та підрозділів внутрішніх справ України.

Міністр Ю.В.Луценко
