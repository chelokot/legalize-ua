Про внесення зміни до пункту 71 Статуту Державної акціонерної компанії "Хліб України"

Стан: Втратив чинність

Текст документа від 09.02.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 червня 2003 р. N 895 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 63 ( 63-2011-п ) від 02.02.2011 }

Про внесення зміни до пункту 71 Статуту Державної акціонерної компанії "Хліб України"

Кабінет Міністрів України постановляє:

У пункті 71 Статуту Державної акціонерної компанії "Хліб України", затвердженого постановою Кабінету Міністрів України від 14 березня 2001 р. N 240 ( 240-2001-п ) (Офіційний вісник України, 2001 р., N 12, ст. 489; 2002 р. N 27, ст. 1256, із зміною, внесеною постановою Кабінету Міністрів України від 1 липня 2002 р. N 872 ( 872-2002-п ), слова "перший заступник" замінити словами "перші заступники".

Перший віце-прем'єр-міністр України М.АЗАРОВ
