Верховна Рада України; Закон від 07.03.2002 № 3114-III

Про внесення зміни до Митного тарифу України

Стан: Втратив чинність

Ідентифікатор: 3114-14

Текст документа від 07.03.2002:

ЗАКОН УКРАЇНИ

Про внесення зміни до Митного тарифу України

( Відомості Верховної Ради України (ВВР), 2002, N 32, ст.233 )

Верховна Рада України постановляє:

1. У розділі XIV Митного тарифу України ( 2371в-14 ), затвердженого Законом України "Про Митний тариф України" ( 2371-14 ) (Відомості Верховної Ради України, 2001 р., N 24, ст. 125; Офіційний вісник України, 2001 р., N 18, ст. 781; Відомості Верховної Ради України, 2001 р., N 45, ст. 239; 2002 р., N 9, ст. 68, N 18-19, ст.133), цифри і слова:

"7102 31 00 00 - - необроблені або 0,5 5 кар"

просто розпиляні, розколоті або піддані чорновій обробці

замінити цифрами і словами

"7102 31 00 00 - - необроблені або 0 0 кар".

просто розпиляні, розколоті або піддані чорновій обробці

2. Цей Закон набирає чинності через 45 днів після його опублікування.

Президент України Л.КУЧМА

м. Київ, 7 березня 2002 року N 3114-III
