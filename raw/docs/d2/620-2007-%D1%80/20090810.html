РОЗПОРЯДЖЕННЯ від 8 серпня 2007 р. N 620-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 780 ( 780-2009-п ) від 29.07.2009 }

Про внесення змін до розпорядження Кабінету Міністрів України від 15 лютого 2006 р. N 87

Внести до абзацу першого розпорядження Кабінету Міністрів України від 15 лютого 2006 р. N 87 ( 87-2006-р ) "Про голову Української частини комісій з військово-технічного співробітництва" такі зміни:

слова "заступника Міністра оборони Терещенка Володимира Івановича" замінити словами "заступника Міністра оборони, який згідно з розподілом функціональних повноважень відповідає за військово-технічне співробітництво,";

слова "та українсько-сербсько-чорногорської" замінити словами ", українсько-сербсько-чорногорської, українсько-екваторіально-гвінейської, українсько-казахстанської, українсько-угорської".

Прем'єр-міністр України В.ЯНУКОВИЧ
