Кабінет Міністрів України; Постанова від 21.01.1998 № 60

Про забезпечення поставок ядерного палива, обладнання і матеріалів для атомних електростанцій

Стан: Втратив чинність

Ідентифікатор: 60-98-п

Текст документа від 07.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 січня 1998 р. N 60 Київ

( Постанова втратила чинність на підставі Постанови КМ N 776 ( 776-2000-п ) від 07.05.2000 )

Про забезпечення поставок ядерного палива, обладнання і матеріалів для атомних електростанцій

( Із змінами, внесеними згідно з Постановою КМ N 328 ( 328-99-п ) від 09.03.99 )

З метою забезпечення атомних електростанцій свіжим ядерним паливом, обладнанням, матеріалами для проведення ремонтних робіт на енергоблоках, вивезення на переробку відпрацьованого палива Кабінет Міністрів України постановляє:

1. Підтримати ініціативу державного підприємства "Національна атомна енергогенеруюча компанія "Енергоатом" щодо укладення в установленому порядку консорційної угоди з фінансовими, комерційними і промисловими підприємствами (далі - учасники) з метою забезпечення стабільного постачання та проведення розрахунків за поставлені на атомні електростанції обладнання і матеріали для ремонту енергоблоків, свіже ядерне паливо, а також розрахунків за відправлене на переробку відпрацьоване ядерне паливо.

2. Взяти до відома, що:

імпорт свіжого ядерного палива, обладнання, матеріалів для ремонту енергоблоків та їх митне оформлення здійснюється державним підприємством "Національна атомна енергогенеруюча компанія "Енергоатом" або за його дорученням атомними електростанціями України, а розрахунки за їх постачання та відправлення на переробку відпрацьованого ядерного палива здійснюють учасники на підставі окремих контрактів з підприємствами Міністерства Російської Федерації по атомній енергії, іншими постачальниками та договорів про переказ боргів компанії "Енергоатом" перед російськими контрагентами на учасників;

компанія "Енергоатом" здійснює розрахунки з учасниками шляхом передачі боргів підприємств - споживачів електроенергії.

( Пункт 3 втратив чинність на підставі Постанови КМ N 328 ( 328-99-п ) від 09.03.99 ) 3. З метою підтримки конкурентоспроможності продукції вітчизняних виробників, яка використовується для розрахунків з постачальниками ядерного палива, обладнання, матеріалів та отримувачами відпрацьованого ядерного палива, дозволити державному підприємству "Національна атомна енергогенеруюча компанія "Енергоатом" здійснювати на конкурсних засадах продаж електроенергії за нерегульованим тарифом, який відповідає тарифу енергопостачальних компаній Міністерства енергетики із знижкою до 30 відсотків, з віднесенням втрат на результати господарської діяльності компанії "Енергоатом", пов'язаної з виробництвом електроенергії.

4. Рекомендувати Національній комісії з питань регулювання електроенергетики за поданням Міністерства енергетики визначати умови оплати транспортування електроенергії з урахуванням заборгованості підприємств Міністерства енергетики атомним електростанціям та фінансового стану енергопостачальних компаній.

5. Контроль за виконанням цієї постанови покласти на Міністра енергетики Шеберстова О.М.
