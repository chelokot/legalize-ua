Текст документа від 23.02.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 лютого 2011 р. N 144 Київ

Про внесення змін до постанови Кабінету Міністрів України від 8 листопада 2000 р. N 1683

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 8 листопада 2000 р. N 1683 ( 1683-2000-п ) "Про затвердження переліків посад та спеціальностей персоналу для експлуатації ядерних установок, підготовка якого підлягає ліцензуванню, і посад персоналу, який безпосередньо здійснює управління реакторною установкою атомної електростанції" (Офіційний вісник України, 2000 р., N 46, ст. 1993; 2002 р., N 1, ст. 16; 2004 р., N 51, ст. 3340) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 23 лютого 2011 р. N 144

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 8 листопада 2000 р. N 1683 ( 1683-2000-п )

1. У назві та абзаці третьому пункту 1 постанови ( 1683-2000-п ) слова "атомної електростанції" виключити.

2. У розділі "Чорнобильська АЕС" переліку посад та спеціальностей персоналу для експлуатації ядерних установок, підготовка якого підлягає ліцензуванню, затвердженого зазначеною постановою ( 1683-2000-п ), позиції "Начальник зміни черги атомної електростанції", "Начальник зміни блока атомної електростанції", "Провідний інженер управління реактором атомної електростанції" виключити.

3. У переліку посад персоналу, який безпосередньо здійснює управління реакторною установкою атомної електростанції, затвердженому зазначеною постановою ( 1683-2000-п ):

1) у назві переліку слова "атомної електростанції" виключити;

2) розділ "Чорнобильська АЕС" виключити;

3) доповнити перелік розділами такого змісту:

"Інститут ядерних досліджень Національної академії наук

Інженер з управління дослідницьким реактором ВВР-М

Завідувач зміни дослідницького реактора ВВР-М

Севастопольський національний університет ядерної енергії та промисловості

Інженер з управління дослідницьким реактором ДР-100

Начальник зміни дослідницького реактора ДР-100".
