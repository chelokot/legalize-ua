ЗАТВЕРДЖЕНО Розпорядження Державної комісії з регулювання ринків фінансових послуг України 08.02.2005 N 3519

Зареєстровано в Міністерстві юстиції України 24 лютого 2005 р. за N 265/10545

КВАЛІФІКАЦІЙНІ ВИМОГИ до осіб, які можуть займатися актуарними розрахунками

{ У тексті Кваліфікаційних вимог, крім абзацу четвертого пункту 1.8 розділу 1, слово "Держфінпослуг" замінено словом "Нацкомфінпослуг" згідно з Розпорядженням Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 2421 ( z2172-12 ) від 27.11.2012 }

1. Загальні положення

1.1. Ці Кваліфікаційні вимоги розроблені відповідно до вимог статей 10, 36 Закону України "Про страхування" ( 85/96-ВР ) та підпункту 60 пункту 4 Положення про Національну комісію, що здійснює державне регулювання у сфері ринків фінансових послуг, затвердженого Указом Президента України від 23 листопада 2011 року N 1070 ( 1070/2011 ).

{ Пункт 1.1 розділу 1 із змінами, внесеними згідно з Розпорядженням Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 2421 ( z2172-12 ) від 27.11.2012 }

1.2. У цих Кваліфікаційних вимогах наведені нижче поняття вживаються в такому значенні:

американська екзаменаційна система - система актуарних екзаменів (іспитів), яка встановлена професійними актуарними організаціями США (Товариством Актуаріїв, Товариством Актуаріїв майнового страхування) (Society of Actuaries, Casualty Actuarial Society) і відповідає вимогам Міжнародної Актуарної Асоціації;

британська екзаменаційна система - система актуарних екзаменів (іспитів), яка встановлена професійною актуарною організацією Великобританії (Faculty and Institute of Actuaries) і відповідає вимогам Міжнародної Актуарної Асоціації;

кваліфікаційний мінімум з питань страхування в Україні (далі - кваліфікаційний мінімум) - перелік питань у сфері страхування, зокрема на знання українського законодавства в цій сфері, володіння якими є обов'язковим для кваліфікованого виконання особою покладених на неї професійних завдань.

1.3. Актуарними розрахунками можуть займатися фізичні особи, які мають вищу освіту за математичним, технічним або економічним напрямом.

1.4. Актуарні розрахунки мають право посвідчувати фізичні особи, які мають кваліфікацію відповідно до цих Кваліфікаційних вимог та отримали свідоцтво про відповідність кваліфікаційним вимогам до осіб, які можуть займатися актуарними розрахунками (далі - Свідоцтво) (додаток 1).

{ Пункт 1.4 розділу 1 в редакції Розпорядження Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 3910 ( z1964-13 ) від 29.10.2013 }

1.5. Національна комісія, що здійснює державне регулювання у сфері ринків фінансових послуг, видає Свідоцтво відповідно до цих Кваліфікаційних вимог. Свідоцтво може видаватись без обмеження строку його дії або строком на три роки. Облік виданих Свідоцтв веде Нацкомфінпослуг.

{ Пункт 1.5 розділу 1 із змінами, внесеними згідно з Розпорядженням Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 2421 ( z2172-12 ) від 27.11.2012 }

1.6. У разі посвідчення актуарних розрахунків зазначення номеру та дати видачі Свідоцтва є обов'язковим.

1.7. Нацкомфінпослуг публікує в засобах масової інформації та на веб-сайті Нацкомфінпослуг список осіб, які отримали Свідоцтво, та інформацію про прийняте рішення щодо анулювання Свідоцтва.

1.8. Рівень кваліфікаційних вимог до осіб, які можуть займатися актуарними розрахунками та посвідчувати їх, визначається шляхом установлення вимог до:

а) рівня освіти;

б) досвіду практичної діяльності;

в) спеціальних знань - професійної кваліфікації (відповідно до підпункту "г" пункту 2.1, підпункту "г" пункту 2.2 та підпункту "г" пункту 2.3 розділу 2 цих Кваліфікаційних вимог) та кваліфікаційного мінімуму, який встановлюється відповідно до пункту 1.6 Положення про навчання, перепідготовку, підвищення кваліфікації та складання екзаменів особами, які провадять діяльність на ринках фінансових послуг, затвердженого розпорядженням Держфінпослуг від 25.12.2003 N 183 ( z0122-04 ), зареєстрованого в Міністерстві юстиції України 28.01.2004 за N 122/8721 (далі - Положення).

{ Підпункт "в" пункту 1.8 розділу 1 із змінами, внесеними згідно з Розпорядженням Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 3910 ( z1964-13 ) від 29.10.2013 }

2. Вимоги до осіб, які можуть займатися актуарними розрахунками та посвідчувати їх

2.1. Особа, яка претендує на право займатися актуарними розрахунками та посвідчувати їх та отримати Свідоцтво (без обмеження строку його дії), повинна мати:

а) вищу освіту;

б) досвід роботи з виконання актуарних розрахунків у межах території України не менше ніж три роки;

в) кваліфікаційне свідоцтво, видане відповідно до Положення ( z0122-04 );

г) диплом магістра за спеціальністю та/або спеціалізацією з актуарної (страхової) та (і) фінансової математики або документи про успішне складання професійних екзаменів, передбачених американською (за кодами SOA Course 1/P - SOA Course 6, або SOA Exam P - SOA Exam C, або CAS Course 1 - CAS Course 6, або CAS Exam 1 - CAS Exam 6) та/або британською (за кодами 101 - 109 або CT1 - CT8) екзаменаційними системами (додаток 2).

{ Підпункт "г" пункту 2.1 розділу 2 в редакції Розпорядження Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 3782 ( z1257-17 ) від 19.09.2017 } { Пункт 2.1 розділу 2 в редакції Розпорядження Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 3910 ( z1964-13 ) від 29.10.2013 }

2.2. Особа, яка претендує на право займатися актуарними розрахунками зі страхування життя, посвідчувати їх та отримати Свідоцтво (строком на три роки), повинна мати:

а) вищу освіту;

б) досвід роботи з виконання актуарних розрахунків із страхування життя у межах території України не менший, ніж три роки;

в) кваліфікаційне свідоцтво, видане відповідно до Положення ( z0122-04 );

г) документи про успішне складання професійних екзаменів, передбачених американською (за кодами SOA Course 1/P - SOA Course 4/C, або SOA Exam P - SOA Exam M/MFE, або CAS Course 1 - CAS Course 4, або CAS Exam 1 - CAS Exam 4) та/або британською (за кодами 101 - 105 або CT1, CT3 - CT5) екзаменаційними системами (додаток 2).

{ Підпункт "г" пункту 2.2 розділу 2 в редакції Розпорядження Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 3910 ( z1964-13 ) від 29.10.2013 }

2.3. Особа, яка претендує на право займатися актуарними розрахунками з видів страхування, інших, ніж страхування життя, посвідчувати їх та отримати Свідоцтво (строком на три роки), повинна мати:

а) вищу освіту;

б) досвід роботи з виконання актуарних розрахунків з видів страхування, інших, ніж страхування життя у межах території України не менший, ніж три роки;

в) кваліфікаційне свідоцтво, видане відповідно до Положення ( z0122-04 );

г) документи про успішне складання професійних екзаменів, передбачених американською (за кодами SOA Course 1/P - SOA Course 4/C, або SOA Exam P - SOA Exam M/MFE, або CAS Course 1 - CAS Course 4, або CAS Exam 1 - CAS Exam 4) та/або британською (за кодами 101 - 104 та 106 або CT1, CT3, CT4, CT6) екзаменаційними системами (додаток 2).

{ Підпункт "г" пункту 2.3 розділу 2 в редакції Розпорядження Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 3910 ( z1964-13 ) від 29.10.2013 }

2.4. Особа, яка відповідно до пунктів 2.2 та 2.3 цього розділу отримала Свідоцтво строком на три роки, може одноразово отримати нове Свідоцтво строком на наступні три роки за умови отримання кваліфікаційного свідоцтва, виданого відповідно до Положення ( z0122-04 ). При цьому кваліфікаційне свідоцтво має бути отримане не раніше, ніж за один рік до дня подання заяви для одержання нового Свідоцтва.

У разі якщо особа за цей період не склала екзамени, необхідні для отримання Свідоцтва без обмеження строку його дії, повторно видане Свідоцтво анулюється відповідно до підпункту "в" пункту 5.1 розділу 5 цих Кваліфікаційних вимог.

{ Розділ 2 доповнено новим пунктом 2.4 згідно з Розпорядженням Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 3910 ( z1964-13 ) від 29.10.2013 }

3. Порядок видачі Свідоцтва

3.1. Свідоцтво видається фізичним особам, які відповідають вимогам, визначеним у розділі 2 цих Кваліфікаційних вимог.

3.2. Для одержання Свідоцтва заявник подає до Нацкомфінпослуг такі документи:

а) заяву про видачу Свідоцтва (додаток 3);

{ Підпункт "а" пункту 3.2 розділу 3 в редакції Розпорядження Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 3910 ( z1964-13 ) від 29.10.2013 }

б) копію документа про вищу освіту;

в) копію сторінок трудової книжки або довідку підписану керівником страховика та засвідчену печаткою страховика (із зазначенням періоду, трудової функції та правових підстав трудових відносин (трудовий договір чи цивільно-правові договори)), що підтверджують досвід роботи з виконання актуарних розрахунків у межах території України;

г) копію сторінок паспорта, що підтверджують дані, зазначені у заяві;

ґ) копію кваліфікаційного свідоцтва, виданого відповідно до Положення ( z0122-04 );

д) копію диплома магістра за спеціальністю та/або спеціалізацією з актуарної (страхової) та (і) фінансової математики або документи про успішне складання професійних екзаменів, передбачених американською та/або британською екзаменаційними системами.
