Про доповнення Переліку документів, на підставі яких вчиняються нотаріальні виконавчі написи на стягнення грошей і майна

Стан: Втратив чинність

Ідентифікатор: 144-66-п

Текст документа від 12.10.1976:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 7 лютого 1966 р. N 144 Київ

( Постанова втратила чинність на підставі Постанови Ради Міністрів УРСР N 483 ( 483-76-п ) від 12.10.76 )

Про доповнення Переліку документів, на підставі яких вчиняються нотаріальні виконавчі написи на стягнення грошей і майна

Рада Міністрів Української РСР постановляє:

Доповнити затверджений постановою Ради Міністрів УРСР від 31 серпня 1964 року N 941 ( 941-64-п ) (ЗП УРСР 1964 р. N 8, ст. 113) Перелік документів, на підставі яких вчиняються нотаріальні виконавчі написи на стягнення грошей і майна, пунктом 6-а такого змісту:

"6-а. Стягнення правлінням житлово-будівельного кооперативу заборгованості членів кооперативу по прострочених платежах по позичках провадиться на підставі:

а) копії зобов'язання боржника, засвідченої правлінням житлово-будівельного кооперативу;

б) засвідченої правлінням житлово-будівельного кооперативу виписки особового рахунку боржника".

Голова Ради Міністрів УРСР В.ЩЕРБИЦЬКИЙ
