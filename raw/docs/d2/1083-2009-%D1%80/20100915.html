Кабінет Міністрів України; Розпорядження від 26.08.2009 № 1083-р

Про виділення коштів Стабілізаційного фонду для створення у 2009 році реєстру судових проваджень, у яких однією із сторін або третьою особою є держава в особі Кабінету Міністрів України, міністерств та інших центральних органів виконавчої влади

Стан: Втратив чинність

Ідентифікатор: 1083-2009-р

Текст документа від 15.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 серпня 2009 р. N 1083-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1840-р ( 1840-2010-р ) від 15.09.2010 }

Про виділення коштів Стабілізаційного фонду для створення у 2009 році реєстру судових проваджень, у яких однією із сторін або третьою особою є держава в особі Кабінету Міністрів України, міністерств та інших центральних органів виконавчої влади

1. Виділити Мін'юсту 11,4 млн. гривень за рахунок коштів Стабілізаційного фонду ( 835-17 ) для створення у 2009 році реєстру судових проваджень, у яких однією із сторін або третьою особою є держава в особі Кабінету Міністрів України, міністерств та інших центральних органів виконавчої влади.

2. Мін'юсту подавати Мінфіну щомісяця до 1 числа наступного періоду звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
