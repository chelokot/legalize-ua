Про утворення урядового органу державного управління у складі Міністерства культури і туризму

Стан: Втратив чинність

Текст документа від 18.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 травня 2005 р. N 382 Київ

{ Постанова втратила чинність одночасно з набранням чинності Указом Президента ( 388/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Про утворення урядового органу державного управління у складі Міністерства культури і туризму

( Із змінами, внесеними згідно з Постановою КМ N 1237 ( 1237-2005-п ) від 21.12.2005 )

На виконання Указу Президента України від 20 квітня 2005 р. N 680 ( 680/2005 ) "Про Міністерство культури і туризму України" Кабінет Міністрів України постановляє:

1. Утворити у складі Міністерства культури і туризму на базі Державної служби охорони культурної спадщини, що реорганізується, Державну службу з питань національної культурної спадщини як урядовий орган державного управління.

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1237 ( 1237-2005-п ) від 21.12.2005 )

2. Установити, що Державна служба з питань національної культурної спадщини є правонаступником Державної служби охорони культурної спадщини.

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1237 ( 1237-2005-п ) від 21.12.2005 )

3. Міністерству культури і туризму подати у двомісячний строк Кабінетові Міністрів України проект Положення про Державну службу з питань національної культурної спадщини.
