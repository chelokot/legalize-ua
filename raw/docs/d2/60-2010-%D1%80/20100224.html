Питання надання громадянам квартир, що придбані Державною іпотечною установою, у м. Лутугиному

Стан: Чинний

Ідентифікатор: 60-2010-р

Текст документа від 24.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 січня 2010 р. N 60-р Київ

Питання надання громадянам квартир, що придбані Державною іпотечною установою, у м. Лутугиному

{ Із змінами, внесеними згідно з Розпорядженням КМ N 293-р ( 293-2010-р ) від 24.02.2010 }

1. Затвердити погоджений Координаційною радою з питань розподілу квартир, що придбані Державною іпотечною установою, при Кабінеті Міністрів України поіменний список громадян, яким надаються придбані у м. Лутугиному Луганської області (квартал Шевченка, 2) квартири (далі - список), що додається до оригіналу. { Зміни до поіменного списку див. в Розпорядженні КМ N 293-р ( 293-2010-р ) від 24.02.2010 }

2. Державній іпотечній установі передати державним органам та Лутугинській міській раді квартири для надання зазначеним у списку громадянам.

3. Виконавчому комітетові Лутугинської міської ради забезпечити в установленому законодавством порядку видачу зазначеним у списку громадянам ордерів на жилі приміщення.

4. Державним органам та Лутугинській міській раді забезпечити неухильне дотримання встановленого Кабінетом Міністрів України порядку розподілу квартир, що придбані Державною іпотечною установою.

Прем'єр-міністр України Ю.ТИМОШЕНКО
