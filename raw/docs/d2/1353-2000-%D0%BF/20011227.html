Текст документа від 27.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 серпня 2000 р. N 1353 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1738 ( 1738-2001-п ) від 27.12.2001 )

Про внесення зміни до постанови Кабінету Міністрів України від 3 лютого 1998 р. N 110

Кабінет Міністрів України постановляє:

Викласти пункт 2 постанови Кабінету Міністрів України від 3 лютого 1998 р. N 110 ( 110-98-п ) "Про умови оплати праці членів окружних і дільничних виборчих комісій" (Офіційний вісник України, 1998 р., N 5, ст. 182) у такій редакції:

"2. У разі коли встановлена пунктом 1 цієї постанови місячна заробітна плата голови, заступника голови, секретаря або члена комісії нижча, ніж його середня місячна заробітна плата за основним місцем роботи, вона встановлюється йому на рівні середньої заробітної плати за основним місцем роботи, визначеної згідно із законодавством, але не більш як 500 гривень".
