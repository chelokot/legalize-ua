Кабінет Міністрів України; Розпорядження від 12.12.2002 № 700-р

Про надання повноважень Міністерству фінансів на затвердження нормативно-правових актів

Стан: Втратив чинність

Ідентифікатор: 700-2002-р

Текст документа від 31.08.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 грудня 2002 р. N 700-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 775 ( 775-2012-п ) від 22.08.2012 }

Про надання повноважень Міністерству фінансів на затвердження нормативно-правових актів

{ Із змінами, внесеними згідно з Постановою КМ N 1016 ( 1016-2011-п ) від 05.10.2011 }

{ У назві та тексті Розпорядження слова "Держмитслужбі" та "Держмитслужбу" замінено відповідно словами "Міністерству фінансів" та "Міністерство фінансів" згідно з Постановою КМ N 1016 ( 1016-2011-п ) від 05.10.2011 }

Відповідно до статей 100 і 104 Митного кодексу України ( 92-15 ) уповноважити Міністерство фінансів розробити і затвердити:

Порядок розгляду заяви і видачі дозволу на використання приміщення, резервуару, майданчика як складу тимчасового зберігання;

Порядок ведення обліку та подання митним органам звітності щодо товарів і транспортних засобів на складах тимчасового зберігання.

Прем'єр-міністр України В.ЯНУКОВИЧ
