Про затвердження переліку платних послуг, які можуть надаватися закладами фізичної культури і спорту, що утримуються за рахунок бюджетних коштів

Стан: Чинний

Ідентифікатор: 356-2009-п

Текст документа від 20.11.2024:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 квітня 2009 р. N 356 Київ

Про затвердження переліку платних послуг, які можуть надаватися закладами фізичної культури і спорту, що утримуються за рахунок бюджетних коштів

{ Із змінами, внесеними згідно з Постановами КМ N 846 ( 846-2011-п ) від 10.08.2011 N 1312 ( 1312-2024-п ) від 15.11.2024 }

Кабінет Міністрів України постановляє:

1. Затвердити перелік платних послуг, які можуть надаватися закладами фізичної культури і спорту, що утримуються за рахунок бюджетних коштів (додається).

2. Міністерству у справах сім'ї, молоді та спорту разом з Міністерством економіки і Міністерством фінансів затвердити у місячний строк порядок та умови надання платних послуг закладами фізичної культури і спорту, що утримуються за рахунок бюджетних коштів.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 квітня 2009 р. N 356

ПЕРЕЛІК платних послуг, які можуть надаватися закладами фізичної культури і спорту, що утримуються за рахунок бюджетних коштів

1. Організація і проведення фізкультурно-спортивних та спортивно-видовищних заходів, реалізація абонементів на їх відвідування.

2. Проведення групових та індивідуальних занять з фізичної культури і спорту згідно з абонементами та квитками.

3. Надання спортивних споруд для проведення спортивно-видовищних заходів, занять з фізичної культури і спорту, організації спортивно-оздоровчих таборів.

4. Реалізація абонементів на відвідування саун, плавальних басейнів, льодових ковзанок тощо.

{ Пункт 5 виключено на підставі Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }

{ Пункт 6 виключено на підставі Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }

7. Організація і проведення навчання та підвищення кваліфікації фахівців з питань фізичної культури і спорту.

8. Проведення семінарів з питань фізичної культури і спорту.

{ Пункт 9 виключено на підставі Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }

10. Розроблення фізкультурно-спортивних програм, комплексу фізичних вправ для групових та індивідуальних занять, надання рекомендацій з їх впровадження. { Пункт 10 в редакції Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }

11. Надання учасникам та відвідувачам фізкультурно-спортивних заходів готелів, гуртожитків та пристосованих для тимчасового проживання приміщень.

12. Проведення монтажу та демонтажу некапітальних спортивних споруд, обладнання, спортивних майданчиків тощо.

13. Надання послуг з прокату спортивного спорядження, обладнання та інвентарю.

14. Проведення ремонту та технічного обслуговування спорядження, транспортних засобів, що використовуються для занять спортом та перевезення спеціального спортивного обладнання. { Пункт 14 в редакції Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }

15. Автомобільне перевезення спортивних команд, спортивного спорядження, обладнання та інвентарю. { Пункт 15 в редакції Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }

16. Організація та проведення тестувань спортсменів для цілей допінг-контролю, які є членами міжнародних спортивних федерацій, спортивних федерацій, спортивних клубів України, інших організацій за їх зверненням, а також спортсменів за зверненням антидопінгових організацій іноземних держав, понад обсяг тестувань, фінансування яких передбачено за рахунок коштів державного бюджету.

{ Перелік доповнено пунктом 16 згідно з Постановою КМ N 1312 ( 1312-2024-п ) від 15.11.2024 }

17. Проведення обробки результатів, включаючи моніторинг результатів тестування спортсменів, визначених у пункті 16 цього переліку, та/або за зверненням антидопінгових організацій іноземних держав, міжнародних спортивних федерацій, спортивних федерацій, спортивних клубів України, інших організацій, що проводять тестування для цілей допінг-контролю.

{ Перелік доповнено пунктом 17 згідно з Постановою КМ N 1312 ( 1312-2024-п ) від 15.11.2024 }

18. Проведення розслідування порушень антидопінгових правил, зокрема доведення фактів порушення антидопінгових правил за результатами тестування спортсменів, визначених у пункті 16 цього переліку, та/або за зверненням антидопінгових організацій іноземних держав, міжнародних спортивних федерацій, спортивних федерацій, спортивних клубів України, інших організацій, що проводять тестування для цілей допінг-контролю.

{ Перелік доповнено пунктом 18 згідно з Постановою КМ N 1312 ( 1312-2024-п ) від 15.11.2024 }

19. Проведення заходів (семінарів, тренінгів, конференцій, форумів, інших заходів) із впровадження антидопінгових правил у спортивну діяльність спортивних федерацій, спортивних клубів України, інших суб'єктів сфери фізичної культури і спорту за їх зверненнями.

{ Перелік доповнено пунктом 19 згідно з Постановою КМ N 1312 ( 1312-2024-п ) від 15.11.2024 }

20. Оцінка, планування, впровадження та перевірка інформаційних та освітніх програм із запобігання застосуванню допінгу у спорті проводиться за зверненнями спортивних федерацій, спортивних клубів України, інших суб’єктів сфери фізичної культури і спорту.

Послуги, визначені пунктами 16-20 цього переліку, можуть надаватися працівниками Національного антидопінгового центру у вільний від основної роботи час понад обсяг, передбачений планом розподілу тестувань та планом освітніх заходів Національного антидопінгового центру на відповідний рік (крім випадків, коли надання таких послуг фінансується за рахунок коштів загального фонду державного бюджету).

{ Перелік доповнено пунктом 20 згідно з Постановою КМ N 1312 ( 1312-2024-п ) від 15.11.2024 }
