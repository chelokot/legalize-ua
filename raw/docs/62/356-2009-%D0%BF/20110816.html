Текст документа від 16.08.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 квітня 2009 р. N 356 Київ

Про затвердження переліку платних послуг, які можуть надаватися закладами фізичної культури і спорту, що утримуються за рахунок бюджетних коштів

{ Із змінами, внесеними згідно з Постановою КМ N 846 ( 846-2011-п ) від 10.08.2011 }

Кабінет Міністрів України постановляє:

1. Затвердити перелік платних послуг, які можуть надаватися закладами фізичної культури і спорту, що утримуються за рахунок бюджетних коштів (додається).

2. Міністерству у справах сім'ї, молоді та спорту разом з Міністерством економіки і Міністерством фінансів затвердити у місячний строк порядок та умови надання платних послуг закладами фізичної культури і спорту, що утримуються за рахунок бюджетних коштів.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 квітня 2009 р. N 356

ПЕРЕЛІК платних послуг, які можуть надаватися закладами фізичної культури і спорту, що утримуються за рахунок бюджетних коштів

1. Організація і проведення фізкультурно-спортивних та спортивно-видовищних заходів, реалізація абонементів на їх відвідування.

2. Проведення групових та індивідуальних занять з фізичної культури і спорту згідно з абонементами та квитками.

3. Надання спортивних споруд для проведення спортивно-видовищних заходів, занять з фізичної культури і спорту, організації спортивно-оздоровчих таборів.

4. Реалізація абонементів на відвідування саун, плавальних басейнів, льодових ковзанок тощо.

{ Пункт 6 виключено на підставі Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }

7. Організація і проведення навчання та підвищення кваліфікації фахівців з питань фізичної культури і спорту.

8. Проведення семінарів з питань фізичної культури і спорту.

{ Пункт 9 виключено на підставі Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }

10. Розроблення фізкультурно-спортивних програм, комплексу фізичних вправ для групових та індивідуальних занять, надання рекомендацій з їх впровадження. { Пункт 10 в редакції Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }

11. Надання учасникам та відвідувачам фізкультурно-спортивних заходів готелів, гуртожитків та пристосованих для тимчасового проживання приміщень.

12. Проведення монтажу та демонтажу некапітальних спортивних споруд, обладнання, спортивних майданчиків тощо.

13. Надання послуг з прокату спортивного спорядження, обладнання та інвентарю.

14. Проведення ремонту та технічного обслуговування спорядження, транспортних засобів, що використовуються для занять спортом та перевезення спеціального спортивного обладнання. { Пункт 14 в редакції Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }

15. Автомобільне перевезення спортивних команд, спортивного спорядження, обладнання та інвентарю. { Пункт 15 в редакції Постанови КМ N 846 ( 846-2011-п ) від 10.08.2011 }
