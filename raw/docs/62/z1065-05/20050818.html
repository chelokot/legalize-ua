Текст документа від 18.08.2005:

МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

18.08.2005 N 393

Зареєстровано в Міністерстві юстиції України 16 вересня 2005 р. за N 1065/11345

Про визнання таким, що втратив чинність, наказу Мінагрополітики України від 21.07.2000 N 130

На виконання статті 3 Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" та розпорядження Кабінету Міністрів України від 08.08.2005 N 321 ( 321-2005-р ) "Про першочергові заходи щодо поліпшення стану справ із прискореного перегляду регуляторних актів та вдосконалення реєстраційної і дозвільної процедури" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства аграрної політики України від 21.07.2000 N 130 ( z0455-00 ) "Про Особливий порядок відкриття спеціальних рахунків цукровим заводам та використання коштів, що накопичуються на цих рахунках", зареєстрований у Міністерстві юстиції України 28.07.2000 за N 455/4676.

2. Державному департаменту продовольства (Кіщак Ю.П.) в установленому порядку подати наказ на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням наказу покласти на заступника Міністра Мельника С.І.

В.о. Міністра І.М.Демчак
