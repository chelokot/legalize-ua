( Постанова втратила чинність на підставі Постанови Нацбанку N 181 ( z0373-98 ) від 06.05.98 )

Про внесення змін та доповнень до Положення "Про порядок ліцензування банків в Україні"

Заслухавши інформацію департаменту реєстрації та ліцензування банків щодо необхідності внесення змін та доповнень до Положення "Про порядок ліцензування банків в Україні", затвердженого постановою Правління Національного банку України від 27 березня 1996 року N 77 ( v0077500-96 ), Правління ПОСТАНОВЛЯЄ:

1. Затвердити зміни та доповнення до Положення "Про порядок ліцензування банків в Україні", затвердженого постановою Правління Національного банку України від 27 березня 1996 року N 77 (додаються).

2. Контроль за виконанням цієї постанови покласти на заступника Голови Правління О.І.Кірєєва.

Голова В.А.Ющенко

Затверджено постановою Правління Національного банку України від 25.11.97 р. N 395 реєстр. N 490 від 25.11.97 р.

Зміни та доповнення до Положення "Про порядок ліцензування банків в Україні", затвердженого постановою Правління Національного банку України від 27.03.1996 року N 77 ( v0077500-96 )

1. Другий абзац пункту 7.10 викласти в такій редакції:

"наявності відповідного рішення Кабінету Міністрів України про визначення банку як уповноваженого здійснювати касове виконання Державного бюджету України;".

2. Сьомий абзац пункту 7.10 викласти в такій редакції:

"- відповідного розпорядження або постанови Уряду Автономної Республіки Крим, обласних, Київської і Севастопольської міських державних адміністрацій;".
