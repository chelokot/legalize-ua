Про встановлення граничних термінів прохідного митного транзиту товарів

Стан: Втратив чинність

Ідентифікатор: 1908-2002-п

Текст документа від 01.01.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 грудня 2002 р. N 1908 Київ

Про встановлення граничних термінів прохідного митного транзиту товарів

( Із змінами, внесеними згідно з Постановами КМ N 92 ( 92-2003-п ) від 18.01.2003 N 1222 ( 1222-2003-п ) від 06.08.2003 )

Відповідно до статті 158 Митного кодексу України ( 92-15 ) Кабінет Міністрів України постановляє:

1. Установити граничні терміни прохідного митного транзиту товарів через митну територію України згідно з додатком.

2. Уповноважити Державну митну службу надавати роз'яснення щодо застосування цієї постанови.

3. Ця постанова набирає чинності з 1 січня 2004 року.

( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 92 ( 92-2003-п ) від 18.01.2003 )

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 27

Додаток до постанови Кабінету Міністрів України від 13 грудня 2002 р. N 1908

ГРАНИЧНІ ТЕРМІНИ прохідного митного транзиту товарів через митну територію України

У разі здійснення перевезень засобами:

автомобільного транспорту - до 10 діб

залізничного транспорту - до 28 діб

авіаційного транспорту - до 5 діб

морського та річкового транспорту - до 20 діб

трубопровідного транспорту - до 31 доби

( Додаток із змінами, внесеними згідно з Постановою КМ N 1222 ( 1222-2003-п ) від 06.08.2003 )
