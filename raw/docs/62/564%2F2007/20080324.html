УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 259/2008 ( 259/2008 ) від 24.03.2008 }

Про делегацію України для участі у переговорах з Міжнародним банком реконструкції та розвитку щодо укладення Угоди про позику (Проект розвитку міської інфраструктури) між Україною та Міжнародним банком реконструкції та розвитку

1. Утворити делегацію України для участі у переговорах з Міжнародним банком реконструкції та розвитку щодо укладення Угоди про позику (Проект розвитку міської інфраструктури) між Україною та Міжнародним банком реконструкції та розвитку в такому складі:

ПОПОВ - Міністр з питань житлово-комунального

Олександр Павлович господарства України, глава делегації

КОЛИШКО - начальник відділу Департаменту

Світлана Юріївна міжнародного співробітництва Міністерства юстиції України

КОЛОСОВА - директор департаменту

Вікторія Павлівна співробітництва з міжнародними фінансовими організаціями Міністерства фінансів України

КУЛИКОВ - третій секретар Департаменту

Сергій Володимирович економічного співробітництва Міністерства закордонних справ України

КУЧЕРЕНКО - директор департаменту

Олена Василівна співробітництва з міжнародними фінансовими організаціями Міністерства економіки України

ТОЛКОВАНОВ - заступник Міністра з питань

В'ячеслав Вікторович житлово-комунального господарства України.

Дозволити главі делегації вносити в разі потреби за погодженням з Міністерством закордонних справ України зміни до складу делегації.

2. Затвердити Директиви делегації України на переговори з Міжнародним банком реконструкції та розвитку щодо укладення Угоди про позику (Проект розвитку міської інфраструктури) між Україною та Міжнародним банком реконструкції та розвитку.

Президент України В.ЮЩЕНКО
