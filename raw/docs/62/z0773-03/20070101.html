Про Тимчасовий порядок проведення взаєморозрахунків між операторами телефонних мереж загального користування та операторами мереж стільникового рухомого зв'язку

{ Із змінами, внесеними згідно з Наказами Державного комітету зв'язку та інформатизації N 261 ( z1253-03 ) від 25.12.2003 N 23 ( z0224-04 ) від 18.02.2004 }

Відповідно до статті 21 Закону України "Про зв'язок" від 16 травня 1995 року N 160/95-ВР ( 160/95-ВР ) та з метою упорядкування взаєморозрахунків між операторами телефонних мереж загального користування і стільникових рухомих мереж НАКАЗУЮ:

1. Затвердити Тимчасовий порядок проведення взаєморозрахунків між операторами телефонних мереж загального користування та операторами мереж стільникового рухомого зв'язку (далі - Тимчасовий порядок), що додається.

2. Операторам - учасникам технологічного процесу на підставі відповідних договорів забезпечити проведення взаєморозрахунків, починаючи з 19 вересня 2003 року, згідно з Тимчасовим порядком.

3. Операторам зв'язку:

3.1. Забезпечити своєчасний обмін необхідною інформацією для проведення взаєморозрахунків відповідно до затверджених ставок плати.

3.2. Надавати Держкомзв'язку щомісяця інформацію щодо обсягів вихідного та вхідного трафіку між абонентами телефонних мереж загального користування та абонентами мереж стільникового рухомого зв'язку, окремо по кожному оператору.

4. Тимчасовий Порядок встановлюється до 1 червня 2004 року. ( Пункт 4 із змінами, внесеними згідно з Наказами Державного комітету зв'язку та інформатизації N 261 ( z1253-03 ) від 25.12.2003, N 23 ( z0224-04 ) від 18.02.2004 )

5. Управлінню економічної політики (Артюшенко Л.В.):

5.1. Розмістити інформацію про введення Тимчасового порядку на веб-сайті Держкомзв'язку України.

5.2. Проаналізувати результати введення Тимчасового порядку та здійснити відповідні заходи щодо недопущення дисбалансу трафіку між учасниками ринку, можливих проявів монополізму серед його учасників та забезпечення споживачів якісними послугами електрозв'язку та підготувати пропозиції щодо подальшого застосування Тимчасового порядку через два місяця після його введення.

6. Контроль за виконанням наказу покласти на першого заступника Голови Л.Нетудихату.

Голова О.В.Яценко

ЗАТВЕРДЖЕНО Наказ Державного комітету зв'язку та інформатизації України 03.09.2003 N 166

Зареєстровано в Міністерстві юстиції України 8 вересня 2003 р. за N 773/8094

ТИМЧАСОВИЙ ПОРЯДОК проведення взаєморозрахунків між операторами телефонних мереж загального користування та операторами мереж стільникового рухомого зв'язку

1. Загальні положення

1.1. Цей Тимчасовий порядок встановлює загальні принципи взаєморозрахунків між операторами місцевого (проводового), міжміського телефонного зв'язку та операторами мереж стільникового рухомого телефонного зв'язку за кодом NDC - учасниками технологічного процесу при здійсненні викликів від телефонних мереж загального користування до стільникових рухомих телефонних мереж та від стільникових рухомих до телефонних мереж загального користування.

2. Загальні принципи проведення взаєморозрахунків

2.1. Взаєморозрахунки між операторами - учасниками технологічного процесу здійснюються на підставі договорів про взаємопідключення мереж та надання послуг взаємного доступу до мереж зв'язку (загального користування, стільникового рухомого).

2.2. Оператори ведуть облік розмов абонентів:

2.2.1. Місцевого телефонного зв'язку до абонентів стільникового рухомого зв'язку, що здійснюються набором коду NDC, який належить відповідним операторам стільникового рухомого зв'язку:

- з кінцевих пристроїв усіх категорій споживачів місцевих телефонних мереж;

- з переговорних пунктів, таксофонів, що належать операторам стаціонарних мереж.

2.2.2. Стільникового рухомого зв'язку до абонентів мереж місцевого телефонного зв'язку.

2.3. Взаєморозрахунки між операторами з надання послуг місцевого, міжміського та стільникового рухомого телефонного зв'язку проводяться за даними трафіку, який фіксується у точках взаємопідключення мереж.

2.4. Тариф за доступ абонентів місцевої телефонної мережі загального користування до мереж операторів стільникового рухомого зв'язку встановлюється Держкомзв'язку України згідно з постановою Кабінету Міністрів України від 25 грудня 1996 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)".

2.5. Взаєморозрахунки між операторами телефонних мереж та операторами стільникового рухомого зв'язку за вихід абонентів телефонної мережі на мережу стільникового рухомого зв'язку здійснюються у співвідношенні 50/50 від затвердженого тарифу Держкомзв'язку України, якщо інше не передбачене договором між цими операторами - учасниками технологічного процесу.

2.5.1. Розподіл доходів між операторами телефонних мереж загального користування здійснюється на договірних засадах.

2.6. Взаєморозрахунки між операторами стільникового рухомого зв'язку та операторами телефонних мереж загального користування за вихід абонентів стільникового рухомого зв'язку на мережі операторів місцевого телефонного зв'язку здійснюються таким чином:

2.6.1. При безпосередньому виході абонентів стільникового рухомого зв'язку на мережі операторів місцевого телефонного зв'язку розрахункова такса, що сплачується операторам місцевого телефонного зв'язку, встановлюється у розмірі 0,11 грн. (без ПДВ), якщо інше не передбачено договорами.

2.6.2. При виході абонентів стільникового рухомого зв'язку на мережі операторів місцевого телефонного зв'язку через операторів міжміського, міжнародного телефонного зв'язку розрахункова такса, що сплачується операторам міжміського, міжнародного телефонного зв'язку, встановлюється у розмірі 0,25 грн. (без ПДВ), у тому числі операторам місцевого телефонного зв'язку - 0,11 грн. (без ПДВ), якщо інше не передбачено договорами.
