ЗАТВЕРДЖЕНО Наказ МЗС України 05.02.2007 N 15

Зареєстровано в Міністерстві юстиції України 19 лютого 2007 р. за N 148/13415

ПОРЯДОК оформлення тимчасового відрядження дипломатичних службовців для призначення на посади дипломатичних радників у державних органах

{ Заголовок Порядку із змінами, внесеними згідно з Наказом Міністерства закордонних справ N 170 ( z0607-25 ) від 04.04.2025 }

{ У тексті Порядку слова "працівник", "центральний орган виконавчої влади" у всіх відмінках та числах замінено словами "службовець", "державний орган" у відповідних відмінках та числах відповідно згідно з Наказом Міністерства закордонних справ N 170 ( z0607-25 ) від 04.04.2025 }

1. Цей Порядок розроблений відповідно до Указу Президента України від 31 грудня 2005 року N 1901 ( 1901/2005 ) "Про Положення про дипломатичного радника державного органу".

2. Порядок визначає механізм та процедуру оформлення тимчасового відрядження дипломатичних службовців для призначення на посади дипломатичних радників державних органів.

3. Тимчасове відрядження дипломатичних службовців до державних органів для призначення на посади дипломатичних радників (далі - дипломатичні радники) здійснюється за наказом Міністра закордонних справ України для виконання дипломатичних функцій після погодження кандидатур з керівниками цих органів.

4. На період виконання зазначених функцій дипломатичні радники залишаються на дипломатичній службі і на них поширюється дія Закону України "Про дипломатичну службу" ( 2728-14 ).

5. Подання на погодження кандидатур на посади дипломатичних радників готує служба управління персоналом МЗС.

{ Пункт 5 із змінами, внесеними згідно з Наказом Міністерства закордонних справ N 170 ( z0607-25 ) від 04.04.2025 }

6. У поданні, викладеному в довільній формі, зазначаються прізвище, ім'я, по батькові (за наявності), дата народження, громадянство, займана посада, стаж роботи, відомості про перебування в кадровому резерві, ділові якості, рівень володіння іноземними мовами. До подання додається біографічна довідка.

{ Пункт 6 із змінами, внесеними згідно з Наказом Міністерства закордонних справ N 170 ( z0607-25 ) від 04.04.2025 }

7. Термін погодження відповідним державним органом кандидатур на посади дипломатичних радників не може перевищувати п'яти календарних днів з дати отримання відповідного подання.

8. Призначення на посади дипломатичних радників здійснюється за наказом керівника відповідного державного органу, про що письмово протягом трьох днів повідомляється Міністру закордонних справ України. Одночасно надсилається копія наказу про призначення дипломатичного радника.

9. Відкликання дипломатичних радників з тимчасового відрядження здійснюється за наказом Міністра закордонних справ України після письмового погодження з керівником відповідного державного органу.

10. Дипломатичні радники можуть бути відкликані Міністром закордонних справ України у випадках, передбачених Законом України "Про дипломатичну службу" ( 2728-14 ).

11. Дипломатичні радники за наказом керівника відповідного державного органу в семиденний строк після надходження наказу з МЗС про їхнє відкликання звільняються з посад.

{ Пункт 11 із змінами, внесеними згідно з Наказом Міністерства закордонних справ N 170 ( z0607-25 ) від 04.04.2025 }

12. Копії наказів про звільнення дипломатичних радників надсилаються до МЗС в установленому порядку.

{ Пункт 12 із змінами, внесеними згідно з Наказом Міністерства закордонних справ N 170 ( z0607-25 ) від 04.04.2025 }

13. Усі записи до трудової книжки та особової справи під час тимчасового відрядження дипломатичних службовців уносяться службою управління персоналом МЗС на підставі документів, отриманих від державних органів.

{ Пункт 13 із змінами, внесеними згідно з Наказом Міністерства закордонних справ N 170 ( z0607-25 ) від 04.04.2025 }
