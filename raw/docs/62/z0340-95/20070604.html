N 311 від 18.09.95 Зареєстровано в Міністерстві м.Київ юстиції України 25 вересня 1995 р. vd950918 vn311 за N 340/876

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 405 ( z0537-07 ) від 15.05.2007 }

Про затвердження Тарифів на перевезення пасажирів і багажу залізничним транспортом в міждержавному сполученні

{ Із змінами, внесеними згідно з Наказом Міністерства транспорту N 125 ( z0165-97 ) від 01.04.97 }

Згідно з Постановою Кабінету Міністрів України від 13 лютого 1995 року N 109 ( 109-95-п ) "Про уточнення повноважень центральних органів державної виконавчої влади, Уряду Автономної Республіки Крим та виконкомів місцевих Рад у галузі ціноутворення" та з метою більш повного відшкодування витрат залізниць України, НАКАЗУЮ:

1. Затвердити та ввести в дію з 1 жовтня 1995 року Тарифи на перевезення пасажирів і багажу залізничним транспортом в міждержавному сполученні. ( Тарифи відсутні в БД "Право" - ( Тарифи втратили чинність на підставі Наказу Міністерства транспорту N 125 ( z0165-97 ) від 01.04.1997 )

2. Укрзалізниці (Слободян А.В.) та начальникам залізниць України забезпечити своєчасне введення Тарифів в дію та правильність їх застосування.

3. Управлінню економічної політики та прогнозування (Бурдей В.В.) разом з управлінням нормативних актів та правової роботи (Наапетян М.Р.) в установленому порядку зареєструвати зазначені Тарифи в Міністерстві юстиції України.

4. З введенням в дію цього наказу втрачають чинність Тарифи на перевезення пасажирів і багажу залізничним транспортом, затверджені наказом Міністерства транспорту України від 22.06.95 N 239 ( z0189-95 ) "Про затвердження Тарифів на перевезення пасажирів і багажу залізничним транспортом в міждержавному сполученні".

5. Контроль за виконанням цього наказу покласти на Першого заступника міністра транспорту України - Генерального директора Укрзалізниці Л.Л.Железняка.
