ПОСТАНОВА від 18 січня 2006 р. N 26 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Деякі питання Секретаріату Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 25 липня 2005 р. N 640 ( 640-2005-п ) "Про утворення Центру комунікації" (Офіційний вісник України, 2005 р., N 30, ст. 1819).

2. В абзаці другому пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) "Питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2000 р., N 4, ст. 110; 2005 р., N 50, ст. 3129) цифри "1065" замінити цифрами "1105".

3. Міністрові Кабінету Міністрів України утворити у складі Секретаріату Кабінету Міністрів України структурний підрозділ з питань комунікації громадськості та влади.
