КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 березня 2003 р. N 415 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1044 ( 1044-2008-п ) від 03.12.2008 }

Про передачу Укрзалізниці повноважень з управління державними корпоративними правами відкритих акціонерних товариств

Кабінет Міністрів України постановляє:

1. Прийняти пропозицію Міністерства транспорту щодо:

передачі Укрзалізниці повноважень з управління державними корпоративними правами відкритих акціонерних товариств згідно з додатком;

ліквідації в установленому порядку державної холдингової компанії "Укрзалізреммаш".

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 18 травня 2001 р. N 540 ( 540-2001-п ) "Про створення державної холдингової компанії "Укрзалізреммаш" (Офіційний вісник України, 2001 р., N 21, ст. 937).
