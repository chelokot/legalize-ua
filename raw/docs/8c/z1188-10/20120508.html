Зареєстровано в Міністерстві юстиції України 29 листопада 2010 р. за N 1188/18483

Про внесення змін до наказу МОЗ від 25.11.2004 N 569

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства охорони здоров'я N 933 ( z1142-10 ) від 01.11.2010, до якого вносились зміни }

Відповідно до Положення про Міністерство охорони здоров'я України, затвердженого Указом Президента України від 24.07.2000 N 918 ( 918/2000 ), та з метою приведення нормативно-правових актів у відповідність до вимог чинного законодавства НАКАЗУЮ:

1. У преамбулі наказу МОЗ від 25.11.2004 N 569 ( z1537-04 ) "Про затвердження обов'язкового мінімального асортименту лікарських засобів для аптек", зареєстрованого в Міністерстві юстиції України 03.12.2004 за N 1537/10136, слова та цифри "постанови Кабінету Міністрів України від 17.11.2004 N 1570 "Про затвердження Правил торгівлі лікарськими засобами в аптечних закладах" замінити словами та цифрами "Положення про Міністерство охорони здоров'я України, затвердженого Указом Президента України від 24.07.2000 N 918 ( 918/2000 )".

2. Департаменту регуляторної політики в сфері обігу лікарських засобів та продукції в системі охорони здоров'я забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Гудзенка О.П.

4. Цей наказ набирає чинності з дня офіційного опублікування.
