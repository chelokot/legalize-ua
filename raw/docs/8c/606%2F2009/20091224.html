Президент України; Указ від 07.08.2009 № 606/2009

Про внесення зміни до Переліку посадових осіб, на яких покладається виконання функцій державного експерта з питань таємниць

Стан: Втратив чинність

Ідентифікатор: 606/2009

Текст документа від 24.12.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу N 987/2009 ( 987/2009 ) від 01.12.2009 }

Про внесення зміни до Переліку посадових осіб, на яких покладається виконання функцій державного експерта з питань таємниць

Внести до розділу "Служба безпеки України" Переліку посадових осіб, на яких покладається виконання функцій державного експерта з питань таємниць, затвердженого Указом Президента України від 29 травня 2006 року N 452 ( 452/2006 ), зміну, виклавши абзац "Начальник управління охорони державної таємниці" в такій редакції:

"Начальник Департаменту охорони державної таємниці та ліцензування".

Президент України В.ЮЩЕНКО

м. Київ, 7 серпня 2009 року N 606/2009
