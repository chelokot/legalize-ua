{ Постанова втратила чинність на підставі Постанови КМ N 1004 ( 1004-2006-п ) від 24.07.2006 }

Про визначення уповноваженого банку

Кабінет Міністрів України постановляє:

1. Визначити уповноваженим банком, який обслуговує розподільчі рахунки оптового ринку електричної енергії України (далі - розподільчі рахунки), Промінвестбанк.

2. Ощадбанку забезпечити:

проведення розрахунків за спожиту електричну енергію відповідно до Положення про порядок проведення розрахунків за електричну енергію, затвердженого постановою Кабінету Міністрів України від 19 липня 2000 р. N 1136 ( 1136-2000-п ) "Про врегулювання відносин на оптовому ринку електричної енергії України", до опублікування затвердженого Національною комісією регулювання електроенергетики переліку розподільчих рахунків в установах уповноваженого банку;

перерахування залишків коштів за спожиту електричну енергію з колишніх розподільчих рахунків, відкритих в його установах, на відповідні розподільчі рахунки, відкриті в установах уповноваженого банку, протягом наступного дня після опублікування затвердженого Національною комісією регулювання електроенергетики переліку розподільчих рахунків в установах уповноваженого банку.

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 19 липня 2000 р. N 1137 ( 1137-2000-п ) "Про визначення уповноваженого банку" (Офіційний вісник України, 2000 р., N 29, ст. 1228).
