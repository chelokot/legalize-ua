ПОСТАНОВА від 25 травня 1998 р. N 738 Київ

Про розміри плати за реєстрацію статутів територіальних громад

Кабінет Міністрів України постановляє:

1. Установити такі розміри плати:

{ Абзац другий пункту 1 виключено на підставі Постанови КМ N 1168 ( 1168-2012-п ) від 19.12.2012 }

за реєстрацію статутів територіальних громад - 5 неоподатковуваних мінімумів доходів громадян;

за видачу дублікатів статутів територіальних громад - 50 відсотків суми встановленої плати. { Абзац четвертий пункту 1 в редакції Постанови КМ N 1168 ( 1168-2012-п ) від 19.12.2012 }

2. Кошти, одержані за реєстрацію статутів територіальних громад у розмірі 50 відсотків зараховуються до державного бюджету. Решта коштів зараховується на відповідний рахунок органу державної реєстрації.
