( Постанова втратила чинність на підставі Постанови КМ N 475 ( 475-92-п ) від 15.08.92 )

Про радника із зовнішньоекономічних зв'язків при Кабінеті Міністрів України

Кабінет Міністрів України постановляє:

1. Установити посаду радника із зовнішньоекономічних зв'язків при Кабінеті Міністрів України.

2. Призначити т. Пєтухова Ігоря Павловича радником із зовнішньоекономічних зв'язків при Кабінеті Міністрів України.

3. Державному секретареві Кабінету Міністрів України вирішити питання, пов'язані зі створенням робочого апарату радника із зовнішньоекономічних зв'язків при Кабінеті Міністрів України.
