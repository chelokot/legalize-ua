Про затвердження Порядку акумулювання, перерозподілу та використання коштів спеціального фонду Української державної насіннєвої інспекції

{ Із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 180 ( z0450-10 ) від 13.04.2010 }

Відповідно до розділу 11 Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04, za716-04 ) зареєстрованого в Міністерстві юстиції України 10.06.2004 за N 716/9315, НАКАЗУЮ:

1. Затвердити Порядок акумулювання, перерозподілу та використання коштів спеціального фонду Української державної насіннєвої інспекції, що додається.

2. Департаменту ринків рослинництва (Демидов О.А.) забезпечити подання цього наказу в установленому порядку на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Мельника С.І.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр Ю.Ф.Мельник

ЗАТВЕРДЖЕНО Наказ Міністерства аграрної політики України 20.10.2009 N 748

Зареєстровано в Міністерстві юстиції України 10 листопада 2009 р. за N 1049/17065

ПОРЯДОК акумулювання, перерозподілу та використання коштів спеціального фонду Української державної насіннєвої інспекції

I. Загальні положення

1.1. Цей Порядок визначає механізм акумулювання, перерозподілу та використання Українською державною насіннєвою інспекцією коштів спеціального фонду державних насіннєвих інспекцій Міністерства аграрної політики України (далі - кошти спеціального фонду).

1.2. Акумулювання коштів спеціального фонду проводиться в межах бюджетних призначень, що визначені для фінансування установ агропромислового комплексу в законі про державний бюджет України на відповідний рік, за кодом програмної класифікації видатків та кредитування державного бюджету 2801310 ( 835-17 ) "Організація і регулювання діяльності установ в системі агропромислового комплексу" для фінансування Української державної насіннєвої інспекції.

1.3. Подальший перерозподіл та використання коштів спеціального фонду проводиться з метою забезпечення фінансування Української державної насіннєвої інспекції та Державної насіннєвої інспекції Автономної Республіки Крим, обласних, районних, міських, міжрайонних державних насіннєвих інспекцій (далі - державні насіннєві інспекції), які не забезпечені або частково забезпечені коштами загального фонду державного бюджету та не мають можливості наповнити спеціальний фонд державного бюджету за рахунок власних надходжень.

{ Пункт 1.3 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 180 ( z0450-10 ) від 13.04.2010 }

II. Акумулювання коштів спеціального фонду

2.1. Державні насіннєві інспекції перераховують Українській державній насіннєвій інспекції отримані як плата за послуги, що надаються згідно з їх функціональними повноваженнями, кошти, які перевищують відповідні витрати, за умови забезпечення ресурсами заходів з виконання основних функцій бюджетних установ.

{ Пункт 2.1 в редакції Наказу Міністерства аграрної політики N 180 ( z0450-10 ) від 13.04.2010 }

2.2. Кошти перераховуються не пізніше 10 числа місяця, наступного за звітним, на підставі наказу Української державної насіннєвої інспекції.

2.3. Спрямування державними насіннєвими інспекціями коштів спеціального фонду до Української державної насіннєвої інспекції здійснюється лише в межах однієї програми та однієї групи власних надходжень відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04 ), зареєстрованого в Мін'юсті 10.06.2004 за N 716/9315 (із змінами).

{ Пункт 2.3 в редакції Наказу Міністерства аграрної політики N 180 ( z0450-10 ) від 13.04.2010 }

2.4. Кошти зараховуються на відповідний рахунок з обліку власних надходжень Української державної насіннєвої інспекції.

III. Використання акумульованих коштів

3.1. Кошти спеціального фонду використовуються згідно з кошторисом, який складений та затверджений відповідно до постанови Кабінету Міністрів України від 28.02.2002 N 228 ( 228-2002-п ) "Про затвердження Порядку складання, розгляду, затвердження та основних вимог до виконання кошторисів бюджетних установ".

3.2. Розподіл акумульованих коштів здійснюється Українською державною насіннєвою інспекцією на підставі обґрунтованих заявок державних насіннєвих інспекцій стосовно необхідності виділення коштів за погодженням з Міністерством аграрної політики України.

3.3. Акумульовані та розподілені Українською державною насіннєвою інспекцією кошти спеціального фонду використовуються відповідно до закону про державний бюджет України на відповідний рік за напрямами, визначеними постановою Кабінету Міністрів України від 17.05.2002 N 659 ( 659-2002-п ) "Про затвердження переліку груп власних надходжень бюджетних установ, вимог щодо їх утворення та напрямків використання".

3.4. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється згідно із законодавством.

3.5. Акумульовані кошти спеціального фонду можуть витрачатись на заходи, необхідні для виконання функцій державних насіннєвих інспекцій, які не забезпечені або частково забезпечені коштами загального фонду, а саме: придбання, будівництво, реконструкція та утримання адміністративних та службових приміщень, придбання обладнання, предметів довгострокового користування, препаратів і реактивів, оплата праці, оплата послуг із капітального ремонту та реконструкції адміністративних та службових приміщень, оплата членських внесків в Міжнародну асоціацію з контролю за якістю насіння (ICTA) та за участь у Схемі по насінню зернових і Схемі по насінню кукурудзи й сорго Організації економічного співробітництва та розвитку, організація друку етикеток, що використовуються при маркуванні партій насіння сільськогосподарських культур.

{ Пункт 3.5 в редакції Наказу Міністерства аграрної політики N 180 ( z0450-10 ) від 13.04.2010 }

IV. Відображення в бухгалтерському обліку та звітності господарських операцій

4.1. Операції про надходження та використання коштів, отриманих як плата за послуги, що надаються бюджетними установами, відображаються у бухгалтерському обліку та фінансовій звітності за формами і в порядку, встановленими Державним казначейством України.

4.2. Облік операцій з акумулювання та перерозподілу коштів, що надходять від державних насіннєвих інспекцій, ведеться на субрахунках в Українській державній насіннєвій інспекції згідно з Планом рахунків бухгалтерського обліку бюджетних установ, затвердженим наказом Головного управління Державного казначейства України від 10.12.99 N 114 ( z0890-99 ), зареєстрованим у Міністерстві юстиції України 20.12.99 за N 890/4183.

4.3. Використання коштів, що фактично надійшли на спеціальний реєстраційний рахунок, здійснюється виключно в межах затвердженого кошторису на відповідний рік.

4.4. Кошти, що не були використані в поточному році, переходять на наступний рік і використовуються згідно із затвердженим кошторисом наступного року.

Директор Департаменту ринків рослинництва О.А.Демидов
