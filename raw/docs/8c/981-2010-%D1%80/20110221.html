РОЗПОРЯДЖЕННЯ від 28 квітня 2010 р. N 981-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 151-р ( 151-2011-р ) від 21.02.2011 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 2 березня 2010 р. N 348

На часткову зміну абзацу другого розпорядження Кабінету Міністрів України від 2 березня 2010 р. N 348 ( 348-2010-р ) уповноважити Віце-прем'єр-міністра України Семиноженка Володимира Петровича підписати Меморандум про взаєморозуміння між Кабінетом Міністрів України та Європейською Організацією Ядерних Досліджень (ЦЕРН) стосовно науково-технічного співробітництва.
