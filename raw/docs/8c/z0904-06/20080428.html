Про затвердження форм Річного плану закупівель товарів, робіт і послуг за державні кошти

{ Із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0468-07 ) від 12.04.2007 }

Відповідно до статті 2-2, частини третьої статті 3-1 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ), Закону України "Про Антимонопольний комітет України" ( 3659-12 ) та з метою забезпечення державного контролю за додержанням законодавства щодо закупівель Антимонопольний комітет України ПОСТАНОВИВ:

1. Затвердити форми Річного плану закупівель товарів, робіт і послуг за державні кошти такі, що додаються:

форму Річного плану діяльності тендерного комітету щодо організації та проведення процедур державних закупівель (додається);

Інструкцію стосовно форми Річного плану діяльності тендерного комітету щодо організації та проведення процедур державних закупівель (додається);

форму Річного плану державних закупівель, який підлягає оприлюдненню (додається) ( z0905-06 );

Інструкцію щодо форми Річного плану державних закупівель, який підлягає оприлюдненню (додається) ( z0905-06 );

форму Річного плану здійснення закупівель товарів за рахунок коштів державного бюджету на умовах міжвідомчої координації (додається) ( z0906-06 );

Інструкцію щодо форми Річного плану здійснення закупівель товарів за рахунок коштів державного бюджету на умовах міжвідомчої координації (додається) ( z0906-06 ).

2. Департаменту конкурентної політики забезпечити в установленому порядку реєстрацію цього розпорядження в Міністерстві юстиції України.

Голова Комітету О.Костусєв

Зареєстровано в Міністерстві юстиції України 1 серпня 2006 р. за N 904/12778

ІНСТРУКЦІЯ стосовно форми Річного плану діяльності тендерного комітету щодо організації та проведення процедур державних закупівель

1. У разі, коли очікувана вартість предмета закупівлі є нижчою за суми, зазначені в частині першій статті 2 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ), такий предмет закупівлі за позиціями плану слід відображати в окремому додатку до Річного плану діяльності тендерного комітету щодо організації та проведення процедур державних закупівель у довільній формі із зазначенням найменування предмета закупівлі та його очікуваної вартості. Позиції в графах 1, 3, 4, 8 і 9 Річного плану є обов'язковими для заповнення, інші позиції форми плану та додаткові позиції на розсуд тендерного комітету рекомендується заповнювати залежно від особливостей організації його роботи.

Примірник Річного плану діяльності тендерного комітету, який затверджується замовником не пізніше ніж у місячний строк після затвердження кошторису (програми, плану використання державних коштів), зміни до нього надсилаються до спеціально уповноваженого центрального органу виконавчої влади з питань координації закупівель товарів, робіт і послуг (далі - уповноважений орган) протягом 15 календарних днів з дати його затвердження. { Пункт 1 доповнено абзацом згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0468-07 ) від 12.04.2007 }

Змінами до Річного плану вважаються будь-які зміни, внесені до плану (виключення з плану закупівлі, включення до плану закупівлі, зміна назви предмета закупівлі тощо). Зміни до Річного плану діяльності тендерного комітету направляються до уповноваженого органу у формі повного річного плану діяльності тендерного комітету з урахуванням змін. { Пункт 1 доповнено абзацом згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0468-07 ) від 12.04.2007 }

2. Щодо графи 1 Форми плану

Предмет закупівлі визначається у порядку, затвердженому Міжвідомчою комісією з питань державних закупівель.

{ Пункт 2 в редакції Розпорядження Антимонопольного комітету N 138-р ( z0468-07 ) від 12.04.2007 }

3. Щодо графи 2 Форми плану

На розсуд замовника - розпорядника (одержувача) бюджетних коштів указується код згідно з економічною класифікацією видатків (КЕКВ) і код згідно з програмною класифікацією видатків (КПКВ), затвердженими наказом Міністерства фінансів України від 27.12.2001 N 604 ( v0604201-01 ).

4. Щодо графи 3 Форми плану

Джерело фінансування закупівлі визначається відповідно до абзацу п'ятого статті 1 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

5. Щодо графи 4 Форми плану

Очікувана вартість предмета закупівлі вказується в гривнях. У разі, коли закуповуються роботи, виконання яких згідно з проектно-кошторисною документацією здійснюватиметься протягом тривалого періоду (більше року), указується повна вартість виконання робіт відповідно до проекту та період його реалізації. { Абзац другий пункту 5 із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0468-07 ) від 12.04.2007 }

6. Щодо графи 5 Форми плану

Указується інформація про частини предмета закупівлі, на які подаватимуть окремі тендерні пропозиції, якщо тендерний комітет має намір визначати окремі частини предмета закупівлі. { Абзац другий пункту 6 із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0468-07 ) від 12.04.2007 }

7. Щодо графи 7 Форми плану

На розсуд замовника вказується код товару або послуги згідно з Державним класифікатором продукції та послуг ДК 016-97 ( v1822217-97, v2822217-97, v3822217-97, v5822217-97 ), затвердженим наказом Державного комітету України по стандартизації, метрології та сертифікації від 30.12.97 N 822 ( v0822217-97 ).

8. Щодо графи 9 Форми плану

Строком початку процедури закупівлі вважається очікуваний місяць початку проведення процедури закупівлі.

{ Пункт 8 із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0468-07 ) від 12.04.2007 }

9. Щодо графи 10 Форми плану

Указується назва підрозділу (у разі здійснення закупівель тендерним комітетом для проведення процедур закупівлі на засадах міжвідомчої координації - найменування розпорядника (одержувача) бюджетних коштів), який може залучатись до підготовки тендерної документації.

10. Щодо графи 11 Форми плану

Строк дії договору замовник заповнює як період, у якому планується провести закупівлю (щонайменше квартал).

{ Інструкцію доповнено пунктом 10 згідно з Розпорядженням Антимонопольного комітету N 138-р ( z0468-07 ) від 12.04.2007 }

11. Щодо графи 12 Форми плану

Замовник може зазначити таку інформацію:

найменування головного розпорядника державних коштів;

{ Абзац четвертий пункту 11 виключено на підставі Розпорядження Антимонопольного комітету N 138-р ( z0468-07 ) від 12.04.2007 }

обґрунтування вибору процедури закупівлі;

намір залучення сторонніх організацій, обґрунтування та умови такого залучення;

підстави та обґрунтування внесення змін до плану;

інші зауваження та коментарі.
