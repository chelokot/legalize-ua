Президент України; Указ від 24.03.2008 № 257/2008

Про зупинення дії деяких положень постанови Кабінету Міністрів України від 23 січня 2008 року N 23, розпоряджень Кабінету Міністрів України від 27 лютого 2008 року N 349-р і N 350-р

Стан: Втратив чинність

Ідентифікатор: 257/2008

Текст документа від 24.03.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії деяких положень постанови Кабінету Міністрів України від 23 січня 2008 року N 23, розпоряджень Кабінету Міністрів України від 27 лютого 2008 року N 349-р і N 350-р

{ Додатково див. Конституційне подання Президента ( n0002100-08 ) від 24.03.2008 }

Кабінет Міністрів України видав 23 січня 2008 року постанову N 23 ( 23-2008-п ) "Про деякі питання Державної іпотечної установи", 27 лютого 2008 року розпорядження N 349-р ( 349-2008-р ) "Про визнання таким, що втратило чинність, розпорядження Кабінету Міністрів України від 8 листопада 2007 р. N 976" та N 350-р ( 350-2008-р ) "Про скасування розпорядження Кабінету Міністрів України від 13 квітня 2007 р. N 190".

Постановою Кабінету Міністрів України від 23 січня 2008 року N 23 ( 23-2008-п ) "Про деякі питання Державної іпотечної установи" передбачено передачу Державної іпотечної установи зі сфери управління Державного агентства України з інвестицій та інновацій до сфери управління Міністерства фінансів України (пункт 2), у зв'язку з чим внесено зміни до постанови Кабінету Міністрів України від 8 жовтня 2004 року N 1330 ( 1330-2004-п ) "Деякі питання Державної іпотечної установи" (пункт 3) та визнано такою, що втратила чинність, постанову Кабінету Міністрів України від 19 вересня 2007 року N 1140 ( 1140-2007-п ) "Про віднесення Державної іпотечної установи до сфери управління Державного агентства з інвестицій та інновацій" (пункт 4).

Розпорядженням Кабінету Міністрів України від 27 лютого 2008 року N 349-р ( 349-2008-р ) визнано таким, що втратило чинність, розпорядження Кабінету Міністрів України від 8 листопада 2007 року N 976 ( 976-2007-р ) "Про схвалення Концепції Державної цільової економічної програми модернізації ринків капіталу в Україні". Зазначена Концепція ( 976-2007-р ) передбачала заходи щодо прискорення формування сучасної ринкової інфраструктури шляхом її інноваційного розвитку (модернізації), поліпшення інвестиційного клімату, розвитку фондового ринку України, запобігання непродуктивному відтоку капіталів.

Розпорядженням Кабінету Міністрів України від 27 лютого 2008 року N 350-р ( 350-2008-р ) скасовано розпорядження Кабінету Міністрів України від 13 квітня 2007 року N 190 ( 190-2007-р ) "Про передачу будинку на Контрактовій площі, 4, у м. Києві (Гостинного двору)", яким було передбачено передачу будинку на Контрактовій площі, 4, у м. Києві (Гостинного двору) до сфери управління Державного агентства України з інвестицій та інновацій для розміщення його центрального апарату.

Прийняття Кабінетом Міністрів України зазначених рішень створює передумови для погіршення роботи, звуження сфери діяльності Державного агентства України з інвестицій та інновацій, яке є спеціально уповноваженим центральним органом виконавчої влади у сфері інноваційної діяльності. Між тим Державне агентство України з інвестицій та інновацій утворено для формування та забезпечення реалізації державної політики у сфері інвестицій та інноваційної діяльності, створення національної інноваційної системи для забезпечення проведення ефективної державної інноваційної політики, координації роботи центральних органів виконавчої влади у сфері інноваційної діяльності.

Зважаючи на наведене, виконання зазначених актів Кабінету Міністрів України неминуче призведе до системних погіршень у сфері інвестиційної та інноваційної діяльності. Законом України "Про основи національної безпеки України" ( 964-15 ) зниження інвестиційної та інноваційної активності і науково-технічного та технологічного потенціалу, скорочення досліджень на стратегічно важливих напрямах інноваційного розвитку визначено серед основних реальних та потенційних загроз національній безпеці України в економічній сфері (стаття 7).

Таким чином, названі акти Кабінету Міністрів України не відповідають частині першій статті 17 Конституції України ( 254к/96-ВР ), за якою забезпечення економічної безпеки держави є її найважливішою функцією.

Ураховуючи наведене та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію:

положень пунктів 2, 3, 4 постанови Кабінету Міністрів України від 23 січня 2008 року N 23 ( 23-2008-п ) "Про деякі питання Державної іпотечної установи" в частині віднесення Державної іпотечної установи до сфери управління Міністерства фінансів України;

розпорядження Кабінету Міністрів України від 27 лютого 2008 року N 349-р ( 349-2008-р ) "Про визнання таким, що втратило чинність, розпорядження Кабінету Міністрів України від 8 листопада 2007 р. N 976";

розпорядження Кабінету Міністрів України від 27 лютого 2008 року N 350-р ( 350-2008-р ) "Про скасування розпорядження Кабінету Міністрів України від 13 квітня 2007 р. N 190".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
