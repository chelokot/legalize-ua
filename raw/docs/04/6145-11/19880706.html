Президія Верховної Ради УРСР; Указ від 06.07.1988 № 6145-XI

Про перетворення союзно-республіканського Державного комітету Української РСР по забезпеченню нафтопродуктами в республіканський Державний комітет Української РСР по забезпеченню нафтопродуктами

Стан: Не застосовується на території України

Ідентифікатор: 6145-11

Текст документа від 06.07.1988:

УКАЗ ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

Про перетворення союзно-республіканського Державного комітету Української РСР по забезпеченню нафтопродуктами в республіканський Державний комітет Української РСР по забезпеченню нафтопродуктами

( Відомості Верховної Ради УРСР, 1988, N 29, ст. 683 )

Президія Верховної Ради Української РСР постановляє:

Перетворити союзно-республіканський Державний комітет Української РСР по забезпеченню нафтопродуктами в республіканський Державний комітет Української РСР по забезпеченню нафтопродуктами.
