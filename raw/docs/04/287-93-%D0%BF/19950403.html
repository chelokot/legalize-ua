Про такси для обчислення розміру шкоди, заподіяної порушенням законодавства про природно-заповідний фонд України

( Із змінами, внесеними згідно з Постановою КМ N 239 ( 239-95-п ) від 03.04.95 )

З метою посилення охорони і використання територій та об'єктів природно-заповідного фонду, відтворення їх природних комплексів Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 239 ( 239-95-п ) від 03.04.95 )

( Пункт 2 втратив чинність на підставі Постанови КМ N 239 ( 239-95-п ) від 03.04.95 )

3. У додатках N 1, 2, 7 і 10 до постанови Ради Міністрів УРСР від 25 травня 1982 р. N 301 "Про відповідальність за порушення лісового законодавства" (ЗП УРСР, 1982 р., N 6, ст. 56) вилучити слова "ліси заповідників, національних і природних парків, заповідні лісові ділянки", "природні пам'ятки", "лісах заповідників, національних і природних парків, заповідних лісових ділянок", "природних пам'ятках".

4. Ця постанова набуває чинності з 1 травня 1993 року.
