ПОСТАНОВА від 2 листопада 1995 р. N 880 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 604 ( 604-2020-п ) від 15.07.2020 }

Про затвердження Переліку військового майна, нестача або розкрадання якого відшкодовується винними особами у кратному співвідношенні до його вартості

Відповідно до Положення про матеріальну відповідальність військовослужбовців за шкоду, заподіяну державі, затвердженого постановою Верховної Ради від 23 червня 1995 р. N 243 ( 243/95-ВР ), Кабінет Міністрів України постановляє:

Затвердити Перелік військового майна, нестача або розкрадання якого відшкодовується винними особами у кратному співвідношенні до його вартості, що додається.
