Про затвердження аеропортових зборів за обслуговування

повітряних суден у Міжнародному аеропорту "Бориспіль"

( Із змінами, внесеними згідно з Наказами Міністерства транспорту N 350 ( z0502-99 ) від 06.07.99 N 600 ( z0889-99 ) від 17.12.99 N 312 ( z0467-01 ) від 23.05.2001 N 404 ( z0534-02 ) від 17.06.2002 )

Відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та рекомендацій Міжнародної організації цивільної авіації (ІКАО) НАКАЗУЮ:

1. Затвердити аеропортові збори за обслуговування повітряних суден у Міжнародному аеропорту "Бориспіль" (додаються).

2. Дозволити Міжнародному аеропорту "Бориспіль" при укладенні угод (договорів) з авіакомпаніями України на аеропортове обслуговування повітряних суден при виконанні регулярних та чартерних міжнародних рейсів у відповідності з міжурядовими угодами про повітряне сполучення зменшувати розмір аеропортових зборів до 30%. ( Пункт 2 із змінами, внесеними згідно з Наказом Мінтрансу N 404 ( z0534-02 ) від 17.06.2002 )

3. Управлінню тарифної та цінової політики (Осадча Т.М.) разом з Головним управлінням правового забезпечення діяльності транспорту (Логінова Л.М.) в установленому порядку зареєструвати даний наказ у Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на Першого заступника Міністра транспорту України - Голову Державної авіаційної адміністрації В.О.Максимова.

Міністр В.І.Череп

Затверджено Наказ Міністерства транспорту України 29.12.97 N 459

Аеропортові збори за обслуговування повітряних суден у Міжнародному аеропорту "Бориспіль"

1. За аеропортове обслуговування повітряних суден, пов'язане із забезпеченням: посадки-зльоту, обслуговування пасажирів у терміналах, наднормативної стоянки пасажирського повітряного судна, авіаційної безпеки пасажирських рейсів, стягуються аеропортові збори за встановленими розмірами.

2. Розміри аеропортових зборів

2.1. Збір за посадку-зліт повітряних суден (без обслуговування повітряного руху) становить:

- 10,5 USD за 1 тонну максимально дозволеної злітної ваги (МЗВ) повітряного судна (ПС).

Збір в нічний час збільшується:

- на 24%, якщо в нічний час здійснюється посадка та/або зліт.

Нічний час встановлюється (час місцевий):

- з 01 квітня по 30 вересня з 20.00 до 06.00 годин;

- з 01 жовтня по 31 березня з 18.00 до 08.00 годин.

При виконанні тренувальних, випробувальних, технічних тощо польотів над злітно-посадочною смугою (ЗПС) кожні 5 (п'ять) "заходів" на посадку враховуються як 1 (одна) посадка, але якщо при цьому включається світлосигнальна система, то кожні 2 (два) "заходи" враховуються як 1 (одна) посадка, навіть коли літак не торкається поверхні ЗПС.

Від сплати збору за посадку-зліт ПС звільняються рейси під літером "А", а також польоти з метою обльоту авіаційної техніки, тренувальні, випробувальні та перегінні польоти для забезпечення виконання рейсів під літером "А", які виконує Державне авіаційне підприємство "Україна". ( Підпункт 2.1 пункту 2 доповнено абзацом згідно з Наказом Мінтрансу N 312 ( z0467-01 ) від 23.05.2001 )

( Підпункт 2.1 пункту 2 із змінами, внесеними згідно з Наказом Мінтрансу N 600 ( z0889-99 ) від 17.12.99 )

2.2. Збір за обслуговування пасажирів у терміналах аеропорту до початку реєстрації за кожного відправленого пасажира становить:

з терміналу "А" - 5,00 USD;

з терміналу "В" та "C" - 13.00 USD. ( Абзац третій пункту 2.2 із змінами, внесеними згідно з Наказом Мінтрансу N 350 ( z0502-99 ) від 06.07.99 )

Від сплати пасажирського збору звільняються: транзитні пасажири; діти до 2 років; пасажири із сервісними квитками авіакомпаній; пасажири рейсів, що виконуються виключно для перевезення королівських осіб, голів держав і урядів; пасажири рейсів із метою пошуку та рятування, які виконуються за завданнями компетентних органів; пасажири рейсів під літером "A", які виконує Державне авіаційне підприємство "Україна". ( Абзац четвертий пункту 2.2 із змінами, внесеними згідно з Наказом Мінтрансу N 350 ( z0502-99 ) від 06.07.99 )

2.3. Збір за наднормативну стоянку пасажирського повітряного судна становить:

- 12% від збору за посадку-зліт повітряного судна в денний час за кожну добу або її частину.

Нормативна (без додаткової оплати) стоянка для пасажирських ПС дорівнює 3 години. Збір не стягується при затриманні ПС з вини працівників аеропорту, а також при виконанні рейсів під літером "A", які виконує Державне авіаційне підприємство "Україна". ( Абзац третій пункту 2.3 із змінами, внесеними згідно з Наказом Мінтрансу N 350 ( z0502-99 ) від 06.07.99 )

2.4. Збір за забезпечення авіаційної безпеки становить: за кожного відправленого пасажира - 4,00 USD.

Від сплати збору за забезпечення авіаційної безпеки звільняються пасажири із сервісними квитками авіакомпаній, транзитні пасажири, а також пасажири рейсів під літером "A", які виконує Державне авіаційне підприємство "Україна". ( Абзац другий підпункту 2.4 пункту 2 із змінами, внесеними згідно з Наказами Мінтрансу N 350 ( z0502-99 ) від 06.07.99, N 312 ( z0467-01 ) від 23.05.2001 )

3. Застосування аеропортових зборів

3.1. До зборів за аеропортове обслуговування при виконанні міжнародних рейсів застосовується коефіцієнт 1,0.

При виконанні рейсів у межах України розміри аеропортових зборів становлять:

------------------------------------------------------------------

| Вид збору | Розмір збору |

|---------------------------------+------------------------------|

|Збір за посадку-зліт, за 1 т МЗВ | 1,05 USD |

|---------------------------------+------------------------------|

|Пасажирський збір (термінал "А"),| |

|за 1 пасажира | 0,50 USD |

|---------------------------------+------------------------------|

|Збір за забезпечення авіаційної | |

|безпеки (термінал "А"), | |

|за 1 пасажира | 0,40 USD |

|---------------------------------+------------------------------|

|Збір за наднормативну стоянку ПС |20 % збору, визначеного згідно|

| | з підпунктом 2.3 пункту 2 |

------------------------------------------------------------------

Примітка.

Абзац другий підпунктів 2.1. та 2.2., абзац перший підпункту 2.4. при визначенні аеропортових зборів для рейсів у межах України не застосовується.

Рейс вважається міжнародним, якщо він починається та/або закінчується за межами державного кордону України, незалежно від кількості проміжних посадок на території України.

( Підпункт 3.1 пункту 3 із змінами, внесеними згідно з Наказами Мінтрансу N 312 ( z0467-01 ) від 23.05.2001, N 404 ( z0534-02 ) від 17.06.2002 )

3.2. Аеропортові збори за обслуговування повітряних суден встановлені без врахування податку на додану вартість.

3.3. Сплата аеропортових зборів здійснюється відповідно до чинного законодавства України щодо валютного регулювання.
