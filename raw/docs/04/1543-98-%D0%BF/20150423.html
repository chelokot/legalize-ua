Про термін виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах у разі виготовлення стандартних зразків-еталонів платини і сплавів металів платинової групи

Стан: Втратив чинність

Ідентифікатор: 1543-98-п

Текст документа від 23.04.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 вересня 1998 р. N 1543 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 198 ( 198-2015-п ) від 15.04.2015 }

Про термін виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах у разі виготовлення стандартних зразків-еталонів платини і сплавів металів платинової групи

( Із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )

Враховуючи технологічні особливості виготовлення стандартних зразків-еталонів платини і сплавів металів платинової групи, відповідно до статті 5 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ) Кабінет Міністрів України постановляє:

Установити термін виконання операцій з давальницькою сировиною у разі виготовлення стандартних зразків-еталонів платини і сплавів металів платинової групи (код УКТ ЗЕД 9031 80 99 00) до 500 днів з дня оформлення вивізної вантажної митної декларації.

( Постанова із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )
