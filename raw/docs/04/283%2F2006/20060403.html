УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Позначку "Опублікуванню не підлягає" знято Указом Президента N 1209/2008 ( 1209/2008 ) від 26.12.2008 }

Про визнання такими, що втратили чинність, деяких положень Указу Президента України від 22 жовтня 2002 року N 937

Визнати такими, що втратили чинність, абзац другий статті 1 та статтю 2 Указу Президента України від 22 жовтня 2002 року N 937 ( 937/2002 ) "Про посилення контролю за виконанням актів Президента України щодо реалізації державної політики у сфері військово-технічного співробітництва".

Президент України В.ЮЩЕНКО

м. Київ, 3 квітня 2006 року N 283/2006
