Кабінет Міністрів України; Розпорядження від 14.04.1997 № 200-р

Про збереження права на медичне обслуговування за Пинзеником В.М. у зв'язку з його відставкою

Стан: Втратив чинність

Ідентифікатор: 200-97-р

Текст документа від 04.12.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 квітня 1997 р. N 200-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 673 ( 673-2014-п ) від 26.11.2014 }

У зв'язку з відставкою Віце-прем'єр-міністра України Пинзеника Віктора Михайловича:

1. Зберегти право:

на медичне та санаторно-курортне лікування за ним та його дружиною у закладах Лікувально-оздоровчого об'єднання при Кабінеті Міністрів України;

користування двома кімнатами у будинку відпочинку Господарського управління Кабінету Міністрів України.

2. Надати Пинзенику В.М. право виклику автомашини з автомобільного підприємства Господарського управління Кабінету Міністрів України в межах визначеної кількості годин.

Прем'єр-міністр України П.ЛАЗАРЕНКО
