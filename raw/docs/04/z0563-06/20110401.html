25.04.2006 N 216

Зареєстровано в Міністерстві юстиції України 17 травня 2006 р. за N 563/12437

{ Наказ втратив чинність на підставі Наказу Державної податкової служби N 979 ( z1439-10 ) від 22.12.2010 }

Про внесення змін до деяких нормативно-правових актів щодо обліку, реєстрації та ідентифікації як платників податків іноземних юридичних осіб та їх відокремлених підрозділів в Україні

{ Із змінами, внесеними згідно з Наказами Державної податкової служби N 978 ( z1400-10 ) від 22.12.2010 N 979 ( z1439-10 ) від 22.12.2010 }

Відповідно до статей 2, 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ), з метою удосконалення обліку, реєстрації та ідентифікації як платників податків іноземних юридичних осіб та їх відокремлених підрозділів в Україні, приведення нормативно-правових актів Державної податкової адміністрації України у відповідність до Положення про Єдиний державний реєстр підприємств та організацій України, затвердженого постановою Кабінету Міністрів України від 22.01.96 N 118 ( 118-96-п ) (у редакції постанови Кабінету Міністрів України від 22.06.2005 N 499 ( 499-2005-п ), та інших нормативно-правових актів НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Державної податкової служби N 979 ( z1439-10 ) від 22.12.2010 }

{ Пункт 2 втратив чинність на підставі Наказу Державної податкової служби N 979 ( z1439-10 ) від 22.12.2010 }

{ Пункт 3 втратив чинність на підставі Наказу Державної податкової служби N 978 ( z1400-10 ) від 22.12.2010 }

4. Затвердити Зміни до Положення про порядок реєстрації та обліку постійних представництв нерезидентів в Україні як платників податку на прибуток, затвердженого наказом Державної податкової адміністрації України від 12.08.97 N 293 ( z0331-97 ), зареєстрованого в Міністерстві юстиції України 21.08.97 за N 331/2135 (у редакції наказу Державної податкової адміністрації України від 16.01.98 N 23 ( z0063-98 ), що додаються ( z0566-06 ).

5. Управлінню реєстрації та обліку платників податків (Калєніченко Н.Г.) подати цей наказ до Міністерства юстиції України на державну реєстрацію.

6. Контроль за виконанням цього наказу покласти на заступника Голови ДПА України Ревуна В.І.
