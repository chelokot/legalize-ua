ПОСТАНОВА від 11 липня 2002 р. N 991 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 749 ( 749-2009-п ) від 17.07.2009 }

Про внесення змін до Положення про Координаційний центр з питань здійснення пенсійної реформи

Кабінет Міністрів України постановляє:

1. В абзаці другому пункту 5 Положення про Координаційний центр з питань здійснення пенсійної реформи, затвердженого постановою Кабінету Міністрів України від 11 квітня 2002 р. N 496 ( 496-2002-п ) (Офіційний вісник України, 2002 р., N 15, ст. 813), слово "п'яти" замінити словом "шести".

2. Надати право голові Координаційного центру з питань здійснення пенсійної реформи вносити зміни до його посадового складу.

Прем'єр-міністр України А.КІНАХ
