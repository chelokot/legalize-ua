Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 березня 2008 р. N 452-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання операцій з переробки опорних валків на митній території України

1. Відповідно до частини третьої статті 232 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити строк виконання операцій з переробки опорних валків за кодом згідно з УКТЗЕД 7224 90 90 00 ( 2371в-14 ), у тому числі тих, митне оформлення яких здійснено до набрання чинності цим розпорядженням, на митній території України 290 днів.

2. Це розпорядження набирає чинності з дня опублікування.
