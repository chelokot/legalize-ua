Кабінет Міністрів України; Розпорядження від 15.06.2006 № 329-р

Про виділення коштів для виплати компенсації за птицю, вилучену у зв'язку з виявленням у Сумській області випадків захворювання на пташиний грип, та проведення профілактичних заходів

Стан: Чинний

Ідентифікатор: 329-2006-р

Текст документа від 25.10.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 червня 2006 р. N 329-р Київ

Про виділення коштів для виплати компенсації за птицю, вилучену у зв'язку з виявленням у Сумській області випадків захворювання на пташиний грип, та проведення профілактичних заходів

{ Із змінами, внесеними згідно з Постановою КМ N 1474 ( 1474-2006-п ) від 25.10.2006 }

1. Виділити МНС 755,134 тис. гривень для виплати компенсації юридичним і фізичним особам за птицю, вилучену у зв'язку з виявленням у Сумській області випадків захворювання на пташиний грип (далі - компенсація), закупівлі необхідних засобів та проведення карантинних заходів. { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1474 ( 1474-2006-п ) від 25.10.2006 }

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 3235-15 ).

2. МНС визначити розміри компенсації та забезпечити виплату її сум готівкою фізичним особам і у безготівковій формі юридичним особам протягом трьох робочих днів за встановленим Міністерством зразком платіжної відомості.

3. МНС подати до 1 вересня 2006 р. Мінекономіки, Мінфіну і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.
