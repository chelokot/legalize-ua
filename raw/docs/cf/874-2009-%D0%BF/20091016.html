Кабінет Міністрів України; Постанова від 19.08.2009 № 874

Питання фінансування у 2009 році за рахунок коштів Стабілізаційного фонду заходів з підтримання зв'язків із закордонними українцями

Стан: Чинний

Ідентифікатор: 874-2009-п

Текст документа від 16.10.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 серпня 2009 р. N 874 Київ

Питання фінансування у 2009 році за рахунок коштів Стабілізаційного фонду заходів з підтримання зв'язків із закордонними українцями

{ Із змінами, внесеними згідно з Постановою КМ N 1054 ( 1054-2009-п ) від 07.10.2009 }

Відповідно до частини другої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) Кабінет Міністрів України постановляє:

1. Здійснити перерозподіл коштів Стабілізаційного фонду в сумі 47 млн. гривень, зокрема Міністерству закордонних справ - 15 млн. гривень, Міністерству культури і туризму - 20 млн. гривень, Міністерству освіти і науки - 5 млн. гривень, Державному комітетові телебачення та радіомовлення - 3 млн. гривень, Державному комітетові у справах національностей та релігій - 4 млн. гривень, за рахунок зменшення обсягу видатків за напрямом, передбаченим пунктом 16 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), і збільшення обсягу видатків за напрямом, передбаченим пунктом 22 частини першої статті 76 цього Закону ( 835-17 ), із спрямуванням їх для здійснення заходів з підтримання зв'язків із закордонними українцями.

{ Пункт 1 в редакції Постанови КМ N 1054 ( 1054-2009-п ) від 07.10.2009 }

2. Забезпечити без попереднього погодження з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету:

Міністерству фінансів - внесення відповідних змін до розпису державного бюджету ( 835-17 );

Державному казначейству - здійснення перерахування коштів Стабілізаційного фонду ( 835-17 ).

Міністерству закордонних справ, Міністерству культури і туризму, Міністерству освіти і науки, Державному комітетові телебачення та радіомовлення, Державному комітетові у справах національностей та релігій:

погодити передбачений пунктом 1 цієї постанови перерозподіл коштів Стабілізаційного фонду ( 835-17 ) з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету;

подати на розгляд Кабінету Міністрів України проекти постанов Кабінету Міністрів України щодо порядку використання у 2009 році коштів Стабілізаційного фонду ( 835-17 ) для здійснення заходів з підтримання зв'язків із закордонними українцями.

{ Пункт 2 в редакції Постанови КМ N 1054 ( 1054-2009-п ) від 07.10.2009 }
