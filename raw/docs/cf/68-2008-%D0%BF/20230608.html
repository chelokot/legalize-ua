Текст документа від 08.06.2023:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 лютого 2008 р. N 68 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 558 ( 558-2023-п ) від 02.06.2023 }

Про використання у 2008 році коштів, передбачених у державному бюджеті для захисту територій від шкідливої дії вод, ведення державного моніторингу поверхневих вод, державного водного кадастру, паспортизації та управління водними ресурсами

Кабінет Міністрів України постановляє:

Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) за програмами "Захист від шкідливої дії вод сільських населених пунктів та сільськогосподарських угідь", "Ведення державного моніторингу поверхневих вод, водного кадастру, паспортизація, управління водними ресурсами" та "Комплексний протипаводковий захист в басейні р. Тиса у Закарпатській області", здійснюється відповідно до порядків, затверджених постановою Кабінету Міністрів України від 21 лютого 2007 р. N 254 ( 254-2007-п ) (Офіційний вісник України, 2007 р., N 14, ст. 513, N 57, ст. 2282, N 71, ст. 2671).

У зв'язку з цим внести до Порядку використання у 2007 році коштів, передбачених у державному бюджеті для захисту територій від шкідливої дії вод, що затверджений зазначеною постановою ( 254-2007-п ), такі зміни:

доповнити абзац перший пункту 4 після слова "об'єктів" словами та цифрами ", а також на підставі позитивного висновку комплексної державної експертизи відповідно до Порядку затвердження інвестиційних програм і проектів будівництва та проведення їх державної експертизи, затвердженого постановою Кабінету Міністрів України від 31 жовтня 2007 р. N 1269 ( 1269-2007-п ) (Офіційний вісник України, 2007 р., N 84, ст. 3106)";

пункти 3 і 5 розділу "Бюджетна програма "Захист від шкідливої дії вод сільських населених пунктів, смт Лазурного та сільськогосподарських угідь" додатка до Порядку ( 254-2007-п ) викласти у такій редакції:

"3. Будівництво та реконструкція об'єктів виробничого призначення, що використовуються службою експлуатації.";

"5. Придбання устаткування, машин і механізмів для загонів з проведення невідкладних та аварійних робіт.".
