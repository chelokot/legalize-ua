Стан: Чинний

Текст документа від 22.09.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 лютого 2011 р. N 75 Київ

Про внесення змін до постанов Кабінету Міністрів України з питань діяльності Державної служби фінансового моніторингу

{ Із змінами, внесеними згідно з Постановами КМ N 299 ( 299-2015-п ) від 14.05.2015 N 411 ( 411-2015-п ) від 17.06.2015 N 510 ( 510-2015-п ) від 17.07.2015 N 552 ( 552-2015-п ) від 05.08.2015 N 708 ( 708-2015-п ) від 16.09.2015 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України з питань діяльності Державної служби фінансового моніторингу зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 лютого 2011 р. N 75

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України з питань діяльності Державної служби фінансового моніторингу

{ Пункт 1 втратив чинність на підставі Постанови КМ N 299 ( 299-2015-п ) від 14.05.2015 }

2. У Порядку надання державними органами на запит суб'єкта первинного фінансового моніторингу інформації про ідентифікацію клієнта, затвердженому постановою Кабінету Міністрів України від 25 серпня 2010 р. N 746 ( 746-2010-п ) (Офіційний вісник України, 2010 р., N 65, ст. 2260):

1) у пункті 4 слова "Держкомпідприємництво, ДПА" замінити словами "Державна реєстраційна служба, Державна податкова служба";

2) у третьому реченні пункту 5 слова "Держкомпідприємництвом, ДПА" замінити словами "Державною реєстраційною службою, Державною податковою службою".
