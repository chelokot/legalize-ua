Текст документа від 13.02.2005:

МІНІСТЕРСТВО ЕКОНОМІКИ ТА З ПИТАНЬ ЄВРОПЕЙСЬКОЇ ІНТЕГРАЦІЇ УКРАЇНИ

НАКАЗ

12.11.2004 N 412

Зареєстровано в Міністерстві юстиції України 3 грудня 2004 р. за N 1540/10139

Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 05.02.2004 N 46

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства економіки та з питань європейської інтеграції

N 46 ( z0229-04 ) від 05.02.2004, до якого вносились зміни }

Відповідно до постанови Кабінету Міністрів України від 24.12.2003 N 1996 ( 1996-2003-п ) "Про переліки товарів, експорт та імпорт яких підлягає ліцензуванню і на які встановлено квоти у 2004 році" (із змінами) та з метою забезпечення ліцензування експорту деяких видів м'яса та м'ясопродуктів, що підлягає ліцензуванню у 2004 році, НАКАЗУЮ:

1. У наказ Міністерства економіки та з питань європейської інтеграції України від 05.02.2004 N 46 ( z0229-04 ) "Про порядок ліцензування експорту, імпорту товарів у 2004 році", зареєстрований у Міністерстві юстиції України 20.02.2004 за N 229/8828, унести такі зміни та доповнення:

пункт 2 після слів та цифр "додатками 2, 4 і 5" доповнити цифрами "18".

2. У Положення про порядок ліцензування експорту товарів у 2004 році ( z0230-04 ), затверджене наказом Міністерства економіки та з питань європейської інтеграції України від 05.02.2004 N 46 ( z0229-04 ) "Про порядок ліцензування експорту, імпорту товарів у 2004 році", зареєстроване в Міністерстві юстиції України 20.02.2004 за N 230/8829, унести такі зміни та доповнення:

1) пункт 1.1 після слова та цифр "додатками 1, 3, 4, 5, 9, 10, 11, 13, 14, 15, 16, 17" доповнити цифрами "18";

2) абзац шостий пункту 2.2 після слів та цифр "згідно з додатками 15, 16 та 17" доповнити цифрами "18";

3) абзац сьомий пункту 2.2 після слова та цифр "додатками 1, 4, 5, 15, 16, 17" доповнити цифрами "18".

3. Управлінню нетарифного регулювання:

разом з юридичним департаментом забезпечити реєстрацію цього наказу в Міністерстві юстиції України в установлений законодавством термін;

разом з адміністративно-господарським департаментом довести цей наказ до відома Державної митної служби України, Міністерства економіки Автономної Республіки Крим, обласних, Київської та Севастопольської міських державних адміністрацій.

4. Контроль за виконанням цього наказу покласти на першого заступника Міністра економіки та з питань європейської інтеграції України Пятницького В.Т.

Міністр економіки та з питань європейської інтеграції України М.Деркач
