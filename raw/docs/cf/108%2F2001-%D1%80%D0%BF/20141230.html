Про деякі питання діяльності Консультативної ради з питань іноземних інвестицій в Україні

{ Із змінами, внесеними згідно з Указом Президента N 892/2010 ( 892/2010 ) від 01.09.2010 }

{ Пункт 1 втратив чинність на підставі Указу Президента N 892/2010 ( 892/2010 ) від 01.09.2010 }

2. На часткову зміну Розпорядження Президента України від 27 квітня 2000 року N 188 ( 188/2000-рп ) "Про робочі органи Консультативної ради з питань іноземних інвестицій в Україні" (із змінами, внесеними Розпорядженнями Президента України від 30 жовтня 2000 року N 333 ( 333/2000-рп ) та N 334 ( 334/2000-рп ):

1) призначити співголовами робочих груп Консультативної ради з питань іноземних інвестицій в Україні:

робочої групи з питань власності та усунення адміністративних перешкод, утвореної згідно з рішенням зазначеної Консультативної ради шляхом об'єднання робочої групи з питань формування інвестиційного іміджу та робочої групи з питань реформування відносин власності та усунення адміністративних перешкод, - ШЛАПАКА Олександра Віталійовича - заступника Міністра економіки України;

робочої групи з питань фінансової політики - АЗАРОВА Миколу Яновича - Голову Державної податкової адміністрації України;

2) затвердити ТУЛУБА Сергія Борисовича - заступника Секретаря Ради національної безпеки і оборони України - співголовою робочої групи з питань нафтогазової промисловості Консультативної ради з питань іноземних інвестицій в Україні;

3) увільнити від виконання обов'язків співголів робочих груп Консультативної ради з питань іноземних інвестицій в Україні:

робочої групи з питань фінансової політики - В. Стельмаха;

робочої групи з питань формування інвестиційного іміджу - В. Ігнащенка;

робочої групи з питань реформування відносин власності та усунення адміністративних перешкод - В. Кальника.

Президент України Л.КУЧМА

м. Київ, 17 квітня 2001 року N 108/2001-рп
