КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 травня 2006 р. N 764 Київ

Про утворення Українського інституту національної пам'яті

{ Із змінами, внесеними згідно з Постановою КМ N 664 ( 664-2008-п ) від 23.07.2008 }

Відповідно до пункту 9-1 статті 116 Конституції України ( 254к/96-ВР ) Кабінет Міністрів постановляє:

1. Утворити Український інститут національної пам'яті як центральний орган виконавчої влади.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 664 ( 664-2008-п ) від 23.07.2008 }

2. Установити, що основними завданнями Українського інституту національної пам'яті є:

посилення уваги суспільства до власної історії, поширення об'єктивної інформації про неї в Україні та світі;

реалізація державної політики та координація діяльності у сфері відновлення та збереження національної пам'яті Українського народу;

забезпечення всебічного вивчення етапів боротьби за відновлення державності України у XX столітті, історичного минулого Українського народу, в тому числі усіх форм репресій;

здійснення комплексу заходів з увічнення пам'яті жертв голодоморів та політичних репресій, учасників національно-визвольної боротьби.

3. Українському інституту національної пам'яті, Міністерству фінансів, Міністерству економіки, Міністерству юстиції подати у двомісячний строк проект положення про зазначений Інститут, а також узгоджені пропозиції щодо його матеріально-технічного і фінансового забезпечення та визначення граничної чисельності працівників апарату.

4. Київській міській державній адміністрації, Міністерству культури і туризму, Державній судовій адміністрації, Службі безпеки, Фонду державного майна, Міністерству економіки, Міністерству фінансів і Міністерству юстиції подати проект рішення Кабінету Міністрів України щодо розміщення Українського інституту національної пам'яті по вул. Липській, 16, у м. Києві.

Прем'єр-міністр України Ю.ЄХАНУРОВ
