{ Постанова втратила чинність на підставі Постанови КМ N 104 ( 104-94-п ) від 22.02.94 }

Про створення Луганського училища міліції Міністерства внутрішніх справ

Кабінет Міністрів України постановляє:

Прийняти пропозицію Міністерства внутрішніх справ про створення Луганського училища міліції на базі Луганського училища професійної підготовки Управління внутрішніх справ Луганської області.

Створення вказаного училища здійснити у межах асигнувань на підготовку кадрів, передбачених Міністерству внутрішніх справ.
