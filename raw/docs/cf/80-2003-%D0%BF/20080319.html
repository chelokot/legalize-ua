Про утворення міжвідомчої робочої групи з питань розроблення нової структури військового резерву людських ресурсів, механізму підготовки та накопичення резервістів, які призначені для комплектування Збройних Сил, інших військових формувань під час мобілізації, та порядку формування єдиного державного замовлення на їх підготовку

Стан: Втратив чинність

Ідентифікатор: 80-2003-п

Текст документа від 19.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 січня 2003 р. N 80 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

Про утворення міжвідомчої робочої групи з питань розроблення нової структури військового резерву людських ресурсів, механізму підготовки та накопичення резервістів, які призначені для комплектування Збройних Сил, інших військових формувань під час мобілізації, та порядку формування єдиного державного замовлення на їх підготовку

( Із змінами, внесеними згідно з Постановами КМ N 1402 ( 1402-2003-п ) від 04.09.2003 N 982 ( 982-2005-п ) від 24.09.2005 N 147 ( 147-2006-п ) від 15.02.2006 )

На виконання статті 2 Указу Президента України від 17 квітня 2002 р. N 348 ( 348/2002 ) "Про Державну програму переходу Збройних Сил України до комплектування військовослужбовцями, які проходять військову службу за контрактом" Кабінет Міністрів України постановляє:

1. Утворити міжвідомчу робочу групу з питань розроблення нової структури військового резерву людських ресурсів, механізму підготовки та накопичення резервістів, які призначені для комплектування Збройних Сил, інших військових формувань під час мобілізації, та порядку формування єдиного державного замовлення на їх підготовку (далі - міжвідомча робоча група) у складі, що додається.

Надати голові міжвідомчої робочої групи право вносити у разі потреби зміни до її персонального складу.

2. Установити, що основними завданнями міжвідомчої робочої групи є:

підготовка пропозицій щодо розроблення нової структури військового резерву людських ресурсів, визначення статусу осіб, зарахованих до нього, та засад виконання цими особами обов'язків резервістів;

розроблення плану заходів щодо створення нової структури військового резерву людських ресурсів, механізму підготовки та накопичення резервістів, які призначені для комплектування Збройних Сил, інших військових формувань під час мобілізації, та порядку формування єдиного державного замовлення на їх підготовку (далі - план заходів);

проведення кожного півріччя аналізу інформації міністерств, інших центральних органів виконавчої влади про хід виконання плану заходів, її узагальнення;

підготовка пропозицій щодо розроблення проектів нормативно-правових актів з питань створення військового резерву людських ресурсів.

3. Установити, що відповідно до основних завдань міжвідомча робоча група має право:

одержувати в установленому порядку від міністерств, інших центральних органів виконавчої влади інформацію, необхідну для виконання покладених на неї завдань;

проводити засідання, наради, семінари, конференції з питань, що належать до її компетенції, із залученням представників органів виконавчої влади, підприємств, установ та організацій.
