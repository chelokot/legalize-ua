КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 серпня 2001 р. N 932 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про утворення Прес-служби Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Утворити у структурі Секретаріату Кабінету Міністрів України, затвердженій постановою Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) (Офіційний вісник України, 2000 р., N 4, ст. 110), Прес-службу Кабінету Міністрів України.

Установити, що Прес-службу Кабінету Міністрів України очолює прес-секретар Прем'єр-міністра України, керівник Прес-служби Кабінету Міністрів України.

2. Визнати такими, що втратили чинність, підпункт 1 пункту 1 (у частині ліквідації Прес-служби Кабінету Міністрів України) та пункт 2 постанови Кабінету Міністрів України від 20 червня 2001 р. N 660 ( 660-2001-п ) (Офіційний вісник України, 2001 р., N 25, ст. 1113).

3. Державному Секретарю Кабінету Міністрів України внести в установленому порядку зміни до штатного розпису Секретаріату Кабінету Міністрів України.

Прем'єр-міністр України А.КІНАХ
