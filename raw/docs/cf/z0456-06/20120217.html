Про затвердження форми згоди на виїзд дітей за кордон на відпочинок та оздоровлення

{ Із змінами, внесеними згідно з Наказом Міністерства України у справах сім'ї, молоді та спорту

N 2025 ( z0589-09 ) від 16.06.2009 }

Відповідно до постанови Кабінету Міністрів України від 21.12.2005 року N 1251 ( 1251-2005-п ) "Про затвердження Порядку організації виїзду дітей за кордон на відпочинок та оздоровлення", з метою впорядкування організації направлення дітей на відпочинок та оздоровлення за кордон та посилення контролю за їх поверненням до України НАКАЗУЮ:

1. Затвердити Форму згоди на виїзд дітей за кордон на відпочинок та оздоровлення, що додається.

{ Пункт 1 із змінами, внесеними згідно з Наказом Міністерства України у справах сім'ї, молоді та спорту N 2025 ( z0589-09 ) від 16.06.2009 }

2. Департаменту з питань дітей (Волинець Л.С.) забезпечити державну реєстрацію цього наказу в Міністерстві юстиції України.

3. Контроль за виконанням наказу покласти на заступника Міністра України у справах сім'ї, молоді та спорту Кондратюк Т.В.
