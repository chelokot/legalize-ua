Про затвердження Положення про технічний порядок проведення аукціонів з розміщення облігацій внутрішньої державної позики

Стан: Втратив чинність

Ідентифікатор: v0638500-99

Текст документа від 08.08.2003:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 186 від 15.04.99 Зареєстровано в юридичному м.Київ департаменті Нацбанку 19 квітня 1999 р. vd990415 vn186 за N 638

Про затвердження Положення про технічний порядок проведення аукціонів з розміщення облігацій внутрішньої державної позики

( Із змінами, внесеними згідно з Постановою Національного банку N 248 ( z0551-03 ) від 18.06.2003 )

У зв'язку з потребою приведення нормативних актів Національного банку України з питань функціонування ринку облігацій внутрішніх державних позик у відповідність з вимогами чинного законодавства України Правління ПОСТАНОВЛЯЄ:

1. Затвердити Положення про технічний порядок проведення аукціонів з розміщення облігацій внутрішньої державної позики. Положення додається.

2. Вважати таким, що втратив чинність, пункт 2 постанови Правління Національного банку України від 26.01.96 N 15 ( v0015500-96, v0349500-96 ).

3. Емісійно-кредитному департаменту (Н.І.Гребеник) довести до відома Кримського республіканського, обласних та по місту Києву і Київській області управлінь Національного банку України та комерційних банків Положення про технічний порядок проведення аукціонів з розміщення облігацій внутрішньої державної позики (друга редакція) для використання в роботі.

4. Департаменту інформатизації (А.С.Савченко) доопрацювати у місячний строк з дати підписання постанови програмно-технологічні комплекси щодо проведення аукціонів з розміщення облігацій внутрішньої державної позики.

5. Постанова набуває чинності з дня її підписання.

6. Контроль за виконанням цієї постанови покласти на першого заступника Голови Правління В.С.Стельмаха.

Голова В.А.Ющенко

( Положення про технічний порядок проведення аукціонів з розміщення облігацій внутрішньої державної позики втратило чинність на підставі Постанови Національного банку N 248 ( z0551-03 ) від 18.06.2003 )
