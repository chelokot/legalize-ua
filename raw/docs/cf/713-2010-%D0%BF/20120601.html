Кабінет Міністрів України; Постанова від 04.08.2010 № 713

Про затвердження фінансового плану Національної акціонерної компанії "Нафтогаз України" як окремої юридичної особи на 2010 рік

Стан: Чинний

Ідентифікатор: 713-2010-п

Текст документа від 01.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 серпня 2010 р. N 713 Київ

Про затвердження фінансового плану Національної акціонерної компанії "Нафтогаз України" як окремої юридичної особи на 2010 рік

{ Із змінами, внесеними згідно з Постановою КМ N 713 ( 713-2010-п ) від 22.12.2010 }

Кабінет Міністрів України постановляє:

1. Затвердити фінансовий план Національної акціонерної компанії "Нафтогаз України" як окремої юридичної особи на 2010 рік (додається до оригіналу).

{ Нову редакцію фінансового плану див. в Постанові КМ N 713 ( 713-2010-п ) від 22.12.2010 }

2. Міністерству фінансів передбачити під час підготовки змін до Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) випуск облігацій внутрішньої державної позики в сумі 7,4 млрд. гривень з наступним придбанням у державну власність в обмін на ці облігації акцій додаткової емісії Національної акціонерної компанії "Нафтогаз України".

Прем'єр-міністр України М.АЗАРОВ
