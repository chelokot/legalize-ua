Питання Українсько-американської міждержавної комісії

Стан: Втратив чинність

Ідентифікатор: 1436/99

Текст документа від 05.03.2002:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 204/2002 ( 204/2002 ) від 05.03.2002 )

Питання Українсько-американської міждержавної комісії

На часткову зміну Указу Президента України від 7 травня 1997 року N 400 ( 400/97 ) "Питання Української частини Секретаріату Українсько-американської міждержавної комісії" (зі змінами, внесеними указами Президента України від 6 листопада 1997 року N 1238 ( 1238/97 ), від 6 лютого 1999 року N 128 ( 128/99 ), від 20 травня 1999 року N 541 ( 541/99 ):

1. Призначити заступника Глави Адміністрації Президента України - Керівника Головного управління з питань зовнішньополітичної діяльності ОРЛА Анатолія Костянтиновича заступником Секретаря Української частини Секретаріату Українсько-американської міждержавної комісії, увільнивши від виконання цих обов'язків В. Огризка.

2. Увести до складу Української частини Секретаріату Українсько-американської міждержавної комісії першого заступника Міністра закордонних справ України ЧАЛОГО Олександра Олександровича.

3. Призначити першого заступника Міністра закордонних справ України ЧАЛОГО Олександра Олександровича співголовою Комітету з питань зовнішньої політики Українсько-американської міждержавної комісії від України, увільнивши від виконання цих обов'язків А. Орла.

Президент України Л.КУЧМА

м. Київ, 3 листопада 1999 року N 1436/99
