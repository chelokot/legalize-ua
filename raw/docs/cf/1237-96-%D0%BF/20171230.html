КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 жовтня 1996 р. N 1237 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1079 ( 1079-2017-п ) від 27.12.2017 }

Про доповнення Положення про порядок направлення громадян на лікування за кордон

Кабінет Міністрів України постановляє:

Доповнити пункт 5 Положення про порядок направлення громадян України на лікування за кордон, затвердженого постановою Кабінету Міністрів України від 8 грудня 1995 р. N 991 ( 991-95-п ) (ЗП України, 1996 р., N 4, ст. 121), абзацом такого змісту:

"Фонду для здійснення заходів щодо ліквідації наслідків Чорнобильської катастрофи та соціального захисту населення (до 20 відсотків у кожному конкретному випадку направлення на лікування осіб, які постраждали внаслідок Чорнобильської катастрофи)".

Прем'єр-міністр України П.ЛАЗАРЕНКО
