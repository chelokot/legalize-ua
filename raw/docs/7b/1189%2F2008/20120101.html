УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1110/2011 ( 1110/2011 ) від 09.12.2011 }

Про новий склад Наглядової ради Національної академії державного управління при Президентові України

1. На зміну статті 1 Указу Президента України від 24 лютого 2004 року N 215 ( 215/2004 ) "Про Наглядову раду Національної академії державного управління при Президентові України" (зі зміною, внесеною Указом від 22 січня 2005 року N 77) ( 77/2005 ) затвердити новий персональний склад Наглядової ради Національної академії державного управління при Президентові України (додається).

2. Цей Указ набирає чинності з дня його опублікування.
