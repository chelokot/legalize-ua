Президент України; Указ від 05.03.1992 № 130

Про деякі заходи щодо поліпшення економічного стану гірничорудних підприємств

Стан: Чинний

Ідентифікатор: 130/92

Текст документа від 01.12.1994:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про деякі заходи щодо поліпшення економічного стану гірничорудних підприємств

( Із змінами, внесеними згідно з Указом Президента N 680/94 ( 680/94 ) від 17.11.94 )

З метою стабілізації роботи підприємств по видобутку залізної та марганцевої руд підземним способом і по будівництву шахт постановляю:

1. Звільнити з 1 лютого 1992 року підприємства по видобутку залізної та марганцевої руд підземним способом і по будівництву шахт від внесків до фонду для здійснення заходів по ліквідації наслідків Чорнобильської катастрофи та соціального захисту населення.

( Стаття 2 втратила чинність на підставі Указу Президента N 680/94 ( 680/94 ) від 17.11.94 )

3. Указ набуває чинності з дня його підписання.

Президент України Л.КРАВЧУК

м. Київ, 5 березня 1992 року N 130
