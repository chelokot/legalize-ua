{ Розпорядження втратило чинність на підставі Розпорядження Антимонопольного комітету

N 200-р ( z0323-08 ) від 08.04.2008 }

Про затвердження Змін до деяких нормативно-правових актів Антимонопольного комітету України з питань державних закупівель

Відповідно до пункту 11 частини третьої статті 7 Закону України "Про Антимонопольний комітет України" ( 3659-12 ), частин другої та третьої статті 3-1 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ) Антимонопольний комітет України ПОСТАНОВИВ:

1. Затвердити:

1.1. Зміни до Інструкції щодо заповнення Примірної форми Оголошення про результати проведення торгів на закупівлю товарів, робіт і послуг за державні кошти, затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 217-р ( z0903-06 ), зареєстрованої в Міністерстві юстиції України 01.08.2006 за N 903/12777 (із змінами) (додаються).

1.2. Зміни до Інструкції щодо заповнення форми Звіту про результати здійснення процедур відкритих торгів із зменшенням ціни і двоступеневих торгів щодо закупівлі товарів, робіт і послуг за державні кошти, затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованої в Міністерстві юстиції України 01.08.2006 за N 907/12781 (із змінами) (додаються) ( z0272-08 ).

1.3. Зміни до форми Звіту про результати здійснення процедури редукціону щодо закупівлі товарів і послуг за державні кошти ( z0908-06 ), затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованим у Міністерстві юстиції України 01.08.2006 за N 907/12781 (із змінами) (додаються) ( z0273-08 ).

1.4. Зміни до Інструкції щодо заповнення форми Звіту про результати здійснення процедури редукціону щодо закупівлі товарів і послуг за державні кошти ( z0908-06 ), затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованої в Міністерстві юстиції України 01.08.2006 за N 908/12782 (із змінами) (додаються) ( z0273-08 ).

1.5. Зміни до форми Звіту про результати здійснення процедури запиту цінових пропозицій (котирувань) щодо закупівлі товарів і послуг за державні кошти ( z0909-06 ), затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованим у Міністерстві юстиції України 01.08.2006 за N 907/12781 (із змінами) (додаються) ( z0274-08 ).

1.6. Зміни до Інструкції щодо заповнення форми Звіту про результати здійснення процедури запиту цінових пропозицій (котирувань) щодо закупівлі товарів і послуг за державні кошти ( z0909-06 ), затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованої в Міністерстві юстиції України 01.08.2006 за N 909/12783 (із змінами) (додаються) ( z0274-08 ).

1.7. Зміни до форми Звіту про результати здійснення процедури торгів з обмеженою участю щодо закупівлі товарів, робіт і послуг за державні кошти ( z0910-06 ), затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованим у Міністерстві юстиції України 01.08.2006 за N 907/12781 (із змінами) (додаються) ( z0275-08 ).

1.8. Зміни до Інструкції щодо заповнення форми Звіту про результати здійснення процедури торгів з обмеженою участю щодо закупівлі товарів, робіт і послуг за державні кошти ( z0910-06 ), затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованої в Міністерстві юстиції України 01.08.2006 за N 910/12784 (із змінами) (додаються) ( z0275-08 ).

1.9. Зміни до форми Звіту про результати здійснення процедури закупівлі у одного учасника товарів, робіт і послуг за державні кошти ( z0911-06 ), затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованим у Міністерстві юстиції України 01.08.2006 за N 907/12781 (із змінами) (додаються) ( z0276-08 ).

1.10. Зміни до Інструкції щодо заповнення форми Звіту про результати здійснення процедури закупівлі в одного учасника товарів, робіт і послуг за державні кошти ( z0911-06 ), затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованої в Міністерстві юстиції України 01.08.2006 за N 911/12785 (із змінами) (додаються) ( z0276-08 ).

2. Зміни до додатка 2 до форм Звітів про результати здійснення процедур закупівель товарів, робіт і послуг за державні кошти ( z0911-06 ), затверджених розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованим у Міністерстві юстиції України 01.08.2006 за N 907/12781, виклавши його в новій редакції (додається) ( z0276-08 ).

3. Зміни до додатка 4 до форм Звітів про результати здійснення процедур закупівель товарів, робіт і послуг за державні кошти ( z0911-06 ), затверджених розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованим у Міністерстві юстиції України 01.08.2006 за N 907/12781, виклавши його в новій редакції (додається) ( z0276-08 ).

4. У графі третій пункту 5 форми Протоколу про розкриття тендерних пропозицій при здійсненні процедур закупівель товарів, робіт і послуг за державні кошти, затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 216-р ( z0900-06 ), зареєстрованим у Міністерстві юстиції України 01.08.2006 за N 900/12774 (у редакції розпорядження Антимонопольного комітету України від 12.04.2007 N 138-р) ( z0463-07 ), слова "та правильність оформлення" виключити.

5. В абзацах шостому та сьомому пункту 1 розпорядження Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ) "Про затвердження форм Звітів про результати здійснення процедур закупівель товарів, робіт і послуг за державні кошти та Інструкцій щодо їх заповнення", зареєстрованого в Міністерстві юстиції України 01.08.2006 за N 907/12781 (із змінами), слова "запиту цінових пропозицій (котирувань) щодо закупівлі товарів і послуг" замінити словами "запиту цінових пропозицій (котирувань) щодо закупівлі товарів, робіт і послуг".

6. Пункт 15 форми Звіту про результати здійснення процедур відкритих торгів із зменшенням ціни і двоступеневих торгів щодо закупівлі товарів, робіт і послуг за державні кошти, затвердженої розпорядженням Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ), зареєстрованим у Міністерстві юстиції України 01.08.2006 за N 907/12781 (із змінами), доповнити абзацом такого змісту:

"(за рішенням тендерного комітету від __________ N _______ )".

7. Департаменту інформаційного забезпечення та аналізу подати це розпорядження на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами).
