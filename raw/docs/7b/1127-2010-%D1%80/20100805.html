Стан: Чинний

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 травня 2010 р. N 1127-р Київ

Про надання гуманітарної допомоги Республіці Таджикистан

{ Із змінами, внесеними згідно з Постановою КМ N 666 ( 666-2010-п ) від 28.07.2010 }

На виконання Указу Президента України від 26 травня 2010 р. N 642 ( 642/2010 ) "Про надання гуманітарної допомоги Республіці Таджикистан":

1. Виділити Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи 4860 тис. гривень для надання гуманітарної допомоги Республіці Таджикистан.

Міністерству фінансів здійснити зазначені видатки за рахунок резервного фонду державного бюджету ( 2154-17 ).

{ Пункт 2 втратив чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

3. Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи:

узгодити у триденний строк з Міністерством фінансів та Міністерством економіки перелік витрат, пов'язаних із наданням гуманітарної допомоги Республіці Таджикистан;

забезпечити в установленому порядку закупівлю, відправлення, доставку та передачу вантажу гуманітарної допомоги.

4. Міністерству закордонних справ і Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи узгодити з відповідними органами Республіки Таджикистан питання доставки та передачі вантажу гуманітарної допомоги.

5. Державній митній службі забезпечити оперативне митне оформлення вантажу гуманітарної допомоги, а Адміністрації Державної прикордонної служби - першочергове здійснення контролю під час його перевезення через державний кордон.

6. Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи подати до 31 липня 2010 р. Міністерству економіки, Міністерству фінансів і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України М.АЗАРОВ
