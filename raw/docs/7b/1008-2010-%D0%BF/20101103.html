КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 листопада 2010 р. N 1008 Київ

Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 3 листопада 2010 р. N 1008

ПЕРЕЛІК актів Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 2 серпня 1996 р. N 913 ( 913-96-п ) "Про затвердження наглядових рад національних закладів (установ) культури України".

2. Постанова Кабінету Міністрів України від 5 жовтня 1996 р. N 1236 ( 1236-96-п ) "Про затвердження складу наглядової ради Меморіального комплексу "Національний музей історії Великої Вітчизняної війни 1941-1945 років".

3. Постанова Кабінету Міністрів України від 28 червня 1997 р. N 690 ( 690-97-п ) "Про затвердження персонального складу наглядових рад національних закладів культури".

4. Постанова Кабінету Міністрів України від 4 грудня 1998 р. N 1922 ( 1922-98-п ) "Про затвердження наглядової ради Національного цирку України".

5. Постанова Кабінету Міністрів України від 18 грудня 1998 р. N 2014 ( 2014-98-п ) "Про затвердження наглядової ради Національного будинку органної та камерної музики України".

6. Постанова Кабінету Міністрів України від 9 серпня 1999 р. N 1449 ( 1449-99-п ) "Про затвердження складу наглядової ради Національного музею літератури України".

7. Постанова Кабінету Міністрів України від 8 листопада 2000 р. N 1660 ( 1660-2000-п ) "Про затвердження персонального складу наглядової ради Національного ансамблю солістів "Київська камерата".

8. Розпорядження Кабінету Міністрів України від 11 липня 2001 р. N 281 ( 281-2001-р ) "Про затвердження наглядової ради Національного історико-культурного заповідника "Качанівка".

9. Розпорядження Кабінету Міністрів України від 11 липня 2001 р. N 287 ( 287-2001-р ) "Про затвердження складу наглядових рад Національного музею Тараса Шевченка та Національного музею-заповідника українського гончарства".

10. Розпорядження Кабінету Міністрів України від 13 березня 2002 р. N 124 ( 124-2002-р ) "Про затвердження персонального складу наглядової ради Національного академічного українського драматичного театру імені Марії Заньковецької".

11. Розпорядження Кабінету Міністрів України від 27 квітня 2002 р. N 244 ( 244-2002-р ) "Про затвердження складу наглядової ради Київського національного університету культури і мистецтв".

12. Розпорядження Кабінету Міністрів України від 19 серпня 2002 р. N 479 ( 479-2002-р ) "Про затвердження складу наглядової ради Національного одеського філармонійного оркестру".

13. Постанова Кабінету Міністрів України від 17 березня 2003 р. N 353 ( 353-2003-п ) "Про затвердження складу наглядових рад Національної музичної академії імені П.І. Чайковського та Національної академії образотворчого мистецтва і архітектури".

14. Розпорядження Кабінету Міністрів України від 24 листопада 2003 р. N 701 ( 701-2003-р ) "Про затвердження складу наглядової ради Національної бібліотеки України для дітей".

15. Розпорядження Кабінету Міністрів України від 7 грудня 2005 р. N 502 ( 502-2005-р ) "Про затвердження складу наглядової ради Львівського національного академічного театру опери та балету імені Соломії Крушельницької".

16. Постанова Кабінету Міністрів України від 23 квітня 2008 р. N 419 ( 419-2008-п ) "Про затвердження складу наглядових рад національних історико-культурних заповідників".

17. Розпорядження Кабінету Міністрів України від 4 листопада 2009 р. N 1322 ( 1322-2009-р ) "Про затвердження складу наглядової ради Одеського національного академічного театру опери та балету".

18. Постанова Кабінету Міністрів України від 2 грудня 2009 р. N 1285 ( 1285-2009-п ) "Про затвердження складу наглядових рад Національного історико-археологічного заповідника "Кам'яна Могила" та Національного історико-меморіального заповідника "Поле Берестецької битви" (Офіційний вісник України, 2009 р., N 93, ст. 3171).

19. Постанова Кабінету Міністрів України від 13 січня 2010 р. N 26 ( 26-2010-п ) "Про затвердження нового складу наглядових рад Національної кіностудії художніх фільмів імені Олександра Довженка та Національної кінематеки України" (Офіційний вісник України, 2010 р., N 2, ст. 62).
