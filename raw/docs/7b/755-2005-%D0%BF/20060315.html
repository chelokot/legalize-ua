Про затвердження Порядку використання коштів спеціального фонду державного бюджету, які спрямовуються на заходи, пов'язані з виконанням організаційних функцій орендодавця

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 295 ( 295-2006-п ) від 15.03.2006 }

Затвердити Порядок використання коштів спеціального фонду державного бюджету, які спрямовуються на заходи, пов'язані з виконанням організаційних функцій орендодавця, що додається.

{ Постановляюча частина із змінами, внесеними згідно з Постановою КМ N 295 ( 295-2006-п ) від 15.03.2006 }

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 25

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 18 серпня 2005 р. N 755

ПОРЯДОК використання коштів спеціального фонду державного бюджету, які спрямовуються на заходи, пов'язані з виконанням організаційних функцій орендодавця

{ Назва Порядка із змінами, внесеними згідно з Постановою КМ N 295 ( 295-2006-п ) від 15.03.2006 }

1. Зараховані до спеціального фонду державного бюджету 3 відсотки плати за оренду цілісних майнових комплексів та іншого державного майна, а також 3 відсотки плати за оренду майна (крім військового майна і майна Національної академії наук України та галузевих академій наук), що належить бюджетним установам, які утримуються за рахунок державного бюджету, використовуються Фондом державного майна для здійснення заходів, пов'язаних з виконанням організаційних функцій орендодавця. { Пункт 1 в редакції Постанови КМ N 295 ( 295-2006-п ) від 15.03.2006 }

2. Зазначені кошти спрямовуються на:

1) забезпечення публікації у засобах масової інформації оголошень про проведення конкурсів на право оренди державного майна;

2) здійснення витрат, пов'язаних з нотаріальним посвідченням та державною реєстрацією договорів оренди;

3) відшкодування державного мита та витрат на інформаційно-технічне забезпечення судового процесу у випадках і в порядку, встановлених законодавством;

4) оплату послуг:

- експертів з незалежної оцінки об'єктів оренди для забезпечення проведення конкурсів на право оренди державного майна та з незалежної оцінки розміру збитків, які підлягають відшкодуванню орендарем при поверненні орендованого державного майна у випадках, встановлених законодавством;

- з проведення аудиторської перевірки при передачі в оренду цілісних майнових комплексів державних підприємств, їх структурних підрозділів;

- з проведення екологічного аудиту.

3. Фонд державного майна визначає в межах бюджетних призначень обсяг коштів за напрямами, визначеними у пункті 2 цього Порядку.

4. Виділення асигнувань та здійснення видатків на заходи, пов'язані з виконанням організаційних функцій орендодавця провадиться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 295 ( 295-2006-п ) від 15.03.2006 }
