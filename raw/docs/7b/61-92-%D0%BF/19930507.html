Стан: Чинний

Текст документа від 07.05.1993:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 лютого 1992 р. N 61 Київ

Про забезпечення підготовки Національної доповіді про стан навколишнього природного середовища в Україні

( Із змінами, внесеними згідно з Постановою КМ N 337 ( 337-93-п ) від 07.05.93 )

Відповідно до Закону УРСР "Про охорону навколишнього природного середовища" ( 1264-12 ) Кабінет Міністрів України постановляє:

1. Для підготовки Національної доповіді про стан навколишнього природного середовища в Україні затвердити комісію у такому складі: Міністр охорони навколишнього природного середовища (голова комісії), Міністр охорони здоров'я (заступник голови комісії), Міністр лісового господарства, Міністр у справах захисту населення від наслідків аварії на Чорнобильській АЕС, голова Державного комітету України по гідрометеорології, перший заступник Міністра економіки, перший заступник Міністра сільського господарства, заступник Міністра закордонних справ, заступник Міністра статистики, заступник Міністра освіти, Міністр у справах будівництва і архітектури, голова Державного комітету по житлово-комунальному господарству, голова Державного комітету по водному господарству, голова Державного комітету з ядерної та радіаційної безпеки, голова Державного комітету по використанню атомної енергії, начальник Головного управління геодезії, картографії та кадастру при Кабінеті Міністрів України, голова Національного космічного агентства України, голова Державного комітету по нагляду за охороною праці, голова Державного комітету по стандартизації, метрології та сертифікації, перший заступник голови Державного комітету України по геології і використанню надр, а також президент Української академії аграрних наук, віце-президент Академії наук, голова президії Українського товариства охорони природи (за їх згодою). ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 337 ( 337-93-п ) від 07.05.93 )

Доручити Міністру охорони навколишнього природного середовища України затверджувати персональний склад комісії.

2. Національна доповідь про стан навколишнього природного середовища в Україні подається щорічно Верховній Раді України до 1 липня. ( Пункт 2 в редакції Постанови КМ N 337 ( 337-93-п ) від 07.05.93 )
