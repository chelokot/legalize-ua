Про забезпечення підготовки Національної доповіді про стан навколишнього природного середовища в Україні

Стан: Чинний

Ідентифікатор: 61-92-п

Текст документа від 28.09.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 лютого 1992 р. N 61 Київ

Про забезпечення підготовки Національної доповіді про стан навколишнього природного середовища в Україні

( Із змінами, внесеними згідно з Постановами КМ N 337 ( 337-93-п ) від 07.05.93 N 1481 ( 1481-2000-п ) від 28.09.2000 )

Відповідно до Закону УРСР "Про охорону навколишнього природного середовища" ( 1264-12 ) Кабінет Міністрів України постановляє:

1. Для підготовки Національної доповіді про стан навколишнього природного середовища в Україні утворити комісію у складі Міністра екології та природних ресурсів (голова комісії), Міністра охорони здоров'я (заступник голови комісії), Міністра з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, першого заступника Міністра економіки, першого заступника Міністра аграрної політики, першого заступника Міністра праці та соціальної політики, заступника Міністра закордонних справ, заступника Міністра освіти і науки, Голови Державного комітету лісового господарства, Голови Державного комітету будівництва, архітектури та житлової політики, Голови Державного комітету по водному господарству, Голови Державного комітету статистики, Голови Державного комітету по земельних ресурсах, Голови Національного космічного агентства, президента Української академії аграрних наук, віце-президента Національної академії наук, голови президії Всеукраїнської ради Українського товариства охорони природи (за згодою). ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 337 ( 337-93-п ) від 07.05.93, в редакції Постанови КМ N 1481 ( 1481-2000-п ) від 28.09.2000 )

Доручити Міністру екології та природних ресурсів України затверджувати персональний склад комісії. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1481 ( 1481-2000-п ) від 28.09.2000 )

2. Національна доповідь про стан навколишнього природного середовища в Україні подається щорічно Верховній Раді України до 1 липня. ( Пункт 2 в редакції Постанови КМ N 337 ( 337-93-п ) від 07.05.93 )
