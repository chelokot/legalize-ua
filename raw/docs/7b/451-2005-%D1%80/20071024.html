Про голову Міжвідомчої координаційної комісії з питань організації виконання вимог Монреальського протоколу по речовинах, що руйнують озоновий шар

Текст документа від 24.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 листопада 2005 р. N 451-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Міжвідомчої координаційної комісії з питань організації виконання вимог Монреальського протоколу по речовинах, що руйнують озоновий шар

Затвердити начальника Державної екологічної інспекції - Головного державного інспектора України з охорони навколишнього природного середовища Кострова Миколу Михайловича головою Міжвідомчої координаційної комісії з питань організації виконання вимог Монреальського протоколу по речовинах, що руйнують озоновий шар, увільнивши від цих обов'язків Пугу Григорія Олександровича ( 1062-95-п ).
