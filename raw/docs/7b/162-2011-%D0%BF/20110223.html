КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 лютого 2011 р. N 162 Київ

Про внесення змін до постанов Кабінету Міністрів України від 23 грудня 2004 р. N 1734 і від 3 листопада 2010 р. N 999

Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України від 23 грудня 2004 р. N 1734 ( 1734-2004-п ) "Про затвердження переліку підприємств, які мають стратегічне значення для економіки і безпеки держави" (Офіційний вісник України, 2004 р., N 52, ст. 3443; 2005 р., N 15, ст. 762; 2006 р., N 50, ст. 3320; 2008 р., N 25, ст. 766, N 65, ст. 2185; 2010 р., N 1, ст. 19, N 33, ст. 1186, N 43, ст. 1412) і від 3 листопада 2010 р. N 999 ( 999-2010-п ) "Про визначення критеріїв віднесення об'єктів державної власності до таких, що мають стратегічне значення для економіки і безпеки держави" (Офіційний вісник України, 2010 р., N 84, ст. 2948) зміни, що додаються.

2. Установити, що плани розміщення акцій енергогенеруючих і енергопостачальних підприємств та умови продажу державних пакетів акцій зазначених підприємств погоджуються з Кабінетом Міністрів України.
