Текст документа від 28.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 лютого 2001 р. N 105 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про затвердження переліку посад, що можуть бути заміщені військовослужбовцями Збройних Сил, Служби безпеки, інших військових формувань в органах виконавчої влади, інших цивільних установах, та граничних військових звань за цими посадами

{ Із змінами, внесеними згідно з Постановою КМ N 567 ( 567-2001-п ) від 23.05.2001 }

{ Зміни до Постанови див. Постанову КМ N 658 ( 658-2001-п ) від 18.06.2001 }

{ Із змінами, внесеними згідно з Постановами КМ N 879 ( 879-2001-п ) від 26.07.2001 N 882 ( 882-2001-п ) від 26.07.2001 N 1168 ( 1168-2001-п ) від 13.09.2001 N 1771 ( 1771-2001-п ) від 28.12.2001 }

Відповідно до статті 2 Указу Президента України від 4 листопада 2000 р. N 1209 ( 1209/2000 ) "Про заходи щодо впорядкування відрядження до цивільних установ військовослужбовців і працівників органів внутрішніх справ" Кабінет Міністрів України постановляє:

1. Затвердити перелік посад, що можуть бути заміщені військовослужбовцями Збройних Сил, Служби безпеки, інших військових формувань в органах виконавчої влади, інших цивільних установах, та граничних військових звань за цими посадами (додається).

2. Керівникам центральних і місцевих органів виконавчої влади та інших цивільних установ:

привести у двомісячний термін свої штатні розписи у відповідність з переліком, затвердженим згідно з пунктом 1 цієї постанови;

відрядити військовослужбовців, що займають посади, які не визначені цією постановою, у розпорядження того органу, в якому їх залишено на службі, або вирішити питання щодо їх переведення (за їх згодою) до цивільних установ, де вони працюють, без залишення на військовій службі.

3. Міністерству внутрішніх справ вжити заходів до скорочення переліку посад, що можуть бути заміщені особами начальницького складу органів внутрішніх справ в органах виконавчої влади, інших цивільних установах, та граничних спеціальних звань за цими посадами.

4. Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

________________ * Посади заміщуються військовослужбовцями СБУ.

** Посади заміщуються до досягнення граничного віку перебування на військовій службі військовослужбовців, які були відряджені до Товариства сприяння обороні України на ці посади.

*** Штатні одиниці у Донецькому ліцеї з посиленою військово-фізичною підготовкою.

**** Посади заміщуються військовослужбовцями у період до 2003 року або до досягнення військовослужбовцями, які відряджені на ці посади, граничного віку перебування на військовій службі.

***** Посади заміщуються як військовослужбовцями, так і особами начальницького складу органів внутрішніх справ і податкової міліції у відповідних спеціальних званнях.
