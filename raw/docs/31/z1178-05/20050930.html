Про визнання таким, що втратило чинність, розпорядження Державної комісії з регулювання ринків фінансових послуг України від 27.01.2004 N 28

Реєстрація: Мін'юст України від 10.10.2005 № 1178/11458

Стан: Чинний

Ідентифікатор: z1178-05

Текст документа від 30.09.2005:

ДЕРЖАВНА КОМІСІЯ З РЕГУЛЮВАННЯ РИНКІВ ФІНАНСОВИХ ПОСЛУГ УКРАЇНИ

РОЗПОРЯДЖЕННЯ

30.09.2005 N 4698

Зареєстровано в Міністерстві юстиції України 10 жовтня 2005 р. за N 1178/11458

Про визнання таким, що втратило чинність, розпорядження Державної комісії з регулювання ринків фінансових послуг України від 27.01.2004 N 28

Відповідно до Закону України "Про фінансові послуги та державне регулювання ринків фінансових послуг" ( 2664-14 ) Державна комісія з регулювання ринків фінансових послуг України ПОСТАНОВИЛА:

1. Розпорядження Державної комісії з регулювання ринків фінансових послуг України від 27.01.2004 N 28 ( z0190-04 ) "Про затвердження Порядку ліцензування діяльності тимчасової адміністрації фінансової установи", зареєстроване в Міністерстві юстиції України 12.02.2004 за N 190/8789, визнати таким, що втратило чинність.

2. Юридичному департаменту забезпечити подання цього розпорядження до Міністерства юстиції України для державної реєстрації.

3. Управлінню організаційно-аналітичного забезпечення роботи керівника (Шевченко Т.М.) забезпечити публікацію цього розпорядження у засобах масової інформації після його державної реєстрації.

4. Контроль за виконанням цього розпорядження залишити за Головою Комісії.

Голова В.Суслов

Протокол засідання від 30.09.2005 N 170
