Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 299/2006

Текст документа від 08.12.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1049/2006 ( 1049/2006 ) від 08.12.2006 }

Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва

1. Призначити ЄХАНУРОВА Юрія Івановича - Прем'єр-міністра України - головою Української частини Спільної українсько-узбецької комісії з всебічного співробітництва.

2. Визнати такими, що втратили чинність:

Розпорядження Президента України від 18 жовтня 1997 року N 355 ( 355/97-рп ) "Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва";

Розпорядження Президента України від 22 червня 2000 року N 231 ( 231/2000-рп ) "Про голову Української частини Спільної українсько-узбецької комісії з всебічного співробітництва";

Розпорядження Президента України від 5 липня 2001 року N 175 ( 175/2001-рп ) "Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва";

Розпорядження Президента України від 17 грудня 2002 року N 400 ( 400/2002-рп ) "Питання Української частини Спільної українсько-узбецької комісії з всебічного співробітництва".

Президент України В.ЮЩЕНКО
