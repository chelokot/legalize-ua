Затверджено наказом Держпатенту України від 25 січня 1995 р. N 09

Порядок надання послуг Державним департаментом інтелектуальної власності ( Назва Порядку із змінами, внесеними згідно з Наказом МОН N 389 ( z0574-00 ) від 16.08.2000 )

1. Надання послуг фізичним та юридичним особам (далі - заявникам) здійснюється відповідно до законів України від 15 грудня 1993 року:

"Про охорону прав на винаходи і корисні моделі" ( 3687-12 ),

"Про охорону прав на промислові зразки" ( 3688-12 ),

"Про охорону прав на знаки для товарів і послуг" ( 3689-12 ),

"Про охорону прав на топографії інтегральних мікросхем".

( 621/97-ВР ) від 5 листопада 1997 року. ( Пункт 1 доповнено абзацом п'ятим згідно з Наказом Держпатенту N 25 ( z0331-98 ) від 20.03.98 )

2. Цей Порядок визначає перелік, терміни надання, рекомендовані розміри та правила оплати послуг, що надаються Державним департаментом інтелектуальної власності (далі - Департамент), що діє у складі Міністерства освіти і науки України, умови та терміни повернення коштів за не надану послугу. ( Пункт 2 із змінами, внесеними згідно з Наказом МОН N 389 ( z0574-00 ) від 16.08.2000 )

3. Послуги, що надаються, рекомендовані розміри їх оплати і терміни надання наведені у Переліку послуг Департаменту, рекомендованих розмірів їх оплати і термінів надання (далі - Перелік), що додається (додаток N 1).

Рекомендовані розміри оплати послуг встановлені у частинах офіційно затвердженої величини мінімуму місячного доходу громадян, що не оподатковується прибутковим податком (далі - неоподатковуваний мінімум).

( Пункт 3 із змінами, внесеними згідно з Наказом МОН N 389 ( z0574-00 ) від 16.08.2000 )

4. Послуга надається при надходженні до Департаменту клопотання (заяви) заявника у довільній формі про надання відповідної послуги та документа про її оплату у розмірі, в межах рекомендованого.

Термін надання послуги в межах вказаного у додатку N 1 і відповідальний за її надання визначаються Департаментом. В окремих випадках термін може бути збільшений, але не більше ніж на один місяць. Про це, а також про відмову від прийняття клопотання (заяви) заявника, Департамент у 10-денний термін повідомляє заявника. В останньому випадку обов'язково вказується причина відмови.

Послуга згідно з пунктом 7 Переліку надається відповідно до Положення про представників у справах інтелектуальної власності (патентних повірених), затвердженого постановою Кабінету Міністрів України від 10 серпня 1994 року N 545 ( 545-94-п ) (у редакції постанови Кабінету Міністрів України від 27 серпня 1997 року N 938 ( 938-97-п ). ( Абзац третій пункту 4 в редакції Наказу Держпатенту N 25 ( z0331-98 ) від 20.03.98 )

Офіційні і нормативні документи Департаменту для тиражування і/або розповсюдження (пункт 9 Переліку) надаються відповідно до окремого договору, укладеного згідно з чинним законодавством.

( Пункт 4 із змінами, внесеними згідно з Наказом МОН N 389 ( z0574-00 ) від 16.08.2000 )

5. Оплата послуг провадиться через кредитні установи шляхом перерахування відповідних сум на розрахункові рахунки Департаменту. Дозволяється перерахування коштів поштовим переказом. Документом, що підтверджує оплату послуги, є копія платіжного доручення на перерахування коштів з відміткою установи банку та підписом оператора або відповідна квитанція. ( Пункт 5 із змінами, внесеними Наказом МОН N 389 ( z0574-00 ) від 16.08.2000 )

6. Сума оплати послуги визначається:

для заявників, що постійно проживають чи знаходяться в Україні, - у валюті України;

для заявників, що постійно проживають чи знаходяться за межами України, - у доларах США.

Якщо Міжнародними договорами, учасником яких є Україна, чи міжурядовими угодами передбачено інший порядок оплати послуг патентних відомств, то заявники, що постійно проживають чи перебувають за межами України, оплату послуг Департаменту провадять відповідно до вимог цих договорів чи угод.

Вартість послуг, що надаються кредитною установою, не входить до суми оплати послуги.

( Пункт 6 із змінами, внесеними згідно з Наказом МОН N 389 ( z0574-00 ) від 16.08.2000 )

7. Кошти за послугу повертаються заявнику повністю у разі повернення Департаментом клопотання (заяви) про надання послуги або відмови у його прийнятті.

Повернення коштів за послугу провадиться протягом одного місяця з дня надходження до Департаменту заяви про їх повернення за умови, що цю заяву подано не пізніше одного року з дня їх зарахування на рахунок Департаменту.

Повернення коштів за послугу провадиться за рахунок цих коштів крім випадків, коли заява про повернення подана:

у зв'язку з ненаданням послуги з вини Департаменту;

у зв'язку з незгодою заявника на подовження терміну її надання за межі вказаного у Переліку;

в інших випадках, передбачених чинним законодавством України. ( Пункт 7 із змінами, внесеними згідно з Наказом МОН N 389 ( z0574-00 ) від 16.08.2000 )

8. Кошти, одержані від оплати послуг, використовуються Департаментом для розвитку державної системи охорони інтелектуальної власності.

Департамент щорічно публікує окремим виданням звіт про витрачення зазначених коштів.

( Пункт 8 із змінами, внесеними згідно з Наказом МОН N 389 ( z0574-00 ) від 16.08.2000 )

9. Відповідальність за ненадання чи неналежне надання послуги Департамент несе відповідно до чинного законодавства.

( Пункт 9 із змінами, внесеними згідно з Наказом МОН N 389 ( z0574-00 ) від 16.08.2000 )

Користувач зобов'язується не вносити до наданого документу ніяких друкованих змін, окрім як за погодженням Власника.

1.4. Користувач зобов'язується не перевищувати без згоди Власника вказаний у пункті 1.1 цього договору тираж.

1.5. Користувач зобов'язується без згоди Власника не надавати будь-якій третій особі право на тиражування і розповсюдження зазначеного у пункті 1.1 цього договору документа.
