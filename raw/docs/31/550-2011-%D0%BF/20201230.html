Кабінет Міністрів України постановляє:

1. Установити, що розмір плати за надання Міністерством освіти і науки платної адміністративної послуги з визнання і встановлення еквівалентності документів про освіту, виданих навчальними закладами іноземних держав, та документів про вищу духовну освіту, виданих закладами вищої духовної освіти, становить: { Абзац перший пункту 1 із змінами, внесеними згідно з Постановами КМ N 652 ( 652-2015-п ) від 19.08.2015, N 74 ( 74-2018-п ) від 14.02.2018 }

три неоподатковуваних мінімуми доходів громадян - для фізичних осіб;

п'ять неоподатковуваних мінімумів доходів громадян - для юридичних осіб.

2. Затвердити перелік платних адміністративних послуг, які надаються Міністерством освіти і науки і Міністерством розвитку економіки, торгівлі та сільського господарства (у сфері інтелектуальної власності), згідно з додатком.
