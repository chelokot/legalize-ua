КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 квітня 2005 р. N 101-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

Про утворення постійно діючої робочої групи для вирішення проблемних питань будівництва міжнародних транзитних терміналів у Державному міжнародному аеропорту "Бориспіль" та стабілізації ситуації в трудових колективах аеропорту та ЗАТ "Авіакомпанія "Аеросвіт"

1. Утворити для вирішення проблемних питань будівництва міжнародних транзитних терміналів у Державному міжнародному аеропорту "Бориспіль" та стабілізації ситуації в трудових колективах аеропорту та ЗАТ "Авіакомпанія "Аеросвіт" постійно діючу робочу групу у складі, що додається.

2. Голові робочої групи:

розробити план засідань робочої, групи;

щотижня (кожної п'ятниці) подавати звіт Кабінету Міністрів України про результати роботи групи.
