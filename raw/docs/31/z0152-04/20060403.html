МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

22.01.2004 N 24

Зареєстровано в Міністерстві юстиції України 4 лютого 2004 р. за N 152/8751

Про внесення змін до Ставок зборів за аеронавігаційне обслуговування повітряних суден у повітряному просторі України

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства транспорту

N 145 ( z0184-97 ) від 22.04.97, до якого вносились зміни }

Відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ :

1. До Ставок зборів за аеронавігаційне обслуговування повітряних суден у повітряному просторі України, затверджених наказом Міністерства транспорту України від 22.04.97 N 145 ( z0184-97 ) "Про затвердження ставок зборів за аеронавігаційне обслуговування повітряних суден у повітряному просторі України", зареєстрованим у Міністерстві юстиції України 20.05.97 за N 184/1988 (із змінами і доповненнями, унесеними наказами Міністерства транспорту України від 17.12.99 N 599 ( z0888-99 ), від 19.12.2000 N 718 ( z0951-00 ), від 14.12.2001 N 873 ( z1054-01 ), від 31.01.2002 N 57 ( z0145-02 ), від 17.06.2002 N 403 ( z0523-02 ), від 27.12.2002 N 937 ( z0029-03 ), зареєстрованими в Міністерстві юстиції України відповідно 20.12.99 за N 888/4181, 26.12.2000 за N 951/5172, 20.12.2001 за N 1054/6245, 14.02.2002 за N 145/6433, 21.06.2002 за N 523/6811, 16.01.2003 за N 29/7350), внести такі зміни:

1.1. У підпункті 2.1 пункту 2 цифри і слова "51,23 дол. США" замінити цифрами і словами "48,01 дол. США".

1.2. У підпунктах 4.1, 4.2 та 4.3 пункту 4 цифри і слова "3,25 дол. США", "2,77 дол. США" та "3,1 дол. США" замінити відповідно цифрами і словами "4,88 дол. США", "4,16 дол. США" та "4,65 дол. США".

2.Департаменту економічного аналізу та стратегічного планування (Демчук А.І.) в установленому порядку зареєструвати цей наказ у Міністерстві юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Державного секретаря Дунаєва Л.Ф.
