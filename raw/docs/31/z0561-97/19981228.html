( Наказ втратив чинність на підставі Наказу Мінекономіки N 161 ( z0829-98 ) від 15.12.98 )

Про затвердження цін на газ природний і тарифів на послуги з його транспортування на 1998 рік

Відповідно до постанови Кабінету Міністрів України від 19 вересня 1997 р. N 1027 ( 1027-97-п ) "Про порядок забезпечення природним газом народного господарства і населення у 1998 році" і керуючись повноваженнями, наданими постановою Кабінету Міністрів України від 25 грудня 1996 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", НАКАЗУЮ:

1. Затвердити граничні оптові ціни підприємств на газ власного видобутку згідно з додатком 1.

2. Затвердити граничну оптову ціну на газ природний, що використовується для потреб населення, комунально-побутової сфери і бюджетних організацій, згідно з додатком 2.

3. Затвердити тарифи на послуги з транспортування природного газу для споживачів України згідно з додатком 3.

4. Розрахунки за природний газ здійснюються споживачами газу в гривнях за ціною, встановленою у доларах США і перерахованою за офіційним курсом Національного банку України на день зарахування коштів на рахунок постачальника газу.

5. Визнати такими, що втрачають чинність з 01.01.98, наказ Мінекономіки від 20.12.95 N 186 ( z0472-95 ) "Про встановлення оптових цін на газ природний та тарифів на його транспортування", зареєстрований у Мін'юсті 21.12.95 за N 472/1008, наказ Мінекономіки від 14.06.96 N 76 ( z0317-96 ) "Про встановлення оптових цін на газ природний та тарифів на його транспортування", зареєстрований у Мін'юсті 19.06.96 за N 317/1342.
