НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

13.01.2011 N 8/1

Зареєстровано в Міністерстві юстиції України 17 січня 2011 р. за N 64/18802

Про внесення змін до постанови НКРЕ від 11.03.2010 N 218

Відповідно до Закону України "Про електроенергетику" ( 575/97-ВР ), Указу Президента України від 14.03.95 N 213 ( 213/95 ) "Про заходи щодо забезпечення діяльності Національної комісії з питань регулювання електроенергетики України" (зі змінами) Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Унести до постанови НКРЕ від 11.03.2010 N 218 ( z0241-10 ) "Про затвердження тарифу на електричну енергію для дитячих центрів "Артек" і "Молода гвардія", зареєстрованої в Міністерстві юстиції України 24.03.2010 за N 241/17536, такі зміни:

назву викласти в такій редакції:

"Про затвердження тарифів на електричну енергію для дитячих центрів "Артек" і "Молода гвардія", релігійних організацій та міського електричного транспорту";

преамбулу викласти в такій редакції:

"Відповідно до Законів України "Про електроенергетику" ( 575/97-ВР ), "Про державну підтримку та особливості функціонування дитячих центрів "Артек" і "Молода гвардія" ( 906-17 ), "Про свободу совісті та релігійні організації" ( 987-12 ), Указів Президента України від 14.03.95 N 213 ( 213/95 ) "Про заходи щодо забезпечення діяльності Національної комісії з питань регулювання електроенергетики України" (зі змінами), від 22.06.94 N 322 ( 322/94 ) "Про надання пільг релігійним організаціям" та постанови Кабінету Міністрів України від 26.06.2007 N 881 ( 881-2007-п ) "Про тариф на електричну енергію для міського електротранспорту" Національна комісія регулювання електроенергетики України постановляє:";

пункт 1 викласти в такій редакції:

"1. Затвердити тарифи на електричну енергію, що відпускається для власних потреб дитячих центрів "Артек" і "Молода гвардія", на комунально-побутові потреби релігійних організацій, міському електричному транспорту, на рівні 26,4 коп. за 1 кВт·год (без ПДВ).".

2. Управлінню цінової політики в електроенергетиці подати цю постанову на державну реєстрацію до Міністерства юстиції України в установленому законодавством порядку.

3. Ця постанова набирає чинності з 1 лютого 2011 року, але не раніше дня її офіційного опублікування.

Голова Комісії С.Тітенко
