Про затвердження Положення про Український державний центр соціальних служб для молоді

Реєстрація: Мін'юст України від 21.10.1998 № 677/3117

Стан: Втратив чинність

Ідентифікатор: z0677-98

Текст документа від 16.08.2000:

МІНІСТЕРСТВО УКРАЇНИ У СПРАВАХ СІМ'Ї ТА МОЛОДІ

НАКАЗ

N 73 від 04.03.98 Зареєстровано в Міністерстві м.Київ юстиції України 21 жовтня 1998 р. за N 677/3117

Про затвердження Положення про Український державний центр соціальних служб для молоді

( Із змінами, внесеними згідно з Наказом Державного комітету у справах сім'ї та молоді

N 108 ( z0475-99 ) від 16.07.99 Наказом Держкоммолодьполітики і спорту

N 1255 ( z0508-00 ) від 20.07.2000 )

Відповідно до постанови Кабінету Міністрів України від 21.01.98 р. N 63 ( 63-98-п ) "Про подальший розвиток мережі центрів соціальних служб для молоді та підвищення ефективності їх діяльності", НАКАЗУЮ:

1. Затвердити Положення про Український державний центр соціальних служб для молоді.

2. Вважати таким, що втратив чинність, п.3 наказу Міністерства України у справах сім'ї та молоді від 27.03.97 N 6/5 ( z0305-97 ) "Про Український державний центр соціальних служб для молоді".

3. Контроль за виконанням даного наказу покласти на заступника Міністра Головатого М.Ф.

Міністр В.І.Довженко

( Положення про Український державний центр соціальних служб для молоді втратило чинність на підставі Наказу Держкоммолодьполітики і спорту N 1255 ( z0508-00 ) від 20.07.2000 )
