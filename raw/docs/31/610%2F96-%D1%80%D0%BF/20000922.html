РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Розпорядження Президента

N 290/2000-рп ( 290/2000-рп ) від 22.09.2000 )

Про зміни у складі експертної групи, затвердженому Розпорядженням Президента України від 4 січня 1995 року N 3

Увести до складу експертної групи з питань підготовки проектів міждержавних договорів про правові відносини та правову допомогу у цивільних, шлюбно-сімейних та кримінальних справах, затвердженого Розпорядженням Президента України від 4 січня 1995 року N 3 ( 3/95-рп ) "Про підготовку проектів міждержавних довоговорів про правові відносини та правову допомогу" (в редакції Розпорядження Президента України ( 399/96-рп ) від 17 жовтня 1996 року N 399), ПЛЮШКА Ігоря Анатолійовича - начальника відділу міжнародно-правових зв'язків та зв'язків із засобами масової інформації Вищого арбітражного суду України.

Президент України Л.КУЧМА

м. Київ, 23 листопада 1996 року N 610/96-рп
