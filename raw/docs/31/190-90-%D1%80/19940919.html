Рада Міністрів УРСР; Розпорядження від 03.05.1990 № 190-р

Щодо звільнення громадян від сплати податку на нежонатих, одиноких і малосімейних громадян СРСР

Стан: Втратив чинність

Ідентифікатор: 190-90-р

Текст документа від 19.09.1994:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

РОЗПОРЯДЖЕННЯ від 3 травня 1990 р. N 190-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 644 ( 644-94-п ) від 19.09.94 }

Звільнити з 1 травня 1990 р. громадян, що проживають в населених пунктах, на які поширюється чинність постанови Ради Міністрів УРСР і Укрпрофради від 14 грудня 1989 р. N 315 ( 315-89-п ), від сплати податку на нежонатих, одиноких і малосімейних громадян СРСР.
