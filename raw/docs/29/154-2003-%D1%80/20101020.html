Про затвердження складу наглядової ради Національної телекомпанії України

Стан: Втратив чинність

Текст документа від 20.10.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 березня 2003 р. N 154-р Київ

Про затвердження складу наглядової ради Національної телекомпанії України

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1993-р ( 1993-2010-р ) від 20.10.2010 }

1. Затвердити склад наглядової ради Національної телекомпанії України, що додається.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 29 липня 2002 р. N 424 ( 424-2002-р ) "Про затвердження наглядової ради Національної телекомпанії України".
