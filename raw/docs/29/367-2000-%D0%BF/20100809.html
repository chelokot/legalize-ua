КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 лютого 2000 р. N 367 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 657 ( 657-2010-п ) від 28.07.2010 }

Про Голову Української частини двосторонньої Міжурядової Українсько-Литовської Комісії з питань торговельно-економічного і науково-технічного співробітництва

Кабінет Міністрів України постановляє:

Затвердити Міністра транспорту Костюченка Леоніда Михайловича Головою Української частини двосторонньої Міжурядової Українсько-Литовської Комісії з питань торговельно-економічного і науково-технічного співробітництва, увільнивши від цих обов'язків Данькевича Івана Петровича.
