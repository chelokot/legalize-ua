НАКАЗ

N 66 від 05.03.96 Зареєстровано в Міністерстві м.Київ юстиції України 26 березня 1996 р. vd960305 vn66 за N 139/1164

{ Наказ втратив чинність на підставі Наказу Міністерства освіти і науки N 1060 ( z1205-14 ) від 19.09.2014 }

Про затвердження Типового положення про атестацію середніх

загальноосвітніх, позашкільних, дошкільних закладів освіти

і закладів освіти для громадян, які потребують соціальної допомоги та реабілітації

( Із змінами, внесеними згідно з Наказом МОН N 553 ( z0678-01 ) від 24.07.2001 )

На виконання постанови Кабінету Міністрів України від 12 лютого 1996 року N 200 ( 200-96-п ) "Про ліцензування, атестацію та акредитацію закладів освіти", НАКАЗУЮ:

1. Затвердити Типове положення про атестацію середніх загальноосвітніх, позашкільних, дошкільних закладів освіти і закладів освіти для громадян, які потребують соціальної допомоги та реабілітації (додається).

2. Опублікувати Типове положення в Інформаційному збірнику Міністерства освіти України.

3. Міністерству освіти Автономної Республіки Крим, управлінням освіти обласних, Київської та Севастопольської міських державних адміністрацій, керівникам закладів освіти забезпечити виконання вимог даного Типового положення.

4. Контроль за виконанням наказу покласти на заступника Міністра Бабака В.П.

Виконуючий обов'язки Міністра В.П.Андрущенко

Затверджено наказом Міносвіти України від 5 березня 1996 року N 66

( Типове положення про атестацію середніх загальноосвітніх, позашкільних, дошкільних закладів освіти і закладів освіти для громадян, які потребують соціальної допомоги та реабілітації втратило чинність на підставі Наказу МОН N 553 ( z0678-01 ) від 24.07.2001 )
