Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 жовтня 2009 р. N 1083

ПОРЯДОК використання у 2010 році коштів, передбачених у державному бюджеті для фінансового підтримання пропаганди України за кордоном

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 433 ( 433-2010-п ) від 09.06.2010 }

1. Цей Порядок визначає механізм використання у 2010 році коштів, передбачених МОН у державному бюджеті за програмою "Фінансова підтримка пропаганди України за кордоном" (далі - бюджетні кошти).

{ Пункт 1 в редакції Постанови КМ N 433 ( 433-2010-п ) від 09.06.2010 }

2. Головним розпорядником бюджетних коштів у сумі 9 млн. гривень є МОН, а їх одержувачем - державне підприємство "Інформаційно-іміджевий центр".

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 433 ( 433-2010-п ) від 09.06.2010 }

3. Бюджетні кошти спрямовуються на:

організацію україномовного табору в рамках проведення фіналу IV Міжнародного фестивалю - конкурсу дитячої творчості "Усі ми діти твої, Україно!" за участю закордонних українців на базі державного підприємства "Український дитячий центр "Молода гвардія"; { Абзац другий пункту 3 в редакції Постанови КМ N 433 ( 433-2010-п ) від 09.06.2010 }

проведення всеукраїнської конференції старшокласників "Модель ЮНЕСКО" в рамках міжнародної освітньої програми "Модель ООН"; { Абзац третій пункту 3 в редакції Постанови КМ N 433 ( 433-2010-п ) від 09.06.2010 }

актуалізацію, технічну підтримку та забезпечення функціонування освітньо-іміджевого порталу; { Абзац четвертий пункту 3 в редакції Постанови КМ N 433 ( 433-2010-п ) від 09.06.2010 }

створення рекламно-інформаційної друкованої продукції для пропагування навчання в Україні іноземців; { Абзац п'ятий пункту 3 в редакції Постанови КМ N 433 ( 433-2010-п ) від 09.06.2010 }

проведення за кордоном міжнародних заходів (виставок, семінарів, конференцій), спрямованих на залучення до навчання в Україні іноземців; { Абзац шостий пункту 3 в редакції Постанови КМ N 433 ( 433-2010-п ) від 09.06.2010 }

пропагування пропозиції України щодо розвитку освіти в засобах масової інформації, розрахованих на закордонну аудиторію; { Абзац сьомий пункту 3 в редакції Постанови КМ N 433 ( 433-2010-п ) від 09.06.2010 }

виробництво презентаційно-іміджевої друкованої та відеопродукції про Україну, зокрема про її систему освіти, для активізації міжнародного співробітництва у зазначеній галузі. { Абзац восьмий пункту 3 в редакції Постанови КМ N 433 ( 433-2010-п ) від 09.06.2010 }

4. МОН затверджує в установленому порядку план заходів щодо фінансового підтримання пропаганди України за кордоном.

{ Абзаци перший-четвертий пункту 4 замінено абзацом згідно з Постановою КМ N 433 ( 433-2010-п ) від 09.06.2010 }

Для проведення передбачених планом заходів МОН видає у кожному конкретному випадку наказ, в якому зазначаються найменування заходу, його виконавець, дата і місце проведення, сума витрат.

До наказу додається кошторис витрат, пов'язаних з підготовкою та проведенням заходу.

5. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

{ Пункт 6 виключено на підставі Постанови КМ N 433 ( 433-2010-п ) від 09.06.2010 }

7. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

Одержувач бюджетних коштів:

бере зобов'язання виключно у межах відповідних фактичних надходжень на зазначену мету;

подає до 1 числа наступного місяця МОН інформацію про використання бюджетних коштів для її узагальнення та надсилання до 5 числа зазначеного місяця Мінфіну.

Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
