КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 грудня 2011 р. N 1308 Київ

Про внесення зміни до пункту 2 постанови Кабінету Міністрів України від 28 березня 2011 р. N 334

Кабінет Міністрів України постановляє:

Внести зміну до пункту 2 постанови Кабінету Міністрів України від 28 березня 2011 р. N 334 ( 334-2011-п ) "Деякі питання використання у 2011 році державних капітальних видатків" (Офіційний вісник України, 2011 р., N 24, ст. 999, N 35, ст. 1440, N 44, ст. 1785, N 46, ст. 1884, N 73, ст. 2736, N 77, ст. 2860, ст. 2861, N 85, ст. 3106, N 87, ст. 3164, N 94, ст. 3430, N 96, ст. 3495, ст. 3500), виклавши абзац другий підпункту 2 в такій редакції:

"60000 тис. - для матеріально-технічного забезпечення органів внутрішніх справ;".

Прем'єр-міністр України М.АЗАРОВ
