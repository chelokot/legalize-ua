Рада Міністрів УРСР; Постанова від 05.04.1991 № 83

Про перелік пам'яток архітектури, які не підлягають передачі у постійне користування релігійним організаціям

Стан: Втратив чинність

Ідентифікатор: 83-91-п

Текст документа від 19.08.1999:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 5 квітня 1991 р. N 83 Київ

Про перелік пам'яток архітектури, які не підлягають передачі у постійне користування релігійним організаціям

{ Із змінами, внесеними згідно з Постановами КМ N 198 ( 198-91-п ) від 14.09.81 N 311 ( 311-92-п ) від 08.06.92 N 947 ( 947-96-п ) від 14.08.96 N 94 ( 94-97-п ) від 30.01.97 N 1399 ( 1399-97-п ) від 15.12.97 N 1311 ( 1311-98-п ) від 17.08.98 N 928 ( 928-99-п ) від 29.05.99 N 1530 ( 1530-99-п ) від 19.08.99 }

З метою збереження визначних пам'яток культової архітектури, забезпечення особливого режиму їх утримання, використання в загальнонародних культурних інтересах Рада Міністрів Української РСР постановляє:

Затвердити перелік культових споруд - визначних пам'яток архітектури, які не підлягають передачі у постійне користування релігійним організаціям, згідно з додатком.

Виконкомам місцевих Рад народних депутатів привести прийняті рішення про передачу релігійним організаціям культових споруд, вказаних у додатку, у відповідність з цією постановою.
