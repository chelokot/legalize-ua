Про утворення Державної житлово-комунальної інспекції

Стан: Втратив чинність

Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 червня 2008 р. N 527 Київ

Про утворення Державної житлово-комунальної інспекції

{ Із змінами, внесеними згідно з Постановами КМ N 954 ( 954-2008-п ) від 22.10.2008 N 464 ( 464-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє:

1. Утворити Державну житлово-комунальну інспекцію як урядовий орган у системі Міністерства з питань житлово-комунального господарства.

{ Пункт 2 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

3. Міністерству з питань житлово-комунального господарства подати Кабінетові Міністрів України у двотижневий строк проект Положення про Державну житлово-комунальну інспекцію та здійснити інші заходи, пов'язані з її утворенням.
