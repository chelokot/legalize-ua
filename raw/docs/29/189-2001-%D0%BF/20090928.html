ПОСТАНОВА від 28 лютого 2001 р. N 189 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 977 ( 977-2009-п ) від 16.09.2009 }

Про першочергові заходи щодо створення захисних лісових насаджень на неугіддях та в басейнах річок

Кабінет Міністрів України постановляє:

1. Схвалити першочергові заходи щодо створення захисних лісових насаджень на неугіддях та в басейнах річок.

2. Державному комітетові по земельних ресурсах, Міністерству аграрної політики, Державному комітетові по водному господарству, Державному комітетові лісового господарства, Українській академії аграрних наук разом з Радою міністрів Автономної Республіки Крим та обласними державними адміністраціями визначити у термін до 1 липня 2001 р. землі для першочергового заліснення відповідно до розроблених проектів землеустрою.

3. Міністерству економіки та Міністерству фінансів передбачати щороку під час формування проектів Державного бюджету України видатки на фінансування першочергових заходів щодо створення захисних лісових насаджень на неугіддях та в басейнах річок.

Прем'єр-міністр України В.ЮЩЕНКО
