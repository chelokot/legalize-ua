Про затвердження складу наглядової ради Національного спортивного комплексу "Олімпійський"

Стан: Втратив чинність

Текст документа від 17.04.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 січня 2008 р. N 13 Київ

Про затвердження складу наглядової ради Національного спортивного комплексу "Олімпійський"

{ Із змінами, внесеними згідно з Постановою КМ N 371 ( 371-2008-п ) від 17.04.2008 }

Кабінет Міністрів України постановляє:

1. Затвердити склад наглядової ради Національного спортивного комплексу "Олімпійський", що додається.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 31 серпня 2006 р. N 1266 ( 1266-2006-п ) "Про затвердження складу наглядової ради Національного спортивного комплексу "Олімпійський".

3. Міністерству у справах сім'ї, молоді та спорту розробити і подати у двотижневий строк Кабінетові Міністрів України Положення про наглядову раду Національного спортивного комплексу "Олімпійський".
