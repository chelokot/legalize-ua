Кабінет Міністрів України; Постанова від 17.04.2008 № 363

Про закупівлю послуг, пов'язаних з формуванням інформаційно-телекомунікаційної системи Державного реєстру виборців

Стан: Втратив чинність

Ідентифікатор: 363-2008-п

Текст документа від 09.10.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 квітня 2008 р. N 363 Київ

{ Про втрату чинності Постанови, як такої, що не відповідає Конституції України (є неконституційною), див. Рішення Конституційного Суду N 22-рп/2008 ( v022p710-08 ) від 09.10.2008 }

{ Дію Постанови зупинено згідно з Указом Президента N 499/2008 ( 499/2008 ) від 02.06.2008 }

Про закупівлю послуг, пов'язаних з формуванням інформаційно-телекомунікаційної системи Державного реєстру виборців

Кабінет Міністрів України постановляє:

Відповідно до пункту 6 Тимчасового положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 28 березня 2008 р. N 274 ( 274-2008-п ), установити, що закупівля Центральною виборчою комісією послуг з розроблення та налагодження програмних засобів створення та ведення інформаційно-телекомунікаційної системи Державного реєстру виборців здійснюється за процедурою закупівлі в одного учасника без погодження з Міністерством економіки.

Прем'єр-міністр України Ю.ТИМОШЕНКО
