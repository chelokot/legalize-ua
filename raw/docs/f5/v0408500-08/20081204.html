Національний банк; Постанова від 01.12.2008 № 408

Про здійснення операцій з купівлі та продажу готівкових іноземних валют

Стан: Чинний

Ідентифікатор: v0408500-08

Текст документа від 04.12.2008:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

01.12.2008 N 408

Про здійснення операцій з купівлі та продажу готівкових іноземних валют

{ Із змінами, внесеними згідно з Постановою Національного банку N 413 ( v0413500-08 ) від 04.12.2008 }

Відповідно до статей 7, 15, 55 Закону України "Про Національний банк України" ( 679-14 ), 66, 67 Закону України "Про банки і банківську діяльність" ( 2121-14 ) та статті 8 Декрету Кабінету Міністрів України "Про систему валютного регулювання і валютного контролю" ( 15-93 ) Правління Національного банку України ПОСТАНОВЛЯЄ:

1. З 2 грудня 2008 року на готівковому валютному ринку України уповноважені банки та уповноважені фінансові установи здійснюють операції з купівлі та продажу готівкової іноземної валюти без обмежень щодо розміру маржі між курсом купівлі та продажу готівкової іноземної валюти та граничного відхилення курсу купівлі та продажу готівкової іноземної валюти від офіційного курсу гривні до іноземних валют, що встановлюється Національним банком України.

{ Пункт 2 втратив чинність на підставі Постанови Національного банку N 413 ( v0413500-08 ) від 04.12.2008 }

3. Ця постанова набирає чинності з дати її підписання.
