ПОСТАНОВА від 25 березня 2009 р. N 261 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про доповнення пункту 7 Положення про закупівлю товарів, робіт і послуг за державні кошти

Кабінет Міністрів України постановляє:

Доповнити пункт 7 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006; 2009 р., N 1, ст. 17, N 11, ст. 338), абзацом такого змісту:

"послуги з підготовки фахівців, наукових і науково-педагогічних кадрів, підвищення кваліфікації, перепідготовки кадрів (післядипломна освіта) та підготовки робітничих кадрів за державним замовленням.".
