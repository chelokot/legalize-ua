Про встановлення розміру збору за видачу ліцензій на експорт (імпорт) товарів

Стан: Чинний

Ідентифікатор: 362-2005-п

Текст документа від 10.03.2022:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 травня 2005 р. N 362 Київ

Про встановлення розміру збору за видачу ліцензій на експорт (імпорт) товарів

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 241 ( 241-2022-п ) від 10.03.2022 }

{ Із змінами, внесеними згідно з Постановою КМ N 241 ( 241-2022-п ) від 10.03.2022 }

Відповідно до статті 16 Закону України "Про зовнішньоекономічну діяльність" ( 959-12 ) Кабінет Міністрів України постановляє:

1. Установити такий розмір збору за видачу ліцензії на експорт (імпорт) товарів:

у режимі неавтоматичного ліцензування - 780 гривень;

у режимі автоматичного ліцензування - 220 гривень.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 241 ( 241-2022-п ) від 10.03.2022 }

1-1. Установити, що до припинення чи скасування воєнного стану в Україні збір за видачу ліцензії на експорт (імпорт) товарів не справляється.

{ Постанову доповнено пунктом 1-1 згідно з Постановою КМ N 241 ( 241-2022-п ) від 10.03.2022 }

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 5 листопада 1991 р. N 312 ( 312-91-п ) "Про порядок експорту товарів (робіт, послуг)" (ЗП України, 1991 р., N 12, ст. 125);

постанову Кабінету Міністрів України від 2 серпня 1996 р. N 893 ( 893-96-п ) "Про розмір державного збору за видачу імпортних ліцензій" (ЗП України, 1996 р., N 16, ст. 425).
