НАКАЗ Міністра оборони України

07.12.2006 N 715

Зареєстровано в Міністерстві юстиції України 18 грудня 2006 р. за N 1323/13197

Про затвердження Переліку посад військовослужбовців офіцерського складу, військовослужбовців рядового, сержантського і старшинського складу військової служби за контрактом, які забезпечуються харчуванням за рахунок держави за нормою N 1 - загальновійськова

{ Із змінами, внесеними згідно з Наказом Міністерства оборони N 586 ( z1205-07 ) від 10.10.2007 }

З метою упорядкування організації харчування військовослужбовців, які забезпечуються харчуванням за рахунок держави за нормою N 1 - загальновійськова, затвердженою постановою Кабінету Міністрів України від 29 березня 2002 року N 426 ( 426-2002-п ) "Про норми харчування військовослужбовців Збройних Сил, інших військових формувань та осіб рядового, начальницького складу органів і підрозділів цивільного захисту" (зі змінами та доповненнями), НАКАЗУЮ:

1. Затвердити Перелік посад військовослужбовців офіцерського складу, військовослужбовців рядового, сержантського і старшинського складу військової служби за контрактом, які забезпечуються харчуванням за рахунок держави за нормою N 1 - загальновійськова, що додається.

2. Наказ Міністра оборони України від 21 травня 2003 року N 145 ( z0410-03 ) "Про затвердження Переліку посад військовослужбовців офіцерського складу, прапорщиків, мічманів і військовослужбовців рядового, сержантського і старшинського складу, які проходять військову службу за контрактом, постійно працюють на аеродромах, полігонах, технічних і стартових позиціях і безпосередньо обслуговують літальні апарати та забезпечуються харчуванням за рахунок держави за нормою N 1 - загальновійськова", зареєстрований в Міністерстві юстиції України 27 травня 2003 року за N 410/7731, уважати таким, що втратив чинність.

3. Наказ розіслати згідно з розрахунком розсилки.

старші водії, водії всіх спеціальностей, старші водії-механіки, водії-механіки, механіки-водії, водії-кранівники, старші водії-електрики, водії-машиністи компресора, старші водії-оператори, механіки-оператори, старші водії-машиністи заправних машин, водії пожежної обслуги, водії-апаратники, водії-хіміки, трактористи всіх спеціальностей, трактористи-механіки, машиністи бульдозера, машиністи екскаватора, трактористи-машиністи, які займаються аеродромно-технічним забезпеченням і наземним обслуговуванням польотів у дні забезпечення польотів;

начальники заправних пунктів літальних апаратів, начальники складів авіаційного пального, начальники електростанцій, компресорних станцій, газозарядних станцій, старші мотористи, мотористи, машиністи компресорів, механіки-акумуляторники, пожежні та старші пожежні пожежних обслуг у дні забезпечення польотів;

в авіаційних бригадах, полках, окремих батальйонах, батальйонах зв'язку та радіотехнічного забезпечення, батальйонах автоматизованого управління, окремих вузлах, вузлах зв'язку та радіотехнічного забезпечення, центрах бойового управління, авіаційних комендатурах (які забезпечують виконання польотів):

начальники радіостанцій, радіомаркетних пунктів, радіопеленгаторних пунктів, старші техніки, техніки (техніки-начальники змін), командири відділень, старші механіки, механіки, водії-електрики, електрики, електрики-дизелісти, старші оператори, оператори, водії-прожектористи (прожектористи) у дні забезпечення польотів; { Абзац п'ятнадцятий пункту 2 із змінами, внесеними згідно з Наказом Міністерства оборони N 586 ( z1205-07 ) від 10.10.2007 }

на випробному полігоні злітно-посадкових систем у період забезпечення проведення польотів та випробувань: { Пункт 2 доповнено абзацом шістнадцятим згідно з Наказом Міністерства оборони N 586 ( z1205-07 ) від 10.10.2007 }

старші техніки та техніки, механіки відділення випробування та обслуговування корабельних злітно-посадкових систем; { Пункт 2 доповнено абзацом сімнадцятим згідно з Наказом Міністерства оборони N 586 ( z1205-07 ) від 10.10.2007 }

старші техніки та техніки, механіки електромеханічного відділу випробного полігона злітно-посадкових систем; { Пункт 2 доповнено абзацом вісімнадцятим згідно з Наказом Міністерства оборони N 586 ( z1205-07 ) від 10.10.2007 }

старші техніки та техніки, дешифрувальники відділення підготовки та регламенту контрольно-записувальної апаратури випробного полігона злітно-посадкових систем; { Пункт 2 доповнено абзацом дев'ятнадцятим згідно з Наказом Міністерства оборони N 586 ( z1205-07 ) від 10.10.2007 }

начальники станцій посадки літаків, техніки та механіки відділень зв'язку та радіотехнічного забезпечення польотів випробного полігона злітно-посадкових систем; { Пункт 2 доповнено абзацом двадцять першим згідно з Наказом Міністерства оборони N 586 ( z1205-07 ) від 10.10.2007 }

командири відділень, водії автомобільних відділень випробного полігона злітно-посадкових систем. { Пункт 2 доповнено абзацом двадцять другим згідно з Наказом Міністерства оборони N 586 ( z1205-07 ) від 10.10.2007 }

Примітки:

1. Харчуванням за рахунок держави за нормою N 1 - загальновійськова забезпечуються військовослужбовці офіцерського складу, військовослужбовці рядового, сержантського і старшинського складу військової служби за контрактом, інженерно-технічного складу авіації:

військовослужбовці офіцерського складу, військовослужбовці рядового, сержантського і старшинського складу військової служби за контрактом, тимчасово призначені наказами командирів авіаційних, авіаційно-технічних військових частин, військових частин зв'язку і радіотехнічного забезпечення на посади, перераховані в пунктах 1 і 2 цього Переліку;

військовослужбовці рядового, сержантського і старшинського складу військової служби за контрактом, що займають офіцерські посади, перераховані в пункті 1 цього Переліку;

військовослужбовці офіцерського складу, військовослужбовці рядового, сержантського і старшинського складу військової служби за контрактом, що займають посади, які мають подвійне найменування, якщо одне з цих найменувань передбачене в пунктах 1 і 2 цього Переліку;

військовослужбовці офіцерського складу пошукових передових командних пунктів з вузлами зв'язку і радіонавігаційних пунктів, що займають посади, перераховані в пункті 1 цього Переліку;

військовослужбовці офіцерського складу, військовослужбовці рядового, сержантського і старшинського складу військової служби за контрактом, літаючих (авіаційно-технічних) лабораторій під час роботи з безпосереднього обслуговування літальних апаратів.

2. При організації харчування військовослужбовців офіцерського складу, військовослужбовців рядового, сержантського і старшинського складу військової служби за контрактом і які проходять службу в місцевостях із складними кліматичними умовами, на висоті від 1000 до 1500 метрів над рівнем моря, керуватися наказом Міністра оборони України від 2 квітня 2003 року N 85 ( z0279-03 ) "Про затвердження переліку військових частин, підрозділів і установ, особовому складу яких вислуга років на пенсію зараховується на пільгових умовах", зареєстрованим у Міністерстві юстиції України 9 квітня 2003 року за N 279/7600 (із змінами).
