РОЗПОРЯДЖЕННЯ від 21 вересня 2011 р. N 893-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 202-р ( 202-2023-р ) від 08.03.2023 }

Про генерального конструктора із створення вибухових речовин і боєприпасів

1. Надати генеральному директору державного підприємства "Державне Київське конструкторське бюро "Луч" Коростельову Олегу Петровичу повноваження генерального конструктора із створення вибухових речовин і боєприпасів.

2. Визнати таким, що втратив чинність, пункт 1 розпорядження Кабінету Міністрів України від 27 грудня 2001 р. N 615 ( 615-2001-р ) "Про генерального конструктора із створення вибухових речовин і боєприпасів".
