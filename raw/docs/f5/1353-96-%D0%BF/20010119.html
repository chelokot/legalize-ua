Кабінет Міністрів України; Постанова від 08.11.1996 № 1353

Про внесення змін до преференційних ставок ввізного мита на окремі види товарів

Стан: Втратив чинність

Ідентифікатор: 1353-96-п

Текст документа від 19.01.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 листопада 1996 р. N 1353 Київ

( Постанова втратила чинність на підставі Постанови КМ N 16 ( 16-2001-п ) від 12.01.2001 )

Про внесення змін до преференційних ставок ввізного мита на окремі види товарів

Кабінет Міністрів України постановляє:

Внести зміни до преференційних ставок ввізного мита ( 4а-93, 4б-93, 4в-93 ), затверджених Декретом Кабінету Міністрів України від 11 січня 1993 р. N 4 ( 4-93 ) "Про Єдиний митний тариф України", на товари (у межах товарних груп 1-24 ТН ЗЕД), крім підакцизних, встановивши їх на рівні 100 відсотків від пільгових ставок ввізного мита на ці товари.

Прем'єр-міністр України П.ЛАЗАРЕНКО
