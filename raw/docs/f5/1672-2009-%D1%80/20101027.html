Кабінет Міністрів України; Розпорядження від 29.12.2009 № 1672-р

Питання надання громадянам квартир, що придбані Державною іпотечною установою, у м. Кременчуці

Стан: Чинний

Ідентифікатор: 1672-2009-р

Текст документа від 27.10.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 грудня 2009 р. N 1672-р Київ

Питання надання громадянам квартир, що придбані Державною іпотечною установою, у м. Кременчуці

{ Із змінами, внесеними згідно з Постановою КМ N 961 ( 961-2010-п ) від 20.10.2010 }

1. Затвердити погоджені Координаційною радою з питань розподілу квартир, що придбані Державною іпотечною установою, при Кабінеті Міністрів України поіменні списки громадян, яким надаються придбані у м. Кременчуці Полтавської області (мікрорайон номер 278, буд. 37, та пров. О. Кошового, 14б) квартири (далі - списки), що додаються до оригіналу.

2. Державній іпотечній установі передати Міністерству оборони, Міністерству внутрішніх справ, Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Державній прикордонній службі, Державному департаменту з питань виконання покарань, Генеральній прокуратурі України та Кременчуцькій міській раді квартири для надання зазначеним у списках громадянам.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 961 ( 961-2010-п ) від 20.10.2010 }

3. Виконавчому комітетові Кременчуцької міської ради забезпечити в установленому законодавством порядку видачу зазначеним у списках громадянам ордерів на жилі приміщення.

4. Міністерству оборони, Міністерству внутрішніх справ, Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Державній прикордонній службі, Державному департаменту з питань виконання покарань, Генеральній прокуратурі України та Кременчуцькій міській раді забезпечити неухильне дотримання встановленого Кабінетом Міністрів України порядку розподілу квартир, що придбані Державною іпотечною установою.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 961 ( 961-2010-п ) від 20.10.2010 }
