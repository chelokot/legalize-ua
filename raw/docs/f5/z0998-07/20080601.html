МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

20.08.2007 N 725

Зареєстровано в Міністерстві юстиції України 31 серпня 2007 р. за N 998/14265

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 533 ( z0430-08 ) від 13.05.2008 }

Про внесення зміни до Тарифів на перевезення пасажирів, багажу і вантажобагажу залізничним транспортом у внутрішньому сполученні

Згідно з постановою Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

1. Зупинити індексацію вартості проїзду пасажирів у пасажирських поїздах, перевезення багажу, перевезення вантажобагажу в орендованих багажних вагонах та перевезення пасажирських вагонів у порожньому стані з 1 вересня 2007 року, передбачену абзацом п'ятим пункту 3 Тарифів на перевезення пасажирів, багажу і вантажобагажу залізничним транспортом у внутрішньому сполученні, затверджених наказом Міністерства транспорту та зв'язку України від 26.04.2006 N 395 ( z0652-06 ) (із змінами, унесеними наказами Міністерства транспорту та зв'язку України від 29.12.2006 N 1222 ( z1386-06 ), зареєстрованим в Міністерстві юстиції України 29.12.2006 за N 1386/13260, та від 27.01.2007 N 58 ( z0068-07 ), зареєстрованим в Міністерстві юстиції України 27.01.2007 за N 68/13335), зареєстрованим в Міністерстві юстиції України 01.06.2006 за N 652/12526.

2. Державній адміністрації залізничного транспорту України (Козак В.В.):

2.1. Подати цей наказ для державної реєстрації до Міністерства юстиції України в установленому порядку.

2.2. Забезпечити правильне застосування зміни до Тарифів ( z0652-06 ) і проінформувати про це населення на вокзалах та пунктах продажу проїзних документів.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Фоменко К.О.

Міністр М.Рудьковський
