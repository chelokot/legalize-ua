Зареєстровано в Міністерстві юстиції України 5 серпня 2005 р. за N 862/11142

Про втрату чинності деяких наказів Міністерства транспорту України

Відповідно до Положення про Міністерство транспорту та зв'язку України, затвердженого Указом Президента України від 27.08.2004 N 1009 ( 1009/2004 ), НАКАЗУЮ:

1. Уважати такими, що втратили чинність, накази Міністерства транспорту України:

від 26 січня 1995 року N 41 ( z0019-95 ) "Про затвердження Тарифів на перевезення пасажирів і багажу залізничним транспортом в міждержавному та внутрішньодержавному сполученні", зареєстрований в Міністерстві юстиції України 26 січня 1995 року за N 19/555;

від 1 квітня 1997 року N 125 ( z0165-97 ) "Про затвердження Тарифів на перевезення пасажирів і багажу залізничним транспортом у міжнародному сполученні", зареєстрований в Міністерстві юстиції України 6 травня 1997 року за N 165/1969;

від 28 вересня 1998 року N 386 ( z0639-98 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні", зареєстрований в Міністерстві юстиції України 9 жовтня 1998 року за N 639/3079;

від 28 квітня 1999 року N 218 ( z0307-99 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід - Захід", зареєстрований в Міністерстві юстиції України 14 травня 1999 року за N 307/3600;

від 19 листопада 2003 року N 897 ( z1113-03 ) "Про затвердження Тарифів на перевезення пасажирів та багажу залізничним транспортом у міжнародному сполученні Схід - Захід", зареєстрований в Міністерстві юстиції України 3 грудня 2003 року за N 1113/8434;

від 8 грудня 2003 року N 952 ( z1204-03 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні", зареєстрований в Міністерстві юстиції України 23 грудня 2003 року за N 1204/8525.

2. Державній адміністрації залізничного транспорту України (Федюшин Ю.М.) подати цей наказ в установленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Міністра - Генерального директора Укрзалізниці Афтаназіва З.С.
