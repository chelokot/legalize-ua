Про заходи щодо підвищення ефективності використання залізничних вантажних вагонів

Стан: Чинний

Ідентифікатор: 706-2004-р

Текст документа від 30.07.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 жовтня 2004 р. N 706-р Київ

Про заходи щодо підвищення ефективності використання залізничних вантажних вагонів

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1039-р ( 1039-2008-р ) від 30.07.2008 }

{ Пункт 1 втратив чинність на підставі Розпорядження КМ N 1039-р ( 1039-2008-р ) від 30.07.2008 }

2. Мінтрансзв'язку:

подати до 1 грудня 2004 р. Кабінетові Міністрів України пропозиції щодо механізму індексації тарифів з урахуванням зміни індексу цін виробників промислової продукції та механізму стимулювання придбання нових залізничних вантажних вагонів у власність підприємствами - користувачами транспортних послуг;

забезпечити у 2004 році збільшення на 20 відсотків обсягів фінансування ремонту вагонів на вагоноремонтних підприємствах та до кінця поточного року забезпечити переобладнання із заміною кузова 450 вагонів, не придатних для перевезення вантажів.

3. Мінпромполітики, Мінпаливенерго та облдержадміністраціям:

вжити заходів, спрямованих на дотримання промисловими підприємствами норм простоїв вагонів під вантажними операціями, передбачених єдиними технологічними процесами роботи під'їзних колій та станцій примикання;

сприяти розвитку колійного господарства промислових підприємств, оновленню їх технічних засобів, закупівлі нового рухомого складу, в тому числі локомотивів, збільшенню переробної спроможності, місць вантаження та розвантаження вагонів.

Прем'єр-міністр України В.ЯНУКОВИЧ
