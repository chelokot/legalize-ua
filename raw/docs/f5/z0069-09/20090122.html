Про внесення змін до наказу Міністерства юстиції України від 15.04.97 N 149/7

Відповідно до статті 9 Закону України "Про судову експертизу" ( 4038-12 ) та з метою вдосконалення порядку ведення державного Реєстру атестованих судових експертів НАКАЗУЮ:

1. Унести зміни до Порядку ведення державного Реєстру атестованих судових експертів,затвердженого наказом Міністерства юстиції України від 15.04.97 N 149/7 ( z0166-97 ) (у редакції наказу Мін'юсту від 24.04.2008 N 672/5) ( z0376-08 ), зареєстрованого в Міністерстві юстиції України 06.05.97 за N 166/1970, виклавши додаток 1 до нього у новій редакції, що додається.

2. Управлінню експертного забезпечення правосуддя (Л.М.Головченко) забезпечити подання цього наказу на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади".

3. Контроль за виконанням цього наказу покласти на заступника Міністра В.В.Богатиря.

Міністр Микола Оніщук

Додаток 1 до Порядку ведення державного Реєстру атестованих судових експертів ( z0166-97 )
