Стан: Втратив чинність

ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

N 763 від 22.11.2001 Зареєстровано в Міністерстві м.Київ юстиції України 7 грудня 2001 р. за N 1020/6211

{ Наказ втратив чинність на підставі Наказу Міністерства фінансів N 706 ( z1100-17 ) від 19.08.2017 }

Про затвердження Порядку декларування валютних цінностей, цінностей, предметів, що переміщуються через митний кордон України громадянами, і оформлення митної декларації та про внесення змін до наказу Держмитслужби України від 08.10.99 N 645

{ Рішення про державну реєстрацію Порядку декларування валютних цінностей, цінностей, предметів, що переміщуються через митний

кордон України громадянами, і оформлення митної декларації

скасовано на підставі Висновку Міністерства юстиції

N 11/84 ( v11_8323-07 ) від 11.07.2007 }

{ Виключено з Державного реєстру нормативно-правових актів 03.08.2007 }

{ Із змінами, внесеними згідно з Наказами Державної митної служби N 648 ( v0648342-07 ) від 31.07.2007 N 604 ( z0629-08 ) від 04.06.2008 }

Відповідно до Митного кодексу України ( 1970-12 ), постанови Кабінету Міністрів України від 15.07.97 N 748 ( 748-97-п ) "Про перелік відомостей, що оголошуються громадянами за встановленою формою у разі переміщення ними через митний кордон України товарів та інших предметів" та з метою впорядкування декларування громадянами товарів та інших предметів НАКАЗУЮ:

{ Пункт 1 скасовано на підставі Наказу Державної митної служби N 648 ( v0648342-07 ) від 31.07.2007 }

{ Пункт 2 фактично втратив чинність у зв'язку з втратою чинності Наказу Державної митної служби України N 645 ( z0739-99 ) від 08.10.99, до якого вносились зміни }

2. Унести до Порядку митного оформлення несупроводжуваного багажу, що переміщується через митний кордон України, затвердженого наказом Держмитслужби України від 08.10.99 N 645 ( z0739-99 ) і зареєстрованого в Міністерстві юстиції України 29.10.99 за N 739/4032, такі зміни:

2.1. У тексті Порядку слова "пасажирська митна декларація" у всіх відмінках замінити словами "митна декларація" у відповідному відмінку.

2.2. Пункт 2.1 викласти в такій редакції:

"2.1. Факт відправлення НСБ із-за кордону зазначається в митній декларації, яка заповнюється власником в 1 примірнику на прикордонній митниці при в'їзді в Україну.

Митна декларація, засвідчена відтиском особистої номерної печатки посадової особи митного органу, залишається у власника НСБ".

2.3. Пункт 2.4 викласти в такій редакції:

"2.4. Предмети та цінності, що містяться в НСБ, декларуються на окремому бланку митної декларації".

2.4. У пункті 3.1 слова "за місцем прописки" замінити словами "за місцем постійного проживання".

2.5. Пункт 3.2 викласти в такій редакції:

"3.2. При відправленні НСБ за межі України його власник або інша особа, яка діє за нотаріально засвідченим дорученням власника цього багажу, заповнює митну декларацію у 2 примірниках, у кожному з яких зазначає відомості про вміст НСБ".

2.6. Пункт 3.3 викласти в такій редакції:

"3.3. Після оформлення НСБ перший примірник митної декларації залишається в справах митного органу, другий - додається до товаросупровідних документів на НСБ".

3. Управлінню організації митного контролю (Терещенко С.С.) та Правовому управлінню (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Управлінню аналізу, прогнозування та зв'язків з громадськістю (Козик Л.Г.) забезпечити висвітлення наказу в засобах масової інформації.

5. Начальникам регіональних митниць, митниць інформувати громадян про затверджений Порядок, у тому числі шляхом висвітлення його в місцевих засобах масової інформації та на наочних інформаційних стендах у місцях розташування відповідних підрозділів митниць і в пунктах пропуску через державний кордон України.

6. Управлінню справами (Карпенко В.П.) забезпечити тиражування та розсилку цього наказу регіональним митницям, митницям після його державної реєстрації.

7. Контроль за виконанням цього наказу покласти на заступника Голови Служби Пашка П.В.
