( Наказ втратив чинність на підставі Наказу Державного комітету статистики N 73 ( z0334-05 ) від 16.03.2005 )

Про затвердження вартості одного людино-дня та вартості інформації на одній сторінці

На виконання пункту 5 Положення про виконання статистичних робіт та надання органами державної статистики послуг на платній основі, затвердженого постановою Кабінету Міністрів України від 3 серпня 1998 року N 1214 ( 1214-98-п ), із змінами і доповненнями, внесеними постановою Кабінету Міністрів України від 16 березня 2000 року N 501 ( 501-2000-п ), НАКАЗУЮ:

1. Затвердити вартість одного людино-дня для встановлення вартості статистичних робіт та послуг, що оплачуються за рахунок замовників, у центральному апараті Держкомстату України в сумі 51,32 грн. відповідно до розрахунку, що додається.

2. Затвердити вартість інформації на одній сторінці для встановлення вартості статистичних робіт та послуг, що оплачуються за рахунок замовників, у центральному апараті Держкомстату України в сумі 0,11 грн. відповідно до розрахунку ( z0838-00 ), що додається.

3. Скасувати наказ Держкомстату України від 13 травня 1999 року N 162 "Про затвердження тимчасової вартості одного людино-дня".

4. Контроль за виконанням наказу покласти на заступника Голови комітету Шишкіну К.М.

Голова комітету О.Г.Осауленко

Затверджено Наказ Держкомстату України 08.11.2000 N 354

Зареєстровано в Міністерстві юстиції України 17 листопада 2000 р. за N 837/5058

Розрахунок вартості одного людино-дня для встановлення вартості статистичних робіт та послуг, що оплачуються за рахунок замовників, у центральному апараті Держкомстату України

1. Витрати, пов'язані з наданням 3965821 грн. платних послуг

2. Чисельність працівників, які 336 надають платні послуги

3. Середньорічна кількість робочих днів 230

Вартість одного людино-дня: 3965821 грн./(336 х 230 ) = 51,32 грн.
