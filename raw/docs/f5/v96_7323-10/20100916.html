МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

12.04.2010 N 296/7

Про затвердження Графіків особистого прийому громадян у Міністерстві юстиції

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 895/7 ( v0895323-10 ) від 16.09.2010 }

Відповідно до статті 22 Закону України "Про звернення громадян" ( 393/96-ВР ) та у зв'язку із змінами в організаційній структурі Міністерства юстиції НАКАЗУЮ:

1. Затвердити Графік особистого прийому громадян Міністром, першим заступником Міністра, заступниками Міністра та Графік особистого прийому громадян посадовими особами структурних підрозділів Міністерства (далі - графіки), що додаються.

2. Першому заступнику Міністра юстиції, заступникам Міністра юстиції, директорам департаментів, начальникам управлінь забезпечити виконання зазначених графіків.

3. Визнати таким, що втратив чинність, наказ Міністерства юстиції України від 29.09.2009 N 852/7 ( v0852323-09 ).

4. Прес-службі Міністерства юстиції через засоби масової інформації оприлюднити графіки.

5. Управлінню розгляду звернень та прийому громадян забезпечити організацію особистого прийому громадян відповідно до затверджених графіків.

6. Контроль за виконанням цього наказу залишаю за собою.

Міністр О.Лавринович
