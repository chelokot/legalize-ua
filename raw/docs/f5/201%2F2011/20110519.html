Про делегацію України для участі у сесіях Виконавчої ради Організації по забороні хімічної зброї

Стан: Втратив чинність

Ідентифікатор: 201/2011

Текст документа від 19.05.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про делегацію України для участі у сесіях Виконавчої ради Організації по забороні хімічної зброї

{ Із змінами, внесеними згідно з Указом Президента N 576/2011 ( 576/2011 ) від 12.05.2011 }

1. Утворити делегацію України для участі у 63-й та 64-й сесіях Виконавчої ради Організації по забороні хімічної зброї (лютий - травень 2011 року, м. Гаага, Королівство Нідерланди) в такому складі:

ГОРІН - Надзвичайний і Повноважний Посол

Олександр Олегович України в Королівстві Нідерланди, глава делегації

ЗАЙЦЕВ - завідувач кафедри аналітичної

Володимир Миколайович хімії Київського національного університету імені Тараса Шевченка, член-кореспондент Національної академії наук України, доктор хімічних наук, заступник глави делегації (за згодою)

КВАСЮК - державний експерт Департаменту

Володимир Анатолійович зовнішньополітичних аспектів національної безпеки Апарату Ради національної безпеки і оборони України

КОРОБКА - начальник військ радіаційного,

Віктор Петрович хімічного і біологічного захисту Збройних Сил України - начальник Центрального управління військ радіаційного, хімічного і біологічного захисту Головного управління оперативного забезпечення Збройних Сил України

ЛАТИШЕВ - експерт Служби безпеки України

Руслан Володимирович

ТОКАРСЬКИЙ - головний консультант Головного

Юрій Богданович управління міжнародних відносин Адміністрації Президента України

СУББОТІН - радник Посольства України

Костянтин Васильович в Королівстві Нідерланди.

Дозволити главі делегації визначати за погодженням із Міністром закордонних справ України членів делегації України, які відряджаються для участі у кожній із сесій Виконавчої ради Організації по забороні хімічної зброї, але не більше трьох осіб одночасно.

{ Стаття 1 із змінами, внесеними згідно з Указом Президента N 576/2011 ( 576/2011 ) від 12.05.2011 }

2. Міністру закордонних справ України затвердити вказівки делегації України на 63-ю та 64-у сесії Виконавчої ради Організації по забороні хімічної зброї.

3. Кабінету Міністрів України вирішити питання фінансового забезпечення участі у сесіях Виконавчої ради Організації по забороні хімічної зброї В. Зайцева, В. Квасюка, В. Коробки, Р. Латишева, Ю. Токарського.

4. Визнати таким, що втратив чинність, Указ Президента України від 22 липня 2009 року N 567 ( 567/2009 ) "Про делегацію України на сесії Виконавчої ради Організації по забороні хімічної зброї".

Президент України В.ЯНУКОВИЧ

м. Київ, 14 лютого 2011 року N 201/2011
