{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 172 ( z0390-07 ) від 17.04.2007 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 21.06.2004 N 139

На виконання постанови Кабінету Міністрів України від 25.08.2004 N 1097 ( 1097-2004-п ) "Про підвищення з 1 вересня 2004 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести до наказу Міністерства праці та соціальної політики України від 21.06.2004 N 139 ( z0770-04 ) "Про умови оплати праці працівників Центру сприяння інституційному розвитку державної служби", зареєстрованого в Міністерстві юстиції України 23.06.2004 за N 770/9369, такі зміни:

1.1. У пункті 1 наказу слова "керівних працівників та спеціалістів" замінити словом "працівників";

1.2. Викласти додаток у новій редакції, що додається.

2. Ці зміни застосовуються з 1 вересня 2004 року.

Міністр М.Папієв
