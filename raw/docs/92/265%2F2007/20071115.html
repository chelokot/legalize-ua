Про зупинення дії постанови Кабінету Міністрів України від 3 квітня 2007 року N 595

Стан: Втратив чинність

Ідентифікатор: 265/2007

Текст документа від 15.11.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 986/2007 ( 986/2007 ) від 22.10.2007 }

Про зупинення дії постанови Кабінету Міністрів України від 3 квітня 2007 року N 595

{ Додатково див. Конституційне подання Президента ( n0005100-07 ) від 03.04.2007 }

Кабінетом Міністрів України 3 квітня 2007 року прийнято постанову N 595 ( 595-2007-п ) "Про невідкладні заходи щодо забезпечення виконання постанов Верховної Ради України від 2 квітня 2007 р. N 837-V "Про запобігання діям, що загрожують конституційному правопорядку, громадському спокою і стабільності в Україні" та N 839-V "Про політичну ситуацію в Україні, пов'язану з оголошенням Указу Президента України від 2 квітня 2007 року "Про дострокове припинення повноважень Верховної Ради України".

Як зазначено у преамбулі постанови N 595 ( 595-2007-п ), Кабінет Міністрів України виходить, зокрема, з того, що Постановою Верховної Ради України від 2 квітня 2007 року N 839-V ( 839-16 ) Указ Президента України від 2 квітня 2007 року N 264 ( 264/2007 ) "Про дострокове припинення повноважень Верховної Ради України" визнано таким, що виданий з порушенням Конституції України ( 254к/96-ВР ).

Таким чином, Кабінет Міністрів України вирішив питання про відповідність Конституції України ( 254к/96-ВР ) акта Президента України, чим фактично перебрав на себе повноваження, яке за Конституцією України ( 254к/96-ВР ) належить виключно Конституційному Суду України.

Зазначене суперечить статтям 147, 150 Конституції України ( 254к/96-ВР ), якими єдиним органом конституційної юрисдикції в Україні, що вирішує питання про відповідність законів та інших правових актів Конституції України ( 254к/96-ВР ), визначено Конституційний Суд України.

Пунктом 1 зазначеної постанови Кабінету Міністрів України ( 595-2007-п ) міністерствам та іншим центральним органам виконавчої влади на виконання Постанови Верховної Ради України від 2 квітня 2007 року N 837-V ( 837-16 ) "Про запобігання діям, що загрожують конституційному правопорядку, громадському спокою і стабільності в Україні" доручено забезпечити здійснення своїх повноважень, передбачених Конституцією ( 254к/96-ВР ) та законами України.

При цьому жодним чином не зазначено про необхідність керуватись під час здійснення таких повноважень актами Президента України. Цим знехтувано конституційні приписи, за якими Кабінет Міністрів України у своїй діяльності керується також указами Президента України, укази і розпорядження глави держави є обов'язковими до виконання на території України (частина третя статті 113, частина третя статті 106 ( 254к/96-ВР ).

Фактичним саботуванням доручення Кабінету Міністрів України забезпечити фінансування позачергових виборів до Верховної Ради України, наданого статтею 4 Указу Президента України від 2 квітня 2007 року N 264 ( 264/2007 ), є встановлена Кабінетом Міністрів України заборона Міністерству фінансів України щодо виділення коштів на проведення позачергових виборів до Верховної Ради України (пункт 4 постанови Кабінету Міністрів України ( 595-2007-п ).

Така заборона суперечить і статті 48 Закону України "Про вибори народних депутатів України" ( 1665-15 ) щодо фінансування виборів народних депутатів України, а відтак - і частині другій статті 77 Конституції України ( 254к/96-ВР ), за якою порядок проведення виборів народних депутатів України встановлюється законом.

Отже, приймаючи постанову ( 595-2007-п ) всупереч Основному Закону України ( 254к/96-ВР ), Кабінет Міністрів України порушив також норми частини другої статті 6 та частини другої статті 19 Конституції України ( 254к/96-ВР ), за якими органи державної влади зобов'язані здійснювати свої повноваження у встановлених Конституцією ( 254к/96-ВР ) межах та на її підставі.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 3 квітня 2007 року N 595 ( 595-2007-п ) "Про невідкладні заходи щодо забезпечення виконання постанов Верховної Ради України від 2 квітня 2007 р. N 837-V "Про запобігання діям, що загрожують конституційному правопорядку, громадському спокою і стабільності в Україні" та N 839-V "Про політичну ситуацію в Україні, пов'язану з оголошенням Указу Президента України від 2 квітня 2007 року "Про дострокове припинення повноважень Верховної Ради України" як такої, що не відповідає Конституції України ( 254к/96-ВР ).

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
