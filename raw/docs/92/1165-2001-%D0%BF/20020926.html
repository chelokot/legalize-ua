КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 вересня 2001 р. N 1165 Київ

Про внесення змін до постанови Кабінету Міністрів України від 17 лютого 2000 р. N 339

( Щодо змін додатково див. Постанови КМ N 1538 ( 1538-2001-п ) від 17.11.2001 N 1679 ( 1679-2001-п ) від 13.12.2001 N 810 ( 810-2002-п ) від 13.06.2002 N 1443 ( 1443-2002-п ) від 26.09.2002 )

Кабінет Міністрів України постановляє:

1. На зміну пункту 1 постанови Кабінету Міністрів України від 17 лютого 2000 р. N 339 ( 339-2000-п ) "Про урядові комітети" (Офіційний вісник України, 2000 р., N 7, ст. 283) установити, що в Кабінеті Міністрів України діють такі урядові комітети:

Урядовий комітет з питань оборони, оборонно-промислового комплексу та правоохоронної діяльності;

Урядовий комітет з питань промислової політики, паливно-енергетичного комплексу, екології та надзвичайних ситуацій;

Урядовий комітет економічного розвитку та з питань європейської інтеграції;

Урядовий комітет соціального, науково-технічного та гуманітарного розвитку;

Урядовий комітет з реформування аграрного сектору.

2. Затвердити посадовий склад урядових комітетів згідно з додатками 1 - 5.

3. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком (додається).

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 13 вересня 2001 р. N 1165

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Пункт 1, підпункти 1 і 2 пункту 2 постанови Кабінету Міністрів України від 20 листопада 2000 р. N 1723 ( 1723-2000-п ) "Про утворення Урядового комітету з питань національної безпеки і оборони, оборонно-промислового комплексу та правоохоронної діяльності та внесення змін і доповнень до постанови Кабінету Міністрів України від 17 лютого 2000 р. N 339" (Офіційний вісник України, 2000 р., N 47, ст. 2038).

2. Постанова Кабінету Міністрів України від 6 грудня 2000 р. N 1796 ( 1796-2000-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 20 листопада 2000 р. N 1723" (Офіційний вісник України, 2000 р., N 50, ст. 2157).

3. Постанова Кабінету Міністрів України від 16 лютого 2001 р. N 154 ( 154-2001-п ) "Про перейменування Урядового комітету з реформування паливно-енергетичного комплексу" (Офіційний вісник України, 2001 р., N 8, ст. 318).

4. Постанова Кабінету Міністрів України від 14 березня 2001 р. N 235 ( 235-2001-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 20 листопада 2000 р. N 1723" (Офіційний вісник України, 2001 р., N 11, ст. 444).

5. Постанова Кабінету Міністрів України від 18 червня 2001 р. N 656 ( 656-2001-п ) "Деякі питання урядових комітетів" (Офіційний вісник України, 2001 р., N 25, ст. 1112).
