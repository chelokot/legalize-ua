Реєстрація: Мін'юст України від 19.06.2007 № 676/13943

Стан: Втратив чинність

Ідентифікатор: z0676-07

Текст документа від 01.09.2008:

НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

14.06.2007 N 750

Зареєстровано в Міністерстві юстиції України 19 червня 2007 р. за N 676/13943

{ Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 934 ( z0769-08 ) від 07.08.2008 }

Про затвердження роздрібних цін на природний газ, що використовується для потреб населення смт Солотвина Закарпатської області безпосередньо із Солотвинського родовища, та внесення змін до постанови НКРЕ від 19.12.2006 N 1672

Відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та враховуючи звернення ВАТ "Закарпатгаз" (лист від 27.03.2007 N 11/670), Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Затвердити роздрібні ціни на природний газ, що використовується для потреб населення смт Солотвина Закарпатської області безпосередньо із Солотвинського родовища (додаються).

2. Унести до постанови НКРЕ від 19.12.2006 N 1672 ( z1330-06 ) "Про роздрібні ціни на природний газ, що використовується для потреб населення", зареєстрованої у Міністерстві юстиції України 20.12.2006 за N 1330/13204, такі зміни:

пункт 1 викласти в такій редакції:

"1. Затвердити роздрібні ціни на природний газ, що використовується для потреб населення, крім населення смт Солотвина Закарпатської області, яке споживає природний газ безпосередньо із Солотвинського родовища (додаються)";

назву "Роздрібні ціни на природний газ, що використовується для потреб населення", затверджені цією постановою, викласти в такій редакції: "Роздрібні ціни на природний газ, що використовується для потреб населення, крім населення смт Солотвина Закарпатської області, яке споживає природний газ безпосередньо із Солотвинського родовища".

3. Управлінню регулювання та цінової політики нафтогазового комплексу в установленому порядку забезпечити подання цієї постанови на державну реєстрацію до Міністерства юстиції України.

4. Постанову НКРЕ від 03.08.2006 N 1034 ( z0986-06 ) "Про роздрібні ціни на газ природний, що використовується для потреб населення смт Солотвина Закарпатської області безпосередньо із Солотвинського родовища та внесення змін до постанови НКРЕ від 08.06.2006 N 739", зареєстровану в Міністерстві юстиції України 18.08.2006 за N 986/12860, визнати такою, що втратила чинність.

5. Ця постанова набуває чинності з 1 липня 2007 року.

Голова Комісії С.Тітенко
