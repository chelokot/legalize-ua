Питання участі в Міжнародній асоціації органів страхового нагляду та Міжнародній організації органів нагляду за пенсійними фондами

Стан: Чинний

Ідентифікатор: 797-2007-р

Текст документа від 06.04.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 вересня 2007 р. N 797-р Київ

Питання участі в Міжнародній асоціації органів страхового нагляду та Міжнародній організації органів нагляду за пенсійними фондами

{ Із змінами, внесеними згідно з Постановою КМ N 256 ( 256-2012-п ) від 28.03.2012 }

Взяти до відома, що відповідальною за забезпечення участі у Міжнародній асоціації органів страхового нагляду (ІАІС) та Міжнародній організації органів нагляду за пенсійними фондами (ІОПС) є Національна комісія, що здійснює державне регулювання у сфері ринків фінансових послуг, а заходи щодо забезпечення участі у зазначених організаціях здійснюються в межах видатків, передбачених у Державному бюджеті України на відповідний рік. { Абзац в редакції Постанови КМ N 256 ( 256-2012-п ) від 28.03.2012 }
