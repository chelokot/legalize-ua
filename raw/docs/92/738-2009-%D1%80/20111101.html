КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 липня 2009 р. N 738-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1097 ( 1097-2011-п ) від 26.10.2011 }

Про внесення змін до розпорядження Кабінету Міністрів України від 25 липня 2002 р. N 419

Внести до розпорядження Кабінету Міністрів України від 25 липня 2002 р. N 419 ( 419-2002-р ) "Про встановлення плати за послуги, що надаються Державною комісією з цінних паперів та фондового ринку" (Офіційний вісник України, 2002 р., N 31, ст. 1484) такі зміни:

в абзаці другому слова "два неоподатковуваних мінімуми" замінити словами "сімдесят неоподатковуваних мінімумів";

в абзаці третьому слова "два неоподатковуваних мінімуми" замінити словами "тридцять п'ять неоподатковуваних мінімумів";

в абзаці четвертому слова "один неоподатковуваний мінімум" замінити словами "двадцять неоподатковуваних мінімумів".

Прем'єр-міністр України Ю.ТИМОШЕНКО
