Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 287-2011-п

Текст документа від 23.03.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 березня 2011 р. N 287 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 27

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 23 березня 2011 р. N 287

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 14 листопада 1997 р. N 1261 ( 1261-97-п ) "Про виконання резолюцій Ради Безпеки ООН щодо Сьєрра-Леоне".

2. Постанова Кабінету Міністрів України від 4 червня 1998 р. N 796 ( 796-98-п ) "Про внесення змін до постанови Кабінету Міністрів України від 14 листопада 1997 р. N 1261".

3. Постанова Кабінету Міністрів України від 29 червня 1999 р. N 1166 ( 1166-99-п ) "Про внесення змін до постанови Кабінету Міністрів України від 14 листопада 1997 р. N 1261" (Офіційний вісник України, 1999 р., N 26, ст. 1245).

4. Постанова Кабінету Міністрів України від 6 вересня 2000 р. N 1394 ( 1394-2000-п ) "Про внесення змін і доповнень до постанови Кабінету Міністрів України від 14 листопада 1997 р. N 1261" (Офіційний вісник України, 2000 р., N 36, ст. 1545).

5. Постанова Кабінету Міністрів України від 13 березня 2002 р. N 289 ( 289-2002-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 14 листопада 1997 р. N 1261" (Офіційний вісник України, 2002 р., N 11, ст. 522).

6. Постанова Кабінету Міністрів України від 15 жовтня 2003 р. N 1606 ( 1606-2003-п ) "Про внесення змін до постанови Кабінету Міністрів України від 14 листопада 1997 р. N 1261" (Офіційний вісник України, 2003 р., N 42, ст. 2207).

7. Пункт 19 змін, що вносяться до актів Кабінету Міністрів України з питань діяльності Служби зовнішньої розвідки, затверджених постановою Кабінету Міністрів України від 25 травня 2006 р. N 726 ( 726-2006-п ) (Офіційний вісник України, 2006 р., N 22, ст. 1609).
