Мінтранс України; Наказ, Тариф від 19.02.2001 № 103

Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні

Реєстрація: Мін'юст України від 05.03.2001 № 191/5382

Стан: Втратив чинність

Ідентифікатор: z0191-01

Текст документа від 04.06.2007:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

N 103 від 19.02.2001 Зареєстровано в Міністерстві юстиції України 5 березня 2001 р. за N 191/5382

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 405 ( z0537-07 ) від 15.05.2007 }

Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні

{ Із змінами, внесеними згідно з Наказами Міністерства транспорту N 289 ( z0415-02 ) від 29.04.2002 N 505 ( z0623-03 ) від 09.07.2003 N 952 ( z1204-03 ) від 08.12.2003 }

Згідно з постановою Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та з метою більш повного відшкодування витрат, пов'язаних із забезпеченням якісного обслуговування пасажирів у поїздах, НАКАЗУЮ:

1. Затвердити Тарифи на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні, що додаються.

2. Укрзалізниці (Горілей С.В.) та начальникам залізниць України забезпечити своєчасне введення у дію цих Тарифів та правильність їх застосування і проінформувати про це населення (на вокзалах та пунктах продажу квитків).

3. Із введенням у дію цього наказу втрачають чинність Тарифи на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні, затверджені наказом Міністерства транспорту від 14 лютого 2000 р. N 53 ( z0113-00 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні" і зареєстровані Міністерством юстиції 29 лютого 2000 р. за N 113/4334.

4. Контроль за виконанням цього наказу покласти на першого заступника Міністра транспорту України - Генерального директора Укрзалізниці Г.М.Кірпу.

Міністр Л.М.Костюченко

Погоджено Заступник Міністра економіки України О.В.Шлапак

( Тарифи на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні втратили чинність на підставі Наказу Міністерства транспорту N 952 ( z1204-03 ) від 08.12.2003 )
