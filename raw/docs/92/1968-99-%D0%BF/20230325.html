Кабінет Міністрів України постановляє:

1. ( Пункт 1 втратив чинність у частині затвердження переліку галузей (підгалузей) виробництва, які є пріоритетними для реалізації інвестиційних проектів на територіях пріоритетного розвитку в Луганській області на підставі Постанови КМ N 895 ( 895-2001-п ) від 26.07.2001 ) Затвердити перелік галузей (підгалузей) виробництва, які є пріоритетними для реалізації інвестиційних проектів на територіях пріоритетного розвитку в Луганській області, та Порядок розгляду і затвердження інвестиційних проектів, що реалізуються у пріоритетних галузях (підгалузях) виробництва на територіях пріоритетного розвитку в Луганській області (додаються).

2. Міністерству економіки щороку розглядати результати запровадження спеціального режиму інвестиційної діяльності у Луганській області та подавати пропозиції щодо внесення змін до переліку пріоритетних галузей (підгалузей) виробництва.

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 31 травня 1999 р. N 930 ( 930-99-п ) "Про затвердження переліку галузей (підгалузей), виробництв, які є пріоритетними для реалізації інвестиційних проектів на територіях пріоритетного розвитку в Луганській області, та Порядку розгляду і схвалення інвестиційних проектів, що реалізуються у пріоритетних галузях (підгалузях), виробництвах на територіях пріоритетного розвитку в Луганській області" (Офіційний вісник України, 1999 р., N 22, ст. 1008).

( ПЕРЕЛІК галузей (підгалузей) виробництва, які є пріоритетними для реалізації інвестиційних проектів на територіях пріоритетного розвитку в Луганській області втратив чинність на підставі Постанови КМ N 895 ( 895-2001-п ) від 26.07.2001 )

ПОРЯДОК розгляду і затвердження інвестиційних проектів, що реалізуються у пріоритетних галузях (підгалузях) виробництва на територіях пріоритетного розвитку в Луганській області

1. Цим Порядком визначається процедура розгляду і затвердження інвестиційних проектів, що реалізуються суб'єктами підприємницької діяльності у пріоритетних галузях (підгалузях) виробництва на територіях пріоритетного розвитку в Луганській області (далі - інвестиційний проект).

2. Затвердження інвестиційних проектів здійснюється Комітетом з питань територій пріоритетного розвитку (далі - Комітет).

3. Суб'єкт підприємницької діяльності (інвестор), який має намір реалізувати інвестиційний проект, або уповноважена ним в установленому порядку особа (далі - заявник) подає до Комітету такі документи:

заяву про розгляд інвестиційного проекту за формою згідно з додатком;

інвестиційний проект (бізнес-план), підписаний заявником, прошитий і пронумерований, у трьох примірниках; ( Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 896 ( 896-2001-п ) від 26.07.2001 )

нотаріально засвідчені копії свідоцтва про державну реєстрацію суб'єкта підприємницької діяльності та копії засновницьких документів юридичної особи;

у разі коли заявником є іноземна юридична особа - документи, що свідчать про реєстрацію (створення) іноземної юридичної особи (нерезидента) у країні її місцезнаходження (витяг з торговельного, банківського або судового реєстру тощо), засвідчені відповідно до законодавства країни, що їх видала, перекладені українською мовою та легалізовані у консульській установі України, якщо міжнародними договорами, в яких бере участь Україна, не передбачено інше. Зазначені документи можуть бути також засвідчені у посольстві відповідної держави в Україні та легалізовані в МЗС;

проект договору (контракту) щодо умов реалізації інвестиційного проекту, погоджений з відповідним органом місцевого самоврядування;

висновки щодо інвестиційного проекту, зроблені відповідно до законодавства України;

довідку органу державної податкової служби за місцезнаходженням заявника про стан розрахунків з бюджетом (для юридичних осіб, зареєстрованих в Україні);

зобов'язання щодо подання Комітету звітності про хід реалізації інвестиційного проекту за формою та у терміни, встановлені Комітетом.

У разі потреби Комітет може вимагати інші документи, що підтверджують спроможність заявника реалізувати інвестиційний проект.

Заявник несе відповідальність за достовірність інформації, що міститься у підготовлених ним документах.

3-1. Якщо інвестиційний проект передбачає ввезення на митну територію України сировини, матеріалів, устаткування та обладнання, разом з документами, визначеними у пункті 3 цього Порядку, заявник подає до Комітету:

переліки та обсяги сировини, матеріалів, устаткування та обладнання із зазначенням коду товару згідно з Українською класифікацією товарів зовнішньоекономічної діяльності (УКТЗЕД), що ввозитимуться в Україну виключно для реалізації інвестиційного проекту, які є його невід'ємною частиною;

обгрунтування обсягів ввезення сировини, матеріалів, устаткування та обладнання.

( Порядок доповнено пунктом 3-1 згідно з Постановою КМ N 896 ( 896-2001-п ) від 26.07.2001 )

4. Після перевірки комплектності пакета документів, зазначених у пунктах 3 і 3-1 цього Порядку, Комітет реєструє їх надходження у спеціальному журналі, присвоює порядковий номер і видає заявнику письмове підтвердження одержання від нього документів. Форма ведення спеціального журналу встановлюється Комітетом. ( Пункт 4 із змінами, внесеними згідно з Постановою КМ N 896 ( 896-2001-п ) від 26.07.2001 )

5. Зареєстровані документи заявника надсилаються у триденний термін Луганській облдержадміністрації для підготовки висновку про доцільність реалізації інвестиційного проекту, зокрема з наданням передбачених законодавством України пільг, виходячи з програм соціально-економічного розвитку області, а також про обгрунтованість переліків та обсягів увезення сировини, матеріалів, устаткування та обладнання. Копію заяви про розгляд інвестиційного проекту та копію інвестиційного проекту Комітет надсилає Мінекономіки для проведення за участю Мінфіну, Мінпромполітики, Мінагрополітики, Державної податкової адміністрації у Луганській області експертизи інвестиційного проекту з метою запобігання негативним наслідкам його реалізації, зокрема щодо виконання державних програм економічного, науково-технічного та соціального розвитку, обсягів надходжень до бюджетів, а також з метою визначення джерел покриття можливих втрат. Відповідні висновки надсилаються у місячний термін Комітетові. ( Абзац перший пункту 5 в редакції Постанови КМ N 9 ( 9-2002-п ) від 10.01.2002 )

В окремих випадках термін підготовки висновків може бути подовжений Комітетом на два тижні.

( Пункт 5 із змінами, внесеними згідно з Постановою КМ N 896 ( 896-2001-п ) від 26.07.2001 )

6. Рішення про затвердження або відмову у затвердженні інвестиційного проекту Комітет приймає у термін, який не може перевищувати 60 днів з дня подання документів заявником.

6-1. Рішення про затвердження інвестиційного проекту приймається Комітетом лише за наявності позитивних висновків щодо доцільності його реалізації від усіх центральних органів виконавчої влади, залучених до проведення експертизи.

( Порядок доповнено пунктом 6-1 згідно з Постановою КМ N 1368 ( 1368-2003-п ) від 27.08.2003 )

7. У разі затвердження інвестиційного проекту заявнику видається свідоцтво про його затвердження разом з одним примірником інвестиційного проекту, на титульному аркуші якого проставляється дата і номер рішення Комітету про затвердження, скріпленим підписом уповноваженої посадової особи та печаткою. Один примірник інвестиційного проекту зберігається у Комітеті.

Якщо інвестиційний проект передбачає ввезення на митну територію України сировини, матеріалів, устаткування та обладнання, один примірник інвестиційного проекту надсилається відповідному митному органу. ( Пункт 7 доповнено абзацом згідно з Постановою КМ N 896 ( 896-2001-п ) від 26.07.2001 )

8. Рішення про затвердження інвестиційного проекту є підставою для укладення органом місцевого самоврядування договору (контракту) з суб'єктом підприємницької діяльності (інвестором).

9. У затвердженні інвестиційного проекту Комітет відмовляє у разі, коли:

одержано негативні висновки щодо доцільності реалізації інвестиційного проекту;

інвестиційний проект не відповідає пріоритетним галузям (підгалузям) виробництва на територіях пріоритетного розвитку в Луганській області, затвердженим Кабінетом Міністрів України;

у поданих документах виявлено недостовірні відомості;

суб'єкт підприємницької діяльності (інвестор) має заборгованість перед бюджетами та державними цільовими фондами.

Відмова у затвердженні інвестиційного проекту надсилається заявникові у письмовій формі з обгрунтуванням причин.

10. Заявник, якому відмовлено у затвердженні інвестиційного проекту, має право після усунення причин та недоліків, що привели до відмови, та доопрацювання інвестиційного проекту повторно подати його на розгляд Комітету.

11. Заявник може ініціювати внесення змін до затвердженого інвестиційного проекту (крім змін, пов'язаних з імпортом товарів 1-24 груп УКТЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ), та змін, що можуть призвести до зменшення кошторисної вартості інвестиційного проекту порівняно з установленим законодавством мінімальним рівнем).

Зміни до інвестиційного проекту розглядаються і затверджуються Комітетом у разі:

зміни коду згідно з УКТЗЕД товару, що ввозиться на митну територію України виключно для реалізації інвестиційного проекту, за винятком зміни коду товару на рівні товарної позиції (перші чотири знаки);

зміни вартості товару у зв'язку з коливанням валютного курсу.

Комітет надсилає по одному примірнику затверджених змін Мінекономіки, Луганській облдержадміністрації, відповідному органу державної податкової служби і митному органу.

Зміни, не передбачені цим пунктом, розглядаються згідно з пунктами 1-10 цього Порядку.

( Пункт 11 в редакції Постанов КМ N 1368 ( 1368-2003-п ) від 27.08.2003, N 1168 ( 1168-2004-п ) від 08.09.2004 )

12. Після отримання свідоцтва про затвердження інвестиційного проекту заявник зобов'язаний у тримісячний термін укласти з органом місцевого самоврядування договір (контракт) щодо умов реалізації інвестиційного проекту і подати до Комітету його копію.

12-1. Зміни до переліку галузей (підгалузей) виробництва, які є пріоритетними для реалізації інвестиційних проектів на територіях пріоритетного розвитку в Луганській області, не поширюються на суб'єктів підприємницької діяльності, які уклали з відповідним органом місцевого самоврядування договір (контракт) щодо умов реалізації інвестиційного проекту до затвердження таких змін Кабінетом Міністрів України.

( Порядок доповнено пунктом 12-1 згідно з Постановою КМ N 1368 ( 1368-2003-п ) від 27.08.2003 )

13. Комітет має право скасувати видане свідоцтво про затвердження інвестиційного проекту у разі:

порушення суб'єктом підприємницької діяльності (інвестором) терміну укладення з органом місцевого самоврядування договору (контракту) щодо умов реалізації інвестиційного проекту;

розірвання договору (контракту) щодо умов реалізації інвестиційного проекту за пропозицією органу місцевого самоврядування відповідно до законодавства.

14. Комітет подає:

у дводенний термін з дня видачі свідоцтва про затвердження інвестиційного проекту або його скасування інформацію відповідним органам місцевого самоврядування, органу державної податкової служби та митному органу; ( Абзац другий пункту 14 із змінами, внесеними згідно з Постановою КМ N 1368 ( 1368-2003-п ) від 27.08.2003 )

до п'ятого числа місяця, що настає за звітним кварталом, Мінекономіки та Мінфіну інформацію про стан реалізації суб'єктами підприємницької діяльності затверджених інвестиційних проектів.
