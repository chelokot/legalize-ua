МІНІСТЕРСТВО ОХОРОНИ НАВКОЛИШНЬОГО ПРИРОДНОГО СЕРЕДОВИЩА УКРАЇНИ

НАКАЗ

12.05.2008 N 241

Зареєстровано в Міністерстві юстиції України 26 травня 2008 р. за N 459/15150

Про визнання такими, що втратили чинність, деяких наказів Мінприроди

З метою приведення нормативно-правових актів Мінприроди у відповідність до норм чинного законодавства НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Мінприроди:

від 18.06.93 N 51 ( z0078-93 ) "Про затвердження Інструкції про порядок видачі дозволів на спеціальне використання рибних ресурсів", зареєстрований в Мін'юсті 01.07.93 за N 78;

від 18.06.93 N 52 ( z0079-93 ) "Про затвердження Інструкції про порядок установлення лімітів використання рибних ресурсів загальнодержавного значення", зареєстрований в Мін'юсті 01.07.93 за N 79;

від 27.02.96 N 22 ( z0216-96 ) "Про Положення про державне управління екологічної безпеки в області, містах Києві та Севастополі Мінекобезпеки України", зареєстрований в Мін'юсті 05.05.96 за N 216/1241;

від 16.06.2000 N 56 ( z0362-00 ) "Про затвердження Порядку видачі погодження для отримання ліцензії на експорт та імпорт озоноруйнівних речовин і продукції, що їх містить", зареєстрований в Мін'юсті 20.06.2000 за N 362/4583;

від 27.05.2002 N 197 ( z0498-02 ) "Про затвердження Порядку видачі погодження для отримання ліцензії на експорт та імпорт озоноруйнівних речовин і продукції, що їх містить", зареєстрований в Мін'юсті 12.06.2002 за N 498/6786;

від 06.06.2003 N 92-М ( z0518-03 ) "Про затвердження Порядку видачі погодження для отримання ліцензії на експорт та імпорт озоноруйнівних речовин і продукції, що їх містить", зареєстрований в Мін'юсті 26.06.2003 за N 518/7839.

2. Юридичному департаменту (Роменський Д.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Тригубенка С.М.
