Про затвердження тарифів на електричну енергію релігійних організацій

{ Назва Постанови із змінами, внесеними згідно з Постановами Національної комісії, що здійснює державне регулювання у сферах енергетики та комунальних послуг N 2021 ( v2021874-16 ) від 24.11.2016, N 2011 ( v2011874-18 ) від 21.12.2018 }

{ Із змінами, внесеними згідно з Постановами Національної комісії регулювання електроенергетики

N 344 ( z0380-11 ) від 17.03.2011 Постановою Національної комісії, що здійснює державне регулювання у сфері енергетики

N 749 ( z0566-14 ) від 23.05.2014 Постановами Національної комісії, що здійснює державне регулювання у сферах енергетики та комунальних послуг

N 2021 ( v2021874-16 ) від 24.11.2016

Відповідно до Законів України "Про електроенергетику" ( 575/97-ВР ), "Про державну підтримку та особливості функціонування дитячих центрів "Артек" і "Молода гвардія" ( 906-17 ), "Про свободу совісті та релігійні організації" ( 987-12 ), Указів Президента України від 22 червня 1994 року N 322 ( 322/94 ) "Про надання пільг релігійним організаціям" та від 10 вересня 2014 року N 715 ( 715/2014 ) "Про затвердження Положення про Національну комісію, що здійснює державне регулювання у сферах енергетики та комунальних послуг" Національна комісія, що здійснює державне регулювання у сферах енергетики та комунальних послуг, ПОСТАНОВЛЯЄ:

{ Преамбула в редакції Постанови НКРЕ N 8/1 ( z0064-11 ) від 13.01.2011, Постанови Національної комісії, що здійснює державне регулювання у сферах енергетики та комунальних послуг N 2021 ( v2021874-16 ) від 24.11.2016 }

1. Установити тарифи на електричну енергію, що відпускається на комунально-побутові потреби релігійних організацій, на рівні: { Абзац перший пункту 1 із змінами, внесеними згідно з Постановами Національної комісії, що здійснює державне регулювання у сферах енергетики та комунальних послуг N 2021 ( v2021874-16 ) від 24.11.2016, N 2011 ( v2011874-18 ) від 21.12.2018 }

1) на період з 01 квітня 2015 року по 31 серпня 2015 року включно - 52,5 коп. за 1 кВт·год (без податку на додану вартість);

2) на період з 01 вересня 2015 року по 29 лютого 2016 року включно - 65,75 коп. за 1 кВт·год (без податку на додану вартість);

3) на період з 01 березня 2016 року по 31 серпня 2016 року включно - 82,5 коп. за 1 кВт·год (без податку на додану вартість);

4) на період з 01 вересня 2016 року по 28 лютого 2017 року включно - 107,5 коп. за 1 кВт·год (без податку на додану вартість);

5) з 01 березня 2017 року - 140 коп. за 1 кВт·год (без податку на додану вартість).

{ Пункт 1 в редакції Постанови НКРЕ N 8/1 ( z0064-11 ) від 13.01.2011; із змінами, внесеними згідно з Постановою НКРЕ N 344 ( z0380-11 ) від 17.03.2011, Постановою Національної комісії, що здійснює державне регулювання у сфері енергетики N 749 ( z0566-14 ) від 23.05.2014; в редакції Постанови Національної комісії, що здійснює державне регулювання у сферах енергетики та комунальних послуг N 220 ( z0231-15 ) від 26.02.2015 }

2. Управлінню цінової політики в електроенергетиці в установленому порядку забезпечити подання цієї постанови на державну реєстрацію до Міністерства юстиції України.

3. Ця постанова набирає чинності з дня її офіційного опублікування.
