Кабінет Міністрів України; Постанова, Порядок від 18.03.2009 № 218

Про затвердження Порядку використання у 2009 році коштів, передбачених у державному бюджеті для поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф

Стан: Чинний

Ідентифікатор: 218-2009-п

Текст документа від 24.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 березня 2009 р. N 218 Київ

Про затвердження Порядку використання у 2009 році коштів, передбачених у державному бюджеті для поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф

{ Із змінами, внесеними згідно з Постановою КМ N 623 ( 623-2010-п ) від 14.07.2010 }

{ Установити, що у 2010 році кошти, передбачені у державному бюджеті ( 2154-17 ) для поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф, використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 623 ( 623-2010-п ) від 14.07.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) для поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 18 березня 2009 р. N 218

ПОРЯДОК використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) для поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф

1. Цей Порядок визначає механізм використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) МОЗ для виконання плану заходів щодо поліпшення медичного обслуговування дітей, які постраждали внаслідок Чорнобильської та інших екологічних катастроф, затвердженого Кабінетом Міністрів України, у складі програми "Забезпечення медичних заходів окремих державних програм та комплексних заходів програмного характеру" (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 623 ( 623-2010-п ) від 14.07.2010 }

2. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється МОЗ в установленому законодавством порядку.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 623 ( 623-2010-п ) від 14.07.2010 }

3. Направлення дітей за медичними показаннями для лікування та оздоровлення у Республіці Куба, а також матеріально-технічне і побутове забезпечення кубинських фахівців та оплата праці на договірній основі у період їх перебування в Україні здійснюються МОЗ в установленому ним порядку.

Відбір кандидатур на посади працівників української адміністрації, педагогів та вихователів для роботи в Республіці Куба з укладенням трудового договору здійснюється у порядку, затвердженому МОЗ у місячний строк після набрання чинності цим Порядком.

4. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 4 в редакції Постанови КМ N 623 ( 623-2010-п ) від 14.07.2010 }

5. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
