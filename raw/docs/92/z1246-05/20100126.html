{ Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 12 ( z0029-10 ) від 13.01.2010 }

Про затвердження Ліцензійних умов провадження господарської діяльності з розподілу природного і нафтового газу

Відповідно до Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ), Положення про Національну комісію регулювання електроенергетики України, затвердженого Указом Президента України від 14.03.95 N 213 ( 213/95 ) (із змінами), та постанови Кабінету Міністрів України від 14.11.2000 N 1698 ( 1698-2000-п ) (із змінами) "Про затвердження переліку органів ліцензування" Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Затвердити Ліцензійні умови провадження господарської діяльності з розподілу природного і нафтового газу, що додаються ( za246-05 ).

2. Управлінню регулювання та цінової політики нафтогазового комплексу в установленому порядку забезпечити:

подання Ліцензійних умов провадження господарської діяльності з розподілу природного і нафтового газу ( za246-05 ) на затвердження до Державного комітету України з питань регуляторної політики та підприємництва;

опублікування цієї постанови відповідно до чинного законодавства.

3. Суб'єктам господарювання, що провадять діяльність на підставі ліцензії на транспортування природного та нафтового газу розподільними трубопроводами, привести свою діяльність відповідно до вимог Ліцензійних умов провадження господарської діяльності з розподілу природного і нафтового газу ( za246-05 ) протягом трьох місяців з дати набрання чинності цією постановою.

4. Визнати такою, що втратила чинність, постанову НКРЕ від 30.09.99 N 1263 ( z0720-99 ) "Про затвердження Умов та Правил здійснення підприємницької діяльності (ліцензійних умов) з транспортування природного та нафтового газу розподільними трубопроводами", зареєстровану в Міністерстві юстиції України 21.10.99 за N 720/4013.
