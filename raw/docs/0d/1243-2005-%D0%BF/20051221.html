Кабінет Міністрів України; Постанова від 21.12.2005 № 1243

Питання оплати праці вищих посадових осіб України, окремих керівних працівників органів державної влади і органів місцевого самоврядування та суддів

Стан: Чинний

Ідентифікатор: 1243-2005-п

Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 грудня 2005 р. N 1243 Київ

Питання оплати праці вищих посадових осіб України, окремих керівних працівників органів державної влади і органів місцевого самоврядування та суддів

Кабінет Міністрів України постановляє:

Установити, що для вищих посадових осіб України, окремих керівних працівників органів державної влади і органів місцевого самоврядування та суддів, розміри посадових окладів яких визначаються залежно від кількості розмірів мінімальної заробітної плати згідно з постановами Кабінету Міністрів України від 30 червня 2005 р. N 510 ( 510-2005-п ), 512 ( 512-2005-п ), 513 ( 513-2005-п ), 514 ( 514-2005-п ), 516 ( 516-2005-п ), 518 ( 518-2005-п ), 519 ( 519-2005-п ), 520 ( 520-2005-п ), 521 ( 521-2005-п ), 522 ( 522-2005-п ), 523 ( 523-2005-п ), 524 ( 524-2005-п ) (Офіційний вісник України, 2005 р., N 27, ст. 1545, ст. 1547, ст. 1548, ст. 1549, ст. 1551, ст. 1553, ст. 1554, ст. 1555, ст. 1556, ст. 1557, ст. 1558, ст. 1559, N 34, ст. 2081, N 35, ст. 2118, N 43, ст. 2713, N 44, ст. 2772, N 46, ст. 2893), від 3 вересня 2005 р. N 865 ( 865-2005-п ) (Офіційний вісник України, 2005 р., N 36, ст. 2195) та іншими нормативно-правовими актами, розміри посадових окладів встановлюються виходячи з розміру мінімальної заробітної плати 332 гривні і в подальшому при підвищенні мінімальної заробітної плати перерахунок не провадиться.
