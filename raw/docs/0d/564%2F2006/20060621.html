Текст документа від 21.06.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про затвердження Всесвітньої поштової конвенції, Заключного протоколу Всесвітньої поштової конвенції, Угоди про служби поштових платежів, Загального регламенту Всесвітнього поштового союзу та Внутрішнього регламенту Конгресів

Затвердити Всесвітню поштову конвенцію ( 995_297 ), Заключний протокол Всесвітньої поштової конвенції ( 995_292 ), Угоду про служби поштових платежів ( 055_001 ), Загальний регламент Всесвітнього поштового союзу ( 995_293 ) та Внутрішній регламент Конгресів ( 995_799 ), підписані від імені України 5 жовтня 2004 року у м. Бухаресті (додаються*).

Президент України В.ЮЩЕНКО

м. Київ, 21 червня 2006 року N 564/2006
