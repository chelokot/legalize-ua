Кабінет Міністрів України; Розпорядження від 18.04.1994 № 258-р

Про звільнення від обкладення ввізним митом технологічного устаткування та матеріалів для виробництва взуття

Стан: Втратив чинність

Ідентифікатор: 258-94-р

Текст документа від 29.11.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 квітня 1994 р. N 258-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 957 ( 957-95-п ) від 29.11.95 )

Звільнити від обкладення ввізним митом технологічне устаткування та матеріали для виробництва взуття, що поставляються спільному українсько-італійському підприємству "Вілкас ЛТД" відповідно до контракту від 20 липня 1992 р. N 0-2463/92, укладеного з італійською фірмою "Пелл куір".

Виконуючий обов'язки Прем'єр-міністра України Ю.ЗВЯГІЛЬСЬКИЙ
