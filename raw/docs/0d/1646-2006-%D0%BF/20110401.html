Ідентифікатор: 1646-2006-п

Текст документа від 01.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 листопада 2006 р. N 1646 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 283 ( 283-2011-п ) від 21.03.2011 }

Про внесення зміни до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів

Кабінет Міністрів України постановляє:

Внести до переліку центральних органів виконавчої влади, діяльність яких спрямовується і координується Кабінетом Міністрів України через відповідних міністрів, затвердженого постановою Кабінету Міністрів України від 23 лютого 2006 р. N 207 ( 207-2006-п ) (Офіційний вісник України, 2006 р., N 8, ст. 458, N 20, ст. 1480, N 26, ст. 1876), зміну, виключивши абзац четвертий пункту 1.
