Про затвердження Положення про операції банків з векселями

Відповідно до законів України "Про банки і банківську діяльність" ( 872-12 ) та "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ) Правління розглянуло проект Положення про операції банків з векселями іПОСТАНОВЛЯЄ:

1. Затвердити Положення про операції банків з векселями ( v0653500-99 ).

2. Визнати таким, що втратив чинність, Порядок проведення банками операцій з векселями, затверджений Головою Правління Національного банку України 25.02.93 ( v1_85500-93 ), із змінами і доповненнями, внесеними постановою Правління від 02.06.97 N 171 ( v0447500-97 ).

Скасувати дію листів Національного банку України від 25.02.93 N 22001/85 ( v1_85500-93 ) "Про порядок проведення банками операцій з векселями", від 13.02.95 N 15010/34 ( v0_34500-95 ), від 20.02.95 N 15010/45, від 22.02.95 N 15010/48 ( v0_48500-95 ) "Роз'яснення до питань, пов'язаних з використанням векселів у господарському обороті".

3. Департаменту платіжних систем (В.М.Кравець) надіслати цю постанову у встановленому порядку регіональним управлінням Національного банку України та комерційним банкам для керівництва в роботі.

4. Зобов'язати установи банків довести зміст цієї постанови до відома своїх клієнтів.

5. Контроль за виконанням цієї постанови покласти на Кримське республіканське, обласні та по м.Києву і Київській області управління Національного банку України.

6. Постанова набуває чинності з 1 липня 1999 р.

Голова В.А.Ющенко
