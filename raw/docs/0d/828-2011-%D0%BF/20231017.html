Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 3 серпня 2011 р. N 828

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. У додатку 1 до Положення про Державний реєстр виробників, розповсюджувачів і демонстраторів фільмів, затвердженого постановою Кабінету Міністрів України від 14 січня 2004 р. N 27 ( 27-2004-п ) (Офіційний вісник України, 2004 р., N 2, ст. 51; 2006 р., N 10, ст. 622), слова "Державна служба кінематографії" замінити словами "Державне агентство України з питань кіно".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 1069 ( 1069-2023-п ) від 10.10.2023 }

3. У Положенні про державну підтримку національних фільмів у продюсерській системі, затвердженому постановою Кабінету Міністрів України від 5 червня 1998 р. N 813 ( 813-98-п ) (Офіційний вісник України, 1998 р., N 23, ст. 827; 2010 р., N 11, ст. 548):

1) в абзаці другому пункту 6 слова "за поданням Держкіно" виключити;

2) у тексті Положення ( 813-98-п ) слово "МКТ" замінити словом "Держкіно".
