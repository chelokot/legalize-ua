КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 грудня 1998 р. N 1909 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 857 ( 857-2006-п ) від 24.06.2006 }

Про визначення акціонерного комерційного банку "Київ" банком-агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Визначити акціонерний комерційний банк "Київ" банком-агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України.

2. Уповноважити Міністра фінансів Мітюкова І.О. підписати від імені Кабінету Міністрів України агентську угоду з акціонерним комерційним банком "Київ".

3. Контроль за виконанням цієї постанови покласти на Віце-прем'єр-міністра України Тігіпка С.Л.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
