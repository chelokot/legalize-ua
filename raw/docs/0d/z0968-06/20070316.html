10.08.2006 N 303

Зареєстровано в Міністерстві юстиції України 11 серпня 2006 р. за N 968/12842

Про внесення змін до наказу Міністерства праці та соціальної політики України від 31.03.2006 N 97

{ Із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 66 ( z0190-07 ) від 23.02.2007 }

Відповідно до постанови Кабінету Міністрів України від 19.07.2006 N 984 ( 984-2006-п ) "Деякі питання оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 31.03.2006 N 97 ( z0407-06 ) "Про умови оплати праці працівників територіальних органів Державного департаменту промислової безпеки, охорони праці та гірничого нагляду", зареєстрованого в Міністерстві юстиції України 10.04.2006 за N 407/12281, виклавши додаток у новій редакції (додається).

2. Перерахунок заробітної плати працівникам проводити згідно з цим наказом, починаючи з 1 квітня 2006 року.

3. У разі, коли розмір посадового окладу працівників територіальних органів Держгірпромнагляду нижчий від визначеного законодавством розміру мінімальної заробітної плати, посадовий оклад встановлювати на рівні відповідного розміру мінімальної заробітної плати. { Пункт 3 із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 66 ( z0190-07 ) від 23.02.2007 }
