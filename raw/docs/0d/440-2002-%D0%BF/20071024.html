Кабінет Міністрів України; Постанова від 30.03.2002 № 440

Про Голову Міжвідомчої координаційної комісії з питань організації виконання вимог Монреальського протоколу по речовинах, що руйнують озоновий шар

Стан: Втратив чинність

Ідентифікатор: 440-2002-п

Текст документа від 24.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 березня 2002 р. N 440 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про Голову Міжвідомчої координаційної комісії з питань організації виконання вимог Монреальського протоколу по речовинах, що руйнують озоновий шар

Кабінет Міністрів України постановляє:

Затвердити начальника Державної екологічної інспекції - Головного державного інспектора України з охорони навколишнього природного середовища Свирида Петра Олексійовича головою Міжвідомчої координаційної комісії з питань організації виконання вимог Монреальського протоколу по речовинах, що руйнують озоновий шар, утвореної постановою Кабінету Міністрів України від 28 грудня 1995 р. N 1062 ( 1062-95-п ) (ЗП України, 1996 р., N 4, ст. 144), звільнивши від цих обов'язків Васильченка Василя Васильовича.
