Про визнання такими, що втратили чинність, деяких розпоряджень Антимонопольного комітету України

Реєстрація: Мін'юст України від 17.04.2008 № 323/15014

Стан: Чинний

Ідентифікатор: z0323-08

Текст документа від 08.04.2008:

АНТИМОНОПОЛЬНИЙ КОМІТЕТ УКРАЇНИ

РОЗПОРЯДЖЕННЯ

08.04.2008 N 200-р

Зареєстровано в Міністерстві юстиції України 17 квітня 2008 р. за N 323/15014

Про визнання такими, що втратили чинність, деяких розпоряджень Антимонопольного комітету України

У зв'язку з набранням чинності Законом України від 20.03.2008 N 150-VI ( 150-17 ) "Про визнання таким, що втратив чинність, Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" та на виконання пункту 7 постанови Кабінету Міністрів України від 28.03.2008 N 274 ( 274-2008-п ) "Про здійснення закупівель товарів, робіт і послуг за державні кошти" Антимонопольний комітет України ПОСТАНОВИВ:

1. Визнати такими, що втратили чинність:

1.1. Розпорядження Антимонопольного комітету України від 20.06.2006 N 214-р ( z0834-06 ) "Про затвердження Положення про порядок проведення перевірок щодо дотримання розпорядниками державних коштів вимог законодавства у сфері державних закупівель", зареєстроване в Міністерстві юстиції України 14.07.2006 за N 834/12708.

1.2. Розпорядження Антимонопольного комітету України від 20.06.2006 N 215-р ( z0899-06 ) "Про затвердження форми Реєстру отриманих тендерних пропозицій при здійсненні процедур закупівель товарів, робіт і послуг за державні кошти та Інструкції щодо її заповнення", зареєстроване в Міністерстві юстиції України 01.08.2006 за N 899/12773.

1.3. Розпорядження Антимонопольного комітету України від 20.06.2006 N 216-р ( z0900-06 ) "Про затвердження форми Протоколу про розкриття тендерних пропозицій при здійсненні процедур закупівель товарів, робіт і послуг за державні кошти та Інструкції щодо її заповнення", зареєстроване в Міністерстві юстиції України 01.08.2006 за N 900/12774.

1.4. Розпорядження Антимонопольного комітету України від 20.06.2006 N 217-р ( z0901-06 ) "Про затвердження форм Оголошень про проведення процедур закупівель та Інструкцій щодо їх заповнення", зареєстроване в Міністерстві юстиції України 01.08.2006 за N 901/12775.

1.5. Розпорядження Антимонопольного комітету України від 20.06.2006 N 218-р ( z0904-06 ) "Про затвердження форм Річного плану закупівель товарів, робіт і послуг за державні кошти", зареєстроване в Міністерстві юстиції України 01.08.2006 за N 904/12778.

1.6. Розпорядження Антимонопольного комітету України від 20.06.2006 N 219-р ( z0907-06 ) "Про затвердження форм Звітів про результати здійснення процедур закупівель товарів, робіт і послуг за державні кошти та Інструкцій щодо їх заповнення", зареєстроване в Міністерстві юстиції України 01.08.2006 за N 907/12781.

1.7. Розпорядження Антимонопольного комітету України від 12.04.2007 N 138-р ( z0463-07 ) "Про затвердження Змін до деяких нормативно-правових актів Антимонопольного комітету України", зареєстроване в Міністерстві юстиції України 07.05.2007 за N 463/13730.

1.8. Розпорядження Антимонопольного комітету України від 10.05.2007 N 185-р ( z0585-07 ) "Про затвердження форми Реєстру недобросовісних учасників процедури закупівлі товарів, робіт і послуг за державні кошти", зареєстроване в Міністерстві юстиції України 05.06.2007 за N 585/13852.

1.9. Розпорядження Антимонопольного комітету України від 19.07.2007 N 337-р ( z0943-07 ) "Про затвердження форми Оголошення щодо запиту цінових пропозицій (котирувань) та Інструкції щодо її заповнення", зареєстроване в Міністерстві юстиції України 15.08.2007 за N 943/14210.

1.10. Розпорядження Антимонопольного комітету України від 04.03.2008 N 120-р ( z0271-08 ) "Про затвердження Змін до деяких нормативно-правових актів Антимонопольного комітету України з питань державних закупівель", зареєстроване в Міністерстві юстиції України 31.03.2008 за N 271/14962.

2. Департаменту інформаційного забезпечення та аналізу подати це розпорядження на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами).
