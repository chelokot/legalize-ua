Про Представництво Президента України в Республіці Крим

Стан: Чинний

Ідентифікатор: 119/94

Текст документа від 31.01.1996:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Представництво Президента України в Республіці Крим

( Із змінами, внесеними згідно з Указом Президента N 100/96 ( 100/96 ) від 31.01.96 )

Відповідно до Закону України "Про Представництво Президента України в Республіці Крим" ( 2875-12 ) постановляю:

1. Утворити Представництво Президента України в Республіці Крим.

2. Призначити СТЕПАНЮКА Дмитра Петровича Постійним Представником Президента України в Автономній Республіці Крим. ( Стаття 2 із змінами, внесеними згідно з Указом Президента N 100/96 ( 100/96 ) від 31.01.96 )

3. Кабінету Міністрів України вирішити питання щодо матеріально-технічного, фінансового та іншого забезпечення Представництва Президента України в Республіці Крим.

4. Указ набирає чинності з дня його підписання.

Президент України Л.КРАВЧУК

м. Київ, 31 березня 1994 року N 119/94
