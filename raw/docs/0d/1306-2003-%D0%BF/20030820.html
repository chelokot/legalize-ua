Кабінет Міністрів України; Постанова від 20.08.2003 № 1306

Про внесення зміни до переліку пунктів пропуску через державний кордон, через які здійснюється переміщення вантажів військового призначення, а також вантажів, що стосуються ядерної діяльності, у разі їх транзиту територією України

Стан: Втратив чинність

Ідентифікатор: 1306-2003-п

Текст документа від 20.08.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 серпня 2003 р. N 1306 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про внесення зміни до переліку пунктів пропуску через державний кордон, через які здійснюється переміщення вантажів військового призначення, а також вантажів, що стосуються ядерної діяльності, у разі їх транзиту територією України

Кабінет Міністрів України постановляє:

Доповнити розділ "Для морського сполучення" переліку пунктів пропуску через державний кордон, через які здійснюється переміщення вантажів військового призначення, а також вантажів, що стосуються ядерної діяльності, у разі їх транзиту територією України, затвердженого постановою Кабінету Міністрів України від 20 липня 1999 р. N 1289 ( 1289-99-п ), словами "Ізмаїльський морський торговельний порт".
