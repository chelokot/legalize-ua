Кабінет Міністрів України; Розпорядження, Перелік від 17.10.2008 № 1335-р

Про передачу Мінпромполітики повноважень з управління корпоративними правами держави стосовно деяких господарських товариств

Стан: Чинний

Ідентифікатор: 1335-2008-р

Текст документа від 30.10.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 жовтня 2008 р. N 1335-р Київ

Про передачу Мінпромполітики повноважень з управління корпоративними правами держави стосовно деяких господарських товариств

{ Із змінами, внесеними згідно з Указом Президента N 970/2008 ( 970/2008 ) від 29.10.2008 }

{ Дію пункту 1 зупинено згідно з Указом Президента N 970/2008 ( 970/2008 ) від 29.10.2008 }

1. Передати Мінпромполітики повноваження з управління корпоративними правами держави стосовно господарських товариств згідно з додатком.

2. Визнати такими, що втратили чинність:

пункт 1 розпорядження Кабінету Міністрів України від 16 травня 2008 р. N 717 ( 717-2008-р ) "Про здійснення Кабінетом Міністрів України повноважень з управління державними корпоративними правами" в частині, що стосується відкритих акціонерних товариств "Одеський припортовий завод", "Київський завод реле та автоматики", "Київський мотоциклетний завод", "Турбоатом", "Завод "Маяк", "Феодосійська суднобудівна компанія "Море", "Науково-виробничий комплекс "Київський завод автоматики імені Г.І. Петровського", "Науково-дослідний інститут електромеханічних приладів" і "Меридіан" імені С.П. Корольова";

розпорядження Кабінету Міністрів України від 24 вересня 2008 р. N 1271 ( 1271-2008-р ) "Питання здійснення повноважень з управління корпоративними правами держави стосовно ВАТ "Азовмаш".

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 25
