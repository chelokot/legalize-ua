Президент України; Указ від 02.04.2010 № 495/2010

Про ліквідацію Національного центру з питань євроатлантичної інтеграції України

Стан: Чинний

Ідентифікатор: 495/2010

Текст документа від 02.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про ліквідацію Національного центру з питань євроатлантичної інтеграції України

Відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Ліквідувати Національний центр з питань євроатлантичної інтеграції України.

2. Увільнити ГОРБУЛІНА Володимира Павловича від виконання обов'язків голови Національного центру з питань євроатлантичної інтеграції України ( 157/2006 ).

3. Державному управлінню справами здійснити в установленому порядку заходи щодо ліквідації апарату Національного центру з питань євроатлантичної інтеграції України, забезпечивши при цьому безумовне виконання вимог законодавства про державну службу та про працю.

4. Визнати такими, що втратили чинність:

статтю 3 Указу Президента України від 27 грудня 2005 року N 1861 ( 1861/2005 ) "Про рішення Ради національної безпеки і оборони України від 25 листопада 2005 року "Про невідкладні заходи щодо дальшого розвитку відносин України з Організацією Північноатлантичного договору (НАТО)";

Указ Президента України від 28 лютого 2006 року N 157 ( 157/2006 ) "Про Національний центр з питань євроатлантичної інтеграції України";

пункт 7 статті 1 Указу Президента України від 11 квітня 2008 року N 333 ( 333/2008 ) "Про внесення змін та визнання такими, що втратили чинність, деяких указів Президента України".

5. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ
