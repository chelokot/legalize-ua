Про зміни у складі Координаційної ради з підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

Стан: Втратив чинність

Ідентифікатор: 353/2009

Текст документа від 08.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 470/2010 ( 470/2010 ) від 02.04.2010 }

Про зміни у складі Координаційної ради з підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

На часткову зміну статті 2 Указу Президента України від 8 травня 2007 року N 389 ( 389/2007 ) "Про забезпечення підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" (зі змінами, внесеними Указами від 15 січня 2008 року N 22 ( 22/2008 ), від 14 лютого 2008 року N 125 ( 125/2008 ) та від 13 січня 2009 року N 18) ( 18/2009 ):

1) затвердити у складі Координаційної ради з підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу (далі - Координаційна рада) УЛЬЯНЧЕНКО Віру Іванівну - Главу Секретаріату Президента України;

2) увести до складу Координаційної ради ВАКАРАША Віктора Михайловича - першого заступника голови Київської обласної державної адміністрації;

3) вивести зі складу Координаційної ради В. Балогу.

Президент України В.ЮЩЕНКО

м. Київ, 26 травня 2009 року N 353/2009
