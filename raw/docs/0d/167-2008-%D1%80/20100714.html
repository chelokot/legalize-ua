{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1399-р ( 1399-2010-р ) від 14.07.2010 }

Про затвердження складу представників Кабінету Міністрів України у Національній тристоронній соціально-економічній раді

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 735-р ( 735-2008-р ) від 21.05.2008 N 406-р ( 406-2009-р ) від 15.04.2009 N 923-р ( 923-2009-р ) від 05.08.2009 }

1. Затвердити склад представників Кабінету Міністрів України у Національній тристоронній соціально-економічній раді, що додається.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 14 листопада 2007 р. N 1024 ( 1024-2007-р ) "Про склад представників Кабінету Міністрів України у Національній тристоронній соціально-економічній раді" (Офіційний вісник України, 2007 р., N 89, ст. 3281).
