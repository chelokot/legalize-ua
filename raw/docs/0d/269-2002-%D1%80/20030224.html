КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 травня 2002 р. N 269-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 210 ( 210-2003-п ) від 24.02.2003 )

Про часткову зміну складу Міжвідомчої аналітично-консультативної ради з питань розвитку продуктивних сил і виробничих відносин

Увести до складу Міжвідомчої аналітично-консультативної ради з питань розвитку продуктивних сил і виробничих відносин, затвердженого постановою Кабінету Міністрів України від 14 серпня 2001 р. N 1047 ( 1047-2001-п ) (Офіційний вісник України, 2001 р., N 33, ст. 1548), Лебеду Галину Борисівну - керівника робочого апарату Ради, секретаря Ради, Власюка Олександра Степановича - виконуючого обов'язки директора Національного інституту стратегічних досліджень, Саханя Івана Яковича - Міністра праці та соціальної політики, Юшка Ігоря Олеговича - Міністра фінансів, вивівши з її складу Бєлова Олександра Федоровича, Мітюкова Ігоря Олександровича, Мунтіяна Валерія Івановича, Сироїд Оксану Іванівну.

Прем'єр-міністр України А.КІНАХ
