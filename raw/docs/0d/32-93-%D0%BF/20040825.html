КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 січня 1993 р. N 32 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1109 ( 1109-2004-п ) від 25.08.2004 )

Питання Міністерства промисловості

( Додатково див. Постанову КМ N 231 ( 231-93-п ) від 27.03.93 )

Кабінет Міністрів України постановляє:

1. Установити граничну чисельність працівників центрального апарату Міністерства промисловості в кількості 300 одиниць.

2. Дозволити Міністерству промисловості мати п'ятьох заступників Міністра, у тому числі одного першого, і колегію в кількості 11 чоловік.

3. Установити, що до сфери управління Міністерства промисловості належать підприємства, установи й організації металургійної і хімічної промисловості та інших галузей.

4. Міністерсту промисловості в місячний термін розробити і подати на затвердження Кабінету Міністрів України положення про Міністерство, погоджене з Міністерством економіки, Міністерством фінансів, Міністерством праці, Міністерством юстиції, Міністерством охорони навколишнього природного середовища, Фондом державного майна, Державним комітетом з матеріальних ресурсів, Державним комітетом з питань науки і технологій.

5. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України від 29 квітня 1992 р. N 216 ( 216-92-п ) "Питання Міністерства промисловості України" (ЗП України, 1992 р., N 5, ст.118), крім пункту 5, і від 1 липня 1992 р. N 367 ( 367-92-п ) "Про доповнення постанови Кабінету Міністрів України від 29 квітня 1992 р. N 216" (ЗП України, 1992 р., N 7, ст.170).
