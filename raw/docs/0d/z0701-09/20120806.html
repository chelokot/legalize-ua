{ Наказ втратив чинність на підставі Наказу Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 327 ( z1216-12 ) від 02.07.2012 }

Про оприлюднення у засобах масової інформації проектної декларації

Відповідно до Закону України "Про фінансово-кредитні механізми і управління майном при будівництві житла та операціях з нерухомістю" ( 978-15 ) НАКАЗУЮ:

1. Встановити, що друкованим засобом масової інформації, в якому публікується проектна декларація, є газета "Урядовий кур'єр".

2. Державній архітектурно-будівельній інспекції (Папка В.В.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу залишаю за собою.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр Василь Куйбіда
