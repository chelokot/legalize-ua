Текст документа від 28.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 вересня 1999 р. N 1805 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1809 ( 1809-2001-п ) від 28.12.2001 )

Про внесення зміни до постанови Кабінету Міністрів України від 18 жовтня 1994 р. N 717

Кабінет Міністрів України постановляє:

На часткову зміну абзацу другого пункту 7 постанови Кабінету Міністрів України від 18 жовтня 1994 р. N 717 ( 717-94-п ) "Питання Української державної корпорації по будівництву, ремонту та утриманню автомобільних доріг" ввести додатково посаду заступника голови Української державної корпорації по будівництву, ремонту та утриманню автомобільних доріг.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
