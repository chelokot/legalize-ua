Кабінет Міністрів України; Постанова від 26.10.2000 № 1596

Про забезпечення діяльності українських миротворчих контингентів і миротворчого персоналу в складі Місії ООН у Демократичній Республіці Конго та Тимчасових сил ООН у Лівані

Стан: Втратив чинність

Ідентифікатор: 1596-2000-п

Текст документа від 30.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 жовтня 2000 р. N 1596 Київ

Про забезпечення діяльності українських миротворчих контингентів і миротворчого персоналу в складі Місії ООН у Демократичній Республіці Конго та Тимчасових сил ООН у Лівані

{ Із змінами, внесеними згідно з Постановою КМ N 401 ( 401-2006-п ) від 30.03.2006 }

На виконання статті 3 Указу Президента України від 20 червня 2000 р. N 806 ( 806/2000 ) "Про направлення миротворчого контингенту і миротворчого персоналу для участі України в Місії Організації Об'єднаних Націй в Демократичній Республіці Конго та миротворчого контингенту для участі України в Тимчасових силах Організації Об'єднаних Націй у Лівані" Кабінет Міністрів України постановляє:

1. Установити, що:

а) українськими миротворчими контингентами і миротворчим персоналом, направленими для участі в міжнародних миротворчих операціях згідно з Указом Президента України від 20 червня 2000 р. N 806 та від 8 лютого 2002 р. N 118 ( 118/2002 ), є: { Абзац перший підпункту "а" пункту 1 із змінами, внесеними згідно з Постановою КМ N 401 ( 401-2006-п ) від 30.03.2006 }

в складі Місії ООН у Демократичній Республіці Конго - відділ управління авіаційними перевезеннями, відділ контролю за повітряним рухом, відділ забезпечення пально-мастильними матеріалами, метеорологічне бюро, 20-й вертолітний загін та взвод матеріально-технічного забезпечення загальною чисельністю до 280 військовослужбовців і миротворчий персонал чисельністю до 20 військовослужбовців Збройних Сил України;

в Тимчасових силах ООН у Лівані - 3-й окремий інженерний батальйон загальною чисельністю до 650 військовослужбовців та штабні офіцери загальною чисельністю до 10 військовослужбовців; { Абзац третій підпункту "а" пункту 1 із змінами, внесеними згідно з Постановою КМ N 401 ( 401-2006-п ) від 30.03.2006 }

{ Підпункт "б" пункту 1 виключено на підставі Постанови КМ N 401 ( 401-2006-п ) від 30.03.2006 }

в) виплата компенсаційних сум у разі загибелі, поранення або каліцтва військовослужбовців українських миротворчих контингентів і миротворчого персоналу в складі Місії ООН у Демократичній Республіці Конго та Тимчасових сил ООН у Лівані здійснюється згідно із законодавством;

г) фінансування витрат на забезпечення формування та перевезення українських миротворчих контингентів і миротворчого персоналу у 2000 році провадиться за рахунок видатків державного бюджету.

2. Міністерству фінансів вжити заходів до забезпечення Міністерства оборони іноземною валютою для здійснення фінансування потреб українських миротворчих контингентів і миротворчого персоналу.

3. Міністерству оборони компенсаційні суми, які надходитимуть від Секретаріату ООН за використання підрозділів, техніки та майна Збройних Сил України в складі Місії ООН та Тимчасових силах ООН, перераховувати до державного бюджету та використовувати для покриття зазначених витрат згідно із затвердженим кошторисом Міністерства.

{ Пункт 4 виключено на підставі Постанови КМ N 401 ( 401-2006-п ) від 30.03.2006 }

5. Установити, що військовослужбовцям українських миротворчих контингентів і миротворчого персоналу виплачується надбавка до щомісячної грошової винагороди в іноземній валюті з дня прибуття до дня вибуття (включно) з території країн з важкими кліматичними умовами у таких розмірах: { Абзац перший пункту 5 із змінами, внесеними згідно з Постановою КМ N 401 ( 401-2006-п ) від 30.03.2006 }

а) в складі Місії ООН у Демократичній Республіці Конго - 20 відсотків; { Підпункт "а" пункту 5 із змінами, внесеними згідно з Постановою КМ N 401 ( 401-2006-п ) від 30.03.2006 }

б) у Тимчасових силах ООН у Лівані - 10 відсотків. Військовослужбовцям зазначеного контингенту і персоналу виплачується надбавка у розмірі 15 відсотків щомісячної грошової винагороди в іноземній валюті за ті місяці, коли вони безпосередньо брали участь у розмінуванні місцевості. { Підпункт "б" пункту 5 в редакції Постанови КМ N 401 ( 401-2006-п ) від 30.03.2006 }

6. Міністерству оборони подати пропозиції про доповнення постанови Кабінету Міністрів України від 8 лютого 1994 р. N 63 ( 63-94-п ) переліком держав, у яких українські миротворчі контингенти і миротворчий персонал беруть участь у міжнародних миротворчих операціях.

Перший віце-прем'єр-міністр України Ю.ЄХАНУРОВ
