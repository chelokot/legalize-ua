Про граничний розмір роздрібних цін на газ природний

( Із змінами, внесеними згідно з Наказом Міністерства економіки N 57 ( z0200-97 ) від 19.05.97 )

Згідно з повноваженнями, затвердженими постановою Кабінету Міністрів України від 13.02.95 N 109 ( 109-95-п ) "Про уточнення повноважень центральних органів державної виконавчої влади, Уряду Автономної Республіки Крим та виконкомів місцевих Рад у галузі ціноутворення", та з метою недопущення зростання цін під час проведення грошової реформи НАКАЗУЮ:

1. Затвердити граничні роздрібні ціни на природний газ, що споживається населенням на комунально-побутові потреби (додаються).

2. Вважати такими, що втратили чинність, граничні розміри роздрібних цін на газ сітьовий, затверджені наказом Мінекономіки від 26.07.96 N 101 ( z0398-96 ).
