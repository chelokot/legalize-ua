Кабінет Міністрів України; Розпорядження від 30.11.2005 № 490-р

Про перенесення робочих днів у 2006 році

Стан: Чинний

Ідентифікатор: 490-2005-р

Текст документа від 18.08.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 листопада 2005 р. N 490-р Київ

Про перенесення робочих днів у 2006 році

{ Із змінами, внесеними згідно з Розпорядженням КМ N 468-р ( 468-2006-р ) від 18.08.2006 }

З метою створення сприятливих умов для святкування 9 травня - Дня Перемоги, 24 серпня - Дня незалежності України, а також раціонального використання робочого часу рекомендувати керівникам підприємств, установ та організацій перенести у 2006 році для працівників, яким встановлено п'ятиденний робочий тиждень з двома вихідними днями, робочі дні:

з понеділка 8 травня - на суботу 6 травня;

з п'ятниці 25 серпня - на суботу 9 вересня. { Пункт із змінами, внесеними згідно з Розпорядженням КМ N 468-р ( 468-2006-р ) від 18.08.2006 }

Прем'єр-міністр України Ю.ЄХАНУРОВ
