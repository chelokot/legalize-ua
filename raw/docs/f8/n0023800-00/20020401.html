Вищий арбітражний суд; Постанова від 08.09.2000

Про визнання недійсним рішення

Стан: Втратив чинність

Ідентифікатор: n0023800-00

Текст документа від 01.04.2002:

ВИЩИЙ АРБІТРАЖНИЙ СУД УКРАЇНИ

ПОСТАНОВА

08.09.2000

( Постанову скасовано на підставі Постанови Верховного Суду ( n0144700-02 ) від 01.04.2002 )

Судова колегія Вищого арбітражного суду України по перегляду рішень, ухвал, постанов розглянула заяву ТОВ "Блек-Вайт" про перевірку рішення Вищого арбітражного суду України у справі за позовом ТОВ "Блек-Вайт" до Міністерства внутрішніх справ України про визнання недійсним рішення від 22.09.99 "Про анулювання дії ліцензій від 07.12.98 N 2256, 2257".

Рішенням судової колегії Вищого арбітражного суду України по розгляду спорів від 07.06.2000 у позові відмовлено з тих підстав, що анулювання дії ліцензій від 07.12.98 N 2256 та N 2257 проведено відповідачем правомірно, оскільки причиною цього були систематичні порушення позивачем умов та правил здійснення охоронної діяльності, що підтверджується матеріалами справи.

Не погоджуючись з рішенням арбітражного суду позивач подав заяву про його перевірку та скасування як такого, що ухвалене при неповному з'ясуванні всіх обставин справи, просить задовольнити його позов. При цьому ним не заперечується наявність допущення ним порушень умов та правил здійснення охоронної діяльності.

Перевіркою матеріалів справи встановлено таке.

Постановою Кабінету Міністрів України від 10.08.93 N 615 ( 615-93-п ) "Про заходи щодо вдосконалення охорони об'єктів державної та іншої форм власності" встановлено, що діяльність з надання послуг по охороні об'єктів державної, колективної та приватної власності, монтажу, ремонту і профілактичному обслуговуванню засобів охоронної сигналізації здійснюється на підставі спеціальних дозволів (ліцензій) на зайняття вказаною діяльністю, які видаються суб'єктам підприємництва за умови їх відповідності вимогам, визначеним Міністерством внутрішніх справ України.

Позивач на підставі виданих міністерством ліцензій від 07.12.98 N 2256 та N 2257 здійснював позавідомчу охорону державної (крім особливо важливих об'єктів), колективної та приватної власності, а також громадян.

Контроль за цією діяльністю здійснює Державна служба МВС України згідно із затвердженою наказом МВС України від 14.04.98 N 257 ( z0338-98 ) Інструкцією про порядок здійснення контролю за діяльністю суб'єктів підприємницької діяльності, які надають послуги з охорони власності, охорони громадян, а також за діяльністю служб охорони підприємств та організацій усіх форм власності.

В процесі неодноразових перевірок дотримання позивачем умов та правил здійснення охоронної діяльності вказаним органом виявлялися численні порушення, наявність яких позивачем не заперечується.

За таких умов дострокове анулювання Міністерством внутрішніх справ дії ліцензій N 2256 і N 2257 є правомірним, а підстави для зміни чи скасування рішення арбітражного суду відсутні.

Керуючись статтями 49, 106, 108 АПК ( 1798-12 ), судова колегія з перегляду рішень, ухвал, постанов Вищого арбітражного суду України ПОСТАНОВИЛА:

рішення судової колегії Вищого арбітражного суду України по розгляду спорів від 07.06.2000 залишити без змін.
