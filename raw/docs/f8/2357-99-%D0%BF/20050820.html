Кабінет Міністрів України; Постанова, Порядок від 22.12.1999 № 2357

Про затвердження Порядку включення підприємств гірничо-металургійного комплексу до переліку підприємств, які беруть участь в економічному експерименті, контролю за ефективністю їх діяльності в умовах експерименту і виключення із зазначеного переліку

Стан: Втратив чинність

Ідентифікатор: 2357-99-п

Текст документа від 20.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 грудня 1999 р. N 2357 Київ

( Постанова втратила чинність на підставі Постанови КМ N 788 ( 788-2005-п ) від 20.08.2005 )

Про затвердження Порядку включення підприємств гірничо-металургійного комплексу до переліку підприємств, які беруть участь в економічному експерименті, контролю за ефективністю їх діяльності в умовах експерименту і виключення із зазначеного переліку

( Із змінами, внесеними згідно з Постановою КМ N 474 ( 474-2001-п ) від 06.05.2001 )

На виконання Закону України "Про проведення економічного експерименту на підприємствах гірничо-металургійного комплексу України" ( 934-14 ) Кабінет Міністрів України постановляє:

Затвердити Порядок включення підприємств гірничо-металургійного комплексу України до переліку підприємств, які беруть участь в економічному експерименті, контролю за ефективністю їх діяльності в умовах експерименту і виключення із зазначеного переліку (додається).

Перший віце-прем'єр-міністр України А.КІНАХ

Інд. 43

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 22 грудня 1999 р. N 2357

ПОРЯДОК включення підприємств гірничо-металургійного комплексу до переліку підприємств, які беруть участь в економічному експерименті, контролю за ефективністю їх діяльності в умовах експерименту і виключення із зазначеного переліку

( У тексті Порядку слово "Мінпромполітики" замінено словом "Держпромполітики" згідно з Постановою КМ N 474 ( 474-2001-п ) від 06.05.2001 )

1. Підприємство, що входить до гірничо-металургійного комплексу і має намір взяти участь в економічному експерименті, подає до робочої групи, створеної Держпромполітики відповідно до постанови Кабінету Міністрів України від 1 жовтня 1999 р. N 1820 ( 1820-99-п ) "Про перелік підприємств гірничо-металургійного комплексу, які беруть участь в економічному експерименті", такі документи:

загальну інформацію про напрями основної виробничої діяльності, номенклатуру продукції та обгрунтування необхідності її виробництва, структуру, стан та використання виробничих потужностей; ( Абзац пункту 1 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

витяг з документів фінансової звітності про основні результати фінансово-господарської діяльності підприємства за останній повний рік та поточний період (щоквартальну); ( Абзац пункту 1 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

інвестиційну програму розвитку підприємства та порівняльні розрахунки фінансових показників господарської діяльності в умовах економічного експерименту; ( Абзац пункту 1 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

відомості про стан виконання поточних розрахунків з бюджетами усіх рівнів і порівняльні розрахунки фінансової діяльності у звичайних умовах та в умовах економічного експерименту; ( Абзац пункту 1 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

відомості про стан розрахунків з виплати заробітної плати, з Пенсійним фондом, за спожиті енергоносії та графіки погашення наявної заборгованості за цими розрахунками; ( Абзац пункту 1 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

план здійснення природоохоронних заходів, у тому числі за рахунок 70 відсотків збору за забруднення навколишнього природного середовища, що залишається у розпорядженні підприємств; ( Абзац пункту 1 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

інформацію про наявність іноземних кредитів, що отримані під гарантії Кабінету Міністрів України, та їх повернення. ( Абзац пункту 1 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

2. Основною умовою для прийняття рішення про доцільність включення підприємства до переліку підприємств, які беруть участь у економічному експерименті (далі - перелік), є наявність документів, зазначених у пункті 1 Порядку, та обгрунтування розрахунків виробничих та фінансово-економічних показників діяльності підприємства в умовах економічного експерименту. При цьому враховується, що частка товарної продукції (послуг), яка виробляється таким підприємством для гірничо-металургійного комплексу, повинна становити не менше ніж 50 відсотків у загальному обсязі його продукції (послуг), а також:

розроблення заходів щодо подолання збитковості в роботі протягом перших двох кварталів участі в експерименті;

забезпечення поточних розрахунків з бюджетами всіх рівнів та збільшення, за результатами участі в експерименті, фактичних надходжень до бюджету порівняно з роботою в загальних умовах.

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 474 ( 474-2001-п ) від 06.05.2001 )

3. Умови економічного експерименту поширюються на підприємство з дня набрання чинності рішенням Кабінету Міністрів України про його включення до переліку. ( Пункт 3 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

4. Робоча група щокварталу розглядає матеріали про включення підприємства до переліку та приймає рішення про доцільність такого включення. ( Пункт 4 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

5. У разі прийняття робочою групою рішення про доцільність включення підприємства до переліку Держпромполітики разом з Державною податковою адміністрацією, Мінекономіки, Мінфіном, Мінекобезпеки та Мін'юстом готує пропозиції, які після погодження з Комітетом Верховної Ради України з питань промислової політики подає Кабінету Міністрів України для прийняття відповідного рішення.

6. У разі відмови включити підприємство до переліку Держпромполітики надсилає обгрунтовану відповідь заінтересованій особі.

7. Підприємства, що беруть участь у економічному експерименті, за результатами своєї роботи щокварталу надають робочій групі звіт, форма якого затверджується наказом Держпромполітики. Відповідальність за достовірність цього звіту покладається на керівника підприємства. ( Пункт 7 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

8. Робоча група у десятиденний термін розглядає матеріали підприємств про результати роботи в умовах економічного експерименту та подає узагальнену інформацію Кабінетові Міністрів України.

9. Контроль за ефективністю роботи підприємств в умовах економічного експерименту здійснюється робочою групою шляхом порівняння показників їх виробничої та фінансово-економічної діяльності, визначених у пункті 7 Порядку, за звітний період з аналогічним періодом минулого року та попереднім кварталом поточного року.

Держпромполітики здійснює щомісячний контроль за виконанням підприємствами умов економічного експерименту на підставі оперативних даних щодо зменшення обсягів бартерних операцій, стану розрахунків з бюджетами всіх рівнів, Пенсійним фондом, із заробітної плати, за спожиті енергоносії та інформує про результати Кабінет Міністрів України.

( Пункт 9 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

10. Рішення про виключення підприємства з переліку приймається у разі:

невнесення поточних платежів до бюджетів усіх рівнів і Пенсійного фонду, збору за забруднення навколишнього природного середовища, а також коли не оплачено спожиті енергоносії;

недотримання вимог щодо зменшення заборгованості із заробітної плати;

порушення угод кооперованих поставок продукції в обсягах, що визначені прямими договорами підприємств та підтверджені гарантованою оплатою;

недотримання вимог щодо зменшення обсягів бартерних операцій та виробництва продукції за давальницькими схемами;

застосування рівня цін, який перевищує експортні, на продукцію, що постачається за прямими договорами у межах виробничої кооперації, в тому числі підприємствам машинобудівного комплексу;

невикористання прибутку підприємства на поточне фінансування заходів з поновлення основних фондів, підвищення технічного та технологічного рівня виробництва в обсязі, що дорівнює або перевищує суми сформованих пільгових коштів.

( Пункт 10 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

11. У разі відсутності протягом двох звітних кварталів позитивних результатів фінансово-господарської діяльності підприємства робоча група розглядає питання про доцільність подальшої його участі в економічному експерименті та подає відповідні пропозиції Кабінетові Міністрів України щодо виключення підприємства з переліку. ( Пункт 11 в редакції Постанови КМ N 474 ( 474-2001-п ) від 06.05.2001 )

12. Держпромполітики за висновками робочої групи готує та подає погоджені із заінтересованими міністерствами та Комітетом Верховної Ради України з питань промислової політики пропозиції про дострокове вилучення підприємства з переліку.

13. Терміном припинення економічного експерименту на підприємстві є дата прийняття Кабінетом Міністрів України відповідного рішення.

14. Прийняття рішення про виключення підприємства з переліку тягне за собою втрату права на пільги, надані відповідно до Закону України "Про проведення економічного експерименту на підприємствах гірничо-металургійного комплексу України" ( 934-14 ).
