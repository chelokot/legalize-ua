Кабінет Міністрів України; Постанова від 19.04.2005 № 299

Про встановлення розміру додаткової грошової винагороди деяким категоріям військовослужбовців та іншим особам

Стан: Втратив чинність

Ідентифікатор: 299-2005-п

Текст документа від 01.01.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 квітня 2005 р. N 299 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1294 ( 1294-2007-п ) від 07.11.2007 }

Про встановлення розміру додаткової грошової винагороди деяким категоріям військовослужбовців та іншим особам

{ Із змінами, внесеними згідно з Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

Кабінет Міністрів України постановляє:

1. Надати право Міністру оборони, керівникам інших центральних органів виконавчої влади, що здійснюють керівництво військовими формуваннями, Міністру внутрішніх справ, Міністру транспорту та зв'язку, Голові Державного департаменту з питань виконання покарань встановлювати починаючи з 1 квітня 2005 р. за рахунок коштів, передбачених зазначеним центральним органам виконавчої влади у державному бюджеті на відповідний рік, військовослужбовцям рядового, сержантського та старшинського складу, які проходять військову службу за контрактом, прапорщикам і мічманам, особам рядового і молодшого начальницького складу органів внутрішніх справ, Державної кримінально-виконавчої служби та служби цивільного захисту щомісячну додаткову грошову винагороду у розмірі від 100 до 300 гривень.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

2. Установити, що:

порядок та умови виплати щомісячної додаткової грошової винагороди, передбаченої пунктом 1 цієї постанови, визначаються Міністром оборони, керівниками інших центральних органів виконавчої влади, що здійснюють керівництво військовими формуваннями, Міністром внутрішніх справ, Міністром транспорту та зв'язку, Головою Державного департаменту з питань виконання покарань залежно від тривалості та умов служби;

щомісячна додаткова грошова винагорода не включається до суми грошового забезпечення, з якої обчислюються пенсії та грошова допомога при звільненні.

Прем'єр-міністр України Ю.ТИМОШЕНКО
