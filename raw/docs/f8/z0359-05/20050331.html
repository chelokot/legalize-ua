Зареєстровано в Міністерстві юстиції України 5 квітня 2005 р. за N 359/10639

Про скасування обов'язкового продажу надходжень в іноземній валюті на користь резидентів

Відповідно до статей 44, 45 і 47 Закону України "Про Національний банк України" ( 679-14 ) та статей 4 та 6 Декрету Кабінету Міністрів України від 19.02.93 N 15-93 ( 15-93 ) "Про систему валютного регулювання і валютного контролю", а також з метою надання права суб'єктам зовнішньоекономічної діяльності самостійно розпоряджатися надходженнями в іноземній валюті Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Визнати такими, що втратили чинність:

постанову Правління Національного банку України від 04.09.98 N 349 ( v0575500-98 ) "Про введення обов'язкового продажу надходжень в іноземній валюті на користь резидентів - юридичних осіб";

постанову Правління Національного банку України від 14.09.98 N 365 ( v0576500-98 ) "Про внесення змін до постанови Правління Національного банку України від 4 вересня 1998 р. N 349 "Про введення обов'язкового продажу надходжень в іноземній валюті на користь резидентів - юридичних осіб";

постанову Правління Національного банку України від 01.10.98 N 408 ( v0408500-98 ) "Про внесення змін до постанови Правління Національного банку від 14.09.98 р. N 365";

постанову Правління Національного банку України від 22.01.99 N 26 ( v0615500-99 ) "Про внесення доповнень до постанови Правління Національного банку України від 04.09.98 N 349 "Про введення обов'язкового продажу надходжень в іноземній валюті на користь резидентів - юридичних осіб";

постанову Правління Національного банку України від 27.01.99 N 39 ( v0615500-99 ) "Про внесення змін та доповнень до постанови Правління Національного банку України від 04.09.98 N 349";

постанову Правління Національного банку України від 12.02.99 N 62 ( v0621500-99 ) "Про внесення змін до постанови Правління Національного банку від 04.09.98 р. N 349";

пункт 3 постанови Правління Національного банку України від 24.03.99 N 141 ( v0636500-99 ) "Про внесення змін і доповнень до окремих нормативних документів Національного банку України з питань валютного регулювання";

пункт 1 постанови Правління Національного банку України від 15.09.99 N 455 ( z0666-99 ) "Про внесення змін і доповнень до деяких нормативно-правових актів Національного банку України", зареєстрованої в Міністерстві юстиції України 01.10.99 за N 666/3959;

постанову Правління Національного банку України від 22.12.99 N 604 ( z0020-00 ) "Про внесення змін до постанови Правління Національного банку України від 04.09.98 N 349", зареєстровану в Міністерстві юстиції України 17.01.2000 за N 20/4241;

постанову Правління Національного банку України від 09.03.2000 N 93 ( z0172-00 ) "Про внесення змін до постанови Правління Національного банку України від 04.09.98 N 349", зареєстровану в Міністерстві юстиції України 17.03.2000 за N 172/4393;

постанову Правління Національного банку України від 12.02.2001 N 62 ( z0175-01 ) "Про внесення змін та доповнень до постанови Правління Національного банку України "Про введення обов'язкового продажу надходжень в іноземній валюті на користь резидентів - юридичних осіб", зареєстровану в Міністерстві юстиції України 27.02.2001 за N 175/5366;

пункт 1 постанови Правління Національного банку України від 09.09.2002 N 336 ( z0776-02 ) "Про вдосконалення порядку здійснення обов'язкового продажу надходжень в іноземній валюті на користь резидентів", зареєстрованої в Міністерстві юстиції України 23.09.2002 за N 776/7064;

постанову Правління Національного банку України від 03.11.2003 N 475 ( z1049-03 ) "Про внесення зміни до постанови Правління Національного банку України від 04.09.98 N 349", зареєстровану в Міністерстві юстиції України 14.11.2003 за N 1049/8370.

2. Департаменту валютного регулювання (М.О.Мельничук) у тримісячний строк з дня набрання чинності цією постановою розробити проекти змін до:

Правил здійснення операцій на міжбанківському валютному ринку України, затверджених постановою Правління Національного банку України від 18.03.99 N 127 ( z0171-99 ) і зареєстрованих у Міністерстві юстиції України 18.03.99 за N 171/3464 (зі змінами);

Положення про порядок видачі Національним банком України індивідуальних ліцензій на розміщення резидентами (юридичними та фізичними особами) валютних цінностей на рахунках за межами України, затвердженого постановою Правління Національного банку України від 14.10.2004 N 485 ( z1413-04 ) та зареєстрованого в Міністерстві юстиції України 05.11.2004 за N 1413/10012.

До внесення відповідних змін зазначені нормативно-правові акти діють у частині, що не регулює здійснення обов'язкового продажу надходжень в іноземній валюті.

3. Департаменту валютного регулювання (М.О.Мельничук) після державної реєстрації в Міністерстві юстиції України довести зміст цієї постанови до відома Операційного і територіальних управлінь Національного банку України та банків для використання в роботі.

4. Контроль за виконанням цієї постанови покласти на Департамент валютного регулювання (М.О.Мельничук).

5. Постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.
