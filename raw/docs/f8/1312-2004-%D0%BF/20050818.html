Кабінет Міністрів України; Постанова від 05.10.2004 № 1312

Про утворення української делегації для участі у Змішаній українсько-румунській прикордонній комісії з перевірки проходження лінії державного кордону

Стан: Чинний

Ідентифікатор: 1312-2004-п

Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 жовтня 2004 р. N 1312 Київ

Про утворення української делегації для участі у Змішаній українсько-румунській прикордонній комісії з перевірки проходження лінії державного кордону

( Із змінами, внесеними згідно з Постановою КМ N 753 ( 753-2005-п ) від 18.08.2005 )

З метою забезпечення виконання Договору між Україною та Румунією про режим українсько-румунського державного кордону, співробітництво та взаємну допомогу з прикордонних питань ( 642_022 ) Кабінет Міністрів України постановляє:

1. Утворити українську делегацію для участі у роботі Змішаної українсько-румунської прикордонної комісії з перевірки проходження лінії державного кордону (далі - Комісія) у складі представників Адміністрації Державної прикордонної служби (голова і два члени делегації), Міністерства оборони (заступник голови і член делегації), Міністерства закордонних справ (член делегації), державної установи "Держгідрографія" (член делегації).

Персональний склад української делегації затверджується Адміністрацією Державної прикордонної служби за поданням відповідних центральних органів виконавчої влади.

2. З метою підвищення ефективності дій центральних і місцевих органів виконавчої влади з проведення спільної перевірки проходження лінії українсько-румунського державного кордону визначити відповідальними:

1) за організацію перевірки, проведення переговорів з цих питань - Адміністрацію Державної прикордонної служби, Міністерство закордонних справ;

2) за проведення аерофотознімальних, топографічних, геодезичних, картографічних робіт, перевірки проходження лінії державного кордону на місцевості, нанесення її на топографічні карти, підготовку підсумкової документації - Міністерство оборони;

3) за проведення гідрографічних робіт на річкових ділянках державного кордону - Міністерство транспорту та зв'язку;

4) за надання організаційної допомоги у проведенні засідань комісії на території прикордонних областей - відповідні обласні державні адміністрації.

3. Фінансування заходів з перевірки проходження лінії державного кордону здійснюється за рахунок коштів, передбачених у державному бюджеті Державній прикордонній службі, Міністерству оборони, Міністерству транспорту та зв'язку.

4. Контроль за діяльністю української делегації покласти на Голову Державної прикордонної служби.

5. Адміністрації Державної прикордонної служби, Міністерству оборони, Міністерству закордонних справ, Державному комітетові по земельних ресурсах, Державному комітетові лісового господарства, Державному комітетові по водному господарству, обласним державним адміністраціям направляти за зверненням голови української делегації відповідних фахівців для участі у переговорах з Румунською Стороною.

6. Адміністрації Державної прикордонної служби подавати після кожного засідання Комісії Кабінетові Міністрів України звіти про результати здійснення заходів з перевірки проходження лінії державного кордону, а також про стан організаційного, матеріально-технічного та фінансового їх забезпечення.

( Пункт 7 втратив чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )
