Кабінет Міністрів України; Постанова від 28.12.2011 № 1391

Про внесення змін до постанов Кабінету Міністрів України від 13 жовтня 2000 р. N 1555 і від 26 квітня 2003 р. N 623

Стан: Чинний

Ідентифікатор: 1391-2011-п

Текст документа від 24.03.2023:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 грудня 2011 р. N 1391 Київ

Про внесення змін до постанов Кабінету Міністрів України від 13 жовтня 2000 р. N 1555 і від 26 квітня 2003 р. N 623

{ Із змінами, внесеними згідно з Постановою КМ N 233 ( 233-2023-п ) від 17.03.2023 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 13 жовтня 2000 р. N 1555 ( 1555-2000-п ) "Про затвердження положень з питань розповсюдження примірників аудіовізуальних творів, фонограм, відеограм, комп'ютерних програм, баз даних" (Офіційний вісник України, 2000 р., N 42, ст. 1792; 2004 р., N 12, ст. 741; 2011 р., N 71, ст. 2673) і від 26 квітня 2003 р. N 623 ( 623-2003-п ) "Про затвердження Порядку присвоєння і нанесення на диски для лазерних систем зчитування та/або матриці спеціального ідентифікаційного коду та визнання спеціальних ідентифікаційних кодів, нанесених на диски та/або матриці, що експортуються, або матриці, що імпортуються" (Офіційний вісник України, 2003 р., N 18-19, ст. 836; 2005 р., N 37, ст. 2280; 2011 р., N 71, ст. 2673) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 грудня 2011 р. N 1391

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 13 жовтня 2000 р. N 1555 ( 1555-2000-п ) і від 26 квітня 2003 р. N 623 ( 623-2003-п )

{ Пункт 1 втратив чинність на підставі Постанови КМ N 233 ( 233-2023-п ) від 17.03.2023 }

2. У додатках 2 і 3 до Порядку присвоєння і нанесення на диски для лазерних систем зчитування та/або матриці спеціального ідентифікаційного коду та визнання спеціальних ідентифікаційних кодів, нанесених на диски та/або матриці, що експортуються, або матриці, що імпортуються, затвердженого постановою Кабінету Міністрів України від 26 квітня 2003 р. N 623 ( 623-2003-п ), слова "Код згідно з ЄДРПОУ" замінити словами "Ідентифікаційний код згідно з ЄДРПОУ (для юридичної особи)/Реєстраційний номер облікової картки платника податків або номер та серія паспорта (для фізичних осіб, які через свої релігійні або інші переконання відмовилися від прийняття реєстраційного номера облікової картки платника податків, офіційно повідомили про це відповідні органи державної влади і мають відмітку у паспорті) (для фізичної особи - підприємця)".
