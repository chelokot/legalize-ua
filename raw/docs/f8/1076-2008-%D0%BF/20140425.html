Текст документа від 25.04.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 грудня 2008 р. N 1076 Київ

Про доповнення постанов Кабінету Міністрів України від 29 березня 2004 р. N 399 і від 9 жовтня 2006 р. N 1404

{ Із змінами, внесеними згідно з Постановою КМ N 117 ( 117-2014-п ) від 23.04.2014 }

Кабінет Міністрів України постановляє:

1. У постанові Кабінету Міністрів України від 29 березня 2004 р. N 399 ( 399-2004-п ) "Деякі питання здійснення попередньої оплати робіт (послуг) замовниками будівництва атомних, гідроакумулюючих та вітрових електростанцій" (Офіційний вісник України, 2004 р., N 13, ст. 891) доповнити:

назву після слова "будівництва" словами "магістральних електричних мереж,";

пункт 1 після слова "будівництва" словами "магістральних електричних мереж (у разі придбання обладнання, визначеного затвердженою проектно-кошторисною документацією),".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 117 ( 117-2014-п ) від 23.04.2014 }
