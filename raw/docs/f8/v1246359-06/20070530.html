Про штатний розпис Центральної виборчої комісії

{ Із змінами, внесеними згідно з Постановами Центральної виборчої комісії N 1277 ( v1277359-06 ) від 25.09.2006 N 1296 ( v1296359-06 ) від 14.12.2006 }

З метою упорядкування умов оплати праці працівників Секретаріату Центральної виборчої комісії, відповідно до постанов Кабінету Міністрів України від 9 березня 2006 року N 268 ( 268-2006-п ) "Про упорядкування структури та умов оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів", від 24 травня 2006 року N 710 ( 710-2006-п ) "Про доповнення додатка 9 до постанови Кабінету Міністрів України від 9 березня 2006 р. N 268", Указу Президента України від 11 грудня 2001 року N 1207 ( 1207/2001 ) "Про деякі заходи щодо зміцнення юридичних служб державних органів", враховуючи наказ Міністерства праці та соціальної політики України від 2 жовтня 1996 року N 77 ( z0593-96 ) "Про умови оплати праці робітників, зайнятих обслуговуванням органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів", Колективний договір автогосподарства Центральної виборчої комісії на 2005 рік (із змінами та доповненнями від 23 травня 2006 року), керуючись статтями 11, 12, частиною другою статті 33 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Затвердити штатний розпис Центральної виборчої комісії (додається).

2. Відділу бухгалтерського обліку та звітності Секретаріату Центральної виборчої комісії провести перерахунок заробітної плати:

- працівників Секретаріату Центральної виборчої комісії з 1 січня 2006 року, крім юридичного управління;

- працівників юридичного управління Секретаріату Центральної виборчої комісії з 1 квітня 2006 року.

3. Визнати такими, що втратили чинність, постанови Центральної виборчої комісії:

від 1 березня 2005 року N 52 ( v0052359-05 );

від 18 травня 2005 року N 83 ( v0083359-05 );

від 24 травня 2005 року N 86 ( v0086359-05 );

від 25 червня 2005 року N 101 ( v0101359-05 );

від 8 липня 2005 року N 108 ( v0108359-05 );

від 8 липня 2005 року N 109 ( v0109359-05 );

від 6 вересня 2005 року N 120 ( v0120359-05 );

від 9 листопада 2005 року N 139 ( v0139359-05 );

від 24 січня 2006 року N 269 ( v0269359-06 ).
