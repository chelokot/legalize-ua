{ Указ втратив чинність на підставі Указу Президента N 496/2010 ( 496/2010 ) від 02.04.2010 }

Про покладення виконання обов'язків

На часткову зміну статті 4 Указу Президента України від 13 березня 2006 року N 215 ( 215/2006 ) "Про Національну систему координації співробітництва України з Організацією Північноатлантичного договору" покласти тимчасово на ХАНДОГІЯ Володимира Дмитровича - заступника Міністра закордонних справ України - виконання обов'язків національного координатора співробітництва України з НАТО у сфері зовнішньої політики, голови Міжвідомчої комісії з питань підготовки України до вступу в НАТО.

Президент України В.ЮЩЕНКО

м. Київ, 18 жовтня 2006 року N 887/2006
