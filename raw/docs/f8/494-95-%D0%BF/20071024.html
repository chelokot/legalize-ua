ПОСТАНОВА від 5 липня 1995 р. N 494 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Української частини двосторонньої міжурядової Українсько-Молдавської комісії з питань торговельно-економічного співробітництва

Кабінет Міністрів України постановляє:

Призначити заступника Міністра промисловості України Мурашка Андрія Петровича головою Української частини двосторонньої міжурядової Українсько-Молдавської комісії з питань торговельно-економічного співробітництва, увільнивши від цих обов'язків Маліча Сергія Валентиновича.
