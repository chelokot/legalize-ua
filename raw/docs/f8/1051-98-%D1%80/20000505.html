Кабінет Міністрів України; Розпорядження від 18.12.1998 № 1051-р

Про митне оформлення вантажу для Національної кіностудії художніх фільмів імені О. Довженка

Стан: Втратив чинність

Ідентифікатор: 1051-98-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 грудня 1998 р. N 1051-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення вантажу (обладнання для переоснащення звукоцеху), який надійшов за контрактом від 14 серпня 1998 р. N 68 для Національної кіностудії художніх фільмів імені Олександра Довженка, з нарахуванням митного збору за його перебування під митним контролем лише за перші 10 днів періоду, за який збір справляється.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
