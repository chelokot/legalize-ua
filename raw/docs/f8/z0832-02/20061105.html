{ Із змінами, внесеними згідно з Наказами Державного комітету статистики N 166 ( z0764-05 ) від 04.07.2005 N 487 ( z1165-06 ) від 17.10.2006 }

Відповідно до статті 14 Закону України "Про державну статистику" ( 2614-12 ) та з метою подальшого удосконалення державних статистичних спостережень з електротранспорту НАКАЗУЮ:

1. Затвердити:

1.1. Форму державного статистичного спостереження N 2-етр "Звіт про роботу міського електротранспорту" та Інструкцію щодо заповнення звіту про роботу міського електротранспорту за формою державного статистичного спостереження N 2-етр (додаються).

1.2. Перший розділ форми державного статистичного спостереження N 2-етр ввести в дію зі звіту за січень 2007 року, другий розділ - зі звіту за 2002 рік. { Підпункт 1.2 пункту 1 із змінами, внесеними згідно з Наказом Державного комітету статистики N 487 ( z1165-06 ) від 17.10.2006 }

2. Поширити форму N 2-етр та Інструкцію щодо її заповнення на трамвайні, тролейбусні, трамвайно-тролейбусні підприємства, виробничі об'єднання "Міськелектротранс", що підпорядковані органам комунального господарства, підприємства та організації, які мають на своєму балансі трамвайне (тролейбусне) господарство, виробничі управління метрополітенів.

3. Управлінню статистики послуг та соціальних програм (Калачова І.В.):

3.1. Передати управлінню справами оригінал бланка форми державного статистичного спостереження N 2-етр та Інструкції щодо її заповнення для тиражування.

3.2. Спільно з Головним міжрегіональним управлінням статистики у м. Києві (Сидоренко М.М.) передбачити внесення відповідних змін до постановки задачі і програмного забезпечення КЕОІ за формою N 2-етр у проекті Плану розробки та експлуатації КЕОІ на 2003 рік.

3.3. Здійснювати методологічне керівництво збором та розробкою звітів за формою N 2-етр.

4. Фінансово-економічному управлінню (Сорокіна Т.В.) забезпечити фінансування виготовлення бланків форми державного статистичного спостереження N 2-етр.

5. Управлінню справами (Царський В.І.) забезпечити контроль за своєчасним виготовленням і розсилкою бланків зазначених форми та Інструкції на адресу Головного управління статистики в Автономній Республіці Крим, обласних, Київського та Севастопольського міських управлінь статистики.

6. Начальнику Головного управління статистики в Автономній Республіці Крим, обласних, Київського та Севастопольського міських управлінь статистики забезпечити в установленому порядку збір, розробку і подання форми державного статистичного спостереження N 2-етр в установлені терміни.

7. Головному міжрегіональному управлінню статистики у м. Києві (Сидоренко М.М.) забезпечити збір і розробку зведених даних форми державного статистичного спостереження N 2-етр згідно з Планом державних статистичних спостережень.

ІНСТРУКЦІЯ ЩОДО ЗАПОВНЕННЯ ЗВІТУ ПРО РОБОТУ МІСЬКОГО ЕЛЕКТРОТРАНСПОРТУ ЗА ФОРМОЮ ДЕРЖАВНОГО СТАТИСТИЧНОГО СПОСТЕРЕЖЕННЯ N 2-ЕТР

{ У тексті Інструкції слово "складання" замінено на "заповнення" в усіх відмінках згідно з Наказом Державного комітету статистики N 487 ( z1165-06 ) від 17.10.2006 }

1. Загальні положення

Ця Інструкція встановлює єдиний порядок обліку обсягів послуг міського електротранспорту (трамвая (фунікулера), тролейбуса, метрополітену), наявності основних виробничих засобів (у натуральному виразі) з метою одержання зведеної статистичної інформації про роботу міського електротранспорту. ( Абзац перший розділу 1 із змінами, внесеними згідно з Наказом Державного комітету статистики N 166 ( z0764-05 ) від 04.07.2005 )

Дія Інструкції поширюється на трамвайні, тролейбусні, трамвайно-тролейбусні підприємства, виробничі об'єднання "Міськелектротранс" усіх форм власності та підпорядкування, підприємства та організації, які мають на своєму балансі трамвайне (тролейбусне) господарство, а також на виробничі управління метрополітенів (далі - підприємства).

2. Порядок заповнення форми державного статистичного спостереження про роботу міського електротранспорту

Звіт про роботу міського електротранспорту за формою державного статистичного спостереження N 2-етр заповнюється окремо для кожного виду транспорту - трамвай (фунікулер), тролейбус, метро.

2.1. У першому розділі "Продукція електротранспорту" наводяться дані про обсяги перевезень пасажирів, у тому числі з платним проїздом. Розділ заповнюється кожен звітний місяць. { Пункт 2.1 розділу 2 із змінами, внесеними згідно з Наказом Державного комітету статистики N 487 ( z1165-06 ) від 17.10.2006 }

2.1.1. "Перевезено пасажирів" - визначається відповідно до пункту 6 Інструкції про порядок обліку пасажирів, що перевозяться громадським транспортом на маршрутах, затвердженої наказом Міністерства статистики України від 27.05.96 N 150 ( z0258-96 ), зареєстрованої в Міністерстві юстиції України 30.05.96 за N 258/1283 (із змінами та доповненнями). Кількість перевезених пасажирів дорівнює сумі кількості перевезених пасажирів за разовими квитками (талонами, жетонами), абонементними квитками та кількості пасажирів з правом безплатного проїзду згідно з чинним законодавством.

При цьому:

кількість перевезених пасажирів за разовими квитками (талонами, жетонами) визначається діленням виторгу від продажу разових квитків (талонів, жетонів) на затверджений місцевими органами виконавчої влади для відповідного виду транспорту тариф або на єдиний тариф для усіх видів транспорту;

кількість перевезених пасажирів за абонементними проїзними квитками визначається множенням кількості проданих абонементних квитків на встановлену кількість поїздок;

кількість перевезених пасажирів за посвідченнями, що дають право на безплатний проїзд у громадському транспорті згідно з чинним законодавством, визначається за коефіцієнтами співвідношення безплатних та платних пасажирів, які затверджуються для підприємств пасажирського транспорту територіальними управліннями статистики один раз на рік.

Із загальної кількості перевезених пасажирів виділяються дані "у тому числі з платним проїздом".

Дані про кількість перевезених пасажирів усього та з платним проїздом наводяться в цілому та "у тому числі за видами сполучення": у внутрішньоміському (перевезення пасажирів у межах міста), з них - в обласному центрі (перевезення пасажирів у межах обласного центру); у приміському (перевезення пасажирів на маршрутах, довжина яких не перевищує 50 км); у міжміському (перевезення пасажирів на маршрутах, довжина яких перевищує 50 км).

2.2. У другому розділі "Шляхове господарство та рухомий склад на кінець звітного року" наводяться дані про основні виробничі фонди у натуральному виразі. Розділ заповнюється один раз на рік за станом на 31 грудня звітного року. ( Пункт 2.2 розділу 2 із змінами, внесеними згідно з Наказом Державного комітету статистики N 166 ( z0764-05 ) від 04.07.2005 )

2.2.1. "Розгорнута довжина колій" - визначається для метрополітену в одноколійному обчисленні і включає пасажирські, вантажні, деповські колії (лінії), роз'їзди, вузли, поворотні кільця та інші колії, які враховані в інвентарних даних.

Довжина колій, що закриті для руху і підлягають знесенню, до звіту не включається.

"Експлуатаційна довжина колій в двоколійному обчисленні" для метрополітену визначається як протяжність головної колії.

"Експлуатаційна довжина колії (лінії) в одноколійному (путному) обчисленні" визначається для трамвайного, тролейбусного (трамвайно-тролейбусного) підприємства і включає довжину всіх трамвайних колій, тролейбусних ліній, які є в експлуатації та перебувають на балансі трамвайних, тролейбусних та трамвайно-тролейбусних господарств".

Підставою для заповнення є технічний паспорт колійного господарства та документи бухгалтерського обліку.

2.2.2. "Інвентарна кількість пасажирського рухомого складу" - включає наявну кількість пасажирських трамвайних вагонів, вагонів метрополітену та тролейбусів, що перебувають на балансі підприємства, незалежно від технічного стану. Підставою для заповнення є документи бухгалтерського обліку основних засобів.

Дані "Інвентарної кількості пасажирського рухомого складу" наводяться в цілому та "у тому числі за часом експлуатації: до 5 років; від 5 до 10 років; від 10 до 15 років; від 15 і більше".

( Підпункт 2.2.3 пункту 2.2 розділу 2 вилучено на підставі Наказу Державного комітету статистики N 166 ( z0764-05 ) від 04.07.2005 )

3. Порядок подання звіту

Звіт про роботу міського електротранспорту за формою N 2-етр заповнюється відповідно до цієї Інструкції, підписується керівником підприємства, який несе адміністративну відповідальність згідно з чинним законодавством.

( Розділ 3 в редакції Наказу Державного комітету статистики N 166 ( z0764-05 ) від 04.07.2005 )
