КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 липня 2010 р. N 1507-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1280-р ( 1280-2014-р ) від 29.12.2014 }

Про експорт електроенергії до Республіки Молдова

1. Погодитися з пропозицією Міністерства палива та енергетики щодо забезпечення експорту електроенергії до Республіки Молдова за оптовою ринковою ціною без урахування обсягу дотації для компенсації втрат, пов'язаних з постачанням електроенергії за регульованим тарифом.

2. Державному підприємству "Енергоринок" забезпечити укладення з постачальниками електроенергії договорів купівлі-продажу електроенергії на оптовому ринку електричної енергії України для її подальшого експорту до Республіки Молдова відповідно до вимог пункту першого цього розпорядження.

Прем'єр-міністр України М.АЗАРОВ
