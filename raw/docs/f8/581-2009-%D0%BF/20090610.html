Інд. 49

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 10 червня 2009 р. N 581

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. Пункт 1 та абзац восьмий пункту 17 Методики розрахунку і порядку використання плати за оренду державного майна, затвердженої постановою Кабінету Міністрів України від 4 жовтня 1995 р. N 786 ( 786-95-п ) (ЗП України, 1996 р., N 2, ст. 57; Офіційний вісник України, 1998 р., N 20, ст. 742; 1999 р., N 26, ст. 1242; 2000 р., N 3, ст. 84, N 49, ст. 2124; 2001 р., N 8, ст. 321; 2002 р., N 28, ст. 1320, N 47, ст. 2124; 2005 р., N 44, ст. 2770; 2007 р., N 1, ст. 34) після слів "інших військових формувань" доповнити словами ", органами, підрозділами, закладами та установами Держспецзв'язку,".

2. Пункт 3 постанови Кабінету Міністрів України від 3 травня 2000 р. N 749 ( 749-2000-п ) "Про затвердження Порядку реєстрації військових частин як суб'єктів господарської діяльності у Збройних Силах" (Офіційний вісник України, 2000 р., N 18, ст. 752) після слів "військові формування" доповнити словами "та Державну службу спеціального зв'язку та захисту інформації".

3. Пункт 3 постанови Кабінету Міністрів України від 11 травня 2000 р. N 778 ( 778-2000-п ) "Про затвердження Порядку надання дозволу військовим частинам Збройних Сил на передачу закріпленого за ними рухомого та нерухомого майна в оренду" (Офіційний вісник України, 2000 р., N 20, ст. 821) після слів "військові формування" доповнити словами "та Державну службу спеціального зв'язку та захисту інформації".
