Про створення Тимчасового координаційного комітету для координації робіт щодо інвестиційного Проекту розвитку житлового господарства України

Стан: Втратив чинність

Ідентифікатор: 56-96-р

Текст документа від 27.06.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 січня 1996 р. N 56-р Київ

Про створення Тимчасового координаційного комітету для координації робіт щодо інвестиційного Проекту розвитку житлового господарства України

( Із змінами, внесеними згідно з Постановою КМ N 1038 ( 1038-2000-п ) від 27.06.2000 )

1. З метою координації робіт щодо інвестиційного Проекту розвитку житлового господарства України (далі - Проект), що фінансуватиметься за рахунок кредиту Світового банку, утворити Тимчасовий координаційний комітет у складі згідно з додатком.

Дозволити голові Тимчасового координаційного комітету вносити зміни до персонального складу зазначеного Комітету.

2. Покласти на Тимчасовий координаційний комітет:

організацію співробітництва представників та місій Світового банку з державними органами і організаціями України, які беруть участь у Проекті;

аналіз та узгодження з представниками Світового банку заходів щодо розвитку житлового господарства України в межах Проекту;

узгодження кандидатур консультантів від України (окремих осіб та організацій), які пропонуються для співпраці із Світовим банком; ( Абзац четвертий пункту 2 із змінами, внесеними згідно з Постановою КМ N 1038 ( 1038-2000-п ) від 27.06.2000 )

призначення керівників робочих груп-координаторів Проекту за конкретними напрямами та затвердження складу цих груп;

аналіз звітів експертів Світового банку та координаторів Проекту за конкретними напрямами;

узгодження матеріалів Проекту для розгляду їх Валютно-кредитною радою Кабінету Міністрів України та Радою директорів Світового банку;

узгодження механізму використання коштів позики Світового банку на реалізацію Проекту;

узгодження механізму повернення позики Світовому банку.

3. Рішення Тимчасового координаційного комітету, прийняті в межах його компетенції, є обов'язковими для учасників Проекту. Рішення оформлюються та доводяться до виконавців у вигляді протоколів засідань Комітету.
