КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 серпня 2000 р. N 325-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 45-р ( 45-2001-р ) від 14.02.2001 )

Про систему розрахунків за електричну енергію

( Із змінами, внесеними згідно з Розпорядженнями КМ N 449-р ( 449-2000-р ) від 14.11.2000 N 453-р ( 453-2000-р ) від 16.11.2000 )

1. Погодитися з пропозицією Мінпаливенерго щодо запровадження на період до 1 квітня 2001 р. системи розрахунків у грошовій формі за спожиту електричну енергію через окремі розподільчі рахунки між енергопостачальними компаніями, державним підприємством "Енергоринок" та:

підприємствами вугільної промисловості, що поставляють вугільну продукцію на електростанції, в рахунок оплати електростанціями отриманої вугільної продукції;

підприємствами НАК "Нафтогаз України", що видобувають та поставляють (транспортують) природний газ на електростанції, а також підприємствами хімічної промисловості, що проводять розрахунки відповідно до постанови Кабінету Міністрів України від 17 лютого 2000 р. N 340 ( 340-2000-п ) "Про механізм забезпечення сільськогосподарських товаровиробників мінеральними добривами у 2000 році" (Офіційний вісник України, 2000 р., N 7, ст. 284), у рахунок оплати електростанціями отриманого природного газу; ( Абзац третій пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 449-р ( 449-2000-р ) від 14.11.2000 )

виробниками електричної енергії, НЕК "Укренерго" в рахунок оплати за електричну енергію, спожиту на власні та господарські потреби; ( Пункт 1 доповнено абзацом четвертим згідно з Розпорядженням КМ N 449-р ( 449-2000-р ) від 14.11.2000 )

підприємствами, які надають послуги з водопостачання і водовідведення підприємствам вугільної промисловості та підприємствам і організаціям, що фінансуються з фонду ядерно-паливного циклу, в рахунок оплати цих послуг; ( Пункт 1 доповнено абзацом п'ятим згідно з Розпорядженням КМ N 449-р ( 449-2000-р ) від 14.11.2000 )

Севастопольським інститутом ядерної енергії та промисловості в обсягах власного споживання електричної енергії в рахунок оплати НАЕК "Енергоатом" підготовки спеціалістів для потреб атомно-енергетичного комплексу; ( Пункт 1 доповнено абзацом шостим згідно з Розпорядженням КМ N 449-р ( 449-2000-р ) від 14.11.2000 )

підприємствами Укрзалізниці, що надають послуги з перевезення вантажів та поставки палива на електростанції, в рахунок оплати електростанціями цих послуг;

підприємствами і організаціями, що фінансуються з фонду ядерно-паливного циклу в рахунок видатків цього фонду на фінансування заходів Комплексної програми створення ядерно-паливного циклу або оплати НАЕК "Енергоатом" послуг, що надаються відповідно до укладених договорів, у тому числі з поставки уранового концентрату;

підприємствами Укрзалізниці: в рахунок оплати НАК "Нафтогаз України" послуг з перевезення мінеральних добрив, отриманих Компанією на суму 6,2 млн. гривень; у рахунок оплати електростанціями енергетичного вугілля з державного резерву та проведення розрахунків Державним агентством з управління державним матеріальним резервом за отримане від Донецької залізниці енергетичне вугілля згідно з розпорядженням Кабінету Міністрів України від 27 жовтня 1999 р. N 1133 ( 1133-99-р ) на суму 42,3 млн. гривень; ( Пункт 1 доповнено абзацом дев'ятим згідно з Розпорядженням КМ N 449-р ( 449-2000-р ) від 14.11.2000 )

виробниками електричної енергії в рахунок оплати боргів, які виникли станом на 1 серпня 2000 р., за передачу електричної енергії споживачам місцевими (локальними) електромережами відповідного класу напруг; ( Пункт 1 доповнено абзацом десятим згідно з Розпорядженням КМ N 449-р ( 449-2000-р ) від 14.11.2000 )

підприємствами - споживачами електричної енергії, які мають непогашену заборгованість за спожиту електроенергію станом на 1 вересня 2000 р. та не погасили її на день проведення зазначених розрахунків, у рахунок оплати виробниками електричної енергії та НЕК "Укренерго" за отримані обладнання, матеріали, паливо, послуги, в тому числі з водопостачання, водовідведення і виконані роботи. Зазначені розрахунки проводяться до 15 грудня 2000 р. за умови відсутності поточної заборгованості цих підприємств за електричну енергію за вересень, жовтень, листопад ц. р.; ( Пункт 1 доповнено абзацом одинадцятим згідно з Розпорядженням КМ N 449-р ( 449-2000-р ) від 14.11.2000 )

підприємствами з надання комунальних послуг, що належать до сфери управління Мінпаливенерго, та працівниками підприємств вугільної промисловості у рахунок погашення заборгованості з виплати їм заробітної плати за рахунок боргу енергогенеруючих компаній за вугілля; ( Пункт 1 доповнено абзацом дванадцятим згідно з Розпорядженням КМ N 449-р ( 449-2000-р ) від 14.11.2000 )

підприємствами установ кримінально-виконавчої системи, що поставляють вугільну продукцію на електростанції, в рахунок оплати електростанціями отриманої вугільної продукції (в межах заборгованості за використану ними електричну енергію, що утворилася станом на 1 жовтня 2000 р. ( Пункт 1 доповнено абзацом згідно з Розпорядженням КМ N 453-р ( 453-2000-р ) від 16.11.2000 )

Дозволити проводити розрахунки, зазначені в абзацах другому - шостому цього пункту, у рахунок поточної оплати цими споживачами за використану ними електроенергію з урахуванням граничних рівнів споживання енергії. ( Пункт 1 доповнено абзацом згідно з Розпорядженням КМ N 449-р ( 449-2000-р ) від 14.11.2000 )

Розрахунки, зазначені в абзацах сьомому - дванадцятому, не враховуються під час визначення граничних рівнів споживання електричної енергії. ( Пункт 1 доповнено абзацом згідно з Розпорядженням КМ N 449-р ( 449-2000-р ) від 14.11.2000 )

2. Взяти до відома, що:

передбачені у пункті 1 цього розпорядження розрахунки проводяться за згодою сторін на підставі актів звірення та спільних протокольних рішень, підписаних усіма учасниками цих розрахунків, шляхом залучення споживачем електричної енергії кредитних банківських ресурсів або використання власних коштів. Умовою проведення таких розрахунків є те, що кожний учасник розрахунків у триденний термін після їх проведення згідно із законодавством здійснює відповідні обов'язкові платежі до бюджетів та до державних цільових фондів;

енергопостачальні компанії, державне підприємство "Енергоринок" відкривають окремі розподільчі рахунки в установах уповноваженого банку, який обслуговує розподільчі рахунки учасників оптового ринку електричної енергії України, для проведення зазначених розрахунків;

підприємства, які розраховуються за поточне споживання електричної енергії згідно з цим розпорядженням, не підлягатимуть відключенню від мережі електропостачання та обмеженню в її споживанні (за винятком аварійних ситуацій) у разі проведення розрахунків у визначений з енергопостачальною компанією день місяця, що настає за місяцем, в якому споживалася електрична енергія.

3. НКРЕ вирішити питання щодо встановлення порядку затвердження за поданням Мінпаливенерго спеціальних алгоритмів розподілу коштів для розрахунків, які провадитимуться згідно з цим розпорядженням.

4. Контроль за виконанням цього розпорядження покласти на Віце-прем'єр-міністра України Тимошенко Ю.В.

5. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 31 березня 2000 р. N 160 ( 160-2000-р ) (Офіційний вісник України, 2000 р., N 14, ст. 571).
