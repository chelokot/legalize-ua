Про соціальний захист громадян України, які працюють у Комісії з економічних питань при Економічній раді Співдружності Незалежних Держав та у Виконавчому комітеті Співдружності Незалежних Держав

Стан: Втратив чинність

Ідентифікатор: 588-2003-п

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 квітня 2003 р. N 588 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Про соціальний захист громадян України, які працюють у Комісії з економічних питань при Економічній раді Співдружності Незалежних Держав та у Виконавчому комітеті Співдружності Незалежних Держав

{ Із змінами, внесеними згідно з Постановами КМ N 896 ( 896-2006-п ) від 03.07.2006 N 703 ( 703-2013-п ) від 14.08.2013 }

Кабінет Міністрів України постановляє:

1. З метою забезпечення соціального захисту громадян України, які відряджені на роботу до Комісії з економічних питань при Економічній раді Співдружності Незалежних Держав (далі - Комісія) та за квотою України до Виконавчого комітету Співдружності Незалежних Держав (далі - Комітет), установити, що:

а) час роботи у Комісії чи Комітеті зараховується до стажу державної служби; { Підпункт "а" пункту 1 в редакції Постанови КМ N 896 ( 896-2006-п ) від 03.07.2006 }

б) вони продовжують перебувати у кадрах державної служби органів, у яких вони працювали, і після закінчення роботи у Комісії чи Комітеті їм надається попередня посада, а у разі неможливості здійснення цього (ліквідація органу, скорочення посади тощо) - інша рівнозначна посада;

в) за ними зберігається право на медичне та санаторно-курортне обслуговування в закладах, де вони обслуговувалися до відрядження;

г) пенсія за віком, у тому числі на пільгових умовах, у разі інвалідності, втрати годувальника встановлюється і виплачується їм (або членам їх сімей) у порядку і відповідно до умов, установлених Законом України "Про державну службу" ( 3723-12 ), виходячи із заробітної плати на час призначення пенсії за посадою державного службовця, яку вони займали до відрядження у Комісію чи Комітет.

У разі ліквідації зазначеної посади державного службовця Міністерство праці та соціальної політики за погодженням з Головним управлінням державної служби та Міністерством фінансів вирішує питання щодо прирівняння ліквідованої посади до відповідної існуючої посади державного службовця.

{ Пункт 2 втратив чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

3. Дія цієї постанови поширюється також на громадян України, які були відряджені до Комісії та Комітету до набрання чинності цією постановою.
