Стан: Втратив чинність

Текст документа від 01.04.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 січня 1993 р. N 38 Київ

Про умови оплати праці працівників органів прокуратури

( Із змінами, внесеними згідно з Постановами КМ N 827 ( 827-93-п ) від 01.10.93 N 955 ( 955-93-п ) від 24.11.93 N 390 ( 390-95-п ) від 05.06.95 N 488 ( 488-95-п ) від 04.07.95 )

( Додатково див. Постанову КМ N 1043 ( 1043-95-п ) від 25.12.95 )

( Із змінами, внесеними згідно з Постановою КМ N 399 ( 399-96-п ) від 03.04.96 )

З метою упорядкування оплати праці працівників органів прокуратури Кабінет Міністрів України постановляє:

1. Затвердити шкали співвідношень посадових окладів працівників органів прокуратури до мінімального розміру заробітної плати згідно з таблицями N 1 - 5.

2. Надати право Генеральному прокуророві України, прокурорам Республіки Крим, областей, м.Києва і прирівняним до них прокурорам у межах установлених фондів оплати праці та граничної чисельності працюючих:

а) вносити до затверджених структур апарату органів прокуратури зміни, викликані необхідністю застосування нових прогресивних організаційних форм, затверджувати штати, встановлювати керівникам підрозділів, спеціалістам і службовцям посадові оклади відповідно до зазначених шкал співвідношень посадових окладів;

б) установлювати:

заступникам керівників структурних підрозділів, не передбаченим цією постановою, посадові оклади на 2 - 7 відсотків нижчі за посадовий оклад відповідного керівника;

посадові оклади для окремих керівників і спеціалістів, не передбачених цією постановою, стосовно розмірів окладів, визначених на основі шкал співвідношень відповідних категорій працівників;

надбавки за високі досягнення у праці або за виконання особливо важливої роботи керівникам підрозділів, спеціалістам і службовцям у розмірі до 50 відсотків посадового окладу. У разі несвоєчасного виконання завдань, погіршення якості роботи і порушення трудової дисципліни ці надбавки скасовуються або зменшуються;

доплати прокурорсько-слідчим працівникам за сумісництво на вакантних посадах за місцем постійної роботи понад установлений робочий час у межах не більше 4 годин у робочий день чи повного робочого дня у вихідний з оплатою за фактично виконану роботу, але не більш як 50 відсотків посадового окладу;

доплати прокурорсько-слідчим працівникам, службовцям і робітникам (за винятком заступників прокурорів, керівників підрозділів та їхніх заступників) за виконання обов'язків тимчасово відсутніх працівників цих же категорій персоналу (у разі хвороби, відпустки без збереження заробітної плати, з інших причин) у розмірі до 50 відсотків посадового окладу за основною роботою, використовуючи для цього до 50 відсотків посадового окладу відсутнього працівника. Доплати за виконання обов'язків тимчасово відсутніх жінок, які перебувають у відпустці, пов'язаній з вагітністю і пологами, а також осіб, які перебувають у частково оплачуваній відпустці по догляду за дитиною до досягнення нею віку трьох років чи у відпустці без збереження заробітної плати, тривалістю, визначеною у медичному висновку, але не більше як до досягнення дитиною шестирічного віку, установлювати у розмірі до 30 відсотків посадового окладу за основною роботою, використовуючи для цієї мети всю економію заробітної плати на посадах, що займають відсутні з цих причин працівники;

в) преміювати працівників прокуратури відповідно до їхнього особистого вкладу в загальні результати роботи, спрямовуючи для цієї мети кошти у розмірі 4-місячного фонду заробітної плати;

г) надавати працівникам матеріальну допомогу, спрямовуючи для цього кошти у розмірі середньомісячного заробітку. ( Абзац перший підпункту "г" пункту 2 із змінами, внесеними згідно з Постановою КМ N 488 ( 488-95-п ) від 04.07.95 )

Преміювання прокурорів Республіки Крим, областей, м. Києва та встановлення надбавок до посадових окладів здійснюються Генеральним прокурором України в межах наявних коштів на оплату праці.

3. Виплачувати:

( Абзац другий пункту 3 втратив чинність на підставі Постанови КМ N 827 ( 827-93-п ) від 01.10.93 )

щомісячну надбавку за вислугу років працівникам органів прокуратури згідно з Указом Президента України від 20 грудня 1991 р. "Про розміри надбавок до посадових окладів за класні чини та вислугу років працівникам органів прокуратури України" ( 11/91 );

( Абзац четвертий пункту 3 втратив чинність на підставі Постанови КМ N 390 ( 390-95-п ) від 05.06.95 )

( Абзац п'ятий пункту 3 втратив чинність на підставі Постанови КМ N 399 ( 399-96-п ) від 03.04.96 )

4. Групи за оплатою праці працівників органів прокуратури областей, міст установлюються відповідно до показників, затверджених постановою Кабінету Міністрів України від 10 червня 1992 р. N 320 ( 320-92-п ) "Про віднесення областей та міст до груп за оплатою праці".

5. Ця постанова вводиться в дію з 1 січня 1993 року.
