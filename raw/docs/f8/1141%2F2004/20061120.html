Президент України; Указ від 28.09.2004 № 1141/2004

Питання представництва України у Міжнародному Суді ООН під час розгляду справи про делімітацію континентального шельфу та виключних економічних зон України та Румунії в Чорному морі

Стан: Чинний

Ідентифікатор: 1141/2004

Текст документа від 20.11.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання представництва України у Міжнародному Суді ООН під час розгляду справи про делімітацію континентального шельфу та виключних економічних зон України та Румунії в Чорному морі

( Із змінами, внесеними згідно з Указами Президента N 1524/2005 ( 1524/2005 ) від 01.11.2005 N 1816/2005 ( 1816/2005 ) від 22.12.2005 N 983/2006 ( 983/2006 ) від 20.11.2006 )

У зв'язку з розглядом Міжнародним Судом ООН справи про делімітацію континентального шельфу та виключних економічних зон України та Румунії в Чорному морі постановляю:

1. Визначити Міністерство закордонних справ України відповідальним органом, який здійснює координацію діяльності щодо захисту прав та інтересів України в Міжнародному Суді ООН.

2. Призначити ВАСИЛЕНКА Володимира Андрійовича - першого заступника Міністра закордонних справ України - Уповноваженим (агентом) України у справі про делімітацію континентального шельфу та виключних економічних зон України та Румунії в Чорному морі, КУПЧИШИНА Олександра Михайловича - Надзвичайного і Повноважного Посла України в Королівстві Нідерланди та КРОХМАЛЯ Володимира Георгійовича - начальника Договірно-правового управління Міністерства закордонних справ України - заступниками Уповноваженого України.

( Стаття 2 із змінами, внесеними згідно з Указами Президента N 1524/2005 ( 1524/2005 ) від 01.11.2005, N 1816/2005 ( 1816/2005 ) від 22.12.2005, N 983/2006 ( 983/2006 ) від 20.11.2006 )

Президент України Л.КУЧМА

м. Київ, 28 вересня 2004 року N 1141/2004
