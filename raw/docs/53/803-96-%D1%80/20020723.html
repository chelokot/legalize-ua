Про митне оформлення імпортних товарів і комплектуючих виробів

Стан: Втратив чинність

Ідентифікатор: 803-96-р

Текст документа від 23.07.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 грудня 1996 р. N 803-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1037 ( 1037-2002-п ) від 23.07.2002 )

Дозволити Держмиткому починаючи з моменту набрання чинності постановою Кабінету Міністрів України від 2 серпня 1996 р. N 907 ( 907-96-п ) здійснювати митне оформлення імпортних товарів і комплектуючих виробів, що ввозяться акціонерним товариством "НОРД" (м. Донецьк) для власного використання, за переліком згідно з додатком без стягнення податку на добавлену вартість.
