1. Затвердити Положення про порядок проведення Головдержслужбою перевірок (додається).

2. Контрольно-інспекційному управлінню Головдержслужби (Алмазов Е.О.) забезпечити в установленому порядку реєстрацію Положення про порядок проведення Головдержслужбою перевірок у Міністерстві юстиції України.

3. Науково-аналітичному управлінню Головдержслужби (Сороко В.М.) після реєстрації в Міністерстві юстиції України наказу Головдержслужби та Положення, забезпечити опублікування їх у "Віснику державної служби України" та розміщення на Web-сторінці Головдержслужби.

4. Контроль за виконанням цього наказу покладаю на заступників Начальника Головдержслужби за розподілом обов'язків.

Києві та Севастополі" і від 30.06.2006 N 886 ( 886-2006-п ) "Про затвердження Порядку проведення перевірки робочими групами центральних органів виконавчої влади", від 26.09.2007 N 1180 ( 1180-2007-п ) "Про затвердження Положення про Головне управління державної служби України", визначає завдання і порядок проведення Головдержслужбою та територіальними органами державної служби Головдержслужби (далі - територіальні органи) перевірок додержання вимог Законів України "Про державну службу", "Про засади запобігання та протидії корупції" ( 1506-17 ) та інших актів законодавства з питань державної служби в державних органах. { Пункт 1.1 із змінами, внесеними згідно з Наказами Головного управління державної служби N 35 ( z0311-04 ) від 23.02.2004, N 223 ( z1157-05 ) від 15.09.2005, N 247 ( z1148-07 ) від 17.09.2007, N 235 ( z0888-09 ) від 01.09.2009 }

Києві та Севастополі", від 26.09.2007 N 1180 ( 1180-2007-п ) "Про затвердження Положення про Головне управління державної служби України", іншими актами чинного законодавства.

2. Предмет, об'єкти та суб'єкти перевірок

2.1. Предметом перевірок є:

нормативно-правові, адміністративні, розпорядчі, інші документи (постанови, рішення, розпорядження, накази, положення, порядки, стандарти, інструкції, вказівки, інструктивні листи тощо), що охоплюють діяльність державних органів щодо створення правових, організаційних, економічних та соціальних умов реалізації громадянами України права на державну службу, а також з питань організації дотримання вимог Закону України "Про засади запобігання та протидії корупції" ( 1506-17 ). ( Абзац другий пункту 2.1 із змінами, внесеними згідно з Наказом Головного управління державної служби N 35 ( z0311-04 ) від 23.02.2004 )

2.2. Об'єктами перевірок є органи державної влади. ( Пункт 2.2 в редакції Наказу Головного управління державної служби N 35 ( z0311-04 ) від 23.02.2004 )

2.3. Суб'єктами перевірок є:

посадові особи Головдержслужби та територіальних органів відповідно до покладених на них завдань, особи, залучені Головдержслужбою або територіальними органами відповідно до покладених на них завдань до проведення перевірки як спеціалісти або експерти з інших установ та організацій, у тому числі контрольних, податкових, митних чи правоохоронних органів. ( Пункт 2.3 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

2.4. Права, обов'язки та відповідальність суб'єктів перевірок:

2.4.1. Права, обов'язки та відповідальність посадових осіб Головдержслужби, територіальних органів, уповноважених проводити перевірку і залучених до перевірки вчених, спеціалістів центральних і місцевих органів виконавчої влади, державних підприємств, установ та організацій, випливають з Конституції України ( 254к/96-ВР ), Законів України "Про державну службу" ( 3723-12 ), "Про засади запобігання та протидії корупції" ( 1506-17 ), інших актів чинного законодавства України.

Посадові особи Головдержслужби, територіальних органів, які уповноважені проводити перевірку, мають право: ( Абзац другий підпункту 2.4.1 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

а) отримувати та ознайомлюватися в установленому порядку з інформацією та документацією щодо правових, організаційно-розпорядчих, фінансово-економічних підстав та обгрунтувань підготовки, розгляду, прийняття та видання нормативно-правових, адміністративних, розпорядчих, інших актів та документів (постанов, рішень, розпоряджень, наказів, положень, інструкцій, стандартів, порядків, вказівок, інструктивних листів тощо) щодо дотримання Законів України "Про державну службу" ( 3723-12 ), "Про засади запобігання та протидії корупції" ( 1506-17 ), інших актів законодавства з питань державної служби;

б) отримувати від посадових осіб об'єкта, на якому проводиться перевірка, необхідні довідки, інформацію, статистичні дані, іншу інформацію;

в) вимагати й отримувати від посадових осіб об'єкта перевірки усні та письмові пояснення з питань, що стосуються предмета перевірки;

г) ставити перед керівником, іншими посадовими особами об'єкта перевірки вимоги щодо невідкладного усунення виявлених порушень, які потребують негайного реагування, окремо зазначати про це в акті перевірки;

ґ) у разі потреби дослідити питання, які вимагають спеціальних знань, ставити перед керівництвом Головдержслужби, територіальних органів питання щодо залучення до перевірки на будь-якій стадії спеціалістів чи експертів; ( Підпункт "і" абзацу 2 підпункту 2.4.1 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

( Підпункт 2.4.1 із змінами, внесеними згідно з Наказами Головного управління державної служби N 35 ( z0311-04 ) від 23.02.2004, N 223 ( z1157-05 ) від 15.09.2005 )

2.4.2. Посадові особи, уповноважені проводити перевірки від імені Головдержслужби, територіальних органів відповідно до покладених на них завдань, зобов'язані:

а) суворо дотримуватися вимог Конституції України ( 254к/96-ВР ), Законів України "Про державну службу" ( 3723-12 ), "Про засади запобігання та протидії корупції" ( 1506-17 ), інших актів чинного законодавства;

б) проводити перевірку відповідно до затвердженої програми та планів проведення названого заходу;

в) суворо дотримуватися принципів законності, повноти, об'єктивності, достовірності та доказовості результатів перевірки;

г) не втручатися в оперативну діяльність об'єкта перевірки, без потреби не оприлюднювати своїх висновків до завершення перевірки;

ґ) виявлені під час перевірки факти порушень, обставини та причини їх скоєння відображати в довідці перевірки з наведенням відповідних документів, письмових та усних пояснень посадових осіб та інших обгрунтувань виявлених фактів; долучати документи, пояснення та інші обгрунтування до довідок перевірок;

д) у всіх випадках виявлених підробок, зловживань та інших правопорушень отримувати від посадових осіб об'єкта перевірки детальні письмові пояснення щодо обставин, мотивів, причин та умов учинення порушень, долучати їх до матеріалів перевірки;

е) на будь-якій стадії перевірки приймати від посадових осіб об'єкта перевірки подані за їх ініціативою усні та письмові заяви, зауваження, пояснення щодо предмета перевірки та при потребі проводити перевірку порушених у зазначених зверненнях питань;

є) за результатами перевірки складати довідку перевірки, ознайомлювати керівництво об'єкта про встановлені факти порушення та доповідати керівництву Головдержслужби;

ж) у разі відмови від підписання керівником або іншою відповідальною особою довідки перевірки робити в довідці перевірки спеціальний запис про це з обов'язковим зазначенням дати, часу, обставин звернення до керівника чи іншої посадової особи з пропозицією ознайомитися і підписати довідку перевірки, а також дати, часу і обставин отримання відмови чи періоду, протягом якого не отримано відповіді від посадової особи;

з) у разі незгоди керівника чи іншої посадової особи об'єкта перевірки з фактами, викладеними в довідці перевірки, запропонувати подати протягом трьох робочих днів письмові зауваження, які додати до довідки перевірки;

і) у всіх випадках відмови посадових осіб об'єкта перевірки допустити осіб, які здійснюють перевірку, до проведення перевірки, надання їм необхідної інформації, документації чи можливості проведення перевірки складати акт про відмову виконувати вказані вимоги із зазначенням дати, часу, місця, даних посадової особи, яка допустила протиправні дії. Невідкладно доповідати про це керівництву Головдержслужби, вжити заходів щодо усунення перешкод для здійснення перевірки.

( Підпункт 2.4.2 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

2.4.3. У разі невиконання або неналежного виконання обов'язків, необ'єктивного, недбалого, упередженого, поверхового проведення перевірки, викладення в довідці перевірки недостовірних або недоведених фактів та обгрунтувань їх скоєння посадова особа, яка проводила перевірку, притягується до відповідальності на підставі, у межах та в спосіб, що передбачені чинним законодавством.

2.5. Права, обов'язки і відповідальність посадових осіб об'єктів перевірки випливають з вимог Конституції України ( 254к/96-ВР ), Закону України "Про державну службу" ( 3723-12 ), інших актів чинного законодавства України.

2.5.1. Посадові особи об'єкта перевірки мають право:

а) вимагати від посадових осіб, уповноважених проводити перевірку, пред'являти доручення на проведення перевірки;

б) на будь-якій стадії перевірки подавати особам, які здійснюють перевірку, усні та письмові заяви, зауваження, пояснення з питань щодо предмета перевірки;

в) відмовлятися від надання пояснень особі, яка проводить перевірку, якщо питання, на які пропонується відповісти, торкаються державної таємниці, розголошувати яку посадова особа об'єкта перевірки не уповноважена;

г) вимагати від осіб, які здійснювали перевірку, після закінчення перевірки надати змогу ознайомитись з результатами перевірки;

ґ) подавати письмові зауваження до результатів перевірки в разі незгоди з викладеними фактами та вимагати їх розгляду особами, які здійснювали перевірку, по суті з доданням їх у вигляді додатка як невід'ємної частини довідки;

д) оскаржувати дії осіб, що здійснювали перевірку, безпосередньо у керівника робочої групи, відповідального за проведення перевірки, чи керівництва Головдержслужби і вимагати отримання від них офіційної письмової відповіді;

е) мають інші права, передбачені Конституцією України ( 254к/96-ВР ) та чинним законодавством України.

2.5.2. Посадові особи об'єкта перевірки зобов'язані:

а) допускати посадових осіб, уповноважених проводити перевірку, до перевірки за наявності відповідного доручення на її проведення;

б) забезпечувати особам, які здійснюють перевірку, умови, потрібні для ефективного проведення перевірки;

в) надавати з дотриманням вимог законодавства про державну таємницю на вимогу осіб, які здійснюють перевірку, всю без винятку інформацію, документи та матеріали, у тому числі архівні, щодо діяльності посадових осіб та колегіальних органів об'єкта перевірки про підготовку, розгляд, прийняття нормативно-правових документів, адміністративних, розпорядчих та інших актів (постанов, рішень, розпоряджень, наказів, положень, інструкцій, стандартів, порядків тощо) щодо дотримання Законів України "Про державну службу" ( 3723-12 ), "Про засади запобігання та протидії корупції" ( 1506-17 ), інших актів законодавства з питань державної служби;

г) надавати інші інформаційні матеріали щодо предмета перевірки (довідки, інформаційні бюлетені, статистичні дані, декларації тощо);

ґ) надавати копії та виписки з документів, завіряти своїм підписом їх достовірність;

д) сприяти особам, які здійснюють перевірку, у проведенні ними в разі потреби обстежень та огляду документів, матеріалів, підписувати за результатами перевірки довідку;

е) давати усні та письмові пояснення з питань щодо предмета перевірки, підтверджувати довідку перевірки. У разі незгоди з викладеними в ньому фактами та доказами окремо про це зазначати;

є) уживати невідкладних заходів щодо усунення виявлених в ході перевірки правопорушень, відшкодування завданої шкоди та притягнення до відповідальності осіб, винних у скоєнні правопорушень.

2.5.3. Посадові особи об'єкта перевірки притягуються до відповідальності на підставі, у межах та в спосіб, що передбачені чинним законодавством.

3. Мета та основні завдання перевірок

3.1. Метою перевірки є:

установлення на об'єкті перевірки фактичного стану справ щодо дотримання єдиної державної політики у сфері державної служби, підвищення її ефективності, дотримання державними органами правових, організаційних, економічних та соціальних умов реалізації громадянами України права на державну службу; ( Абзац другий пункту 3.1 із змінами, внесеними згідно з Наказом Головного управління державної служби N 35 ( z0311-04 ) від 23.02.2004 )

установлення на об'єкті перевірки фактичного стану справ щодо виконання законодавчих та інших нормативно-правових актів з питань запобігання та протидії корупції в органах державної влади; { Абзац третій пункту 3.1 із змінами, внесеними згідно з Наказами Головного управління державної служби N 35 ( z0311-04 ) від 23.02.2004, N 235 ( z0888-09 ) від 01.09.2009 }

вироблення та надання об'єкту перевірки на підставі аналізу матеріалів перевірки практичних рекомендацій щодо підвищення ефективності діяльності з питань, що перевірялися, усунення виявлених недоліків та запобігання їм у майбутньому.

3.2. Основними завданнями при проведенні перевірок є:

перевірка дотримання державними органами Конституції України ( 254к/96-ВР ), вимог актів законодавства з питань державної служби; ( Абзац другий пункту 3.2 із змінами, внесеними згідно з Наказом Головного управління державної служби N 35 ( z0311-04 ) від 23.02.2004 )

перевірка виконання вимог антикорупційного законодавства України органами виконавчої влади; ( Абзац третій пункту 3.2 із змінами, внесеними згідно з Наказом Головного управління державної служби N 35 ( z0311-04 ) від 23.02.2004 )

перевірка результативності та ефективності вжитих заходів щодо виконання вимог Законів України "Про державну службу" ( 3723-12 ), "Про засади запобігання та протидії корупції" ( 1506-17 ), інших нормативно-правових актів на виконання зазначених законів;

перевірка стану впровадження та функціонування підсистеми обліку державних службовців I-VII категорій "Картка" в органах, де працюють державні службовці. ( Пункт 3.2 доповнено абзацом згідно з Наказом Головдержслужби N 129 ( z1007-04 ) від 04.08.2004, із змінами, внесеними згідно з Наказом Головного управління державної служби N 10 ( z0117-06 ) від 25.01.2006 )

4. Планування та порядок проведення перевірок

4.1. Перевірки Головдержслужбою, її територіальними органами відповідно до покладених на них завдань проводяться планово та позапланово. ( Підпункт 4.1 пункту 4 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

4.2. Планові перевірки проводяться на підставі планів роботи Головдержслужби, її територіальними органами відповідно до покладених на них завдань. Позапланові перевірки проводяться за окремим рішенням Начальника Головдержслужби та відповідно до покладених завдань на територіальні органи, за рішенням начальника територіального органу. ( Підпункт 4.2 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

4.3. Підготовка до проведення перевірки:

4.3.1. Обов'язковою умовою проведення перевірки є наявність затвердженої програми перевірки. Проект програми розробляється у підрозділі, відповідальному за проведення перевірки, на підставі планів робіт або відповідного рішення Начальника Головдержслужби, начальника територіального органу про проведення позапланових контрольних заходів. ( Підпункт 4.3.1 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

4.3.2. Перед складанням програми перевірки підрозділ, відповідальний за її проведення, аналізує:

нормативно-правову базу, що стосується об'єкта перевірки;

інформаційно-аналітичні дані, що надходили до Головдержслужби, територіальних органів від органу, у якому передбачено проведення перевірки; ( Абзац третій підпункту 4.3.2 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

інформацію, отриману від контрольних та правоохоронних органів щодо раніше проведених перевірок в органі, у якому передбачено проведення перевірки.

4.3.3. Програма перевірки складається у відповідності з чинним законодавством з урахуванням внутрішніх нормативних документів Головдержслужби та територіальних органів відповідно до покладених на них завдань та визначає:

мету проведення перевірки;

її предмет;

перелік об'єктів перевірки;

орієнтовний перелік питань, що підлягають перевірці, з урахуванням особливостей предмета і повноважень суб'єктів перевірки (може уточнюватись та доповнюватись у ході проведення перевірки); { Абзац п'ятий підпункту 4.3.3 пункту 4 в редакції Наказу Головного управління державної служби N 247 ( z1148-07 ) від 17.09.2007 }

терміни проведення перевірки;

перелік базових нормативно-правових актів, що регулюють предмет перевірки та питання, на які слід звернути увагу в ході проведення перевірки;

склад робочої групи.

Термін перевірки, склад робочої групи визначається з урахуванням обсягу та особливостей проведення перевірки, але, як правило, не більше 10 днів (цільова перевірка - до п'яти днів). Термін перевірки може бути продовжений Начальником Головдержслужби, начальником територіального органу на підставі доповідної записки керівника відповідного структурного підрозділу Головдержслужби, начальником територіального органу, відповідального за проведення перевірки. ( Абзац дев'ятий підпункту 4.3.3 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

У разі потреби до складу робочої групи можуть бути залучені вчені, спеціалісти центральних і місцевих органів виконавчої влади, державних підприємств, установ та організацій (за погодженням з їх керівниками) для розгляду питань, що належать до їх компетенції. ( Абзац десятий підпункту 4.3.3 із змінами, внесеними згідно з Наказом Головного управління державної служби N 35 ( z0311-04 ) від 23.02.2004 )

( Підпункт 4.3.3 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

4.3.4. Програма перевірки затверджується Начальником Головдержслужби, начальником територіального органу або заступником Начальника, який за функціональними обов'язками здійснює кураторство підрозділу, відповідального за проведення перевірки. ( Підпункт 4.3.4 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

4.3.5. Перед початком перевірки керівником робочої групи оформляється доручення на проведення перевірки, у якому зазначається прізвище, ім'я, по батькові керівника робочої групи та посадових осіб, які здійснюють перевірку, підстава проведення перевірки, об'єкт перевірки, термін проведення перевірки.

Доручення на проведення перевірки та програма перевірки доводяться до суб'єктів перевірки перед початком її проведення. { Підпункт 4.3.5 пункту 4 доповнено абзацом другим згідно з Наказом Головного управління державної служби N 247 ( z1148-07 ) від 17.09.2007 }

4.3.6. Керівник робочої групи має право:

у разі потреби за поданням співвиконавців або в разі неналежного виконання ними завдань уносити пропозиції Начальнику Головдержслужби, начальнику територіального органу щодо змін складу робочої групи з повідомленням про це керівництва об'єкта перевірки;

подавати Начальнику Головдержслужби, начальнику територіального органу інформацію про неналежне виконання завдань, визначених у програмі перевірки, членами робочої групи;

отримувати інформацію від експертів, інших спеціалістів державних установ, які не були залучені як співвиконавці до перевірки.

{ Пункт 4 доповнено підпунктом 4.3.6 згідно з Наказом Головного управління державної служби N 247 ( z1148-07 ) від 17.09.2007 }

4.4. Проведення перевірки.

4.4.1. Перед початком перевірки заступник начальника Головдержслужби, начальник територіального органу або за його дорученням начальник управління (відділу), заступник начальника територіального органу проводить інструктаж з працівниками, які здійснюють перевірку, та заздалегідь попереджає керівника державного органу про дату та мету перевірки, погоджує порядок підбиття підсумків перевірки. ( Підпункт 4.4.1 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

4.4.2. Керівник робочої групи забезпечує збір необхідної інформації про об'єкт перевірки, вивчає умови роботи та особливості діяльності об'єкта перевірки, здійснює інші дії щодо організації та створення умов для проведення перевірки.

4.4.3. Заступник Начальника Головдержслужби, начальник територіального управління або начальник управління чи посадова особа територіального органу, які відповідають за перевірку, контролюють хід її проведення і в разі потреби дають керівнику робочої групи доручення, обов'язкові для виконання. ( Підпункт 4.4.3 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

4.5. Оформлення результатів проведення перевірок.

4.5.1. Про попередні підсумки перевірки державного органу його керівників інформує керівник робочої групи або інша посадова особа, визначена Начальником Головдержслужби, начальником територіального органу. За результатами перевірки складається довідка перевірки, яка підписується всіма членами робочої групи.

Працівники, залучені до проведення перевірки, складають і подають керівникові робочої групи довідку за результатами перевірки питань, віднесених до їх компетенції, з відповідними висновками та пропозиціями (на паперовому та електронному носіях). { Підпункт 4.5.1 пункту 4 доповнено абзацом другим згідно з Наказом Головного управління державної служби N 247 ( z1148-07 ) від 17.09.2007 }

( Підпункт 4.5.1 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

4.5.2. Довідка перевірки опрацьовується працівниками Головдержслужби, протягом п'яти робочих днів після закінчення терміну перевірки. Вона має розкривати визначені програмою перевірки питання, містити перелік усіх без винятку встановлених фактів порушень чинного законодавства з питань дотримання вимог Законів України "Про державну службу" ( 3723-12 ), "Про засади запобігання та протидії корупції" ( 1506-17 ), прізвища та посади конкретних осіб, відповідальних за скоєння правопорушення, висновки та пропозиції. У разі потреби заступник Начальника Головдержслужби, посадова особа територіального органу за погодженням з Начальником Головдержслужби, начальником територіального органу може подовжити термін підготовки довідки перевірки, але не більше двох тижнів.

{ Підпункт 4.5.2 із змінами, внесеними згідно з Наказами Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005, N 247 ( z1148-07 ) від 17.09.2007 }

4.5.3. При оформленні результатів перевірки повинна додержуватися об'єктивність, достовірність, обгрунтованість, ясність і вичерпність опису виявлених фактів і даних.

4.5.4. Якщо в ході проведення перевірки виявлені порушення, що безпосередньо пов'язані з порушеннями вимог Закону України "Про засади запобігання та протидії корупції" ( 1506-17 ), то керівник групи повідомляє про це керівництво Головдержслужби та спеціально уповноважені суб'єкти у сфері протидії корупції.

{ Підпункт 4.5.4 пункту 4.5 розділу 4 із змінами, внесеними згідно з Наказом Головного управління державної служби N 235 ( z0888-09 ) від 01.09.2009 }

5. Реалізація матеріалів перевірок, контроль за усуненням виявлених у ході перевірок порушень

5.1. Рішення про реалізацію матеріалів перевірки в залежності від установлених порушень приймає Начальник Головдержслужби, начальник територіального органу відповідно до покладених на нього завдань. ( Підпункт 5.1 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

5.2. У разі виявлення під час проведення перевірок фактів порушення Законів України "Про державну службу" ( 3723-12 ), "Про засади запобігання та протидії корупції" ( 1506-17 ), інших законодавчих та нормативно-правових актів з питань державної служби та запобігання та протидії корупції Головдержслужба, територіальні органи відповідно до покладених на них завдань вносять в установленому порядку пропозиції про скасування рішень, прийнятих усупереч законодавству, а також пропозиції щодо усунення виявлених недоліків та притягнення до відповідальності винних посадових осіб.

{ Пункт 5.2 із змінами, внесеними згідно з Наказами Головного управління державної служби N 35 ( z0311-04 ) від 23.02.2004, N 223 ( z1157-05 ) від 15.09.2005, N 235 ( z0888-09 ) від 01.09.2009 }

5.3. Реалізацію прийнятих рішень та рекомендацій щодо усунення виявлених порушень та недоліків здійснює і контролює управління (відділ) Головдержслужби або відділи територіальних органів, які були відповідальними за перевірку, якщо інше не передбачено постановою колегії Головдержслужби, дорученням начальника територіального органу, якщо інше не було передбачено постановою колегії Головдержслужби, дорученням Начальника (заступника Начальника) Головдержслужби. ( Пункт 5.3 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )

5.4. На підставі аналізу інформації (лист-повідомлення до Головдержслужби про усунення недоліків тощо), що надійшла з об'єкта перевірки щодо усунення виявлених під час перевірки порушень керівник відповідного структурного підрозділу, який здійснював перевірку, готує доповідну записку з пропозиціями щодо зняття питання з контролю (якщо вжито вичерпних заходів).

5.5. У разі невиконання об'єктом перевірки в установлені терміни заходів до усунення виявлених в процесі перевірки порушень (лист-повідомлення до Головдержслужби про усунення недоліків), підрозділ, який здійснював перевірку, може внести пропозицію, звернутися до вищих органів або органів прокуратури з пропозиціями усунути порушення закону, поновити порушені права і притягти в установленому законом порядку до відповідальності осіб, які допустили ці порушення, або щодо проведення повторної перевірки органу, що перевірявся. { Підпункт 5.5 пункту 5 із змінами, внесеними згідно з Наказом Головного управління державної служби N 247 ( z1148-07 ) від 17.09.2007 }

5.6. У разі здійснення повторної перевірки готуються і подаються керівництву Головдержслужби на розгляд доповідна записка з висновками щодо стану справ в органі, у якому проведено таку перевірку.

5.7. Матеріали перевірок використовуються при підготовці відповідної інформації Секретаріату Президента України, Кабінету Міністрів України, керівництву Головдержслужби, при підготовці річних звітів та при наступній перевірці.

{ Пункт 5.7 розділу 5 із змінами, внесеними згідно з Наказом Головного управління державної служби N 235 ( z0888-09 ) від 01.09.2009 }

5.8. Оформлені матеріали перевірок та додатки до них зберігаються у підрозділі, що здійснював перевірку.

5.9. Контроль за реалізацією рішень Головдержслужби, територіальних органів відповідно до покладених на них завдань щодо проведення контрольних заходів здійснює заступник Начальника Головдержслужби, заступник начальника територіального органу, на якого відповідно до розподілу обов'язків покладено питання контролю за роботою контрольно-інспекційного управління. ( Пункт 5.9 із змінами, внесеними згідно з Наказом Головного управління державної служби N 223 ( z1157-05 ) від 15.09.2005 )
