ІНСТРУКЦІЯ

про порядок обчислення і сплати платежів за спеціальне використання надр при видобуванні корисних копалин

( Зі змінами, внесеними згідно з Наказами N 65/81/69 ( z0170-94 ) від 15.07.94 N 47/39/86 ( z0185-95 ) від 5.06.95)

I. Загальні положення

1. Інструкцію про порядок обчислення і сплати платежів за спеціальне використання надр при видобуванні корисних копалин (надалі - Інструкція) розроблено на підставі Кодексу України про надра ( 132/94-ВР ), Закону України "Про охорону навколишнього природного середовища" ( 1264-12 ), Закону України "Про підприємництво" ( 698-12 ) та постанов Кабінету Міністрів України від 8 лютого 1994 року N 85 ( 85-94-п ) "Про затвердження Тимчасового порядку справляння плати за спеціальне використання надр при видобуванні корисних копалин" та від 12 грудня 1994 року N 827 ( 827-94-п ) "Про затвердження переліків корисних копалин загальнодержавного та місцевого значення". ( Пункт 1 в редакції Наказу ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95)

2. Інструкція обов'язкова для виконання суб'єктами підприємницької діяльності незалежно від форм власності та відомчого підпорядкування.

3. Інструкція передбачає порядок обчислення і сплати суб'єктами підприємницької діяльності плати за спеціальне використання надр при видобуванні корисних копалин до бюджетів, а також відповідальність платників за достовірність даних про обсяг погашених запасів (видобутку) корисних копалин, правильність обчислення, повноту і своєчасність сплати цього платежу до бюджетів.

Інструкція визначає єдині на території України, її континентальному шельфі правила стягнення плати за спеціальне використання надр при видобуванні корисних копалин незалежно від їх якості, гірничогеологічних та інших умов розробки родовищ.

4. Внесення плати за спеціальне використання надр при видобуванні корисних копалин не звільняє суб'єктів підприємницької діяльності від сплати відрахувань за геологорозвідувальні роботи, виконані за рахунок державного бюджету , від сплати платежів за видачу ліцензій на право пошуку (розвідки) і розробки родовищ корисних копалин від сплати інших платежів, якщо інше не передбачено положеннями міжнародної угоди.

Плата за спеціальне використання надр при видобуванні корисних копалин не справляється за видобуті прісні підземні води. Плата за спеціальне використання прісних підземних вод справляється згідно з Порядком справляння плати за спеціальне використання прісних водних ресурсів, затвердженого постановою Кабінету Міністрів України від 8 лютого 1994 року N 75 ( 75-94-п ) "Про затвердження Порядку справляння плати за спеціальне використання прісних водних ресурсів і тимчасових нормативівплати за їх спеціальне використання. ( Пункт 4 із змінами, внесеними згідно з Наказом ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95)

5. Плата встановлюється за спеціальне використання надр при видобуванні корисних копалин загальнодержавного і місцевого значення.

Розподіл корисних копалин на корисні копалини загальнодержавного і місцевого значення визначено постановою Кабінету Міністрів України від 12 грудня 1994 року N 827 ( 827-94-п ) "Про затвердження переліків корисних копалин загальнодержавного та місцевого значення".

( Пункт 5 в редакції Наказів ГДПІ N 65/81/69 ( z0170-94 ) від 15.07.94, N 47/39/86 ( z0185-95 ) від 5.06.95)

II. Об'єкт справляння плати за спеціальне використання надр при видобуванні корисних копалин

6. Об'єктом справляння плати за спеціальне використання надр при видобуванні корисних копалин є обсяг погашених балансових запасів (для нафти, конденсату, газу, торфу та гідромінеральних ресурсів - обсяг видобутих) корисних копалин.

До погашених запасів належать як видобуті, так і залишені невидобутими із надр (втрачені) балансові запаси корисної копалини. До втрат корисних копалин у процесі видобування належать всі види втрат в надрах, які діляться на загальношахтні та експлуатаційні, де загальношахтні втрати - це втрати балансових запасів корисної копалини, які знаходяться в охоронних ціликах біля капітальних гірничих виробок, під будівлями, технічними спорудами, водоймищами, а експлуатаційні втрати - це втрати балансових запасів корисної копалини, які виникають безпосередньо у процесі її видобування (в т.ч. і втрати з геологічних умов).

( Абзац другий пункту 6 в редакції N 47/39/86 ( z0185-95 ) від 5.06.95 )

До гідромінеральних ресурсів, за які справляється плата за спеціальне використання надр при видобуванні корисних копалин, належать підземні мінеральні, промислові, термальні води, ропа, мінеральні грязі та мул. ( Абзац третій пункту 6 в редакції N 47/39/86 ( z0185-95 ) від 5.06.95 )

У разі розробки забалансових запасів корисних копалин вони повинні бути переведені на балансові. Порядок переведення визначається Державним комітетом по геології і використанню надр та Державним комітетом по нагляду за охороною праці.

III. Платники плати за спеціальне використання надр при видобуванні корисних копалин

7. Платниками плати за спеціальне використання надр при видобуванні корисних копалин є суб'єкти підприємницької діяльності незалежно від форм власності, включаючи підприємства з іноземними інвестиціями, які здійснюють видобуток корисних копалин. ( Пункт 7 із змінами, внесеними згідно з Наказом ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

8. Плату за спеціальне використання надр при видобуванні корисних копалин вносять:

- суб'єкт підприємницької діяльності, що видобуває та реалізує мінеральну сировину. При цьому не має значення природний вміст корисного компонента, хто отримує продукцію, характер наступної переробки та використання мінеральної сировини;

- суб'єкт підприємницької діяльності, до складу якого входить структурний підрозділ (шахта, рудник, кар'єр тощо), що займається видобутком корисних копалин і передає їх для подальшої переробки в його межах.

9. У випадку, якщо платник об'єднався на основі будь-якої форми з іншим підприємством і при цьому перестає функціонувати як самостійна юридична особа, то платником стає підприємство-правонаступник.

9.1. Від плати за спеціальне використання надр при видобуванні корисних копалин звільняються землевласники і землекористувачі, які здійснюють у встановленому порядку в межах наданих їм у власність або користування земельних ділянок видобуток корисних копалин місцевого значення для власних потреб.

Під встановленим порядком розуміється необхідність отримання користувачем надр спеціального дозволу (ліцензії) на користування ділянкою надр та гірничого відводу. Землевласники і землекористувачі в межах наданих їм земельних ділянок мають право без спеціальних дозволів (ліцензій) та гірничого відводу видобувати для своїх господарських і побутових потреб корисні копалини місцевого значення і торф загальною глибиною розробки до двох метрів.

Надра у користування для розробки родовищ торфу надаються без надання гірничого відводу на підставі спеціальних дозволів (ліцензій).

( Розділ III доповнено пунктом 9.1 згідно з Наказом ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

IV. Нормативи плати за спеціальне використання надр при видобуванні корисних копалин

10. Розмір плати за спеціальне використання надр при видобуванні корисних копалин обчислюється платниками самостійно виходячи з обсягу погашених балансових запасів (для нафти, газу, торфу, конденсату та гідромінеральних ресурсів - обсягу видобутку), ціни реалізації одиниці видобутої мінеральної сировини, нормативу плати та коригуючого коефіцієнта.

11. Для суб'єкта підприємницької діяльності встановлено єдиний норматив за кожну одиницю погашених (для нафти, торфу, конденсату, газу та гідромінеральних ресурсів - видобутих) балансових запасів корисних копалин в розмірі 1 відсотка ціни реалізації одиниці видобутої мінеральної сировини без врахування податку на добавлену вартість.

12. Для підприємства вугільної промисловості до нормативу плати застосовується коригуючий коефіцієнт 0,5.

13. Для суб'єкта підприємницької діяльності, до складу якого входить структурний підрозділ, що займається видобутком корисних копалин (шахта, рудник, кар'єр тощо) і передає їх для переробки в межах цього суб'єкта за собівартістю, при обчисленні плати за спеціальне використання надр при видобуванні корисних копалин, замість ціни, приймається собівартість у межах підрозділу (цеху), збільшена на коригуючий коефіцієнт 1,1.

V. Порядок обчислення і стягнення плати за спеціальне використання надр при видобуванні корисних копалин

14. Плата за спеціальне використання надр при видобуванні корисних копалин встановлюється і вноситься до бюджетів з 1 квітня 1994 року.

15. Плата обчислюється щоквартально виходячи з фактичного обсягу погашених балансових запасів (для нафти, торфу, конденсату, газу та гідромінеральних ресурсів - обсягу видобутих) корисних копалин та нормативів плати з врахуванням коригуючих коефіцієнтів.

Для визначення плати використовується державна статистична звітність і геолого-маркшейдерська документація підприємства.

Після закінчення першого кварталу, півріччя, 9 місяців і року, платник обчислює плату за спеціальне використання надр при видобуванні корисних копалин за наростаючим підсумком з початку року (додаток N 1) і щоквартально складає за встановленою формою (додатки N 2,3) розрахунок та подає його податковим органам за місцезнаходженням родовища корисних копалин не пізніше 15 числа місяця, наступного за звітним кварталом.

Суб'єкт підприємницької діяльності, зареєстрований у податковій інспекції іншого району (міста), ніж місцезнаходження родовища корисної копалини, подає копію розрахунку також у податкову інспекцію, де він зареєстрований, з відміткою податкової інспекції, яка прийняла оригінал розрахунку і копію платіжного документа. ( Пункт 15 доповнено абзацем згідно з Наказом ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

16. Якщо суб'єкт підприємницької діяльності одну частину видобутих корисних копалин реалізує, а другу - передає для переробки за собівартістю, обчислення плати за спеціальне використання надр при видобуванні корисних копалин здійснюється окремо. Загальна сума плати складається із сум, нарахованих за обсягом реалізації мінеральної сировини та обсягом передачі її за собівартістю (додаток N 1).

17. При розробці суб'єктом підприємницької діяльності більше одного виду мінеральної сировини, плата за спеціальне використання надр при видобуванні корисних копалин обчислюється за кожний вид окремо.

18. У разі видобування комплексних (багатокомпонентних) видів корисних копалин плата обчислюється як за один вид мінеральної сировини профілюючого компонента.

19. Фактична ціна одиниці реалізованої мінеральної сировини визначається шляхом ділення виручки, одержаної фактично від реалізації корисних копалин, на обсяг її реалізації за звітний період, а собівартість одиниці видобутої мінеральної сировини - собівартості мінеральної сировини на обсяг, що відповідає її собівартості.

20. Якщо суб'єкт підприємницької діяльності реалізує мінеральну сировину за іноземну валюту за межі України, її вартість перераховується в національну грошову одиницю України за курсом, встановленим Національним банком України, що діяв на дату реалізації продукції.

21. Підприємство, що одержує дотацію на компенсацію перевищення розрахункової ціни над ціною реалізації мінеральної сировини із бюджету, вносить плату за спеціальне використання надр при видобуванні корисних копалин виходячи з ціни реалізації.

22. Виробниче об'єднання, що вносить плату за спеціальне використання надр при видобуванні корисних копалин за включені до його складу гірничодобувні цехи (шахта, рудник, кар'єр тощо), складає розрахунки у розрізі виробничих одиниць.

23. Сплата платежу за спеціальне використання надр при видобуванні корисних копалин проводиться платниками щоквартально у 5-денний термін з дня, встановленого пунктом 15 цієї Інструкції для подання розрахунку.

24. Суми платежів за спеціальне використання надр при видобуванні корисних копалин надходять до державного бюджету, бюджетів Автономної Республіки Крим, областей, міст Києва і Севастополя.

( Пункт 24 із змінами, внесеними згідно з Наказом ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

25. Плата за спеціальне використання надр при видобуванні корисних копалин загальнодержавного значення в розмірі 40 відсотків перераховується платниками до державного бюджету і 60 відсотків - до бюджетів Автономної Республіки Крим, областей, міст Києва і Севастополя, за місцезнаходженням родовища корисних копалин, на розділ 16 Класифікації доходів і видатків Державного та місцевих бюджетів, затвердженої наказом Міністерства фінансів України від 16 липня 1992 року N 35 ( v0035201-92 ). Символ звітності банку Державного бюджету - 53.

Платежі за спеціальне використання надр при видобуванні корисних копалин місцевого значення перераховуються до бюджетів Автономної Республіки Крим, областей, міст Києва і Севастополя за місцезнаходженням родовища корисних копалин, на розділ 16 Класифікації доходів і видатків державного та місцевих бюджетів.

Платежі за спеціальне використання надр при видобуванні корисних копалин, що надходять до бюджетів Автономної Республіки Крим, областей, міст Києва і Севастополя, розподіляються між місцевими бюджетами різних рівнів відповідно Верховною Радою Автономної Республіки Крим, обласними, Київською і Севастопольською міськими Радами народних депутатів.

( Пункт 25 в редакції Наказу ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

26. Суми платежів за спеціальне використання надр при видобуванні корисних копалин вносяться до відповідних бюджетів з розрахункових рахунків платників. Сплачений платіж платником відноситься на витрати виробництва.

VI. Контроль за визначенням обсягу погашених запасів (видобутку) корисних копалин, станом їх обліку правильністю обчислення та своєчасністю сплати платежу за спеціальне використання надр при видобуванні корисних копалин

27. Державний комітет України по нагляду за охороною праці протягом місяця з моменту надання суб'єкту підприємницької діяльності гірничого відводу на експлуатацію родовищ корисних копалин загальнодержавного значення, а Верховна Рада Автономної Республіки Крим, обласна, Київська та Севастопольська міські Ради народних депутатів - місцевого значення повідомляють про це податкові органи за місцезнаходженням родовища корисних копалин. ( Пункт 27 із змінами, внесеними згідно з Наказом ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

28. Контроль за дотриманням умов користування надрами, що зазначені у ліцензії, здійснюється органами державного геологічного контролю Державного комітету по геології і використанню надр.

29. Контроль за правильністю визначення обсягів видобутку і погашення балансових запасів корисних копалин здійснюють органи Державного комітету по нагляду за охороною праці.

Органи Державного комітету по нагляду за охороною праці, якщо виникає потреба, направляють до податкових органів копії актів перевірок підприємств, установ, організацій з питань обсягів видобутку і погашення балансових запасів корисних копалин, а в окремих випадках беруть участь у перевірках повноти і своєчасності сплати платежів за спеціальне використання надр при видобуванні корисних копалин, що проводяться державними податковими органами.

30. Контроль за правильністю обчислення і своєчасністю сплати платежу за спеціальне використання надр при видобуванні корисних копалин здійснюється державними податковими інспекціями за місцезнаходженням родовища корисної копалини.

( Пункт 30 із змінами, внесеними згідно з Наказом ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

31. Документальна перевірка правильності обчислення і своєчасності перерахування до відповідних бюджетів плати за спеціальне використання надр при видобуванні корисних копалин здійснюється державною податковою інспекцією за місцезнаходженням родовища корисної копалини. При необхідності до перевірок залучаються органи Державного комітету по геології і використанню надр, Міністерства охорони навколишнього природного середовища та ядерної безпеки та Державного комітету по водному господарству.

( Пункт 31 із змінами, внесеними згідно з Наказом ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

32. Облік нарахованих і сплачених сум платежів за спеціальне використання надр при видобуванні корисних копалин державними податковими інспекціями ведеться відповідно до встановленого порядку ведення оперативно-бухгалтерського обліку.

33. Повернення та зарахування неправильно сплачених сум платежів за спеціальне використання надр при видобуванні корисних копалин проводиться із відповідних бюджетів за заявою платника.

VII. Відповідальність платників

34. Платники несуть відповідальність за повноту обчислення і своєчасну сплату платежів за спеціальне використання надр при видобуванні корисних копалин до бюджету, а також за правильне складання і своєчасне подання розрахунків державним податковим інспекціям.

35. Державні податкові інспекції мають право застосовувати до підприємств, установ, організацій і громадян фінансові санкції та накладати адміністративні штрафи відповідно до Закону України "Про державну податкову службу в Україні" ( 509-12 ).

( Пункт 35 в редакції Наказу ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

36. ( Пункт 36 виключено на підставі Наказу ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 ) За неподання або несвоєчасне подання державним податковим інспекціям розрахунків та інших документів, необхідних для обчислення платежів, а також за неподання або несвоєчасне подання установам банків платіжних доручень на сплату платежу до бюджетів з платника стягуються фінансові санкції в розмірі 10 відсотків сум, належних до сплати бюджетам.

37. Суми платежів за спеціальне використання надр при видобуванні корисних копалин, що не були внесені у встановлений термін, сплачуються до відповідного бюджету з нарахуванням пені у розмірі 0,3 відсотка суми недоїмки за кожний день прострочки платежу, починаючи з наступного дня після настання строку платежу включно до дня сплати.

Стягнення не внесених у строк сум платежів за спеціальне використання надр при видобуванні корисних копалин, відстрочка і розстрочка платежів, зарахування і повернення неправильно сплачених сум проводиться відповідно до Декрету Кабінету Міністрів від 21 січня 1993 року N 8-93 "Про стягнення не внесених у строк податків і неподаткових платежів".

38. ( Пункт 38 виключено на підставі Наказу ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 ) У разі приховування (заниження) платниками суми платежу з них стягується сума донарахованого платежу і штраф у двократному розмірі тієї ж суми, а в разі повторного порушення протягом року після встановлення порушення попередньою перевіркою - штраф у п'ятикратному розмірі.

39. Донараховані за результатами перевірок суми платежів за спеціальне використання надр при видобуванні корисних копалин, суми недоїмки, а також суми штрафів та інших санкцій стягуються до відповідних бюджетів.

40. Суми донарахованих за результатами перевірок платежу, сум недоїмки, а також сум штрафів та інших санкцій, передбачених пунктом 7 статті 11 Закону України "Про державну податкову службу в Україні" ( 509-12 ) та іншим законодавством України, стягуються з підприємств, організацій, незалежно від форм власності та наслідків фінансово-господарської діяльності, у безспірному порядку, а з громадян - за рішенням суду або за виконавчими написами АО Таріусів".

( Пункт 40 в редакції Наказу ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

41. ( Пункт 41 виключено на підставі Наказу ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 ) Керівники та інші службові особи підприємств, установ і організацій, винні у порушенні податкового законодавства, у приховуванні (заниженні) об'єктів оподаткування, а також у відсутності бухгалтерського обліку об'єктів оподаткування або веденні його з порушенням встановленого порядку, у неподанні, несвоєчасному поданні або поданні за невстановленою формою розрахунків, платіжних доручень та інших документів, пов'язаних з обчисленням і сплатою платежів за спеціальне використання надр при видобуванні корисних копалин, притягуються до адміністративного штрафу у розмірі від п'яти до десяти мінімальних розмірів заробітної плати.

VIII. Права платників на оскарження дії службових осіб, державних податкових інспекцій

42. Платники мають право оскаржити дії службових осіб державних податкових інспекцій у порядку, встановленому чинним законодавством України.

( Пункт 42 в редакції Наказу ГДПІ N 47/39/86 ( z0185-95 ) від 5.06.95 )

Додаток N 1 до Інструкції про порядок обчислення і сплати платежів за спеціальне використання надр при видобуванні корисних копалин

Приклади розрахунків:

Приклад 1. За перше півріччя 1993 року залізорудний гірничозбагачувальний комбінат видобув 100000 т залізистих кварцитів. Кар'єр - гірничодобувний підрозділ комбінату. Втрати в надрах - 5000 т. Обсяг погашених балансових запасів - 105000 (100000 + 5000) т. Собівартість видобутку 100000 т переданої для збагачення мінеральної сировини - 5000 млн.крб.

За 1 квартал плата за спеціальне використання надр при видобуванні корисних копалин сплачена комбінатом у розмірі 30 млн.крб.

Собівартість одиниці переданої мінеральної сировини дорівнює:

5000000000 крб / 100000 т = 50000 крб./т

Сума плати за перше півріччя:

105000 т * 50000 крб. * 1,1 * 1% = 57,75 млн.крб

Сума належної плати: 57,75 - 30 = 27,75 млн.крб

Приклад 2. Комбінат розробляє родовище каоліну. За звітний період видобуто - 200000 т, втрати - 6000 т. Обсяг погашених запасів дорівнює - 206000 (200000 + 6000) т. Кар'єр - гірничодобувний підрозділ комбінату. Одну частину загального обсягу - 100000 т (50%) каоліну реалізовано і одержано виручку - 2000 млн.крб. Другу частину - 100000 т (50%) використано комбінатом для виробництва вогнетривів. Собівартість видобутку 200000 т переданого каоліну - 3000 млн.крб.

Розрахунок плати обчислюється окремо для сировини, що реалізована, і для сировини, що використана на комбінаті. Обсяг погашених запасів ділиться пропорційно.

Ціна одиниці реалізованої мінеральної сировини дорівнює:

2000000000 крб. / 100000 т = 20000 крб. / т

Собівартість одиниці переданої мінеральної сировини дорівнює:

3000000000 крб. / 100000 т = 15000 крб. / т

Сума плати:

I. 103000 т * 20000 крб. * 1% = 20,6 млн.крб

II. 103000 т * 15000 крб. * 1,1 * 1% = 16,995 млн.крб

Загальна сума: 20,6 + 16,995 = 37,595 млн.крб
