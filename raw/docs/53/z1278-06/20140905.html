ДЕРЖАВНИЙ ДЕПАРТАМЕНТ УКРАЇНИ З ПИТАНЬ ВИКОНАННЯ ПОКАРАНЬ МІНІСТЕРСТВО ОХОРОНИ ЗДОРОВ'Я УКРАЇНИ

{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 1348/5/572 ( z0990-14 ) від 15.08.2014 }

Про затвердження Змін до спільного наказу Державного департаменту України з питань виконання покарань та Міністерства охорони здоров'я України від 27.04.2000 N 79/91

З метою приведення нормативно-правових актів Державного департаменту України з питань виконання покарань (далі - Департамент) у відповідність до чинного законодавства України, зокрема до Закону України "Про Державну кримінально-виконавчу службу України" ( 2713-15 ), НАКАЗУЄМО:

1. Затвердити Зміни до спільного наказу Державного департаменту України з питань виконання покарань та Міністерства охорони здоров'я України від 27.04.2000 N 79/91 ( z0320-00 ) "Про затвердження Інструкції про порядок проведення медико-соціальної експертизи інвалідів, які відбувають покарання в установах кримінально-виконавчої системи", зареєстрованого в Міністерстві юстиції України 31.05.2000 за N 320/4541, що додаються.

2. Управлінню охорони здоров'я Департаменту подати цей наказ у встановленому порядку на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на начальника управління охорони здоров'я Департаменту Живаго С.Б. та начальника Відділу медико-соціальної експертизи Міністерства охорони здоров'я України Марунича В.В.

Голова Державного департаменту України з питань виконання покарань В.В.Кощинець

Міністр охорони здоров'я України Ю.В.Поляченко

ЗАТВЕРДЖЕНО Наказ Державного департаменту України з питань виконання покарань, Міністерства охорони здоров'я України 06.11.2006 N 216/733

Зареєстровано в Міністерстві юстиції України 7 грудня 2006 р. за N 1278/13152

ЗМІНИ до спільного наказу Державного департаменту України з питань виконання покарань та Міністерства охорони здоров'я України від 27.04.2000 N 79/91 "Про затвердження Інструкції про порядок проведення медико-соціальної експертизи інвалідів, які відбувають покарання в установах кримінально-виконавчої системи", зареєстрованого в Міністерстві юстиції України 31.05.2000 за N 320/4541 ( z0320-00 )

1. У наказі Державного департаменту України з питань виконання покарань та Міністерства охорони здоров'я України від 27.04.2000 N 79/91 ( z0320-00 ) "Про затвердження Інструкції про порядок проведення медико-соціальної експертизи інвалідів, які відбувають покарання в установах кримінально-виконавчої системи", зареєстрованому в Міністерстві юстиції України 31.05.2000 за N 320/4541 (далі - Наказ):

1.1. У назві та тексті Наказу ( z0320-00 ) слова "установи кримінально-виконавчої системи" у всіх відмінках замінити словами "установи виконання покарань та слідчі ізолятори" у відповідних відмінках.

1.2. У пункті 2 Наказу ( z0320-00 ) слова "управлінь (відділів)" замінити словами "територіальних органів управління".

1.3. У пункті 4 Наказу ( z0320-00 ) слова "медичного та санітарно-епідеміологічного обслуговування спецконтингенту" замінити словами "охорони здоров'я", прізвище та ініціали Гунченко О.М. замінити на прізвище та ініціали Живаго С.Б.

2. В Інструкції про порядок проведення медико-соціальної експертизи інвалідів, які відбувають покарання в установах кримінально-виконавчої системи ( z0320-00 ), затвердженій Наказом (далі - Інструкція):

2.1. У назві та тексті Інструкції ( z0320-00 ) слова "установи кримінально-виконавчої системи" у всіх відмінках замінити словами "установи виконання покарань та слідчі ізолятори" у відповідних відмінках.

2.2. У пункті 1.2 Інструкції ( z0320-00 ) слова "управлінь (відділів)" замінити словами "територіальних органів управління", слова "обласних управлінь охорони здоров'я" замінити словами "Міністерства охорони здоров'я України".

2.3. У пункті 2.1 Інструкції ( z0320-00 ) слова "лікувальних закладах кримінально-виконавчої системи" замінити словами "лікувальних закладах Державної кримінально-виконавчої служби".

2.4. Пункт 2.5 Інструкції ( z0320-00 ) викласти в такій редакції:

"2.5. Оплата праці членів МСЕК під час виїзних засідань проводиться у порядку, визначеному спільним наказом Міністерства праці та соціальної політики України і Міністерства охорони здоров'я України від 05.10.2005 N 308/519 ( z1209-05 ) "Про впорядкування умов оплати праці працівників закладів охорони здоров'я та установ соціального захисту населення", зареєстрованим у Міністерстві юстиції України 17 жовтня 2005 року за N 1209/11489 (із змінами)".
