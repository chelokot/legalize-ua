Про затвердження складу наглядових рад національних заповідників

{ Із змінами, внесеними згідно з Постановами КМ N 1278 ( 1278-2009-п ) від 02.12.2009 N 109 ( 109-2012-п ) від 20.02.2012 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 109 ( 109-2012-п ) від 20.02.2012 }

2. Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 1 липня 2009 р. N 674

ПЕРЕЛІК актів Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 6 липня 1998 р. N 1021 ( 1021-98-п ) "Про затвердження складу наглядової ради Національного історико-архітектурного заповідника "Кам'янець".

2. Постанова Кабінету Міністрів України від 1 березня 1999 р. N 305 ( 305-99-п ) "Про затвердження персонального складу наглядової ради Національного архітектурно-історичного заповідника "Чернігів стародавній".

3. Постанова Кабінету Міністрів України від 16 листопада 2002 р. N 1750 ( 1750-2002-п ) "Про затвердження складу наглядової ради Національного заповідника "Софія Київська" (Офіційний вісник України, 2002 р., N 47, ст. 2138).

4. Постанова Кабінету Міністрів України від 31 березня 2003 р. N 409 ( 409-2003-п ) "Про зміну складу наглядової ради Національного заповідника "Софія Київська" (Офіційний вісник України, 2003 р., N 14, ст. 615).

5. Розпорядження Кабінету Міністрів України від 13 квітня 2005 р. N 100 ( 100-2005-р ) "Про затвердження складу наглядової ради Національного заповідника "Замки Тернопілля".
