МІНІСТЕРСТВО ОСВІТИ УКРАЇНИ

НАКАЗ

N 236 від 20.07.1994 Зареєстровано в Міністерстві м.Київ юстиції України 8 серпня 1994 р. за N 184/393

Про затвердження Інструкції про порядок прийому учнів до загальноосвітніх навчально-виховних закладів на конкурсній основі

( Із змінами, внесеними згідно з Наказом Міністерства освіти і науки N 389 ( z0547-03 ) від 19.06.2003 )

З метою забезпечення належної організації і проведення приймання учнів до загальноосвітніх середніх навчально-виховних закладів на конкурсній основі відповідно до п.17 Положення про середній загальноосвітній навчально-виховний заклад ( 660-93-п ) НАКАЗУЮ:

1. Затвердити Інструкцію про порядок прийому учнів до загальноосвітніх навчально-виховних закладів на конкурсній основі (додається).

2. Міністерству освіти Республіки Крим, управлінням (відділам) освіти місцевих органів державної виконавчої влади, керівникам загальноосвітніх навчально-виховних закладів забезпечити проведення конкурсного приймання учнів відповідно до даної Інструкції.

3. Контроль за виконанням наказу покласти на заступника міністра О.Г.Мороза.

В.о.Міністра В.П.Шепотько

( Інструкція про порядок прийому учнів до загальноосвітніх навчально-виховних закладів на конкурсній основі втратила чинність на підставі Наказу Міністерства освіти і науки N 389 ( z0547-03 ) від 19.06.2003 )
