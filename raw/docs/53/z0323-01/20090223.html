ДЕРЖАВНИЙ КОМІТЕТ ЗВ'ЯЗКУ ТА ІНФОРМАТИЗАЦІЇ УКРАЇНИ

НАКАЗ

N 46 від 19.03.2001 Зареєстровано в Міністерстві юстиції України 10 квітня 2001 р. за N 323/5514

Про затвердження Переліку товарів і послуг, при реалізації яких дозволяється проводити розрахункові операції без застосування реєстраторів розрахункових операцій з використанням розрахункових книжок та книг обліку розрахункових операцій відділеннями та пунктами поштового зв'язку в селах

{ Із змінами, внесеними згідно з Наказом Державного комітету зв'язку та інформатизації N 170 ( z0830-03 ) від 08.09.2003 Наказом Міністерства транспорту та зв'язку N 1536 ( z0141-09 ) від 22.12.2008 }

Відповідно до Закону України "Про застосування реєстраторів розрахункових операцій у сфері торгівлі, громадського харчування та послуг" ( 265/95-ВР ), постанови Кабінету Міністрів України від 23.08.2000 N 1336 ( 1336-2000-п ) "Про забезпечення реалізації статті 10 Закону України "Про застосування реєстраторів розрахункових операцій у сфері торгівлі, громадського харчування та послуг" та з метою поліпшення забезпечення товарами населення, яке проживає у сільській місцевості, НАКАЗУЮ:

1. Затвердити Перелік товарів і послуг, при реалізації яких дозволяється проводити розрахункові операції без застосування реєстраторів розрахункових операцій з використанням розрахункових книжок та книг обліку розрахункових операцій відділеннями та пунктами поштового зв'язку в селах (додається).

{ Пункт 2 втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 1536 ( z0141-09 ) від 22.12.2008 }

3. Генеральному директору УДППЗ "Укрпошта" (Мухін В.Г.) організувати роботу з продажу товарів, зазначених у Переліку, та забезпечити контроль за здійсненням розрахунків із споживачами за реалізований товар.

4. Контроль за виконанням наказу покласти на заступника Голови Держкомзв'язку Ревякіна О.М.

Голова Державного комітету зв'язку та інформатизації України О.Б.Шевчук

Затверджено Наказ Державного комітету зв'язку та інформатизації України 19.03.2001 N 46

Зареєстровано в Міністерстві юстиції України 10 квітня 2001 р. за N 323/5514

Перелік товарів і послуг, при реалізації яких дозволяється проводити розрахункові операції без застосування реєстраторів розрахункових операцій з використанням розрахункових книжок та книг обліку розрахункових операцій відділеннями та пунктами поштового зв'язку в селах

1. Тара та упаковка для поштових відправлень, фурнітура до них.

2. Паперобілові товари.

3. Друковані видання.

4. Мило туалетне й господарське.

5. Сірники й сіль.

6. Канцелярські товари.

7. Галантерейні, парфумерно-косметичні та санітарно-гігієнічні товари.

8. Синтетичні мийні засоби.

9. Тютюнові вироби.

10. Продовольчі товари (розфасовані, із зазначенням терміну використання): хліб і хлібобулочні вироби, крупи, макаронні вироби, чай, кава, безалкогольні напої (включаючи мінеральні води), оцет.

11. Панчішно-шкарпеткові вироби.

12. Гумове та полімерне взуття.

13. Фототовари (фотоплівка, фотопапір, фоторамки, фотоальбоми).

14. Господарчі товари (свічки, поліетиленові тази, відра, бочки, посуд).

( Пункти 10-14 поширюються на діяльність об'єктів поштового зв'язку в селах з населенням не більше 1,0 тис. чоловік згідно з Наказом Державного комітету зв'язку та інформатизації N 170 ( z0830-03 ) від 08.09.2003 )

( Перелік із змінами, внесеними згідно з Наказом Державного комітету зв'язку та інформатизації N 170 ( z0830-03 ) від 08.09.2003 )
