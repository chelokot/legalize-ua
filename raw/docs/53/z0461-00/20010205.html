Текст документа від 05.02.2001:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

N 377 від 19.07.2000 Зареєстровано в Міністерстві юстиції України 31 липня 2000 р. за N 461/4682

Про затвердження Коефіцієнтів, що застосовуються до тарифів Збірника тарифів на перевезення вантажів залізничним транспортом України та змін і доповнень до цього Збірника

( Із змінами, внесеними згідно з Наказом Мінтрансу N 68 ( z0115-01 ) від 05.02.2001 )

Відповідно до постанови Кабінету Міністрів України від 25 грудня 1996 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

( Пункт 1 втратив чинність на підставі з Наказу Мінтрансу N 68 ( z0115-01 ) від 05.02.2001 )

2. Затвердити Зміни і доповнення до Збірника тарифів на перевезення вантажів залізничним транспортом України ( z0462-00 ), затвердженого наказом Міністерства транспорту України від 15.11.99 N 551 ( z0828-99 ) і зареєстрованого в Міністерстві юстиції України 01.12.99 за N 828/4121, що додаються.

3. Департаменту транспортної політики (Легенький Г.М.) разом з Департаментом нормативно-правового забезпечення (Логінова Л.М.) у встановленому порядку зареєструвати цей наказ у Міністерстві юстиції України.

4. Укрзалізниці (Кірпа Г.М.) після реєстрації цього наказу в Міністерстві юстиції України забезпечити своєчасне його доведення до відома вантажовідправників, вантажоодержувачів та населення України.

5. Наказ Міністерства транспорту України від 18.02.2000 N 56 ( z0097-00 ) "Про затвердження Коефіцієнтів, що застосовуються до тарифів Збірника тарифів на перевезення вантажів залізничним транспортом України", зареєстрований в Міністерстві юстиції України 21.02.2000 за N 97/4318, вважати таким, що втратив чинність.

6. Контроль за виконанням наказу покласти на першого заступника Міністра Колеснікова О.О.

Міністр Л.М.Костюченко

( Коефіцієнти, що застосовуються до тарифів Збірника тарифів на перевезення вантажів залізничним транспортом України втратили чинність на підставі Наказу Мінтрансу N 68 ( z0115-01 ) від 05.02.2001 )
