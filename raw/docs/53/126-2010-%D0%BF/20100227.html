Кабінет Міністрів України; Постанова від 17.02.2010 № 126

Про закупівлю енергетичного вугілля

Стан: Втратив чинність

Ідентифікатор: 126-2010-п

Текст документа від 27.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 лютого 2010 р. N 126 Київ

Про закупівлю енергетичного вугілля

{ Із змінами, внесеними згідно з Постановою КМ N 167 ( 167-2010-п ) від 24.02.2010 }

З метою задоволення потреби енергогенеруючих компаній в енергетичному вугіллі Кабінет Міністрів України постановляє:

{ Вступна частина в редакції Постанови КМ N 167 ( 167-2010-п ) від 24.02.2010 }

1. Погодитися з пропозицією Міністерства палива та енергетики щодо здійснення до 31 березня 2010 р. закупівлі за державні кошти енергетичного вугілля для виробництва електричної та теплової енергії енергогенеруючими компаніями, які провадять ліцензовану діяльність з виробництва електричної та/або теплової енергії, без застосування процедури закупівлі, визначеної Положенням про закупівлю товарів, робіт і послуг за державні кошти, затвердженим постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006), в обсязі, необхідному для покриття дефіциту енергетичного вугілля, що утворився у зв'язку з постачанням вугілля відповідно до постанови Кабінету Міністрів України від 29 грудня 2009 р. N 1416 ( 1416-2009-п ) "Про закупівлю енергетичного вугілля" (Офіційний вісник України, 2010 р., N 1, ст. 9, N 5, ст. 206).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 167 ( 167-2010-п ) від 24.02.2010 }

2. Енергогенеруючим компаніям, зазначеним у пункті 1 цієї постанови, подати Міністерству економіки звіт про результати здійснення закупівлі.
