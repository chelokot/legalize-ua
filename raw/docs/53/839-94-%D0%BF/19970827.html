Питання Міністерства освіти

Стан: Втратив чинність

Ідентифікатор: 839-94-п

Текст документа від 27.08.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 грудня 1994 р. N 839 Київ

Питання Міністерства освіти

( Із змінами, внесеними згідно з Постановою КМ N 936 ( 936-97-п ) від 27.08.97 )

Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. Установити граничну чисельність працівників центрального апарату Міністерства освіти в кількості 286 одиниць.

Дозволити Міністерству освіти мати шістьох заступників Міністра, у тому числі два перших, та колегію в кількості 17 чоловік. ( На часткову зміну абзацу другого пункту 1 ввести посаду заступника Міністра освіти України замість посади першого заступника Міністра згідно з Постановою КМ N 936 ( 936-97-п )

від 27.08.97 )

2. Міністерству освіти подати Кабінетові Міністрів України в установленому порядку проект Положення про Міністерство освіти та пропозиції про структуру його центрального апарату.

3. Визнати такими, що втратили чинність, пункти 2 і 3 постанови Кабінету Міністрів України від 8 липня 1992 р. N 384 ( 384-92-п ) та пункт 1 постанови Кабінету Міністрів України від 9 листопада 1993 р. N 912 ( 912-93-п ).

Прем'єр-міністр України В. МАСОЛ
