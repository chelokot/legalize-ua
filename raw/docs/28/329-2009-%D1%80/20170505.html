Питання обліку електричної енергії, що використовується для зовнішнього освітлення населених пунктів та магістральних доріг і вулиць

Стан: Чинний

Ідентифікатор: 329-2009-р

Текст документа від 05.05.2017:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 березня 2009 р. N 329-р Київ

Питання обліку електричної енергії, що використовується для зовнішнього освітлення населених пунктів та магістральних доріг і вулиць

{ Із змінами, внесеними згідно з Постановою КМ N 282 ( 282-2017-п ) від 26.04.2017 }

1. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським держадміністраціям забезпечити ведення з 1 січня 2010 р. обліку електричної енергії, що використовується для зовнішнього освітлення населених пунктів та магістральних доріг і вулиць, за показаннями приладів диференційованого за годинами доби її обліку, внесених до Державного реєстру засобів вимірювальної техніки.

{ Пункт 2 виключено на підставі Постанови КМ N 282 ( 282-2017-п ) від 26.04.2017 }
