Президія Верховної Ради УРСР; Постанова від 19.07.1979 № 4910-IX

Про розміри і порядок виплати добових депутатам Верховної Ради Української РСР у зв'язку з виконанням ними депутатських повноважень

Стан: Втратив чинність

Ідентифікатор: 4910-09

Текст документа від 01.08.1995:

ПОСТАНОВА ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

( Постанова втратила чинність на підставі Закону N 277/95-ВР від 07.07.95, ВВР, 1995, N 28, ст.210 )

Про розміри і порядок виплати добових депутатам Верховної Ради Української РСР у зв'язку з виконанням ними депутатських повноважень

( Відомості Верховної Ради (ВВР), 1979, N 31, ст. 401 )

( Із змінами, внесеними згідно з Указом Президії ВР УРСР N 2157-X ( 2157-10 ) від 14.07.81, ВВР, 1981, N 30, ст. 465 Постановою Президії ВР УРСР

N 9251а-XI ( 9251а-11 ) від 10.05.90 )

Відповідно до статті 2 Закону України від 29 липня 1938 року "Про відшкодування депутатам Верховної Ради УРСР витрат, зв'язаних з виконанням депутатських повноважень" Президія Верховної Ради Української РСР постановляє:

( Преамбула із змінами, внесеними згідно з Указом Президії ВР УРСР N 2157-X ( 2157-10 ) від 14.07.81 )

1. Добові виплачуються депутатові Верховної Ради Української РСР для відшкодування витрат, зв'язаних з виконанням депутатських повноважень при виїзді депутата за межі постійного місця проживання.

2. За час участі депутата Верховної Ради Української РСР у сесіях Верховної Ради Української РСР, засіданнях Президії Верховної Ради Української РСР і комісій Верховної Ради Української РСР, а також за час виїзду депутата для виконання доручення Верховної Ради Української РСР, Президії Верховної Ради Української РСР або комісії Верховної Ради Української РСР добові виплачуються депутатові в розмірі 15 карбованців за кожну добу, включаючи вихідні і святкові дні.

( Пункт 2 із змінами, внесеними згідно з Постановою Президії ВР УРСР N 9251а-XI ( 9251а-11 ) від 10.05.90 )

Виплата добових починається з дня прибуття депутата, але не більш як за добу до відкриття сесії Верховної Ради Української РСР, до початку засідання відповідного органу Верховної Ради Української РСР чи до початку роботи депутата по виконанню даного йому доручення. Виплата добових припиняється через добу після закриття сесії Верховної Ради Української РСР, закриття засідання органу Верховної Ради Української РСР чи після закінчення роботи депутата по виконанню даного йому доручення.

В зазначених у цій статті випадках добові виплачуються депутатові з коштів, передбачених кошторисом Президії Верховної Ради Української РСР.

У всіх інших випадках за час виконання депутатом Верховної Ради Української РСР депутатських повноважень йому виплачуються добові і відшкодовуються витрати по найманню жилого приміщення в розмірах і порядку, встановлених законодавством для працівників, що відряджаються за кордон.

5. Визнати такою, що втратила чинність, Постанову Президії Верховної Ради Української РСР від 15 листопада 1938 року "Про добові членам Президії і комісій Верховної Ради УРСР при виїздах їх на засідання Президії і комісій" (Протокол засідання Президії Верховної Ради УРСР, 1938 р., N 2, п. 4).
