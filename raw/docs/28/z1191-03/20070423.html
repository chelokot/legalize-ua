ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

09.12.2003 N 847

Зареєстровано в Міністерстві юстиції України 19 грудня 2003 р. за N 1191/8512

{ Наказ втратив чинність на підставі Наказу Державної митної служби N 261 ( z0321-07 ) від 28.03.2007 }

Про затвердження Порядку установлення та застосування критерію достатньої переробки товару, якщо цей критерій щодо конкретного товару або конкретної країни (країн) не обумовлено міжнародним договором

Відповідно до статей 279, 280 Митного кодексу України від 11.07.2002 N 92-IV ( 92-15 ) і постанови Кабінету Міністрів України від 27.12.2002 N 2030 ( 2030-2002-п ) НАКАЗУЮ:

1. Затвердити Порядок установлення та застосування критерію достатньої переробки товару, якщо цей критерій щодо конкретного товару або конкретної країни (країн) не обумовлено міжнародним договором, що додається.

2. Управлінню тарифного регулювання (Пашинний О.І.) і Управлінню правової роботи (Будаков А.Ю.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Установити, що цей наказ застосовується з дня набрання чинності Митним кодексом України ( 92-15 ).

4. Контроль за виконанням наказу покласти на заступника Голови Служби Дьоміна Ю.М.

В. о. Голови Служби В.Я.Лозко

ЗАТВЕРДЖЕНО Наказ Державної митної служби України 09.12.2003 N 847

Зареєстровано в Міністерстві юстиції України 19 грудня 2003 р. за N 1191/8512

ПОРЯДОК установлення та застосування критерію достатньої переробки товару, якщо цей критерій щодо конкретного товару або конкретної країни (країн) не обумовлено міжнародним договором

1. Загальні положення

1.1. Цей Порядок застосовується на підставі статей 279 і 280 Митного кодексу України ( 92-15 ) та постанови Кабінету Міністрів України від 27.12.2002 N 2030 ( 2030-2002-п ), якщо стосовно конкретного товару або конкретної країни (країн) критерій достатньої переробки не обумовлено міжнародним договором.

1.2. У цьому Порядку терміни вживаються в тому самому значенні, що й у Митному кодексі України.

2. Установлення й застосування критерію достатньої переробки товару

2.1. Критерій достатньої переробки товару визначається правилом, яке потребує в результаті переробки товару зміни класифікаційного коду цього товару за Гармонізованою системою опису та кодування товарів ( 995_079 ) на рівні будь-якого з перших чотирьох знаків (далі - Правило зміни класифікаційного коду).

2.2. Правило зміни класифікаційного коду застосовується тільки за наявності даних про код товару за Гармонізованою системою опису та кодування товарів ( 995_079 ), одержаного в результаті переробки матеріалів, і про коди матеріалів, з яких виготовлено цей товар і які походять з іншої країни чи невідомого походження.

Якщо такі дані відсутні, то критерій достатньої переробки товару вважається невизначеним.

2.3. Правило зміни класифікаційного коду виконується за умови відмінності класифікаційного коду за Гармонізованою системою опису та кодування товарів ( 995_079 ) на рівні будь-якого з перших чотирьох знаків від класифікаційних кодів матеріалів, з яких виготовлено цей товар і які походять з іншої країни чи невідомого походження. При цьому не визнаються такими, що відповідають критерію достатньої переробки товару, операції, зазначені в статті 280 Митного кодексу України ( 92-15 ).
