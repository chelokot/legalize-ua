Текст документа від 01.06.2012:

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України

( Відомості Верховної Ради України (ВВР), 2001, N 41, ст.203 )

{ Із змінами, внесеними згідно з Кодексом N 4495-VI ( 4495-17 ) від 13.03.2012, ВВР, 2012, N 44-45, N 46-47, N 48, ст.552 }

Верховна Рада України постановляє:

I. Внести зміни до таких законів України:

1. У Законі України "Про ставки вивізного (експортного) мита на насіння деяких видів олійних культур" ( 1033-14 ) (Відомості Верховної Ради України, 1999 р., N 44, ст. 389):

а) статтю 1 викласти в такій редакції:

"Стаття 1. Затвердити ставки вивізного (експортного) мита на насіння таких видів олійних культур:

------------------------------------------------------------------

згідно з ТН ЗЕД | ТН ЗЕД |(експортного) мита у

| |відсотках до митної

| |вартості товару

----------------+----------------------------+--------------------

------------------------------------------------------------------

б) пункт 1 статті 2 викласти в такій редакції:

"1. Цей Закон набирає чинності з дня його опублікування".

{ Пункт 2 розділу I втратив чинність на підставі Кодексу N 4495-VI ( 4495-17 ) від 13.03.2012 }

II. Цей Закон набирає чинності з дня його опублікування.
