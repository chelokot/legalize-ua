Текст документа від 15.08.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 710/2007 ( 710/2007 ) від 15.08.2007 }

Про оновлення складу Української частини Українсько-Російської міждержавної комісії

1. Затвердити:

персональний склад Української частини Українсько-Російської міждержавної комісії (додаток N 1);

персональний склад Української частини Комітету з питань економічного співробітництва Українсько-Російської міждержавної комісії (додаток N 2);

персональний склад Української частини Підкомітету з питань безпеки Українсько-Російської міждержавної комісії (додаток N 3);

персональний склад Української частини Підкомітету з міжнародного співробітництва Українсько-Російської міждержавної комісії (додаток N 4);

персональний склад Української частини Підкомісії з питань функціонування Чорноморського флоту Російської Федерації та його перебування на території України Українсько-Російської міждержавної комісії (додаток N 5).

2. Визнати таким, що втратив чинність, Указ Президента України від 4 листопада 2005 року N 1543 ( 1543/2005 ) "Питання Української частини Українсько-Російської міждержавної комісії".
