Кабінет Міністрів України; Розпорядження, План, Заходи від 17.09.2008 № 1242-р

Про затвердження плану заходів щодо підвищення ефективності залучення та використання коштів міжнародних фінансових організацій на друге півріччя 2008 р. - 2009 рік

Стан: Чинний

Ідентифікатор: 1242-2008-р

Текст документа від 21.10.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 вересня 2008 р. N 1242-р Київ

Про затвердження плану заходів щодо підвищення ефективності залучення та використання коштів міжнародних фінансових організацій на друге півріччя 2008 р. - 2009 рік

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1241-р ( 1241-2009-р ) від 21.10.2009 }

1. Затвердити план заходів щодо підвищення ефективності залучення та використання коштів міжнародних фінансових організацій на друге півріччя 2008 р. - 2009 рік, що додається.

2. Мінекономіки проводити моніторинг виконання затвердженого цим розпорядженням плану заходів та щокварталу інформувати Кабінет Міністрів України про результати його виконання.

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 8 лютого 2006 р. N 62 ( 62-2006-р ) "Про заходи щодо забезпечення ефективного залучення та використання коштів міжнародних фінансових організацій" (Офіційний вісник України, 2006 р., N 6, ст. 314).
