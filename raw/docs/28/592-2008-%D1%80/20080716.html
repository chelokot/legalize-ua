Кабінет Міністрів України; Розпорядження від 12.04.2008 № 592-р

Питання стабілізації продовольчого ринку

Стан: Чинний

Ідентифікатор: 592-2008-р

Текст документа від 16.07.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 квітня 2008 р. N 592-р Київ

Питання стабілізації продовольчого ринку

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 848-р ( 848-2008-р ) від 18.06.2008 N 968-р ( 968-2008-р ) від 16.07.2008 }

Погодитися з пропозицією Мінекономіки та Держкомрезерву щодо реалізації запасів м'яса, закупленого відповідно до постанови Кабінету Міністрів України від 12 березня 2008 р. N 190-2, через державне підприємство "Ресурспостач" визначеним Мінекономіки підприємствам м'ясопереробної промисловості і роздрібної торгівлі за ціною, що встановлюється як різниця між вартістю закупівлі м'яса та сумою сплаченого ввізного мита, або на аукціоні відповідно до Порядку реалізації матеріальних цінностей державного резерву, затвердженого постановою Кабінету Міністрів України від 25 серпня 2004 р. N 1078 ( 1078-2004-п ) (Офіційний вісник України, 2004 р., N 34, ст. 2246; 2008 р., N 26, ст. 820).

{ Розпорядження із змінами, внесеними згідно з Розпорядженнями КМ N 848-р ( 848-2008-р ) від 18.06.2008, N 968-р ( 968-2008-р ) від 16.07.2008 }
