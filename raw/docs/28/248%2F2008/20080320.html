Стан: Чинний

Ідентифікатор: 248/2008

Текст документа від 20.03.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання такими, що втратили чинність, деяких указів Президента України

1. Визнати такими, що втратили чинність:

статтю 1 Указу Президента України від 10 липня 1995 року N 584 ( 584/95 ) "Про додаткові заходи щодо соціального захисту суддів";

Указ Президента України від 21 серпня 1999 року N 1048 ( 1048/99 ) "Про розміри надбавок до посадових окладів суддів за кваліфікаційні класи";

Указ Президента України від 25 листопада 2002 року N 1061 ( 1061/2002 ) "Про внесення зміни до Указу Президента України від 10 липня 1995 року N 584";

статтю 4 Указу Президента України від 11 грудня 2002 року N 1150 ( 1150/2002 ) "Про забезпечення діяльності Конституційного Суду України";

Указ Президента України від 17 грудня 2003 року N 1446 ( 1446/2003 ) "Про внесення зміни до Указу Президента України від 21 серпня 1999 року N 1048";

Указ Президента України від 3 березня 2006 року N 188 ( 188/2006 ) "Про внесення змін до деяких указів Президента України";

Указ Президента України від 13 листопада 2006 року N 956 ( 956/2006 ) "Про внесення зміни до статті 4 Указу Президента України від 11 грудня 2002 року N 1150".

2. Цей Указ набирає чинності з 1 березня 2008 року.

Президент України В.ЮЩЕНКО

м. Київ, 20 березня 2008 року N 248/2008
