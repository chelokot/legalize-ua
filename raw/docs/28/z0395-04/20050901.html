( Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 326 ( z1239-05 ) від 14.10.2005 )

Про внесення змін до наказу Міністерства праці та соціальної політики України від 30.11.2001 N 511

На виконання постанови Кабінету Міністрів України від 11.02.2004 N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести до наказу Міністерства праці та соціальної політики України від 30.11.2001 N 511 ( z1012-01 ) "Про умови оплати праці працівників Всеукраїнського центру професійної реабілітації інвалідів", зареєстрованого в Міністерстві юстиції України 07.12.2001 за N 1012/6203 (зі змінами), зміни, виклавши додатки 1-6 у редакції, що додається.

2. Ці зміни застосовуються з 1 березня 2004 року.

Міністр М.Папієв
