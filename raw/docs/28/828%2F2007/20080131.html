Про зупинення дії постанови Кабінету Міністрів України від 5 вересня 2007 року N 1097

Стан: Втратив чинність

Ідентифікатор: 828/2007

Текст документа від 31.01.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1301/2007 ( 1301/2007 ) від 28.12.2007 }

Про зупинення дії постанови Кабінету Міністрів України від 5 вересня 2007 року N 1097

{ Додатково див. Конституційне подання Президента ( n0021100-07 ) від 07.09.2007 }

Кабінетом Міністрів України 5 вересня 2007 року видано постанову N 1097 ( 1097-2007-п ) "Про деякі заходи щодо здійснення державного контролю за дотриманням порядку складання загальних списків виборців".

Зазначеною постановою ( 1097-2007-п ) Кабінетом Міністрів України з посиланням на статтю 116 Конституції України ( 254к/96-ВР ), частину сімнадцяту статті 39 Закону України "Про вибори народних депутатів України" ( 1665-15 ) дано низку доручень Міністерству внутрішніх справ України, Міністерству закордонних справ України, Міністерству юстиції України, Державному департаменту України з питань виконання покарань, іншим центральним та місцевим органам виконавчої влади щодо здійснення державного контролю за дотриманням порядку складання загальних списків виборців.

Статтею 39 Закону України "Про вибори народних депутатів України" ( 1665-15 ) врегульовано порядок складання загальних списків виборців. Зокрема, частиною сімнадцятою цієї статті Закону ( 1665-15 ), з посиланням на яку Кабінет Міністрів України видав названу постанову ( 1097-2007-п ), визначено, що державний контроль за дотриманням органами, підприємствами, закладами, установами, організаціями, представництвами, командирами військових частин (формувань) порядку складання загальних списків виборців здійснюють Кабінет Міністрів України та Центральна виборча комісія.

Разом із тим процедуру складання загальних списків виборців, а відтак і здійснення, зокрема, Кабінетом Міністрів України державного контролю за дотриманням порядку складання саме загальних списків виборців Законом України "Про вибори народних депутатів України" ( 1665-15 ) передбачено лише під час проведення чергових виборів до Верховної Ради України, які за статтею 77 Конституції України ( 254к/96-ВР ), статтею 15 Закону України "Про вибори народних депутатів України" ( 1665-15 ) проводяться у зв'язку із закінченням конституційного строку повноважень Верховної Ради України.

Так, за статтею 39 Закону України "Про вибори народних депутатів України" ( 1665-15 ), якою врегульовано порядок складання загальних списків виборців, для підготовки проведення голосування виборців до 1 жовтня року, який передує року проведення чергових виборів народних депутатів України, складаються загальні списки виборців за формою, затвердженою Центральною виборчою комісією (частина перша). За частиною другою цієї статті для складання та уточнення загальних списків виборців, які проживають на території кожного села, селища, міста та району у містах Києві та Севастополі, районними, районними у містах Києві та Севастополі державними адміністраціями, виконавчими органами міських рад (міст республіканського в Автономній Республіці Крим, обласного значення) утворюються робочі групи обліку виборців на період з 1 серпня року, що передує року проведення чергових виборів, до дня проведення чергових виборів включно.

На підставі частин дев'ятнадцятої та двадцятої статті 39 Закону України "Про вибори народних депутатів України" ( 1665-15 ) під час організації підготовки до проведення чергових виборів до Верховної Ради України складаються місцевий (районний, міський, районний у містах Києві та Севастополі) загальний список виборців, регіональний загальний список виборців - загальний список виборців, складений у межах відповідного регіону (Автономної Республіки Крим, областей, міст Києва та Севастополя), загальний список виборців, які проживають або перебувають за кордоном.

Частиною першою статті 41 Закону України "Про вибори народних депутатів України" ( 1665-15 ) передбачено, що після утворення виборчих дільниць робочі групи обліку виборців на основі відповідного уточненого загального списку виборців, зазначеного у частині тринадцятій статті 40 цього Закону ( 1665-15 ), складають списки виборців по кожній звичайній виборчій дільниці.

Водночас подальше застосування викладеного вище порядку складання загальних списків виборців на чергових виборах народних депутатів України здійснюватиметься на підставі Закону України "Про Державний реєстр виборців" ( 698-16 ), який набирає чинності з 1 жовтня 2007 року і містить відмінний від передбаченого чинним Законом України "Про вибори народних депутатів України" ( 1665-15 ) порядок складання списків виборців. Згідно з пунктом 3 розділу VII Закону України "Про Державний реєстр виборців" ( 698-16 ) після набрання ним чинності Закони України "Про вибори народних депутатів України" ( 1665-15 ), "Про вибори Президента України" ( 474-14 ), "Про вибори депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів" ( 1667-15 ), "Про всеукраїнський та місцеві референдуми" ( 1286-12 ) стосовно складання та уточнення списків виборців діють у частині, що не суперечить Закону України "Про Державний реєстр виборців" ( 698-16 ).

Разом із тим за частиною першою статті 102 Закону України "Про вибори народних депутатів України" ( 1665-15 ) підготовка та проведення позачергових виборів народних депутатів України, що призначаються Президентом України з підстав і в порядку, встановлених Конституцією України ( 254к/96-ВР ), здійснюється у порядку та в строки, встановлені названим Законом ( 1665-15 ), з урахуванням особливостей, установлених його статтями 102 та 102-1 - 102-6.

Так, відповідно до частин першої та четвертої статті 102-1 Закону України "Про вибори народних депутатів України" ( 1665-15 ) для проведення позачергових виборів народних депутатів України використовуються територіальні виборчі округи та звичайні і закордонні виборчі дільниці, утворені для проведення останніх виборів народних депутатів України. Згідно з частиною першою статті 102-3 зазначеного Закону ( 1665-15 ) складання списків виборців для позачергових виборів народних депутатів України здійснюється з використанням основних механізмів і процедур, визначених Законом України "Про Державний реєстр виборців" ( 698-16 ), у порядку і з особливостями, встановленими названою статтею. Частиною другою статті 102-3 Закону України "Про вибори народних депутатів України" ( 1665-15 ) визначено, що робочими групами обліку виборців, які утворюються районними, районними у містах Києві та Севастополі державними адміністраціями, виконавчими органами міських рад (міст республіканського в Автономній Республіці Крим, обласного значення) не пізніш як на п'ятий день з початку виборчого процесу позачергових виборів депутатів та діють до дня виборів включно, здійснюється складання списків виборців на звичайних виборчих дільницях. Відповідно до частини п'ятої вказаної статті Закону ( 1665-15 ) списки виборців на звичайних виборчих дільницях складаються робочими групами на підставі загальних списків виборців, наданих у встановленому законодавством порядку Центральною виборчою комісією, з використанням списків виборців на звичайних виборчих дільницях, на підставі яких проводилося голосування на останніх виборах народних депутатів України.

Отже, під час організації підготовки і проведення позачергових виборів народних депутатів України Законом України "Про вибори народних депутатів України" ( 1665-15 ) передбачено складання лише списків виборців на виборчих дільницях та взагалі не передбачено складання загальних списків виборців.

Таким чином, постановою Кабінету Міністрів України від 5 вересня 2007 року N 1097 ( 1097-2007-п ) визначено заходи щодо здійснення державного контролю за непередбаченою та нездійснюваною процедурою виборчого процесу.

Відтак, видавши постанову від 5 вересня 2007 року N 1097 ( 1097-2007-п ) "Про деякі заходи щодо здійснення державного контролю за дотриманням порядку складання загальних списків виборців", Кабінет Міністрів України діяв усупереч Закону України "Про вибори народних депутатів України" ( 1665-15 ) та у спосіб, що ним не передбачено. У зв'язку з цим названа постанова ( 1097-2007-п ) не відповідає нормам Конституції України ( 254к/96-ВР ), зокрема частини другої статті 6, за якою органи виконавчої влади зобов'язано здійснювати свої повноваження у встановлених Конституцією ( 254к/96-ВР ) межах і відповідно до законів України, частини другої статті 19, відповідно до якої органи державної влади зобов'язані діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України, та частини третьої статті 113 Основного Закону ( 254к/96-ВР ) держави, згідно з якою Кабінет Міністрів України керується у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 5 вересня 2007 року N 1097 ( 1097-2007-п ) "Про деякі заходи щодо здійснення державного контролю за дотриманням порядку складання загальних списків виборців", крім пункту 9 цієї постанови ( 1097-2007-п ).

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
