{ Розпорядження втратило чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про голову Комісії з встановлення пенсій за особливі заслуги перед Україною при Кабінеті Міністрів України

Затвердити Віце-прем'єр-міністра України Кириленка В'ячеслава Анатолійовича головою Комісії з встановлення пенсій за особливі заслуги перед Україною при Кабінеті Міністрів України ( 1578-2000-п ), увільнивши від цих обов'язків Томенка Миколу Володимировича.
