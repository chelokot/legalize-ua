УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 438/2010 ( 438/2010 ) від 23.03.2010 }

Про новий склад Української частини Підкомісії з питань функціонування Чорноморського флоту Російської Федерації та його перебування на території України Українсько-Російської міждержавної комісії

На часткову зміну статті 1 Указу Президента України від 5 травня 2008 року N 416 ( 416/2008 ) "Про оновлення складу українських частин робочих органів Українсько-Російської міждержавної комісії" затвердити новий персональний склад Української частини Підкомісії з питань функціонування Чорноморського флоту Російської Федерації та його перебування на території України Українсько-Російської міждержавної комісії (додається).
