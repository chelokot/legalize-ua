КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 грудня 2002 р. N 1911 Київ

Про затвердження переліку товарів промислового призначення, вивезення яких громадянами України, іноземцями та особами без громадянства за межі митної території України не допускається

( Із змінами, внесеними згідно з Постановою КМ N 92 ( 92-2003-п ) від 18.01.2003 )

Відповідно до статті 251 Митного кодексу України ( 92-15 ) Кабінет Міністрів України постановляє:

1. Затвердити перелік товарів промислового призначення, вивезення яких громадянами України, іноземцями та особами без громадянства за межі митної території України не допускається (додається).

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

3. Ця постанова набирає чинності з 1 січня 2004 року.

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 11 вересня 1996 р. N 1094 ( 1094-96-п ) "Про затвердження переліку предметів промислового призначення, що застосовуються у виробничій сфері, вивезення (пересилання) яких громадянами України, іноземцями та особами без громадянства за межі митної території України забороняється" (ЗП України, 1996 р., N 17, ст. 486).

2. Постанова Кабінету Міністрів України від 1 вересня 1997 р. N 954 ( 954-97-п ) "Про внесення доповнень до постанови Кабінету Міністрів України від 11 вересня 1996 р. N 1094" (Офіційний вісник України, 1997 р., число 36, с. 20).

3. Постанова Кабінету Міністрів України від 28 січня 2002 р. N 89 ( 89-2002-п ) "Про внесення доповнень до постанови Кабінету Міністрів України від 11 вересня 1996 р. N 1094" (Офіційний вісник України, 2002 р., N 5, ст. 191).

4. Пункт 4 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 11 жовтня 2002 р. N 1493 ( 1493-2002-п ) (Офіційний вісник України, 2002 р., N 42, ст. 1925).
