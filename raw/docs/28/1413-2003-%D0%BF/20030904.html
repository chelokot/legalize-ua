Кабінет Міністрів України; Постанова від 04.09.2003 № 1413

Про внесення зміни до переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку в Донецькій області, для яких встановлено спеціальний режим інвестиційної діяльності

Стан: Втратив чинність

Ідентифікатор: 1413-2003-п

Текст документа від 04.09.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 вересня 2003 р. N 1413 Київ

Про внесення зміни до переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку в Донецькій області, для яких встановлено спеціальний режим інвестиційної діяльності

Кабінет Міністрів України постановляє:

1. У переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку в Донецькій області, для яких встановлено спеціальний режим інвестиційної діяльності, затвердженому постановою Кабінету Міністрів України від 11 серпня 2000 р. N 1255 ( 1255-2000-п ) (Офіційний вісник України, 2000 р., N 33, ст. 1403; 2001 р., N 40, ст. 1801; 2002 р., N 21, ст. 1031), виключити позицію

"15.1 М'ясна промисловість (виключно з вітчизняної сировини)".

2. Дія цієї постанови не поширюється на суб'єкти підприємницької діяльності, які реалізують інвестиційні проекти у м'ясній промисловості, схвалені до набрання чинності цією постановою.

Прем'єр-міністр України В.ЯНУКОВИЧ
