Стан: Втратив чинність

Ідентифікатор: z0600-10

Текст документа від 23.12.2016:

НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

15.07.2010 N 817

Зареєстровано в Міністерстві юстиції України 3 серпня 2010 р. за N 600/17895

{ Постанова втратила чинність на підставі Постанови Національної комісії, що здійснює державне регулювання у сферах енергетики та комунальних послуг

N 2364 ( v2364874-16 ) від 23.12.2016 }

Про внесення змін до Умов та Правил здійснення підприємницької діяльності з постачання електричної енергії за нерегульованим тарифом

Відповідно до Закону України "Про електроенергетику" ( 575/97-ВР ), Указу Президента України від 14.03.95 N 213 ( 213/95 ) "Про заходи щодо забезпечення діяльності Національної комісії з питань регулювання електроенергетики України" (зі змінами) Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Унести до Умов та Правил здійснення підприємницької діяльності з постачання електричної енергії за нерегульованим тарифом, затверджених постановою НКРЕ від 12.08.96 N 36 ( z0448-96 ), зареєстрованих у Міністерстві юстиції України 14.08.96 за N 448/1473, такі зміни:

пункт 2.4 доповнити новим абзацом такого змісту:

"Ліцензіат повинен здійснювати купівлю-продаж електричної енергії з використанням даних, отриманих з автоматизованих систем комерційного обліку електричної енергії, відповідно до вимог Правил користування електричною енергією, затверджених постановою НКРЕ від 31.07.96 N 28 ( z0417-96 ), зареєстрованих у Міністерстві юстиції України 02.08.96 за N 417/1442, та Інструкції про порядок комерційного обліку електричної енергії ( va349227-98 ) (додаток 10 до Договору між членами Оптового ринку електроенергії) ( n0001227-96 )".

2. Ліцензіатам з постачання електричної енергії за нерегульованим тарифом привести свою діяльність у відповідність до вимог цієї постанови до 31 грудня 2010 року.

3. Управлінню інформаційних технологій забезпечити подання цієї постанови на державну реєстрацію до Міністерства юстиції України в установленому законодавством порядку.

4. Ця постанова набирає чинності з дня її офіційного опублікування.
