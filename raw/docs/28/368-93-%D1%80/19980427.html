Стан: Втратив чинність

Ідентифікатор: 368-93-р

Текст документа від 27.04.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 червня 1993 p. N 368-р Київ

Про затвердження коефіцієнтів співвідношення посадових окладів працівників секретаріату Національної ради соціального партнерства до мінімального розміру заробітної плати

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 551-р ( 551-95-р ) від 30.08.95 N 273-р ( 273-98-р ) від 27.04.98 }

1. На виконання Указу Президента України від 27 квітня 1993 р. N 151/93 "Про Національну раду соціального партнерства" затвердити коефіцієнти співвідношення посадових окладів працівників секретаріату Національної ради до мінімального розміру заробітної плати згідно з додатком.

2. Поширити на працівників секретаріату Національної ради соціального партнерства умови оплати праці (доплати, надбавки, преміювання, інші види матеріального стимулювання), затверджені постановою Кабінету Міністрів України від 21 січня 1993 р. N 35 ( 35-93-п ).

( Пункт 3 втратив чинність на підставі Розпорядження КМ N 273-р ( 273-98-р ) від 27.04.98 )

4. Мінфіну профінансувати витрати по забезпеченню діяльності Національної ради соціального партнерства в межах асигнувань, затверджених в державному бюджеті на 1993 рік на утримання органів державної виконавчої влади.

5. Прирівняти Керівника секретаріату Національної ради соціального партнерства за умовами матеріально-побутового забезпечення, медичного і транспортного обслуговування до голови державного комітету України.

{ Установити, що заступник Керівника і завідуючий протокольним відділом секретаріату Національної ради соціального партнерства за умовами матеріально-побутового забезпечення, медичного і транспортного обслуговування прирівнюються відповідно до заступника голови і начальника відділу державного комітету згідно з Розпорядженням КМ N 551-р ( 551-95-р ) від 30.08.95 }
