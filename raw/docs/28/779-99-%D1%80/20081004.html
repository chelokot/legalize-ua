Кабінет Міністрів України; Розпорядження від 03.08.1999 № 779-р

Про зміни у складі міжвідомчої координаційної ради з підготовки і реалізації проекту "Гарантії від некомерційних ризиків у сфері високих технологій та промислової конверсії", утвореної розпорядженням Кабінету Міністрів України від 27 травня 1999 р. N 507

Стан: Втратив чинність

Ідентифікатор: 779-99-р

Текст документа від 04.10.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 серпня 1999 р. N 779-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 871 ( 871-2008-п ) від 01.10.2008 }

N 507 ( 507-99-р ), Єфіменка Леоніда Васильовича - заступника Міністра юстиції.
