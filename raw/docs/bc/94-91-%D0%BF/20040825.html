Стан: Втратив чинність

Текст документа від 25.08.2004:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 15 квітня 1991 р. N 94 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1109 ( 1109-2004-п ) від 25.08.2004 )

Про заходи щодо забезпечення нормальної роботи телебачення і радіо

( Із змінами, внесеними згідно з Постановою КМ N 386 ( 386-94-п ) від 11.06.94 )

У зв'язку з тим, що останнім часом почастішали випадки незаконних вимог окремих громадян і організацій щодо позапрограмного надання прямого ефіру, а також інші протиправні дії, які заважають нормальному функціонуванню телебачення і радіо, Рада Міністрів Української РСР постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 386 ( 386-94-п ) від 11.06.94 )

2. Міністерству внутрішніх справ УРСР забезпечити належну охорону приміщень Державного комітету УРСР по телебаченню і радіомовленню для нормального функціонування його творчих і технічних підрозділів, використовуючи всю повноту повноважень у межах чинного законодавства.

Заступник Голови
