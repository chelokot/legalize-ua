Верховна Рада України; Постанова від 28.12.2007 № 101-VI

Про призначення позачергових виборів Білоріченського селищного голови (Білоріченська селищна рада Лутугинського району Луганської області)

Стан: Чинний

Ідентифікатор: 101-17

Текст документа від 20.03.2008:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про призначення позачергових виборів Білоріченського селищного голови (Білоріченська селищна рада Лутугинського району Луганської області)

( Відомості Верховної Ради України (ВВР), 2008, N 9, ст.94 )

{ Із змінами, внесеними згідно з Постановою ВР N 158-VI ( 158-17 ) від 20.03.2008, ВВР, 2008, N 15, ст.127 }

{ У назві та тексті Постанови слова "Білорічненського", "Білорічненська" замінено відповідно словами "Білоріченського", "Білоріченська" згідно з Постановою ВР N 158-VI ( 158-17 ) від 20.03.2008 }

У зв'язку з достроковим припиненням повноважень Білоріченського селищного голови Нечипоренка М.Б. (Білоріченська селищна рада Лутугинського району Луганської області) та відповідно до пункту 30 частини першої статті 85 Конституції України ( 254к/96-ВР ), частини третьої статті 14, частин другої та шостої статті 15, статей 82, 83 Закону України "Про вибори депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів" ( 1667-15 ) Верховна Рада України постановляє:

1. Призначити позачергові вибори Білоріченського селищного голови (Білоріченська селищна рада Лутугинського району Луганської області) на неділю 16 березня 2008 року.

2. Центральній виборчій комісії з урахуванням пропозицій відповідної територіальної виборчої комісії визначити обсяг бюджетних видатків, необхідних для проведення позачергових виборів Білорічненського селищного голови.

3. Кабінету Міністрів України в межах повноважень вжити невідкладних заходів щодо забезпечення фінансування позачергових виборів Білоріченського селищного голови за рахунок коштів цільової субвенції з Державного бюджету України ( 107-17 ).

4. Ця Постанова набирає чинності з дня її опублікування.
