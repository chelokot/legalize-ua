КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 березня 1994 р. N 146 Київ

{ Дію Постанови відновлено згідно з Постановою КМ N 775 ( 775-94-п ) від 16.11.94 }

{ Постанова втратила чинність на підставі Постанови КМ N 734 ( 734-94-п ) від 24.10.94 }

Про внесення змін до постанови Кабінету Міністрів України від 17 грудня 1993 р. N 1046

{ Із змінами, внесеними згідно з Постановою КМ N 180 ( 180-2013-п ) від 13.03.2013 }

З метою посилення тарифного регулювання поставок товарів за імпортом, захисту економічних інтересів вітчизняних товаровиробників Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. Призупинити дію додатка N 3 до постанови Кабінету Міністрів України від 17 грудня 1993 р. N 1046 ( 1046-93-п ) "Про перелік товарів, експорт та імпорт яких підлягає квотуванню і ліцензуванню у 1994 році".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }
