ПОСТАНОВА від 2 квітня 2002 р. N 454 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про внесення змін до структури Секретаріату Кабінету Міністрів України

У зв'язку з введенням єдиної автоматизованої системи обліку та контролю документації Кабінет Міністрів України постановляє:

Утворити в структурі Секретаріату Кабінету Міністрів України, затвердженій постановою Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) (Офіційний вісник України, 2000 р., N 4, ст. 110), Департамент діловодства та моніторингу замість Управління діловодства і Управління моніторингу, що ліквідуються.

Прем'єр-міністр України А.КІНАХ
