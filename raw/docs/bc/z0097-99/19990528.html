ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 38 від 27.01.99 Зареєстровано в Міністерстві м.Київ юстиції України 15 лютого 1999 р. за N 97/3390

Про внесення змін та доповнень до нормативних актів Національного банку України

( Із змінами, внесеними згідно з Постановами Нацбанку N 127 ( z0171-99 ) від 18.03.99 N 136 ( z0338-99 ) від 24.03.99 )

На виконання вимог Указу Президента України від 06.11.98 N 1222/98 "Про гербовий збір" Правління ПОСТАНОВЛЯЄ:

1. Внести зміни та доповнення до таких нормативних актів Національного банку України:

( Пункт 1.1 втратив чинність на підставі Постанови Нацбанку N 136 ( z0338-99 ) від 24.03.99 ) 1.1. Пункт 4 Загальних положень Інструкції про порядок розрахунків в іноземній валюті за експортно-імпортними операціями на умовах відстрочки платежів чи поставок, затвердженої наказом Національного банку України від 14.06.94 N 85 ( v0085500-94, ), із змінами та доповненнями, доповнити абзацом такого змісту:

"Відповідно до вимог Указу Президента України від 06.11.98 за N 1222/98 "Про гербовий збір" та актів законодавства України здійснюється маркування усіх оригіналів договорів, установчих документів та векселів суб'єктів підприємницької діяльності".

1.2. Порядок про застосування іноземної валюти в страховій діяльності, затверджений постановою Правління від 23.09.96 N 245 ( v0391500-96 ), із змінами, доповнити пунктом 3 такого змісту:

"Відповідно до вимог Указу Президента України від 06.11.98 за N 1222/98 "Про гербовий збір" та актів законодавства України здійснюється маркування усіх оригіналів договорів, установчих документів та векселів суб'єктів підприємницької діяльності".

1.3. Розділ 3 Положення про впровадження пластикових карток міжнародних платіжних систем у розрахунках за товари, надані послуги та при видачі готівки, затвердженого постановою Правління від 24.02.97 N 37 ( z0086-97 ), зареєстроване в Міністерстві юстиції України 24.03.97 за N 86/1890, із змінами і доповненнями, доповнити пунктом 3.7 такого змісту:

"Відповідно до вимог Указу Президента України від 06.11.98 за N 1222/98 "Про гербовий збір" та актів законодавства України здійснюється маркування усіх оригіналів договорів, установчих документів та векселів суб'єктів підприємницької діяльності".

1.4. Підпункт 4.4 пункту 4 Правил використання готівкової іноземної валюти на території України, затверджених постановою Правління від 26.03.98 N 119 ( z0245-98 ), зареєстрованих в Міністерстві юстиції України 15.04.98 за N 245/2635, доповнити абзацом такого змісту:

"Відповідно до вимог Указу Президента України від 06.11.98 за N 1222/98 "Про гербовий збір" та актів законодавства України здійснюється маркування усіх оригіналів договорів, установчих документів та векселів суб'єктів підприємницької діяльності".

1.5. Розділ 2 Положення про відкриття та функціонування в уповноважених банках України рахунків банків-кореспондентів в іноземній валюті та в гривнях, затвердженого постановою Правління від 26.03.98 N 118 ( z0231-98 ), зареєстрованого в Міністерстві юстиції України 10.04.98 за N 231/2671, із змінами і доповненнями, доповнити пунктом 2.6 такого змісту:

"Відповідно до вимог Указу Президента України від 06.11.98 за N 1222/98 "Про гербовий збір" та актів законодавства України здійснюється маркування усіх оригіналів договорів, установчих документів та векселів суб'єктів підприємницької діяльності".

( Пункт 1.6 втратив чинність на підставі Постанови Нацбанку N 127 ( z0171-99 ) від 18.03.99 ) 1.6. Розділ 2 Правил здійснення операцій на міжбанківському валютному ринку України, затвердженого постановою Правління від 15.04.98 N 150 ( z0407-98 ), зареєстрованого в Міністерстві юстиції України 30.06.98 за N 407/2847, зі змінами і доповненнями, доповнити пунктом 2.8 такого змісту:

"Відповідно до вимог Указу Президента України від 06.11.98 за N 1222/98 "Про гербовий збір" та актів законодавства України здійснюється маркування усіх оригіналів договорів, установчих документів та векселів суб'єктів підприємницької діяльності".

1.7. Доповнити пункт 1 Положення про порядок реєстрації одержання резидентами кредитів в іноземній валюті від іноземних кредиторів, затвердженого постановою Правління від 07.05.97 N 144 ( v0442500-97, v1549500-98 ), із змінами, абзацом четвертим такого змісту:

"Відповідно до вимог Указу Президента України від 06.11.98 за N 1222/98 "Про гербовий збір" та актів законодавства України здійснюється маркування усіх оригіналів угод з нерезидентом".

2. Постанова набуває чинності через десять днів після її державної реєстрації в Міністерстві юстиції України.
