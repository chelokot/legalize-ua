( Указ втратив чинність на підставі Указу Президента N 583/2000 від 11.04.2000 )

Про зміни у складі Комісії по державних нагородах України при Президентові України

1. Вивести зі складу Комісії по державних нагородах України при Президентові України ( 747/94 ) ЛОПАТУ Анатолія Васильовича у зв'язку з переходом на іншу роботу.

2. Ввести до складу Комісії по державних нагородах України при Президентові України Начальника Генерального штабу Збройних Сил України - першого заступника Міністра оборони України, генерал-лейтенанта ЗАТИНАЙКА Олександра Івановича.
