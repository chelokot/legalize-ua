Текст документа від 29.01.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2001 р. N 1488 Київ

Про затвердження нового складу Міжвідомчої комісії з міжнародної торгівлі

( Із змінами, внесеними згідно з Постановами КМ N 1335 ( 1335-2002-п ) від 12.09.2002 N 124 ( 124-2003-п ) від 29.01.2003 )

Кабінет Міністрів України постановляє:

1. Затвердити новий склад Міжвідомчої комісії з міжнародної торгівлі (додається).

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України від 28 квітня 2000 р. N 729 ( 729-2000-п ) "Про затвердження нового складу Міжвідомчої комісії з міжнародної торгівлі" та від 18 січня 2001 р. N 23 ( 23-2001-п ) "Про внесення змін до складу Міжвідомчої комісії з міжнародної торгівлі".
