Текст документа від 03.08.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 липня 1996 р. N 767 Київ

Про реалізацію Конвенції ООН про права дитини, Всесвітньої декларації про забезпечення виживання, захисту і розвитку дітей, Національної програми "Діти України" та підготовку щорічної державної доповіді про становище дітей в Україні

( Із змінами, внесеними згідно з Постановою КМ N 176 ( 176-98-п ) від 16.02.98 )

( Постанова втратила чинність, крім абзацу першого пункту 1, на підставі Постанови КМ N 1200 ( 1200-2000-п ) від 03.08.2000 )

Кабінет Міністрів України постановляє:

1. Утворити Міжвідомчу комісію з питань охорони дитинства та Національної програми "Діти України" ( 63/96 ) (далі - Комісія). ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1200 ( 1200-2000-п ) від 03.08.2000 )
