Кабінет Міністрів України; Розпорядження від 14.08.1999 № 817-р

Про здійснення митного оформлення дизельного пального, що імпортується ДАК "Укрресурси"

Стан: Втратив чинність

Ідентифікатор: 817-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 серпня 1999 р. N 817-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

З метою прискорення розрахунків та оптимізації використання коштів, які надходять на оплату дизельного пального, що закуповується згідно з постановою Кабінету Міністрів України від 5 липня 1999 р. N 1191 ( 1191-99-п ) "Про забезпечення потреб сільськогосподарських товаровиробників у пальному для проведення збиральних та осінньо-польових робіт у 1999 році", дозволити, як виняток, Держмитслужбі здійснювати митне оформлення дизельного пального, що імпортується ДАК "Укрресурси", із сплатою податку на додану вартість та акцизного збору шляхом видачі простих векселів без банківського авалю.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
