Кабінет Міністрів України; Постанова, Порядок від 07.03.2007 № 405

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для надання допомоги біженцям

Стан: Чинний

Ідентифікатор: 405-2007-п

Текст документа від 23.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 березня 2007 р. N 405 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для надання допомоги біженцям

{ Установити, що кошти, передбачені у державному бюджеті ( 107-17 ) для надання допомоги біженцям, використовуються у 2008 році відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 135 ( 135-2008-п ) від 05.03.2008 }

{ Установити, що кошти, передбачені у державному бюджеті ( 835-17 ) для надання допомоги біженцям, використовуються у 2009 році відповідно до Порядку, затвердженого цією Постановою, з урахуванням того, що закупівля товарів, робіт і послуг за бюджетні кошти здійснюється в установленому законодавством порядку, згідно з Постановою КМ N 216 ( 216-2009-п ) від 18.03.2009 }

{ Установити, що у 2010 році кошти, передбачені у державному бюджеті ( 2154-17 ) для надання допомоги біженцям, використовуються відповідно до Порядку, затвердженого цією Постановою, з урахуванням особливостей, зазначених в Постанові КМ N 579 ( 579-2010-п ) від 14.07.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для надання допомоги біженцям, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 березня 2007 р. N 405

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для надання допомоги біженцям

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Держкомнацрелігій для надання допомоги біженцям (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються на:

створення та утримання пунктів тимчасового розміщення біженців (далі - пункти), зокрема на оплату праці працівників та витрат, пов'язаних з їх відрядженням, створення умов для перебування біженців (придбання продуктів харчування, білизни, предметів першої необхідності, товарів культурно-побутового та господарського призначення), оплату комунальних послуг, послуг зв'язку та послуг, пов'язаних з охороною і утриманням автотранспортних засобів, проведення робіт з будівництва і реконструкції пунктів;

ведення централізованого обліку та створення бази даних про осіб, що подали заяву про надання їм статусу біженця, та забезпечення її функціонування;

надання матеріальної допомоги біженцям;

виготовлення документів, що посвідчують особу біженця;

транспортування біженців з органів міграційної служби до пунктів;

забезпечення перекладу звернень біженців та інформації про країни їх походження.

3. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

4. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

5. Держкомнацрелігій затверджує план заходів щодо використання бюджетних коштів разом з поквартальними результативними показниками їх виконання та подає його у двотижневий строк Мінфіну.

Інформацію про виконання поквартальних результативних показників Держкомнацрелігій подає Мінфіну в тижневий строк після завершення звітного кварталу та за результатами виконання показників за одинадцять місяців.

Держкомнацрелігій проводить щокварталу аналіз відповідності виконання зазначених показників обсягам фінансування, про результати якого інформує у триденний строк Мінфін.

6. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
