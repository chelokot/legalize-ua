МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

13.07.2009 N 267

Зареєстровано в Міністерстві юстиції України 29 липня 2009 р. за N 710/16726

Про внесення змін до наказу Міністерства праці та соціальної політики України від 05.04.2006 N 104

На виконання пункту 2 постанови Кабінету Міністрів України від 20.05.2009 N 482 ( 482-2009-п ) "Деякі питання оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів, що фінансуються з бюджету" та з метою впорядкування умов оплати праці працівників центрів соціальних служб для сім'ї, дітей та молоді НАКАЗУЮ:

1. Пункт 1 наказу Міністерства праці та соціальної політики України від 05.04.2006 N 104 ( z0424-06 ) "Про умови оплати праці працівників центрів соціальних служб для сім'ї, дітей та молоді", зареєстрованого в Міністерстві юстиції України 12.04.2006 за N 424/12298 (зі змінами), доповнити новим абзацом другим такого змісту:

"Установити, що у разі, коли розміри посадових окладів працівників, зазначені у додатках 1-7, нижчі ніж визначений законом розмір мінімальної заробітної плати, посадові оклади установлюються на рівні відповідного розміру мінімальної заробітної плати.".

2. Директору департаменту з питань державного регулювання заробітної плати та умов праці Товстенку О.П. у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності з дня його офіційного опублікування.
