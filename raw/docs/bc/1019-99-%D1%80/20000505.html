Кабінет Міністрів України; Розпорядження від 27.09.1999 № 1019-р

Про здійснення митного оформлення технологічного обладнання, що надходитиме на адресу ВАТ "Бориславська фабрика клеєних нетканих матеріалів"

Стан: Втратив чинність

Ідентифікатор: 1019-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 вересня 1999 р. N 1019-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення технологічного обладнання, що надходитиме на адресу ВАТ "Бориславська фабрика клеєних нетканих матеріалів" (м. Борислав Львівської області) для власних виробничих потреб, як товарів критичного імпорту відповідно до укладеного ним з фірмою "Textima Export Import GmbH" (Берлін) договору від 20 грудня 1997 р. N 97 013 06 (з доповненням N 1 та додатками 1 - 3).

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
