КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 березня 2008 р. N 444-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про затвердження нового складу комісії з розроблення пропозицій щодо удосконалення системи державного управління в інноваційній сфері

На часткову зміну абзацу першого пункту 1 розпорядження Кабінету Міністрів України від 28 листопада 2007 р. N 1064 ( 1064-2007-р ) "Про утворення комісії з розроблення пропозицій щодо удосконалення системи державного управління в інноваційній сфері" затвердити новий склад зазначеної комісії, що додається.
