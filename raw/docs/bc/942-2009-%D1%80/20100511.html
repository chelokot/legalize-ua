{ Розпорядження втратило чинність на підставі Постанови КМ N 328 ( 328-2010-п ) від 21.04.2010 }

Про зміну складу Міжвідомчої комісії з міжнародної торгівлі

Увести до складу Міжвідомчої комісії з міжнародної торгівлі, затвердженого постановою Кабінету Міністрів України від 17 квітня 2008 р. N 384 ( 384-2008-п ), Рогача Олександра Пантелеймоновича - начальника департаменту СБУ, Митника Зіновія Миколайовича - заступника Міністра охорони здоров'я, вивівши з її складу Репіна Юрія Івановича, Пятницького Валерія Тезійовича.

У складі Міжвідомчої комісії з міжнародної торгівлі зазначити посаду Ференс Олени Миколаївни:

"директор департаменту Мін'юсту".
