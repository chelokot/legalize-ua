Про форми протоколів територіальних виборчих комісій про підсумки голосування та результати виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів

Стан: Втратив чинність

ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

ПОСТАНОВА

13.10.2010 N 405

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 477 ( v0477359-14 ) від 05.05.2014 }

Про форми протоколів територіальних виборчих комісій про підсумки голосування та результати виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів

Відповідно до пункту 4 частини першої статті 24, частини тринадцятої статті 27, частин чотирнадцятої - дев'ятнадцятої статті 75, частин першої, третьої статті 76, частин першої, дев'ятої - одинадцятої статті 77 Закону України "Про вибори депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів" ( 2487-17 ), керуючись статтями 11-13, пунктом 7 статті 21 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Встановити форми протоколів:

територіальної виборчої комісії про підсумки голосування в багатомандатному виборчому окрузі з виборів депутатів Верховної Ради Автономної Республіки Крим (додаток 1) ( va405359-10 );

територіальної виборчої комісії про підсумки голосування в одномандатному мажоритарному виборчому окрузі з виборів депутатів Верховної Ради Автономної Республіки Крим (додаток 2) ( va405359-10 );

територіальної виборчої комісії про підсумки голосування в багатомандатному виборчому окрузі з виборів депутатів обласної, районної, міської, районної в місті ради (додаток 3) ( va405359-10 );

територіальної виборчої комісії про підсумки голосування в одномандатному мажоритарному виборчому окрузі з виборів депутатів обласної, районної, міської, районної в місті ради (додаток 4) ( va405359-10 );

територіальної виборчої комісії про підсумки голосування в одномандатному виборчому окрузі з виборів депутатів сільської, селищної ради (додаток 5) ( va405359-10 );

територіальної виборчої комісії про підсумки голосування в одномандатному виборчому окрузі з виборів сільського, селищного, міського голови (додаток 6) ( va405359-10 );

виборчої комісії Автономної Республіки Крим про результати виборів депутатів Верховної Ради Автономної Республіки Крим у багатомандатному виборчому окрузі (додаток 7) ( va405359-10 );

виборчої комісії Автономної Республіки Крим про результати виборів депутатів Верховної Ради Автономної Республіки Крим в одномандатному мажоритарному виборчому окрузі (додаток 8) ( va405359-10 );

обласної, районної, міської, районної в місті виборчої комісії про результати виборів депутатів обласної, районної, міської, районної в місті ради в багатомандатному виборчому окрузі (додаток 9) ( va405359-10 );

обласної, районної, міської, районної в місті виборчої комісії про результати виборів депутатів обласної, районної, міської, районної в місті ради в одномандатному мажоритарному виборчому окрузі (додаток 10) ( va405359-10 );

сільської, селищної виборчої комісії про результати виборів депутатів сільської, селищної ради в одномандатному виборчому окрузі (додаток 11) ( va405359-10 );

сільської, селищної, міської виборчої комісії про результати виборів в одномандатному виборчому окрузі з виборів сільського, селищного, міського голови (додаток 12) ( va405359-10 ).

2. Визнати такою, що втратила чинність, постанову Центральної виборчої комісії від 19 травня 2008 року N 28 ( v0028359-08 ) "Про форми протоколів територіальних виборчих комісій, що здійснюють підготовку та проведення виборів депутатів місцевих рад, сільських, селищних, міських голів".

3. Цю постанову надіслати Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям для доведення до відома територіальних виборчих комісій.
