КАБІНЕТ МІНІСТРІВ УКРАЇНИ
РОЗПОРЯДЖЕННЯ

від 18 червня 2014 р. № 573-р
Київ

Про внесення зміни до пункту 1 розпорядження Кабінету Міністрів України від 21 травня 2014 р. № 528

Внести зміну до пункту 1 розпорядження Кабінету Міністрів України від 21 травня 2014 р. № 528 “Про виділення коштів для здійснення невідкладних заходів з ліквідації наслідків надзвичайної ситуації, що склалася 12 травня 2014 р. в житловому будинку по вул. Лазурній, 40, у м. Миколаєві”, виклавши абзац другий у такій редакції:

“2150 тис. гривень - для надання постраждалим грошової допомоги з метою розв’язання соціально-побутових проблем з розрахунку по 10 тис. гривень кожній особі;”.

Прем'єр-міністр України

А.ЯЦЕНЮК

Інд. 70
