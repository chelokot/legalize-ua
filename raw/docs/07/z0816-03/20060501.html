{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 134 ( z0460-06 ) від 14.04.2006 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 03.11.2000 N 299

На виконання постанови Кабінету Міністрів України від 06.08.2003 N 1207 ( 1207-2003-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 03.11.2000 N 299 ( z0844-00 ) "Про умови оплати праці працівників Комітету з Державних премій України в галузі науки і техніки", зареєстрованого в Міністерстві юстиції України 21.11.2000 за N 844/5065, виклавши додаток у новій редакції (додається).

2. Ці умови набирають чинності з 1 вересня 2003 року.

Міністр М.Папієв

Додаток до наказу Міністерства праці та соціальної політики України 03.11.2000 N 299 ( z0844-00 ) (у редакції наказу Міністерства праці та соціальної політики України від 02.09.2003 N 247)
