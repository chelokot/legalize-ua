Текст документа від 05.06.2012:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до деяких указів Президента України

{ Із змінами, внесеними згідно з Указом Президента N 347/2012 ( 347/2012 ) від 24.05.2012 }

Внести до указів Президента України такі зміни:

1. В абзацах другому та третьому пункту 8 Концепції переходу Збройних Сил України до комплектування військовослужбовцями контрактної служби на період до 2015 року, схваленої Указом Президента України від 7 квітня 2001 року N 239 ( 239/2001 ), слово "об'єднань" виключити.

{ Стаття 2 втратила чинність на підставі Указу Президента N 347/2012 ( 347/2012 ) від 24.05.2012 }

3. У пункті 30 Воєнної доктрини України, затвердженої Указом Президента України від 15 червня 2004 року N 648 ( 648/2004 ), слово "об'єднань" виключити.

4. У пункті 5 Положення про проходження громадянами України служби у військовому резерві Збройних Сил України, затвердженого Указом Президента України від 1 лютого 2007 року N 66 ( 66/2007 ), слово "об'єднань" виключити.

5. В абзаці четвертому статті 2 Указу Президента України від 4 червня 2008 року N 516 ( 516/2008 ) "Про деякі питання здійснення керівництва у сферах національної безпеки і оборони" слово "об'єднань" виключити.

6. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
