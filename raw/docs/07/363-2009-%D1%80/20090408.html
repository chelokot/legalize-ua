Про затвердження складу експертно-апеляційної ради при Держкомпідприємництві

1. Затвердити склад експертно-апеляційної ради при Держкомпідприємництві, що додається.

Надати голові експертно-апеляційної ради право вносити у разі потреби зміни до її складу.

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 28 листопада 2003 р. N 692 ( 692-2003-р ) "Про затвердження нового складу експертно-апеляційної ради при Держпідприємництві" (Офіційний вісник України, 2003 р., N 47, ст. 2446);

розпорядження Кабінету Міністрів України від 6 серпня 2008 р. N 1087 ( 1087-2008-р ) "Про затвердження нового складу експертно-апеляційної ради при Держкомпідприємництві" (Офіційний вісник України, 2008 р., N 60, ст. 2040).
