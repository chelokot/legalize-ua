Зареєстровано в Міністерстві юстиції України 28 грудня 2004 р. за N 1658/10257

Про втрату чинності наказу Міністерства освіти України від 07.04.94 N 94

З метою реалізації постанови Кабінету Міністрів України від 12.03.2003 N 305 ( 305-2003-п ) "Про затвердження Положення про дошкільний навчальний заклад" та у зв'язку з прийняттям Міністерством освіти і науки України наказу від 24.04.2003 N 257 ( v0257290-03 ) "Про затвердження Примірного статуту дошкільного навчального закладу" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства освіти України від 07.04.94 N 94 ( z0075-94 ) "Про затвердження Типового статуту дошкільного виховного закладу", зареєстрований у Міністерстві юстиції України 19.04.94 за N 75/284.

2. Контроль за виконанням наказу покласти на заступника Міністра Огнев'юка В.О.

Міністр В.Г.Кремень
