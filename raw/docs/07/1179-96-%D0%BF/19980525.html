КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 вересня 1996 р. N 1179 Київ

( Постанова втратила чинність на підставі Постанови КМ N 755 ( 755-98-п ) від 25.05.98 )

Про внесення змін до постанови Кабінету Міністрів України від 11 червня 1996 р. N 637

Кабінет Міністрів України постановляє:

На часткову зміну додатку N 1 до постанови Кабінету Міністрів України від 11 червня 1996 р. N 637 ( 637-96-п ) затвердити граничну чисельність працівників центрального апарату Національного космічного агентства у кількості 67 одиниць, в тому числі заступників генерального директора - 3.
