Про доповнення до Положення про порядок надання безпроцентної позики безробітним для заняття підприємницькою діяльністю

Реєстрація: Мін'юст України від 18.08.1994 № 199/409

Стан: Втратив чинність

Ідентифікатор: z0199-94

Текст документа від 27.07.1998:

МІНІСТЕРСТВО ПРАЦІ УКРАЇНИ

НАКАЗ

N 46 від 16.08.94 Зареєстровано в Міністерстві м.Київ юстиції України 18 серпня 1994 р. за N 199/409

( Наказ втратив чинність на підставі Наказу Мінпраці та соцполітики N 127 ( z0477-98 ) від 08.07.98 )

Про доповнення до Положення про порядок надання безпроцентної позики безробітним для заняття підприємницькою діяльністю

Міністерство праці України НАКАЗУЄ:

1. В Положенні про надання безпроцентної позики безробітним для заняття підприємницькою діяльністю, що затверджене наказом Міністерства праці України від 26 липня 1993 р. N 54 ( z0119-93 ), доповнити пункт 3.6 після слів "(зобов'язання гаранта)" словами "які повинні бути нотаріально посвідчені".

Міністр М.Г.Каскевич
