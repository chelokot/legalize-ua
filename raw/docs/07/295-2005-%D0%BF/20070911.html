Текст документа від 11.09.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 квітня 2005 р. N 295 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1112 ( 1112-2007-п ) від 11.09.2007 - дію Постанови зупинено згідно з Указом Президента N 876/2007 ( 876/2007 ) від 17.09.2007 }

Про утворення Державного департаменту адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів

Кабінет Міністрів України постановляє:

1. Утворити у складі Міністерства оборони на базі Національного координаційного центру адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів, що ліквідується, Державний департамент адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів як урядовий орган державного управління.

2. Не для друку. ( Вносить зміни до Постанови КМ N 389 ( 389-2004-п ) від 26.03.2004 )

3. Міністерству оборони:

подати Кабінетові Міністрів у двомісячний строк на затвердження проект Положення про Державний департамент адаптації військовослужбовців, звільнених у запас або відставку, та конверсії колишніх військових об'єктів;

забезпечити фінансування діяльності Державного департаменту у межах призначень, передбачених Міністерству у державному бюджеті на відповідний рік.
