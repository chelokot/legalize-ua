КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 лютого 2006 р. N 121 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 954 ( 954-2008-п ) від 22.10.2008 }

Про внесення змін у додаток 1 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314

Кабінет Міністрів України постановляє:

Внести у додаток 1 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314 ( 314-2001-п ) "Про встановлення ліміту легкових автомобілів, що обслуговують державні органи" (Офіційний вісник України, 2001 р., N 14, ст. 602; 2002 р., N 23, ст. 1090; 2004 р., N 18, ст. 1284) такі зміни:

доповнити додаток після позиції "Мін'юст" такою позицією:

"Мінбуд 8";

виключити такі позиції:

"Державний комітет з будівництва та архітектури 5

Держжитлокомунгосп 6".
