Кабінет Міністрів України; Постанова від 12.12.2002 № 1882

Про встановлення норм ввезення (вивезення) алкогольних напоїв і тютюнових виробів для споживання членами екіпажу та пасажирами на борту транспортного засобу, який здійснює міжнародний рейс і прибуває на митну територію України

Стан: Втратив чинність

Ідентифікатор: 1882-2002-п

Текст документа від 01.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 грудня 2002 р. N 1882 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 445 ( 445-2012-п ) від 21.05.2012 }

Про встановлення норм ввезення (вивезення) алкогольних напоїв і тютюнових виробів для споживання членами екіпажу та пасажирами на борту транспортного засобу, який здійснює міжнародний рейс і прибуває на митну територію України

( Із змінами, внесеними згідно з Постановою КМ N 92 ( 92-2003-п ) від 18.01.2003 )

Відповідно до статті 118 Митного кодексу України ( 92-15 ) Кабінет Міністрів України постановляє:

1. Установити, що на борту транспортного засобу, який здійснює міжнародний рейс і прибуває на митну територію України, дозволяється ввозити (вивозити) алкогольні напої і тютюнові вироби для споживання членами екіпажу та пасажирами з розрахунку споживання однією особою на добу за нормами:

алкогольні напої - 1 літр;

тютюнові вироби - 40 грамів.

2. Уповноважити Державну митну службу надавати роз'яснення щодо застосування цієї постанови.

3. Ця постанова набирає чинності з 1 січня 2004 року.

( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 92 ( 92-2003-п ) від 18.01.2003 )
