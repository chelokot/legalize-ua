1. Внести до актів Кабінету Міністрів України зміни, що додаються.

2. Постанова Кабінету Міністрів України від 21 грудня 1998 р. N 2027 ( 2027-98-п ) "Про утворення в системі органів Міністерства юстиції служби громадянства та реєстрації фізичних осіб" (Офіційний вісник України, 1998 р., N 51, ст. 1888).

3. Розпорядження Кабінету Міністрів України від 20 листопада 1999 р. N 1257 ( 1257-99-р ) (Офіційний вісник України, 1999 р., N 47, ст. 2312).

5. Постанова Кабінету Міністрів України від 26 травня 2005 р. N 390 ( 390-2005-п ) "Про утворення Державного департаменту у справах релігій" (Офіційний вісник України, 2005 р., N 22, ст. 1209).

6. Постанова Кабінету Міністрів України від 8 листопада 2006 р. N 1575 ( 1575-2006-п ) "Про утворення Державного комітету України у справах національностей та релігій" (Офіційний вісник України, 2006 р., N 45, ст. 3019).

8. Постанова Кабінету Міністрів України від 19 вересня 2007 р. N 1143 ( 1143-2007-п ) "Про затвердження Типового регламенту центрального органу виконавчої влади" (Офіційний вісник України, 2007 р., N 71, ст. 2681).

10. Розпорядження Кабінету Міністрів України від 28 травня 2008 р. N 774 ( 774-2008-р ) "Про внесення змін до розпорядження Кабінету Міністрів України від 20 листопада 1999 р. N 1257 та визнання таким, що втратило чинність, розпорядження Кабінету Міністрів України від 8 лютого 2006 р. N 76" (Офіційний вісник України, 2008 р., N 39, ст. 1304).
