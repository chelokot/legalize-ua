ПОСТАНОВА від 23 грудня 2006 р. N 1792 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 323 ( 323-2016-п ) від 05.05.2016 }

Про умови оплати праці керівника Апарату Прем'єр-міністра України, його першого заступника та заступників

Кабінет Міністрів України постановляє:

1. Установити починаючи з 18 жовтня 2006 року:

посадові оклади у відсотках посадового окладу Прем'єр-міністра України: керівнику Апарату Прем'єр-міністра України - 85, першому заступнику керівника Апарату - 77, заступнику керівника Апарату - 75 відсотків;

інші умови оплати праці керівника Апарату Прем'єр-міністра України визначаються на рівні першого заступника Міністра Кабінету Міністрів України, першого заступника, заступника керівника Апарату Прем'єр-міністра України - на рівні заступника Міністра Кабінету Міністрів України.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 20 липня 2005 р. N 597 ( 597-2005-п ) "Про умови оплати праці Керівника Служби Прем'єр-міністра України" (Офіційний вісник України, 2005 р., N 29, ст. 1717).
