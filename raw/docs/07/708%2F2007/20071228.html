Президент України; Указ від 15.08.2007 № 708/2007

Про зупинення дії постанов Кабінету Міністрів України від 21 березня 2007 року N 482, N 483, від 25 липня 2007 року N 971 та розпоряджень Кабінету Міністрів України від 12 травня 2007 року N 294-р, від 23 травня 2007 року N 331-р

Стан: Втратив чинність

Ідентифікатор: 708/2007

Текст документа від 28.12.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1308/2007 ( 1308/2007 ) від 28.12.2007 }

Про зупинення дії постанов Кабінету Міністрів України від 21 березня 2007 року N 482, N 483, від 25 липня 2007 року N 971 та розпоряджень Кабінету Міністрів України від 12 травня 2007 року N 294-р, від 23 травня 2007 року N 331-р

{ Додатково див. Конституційне подання Президента ( n0017100-07 ) від 15.08.2007 }

Кабінетом Міністрів України видано постанови від 21 березня 2007 року N 482 ( 482-2007-п ) "Про звільнення Гайдука О.В. з посади Голови Національної комісії з питань регулювання зв'язку України", N 483 ( 483-2007-п ) "Про призначення Звєрєва В.П. Головою Національної комісії з питань регулювання зв'язку України" та розпорядження від 12 травня 2007 року N 294-р ( 294-2007-р ) "Про звільнення Апасова С.І. з посади члена Національної комісії з питань регулювання зв'язку України", від 23 травня 2007 року N 331-р ( 331-2007-р ) "Про призначення Костриби Н.П. членом Національної комісії з питань регулювання зв'язку України".

Названими актами Кабінет Міністрів України призначив на посади та звільнив з посад Голову та членів Національної комісії з питань регулювання зв'язку України.

25 липня 2007 року Кабінетом Міністрів України видано постанову N 971 ( 971-2007-п ), якою затверджено Положення про Національну комісію з питань регулювання зв'язку України.

Відповідно до названого Положення ( 971-2007-п ) Національна комісія з питань регулювання зв'язку України є центральним органом виконавчої влади із спеціальним статусом, діяльність якого спрямовується і координується Кабінетом Міністрів України (пункт 1) ( 971-2007-п ). За пунктом 6 Положення ( 971-2007-п ) Голову та членів Комісії призначає на посаду та звільняє з посади в установленому порядку Кабінет Міністрів України за поданням Прем'єр-міністра України.

Таким чином, Кабінет Міністрів України прийняв рішення з питань діяльності Національної комісії з питань регулювання зв'язку України, до компетенції якої віднесено регулювання природних монополій у сфері зв'язку.

Між тим згідно з частиною третьою статті 42 Конституції України ( 254к/96-ВР ) види і межі монополії визначаються законом. Особливості правового регулювання зазначених питань передбачено Законами України "Про природні монополії" ( 1682-14 ) та "Про телекомунікації" ( 1280-15 ). Відповідно до статті 4 Закону України "Про природні монополії" ( 1682-14 ) Національна комісія з питань регулювання зв'язку України є органом регулювання у сфері зв'язку.

Згідно зі статтею 17 Закону України "Про телекомунікації" ( 1280-15 ) Національна комісія з питань регулювання зв'язку діє на підставі Положення ( 971-2007-п ), розробленого відповідно до законодавства і затвердженого Президентом України. За статтею 20 цього ж Закону ( 1280-15 ) Голову та членів Національної комісії з питань регулювання зв'язку України призначає за поданням Прем'єр-міністра України на посади та припиняє їх повноваження на цих посадах Президент України.

Конституційним обов'язком Президента України є забезпечення національної безпеки, складовою якої є економічна та інформаційна безпека держави, та здійснення керівництва у цій сфері (стаття 17, пункти 1 і 17 частини першої статті 106 Конституції України) ( 254к/96-ВР ).

Ураховуючи, що створення ефективного механізму державного регулювання природних монополій за статтею 8 Закону України "Про основи національної безпеки України" ( 964-15 ) є одним із основних напрямів державної політики з питань національної безпеки України в економічній сфері, зазначені акти Кабінету Міністрів України не відповідають статтям 17, 42, пункту 1 і 17 частини першої статті 106 Конституції України ( 254к/96-ВР ), Законам України "Про природні монополії" ( 1682-14 ) та "Про телекомунікації" ( 1280-15 ).

Крім того, названі акти Кабінету Міністрів України не відповідають і частині другій статті 8 Конституції України ( 254к/96-ВР ), згідно з якою нормативно-правові акти мають прийматися на основі Конституції України ( 254к/96-ВР ) і відповідати їй, а також частині другій статті 6 та частині другій статті 19 Основного Закону ( 254к/96-ВР ) держави, за якими органи державної влади зобов'язані діяти лише в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України.

З огляду на викладене та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію:

постанови Кабінету Міністрів України від 21 березня 2007 року N 482 ( 482-2007-п ) "Про звільнення Гайдука О.В. з посади Голови Національної комісії з питань регулювання зв'язку України";

постанови Кабінету Міністрів України від 21 березня 2007 року N 483 ( 483-2007-п ) "Про призначення Звєрєва В.П. Головою Національної комісії з питань регулювання зв'язку України";

постанови Кабінету Міністрів України від 25 липня 2007 року N 971 ( 971-2007-п ) "Про затвердження Положення про Національну комісію з питань регулювання зв'язку України";

розпорядження Кабінету Міністрів України від 12 травня 2007 року N 294-р ( 294-2007-р ) "Про звільнення Апасова С.І. з посади члена Національної комісії з питань регулювання зв'язку України";

розпорядження Кабінету Міністрів України від 23 травня 2007 року N 331-р ( 331-2007-р ) "Про призначення Костриби Н.П. членом Національної комісії з питань регулювання зв'язку України".

2. Цей Указ набирає чинності з дня його опублікування.
