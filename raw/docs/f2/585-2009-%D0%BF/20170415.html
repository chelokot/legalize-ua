Кабінет Міністрів України; Постанова від 10.06.2009 № 585

Про внесення змін до Порядку здійснення державного контролю за ефективним (раціональним) використанням паливно-енергетичних ресурсів

Стан: Втратив чинність

Ідентифікатор: 585-2009-п

Текст документа від 15.04.2017:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 червня 2009 р. N 585 Київ

{ Постанова втратила чинність на підставі Постанов КМ N 239 ( 239-2017-п ) від 10.03.2017 N 282 ( 282-2017-п ) від 26.04.2017 }

Про внесення змін до Порядку здійснення державного контролю за ефективним (раціональним) використанням паливно-енергетичних ресурсів

Кабінет Міністрів України постановляє:

Внести до Порядку здійснення державного контролю за ефективним (раціональним) використанням паливно-енергетичних ресурсів, затвердженого постановою Кабінету Міністрів України від 22 жовтня 2008 р. N 935 ( 935-2008-п ) "Про організацію державного контролю за ефективним (раціональним) використанням паливно-енергетичних ресурсів" (Офіційний вісник України, 2008 р., N 82, ст. 2761), такі зміни:

абзац перший пункту 3 після слів "паливно-енергетичних ресурсів" доповнити словами "або порушення законодавства у сфері енергозбереження";

у пункті 4 слово "енергії," замінити словами "енергії або нормативами витрат паливно-енергетичних ресурсів,", а після слів "річне споживання" доповнити словами ", крім випадків, що підтверджені документально, за період від дня настання до їх виявлення, але не більш як за один рік від дня порушення таким суб'єктом установлених актами законодавства правил,".

Прем'єр-міністр України Ю.ТИМОШЕНКО
