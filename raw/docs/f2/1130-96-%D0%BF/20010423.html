КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 вересня 1996 р. N 1130 Київ

( Постанова втратила чинність на підставі Постанови КМ N 367 ( 367-2001-п ) від 23.04.2001 )

Про введення посади заступника Міністра енергетики та електрифікації України - головного державного інспектора з енергетичного нагляду

Кабінет Міністрів України постановляє:

Ввести у Міністерстві енергетики та електрифікації посаду заступника Міністра енергетики та електрифікації України - головного державного інспектора з енергетичного нагляду замість посади заступника Міністра енергетики та електрифікації України.
