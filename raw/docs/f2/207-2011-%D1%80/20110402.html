РОЗПОРЯДЖЕННЯ від 11 березня 2011 р. N 207-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 334 ( 334-2011-п ) від 28.03.2011 }

Про передачу бюджетних призначень Міністерству регіонального розвитку, будівництва та житлово-комунального господарства

1. Передати бюджетні призначення, передбачені Міністерству фінансів за загальним фондом державного бюджету ( 2857-17 ) за програмою КПКВК 3511090 "Державні капітальні видатки, що розподіляються Кабінетом Міністрів України", у сумі 95000 тис. гривень Міністерству регіонального розвитку, будівництва та житлово-комунального господарства для фінансування робіт з берегоукріплення, протизсувних та упоряджувальних робіт на Чорноморському узбережжі Криму в районі смт Форос для запобігання виникненню надзвичайних ситуацій природного характеру.

Передачу бюджетних призначень здійснити в межах видатків розвитку.

2. Міністерству регіонального розвитку, будівництва та житлово-комунального господарства забезпечити погодження передачі бюджетних призначень з Комітетом Верховної Ради України з питань бюджету.

Міністерству фінансів внести після зазначеного погодження відповідні зміни до розпису державного бюджету.

3. Державній казначейській службі перерахувати Міністерству регіонального розвитку, будівництва та житлово-комунального господарства кошти у сумі, зазначеній у пункті 1 цього розпорядження.

4. Міністерству регіонального розвитку, будівництва та житлово-комунального господарства розробити за погодженням з Міністерством фінансів та затвердити порядок використання коштів державного бюджету.

Прем'єр-міністр України М.АЗАРОВ
