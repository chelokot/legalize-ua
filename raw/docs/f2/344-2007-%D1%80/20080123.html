Текст документа від 23.01.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 травня 2007 р. N 344-р Київ

Про підписання Меморандуму між Урядом України та Урядом Японії про співпрацю з впровадження Рамкової конвенції ООН про зміну клімату та Кіотського протоколу до неї

{ Із змінами, внесеними згідно з Розпорядженням КМ N 90-р ( 90-2008-р ) від 23.01.2008 }

Схвалити проект Меморандуму між Урядом України та Урядом Японії про співпрацю з впровадження Рамкової конвенції ООН про зміну клімату та Кіотського протоколу до неї.

Уповноважити Міністра охорони навколишнього природного середовища Філіпчука Георгія Георгійовича підписати зазначений Меморандум. { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 90-р ( 90-2008-р ) від 23.01.2008 }
