КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 липня 2001 р. N 847 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1167 ( 1167-2005-п ) від 07.12.2005 )

Про управління часткою держави у статутному фонді Національного депозитарію

Кабінет Міністрів України постановляє:

1. Передати в управління Міністерству фінансів частку держави у розмірі 86 відсотків статутного фонду Національного депозитарію.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 18 травня 1999 р. N 849 ( 849-99-п ) "Про питання управління часткою держави у статутному фонді Національного депозитарію" (Офіційний вісник України, 1999 р., N 20, ст. 901).
