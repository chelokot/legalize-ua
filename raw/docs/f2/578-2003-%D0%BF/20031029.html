ПОСТАНОВА від 23 квітня 2003 р. N 578 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1691 ( 1691-2003-п ) від 29.10.2003 )

Про зміну складу Національної ради з питань безпечної життєдіяльності населення

Кабінет Міністрів України постановляє:

На часткову зміну пункту 1 постанови Кабінету Міністрів України від 12 квітня 2002 р. N 531 ( 531-2002-п ) "Про затвердження складу Національної ради з питань безпечної життєдіяльності населення" (Офіційний вісник України, 2002 р., N 16, ст. 868) затвердити новий посадовий склад Національної ради з питань безпечної життєдіяльності населення, що додається.
