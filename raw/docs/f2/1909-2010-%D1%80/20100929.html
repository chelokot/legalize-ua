Про затвердження титулу будови розкриття і підготовки похилого поля шахти, підготовки похилого поля пласта l (l ) блока N 4, 3 1 будівництво блока N 5

Затвердити поданий Міністерством вугільної промисловості титул будови "Розкриття і підготовка похилого поля шахти, підготовка похилого поля пласта l (l ) блока N 4, будівництво 3 1

блока N 5 відокремленого підрозділу "Шахта "Стаханова" державного підприємства "Красноармійськвугілля", будівництво якої розпочато у 1979 році, що додається.
