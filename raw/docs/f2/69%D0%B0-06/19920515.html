Президія Верховної Ради УРСР; Указ від 26.03.1966 № 69a-06

Про внесення доповнень до статті 138 Кримінального кодексу Української РСР

Стан: Втратив чинність

Ідентифікатор: 69а-06

Текст документа від 15.05.1992:

УКАЗ ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

( Указ втратив чинність на підставі Закону N 2354-XII ( 2354-12 ) від 15.05.92, ВВР, 1992, N 32, ст.457 )

Про внесення доповнень до статті 138 Кримінального кодексу Української РСР

( Відомості Верховної Ради (ВВР), 1966, N 13, ст. 69 )

Президія Верховної Ради Української РСР постановляє:

Доповнити статтю 138 Кримінального кодексу Української РСР ( 2001-05 , 2002-05 ) частиною другою такого змісту:

"Ті ж діяння, вчинені особою, яка раніше судилася за порушення законів про відокремлення церкви від держави і школи від церкви, а так само організаційна діяльність, спрямована до вчинення цих діянь, -

караються позбавленням волі на строк до трьох років".
