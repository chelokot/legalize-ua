НАКАЗ

24.07.2008 N 1270/5

Зареєстровано в Міністерстві юстиції України 25 липня 2008 р. за N 692/15383

Про внесення змін до деяких нормативно-правових актів Міністерства юстиції України

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 2432/5 ( z1126-16 ) від 05.08.2016 }

Відповідно до Положення про Міністерство юстиції України, затвердженого постановою Кабінету Міністрів України від 14.11.2006 N 1577 ( 1577-2006-п ), НАКАЗУЮ:

1. Пункт 5 наказу Міністерства юстиції України від 25.04.2008 N 710/5 ( z0417-08 ) "Про внесення змін до Положення про Єдиний державний реєстр виконавчих проваджень", зареєстрованого в Міністерстві юстиції України 15.05.2008 за N 417/15108, виключити. У зв'язку з цим пункт 6, підпункти 6.1 та 6.2 уважати відповідно пунктом 5, підпунктами 5.1 та 5.2.

{ Пункт 2 фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства юстиції N 43/5 ( z0388-03 ) від 20.05.2003, до якого вносились зміни } 2. Унести до Положення про Єдиний державний реєстр виконавчих проваджень, затвердженого наказом Міністерства юстиції України від 20.05.2003 N 43/5 ( z0388-03 ), зареєстрованого в Міністерстві юстиції України 21.05.2003 за N 388/7709 (із змінами), такі зміни:

2.1. У пункті 1.3 слова "Державне підприємство "Держреєстр" замінити словами "державне підприємство "Інформаційний центр" Міністерства юстиції України".

2.2. Пункт 1.8 доповнити словами "та інших реєстрів, адміністратором яких є державне підприємство "Інформаційний центр" Міністерства юстиції України".

2.3. У пункті 6.1:

2.3.1. Після слів "у вигляді" доповнити словом "скорочених".

2.3.2. Доповнити новим реченням такого змісту: "Повні витяги з Єдиного реєстру надаються на запити сторін виконавчого провадження".

2.4. У абзаці першому пункту 6.7 слово "витягу" замінити словами "скороченому витязі".

2.5. Розділ 6 після пункту 6.7 доповнити новим пунктом 6.8 такого змісту:

"6.8. У повному витязі з Єдиного реєстру, який надається сторонам виконавчого провадження, зазначаються відомості, визначені пунктами 2.3 та 3.1 цього Положення".

У зв'язку з цим пункти 6.8-6.10 вважати відповідно пунктам 6.9-6.11.

3. Департаменту державної виконавчої служби Міністерства юстиції України (Стаднік Г.В.), державному підприємству "Інформаційний центр" Міністерства юстиції України (Добжанський В.Б.):

3.1. Подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (зі змінами).

3.2. Довести наказ до відома Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управлінь юстиції в областях, містах Києві та Севастополі, регіональних філій державного підприємства "Інформаційний центр" Міністерства юстиції України та забезпечити його належне виконання.

4. Контроль за виконанням цього наказу залишаю за собою.

Міністр Микола Оніщук
