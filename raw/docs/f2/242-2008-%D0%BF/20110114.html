КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 березня 2008 р. N 242 Київ

Деякі питання увічнення пам'яті жертв війни та політичних репресій

{ Із змінами, внесеними згідно з Постановою КМ N 8 ( 8-2011-п ) від 12.01.2011 }

Кабінет Міністрів України постановляє:

1. Прийняти пропозицію Українського інституту національної пам'яті та Міністерства оборони щодо передачі державного підприємства "Центр" до сфери управління зазначеного Інституту.

2. Міністерству фінансів і Державному комітетові архівів передати відповідно до частини шостої статті 23 Бюджетного кодексу України ( 2542-14 ) Українському інститутові національної пам'яті видатки, передбачені Державному комітетові архівів за бюджетною програмою "Пошук і впорядкування поховання жертв війни та політичних репресій" ( 107-17 ).

3. На зміну пункту 1 постанови Кабінету Міністрів України від 13 липня 2004 р. N 917 ( 917-2004-п ) (Офіційний вісник України, 2004 р., N 28, ст. 1896) затвердити склад Державної міжвідомчої комісії у справах увічнення пам'яті жертв війни та політичних репресій згідно з додатком.

4. Внести до постанов Кабінету Міністрів України такі зміни:

у пункті 3 постанови Кабінету Міністрів України від 2 серпня 1996 р. N 897 ( 897-96-п ) "Про Державну міжвідомчу комісію у справах увічнення пам'яті жертв війни та політичних репресій" (ЗП України, 1996 р., N 16, ст. 426; Офіційний вісник України, 2004 р., N 28, ст. 1896; 2007 р., N 26, ст. 1046) слова "Міністерства оборони" замінити словами "Українського інституту національної пам'яті".

{ Абзац третій пункту 4 втратив чинність на підставі Постанови КМ N 8 ( 8-2011-п ) від 12.01.2011 }
