{ Розпорядження втратило чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Про внесення змін до розпорядження Кабінету Міністрів України від 27 червня 2001 р. N 264

1. На часткову зміну пункту 1 розпорядження Кабінету Міністрів України від 27 червня 2001 р. N 264 ( 264-2001-р ) (із змінами і доповненнями, внесеними розпорядженням від 24 липня 2001 р. N 292 ( 292-2001-р ) ввести до складу міжвідомчої робочої групи для сприяння розв'язанню проблем Акціонерного комерційного агропромислового банку "Україна":

Юшка Ігоря Олеговича - Міністра фінансів (керівник міжвідомчої робочої групи);

Пахачук Людмилу Данилівну - заступника голови правління Ощадного банку;

Пашину Наталію Прокопівну - першого заступника Голови Державного казначейства;

Підвисоцького Валентина Геннадійовича - віце-президента Українського союзу промисловців і підприємців з питань інвестицій та регіонального розвитку (за згодою);

Струкова Віталія Миколайовича - виконуючого обов'язки голови Агентства з питань банкрутства;

Уманського Ігоря Івановича - заступника Державного секретаря Мінекономіки,

вивівши з її складу Мітюкова Ігоря Олександровича, Гулея Анатолія Івановича, Миколенка Петра Петровича, Русаліна Костянтина Олександровича, Тополова Віктора Семеновича.

2. Доповнити розпорядження пунктом 3 такого змісту:

"3. Дозволити керівникові міжвідомчої робочої групи у разі потреби вносити зміни до її складу".

Прем'єр-міністр України А.КІНАХ
