Про розміщення Державної комісії з цінних паперів та фондового ринку

Стан: Чинний

Текст документа від 28.03.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 листопада 2006 р. N 566-р Київ

Про розміщення Державної комісії з цінних паперів та фондового ринку

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 579-р ( 579-2011-р ) від 22.06.2011 N 153-р ( 153-2012-р ) від 28.03.2012 }

1. { Абзац перший пункту 1 виключено на підставі Розпорядження КМ N 153-р ( 153-2012-р ) від 28.03.2012 }

У зв'язку з цим у розпорядженні Кабінету Міністрів України від 5 квітня 2006 р. N 185 ( 185-2006-р ) "Про розміщення НКАУ" слова "четвертому, десятому - тринадцятому" замінити словами "п'ятому, шостому, сьомому та дев'ятому".

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 579-р ( 579-2011-р ) від 22.06.2011 }

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 1 березня 2004 р. N 99 ( 99-2004-р ) "Про розміщення Державної комісії з цінних паперів та фондового ринку".
