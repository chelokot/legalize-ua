ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

04.03.2004 N 64

Зареєстровано в Міністерстві юстиції України 5 травня 2004 р. за N 560/9159

{ Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку

N 433 ( z0807-06 ) від 23.06.2006 }

Про внесення змін та доповнень до рішення від 10.12.2003 N 556

Відповідно до Законів України "Про недержавне пенсійне забезпечення" ( 1057-15 ), "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ) Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Внести до рішення Державної комісії з цінних паперів та фондового ринку від 10.12.2003 N 556 ( za029-04 ) "Про затвердження Змін та доповнень до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів", зареєстрованого в Міністерстві юстиції України 13.01.2004 за N 29/8628, такі зміни та доповнення:

1.1) доповнити рішення пунктом 2 такого змісту:

"2. Умова щодо сплати статутного фонду (капіталу) на день державної реєстрації для юридичних осіб, які мають намір отримати ліцензію на здійснення професійної діяльності на ринку цінних паперів - діяльності з управління активами інститутів спільного інвестування, поширюється лише на юридичних осіб, які зареєстровані в установленому законодавством порядку після набрання чинності цим рішенням";

1.2) у зв'язку з цим пункти 2-4 рішення вважати відповідно пунктами 3-5.

2. Виконавчому секретарю М.Каскевичу забезпечити:

подання цього рішення на затвердження до Державного комітету України з питань регуляторної політики та підприємництва;

державну реєстрацію цього рішення в Міністерстві юстиції України;

опублікування цього рішення відповідно до чинного законодавства.

3. Рішення набирає чинності відповідно до чинного законодавства.

4. Контроль за виконанням цього рішення покласти на Виконавчого секретаря М.Каскевича.

Голова Комісії О.Мозговий
