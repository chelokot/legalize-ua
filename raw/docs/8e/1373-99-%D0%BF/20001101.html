КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 липня 1999 р. N 1373 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1493 ( 1493-2000-п ) від 29.09.2000 )

Про внесення доповнення до постанови Кабінету Міністрів України від 24 червня 1999 р. N 1112

Кабінет Міністрів України постановляє:

Доповнити перелік банків України, до яких рекомендується звертатися для авалювання векселів, що видаються з метою митного оформлення пально-мастильних матеріалів, визначений постановою Кабінету Міністрів України від 24 червня 1999 р. N 1112 ( 1112-99-п ) "Про деякі питання митного оформлення пально-мастильних матеріалів", такими словами:

"Акціонерний комерційний банк "Трансбанк"

Акціонерне товариство "Український інноваційний банк".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
