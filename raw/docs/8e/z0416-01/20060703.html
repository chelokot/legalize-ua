{ Із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 127 ( z0434-03 ) від 20.05.2003 Наказом Міністерства економіки N 196 ( z0732-06 ) від 06.06.2006 }

На виконання Закону України "Про відновлення платоспроможності боржника або визнання його банкрутом" ( 2343-12 ) та Указу Президента України "Про Міністерство економіки України" від 23 жовтня 2000 року N 1159/2000 ( 1159/2000 ) НАКАЗУЮ:

1. Затвердити Порядок подання пропозицій господарському суду щодо кандидатур арбітражних керуючих, що додається. ( Пункт 1 із змінами, внесеними згідно з Наказом Міністерства економіки та з питань європейської інтеграції N 127 ( z0434-03 ) від 20.05.2003 )

2. Управлінню з питань власності та банкрутства подати цей наказ на державну реєстрацію до Міністерства юстиції України.

ПОРЯДОК подання пропозицій господарському суду щодо кандидатур арбітражних керуючих

{ У тексті Порядку слова "територіальний орган з питань банкрутства Міністерства економіки та з питань європейської інтеграції України (далі - територіальний орган)" в усіх відмінках замінено словами "територіальний орган з питань банкрутства (далі - територіальний орган)" у відповідному відмінку, слова "Міністерство економіки та з питань європейської інтеграції України (далі - Міністерство)" та "управління з питань власності та банкрутства Міністерства (далі - управління)" в усіх відмінках замінено словами "Державний департамент з питань банкрутства (далі - Департамент)" у відповідному відмінку згідно з Наказом Міністерства економіки N 196 ( z0732-06 ) від 06.06.2006 }

1. У цьому Порядку визначено подання пропозицій господарському суду щодо кандидатур арбітражних керуючих (розпорядників майна, керуючих санацією, ліквідаторів) для державних підприємств або підприємств, у статутному фонді яких частка державної власності перевищує 25 відсотків, у разі порушення щодо них справи про банкрутство та в інших випадках, передбачених Законом України "Про відновлення платоспроможності боржника або визнання його банкрутом" ( 2343-12 ) (далі - Закон).

Подання пропозицій господарському суду щодо кандидатур арбітражних керуючих для державних підприємств або підприємств, у статутному фонді яких частка державної власності перевищує 25 відсотків, здійснюється за участю органу, уповноваженого управляти державним майном. { Пункт 1 доповнено абзацом згідно з Наказом Міністерства економіки N 196 ( z0732-06 ) від 06.06.2006 }

2. Подання господарському суду пропозиції щодо кандидатури арбітражного керуючого здійснюється на підставі:

ухвали господарського суду;

звернення учасників провадження у справі про банкрутство щодо кандидатури арбітражного керуючого за формою згідно з додатком 1;

на інших підставах, передбачених Законом ( 2343-12 ).

У зазначених документах код та назва боржника і позивача наводяться відповідно до Єдиного державного реєстру підприємств і організацій України.

3. Ухвали господарських судів надсилаються територіальним органам з питань банкрутства за місцезнаходженням боржника (далі - територіальний орган). Звернення учасників провадження у справі про банкрутство та осіб, які за власною ініціативою виявили бажання взяти участь у справі, надсилаються Державному департаменту з питань банкрутства (далі - Департамент) або територіальним органам.

Територіальний орган після одержання зазначених у пункті 2 документів протягом трьох робочих днів готує відповідний пакет документів, які перераховані в пункті 5 Порядку.

4. Відбір щодо кандидатури арбітражного керуючого здійснюється постійно діючою при Департаменті Комісією з підготовки пропозицій господарському суду щодо кандидатур арбітражних керуючих (далі - Комісія) за результатами розгляду:

даних реєстру арбітражних керуючих;

пропозиції територіального органу;

звернення учасників провадження у справі про банкрутство щодо кандидатури арбітражного керуючого;

звернення органу, уповноваженого управляти державним майном, щодо кандидатури арбітражного керуючого; { Пункт 4 доповнено абзацом згідно з Наказом Міністерства економіки N 196 ( z0732-06 ) від 06.06.2006 }

звернення осіб, які за власною ініціативою виявили бажання взяти участь у справі.

У визначених Законом ( 2343-12 ) випадках розглядаються також пропозиції щодо кандидатур арбітражних керуючих з числа працівників державного органу з питань банкрутства.

Територіальний орган не пізніше наступного робочого дня після підготовки зазначеного в пункті 5 Порядку пакета документів надсилає його телефаксом до Державного департаменту з питань банкрутства (далі - Департамент). Оригінали вказаних документів надсилаються поштою.

Департамент завершує підготовку пропозицій щодо кандидатур арбітражних керуючих протягом трьох днів після одержання відповідних документів від територіальних органів та інших осіб, які за власною ініціативою виявили бажання взяти участь у справі.

5. Пакет документів щодо кандидатури арбітражного керуючого, який подається Департаментом до Комісії, повинен включати:

коротку інформацію про запропоновану кандидатуру (прізвище, ім'я та по батькові, перелік 2-3 останніх підприємств, на яких виконувалися (виконуються) ним повноваження розпорядника майна, керуючого санацією чи ліквідатора, та інше);

письмову згоду запропонованої особи на виконання повноважень арбітражного керуючого у справі про банкрутство, у якій зазначається також про відсутність ознак заінтересованої особи стосовно боржника, за формою згідно з додатком 2;

коротку інформацію щодо підприємства-боржника, за формою згідно з додатком 3 (за наявності).

6. Комісія погоджує кандидатуру арбітражного керуючого, яку буде запропоновано господарському суду, окремо з кожної справи, керуючись такими критеріями:

набутий досвід роботи на аналогічних за профілем виробничої діяльності підприємствах;

участь в інших справах;

ефективність виконання повноважень арбітражного керуючого в минулому за даними моніторингу діяльності арбітражних керуючих;

наявність погодження кандидатури органом місцевого самоврядування або центральним органом виконавчої влади у випадках, передбачених Законом ( 2343-12 );

черговість надходження пропозицій;

ділова репутація арбітражного керуючого, тобто сукупність підтвердженої інформації про нього, яка дає можливість зробити висновок про професійні здібності арбітражного керуючого, його порядність та відповідність його діяльності вимогам законодавства. { Пункт 6 доповнено абзацом згідно з Наказом Міністерства економіки N 196 ( z0732-06 ) від 06.06.2006 }

7. Без погодження Комісією територіальні органи пропонують господарським судам кандидатури арбітражних керуючих у разі порушення справи про банкрутство громадянина-підприємця (статті 47-49 Закону) ( 2343-12 ), селянського (фермерського) господарства (стаття 50 Закону), відсутнього боржника (стаття 52 Закону).

У погодженні запропонованої кандидатури Комісією може бути відмовлено, якщо:

процедура погодження арбітражних керуючих та подані документи не відповідають вимогам цього Порядку;

Департамент одержав стосовно запропонованої кандидатури документи, у яких у встановленому законодавством порядку зафіксовані факти порушення зазначеним арбітражним керуючим ліцензійних умов, визначених законодавством.

У разі відмови в погодженні запропонованої кандидатури повторне подання нової кандидатури здійснюється відповідно до пунктів 4-7 цього Порядку.

8. Комісія погоджує запропоновану кандидатуру або відмовляє у її погодженні в день проведення засідання.

У день одержання погодження Комісією запропонованої кандидатури, але не пізніше наступного робочого дня Департамент готує лист господарському суду з пропозицією щодо кандидатури арбітражного керуючого. Лист підписується посадовою особою Департаменту, яка має на це повноваження, та засвідчується печаткою Департаменту. { Абзац другий пункту 8 із змінами, внесеними згідно з Наказом Міністерства економіки N 196 ( z0732-06 ) від 06.06.2006 }

У разі відмови Комісією у погодженні запропонованої кандидатури Департамент готує лист ініціаторам звернення з обґрунтуванням причин відмови в погодженні. { Абзац третій пункту 8 в редакції Наказу Міністерства економіки N 196 ( z0732-06 ) від 06.06.2006 }

9. У день підписання листа посадовою особою Департаменту він надсилається з пропозицією щодо кандидатури арбітражного керуючого до відповідного господарського суду. Не пізніше наступного робочого дня Департамент надсилає копію зазначеного листа відповідному територіальному органу та особі, яка звернулася з цього питання до Комісії. { Пункт 9 із змінами, внесеними згідно з Наказом Міністерства економіки N 196 ( z0732-06 ) від 06.06.2006 }

10. Діловодство та облік справ щодо прийняття рішень, визначених цим Порядком, здійснює Департамент.
