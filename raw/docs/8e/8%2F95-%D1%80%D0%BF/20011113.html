Текст документа від 13.11.2001:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про Комісію з розробки проекту акціонування державного підприємства "Науково-виробниче об'єднання Хартрон"

З метою розробки механізму акціонування державних підприємств, що визначають науково-технологічний та військовий потенціал країни, нагромадження досвіду щодо зміни умов їх господарювання:

1. Утворити Комісію з розробки проекту акціонування державного підприємства "Науково-виробниче об'єднання Хартрон" (далі - Комісія).

Затвердити персональний склад Комісії (додається).

2. Надати Комісії право залучати до роботи спеціалістів центральних органів державної виконавчої влади, а також фахівців і вчених, у тому числі на договірних засадах, та одержувати інформацію, необхідну для її роботи.

3. Технічне та інше забезпечення роботи Комісії покласти на Секретаріат Ради національної безпеки.

4. Це Розпорядження набирає чинності з дня його підписання.

Президент України Л.КУЧМА

м.Київ, 16 січня 1995 року N 8/95-рп
