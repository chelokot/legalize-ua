Президент України; Указ від 12.05.2011 № 578/2011

Про направлення миротворчого контингенту для участі України в наданні підтримки Операції ООН у Кот-д'Івуарі

Стан: Чинний

Ідентифікатор: 578/2011

Текст документа від 06.06.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про направлення миротворчого контингенту для участі України в наданні підтримки Операції ООН у Кот-д'Івуарі

{ Рішення Президента схвалено Законом N 3404-VI ( 3404-17 ) від 19.05.2011, ВВР, 2011, N 50, ст.538 }

Ураховуючи зобов'язання України як держави - члена Організації Об'єднаних Націй,

беручи до уваги Резолюції Ради Безпеки ООН N 1609 ( 995_d44 ) від 24 червня 2005 року, N 1865 ( 995_h84 ) від 27 січня 2009 року, N 1880 ( 995_i06 ) від 30 липня 2009 року, N 1933 ( 995_i89 ) від 30 червня 2010 року, N 1951 ( 995_j04 ) від 24 листопада 2010 року, N 1962 ( 995_j13 ) від 20 грудня 2010 року, N 1967 ( 995_j14 ) від 19 січня 2011 року, N 1968 ( 995_j36 ) від 16 лютого 2011 року та N 1975 ( 995_j60 ) від 30 березня 2011 року,

вважаючи, що дальша участь України в наданні підтримки Операції ООН у Кот-д'Івуарі відповідає національним інтересам України, сприятиме підтриманню міжнародного миру і безпеки,

на підставі пропозиції Ради національної безпеки і оборони України, відповідно до Закону України "Про участь України в міжнародних миротворчих операціях" ( 613-14 ) постановляю:

1. Направити для участі України в наданні підтримки Операції ООН у Кот-д'Івуарі миротворчий контингент загальною чисельністю до 70 осіб з числа миротворчого контингенту України, який діє у складі Місії ООН у Ліберії, у строки, визначені Радою Безпеки ООН, на період до 30 вересня 2011 року.

2. Кабінету Міністрів України забезпечити направлення миротворчого контингенту, зазначеного у статті 1 цього Указу.

Президент України В.ЯНУКОВИЧ

м. Київ, 12 травня 2011 року N 578/2011
