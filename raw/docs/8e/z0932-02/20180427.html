{ Наказ втратив чинність на підставі Наказу Міністерства фінансів N 364 ( z0421-18 ) від 15.03.2018 }

Про затвердження форми акта про невідповідність товарів відомостям, зазначеним у потрібних для здійснення митного контролю документах, про пошкодження товарів чи їх упаковки або маркування

{ Із змінами, внесеними згідно з Наказом Державної митної служби

N 45 ( z0058-03 ) від 23.01.2003 }

Відповідно до статті 76 Митного кодексу України ( 92-15 ) та з метою вдосконалення процедури митного оформлення товарів, що переміщуються підприємствами через митний кордон України, НАКАЗУЮ:

1. Затвердити форму акта про невідповідність товарів відомостям, зазначеним у потрібних для здійснення митного контролю документах, про пошкодження товарів чи їх упаковки або маркування (далі - Акт), що додається.

2. Установити, що підприємства, які переміщують товари через митний кордон України, складають Акт у присутності посадової особи митного органу, у зоні діяльності якого виявлено:

невідповідність товарів відомостям, зазначеним у потрібних для здійснення митного контролю документах;

пошкодження товарів чи їх упаковки або маркування.

Акт може складатися в 4-х примірниках: перший примірник призначено для підприємства, що переміщує товари через митний кордон України, другий - для митного органу за місцем його складання, третій - для митниці призначення, четвертий - для власника товару.

3. Митним органам, яким товари повинні бути задекларовані відповідно до обраного їх власником (уповноваженою ним особою) митного режиму, приймати для здійснення митних процедур Акти, подані підприємствами, що переміщують товари, незалежно від місця їх складення.

4. Установити, що цей наказ застосовується з дня набрання чинності Митним кодексом України ( 92-15 ).

( Пункт 4 в редакції Наказу Державної митної служби N 45 ( z0058-03 ) від 23.01.2003 )

5. Управлінню правової роботи (Мельник М.В.) забезпечити державну реєстрацію наказу в Міністерстві юстиції України.

6. Управлінню справами (Карпенко В.П.) забезпечити висвітлення вимог наказу в засобах масової інформації.

7. Контроль за виконанням цього наказу покласти на заступника Голови Служби Пашка П.В.
