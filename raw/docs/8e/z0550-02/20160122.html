N 163/588/217 від 18.06.2002 Зареєстровано в Міністерстві м.Київ юстиції України 1 липня 2002 р. за N 550/6838

{ Наказ втратив чинність на підставі Наказу Міністерства аграрної політики та продовольства N 482/1584/866 ( z1680-15 ) від 17.12.2015 }

Про посилення державного контролю та нагляду за торгівлею пестицидами і агрохімікатами

{ Із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 64/1232/73 ( z0243-06 ) від 17.02.2006 }

Відповідно до Законів України "Про пестициди і агрохімікати" ( 86/95-ВР ), "Про забезпечення санітарного та епідемічного благополуччя населення" ( 4004-12 ) та з метою посилення державного контролю і нагляду за торгівлею та використанням незареєстрованих та (або) неякісних пестицидів і агрохімікатів НАКАЗУЄМО:

1. Міністерству аграрної політики Автономної Республіки Крим, головним управлінням агропромислового розвитку обласних державних адміністрацій та Управлінню агропромислового розвитку Севастопольської міської держадміністрації, головним управлінням МВС України в Автономній Республіці Крим, м. Києві та Київській області, УМВС України в областях та м. Севастополі, головним державним санітарним лікарям Автономної Республіки Крим, областей, міст Києва та Севастополя: { Пункт 1 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 64/1232/73 ( z0243-06 ) від 17.02.2006 }

1.1. Щорічно розробляти плани спільних рейдових перевірок щодо дотримання вимог чинного законодавства юридичними і фізичними особами при транспортуванні, зберіганні та торгівлі пестицидами і агрохімікатами та забезпечити їх виконання. { Пункт 1.1 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 64/1232/73 ( z0243-06 ) від 17.02.2006 }

1.2. Інформацію про результати перевірок подавати щокварталу Мінагрополітики, МОЗ та МВС.

1.3. Забезпечити контроль за вилученими із обігу незареєстрованими пестицидами і агрохімікатами, їх зберіганням та утилізацією відповідно до встановленого порядку.

1.4. Посилити просвітницьку роботу через засоби масової інформації щодо дотримання санітарно-гігієнічних та екологічних вимог при торгівлі пестицидами і агрохімікатами.

2. Координацію роботи щодо виконання плану спільних перевірок торгівлі пестицидами і агрохімікатами покласти на Головну державну інспекцію захисту рослин Мінагрополітики України (Котелянець М.Г.) { Пункт 2 із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 64/1232/73 ( z0243-06 ) від 17.02.2006 }

3. Контроль за виконанням наказу покласти на заступника Державного секретаря Мінагрополітики України Яковенка В.П., заступника Державного секретаря МВС України - генерал-лейтенанта міліції Варенка В.І., Головного державного санітарного лікаря України - першого заступника Державного секретаря МОЗ України Бобильову О. О.
