Прем'єр-міністр України М.АЗАРОВ

Інд. 39

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 липня 2010 р. N 698

ПОРЯДОК використання коштів, передбачених у державному бюджеті для підтримки статутної діяльності всеукраїнських асоціацій органів місцевого самоврядування

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 59 ( 59-2013-п ) від 30.01.2013 }

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті Мінрегіону за програмою "Підтримка статутної діяльності Всеукраїнських асоціацій органів місцевого самоврядування" (далі - бюджетні кошти).

{ Пункт 1 в редакції Постанови КМ N 59 ( 59-2013-п ) від 30.01.2013 }

2. Головним розпорядником бюджетних коштів і відповідальним виконавцем бюджетної програми є Мінрегіон, одержувачами бюджетних коштів є всеукраїнські асоціації органів місцевого самоврядування (далі - всеукраїнські асоціації).

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 59 ( 59-2013-п ) від 30.01.2013 }

3. Бюджетні кошти спрямовуються на виконання всеукраїнськими асоціаціями статутних завдань, передбачених статтею 14 Закону України "Про асоціації органів місцевого самоврядування" ( 1275-17 ), а саме:

1) розроблення та надання органам державної влади пропозицій щодо розвитку місцевого самоврядування;

2) надання методичної, правової та інформаційної допомоги органам місцевого самоврядування у здійсненні ними своїх повноважень;

3) сприяння органам місцевого самоврядування у підготовці проектів їх актів, програм соціально-економічного та культурного розвитку територіальних громад;

4) узагальнення та поширення досвіду діяльності органів місцевого самоврядування з питань соціально-економічного та культурного розвитку.

4. Розподіл бюджетних коштів за напрямами, зазначеними в пункті 3 цього Порядку, здійснюється Мінрегіоном на підставі поданих всеукраїнськими асоціаціями обґрунтувань потреби в коштах і кошторисів з детальними розрахунками витрат, визначених з урахуванням установлених норм та нормативів, діючих цін і тарифів, календарних планів заходів і можливості здійснення відповідних видатків за рахунок надходжень з інших джерел.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 59 ( 59-2013-п ) від 30.01.2013 }

5. Календарні плани заходів всеукраїнських асоціацій на поточний рік та порядок їх проведення погоджуються з Мінрегіоном.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 59 ( 59-2013-п ) від 30.01.2013 }

6. Проведення операцій, пов’язаних з використанням бюджетних коштів, здійснюється в установленому законодавством порядку.

{ Пункт 6 в редакції Постанови КМ N 59 ( 59-2013-п ) від 30.01.2013 }

7. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється в установленому законом порядку.

{ Пункт 7 із змінами, внесеними згідно з Постановою КМ N 59 ( 59-2013-п ) від 30.01.2013 }

8. Не допускається спрямування бюджетних коштів на:

виконання програм і здійснення заходів, метою яких є отримання прибутку;

придбання товарів, робіт і послуг для здійснення заходів загальнодержавного та міжнародного рівня, використання яких безпосередньо не пов'язане з організацією таких заходів та участю в них;

здійснення видатків, що проводяться за рахунок інших бюджетних програм; { Абзац четвертий пункту 8 із змінами, внесеними згідно з Постановою КМ N 59 ( 59-2013-п ) від 30.01.2013 }

оплату посередницьких послуг.

9. Складення та подання фінансової та бюджетної звітності про використання бюджетних коштів, а також контроль за їх цільовим і ефективним витрачанням здійснюються в установленому законодавством порядку.

{ Пункт 9 із змінами, внесеними згідно з Постановою КМ N 59 ( 59-2013-п ) від 30.01.2013 }
