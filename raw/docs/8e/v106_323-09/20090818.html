{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 1492/5 ( v1492323-09 ) від 18.08.2009 }

Про затвердження нового складу Міжвідомчої робочої групи із забезпечення реалізації Закону України "Про організацію формування та обігу кредитних історій"

Відповідно до підпунктів 1, 2 пункту 5 та пункту 8 Положення про Міністерство юстиції України, затвердженого постановою Кабінету Міністрів України від 14 листопада 2006 N 1577 ( 1577-2006-п ), НАКАЗУЮ:

На зміну пункту 1 наказу Міністерства юстиції України від 07.07.2006 N 805/7 (зі змінами, внесеними наказом Міністерства юстиції України від 22.04.2008 N 547/7) затвердити новий склад Міжвідомчої робочої групи із забезпечення реалізації Закону України "Про організацію формування та обігу кредитних історій" ( 2704-15 ), що додається.

Міністр М.Оніщук

Додаток до наказу Міністерства юстиції України 30.01.2009 N 106/7

СКЛАД Міжвідомчої робочої групи із забезпечення реалізації Закону України "Про організацію формування та обігу кредитних історій" ( 2704-15 )

КУГАТКІН - заступник директора Департаменту - Юрій Степанович начальник відділу регулювання діяльності бюро кредитних історій Департаменту легалізації та регулювання діяльності бюро кредитних історій Міністерства юстиції України, заступник керівника міжвідомчої робочої групи

КОНОТОПЕЦЬ - головний спеціаліст відділу Наталія Миколаївна регулювання діяльності бюро кредитних історій Департаменту легалізації та регулювання діяльності бюро кредитних історій Міністерства юстиції України, секретар міжвідомчої робочої групи

КОМАХА - заступник директора Департаменту - Юрій Юрійович начальник відділу бюджетного законодавства Департаменту фінансового законодавства Міністерства юстиції України

ПАЛАМАРЧУК - голова правління ЗАТ "Перше Антоніна Борисівна всеукраїнське бюро кредитних історій", віце-президент Асоціації українських банків (за згодою)

СВИСТУН - директор юридичного департаменту ЗАТ Роман Степанович "Міжнародне бюро кредитних історій" (за згодою)

ОМЕЛЬЯНЕНКО - директор ТОВ "БЮРО КРЕДИТНИХ ІСТОРІЙ Андрій Миколайович "РУССКИЙ СТАНДАРТ" (за згодою)
