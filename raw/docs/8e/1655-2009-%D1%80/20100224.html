Питання надання громадянам квартир, що придбані Державною іпотечною установою, у с. Снов'янці

Стан: Чинний

Ідентифікатор: 1655-2009-р

Текст документа від 24.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 грудня 2009 р. N 1655-р Київ

Питання надання громадянам квартир, що придбані Державною іпотечною установою, у с. Снов'янці

{ Із змінами, внесеними згідно з Розпорядженням КМ N 293-р ( 293-2010-р ) від 24.02.2010 }

1. Затвердити погоджений Координаційною радою з питань розподілу квартир, що придбані Державною іпотечною установою, при Кабінеті Міністрів України поіменний список громадян, яким надаються придбані у с. Снов'янці Чернігівської області (вул. Лісова, 2) квартири (далі - список), що додається до оригіналу.

{ Зміни до поіменного списку див. в Розпорядженні КМ N 293-р ( 293-2010-р ) від 24.02.2010 }

2. Державній іпотечній установі передати Міністерству внутрішніх справ, Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Державній прикордонній службі, Генеральній прокуратурі України та Боромиківській сільській раді квартири для надання зазначеним у списку громадянам.

3. Виконавчому комітетові Боромиківської сільської ради забезпечити в установленому законодавством порядку видачу зазначеним у списку громадянам ордерів на жилі приміщення.

4. Міністерству внутрішніх справ, Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Державній прикордонній службі, Генеральній прокуратурі України та Боромиківській сільській раді забезпечити неухильне дотримання встановленого Кабінетом Міністрів України порядку розподілу квартир, що придбані Державною іпотечною установою.

Прем'єр-міністр України Ю.ТИМОШЕНКО
