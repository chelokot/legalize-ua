Президент України; Указ від 05.10.2011 № 965/2011

Про внесення зміни до Положення про Державне агентство земельних ресурсів України

Стан: Втратив чинність

Ідентифікатор: 965/2011

Текст документа від 17.01.2012:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення зміни до Положення про Державне агентство земельних ресурсів України

{ Із змінами, внесеними згідно з Указом Президента N 1/2012 ( 1/2012 ) від 03.01.2012 }

1. Внести до пункту 4 Положення про Державне агентство земельних ресурсів України, затвердженого Указом Президента України від 8 квітня 2011 року N 445 ( 445/2011 ), зміну, виклавши підпункт 17 у такій редакції:

"17) здійснює державну реєстрацію земельних ділянок та обмежень у їх використанні".

2. Цей Указ набирає чинності з 1 січня 2013 року.

{ Стаття 2 в редакції Указу Президента N 1/2012 ( 1/2012 ) від 03.01.2012 }
