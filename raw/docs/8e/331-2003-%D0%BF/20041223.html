Про внесення зміни до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

Текст документа від 23.12.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 березня 2003 р. N 331 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1734 ( 1734-2004-п ) від 23.12.2004 )

Про внесення зміни до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

Кабінет Міністрів України постановляє:

У підрозділі "Луганська область" розділу "Мінпромполітики" переліку підприємств, які мають стратегічне значення для економіки і безпеки держави, затвердженого постановою Кабінету Міністрів України від 29 серпня 2000 р. N 1346 ( 1346-2000-п ) (Офіційний вісник України, 2000 р., N 35, ст. 1498; 2002 р., N 10, ст. 474), позицію "05800159 ВАТ "Барвник", м. Рубіжне" виключити.
