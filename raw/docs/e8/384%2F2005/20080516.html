Стан: Чинний

Текст документа від 16.05.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про членів Ради Національного банку України

{ Із змінами, внесеними згідно з Указами Президента N 782/2006 ( 782/2006 ) від 25.09.2006 N 448/2008 ( 448/2008 ) від 16.05.2008 }

Відповідно до пункту 12 частини першої статті 106 Конституції України ( 254к/96-ВР ) та статті 10 Закону України "Про Національний банк України" ( 679-14 ) постановляю:

1. Призначити членами Ради Національного банку України:

ГЕЙЦЯ - директора Інституту економічного

Валерія Михайловича прогнозування НАН України

ДАНИЛЕНКА - завідувача відділу фінансового та

Анатолія Івановича монетарного регулювання Об'єднаного інституту економіки НАН України

ОНІЩУКА - першого заступника Голови Комітету

Миколу Васильовича Верховної Ради України з питань правової політики (за згодою)

ПОЛЯЧЕНКО - народний депутат України (за згодою)

Володимир Аврумович

САБЛУКА - директора Національного наукового

Петра Трохимовича центру "Інститут аграрної економіки" Української академії аграрних наук

ФЕДОРЕНКА - віце-президента Відкритого акціонерного Анатолія Васильовича товариства "КІНТО"

ЯЦЕНЮК - Перший заступник Глави Секретаріату

Арсеній Петрович Президента України - Представник Президента України у Кабінеті Міністрів України.

{ Стаття 1 із змінами, внесеними згідно з Указами Президента N 782/2006 ( 782/2006 ) від 25.09.2006, N 448/2008 ( 448/2008 ) від 16.05.2008 }

2. Звільнити членів Ради Національного банку України: Галієва Е.Е., Гальчинського А.С., Горбаля В.М., Льовочкіна С.В., Осику С.Г., Хорошковського В.І., Шарова І.Ф.

3. Визнати такими, що втратили чинність:

Указ Президента України від 9 жовтня 2000 року N 1125 ( 1125/2000 ) "Про призначення членів Ради Національного банку України";

Указ Президента України від 16 січня 2003 року N 28 ( 28/2003 ) "Про призначення членів Ради Національного банку України".
