Кабінет Міністрів України; Постанова від 11.10.2010 № 964

Про внесення зміни до пункту 1 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

Стан: Втратив чинність

Ідентифікатор: 964-2010-п

Текст документа від 11.10.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 жовтня 2010 р. N 964 Київ

Про внесення зміни до пункту 1 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

Кабінет Міністрів України постановляє:

Внести зміну до пункту 1 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів, затверджених постановою Кабінету Міністрів України від 22 жовтня 2008 р. N 943 ( 943-2008-п ) "Про економію бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів" (Офіційний вісник України, 2008 р., N 84, ст. 2816; 2009 р., N 45, ст. 1507, N 83, ст. 2823, N 95, ст. 3269; 2010 р., N 5, ст. 200, N 60, ст. 2094, N 74, ст. 2621), доповнивши його після слів "автотранспорту" словами "(крім транспортних засобів спеціалізованого призначення для потреб органів внутрішніх справ)".

Прем'єр-міністр України М.АЗАРОВ
