Про надання у 2009 році державних гарантій за зобов'язаннями Державної служби автомобільних доріг

Стан: Чинний

Ідентифікатор: 31-2009-п

Текст документа від 13.08.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 січня 2009 р. N 31 Київ

Про надання у 2009 році державних гарантій за зобов'язаннями Державної служби автомобільних доріг

{ Із змінами, внесеними згідно з Постановами КМ N 717 ( 717-2009-п ) від 08.07.2009 N 841 ( 841-2009-п ) від 29.07.2009 }

Кабінет Міністрів України постановляє:

1. Затвердити Порядок надання у 2009 році державних гарантій за зобов'язаннями Державної служби автомобільних доріг, що додається.

2. Уповноважити Міністра фінансів підписувати документи щодо надання державних гарантій за зобов'язаннями Державної служби автомобільних доріг, у тому числі здійснювати аваль векселів, за якими вона є трасатом, за умови виконання нею вимог, передбачених у затвердженому цією постановою Порядку.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 841 ( 841-2009-п ) від 29.07.2009 }

3. Установити, що вибір кредиторів, які надають Державній службі автомобільних доріг кредити під державні гарантії, а також вибір юридичних радників, які надають зазначеній Службі юридичні послуги, пов'язані з виконанням зобов'язань за кредитами, взятими під державні гарантії у поточному та минулих роках, здійснюється Службою без застосування вимог Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006).

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 27

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 січня 2009 р. N 31

ПОРЯДОК надання у 2009 році державних гарантій за зобов'язаннями Державної служби автомобільних доріг

1. Цей Порядок регулює відносини, пов'язані з наданням відповідно до статті 14 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) Кабінетом Міністрів України державних гарантій для забезпечення виконання зобов'язань за внутрішніми та зовнішніми запозиченнями, що здійснюються Укравтодором (далі - запозичення) та за векселями, за якими Укравтодор є трасатом, шляхом здійснення авалю, крім зобов'язань за кредитом у сумі 465 млн. доларів США, що передбачається залучити від банку "Кредіт Свісс Інтернешнл".

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 841 ( 841-2009-п ) від 29.07.2009 }

2. Державні гарантії надаються у межах загального обсягу, встановленого Законом України "Про Державний бюджет України на 2009 рік" ( 835-17 ), у разі, коли розмір зобов'язань Укравтодору щодо повернення запозичень та погашення векселів, за якими Укравтодор є трасатом, не перевищує 8 млрд. гривень.

{ Пункт 2 із змінами, внесеними згідно з Постановами КМ N 717 ( 717-2009-п ) від 08.07.2009, N 841 ( 841-2009-п ) від 29.07.2009 }

3. Запозичення та векселі використовуються для виконання зобов'язань, що виникають у зв'язку з фінансуванням проектів будівництва, реконструкції та капітального ремонту автомобільних доріг, у тому числі за залученими у минулі роки кредитами.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 841 ( 841-2009-п ) від 29.07.2009 }

4. Для надання державних гарантій за запозиченнями Укравтодор подає Мінфіну такі документи: { Абзац перший пункту 4 із змінами, внесеними згідно з Постановою КМ N 841 ( 841-2009-п ) від 29.07.2009 }

проекти кредитних договорів;

відомості про залучені Укравтодором запозичення разом з графіками їх погашення та обслуговування;

техніко-економічний розрахунок (бізнес-план) або відповідний фінансово-економічний розрахунок;

копію річного балансу за минулий рік з додатками та копію балансу на останню звітну дату з відміткою Головного управління Державного казначейства у м. Києві.

5. До надання державної гарантії Мінфін та Укравтодор укладають договір про відшкодування витрат державного бюджету, які можуть виникнути у разі виконання державою гарантійних зобов'язань.

У договорі передбачаються зобов'язання Укравтодору щодо:

відшкодування витрат державного бюджету, пов'язаних з виконанням гарантійних зобов'язань;

сплати пені за кожний день прострочення відшкодування зазначених витрат;

подання Мінфіну інформації, необхідної для проведення моніторингу спроможності Укравтодору виконувати зобов'язання за запозиченнями та за векселями; { Абзац п'ятий пункту 5 із змінами, внесеними згідно з Постановою КМ N 841 ( 841-2009-п ) від 29.07.2009 }

обов'язкового погодження з Мінфіном здійснення видатків на будівництво, реконструкцію та капітальний ремонт автомобільних доріг загального користування у разі недостатності коштів для внесення чергового платежу за кредитами чи векселями або наявності простроченої заборгованості за кредитами, наданими під державні гарантії, чи заборгованості з відшкодування витрат державного бюджету, пов'язаних з виконанням гарантійних зобов'язань. { Абзац шостий пункту 5 із змінами, внесеними згідно з Постановою КМ N 841 ( 841-2009-п ) від 29.07.2009 }

6. Аваль з векселями, за якими Укравтодор є трасатом, здійснюється у порядку, встановленому Кабінетом Міністрів України.

{ Порядок доповнено пунктом 6 згідно з Постановою КМ N 841 ( 841-2009-п ) від 29.07.2009 }
