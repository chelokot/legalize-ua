КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 серпня 2001 р. N 385-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 142 ( 142-2003-п ) від 29.01.2003 )

Про внесення змін до розпорядження Кабінету Міністрів України від 23 квітня 2001 р. N 145

Внести до розпорядження Кабінету Міністрів України від 23 квітня 2001 р. N 145 "Про утворення Координаційної ради з розроблення пропозицій щодо передачі земель із державної у комунальну власність у мм. Києві, Севастополі та Дніпропетровську" ( 145-2001-р ) такі зміни:

затвердити новий склад Координаційної ради з розроблення пропозицій щодо передачі земель із державної у комунальну власність у мм. Києві, Севастополі та Дніпропетровську, що додається;

абзац другий розпорядження доповнити словами "а також у разі потреби вносити зміни до її складу";

доповнити розпорядження абзацом такого змісту:

"Головою Координаційної ради є Віце-прем'єр-міністр України згідно з розподілом функціональних повноважень".

Прем'єр-міністр України А.КІНАХ

Інд. 22
