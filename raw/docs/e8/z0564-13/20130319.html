Про внесення змін до Переліку товарів, робіт та послуг, на закупівлю яких спрямовуються кошти, що підлягають перерахуванню Пенсійним фондом України та органами праці та соціального захисту населення установам, де особи перебувають на повному державному утриманні

Відповідно до пункту 9 Порядку перерахування Пенсійним фондом України або органами праці та соціального захисту населення коштів установам (закладам), у яких особи перебувають на повному державному утриманні, та їх використання, затвердженого постановою Кабінету Міністрів України від 04 березня 2004 року № 269, та з метою поліпшення умов перебування осіб в установах (закладах) системи органів праці та соціального захисту населення, де особи перебувають на повному державному утриманні, НАКАЗУЮ:

1. Унести зміни до Переліку товарів, робіт та послуг, на закупівлю яких спрямовуються кошти, що підлягають перерахуванню Пенсійним фондом України та органами праці та соціального захисту населення установам, де особи перебувають на повному державному утриманні, затвердженого наказом Міністерства соціальної політики України від 20 березня 2012 року № 150, зареєстрованого в Міністерстві юстиції України 09 квітня 2012 року за № 516/20829, виклавши його у новій редакції, що додається.

2. Департаменту соціальних послуг (І. Тарабукіна) забезпечити подання в установленому порядку цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Л. Дроздову.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

1. За КЕКВ 2210 "Предмети, матеріали, обладнання та інвентар, у тому числі м’який інвентар та обмундирування":

будівельні матеріали, обладнання, матеріали, сантехнічне обладнання для душових, ванних кімнат та туалетів (унітази, умивальники, бачки, крани, змішувачі), інвентар та інструменти лише для забезпечення господарської діяльності, пов’язаної з поліпшенням умов перебування підопічних та вихованців;

малоцінні предмети (фізкультурний інвентар, іграшки для дитячих установ);

меблі (ліжка, столи, стільці, шафи, тумбочки), віконні та дверні блоки, жалюзі, ролети для приміщень, де безпосередньо проживають підопічні та вихованці;

білизна (у тому числі постільна білизна), рушники, робочі костюми підопічним та вихованцям для участі у процесі працетерапії, спортивна форма (у тому числі спортивне взуття), одяг та м'який інвентар, тканини, штори та фіранки, занавіски, матраци;

передплата періодичних видань для підопічних та вихованців;

посуд;

домовини, вінки, хрести;

засоби особистої гігієни (гігієнічні прокладки, памперси для дітей та дорослих, мило, зубна паста, піна для гоління, туалетний папір, гребінець, зубна щітка, шампунь, лезо, станки для гоління, мочалки, пральний порошок, мийні засоби);

канцелярські вироби для навчально-виховного процесу (альбоми, розмальовки, олівці, фломастери, ручки, лінійки, кольоровий папір та картон, пластилін, фарби та пензлі); для творчості (декоративна сітка, флізелін декоративний, органза декоративна, папір для квілінгу, бісер, нитки для вишивання, нитки для шиття, фурнітура для одягу, дріт, проволока);

іграшки, дитячі надувні басейни, спортивний інвентар, ігрове обладнання та м’які модулі для кімнат.

2. За КЕКВ 2220 "Медикаменти та перев’язувальні матеріали":

медикаменти, діагностичні тести та перев'язувальні матеріали;

вітаміни, вакцини для підопічних та вихованців, дезінфекційні засоби, плівки для рентгенівських знімків, матеріали для проведення аналізів, медичний інвентар (термометри, ланцети, пінцети, голки, шприци, супінатори та інше медичне обладнання, яке не береться на облік як основні засоби, сечо- і калоприймачі), слухові апарати, окуляри;

матеріали для лікування зубів підопічних та вихованців (за наявності стоматологічного кабінету в установі);

клейонка медична;

продукти терапевтичного харчування (за призначенням лікаря).

3. За КЕКВ 2230 "Продукти харчування":

продукти харчування та/або оплата послуг з харчування для забезпечення виконання добових натуральних норм харчування;

питна вода.

4. За КЕКВ 2240 "Оплата послуг (крім комунальних)":

ритуальні послуги (у тому числі оплата послуг священика, спорудження на могилі померлого (загиблого) надгробка, огорожі навколо могили);

послуги зв’язку (за користування радіоточкою);

послуги з поточного ремонту житлових приміщень;

послуги з охорони (у тому числі позавідомчої охорони) (у спеціальних будинках-інтернатах та будинках-інтернатах зі спеціальним відділенням).

5. За КЕКВ 3110 "Придбання обладнання і предметів довгострокового користування" на придбання активів, віднесених згідно із законодавством до основних засобів та окремих інших необоротних матеріальних активів:

кухонне обладнання (газові або електричні плити, холодильні та морозильні камери, варочні котли, електричні сковорідки (жаровні), обладнання для випічки хлібобулочних виробів; технологічне обладнання для забезпечення дієтичного харчування з урахуванням профілю установи (протиральна машина, блендери), обладнання та устаткування для очищення питної води;

обладнання для лазне-прального комплексу (пральні машини, прасувальні дошки та котки (обладнання), бойлери для підігріву води (у душових та ванних кімнатах);

кондиціонери та вентилятори для житлових приміщень, їдалень, актових залів, бібліотек (придбання та встановлення);

комп’ютери (за наявності комп’ютерних класів), теле-, відео-, фото-, музична апаратура та музичні інструменти для кімнат відпочинку підопічних та вихованців, актових залів, бібліотек;

дезкамери, фізіотерапевтична апаратура, стоматологічне обладнання (за наявності у штатному розписі посади лікаря-стоматолога), сухожарові шафи, автоклави, стерилізатори;

санітарні автомобілі, мікроавтобуси та автомобілі (понад 10 посадочних місць) для перевезення підопічних та вихованців;

обладнання для майстерень для проведення трудової реабілітації підопічних та вихованців;

меблі для житлових кімнат та житлових приміщень, їдалень, бібліотек, актових залів, де проводяться культурно-масові заходи;

книги та підручники для бібліотечного фонду;

килими, килимові доріжки та штори для житлових приміщень;

паркові лавки;

гойдалки;

альтанки та павільйони для відпочинку.

6. За КЕКВ 3131 "Капітальний ремонт житлового фонду (приміщень)" направляти видатки на капітальний ремонт житлових будівель (житлових кімнат, передпокоїв, санвузлів, кімнат для відпочинку або віталень, холів, ванних кімнат, душових з місцем для роздягання).

7. За КЕКВ 3132 "Капітальний ремонт інших об’єктів" проводити капітальний ремонт інших об'єктів (допоміжних приміщень - культурно-дозвільні, фізкультурно-спортивні та лікувально-трудові (або виробничі) приміщення, їдальні, пральні, лазні, бойлерні, вуличні туалети).

8. За КЕКВ 3131, 3132 здійснюється капітальний ремонт окремих вузлів та систем, які є складовою частиною об'єктів, а саме: водопостачання, газопостачання, каналізації, кондиціювання, сміттєпроводів, пасажирських та вантажних ліфтів тощо.

9. Виконання робіт відповідно за КЕКВ 3131 "Капітальний ремонт житлового фонду (приміщень)" та КЕКВ 3132 "Капітальний ремонт інших об’єктів" здійснюється за погодженням з відповідними структурними підрозділами з питань соціального захисту населення Ради міністрів Автономної Республіки Крим, обласних, Київської та Севастопольської міських державних адміністрацій виключно послідовно лише у разі:

стовідсоткового виконання добових натуральних норм харчування; забезпечення медикаментами; м’яким інвентарем; надання окремих видів послуг; придбання обладнання;

виникнення аварійної ситуації (відхилення від нормальних умов життя і діяльності людей, які призвели (можуть призвести) до загрози життю та здоров’ю людей, руйнування будівель, споруд, обладнання).
