КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 листопада 2003 р. N 1804 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Про внесення змін до деяких постанов Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановами КМ N 268 ( 268-2006-п ) від 09.03.2006 N 954 ( 954-2008-п ) від 22.10.2008 }

Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України зміни, що додаються.

2. Ця постанова набирає чинності з 1 січня 2004 року.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 20 листопада 2003 р. N 1804

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

{ Пункт 1 втратив чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

2. У додатку 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851; 2002 р., N 31, ст. 1479, N 34, ст. 1594) у позиції "Міністерство юстиції" цифри "503", "4" і "19430" замінити відповідно цифрами "550", "9" і "19383".
