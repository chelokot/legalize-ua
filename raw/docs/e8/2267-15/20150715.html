ЗАКОН УКРАЇНИ

{ Закон втратив чинність на підставі Закону N 1697-VII ( 1697-18 ) від 14.10.2014, ВВР, 2015, N 2-3, ст.12 }

Про внесення зміни до статті 36-1 Закону України "Про прокуратуру"

( Відомості Верховної Ради України (ВВР), 2005, N 6, ст.132 )

Верховна Рада України постановляє:

1. Частину другу статті 36-1 Закону України "Про прокуратуру" ( 1789-12 ) (Відомості Верховної Ради України, 1991 р., N 53, ст. 793; 2001 р., N 44, ст. 233) після слів "чи матеріальний стан" доповнити словами "похилий вік".

2. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 17 грудня 2004 року N 2267-IV
