Президент України; Указ від 19.04.2001 № 266/2001

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

Стан: Втратив чинність

Ідентифікатор: 266/2001

Текст документа від 13.05.2003:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 402/2003 ( 402/2003 ) від 13.05.2003 )

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

1. Увести до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України, затвердженого Указом Президента України від 31 грудня 1999 року N 1659 ( 1659/99 ) (із змінами, внесеними Указом від 28 січня 2000 року N 108) ( 108/2000 ), таких осіб:

БЛАЖІВСЬКИЙ - начальник управління Генеральної Євген Миколайович прокуратури України, секретар Комітету

РАДЧЕНКО - Голова Служби безпеки України

Володимир Іванович

СМИРНОВ - Міністр внутрішніх справ України.

Юрій Олександрович

2. Затвердити у складі зазначеного Комітету СТЕЛЬМАХА Володимира Семеновича - Голову Національного банку України (за згодою).

3. Вивести зі складу цього Комітету Войцеховського О.В., Деркача Л.В., Кравченка Ю.Ф.

Президент України Л.КУЧМА

м. Київ, 19 квітня 2001 року N 266/2001
