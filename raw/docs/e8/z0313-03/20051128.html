Зареєстровано в Міністерстві юстиції України 21 квітня 2003 р. за N 313/7634

( Наказ втратив чинність на підставі Наказу Міністерства фінансів N 780 ( z1392-05 ) від 14.11.2005 )

Про внесення змін до наказу Міністерства фінансів України від 28.12.2001 N 611

На виконання статті 44 Закону України від 18 жовтня 2001 року N 2766-III ( 2766-14 ) "Про вибори народних депутатів України" НАКАЗУЮ:

1. У формі Декларації про майно та доходи кандидата у народні депутати України і членів його сім'ї, одержані у 2001 році, затвердженій наказом Міністерства фінансів України від 28.12.2001 N 611 ( z0001-02 ) "Про затвердження форми Декларації про майно та доходи кандидата у народні депутати України і членів його сім'ї", зареєстрованим у Міністерстві юстиції України 02.01.2002 за N 1/6289, цифри "2001" замінити на "20__".

2. Департаменту зведеного бюджету (Данилишин А.А.) в установленому порядку подати цей наказ на державну реєстрацію до Міністерства юстиції України.
