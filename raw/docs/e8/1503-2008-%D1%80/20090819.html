Кабінет Міністрів України; Розпорядження від 03.12.2008 № 1503-р

Про відкриття пункту пропуску через державний кордон на території державного підприємства "Керченський морський торговельний порт"

Стан: Чинний

Ідентифікатор: 1503-2008-р

Текст документа від 19.08.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 грудня 2008 р. N 1503-р Київ

Про відкриття пункту пропуску через державний кордон на території державного підприємства "Керченський морський торговельний порт"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 978-р ( 978-2009-р ) від 19.08.2009 }

1. Відкрити на території державного підприємства "Керченський морський торговельний порт" пункт пропуску через державний кордон для міжнародного морського вантажного, пасажирського та поромного сполучення з постійним і цілодобовим режимом функціонування.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 978-р ( 978-2009-р ) від 19.08.2009 }

2. В абзаці четвертому розпорядження Кабінету Міністрів України від 29 лютого 1996 р. N 143 ( 143-96-р ) слова "Керченський морський порт," виключити.

Прем'єр-міністр України Ю.ТИМОШЕНКО
