МІНІСТЕРСТВО КУЛЬТУРИ І ТУРИЗМУ УКРАЇНИ

НАКАЗ

21.03.2006 N 138

Зареєстровано в Міністерстві юстиції України 7 квітня 2006 р. за N 398/12272

Про внесення змін та доповнень до наказу Міністерства культури і мистецтв України від 15.11.2002 N 647

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства культури і мистецтв N 647 ( z0948-02 ) від 15.11.2002, до якого вносились зміни }

Відповідно до Закону України "Про вивезення, ввезення та повернення культурних цінностей" ( 1068-14 ) та постанови Кабінету Міністрів України від 26.08.2003 N 1343 ( 1343-2003-п ) "Про затвердження Порядку проведення державної експертизи культурних цінностей та розмірів плати за її проведення" НАКАЗУЮ

1. Унести до Переліку державних установ, закладів культури, інших організацій, яким надається право проведення державної експертизи культурних цінностей, затвердженого наказом Міністерства культури і мистецтв України від 15.11.2002 N 647 ( z0948-02 ), зареєстрованого в Міністерстві юстиції України 05.12.2002 за N 948/7236 (із змінами) (далі - Перелік), такі доповнення:

1.1. Пункти 1, 2, 3, 9 Переліку ( z0948-02 ) доповнити окремим рядком "Харківський історичний музей".

1.2. Пункт 4 Переліку ( z0948-02 ) доповнити окремим рядком "Центральний музей Збройних Сил України (за згодою)".

1.3. Пункти 4, 9 Переліку ( z0948-02 ) доповнити окремим рядком "Державний політехнічний музей при Національному технічному університеті України КПІ" (за згодою)".

1.4. Пункти 6, 7, 9 Переліку ( z0948-02 ) доповнити окремим рядком "Харківська державна наукова бібліотека ім. В.Г.Короленка".

1.5. Пункти 8, 9 Переліку ( z0948-02 ) доповнити окремим рядком "Вінницький обласний художній музей".

1.6. Пункти 8, 9 Переліку ( z0948-02 ) доповнити окремим рядком "Харківський художній музей".

1.7. Пункт 9 Переліку ( z0948-02 ) доповнити окремим рядком "Національний музей історії України".

1.8. Пункт 12 Переліку ( z0948-02 ) доповнити окремим рядком "Київський державний художньо-виробничий комбінат Міністерства культури і туризму".

2. У тексті наказу Міністерства культури і мистецтв України від 15.11.2002 N 647 ( z0948-02 ) "Про затвердження Переліку державних установ, закладів культури, інших організацій, яким надається право проведення державної експертизи культурних цінностей", зареєстрованого в Міністерстві юстиції України 05.12.2002 за N 948/7236, слова "Міністерство культури і мистецтв України" замінити словами "Міністерство культури і туризму України" у відповідному відмінку.

3. Державній службі контролю за переміщенням культурних цінностей через державний кордон України:

1) забезпечити подання наказу на державну реєстрацію до Міністерства юстиції України;

2) у десятиденний термін після державної реєстрації довести цей наказ до відома Міністерства культури і мистецтв Автономної Республіки Крим, управлінь культури обласних, Севастопольської міської державних адміністрацій, Головного управління культури та мистецтва Київської міської державної адміністрації.

4. Контроль за виконанням наказу покласти на заступника Голови Державної служби контролю за переміщенням культурних цінностей через державний кордон України С.М.Шкляр.
