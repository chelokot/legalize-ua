Зареєстровано в Міністерстві юстиції України 23 травня 2005 р. за N 554/10834

Про втрату чинності деяких наказів Міністерства транспорту України

На виконання доручення Кабінету Міністрів України від 22.12.2004 N 54412/1/1-04 та у зв'язку з прийняттям Державіаслужбою власних нормативно-правових актів НАКАЗУЮ:

1. Уважати такими, що втратили чинність, накази Міністерства транспорту України:

від 28.01.99 N 41 ( z0058-99 ) "Про затвердження Положення про порядок проведення конкурсу на право експлуатації міжнародної повітряної лінії", зареєстрований в Міністерстві юстиції України 02.02.99 за N 58/3351;

від 23.06.99 N 327 ( z0440-99 ) "Про затвердження Положення про призначене авіапідприємство з боку України на експлуатацію міжнародної повітряної лінії", зареєстрований в Міністерстві юстиції України 05.07.99 за N 440/3733;

від 27.12.99 N 629 ( z0082-00 ) "Про затвердження Положення про сертифікацію суб'єктів, що надають агентські послуги з продажу авіаційних перевезень на території України", зареєстрований в Міністерстві юстиції України 10.02.2000 за N 82/4303;

від 29.05.2000 N 272 ( z0329-00 ) "Про внесення змін до наказу Міністерства транспорту України від 27.12.99 N 629", зареєстрований в Міністерстві юстиції України 05.06.2000 за N 329/4550;

від 15.08.2000 N 430 ( z0043-01 ) "Про внесення змін і доповнень до Положення про сертифікацію суб'єктів, що надають агентські послуги з продажу авіаційних перевезень на території України, затвердженого наказом Міністерства транспорту України від 27.12.99 N 629", зареєстрований в Міністерстві юстиції України 19.01.2001 за N 43/5234;

від 28.04.2004 N 354 ( z0574-04 ) "Про внесення змін до Положення про сертифікацію суб'єктів, що надають агентські послуги з продажу авіаційних перевезень на території України", зареєстрований в Міністерстві юстиції України 07.05.2004 за N 574/9173.

2. Департаменту нормативно-правового забезпечення (М.М. Ониськів) забезпечити подання цього наказу в установленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Рябікіна П.Б.

Міністр Є.А.Червоненко
