Кабінет Міністрів України; Розпорядження від 30.11.2004 № 876-р

Деякі питання переміщення товарів та іншого майна у пункті пропуску через державний кордон на аеродромі "Гостомель"

Стан: Втратив чинність

Ідентифікатор: 876-2004-р

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 листопада 2004 р. N 876-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 270-р ( 270-2006-р ) від 11.05.2006 }

Деякі питання переміщення товарів та іншого майна у пункті пропуску через державний кордон на аеродромі "Гостомель"

На часткову зміну розпорядження Кабінету Міністрів України від 15 жовтня 1992 р. N 678 ( 678-92-р ) установити, що пункт пропуску через державний кордон на аеродромі "Гостомель" використовується виключно для переміщення товарів, призначених для виробничих потреб Авіаційного науково-технічного комплексу імені О.К. Антонова, військового майна, товарів за державним замовленням і таких, що підлягають експертному контролю, а також вантажів гуманітарної допомоги.

Прем'єр-міністр України В.ЯНУКОВИЧ
