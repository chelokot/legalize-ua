КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 квітня 2004 р. N 476 Київ

Про внесення змін до Правил надання населенню послуг з газопостачання

{ Із змінами, внесеними згідно з Постановою КМ N 442 ( 442-2016-п ) від 13.07.2016 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 442 ( 442-2016-п ) від 13.07.2016 }

2. Міністерству палива та енергетики, Національній комісії регулювання електроенергетики, Державному комітетові з питань технічного регулювання та споживчої політики, Антимонопольному комітетові та Національній акціонерній компанії "Нафтогаз України" розробити і затвердити до 1 серпня 2004 р. Методику проведення перерахунку розміру плати за газопостачання у разі відхилення параметрів якості газу від встановленої величини.

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 8 червня 2001 р. N 644 ( 644-2001-п ) "Про внесення змін до постанови Кабінету Міністрів України від 9 грудня 1999 р. N 2246" (Офіційний вісник України, 2001 р., N 24, ст. 1075).
