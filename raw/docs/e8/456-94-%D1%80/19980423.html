Кабінет Міністрів України; Розпорядження від 15.06.1994 № 456-р

Про поширення дії розпорядження Кабінету Міністрів України від 30 травня 1994 р. N 378

Стан: Втратив чинність

Ідентифікатор: 456-94-р

Текст документа від 23.04.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 червня 1994 р. N 456-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 551 ( 551-98-п ) від 23.04.98 )

( Із змінами, внесеними згідно з Постановою КМ N 552 ( 552-95-п ) від 25.07.95 )

Поширити дію розпорядження Кабінету Міністрів України від 30 травня 1994 р. N 378 ( 378-94-р ) на працівників виконавчого апарату Українського державного концерну місцевої промисловості (Укрмісцевпром).

( На часткову зміну Розпорядження посаду голови державного концерну "Укрмісцевпром" віднесено до другої категорії державних службовців згідно з Постановою КМ N 552 ( 552-95-п ) від 25.07.95 )
