Кабінет Міністрів України; Розпорядження від 28.08.1996 № 544-р

Про утворення оперативної групи для організації контролю за ходом виконання рішень щодо стабілізації роботи вугільної промисловості України

Стан: Втратив чинність

Ідентифікатор: 544-96-р

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 серпня 1996 р. N 544-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

1. З метою організації контролю за ходом виконання рішень Президента України та Кабінету Міністрів України щодо стабілізації роботи вугільної промисловості утворити оперативну групу в складі згідно з додатком.

Надати керівникові групи право вносити зміни до її складу.

2. Першому віце-прем'єр-міністру України Дурдинцю В.В. утворити у складі зазначеної оперативної групи робочу групу з числа її членів, поклавши на неї обов'язки з організації підготовки матеріалів для розгляду на засіданнях оперативної групи та оформлення прийнятих рішень.

Прем'єр-міністр України П.ЛАЗАРЕНКО

Додаток до розпорядження Кабінету Міністрів України від 28 серпня 1996 р. N 544-р

СКЛАД оперативної групи для організації контролю за ходом виконання рішень Президента України та Кабінету Міністрів України щодо стабілізації роботи вугільної промисловості

ДУРДИНЕЦЬ В.В. - Перший віце-прем'єр-міністр України (керівник групи)

ПІДГАЙНИЙ Я.М. - перший заступник Міністра вугільної промисловості (заступник керівника групи)

ЛУЧНІКОВ В.А. - перший заступник Міністра енергетики та електрифікації

ТКАЧУК С.П. - голова Держнаглядохоронпраці

ЗІПІР А.П. - заступник Міністра вугільної промисловості

ВРУБЛЕВСЬКИЙ А.Г. - заступник Міністра економіки

ТЕНТЮК В.П. - заступник Міністра фінансів - голова Державного казначейства

ПЕРШИН В.Л. - заступник Міністра фінансів

КІРЕЄВ О.І. - заступник Голови правління Національного банку (за згодою)

ТЕРЕЩЕНКО В.П. - заступник Міністра промисловості

МЕЖИНСЬКИЙ В.В. - перший заступник голови Держтелерадіо

ЛАШКО А.Д. - заступник генерального директора Державної адміністрації залізничного транспорту

ЧЕРНИШОВ В.Г. - начальник Управління з питань паливно-енергетичного комплексу Кабінету Міністрів України

КОРЗУН А.В. - заступник завідуючого Відділом з питань паливно-енергетичного комлексу Кабінету Міністрів України (керівник робочої групи)

КРАСИЛЬЩИКОВ А.Л. - заступник завідуючого Відділом з питань соціального захисту та трудових відносин Кабінету Міністрів України

ЛИТВИН М.О. - помічник Першого віце-прем'єр-міністра України

ЗІНЬКОВ В.І. - головний спеціаліст Відділу з питань грошово-кредитної політики і фінансів Кабінету Міністрів України

КОЧУРА М.І. - головний спеціаліст Відділу розвитку національної економіки Кабінету Міністрів України

НЕГОДА С.Д. - головний спеціаліст Відділу взаємодії з місцевими радами і органами виконавчої влади Кабінету Міністрів України
