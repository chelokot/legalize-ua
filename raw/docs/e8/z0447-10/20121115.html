ЗМІНИ до Повідомлень щодо обслуговування повітряного руху - Авіаційних правил України ( z0354-02 )

{ Документ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства транспорту N 199 ( z0354-02 ) від 25.03.2002, до якого вносились зміни }

1. У пункті 1.6 глави 1:

1.1. Визначення "Укравіатранс - Державний департамент авіаційного транспорту України" замінити словами "Державіаадміністрація - Державна авіаційна адміністрація".

1.2. Доповнити пункт скороченнями та визначеннями в такій редакції, розмістивши їх в алфавітному порядку:

"CAM - Code Allocation Message - повідомлення про призначення коду;

CCAMS - Centralized SSR code Assignment and Management System - Система централізованого розподілу та управління кодами вторинної радіолокації;

CCM - Code Cancellation Message - повідомлення про відміну коду;

COR - Code Request Message - повідомлення про запит коду;

ETFMS - Enhanced Tactical Flow Management System - модернізована система тактичної організації потоків повітряного руху;".

2. Підпункт 6.3.5 пункту 6.3 глави 6 викласти в такій редакції:

"6.3.5. У разі якщо ПС, з яким стався інцидент, прямує до пункту призначення, що перебуває за межами зони обслуговування органу ОПР, який забезпечує обслуговування у районі, де стався інцидент, то необхідно повідомити про зазначений випадок орган ОПР на аеродромі призначення і попросити його одержати від пілота звіт про інцидент. До повідомлення необхідно включати таку інформацію:

а) тип інциденту (AIRPROX, правила чи засоби);

б) пізнавальний індекс відповідного ПС;

в) час і місцезнаходження ПС у момент інциденту;

г) короткі відомості про інцидент.

Типова форма звіту про інцидент під час повітряного руху публікується в АІР України.".
