Про скасування рішень голови Сумської обласної державної адміністрації Н. Гаркавої

Стан: Чинний

Ідентифікатор: 999/2006

Текст документа від 24.11.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про скасування рішень голови Сумської обласної державної адміністрації Н. Гаркавої

Внаслідок відсутності прийнятого в установленому порядку рішення про продовження терміну перебування голови Сумської обласної державної адміністрації Н. Гаркавої на державній службі та невнесення Кабінетом Міністрів України всупереч Конституції України ( 254к/96-ВР ) та Закону України "Про державну службу" ( 3723-12 ) подання щодо її звільнення із займаної посади Н. Гаркава продовжує на порушення Закону України "Про державну службу" ( 3723-12 ) перебувати на державній службі та виконувати посадові обов'язки на посаді голови місцевої державної адміністрації, в тому числі видавати розпорядження.

Видання розпоряджень Н. Гаркавою за відсутності законних підстав для перебування на державній службі не відповідає частині другій статті 19 Конституції України ( 254к/96-ВР ), за якою органи державної влади та їх посадові особи зобов'язані діяти на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України, статті 3 Закону України "Про місцеві державні адміністрації" ( 586-14 ), яка визначає принцип законності одним із принципів діяльності місцевих державних адміністрацій, статті 7 цього ж Закону ( 586-14 ), за якою місцеві державні адміністрації у своїй діяльності керуються, зокрема, Конституцією ( 254к/96-ВР ) та законами України.

Виходячи з наведеного, відповідно до частини восьмої статті 118 Конституції України ( 254к/96-ВР ) та статті 43 Закону України "Про місцеві державні адміністрації" ( 586-14 ) постановляю:

1. Скасувати розпорядження голови Сумської обласної державної адміністрації Н. Гаркавої, видані після 8 листопада 2006 року, як такі, що суперечать Конституції України ( 254к/96-ВР ) та Законам України "Про місцеві державні адміністрації" ( 586-14 ) та "Про державну службу" ( 3723-12 ).

2. Цей Указ набирає чинності з дня опублікування.

Президент України В.ЮЩЕНКО
