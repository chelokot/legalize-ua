ПОСТАНОВА від 23 липня 2008 р. N 681 Київ

{ Постанова втратила чинність одночасно з набранням чинності Указом Президента ( 387/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Питання державного управління в галузі автомобільного транспорту

{ Із змінами, внесеними згідно з Постановами КМ N 771 ( 771-2008-п ) від 03.09.2008 N 1228 ( 1228-2009-п ) від 18.11.2009 }

З метою удосконалення системи державного управління в галузі автомобільного транспорту Кабінет Міністрів України постановляє:

1. Утворити Державну адміністрацію автомобільного транспорту на базі Державного департаменту автомобільного транспорту, що ліквідується.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 1228 ( 1228-2009-п ) від 18.11.2009 }

4. Міністерству транспорту та зв'язку до 1 грудня поточного року:

здійснити заходи, пов'язані з реорганізацією Головної державної інспекції на автомобільному транспорті;

підготувати та подати Кабінетові Міністрів України Положення про Державну адміністрацію автомобільного транспорту;

внести в установленому порядку зміни до власних нормативно-правових актів.
