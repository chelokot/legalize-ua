Кабінет Міністрів України; Розпорядження від 05.11.2008 № 1400-р

Про підписання Угоди між Кабінетом Міністрів України і Урядом Російської Федерації про взаємне заснування відділень Торговельно-економічної місії у складі Посольства України в Російській Федерації та відділень Торговельного представництва Російської Федерації в Україні

Стан: Чинний

Ідентифікатор: 1400-2008-р

Текст документа від 24.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 листопада 2008 р. N 1400-р Київ

Про підписання Угоди між Кабінетом Міністрів України і Урядом Російської Федерації про взаємне заснування відділень Торговельно-економічної місії у складі Посольства України в Російській Федерації та відділень Торговельного представництва Російської Федерації в Україні

{ Із змінами, внесеними згідно з Розпорядженням КМ N 513-р ( 513-2009-р ) від 24.04.2009 }

Схвалити проект Угоди між Кабінетом Міністрів України і Урядом Російської Федерації про взаємне заснування відділень Торговельно-економічної місії у складі Посольства України в Російській Федерації та відділень Торговельного представництва Російської Федерації в Україні.

Уповноважити заступника Міністра закордонних справ Купчишина Олександра Михайловича підписати зазначену Угоду. { Абзац другій із змінами, внесеними згідно з Розпорядженням КМ N 513-р ( 513-2009-р ) від 24.04.2009 }
