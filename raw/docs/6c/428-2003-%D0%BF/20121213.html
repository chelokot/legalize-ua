Про затвердження нового складу Головної редакційної колегії науково-документальної серії книг "Реабілітовані історією"

Текст документа від 13.12.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 березня 2003 р. N 428 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1124 ( 1124-2012-п ) від 28.11.2012 }

Про затвердження нового складу Головної редакційної колегії науково-документальної серії книг "Реабілітовані історією"

На часткову зміну пункту 2 постанови Кабінету Міністрів України від 11 вересня 1992 р. N 530 ( 530-92-п ) "Про підготовку і випуск серії книг "Реабілітовані історією" затвердити новий склад Головної редакційної колегії науково-документальної серії книг "Реабілітовані історією" (додається).

Дозволити голові Колегії у разі потреби вносити зміни до її складу.
