Про граничну чисельність працівників центрального апарату Міністерства юстиції

Стан: Втратив чинність

Ідентифікатор: 2008-98-п

Текст документа від 25.05.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 грудня 1998 р. N 2008 Київ

Про граничну чисельність працівників центрального апарату Міністерства юстиції

( Із змінами, внесеними згідно з Постановами КМ N 118 ( 118-99-п ) від 29.01.99 N 904 ( 904-99-п ) від 25.05.99 )

Кабінет Міністрів України постановляє:

1. На часткову зміну додатка 1 до постанови Кабінету Міністрів України від 25 травня 1998 р. N 755 ( 755-98-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм місцевих органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 1998 р., N 22, ст. 800) затвердити граничну чисельність працівників центрального апарату Міністерства юстиції у кількості 370 одиниць і чисельність заступників Міністра юстиції - у кількості 7 одиниць, у тому числі заступник Міністра юстиції - Уповноважений у справах дотримання Конвенції про захист прав і основних свобод людини та заступник Міністра юстиції - директор департаменту державної виконавчої служби. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 118 ( 118-99-п ) від 29.01.99 ) ( На часткову зміну постанови установити кількість заступників Міністра юстиції вісім одиниць, у тому числі заступник Міністра юстиції - Уповноважений у справах дотримання Конвенції про захист прав і основних свобод людини та заступник Міністра юстиції - директор департаменту державної виконавчої служби, без зміни граничної чисельності працівників центрального апарату Міністерства згідно з Постановою КМ N 904 ( 904-99-п ) від 25.05.99 )

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 6 червня 1998 р. N 812 ( 812-98-п ) "Про граничну чисельність працівників центрального апарату Міністерства юстиції" (Офіційний вісник України, 1998 р., N 23, ст. 830);

пункт 1 постанови Кабінету Міністрів України від 3 вересня 1998 р. N 1375 ( 1375-98-п ) "Про граничну чисельність працівників системи Міністерства юстиції" (Офіційний вісник України, 1998 р., N 36, ст. 1325) в частині затвердження граничної чисельності працівників центрального апарату Міністерства юстиції.
