Кабінет Міністрів України; Постанова, Порядок від 14.10.2009 № 1134

Про виділення коштів для проведення першочергових робіт з будівництва системи відводу стічних вод від станції біологічної очистки "Північна" в м. Одесі

Стан: Чинний

Ідентифікатор: 1134-2009-п

Текст документа від 15.12.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 жовтня 2009 р. N 1134 Київ

Про виділення коштів для проведення першочергових робіт з будівництва системи відводу стічних вод від станції біологічної очистки "Північна" в м. Одесі

{ Із змінами, внесеними згідно з Постановою КМ N 1339 ( 1339-2009-п ) від 02.12.2009 }

Кабінет Міністрів України постановляє:

1. Виділити Міністерству регіонального розвитку та будівництва за рахунок нерозподілених коштів Стабілізаційного фонду за напрямом, передбаченим пунктом 22 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), 83 млн. гривень для проведення першочергових робіт з будівництва системи відводу стічних вод від станції біологічної очистки "Північна" в м. Одесі.

Міністерству фінансів здійснити зазначені видатки, а Державному казначейству забезпечити перерахування коштів у встановленому порядку.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1339 ( 1339-2009-п ) від 02.12.2009 }

2. Затвердити Порядок використання у 2009 році коштів Стабілізаційного фонду для проведення першочергових робіт з будівництва системи відводу стічних вод від станції біологічної очистки "Північна" в м. Одесі, що додається.

3. Внести до розпорядження Кабінету Міністрів України від 3 вересня 2009 р. N 1157 ( 1157-2009-р ) "Про виділення коштів для здійснення в регіонах деяких невідкладних природоохоронних заходів" зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 жовтня 2009 р. N 1134

ПОРЯДОК використання у 2009 році коштів Стабілізаційного фонду для проведення першочергових робіт з будівництва системи відводу стічних вод від станції біологічної очистки "Північна" в м. Одесі

1. Цей Порядок визначає механізм використання у 2009 році коштів Стабілізаційного фонду, виділених відповідно до пункту 22 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), для проведення першочергових робіт з будівництва системи відводу стічних вод від станції біологічної очистки "Північна" в м. Одесі (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Мінрегіонбуд.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1339 ( 1339-2009-п ) від 02.12.2009 }

3. Мінрегіонбуд подає Мінфіну пропозиції щодо розподілу бюджетних коштів за кодами економічної класифікації видатків державного бюджету. Мінфін з урахуванням зазначених пропозицій визначає бюджетну програму, закріплює за нею код програмної та функціональної класифікації видатків та кредитування державного бюджету і вносить зміни до розпису державного бюджету.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1339 ( 1339-2009-п ) від 02.12.2009 }

4. Бюджетні кошти спрямовуються з урахуванням Порядку використання у 2009 році коштів Стабілізаційного фонду, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) (Офіційний вісник України, 2009 р., N 24, ст. 793).

5. Об'єкти капітального будівництва фінансуються відповідно до Порядку державного фінансування капітального будівництва, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) (Офіційний вісник України, 2001 р., N 52, ст. 2374).

6. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

7. Після закінчення бюджетного періоду залишки бюджетних коштів, що обліковуються на рахунках розпорядників бюджетних коштів станом на 1 січня 2010 р. за визначеною бюджетною програмою, підлягають обов'язковому поверненню до Стабілізаційного фонду.

8. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 жовтня 2009 р. N 1134

ЗМІНИ, що вносяться до розпорядження Кабінету Міністрів України від 3 вересня 2009 р. N 1157 ( 1157-2009-р )

Пункти 1 і 3 викласти в такій редакції:

"1. Виділити Держводгоспу 83,5 млн. гривень для проведення першочергових робіт з будівництва системи відводу стічних вод від станції біологічної очистки "Північна" в м. Одесі за рахунок залишку коштів Державного фонду охорони навколишнього природного середовища, який утворився на 1 січня 2009 року.

Визначити Держводгосп головним розпорядником коштів Державного фонду охорони навколишнього природного середовища, виділених на зазначені цілі.

Мінфіну забезпечити визначення бюджетної програми, закріплення за нею кодів програмної та функціональної класифікації видатків кредитування бюджету та внесення змін до розпису державного бюджету.";

"3. Держводгоспу:

забезпечити використання виділених згідно з абзацом першим цього розпорядження коштів з урахуванням Порядку державного фінансування капітального будівництва, затвердженого постановою Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) (Офіційний вісник України, 2001 р., N 52, ст. 2374);

подати до 20 січня 2010 р. Мінфіну та Державному казначейству звіт про використання зазначених коштів.".
