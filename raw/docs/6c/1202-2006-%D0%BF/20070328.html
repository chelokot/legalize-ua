Стан: Чинний

Ідентифікатор: 1202-2006-п

Текст документа від 28.03.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 серпня 2006 р. N 1202 Київ

Про внесення змін до деяких постанов Кабінету Міністрів України та визнання такою, що втратила чинність, постанови Кабінету Міністрів України від 17 грудня 2005 р. N 1214

{ Із змінами, внесеними згідно з Постановою КМ N 556 ( 556-2007-п ) від 28.03.2007 }

Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України зміни, що додаються.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 17 грудня 2005 р. N 1214 ( 1214-2005-п ) (Офіційний вісник України, 2005 р., N 51, ст. 3201).

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 30

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 серпня 2006 р. N 1202

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. Абзац другий пункту 13 розділу IV Тимчасового регламенту Кабінету Міністрів України, затвердженого постановою Кабінету Міністрів України від 5 червня 2000 р. N 915 ( 915-2000-п ) (Офіційний вісник України, 2000 р., N 24, ст. 994; 2004 р., N 9, ст. 535, N 15, ст. 1038; 2005 р., N 42 ст. 2657; 2006 р., N 18, ст. 1346, N 27 ст. 1952), викласти у такій редакції:

"У разі відсутності з поважних причин міністра, керівника іншого центрального органу виконавчої влади, який є членом урядового комітету, в засіданні комітету може брати участь з правом дорадчого голосу один з його заступників (а замість керівника колегіального органу - один з членів цього органу) за попереднім погодженням з головою урядового комітету".

2. У пункті 1 постанови Кабінету Міністрів України від 24 лютого 2003 р. N 238 ( 238-2003-п ) "Про організацію розгляду питань євроатлантичної інтеграції України" (Офіційний вісник України, 2003 р., N 9, ст. 386; 2005 р., N 42, ст. 2657) слова "Урядовий комітет з питань правової політики та оборони" замінити словами "Урядовий комітет з питань правової політики, оборони, міжнародного співробітництва та європейської інтеграції".
