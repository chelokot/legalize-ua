Про затвердження Положення про Центральний відділ реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї та Положення про Лівобережний відділ реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 2926/5 ( z1179-10 ) від 23.11.2010 }

Відповідно до підпункту 29 пункту 4 Положення про Міністерство юстиції України, затвердженого постановою Кабінету Міністрів України від 14.11.2006 N 1577 ( 1577-2006-п ) (із змінами), НАКАЗУЮ:

1. Затвердити Положення про Центральний відділ реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї (додається).

2. Затвердити Положення про Лівобережний відділ реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї (додається) ( z0283-10 ).

3. Визнати таким, що втратив чинність, наказ Міністерства юстиції України від 21.07.99 N 44/5 ( z0491-99 ) "Про затвердження Положення про Центральний відділ реєстрації шлюбів м. Києва з Державним центром розвитку сім'ї", зареєстрований в Міністерстві юстиції України 21.07.99 за N 491/3784 (із змінами).

4. Визнати таким, що втратив чинність, наказ Міністерства юстиції України від 27.09.99 N 59/5 ( z0660-99 ) "Про затвердження Положення про Лівобережний відділ реєстрації шлюбів м. Києва з Державним центром розвитку сім'ї", зареєстрований в Міністерстві юстиції України 30.09.99 за N 660/3953 (із змінами).

5. Цей наказ набирає чинності з дня його офіційного опублікування.

6. Департаменту у справах цивільного стану громадян (Кунда В.В.) подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами).

7. Контроль за виконанням цього наказу покласти на заступника Міністра Єфіменка Л.В.

ЗАТВЕРДЖЕНО Наказ Міністерства юстиції України 07.04.2010 N 726/5

Зареєстровано в Міністерстві юстиції України 9 квітня 2010 р. за N 282/17577

ПОЛОЖЕННЯ про Центральний відділ державної реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї

{ У назві та тексті Положення слова "реєстрація шлюбів", "реєстрація шлюбу" в усіх відмінках замінено словами "державна реєстрація шлюбів", "державна реєстрація шлюбу" у відповідному відмінку згідно з Наказом Міністерства юстиції N 2926/5 ( z1179-10 ) від 23.11.2010 }

1. Центральний відділ державної реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї (далі - відділ) є територіальним органом Міністерства юстиції України, ним створюється, реорганізується, ліквідується і безпосередньо йому підпорядковується.

{ Пункт 1 із змінами, внесеними згідно з Наказом Міністерства юстиції N 2926/5 ( z1179-10 ) від 23.11.2010 }

2. Відділ у своїй діяльності керується Конституцією України ( 254к/96-ВР ), законами України, а також актами Президента України, постановами Верховної Ради України, Кабінету Міністрів України, наказами Міністерства юстиції, іншими нормативно-правовими актами та цим Положенням.

3. Основними завданнями відділу є:

3.1. Забезпечення повної, своєчасної і правильної державної реєстрації шлюбу відповідно до чинного законодавства.

3.2. Забезпечення у межах визначеної компетенції реалізації особистих немайнових прав громадян.

3.3. Реалізація державної політики щодо розвитку та зміцнення сім'ї.

3.4. Збереження архівного фонду.

3.5. Ведення з дотриманням вимог чинного законодавства Державного реєстру актів цивільного стану громадян.

3.6. Видача свідоцтв про шлюб.

{ Підпункт 3.6 пункту 3 в редакції Наказу Міністерства юстиції N 2926/5 ( z1179-10 ) від 23.11.2010 }

4. Відділ відповідно до покладених на нього завдань:

4.1. Проводить державну реєстрацію шлюбу та про кожний факт реєстрації акту цивільного стану видає відповідне свідоцтво.

4.2. Уносить до Державного реєстру актів цивільного стану громадян відомості про шлюб, а також про внесення змін, поновлення та анулювання актових записів про шлюб відповідно до Порядку ведення Державного реєстру актів цивільного стану громадян, затвердженого постановою Кабінету Міністрів України від 22.08.2007 N 1064 ( 1064-2007-п ) (зі змінами).

{ Підпункт 4.2 пункту 4 із змінами, внесеними згідно з Наказом Міністерства юстиції N 2926/5 ( z1179-10 ) від 23.11.2010 }

4.3. При прийнятті заяви про державну реєстрацію шлюбу на бажання наречених видає направлення на медичне обстеження.

4.4. Забезпечує належне зберігання та оформлення книг державної реєстрації шлюбів та іншої документації, пов'язаної з державною реєстрацією шлюбу.

4.5. Веде у встановленому законодавством порядку (на паперових та електронних носіях) облік актових записів про шлюб.

4.6. Видає повторно свідоцтва про шлюб та витяги/повні витяги з Державного реєстру актів цивільного стану громадян у порядку, встановленому чинним законодавством України.

{ Підпункт 4.6 пункту 4 із змінами, внесеними згідно з Наказом Міністерства юстиції N 2926/5 ( z1179-10 ) від 23.11.2010 }

4.7. Забезпечує належні облік та зберігання, а також витрачання бланків свідоцтв про шлюб з дотриманням вимог законодавства.

4.8. Вивчає й узагальнює практику застосування чинного законодавства з питань державної реєстрації актів цивільного стану.

4.9. Подає до Міністерства юстиції України звіти про державну реєстрацію шлюбу та використання бланків свідоцтв про шлюб.

4.10. Надсилає звіти про державну реєстрацію шлюбу за формами N 97 "Про реєстрацію актів цивільного стану" (місячна) та N 98 "Про реєстрацію актів цивільного стану" (піврічна, річна), затвердженими наказом Міністерства юстиції України від 12.10.2009 N 1822/5 ( z0949-09 ), зареєстрованим в Мін'юсті 12.10.2009 за N 949/16965, до Головного управління юстиції у місті Києві.

4.11. Розглядає звернення громадян, а також запити установ та організацій з питань, що належать до компетенції відділу.

4.12. Організовує та надає фізичним особам з дотриманням вимог чинного законодавства платні послуги, перелік яких затверджується Кабінетом Міністрів України.

{ Підпункт 4.12 пункту 4 в редакції Наказу Міністерства юстиції N 2926/5 ( z1179-10 ) від 23.11.2010 }

4.13. Організовує проведення досліджень сучасної сім'ї за науковими методиками і подає свої висновки й пропозиції Міністерству юстиції України, іншим організаціям та установам.

5. Відділ має право:

5.1. Безоплатно одержувати від органів державної влади, підприємств, установ та організацій документи, необхідні для виконання покладених на нього завдань.

5.2. Розробляти програми щодо розвитку та зміцнення сім'ї.

5.3. Залучати до роботи кваліфікованих спеціалістів, укладати угоди з фізичними та юридичними особами з метою забезпечення завдань та функцій відділу.

5.4. Використовувати кошти згідно з кошторисом доходів та видатків.

6. Відділ взаємодіє з іншими органами реєстрації актів цивільного стану та місцевими органами виконавчої влади, органами місцевого самоврядування, а також підприємствами, установами та організаціями з питань, що належать до його компетенції.

7. Начальник відділу призначається на посаду та звільняється з посади Міністром юстиції України.

Начальником відділу може бути громадянин України, який має повну вищу юридичну освіту за освітньо-кваліфікаційним рівнем спеціаліста, магістра та стаж роботи у сфері правової діяльності на державній службі на посаді головного спеціаліста чи в інших сферах управління не менше трьох років.

Начальник відділу має заступника, який призначається на посаду та звільняється з посади Міністром юстиції України.

8. Начальник відділу:

8.1. Здійснює керівництво відділом, організовує його роботу та відповідає за виконання покладених на відділ завдань і здійснення ним своїх функцій.

8.2. Уносить подання щодо призначення на посаду та звільнення з посади заступника начальника відділу, заохочення і притягнення його до дисциплінарної відповідальності.

8.3. Призначає на посади та звільняє з посад спеціалістів та інших працівників відділу, вирішує питання щодо їх заохочення та притягнення до дисциплінарної відповідальності.

8.4. Забезпечує та контролює дотримання працівниками відділу виконавської та трудової дисципліни.

8.5. Веде особистий прийом громадян.

8.6. Видає у межах своєї компетенції накази, організовує та контролює ведення діловодства у відділі.

8.7. Розподіляє обов'язки між працівниками відділу та затверджує посадові інструкції працівників відділу.

8.8. Організовує підвищення кваліфікації працівників відділу.

8.9. У встановленому законом порядку вирішує питання про скорочення місячного строку державної реєстрації шлюбу.

8.10. Розпоряджається коштами в межах кошторису доходів і видатків, забезпечує дотримання фінансової та штатної дисципліни, збереження коштів і матеріальних цінностей.

8.11. Відповідає за належне зберігання та облік, оформлення і ведення книг державної реєстрації шлюбів та іншої службової документації.

8.12. Відповідає за належні облік та зберігання, а також витрачання бланків свідоцтв про шлюб з дотриманням вимог законодавства.

8.13. Відповідає за належну організацію роботи щодо надання згідно з частиною третьою статті 20 Закону України "Про державну реєстрацію актів цивільного стану" ( 2398-17 ) платних послуг, а також ведення обліку платних послуг відповідно до порядку надання платних послуг відділами державної реєстрації актів цивільного стану, що затверджується Міністерством юстиції України.

{ Підпункт 8.13 пункту 8 в редакції Наказу Міністерства юстиції N 2926/5 ( z1179-10 ) від 23.11.2010 }

{ Підпункт 8.14 пункту 8 виключено на підставі Наказу Міністерства юстиції N 2926/5 ( z1179-10 ) від 23.11.2010 }

9. Відділ утримується за рахунок Державного бюджету України. Організаційна штатна структура та штатний розпис відділу затверджуються Міністерством юстиції України.

10. Відділ є юридичною особою, має печатку із зображенням Державного Герба України та своїм найменуванням.

11. У разі ліквідації відділу майно та кошти передаються на баланс Головного управління юстиції у місті Києві.
