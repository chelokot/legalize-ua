Про заходи стабілізації ситуації, що склалася на внутрішньому ринку цукру

Стан: Втратив чинність

Ідентифікатор: 611-2009-р

Текст документа від 13.06.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 травня 2009 р. N 611-р Київ

Про заходи стабілізації ситуації, що склалася на внутрішньому ринку цукру

{ Із змінами, внесеними згідно з Розпорядженням КМ N 638-р ( 638-2009-р ) від 13.06.2009 }

1. Держкомрезерву:

здійснити відпуск з державного матеріального резерву 10 тис. тонн цукру за ціною закупівлі з урахуванням витрат, пов'язаних із зберіганням, визначеним Мінекономіки підприємствам роздрібної торгівлі, насамперед тим, що мають розгалужену мережу, для реалізації його населенню з урахуванням балансів внутрішнього споживання цукру; { Абзац другий пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 638-р ( 638-2009-р ) від 13.06.2009 }

забезпечити поповнення запасів у державному резерві цукром, виробленим із цукрових буряків урожаю 2009 року, щонайменше в обсязі, відпущеному згідно з абзацом другим пункту 1 цього розпорядження.

2. Взяти до відома, що:

торговельна надбавка до ціни реалізації цукру з державного матеріального резерву не повинна перевищувати 15 відсотків оптово-відпускної ціни Держкомрезерву;

відпуск цукру з державного матеріального резерву здійснюється на умовах попередньої оплати без права експорту та перепродажу.

{ Пункт 2 в редакції Розпорядження КМ N 638-р ( 638-2009-р ) від 13.06.2009 }

3. Держцінінспекції забезпечити здійснення контролю за ціною продажу населенню цукру з державного матеріального резерву та інформувати щодекади Мінекономіки про ціну на нього.

{ Пункт 3 в редакції Розпорядження КМ N 638-р ( 638-2009-р ) від 13.06.2009 }
