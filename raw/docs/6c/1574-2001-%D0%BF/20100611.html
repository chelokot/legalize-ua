КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 листопада 2001 р. N 1574 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про утворення Експертно-консультаційної комісії з питань врегулювання проблем виробництва і обігу спирту, алкогольних напоїв та тютюнових виробів

( Із змінами, внесеними згідно з Постановами КМ N 408 ( 408-2002-п ) від 29.03.2002 N 1206 ( 1206-2002-п ) від 19.08.2002 )

З метою удосконалення механізмів регулювання виробництва, експорту, імпорту, оптової і роздрібної торгівлі спиртом етиловим, коньячним та плодовим, алкогольними напоями і тютюновими виробами Кабінет Міністрів України постановляє:

1. Утворити Експертно-консультаційну комісію з питань врегулювання проблем виробництва і обігу спирту, алкогольних напоїв та тютюнових виробів.
