Питання надання громадянам квартир, що придбані Державною іпотечною установою, у м. Артемівську

Стан: Чинний

Ідентифікатор: 32-2010-р

Текст документа від 24.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 січня 2010 р. N 32-р Київ

Питання надання громадянам квартир, що придбані Державною іпотечною установою, у м. Артемівську

{ Із змінами, внесеними згідно з Розпорядженням КМ N 293-р ( 293-2010-р ) від 24.02.2010 }

1. Затвердити погоджені Координаційною радою з питань розподілу квартир, що придбані Державною іпотечною установою, при Кабінеті Міністрів України поіменні списки громадян, яким надаються придбані у м. Артемівську Донецької області (вулиці О. Сибірцева, 172, і Широка, 4) квартири (далі - списки), що додаються до оригіналу.

{ Зміни до поіменного списку див. в Розпорядженні КМ N 293-р ( 293-2010-р ) від 24.02.2010 }

2. Державній іпотечній установі передати Міністерству оборони, Службі безпеки, Міністерству внутрішніх справ, Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Державному департаменту з питань виконання покарань, Генеральній прокуратурі України та Артемівській міській раді квартири для надання зазначеним у списках громадянам.

3. Виконавчому комітетові Артемівської міської ради забезпечити в установленому законодавством порядку видачу зазначеним у списках громадянам ордерів на жилі приміщення.

4. Міністерству оборони, Службі безпеки, Міністерству внутрішніх справ, Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Державному департаменту з питань виконання покарань, Генеральній прокуратурі України та Артемівській міській раді забезпечити неухильне дотримання встановленого Кабінетом Міністрів України порядку розподілу квартир, що придбані Державною іпотечною установою.

Прем'єр-міністр України Ю.ТИМОШЕНКО
