Кабінет Міністрів України; Розпорядження від 23.07.2009 № 917-р

Про виділення коштів Стабілізаційного фонду для здешевлення кредитів та підтримки окремих проектів в агропромисловому комплексі

Стан: Чинний

Ідентифікатор: 917-2009-р

Текст документа від 19.08.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 липня 2009 р. N 917-р Київ

Про виділення коштів Стабілізаційного фонду для здешевлення кредитів та підтримки окремих проектів в агропромисловому комплексі

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1014-р ( 1014-2009-р ) від 19.08.2009 }

1. Виділити Мінагрополітики за рахунок коштів Стабілізаційного фонду за напрямом, визначеним у пункті 1 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), 275 000 тис. гривень для здешевлення кредитів та підтримки окремих проектів в агропромисловому комплексі, в тому числі:

1) на безповоротній основі у сумі 205 000 тис. гривень для:

фінансової підтримки підприємств агропромислового комплексу через механізм здешевлення кредитів - 115 000 тис. гривень, у тому числі 30 000 тис. гривень - для здешевлення кредитів, залучених для реалізації інноваційних проектів, що пройшли державну реєстрацію в установленому законодавством порядку;

підтримки виробництва продукції тваринництва - 20 000 тис. гривень;

консервації шахти N 9 державного підприємства "Солотвинський солерудник", Тячівський район Закарпатської області - 35 000 тис. гривень;

державної підтримки сільськогосподарських обслуговуючих кооперативів - 90 000 тис. гривень; { Абзац п'ятий підпункту 1 пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 1014-р ( 1014-2009-р ) від 19.08.2009 }

2) на поворотній основі у сумі 70 000 тис. гривень за таким напрямом, як підтримка окремих проектів в агропромисловому комплексі, зокрема для надання кредитів фермерським господарствам.

Зазначені кошти Стабілізаційного фонду використовуються відповідно до Порядку використання у 2009 році коштів Стабілізаційного фонду для здешевлення кредитів, фінансування інвестиційних проектів та підтримки окремих проектів в агропромисловому комплексі, затвердженого постановою Кабінету Міністрів України від 13 травня 2009 р. N 463 ( 463-2009-п ) (Офіційний вісник України, 2009 р., N 36, ст. 1225).

2. Мінфіну виділити асигнування в обсязі 275 000 тис. гривень, визначивши джерелом покриття видатків надходження від цільового розміщення державних цінних паперів.

Прем'єр-міністр України Ю.ТИМОШЕНКО
