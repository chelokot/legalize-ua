28.02.2006 N 68

Зареєстровано в Міністерстві юстиції України 13 березня 2006 р. за N 263/12137

Про залучення банків України до касового обслуговування з метою оплати готівкою чеків органів Державного казначейства України у 2006 - 2008 роках

{ Із змінами, внесеними згідно з Наказами Державного казначейства N 79 ( z0387-07 ) від 03.04.2007 N 137 ( z0758-07 ) від 03.07.2007 N 74 ( z0213-08 ) від 25.02.2008 }

Керуючись п.1 постанови Кабінету Міністрів України від 1 березня 2001року N 200 ( 200-2001-п ) "Деякі питання касового виконання Державного бюджету України", результатами конкурсу з визначення банків, які залучатимуться до касового обслуговування з метою оплати готівкою чеків органів Державного казначейства України у 2006 - 2008 роках, НАКАЗУЮ:

1. Затвердити Перелік банків України та умови, на яких ці банки залучаються до касового обслуговування з метою оплати готівкою чеків органів Державного казначейства України у 2006 - 2008 роках (додається).

2. Установити, що для органів Державного казначейства України на місцях рішення розпорядників бюджетних коштів, які ними обслуговуються, стосовно вибору банку є пріоритетним.

3. Установити, що для виплат готівки органи Державного казначейства України можуть відкривати рахунки за балансовими рахунками 257-ї групи Плану рахунків бухгалтерського обліку банків України ( z0918-04 ) виключно в установах банків, що визначені цим наказом.

4. Управлінню фінансових ресурсів Державного казначейства України (Борець К.А.) подати цей наказ на державну реєстрацію до Міністерства юстиції України.

5. Цей наказ набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

6. Визнати таким, що втратив чинність, наказ Державного казначейства України від 10 січня 2005 року N3 ( z0059-05 ) "Про залучення банків України до касового обслуговування з метою оплати готівкою чеків органів Державного казначейства України", зареєстрований Міністерством юстиції України 19 січня 2005 року за N 59/10339.

7. Контроль за виконанням цього наказу покласти на начальника Департаменту обслуговування кошторисів головних розпорядників коштів та інших клієнтів Державного казначейства України (Шевчук В.О.) та начальників управлінь Державного казначейства в Автономній Республіці Крим, областях, містах Києві та Севастополі.
