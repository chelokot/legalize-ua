Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 26 липня 2006 р. N 1026

Стан: Втратив чинність

Текст документа від 26.01.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 грудня 2006 р. N 1720 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 12 ( 12-2009-п ) від 14.01.2009 }

Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 26 липня 2006 р. N 1026

Кабінет Міністрів України постановляє:

Внести зміну до пункту 1 постанови Кабінету Міністрів України від 26 липня 2006 р. N 1026 ( 1026-2006-п ) "Питання виготовлення бланків посвідчень ветеранів війни і бланків листів талонів на право одержання проїзних квитків" (Офіційний вісник України, 2006 р., N 30, ст. 2145), виклавши абзац другий у такій редакції:

"для інвалідів війни, учасників війни та осіб, на яких поширюється чинність Закону України "Про статус ветеранів війни, гарантії їх соціального захисту" ( 3551-12 ), - за замовленням Міністерства праці та соціальної політики;".

Прем'єр-міністр України В.ЯНУКОВИЧ
