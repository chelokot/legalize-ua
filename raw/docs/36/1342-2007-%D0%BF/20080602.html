ПОСТАНОВА від 21 листопада 2007 р. N 1342 Київ

{ Постанову скасовано на підставі Постанови КМ N 482 ( 482-2008-п ) від 21.05.2008 }

Про утворення Державного комітету харчової промисловості України

Кабінет Міністрів України постановляє:

1. Утворити на базі департаменту харчової промисловості Міністерства аграрної політики, що ліквідується, Державний комітет харчової промисловості України як центральний орган виконавчої влади (далі - Комітет), діяльність якого спрямовується і координується Кабінетом Міністрів України через Міністра аграрної політики.

2. Установити, що Комітет є правонаступником Міністерства аграрної політики з питань харчової та переробної промисловості.

3. Скасувати постанову Кабінету Міністрів України від 4 жовтня 2006 р. N 1380 ( 1380-2006-п ) "Про утворення Державного департаменту харчової промисловості та продовольчого ринку" (Офіційний вісник України, 2006 р., N 40, ст. 2684).

4. Міністерству аграрної політики:

1) подати в двомісячний строк Кабінетові Міністрів України пропозиції щодо:

визначення граничної чисельності працівників Комітету та вирішення інших питань, пов'язаних із забезпеченням його функціонування;

приведення актів законодавства у відповідність з цією постановою;

2) привести власні рішення у відповідність з цією постановою.

5. Взяти до відома, що Комітет розміщується в будинку по вул. Б. Грінченка, 1, у м. Києві.
