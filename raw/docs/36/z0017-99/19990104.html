НАКАЗ

N 1 від 04.01.99 Зареєстровано в Міністерстві м.Київ юстиції України 14 січня 1999 р. за N 17/3310

Про затвердження коефіцієнтів, що застосовуються до тарифів Прейскуранта N 10-01

З метою забезпечення конкурентоздатності продукції національних товаровиробників на міжнародному та внутрішньому ринках та створення умов для збільшення обсягів перевезень вантажів, відповідно до постанов Кабінету Міністрів України від 29 лютого 1996 року N 262 ( 262-96-п ) "Про затвердження Положення про Державну адміністрацію залізничного транспорту України", від 25 грудня 1996 року N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та від 18 грудня 1998 року N 1998 ( 1998-98-п ) "Про удосконалення порядку формування цін" НАКАЗУЮ:

1. Затвердити Коефіцієнти, що застосовуються до тарифів Прейскуранта N 10-01 "Тарифи на вантажні залізничні перевезення" для визначення вартості перевезення вантажів у національній валюті України (додаються).

2. Надати право Державній адміністрації залізничного транспорту України відповідно до економічної ефективності та собівартості перевезень знижувати не більш як на 25% розмір коефіцієнтів.

3. Укрзалізниці (А.В.Слободян) забезпечити своєчасне доведення цього наказу до відома вантажовідправників, вантажоодержувачів та населення України.

4. Головному управлінню тарифного та цінового регулювання (А.В.Кузьменко) разом з Головним управлінням правового забезпечення (Л.М.Логінова) в установленому порядку зареєструвати цей наказ у Міністерстві юстиції України.

5. Накази Міністерства транспорту від 04.09.98 N 352 ( z0582-98 ) "Про затвердження коефіцієнтів, що застосовуються до тарифів Прейскуранта N 10-01", від 16.10.98 N 408 ( z0699-98 ) "Про внесення змін та доповнень до коефіцієнтів, що застосовуються до тарифів Прейскуранта N 10-01" та від 02.11.98 N 425 ( z0726-98 ) "Про внесення доповнень до наказу Міністерства транспорту України від 04.09.98 р. N 352" визнати такими, що втратили чинність.

6. Контроль за виконанням наказу покласти на заступника генерального директора Укрзалізниці Л.М.Петренка.

Міністр І.П.Данькевич

Примітка. ЕМ - які перевозяться на експорт маршрутними відправками; Е - які перевозяться на експорт; ЕнМ - які перевозяться на експорт не маршрутними відправками; І, і. - імпортовані; У - які перевозяться в межах України.

1. Ці коефіцієнти застосовуються на всіх лініях залізниць України.

2. Коефіцієнти застосовуються при розрахуванні плати за перевезення вантажів усіх видів відправлень. Коефіцієнти, що застосовуються до тарифів Прейскуранта N 10-01, диференційовані залежно від роду вантажу та виду відправки.

3. Умови та порядок виконання перевезення вантажів залізничним транспортом, а також відповідальність сторін при цьому визначаються чинним законодавством.

4. Коефіцієнти затверджені для визначення вартості перевезення вантажів у національній валюті України.

5. Платня за перевезення вантажів визначається без урахування податку на додану вартість.
