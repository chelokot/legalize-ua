ПОСТАНОВА від 11 серпня 2010 р. N 707 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 110 ( 110-2011-п ) від 16.02.2011 }

Про внесення зміни до пункту 7-1 Порядку здійснення запозичень до місцевих бюджетів

Кабінет Міністрів України постановляє:

Внести зміну до абзацу п'ятого пункту 7-1 Порядку здійснення запозичень до місцевих бюджетів, затвердженого постановою Кабінету Міністрів України від 24 лютого 2003 р. N 207 ( 207-2003-п ) (Офіційний вісник України, 2003 р., N 9, ст. 377; 2006 р., N 45, ст. 3006; 2009 р., N 62, ст. 2196), доповнивши його після слів "іншої операції" словами ", а також запозичення з метою здійснення заходів з підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, передбачених Державною цільовою програмою підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженою постановою Кабінету Міністрів України від 14 квітня 2010 р. N 357 ( 357-2010-п ) (Офіційний вісник України, 2010 р., N 39, ст. 1297), зокрема з оновлення парку автобусів та тролейбусів міст, в яких проводитимуться матчі фінальної частини чемпіонату Європи 2012 року з футболу,".

Прем'єр-міністр України М.АЗАРОВ
