КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 вересня 2011 р. N 940 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1162 ( 1162-2012-п ) від 19.12.2012 }

Про відновлення дії постанов Кабінету Міністрів України від 24 жовтня 2001 р. N 1388 та від 13 лютого 2006 р. N 130

Кабінет Міністрів України постановляє:

Відновити дію постанов Кабінету Міністрів України від 24 жовтня 2001 р. N 1388 ( 1388-2001-п ) "Про затвердження Програми комплексного протипаводкового захисту в басейні р. Тиси у Закарпатській області на 2002-2006 роки та прогноз до 2015 року" (Офіційний вісник України, 2001 р., N 43, ст. 1932) та від 13 лютого 2006 р. N 130 ( 130-2006-п ) "Про внесення змін до постанови Кабінету Міністрів України від 24 жовтня 2001 р. N 1388" (Офіційний вісник України, 2006 р., N 7, ст. 352).

У зв'язку з цим пункти 4 та 18 переліку постанов Кабінету Міністрів України, що втратили чинність, затвердженого постановою Кабінету Міністрів України від 22 червня 2011 р. N 704 ( 704-2011-п ) "Про скорочення кількості та укрупнення державних цільових програм" (Офіційний вісник України, 2011 р., N 51, ст. 2036), скасувати.

Прем'єр-міністр України М.АЗАРОВ
