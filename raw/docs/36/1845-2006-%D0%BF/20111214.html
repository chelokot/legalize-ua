КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 грудня 2006 р. N 1845 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1030 ( 1030-2011-п ) від 05.10.2011 }

Про внесення зміни до постанови Кабінету Міністрів України від 13 квітня 2005 р. N 269

Кабінет Міністрів України постановляє:

1. У пункті 1 постанови Кабінету Міністрів України від 13 квітня 2005 р. N 269 ( 269-2005-п ) "Про здійснення попереднього документального контролю товарів у пунктах пропуску через державний кордон України" (Офіційний вісник України, 2005 р., N 15, ст. 760; 2006 р., N 26, ст. 1879) та у тексті Порядку здійснення попереднього документального контролю товарів у пунктах пропуску через державний кордон України, затвердженого зазначеною постановою, слово "радіологічний" у всіх відмінках виключити.

2. Ця постанова набирає чинності через 45 днів з дня офіційного опублікування.
