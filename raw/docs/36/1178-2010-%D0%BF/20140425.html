Кабінет Міністрів України; Постанова від 15.12.2010 № 1178

Про здійснення попередньої оплати робіт, пов'язаних з організацією та проведенням Міжнародної виставки-ярмарку "Grune-Woche - 2011"

Стан: Чинний

Ідентифікатор: 1178-2010-п

Текст документа від 25.04.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 грудня 2010 р. N 1178 Київ

Про здійснення попередньої оплати робіт, пов'язаних з організацією та проведенням Міжнародної виставки-ярмарку "Grune-Woche - 2011"

{ Із змінами, внесеними згідно з Постановою КМ N 117 ( 117-2014-п ) від 23.04.2014 }

З метою забезпечення участі України у Міжнародній виставці-ярмарку "Grune-Woche - 2011", яка відбудеться 21-30 січня 2011 р. у м. Берліні (Німеччина), Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Міністерства аграрної політики та продовольства щодо здійснення попередньої оплати робіт, пов'язаних з організацією та проведенням Міжнародної виставки-ярмарку "Grune-Woche - 2011", за рахунок коштів Стабілізаційного фонду ( 2154-17 ), виділених згідно з розпорядженням Кабінету Міністрів України від 15 вересня 2010 р. N 1833 ( 1833-2010-р ) "Про виділення коштів Стабілізаційного фонду для здешевлення кредитів, фінансування інвестиційних проектів, загальнодержавних та державних цільових програм в агропромисловому комплексі, вирішення питань матеріально-технічного забезпечення бюджетних установ агропромислового комплексу", - в сумі 4055000 гривень.

2. Взяти до відома, що виконавець робіт, пов'язаних з організацією та проведенням Міжнародної виставки-ярмарку "Grune-Woche - 2011", визначений Міністерством аграрної політики та продовольства в установленому порядку, подасть не пізніше ніж 15 лютого 2011 р. Міністерству звіт про використання коштів, зазначених у пункті 1 цієї постанови.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 117 ( 117-2014-п ) від 23.04.2014 }
