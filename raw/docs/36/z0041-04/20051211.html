Держатомрегулювання України; Наказ від 03.12.2003 № 149

Про доповнення Переліку посад працівників центрального апарату Державного комітету ядерного регулювання України, які безпосередньо виконують функції державного регулювання ядерної та радіаційної безпеки

Реєстрація: Мін'юст України від 14.01.2004 № 41/8640

Стан: Втратив чинність

Ідентифікатор: z0041-04

Текст документа від 11.12.2005:

ДЕРЖАВНИЙ КОМІТЕТ ЯДЕРНОГО РЕГУЛЮВАННЯ УКРАЇНИ

НАКАЗ

03.12.2003 N 149

Зареєстровано в Міністерстві юстиції України 14 січня 2004 р. за N 41/8640

( Наказ втратив чинність на підставі Наказу Державного комітету ядерного регулювання N 131 ( z1440-05 ) від 18.11.2005 )

Про доповнення Переліку посад працівників центрального апарату Державного комітету ядерного регулювання України, які безпосередньо виконують функції державного регулювання ядерної та радіаційної безпеки

У зв'язку зі зміною структури Державного комітету ядерного регулювання України та змінами, що сталися у штатному розписі на 2003 рік, з метою забезпечення виконання абзацу 1 пункту 3 постанови Кабінету Міністрів України від 02.04.2001 N 313 ( 313-2001-п ) "Деякі питання Державного комітету ядерного регулювання" НАКАЗУЮ:

1. Доповнити посадою заступника начальника відділу ліцензування ядерних установок Управління регулювання безпеки ядерних установок Перелік посад працівників центрального апарату Держатомрегулювання України, які безпосередньо виконують функції державного регулювання ядерної та радіаційної безпеки, затверджений наказом Держатомрегулювання України від 28.08.2003 N 113 ( z0804-03 ), який зареєстровано у Міністерстві юстиції України 15.09.2003 за N 804/8125.

2. Контроль за дотриманням цього наказу залишаю за собою.

Голова В.В.Грищенко
