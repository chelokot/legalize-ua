Текст документа від 24.01.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 43/2008 ( 43/2008 ) від 21.01.2008 }

Про внесення змін до Указу Президента України від 11 вересня 2006 року N 749

Відповідно до частини четвертої статті 107 Конституції України ( 254к/96-ВР ) постановляю:

На часткову зміну Указу Президента України від 11 вересня 2006 року N 749 ( 749/2006 ) "Про склад Ради національної безпеки і оборони України" (зі змінами, внесеними Указами від 20 вересня 2006 року N 761 ( 761/2006 ), від 17 жовтня 2006 року N 884 ( 884/2006 ), від 15 листопада 2006 року N 966 ( 966/2006 ) та від 24 листопада 2006 року N 1000 ( 1000/2006 ):

1) ввести до складу Ради національної безпеки і оборони України ЦУШКА Василя Петровича - Міністра внутрішніх справ України;

2) вивести зі складу Ради національної безпеки і оборони України Ю. Луценка.

Президент України В.ЮЩЕНКО

м. Київ, 14 грудня 2006 року N 1074/2006
