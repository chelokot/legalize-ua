ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 травня 2010 р. N 366

ПОРЯДОК використання коштів, передбачених у державному бюджеті на придбання шкільних автобусів для перевезення дітей, що проживають у сільській місцевості

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 274 ( 274-2011-п ) від 28.02.2011 }

{ У тексті Порядку слово "МОН" замінено словами "Міністерство освіти і науки, молоді та спорту" у відповідному відмінку згідно з Постановою КМ N 1176 ( 1176-2010-п ) від 20.12.2010 }

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті Міністерству освіти і науки, молоді та спорту за програмою "Придбання шкільних автобусів для перевезення дітей, що проживають у сільській місцевості" (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 274 ( 274-2011-п ) від 28.02.2011 }

2. Головним розпорядником бюджетних коштів є Міністерство освіти і науки, молоді та спорту, розпорядником бюджетних коштів нижчого рівня - Інститут інноваційних технологій і змісту освіти (далі - розпорядник бюджетних коштів).

Головний розпорядник та розпорядник бюджетних коштів забезпечують їх цільове та ефективне використання. { Пункт 2 доповнено абзацом згідно з Постановою КМ N 274 ( 274-2011-п ) від 28.02.2011 }

3. Бюджетні кошти спрямовуються на закупівлю шкільних автобусів для перевезення дітей, що проживають у сільській місцевості, а також спеціальних шкільних автобусів, у яких обладнано місця для дітей з обмеженими фізичними можливостями на інвалідних візках, з метою забезпечення учнів (вихованців) навчальних закладів у сільській місцевості транспортом до місця навчання і додому безоплатно відповідно до статті 21 Закону України "Про загальну середню освіту" ( 651-14 ).

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1176 ( 1176-2010-п ) від 20.12.2010; в редакції Постанови КМ N 274 ( 274-2011-п ) від 28.02.2011 }

3-1. Бюджетні кошти використовуються з урахуванням необхідності виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державної казначейської служби, у разі їх відповідності паспорту бюджетної програми.

{ Порядок доповнено пунктом 3-1 згідно з Постановою КМ N 274 ( 274-2011-п ) від 28.02.2011 }

4. Пропорційний розподіл шкільних автобусів і спеціальних шкільних автобусів, у яких обладнано місця для дітей з обмеженими фізичними можливостями на інвалідних візках, здійснюється головним розпорядником бюджетних коштів відповідно до заявок Міністерства освіти і науки Автономної Республіки Крим, головних управлінь (управлінь) освіти і науки обласних та Севастопольської міської держадміністрацій, що складаються з урахуванням розподілу бюджетних коштів на поточний рік, виділених на таку мету, із зазначенням районів адміністративно-територіальних одиниць та подаються Міністерству освіти і науки, молоді та спорту в установленому ним порядку. { Абзац перший пункту 4 із змінами, внесеними згідно з Постановами КМ N 1176 ( 1176-2010-п ) від 20.12.2010, N 274 ( 274-2011-п ) від 28.02.2011 }

Перелік районів адміністративно-територіальних одиниць, до яких поставляються шкільні автобуси і спеціальні шкільні автобуси, в яких обладнано місця для дітей з обмеженими фізичними можливостями на інвалідних візках, затверджує Міністерство освіти і науки, молоді та спорту. { Абзац другий пункту 4 із змінами, внесеними згідно з Постановами КМ N 1176 ( 1176-2010-п ) від 20.12.2010, N 274 ( 274-2011-п ) від 28.02.2011 }

Остаточний розподіл шкільних автобусів і спеціальних шкільних автобусів, у яких обладнано місця для дітей з обмеженими фізичними можливостями на інвалідних візках, здійснюється головним розпорядником бюджетних коштів за результатами їх закупівлі. { Пункт 4 доповнено абзацом згідно з Постановою КМ N 799 ( 799-2011-п ) від 25.07.2011 }

5. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється в установленому законодавством порядку.

6. Розпорядник бюджетних коштів на підставі договорів про закупівлю може здійснювати попередню оплату у розмірі до 30 відсотків вартості шкільних автобусів і спеціальних шкільних автобусів, у яких обладнано місця для дітей з обмеженими фізичними можливостями на інвалідних візках, визначеної в договорах про їх закупівлю. { Абзац перший пункту 6 в редакції Постанов КМ N 1176 ( 1176-2010-п ) від 20.12.2010, N 274 ( 274-2011-п ) від 28.02.2011 }

У разі коли протягом одного місяця після внесення попередньої оплати поставка зазначених автобусів не здійснена, сума попередньої оплати підлягає поверненню розпоряднику бюджетних коштів. { Абзац другий пункту 6 із змінами, внесеними згідно з Постановою КМ N 274 ( 274-2011-п ) від 28.02.2011 }

Остаточна оплата вартості шкільних автобусів та спеціальних шкільних автобусів здійснюється на підставі актів приймання-передачі. { Абзац третій пункту 6 із змінами, внесеними згідно з Постановою КМ N 274 ( 274-2011-п ) від 28.02.2011 }

Постачальник у разі отримання попередньої оплати не пізніше ніж 5 числа місяця, що настає за звітним періодом, подає розпоряднику бюджетних коштів інформацію про фактично поставлені шкільні автобуси і спеціальні шкільні автобуси, в яких обладнано місця для дітей з обмеженими фізичними можливостями на інвалідних візках, за формою, встановленою розпорядником бюджетних коштів. { Пункт 6 доповнено абзацом згідно з Постановою КМ N 1176 ( 1176-2010-п ) від 20.12.2010; із змінами, внесеними згідно з Постановою КМ N 274 ( 274-2011-п ) від 28.02.2011 }

7. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого в установленому порядку.

{ Пункт 7 із змінами, внесеними згідно з Постановою КМ N 274 ( 274-2011-п ) від 28.02.2011 }

8. Розпорядник бюджетних коштів надсилає щомісяця до 15 числа Міністерству освіти і науки, молоді та спорту в установленому ним порядку інформацію про використання бюджетних коштів та кількість придбаних автобусів у розрізі районів адміністративно-територіальних одиниць для її узагальнення та подання Мінфіну щомісяця до 25 числа.

{ Пункт 8 із змінами, внесеними згідно з Постановою КМ N 274 ( 274-2011-п ) від 28.02.2011 }

9. Складення та подання фінансової і бюджетної звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.

{ Пункт 9 в редакції Постанови КМ N 274 ( 274-2011-п ) від 28.02.2011 }
