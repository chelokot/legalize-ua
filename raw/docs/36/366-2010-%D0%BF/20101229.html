ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 травня 2010 р. N 366

ПОРЯДОК використання у 2010 році коштів, передбачених у державному бюджеті ( 2154-17 ) на придбання шкільних автобусів для перевезення дітей, що проживають у сільській місцевості

{ У тексті Порядку слово "МОН" замінено словами "Міністерство освіти і науки, молоді та спорту" у відповідному відмінку згідно з Постановою КМ N 1176 ( 1176-2010-п ) від 20.12.2010 }

1. Цей Порядок визначає механізм використання у 2010 році коштів, передбачених у державному бюджеті ( 2154-17 ) Міністерству освіти і науки, молоді та спорту за програмою "Придбання шкільних автобусів для перевезення дітей, що проживають у сільській місцевості" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Міністерство освіти і науки, молоді та спорту, розпорядником бюджетних коштів нижчого рівня - Інститут інноваційних технологій і змісту освіти (далі - розпорядник бюджетних коштів).

3. Бюджетні кошти спрямовуються на закупівлю шкільних автобусів для перевезення дітей, що проживають у сільській місцевості, відповідно до Програми "Шкільний автобус", затвердженої постановою Кабінету Міністрів України від 16 січня 2003 р. N 31 ( 31-2003-п ) (Офіційний вісник України, 2003 р., N 3, ст. 80).

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1176 ( 1176-2010-п ) від 20.12.2010 }

4. Пропорційний розподіл шкільних автобусів здійснюється головним розпорядником бюджетних коштів відповідно до заявок Міністерства освіти і науки Автономної Республіки Крим, головних управлінь (управлінь) освіти і науки обласних та Севастопольської міської держадміністрацій, що складаються з урахуванням розподілу бюджетних коштів на 2010 рік ( 2154-17 ), виділених на таку мету, із зазначенням районів адміністративно-територіальних одиниць та подаються Міністерству освіти і науки, молоді та спорту в установленому ним порядку. { Абзац перший пункту 4 із змінами, внесеними згідно з Постановою КМ N 1176 ( 1176-2010-п ) від 20.12.2010 }

Перелік районів адміністративно-територіальних одиниць, до яких поставляються шкільні автобуси, затверджує Міністерство освіти і науки, молоді та спорту. { Абзац другий пункту 4 із змінами, внесеними згідно з Постановою КМ N 1176 ( 1176-2010-п ) від 20.12.2010 }

5. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється в установленому законодавством порядку.

6. Попередня оплата може вноситися у розмірі до 100 відсотків вартості шкільних автобусів, визначеної у договорах про їх закупівлю, за умови поставки шкільних автобусів не пізніше 30 січня 2011 року. { Абзац перший пункту 6 в редакції Постанови КМ N 1176 ( 1176-2010-п ) від 20.12.2010 }

У разі коли протягом одного місяця після внесення попередньої оплати поставка шкільних автобусів не здійснена, сума попередньої оплати підлягає поверненню розпоряднику бюджетних коштів.

Остаточна оплата вартості шкільних автобусів здійснюється на підставі актів приймання-передачі.

Постачальник у разі отримання попередньої оплати не пізніше ніж 5 числа місяця, що настає за звітним періодом, подає розпоряднику бюджетних коштів інформацію про фактично поставлені шкільні автобуси за формою, встановленою розпорядником бюджетних коштів. { Пункт 6 доповнено абзацом згідно з Постановою КМ N 1176 ( 1176-2010-п ) від 20.12.2010 }

7. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

8. Розпорядник бюджетних коштів надсилає щомісяця до 15 числа Міністерству освіти і науки, молоді та спорту в установленому ним порядку інформацію про використання бюджетних коштів для її узагальнення та подання Мінфіну щомісяця до 25 числа.

9. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
