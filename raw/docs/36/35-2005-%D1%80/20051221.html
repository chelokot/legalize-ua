Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 лютого 2005 р. N 35-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

Про робочу групу з опрацювання проблемних питань приватизації державного майна

( Із змінами, внесеними згідно з Розпорядженням КМ N 74-р ( 74-2005-р ) від 30.03.2005 )

1. Утворити робочу групу з опрацювання проблемних питань приватизації державного майна у складі згідно з додатком.

Надати керівникові робочої групи право вносити у разі потреби зміни до її складу.

2. Установити, що проекти нормативно-правових актів Кабінету Міністрів України з проблемних питань приватизації державного майна, схвалені робочою групою, подаються на засідання Кабінету Міністрів України без розгляду урядовими комітетами.
