Про затвердження Змін до деяких наказів

{ Із змінами, внесеними згідно з Наказами Міністерства екології та природних ресурсів N 250 ( z0784-12 ) від 03.05.2012 N 30 ( z0255-15 ) від 17.02.2015 }

Відповідно до Законів України "Про центральні органи виконавчої влади" ( 3166-17 ), від 17.03.2011 N 3165-VI ( 3165-17 ) "Про внесення змін до Закону України "Про Кабінет Міністрів України", Указів Президента України від 09.12.2010 N 1085 ( 1085/2010 ) "Про оптимізацію системи центральних органів виконавчої влади", від 06.04.2011 N 391 ( 391/2011 ) "Про Положення про Державну службу геології та надр України", від 13.04.2011 N 452 ( 452/2011 ) "Про Положення про Міністерство екології та природних ресурсів України", від 13.04.2011 N 454 ( 454/2011 ) "Про Положення про Державну екологічну інспекцію України", постанови Кабінету Міністрів України від 28.03.2011 N 346 ( 346-2011-п ) "Про ліквідацію урядових органів" НАКАЗУЮ:

1. Затвердити Зміни до деяких наказів, що додаються.

2. Юридичному департаменту (Роменський Д.В.) забезпечити подання цього наказу на державну реєстрацію в установленому порядку до Міністерства юстиції.

3. Контроль за виконанням цього наказу залишаю за собою.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

Перший заступник Міністра М.І.Романов

ЗАТВЕРДЖЕНО Наказ Міністерства екології та природних ресурсів України 09.06.2011 N 196

Зареєстровано в Міністерстві юстиції України 1 липня 2011 р. за N 794/19532

ЗМІНИ до деяких наказів

1. У пункті 1.4 глави 1, додатку 2 та додатку 3 до Інструкції про порядок видачі дозволів на добування (збирання) видів тварин і рослин, занесених до Червоної книги України, форм клопотання та бланків дозволів на таке добування, затвердженої наказом Міністерства охорони навколишнього природного середовища України від 01.02.93 N 3 ( z0004-93 ), зареєстрованої в Міністерстві юстиції України 12.02.93 за N 4, слова "Міністерство охорони навколишнього природного середовища України" замінити словами "Міністерство екології та природних ресурсів України".

2. В абзаці третьому пункту 13 та пункті 21 Положення про екологічні фонди природних заповідників, біосферних заповідників, національних природних парків, ботанічних садів, дендрологічних парків та зоологічних парків, затвердженого наказом Міністерства охорони навколишнього природного середовища України від 26.02.93 N 16 ( z0009-93 ), зареєстрованого в Міністерстві юстиції України 16.03.93 за N 9, слова "Міністерство охорони навколишнього природного середовища України" у всіх відмінках замінити словами "Міністерство екології та природних ресурсів України" у відповідних відмінках.

3. У Методиці розрахунку збитків, заподіяних рибному господарству внаслідок порушення законодавства про охорону навколишнього природного середовища, затвердженої наказом Міністерства охорони навколишнього природного середовища та ядерної безпеки України від 18.05.95 N 36 ( z0155-95 ), зареєстрованої в Міністерстві юстиції України 26.05.95 за N 155/691:

в абзаці першому пункту 1 слово "Мінекобезпеки" виключити;

абзац четвертий пункту 2 викласти у такій редакції:

"Положення про Державну екологічну інспекцію України, затверджене Указом Президента України від 13.04.2011 N 454 ( 454/2011 ).";

у пункті 3.3 глави 3 слово "Мінприроди" виключити;

у пункті 4.1 глави 4 слово "Мінекобезпеки" замінити словом "Держекоінспекції".

4. У тексті Загальних положень забезпечення безпеки при знятті з експлуатації атомних електростанцій та дослідницьких ядерних реакторів, затверджених наказом Міністерства охорони навколишнього природного середовища та ядерної безпеки України від 09.01.98 N 2 ( z0047-98 ), зареєстрованих у Міністерстві юстиції України 23.01.98 за N 47/2487, слово "Мінекобезпеки" замінити словами "Мінприроди України".

{ Пункт 5 втратив чинність на підставі Наказу Міністерства екології та природних ресурсів N 30 ( z0255-15 ) від 17.02.2015 }

6. У Структурі, змісті та порядку ведення паспорта водно-болотного угіддя міжнародного значення, затверджених наказом Міністерства екології та природних ресурсів України від 27.12.2002 N 524 ( z0040-03 ), зареєстрованих у Міністерстві юстиції України 20.01.2003 за N 40/7361:

у пункті 3.5. глави 3 слова "Державної служби заповідної справи" виключити;

у тексті слово "Мінекоресурсів" замінити словом "Мінприроди".

{ Пункт 7 фактично втратив чинність у зв'язку з втратою чинності Наказу міністерства охорони навколишнього природного середовища N 47 ( z0295-04 ) від 10.02.2004, до якого вносились зміни } 7. У тексті Положення про Міжвідомчу комісію з екологічних питань Азовського і Чорного морів, затвердженого наказом Міністерства охорони навколишнього природного середовища України від 10.02.2004 N 47 ( z0295-04 ), зареєстрованого в Міністерстві юстиції України 04.03.2004 за N 295/8894, слова "Міністерство охорони навколишнього природного середовища" у всіх відмінках замінити словом "Мінприроди".

8. У пункті 3.2 глави 3 та пункті 4.3 глави 4 Положення про щоквартальне інформування населення через ЗМІ про об'єкти, які є найбільшими забруднювачами навколишнього природного середовища, затвердженого наказом Міністерства охорони навколишнього природного середовища України від 01.11.2005 N 397 ( z1510-05 ), зареєстрованого в Міністерстві юстиції України 15.12.2005 за N 1510/11790, слова "Міністерство охорони навколишнього природного середовища" у всіх відмінках замінити словом "Мінприроди".

9. У Положенні про проведення Всеукраїнського конкурсу "Національне дерево України", затвердженому наказом Міністерства охорони навколишнього природного середовища України від 10.12.2009 N 611 ( z0018-10 ), зареєстрованому в Міністерстві юстиції України 13.01.2010 за N 18/17313:

у пункті 1.1 розділу І слова "Державною службою заповідної справи спільно з територіальними органами" виключити;

у тексті слова "Державна служба заповідної справи" у всіх відмінках замінити словами "Мінприроди України".
