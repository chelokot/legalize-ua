Текст документа від 18.05.2004:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Академію мистецтв України

( Із змінами, внесеними згідно з Указами Президента N 1289/96 ( 1289/96 ) від 31.12.96 N 1262/2000 ( 1262/2000 ) від 27.11.2000 N 268/2002 ( 268/2002 ) від 19.03.2002 N 463/2004 ( 463/2004 ) від 21.04.2004 )

З метою дальшого розвитку українського мистецтва, відродження національних традицій, проведення фундаментальних досліджень з історії становлення і розвитку художньої культури України постановляю:

1. Прийняти пропозицію групи провідних діячів мистецтв та науки і заснувати в місті Києві Академію мистецтв України як вищу творчо-наукову установу у галузі мистецтва.

2. Академія мистецтв України є самоврядною організацією, що діє на основі Статуту, може мати у своєму складі творчі майстерні та студії, науково-дослідні інститути, методичні центри, лабораторії, експериментальні навчальні заклади, інші установи для забезпечення творчої праці митців та наукових досліджень у галузі художньої культури.

3. Основними завданнями Академії мистецтв України є:

сприяння дальшому розвитку художньої творчості в Україні, створенню і поширенню художніх цінностей;

пошук ефективних шляхів відродження і збагачення української культури, розвиток національних мистецьких традицій, визначних художніх шкіл та осередків;

проведення фундаментальних науково-теоретичних досліджень з проблем художньої творчості, історії та теорії українського мистецтва, художньої критики, мистецької освіти та естетичного виховання молоді;

вивчення та наукове узагальнення світових тенденцій і досягнень у розвитку мистецтва, створення умов для ефективного використання цих досягнень з метою дальшого розвитку української культури, зміцнення культурного співробітництва з митцями іноземних держав.

4. Установити чисельність членів Академії мистецтв України у кількості 49 дійсних членів і 68 членів-кореспондентів. ( Стаття 4 із змінами, внесеними згідно з Указами Президента N 1262/2000 ( 1262/2000 ) від 27.11.2000, N 268/2002 ( 268/2002 ) від 19.03.2002, N 463/2004 ( 463/2004 ) від 21.04.2004 )

5. Перші вибори до Академії проводяться за Тимчасовим положенням про вибори до Академії мистецтв України, яке затверджують дійсні члени-засновники Академії.

Надати можливість стати членами Академії понад установлену чисельність дійсним членам і членам-кореспондентам колишньої Академії мистецтв СРСР, які є громадянами України.

Затвердити дійсними членами-засновниками Академії мистецтв України Авдієвського А.Т., Бєлікова М.О., Гнатюка Д.М., Данченка С.В., Іллєнка Ю.Г., Ляшенка І.Ф., Мащенка М.П., Миська Е.П., Резніковича М.І., Тимошенка О.С., Чебикіна А.В., Чепелика В.А., Вантуха М.М., Знобу В.І., Криволапова М.О., Сидоренка В.Д. ( Пункт 5 із змінами, внесеними згідно з Указом Президента N 1289/96 від 31.12.96 )

( На додаток до Указу призначити президентом-організатором Академії мистецтв України народного художника України Чебикіна Андрія Володимировича згідно з Указом Президента N 1289/96 від 31.12.96 )

6. Кабінету Міністрів України здійснити заходи, пов'язані з організацією Академії мистецтв України, передбачити у проекті Державного бюджету України на 1997 рік витрати на організацію і функціонування Академії.

7. Національній академії наук України надати організаційну та методичну допомогу в заснуванні Академії мистецтв України.

8. Цей Указ набирає чинності з дня його підписання.
