Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 травня 2004 р. N 295-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

Про зміну складу міжвідомчої експертно-аналітичної групи з питань проведення моніторингу світових цін та цін певних товарних ринків

Затвердити Войцещука Андрія Дмитровича - заступника Голови Держмитслужби керівником міжвідомчої експертно-аналітичної групи з питань проведення моніторингу світових цін та цін певних товарних ринків, утвореної розпорядженням Кабінету Міністрів України від 23 квітня 2003 р. N 217 ( 217-2003-р ), увільнивши від цих обов'язків Пашка Павла Володимировича.
