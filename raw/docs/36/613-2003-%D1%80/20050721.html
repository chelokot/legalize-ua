Текст документа від 21.07.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 жовтня 2003 р. N 613-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 277-р ( 277-2005-р ) від 21.07.2005 )

Про присвоєння спеціальному загону "Кобра" особливого призначення при МВС імені Ю.О. Дагаєва

Прийняти пропозицію МВС про присвоєння спеціальному загону "Кобра" особливого призначення при МВС імені Юрія Олександровича Дагаєва - засновника загону, колишнього заступника Міністра внутрішніх справ і надалі іменувати його - спеціальний загін "Кобра" особливого призначення при МВС імені Юрія Дагаєва.

Прем'єр-міністр України В.ЯНУКОВИЧ
