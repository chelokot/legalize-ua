Про затвердження Інструкції про порядок обчислення і сплати податку на добавлену вартість

{ Із змінами, внесеними згідно з Наказами ГДПІ N 44 ( z0140-94 ) від 31.05.94 N 56 ( z0154-94 ) від 30.06.94 N 76 ( z0198-94 ) від 12.08.94 N 98 ( z0483-95 ) від 25.12.95 N 21 ( z0148-96 ) від 11.03.96 N 40 ( z0236-96 ) від 07.05.96 Наказами ДПА N 40 ( z0062-97 ) від 18.02.97 N 495 ( z0673-99 ) від 16.09.99 }

1. На виконання Декрету Кабінету Міністрів України від 26 грудня 1992 р. N 14-92 ( 14-92 ) "Про податок на добавлену вартість" затвердити Інструкцію про порядок обчислення і сплати податку на добавлену вартість (додається).

2. Вважати такими, що зупиняють дію з 6 січня 1993 року, нормативні акти Міністерства фінансів України і Головної державної податкової інспекції України згідно з переліком, що додається.

Заступник Міністра фінансів, Начальник Головної державної податкової інспекції України В.П.Тентюк ( Інструкція про порядок обчислення і сплати податку на добавлену вартість втратила чинність на підставі Наказу Державної податкової адміністрації N 495 ( z0673-99 ) від 16.09.99 )

ЗАТВЕРДЖЕНО наказом Головної державної податкової інспекції України від 10 лютого 1993 р.N 3
