КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 червня 2002 р. N 765 Київ

Про повноваження Державної податкової служби

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 850 ( 850-2011-п ) від 10.08.2011 }

{ Із змінами, внесеними згідно з Постановою КМ N 850 ( 850-2011-п ) від 10.08.2011 }

Кабінет Міністрів України постановляє:

1. Покласти на Державну податкову службу повноваження з: { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 850 ( 850-2011-п ) від 10.08.2011 }

ведення Єдиного державного реєстру виробників спирту етилового, коньячного і плодового, спирту етилового ректифікованого виноградного, спирту етилового ректифікованого плодового, спирту-сирцю виноградного, спирту-сирцю плодового, алкогольних напоїв та тютюнових виробів;

затвердження за погодженням з Міністерством аграрної політики та продовольства норм втрат і виходу спирту етилового, коньячного і плодового, спирту етилового ректифікованого виноградного, спирту етилового ректифікованого плодового, спирту-сирцю виноградного, спирту-сирцю плодового та алкогольних напоїв. { Абзац третій пункту 1 із змінами, внесеними згідно з Постановою КМ N 850 ( 850-2011-п ) від 10.08.2011 }

2. Ця постанова набирає чинності з дня її опублікування.
