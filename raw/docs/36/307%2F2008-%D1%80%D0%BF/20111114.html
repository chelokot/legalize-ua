Президент України; Розпорядження від 24.10.2008 № 307/2008-рп

Про внесення змін до складу української делегації Спільної українсько-молдовської демаркаційної комісії

Стан: Втратив чинність

Ідентифікатор: 307/2008-рп

Текст документа від 14.11.2011:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 1008/2011 ( 1008/2011 ) від 31.10.2011 }

Про внесення змін до складу української делегації Спільної українсько-молдовської демаркаційної комісії

Увести до складу української делегації Спільної українсько-молдовської демаркаційної комісії, затвердженого Розпорядженням Президента України від 13 березня 2006 року N 45 ( 45/2006-рп ) "Про новий склад української делегації Спільної українсько-молдовської демаркаційної комісії" (зі змінами, внесеними Розпорядженням від 27 серпня 2007 року N 188) ( 188/2007-рп ), ТКАЛІЧА Володимира Петровича - голову Державної служби геодезії, картографії та кадастру і КУЛІНІЧА Володимира Васильовича - заступника Голови Державного комітету України із земельних ресурсів, вивівши з її складу І. Макаренка та Ю. Олексієнка.

Президент України В.ЮЩЕНКО

м. Київ, 24 жовтня 2008 року N 307/2008-рп
