09.07.2003 N 94

Зареєстровано в Міністерстві юстиції України 28 липня 2003 р. за N 646/7967

( Наказ втратив чинність на підставі Наказу Державного комітету архівів N 138 ( z1469-05 ) від 21.11.2005 )

Про внесення змін до наказу Держкомархіву України від 05.05.01 N 37

Відповідно до постанови Кабінету Міністрів України від 19.05.2003 N 740 ( 740-2003-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів і організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Держкомархіву України від 05.05.01 N 37 ( z0410-01 ) "Про впорядкування умов оплати праці працівників архівних установ", зареєстрованого в Міністерстві юстиції 14.05.01 за N 410/5601 (із змінами, внесеними наказом Держкомархіву від 04.02.2002 N 9 ( z0161-02 ), зареєстрованим у Міністерстві юстиції 19.02.2002 за N 161/6449), виклавши додатки 1-5 у новій редакції, що додається.

2. Керівникам архівних установ у межах затвердженого фонду заробітної плати встановити працівникам посадові оклади (ставки заробітної плати), виходячи з розмірів та у терміни, передбачені додатками 1-5.

Голова Державного комітету Г.В.Боряк Додаток 1 до наказу Держкомархіву України 05.05.2001 N 37 ( z0410-01 ) (у редакції наказу Держкомархіву України від 09.07.2003 N 94)
