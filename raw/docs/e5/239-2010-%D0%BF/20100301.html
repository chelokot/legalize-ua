Кабінет Міністрів України постановляє:

N 107 ( 107-2008-п ) "Про затвердження Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" (Офіційний вісник України, 2008 р., N 18, ст. 482, N 82, ст. 2763; 2009 р., N 59, ст. 2067; 2010 р., N 7, ст. 329) і від 20 січня 2010 р. N 36 ( 36-2010-п ) "Питання фінансування підготовки об'єктів інфраструктури до проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу за рахунок коштів Стабілізаційного фонду" (Офіційний вісник України, 2010 р., N 3, ст. 98, N 7, ст. 329) зміни, що додаються.
