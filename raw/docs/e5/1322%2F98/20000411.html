( Указ втратив чинність на підставі Указу Президента N 583/2000 від 11.04.2000 )

Питання Комісії по державних нагородах України при Президентові України

На часткову зміну Указу Президента України від 9 грудня 1994 року N 747 ( 747/94 ) "Про Комісію по державних нагородах України при Президентові України" (зі змінами, внесеними Указом Президента України від 7 лютого 1997 року N 103 ( 103/97 ) постановляю:

Внести до складу Комісії по державних нагородах України при Президентові України такі зміни:

1. Увести до складу Комісії по державних нагородах України при Президентові України:

БІЛОБЛОЦЬКОГО - Главу Адміністрації Президента

Миколу Петровича України

ШКІДЧЕНКА - начальника Генерального штабу Володимира Петровича Збройних Сил України - першого заступника Міністра оборони України, генерал-полковника.

2. Призначити БІЛОБЛОЦЬКОГО Миколу Петровича Головою Комісії по державних нагородах України при Президентові України.

3. Вивести зі складу Комісії по державних нагородах України при Президентові України КУШНАРЬОВА Євгена Петровича і ЗАТИНАЙКА Олександра Івановича.

4. Затвердити у складі Комісії по державних нагородах України при Президентові України:

КУРАСА - директора Інституту політичних і Івана Федоровича етнонаціональних досліджень НАН України, позаштатного радника Президента України, академіка НАН України

СІРЕНКА - народного депутата України, Василя Федоровича Голову Комітету Верховної Ради України з питань правової реформи, доктора юридичних наук (за згодою).

Президент України Л.КУЧМА
