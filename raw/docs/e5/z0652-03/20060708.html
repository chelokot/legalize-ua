Про внесення змін до наказу Міністерства праці та соціальної політики України від 22.06.2000 N 142

Відповідно до постанови Кабінету Міністрів України від 19.05.2003 N 740 ( 740-2003-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів і організацій окремих галузей бюджетної сфери" НАКАЗУЮ :

1. Унести до наказу Міністерства праці та соціальної політики України від 22.06.2000 N 142 ( z0478-00 ) "Про умови оплати праці працівників апарату Центральної ради, Кримської республіканської, обласних, Київської та Севастопольської міських рад фізкультурно-спортивного товариства "Динамо" України", зареєстрованого в Міністерстві юстиції України 04.08.2000 за N 478/4699 (зі змінами), такі зміни:

1) пункт 3 доповнити словами "і постанови Кабінету Міністрів України від 19 травня 2003 року N 740 ( 740-2003-п )";

2) додатки 1-3 викласти в новій редакції (додаються).

2. Установити працівникам посадові оклади (ставки заробітної плати) виходячи з розмірів та в терміни, що передбачені додатками 1-3.

Міністр М.Папієв

Додаток 1 до наказу Міністерства праці та соціальної політики України 22.06.2000 N 142 ( z0478-00 ) (у редакції наказу Міністерства праці та соціальної політики України від 14.07.2003 N 198)
