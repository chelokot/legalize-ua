{ Розпорядження втратило чинність на підставі Розпорядження КМ N 643-р ( 643-2006-р ) від 27.12.2006 }

Про доповнення розпорядження Кабінету Міністрів України від 29 березня 2000 р. N 152

Доповнити розпорядження Кабінету Міністрів України від 29 березня 2000 р. N 152 ( 152-2000-р ) (Офіційний вісник України, 2000 р., N 13, ст. 531) після абзацу шостого новим абзацом такого змісту:

"за реєстрацію змін, що вносяться до статуту фондової біржі або торговельно-інформаційної системи, - 50 неоподатковуваних мінімумів доходів громадян".

У зв'язку з цим абзац сьомий вважати абзацом восьмим.
