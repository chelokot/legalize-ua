ПОСТАНОВА від 13 травня 1996 р. N 506 Київ

( Постанова втратила чинність на підставі Постанови КМ N 842 ( 842-98-п ) від 08.06.98 )

Про склад Міжвідомчої комісії з розгляду і підготовки документів щодо створення спеціальних (вільних) економічних зон

( Із змінами, внесеними згідно з Розпорядженням КМ N 406-р ( 406-96-р ) від 20.06.96 )

Кабінет Міністрів України постановляє:

1. Затвердити склад Міжвідомчої комісії з розгляду і підготовки документів щодо створення спеціальних (вільних) економічних зон згідно з додатком.

2. Визнати такими, що втратили чинність, додаток до постанови Кабінету Міністрів України від 14 липня 1993 р.N 533 ( 533-93-п ), розпорядження Кабінету Міністрів України від 27 жовтня 1993 р. N 896 ( 896-93-р ), від 31 грудня. 1993 р. N 1200 ( 1200-93-р ), від 26 липня 1994 р. N 548 ( 548-94-р ), від 31 травня 1995 р. N 306 ( 306-95-р ).
