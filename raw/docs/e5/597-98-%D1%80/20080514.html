{ Розпорядження втратило чинність на підставі Розпорядження КМ N 711-р ( 711-2008-р ) від 14.05.2008 }

Про призначення Морозова А.О. генеральним конструктором Єдиної автоматизованої системи управління Збройними Силами

Прийняти пропозицію Міноборони, Мінпромполітики та Національної академії наук про призначення Морозова Анатолія Олексійовича - директора Інституту проблем математичних машин і систем Національної академії наук генеральним конструктором Єдиної автоматизованої системи управління Збройними Силами.

Визначити Інститут проблем математичних машин і систем Національної академії наук головною організацією у створенні Єдиної автоматизованої системи управління Збройними Силами.
