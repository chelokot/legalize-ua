Текст документа від 08.02.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 серпня 1999 р. N 1491 Київ

Про умови оплати праці працівників Рахункової палати Верховної Ради Автономної Республіки Крим

( Із змінами, внесеними згідно з Постановою КМ N 249 ( 249-2000-п ) від 08.02.2000 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 249 ( 249-2000-п ) від 08.02.2000 ) 1. Затвердити схему посадових окладів керівних працівників і спеціалістів Рахункової палати Верховної Ради Автономної Республіки Крим згідно з додатком.

2. Посадові оклади службовців Рахункової палати Автономної Республіки Крим установлюються на рівні посадових окладів службовців апарату Верховної Ради Автономної Республіки Крим.

3. Установити надбавки за особливі умови роботи голові Рахункової палати Верховної Ради Автономної Республіки Крим, його заступникам, секретарю Рахункової палати у розмірі до 90 відсотків, головним контролерам - завідуючим відділами, головним контролерам, контролерам - до 50 відсотків посадового окладу з урахуванням доплати за ранг державного службовця.

Конкретні розміри надбавок голові Рахункової палати Автономної Республіки Крим, його заступникам та секретарю Рахункової палати встановлюються Верховною Радою Автономної Республіки Крим, головним контролерам - завідуючим відділами, головним контролерам, контролерам - головою Рахункової палати Автономної Республіки Крим.

( Пункт 4 втратив чинність на підставі Постанови КМ N 249 ( 249-2000-п ) від 08.02.2000 ) 4. Інші умови оплати праці керівних працівників, спеціалістів і службовців Рахункової палати Верховної Ради Автономної Республіки Крим установлюються відповідно до постанови Кабінету Міністрів України від 21 січня 1993 р. N 35 ( 35-93-п) "Про умови оплати праці працівників апарату органів державної виконавчої влади та інших органів" з відповідними змінами і доповненнями.

5. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади голови Рахункової палати Верховної Ради Автономної Республіки Крим до першої категорії, його першого заступника та заступників - до другої категорії, секретаря Рахункової палати, головних контролерів - завідуючих відділами, головних контролерів - до третьої категорії, контролерів, помічника голови Рахункової палати - до четвертої категорії, консультантів, інших спеціалістів - до п'ятої категорії посад державних службовців.
