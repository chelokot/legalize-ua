КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 серпня 1999 р. N 1491 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 493 ( 493-2012-п ) від 23.05.2012 }

Про умови оплати праці працівників Рахункової палати Верховної Ради Автономної Республіки Крим

{ Із змінами, внесеними згідно з Постановами КМ N 249 ( 249-2000-п ) від 08.02.2000 N 268 ( 268-2006-п ) від 09.03.2006 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 249 ( 249-2000-п ) від 08.02.2000 }

2. Посадові оклади службовців Рахункової палати Автономної Республіки Крим установлюються на рівні посадових окладів службовців апарату Верховної Ради Автономної Республіки Крим.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

{ Пункт 4 втратив чинність на підставі Постанови КМ N 249 ( 249-2000-п ) від 08.02.2000 }

5. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади голови Рахункової палати Верховної Ради Автономної Республіки Крим до першої категорії, його першого заступника та заступників - до другої категорії, секретаря Рахункової палати, головних контролерів - завідуючих відділами, головних контролерів - до третьої категорії, контролерів, помічника голови Рахункової палати - до четвертої категорії, консультантів, інших спеціалістів - до п'ятої категорії посад державних службовців.
