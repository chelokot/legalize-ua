Кабінет Міністрів України; Розпорядження від 13.12.1999 № 1403-р

Про дозвіл Держмитслужбі на здійснення митного оформлення технологічного обладнання для виготовлення меблів, ввезеного колективним підприємством "Украміт" (м. Хмельницький)

Стан: Втратив чинність

Ідентифікатор: 1403-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 грудня 1999 р. N 1403-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення технологічного обладнання для виготовлення меблів, ввезеного протягом 1996 року для власних виробничих потреб колективним підприємством "Украміт" (м. Хмельницький) відповідно до контракту від 8 вересня 1995 р. з американською компанією ТОВ "Нордон", з нарахуванням митного збору за його перебування під митним контролем лише за перші 15 днів періоду, за який цей збір справляється.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
