Про втрату чинності деяких наказів Міністерства транспорту України

Відповідно до Положення про Міністерство транспорту та зв'язку України, затвердженого Указом Президента України від 27.08.2004 N 1009 ( 1009/2004 ), НАКАЗУЮ:

1. Уважати такими, що втратили чинність, накази Міністерства транспорту України:

від 02.12.96 N 382 ( z0752-96 ) "Про затвердження Порядку збирання та практичного використання інформації бортових систем реєстрації на підприємствах цивільної авіації України", зареєстрований в Міністерстві юстиції України 27.12.96 за N 752/1777;

від 06.09.99 N 432 ( z0636-99 ) "Про затвердження Правил видачі Сертифікатів придатності щодо шуму на місцевості цивільних повітряних суден України", зареєстрований в Міністерстві юстиції України 22.09.99 за N 636/3929;

від 01.11.99 N 526 ( z0799-99 ) "Про затвердження Інструкції про порядок розшуку багажу, що не надійшов до аеропорту призначення", зареєстрований в Міністерстві юстиції України 19.11.99 за N 799/4092;

від 15.07.2004 N 630 ( z0958-04 ) "Про затвердження Інструкції з організації перевезень вантажів повітряним транспортом", зареєстрований в Міністерстві юстиції України 02.08.2004 за N 958/9557.

2. Юридичному департаменту (Ониськів М.М.) забезпечити подання цього наказу в установленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконання цього наказу покласти на заступника Міністра Рябікіна П.Б.

Міністр В.Бондар
