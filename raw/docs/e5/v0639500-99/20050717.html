( Постанова втратила чинність на підставі Постанови Національного банку N 221 ( z0719-05 ) від 16.06.2005 )

Про внесення доповнень до пункту 3 Порядку ведення аналітичного обліку установами банків України

Відповідно до статті 33 Закону України "Про банки і банківську діяльність" ( 872-12 ) та з метою забезпечення реальної фінансової та статистичної звітності, що надається комерційними банками Національному банку України, Правління ПОСТАНОВЛЯЄ:

1. Доповнити пункт 3 Порядку ведення аналітичного обліку установами банків України, затвердженого постановою Правління Національного банку України від 30.12.97 N 466 ( v0511500-97 ), із змінами і доповненнями, внесеними постановою Правління Національного банку України від 16.12.98 N 520 ( va520500-98, v0609500-99 ), підпунктом 3.10 такого змісту:

"3.10. Організаційно-правова форма господарювання.

Опис параметра.

Організаційно-правова форма господарювання - це параметр, який вказує на розподіл контрагентів за організаційно-правовими формами господарювання. Він використовується під час збирання та оброблення інформації в автоматизованих системах. Визначення параметра надане у Класифікації організаційно-правових форм господарювання, затвердженій наказом Держстандарту України від 22.11.94 N 288 ( vb288217-94 ). Код організаційно-правової форми господарювання надається контрагентам (клієнтам) банків органами державної статистики при включенні їх до Єдиного державного реєстру підприємств та організацій України. Цей параметр потрібно заповнювати для контрагентів - суб'єктів господарської діяльності.

Формат параметра

2 цифри."

2. Постанова набуває чинності з 1 травня 1999 року.

3. Контроль за виконанням цієї постанови покласти на Департамент бухгалтерського обліку (П.М.Сенищ).

В.о. Голови В.С.Стельмах
