Кабінет Міністрів України; Постанова від 18.02.2009 № 118

Про першочергові заходи з будівництва енергоблоків N 3 і 4 Хмельницької АЕС

Стан: Чинний

Ідентифікатор: 118-2009-п

Текст документа від 21.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 лютого 2009 р. N 118 Київ

Про першочергові заходи з будівництва енергоблоків N 3 і 4 Хмельницької АЕС

{ Із змінами, внесеними згідно з Постановами КМ N 666 ( 666-2010-п ) від 28.07.2010 N 969 ( 969-2011-п ) від 14.09.2011 }

Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Міністерства енергетики та вугільної промисловості щодо застосування технічних характеристик реакторної установки типу ВВЕР-1000/В-392 для розроблення техніко-економічного обґрунтування інвестицій та проекту енергоблоків N 3 і 4 Хмельницької АЕС та щодо визначення державного підприємства "Національна атомна енергогенеруюча компанія "Енергоатом" (далі - Компанія) замовником будівництва зазначених енергоблоків.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 969 ( 969-2011-п ) від 14.09.2011 }

{ Пункт 2 втратив чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

3. Взяти до відома, що до затвердження проекту енергоблоків N 3 і 4 Хмельницької АЕС виконання підготовчих робіт за окремими проектами, а також ремонтно-відбудовних робіт згідно із затвердженою в установленому порядку проектно-кошторисною документацією здійснює Компанія з інформуванням до початку проведення відповідних робіт Міністерства екології та природних ресурсів і Державної інспекції ядерного регулювання, наданням за їх запитами необхідних матеріалів та подальшим включенням витрат, пов'язаних з виконанням таких робіт, до зведеного кошторису витрат з будівництва зазначених енергоблоків.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 969 ( 969-2011-п ) від 14.09.2011 }

4. Рекомендувати Національній комісії регулювання електроенергетики передбачати під час формування ціни на електричну енергію, що виробляється атомними електростанціями Компанії, кошти для розроблення техніко-економічного обґрунтування інвестицій та проекту енергоблоків N 3 і 4 Хмельницької АЕС, виконання підготовчих і ремонтно-відбудовних робіт, пов'язаних з початком їх будівництва, а також для закупівлі відповідного обладнання, що виготовляється протягом тривалого строку.

Прем'єр-міністр України Ю.ТИМОШЕНКО
