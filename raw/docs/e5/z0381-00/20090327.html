Національний банк; Постанова від 26.05.2000 № 215

Про затвердження Положення про застосування Національним банком України до банків та інших фінансово-кредитних установ заходів впливу за порушення банківського законодавства та внесення змін до нормативно-правових актів Національного банку України

Реєстрація: Мін'юст України від 03.07.2000 № 381/4602

Стан: Втратив чинність

Ідентифікатор: z0381-00

Текст документа від 27.03.2009:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 215 від 26.05.2000 Зареєстровано в Міністерстві м.Київ юстиції України 3 липня 2000 р. vd20000526 vn215 за N 381/4602

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про затвердження Положення про застосування Національним банком України до банків та інших фінансово-кредитних установ заходів впливу за порушення банківського законодавства та внесення змін до нормативно-правових актів Національного банку України

{ Із змінами, внесеними згідно з Постановою Національного банку N 368 ( z0841-01 ) від 28.08.2001 - зміни набувають чинності з 01.01.2002 }

З метою удосконалення системи заходів впливу, що застосовуються до банків та інших фінансово-кредитних установ за порушення банківського законодавства, Правління ПОСТАНОВЛЯЄ:

( Пункт 1 втратив чинність з 01.01.2002 на підставі Постанови Національного банку N 368 ( z0841-01 ) від 28.08.2001 )

2. Затвердити Положення про застосування Національним банком України до банків та інших фінансово-кредитних установ заходів впливу за порушення банківського законодавства ( z0382-00 ).

3. Визнати такою, що втратила чинність, постанову Правління Національного банку України "Про затвердження Положення про застосування Національним банком України заходів впливу до комерційних банків за порушення банківського законодавства" від 04.02.98 N 38 ( z0177-98 ), зареєстровану в Міністерстві юстиції України 19.03.98 за N 177/2617 (із змінами та доповненнями).

4. Постанова набуває чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

5. Департаменту пруденційного нагляду довести цю постанову після державної реєстрації до відома самостійних структурних підрозділів Національного банку України, Кримського республіканського, територіальних та по м.Києву і Київській області управлінь Національного банку України, а також банків і фінансово-кредитних установ для керівництва та використання в роботі.

6. Контроль за виконанням цієї постанови залишаю за собою.

Голова В.С.Стельмах

( Зміни до Інструкції про порядок регулювання та аналіз діяльності комерційних банків ( z0323-98 ) втратили чинність на підставі Постанови Національного банку N 368 ( z0841-01 ) від 28.08.2001 - з 01.01.2002 )
