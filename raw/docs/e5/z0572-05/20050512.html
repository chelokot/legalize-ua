ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

12.05.2005 N 163

Зареєстровано в Міністерстві юстиції України 25 травня 2005 р. за N 572/10852

Про визнання такими, що втратили чинність, нормативно-правових актів Національного банку України

Відповідно до статті 7 Закону України "Про Національний банк України" ( 679-14 ) та у зв'язку з урегулюванням Законом України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ) питання своєчасності сплати страхових внесків до Пенсійного фонду України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Визнати такими, що втратили чинність:

постанову Правління Національного банку України від 30.04.97 N 135 ( z0196-97 ) "Про затвердження Порядку сплати платниками заборгованості за внесками до Пенсійного фонду України", зареєстровану в Міністерстві юстиції України 28.05.97 за N 196/2000;

постанову Правління Національного банку України від 14.05.98 N 194 ( z0356-98 ) "Про внесення змін до Порядку сплати платниками заборгованості за внесками до Пенсійного фонду України", зареєстровану в Міністерстві юстиції України 29.05.98 за N 356/2796;

постанову Правління Національного банку України від 17.05.2001 N 194 ( z0454-01 ) "Про внесення змін до Порядку сплати заборгованості за зборами на обов'язкове державне пенсійне страхування", зареєстровану в Міністерстві юстиції України 29.05.2001 за N 454/5645.

2. Департаменту платіжних систем після державної реєстрації в Міністерстві юстиції України довести зміст цієї постанови до відома Операційного, територіальних управлінь Національного банку України та банків для використання в роботі.

3. Постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

Голова В.С.Стельмах
