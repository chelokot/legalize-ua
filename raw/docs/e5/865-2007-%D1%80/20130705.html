Кабінет Міністрів України; Розпорядження від 10.10.2007 № 865-р

Питання міжвідомчої робочої групи з координації та контролю за ходом підготовки і реалізації проектів розвитку житлово-комунального господарства населених пунктів

Стан: Втратив чинність

Ідентифікатор: 865-2007-р

Текст документа від 05.07.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 жовтня 2007 р. N 865-р Київ

Питання міжвідомчої робочої групи з координації та контролю за ходом підготовки і реалізації проектів розвитку житлово-комунального господарства населених пунктів

{ Із змінами, внесеними згідно з Постановою КМ N 451 ( 451-2013-п ) від 26.06.2013 }

1. Установити, що міжвідомча робоча група з координації та контролю за ходом підготовки і реалізації проектів розвитку житлово-комунального господарства населених пунктів, утворена розпорядженням Кабінету Міністрів України від 21 лютого 2001 р. N 50 ( 50-2001-р ) - із змінами, внесеними розпорядженням Кабінету Міністрів України від 26 вересня 2002 р. N 551 ( 551-2002-р ) (Офіційний вісник України, 2002 р., N 40, ст. 1870), постановою Кабінету Міністрів України від 15 лютого 2006 р. N 147 ( 147-2006-п ) (Офіційний вісник України, 2006 р., N 7, ст. 360) і розпорядженням Кабінету Міністрів України від 16 січня 2007 р. N 8 ( 8-2007-р ) (Офіційний вісник України, 2007 р., N 3, ст. 104), діє у складі першого заступника Міністра регіонального розвитку, будівництва та житлово-комунального господарства (голова робочої групи), представників Міністерства економічного розвитку і торгівлі, Міністерства регіонального розвитку, будівництва та житлово-комунального господарства, Міністерства фінансів, Міністерства екології та природних ресурсів, Міністерства закордонних справ, Державного агентства з енергоефективності та енергозбереження, Секретаріату Кабінету Міністрів України. { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 451 ( 451-2013-п ) від 26.06.2013 }

Персональний склад групи затверджує її голова.

2. У пункті 2 розпорядження Кабінету Міністрів України від 21 лютого 2001 р. N 50 ( 50-2001-р ) слово "Мінбуд" замінити словом "Мінжитлокомунгосп".

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 16 січня 2007 р. N 8 ( 8-2007-р ) "Про внесення змін до розпорядження Кабінету Міністрів України від 21 лютого 2001 р. N 50" (Офіційний вісник України, 2007 р., N 3, ст. 104).
