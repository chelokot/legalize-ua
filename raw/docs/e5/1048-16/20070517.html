Верховна Рада України; Постанова від 17.05.2007 № 1048-V

Про призначення позачергових виборів Ільпибоцького сільського голови (Демидівський район Рівненської області)

Стан: Чинний

Ідентифікатор: 1048-16

Текст документа від 17.05.2007:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про призначення позачергових виборів Ільпибоцького сільського голови (Демидівський район Рівненської області)

( Відомості Верховної Ради України (ВВР), 2007, N 31, ст.409 )

У зв'язку з достроковим припиненням повноважень Ільпибоцького сільського голови Новіцької М.І. (Демидівський район Рівненської області) та відповідно до пункту 30 частини першої статті 85 Конституції України ( 254к/96-ВР ), частини третьої статті 14, частин другої та шостої статті 15, статей 82, 83 Закону України "Про вибори депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів" ( 1667-15 ) Верховна Рада України постановляє:

1. Призначити позачергові вибори Ільпибоцького сільського голови (Демидівський район Рівненської області) на неділю 29 липня 2007 року.

2. Центральній виборчій комісії з урахуванням пропозицій відповідної територіальної виборчої комісії визначити обсяг бюджетних видатків, необхідних для проведення позачергових виборів Ільпибоцького сільського голови.

3. Кабінету Міністрів України в межах повноважень вжити невідкладних заходів щодо забезпечення фінансування позачергових виборів Ільпибоцького сільського голови за рахунок коштів цільової субвенції з Державного бюджету України ( 489-16 ).

4. Ця Постанова набирає чинності з дня її опублікування.
