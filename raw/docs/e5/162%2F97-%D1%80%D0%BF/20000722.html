РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 911/2000 ( 911/2000 ) від 22.07.2000 )

Про структуру та штати Представництва Президента України в Автономній Республіці Крим

( Із змінами, внесеними згідно з Розпорядженнями Президента N 199/97-рп від 13.05.97 N 419/97-рп від 27.11.97 N 335/98-рп від 23.06.98 N 550/98-рп від 17.11.98 )

( Додатково див. Розпорядження Президента N 68/98-рп від 27.03.98 )

Відповідно до статті 139 Конституції України ( 254к/96-ВР ) та статті 9 Закону України "Про Представництво Президента України в Республіці Крим" ( 2875-12 ):

1. Затвердити структуру апарату Представництва Президента України в Автономній Республіці Крим (додається), визначивши її чисельність у кількості 32 осіб. ( Пункт 1 із змінами, внесеними згідно з Розпорядженням Президента N 550/98-рп від 17.11.98 )

2. Прирівняти за умовами оплати праці та матеріально-побутового забезпечення Представника Президента України в Автономній Республіці Крим, його заступника та інших працівників Представництва відповідно до керівників Уряду Автономної Республіки Крим та працівників і спеціалістів його апарату.

3. Кабінету Міністрів України у місячний строк привести свої рішення у відповідність з цим Розпорядженням.

4. Визнати такими, що втратили чинність Розпорядження Президента України від 12 травня 1994 року N 36 ( 36/94-рп ) "Про затвердження структури та граничної чисельності апарату Представництва Президента України в Республіці Крим" та від 19 лютого 1996 року N 39 ( 39/96-рп ) "Про внесення змін і доповнень до пункту 1 Розпорядження Президента України від 12 травня 1994 року N 36".
