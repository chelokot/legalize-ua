КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 січня 1996 р. N 94 Київ

Про внесення змін до ставок ввізного мита на окремі види товарів і до деяких рішень Уряду України

( Із змінами, внесеними згідно з Постановою КМ N 566 ( 566-96-п ) від 29.05.96

З метою зменшення дефіциту державного бюджету Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита на товари згідно з додатком. ( На часткову зміну пункту 1 встановити, що ставки ввізного мита на картоплю свіжу або охолоджену (код товару згідно з ГС 07.01) у 1996 році застосовуються з 1 січня по 31 травня згідно з Постановою КМ N 566 ( 566-96-п ) від 29.05.96 )

2. Виключити із додатка до постанови Кабінету Міністрів України від 3 травня 1994 р. N 285 ( 285-94-п ) "Про зміни ставок ввізного мита на окремі види товарів" (ЗП України, 1994 р., N 11, ст.266) товари за кодами згідно з ГС 02.07, 04.05, 04.06, 15.12, 15.17, 87.02 (крім 87.02 90900 тролейбуси), із додатка до постанови Кабінету Міністрів України від 22 лютого 1995 р. N 139 ( 139-95-п ) "Про внесення змін до ставок ввізного мита на товари, яких достатньо виробляється у країні" (ЗП України, 1996 р., N 5, ст.128) товари за кодами згідно з ГС 07.01, 12.10, 84.33 53300.

3. Ця постанова набирає чинності через 10 днів після її опублікування у газеті "Урядовий кур'єр".
