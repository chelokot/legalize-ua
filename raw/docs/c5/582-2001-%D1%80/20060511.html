КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 грудня 2001 р. N 582-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Про затвердження голови Міжгалузевої комісії з питань навігації і управління транспортними засобами та іншими рухомими об'єктами

Затвердити Першого віце-прем'єр-міністра України Дубину Олега Вікторовича головою Міжгалузевої комісії з питань навігації і управління транспортними засобами та іншими рухомими об'єктами ( 1469-97-п ), звільнивши від цих обов'язків Єханурова Ю.І.
