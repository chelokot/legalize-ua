КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 січня 2000 р. N 133 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1736 ( 1736-2000-п ) від 24.11.2000 )

( Постанову скасовано на підставі Указу Президента N 722/2000 ( 722/2000 ) від 25.05.2000 )

Про затвердження спостережної ради Національної акціонерної компанії "Нафтогаз України"

Кабінет Міністрів України постановляє:

1. Затвердити новий склад спостережної ради Національної акціонерної компанії "Нафтогаз України", що додається.

2. Визнати такими, що втратили чинність, постанову Кабінету Міністрів України від 10 квітня 1999 р. N 573 ( 573-99-п ) "Про внесення змін до постанови Кабінету Міністрів України від 25 травня 1998 р. N 747" (Офіційний вісник України, 1999 р., N 15, ст. 607) та абзац дев'ятнадцятий постанови Кабінету Міністрів України від 17 серпня 1999 р. N 1506 ( 1506-99-п ) "Про голову деяких державних комісій та інших органів, утворених Кабінетом Міністрів України".

Прем'єр-міністр України В.ЮЩЕНКО
