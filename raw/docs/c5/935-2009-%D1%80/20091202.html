Кабінет Міністрів України; Розпорядження від 22.07.2009 № 935-р

Про продовження дії Меморандуму порозуміння між Кабінетом Міністрів України та підприємствами гірничо-металургійного комплексу

Стан: Чинний

Ідентифікатор: 935-2009-р

Текст документа від 02.12.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 липня 2009 р. N 935-р Київ

Про продовження дії Меморандуму порозуміння між Кабінетом Міністрів України та підприємствами гірничо-металургійного комплексу

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1479-р ( 1479-2009-р ) від 02.12.2009 }

1. Продовжити до 1 квітня 2010 р. дію Меморандуму порозуміння між Кабінетом Міністрів України та підприємствами гірничо-металургійного комплексу України ( n0003120-08 ).

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 1479-р ( 1479-2009-р ) від 02.12.2009 }

2. Установити, що преференції, передбачені Меморандумом ( n0003120-08 ), який зазначений у пункті 1 цього розпорядження, та встановлені постановою Кабінету Міністрів України від 14 жовтня 2008 р. N 925 ( 925-2008-п ) "Про першочергові заходи щодо стабілізації ситуації, що склалася в гірничо-металургійному та хімічному комплексі" (Офіційний вісник України, 2008 р., N 81, ст. 2731), застосовуються для підприємств гірничо-металургійного комплексу в разі виконання ними таких умов:

встановлення на внутрішньому ринку цін на металопродукцію не вище експортних та її постачання підприємствам транспортної, енергетичної та вугільної галузей без залучення третіх осіб; { Абзац другий пункту 2 із змінами, внесеними згідно з Розпорядженням КМ N 1479-р ( 1479-2009-р ) від 02.12.2009 }

відсутність заборгованості перед бюджетом, Пенсійним фондом України, НАК "Нафтогаз України", постачальниками вугілля вітчизняного походження та із заробітної плати, виконання колективних договорів. { Абзац третій пункту 2 із змінами, внесеними згідно з Розпорядженням КМ N 1479-р ( 1479-2009-р ) від 02.12.2009 }
