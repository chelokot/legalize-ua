Президент України; Указ від 02.11.2006 № 926/2006

Про утворення Комісії з опрацювання пропозицій щодо внесення змін до Конституції України та підготовки законопроектів, спрямованих на їх реалізацію

Стан: Втратив чинність

Ідентифікатор: 926/2006

Текст документа від 15.01.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1293/2007 ( 1293/2007 ) від 27.12.2007 }

Про утворення Комісії з опрацювання пропозицій щодо внесення змін до Конституції України та підготовки законопроектів, спрямованих на їх реалізацію

З метою забезпечення системного та комплексного опрацювання пропозицій з удосконалення конституційного регулювання суспільних відносин в Україні, створення збалансованої системи стримувань і противаг, як це проголошено Універсалом національної єдності ( n0010100-06 ), опрацювання пропозицій щодо внесення змін до Конституції України ( 254к/96-ВР ) та підготовки проектів законів щодо системного запровадження таких змін, залучення до цієї роботи представників різних політичних сил та відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Утворити при Президентові України Комісію з опрацювання пропозицій щодо внесення змін до Конституції України ( 254к/96-ВР ) та підготовки законопроектів, спрямованих на їх реалізацію.

2. Запропонувати Голові Верховної Ради України, керівникам депутатських фракцій у Верховній Раді України, Прем'єр-міністрові України внести пропозиції щодо кандидатур для включення до складу зазначеної Комісії.

Президент України В.ЮЩЕНКО
