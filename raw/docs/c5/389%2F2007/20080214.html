УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про забезпечення підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу

{ Із змінами, внесеними згідно з Указами Президента N 802/2007 ( 802/2007 ) від 31.08.2007 N 22/2008 ( 22/2008 ) від 15.01.2008 N 125/2008 ( 125/2008 ) від 14.02.2008 }

З метою забезпечення належної підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу постановляю:

1. Утворити Координаційну раду з підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу (далі - Координаційна рада).

1-1. Установити, що основною формою роботи Координаційної ради є засідання, які проводяться не рідше одного разу на квартал. У разі потреби Голова Координаційної ради скликає позачергове засідання.

Засідання Координаційної ради вважається правомочним, якщо на ньому присутні більшість членів Координаційної ради.

Рішення Координаційної ради приймається шляхом голосування більшістю присутніх на її засіданні членів Координаційної ради. У разі рівного розподілу голосів голос Голови Координаційної ради є вирішальним.

Результати засідання Координаційної ради оформляються протоколом.

Рішення Ради є обов'язковими для розгляду центральними та місцевими органами виконавчої влади.

{ Указ доповнено статтею 1-1 згідно з Указом Президента N 802/2007 ( 802/2007 ) від 31.08.2007 }

2. Затвердити персональний склад Координаційної ради (додається).

3. Кабінету Міністрів України утворити Організаційний комітет з підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу (далі - Організаційний комітет).

4. Організаційному комітету підготувати та подати у місячний строк на затвердження Координаційній раді план заходів на 2007-2012 роки щодо підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу.

5. Визнати таким, що втратив чинність, Указ Президента України від 24 квітня 2007 року N 346 ( 346/2007 ) "Про заходи щодо забезпечення підготовки та проведення в Україні фінального турніру чемпіонату Європи 2012 року з футболу".

6. Цей Указ набирає чинності з дня його опублікування.
