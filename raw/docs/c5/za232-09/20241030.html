Про затвердження Порядку розслідування страхових випадків та обґрунтованості виплати матеріального забезпечення безробітним

Стан: Втратив чинність

Ідентифікатор: za232-09

Текст документа від 30.10.2024:

ПРАВЛІННЯ ПЕНСІЙНОГО ФОНДУ УКРАЇНИ

ПОСТАНОВА

13.02.2009 N 7-1

Зареєстровано в Міністерстві юстиції України 12 березня 2009 р. за N 232/16248

{ Постанова втратила чинність на підставі Постанови Пенсійного фонду N 27-2 ( za467-24 ) від 10.09.2024 }

Про затвердження Порядку розслідування страхових випадків та обґрунтованості виплати матеріального забезпечення безробітним

Відповідно до частини третьої статті 22 Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ), пункту 12 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261 ( 1261-2007-п ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Затвердити Порядок розслідування страхових випадків та обґрунтованості виплати матеріального забезпечення безробітним, що додається ( z0232-09 ).

2. Юридичному управлінню (Рябцева Т.Б.) подати цю постанову для державної реєстрації до Міністерства юстиції України.

3. Контроль за виконанням цієї постанови покласти на заступника Голови правління В.А.Колбуна.
