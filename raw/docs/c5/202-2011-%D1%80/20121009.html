РОЗПОРЯДЖЕННЯ від 17 березня 2011 р. N 202-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 904 ( 904-2012-п ) від 03.10.2012 }

Про внесення змін у додаток до постанови Кабінету Міністрів України від 18 лютого 2009 р. N 148

Внести у додаток до постанови Кабінету Міністрів України від 18 лютого 2009 р. N 148 ( 148-2009-п ) "Деякі питання участі держави у капіталізації банків" (Офіційний вісник України, 2009 р., N 15, ст. 474; 2010 р., N 36, ст. 1231, N 65, ст. 2304, N 69, ст. 2491; 2011 р., N 12, ст. 526) такі зміни:

ввести до складу Експертно-аналітичної ради з питань участі держави у капіталізації банків Рибака Сергія Олександровича - заступника Міністра фінансів, вивівши з її складу Кравця Андрія Миколайовича;

зазначити нові посади таких членів Експертно-аналітичної ради з питань участі держави у капіталізації банків:

"МАТУЗКА - директор юридичного департаменту

Ярослав Васильович Мінфіну

СИСОЄВА - директор департаменту фінансової

Тетяна Петрівна політики Мінфіну".

Прем'єр-міністр України М.АЗАРОВ
