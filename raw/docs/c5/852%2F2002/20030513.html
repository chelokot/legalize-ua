Президент України; Указ від 23.09.2002 № 852/2002

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю

Стан: Втратив чинність

Ідентифікатор: 852/2002

Текст документа від 13.05.2003:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 402/2003 ( 402/2003 ) від 13.05.2003 )

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю

Увести до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України, затвердженого Указом Президента України від 31 грудня 1999 року N 1659 ( 1659/99 ) (зі змінами, внесеними Указами від 28 січня 2000 року N 108 ( 108/2000 ), від 19 квітня 2001 року N 266 ( 266/2001 ), від 13 вересня 2001 року N 837 ( 837/2001 ) та від 19 червня 2002 року N 561 ( 561/2002 ), ДЖИГУ Миколу Васильовича - першого заступника Державного секретаря Міністерства внутрішніх справ України - начальника Головного управління по боротьбі з організованою злочинністю, вивівши зі складу зазначеного Комітету Корнієнка М.В.

Президент України Л.КУЧМА

м. Київ, 23 вересня 2002 року N 852/2002
