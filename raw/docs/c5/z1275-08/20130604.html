Про внесення змін до наказу Міністерства праці та соціальної політики України від 29.11.2000 N 319

Реєстрація: Мін'юст України від 30.12.2008 № 1275/15966

Стан: Чинний

Ідентифікатор: z1275-08

Текст документа від 04.06.2013:

МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

03.12.2008 N 565

Зареєстровано в Міністерстві юстиції України 30 грудня 2008 р. за N 1275/15966

Про внесення змін до наказу Міністерства праці та соціальної політики України від 29.11.2000 N 319

{ Із змінами, внесеними згідно з Наказом Міністерства праці та соціальної політики N 115 ( z0451-10 ) від 31.05.2010 Наказами Міністерства соціальної політики N 34 ( z0211-11 ) від 03.02.2011 N 47 ( z0237-12 ) від 01.02.2012 N 209 ( z0730-13 ) від 18.04.2013 }

Відповідно до постанови Кабінету Міністрів України від 25 жовтня 2008 року N 939 ( 939-2008-п ) "Питання оплати праці працівників установ, закладів та організацій бюджетної сфери" (із змінами) НАКАЗУЮ:

1. У додатку до наказу Міністерства праці та соціальної політики України від 29.11.2000 N 319 ( z0888-00 ) "Про упорядкування умов оплати праці працівників Державного сховища дорогоцінних металів і дорогоцінного каміння України", зареєстрованого в Міністерстві юстиції України 05.12.2000 за N 888/5109 (із змінами), графу "з 1 грудня 2008 року" виключити.

2. Установити, що розміри посадових окладів (тарифних ставок), зазначені у додатку до наказу, змінюються в установленому порядку пропорційно підвищенню посадового окладу (тарифної ставки) працівника I тарифного розряду, розмір якого визначено у примітці 1 до додатка 1 до постанови Кабінету Міністрів України від 30.08.2002 N 1298 ( 1298-2002-п ) "Про оплату праці працівників на основі Єдиної тарифної сітки розрядів і коефіцієнтів з оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери. { Абзац пункту 2 в редакції Наказу Міністерства праці та соціальної політики N 115 ( z0451-10 ) від 31.05.2010 - застосовується з 1 січня 2010 року; із змінами, внесеними згідно з Наказами Міністерства соціальної політики N 34 ( z0211-11 ) від 03.02.2011 - застосовується з 1 січня 2011 року, N 47 ( z0237-12 ) від 01.02.2012 - застосовується з 1 січня 2012 року; N 209 ( z0730-13 ) від 18.04.2013 - застосовується з 1 січня 2013 року }

Для працівників, у яких посадові оклади менші ніж розмір мінімальної заробітної плати, посадові оклади (тарифні ставки) у штатному розписі установлюються на рівні мінімальної заробітної плати. { Абзац пункту 2 в редакції Наказу Міністерства праці та соціальної політики N 115 ( z0451-10 ) від 31.05.2010 - застосовується з 1 січня 2010 року}

Заробітна плата працівників, визначена з урахуванням зазначених посадових окладів, індексується відповідно до Закону України "Про індексацію грошових доходів населення" ( 1282-12 ).

3. Директору департаменту з питань державного регулювання заробітної плати та умов праці Товстенку О.П. у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

Міністр Л.Денісова
