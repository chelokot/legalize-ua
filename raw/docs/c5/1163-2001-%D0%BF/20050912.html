Про внесення змін до постанови Кабінету Міністрів України від 28 квітня 2001 р. N 414

Стан: Втратив чинність

Ідентифікатор: 1163-2001-п

Текст документа від 12.09.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 вересня 2001 р. N 1163 Київ

( Постанова втратила чинність на підставі Постанови КМ N 881 ( 881-2005-п ) від 12.09.2005 )

Про внесення змін до постанови Кабінету Міністрів України від 28 квітня 2001 р. N 414

З метою постійного контролю діяльності, пов'язаної з виробництвом оптичних носіїв інформації, Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 28 квітня 2001 р. N 414 ( 414-2001-п ) "Про затвердження Положення про комісію з проведення перевірок підприємств - виробників оптичних дисків та порядку проведення цих перевірок" (Офіційний вісник України, 2001 р., N 18, ст. 792) такі зміни:

у пункті 2 постанови слова "у тримісячний термін" замінити словом "постійне";

в абзаці першому пункту 7 Тимчасового порядку проведення перевірок підприємств - виробників оптичних дисків, затвердженого зазначеною постановою, слова "який складається та підписується в день закінчення перевірки" замінити словами "який складається та підписується протягом трьох днів після закінчення перевірки".

Прем'єр-міністр України А.КІНАХ
