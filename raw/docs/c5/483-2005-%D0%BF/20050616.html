Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 483-2005-п

Текст документа від 16.06.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 червня 2005 р. N 483 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 40

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 16 червня 2005 р. N 483

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 6 листопада 1995 р. N 892 ( 892-95-п ) "Питання Державного комітету у справах релігій".

2. Постанова Кабінету Міністрів України від 26 січня 1996 р. N 126 ( 126-96-п ) "Про затвердження членів колегії Державного комітету у справах релігій".

3. Постанова Кабінету Міністрів України від 20 травня 1997 р. N 463 ( 463-97-п ) "Про членів колегії Державного комітету у справах релігій".

4. Постанова Кабінету Міністрів України від 22 жовтня 1999 р. N 1954 ( 1954-99-п ) "Про членів колегії Державного комітету у справах релігій".

5. Постанова Кабінету Міністрів України від 7 лютого 2000 р. N 238 ( 238-2000-п ) "Про членів колегії Державного комітету у справах релігій".

6. Постанова Кабінету Міністрів України від 13 вересня 2002 р. N 1378 ( 1378-2002-п ) "Про колегію Державного комітету у справах релігій" (Офіційний вісник України, 2002 р., N 38, ст. 1779).
