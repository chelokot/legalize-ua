Текст документа від 27.12.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 грудня 1999 р. N 2358 Київ

Про внесення змін до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288

( Із змінами, внесеними згідно з Постановою КМ N 2376 ( 2376-99-п ) від 27.12.99 )

Відповідно до Указу Президента України від 15 грудня 1999 р. N 1574 ( 1574/99 ) Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288 ( 2288-99-п ) "Про впорядкування умов оплати праці працівників апарату органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів" такі зміни:

у пункті 1 зазначеної постанови слова "апарату Кабінету Міністрів України" замінити словами "Секретаріату Кабінету Міністрів України";

додаток 2 до цієї постанови викласти в новій редакції, що додається;

у додатку 46 слова "апарат Кабінету Міністрів України" замінити словами "Секретаріат Кабінету Міністрів України".

Умови оплати праці, визначені для працівників Секретаріату Кабінету Міністрів України, поширюються на працівників апарату Кабінету Міністрів України. ( Постанову доповнено абзацом згідно з Постановою КМ N 2376 ( 2376-99-п ) від 27.12.99 )
