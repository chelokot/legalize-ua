Кабінет Міністрів України; Розпорядження від 28.10.1998 № 861-р

Про здійснення митного оформлення вантажу (обладнання для дитячих та рододопоміжних закладів), що був ввезений на адресу Центру охорони материнства і дитинства (м. Сімферополь)

Стан: Втратив чинність

Ідентифікатор: 861-98-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 жовтня 1998 р. N 861-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Держмитслужбі здійснити митне оформлення вантажу (обладнання для дитячих та рододопоміжних закладів), що був ввезений 11 липня 1997 р. на адресу Центру охорони материнства і дитинства (м. Сімферополь, вул. Б. Хмельницького, 16) від Церкви останніх днів (США, штат Юта, м. Солт Лейк Сіті) для забезпечення лікувальних закладів Автономної Республіки Крим без справляння митних зборів за перебування його під митним контролем.

Прем'єр-міністр України В. ПУСТОВОЙТЕНКО
