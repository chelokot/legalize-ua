Про втрату чинності наказу від 22.09.99 N 1781

На виконання вимог пункту 2 постанови Кабінету Міністрів України від 28.12.92 N 731 ( 731-92-п ) "Про затвердження Положення про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади", у зв'язку з втратою чинності постановою Кабінету Міністрів України від 30.06.99 N 1347 ( 1347-99-п ) "Про внесення зміни до Методики оцінки вартості майна під час приватизації" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Фонду державного майна України від 22.09.99 N 1781 ( z0687-99 ) "Про затвердження Положення про порядок виконання постанови Кабінету Міністрів України від 30.06.99 N 1347 "Про внесення зміни до Методики оцінки вартості майна під час приватизації", зареєстрований в Міністерстві юстиції України 07.10.99 за N 687/3980.

2. Департаменту оцінки майна, майнових прав та професійної оціночної діяльності (Н. Лебідь) подати цей наказ у встановленому порядку до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Д. Парфененка.

Голова Фонду М.Чечетов
