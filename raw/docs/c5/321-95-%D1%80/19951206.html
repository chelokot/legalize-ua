Кабінет Міністрів України; Розпорядження від 01.06.1995 № 321-р

Про відкриття пункту пропуску через державний кордон України з Республікою Польща "Рава Руська" для міждержавного вантажного залізничного сполучення

Стан: Втратив чинність

Ідентифікатор: 321-95-р

Текст документа від 06.12.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ РОЗПОРЯДЖЕННЯ

від 1 червня 1995 р. N 321-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 744-р ( 744-95-р ) від 06.12.95 )

Відкрити пункт пропуску через державний кордон України з Республікою Польща "Рава Руська" для міждержавного вантажного залізничного сполучення.
