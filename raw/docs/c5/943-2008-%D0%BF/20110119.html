Про економію державних коштів

Стан: Втратив чинність

Ідентифікатор: 943-2008-п

Текст документа від 19.01.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 жовтня 2008 р. N 943 Київ

Про економію бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів

{ Із змінами, внесеними згідно з Постановами КМ N 506 ( 506-2009-п ) від 20.05.2009 N 595 ( 595-2009-п ) від 17.06.2009 N 1150 ( 1150-2009-п ) від 16.09.2009 N 1322 ( 1322-2009-п ) від 08.12.2009 N 53 ( 53-2010-п ) від 27.01.2010 N 241 ( 241-2010-п ) від 02.03.2010 N 700 ( 700-2010-п ) від 04.08.2010 N 877 ( 877-2010-п ) від 29.09.2010 N 964 ( 964-2010-п ) від 11.10.2010 N 1136 ( 1136-2010-п ) від 15.12.2010 N 1139 ( 1139-2010-п ) від 13.12.2010 N 1177 ( 1177-2010-п ) від 20.12.2010 N 1185 ( 1185-2010-п ) від 22.12.2010 N 14 ( 14-2011-п ) від 12.01.2011 }

{ Змінюється Постановою КМ N 28 ( 28-2011-п ) від 19.01.2011 }

З метою економного і раціонального використання бюджетних коштів Кабінет Міністрів України постановляє:

1. Затвердити заходи щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів, що додаються.

Визначити відповідальними за виконання зазначених заходів головних розпорядників коштів державного бюджету.

2. Рекомендувати органам місцевого самоврядування протягом місяця затвердити заходи щодо економного та раціонального використання бюджетних коштів, передбачених для їх утримання.

3. Головному контрольно-ревізійному управлінню забезпечити постійний контроль за виконанням органами державної влади та іншими державними органами затверджених цією постановою заходів і щокварталу інформувати Кабінет Міністрів України про стан їх виконання.
