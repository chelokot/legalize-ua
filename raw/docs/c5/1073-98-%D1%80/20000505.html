Кабінет Міністрів України; Розпорядження від 25.12.1998 № 1073-р

Про дозвіл Держмитслужбі на здійснення митного оформлення спеціалізованого поліцейського автомобіля марки Форд Краун Вікторія, який передається УМВС в Чернігівській області як гуманітарна допомога

Стан: Втратив чинність

Ідентифікатор: 1073-98-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 грудня 1998 р. N 1073-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення спеціалізованого поліцейського автомобіля марки Форд Краун Вікторія, 1995 року випуску (номер шасі 2FALP72W9SX202221), який передається УМВС в Чернігівській області як гуманітарна допомога корпорацією "Giant Modern Venture International, Ins." (США, м. Беллав'ю), без сплати митних зборів.

Державтоінспекції провести відповідну реєстрацію зазначеного автомобіля.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
