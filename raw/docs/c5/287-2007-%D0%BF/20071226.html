Про звільнення Улинця Е.М. з посади начальника Державного департаменту пожежної безпеки

{ Щодо поновлення з 22.02.2007 Улинця Ернеста Михайловича на посаді начальника Державного департаменту пожежної безпеки див. Розпорядження КМ N 1261-р ( 1261-2007-р ) від 26.12.2007 }

Кабінет Міністрів України постановляє:
