Стан: Втратив чинність

Текст документа від 12.10.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1433/2005 ( 1433/2005 ) від 12.10.2005 )

Про внесення змін до Указу Президента України від 22 липня 2000 року N 911

Внести до Указу Президента України від 22 липня 2000 року N 911 ( 911/2000 ) "Питання Представництва Президента України в Автономній Республіці Крим" (зі змінами, внесеними Указами від 14 грудня 2000 року N 1336 ( 1336/2000 ) та від 4 липня 2003 року N 564 ( 564/2003 ) такі зміни:

1. У статті 2 цифри "28" замінити цифрами "29".

2. Абзац другий структури Представництва Президента України в Автономній Республіці Крим, затвердженої цим Указом ( 911/2000 ), викласти в такій редакції:

"Два перших заступники Постійного Представника Президента України в Автономній Республіці Крим".

Президент України Л.КУЧМА

м. Київ, 30 квітня 2004 року N 496/2004
