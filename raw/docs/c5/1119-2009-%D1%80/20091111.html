КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 вересня 2009 р. N 1119-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1361-р ( 1361-2009-р ) від 11.11.2009 }

{ Дію Розпорядження зупинено згідно з Указом Президента N 834/2009 ( 834/2009 ) від 20.10.2009 }

Деякі питання проведення конверсії смуг радіочастот

1. Міноборони, Мінтрансзв'язку, НКРЗ з урахуванням висновків міжвідомчої комісії з обґрунтування обсягів та витрат, пов'язаних з проведенням конверсії радіочастотного ресурсу, провести конверсію смуг радіочастот 1920-1935 МГц, 1950-1980 МГц, 2010-2015 МГц, 2020-2025 МГц, 2110-2125 МГц, 2140-2170 МГЦ для запровадження системи мобільного зв'язку третього покоління стандарту IMT-2000 (UMTS) шляхом зміни частотних присвоєнь радіоелектронних засобів спеціальних користувачів, які працюють у зазначених смугах радіочастот, і переведення їх поза такі смуги радіочастот в межах асигнувань, виділених для утримання відповідних центральних органів виконавчої влади.

2. НКРЗ організувати проведення тендерів (відкритих аукціонів) на видачу ліцензії на користування радіочастотним ресурсом у смугах радіочастот 1920-1935 МГц, 1950-1980 МГц, 2010-2015 МГц, 2020-2025 МГц, 2110-2125 МГц, 2140-2170 МГц для впровадження радіотехнології "Цифровий стільниковий радіозв'язок IMT-2000 (UMTS)".

Прем'єр-міністр України Ю.ТИМОШЕНКО
