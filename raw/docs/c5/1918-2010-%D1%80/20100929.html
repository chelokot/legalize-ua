Про виділення коштів Стабілізаційного фонду для часткової компенсації вартості електроенергії, використаної для поливу сільськогосподарських культур на зрошуваних землях

Стан: Чинний

Ідентифікатор: 1918-2010-р

Текст документа від 29.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 вересня 2010 р. N 1918-р Київ

Про виділення коштів Стабілізаційного фонду для часткової компенсації вартості електроенергії, використаної для поливу сільськогосподарських культур на зрошуваних землях

1. Виділити Міністерству аграрної політики за рахунок коштів Стабілізаційного фонду ( 2154-17 ) за напрямом, передбаченим пунктом 1 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ), на безповоротній основі 43590,2 тис. гривень для часткової компенсації вартості електроенергії, використаної для поливу сільськогосподарських культур на зрошуваних землях.

Зазначені кошти Стабілізаційного фонду ( 2154-17 ) використовуються згідно з постановою Кабінету Міністрів України від 2 вересня 2010 р. N 858 ( 858-2010-п ) "Про порядок використання у 2010 році коштів Стабілізаційного фонду для державної підтримки виробництва продукції рослинництва шляхом часткової компенсації вартості електроенергії, використаної для поливу сільськогосподарських культур на зрошуваних землях" (Офіційний вісник України, 2010 р., N 71, ст. 2558).

2. Міністерству фінансів внести зміни до розпису Державного бюджету України на 2010 рік ( 2154-17 ), визначивши джерелом покриття витрат, зазначених у пункті 1 цього розпорядження, надходження коштів від цільового розміщення державних цінних паперів.

Прем'єр-міністр України М.АЗАРОВ
