КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 вересня 2007 р. N 1170 Київ

Питання Національної юридичної академії імені Ярослава Мудрого

{ Із змінами, внесеними згідно з Постановою КМ N 1490 ( 1490-2022-п ) від 30.12.2022 }

Кабінет Міністрів України постановляє:

1. Прийняти пропозицію Міністерства освіти і науки та Служби безпеки щодо перетворення факультету підготовки слідчих кадрів для СБУ (слідчий факультет) Національної юридичної академії імені Ярослава Мудрого в Інститут підготовки юридичних кадрів для Служби безпеки зазначеної Академії (далі - Інститут).

2. Установити, що студенти факультету підготовки слідчих кадрів для СБУ (слідчий факультет) Національної юридичної академії імені Ярослава Мудрого продовжують навчання в Інституті.

3. Витрати, пов'язані з утворенням Інституту, провести у межах видатків, передбачених у державному бюджеті для Служби безпеки за програмою "Підготовка і перепідготовка кадрів Служби безпеки України вищими навчальними закладами III та IV рівнів акредитації".

4. Внести до постанов Кабінету Міністрів України від 15 грудня 1997 р. N 1410 ( 1410-97-п ) "Про створення єдиної системи військової освіти" (Офіційний вісник України, 1997 р., число 51, с. 32; 2003 р., N 37, ст. 1981) і від 29 листопада 2001 р. N 1612 ( 1612-2001-п ) "Деякі питання Національної юридичної академії імені Ярослава Мудрого" (Офіційний вісник України, 2001 р., N 49, ст. 2196) зміни, що додаються.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 вересня 2007 р. N 1170

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 15 грудня 1997 р. N 1410 ( 1410-97-п ) і від 29 листопада 2001 р. N 1612 ( 1612-2001-п )

{ Пункт 1 втратив чинність на підставі Постанови КМ N 1490 ( 1490-2022-п ) від 30.12.2022 }

2. Підпункти 1-5 пункту 14 Статуту Національної юридичної академії України імені Ярослава Мудрого, затвердженого постановою Кабінету Міністрів України від 29 листопада 2001 р. N 1612 ( 1612-2001-п ), замінити підпунктами 1-4 такого змісту:

"1) очна форма навчання:

Інститут підготовки кадрів для органів прокуратури України;

Інститут підготовки юридичних кадрів для Служби безпеки;

господарсько-правовий факультет;

факультет підготовки кадрів для МВС (слідчо-криміналістичний);

факультет підготовки кадрів для органів юстиції;

факультет військової юстиції;

факультет підготовки юристів для МЗС;

факультет підготовки професійних суддів;

факультет підготовки кадрів для Державного департаменту з питань виконання покарань;

факультет підготовки кадрів для системи Пенсійного фонду;

2) заочна форма навчання:

факультет з підготовки фахівців за державним замовленням;

факультет з підготовки фахівців на госпрозрахунковій основі;

3) Інститут підвищення кваліфікації юридичних кадрів;

4) відокремлені структурні підрозділи:

Кримський юридичний інститут (м. Сімферополь);

Полтавський факультет (м. Полтава);".

У зв'язку з цим підпункт 6 вважати підпунктом 5.
