КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 вересня 1991 р. N 220 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1109 ( 1109-2004-п ) від 25.08.2004 )

Про перелік готових промислових товарів народного споживання, які забороняється використовувати як сировину або напівфабрикати для виготовлення з них нових товарів з метою збуту

У зв'язку з введенням в дію Закону УРСР "Про захист споживчого ринку в Українській РСР" ( 1255-12 ) Кабінет Міністрів України постановляє:

1. Затвердити перелік готових промислових товарів народного споживання, що реалізуються через роздрібну торговельну мережу, які забороняється використовувати як сировину або напівфабрикати для виготовлення з них нових товарів з метою збуту, згідно з додатком.

Надати Міністерству економіки України право вносити зміни до зазначеного переліку товарів виходячи із стану споживчого ринку.

2. Раді Міністрів Кримської АРСР, облвиконкомам, Київському і Севастопольському міськвиконкомам забезпечити широке інформування населення про встановлену законом відповідальність за використання зазначених у переліку до цієї постанови товарів як сировини або напівфабрикатів для виготовлення з них нових товарів з метою збуту.
