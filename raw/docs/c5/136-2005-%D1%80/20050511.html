Текст документа від 11.05.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 травня 2005 р. N 136-р Київ

Про встановлення строку виконання ремонтно-відновлювальних робіт для деяких видів енергетичного обладнання на митній території України

Відповідно до статті 232 Митного кодексу України ( 92-15 ) та з урахуванням технологічних особливостей встановити для енергетичного обладнання за кодом згідно з УКТЗЕД 8410 90 90 00 ( 2371г-14 ) строк виконання ремонтно-відновлювальних робіт на митній території України 180 днів.

Прем'єр-міністр України Ю.ТИМОШЕНКО
