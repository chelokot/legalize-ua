Президент України; Указ від 22.01.2010 № 54/2010

Про зупинення дії розпорядження Кабінету Міністрів України від 23 грудня 2009 року N 1584-р

Стан: Втратив чинність

Ідентифікатор: 54/2010

Текст документа від 22.01.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії розпорядження Кабінету Міністрів України від 23 грудня 2009 року N 1584-р

{ Додатково див. Конституційне подання Президента ( n0001100-10 ) від 22.01.2010 }

Кабінетом Міністрів України 23 грудня 2009 року видано розпорядження N 1584-р ( 1584-2009-р ) "Про призначення Гошовського З.Й. керівником торговельно-економічної місії у складі Посольства України в Словацькій Республіці". Прийняття Кабінетом Міністрів України цього рішення здійснено без погодження Президентом України відповідної кандидатури для призначення на посаду керівника торговельно-економічної місії у складі Посольства України в Словацькій Республіці.

Розпорядження Кабінету Міністрів України від 23 грудня 2009 року N 1584-р ( 1584-2009-р ) не відповідає Конституції України ( 254к/96-ВР ).

Відповідно до пункту 3 частини першої статті 106 Конституції України ( 254к/96-ВР ) Президент України здійснює керівництво зовнішньополітичною діяльністю держави.

Конституційний Суд України у своєму Рішенні від 15 січня 2009 року N 2-рп/2009 ( v002p710-09 ) зазначив, що Президент України та Кабінет Міністрів України мають окремі конституційні повноваження у сфері зовнішньополітичної діяльності, але лише Президент України як глава держави наділений повноваженням здійснювати керівництво цією діяльністю. Це означає, що глава держави не тільки здійснює загальне спрямування зовнішньополітичного курсу держави згідно з визначеними Верховною Радою України засадами зовнішньої політики України, але й застосовує відповідні засоби впливу на діяльність суб'єктів зовнішньополітичної діяльності з метою забезпечення національних інтересів і безпеки України. Реалізація цього конституційного повноваження обумовлює участь глави держави у доборі кадрів, у тому числі через попереднє погодження кандидатур на відповідні посади.

Указом Президента України від 30 квітня 1994 року N 200 ( 200/94 ) "Про Торговельно-економічну місію у складі закордонної дипломатичної установи України" (зі змінами, внесеними Указом від 26 лютого 2007 року N 145) ( 145/2007 ) установлено, що кандидатура для призначення на посаду керівника торговельно-економічної місії попередньо погоджується з Президентом України.

Крім того, Указом Президента України від 4 червня 2008 року N 513 ( 513/2008 ) "Про деякі питання керівництва зовнішньополітичною діяльністю держави" (який Рішенням Конституційного Суду України від 15 січня 2009 року N 2-рп/2009 ( v002p710-09 ) визнано таким, що відповідає Конституції України) ( 254к/96-ВР ) передбачено, що кандидатури на посади радника-посланника, радника дипломатичного представництва України в іноземній державі попередньо погоджуються в установленому порядку з Президентом України. У зв'язку з цим слід зазначити, що відповідно до пункту 6 Положення про торговельно-економічну місію у складі закордонної дипломатичної установи України, затвердженого Указом Президента України від 30 квітня 1994 року N 200 ( 200/94 ), керівник торговельно-економічної місії за посадою є радником-посланником або радником закордонної дипломатичної установи України.

Відтак, розпорядження N 1584-р ( 1584-2009-р ) не відповідає пункту 3 частини першої статті 106 Конституції України ( 254к/96-ВР ), за яким Президент України здійснює керівництво зовнішньополітичною діяльністю держави, актам глави держави, виданим на виконання цього конституційного повноваження, та видано всупереч вищеназваному Рішенню Конституційного Суду України.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 23 грудня 2009 року N 1584-р ( 1584-2009-р ) "Про призначення Гошовського З.Й. керівником торговельно-економічної місії у складі Посольства України в Словацькій Республіці".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
