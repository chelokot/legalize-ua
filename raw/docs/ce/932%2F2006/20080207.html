УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у міжнародних заходах у рамках Конвенції про заборону або обмеження застосування конкретних видів звичайної зброї, які можуть вважатись такими, що завдають надмірних ушкоджень або мають невибіркову дію

1. Утворити делегацію України для участі у міжнародних заходах у рамках Конвенції про заборону або обмеження застосування конкретних видів звичайної зброї, які можуть вважатись такими, що завдають надмірних ушкоджень або мають невибіркову дію ( 995_266 ), які відбуватимуться у м. Женеві, Швейцарська Конфедерація, зокрема у 8-й щорічній зустрічі держав - учасниць Протоколу II до зазначеної Конвенції ( 995_266 ) (6 листопада 2006 року) та у Третій Конференції з розгляду дії Конвенції (7-17 листопада 2006 року), в такому складі:

БЄЛАШОВ - директор Департаменту контролю над

Володимир Євгенович озброєннями та військово-технічного співробітництва Міністерства закордонних справ України, глава делегації

МОСКВІТІН - заступник Постійного представника

Олександр Олексійович України при Відділенні ООН та інших міжнародних організаціях у Женеві, заступник глави делегації

МАРЧЕНКО - директор Департаменту сил цивільного

Григорій Борисович захисту Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, член делегації

СИРОТЕНКО - старший офіцер з наукової роботи відділу Василь Володимирович планування інженерного забезпечення Центрального управління Інженерних військ Головного управління оперативного забезпечення командування сил підтримки Збройних Сил України, член делегації

ЧЕРНЯВСЬКИЙ - головний консультант Головної служби

Анатолій Анатолійович оборонної політики Секретаріату Президента України, член делегації.

2. Міністрові закордонних справ України затвердити вказівки делегації України на зазначені у пункті 1 цього Указу міжнародні заходи.

3. Кабінету Міністрів України вирішити питання про виділення коштів у іноземній валюті для забезпечення участі у міжнародних заходах у рамках Конвенції ( 995_266 ) В. Сиротенка, А. Чернявського (відряджаються з 5 по 19 листопада 2006 року) та Г. Марченка (відряджається з 12 по 17 листопада 2006 року).

Президент України В.ЮЩЕНКО
