Про виділення коштів для закінчення робіт, пов'язаних із здійсненням протихолерних заходів у Кілійському районі Одеської області

Текст документа від 26.07.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 травня 1999 р. N 884 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1178 ( 1178-2000-п ) від 26.07.2000 )

Про виділення коштів для закінчення робіт, пов'язаних із здійсненням протихолерних заходів у Кілійському районі Одеської області

Кабінет Міністрів України постановляє:

1. Виділити Одеській обласній державній адміністрації на 1999 рік 1312 тис. гривень для закінчення робіт, пов'язаних із здійсненням протихолерних заходів у Кілійському районі Одеської області.

Міністерству фінансів профінансувати зазначені витрати за рахунок резервного фонду Кабінету Міністрів України.

2. Одеській обласній державній адміністрації поінформувати до кінця поточного року Міністерство фінансів та Міністерство економіки про використання коштів, виділених відповідно до цієї постанови.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
