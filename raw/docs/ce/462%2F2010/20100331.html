УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

1. Визнати такими, що втратили чинність:

Указ Президента України від 29 жовтня 2009 року N 872 ( 872/2009 ) "Про зупинення дії розпорядження Кабінету Міністрів України від 23 вересня 2009 року N 1178-р";

Указ Президента України від 2 листопада 2009 року N 890 ( 890/2009 ) "Про зупинення дії окремих постанов Кабінету Міністрів України";

Указ Президента України від 4 листопада 2009 року N 900 ( 900/2009 ) "Про зупинення дії постанови Кабінету Міністрів України від 21 жовтня 2009 року N 1117";

Указ Президента України від 21 грудня 2009 року N 1080 ( 1080/2009 ) "Про зупинення дії постанов Кабінету Міністрів України від 24 вересня 2008 року N 854 та від 22 жовтня 2008 року N 934";

Указ Президента України від 8 лютого 2010 року N 130 ( 130/2010 ) "Про зупинення дії постанови Кабінету Міністрів України від 27 січня 2010 року N 61".

2. Цей Указ набирає чинності з дня його опублікування.
