РОЗПОРЯДЖЕННЯ від 28 листопада 2007 р. N 1063-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1070-р ( 1070-2008-р ) від 06.08.2008 }

Питання удосконалення підготовки льотного складу військової авіації

Погодитися з пропозицією Міноборони щодо здійснення закупівлі восьми літаків типу ЯК-52м і послуг з ремонту трьох вертольотів типу МІ-8мт(мтв) та шести вертольотів типу МІ-2у з метою удосконалення підготовки льотного складу військової авіації для потреб Міноборони, інших військових формувань та правоохоронних органів спеціального призначення.

Міноборони і Мінфіну вирішити питання щодо фінансування закупівлі та ремонту зазначених повітряних суден військової авіації в межах коштів, що передбачені бюджетною програмою 2101150 "Розвиток озброєння та військової техніки Збройних Сил України" ( 489-16 ).

Прем'єр-міністр України В.ЯНУКОВИЧ
