Президент України; Указ від 11.05.1999 № 493/99

Про порядок складення присяги суддею, вперше призначеним на посаду

Стан: Втратив чинність

Ідентифікатор: 493/99

Текст документа від 17.11.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про порядок складення присяги суддею, вперше призначеним на посаду

{ Із змінами, внесеними згідно з Указами Президента N 991/99 від 16.08.99 N 59/2003 ( 59/2003 ) від 03.02.2003 N 1423/2003 ( 1423/2003 ) від 10.12.2003 N 560/2010 ( 560/2010 ) від 20.04.2010 N 1025/2010 ( 1025/2010 ) від 15.11.2010 }

З метою реалізації вимог Закону України "Про статус суддів" ( 2862-12 ) щодо складення присяги суддею, вперше призначеним на посаду, постановляю:

1. Затвердити Порядок складення присяги суддею, вперше призначеним на посаду (додається).

2. Установити, що цей Порядок є чинним до прийняття відповідного закону України.

Президент України Л.КУЧМА

м. Київ, 11 травня 1999 року N 493/99

ЗАТВЕРДЖЕНО Указом Президента України від 11 травня 1999 року N 493/99

ПОРЯДОК складення присяги суддею, вперше призначеним на посаду

1. Суддя, якого Президент України призначив вперше на посаду професійного судді, складає присягу, текст якої визначено Законом України "Про статус суддів" ( 2862-12 ).

{ Пункт 1 із змінами, внесеними згідно з Указом Президента N 991/99 від 16.08.99

2. Суддя складає присягу у присутності Президента України, Голови Конституційного Суду України, Голови Верховного Суду України, Голови Вищого спеціалізованого суду України з розгляду цивільних і кримінальних справ, Голови Вищого адміністративного суду України, Голови Вищого господарського суду України, Голови Вищої ради юстиції, Голови Вищої кваліфікаційної комісії суддів України, Міністра юстиції України, Голови Комітету Верховної Ради України з питань правосуддя, Голови Державної судової адміністрації України в урочистій обстановці у приміщенні, де встановлено Державний Герб України і Державний Прапор України. { Абзац перший пункту 2 в редакції Указу Президента N 59/2003 ( 59/2003 ) від 03.02.2003; із змінами, внесеними згідно з Указами Президента N 560/2010 ( 560/2010 ) від 20.04.2010, N 1025/2010 ( 1025/2010 ) від 15.11.2010 }

В окремих випадках суддя складає присягу, за дорученням Президента України, у присутності голови обласної державної адміністрації, членів відповідної ради суддів, голови відповідного апеляційного суду, суддів суду, в який його призначено, та начальника територіального управління державної судової адміністрації в урочистій обстановці у приміщенні, де встановлено Державний Герб України і Державний Прапор України. { Пункт 2 доповнено абзацом згідно з Указом Президента N 1423/2003 ( 1423/2003 ) від 10.12.2003 }

Суддя може запросити на церемонію близьких родичів.

3. Присягу зачитує сам суддя, а в разі коли її складають кілька суддів - найстаріший за віком суддя, після чого він (вони) скріплює (скріплюють) її текст своїм підписом.

4. Після складення присяги Президент України або за його дорученням голова обласної державної адміністрації вручає судді посвідчення судді.

{ Пункт 4 із змінами, внесеними згідно з Указом Президента N 1423/2003 ( 1423/2003 ) від 10.12.2003 }

5. Церемонія складення присяги суддею (суддями) завершується виконанням Державного Гімну України.

6. Підписаний суддею текст присяги зберігається в його особистій справі.

Про складення присяги робиться запис у трудовій книжці судді.
