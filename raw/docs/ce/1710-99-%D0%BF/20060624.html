КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 вересня 1999 р. N 1710 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 857 ( 857-2006-п ) від 24.06.2006 }

Про визначення Першого українського міжнародного банку банком-агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Визначити Перший український міжнародний банк банком-агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України.

2. Уповноважити Міністра фінансів Мітюкова І.О. підписати від імені Кабінету Міністрів України агентську угоду з Першим українським міжнародним банком.

3. Контроль за виконанням цієї постанови покласти на Віце-прем'єр-міністра України Тігіпка С.Л.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
