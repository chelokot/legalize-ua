МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

10.08.2007 N 586

Зареєстровано в Міністерстві юстиції України 15 серпня 2007 р. за N 935/14202

Про визнання такими, що втратили чинність, наказів Мінагрополітики від 20.06.2006 N 315 та від 20.06.2006 N 316

У зв'язку зі втратою чинності постанов Кабінету Міністрів України від 07.03.2006 N 254 ( 254-2006-п ) "Про використання у 2006 році коштів державного бюджету для проведення заходів, пов'язаних із селекцією в рибному господарстві" та від 07.03.2006 N 255 ( 255-2006-п ) "Про використання у 2006 році коштів державного бюджету для здійснення заходів з відтворення водних живих ресурсів внутрішніх водойм та Азово-Чорноморського басейну" НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Міністерства аграрної політики України від 20.06.2006 N 315 ( z1001-06 ) "Про затвердження Розмірів бюджетних видатків для проведення заходів, пов'язаних із селекцією в рибному господарстві", зареєстрований в Міністерстві юстиції України 23.08.2006 за N 1001/12875, та від 20.06.2006 N 316 ( z1002-06 ) "Про затвердження Розмірів бюджетних видатків для здійснення заходів з відтворення водних живих ресурсів внутрішніх водойм та Азово-Чорноморського басейну", зареєстрований в Міністерстві юстиції України 23.08.2006 за N 1002/12876.

2. Державному комітету рибного господарства України (Сочнев С.В.) забезпечити в установленому порядку подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням наказу покласти на заступника Міністра П.І.Вербицького.

Виконуючий обов'язки Міністра Б.К.Супіханов
