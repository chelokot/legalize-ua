Про новий склад Міжвідомчої комісії з питань регулювання імпорту

( Із змінами, внесеними згідно з Розпорядженням Президента N 206/99-рп від 02.09.99 )

1. Затвердити новий персональний склад Міжвідомчої комісії з питань регулювання імпорту, утвореної Указом Президента України від 21 вересня 1994 року N 545 ( 545/94 ) "Про заходи щодо здійснення єдиної державної політики регулювання імпорту" (додається).

2. Визнати таким, що втратив чинність, пункт 1 Розпорядження Президента України від 1 грудня 1997 року N 426 ( 426/97-рп ) "Про персональний склад Міжвідомчої комісії з питань регулювання імпорту".

Президент України Л.КУЧМА

м. Київ, 1 червня 1999 року N 118/99-рп
