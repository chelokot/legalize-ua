Питання утворення Державного центру інноваційних біотехнологій

Стан: Чинний

Ідентифікатор: 27-2010-п

Текст документа від 14.10.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 січня 2010 р. N 27 Київ

Питання утворення Державного центру інноваційних біотехнологій

{ Із змінами, внесеними згідно з Постановою КМ N 1023 ( 1023-2011-п ) від 05.10.2011 }

Кабінет Міністрів України постановляє:

1. Підтримати пропозицію Української академії аграрних наук щодо утворення Державного центру інноваційних біотехнологій (далі - Центр) як державної наукової установи на базі Міжвідомчого науково-експериментального центру з вивчення інфекційних хвороб, спільних для людей і тварин, Інституту ветеринарної медицини Української академії аграрних наук шляхом його виділення із складу зазначеного Інституту.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1023 ( 1023-2011-п ) від 05.10.2011 }

2. Установити, що:

Статут Центру затверджується Державним агентством з питань науки, інновацій та інформатизації;

керівництво Центром здійснює директор, який призначається на посаду Державним агентством з питань науки, інновацій та інформатизації;

визначення напрямів науково-дослідної діяльності Центру та її координацію здійснює наукова рада, яку очолює голова, що затверджується Державним агентством з питань науки, інновацій та інформатизації.

{ Пункт 2 в редакції Постанови КМ N 1023 ( 1023-2011-п ) від 05.10.2011 }

{ Пункт 3 виключено на підставі Постанови КМ N 1023 ( 1023-2011-п ) від 05.10.2011 }

4. Розмістити Центр у приміщеннях першого поверху робочою площею 210 кв. метрів та п'ятого поверху (повністю) будинку по вул. Донецькій, 30, у м. Києві.

5. Інституту ветеринарної медицини Української академії аграрних наук забезпечити передачу Центру придбаного за рахунок бюджетних коштів обладнання (устатковання), необхідного для забезпечення його функціонування.

6. Міністерству фінансів внести Кабінетові Міністрів України у тижневий строк пропозиції щодо визначення джерел фінансування Центру та передбачити під час доопрацювання проекту Державного бюджету України на 2010 рік і складання проекту Державного бюджету України на наступні роки кошти, необхідні для забезпечення функціонування Центру та здійснення ним науково-дослідних робіт.

7. Голові наукової ради Завірюсі А.І. невідкладно внести на розгляд Кабінету Міністрів України пропозиції щодо кандидатури директора Центру та персонального складу наукової ради.
