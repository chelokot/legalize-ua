Про внесення змін до деяких законів України з питань оподаткування

( Відомості Верховної Ради України (ВВР), 2002, N 5, ст. 31 )

{ Із змінами, внесеними згідно з Кодексом N 2755-VI ( 2755-17 ) від 02.12.2010, ВВР, 2011, N 13-14, N 15-16, N 17, ст.112 }
