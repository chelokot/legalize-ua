Про новий склад Наглядової ради Національного фонду соціального захисту матерів і дітей "Україна - дітям"

На зміну статті 2 Указу Президента України від 19 березня 1997 року N 253 ( 253/97 ) "Питання Національного фонду соціального захисту матерів і дітей "Україна - дітям" (зі змінами, внесеними Указами від 19 вересня 1997 року N 1050 ( 1050/97 ), від 30 квітня 1999 року N 459 ( 459/99 ), від 1 червня 2000 року N 742 ( 742/2000 ), від 9 вересня 2000 року N 1051 ( 1051/2000 ) і від 15 жовтня 2001 року N 977 ( 977/2001 ) затвердити новий персональний склад Наглядової ради Національного фонду соціального захисту матерів і дітей "Україна - дітям" (додається).
