КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 квітня 1999 р. N 615 Київ

{ Постанова втратила чинність на підставі Постанов КМ N 645 ( 645-2015-п ) від 22.07.2015 N 656 ( 656-2015-п ) від 19.08.2015 }

Про документи про освіту

Кабінет Міністрів України постановляє:

1. Абзац третій пункту 3 постанови Кабінету Міністрів України від 12 листопада 1997 р. N 1260 ( 1260-97-п ) "Про документи про освіту та вчені звання" (Офіційний вісник України, 1997 р., число 46, с. 84) викласти у такій редакції:

"продовжити виготовлення документів про освіту на основі фотокомп'ютерних технологій з використанням виробничих потужностей з виготовлення цінних паперів поліграфічного комбінату "Україна" з одночасним запровадженням загальнодержавної автоматизованої системи обліку виданих документів".

2. Установити, що випусникам навчальних закладів 1999 року можуть бути видані документи про освіту за зразками, затвердженими постановою Кабінету Міністрів України від 17 грудня 1993 р. N 1058 ( 1058-93-п ) "Про затвердження переліку і зразків документів про освіту та вчені звання в Україні", в межах їх наявної кількості.
