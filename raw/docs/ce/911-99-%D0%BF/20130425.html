Про термін виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах у разі виготовлення срібних заготовок для монет

Стан: Втратив чинність

Ідентифікатор: 911-99-п

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 травня 1999 р. N 911 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про термін виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах у разі виготовлення срібних заготовок для монет

{ Із змінами, внесеними згідно з Постановами КМ N 1648 ( 1648-2001-п ) від 13.12.2001 N 386 ( 386-2008-п ) від 17.04.2008 }

Враховуючи технологічні особливості виготовлення срібних заготовок для монет та відповідно до статті 5 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ) Кабінет Міністрів України постановляє:

Установити термін виконання операції з давальницькою сировиною у разі виготовлення заготовок для монет (код УКТ ЗЕД 7106 92 20 00) до 270 днів з дня оформлення вивізної вантажної митної декларації.

{ Постанова із змінами, внесеними згідно з Постановами КМ N 1648 ( 1648-2001-п ) від 13.12.2001, N 386 ( 386-2008-п ) від 17.04.2008 }
