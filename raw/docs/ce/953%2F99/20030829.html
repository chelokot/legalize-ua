Президент України; Указ від 02.08.1999 № 953/99

Про внесення доповнення до Указу Президента України від 13 лютого 1998 року N 117

Стан: Втратив чинність

Ідентифікатор: 953/99

Текст документа від 29.08.2003:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 947/2003 ( 947/2003 ) від 29.08.2003 )

Про внесення доповнення до Указу Президента України від 13 лютого 1998 року N 117

Доповнити підпункт 2 абзацу другого пункту 36 Положення про державний експортний контроль в Україні, затвердженого Указом Президента України від 13 лютого 1998 року N 117 ( 117/98 ) (із змінами, внесеними Указом від 26 березня 1999 року N 283 ( 283/99 ), словами "або інший офіційний документ, що містить необхідні відомості для проведення експертизи та прийняття відповідного рішення".

Президент України Л.КУЧМА

м. Київ, 2 серпня 1999 року N 953/99
