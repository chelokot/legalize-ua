Про затвердження Порядку та форми повідомлення про результати розрахунків авансових внесків податку на прибуток

( Із змінами, внесеними згідно з Наказами Державної податкової адміністрації N 124 ( z0211-99 ) від 15.03.99 N 339 ( z0456-99, z0457-99 ) від 01.07.99 )

( Додатково див. Наказ Державної податкової адміністрації N 388 ( z0517-99 ) від 24.07.99 )

( Із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 42 ( z0077-03 ) від 29.01.2003 )

З метою забезпечення виконання пункту 16.7 статті 16 Закону України "Про оподаткування прибутку підприємств" ( 334/94-ВР ) та відповідно до п.4 ст.8 Закону України "Про державну податкову службу в Україні" ( 509-12 ) НАКАЗУЮ:

1. Затвердити Порядок та форму повідомлення про результати розрахунків авансових внесків податку на прибуток, що додаються.

2. Начальнику Головного управління прямих податків А.П.Фурману подати цей наказ та Порядок повідомлення про результати розрахунків авансових внесків податку на прибуток до Міністерства юстиції України на державну реєстрацію.

Виконуючий обов'язки Голови Ф.О.Ярошенко

( Порядок повідомлення про результати розрахунків авансових внесків податку на прибуток втратив чинність на підставі Наказу Державної податкової адміністрації N 42 ( z0077-03 ) від 29.01.2003 )
