Кабінет Міністрів України; Розпорядження від 19.08.2009 № 977-р

Питання закупівлі речового майна за кошти резервного фонду державного бюджету для святкування 18-ї річниці незалежності України

Стан: Чинний

Ідентифікатор: 977-2009-р

Текст документа від 19.08.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 серпня 2009 р. N 977-р Київ

Питання закупівлі речового майна за кошти резервного фонду державного бюджету для святкування 18-ї річниці незалежності України

1. Відповідно до пункту 6 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006; 2009 р., N 20, ст. 628, N 40, ст. 1351, N 50, ст. 1674), установити, що закупівля для святкування 18-ї річниці незалежності України речового майна за рахунок коштів резервного фонду державного бюджету ( 835-17 ), виділених згідно з розпорядженням Кабінету Міністрів України від 22 липня 2009 р. N 857 ( 857-2009-р ), здійснюється Міноборони за процедурою закупівлі в одного учасника без погодження з Мінекономіки.

2. Державному казначейству невідкладно реєструвати зобов'язання Міноборони щодо закупівлі речового майна згідно з пунктом 1 цього розпорядження.

3. ГоловКРУ здійснити ревізію ефективного та цільового витрачання коштів резервного фонду державного бюджету ( 835-17 ), виділених для проведення заходів щодо підготовки та святкування 18-ї річниці незалежності України, у місячний строк після проведення зазначених заходів.

Прем'єр-міністр України Ю.ТИМОШЕНКО
