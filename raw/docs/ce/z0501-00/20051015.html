N 419 від 02.08.2000 Зареєстровано в Міністерстві м.Київ юстиції України 15 серпня 2000 року vd20000802 vn419 за N 501/4722

( Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 559 ( z1133-05 ) від 16.09.2005 )

Про встановлення знижки вартості квитка (без плацкарти) на проїзд у поїзді міжнародного сполучення 624/623 Харків-Готня

Згідно з постановою Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та з метою збереження пасажиропотоку НАКАЗУЮ:

1. Установити знижку в розмірі 50 відсотків від вартості квитка (без плацкарти) на проїзд у поїзді міжнародного сполучення 624/623 Харків-Готня, визначеної Тарифами на перевезення пасажирів і багажу залізничним транспортом у міжнародному сполученні, затвердженими наказом Міністерства транспорту України від 03.12.97 N 409 ( z0584-97 ) і зареєстрованими в Міністерстві юстиції України 11.12.97 за N 584/2388.

2. Укрзалізниці (Горілей С.В.) та начальникам залізниць України забезпечити своєчасне введення у дію цього наказу, правильність застосування зазначеної знижки та поінформування пасажирів (на вокзалах та пунктах оформлення проїзних документів).

3. Контроль за виконанням цього наказу покласти на заступника Міністра транспорту України Демиденка А.Ф.
