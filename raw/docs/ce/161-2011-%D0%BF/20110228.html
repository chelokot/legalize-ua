Кабінет Міністрів України; Постанова від 28.02.2011 № 161

Про внесення змін до Порядку використання коштів державного бюджету, що спрямовуються для проведення державних виставкових заходів у сфері агропромислового комплексу

Стан: Чинний

Ідентифікатор: 161-2011-п

Текст документа від 28.02.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 лютого 2011 р. N 161 Київ

Про внесення змін до Порядку використання коштів державного бюджету, що спрямовуються для проведення державних виставкових заходів у сфері агропромислового комплексу

Кабінет Міністрів України постановляє:

Внести до Порядку використання коштів державного бюджету, що спрямовуються для проведення державних виставкових заходів у сфері агропромислового комплексу, затвердженого постановою Кабінету Міністрів України від 6 травня 2005 р. N 325 ( 325-2005-п ) "Питання використання коштів, передбачених у державному бюджеті для фінансової підтримки підприємств агропромислового комплексу" (Офіційний вісник України, 2005 р., N 19, ст. 997; 2006 р., N 10, ст. 615; 2007 р., N 14, ст. 521; 2008 р., N 23, ст. 678; 2010 р., N 48, ст. 1578), такі зміни:

доповнити пункт 1 абзацом такого змісту:

"Головним розпорядником бюджетних коштів та відповідальним виконавцем бюджетної програми "Проведення державних виставкових заходів у сфері агропромислового комплексу" є Міністерство аграрної політики та продовольства.";

у пункті 4 слова "Державним казначейством" замінити словами "в установленому законодавством порядку";

у пункті 5 слова "Фінансова звітність" замінити словом "Звітність";

пункт 7 викласти у такій редакції:

"7. Контроль за цільовим та ефективним використанням бюджетних коштів здійснюється у встановленому законодавством порядку.";

у тексті Порядку ( 325-2005-п ) слово "Мінагрополітики" замінити словами "Міністерство аграрної політики та продовольства" у відповідному відмінку.

Прем'єр-міністр України М.АЗАРОВ
