Текст документа від 21.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 серпня 2005 р. N 340-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

Про внесення змін до розпорядження Кабінету Міністрів України від 18 липня 2005 р. N 273

Внести зміни до розпорядження Кабінету Міністрів України від 18 липня 2005 р. N 273 ( 273-2005-р ) "Про утворення робочої групи з підготовки законопроекту про створення сприятливих умов для залучення інвестицій в економіку" та у назву додатка, доповнивши їх після слів "робоча група з" у всіх відмінках словами "питань спеціальних (вільних) економічних зон та територій пріоритетного розвитку із спеціальним режимом інвестиційної діяльності та".

Прем'єр-міністр України Ю.ТИМОШЕНКО
