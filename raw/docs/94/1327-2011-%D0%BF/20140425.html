ПОСТАНОВА від 21 грудня 2011 р. N 1327 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 117 ( 117-2014-п ) від 23.04.2014 }

Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404

Кабінет Міністрів України постановляє:

Внести зміну до пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752, N 44, ст. 2946, N 51, ст. 3406; 2007 р., N 43, ст. 1715, N 53, ст. 2157, N 56, ст. 2252, N 59, ст. 2344, N 91, ст. 3336; 2008 р., N 9, ст. 220, N 63, ст. 2146, N 69, ст. 2322, N 70, ст. 2355, N 81, ст. 2737, N 90, ст. 3004, N 95, ст. 3142; 2009 р., N 5, ст. 128, N 43, ст. 1442, N 46, ст. 1550, N 52, ст. 1794, N 79, ст. 2679, N 97, ст. 3362, N 99, ст. 3423; 2010 р., N 9, ст. 462, N 39, ст. 1307, N 70, ст. 2529, N 84, ст. 2958, N 90, ст. 3180, N 91, ст. 3222, N 94, ст. 3338, ст. 3342, N 98, ст. 3495, N 100, ст. 3567; 2011 р., N 14, ст. 568, N 41, ст. 1693, N 42, ст. 1723, N 47, ст. 1908, ст. 1921, N 56, ст. 2246, N 87, ст. 3172) - із змінами, внесеними постановами Кабінету Міністрів України від 7 грудня 2011 р. N 1273 ( 1273-2011-п ) і від 12 грудня 2011 р. N 1267 ( 1267-2011-п ), доповнивши останній абзац після слів "послуг поштового зв'язку" словами ", транспортних послуг з авіаперевезень".
