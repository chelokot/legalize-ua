Про визнання наказу Держкомприродресурсів України від 25.10.2004 N 199 таким, що втратив чинність

Реєстрація: Мін'юст України від 13.04.2006 № 437/12311

Стан: Чинний

Ідентифікатор: z0437-06

Текст документа від 05.04.2006:

МІНІСТЕРСТВО ОХОРОНИ НАВКОЛИШНЬОГО ПРИРОДНОГО СЕРЕДОВИЩА УКРАЇНИ

НАКАЗ

05.04.2006 N 163

Зареєстровано в Міністерстві юстиції України 13 квітня 2006 р. за N 437/12311

Про визнання наказу Держкомприродресурсів України від 25.10.2004 N 199 таким, що втратив чинність

Відповідно до Указу Президента України від 20.04.2005 N 675 ( 675/2005 ) "Про Міністерство охорони навколишнього природного середовища України" (із змінами) та постанови Кабінету Міністрів України від 20.02.2006 N 168 ( 168-2006-п ) "Про затвердження Порядку надання у 2006 році спеціальних дозволів на користування надрами" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Державного комітету природних ресурсів України від 25.10.2004 N 199 ( z1495-04 ) "Щодо затвердження Переліку випадків надання спеціальних дозволів (ліцензій) на користування надрами без проведення аукціонів", зареєстрований у Міністерстві юстиції України від 24.11.2004 за N 1495/10094.

2. Державній геологічній службі (Гурський Д.С.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на Першого заступника Міністра Лизуна С.О.

Міністр П.Ігнатенко
