Стан: Втратив чинність

Ідентифікатор: 184-2006-р

Текст документа від 08.08.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 квітня 2006 р. N 184-р Київ

{ Розпорядження скасовано на підставі Розпорядження КМ N 614-р ( 614-2007-р ) від 08.08.2007 }

Про затвердження складу Національної експертної комісії з питань захисту суспільної моралі

1. Затвердити склад Національної експертної комісії з питань захисту суспільної моралі, що додається.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 27 липня 2005 р. N 294 ( 294-2005-р ) "Про затвердження нового складу Національної експертної комісії з питань захисту суспільної моралі".
