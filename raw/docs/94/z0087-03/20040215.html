ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

27.01.2003 N 49

Зареєстровано в Міністерстві юстиції України 4 лютого 2003 р. за N 87/7408

Про посилення контролю за доставкою в митниці призначення окремих видів товарів

( Із змінами, внесеними згідно з Наказом Державної митної служби N 73 ( z0151-04 ) від 02.02.2004 )

Відповідно до постанови Кабінету Міністрів України від 23.02.99 N 255 ( 255-99-п ) "Про посилення контролю за доставкою до митниць призначення вантажів, які переміщуються під митним контролем" і з метою вдосконалення механізму контролю за транзитним переміщенням через митну територію України окремих видів товарів НАКАЗУЮ:

1. Установити, що транзитні переміщення через митну територію України автомобільним транспортом товарів 02-04, 07-09, 12, 15-21, 2201, 2202 груп і позицій згідно з УКТЗЕД ( 2371а-14 ) здійснюються за умови надання митним органам фінансових гарантій, передбачених постановами Кабінету Міністрів України від 29.06.96 N 700 ( 700-96-п ) "Про Положення про надання митним органам України фінансових гарантій щодо обов'язкової доставки товарів до митниць призначення" і від 04.10.96 N 1216 ( 1216-96-п ) "Про Положення про надання фінансових гарантій митним органам незалежними фінансовими посередниками щодо обов'язкової доставки товарів до митниць призначення", чи за умови охорони й супроводження цих товарів силами митних органів відповідно до наказу Держмитслужби України від 20.08.2003 N 565 ( z0746-03 ) "Про затвердження Інструкції про організацію та порядок охорони й супроводження товарів підрозділами митної варти Державної митної служби України", зареєстрованого в Міністерстві юстиції України 29.08.2003 за N 746/8067. ( Пункт 1 із змінами, внесеними згідно з Наказом Державної митної служби N 73 ( z0151-04 ) від 02.02.2004 )

2. Положення пункту 1 цього наказу не застосовується в разі перевезення товарів на умовах Митної конвенції про міжнародне перевезення вантажів із застосуванням книжки МДП 1975 року.

3. Управлінню технологій митного контролю (Сьомка С.М.) і Управлінню правової роботи (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Прес-службі (Гунько С.О.) після державної реєстрації цього наказу забезпечити висвітлення його в засобах масової інформації, Управлінню міжнародного митного співробітництва (Мароха В.М.) інформувати Міністерство закордонних справ України про дату введення в дію наказу для надання інформації іноземним суб'єктам зовнішньоекономічної діяльності.

5. Начальникам регіональних митниць, митниць довести цей наказ до відома суб'єктів підприємницької діяльності.

6. Установити, що наказ набирає чинності через 45 днів з дати його реєстрації в Міністерстві юстиції України.

7. Контроль за виконанням цього наказу покласти на заступника Голови Служби Пашка П.В.
