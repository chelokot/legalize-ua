ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

27.01.2003 N 49

Зареєстровано в Міністерстві юстиції України 4 лютого 2003 р. за N 87/7408

Про посилення контролю за доставкою в митниці призначення окремих видів товарів

( Із змінами, внесеними згідно з Наказами Державної митної служби N 73 ( z0151-04 ) від 02.02.2004 N 457 ( z0819-04 ) від 21.06.2004 N 812 ( z1469-04 ) від 11.11.2004 )

Відповідно до постанови Кабінету Міністрів України від 23.02.99 N 255 ( 255-99-п ) "Про посилення контролю за доставкою до митниць призначення вантажів, які переміщуються під митним контролем" і з метою вдосконалення механізму контролю за транзитним переміщенням через митну територію України окремих видів товарів НАКАЗУЮ:

1. Установити, що транзитні переміщення через митну територію України автомобільним транспортом товарів 02 - 04, 07 - 09, 12, 15 - 21, 2201, 2202, 3302, 3402, 4011, 4202, 4303, 4901, 6101, 6102, 6103, 6104, 6105, 6106, 6107, 6108, 6109, 6110, 6111, 6112, 6113, 6114, 6115, 6116, 6117, 6201, 6202, 6203, 6204, 6205, 6206, 6207, 6208, 6209, 6210, 6211, 6212, 6213, 6214, 6215, 6216, 6217, 6401, 6402, 6403, 6404, 6405, 6406, 8415, 8418, 8450, 8452, 8471, 8473 30, 8509, 8510, 8516, 8517, 8518, 8519, 8520, 8521, 8524, 8525, 8527, 8528, 8536, 9303, 9401, 9403 груп, товарних позицій та підкатегорії 6309 00 00 00 згідно з УКТ ЗЕД ( 2371а-14, 2371б-14, 2371в-14, 2371г-14 ) здійснюються за умови застосування одного із заходів гарантування доставки товарів, установлених статтею 161 Митного кодексу України ( 92-15 ). ( Пункт 1 із змінами, внесеними згідно з Наказом Державної митної служби N 73 ( z0151-04 ) від 02.02.2004; в редакції Наказів Держмитслужби N 457 ( z0819-04 ) від 21.06.2004, N 812 ( z1469-04 ) від 11.11.2004 )

( Пункт 2 виключено на підставі Наказу Держмитслужби N 457 ( z0819-04 ) від 21.06.2004 )

2. Управлінню технологій митного контролю (Сьомка С.М.) і Управлінню правової роботи (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Прес-службі (Гунько С.О.) після державної реєстрації цього наказу забезпечити висвітлення його в засобах масової інформації, Управлінню міжнародного митного співробітництва (Мароха В.М.) інформувати Міністерство закордонних справ України про дату введення в дію наказу для надання інформації іноземним суб'єктам зовнішньоекономічної діяльності.

4. Начальникам регіональних митниць, митниць довести цей наказ до відома суб'єктів підприємницької діяльності.

5. Установити, що наказ набирає чинності через 45 днів з дати його реєстрації в Міністерстві юстиції України.

6. Контроль за виконанням цього наказу покласти на заступника Голови Служби Пашка П.В.
