Кабінет Міністрів України; Розпорядження від 05.08.2009 № 954-р

Про виділення коштів для проведення першочергових аварійно-відбудовних робіт на автодорожньому переїзді греблі Дніпровської ГЕС

Стан: Чинний

Ідентифікатор: 954-2009-р

Текст документа від 14.10.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 серпня 2009 р. N 954-р Київ

Про виділення коштів для проведення першочергових аварійно-відбудовних робіт на автодорожньому переїзді греблі Дніпровської ГЕС

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1300-р ( 1300-2009-р ) від 14.10.2009 }

1. Виділити Запорізькій облдержадміністрації 7732,7 тис. гривень для проведення першочергових аварійно-відбудовних робіт на автодорожньому переїзді греблі Дніпровської ГЕС.

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 835-17 ).

Дозволити здійснювати попередню оплату товарів, робіт і послуг, пов'язаних з проведенням першочергових аварійно-відбудовних робіт, на строк не більше одного місяця в розмірі 30 відсотків їх вартості. { Пункт 1 доповнено абзацом згідно з Розпорядженням КМ N 1300-р ( 1300-2009-р ) від 14.10.2009 }

2. Запорізькій облдержадміністрації:

затвердити у тижневий строк за погодженням з Мінекономіки, Мінфіном та Мінрегіонбудом перелік витрат, пов'язаних з проведенням першочергових аварійно-відбудовних робіт на автодорожньому переїзді греблі Дніпровської ГЕС;

подати до кінця 2009 року Мінекономіки, Мінфіну, Мінрегіонбуду та Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
