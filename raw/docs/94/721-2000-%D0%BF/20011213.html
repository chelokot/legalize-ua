Кабінет Міністрів України; Постанова від 28.04.2000 № 721

Про встановлення термінів виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах у разі виготовлення труб

Стан: Втратив чинність

Ідентифікатор: 721-2000-п

Текст документа від 13.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 квітня 2000 р. N 721 Київ

Про встановлення термінів виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах у разі виготовлення труб

( Із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )

Відповідно до статті 2 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ) Кабінет Міністрів України постановляє:

Установити терміни виконання операцій з давальницькою сировиною, що ввозиться на митну територію України, у разі виготовлення труб з круглим внутрішнім і зовнішнім розрізом, зовнішній діаметр яких більше 406,4 мм, із чорних металів, поздовжніх, зварених дуговим зварюванням під флюсом для нафто- та газопроводів (код товару згідно з УКТ ЗЕД 7305 11 00 00) без антикорозійного покриття - 180, а з антикорозійним покриттям - 270 календарних днів з дати оформлення ввізної вантажної митної декларації.

( Постанова із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )
