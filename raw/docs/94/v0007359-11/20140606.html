{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 778 ( v0778359-14 ) від 06.06.2014 }

Про внесення змін до постанов Центральної виборчої комісії від 9 вересня 2010 року N 340 та від 8 жовтня 2010 N 398

Керуючись статтями 11-13 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

Внести до постанов Центральної виборчої комісії такі зміни:

1. У постанові Центральної виборчої комісії від 9 вересня 2010 року N 340 ( v0340359-10 ) "Про Порядок складання попередніх списків виборців для звичайних виборчих дільниць для підготовки і проведення голосування з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів":

1) у преамбулі постанови ( v0340359-10 ) слова "другої - дев'ятої" замінити словами "другої - восьмої";

2) у Порядку складання попередніх списків виборців для звичайних виборчих дільниць для підготовки і проведення голосування з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів ( v0340359-10 ), затвердженому зазначеною постановою:

у пунктах 5 та 6:

цифри "26" замінити цифрами "30";

слова та цифри "від 3 вересня 2010 року N 337" замінити словами та цифрами "від 13 січня 2011 року N 6 ( v0006359-11 ), зі зміною у назві подання періоду, за який подаються відомості";

пункт 7 виключити.

2. Абзаци перший та другий пункту 3.1 Роз'яснення щодо уточнення попереднього списку виборців на звичайній виборчій дільниці для підготовки і проведення голосування з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів, затвердженого постановою Центральної виборчої комісії від 8 жовтня 2010 року N 398 ( v0398359-10 ), викласти в такій редакції:

"3.1. Керівники органів, закладів, установ, зазначених у статті 22 Закону України "Про Державний реєстр виборців" ( 698-16 ), за одинадцять днів до дня місцевих виборів подають відповідному органу ведення Реєстру передбачені вказаною статтею відомості за формами, встановленими постановою Центральної виборчої комісії від 13 січня 2011 року N 6 ( v0006359-11 ), зі зміною у назві подання періоду, за який подаються відомості.

Такі відомості подаються за період з дати подання відомостей для складання попереднього списку виборців для підготовки і проведення голосування з відповідних місцевих виборів до дня подання цих відомостей.".

3. Визнати такою, що втратила чинність, постанову Центральної виборчої комісії від 3 вересня 2010 року N 337 ( v0337359-10, va337359-10 ) "Про форми подань з відомостями про виборців (осіб) для складання та уточнення попередніх списків виборців для звичайних виборчих дільниць під час підготовки виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів".

4. Цю постанову надіслати Міністерству внутрішніх справ України, Міністерству закордонних справ України, Міністерству оборони України, Міністерству охорони здоров'я України, Міністерству соціальної політики України, Міністерству юстиції України, Державній пенітенціарній службі України, Державній судовій адміністрації України, а також Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям для доведення до відома регіональних органів адміністрування та органів ведення Державного реєстру виборців та сільських, селищних, міських голів.
