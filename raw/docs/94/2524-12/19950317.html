Текст документа від 17.03.1995:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

( Постанова втратила чинність на підставі Постанови ВР N 96/95-ВР від 17.03.95, ВВР 1995, N 11, ст.701 )

Про введення в дію Закону України "Про внесення змін і доповнень до Закону України "Про статус автономної Республіки Крим"

( Додатково див. Постанову ВР N 29/94-ВР від 02.06.94, ВВР 1994, N 23, ст.176 )

Верховна Рада України постановляє :

Ввести в дію Закон України "Про внесення змін і доповнень до Закону України "Про статус автономної Республіки Крим" ( 2523-12 ) після приведення Верховною Радою Республіки Крим Конституції і законодавства Республіки Крим у відповідність з Конституцією

( 888-09 ) і законами України.
