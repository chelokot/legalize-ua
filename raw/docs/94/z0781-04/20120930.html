НАКАЗ

Зареєстровано в Міністерстві юстиції України 24 червня 2004 р. за N 781/9380

Про визнання таким, що втратив чинність, наказу Держмитслужби України від 02.09.2003 N 585 та внесення змін до наказів Держмитслужби України

{ Із змінами, внесеними згідно з Наказами Державної митної служби N 1118 ( z1428-05 ) від 17.11.2005 N 381 ( z0694-06 ) від 17.05.2006 N 933 ( z1329-07 ) від 07.11.2007 Наказами Міністерства фінансів N 631 ( z1360-12 ) від 30.05.2012 N 651 ( z1372-12 ) від 30.05.2012 }

Відповідно до Положення про Державну митну службу України, затвердженого Указом Президента України від 24.08.2000 N 1022 ( 1022/2000 ), постанови Кабінету Міністрів України від 09.06.97 N 574 ( 574-97-п ) "Про затвердження Положення про вантажну митну декларацію" (зі змінами й доповненнями) і з метою приведення нормативно-правових актів Держмитслужби України у відповідність до законодавства України НАКАЗУЮ:

1. Уважати таким, що втратив чинність, наказ Держмитслужби України від 02.09.2003 N 585 ( z0818-03 ) "Про внесення змін і доповнень до наказів Держмитслужби України", зареєстрований у Міністерстві юстиції України 17.09.2003 за N 818/8139.

{ Пункт 7 втратив чинність на підставі Наказу Міністерства фінансів N 631 ( z1360-12 ) від 30.05.2012 }

8. Департаменту організації митного контролю (Сьомка С.М.) і Департаменту правового забезпечення (Очич Ю.М.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

9. Управлінню інформаційного забезпечення та митної статистики (Макаренко А.В.) у 10-денний строк після державної реєстрації цього наказу допрацювати відповідні програмні забезпечення з урахуванням унесених змін.

10. Установити, що цей наказ набирає чинності через 10 днів від дня його офіційного опублікування.

11. Начальникам регіональних митниць, митниць довести цей наказ до відома юридичних і фізичних осіб.

12. Контроль за виконанням наказу покласти на першого заступника Голови Служби Іванюка М.М.
