Кабінет Міністрів України; Розпорядження від 25.10.2002 № 602-р

Про розміщення Українського науково-технологічного центру

Стан: Втратив чинність

Ідентифікатор: 602-2002-р

Текст документа від 28.05.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 жовтня 2002 р. N 602-р Київ

Про розміщення Українського науково-технологічного центру

{ Із змінами, внесеними згідно з Розпорядженням КМ N 773-р ( 773-2008-р ) від 28.05.2008 }

Погодитися з пропозицією МЗС та Київської міськдержадміністрації щодо розміщення Українського науково-технологічного центру в будинку по вул. Каменярів, 21, у м. Києві.

МОН за погодженням з Київською міськдержадміністрацією та МЗС укласти договір оренди цього будинку на 2008 рік. { Абзац другий в редакції Розпорядження КМ N 773-р ( 773-2008-р ) від 28.05.2008 }

Мінфіну, Державному казначейству разом з відповідними головними розпорядниками бюджетних коштів забезпечити фінансування видатків на утримання Українського науково-технологічного центру в межах бюджетних призначень на 2002 ( 2905-14 ) та наступні роки з урахуванням умов зазначеного договору оренди.

Прем'єр-міністр України А.КІНАХ
