КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 червня 2006 р. N 315-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

Про утворення комісії з розгляду пропозицій потенційних інвесторів щодо завершення будівництва Криворізького гірничо-збагачувального комбінату окислених руд

Для всебічного вивчення та оцінки пропозицій потенційних інвесторів щодо завершення будівництва Криворізького гірничо-збагачувального комбінату окислених руд утворити комісію у складі представників Мінекономіки. Мінпромполітики, МЗС, Мінфіну, Мінприроди, Мін'юсту, Мінпраці, Пенсійного фонду та Секретаріату Кабінету Міністрів України.

Головою комісії призначити заступника Голови Фонду державного майна Парфененка Дмитра Миколайовича.

Голові комісії:

затвердити її персональний склад;

інформувати Кабінет Міністрів України про результати розгляду пропозицій.

Прем'єр-міністр України Ю.ЄХАНУРОВ
