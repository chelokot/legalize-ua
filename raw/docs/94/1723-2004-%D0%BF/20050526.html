Текст документа від 26.05.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 грудня 2004 р. N 1723 Київ

( Постанова втратила чинність на підставі Постанови КМ N 378 ( 378-2005-п ) від 26.05.2005 )

Про внесення змін до деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. У пункті 1 Порядку централізованого оформлення, виготовлення та видачі паспорта громадянина України для виїзду за кордон, затвердженого постановою Кабінету Міністрів України від 2 квітня 2002 р. N 450 ( 450-2002-п ) (Офіційний вісник України, 2002 р., N 14, ст. 754), слова "Державним центром виготовлення паспортних документів" замінити словами "Державним підприємством "Державний центр персоналізації документів".

2. У підпункті 5 пункту 3 Положення про Головний обчислювальний центр Єдиної державної автоматизованої паспортної системи, затвердженого постановою Кабінету Міністрів України від 29 квітня 2004 р. N 573 ( 573-2004-п ) (Офіційний вісник України, 2004 р., N 17, ст. 1197), слова "Державного центру виготовлення паспортних документів" замінити словами "Державного підприємства "Державний центр персоналізації документів".
