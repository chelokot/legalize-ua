НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

N 1080 від 24.10.2001 Зареєстровано в Міністерстві юстиції України 19 листопада 2001 р. за N 961/6152

{ Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 1034 ( z0986-06 ) від 03.08.2006 }

Про роздрібні ціни на газ природний, що використовується населенням смт Солотвина Закарпатської області безпосередньо із Солотвинського родовища на комунально-побутові потреби

{ Із змінами, внесеними згідно з Постановою Національної комісії регулювання електроенергетики N 400 ( z0412-06 ) від 30.03.2006 }

Згідно з повноваженнями, наданими Указом Президента України від 21.04.98 N 335 ( 335/98 ) "Питання Національної комісії регулювання електроенергетики України", постановою Кабінету Міністрів України від 25 грудня 1996 року N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", ураховуючи звернення НАК "Нафтогаз України" щодо визначення механізму зниження ціни на природний газ (який споживається населенням смт Солотвина Закарпатської області безпосередньо із Солотвинського родовища) у залежності від фактичної величини теплоти згорання, Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Затвердити роздрібні ціни на газ природний, що використовується населенням смт Солотвина Закарпатської області безпосередньо із Солотвинського родовища на комунально-побутові потреби (додаються).

{ Пункт 2 фактично втратив чинність у зв'язку з втратою чинності Постанови Національної комісії регулювання електроенергетики N 310 ( z0153-99 ) від 10.03.99, до якої вносились зміни } 2. Унести зміну до постанови НКРЕ від 10.03.99 N 310 ( z0153-99 ) "Про роздрібні ціни на газ природний, що використовується населенням на комунально-побутові потреби", зареєстрованої у Міністерстві юстиції України 10.03.99 за N 153/3446, виклавши пункт 1 у такій редакції:

"1. Затвердити роздрібні ціни на газ природний, що використовується населенням на комунально-побутові потреби, згідно з додатком, крім населення смт Солотвина Закарпатської області, яке споживає природний газ безпосередньо із Солотвинського родовища".

3. ДК "Укргазвидобування" НАК "Нафтогаз України" щомісяця надає ВАТ з газопостачання та газифікації "Закарпатгаз" інформацію про величину теплоти згорання природного газу, видобутого із Солотвинського родовища.

4. Контроль за виконанням пункту 3 постанови покласти на Закарпатське територіальне представництво НКРЕ.

5. Установити, що ця постанова набуває чинності з 1 грудня 2001 року.
