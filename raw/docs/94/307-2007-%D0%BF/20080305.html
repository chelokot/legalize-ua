Кабінет Міністрів України; Постанова, Порядок від 01.03.2007 № 307

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для впровадження інвестиційних технологій у виробництво технічних засобів реабілітації інвалідів

Стан: Чинний

Ідентифікатор: 307-2007-п

Текст документа від 05.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 2007 р. N 307 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для впровадження інвестиційних технологій у виробництво технічних засобів реабілітації інвалідів

{ Із змінами, внесеними згідно з Постановою КМ N 132 ( 132-2008-п ) від 05.03.2008 }

{ Установити, що використання у 2008 році коштів, передбачених Міністерству праці та соціальної політики у державному бюджеті ( 107-17 ) за програмою "Впровадження інноваційних технологій у виробництві технічних засобів реабілітації інвалідів", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 132 ( 132-2008-п ) від 05.03.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для впровадження інвестиційних технологій у виробництво технічних засобів реабілітації інвалідів, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 1 березня 2007 р. N 307

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для впровадження інноваційних технологій у виробництво технічних засобів реабілітації інвалідів

{ У назві та тексті Порядку слово "інвестиційних" замінено словом "інноваційних" згідно з Постановою КМ N 132 ( 132-2008-п ) від 05.03.2008 }

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті ( 489-16 ) Мінпраці за програмою 2501370 "Впровадження інноваційних технологій у виробництві технічних засобів реабілітації інвалідів" (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються на фінансування впровадження інноваційних технологій у виробництво технічних та інших засобів реабілітації, комплектуючих частин до протезно-ортопедичних виробів.

{ Пункт 2 в редакції Постанови КМ N 132 ( 132-2008-п ) від 05.03.2008 }

3. Мінпраці визначає одержувачами бюджетних коштів державні та казенні протезно-ортопедичні підприємства і державне підприємство "Київський завод "Імпульс".

4. Операції з бюджетними коштами проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 4 в редакції Постанови КМ N 132 ( 132-2008-п ) від 05.03.2008 }

5. Закупівля товарів, робіт і послуг за бюджетні кошти здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

6. З метою недопущення виникнення кредиторської заборгованості на кінець року в договір про закупівлю товарів, робіт і послуг обов'язково включається вимога про можливе коригування визначеної у договорі суми та зобов'язань сторін у разі зменшення бюджетних призначень під час уточнення показників Державного бюджету України на 2007 рік ( 489-16 ).

{ Пункт 7 виключено на підставі Постанови КМ N 132 ( 132-2008-п ) від 05.03.2008 }

8. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим і ефективним витрачанням здійснюються в установленому законодавством порядку.
