{ Розпорядження скасовано на підставі Розпорядження КМ N 288-р ( 288-2006-р ) від 25.05.2006 }

Про охоронну зону навколо парку-пам'ятки садово-паркового мистецтва загальнодержавного значення "Феофанія"

Прийняти пропозицію Національної академії наук щодо встановлення охоронної зони навколо парку-пам'ятки садово-паркового мистецтва загальнодержавного значення "Феофанія" згідно з додатком.

Взяти до відома, що Київська міська рада за погодженням з Національною академією наук та Мінприроди затвердить відповідно до частини третьої статті 53 Закону України "Про природно-заповідний фонд України" ( 2456-12 ) режим зазначеної охоронної зони з урахуванням можливості її забудови не вище трьох поверхів.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 21

Додаток до розпорядження Кабінету Міністрів України від 25 листопада 2004 р. N 871-р
