Про затвердження Положення про продаж єдиних майнових комплексів державних підприємств, які за класифікацією об'єктів приватизації віднесені до груп В, Г

Реєстрація: Мін'юст України від 25.09.2002 № 784/7072

Стан: Втратив чинність

Ідентифікатор: za784-02

Текст документа від 14.08.2018:

АНТИМОНОПОЛЬНИЙ КОМІТЕТ УКРАЇНИ

РОЗПОРЯДЖЕННЯ

26.07.2002 N 226-р

Зареєстровано в Міністерстві юстиції України 25 вересня 2002 р. за N 784/7072

{ Розпорядження втратило чинність на підставі Розпорядження Антимонопольного комітету

N 11-рп ( zb830-18 ) від 21.06.2018 }

Про затвердження Положення про продаж єдиних майнових

комплексів державних підприємств, які за класифікацією об'єктів приватизації віднесені до груп В, Г

{ Із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 255-р ( zb782-12 ) від 26.04.2012 }

1. Керуючись статтею 7 Закону України "Про Антимонопольний комітет України" ( 3659-12 ) та статтею 16 Закону України "Про приватизацію державного майна" ( 2163-12 ), затвердити Положення про продаж єдиних майнових комплексів державних підприємств, які за класифікацією об'єктів приватизації віднесені до груп В, Г ( zc784-02 ), що додається.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням Антимонопольного комітету N 255-р ( zb782-12 ) від 26.04.2012 }

2. Вважати таким, що втратило чинність, розпорядження Антимонопольного комітету України від 29 жовтня 2001 року N 140-р ( za090-01, z1090-01 ), зареєстроване в Міністерстві юстиції України 28 грудня 2001 року за N 1090/6281 "Про затвердження Положення про продаж цілісних майнових комплексів державних підприємств, які мають стратегічне значення для економіки та безпеки держави чи займають монопольне становище на загальнодержавному ринку".
