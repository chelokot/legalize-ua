КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 червня 2009 р. N 672-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про особливості закупівлі високотехнологічної продукції

1. Для подолання кризових явищ у промисловості та недопущення зменшення обсягу виробництва високотехнологічної продукції на підприємствах, які мають стратегічне значення для економіки і безпеки держави, та підприємствах оборонно-промислового комплексу, переліки яких затверджені відповідно постановою Кабінету Міністрів України від 23 грудня 2004 р. N 1734 ( 1734-2004-п ) (Офіційний вісник України, 2004 р., N 52, ст. 3443) та розпорядженням Кабінету Міністрів України від 30 жовтня 2008 р. N 1382 ( 1382-2008-р ) (далі - виробники), погодитися з пропозицією Мінпромполітики щодо запровадження у період до 31 грудня 2014 р. практики укладення між державними підприємствами - суб'єктами природних монополій, державними акціонерними товариствами та холдинговими компаніями, річні фінансові плани яких затверджуються Кабінетом Міністрів України (далі - підприємства), і виробниками договорів про закупівлю за кошти підприємств послуг з розроблення та виготовлення зазначеної продукції на довгостроковій (до п'яти років) основі за результатами проведених відповідно до законодавства процедур закупівлі.

2. Мінпромполітики разом з іншими центральними органами виконавчої влади, до сфери управління яких належать зазначені у пункті 1 цього розпорядження підприємства, підготувати та затвердити комплекс заходів, пов'язаних з переходом на довгострокове (до п'яти років) планування розроблення та виготовлення високотехнологічної продукції.
