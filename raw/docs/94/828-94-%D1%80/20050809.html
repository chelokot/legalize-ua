Кабінет Міністрів України; Розпорядження від 10.11.1994 № 828-р

Про віднесення до категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 828-94-р

Текст документа від 09.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 листопада 1994 р. N 828-р Київ

Про віднесення до категорій посад державних службовців

( Із змінами, внесеними згідно з Розпорядженнями КМ N 40-р ( 40-2005-р ) від 24.02.2005 N 326-р ( 326-2005-р ) від 09.08.2005 )

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади заступників керівників головних управлінь (управлінь), керівників відділів управлінь та служб Адміністрації Президента України, Секретаріату Верховної Ради України, апарату Кабінету Міністрів України; першого помічника Голови Верховної Ради України - завідуючого секретаріатом до другої категорії посад державних службовців.

( Розпорядження із змінами, внесеними згідно з Розпорядженнями КМ N 40-р ( 40-2005-р ) від 24.02.2005, N 326-р ( 326-2005-р ) від 09.08.2005 )
