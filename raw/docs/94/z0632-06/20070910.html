ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

19.05.2006 N 215

Зареєстровано в Міністерстві юстиції України 30 травня 2006 р. за N 632/12506

{ Наказ втратив чинність на підставі Наказу Державного комітету статистики N 310 ( z0988-07 ) від 21.08.2007 }

Про внесення змін до наказу Держкомстату України від 14.07.2003 N 216 "Про затвердження форм державних статистичних спостережень з питань ліквідації наслідків Чорнобильської катастрофи та інструкцій щодо їх заповнення"

Відповідно до статті 14 Закону України "Про державну статистику" ( 2614-12 ) (зі змінами) та з метою зменшення звітного навантаження на респондентів НАКАЗУЮ:

1. Унести зміни та доповнення до пункту 1 наказу Державного комітету статистики України від 14.07.2003 N 216 ( z0689-03 ) "Про затвердження форм державних статистичних спостережень з питань ліквідації наслідків Чорнобильської катастрофи та інструкцій щодо їх заповнення" та інструкцій щодо заповнення цих форм державних статистичних спостережень, зареєстрованого в Міністерстві юстиції України 06.08.2003 за N 689/8010:

1.1. Змінити періодичність подання форм державних статистичних спостережень N 1 (Чорнобиль) "Звіт про переселення жителів населених пунктів, які постраждали внаслідок Чорнобильської катастрофи" і N 7 (Чорнобиль) ( z0692-03 ) "Звіт про чисельність громадян, які мають статус постраждалих внаслідок Чорнобильської катастрофи", замінивши слово "піврічна" на "річна" у всіх відмінках та, відповідно, в інструкції щодо заповнення форми державного статистичного спостереження N 1 (Чорнобиль) "Звіт про переселення жителів населених пунктів, які постраждали внаслідок Чорнобильської катастрофи" слова "раз у півріччя" на "раз у рік".

1.2. Замінити у формах державних статистичних спостережень N 1 (Чорнобиль) "Звіт про переселення жителів населених пунктів, які постраждали внаслідок Чорнобильської катастрофи", N 3 (Чорнобиль) ( z0691-03 ) "Звіт про чисельність населення, яке проживає в зонах радіоактивного забруднення внаслідок Чорнобильської катастрофи" і N 7 (Чорнобиль) ( z0692-03 ) "Звіт про чисельність громадян, які мають статус постраждалих внаслідок Чорнобильської катастрофи" та інструкціях щодо їх заповнення слова "районному (міському) відділу статистики" на "районному (міському) управлінню (відділу) статистики" в усіх відмінках.

1.3. Визнати таким, що втратив чинність, пункт 1 наказу ( z0689-03 ) в частині дії форми державного статистичного спостереження N 2 (Чорнобиль) ( z0690-03 ) "Звіт про прийняття жителів з населених пунктів, що постраждали внаслідок Чорнобильської катастрофи, у чисті зони" та інструкції щодо її заповнення.

2. Зміни та доповнення, внесені пунктом 1 цього наказу, увести у дію з 1 липня 2006 року.

3. Департаменту статистики населення та адміністративно-територіального устрою (Стельмах Л.М.) спільно з Головним міжрегіональним управлінням статистики у м. Києві (Сидоренко М.М.) унести необхідні зміни до Плану розробки та експлуатації комплексів електронної обробки статистичної інформації на 2006 рік, затвердженого наказом Державного комітету статистики України від 01.03.2006 N 63.

4. Департаменту фінансового забезпечення, бухгалтерського обліку та звітності (Кучіна І.Ю.) забезпечити фінансування виготовлення та доставки бланків форм державних статистичних спостережень та інструкцій щодо їх заповнення зі змінами та доповненнями, внесеними пунктом 1 цього наказу.

5. Адміністративно-господарському департаменту (Царський В.І.) забезпечити контроль за своєчасним виготовленням та доставкою бланкової продукції на адресу відповідних територіальних органів державної статистики.

6. Контроль за виконанням цього наказу покласти на заступника Голови Власенко Н.С.

Голова О.Г.Осауленко
