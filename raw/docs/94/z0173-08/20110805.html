Зареєстровано в Міністерстві юстиції України 5 березня 2008 р. за N 173/14864

Про внесення змін до наказу Міністерства праці та соціальної політики України від 05.04.2006 N 106

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства праці та соціальної політики N 106 ( z0423-06 ) від 05.04.2006, до якого вносились зміни }

Відповідно до постанови Кабінету Міністрів України від 06.02.2008 N 34 ( 34-2008-п ) "Про внесення зміни до деяких постанов Кабінету Міністрів України" та з метою впорядкування умов оплати праці працівників Фонду сприяння місцевому самоврядуванню України НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 05.04.2006 N 106 ( z0423-06 ) "Про умови оплати праці працівників Фонду сприяння місцевому самоврядуванню України", зареєстрованого в Міністерстві юстиції України 12.04.2006 за N 423/12297, виклавши додаток у новій редакції (додається).

2. Ці зміни застосовуються, починаючи з 1 лютого 2008 року.

Міністр Л.Денісова

ПОГОДЖЕНО:

Заступник Міністра фінансів України В.Матвійчук
