НАКАЗ

N 32 від 09.04.97 Зареєстровано в Міністерстві м.Київ юстиції України 12 травня 1997 р. vd970409 vn32 за N 172/1976

Про затвердження Інструкції про відкриття реєстраційних рахунків органами Державного казначейства України

( Із змінами, внесеними згідно з Наказом Державного казначейства N 221 ( z0976-02 ) від 02.12.2002 )

З метою запровадження казначейської системи виконання державного бюджету НАКАЗУЮ:

1. Затвердити Інструкцію про відкриття реєстраційних рахунків органами Державного казначейства України (додається).

2. Контроль за виконанням Інструкції покласти на заступника начальника Головного управління Державного казначейства України - Кучина Л.С.

Заступник Міністра фінансів - начальник Головного управління Державного казначейства України В.П.Тентюк

( Інструкція про відкриття реєстраційних рахунків органами Державного казначейства України втратила чинність на підставі Наказу Державного казначейства N 221 ( z0976-02 ) від 02.12.2002 )
