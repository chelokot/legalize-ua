КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 серпня 2002 р. N 1306 Київ

Про колегію Міністерства праці та соціальної політики

( Із змінами, внесеними згідно з Постановами КМ N 1547 ( 1547-2002-п ) від 15.10.2002 N 1925 ( 1925-2002-п ) від 17.12.2002 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 1925 ( 1925-2002-п ) від 17.12.2002 )

2. Затвердити членами колегії Міністерства праці та соціальної політики Безсмертну Ольгу Володимирівну, Дроздову Лідію Миколаївну, з правом дорадчого голосу Кириленка В'ячеслава Анатолійовича (за згодою), Сушкевича Валерія Михайловича (за згодою).

( Затвердити членами колегії Міністерства праці та соціальної політики з правом дорадчого голосу Вернигору Леоніда Михайловича (за згодою), Сандлера Дмитра Михайловича (за згодою) згідно з Постановою КМ N 1547 ( 1547-2002-п ) від 15.10.2002 )

3. Визнати такими, що втратили чинність:

пункт 3 постанови Кабінету Міністрів України від 3 вересня 1997 р. N 966 ( 966-97-п ) "Питання Міністерства праці та соціальної політики" (Офіційний вісник України, 1997 р., число 36, с. 25);

пункт 1 постанови Кабінету Міністрів України від 21 жовтня 1998 р. N 1676 ( 1676-98-п ) "Про колегію Міністерства праці та соціальної політики України" (Офіційний вісник України, 1998 р., N 42, ст. 1560);

пункт 1 постанови Кабінету Міністрів України від 22 грудня 1998 р. N 2051 ( 2051-98-п ) "Про колегію Міністерства праці та соціальної політики України" (Офіційний вісник України, 1998 р., N 51, ст. 1900).
