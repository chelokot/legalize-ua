Реєстрація: Мін'юст України від 04.08.2003 № 672/7993

МІНІСТЕРСТВО ЕКОНОМІКИ ТА З ПИТАНЬ ЄВРОПЕЙСЬКОЇ ІНТЕГРАЦІЇ УКРАЇНИ

НАКАЗ

18.07.2003 N 193

Зареєстровано в Міністерстві юстиції України 4 серпня 2003 р. за N 672/7993

{ Наказ втратив чинність на підставі Наказу Міністерства економіки N 139 ( z0525-06 ) від 17.04.2006 }

Про вдосконалення роботи з організації навчання та підвищення кваліфікації спеціалістів з питань здійснення процедури закупівлі товарів, робіт і послуг за державні кошти

( Із змінами, внесеними згідно з Наказами Міністерства економіки та з питань європейської інтеграції N 345 ( z1136-03 ) від 28.11.2003 N 166 ( z0630-04 ) від 28.04.2004 )

Відповідно до постанови Кабінету Міністрів України від 01.06.2002 N 734 ( 734-2002-п ) "Про організацію навчання та підвищення кваліфікації спеціалістів з питань здійснення процедури закупівлі товарів, робіт і послуг за державні кошти" та на виконання постанови Кабінету Міністрів України від 02.06.2003 N 819 ( 819-2003-п ) "Про внесення змін та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань державних закупівель" НАКАЗУЮ:

1. Установити, що навчання та підвищення кваліфікації спеціалістів у сфері державних закупівель проводяться на базі тих навчальних закладів, які мають ліцензії Міністерства освіти і науки України із зазначенням зокрема такого виду освітніх послуг, як навчання та підвищення кваліфікації спеціалістів у сфері державних закупівель.

Зазначені ліцензії видаються Міністерством освіти і науки України згідно із законодавством навчальним закладам, які надали погоджені Міністерством економіки та з питань європейської інтеграції України програми навчання та підвищення кваліфікації, плани лекційних матеріалів, тестові завдання (екзаменаційні білети) та склад викладачів.

Затвердити форму сертифіката про проходження курсу навчання спеціалістів у сфері державних закупівель (додається).

( Пункт 1 в редакції Наказу Мінекономіки, європ.інтеграції N 166 ( z0630-04 ) від 28.04.2004 )

2. Установити, що:

термін курсу підвищення кваліфікації становить 4 дні;

термін курсу навчання становить 2 тижні;

викладачами на курсах навчання та підвищення кваліфікації можуть бути особи, які мають досвід роботи (у тому числі викладацької) у сфері державних закупівель не менше двох років та отримали відповідний сертифікат про проходження курсу навчання спеціалістів у сфері державних закупівель; ( Абзац четвертий пункту 2 в редакції Наказу Мінекономіки, європ.інтеграції N 166 ( z0630-04 ) від 28.04.2004 )

програми навчання та підвищення кваліфікації, сертифікати, плани лекційних матеріалів, тестові завдання (екзаменаційні білети - у разі проведення навчання) та склад викладачів курсів затверджуються директором департаменту з питань координації державних закупівель та державного замовлення (у разі відсутності директора департаменту - його заступником або начальником управління методології, правового забезпечення та контролю у сфері державних закупівель) Міністерства економіки та з питань європейської інтеграції України; ( Абзац п'ятий пункту 2 в редакції Наказу Міністерства економіки та з питань європейської інтеграції N 345 ( z1136-03 ) від 28.11.2003 )

після проходження курсу підвищення кваліфікації слухачам видається свідоцтво, форма якого затверджена постановою Кабінету Міністрів України від 12.11.1997 N 1260 ( 1260-97-п ) "Про документи про освіту та вчені звання";

після проходження курсу навчання слухачам видається сертифікат за формою, затвердженою цим наказом;

оцінка рівня організації базовими навчальними закладами курсів підвищення кваліфікації та курсів навчання проводиться Міністерством економіки та з питань європейської інтеграції України на підставі проведення анкетування слухачів курсів.

( Абзац дев'ятий пункту 2 виключено на підставі Наказу Мінекономіки, європ.інтеграції N 166 ( z0630-04 ) від 28.04.2004 )

3. Департаменту з питань координації державних закупівель та державного замовлення: ( Абзац перший пункту 3 в редакції Наказу Мінекономіки, європ.інтеграції N 166 ( z0630-04 ) від 28.04.2004 )

вести реєстри навчальних закладів, які отримали ліцензії Міністерства освіти і науки України на навчання та підвищення кваліфікації спеціалістів у сфері державних закупівель, осіб, які мають право бути викладачами на курсах навчання та підвищення кваліфікації, виданих сертифікатів про проходження навчання на підставі відповідної інформації, що подається навчальними закладами, та забезпечити розміщення зазначеної інформації у розділі "Державні закупівлі" Інтернет-сторінки Міністерства економіки та з питань європейської інтеграції України; ( Абзац другий пункту 3 в редакції Наказу Мінекономіки, європ.інтеграції N 166 ( z0630-04 ) від 28.04.2004 )

здійснювати оцінку рівня організації курсів підвищення кваліфікації та курсів навчання шляхом анкетування їх слухачів;

розробити форму анкети для проведення анкетування слухачів курсів підвищення кваліфікації та курсів навчання і надати її навчальним закладам; ( Абзац четвертий пункту 3 із змінами, внесеними згідно з Наказом Мінекономіки, європ.інтеграції N 166 ( z0630-04 ) від 28.04.2004 )

забезпечити реєстрацію цього наказу в Міністерстві юстиції України та публікацію його в бюлетені "Вісник державних закупівель".

4. Скасувати накази Міністерства економіки та з питань європейської інтеграції України від 16.08.2002 N 254 ( v0254569-02 ) "Про організацію навчання та підвищення кваліфікації спеціалістів у сфері державних закупівель" та від 31.03.2003 N 77 ( v0077569-03 ) "Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 16.08.2002 N 254".

5. Цей наказ набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.
