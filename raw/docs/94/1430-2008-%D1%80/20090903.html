Текст документа від 03.09.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 листопада 2008 р. N 1430-р Київ

Про невідкладні заходи щодо стабілізації ситуації в легкій промисловості

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1036-р ( 1036-2009-р ) від 03.09.2009 }

1. Держмитслужбі, Мінпромполітики, Мінекономіки здійснювати постійний моніторинг статистичних даних щодо експорту з країн походження товарів легкої промисловості в Україну та їх імпорту на митну територію України з метою виявлення незаконних шляхів надходження таких товарів та їх обсягів.

2. Держмитслужбі забезпечити здійснення ефективного контролю за недопущенням заниження митної вартості товарів легкої промисловості, що ввозяться на митну територію України.

3. Мінпромполітики, Мінекономіки підготувати:

{ Абзац другий пункту 3 виключено на підставі Розпорядження КМ N 1036-р ( 1036-2009-р ) від 03.09.2009 }

пропозиції щодо внесення сировини, допоміжних матеріалів та обладнання, які не виробляються в Україні, до переліку товарів критичного імпорту.

4. Держмитслужбі, Мінекономіки, Мінпромполітики, МЗС опрацювати питання щодо визначення спеціалізованих пунктів пропуску на митному кордоні України, через які здійснюватиметься ввезення на її митну територію товарів легкої промисловості.

5. Мінпромполітики, Держспоживстандарту, Мінекономіки розробити до 2010 року проект технічного регламенту маркування виробів легкої промисловості.

Прем'єр-міністр України Ю.ТИМОШЕНКО
