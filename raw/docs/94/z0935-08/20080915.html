Про внесення змін до наказу Мінтрансзв'язку від 14.04.2008 N 433

Відповідно до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та рекомендацій Міжнародної організації цивільної авіації (IKAO) НАКАЗУЮ:

1. Унести до наказу Міністерства транспорту та зв'язку України від 14.04.2008 N 433 ( z0408-08 ) "Про встановлення аеропортових зборів за обслуговування повітряних суден і пасажирів в аеропортах України та внесення змін до наказу Мінтрансу від 06.07.99 N 352" (далі - Наказ), зареєстрованого в Міністерстві юстиції України 14.05.2008 за N 408/15099, такі зміни:

1.1. Пункт 2 Наказу ( z0408-08 ) виключити. У зв'язку з цим пункти 3, 4, 5 вважати пунктами 2, 3, 4.

2. Унести до Аеропортових зборів за обслуговування повітряних суден і пасажирів в аеропортах України, затверджених наказом Міністерства транспорту та зв'язку України від 14.04.2008 N 433 ( z0408-08 ), зареєстрованим в Міністерстві юстиції України 14.05.2008 за N 408/15099, такі зміни:

2.1. У розділі I цифри "1 - 9" замінити цифрами "1 - 20";

2.2. Пункт 4 додатка 4 до Аеропортових зборів за обслуговування повітряних суден і пасажирів в аеропортах України ( z0408-08 ) викласти в такій редакції:

"4. Збір за наднормативну стоянку ПС - 0,34 дол. США за кожну годину наднормативної стоянки та кожну тонну МЗМ ПС";

2.3. Доповнити новими додатками 10 - 20 (додаються).

3. Державіаадміністрації (Поліщук К.А.):

3.1. Забезпечити подання цього наказу до Міністерства юстиції України в установленому порядку на державну реєстрацію.

3.2. Довести цей наказ до відома керівників авіапідприємств цивільної авіації України для використання в роботі.

4. Визнати такими, що втратили чинність, накази Міністерства транспорту України:

від 03.07.95 N 253 ( z0207-95 ) "Про затвердження аеропортових зборів за обслуговування повітряних суден в Міжнародному аеропорту "Київ" (Жуляни)", зареєстрований у Міністерстві юстиції України 07.07.95 за N 207/743;

від 04.03.98 N 67 ( z0197-98 ) "Про затвердження аеропортових зборів за обслуговування повітряних суден у міжнародному аеропорту "Миколаїв", зареєстрований у Міністерстві юстиції України 25.03.98 за N 197/2637;

від 06.07.99 N 351 ( z0503-99 ) "Про затвердження аеропортових зборів за обслуговування повітряних суден в аеропортах України, для яких не встановлені індивідуальні аеропортові збори", зареєстрований у Міністерстві юстиції України 26.07.99 за N 503/3796;

від 06.07.99 N 352 ( z0504-99 ) "Про затвердження аеропортових зборів за обслуговування повітряних суден у міжнародних аеропортах: "Рівне", "Херсон", зареєстрований у Міністерстві юстиції України 26.07.99 за N 504/3797;

від 05.10.2000 N 551 ( z0734-00 ) "Про затвердження аеропортових зборів за обслуговування повітряних суден у міжнародному аеропорту "Ужгород", зареєстрований у Міністерстві юстиції України 23.10.2000 за N 734/4955.

5. Контроль за виконанням цього наказу покласти на заступника Міністра - голову Державної авіаційної адміністрації Давидова О.М.
