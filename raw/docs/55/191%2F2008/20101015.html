{ Указ втратив чинність на підставі Указу Президента N 932/2010 ( 932/2010 ) від 04.10.2010 }

Про внесення зміни до Положення про Національну премію України імені Тараса Шевченка

Пункт 9 Положення про Національну премію України імені Тараса Шевченка, затвердженого Указом Президента України від 14 листопада 2005 року N 1599 ( 1599/2005 ), викласти в такій редакції:

"9. До колективу претендентів не допускається включення осіб, які виконували адміністративні, організаторські чи консультативні функції".
