КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 травня 2005 р. N 156-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 174 ( 174-2011-п ) від 02.03.2011 }

Про робочу групу з питань погашення простроченої заборгованості за кредитами, залученими державою або під державні гарантії

( Із змінами, внесеними згідно з Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 )

Утворити робочу групу з питань погашення простроченої заборгованості за кредитами, залученими державою або під державні гарантії, у складі згідно з додатком.

Надати керівникові робочої групи право вносити у разі потреби зміни до її складу.
