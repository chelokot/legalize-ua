УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Перелік посад, приписаних до дипломатичних рангів України

{ Із змінами, внесеними згідно з Указами Президента N 280/2004 ( 280/2004 ) від 05.03.2004 N 1157/2007 ( 1157/2007 ) від 28.11.2007 N 46/2008 ( 46/2008 ) від 23.01.2008 N 1186/2008 ( 1186/2008 ) від 19.12.2008 N 944/2010 ( 944/2010 ) від 11.10.2010 }

Відповідно до статті 2 Закону України "Про дипломатичні ранги України" ( 253-15 ) постановляю:

{ Преамбула із змінами, внесеними згідно з Указом Президента N 1157/2007 ( 1157/2007 ) від 28.11.2007 }

1. Затвердити Перелік посад, приписаних до дипломатичних рангів України (додається).

2. Міністерству закордонних справ України забезпечити до 1 травня 2002 року в установленому порядку вирішення питань щодо присвоєння дипломатичним працівникам дипломатичних рангів згідно з посадами, які вони займають.

3. Визнати такими, що втратили чинність:

Указ Президента України від 16 липня 1993 року N 267 ( 267/93 ) "Про Положення про дипломатичну службу в Україні";

Указ Президента України від 18 вересня 1996 року N 842 ( 842/96 ) "Про Перелік посад, приписаних до дипломатичних рангів України";

Указ Президента України від 16 січня 1998 року N 19 ( 19/98 ) "Про внесення змін і доповнень до Положення про дипломатичну службу в Україні та Переліку посад, приписаних до дипломатичних рангів України";

пункт 9 Змін, що вносяться до актів Президента України, затверджених Указом Президента України від 27 січня 1999 року N 70 ( 70/99 ) "Про зміни та визнання такими, що втратили чинність, деяких актів Президента України".
