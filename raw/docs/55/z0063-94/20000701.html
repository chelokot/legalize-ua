Реєстрація: Мін'юст України від 01.04.1994 № 63/272

Стан: Втратив чинність

Ідентифікатор: z0063-94

Текст документа від 01.07.2000:

МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ

НАКАЗ

N 29 від 25.03.94 Зареєстровано в Міністерстві м.Київ юстиції України 1 квітня 1994 р. за N 63/272

( Наказ втратив чинність з 1 липня 2000 року на підставі Наказу Мінфіну N 115 ( z0339-00 ) від 26.05.2000 )

Про внесення змін і доповнень до деяких нормативних актів з питань бухгалтерського обліку

( Із змінами, внесеними згідно з Наказами Мінфіну N 68 ( z0138-95 ) від 10.05.95 )

У зв'язку з постановою Кабінету Міністрів України від 21 березня 1994 р. N 175 ( 175-94-п ) "Про внесення змін і доповнень до постанов Кабінету Міністрів України від 3 квітня 1993 р. N 250 ( 250-93-п ) і від 19 вересня 1993 р. N 764 ( 764-93-п )" НАКАЗУЮ:

Внести такі зміни і доповнення:

1. До Вказівок щодо організації бухгалтерського обліку в Україні, затверджених наказом Міністерства фінансів України від 7 травня 1993 р. N 25 ( z0052-93 ):

а) ( Підпункт (а) пункту 1 втратив чинність на підставі Наказу Мінфіну N 68 ( z0138-95 ) від 10.05.95 ) пункт 1 доповнити абзацом такого змісту:

"порядок відображення курсових різниць по операціях в іноземній валюті.";

б) в абзаці третьому пункту 2 слова "фінансових управлінь Ради Міністрів Республіки Крим" замінити словами "Міністерства фінансів Республіки Крим, фінансових управлінь";

в) пункт 4 доповнити абзацом такого змісту:

"Підприємства, які за чинним законодавством виплачують винагороду за вислугу років, можуть створювати резерв на її виплату, включаючи відрахування на державне соціальне страхування";

г) пункт 8 після слів "субрахунку 2 "Малоцінні і швидкозношувані предмети в експлуатації" доповнити словом і цифрою "рахунку 12";

д) абзац одинадцятий пункту 13 після слів "сума нарахованого зносу" доповнити словами "(його нарахування відображається по дебету рахунків обліку затрат на виробництво, кошторисів витрат у кореспонденції з рахунком 02 "Знос (амортизація) майна")";

е) ( Підпункт (е) пункту 1 втратив чинність на підставі Наказу Мінфіну N 68 ( z0138-95 ) від 10.05.95 ) пункт 17 доповнити абзацом такого змісту:

"Підприємства можуть протягом усього звітного року курсові різниці відображати безпосередньо у кореспонденції з рахунком 80 "Прибутки і збитки", на який при такому варіанті повинно бути у звітному періоді списане кредитове сальдо субрахунку "Курсові різниці по операціях в іноземних валютах" рахунку 88 "Фонди спеціального призначення";

є) пункт 18 доповнити абзацом такого змісту:

"Усі розрахунки вартісних показників (нарахування податків, заробітної плати, пенсій, допомог, відрахувань, обов'язкових платежів тощо) провадяться та у первинних облікових документах заповнюються у сумах, кратних 1000". ( Підпункт "є" пункту 1 із змінами, внесеними згідно з Наказом Мінфіну N 68 ( z0138-95 ) від 10.05.95 )

2. У листі Міністерства фінансів України від 16 квітня 1992 р. N 18-445 ( v-445201-92 ) від 16.04.92 ) "Про бухгалтерський облік операцій в іноземних валютах":

а) ( Підпункт (а) пункту 2 втратив чинність на підставі Наказу Мінфіну N 68 ( z0138-95 ) від 10.05.95 ) після абзацу дев'ятого доповнити абзацом десятим такого змісту:

"Підприємства можуть протягом усього звітного року курсові різниці відображати у кореспонденції з рахунком 80 "Прибутки і збитки", на який при такому варіанті повинно бути у звітному періоді списане кредитове сальдо субрахунку "Курсові різниці по операціях в іноземних валютах" рахунку 88 "Фонди спеціального призначення";

б) абзац десятий вважати абзацом одинадцятим.

3. У листі Міністерства фінансів України від 20 березня 1992 р. N 18-430 ( v-430201-92 ) "Про бухгалтерський облік доходів підприємств і організацій" абзац четвертий пункту 7 виключити.

4. Зазначені зміни і доповнення застосовуються з 1 квітня 1994 року.
