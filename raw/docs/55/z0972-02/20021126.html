26.11.2002 N 468/579/479

Зареєстровано в Міністерстві юстиції України 16 грудня 2002 р. за N 972/7260

Про внесення змін та доповнень до Методики розрахунку платежів за користування надрами для видобування урану, сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння), виробної (виробне каміння) та для облицьовувальних матеріалів

На виконання постанови Кабінету Міністрів України від 28 лютого 2002 року N 222 ( 222-2002-п ) "Про затвердження диференційованих нормативів плати за користування надрами для видобування бурштинової, титанової та титано-цирконієвої руди" НАКАЗУЄМО:

1. Назву та текст Методики розрахунку платежів за користування надрами для видобування урану, сировини ювелірної (дорогоцінне каміння), ювелірно-виробної (напівдорогоцінне каміння), виробної (виробне каміння) та облицьовувальних матеріалів, затвердженої наказом Міністерства охорони навколишнього природного середовища та ядерної безпеки України, Державної податкової адміністрації України, Міністерства праці та соціальної політики України і Державного комітету України по геології і використанню надр від 7 квітня 1999 року N 79/187/51/57 ( z0263-99 ) та зареєстрованої в Міністерстві юстиції України 27 квітня 1999 року за N 263/3556, після слів "сировини ювелірної (дорогоцінне каміння)" доповнити словами "крім бурштину".

2. Державній геологічній службі Міністерства екології та природних ресурсів України (Д.Гурський) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України відповідно до вимог чинного законодавства України.

3. Контроль за виконанням цього наказу покласти на Першого заступника Державного секретаря Лизуна С.О.
