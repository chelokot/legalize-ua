Питання Державного комітету зв'язку та інформатизації

Стан: Втратив чинність

Текст документа від 07.08.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 червня 1999 р. N 957 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1231 ( 1231-2000-п ) від 07.08.2000 )

Питання Державного комітету зв'язку та інформатизації

( Із змінами, внесеними згідно з Постановою КМ N 501 ( 501-2000-п ) від 16.03.2000 )

Відповідно до Указу Президента України від 13 березня 1999 р. N 250 ( 250/99 ) "Про зміни в системі центральних органів виконавчої влади України" Кабінет Міністрів України постановляє:

1. Установити граничну чисельність працівників центрального апарату Державного комітету зв'язку та інформатизації у кількості 198, у тому числі шість військовослужбовців.

2. Дозволити Державному комітетові зв'язку та інформатизації мати чотирьох заступників Голови, у тому числі одного першого, та колегію у кількості одинадцяти чоловік.

3. Установити ліміт легкових автомобілів, що обслуговують Державний комітет зв'язку та інформатизації, 5 одиниць.

( Пункт 4 втратив чинність на підставі Постанови КМ N 501 ( 501-2000-п ) від 16.03.2000 ) 4. Дозволити Державному комітетові зв'язку та інформатизації здійснювати за згодою підприємств, що належать до сфери його управління, витрати на утримання центрального апарату за рахунок відрахувань від прибутку, що залишається у розпорядженні зазначених підприємств, у межах встановленої граничної чисельності та кошторису витрат на його утримання.
