НАКАЗ

N 499 від 27.11.96 Зареєстровано в Міністерстві м.Київ юстиції України 19 грудня 1996 р. за N 728/1753

Про внесення змін та доповнень до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, затвердженого наказом Держстандарту України від 30.06.93 N 95, та встановлення термінів її введення

( Додатково див. Наказ Держстандарту N 388 ( z0304-97 ) від 04.07.97 )

( Із змінами, внесеними згідно з Наказом Держстандарту N 268 ( z0209-97 ) від 17.05.97 )

Відповідно до Декрету Кабінету Міністрів України від 10.05.93 N 46-93 "Про стандартизацію та сертифікацію", з метою актуалізації Переліку продукції, що підлягає обов'язковій сертифікації в Україні, затвердженого наказом Держстандарту України від 30.06.93 N 95 ( z0112-93 ) (далі - Перелік), НАКАЗУЮ:

1. Внести зміни та доповнення до Переліку, затвердженого наказом Держстандарту України від 30.06.93 N 95 ( z0112-93), із змінами і доповненнями, внесеними наказами Держстандарту України від 21.02.94 N 35 ( z0069-94 ), від 06.02.95 N 44 ( z0040-95 ), від 19.05.95 N 161 ( z0170-95 ), від 26.06.95 N 215 ( z0203-95 ), від 22.12.95 N 437 ( z0479-95 ), від 03.01.96 N 1 ( z0026-96 ), від 26.03.96 N 132 ( z0156-96 ), від 11.06.96 N 230 ( z0323-96 ), від 11.06.96 N 235 ( z0311-96 ), від 16.08.96 N 345 ( z0491-96 ), виклавши його в новій редакції, що додається.

2. Встановити терміни введення обов'язкової сертифікації окремих видів продукції в Україні ( z0729-96 ), з урахуванням термінів, встановлених наказами, зазначеними у пункті 1 цього наказу.

3. Управлінню міжнародного співробітництва, кадрів, правових питань та учбових закладів довести цей наказ до відома:

- Міністерства закордонних справ та міністерства зовнішніх економічних зв'язків і торгівлі для подальшого інформування посольств та торговельно-економічних місій країн, які мають дипломатичні представництва в Україні;

- національних органів країни, з якими укладено угоди про співробітництво в галузі стандартизації, метрології та сертифікації.

4. Функціональним управлінням Держстандарту відповідно до напрямків своєї діяльності довести цей наказ до відома центральних органів державної виконавчої влади.

5. УкрНДІССІ здійснити видання Переліку продукції, що підлягає обов'язковій сертифікації в Україні.

6. Контроль за виконанням цього наказу покласти на заступника Голови Держстандарту України Є.Верещагу.
