КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 липня 2007 р. N 895 Київ

{ Постанову скасовано на підставі Постанови КМ N 1403 ( 1403-2007-п ) від 24.12.2007 }

{ Дію Постанови зупинено згідно з Указом Президента N 707/2007 ( 707/2007 ) від 13.08.2007 }

Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 12 липня 1999 р. N 1228

Кабінет Міністрів України постановляє:

Внести зміну до пункту 1 постанови Кабінету Міністрів України від 12 липня 1999 р. N 1228 ( 1228-99-п ) "Про надання суб'єктам зовнішньоекономічної діяльності повноважень на право здійснення експорту, імпорту товарів військового призначення та товарів, які містять відомості, що становлять державну таємницю" (Офіційний вісник України, 1999 р., N 28, ст. 1412, N 45, ст. 2230; 2001 р., N 5, ст. 181; 2002 р., N 47, ст. 2157; 2003 р., N 40, ст. 2096; 2006 р., N 27, ст. 1940, N 40, ст. 2677), виклавши абзац третій в такій редакції:

"експорту та імпорту товарів військового призначення і товарів, які містять відомості, що становлять державну таємницю, - державному підприємству "Зовнішньоторговельна фірма "ТАСКО-експорт" (м. Київ).".

Прем'єр-міністр України В.ЯНУКОВИЧ
