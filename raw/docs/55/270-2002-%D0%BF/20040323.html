Кабінет Міністрів України; Постанова від 07.03.2002 № 270

Про внесення змін до постанови Кабінету Міністрів України від 5 червня 2000 р. N 892

Стан: Чинний

Ідентифікатор: 270-2002-п

Текст документа від 23.03.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 березня 2002 р. N 270 Київ

Про внесення змін до постанови Кабінету Міністрів України від 5 червня 2000 р. N 892

( Із змінами, внесеними згідно з Постановою КМ N 359 ( 359-2004-п ) від 23.03.2004 )

Кабінет Міністрів України постановляє:

1. Внести до постанови Кабінету Міністрів України від 5 червня 2000 р. N 892 ( 892-2000-п ) "Про заходи щодо стабілізації роботи підприємств вугільної промисловості" (Офіційний вісник України, 2000 р., N 23, ст. 943) зміни, що додаються.

2. Ця постанова набирає чинності з 2 квітня 2002 року.

Прем'єр-міністр України А.КІНАХ

Інд. 34

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 березня 2002 р. N 270

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 5 червня 2000 р. N 892 ( 892-2000-п )

1. Пункт 7 після слова "кошти" доповнити словами "крім сум податку на додану вартість".

2. ( Пункт 2 втратив чинність на підставі Постанови КМ N 359 ( 359-2004-п ) від 23.03.2004 )

3. Пункт 8 викласти в такій редакції:

"8. Контроль за виконанням цієї постанови покласти на Віце-прем'єр-міністра України відповідно до розподілу обов'язків".
