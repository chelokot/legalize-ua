1. Указ Президента України від 28 жовтня 1996 року N 1005 ( 1005/96 ) "Про Міністерство України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи".

4. Указ Президента України від 26 листопада 2001 року N 1140 ( 1140/2001 ) "Про внесення змін до Положення про Міністерство України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи".
