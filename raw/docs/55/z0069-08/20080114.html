14.01.2008 N 2-1

Зареєстровано в Міністерстві юстиції України 30 січня 2008 р. за N 69/14760

Про внесення змін до постанови правління Пенсійного фонду України від 14.01.2005 N 1-1

Відповідно до Законів України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ) (із змінами), "Про збір на обов'язкове державне пенсійне страхування" ( 400/97-ВР ) (із змінами), "Про внесення змін до деяких законів України щодо оподаткування сільськогосподарських підприємств" ( 2287-15 ) правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Унести до постанови правління Пенсійного фонду України від 14.01.2005 N 1-1 ( za127-05 ) "Про затвердження Порядку компенсації Пенсійному фонду України різниці між сумою страхових внесків, сплачених за спеціальною ставкою платниками фіксованого сільськогосподарського податку, та страховими внесками, які були б сплачені при застосуванні ставки, визначеної в абзаці другому пункту 1 статті 4 Закону України "Про збір на обов'язкове державне пенсійне страхування", зареєстрованої у Міністерстві юстиції України 01.02.2005 за N 127/10407, такі зміни:

преамбулу викласти в такій редакції:

"На виконання Законів України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ), "Про збір на обов'язкове державне пенсійне страхування" ( 400/97-ВР ), "Про внесення змін до деяких законів України щодо оподаткування сільськогосподарських підприємств" ( 2287-15 ) та пункту 12 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 24.10.2007 N 1261 ( 1261-2007-п ), правління Пенсійного фонду України".

2. Унести до Порядку компенсації Пенсійному фонду України різниці між сумою страхових внесків, сплачених за спеціальною ставкою платниками фіксованого сільськогосподарського податку, та страховими внесками, які були б сплачені при застосуванні ставки, визначеної в абзаці другому пункту 1 статті 4 Закону України "Про збір на обов'язкове державне пенсійне страхування" ( z0127-05 ), затвердженого наказом Міністерства аграрної політики України від 14.01.2005 N 10 ( z0127-05 ) та постановою правління Пенсійного фонду України від 14.01.2005 N 1-1 ( za127-05 ) (далі - Порядок), такі зміни:

2.1. У пункті 1 Порядку ( z0127-05 ) слова та цифри "Про Державний бюджет України на 2007 рік" вилучити;

2.2. У назві графи 4 Таблиці Додатка 1 до пункту 4 Порядку ( z0127-05 ) цифри "13,28" замінити цифрами "19,92";

2.3. У рядку 2 Таблиці Додатка 2 до пункту 5 Порядку ( z0127-05 ) цифри "13,28" замінити цифрами "19,92";

2.4. У рядку 2 Таблиці Додатка 3 до пункту 5 Порядку ( z0127-05 ) цифри "13,28" замінити цифрами "19,92".

3. Департаменту надходження доходів (Литвиненко В.В.) та юридичному управлінню (Рябцева Т.Б.) подати цю постанову на державну реєстрацію до Міністерства юстиції України.
