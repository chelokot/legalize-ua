Кабінет Міністрів України; Розпорядження від 25.05.2011 № 446-р

Питання віднесення деяких посад працівників Адміністрації Президента України до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 446-2011-р

Текст документа від 20.08.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 травня 2011 р. N 446-р Київ

Питання віднесення деяких посад працівників Адміністрації Президента України до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Постановами КМ N 350 ( 350-2014-п ) від 13.08.2014 N 351 ( 351-2014-п ) від 13.08.2014 }

1. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Адміністрації Президента України до таких категорій посад державних службовців:

перша категорія - Прес-секретар Президента України, перший помічник Президента України; { Абзац другий пункту 1 в редакції Постанови КМ N 350 ( 350-2014-п ) від 13.08.2014 }

друга категорія - перший заступник керівника Головного департаменту, Служби Президента України, заступник керівника Головного департаменту (департаменту), Служби Президента України, Офісу Глави Адміністрації, Приймальні Президента України, заступник керівника Служби Президента України - керівник департаменту, керівник департаменту у складі Головного департаменту, Служби Президента України, заступник керівника департаменту у складі Головного департаменту, Служби Президента України, помічник Президента України - перший заступник керівника Служби Президента України, завідувач відділу у складі Головного департаменту (департаменту), Служби Президента України, Офісу Глави Адміністрації, Приймальні Президента України, заступник керівника Головного департаменту - керівник департаменту, заступник керівника департаменту - завідувач відділу, заступник керівника Приймальні Президента України - завідувач відділу, завідувач відділу - головний інспектор, уповноважений Президента України, радник Глави Адміністрації Президента України; { Абзац третій пункту 1 в редакції Постанови КМ N 351 ( 351-2014-п ) від 13.08.2014 }

третя категорія - заступник завідувача самостійного відділу, заступник завідувача відділу у складі Головного департаменту (департаменту), Приймальні Президента України, заступник завідувача відділу - завідувач сектору, помічники Глави Адміністрації, першого заступника, заступника Глави Адміністрації, референт, головний консультант, головний консультант - заступник головного інспектора, головний консультант - інспектор, старший консультант. { Абзац четвертий пункту 1 в редакції Постанови КМ N 351 ( 351-2014-п ) від 13.08.2014 }

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 2 червня 2010 р. N 1154 ( 1154-2010-р ) "Про віднесення посад працівників Адміністрації Президента України до відповідних категорій посад державних службовців" (Офіційний вісник України, 2010 р., N 42, ст. 1383);

пункт 2 змін, що вносяться до розпоряджень Кабінету Міністрів України від 10 листопада 1994 р. N 828 ( 828-94-р ) і від 2 червня 2010 р. N 1154 ( 1154-2010-р ), затверджених розпорядженням Кабінету Міністрів України від 2 вересня 2010 р. N 1766 ( 1766-2010-р ) "Питання віднесення деяких посад працівників Адміністрації Президента України до відповідних категорій посад державних службовців" (Офіційний вісник України, 2010 р., N 68, ст. 2470).
