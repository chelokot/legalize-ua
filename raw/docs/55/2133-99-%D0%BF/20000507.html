КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 листопада 1999 р. N 2133 Київ

( Постанова втратила чинність на підставі Постанов КМ N 776 ( 776-2000-п ) від 07.05.2000 )

Про додаткові заходи з паливозабезпечення теплових електростанцій

( Див. Постанову КМ N 905 ( 905-2000-п ) від 05.06.2000 )

З метою забезпечення сталого і надійного функціонування енергосистеми України шляхом залучення додаткових паливних ресурсів та збільшення виробничих потужностей теплових електростанцій Кабінет Міністрів України постановляє:

1. Міністерству енергетики, Міністерству промислової політики, обласним державним адміністраціям сприяти в проведенні розрахунків між енергогенеруючими компаніями, постачальниками імпортного вугілля та підприємствами - споживачами електроенергії продукцією зазначених підприємств, яка спрямовується на оплату імпортного вугілля, з віднесенням цих розрахунків підприємств - споживачів електроенергії на грошову оплату.

2. Доповнити перелік товарів критичного імпорту, затверджений постановою Кабінету Міністрів від 18 червня 1999 р. N 1080 ( 1080-99-п ) "Про перелік товарів критичного імпорту" (Офіційний вісник України, 1999 р., N 25, ст. 1167, N 27, ст. 1377), товаром за кодом згідно з ТН ЗЕД 2701 12900 (вугілля кам'яне інше).

3. Контроль за виконанням цієї постанови покласти на Першого віце-прем'єр-міністра України Кінаха А.К.
