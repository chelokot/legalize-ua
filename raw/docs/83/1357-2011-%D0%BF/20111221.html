Текст документа від 21.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 грудня 2011 р. N 1357 Київ

Про внесення змін до пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404

Кабінет Міністрів України постановляє:

Внести до пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752, N 51, ст. 3406; 2007 р., N 43, ст. 1715, N 53, ст. 2157, N 56, ст. 2252, N 59, ст. 2344, N 91, ст. 3336; 2008 р., N 9, ст. 220, N 63, ст. 2146, N 69, ст. 2322, N 81, ст. 2737, N 90, ст. 3004; 2009 р., N 5, ст. 128, N 52, ст. 1794, N 79, ст. 2679; 2010 р., N 39, ст. 1307, N 70, ст. 2529, N 91, ст. 3222; 2011 р., N 41, ст. 1693, N 47, ст. 1908, N 97, ст. 3533, ст. 3545, N 98, ст. 3574) - із змінами, внесеними постановою Кабінету Міністрів України від 21 грудня 2011 р. N 1334 ( 1334-2011-п ), такі зміни:

підпункт 1 доповнити абзацом такого змісту:

"лікарських засобів і виробів медичного призначення;";

абзац восьмий підпункту 2 виключити;

підпункт 5 доповнити абзацом такого змісту:

"обладнання для об'єкта "Будівництво сучасного лікувально-діагностичного комплексу Національної дитячої спеціалізованої лікарні "Охматдит" по вул. Чорновола, 28/1, у Шевченківському районі м. Києва;";

останній абзац пункту 1 після слів "палацу культури імені Г.І. Петровського у м. Донецьку" доповнити словами ", обладнання для об'єкта "Будівництво сучасного лікувально-діагностичного комплексу Національної дитячої спеціалізованої лікарні "Охматдит" по вул. Чорновола, 28/1, у Шевченківському районі м. Києва".
