Кабінет Міністрів України; Розпорядження від 03.03.1995 № 131-р

Про віднесення посад працівників апарату судів та арбітражних судів до категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 131-95-р

Текст документа від 24.02.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 березня 1995 p. N 131-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 88-р ( 88-2003-р ) від 24.02.2003 )

Про віднесення посад працівників апарату судів та арбітражних судів до категорій посад державних службовців

( Із змінами, внесеними згідно з Розпорядженнями КМ N 147-р ( 147-97-р ) від 19.03.97 N 560-р ( 560-97-р ) від 03.10.97 N 55-р ( 55-2002-р ) від 14.02.2002 )

( Розпорядження втратило чинність у частині віднесення до категорій посад державних службовців працівників апарату Конституційного Суду України на підставі Розпорядження КМ N 147-р ( 147-97-р ) від 19.03.97 )

( Розпорядження втратило чинність в частині віднесення до категорії посад державних службовців працівників апарату арбітражних судів України на підставі Розпорядження КМ N 55-р ( 55-2002-р ) від 14.02.2002 )

Відповідно до статей 9 та 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників апарату судів та арбітражних судів до таких категорій посад державних службовців:

друга категорія - посади помічників голів Конституційного Суду України, Верховного Суду України та радника голови Вищого арбітражного суду України, начальників управлінь та відділів Конституційного Суду України, Верховного Суду України та Вищого арбітражного суду України;

третя категорія - посади заступників начальників управлінь та відділів, начальників секретаріатів, головних консультантів, старших консультантів, консультантів Конституційного Суду України, Верховного Суду України та Вищого арбітражного суду України;

четверта категорія - посади спеціалістів Конституційного Суду України, Верховного Суду України та Вищого арбітражного суду України, відповідальних секретарів, секретарів судового засідання, секретарів судової колегії, Пленуму та Президії Верховного Суду України, Вищої кваліфікаційної комісії суддів України та Ради суддів України; помічників голів, старших консультантів, головного бухгалтера Верховного Суду Автономної Республіки Крим, обласних судів, міжобласного суду, Київського та Севастопольського міських судів, арбітражних судів Автономної Республіки Крим, областей, міст Києва і Севастополя, військових судів регіонів і Військово-Морських Сил;

п'ята категорія - посади консультантів, завідуючих приймальнею, старших судових виконавців, судових виконавців, старших секретарів судів, секретарів судів, секретарів судового засідання, секретарів судової колегії, судових розпорядників, перекладачів Верховного Суду Автономної Республіки Крим, обласних судів, міжобласного суду, Київського та Севастопольського міських судів, військових судів регіонів і Військово-Морських Сил;

шоста категорія - посади помічників голів, юрисконсультів, консультантів міжрайонних (окружних) судів, районних (міських) судів, військових судів гарнізонів;

сьома категорія - посади старших секретарів судів, секретарів судів, секретарів судового засідання, судових виконавців, судових розпорядників, перекладачів міжрайонних (окружних) судів, районних (міських) судів, військових судів гарнізонів.

( На доповнення до Розпорядження віднести посади працівників арбітражних судів до таких категорій посад державних службовців:

друга категорія - посада помічника Голови Вищого арбітражного суду України;

четверта категорія - посади начальників секретаріатів арбітражних колегій, відповідальних секретарів колегії і Пленуму, секретарів судового засідання, секретарів судової колегії Вищого арбітражного суду України; начальників відділів, їх заступників, радників арбітражних судів Автономної Республіки Крим, областей, міст Києва і Севастополя;

п'ята категорія - посади консультантів, завідуючих приймальнею, спеціалістів арбітражних судів Автономної Республіки Крим, областей, міст Києва і Севастополя - згідно з Розпорядженням КМ N 560-р ( 560-97-р ) від 03.10.97 )
