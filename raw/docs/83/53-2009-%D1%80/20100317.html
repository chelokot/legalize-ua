{ Розпорядження втратило чинність на підставі Розпорядження КМ N 489-р ( 489-2010-р ) від 17.03.2010 }

Деякі питання Фонду державного майна

Розпорядженням Кабінету Міністрів України від 6 лютого 2008 р. N 201 ( 201-2008-р ) першого заступника Голови Фонду державного майна Петрова В.М. звільнено із займаної посади у зв'язку з досягненням граничного віку перебування на державній службі. Дію зазначеного розпорядження ( 201-2008-р ) зупинено Указом Президента України від 25 квітня 2008 р. N 404 ( 404/2008 ). Ухвалою Конституційного Суду України від 17 вересня 2008 р. N 46-уп/2008 ( va46u710-08 ) припинено конституційне провадження у справі за конституційним поданням Президента України ( n0010100-08 ) щодо відповідності Конституції України ( 254к/96-ВР ) (конституційності), зокрема розпорядження Кабінету Міністрів України від 6 лютого 2008 р. N 201 ( 201-2008-р ), з огляду на непідвідомчість Конституційному Суду України питання, порушеного у конституційному поданні ( n0010100-08 ).

Постановою окружного адміністративного суду м. Києва від 26 червня 2008 р. Петрову В.М. у задоволенні позову про визнання незаконним розпорядження Кабінету Міністрів України ( 201-2008-р ) щодо його звільнення з посади відмовлено.

Ухвалою Київського апеляційного адміністративного суду від 23 січня 2009 р. (справа 22-а-30267/08) апеляційна скарга Петрова В.М. залишена без задоволення, а постанова окружного адміністративного суду м. Києва від 26 червня 2008 р. залишена без змін, тобто судом підтверджено законність прийнятого Кабінетом Міністрів України рішення ( 201-2008-р ).

Оскільки на момент прийняття відповідного судового рішення розпорядження Кабінету Міністрів України ( 201-2008-р ) про звільнення Петрова В.М. не було виконано, Київський апеляційний адміністративний суд окремою ухвалою постановив довести до відома Генерального прокурора України для вирішення питання про порушення проти винних осіб кримінальної справи за ознаками злочину, передбаченого статтею 365 Кримінального кодексу України ( 2341-14 ) (перевищення влади або службових повноважень), яке полягає в тому, що Петров В.М. не будучи державним службовцем з 2 лютого 2008 р. по 8 січня 2009 р. виконував з відома та за згодою Голови Фонду державного майна Семенюк-Самсоненко В.П. обов'язки першого заступника Голови цього Фонду.

З урахуванням викладеного та зважаючи на те, що постановою Верховної Ради України від 26 грудня 2008 р. N 832-VI ( 832-17 ) Семенюк-Самсоненко В.П. звільнено з посади Голови Фонду державного майна, з метою забезпечення керованості діяльністю Фонду, його регіональних відділень і представництв, виконання покладених на нього повноважень:

1. До прийняття Верховною Радою України відповідного рішення покласти виконання обов'язків Голови Фонду державного майна на заступника Голови Фонду Парфененка Дмитра Миколайовича.

2. Скасувати розпорядження Кабінету Міністрів України від 27 грудня 2008 р. N 1599 ( 1599-2008-р ).
