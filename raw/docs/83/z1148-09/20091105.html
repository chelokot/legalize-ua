05.11.2009 N 1135

Зареєстровано в Міністерстві юстиції України 30 листопада 2009 р. за N 1148/17164

Про затвердження Змін до деяких нормативно-правових актів Міністерства транспорту України, Міністерства транспорту та зв'язку України

Відповідно до пункту 4 Положення про Міністерство транспорту та зв'язку України, затвердженого постановою Кабінету Міністрів України від 06.06.2006 N 789 ( 789-2006-п ), та статті 5 Статуту залізниць України, затвердженого постановою Кабінету Міністрів України від 06.04.98 N 457 ( 457-98-п ), НАКАЗУЮ:

1. Затвердити Зміни до Правил приймання вантажів до перевезення, затверджених наказом Міністерства транспорту України від 21.11.2000 N 644 ( z0861-00 ), зареєстрованих у Міністерстві юстиції України 24.11.2000 за N 861/5082 (із змінами), що додаються.

2. Затвердити Зміни до Правил безпеки та порядку ліквідації наслідків аварійних ситуацій з небезпечними вантажами при перевезенні їх залізничним транспортом, затверджених наказом Міністерства транспорту України від 16.10.2000 N 567 ( z0857-00 ), зареєстрованих у Міністерстві юстиції України 23.11.2000 за N 857/5078 (із змінами), що додаються ( z1149-09 ).

3. Затвердити Зміни до Правил перевезення наливних вантажів, затверджених наказом Міністерства транспорту України від 18.04.2003 N 299 ( z0558-03 ), зареєстрованих у Міністерстві юстиції України 07.07.2003 за N 558/7879 (із змінами), що додаються ( z1150-09 ).

4. Затвердити Зміни до Правил перевезення небезпечних вантажів, затверджених наказом Міністерства транспорту та зв'язку України від 25.11.2008 N 1430 ( z0180-09 ), зареєстрованих у Міністерстві юстиції України 26.02.2009 за N 180/16196 (із змінами), що додаються ( z1151-09 ).

5. Державній адміністрації залізничного транспорту України (Костюк М.Д.):

5.1. Подати цей наказ до Міністерства юстиції України на державну реєстрацію в установленому порядку.

5.2. Довести цей наказ до відома залізниць, підприємств, установ та організацій, які користуються послугами залізничного транспорту.

6. Цей наказ набирає чинності з 01.01.2010.

7. Контроль за виконанням цього наказу покласти на заступника Міністра Бадагова В.Ф.
