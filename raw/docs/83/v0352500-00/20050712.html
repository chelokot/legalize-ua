Про впровадження пілотного проекту Національної системи масових електронних платежів

Стан: Втратив чинність

Ідентифікатор: v0352500-00

Текст документа від 12.07.2005:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 352 від 07.09.2000 м.Київ

Про впровадження пілотного проекту Національної системи масових електронних платежів

( Із змінами, внесеними згідно з Постановою Національного банку N 252 ( v0252500-05 ) від 12.07.2005 )

Відповідно до статей 40 та 41 Закону України "Про Національний банк України" ( 679-14 ) Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Розпочати впровадження пілотного проекту Національної системи масових електронних платежів (далі - НСМЕП) з III кварталу 2000 року в містах Києві, Харкові та Одесі.

2. Установити граничну кількість банків - учасників пілотного проекту НСМЕП - 10 та кількість емітованих платіжних карток - не більше ніж 100000 шт.

( Пункт 3 втратив чинність на підставі Постанови Національного банку N 252 ( v0252500-05 ) від 12.07.2005 )

4. Затвердити Тимчасові тарифи на послуги Національного банку України, що надаються банкам України в рамках упровадження пілотного проекту та експлуатації НСМЕП (додаток 2).

5. Раді НСМЕП у 10-денний строк з дати підписання цієї постанови:

визначити банки, що бажають взяти участь у впровадженні пілотного проекту НСМЕП, згідно з їх проханням;

затвердити тимчасові ліміти в рамках упровадження пілотного проекту та експлуатації НСМЕП;

затвердити розміри міжбанківських комісійних;

затвердити проект бухгалтерської моделі НСМЕП.

( Пункт 6 втратив чинність на підставі Постанови Національного банку N 252 ( v0252500-05 ) від 12.07.2005 )

7. Доручити виконувати функції:

Розрахункового банку за операціями з платіжними картками НСМЕП - Операційному управлінню Національного банку України (В.Д.Щуцький);

Головного процесингового центру НСМЕП - Центральній розрахунковій палаті Національного банку України (І.М.Коваль);

Регіонального процесингового центру НСМЕП в Харківському регіоні - Харківському обласному управлінню Національного банку України (В.В.Качук);

( Абзац п'ятий пункту 7 втратив чинність на підставі Постанови Національного банку N 252 ( v0252500-05 ) від 12.07.2005 )

8. Департаменту інформатизації (А.С.Савченко) укласти відповідний договір з ТОВ "Аверс-процесинг", згідно з яким на ТОВ "Аверс-процесинг" покладаються функції регіонального процесингового центру НСМЕП в Одеському регіоні.

9. Фінансовому департаменту (О.М.Кандибка) забезпечити:

фінансування робіт, пов'язаних з упровадженням та функціонуванням пілотного проекту НСМЕП у межах кошторису на 2000 рік;

можливість повторного використання коштів, що повертаються за використані чіп-модулі від виробника (виробників) пластикових карток, для подальшої купівлі чіп-модулів для НСМЕП.

10. Територіальним управлінням Національного банку України сприяти впровадженню пілотного проекту НСМЕП, проводити роз'яснювальну роботу серед банків, місцевих органів влади, підприємств, населення.

11. Департаменту інформатизації (А.С.Савченко) довести цю постанову до відома керівників територіальних управлінь Національного банку України та комерційних банків для використання в роботі.

12. Контроль за виконанням цієї постанови покласти на заступника Голови Національного банку України Сенища П.М.

Голова В.С.Стельмах

( Додаток 1 втратив чинність на підставі Постанови Національного банку N 252 ( v0252500-05 ) від 12.07.2005 )
