Президент України; Указ від 20.05.2008 № 462/2008

Про зупинення дії розпорядження Кабінету Міністрів України від 16 травня 2008 року N 717-р

Стан: Втратив чинність

Ідентифікатор: 462/2008

Текст документа від 20.05.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії розпорядження Кабінету Міністрів України від 16 травня 2008 року N 717-р

{ Додатково див. Конституційне подання Президента ( n0015100-08 ) від 20.05.2008 }

Кабінетом Міністрів України 16 травня 2008 року видано розпорядження N 717-р ( 717-2008-р ) "Про здійснення Кабінетом Міністрів України повноважень з управління державними корпоративними правами", яким повноваження з управління державними корпоративними правами відкритих акціонерних товариств "Одеський припортовий завод", "Київський завод реле та автоматики", "Київський мотоциклетний завод", "Турбоатом", "Завод "Маяк", "Феодосійська суднобудівна компанія "Море", "Науково-виробничий комплекс "Київський завод автоматики імені Г.І. Петровського", "Науково-дослідний інститут електромеханічних приладів", "Укртелеком", "Меридіан" імені С.П. Корольова" та Державної акціонерної компанії "Україна туристична" покладено на Кабінет Міністрів України.

Розпорядження від 16 травня 2008 року ( 717-2008-р ) видано Урядом України з перевищенням наданих йому повноважень, усупереч вимозі пункту 5 статті 116 Конституції України ( 254к/96-ВР ), яка зобов'язує його здійснювати управління об'єктами державної власності відповідно до закону.

Правові основи управління об'єктами державної власності визначені Законом України "Про управління об'єктами державної власності" ( 185-16 ).

Цим Законом ( 185-16 ) до повноважень Кабінету Міністрів України з управління корпоративними правами, що належать державі у статутних фондах господарських організацій, віднесено визначення порядку призначення уповноваженої особи на виконання функцій з управління корпоративними правами держави, порядку управління корпоративними правами держави та виплати винагороди уповноваженим особам за належне виконання ними функцій з управління корпоративними правами держави; прийняття за поданням Фонду державного майна України рішення про передачу повноважень з управління корпоративними правами держави уповноваженим органам управління та господарським структурам (пункти 3, 13 і 14 частини другої статті 5 Закону) ( 185-16 ).

Функції з управління корпоративними правами держави виконуються Кабінетом Міністрів України відповідно до цього Закону ( 185-16 ) безпосередньо, без скликання зборів акціонерів, у разі, якщо корпоративні права держави становлять 100 відсотків у статутному фонді господарської організації (частина четверта статті 11) ( 185-16 ). Однак у статутних фондах відкритих акціонерних товариств "Одеський припортовий завод", "Київський завод реле та автоматики", "Турбоатом", "Науково-виробничий комплекс "Київський завод автоматики імені Г.І. Петровського", "Науково-дослідний інститут електромеханічних приладів", "Укртелеком", "Меридіан" імені С.П. Корольова", зазначених у розпорядженні N 717-р ( 717-2008-р ), державна частка становить менше ніж 100 відсотків.

У таких випадках Законом ( 185-16 ) безпосереднє здійснення управління корпоративними правами держави (у порядку, встановленому Кабінетом Міністрів України) покладено на міністерства та інші органи виконавчої влади, Фонд державного майна України, державні господарські організації, уповноважених осіб (статті 6, 7, 9, 10) ( 185-16 ).

Відтак, розпорядження Кабінету Міністрів України від 16 травня 2008 року N 717-р ( 717-2008-р ) не відповідає також частині другій статті 8 Конституції України ( 254к/96-ВР ), якою встановлено, що нормативно-правові акти приймаються на основі Конституції України ( 254к/96-ВР ) і повинні відповідати їй, частині другій статті 6, частині другій статті 19 та частині третій статті 113 Основного Закону України ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватись у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, діяти на підставі та у спосіб, що ними передбачені.

Ураховуючи наведене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 16 травня 2008 року N 717-р ( 717-2008-р ) "Про здійснення Кабінетом Міністрів України повноважень з управління державними корпоративними правами".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
