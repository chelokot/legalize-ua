Кабінет Міністрів України; Постанова, Порядок від 07.03.2007 № 412

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки творчих спілок у сфері засобів масової інформації

Стан: Чинний

Ідентифікатор: 412-2007-п

Текст документа від 05.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 березня 2007 р. N 412 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки творчих спілок у сфері засобів масової інформації

{ Із змінами, внесеними згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) за програмою "Фінансова підтримка творчих спілок у сфері засобів масової інформації", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки творчих спілок у сфері засобів масової інформації, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 51

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 березня 2007 р. N 412

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки творчих спілок у сфері засобів масової інформації

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Держкомтелерадіо за програмою "Фінансова підтримка творчих спілок у сфері засобів масової інформації" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Держкомтелерадіо, а їх одержувачами - Національна спілка журналістів та її територіальні організації.

3. Бюджетні кошти спрямовуються їх одержувачам і використовуються для підтримки територіальних організацій Національної спілки журналістів у виконанні їх статутних завдань, а саме для сприяння розвитку журналістики, популяризації кращих творчих надбань в галузі журналістики, захисту соціальних, економічних, творчих інтересів журналістів, надання допомоги у підвищенні кваліфікації журналістів, організації творчих конкурсів, виставок, авторських вечорів, прем'єр, фестивалів тощо.

Видатки одержувачі бюджетних коштів здійснюють на підставі плану використання цих коштів, затвердженого в установленому законодавством порядку.

4. Бюджетні кошти використовуються Держкомтелерадіо у межах бюджетних асигнувань, визначених кошторисом, з урахуванням необхідності виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державного казначейства, у разі їх відповідності паспортові бюджетної програми та напрямам, визначеним планом використання бюджетних коштів.

5. Операції, пов'язані з обслуговуванням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 6 виключено на підставі Постанови КМ N 127 ( 127-2008-п ) від 05.03.2008 }

7. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
