ДЕРЖАВНИЙ КОМІТЕТ ЗВ'ЯЗКУ ТА ІНФОРМАТИЗАЦІЇ УКРАЇНИ

НАКАЗ

20.08.2003 N 152

Зареєстровано в Міністерстві юстиції України 29 серпня 2003 за N 747/8068

Про встановлення одиниць обліку часу телефонних розмов та телеграфних повідомлень

На виконання Закону України "Про внесення зміни до статті 12 Закону України "Про зв'язок" від 20 лютого 2003 року N 556-IV ( 556-15 ) щодо проведення розрахунків зі споживачами лише за повні тарифні одиниці часу НАКАЗУЮ:

1. Встановити з 21.09.2003 з урахуванням технічних можливостей обладнання місцевих, міжміських, міжнародних телефонних мереж, телеграфних мереж абонентського телеграфування та телекса (далі - АТ/ТХ) для тарифікації такі одиниці обліку часу телефонних розмов та телеграфних повідомлень:

- для місцевого, автоматичного міжміського та міжнародного телефонного зв'язку, крім послуг, що надаються з таксофонів, - одна секунда;

- для міжміського та міжнародного телефонного зв'язку за попереднім замовленням - одна хвилина;

- для розмов з таксофонів - 15 сек; для монетних таксофонів - відповідно до номіналу монет, що були використані;

- на телеграфній мережі АТ/ТХ для з'єднання в межах України - 5 секунд, для міжнародного з'єднання, включаючи країни СНД, - одна секунда.

2. При наданні послуг місцевого телефонного зв'язку з почасовою оплатою місцевих розмов облік проводиться за накопичувальною системою протягом розрахункового періоду з 21.09.2003.

3. УЕП підготувати зміни до Граничних тарифів на основні послуги електрозв'язку та тарифів на виплату державних пенсій та грошової допомоги, затверджених наказом Держкомзв'язку України від 07.06.2002 N 120 ( z0595-02 ) та зареєстрованих у Міністерстві юстиції України 19 липня 2002 року за N 595/6883.

4. УСНТП підготувати зміни у відповідну нормативно-правову базу галузі.

5. Операторам зв'язку здійснити організаційні та технічні заходи щодо забезпечення виконання Закону України "Про внесення зміни до статті 12 Закону України "Про зв'язок" ( 556-15 ) та цього наказу до 21.09.2003.

6. Контроль за виконанням наказу покласти на заступника Голови О.П.Проживальського.

В.о. Голови Л.І.Нетудихата
