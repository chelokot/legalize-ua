Про терміни впровадження електронних контрольно-касових апаратів у підприємствах сфери торгівлі, громадського харчування та послуг

Текст документа від 20.12.2017:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 січня 1994 р. N 14 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 987 ( 987-2017-п ) від 18.12.2017 }

Про терміни впровадження електронних контрольно-касових апаратів у підприємствах сфери торгівлі, громадського харчування та послуг

( Із змінами, внесеними згідно з Постановою КМ N 79 ( 79-96-п ) від 16.01.96 )

( Додатково див. Постанову КМ N 442 ( 442-97-п ) від 12.05.97 )

( Із змінами, внесеними згідно з Постановою КМ N 189 ( 189-98-п ) від 18.02.98 )

З метою вдосконалення механізму виконання державного, республіканського (Республіки Крим) і місцевих бюджетів, посилення захисту прав споживачів, прискорення виконання завдань Концепції поетапного виробництва і впровадження контрольно-касових апаратів у підприємствах торгівлі, громадського харчування та послуг, затвердженої постановою Кабінету Міністрів України від 28 жовтня 1993 р. N 893 ( 893-93-п ), Кабінет Міністрів України постановляє:

1. Раді Міністрів Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям забезпечити запровадження порядку розрахунків із споживачами у підприємствах сфери торгівлі, громадського харчування та послуг за готівку через електронні контрольно-касові апарати з обов'язковою видачею касового чека у терміни згідно з додатками N 1 - 3.

2. Київському науково-виробничому об'єднанню "Електронмаш" забезпечити своєчасне виготовлення та реалізацію електронних контрольно-касових апаратів, їх гарантійне і сервісне обслуговування.

3. Перелік окремих форм діяльності у сфері торгівлі, громадського харчування та послуг, специфіка яких дозволяє здійснювати розрахунки із споживачами без застосування електронних контрольно-касових апартів з використанням товарно-касових книг, затверджується Міністерством економіки за погодженням з Міністерством зовнішніх економічних зв'язків і Міністерством фінансів.
