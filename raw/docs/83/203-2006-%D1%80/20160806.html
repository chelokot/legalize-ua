Про забезпечення діяльності секретаріату Національної тристоронньої соціально-економічної ради

Стан: Чинний

Ідентифікатор: 203-2006-р

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 квітня 2006 р. N 203-р Київ

Про забезпечення діяльності секретаріату Національної тристоронньої соціально-економічної ради

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 520-р ( 520-2006-р ) від 18.10.2006 N 501-р ( 501-2013-р ) від 11.07.2013 Постановою КМ N 465 ( 465-2016-п ) від 22.07.2016 }

1. Установити, що фінансове забезпечення діяльності секретаріату Національної тристоронньої соціально-економічної ради у 2006 році здійснюється в межах видатків, передбачених у Законі України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Національній службі посередництва і примирення України на сприяння врегулюванню колективних трудових спорів (конфліктів).

1-1. Секретаріату Національної ради соціального партнерства, що ліквідується, передати в установленому порядку кошти та матеріальні цінності секретаріату Національної тристоронньої соціально-економічної ради.

{ Розпорядження доповнено пунктом 1-1 згідно з Розпорядженням КМ N 520-р ( 520-2006-р ) від 18.10.2006 }

1-2. Взяти до відома, що секретаріат Національної тристоронньої соціально-економічної ради розташований у приміщеннях будинку ВАТ "Український зональний науково-дослідний і проектний інститут по цивільному будівництву" загальною площею 141,4 кв. метра по бульв. Лесі Українки, 26, у м. Києві на умовах оренди.

{ Розпорядження доповнено пунктом 1-2 згідно з Розпорядженням КМ N 520-р ( 520-2006-р ) від 18.10.2006 }

{ Пункт 2 втратив чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

3. Установити, що соціально-побутове забезпечення, медичне та транспортне обслуговування керівника і заступника керівника секретаріату Національної тристоронньої соціально-економічної ради здійснюється на рівні відповідно керівника та заступника урядового органу державного управління.

4. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 29 квітня 1994 р. N 303 ( 303-94-р ).
