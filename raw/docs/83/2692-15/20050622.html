Верховна Рада України; Постанова від 22.06.2005 № 2692-IV

Про порядок розгляду законопроектів, що стосуються виборів народних депутатів України

Стан: Чинний

Ідентифікатор: 2692-15

Текст документа від 22.06.2005:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про порядок розгляду законопроектів, що стосуються виборів народних депутатів України

Відповідно до частини третьої статті 3.2.3 Регламенту Верховної Ради України ( 129а/94-ВР ) Верховна Рада України постановляє:

I. Провести розгляд законопроектів, що стосуються виборів народних депутатів України, на пленарному засіданні Верховної Ради України 22 червня 2005 року в порядку, визначеному Регламентом Верховної Ради України ( 129а/94-ВР, 129б/94-ВР ), з такими особливостями:

1. Відхилити як такі, що суттєво змінюють виборчу систему або якими пропонується змінити "прохідний бар'єр" для партій (блоків), що беруть участь у розподілі депутатських мандатів, законопроекти:

реєстр. N 6259, внесений народними депутатами України Губським Б.В., Гуровим В.М., Демьохіним В.А., Климпушем О.Д. та іншими;

реєстр. N 6531, внесений народним депутатом України Горбачовим В.С.;

реєстр. N 6531-1, внесений народним депутатом України Гавришем С.Б.;

реєстр. N 7428, внесений народним депутатом України Миримським Л.Ю.

2. Відхилити як такі, що втратили актуальність, законопроекти:

реєстр. N 5605, внесений народними депутатами України Білозір О.В., Томенком М.В., Богатирьовою Р.В.;

реєстр. N 6273, внесений народними депутатами України Козаченком О.О., Шкляром В.Б., Бондарчуком С.В., Мусіякою В.Л. та іншими;

реєстр. N 6351, внесений народним депутатом України Черновецьким Л.М.;

реєстр. N 6368, внесений народним депутатом України Терьохіним С.А.;

реєстр. N 7008, внесений народними депутатами України Ключковським Ю.Б., Пинзеником В.М.;

реєстр. N 7008-1, внесений народним депутатом України Кармазіним Ю.А.;

реєстр. N 7008-2, внесений народним депутатом України Качуром П.С.;

реєстр. N 7011, внесений народним депутатом України Мішурою В.Д.;

реєстр. N 7575, внесений народними депутатами України Кеменяшем О.М., Ширком Ю.В.

3. Для розгляду проекту Закону України про внесення змін до Закону України "Про вибори народних депутатів України" (реєстр. N 6531-2), внесеного народними депутатами України Ключковським Ю.Б., Зарубінським О.О., Оніщуком М.В., Пономаренком Г.Г., Мокроусовим А.О., відвести:

для доповіді автору законопроекту - до 10 хвилин;

для відповідей на запитання доповідачу - до 5 хвилин;

для виступів керівників депутатських фракцій і груп у

Верховній Раді України - до 3 хвилин кожному виступаючому.

II. Ця Постанова набирає чинності з моменту її прийняття.
