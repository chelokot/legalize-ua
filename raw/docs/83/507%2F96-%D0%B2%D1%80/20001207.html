Текст документа від 07.12.2000:

ЗАКОН УКРАЇНИ

( Закон втратив чинність на підставі Закону N 2121-III ( 2121-14 ) від 07.12.2000, ВВР, 2001, N 5-6, ст.30 )

Про внесення доповнення до статті 21 Закону України "Про банки і банківську діяльність"

( Відомості Верховної Ради України (ВВР), 1997, N 3, ст. 7 )

Верховна Рада України постановляє:

Статтю 21 Закону України "Про банки і банківську діяльність" ( 872-12 ) (Відомості Верховної Ради УРСР, 1991 р., N 25, ст.281; Відомості Верховної Ради України, 1993 р., N 10, ст.76, N 26, ст.277; 1996 р., N 3, ст.11) доповнити словами: "крім сплати ввізного мита, митних та акцизних зборів і податку на добавлену вартість при імпорті товарів (послуг)".
