{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 228 ( z0759-06 ) від 19.06.2006 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 12.01.2004 N 5

На виконання постанови Кабінету Міністрів України від 15 січня 2005 року N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ :

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 12.01.2004 N 5 ( z0127-04 ) "Про умови оплати праці працівників апарату Центральної, Кримської республіканської рад, обласних, Київської і Севастопольської міських, міських, районних і районних у містах організацій фізкультурно-спортивного товариства "Спартак", зареєстрованого в Міністерстві юстиції України 29.01.2004 за N 127/8726, виклавши додатки 1-5 у новій редакції (додаються).

2. Ці зміни застосовуються з 1 січня 2005 року.

В.о. Міністра М.Папієв
