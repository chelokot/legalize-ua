Верховна Рада України; Постанова від 21.09.2006 № 179-V

Про "День Уряду України" у грудні 2006 року (з порядком денним "Про захист прав онкологічних хворих в Україні та виконання державної програми "Онкологія")

Стан: Втратив чинність

Ідентифікатор: 179-16

Текст документа від 23.02.2007:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

{ Постанова втратила чинність на підставі Постанови ВР N 715-V ( 715-16 ) від 23.02.2007, ВВР, 2007, N 16, ст.235 }

Про "День Уряду України" у грудні 2006 року (з порядком денним "Про захист прав онкологічних хворих в Україні та виконання державної програми "Онкологія")

( Відомості Верховної Ради України (ВВР), 2006, N 43, ст.429 )

{ Із змінами, внесеними згідно з Постановою ВР N 267-V ( 267-16 ) від 19.10.2006, ВВР, 2006, N 50, ст.505 }

Верховна Рада України постановляє:

1. Провести 6 грудня 2006 року в Комітеті Верховної Ради України з питань охорони здоров'я слухання з порядком денним "Про захист прав онкологічних хворих в Україні та виконання Державної програми "Онкологія" на 2002-2006 роки ( 392-2002-п ).

{ Пункт 1 в редакції Постанови ВР N 267-V ( 267-16 ) від 19.10.2006 }

2. Провести в березні 2007 року у Верховній Раді України "День Уряду України" з порядком денним "Про захист прав онкологічних хворих в Україні та виконання Державної програми "Онкологія" на 2002-2006 роки ( 392-2002-п ).

{ Пункт 2 в редакції Постанови ВР N 267-V ( 267-16 ) від 19.10.2006 }

3. Кабінету Міністрів України визначити доповідачів, підготувати необхідні аналітичні та довідкові матеріали із зазначеного питання, у тому числі щодо внесення відповідних змін до законодавства, і не пізніш як за п'ять днів до проведення "Дня Уряду України" надати ці матеріали відповідним комітетам Верховної Ради України, народним депутатам України".

{ Пункт 3 в редакції Постанови ВР N 267-V ( 267-16 ) від 19.10.2006 }

4. Комітетам Верховної Ради України з питань охорони здоров'я, з питань соціальної політики та праці, з питань прав людини, національних меншин і міжнаціональних відносин, у справах пенсіонерів, ветеранів та інвалідів здійснити необхідні заходи щодо організації та методичного забезпечення проведення "Дня Уряду України.

{ Постанову доповнено пунктом 4 згідно з Постановою ВР N 267-V ( 267-16 ) від 19.10.2006 }
