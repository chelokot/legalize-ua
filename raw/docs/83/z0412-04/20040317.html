ДЕРЖАВНИЙ КОМІТЕТ ЗВ'ЯЗКУ ТА ІНФОРМАТИЗАЦІЇ УКРАЇНИ

НАКАЗ

17.03.2004 N 50

Зареєстровано в Міністерстві юстиції України 2 квітня 2004 р. за N 412/9011

Про встановлення одиниць обліку часу телефонних розмов абонентів стаціонарної телефонної мережі з абонентами мереж операторів стільникового рухомого зв'язку

На виконання п. 3 статті 39 Закону України "Про телекомунікації" ( 1280-15 ) щодо врахування лише повної тарифної одиниці часу при розрахунках із споживачами НАКАЗУЮ:

1. Установити для тарифікації телефонних розмов абонентів стаціонарної телефонної мережі з абонентами мереж операторів стільникового рухомого зв'язку (за кодами мереж операторів стільникового рухомого зв'язку) з урахуванням технічних можливостей обладнання такі одиниці обліку часу:

для автоматичного доступу - одна секунда;

за попереднім замовленням - одна хвилина.

2. Установити мінімальну тривалість розмови, яка дорівнює визначеній одиниці обліку часу, для тарифікації телефонних розмов абонентів стаціонарної телефонної мережі загального користування з абонентами мереж операторів стільникового рухомого зв'язку (за кодами мереж операторів стільникового рухомого зв'язку) за попереднім замовленням.

3. Скасувати наказ Державного комітету зв'язку України від 01.12.2003 N 240 "Про встановлення одиниць обліку часу телефонних розмов абонентів стаціонарної телефонної мережі з абонентами мереж операторів стільникового рухомого зв'язку".

4. Контроль за виконанням наказу покласти на заступника Голови Проживальського О.П.
