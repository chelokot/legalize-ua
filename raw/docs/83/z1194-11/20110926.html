Зареєстровано в Міністерстві юстиції України 17 жовтня 2011 р. за N 1194/19932

Про внесення змін до наказу МНС України від 19.06.2003 N 201

Відповідно до вимог статті 11 Закону України "Про аварійно-рятувальні служби" ( 1281-14 ) та Положення про Міністерство надзвичайних ситуацій України, затвердженого Указом Президента України від 06.04.2011 N 402 ( 402/2011 ), з метою приведення власних нормативно-правових актів у відповідність до чинного законодавства НАКАЗУЮ:

1. У преамбулі наказу МНС України від 19.06.2003 N 201 ( z0640-03 ) "Про затвердження Порядку атестації аварійно-рятувальних служб та рятувальників", зареєстрованого в Міністерстві юстиції України 24.07.2003 за N 640/7961, слова та цифри "Положення про Міністерство України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, затвердженого постановою Кабінету Міністрів України від 02.11.2006 N 1539" замінити словами та цифрами "Положення про Міністерство надзвичайних ситуацій України, затвердженого Указом Президента України від 06.04.2011 N 402 ( 402/2011 )".

2. Внести до Порядку атестації аварійно-рятувальних служб та рятувальників, затвердженого наказом МНС України від 19.06.2003 N 201 ( z0640-03 ), зареєстрованого в Міністерстві юстиції України 24.07.2003 за N 640/7961, такі зміни:

2.1. У главі 1:

пункт 1.1 викласти в такій редакції:

"1.1. Цей Порядок розроблено відповідно до вимог статті 11 Закону України "Про аварійно-рятувальні служби" ( 1281-14 ) та Положення про Міністерство надзвичайних ситуацій України, затвердженого Указом Президента України від 06.04.2011 N 402 ( 402/2011 )".

2.2. У главі 2:

2.2.1. У пункті 2.3 слова "Міністр України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" замінити словами "Міністр надзвичайних ситуацій України";

2.2.2. В абзаці другому пункту 2.14 слова "Державна спеціалізована аварійно-рятувальна служба на водних об'єктах України МНС (далі - ДСАРСВО)" замінити словами "Департамент управління рятувальними силами МНС України".

2.3. У главі 3:

2.3.1. В абзацах першому та третьому пункту 3.5 абревіатуру "ДСАРСВО" замінити словами "Департамент управління рятувальними силами МНС України";

2.3.2. У пункті 3.10 слова "Департамент сил цивільного захисту МНС України" замінити словами "Департамент управління рятувальними силами МНС України".

2.4. У тексті Порядку ( z0640-03 ) слова "Державну інспекцію цивільного захисту та техногенної безпеки" у всіх відмінках замінити словами "Державну інспекцію техногенної безпеки України" у відповідних відмінках.

2.5. У тексті Порядку ( z0640-03 ) слова "Міністерство України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" у всіх відмінках замінити словами "Міністерство надзвичайних ситуацій України" у відповідних відмінках.

3. Директору Департаменту управління рятувальними силами (Марченко Г.Б.), начальнику Управління правового забезпечення (Поворозник Р.Р.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Цей наказ набирає чинності з дня його офіційного опублікування.

5. Контроль за виконанням цього наказу покласти на заступника Міністра Бута В.П.

Міністр В.Балога
