Президент України; Указ від 14.08.2008 № 711/2008

Про зупинення дії постанови Кабінету Міністрів України від 30 липня 2008 року N 692

Стан: Втратив чинність

Ідентифікатор: 711/2008

Текст документа від 14.08.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанови Кабінету Міністрів України від 30 липня 2008 року N 692

{ Додатково див. Конституційне подання Президента ( n0029100-08 ) від 14.08.2008 }

Кабінетом Міністрів України 30 липня 2008 року видано постанову N 692 ( 692-2008-п ) "Деякі питання державного управління у сфері міграційної політики".

Названим актом Кабінету Міністрів України ( 692-2008-п ):

перейменовано Державний департамент у справах громадянства, імміграції та реєстрації фізичних осіб у Державний департамент міграційної служби (пункт 1) ( 692-2008-п );

на Міністерство внутрішніх справ України покладено виконання завдань з реалізації державної політики у сфері міграції (пункт 2) ( 692-2008-п );

до сфери управління Міністерства внутрішніх справ України передано пункти тимчасового розміщення біженців, до складу головних управлінь, управлінь зазначеного Міністерства в Автономній Республіці Крим, областях, містах Києві та Севастополі - органи міграційної служби в Автономній Республіці Крим, областях, містах Києві та Севастополі (пункт 3) ( 692-2008-п ), а також доручено здійснити пов'язані з цим відповідні заходи (пункти 4, 5) ( 692-2008-п ).

Постанову N 692 ( 692-2008-п ) видано Кабінетом Міністрів України всупереч положенням Конституції України ( 254к/96-ВР ).

Згідно з частиною третьою статті 17 Конституції України ( 254к/96-ВР ) організація і порядок діяльності відповідних військових формувань та правоохоронних органів держави, що забезпечують державну безпеку і захист державного кордону України, визначаються законом. За приписом пункту 22 частини першої статті 85 Основного Закону ( 254к/96-ВР ) держави визначення функцій Міністерства внутрішніх справ України належить до повноважень Верховної Ради України. Пункт 10 частини першої статті 92 Конституції України ( 254к/96-ВР ) передбачає, що засади регулювання міграційних процесів визначаються виключно законами України.

Усупереч наведеним конституційним положенням Кабінет Міністрів України своєю постановою ( 692-2008-п ) вирішив питання щодо покладення завдань із реалізації державної політики у сфері міграції на Міністерство внутрішніх справ України, тим самим поза межами повноважень і з порушенням порядку, що встановлені згаданими конституційними нормами, визначив функції Міністерства внутрішніх справ України, змінив законодавчо визначені засади функціонування органів міграційної служби.

Статтею 6 Закону України "Про біженців" ( 2557-14 ) установлено, що створення та утримання пунктів тимчасового розміщення біженців належить до компетенції спеціально уповноваженого центрального органу виконавчої влади у справах міграції. За цим же Законом ( 2557-14 ) органи міграційної служби в Автономній Республіці Крим, областях, містах Києві та Севастополі підпорядковуються спеціально уповноваженому центральному органу виконавчої влади у справах міграції (стаття 7) ( 2557-14 ).

Відтак, видавши постанову N 692 ( 692-2008-п ), Кабінет Міністрів України вирішив питання, віднесені Конституцією України ( 254к/96-ВР ) до повноважень Верховної Ради України, врегулював підзаконним актом питання, які за Основним Законом ( 254к/96-ВР ) держави визначаються виключно законами України, чим порушив вищезазначені норми Конституції України ( 254к/96-ВР ), а також вимоги частини третьої статті 113, частини першої статті 117 Основного Закону ( 254к/96-ВР ) держави, які зобов'язують Кабінет Міністрів України керуватись у своїй діяльності, зокрема, Конституцією України ( 254к/96-ВР ), видавати постанови і розпорядження в межах своєї компетенції.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 30 липня 2008 року N 692 ( 692-2008-п ) "Деякі питання державного управління у сфері міграційної політики", крім пункту 6.

2. Визнати таким, що втратив чинність, Указ Президента України від 21 липня 2008 року N 643 ( 643/2008 ) "Про зупинення дії постанови Кабінету Міністрів України від 18 червня 2008 року N 558".

3. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
