ДЕРЖАВНА КОМІСІЯ З РЕГУЛЮВАННЯ РИНКІВ ФІНАНСОВИХ ПОСЛУГ УКРАЇНИ

РОЗПОРЯДЖЕННЯ

31.03.2011 N 170

Зареєстровано в Міністерстві юстиції України 19 квітня 2011 р. за N 484/19222

Про внесення змін до деяких нормативно-правових актів Державної комісії з регулювання ринків фінансових послуг України

{ Із змінами, внесеними згідно з Розпорядженням Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг

N 4368 ( z2161-13 ) від 28.11.2013 }

Відповідно до пункту 1 частини першої статті 28 Закону України "Про фінансові послуги та державне регулювання ринків фінансових послуг" ( 2664-14 ) та з метою приведення нормативно-правових актів Держфінпослуг у відповідність до Цивільного кодексу України ( 435-15 ) та Закону України "Про фінансові послуги та державне регулювання ринків фінансових послуг" Державна комісія з регулювання ринків фінансових послуг України ПОСТАНОВИЛА:

{ Пункт 1 втратив чинність на підставі Розпорядження Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 4368 ( z2161-13 ) від 28.11.2013 }

{ Пункт 2 втратив чинність на підставі Розпорядження Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 4368 ( z2161-13 ) від 28.11.2013 }

{ Пункт 3 втратив чинність на підставі Розпорядження Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 4368 ( z2161-13 ) від 28.11.2013 }

4. Департаменту юридичного забезпечення забезпечити подання цього розпорядження до Міністерства юстиції України для державної реєстрації.

5. Відділу зв'язків з державними органами, громадськістю та протоколу департаменту організаційно-аналітичного, документального та кадрового забезпечення забезпечити розміщення цього розпорядження на офіційному сайті Держфінпослуг в мережі Інтернет після його державної реєстрації.

6. Це розпорядження набирає чинності з дня його офіційного опублікування.

7. Контроль за виконанням цього розпорядження покласти на заступника Голови відповідно до розподілу обов'язків.
