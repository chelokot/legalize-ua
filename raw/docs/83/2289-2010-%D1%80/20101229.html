Про перерозподіл деяких бюджетних призначень, передбачених Міністерству фінансів на 2010 рік

Стан: Чинний

Ідентифікатор: 2289-2010-р

Текст документа від 29.12.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 грудня 2010 р. N 2289-р Київ

Про перерозподіл деяких бюджетних призначень, передбачених Міністерству фінансів на 2010 рік

{ Із змінами, внесеними згідно з Постановою КМ N 1184 ( 1184-2010-п ) від 27.12.2010 }

Відповідно до частини другої статті 26 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) здійснити перерозподіл бюджетних призначень загального фонду державного бюджету, передбачених Міністерству фінансів за програмою 3511190 "Субвенція з державного бюджету місцевим бюджетам на здійснення заходів щодо соціально-економічного розвитку регіонів", у межах їх загального обсягу в сумі 17138,35 тис. гривень шляхом зменшення обсягу видатків споживання та збільшення обсягу видатків розвитку. { Абзац перший із змінами, внесеними згідно з Постановою КМ N 1184 ( 1184-2010-п ) від 27.12.2010 }

Міністерству фінансів внести відповідні зміни до розпису державного бюджету ( 2154-17 ).

Прем'єр-міністр України М.АЗАРОВ
