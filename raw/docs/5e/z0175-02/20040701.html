ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 56 від 08.02.2002 Зареєстровано в Міністерстві м.Київ юстиції України 22 лютого 2002 р. за N 175/6463

( Постанова втратила чинність на підставі Постанови Національного банку N 172 ( z0595-04 ) від 21.04.2004 )

Про внесення змін до Положення про порядок формування обов'язкових резервів для банків України

У зв'язку з унесенням змін до Плану рахунків бухгалтерського обліку комерційних банків ( va493500-97 ) (затверджений постановою Правління Національного банку України від 21.11.97 N 388 ( v0493500-97 ), зі змінами), затверджених постановами Правління Національного банку України від 10.01.2002 N 11 ( z0022-02 ) (зареєстровані в Міністерстві юстиції України 10.01.2002 за N 22/6310) та від 29.01.2002 N 43 ( z0079-02 ) (зареєстровані в Міністерстві юстиції України 30.01.2002 за N 79/6367), що стосуються забезпечення бухгалтерського обліку коштів виборчих фондів, та з метою систематизації вимог щодо виконання банками нормативу обов'язкового резервування Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Унести до Положення про порядок формування обов'язкових резервів для банків України, затвердженого постановою Правління Національного банку України від 27.06.2001 N 244 ( z0586-01 ) та зареєстрованого в Міністерстві юстиції України 11.07.2001 за N 586/5777, такі зміни:

1.1. У главі 1:

у пунктах 1.2 та 1.4 слово "консолідованим" замінити словом "зведеним";

у пункті 1.3 слово "коштів" замінити словом "кредитів".

1.2. У пункті 2.2 глави 2:

цифри та слова "1605 плюс 2605 плюс 2625 мінус 1505 - пасивне сальдо" виключити;

після рахунку 2604 унести рахунок 2605;

після рахунку 2622 унести рахунок 2625;

після рахунку 2635 унести рахунки 2640, 2641, 2642 та 2643.

2. Установити норматив резервування коштів, що обліковуються за рахунками 2640, 2641, 2642 та 2643, у розмірі 100 процентів.

3. Департаменту монетарної політики (Н.І.Гребеник) після державної реєстрації цих змін у Міністерстві юстиції України довести їх зміст до відома територіальних управлінь Національного банку України та банків для використання в роботі.

4. Постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

5. Контроль за виконанням цієї постанови покласти на першого заступника Голови А.В.Шаповалова.
