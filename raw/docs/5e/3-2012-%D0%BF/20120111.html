Текст документа від 11.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 січня 2012 р. N 3 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 11 січня 2012 р. N 3

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 12 травня 2007 р. N 717 ( 717-2007-п ) "Про затвердження Положення про Міністерство з питань житлово-комунального господарства України" (Офіційний вісник України, 2007 р., N 37, ст. 1471).

2. Постанова Кабінету Міністрів України від 16 травня 2007 р. N 750 ( 750-2007-п ) "Деякі питання Міністерства регіонального розвитку та будівництва" (Офіційний вісник України, 2007 р., N 39, ст. 1545).

3. Пункти 19 та 21 змін, що вносяться до положень про центральні органи виконавчої влади, затверджених постановою Кабінету Міністрів України від 27 лютого 2008 р. N 101 ( 101-2008-п ) (Офіційний вісник України, 2008 р., N 16, ст. 416).

4. Постанова Кабінету Міністрів України від 26 березня 2008 р. N 233 ( 233-2008-п ) "Про доповнення пункту 4 Положення про Міністерство з питань житлово-комунального господарства України" (Офіційний вісник України, 2008 р., N 24, ст. 736).

5. Постанова Кабінету Міністрів України від 10 вересня 2008 р. N 798 ( 798-2008-п ) "Про затвердження Положення про Державну житлово-комунальну інспекцію" (Офіційний вісник України, 2008 р., N 69, ст. 2310).

6. Постанова Кабінету Міністрів України від 28 січня 2009 р. N 68 ( 68-2009-п ) "Про внесення змін до Положення про Міністерство з питань житлово-комунального господарства України та Положення про Державну житлово-комунальну інспекцію" (Офіційний вісник України, 2009 р., N 11, ст. 313).

7. Постанова Кабінету Міністрів України від 11 лютого 2010 р. N 119 ( 119-2010-п ) "Про доповнення пункту 14 Положення про Міністерство регіонального розвитку та будівництва України" (Офіційний вісник України, 2010 р., N 9, ст. 461).

8. Постанова Кабінету Міністрів України від 14 липня 2010 р. N 584 ( 584-2010-п ) "Про внесення змін до Положення про Міністерство з питань житлово-комунального господарства України" (Офіційний вісник України, 2010 р., N 53, ст. 1778).
