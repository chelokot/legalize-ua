Про Національну раду по туризму

( Із змінами, внесеними згідно з Постановами КМ N 2023 ( 2023-98-п ) від 18.12.98 N 1503 ( 1503-2000-п ) від 28.09.2000 N 640 ( 640-2003-п ) від 26.04.2003 N 1106 ( 1106-2003-п ) від 17.07.2003 )

Відповідно до статті 7 Закону України "Про туризм" ( 324/95-ВР ) Кабінет Міністрів України постановляє:

1. Утворити Національну раду по туризму та затвердити її персональний склад (додається).

2. Затвердити Положення про Національну раду по туризму (додається).

ПОЛОЖЕННЯ про Національну раду по туризму

1. Національна рада по туризму є координаційним колегіальним органом. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 640 ( 640-2003-п ) від 26.04.2003 )

2. Національна рада по туризму у своїй діяльності керується Конституцією України ( 254к/96-ВР ), законами України, постановами Верховної Ради України, указами і розпорядженнями Президента України, декретами, постановами і розпорядженнями Кабінету Міністрів України, міжнародними договорами, у яких бере участь Україна, а також цим Положенням. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 640 ( 640-2003-п ) від 26.04.2003 )

3. Основними завданнями Національної ради по туризму є:

координація діяльності центральних та місцевих органів виконавчої влади, пов'язаної з реалізацією державної політики в галузі туризму як одного з пріоритетних напрямів розвитку національної культури та економіки; ( Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 640 ( 640-2003-п ) від 26.04.2003 )

розгляд пропозицій щодо перспектив і напрямів розвитку внутрішнього та міжнародного туризму, розроблення та запровадження системи управління галуззю туризму;

розроблення заходів щодо захисту інтересів держави в галузі туризму.

4. Національна рада по туризму відповідно до покладених на неї завдань на своїх засіданнях розглядає такі питання:

1) дотримання центральними та місцевими органами виконавчої влади Закону України "Про туризм" ( 324/95-ВР ), інших актів законодавства з питань туризму; ( Підпункт перший пункту 4 із змінами, внесеними згідно з Постановою КМ N 640 ( 640-2003-п ) від 26.04.2003 )

2) підготовка пропозицій щодо вдосконалення нормативно-правової бази в галузі туризму;

3) визначення перспектив створення розвинутої інфраструктури туризму, будівництва нових, реконструкції та модернізації діючих підприємств галузі туризму;

4) здійснення заходів щодо приведення у відповідність з міжнародними стандартами рівня обслуговування туристів у готелях, мотелях, кемпінгах, підприємствах харчування, на залізничному, повітряному, морському, річковому та автомобільному транспорті, а також на міжнародних автомобільних шляхах України;

5) попереднє визначення джерел фінансування програм розвитку туризму, підготовка пропозицій про заохочення національних та іноземних інвестицій в розвиток туристичної індустрії;

6) підготовка пропозицій про створення сприятливого для розвитку туризму податкового, валютного, митного, прикордонного та візового режимів;

7) підготовка пропозицій про запровадження пільгових умов для організації туристичної та екскурсійної роботи серед дітей, підлітків, молоді, інвалідів та малозабезпечених верств населення;

8) забезпечення безпеки туристів, захисту їх прав, інтересів та майна;

9) розроблення та запровадження системи інформаційної, рекламної та видавничої діяльності з питань туризму, підготовка і відкриття нових туристичних маршрутів;

10) виконання національних і регіональних програм з питань туризму, розроблення пропозицій щодо розвитку туризму в регіонах;

11) організація та розвиток системи наукового забезпечення галузі туризму;

12) кадрове забезпечення галузі туризму та створення з цією метою мережі закладів освіти різного рівня для підготовки, перепідготовки і підвищення кваліфікації кадрів для туристичних підприємств і організацій;

13) розвиток співробітництва України в галузі туризму із зарубіжними країнами та міжнародними організаціями, участі у міжнародних програмах розвитку туризму.

5. Національна рада по туризму має право:

одержувати від центральних та місцевих органів виконавчої влади, органів місцевого самоврядування, туристичних підприємств незалежно від форм власності інформацію, документи і матеріали, необхідні для її діяльності; ( Абзац другий пункту 5 із змінами, внесеними згідно з Постановою КМ N 640 ( 640-2003-п ) від 26.04.2003 )

створювати тимчасові робочі групи з числа своїх членів і представників інших заінтересованих підприємств, установ і організацій, а також групи експертів, консультантів, учених і фахівців;

заслуховувати інформацію керівників центральних та місцевих органів виконавчої влади і органів місцевого самоврядування з питань, що належать до компетенції Національної ради по туризму; ( Абзац четвертий пункту 5 із змінами, внесеними згідно з Постановою КМ N 640 ( 640-2003-п ) від 26.04.2003 )

залучати в установленому порядку керівників центральних та місцевих органів виконавчої влади, суб'єктів підприємницької діяльності, громадських організацій у сфері туризму, які не входять до складу Національної ради, до участі в її засіданнях. ( Абзац п'ятий пункту 5 в редакції Постанови КМ N 640 ( 640-2003-п ) від 26.04.2003 )

6. Персональний склад Національної ради по туризму затверджує Віце-прем'єр-міністр України, який є головою Національної ради по туризму. ( Пункт 6 в редакції Постанови КМ N 1503 ( 1503-2000-п ) від 28.09.2000 )

7. До складу Національної ради по туризму входять Голова Держтурадміністрації - заступник голови Ради, відповідальний працівник Секретаріату Кабінету Міністрів України - відповідальний секретар Ради, заступник Міністра аграрної політики, заступник Міністра внутрішніх справ, заступник Міністра економіки та з питань європейської інтеграції, заступник Міністра закордонних справ, заступник Міністра культури і мистецтв, заступник Міністра охорони здоров'я, заступник Міністра транспорту, заступник Міністра фінансів, заступник Голови Держмитслужби, заступник Голови Держкомнацміграції, заступник Голови Держкомкордону та інші особи за визначенням голови Національної ради. ( Пункт 7 в редакції Постанов КМ N 1503 ( 1503-2000-п ) від 28.09.2000, N 640 ( 640-2003-п ) від 26.04.2003, із змінами, внесеними згідно з Постановою КМ N 1106 ( 1106-2003-п ) від 17.07.2003 )

8. Рішення Національної ради по туризму оформляються у вигляді протоколів, рекомендацій і є обов'язковими для розгляду центральними та місцевими органами виконавчої влади, органами місцевого самоврядування, підприємствами, установами та організаціями незалежно від форм власності, а також громадянами. ( Абзац перший пункту 8 із змінами, внесеними згідно з Постановою КМ N 640 ( 640-2003-п ) від 26.04.2003 )

У необхідних випадках рішення Національної ради по туризму можуть оформлюватися спільними наказами, постановами колегій центральних органів виконавчої влади. ( Абзац другий пункту 8 із змінами, внесеними згідно з Постановою КМ N 640 ( 640-2003-п ) від 26.04.2003 )

9. Національна рада по туризму здійснює свою діяльність відповідно до затверджуваних нею планів роботи. Засідання Національної ради проводяться в міру потреби, але не рідше ніж два рази на рік.

10. Засідання Національної ради по туризму вважається правомочним, якщо на ньому присутня більшість її членів. Рішення і рекомендації Національної ради приймаються більшістю голосів присутніх її членів. За умови рівної кількості голосів голос голови Національної ради є вирішальним.

Рішення Національної ради по туризму з питань, що зачіпають інтереси окремих центральних та місцевих органів виконавчої влади, приймаються в присутності їх представників. ( Абзац другий пункту 10 із змінами, внесеними згідно з Постановою КМ N 640 ( 640-2003-п ) від 26.04.2003 )

11. Організаційно-технічне забезпечення роботи Національної ради по туризму здійснює Держтурадміністрація.

Витрати, пов'язані з роботою Національної ради по туризму, здійснюються за рахунок коштів, передбачених кошторисом Держтурадміністрації.

( Пункт 11 із змінами, внесеними згідно з Постановами КМ N 1503 ( 1503-2000-п ) від 28.09.2000, КМ N 640 ( 640-2003-п ) від 26.04.2003 )
