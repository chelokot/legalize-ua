Зареєстровано в Міністерстві юстиції України 28 серпня 2009 р. за N 808/16824

Про внесення змін до наказу Державної податкової адміністрації України від 20.10.2005 N 462

Відповідно до статті 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ), статті 3 Закону України "Про ставки акцизного збору на спирт етиловий та алкогольні напої" ( 178/96-ВР ) та постанови Кабінету Міністрів України від 05.03.2009 N 242 ( 242-2009-п ) "Деякі питання використання спирту етилового для виробництва лікарських засобів" НАКАЗУЮ:

1. Унести до Довідки про прогнозований обсяг потреби спирту етилового для виготовлення продукції до податкового векселя, затвердженої наказом Державної податкової адміністрації України від 20.10.2005 N 462 ( z1326-05 ), зареєстрованим у Міністерстві юстиції України 02.11.2005 за N 1326/11606, такі зміни:

1.1. Назву графи 7 викласти в такій редакції: "Одиниця виміру продукції";

1.2. У назві графи 8 слова "л, дал, кг" виключити.

2. Доповнити Довідку векселедавця про цільове використання спирту етилового, затверджену наказом Державної податкової адміністрації України від 20.10.2005 N 462 ( z1326-05 ), зареєстрованим у Міністерстві юстиції України 02.11.2005 за N 1326/11606, після графи 3 новою графою такого змісту: "Кількість виробленої продукції, л, шт., кг". У зв'язку з цим графи 4-9 вважати відповідно графами 5-10.

3. Управлінню акцизного збору (Філозоп А.І.) подати цей наказ до Міністерства юстиції України на державну реєстрацію у встановленому порядку.

4. Департаменту масово-роз'яснювальної роботи та звернень громадян (Косарчук В.П.) довести цей наказ через засоби масової інформації та веб-сайт ДПА до відома платників податків.

5. Цей наказ набирає чинності через десять днів після державної реєстрації.

6. Контроль за виконанням наказу покласти на першого заступника Голови Буханевича О.М.

В.о. Голови В.О.Кайзерман
