КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 січня 2004 р. N 7-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 866 ( 866-2011-п ) від 03.08.2011 }

Про утворення Міжвідомчої комісії з питань удосконалення діяльності санаторно-курортних закладів та захисту майнових інтересів держави під час їх приватизації

{ Із змінами, внесеними згідно з Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 }

1. Утворити Міжвідомчу комісію з питань удосконалення діяльності санаторно-курортних закладів та захисту майнових інтересів держави під час їх приватизації (далі - Міжвідомча комісія).

2. Затвердити склад Міжвідомчої комісії згідно з додатком.

Надати голові Міжвідомчої комісії право вносити у разі потреби зміни до її складу.

3. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 30 березня 2002 р. N 182 ( 182-2002-р ) "Про утворення Міжвідомчої комісії з підготовки проекту Концепції розвитку санаторно-курортної галузі та здійснення заходів щодо захисту майнових інтересів держави під час приватизації оздоровчих закладів" і від 26 грудня 2002 р. N 725 ( 725-2002-р ) "Про утворення Міжвідомчої робочої групи з питань удосконалення діяльності санаторно-курортних закладів".
