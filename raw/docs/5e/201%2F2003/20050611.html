УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президент N 834/2005 ( 834/2005 ) від 23.05.2005 )

Про внесення змін до складу Комісії з питань реформування правоохоронних органів в Україні

1. Увести до складу Комісії з питань реформування правоохоронних органів в Україні, затвердженого Указом Президента України від 17 січня 2001 року N 17 ( 17/2001 ) (зі змінами, внесеними Указами від 22 березня 2001 року N 194 ( 194/2001 ), від 18 квітня 2001 року N 263 ( 263/2001 ) та від 7 вересня 2001 року N 811 ( 811/2001 ), таких осіб:

МЕДВЕДЧУК - Глава Адміністрації Президента

Віктор Володимирович України, заступник Голови Комісії

БАБЕНКО - ректор Інституту Генеральної

Володимир Іванович прокуратури України

ВИНОКУРОВ - перший заступник Генерального

Сергій Маркіянович прокурора України

ГАПОН - Державний секретар Міністерства

Олександр Андрійович внутрішніх справ України

ЛОЗКО - перший заступник Голови Державної

Віктор Якович митної служби України

ПТАШИНСЬКИЙ - перший заступник Голови Державного

Олександр Борисович департаменту України з питань виконання покарань

СТЕФАНЮК - перший заступник Голови Головного

Ігор Богданович контрольно-ревізійного управління України

ШИТРЯ - заступник Голови Державної

Олексій Іванович податкової адміністрації України

ЯЦУБА - Державний секретар Кабінету

Володимир Григорович Міністрів України.

2. Вивести зі складу зазначеної Комісії Єханурова Ю.І., Бєлова О.Ф., Біласа І.Г., Васильєва Г.А., Гарника М.В., Гончаренка В.Г., Джигу М.В., Короля В.М., Литвина В.М., Мельника П.В., Шакуна В.І.
