Про внесення зміни до постанови Кабінету Міністрів України від 24 березня 1999 р. N 441

( Із змінами, внесеними згідно з Постановою КМ N 2149 ( 2149-99-п ) від 25.11.99 )

З метою задоволення потреб населення у житлово-комунальних послугах та поліпшення фінансового становища підприємств і організацій житлово-комунального господарства Кабінет Міністрів України постановляє:

1. Доповнити пункт 7 Порядку постачання електричної енергії споживачам, затвердженого постановою Кабінету Міністрів України від 24 березня 1999 р. N 441 ( 441-99-п ) "Про невідкладні заходи щодо стабілізації фінансового становища підприємств електроенергетичної галузі" (Офіційний вісник України, 1999 р., N 12, ст. 480, N 21, ст. 964) абзацом такого змісту:

"споживачам - підприємствам та організаціям, що надають житлово-комунальні послуги населенню з утримання та експлуатації житла, ліфтів, прибудинкових територій, водопостачання і водовідведення, постачання теплової енергії, вивезення твердих побутових відходів та рідких нечистот, незалежно від стану розрахунків за використану електричну енергію - в обсязі, необхідному для надання зазначених житлово-комунальних послуг".

2. Рекомендувати енергопостачальним організаціям не застосовувати до підприємств та організацій, що надають житлово-комунальні послуги населенню з утримання та експлуатації житла, ліфтів, прибудинкових територій, водопостачання і водовідведення, постачання теплової енергії, вивезення твердих побутових відходів та рідких нечистот, а також до підприємств міського електротранспорту (за переліками, визначеними Радою міністрів Автономної Республіки Крим, обласними, Київською та Севастопольською міськими державними адміністраціями), стягнення п'ятикратної вартості понад встановлені величини електричної енергії та потужності, передбачене частинами п'ятою і шостою статті 26 Закону України "Про електроенергетику" ( 575/97-ВР ), у разі перевищення ними встановлених граничних величин споживання електричної енергії та потужності, а також стягнення пені за несвоєчасні розрахунки за використану електричну енергію, у тому числі за попередній період. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 2149 ( 2149-99-п ) від 25.11.99 )

3. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям разом з місцевими енергопостачальними організаціями сприяти підприємствам і організаціям житлово-комунального господарства та підприємствам міського електротранспорту у вирішенні питань постачання в достатніх обсягах електричної енергії та її оплати. ( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 2149 ( 2149-99-п ) від 25.11.99 )
