Про передачу цілісного майнового комплексу державного підприємства "Білоцерківський завод "Еталон" до сфери управління Київської облдержадміністрації

Стан: Втратив чинність

Ідентифікатор: 1101-2011-р

Текст документа від 22.07.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 листопада 2011 р. N 1101-р Київ

{ Розпорядження скасовано на підставі Розпорядження КМ N 762-р ( 762-2015-р ) від 22.07.2015 }

Про передачу цілісного майнового комплексу державного підприємства "Білоцерківський завод "Еталон" до сфери управління Київської облдержадміністрації

Прийняти пропозицію Міністерства надзвичайних ситуацій та Київської облдержадміністрації щодо передачі цілісного майнового комплексу державного підприємства "Білоцерківський завод "Еталон" (м. Біла Церква, вул. Сухоярська, 16) до сфери управління зазначеної облдержадміністрації.

Прем'єр-міністр України М.АЗАРОВ
