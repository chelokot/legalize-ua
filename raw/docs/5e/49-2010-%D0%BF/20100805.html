Кабінет Міністрів України; Постанова від 27.01.2010 № 49

Питання використання у 2010 році коштів Стабілізаційного фонду для забезпечення інформування органів місцевого самоврядування

Стан: Чинний

Ідентифікатор: 49-2010-п

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 січня 2010 р. N 49 Київ

Питання використання у 2010 році коштів Стабілізаційного фонду для забезпечення інформування органів місцевого самоврядування

{ Із змінами, внесеними згідно з Постановами КМ N 127 ( 127-2010-п ) від 17.02.2010 N 666 ( 666-2010-п ) від 28.07.2010 }

Кабінет Міністрів України постановляє:

1. Виділити Міністерству регіонального розвитку та будівництва за рахунок залишку коштів Стабілізаційного фонду станом на 1 січня 2010 р. на безповоротній основі 1980000 гривень для фінансування заходів із забезпечення у I кварталі 2010 року сільських і селищних рад газетою "Урядовий кур'єр" (далі - кошти Стабілізаційного фонду).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 127 ( 127-2010-п ) від 17.02.2010 }

2. Установити що:

кошти Стабілізаційного фонду спрямовуються з урахуванням вимог постанови Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) "Питання використання коштів Стабілізаційного фонду" (Офіційний вісник України, 2009 р., N 24, ст. 793), - із змінами, внесеними постановою Кабінету Міністрів України від 13 січня 2010 р. N 33 ( 33-2010-п );

головним розпорядником коштів Стабілізаційного фонду є Міністерство регіонального розвитку та будівництва;

операції, пов'язані з використанням коштів Стабілізаційного фонду, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

3. Забезпечити до погодження розподілу коштів Стабілізаційного фонду з комітетами Верховної Ради України з питань бюджету і з питань фінансів та банківської діяльності:

Міністерству фінансів - внесення відповідних змін до тимчасового розпису Державного бюджету України на I квартал 2010 року;

Державному казначейству - перерахування коштів Стабілізаційного фонду.

{ Пункт 4 втратив чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }
