КАБІНЕТ МІНІСТРІВ УКРАЇНИ
РОЗПОРЯДЖЕННЯ

від 3 січня 2023 р. № 3-р
Київ

Про відкриття тимчасового міжнародного пункту контролю через державний кордон на залізничній станції Рахів

З метою впорядкування діяльності міжнародного пункту пропуску через державний кордон з Румунією для залізничного сполучення “Ділове” відкрити на території залізничної станції Рахів міжнародний пункт контролю через державний кордон “Рахів” для залізничного пасажирського сполучення з тимчасовим (на період дії воєнного стану та 90 днів після його припинення або скасування) режимом функціонування і цілодобовим часом роботи.

Прем'єр-міністр України

Д. ШМИГАЛЬ
