Текст документа від 07.05.2022:

УКАЗ ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

{ Указ не застосовується на території України згідно із Законом N 2215-IX ( 2215-20 ) від 21.04.2022 }

Про перетворення Державного комітету Української РСР по праці і відділів по праці виконавчих комітетів обласних, міських Рад народних депутатів

( Відомості Верховної Ради УРСР, 1988, N 32, ст. 765 )

Президія Верховної Ради Української РСР постановляє:

1. Перетворити Державний комітет Української РСР по праці у союзно-республіканський Державний комітет Української РСР по праці і соціальних питаннях.

2. Перетворити відділи по праці виконавчих комітетів обласних, міських Рад народних депутатів у відділи (управління) по праці і соціальних питаннях виконавчих комітетів обласних, міських Рад народних депутатів.
