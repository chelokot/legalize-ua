{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Питання розрахунків за поставлене енергогенеруючим компаніям вугілля

Кабінет Міністрів України постановляє:

1. Установити, що закупівля послуги з надання кредиту уповноваженим банком - відкритим акціонерним товариством "Державний ощадний банк України" у розмірі 625 млн. гривень (далі - кредит) для проведення розрахунків енергогенеруючими компаніями, пакети акцій яких, що належать державі, передані до статутного фонду Національної акціонерної компанії "Енергетична компанія України", що використовують вугілля для виробництва електричної та/або теплової енергії (далі - енергогенеруючі компанії), здійснюється державним підприємством "Енергоринок" без погодження з Міністерством економіки застосування процедури закупівлі зазначеної послуги в одного учасника.

2. Взяти до відома, що енергогенеруючі компанії спрямують кошти, що надійдуть від державного підприємства "Енергоринок" після отримання ним кредиту, на розрахунки за вугілля, поставлене державним підприємством "Вугілля України".

3. Рекомендувати Національній комісії регулювання електроенергетики України встановити алгоритм розподілу коштів, що надходять з поточних рахунків із спеціальним режимом використання енергогенеруючих компаній за поставлену державному підприємству "Енергоринок" електроенергію, з урахуванням необхідності погашення кредиту.

Прем'єр-міністр України Ю.ТИМОШЕНКО
