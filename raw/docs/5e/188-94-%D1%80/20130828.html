Кабінет Міністрів України; Розпорядження від 23.03.1994 № 188-р

Про віднесення деяких посад керівників апарату Верховної Ради України до відповідних категорій державних службовці

Стан: Втратив чинність

Ідентифікатор: 188-94-р

Текст документа від 28.08.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 березня 1994 р. N 188-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 663-р ( 663-2013-р ) від 28.08.2013 }

Про віднесення деяких посад керівників апарату Верховної Ради України до відповідних категорій державних службовців

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади керуючого справами Верховної Ради України, першого заступника керівника Секретаріату Верховної Ради України, першого заступника керуючого справами, начальника Господарського управління Кабінету Міністрів України - заступника Міністра Кабінету Міністрів до 1 категорії державних службовців, а посади заступника керуючого справами та заступників начальника Господарського управління - до 2 категорії державних службовців.
