Про штатний розпис Центральної виборчої комісії

( Із змінами, внесеними згідно з Постановами Центральної виборчої комісії N 83 ( v0083359-05 ) від 18.05.2005 N 86 ( v0086359-05 ) від 24.05.2005 N 101 ( v0101359-05 ) від 25.06.2005 N 108 ( v0108359-05 ) від 08.07.2005 N 109 ( v0109359-05 ) від 08.07.2005 N 120 ( v0120359-05 ) від 06.09.2005 N 139 ( v0139359-05 ) від 09.11.2005 )

На виконання постанови Центральної виборчої комісії від 22 лютого 2005 року N 45 ( v0045359-05 ) "Про структуру і чисельність Секретаріату, патронатної служби та автогосподарства Центральної виборчої комісії" та відповідно до постанови Кабінету Міністрів України від 13 грудня 1999 року N 2288 ( 2288-99-п ) "Про впорядкування умов оплати праці працівників апарату органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів", наказу Міністерства праці України від 2 жовтня 1996 року N 77 ( z0593-96 ) "Про умови оплати праці робітників, зайнятих обслуговуванням органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів", Колективного договору автогосподарства Центральної виборчої комісії на 2003 рік, зареєстрованого Управлінням праці та соціального захисту населення Печерської районної державної адміністрації за N 382 від 1 серпня 2003 року, керуючись частиною третьою статті 6, статтями 12, 33, 34, 35, частиною першою статті 36, частиною першою статті 37 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Затвердити штатний розпис Центральної виборчої комісії (додається).

2. Визнати такою, що втратила чинність, постанову Центральної виборчої комісії від 25 січня 2005 року N 22 ( v0022359-05 ) "Про штатні розписи Центральної виборчої комісії та автогосподарства Центральної виборчої комісії".

Голова Центральної виборчої комісії Я.ДАВИДОВИЧ

ЗАТВЕРДЖЕНО чисельність - 334 штатні одиниці з місячним фондом заробітної плати за посадовими окладами 225282 грн. (двісті двадцять п'ять тисяч двісті вісімдесят дві грн.)
