Питання Державного комітету у справах релігій

Стан: Втратив чинність

Текст документа від 16.06.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 листопада 1995 р. N 892 Київ

( Постанова втратила чинність на підставі Постанови КМ N 483 ( 483-2005-п ) від 16.06.2005 )

Питання Державного комітету у справах релігій

( Із змінами, внесеними згідно з Розпорядженням КМ N 717-р ( 717-95-р ) від 21.11.95 Постановами КМ N 357 ( 357-2000-п ) від 18.02.2000 N 1378 ( 1378-2002-п ) від 13.09.2002 N 1925 ( 1925-2002-п ) від 17.12.2002 )

Відповідно до Указу Президента України від 11 жовтня 1995 р. N 944 ( 944/95 ) "Про утворення Державного комітету України у справах релігій" Кабінет Міністрів України постановляє:

1. Установити граничну чисельність працівників центрального апарату Державного комітету у справах релігій у кількості 55 одиниць, скоротивши при цьому на таку ж кількість чисельність працівників центрального апарату Міністерства у справах національностей, міграції та культів.

Дозволити Державному комітетові у справах релігій мати трьох заступників голови, у тому числі одного першого. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1925 ( 1925-2002-п ) від 17.12.2002 )

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1378 ( 1378-2002-п ) від 13.09.2002 )

2. Міністерству фінансів профінансувати витрати на утримання Державного комітету у справах релігій в 1995 році за рахунок асигнувань на утримання органів державної виконавчої влади, передбачених у Державному бюджеті.

( Пункт 3 втратив чинність на підставі Постанови КМ N 357 ( 357-2000-п ) від 18.02.2000 )

4. ( Абзац перший пункту 4 втратив чинність на підставі Розпорядження КМ N 717-р ( 717-95-р ) від 21.11.95 )

( Абзац другий пункту 4 втратив чинність на підставі Розпорядження КМ N 717-р ( 717-95-р ) від 21.11.95 )

Міністерству у справах національностей, міграції та культів у місячний термін вивільнити будинок по вул.Грушевського, 14/1.

5. Міністерству зв'язку забезпечити Державний комітет у справах релігій засобами зв'язку, згідно з його замовленням.
