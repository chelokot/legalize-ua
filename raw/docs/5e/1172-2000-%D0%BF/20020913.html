КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 липня 2000 р. N 1172 Київ

Про колегію Міністерства екології та природних ресурсів

( Із змінами, внесеними згідно з Постановою КМ N 1376 ( 1376-2002-п ) від 13.09.2002 )

Кабінет Міністрів України постановляє:

1. Дозволити Міністерству екології та природних ресурсів мати колегію у кількості 20 осіб.

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1376 ( 1376-2002-п ) від 13.09.2002 )

2. Затвердити членами колегії Міністерства екології та природних ресурсів Бондаря Анатолія Лаврентійовича, Грищенка Вадима Васильовича, Гурського Дмитра Сергійовича, Давидок Віру Петрівну, Дем'яненка Анатолія Івановича, Леоненка Віктора Борисовича, Ліпінського В'ячеслава Миколайовича, Маторіна Євгена Михайловича, Мовчана Ярослава Івановича, Розенка Павла Валерійовича, Рубана Юрія Григоровича, Свирида Петра Олексійовича. ( Затвердити членом колегії Міністерства екології та природних ресурсів з правом дорадчого голосу Різака Івана Михайловича (за згодою) згідно з Постановою КМ N 1376 ( 1376-2002-п ) від 13.09.2002 )
