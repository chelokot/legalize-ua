Стан: Втратив чинність

Текст документа від 05.08.1992:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 18 березня 1991 р. N 58 Київ

( Постанова втратила чинність на підставі Постанови КМ N 451 ( 451-92-п ) від 05.08.92 )

Про внесення доповнень до постанови Ради Міністрів УРСР від 15 травня 1990 р. N 112

Рада Міністрів Української РСР постановляє:

Погодитись з пропозицією Комісії Президії Ради Міністрів УРСР по вдосконаленню господарського механізму про доповнення розділу I додатка до постанови Ради Міністрів УРСР від 15 травня 1990 р. N 112 ( 112-90-п ) "Про порядок здачі підприємств (об'єднань) республіканського і місцевого підпорядкування та їх майна в оренду" (ЗП УРСР, 1990 р., N 5, ст. 29, N 9, ст. 49, N 11, ст. 64) абзацом такого змісту:

"Підприємства Мінмонтажспецбуду УРСР, які виготовляють продукцію для спеціальних галузей, забезпечують будівництво і відбудову об'єктів народного господарства в особливий період (надзвичайних ситуаціях), здійснюють виробництво спеціалізованих засобів механізації, деталей трубопроводів, монтажних виробів та їх конструкцій для забезпечення, в основному, загальногалузевих потреб".
