Кабінет Міністрів України постановляє:

Схвалити такі основні прогнозні макропоказники економічного і соціального розвитку України на 2011 рік та покласти їх в основу розроблення проектів Державної програми економічного і соціального розвитку України на 2011 рік та Державного бюджету України на 2011 рік:

номінальний - 1291 млрд. гривень; { Абзац третій постановляючої частини із змінами, внесеними згідно з Постановою КМ N 587 ( 587-2011-п ) від 06.06.2011 }

відсотків до попереднього року - 104,7; { Абзац четвертий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 587 ( 587-2011-п ) від 06.06.2011 }

індекс споживчих цін (грудень до грудня попереднього року) - 108,9 відсотка;

індекс цін виробників промислової продукції (грудень до грудня попереднього року) - 117,9 відсотка; { Абзац шостий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 587 ( 587-2011-п ) від 06.06.2011 }

прибуток прибуткових підприємств - 242,3 млрд. гривень; { Абзац сьомий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 587 ( 587-2011-п ) від 06.06.2011 }

фонд оплати праці найманих працівників і грошового забезпечення військовослужбовців - 399,5 млрд. гривень; { Абзац восьмий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 587 ( 587-2011-п ) від 06.06.2011 }

середньомісячна заробітна плата працівників:

номінальна - 2695 гривень; { Абзац десятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 587 ( 587-2011-п ) від 06.06.2011 }

номінальна, скоригована на індекс споживчих цін, відсотків до попереднього року - 110,1; { Абзац одинадцятий постановляючої частини із змінами, внесеними згідно з Постановою КМ N 587 ( 587-2011-п ) від 06.06.2011 }

продуктивність праці, відсотків до попереднього року - 104,1;

кількість зайнятих економічною діяльністю віком 15-70 років (у середньому за рік) - 20,6-20,4 млн. осіб;

рівень безробіття, визначений за методологією Міжнародної організації праці, - 7,6-8,1 відсотка;
