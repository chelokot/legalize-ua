ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

N 252 від 14.07.98 Зареєстровано в Міністерстві м.Київ юстиції України 16 жовтня 1998 р. vd980714 vn252 за N 664/3104

Про затвердження форм державної статистичної звітності

з статистики науки та інновацій, а також інструкцій щодо їх заповнення

( Із змінами, внесеними згідно з Наказами Державного комітету статистики N 261 ( z0555-00 ) від 04.08.2000 N 290 ( z0850-03 ) від 09.09.2003 )

Відповідно до статті 12 Закону України "Про державну статистику" ( 2614-12 ) та з метою удосконалення форм державної статистичної звітності і показників статистики науки та інновацій НАКАЗУЮ:

1. Затвердити такі, що додаються:

1.1. Форми державної статистичної звітності:

( Наказ втратив чинність у частині затвердження форми державних статистичних спостережень N 6-нт(ліцензії)-річна та інструкції щодо її заповнення на підставі Наказу Держкомстату N 290 ( z0850-03 ) від 09.09.2003 ) - N 6-нт (ліцензії) - річна "Звіт про продаж ліцензій на об'єкти інтелектуальної власності" ( z0665-98 );

( Наказ втратив чинність в частині затвердження форми державної статистичної звітності N 1-наука - квартальна на підставі Наказу Держкомстату N 261 ( z0555-00 ) від 04.08.2000 ) - N 1-наука - квартальна "Звіт про виконання науково-технічних робіт".

1.2. Інструкцію щодо заповнення державної статистичної звітності за формою N 6-нт (ліцензії) - річна "Звіт про продаж ліцензій на об'єкти інтелектуальної власності" ( z0665-98 ).

( Наказ втратив чинність в частині затвердження Інструкції щодо заповнення державної статистичної звітності за формою N 1-наука - квартальна на підставі Наказу Держкомстату N 261 ( z0555-00 ) від 04.08.2000 ) 1.3. Інструкцію щодо заповнення державної статистичної звітності за формою N 1-наука - квартальна "Звіт про виконання науково-технічних робіт".

2. Розповсюдити зазначені форми державної статистичної звітності, а також інструкції щодо їх заповнення на організації, підприємства, установи всіх форм власності та організаційно-правових форм господарювання та ввести їх у дію, починаючи зі звіту за 1998 рік.

3. Управлінню статистики промисловості (Васєчко О.О.) підготувати оригінали форм статзвітності та інструкції про порядок їх заповнення для здачі до друку в інформаційно-видавничий центр Держкомстату України.

4. Фінансово-економічному управлінню (Сорокіна Т.В.) забезпечити фінансування виготовлення та розсилки бланків форм державної статистичної звітності.

5. НДІ статистики Держкомстату України (Карпов В.І.) забезпечити своєчасне тиражування та розсилку бланків у регіональні, Київське та Севастопольське міські управління статистики.

6. Голові Держкомстату Автономної Республіки Крим, начальникам обласних, Київського і Севастопольського міських управлінь статистики забезпечити збір, розробку і подання Держкомстату України звітів у встановлені терміни.

7. Вважати такими, що втратили чинність у частині дії форм державної статистичної звітності:

7.1. Наказ Мінстату України від 06.07.95 N 168 ( z0235-95, z0240-95 ): N 6-нт (ліцензії);

7.2. Наказ Мінстату України від 09.07.96 N 207 ( z0391-96, z0392-96 ): N 5-нт (сертифікація);

7.3. Наказ Держкомстату України від 27.08.97 N 10 ( z0441-97 ): N 1-наука (річна), N 2-наука (квартальна-термінова).

8. Контроль за виконанням наказу покласти на Першого заступника Голови Держкомстату України Головка В.А.

Голова Держкомстату О.Г.Осауленко

( Форма N 1-наука - квартальна втратила чинність на підставі Наказу Держкомстату N 261 ( z0555-00 ) від 04.08.2000 )
