Кабінет Міністрів України; Розпорядження від 28.12.1998 № 1082-р

Про митне оформлення спецавтомобілів для технічного обслуговування, обладнання та інших вантажів, що надійшли на адресу ВАТ "Харківський тракторний завод"

Стан: Втратив чинність

Ідентифікатор: 1082-98-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 грудня 1998 р. N 1082-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Держмитслужбі здійснити митне оформлення спецавтомобілів для технічного обслуговування, обладнання та інших вантажів, що надійшли на адресу ВАТ "Харківський тракторний завод" відповідно до укладеного контракту від 4 вересня 1997 р. N 804-05750295/276-03-97 з німецькою фірмою "Дойц АГ", без сплати податку на додану вартість, мита та митних зборів, які справляються за перебування вантажу під митним контролем.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
