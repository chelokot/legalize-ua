Про Групу консультантів з питань ринкової економіки

Стан: Втратив чинність

Текст документа від 21.07.1994:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 406/94 ( 406/94 ) від 21.07.94 }

Про Групу консультантів з питань ринкової економіки

{ Із змінами, внесеними згідно з Розпорядженням Президента N 7/94-рп ( 7/94-рп ) від 27.01.94 }

З метою вивчення, аналізу та підготовки пропозицій з питань становлення і розвитку ринкових відносин та підприємництва в Україні постановляю:

1. Утворити в Адміністрації Президента України Групу консультантів з питань ринкової економіки в кількості чотирьох осіб за рахунок скорочення штату апарату Ради національної безпеки при Президентові України.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням Президента N 7/94-рп ( 7/94-рп ) від 27.01.94 }

2. Затвердити структуру та штати Групи консультантів з питань ринкової економіки.

3. Координацію роботи цієї Групи покласти на Радника Президента України з питань ринкової економіки БАСКАКОВА Юрія Георгійовича.

Президент України Л.КРАВЧУК

м.Київ, 1 грудня 1993 року N 127/93-рп
