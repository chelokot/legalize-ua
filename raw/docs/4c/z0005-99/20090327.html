Про окремі питання, пов'язані з регулюванням діяльності комерційних банків

Реєстрація: Мін'юст України від 05.01.1999 № 5/3298

Стан: Втратив чинність

Ідентифікатор: z0005-99

Текст документа від 27.03.2009:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 524 від 17.12.98 Зареєстровано в Міністерстві м.Київ юстиції України 5 січня 1999 р. за N 5/3298

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про окремі питання, пов'язані з регулюванням діяльності комерційних банків

{ Із змінами, внесеними згідно з Постановами Нацбанку N 133 ( z0280-99 ) від 23.03.99 N 376 ( z0562-99 ) від 13.08.99 N 585 ( z0877-99 ) від 13.12.99 N 601 ( z0004-00 ) від 22.12.99 N 290 ( z0946-05 ) від 12.08.2005 }

Відповідно до Закону України "Про банки і банківську діяльність" ( 872-12 ) та враховуючи ситуацію, що склалася на грошово-кредитному ринку України, Правління ПОСТАНОВЛЯЄ:

1. Встановити, що контроль за дотриманням розміру мінімального статутного капіталу, перерахованого в ЕКЮ, здійснюється тільки під час реєстрації комерційного банку.

При здійсненні контролю за поточною діяльністю комерційних банків достатність капіталу, інші економічні нормативи та ліцензійні вимоги щодо окремих операцій визначаються на підставі загальної суми капіталу.

Вищезазначене стосується і банків, створених за участю іноземного капіталу.

( Пункт 2 виключено на підставі Постанови Нацбанку N 585 ( z0877-99 ) від 13.12.99 )

( Пункт 3 втратив чинність на підставі Постанови Національного банку N 290 ( z0946-05 ) від 12.08.2005 )

4. Враховуючи, що норма обов'язкового резервування є інструментом реалізації грошово-кредитної політики, встановити, що формування обов'язкових резервів банки здійснюють у грошовій одиниці України від суми залучених коштів у будь-якій валюті.

5. Іноземна валюта, яку банк отримав у вигляді сплати іноземним інвестором відповідної частки статутного капіталу, може використовуватися при здійсненні банківських операцій, у тому числі й при наданні кредитів в іноземній валюті на тих самих умовах, що надаються банкам-резидентам, капітал яких сформований без участі іноземних інвесторів.

Банки можуть надавати кредити в іноземній валюті і в тому разі, якщо для цього вони залучають депозити чи кредити в іноземній валюті від резидентів чи нерезидентів.

( Абзац третій пункту 5 втратив чинність на підставі Постанови Нацбанку N 601 ( z0004-00 ) від 22.12.99 ) Якщо валютні кредити надані резидентам України комерційними банками за рахунок іноземної валюти, залученої від іноземних кредиторів, то при настанні строку їх повернення зворотна конвертація здійснюється без обмеження. Дія постанови Правління Національного банку України "Про кредитування в іноземній валюті" від 20.11.98 N 489 ( z0785-98 ) на такі кредити не поширюється.

6. Юридичному департаменту (В.Л.Кротюк) до 10.01.99 підготувати в порядку законодавчої ініціативи від імені Національного банку України звернення до Верховної Ради України про внесення відповідних змін до законодавства України про оподаткування з урахуванням того, що комерційні банки в силу специфіки діяльності зобов'язані здійснювати операції з іноземною валютою за дорученням її власників.

7. Регіональним управлінням Національного банку України, враховуючи значні коливання валютного курсу протягом вересня-жовтня 1998 року, не вважати порушенням відхилення в дотриманні комерційними банками всіх обов'язкових економічних нормативів (крім нормативів ліквідності) тільки в частині відхилень, що спричинені зміною курсу гривні (до завершення строку дії кредитних угод).

Регіональним управлінням Національного банку України розглянути кожний випадок таких порушень і подати відповідні пропозиції щодо застосування до цих банків заходів впливу Департаментом безвиїзного нагляду Національного банку України (Ю.О.Герасименко)не пізніше 20.01.99.

8. Департаментам безвиїзного нагляду (Ю.О.Герасименко), реєстрації і ліцензування (О.І.Пархоменко), з питань роботи з проблемними банками (В.І.Ревун), юридичному (В.Л.Кротюк), управлінню координації з питань банківського нагляду (І.Ю.Горячек) протягом 15 днів після набуття чинності цієї постанови привести чинні нормативні акти Національного банку України у відповідність з вимогами даної постанови.

9. Постанова набуває чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

10. Контроль за виконанням цієї постанови покласти на першого заступника Голови Правління В.С.Стельмаха, заступника Голови Правління О.І.Кірєєва.

Голова В.А.Ющенко
