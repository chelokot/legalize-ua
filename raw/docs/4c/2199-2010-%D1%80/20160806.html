{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Про внесення змін до розпорядження Кабінету Міністрів України від 29 березня 1997 р. N 169

Внести до розпорядження Кабінету Міністрів України від 29 березня 1997 р. N 169 ( 169-97-р ) (Офіційний вісник України, 1997 р., число 14, с. 89; 1999 р., N 8, ст. 302) такі зміни:

в абзаці першому слова "Верховної Ради України" виключити;

абзац четвертий після слів "помічника Голови палати," доповнити словами "прес-секретаря Голови палати,".

Прем'єр-міністр України М.АЗАРОВ
