КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 липня 2004 р. N 851 Київ

( Постанова втратила чинність на підставі Постанови КМ N 468 ( 468-2005-п ) від 16.06.2005 )

Про зміну складу Митно-тарифної ради України

Кабінет Міністрів України постановляє:

Увести до складу Митно-тарифної ради України, затвердженого постановою Кабінету Міністрів України від 3 березня 2004 р. N 225 ( 225-2004-п ) (Офіційний вісник України, 2004 р., N 9, ст. 531), заступника Міністра економіки та з питань європейської інтеграції Білокурова Дмитра Едуардовича і заступника Міністра палива та енергетики Светеліка Олександра Дмитровича, вивівши з її складу Тітенка Сергія Михайловича.
