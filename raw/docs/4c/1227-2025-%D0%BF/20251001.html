Київ

Про затвердження Порядку подання та оновлення інформації про можливості для молоді, партнерські можливості для молоді та функціонування веб-порталу “Можливості для молоді”

Кабінет Міністрів України постановляє:

1. Затвердити Порядок подання та оновлення інформації про можливості для молоді, партнерські можливості для молоді та функціонування веб-порталу “Можливості для молоді”, що додається.

2. Міністерству молоді та спорту забезпечити розроблення та впровадження програмного забезпечення, необхідного для функціонування веб-порталу “Можливості для молоді”.

3. Ця постанова набирає чинності з дня її опублікування та діє протягом правового режиму воєнного стану.

ПОРЯДОК
подання та оновлення інформації про можливості для молоді, партнерські можливості для молоді та функціонування веб-порталу “Можливості для молоді”

1. Цей Порядок визначає механізм ведення, подання та оновлення інформації про можливості для молоді та партнерські можливості для молоді, регулює функціональні можливості веб-порталу “Можливості для молоді”, а також інші питання, пов’язані з його функціонуванням та технічною підтримкою.

2. Веб-портал “Можливості для молоді” (далі - веб-портал) є веб-порталом, що містить інформацію про можливості для молоді, партнерські можливості для молоді, та спрямований на підтримку розвитку молоді в Україні шляхом забезпечення доступу молоді до можливостей для молоді, партнерських можливостей для молоді з метою їх самореалізації та активної участі в суспільному житті.

3. У цьому Порядку терміни вживаються у такому значенні:

база даних веб-порталу “Можливості для молоді” (далі - база даних) - іменована сукупність взаємопов’язаних, структурованих даних, що організовані за визначеною логічною моделлю та зберігаються в електронному вигляді з метою забезпечення функціонування та наповнення вебпорталу;

електронний кабінет - персоніфікована веб-сторінка (веб-сервіс чи інший програмний інтерфейс) уповноваженої особи веб-порталу, призначена для забезпечення можливості створення, перегляду та редагування інформації на веб-порталі;

користувачі веб-порталу - організатори можливостей для молоді, організатори партнерських можливостей для молоді, молодь, суб’єкти молодіжної роботи, органи державної влади, органи місцевого самоврядування, юридичні особи публічного та приватного права, посадові особи Українського молодіжного фонду (далі - Фонд), особи, які здійснюють перегляд інформації про наявні можливості для молоді, партнерські можливості для молоді та іншої інформації, визначеної цим Порядком;

можливості для молоді - можливості, доступні для молоді з метою її підтримки (премія, стипендія, бюджетний грант, грант, кредит, компенсація, послуга, стажування, кешбек, конкурс, програма, консультація, фінансування проекту, інше), що надаються організаторами можливостей для молоді;

організатори можливостей для молоді - органи державної влади, юридичні особи публічного права, які надають можливості для молоді та забезпечують надсилання інформації про наявні можливості для молоді до Фонду для внесення ним зазначеної інформації до бази даних;

організатори партнерських можливостей для молоді - юридичні особи приватного права, які надають молоді партнерські можливості для молоді та забезпечують надсилання інформації про наявні партнерські можливості для молоді до Фонду для внесення ним зазначеної інформації до бази даних;

партнерські можливості для молоді - можливості, доступні для молоді з метою її підтримки (премія, стипендія, грант, кредит, компенсація, послуга, стажування, кешбек, конкурс, програма, консультація, фінансування проекту, інше), що надаються організаторами партнерських можливостей для молоді, які пройшли перевірку Фондом відповідно до цього Порядку;

уповноважені особи веб-порталу - посадові особи Фонду.

Інші терміни в цьому Порядку вживаються у значенні, наведеному в Законах України “Про основні засади молодіжної політики”, “Про соціальні послуги”, “Про інформацію”, “Про захист інформації в інформаційно-комунікаційних системах”, “Про електронні документи та електронний документообіг”, “Про електронну ідентифікацію та електронні довірчі послуги”, “Про електронні комунікації”.

4. Програмне забезпечення веб-порталу є об’єктом права державної власності. Виключні майнові права інтелектуальної власності на програмне забезпечення належать державі в особі Мінмолодьспорту.

5. Власником веб-порталу є держава в особі Мінмолодьспорту.

6. Держателем веб-порталу та володільцем інформації, що обробляється на веб-порталі, є Фонд.

7. Технічним адміністратором веб-порталу є Фонд (далі - адміністратор веб-порталу), що належить до сфери управління Мінмолодьспорту.

8. Захист інформації на веб-порталі під час її обробки та обміну здійснюється відповідно до Закону України “Про захист інформації в інформаційно-комунікаційних системах”.

9. Створення та функціонування веб-порталу може здійснюватися за рахунок коштів державного бюджету, коштів міжнародної технічної допомоги та/або фінансової допомоги міжнародних організацій, інших джерел, не заборонених законодавством.

10. Наповнення веб-порталу здійснюється державною мовою.

11. Користування веб-порталом здійснюється на безоплатній основі цілодобово сім днів на тиждень, крім випадків проведення модернізації або планових і позапланових профілактичних та/або технічних робіт, пов’язаних з усуненням технічних та/або методологічних помилок чи технічного збою в роботі, тривалість проведення яких визначається адміністратором веб-порталу та відображається на веб-порталі.

12. Основними завданнями веб-порталу є:

забезпечення молоді доступу до можливостей для молоді, партнерських можливостей для молоді, що сприяють її самореалізації та активній участі в суспільному житті;

забезпечення збору, відображення та аналізу статистичних даних щодо функціонування веб-порталу, зокрема кількості відвідувань, переглядів можливостей для молоді, партнерських можливостей для молоді;

забезпечення уповноваженим особам веб-порталу доступу до електронних кабінетів;

захист даних (зокрема персональних), розміщених на веб-порталі від несанкціонованого доступу, знищення, модифікації;

виконання інших завдань, пов’язаних із можливостями для молоді, партнерськими можливостями для молоді.

13. Функціональними можливостями веб-порталу є:

зберігання та відображення інформації про можливості для молоді, партнерські можливості для молоді;

автентифікація уповноважених осіб веб-порталу на різних етапах обробки і зберігання інформації про можливості для молоді, партнерські можливості для молоді;

розмежування прав користувачів веб-порталу та уповноважених осіб веб-порталу на внесення, перегляд інформації на веб-порталі, внесення змін та доповнень до такої інформації, забезпечення контролю за реалізацією користувачами веб-порталу та уповноваженими особами веб-порталу прав доступу;

реєстрація уповноважених осіб веб-порталу на веб-порталі, зокрема з використанням засобів електронної ідентифікації, які дають змогу однозначно встановлювати особу;

внесення інформації про можливості для молоді, партнерські можливості для молоді на веб-порталі уповноваженими особами веб-порталу;

інші функціональні можливості, необхідні для виконання завдань веб-порталу.

14. Інформація на веб-портал вноситься уповноваженими особами веб-порталу відповідно до їх прав доступу, визначених адміністратором веб-порталу.

15. Джерелом інформації веб-порталу є дані, які організатори можливостей для молоді, організатори партнерських можливостей для молоді надсилають офіційними листами адміністратору веб-порталу, після чого адміністратор веб-порталу вносить її до бази даних.

16. Суб’єктами веб-порталу є:

власник веб-порталу;

держатель та володілець інформації веб-порталу;

адміністратор веб-порталу;

користувачі веб-порталу.

17. Держатель та володілець інформації веб-порталу здійснює організаційне, технічне та інформаційне забезпечення функціонування веб-порталу, зокрема:

приймає рішення щодо створення, розвитку, модифікації чи модернізації веб-порталу та апаратного забезпечення, на якому він функціонує;

затверджує технічні вимоги та технічні завдання з розроблення, доопрацювання або модернізації програмного забезпечення веб-порталу, погоджує відповідні пропозиції розробників.

18. Адміністратор веб-порталу забезпечує:

безперервне функціонування веб-порталу відповідно до технічної документації;

оновлення та модернізацію програмного забезпечення веб-порталу;

електронну інформаційну взаємодію веб-порталу з іншими державними електронними інформаційними ресурсами;

технічну та інформаційну підтримку користувачів веб-порталу;

проведення моніторингу та контролю функціонування веб-порталу;

захист достовірності, цілісності та безпеки бази даних, апаратного і програмного забезпечення веб-порталу;

здійснення заходів з популяризації веб-порталу;

інші заходи, пов’язані з функціонуванням веб-порталу.

Адміністратор веб-порталу здійснює:

надання доступу користувачів до веб-порталу, зокрема надання прав доступу уповноваженим особам веб-порталу;

облік уповноважених осіб веб-порталу;

наповнення веб-порталу інформацією про можливості для молоді, партнерські можливості для молоді та іншими даними відповідно до встановленого порядку;

розгляд пропозицій (зауважень) щодо удосконалення функціонування веб-порталу;

виявлення програмно-апаратних помилок, надання відповідної інформації розробникам і контроль за їх усуненням;

укладення договорів на обслуговування технічної інфраструктури та залучення сторонніх фахівців;

введення в експлуатацію апаратних, програмних засобів, технічних засобів електронних комунікацій і захисту інформації;

оприлюднення інформації з веб-порталу у формі відкритих даних на Єдиному державному веб-порталі відкритих даних.

19. Для забезпечення контролю за роботою веб-порталу адміністратору веб-порталу надається право перегляду журналу всіх дій та/або подій, доступних на веб-порталі, за допомогою електронної позначки часу.

20. Доступ користувачів веб-порталу до інформації, розміщеної на веб-порталі, може здійснюватися через веб-портал та на Єдиному державному веб-порталі відкритих даних.

21. Користувачі веб-порталу мають право:

безоплатно та цілодобово користуватися веб-порталом;

звертатися до адміністратора веб-порталу з пропозиціями (зауваженнями) щодо функціонування веб-порталу.

22. Робота веб-порталу передбачає:

внесення до бази даних інформації про можливості для молоді, партнерські можливості для молоді, її редагування та видалення;

можливість заповнення форми для подачі партнерських можливостей для молоді;

формування статистичних звітів, що здійснюється на підставі інформації, внесеної до бази даних.

23. Організатори можливостей для молоді зобов’язані протягом трьох робочих днів після появи нових можливостей для молоді надсилати адміністратору веб-порталу офіційний лист, підписаний уповноваженою особою з використанням кваліфікованого електронного підпису або удосконаленого електронного підпису, що базується на кваліфікованому сертифікаті електронного підпису, або електронної ідентифікації з використанням засобів електронної ідентифікації відповідно до схем електронної ідентифікації, або інтегрованої системи електронної ідентифікації, на адресу електронної пошти адміністратора веб-порталу або через систему електронної взаємодії органів виконавчої влади для внесення інформації про можливості для молоді до бази даних. Лист для внесення нових можливостей для молоді до бази даних повинен містити таку інформацію:

найменування організатора можливості для молоді;

назва можливості для молоді;

короткий опис можливості для молоді (до 200 друкованих символів);

посилання на опис щодо процедури отримання можливості для молоді, розміщений на офіційному веб-сайті організатора можливостей для молоді;

тип можливості для молоді: премія, стипендія, бюджетний грант, грант, кредит, компенсація, послуга, стажування, кешбек, конкурс, програма, консультація, фінансування проекту, інше;

напрям можливості для молоді: молодь, спорт, утвердження української національної та громадянської ідентичності, освіта, культура, бізнес, житло, медицина, ветерани, сільське господарство, працевлаштування, соціальний, наука, інше;

розмір фінансової підтримки в межах можливості для молоді (у національній валюті);

для якого віку надається можливість для молоді;

для якої статі передбачена можливість для молоді;

вимоги щодо наявності здобутого рівня освіти або рівня освіти, що здобувається;

обмеження у регіоні надання можливості для молоді;

вимоги щодо стажу роботи;

вимога щодо наявності статусу фізичної особи - підприємця;

вимоги до сімейного стану;

вимоги щодо наявності дітей;

вимоги щодо наявності статусу внутрішньо переміщеної особи;

вимоги до наявності групи інвалідності;

вимоги щодо проходження військової служби;

форма подачі запиту для отримання можливості для молоді: електронна, паперова, змішана;

дата відкриття доступу до можливості для молоді;

граничний строк доступу до можливості для молоді;

нормативно-правові акти, що регулюють питання стосовно можливості для молоді;

нинішній статус можливості для молоді: очікується, діюча, зупинено;

інформацію, що містить символіку комуністичного або націонал-соціалістичного (нацистського) тоталітарного режиму, крім випадків, передбачених Законом України “Про засудження комуністичного та націонал-соціалістичного (нацистського) тоталітарних режимів в Україні та заборону пропаганди їхньої символіки”;

інформацію, що містить пропаганду російського тоталітарного режиму, збройної агресії Російської Федерації як держави-терориста проти України, а також символіку воєнного вторгнення російського тоталітарного режиму, крім випадків, передбачених Законом України “Про заборону пропаганди російського нацистського тоталітарного режиму, збройної агресії Російської Федерації як держави-терориста проти України, символіки воєнного вторгнення російського нацистського тоталітарного режиму в Україну”;

інформацію, що принижує або зневажає державну мову;

інформацію, що заперечує або ставить під сумнів існування українського народу (нації) та/або української державності та/або української мови.

38. Інформація, розміщена на веб-порталі та на Єдиному державному веб-порталі відкритих даних, повинна відповідати меті її внесення на веб-портал, зокрема надання молоді доступу до можливостей для молоді, партнерських можливостей для молоді, її самореалізації та активної участі в суспільному житті.

39. У разі виявлення невідповідності інформації, розміщеної на веб-порталі та на Єдиному державному веб-порталі відкритих даних, вимогам, визначеним пунктами 37 і 38 цього Порядку, після надання до неї доступу користувачам веб-порталу відповідно до прав доступу адміністратор веб-порталу негайно вживає заходів до обмеження доступу користувачів веб-порталу до відповідної інформації та видалення такої інформації з веб-порталу та Єдиного державного веб-порталу відкритих даних.
