20.04.2005 N 106

Зареєстровано в Міністерстві юстиції України 20 квітня 2005 р. за N 424/10704

Про внесення зміни до наказу Міністерства економіки та з питань європейської інтеграції України від 14.04.2005 N 95

На виконання пункту 23 додатка до постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

В абзаці першому пункту 1 наказу Міністерства економіки та з питань європейської інтеграції України від 14.04.2005 N 95 ( z0407-05 ) "Про встановлення граничних рівнів оптово-відпускних цін на дизельне паливо і бензини моторні", зареєстрованого в Міністерстві юстиції України 15.04.2005 за N 407/10687, цифри "01.05.2005" замінити цифрами "01.06.2005".
