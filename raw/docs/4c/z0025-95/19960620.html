Стан: Втратив чинність

Ідентифікатор: z0025-95

Текст документа від 20.06.1996:

МІНІСТЕРСТВО ЕКОНОМІКИ УКРАЇНИ

НАКАЗ

N 1 від 10.01.95 Зареєстровано в Міністерстві м.Київ юстиції України 31 січня 1995 р. за N 25/561

( Наказ втратив чинність на підставі Наказу Мінекономіки N 73 ( z0322-96 ) від 13.06.96 )

Про затвердження Переліку окремих форм діяльності у сфері торгівлі, громадського харчування та послуг, специфіка яких дозволяє здійснювати розрахунки із споживачами без застосування електронних контрольно-касових апаратів з використанням товарно-касових книг

( Із змінами, внесеними згідно з Наказами Мінекономіки N 147 ( z0339-95 ) від 20.09.95 N 11 ( z0044-96 ) від 25.01.96 )

Відповідно до постанови Кабінету Міністрів України від 19.01.94 N 14 ( 14-94-п ) "Про терміни впровадження електронних контрольно-касових апаратів у підприємствах торгівлі, громадського харчування та послуг" НАКАЗУЮ:

1. Затвердити погоджений з МЗЕЗ і Мінфіном Перелік окремих форм діяльності у сфері торгівлі, громадського харчування та послуг, специфіка яких дозволяє здійснювати розрахунки із споживачами без застосування електронних контрольно-касових апаратів з використанням товарно-касових книг (додається).

2. Скасувати наказ Мінекономіки від 21.02.94 N 17 "Про затвердження Переліку окремих форм діяльності у сфері торгівлі, громадського харчування та послуг, специфіка яких дозволяє здійснювати розрахунки із споживачами без застосування контрольно-касових апаратів з використанням товарно-касових книг".

Міністр Р.В.Шпек

Затверджено наказом Міністерства економіки України від 10.01.1995 р. N 1

Перелік окремих форм діяльності у сфері торгівлі, громадського харчування та послуг, специфіка яких дозволяє здійснювати розрахунки із споживачами без застосування електронних контрольно-касових апаратів з використанням товарно-касових книг*

1. Роздрібна торгівля з лотків, корзин, ручних візків, цистерн, транспортних засобів продовольчими і непродовольчими товарами, включаючи торгівлю овочами, фруктами та баштанними культурами, свіжою рибою, квітами, друкованою продукцією. ( Пункт 1 із змінами, внесеними згідно з Наказом Мінекономіки N 11 ( z0044-96 ) від 25.01.96 )

2. Торгівля в кіосках та на літніх майданчиках морозивом, безалкогольними напоями, кулінарними, кондитерськими виробами і молочними продуктами. ( Пункт 2 в редакції Наказу Мінекономіки N 147 (z0339-95 ) від 20.09.95 )

3. Продаж газет, журналів, конвертів, листівок, знаків поштової оплати, торгівля друкованою продукцією в кіосках.

4. Торгівля в їдальнях і буфетах загальноосвітніх шкіл, профтехучилищ, сільськогосподарських підприємств, де середній квартальний прибуток, що залишається в розпоряжденні підприємства громадського харчування, не перевищує середню вартість електронного контрольно-касового апарату вітчизняного виробництва.

5. Торгівля сільськогосподарською продукцією на колгоспних ринках.

6. Надання послуг населенню з видачею квитків, талонів, квитанцій, путівок, застосуванням марок державного мита або інших документів суворої звітності.

7. Торгівля в аптечних кіосках I-II груп у сільській місцевості; торговельне обслуговування на тваринницьких фермах, польових станах, в тракторних бригадах; реалізація населенню отриманої від рубок лісу деревини в держлісгоспах. ( Перелік доповнено пунктом 7 згідно з Наказом Мінекономіки N 11 ( z0044-96 ) від 25.01.96 )

*Використання товарно-касових книг регламентується Порядком ведення товарно-касової книги при розрахунках готівкою у сфері торгівлі, громадського харчування та послуг, затвердженним наказом Мінфіну та Мінстату від 21.11.94 113/252 ( z0288-94 ).
