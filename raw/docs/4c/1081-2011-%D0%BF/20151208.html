{ Постанова втратила чинність на підставі Постанови КМ N 1002 ( 1002-2015-п ) від 05.12.2015 }

Про внесення змін до Статуту Національної акціонерної компанії "Нафтогаз України"

Кабінет Міністрів України постановляє:

1. Внести до Статуту Національної акціонерної компанії "Нафтогаз України", затвердженого постановою Кабінету Міністрів України від 25 травня 1998 р. N 747 ( 747-98-п ) "Про утворення Національної акціонерної компанії "Нафтогаз України", - із змінами, внесеними постановами Кабінету Міністрів України від 2 грудня 2009 р. N 1354 ( 1354-2009-п ) (Офіційний вісник України, 2009 р., N 97, ст. 3364), від 12 жовтня 2010 р. N 935 ( 935-2010-п ) (Офіційний вісник України, 2010 р., N 78, ст. 2767), від 26 січня 2011 р. N 46 ( 46-2011-п ) (Офіційний вісник України, 2011 р., N 6, ст. 280) та від 23 травня 2011 р. N 527 ( 527-2011-п ) (Офіційний вісник України, 2011 р., N 39, ст. 1597), зміни, що додаються.

2. Міністерству енергетики та вугільної промисловості вжити заходів для державної реєстрації змін до Статуту Національної акціонерної компанії "Нафтогаз України", затверджених цією постановою.
