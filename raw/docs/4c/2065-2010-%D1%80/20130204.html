Кабінет Міністрів України; Розпорядження від 03.11.2010 № 2065-р

Про віднесення посад керівних працівників, спеціалістів секретаріату та інспекторів Вищої кваліфікаційної комісії суддів України до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 2065-2010-р

Текст документа від 04.02.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 листопада 2010 р. N 2065-р Київ

Про віднесення посад керівних працівників та спеціалістів секретаріату Вищої кваліфікаційної комісії суддів України до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженням КМ N 48-р ( 48-2013-р ) від 04.02.2013 }

Відповідно до статті 98 Закону України "Про судоустрій і статус суддів" ( 2453-17 ) та статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади керівних працівників та спеціалістів секретаріату Вищої кваліфікаційної комісії суддів України до таких категорій посад державних службовців:

перша - керівник секретаріату Вищої кваліфікаційної комісії суддів України;

друга - заступник керівника секретаріату Вищої кваліфікаційної комісії суддів України, керівник служби дисциплінарних інспекторів, директор департаменту;

третя - заступник керівника служби дисциплінарних інспекторів, заступник директора департаменту, начальник самостійного управління, начальник самостійного відділу, радник голови Вищої кваліфікаційної комісії суддів України, помічник голови Вищої кваліфікаційної комісії суддів України, дисциплінарний інспектор; { Абзац четвертий в редакції Розпорядження КМ N 48-р ( 48-2013-р ) від 04.02.2013 }

четверта - заступник начальника самостійного управління, заступник начальника самостійного відділу, начальник відділу в складі департаменту, начальник відділу в складу управління, заступник начальника відділу в складі департаменту, заступник начальника відділу в складі управління, завідуючий самостійним сектором, помічник-консультант; { Абзац п'ятий в редакції Розпорядження КМ N 48-р ( 48-2013-р ) від 04.02.2013 }

п'ята - завідуючий сектором у складі управління, відділу, головний спеціаліст, головний консультант, провідний спеціаліст, старший консультант, спеціаліст першої категорії, консультант.
