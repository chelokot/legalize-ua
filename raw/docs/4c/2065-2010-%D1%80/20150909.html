Кабінет Міністрів України; Розпорядження від 03.11.2010 № 2065-р

Про віднесення посад керівних працівників, спеціалістів секретаріату та інспекторів Вищої кваліфікаційної комісії суддів України до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 2065-2010-р

Текст документа від 09.09.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 листопада 2010 р. N 2065-р Київ

Про віднесення посад керівних працівників, спеціалістів секретаріату та інспекторів Вищої кваліфікаційної комісії суддів України до відповідних категорій посад державних службовців

{ Назва Розпорядження із змінами, внесеними згідно з Постановою КМ N 644 ( 644-2015-п ) від 02.09.2015 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 48-р ( 48-2013-р ) від 04.02.2013 Постановою КМ N 644 ( 644-2015-п ) від 02.09.2015 }

Відповідно до статей 109 і 110 Закону України "Про судоустрій і статус суддів" ( 2453-17 ) та статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади керівних працівників, спеціалістів секретаріату та інспекторів Вищої кваліфікаційної комісії суддів України до таких категорій посад державних службовців: { Абзац перший із змінами, внесеними згідно з Постановою КМ N 644 ( 644-2015-п ) від 02.09.2015 }

перша - керівник секретаріату Вищої кваліфікаційної комісії суддів України;

друга - заступник керівника секретаріату Вищої кваліфікаційної комісії суддів України, керівник служби інспекторів, директор департаменту; { Абзац третій із змінами, внесеними згідно з Постановою КМ N 644 ( 644-2015-п ) від 02.09.2015 }

третя - ззаступник керівника служби інспекторів, заступник директора департаменту, начальник самостійного управління, начальник самостійного відділу, радник голови Вищої кваліфікаційної комісії суддів України, помічник голови Вищої кваліфікаційної комісії суддів України, інспектор; { Абзац четвертий в редакції Розпорядження КМ N 48-р ( 48-2013-р ) від 04.02.2013; із змінами, внесеними згідно з Постановою КМ N 644 ( 644-2015-п ) від 02.09.2015 }

четверта - заступник начальника самостійного управління, заступник начальника самостійного відділу, начальник відділу в складі департаменту, начальник відділу в складу управління, заступник начальника відділу в складі департаменту, заступник начальника відділу в складі управління, завідувач самостійного сектору, помічник-консультант; { Абзац п'ятий в редакції Розпорядження КМ N 48-р ( 48-2013-р ) від 04.02.2013; із змінами, внесеними згідно з Постановою КМ N 644 ( 644-2015-п ) від 02.09.2015 }

п'ята - завідувач сектору у складі департаменту, управління, відділу, головний спеціаліст, головний консультант, провідний спеціаліст, старший консультант, спеціаліст першої категорії, консультант. { Абзац шостий із змінами, внесеними згідно з Постановою КМ N 644 ( 644-2015-п ) від 02.09.2015 }
