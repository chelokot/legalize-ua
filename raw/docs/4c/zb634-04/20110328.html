ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

17.11.2004 N 489

Зареєстровано в Міністерстві юстиції України 23 грудня 2004 р. за N 1634/10233

Про затвердження Положення про порядок проведення конкурсів з продажу пакетів акцій акціонерних товариств

{ Щодо змін додатково див. Рішення Державної комісії з цінних паперів та фондового ринку N 177 ( zb312-11 ) від 22.02.2011 }

Керуючись підпунктом 67 пункту 4 Положення про Державну комісію з цінних паперів та фондового ринку ( 142/97 ), затвердженого Указом Президента України від 25 вересня 2002 року N 861 ( 861/2002 ), Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Положення про порядок проведення конкурсів з продажу пакетів акцій акціонерних товариств, що додається ( z1634-04 ).

2. Рішення Державної комісії з цінних паперів та фондового ринку від 08.09.2004 N 381 "Про погодження проекту Положення про порядок проведення конкурсів з продажу пакетів акцій акціонерних товариств" скасувати.

3. Контроль за виконанням цього рішення покласти на заступника Виконавчого секретаря О. Петрашка.

Голова Комісії А.Балюк
