ПОСТАНОВА від 10 вересня 2008 р. N 820 Київ

Деякі питання вдосконалення управління підприємствами спиртової та лікеро-горілчаної промисловості

{ Із змінами, внесеними згідно з Постановами КМ N 1127 ( 1127-2008-п ) від 27.12.2008 N 886 ( 886-2020-п ) від 23.09.2020 }

З метою підвищення ефективності функціонування підприємств спиртової та лікеро-горілчаної промисловості, вдосконалення системи управління у зазначеній галузі Кабінет Міністрів України постановляє:

{ Пункт 1 виключено на підставі Постанови КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

2. Погодитися з пропозиціями Міністерства аграрної політики щодо:

ліквідації обласних державних об'єднань, що входять до складу Державного концерну спиртової та лікеро-горілчаної промисловості (концерн "Укрспирт"), крім Київського обласного державного об'єднання спиртової та лікеро-горілчаної промисловості; { Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

{ Абзац третій пункту 2 скасовано як такий, що нереалізований, в частині передачі державного підприємства "Житомирський лікеро-горілчаний завод" до сфери управління Міністерства аграрної політики згідно з Постановою КМ N 886 ( 886-2020-п ) від 23.09.2020 }

передачі державного підприємства "Житомирський лікеро-горілчаний завод" та дочірніх підприємств "Ладижинський завод "Екстра" і "Межирічківський вітамінний завод" державної акціонерної компанії "Укрмедпром" до сфери управління Міністерства аграрної політики.

3. Міністерству аграрної політики:

{ Абзац другий пункту 3 виключено на підставі Постанови КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

здійснити в установленому порядку заходи, пов'язані з ліквідацією обласних державних об'єднань, що входять до складу Державного концерну спиртової та лікеро-горілчаної промисловості (концерн "Укрспирт"). { Абзац третій пункту 3 в редакції Постанови КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

{ Абзац четвертий пункту 3 виключено на підставі Постанови КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

{ Абзац п'ятий пункту 3 виключено на підставі Постанови КМ N 1127 ( 1127-2008-п ) від 27.12.2008 }

4. Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

5. Ця постанова набирає чинності з дня опублікування.
