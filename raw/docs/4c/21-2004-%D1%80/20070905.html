{ Розпорядження втратило чинність на підставі Постанови КМ N 1096 ( 1096-2007-п ) від 05.09.2007 }

Про затвердження членів колегії Міністерства охорони навколишнього природного середовища

Затвердити членами колегії Міністерства охорони навколишнього природного середовища Павленка Володимира Петровича, з правом дорадчого голосу (за згодою) Бойка Віктора Олексійовича, Гладія Михайла Васильовича, Руденка Геннадія Борисовича, Шкірю Ігоря Миколайовича.
