НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

30.09.2005 N 858

Зареєстровано в Міністерстві юстиції України 21 жовтня 2005 р. за N 1244/11524

{ Постанова втратила чинність на підставі Постанови Національної комісії, що здійснює державне регулювання у сферах енергетики та комунальних послуг N 229 ( z0405-17 ) від 27.02.2017 }

Про затвердження Ліцензійних умов провадження господарської діяльності з транспортування нафтопродуктів магістральними трубопроводами

Відповідно до Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ), Положення про Національну комісію регулювання електроенергетики України, затвердженого Указом Президента України від 14.03.95 N 213 ( 213/95 ) (із змінами), та постанови Кабінету Міністрів України від 14.11.2000 N 1698 ( 1698-2000-п ) "Про затвердження переліку органів ліцензування" (із змінами) Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Затвердити Ліцензійні умови провадження господарської діяльності з транспортування нафтопродуктів магістральними трубопроводами, що додаються ( z1244-05 ).

2. Управлінню регулювання та цінової політики нафтогазового комплексу в установленому порядку забезпечити:

надання Ліцензійних умов провадження господарської діяльності з транспортування нафтопродуктів магістральними трубопроводами на затвердження до Державного комітету України з питань регуляторної політики та підприємництва;

опублікування цієї постанови відповідно до чинного законодавства.

3. Суб'єктам господарювання, що провадять діяльність на підставі ліцензії на транспортування нафтопродуктів магістральними трубопроводами, привести свою діяльність у відповідність до вимог Ліцензійних умов провадження господарської діяльності з транспортування нафтопродуктів магістральними трубопроводами протягом трьох місяців з дати набрання чинності цією постановою.

4. Визнати такою, що втратила чинність, постанову НКРЕ від 08.06.2000 N 632 ( z0373-00 ) "Про затвердження Умов та Правил здійснення підприємницької діяльності (ліцензійних умов) з транспортування нафтопродуктів магістральними трубопроводами", зареєстровану в Міністерстві юстиції України 29.06.2000 за N 373/4594.
