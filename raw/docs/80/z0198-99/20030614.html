НАКАЗ

N 157 від 17.03.99 Зареєстровано в Міністерстві м.Київ юстиції України 31 березня 1999 р. vd990317 vn157 за N 198/3491

( Наказ втратив чинність на підставі Наказу Державної митної служби N 129 ( z0424-03 ) від 28.02.2003 )

Про внесення змін до Переліку, затвердженого наказом Державної митної служби України від 27.07.98 N 436

Відповідно до п.1 постанови Кабінету Міністрів України від 02.04.98 N 419 ( 419-98-п ) "Про заходи щодо посилення контролю за ввезенням в Україну окремих видів товарів, що імпортуються суб'єктами підприємницької діяльності" НАКАЗУЮ:

1. Виключити з Переліку товарів, що ввозяться за попередньою вантажною митною декларацією, затвердженого наказом Державної митної служби України від 27.07.98 N 436 ( z0506-98 ), товари, що класифікуються за кодом 4802 відповідно до ТН ЗЕД.

2. Управлінню організації митного контролю (Більчук О.С.), Правовому управлінню (Тимошенко С.В.) забезпечити подання цього наказу в Міністерство юстиції на державну реєстрацію.

3. Управлінню справами (Максимов Ю.Ю.) забезпечити доведення наказу до особового складу митних органів.

4. Прес-центру (Старостін А.А.), начальникам регіональних митниць, начальникам митниць довести наказ до відома суб'єктів ЗЕД і громадян.

5. Контроль за виконанням цього наказу покласти на заступника Голови Служби Соболя І.М.

В.о.Голови Служби О.Єгоров
