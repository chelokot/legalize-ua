Про умови оплати праці працівників притулків для неповнолітніх у мережі служб у справах неповнолітніх

На виконання пункту 3 постанови Кабінету Міністрів України від 09.06.97 N 565 ( 565-97-п ) "Про Типове положення про притулок для неповнолітніх служб у справах неповнолітніх" та відповідно до постанови Кабінету Міністрів України від 29.06.96 N 565 ( 565-96-п ) "Про упорядкування умов оплати праці працівників окремих галузей бюджетної сфери" з наступними змінами та доповненнями до неї НАКАЗУЮ:

1. Затвердити умови оплати праці працівників притулків для неповнолітніх у мережі служб у справах неповнолітніх згідно з умовами оплати праці працівників закладів освіти для тих дітей і підлітків, які потребують соціальної допомоги і реабілітації:

керівних та педагогічних працівників, спеціалістів, службовців, робітників - згідно з умовами оплати праці, передбаченими наказами Міністерства освіти України від 15.04.93 N 102 ( z0056-93 ) "Про затвердження Інструкції про порядок обчислення заробітної плати працівників освіти", від 25.07.96 N 252 ( z0421-96 ) "Про розміри посадових окладів (ставок заробітної плати) працівників закладів освіти" для відповідних працівників спеціальних закладів освіти для дітей і підлітків (з особливим режимом), які потребують особливих умов виховання, з наступними змінами до них щодо зазначених категорій працівників;

медичних працівників - згідно з умовами оплати праці, передбаченими для відповідних працівників наказами Міністерства охорони здоров'я України від 23.11.93 N 229 ( z0198-93 ) "Про затвердження Інструкції про порядок обчислення заробітної плати працівників закладів охорони здоров'я та соціального захисту населення", від 04.09.96 N 274 ( z0529-96 ) "Про затвердження схем посадових окладів (ставок заробітної плати) працівників закладів охорони здоров'я та соціального захисту населення", з наступними змінами та доповненнями до них щодо зазначеної категорії працівників.

2. Затвердити схеми посадових окладів (ставок заробітної плати) керівних та педагогічних працівників, спеціалістів, службовців, робітників і медичних працівників притулків для неповнолітніх служб у справах неповнолітніх згідно з додатками N 1-5.
