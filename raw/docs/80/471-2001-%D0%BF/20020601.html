Кабінет Міністрів України; Постанова від 06.05.2001 № 471

Про доповнення переліку територій, на яких у порядку експерименту застосовується спеціальний торговий патент

Стан: Втратив чинність

Ідентифікатор: 471-2001-п

Текст документа від 01.06.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 травня 2001 р. N 471 Київ

Про доповнення переліку територій, на яких у порядку експерименту застосовується спеціальний торговий патент

( Із змінами, внесеними згідно з Постановою КМ N 735 ( 735-2002-п ) від 01.06.2002 )

Кабінет Міністрів України постановляє:

1. Доповнити перелік територій, на яких у порядку експерименту застосовується спеціальний торговий патент, затверджений постановою Кабінету Міністрів України від 8 червня 1998 р. N 826 ( 826-98-п ) (Офіційний вісник України, 1998 р., N 23, ст. 833, N 25, ст. 928, N 26, ст. 955, N 34, ст. 1278; 1999 р., N 43, ст. 2140) абзацами такого змісту:

"м. Білгород-Дністровський Одеської області

смт Затока Одеської області

смт Сергіївка Одеської області"

2. Встановити термін проведення експерименту із застосування спеціальних торгових патентів на територіях м. Білгорода-Дністровського смт Затоки та смт Сергіївки Одеської області на період до 31 грудня 2006 р. починаючи з дня набрання чинності цією постановою.

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 735 ( 735-2002-п ) від 01.06.2002 )
