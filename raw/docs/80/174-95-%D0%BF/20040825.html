Про сплату вартості послуг, пов'язаних з подачею води на зрошення

Стан: Втратив чинність

Ідентифікатор: 174-95-п

Текст документа від 25.08.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 березня 1995 р. N 174 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1109 ( 1109-2004-п ) від 25.08.2004 )

Про сплату вартості послуг, пов'язаних з подачею води на зрошення

Кабінет Міністрів України постановляє:

Продовжити на 1995 рік чинність постанови Кабінету Міністрів України від 26 квітня 1994 р. N 247 ( 247-94-п ) "Про розмір плати за використання прісних водних ресурсів сільськогосподарськими товаровиробниками" у частині звільнення виробників сільськогосподарської продукції, включаючи тих, що здійснюють зрошення, від сплати постачальникам - підприємствам (організаціям) Державного комітету по водному господарству вартості послуг, пов'язаних з подачею води на зрошення.
