ПОСТАНОВА від 11 березня 2004 р. N 300 Київ

( Постанова втратила чинність на підставі Постанови КМ N 437 ( 437-2005-п ) від 08.06.2005 )

Про затвердження складу Міжвідомчої комісії з міжнародної торгівлі

Кабінет Міністрів України постановляє:

1. Затвердити склад Міжвідомчої комісії з міжнародної торгівлі (додається).

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 16 листопада 2001 р. N 1488 ( 1488-2001-п ) "Про затвердження нового складу Міжвідомчої комісії з міжнародної торгівлі";

постанову Кабінету Міністрів України від 12 вересня 2002 р. N 1335 ( 1335-2002-п ) "Про внесення змін до складу Міжвідомчої комісії з міжнародної торгівлі";

постанову Кабінету Міністрів України від 29 січня 2003 р. N 124 ( 124-2003-п ) "Про внесення змін до складу Міжвідомчої комісії з міжнародної торгівлі";

розпорядження Кабінету Міністрів України від 23 квітня 2003 р. N 249 ( 249-2003-р ) "Про зміну у складі Міжвідомчої комісії з міжнародної торгівлі".
