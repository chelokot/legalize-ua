Текст документа від 01.10.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 лютого 1995 р. N 104 Київ

Про щомісячні компенсаційні виплати деяким категоріям пенсіонерів

( Із змінами, внесеними згідно з Постановами КМ N 411 ( 411-95-п ) від 13.06.95 N 776 ( 776-95-п ) від 02.10.95 )

У зв'язку з подорожчанням продовольчих і непродовольчих товарів, а також електроенергії Кабінет Міністрів України постановляє:

1. Установити з 1 лютого 1995 р. щомісячні компенсаційні виплати в розмірі 890 тис. крб. пенсіонерам, яким пенсії (крім соціальних за віком) призначені органами соціального захисту населення відповідно до Законів України "Про пенсійне забезпечення" ( 1788-12 ), "Про пенсійне забезпечення військовослужбовців та осіб начальницького і рядового складу органів внутрішніх справ" ( 2262-12 ) і "Про статус і соціальний захист громадян, які постраждали внаслідок Чорнобильської катастрофи" ( 796-12 ). Одержувачам соціальних пенсій за віком ці виплати установити в розмірі 50 відсотків зазначеної суми.

( Збільшити з 1 червня 1995 р. щомісячні компенсаційні виплати пенсіонерам (крім тих, які одержують соціальні пенсії за віком), установивши їх в розмірі 1330 тис. карбованців згідно з Постановою КМ N 411 ( 411-95-п ) від 13.06.95 ) ( Збільшити з 1 жовтня 1995 р. в 1,22 раза щомісячні компенсаційні виплати, установивши їх в розмірі 1623 тис. карбованців. Одержувачам соціальних пенсій за віком компенсаційні виплати провадяться в розмірі 812 тис. карбованців згідно з Постановою КМ N 776 ( 776-95-п ) від 02.10.95 )

2. Пенсійному фонду разом з Міністерством фінансів внести до Кабінету Міністрів України пропозиції щодо покриття дефіциту бюджету Пенсійного фонду.

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 11 листопада 1994 р. N 767 ( 767-94-п ) "Про доповнення Переліку видів оплати праці та інших виплат, на які не нараховуються страхові внески та які не враховуються при визначенні середньомісячного заробітку для обчислення пенсій".
