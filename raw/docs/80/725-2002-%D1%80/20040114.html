КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 грудня 2002 р. N 725-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 7-р ( 7-2004-р ) від 14.01.2004 )

Про утворення Міжвідомчої робочої групи з питань удосконалення діяльності санаторно-курортних закладів

1. Утворити Міжвідомчу робочу групу з питань удосконалення діяльності санаторно-курортних закладів.

Затвердити склад Міжвідомчої робочої групи, що додається.

Надати право голові Міжвідомчої робочої групи вносити у разі потреби зміни до її складу.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 7 вересня 2002 р. N 517 ( 517-2002-р ) "Про утворення Міжвідомчої робочої групи з удосконалення роботи санітарно-курортних закладів".
