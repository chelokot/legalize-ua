ПОСТАНОВА від 12 квітня 1993 р. N 270 Київ

( Постанова втратила чинність на підставі Постанови КМ N 285 ( 285-95-п ) від 17.04.95 )

Про внесення змін до постанови Кабінету Міністрів України від 25 жовтня 1991 р. N 282

Кабінет Міністрів України постановляє :

На зміну постанови Кабінету Міністрів України від 25 жовтня 1991 р. N 282 ( 282-91-п ) "Про встановлення плати за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів" (ЗП України 1991 р., N 11, ст. 115) установити плату за видачу дозволу на здійснення діяльності по випуску та обігу цінних паперів у розмірі трьох мінімальних заробітних плат.

В. о. Прем'єр-міністра України В. ПИНЗЕНИК
