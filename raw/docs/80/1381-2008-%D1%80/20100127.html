Про затвердження плану заходів щодо адаптації української економіки до вимог СОТ

{ Із змінами, внесеними згідно з Розпорядженням КМ N 141-р ( 141-2010-р ) від 27.01.2010 }

1. Затвердити план заходів щодо адаптації української економіки до вимог СОТ, що додається.

2. Міністерствам та іншим центральним органам виконавчої влади забезпечити виконання плану заходів, затвердженого цим розпорядженням, та подання щороку до 20 січня Мінекономіки інформації про стан його виконання для узагальнення та інформування до 20 лютого Кабінету Міністрів України.
