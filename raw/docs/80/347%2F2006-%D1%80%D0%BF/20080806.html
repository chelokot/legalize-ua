{ Розпорядження втратило чинність на підставі Указу Президента N 693/2008 ( 693/2008 ) від 06.08.2008 }

Про внесення змін до Розпорядження Президента України від 9 червня 2006 року N 174

На зміну пункту 2 Розпорядження Президента України від 9 червня 2006 року N 174 ( 174/2006-рп ) "Про робочу групу з питань заснування Балто-Чорноморсько-Каспійського банку розвитку":

1) увести до складу робочої групи з питань заснування Балто-Чорноморсько-Каспійського банку розвитку ЯЦЕНЮКА Арсенія Петровича - Першого заступника Глави Секретаріату Президента України - Представника Президента України у Кабінеті Міністрів України, призначивши його керівником робочої групи;

2) вивести зі складу зазначеної робочої групи Васюника І.В., увільнивши його від виконання обов'язків керівника цієї групи.

Президент України В.ЮЩЕНКО

м. Київ, 18 жовтня 2006 року N 347/2006-рп
