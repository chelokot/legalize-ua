Про затвердження Змін до Вимог щодо написання найменування юридичної особи або її відокремленого підрозділу

Стан: Чинний

Ідентифікатор: z0376-06

Текст документа від 23.03.2012:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ПИТАНЬ РЕГУЛЯТОРНОЇ ПОЛІТИКИ ТА ПІДПРИЄМНИЦТВА

НАКАЗ

27.03.2006 N 29

Зареєстровано в Міністерстві юстиції України 3 квітня 2006 р. за N 376/12250

Про затвердження Змін до Вимог щодо написання найменування юридичної особи або її відокремленого підрозділу

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Державного комітету України з питань регуляторної політики та підприємництва N 65 ( z0792-04 ) від 09.06.2004, до якого вносились зміни }

З метою додержання вимог до написання найменування юридичної особи, установлених статтею 90 Цивільного кодексу України ( 435-15 ), статтею 23 Закону України "Про державну реєстрацію юридичних осіб та фізичних осіб-підприємців" ( 755-15 ) та іншими законами, зокрема, статтею 18 Закону України "Про освіту" ( 1060-12 ), яка встановлює вимоги до написання найменування навчальних закладів, НАКАЗУЮ:

1. Затвердити Зміни до Вимог щодо написання найменування юридичної особи або її відокремленого підрозділу, затверджених наказом Держпідприємництва України від 09.06.2004 N 65 ( z0792-04 ) та зареєстрованих Міністерством юстиції України 29.06.2004 за N 792/9391 (із змінами, унесеними наказом Держпідприємництва України від 17.10.2005 N 93 ( z1330-05 ), зареєстрованими в Міністерстві юстиції України 03.11.2005 за N 1330/11610), що додаються.

2. Департаменту реєстрації та ліцензування Держпідприємництва України (Барбелюк О.Б.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на першого заступника Голови Державного комітету України з питань регуляторної політики та підприємництва Ващенка К.А.

Голова А.Дашкевич

ЗАТВЕРДЖЕНО Наказ Держпідприємництва України 27.03.2006 N 29

Зареєстровано в Міністерстві юстиції України 3 квітня 2006 р. за N 376/12250

ЗМІНИ до Вимог щодо написання найменування юридичної особи або її відокремленого підрозділу ( z0792-04 )

Пункт 1.1 викласти в редакції:

"1.1. Юридична особа повинна мати своє найменування. У найменуванні юридичної особи зазначаються її організаційно-правова форма (крім органів державної влади, органів місцевого самоврядування, органів влади Автономної Республіки Крим) та назва. Найменування юридичної особи викладається державною мовою".
