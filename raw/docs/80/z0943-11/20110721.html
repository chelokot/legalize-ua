НАКАЗ

21.07.2011 N 177

Зареєстровано в Міністерстві юстиції України 3 серпня 2011 р. за N 943/19681

Про визнання такими, що втратили чинність, деяких наказів

Відповідно до Законів України "Про радіочастотний ресурс України" ( 1770-14 ), "Про телекомунікації" ( 1280-15 ), Указу Президента України від 30.06.2011 N 717 ( 717/2011 ) "Про Адміністрацію Державної служби спеціального зв'язку та захисту інформації України" та з метою приведення нормативно-правових актів у відповідність до законодавства НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

наказ Державного комітету зв'язку України від 22.08.97 N 124 ( z0564-97 ) "Про затвердження Регламенту аматорського радіозв'язку України", зареєстрований у Міністерстві юстиції України 27.11.97 за N 564/2368;

наказ Державного комітету зв'язку та інформатизації України від 19.02.2001 N 22 ( z0196-01 ) "Про затвердження змін та доповнень до Регламенту аматорського радіозв'язку України", зареєстрований в Міністерстві юстиції України 06.03.2001 за N 196/5387;

наказ Державного комітету зв'язку та інформатизації України від 17.06.2004 N 132 ( z0977-04 ) "Про затвердження Ліцензійних умов провадження діяльності у сфері телекомунікацій з надання послуг фіксованого міжнародного, міжміського, місцевого телефонного зв'язку з правом технічного обслуговування та експлуатації телекомунікаційних мереж і надання в користування каналів електрозв'язку", зареєстрований у Міністерстві юстиції України 05.08.2004 за N 977/9576.

2. Юридичному управлінню Адміністрації Держспецзв'язку подати цей наказ у встановленому порядку на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності з дня його офіційного опублікування.
