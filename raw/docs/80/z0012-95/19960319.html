МІНІСТЕРСТВО ЗОВНІШНІХ ЕКОНОМІЧНИХ ЗВ'ЯЗКІВ УКРАЇНИ

НАКАЗ

N 3 від 19.01.95 Зареєстровано в Міністерстві м.Київ юстиції України 19 січня 1995 р. за N 12/548

( Наказ втратив чинність на підставі Наказу МЗЕЗ N 133-а ( z0124-96, z0117-96 ) від 24.02.96 )

На виконання Указу Президента України від 13.01.95 N 45/95

На виконання Указу Президента України від 13 січня 1995 р. N 45/95 "Про внесення змін до Указу Президента України від 7 листопада 1994 року N 659" та з метою вдосконалення системи обліку (реєстрації) зовнішньоторговельних договорів (контрактів) та подальшої лібералізації і стимулювання зовнішньоекономічної діяльності, НАКАЗУЮ:

1. Установити, що облік (реєстрація) зовнішньоекономічних договорів (контрактів), які укладені суб'єктами зовнішньоекономічної діяльності України всіх форм власності та предметом яких є товари походженням з України, експорт яких здійснюється у рамках бартерних (товарообмінних) операцій, провадиться МЗЕЗ України та уповноваженими ним органами по товарах, зазначених:

- у переліках N 6, N 8, N 9, затверджених наказом МЗЕЗ України від 18.11.94 N 210 (зареєстрованих в Міністерстві юстиції України від 07.12.94 N 291/501) ( z0291-94 );

- у переліку N 7, затвердженого наказом МЗЕЗ України від 18.11.94 N 210 ( z0291-94 ), при здійсненні бартерних (товарообмінних) операцій до країн, перелік яких встановлено у додатку N 1 до наказу МЗЕЗ України від 06.12.94 N 221 (зареєстрованого в Міністерстві юстиції України від 07.12.94 N 295/505) ( z0295-94 ).

2. Установити, що облік (реєстрація) зовнішньоекономічних договорів (контрактів), якими передбачено здійснення бартерних (товарообмінних) операцій суб'єктами зовнішньоекономічної діяльності України, спеціально уповноваженими на це Кабінетом Міністрів України та предметом яких є товари, що підпадають під спеціальний режим експорту окремих видів товарів згідно з Декретами Кабінету Міністрів України "Про встановлення спеціального режиму експорту окремих товарів" від 26.12.92 N 16-92 та "Про державне регулювання виробництва, торгівлі, експорту спирту, напоїв з його використанням і торгівлю тютюновими виробами" від 31.12.92 N 25-92, із змінами, які внесені Декретом Кабінету Міністрів України "Про лібералізацію зовнішньоекономічної діяльності" від 20.05.93 N 54-93, провадиться МЗЕЗ України у порядку, встановленому наказами МЗЕЗ України від 18.11.94 N 210 ( z0291-94 ), від 06.12.94 N 221 ( z0295-94 ) та від 20.12.94 N 232 ( z0314-94 ).

3. Внести доповнення до переліку N 8, затвердженого наказом МЗЕЗ України від 18.11.94 N 210 ( z0291-94 ), включивши до нього чавун переробний - код по ТН ЗЕД 72.01, у зв'язку з застосуванням до цього товару антидемпінгових процедур.

4. Юридичному управлінню (Кузнецов О.В.) забезпечити реєстрацію в Міністерстві юстиції України цього наказу у дводенний термін.

5. Управлінню інформації та стратегічних досліджень (Загорняк О.В.) підготувати та забезпечити публікації цього наказу у газеті "Урядовий Кур'єр" та інших засобах масової інформації в триденний термін після його державної реєстрації.

6. Головному управлінню з питань зовнішньої торгівлі (Віслоух О.В.) забезпечити доведення цього наказу до регіональних управлінь ЗЕЗ України в дводенний термін після його державної реєстрації для подальшого неухильного виконання.

7. Контроль за виконанням цього наказу покласти на Першого заступника Міністра п.Подолєва І.В.

Міністр С.Г.Осика
