Про внесення змін до Правил користування електричною енергією

Згідно з повноваженнями, наданими Законом України "Про електроенергетику" ( 575/97-ВР ) та Указом Президента України від 21.04.98 N 335/98 ( 335/98 ) "Питання Національної комісії регулювання електроенергетики України", на виконання доручення Кабінету Міністрів України від 16.09.03 N 53150 Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

Унести до Правил користування електричною енергією, затверджених постановою НКРЕ від 31.07.96 N 28 ( z0417-96 ), у редакції постанови НКРЕ від 22.08.2002 N 928 ( z0903-02 ) (далі - Правила), такі зміни:

1. Пункт 4.6 Правил після слів "диференційованими за періодами часу" доповнити словами "в тому числі за годинами доби", після слів "власного споживання" доповнити словом "відповідними".

2. Підпункт 13 пункту 11.2 Правил вилучити.
