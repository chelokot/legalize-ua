Про внесення змін до Положення про порядок призначення уповноважених осіб, здійснення ними управління державними корпоративними правами та контролю за їх діяльністю

Стан: Втратив чинність

Ідентифікатор: 886-99-п

Текст документа від 15.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 травня 1999 р. N 886 Київ

( Постанова втратила чинність на підставі Постанови КМ N 791 ( 791-2000-п ) від 15.05.2000 )

Про внесення змін до Положення про порядок призначення уповноважених осіб, здійснення ними управління державними корпоративними правами та контролю за їх діяльністю

Кабінет Міністрів України постановляє:

Внести до Положення про порядок призначення уповноважених осіб, здійснення ними управління державними корпоративними правами та контролю за їх діяльністю, затвердженого постановою Кабінету Міністрів України від 4 листопада 1998 р. N 1741 ( 1741-98-п ) (Офіційний вісник України, 1998 р., N 44, ст. 1634; 1999 р., N 9, ст. 348), зміни, що додаються.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

Інд. 25

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 24 травня 1999 р. N 886

ЗМІНИ, що вносяться до Положення про порядок призначення уповноважених осіб, здійснення ними управління державними корпоративними правами та контролю за їх діяльністю ( 1741-98-п )

1. Абзац восьмий пункту 14 виключити.

2. Пункт 15 доповнити новими абзацами другим та третім такого змісту:

"зобов'язання уповноваженої особи щодо оплати аудиту товариства, проведеного на замовлення Агентства;

зобов'язання уповноваженої особи щодо страхування ризиків невиконання завдань з управління державними корпоративними правами".

У зв'язку з цим абзаци другий - дванадцятий вважати відповідно абзацами четвертим - чотирнадцятим.

3. Абзац сьомий пункту 17 виключити.

4. У пункті 21 друге речення виключити.

5. Пункт 22 виключити.

У зв'язку з цим:

пункт 23 вважати пунктом 22, виклавши його у такій редакції:

"22. Засідання конкурсної комісії є закритими. Рішення про визначення переможця конкурсу вважається правомочним, якщо за нього проголосувало дві третини присутніх членів комісії";

пункти 24 - 33 вважати відповідно пунктами 23 - 32.

6. Пункт 32 викласти у такій редакції:

"32. У разі невиконання або неналежного виконання уповноваженою особою умов договору, вона несе відповідальність згідно з законодавством".
