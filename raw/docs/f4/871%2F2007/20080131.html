Про зупинення дії постанови Кабінету Міністрів України від 11 вересня 2007 року N 1106

{ Додатково див. Конституційне подання Президента ( n0024100-07 ) від 14.09.2007 }

Кабінетом Міністрів України 11 вересня 2007 року видано постанову N 1106 ( 1106-2007-п ) "Питання забезпечення складання списків виборців".

Зазначеною постановою ( 1106-2007-п ) Кабінет Міністрів України з посиланням на частину восьму статті 102-3 Закону України "Про вибори народних депутатів України" ( 1665-15 ) затвердив Порядок передачі даних для забезпечення складання списків виборців.

Як зазначено у пункті 1 Порядку ( 1106-2007-п ), ним визначено механізм передачі міністерствами, іншими центральними органами виконавчої влади інформації, необхідної для складання списків виборців на звичайних виборчих дільницях відповідно до вимог Закону України "Про вибори народних депутатів України" ( 1665-15 ).

Пунктом 2 цього Порядку ( 1106-2007-п ) Міністерству внутрішніх справ України, Міністерству юстиції України, Міністерству праці та соціальної політики України, Пенсійному фонду України, Державній податковій адміністрації України дано низку доручень, які мають бути виконані на етапі підготовки інформації, необхідної для складання списків виборців. При цьому згідно з пунктом 5 Порядку ( 1106-2007-п ) інформація, звірена відповідно до вимог цього Порядку ( 1106-2007-п ), передається територіальними органами міністерств, інших центральних органів виконавчої влади до відповідних робочих груп обліку виборців, окружних виборчих комісій відповідно до вимог Закону України "Про вибори народних депутатів України" ( 1665-15 ).

Між тим відомості про громадян України під час організації позачергових виборів народних депутатів України до відповідної робочої групи обліку виборців згідно з частиною восьмою статті 102-3 Закону України "Про вибори народних депутатів України" ( 1665-15 ), на яку посилається Кабінет Міністрів України у своїй постанові ( 1106-2007-п ), подаються не пізніш як за тридцять днів до дня виборів. Частина дванадцята статті 102-3 Закону України "Про вибори народних депутатів України" ( 1665-15 ) уповноважує робочу групу обліку виборців уточнити списки виборців з використанням зазначених відомостей та зобов'язує її виготовити по два примірники списку виборців на кожній звичайній виборчій дільниці, утвореній у межах відповідної адміністративно-територіальної одиниці, не пізніш як за двадцять днів до дня виборів.

Таким чином, нормативно-правовим актом Кабінету Міністрів України ( 1106-2007-п ) визначено механізм передачі центральними органами виконавчої влади інформації, яка на день видання цього акта вже подана на виконання Закону України "Про вибори народних депутатів України" ( 1665-15 ).

За таких умов приписи постанови ( 1106-2007-п ), про яку йдеться, поширено на правовідносини, які існували до набрання чинності цими приписами, тобто їм надано зворотну дію в часі, що не відповідає частині першій статті 58 Конституції України ( 254к/96-ВР ), за якою закони та інші нормативно-правові акти не мають зворотної дії в часі, крім випадків, коли вони пом'якшують або скасовують відповідальність особи.

Відтак, постанова Кабінету Міністрів України ( 1106-2007-п ) не відповідає й частині другій статті 8, частині другій статті 19 та частині третій статті 113 Основного Закону ( 254к/96-ВР ) держави, за якими Конституція України ( 254к/96-ВР ) має найвищу юридичну силу, нормативно-правові акти мають відповідати їй, органи державної влади зобов'язані діяти у спосіб, що передбачений Конституцією України ( 254к/96-ВР ), Кабінет Міністрів України у своїй діяльності керується Конституцією України ( 254к/96-ВР ).

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 11 вересня 2007 року N 1106 ( 1106-2007-п ) "Питання забезпечення складання списків виборців".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
