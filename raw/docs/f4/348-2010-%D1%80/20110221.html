Кабінет Міністрів України; Розпорядження від 02.03.2010 № 348-р

Про підписання Меморандуму про взаєморозуміння між Кабінетом Міністрів України та Європейською Організацією Ядерних Досліджень (ЦЕРН) стосовно науково-технічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 348-2010-р

Текст документа від 21.02.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 березня 2010 р. N 348-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 151-р ( 151-2011-р ) від 21.02.2011 }

Про підписання Меморандуму про взаєморозуміння між Кабінетом Міністрів України та Європейською Організацією Ядерних Досліджень (ЦЕРН) стосовно науково-технічного співробітництва

{ Із змінами, внесеними згідно з Розпорядженням КМ N 981-р ( 981-2010-р ) від 28.04.2010 }

Схвалити проект Меморандуму про взаєморозуміння між Кабінетом Міністрів України та Європейською Організацією Ядерних Досліджень (ЦЕРН) стосовно науково-технічного співробітництва.

Уповноважити Віце-прем'єр-міністра України Семиноженка Володимира Петровича підписати зазначений Меморандум. { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 981-р ( 981-2010-р ) від 28.04.2010 }
