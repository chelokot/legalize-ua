Про призначення Уповноваженого Кабінету Міністрів України з виконання Угоди між Урядом України та Урядом Угорської Республіки з питань водного господарства на прикордонних водах та його заступників

Стан: Чинний

Ідентифікатор: 511-2008-п

Текст документа від 05.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 червня 2008 р. N 511 Київ

Про призначення Уповноваженого Кабінету Міністрів України з виконання Угоди між Урядом України та Урядом Угорської Республіки з питань водного господарства на прикордонних водах та його заступників

{ Із змінами, внесеними згідно з Постановою КМ N 1347 ( 1347-2011-п ) від 28.12.2011 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 1347 ( 1347-2011-п ) від 28.12.2011 }

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 12 листопада 1993 р. N 920 ( 920-93-п ) "Про призначення уповноваженого Уряду України і його заступників по виконанню Угоди між Урядом України та Урядом Угорської Республіки з питань водного господарства на прикордонних водах";

постанову Кабінету Міністрів України від 18 липня 1998 р. N 1118 ( 1118-98-п ) "Про призначення Уповноваженого Кабінету Міністрів України по виконанню Угоди між Урядом України та Урядом Угорської Республіки з питань водного господавства на прикордонних водах";

постанову Кабінету Міністрів України від 9 серпня 2001 р. N 989 ( 989-2001-п ) "Про призначення заступника Уповноваженого Кабінету Міністрів України по виконанню Угоди між Урядом України та Урядом Угорської Республіки з питань водного господарства на прикордонних водах".
