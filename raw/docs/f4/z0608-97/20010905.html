НАКАЗ

N 126/137 від 02.12.97 Зареєстровано в Міністерстві м.Київ юстиції України 19 грудня 1997 р. vd971202 vn126/137 за N 608/2412

Про затвердження Типової інструкції про порядок списання основних засобів бюджетних установ

( Із змінами, внесеними згідно з Наказом Державного казначейства N 142/181 ( z0787-01 ) від 10.08.2001 )

З метою встановлення єдиних вимог до порядку списання основних засобів установами та організаціями, які утримуються за рахунок державного або місцевих бюджетів, НАКАЗУЄМО:

1. Затвердити Типову інструкцію про порядок списання основних засобів бюджетних установ (додається).

2. Міністерствам, іншим центральним органам виконавчої влади видати у разі необхідності галузеві інструкції по списанню основних засобів, узгодивши їх з чинним законодавством і даною Типовою інструкцією.

3. Вважати такою, що не застосовується "Типовую инструкцию о порядке списания пришедших в негодность зданий, сооружений, машин, оборудования, транспортных средств и другого имущества, относящегося к основным средствам (фондам)" від 01.07.85 р. N 100 ( v0100400-85 ), затверджену Міністерством фінансів СРСР і Державним плановим комітетом СРСР в частині, що стосується бюджетних установ, організацій.

Заступник Міністра фінансів- начальник Головного управління Державного казначейства України П.Г.Петрашко

Перший заступник Міністра економіки України В.Я.Шевчук

( Типова інструкція про порядок списання основних засобів бюджетних установ втратила чинність на підставі Наказу Державного казначейства N 142/181 ( z0787-01 ) від 10.08.2001 )
