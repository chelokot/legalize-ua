УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 506/2010 ( 506/2010 ) від 06.04.2010 }

Про внесення змін до Указу Президента України від 21 січня 2008 року N 43

Відповідно до частини четвертої статті 107 Конституції України ( 254к/96-ВР ) постановляю:

На часткову зміну Указу Президента України від 21 січня 2008 року N 43 ( 43/2008 ) "Про склад Ради національної безпеки і оборони України" ввести до складу Ради національної безпеки і оборони України КИРИЧЕНКА Сергія Олександровича - начальника Генерального штабу - Головнокомандувача Збройних Сил України, генерала армії України.

Президент України В.ЮЩЕНКО
