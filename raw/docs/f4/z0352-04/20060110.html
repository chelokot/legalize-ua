( Наказ втратив чинність на підставі Наказу Міністерства економіки N 520 ( z1592-05 ) від 20.12.2005 )

Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 21.12.2001 N 317

На виконання постанови Кабінету Міністрів України від 11.02.2004 N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства економіки та з питань європейської інтеграції України від 21.12.2001 N 317 ( z1084-01 ) "Про встановлення розмірів посадових окладів (ставок заробітної плати) працівників Вищих курсів іноземних мов при Міністерстві економіки та з питань європейської інтеграції України", зареєстрованого у Міністерстві юстиції України 27.12.2001 за N 1084/6275, із змінами, унесеними наказом Міністерства економіки та з питань європейської інтеграції України від 13.08.2003 N 218 ( z0725-03 ), зареєстрованим у Міністерстві юстиції України 19.08.2003 за N 725/8046, виклавши додатки 1-3 в редакції, що додається.

2. Установити керівним, науково-педагогічним, педагогічним та іншим працівникам Вищих курсів іноземних мов при Міністерстві економіки та з питань європейської інтеграції України посадові оклади (ставки заробітної плати) у розмірах, визначених у додатках 1-3 цього наказу.

3. Контроль за виконанням цього наказу покласти на директора адміністративно-господарського департаменту Дробного В.В.
