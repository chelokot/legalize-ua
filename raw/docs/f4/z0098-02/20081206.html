НАКАЗ

N 16 від 21.01.2002 Зареєстровано в Міністерстві м. Київ юстиції України 4 лютого 2002 р. за N 98/6386

{ Наказ втратив чинність на підставі Наказу Міністерства охорони здоров'я N 510 ( z1126-08 ) від 02.09.2008 }

Про внесення змін і доповнень до Переліку захворювань, які дають право на усиновлення хворих дітей без дотримання строків їх перебування на обліку в Центрі з усиновлення дітей при Міністерстві освіти і науки України

( Із змінами, внесеними згідно з Наказом Міністерства охорони здоров'я

N 467 ( z0982-02 ) від 12.12.2002 - набуває чинності

одночасно з набранням чинності Сімейним кодексом ( 2947-14 )

У зв'язку з поліпшенням надання спеціалізованої медичної допомоги дітям у закладах охорони здоров'я та відповідно до статті 283 Сімейного кодексу України ( 2947-14 ) НАКАЗУЮ:

( Преамбула в редакції Наказу Міністерства охорони здоров'я N 467 ( z0982-02 ) від 12.12.2002 - набуває чинності одночасно з набранням чинності Сімейним кодексом ( 2947-14 )

1. Унести зміни та доповнення до Переліку захворювань, які дають право на усиновлення хворих дітей без дотримання строків їх перебування на обліку в Центрі з усиновлення дітей при Міністерстві освіти і науки України, затвердженого наказом Міністерства охорони здоров'я України від 4 січня 1997 року за N 2 ( z0140-97 ) та зареєстрованого в Міністерстві юстиції України 16 квітня 1997 року за N 140/1944, виклавши його в новій редакції, що додається.

2. Міністру охорони здоров'я Автономної Республіки Крим, начальникам управлінь охорони здоров'я обласних, Севастопольської міської державних адміністрацій, Головного управління охорони здоров'я Київської міської державної адміністрації:

2.1. Забезпечити постійний контроль за правильністю застосування Переліку захворювань, які дають право на усиновлення хворих дітей без дотримання строків їх перебування на обліку в Центрі з усиновлення дітей при Міністерстві освіти і науки України ( z0140-97 ).

2.2. Посилити контроль за достовірністю оформлення висновку про стан здоров'я, фізичний та розумовий розвиток дитини, яка може бути усиновлена.

3. Контроль за виконанням цього наказу покласти на заступника Державного секретаря Гойду Н.Г.

Міністр В.Ф.Москаленко
