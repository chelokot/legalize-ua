ПОСТАНОВА від 24 червня 2009 р. N 710 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про внесення зміни до постанови Кабінету Міністрів України від 14 жовтня 2008 р. N 925

Кабінет Міністрів України постановляє:

У пунктах 4 і 5 постанови Кабінету Міністрів України від 14 жовтня 2008 р. N 925 ( 925-2008-п ) "Про першочергові заходи щодо стабілізації ситуації, що склалася в гірничо-металургійному та хімічному комплексі" (Офіційний вісник України, 2008 р., N 81, ст. 2731, N 100, ст. 3348; 2009 р., N 27, ст. 908) та назві додатка 3 до зазначеної постанови ( 925-2008-п ) слова і цифри "до 1 липня 2009 р." замінити словами і цифрами "до 1 жовтня 2009 р.".
