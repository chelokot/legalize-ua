Питання Міністерства оборони

Стан: Втратив чинність

Ідентифікатор: 476-2011-р

Текст документа від 13.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 травня 2011 р. N 476-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 937 ( 937-2011-п ) від 07.09.2011 }

Питання Міністерства оборони

1. Затвердити граничну чисельність працівників і військовослужбовців центрального апарату Міністерства оборони у кількості 770 осіб, з них 150 військовослужбовців.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 28 липня 2010 р. N 1570 ( 1570-2010-р ) "Питання Міністерства оборони" (Офіційний вісник України, 2010 р., N 57, ст. 1973).

Прем'єр-міністр України М.АЗАРОВ
