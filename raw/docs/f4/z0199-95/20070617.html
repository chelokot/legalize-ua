ГОЛОВНЕ АРХІВНЕ УПРАВЛІННЯ ПРИ КАБІНЕТІ МІНІСТРІВ УКРАЇНИ МІНІСТЕРСТВО ВНУТРІШНІХ СПРАВ УКРАЇНИ

Про затвердження Положення про Галузевий державний архів Міністерства внутрішніх справ України

{ Із змінами, внесеними згідно з Наказом Держархіву N 33/317 ( z0405-01 ) від 26.04.2001 Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

Відповідно до Закону України "Про Національний архівний фонд і архівні установи" ( 3814-12 ) та постанови Кабінету Міністрів України від 20 березня 1995 року N 192 ( 192-95-п ) НАКАЗУЄМО:

Затвердити Положення про Галузевий державний архів Міністерства внутрішніх справ України (додається).

В.О. Начальника Головного архівного управління при Кабінеті Міністрів України В.С.Лозицький

Міністр внутрішніх справ України Л.В.Бородич

Затверджено наказом Головного архівного управління при Кабінеті Міністрів України та Міністерства внутрішніх справ України від 6 червня 1995 року N 34/382

Положення про Галузевий державний архів Міністерства внутрішніх справ України

( У тексті Положення слова "військах внутрішньої та конвойної охорони" замінено на слова "внутрішніх військах" згідно з Наказом Держархіву N 33/317

( z0405-01 ) від 26.04.2001 )

( У тексті Положення слово "Головархів" замінено на слова "Державний комітет архівів" згідно з Наказом Держархіву N 33/317 ( z0405-01 ) від 26.04.2001 )

1. Галузевий державний архів Міністерства внутрішніх справ України (надалі - Архів) створений відповідно до Закону України "Про Національний архівний фонд та архівні установи" ( 3814-12 ) та постанови Кабінету Міністрів України від 20 березня 1995 року N 192 ( 192-95-п ). Він є архівною установою, що входить у систему Міністерства внутрішніх справ на правах відділу управління центрального апарату МВС України.

Архів ліквідується за рішенням Кабінету Міністрів України.

{ Пункт 1 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

2. Архів у своїй діяльності керується Конституцією України ( 888-09 ), законами України, постановами Верховної Ради України, указами й розпорядженнями Президента України, декретами, постановами й розпорядженнями Кабінету Міністрів України, наказами Головного архівного управління при Кабінеті Міністрів України (Державного комітету архівів України), Міністерства внутрішніх справ України, а також цим Положенням.

Нормативно-методичне забезпечення та контроль за збереженістю й користуванням документами Архіву покладається на Державний комітет архівів України та МВС України. { Абзац другий пункту 2 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

3. Архів здійснює приймання, облік, зберігання документів, що утворилися в процесі діяльності органів, підрозділів, внутрішніх військ МВС України, та створює умови для їх використання.

Він є науково-методичним центром з питань організації роботи з архівними документами, які тимчасово зберігаються в органах, підрозділах, внутрішніх військах МВС України.

4. До документів, що підлягають постійному зберіганню в Архіві, відносяться документи, які утворилися в процесі оперативно-розшукової та іншої спеціальної діяльності органів, підрозділів, внутрішніх військ МВС України, страхові копії цих документів та довідковий апарат до них. { Пункт 4 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

5. До документів, що підлягають тимчасовому зберіганню в Архіві, відносяться:

5.1. Документи загального провадження, які утворилися в процесі діяльності органів, підрозділів, внутрішніх військ МВС України.

5.2. Документи з особового складу органів, підрозділів, внутрішніх військ МВС України. { Підпункт 5.2 пункту 5 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

5.3. Фонди особистого походження ветеранів органів, підрозділів, внутрішніх військ МВС України.

5.4. Закриті кримінальні справи, справи протокольного провадження.

5.5. Особові справи осіб, які під час перебування в місцях позбавлення волі, ЛТП втратили працездатність або померли.

5.6. Документи ліквідованих органів, підрозділів, військових частин внутрішніх військ МВС України.

5.7. Службові відомчі видання.

5.8. Довідковий апарат до документів Архіву. { Підпункт 5.8 пункту 5 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

6. Види документів та строки їх передачі до державних архівів визначаються МВС України за погодженням з Державним комітетом архівів України.

7. Головним завданням Архіву є:

7.1. Забезпечення збереженості документів, що знаходяться на зберіганні в Архіві, та створення необхідних умов для користування ними. { Підпункт 7.1 пункту 7 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

7.2. Контроль за збереженістю документів, що тимчасово зберігаються в органах, підрозділах, внутрішніх військах МВС України. { Підпункт 7.2 пункту 7 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

7.3. Комплектування Архіву документами.

7.4. Створення й вдосконалення облікового та довідкового апарату до документів Архіву. { Підпункт 7.4 пункту 7 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

7.5. Ведення державного обліку документів Національного архівного фонду та подання відомостей Державного комітету архівів України. { Підпункт 7.5 пункту 7 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

7.6. Контроль та організаційно-методичне забезпечення роботи з архівними документами в органах, підрозділах, внутрішніх військах МВС України.

7.7. Видання, у межах своєї компетенції, обов'язкових для виконання органами, підрозділами, внутрішніми військами МВС України методичних посібників з архівної справи.

7.8. Участь у виявленні документів історико-культурної спадщини України, що перебувають за кордоном, їх поверненні або відтворенні в копіях.

7.9. Робота з власниками документів особового походження щодо передачі їх на зберігання до Архіву. { Підпункт 7.9 пункту 7 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

7.10. Передача до державних архівів України документів Національного архівного фонду, які не відносяться до оперативно-розшукової діяльності органів, підрозділів, внутрішніх військ МВС України.

7.11. Робота щодо віднесення документів Національного архівного фонду до унікальних. { Підпункт 7.11 пункту 7 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

7.12. Виконання запитів органів державної влади й місцевого самоврядування, наукових, культурних та інших закладів, підприємств, установ, організацій, громадян та їх об'єднань про наявність документів, що їх цікавлять. Видача копій документів і архівних довідок.

7.13. Надання відвідувачам для користування в читальному залі Архіву документів або їх копій з урахуванням Законів України "Про Національний архівний фонд та архівні установи" ( 3814-12 ), "Про інформацію" ( 2657-12 ) та "Про державну таємницю" ( 3855-12 ). { Підпункт 7.13 пункту 7 із змінами, внесеними згідно з Наказом Державного комітету архівів N 83/163 ( z0588-07 ) від 25.05.2007 }

7.14. Публікація згідно з чинним законодавством документів, що знаходяться на зберіганні, надання їх для виставок, використання в засобах масової інформації.

7.15. Здійснення заходів для підвищення кваліфікації працівників Архіву, а також осіб, відповідальних за роботу з документами в органах, підрозділах, внутрішніх військах МВС України. Проведення нарад та семінарів.

8. Архів має право:

8.1. Одержувати від органів, підрозділів, внутрішніх військ МВС України відомості про роботу з архівними документами.

8.2. Перевіряти стан роботи з архівними документаму в органах, підрозділах, внутрішніх військах МВС України, доповідати безпосередньо їх керівникам про недоліки в зазначеній роботі та вимагати вжиття заходів для її поліпшення.

8.3. Визначати, відповідно до чинного законодавства, порядок користування документами, що зберігаються в Архіві.

8.4. Давати, в межах своїх повноважень, обов'язкові для виконання вказівки щодо організації роботи з документами в органах, підрозділах, внутрішніх військах МВС України.

8.5. Розробляти, за погодженням з Державним комітетом архівів України, нормативно-методичні документи з архівної справи, контролювати їх виконання в органах, підрозділах, внутрішніх військах охорони МВС України.

8.6. Залучати, за погодженням з керівництвом МВС України, до роботи над науковими темами й методичними посібниками інші установи з відповідною оплатою праці їх співробітників.

9. Архів забезпечується відповідними штатами, приміщеннями, технологічним обладнянням, матеріальними та фінансовими ресурсами за рахунок кошторису Міністерства внутрішніх справ України.

10. Архів має печатку з відображенням назви "Державних архів Міністерства внутрішніх справ України".

11. Архів очолює начальник, який призначається та звільняється з посади першим заступником Міністра внутрішніх справ України. ( Пункт 11 із змінами, внесеними згідно з Наказом Держархіву N 33/317 ( z0405-01 ) від 26.04.2001 )

12. Начальник Архіву:

12.1. Організує діяльність Архіву, персонально відповідає за виконання покладених на нього завдань.

12.2. Розподіляє обов'язки між працівниками Архіву, які закріплюються в їх посадових інструкціях.

12.3. Вирішує, в межах своєї компетенції, питання про доступ до документів працівників органів, підрозділів, внутрішніх військ МВС України, представників інших підприємств, установ, організацій, об'єднань громадян та приватних осіб.

12.4. Провадить прийом громадян та розглядає заяви, що належать до компетенції Архіву.

12.5. Представляє Архів з усіх питань, пов'язаних з його діяльністю.

13. Для організації й проведення експертизи цінності документів з метою віднесення їх до Національного архівного фонду в Архіві створюється експертно-перевірна комісія (ЕПК). Положення про ЕПК та її персональний склад затверджується МВС України та Державним комітетом архівів України.
