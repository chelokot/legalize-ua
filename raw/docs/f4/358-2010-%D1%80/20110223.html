Про передачу Державному спеціалізованому підприємству "Укрспецторг" майна військового містечка N 266

Стан: Втратив чинність

Ідентифікатор: 358-2010-р

Текст документа від 23.02.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 березня 2010 р. N 358-р Київ

{ Розпорядження скасовано на підставі Розпорядження КМ N 136-р ( 136-2011-р ) від 23.02.2011 }

Про передачу Державному спеціалізованому підприємству "Укрспецторг" майна військового містечка N 266

Прийняти пропозицію Міністерства оборони про передачу Державному спеціалізованому підприємству "Укрспецторг" майна військового містечка N 266, розташованого по пров. Бородянському, 3, у м. Києві, згідно з додатком із закріпленням такого майна на праві господарського відання.

Міністерству оборони забезпечити у місячний строк передачу зазначеного майна Державному спеціалізованому підприємству "Укрспецторг".

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 29
