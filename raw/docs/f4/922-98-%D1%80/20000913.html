Кабінет Міністрів України; Розпорядження від 12.11.1998 № 922-р

Про закріплення у державній власності пакету акцій ДАЕК "Житомиробленерго"

Стан: Втратив чинність

Ідентифікатор: 922-98-р

Текст документа від 13.09.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 листопада 1998 р. N 922-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 353-р ( 353-2000-р ) від 13.09.2000 )

Про закріплення у державній власності пакету акцій ДАЕК "Житомиробленерго"

1. Відповідно до пункту 14 Державної програми приватизації на 1998 рік ( 124/98-ВР ) закріпити у державній власності на 5 років пакет акцій у розмірі 50 відсотків статутного фонду плюс одна акція ДАЕК "Житомиробленерго".

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 3 липня 1998 р. N 519 ( 519-98-р ).
