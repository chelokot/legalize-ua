25.03.2004 N 27

( Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 331 ( v0331359-04 ) від 06.08.2004 )

Про штатний розпис Центральної виборчої комісії та автогосподарства Центральної виборчої комісії

Керуючись статтями 11, 12 та 27 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ), відповідно до постанови Кабінету Міністрів України від 13 грудня 1999 року N 2288 ( 2288-99-п ) "Про впорядкування умов оплати праці працівників апарату органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів", постанов Центральної виборчої комісії від 6 березня 2004 року N 18 ( v0018359-04 ) "Про структуру і чисельність Секретаріату Центральної виборчої комісії та автогосподарства Центральної виборчої комісії", від 25 березня 2004 року N 26 ( v0026359-04 ) "Про внесення змін до структури Секретаріату Центральної виборчої комісії, затвердженої постановою Центральної виборчої комісії від 6 березня 2004 року N 18", наказу Міністерства праці України від 2 жовтня 1996 року N 77 ( z0593-96 ) "Про умови оплати праці робітників, зайнятих обслуговуванням органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів" та Угоди між Міністерством транспорту України і профспілками працівників автомобільного транспорту України по галузі автомобільного транспорту на 2002-2003 роки із змінами та доповненнями Центральна виборча комісія постановляє:

Затвердити штатний розпис Центральної виборчої комісії та автогосподарства Центральної виборчої комісії (додатки 1, 2*).
