Про організацію будівництва інфраструктурних об'єктів Київського регіону

Стан: Чинний

Ідентифікатор: 313-2011-р

Текст документа від 03.07.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 квітня 2011 р. N 313-р Київ

Про організацію будівництва інфраструктурних об'єктів Київського регіону

{ Із змінами, внесеними згідно з Постановами КМ N 982 ( 982-2011-п ) від 19.09.2011 N 418 ( 418-2015-п ) від 17.06.2015 }

1. Погодитися з пропозицією Державного агентства з інвестицій та управління національними проектами щодо реалізації проекту "Інфраструктурні об'єкти Київського регіону" (далі - проект).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 418 ( 418-2015-п ) від 17.06.2015 }

2. Узяти до відома, що:

складовими проекту є об'єкти:

- міська кільцева автомобільна дорога навколо м. Києва від вул. Столичне шосе до автомобільної дороги М-03 Київ - Харків - Довжанський на ділянці Київ - Бориспіль;

- будівництво дороги від Подільського мостового переходу через р. Дніпро до просп. Ватутіна з будівництвом транспортної розв'язки на примиканні в урочищі Горбачиха до Подільського мостового переходу через р. Дніпро у м. Києві;

заходи з підготовки до реалізації складових проекту (виготовлення техніко-економічних обґрунтувань) здійснюються протягом 2011 року;

реалізація складових проекту здійснюється після схвалення Кабінетом Міністрів України техніко-економічних обґрунтувань складових проектів із визначенням джерел фінансування (в тому числі за рахунок довгострокових зовнішніх запозичень під державні гарантії України);

проект реалізується у строки, визначені техніко-економічними обґрунтуваннями складових проекту;

функції замовника з реалізації складових проекту покладаються на державне підприємство "Дирекція з будівництва та управління національного проекту "Повітряний експрес" та інших інфраструктурних об'єктів Київського регіону.

{ Пункт 2 в редакції Постанови КМ N 982 ( 982-2011-п ) від 19.09.2011 }

3. Міністерству інфраструктури забезпечити проведення в установленому порядку комплексної державної експертизи проекту.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 418 ( 418-2015-п ) від 17.06.2015 }

4. Міністерству економічного розвитку і торгівлі та Міністерству фінансів розглянути під час погодження техніко-економічного обґрунтування проекту питання щодо залучення кредиту для реалізації проекту під державні гарантії.

5. Державному агентству земельних ресурсів, Державному агентству лісових ресурсів, Київській міській і Київській обласній держадміністраціям вирішити в установленому порядку питання щодо виділення земельних ділянок для будівництва інфраструктурних об'єктів Київського регіону.

Прем'єр-міністр України М.АЗАРОВ
