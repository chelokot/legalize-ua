Деякі питання подальшого розвитку вітроенергетики

Стан: Чинний

Ідентифікатор: 705-2009-п

Текст документа від 02.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 липня 2009 р. N 705 Київ

Деякі питання подальшого розвитку вітроенергетики

{ Із змінами, внесеними згідно з Постановою КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Кабінет Міністрів України постановляє:

1. Покласти на Національне агентство з питань забезпечення ефективного використання енергетичних ресурсів координацію роботи з виконання Комплексної програми будівництва вітрових електростанцій, схваленої постановою Кабінету Міністрів України від 3 лютого 1997 р. N 137 ( 137-97-п ) (Офіційний вісник України, 1997 р., число 8, с. 139).

{ Пункт 2 втратив чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

3. Національному агентству з питань забезпечення ефективного використання енергетичних ресурсів разом з Національним космічним агентством, Міністерством фінансів і Міністерством економіки розробити та подати у тримісячний строк Кабінетові Міністрів України пропозиції про внесення змін до Комплексної програми будівництва вітрових електростанцій ( 137-97-п ).

4. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 28 березня 2007 р. N 557 ( 557-2007-п ) "Про подальший розвиток вітроенергетики в Україні" (Офіційний вісник України, 2007 р., N 24, ст. 985).
