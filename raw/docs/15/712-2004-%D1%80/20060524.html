Кабінет Міністрів України; Розпорядження від 08.10.2004 № 712-р

Про встановлення строку виконання операцій з ремонту та будівництва (складання) залізничних пасажирських вагонів

Стан: Втратив чинність

Ідентифікатор: 712-2004-р

Текст документа від 24.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 жовтня 2004 р. N 712-р Київ

Про встановлення строку виконання операцій з ремонту та будівництва (складання) залізничних пасажирських вагонів

{ Із змінами, внесеними згідно з Розпорядженням КМ N 277-р ( 277-2006-р ) від 17.05.2006 }

1. Відповідно до статті 232 Митного кодексу ( 92-15 ) установити, що строк виконання операцій з ремонту та будівництва (складання) залізничних пасажирських вагонів за кодом згідно з УКТЗЕД ( 2371г-14 ) 8605 00 00 00 не може перевищувати 360 днів з дати оформлення ввізної вантажної митної декларації.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 277-р ( 277-2006-р ) від 17.05.2006 }

2. Це розпорядження набирає чинності з дня опублікування.
