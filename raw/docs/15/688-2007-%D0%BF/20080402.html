КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 травня 2007 р. N 688 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки Державного камерного ансамблю "Київські солісти"

{ Із змінами, внесеними згідно з Постановою КМ N 298 ( 298-2008-п ) від 02.04.2008 }

{ Установити, що у 2008 році кошти, передбачені у державному бюджеті ( 107-17 ) Державному управлінню справами за програмою "Фінансова підтримка Державного камерного ансамблю "Київські солісти", використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 298 ( 298-2008-п ) від 02.04.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки Державного камерного ансамблю "Київські солісти", що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 3 травня 2007 р. N 688

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки Державного камерного ансамблю "Київські солісти"

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Державному управлінню справами за програмою "Фінансова підтримка Державного камерного ансамблю "Київські солісти" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Державне управління справами, а їх одержувачем - Державний камерний ансамбль "Київські солісти" (далі - ансамбль).

3. Бюджетні кошти спрямовуються на забезпечення статутної діяльності ансамблю, зокрема на провадження концертно-гастрольної діяльності, збереження та популяризацію світової і національної музичної спадщини в Україні та за кордоном.

4. Бюджетні кошти використовуються Державним управлінням справами у межах бюджетних призначень, установлених Законом України "Про Державний бюджет України на 2008 рік та про внесення змін до деяких законодавчих актів України" ( 107-17 ), з урахуванням необхідності виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державного казначейства, у разі їх відповідності паспорту бюджетної програми.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 298 ( 298-2008-п ) від 02.04.2008 }

5. Обсяг фінансової підтримки ансамблю, що надається для покриття поточних витрат, не забезпечених їх власними доходами, не повинен перевищувати 95 відсотків фактичного обсягу валового доходу за підсумками року.

Розрахунок для визначення обсягу фінансової підтримки подається ансамблем щокварталу до 10 числа наступного місяця Державному управлінню справами, яке визначає розмір фінансової підтримки ансамблю для подання Мінфіну до 10 грудня поточного року.

6. У разі зменшення бюджетних призначень Державне управління справами з метою недопущення виникнення кредиторської заборгованості на кінець року здійснює відповідне коригування суми видатків з фінансової підтримки ансамблю.

7. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

8. Державне управління справами затверджує результативні показники діяльності ансамблю з поквартальною розбивкою та подає Мінфіну у двотижневий строк після затвердження розпису державного бюджету.

Інформація про виконання зазначених показників подається Державним управлінням справами Мінфіну щокварталу у тижневий строк після закінчення звітного періоду та за результатами їх виконання за одинадцять місяців.

11. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
