КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 квітня 2004 р. N 580 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

Про внесення змін до пункту 2 постанови Кабінету Міністрів України від 14 лютого 1998 р. N 144

Кабінет Міністрів України постановляє:

1. Внести до пункту 2 постанови Кабінету Міністрів України від 14 лютого 1998 р. N 144 ( 144-98-п ) "Питання забезпечення діяльності Центральної виборчої комісії" (Офіційний вісник України, 1998 р., N 7, ст. 243) такі зміни:

слова "прес-секретарю" замінити словами "помічникам заступника Голови Комісії, секретаря Комісії та її членів; керівнику прес-служби";

доповнити пункт абзацом такого змісту:

"Установити членам Комісії, керівнику її секретаріату, начальникам управлінь та завідуючим самостійних відділів секретаріату надбавку за особливі умови роботи в розмірі 100 відсотків посадового окладу з урахуванням доплати за ранг та вислугу років".

2. Міністерству фінансів під час підготовки пропозицій стосовно внесення змін до Закону України "Про Державний бюджет України на 2004 рік" ( 1344-15 ) вирішити питання щодо виділення коштів, необхідних для виконання цієї постанови.

Прем'єр-міністр України В.ЯНУКОВИЧ
