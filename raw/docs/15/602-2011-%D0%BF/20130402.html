{ Постанова втратила чинність на підставі Постанови КМ N 180 ( 180-2013-п ) від 13.03.2013 }

Про внесення зміни до складу Митно-тарифної ради України

Кабінет Міністрів України постановляє:

Внести зміну до складу Митно-тарифної ради України, затвердженого постановою Кабінету Міністрів України від 29 грудня 2005 р. N 1299 ( 1299-2005-п ) "Деякі питання Митно-тарифної ради України" (Офіційний вісник України, 2005 р., N 52, ст. 3334; 2006 р., N 7, ст. 360), замінивши слова "Міністр економіки" словами "Перший віце-прем'єр-міністр України - Міністр економічного розвитку і торгівлі".
