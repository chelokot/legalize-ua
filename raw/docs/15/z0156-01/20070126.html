ГОЛОВНЕ КОНТРОЛЬНО-РЕВІЗІЙНЕ УПРАВЛІННЯ УКРАЇНИ

НАКАЗ

N 11 від 07.02.2001 Зареєстровано в Міністерстві юстиції України 22 лютого 2001 р. за N 156/5347

Про затвердження Типового положення про контрольно-ревізійний підрозділ

{ Із змінами, внесеними згідно з Наказами Головного контрольно-ревізійного управління N 74 ( z0750-01 ) від 16.08.2001 N 320 ( z1575-04 ) від 29.11.2004 N 409 ( z0020-07 ) від 18.12.2006 }

На виконання Указу Президента України від 28.11.2000 N 1265/2000 ( 1265/2000 ) "Про Положення про Головне контрольно-ревізійне управління України" НАКАЗУЮ:

1. Затвердити Типове положення про Контрольно-ревізійний відділ у районі, місті, районі в місті та міжрайонний контрольно-ревізійний відділ без статусу юридичної особи ( z0157-01 ) (додаються). { Пункт 1 із змінами, внесеними згідно з Наказом Головного контрольно-ревізійного управління N 409 ( z0020-07 ) від 18.12.2006 }

2. Начальникам контрольно-ревізійних управлінь в Автономній Республіці Крим, областях, містах Києві і Севастополі на підставі затверджених цим наказом типових положень підготувати нові редакції положень про контрольно-ревізійні підрозділи. Положення про контрольно-ревізійні відділи у районах, містах, районах у містах, міжрайонні контрольно-ревізійні відділи зі статусом юридичної особи у 2 примірниках до 15.03.2001 подати до ГоловКРУ на затвердження.

3. Скасувати наказ ГоловКРУ від 17.11.99 N 101 "Про затвердження Типових положень про контрольно-ревізійні відділи".

4. Управлінню забезпечення взаємодії з правоохоронними органами та правової роботи після державної реєстрації довести цей наказ до відома контрольно-ревізійних управлінь в Автономній Республіці Крим, областях, містах Києві та Севастополі.

5. Контроль за виконанням цього наказу покласти на першого заступника Голови ГоловКРУ України Стефанюка І.Б.

Голова М.М.Каленський

{ Типове положення про Контрольно-ревізійний відділ у районі, місті, районі в місті та міжрайонний контрольно-ревізійний відділ зі статусом юридичної особи втратило чинність на підставі Наказу Головного контрольно-ревізійного управління N 409 ( z0020-07 ) від 18.12.2006 }
