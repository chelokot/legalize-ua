{ Наказ втратив чинність на підставі Наказу Державного комітету України з промислової безпеки, охорони праці та гірничого нагляду N 91 ( z0501-07 ) від 28.04.2007 }

Про внесення змін до наказу Держнаглядохоронпраці України від 02.04.2004 N 93

Відповідно до постанови Кабінету Міністрів України від 25 серпня 2004 року N 1097 ( 1097-2004-п ) "Про підвищення з 1 вересня 2004 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Держнаглядохоронпраці України від 02.04.2004 N 93 ( z0506-04 ) "Про умови оплати праці працівників Національного науково-дослідного інституту охорони праці", зареєстрованого в Міністерстві юстиції України 20.04.2004 за N 506/9105 (із змінами, унесеними наказом Держнаглядохоронпраці України від 27.05.2004 N 135 ( z0707-04 ), зареєстрованим у Міністерстві юстиції України 09.06.2004 за N 707/9306), виклавши додатки 1-3 у новій редакції (додаються).

2. Управлінню бухгалтерського обліку і звітності (Кулікова О.Л.) погодити цей наказ з Міністерством праці та соціальної політики України і Міністерством фінансів України та подати на державну реєстрацію Міністерству юстиції України.

3. Директору Національного науково-дослідного інституту охорони праці (Лисюк М.О.) запровадити ці зміни у встановлений термін в межах фонду заробітної плати, передбаченого кошторисом.

Голова Комітету С.Сторчак
