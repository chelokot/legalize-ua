Мінфін України; Наказ від 12.05.2009 № 658

Про внесення змін до Порядку проведення оцінки фінансового стану бенефіціара та визначення виду забезпечення для обслуговування та погашення позики, наданої за рахунок коштів міжнародних фінансових організацій

Реєстрація: Мін'юст України від 18.06.2009 № 533/16549

Стан: Втратив чинність

Ідентифікатор: z0533-09

Текст документа від 12.05.2009:

МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ

НАКАЗ

12.05.2009 N 658

Зареєстровано в Міністерстві юстиції України 18 червня 2009 р. за N 533/16549

Про внесення змін до Порядку проведення оцінки фінансового стану бенефіціара та визначення виду забезпечення для обслуговування та погашення позики, наданої за рахунок коштів міжнародних фінансових організацій

Відповідно до пункту 7 постанови Кабінету Міністрів України від 26.11.2008 N 1027 ( 1027-2008-п ) "Про порядок ініціювання, підготовки та реалізації проектів економічного і соціального розвитку України, що підтримуються міжнародними фінансовими організаціями" НАКАЗУЮ:

1. Унести до розділу I Порядку проведення оцінки фінансового стану бенефіціара та визначення виду забезпечення для обслуговування та погашення позики, наданої за рахунок коштів міжнародних фінансових організацій, затвердженого наказом Міністерства фінансів України від 01.04.2003 N 247 ( z0315-03 ), зареєстрованого в Міністерстві юстиції України 21.04.2003 за N 315/7636 (у редакції наказу Міністерства фінансів України від 26.10.2006 N 1012) ( z1361-06 ), такі зміни:

абзац сьомий пункту 1 викласти в такій редакції:

"Порядок ініціювання, підготовки та реалізації проектів - Порядок ініціювання, підготовки та реалізації проектів економічного і соціального розвитку України, що підтримуються міжнародними фінансовими організаціями, затверджений постановою Кабінету Міністрів України від 26.11.2008 N 1027 ( 1027-2008-п ) (зі змінами)";

у пункті 2 слова "Порядком підготовки та реалізації проектів" замінити словами "Порядком ініціювання, підготовки та реалізації проектів ( 1027-2008-п )";

пункт 3 викласти в такій редакції:

"3. Оцінка фінансового стану, визначення виду забезпечення та його розміру проводиться для розроблення проектної пропозиції, яку передбачено пунктом 8 Порядку ініціювання, підготовки та реалізації проектів ( 1027-2008-п )";

у пункті 4 слова "порядком підготовки та реалізації" замінити словами "Порядком ініціювання, підготовки та реалізації".

2. Встановити, що проведення оцінки фінансового стану бенефіціара та визначення виду забезпечення для обслуговування та погашення позики, наданої за рахунок коштів Кредитної установи для відбудови, яка діє на підставі повноважень від Уряду Федеративної Республіки Німеччина, здійснюються відповідно до цього Порядку.

3. Департаменту співробітництва з міжнародними фінансовими організаціями (Колосова В.П.) забезпечити подання цього наказу в установленому порядку на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням цього наказу залишаю за собою.

5. Цей наказ набирає чинності через 10 днів після державної реєстрації.

Перший заступник Міністра І.Уманський
