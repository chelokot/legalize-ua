N 218 від 12.05.99 Зареєстровано в Міністерстві м.Київ юстиції України 21 липня 1999 р. vd990512 vn218 за N 486/3779

( Наказ втратив чинність на підставі Наказу Державного комітету з питань технічного регулювання та споживчої політики N 233 ( z1063-05 ) від 31.08.2005 )

Про затвердження Переліку умовних позначень нормативно-правових актів Держстандарту України з питань метрології, зареєстрованих у Міністерстві юстиції України

З метою вдосконалення нормативної бази з метрології під час реалізації Закону України "Про метрологію та метрологічну діяльність" ( 113/98-ВР ) та для полегшення користування відомчими нормативно-правовими актами Держстандарту України з питань метрології, які пройшли державну реєстрацію в Міністерстві юстиції України, НАКАЗУЮ:

1. Затвердити Перелік умовних позначень нормативно-правових актів Держстандарту України з питань метрології, зареєстрованих у Міністерстві юстиції України, що додається.

2. Начальнику управління метрології, єдиного часу та еталонних частот Салганику Б.Ш. - забезпечити подання на державну реєстрацію до Міністерства юстиції України наказу "Про затвердження Переліку умовних позначень нормативно-правових актів Держстандарту України з питань метрології, зареєстрованих у Міністерстві юстиції України" згідно з чинним законодавством.

3. Директорам державних наукових метрологічних центрів та територіальних органів Держстандарту України - забезпечити безумовне виконання наказу "Про затвердження Переліку умовних позначень нормативно-правових актів Держстандарту України з питань метрології, зареєстрованих у Міністерстві юстиції України".

4. Контроль за виконанням цього наказу покласти на заступника голови Держстандарту України Величка О.М.

Голова Держстандарту Т.Кисільова
