КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 травня 2009 р. N 674-р Київ

Про затвердження фінансового плану державного підприємства "Український державний центр радіочастот" на 2009 рік

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1258-р ( 1258-2009-р ) від 14.10.2009 }
