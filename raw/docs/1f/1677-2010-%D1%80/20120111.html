Кабінет Міністрів України; Розпорядження від 18.08.2010 № 1677-р

Про зміну складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів соціального страхування

Стан: Втратив чинність

Ідентифікатор: 1677-2010-р

Текст документа від 11.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 серпня 2010 р. N 1677-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 19-р ( 19-2012-р ) від 11.01.2012 }

Про зміну складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах фондів соціального страхування

Внести зміни, що додаються, до складу осіб, уповноважених представляти інтереси держави у правліннях та наглядових радах:

Фонду соціального страхування від нещасних випадків на виробництві та професійних захворювань, затвердженого розпорядженням Кабінету Міністрів України від 15 вересня 2006 р. N 488 ( 488-2006-р ) (Офіційний вісник України, 2006 р., N 38, ст. 2597; 2008 р., N 15, ст. 395, N 87, ст. 2924; 2009 р., N 80, ст. 2720);

Фонду загальнообов'язкового державного соціального страхування України на випадок безробіття, затвердженого розпорядженням Кабінету Міністрів України від 21 лютого 2007 р. N 59 ( 59-2007-р ) (Офіційний вісник України, 2007 р., N 14, ст. 536, N 39, ст. 1567, N 91, ст. 3341; 2008 р., N 15, ст. 396, N 87, ст. 2924; 2009 р., N 80, ст. 2720);

Фонду соціального страхування з тимчасової втрати працездатності, затвердженого розпорядженням Кабінету Міністрів України від 14 листопада 2007 р. N 996 ( 996-2007-р ) (Офіційний вісник України, 2007 р., N 88, ст. 3222; 2008 р., N 15, ст. 394, N 41, ст. 1369, N 87, ст. 2924; 2009 р., N 101, ст. 3541).
