Про зміну у складі Комітету з економічних реформ

На часткову зміну статті 2 Указу Президента України від 17 березня 2010 року N 355 ( 355/2010 ) "Питання Комітету з економічних реформ" (зі змінами, внесеними Указами від 8 квітня 2010 року N 524 ( 524/2010 ), від 14 травня 2010 року N 627 ( 627/2010 ) та від 10 червня 2010 року N 681) ( 681/2010 ) увести до складу Комітету з економічних реформ ГОРІНУ Ірину Анатоліївну - народного депутата України (за згодою).
