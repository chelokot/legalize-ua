КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 травня 1996 р. N 518 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1426 ( 1426-2004-п ) від 28.10.2004 )

Про Український фонд сприяння соціальному захисту неповнолітніх

( Із змінами, внесеними згідно з Постановою КМ N 1635 ( 1635-98-п ) від 16.10.98 )

Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Комітету у справах неповнолітніх Кабінету Міністрів України про створення Українського фонду сприяння соціальному захисту неповнолітніх.

( Пункт 2 втратив чинність на підставі Постанови КМ N 1635 ( 1635-98-п ) від 16.10.98 ) 2. Установити, що:

формування Українського фонду сприяння соціальному захисту неповнолітніх здійснюється за рахунок коштів, що будуть надходити від добровільних внесків підприємств, установ, організацій, окремих громадян та інших не заборонених законодавством джерел надходжень;

розпорядником коштів Українського фонду сприяння соціальному захисту неповнолітніх є Комітет у справах неповнолітніх Кабінету Міністрів України;

невикористані кошти Українського фонду сприяння соціальному захисту неповнолітніх залишаються у розпорядженні Комітету і вилученню не підлягають.

( Пункт 3 втратив чинність на підставі Постанови КМ N 1635 ( 1635-98-п ) від 16.10.98 ) 3. Комітету у справах неповнолітніх Кабінету Міністрів України разом з Міністерством фінансів затвердити у місячний термін Положення про Український фонд сприяння соціальному захисту неповнолітніх.

4. Рекомендувати Урядові Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям створити місцеві фонди сприяння соціальному захисту неповнолітніх.
