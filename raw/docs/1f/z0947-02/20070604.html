Текст документа від 04.06.2007:

МІНІСТЕРСТВО ТРАНСПОРТУ УКРАЇНИ

НАКАЗ

02.12.2002 N 853

Зареєстровано в Міністерстві юстиції України 4 грудня 2002 р. за N 947/7235

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 405 ( z0537-07 ) від 15.05.2007 }

Про затвердження Тарифів на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід-Захід

{ Із змінами, внесеними згідно з Наказом Міністерства транспорту N 897 ( z1113-03 ) від 19.11.2003 }

Згідно з постановою Кабінету Міністрів України від 25 грудня 1996 р. N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

1. Затвердити Тарифи на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід-Захід (Тарифи та таблиці до них додаються).

2. Ввести зазначені Тарифи в дію з 15 грудня 2002 р.

3. Укрзалізниці (Федюшин Ю.М.) та начальникам залізниць України забезпечити своєчасне введення в дію цих Тарифів та правильність їх застосування і поінформувати про це населення (на вокзалах та пунктах продажу проїзних документів).

4. З уведенням у дію цього наказу втрачають чинність Тарифи на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід-Захід, затверджені наказом Міністерства транспорту України від 4 травня 2000 р. N 209 ( z0290-00 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід-Захід" і зареєстровані в Міністерстві юстиції України 18 травня 2000 р. за N 290/4511 (із змінами і доповненнями, унесеними наказом Міністерства транспорту України від 28.05.2001 N 327 ( z0469-01 ), зареєстрованим у Міністерстві юстиції України 31.05.2001 за N 469/5660 ).

5. Контроль за виконанням цього наказу покласти на заступника Державного секретаря Дунаєва Л.Ф.

Міністр Г.Кірпа

( Тарифи на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід - Захід втратили чинність на підставі Наказу Міністерства транспорту N 897 ( z1113-03 ) від 19.11.2003 )
