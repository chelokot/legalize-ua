Стан: Чинний

Текст документа від 23.04.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 травня 2007 р. N 766 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для зміцнення матеріально-технічної бази Національного палацу мистецтв "Україна"

{ Із змінами, внесеними згідно з Постановою КМ N 414 ( 414-2008-п ) від 23.04.2008 }

{ Установити, що кошти, передбачені у державному бюджеті ( 107-17 ) Державному управлінню справами за програмою "Заходи щодо зміцнення матеріально-технічної бази Національного палацу мистецтв "Україна", використовуються у 2008 році відповідно до Порядку, затвердженого цією Постановою, з урахуванням особливостей, вказаних у Постанові КМ N 414 ( 414-2008-п ) від 23.04.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для зміцнення матеріально-технічної бази Національного палацу мистецтв "Україна", що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 23 травня 2007 р. N 766

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для зміцнення матеріально-технічної бази Національного палацу мистецтв "Україна"

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених Державному управлінню справами у державному бюджеті за програмою "Заходи щодо зміцнення матеріально-технічної бази Національного палацу мистецтв "Україна" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Державне управління справами, а їх одержувачем - Національний палац мистецтв "Україна" (далі - Палац "Україна").

3. Бюджетні кошти спрямовуються Державним управлінням справами Палацу "Україна" на закупівлю відеокамер та обладнання для оснащення теле- і відеостудії з метою проведення прямої телевізійної трансляції та відеозапису загальнодержавних, міжнародних, громадсько-політичних і культурно-мистецьких заходів.

Бюджетні кошти використовуються Державним управлінням справами у межах бюджетних призначень, установлених Законом України "Про Державний бюджет України на 2007 рік" ( 489-16 ), згідно із затвердженим ним планом заходів з урахуванням необхідності виконання взятих на облік в органах Державного казначейства бюджетних зобов'язань минулих років та у разі їх відповідності паспорту бюджетної програми.

4. Закупівля товарів, робіт і послуг здійснюється відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ).

Палац "Україна" укладає з переможцем процедури закупівлі товарів, робіт і послуг, пов'язаних із зміцненням його матеріально-технічної бази, відповідні договори купівлі-продажу, виконання робіт і надання послуг.

5. У договорах про закупівлю товарів, робіт і послуг за рахунок бюджетних коштів обов'язково передбачаються такі вимоги:

сума, визначена в договорі, повинна коригуватися у разі уточнення показників державного бюджету;

постачання товарів, виконання робіт і надання послуг здійснюються до закінчення календарного року в повному обсязі згідно з укладеними договорами.

6. Операції, пов'язані з бюджетними коштами, проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

7. У разі зменшення бюджетних призначень Державне управління справами з метою недопущення виникнення заборгованості на кінець року провадить відповідне коригування суми видатків, спрямованих на зміцнення матеріально-технічної бази Палацу "Україна".

8. Державне управління справами затверджує результативні показники виконання бюджетної програми з поквартальною розбивкою та подає Мінфіну у двотижневий строк після затвердження розпису державного бюджету.

Інформацію про виконання результативних показників Державне управління справами подає Мінфіну у тижневий строк після закінчення звітного кварталу та одинадцяти місяців.

9. За нецільове використання бюджетних коштів відповідальність покладається на Державне управління справами та Палац "Україна".

{ Вимоги пункту 9 не застосовуються у 2008 згідно з Постановою КМ N 414 ( 414-2008-п ) від 23.04.2008 }

10. У разі коли під час виконання бюджетної програми допущено суттєві порушення, Мінфін та Державне управління справами проводять узгоджувальні наради, за результатами яких вносять на розгляд Першого віце-прем'єр-міністра України, Міністра фінансів пропозиції щодо подальшого порядку її фінансування.

{ Вимоги пункту 10 не застосовуються у 2008 році згідно з Постановою КМ N 414 ( 414-2008-п ) від 23.04.2008 }

11. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим і ефективним витрачанням здійснюються в установленому законодавством порядку.
