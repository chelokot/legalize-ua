Щодо затвердження Положення про порядок видачі приватизаційних майнових сертифікатів громадянам України, які з поважних причин не встигли їх отримати у встановлений законодавством термін

Стан: Втратив чинність

Ідентифікатор: za064-97

Текст документа від 10.05.2011:

ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

N 165 від 13.02.97 Зареєстровано в Міністерстві м.Київ юстиції України 5 березня 1997 р. за N 64/1866

{ Наказ втратив чинність на підставі Наказу Фонду державного майна N 519 ( za519-11 ) від 06.04.2011 }

Щодо затвердження Положення про порядок видачі приватизаційних майнових сертифікатів громадянам України, які з поважних причин не встигли їх отримати у встановлений законодавством термін

( Додатково див. Постанову Нацбанку N 289 ( z0425-97 ) від 01.09.97 )

( Із змінами, внесеними згідно з Постановою Нацбанку N 214 ( z0515-01 ) від 06.06.2001 Наказом Фонду державного майна N 979 ( z0516-01 ) від 06.06.2001 )

На виконання п.3 Постанови Верховної Ради України "Про продовження термінів обігу приватизаційних паперів" N 657/96-ВР від 27 грудня 1996 року, НАКАЗУЄМО:

( Пункт 1 втратив чинність на підставі Постанови Нацбанку N 214 ( z0515-01 ) від 06.06.2001, Наказу Фонду державного майна N 979 ( z0516-01 ) від 06.06.2001 )

2. Регіональним відділенням Фонду державного майна України після затвердження Положення, сформувати та затвердити персональний склад комісій по розгляду звернень громадян України, які з поважних причин не встигли отримати приватизаційні майнові сертифікати у встановлений законодавством термін.
