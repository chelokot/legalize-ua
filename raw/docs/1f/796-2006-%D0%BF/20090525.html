Питання Державного комітету ядерного регулювання

Стан: Чинний

Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 червня 2006 р. N 796 Київ

Питання Державного комітету ядерного регулювання

{ Із змінами, внесеними згідно з Постановами КМ N 954 ( 954-2008-п ) від 22.10.2008 N 464 ( 464-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

2. Міністерству фінансів разом з Державним комітетом ядерного регулювання та Міністерством охорони навколишнього природного середовища вирішити в установленому порядку питання щодо передачі Державному комітетові ядерного регулювання частини бюджетних призначень Міністерства охорони навколишнього природного середовища з урахуванням повноважень, наданих зазначеному Комітетові, та граничної чисельності його працівників.

3. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям сприяти Державному комітетові ядерного регулювання в забезпеченні державних інспекцій з ядерної та радіаційної безпеки службовими приміщеннями та телефонним зв'язком.

Прем'єр-міністр України Ю.ЄХАНУРОВ
