Кабінет Міністрів України; Постанова, Порядок від 30.08.2010 № 775

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 серпня 2010 р. N 775 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 411 ( 411-2015-п ) від 17.06.2015 }

Про затвердження Порядку подання суб'єктами господарювання, підприємствами, установами, організаціями, що не є суб'єктами первинного фінансового моніторингу, інформації на запит Державної служби фінансового моніторингу

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 75 ( 75-2011-п ) від 07.02.2011 }

{ Із змінами, внесеними згідно з Постановою КМ N 75 ( 75-2011-п ) від 07.02.2011 }

Відповідно до статей 12 і 20 Закону України "Про запобігання та протидію легалізації (відмиванню) доходів, одержаних злочинним шляхом, або фінансуванню тероризму" ( 249-15 ) Кабінет Міністрів України постановляє:

Затвердити Порядок подання суб'єктами господарювання, підприємствами, установами, організаціями, що не є суб'єктами первинного фінансового моніторингу, інформації на запит Державної служби фінансового моніторингу (додається).

{ Постановляюча частина із змінами, внесеними згідно з Постановою КМ N 75 ( 75-2011-п ) від 07.02.2011 }

Прем'єр-міністр України М.АЗАРОВ

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 30 серпня 2010 р. N 775

ПОРЯДОК подання суб'єктами господарювання, підприємствами, установами, організаціями, що не є суб'єктами первинного фінансового моніторингу, інформації на запит Державної служби фінансового моніторингу

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 75 ( 75-2011-п ) від 07.02.2011 }

1. Цей Порядок визначає обсяг та процедуру подання суб'єктами господарювання, підприємствами, установами, організаціями незалежно від форми власності, що не є суб'єктами первинного фінансового моніторингу (далі - суб'єкти), на запит Держфінмоніторингу інформації, пов'язаної з проведенням аналізу фінансових операцій, що стали об'єктом фінансового моніторингу, довідок та копій документів (у тому числі тих, що становлять банківську або комерційну таємницю), необхідних для виконання Держфінмоніторингом покладених на нього завдань у сфері боротьби з легалізацією (відмиванням) доходів, одержаних злочинним шляхом, або фінансуванням тероризму.

2. Інформація, що подається суб'єктами відповідно до цього Порядку, є інформацією з обмеженим доступом. Обмін зазначеною інформацією, її розкриття та захист здійснюються відповідно до закону.

3. Інформація, довідки та копії документів, які запитуються Держфінмоніторингом, використовуються з метою проведення аналізу фінансових операцій, що стали об'єктом фінансового моніторингу у Держфінмоніторингу.

4. Запити надсилаються суб'єктам у письмовій формі на офіційному бланку Держфінмоніторингу та підписуються Головою Держфінмоніторингу або його заступником.

5. Держфінмоніторинг має право запитувати у суб'єктів інформацію (копії документів) про фінансові операції, що стали об'єктом фінансового моніторингу, інформацію про учасників таких операцій, а також інформацію щодо активів учасників операцій.

6. Суб'єкти, їх посадові особи зобов'язані подавати письмово інформацію, що стосується фінансових операцій, які стали об'єктом фінансового моніторингу у Держфінмоніторингу, та необхідну для виконання покладених на Держфінмоніторинг завдань, додаючи засвідчені печаткою суб'єкта копії документів, що її підтверджують, та необхідні довідки.

7. Лист-відповідь суб'єкта на запит Держфінмоніторингу повинен містити:

номер та дату запиту Держфінмоніторингу, на який надається відповідь;

повну та змістовну інформацію, що запитується Держфінмоніторингом, у тому числі з обмеженим доступом, зокрема таку, що становить банківську або комерційну таємницю, за винятком інформації про конкретних фізичних осіб;

засвідчені печаткою суб'єкта копії документів, що підтверджують подану інформацію, та необхідні довідки відповідно до запиту Держфінмоніторингу;

підпис повноважної посадової особи, скріплений відбитком печатки.

8. Задоволення запиту (надсилання відповіді) здійснюється протягом п'яти робочих днів з дати його отримання.
