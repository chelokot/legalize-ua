РОЗПОРЯДЖЕННЯ від 17 червня 2009 р. N 673-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1280-р ( 1280-2014-р ) від 29.12.2014 }

Про внесення зміни до пункту 2 розпорядження Кабінету Міністрів України від 27 травня 2009 р. N 574

Пункт 2 розпорядження Кабінету Міністрів України від 27 травня 2009 р. N 574 ( 574-2009-р ) "Про експорт електроенергії до Республіки Білорусь" викласти у такій редакції:

"2. Державному підприємству "Енергоринок" забезпечити укладення з постачальниками електроенергії договорів купівлі-продажу електроенергії на оптовому ринку електричної енергії України для її подальшого експорту до Республіки Білорусь за оптовою ринковою ціною без урахування обсягу дотації для компенсації втрат, пов'язаних з постачанням електроенергії за регульованим тарифом.".

Прем'єр-міністр України Ю.ТИМОШЕНКО
