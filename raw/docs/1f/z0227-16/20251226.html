Про затвердження Норм відпуску мастильних та обтиральних матеріалів для озброєння територіальних управлінь, з’єднань, військових частин та навчальних закладів Національної гвардії України

{Із змінами, внесеними згідно з Наказом Міністерства внутрішніх справ
№ 815 від 20.11.2025}

Відповідно до Закону України «Про Національну гвардію України», підпункту 50 пункту 4, пункту 9 Положення про Міністерство внутрішніх справ України, затвердженого постановою Кабінету Міністрів України від 28 жовтня 2015 року № 878, з метою якісного обслуговування та підтримання озброєння в постійній бойовій готовності в підрозділах Національної гвардії України НАКАЗУЮ :

1. Затвердити Норми відпуску мастильних та обтиральних матеріалів для озброєння територіальних управлінь, з’єднань, військових частин та навчальних закладів Національної гвардії України (далі – Норми), що додаються.

2. Головному управлінню Національної гвардії України:

1) використання мастильних та обтиральних матеріалів для озброєння проводити згідно з цими Нормами;

2) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України в установленому порядку.

3. Цей наказ набирає чинності з дня його офіційного опублікування.

4. Контроль за виконанням цього наказу покласти на заступника Міністра генерал-полковника Ярового С.А.

Міністр

Примітки:


1. Мастила збройові РЖ та ВО застосовуються: РЖ – при температурі повітря від +5 °С до -50 °С, ВО – при температурі повітря від +5 °С до +50 °С.
2. Для навчального озброєння встановлюються 25% від зазначених норм.
3. Для озброєння на складах установлюється 3% від зазначених норм.
4. Для майна, що належить до номенклатури служби ракетно-артилерійського озброєння, яке не внесено до зазначених норм, застосовуються витрати матеріалів (мастил, рідин, засобів для чищення), передбачені технічною документацією заводу-виробника.

{Норми із змінами, внесеними згідно з Наказом Міністерства внутрішніх справ № 815 від 20.11.2025 }
