Кабінет Міністрів України; Постанова від 14.04.2010 № 319

Про використання у 2010 році коштів Стабілізаційного фонду для завершення будівництва Всеукраїнського центру радіохірургії

Стан: Чинний

Ідентифікатор: 319-2010-п

Текст документа від 02.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 квітня 2010 р. N 319 Київ

Про використання у 2010 році коштів Стабілізаційного фонду для завершення будівництва Всеукраїнського центру радіохірургії

{ Із змінами, внесеними згідно з Постановою КМ N 369 ( 369-2010-п ) від 19.05.2010 }

Кабінет Міністрів України постановляє:

1. Виділити Міністерству охорони здоров'я 130 млн. гривень за рахунок надходжень до Стабілізаційного фонду від цільового розміщення державних цінних паперів для завершення будівництва Всеукраїнського центру радіохірургії у складі Клінічної лікарні "Феофанія" за напрямом, передбаченим пунктом 11 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) (далі - кошти Стабілізаційного фонду).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 369 ( 369-2010-п ) від 19.05.2010 }

2. Установити, що:

кошти Стабілізаційного фонду спрямовуються з урахуванням вимог Порядку, затвердженого постановою Кабінету Міністрів України від 11 березня 2009 р. N 289 ( 289-2009-п ) "Питання використання коштів Стабілізаційного фонду" (Офіційний вісник України, 2009 р., N 24, ст. 793; 2010 р., N 2, ст. 69), на завершення будівництва Всеукраїнського центру радіохірургії у складі Клінічної лікарні "Феофанія";

головним розпорядником коштів Стабілізаційного фонду є Міністерство охорони здоров'я.

3. Забезпечити:

Міністерству фінансів - внесення в установленому порядку відповідних змін до розпису державного бюджету; { Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 369 ( 369-2010-п ) від 19.05.2010 }

Державному казначейству - перерахування коштів Стабілізаційного фонду.

{ Пункт 4 виключено на підставі Постанови КМ N 369 ( 369-2010-п ) від 19.05.2010 }
