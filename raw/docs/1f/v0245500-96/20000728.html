Про затвердження нормативних актів Національного банку України і внесення змін та доповнень до чинних нормативних актів Національного банку України

Стан: Втратив чинність

Ідентифікатор: v0245500-96

Текст документа від 28.07.2000:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 245 від 23.09.96 м.Київ

vd960923 vn245

Про затвердження нормативних актів Національного банку України і внесення змін та доповнень до чинних нормативних актів Національного банку України

( Із змінами, внесеними згідно з Постановою Нацбанку N 283 ( z0452-00 ) від 12.07.2000 )

Розглянувши пропозиції департаменту валютного регулювання та юридичного департаменту щодо затвердження нормативних актів Національного банку України і внесення змін та доповнень до чинних нормативних актів Національного банку України у зв'язку з проведенням грошової реформи, Правління ПОСТАНОВЛЯЄ:

1. Затвердити:

- в новій редакції розділ 4 (додаток N 1) ( v0385500-96 ) Інструкції N 3 "Про відкриття банками рахунків в національній та іноземній валюті", затвердженої постановою Правління Національного банку України від 27 травня 1996 року за N 121 ( v0121500-96 );

- "Порядок бухгалтерського обліку та розрахунків за рахунками "Лоро" банків-нерезидентів у валюті України" (додаток N 2) ( v0386500-96 );

( Абзац втратив чинність на підставі Постанови Нацбанку N 283 ( z0452-00 ) від 12.07.2000 )

- "Порядок купівлі фізичними особами-резидентами іноземної валюти на міжбанківському валютному ринку України" (додаток N 4) ( v0388500-96 );

- "Порядок надання уповноваженим банкам індивідуальних ліцензій на вивезення банкнот іноземної валюти і спеціальних дозволів на ввезення банкнот іноземної валюти та бланків чеків" (додаток N 5) ( v0389500-96 );

- "Правила переказу іноземної валюти за межі України за рахунок особистих коштів фізичних осіб-резидентів і нерезидентів" (додаток N 6) ( v0390500-96 );

- "Порядок застосування іноземної валюти в страховій діяльності" (додаток N 7) ( v0391500-96 ).

2. Департаменту бухгалтерського обліку та розрахунків в "Плані рахунків бухгалтерського обліку банків України" ( v0332500-95 ) передбачити рахунок для обліку депозитів постійних представництв юридичних осіб-нерезидентів, що займаються підприємницькою діяльністю.

3. Встановити, що із затвердженням цієї постанови втрачають чинність такі листи Національного банку України:

- N 13-312/349-3955 ( v3955500-96 ) від 17.07.96 р.;

- N 13-312/362 ( v_362500-96 ) від 23.07.96 р.;

- N 276 ( v0276500-95 ) від 26.07.95 р.

4. Першому заступнику Голови Правління Національного банку України забезпечити контроль за виконанням цієї постанови.

5. Постанова набирає чинності з 3 жовтня 1996 року.

Голова Правління В.А.Ющенко
