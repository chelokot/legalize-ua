Про визнання таким, що втратив чинність, наказу Мінпаливенерго від 25.07.2008 N 396

На виконання пункту 3 Змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 28.01.2009 N 36 ( 36-2009-п ) "Про внесення змін до деяких постанов Кабінету Міністрів України", НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Мінпаливенерго від 25.07.2008 N 396 ( z0733-08 ) "Про затвердження витрат НАК "Нафтогаз України" на реалізацію природного газу", зареєстрований в Міністерстві юстиції України 11.08.2008 за N 733/15424, із змінами, внесеними наказом Мінпаливенерго від 21.10.2008 N 517 ( z1027-08 ) "Про внесення змін до наказу Мінпаливенерго України від 25.07.2008 N 396", зареєстрованим в Міністерстві юстиції України 27.10.2008 за N 1027/15718.

2. Контроль за виконанням цього наказу покласти на заступника Міністра Макуху В.О.
