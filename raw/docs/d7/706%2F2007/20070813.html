Президент України; Указ від 13.08.2007 № 706/2007

Про зупинення дії постанов Кабінету Міністрів України від 29 грудня 2006 року N 1854 та від 14 березня 2007 року N 456

Стан: Втратив чинність

Ідентифікатор: 706/2007

Текст документа від 13.08.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанов Кабінету Міністрів України від 29 грудня 2006 року N 1854 та від 14 березня 2007 року N 456

{ Додатково див. Конституційне подання Президента ( n0015100-07 ) від 13.08.2007 }

Кабінетом Міністрів України 29 грудня 2006 року видано постанову N 1854 ( 1854-2006-п ) "Про вдосконалення управління атомно-промисловим комплексом", якою передбачено утворення державного концерну "Укратомпром". Постановою Кабінету Міністрів України від 14 березня 2007 року N 456 ( 456-2007-п ) "Деякі питання державного концерну "Укратомпром" затверджено Статут цього Концерну.

Названі постанови ( 1854-2006-п, 456-2007-п ) передбачають утворення державного концерну "Укратомпром" як господарського об'єднання державних підприємств та організацій, зокрема державних підприємств "Національна атомна енергогенеруюча компанія "Енергоатом", "Східний гірничо-збагачувальний комбінат", "Смоли", Українського науково-дослідного та проектно-розвідувального інституту промислової технології, які відповідно до Закону України "Про перелік об'єктів права державної власності, що не підлягають приватизації" ( 847-14 ) є такими, що не підлягають приватизації, із передачею до статутного фонду Концерну виробничих і невиробничих фондів, коштів, інших цінностей зазначених підприємств.

Утворення такого господарського об'єднання, що володіє, користується та розпоряджається належним йому майном, діє на принципах повної господарської самостійності, несе відповідальність за результати своєї господарської діяльності та виконання зобов'язань (пункти 2.2, 2.4, 4.3 Статуту державного концерну "Укратомпром"), уможливлює відчуження з державної власності переданого Концерну його учасниками майна, приватизація якого заборонена.

Таким чином, зазначеними постановами Кабінету Міністрів України ( 1854-2006-п, 456-2007-п ) всупереч Закону України "Про основи національної безпеки України" ( 964-15 ), за яким стале функціонування і розвиток паливно-енергетичного комплексу держави визначено одним з основних напрямів державної політики з питань національної безпеки в економічній сфері (стаття 8) ( 964-15 ), надається можливість відчуження з державної власності майна, приватизація якого заборонена, зокрема атомних електростанцій, що працюють в єдиній енергосистемі України і забезпечують її цілісність. Це створює загрозу економічній безпеці держави.

Відтак, названі постанови Кабінету Міністрів України ( 1854-2006-п, 456-2007-п ) не відповідають частині першій статті 17 Конституції України ( 254к/96-ВР ), за якою забезпечення економічної безпеки держави є її найважливішою функцією, а також частині другій статті 8 Основного Закону України ( 254к/96-ВР ), за якою нормативно-правові акти приймаються на основі Конституції України ( 254к/96-ВР ) і повинні відповідати їй, нормам частини другої статті 6, частини другої статті 19 та частини третьої статті 113 Конституції України ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, діяти на підставі та у спосіб, що ними передбачені.

Ураховуючи наведене та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію:

постанови Кабінету Міністрів України від 29 грудня 2006 року N 1854 ( 1854-2006-п ) "Про вдосконалення управління атомно-промисловим комплексом";

постанови Кабінету Міністрів України від 14 березня 2007 року N 456 ( 456-2007-п ) "Деякі питання державного концерну "Укратомпром".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 13 серпня 2007 року N 706/2007
