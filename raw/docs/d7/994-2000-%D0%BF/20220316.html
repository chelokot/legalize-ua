{ Постанова втратила чинність на підставі Постанови КМ N 278 ( 278-2022-п ) від 23.02.2022 }

Про внесення змін до постанови Кабінету Міністрів України від 22 лютого 1999 р. N 236

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 22 лютого 1999 р. N 236 ( 236-99-п ) "Про затвердження граничних розмірів плати за проходження суден шлюзами Дніпровського каскаду" (Офіційний вісник України, 1999 р., N 8, ст. 42) такі зміни:

1) у назві і тексті постанови слово "граничних" виключити;

2) абзац другий пункту 1 виключити;

3) розміри плати за проходження суден шлюзами Дніпровського каскаду, затверджені зазначеною постановою, викласти у редакції, що додається.
