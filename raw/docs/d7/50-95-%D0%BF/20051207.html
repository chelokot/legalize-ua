Кабінет Міністрів України; Постанова від 25.01.1995 № 50

Про порядок розподілу коштів, отриманих від суб'єктів зовнішньоекономічної діяльності України за здійснення обліку (реєстрації) зовнішньоекономічних договорів (контрактів)

Стан: Втратив чинність

Ідентифікатор: 50-95-п

Текст документа від 07.12.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 січня 1995 р. N 50 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1177 ( 1177-2005-п ) від 07.12.2005 )

Про порядок розподілу коштів, отриманих від суб'єктів зовнішньоекономічної діяльності України за здійснення обліку (реєстрації) зовнішньоекономічних договорів (контрактів)

( Із змінами, внесеними згідно з Постановою КМ N 283 ( 283-98-п ) від 07.03.98 )

На виконання Указу Президента України від 7 листопада 1994 р. N 659 ( 659/94 ) "Про облік окремих видів зовнішньоекономічних договорів (контрактів) в Україні" Кабінет Міністрів України ПОСТАНОВЛЯЄ:

Установити такий порядок розподілу коштів, отриманих від суб'єктів зовнішньоекономічної діяльності України за здійснення обліку (реєстрації) зовнішньоекономічних договорів (контрактів):

кошти, одержані Міністерством зовнішніх економічних зв'язків і торгівлі за здійснення обліку (реєстрації) зовнішньоекономічних договорів (контрактів), перераховуються до державного бюджету;

( Абзац третій в редакції Постанови КМ N 283 ( 283-98-п ) від 07.03.98 )

75 відсотків коштів, одержаних органами, уповноваженими Міністерством зовнішніх економічних зв'язків і торгівлі здійснювати облік (реєстрацію) зовнішньоекономічних договорів (контрактів), перераховуються до державного бюджету, 25 відсотків - до бюджетів Автономної Республіки Крим, областей, міст Києва та Севастополя. ( Абзац четвертий в редакції Постанови КМ N 283 ( 283-98-п ) від 07.03.98 )
