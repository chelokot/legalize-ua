РОЗПОРЯДЖЕННЯ

N 249-р від 29.11.99 Зареєстровано в Міністерстві м.Київ юстиції України 10 грудня 1999 р. vd991129 vn249-р за N 855/4148

{ Розпорядження втратило чинність на підставі Розпорядження Антимонопольного комітету

N 247-р ( z0696-09 ) від 14.07.2009 }

Про Положення про порядок проведення перевірок дотримання антимонопольного законодавства

{ Із змінами, внесеними згідно з Розпорядженнями Антимонопольного комітету N 33-р ( z0292-01 ) від 23.02.2001 N 182-р ( z0139-02 ) від 25.12.2001 }

Відповідно до Законів України "Про Антимонопольний комітет України" ( 3659-12 ), "Про обмеження монополізму та недопущення недобросовісної конкуренції у підприємницькій діяльності" ( 2132-12 ), Указу Президента України від 23 липня 1998 року N 817/98 "Про деякі заходи з дерегулювання підприємницької діяльності", з метою здійснення повного й об'єктивного контролю за дотриманням антимонопольного законодавства органами державної влади, органами місцевого самоврядування, органами адміністративно-господарського управління та контролю, суб'єктами господарювання та враховуючи пропозиції територіальних відділень,

затвердити Положення про порядок проведення перевірок дотримання антимонопольного законодавства (надалі - Положення), що додається.

Голова Комітету О.Завада

Затверджено Розпорядження Антимонопольного комітету України 29.11.99 N 249-р

Зареєстровано в Міністерстві юстиції України 10 грудня 1999 р. за N 855/4148
