Про передачу у 2011 році деяких бюджетних призначень Міністерству культури

Стан: Чинний

Ідентифікатор: 712-2011-р

Текст документа від 27.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 липня 2011 р. N 712-р Київ

Про передачу у 2011 році деяких бюджетних призначень Міністерству культури

{ Із змінами, внесеними згідно з Постановою КМ N 1335 ( 1335-2011-п ) від 12.12.2011 }

1. Передати бюджетні призначення, передбачені у 2011 році Міністерству фінансів у загальному фонді державного бюджету ( 2857-17 ) за програмою 3511090 "Державні капітальні видатки, що розподіляються Кабінетом Міністрів України" (загальнодержавні витрати), у сумі 5700 тис. гривень Міністерству культури для здійснення заходів з відзначення 1000-річчя заснування Софійського собору та проведення протиаварійних і ремонтно-реставраційних робіт в Андріївській церкві. { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1335 ( 1335-2011-п ) від 12.12.2011 }

Передачу бюджетних призначень здійснити в межах видатків розвитку.

2. Забезпечити:

1) Міністерству культури:

погодження передачі бюджетних призначень, передбаченої пунктом 1 цього розпорядження, з Комітетом Верховної Ради України з питань бюджету;

подання щомісяця до 5 числа Міністерству фінансів звіту про використання бюджетних коштів відповідно до переданих бюджетних призначень;

2) після зазначеного погодження:

Міністерству фінансів - відкриття у разі потреби нової бюджетної програми та внесення відповідних змін до розпису державного бюджету;

Державній казначейській службі - перерахування бюджетних коштів відповідно до переданих бюджетних призначень.

Прем'єр-міністр України М.АЗАРОВ
