УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 43/2008 ( 43/2008 ) від 21.01.2008 }

Про внесення зміни до Указу Президента України від 11 вересня 2006 року N 749

Відповідно до частини четвертої статті 107 Конституції України ( 254к/96-ВР ) постановляю:

На часткову зміну Указу Президента України від 11 вересня 2006 року N 749 ( 749/2006 ) "Про склад Ради національної безпеки і оборони України" (зі змінами, внесеними Указами від 20 вересня 2006 року N 761 ( 761/2006 ), від 17 жовтня 2006 року N 884 ( 884/2006 ) та від 15 листопада 2006 року N 966 ( 966/2006 ) ввести до складу Ради національної безпеки і оборони України КІНАХА Анатолія Кириловича - Голову Комітету Верховної Ради України з питань національної безпеки і оборони (за згодою).
