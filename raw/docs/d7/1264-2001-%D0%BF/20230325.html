КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 вересня 2001 р. N 1264 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 242 ( 242-2023-п ) від 17.03.2023 }

Про внесення змін до постанови Кабінету Міністрів України від 26 липня 2000 р. N 1175

Кабінет Міністрів України постановляє:

Доповнити розділ "Житомирська область" переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку Житомирської, Чернігівської областей, м. Шостка Сумської області, на території спеціальної економічної зони "Миколаїв", де встановлено спеціальний режим інвестиційної діяльності, затвердженого постановою Кабінету Міністрів України від 26 липня 2000 р. N 1175 ( 1175-2000-п ) "Про деякі питання інвестиційної діяльності на територіях пріоритетного розвитку та спеціальних економічних зон" (Офіційний вісник України, 2000 р., N 30, ст. 1281; N 52, ст. 2271), такими позиціями:

"14.22 Видобування глини та каоліну 15.32 Виробництво фруктових та овочевих соків (виключно з вітчизняної сировини) 15.71 Виробництво готових кормів для тварин, що утримуються на фермах 18.22 Виробництво верхнього одягу 24.15 Виробництво мінеральних добрив та азотних сполук 25.23 Виробництво пластмасового обладнання для будівництва".

Прем'єр-міністр України А.КІНАХ
