Питання Антикризового центру

Стан: Втратив чинність

Ідентифікатор: 1001/2005

Текст документа від 07.03.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 118/2007 ( 118/2007 ) від 19.02.2007 }

Питання Антикризового центру

1. Внести до Указу Президента України від 18 березня 2003 року N 228 ( 228/2003 ) "Про Положення про Антикризовий центр" такі зміни:

а) статтю 3 визнати такою, що втратила чинність;

б) у Положенні, затвердженому зазначеним Указом:

абзац другий пункту 5 викласти в такій редакції:

"Головою Центру є Президент України, заступником Голови - Державний секретар України";

пункти 2, 3, 10 додатка до Положення викласти відповідно в такій редакції:

"2. Міністерство охорони навколишнього природного середовища України

3. Міністерство економіки України";

"10. Міністерство транспорту та зв'язку України".

2. Затвердити новий персональний склад Антикризового центру (додається).

3. Визнати такими, що втратили чинність:

статтю 2 Указу Президента України від 5 листопада 2002 року N 991 ( 991/2002 ) "Про Антикризовий центр";

Указ Президента України від 22 листопада 2003 року N 1338 ( 1338/2003 ) "Про зміни у складі Антикризового центру";

Указ Президента України від 4 листопада 2004 року N 1366 ( 1366/2004 ) "Про зміну у складі Антикризового центру";

абзац дванадцятий статті 2 Указу Президента України від 22 січня 2005 року N 77 ( 77/2005 ) "Про внесення змін до деяких актів Президента України".
