Президент України; Указ від 23.10.1999 № 1377/99

Про присвоєння почесного найменування "Закарпатський" 254 зенітному ракетному ордена Червоного Прапора полку 28 корпусу протиповітряної оборони Військ Протиповітряної оборони України

Стан: Втратив чинність

Ідентифікатор: 1377/99

Текст документа від 30.10.2000:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1173/2000 ( 1173/2000 ) від 30.10.2000 )

Про присвоєння почесного найменування "Закарпатський" 254 зенітному ракетному ордена Червоного Прапора полку 28 корпусу протиповітряної оборони Військ Протиповітряної оборони України

У зв'язку з 55-ю річницею визволення України від фашистських загарбників, враховуючи героїчні традиції частини, високий професіоналізм особового складу, успішне виконання завдань з протиповітряної оборони у мирний час та з метою виховання військової молоді на бойових традиціях старшого покоління постановляю:

Присвоїти 254 зенітному ракетному ордена Червоного Прапора полку 28 корпусу протиповітряної оборони Військ Протиповітряної оборони України почесне найменування "Закарпатський" і надалі іменувати його - 254 зенітний ракетний Закарпатський ордена Червоного Прапора полк 28 корпусу протиповітряної оборони Військ Протиповітряної оборони України.

Президент України Л.КУЧМА

м. Київ, 23 жовтня 1999 року N 1377/99
