Про Перелік посадових осіб, на яких покладається виконання функцій державного експерта з питань таємниць

{ Із змінами, внесеними згідно з Указом Президента N 606/2009 ( 606/2009 ) від 07.08.2009 }

Відповідно до статті 9 Закону України "Про державну таємницю" ( 3855-12 ) постановляю:

1. Затвердити Перелік посадових осіб, на яких покладається виконання функцій державного експерта з питань таємниць (додається).

2. Визнати такими, що втратили чинність:

Указ Президента України від 18 жовтня 2000 року N 1144 ( 1144/2000 ) "Про посадових осіб органів державної влади, на яких покладається виконання функцій державного експерта з питань таємниць";

Указ Президента України від 11 жовтня 2002 року N 917 ( 917/2002 ) "Про внесення змін до Указу Президента України від 18 жовтня 2000 року N 1144";

Указ Президента України від 25 листопада 2002 року N 1060 ( 1060/2002 ) "Про внесення зміни до Указу Президента України від 18 жовтня 2000 року N 1144";

пункт 2 змін, що вносяться до указів Президента України, затверджених Указом Президента України від 9 липня 2003 року N 586 ( 586/2003 ) "Про зміни та визнання такими, що втратили чинність, деяких указів Президента України";

пункт 14 змін, що вносяться до деяких указів Президента України, затверджених Указом Президента України від 29 жовтня 2003 року N 1227 ( 1227/2003 ) "Про внесення змін до деяких указів Президента України";

Указ Президента України від 19 січня 2004 року N 58 ( 58/2004 ) "Про внесення змін до Указу Президента України від 18 жовтня 2000 року N 1144";

статтю 1 Указу Президента України від 4 листопада 2004 року N 1368 ( 1368/2004 ) "Про внесення змін до деяких указів Президента України".
