КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 жовтня 1999 р. N 2008 Київ

( Постанова втратила чинність на підставі Постанови КМ N 905 ( 905-2000-п ) від 05.06.2000 )

Про доповнення переліку товарів критичного імпорту

Кабінет Міністрів України постановляє:

1. Доповнити перелік товарів критичного імпорту, затверджений постановою Кабінету Міністрів України від 18 червня 1999 р. N 1080 ( 1080-99-п ) "Про перелік товарів критичного імпорту", із змінами, внесеними постановою Кабінету Міністрів України від 7 липня 1999 р. N 1206 ( 1206-99-п ), товаром за кодом згідно з ТН ЗЕД 8701 20 100 (тільки сідельні автотягачі).

2. Ця постанова набирає чинності з дня її опублікування.
