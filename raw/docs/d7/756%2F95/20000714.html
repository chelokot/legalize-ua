( Указ втратив чинність на підставі Указу Президента N 889/2000 ( 889/2000 ) від 14.07.2000 )

Про нагородження відзнакою Президента України "Іменна вогнепальна зброя"

За вагомий особистий внесок в успішне виконання тристоронньої угоди між Україною, Російською Федерацією та Сполученими Штатами Америки, забезпечення високої бойової готовності військ постановляю:

Нагородити відзнакою Президента України "Іменна вогнепальна зброя" командуючого ракетною армією, генерал-полковника МИХТЮКА Володимира Олексійовича.

Президент України Л.КУЧМА

м. Київ, 17 серпня 1995 року N 756/95
