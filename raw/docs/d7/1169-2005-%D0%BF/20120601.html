Кабінет Міністрів України; Постанова від 07.12.2005 № 1169

Про внесення зміни до переліку місць митного контролю нафти, що переміщується через митний кордон України трубопровідним транспортом

Стан: Втратив чинність

Ідентифікатор: 1169-2005-п

Текст документа від 01.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 грудня 2005 р. N 1169 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 450 ( 450-2012-п ) від 21.05.2012 }

Про внесення зміни до переліку місць митного контролю нафти, що переміщується через митний кордон України трубопровідним транспортом

Кабінет Міністрів України постановляє:

Внести зміну до переліку місць митного контролю нафти, що переміщується через митний кордон України трубопровідним транспортом, затвердженого постановою Кабінету Міністрів України від 17 грудня 2003 р. N 1958 ( 1958-2003-п ) (Офіційний вісник України, 2003 р., N 51, ст. 2699), доповнивши його позицією такого змісту:

"Нафтоперекачувальна станція с. Яворів Долинського району "Долина" Дрогобицького районного Івано-Франківської області". управління ВАТ "Укртранснафта", система вимірювання кількості та контролю якості нафти N 462 (або її обліку за резервуарами)

Прем'єр-міністр України Ю.ЄХАНУРОВ
