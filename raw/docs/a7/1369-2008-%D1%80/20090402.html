Про операції з одиницями (частинами) установленої кількості

Стан: Чинний

Ідентифікатор: 1369-2008-р

Текст документа від 02.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 жовтня 2008 р. N 1369-р Київ

Про операції з одиницями (частинами) установленої кількості

{ Із змінами, внесеними згідно з Розпорядженням КМ N 360-р ( 360-2009-р ) від 02.04.2009 }

Відповідно до пункту 2 постанови Кабінету Міністрів України від 20 серпня 2008 р. N 718 ( 718-2008-п ) (Офіційний вісник України, 2008 р., N 63, ст. 2129) уповноважити Нацекоінвестагентство на здійснення в установленому порядку у період до 31 грудня 2009 р. операцій з передачі одиниць (частин) установленої кількості в загальному обсязі 26 253 247 тонн еквіваленту двоокису вуглецю, зокрема операцій з передачі:

{ Абзац перший із змінами, внесеними згідно з Розпорядженням КМ N 360-р ( 360-2009-р ) від 02.04.2009 }

одиниць скорочення викидів, які індивідуально позначені додаванням до серійного номера одиниць (частин) установленої кількості ідентифікатора (реєстраційного номера) проекту спільного впровадження, утворених у результаті його реалізації;

одиниць (частин) установленої кількості як скорочення викидів, досягнутого власником об'єкта до початку першого періоду дії Кіотського протоколу ( 995_801 ) в результаті реалізації проекту спільного впровадження, на рахунок іноземної держави або уповноваженого нею покупця;

одиниць (частин) установленої кількості на депозитні (кастодіальні) рахунки.

Прем'єр-міністр України Ю.ТИМОШЕНКО
