Про внесення зміни до переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності

Стан: Втратив чинність

Ідентифікатор: 434-2008-п

Текст документа від 06.09.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 травня 2008 р. N 434 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 546 ( 546-2016-п ) від 23.08.2016 }

Про внесення зміни до переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності

Кабінет Міністрів України постановляє:

1. У пунктах 41-43 переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності, затвердженого постановою Кабінету Міністрів України від 4 липня 2001 р. N 756 ( 756-2001-п ) (Офіційний вісник України, 2001 р., N 27, ст. 1212), графу "Документи, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності" викласти у такій редакції:

"відомості за підписом заявника - суб'єкта господарювання щодо

наявності матеріально-технічної бази та необхідного для

провадження відповідного виду господарської діяльності рівня

освіти і кваліфікації за формою, встановленою

Держкомветмедицини".

2. Ця постанова набирає чинності з дня опублікування.
