( Розпорядження втратило чинність на підставі Розпорядження КМ N 646-р ( 646-98-р ) від 03.08.98 )

Про закріплення у державній власності пакету акцій ВАТ "Одесакабель"

Відповідно до підпункту 5.1.1 розділу 5 частини II Державної програми приватизації на 1997 рік ( 294/97-ВР ) закріпити у державній власності пакет акцій у розмірі 51 відсоток статутного фонду ВАТ "Одесакабель" на 3 роки.
