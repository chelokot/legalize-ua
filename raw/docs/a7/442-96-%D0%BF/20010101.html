( Із змінами, внесеними згідно з Постановами КМ N 989 ( 989-97-п ) від 08.09.97 N 1364 ( 1364-97-п ) від 08.12.97 N 847 ( 847-98-п ) від 10.06.98 N 445 ( 445-99-п ) від 24.03.99 N 1929 ( 1929-99-п ) від 19.10.99 N 700 ( 700-2000-п ) від 25.04.2000 )

Відповідно до статті 84 Кодексу торговельного мореплавства України ( 176/95-ВР ) Кабінет Міністрів України постановляє:

1. Затвердити Положення про портові збори, що додається.

2. Установити, що розміри зборів є граничними, а порядок застосування знижок до них визначається Міністерством транспорту.

ПОЛОЖЕННЯ про портові збори

Загальні питання

1. Портові збори (корабельний, канальний, маяковий, причальний, якірний, адміністративний та санітарний) справляються у морських портах із суден зазначених груп і плавучих споруд, що плавають під Державним прапором України та іноземним прапором:

вантажні судна, що заходять у порти для виконання

вантажних операцій, та плавучі споруди група А

пасажирські судна, включаючи швидкісні судна на

підводних крилах, та пороми, що заходять у порти

для виконання вантажопасажирських операцій,

криголами, які не належать порту та не орендовані група Б

ним

ліхтери, буксири, буксири-штовхачі, штовхачі, баржі

(самохідні і несамохідні), річкові самохідні судна,

включаючи судна типу ріка-море пароплавств, які є

членами Братиславської угоди, що заходять у порти

на р.Дунаї, а також річкові самохідні судна, що

заходять в інші порти для подальшого перевантаження

вантажів на морські судна і навпаки група В

несамохідні судна (крім барж) група Г

судна, що заходять у порт вимушено*, для

постачання, карантинних потреб, а також судна,

які прямують на ремонт на судноремонтні підприємства

(бази) України група Д

службові та військові судна група Д

навчальні, навчально-виробничі судна при виконанні

ними рейсів за навчальними планами навчальних

закладів, на борту яких перебуває не менш як 50 група Д

курсантів, навчально-тренажерні судна

наукові та дослідні судна, швидкісні судна на

підводних крилах, що виконують регулярні

пасажирські рейси за розкладом у каботажному

плаванні (крім прогулянкових і круїзних рейсів) група Д

інші судна (судна судноремонтного заводу,

аварійно-рятувальні, підводно-технічні, технічні,

госпітальні, гідрографічні, судна місцевого

портового флоту, криголами, які належать порту та

орендовані ним, спортивні судна, приватні яхти, група Е

парусні судна, судна, які проходять ходові

випробування та риболовецькі судна, що заходять у

порти без виконання вантажних операцій)

-------------

Примітка. Судна груп В (буксири та баржі), Д та Е, які виконують комерційні вантажні рейси, належать до групи А.

Судна груп Д та Е, які виконують комерційні вантажопасажирські рейси, належать до групи Б.

Порядок обчислення і справляння зборів поширюється на суб'єктів підприємницької діяльності всіх форм власності, які виконують роботи та надають послуги у морських портах та на причалах судноремонтних заводів України, незалежно від підпорядкованості цих портів (причалів).

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 989 ( 989-97-п ) від 08.09.97, в редакції Постанови КМ N 445 ( 445-99-п ) від 24.03.99, із змінами, внесеними згідно з Постановою КМ N 700 ( 700-2000-п ) від 25.04.2000 )

2. Сплата портових зборів у портах здійснюється до виходу судна з порту, а за транзитний прохід суден Керч-Єнікальським каналом (КЄК) та каналом Прорва - шляхом попередньої оплати або безпосередньо на вході у КЄК та канал Прорва, якщо при цьому не обумовлено інше. ( Пункт 2 в редакції Постанови КМ N 445 ( 445-99-п ) від 24.03.99 )

3. Нарахування портових зборів здійснюється з умовного об'єму судна, який обчислюється в кубічних метрах і дорівнює добутку трьох величин (довжина судна, ширина судна і висота борту судна), визначених в обмірному свідоцтві (головні розмірення) або документі, що його замінює.

Для морських суден, крім твіндечних суден, що перевозять вантажі на верхній палубі чи мають дві або більше палуб, висота борту, яка використовується для обчислення об'єму судна, повинна становити не менше половини ширини судна. ( Абзац другий пункту 3 в редакції Постанови КМ N 700 ( 700-2000-п ) від 25.04 2000 )

Умовний об'єм баржо-буксирних складів, караванів та інших складених плавучих споруд для нарахування всіх видів зборів, крім санітарного, дорівнює сумі об'ємів окремих елементів.

Для розрахунку всіх видів зборів умовний об'єм суден РО-РО, РО-ФЛОУ, ОБО, ЛО-РО контейнеровозів, худобовозів, ліхтеровозів, автомобілевозів застосовується з коефіцієнтом 0,7. Тип судна та його спеціалізація визначаються за судновими документами. Коефіцієнт 0,7 застосовується тільки у разі використання зазначених суден відповідно до їх спеціалізації. ( Абзац четвертий пункту 3 із змінами, внесеними згідно з Постановою КМ N 700 ( 700-2000-п ) від 25.04 2000 )

Для суден групи Б, що мають дві або більше палуб, висота борту, яка використовується для обчислення об'єму судна, повинна становити половину ширини судна. ( Пункт 3 доповнено абзацом згідно з Постановою КМ N 700 ( 700-2000-п ) від 25.04 2000 )

( Пункт 3 в редакції Постанови КМ N 445 ( 445-99-п ) від 24.03.99 )

4. Для ліхтеровозів, що здійснюють вантажні операції з ліхтерами на зовнішньому або внутрішньому рейді, портові збори нараховуються з об'єму ліхтерів, зданих ліхтеровозом при прибутті до порту і прийнятих ним при виході з нього.

5. Для вантажних суден групи А, які працюють на лініях закордонного плавання, відкритих у встановленому порядку, під час справляння корабельного збору надається знижка у розмірі 20 відсотків.

6. Основними ознаками лінії закордонного плавання є:

установлення обов'язкових і факультативних іноземних та українських портів заходу;

закріплення для роботи на лінії типів суден;

установлення періодичності заходу закріплених суден в українські порти;

реєстрації лінії Державним департаментом морського і річкового транспорту за поданням адміністрації порту (морського порту).

7. Для суден, що заходять у порт Южний під навантаження генеральних та навалочних вантажів, порт може застосовувати знижку з усіх видів портових зборів у розмірі 50 відсотків.

У порту Ялта застосовуються такі знижки: ( Пункт 7 доповнено абзацом згідно з Постановою КМ N 445 ( 445-99-п ) від 24.03.99 )

50 відсотків - із ставки корабельного збору для суден групи А; ( Пункт 7 доповнено абзацом згідно з Постановою КМ N 445 ( 445-99-п ) від 24.03.99 )

20 відсотків - із ставок усіх видів портових зборів для круїзних пасажирських суден закордонного плавання групи Б (за винятком тих, що виконують вантажопасажирські рейси). ( Пункт 7 доповнено абзацом згідно з Постановою КМ N 445 ( 445-99-п ) від 24.03.99 )

У порту Одеса застосовується знижка у розмірі 10 відсотків із ставок усіх видів портових зборів для круїзних пасажирських суден закордонного плавання групи Б (за винятком тих, що виконують вантажопасажирські рейси. ( Пункт 7 доповнено абзацом згідно з Постановою КМ N 445 ( 445-99-п ) від 24.03.99 )

8. Якщо на судно поширюється застосування кількох знижок портових зборів, застосовується тільки найбільша порівняно з базовою ставкою.

9. Державна належність судна і відповідно наданий йому статус під час справляння портових зборів визначається за прапором, під яким це судно плаває, незалежно від того, хто є його власником і хто його використовує.

10. Сплата портових зборів здійснюється відповідно до Декрету Кабінету Міністрів України від 19 лютого 1993 р. N 15 ( 15-93 ) "Про систему валютного регулювання і валютного контролю". ( Пункт 10 в редакції Постанови КМ N 445 ( 445-99-п ) від 24.03.99 )

11. Із сум портових зборів, що справляються у валюті України, податок на добавлену вартість сплачується відповідно до законодавства. При цьому під час надання портом послуг суднам каботажного плавання, сума зборів, визначена відповідно до цього Положення, збільшується на суму податку на добавлену вартість, а в інших випадках - сума податку на добавлену вартість, що підлягає сплаті до бюджету, обчислюється з суми зборів, нарахованих і сплачених порту без такого збільшення.

Примітки: 1. Судна, що заходять у порти для здійснення процедур, пов'язаних з пропуском через державний кордон України без виконання вантажних операцій, звільняються від сплати корабельного збору.

2. У Дніпро-Бузькому морському порту збір безпосередньо сплачується державному підприємству - морській державній адміністрації Дніпро-Бузького морського порту (далі - морська державна адміністрація порту).

( Пункт 12 із змінами, внесеними згідно з Постановами КМ N 445 ( 445-99-п ) від 24.03.99, КМ N 700 ( 700-2000-п ) від 25.04.2000 )

13. Від сплати корабельного збору звільняються судна груп Д та Е.

14. Корабельний збір за пільговими ставками справляється із суден, що плавають під Державним прапором України, та із суден, що плавають під прапором держав, з якими Україна уклала міжнародні договори про надання суднам режиму найбільшого сприяння або національного режиму.

Ставки корабельного збору для суден у каботажному плаванні застосовуються тільки для суден, що здійснюють рейси у каботажному плаванні під Державним прапором України.

У разі, коли максимальна осадка великотоннажних суден, зазначена в обмірному свідоцтві, перевищує встановлену для конкретного порту допустиму осадку судна, що призводить до неповного його завантаження, порт має право при нарахуванні корабельного збору зменшувати висоту борту судна на величину невикористаної осадки.

( Пункт 14 із змінами, внесеними згідно з Постановою КМ N 445 ( 445-99-п ) від 24.03.99, в редакції Постанови КМ N 700 ( 700-2000-п ) від 25.04.2000 )

15. Якщо судна групи А протягом одного рейсу заходять послідовно у кілька портів України, корабельний збір справляється:

у разі заходження в два порти - із знижкою 50 відсотків базової ставки у кожному порту заходження;

у разі заходження більш як у два порти - у першому порту із знижкою 50, а в кожному наступному - 75 відсотків базової ставки. ( Пункт 15 в редакції Постанови КМ N 445 ( 445-99-п ) від 24.03.99 )

16. Із суден групи Б корабельний збір справляється у кожному порту заходу при вході у порт і виході з нього за ставками із знижкою 50 відсотків тільки за перший і другий рейси, що здійснюються судном протягом календарного року. Під час наступних заходів у порт протягом календарного року корабельний збір з цих суден не справляється.

17. Для суден групи В корабельний збір справляється за кожне заходження в порт і вихід з порту за такими ставками:

1) для суден у закордонному плаванні:

40,5 долара США - із судна, буксира;

20,25 долара США - з одиниці (баржа, ліхтер);

2) для суден у каботажному плаванні:

10 доларів США - із судна-буксира;

5 доларів США - з одиниці (баржа, ліхтер).

( Абзац четвертий виключено на підставі Постанови КМ N 700 (700-2000-п ) від 25.04.2000 ) У разі коли максимальна осадка великотоннажних суден (максимальна осадка більша ніж 4,5 м) перевищує допустиму осадку суден у порту, що приводить до неповного їх завантаження, корабельний збір справляється з умовного об'єму суден, який обчислюється виходячи з їх довжини, ширини та допустимої осадки.

( Абзац п'ятий виключено на підставі Постанови КМ N 700 (700-2000-п ) від 25.04.2000 ) Допустима осадка суден у порту встановлюється "Обов'язковими постановами по порту.

Корабельний збір, що справляється із суден групи В, які заходять у Дніпро-Бузький морський порт, перераховується морській державній адміністрації порту. ( Пункт 17 доповнено абзацом згідно з Постановою КМ N 700 (700-2000-п ) від 25.04.2000 )
