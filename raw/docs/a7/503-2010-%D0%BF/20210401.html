ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 23 червня 2010 р. N 503

ПОРЯДОК використання коштів, передбачених у державному бюджеті на формування Аграрним фондом державного інтервенційного фонду, а також закупівлю матеріально-технічних ресурсів для потреб сільськогосподарських товаровиробників

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 96 ( 96-2011-п ) від 07.02.2011 }

1. Цей Порядок визначає механізм використання коштів, передбачених у Державному бюджеті України на відповідний рік Міністерству аграрної політики та продовольства на формування Аграрним фондом державного інтервенційного фонду, а також закупівлю матеріально-технічних ресурсів для потреб сільськогосподарських товаровиробників (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 96 ( 96-2011-п ) від 07.02.2011 }

2. Міністерство аграрної політики та продовольства спрямовує бюджетні кошти Аграрному фонду для здійснення фінансових інтервенцій на організованому аграрному ринку, заставних, форвардних та ф'ючерсних закупівель об'єктів державного цінового регулювання.

3. Аграрний фонд використовує бюджетні кошти для закупівлі об'єктів державного цінового регулювання до державного інтервенційного фонду шляхом здійснення фінансових інтервенцій, заставних, форвардних та ф'ючерсних закупівель з урахуванням таких особливостей:

фінансові інтервенції здійснюються відповідно до вимог Закону України "Про державну підтримку сільського господарства України" ( 1877-15 );

заставні, форвардні та ф'ючерсні закупівлі здійснюються Аграрним фондом у встановленому законодавством порядку;

Аграрний фонд може за окремим рішенням Кабінету Міністрів України використовувати бюджетні кошти для закупівлі об'єктів державного цінового регулювання, не пов'язаних з державним ціновим регулюванням, та матеріально-технічних ресурсів для потреб сільськогосподарських товаровиробників на умовах і в обсягах, що визначені таким рішенням.

4. Операції, пов'язані з фінансовими інтервенціями, форвардними та ф'ючерсними закупівлями об'єктів державного цінового регулювання, а також матеріально-технічних ресурсів для потреб сільськогосподарських товаровиробників, проводяться Аграрним фондом на Аграрній біржі.

5. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

6. Аграрний фонд подає щокварталу до 10 числа звітного періоду Міністерству аграрної політики та продовольства інформацію про обсяг використання бюджетних коштів.

Міністерство аграрної політики та продовольства подає Мінфіну в установлений для фінансової звітності строк звіт про використання бюджетних коштів.

7. Складення та подання звітності про використання бюджетних коштів, а також контроль за використанням бюджетних коштів здійснюються уповноваженими органами в установленому законодавством порядку.

{ Пункт 7 із змінами, внесеними згідно з Постановою КМ N 96 ( 96-2011-п ) від 07.02.2011 }
