МІНІСТЕРСТВО ФІНАНСІВ УКРАЇНИ

НАКАЗ

N 43 від 29.06.93 Зареєстровано в Міністерстві м.Київ юстиції України 9 липня 1993 р. за N 84

( Наказ втратив чинність на підставі Наказу Міністерства фінансів N 565 ( z0993-05 ) від 18.08.2005 )

Про затвердження Інструкції про умови ліцензування страхової діяльності на території України та контролю за їх дотриманням

( Із змінами, внесеними згідно з Наказом Міністерства фінансів N 22 ( v0022201-94 ) від 03.03.94 )

Відповідно до постанови Кабінету Міністрів України від 13 січня 1993 року N 18 ( 18-93-п ) "Про внесення змін і доповнень до постанови Ради Міністрів УРСР від 15 квітня 1991 р. N 99 "Про порядок видачі суб'єктам підприємницької діяльності спеціальних дозволів (ліцензій) на здійснення окремих видів діяльності та про розмір плати за державну реєстрацію суб'єктів підприємництва" НАКАЗУЮ:

1. Затвердити Інструкцію про умови ліцензування страхової діяльності на території України та контролю за їх дотриманням (додається).

2. Покласти роботу по здійсненню ліцензування страхової діяльності на Управління удосконалення фінансового механізму.

3. Цю Інструкцію довести до відома усіх зацікавлених організацій та установ.

4. Контроль за виконанням наказу покласти на першого заступника Міністра Сивульського М.І.

Міністр Г.О.П'ятаченко

( Інструкція про умови ліцензування страхової діяльності на території України та контролю за їх дотриманням втратила чинність на підставі Наказу Міністерства фінансів N 22 ( v0022201-94 ) від 03.03.94 )
