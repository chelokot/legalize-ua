Президент України; Указ від 05.10.2004 № 1171/2004

Про внесення змін до Положення про порядок надання грантів Президента України молодим діячам у галузі театрального, музичного, образотворчого мистецтва та кінематографії для створення і реалізації творчих проектів

Стан: Втратив чинність

Ідентифікатор: 1171/2004

Текст документа від 26.12.2025:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 982/2025 ( 982/2025 ) від 24.12.2025 }

Про внесення змін до Положення про порядок надання грантів Президента України молодим діячам у галузі театрального, музичного, образотворчого мистецтва та кінематографії для створення і реалізації творчих проектів

Внести до Положення про порядок надання грантів Президента України молодим діячам у галузі театрального, музичного, образотворчого мистецтва та кінематографії для створення і реалізації творчих проектів, затвердженого Указом Президента України від 6 лютого 1999 року N 127 ( 127/99 ) (зі змінами, внесеними Указом від 15 березня 2002 року N 242 ( 242/2002 ), такі зміни:

1. У пункті 4 слова "а для одержання гранту в галузі театрального, музичного мистецтва та кінематографії - також" виключити.

2. У пункті 8:

абзаци перший і другий виключити;

абзац третій після слова "музичного" доповнити словом "образотворчого".

3. У пункті 9:

абзац перший виключити;

перше речення абзацу другого після слова "музичного" доповнити словом "образотворчого".

Президент України Л.КУЧМА

м. Київ, 5 жовтня 2004 року N 1171/2004
