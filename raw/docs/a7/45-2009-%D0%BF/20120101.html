Про скасування постанови Кабінету Міністрів України від 20 грудня 2008 р. N 1118

Стан: Втратив чинність

Текст документа від 01.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 січня 2009 р. N 45 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1374 ( 1374-2011-п ) від 28.12.2011 }

Про скасування постанови Кабінету Міністрів України від 20 грудня 2008 р. N 1118

{ Із змінами, внесеними згідно з Постановою КМ N 67 ( 67-2009-п ) від 04.02.2009 }

Кабінет Міністрів України постановляє:

Скасувати постанову Кабінету Міністрів України від 20 грудня 2008 р. N 1118 ( 1118-2008-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 16 березня 2000 р. N 507" (Офіційний вісник України, 2008 р., N 100, ст. 3309).

У зв'язку з цим відновити дію пункту 4 постанови Кабінету Міністрів України від 16 березня 2000 р. N 507 ( 507-2000-п ) "Про роз'яснення Указу Президента України від 3 липня 1998 р. N 727" у редакції, що діяла на день набрання чинності постановою Кабінету Міністрів України від 20 грудня 2008 р. N 1118 ( 1118-2008-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 16 березня 2000 р. N 507" (Офіційний вісник України, 2008 р., N 100, ст. 3309). { Постановляючу частину доповнено абзацом згідно з Постановою КМ N 67 ( 67-2009-п ) від 04.02.2009 }
