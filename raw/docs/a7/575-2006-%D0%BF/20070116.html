Текст документа від 16.01.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 квітня 2006 р. N 575 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1622 ( 1622-2006-п ) від 16.11.2006 }

Про внесення зміни до пункту 8 Положення про Департамент державної виконавчої служби

Кабінет Міністрів України постановляє:

Внести до пункту 8 Положення про Департамент державної виконавчої служби, затвердженого постановою Кабінету Міністрів України від 3 серпня 2005 р. N 711 ( 711-2005-п ) (Офіційний вісник України, 2005 р., N 32, ст. 1926), зміну, виключивши слова "погодженим з директором Департаменту".

Прем'єр-міністр України Ю.ЄХАНУРОВ
