{ Розпорядження втратило чинність на підставі Постанови КМ N 205 ( 205-2013-п ) від 27.03.2013 }

Про передачу МОН повноважень на затвердження порядку ведення Державного реєстру договорів про трансфер технологій

Відповідно до статті 22 Закону України "Про Кабінет Міністрів України" ( 514-16 ) передати МОН передбачені статтею 13 Закону України "Про державне регулювання діяльності у сфері трансферу технологій" ( 143-16 ) повноваження на затвердження порядку ведення Державного реєстру договорів про трансфер технологій.
