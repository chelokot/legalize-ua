Текст документа від 27.04.1998:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 5 квітня 1991 р. N 82 Київ

( Постанова втратила чинність на підставі Постанови КМ N 577 ( 577-98-п ) від 27.04.98 )

Про республіканську постійно діючу книжкову лотерею

Рада Міністрів Української РСР постановляє:

Дозволити Державному комітетові УРСР по пресі проводити республіканську постійно діючу книжкову лотерею в порядку, передбаченому постановою Ради Міністрів УРСР від 21 грудня 1990 р. N 386 ( 386-90-п ) "Про порядок проведення грошових, речових і грошово-речових лотерей в Українській РСР" (ЗП УРСР, 1990 р., N 12, ст. 74 ).

У зв'язку з цим визнати такими, що втратили чинність, постанову Ради Міністрів УРСР від 20 квітня 1967 р. N 241 "Про проведення в Українській РСР постійно діючої книжкової лотереї" (ЗП УРСР, 1967 р., N 4, ст. 37) та постанову Ради Міністрів УРСР від 19 жовтня 1971 р. N 471 "Про внесення змін до Умов постійно діючої в Українській РСР книжкової лотереї" (ЗП УРСР, 1971 р., N 10, ст. 90).
