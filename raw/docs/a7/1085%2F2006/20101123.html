Президент України; Указ від 15.12.2006 № 1085/2006

Про деякі питання Національної системи координації співробітництва України з Організацією Північноатлантичного договору

Стан: Втратив чинність

Ідентифікатор: 1085/2006

Текст документа від 23.11.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1039/2010 ( 1039/2010 ) від 18.11.2010 }

Про деякі питання Національної системи координації співробітництва України з Організацією Північноатлантичного договору

{ Із змінами, внесеними згідно з Указом Президента N 496/2010 ( 496/2010 ) від 02.04.2010 }

1. Внести до Указу Президента України від 13 березня 2006 року N 215 ( 215/2006 ) "Про Національну систему координації співробітництва України з Організацією Північноатлантичного договору" такі зміни:

1) абзац третій частини другої статті 1 викласти в такій редакції:

"Кабінет Міністрів України забезпечує, в тому числі через Урядовий комітет з питань правової політики, оборони, міжнародного співробітництва та європейської інтеграції, реалізацію державної політики щодо співробітництва України з НАТО, зокрема щодо досягнення критеріїв членства України в НАТО";

2) у статті 2:

абзац перший викласти в такій редакції:

"2. Установити, що національними координаторами співробітництва України з НАТО призначаються посадові особи, до компетенції яких за розподілом обов'язків належать питання євроатлантичної інтеграції, зокрема";

слова "перший заступник", "заступник" замінити словами "перший заступник або заступник".

{ Стаття 2 втратила чинність на підставі Указу Президента N 496/2010 ( 496/2010 ) від 02.04.2010 }

Президент України В.ЮЩЕНКО
