Стан: Чинний

Текст документа від 02.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про ліквідацію Політичної ради при Президентові України

Відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Ліквідувати Політичну раду при Президентові України.

У зв'язку з цим визнати такими, що втратили чинність:

Указ Президента України від 12 жовтня 2005 року N 1435 ( 1435/2005 ) "Про Політичну раду при Президентові України";

Указ Президента України від 17 травня 2006 року N 410 ( 410/2006 ) "Про призначення О. Рибачука секретарем Політичної ради при Президентові України";

Указ Президента України від 18 жовтня 2006 року N 885 ( 885/2006 ) "Про внесення змін до Указу Президента України від 12 жовтня 2005 року N 1435";

Указ Президента України від 9 червня 2008 року N 526 ( 526/2008 ) "Про внесення зміни до Указу Президента України від 12 жовтня 2005 року N 1435".

2. Цей Указ набирає чинності з дня його опублікування.
