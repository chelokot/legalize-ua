Текст документа від 22.07.2005:

МІНІСТЕРСТВО ЕКОНОМІКИ УКРАЇНИ

НАКАЗ

22.07.2005 N 215

Зареєстровано в Міністерстві юстиції України 5 вересня 2005 р. за N 987/11267

Про визнання такими, що втратили чинність, деяких наказів Міністерства економіки та з питань європейської інтеграції України

Відповідно до постанови Кабінету Міністрів України від 28.05.2005 N 406 ( 406-2005-п ) "Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України" НАКАЗУЮ:

1. Визнати такими, що втратили чинність:

наказ Міністерства економіки та з питань європейської інтеграції України від 29.09.2003 N 263 ( z0887-03 ) "Про Порядок реєстрації (обліку) зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою", зареєстрований у Міністерстві юстиції України 02.10.2003 за N 887/8208;

наказ Міністерства економіки та з питань європейської інтеграції України від 26.02.2004 N 72 ( z0273-04 ) "Про внесення змін до наказу Міністерства економіки та з питань європейської інтеграції України від 29.09.2003 N 263", зареєстрований у Міністерстві юстиції України 02.03.2004 за N 273/8872.

2. Контроль за виконанням цього наказу покласти на заступника Міністра економіки України Березного А.В.

Виконуючий обов'язки Міністра економіки України С.Романюк
