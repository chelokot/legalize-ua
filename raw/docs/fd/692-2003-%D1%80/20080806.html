Про затвердження нового складу експертно-апеляційної ради при Держпідприємництві

Стан: Втратив чинність

Ідентифікатор: 692-2003-р

Текст документа від 06.08.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 листопада 2003 р. N 692-р Київ

Про затвердження нового складу експертно-апеляційної ради при Держпідприємництві

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1087-р ( 1087-2008-р ) від 06.08.2008 }

Затвердити новий склад експертно-апеляційної ради при Держпідприємництві, утвореної постановою Кабінету Міністрів України від 8 листопада 2000 р. N 1669 ( 1669-2000-п ) (Офіційний вісник України, 2000 р., N 45, ст. 1944), що додається.

Дозволити голові експертно-апеляційної ради вносити у разі потреби зміни до її складу.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 25
