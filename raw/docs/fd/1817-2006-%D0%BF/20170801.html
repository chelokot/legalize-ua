КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 грудня 2006 р. N 1817 Київ

Про внесення змін до постанов Кабінету Міністрів України від 7 квітня 1998 р. N 469 і від 1 березня 1999 р. N 304

{ Із змінами, внесеними згідно з Постановами КМ N 741 ( 741-2015-п ) від 23.09.2015 N 540 ( 540-2017-п ) від 19.07.2017 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 7 квітня 1998 р. N 469 ( 469-98-п ) "Про затвердження Положення про державну атестацію науково-дослідних (науково-технічних) установ" (Офіційний вісник України, 1998 р., N 14, ст. 545; 1999 р., N 33, ст. 1727) і від 1 березня 1999 р. N 304 ( 304-99-п ) "Про порядок визначення обсягів базового фінансування фундаментальних наукових досліджень за рахунок коштів державного бюджету" (Офіційний вісник України, 1999 р., N 9, ст. 344) зміни, що додаються.
