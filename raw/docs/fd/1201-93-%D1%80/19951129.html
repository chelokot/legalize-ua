Кабінет Міністрів України; Розпорядження від 31.12.1993 № 1201-р

Про звільнення від сплати мита спеціальних матеріалів, що ввозяться для використання Управлінням справами Верховної Ради України

Стан: Втратив чинність

Ідентифікатор: 1201-93-р

Текст документа від 29.11.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 грудня 1993 р. N 1201-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 957 ( 957-95-п ) від 29.11.95 )

Звільнити від сплати мита під час переміщення через митний кордон України спеціальних матеріалів, що ввозяться для використання Управлінням справами Верховної Ради України згідно з контрактом N 23/509016.

Виконуючий обов'язки Прем'єр-міністра України Ю.ЗВЯГІЛЬСЬКИЙ
