Про призначення т. Комісаренка С.В. головою Республіканської надзвичайної протиепідемічної комісії при Раді Міністрів УРСР

Текст документа від 21.05.1992:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 1 вересня 1990 р. N 236 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 260 ( 260-92-п ) від 21.05.92 }

Про призначення т. Комісаренка С.В. головою Республіканської надзвичайної протиепідемічної комісії при Раді Міністрів УРСР

Рада Міністрів Української РСР постановляє:

Відповідно до розподілу обов'язків між заступниками Голови Ради Міністрів УРСР призначити т. Комісаренка Сергія Васильовича головою Республіканської надзвичайної протиепідемічної комісії при Раді Міністрів УРСР.

Визнати таким, що втратив чинність, пункт 1 постанови Ради Міністрів УРСР від 16 квітня 1980 р. N 245.
