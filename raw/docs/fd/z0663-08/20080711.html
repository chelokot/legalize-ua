МІНІСТЕРСТВО ОХОРОНИ НАВКОЛИШНЬОГО ПРИРОДНОГО СЕРЕДОВИЩА УКРАЇНИ

НАКАЗ

11.07.2008 N 358

Зареєстровано в Міністерстві юстиції України 17 липня 2008 р. за N 663/15354

Про визнання такими, що втратили чинність, деяких наказів Мінприроди

З метою приведення нормативно-правових актів Мінприроди у відповідність до постанови Кабінету Міністрів України від 17 квітня 2008 року N 392 ( 392-2008-п ) "Про забезпечення виконання міжнародних зобов'язань України за Рамковою конвенцією ООН про зміну клімату та Кіотським протоколом до неї" НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Мінприроди:

від 17.07.2006 N 341 ( z0925-06 ) "Про затвердження Вимог до документів, у яких обґрунтовуються обсяги антропогенних викидів та абсорбції парникових газів, для отримання листа-підтримки власником джерела викидів, на якому планується реалізація проекту спільного впровадження", зареєстрований в Мін'юсті 02.08.2006 за N 925/12799;

від 17.07.2006 N 342 ( z0926-06 ) "Про затвердження Вимог до підготовки проектів спільного впровадження", зареєстрований в Мін'юсті 02.08.2006 за N 926/12800.

2. Департаменту державного екологічного моніторингу (Овчиннікова Н.Б.) забезпечити подання наказу на державну реєстрацію до Міністерства юстиції України в установленому порядку.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Бевзу В.О.

Міністр Г.Філіпчук
