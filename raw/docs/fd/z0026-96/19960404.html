Держстандарт України; Наказ від 03.01.1996 № 1

Про внесення змін до наказу від 06.02.95 р. N 44 "Про внесення доповнень до Переліку продукції, що підлягає обов'язковій сертифікації"

Реєстрація: Мін'юст України від 17.01.1996 № 26/1051

Стан: Втратив чинність

Ідентифікатор: z0026-96

Текст документа від 04.04.1996:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ПО СТАНДАРТИЗАЦІЇ, МЕТРОЛОГІЇ ТА СЕРТИФІКАЦІЇ

НАКАЗ

N 1 від 03.01.96 Зареєстровано в Міністерстві м.Київ юстиції України 17 січня 1996 р. vd960103 vn1 за N 26/1051

Про внесення змін до наказу від 06.02.95 р. N 44 "Про внесення доповнень до Переліку продукції, що підлягає обов'язковій сертифікації"

( Із змінами, внесеними згідно з Наказом Держкомстандарту N 132 ( z0156-96 ) від 26.03.96 )

Відповідно до Декрету Кабінету Міністрів України від 10.05.93 р. N 46-93 "Про стандартизацію і сертифікацію" для забезпечення строків введення обов'язкової сертифікації нафти і палива на виконання рішення колегії Держстандарту України від 28 грудня 1995 року (протокол N 5), НАКАЗУЮ:

1. Абзац третій пункту 2 наказу Держстандарту України від 06.02.95 р. N 44 ( z0040-95 ) викласти у наступній редакції:

"продукція за підрозділами 24.1-24.5, розділами 26-29 та підрозділами 31.3-31.6 - з 1 січня 1996 року". ( Абзац другий пункту 1 із змінами, внесеними згідно з Наказом Держкомстандарту N 132 ( z0156-96 ) від 26.03.96 )

2. Управлінню сертифікації Держстандарту України довести зазначені зміни до міністерств, відомств і установ.

Голова Держстандарту України Т.М.Кисільова
