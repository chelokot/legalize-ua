МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

12.03.2007 N 91

Зареєстровано в Міністерстві юстиції України 28 березня 2007 р. за N 282/13549

Про визнання такими, що втратили чинність, наказів Мінпраці від 10.12.2002 N 639 та від 22.08.2003 N 234

На виконання доручення Кабінету Міністрів України від 12.01.2007 N 554/3/1-07 до Закону України "Про внесення змін до деяких законодавчих актів України з питань закупівлі товарів, робіт і послуг за державні кошти" від 01.12.2006 N 424-V ( 424-16 ) та з метою приведення власних нормативно-правових актів у відповідність з цим Законом НАКАЗУЮ:

Визнати такими, що втратили чинність:

наказ Міністерства праці та соціальної політики України від 10.12.2002 N 639 ( z0990-02 ) "Про затвердження Положення про відбір навчальних закладів для організації професійного навчання безробітних за рахунок коштів Фонду загальнообов'язкового державного соціального страхування на випадок безробіття", зареєстрований у Міністерстві юстиції України 19.12.2002 за N 990/7278;

наказ Міністерства праці та соціальної політики України від 22.08.2003 N 234 ( z0776-03 ) "Про внесення змін до Положення про відбір навчальних закладів для організації професійного навчання безробітних за рахунок коштів Фонду загальнообов'язкового державного соціального страхування на випадок безробіття", зареєстрований у Міністерстві юстиції України 09.09.2003 за N 776/8097.
