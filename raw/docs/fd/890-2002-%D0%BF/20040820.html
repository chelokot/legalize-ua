Про умови оплати праці працівників національних закладів культури

( Із змінами, внесеними згідно з Постановою КМ N 52 ( 52-2003-п ) від 18.01.2003 )

( Про підвищення з 1 березня 2004 р. на 10,8 відсотка посадових окладів додатково див. Постанову КМ N 166 ( 166-2004-п ) від 11.02.2004 )

( Про підвищення з 1 січня 2005 р. у два рази діючих станом на 1 березня 2004 р. максимальні посадових окладів додатково див.

Постанову КМ N 995 ( 995-2004-п ) від 03.08.2004 )

З метою забезпечення єдиного підходу в оплаті праці працівників національних закладів культури Кабінет Міністрів України постановляє:

1. Установити, що визначені станом на 1 січня 2002 р. посадові оклади (ставки заробітної плати) працівників національних закладів культури, на яких не поширюється дія постанови Кабінету Міністрів України від 15 жовтня 2001 р. N 1345 ( 1345-2001-п ) "Про оплату праці працівників національних закладів культури" (Офіційний вісник України, 2001 р., N 42, ст. 1889), підвищуються в розмірах згідно з додатком.

2. Міністерству фінансів передбачати під час розроблення проектів закону про Державний бюджет України на 2003 р. та наступні роки асигнування на підвищення посадових окладів (ставок заробітної плати) працівників національних закладів культури.

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 10 січня 2002 р. N 18 ( 18-2002-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" (Офіційний вісник України, 2002 р., N 2, ст. 66) у частині підвищення на 15 відсотків посадових окладів (ставок заробітної плати) працівників національних закладів культури, зазначених у пункті 1 цієї постанови.

4. Ця постанова набирає чинності з 1 січня 2003 року.
