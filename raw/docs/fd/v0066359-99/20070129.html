{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 6 ( v0006359-07 ) від 29.01.2007 }

Відповідно, до статей 11, 12 17 Закону України. "Про Центральну виборчу комісію" ( 733/97-ВР ) та статті 18 Закону України "Про всеукраїнський та місцеві референдуми" ( 1286-12 ) Центральна виборча комісія постановляє:

Затвердити форму підписного листа, що видається ініціативним групам для збирання підписів громадян під вимогою про проведення місцевого референдуму (додається).
