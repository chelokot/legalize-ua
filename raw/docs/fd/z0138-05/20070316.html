Зареєстровано в Міністерстві юстиції України 2 лютого 2005 р. за N 138/10418

Про внесення змін до наказу Міністерства праці та соціальної політики України від 04.04.2000 N 76

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства праці та соціальної політики

N 76 ( z0221-00 ) від 04.04.2000, до якого вносились зміни }

На виконання постанови Кабінету Міністрів України від 15.01.2005 N 37 ( 37-2005-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 04.04.2000 N 76 ( z0221-00 ) "Про умови оплати праці працівників Національної служби посередництва і примирення", зареєстрованого в Міністерстві юстиції України 11.04.2000 за N 221/4442 (зі змінами), виклавши додатки 1, 2 у новій редакції (додаються).

2. Ці умови застосовуються з 1 січня 2005 року.

В.о. Міністра М.Папієв
