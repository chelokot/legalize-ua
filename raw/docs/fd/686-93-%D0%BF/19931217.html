( Із змінами, внесеними згідно з Постановою КМ N 1040 ( 1040-93-п ) від 17.12.93 )

Кабінет Міністрів України постановляє:

1. Звільнити від обкладання вивізним (експортним) митом товари згідно з додатком N 1.

2. Зменшити ставки вивізного (експортного) мита на товари згідно з додатком N 2.
