Кабінет Міністрів України; Розпорядження від 11.01.2012 № 7-р

Про доручення на здійснення державних зовнішніх запозичень у 2012 році

Стан: Чинний

Ідентифікатор: 7-2012-р

Текст документа від 15.02.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 січня 2012 р. N 7-р Київ

Про доручення на здійснення державних зовнішніх запозичень у 2012 році

{ Із змінами, внесеними згідно з Розпорядженням КМ N 91-р ( 91-2012-р ) від 15.02.2012 }

Відповідно до частини першої статті 16 Бюджетного кодексу України ( 2456-17 ) доручити Міністру фінансів Хорошковському Валерію Івановичу здійснювати державні зовнішні запозичення у 2012 році у межах, передбачених Законом України “Про Державний бюджет України на 2012 рік” ( 4282-17 ), і на умовах, визначених Кабінетом Міністрів України, та укладати для цього необхідні договори.

{ Текст Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 91-р ( 91-2012-р ) від 15.02.2012 }
