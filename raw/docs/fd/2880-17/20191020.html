Верховна Рада України; Закон від 23.12.2010 № 2880-VI

Про внесення змін до деяких законодавчих актів України щодо гарантування прав концесіонерів

Стан: Чинний

Ідентифікатор: 2880-17

Текст документа від 20.10.2019:

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законодавчих актів України щодо гарантування прав концесіонерів

( Відомості Верховної Ради України (ВВР), 2011, N 30, ст.275 )

{ Із змінами, внесеними згідно із Законом N 155-IX ( 155-20 ) від 03.10.2019, ВВР, 2019, N 48, ст.325 }

Верховна Рада України постановляє:

I. Внести зміни до таких законодавчих актів України:

1. Частину другу статті 134 Земельного кодексу України ( 2768-14 ) (Відомості Верховної Ради України, 2002 р., N 3-4, ст. 27) після абзацу двадцять першого доповнити новим абзацом такого змісту:

"використання земельних ділянок для здійснення концесійної діяльності".

У зв'язку з цим абзац двадцять другий вважати абзацом двадцять третім.

{ Пункт 2 розділу I втратив чинність на підставі Закону N 155-IX ( 155-20 ) від 03.10.2019 }

II. Цей Закон набирає чинності з дня його опублікування.
