КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 березня 2006 р. N 309 Київ

Про затвердження бюджету Пенсійного фонду України на 2006 рік

{ Із змінами, внесеними згідно з Постановою КМ N 1522 ( 1522-2006-п ) від 02.11.2006 }

Кабінет Міністрів України постановляє:

Затвердити бюджет Пенсійного фонду України на 2006 рік, що додається, за доходами в сумі 70202306,4 тис. гривень і за видатками в сумі 70202306,4 тис. гривень, передбачивши, що у загальній сумі доходів бюджету Пенсійного фонду України враховуються кошти в сумі 7289495,4 тис. гривень, що виділяються згідно із Законом України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) за програмою "Покриття дефіциту коштів Пенсійного фонду України для виплати пенсій".
