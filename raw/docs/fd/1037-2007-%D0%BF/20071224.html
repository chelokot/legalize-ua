ПОСТАНОВА від 8 серпня 2007 р. N 1037 Київ

{ Постанову скасовано на підставі Постанови КМ N 1403 ( 1403-2007-п ) від 24.12.2007 }

{ Дію Постанови зупинено згідно з Указом Президента N 819/2007 ( 819/2007 ) від 04.09.2007 }

Про управління державними корпоративними правами закритого акціонерного товариства "Транснаціональна фінансово-промислова нафтова компанія "Укртатнафта"

Кабінет Міністрів України постановляє:

1. Установити, що повноваження з управління державними корпоративними правами закритого акціонерного товариства "Транснаціональна фінансово-промислова нафтова компанія "Укртатнафта" здійснює Фонд державного майна.

2. Міністерству палива та енергетики разом з Національною акціонерною компанією "Нафтогаз України" здійснити у місячний строк заходи щодо передачі Фондові державного майна пакета акцій, які належать державі у статутному капіталі закритого акціонерного товариства "Транснаціональна фінансово-промислова нафтова компанія "Укртатнафта".

3. Уповноважити Голову Фонду державного майна Семенюк В.П. підписати акт приймання-передачі зазначеного у пункті 2 цієї постанови пакета акцій.
