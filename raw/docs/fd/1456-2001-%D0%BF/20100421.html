КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 листопада 2001 р. N 1456 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 316 ( 316-2010-п ) від 19.04.2010 }

Про внесення змін до Положення про Постійного Представника Кабінету Міністрів України у Верховній Раді України

Кабінет Міністрів України постановляє:

Внести до Положення про Постійного Представника Кабінету Міністрів України у Верховній Раді України, затвердженого постановою Кабінету Міністрів України від 3 жовтня 2001 р. N 1292 ( 1292-2001-п ), такі зміни:

1) у пункті 1 слово "посадовою" виключити;

2) пункт 7 викласти у такій редакції:

"7. Організаційно-технічне забезпечення діяльності Постійного Представника здійснюється Секретаріатом Кабінету Міністрів України";

3) пункт 8 виключити.
