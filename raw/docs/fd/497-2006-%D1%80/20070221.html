Кабінет Міністрів України; Розпорядження від 28.09.2006 № 497-р

Про визначення уповноваженого органу, відповідального за виконання Угоди (у формі обміну нотами) між Урядом України та Урядом Японії про надання японського гранту непроектного типу на закупівлю товарів та Узгодженого протоколу до неї

Стан: Чинний

Ідентифікатор: 497-2006-р

Текст документа від 21.02.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 вересня 2006 р. N 497-р Київ

Про визначення уповноваженого органу, відповідального

за виконання Угоди (у формі обміну нотами) між Урядом

України та Урядом Японії про надання японського гранту непроектного типу на закупівлю товарів та Узгодженого протоколу до неї

{ Із змінами, внесеними згідно з Розпорядженням КМ N 60-р ( 60-2007-р ) від 21.02.2007 }

Визначити Держінвестицій уповноваженим органом, відповідальним за виконання Угоди (у формі обміну нотами) між Урядом України та Урядом Японії про надання японського гранту непроектного типу на закупівлю товарів та Узгодженого протоколу до неї, підписаних 15 березня 2006 р. у м. Києві.

{ Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 60-р ( 60-2007-р ) від 21.02.2007 }
