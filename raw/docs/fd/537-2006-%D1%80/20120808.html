Про визначення Компетентної організації в Координаційній раді із забезпечення безпеки шифрувальних засобів та їх експлуатації в системах урядового та закритого відомчого зв'язку держав - учасниць СНД

Стан: Чинний

Ідентифікатор: 537-2006-р

Текст документа від 08.08.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 листопада 2006 р. N 537-р Київ

Про визначення Компетентної організації в Координаційній раді із забезпечення безпеки шифрувальних засобів та їх експлуатації в системах урядового та закритого відомчого зв'язку держав - учасниць СНД

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 268-р ( 268-2007-р ) від 12.05.2007 N 774-р ( 774-2011-р ) від 17.08.2011 N 552-р ( 552-2012-р ) від 08.08.2012 }

1. Визначити, що з 1 січня 2007 р. Державна служба спеціального зв'язку та захисту інформації є Компетентною організацією в Координаційній раді із забезпечення безпеки шифрувальних засобів та їх експлуатації в системах урядового та закритого відомчого зв'язку держав - учасниць СНД.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 774-р ( 774-2011-р ) від 17.08.2011 }

2. Уповноважити першого заступника Голови Державної служби спеціального зв'язку та захисту інформації Цуркана Олександра Григоровича представляти Кабінет Міністрів України в Координаційній раді із забезпечення безпеки шифрувальних засобів та їх експлуатації в системах урядового та закритого відомчого зв'язку держав - учасниць СНД.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженнями КМ N 268-р ( 268-2007-р ) від 12.05.2007, N 774-р ( 774-2011-р ) від 17.08.2011, N 552-р ( 552-2012-р ) від 08.08.2012 }
