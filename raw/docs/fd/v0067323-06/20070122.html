Про здійснення експертизи проектів законів та проектів інших нормативно-правових актів на їх відповідність Конвенції про захист прав людини і основоположних свобод

Стан: Втратив чинність

Ідентифікатор: v0067323-06

Текст документа від 22.01.2007:

МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

15.08.2006 N 67/5

Про здійснення експертизи проектів законів та проектів інших нормативно-правових актів на їх відповідність Конвенції про захист прав людини і основоположних свобод

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 18/5 ( v0018323-07 ) від 22.01.2007 }

На виконання Закону України від 23 лютого 2006 року N 3477-IV ( 3477-15 ) "Про виконання рішень та застосування практики Європейського суду з прав людини" та постанови Кабінету Міністрів України від 31 травня 2006 року N 784 ( 784-2006-п ) "Про заходи щодо реалізації Закону України "Про виконання рішень та застосування практики Європейського суду з прав людини" НАКАЗУЮ:

1. Урядовому уповноваженому у справах Європейського суду з прав людини затвердити Методичні рекомендації щодо здійснення експертизи нормативно-правових актів (їх проектів) на відповідність Конвенції про захист прав людини і основоположних свобод ( n0003323-06 ) (далі - Методичні рекомендації).

2. Керівникам структурних підрозділів Міністерства юстиції при надходженні на експертизу до структурних підрозділів проектів законів та проектів інших нормативно-правових актів (далі - проекти нормативно-правових актів) забезпечити перевірку, чи стосуються зазначені акти за предметом правового регулювання прав і свобод, гарантованих Конвенцією про захист прав людини і основоположних свобод ( 995_004 ) (далі - Конвенція), відповідно до Методичних рекомендацій ( n0003323-06 ) та з урахуванням довідки, наведеної у Додатку 15 до Тимчасового регламенту Кабінету Міністрів України, затвердженого постановою Кабінету Міністрів України від 5 червня 2000 р. N 915 ( 915-2000-п ).

3. Керівникам структурних підрозділів Міністерства юстиції, визначеним відповідальними за здійснення правової експертизи, забезпечувати впродовж двох днів передачу копій проектів нормативно-правових актів, які за предметом правового регулювання стосуються прав та свобод, гарантованих Конвенцією ( 995_004 ), до Секретаріату Урядового уповноваженого у справах Європейського суду з прав людини. { Пункт 3 із змінами, внесеними згідно з Наказом Міністерства юстиції N 18/5 ( v0018323-07 ) від 22.01.2007 }

4. Покласти на керівників структурних підрозділів Міністерства юстиції персональну відповідальність за визначення належності проектів законів та проектів інших нормативно-правових актів до сфери регулювання Конвенцією ( 995_004 ), а також за своєчасність передання копій відповідних проектів на експертизу до Секретаріату Урядового уповноваженого у справах Європейського суду з прав людини. { Наказ доповнено пунктом згідно з Наказом Міністерства юстиції N 18/5 ( v0018323-07 ) від 22.01.2007 }

5. Керівникам структурних підрозділів Міністерства юстиції, визначеним відповідальними за підготовку проектів нормативно-правових актів, направляти ці проекти на погодження до Секретаріату Урядового уповноваженого у справах Європейського суду з прав людини. { Пункт із змінами, внесеними згідно з Наказом Міністерства юстиції N 18/5 ( v0018323-07 ) від 22.01.2007 }

6. Секретаріату Урядового уповноваженого у справах Європейського суду з прав людини (Шевчук І.А.) забезпечити:

- проведення експертизи проектів нормативно-правових актів, які за предметом правового регулювання стосуються прав та свобод, гарантованих Конвенцією ( 995_004 ), на їх відповідність зазначеній Конвенції;

- надання у строк до 10 днів структурним підрозділам Міністерства юстиції, визначеним відповідальними за здійснення правової експертизи, висновків щодо відповідності проектів нормативно-правових актів Конвенції ( 995_004 ), які підписуються заступником Міністра відповідно до розподілу функціональних повноважень. { Підпункт 2 пункту в редакції Наказу Міністерства юстиції N 18/5 ( v0018323-07 ) від 22.01.2007 }

{ Пункт із змінами, внесеними згідно з Наказом Міністерства юстиції N 18/5 ( v0018323-07 ) від 22.01.2007 }

7. Керівникам структурних підрозділів Міністерства юстиції, визначеним відповідальними за здійснення правової експертизи, забезпечити включення до Висновку Міністерства юстиції за результатами здійснення правової експертизи проекту нормативно-правового акта нового розділу:

"9. Висновок щодо відповідності проекту нормативно-правового акта Конвенції про захист прав людини і основоположних свобод" ( 995_004 ) (варіанти тез до висновку додаються).

8. Департаменту кадрової роботи та державної служби (Набоченко С.І.) довести цей наказ до відома керівників структурних підрозділів центрального апарату Міністерства юстиції, визначених відповідальними за здійснення правової експертизи.

9. Контроль за виконанням цього наказу покласти на першого заступника Міністра Крупка П.М.

Міністр Р.Зварич

Додаток

ВИСНОВОК Міністерства юстиції України за результатами правової експертизи проекту

Головний розробник -

1. Правові підстави прийняття акта

2. Відповідність проекту Конституції України ( 995_004 )

3. Відповідність проекту актам законодавства, що мають вищу юридичну силу

4. Узгодженість проекту з актами такої ж юридичної сили

5. Відповідність проекту міжнародним договорам України

6. Відповідність проекту вимогам нормопроектувальної техніки

7. Належність проекту до пріоритетних сфер, в яких здійснюється адаптація законодавства України до acquis communautaire

8. Висновок гендерно-правової експертизи

9. Висновок на відповідність Конвенції про захист прав людини і основоположних свобод ( 995_004 )

Варіанти:

1) проект нормативно-правового акта відповідає Конвенції про захист прав людини і основоположних свобод 1950 р. ( 995_004 ) та протоколів до неї;

2) проект нормативно-правового акта не відповідає Конвенції про захист прав людини і основоположних свобод 1950 р. ( 995_004 ) та протоколів до неї (наводяться положення проекту нормативно-правового акта, які не відповідають Конвенції);

3) проект нормативно-правового акта за предметом правового регулювання не стосується Конвенції про захист прав людини і основоположних свобод 1950 р. ( 995_004 ) та протоколів до неї.

10. Узагальнений висновок
