Про затвердження Переліку підприємств-монополістів, щодо яких запроваджується регулювання фондів оплати праці

Реєстрація: Мін'юст України від 10.01.2005 № 18/10298

Стан: Втратив чинність

Ідентифікатор: za018-05

Текст документа від 08.10.2005:

АНТИМОНОПОЛЬНИЙ КОМІТЕТ УКРАЇНИ

РОЗПОРЯДЖЕННЯ

17.12.2004 N 508-р

Зареєстровано в Міністерстві юстиції України 10 січня 2005 р. за N 18/10298

( Розпорядження втратило чинність на підставі Розпорядження Антимонопольного комітету

N 273-р ( za110-05 ) від 09.09.2005 )

Про затвердження Переліку підприємств-монополістів, щодо яких запроваджується регулювання фондів оплати праці

Керуючись статтею 13 Закону України "Про Антимонопольний комітет України" ( 3659-12 ) та відповідно до постанови Кабінету Міністрів України від 26 травня 2004 року N 683 ( 683-2004-п ) "Про затвердження Порядку визначення сум, що вносяться до державного бюджету підприємствами-монополістами у 2004 році та I кварталі 2005 року у зв'язку з перевищенням розрахункової величини фонду оплати праці" Антимонопольний комітет України ПОСТАНОВИВ:

1. Затвердити Перелік підприємств-монополістів, щодо яких запроваджується регулювання фондів оплати праці, що додається ( z0018-05 ).

2. Визнати таким, що втратив чинність, наказ Міністерства економіки України, Державного комітету статистики України, Антимонопольного комітету України від 29 грудня 1999 року N 160/422/16 ( z0096-00 ) "Про затвердження Переліку підприємств-монополістів, щодо яких запроваджується регулювання фондів оплати праці", зареєстрований у Міністерстві юстиції України 17 лютого 2000 року за N 96/4317.
