{ Розпорядження скасовано на підставі Розпорядження КМ N 429-р ( 429-95-р ) від 08.07.95 }

Про передачу в оперативне управління МВС будинку по вул. Шовковичній, 14, у м. Києві

З метою скорочення витрат на утримання особняків, які не можуть використовуватись без здійснення капітального ремонту. Господарському управлінню Кабінету Міністрів України передати в оперативне управління МВС будинок по вул. Шовковичній, 14, у м. Києві із засобами зв'язку та проектно-кошторисною документацією на його реконструкцію.

Виключити вказаний будинок з додатка до постанови Кабінету Міністрів України від 19 січня 1994 року N 18 ( 18-94-п ).
