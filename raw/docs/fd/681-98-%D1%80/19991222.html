Про встановлення терміну виготовлення обладнання і вузлів для машин безперервного розливу сталі з давальницької сировини

Текст документа від 22.12.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 серпня 1998 р. N 681-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 2345 ( 2345-99-п ) від 22.12.99 )

Про встановлення терміну виготовлення обладнання і вузлів для машин безперервного розливу сталі з давальницької сировини

Відповідно до статті 2 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ) установити термін виготовлення обладнання і вузлів для машин безперервного розливу сталі (код ТН ЗЕД 845 490 000) з давальницької сировини (перелік додається) до 250 календарних днів з моменту оформлення ввізної вантажної митної декларації на давальницьку сировину.
