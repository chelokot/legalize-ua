Про внесення змін до наказу Мінкультури України від 10.06.2002 N 366

На виконання постанови Кабінету Міністрів України від 11.02.2004 N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства культури і мистецтв України від 10.06.2002 N 366 ( z0511-02 ) "Про оплату праці працівників Національного заповідника "Софія Київська", зареєстрованого в Міністерстві юстиції України 18.06.2002 за N 511/6799, виклавши додатки 1-4 у редакції, що додається.

2. Контроль за виконанням наказу покласти на заступника Міністра І.В.Ніколайка.

3. Ці зміни застосовуються з 1 березня 2004 року.
