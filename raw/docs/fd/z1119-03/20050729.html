Про затвердження Порядку перерахування до державного бюджету коштів, одержаних від приватизації державного майна

( Із змінами, внесеними згідно з Наказами Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004 N 156/1876 ( z1199-04 ) від 14.09.2004 N 122/1965 ( z0767-05 ) від 06.07.2005 )

З метою забезпечення виконання статей 20, 21, 36, 58, 61, 63 Закону України "Про Державний бюджет України на 2003 рік" ( 380-15 ) НАКАЗУЄМО:

1. Затвердити Порядок перерахування до державного бюджету коштів, одержаних від приватизації державного майна, що додається.

2. Начальнику Управління методології з виконання бюджетів, бухгалтерського обліку та звітності Державного казначейства України Сушко Н.І. забезпечити державну реєстрацію зазначеного Порядку в Міністерстві юстиції України.

3. В. о. начальника Управління організації діловодства та контролю виконавської дисципліни Державного казначейства України Ливун С.В. у триденний термін після державної реєстрації наказу забезпечити його доведення управлінням Державного казначейства в Автономній Республіці Крим, областях, містах Києві та Севастополі.

4. Фонду Державного майна України у дводенний термін після державної реєстрації Порядку перерахування до державного бюджету коштів, одержаних від приватизації об'єктів державної власності, забезпечити його доведення до територіальних відділень Фонду Державного майна України всіх рівнів.

5. Уважати таким, що втратив чинність, Порядок перерахування до державного бюджету коштів, одержаних від приватизації об'єктів державної власності, затверджений наказом Державного казначейства України та Фонду державного майна України від 28.08.2002 N 167/1534 ( z0750-02 ), зареєстрований у Міністерстві юстиції України 13.09.2002 за N 750/7038.

6. Контроль за виконанням цього наказу покласти на заступника Голови Державного казначейства України О.О.Чечуліну та Голову Фонду державного майна України М.В.Чечетова.

ПОРЯДОК перерахування до державного бюджету коштів, одержаних від приватизації державного майна

Цей Порядок регулює питання перерахування коштів, одержаних від приватизації державного майна, до Державного бюджету України.

1. Загальні положення

1.1. Відповідно до Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ) кошти, які надійшли від приватизації державного майна, належать до надходжень фінансування загального та спеціального фондів державного бюджету. ( Пункт 1.1 із змінами, внесеними згідно з Наказами Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004, N 122/1965 ( z0767-05 ) від 06.07.2005 )

1.2. Розподіл коштів, одержаних від приватизації державного майна, інших надходжень, безпосередньо пов'язаних з процесом приватизації та кредитуванням підприємств*, здійснюється згідно з вимогами Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ), Закону України "Про Державну програму приватизації" ( 1723-14 ) та інших законодавчих актів. ( Пункт 1.2 із змінами, внесеними згідно з Наказом Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004, N 122/1965 ( z0767-05 ) від 06.07.2005 )

2. Порядок перерахування до державного бюджету коштів, одержаних від приватизації державного майна

2.1. Надходження від приватизації державного майна та інші надходження, безпосередньо пов'язані з приватизацією та кредитуванням підприємств, відповідно до статей 22 та 23 Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ) належать до надходжень фінансування загального та спеціального фондів Державного бюджету в частині фінансування. ( Пункт 2.1 в редакції Наказу Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004; із змінами, внесеними згідно з Наказом Державного казначейства N 122/1965 ( z0767-05 ) від 06.07.2005 N 122/1965 ( z0767-05 ) від 06.07.2005 )

2.2. Фонду державного майна України та органам приватизації в Державному казначействі України та управліннях Державного казначейства в Автономній Республіці Крим, областях, містах Києві та Севастополі відкриваються 2 рахунки за балансовим рахунком 3718 "Рахунок для обліку коштів від приватизації майна" Плану рахунків бухгалтерського обліку виконання державного та місцевих бюджетів, затвердженого наказом Державного казначейства України від 28.11.2000 N 119 ( v0119506-00 ), із змінами та доповненнями.

На перший рахунок зараховуються у повному обсязі кошти, одержані від приватизації державного майна, інші надходження, безпосередньо пов'язані з процесом приватизації, які визначені пунктом 2 статті 22 та пунктами 2-4 статті 23 Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ). ( Абзац другий пункту 2.2 в редакції Наказу Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004 )

На другий рахунок зараховуються кошти, одержані від приватизації об'єктів комунальної власності, якщо органами місцевого самоврядування були делеговані державним органам приватизації відповідні повноваження.

( Пункт 2.2 розділу 2 із змінами, внесеними згідно з Наказом Державного казначейства N 122/1965 ( z0767-05 ) від 06.07.2005 )

2.3. Органи Державного казначейства наступного дня після зарахування коштів на рахунки органів приватизації передають представникам Фонду державного майна України виписки з зазначених рахунків та реєстр розрахункових документів до них.

2.4. На підставі платіжних доручень, підготовлених Фондом державного майна України чи органами приватизації і наданих Державному казначейству України протягом трьох робочих днів після отримання виписки, кошти, одержані від приватизації об'єктів комунальної власності, за вирахуванням податку на додану вартість, спрямовуються на відповідний рахунок з обліку доходів місцевого бюджету. ( Пункт 2.4 в редакції Наказів Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004, N 122/1965 ( z0767-05 ) від 06.07.2005 )

2.5. На підставі платіжних доручень, підготовлених Фондом державного майна України чи органами приватизації і наданих Державному казначейству України протягом трьох робочих днів після отримання виписки, кошти, одержані від приватизації державного майна, за вирахуванням податку на додану вартість, розподіляються згідно з нормативами, затвердженими Законом України "Про Державний бюджет України на 2005 рік" ( 2285-15 ), та перераховуються на рахунки, відкриті в Державному казначействі України (центральний рівень) за балансовими рахунками 3231 "Інші кошти, залучені до загального фонду державного бюджету", 3232 "Інші кошти, залучені до спеціального фонду державного бюджету" Плану рахунків бухгалтерського обліку виконання державного та місцевих бюджетів, затвердженого наказом Державного казначейства України від 28.11.2000 N 119 ( v0119506-00 ) (зі змінами та доповненнями).

Аналітичні рахунки за вказаними балансовими рахунками відкриті в розрізі територій та кодів класифікації бюджету за типом боргового зобов'язання.

Відповідно до пункту 7 статті 2 Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ) податок на додану вартість зараховується до доходів загального фонду державного бюджету.

( Пункт 2.5 в редакції Наказів Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004, N 122/1965 ( z0767-05 ) від 06.07.2005 )

2.6. На рахунки, відкриті за балансовим рахунком 3231 "Інші кошти, залучені до загального фонду державного бюджету" Плану рахунків бухгалтерського обліку виконання державного та місцевих бюджетів, затвердженого наказом Державного казначейства України від 28.11.2000 N 119 ( v0119506-00 ) (зі змінами та доповненнями), зараховуються 99 відсотків коштів, одержаних від приватизації державного майна (крім об'єктів, для яких передбачено окремий розподіл коштів) та інших надходжень, безпосередньо пов'язаних з процесом приватизації та кредитуванням підприємств, але не менше 6 911 181,1 тис. гривень. ( Абзац перший пункту 2.6 в редакції Наказів Державного казначейства N 156/1876 ( z1199-04 ) від 14.09.2004, N 122/1965 ( z0767-05 ) від 06.07.2005 )

Кошти, зараховані на рахунки, відкриті за балансовим рахунком 3231 "Інші кошти, залучені до загального фонду державного бюджету", використовуються для фінансування загального фонду державного бюджету.

( Пункт 2.6 в редакції Наказів Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004, N 122/1965 ( z0767-05 ) від 06.07.2005 )

2.7. На рахунки, відкриті за балансовим рахунком 3232 "Інші кошти, залучені до спеціального фонду державного бюджету", зараховуються:

90 відсотків надходжень від приватизації об'єктів незавершеного будівництва, що споруджувалися відповідно до Чорнобильської будівельної програми;

75 відсотків надходжень, отриманих від продажу акцій відкритих акціонерних товариств за переліком, визначеним Кабінетом Міністрів України для ліквідації наслідків аварії на очисних спорудах міста Харкова;

Кошти, які зараховані на рахунки, відкриті за балансовим рахунком 3232 "Інші кошти, залучені до спеціального фонду державного бюджету" Плану рахунків бухгалтерського обліку виконання державного та місцевих бюджетів, затвердженого наказом Державного казначейства України від 28.11.2000 N 119 ( v0119506-00 ) (зі змінами та доповненнями), використовуються для фінансування спеціального фонду державного бюджету та спрямовуються на заходи, передбачені:

- пунктом 35 статті 45 Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 );

- пунктом 36 статті 45 Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ), але не більше ніж 18 000 тис. гривень).

( Абзац четвертий пункту 2.7 в редакції Наказу Державного казначейства N 122/1965 ( z0767-05 ) від 06.07.2005 ) ( Пункт 2.7 в редакції Наказу Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004 )

2.8. Крім того, на рахунки за балансовим рахунком 3232 "Інші кошти, залучені до спеціального фонду державного бюджету" Плану рахунків бухгалтерського обліку виконання державного та місцевих бюджетів, затвердженого наказом Державного казначейства України від 28.11.2000 N 119 ( v0119506-00 ) (зі змінами та доповненнями), зараховуються кошти, які витрачаються на заходи, пов'язані з проведенням приватизації державного майна згідно з пунктом 34 статті 45 Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ), а саме:

1 відсоток надходжень від приватизації державного майна (крім об'єктів, для яких передбачено окремий розподіл коштів) та інших надходжень, безпосередньо пов'язаних з процесом приватизації та кредитуванням підприємств, але не більше 49 997,6 тис. гривень, з урахуванням пунктів 3 і 4 статті 23 Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 );

10 відсотків надходжень від приватизації об'єктів незавершеного будівництва, що споруджувалися відповідно до Чорнобильської будівельної програми;

25 відсотків надходжень, отриманих від продажу на відкритих аукціонах акцій відкритих акціонерних товариств за переліком, визначеним Кабінетом Міністрів України для ліквідації наслідків аварії на очисних спорудах міста Харкова.

( Пункт 2.8 в редакції Наказу Державного казначейства N 122/1965 ( z0767-05 ) від 06.07.2005 )

2.9. Кошти, які відповідно до Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ) спрямовуються на заходи, пов'язані з проведенням приватизації державного майна, але не більше 56 010,7 тис. гривень на підставі розподілу Фонду державного майна України (головного розпорядника коштів), перераховуються Державним казначейством України на спеціальні реєстраційні рахунки, відкриті Фонду державного майна України в Державному казначействі України, органам приватизації в управліннях Державного казначейства в АРК, областях, містах Києві та Севастополі за балансовим рахунком 3522 "Реєстраційні рахунки розпорядників за коштами спеціального фонду державного бюджету" Плану рахунків бухгалтерського обліку виконання державного та місцевих бюджетів, затвердженого наказом Державного казначейства України від 28.11.2000 N 119 ( v0119506-00 ) (зі змінами та доповненнями). ( Пункт 2.9 із змінами, внесеними згідно з Наказом Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004; в редакції Наказів Державного казначейства N 156/1876 ( z1199-04 ) від 14.09.2004, N 122/1965 ( z0767-05 ) від 06.07.2005 )

2.10. Видатки за рахунок коштів, отриманих на фінансування загального та спеціального фондів державного бюджету, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04 ) та зареєстрованого в Міністерстві юстиції України 10.06.2004 за N 716/9315. ( Пункт 2.10 в редакції Наказу Державного казначейства N 156/1876 ( z1199-04 ) від 14.09.2004 )

2.11. Кошти, отримані як застава від покупців для участі в аукціоні, конкурсі, зараховуються на рахунки, відкриті в управліннях Державного казначейства за 373-ю групою рахунків "Депозитні рахунки розпорядників коштів бюджетів". ( Пункт 2.11 із змінами, внесеними згідно з Наказом Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004 )

2.12. Не зараховуються до державного бюджету кошти, які надійшли відповідно до умов продажу пакетів акцій відкритих акціонерних товариств на конкурсній основі та у вигляді фінансових гарантій при наданні послуг, у зв'язку з виконанням програми приватизації, і які підлягають поверненню особам, що їх унесли.

( Пункт 2.13 вилучено на підставі Наказу Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004 )

( Пункт 2.14 вилучено на підставі Наказу Державного казначейства N 76/786 ( z0586-04 ) від 20.04.2004 )

2.13. Кошти, які Фонд державного майна України отримує від позикодавців на зворотній основі з метою оплати послуг оцінювачів, зараховуються на рахунок Фонду державного майна України, відкритий за балансовим рахунком 3711 "Інші кошти розпорядників коштів державного бюджету" Плану рахунків бухгалтерського обліку виконання державного та місцевих бюджетів, затвердженого наказом Державного казначейства України від 28.11.2000 N 119 ( v0119506-00 ), із змінами та доповненнями.

Повернення коштів позикодавцям Фонд державного майна України здійснює за рахунок коштів, які надходять на спеціальний реєстраційний рахунок Фонду, відкритий за балансовим рахунком 3522 "Реєстраційні рахунки розпорядників за коштами спеціального фонду державного бюджету". Із зазначеного рахунку відповідна сума коштів перераховується Фондом державного майна на рахунок, відкритий йому за балансовим рахунком 3711, а з цього рахунку - позикодавцю.

2.14. Кошти, зараховані помилково, або кошти, які підлягають поверненню за рішеннями судових органів, на підставі розрахункових документів перераховуються за призначенням.

2.15. Остаточний розподіл коштів від приватизації та їх перерахування до загального та спеціального фондів Державного бюджету за звітний період (місяць) здійснюється до 10 числа місяця, наступного за звітнім.

2.16. Відповідальність за правильність розподілу коштів між загальним та спеціальним фондами державного бюджету несуть органи Фонду державного майна України.

3. Бухгалтерський облік операцій за коштами, що надходять від приватизації державного майна, який здійснюється органами приватизації та органами Державного казначейства України

3.1. В органах приватизації кошти, одержані від приватизації державного майна, добровільних внесків українських та іноземних юридичних і фізичних осіб, громадських організацій, інших надходжень, відповідно до чинного законодавства обліковуються на рахунках, відкритих відповідно до Плану рахунків бухгалтерського обліку бюджетних установ, затвердженого наказом Головного управління Державного казначейства України від 10.12.99 N 114 ( z0890-99 ) та зареєстрованого Міністерством юстиції України 20.12.99 за N 890/4183, із змінами та доповненнями.

3.2. В органах Державного казначейства України кошти, які надходять від приватизації державного майна, обліковуються на рахунках, відкритих відповідно до Плану рахунків бухгалтерського обліку виконання державного та місцевих бюджетів, затвердженого наказом Державного казначейства України від 28.11.2000 N 119 ( v0119506-00 ), із змінами та доповненнями.

3.3. Щомісяця, до 10 числа, наступного за звітним, Державне казначейство України та Фонд державного майна України проводять звірки надходжень коштів від приватизації до загального та спеціального фондів Державного бюджету, результати яких відображаються в актах звірки, підписаних обома сторонами.
