( Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 352 ( z1374-05 ) від 31.10.2005 )

Про внесення змін до наказу Міністерства праці та соціальної політики України від 15.10.2004 N 258

На виконання постанови Кабінету Міністрів України від 15.01.2005 N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 15.10.2004 N 258 ( z1363-04 ) "Про умови оплати праці працівників Державного фонду стимулювання і фінансування заходів з охорони навколишнього природного середовища", зареєстрованого в Міністерстві юстиції України 26.10.2004 за N 1363/9962, виклавши додатки 1, 2 у новій редакції (додаються).

2. Ці зміни застосовуються з 1 січня 2005 року.

В.о. Міністра М.Папієв

Заступник Міністра фінансів України С.М.Макацарія
