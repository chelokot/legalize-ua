Кабінет Міністрів України; Постанова від 24.04.2000 № 705

Про внесення змін до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

Стан: Втратив чинність

Ідентифікатор: 705-2000-п

Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 квітня 2000 р. N 705 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

{ Постанова втратила чинність в частині встановлення ліміту легкових автомобілів, що обслуговують центральні органи виконавчої влади та підпорядковані їм територіальні органи, на підставі Постанови КМ N 314 ( 314-2001-п ) від 02.04.2001 }

Про внесення змін до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

Кабінет Міністрів України постановляє:

Внести у додаток 2 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339), із змінами, внесеними постановою Кабінету Міністрів України від 10 березня 2000 р. N 471 ( 471-2000-п ), такі зміни:

у позиції "Державний комітет стандартизації, метрології та сертифікації" графу "Ліміт легкових автомобілів підпорядкованих їм територіальних органів" доповнити цифрами "27";

у позиції "Усього" цифри "4637" замінити цифрами "4664".

Прем'єр-міністр України В.ЮЩЕНКО
