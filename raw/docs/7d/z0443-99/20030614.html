НАКАЗ

N 369 від 16.06.99 Зареєстровано в Міністерстві юстиції України 6 липня 1999 р. за N 443/3736

( Наказ втратив чинність на підставі Наказу Державної митної служби N 129 ( z0424-03 ) від 28.02.2003 )

Про внесення змін до Переліку, затвердженого наказом Держмитслужби України від 27.07.98 N 436

Відповідно до п.1 постанови Кабінету Міністрів України від 02.04.98 N 419 ( 419-98-п ) "Про заходи щодо посилення контролю за ввезенням в Україну окремих видів товарів, що імпортуються суб'єктами підприємницької діяльності" НАКАЗУЮ:

1. Виключити з Переліку товарів, що ввозяться за попередньою вантажною митною декларацією, затвердженого наказом Державної митної служби України від 27.07.98 N 436 ( z0506-98 ), товари, що класифікуються у позиціях ТН ЗЕД 3923 "Вироби з пластмас для пакування і транспортування" та 4819 "Ящики, коробки, пакети паперові".

2. Доповнити Перелік товарів, що ввозяться за попередньою вантажною митною декларацією, затверджений наказом Державної митної служби України від 27.07.98 N 436, товарами, що класифікуються у позиціях ТН ЗЕД 4801 "Папір газетний в рулонах або аркушах" і 4901 "Друковані книги, брошури, листівки та аналогічні друковані матеріали".

3. Скасувати наказ Держмитслужби від 22.05.98 N 305 ( v0305342-98 ) "Про затвердження Тимчасового переліку товарів, що ввозяться за попередньою декларацією".

4. Управлінню організації митного контролю (Більчук О.С.), Правовому управлінню (Тимошенко С.В.) забезпечити подання цього наказу в Міністерство юстиції на державну реєстрацію.

5. Управлінню справами (Максимов Ю.Ю.) забезпечити доведення наказу до особового складу митних органів.

6. Прес-центру (Старостін А.А.), начальникам регіональних митниць, начальникам митниць довести наказ до відома суб'єктів ЗЕД і громадян.

7. Контроль за виконанням цього наказу покласти на заступника Голови Служби Соболя І.М.
