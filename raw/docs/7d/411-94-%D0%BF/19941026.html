КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 червня 1994 р. N 411 Київ

( Постанова втратила чинність на підставі Постанови КМ N 733 ( 733-94-п ) від 21.10.94 )

Про доповнення додатка до постанови Кабінету Міністрів України від 3 грудня 1993 р. N 978

З метою впорядкування тарифів на послуги теплопостачання, що надаються населенню м.Києва, Кабінет Міністрів України ПОСТАНОВЛЯЄ:

Доповнити додаток до постанови Кабінету Міністрів України від 3 грудня 1993 р. N 978 ( 978-93-п ) "Про впорядкування цін і тарифів" після абзацу "теплова енергія для центрального опалення" абзацами такого змісту:

"Для м.Києва:

теплова енергія для гарячого

водопостачання 3,1 -"-

теплова енергія для центрального

опалення 3,5 -"-"
