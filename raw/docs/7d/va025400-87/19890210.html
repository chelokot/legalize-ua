ЗБІРНИК цін на проектні роботи для будівництва

Розділ 8 Гірничорудна промисловість (із змінами та доповненнями)

{ Із змінами, внесеними згідно з Наказом Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

Вказівки щодо застосування цін

1. У даному розділі Збірника наведено ціни на розроблення проектно-кошторисної документації на будівництво гірничорудних підприємств з видобутку і переробки руд чорних, кольорових, рідкісних і благородних металів, алмазовмісних руд, розсипів, формувальної і флюсової сировини, неметалевих руд, а також нерудної сировини для виробництва будівельних матеріалів.

2. Цінами, крім робіт, обговорених у Загальних вказівках щодо застосування Збірника цін на проектні роботи для будівництва і вказівках щодо застосування цін глав даного розділу, не враховано вартість проектування житлово-цивільного будівництва.

{ Пункт 2 із змінами, внесеними згідно з Наказом Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

3. Вартість робіт з вибору майданчика (траси) для будівництва визначається за цінами на розроблення проекту відповідного об'єкта з коефіцієнтом 0,03.

Вартість розроблення матеріалів для оформлення дозволу на спецводокористування враховано вартістю вибору майданчика.

{ Пункт 3 в редакції Наказу Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

4. При користуванні даним розділом необхідно керуватися також Загальними вказівками щодо застосування Збірника цін на проектні роботи для будівництва.

5. Вартість проектних робіт з підтримки потужності гірничорудних підприємств чорної металургії (нових горизонтів шахт, кар'єрів) визначається з застосуванням коефіцієнтів від 1,0 до 1,05, що установлюються проектною організацією за узгодженням з замовником відповідно до трудомісткості проектних робіт.

{ Розділ доповнено пунктом 5 згідно з Наказом Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

Розділ 1. Гірничорудні підприємства чорної і кольорової

металургії, гірничохімічної, азбестової, вогнетривкої і флюсової сировини

{ Назва глави в редакції Наказу Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

1. У даній главі Збірника наведено ціни на проектування гірничорудних підприємств з видобутку і переробки чорних, кольорових руд, рідкісних і благородних металів і алмазовмісної сировини, гірничохімічної, азбестової, вогнетривкої і флюсової сировини.

Крім того, у даній главі наведено ціни на розроблення проектно-кошторисної документації для будівництва у всіх галузях гірничовидобувальної промисловості спеціальних споруд по захисту кар'єрних і шахтних полів від підземних вод, захисту територій від підтоплення і підземних вод від забруднення в зоні впливу хвостосховищ або шламонакопичувачів, а також спеціальних установок для запобігання змерзанню руд і концентратів при їх транспортуванні в залізничних вагонах і думпкарах і закладних комплексів при підземній розробці родовищ корисних копалин.

{ Пункт 1 в редакції Наказу Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

2. Вартість проектування інженерних мереж і комунікацій, що зв'язують окремі майданчики одного рудника (шахти) або фабрики, незалежно від їх протяжності і технічних параметрів, враховано ціною на розроблення проектно-кошторисної документації відповідних підприємств.

Виняток складають проектовані рудники (шахти) або фабрики, окремі об'єкти або майданчики яких віддалені на відстань більше 10 км один від одного; у цьому випадку ціни на розроблення проектно-кошторисної документації приймаються з коефіцієнтом 1,03. { Пункт 2 в редакції Наказу Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

3. При проектуванні гірничодобувних комбінатів (рудоуправлінь), що складаються з рудника (шахти) і фабрики або декількох рудників (шахт) і фабрик, вартість проектних робіт визначається підсумовуванням цін по цих підприємствах, а вартість проектування інженерних мереж і комунікацій, що їх зв'язують, визначається додатково за відповідними розділами Збірника цін.

{ Пункт 3 в редакції Наказу Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

4. При проектуванні в складі гірничовидобувальних комбінатів (рудоуправлінь) або гірничо-збагачувальних комбінатів об'єктів загально-комбінатського або районного значення, що обслуговують не один, а декілька рудників (шахт), або рудник (шахту) і фабрику, або таких, що забезпечують, поряд з рудником (шахтою) або фабрикою, також інші промислові підприємства або житлові селища даного району, вартість розроблення проектно-кошторисної документації по цих об'єктах приймається додатково до комплексних цін проектування гірничорудних підприємств (рудників) визначається за відповідними розділами Збірника цін.

У цьому випадку ціна проектування гірничорудних підприємств (рудників, фабрик) відповідно зменшується на 0,3-1,5% за кожний з об'єктів залежно від складності і трудомісткості.

Інженерні мережі і комунікації, що зв'язують рудник (шахту) або фабрику з об'єктами загальнокомбінатського або районного значення, відносяться до позамайданчикових: вартість їх проектування також визначається додатково за відповідними розділами Збірника цін.

{ Пункт 4 в редакції Наказу Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

5. Цінами не враховано вартість проектування:

спеціалізованих цехів гумування, корундування і вулканізації;

кисневих і газороздавальних установок, газорозподільних пунктів на газопроводах районного значення;

гірничорятувальних, газорятувальних, гідрометеоспостережувальних і сейсмічних станцій, протилавинних і протиселевих заходів;

споруд для виробництва на місці закладних, хімікотехнологічних, вибухових або інших експлуатаційних матеріалів, що використовуються при роботі рудника або фабрики;

споруд для очищення повітря, що подається для провітрювання рудників, або повітря, що викидається в атмосферу після провітрювання;

споруд дренажу промислових майданчиків, протифільтраційних і дренажних завіс;

розвантажувальних (з розвантаження сирої руди) і навантажувальних (з навантаження готової продукції) залізничних станцій, якщо на цих станціях, крім власне розвантажувальних (навантажувальних) колій, приймальних (навантажувальних) бункерів і складів, зважувальних і дозувальних установок, а також маневрових пристроїв для просування вагонів під час розвантаження (навантаження), входять інші колії та облаштування, призначені для виконання поїзної і маневрової роботи з приймання і відправлення маршрутних і збірних поїздів, їх обробки, підготовки під навантаження, розформування, формування, сортування тощо;

колійного розвитку та облаштування, що забезпечують підготовку вагонів МШС під навантаження;

комплексів вагоноперевертальників з колійним розвитком, призначених для розвантаження вагонів МШС;

спеціальних установок для запобігання змерзанню руд і концентратів при їх транспортуванні в залізничних вагонах і думпкарах, а також споруд з розморожування руд і концентратів і спеціальних способів розвантаження вантажів, що змерзлися; { Абзац одинадцятий пункту 5 із змінами, внесеними згідно з Наказом Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

проходки шахтних стволів і виробіток спеціальними способами (заморожування, кесонний, цементація тощо), а також проходки горизонтальних або похилих залізничних тунелів похилих конвеєрних або скіпових стволів і автоз'їздів, крім випадків, коли ці або подібні їм споруди входять до складу комплексів циклічно-потокової технології, що застосовується для відкритих гірничих робіт;

радіоізотопних лабораторій, складів для збереження радіоізотопних приладів і матеріалів, споруд для нейтралізації і поховання радіоізотопних відходів, засобів захисту від радіоактивності;

цехів і лабораторій з ремонту контрольно-вимірювальних приладів, засобів автоматизації і зв'язку, обчислювальної техніки;

споруд і комунікацій для спеціальних (хімічних та ін.) методів очищення промстоків і води;

споруд і комунікацій для комплексу гідротранспорту руди і продуктів збагачення;

будівель і споруд, що передбачаються для компенсації господарських або природних об'єктів, що зносяться або порушуються, які знаходяться на території проектованого гірничорудного підприємства або поряд з ним, відновлення земель або умов водокористування, збереження і надолуження ресурсів підземних вод, відводу річок, осушування озер, спеціальних гідротехнічних споруд та інших заходів, пов'язаних з підготовкою території будівництва або експлуатацією підприємства без нанесення шкоди народному господарству та екологічним умовам даного району, спеціальних заходів щодо охорони будівель, споруд і природних об'єктів за межами проммайданчика від шкідливого впливу підземних робіт;

баз будіндустрії, ремонтно-будівельних цехів і цехів для капітального ремонту гірничого, збагачувального та іншого устаткування, учбово-курсових комбінатів, профілакторіїв та інших об'єктів комунального і культурно-побутового призначення, підсобних господарств, цехів і ділянок з повторного використання експлуатаційних матеріалів і відходів виробництва, переробки попутно видобувних розкривних порід або продуктів збагачення, цехів і ділянок з випуску товарів народного споживання, а також інших виробництв, не пов'язаних з випуском основної продукції рудника або фабрики; { Пункт 5 доповнено абзацом згідно з Наказом Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

розроблення проектів гірничих і земельних відводів, консервації або ліквідації гірничорудного підприємства, розроблення матеріалів для отримання дозволів на спецводокористування; { Пункт 5 доповнено абзацом згідно з Наказом Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

вантажних і пасажирських канатних доріг; { Пункт 5 доповнено абзацом згідно з Наказом Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

біологічної рекультивації кар'єрів, відвалів і пляжів хвостосховищ. { Пункт 5 доповнено абзацом згідно з Наказом Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

6. За наявності особливо шкідливих або небезпечних умов експлуатації (загазованість, радіоактивність, силікозність, ударонебезпечність, небезпека ендогенних пожеж) до цін на проектування гірничорудних підприємств застосовується коефіцієнт 1,1 за кожну з зазначених умов.

{ Пункт 6 в редакції Наказу Міністерства кольорової металургії СРСР N 36 ( v0036400-89 ) від 10.02.89 }

7. Вартість розроблення проектно-кошторисної документації на будівництво гірничорудних підприємств (рудників, фабрик), що здійснюється в СРСР за участю країн СЕВ або з залученням іноземних фірм, визначається за цінами даного розділу з коефіцієнтом 1,25.

8. При проектуванні гірничодобувних підприємств для видачі роздільними потоками двох і більше різних типів (сортів) руд або різних видів розкривних порід, вартість розроблення частин: технологічної, техніко-економічної, генплан і транспорт визначається з коефіцієнтом 1,2.
