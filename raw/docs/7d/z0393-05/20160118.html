Про внесення змін до деяких наказів Міністерства юстиції України

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 2710/5 ( z1620-15 ) від 22.12.2015 }

Відповідно до Закону України "Про виконавче провадження" ( 606-14 ), з метою удосконалення процедури реалізації арештованого державним виконавцем майна боржника НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства юстиції N 2710/5 ( z1620-15 ) від 22.12.2015 }

{ Пункт 2 втратив чинність на підставі Наказу Міністерства юстиції N 2710/5 ( z1620-15 ) від 22.12.2015 }

{ Пункт 3 втратив чинність на підставі Наказу Міністерства юстиції N 2710/5 ( z1620-15 ) від 22.12.2015 }

4. Департаменту Державної виконавчої служби (Тісногуз В.В.):

4.1. Подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами та доповненнями).

4.2. Довести цей наказ до відома начальника Головного

управління юстиції Міністерства юстиції України в Автономній Республіці Крим, начальників обласних, Київського та Севастопольського міських управлінь юстиції та забезпечити його належне виконання.

5. Контроль за виконанням цього наказу покласти на заступника Міністра юстиції України М.М. Шупеню.

Міністр Р.М.Зварич
