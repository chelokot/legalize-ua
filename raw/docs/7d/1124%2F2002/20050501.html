( Указ втратив чинність на підставі Указу Президента N 625/2005 ( 625/2005 ) від 11.04.2005 )

Про зміни у складі Консультативної ради з питань іноземних інвестицій в Україні

На часткову зміну Указу Президента України від 11 квітня 1997 року N 323 ( 323/97 ) "Про Консультативну раду з питань іноземних інвестицій в Україні" (зі змінами, внесеними Указами від 29 липня 1997 року N 717 ( 717/97 ), від 11 вересня 1997 року N 1006 ( 1006/97 ), від 6 травня 1998 року N 414 ( 414/98 ), від 21 березня 2000 року N 468 ( 468/2000 ), від 29 травня 2000 року N 725 ( 725/2000 ), від 8 червня 2000 року N 775 ( 775/2000 ), від 19 жовтня 2000 року N 1146 ( 1146/2000 ), від 24 жовтня 2000 року N 1162 ( 1162/2000 ), від 25 квітня 2001 року N 280 ( 280/2001 ), від 14 червня 2001 року N 429 ( 429/2001 ), від 1 листопада 2001 року N 1036 ( 1036/2001 ), від 8 листопада 2001 року N 1060 ( 1060/2001 ) та від 1 квітня 2002 року N 310 ( 310/2002 ):

ввести до складу Консультативної ради з питань іноземних інвестицій в Україні Джеймса Лі-ПЕМБЕРТОНА - директора Європейського інвестиційно-банківського підрозділу банку "Кредіт Свіс Ферст Бостон" (Великобританія), Дейва РОДЖЕРСА - голову ради директорів компанії "Каргілл Інтернешнл" (США);

вивести зі складу зазначеної Консультативної ради Девіда Малфорда, Хубертуса Спієрінгса.

Президент України Л.КУЧМА
