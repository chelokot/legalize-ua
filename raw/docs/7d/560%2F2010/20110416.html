Президент України; Указ від 20.04.2010 № 560/2010

Про внесення зміни до Порядку складення присяги суддею, вперше призначеним на посаду

Стан: Втратив чинність

Ідентифікатор: 560/2010

Текст документа від 16.04.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 380/2011 ( 380/2011 ) від 06.04.2011 }

Про внесення зміни до Порядку складення присяги суддею, вперше призначеним на посаду

1. Внести до Порядку складення присяги суддею, вперше призначеним на посаду, затвердженого Указом Президента України від 11 травня 1999 року N 493 ( 493/99 ) (зі змінами, внесеними Указами від 3 лютого 2003 року N 59 ( 59/2003 ) та від 10 грудня 2003 року N 1423) ( 1423/2003 ), зміну, доповнивши абзац перший пункту 2 після слів "Міністра юстиції України" словами "Голови Комітету Верховної Ради України з питань правосуддя".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 20 квітня 2010 року N 560/2010
