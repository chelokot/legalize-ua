ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

19.07.2005 N 407

Зареєстровано в Міністерстві юстиції України 08 вересня 2005 р. за N 1015/11295

Про скасування регуляторних актів Державної комісії з цінних паперів та фондового ринку

З метою вчасного виконання доручення Прем'єр-міністра України від 07.06.2005 N 28646/1/1-05 до Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики", Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Скасувати:

наказ від 15.10.96 N 243 ( v0243312-96 ) "Про затвердження форм звітності та організацію подання квартальних звітів щодо здійснення діяльності по веденню реєстрів власників іменних цінних паперів";

наказ від 25.06.97 N 155 ( v0155312-97 ) "Про подання реєстраторами звітів щодо діяльності з ведення реєстрів власників іменних цінних паперів";

рішення від 03.07.97 N 15 ( v0015312-97 ) "Про затвердження Вимог Державної комісії з цінних паперів та фондового ринку щодо аудиторської перевірки страхових компаній (акціонерних товариств та підприємств-емітентів облігацій)".

2. Керівнику апарату Державної комісії з цінних паперів та фондового ринку М.Непрану забезпечити публікацію рішення у встановленому законодавством порядку.

3. Контроль за виконанням цього рішення покласти на Керівника апарату Державної комісії з цінних паперів та фондового ринку М.Непрана.

Голова Комісії А.Балюк
