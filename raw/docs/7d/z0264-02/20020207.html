1.2. Права власності на інтелектуальні та культурні цінності, створені завдяки реалізації проекту, належать Виконавцю.

1.3. Посилання на фінансову підтримку Комітету щодо здійснення проекту в друкованих матеріалах, засобах масової інформації та публічних виступах є обов'язковим.

2. Умови надання та використання гранту

2.1. Грант надається на термін дії цієї Угоди в порядку, передбаченому нею.

2.2. Використання гранту відбувається відповідно до плану реалізації проекту за таким графіком:

|гранту (грн.) | | | | |

|------------------+----------+----------+-----------+-----------|

|Кінцева дата | | | | |

|використання | | | | |

------------------------------------------------------------------

2.3. Грант надається виключно у формі безготівкового перерахування коштів на підставі заяви Виконавця на спеціально відкритий рахунок Ощадного банку України.

2.4. У разі використання будь-якої частини гранту не за призначенням або з порушенням чинного законодавства Виконавець відшкодовує у повному обсязі всі витрати Комітету для здійснення проекту на момент припинення дії цієї Угоди.

2.5. Виконавець подає до Комітету:

- поетапно проміжні творчі та проміжні фінансові звіти відповідно до вимог Комітету. Отримання Комітетом цих звітів є підставою для подальшої підтримки реалізації проекту;

- завершальний творчий і завершальний фінансовий звіти - у місячний термін після закінчення дії Угоди.

До творчого звіту включається інформація про проведену роботу з реалізації проекту, отримані результати, наводяться оцінки фахівців щодо значущості проекту в гуманітарній і соціальній сферах.

У фінансовому звіті наводиться перелік усіх видатків на здійснення проекту за схемою: предмет витрат, сума в гривнях, найменування отримувача коштів, дата банківського перерахування.

Фінансовий звіт оформляється відповідно до вимог Положення про порядок реалізації програм та проведення заходів з питань дітей, молоді, жінок та сім'ї, затвердженого наказом Державного комітету молодіжної політики, спорту і туризму України від 01.11.2000 N 2111 і зареєстрованого Міністерством юстиції України 21.02.2001 за N 153/5344.

3. Права та обов'язки сторін

3.1. Комітет має право:

- отримувати проміжні та завершальні фінансові звіти за проектом;

- припинити фінансування проекту за умови використання Виконавцем коштів не за призначенням або з порушенням чинного законодавства, а також на підставі негативної оцінки проміжних результатів.

3.2. Комітет зобов'язаний:

- надавати фінансову та організаційну підтримку здійсненню проекту, не порушуючи плану його реалізації;

- контролювати використання гранту за призначенням;

- слідкувати за дотриманням чинного законодавства Виконавцем проекту.

3.3. Виконавець має право:

- власності на інтелектуальні та культурні цінності, створені завдяки реалізації проекту;

- отримувати фінансову й організаційну підтримку згідно з планом реалізації проекту.

3.4. Виконавець зобов'язаний:

- у друкованих матеріалах, засобах масової інформації та публічних виступах вказувати на фінансову й організаційну підтримку Комітету;

- використовувати грант відповідно до плану реалізації проекту;

- своєчасно подавати проміжні й завершальні фінансові та творчі звіти згідно з вимогами Комітету;

- зберігати фінансові та будь-які документи щодо проекту протягом наступних п'яти років;

- під час планових аудиторських перевірок і моніторингу проекту безперешкодно надавати відповідні документи;

- у разі неповного використання виділених коштів повернути їх залишок на рахунок Комітету в 10-денний термін після закінчення дії цієї Угоди.

4. Дострокове припинення Угоди

Дію цієї Угоди може бути припинено у разі встановлення факту використання Виконавцем будь-якої частини гранту не за призначенням або з порушенням чинного законодавства, негативної оцінки Комітетом проміжних результатів реалізації проекту на підставі звіту Виконавця, результатів моніторингу проекту чи аудиторської перевірки.

5. Порядок розв'язання спорів

Усі спори, які можуть виникнути в процесі реалізації проекту або припинення дії Угоди, вирішуються в судовому порядку відповідно до законодавства України.

6. Кінцеві положення

6.1. Цю Угоду укладено та підписано у двох примірниках (по одному для кожної зі сторін), при цьому обидва примірники мають однакову юридичну силу.

6.2. Заявка, опис проекту, реєстраційна картка проекту, кошторис проекту, а також інші документи, які будуть підписані сторонами на виконання цієї Угоди, є її невід'ємними частинами.
