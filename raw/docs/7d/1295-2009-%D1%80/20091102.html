Кабінет Міністрів України; Розпорядження від 30.10.2009 № 1295-р

Про розбронювання матеріальних цінностей мобілізаційного резерву у зв'язку з проведенням заходів, спрямованих на запобігання поширенню грипу типу А/H1N1/Каліфорнія/04/09 та гострих респіраторних захворювань

Стан: Чинний

Ідентифікатор: 1295-2009-р

Текст документа від 02.11.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 жовтня 2009 р. N 1295-р Київ

Про розбронювання матеріальних цінностей мобілізаційного резерву у зв'язку з проведенням заходів, спрямованих на запобігання поширенню грипу типу А/H1N1/Каліфорнія/04/09 та гострих респіраторних захворювань

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1296-р ( 1296-2009-р ) від 02.11.2009 }

1. У зв'язку з проведенням заходів, спрямованих на запобігання поширенню грипу типу А/H1N1/Каліфорнія/04/09 та гострих респіраторних захворювань, розбронювати з мобілізаційного резерву марлю медичну в обсязі 6 млн. метрів, яка зберігається на центральних складах МОЗ, базах спецмедпостачання Міністерства охорони здоров'я Автономної Республіки Крим, головних управлінь, управлінь охорони здоров'я обласних, Київської міської держадміністрацій.

Держкомрезерву здійснити відпуск розброньованої марлі медичної на безоплатній основі Державному департаменту з питань виконання покарань в обсязі 1 млн. метрів, іншим одержувачам - решту марлі за рознарядкою Мінекономіки.

2. МОЗ за рахунок коштів, виділених відповідно до постанови Кабінету Міністрів України від 30 жовтня 2009 р. N 1147 ( 1147-2009-п ) "Про фінансування невідкладних заходів, спрямованих на запобігання поширенню інфекційних захворювань серед населення", перерахувати Держкомрезерву 10 млн. гривень для поновлення запасів марлі медичної у мобілізаційному резерві.

{ Пункт 2 в редакції Розпорядження КМ N 1296-р ( 1296-2009-р ) від 02.11.2009 }
