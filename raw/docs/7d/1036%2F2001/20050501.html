( Указ втратив чинність на підставі Указу Президента N 625/2005 ( 625/2005 ) від 11.04.2005 )

Про зміну в складі Консультативної ради з питань іноземних інвестицій в Україні

На часткову зміну Указу Президента України від 11 квітня 1997 року N 323 ( 323/97 ) "Про Консультативну раду з питань іноземних інвестицій в Україні" (із змінами, внесеними Указами від 29 липня 1997 року N 717 ( 717/97 ), від 11 вересня 1997 року N 1006 ( 1006/97 ), від 6 травня 1998 року N 414 ( 414/98 ), від 21 березня 2000 року N 468 ( 468/2000 ), від 29 травня 2000 року N 725 ( 725/2000 ), від 8 червня 2000 року N 775 ( 775/2000 ), від 19 жовтня 2000 року N 1146 ( 1146/2000 ), від 25 квітня 2001 року N 280 ( 280/2001 ) та від 14 червня 2001 року N 429 ( 429/2001 ) ввести до складу Консультативної ради з питань іноземних інвестицій в Україні Хармануса КВАСТА - голову спостережної ради відкритого акціонерного товариства "Дамен Шіпярдс Океан", виконавчого директора компанії "Б.В.Холдинг Маатсхаппей Дамен" (Нідерланди).

Президент України Л.КУЧМА
