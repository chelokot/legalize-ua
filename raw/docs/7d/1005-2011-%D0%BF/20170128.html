КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 вересня 2011 р. N 1005 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1059 ( 1059-2016-п ) від 23.11.2016 }

Про затвердження переліку товарів власного виробництва, 80 відсотків прибутку підприємств від продажу яких на митній території України звільняється від оподаткування

Відповідно до пункту 158.1 статті 158 Податкового кодексу України ( 2755-17 ) Кабінет Міністрів України постановляє:

1. Затвердити перелік товарів власного виробництва, 80 відсотків прибутку підприємств від продажу яких на митній території України звільняється від оподаткування, згідно з додатком.

2. Ця постанова набирає чинності з дня опублікування.
