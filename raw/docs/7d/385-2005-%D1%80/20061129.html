Кабінет Міністрів України; Розпорядження від 05.09.2005 № 385-р

Питання утримання ракетного крейсера "Україна"

Стан: Чинний

Ідентифікатор: 385-2005-р

Текст документа від 29.11.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 вересня 2005 р. N 385-р Київ

Питання утримання ракетного крейсера "Україна"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 583-р ( 583-2006-р ) від 29.11.2006 }

1. Міноборони:

взяти на облік ракетний крейсер "Україна" (далі - крейсер) як майно Збройних Сил та забезпечити його утримання у межах призначень, передбачених у державному бюджеті на відповідний рік для забезпечення функціонування Збройних Сил;

разом з Мінпромполітики і державним підприємством "Суднобудівний завод імені 61 комунара" визначити у місячний строк розмір збитків, завданих підприємству у зв'язку з припиненням будівництва крейсера та джерела їх покриття.

2. Державній компанії "Укрспецекспорт" разом з МЗС і Мінпромполітики провести до кінця 2006 року маркетингові дослідження з метою визначення потенційних покупців крейсера та внести Міноборони пропозиції щодо його реалізації.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 583-р ( 583-2006-р ) від 29.11.2006 }
