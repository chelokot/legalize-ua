{ Розпорядження втратило чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

Про утворення міжвідомчої робочої групи з питань зменшення споживання природного газу в промисловості

1. Утворити міжвідомчу робочу групу з питань зменшення споживання природного газу в промисловості у складі згідно з додатком.

Надати голові міжвідомчої робочої групи право вносити у разі потреби зміни до її складу.

2. Установити, що:

засідання міжвідомчої робочої групи скликаються відповідно до плану роботи, затвердженого її головою;

організаційне забезпечення роботи міжвідомчої робочої групи здійснюється НАЕР.
