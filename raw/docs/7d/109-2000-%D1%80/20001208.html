Кабінет Міністрів України; Розпорядження від 02.03.2000 № 109-р

Щодо черговості проведення засідань Кабінету Міністрів України та урядових комітетів

Стан: Втратив чинність

Ідентифікатор: 109-2000-р

Текст документа від 08.12.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 березня 2000 р. N 109-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 485-р ( 485-2000-р ) від 08.12.2000 )

( Із змінами, внесеними згідно з Розпорядженням КМ N 445-р ( 445-2000-р ) від 08.11.2000 )

Установити, що засідання Кабінету Міністрів України, урядових комітетів проводяться у такі дні тижня (у міру готовності матеріалів для розгляду відповідних питань):

Кабінету Міністрів України - у середу;

Урядового комітету з реформування аграрного сектору та з питань екології - у понеділок;

Урядового комітету соціального та гуманітарного розвитку - у вівторок;

Урядового комітету з реформування паливно-енергетичного комплексу - у п'ятницю;

Урядового комітету економічного розвитку - у четвер.

Засідання Кабінету Міністрів України та урядових комітетів проводяться, як правило, у першій половині дня.

( Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 445-р ( 445-2000-р ) від 08.11.2000 )
