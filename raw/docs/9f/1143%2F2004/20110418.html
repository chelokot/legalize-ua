Про внесення зміни до пункту 4 Положення про Міністерство юстиції України

Підпункт 22 пункту 4 Положення про Міністерство юстиції України, затвердженого Указом Президента України від 30 грудня 1997 року N 1396 ( 1396/97 ) (зі змінами, внесеними Указами від 15 вересня 1998 року N 1019 ( 1019/98 ), від 9 лютого 1999 року N 145 ( 145/99 ), від 31 липня 2000 року N 934 ( 934/2000 ), від 7 серпня 2001 року N 596 ( 596/2001 ), від 11 січня 2002 року N 12 ( 12/2002 ), від 27 грудня 2002 року N 1233 ( 1233/2002 ), від 17 лютого 2003 року N 134 ( 134/2003 ) та від 21 серпня 2004 року N 965 ( 965/2004 ), після слів "Торгово-промислової палати України" доповнити словами "постійно діючих третейських судів".

Президент України Л.КУЧМА
