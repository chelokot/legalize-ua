( Постанова втратила чинність на підставі Постанови КМ N 1053 ( 1053-2005-п ) від 05.11.2005 )

Про перелік видів фізкультурно-оздоровчої та спортивної діяльності, які підлягають ліцензуванню

Відповідно до статті 4 Закону України "Про підприємництво" ( 698-12 ) (в редакції Закону України від 23 грудня 1997 р. N 762) ( 762/97-ВР ) Кабінет Міністрів України постановляє:

Затвердити перелік видів фізкультурно-оздоровчої та спортивної діяльності, які підлягають ліцензуванню (додається).

Перший віце-прем'єр-міністр України А.ГОЛУБЧЕНКО

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 27 травня 1998 р. N 751

ПЕРЕЛІК видів фізкультурно-оздоровчої та спортивної діяльності, які підлягають ліцензуванню

Організація та проведення спортивних занять професіоналів та любителів спорту.

Діяльність з підготовки спортсменів до змагань з різних видів спорту.
