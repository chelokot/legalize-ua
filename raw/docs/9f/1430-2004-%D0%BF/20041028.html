КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 жовтня 2004 р. N 1430 Київ

Про доповнення переліку населених пунктів, яким надається статус гірських

Кабінет Міністрів України постановляє:

Доповнити перелік населених пунктів, яким відповідно до Закону України "Про статус гірських населених пунктів в Україні" ( 56/95-ВР ) надається статус гірських, затверджений постановою Кабінету Міністрів України від 11 серпня 1995 р. N 647 ( 647-95-п ) (ЗП України, 1996 р., N 1, ст. 1, N 4, ст. 130, N 6, ст. 206, N 10, ст. 285; Офіційний вісник України, 2001 р., N 4, ст. 128, N 13, ст. 536; 2002 р., N 3, ст. 93), населеними пунктами згідно з додатком.
