Про зупинення дії постанов Кабінету Міністрів України від 16 січня 2007 року N 35 та від 14 березня 2007 року N 443

Стан: Втратив чинність

Текст документа від 06.11.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 996/2008 ( 996/2008 ) від 04.11.2008 }

Про зупинення дії постанов Кабінету Міністрів України від 16 січня 2007 року N 35 та від 14 березня 2007 року N 443

{ Додатково див. Конституційне подання Президента ( n0030100-08 ) від 03.10.2008 }

Відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити з мотивів невідповідності Конституції України ( 254к/96-ВР ), зокрема частинам першій та другій статті 8, частині другій статті 19, частині третій статті 22, частині третій статті 113, пунктам 5, 9 і 10 статті 116, частині першій статті 117, дію постанов Кабінету Міністрів України:

від 16 січня 2007 року N 35 ( 35-2007-п ) "Питання Київського національного університету імені Тараса Шевченка";

від 14 березня 2007 року N 443 ( 443-2007-п ) "Про затвердження Статуту Київського національного університету імені Тараса Шевченка".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 3 жовтня 2008 року N 893/2008
