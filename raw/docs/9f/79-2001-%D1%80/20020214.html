КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 березня 2001 р. N 79-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 53-р ( 53-2002-р ) від 14.02.2002 )

Про перелік офшорних зон

1. Відповідно до пункту 18.3 статті 18 Закону України "Про оподаткування прибутку підприємств" ( 334/94-ВР ) оприлюднити перелік офшорних зон згідно з додатком.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 1 березня 2000 р. N 106 ( 106-2000-р ) (Офіційний вісник України, 2000 р., N 9, ст. 351).
