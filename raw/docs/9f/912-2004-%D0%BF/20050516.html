Про затвердження посадового складу Урядової комісії з питань боротьби з ВІЛ/СНІДом

Стан: Втратив чинність

Ідентифікатор: 912-2004-п

Текст документа від 16.05.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 липня 2004 р. N 912 Київ

( Постанова втратила чинність на підставі Постанови КМ N 352 ( 352-2005-п ) від 16.05.2005 )

Про затвердження посадового складу Урядової комісії з питань боротьби з ВІЛ/СНІДом

( Зміни до посадового складу Урядової комісії див. в Постанові КМ N 371 ( 371-2005-п ) від 18.05.2005 - втратили чинність на підставі Постанови КМ N 559 ( 559-2005-п ) від 12.07.2005 )

Кабінет Міністрів України постановляє:

1. Затвердити посадовий склад Урядової комісії з питань боротьби з ВІЛ/СНІДом, що додається.

2. Визнати такими, що втратили чинність:

пункт 2 постанови Кабінету Міністрів України від 26 жовтня 2001 р. N 1401 ( 1401-2001-п ) (Офіційний вісник України, 2001 р., N 44, ст. 1966);

постанову Кабінету Міністрів України від 15 червня 2003 р. N 899 ( 899-2003-п ) (Офіційний вісник України, 2003 р., N 25, ст. 1189);

пункт 39 змін, що вносяться до актів Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 17 липня 2003 р. N 1106 ( 1106-2003-п ) (Офіційний вісник України, 2003 р., N 30, ст. 1546).
