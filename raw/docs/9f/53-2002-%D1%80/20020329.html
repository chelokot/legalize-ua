КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 лютого 2002 р. N 53-р Київ

Про перелік офшорних зон

( Із змінами, внесеними згідно з Розпорядженням КМ N 156-р ( 156-2002-р ) від 29.03.2002 )

1. Відповідно до пункту 18.3 статті 18 Закону України "Про оподаткування прибутку підприємств" ( 334/94-ВР ) оприлюднити перелік офшорних зон згідно з додатком.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 14 березня 2001 р. N 79 ( 79-2001-р ) (Офіційний вісник України, 2001 р., N 11, ст. 452).
