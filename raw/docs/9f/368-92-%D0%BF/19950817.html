Питання Державного інноваційного Фонду

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 липня 1992 р. N 368 Київ

Питання Державного інноваційного Фонду

( Із змінами, внесеними згідно з Постановами КМ N 561 ( 561-92-п ) від 05.10.92 N 660 ( 660-95-п ) від 17.08.95 )

Відповідно до Закону України "Про основи державної політики в сфері науки і науково-технічної діяльності" ( 1977-12 ) Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 660 ( 660-95-п ) від 17.08.95 )

2. Установити граничну чисельність працівників апарату Державного інноваційного фонду у кількості 28 одиниць з утриманням їх за рахунок коштів, що надходять до цього Фонду.

( Пункт 3 втратив чинність на підставі Постанови КМ N 660 ( 660-95-п ) від 17.08.95 )

4. Міністерству фінансів і Міністерству економіки України щорічно передбачати у проектах державного бюджету та показників економічного і соціального розвитку України асигнування для Державного інноваційного фонду.

5. Державному інноваційному фонду разом з Міністерством економіки і Міністерством державних ресурсів України протягом місяця узгодити порядок визначення і використання резерву матеріально-технічних і сировинних ресурсів, що виділяються державою на потреби розвитку науки і техніки.

6. Міністерству державних ресурсів України виділити обладнання, транспорт і засоби зв'язку для забезпечення діяльності Державного інноваційного фонду.

Міністерству зв'язку України забезпечити Державний інноваційний фонд за його заявкою сучасними засобами зв'язку, телефонним міжміським і міжнародним зв'язком.

7. Київській міській державній адміністрації вирішити питання про виділення Державному інноваційному фонду приміщення загальною прощею 180 кв. метрів.

8. Раді Міністрів Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям надати допомогу в становленні й діяльності регіональних відділень Державного інноваційного фонду.

Прем'єр-міністр України В.ФОКІН
