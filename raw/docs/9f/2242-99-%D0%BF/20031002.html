КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 грудня 1999 р. N 2242 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1540 ( 1540-2003-п ) від 02.10.2003 )

Про внесення доповнення до постанови Кабінету Міністрів України від 31 серпня 1995 р. N 709

У зв'язку з прийняттям Закону України "Про угоди про розподіл продукції" ( 1039-14 ) Кабінет Міністрів України постановляє:

Пункт 7 Порядку надання спеціальних дозволів (ліцензій) на користування надрами, затвердженого постановою Кабінету Міністрів України від 31 серпня 1995 р. N 709 ( 709-95-п ) (ЗП України, 1996 р., N 1, ст. 28; Офіційний вісник України, 1997 р., число 30, с. 34; 1999 р., N 32, ст. 1665), після підпункту "г" доповнити новим підпунктом такого змісту:

"д) реалізації угод про розподіл продукції".

У зв'язку з цим підпункт "д" вважати підпунктом "є".
