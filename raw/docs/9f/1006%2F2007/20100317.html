Про внесення зміни до Указу Президента України від 23 травня 2005 року N 841

Внести до Указу Президента України від 23 травня 2005 року N 841 ( 841/2005 ) "Про кількість заступників Голови Служби безпеки України" (зі змінами, внесеними указами Президента України від 26 липня 2006 року N 647 ( 647/2006 ), від 15 листопада 2006 року N 968 ( 968/2006 ), від 16 квітня 2007 року N 305 ( 305/2007 ), від 12 травня 2007 року N 398 ( 398/2007 ) та від 20 червня 2007 року N 543) ( 543/2007 ) зміну, замінивши слова "вісьмох заступників" словами "сімох заступників".
