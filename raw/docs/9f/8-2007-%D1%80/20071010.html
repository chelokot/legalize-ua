РОЗПОРЯДЖЕННЯ від 16 січня 2007 р. N 8-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 865-р ( 865-2007-р ) від 10.10.2007 }

Про внесення змін до розпорядження Кабінету Міністрів України від 21 лютого 2001 р. N 50

Внести до розпорядження Кабінету Міністрів України від 21 лютого 2001 р. N 50 ( 50-2001-р ) "Про утворення міжвідомчої робочої групи з координації та контролю за ходом підготовки і реалізації проектів розвитку житлово-комунального господарства населених пунктів" - із змінами, внесеними розпорядженням Кабінету Міністрів України від 26 вересня 2002 р. N 551 ( 551-2002-р ) (Офіційний вісник України, 2002 р., N 40, ст. 1870) і постановою Кабінету Міністрів України від 15 лютого 2006 р. N 147 ( 147-2006-п ) (Офіційний вісник України, 2006 р., N 7, ст. 360), такі зміни:

у пункті 1:

на часткову зміну абзацу першого затвердити склад міжвідомчої робочої групи з питань підготовки і реалізації проектів розвитку житлово-комунального господарства населених пунктів з числа заступника Міністра будівництва, архітектури та житлово-комунального господарства (голова робочої групи), керівних працівників Мінекономіки, Мінбуду, Мінфіну, Мінприроди, НАЕР та працівників Секретаріату Кабінету Міністрів України;

абзац другий викласти у такій редакції:

"Голові міжвідомчої робочої групи затвердити її персональний склад.";

у пункті 2 слово "Держжитлокомунгосп" замінити словом "Мінбуд".

Прем'єр-міністр України В.ЯНУКОВИЧ
