КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 серпня 2002 р. N 1252 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про визнання такою, що втратила чинність, постанови Кабінету Міністрів України від 31 травня 1994 р. N 342

Кабінет Міністрів України постановляє:

Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 31 травня 1994 р. N 342 "Про затвердження Положення про проходження військової служби військовослужбовцями, які можуть бути відряджені до державних органів, Товариства сприяння обороні України, Академії наук України та галузевих академій наук".

Прем'єр-міністр України А.КІНАХ
