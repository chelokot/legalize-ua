КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 травня 2005 р. N 150-р Київ

Питання використання власних залізничних вантажних вагонів

( Із змінами, внесеними згідно з Розпорядженням КМ N 198-р ( 198-2005-р ) від 16.06.2005 )

1. Погодитися з пропозицією Мінтрансзв'язку щодо нарахування платежів за перевезення вантажів у залізничних вагонах вантажовласників та операторів із застосуванням знижки у розмірах згідно з додатком.

( Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 198-р ( 198-2005-р ) від 16.06.2005 )

2. Додаток 2 до розпорядження Кабінету Міністрів України від 13 липня 2004 р. N 455 ( 455-2004-р ) "Про тарифи на перевезення вантажів залізничним транспортом" (Офіційний вісник України, 2004 р., N 28, ст. 1903) виключити.
