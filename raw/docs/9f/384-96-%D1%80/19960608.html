Стан: Втратив чинність

Ідентифікатор: 384-96-р

Текст документа від 08.06.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 червня 1996 р. N 384-р Київ

Про зміни в складі координаційних рад, утворених для організації роботи з підготовки проектів державних програм соціально-економічного розвитку Поділля, Українського Причорномор'я та Придніпровського регіону

Включити до складу координаційних рад, утворених відповідно до постанов Кабінету Міністрів України від 12 квітня 1995 р. N 279 ( 279-95-п ), від 5 травня 1995 р. N 324 ( 324-95-п ) та від 17 жовтня 1995 р. N 838 ( 838-95-п ) для організації роботи з підготовки проектів державних програм соціально-економічного розвитку Поділля, Українського Причорномор'я та Придніпровського регіону Седуна Миколу Васильовича - начальника Головного управління культурно-просвітницької роботи Мінкультури, виключивши зі складу цих рад Сердюка Юрія Олександровича.

Включити до складу координаційних рад, утворених для організації роботи з підготовки проектів державних програм соціально-економічного розвитку Поділля та Українського Причорномор'я Кузьменка Сергія Олександровича - заступника Міністра енергетики та електрифікації, виключивши зі складу цих рад Буцьо Зіновія Юрійовича.

Надати право голові зазначених координаційних рад вносити зміни до їх персонального складу.

Прем'єр-міністр України П.ЛАЗАРЕНКО
