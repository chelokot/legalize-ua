УКАЗ ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

{ Указ не застосовується на території України згідно із Законом N 2215-IX ( 2215-20 ) від 21.04.2022 }

Про утворення союзно-республіканського Міністерства лісової промисловості Української РСР

( Відомості Верховної Ради УРСР, 1988, N 34, ст. 836 )

Президія Верховної Ради Української РСР постановляє:

Утворити союзно-республіканське Міністерство лісової промисловості Української РСР на базі Міністерства лісової і деревообробної промисловості Української РСР.
