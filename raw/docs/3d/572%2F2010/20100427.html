Президент України; Указ від 27.04.2010 № 572/2010

Про внесення змін до Указу Президента України від 21 березня 2002 року N 277

Стан: Чинний

Ідентифікатор: 572/2010

Текст документа від 27.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Указу Президента України від 21 березня 2002 року N 277

1. Внести до Указу Президента України від 21 березня 2002 року N 277 ( 277/2002 ) "Про переліки посад військовослужбовців і працівників правоохоронних органів, що підлягають заміщенню особами вищого офіцерського (начальницького) складу, та граничних військових і спеціальних звань за цими посадами" такі зміни:

1) у додатку N 1 до Указу ( 277/2002 ) (в редакції Указу від 21 жовтня 2009 року N 846 ( 846/2009 ), зі змінами, внесеними Указом від 23 лютого 2010 року N 213) ( 213/2010 ) у розділі "Центральний апарат Міністерства оборони України" позиції "Директор Департаменту кадрової політики" і "Директор Військово-медичного департаменту" виключити;

2) у додатку N 4 до Указу ( 277/2002 ) (зі змінами, внесеними Указами від 27 червня 2003 року N 562 ( 562/2003 ), від 17 липня 2006 року N 616 ( 616/2006 ), від 23 серпня 2007 року N 786 ( 786/2007 ) та від 16 листопада 2007 року N 1114) ( 1114/2007 ) назву позиції "Заступник начальника Управління - начальник Служби охорони Президента України" викласти в такій редакції: "Заступник начальника Управління - начальник Служби безпеки Президента України".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 27 квітня 2010 року N 572/2010
