КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 лютого 2006 р. N 194 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1695 ( 1695-2006-п ) від 08.12.2006 }

Про внесення змін до переліку органів ліцензування

Кабінет Міністрів України постановляє:

Внести до переліку органів ліцензування, затвердженого постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001; 2004 р., N 25, ст. 1650), такі зміни:

пункт 35 викласти у такій редакції:

"35. Держгеолслужба пошук (розвідка) корисних копалин, видобування уранових руд";

доповнити перелік пунктом 36 такого змісту:

"36. Укргеодез- виконання топографо-геодезичних і картографія картографічних робіт".

Прем'єр-міністр України Ю.ЄХАНУРОВ
