Про уповноваження колективного сільськогосподарського підприємства

Стан: Втратив чинність

Ідентифікатор: 387-94-р

Текст документа від 05.10.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 травня 1994 р. N 387-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 647 ( 647-96-р ) від 05.10.96 )

Уповноважити колективне сільськогосподарське підприємство імені Мічуріна (Хмельницький район Вінницької області) здійснювати експорт товарів за кодом ТН ЗЕД 22.07 ( n0001410-92 ) в обсязі 2,5 млн. декалітрів.
