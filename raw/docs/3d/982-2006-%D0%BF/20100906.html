КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 липня 2006 р. N 982 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 781 ( 781-2010-п ) від 27.08.2010 }

Про внесення змін до постанови Кабінету Міністрів України від 28 серпня 2003 р. N 1378

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 28 серпня 2003 р. N 1378 ( 1378-2003-п ) "Про вдосконалення роботи із забезпечення учнів і студентів навчальних закладів підручниками та посібниками" (Офіційний вісник України, 2003 р., N 36, ст. 1945; 2006 р., N 6, ст. 300) зміни, що додаються.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 17 липня 2006 р. N 982

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 28 серпня 2003 р. N 1378 ( 1378-2003-п )

У пункті 2 постанови ( 1378-2003-п ):

підпункт 2 викласти в такій редакції:

"2) забезпечити один раз на три роки видання букварів відповідно до кількості учнів перших класів, вчителів загальноосвітніх шкіл, потреб бібліотечного фонду, методичних кабінетів та заявок вищих навчальних закладів, що готують педагогічні кадри, починаючи з 2006/07 навчального року";

підпункт 4 викласти в такій редакції:

"4) у період переходу загальної середньої освіти на новий зміст, структуру та 12-річний строк навчання продовжити до 2008 року строк дії грифа підручникам для 9-11 класів. Додаткове друкування підручників, яким надання грифа припинено та продовжено строк дії грифа, здійснювати в обсязі не більш як 100 відсотків".
