Питання Державного комітету нафтової, газової та нафтопереробної промисловості

Стан: Втратив чинність

Ідентифікатор: 93-95-п

Текст документа від 23.04.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 лютого 1995 р. N 93 Київ

( Постанова втратила чинність на підставі Постанови КМ N 367 ( 367-2001-п ) від 23.04.2001 )

Питання Державного комітету нафтової, газової та нафтопереробної промисловості

( Із змінами, внесеними згідно з Постановою КМ N 377 ( 377-96-п ) від 01.04.96 )

Відповідно до Указу Президента України від 18 січня 1995 р. N 61 ( 61/95 ) "Про утворення Державного комітету нафтової, газової та нафтопереробної промисловості України" Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. Установити граничну чисельність працівників центрального апарату Державного комітету нафтової, газової та нафтопереробної промисловості у кількості 151 чоловіка.

Дозволити Державному комітетові нафтової, газової та нафтопереробної промисловості мати шістьох заступників голови, в тому числі одного першого, а також колегію у кількості 11 чоловік.

2. Установити, що Державний комітет нафтової, газової та нафтопереробної промисловості є правонаступником ліквідованого Державного комітету по нафті і газу.

3. Передати до сфери управління Державного комітету нафтової, газової та нафтопереробної промисловості підприємства, організації та установи, що входили до сфери управління Державного комітету по нафті і газу.

4. ( Пункт 4 втратив чинність на підставі Постанови КМ N 377 ( 377-96-п ) від 01.04.96 ) Міністерству фінансів передбачати починаючи з 1995 року в проектах державного бюджету кошти на утримання центрального апарату Державного комітету нафтової, газової та нафтопереробної промисловості.

4. Прийняти пропозицію Державного комітету нафтової, газової та нафтопереробної промисловості, погоджену з відкритим акціонерним товариством "Інститут транспорту нафти", щодо розміщення центрального апарату цього Комітету в будинку на вул. Артема, 60, у м.Києві.

5. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 14 грудня 1992 р. N 701 ( 701-92-п ) "Питання Державного комітету по нафті і газу" (ЗП України, 1992 р., N 12, ст.301).
