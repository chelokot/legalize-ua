Про утворення міжвідомчої робочої групи з питань будівництва стадіону в м. Львові по вул. Стрийській - Кільцевій дорозі

Стан: Втратив чинність

Ідентифікатор: 173-2010-р

Текст документа від 11.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 січня 2010 р. N 173-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про утворення міжвідомчої робочої групи з питань будівництва стадіону в м. Львові по вул. Стрийській - Кільцевій дорозі

1. Утворити міжвідомчу робочу групу з питань будівництва стадіону в м. Львові по вул. Стрийській - Кільцевій дорозі (далі - міжвідомча робоча група).

Затвердити головою міжвідомчої робочої групи Віце-прем'єр-міністра України Васюника Івана Васильовича.

2. Голові міжвідомчої робочої групи затвердити її склад та положення про міжвідомчу робочу групу, передбачивши, зокрема, що її засідання проводяться у разі потреби, але не рідше ніж один раз на місяць, рішення оформляються протоколом, який підписує голова, а в разі його відсутності - заступник голови міжвідомчої робочої групи.

Прем'єр-міністр України Ю.ТИМОШЕНКО
