Про утворення комісії з ліквідації Державної служби технічного регулювання

Стан: Чинний

Ідентифікатор: 596-2011-р

Текст документа від 25.07.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 червня 2011 р. N 596-р Київ

Про утворення комісії з ліквідації Державної служби технічного регулювання

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 794-р ( 794-2011-р ) від 22.08.2011 N 502-р ( 502-2012-р ) від 25.07.2012 }

1. Утворити комісію з ліквідації Державної служби технічного регулювання.

Затвердити головою зазначеної комісії заступника Голови Державної інспекції з питань захисту прав споживачів Соколову Ольгу Петрівну. { Абзац другий пункту 1 із змінами, внесеними згідно з Розпорядженнями КМ N 794-р ( 794-2011-р ) від 22.08.2011, N 502-р ( 502-2012-р ) від 25.07.2012 }

2. Голові комісії:

затвердити персональний склад комісії;

забезпечити здійснення заходів, пов'язаних з ліквідацією Державної служби технічного регулювання;

поінформувати у чотиримісячний строк Кабінет Міністрів України про результати проведеної роботи.

Прем'єр-міністр України М.АЗАРОВ
