Зареєстровано в Міністерстві юстиції України 14 червня 2004 р. за N 727/9326

Про внесення змін до наказу МНС України від 28.08.2002 N 222 "Про впорядкування умов оплати праці членів екіпажів морських суден аварійно-рятувального загону МНС України"

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 222 ( z0071-03 ) від 28.08.2002, до якого вносились зміни }

Відповідно до постанови Кабінету Міністрів України від 11 лютого 2004 р. N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести до наказу МНС України від 28.08.2002 N 222 ( z0071-03 ) "Про впорядкування умов оплати праці членів екіпажів морських суден аварійно-рятувального загону МНС України", зареєстрованого Міністерством юстиції України 29 січня 2003 року за N 71/7392, із змінами, унесеними наказом МНС України від 26.08.2003 N 301 ( z0792-03 ) "Про внесення змін до наказу МНС України від 28.08.2002 N 222 "Про впорядкування умов оплати праці членів екіпажів морських суден аварійно-рятувального загону МНС України", зареєстрованим у Міністерстві юстиції України 10 вересня 2003 року за N 792/8113, такі зміни, виклавши додатки 1-4, а також пункт 1 розділу II (Особливості оплати праці водолазів) у новій редакції, що додаються.

2. Ці зміни застосуються з 1 березня 2004 року.

3. Контроль за виконанням цього наказу покласти на заступника Міністра - керівника апарату Романова В.М.

Міністр Г.В.Рева
