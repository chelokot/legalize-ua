Кабінет Міністрів України; Розпорядження від 05.04.2006 № 179-р

Про делегування представників Кабінету Міністрів України до складу адміністративної ради Фонду гарантування вкладів фізичних осіб

Стан: Втратив чинність

Ідентифікатор: 179-2006-р

Текст документа від 18.07.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 квітня 2006 р. N 179-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 543-р ( 543-2007-р ) від 18.07.2007 }

Про делегування представників Кабінету Міністрів України до складу адміністративної ради Фонду гарантування вкладів фізичних осіб

1. Делегувати до складу адміністративної ради Фонду гарантування вкладів фізичних осіб представників Кабінету Міністрів України:

Лісовенка Віталія Васильовича - заступника Міністра фінансів;

Максюту Анатолія Аркадійовича - першого заступника Міністра економіки.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 15 лютого 2002 р. N 71 ( 71-2002-р ) "Про делегування представників Кабінету Міністрів України до складу адміністративної ради Фонду гарантування вкладів фізичних осіб".

Прем'єр-міністр України Ю.ЄХАНУРОВ
