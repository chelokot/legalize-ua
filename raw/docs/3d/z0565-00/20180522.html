N 1697 від 15.08.2000 Зареєстровано в Міністерстві м.Київ юстиції України 31 серпня 2000 р. за N 565/4786

{ Наказ втратив чинність на підставі Наказу Фонду державного майна N 499 ( z0484-18 ) від 10.04.2018 }

Про внесення змін та доповнень до Положення про комісію з приватизації

Відповідно до Закону України "Про приватизацію державного майна" ( 2163-12 ) (із змінами та доповненнями) НАКАЗУЮ:

1. Внести такі зміни та доповнення до Положення про комісію з приватизації, затвердженого наказом Фонду державного майна України від 15.07.97 N 743 ( z0361-97 ) і зареєстрованого в Міністерстві юстиції України 29.08.97 за N 361/2165:

1.1. Абзаци п'ятий, сьомий, восьмий підпункту 2.1 пункту 2 вилучити.

1.2. Пункт 2 доповнити підпунктом 2.2 такого змісту:

"2.2. У разі звернення керівництва підприємства, що є в процесі приватизації, до державного органу приватизації стосовно відчуження майна та інших дій, необхідних для ефективного функціонування підприємства згідно з вимогами Закону України "Про приватизацію державного майна" ( 2163-12 ), комісія розглядає представлені документи та надає державному органу приватизації відповідні пропозиції".

1.3. Пункт 5 вилучити.

2. Директору Департаменту реформування власності Є. Філозопу:

- у п'ятиденний термін з дня затвердження цього наказу забезпечити його подання на державну реєстрацію до Міністерства юстиції України;

- у десятиденний термін з дня державної реєстрації цього наказу забезпечити його подання до Державного інформаційного бюлетеня про приватизацію для опублікування.

3. Контроль за виконанням цього наказу покласти на заступника Голови Фонду В. Васильєва.

Голова Фонду О.Бондар
