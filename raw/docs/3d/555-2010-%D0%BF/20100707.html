КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 липня 2010 р. N 555 Київ

Про внесення зміни до постанови Кабінету Міністрів України від 18 серпня 1994 р. N 569

Кабінет Міністрів України постановляє:

На часткову зміну постанови Кабінету Міністрів України від 18 серпня 1994 р. N 569 ( 569-94-п ) - із змінами, внесеними постановами Кабінету Міністрів України від 26 квітня 2003 р. N 599 ( 599-2003-п ) та від 4 червня 2008 р. N 512 ( 512-2008-п ) (Офіційний вісник України, 2008 р., N 41, ст. 1352), призначити заступника Голови Державного комітету по водному господарству Яцюка Михайла Васильовича Уповноваженим Кабінету Міністрів України в Українсько-Словацькій комісії по прикордонних водах, увільнивши від цих обов'язків Шевелєва Олександра Івановича.

Прем'єр-міністр України М.АЗАРОВ
