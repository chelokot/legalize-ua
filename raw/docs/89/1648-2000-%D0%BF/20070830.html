{ Постанова втратила чинність на підставі Постанови КМ N 1075 ( 1075-2007-п ) від 30.08.2007 }

Про реорганізацію Державного департаменту ветеринарної медицини в урядовий орган державного управління

Кабінет Міністрів України постановляє:

1. Реорганізувати Державний департамент ветеринарної медицини в урядовий орган державного управління у складі Міністерства аграрної політики.

2. Взяти до відома, що Державний департамент ветеринарної медицини розміщується у м. Києві по вул. Хрещатик, 24.

3. Міністерству аграрної політики подати у місячний термін Кабінетові Міністрів України проект Положення про Державний департамент ветеринарної медицини та пропозиції щодо приведення актів законодавства у відповідність з цією постановою.
