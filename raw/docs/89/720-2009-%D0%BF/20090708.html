Текст документа від 08.07.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 липня 2009 р. N 720 Київ

Про внесення змін до пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404

Кабінет Міністрів України постановляє:

Внести до пункту 1 постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752, N 44, ст. 2946, N 51, ст. 3406; 2007 р., N 43, ст. 1715, N 53, ст. 2157, N 56, ст. 2252, N 59, ст. 2344, N 91, ст. 3336; 2008 р., N 9, ст. 220, N 63, ст. 2146, N 69, ст. 2322, N 70, ст. 2355, N 81, ст. 2737, N 90, ст. 3004, N 95, ст. 3142; 2009 р., N 5, ст. 128, N 43, ст. 1442, N 46, ст. 1550) такі зміни:

підпункт 2 доповнити абзацами такого змісту:

"інших товарів вартістю не більш як 100 тис. гривень;

інших робіт та послуг, якщо розмір такої оплати не перевищує 30 відсотків їх вартості;";

доповнити пункт абзацом такого змісту:

"Замовники здійснюють попередню оплату вартості лише тих товарів, робіт і послуг, що згідно з договорами передбачається поставити, виконати, надати протягом поточного бюджетного року.".
