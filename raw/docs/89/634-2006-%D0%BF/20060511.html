Кабінет Міністрів України; Постанова від 11.05.2006 № 634

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для здійснення заходів з реалізації Європейської хартії регіональних мов або мов меншин

Стан: Чинний

Ідентифікатор: 634-2006-п

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 травня 2006 р. N 634 Київ

Про порядок використання у 2006 році коштів, передбачених

у державному бюджеті для здійснення заходів з реалізації Європейської хартії регіональних мов або мов меншин

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Установити, що кошти, передбачені у державному бюджеті ( 3235-15 ) для здійснення заходів з реалізації Європейської хартії регіональних мов або мов меншин ( 994_014 ), використовуються у 2006 році відповідно до Порядку використання коштів, передбачених у державному бюджеті для здійснення заходів з реалізації Європейської хартії регіональних мов або мов меншин, затвердженого постановою Кабінету Міністрів України від 21 грудня 2005 р. N 1233 ( 1233-2005-п ) (Офіційний вісник України, 2005 р., N 52, ст. 3276).

Прем'єр-міністр України Ю.ЄХАНУРОВ
