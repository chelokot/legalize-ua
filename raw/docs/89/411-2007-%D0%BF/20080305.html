Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для технічного переоснащення обласних державних телерадіокомпаній

Стан: Чинний

Ідентифікатор: 411-2007-п

Текст документа від 05.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 березня 2007 р. N 411 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для технічного переоснащення обласних державних телерадіокомпаній

{ Із змінами, внесеними згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) за програмою "Технічне переоснащення обласних державних телерадіокомпаній", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 127 ( 127-2008-п ) від 05.03.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для технічного переоснащення обласних державних телерадіокомпаній, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 51

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 березня 2007 р. N 411

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для технічного переоснащення обласних державних телерадіокомпаній

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених Держкомтелерадіо у загальному фонді державного бюджету ( 489-16 ) за програмою "Технічне переоснащення обласних державних телерадіокомпаній" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Держкомтелерадіо, а їх одержувачами переможці процедури закупівлі товарів, робіт і послуг, пов'язаних з технічним переоснащенням обласних державних телерадіокомпаній.

3. Бюджетні кошти спрямовуються на закупівлю обладнання для обласних державних телерадіокомпаній (далі - телерадіокомпанії) та використовуються Держкомтелерадіо у межах бюджетних асигнувань, визначених кошторисом, з урахуванням:

технічного стану телерадіокомпаній;

необхідності виконання бюджетних зобов'язань минулих років, узятих на облік в органах Державного казначейства, у разі їх відповідності паспортові бюджетної програми.

4. Держкомтелерадіо:

1) затверджує перелік обладнання, що закуповується за бюджетні кошти;

2) здійснює розміщення замовлення на технічне переоснащення телерадіокомпаній відповідно до Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 );

3) укладає договори з одержувачами бюджетних коштів з урахуванням таких вимог:

сума, визначена в договорі, може коригуватися у процесі уточнення показників державного бюджету;

поставка товарів, виконання робіт і надання послуг обов'язково здійснюються до закінчення календарного року;

{ Підпункт 4 пункту 4 виключено на підставі Постанови КМ N 127 ( 127-2008-п ) від 05.03.2008 }

5) забезпечує розгляд на колегії Комітету та затверджує розподіл закупленого за бюджетні кошти обладнання між телерадіокомпаніями.

5. Попередня оплата товарів, робіт і послуг за рахунок бюджетних коштів здійснюється відповідно до постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752).

Остаточні розрахунки згідно з договором проводяться Держкомтелерадіо на підставі актів приймання-передачі та поданих одержувачами бюджетних коштів відповідних рахунків.

6. Операції, пов'язані з обслуговуванням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 7 виключено на підставі Постанови КМ N 127 ( 127-2008-п ) від 05.03.2008 }

{ Пункт 8 виключено на підставі Постанови КМ N 127 ( 127-2008-п ) від 05.03.2008 }

9. Відповідальність за цільове використання бюджетних коштів покладається на головного розпорядника бюджетних коштів та їх одержувачів.

10. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
