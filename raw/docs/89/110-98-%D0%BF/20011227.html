КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 лютого 1998 р. N 110 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1738 ( 1738-2001-п ) від 27.12.2001 )

Про умови оплати праці членів окружних і дільничних виборчих комісій

( Із змінами, внесеними згідно з Постановами КМ N 364 ( 364-98-п ) від 25.03.98 N 1353 ( 1353-2000-п ) від 30.08.2000 )

Відповідно до статті 17 Закону України "Про вибори народних депутатів України" ( 541/97-ВР ) Кабінет Міністрів України постановляє:

1. Установити місячну заробітну плату членам виборчих комісій, звільненим від виконання виробничих або службових обов'язків за основним місцем роботи, на період виборчої кампанії у таких розмірах:

(гривень)

——————————————————————————————————————————————————————————————————

| Окружна виборча | Дільнична виборча

| комісія | комісія

——————————————————————————————————————————————————————————————————

Голова комісії 280 200 Заступник голови комісії 260 185 Секретар комісії 240 170 Член комісії 200 160

2. У разі коли встановлена пунктом 1 цієї постанови місячна заробітна плата голови, заступника голови, секретаря або члена комісії нижча, ніж його середня місячна заробітна плата за основним місцем роботи, вона встановлюється йому на рівні середньої заробітної плати за основним місцем роботи, визначеної згідно із законодавством, але не більш як 500 гривень. ( Дію пункту 2 поширено на членів окружних та дільничних виборчих комісій по виборах депутатів Верховної Ради Автономної Республіки Крим згідно з Постановою КМ N 364 ( 364-98-п ) від 25.03.98 )

( Пункт 2 в редакції Постанови КМ N 1353 ( 1353-2000-п ) від 30.08.2000 )

3. Надати голові окружної виборчої комісії право виплачувати активним членам окружних і дільничних виборчих комісій у межах економії фонду заробітноЇ плати одноразову винагороду у розмірі до 100 відсотків місячної заробітної плати члена відповідної виборчої комісії після завершення її роботи. ( Дію пункту 3 поширено на членів окружних та дільничних виборчих комісій по виборах депутатів Верховної Ради Автономної Республіки Крим згідно з Постановою КМ N 364 ( 364-98-п ) від 25.03.98 )

4. Виплата заробітної плати членам окружної та дільничної виборчих комісій провадиться окружними виборчими комісіями за рахунок видатків окружних та дільничних виборчих комісій для забезпечення підготовки та проведення виборів народних депутатів України.

5. Заробітна плата, нарахована за час роботи у виборчих комісіях, включається до фактичного заробітку за основним місцем роботи при обчисленні пенсій та середньої заробітної плати у випадках, передбачених законодавством. ( Дію пункту 5 поширено на членів окружних та дільничних виборчих комісій по виборах депутатів Верховної Ради Автономної Республіки Крим згідно з Постановою КМ N 364 ( 364-98-п ) від 25.03.98 )

6. Міністерству фінансів разом з Міністерством праці та соціальної політики за погодженням з Центральною виборчою комісією розробити і затвердити порядок нарахування і виплати заробітної плати та одноразової винагороди членам виборчих комісій на період виборчої кампанії.
