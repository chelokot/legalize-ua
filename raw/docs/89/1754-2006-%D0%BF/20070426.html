Кабінет Міністрів України; Постанова від 19.12.2006 № 1754

Про внесення змін до постанов Кабінету Міністрів України від 5 квітня 2006 р. N 441 і від 26 червня 2006 р. N 873

Стан: Чинний

Ідентифікатор: 1754-2006-п

Текст документа від 26.04.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 грудня 2006 р. N 1754 Київ

Про внесення змін до постанов Кабінету Міністрів України від 5 квітня 2006 р. N 441 і від 26 червня 2006 р. N 873

{ Із змінами, внесеними згідно з Постановою КМ N 676 ( 676-2007-п ) від 26.04.2007 }

Кабінет Міністрів України постановляє:

1. У постановляючій частині постанови Кабінету Міністрів України від 5 квітня 2006 р. N 441 ( 441-2006-п ) "Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для здійснення заходів щодо формування державного замовлення на ринку продовольчих товарів" (Офіційний вісник України, 2006 р., N 14, ст. 997):

абзац другий викласти в такій редакції:

"придбання сільськогосподарської продукції (у тому числі зерна) з метою її закладення до державного резерву здійснюється відповідно до Порядку придбання матеріальних цінностей для закладення до державного матеріального резерву, затвердженого постановою Кабінету Міністрів України від 26 червня 2006 р. N 873 ( 873-2006-п ), а також шляхом укладення угод купівлі-продажу на акредитованих біржах - тільки у разі придбання зерна";

в абзаці третьому слова "до тендерної документації та договору про закупівлю з переможцем торгів" замінити словами "до конкурсної документації, договору про придбання продукції або угоди купівлі-продажу на акредитованій біржі".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 676 ( 676-2007-п ) від 26.04.2007 }
