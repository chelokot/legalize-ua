Про внесення змін до Інструкції про порядок складання місячних звітів по формі N 5-зез "Звіт про експорт (імпорт) товарів, що не проходять митного декларування"

Стан: Втратив чинність

Ідентифікатор: z0368-99

Текст документа від 09.08.2001:

ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

N 176 від 27.05.99 Зареєстровано в Міністерстві м.Київ юстиції України 11 червня 1999 р. vd990527 vn176 за N 368/3661

( Наказ втратив чинність на підставі Наказу Держкомстату N 328 ( z0681-01 ) від 23.07.2001 )

Про внесення змін до Інструкції про порядок складання

місячних звітів по формі N 5-зез "Звіт про експорт

(імпорт) товарів, що не проходять митного декларування"

У зв'язку з удосконаленням методології статистики зовнішньої торгівлі та переходом до міжнародних стандартів згідно з Методологічними рекомендаціями Статкомітету ООН "Статистика міжнародної торгівлі товарами: концепції та визначення" (1998 рік) потребує уточнення Інструкція про порядок складання місячних звітів по ф. N 5-зез "Звіт про експорт (імпорт) товарів, що не проходять митного декларування", затверджена наказом Міністерства статистики України від 19 квітня 1997 року N 106 ( z0192-97 ) і зареєстрована Міністерством юстиції України 27 травня 1997 року за N 192/1996, НАКАЗУЮ:

1. Внести зміни до Інструкції про порядок складання місячних звітів по формі N 5-зез "Звіт про експорт (імпорт) товарів, що не проходять митного декларування".

1.1. Пункт 2.4 викласти в такій редакції:

"Повернення товарів у зовнішній торгівлі реєструється окремо. Якщо експортний товар згодом повернений, його слід включати як імпорт на момент його повернення. Аналогічно товари, ввезені та згодом повернені, необхідно включати як експорт також на момент повернення. Підприємство повинне надати обласному управлінню статистики письмове підтвердження про повернення товару з визначенням країни, валюти, назви товару і його коду за ТН ЗЕД та кількості і вартості поверненого вантажу в тис. одиниць валюти контракту".
