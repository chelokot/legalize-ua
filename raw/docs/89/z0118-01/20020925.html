ДЕРЖАВНИЙ КОМІТЕТ СТАНДАРТИЗАЦІЇ, МЕТРОЛОГІЇ ТА СЕРТИФІКАЦІЇ УКРАЇНИ

НАКАЗ

N 29 від 24.01.2001 Зареєстровано в Міністерстві м. Київ юстиції України 7 лютого 2001 р. за N 118/5309

( Наказ втратив чинність на підставі Наказу Державного комітету стандартизації, метрології та сертифікації N 498 ( z0782-02 ) від 30.08.2002 )

Про внесення змін до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, і до Термінів уведення обов'язкової сертифікації окремих видів продукції в Україні

Відповідно до статті 14 Декрету Кабінету Міністрів України від 10.05.93 N 46-93 ( 46-93 ) "Про стандартизацію і сертифікацію" та на виконання Указу Президента України від 22.01.2000 N 89/2000 ( 89/2000 ) "Про запровадження єдиної державної регуляторної політики у сфері підприємництва" НАКАЗУЮ:

1. Унести до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, затвердженого наказом Держстандарту України від 30.06.93 N 95 ( z0112-93 ) і зареєстрованого в Міністерстві юстиції України 19.08.93 за N 112, зі змінами та доповненнями, унесеними наказами Держстандарту України від 27.11.96 N 499 ( z0728-96, za728-96 ), від 17.05.97 N 268 ( z0209-97 ), від 04.07.97 N 388 ( z0304-97 ), від 11.09.97 N 549 ( z0461-97 ), від 20.01.98 N 27 ( z0072-98 ), від 27.01.99 N 37 ( z0234-99 ), від 05.05.99 N 205 ( z0299-99 ), від 14.06.99 N 322 ( z0404-99 ), від 14.06.99 N 323 ( z0416-99 ), від 25.10.99 N 287 ( z0784-99 ), від 10.12.99 N 389 ( z0897-99 ), від 29.12.99 N 418 ( z0013-00 ), від 27.03.2000 N 241 ( z0223-00 ), від 21.07.2000 N 448 ( z0454-00 ), від 24.07.2000 N 449 ( z0483-00 ), зареєстрованими в Міністерстві юстиції України відповідно 19.12.96 за N 728/1753, 05.06.97 за N 209/2013, 13.08.97 за N 304/2108, 09.10.97 за N 461/2265, 04.02.98 за N 72/2512, 15.04.99 за N 234/3527, 11.05.99 за N 299/3592, 22.06.99 за N 404/3697, 24.06.99 за N 416/3709, 15.11.99 за N 784/4077, 22.12.99 за N 897/4190, 13.01.2000 за N 13/4234, 11.04.2000 за N 223/4444, 28.07.2000 за N 454/4675, 08.08.2000 за N 483/4704, такі зміни:

1) вилучити: розділ "36. Послуги автомобільного транспорту".

2. Вилучити з Термінів уведення обов'язкової сертифікації окремих видів продукції в Україні, затверджених наказом Держстандарту України від 27.11.96 N 499 ( z0729-96 ) і зареєстрованих у Міністерстві юстиції України 19.12.96 за N 729/1754, із змінами та доповненнями, унесеними наказами Держстандарту України від 04.07.97 N 388 ( z0304-97 ), від 11.09.97 N 549 ( z0461-97 ), від 20.01.98 N 27 ( z0072-98 ), від 27.01.99 N 37 ( z0234-99 ), від 05.05.99 N 205 ( z0299-99 ), від 14.06.99 N 322 ( z0404-99 ), від 25.10.99 N 287 ( z0784-99 ), від 10.12.99 N 389 ( z0897-99 ), від 29.12.99 N 418 ( z0013-00 ), зареєстрованими в Міністерстві юстиції України відповідно 13.08.97 за N 304/2108, 09.10.97 за N 461/2265, 04.02.98 за N 72/2512, 15.04.99 за N 234/3527, 11.05.99 за N 299/3592, 22.06.99 за N 404/3697, 15.11.99 за N 784/4077, 22.12.99 за N 897/4190, 13.01.2000 за N 13/4234, 28.07.2000 за N 454/4675, 08.08.2000 за N 483/4704, рядок "36. Послуги автомобільного транспорту ... 01.09.99".

3. Управлінню державного нагляду та підтвердження відповідності (Баб'як О.М.) у п'ятиденний термін забезпечити подання на державну реєстрацію до Міністерства юстиції України наказу "Про внесення змін до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, і до Термінів уведення обов'язкової сертифікації окремих видів продукції в Україні".

4. Українському науково-дослідному інституту стандартизації, сертифікації та інформатики (Угаров Б.В.) після державної реєстрації в Міністерстві юстиції України наказу "Про внесення змін до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, і до Термінів уведення обов'язкової сертифікації окремих видів продукції в Україні" забезпечити його публікацію в черговому виданні щомісячного інформаційного покажчика "Стандарти".

5. Наказ "Про внесення змін до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, і до Термінів уведення обов'язкової сертифікації окремих видів продукції в Україні" набирає чинності через один місяць після реєстрації в Міністерстві юстиції України.

6. Контроль за виконанням цього наказу залишаю за собою.
