ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 448 від 03.11.98 Зареєстровано в юридичному м.Київ департаменті Нацбанку 5 листопада 1998 р. vd981103 vn448 за N 585

( Постанова втратила чинність на підставі Постанови Національного банку N 625 ( z1650-04 ) від 10.12.2004 )

Про затвердження Інструкції з бухгалтерського обліку операцій з ювілейними монетами в установах комерційних банків України

У зв'язку з введенням у дію нового Плану рахунків бухгалтерського обліку комерційних банків ( va493500-97 ) та з метою приведення у відповідність з ним бухгалтерського обліку операцій із придбання, реалізації ювілейних монет гривневого і карбованцевого номіналу Правління ПОСТАНОВЛЯЄ:

1. Затвердити Інструкцію з бухгалтерського обліку операцій з ювілейними монетами в установах комерційних банків України (додається).

2. Визнати такими, що втратили чинність, постанови Правління Національного банку України від 02.10.96 N 255 ( v0255500-96 ) "Про порядок обліку та реалізації пам'ятних і ювілейних монет України, що мають карбованцевий номінал" та від 28.11.96 N 313 ( v0401500-96 ) "Про порядок введення в обіг та облік ювілейних монет, що мають гривневий номінал і є дійсним засобом платежу".

3. Постанова набуває чинності з 1 грудня 1998 р.

4. Контроль за виконанням цієї постанови покласти на Департамент бухгалтерського обліку (П.М.Сенищ).

Голова В.А.Ющенко

Затверджено постановою Правління НБУ N 448 від 03.11.98 р. (реєстр. N 585 від 05.11.98 р.)

Інструкція з бухгалтерського обліку операцій з ювілейними монетами в установах комерційних банків України

I. Загальні положення

Інструкція з бухгалтерського обліку операцій з ювілейними монетами визначає порядок бухгалтерського обліку в установах комерційних банків операцій із придбання, реалізації ювілейних монет гривневого і карбованцевого номіналу.

Фінансовий облік операцій із придбання та реалізації ювілейних монет здійснюється за такими балансовими та позабалансовими рахунками:

балансовими:

N 1001 "Банкноти та монети в касі банку"

N 1200 "Кореспондентський рахунок у Національному банку України"

N 1819 "Інша дебіторська заборгованість за операціями з банками"

N 1919 "Інша кредиторська заборгованість за операціями з банками"

N 2909 "Інша кредиторська заборгованість за операціями з клієнтами банку"

N 3400 "Господарські матеріали на складі"

N 3500 "Витрати майбутніх періодів"

N 3520 "Дебіторська заборгованість за податками та обов'язковими платежами"

N 3620 "Кредиторська заборгованість за податками та обов'язковими платежами"

N 6109 "Інші комісійні доходи за операціями з банками"

N 6209 "Результат від торговельних операцій з іншими фінансовими інструментами"

N 7454 "Представницькі витрати"

позабалансовими:

N 9819 "Інші цінності і документи"

N 9910 "Контррахунки для рахунків розділів 96-98"

Облік сертифікатів до ювілейних монет здійснюється за умовною вартістю одна гривня за позабалансовим рахунком N 9819 "Інші цінності і документи".

Облік футлярів та іншої упаковки ювілейних монет здійснюється окремо за рахунками товарно-матеріальних цінностей.
