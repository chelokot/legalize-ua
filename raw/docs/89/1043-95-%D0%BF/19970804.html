Кабінет Міністрів України; Постанова від 25.12.1995 № 1043

Про упорядкування оплати праці працівників апарату органів державної виконавчої влади, прокуратури, судів, митної служби та інших органів

Стан: Втратив чинність

Ідентифікатор: 1043-95-п

Текст документа від 04.08.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 грудня 1995 р. N 1043 Київ

Про упорядкування оплати праці працівників апарату органів державної виконавчої влади, прокуратури, судів, митної служби та інших органів

( Поширити дію постанови на народних депутатів України з 1 березня 1996 року згідно з Постановою Президії ВР N 214/96-ПВ від 23.03.96 )

( Постанова втратила чинність в частині митних органів на підставі Постанови КМ N 225 ( 225-97-п ) від 12.03.97 )

( Із змінами, внесеними згідно з Постановою КМ N 828 ( 828-97-п ) від 04.08.97 )

З метою створення відповідних умов для належного виконання службових обов'язків працівників апарату органів державної виконавчої влади, прокуратури, судів, митної служби та інших органів Кабінет Міністрів України постановляє:

1. Підвищити посадові оклади працівників апарату органів державної виконавчої влади, прокуратури, судів, митної служби та інших органів, визначені виходячи з мінімальної заробітної плати (60 тис.крб.) і коефіцієнтів співвідношень посадових окладів до мінімального розміру заробітної плати, затверджених постановами Кабінету Міністрів України від 21 січня 1993 р. N 35 ( 35-93-п ), 38 ( 38-93-п ), 39 ( 39-93-п) і 40 ( 40-93-п ), від 18 лютого 1993 р. N 125 ( 125-93-п ), від 8 червня 1994 р. N 376 ( 376-94-п ), від 28 червня 1994 р. N 437 ( 437-94-п ), від 6 листопада 1995 р. N 888 ( 888-95-п) і від 29 листопада 1995 р. N 954 ( 954-95-п ), розпорядженням Кабінету Міністрів України від 5 червня 1993 р. N 368 ( 368-93-р ), та працівників, на яких поширено умови оплати праці, передбачені постановою Кабінету Міністрів України від 21 січня 1993 р., N 35, на коефіцієнт 15 - для керівних працівників і спеціалістів та на коефіцієнт 16 - для службовців, без застосування підвищуючих коефіцієнтів, передбачених у додатку N 6 до постанови Кабінету Міністрів України від 2 червня 1993 р. N 393 ( 393-93-п ) в редакції постанови Кабінету Міністрів України від 8 лютого 1995 р. N 102 (ЗП України, 1995 р., N 5, ст.113).

2. ( Пункт 2 втратив чинність в частині, керівних працівників та спеціалістів державної податкової служби інспекції на підставі Постанови КМ N 828 ( 828-97-п ) від 04.08.97 ) Підвищити у 2 рази розміри надбавок до посадових окладів за дипломатичні ранги України, персональні звання службових осіб митних органів, державної податкової інспекції, ранги державних службовців, визначені відповідно до постанови Кабінету Міністрів України від 21 грудня 1994 р. N 855 ( 855-94-п ) "Про розміри надбавок до посадових окладів працівників за дипломатичні ранги України, персональні звання та ранги державних службовців".

3. ( Пункт 3 втратив чинність в частині, керівних працівників та спеціалістів державної податкової служби інспекції на підставі Постанови КМ N 828 ( 828-97-п ) від 04.08.97 ) У постанові Кабінету Міністрів України від 16 жовтня 1995 р. N 821 ( 821-95-п ) "Про підвищення посадових окладів керівних працівників і спеціалістів державної податкової служби та державної контрольно-ревізійної служби":

у пункті 1 цифри "12,5" замінити цифрами "15";

пункт 3 визнати таким, що втратив чинність.

4. Видатки, пов'язані з упорядкуванням оплати праці працівників апарату органів державної виконавчої влади, прокуратури, судів, митної служби, інших органів, здійснити в межах асигнувань, передбачених у Державному бюджеті України на 1996 рік на утримання відповідних органів.

5. Визнати такими, що втратили чинність:

абзац четвертий пункту 1 постанови Кабінету Міністрів України від 13 червня 1995 р. N 409 ( 409-95-п ) "Про підвищення заробітної плати на державних підприємствах, в установах і організаціях" (ЗП України, 1995 р., N 8, ст. 212);

абзац третій пункту 1 постанови Кабінету Міністрів України від 2 жовтня 1995 р. N 778 ( 778-95-п ) "Про підвищення з 1 жовтня 1995 р. заробітної плати працівників бюджетних установ і організацій".

6. Ця постанова набуває чинності з 1 січня 1996 року.
