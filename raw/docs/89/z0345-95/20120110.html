Про порядок оплати робіт, що виконуються проектно-розвідувальними станціями хімізації сільського господарства

Реєстрація: Мін'юст України від 29.09.1995 № 345/881

Стан: Втратив чинність

Ідентифікатор: z0345-95

Текст документа від 10.01.2012:

МІНІСТЕРСТВО СІЛЬСЬКОГО ГОСПОДАРСТВА І ПРОДОВОЛЬСТВА УКРАЇНИ

НАКАЗ

N 321 від 30.11.93 Зареєстровано в Міністерстві м.Київ юстиції України 29 вересня 1995 р. vd931130 vn321 за N 345/881

Про порядок оплати робіт, що виконуються проектно-розвідувальними станціями хімізації сільського господарства

{ Із змінами, внесеними згідно з Наказом Міністерства аграрної політики та продовольства

N 536 ( z1517-11 ) від 11.10.2011 }

З метою впорядкування оплати проектно-розвідувальних, виробничих і науково-дослідних робіт, що виконуються проектно-розвідувальними станціями хімізації сільського господарства, НАКАЗУЮ:

I. Зберегти в основі діючий порядок, при якому проектно-розвідувальні станції хімізації сільського господарства виконують проектно-розвідувальні, виробничі та науково-дослідні роботи по агрохімічному обслуговуванню сільського господарства, які фінансуються за рахунок коштів Державного бюджету та коштів замовників.

II. Затвердити:

1) погоджений з Міністерством фінансів України Перелік проектно-розвідувальних, виробничих і науково-дослідних робіт, що виконуються Кримською республіканською та обласними державними проектно-розвідувальними станціями хімізації сільського господарства за рахунок Державного бюджету України, що додається;

2) Перелік проектно-розвідувальних, виробничих і науково-дослідних робіт, що виконуються Кримською республіканською та обласними державними проектно-розвідувальними станціями хімізації сільського господарства за договорами, що додається;

3) Програму робіт проектно-розвідувальних станцій хімізації сільського господарства, що додається;

{ Пункт 4 розділу II втратив чинність на підставі Наказу Міністерства аграрної політики та продовольства N 536 ( z1517-11 ) від 11.10.2011 }

{ Пункт 5 розділу II втратив чинність на підставі Наказу Міністерства аграрної політики та продовольства N 536 ( z1517-11 ) від 11.10.2011 }

III. Встановити, що обсяги робіт, які фінансуються з Державного бюджету, виконуються відповідно до затвердженої Мінсільгосппродом програми в межах передбачених ним коштів.

Перший заступник Міністра А.А.Засуха

{ Положення про агрохімічний паспорт поля, земельної ділянки втратило чинність на підставі Наказу Міністерства аграрної політики та продовольства N 536 ( z1517-11 ) від 11.10.2011 }
