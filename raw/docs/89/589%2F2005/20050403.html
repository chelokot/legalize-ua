Текст документа від 03.04.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про голову Національної комісії України у справах ЮНЕСКО

На зміну статті 2 Указу Президента України від 9 листопада 1995 року N 1022 ( 1022/95 ) "Про Національну комісію України у справах ЮНЕСКО" (зі змінами, внесеними Указами від 21 грудня 1998 року N 1366 ( 1366/98 ) та від 20 травня 2004 року N 565 ( 565/2004 ) призначити ОГРИЗКА Володимира Станіславовича - першого заступника Міністра закордонних справ України - головою Національної комісії України у справах ЮНЕСКО, увільнивши від виконання цих обов'язків В. Єльченка.

Президент України В.ЮЩЕНКО
