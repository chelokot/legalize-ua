Стан: Чинний

Ідентифікатор: 1-2009-р

Текст документа від 18.03.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 січня 2009 р. N 1-р Київ

Про виділення коштів для придбання житла, відшкодування вартості втраченого майна та виплати матеріальної допомоги постраждалим від надзвичайної ситуації, що виникла 24 грудня 2008 р. у м. Євпаторії, а також проведення робіт з демонтажу будинку по вул. Некрасова, 67

{ Назва Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 280-р ( 280-2009-р ) від 18.03.2009 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 280-р ( 280-2009-р ) від 18.03.2009 }

1. Виділити Мінпраці 47,5 млн. гривень для придбання житла, відшкодування вартості втраченого майна та виплати матеріальної допомоги постраждалим від надзвичайної ситуації, що виникла 24 грудня 2008 р. у м. Євпаторії, у тому числі 4,07 млн. гривень для проведення робіт з демонтажу будинку по вул. Некрасова, 67. { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 280-р ( 280-2009-р ) від 18.03.2009 }

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 835-17 ).

2. Мінфіну та Державному казначейству забезпечити перерахування 9 січня 2009 р. Мінпраці виділених коштів і здійснити передбачені цим розпорядженням видатки без затвердження переліків витрат, пов'язаних з придбанням житла, відшкодуванням вартості втраченого майна та виплатою матеріальної допомоги постраждалим.

3. Дозволити Мінпраці здійснювати попередню оплату вартості житла для постраждалих.

4. Мінпраці:

спрямувати виділені згідно з цим розпорядженням кошти на придбання житла, відшкодування вартості втраченого майна та виплату матеріальної допомоги постраждалим, проведення робіт з демонтажу будинку по вул. Некрасова, 67; { Абзац другий пункту 4 із змінами, внесеними згідно з Розпорядженням КМ N 280-р ( 280-2009-р ) від 18.03.2009 }

подати до кінця 2009 року Мінекономіки, Мінрегіонбуду, Мінфіну та Державному казначейству звіт про використання виділених згідно з цим коштів. { Абзац третій пункту 4 із змінами, внесеними згідно з Розпорядженням КМ N 280-р ( 280-2009-р ) від 18.03.2009 }
