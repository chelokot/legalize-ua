РОЗДІЛ 1. ЗАГАЛЬНІ ПОЛОЖЕННЯ

1.1. Це Положення визначає склад, терміни та порядок подання до Державної комісії з цінних паперів та фондового ринку (далі - Комісія) адміністративних даних фондових бірж та торговельно-інформаційних систем (далі - організатори торгівлі) та інформації про них. ( Пункт 1.1 із змінами, внесеними згідно з Рішенням Держкомісціннихпаперів N 326 ( z0916-02 ) від 29.10.2002 )

1.2. Дія цього Положення поширюється на організаторів торгівлі, які зареєстровані в Комісії та отримали ліцензію на здійснення професійної діяльності на ринку цінних паперів, а саме діяльності з організації торгівлі на ринку цінних паперів, у встановленому Комісією порядку.

1.3. Прийняті адміністративні дані - адміністративні дані, подані до відповідного підрозділу Комісії в електронній та паперовій формах у терміни та обсязі, які встановлені цим Положенням. Паперова форма адміністративних даних за складом даних має відповідати електронній формі, крім щоденних та щомісячних адміністративних даних, які надаються лише в електронній формі. Адміністративні дані мають бути зареєстровані в журналі прийнятих адміністративних даних з відміткою про реєстрацію на титульному аркуші. При надходженні адміністративних даних поштою дата подання визначається за поштовим штемпелем відділення зв'язку, що обслуговує відправника. При невиконанні цих умов адміністративні дані вважаються поданими несвоєчасно. ( Пункт 1.3 в редакції Рішень Держкомісціннихпаперів N 326 ( z0916-02 ) від 29.10.2002, N 382 ( z0906-03 ) від 23.09.2003 )

1.4. Режим "реального часу" - режим, при якому укладання угоди в організатора торгівлі та інформування Комісії про суттєві умови укладеної угоди виконуються одночасно.

( Назва розділу 2 із змінами, внесеними згідно з Рішенням Держкомісціннихпаперів

N 326 ( z0916-02 ) від 29.10.2002 )

2.1. Суб'єктами подання адміністративних даних є організатори торгівлі, які мають ліцензії Комісії на здійснення професійної діяльності на ринку цінних паперів, а саме діяльності з організації торгівлі на ринку цінних паперів, отримані у встановленому чинним законодавством порядку. ( Пункт 2.1 із змінами, внесеними згідно з Рішенням Держкомісціннихпаперів N 326 ( z0916-02 ) від 29.10.2002 )

2.2. Організатори торгівлі подають до центрального апарату Комісії такі види адміністративних даних:

- щоденні;

- щомісячні;

- квартальні;

- річні.

( Пункт 2.2 в редакції Рішення Держкомісціннихпаперів N 326 ( z0916-02 ) від 29.10.2002 )

2.3. Організатори торгівлі подають адміністративні дані до Комісії в такі терміни:

- щоденні - до 19 години цього звітного дня; ( Абзац другий пункту 2.3 в редакції Рішення Держкомісціннихпаперів N 382 ( z0906-03 ) від 23.09.2003 )

- щомісячні - до 10-го числа місяця, наступного за звітним;

- квартальні - до останього числа місяця, наступного за звітним кварталом;

- річні - до 1 квітня року, наступного за звітним. У разі, коли останній день подання адміністративних даних випадає на неробочий, термін подання переноситься на перший після неробочого робочий день.

( Пункт 2.3 в редакції Рішення Держкомісціннихпаперів N 326 ( z0916-02 ) від 29.10.2002 )

2.4. Адміністративні дані складаються шляхом заповнення українською мовою таблиць та форм, передбачених цим Положенням, за допомогою програмних засобів, які забезпечують формування файлів електронної форми. ( Пункт 2.4 із змінами, внесеними згідно з Рішенням Держкомісціннихпаперів N 326 ( z0916-02 ) від 29.10.2002, в редакції Рішення Держкомісціннихпаперів N 382 ( z0906-03 ) від 23.09.2003 )

2.5. Адміністративні дані у паперовій формі формуються у вигляді друкованих таблиць, які за складом інформації відповідають електронній формі адміністративних даних. Відповідність інформації в паперовій та електронній формах підтверджується підписом керівника організатора торгівлі на титульному аркуші. Адміністративні дані супроводжуються листом на фірмовому бланку організатора торгівлі, у якому зазначається звітний період і перелік документів паперової форми та файлів електронної форми, що додаються. ( Пункт 2.5 в редакції Рішення Держкомісціннихпаперів N 326 ( z0916-02 ) від 29.10.2002 )

2.6. Вимоги до формування та відправки електронних форм адміністративних даних організаторів торгівлі засобами електронної пошти:

- одне поштове повідомлення може містити лише одну електронну форму адміністративних даних;

- електронні файли адміністративних даних обов'язково повинні мати назви, визначені цим Положенням;

- файли електронної форми адміністративних даних, надіслані заархівованими (архіви ZIP, ARJ та ін.) системою автоматичного прийняття поштових повідомлень та обробки інформації, не опрацьовуються.

( Пункт 2.6 із змінами, внесеними згідно з Рішенням Держкомісціннихпаперів N 326 ( z0916-02 ) від 29.10.2002 )

2.7. Про дату отримання електронного файла адміністративних даних організатора торгівлі та порядковий номер, за яким адміністративні дані отримано, відповідний підрозділ Комісії, який здійснює приймання адміністративних даних, повідомляє організатора торгівлі електронною поштою не пізніше наступного робочого дня після надходження адміністративних даних до Комісії. Після подання паперової форми адміністративних даних відповідний підрозділ Комісії, який здійснює приймання адміністративних даних організатора торгівлі, проводить перевірку на відповідність паперової та електронної форм адміністративних даних та повідомляє організатора торгівлі засобами електронної пошти про прийняття або неприйняття адміністративних даних протягом трьох робочих днів з дня надходження адміністративних даних у паперовій формі до цього підрозділу Комісії. ( Пункт 2.7 в редакції Рішення Держкомісціннихпаперів N 326 ( z0916-02 ) від 29.10.2002 )

2.8. У разі невідповідності електронної форми адміністративних даних вимогам цього Положення відповідний підрозділ Комісії повідомляє організатора торгівлі з указанням причин, за якими адміністративні дані не були прийняті. Організатор торгівлі протягом трьох робочих днів повинен усунути ці причини та надати адміністративні дані повторно. ( Пункт 2.8 в редакції Рішень Держкомісціннихпаперів N 326 ( z0916-02 ) від 29.10.2002, N 382 ( z0906-03 ) від 23.09.2003 )
