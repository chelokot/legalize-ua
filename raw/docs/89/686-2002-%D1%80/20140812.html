{ Розпорядження втратило чинність на підставі Постанови КМ N 309 ( 309-2014-п ) від 06.08.2014 }

Про внесення зміни у додаток 2 до розпорядження Кабінету Міністрів України від 2 грудня 2002 р. N 685

У додатку 2 до розпорядження Кабінету Міністрів України від 2 грудня 2002 р. N 685 ( 685-2002-р ) "Про забезпечення взаємодії Кабінету Міністрів України з Верховною Радою України, місцевими органами виконавчої влади та органами місцевого самоврядування" в графі "Назва адміністративно-територіальної одиниці" слова "Харківська область" замінити словами "м. Київ", а слова "м. Київ" - словами "Харківська область".
