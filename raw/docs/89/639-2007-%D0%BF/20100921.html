Текст документа від 21.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 квітня 2007 р. N 639 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для збереження та функціонування національної еталонної бази

{ Із змінами, внесеними згідно з Постановами КМ N 258 ( 258-2008-п ) від 26.03.2008 N 850 ( 850-2010-п ) від 15.09.2010 }

{ Установити, що використання у 2008 році коштів, передбачених Мінекономіки у державному бюджеті ( 107-17 ) за програмою "Збереження та функціонування національної еталонної бази", здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 258 ( 258-2008-п ) від 26.03.2008 }

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для збереження та функціонування національної еталонної бази, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 20 квітня 2007 р. N 639

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для збереження та функціонування національної еталонної бази

Загальні положення

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Мінекономіки за програмою "Збереження та функціонування національної еталонної бази" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є Мінекономіки.

Розпорядником бюджетних коштів нижчого рівня є Держспоживстандарт.

Розпорядник бюджетних коштів нижчого рівня затверджує в установленому порядку план заходів щодо збереження та функціонування національної еталонної бази. { Пункт 2 доповнено абзацом згідно з Постановою КМ N 850 ( 850-2010-п ) від 15.09.2010 }

Для проведення передбачених планом заходів робіт розпорядник бюджетних коштів нижчого рівня видає у кожному конкретному випадку наказ, у якому зазначаються найменування заходу, його виконавець, дата і місце проведення, сума витрат. { Пункт 2 доповнено абзацом згідно з Постановою КМ N 850 ( 850-2010-п ) від 15.09.2010 }

До наказу додається кошторис витрат, пов'язаних з підготовкою та проведенням заходу, з відповідними розрахунками та обґрунтуванням. { Пункт 2 доповнено абзацом згідно з Постановою КМ N 850 ( 850-2010-п ) від 15.09.2010 }

3. Бюджетні кошти спрямовуються на виконання робіт із збереження та функціонування національної еталонної бази згідно з додатком.

Вимоги щодо використання бюджетних коштів

4. Закупівля товарів, робіт і послуг за державні кошти здійснюється в установленому законом порядку.

{ Пункт 4 в редакції Постанови КМ N 850 ( 850-2010-п ) від 15.09.2010 }

5. З метою недопущення виникнення кредиторської заборгованості на кінець року до договору про закупівлю робіт включається вимога щодо коригування визначеної в ньому суми та зобов'язань сторін договору в разі зменшення бюджетних призначень під час уточнення показників Державного бюджету України на 2007 рік ( 489-16 ).

6. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 6 в редакції Постанови КМ N 850 ( 850-2010-п ) від 15.09.2010 }

7. Попередня оплата робіт відповідно до укладених договорів про закупівлю робіт може здійснюватися у розмірі до 30 відсотків їх вартості відповідно до постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752).

Остаточна оплата вартості виконаних робіт провадиться на підставі актів приймання-передачі.

Звітність про використання бюджетних коштів та контроль за їх витрачанням

{ Пцнут 8 виключено на підставі Постанови КМ N 258 ( 258-2008-п ) від 26.03.2008 }

9. Складення і подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.

Розпорядник бюджетних коштів нижчого рівня подає щокварталу до 1 числа місяця, що настає за звітним періодом, головному розпорядникові бюджетних коштів інформацію про використання бюджетних коштів для її узагальнення та надсилання до 5 числа зазначеного місяця Мінфіну. { Пункт 9 доповнено абзацом згідно з Постановою КМ N 850 ( 850-2010-п ) від 15.09.2010 }

Додаток до Порядку

ПЕРЕЛІК робіт із збереження та функціонування національної еталонної бази

1. Виконання регламентних ремонтно-відновлювальних робіт з експлуатації апаратури та засобів вимірювальної техніки, що входить до складу державних еталонів.

2. Придбання витратних матеріалів і комплектувальних частин для проведення ремонту еталонних комплексів та апаратури (в тому числі електричної та теплової енергії, води, рідкого азоту, рідкого гелію).

3. Проведення проектних робіт з модернізації систем кондиціонування.

4. Модернізація систем кондиціонування (монтаж та налагодження).

5. Забезпечення охорони об'єктів національного надбання та здійснення контролю за дотриманням правил протипожежної безпеки.

6. Удосконалення інформаційно-аналітичної системи державних еталонів.

7. Проведення аналізу технічного стану державних еталонів та ведення документації.

8. Проведення поточного ремонту і заходів щодо збереження у належному стані будівель, у яких розміщуються об'єкти лінійно-геодезичного полігону, приміщень та інших об'єктів інженерно-технічної інфраструктури з метою створення стабільних умов для збереження державних еталонів.

9. Періодична метрологічна атестація державних еталонів та їх складових частин.

10. Повірка засобів вимірювальної техніки, що входить до складу державних еталонів.
