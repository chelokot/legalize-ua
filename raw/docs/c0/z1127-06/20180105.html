Про внесення змін до деяких наказів Держмитслужби України

{ Із змінами, внесеними згідно з Наказом Міністерства фінансів N 936 ( z1543-12 ) від 21.08.2012 }

Відповідно до частини другої пункту 6 статті 11 Митного кодексу України ( 92-15 ) й з метою впорядкування дій посадових осіб митних органів при здійсненні митного оформлення товарів, що перевозяться із застосуванням книжки міжнародного дорожнього перевезення, НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства фінансів N 936 ( z1543-12 ) від 21.08.2012 }

2. У Порядку реалізації положень Митної конвенції про міжнародне перевезення вантажів із застосуванням книжки МДП, затвердженому наказом Державної митної служби України від 21.11.2001 N 755 ( z1036-01 ) і зареєстрованому в Міністерстві юстиції України 14.12.2001 за N 1036/6227 (зі змінами):

пункт 3.4 викласти в такій редакції:

"3.4. Якщо при ввезенні в Україну з метою транзиту товару сума податків і зборів (обов'язкових платежів), що підлягає сплаті в разі його випуску у вільний обіг на митній території України, перевищує розмір гарантії (тобто суму, еквівалентну 50 000 доларів США в національній валюті України в перерахунку за курсом, установленим Національним банком України на день подання книжки МДП до оформлення), то операція МДП проводиться відповідно до норм статті 23 Конвенції МДП ( 995_012 ) і частини першої статті 165 Митного кодексу України ( 92-15 )";

абзац другий підпункту 4.6.2 вилучити;

у зв'язку з цим абзаци третій - двадцять четвертий вважати відповідно абзацами другим - двадцять третім.

3. Управлінню контролю за переміщенням вантажів (Луговець В.А.) і Юридичному департаменту (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Начальникам митних органів довести цей наказ до відома суб'єктів підприємницької діяльності.

5. Установити, що цей наказ набирає чинності через 10 днів після його офіційного опублікування.

Контроль за виконанням наказу залишаю за собою.

Т.в.о. Голови Держмитслужби України О.О.Федоров
