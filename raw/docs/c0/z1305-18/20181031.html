Зразки
спеціального одягу, взуття та спорядження військовослужбовців Служби зовнішньої розвідки України на мирний час та особливий період

I. Головні убори

1. Шапка польова демісезонна спеціальна

[ image ]


Шапка польова демісезонна спеціальна з трикотажного полотна сірого кольору. Підкладка з полотна типу «фліс». Шапка складається з головки та нижньої частини. Головка шапки має форму півсфери та складається з п’яти клинків. Нижня частина шапки складається з однієї деталі. Шапка має максимально пласкі шви.

2. Кепі тактичне спеціальне

[ image ]

Кепі тактичне спеціальне з бавовняної тканини сірого кольору. Головка виробу складається з шести клинків з обметаними вентиляційними отворами, текстильною застібкою для регулювання об’єму та начільника зсередини. Місце зшитих клинків оброблено текстильною застібкою. Козирок формостійкий.

На передній панелі - текстильна застібка для розміщення ідентифікаторів.

3. Балаклава тактична спеціальна

[ image ]

Балаклава з гладкофарбованого трикотажного бавовняного полотна сірого або чорного кольору.

Виріб складається з трьох деталей: задньої, передньої верхньої та передньої нижньої.

II. Одяг

1. Сорочка тактична спеціальна з довгими рукавами

Сорочка тактична спеціальна з довгими рукавами може бути двох видів:

[ image ]

з тканини сірого кольору з відкладним коміром на відрізній стійці (прямого силуету). Сорочка застібається на ґудзики. Пілки з двома нагрудними накладними кишенями з клапанами та прихованими кишенями, які застібаються на дві текстильні застібки. Накладні кишені - з двома застроченими складками. Рукави вшивні з хлястиками для їх фіксації під час закочування та манжетами. На лівому рукаві - кишеня для ручки;

[ image ]

з тканини сірого кольору з відкладним коміром на відрізній стійці та з пришивною нижньою манжетою, на якій два ряди застібок-ґудзиків для регулювання об’єму у поясі. Сорочка застібається на ґудзики. Пілки з двома нагрудними накладними кишенями з клапанами та прихованими кишенями, які застібаються на дві текстильні застібки. Накладні кишені - з двома застроченими складками. Рукави вшивні з хлястиками для їх фіксації під час закочування та манжетами. На лівому рукаві - кишеня для ручки.

2. Сорочка тактична спеціальна з короткими рукавами

Сорочка тактична спеціальна з короткими рукавами може бути двох видів:

[ image ]

з тканини сірого кольору з відкладним коміром на відрізній стійці (прямого силуету). Сорочка застібається на ґудзики. Пілки з двома нагрудними накладними кишенями з клапанами та прихованими кишенями, які застібаються на текстильні застібки. Накладні кишені - з двома застроченими складками. Рукави вшивні. На лівому рукаві - кишеня для ручки;

[ image ]

з тканини сірого кольору з відкладним коміром на відрізній стійці та пришивною нижньою манжетою, на якій два ряди застібок-ґудзиків для регулювання об’єму у поясі. Сорочка застібається на ґудзики. Пілки - з двома нагрудними накладними кишенями з клапанами та прихованими кишенями, які застібаються на текстильні застібки. Накладні кишені - з двома застроченими складками. Рукави вшивні. На лівому рукаві - кишеня для ручки.

3. Штани тактичні спеціальні

[ image ]

Штани тактичні спеціальні з тканини сірого кольору. Штани мають пришивний пояс, застібаються на кнопку, ґудзик та «блискавку» в середньому шві передніх половинок.

Передні половинки - з відрізними бочками, які утворюють бокові кишені. По бокових швах нашиті накладні кишені з клапанами, що застібаються на дві текстильні застібки. Передні половинки мають додатково дві прорізні кишені. Дві задні прорізні кишені з клапаном застібаються на дві текстильні застібки. Задня частина пояса стягується за допомогою еластичної стрічки. По верхньому краю штанів вшито сім хомутиків. Штани мають підсилювальні накладки на ділянці колін.

4. Сорочка тактична польова спеціальна

[ image ]

Сорочка тактична польова спеціальна з трикотажного синтетичного полотна сірого кольору.

На рукавах - кишені, що застібаються на «блискавки» та мають текстильні панелі для розміщення ідентифікаторів.

Сорочка має накладки на плечах, спині та верхній частині грудної клітки.

Сорочка тактична польова спеціальна має максимально пласкі шви.

5. Штани тактичні польові спеціальні

[ image ]

Штани тактичні польові спеціальні зі змішаної тканини сірого кольору. У поперековій частині розміщені вставки з еластичної тканини та потаємні врізні кишені.

Штани мають дві накладні задні кишені, дві внутрішні бокові кишені та дві накладні кишені по бокових швах, що застібаються на «блискавки».

6. Куртка-утеплювач зимова спеціальна

[ image ]

Куртка-утеплювач зимова спеціальна з матеріалу типу «фліс» сірого кольору (приталеного силуету) з центральною застібкою на «блискавку».

На пілках у верхній та нижній частинах розташовані чотири зовнішні прорізні кишені, що застібаються на «блискавку», додатково передбачені дві внутрішні кишені відкритого типу.

На плечах, рукавах та біля кишень - підсилювальні накладки. На правому рукаві - текстильна застібка для розміщення ідентифікаторів.

7. Куртка тактична спеціальна

[ image ]

Куртка тактична спеціальна з двошарового комбінованого синтетичного гладкофарбованого матеріалу сірого або чорного кольору.

Куртка тактична спеціальна має високий комір, центральну застібку на «блискавку», сітчасту підкладку та регулюється в нижній частині по об’єму.

Куртка тактична спеціальна має чотири зовнішні врізні кишені, що застібаються на «блискавки». Кишені розташовані симетрично на грудях та в нижній частині.

Рукави вшивні. На верхній частині лівого рукава - врізна кишеня, що застібається на «блискавку». Манжети рукавів мають текстильну застібку та вшиту резинку для регулювання об’єму.

На правій та лівій пілочках - потаємні текстильні застібки для розміщення ідентифікаторів.

Куртка має прямий силует. На спинці - текстильна застібка для розміщення ідентифікаторів, розташована по всій ширині спинки та прихована у врізній кишені, що застібається на «блискавку».

8. Куртка польова демісезонна спеціальна

[ image ]

Куртка польова демісезонна спеціальна з тришарового комбінованого синтетичного гладкофарбованого матеріалу сірого кольору приталеного силуету з центральною застібкою на «блискавку».

Куртка має високий комір та регулюється по об’єму в поперековій та нижній частинах.

На куртці симетрично розташовано шість зовнішніх врізних кишень - на грудях, нижній частині куртки та рукавах.

Рукави вшивні. У верхній частині рукавів - текстильні застібки для розміщення ідентифікаторів. Зовнішня частина рукавів довша за внутрішню, вони регулюються вшитою резинкою.

Куртка з капюшоном, який можна сховати в її комір. Комір застібається на чотири текстильні застібки.

9. Куртка польова зимова спеціальна

[ image ]

Куртка польова зимова спеціальна (прямого силуету) з тришарового комбінованого синтетичного гладкофарбованого матеріалу сірого кольору. Куртка з центральною внутрішньою застібкою на «блискавку», яка закривається клапаном, що має п’ять текстильних застібок.

Куртка доповнена шістьма зовнішніми об’ємними кишенями. Верхні прорізні кишені мають дві текстильні застібки, середні та нижні застібаються на «блискавки».

Спинка - пряма. Куртка має високий комір та капюшон, регулюється по об’єму.

Рукави вшивні. У ліктьовій частині - накладка з додаткового матеріалу з двома виточками для надання об’єму. У верхній частині рукавів - текстильні застібки для розміщення ідентифікаторів. Для зменшення об’єму по низу рукава використовується пата з текстильною застібкою.

10. Штани польові зимові спеціальні

[ image ]

Штани польові зимові спеціальні з тришарового комбінованого синтетичного гладкофарбованого матеріалу сірого кольору.

Штани мають дві об’ємні накладні кишені, які застібаються на «блискавку». У середині основних кишень розміщені додаткові кишені з поліамідної сітки. Основні кишені мають стоки для води. Штани застібаються на «блискавку» та текстильну застібку, мають широкий еластичний пояс, на якому розміщено п’ять хомутиків з додатковими текстильними застібками.

З двох сторін штанів - застібки на «блискавки» з захисним клапаном.

Нижня частина штанів має пату з текстильною застібкою для регулювання ширини.

Зона колін посилена додатковим шаром основного матеріалу.

Утеплювач штанів кріпиться за допомогою восьми ґудзиків на поясі. Передня та задня частини штанів з’єднуються між собою чотирма ґудзиками. Довжина утеплювача штанів досягає середини гомілки.

Штани комплектуються підтяжками.

III. Білизна

1. Футболка-поло тактична спеціальна з короткими рукавами

[ image ]

Футболка-поло тактична спеціальна з короткими рукавами з бавовняного трикотажного полотна сірого або бежевого кольору. Має відкладний комір, що застібається на три ґудзики.

На лівому рукаві розміщена врізна кишеня, що застібається на «блискавку».

2. Футболка польова спеціальна

[ image ]

Футболка польова спеціальна з гладкофарбованого трикотажного полотна сірого або чорного кольору. Низ виробу та рукави оброблені швом у підгин. Футболка польова спеціальна має максимально пласкі шви.

3. Термобілизна демісезонна спеціальна

[ image ]

Термобілизна демісезонна спеціальна складається з сорочки демісезонної спеціальної та кальсонів демісезонних спеціальних.

Сорочка демісезонна спеціальна за конструкцію є нижньою сорочкою (з довгим рукавом) з синтетичного трикотажного кулірного гладкофарбованого полотна сірого кольору. Сорочка складається з деталі переду, деталі спинки, двох рукавів із манжетами. Низ сорочки оброблений швом у підгин. Рукав вшивний одношовний довгий. Спинка суцільнокроєна подовжена зі зміщеною лінією плеча у бік пілочки. Сорочка має максимально пласкі шви.

Кальсони демісезонні спеціальні з синтетичного трикотажного кулірного гладкофарбованого полотна сірого кольору. Кальсони складаються з передніх та задніх половинок, ластовиці та вшитої еластичної тасьми. Пояс суцільнокроєний з обробленою тасьмою.

Кальсони мають максимально пласкі шви.

4. Шкарпетки тактичні

[ image ]

Шкарпетки тактичні чорного кольору виготовлені з синтетичного вологопоглинаючого волокна та повітропроникного матеріалу. Мають підсилювальні захисні вставки на п’ятках та носках.

5. Шкарпетки тактичні зимові

[ image ]

Шкарпетки тактичні зимові чорного кольору виготовлені з вовни та мають підсилювальні захисні вставки на п’ятках та носках.

IV. Взуття

1. Черевики літні спеціальні

[ image ]

Черевики літні спеціальні з натуральної шкіри (замші), матеріалу типу CORDURA сірого кольору та мембрани типу GORE-TEX.

Проміжна частина устілки черевиків із поліуретану, підкладка - з безшовного мембранного матеріалу GORE-TEX.

Черевики літні спеціальні мають нейлоновий стабілізатор, тришарові з’ємні устілки, як шнурівка використовуються закриті петлі-крючки.

2. Черевики спеціальні

[ image ]

Черевики спеціальні з натуральної шкіри (замші) сірого кольору та мембрани типу GORE-TEX.

Верх черевиків виготовлений із поєднанням мікрофібри та синтетичного матеріалу. Носок та п’ятка посилені додатковим шаром основного матеріалу.

Підошва черевиків спеціальних має стабілізатор та гнучкий сітчастий супінатор.

3. Черевики тактичні спеціальні

[ image ]

Черевики літні спеціальні з натуральної шкіри (замші), матеріалу типу CORDURA сірого кольору та мембрани типу GORE-TEX.

Проміжна частина устілки черевиків із поліуретану, підкладка - з безшовного мембранного матеріалу типу GORE-TEX.

Черевики мають нейлоновий стабілізатор, тришарові знімні устілки, як шнурівка використовуються закриті петлі-крючки. Висота взуття - 14,5 см.

V. Спорядження

1. Пояс тактичний спеціальний

[ image ]

Пояс тактичний спеціальний з високоякісного нейлону сірого кольору. Має алюмінієву пряжку, посилений фіксатор, кріплення для нашивки 2,54 х 2,54 см із зовнішнього боку.

2. Ремінь тактичний спеціальний

[ image ]

Ремінь тактичний спеціальний з нейлону твердого переплетіння сірого або чорного кольору. Має пряжку із парашутного сплаву з натяжним стержнем. Ширина ременя - 4,5 см.

3. Сумка тактична

[ image ]

Сумка тактична сірого кольору з:

центральним відділенням для розміщення магазинів;

додатковим відділенням для розміщення документів;

потаємним відділенням для носіння зброї.

Плечовий ремінь сумки тактичної регулюється за об’ємом та має додатковий ремінь для фіксації.

Розмір сумки тактичної: 18 х 24 х 7,5 см.

4. Рюкзак спеціальний

[ image ]

Рюкзак спеціальний зі зносостійкого вологостійкого нейлону сірого кольору. Основне відділення має дві сітчасті кишені та кишеню для ноутбука. Зверху розміщена кишеня, оброблена флісом.

Спинка з ущільнювачем і вентиляційною системою.

На рюкзаку передбачені текстильні застібки для розміщення ідентифікаторів та кріплення для спорядження. З обох боків - компресійні ремені для регулювання об’єму. Плечові лямки регулюються за об’ємом. Розмір рюкзака тактичного спеціального: 46 х 28 х 15 см. Об’єм: 21,20 л.

5. Рюкзак тактичний спеціальний

[ image ]

Рюкзак тактичний спеціальний зі зносостійкого вологостійкого нейлону сірого кольору. Спинка з ущільнювачем і вентиляційною системою. Рюкзак має текстильні застібки для розміщення ідентифікаторів.

З трьох боків нашиті кріплення для спорядження.

Головне відділення рюкзака має кишені з сітчастого матеріалу та металеві отвори для дренажу. Зверху - кишеня, оброблена флісом.

Плечові лямки регулюються за об’ємом.

Розмір рюкзака тактичного спеціального: 58 х 38 х 20 см. Об’єм: 47,5 л.
