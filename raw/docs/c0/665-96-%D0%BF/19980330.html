Кабінет Міністрів України; Постанова від 20.06.1996 № 665

Про призупинення видачі суб'єктам підприємницької діяльності спеціальних дозволів (ліцензій) на виготовлення горілки, горілчаних, лікерних і коньячних виробів

Стан: Втратив чинність

Ідентифікатор: 665-96-п

Текст документа від 30.03.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 червня 1996 р. N 665 Київ

Про призупинення видачі суб'єктам підприємницької діяльності спеціальних дозволів (ліцензій) на виготовлення горілки, горілчаних, лікерних і коньячних виробів

( Додатково див. Постанову ВР N 363/96-ВР від 12.09.96 )

( Із змінами, внесеними згідно з Постановою КМ N 385 ( 385-98-п ) від 30.03.98 )

З метою забезпечення збільшення надходжень коштів до державного бюджету, стабілізації роботи спеціалізованих лікеро-горілчаних і коньячних підприємств Кабінет Міністрів України постановляє:

Призупинити дію підпунктів 5 та 14 пункту 1 Положення про порядок видачі суб'єктам підприємницької діяльності спеціальних дозволів (ліцензій) на здійснення окремих видів діяльності, затвердженого постановою Кабінету Міністрів України від 17 травня 1994 р. N 316 ( 316-94-п ) (ЗП України, 1994 р., N 9, ст. 221; 1995 р., N 5, ст. 125), у частині видачі спеціальних дозволів (ліцензій) на виготовлення горілки, горілчаних, лікерних і коньячних виробів підприємствами усіх форм власності, за винятком державних спеціалізованих лікеро-горілчаних підприємств Комітету харчової промисловості України та коньячних підприємств Комітету з питань садівництва, виноградарства та виноробної промисловості України.

( Постанова із змінами, внесеними згідно з Постановою КМ N 385 ( 385-98-п ) від 30.03.98 )
