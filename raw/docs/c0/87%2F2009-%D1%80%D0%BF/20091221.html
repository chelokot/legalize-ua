{ Розпорядження втратило чинність на підставі Розпорядження Президента

N 268/2009-рп ( 268/2009-рп ) від 21.12.2009 }

Про відсторонення від посади голови районної державної адміністрації

Відповідно до частини третьої статті 147 Кримінально-процесуального кодексу України ( 1002-05 ) відсторонити ПАЛАМАРЧУКА Сергія Миколайовича від посади голови Котовської районної державної адміністрації Одеської області у зв'язку з притягненням його до кримінальної відповідальності.

Президент України В.ЮЩЕНКО

м. Київ, 27 травня 2009 року N 87/2009-рп
