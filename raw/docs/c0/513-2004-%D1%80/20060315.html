Кабінет Міністрів України; Розпорядження від 28.07.2004 № 513-р

Про затвердження рішення Комісії з приватизації ВАТ "Укртелеком" про умови приватизації ВАТ "Укртелеком"

Стан: Втратив чинність

Ідентифікатор: 513-2004-р

Текст документа від 15.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 липня 2004 р. N 513-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 292 ( 292-2006-п ) від 15.03.2006 }

Про затвердження рішення Комісії з приватизації ВАТ "Укртелеком" про умови приватизації ВАТ "Укртелеком"

1. Відповідно до статті 9 Закону України "Про особливості приватизації відкритого акціонерного товариства "Укртелеком" ( 1869-14 ) затвердити рішення Комісії з приватизації ВАТ "Укртелеком" від 14 липня 2004 р. N 32 (додається до оригіналу).

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 4 червня 2002 р. N 300 ( 300-2002-р ) "Про затвердження рішення Комісії з приватизації ВАТ "Укртелеком" про умови приватизації ВАТ "Укртелеком".

Прем'єр-міністр України В.ЯНУКОВИЧ
