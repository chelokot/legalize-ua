Стан: Чинний

Ідентифікатор: 348-2006-п

Текст документа від 11.10.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 березня 2006 р. N 348 Київ

Про затвердження Порядку використання у 2006 році субвенції з державного бюджету місцевим бюджетам на придбання вагонів для комунального електротранспорту (тролейбусів і трамваїв)

{ Із змінами, внесеними згідно з Постановою КМ N 1410 ( 1410-2006-п ) від 11.10.2006 }

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2006 році субвенції з державного бюджету ( 3235-15 ) місцевим бюджетам на придбання вагонів для комунального електротранспорту (тролейбусів і трамваїв), що додається.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 17 березня 2006 р. N 348

ПОРЯДОК використання у 2006 році субвенції з державного бюджету ( 3235-15 ) місцевим бюджетам на придбання вагонів для комунального електротранспорту (тролейбусів і трамваїв)

1. Цей Порядок визначає механізм використання у 2006 році коштів субвенції з державного бюджету ( 3235-15 ) місцевим бюджетам на придбання вагонів для комунального електротранспорту (тролейбусів і трамваїв) (далі - субвенція).

2. Субвенція спрямовується за розподілом згідно з додатком 7 до Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) на рахунки бюджету Автономної Республіки Крим, обласних бюджетів (за винятком Закарпатської області), бюджетів мм. Києва та Севастополя, відкриті в органах Державного казначейства.

Субвенція надається за умови попереднього виділення з місцевого бюджету та з інших джерел, не заборонених законодавством, такої ж частки коштів для придбання тролейбусів і трамваїв. { Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 1410 ( 1410-2006-п ) від 11.10.2006 }

3. Рада міністрів Автономної Республіки Крим і облдержадміністрації (за винятком Закарпатської) розподіляють субвенцію між бюджетами міст Автономної Республіки Крим і областей, в яких функціонує міський електротранспорт.

4. Граничний розмір бюджетних зобов'язань, узятих за загальним фондом державного бюджету ( 3235-15 ), не повинен перевищувати квартального обсягу бюджетних призначень.

Бюджетні зобов'язання за спеціальним фондом державного бюджету беруться лише після надходження відповідних коштів до спеціального фонду.

5. Придбання тролейбусів і трамваїв за рахунок субвенції здійснюється з урахуванням вимог Законів України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ) та "Про міський електричний транспорт" ( 1914-15 ), зокрема щодо підтримки вітчизняних виробників.

6. Складення та подання фінансової звітності про використання субвенції, а також контроль за її цільовим витрачанням здійснюються в установленому законодавством порядку.
