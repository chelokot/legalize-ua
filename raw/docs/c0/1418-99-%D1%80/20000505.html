Кабінет Міністрів України; Розпорядження від 16.12.1999 № 1418-р

Про дозвіл Держмитслужбі здійснити митне оформлення вантажів, що надходять на адресу АТ "НОРД" (м. Донецьк)

Стан: Втратив чинність

Ідентифікатор: 1418-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 грудня 1999 р. N 1418-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення вантажів, що надходять на адресу АТ "НОРД" (м. Донецьк) для власних виробничих потреб за контрактами згідно з додатком, без сплати митного збору за їх перебування під митним контролем та додаткового збору, встановленого постановою Кабінету Міністрів України від 19 травня 1999 р. N 840 ( 840-99-п ).
