Про розміщення Національної ради з питань телебачення і радіомовлення

Стан: Чинний

Текст документа від 31.01.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 липня 2005 р. N 253-р

Про розміщення Національної ради з питань телебачення і радіомовлення

{ Із змінами, внесеними згідно з Розпорядженням КМ N 29-р ( 29-2007-р ) від 31.01.2007 }

{ На часткову заміну пунктів 1 і 2 прийняти пропозицію Держкомтелерадіо щодо передачі приміщень першого - п'ятого поверхів будинку по вул. Прорізній, 2, у м. Києві Національній раді з питань телебачення і радіомовлення із закріпленням їх на праві оперативного управління за Національною радою згідно з Розпорядженням КМ N 29-р ( 29-2007-р ) від 31.01.2007 }

1. Передати в оперативне управління Національної ради з питань телебачення і радіомовлення будинок по вул. Прорізній, 2, у м. Києві.

Держкомтелерадіо здійснити у тижневий строк передачу в установленому порядку зазначеного будинку Національній раді з питань телебачення і радіомовлення.

2. Взяти до відома, що Національна рада з питань телебачення і радіомовлення укладе договір оренди приміщень з Держкомтелерадіо та Комітетом з Національної премії України імені Тараса Шевченка на умовах оплати фактичних витрат, пов'язаних з їх утриманням.

3. Мінтрансзв'язку забезпечити Національну раду з питань телебачення і радіомовлення телефонним зв'язком.

4. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 8 лютого 1995 р. N 67 ( 67-95-р ), від 27 березня 2003 р. N 173 ( 173-2003-р ) і від 20 квітня 2005 р. N 107 ( 107-2005-р ).
