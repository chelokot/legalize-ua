Про звільнення Круглика С.В. з посади керівника торговельно-економічної місії у складі Посольства України у Французькій Республіці

Стан: Чинний

Текст документа від 18.05.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 березня 2004 р. N 354 Київ

Про звільнення Круглика С.В. з посади керівника торговельно-економічної місії у складі Посольства України у Французькій Республіці

( Із змінами, внесеними згідно з Постановою КМ N 647 ( 647-2004-п ) від 18.05.2004 )

Кабінет Міністрів України постановляє:

Звільнити Круглика Сергія Вікторовича з посади керівника торговельно-економічної місії у складі Посольства України у Французькій Республіці у зв'язку із закінченням довготермінового відрядження.

Ця постанова набирає чинності з 15 липня 2004 року.

( Постанову доповнено абзацом згідно з Постановою КМ N 647 ( 647-2004-п ) від 18.05.2004 )
