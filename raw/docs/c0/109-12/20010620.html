Текст документа від 20.06.2001:

ПОСТАНОВА ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

( Постанова втратила чинність на підставі Закону N 2419-III ( 2419-14 ) від 17.05.2001, ВВР, 2001, N 31, ст.149 )

Про затвердження форми нагородного листа для представлення до нагородження державними нагородами Української РСР

( Відомості Верховної Ради (ВВР), 1990, N 33, ст.489 )

Президія Верховної Ради Української РСР постановляє:

1. Затвердити форму нагородного листа для представлення до нагородження державними нагородами Української РСР (додається).

2. Визнати такою, що втратила чинність, постанову Президії Верховної Ради УРСР від 20 квітня 1989 року "Про затвердження форми нагородного листа для представлення до нагородження державними нагородами Української РСР" ( 7390-11 ).
