Верховна Рада України; Закон від 05.06.2003 № 921-IV

Про внесення змін до Закону України "Про перелік об'єктів права державної власності, що не підлягають приватизації"

Стан: Втратив чинність

Ідентифікатор: 921-15

Текст документа від 05.06.2003:

ЗАКОН УКРАЇНИ

Про внесення змін до Закону України "Про перелік об'єктів права державної власності, що не підлягають приватизації"

( Відомості Верховної Ради України (ВВР), 2003, N 39, ст.337 )

Верховна Рада України постановляє:

1. Внести зміни до переліку об'єктів права державної власності, що не підлягають приватизації, затвердженого Законом України "Про перелік об'єктів права державної власності, що не підлягають приватизації" ( 847-14 ) (Відомості Верховної Ради України, 1999 р., N 37, ст. 332; 2001 р., N 48, ст. 255; 2002 р., N 11, ст. 82, N 14, ст. 94, N 29, ст. 196, ст. 197), згідно з додатком.

2. Цей Закон набирає чинності з дня його опублікування.
