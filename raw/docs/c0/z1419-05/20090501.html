МІНІСТЕРСТВО ТРАНСПОРТУ ТА ЗВ'ЯЗКУ УКРАЇНИ

НАКАЗ

14.11.2005 N 770

Зареєстровано в Міністерстві юстиції України 24 листопада 2005 р. за N 1419/11699

{ Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 317 ( z0340-09 ) від 26.03.2009 }

Про внесення змін до наказу Міністерства транспорту України від 02.02.99 N 53 та визнання такими, що втратили чинність, деяких наказів Міністерства транспорту України

Відповідно до постанови Кабінету Міністрів України від 25 грудня 1996 року N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" та розпорядження Кабінету Міністрів України від 8 жовтня 2004 року N 706-р ( 706-2004-р ) "Про заходи щодо підвищення ефективності використання залізничних вантажних вагонів" НАКАЗУЮ:

1. Унести такі зміни до наказу Міністерства транспорту України від 02.02.99 N 53 ( z0103-99 ) "Про затвердження ставок плати за користування вагонами і контейнерами залізниць", зареєстрованого в Міністерстві юстиції України 18.02.99 за N 103/3396:

у назві наказу слова "вагонами і" виключити;

у преамбулі слова "вантажних вагонів та" виключити;

в абзацах першому та другому пункту 1 слова "вантажними вагонами і" виключити;

пункт 2 виключити;

у зв'язку з цим пункти 3, 4, 5 наказу вважати пунктами 2, 3, 4 відповідно.

У Ставках плати за користування вагонами і контейнерами залізниць:

у назві слова "вагонами і" виключити;

таблицю 1 та пояснення до неї виключити;

у таблиці 2 слово і цифру "Таблиця 2" та слова "Ставки плати за користування контейнерами" виключити.

2. Визнати такими, що втратили чинність, накази Міністерства транспорту України:

від 10.06.99 N 302 ( z0411-99 ) "Про внесення доповнення до таблиці 1 Ставок плати за користування вантажними вагонами залізниць", зареєстрований в Міністерстві юстиції України 24.06.99 за N 411/3704;

від 03.12.99 N 582 ( z0875-99 ) "Про застосування Ставок плати за користування вантажними вагонами залізниць", зареєстрований в Міністерстві юстиції України 16.12.99 за N 875/4168;

від 31.12.99 N 641 ( z0032-00 ) "Про внесення доповнення до наказу Мінтрансу України від 02.02.99 N 53", зареєстрований в Міністерстві юстиції України 21.01.2000 за N 32/4253;

від 26.06.2002 N 425 ( z0554-02 ) "Про затвердження тарифів на перевезення експортно-імпортних вантажів у великотоннажних контейнерах контейнерними поїздами у сполученні Балтійське море - Чорне море", зареєстрований в Міністерстві юстиції України 03.07.2002 за N 554/6842.

3. Державній адміністрації залізничного транспорту України (Афтаназів З.С.) подати цей наказ у встановленому порядку до Міністерства юстиції України для державної реєстрації.

4. Контроль за виконанням цього наказу покласти на заступника Міністра - генерального директора Укрзалізниці Афтаназіва З.С.

Міністр В.Бондар
