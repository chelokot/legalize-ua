Стан: Втратив чинність

Ідентифікатор: z0643-02

Текст документа від 07.03.2003:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 283 від 02.08.2002 Зареєстровано в Міністерстві юстиції України 9 серпня 2002 р. N 643/6931

Про затвердження Тимчасового положення про порядок кредитування (рефінансування) Національним банком України банків, які здійснюють довгострокове кредитування

( Із змінами, внесеними згідно з Постановою Національного банку

N 51 ( z0150-03 ) від 12.02.2003 )

Відповідно до Законів України "Про Національний банк України" ( 679-14 ), "Про банки і банківську діяльність" ( 2121-14 ), "Про заставу" ( 2654-12 ) та з метою реалізації заходів в сфері грошового обігу, направлених на економічне зростання та забезпечення банків довгостроковими кредитними ресурсами, Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити Тимчасове положення про порядок кредитування (рефінансування) Національним банком України банків, які здійснюють довгострокове кредитування (далі - Тимчасове положення), що додається.

2. Департаментам бухгалтерського обліку (В.І.Ричаківська), інформатизації (А.С.Савченко), економічного (В.І.Галь) забезпечити організацію складання та подання звітності за кредитами, які надаватимуться відповідно до Тимчасового положення.

3. Департаменту монетарної політики (Н.І. Гребеник) після державної реєстрації цього Тимчасового положення довести його зміст до відома територіальних управлінь Національного банку України та банків для використання в роботі.

4. Постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

5. Контроль за виконанням цієї постанови покласти на першого заступника Голови А.В. Шаповалова.

Голова В.С. Стельмах

( Тимчасове положення про порядок кредитування (рефінансування) Національним банком України банків, які здійснюють довгострокове кредитування втратило чинність на підставі Постанови Національного банку N 51 ( z0150-03 ) від 12.02.2003 )
