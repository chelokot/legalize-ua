N 688 від 15.04.99 Зареєстровано в Міністерстві м.Київ юстиції України 29 квітня 1999 р. vd990415 vn688 за N 273/3566

( Наказ втратив чинність на підставі Наказу Фонду державного майна N 1851 ( z0880-02 ) від 22.10.2002 )

Щодо дії Положення про приватизацію майна об'єктів соціальної сфери

У зв'язку із введенням у дію Державної програми приватизації на 1999 рік ( 209/99 ) НАКАЗУЮ:

1. Поширити дію Положення про приватизацію майна об'єктів соціальної сфери, віднесених Державною програмою приватизації на 1998 рік до групи Ж, затвердженого наказом ФДМУ від 06.05.98 N 888 ( z0366-98 ) та зареєстрованого Міністерством юстиції України 4 червня 1998 р. за N 366/2806, на об'єкти приватизації, які віднесені Державною програмою приватизації на 1999 рік до об'єктів групи Ж.

2. Департаменту індивідуального продажу здійснити державну реєстрацію наказу в Міністерстві юстиції України.

3. Відповідальність за виконання цього наказу покласти на начальників регіональних відділень ФДМУ та Голову Фонду майна Автономної Республіки Крим.

4. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Л.Кальніченка.
