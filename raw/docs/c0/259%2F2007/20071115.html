Президент України; Указ від 30.03.2007 № 259/2007

Про заміщення посади головного консультанта Секретаріату Президента України військовослужбовцем

Стан: Втратив чинність

Ідентифікатор: 259/2007

Текст документа від 15.11.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1020/2007 ( 1020/2007 ) від 25.10.2007 }

Про заміщення посади головного консультанта Секретаріату Президента України військовослужбовцем

Установити, що одна посада головного консультанта Служби забезпечення зв'язків з Верховною Радою України та Кабінетом Міністрів України Секретаріату Президента України може бути заміщена військовослужбовцем Служби безпеки України з граничним військовим званням полковника.

Президент України В.ЮЩЕНКО

м. Київ, 30 березня 2007 року N 259/2007
