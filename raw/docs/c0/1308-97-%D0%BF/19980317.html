Текст документа від 17.03.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 листопада 1997 р. N 1308 Київ

Про Міжвідомчу координаційну раду з підготовки другого проекту розвитку підприємств

( Із змінами, внесеними згідно з Постановою КМ N 318 ( 318-98-п ) від 17.03.98 )

З метою забезпечення координації та здійснення контролю за ходом підготовки другого проекту розвитку підприємств, що підтримується Міжнародним банком реконструкції та розвитку, Кабінет Міністрів України постановляє:

1. Утворити Міжвідомчу координаційну раду з підготовки другого проекту розвитку підприємств у складі згідно з додатком.

2. Установити, що Міжвідомча координаційна рада проводить засідання відповідно до регламенту, затвердженого її головою.

3. Визначити відповідальними:

а) за підготовку другого проекту розвитку підприємств в цілому - Міністерство економіки;

б) за підготовку складових проекту:

Міністерство фінансів - реформування системи бухгалтерського обліку на підприємствах;

Фонд державного майна - проведення приватизації підприємств та об'єктів незавершеного будівництва;

Державну комісію з цінних паперів та фондового ринку - реформування фондового ринку;

Агентство з питань запобігання банкрутству підприємств та організацій - реформування системи банкрутства;

Державний комітет з питань розвитку підприємництва - дерегулювання підприємницької діяльності. ( Підпункт "б" пункту 3 дооповнений абзацом шостим згідно з Постановою КМ N 318 ( 318-98-п ) від 17.03.98 )
