Президент України; Указ від 31.07.1998 № 831/98

Про внесення зміни до Указу Президента України від 8 лютого 1997 року N 129

Стан: Втратив чинність

Ідентифікатор: 831/98

Текст документа від 21.02.2001:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 107/2001 ( 107/2001 ) від 21.02.2001 )

Про внесення зміни до Указу Президента України від 8 лютого 1997 року N 129

Внести зміну до розділу "Міністерство України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" Переліку посад в органах виконавчої влади та інших цивільних установах, які можуть бути заміщені особами вищого офіцерського складу Збройних Сил України, Служби безпеки України, інших військових формувань, та граничних військових звань за цими посадами, затвердженого Указом Президента України від 8 лютого 1997 року N 129 ( 129/97 ) (із змінами, внесеними Указом Президента України від 27 листопада 1997 року N 1313 ( 1313/97 ), замінивши в абзаці другому слово "одна" словом "три".

Президент України Л.КУЧМА
