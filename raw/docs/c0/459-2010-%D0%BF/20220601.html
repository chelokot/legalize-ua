КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 червня 2010 р. N 459 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 577 ( 577-2022-п ) від 10.05.2022 }

Про внесення змін до постанови Кабінету Міністрів України від 6 листопада 1997 р. N 1238

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 6 листопада 1997 р. N 1238 ( 1238-97-п ) "Про обов'язковий профілактичний наркологічний огляд і порядок його проведення" (Офіційний вісник України, 1997 р., число 46, с. 53; 1998 р., N 34, ст. 1277, N 38, ст. 1395; 2006 р., N 22, ст. 1609, N 48, ст. 3200; 2007 р., N 47, ст. 1933) такі зміни:

пункт 17 переліку професій та видів діяльності, для яких є обов'язковим первинний і періодичний профілактичний наркологічний огляд, затвердженого зазначеною постановою ( 1238-97-п ), після слова "СБУ," доповнити словами "Державну прикордонну службу,";

абзац перший пункту 2 Порядку проведення обов'язкового профілактичного наркологічного огляду громадян, затвердженого зазначеною постановою ( 1238-97-п ), після слів "Служби зовнішньої розвідки" доповнити словами "та особового складу Державної прикордонної служби".

Прем'єр-міністр України М.АЗАРОВ
