Кабінет Міністрів України; Розпорядження від 15.03.2006 № 137-р

Про виділення коштів для проведення першочергових робіт з ліквідації наслідків розливу ртуті у приміщенні Національної ради з питань телебачення і радіомовлення

Стан: Чинний

Ідентифікатор: 137-2006-р

Текст документа від 17.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 15 березня 2006 р. N 137-р Київ

Про виділення коштів для проведення першочергових робіт з ліквідації наслідків розливу ртуті у приміщенні Національної ради з питань телебачення і радіомовлення

{ Із змінами, внесеними згідно з Розпорядженням КМ N 280-р ( 280-2006-р ) від 17.05.2006 }

1. Виділити Національній раді з питань телебачення і радіомовлення 202,242 тис. гривень для проведення першочергових робіт з ліквідації наслідків розливу ртуті, що стався 15 лютого 2006 р. у приміщенні по вул. Прорізній, 2, у м. Києві.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 280-р ( 280-2006-р ) від 17.05.2006 }

2. Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 3235-15 ).

{ Пункт 3 виключено на підставі Розпорядження КМ N 280-р ( 280-2006-р ) від 17.05.2006 }

4. Національній раді з питань телебачення і радіомовлення подати до кінця березня 2006 р. Мінекономіки, Мінфіну і Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України Ю.ЄХАНУРОВ
