Кабінет Міністрів України; Постанова від 17.02.2010 № 210

Про фінансування видатків на проведення ремонту військової техніки (вертольотів) за державним оборонним замовленням у національних виробників та на оплату вартості її транспортування

Стан: Чинний

Ідентифікатор: 210-2010-п

Текст документа від 29.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 лютого 2010 р. N 210 Київ

Про фінансування видатків на проведення ремонту військової техніки (вертольотів) за державним оборонним замовленням у національних виробників та на оплату вартості її транспортування

{ Із змінами, внесеними згідно з Постановами КМ N 307 ( 307-2010-п ) від 14.04.2010 N 612 ( 612-2010-п ) від 21.07.2010 }

Кабінет Міністрів України постановляє:

1. Виділити Міністерству оборони у II кварталі 2010 р. на безповоротній основі 43215,5 тис. гривень відповідно до пункту 2 частини першої статті 74 Закону України "Про Державний бюджет України на 2010 рік" ( 2154-17 ) за рахунок коштів, одержаних від приватизації державного майна, а в разі їх недостатності - за рахунок коштів від продажу земельних ділянок несільськогосподарського призначення або прав на них, а також надходжень від цільового розміщення державних цінних паперів, для погашення кредиторської заборгованості з оплати послуг з ремонту військової техніки (вертольотів), що виникла у 2009 році за бюджетною програмою "Створення, закупівля і модернізація озброєння та військової техніки за державним оборонним замовленням Міністерства оборони.

{ Пункт 1 в редакції Постанови КМ N 307 ( 307-2010-п ) від 14.04.2010; із змінами, внесеними згідно з Постановою КМ N 612 ( 612-2010-п ) від 21.07.2010 }

2. Дозволити Міністерству оборони укласти у 2010 році договори про транспортування військової техніки (вертольотів) до місця дислокації українського миротворчого контингенту, в яких передбачати внесення попередньої оплати в розмірі 100 відсотків їх вартості.

3. Міністерству фінансів внести в установленому порядку зміни до розпису (тимчасового розпису) Державного бюджету України.

{ Пункт 3 із змінами, внесеними згідно з Постановами КМ N 307 ( 307-2010-п ) від 14.04.2010, N 612 ( 612-2010-п ) від 21.07.2010 }

4. Міністерству оборони погодити розподіл коштів Стабілізаційного фонду з Комітетами Верховної Ради України з питань бюджету та з питань фінансів і банківської діяльності.

5. Установити, що:

операції, пов'язані з використанням коштів Стабілізаційного фонду, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством;

після закінчення бюджетного року залишки бюджетних коштів станом на 1 січня 2011 р. обов'язково повертаються до Стабілізаційного фонду.

6. Міністерству оборони подати до кінця грудня 2010 р. Міністерству економіки, Міністерству фінансів та Державному казначейству звіт про використання коштів, виділених відповідно до цієї постанови.
