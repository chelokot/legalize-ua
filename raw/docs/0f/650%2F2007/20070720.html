Президент України; Указ від 20.07.2007 № 650/2007

Про визнання такими, що втратили чинність, деяких указів Президента України

Стан: Чинний

Ідентифікатор: 650/2007

Текст документа від 20.07.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання такими, що втратили чинність, деяких указів Президента України

1. Визнати такими, що втратили чинність:

Указ Президента України від 10 листопада 1994 року N 666 ( 666/94 ) "Про невідкладні заходи щодо прискорення земельної реформи у сфері сільськогосподарського виробництва", крім статті 3;

Указ Президента України від 12 липня 1995 року N 608 ( 608/95 ) "Про приватизацію та оренду земельних ділянок несільськогосподарського призначення для здійснення підприємницької діяльності";

Указ Президента України від 21 квітня 1998 року N 332 ( 332/98 ) "Про захист прав власників земельних часток (паїв)";

Указ Президента України від 19 січня 1999 року N 32 ( 32/99 ) "Про продаж земельних ділянок несільськогосподарського призначення";

Указ Президента України від 28 червня 1999 року N 765 ( 765/99 ) "Про додаткові заходи щодо задоволення потреб громадян у земельних ділянках";

Указ Президента України від 4 лютого 2000 року N 168 ( 168/2000 ) "Про заходи щодо розвитку та регулювання ринку земель населених пунктів, інших земель несільськогосподарського призначення";

статтю 5 Указу Президента України від 9 березня 2000 року N 399 ( 399/2000 ) "Про внесення змін до деяких указів Президента України";

Указ Президента України від 12 квітня 2000 року N 584 ( 584/2000 ) "Про забезпечення економічних інтересів і соціального захисту працівників соціальної сфери села та вирішення окремих питань, що виникли в процесі проведення земельної реформи".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
