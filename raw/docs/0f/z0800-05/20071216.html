{ Наказ втратив чинність на підставі Наказу Міністерства оборони N 648 ( z1345-07 ) від 20.11.2007 }

Про внесення доповнення до наказу Міністра оборони України від 03.09.2001 N 309

У зв'язку з реформуванням та змінами в організаційно-штатній структурі органів військового управління, об'єднань, з'єднань, військових частин Збройних Сил України НАКАЗУЮ:

1. Затвердити Доповнення до Переліку посад військовослужбовців органів військового управління, об'єднань, з'єднань, військових частин, військових навчальних закладів Збройних Сил України, військова служба яких пов'язана зі стрибками з парашутом ( z0825-01 ), затвердженого наказом Міністра оборони України від 3 вересня 2001 року N 309 ( z0824-01 ) "Про визначення умов зарахування вислуги років для призначення пенсії військовослужбовцям, військова служба яких пов'язана зі стрибками з парашутом" (зі змінами та доповненнями), зареєстрованого у Міністерстві юстиції України 18 вересня 2001 року за N 824/6015, що додається.

2. Наказ розіслати згідно з розрахунком розсилки.

Тимчасово виконуючий обов'язки Міністра оборони України Л.І.Поляков
