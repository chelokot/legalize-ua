КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 квітня 2003 р. N 587 Київ

Про внесення змін до постанови Кабінету Міністрів України від 12 січня 2001 р. N 15

( Із змінами, внесеними згідно з Постановами КМ N 1402 ( 1402-2003-п ) від 04.09.2003 N 579 ( 579-2005-п ) від 13.07.2005 Розпорядженням КМ N 473-р ( 473-2005-р ) від 22.11.2005 )

Кабінет Міністрів України постановляє:

1. Затвердити новий склад Міжвідомчої ради з питань вивезення, ввезення та повернення культурних цінностей (додається).

Дозволити голові ради вносити у разі потреби зміни до її складу. ( Пункт 1 доповнено абзацом згідно з Постановою КМ N 579 ( 579-2005-п ) від 13.07.2005 )

Визнати таким, що втратив чинність, абзац другий пункту 1 постанови Кабінету Міністрів України від 12 січня 2001 р. N 15 ( 15-2001-п ) "Про утворення Міжвідомчої ради з питань вивезення, ввезення та повернення культурних цінностей" (Офіційний вісник України, 2001 р., N 3, ст. 69).

2. Внести до Положення про Міжвідомчу раду з питань вивезення, ввезення та повернення культурних цінностей, затвердженого зазначеною постановою ( 15-2001-п ), такі зміни:

абзац третій пунктів 4 і 7 після слів "тимчасові робочі групи" доповнити словами "експертні групи";

пункт 6 викласти у такій редакції:

"6. Раду очолює Віце-прем'єр-міністр України".

Прем'єр-міністр України В.ЯНУКОВИЧ
