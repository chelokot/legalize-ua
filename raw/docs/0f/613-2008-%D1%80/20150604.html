Деякі питання розпорядження земельними ділянками, що вивільняються у процесі реформування Збройних Сил

Стан: Чинний

Ідентифікатор: 613-2008-р

Текст документа від 04.06.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 квітня 2008 р. N 613-р Київ

Деякі питання розпорядження земельними ділянками, що вивільняються у процесі реформування Збройних Сил

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 627-р ( 627-2009-р ) від 10.06.2009 N 765-р ( 765-2012-р ) від 10.10.2012 N 567-р ( 567-2015-р ) від 04.06.2015 }

1. Міністерству оборони завершити протягом 2012-2017 років за погодженням з органами місцевого самоврядування передачу об'єктів житлового фонду, соціально-культурної сфери та об'єктів їх інженерної інфраструктури, розташованих на земельних ділянках, площі та межі яких визначені згідно з проектом розподілу території.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженнями КМ N 627-р ( 627-2009-р ) від 10.06.2009, N 765-р ( 765-2012-р ) від 10.10.2012, N 567-р ( 567-2015-р ) від 04.06.2015 }

{ Пункт 2 виключено на підставі Розпорядження КМ N 567-р ( 567-2015-р ) від 04.06.2015 }

3. Міністерству оборони та Державній службі з питань геодезії, картографії та кадастру забезпечити розроблення землевпорядної документації на земельні ділянки, що вивільняються у процесі реформування Збройних Сил, і провести державну реєстрацію таких земельних ділянок.
