КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 вересня 2003 р. N 1457 Київ

Про затвердження Порядку реєстрації зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою

( Із змінами, внесеними згідно з Постановою КМ N 1782 ( 1782-2003-п ) від 20.11.2003 )

( У назві і тексті постанови та Порядку слова "та нафтопродукти" в усіх відмінках виключено згідно з Постановою КМ N 1782 ( 1782-2003-п ) від 20.11.2003 )

Кабінет Міністрів України постановляє:

1. Затвердити Порядок реєстрації зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою за кодом згідно з УКТЗЕД 2709009000 ( 2371а-14 ) (додається).

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1782 ( 1782-2003-п ) від 20.11.2003 )

2. Міністерству палива та енергетики за погодженням з Міністерством економіки та з питань європейської інтеграції розробити Порядок погодження зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою.

3. Міністерству палива та енергетики запровадити складання поточних та прогнозних щомісячних балансів нафти.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 16 вересня 2003 р. N 1457

ПОРЯДОК реєстрації зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою

1. Цей Порядок визначає процедуру реєстрації зовнішньоекономічних контрактів (договорів) на здійснення експортних операцій з нафтою за кодом згідно з УКТЗЕД 2709009000 ( 2371а-14 ).

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1782 ( 1782-2003-п ) від 20.11.2003 )

2. Для реєстрації зовнішньоекономічного контракту (договору) на здійснення експертних операцій з нафтою (далі - зовнішньоекономічний контракт) суб'єкт зовнішньоекономічної діяльності подає Мінекономіки такі документи:

супровідний лист;

інформаційну картку зовнішньоекономічного контракту за формою, встановленою Мінекономіки;

оригінал зовнішньоекономічного контракту з усіма діючими на дату подання додатками, специфікаціями, додатковими угодами та іншими документами, які є невід'ємними частинами контракту, та його завірену копію;

копію свідоцтва про державну реєстрацію суб'єкта підприємницької діяльності;

копію витягу з торговельного, банківського або судового реєстру про реєстрацію іноземного суб'єкта господарської діяльності або копію його реєстраційного посвідчення, виданого компетентним органом іноземної держави;

лист-погодження зовнішньоекономічного контракту Мінпаливенерго;

документ, що підтверджує оплату послуг з реєстрації зовнішньоекономічного контракту.

Відповідальність за достовірність відомостей, що містяться у поданих для реєстрації документах, несе суб'єкт зовнішньоекономічної діяльності.

3. Мінпаливенерго протягом трьох робочих днів після звернення суб'єкта зовнішньоекономічної діяльності погоджує зовнішньоекономічний контракт.

4. Мінекономіки протягом трьох робочих днів після подання документів, передбачених пунктом 2 цього Порядку, реєструє та оформлює їх і видає картку реєстрації-обліку зовнішньоекономічного контракту, складену за формою, встановленою Мінекономіки, яка є документом, що підтверджує реєстрацію зовнішньоекономічного контракту.

Датою подання документів на реєстрацію зовнішньоекономічного контракту є день реєстрації заяви (супровідного листа) в журналі встановленого зразка, який веде Мінекономіки, за умови подання документів, зазначених у пункті 2 цього Порядку.

5. Відомості, що містяться у документах, поданих для реєстрації зовнішньоекономічного контракту, не підлягають розголошенню. Розголошення таких відомостей тягне за собою відповідальність згідно із законодавством.

6. У реєстрації зовнішньоекономічного контракту може бути відмовлено у разі:

подання не всіх документів, передбачених пунктом 2 цього Порядку;

невідповідності умов зовнішньоекономічного контракту законодавству у сфері зовнішньоекономічної діяльності;

застосування до суб'єкта зовнішньоекономічної діяльності або до його іноземного контрагента спеціальних санкцій, передбачених статтею 37 Закону України "Про зовнішньоекономічну діяльність" ( 959-12 ), що діють на момент звернення суб'єкта зовнішньоекономічної діяльності про реєстрацію зовнішньоекономічного контракту;

порушення суб'єктом зовнішньоекономічної діяльності або його іноземним контрагентом законодавства у сфері зовнішньоекономічної діяльності.

7. У разі відмови в реєстрації зовнішньоекономічного контракту Мінекономіки надсилає заявнику протягом трьох днів після прийняття такого рішення повідомлення з обгрунтуванням причин відмови.

Заявник має право доопрацювати документи згідно з вимогами цього Порядку. У такому разі строк розгляду продовжується до внесення заявником доопрацьованих документів.

8. Картка реєстрації-обліку зовнішньоекономічного контракту та оригінал зовнішньоекономічного контракту видаються заявникові або уповноваженій ним особі.

9. Строк дії картки реєстрації-обліку зовнішньоекономічного контракту - один рік з дати її оформлення.

Мінекономіки за бажанням суб'єкта зовнішньоекономічної діяльності може скоротити строк дії картки реєстрації-обліку зовнішньоекономічного контракту, про що в ній робиться відповідний запис.

У разі втрати картки-обліку зовнішньоекономічного контракту її дублікат не видається.

10. У разі зміни умов зовнішньоекономічного контракту він підлягає перереєстрації згідно з цим Порядком. При цьому суб'єкт зовнішньоекономічної діяльності подає оригінал картки реєстрації-обліку зовнішньоекономічного контракту з позначками митниць про фактичне відвантаження нафти відповідно до умов, зазначених у картці.
