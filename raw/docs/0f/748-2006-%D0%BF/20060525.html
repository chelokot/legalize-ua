Стан: Втратив чинність

Ідентифікатор: 748-2006-п

Текст документа від 25.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 травня 2006 р. N 748 Київ

Про внесення змін та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України щодо ліцензування професійної діяльності на ринку цінних паперів

Кабінет Міністрів України постановляє:

1. Пункт 16 переліку органів ліцензування, затвердженого постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001), виключити.

2. Пункт 33 переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності, затвердженого постановою Кабінету Міністрів України від 4 липня 2001 р. N 756 ( 756-2001-п ) (Офіційний вісник України, 2001 р., N 27, ст. 1212; 2004 р., N 10, ст. 611), виключити.

3. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 17 травня 2002 р. N 645 ( 645-2002-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 4 липня 2001 р. N 756" (Офіційний вісник України, 2002 р., N 21, ст. 1023);

постанову Кабінету Міністрів України від 11 березня 2004 р. N 307 ( 307-2004-п ) "Про внесення зміни до пункту 33 переліку документів, які додаються до заяви про видачу ліцензії для окремого виду господарської діяльності" (Офіційний вісник України, 2004 р., N 10, ст. 611).
