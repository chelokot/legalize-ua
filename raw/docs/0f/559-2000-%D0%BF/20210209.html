ПОСТАНОВА від 27 березня 2000 р. N 559 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 81 ( 81-2021-п ) від 03.02.2021 }

Про склад Координаційної ради з питань врегулювання кризових ситуацій у вугільній промисловості

{ Щодо змін додатково див. Постанову КМ N 579 ( 579-2005-п ) від 13.07.2005 }

Кабінет Міністрів України постановляє:

1. Затвердити новий склад Координаційної ради з питань врегулювання кризових ситуацій у вугільній промисловості при Кабінеті Міністрів України, утвореної постановою Кабінету Міністрів України від 1 березня 1999 р. N 281 ( 281-99-п ), що додається.

Надати право голові зазначеної Координаційної ради вносити зміни до її складу.

2. Визнати такими, що втратили чинність, абзац сімнадцятий постанови Кабінету Міністрів України від 17 серпня 1999 р. N 1506 ( 1506-99-п ) та постанову Кабінету Міністрів України від 29 жовтня 1999 р. N 2022 ( 2022-99-п ).
