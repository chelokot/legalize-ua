Кашкет для осіб вищого складу поліції

[ image ]

Кашкет для генералів поліції першого рангу складається з денця овальної форми, стінок, околиша та канта з напіввовняної тканини темно-синього кольору, козирка, філігранного ремінця, який прикріплюється двома форменими ґудзиками сріблястого кольору.

Філігранний ремінець з плетеного шнура сріблястого кольору, з’єднаний у кільце та складений удвоє, з петлями на кінцях для кріплення до кашкета.

На стінках кашкета оброблено по два вентиляційних отвори з обох боків.

По околишу вишито листки дуба сріблястого кольору по чотири в обидва боки від кокарди, розташовані між кокардою та ґудзиками.

Козирок обтягнуто лаковою шкірою чорного кольору з гаптуванням сріблястого кольору у вигляді листків калини і дуба та шнура по краю козирка.

По центру околиша - металева кокарда сріблястого кольору.

Кашкет

[ image ]

Кашкет складається з денця овальної форми, стінок, околиша та канта з напіввовняної тканини темно-синього кольору, козирка, філігранного ремінця, який прикріплюється двома форменими ґудзиками сріблястого кольору.

Філігранний ремінець з плетеного шнура сріблястого кольору, з’єднаний у кільце та складений удвоє, з петлями на кінцях для кріплення до кашкета.

На стінках кашкета оброблено по два вентиляційних отвори з обох боків.

Кепі для осіб вищого складу поліції

[ image ]

Кепі для осіб вищого складу поліції із змішаної або синтетичної тканини темно-синього кольору, кольору хакі або в колористиці “камуфляж” складається з ковпака та козирка.

Ковпак складається із шести клинів, на кожному клині оброблено по одному вентиляційному отвору. У точці з’єднання клинів - декоративний ґудзик.

Козирок формований, обтягнутий тканиною з гаптуванням у вигляді листків дуба.

По низу кепі ззаду - хлястики з текстильною застібкою для регулювання щільності облягання. На верхньому хлястику - гаптування “ПОЛІЦІЯ”.

У кепі темно-синього кольору гаптування сріблястого кольору.

У кепі кольору хакі або в колористиці “камуфляж” гаптування кольору хакі.

По центру - вишита кокарда.

Кепі

[ image ]

Кепі із змішаної або синтетичної тканини темно-синього кольору, кольору хакі або в колористиці “камуфляж” складається з ковпака та козирка.

Ковпак складається із шести клинів. На кожному клині оброблено по одному вентиляційному отвору.

У точці з’єднання клинів - декоративний ґудзик.

На бічних клинах кепі темно-синього кольору - напис “ПОЛІЦІЯ” із світловідбивальними властивостями.

Козирок формований, обтягнутий змішаною або синтетичною тканиною.

У шві обшивання козирка кепі темно-синього кольору - кант із світловідбивальними властивостями.

Уздовж контуру козирка - оздоблювальні строчки.

По низу кепі ззаду - хлястики з текстильною застібкою для регулювання щільності облягання.

По центру - вишита кокарда.

Панама

[ image ]

Панама із змішаної або синтетичної тканини кольору хакі або в колористиці “камуфляж” складається з денця, стінки, полів та маски.

Стінка подвійна. На зовнішньому боці стінки нашита стрічка вертикальними строчками, між якими утворено отвори. На стінці ззаду під стрічкою - отвори для шнура із фіксатором для регулювання щільності прилягання.

На стінці над стрічкою - вентиляційні отвори з обох боків.

Поля панами складаються з верхньої та нижньої частин.

Уздовж контуру полів - оздоблювальні строчки.

У шов вшивання полів у стінку ззовні вшито маску з трикотажного сітчастого полотна, по нижньому краю якої прокладено еластичний шнур.

У шов вшивання полів у стінку із середини, по бічних сторонах, вшито шнур з фіксатором для фіксації панами на голові.

Берет

[ image ]

Берет із в’язаного трикотажного полотна чорного, темно-синього кольору або кольору хакі.

Берет формований на підкладці, з підкокардником.

На береті оброблено по два вентиляційних отвори з обох боків.

Берет із бейкою із штучної шкіри, у середину якої протягнуто шнур для регулювання щільності облягання.

На береті, ліворуч від центру - вишита кокарда / беретний знак.

[ image ]

Пальто прямого силуету з центральною потайною застібкою на петлі та ґудзики з поясом.

Пілочки з кокетками, боковими прорізними кишенями з листочками.

На лівій пілочці нашито накладну деталь з двома обробленими отворами для кріплення спеціального жетона.

На підборті лівої пілочки нагрудна прорізна кишеня з обшивками, яка застібається на застібку-блискавку.

Спинка з кокеткою, обшивними складками, середнім швом, який закінчується шліцом.

У бокових швах хомутики для пояса.

Пальто з відкладним коміром та із знімним коміром з натурального хутра чорного кольору.

Рукави вшивні двошовні. Задня частина рукава з виточкою на ділянці ліктя.

На ділянці плечових швів - погони з петлею, які застібаються на формений ґудзик сріблястого кольору.

Плащ прямого силуету двобортний із застібкою на петлі та формені ґудзики сріблястого кольору з поясом.

Пілочки з відлітними кокетками, боковими прорізними кишенями з листочками. На кокетці лівої пілочки нашито накладну деталь з двома обробленими отворами для кріплення спеціального жетона.

Спинка з відлітною кокеткою з потайною застібкою на петлю та ґудзик.

Куртка

[ image ]

Куртка з плащової тканини темно-синього кольору з мембранним покриттям на підкладці із шаром утеплювача та із знімною підстібкою.

Куртка подовжена з центральною застібкою на застібку-блискавку з двома бігунками та текстильними застібками, які розташовані на зовнішній нашивній планці, з вітрозахисною внутрішньою планкою та знімним капюшоном.

На пілочках горизонтальні нагрудні та похилі бокові прорізні кишені з обшивками, які застібаються на застібку-блискавку. На верхній частині лівої пілочки нашито накладну деталь з двома обробленими отворами для кріплення спеціального жетона. На верхній частині правої пілочки та спинці напис “ПОЛІЦІЯ” із світловідбивальними властивостями.

Рюкзак

[ image ]

Рюкзак із синтетичної тканини з водотривким покриттям чорного кольору, кольору хакі або в колористиці “камуфляж”.

Рюкзак із жорсткою спинкою (каркасом), кишенями для каркасних елементів та гідратора для води.

Рюкзак із підвісною знімною системою регулювання по висоті.

Рюкзак усередині розділено на два відділення перегородкою, що застібається на застібку-блискавку. Основне відділення з входом угорі, край якого стягується еластичним шнуром з фіксатором та накривається клапаном, що застібається на застібки типу “фастекс”. Нижнє відділення (для взуття) із застібкою на застібку-блискавку. Об’єми основного та нижнього відділень регулюються за допомогою бічних та вертикальних компресійних ременів із синтетичної стрічки із застібками типу “фастекс”.

Клапан рюкзака із стрічками системи модульного кріплення та кишенями на зовнішній та внутрішній сторонах.

Рюкзак на ділянці спинки з внутрішніми кишенями, що застібаються на застібки-блискавки.

На бічних частинах рюкзака - кишені (підсумки), що кріпляться за допомогою стрічок системи модульного кріплення.

Плечові лямки анатомічної форми з демпферними вставками, ременями із синтетичної стрічки та пряжками для регулювання їх довжини, а також із нагрудним ременем для стягування лямок на ділянці грудей та системою швидкого скиду рюкзака.

Підвісна система для перенесення навантаження на пояс анатомічної форми знімна з амортизаційними вставками, ременями із синтетичної ремінної стрічки із застібкою на триточкову застібку типу “фастекс” та стрічками системи модульного кріплення.

У верхній та нижній частинах рюкзака - петлі-ручки із синтетичної ремінної стрічки для транспортування

Угорі фронтальної частини рюкзака - платформа із текстильної застібки для кріплення знімного планшета.

Дно рюкзака ущільнено, на ньому розміщено ремені із синтетичної ремінної стрічки для кріплення вантажу.

Жетон ідентифікаційний з харчової нержавіючої сталі у вигляді прямокутника розміром 45 × 26 міліметрів, завтовшки 1 міліметр, кути якого заокруглені. Паралельно довшій стороні прямокутника посередині проходить перфораційна лінія, по якій жетон у разі потреби може бути переломлений. Жетон має отвір діаметром 3 міліметри з метою кріплення на шнурку (ланцюжку) для носіння на шиї. Після звільнення поліцейського жетон зберігається в його архівній особовій справі.

ширина обвідки шрифту - 0,4 міліметра;

глибина обвідки шрифту - до 0,2 міліметра;

висота шрифту - 2,2 міліметра;
