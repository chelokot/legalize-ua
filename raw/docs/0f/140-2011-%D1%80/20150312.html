Про утворення робочої групи з оперативного вирішення питань, пов'язаних із захистом інтересів громадян України, які перебувають на території держав Північної Африки і Близького Сходу

Текст документа від 12.03.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 лютого 2011 р. N 140-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 77 ( 77-2015-п ) від 04.03.2015 }

Про утворення робочої групи з оперативного вирішення питань, пов'язаних із захистом інтересів громадян України, які перебувають на території держав Північної Африки і Близького Сходу

{ Із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2012-п ) від 12.03.2012 Розпорядженням КМ N 559-р ( 559-2012-р ) від 15.08.2012 }

1. У зв'язку із загостренням загальної безпекової ситуації у державах Північної Африки і Близького Сходу та з метою координації дій центральних органів виконавчої влади із здійснення у 2012 році заходів щодо забезпечення захисту інтересів громадян України, які на даний час перебувають на території зазначених держав, утворити робочу групу з оперативного вирішення питань, пов'язаних із захистом інтересів громадян України, які перебувають на території держав Північної Африки і Близького Сходу, на чолі з Першим віце-прем'єр-міністром України Хорошковським В.І. у складі згідно з додатком. { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2012-п ) від 12.03.2012, Розпорядженням КМ N 559-р ( 559-2012-р ) від 15.08.2012 }

Голові робочої групи затвердити її персональний склад та у разі потреби вносити до нього зміни, залучати до діяльності робочої групи в установленому порядку працівників центральних органів виконавчої влади, інших державних органів, підприємств, установ та організацій (за погодженням з їх керівниками) та забезпечити отримання у разі потреби від державних органів, підприємств установ та організацій документів і матеріалів, необхідних для провадження діяльності робочої групи.

2. Робочій групі, утвореній згідно з цим розпорядженням, інформувати щокварталу до 30 числа останнього місяця кварталу Кабінет Міністрів України про результати її діяльності.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 559-р ( 559-2012-р ) від 15.08.2012 }

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 2 лютого 2011 р. N 83 ( 83-2011-р ) "Про утворення оперативного штабу з вирішення питань, пов'язаних із перебуванням громадян України на території Арабської Республіки Єгипет".
