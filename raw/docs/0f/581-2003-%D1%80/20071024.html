КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 жовтня 2003 р. N 581-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про співголову Експертно-консультаційної комісії з питань державного регулювання виробництва і обігу спирту, алкогольних напоїв та тютюнових виробів

Затвердити першого заступника Голови Державної податкової адміністрації Шитрю Олексія Івановича співголовою Експертно-консультаційної комісії з питань державного регулювання виробництва і обігу спирту, алкогольних напоїв та тютюнових виробів ( 1206-2002-п ), увільнивши від цих обов'язків Ярошенка Федора Олексійовича.
