Текст документа від 04.04.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 липня 2010 р. N 667 Київ

{ Постанова втратила чинність одночасно з набранням чинності Указом Президента ( 236/2012 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Про внесення змін до постанов Кабінету Міністрів України від 13 вересня 2000 р. N 1432 і від 13 грудня 2000 р. N 1819

Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України від 13 вересня 2000 р. N 1432 ( 1432-2000-п ) "Про Державну інспекцію з контролю за цінами" (Офіційний вісник України, 2000 р., N 38, ст. 1621) і від 13 грудня 2000 р. N 1819 ( 1819-2000-п ) "Питання Державної інспекції з контролю за цінами" (Офіційний вісник України, 2000 р., N 50, ст. 2162; 2005 р., N 50, ст. 3126; 2008 р., N 84, ст. 2821) зміни, що додаються.

2. Державній інспекції з контролю за цінами затвердити чисельність і структуру її територіальних органів у межах асигнувань, передбачених на їх утримання.

Прем'єр-міністр України М.АЗАРОВ

Інд. 40

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 липня 2010 р. N 667

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 13 вересня 2000 р. N 1432 ( 1432-2000-п ) і від 13 грудня 2000 р. N 1819 ( 1819-2000-п )

1. У пункті 1 постанови Кабінету Міністрів України від 13 вересня 2000 р. N 1432 ( 1432-2000-п ) слова "- державні інспекції з контролю за цінами" виключити.

2. У постанові Кабінету Міністрів України від 13 грудня 2000 р. N 1819 ( 1819-2000-п ):

1) у другому реченні пункту 2 постанови слова "державним інспекціям з контролю за цінами" замінити словами "територіальним органам Державної інспекції з контролю за цінами";

2) у Положенні про Державну інспекцію з контролю за цінами ( 1819-2000-п ), затвердженому зазначеною постановою:

у пункті 6:

в абзаці першому слова "Начальники державних інспекцій з контролю за цінами та їх заступники" замінити словами "Начальник Державної інспекції з контролю за цінами та його заступники, начальники територіальних органів Державної інспекції з контролю за цінами та їх заступники";

в абзаці другому слова "відповідній державній інспекції з контролю за цінами" замінити словами "відповідному територіальному органу Державної інспекції з контролю за цінами";

у першому реченні пункту 11 слова "- державні інспекції з контролю за цінами" виключити.
