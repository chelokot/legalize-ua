{ Постанову скасовано на підставі Постанови КМ N 45 ( 45-2009-п ) від 28.01.2009 }

Про внесення зміни до постанови Кабінету Міністрів України від 16 березня 2000 р. N 507

Кабінет Міністрів України постановляє:

1. Підпункт 4 постанови Кабінету Міністрів України від 16 березня 2000 р. N 507 ( 507-2000-п ) "Про роз'яснення Указу Президента України від 3 липня 1998 р. N 727" (Офіційний вісник України, 2000 р., N 12, ст. 461) викласти у такій редакції:

"4) суб'єкти малого підприємництва - фізичні особи, які до переходу на спрощену систему оподаткування, обліку та звітності були платниками податку на додану вартість, повинні подати до відповідного органу державної податкової служби заяву про анулювання реєстрації їх як платників податку на додану вартість і здати відповідне свідоцтво;".

2. Ця постанова набирає чинності з дня опублікування.
