Про внесення змін до пункту 1 постанови Кабінету Міністрів України від 23 грудня 2005 р. N 1267

Стан: Втратив чинність

Ідентифікатор: 890-2008-п

Текст документа від 24.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 вересня 2008 р. N 890 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1184 ( 1184-2011-п ) від 14.11.2011 }

Про внесення змін до пункту 1 постанови Кабінету Міністрів України від 23 грудня 2005 р. N 1267

{ Із змінами, внесеними згідно з Постановою КМ N 937 ( 937-2011-п ) від 07.09.2011 }

Кабінет Міністрів України постановляє:

1. У пункті 1 постанови Кабінету Міністрів України від 23 грудня 2005 р. N 1267 ( 1267-2005-п ) "Деякі питання Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" (Офіційний вісник України, 2005 р., N 52, ст. 3310; 2006 р., N 38, ст. 2592; 2007 р., N 70, ст. 2658) замінити:

{ Абзац другий пункту 1 втратив чинність на підставі Постанови КМ N 937 ( 937-2011-п ) від 07.09.2011 }

в абзаці третьому цифри "8869" та "6305" відповідно цифрами "8899" та "6335".

2. Ця постанова набирає чинності з 1 січня 2009 року.
