Президент України; Указ від 08.10.2007 № 948/2007

Про зупинення дії розпорядження Кабінету Міністрів України від 6 вересня 2007 року N 705-р

Стан: Втратив чинність

Ідентифікатор: 948/2007

Текст документа від 08.10.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії розпорядження Кабінету Міністрів України від 6 вересня 2007 року N 705-р

{ Додатково див. Конституційне подання Президента ( n0033100-07 ) від 08.10.2007 }

Кабінетом Міністрів України 6 вересня 2007 року видано розпорядження N 705-р ( 705-2007-р ) "Про передачу цілісного майнового комплексу державного підприємства "Міжнародний аеропорт "Львів".

Зазначеним розпорядженням ( 705-2007-р ) цілісний майновий комплекс державного підприємства "Міжнародний аеропорт "Львів" разом із злітно-посадковою смугою передано у власність територіальної громади м. Львова.

Назване розпорядження ( 705-2007-р ) не відповідає завданням щодо реформування та розвитку Збройних Сил України, визначеним Указом Президента України від 27 грудня 2005 року N 1862-25т, що виданий згідно зі статтею 106 Конституції України ( 254к/96-ВР ) та на виконання Законів України "Про основи національної безпеки України" ( 964-15 ) та "Про організацію оборонного планування" ( 2198-15 ). Злітно-посадкова смуга, про яку йдеться в розпорядженні Кабінету Міністрів України ( 705-2007-р ), разом з військовим аеродромом "Львів" використовуються для потреб Збройних Сил України до 2011 року включно. Вилучення зазначеної злітно-посадкової смуги з управління Міністерства оборони України призведе до зниження бойової готовності військ, що створить загрозу національній безпеці.

З огляду на наведене зазначене рішення Кабінету Міністрів України ( 705-2007-р ) не відповідає статті 17 Конституції України ( 254к/96-ВР ), за якою забезпечення захисту суверенітету і територіальної цілісності України визнаються найважливішими функціями держави, пункту 7 статті 116 Конституції України ( 254к/96-ВР ), яким на Кабінет Міністрів України покладено здійснення заходів щодо забезпечення обороноздатності і національної безпеки України, частині третій статті 113 Конституції України ( 254к/96-ВР ), згідно з якою Кабінет Міністрів України зобов'язаний керуватися у своїй діяльності Конституцією України ( 254к/96-ВР ), а також, зокрема, указами Президента України, прийнятими відповідно до Конституції ( 254к/96-ВР ) та законів України.

За викладених обставин розпорядження Кабінету Міністрів України N 705-р ( 705-2007-р ) не відповідає й частині другій статті 8 Конституції України ( 254к/96-ВР ), згідно з якою нормативно-правові акти мають прийматися на основі Конституції України ( 254к/96-ВР ) і відповідати їй.

Ураховуючи наведене, відповідно до пунктів 1, 15 і 17 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 6 вересня 2007 року N 705-р ( 705-2007-р ) "Про передачу цілісного майнового комплексу державного підприємства "Міжнародний аеропорт "Львів".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 8 жовтня 2007 року N 948/2007
