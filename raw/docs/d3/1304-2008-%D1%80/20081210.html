Кабінет Міністрів України; Розпорядження від 08.10.2008 № 1304-р

Про забезпечення фінансування добудови першої черги Дністровської ГАЕС

Стан: Чинний

Ідентифікатор: 1304-2008-р

Текст документа від 10.12.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 жовтня 2008 р. N 1304-р Київ

Про забезпечення фінансування добудови першої черги Дністровської ГАЕС

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1576-р ( 1576-2008-р ) від 10.12.2008 }

1. Погодитися з пропозицією Мінпаливенерго та ВАТ "Укргідроенерго" щодо залучення у IV кварталі 2008 р. для забезпечення фінансування добудови першої черги Дністровської ГАЕС довгострокового кредиту на суму до 650 млн. гривень з поверненням до 2012 року.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 1576-р ( 1576-2008-р ) від 10.12.2008 }

2. Рекомендувати НКРЕ для забезпечення погашення зазначеного у пункті 1 цього розпорядження кредиту та виплати відсотків за ним встановити на період до 2012 року цільову надбавку до тарифу на електричну енергію, що виробляється ВАТ "Укргідроенерго".

3. Взяти до відома, що ВАТ "Укргідроенерго":

відкриває відповідно до законодавства рахунок у визначеному на конкурсних засадах банку для акумулювання коштів, що надходять від сплати цільової надбавки до тарифу на електричну енергію, встановленої згідно з пунктом 2 цього розпорядження;

забезпечує цільове використання коштів, залучених згідно з пунктом 1 цього розпорядження, виключно за кошторисами витрат, передбачених затвердженим в установленому порядку титулом перехідної будови (об'єкта).

Прем'єр-міністр України Ю.ТИМОШЕНКО
