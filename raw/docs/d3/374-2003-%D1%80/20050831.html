Про визначення Державного агента із забезпечення заставних закупок зерна

Стан: Втратив чинність

Ідентифікатор: 374-2003-р

Текст документа від 31.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 червня 2003 р. N 374-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 832 ( 832-2005-п ) від 31.08.2005 )

Про визначення Державного агента із забезпечення заставних закупок зерна

1. Погодитися з рішенням Мінагрополітики і комісії з конкурсного відбору Державного агента із забезпечення заставних закупок зерна (протокол від 26 березня 2003 р. N 4) щодо визначення ДАК "Хліб України" Державним агентом із забезпечення заставних закупок зерна.

2. Державному агенту із забезпечення заставних закупок зерна здійснити заставні операції із зерном у строки та на умовах, передбачених Законом України "Про зерно та ринок зерна в Україні" ( 37-15 ) і постановою Кабінету Міністрів України від 7 лютого 2003 р. N 164 ( 164-2003-п ) "Про здійснення заставних операцій із зерном" (Офіційний вісник України, 2003 р., N 7, ст. 281).

3. Контроль за виконанням цього розпорядження покласти на Міністра аграрної політики.
