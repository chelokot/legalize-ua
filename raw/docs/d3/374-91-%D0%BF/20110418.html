Питання Адміністрації зони відчуження земель, радіаційно забруднених внаслідок Чорнобильської катастрофи

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 грудня 1991 р. N 374 Київ

{ Постанова втратила чинність одночасно з набранням чинності Указом Президента ( 393/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Питання Адміністрації зони відчуження земель, радіаційно забруднених внаслідок Чорнобильської катастрофи

( Із змінами, внесеними згідно з Постановою КМ N 134 ( 134-96-п ) від 29.01.96 )

( В тексті Постанови перейменовано Адміністрацію зони відчуження у Адміністрацію зони відчуження і зони безумовного (обов'язкового) відселення згідно з Постановою КМ N 134 ( 134-96-п ) від 29.01.96 )

Відповідно до Закону УРСР "Про правовий режим території, що зазнала радіоактивного забруднення внаслідок Чорнобильської катастрофи" ( 791а-12 ) Кабінет Міністрів України постановляє:

1. Міністерству України у справах захисту населення від наслідків аварії на Чорнобильській АЕС створити Адміністрацію зони відчуження земель, радіаційно забруднених внаслідок Чорнобильської катастрофи (надалі - Адміністрація зони відчуження і зони безумовного (обов'язкового) відселення) як спеціальний підрозділ Міністерства і затвердити положення про неї.

2. Установити Міністерству України у справах захисту населення від наслідків аварії на Чорнобильській АЕС для Адміністрації зони відчуження і зони безумовного (обов'язкового) відселення чисельність її працівників у кількості 59 одиниць.

3. Установити додатково посаду заступника Міністра України у справах захисту населення від наслідків аварії на Чорнобильській АЕС - начальника Адміністрації зони відчуження і зони безумовного (обов'язкового) відселення.

4. Міністерству фінансів України профінансувати у поточному році видатки на утримання Адміністрації зони відчуження і зони безумовного (обов'язкового) відселення за рахунок асигнувань, передбачених у республіканському бюджеті на утримання органів державного управління.

5. Міністерству економіки України, Державному комітетові України по зв'язку вирішити питання оснащення приміщень Адміністрації зони відчуження і зони безумовного (обов'язкового) відселення меблями, обладнанням, друкарською обчислювальною і розмножувальною технікою, засобами зв'язку.
