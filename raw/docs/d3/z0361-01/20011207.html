Про впорядкування окремих питань фінансово-господарської діяльності державних циркових підприємств

Реєстрація: Мін'юст України від 20.04.2001 № 361/5552

Стан: Втратив чинність

Ідентифікатор: z0361-01

Текст документа від 07.12.2001:

МІНІСТЕРСТВО КУЛЬТУРИ І МИСТЕЦТВ УКРАЇНИ

НАКАЗ

N 187 від 17.04.2001 Зареєстровано в Міністерстві юстиції України 20 квітня 2001 р. за N 361/5552

Про впорядкування окремих питань фінансово-господарської діяльності державних циркових підприємств

( Із змінами, внесеними згідно з Наказом Мінкультури N 719 ( z1021-01 ) від 26.11.2001 )

З метою вдосконалення гастрольної діяльності циркових колективів, упорядкування фінансово-господарської діяльності державних циркових підприємств, зміцнення фінансової дисципліни НАКАЗУЮ:

( Пункт 1 втратив чинність на підставі Наказу Мінкультури N 719 ( z1021-01 ) від 26.11.2001 )

2. Установити:

2.1. Керівники державних підприємств України несуть персональну відповідальність за неухильне дотримання норм чинної Інструкції з ведення квиткового господарства в театрально-видовищних підприємствах, затвердженої наказом Мінкультури від 07.07.99 N 452 ( z0483-99 ) та зареєстрованої Мін'юстом 20.07.99 за N 483/3776 (із змінами і доповненнями).

2.2. У разі використання резидентами, нерезидентами-юридичними і фізичними особами глядачевих залів державних цирків для надання інших послуг, доходи цирку не можуть бути меншими від запланованих на рік середніх видатків на проведення однієї вистави.

2.3. Керівники державних циркових підприємств мають право укладати угоди з провідними майстрами вітчизняного циркового мистецтва на умовах разової ставки (з оплатою за рахунок власних коштів підприємства) в розмірах, погоджених з Міністерством культури і мистецтв.

3. Керівникам державних циркових підприємств привести до 01.06.2001 статути підприємств у відповідність з положеннями цього наказу.

4. Відділу кадрового забезпечення (Л.М.Колесник) внести доповнення до контрактів з керівниками державних циркових підприємств відповідно до Указу Президента України від 16.11.2000 N 1242 ( 1242/2000 ), постанови Кабінету Міністрів України від 03.07.2000 N 1050 ( 1050-2000-п ) та наказу Мінкультури від 21.07.2000 N 372.

5. Контроль за виконанням наказу покласти на заступника Міністра В.В.Корнієнка.
