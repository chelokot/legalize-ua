( Із змінами, внесеними згідно з Постановами КМ N 1341 ( 1341-99-п ) від 23.07.99 N 1421 ( 1421-2000-п ) від 13.09.2000 N 44 ( 44-2005-п ) від 15.01.2005 N 541 ( 541-2005-п ) від 04.07.2005 N 575 ( 575-2005-п ) від 14.07.2005 )

( У назві та тексті постанови слово "плата" в усіх відмінках замінено словом "збір" у відповідних відмінках згідно з Постановою КМ N 1341 ( 1341-99-п ) від 23.07.99 )

( У тексті Постанови слова "Комітет водного господарства" і "Міністерство охорони навколишнього природного середовища та ядерної безпеки" в усіх відмінках замінено відповідно словами "Державний комітет по водному господарству" та "Міністерство екології та природних ресурсів" у необхідному відмінку згідно з Постановою КМ N 1421 ( 1421-2000-п ) від 13.09.2000 )

Кабінет Міністрів України постановляє:

1. Затвердити нормативи збору за спеціальне водокористування згідно з додатками 1-9 і ввести їх в дію з 1 липня 1999 року.

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 44 ( 44-2005-п ) від 15.01.2005 )

( Пункт 2 виключено на підставі Постанови КМ N 1341 ( 1341-99-п ) від 23.07.99 )

3. Міністерству фінансів, Державній податковій адміністрації, Міністерству економіки, Міністерству екології та природних ресурсів за погодженням з Державним комітетом по водному господарству, Комітетом з питань геології та використання надр розробити та подати у місячний термін до Кабінету Міністрів України проект Порядку справляння збору за спеціальне використання водних ресурсів.

4. Міністерству екології та природних ресурсів, Державному комітетові по водному господарству визначити у місячний термін перелік водних ресурсів місцевого значення.

5. Міністерствам, іншим центральним органам виконавчої влади і привести свої нормативно-правові акти у відповідальність з цією постановою.

6. Визнати такими, що втратили чинність з 1 липня 1999 р., постанови Кабінету Міністрів України згідно з додатком 5.

Додаток 8 до постанови Кабінету Міністрів України від 18 травня 1999 р. N 836

НОРМАТИВ збору за спеціальне водокористування в частині використання поверхневих вод для потреб рибництва

Для поповнення водою ставків у процесі розведення риби та інших водних живих ресурсів у рибних господарствах на всіх поверхневих водних об'єктах - 10,60 коп. за 100 куб. метрів води.

( Постанову доповнено додатком 8 згідно з Постановою КМ N 44 ( 44-2005-п ) від 15.01.2005; із змінами, внесеними згідно з Постановою КМ N 541 ( 541-2005-п ) від 04.07.2005 )
