Зареєстровано в Міністерстві юстиції України 25 грудня 2003 р. за N 1227/8548

Про затвердження Змін до форми декларації з податку на прибуток підприємства та Порядку її складання, затверджених наказом ДПА України від 29.03.2003 N 143

Відповідно до пунктів 16.4 і 16.15 статті 16 Закону України "Про оподаткування прибутку підприємств" ( 334/94-ВР ), статті 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ) та у зв'язку із впровадженням Закону України від 22 травня 2003 року N 889-IV ( 889-15 ) "Про податок з доходів фізичних осіб" НАКАЗУЮ:

1. Затвердити Зміни до форми декларації з податку на прибуток підприємства та Порядку її складання, затверджених наказом ДПА України від 29.03.2003 N 143 ( z0271-03 ), зареєстрованим у Міністерстві юстиції України 08.04.2003 за N 271/7592 (додаються).

2. Департаменту методології (Піхоцький В.Ф.):

2.1. Подати цей наказ на узгодження до Комітету Верховної Ради України з питань фінансів і банківської діяльності та в Державну комісію з регулювання ринків фінансових послуг України.

2.2. Після узгодження з Комітетом Верховної Ради України з питань фінансів і банківської діяльності та Державною комісією з регулювання ринків фінансових послуг України подати цей наказ до Міністерства юстиції України для державної реєстрації.

3. Департаменту автоматизації процесів оподаткування (Семирга М.І.) внести відповідні зміни до програмного забезпечення для опрацювання державними податковими органами декларації з податку на прибуток підприємства.

4. Контроль за виконанням цього наказу покласти на заступника Голови Лекаря С.І.

Голова Ю.Ф.Кравченко

ЗМІНИ до форми декларації з податку на прибуток підприємства та Порядку її складання ( z0271-03 )

1. Форму декларації з податку на прибуток підприємства ( z0271-03 ) після коду рядка декларації 19.3 доповнити рядком 19.4 такого змісту:

------------------------------------------------------------------

|з доходів фізичних осіб, |19.4 К7 | |

|нарахованих як проценти | | |

------------------------------------------------------------------

2. У пункті 1.2 розділу 1 "Загальні положення" Порядку складання декларації з податку на прибуток підприємства ( z0271-03 ) слова "банків та підприємств, основною діяльністю яких є виробництво сільськогосподарської продукції" замінити словами "та банків".

3. В абзаці 2 пункту 3.1 розділу 3 "Порядок заповнення декларації" Порядку складання декларації з податку на прибуток підприємства ( z0271-03 ) після слів "установлених Законом N 334" доповнити словами "та Законом України від 22 травня 2003 року N 889-IV ( 889-15 ) "Про податок з доходів фізичних осіб" (далі - Закон N 889)."

4. Таблицю пункту 3.1 розділу 3 "Порядок заповнення декларації" Порядку складання декларації з податку на прибуток підприємства ( z0271-03 ) після коду рядка декларації 19.3 доповнити рядком 19.4 такого змісту:

-------------------------------------------------------------------

| 19.4 |пп. 9.2.2 п. 9.2 ст. 9 Закону N 889 ( 889-15 ) |

-------------------------------------------------------------------

5. Розділ 4 "Строки подання декларації та сплати податку" Порядку складання декларації з податку на прибуток підприємства ( z0271-03 ) після пункту 4.1 доповнити таким пунктом:

"4.2. Підприємства, основною діяльністю яких є виробництво сільськогосподарської продукції, подають декларацію за підсумками податкового (звітного) року в терміни, встановлені законом для річного базового податкового (звітного) періоду".

У зв'язку з цим пункти 4.2 та 4.3 розділу 4 "Строки подання декларації та сплати податку" Порядку складання декларації з податку на прибуток підприємства ( z0271-03 ) вважати пунктами 4.3 та 4.4.
