Текст документа від 01.05.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 травня 2000 р. N 786 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 304 ( 304-2016-п ) від 20.04.2016 }

Про умови оплати праці працівників Національної ради з питань телебачення і радіомовлення

( Із змінами, внесеними згідно з Постановами КМ N 1478 ( 1478-2000-п ) від 28.09.2000 N 802 ( 802-2001-п ) від 11.07.2001 )

З метою впорядкування умов оплати праці працівників Національної ради з питань телебачення і радіомовлення Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 802 ( 802-2001-п ) від 11.07.2001 )

2. Установити надбавку за особливий характер роботи та інтенсивність праці:

Голові Національної ради з питань телебачення і радіомовлення та його заступникам - у розмірі 90 відсотків посадового окладу з урахуванням надбавки за ранг;

іншим членам Національної ради - 70 відсотків посадового окладу з урахуванням надбавки за ранг.

( Постанову доповнено пунктом 2 згідно з Постановою КМ N 1478 ( 1478-2000-п ) від 28.09.2000 )

3. Визнати таким, що втратив чинність, пункт 2 постанови Кабінету Міністрів України від 20 жовтня 1995 р. N 844 ( 844-95-п ) "Питання забезпечення діяльності Національної ради з питань телебачення і радіомовлення" в частині оплати праці, а стосовно умов оплати праці, матеріально-побутового забезпечення, медичного та транспортного обслуговування виконавчого секретаря Національної ради з питань телебачення і радіомовлення - з дня призначення членів Національної ради з питань телебачення і радіомовлення.
