Кабінет Міністрів України; Постанова від 16.11.2011 № 1170

Про внесення зміни до пункту 3 Порядку використання коштів, передбачених у державному бюджеті для забезпечення житлом інвалідів Великої Вітчизняної війни I групи, які протягом тривалого строку перебувають у черзі на отримання житла

Стан: Втратив чинність

Ідентифікатор: 1170-2011-п

Текст документа від 08.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2011 р. N 1170 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 503 ( 503-2012-п ) від 23.05.2012 }

Про внесення зміни до пункту 3 Порядку використання коштів, передбачених у державному бюджеті для забезпечення житлом інвалідів Великої Вітчизняної війни I групи, які протягом тривалого строку перебувають у черзі на отримання житла

Кабінет Міністрів України постановляє:

Внести зміну до пункту 3 Порядку використання коштів, передбачених у державному бюджеті для забезпечення житлом інвалідів Великої Вітчизняної війни I групи, які протягом тривалого строку перебувають у черзі на отримання житла, затвердженого постановою Кабінету Міністрів України від 20 квітня 2011 р. N 437 ( 437-2011-п ) (Офіційний вісник України, 2011 р., N 30, ст. 1312), замінивши цифри і слова "1 січня 2010 р." цифрами і словами "1 січня 2011 р.".

Прем'єр-міністр України М.АЗАРОВ
