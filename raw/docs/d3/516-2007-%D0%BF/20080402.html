Кабінет Міністрів України; Постанова, Порядок від 21.03.2007 № 516

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для проведення науково-практичних конференцій і семінарів з економічних проблем

Стан: Чинний

Ідентифікатор: 516-2007-п

Текст документа від 02.04.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 березня 2007 р. N 516 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для проведення науково-практичних конференцій і семінарів з економічних проблем

{ Із змінами, внесеними згідно з Постановою КМ N 294 ( 294-2008-п ) від 02.04.2008 }

{ Установити, що кошти, передбачені у державному бюджеті ( 107-17 ) Міністерству економіки за програмою "Проведення науково-практичних конференцій і семінарів з економічних проблем", використовуються у 2008 році відповідно до Порядку використання у 2007 році коштів, передбачених у державному бюджеті для проведення науково-практичних конференцій і семінарів з економічних проблем, затвердженого цією Постановою, згідно з Постановою КМ N 294 ( 294-2008-п ) від 02.04.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для проведення науково-практичних конференцій і семінарів з економічних проблем, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 42

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 березня 2007 р. N 516

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для проведення науково-практичних конференцій і семінарів з економічних проблем

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) Мінекономіки за програмою "Проведення науково-практичних конференцій і семінарів з економічних проблем" (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються на фінансування витрат, пов'язаних з підготовкою та забезпеченням проведення науково-практичних конференцій і семінарів з економічних проблем.

3. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 294 ( 294-2008-п ) від 02.04.2008 }

4. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

Попередня оплата товарів, робіт і послуг, що закуповуються за бюджетні кошти, здійснюється у розмірі, який не перевищує 30 відсотків їх вартості, відповідно до постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752).

Остаточні розрахунки згідно з договором про закупівлю товарів, робіт і послуг за бюджетні кошти здійснюються Мінекономіки на підставі актів приймання-передачі після виконання договору у повному обсязі.

5. З метою недопущення виникнення кредиторської заборгованості на кінець року до тендерної документації та договору про закупівлю товарів, робіт і послуг за бюджетні кошти включається вимога щодо коригування визначеної у договорі суми та зобов'язань сторін у разі зменшення бюджетних призначень під час уточнення показників Державного бюджету України на 2007 рік ( 489-16 ).

6. Мінекономіки готує та затверджує план заходів щодо виконання бюджетної програми та подає Мінфіну у двотижневий строк після затвердження розпису державного бюджету.

Інформацію про виконання зазначеного плану заходів Мінекономіки подає Мінфіну у двотижневий строк після проведення науково-практичних конференцій і семінарів з економічних проблем.

7. Відповідальність за цільове використання бюджетних коштів покладається на Мінекономіки.

{ Пункт 8 виключено на підставі Постанови КМ N 294 ( 294-2008-п ) від 02.04.2008 }

9. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
