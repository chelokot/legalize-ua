Президія Верховної Ради УРСР; Указ від 09.02.1982 № 3109-X

Про встановлення почесного звання "Заслужений журналіст Української РСР"

Стан: Втратив чинність

Ідентифікатор: 3109-10

Текст документа від 15.11.1988:

УКАЗ ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНСЬКОЇ РСР

Про встановлення почесного звання "Заслужений журналіст Української РСР"

( Відомості Верховної Ради (ВВР), 1982, N 8, ст. 98 )

( Із змінами, внесеними згідно з Указом Президії Верховної Ради УРСР N 6848-XI ( 6848-11 ) від 15.11.88, ВВР, 1988, N 48, ст. 1127 )

Президія Верховної Ради Української РСР постановляє:

( Стаття 1 втратила чинність на підставі Указу Президії Верховної Ради УРСР N 6848-XI ( 6848-11 ) від 15.11.88 )

( Стаття 2 втратила чинність на підставі Указу Президії Верховної Ради УРСР N 6848-XI ( 6848-11 ) від 15.11.88 )

( Стаття 3 втратила чинність на підставі Указу Президії Верховної Ради УРСР N 6848-XI ( 6848-11 ) від 15.11.88 )

4. Внести такі доповнення до Положення про державні нагороди Української РСР ( 1870-10 ), затвердженого Указом Президії Верховної Ради Української РСР від 7 травня 1981 року (Відомості Верховної Ради УРСР, 1981 р., N 20, ст. 290; N 41, ст. 674; N 50, ст. 856):

1) статтю 7 Положення після слів "Заслужений архітектор Української РСР" доповнити словами "Заслужений журналіст Української РСР";

2) частину першу статті 8 Положення після слів "Заслужений архітектор Української РСР" доповнити словами "Заслужений журналіст Української РСР";

3) статтю 10 Положення після абзаца "Заслужений архітектор Української РСР" доповнити абзацом такого змісту:

"Заслужений журналіст Української РСР - членам Спілки журналістів, які працюють в редакціях газет, телебачення, радіомовлення журналів, інформаційних агентств, видавництв та інших організацях".
