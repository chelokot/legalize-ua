Про затвердження норм харчування для ВІЛ-інфікованих та хворих на СНІД дітей

Кабінет Міністрів України постановляє :

1. Затвердити:

норми харчування для ВІЛ-інфікованих та хворих на СНІД дітей згідно з додатком 1;

норми заміни харчових продуктів за енергетичною цінністю згідно з додатком 2.

2. Міністерству охорони здоров’я, іншим центральним органам виконавчої влади, Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям забезпечити дотримання затверджених цією постановою норм харчування для ВІЛ-інфікованих та хворих на СНІД дітей.

Примітки:



1. Продукти щоденного споживання (молоко, хліб, масло вершкове) використовуються в межах добової норми ± 5 відсотків, а такі продукти, як сир, риба, дріжджі тощо, споживаються кілька разів на тиждень. Наприклад, для риби: добова норма 50 грамів, використовується в меню 3 рази на тиждень. Розрахунок використання такий: (50 х 7) : 3 = 350 : 3 = 116,6 грама (на день); для дріжджів розрахунок такий: (1 х 7) : 2 = 3,5 грама (на день).
2. За відсутності необхідних продуктів харчування слід проводити їх заміну згідно з нормами заміни.
3. Для заготівлі квашених свіжих овочів (огірки, помідори, капуста тощо) використовується сіль згідно з рецептурами понад добову норму.
4. Норма овочів, фруктів у літньо-осінній період може бути збільшена на 50-100 відсотків за рахунок зменшення на 50 відсотків норми крупів, макаронних виробів та картоплі. У зимово-весняний період норма овочів, фруктів свіжих може бути зменшена на 30-50 відсотків із збільшенням норми соків на 50 відсотків.
5. Залежно від стану здоров’я дитини (загострення захворювання чи наявності супутньої патології) лікар може призначити індивідуальну для цієї дитини корекцію харчового раціону, про що робиться відповідний запис в амбулаторній картці чи в історії хвороби дитини.
