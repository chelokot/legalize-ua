Про організаційні заходи щодо ліквідації Державного департаменту фінансового моніторингу

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 жовтня 2004 р. N 1460 Київ

Про організаційні заходи щодо ліквідації Державного департаменту фінансового моніторингу

{ Із змінами, внесеними згідно з Постановами КМ N 268 ( 268-2006-п ) від 09.03.2006 N 954 ( 954-2008-п ) від 22.10.2008 N 464 ( 464-2009-п ) від 13.05.2009 }

На виконання Указу Президента України від 28 вересня 2004 р. N 1144 ( 1144/2004 ) "Про Державний комітет фінансового моніторингу України" Кабінет Міністрів України постановляє:

1. Ліквідувати з 1 січня 2005 р. Державний департамент фінансового моніторингу, що діє у складі Міністерства фінансів.

Утворити комісію з ліквідації Державного департаменту фінансового моніторингу.

Головою ліквідаційної комісії затвердити Голову Державного комітету фінансового моніторингу Гуржія Сергія Григоровича.

Голові ліквідаційної комісії:

затвердити персональний склад комісії та забезпечити її діяльність;

поінформувати до 1 лютого 2005 р. Кабінет Міністрів України про завершення роботи.

2. Зберегти за Гуржієм С.Г. на період роботи ліквідаційної комісії середню заробітну плату, встановлену за попереднім місцем роботи.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

4. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

5. Погодитися з пропозицією Міністерства фінансів та Державного департаменту фінансового моніторингу щодо передачі будинку по вул. Білоруській, 24, у м. Києві із сфери управління Міністерства фінансів до сфери управління Державного комітету фінансового моніторингу.

6. Пункти 3 і 4 цієї постанови набирають чинності з 1 січня 2005 року.
