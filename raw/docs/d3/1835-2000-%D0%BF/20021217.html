Кабінет Міністрів України; Постанова від 18.12.2000 № 1835

Про затвердження членів колегії Державного комітету інформаційної політики, телебачення і радіомовлення

Стан: Втратив чинність

Ідентифікатор: 1835-2000-п

Текст документа від 17.12.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 грудня 2000 р. N 1835 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1925 ( 1925-2002-п ) від 17.12.2002 )

Про затвердження членів колегії Державного комітету інформаційної політики, телебачення і радіомовлення

( Із змінами, внесеними згідно з Постановою КМ N 805 ( 805-2002-п ) від 13.06.2002 )

Кабінет Міністрів України постановляє:

1. Дозволити Державному комітету інформаційної політики, телебачення і радіомовлення мати колегію у кількості 18 чоловік.

( Пункт 2 втратив чинність на підставі Постанови КМ N 805 ( 805-2002-п ) від 13.06.2002 )
