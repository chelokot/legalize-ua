Президент України; Указ від 16.05.1992 № 301

Про утворення колегії Міністерства оборони України та військових рад в оперативних командуваннях, об'єднаннях Збройних Сил України

Стан: Втратив чинність

Ідентифікатор: 301/92

Текст документа від 29.09.1998:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про утворення колегії Міністерства оборони України та військових рад в оперативних командуваннях, об'єднаннях Збройних Сил України

( Із змінами, внесеними згідно з Указами Президента N 61/93 від 24.02.93 N 473/94 від 25.08.94 N 1070/98 від 29.09.98 )

З метою забезпечення реалізації постанов Ради оборони України, колегіальності у виробленні рішень по керівництву Збройними Силами України постановляю:

1. Утворити колегію Міністерства оборони України у складі:

Міністр оборони України - голова колегії;

заступники Міністра оборони України за посадою;

керівники структурних підрозділів апарату Міністерства оборони України.

( Стаття 1 в редакції Указу Президента N 61/93 від 24.02.93 )

2. Утворити військові ради в командуваннях видами Збройних Сил України, військами оперативних командувань та управліннях об'єднань у складі: ( Абзац перший статті 2 із змінами, внесеними згідно з Указами Президента N 473/94 від 25.08.94, N 1070/98 від 29.09.98 )

командуючий (командир) - голова військової ради; ( Абзац другий статті 2 із змінами, внесеними згідно з Указом Президента N 1070/98 від 29.09.98 )

( Абзац третій статті 2 виключено на підставі Указу Президента N 473/94 від 25.08.94 ) Представник Президента України в області;

Голова Ради міністрів Автономної Республіки Крим, голова обласної, Київської, Севастопольської міської державної адміністрації, залежно від регіону, де розташовано відповідне управління об'єднання; ( Абзац третій статті 2 в редакції Указу Президента N 1070/98 від 29.09.98 )

заступники командуючого (командира); ( Абзац четвертий статті 2 із змінами, внесеними згідно з Указом Президента N 1070/98 від 29.09.98 )

інші особи, які займають керівні посади в командуваннях видами Збройних Сил України, військами оперативних командувань та управліннях об'єднань. ( Абзац статті 2 із змінами, внесеними згідно з Указами Президента N 473/94 від 25.08.94, N 1070/98 від 29.09.98 )

( Стаття 2 в редакції Указу Президента N 61/93 від 24.02.93 )

3. Міністерству оборони України розробити проекти Положень про колегію та військові ради і подати їх на

затвердження Кабінету Міністрів України. ( Стаття 3 із змінами, внесеними згідно з Указом Президента N 61/93 від 24.02.93 )

Президент України Л. КРАВЧУК
