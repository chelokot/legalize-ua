Ідентифікатор: 448-2009-п

Текст документа від 29.05.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 квітня 2009 р. N 448 Київ

Про внесення змін до постанов Кабінету Міністрів України від 3 травня 2007 р. N 696 та від 22 лютого 2008 р. N 107

{ Із змінами, внесеними згідно з Постановою КМ N 357 ( 357-2010-п ) від 14.04.2010 }

Кабінет Міністрів України постановляє:

1. Доповнити постанову Кабінету Міністрів України від 3 травня 2007 р. N 696 ( 696-2007-п ) "Про заходи щодо створення національної супутникової системи зв'язку" (Офіційний вісник України, 2007 р., N 33, ст. 1342) пунктом 8 такого змісту:

"8. Національному космічному агентству разом з Міністерством фінансів, Міністерством економіки, Державною інноваційною фінансово-кредитною установою та державним підприємством "Укркосмос" розробити і подати на розгляд Кабінету Міністрів України проект порядку надання у 2009 році державних гарантій щодо фінансування створення національної супутникової системи зв'язку.".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 357 ( 357-2010-п ) від 14.04.2010 }
