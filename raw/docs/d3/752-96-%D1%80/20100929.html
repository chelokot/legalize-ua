Кабінет Міністрів України; Розпорядження від 25.11.1996 № 752-р

Про експорт та оптову торгівлю товарами за кодами ТН ЗЕД 22.07

Стан: Втратив чинність

Ідентифікатор: 752-96-р

Текст документа від 29.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 листопада 1996 р. N 752-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1898-р ( 1898-2010-р ) від 29.09.2010 }

Уповноважити здійснювати експорт та оптову торгівлю товарами за кодами ТН ЗЕД 22.07 Львівське обласне державне об'єднання спиртової та лікеро-горілчаної промисловості, Чернігівське обласне державне об'єднання спиртової та лікеро-горілчаної промисловості, Тернопільське обласне державне об'єднання спиртової та лікеро-горілчаної промисловості.
