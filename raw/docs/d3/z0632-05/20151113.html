Про внесення змін до розпорядження Державної комісії з регулювання ринків фінансових послуг України від 29.12.2003 N 188

Реєстрація: Мін'юст України від 07.06.2005 № 632/10912

Стан: Втратив чинність

Ідентифікатор: z0632-05

Текст документа від 13.11.2015:

ДЕРЖАВНА КОМІСІЯ З РЕГУЛЮВАННЯ РИНКІВ ФІНАНСОВИХ ПОСЛУГ УКРАЇНИ

РОЗПОРЯДЖЕННЯ

27.05.2005 N 4083

Зареєстровано в Міністерстві юстиції України 7 червня 2005 р. за N 632/10912

{ Розпорядження втратило чинність на підставі Розпорядження Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг

N 2337 ( z1261-15 ) від 29.09.2015 }

Про внесення змін до розпорядження Державної комісії з регулювання ринків фінансових послуг України від 29.12.2003 N 188

На виконання рішення господарського суду м. Києва від 22.10.2004 за справою N 22/404 за позовом закритого акціонерного товариства "УСК "Веста" до Державної комісії з регулювання ринків фінансових послуг України та у зв'язку з набранням чинності постановою Кабінету Міністрів України від 13.04.2005 N 286 ( 286-2005-п ) "Про встановлення розміру плати за видачу ліцензії на проведення конкретного виду страхування" Державна комісія з регулювання ринків фінансових послуг України ПОСТАНОВИЛА:

1. Унести до розпорядження Державної комісії з регулювання ринків фінансових послуг України від 29.12.2003 N 188 ( z0240-04 ) "Про встановлення плати за видачу ліцензій", зареєстрованого в Міністерстві юстиції України 23.02.2004 за N 240/8839, такі зміни:

1.1. У пункті 1 слова "(крім ліцензії на проведення страхування життя)" замінити словами "(крім ліцензій на проведення конкретного виду страхування)".

1.2. Пункт 2 виключити. У зв'язку з цим пункти 3-6 уважати відповідно пунктами 2-5.

1.3. У додатку 1 до розпорядження позиції 1-5 виключити. У зв'язку з цим позиції 6-13 уважати відповідно позиціями 1-8.

1.4. У додатку 2 до розпорядження позицію 1 виключити. У зв'язку з цим позиції 2-9 уважати відповідно позиціями 1-8.

2. Департаменту державного регулювання та розвитку ринків фінансових послуг (Мосійчук Т.К.), Юридичному управлінню (Ткаченко Д.В.) забезпечити подання цього розпорядження до Міністерства юстиції України для державної реєстрації.

3. Управлінню організаційно-аналітичного забезпечення роботи керівника (Шевченко Т.М.) забезпечити опублікування цього розпорядження в засобах масової інформації після його державної реєстрації.

4. Контроль за виконанням цього розпорядження залишити за Головою Комісії.

Голова Комісії В.Суслов
