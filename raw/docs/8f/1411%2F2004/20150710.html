УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до деяких указів Президента України

{ Із змінами, внесеними згідно з Указом Президента N 398/2015 ( 398/2015 ) від 07.07.2015 }

Внести до указів Президента України такі зміни:

1. В Указі Президента України від 9 лютого 1999 року N 145 ( 145/99 ) "Про заходи щодо вдосконалення нормотворчої діяльності органів виконавчої влади" (зі змінами, внесеними Указом від 19 лютого 2003 року N 143 ( 143/2003 ):

а) в статті 3:

абзаци третій і четвертий виключити. У зв'язку з цим абзаци п'ятий і шостий вважати відповідно абзацами третім і четвертим;

в абзаці третьому слово "планами" замінити словом "планом";

б) статті 5-7 визнати такими, що втратили чинність.

{ Стаття 2 втратила чинність на підставі Указу Президента N 398/2015 ( 398/2015 ) від 07.07.2015 }
