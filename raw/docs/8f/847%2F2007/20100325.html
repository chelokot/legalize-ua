УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ скасовано на підставі Указу Президента N 402/2010 ( 402/2010 ) від 23.03.2010 }

Про деякі питання забезпечення реалізації прав громадян на приватизацію об'єктів державної власності

З метою забезпечення реалізації прав громадян України на приватизацію об'єктів державної власності, керуючись частиною другою статті 102 Конституції України ( 254к/96-ВР ), постановляю:

1. Кабінету Міністрів України та Державному управлінню справами вирішити питання про передачу майнових комплексів Державного підприємства "Чайка" (м. Київ, вул. Гарматна, 38) та Державного підприємства "Дібрівський кінний завод N 62" (Полтавська область, Миргородський район, с. Петрівці) в управління Міністерства аграрної політики України для подальшої їх приватизації в установленому законом порядку.

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
