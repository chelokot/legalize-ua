Про затвердження нового складу Координаційної ради з адаптації законодавства України до законодавства Європейського Союзу

{ Із змінами, внесеними згідно з Постановою КМ N 944 ( 944-2011-п ) від 07.09.2011 }

Кабінет Міністрів України постановляє:

На часткову зміну пункту 1 постанови Кабінету Міністрів України від 15 жовтня 2004 р. N 1365 ( 1365-2004-п ) "Деякі питання адаптації законодавства України до законодавства Європейського Союзу" (Офіційний вісник України, 2004 р., N 42, ст. 2763; 2005 р., N 9, ст. 475; 2009 р., N 20, ст. 641; 2010 р., N 70, ст. 2523) затвердити новий склад Координаційної ради з адаптації законодавства України до законодавства Європейського Союзу згідно з додатком.
