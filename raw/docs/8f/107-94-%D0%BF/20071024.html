КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 лютого 1994 р. N 107 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про призначення Свіженка В.О. головою Української частини Українсько-Грузинської комісії з питань співробітництва у сфері науки та технологій

Кабінет Міністрів України постановляє:

Призначити заступника голови Державного комітету з питань науки і технологій Свіженка Віктора Олексійовича головою Української частини Українсько-Грузинської комісії з питань співробітництва у сфері науки та технологій.
