Затверджено Наказ Державного департаменту України з питань виконання покарань 10 серпня 2000 р. N 162

Зареєстровано в Міністерстві юстиції України 23 серпня 2000 р. за N 536/4757

Інструкція про порядок забезпечення речовим майном засуджених, які відбувають покарання в установах виконання покарань, та осіб, які утримуються у слідчих ізоляторах

{ Назва Інструкції із змінами, внесеними згідно з Наказами Державного департаменту України з питань виконання покарань N 228 ( z1226-03 ) від 02.12.2003, N 258 ( z1177-09 ) від 10.11.2009 }

1. Загальні положення

1.1. Усі засуджені, які відбувають покарання в установах виконання покарань, та особи, які утримуються у слідчих ізоляторах, забезпечуються речовим майном та постільними речами згідно із затвердженими нормами.

{ Пункт 1.1 із змінами, внесеними згідно з Наказами Державного департаменту України з питань виконання покарань N 228 ( z1226-03 ) від 02.12.2003, N 258 ( z1177-09 ) від 10.11.2009 }

1.2. Вартість речового майна, виданого в користування, забезпечується за рахунок коштів, зароблених у установах виконання покарань, та згідно із заявами за рахунок коштів, що надійшли на особові рахунки. ( Пункт 1.2 із змінами, внесеними згідно з Наказом Держдепартаменту вик. покарань N 228 ( z1226-03 ) від 02.12.2003 )

1.3. Засудженим неповнолітнім, інвалідам першої та другої груп, жінкам з вагітністю понад чотири місяці, непрацюючим жінкам, які мають дітей у будинках дитини при виправних колоніях, непрацюючим чоловікам віком понад шістдесят років і жінкам - понад п'ятдесят п'ять років (якщо вони не одержують пенсії), а також особам, звільненим від роботи через хворобу, у тому числі хворим на активну форму туберкульозу, одяг, взуття, білизна, надаються безоплатно. ( Пункт 1.3 в редакції Наказу Держдепартаменту вик. покарань N 228 ( z1226-03 ) від 02.12.2003 )

1.4. Засуджені та особи, які утримуються в слідчих ізоляторах, можуть придбавати за власні кошти верхній одяг і взуття в магазинах установ або отримувати його в посилках (передачах) в асортименті і кількості, затвердженій відповідними нормами, а натільну і постільну білизну без обмежень. Це майно підлягає обліку.

{ Пункт 1.4 в редакції Наказу Держдепартаменту вик. покарань N 228 ( z1226-03 ) від 02.12.2003; із змінами, внесеними згідно з Наказом Державного департаменту України з питань виконання покарань N 258 ( z1177-09 ) від 10.11.2009 }

1.5. Засудженим до довічного позбавлення волі видається верхній одяг спеціального зразка. ( Пункт 1.5 в редакції Наказу Держдепартаменту вик. покарань N 228 ( z1226-03 ) від 02.12.2003 )

1.6. Ремонт одягу та взуття для спецконтингенту здійснюється за власні кошти, що розміщені на особових рахунках.

1.7. У разі передчасного зносу одягу та взуття або втрати речового майна засудженими нові предмети відпускаються на підставі розпорядження керівника установи, виходячи з матеріалів службового розслідування та особистих заяв, тільки за кошти, що розміщені на особових рахунках, або, як виняток, видається речове майно, що було в користуванні.

1.8. При переведенні з числа спецконтингенту до іншої установи особи відбувають в одязі та взутті, що є в їхньому користуванні. У разі потреби видаються предмети речового майна за сезоном, згідно з нормою належності з урахуванням строків носіння.

1.9. Для перевдягання засуджених, які поміщаються у дисциплінарні ізолятори, карцери або переводяться до приміщень камерного типу (одиночних камер), використовується майно підмінного фонду. ( Пункт 1.9 в редакції Наказу Держдепартаменту вик. покарань N 228 ( z1226-03 ) від 02.12.2003 )

1.10. Засуджені, які звільнилися з установ виконання покарань, при відсутності необхідного за сезоном одягу, взуття і коштів на їх придбання забезпечуються одягом і взуттям безкоштовно (з підмінного фонду).

{ Пункт 1.10 із змінами, внесеними згідно з Наказами Державного департаменту України з питань виконання покарань N 228 ( z1226-03 ) від 02.12.2003, N 258 ( z1177-09 ) від 10.11.2009 }

1.11. Інвентарне майно, що підлягає вибракуванню і списанню, вилучається з користування та зосереджується в окремих приміщеннях. Зберігання не придатного для подальшого використання майна разом з новим забороняється.

1.12. При визначенні вартості загубленого, не придатного для подальшого використання майна враховується фактичний його знос, залежно від установленого терміну експлуатації.

1.13. Строки носіння предметів речового майна та експлуатації постільних речей визначаються з моменту їх фактичної видачі.

2. Порядок таврування інвентарного майна

2.1. Тавруванню підлягають усі предмети інвентарного користування. Таврування інвентарного майна здійснюється з метою його закріплення за установами кримінально-виконавчої системи, а також для визначення терміну експлуатації.

2.2. На предмети інвентарного майна тавро наноситься в місцях, що унеможливлюють його повторне таврування.

2.3. Для таврування речового майна застосовується тавро NN 1-4: Тавро N 1
