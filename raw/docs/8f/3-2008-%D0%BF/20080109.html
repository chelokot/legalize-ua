КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 січня 2008 р. N 3 Київ

Про скорочення посад заступників Міністра України у справах сім'ї, молоді та спорту

Кабінет Міністрів України постановляє:

1. Скоротити дві посади заступників Міністра України у справах сім'ї, молоді та спорту.

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України від 18 жовтня 2006 р. N 1447 ( 1447-2006-п ) (Офіційний вісник України, 2006 р., N 42, ст. 2818) і від 21 березня 2007 р. N 485 ( 485-2007-п ) (Офіційний вісник України, 2007 р., N 22, ст. 859).
