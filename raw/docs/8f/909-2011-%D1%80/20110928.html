Кабінет Міністрів України; Розпорядження від 28.09.2011 № 909-р

Про внесення змін до розпоряджень Кабінету Міністрів України від 27 липня 2011 р. N 761 і від 22 серпня 2011 р. N 848

Стан: Чинний

Ідентифікатор: 909-2011-р

Текст документа від 28.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 вересня 2011 р. N 909-р Київ

Про внесення змін до розпоряджень Кабінету Міністрів України від 27 липня 2011 р. N 761 і від 22 серпня 2011 р. N 848

Внести до розпоряджень Кабінету Міністрів України від 27 липня 2011 р. N 761 ( 761-2011-р ) "Деякі питання використання у 2011 році державних капітальних видатків" і від 22 серпня 2011 р. N 848 ( 848-2011-р ) "Про передачу у 2011 році деяких бюджетних призначень" зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 28 вересня 2011 р. N 909-р

ЗМІНИ, що вносяться до розпоряджень Кабінету Міністрів України від 27 липня 2011 р. N 761 ( 761-2011-р ) і від 22 серпня 2011 р. N 848 ( 848-2011-р )

1. У пункті 1 розпорядження Кабінету Міністрів України від 27 липня 2011 р. N 761 ( 761-2011-р ):

абзац четвертий підпункту 2 викласти в такій редакції:

"15000 тис. - для виконання робіт з реконструкції будівлі і споруд Українського науково-практичного центру ендокринної хірургії, трансплантації ендокринних органів і тканин Міністерства охорони здоров'я (м. Київ);";

абзац перший та другий підпункту 23 викласти в такій редакції:

"23) Донецькій облдержадміністрації - 39700 тис. гривень, з них:

30000 тис. - для реконструкції стадіону "Металург" (м. Артемівськ);";

підпункт 26 викласти в такій редакції:

"26) Івано-Франківській облдержадміністрації - 35000 тис. гривень, з них:

30000 тис. - для будівництва мостового переходу на км 103 + 555 автомобільної дороги державного значення Стрий - Чернівці - Мамалига;

5000 тис. - для реконструкції вул. Січових Стрільців у м. Коломиї;".

2. Підпункт 1 пункту 1 розпорядження Кабінету Міністрів України від 22 серпня 2011 р. N 848 ( 848-2011-р ) викласти в такій редакції:

"1) Державній судовій адміністрації - 3000 тис. гривень для проведення капітального ремонту приміщень, з них:

Вінницькому апеляційному адміністративному суду - 1000 тис. гривень;

Одеському окружному адміністративному суду - 1000 тис. гривень;

окружному адміністративному суду Автономної Республіки Крим - 1000 тис. гривень;".
