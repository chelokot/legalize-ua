КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 грудня 2005 р. N 1186 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 700 ( 700-2014-п ) від 10.12.2014 }

Про внесення зміни до пункту 3 постанови Кабінету Міністрів України від 3 березня 2005 р. N 174

Кабінет Міністрів України постановляє:

В абзаці першому пункту 3 постанови Кабінету Міністрів України від 3 березня 2005 р. N 174 ( 174-2005-п ) "Деякі питання координації діяльності органів виконавчої влади у сфері європейської інтеграції" (Офіційний вісник України, 2005 р., N 9, ст. 475, N 15, ст. 778) слова і цифри "чисельність працівників якого збільшується до 50 осіб" виключити.
