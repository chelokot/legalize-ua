Кабінет Міністрів України; Постанова від 16.10.1997 № 1149

Про внесення змін до складу Міжвідомчої комісії з питань регулювання закупівлі товарів (робіт, послуг) для державних потреб

Стан: Втратив чинність

Ідентифікатор: 1149-97-п

Текст документа від 07.05.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 жовтня 1997 р. N 1149 Київ

Про внесення змін до складу Міжвідомчої комісії з питань регулювання закупівлі товарів (робіт, послуг) для державних потреб

( Із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

( У назві і тексті слово "товарів" замінено словами "товарів (робіт, послуг)" згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

Кабінет Міністрів України постановляє:

Затвердити головою Міжвідомчої комісії з питань регулювання закупівлі товарів (робіт, послуг) для державних потреб, утвореної постановою Кабінету Міністрів України від 4 червня 1996 р. N 611 ( 611-96-п ), Суслова Віктора Івановича - Міністра економіки, увільнивши від цих обов'язків Єханурова Юрія Івановича.
