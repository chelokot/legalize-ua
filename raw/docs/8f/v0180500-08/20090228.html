{ Постанова втратила чинність на підставі Постанови Національного банку N 100 ( v0100500-09 ) від 28.02.2009 }

Про внесення зміни до постанови Правління Національного банку України від 06.03.2001 N 96

Керуючись статтею 44 Закону України "Про Національний банк України" ( 679-14 ) та з метою подальшого вдосконалення порядку здійснення Європейським банком реконструкції та розвитку (далі - ЄБРР) операцій за кореспондентським рахунком у гривнях, відкритим у Закритому акціонерному товаристві "Перший Український Міжнародний банк" для проведення ЄБРР діяльності в Україні згідно з Угодою про заснування Європейського банку реконструкції та розвитку від 29.05.90 ( 995_062 ), Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Пункт 1 постанови Правління Національного банку України від 06.03.2001 N 96 ( v0096500-01 ) "Про порядок проведення операцій за кореспондентським рахунком у гривнях, який відкрито ЄБРР у Першому українському міжнародному банку" доповнити абзацом четвертим такого змісту:

"Уповноважений банк здійснює зарахування коштів, перерахованих ЄБРР від імені резидента-позичальника на рахунок постійного представництва нерезидента в Україні, за договором резидента-позичальника з нерезидентом-отримувачем коштів, згідно з яким розрахунки з нерезидентом здійснюються через постійне представництво цього нерезидента в Україні, в порядку, установленому абзацами другим та третім цього пункту".

2. Департаменту валютного регулювання (О.А.Щербакова) довести зміст цієї постанови до відома територіальних управлінь Національного банку України та банків України для використання в роботі.

3. Контроль за виконанням цієї постанови покласти на Управління Національного банку України в Донецькій області (Ю.М.Чифільов).

4. Постанова набирає чинності з дня її підписання.

Голова В.С.Стельмах
