Про внесення зміни до Постанови Верховної Ради України від 21 грудня 2000 року "Про продовження терміну використання житлових чеків для приватизації державного житлового фонду"

( Відомості Верховної Ради України (ВВР), 2006, N 49, ст.495 )

Верховна Рада України постановляє:

1. У пункті 1 Постанови Верховної Ради України від 21 грудня 2000 року "Про продовження терміну використання житлових чеків для приватизації державного житлового фонду" ( 2160-14 ) (Відомості Верховної Ради України, 2001 р., N 4, ст. 26; 2003 р., N 7, ст. 74) цифри і слова "до 31 грудня 2006 року" замінити цифрами і словами "до 31 грудня 2008 року".

2. Ця Постанова набирає чинності з дня її опублікування.
