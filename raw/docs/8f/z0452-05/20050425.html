ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З НАГЛЯДУ ЗА ОХОРОНОЮ ПРАЦІ

НАКАЗ

25.04.2005 N 64

Зареєстровано в Міністерстві юстиції України 29 квітня 2005 р. за N 452/10732

Про втрату чинності наказу від 10.11.98 N 215

З метою удосконалення законодавства про охорону праці, у зв'язку із набранням чинності постановою Кабінету Міністрів України від 26 травня 2004 року N 687 ( 687-2004-п ) "Про затвердження Порядку проведення огляду, випробування та експертного обстеження (технічного діагностування) машин, механізмів, устатковання підвищеної небезпеки" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Держнаглядохоронпраці України від 10.11.98 N 215 ( z0740-98 ) "Про затвердження Порядку проведення експертного обстеження ліфтів", зареєстрований у Міністерстві юстиції України 20.11.98 за N 740/3180.

2. Начальнику управління організації державного нагляду в металургії, енергетиці, будівництві та котлонагляду (Іванченко В.І.) подати цей наказ до Міністерства юстиції України для державної реєстрації.

3. Управлінню нормативно-правового та юридичного забезпечення (Калиновська І.Г.) унести цей наказ до Державного реєстру нормативно-правових актів з охорони праці.

4. Контроль за виконанням наказу покласти на заступника Голови Комітету Плетньова В.А.
