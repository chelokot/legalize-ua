КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 квітня 1995 р. N 263 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

{ Постанова втратила чинність на підставі Постанови КМ N 619 ( 619-2012-п ) від 11.07.2012 }

Про внесення зміни до пункту 6 постанови Кабінету Міністрів України від 11 червня 1994 р. N 383

Кабінет Міністрів України постановляє:

Пункт 6 постанови Кабінету Міністрів України від 11 червня 1994 р. N 383 ( 383-94-п ) "Питання Державного комітету по матеріальних резервах" викласти у такій редакції:

"6. Визнати таким, що втратило чинність, Положення про Державний комітет України по матеріальних резервах, затверджене постановою Кабінету Міністрів України від 27 травня 1992 р. N 280-05".
