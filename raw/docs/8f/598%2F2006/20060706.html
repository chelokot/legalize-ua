Текст документа від 06.07.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення зміни до Указу Президента України від 3 травня 2006 року N 332

На часткову зміну Указу Президента України від 3 травня 2006 року N 332 ( 332/2006 ) вважати ЧУПРУНА Вадима Прокоповича звільненим з посади голови Донецької обласної державної адміністрації згідно з поданою ним заявою.

Президент України В.ЮЩЕНКО
