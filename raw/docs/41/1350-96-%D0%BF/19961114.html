Про забезпечення діяльності Конституційного Суду України

{ Із змінами, внесеними згідно з Постановою КМ N 1383 ( 1383-96-п ) від 14.11.96 }

З метою забезпечення діяльності Конституційного Суду України, реалізації матеріальних та інших гарантій, що надаються суддям Конституційного Суду України, їх соціального захисту, відповідно до статті 9 розділу IV Закону України "Про Конституційний Суд України" ( 422/96-ВР ) та на виконання розпорядження Президента України від 21 жовтня 1996 р. N 458 ( 458/96-рп ) Кабінет Міністрів України постановляє:

1. Міністерству юстиції забезпечити Бібліотеку Конституційного Суду України чинними актами законодавства (у тому числі і на магнітних носіях), прийнятими до 1 січня 1997 року.

{ Пункт 1 в редакції Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

{ Пункт 2 виключено на підставі Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

{ Пункт 3 виключено на підставі Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

2. Суддя Конституційного Суду України користується на території України правом безоплатного проїзду на залізничному, повітряному, автомобільному, водному та на всіх видах міського пасажирського транспорту (за винятком таксі), а також правом придбання проїзних документів поза чергою.

{ Абзац другий пункту виключено на підставі Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

Витрати, пов'язані із забезпеченням безоплатного проїзду суддів Конституційного Суду України, покриваються за рахунок Державного бюджету України.

{ Абзац четвертий пункту виключено на підставі Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

Суддя Конституційного Суду України має право безоплатного користування залами офіційних делегацій аеропортів, залізничних вокзалів і станцій, морських вокзалів (портів) і річкових вокзалів у порядку і на умовах, установлених для народних депутатів України.

{ Абзац шостий пункту 4 виключено на підставі Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

3. Суддя Конституційного Суду України має право користуватися службовим автомобілем як член Кабінету Міністрів України.

{ Пункт 6 виключено на підставі Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

{ Пункт 7 виключено на підставі Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

4. Усі види поштових та телеграфних відправлень судді Конституційного Суду України, за його бажанням, пересилаються (передаються), обробляються та доставляються як урядові.

{ Пункт 9 виключено на підставі Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

5. Державний захист суддів Конституційного Суду України, членів їх сімей та майна забезпечується Управлінням державної охорони України та Міністерством внутрішніх справ відповідно до чинного законодавства, у тому числі шляхом установлення найсучасніших засобів зв'язку та охоронної сигналізації в приміщеннях, де проживають судді та їх сім'ї.

{ Пункт із змінами, внесеними згідно з Постановою КМ N 1383 ( 1383-96-п ) від 14.11.96 }

6. Судді Конституційного Суду України, повноваження якого закінчились або достроково припинені у зв'язку з досягненням ним 65-річного віку чи поданням заяви про відставку, провадяться виплати відповідно до Закону України "Про статус суддів" ( 2862-12 ).

7. Суддя Конституційного Суду України при пред'явленні посвідчення судді Конституційного Суду України користується правом безперешкодного доступу на підприємства, в установи і організації, розташовані на території України, незалежно від їх підпорядкованості, форм власності.

{ Пункт із змінами, внесеними згідно з Постановою КМ N 1383 ( 1383-96-п ) від 14.11.96 }

{ Абзац другий пункту 12 виключено на підставі Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

8. За умовами оплати праці, матеріально-побутового, медичного, санаторно-курортного та транспортного забезпечення працівників Секретаріату Конституційного Суду України прирівняти до відповідних категорій працівників апарату Кабінету Міністрів України.

{ Абзац другий пункту 13 виключено на підставі Постанови КМ N 1383 ( 1383-96-п ) від 14.11.96 }

9. Міністерству економіки та Міністерству фінансів за поданням Голови Конституційного Суду України передбачати з 1997 року централізовані капітальні вкладення на створення матеріально-технічної бази Конституційного Суду України.

10. Міністерству фінансів під час доопрацювання проекту державного бюджету на 1997 рік та його розроблення на наступні роки передбачати окремою статтею витрати на утримання Конституційного Суду України, включаючи видатки, передбачені цією постановою.
