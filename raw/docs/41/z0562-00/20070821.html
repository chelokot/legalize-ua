Текст документа від 21.08.2007:

ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

N 1691 від 14.08.2000 Зареєстровано в Міністерстві м. Київ юстиції України 30 серпня 2000 р. за N 562/4783

Про затвердження Положення про порядок передприватизаційної підготовки підприємств, у статутних фондах яких є державна частка

{ Із змінами, внесеними згідно з Наказом Фонду державного майна

N 1229 ( z0926-07 ) від 24.07.2007 }

З метою забезпечення реалізації завдань, установлених Державною програмою приватизації на 2000-2002 роки, затвердженою Законом України "Про державну програму приватизації" ( 1723-14 ), НАКАЗУЮ:

1. Затвердити Положення про порядок передприватизаційної підготовки підприємств, у статутних фондах яких є державна частка (додається).

2. Директору Департаменту реформування підприємств агропромислового комплексу Чорноіванову В.В. забезпечити державну реєстрацію Положення, зазначеного в пункті 1 цього наказу, в Міністерстві юстиції України. Після державної реєстрації цього наказу забезпечити подання його до редакційно-видавничого відділу для опублікування в Державному інформаційному бюлетені про приватизацію.

3. Контроль за виконанням цього наказу покласти на заступника Голови Фонду В.Васильєва.

Голова Фонду О.Бондар

{ Положення про порядок передприватизаційної підготовки підприємств, у статутних фондах яких є державна частка втратило чинність на підставі Наказу Фонду державного майна N 1229 ( z0926-07 ) від 24.07.2007 }
