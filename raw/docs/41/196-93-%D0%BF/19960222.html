Про граничну чисельність працівників Державного комітету по земельних ресурсах та його місцевих органів

Текст документа від 22.02.1996:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 березня 1993 р. N 196 Київ

( Постанова втратила чинність на підставі Постанови КМ N 234 ( 234-96-п ) від 22.02.96 )

Про граничну чисельність працівників Державного комітету по земельних ресурсах та його місцевих органів

Ураховуючи збільшення обсягів робіт, пов'язаних з проведенням земельної реформи в умовах рівноправного розвитку різних форм власності на землю, Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. Установити граничну чисельність працівників центрального апарату Державного комітету по земельних ресурсах у кількості 100 одиниць та його місцевих органів - 2875 одиниць.

2. Визнати таким, що втратив чинність, пункт 2 постанови Кабінету Міністрів України від 22 червня 1992 р. N 345 ( 345-92-п ) "Питання Державного комітету України по земельних ресурсах" (ЗП України, 1992 р., N 7, ст.161).
