Про керівників деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

Стан: Втратив чинність

Ідентифікатор: 473-2005-р

Текст документа від 26.07.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 листопада 2005 р. N 473-р Київ

Про керівників деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 1016 ( 1016-2006-п ) від 26.07.2006 }

1. Затвердити:

1) Прем'єр-міністра України головою Координаційної ради з адаптації законодавства України до законодавства Європейського Союзу ( 1365-2004-п );

2) Першого віце-прем'єр-міністра України:

головою:

- Державної комісії з питань техногенно-екологічної безпеки та надзвичайних ситуацій ( 174-98-п );

- Міжвідомчої комісії з організації укладення та виконання угод про розподіл продукції ( 1119-2000-п );

- Міжвідомчої комісії з питань забезпечення ефективного і безпечного функціонування авіаційного транспорту, авіаційної промисловості, авіації загального призначення та системи використання повітряного простору України ( 1923-2000-п );

- Комісії з організації діяльності технологічних парків та інноваційних структур інших типів ( 961-2001-п );

- Ради стандартизації та технічного регулювання ( 484-2002-п ); { Абзац сьомий підпункту 2 пункту 1 в редакції Постанови КМ N 1016 ( 1016-2006-п ) від 26.07.2006 }

- Міжвідомчої комісії з питань транспортних коридорів та транзитної політики ( 965-2002-п );

- Координаційної ради з питань функціонування Єдиної державної інформаційної системи у сфері запобігання та протидії легалізації (відмиванню) доходів, одержаних злочинним шляхом, і фінансуванню тероризму ( 1250-2004-п );

- Міжвідомчої комісії з комплексного розв'язання проблем Чорнобильської АЕС ( 1926-2002-п );

- Національної ради з питань безпечної життєдіяльності населення ( 733-93-п );

- Міжвідомчої координаційної ради з питань боротьби з контрабандою ( 173-2005-п );

керівником робочої групи з опрацювання питань функціонування ринку нафти і нафтопродуктів та розвитку нафтопереробної промисловості ( 305-2005-р );

3) Віце-прем'єр-міністра України (питання регіональної політики) - головою:

Міжвідомчої комісії з питань місцевого самоврядування при Кабінеті Міністрів України ( 1000-98-п );

Міжвідомчої комісії з реалізації реформи житлово-комунального господарства ( 2194-99-п );

4) Віце-прем'єр-міністра України (питання гуманітарної і соціальної політики) - головою:

Національної координаційної ради боротьби з наркоманією при Кабінеті Міністрів України ( 968-95-п );

Державної надзвичайної протиепідемічної комісії при Кабінеті Міністрів України ( 22-2004-п );

Комісії з питань гуманітарної допомоги при Кабінеті Міністрів України ( 553-2000-п );

наглядової ради Українського фонду соціальних інвестицій ( 234-2000-р );

Комітету з присудження Премії Кабінету Міністрів України за внесок молоді у розбудову держави ( 951-2000-п );

Урядової комісії з вивчення діяльності ОУН-УПА ( 1004-97-п );

Міжвідомчої комісії по боротьбі з туберкульозом ( 1480-2000-п );

спостережної ради Українського національного фонду "Взаєморозуміння і примирення" при Кабінеті Міністрів України ( 1410-2000-п );

Міжвідомчої ради з питань вивезення, ввезення та повернення культурних цінностей ( 587-2003-п );

Міжвідомчої ради з питань захисту прав споживачів ( 317-2002-п );

наглядової ради з питань реалізації спільного із Світовим банком проекту "Контроль за туберкульозом та ВІЛ/СНІДом в Україні" ( 971-2002-п );

Ради з питань реклами ( 2016-2003-п );

Комісії з розгляду питань нагородження Почесною грамотою Кабінету Міністрів України ( 2021-2003-п );

Національної координаційної ради з питань запобігання поширенню ВІЛ-інфекції/СНІДу ( 352-2005-п );

Координаційного комітету з проведення загальнонаціональної акції "Відродимо Хортицю!" ( 441-2005-п );

5) Віце-прем'єр-міністра України (питання розвитку агропромислового комплексу та природокористування) - головою:

Міжвідомчої координаційної комісії з питань підтримки індивідуального житлового будівництва на селі ( 376-97-п );

Міжвідомчої комісії із забезпечення виконання Рамкової конвенції ООН про зміну клімату ( 583-99-п );

Координаційної ради з питань аграрної політики ( 1605-2001-п );

Міжвідомчої експертної ради з питань визначення пріоритетів у виробництві нової техніки та обладнання для сільськогосподарських товаровиробників ( 498-2003-р ).

2. Увільнити Кінаха Анатолія Кириловича, Рибачука Олега Борисовича, Азарова Миколу Яновича, Томенка Миколу Володимировича, Табачника Дмитра Володимировича, Кириленка Івана Григоровича, Клюєва Андрія Петровича від обов'язків керівників органів, зазначених у пункті 1 цього розпорядження.
