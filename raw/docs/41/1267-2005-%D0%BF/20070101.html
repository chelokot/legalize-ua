Кабінет Міністрів України; Постанова від 23.12.2005 № 1267

Деякі питання Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

Стан: Втратив чинність

Ідентифікатор: 1267-2005-п

Текст документа від 01.01.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 грудня 2005 р. N 1267 Київ

Деякі питання Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

{ Із змінами, внесеними згідно з Постановами КМ N 363 ( 363-2006-п ) від 25.03.2006 N 1319 ( 1319-2006-п ) від 18.09.2006 N 1421 ( 1421-2006-п ) від 18.10.2006 }

Кабінет Міністрів України постановляє:

1. Затвердити граничну чисельність працівників Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи:

центрального апарату Міністерства у кількості 586 осіб, у тому числі 175 осіб начальницького складу; { Абзац другий пункту 1 із змінами, внесеними згідно з Постановами КМ N 363 ( 363-2006-п ) від 25.03.2006, N 1319 ( 1319-2006-п ) від 18.09.2006, N 1421 ( 1421-2006-п ) від 18.10.2006 }

територіальних органів Міністерства в Автономній Республіці Крим, областях, мм. Києві та Севастополі, районів, міст та районів у містах у кількості 8869 осіб, у тому числі 6305 осіб начальницького складу. { Абзац третій пункту 1 із змінами, внесеними згідно з Постановою КМ N 1319 ( 1319-2006-п ) від 18.09.2006 }

2. Внести у додатки до постанов Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851; 2002 р., N 51, ст. 2301; 2004 р., N 8, ст. 481; 2005 р., N 28, ст. 1625) та від 2 квітня 2001 р. N 314 ( 314-2001-п ) "Про встановлення ліміту легкових автомобілів, що обслуговують державні органи" (Офіційний вісник України, 2001 р., N 14, ст. 602; 2002 р., N 51, ст. 2301; 2004 р., N 30, ст. 2018) зміни, що додаються.

3. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 26 квітня 2003 р. N 637 ( 637-2003-п ) "Про граничну чисельність працівників центрального апарату Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" (Офіційний вісник України, 2003 р., N 18-19, ст. 850);

постанову Кабінету Міністрів України від 30 грудня 2003 р. N 2075 ( 2075-2003-п ) "Про забезпечення виконання державних програм соціального захисту населення, постраждалого внаслідок Чорнобильської катастрофи" (Офіційний вісник України, 2003 р., N 52, ст. 2821).

4. Міністерству фінансів вирішити в установленому порядку питання щодо фінансування утримання Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Міністерства палива та енергетики, Міністерства охорони навколишнього природного середовища з урахуванням змін, внесених цією постановою.
