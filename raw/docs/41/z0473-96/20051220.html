N 85 від 08.08.96 Зареєстровано в Міністерстві м.Київ юстиції України 23 серпня 1996 р. vd960808 vn85 за N 473/1498

( Наказ втратив чинність на підставі Наказу Державного комітету лісового господарства N 493 ( z1484-05 ) від 24.11.2005 )

Про затвердження вартості ліцензій для полювання в мисливських угіддях України для громадян України та іноземних громадян

Згідно з Положенням про мисливське господарство та порядок здійснення полювання, затвердженого постановою Кабінету Міністрів України від 20 липня 1996 року N 780 ( 780-96-п ), НАКАЗУЮ:

1. Затвердити погоджену з Міністерством фінансів України вартість ліцензій для полювання в мисливських угіддях України на ведмедя, кабана, лань, оленів благородного та плямистого, козулю, лося, муфлона для громадян України та іноземних громадян, що додається.

2. Начальникам обласних управлінь лісового господарства, генеральним директорам державних лісогосподарських об'єднань довести цей наказ до відома всіх користувачів мисливських угідь області.

3. Вартість ліцензій для спортивного полювання, затверджену Мінлісгоспом України 26 липня 1995 року скасувати як таку, що не пройшла державної реєстрації.

4. Контроль за виконанням наказу покласти на начальника управління мисливського господарства Шадуру М.В.

Міністр В.І.Самоплавський

Затверджено наказом Мінлісгоспу України від 8 серпня 1996 року N 85

Вводиться в дію з 3 вересня 1996 року.

II. Розрахунки з мисливцями за ліцензії проводяться в національній валюті України перед початком полювання.
