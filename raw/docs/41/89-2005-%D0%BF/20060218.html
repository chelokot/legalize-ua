Кабінет Міністрів України; Постанова, Порядок від 22.01.2005 № 89

Про затвердження Порядку зарахування та використання надходжень від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію

Стан: Втратив чинність

Ідентифікатор: 89-2005-п

Текст документа від 18.02.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 січня 2005 р. N 89 Київ

Про затвердження Порядку зарахування та використання надходжень від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію

( Із змінами, внесеними згідно з Постановами КМ N 432 ( 432-2005-п ) від 08.06.2005 N 163 ( 163-2006-п ) від 18.02.2006 )

Відповідно до пунктів 3-5, 7, 9, 45, 48, 49 статті 43 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

( Вступна частина із змінами, внесеними згідно з Постановою КМ N 432 ( 432-2005-п ) від 08.06.2005; в редакції Постанови КМ N 163 ( 163-2006-п ) від 18.02.2006 )

1. Затвердити Порядок зарахування та використання надходжень від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію (додається).

2. Взяти до відома, що Національна комісія регулювання електроенергетики:

1) установить розмір збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію (далі - збір) для державного підприємства "Енергоринок" та усіх виробників електричної енергії, які мають ліцензію на право провадження такої підприємницької діяльності та продають електричну енергію поза оптовим ринком електричної енергії;

2) внесе відповідні зміни до алгоритму розподілу коштів з поточного рахунка із спеціальним режимом використання оптового постачальника електричної енергії з урахуванням того, що державне підприємство "Енергоринок" сплачує збір виходячи з фактично оплачених обсягів електричної енергії не пізніше наступного дня після отримання плати за них. ( Підпункт 2 пункту 2 в редакції Постанови КМ N 432 ( 432-2005-п ) від 08.06.2005; із змінами, внесеними згідно з Постановою КМ N 163 ( 163-2006-п ) від 18.02.2006 )

3. Міністерству палива та енергетики разом з Національною комісією регулювання електроенергетики подати в місячний строк в установленому порядку Кабінетові Міністрів України перелік об'єктів, на будівництво яких спрямовуватимуться кошти, що надійдуть від збору в 2006 році.

Міністерству промислової політики за погодженням з Національною комісією регулювання електроенергетики визначити в місячний строк перелік об'єктів, на будівництво яких відповідно до пункту 3 статті 43 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) спрямовуватимуться кошти, що надійдуть від збору в 2005 році. ( Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 432 ( 432-2005-п ) від 08.06.2005 )

( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 163 ( 163-2006-п ) від 18.02.2006 )

4. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 26 грудня 2003 р. N 2043 ( 2043-2003-п ) "Про затвердження Порядку використання надходжень від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію" (Офіційний вісник України, 2003 р., N 52, ст. 2811).

Виконуючий обов'язки Прем'єр-міністра України М.АЗАРОВ

Інд. 37

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 22 січня 2005 р. N 89

ПОРЯДОК зарахування та використання надходжень від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію

1. Цей Порядок визначає механізм зарахування та використання у 2006 році коштів за бюджетними програмами, джерелом яких є кошти, що надійшли від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію (далі - збір).

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 163 ( 163-2006-п ) від 18.02.2006 )

2. Надходження від збору зараховуються:

з поточного рахунка із спеціальним режимом використання оптового постачальника електричної енергії на рахунок, відкритий в управлінні Державного казначейства у м. Києві за балансовим рахунком 3121 "Надходження коштів спеціального фонду державного бюджету, які спрямовуються на спеціальні видатки", за кодом класифікації доходів бюджету 24120000 "Збір у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію";

з поточних рахунків виробників електричної енергії, які мають ліцензію на право провадження такої підприємницької діяльності та продають електричну енергію поза оптовим ринком електричної енергії, на рахунки, відкриті у відповідних управліннях Державного казначейства за балансовим рахунком 3121 "Надходження коштів спеціального фонду державного бюджету, які спрямовуються на спеціальні видатки", за кодом класифікації доходів бюджету 24120000 "Збір у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію".

3. Під час перерахування коштів від збору державним підприємством "Енергоринок" виробниками електричної енергії, які мають ліцензію на право провадження такої підприємницької діяльності та продають електричну енергію поза оптовим ринком електричної енергії, в платіжному дорученні у графі "Призначення платежу" зазначається "Кошти від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію".

4. Кошти, що надійшли від збору, використовуються відповідно до порядку касового виконання державного бюджету за видатками та в межах, передбачених помісячним розписом спеціального фонду державного бюджету за напрямами, визначеними паспортами, що складені за кожною бюджетною програмою, джерелом якої є кошти збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію, згідно з кошторисами і планами використання бюджетних коштів.

5. Головні розпорядники коштів:

включають підприємства та організації, визначені замовниками робіт за відповідними напрямами, що передбачені пунктів 3-5, 7, 9 45, 48, 49 статті 43 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ), до мережі юридичних осіб як одержувачів бюджетних коштів; ( Абзац другий пункту 5 із змінами, внесеними згідно з Постановами КМ N 432 ( 432-2005-п ) від 08.06.2005, N 163 ( 163-2006-п ) від 18.02.2006 )

розподіляють асигнування спеціального фонду державного бюджету між одержувачами бюджетних коштів за кожною бюджетною програмою.
