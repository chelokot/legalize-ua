КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 січня 2005 р. N 89 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 260 ( 260-2019-п ) від 06.03.2019 }

Про затвердження Порядку зарахування та використання надходжень від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію

{ Із змінами, внесеними згідно з Постановами КМ N 432 ( 432-2005-п ) від 08.06.2005 N 163 ( 163-2006-п ) від 18.02.2006 N 208 ( 208-2007-п ) від 14.02.2007 N 332 ( 332-2008-п ) від 09.04.2008 N 344 ( 344-2009-п ) від 15.04.2009 }

Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 432 ( 432-2005-п ) від 08.06.2005; в редакції Постанов КМ N 163 ( 163-2006-п ) від 18.02.2006, N 208 ( 208-2007-п ) від 14.02.2007 }

1. Затвердити Порядок зарахування та використання надходжень від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію (додається).

2. Взяти до відома, що Національна комісія регулювання електроенергетики:

1) установить розмір збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію (далі - збір) для державного підприємства "Енергоринок" та усіх виробників електричної енергії, які мають ліцензію на право провадження такої підприємницької діяльності та продають електричну енергію поза оптовим ринком електричної енергії;

2) внесе відповідні зміни до алгоритму розподілу коштів з поточного рахунка із спеціальним режимом використання оптового постачальника електричної енергії з урахуванням того, що державне підприємство "Енергоринок" сплачує збір виходячи з фактично оплачених обсягів електричної енергії, крім обсягу заборгованості, що погашається згідно із Законом України "Про заходи, спрямовані на забезпечення сталого функціонування підприємств паливно-енергетичного комплексу ( 2711-15 ), не пізніше наступного дня після отримання плати за них. { Підпункт 2 пункту 2 в редакції Постанови КМ N 432 ( 432-2005-п ) від 08.06.2005; із змінами, внесеними згідно з Постановами КМ N 163 ( 163-2006-п ) від 18.02.2006, N 208 ( 208-2007-п ) від 14.02.2007 }

3. { Абзац перший пункту 3 виключено на підставі Постанови КМ N 208 ( 208-2007-п ) від 14.02.2007 }

Міністерству промислової політики за погодженням з Національною комісією регулювання електроенергетики визначити в місячний строк перелік об'єктів, на будівництво яких відповідно до пункту 3 статті 40 Закону України "Про Державний бюджет України на 2007 рік" ( 489-16 ) спрямовуватимуться кошти, що надійдуть від збору в 2005 році. { Абзац другий пункту 3 із змінами, внесеними згідно з Постановами КМ N 432 ( 432-2005-п ) від 08.06.2005, N 208 ( 208-2007-п ) від 14.02.2007 }

( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 163 ( 163-2006-п ) від 18.02.2006 )

4. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 26 грудня 2003 р. N 2043 ( 2043-2003-п ) "Про затвердження Порядку використання надходжень від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію" (Офіційний вісник України, 2003 р., N 52, ст. 2811).

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 22 січня 2005 р. N 89

ПОРЯДОК зарахування та використання надходжень від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію

1. Цей Порядок визначає механізм зарахування та використання у 2009 році коштів за бюджетними програмами, джерелом яких є кошти, що надійшли від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію (далі - збір).

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 163 ( 163-2006-п ) від 18.02.2006, N 208 ( 208-2007-п ) від 14.02.2007, N 332 ( 332-2008-п ) від 09.04.2008, N 344 ( 344-2009-п ) від 15.04.2009 }

2. Надходження від збору, крім надходжень від сплати за зобов'язаннями державного підприємства "Енергоринок" перед державним бюджетом із збору за минулі роки в обсязі 160000 тис. гривень, зараховуються: { Абзац перший пункту 2 в редакції Постанови КМ N 332 ( 332-2008-п ) від 09.04.2008; із змінами, внесеними згідно з Постановою КМ N 344 ( 344-2009-п ) від 15.04.2009 }

з поточного рахунка із спеціальним режимом використання оптового постачальника електричної енергії на рахунок, відкритий в управлінні Державного казначейства у м. Києві за балансовим рахунком 3121 "Надходження коштів спеціального фонду державного бюджету, які спрямовуються на спеціальні видатки", за кодом класифікації доходів бюджету 24120000 "Збір у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію";

з поточних рахунків виробників електричної енергії, які мають ліцензію на право провадження такої підприємницької діяльності та продають електричну енергію поза оптовим ринком електричної енергії, на рахунки, відкриті у відповідних управліннях Державного казначейства за балансовим рахунком 3121 "Надходження коштів спеціального фонду державного бюджету, які спрямовуються на спеціальні видатки", за кодом класифікації доходів бюджету 24120000 "Збір у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію".

2-1. Сплата за зобов'язаннями державного підприємства "Енергоринок" перед державним бюджетом із збору за минулі роки проводиться з поточного рахунка із спеціальним режимом використання оптового постачальника електричної енергії на рахунок, відкритий в управлінні Державного казначейства у м. Києві за балансовим рахунком 3121 "Надходження коштів спеціального фонду державного бюджету, які спрямовуються на спеціальні видатки", за кодом класифікації доходів бюджету 24120100 "Сплата зобов'язань державного підприємства "Енергоринок" перед державним бюджетом із збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію за минулі роки".

Під час перерахування коштів від збору державним підприємством "Енергоринок" відповідно до абзацу першого цього пункту в платіжному дорученні у графі "Призначення платежу" зазначається "Сплата зобов'язань державного підприємства "Енергоринок" перед державним бюджетом із збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію за минулі роки відповідно до пункту 5 статті 6 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ). { Абзац другий пункту 2-1 із змінами, внесеними згідно з Постановою КМ N 344 ( 344-2009-п ) від 15.04.2009 }

{ Порядок доповнено пунктом 2-1 згідно з Постановою КМ N 332 ( 332-2008-п ) від 09.04.2008 }

3. Під час перерахування коштів від збору державним підприємством "Енергоринок" і виробниками електричної енергії, які мають ліцензію на право провадження такої підприємницької діяльності та продають електричну енергію поза оптовим ринком електричної енергії, в платіжному дорученні у графі "Призначення платежу" зазначається "Кошти від збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію".

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 332 ( 332-2008-п ) від 09.04.2008 }

4. Кошти, що надійшли від збору, використовуються відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством, у межах, передбачених помісячним розписом спеціального фонду державного бюджету, за бюджетними програмами, джерелом яких є кошти збору у вигляді цільової надбавки до діючого тарифу на електричну та теплову енергію.
