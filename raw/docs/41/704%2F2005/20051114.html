Президент України; Указ від 21.04.2005 № 704/2005

Про вдосконалення контролю за виробництвом та обігом алкогольних напоїв і тютюнових виробів

Стан: Чинний

Ідентифікатор: 704/2005

Текст документа від 14.11.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про вдосконалення контролю за виробництвом та обігом алкогольних напоїв і тютюнових виробів

( Із змінами, внесеними згідно з Указом Президента N 1527/2005 ( 1527/2005 ) від 01.11.2005 )

( Статтю 1 виключено на підставі Указу Президента N 1527/2005 ( 1527/2005 ) від 01.11.2005 )

2. В абзаці одинадцятому пункту 1 статті 2 Указу Президента України від 27 грудня 2002 року N 1234 ( 1234/2002 ) "Про невідкладні заходи щодо забезпечення контролю за виробництвом та обігом спирту, алкогольних напоїв і тютюнових виробів" (зі змінами, внесеними Указами від 22 березня 2004 року N 351 ( 351/2004 ) та від 8 червня 2004 року N 628 ( 628/2004 ) слова "та обов'язкового захисту цих акцизних марок голографічними захисними елементами, виробник яких визначається в установленому порядку на конкурсних засадах" виключити.

3. Визнати таким, що втратив чинність, Указ Президента України від 22 березня 2004 року N 351 ( 351/2004 ) "Про внесення зміни до Указу Президента України від 27 грудня 2002 року N 1234".

4. Кабінету Міністрів України:

привести свої рішення у відповідність із цим Указом;

забезпечити приведення актів міністерств, інших центральних органів виконавчої влади у відповідність із цим Указом.

Президент України В.ЮЩЕНКО

м. Київ, 21 квітня 2005 року N 704/2005
