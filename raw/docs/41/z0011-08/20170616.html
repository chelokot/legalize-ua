Реєстрація: Мін'юст України від 11.01.2008 № 11/14702

Стан: Втратив чинність

Ідентифікатор: z0011-08

Текст документа від 16.06.2017:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ЗАТВЕРДЖЕНО Постанова Правління Національного банку України 17.12.2007 N 460 ( z0010-08 )

Зареєстровано в Міністерстві юстиції України 11 січня 2008 р. за N 11/14702

{ Зміни втратили чинність на підставі Постанови Національного банку N 53 ( v0053500-17 ) від 15.06.2017 }

ЗМІНИ до Переліку і тарифів на послуги, що надаються Національним банком України, який виконує функції Платіжної організації НСМЕП, членам та учасникам НСМЕП ( z0784-03 )

1. У колонці "Найменування послуг" у послузі під номером 10 слова "та учасникам", слова та цифру "(щорічно, за 1 рік)" виключити.
