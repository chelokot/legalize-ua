Національний банк; Постанова від 19.02.1999 № 70

Про закриття рахунків з обліку позабюджетних коштів бюджетних організацій, які утримуються з Державного бюджету України

Стан: Втратив чинність

Ідентифікатор: v0623500-99

Текст документа від 13.02.2009:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 70 від 19.02.99 Зареєстровано в юридичному м.Київ департаменті Нацбанку 23 лютого 1999 р. vd990219 vn70 за N 623

{ Постанова втратила чинність на підставі Постанови Національного банку N 73 ( v0073500-09 ) від 13.02.2009 }

Про закриття рахунків з обліку позабюджетних коштів бюджетних організацій, які утримуються з Державного бюджету України

{ Із змінами, внесеними згідно з Постановами Нацбанку N 226 ( v0226500-99 ) від 11.05.99 N 296 ( v0296500-99 ) від 22.06.99 }

На виконання Указу Президента України від 15.02.99 N 173 ( 173/99 ) "Про внесення змін до Указу Президента України від 27.04.95 N 335" та постанови Кабінету Міністрів України від 17.02.99 N 180 ( 180-99-п ) "Про деякі питання діяльності Державного казначейства України" Правління ПОСТАНОВЛЯЄ:

1. Установам Національного банку України та комерційних банків забезпечити за зверненнями клієнтів своєчасне закриття рахунків з обліку позабюджетних коштів, відкритих згідно з Планом рахунків бухгалтерського обліку комерційних банків України ( va493500-97 ) за балансовим рахунком N 2530 "Інші кошти клієнтів, які утримуються з Державного бюджету" та Планом рахунків бухгалтерського обліку Національного банку України за балансовим рахунком N 3530 "Інші кошти клієнтів, які утримуються з Державного бюджету".

2. Визначені у пункті 1 цієї постанови рахунки повинні закритися:

- Міністерством охорони здоров'я, його установами та організаціями - до 20 лютого 1999 р.;

- Державною податковою адміністрацією, її установами та організаціями - до 1 квітня 1999 р.;

- Державною митною службою, її установами та організаціями - до 1 липня 1999 р.;

- міністерствами, іншими центральними органами виконавчої влади, іншими установами та організаціями - до 1 вересня 1999 року.

Рахунки залишаються відкритими тільки для органів Державного казначейства України. ( Абзац пункту 2 із змінами, внесеними згідно з Постановами Нацбанку N 226 ( v0226500-99 ) від 11.05.99, N 296 ( v0296500-99 ) від 22.06.99 )

3. Заборонити відкриття клієнтам нових рахунків за балансовими рахунками N 2530 (КБ), N 3530 (НБУ) "Інші кошти клієнтів, які утримуються з Державного бюджету", крім органів Державного казначейства України. ( Пункт 3 із змінами, внесеними згідно з Постановами Нацбанку N 226 ( v0226500-99 ) від 11.05.99, N 296 ( v0296500-99 ) від 22.06.99 )

4. Контроль за виконанням цієї постанови покласти на Департамент платіжних систем (В.М.Кравець) та регіональні управління Національного банку України.

5. Постанова набуває чинності з часу її прийняття.

В.о.Голови В.С.Стельмах
