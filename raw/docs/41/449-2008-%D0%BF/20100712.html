Кабінет Міністрів України; Постанова, Порядок від 14.05.2008 № 449

Питання перерахування енергогенеруючими компаніями коштів до спеціального фонду державного бюджету та використання у 2008 році коштів за деякими бюджетними програмами

Стан: Чинний

Ідентифікатор: 449-2008-п

Текст документа від 12.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 травня 2008 р. N 449 Київ

Питання перерахування енергогенеруючими компаніями коштів до спеціального фонду державного бюджету та використання у 2008 році коштів за деякими бюджетними програмами

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

{ Із змінами, внесеними згідно з Постановами КМ N 883 ( 883-2009-п ) від 19.08.2009 N 1019 ( 1019-2009-п ) від 16.09.2009 N 534 ( 534-2010-п ) від 30.06.2010 }

Кабінет Міністрів України постановляє:

1. Установити, що передбачене статтею 74 Закону України "Про Державний бюджет України на 2008 рік та про внесення змін до деяких законодавчих актів України" ( 107-17 ) перерахування енергогенеруючими компаніями коштів до спеціального фонду державного бюджету у рахунок погашення заборгованості перед Державним комітетом з державного матеріального резерву за отримане у 1997-2000 роках згідно з рішеннями Кабінету Міністрів України органічне паливо та їх використання здійснюється відповідно до Порядку, затвердженого постановою Кабінету Міністрів України від 27 квітня 2006 р. N 597 ( 597-2006-п ) (Офіційний вісник України, 2006 р., N 18, ст. 1342), з посиланням у платіжному дорученні на зазначену статтю Закону.

2. Затвердити Порядок використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) з метою здешевлення кредитів на створення запасів твердого палива для теплоелектростанцій, що додається.

3. Рекомендувати Національній комісії регулювання електроенергетики здійснювати коригування кошторису державного підприємства "Енергоринок" на суму коштів, отриманих підприємством відповідно до цієї постанови.

{ Постанову доповнено пунктом 3 згідно з Постановою КМ N 883 ( 883-2009-п ) від 19.08.2009 }

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 37

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 травня 2008 р. N 449

ПОРЯДОК використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) з метою здешевлення кредитів на створення запасів твердого палива для теплоелектростанцій

1. Цей Порядок визначає механізм використання у 2010 році коштів, передбачених Мінпаливенерго за бюджетною програмою "Будівництво енергоблоків, атомних, гідроакумулюючих, інших електростанцій, теплоелектроцентралей, будівництво та реконструкція ліній електропередачі та підстанцій (у тому числі 150000 тис. гривень для об'єктів електроенергетики Автономної Республіки Крим), а також здешевлення кредитів на створення запасів твердого палива для теплоелектростанцій" у частині здешевлення кредитів на створення запасів твердого палива для теплоелектростанцій (далі - бюджетні кошти).

{ Пункт 1 в редакції Постанови КМ N 534 ( 534-2010-п ) від 30.06.2010 }

2. Бюджетні кошти використовуються для часткової компенсації відсоткової ставки за залученими кредитами, зазначеними у пункті 1 цього Порядку (далі - компенсація), з метою створення на 1 листопада 2010 р. запасів твердого палива на теплоелектростанціях в обсягах, необхідних для забезпечення їх сталої роботи в осінньозимовий період 2010/11 року.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 883 ( 883-2009-п ) від 19.08.2009; в редакції Постанови КМ N 534 ( 534-2010-п ) від 30.06.2010 }

3. Компенсація виплачується відповідно до укладених договорів:

енергогенеруючим компаніям, у статутних фондах яких більш як 50 відсотків акцій (часток, паїв) належить державі, для створення запасів твердого палива для теплоелектростанцій згідно із затвердженим Мінпаливенерго переліком за умови, що вироблена ними електрична енергія продається на оптовому ринку електричної енергії України;

державному підприємству "Енергоринок" за кредитами, залученими з грудня 2009 р. у ВАТ "Державний ощадний банк України" з метою проведення розрахунків за паливо для задоволення потреб енергогенеруючих компаній. { Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 534 ( 534-2010-п ) від 30.06.2010 }

{ Пункт 3 в редакції Постанови КМ N 883 ( 883-2009-п ) від 19.08.2009 }

4. Для отримання компенсації енергогенеруюча компанія подає Мінпаливенерго:

затверджений її керівником розрахунок необхідного помісячного обсягу запасів твердого палива у кількісному та вартісному виразі, в тому числі обсягу, що буде придбаватися за рахунок кредитів, відсоткова ставка за якими частково компенсуватиметься за рахунок бюджетних коштів;

засвідчені в установленому порядку копії укладених з банком цільових кредитних договорів на придбання твердого палива;

копії довідок-розрахунків банку про суму відсотків за користування цільовими кредитами протягом відповідного періоду;

довідки про надання кредитів, видані банком;

розрахунок суми компенсації за залученими кредитами, виданий банком;

платіжні доручення про оплату з використанням кредитних коштів поставленого твердого палива з посиланням на відповідні розрахунки;

довідку про обсяги і вартість твердого палива, придбаного за кредитні кошти;

засвідчені підписом керівника та скріплені печаткою копії актів про рух і залишки палива та актів інвентаризації складів теплоелектростанцій компанії;

реєстри і копії актів приймання за кількістю та якістю твердого палива разом з транспортними документами і комерційними актами;

щомісяця до 7 числа наступного періоду, а за грудень - до 25 грудня документи, що підтверджують стан погашення кредитів і відсотків за користування ними, у тому числі розмір виплаченої компенсації.

{ Пункт 4 в редакції Постанови КМ N 534 ( 534-2010-п ) від 30.06.2010 }

5. Для отримання компенсації державне підприємство "Енергоринок" подає Мінпаливенерго такі документи:

копію укладеного з ВАТ "Державний ощадний банк України" кредитного договору про залучення коштів з метою проведення розрахунків за паливо для задоволення потреб енергогенеруючих компаній, засвідчену підписом та скріплену печаткою;

копію постанови НКРЕ про перерахування коштів енергогенеруючим компаніям для проведення розрахунків за паливо;

копії платіжних доручень на перерахування коштів, залучених у ВАТ "Державний ощадний банк України" відповідно до постанов НКРЕ, на поточні рахунки енергогенеруючих компаній;

копію довідки-розрахунку банку про суму відсотків за користування цільовим кредитом протягом відповідного періоду;

довідку банку про надання кредиту;

розрахунок компенсації за кредитами, залученими у ВАТ "Державний ощадний банк України" відповідно до постанов НКРЕ, за формою, затвердженою Мінпаливенерго. До суми компенсації не включаються суми штрафних санкцій та/або інших боргових зобов'язань за кредитами. { Абзац сьомий пункту 5 в редакції Постанови КМ N 1019 ( 1019-2009-п ) від 16.09.2009 }

Енергогенеруюча компанія подає Мінпаливенерго:

звіт про використання коштів, отриманих відповідно до постанов НКРЕ, та копії платіжних доручень на перерахування компанією коштів за тверде паливо, засвідчені підписом та скріплені печаткою;

копії актів приймання-передачі твердого палива, розрахунки за яке проведено за рахунок отриманих від державного підприємства "Енергоринок" відповідно до постанов НКРЕ коштів, засвідчені підписом та скріплені печаткою;

засвідчені підписом керівника та скріплені печаткою копії актів про рух і залишки палива та актів інвентаризації складів теплоелектростанцій компанії. { Абзац пункту 5 в редакції Постанови КМ N 534 ( 534-2010-п ) від 30.06.2010 }

{ Пункт 5 в редакції Постанови КМ N 883 ( 883-2009-п ) від 19.08.2009 }

6. Мінпаливенерго:

1) приймає на підставі документів, зазначених у пункті 4 цього Порядку, рішення щодо виділення бюджетних коштів для виплати компенсації та визначає їх одержувача;

2) проводить на підставі документів, зазначених у пункті 5 цього Порядку, розрахунок компенсації відсоткової ставки державного підприємства "Енергоринок" за кредитами, залученими у ВАТ "Державний ощадний банк України" з метою проведення розрахунків за паливо для задоволення потреб енергогенеруючих компаній, та приймає рішення щодо виділення бюджетних коштів для виплати компенсації. { Абзац перший підпункту 2 пункту 6 із змінами, внесеними згідно з Постановою КМ N 534 ( 534-2010-п ) від 30.06.2010 }

Компенсація відсоткової ставки державного підприємства "Енергоринок" розраховується виходячи з суми компенсації відсоткової ставки підприємства та коштів, фактично спрямованих енергогенеруючою компанією на проведення розрахунків за вугілля, в загальному обсязі залучених підприємством кредитних коштів.

Видатки, необхідні для проведення компенсаційних виплат, здійснюються шляхом перерахування бюджетних коштів з реєстраційного рахунка Мінпаливенерго на відкриті в банках поточні рахунки енергогенеруючих компаній та державного підприємства "Енергоринок".

{ Пункт 6 в редакції Постанови КМ N 883 ( 883-2009-п ) від 19.08.2009 }

6-1. Компенсація виплачується в розмірі подвійної облікової ставки Національного банку, що діє на дату нарахування відсотків за користування кредитом, але не вище фактичної відсоткової ставки за кредитним договором.

{ Порядок доповнено пунктом 6-1 згідно з Постановою КМ N 883 ( 883-2009-п ) від 19.08.2009 }

7. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
