Кабінет Міністрів України; Розпорядження від 28.07.1999 № 740-р

Про дозвіл Держмитслужбі на здійснення митного оформлення сировинних ресурсів, що надійшли на адресу ВАТ "Артемівський завод по обробці кольорових металів" (Донецька область)

Стан: Втратив чинність

Ідентифікатор: 740-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 липня 1999 р. N 740-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення сировинних ресурсів, що надійшли на адресу ВАТ "Артемівський завод по обробці кольорових металів" (Донецька область) для власних потреб згідно з контрактами від 9 червня 1999 р. N 29 з додатками 1 та 2, укладеним з фірмою "SLAV AG" (Австрія), та від 17 червня 1999 р. N 33 з додатками 1 та 2, укладеним з компанією "TRACO LIMITED" (Великобританія), як товарів критичного імпорту.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
