Ідентифікатор: z0479-95

Текст документа від 25.09.2002:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ПО СТАНДАРТИЗАЦІЇ, МЕТРОЛОГІЇ ТА СЕРТИФІКАЦІЇ

НАКАЗ

N 437 від 22.12.95 Зареєстровано в Міністерстві м.Київ юстиції України 27 грудня 1995 р. за N 479/1015

{ Наказ втратив чинність на підставі Наказу Державного комітету стандартизації, метрології та сертифікації N 498 ( z0782-02 ) від 30.08.2002 }

Про внесення доповнення до наказу від 06.02.95 N 44 "Про внесення доповнень до "Переліку продукції, що підлягає обов'язковій сертифікації"

Відповідно до доручення Прем'єр-міністра України від 23 листопада 1995 року N інд.22, НАКАЗУЮ:

1. У пункті 2 наказу Держстандарту від 06.02.95 р. N 44 ( z0040-95 ) другий абзац після слів "з 1 липня 1995 року" доповнити словами "за винятком продукції, внесеної до підрозділів 30.6-30.9. Продукція за цими підрозділами підлягає обов'язковій сертифікації з 1 січня 1997 року".

2. Управлінню сертифікації Держстандарту довести інформацію щодо встановлення терміну введення в Україні обов'язкової сертифікації продукції, зазначеної в п.1 цього наказу, до зацікавлених міністерств, відомств і установ.
