Кабінет Міністрів України; Розпорядження від 03.10.2007 № 829-р

Про передачу цілісних майнових комплексів дочірніх підприємств ДАК "Хліб України" до сфери управління Держкомрезерву

Стан: Чинний

Ідентифікатор: 829-2007-р

Текст документа від 11.05.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 жовтня 2007 р. N 829-р Київ

Про передачу цілісних майнових комплексів дочірніх підприємств ДАК "Хліб України" до сфери управління Держкомрезерву

{ Додатково див. Постанову окружного адміністративного суду м. Києва N 5/175 ( v0175805-07 ) від 27.11.2007 - Постанову скасовано на підставі Постанови Вищого адміністративного суду N К-9876/09 ( v9876760-10 ) від 11.05.2010 }

1. Погодитися з пропозицією Держкомрезерву щодо передачі до сфери його управління цілісних майнових комплексів дочірніх підприємств ДАК "Хліб України" "Красноперекопський елеватор", "Нижньогірський елеватор", "Черняхівський комбінат хлібопродуктів", "Уманський елеватор", "Одеський портовий елеватор".

2. ДАК "Хліб України":

здійснити у місячний строк передачу зазначених у пункті 1 цього розпорядження майнових комплексів до сфери управління Держкомрезерву;

подати Кабінетові Міністрів України пропозиції про внесення змін до Статуту Компанії, пов'язаних із зміною розміру її статутного фонду, і після затвердження зазначених змін зареєструвати їх в Державній комісії з цінних паперів та фондового ринку.

3. Фонду державного майна внести зміни до Єдиного реєстру об'єктів державної власності, що випливають з цього розпорядження.

4. Мінфіну, Мінекономіки, Держкомрезерву подати до 20 листопада 2007 р. Кабінетові Міністрів України проект Закону України "Про внесення змін до Закону України "Про Державний бюджет України на 2007 рік" у частині списання заборгованості ДАК "Хліб України" перед Держкомрезервом у сумі 267001301,33 гривні, що виникла в результаті виконання постанов Кабінету Міністрів України від 24 січня 1998 р. N 79 ( 79-98-п ) "Про порядок повернення Державною акціонерною компанією "Хліб України" зерна в державний резерв за отримані у 1997 році товарно-матеріальні цінності", від 5 травня 1998 р. N 598 ( 598-98-п ) "Про проведення розрахунків з оптовими постачальниками за відвантажені сільськогосподарським товаровиробникам мінеральні добрива", від 25 серпня 1998 р. N 1338 ( 1338-98-п ) "Про забезпечення сільського господарства хімічними засобами захисту рослин у 1998-1999 роках", від 11 грудня 1998 р. N 1962 ( 1962-98-п ) "Про внесення доповнень до постанови Кабінету Міністрів України від 8 вересня 1998 р. N 1395", від 18 грудня 1998 р. N 2002 ( 2002-98-п ) "Про проведення розрахунків Державною акціонерною компанією "Хліб України" за мінеральні добрива, одержані від торговельно-енергетичної компанії "Ітера-Україна" та розпоряджень Кабінету Міністрів України від 16 листопада 1998 р. N 945 ( 945-98-р ) і від 19 квітня 1999 р. N 312.
