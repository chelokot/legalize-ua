Про затвердження форм довідок щодо цільового використання спирту етилового та журналу обліку погашення податкових векселів

{ Із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 318 ( z0730-06 ) від 05.06.2006 }

Відповідно до статті 3 Закону України "Про ставки акцизного збору на спирт етиловий та алкогольні напої" ( 178/96-ВР ), Порядку випуску, обігу та погашення податкових векселів, авальованих банком (податкових розписок), що видаються до отримання з акцизного складу спирту етилового, який використовується для виготовлення окремих видів продукції, затвердженого постановою Кабінету Міністрів України від 23 серпня 2005 року N 796 ( 796-2005-п ), статті 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ) та з метою належної організації контролю за цільовим використанням спирту етилового НАКАЗУЮ:

{ Преамбула із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 318 ( z0730-06 ) від 05.06.2006 }

1. Затвердити такі форми:

1.1. Довідка про прогнозований обсяг потреби спирту етилового для виготовлення продукції до податкового векселя, що додається. { Пункт 1.1 із змінами, внесеними згідно з Наказом Державної податкової адміністрації N 318 ( z0730-06 ) від 05.06.2006 }

1.2. Довідка векселедавця про цільове використання спирту етилового, що додається.

1.3. Журнал обліку погашення податкових векселів, що додається.

2. Департаменту з питань адміністрування акцизного збору і контролю за виробництвом та обігом підакцизних товарів (Гончар І.М.) в установленому порядку подати цей наказ до Міністерства юстиції України для державної реєстрації.

3. Департаменту масово-роз'яснювальної роботи (Косарчук В.П.) та Управлінню інформаційної політики (Штолько О.В.) після державної реєстрації цього наказу оприлюднити його на веб-сайті ДПА України та в засобах масової інформації.

4. Скасувати наказ Державної податкової адміністрації України від 17.03.2003 N 121 ( v0121225-03 ) "Про затвердження форм довідок щодо цільового використання спирту етилового".

5. Контроль за виконанням цього наказу покласти на заступника Голови ДПА України Лекаря С.І.

Голова О.І.Кірєєв
