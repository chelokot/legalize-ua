Кабінет Міністрів України; Розпорядження від 18.03.2009 № 493-р

Про виділення коштів для ліквідації наслідків аварії на шахті імені Карла Маркса державного підприємства "Орджонікідзевугілля"

Стан: Чинний

Ідентифікатор: 493-2009-р

Текст документа від 03.09.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 березня 2009 р. N 493-р Київ

Про виділення коштів для ліквідації наслідків аварії на шахті імені Карла Маркса державного підприємства "Орджонікідзевугілля"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1034-р ( 1034-2009-р ) від 03.09.2009 }

1. Виділити Мінвуглепрому 15 млн. гривень для подальшого проведення робіт з ліквідації наслідків аварії, що сталася 8 червня 2008 р. на шахті імені Карла Маркса державного підприємства "Орджонікідзевугілля", у тому числі 150 тис. гривень для надання додаткової грошової допомоги Турковій Катерині Альбертівні, доньці загиблого внаслідок аварії Туркова Альберта Геннадійовича. { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 1034-р ( 1034-2009-р ) від 03.09.2009 }

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 835-17 ).

2. Мінвуглепрому:

затвердити у тижневий строк за погодженням з Мінекономіки, Мінфіном і Мінрегіонбудом перелік витрат, пов'язаних з проведенням невідкладних аварійно-відбудовних робіт;

подати до 1 липня 2009 р. Мінекономіки, Мінфіну, Мінрегіонбуду та Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
