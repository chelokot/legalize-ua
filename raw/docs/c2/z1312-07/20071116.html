МІНІСТЕРСТВО ПРАЦІ ТА СОЦІАЛЬНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

16.11.2007 N 613

Зареєстровано в Міністерстві юстиції України 26 листопада 2007 р. за N 1312/14579

Про втрату чинності наказу Міністерства праці та соціальної політики України від 05.05.2006 N 169

Відповідно до постанови Кабінету Міністрів України від 11.09.2007 N 1123 ( 1123-2007-п ) "Про умови оплати праці працівників державних нотаріальних контор та державних нотаріальних архівів" НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства праці та соціальної політики України від 05.05.2006 N 169 ( z0530-06 ) "Про умови оплати праці працівників державних нотаріальних контор", зареєстрований в Міністерстві юстиції України 06.05.2006 за N 530/12404 (зі змінами).

2. Цей наказ набирає чинності з 1 січня 2008 року.
