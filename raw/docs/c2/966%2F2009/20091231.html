Текст документа від 31.12.2009:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1028/2009 ( 1028/2009 ) від 11.12.2009 }

Про зупинення дії окремих постанов Кабінету Міністрів України

{ Додатково див. Конституційне подання Президента ( n0046100-09 ) від 25.11.2009 }

Кабінет Міністрів України 29 жовтня 2009 року видав постанову N 1144 ( 1144-2009-п ) "Про залучення державним українським об'єднанням "Політехмед" у 2009 році іноземного кредиту під державну гарантію для реалізації інвестиційного проекту щодо закупівлі автомобілів швидкої медичної допомоги з метою посилення соціальної захищеності громадян України", якою погодився з пропозицією Міністерства охорони здоров'я України щодо залучення іноземного кредиту в сумі, що не перевищує 100 млн. доларів США (за офіційним курсом, установленим Національним банком України на 23 жовтня 2009 року, - 800 млн. гривень), для реалізації інвестиційного проекту щодо закупівлі автомобілів швидкої медичної допомоги з метою посилення соціальної захищеності громадян України під державну гарантію. При цьому Кабінет Міністрів України доручив Міністерству охорони здоров'я України та Міністерству фінансів України забезпечити обслуговування іноземного кредиту та авансового платежу, а також інших платежів і витрат, пов'язаних із реалізацією інвестиційного проекту, за рахунок коштів Державного бюджету України на 2009 та наступні роки.

Також 29 жовтня 2009 року Кабінет Міністрів України видав постанову N 1145 ( 1145-2009-п ) "Про залучення у 2009 році під державну гарантію іноземного кредиту для реалізації інвестиційного проекту щодо закупівлі засобів реабілітації (автомобілів) для забезпечення інвалідів з метою посилення соціальної захищеності громадян України", якою погодився з пропозицією Міністерства праці та соціальної політики України щодо залучення іноземного кредиту в сумі, що не перевищує 400 млн. доларів США (за офіційним курсом, установленим Національним банком України на 23 жовтня 2009 року, - 3200 млн. гривень), для реалізації інвестиційного проекту щодо закупівлі засобів реабілітації (автомобілів) для забезпечення інвалідів з метою посилення соціальної захищеності громадян України під державну гарантію. Зазначеною постановою ( 1145-2009-п ) Кабінет Міністрів України доручив Міністерству фінансів України забезпечити обслуговування іноземного кредиту та авансового платежу, а також інших платежів і витрат, пов'язаних із реалізацією інвестиційного проекту, за рахунок коштів Державного бюджету України на 2010 та наступні роки, що передбачатимуться Міністерству праці та соціальної політики України.

До зазначених постанов ( 1144-2009-п, 1145-2009-п ) 4 листопада 2009 року постановою Кабінету Міністрів України N 1163 ( 1163-2009-п ) було внесено низку змін.

Названі постанови Кабінету Міністрів України ( 1144-2009-п, 1145-2009-п, 1163-2009-п ) не відповідають Конституції України ( 254к/96-ВР ), виходячи з такого.

За Конституцією України ( 254к/96-ВР ) Кабінет Міністрів України є вищим органом у системі органів виконавчої влади (частина перша статті 113) ( 254к/96-ВР ); органи законодавчої, виконавчої та судової влади здійснюють свої повноваження у встановлених Конституцією ( 254к/96-ВР ) межах і відповідно до законів України та зобов'язані діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України (частина друга статті 6, частина друга статті 19) ( 254к/96-ВР ); Кабінет Міністрів України у своїй діяльності керується Конституцією ( 254к/96-ВР ) та законами України, здійснює визначені Конституцією ( 254к/96-ВР ) та законами України повноваження (частина третя статті 113, пункт 10 статті 116) ( 254к/96-ВР ).

Основним Законом держави ( 254к/96-ВР ) також визначено, що виключно законами України встановлюються Державний бюджет України і бюджетна система України, виключно законом про Державний бюджет України визначаються будь-які видатки держави на загальносуспільні потреби, розмір і цільове спрямування цих видатків (пункт 1 частини другої статті 92, частина друга статті 95) ( 254к/96-ВР ).

Законом України "Про Державний бюджет України на 2009 рік" ( 835-17 ) установлено, що у 2009 році державні гарантії надаються Кабінетом Міністрів України загалом в обсязі, що не перевищує 37.000.000 тис. гривень (частина перша статті 14) ( 835-17 ).

Після прийняття зазначених рішень Кабінетом Міністрів України взято зобов'язань щодо надання державних гарантій за кредитами на суму понад 60 млрд. гривень, що суттєво перевищує обсяг гарантій, передбачений Законом України "Про Державний бюджет України на 2009 рік" ( 835-17 ).

Відтак, вирішивши названими підзаконними актами питання щодо надання державних гарантій в сумі, що перевищує встановлений зазначеним Законом ( 835-17 ) граничний обсяг, а також установивши підзаконними актами, що обслуговування та погашення цих кредитів, внесення інших платежів, пов'язаних із реалізацією інвестиційного проекту, здійснюватиметься за рахунок коштів, які не передбачені Законом України "Про Державний бюджет України на 2009 рік" ( 835-17 ), та ще не затверджені в установленому порядку законами про Державний бюджет України на наступні роки, Кабінет Міністрів України порушив наведені вище норми частини другої статті 6, частини другої статті 19, пункту 1 частини другої статті 92, частини другої статті 95, частини третьої статті 113, пункту 10 статті 116 Конституції України ( 254к/96-ВР ), перебрав на себе повноваження Верховної Ради України, а отже, порушив норми статті 75, пунктів 3 і 4 частини першої статті 85 та статті 91 Конституції України ( 254к/96-ВР ), за якими Верховна Рада України є єдиним органом законодавчої влади в Україні, затверджує Державний бюджет України та вносить зміни до нього.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію:

постанови Кабінету Міністрів України від 29 жовтня 2009 року N 1144 ( 1144-2009-п ) "Про залучення державним українським об'єднанням "Політехмед" у 2009 році іноземного кредиту під державну гарантію для реалізації інвестиційного проекту щодо закупівлі автомобілів швидкої медичної допомоги з метою посилення соціальної захищеності громадян України";

постанови Кабінету Міністрів України від 29 жовтня 2009 року N 1145 ( 1145-2009-п ) "Про залучення у 2009 році під державну гарантію іноземного кредиту для реалізації інвестиційного проекту щодо закупівлі засобів реабілітації (автомобілів) для забезпечення інвалідів з метою посилення соціальної захищеності громадян України";

постанови Кабінету Міністрів України від 4 листопада 2009 року N 1163 ( 1163-2009-п ) "Про внесення змін до постанов Кабінету Міністрів України від 29 жовтня 2009 р. N 1144 і N 1145".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
