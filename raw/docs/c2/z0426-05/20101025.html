Про затвердження Довідника кодів помилок щодо проходження автоматичного логічно-семантичного контролю повідомлень про фінансові операції від банківських установ, що надходять засобами електронної пошти Національного банку України

Реєстрація: Мін'юст України від 21.04.2005 № 426/10706

Стан: Втратив чинність

Ідентифікатор: z0426-05

Текст документа від 25.10.2010:

ДЕРЖАВНИЙ КОМІТЕТ ФІНАНСОВОГО МОНІТОРИНГУ УКРАЇНИ

НАКАЗ

31.03.2005 N 82

Зареєстровано в Міністерстві юстиції України 21 квітня 2005 р. за N 426/10706

{ Наказ втратив чинність на підставі Наказу Державного комітету фінансового моніторингу N 152 ( z0894-10 ) від 30.08.2010 }

Про затвердження Довідника кодів помилок щодо проходження автоматичного логічно-семантичного контролю повідомлень про фінансові операції від банківських установ, що надходять засобами електронної пошти Національного банку України

Відповідно до статей 5, 13 Закону України "Про запобігання та протидію легалізації (відмиванню) доходів, одержаних злочинним шляхом" ( 249-15 ), пункту 4.4 Положення про здійснення банками фінансового моніторингу, затвердженого постановою Правління Національного банку України від 14.05.2003 N 189 ( z0381-03 ) та зареєстрованого в Міністерстві юстиції України 20.05.2003 за N 381/7702, НАКАЗУЮ:

1. Затвердити Довідник кодів помилок щодо проходження автоматичного логічно-семантичного контролю повідомлень про фінансові операції від банківських установ, що надходять засобами електронної пошти Національного банку України, що додається.

2. Юридичному управлінню разом з Департаментом інформаційних технологій забезпечити державну реєстрацію цього наказу в Міністерстві юстиції України.

3. Департаменту інформаційних технологій у десятиденний термін після державної реєстрації в Міністерстві юстиції України довести зміст цього наказу до відома банківських установ.

4. Контроль за виконанням цього наказу покласти на першого заступника Голови Державного комітету фінансового моніторингу України Зубрія В.П.

Голова Державного комітету фінансового моніторингу України С.Г.Гуржій

ПОГОДЖЕНО:

Заступник Голови Національного банку України В.Л.Кротюк
