Про внесення змін до наказу Міністра оборони України від 12.12.2005 N 736

Відповідно до абзацу третього пункту 2 постанови Кабінету Міністрів України від 28.12.92 N 731 ( 731-92-п ) "Про затвердження Положення про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами) НАКАЗУЮ:

1. У преамбулі наказу Міністра оборони України від 12.12.2005 N 736 ( z1560-05, za560-05 ) "Про встановлення заохочувальної відзнаки Міністерства оборони України "Знак пошани", зареєстрованого в Міністерстві юстиції України 26.12.2005 за N 1560/11840, слова та цифри "та Положення про Міністерство оборони України, затвердженого Указом Президента України від 21 серпня 1997 року N 888 ( 888/97 ) (у редакції Указу Президента України від 4 липня 2002 року N 618) ( 618/2002 ) (із змінами)," виключити.

2. Наказ розіслати до окремої військової частини.

3. Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр оборони України М.Б.Єжель
