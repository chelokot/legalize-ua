ПОСТАНОВА від 18 січня 2001 р. N 23 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1488 ( 1488-2001-п ) від 16.11.2001 )

Про внесення змін до складу Міжвідомчої комісії з міжнародної торгівлі

Кабінет Міністрів України постановляє:

Увести до складу Міжвідомчої комісії з міжнародної торгівлі, затвердженого постановою Кабінету Міністрів України від 28 квітня 2000 р. N 729 ( 729-2000-п ), Міністра економіки Рогового Василя Васильовича (голова Комісії), першого заступника Міністра закордонних справ Чалого Олександра Олександровича та заступника Голови Антимонопольного комітету Струка Василя Миколайовича, вивівши з її складу Тігіпка Сергія Леонідовича, Бершеду Євгена Романовича та Мельниченка Олександра Івановича.
