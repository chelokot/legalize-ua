Про затвердження Порядку оприлюднення частини регулярної інформації про емітента

Реєстрація: Мін'юст України від 02.09.1998 № 545/2985

Стан: Втратив чинність

Ідентифікатор: z0545-98

Текст документа від 22.11.2002:

ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

N 97 від 31.07.98 Зареєстровано в Міністерстві м.Київ юстиції України 2 вересня 1998 р. vd980731 vn97 за N 545/2985

Про затвердження Порядку оприлюднення частини регулярної інформації про емітента

( Із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку

N 327 ( z0911-02 ) від 29.10.2002 )

З метою вдосконалення порядку оприлюднення частини регулярної інформації про емітента Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Порядок оприлюднення частини регулярної інформації про емітента, що додається.

2. Рішення набуває чинності відповідно до діючого законодавства.

3. Контроль за виконанням цього рішення покласти на Члена Комісії О.Бойка.

Голова Комісії О.Мозговий

Затверджено Рішення Державної комісії з цінних паперів та фондового ринку 31.07.98 N 97

Зареєстровано в Міністерстві юстиції України 2 вересня 1998 р. за N 545/2985

Порядок оприлюднення частини регулярної інформації про емітента

Цей Порядок розроблено згідно з Законами України "Про цінні папери і фондову біржу" ( 1201-12 ), "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ).

1. Емітент цінних паперів при поданні регулярної інформації про своє господарсько-фінансове становище і результати діяльності (далі - звіт) відповідно до вимог Положення про надання регулярної інформації відкритими акціонерними товариствами та підприємствами - емітентами облігацій, затвердженого рішенням Державної комісії з цінних паперів та фондового ринку від 09.06.98 N 72 ( z0431-98 ), зареєстрованого в Міністерстві юстиції України 08.07.98 за N 431/2871 (у редакції рішення Державної комісії з цінних паперів та фондового ринку від 17.01.2000 N 3 ( z0063-00 ), зареєстрованого в Міністерстві юстиції України 03.02.2000 за N 63/4284), може звернутись до Державної комісії з цінних паперів та фондового ринку (далі - Комісія) із заявою про оприлюднення частини регулярної інформації про емітента (далі - заява). ( Пункт 1 в редакції Рішення Державної комісії з цінних паперів та фондового ринку N 327 ( z0911-02 ) від 29.10.2002 )

2. Заява повинна містити докладне обгрунтування причин, з яких емітент просить не оприлюднювати певних відомостей, що містяться у звіті.

Управління звітності учасників ринку цінних паперів протягом 7 днів з дати подання заяви розглядає звіт разом із заявою та подає на розгляд Комісії свої пропозиції.

( Пункт 2 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 327 ( z0911-02 ) від 29.10.2002 )

3. Комісія в 10-денний термін приймає рішення про оприлюднення частини звіту або відмовляє в задоволенні заяви. Виписка з відповідного протоколу засідання Комісії надсилається до Управління звітності учасників ринку цінних паперів та Першого відділу. ( Пункт 3 із змінами, внесеними згідно з Рішенням Державної комісії з цінних паперів та фондового ринку N 327 ( z0911-02 ) від 29.10.2002 )

4. У разі прийняття Комісією рішення про оприлюднення частини звіту ті відомості з даних звіту, які не підлягають оприлюдненню, передаються для зберігання до Першого відділу Комісії.
