( Наказ втратив чинність на підставі Наказу Міністерства культури і туризму N 745 ( z1285-05 ) від 18.10.2005 )

Про внесення змін до наказу Мінкультури України від 16.01.2002 N 20

На виконання постанови Кабінету Міністрів України від 16.08.2004 N 1051 ( 1051-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) артистичного та художнього персоналу деяких національних закладів культури" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства культури і мистецтв України від 16.01.2002 N 20 ( z0046-02 ) "Про оплату праці працівників національних закладів культури (мистецьких)", зареєстрованого в Міністерстві юстиції України 18.01.2002 за N 46/6334 (зі змінами та доповненнями), виклавши додаток 1 у новій редакції (додається).

2. Керівникам національних закладів культури передбачати видатки на преміювання своїх працівників у розмірі не менше ніж 3 відсотки планового фонду заробітної плати.

3. Контроль за виконанням наказу покласти на заступника Міністра І.В. Ніколайка.

4. Ці зміни застосовуються з 1 вересня 2004 року.

Міністр Ю.П.Богуцький
