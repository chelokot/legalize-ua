Текст документа від 07.08.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 червня 1999 р. N 954 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1231 ( 1231-2000-п ) від 07.08.2000 )

Питання Комітету з питань стандартизації, метрології та сертифікації

Кабінет Міністрів України постановляє:

1. Затвердити граничну чисельність працівників апарату Комітету з питань стандартизації, метрології та сертифікації 90 чоловік, у тому числі трьох заступників голови Комітету, з них одного першого, а також склад колегії у кількості 11 чоловік.

2. Установити ліміт легкових автомобілів, що обслуговують Комітет, дві одиниці.

3. Визнати такими, що втратили чинність:

пункт 3 постанови Кабінету Міністрів України від 16 березня 1993 р. N 191 ( 191-93-п ) "Про утворення Державної комісії єдиного часу і еталонних частот" (ЗП України, 1993 р., N 9, ст. 166);

постанову Кабінету Міністрів України від 5 липня 1994 р. N 462 ( 462-94-п ) "Питання Державного комітету по стандартизації, метрології та сертифікації" (ЗП України, 1994 р., N 10, ст. 258);

пункт 1 постанови Кабінету Міністрів України від 10 червня 1996 р. N 623 ( 623-96-п ) "Про колегію Державного комітету по стандартизації, метрології та сертифікації";

пункт 1 постанови Кабінету Міністрів України від 12 вересня 1996 р. N 1113 ( 1113-96-п ) "Про колегію Державного комітету по стандартизації, метрології та сертифікації".
