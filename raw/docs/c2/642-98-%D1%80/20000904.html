Кабінет Міністрів України; Розпорядження від 03.08.1998 № 642-р

Про закріплення у державній власності пакету акцій ВАТ "Азовзагальмаш"

Стан: Втратив чинність

Ідентифікатор: 642-98-р

Текст документа від 04.09.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 серпня 1998 р. N 642-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1383 ( 1383-2000-п ) від 04.09.2000 )

Про закріплення у державній власності пакету акцій ВАТ "Азовзагальмаш"

1. Відповідно до пункту 16 Державної програми приватизації на 1998 рік ( 124/98-ВР ) закріпити у державній власності на 5 років пакет акцій у розмірі 25 відсотків статутного фонду плюс одна акція ВАТ "Азовзагальмаш".

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 28 жовтня 1997 р. N 615 ( 615-97-р ).

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
