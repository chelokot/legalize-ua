Затвердити Порядок використання у 2004 році коштів Фонду соціального захисту інвалідів на функціонування центрів реабілітації інвалідів, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 травня 2004 р. N 698

ПОРЯДОК використання у 2004 році коштів Фонду соціального захисту інвалідів на функціонування центрів реабілітації інвалідів

1. Цей Порядок визначає механізм здійснення передбачених кошторисом Фонду соціального захисту інвалідів видатків, пов'язаних із забезпеченням функціонування центрів реабілітації інвалідів (далі - центри), за рахунок сум, отриманих в результаті застосування адміністративно-господарських санкцій відповідно до статті 20 Закону України "Про основи соціальної захищеності інвалідів в Україні" ( 875-12 ).

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 76 ( 76-2005-п ) від 21.01.2005; в редакції Постанови КМ N 142 ( 142-2006-п ) від 15.02.2006 )

2. Цей Порядок передбачає здійснення видатків, пов'язаних із забезпеченням функціонування: ( Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 142 ( 142-2006-п ) від 15.02.2006 )

Всеукраїнського центру професійної реабілітації інвалідів (смт Лютіж Київської області), Державного комплексу ранньої соціальної реабілітації дітей-інвалідів (м. Миколаїв), підприємств "Національний центр параолімпійської і дефлімпійської підготовки та реабілітації інвалідів" і "Західний реабілітаційно-спортивний центр" Національного комітету спорту інвалідів"; { Абзац другий пункту 2 в редакції Постанови КМ N 1589 ( 1589-2006-п ) від 15.11.2006 }

міжрегіональних центрів професійної реабілітації інвалідів та обласних центрів ранньої соціальної реабілітації дітей-інвалідів, підпорядкованих відповідно Мінпраці, Міністерству праці та соціального захисту Автономної Республіки Крим, головним управлінням праці та соціального захисту населення облдержадміністрацій, Головному управлінню соціального захисту населення Київської міськдержадміністрації і управлінню праці та соціального захисту населення Севастопольської міськдержадміністрації. { Абзац третій пункту 2 із змінами, внесеними згідно з Постановами КМ N 142 ( 142-2006-п ) від 15.02.2006, N 181 ( 181-2007-п ) від 09.02.2007 }

{ Пункт 3 виключено на підставі Постанови КМ N 142 ( 142-2006-п ) від 15.02.2006 }

4. Кошти для здійснення видатків центрами виділяє Мінпраці за поданням Фонду соціального захисту інвалідів із спеціального фонду державного бюджету, що формується за рахунок цільових надходжень до Фонду сум, отриманих в результаті застосування адміністративно-господарських санкцій за нестворення робочих місць для інвалідів. { Пункт 4 в редакції Постанови КМ N 142 ( 142-2006-п ) від 15.02.2006; із змінами, внесеними згідно з Постановою КМ N 181 ( 181-2007-п ) від 09.02.2007 }

5. Обсяг коштів спеціального фонду державного бюджету на здійснення видатків центрів затверджується Фондом соціального захисту інвалідів за погодженням з Мінпраці на підставі поданих центрами розрахунків.

( Пункт 5 із змінами, внесеними згідно з Постановою КМ N 142 ( 142-2006-п ) від 15.02.2006 )

6. Кошти спеціального фонду державного бюджету використовуються згідно з кошторисами центрів, затвердженими в установленому законодавством порядку. { Пункт 6 із змінами, внесеними згідно з Постановою КМ N 1589 ( 1589-2006-п ) від 15.11.2006; в редакції Постанови КМ N 181 ( 181-2007-п ) від 09.02.2007 }

7. Кошти спеціального фонду державного бюджету згідно з розподілом Фонду соціального захисту інвалідів спрямовуються на рахунки центрів в установленому законодавством порядку. { Пункт 7 в редакції Постанови КМ N 181 ( 181-2007-п ) від 09.02.2007 }

{ Пункт 8 виключено на підставі Постанови КМ N 181 ( 181-2007-п ) від 09.02.2007 }
