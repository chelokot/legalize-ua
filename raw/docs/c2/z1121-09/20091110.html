НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

10.11.2009 N 1280

Зареєстровано в Міністерстві юстиції України 20 листопада 2009 р. за N 1121/17137

Про внесення змін до Тарифів на електроенергію, що відпускається населенню і населеним пунктам, та Порядку застосування тарифів на електроенергію, що відпускається населенню і населеним пунктам

Відповідно до Закону України "Про електроенергетику" ( 575/97-ВР ), Указу Президента України від 14.03.95 N 213 ( 213/95 ) "Про заходи щодо забезпечення діяльності Національної комісії з питань регулювання електроенергетики України" (із змінами), постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", пункту 2 розпорядження Кабінету Міністрів України від 29.10.2009 N 1324-р ( 1324-2009-р ) "Про додаткові заходи щодо енергозабезпечення населення, яке проживає в багатоквартирних будинках, не газифікованих природним газом" Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Унести зміни до Тарифів на електроенергію, що відпускається населенню і населеним пунктам, затверджених постановою НКРЕ від 10.03.99 N 309 ( z0151-99 ) (у редакції постанови НКРЕ від 20.07.2006 N 926) ( z0918-06 ), зареєстрованих в Міністерстві юстиції України 10.03.99 за N 151/3444, виклавши їх в новій редакції, що додається.

2. Пункт 1.4 Порядку застосування тарифів на електроенергію, що відпускається населенню і населеним пунктам ( z0152-99 ), затвердженого постановою НКРЕ від 10.03.99 N 309 ( z0151-99 ) (у редакції постанови НКРЕ від 10.07.2002 N 758 ( z0626-02 ) та із змінами, внесеними постановами НКРЕ від 25.02.2004 N 188 ( z0308-04 ), від 30.03.2006 N 401 ( z0413-06 ), від 20.07.2006 N 926) ( z0918-06 ), зареєстрованого в Міністерстві юстиції України 10.03.99 за N 152/3445, доповнити новим абзацом такого змісту:

"Відпуск електроенергії населенню, яке проживає в багатоквартирних будинках населених пунктів (міст, сіл, селищ), не газифікованих природним газом і в яких відсутні або не функціонують системи централізованого теплопостачання, проводиться за тарифом 15,6 коп. за 1 кВт.год.".

3. Управлінню цінової політики в електроенергетиці подати цю постанову на державну реєстрацію до Міністерства юстиції України в установленому законодавством порядку.

4. Ця постанова набирає чинності з 1 грудня 2009 року.
