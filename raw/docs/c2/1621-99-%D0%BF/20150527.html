Про затвердження членів колегії Національного космічного агентства

( Із змінами, внесеними згідно з Постановою КМ N 1925 ( 1925-2002-п ) від 17.12.2002 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 1925 ( 1925-2002-п ) від 17.12.2002 )

2. Затвердити членами колегії Національного космічного агентства Бойка Григорія Степановича, Ганзю Людмилу Іванівну, Засуху Сергія Олексійовича, Каневського Валерія Олександровича, Махоніна Євгена Івановича, Сердюка Олександра Йосиповича, Федорова Олега Павловича, Халяву Валерія Андрійовича.

3. Визнати таким, що втратив чинність, пункт 2 постанови Кабінету Міністрів України від 16 вересня 1993 р. N 817 ( 817-93-п ).
