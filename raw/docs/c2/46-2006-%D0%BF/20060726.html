Кабінет Міністрів України; Постанова від 24.01.2006 № 46

Про закупівлю товарів для проведення заходів з виконання Комплексної програми "Цукровий діабет" і лікування нецукрового діабету, а також інформатизації і комп'ютеризації загальноосвітніх навчальних закладів

Стан: Чинний

Ідентифікатор: 46-2006-п

Текст документа від 26.07.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 січня 2006 р. N 46 Київ

Про закупівлю товарів для проведення заходів з виконання Комплексної програми "Цукровий діабет" і лікування нецукрового діабету, а також інформатизації і комп'ютеризації загальноосвітніх навчальних закладів

{ Із змінами, внесеними згідно з Постановою КМ N 1009 ( 1009-2006-п ) від 26.07.2006 }

Кабінет Міністрів України постановляє:

Установити, що у 2006 році закупівля товарів за рахунок цільових коштів, що враховані при визначенні міжбюджетних трансфертів між державним бюджетом та місцевими бюджетами, для проведення заходів з виконання Комплексної програми "Цукровий діабет" ( 545/99 ) і лікування нецукрового діабету, а також за рахунок коштів, передбачених у державному бюджеті для інформатизації та комп'ютеризації загальноосвітніх навчальних закладів у сумі 161617,5 тис. гривень, здійснюється на засадах міжвідомчої координації відповідно до статті 14-1 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ). { Абзац перший постановляючої частини із змінами, внесеними згідно з Постановою КМ N 1009 ( 1009-2006-п ) від 26.07.2006 }

Визначити генеральними замовниками відповідно Міністерство охорони здоров'я та Міністерство освіти і науки.

Прем'єр-міністр України Ю.ЄХАНУРОВ
