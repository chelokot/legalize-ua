Текст документа від 01.05.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 625/2005 ( 625/2005 ) від 11.04.2005 )

Про внесення змін до складу Консультативної ради з питань іноземних інвестицій в Україні

Внести до складу Консультативної ради з питань іноземних інвестицій в Україні, затвердженого Указом Президента України від 11 квітня 1997 року N 323 ( 323/97 ) (із змінами, внесеними Указами від 29 липня 1997 року N 717 ( 717/97 ), від 11 вересня 1997 року N 1006 ( 1006/97 ) та від 6 травня 1998 року N 414 ( 414/98 ), такі зміни:

1. Увести до складу зазначеної Консультативної ради таких осіб:

ЛЬОВОЧКІН - референт Президента України,

Сергій Володимирович секретар Консультативної ради

СТЕЛЬМАХ - Голова Національного банку

Володимир Семенович України (за згодою)

ТІГІПКО - Міністр економіки України.

Сергій Леонідович

2. Затвердити у складі Ради ЮЩЕНКА Віктора Андрійовича - Прем'єр-міністра України.

3. Вивести зі складу Ради В. Кузнєцова, В. Литвицького, В. Пустовойтенка, Р. Шпека.

Президент України Л.КУЧМА

м. Київ, 21 березня 2000 року N 468/2000
