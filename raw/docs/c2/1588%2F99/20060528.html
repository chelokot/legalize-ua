УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 340/2006 ( 340/2006 ) від 03.05.2006 }

Про внесення змін до статті 2 Указу Президента України від 22 липня 1998 року N 810

На часткову зміну статті 2 Указу Президента України від 22 липня 1998 року N 810 ( 810/98 ) "Про заходи щодо впровадження Концепції адміністративної реформи в Україні" (із змінами, внесеними Указами Президента України від 10 вересня 1998 року N 1000 ( 1000/98 ), від 21 вересня 1998 року N 1048 ( 1048/98 ) та від 9 січня 1999 року N 5 ( 5/99 ) встановити, що контроль за розробленням та реалізацією пропозицій щодо впровадження положень цієї Концепції у сфері реформування місцевих органів виконавчої влади, органів місцевого самоврядування та державної служби здійснює заступник Голови Державної комісії з проведення в Україні адміністративної реформи, Глава Адміністрації Президента України В. Литвин.

Президент України Л.КУЧМА

м. Київ, 18 грудня 1999 року N 1588/99
