Про визнання такими, що втратили чинність, окремих нормативно-правових актів Національного банку України

Стан: Чинний

Ідентифікатор: v-513500-10

Текст документа від 26.11.2010:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

26.11.2010 N 513

Про визнання такими, що втратили чинність, окремих нормативно-правових актів Національного банку України

Керуючись статтею 15 Закону України "Про Національний банк України" ( 679-14 ), з метою усунення порушень, виявлених Міністерством юстиції України за результатами перевірки стану дотримання Національним банком України законодавства про державну реєстрацію нормативно-правових актів, Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Визнати такими, що втратили чинність, з дня підписання цієї постанови:

постанову Правління Національного банку України від 03.11.2009 N 650 ( v0650500-09 ) "Про стимулювання кредитування економіки України";

постанову Правління Національного банку України від 13.04.2010 N 180 ( v0180500-10 ) "Про внесення зміни до постанови Правління Національного банку України від 03.11.2009 N 650".

2. Визнати такими, що втратили чинність, з 01.01.2011:

постанову Правління Національного банку України від 05.02.2009 N 49 ( v0049500-09 ) "Про окремі питання діяльності банків";

постанову Правління Національного банку України від 03.06.2009 N 328 ( v0328500-09 ) "Про заходи щодо забезпечення погашення кредитів";

постанову Правління Національного банку України від 05.03.2010 N 113 ( v0113500-10 ) "Про внесення зміни до постанови Правління Національного банку України від 05.02.2009 N 49";

постанову Правління Національного банку України від 05.03.2010 N 115 ( v0115500-10 ) "Про внесення змін до деяких нормативно-правових актів Національного банку України".

3. Департаменту нормативно-методологічного забезпечення банківського регулювання та нагляду (Н.В.Іваненко) довести зміст цієї постанови до відома структурних підрозділів центрального апарату, територіальних управлінь Національного банку України та банків.

4. Контроль за виконанням цієї постанови покласти на заступника Голови Національного банку України І.В.Соркіна.

5. Ця постанова набирає чинності з дня її підписання.

В.о. Голови С.Г.Арбузов
