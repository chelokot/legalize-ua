Кабінет Міністрів України; Постанова від 18.05.1998 № 698

Про збільшення розміру стипендії Президента України для молодих учених

Стан: Втратив чинність

Ідентифікатор: 698-98-п

Текст документа від 26.09.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 травня 1998 р. N 698 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1462 ( 1462-2002-п ) від 26.09.2002 )

Про збільшення розміру стипендії Президента України для молодих учених

Кабінет Міністрів України постановляє:

На зміну пункту 1 постанови Кабінету Міністрів України від 18 грудня 1995 р. N 1014 ( 1014-95-п ) "Про підвищення розміру стипендій для молодих учених" (ЗП України, 1996 р., N 4, ст. 128) збільшити розмір стипендії Президента України для молодих учених, установивши її у розмірі 100 гривень.
