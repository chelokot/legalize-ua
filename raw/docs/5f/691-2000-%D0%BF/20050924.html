КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 квітня 2000 р. N 691 Київ

( Постанова втратила чинність на підставі Постанови КМ N 942 ( 942-2005-п ) від 24.09.2005 )

Про утворення державної госпрозрахункової установи "Агентство з питань банкрутства"

Відповідно до статті 3 Указу Президента України від 15 грудня 1999 р. N 1573 ( 1573/99 ) "Про зміни у структурі центральних органів виконавчої влади" Кабінет Міністрів України постановляє:

1. Міністерству економіки:

утворити державну госпрозрахункову установу "Агентство з питань банкрутства" на базі ліквідованого центрального органу виконавчої влади - Агентства з питань банкрутства;

затвердити у місячний термін Положення про державну госпрозрахункову установу "Агентство з питань банкрутства", передбачивши в ньому, що основним завданням Агентства є надання послуг у процесі провадження у справах про банкрутство відповідно до Закону України "Про відновлення платоспроможності боржника або визнання його банкрутом" ( 2343-12 ).

2. Передати майно ліквідованого Агентства з питань банкрутства до сфери управління Міністерства економіки.

3. У переліку органів, які видають ліцензії на провадження певних видів підприємницької діяльності, затвердженому постановою Кабінету Міністрів України від 3 липня 1998 р. N 1020 ( 1020-98-п ) "Про порядок ліцензування підприємницької діяльності" (Офіційний вісник України, 1998 р., N 27, ст. 1004, N 41, ст. 1511, N 43, ст. 1594, N 50, ст. 1843; 1999 р., N 2, ст. 61, N 15, ст. 610, N 30, ст. 1534, N 42. ст. 2090) слова "Агентство з питань банкрутства" замінити словами "Міністерство економіки".
