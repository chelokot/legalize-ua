Про затвердження Положень про Головний інформаційний фонд стандартів Держстандарту та Національний інформаційний центр із стандартизації та сертифікації Міжнародної інформаційної мережі ISONET

Стан: Втратив чинність

Ідентифікатор: z0261-95

Текст документа від 10.04.2003:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ПО СТАНДАРТИЗАЦІЇ, МЕТРОЛОГІЇ ТА СЕРТИФІКАЦІЇ

НАКАЗ

N 245 від 13.07.95 Зареєстровано в Міністерстві м.Київ юстиції України 28 липня 1995 р. vd950713 vn245 за N 261/797

Про затвердження Положень про Головний інформаційний

фонд стандартів Держстандарту та Національний

інформаційний центр із стандартизації та сертифікації Міжнародної інформаційної мережі ISONET

( Із змінами, внесеними згідно з Наказом Державного комітету України з питань технічного регулювання та споживчої політики

N 48 ( z0282-03 ) від 25.03.2003 )

На виконання постанови Кабінету Міністрів України від 1 лютого 1995 року N 84 ( 84-95-п ) "Про створення Національного автоматизованого інформаційного фонду стандартів", з метою вдосконалення інформаційного забезпечення державних органів, підприємств, установ, організацій, громадських організацій і громадян у сфері стандартизації, метрології і сертифікації та створення умов щодо приєднання України до Генеральної Угоди з тарифів і торгівлі (ГАТТ) та Світової організації торгівлі (СОТ) НАКАЗУЮ:

1. Затвердити Положення про Національний інформаційний центр із стандартизації та сертифікації Міжнародної інформаційної мережі ISONET (додаються) ( z0262-95 ).

( Пункт 1 із змінами, внесеними згідно з Наказом Державного комітету України з питань технічного регулювання та споживчої політики N 48 ( z0282-03 ) від 25.03.2003 )

2. Встановити строк введення в дію зазначених Положень з 9 серпня 1995 року.

Голова Держстандарту України Ю.Д.Северінов

( Положення про Головний інформаційний фонд стандартів Держстандарту України втратило чинність на підставі Наказу Державного комітету України з питань технічного регулювання та споживчої політики N 48 ( z0282-03 ) від 25.03.2003 )
