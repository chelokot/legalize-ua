УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 540/2013 ( 540/2013 ) від 03.10.2013 }

Про делегацію України для участі в переговорах у рамках Світової організації торгівлі

1. Утворити делегацію України для участі в переговорах у рамках Світової організації торгівлі в такому складі:

ПЯТНИЦЬКИЙ - заступник Міністра економіки

Валерій Тезійович України, глава делегації

БУРКАТ - начальник відділу Департаменту

Євген Валерійович економічного співробітництва Міністерства закордонних справ України

ВІТКІН - заступник Голови Державного комітету Леонід Михайлович України з питань технічного регулювання та споживчої політики

ГОРЖЕЄВ - перший заступник Голови Державного

Володимир Михайлович комітету ветеринарної медицини України

ГРИЩЕНКО - заступник Міністра промислової

Сергій Георгійович політики України

ЖУКОВСЬКИЙ - Керівник Головної служби

Роман Сергійович соціально-економічного розвитку Секретаріату Президента України

ЗАВАЛЕВСЬКА - заступник Міністра аграрної політики Валентина Олександрівна України

ЗАЙЦЕВА - голова Центру обробки запитів країн

Світлана Петрівна членів Світової організації торгівлі і Світової організації торгівлі та їх інформування

ЛУТКОВСЬКА - заступник Міністра юстиції України

Валерія Володимирівна

ПАЛАДІЙ - голова Державного департаменту

Микола Васильович інтелектуальної власності

ПІКОВСЬКИЙ - перший заступник Голови Державної

Ігор Олександрович митної служби України

ПІНСЬКИЙ - начальник Управління

Олександр Іванович зовнішньоекономічної політики та міжнародного співробітництва Секретаріату Кабінету Міністрів України

ПОНОМАРЕНКО - перший заступник головного державного Анатолій Миколайович санітарного лікаря України

ФУДАШКІН - заступник Міністра фінансів України

Денис Олександрович

ЦИМБАЛ - директор департаменту співробітництва В'ячеслав Анатолійович з Світовою організацією торгівлі Міністерства економіки України

ЧЕРВАНЧУК - завідувач відділу Головної служби

Сергій Анатолійович соціально-економічного розвитку Секретаріату Президента України.

2. Дозволити главі делегації України в разі потреби:

вносити за погодженням із керівниками центральних органів виконавчої влади зміни до персонального складу делегації;

залучати для забезпечення роботи делегації працівників дипломатичної служби закордонних дипломатичних установ України та експертів.

3. Затвердити Директиви делегації України на переговори у рамках Дохійського раунду розвитку Світової організації торгівлі.

Главі делегації України забезпечити щоквартальне інформування Президента України про хід багатосторонніх та двосторонніх переговорів у рамках Світової організації торгівлі та подання звітів про результати участі делегації України у цих переговорах.

4. Кабінету Міністрів України вирішити питання щодо фінансового забезпечення участі делегації України в переговорах у рамках Світової організації торгівлі.

5. Визнати такими, що втратили чинність:

Указ Президента України від 18 листопада 2003 року N 1313 ( 1313/2003 ) "Про заходи щодо прискорення вступу України до Світової організації торгівлі";

Указ Президента України від 13 липня 2005 року N 1102 ( 1102/2005 ) "Про новий склад делегації України на переговорах зі вступу України до Світової організації торгівлі";

Указ Президента України від 28 лютого 2006 року N 156 ( 156/2006 ) "Про питання делегації України на переговорах зі вступу України до Світової організації торгівлі".

Президент України В.ЮЩЕНКО
