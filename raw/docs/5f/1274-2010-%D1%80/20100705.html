Кабінет Міністрів України; Розпорядження від 29.06.2010 № 1274-р

Про виділення коштів для проведення невідкладних заходів з ліквідації наслідків стихійного лиха, що сталося 22-29 червня 2010 р. у Чернівецькій області

Стан: Чинний

Ідентифікатор: 1274-2010-р

Текст документа від 05.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 червня 2010 р. N 1274-р Київ

Про виділення коштів для проведення невідкладних заходів з ліквідації наслідків стихійного лиха, що сталося 22-29 червня 2010 р. у Чернівецькій області

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1347-р ( 1347-2010-р ) від 05.07.2010 }

1. Для проведення невідкладних заходів з ліквідації наслідків стихійного лиха, що сталося 22-29 червня 2010 р. у Чернівецькій області, виділити 40 млн. гривень, у тому числі Чернівецькій облдержадміністрації - 27 млн., Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи - 2,5 млн., Державній службі автомобільних доріг - 7,5 млн., Державному комітету по водному господарству - 3 млн. гривень.

Міністерству фінансів здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 2154-17 ).

2. Чернівецькій облдержадміністрації забезпечити:

1) виплату до 1 липня 2010 р. за рахунок коштів, виділених відповідно до цього розпорядження, матеріальної грошової допомоги:

власникам житлових будинків, які повністю зруйновані, - по 5 тис. гривень;

сім'ям, які відселені з житлових будинків, що підлягають капітальному ремонту, - по 2,5 тис. гривень на сім'ю;

сім'ям, житлові будинки яких пошкоджено, - по 1 тис. гривень на сім'ю;

1-1) виплату матеріальної грошової допомоги сім'ям загиблих - по 100 тис. гривень на кожного загиблого члена сім'ї; { Пункт 2 доповнено підпунктом 1-1 згідно з Розпорядженням КМ N 1347-р ( 1347-2010-р ) від 05.07.2010 }

2) спрямування в установленому законодавством порядку коштів місцевих бюджетів для надання допомоги постраждалим громадянам та ремонту приміщень бюджетних установ і об'єктів житлово-комунального господарства;

3) в одноденний строк підготовку та затвердження райдержадміністраціями списків осіб для виплати матеріальної грошової та у дводенний строк її виплату за зазначеними списками.

3. Міністерству фінансів і Державному казначейству перерахувати 29 червня 2010 р. кошти резервного фонду державного бюджету ( 2154-17 ) та здійснити видатки Чернівецькій облдержадміністрації на виплату матеріальної грошової допомоги без затвердження переліку витрат.

4. Чернівецькій облдержадміністрації затвердити порядок виплати матеріальної грошової допомоги, передбаченої пунктом 2 цього розпорядження.

5. Чернівецькій облдержадміністрації, Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, Державній службі автомобільних доріг, Державному комітету по водному господарству:

затвердити у тижневий строк за погодженням з Міністерством економіки, Міністерством фінансів і Міністерством регіонального розвитку та будівництва перелік витрат, пов'язаних з проведенням невідкладних заходів з ліквідації наслідків стихійного лиха;

подати до 1 грудня 2010 р. Міністерству економіки, Міністерству фінансів, Міністерству регіонального розвитку та будівництва і Державному казначейству звіт про використання коштів резервного фонду державного бюджету ( 2154-17 ), виділених відповідно до цього розпорядження.

6. Установити, що проектно-кошторисна документація для проведення відновних робіт на об'єктах, які постраждали внаслідок стихійного лиха, що сталося 22-29 червня 2010 р. у Чернівецькій області, складається відповідно до законодавства. У разі потреби невідкладні відновні роботи можуть проводитися за рішенням Чернівецької облдержадміністрації на підставі кошторисів витрат на такі роботи, складених та затверджених у визначеному облдержадміністрацією порядку. У такому разі органи Державного казначейства забезпечують перерахування коштів виконавцям робіт на підставі зазначених кошторисів, укладених між замовниками та виконавцями робіт договорів, актів виконаних робіт, оформлених відповідно до законодавства.

{ Розпорядження доповнено пунктом 6 Розпорядженням КМ N 1347-р ( 1347-2010-р ) від 05.07.2010 }
