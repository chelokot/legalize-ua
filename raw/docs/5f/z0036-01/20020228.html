Стан: Втратив чинність

ДЕРЖАВНИЙ КОМІТЕТ БУДІВНИЦТВА, АРХІТЕКТУРИ ТА ЖИТЛОВОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

N 8 від 09.01.2001 Зареєстровано в Міністерстві м. Київ юстиції України 18 січня 2001 р. за N 36/5227

{ Наказ втратив чинність на підставі Наказу Держбуду N 36 ( z0209-02 ) від 15.02.2002 Наказу Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 327 ( z1216-12 ) від 02.07.2012 }

Про внесення доповнень до Інструкції про порядок державної реєстрації права власності на об'єкти нерухомого майна, що перебувають у власності юридичних та фізичних осіб, затвердженої наказом Держбуду від 09.06.98 N 121

З метою приведення Інструкції про порядок державної реєстрації права власності на об'єкти нерухомого майна, що перебувають у власності юридичних та фізичних осіб, затвердженої наказом Державного комітету будівництва, архітектури та житлової політики України від 09.06.98 N 121 ( z0399-98 ), у відповідність до розпорядження Кабінету Міністрів України від 20.12.2000 N 501-р ( 501-2000-р ) НАКАЗУЮ:

1. Унести до Інструкції про порядок державної реєстрації права власності на об'єкти нерухомого майна, що перебувають у власності юридичних та фізичних осіб, затвердженої наказом Державного комітету будівництва, архітектури та житлової політики України від 09.06.98 N 121 ( z0399-98 ) та зареєстрованої у Міністерстві юстиції України 26.06.98 за N 399/2839 (далі - Інструкція), такі доповнення:

1.1. Пункт 4.1 Інструкції доповнити підпунктом "в" у такій редакції:

"в) Державним управлінням справами - суб'єктам, що беруть участь разом з Державним управлінням справами у будівництві нового житла, на їх частку".

1.2. Додаток 1 до Інструкції доповнити пунктом 18 у такій редакції:

"18. Свідоцтва про право власності, видані Державним управлінням справами суб'єктам, що беруть участь разом з Державним управлінням справами у будівництві нового житла".

2. Управлінню нормативно-правового забезпечення реформування житлової політики та експлуатації житлового фонду (Макаренко Л.О.) подати наказ для державної реєстрації у Міністерство юстиції України.
