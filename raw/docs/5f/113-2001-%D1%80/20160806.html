Кабінет Міністрів України; Розпорядження від 28.03.2001 № 113-р

Про віднесення посад працівників секретаріату Комісії з питань діяльності підприємств та організацій громадських організацій інвалідів до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 113-2001-р

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 березня 2001 р. N 113-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Про віднесення посад працівників секретаріату Комісії з питань діяльності підприємств та організацій громадських організацій інвалідів до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 426-р ( 426-2004-р ) від 05.07.2004 N 1114-р ( 1114-2008-р ) від 20.08.2008 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади керівних працівників і спеціалістів секретаріату Комісії з питань діяльності підприємств та організацій громадських організацій інвалідів до таких категорій державних службовців:

друга категорія - посада секретаря Комісії - керівника секретаріату;

третя категорія - посада заступника керівника секретаріату;

четверта категорія - посади керівників, заступників керівників структурних підрозділів секретаріату; { Розпорядження доповнено позицією згідно з Розпорядженням КМ N 426-р ( 426-2004-р ) від 05.07.2004; в редакції Розпорядження КМ N 1114-р ( 1114-2008-р ) від 20.08.2008 }

п'ята категорія - посади спеціалістів секретаріату.
