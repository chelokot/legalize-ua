Про внесення зміни до Положення про порядок формування обов'язкових резервів для банків України

Відповідно до статті 15 Закону України "Про Національний банк України" ( 679-14 ) та Змін до Плану рахунків бухгалтерського обліку банків України, затверджених постановою Правління Національного банку України від 20.08.2003 N 356 ( z0795-03 ) і зареєстрованих у Міністерстві юстиції України 11.09.2003 за N 795/8116, а також з метою систематизації вимог щодо виконання банками нормативу обов'язкового резервування Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Доповнити пункт 2.2 Положення про порядок формування обов'язкових резервів для банків України, затвердженого постановою Правління Національного банку України від 27.06.2001 N 244 ( z0586-01 ) та зареєстрованого в Міністерстві юстиції України 11.07.2001 за N 586/5777 (із змінами), після цифр "3306" цифрами та словами "3310 плюс 3311 плюс 3315 плюс 3317 мінус 3316".

2. Департаменту монетарної політики (Н.І.Гребеник) після державної реєстрації довести зміст цієї постанови до відома територіальних управлінь Національного банку України та банків для використання в роботі.

3. Постанова набирає чинності з 1 січня 2004 року.

4. Контроль за виконанням цієї постанови покласти на першого заступника Голови А.П.Яценюка.
