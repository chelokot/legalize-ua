Про встановлення посадових окладів осіб офіцерського складу Державної прикордонної служби України

{ Із змінами, внесеними згідно з Наказом Адміністрації Державної прикордонної служби N 888 ( z1411-11 ) від 21.11.2011 }

Відповідно до постанови Кабінету Міністрів України від 07.11.2007 N 1294 ( 1294-2007-п ) "Про упорядкування структури та умов грошового забезпечення військовослужбовців, осіб рядового і начальницького складу та деяких інших осіб" НАКАЗУЮ:

1. Затвердити:

Схему посадових окладів осіб офіцерського складу Адміністрації Державної прикордонної служби України згідно з додатком 1 до наказу;

Схему посадових окладів осіб офіцерського складу регіональних управлінь Державної прикордонної служби України згідно з додатком 2 до наказу.

Схему посадових окладів осіб офіцерського складу прикордонних загонів Державної прикордонної служби України згідно з додатком 3 до наказу. { Пункт 1 доповнено абзацом четвертим згідно з Наказом Адміністрації Державної прикордонної служби N 888 ( z1411-11 ) від 21.11.2011 }

Схему посадових окладів осіб офіцерського складу навчальних закладів та науково-дослідних установ Державної прикордонної служби України згідно з додатком 4 до наказу. { Пункт 1 доповнено абзацом п'ятим згідно з Наказом Адміністрації Державної прикордонної служби N 888 ( z1411-11 ) від 21.11.2011 }

2. Ці Схеми застосовувати під час тарифікації посад осіб офіцерського складу в штатах відповідних органів Державної прикордонної служби України.

3. Контроль за виконанням цього наказу покласти на заступника директора Департаменту охорони державного кордону - начальника управління планування, оборонної, мобілізаційної роботи та організації антитерористичних заходів та директора Фінансово-економічного департаменту Адміністрації Державної прикордонної служби України.

4. Фінансово-економічному департаменту Адміністрації Державної прикордонної служби України спільно з управлінням правового забезпечення Міжнародно-правового департаменту Адміністрації Державної прикордонної служби України забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

5. Наказ довести до відома особового складу в частині, що його стосується.

6. Цей наказ набирає чинності з дня його офіційного опублікування.
