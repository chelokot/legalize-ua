1. Затвердити:

Схему посадових окладів осіб офіцерського складу Адміністрації Державної прикордонної служби України згідно з додатком 1 до наказу;

Схему посадових окладів осіб офіцерського складу Мобільного прикордонного загону Державної прикордонної служби України згідно з додатком 5 до наказу; { Пункт 1 доповнено абзацом шостим згідно з Наказом Адміністрації Державної прикордонної служби N 597 ( z1411-12 ) від 02.08.2012 }

Схему посадових окладів осіб офіцерського складу Окремого контрольно-пропускного пункту Державної прикордонної служби України згідно з додатком 6 до наказу; { Пункт 1 доповнено абзацом сьомим згідно з Наказом Адміністрації Державної прикордонної служби N 597 ( z1411-12 ) від 02.08.2012 }

Схему посадових окладів осіб офіцерського складу загону Морської охорони Державної прикордонної служби України згідно з додатком 7 до наказу; { Пункт 1 доповнено абзацом восьмим згідно з Наказом Адміністрації Державної прикордонної служби N 597 ( z1411-12 ) від 02.08.2012 }

Схему посадових окладів осіб офіцерського складу авіаційної частини Державної прикордонної служби України згідно з додатком 8 до наказу; { Пункт 1 доповнено абзацом дев'ятим згідно з Наказом Адміністрації Державної прикордонної служби N 597 ( z1411-12 ) від 02.08.2012 }

Схему посадових окладів осіб офіцерського складу органів забезпечення Державної прикордонної служби України згідно з додатком 10 до наказу. { Пункт 1 доповнено абзацом одинадцятим згідно з Наказом Адміністрації Державної прикордонної служби N 597 ( z1411-12 ) від 02.08.2012 }

2. Ці Схеми застосовувати під час тарифікації посад осіб офіцерського складу в штатах відповідних органів Державної прикордонної служби України.

3. Контроль за виконанням цього наказу покласти на заступника директора Департаменту охорони державного кордону - начальника управління планування, оборонної, мобілізаційної роботи та організації антитерористичних заходів та директора Фінансово-економічного департаменту Адміністрації Державної прикордонної служби України.

4. Фінансово-економічному департаменту Адміністрації Державної прикордонної служби України спільно з управлінням правового забезпечення Міжнародно-правового департаменту Адміністрації Державної прикордонної служби України забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

5. Наказ довести до відома особового складу в частині, що його стосується.

6. Цей наказ набирає чинності з дня його офіційного опублікування.
