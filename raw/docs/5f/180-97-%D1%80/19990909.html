Про склад редакційно-художньої ради з питань видання знаків поштової оплати в Україні

Стан: Втратив чинність

Ідентифікатор: 180-97-р

Текст документа від 09.09.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 квітня 1997 р. N 180-р Київ

Про склад редакційно-художньої ради з питань видання знаків поштової оплати в Україні

( Із змінами, внесеними згідно з Розпорядженнями КМ N 24-р ( 24-98-р ) від 19.01.98 N 943-р ( 943-99-р ) від 09.09.99 )

Відповідно до статті 22 Закону України "Про зв'язок" ( 160/95-ВР ) затвердити склад редакційно-художньої ради з питань видання знаків поштової оплати в Україні згідно з додатком.

Прем'єр-міністр України П.ЛАЗАРЕНКО

Інд.34

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 3 квітня 1997 р. N 180-р

СКЛАД редакційно-художньої ради з питань видання знаків поштової оплати в Україні

ОРЛЕНКО - заступник Голови Держкомзв'язку, голова Микола Петрович ради

СТЕЦЕНКО - заступник директора державного Михайло Іванович підприємства "Видавництво "Марка України", перший заступник голови ради

ЛАХНО - заступник начальника управління Тетяна Петрівна Держкомзв'язку, заступник голови ради

ТИХОПЛАВ - інженер державного підприємства Світлана Олексіївна "Видавництво "Марка України", секретар ради

БЕХТІР - голова правління Асоціації філателістів Володимир Григорович України (за згодою)

ДЕМЧЕНКО - головний спеціаліст Головного управління Анатолій Миколайович книговидавничої діяльності та поліграфії Державного комітету інформаційної політики

ЗДАНЕВИЧ - головний технолог поліграфічного Олена Валентинівна комбінату "Україна"

ЗЕРКАЛЬ - заступник начальника відділу Головного Людмила Олексіївна управління по організації виготовлення цінних паперів Мінфіну

ІВАХНЕНКО - художник-графік, член Спілки художників Олександр Андрійович (за згодою)

КОВШУРА - заступник начальника управління мистецтв Віра Василівна Мінкультури

ЛУКОМСЬКА - головний художник видавництва "Преса Тетяна Дмитрівна України"

МУХІН - генеральний директор державного Василь Георгійович підприємства поштового зв'язку "Укрпошта"

ПИРІГ - член правління Асоціації філателістів Любомир Антонович України (за згодою)

СКЛЯРЕНКО - директор Київської дирекції державного Сергій Миколайович підприємства поштового зв'язку "Укрпошта"

СТЕПОВИК - провідний науковий співробітник Інституту Дмитро Власович мистецтвознавства, фольклору та етнографії імені М.Т. Рильського Національної академії наук

ТИТАРЕНКО - головний художник поліграфічного Володимир Павлович комбінату "Україна"

ШОСТЯ - декан факультету образотворчого мистецтва Віталій Миколайович Української академії мистецтв і архітектури
