Про склад Оперативної міжвідомчої комісії з питань подолання платіжної кризи

1. Затвердити персональний склад Оперативної міжвідомчої комісії з питань подолання платіжної кризи (додаєтья).

2. Визнати такими, що втратили чинність:

Розпорядження Президента України від 2 листопада 1994 року N 162 ( 162/94-рп ) "Про Оперативну міжвідомчу комісію з питань подолання платіжної кризи";

Розпорядження Президента України від 3 жовтня 1995 року N 254 ( 254/95-рп ) "Про зміни у складі Оперативної міжвідомчої комісії з питань подолання платіжної кризи".
