УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 888/2000 ( 888/2000 ) від 14.07.2000 )

Про Фонд сприяння розвитку мистецтв України

( Із змінами, внесеними згідно з Указом Президента N 405/95 ( 405/95 ) від 31.05.95 )

З метою надання підтримки закладам, підприємствам і організаціям культури, забезпечення соціального захисту творчих працівників та відповідно до пункту 7-4 статті 114-5 Конституції України ( 888-09 ) постановляю:

1. Підтримати ініціативу ряду суб'єктів підприємницької діяльності та творчих спілок України і утворити благодійний фонд - Фонд сприяння розвитку мистецтв України (далі - Фонд), установивши особливий порядок його утворення та діяльності.

2. Кошти Фонду формуються за рахунок благодійних пожертвувань і добровільних внесків фізичних і юридичних осіб, а також інших надходжень, одержаних на підставах, не заборонених законодавством України.

( Частина друга статті 2 втратила чинність на підставі Указу Президента N 405/95 ( 405/95 ) від 31.05.95 )

3. Призначити МАТВІЄНКА Анатолія Сергійовича головою ради Фонду сприяння розвитку мистецтв України.

4. А. Матвієнку подати у місячний строк проект Положення про Фонд сприяння розвитку мистецтв України.

5. Рекомендувати органам, уповноваженим управляти майном, що перебуває у державній власності, вирішувати питання виділення приміщень для Фонду.

Президент України Л.КРАВЧУК
