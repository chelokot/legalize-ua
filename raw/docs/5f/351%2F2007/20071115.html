Президент України; Указ від 25.04.2007 № 351/2007

Про заміщення посади референта Уповноваженого Президента України з питань контролю за діяльністю Служби безпеки України військовослужбовцем

Стан: Втратив чинність

Ідентифікатор: 351/2007

Текст документа від 15.11.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1020/2007 ( 1020/2007 ) від 25.10.2007 }

Про заміщення посади референта Уповноваженого Президента України з питань контролю за діяльністю Служби безпеки України військовослужбовцем

Установити, що посада референта Уповноваженого Президента України з питань контролю за діяльністю Служби безпеки України може бути заміщена військовослужбовцем Служби безпеки України з граничним військовим званням полковника.

Президент України В.ЮЩЕНКО

м. Київ, 25 квітня 2007 року N 351/2007
