УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1871/2005 ( 1871/2005 ) від 29.12.2005 )

Про співголову та заступника співголови Національної ради соціального партнерства

На часткову зміну Указу Президента України від 8 лютого 1993 року N 34 ( 34/93 ) "Про Національну раду соціального партнерства" (зі змінами, внесеними Указами від 29 січня 1996 року N 97 ( 97/96 ), від 15 листопада 1996 року N 1083 ( 1083/96 ), від 19 червня 1997 року N 560 ( 560/97 ) та від 31 липня 1998 року N 834 ( 834/98 ):

увести до складу Національної ради соціального партнерства ПАПІЄВА Михайла Миколайовича - Міністра праці та соціальної політики України і КРАСИЛЬЩИКОВА Анатолія Лаврентійовича - начальника Управління стратегії реформування соціальних відносин Секретаріату Кабінету Міністрів України, призначивши їх відповідно співголовою та заступником співголови цієї Ради від Кабінету Міністрів України;

вивести зі складу Національної ради соціального партнерства Саханя І.Я. та Іванкевича В.В.

Президент України Л.КУЧМА

м. Київ, 30 січня 2003 року N 51/2003
