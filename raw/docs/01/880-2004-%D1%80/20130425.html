Кабінет Міністрів України; Розпорядження від 30.11.2004 № 880-р

Про встановлення строку виконання операцій з ремонту літаків типу ЯК, ІЛ та ТУ за межами митної території України

Стан: Втратив чинність

Ідентифікатор: 880-2004-р

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 листопада 2004 р. N 880-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення строку виконання операцій з ремонту літаків типу ЯК, ІЛ та ТУ за межами митної території України

( Із змінами, внесеними згідно з Розпорядженням КМ N 974-р ( 974-2004-р ) від 31.12.2004 )

Відповідно до частини третьої статті 240 Митного кодексу України ( 92-15 ) встановити строк виконання операцій з ремонту літаків типу ЯК, ІЛ та ТУ за межами митної території України, 260 днів від дати оформлення вивізної вантажної митної декларації. ( Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 974-р ( 974-2004-р ) від 31.12.2004 )

Прем'єр-міністр України В.ЯНУКОВИЧ
