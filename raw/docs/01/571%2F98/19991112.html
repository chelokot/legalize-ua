Президент України; Указ від 30.05.1998 № 571/98

Про робочий орган Комісії з питань морської політики

Стан: Втратив чинність

Ідентифікатор: 571/98

Текст документа від 12.11.1999:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про робочий орган Комісії з питань морської політики

( Із змінами, внесеними згідно з Указом Президента N 1465/99 від 12.11.99 )

З метою створення умов для функціонування Комісії з питань морської політики при Президентові України постановляю:

1. Покласти функції робочого органу із забезпечення діяльності Комісії з питань морської політики на Державну адміністрацію морського і річкового транспорту України. ( Стаття 1 із змінами, внесеними згідно з Указом Президента N 1465/99 від 12.11.99 )

2. У зв'язку з цим внести зміни до таких Указів Президента України:

1) в Указі від 18 грудня 1995 року N 1152 ( 1152/95 ) "Про Комісію з питань морської політики":

затвердити новий склад Комісії з питань морської політики (додається);

слова "державної виконавчої" замінити словом "виконавчої";

статтю 6 визнати такою, що втратила чинність;

2) у Положенні про Комісію з питань морської політики при Президентові України, затвердженому Указом від 16 травня 1996 року N 350 ( 350/96 ) "Про Положення про Комісію з питань морської політики":

слова "державної виконавчої" замінити словом "виконавчої";

пункт 9 визнати таким, що втратив чинність.

Президент України Л.КУЧМА

м. Київ, 30 травня 1998 року N 571/98
