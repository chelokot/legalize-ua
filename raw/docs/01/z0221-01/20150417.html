Зареєстровано в Міністерстві юстиції України 13 березня 2001 р. за N 221/5412

Інструкція щодо складання державного статистичного спостереження за формою N 2-вод "Звіт про наявність власних морських і річкових суден, вантажних та пасажирських причалів-набережних

{ Назва Інструкції в редакції Наказу Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005, із змінами, внесеними згідно з Наказом Державного комітету статистики N 551 ( z1280-06 ) від 27.11.2006 }

( У тексті Інструкції назву форми "Звіт про наявність власних торговельних суден" замінено на "Звіт про наявність власних морських і річкових суден, вантажних та пасажирських причалів-набережних" згідно з Наказом Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

( У тексті Інструкції слова "державна статистична звітність" у всіх відмінках замінено словами "державне статистичне спостереження" у відповідному відмінку згідно з Наказом Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

1. Загальні положення

Інструкція щодо складання державного статистичного спостереження про наявність торговельних суден за формою N 2-вод "Звіт про наявність власних морських і річкових суден, вантажних та пасажирських причалів-набережних" (далі - Інструкція) створена з метою одержання всебічної та вичерпної статистичної інформації про кількісні та якісні характеристики морського і річкового флоту України.

Дія Інструкції поширюється на підприємства, установи і організації (далі - підприємства) - юридичні особи всіх форм власності та видів економічної діяльності, які мають на балансі:

- морські і річкові судна, крім малих; ( Абзац третій пункту 1 із змінами, внесеними згідно з Наказом Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

- вантажні та пасажирські причали.

2. Основні терміни та їх тлумачення

Основні терміни, які використовуються в Інструкції, відповідають термінам Кодексу торговельного мореплавства України ( 176/95-ВР ), Глосарію по статистиці транспорту (Євростат, ЕКМТ, ЄЕК ООН 1994 р.).

2.1. Торговельне судно (далі - судно) - самохідна чи несамохідна плавуча споруда, що використовується:

- для перевезення вантажів, пасажирів, багажу і пошти, для рибного чи іншого морського промислу, розвідки і добування корисних копалин, рятування людей і суден, що зазнають лиха на воді, буксирування інших суден та плавучих об'єктів, здійснення гідротехнічних робіт чи піднімання майна, що затонуло;

- для несення спеціальної державної служби (охорона промислів, санітарна і карантинна служба, захист від забруднення тощо);

- для наукових, навчальних і культурних цілей;

- для спорту;

- для інших потреб з іншою метою.

2.2. За районами плавання судна поділяються:

- на річкові, призначені для судноплавства по внутрішніх водних шляхах (річках, озерах, каналах) без права виходу в море;

- морські, призначені для судноплавства у морських територіальних водах України з виходом у нейтральні та територіальні води інших країн;

- змішаного типу "ріка-море", призначені для судноплавства по внутрішніх водних шляхах (річках, озерах, каналах) з правом виходу в море.

2.3. За наявністю двигуна судна поділяються на самохідні, які оснащені самостійною рухомою установкою (двигуном), та несамохідні, які не мають власної рухомої установки (двигуна) і рух яких здійснюється за допомогою самохідних суден.

2.4. За призначенням судна поділяються на транспортні, рибальські, спеціального призначення, технічні, службово-допоміжні.

2.4.1. Основними типами транспортних суден є:

- пасажирські - для перевезень пасажирів та їх багажу;

- вантажні - для перевезення вантажів (універсальні, контейнеровози, докові, баржевози, ліхтеровози, накатні (Ро-Ро), наливні, навалочні (балкери), лісовозні, рефрижераторні):

наливні, призначені для перевезення вантажів у стані рідини;

суховантажні, призначені для перевезення сипучих та генеральних вантажів;

- вантажопасажирські - призначені одночасно для перевезень пасажирів і вантажів.

2.4.2. Основними типами рибальських суден є:

- промислові, призначені для промислу риби, китів, тюленів, моржів або інших живих ресурсів моря (траулери, сейнери, тунцелови, риболовні боти, сіткопідіймачі, китобійні та краболовні судна);

- промислово-переробні, призначені для промислу та обробки власного улову (морозильні траулери-рибозаводи, великі сардинні траулери - рибоконсервні заводи, морозильні траулери, судна для переробки оселедців, крабів, рибоконсервні плавучі бази, рибомучні судна, морозильні судна).

2.4.3. Основними типами суден спеціального призначення є:

- науково-дослідницькі, експедиційні, гідрологічні, гідрографічні, гідрометеорологічні, навчальні, призначені для виконання наукових досліджень та навчальних робіт;

- китобази, рибобази та інші судна, призначені для переробки живих ресурсів моря і не зайняті їх ловом;

- бурові, добувні, призначені для розвідки, буріння і добування корисних копалин;

- криголами, призначені для розчищення шляхів і забезпечення умов судноплавства у зимовий період;

- рятувальні судна, буксири рятувальні, аварійно-рятувальні судна, призначені для виконання рятувальних робіт;

- патрульні судна, призначені для несення патрульної служби;

- хімозачисні станції, призначені для виконання робіт з очищення суден від бруду.

2.4.4. Основними типами технічних суден є:

- земснаряди, землесоси, гідропісконавантажувачі, грунтовозні шаланди, грунтовозні судна, призначені для виконання робіт з підтримки габаритів водного шляху та акваторії порту;

- нафтозбірні судна, призначені для збору з водної поверхні залишків нафтопродуктів або інших наливних вантажів;

- плавучі доки та майстерні, ремонтні майстерні, призначені для виконання технічного обслуговування інших суден.

2.4.5. Основними типами службово-допоміжних суден є:

- буксирні, призначені для буксирування, штовхання, одночасного буксирування або штовхання суден, барж, плотів;

- рейдово-маневрові, судна забезпечення паливом та продуктами життєзабезпечення, призначені для обслуговування флоту;

- лоцманські, роз'їзні, протипожежні, водолазні, санітарні, асенізаційні, агітаційні, призначені для обслуговування портового господарства;

- плавучі крани, кранові судна, буксири для завезення якорів, зерноперевантажувачі, призначені для здійснення вантажопідйомних операцій;

- інші (понтони, дебаркадери, брандвахти, плавучі копри, плавучі готелі, плавучі ресторани).

2.5. Основними технічними характеристиками торговельних суден є:

- валова місткість (куб. метр) - найбільший об'єм корпусу та приміщень на судні як інженерної споруди, окрім об'єму рульової рубки, камбузів, туалетів, усіх світлових люків та східних мілких рубок;

- вантажопідйомність (т) - максимальна вага (брутто) вантажу, яку може прийняти судно на борт;

- дейдвейт (т) - різниця між водотоннажністю судна до вантажної ватерлінії, що відповідає призначеному літньому надводному борту у воді із щільністю 1,025 т/куб.м, та водотоннажністю порожнього судна;

- водотоннажність порожнього судна (т) - об'єм підводної частини судна без вантажу, палива, мастила, баластної, прісної, котельної води в цистернах, стічних вод, запасів на судні, а також без пасажирів, але з водою, паливом у судових системах та механізмах; ( Абзац четвертий пункту 2.5 із змінами, внесеними згідно з Наказом Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

- потужність (кВт) - механічна потужність головної силової установки, яку може розвити двигун судна (кілька двигунів); один кВт дорівнює 1,36 к.с.;

- пасажиромісткість (пасажирів) - максимально допустима кількість пасажирів, яку може перевозити судно.

2.6. Причал - гідротехнічна споруда (або їх комплекс), яка функціонує у складі порту або самостійно і призначена для підходу, швартування, стоянки та обслуговування суден, посадки і висадки пасажирів, вантажних операцій тощо. Механізований причал - берегова споруда, оснащена закріпленими береговими і плавучими навантажувально-розвантажувальними механізмами. ( Пункт 2.6 в редакції Наказу Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

3. Документи первинного обліку

Документами первинного обліку наявності торговельних суден є:

- загальносуднова специфікація; ( Абзац перший пункту 3 із змінами, внесеними згідно з Наказом Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

- класифікаційне свідоцтво або обмірне свідоцтво; ( Абзац пункту 3 із змінами, внесеними згідно з Наказом Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

- мірильне свідоцтво;

- міжнародне мірильне свідоцтво;

- пасажирське свідоцтво;

- свідоцтво про безпеку вантажного судна стосовно обладнання та забезпечення;

- свідоцтво про придатність до плавання для суден під прапором України. ( Абзац пункту 3 із змінами, внесеними згідно з Наказом Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

Документом первинного обліку про морський (річковий) причал порту (пристані) є:

свідоцтво про реєстрацію причалу (пристані);

свідоцтво про придатність причалу (пристані) до експлуатації.

( Абзац пункту 3 в редакції Наказу Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

4. Порядок складання звіту

( Назва пункту 4 в редакції Наказу Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

4.1. Державне статистичне спостереження за формою N 2-вод "Звіт про наявність власних морських і річкових суден, вантажних та пасажирських причалів-набережних" ( v0254202-99 ) складають один раз у три роки за станом на 31 грудня підприємства - юридичні особи всіх форм власності та видів економічної діяльності, які мають на балансі торговельні судна, а також причали. Обліку підлягає інвентарна кількість наявних торговельних суден, причалів, що перебувають на балансі підприємства незалежно від їх придатності до експлуатації та технічного стану, місцезнаходження (на території України або в інших державах) з урахуванням таких, що здані в оренду іншим підприємствам. { Абзац перший пункту 4.1 із змінами, внесеними згідно з Наказом Державного комітету статистики N 551 ( z1280-06 ) від 27.11.2006 }

Звіт не складають іноземні підприємства - власники торговельних суден, які знаходяться на території України, та підприємства, що орендують судна або причали.

До звіту не включаються дані про наявність малих суден - пасажирських суден місткістю до 12 чоловік та потужністю головних двигунів менше 55 кВт, рибальських суден з потужністю головного двигуна менше 50 кВт, вантажних транспортних суден потужністю енергетичного обладнання менше 100 кВт або валовою місткістю до 80 рег. тонн.

( Пункт 4.1 із змінами, внесеними згідно з Наказом Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

4.2. Державне статистичне спостереження за формою N 2-вод ( v0254202-99 ) складається за типами та призначенням суден за такими технічними характеристиками: валова місткість, вантажопідйомність, дейдвейт, потужність, пасажиромісткість.

Дані про судна, що не придатні для експлуатації, заповнюють на підставі загальносуднової специфікації (рік побудови, реєстраційна потужність, повна вантажопідйомність - дейдвейт, чиста вантажопідйомність, пасажиромісткість).

Дані про судна, що придатні для експлуатації, заповнюють на підставі документів про проходження класифікаційного та конвекційного нагляду:

- класифікаційного свідоцтва або обмірного свідоцтва (тип, рік побудови, валова місткість, дейдвейт, сумарна потужність);

- мірильного свідоцтва (рік побудови, валова місткість) або міжнародного мірильного свідоцтва (рік побудови, валова місткість, пасажиромісткість);

- пасажирського свідоцтва (валова місткість, пасажиромісткість);

- свідоцтва про безпеку вантажного судна щодо обладнання та забезпечення (валова місткість, дейдвейт);

- свідоцтва про придатність до плавання для суден під прапором України (валова місткість, рік побудови, потужність).

4.3. Облік суден у державному статистичному спостереженні за формою N 2-вод ( v0254202-99 ) передбачає групування за ознаками:

- "за віком (з моменту побудови)" - до 5 років, від 5 до 10 років, від 10 до 20 років, від 20 років і більше стосовно Правил регістру України;

- "нові судна" - судна, побудовані у звітному році;

- "за вантажопідйомністю".

( Абзац п'ятий пункту 4.3 виключено на підставі Наказу Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

( Абзац шостий пункту 4.3 виключено на підставі Наказу Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

4.4. Судна змішаного типу "ріка-море", призначені для судноплавства внутрішніми водними шляхами (річками, озерами, каналами) з правом виходу в море, рахуються до річкового флоту та у розділах 1.1, 1.3 показують дейдвейт.

Валову місткість згідно з Міжнародною конвенцією про обмірювання суден 1969 року (МК-69) ( 995_145 ) заповнюють судна, які працюють у закордонному сполученні, крім річки Дунай (згідно з протоколом Міжнародної конвенції про обмірювання суден 1969 року, до якої приєдналась Україна).

Суднобудівні та судноремонтні заводи, які мають на балансі суднобудівні і судноремонтні причали, включають їх до рядка 3051. ( Пункт 4.4 в редакції Наказу Державного комітету статистики N 303 ( z1308-05 ) від 11.10.2005 )

5. Порядок подання звіту

Звіт державного статистичного спостереження за формою N 2-вод "Звіт про наявність власних морських і річкових суден, вантажних та пасажирських причалів-набережних" (один раз у три роки) ( v0363202-04 ) заповнюється і підписується керівником підприємства, який несе адміністративну відповідальність за його повноту та достовірність згідно з чинним законодавством.
