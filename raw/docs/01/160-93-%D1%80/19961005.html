Про здійснення експорту товарів за кодами ТН ЗЕД

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 березня 1993 р. N 160-р Київ

( Із змінами, внесеними згідно з Розпорядження КМ N 647 ( 647-96-р ) від 05.10.96 )

( Розпорядження втратило чинність в частині надання повноважень на здійснення експорту спирту за кодом ТН ЗЕД 22.07 на підставі Розпорядження КМ N 647-р ( 647-96-р ) від 05.10.96 )

Відповідно до декретів Кабінету Міністрів України від 26 грудня 1992 р. N 16-92 ( 16-92 ) "Про встановлення спеціального режиму експорту окремих видів товарів" та від 31 грудня 1992 р. N 25-92 ( 25-92 ) "Про державне регулювання виробництва, торгівлі, експорту спирту, напоїв з його використанням і торгівлю тютюновими виробами" за поданням МЗЕЗ уповноважити здійснювати експорт товарів за кодами:

Верхньодніпровський державний гірничо-металургійний комбінат - ТН ЗЕД 2614.00100, 2614.00900, 2615.10000, 8112.91100;

Миколаївський глиноземний завод - ТН ЗЕД 2606, 7601, 7610, 8112.91900;

Броварський завод алюмінієвих будівельних конструкцій - ТН ЗЕД 7612.90910, 7612.90990, 7604, 7610, 7615;

концерн "Укрспирт" Держхарчопрому - ТН ЗЕД 2207, 2208;

концерн "Хлорвініл" - ТН ЗЕД 8104.11000.
