Кабінет Міністрів України; Розпорядження від 18.03.1992 № 158-р

Питання розміщення Мінвестбуду України

Стан: Втратив чинність

Ідентифікатор: 158-92-р

Текст документа від 06.09.1994:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 березня 1992 р. N 158-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 656-р ( 656-94-р ) від 06.09.94 )

( Із змінами, внесеними згідно з Розпорядженням КМ N 267-р ( 267-92-р ) від 08.05.92 )

( Додатково див. Розпорядження КМ N 775-р ( 775-92-р ) від 27.11.92 )

1. Передати на баланс Мінвестбуду України будинки по вулицях Прорізній, 15, Струтинського, 4, Карла Маркса, 11 в і Червоноармійській, 29 б, у м. Києві.

Мінівестбуду України разом з Київським міськвиконкомом вирішити питання про вивільнення службової площі, що арендується у вказаних будинках сторонніми організаціями.

Мінівестбуду України вивільнити у місячний строк службові приміщення в будинку по вул. Садовій, 3, в яких розміщено центральний апарат колишнього Держбуду України.

( Пункт 2 втратив чинність на підставі Розпорядження КМ N 267-р ( 267-92-р ) від 08.05.92 )

3. Визнати таким, що втратив чинність, пункт 7 постанови Кабінету Міністрів УРСР від 24 червня 1991 р. N 52 ( 52-91-п ).
