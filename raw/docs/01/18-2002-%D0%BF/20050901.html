Кабінет Міністрів України; Постанова від 10.01.2002 № 18

Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери

Стан: Втратив чинність

Ідентифікатор: 18-2002-п

Текст документа від 01.09.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 січня 2002 р. N 18 Київ

( Постанова втратила чинність на підставі Постанови КМ N 790 ( 790-2005-п ) від 22.08.2005 )

Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери

( Постанова втратила чинність у частині підвищення на 15 відсотків посадових окладів (ставок заробітної плати) працівників Національного академічного українського драматичного театру імені Марії Заньковецької згідно з Постановою КМ N 889 ( 889-2002-п ) від 01.07.2002 )

( Постанова втратила чинність у частині підвищення на 15 відсотків посадових окладів (ставок заробітної плати) працівників національних закладів культури згідно з Постановою КМ N 890 ( 890-2002-п ) від 01.07.2002 - набуває чинності з 01.01.2003 )

( Про підвищення з 1 березня 2004 р. на 10,8 відсотка посадових окладів додатково див. Постанову КМ N 166 ( 166-2004-п ) від 11.02.2004 )

( Постанова втратила чинність у частині підвищення на 15 відсотків посадових окладів (ставок заробітної плати) працівників Національної бібліотеки України для дітей згідно з Постановою КМ N 498 ( 498-2004-п ) від 14.04.2004 )

( Про підвищення з 1 січня 2005 р. у два рази діючих станом на 1 березня 2004 р. максимальні посадових окладів додатково див.

Постанову КМ N 995 ( 995-2004-п ) від 03.08.2004 )

( Про підвищення з 1 вересня 2004 р. у два рази діючих станом на 1 березня 2004 р. посадових окладів додатково див. Постанову КМ N 1051 ( 1051-2004-п ) від 16.08.2004 )

Кабінет Міністрів України постановляє:

1. Підвищити з 1 лютого 2002 р. на 15 відсотків посадові оклади (ставки заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери, передбачені постановою Кабінету Міністрів України від 7 лютого 2001 р. N 134 ( 134-2001-п ) "Про впорядкування умов оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" (Офіційний вісник України, 2001 р., N 7, ст. 278, N 21, ст. 938), крім працівників, яким вони підвищені згідно з постановами Кабінету Міністрів України від 14 серпня 2001 р. N 1045 ( 1045-2001-п ) "Про підвищення посадових окладів (ставок заробітної плати) та погодинної оплати праці працівників установ і закладів освіти" (Офіційний вісник України, 2001 р., N 33, ст. 1547) та від 15 жовтня 2001 р. N 1345 ( 1345-2001-п ) "Про оплату праці працівників національних закладів культури" (Офіційний вісник України, 2001 р., N 42, ст. 1889).

2. Міністерствам, іншим центральним органам виконавчої влади, а також галузевим академіям наук, за погодженням з Міністерством праці та соціальної політики і Міністерством фінансів привести свої нормативно-правові акти з питань оплати праці працівників підвідомчих бюджетних установ, закладів та організацій у відповідність з цією постановою.
