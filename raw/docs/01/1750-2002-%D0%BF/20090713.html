КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2002 р. N 1750 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 674 ( 674-2009-п ) від 01.07.2009 }

Про затвердження складу наглядової ради Національного заповідника "Софія Київська"

( Із змінами, внесеними згідно з Постановою КМ N 409 ( 409-2003-п ) від 31.03.2003 )

Кабінет Міністрів України постановляє:

1. Затвердити склад наглядової ради Національного заповідника "Софія Київська" згідно з додатком.

2. Визнати такими, що втратили чинність:

абзац п'ятий пункту 1 постанови Кабінету Міністрів України від 13 травня 1996 р. N 500 ( 500-96-п ) "Про Національний заповідник "Софія Київська" (ЗП України, 1996 р., N 11, ст. 324);

постанову Кабінету Міністрів України від 15 лютого 1999 р. N 197 ( 197-99-п ) "Про затвердження нового складу наглядової ради Національного заповідника "Софія Київська" (Офіційний вісник України, 1999 р., N 7 ст. 250).
