Кабінет Міністрів України; Розпорядження від 04.07.1997 № 364-р

Про збереження пільг Жолобову В.М.

Стан: Втратив чинність

Ідентифікатор: 364-97-р

Текст документа від 04.12.2014:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 липня 1997 р. N 364-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 673 ( 673-2014-п ) від 26.11.2014 }

Надати право колишньому голові Херсонської обласної державної адміністрації, заступнику генерального директора НКА, льотчику-космонавту СРСР, Герою Радянського Союзу Жолобову Віталію Михайловичу:

користування приміщенням (1 кімната) у будинку відпочинку Господарського управління Кабінету Міністрів України;

виклику автомашини з автопідприємства Господарського управління Кабінету Міністрів України у межах визначеної кількості годин.

Виконуючий обов'язки Прем'єр-міністра України В.ДУРДИНЕЦЬ
