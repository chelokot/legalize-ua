КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 жовтня 2009 р. N 1235 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про особливості закупівлі запасних частин, необхідних для проведення ремонту рятувального судна "Світломор-4"

Кабінет Міністрів України постановляє:

Установити, що:

відповідно до пункту 6 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692, N 90, ст. 3006), закупівля запасних частин, необхідних для проведення ремонту рятувального судна "Світломор-4", здійснюється державним підприємством "Одеський морський торговельний порт" за процедурою закупівлі в одного учасника без погодження з Міністерством економіки;

державне підприємство "Одеський морський торговельний порт" у триденний строк після укладення відповідного договору про закупівлю надсилає його копію Міністерству економіки та Головному контрольно-ревізійному управлінню.

Прем'єр-міністр України Ю.ТИМОШЕНКО
