Про забезпечення взаємодії Кабінету Міністрів України з Верховною Радою України, місцевими органами виконавчої влади та органами місцевого самоврядування

Ідентифікатор: 685-2002-р

Текст документа від 13.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 грудня 2002 р. N 685-р Київ

Про забезпечення взаємодії Кабінету Міністрів України з Верховною Радою України, місцевими органами виконавчої влади та органами місцевого самоврядування

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 686-р ( 686-2002-р ) від 12.12.2002 N 252-р ( 252-2003-р ) від 23.04.2003 Постановою КМ N 1106 ( 1106-2003-п ) від 17.07.2003 Розпорядженнями КМ N 4-р ( 4-2005-р ) від 11.01.2005 N 51-р ( 51-2005-р ) від 03.03.2005 N 477-р ( 477-2006-р ) від 31.08.2006 N 615-р ( 615-2006-р ) від 13.12.2006 }

З метою забезпечення взаємодії Кабінету Міністрів України з Верховною Радою України, місцевими органами виконавчої влади та органами місцевого самоврядування закріпити керівників Кабінету Міністрів України за депутатськими фракціями (групами) та комітетами Верховної Ради України, а міністерства та інші центральні органи виконавчої влади за адміністративно-територіальними одиницями згідно з додатками 1 і 2.
