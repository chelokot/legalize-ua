КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 грудня 2002 р. N 685-р Київ

Про забезпечення взаємодії Кабінету Міністрів України з Верховною Радою України, місцевими органами виконавчої влади та органами місцевого самоврядування

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 686-р ( 686-2002-р ) від 12.12.2002 N 252-р ( 252-2003-р ) від 23.04.2003 Постановою КМ N 1106 ( 1106-2003-п ) від 17.07.2003 Розпорядженнями КМ N 4-р ( 4-2005-р ) від 11.01.2005 N 51-р ( 51-2005-р ) від 03.03.2005 N 477-р ( 477-2006-р ) від 31.08.2006 N 615-р ( 615-2006-р ) від 13.12.2006 N 705-р ( 705-2010-р ) від 31.03.2010 N 980-р ( 980-2010-р ) від 28.04.2010 N 1038-р ( 1038-2010-р ) від 12.05.2010 N 1084-р ( 1084-2010-р ) від 26.05.2010 N 1690-р ( 1690-2010-р ) від 18.08.2010 N 2004-р ( 2004-2010-р ) від 20.10.2010 N 31-р ( 31-2011-р ) від 19.01.2011 }

З метою забезпечення взаємодії Кабінету Міністрів України з Верховною Радою України, місцевими органами виконавчої влади та органами місцевого самоврядування закріпити керівників Кабінету Міністрів України за депутатськими фракціями (групами) та комітетами Верховної Ради України, а міністерства та інші центральні органи виконавчої влади за адміністративно-територіальними одиницями згідно з додатками 1 і 2.

Прем'єр-міністр України В.ЯНУКОВИЧ
