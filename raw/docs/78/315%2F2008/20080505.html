Президент України; Указ від 10.04.2008 № 315/2008

Питання Київського національного університету імені Тараса Шевченка

Стан: Чинний

Ідентифікатор: 315/2008

Текст документа від 05.05.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Київського національного університету імені Тараса Шевченка

{ Із змінами, внесеними згідно з Указом Президента N 410/2008 ( 410/2008 ) від 05.05.2008 }

1. Вважати СКОПЕНКА Віктора Васильовича звільненим з посади Ректора Київського національного університету імені Тараса Шевченка у зв'язку з виходом на пенсію.

{ Стаття 1 із змінами, внесеними згідно з Указом Президента N 410/2008 ( 410/2008 ) від 05.05.2008 }

2. Міністерству освіти і науки України забезпечити організацію відповідно до Закону України "Про вищу освіту" ( 2984-14 ) виборів Ректора Київського національного університету імені Тараса Шевченка.

3. Тимчасово, до вирішення в установленому порядку питання про призначення Ректора Київського національного університету імені Тараса Шевченка, покласти виконання обов'язків Ректора Київського національного університету імені Тараса Шевченка на ГУБЕРСЬКОГО Леоніда Васильовича - директора Інституту міжнародних відносин Київського національного університету імені Тараса Шевченка, академіка Національної академії наук України, увільнивши від виконання обов'язків Ректора Київського національного університету імені Тараса Шевченка В. Литвина.

{ Стаття 3 із змінами, внесеними згідно з Указом Президента N 410/2008 ( 410/2008 ) від 05.05.2008 }

4. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 10 квітня 2008 року N 315/2008
