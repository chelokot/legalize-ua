КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 вересня 2000 р. N 1494 Київ

{ Постанова втрачає чинність на підставі Постанови КМ N 93 ( 93-2003-п ) від 18.01.2003 з дати набрання чинності частиною тринадцятою статті 71 Митного кодексу України ( 92-15 ), яка набирає чинності з моменту набуття Україною членства у Світовій організації торгівлі }

Про тимчасове припинення дії постанови Кабінету Міністрів України від 18 вересня 1998 р. N 1460

Кабінет Міністрів України постановляє:

1. Припинити на період до 1 січня 2001 р. дію постанови Кабінету Міністрів України від 18 вересня 1998 р. N 1460 ( 1460-98-п ) "Про внесення доповнення до постанови Кабінету Міністрів України від 27 січня 1997 р. N 65" (Офіційний вісник України, 1998 р., N 38, ст. 1392; 2000 р., N 8, ст. 320).

2. Ця постанова набирає чинності з дня її опублікування.
