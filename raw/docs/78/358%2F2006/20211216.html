Стан: Чинний

Ідентифікатор: 358/2006

Текст документа від 16.12.2021:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про довічні державні стипендії для військовослужбовців, осіб рядового і молодшого начальницького складу органів внутрішніх справ України, які брали безпосередню участь у гасінні пожежі на Чорнобильській АЕС та її охороні 26 квітня 1986 року

{ Із змінами, внесеними згідно з Указом Президента N 649/2021 ( 649/2021 ) від 14.12.2021 }

1. Заснувати з 1 червня 2006 року довічні державні стипендії для військовослужбовців, осіб рядового і молодшого начальницького складу органів внутрішніх справ України, які брали безпосередню участь у гасінні пожежі на Чорнобильській АЕС та її охороні 26 квітня 1986 року і внаслідок значного радіоактивного опромінення стали інвалідами (далі - довічні державні стипендії), призначивши їх зазначеним особам за списком, що додається.

2. Установити, що:

довічні державні стипендії виплачуються за місцем отримання пенсії щомісяця у розмірі п'яти прожиткових мінімумів для осіб, які втратили працездатність, незалежно від розміру пенсії чи заробітної плати; { Абзац другий статті 2 із змінами, внесеними згідно з Указом Президента N 649/2021 ( 649/2021 ) від 14.12.2021 }

у разі смерті стипендіата або виїзду його на постійне місце проживання за межі України виплата зазначеної стипендії припиняється.

3. Кабінету Міністрів України передбачати під час уточнення показників Державного бюджету України на 2006 рік ( 3235-15 ) та розроблення законопроектів про Державний бюджет України на 2007 і наступні роки кошти для фінансування видатків, пов'язаних з виплатою довічних державних стипендій.
