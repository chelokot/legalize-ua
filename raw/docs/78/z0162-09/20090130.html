Про втрату чинності наказу Міністерства праці України від 11.07.94 N 39

Відповідно до постанови Кабінету Міністрів України від 02.02.2000 N 207 ( 207-2000-п ) "Про визнання таким, що втратили чинність, актів Кабінету Міністрів України з питань оплати праці" НАКАЗУЮ:

Визнати таким, що втратив чинність, наказ Міністерства праці України від 11.07.94 N 39 ( z0168-94 ) "Про умови оплати праці працівників Головної лікарської служби "Укрзалізниці" Міністерства транспорту України", зареєстрований у Міністерстві юстиції України 25.07.94 за N 168/377.
