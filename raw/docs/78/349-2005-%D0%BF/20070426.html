Про закупівлю будівельно-монтажних робіт для завершення капітального ремонту і реконструкції будівлі Науково-практичного медичного центру дитячої кардіології та кардіохірургії Міністерства охорони здоров'я

Текст документа від 26.04.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 травня 2005 р. N 349 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 676 ( 676-2007-п ) від 26.04.2007 }

Про закупівлю будівельно-монтажних робіт для завершення капітального ремонту і реконструкції будівлі Науково-практичного медичного центру дитячої кардіології та кардіохірургії Міністерства охорони здоров'я

Відповідно до частини другої статті 2 Закону України "Про закупівлю товарів, робіт і послуг за державні кошти" ( 1490-14 ) Кабінет Міністрів України постановляє:

Визначити як специфічні будівельно-монтажні роботи, що закуповуються для завершення капітального ремонту та реконструкції будівлі Науково-практичного медичного центру дитячої кардіології та кардіохірургії Міністерства охорони здоров'я по вул. Чорновола, 28/1, у м. Києві.

Міністерству охорони здоров'я здійснити закупівлю зазначених робіт за процедурою закупівлі у одного постачальника (учасника) без погодження з Міністерством економіки.

Прем'єр-міністр України Ю.ТИМОШЕНКО
