КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 січня 1999 р. N 22 Київ

Про внесення змін і доповнень до постанови Кабінету Міністрів України від 3 липня 1998 р. N 1020

( Із змінами, внесеними згідно з Постановою КМ N 1698 ( 1698-2000-п ) від 14.11.2000 )

Відповідно до Указу Президента України від 17 листопада 1998 р. N 1257 ( 1257/98 ) "Про запровадження ліцензування діяльності господарюючих суб'єктів у сфері природних монополій" Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 1698 ( 1698-2000-п ) від 14.11.2000 )

2. Національній комісії регулювання електроенергетики у місячний термін подати на затвердження Кабінету Міністрів України порядок видачі ліцензій на здійснення видів підприємницької діяльності, ліцензування яких належить до компетенції комісії.

3. Ця постанова набирає чинності з 1 січня 1999 року.
