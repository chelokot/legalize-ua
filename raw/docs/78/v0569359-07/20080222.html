Про штатний розпис Центральної виборчої комісії на 2007 рік

Відповідно до статей 11, 12, пункту 7 частини другої статті 26, частин другої, четвертої статті 33, частини першої статті 36 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), постанов Кабінету Міністрів України від 28 лютого 2002 року N 228 ( 228-2002-п ) "Про затвердження Порядку складання, розгляду, затвердження та основних вимог до виконання кошторисів бюджетних установ", від 30 червня 2005 року N 522 ( 522-2005-п ) "Про оплату праці Голови, заступників Голови та членів Центральної виборчої комісії", від 9 березня 2006 року N 268 ( 268-2006-п ) "Про упорядкування структури та умов оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів", постанови Центральної виборчої комісії від 17 грудня 2007 року N 568 ( v0568359-07 ) "Про структуру і чисельність Секретаріату, патронатної служби, Служби розпорядника Державного реєстру виборців та автогосподарства Центральної виборчої комісії", наказу Міністерства праці та соціальної політики України від 2 жовтня 1996 року N 77 ( z0593-96 ) "Про умови оплати праці робітників, зайнятих обслуговуванням органів виконавчої влади, місцевого самоврядування та їх виконавчих органів, органів прокуратури, судів та інших органів", Колективного договору автогосподарства Центральної виборчої комісії на 2007 рік, Центральна виборча комісія постановляє:

1. Затвердити штатний розпис Центральної виборчої комісії на 2007 рік згідно з додатками 1, 2, 3* до цієї постанови.

2. Визнати такими, що втратили чинність, постанови Центральної виборчої комісії:

від 30 травня 2007 року N 40 ( v0040359-07 ) "Про штатний розпис Центральної виборчої комісії на 2007 рік";

від 6 грудня 2007 року N 565 ( v0565359-07 ) "Про внесення змін до штатного розпису Центральної виборчої комісії на 2007 рік".
