{ Наказ втратив чинність на підставі Наказу Міністерства соціальної політики N 518 ( z0871-20 ) від 27.07.2020 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 20.09.2004 N 230

Відповідно до постанови Кабінету Міністрів України від 22.08.2005 N 790 ( 790-2005-п ) "Про внесення змін та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести до наказу Міністерства праці та соціальної політики України від 20.09.2004 N 230 ( z1210-04 ) "Про умови оплати праці працівників Центру по усиновленню дітей при Міністерстві освіти і науки України", зареєстрованого в Міністерстві юстиції України 23.09.2004 за N 1210/9809, (із змінами), такі зміни:

1.1. У підпункті 1 "ґ" пункту 2 слова "відсутнього працівника або за вакантною посадою" виключити.

1.2. Викласти додаток у новій редакції (додається).

2. Ці зміни застосовуються з 1 вересня 2005 року.

Міністр І.Сахань

ПОГОДЖЕНО:

Заступник Міністра фінансів України В.М.Матвійчук
