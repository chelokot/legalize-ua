Про внесення змін до постанови Кабінету Міністрів України від 23 серпня 1995 р. N 672

Стан: Чинний

Ідентифікатор: 1220-2011-п

Текст документа від 30.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 листопада 2011 р. N 1220 Київ

Про внесення змін до постанови Кабінету Міністрів України від 23 серпня 1995 р. N 672

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 23 серпня 1995 р. N 672 ( 672-95-п ) "Про затвердження зразків і описів гербових печаток, печаток без зображення Державного Герба України, бланків і вивісок обласних, Київської та Севастопольської міських, районних, районних у містах Києві та Севастополі державних адміністрацій" зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 71

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 30 листопада 2011 р. N 1220

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 23 серпня 1995 р. N 672 ( 672-95-п )

1. У назві і тексті постанови ( 672-95-п ) слова "Державного герба України" замінити словами "Державного Герба України".

2. У додатках до постанови ( 672-95-п ):

1) додатки 1, 3-6 викласти в такій редакції:

"Додаток N 1 до постанови Кабінету Міністрів України від 23 серпня 1995 р. N 672 ( 672-95-п ) (у редакції постанови Кабінету Міністрів України від 30 листопада 2011 р. N 1220)

ЗРАЗКИ гербових печаток обласної, Київської та Севастопольської міської, районної, районної у містах Києві та Севастополі державної адміністрації

( 1220а-2011-п )";

"Додаток N 3 до постанови Кабінету Міністрів України від 23 серпня 1995 р. N 672 ( 672-95-п ) (у редакції постанови Кабінету Міністрів України від 30 листопада 2011 р. N 1220)

ЗРАЗКИ печаток без зображення Державного Герба України обласних державних адміністрацій

( 1220а-2011-п )

Додаток N 4 до постанови Кабінету Міністрів України від 23 серпня 1995 р. N 672 ( 672-95-п ) (у редакції постанови Кабінету Міністрів України від 30 листопада 2011 р. N 1220)

ЗРАЗКИ печаток без зображення Державного Герба України Київської та Севастопольської міських державних адміністрацій

( 1220а-2011-п )

Додаток N 5 до постанови Кабінету Міністрів України від 23 серпня 1995 р. N 672 ( 672-95-п ) (у редакції постанови Кабінету Міністрів України від 30 листопада 2011 р. N 1220)

ЗРАЗКИ печаток без зображення Державного Герба України районних державних адміністрацій

( 1220а-2011-п )

Додаток N 6 до постанови Кабінету Міністрів України від 23 серпня 1995 р. N 672 ( 672-95-п ) (у редакції постанови Кабінету Міністрів України від 30 листопада 2011 р. N 1220)

ЗРАЗКИ печаток без зображення Державного Герба України районних у містах Києві та Севастополі державних адміністрацій

( 1220а-2011-п )";

2) у додатку 2:

у другому реченні абзацу першого слова "малого герба України" замінити словами "малого Державного Герба України";

перше речення абзацу другого після слів "(для районних державних адміністрацій)" доповнити словами "та її ідентифікаційний код згідно з ЄДРПОУ";

абзац четвертий після слів "областей і міст" доповнити словами ", ідентифікаційних кодів місцевих державних адміністрацій згідно з ЄДРПОУ";

3) у додатку 7:

у назві та абзаці першому додатка слова "Державного герба України" замінити словами "Державного Герба України";

перше речення абзацу другого після слів "(для районних державних адміністрацій)" доповнити словами "та її ідентифікаційний код згідно з ЄДРПОУ";

абзац п'ятий після слів "областей і міст" доповнити словами ", ідентифікаційних кодів місцевих державних адміністрацій згідно з ЄДРПОУ";

4) у першому реченні абзацу другого додатка 10 слова "малого герба України" замінити словами "малого Державного Герба України";

5) у додатку 12:

у першому реченні абзацу другого слова "малого герба України" замінити словами "малого Державного Герба України";

в абзаці шостому слова "малий герб" замінити словами "малий Державний Герб України".
