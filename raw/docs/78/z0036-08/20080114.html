1. Затвердити Порядок контролю за додержанням Ліцензійних умов провадження господарської діяльності, пов'язаної із збиранням, обробленням, зберіганням, захистом, використанням інформації, яка складає кредитну історію ( z1384-06 ), що додається.

2. Департаменту ліцензування Державного комітету України з питань регуляторної політики та підприємництва (Іванченко О.Б.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Управлінню систематизації законодавства та правової інформації Міністерства юстиції України (Пушенко О.Г.) забезпечити офіційне оприлюднення цього наказу.

4. Контроль за виконанням цього наказу покласти на Голову Державного комітету України з питань регуляторної політики та підприємництва Ващенка К.О. та заступника Міністра юстиції України Богашеву Н.В.

ЗАТВЕРДЖЕНО Наказ Державного комітету України з питань регуляторної політики та підприємництва, Міністерства юстиції України 14.01.2008 N 5/27/5

Зареєстровано в Міністерстві юстиції України 18 січня 2008 р. за N 36/14727

ПОРЯДОК контролю за додержанням Ліцензійних умов провадження господарської діяльності, пов'язаної із збиранням, обробленням, зберіганням, захистом, використанням інформації, яка складає кредитну історію ( z1384-06 )

1. Загальні положення

1.1. Цей Порядок розроблений відповідно до Законів України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ), "Про організацію формування та обігу кредитних історій" ( 2704-15 ), постанови Кабінету Міністрів України від 14.11.2000 N 1698 ( 1698-2000-п ) "Про затвердження переліку органів ліцензування" та Ліцензійних умов провадження господарської діяльності, пов'язаної із збиранням, обробленням, зберіганням, захистом, використанням інформації, яка складає кредитну історію, затверджених наказом Державного комітету України з питань регуляторної політики та підприємництва і Міністерства юстиції України від 27.12.2006 N 115/107/5 ( z1384-06 ), зареєстрованих у Міністерстві юстиції України 28.12.2006 за N 1384/13258 (далі - Ліцензійні умови).

1.2. Цей Порядок встановлює правила та умови здійснення контролю за додержанням бюро кредитних історій (далі - ліцензіати) Ліцензійних умов ( z1384-06 ).

1.3. Контроль за додержанням ліцензіатами Ліцензійних умов ( z1384-06 ) у межах своїх повноважень здійснюють: Державний комітет України з питань регуляторної політики та підприємництва як спеціально уповноважений орган з питань ліцензування та його територіальні органи, Міністерство юстиції України як орган ліцензування (далі - органи контролю).

1.4. У цьому Порядку терміни вживаються у значеннях, наведених у Законах України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ) та "Про організацію формування та обігу кредитних історій" ( 2704-15 ).

1.5. Контроль за додержанням ліцензіатами Ліцензійних умов ( z1384-06 ) здійснюється шляхом проведення планових та позапланових перевірок.

1.6. Метою планової перевірки є встановлення фактичного стану додержання ліцензіатами Ліцензійних умов ( z1384-06 ).

Метою позапланової перевірки є встановлення фактичного стану виконання розпоряджень про усунення порушень Ліцензійних умов ( z1384-06 ) або перевірка інформації, зазначеної у заяві (повідомленні) про порушення ліцензіатами Ліцензійних умов.

1.7. Предметом перевірки є відповідність діяльності ліцензіатів вимогам Ліцензійних умов ( z1384-06 ) при здійсненні ними діяльності із збирання, оброблення, зберігання, захисту, використання інформації, що складає кредитну історію.

2. Організація перевірок

2.1. Планові перевірки додержання Ліцензійних умов ( z1384-06 ) здійснюються органами контролю відповідно до річних планів, які затверджуються органом контролю до 1 грудня року, що передує плановому. План перевірок органу контролю погоджується Держкомпідприємництвом.

2.2. Позапланові перевірки здійснюються органами контролю лише на підставі надходження до них у письмовій формі заяви (повідомлення) про порушення ліцензіатами Ліцензійних умов ( z1384-06 ) або з метою перевірки виконання розпоряджень про усунення порушень Ліцензійних умов.

2.3. Для проведення перевірки органи контролю видають наказ про створення комісії з перевірки (далі - комісія), у якому зазначаються найменування ліцензіата, щодо якого буде здійснюватися перевірка та строк проведення перевірки.

На підставі наказу оформляється посвідчення на проведення перевірки (додаток 1), яке підписується керівником органу контролю (його заступником) та засвідчується печаткою.

2.4. Посвідчення реєструється в Журналі обліку посвідчень на проведення перевірки (додаток 2), сторінки якого мають бути пронумеровані, прошнуровані та скріплені печаткою.

2.5. Орган контролю не пізніш як за десять робочих днів письмово повідомляє ліцензіата (наглядову раду в разі її створення та виконавчий орган товариства) про проведення перевірки. Повідомлення надсилається рекомендованим листом, телефонограмою або вручається особисто керівнику або уповноваженій на це установчими документами, довіреністю, законом та іншими актами цивільного законодавства особі ліцензіата (далі - уповноважена особа) під розписку на примірнику органу контролю.

2.6. Перевірка на письмове клопотання ліцензіата може бути перенесена за згодою керівника органу контролю.

3. Права та обов'язки комісії і посадових осіб ліцензіатів

3.1. Голова та члени комісії при здійсненні перевірки мають право:

отримувати всю необхідну інформацію щодо дотримання ліцензіатом Ліцензійних умов ( z1384-06 ) від посадових осіб ліцензіата;

входити до будь-яких приміщень ліцензіата, у яких здійснюється господарська діяльність, яка підлягає ліцензуванню, для з'ясування питань, безпосередньо пов'язаних з перевіркою;

оглядати за участю посадових осіб ліцензіата територію, будівлі, споруди, приміщення та обладнання, що використовуються для здійснення господарської діяльності, яка підлягає ліцензуванню;

ознайомлюватися з усіма необхідними для проведення перевірки документами ліцензіата та отримувати їх копії, витяги з цих документів, дані на комп'ютерних електронних носіях та інші матеріали, які стосуються господарської діяльності, яка підлягає ліцензуванню;

ознайомлюватися з документами ліцензіата з обмеженим доступом, що стосуються господарської діяльності, яка підлягає ліцензуванню;

одержувати від ліцензіата письмові пояснення з питань, що виникають під час проведення перевірки.

3.2. Голова та члени комісії при здійсненні перевірки зобов'язані:

дотримуватися визначених вимог законодавства щодо збереження конфіденційної та службової інформації;

забезпечувати нерозголошення комерційної таємниці, що стає доступною їм у ході здійснення перевірки;

на будь-якій стадії перевірки приймати від посадових осіб ліцензіата подані за їх ініціативою заяви, зауваження, пояснення щодо предмета перевірки та проводити перевірку викладених у цих зверненнях питань, про що зазначати в акті перевірки.

3.3. Посадові особи ліцензіата під час здійснення перевірки мають право:

вимагати від комісії додержання вимог законодавства;

перевіряти наявність у членів комісії службового посвідчення і одержувати копію посвідчення на проведення перевірки;

не допускати комісію до проведення перевірки, якщо:

вона проводиться з порушенням вимог щодо періодичності проведення перевірок;

голова або член комісії не надав копію посвідчення на проведення перевірки або наданий документ не відповідає вимогам цього Порядку;

бути присутніми під час здійснення перевірки;

вимагати нерозголошення інформації, що є комерційною таємницею ліцензіата;

одержувати та ознайомлюватися з актом перевірки;

надавати в письмовій формі свої пояснення, зауваження або заперечення до акта перевірки;

оскаржувати в установленому законом порядку неправомірні дії комісії.

3.4. Посадові особи ліцензіата зобов'язані:

допускати комісію до перевірки за умови дотримання вимог здійснення контролю, передбачених законодавством;

виконувати вимоги органу контролю щодо усунення виявлених порушень Ліцензійних умов ( z1384-06 );

сприяти нормальній роботі комісії, не чинити їй перешкод, забезпечити комісію робочими місцями та необхідними технічними засобами;

надавати для ознайомлення необхідні документи та надавати їх копії, пояснення, довідки, відомості та інші матеріали з питань, що стосуються предмета перевірки;

одержувати примірник акта перевірки та розпорядження органу контролю про усунення виявлених порушень Ліцензійних умов ( z1384-06 ).

4. Порядок проведення перевірки

4.1. Перед початком здійснення перевірки голова комісії зобов'язаний пред'явити керівнику (уповноваженій особі) ліцензіата посвідчення на проведення перевірки та службові посвідчення голови та членів комісії і надати копію посвідчення на проведення перевірки.

У разі проведення позапланової перевірки на підставі надходження до органу контролю у письмовій формі заяви (повідомлення) про порушення ліцензіатом Ліцензійних умов ( z1384-06 ) керівнику (уповноваженій особі) ліцензіата надається для ознайомлення копія цієї заяви (повідомлення).

4.2. Перед початком здійснення перевірки голова комісії вносить запис до відповідного журналу ліцензіата про строк проведення перевірки, посади, прізвища та ініціали голови та членів комісії (за наявності такого журналу).

4.3. Посадові особи ліцензіата зобов'язані забезпечити належні, у тому числі технічні, умови для роботи членів комісії, якісного та повного виконання поставлених перед ними завдань. У разі створення перешкод в роботі комісії її голова складає акт про відмову ліцензіата в проведенні перевірки (додаток 3) в двох примірниках.

4.4. Відмовою ліцензіата в проведенні перевірки вважається:

відсутність керівника (уповноваженої особи) ліцензіата при проведенні перевірки;

відмова ліцензіата в доступі комісії на свою територію, до будівель, споруд та інших приміщень ліцензіата, у яких здійснюється ліцензована господарська діяльність;

відмова ліцензіата забезпечити умови для проведення перевірки або надати всі необхідні документи, що підтверджують додержання ним Ліцензійних умов ( z1384-06 ).

При цьому в акті про відмову ліцензіата в проведенні перевірки вказуються ці факти, а до акта додаються відповідні пояснення керівника (посадових осіб) ліцензіата (у разі їх надання).

4.5. При плановій перевірці комісія перевіряє:

4.5.1. Документи:

ліцензію на провадження господарської діяльності, пов'язаної із збиранням, обробленням, зберіганням, захистом, використанням інформації, яка складає кредитну історію, або довідки органу ліцензування про прийняття заяви на переоформлення (про видачу дубліката) ліцензії;

свідоцтво про державну реєстрацію юридичної особи;

довідку про внесення до Єдиного державного реєстру підприємств та організацій України;

Положення бюро кредитних історій, погоджене Мін'юстом;

що підтверджують виконання технологічних умов, установлених Ліцензійними умовами ( z1384-06 );

що підтверджують виконання кваліфікаційних вимог, установлених Ліцензійними умовами ( z1384-06 );

що підтверджують здійснення обробки інформації, яка складає кредитну історію, в інформаційній, телекомунікаційній та/або інформаційно-телекомунікаційній системі ліцензіата, одержані в порядку, установленому Законом України "Про захист інформації в інформаційно-телекомунікаційних системах" ( 80/94-ВР );

що свідчать про своєчасне повідомлення Мін'юсту про зміну даних, зазначених у документах, що додавалися до заяви про видачу ліцензії.

4.5.2. Відповідність відомостей, що містяться у ліцензії, відомостям, зазначеним у свідоцтві про державну реєстрацію ліцензіата, довідці про внесення до Єдиного державного реєстру підприємств та організацій України, установчим документам ліцензіата.

4.5.3. Достовірність відомостей у документах, поданих ліцензіатом для отримання ліцензії.

4.5.4. Виконання розпоряджень про усунення порушень Ліцензійних умов ( z1384-06 ) у разі, якщо вони видавалися.

4.6. При позаплановій перевірці комісія перевіряє факти порушення ліцензіатом Ліцензійних умов, наведені в заяві (повідомленні), або виконання ліцензіатом розпоряджень про усунення порушень Ліцензійних умов ( z1384-06 ).

4.7. Усі копії та витяги з документів, які стосуються предмета перевірки, отримані членами комісії, повинні бути засвідчені підписом керівника (уповноваженої особи) ліцензіата та печаткою ліцензіата.

4.8. Отримані від уповноважених та інших осіб ліцензіата пояснення з питань, які стосуються предмета перевірки, долучаються до акта перевірки.

5. Оформлення результатів перевірки

5.1. За результатами перевірки комісія складає акт перевірки додержання Ліцензійних умов (додаток 4), у якому зазначаються: підстава, мета перевірки, період, за який проводилася перевірка, склад комісії та фактичний стан додержання Ліцензійних умов ( z1384-06 ).

У цьому акті відображаються результати перевірки дотримання вимог, передбачених Ліцензійними умовами ( z1384-06 ), факти порушень Ліцензійних умов, інформація про документи та інші матеріали, на яких ґрунтуються викладені факти, прізвища та посади осіб, причетних до вчиненого порушення, та їх пояснення.

5.2. Порушення, які були виявлені при перевірці, мають бути викладені в акті перевірки з посиланням на конкретні пункти Ліцензійних умов, що були порушені ліцензіатом. Довільне викладання або трактування в цьому акті вимог Ліцензійних умов ( z1384-06 ) не допускається.

Результат перевірки викладається достовірно, обґрунтовано та наводиться вичерпний опис виявлених фактів і даних. Не допускається включення до акта різного роду припущень та непідтверджених даних про ліцензіата.

5.3. Акт перевірки додержання Ліцензійних умов ( z1384-06 ) складається у двох примірниках та підписується головою та членами комісії, керівником (уповноваженою особою) ліцензіата. Голова комісії підписує кожну сторінку цього акта та відповідає за об'єктивність та обґрунтованість акта перевірки додержання Ліцензійних умов.

Один примірник акта перевірки передається керівнику (уповноваженій особі) ліцензіата.

5.4. У разі незгоди керівника (уповноваженої особи) ліцензіата з фактами, викладеними в акті, їх обґрунтуваннями та доказами він не пізніше трьох робочих днів з дати складання акта перевірки повинен подати голові комісії аргументовані письмові зауваження стосовно питань, з якими не погоджується. При цьому на всіх примірниках акта перевірки перед підписом керівника (уповноваженої особи) ліцензіата робиться запис "Із зауваженнями". Зазначені зауваження розглядаються протягом одного робочого дня після їх отримання. Результати розгляду цих зауважень викладаються окремою довідкою і підписуються головою комісії. Зауваження і довідка про результати їх розгляду додаються до акта перевірки та є його невід'ємною частиною. Зауваження, подані з порушенням триденного строку, не розглядаються.

5.5. У разі відмови керівника (уповноваженої особи) ліцензіата від підписання акта перевірки додержання Ліцензійних умов ( z1384-06 ) цей факт фіксується в акті та засвідчується підписом голови комісії.

5.6. Датою складання акта перевірки додержання Ліцензійних умов ( z1384-06 ) є дата підписання цього акта головою, членами комісії та керівником (уповноваженою особою) ліцензіата.

5.7. У разі виявлення порушень Ліцензійних умов ( z1384-06 ) керівник органу контролю не пізніше п'яти робочих днів з дати складання акта перевірки додержання Ліцензійних умов видає розпорядження про усунення порушень Ліцензійних умов (додаток 5), який надсилається ліцензіату з повідомленням про вручення.

5.8. У разі усунення ліцензіатом порушень, зазначених в акті перевірки додержання Ліцензійних умов ( z1384-06 ), до прийняття розпорядження про їх усунення та надання органу контролю документів, які це підтверджують і не потребують додаткової перевірки, розпорядження про усунення порушень Ліцензійних умов не видається.

5.9. Ліцензіат, який одержав розпорядження про усунення порушень Ліцензійних умов ( z1384-06 ), зобов'язаний в установлений у розпорядженні строк усунути вищезазначені порушення Ліцензійних умов та подати в цей самий строк у письмовій формі органу контролю інформацію про їх усунення з поданням завірених копій первинних, розпорядчих та інших документів, що підтверджують усунення порушень.

5.10. Якщо ліцензіатом документально підтверджено усунення порушень Ліцензійних умов ( z1384-06 ), то перевірка виконання розпорядження про усунення порушень Ліцензійних умов може не проводитись.

5.11. У разі неподання ліцензіатом інформації про усунення порушень до органу контролю протягом строку, зазначеного в розпорядженні про усунення порушень Ліцензійних умов ( z1384-06 ), після закінчення цього строку проводиться позапланова перевірка.

Позапланова перевірка ліцензіата може бути проведена з метою перевірки інформації про усунення порушень Ліцензійних умов ( z1384-06 ), яка подається ліцензіатом органу контролю.

5.12. Якщо органом контролю в ході перевірки виявлено повторне порушення ліцензіатом Ліцензійних умов ( z1384-06 ); недостовірні відомості у документах, поданих ліцензіатом для одержання ліцензії; факт неподання в установлений строк повідомлення про зміну даних, зазначених у документах, що додавалися до заяви про видачу ліцензії, то протягом трьох робочих днів з дати складання акта перевірки додержання ліцензіатом Ліцензійних умов орган контролю, який провів цю перевірку, складає у двох примірниках відповідний акт про повторне порушення ліцензіатом Ліцензійних умов та/або акт про виявлення недостовірних відомостей у документах, поданих ліцензіатом для одержання ліцензії та/або акт про встановлення факту неподання в установлений строк повідомлення про зміну даних, зазначених у документах, що додавалися до заяви про видачу ліцензії (додаток 6).

Усі примірники актів підписуються головою та членами комісії. Один примірник акта зберігає орган контролю, а другий у дводенний строк вручається або надсилається рекомендованим листом керівнику ліцензіата.

5.13 Неможливістю ліцензіата забезпечити виконання Ліцензійних умов ( z1384-06 ) вважається недодержання підпункту 3.10 Ліцензійних умов.

Відомості про неможливість ліцензіата забезпечити виконання Ліцензійних умов ( z1384-06 ), які є підставою для анулювання ліцензії, викладаються на підставі акта перевірки додержання ліцензіатом Ліцензійних умов (додаток 6).

6. Рішення про анулювання ліцензії

6.1. Підставами для анулювання ліцензії є:

заява ліцензіата про анулювання ліцензії;

рішення про скасування державної реєстрації ліцензіата;

акт про невиконання розпорядження про усунення порушень Ліцензійних умов ( z1384-06 );

акт про повторне порушення ліцензіатом Ліцензійних умов ( z1384-06 );

акт про виявлення недостовірних відомостей у документах, поданих ліцензіатом для одержання ліцензії;

акт про встановлення факту неподання в установлений строк повідомлення про зміну даних, зазначених в документах, що додавалися до заяви про видачу ліцензії;

акт про встановлення факту передачі ліцензії іншій юридичній особі для провадження господарської діяльності;

неможливість ліцензіата забезпечити виконання Ліцензійних умов ( z1384-06 );

акт про відмову ліцензіата в проведенні перевірки органом ліцензування або спеціально уповноваженим органом з питань ліцензування.

6.3. У разі складання актів посадовими особами Держкомпідприємництва, що є підставою для анулювання ліцензії, Держкомпідприємництво звертається до Мін'юсту з пропозицією щодо анулювання ліцензії.

6.3. Розгляд питань про анулювання ліцензій на підставі акта про виявлення недостовірних відомостей у документах, поданих ліцензіатом для одержання ліцензії; акта про встановлення факту неподання в установлений строк повідомлення про зміну даних, зазначених у документах, що додаються до заяви про видачу ліцензії; акта про невиконання розпорядження про усунення порушень Ліцензійних умов ( z1384-06 ) здійснюється Мін'юстом з обов'язковим запрошенням ліцензіата або його представника.

6.4. Мін'юст повинен отримати підтвердження щодо повідомлення ліцензіата про час та місце розгляду питання про анулювання ліцензії.

6.5. Розгляд питання про анулювання ліцензії в разі повторного порушення ліцензіатом Ліцензійних умов ( z1384-06 ) здійснюється за наявності таких документів:

акта перевірки додержання ліцензіатом Ліцензійних умов ( z1384-06 ), у якому відображені дані про повторне (повторні) порушення ліцензіатом Ліцензійних умов;

акта попередньої перевірки додержання ліцензіатом Ліцензійних умов ( z1384-06 );

розпорядження про усунення порушень Ліцензійних умов ( z1384-06 );

розпорядчого документа, на підставі якого здійснювалась відповідна перевірка.

6.6. Мін'юст приймає рішення про анулювання ліцензії протягом десяти робочих днів з дати встановлення підстав для анулювання. Рішення вручається (надсилається) ліцензіату із зазначенням підстав анулювання не пізніше трьох робочих днів з дати його прийняття.

6.7. Рішення про анулювання ліцензії набирає чинності через десять днів з дати його прийняття.

6.8. Запис про дату та номер рішення про анулювання ліцензії вноситься до Ліцензійного реєстру провадження господарської діяльності, пов'язаної із збиранням, обробленням, зберіганням, захистом, використанням інформації, яка складає кредитну історію, не пізніше наступного робочого дня після набрання чинності рішенням про анулювання ліцензії.

6.9. У разі анулювання ліцензії на підставі акта про повторне порушення ліцензіатом Ліцензійних умов ( z1384-06 ), акта про встановлення факту неподання в установлений строк повідомлення про зміну даних, зазначених у документах, що додавалися до заяви про видачу ліцензії, акта про виявлення недостовірних відомостей у документах, поданих ліцензіатом для одержання ліцензії, акта про невиконання розпорядження про усунення порушень Ліцензійних умов ліцензіат може одержати нову ліцензію на право провадження цього виду господарської діяльності не раніше ніж через рік з дати прийняття Мін'юстом рішення про анулювання ліцензії.

7. Оскарження рішення про анулювання ліцензії

7.1. У разі подання ліцензіатом протягом десяти днів з дня прийняття рішення про анулювання ліцензії скарги до експертно-апеляційної ради при Державному комітеті України з питань регуляторної політики та підприємництва дія даного рішення Мін'юсту як органу ліцензування зупиняється до прийняття відповідного рішення Держкомпідприємництвом.

7.2. Рішення експертно-апеляційної ради щодо звернення (апеляції) ліцензіата є підставою для видання Держкомпідприємництвом розпорядження про усунення порушень законодавства у сфері ліцензування, допущених Мін'юстом.

7.3. Рішення про анулювання ліцензії може бути оскаржене в судовому порядку.
