Про утворення Комітету у справах ветеранів

Стан: Втратив чинність

Ідентифікатор: 246/94

Текст документа від 27.11.1997:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1309/97 від 27.11.97 )

Про утворення Комітету у справах ветеранів

{ Щодо ліквідації Комітету додатково див. Указ Президента N 3/97 ( 3/97 ) від 04.01.97 }

З метою здійснення єдиної державної політики щодо правового та соціального захисту ветеранів постановляю:

1. Утворити при Президентові України Комітет у справах ветеранів (далі - Комітет).

2. Призначити ГЕРАСИМОВА Івана Олександровича Головою Комітету - Радником Президента України у справах ветеранів.

Президент України Л.КРАВЧУК
