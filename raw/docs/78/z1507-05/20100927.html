{ Із змінами, внесеними згідно з Наказом Державного комітету фінансового моніторингу N 81 ( z0686-09 ) від 07.07.2009 }

На виконання вимог Кодексу України про адміністративні правопорушення ( 80731-10, 80732-10 ) та з метою дотримання уповноваженими посадовими особами Державного комітету фінансового моніторингу України законодавства при оформленні ними матеріалів про адміністративні правопорушення НАКАЗУЮ:

1. Затвердити Інструкцію з оформлення матеріалів про адміністративні правопорушення, що додається.

2. Департаменту взаємодії та методичного забезпечення системи фінансового моніторингу (Підгородецька Л.М.) спільно з Юридичним управлінням (Чебан І.М.) забезпечити подання цього наказу до Міністерства юстиції України для державної реєстрації.

3. Контроль за виконанням цього наказу покласти на заступника Голови Державного комітету фінансового моніторингу Кірсанова В.М.

ІНСТРУКЦІЯ з оформлення матеріалів про адміністративні правопорушення

1. Загальні положення

Ця Інструкція розроблена відповідно до вимог Кодексу України про адміністративні правопорушення ( 80731-10, 80732-10 ) і встановлює порядок оформлення матеріалів, які складаються при адміністративному провадженні, та порядок їх обліку.

2. Оформлення матеріалів про адміністративні правопорушення

2.1. При вчиненні посадовими особами суб'єктів первинного фінансового моніторингу адміністративного правопорушення уповноважена посадова особа Державного комітету фінансового моніторингу України (далі - Уповноважена особа Держфінмоніторингу України) згідно зі статтями 254-256 Кодексу України про адміністративні правопорушення ( 80732-10 ) складає протокол про адміністративне правопорушення (далі - протокол) (додаток 1).

2.2. Усі реквізити протоколу заповнюються українською мовою. Не допускається закреслення чи виправлення відомостей, що заносяться до протоколу, а також унесення додаткових записів після того, як протокол підписаний особою, щодо якої він складений (далі - порушник).

2.3. Якщо правопорушення вчинено кількома особами, то протокол про адміністративне правопорушення складається на кожну особу окремо.

2.4. При складанні протоколу обов'язково вказується частина статті 166-9 Кодексу України про адміністративні правопорушення ( 80731-10 ), згідно з якою настає адміністративна відповідальність.

2.5. При викладенні обставин правопорушення вказуються місце та час його вчинення, суть правопорушення, які саме протиправні дії чи бездіяльність вчинив порушник та які положення законодавства цим порушено.

2.6. Якщо є свідки правопорушення, до протоколу вносяться прізвища, ім'я та по батькові свідків, адреси їх місця проживання, а також ставляться підписи свідків.

2.7. Уповноважена особа Держфінмоніторингу України зобов'язана ознайомити порушника з його правами і обов'язками, передбаченими статтею 268 Кодексу України про адміністративні правопорушення ( 80732-10 ), та змістом статті 63 Конституції України ( 254к/96-ВР ), про що робиться відмітка у протоколі. Про обізнаність з вищевказаним порушник ставить у протоколі свій підпис, а у разі відмови поставити підпис - про це робиться відповідний запис у протоколі, який засвідчується підписом Уповноваженої особи Держфінмоніторингу України.

{ Пункт 2.7 із змінами, внесеними згідно з Наказом Державного комітету фінансового моніторингу N 81 ( z0686-09 ) від 07.07.2009 }

2.8. Порушникові пропонується надати письмове пояснення за суттю вчиненого правопорушення, яке вноситься до протоколу і засвідчується підписом порушника. Пояснення може додаватись до протоколу окремо, про що робиться запис у цьому протоколі.

У разі відмови порушника, який притягається до адміністративної відповідальності, від надання пояснень за суттю вчиненого правопорушення, Уповноважена особа Держфінмоніторингу України вносить до нього відповідний запис. { Пункт 2.8 доповнено абзацом згідно з Наказом Державного комітету фінансового моніторингу N 81 ( z0686-09 ) від 07.07.2009 }

2.9. Протокол підписується Уповноваженою особою Держфінмоніторингу України, порушником і свідками, у випадку їх наявності. { Абзац перший пункту 2.9 в редакції Наказу Державного комітету фінансового моніторингу N 81 ( z0686-09 ) від 07.07.2009 }

У разі відмови порушника, який притягається до адміністративної відповідальності, від підписання протоколу Уповноважена особа Держфінмоніторингу України робить про це відповідний запис, який засвідчує своїм підписом та підписами свідків, у випадку їх наявності. { Абзац другий пункту 2.9 в редакції Наказу Державного комітету фінансового моніторингу N 81 ( z0686-09 ) від 07.07.2009 }

Порушник має право додати до протоколу пояснення і зауваження щодо змісту протоколу, а також викласти мотиви відмови від його підпису.

2.10. До протоколу долучаються матеріали, що підтверджують факт вчинення адміністративного правопорушення.

Кожний документ повинен мати свої реквізити (дату, адресу, назву, підписи тощо), містити достовірну інформацію та відповідати вимогам законодавства.

2.11. Складений протокол та інші матеріали, що підтверджують факт вчинення адміністративного правопорушення, формуються у справу, яка оформляється в установленому порядку. Справа про адміністративне правопорушення разом із супровідним листом Державного комітету фінансового моніторингу України направляються до районного (міського, міськрайонного) суду за місцем вчинення адміністративного правопорушення.

2.12. Протокол про адміністративне правопорушення складається у двох екземплярах, один з яких під розписку вручається порушнику, який притягається до адміністративної відповідальності.

{ Пункт 2.12 в редакції Наказу Державного комітету фінансового моніторингу N 81 ( z0686-09 ) від 07.07.2009 }

3. Облік матеріалів про адміністративні правопорушення

3.1. Протокол не пізніше наступного дня після його складання реєструється Уповноваженою особою Держфінмоніторингу України у Журналі реєстрації протоколів про адміністративні правопорушення (додаток 2), сторінки якого повинні бути прошнуровані та пронумеровані, а також скріплені печаткою Державного комітету фінансового моніторингу України.

3.2. Бланк протоколу має серію і номер.

3.3. Облік видачі бланків протоколів ведеться в Журналі видачі бланків протоколів про адміністративні правопорушення (додаток 3).

3.4. Журнали видачі бланків протоколів про адміністративні правопорушення та Журнали реєстрації протоколів про адміністративні правопорушення зберігаються протягом строку, встановленого законодавством України.
