{ Наказ втратив чинність на підставі Наказу Міністерства фінансів N 651 ( z1372-12 ) від 30.05.2012 }

Про внесення змін до класифікаторів, що використовуються при заповненні окремих граф вантажної митної декларації

{ Із змінами, внесеними згідно з Наказом Державної митної служби

N 1454 ( z0055-09 ) від 24.12.2008 }

З метою приведення нормативних актів Держмитслужби у відповідність до чинного законодавства України НАКАЗУЮ:

1. Унести такі зміни до класифікаторів, що використовуються при заповненні граф вантажної митної декларації:

1.1. Класифікатор видів митних платежів (додаток 1 до наказу Держмитслужби від 09.07.97 N 307 ( z0443-97 ) у редакції наказу Держмитслужби від 24.05.2000 N 300 ( z0349-00 ) викласти в новій редакції, що додається.

{ Підпункт 1.2 пункту 1 фактично втратив чинність у зв'язку з втратою чинності Наказу Державної митної служби N 363 ( z0443-98 ) від 23.06.98, до якого вносились зміни } 1.2. У Класифікаторі видів та ставок митних зборів (додаток 1 до Порядку справляння митних зборів, які нараховуються за вантажною митною декларацією, затвердженого наказом Держмитслужби від 23.06.98 N 363) ( z0443-98 ):

1.2.1. Виключити пункт 3.

1.2.2. Пункти 4 - 6 уважати відповідно пунктами 3 - 5.

2. Інформаційно-аналітичному митному управлінню (Копосов С.А.) унести відповідні зміни до програмного забезпечення, що використовується при митному оформленні товарів.

3. Управлінню митних платежів (Шульга С.В.) та Правовому управлінню (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Управлінню справами (Карпенко В.П.) забезпечити тиражування й розсилку цього наказу до регіональних митниць, митниць після його реєстрації в Міністерстві юстиції України.

5. Начальникам регіональних митниць, митниць довести цей наказ до відома суб'єктів підприємницької діяльності та підприємств, що здійснюють декларування на підставі договору, які працюють у зонах діяльності митних органів.

6. Контроль за виконанням наказу покласти на заступника Голови Служби Шейка О.П.

В.о. Голови Служби О.Єгоров
