КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 жовтня 1999 р. N 1889 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 879 ( 879-2013-п ) від 04.12.2013 }

Про внесення доповнення до постанови Кабінету Міністрів України від 2 квітня 1998 р. N 418

Кабінет Міністрів України постановляє:

Абзац другий пункту 1 постанови Кабінету Міністрів України від 2 квітня 1998 р. N 418 ( 418-98-п ) "Про встановлення показників питомої ваги давальницької сировини у загальній вартості готової продукції за окремими видами операцій у зовнішньоекономічних відносинах" (Офіційний вісник України, 1998 р., N 14, ст. 519) доповнити словами і цифрами "та на папір для пакування жировмісних харчових продуктів, що класифікується за кодом ТН ЗЕД 48.06 20000, який вивозиться з митної території України як давальницька сировина з метою виготовлення та ввезення готової продукції - паперу металізованого для харчових продуктів відповідно до коду ТН ЗЕД 48.11 90900".
