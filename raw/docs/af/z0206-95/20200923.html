Про затвердження форми заяви на патент на право оренди будівлі (споруди, приміщення)

{ Із змінами, внесеними згідно з Наказом Фонду державного майна

N 1850 ( z0883-02 ) від 22.10.2002 }

На виконання Указу Президента України від 30.12.94 N 827/94 "Про заходи щодо прискорення процесу малої приватизації в Україні" та у відповідності з Положенням про патент на право оренди будівель (споруд, приміщень), затвердженого наказом Фонду державного майна України N 90 ( z0071-95 ) від 31.01.95, НАКАЗУЮ:

1. Затвердити форму заяви на патент на право оренди будівлі (споруди, приміщення).

2. Департаменту малої приватизації та оцінки майна зареєструвати форму заяви в Міністерстві юстиції України.

3. Після реєстрації зазначеної форми Департаменту малої приватизації та оцінки майна забезпечити передачу документа регіональним відділенням Фонду державного майна України.

4. Контроль за виконанням цього наказу покласти на заступника Голови Фонду державного майна України О.Бондаря.

Голова Фонду державного майна України Ю.Єхануров
