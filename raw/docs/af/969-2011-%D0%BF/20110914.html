Про внесення змін і визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 969-2011-п

Текст документа від 14.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 вересня 2011 р. N 969 Київ

Про внесення змін і визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України зміни, що додаються.

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 вересня 2011 р. N 969

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

1. В абзаці першому пункту 1 і пункті 2 постанови Кабінету Міністрів України від 30 липня 1996 р. N 861 ( 861-96-п ) "Про визначення центрального органу та пункту зв'язку з питань фізичного захисту ядерного матеріалу" (Офіційний вісник України, 2001 р., N 33, ст. 1545) слова "Державний комітет ядерного регулювання" в усіх відмінках замінити словами "Державна інспекція ядерного регулювання" у відповідному відмінку.

2. У постанові Кабінету Міністрів України від 31 серпня 2005 р. N 845 ( 845-2005-п ) "Питання кваліфікаційної атестації та стимулювання працівників Державного комітету ядерного регулювання, які безпосередньо виконують функції з державного регулювання ядерної та радіаційної безпеки" (Офіційний вісник України, 2005 р., N 36, ст. 2186; 2008 р., N 49, ст. 1581):

у назві і тексті постанови ( 845-2005-п ) слова "Державний комітет ядерного регулювання" та "Міністерство праці та соціальної політики" в усіх відмінках замінити відповідно словами "Державна інспекція ядерного регулювання" та "Міністерство соціальної політики" у відповідному відмінку;

у пункті 1 слово "його" замінити словом "її".

3. У постанові Кабінету Міністрів України від 18 липня 2007 р. N 939 ( 939-2007-п ) "Про затвердження Технічного регламенту щодо контейнерів для зберігання та захоронення радіоактивних відходів і плану заходів з його застосування" (Офіційний вісник України, 2007 р., N 53, ст. 2162):

у пункті 2 слова "Державний комітет ядерного регулювання відповідальним" замінити словами "Державну інспекцію ядерного регулювання відповідальною";

у плані заходів із застосування Технічного регламенту щодо контейнерів для зберігання та захоронення радіоактивних відходів на 2007-2011 роки ( 939-2007-п ), затвердженому зазначеною постановою, слова "Держспоживстандарт", "Мінпаливенерго", "Мінпромполітики" замінити відповідно словами "Мінекономрозвитку", "Міненерговугілля", "Агентство держмайна".

4. У постанові Кабінету Міністрів України від 10 вересня 2008 р. N 809 ( 809-2008-п ) "Про встановлення надбавки за особливі умови роботи державним інспекторам Державного комітету ядерного регулювання" (Офіційний вісник України, 2008 р., N 69, ст. 2320):

у назві постанови ( 809-2008-п ) слова "Державного комітету ядерного регулювання" замінити словами "Державної інспекції ядерного регулювання";

в абзаці першому постанови ( 809-2008-п ) слова "Державного комітету ядерного регулювання та його" замінити словами "Державної інспекції ядерного регулювання та її".

5. У постанові Кабінету Міністрів України від 18 лютого 2009 р. N 118 ( 118-2009-п ) "Про першочергові заходи з будівництва енергоблоків N 3 і 4 Хмельницької АЕС" (Офіційний вісник України, 2009 р., N 13, ст. 397):

у пункті 1 постанови ( 118-2009-п ) слова "Міністерства палива та енергетики" замінити словами "Міністерства енергетики та вугільної промисловості";

у пункті 3 постанови ( 118-2009-п ) слова "Міністерства охорони навколишнього природного середовища і Державного комітету ядерного регулювання" замінити словами "Міністерства екології та природних ресурсів і Державної інспекції ядерного регулювання.".

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 вересня 2011 р. N 969

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 10 серпня 1992 р. N 458 ( 458-92-п ) "Про затвердження Положення про Головну державну інспекцію по нагляду за ядерною та радіаційною безпекою Державного комітету України з ядерної та радіаційної безпеки" (ЗП України, 1992 р., N 9, ст. 216).

2. Постанова Кабінету Міністрів України від 21 вересня 1995 р. N 751 ( 751-95-п ) "Питання Головної державної інспекції з нагляду за ядерною безпекою" (ЗП України, 1996 р., N 2, ст. 41).

3. Постанова Кабінету Міністрів України від 29 червня 1996 р. N 708 ( 708-96-п ) "Про затвердження Положення про порядок встановлення розмірів та накладення штрафів на підприємства, установи і організації, які здійснюють діяльність у сфері використання ядерної енергії, у разі порушення ними норм, правил і стандартів безпеки або умов дозволів на ведення робіт" (ЗП України, 1996 р., N 14, ст. 390).

4. Пункт 24 змін, що вносяться до актів Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 25 серпня 1998 р. N 1336 ( 1336-98-п ) (Офіційний вісник України, 1998 р., N 34, ст. 1277).

5. Пункт 4 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 9 серпня 2001 р. N 1006 ( 1006-2001-п ) (Офіційний вісник України, 2001 р., N 33, ст. 1545).

6. Постанова Кабінету Міністрів України від 27 грудня 2006 р. N 1830 ( 1830-2006-п ) "Про затвердження Положення про Державний комітет ядерного регулювання України" (Офіційний вісник України, 2006 р., N 52, ст. 3516).

7. Пункт 7 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 23 липня 2008 р. N 664 ( 664-2008-п ) (Офіційний вісник України, 2008 р., N 56, ст. 1867).

8. Постанова Кабінету Міністрів України від 10 червня 2009 р. N 571 ( 571-2009-п ) "Про доповнення пункту 4 Положення про Державний комітет ядерного регулювання України" (Офіційний вісник України, 2009 р., N 43, ст. 1443).
