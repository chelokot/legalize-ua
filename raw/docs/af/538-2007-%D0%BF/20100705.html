Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки роботи із створення умов для безпеки туристів, розбудови туристичної інфраструктури міжнародних транспортних коридорів та магістралей

Текст документа від 05.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 березня 2007 р. N 538 Київ

Про затвердження Порядку використання у 2007 році коштів, передбачених у державному бюджеті для фінансової підтримки роботи із створення умов для безпеки туристів, розбудови туристичної інфраструктури міжнародних транспортних коридорів та магістралей

{ Із змінами, внесеними згідно з Постановами КМ N 324 ( 324-2008-п ) від 09.04.2008 N 501 ( 501-2010-п ) від 23.06.2010 }

{ Установити, що у 2008 році кошти, передбачені Міністерству культури і туризму у державному бюджеті ( 107-17 ) для фінансової підтримки створення умов безпеки туристів та розбудови туристичної інфраструктури міжнародних транспортних коридорів та магістралей в Україні, використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 324 ( 324-2008-п ) від 09.04.2008 }

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

{ Установити, що у 2010 році кошти, передбачені у державному бюджеті ( 2154-17 ) за програмою "Фінансова підтримка створення умов безпеки туристів та розбудови туристичної інфраструктури міжнародних транспортних коридорів та магістралей в Україні", використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки роботи із створення умов для безпеки туристів, розбудови туристичної інфраструктури міжнародних транспортних коридорів та магістралей, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 березня 2007 р. N 538

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для фінансової підтримки роботи із створення умов для безпеки туристів, розбудови туристичної інфраструктури міжнародних транспортних коридорів та магістралей

Загальні питання

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) МКТ за програмою "Фінансова підтримка створення умов безпеки туристів та розбудови туристичної інфраструктури міжнародних транспортних коридорів та магістралей в Україні" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів є МКТ, розпорядником нижчого рівня - Держтуризмкурортів.

Напрями використання бюджетних коштів

3. Мета Порядку полягає у забезпеченні прозорої та ефективної процедури використання бюджетних коштів.

4. Бюджетні кошти спрямовуються на виконання робіт із створення безпечних умов для відвідування країни та об'єктів туристичної інфраструктури шляхом:

складення переліку туристичних маршрутів, об'єктів відвідувань та інфраструктури із зазначенням обов'язкових характеристик, вимог щодо безпеки туристів під час відвідування таких об'єктів та їх облаштування з метою віднесення до категорії "туристичний";

розроблення схеми розташування туристичних маршрутів, об'єктів відвідувань та інфраструктури;

створення системи інформаційного обслуговування туристів і суб'єктів туристичної індустрії;

виготовлення відповідно до міжнародних вимог спеціальних дорожніх знаків, що інформують про туристичні маршрути, об'єкти відвідування та інфраструктури; проведення інвентаризації об'єктів туристичної інфраструктури, облаштування туристичних маршрутів інформаційними знаками;

проведення семінарів і конференцій з метою залучення інвестицій для будівництва об'єктів туристичної інфраструктури;

розроблення та видання карт, схем, довідників для автотуристів з метою розповсюдження в пунктах перетину кордону та найбільших туристичних центрах.

Вимоги щодо використання бюджетних коштів

5. Бюджетні кошти використовуються Держтуризмкурортів у межах бюджетних призначень з урахуванням плану заходів щодо створення умов для безпеки туристів та розбудови туристичної інфраструктури міжнародних транспортних коридорів та магістралей (далі - план заходів), затвердженого Держтуризмкурортів за погодженням з МКТ і Мінфіном, та необхідності виконання бюджетних зобов'язань минулих років, взятих на облік в органах Державного казначейства, в разі їх відповідності паспорту бюджетної програми та напрямам, визначеним планом заходів. { Абзац перший пункту 5 із змінами, внесеними згідно з Постановами КМ N 324 ( 324-2008-п ) від 09.04.2008, N 501 ( 501-2010-п ) від 23.06.2010 }

У разі потреби Держтуризмкурортів вносить до плану заходів зміни за погодженням з МКТ і Мінфіном. { Абзац другий пункту 5 із змінами, внесеними згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

Для здійснення передбачених у плані заходів Держтуризмкурортів видає наказ, в якому зазначається найменування заходу, відповідальний за його виконання, дата і місце здійснення, сума витрат. До наказу додається кошторис витрат, пов'язаних з підготовкою та здійсненням заходу, з відповідними розрахунками та обґрунтуваннями. { Пункт 5 доповнено абзацом згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

Заходи здійснюються без залучення посередників. { Пункт 5 доповнено абзацом згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

Не допускається спрямування бюджетних коштів на: { Пункт 5 доповнено абзацом згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

придбання товарів, робіт і послуг, які безпосередньо не пов'язані із здійсненням заходів та участю в них; { Пункт 5 доповнено абзацом згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

оплату посередницьких послуг; { Пункт 5 доповнено абзацом згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

фінансування заходів, на проведення яких здійснюються видатки за рахунок коштів, передбачених на виконання інших бюджетних програм. { Пункт 5 доповнено абзацом згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

6. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку. { Абзац перший пункту 6 із змінами, внесеними згідно з Постановою КМ N 324 ( 324-2008-п ) від 09.04.2008 }

Виконавцем робіт відповідно до цього Порядку є переможець процедури закупівлі товарів, робіт і послуг.

7. Попередня оплата товарів, робіт і послуг здійснюється відповідно до постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) "Питання попередньої оплати товарів, робіт і послуг, що закуповуються за бюджетні кошти" (Офіційний вісник України, 2006 р., N 41, ст. 2752) на підставі укладених договорів і не може перевищувати 30 відсотків їх вартості.

Остаточні розрахунки за договорами здійснюються на підставі актів приймання-передачі виконаних робіт та проведених розрахунків.

8. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 8 в редакції Постанови КМ N 324 ( 324-2008-п ) від 09.04.2008 }

9. З метою недопущення виникнення кредиторської заборгованості на кінець року до тендерної документації та договору про закупівлю товарів, робіт і послуг включається вимога щодо коригування визначеної в договорі суми та зобов'язань сторін договору в разі зменшення бюджетних призначень під час уточнення показників державного бюджету.

Звітність про використання бюджетних коштів та контроль за їх витрачанням

10. МКТ затверджує результативні показники щодо виконання плану заходів з його поквартальною розбивкою.

Відомості про зазначені показники надсилаються Мінфіну у двотижневий строк.

Інформацію про виконання показників МКТ подає Мінфіну у тижневий строк після завершення звітного періоду та одинадцяти місяців.

У разі невиконання показників МКТ утворює комісію, яка розглядає питання щодо подальшого фінансування виконання плану заходів. { Пункт 10 доповнено абзацом згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

Про рішення комісії МКТ письмово повідомляє Мінфін у триденний строк після його прийняття. { Пункт 10 доповнено абзацом згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

Якщо план заходів виконується не на належному рівні, Мінфін і МКТ проводять узгоджувальні наради, за результатами яких подають Міністрові фінансів пропозиції щодо подальшого фінансування виконання зазначеного плану. { Пункт 10 доповнено абзацом згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

11. За нецільове використання бюджетних коштів відповідальність несуть головний розпорядник, розпорядник бюджетних коштів нижчого рівня та виконавці.

11-1. Виконавці подають щомісяця до 1 числа МКТ інформацію про використання бюджетних коштів для її узагальнення та надсилання до 5 числа Мінфіну.

{ Порядок доповнено пунктом 11-1 згідно з Постановою КМ N 501 ( 501-2010-п ) від 23.06.2010 }

{ Пункт 12 виключено на підставі Постанови КМ N 324 ( 324-2008-п ) від 09.04.2008 }

13. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
