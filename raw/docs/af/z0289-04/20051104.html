24.02.2004 N 36

Зареєстровано в Міністерстві юстиції України 4 березня 2004 р. за N 289/8888

Про внесення змін до наказу Міністерства праці та соціальної політики України від 29.01.2002 N 69

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства праці та соціальної політики

N 69 ( z0129-02 ) від 29.01.2002, до якого вносились зміни }

Відповідно до постанови Кабінету Міністрів України від 19 травня 2003 року N 740 ( 740-2003-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 29.01.2002 N 69 ( z0129-02 ) "Про впорядкування умов оплати праці працівників окремих підрозділів, створених при органах виконавчої влади, їх самостійних управліннях і відділах та при виконавчих органах рад", зареєстрованого в Міністерстві юстиції України 12.02.2002 за N 129/6417, виклавши додаток у новій редакції (додається).

2. Ці умови застосовуються з 1 січня 2004 року.

Міністр М.Папієв

ПОГОДЖЕНО:

Міністерство фінансів України Заступник Міністра А.І.Мярковський
