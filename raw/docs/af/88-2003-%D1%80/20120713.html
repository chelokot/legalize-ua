Кабінет Міністрів України; Розпорядження від 24.02.2003 № 88-р

Про віднесення посад працівників апарату судів загальної юрисдикції до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 88-2003-р

Текст документа від 13.07.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 лютого 2003 р. N 88-р Київ

Про віднесення посад працівників апарату судів загальної юрисдикції до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженням КМ N 530-р ( 530-2004-р ) від 28.07.2004 Постановами КМ N 1097 ( 1097-2010-п ) від 01.12.2010 N 215 ( 215-2011-п ) від 09.03.2011 N 601 ( 601-2012-п ) від 04.07.2012 }

1. Відповідно до статей 9 і 25 Закону України "Про державну службу" ( 3723-12 ) та статті 149 Закону України "Про судоустрій і статус суддів" ( 2453-17 ) віднести посади працівників апарату судів загальної юрисдикції до таких категорій посад державних службовців: { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

1) перша категорія:

посада керівника апарату Верховного Суду України, вищих спеціалізованих судів України; { Абзац другий підпункту 1 пункту 1 із змінами, внесеними згідно з Постановою КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

2) друга категорія:

а) посади заступника керівника апарату, начальників управлінь, самостійних відділів та інших самостійних структурних підрозділів Верховного Суду України; { Підпункт "а" підпункту 2 пункту 1 в редакції Постанови КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

б) посади заступника керівника апарату, начальників управлінь, самостійних відділів та інших самостійних структурних підрозділів вищих спеціалізованих судів України; { Підпункт "б" підпункту 2 пункту 1 в редакції Постанови КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

{ Підпункт "в" підпункту 2 пункту 1 виключено на підставі Постанови КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

3) третя категорія:

а) посади помічника голови, помічника першого заступника голови, помічників заступників голови - секретарів судових палат, помічників заступників секретарів судових палат, помічників суддів Верховного Суду України; посади заступників начальників управлінь, самостійних відділів та інших самостійних структурних підрозділів, начальників відділів у складі управлінь, завідуючих секторами, наукових консультантів, головних консультантів, головних спеціалістів, старших консультантів, головного бухгалтера Верховного Суду України; { Підпункт "а" підпункту 3 пункту 1 із змінами, внесеними згідно з Постановою КМ N 1097 ( 1097-2010-п ) від 01.12.2010; в редакції Постанови КМ N 215 ( 215-2011-п ) від 09.03.2011; із змінами, внесеними згідно з Постановою КМ N 601 ( 601-2012-п ) від 04.07.2012 }

б) посади помічника голови, помічника заступника голови, помічників суддів вищих спеціалізованих судів України; посади заступників начальників управлінь, самостійних відділів та інших самостійних структурних підрозділів, начальників відділів у складі управлінь, завідуючих секторами, наукових консультантів, головних консультантів, головних спеціалістів, старших консультантів, головного бухгалтера вищих спеціалізованих судів; { Підпункт "б" підпункту 3 пункту 1 в редакції Постанов КМ N 1097 ( 1097-2010-п ) від 01.12.2010, N 215 ( 215-2011-п ) від 09.03.2011 }

{ Підпункт "в" підпункту 3 пункту 1 виключено на підставі Постанови КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

г) посада керівника апарату апеляційних судів; { Підпункт "г" підпункту 3 пункту 1 із змінами, внесеними згідно з Постановою КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

4) четверта категорія:

а) посади консультантів, спеціалістів, старших судових розпорядників, судових розпорядників Верховного Суду України; { Підпункт 4"а" пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 530-р ( 530-2004-р ) від 28.07.2004; в редакції Постанови КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

б) посади консультантів, спеціалістів, старших секретарів суду, секретарів судового засідання, секретарів суду, старших судових розпорядників, судових розпорядників вищих спеціалізованих судів України; { Підпункт 4"б" пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 530-р ( 530-2004-р ) від 28.07.2004, Постановою КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

{ Підпункт "в" підпункту 4 пункту 1 виключено на підставі Постанови КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

г) посади помічника голови, помічника заступника голови, заступника керівника апарату, начальників відділів апеляційних судів; { Підпункт "г" підпункту 4 пункту 1 в редакції Постанов КМ N 1097 ( 1097-2010-п ) від 01.12.2010, N 215 ( 215-2011-п ) від 09.03.2011 }

ґ) посада керівника апарату місцевих судів; { Підпункт "ґ" підпункту 4 пункту 1 із змінами, внесеними згідно з Постановою КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

5) п'ята категорія:

{ Підпункт "а" підпункту 5 пункту 1 виключено на підставі Постанови КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

б) посади помічників суддів апеляційних судів; посади заступників начальників відділів, головних спеціалістів, старших консультантів, головного бухгалтера апеляційних судів; { Підпункт "б" підпункту 5 пункту 1 із змінами, внесеними згідно з Постановою КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

в) посади помічника голови, помічника заступника голови, помічників суддів місцевих судів; посади заступника керівника апарату, начальника відділу, головних спеціалістів, старших консультантів, головного бухгалтера місцевих судів; { Підпункт "в" підпункту 5 пункту 1 в редакції Постанов КМ N 1097 ( 1097-2010-п ) від 01.12.2010, N 215 ( 215-2011-п ) від 09.03.2011 }

6) шоста категорія:

а) посади консультантів, спеціалістів, старших секретарів суду, секретарів судового засідання, секретарів суду, старших судових розпорядників, судових розпорядників апеляційних судів; { Підпункт 6"а" пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 530-р ( 530-2004-р ) від 28.07.2004, Постановою КМ N 1097 ( 1097-2010-п ) від 01.12.2010 }

б) посади спеціалістів, консультантів, старших секретарів суду, секретарів судового засідання, старших судових розпорядників, судових розпорядників, секретарів суду місцевих судів. ( Підпункт 6 "б" пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 530-р ( 530-2004-р ) від 28.07.2004 )

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 3 березня 1995 р. N 131 ( 131-95-р );

розпорядження Кабінету Міністрів України від 20 січня 1998 р. N 36 ( 36-98-р );

розпорядження Кабінету Міністрів України від 14 лютого 2002 р. N 55 ( 55-2002-р ) "Про віднесення посад працівників апарату господарських судів до відповідних категорій посад державних службовців" (Офіційний вісник України, 2002 р., N 7, ст. 299).
