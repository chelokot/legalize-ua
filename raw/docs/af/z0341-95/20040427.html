Ідентифікатор: z0341-95

ДЕРЖАВНИЙ МИТНИЙ КОМІТЕТ УКРАЇНИ

НАКАЗ

N 460 від 21.09.95 Зареєстровано в Міністерстві м.Київ юстиції України 27 вересня 1995 р. vd950921 vn460 за N 341/877

( Наказ втратив чинність на підставі Наказу Державної митної служби N 221 ( z0429-04 ) від 29.03.2004 )

Про декларування товарів, що переміщуються транзитом через територію України

( Із змінами, внесеними згідно з Наказом Митного комітету N 563 ( z0423-95 ) від 13.11.95 )

З метою забезпечення належного контролю та обліку переміщення транзитних вантажів та на виконання Указу Президента України від 14 липня 1995 року N 614 ( 614/95 ) "Про заходи щодо забезпечення контролю за переміщенням транзитом товарів через територію України" і статті 54 Митного кодексу України ( 1970-12 ) НАКАЗУЮ:

1. Запровадити обов'язкове декларування з поданням митниці вантажних митних декларацій на бланках форми МД-2 (МД-3) всіх вантажів, що переміщуються транзитом через територію України, в такі терміни:

1.1. Підакцизних вантажів, що переміщуються автомобільним транспортом, з 15 жовтня 1995 року;

1.2. Інших вантажів, що переміщуються автомобільним транспортом, з 1 листопада 1995 року;

1.3. Інших вантажів, що переміщуються повітряним та водним транспортом, а також підакцизних вантажів, що переміщуються залізничним транспортом, з 15 листопада 1995 року. ( Підпункт 1.3 пункту 1 в редакції Наказу Митного комітету N 563 ( z0423-95 ) від 13.11.95 )

1.4. До 1 лютого 1996 року декларування транзитних підакцизних вантажів, що переміщуються залізничним транспортом здійснювати по прикордонних станціях, розташованих в зонах діяльності Західного, Карпатського, Південного, Кримського територіальних митних управлінь та Маріупольської і Могилів-Подільської митниць, незалежно від напрямку транзиту, одноразово:

- у разі ввезення транзитних підакцизних товарів через зазначені пункти, вони декларуються як в пункті пропуску на митну територію України;

- у разі вивезення транзитних підакцизних товарів через зазначені пункти, вони декларуються як в пункті випуску з митної території України, якщо при ввезенні таких товарів не було забезпечено декларування транзиту.

1.4.1. Контроль доставлення вантажів з пунктів пропуску до прикордонних станцій (пунктів випуску) здійснювати по провізних відомостях.

1.4.2. У випадку, коли напрямок транзиту підакцизних вантажів проходить поза зонами діяльності митних установ, вказаних у пункті 1.4, доставлення вантажу від пункту пропуску до пункту випуску здійснювати тільки по провізних відомостях без декларування транзиту.

( Пункт 1 доповнено підпунктом 1.4 згідно з Наказом Митного комітету N 563 ( z0423-95 ) від 13.11.95 )

1.5. Починаючи з 1 лютого 1996 року декларування усіх транзитних вантажів здійснювати у повному обсязі на вхідних прикордонних залізничних станціях. ( Пункт 1 доповнено підпунктом 1.5 згідно з Наказом Митного комітету N 563 ( z0423-95 ) від 13.11.95 )

2. Ввести з 15 жовтня 1995 року окремий облік та окреме ведення звітності про вантажі, що переміщуються транзитом через територію України.

3. Начальнику Інформаційно-обчислювального центру (Сидоренко В.Ф.) та заступнику начальника Митно-тарифного управління (Демченко В.І.) розробити порядок ведення звітності про вантажі, що переміщуються транзитом, і довести його до відома митних установ.

4. Начальникам територіальних митних управлінь, начальникам митниць інформувати суб'єктів ЗЕД про встановлений порядок та взяти виконання пунктів 1, 2 під особистий контроль.

5. Загальний контроль за виконанням цього наказу покласти на заступника Голови Соловкова Ю.П.
