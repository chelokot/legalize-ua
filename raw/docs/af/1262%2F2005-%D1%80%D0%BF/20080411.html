Президент України; Розпорядження від 06.12.2005 № 1262/2005-рп

Питання Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 1262/2005-рп

Текст документа від 11.04.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 339/2008 ( 339/2008 ) від 11.04.2008 }

Питання Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва

1. Призначити ЄХАНУРОВА Юрія Івановича - Прем'єр-міністра України - головою Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва.

2. Визнати такими, що втратили чинність:

Розпорядження Президента України від 20 серпня 2001 року N 205 ( 205/2001-рп ) "Про голову Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва";

Розпорядження Президента України від 7 лютого 2003 року N 34 ( 34/2003-рп ) "Про голову Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва".

Президент України В.ЮЩЕНКО

м. Київ, 6 грудня 2005 року N 1262/2005-рп
