ПРАВЛІННЯ ПЕНСІЙНОГО ФОНДУ УКРАЇНИ

ПОСТАНОВА

26.09.2011 N 28-5

Зареєстровано в Міністерстві юстиції України 12 жовтня 2011 p. за N 1177/19915

{ Постанова втратила чинність на підставі Постанови Пенсійного фонду N 26-1 ( z1464-17 ) від 03.11.2017 }

Про внесення зміни до постанови правління Пенсійного фонду України від 25.03.2004 N 4-1 "Про Порядок обліку, зберігання, оформлення та видачі пенсійних посвідчень в Пенсійному фонді України та його органах"

Відповідно до пунктів 9, 11 Положення про Пенсійний фонд України, затвердженого Указом Президента України від 06.04.2011 N 384 ( 384/2011 ), правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Унести до постанови правління Пенсійного фонду України від 25.03.2004 N 4-1 ( z0427-04 ) "Про Порядок обліку, зберігання, оформлення та видачі пенсійних посвідчень в Пенсійному фонді України та його органах", зареєстрованої у Міністерстві юстиції України 06.04.2004 за N 427/9026, таку зміну:

у підпункті 5 пункту 2 додатка до цієї постанови слова "з лицьового боку якої невидимою при денному світлі фарбою, яка набуває під дією ультрафіолетового проміння червоного свічення, по діагоналі надруковано слово "Україна", що повторюється, фарбою, яка змінює колір під різним кутом зору від блакитного до світло-жовтого, по діагоналі надруковані слова "Пенсійний фонд України" виключити.

2. Пенсійні посвідчення, видані до набрання чинності цією постановою, дійсні до закінчення терміну їх дії або до заміни їх в установленому порядку на нові.

3. Юридичному управлінню (Рябцева Т.Б.) подати цю постанову на державну реєстрацію до Міністерства юстиції України.

4. Ця постанова набирає чинності з дня її офіційного опублікування.

5. Контроль за виконанням цієї постанови покласти на заступника Голови правління Никитенко В.С.

Голова правління Б.Зайчук
