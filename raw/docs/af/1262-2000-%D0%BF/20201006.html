ПОСТАНОВА від 11 серпня 2000 р. N 1262 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 879 ( 879-2020-п ) від 23.09.2020 }

Про внесення змін до постанови Кабінету Міністрів України від 14 квітня 1999 р. N 583

Кабінет Міністрів України постановляє:

На часткову зміну пункту 1 постанови Кабінету Міністрів України від 14 квітня 1999 р. N 583 ( 583-99-п ) "Про Міжвідомчу комісію із забезпечення виконання Рамкової конвенції ООН про зміну клімату" (Офіційний вісник України, 1999 р., N 15, ст. 613) затвердити новий склад Міжвідомчої комісії із забезпечення виконання Рамкової конвенції ООН про зміну клімату ( 995_044 ) (додається).

У Положенні про Міжвідомчу комісію із забезпечення виконання Рамкової конвенції ООН про зміну клімату, затвердженому зазначеною постановою:

в абзаці першому пункту 6 слова "який має двох заступників" замінити словами "який має одного першого та двох заступників";

в абзаці четвертому пункту 8 слово "заступником" замінити словами "першим заступником".
