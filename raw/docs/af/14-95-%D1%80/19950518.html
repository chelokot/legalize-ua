Кабінет Міністрів України; Розпорядження від 12.01.1995 № 14-р

Про віднесення посади президента Української державної корпорації по виконанню монтажних і спеціальних будівельних робіт до першої категорії державних службовців

Стан: Втратив чинність

Ідентифікатор: 14-95-р

Текст документа від 18.05.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 січня 1995 р. N 14-р Київ

{ Із змінами, внесеними згідно з Постановою КМ N 350 ( 350-95-п ) від 18.05.95 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посаду президента Української державної корпорації по виконанню монтажних і спеціальних будівельних робіт до другої категорії державних службовців, а посади перших віце-президентів і віце-президентів корпорації - до другої категорії державних службовців. { Абзац перший із змінами, внесеними згідно з Постановою КМ N 350 ( 350-95-п ) від 18.05.95 }

Посади інших працівників корпорації, які здійснюють організаційно-розпорядчі та консультаційно-дорадчі функції, прирівнюються за категоріями до відповідних посад працівників міністерств.
