{ Постанова втратила чинність на підставі Постанови КМ N 1107 ( 1107-2012-п ) від 28.11.2012 }

Про затвердження членів колегії Державного комітету з питань регуляторної політики та підприємництва

Кабінет Міністрів України постановляє:

Затвердити членами колегії Державного комітету з питань регуляторної політики та підприємництва Георгієвського Миколу Сергійовича, Головка Віктора Анатолійовича, Кожевіну Наталію Дмитрівну, Оперенка Григорія Миколайовича, Регурецького Василя Васильовича, Шлапака Олександра Віталійовича.
