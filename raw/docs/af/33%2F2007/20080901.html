Президент України; Указ від 23.01.2007 № 33/2007

Питання Державного управління справами

Стан: Чинний

Ідентифікатор: 33/2007

Текст документа від 01.09.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Державного управління справами

{ Із змінами, внесеними згідно з Указом Президента N 719/2008 ( 719/2008 ) від 19.08.2008 }

1. На часткову зміну Указу Президента України від 23 лютого 2000 року N 278 ( 278/2000 ) "Про Державне управління справами" (зі змінами, внесеними Указом від 20 серпня 2002 року N 729 ( 729/2002 ) встановити, що Державне управління справами є допоміжним органом, створеним Президентом України відповідно до пункту 28 статті 106 Конституції України ( 254к/96-ВР ) для матеріально-технічного, соціально-побутового та іншого забезпечення діяльності Президента України, Ради національної безпеки і оборони України, Секретаріату Президента України та інших створених Президентом України консультативних, дорадчих та допоміжних органів і служб.

Матеріально-технічне, соціально-побутове, транспортне та інше забезпечення діяльності Верховної Ради України, Кабінету Міністрів України, інших державних органів здійснюється Державним управлінням справами в межах наданих йому бюджетних призначень, передбачених законом про Державний бюджет України на такі цілі. В іншому випадку забезпечення діяльності зазначених органів здійснюється підприємствами, установами, організаціями, що перебувають в управлінні Державного управління справами, в установленому порядку на договірних засадах.

2. Зменшити кількість заступників Керівника Державного управління справами до чотирьох, у тому числі одного першого заступника, яких призначає на посади та звільняє з посад Президент України за поданням Керівника Державного управління справами.

{ Встановити, що Керівник Державного управління справами має п'ятьох заступників, у тому числі одного першого заступника згідно з Указом Президента N 719/2008 ( 719/2008 ) від 19.08.2008 }

3. З метою забезпечення доступності для населення України високоспеціалізованої та якісної медичної допомоги Кабінету Міністрів України разом з Державним управлінням справами вирішити в установленому порядку питання щодо створення Всеукраїнського центру радіохірургії у складі клінічної лікарні "Феофанія".

4. Комісії з питань забезпечення Державним управлінням справами медичного та санаторно-курортного обслуговування уточнити в місячний строк:

перелік державних органів, підприємств, установ, організацій, медичне та санаторно-курортне обслуговування працівників яких забезпечується Державним управлінням справами;

категорії осіб, лікувально-профілактична допомога, санітарне та епідемічне благополуччя і санаторно-курортне обслуговування яких забезпечується Державним управлінням справами.

5. Керівникові Державного управління справами подати у місячний строк пропозиції щодо внесення змін до актів Президента України, що випливають із цього Указу.

Президент України В.ЮЩЕНКО
