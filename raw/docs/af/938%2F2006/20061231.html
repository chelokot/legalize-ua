УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанови Кабінету Міністрів України від 15 вересня 2006 року N 1315

{ Додатково див. Конституційне подання Президента ( n0005100-06 ) від 10.11.2006 }

Кабінет Міністрів України 15 вересня 2006 року прийняв постанову N 1315 ( 1315-2006-п ) "Питання Державного комітету з промислової безпеки, охорони праці та гірничого нагляду", якою затверджено Положення про Державний комітет України з промислової безпеки, охорони праці та гірничого нагляду.

Відповідно до зазначеного Положення ( 1315-2006-п ) до повноважень Державного комітету України з промислової безпеки, охорони праці та гірничого нагляду віднесено, зокрема, формування та забезпечення реалізації державної політики у сфері промислової безпеки та охорони праці, здійснення державного гірничого нагляду, безпечного поводження з вибуховими матеріалами промислового призначення.

Однак Указом Президента України від 10 жовтня 2005 року N 1430 ( 1430/2005 ) "Про Положення про Міністерство України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи", який є чинним у частині, що не суперечить Конституції України ( 254к/96-ВР ), здійснення зазначених повноважень покладено на Міністерство України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи.

Таким чином, зазначена постанова Кабінету Міністрів України ( 1315-2006-п ) прийнята всупереч Указу Президента України ( 1430/2005 ), а отже, не відповідає частині третій статті 113 Конституції України ( 254к/96-ВР ), згідно з якою Кабінет Міністрів України у своїй діяльності керується, зокрема, указами Президента України, прийнятими відповідно до Конституції ( 254к/96-ВР ) та законів України, та пункту 1 частини першої статті 116 Основного Закону України ( 254к/96-ВР ), за якою Кабінет Міністрів України забезпечує виконання актів Президента України. Як наслідок, зазначене рішення Кабінету Міністрів України ( 1315-2006-п ) не відповідає частині другій статті 6 та частині другій статті 19 Конституції України ( 254к/96-ВР ), згідно з якими органи державної влади зобов'язані діяти лише на підставі та у спосіб, що передбачені Конституцією України ( 254к/96-ВР ).

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 15 вересня 2006 року N 1315 ( 1315-2006-п ) "Питання Державного комітету з промислової безпеки, охорони праці та гірничого нагляду" як такої, що не відповідає Конституції України ( 254к/96-ВР ).

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
