РОЗПОРЯДЖЕННЯ від 23 квітня 2005 р. N 125-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 9-р ( 9-2006-р ) від 11.01.2006 )

Про передачу МОЗ будинку у м. Києві

1. Передати до сфери управління МОЗ будинок по вул. Щорса, 7/9, у м. Києві для розміщення центрального апарату Міністерства.

МОЗ, Мінфіну і Мінекономіки внести пропозиції щодо фінансування витрат, пов'язаних з переміщенням Міністерства у будинок по вул. Щорса, 7/9, та проведення поточного ремонту його приміщень.

2. МОЗ забезпечити в місячний строк вивільнення будинку по вул. М. Грушевського, 7.

3. Мінтрансзв'язку забезпечити МОЗ телефонним зв'язком.
