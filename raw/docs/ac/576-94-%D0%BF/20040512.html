Про залучення коштів підприємств, організацій та громадян для розвитку місцевих телефонних мереж

Текст документа від 12.05.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 серпня 1994 р. N 576 Київ

( Постанова втратила чинність на підставі Постанови КМ N 610 ( 610-2004-п ) від 12.05.2004 )

Про залучення коштів підприємств, організацій та громадян для розвитку місцевих телефонних мереж

З метою створення умов для подальшого розвитку місцевих телефонних мереж та більш повного забезпечення господарського сектора і населення всіма видами електрозв'язку Кабінет Міністрів України ПОСТАНОВЛЯЄ:

1. Прийняти пропозицію Міністерства зв'язку, погоджену з Міністерством економіки, про залучення державними підприємствами зв'язку на договірних засадах коштів підприємств, організацій та громадян для розвитку місцевих телефонних мереж на умовах гарантованого встановлення їм телефонів та надання права на користування і розпорядження телефонною лінією.

2. Установити, що вартість будівництва однієї телефонної лінії визначається Кримським республіканським, обласними, Севастопольським міським підприємствами зв'язку та підприємством "Київелектрозв'язок" за погодженням з Урядом Криму, облвиконкомами, Київським та Севастопольським міськвиконкомами з урахуванням усіх витрат, пов'язаних із спорудженням автоматичної телефонної станції, кабельної мережі, установкою абонентського телефонного апарату, та рентабельності в розмірі до 20 відсотків.

3. Уряду Криму, облвиконкомам, Київському та Севастопольському міськвиконкомам сприяти підприємствам зв'язку у залученні згідно з цією постановою коштів для розвитку місцевих телефонних мереж, виділенні приміщень для автоматичних телефонних станцій та у вирішенні інших питань створення зазначених мереж.
