ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

10.07.2003 N 296

Зареєстровано в Міністерстві юстиції України 18 липня 2003 р. за N 619/7940

Про внесення змін до нормативно-правових актів Національного банку України

{ Із змінами, внесеними згідно з Постановами Національного банку N 143 ( z0463-06 ) від 12.04.2006 N 134 ( z0708-12 ) від 09.04.2012 }

Відповідно до статей 9, 10, 11, 25, 34 Закону України "Про банки і банківську діяльність" ( 2121-14 ) та з метою вдосконалення нормативно-правових актів Національного банку України з питань створення і державної реєстрації банківських об'єднань та створення дочірнього банку, філії українського банку на території інших держав Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити:

{ Абзац другий пункту 1 втратив чинність на підставі Постанови Національного банку N 134 ( z0708-12 ) від 09.04.2012 }

{ Абзац третій пункту 1 втратив чинність на підставі Постанови Національного банку N 143 ( z0463-06 ) від 12.04.2006 }

2. Постанова набирає чинності через 10 днів після державної реєстрації в Міністерстві юстиції України.

3. Контроль за виконанням цієї постанови покласти на заступника Голови О.В.Шлапака.

Голова С.Л.Тігіпко

{ Зміни до Положення про порядок створення і державної реєстрації банківських об'єднань втратили чинність на підставі Постанови Національного банку N 134 ( z0708-12 ) від 09.04.2012 }
