Текст документа від 11.01.2012:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання такими, що втратили чинність, деяких указів Президента України

1. Визнати такими, що втратили чинність:

Указ Президента України від 10 грудня 2003 року N 1425 ( 1425/2003 ) "Про Положення про порядок розгляду питань щодо призначення суддів на адміністративні посади в судах загальної юрисдикції (крім адміністративних посад у Верховному Суді України) та звільнення з цих посад";

Указ Президента України від 29 березня 2004 року N 372 ( 372/2004 ) "Про внесення змін до деяких указів Президента України";

Указ Президента України від 30 червня 2004 року N 697 ( 697/2004 ) "Про Положення про порядок розгляду питань та підготовки матеріалів щодо призначення на посаду професійного судді вперше";

Указ Президента України від 11 вересня 2006 року N 747 ( 747/2006 ) "Про внесення змін до Указів Президента України від 10 грудня 2003 року N 1425 і від 30 червня 2004 року N 697";

Указ Президента України від 10 листопада 2006 року N 944 ( 944/2006 ) "Про внесення змін до Указу Президента України від 30 червня 2004 року N 697";

Указ Президента України від 12 березня 2007 року N 190 ( 190/2007 ) "Про внесення зміни до Указу Президента України від 10 грудня 2003 року N 1425";

Указ Президента України від 23 березня 2007 року N 240 ( 240/2007 ) "Про внесення зміни до Указу Президента України від 10 грудня 2003 року N 1425";

Указ Президента України від 16 березня 2009 року N 158 ( 158/2009 ) "Про внесення змін до Указу Президента України від 30 червня 2004 року N 697".

2. Цей Указ набирає чинності з дня його опублікування.
