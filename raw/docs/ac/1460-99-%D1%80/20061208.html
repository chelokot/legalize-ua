Кабінет Міністрів України; Розпорядження від 28.12.1999 № 1460-р

Про віднесення посади керівника Секретаріату Прем'єр-міністра України до другої категорії посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 1460-99-р

Текст документа від 08.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 грудня 1999 р. N 1460-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 599-р ( 599-2006-р ) від 08.12.2006 }

1. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посаду керівника Секретаріату Прем'єр-міністра України до другої категорії посад державних службовців.

2. Прирівняти керівника Секретаріату Прем'єр-міністра України за умовами оплати праці, матеріально-побутового, медичного і транспортного забезпечення до першого помічника Прем'єр-міністра України.

Прем'єр-міністр України В.ЮЩЕНКО
