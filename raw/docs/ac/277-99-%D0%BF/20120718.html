Стан: Втратив чинність

Ідентифікатор: 277-99-п

Текст документа від 18.07.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 березня 1999 р. N 277 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 619 ( 619-2012-п ) від 11.07.2012 }

Про визнання таким, що втратило чинність, Положення про Державний комітет України по матеріальних резервах

У зв'язку із затвердженням Указом Президента України від 9 грудня 1998 р. N 1340 ( 1340/98 ) Положення про Державний комітет України по матеріальних резервах Кабінет Міністрів України постановляє:

Визнати таким, що втратило чинність, Положення про Державний комітет України по матеріальних резервах, затверджене постановою Кабінету Міністрів України від 11 червня 1994 р. N 383 ( 383-94-п ).
