Питання діяльності груп аналізу політики у центральних органах виконавчої влади

Стан: Втратив чинність

Ідентифікатор: 334-2010-р

Текст документа від 21.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 березня 2010 р. N 334-р Київ

Питання діяльності груп аналізу політики у центральних органах виконавчої влади

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1292-р ( 1292-2011-р ) від 21.12.2011 }

{ У тексті Розпорядження слова "Головне управління державної служби" в усіх відмінках замінено словами "Національне агентство з питань державної служби" у відповідному відмінку згідно з Розпорядженням КМ N 1292-р ( 1292-2011-р ) від 21.12.2011 }

1. Міністерствам, іншим центральним органам виконавчої влади з метою підвищення професійного рівня державних службовців з підготовки урядових рішень, спрямованих на виконання Порядку денного асоціації Україна - ЄС та адаптацію державної служби до стандартів Європейського Союзу:

подавати щороку до 15 жовтня Національному агентству з питань державної служби за затвердженою ним формою пропозиції щодо утворення у разі потреби груп аналізу політики для узагальнення та внесення їх до 1 грудня Українській частині Комітету з питань співробітництва між Україною та Європейськими Співтовариствами (Європейським Союзом) для схвалення;

утворювати з метою аналізу проблеми у певній сфері (секторі) державного управління та підготовки проекту політичної пропозиції групи аналізу політики у місячний строк після схвалення Українською частиною Комітету з питань співробітництва між Україною та Європейськими Співтовариствами (Європейським Союзом) узагальнених Національним агентством з питань державної служби пропозицій;

вносити в установленому порядку в місячний строк після завершення роботи груп аналізу політики та розгляду Українською частиною Комітету з питань співробітництва між Україною та Європейськими Співтовариствами (Європейським Союзом) результатів діяльності таких груп політичні пропозиції на розгляд Кабінету Міністрів України.

2. Національному агентству з питань державної служби визначити порядок методично-організаційного супроводження діяльності груп аналізу політики.

Прем'єр-міністр України Ю.ТИМОШЕНКО
