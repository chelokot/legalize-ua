Про затвердження типових актів перевірки виконання умов договорів купівлі-продажу

{ Із змінами, внесеними згідно з Наказом Фонду державного майна N 350 ( z0421-11 ) від 14.03.2011 }

На виконання вимог Закону України "Про приватизацію державного майна" ( 2163-12 ) щодо здійснення державними органами приватизації контролю виконання умов договорів купівлі-продажу та з метою встановлення єдиних вимог до документального оформлення результатів цього контролю НАКАЗУЮ:

1. Затвердити Типовий акт поточної перевірки виконання умов договорів купівлі-продажу та Типовий акт підсумкової перевірки виконання умов договорів купівлі-продажу (додатки 1 та 2).

2. Департаменту договірного менеджменту (Тараба В.П.) у триденний термін з дня підписання цього наказу забезпечити подання його до Міністерства юстиції України для державної реєстрації.

3. Редакційно-видавничому відділу ( Путівська Н.А.) у десятиденний термін з дня державної реєстрації у Міністерстві юстиції України цього наказу забезпечити його публікацію у Державному інформаційному бюлетені "Про приватизацію".

4. Контроль за виконанням цього наказу залишаю за собою.

Т. в. о. Голови Фонду В.Ковтюх
