Текст документа від 19.09.1997:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 серпня 1995 р. N 656 Київ

Про вдосконалення системи ліцензування внутрішніх та міжнародних перевезень пасажирів і вантажів автомобільним транспортом

( Із змінами, внесеними згідно з Постановами КМ N 194 ( 194-96-п ) від 12.02.96 N 1038 ( 1038-97-п ) від 19.09.97 )

На часткову зміну постанови Кабінету Міністрів України від 17 травня 1994 р. N 316 ( 316-94-п ) "Про Положення про порядок видачі суб'єктам підприємницької діяльності спеціальних дозволів (ліцензій) на здійснення окремих видів діяльності" Кабінет Міністрів України постановляє:

1. Дозволити Міністерству транспорту делегувати функції щодо видачі документів на право здійснення внутрішніх та міжнародних перевезень пасажирів і вантажів автомобільним транспортом державним госпрозрахунковим підприємствам - обласним та Автономної Республіки Крим бюро ліцензування автомобільних перевезень (по Україні, в країни СНД та Балтії) та Українському бюро ліцензування автомобільних перевезень (в країни Європи та Азії).

( Пункт 2 втратив чинність на підставі Постанови КМ N 194 ( 194-96-п ) від 12.02.96 )

( Пункт 3 втратив чинність на підставі Постанови КМ N 1038 ( 1038-97-п ) від 19.09.97 )
