Про віднесення посади радника Керівника Апарату Верховної Ради України до другої категорії посад державних службовців

Текст документа від 28.08.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 березня 2004 р. N 126-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 663-р ( 663-2013-р ) від 28.08.2013 }

Про віднесення посади радника Керівника Апарату Верховної Ради України до другої категорії посад державних службовців

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посаду радника Керівника Апарату Верховної Ради України до другої категорії посад державних службовців.
