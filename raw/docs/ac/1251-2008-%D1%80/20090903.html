КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 вересня 2008 р. N 1251-р Київ

Питання передачі нерухомого майна у зв'язку з підготовкою та проведенням в Україні фінальної частини чемпіонату Європи 2012 року з футболу

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1033-р ( 1033-2009-р ) від 03.09.2009 }

1. Прийняти пропозицію Мінсім'ямолодьспорту та Міноборони щодо передачі цілісного майнового комплексу військового містечка N 1 (с. Гореничі Києво-Святошинського району Київської області) в управління Мінсім'ямолодьспорту для утворення Національного олімпійського центру підготовки з ігрових видів спорту.

{ На часткову зміну пункту 1 установити, що до сфери управління Мінсім'ямолодьспорту передаються об'єкти нерухомого майна військового містечка N 1 по вул. Столичній, 1, у с. Гореничі Києво-Святошинського району Київської області згідно з переліком, що додається, згідно з Розпорядженням КМ N 1033-р ( 1033-2009-р ) від 03.09.2009 }

2. Внести до переліку нерухомого військового майна Збройних Сил, яке може бути відчужено, затвердженого розпорядженням Кабінету Міністрів України від 17 жовтня 2007 р. N 896 ( 896-2007-р ), зміни, що додаються.
