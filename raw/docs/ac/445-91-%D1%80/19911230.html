Кабінет Міністрів України; Розпорядження від 30.12.1991 № 445-р

Щодо виділення на 1991 рік коштів з республіканського позабюджетного фонду стабілізації економіки для подання фінансової допомоги

Стан: Чинний

Ідентифікатор: 445-91-р

Текст документа від 30.12.1991:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 грудня 1991 р. N 445-р Київ

Виділити на 1991 рік з республіканського позабюджетного фонду стабілізації економіки для подання фінансової допомоги:

Запорізькому облвиконкому 1,4 млн. крб. на погашення заборгованості по довгостроковому кредиту банку, що був виданий на будівництво Токмацького заводу по випуску аглопориту;

Львівському облвиконкому 8,4 млн. крб. для відшкодування колгоспам Стрийського району затрат по будівництву об'єктів соціально-культурного призначення;

Донецькому міськвиконкому 12 млн. крб. на будівництво житла, об'єктів соціально-культурної сфери і комунального господарства;

Шосткінському міськвиконкому (Сумська область) 2 млн. крб. для розрахунків за виконані роботи по будівництву лікарні і житлових будинків;

Ярмолинецькому райвиконкому (Хмельницька область) 1 млн. крб. для розрахунків за виконані роботи по реконструкції і будівництву об'єктів соціально-культурного призначення, внутрігосподарських шляхів, придбане обладнання;

Березівському райвиконкому (Одеська область) 0,6 млн. крб. на оплату виконаних робіт по будівництву районної лікарні та Арцизькому райвиконкому (ця ж область) 1 млн. крб. для відшкодування затрат на будівництво клубу радгоспу "Дністровський".

Прем'єр-міністр України В.ФОКІН
