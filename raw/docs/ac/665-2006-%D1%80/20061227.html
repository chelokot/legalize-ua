РОЗПОРЯДЖЕННЯ від 27 грудня 2006 р. N 665-р Київ

Про віднесення наукових об'єктів до таких, що становлять національне надбання

Віднести до таких, що становлять національне надбання, наукові об'єкти згідно з додатком.

{ Перелік наукових об'єктів, що становлять національне надбання додатково див. у Постанові КМ № 1709 ( 1709-2001-п ) від 19.12.2001 р. }

МОН включити зазначені наукові об'єкти до Державного реєстру наукових об'єктів, що становлять національне надбання.
