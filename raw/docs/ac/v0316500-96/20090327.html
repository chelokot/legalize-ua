Про затвердження змін та доповнень до окремих нормативних актів Національного банку України

Стан: Втратив чинність

Ідентифікатор: v0316500-96

Текст документа від 27.03.2009:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 316 від 06.12.96 м.Київ

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про затвердження змін та доповнень до окремих нормативних актів Національного банку України

{ Із змінами, внесеними згідно з Постановами Нацбанку N 278 ( z0449-97 ) від 19.08.97 N 414 ( v0579500-98 ) від 08.10.98 N 135 ( z0368-01 ) від 29.03.2001 }

У зв'язку з тим, що набув чинності Закон України "Про внесення зміни до статті 24 Закону України "Про підприємства в Україні" ( 419/96-ВР ), та з метою подання до банків суб'єктами господарювання розрахункових документів за єдиними формами, Правління ПОСТАНОВЛЯЄ:

1. Затвердити нову редакцію:

{ Підпункт 1.1 втратив чинність на підставі Постанови Національного банку N 135 ( z0368-01 ) від 29.03.2001 } 1.1. пункту 141 розділу IX "Розрахунки платіжними вимогами без акцепту платників та безспірне стягнення коштів" Інструкції N 7 "Про безготівкові розрахунки в господарському обороті України" ( v0204500-96 ), затвердженої постановою Правління Національного банку України від 02.08.96 р. N 204 (додаток N 1) (нова редакція ( v0402500-96 );

( Підпункт 1.2 пункту 1 втратив чинність на підставі Постанови Нацбанку N 414 ( v0579500-98 ) від 08.10.98 ) 1.2. пункту 8.1 розділу 8 "Безспірне стягнення та безакцептне списання коштів з кореспондентських рахунків комерційних банків" Положення "Про міжбанківські розрахунки в Україні" ( v0357500-96 ), затвердженого постановою Правління Національного банку України від 21.03.96 р. N 65 (додаток N 2) (нова редакція ( v0403500-96 ).

{ Пункт 2 втратив чинність на підставі Постанови Національного банку N 135 ( z0368-01 ) від 29.03.2001 } 2. Доповнити Інструкцію N 7 "Про безготівкові розрахунки в господарському обороті України" ( v0204500-96 ) новим розділом XII "Технічні норми обов'язкових елементів розрахункових документів" (додаток N 3 ( va316500-96 ) і ввести його в дію з 1 лютого 1997 року.

3. Департаменту валютного регулювання (С.О.Яременко) у 3-денний термін подати Правлінню зміни до Порядку безспірного стягнення та безакцептного списання коштів з рахунків в іноземній валюті суб'єктів підприємницької діяльності (крім банків) на території України ( v0393500-96 ), затвердженого постановою Правління Національного банку України від 10.10.96 р. N 261.

4. Управлінню платіжних систем та касового виконання Держбюджету (Л.В.Письменна) забезпечити доведення змін до Інструкції Національного банку України N 7 і Положення "Про міжбанківські розрахунки в Україні" Кримському республіканському, обласним та по м.Києву і Київській області управлінням Національного банку України, а також комерційним банкам для керівництва в роботі. Комерційним банкам довести зазначені зміни до відома своїх клієнтів.

5. Встановити, що із затвердженням зміни до статті 24 Закону України "Про підприємства в Україні" ( 887-12 ) лист Національного банку України від 24.06.96 р. N 12-214/608-3454 ( v3454500-96 ) "Про черговість платежів" із змінами до нього від 22.10.96 р. N 12-214/1069-6299 ( v6299500-96 ) не поширюється на суб'єктів підприємницької діяльності, які діють на підставі Закону України "Про підприємства в Україні".

( Пункт 6 втратив чинність на підставі Постанови N 278 ( z0449-97 ) від 19.08.97 ) 6. Встановити, що до прийняття Верховною Радою України змін до статті 381 Цивільного кодексу України ( 1540-06 ), вирішення питання щодо реструктуризації заборгованості до бюджету, тимчасово залишити порядок використання підприємствами коштів на потреби підприємства, встановлений згідно з Урядовою телеграмою від 18.04.96 р. NN 67-1004/98 і 12-214/337 ( v_337500-96 ) "Про черговість платежів".

7. Контроль за виконанням цієї постанови покласти на управління платіжних систем та касового виконання Держбюджету (Л.В.Письменна) та Кримське республіканське, обласні та по м.Києву і Київській області управління Національного банку України.

В.о. Голови Правління В.С.Стельмах
