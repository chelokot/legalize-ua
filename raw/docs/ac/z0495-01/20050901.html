N 48 від 25.05.2001 Зареєстровано в Міністерстві юстиції України 11 червня 2001 р. за N 495/5686

( Наказ втратив чинність на підставі Наказу Державного комітету архівів N 138 ( z1469-05 ) від 21.11.2005 )

Про внесення змін до наказу Держкомархіву від 05.05.2001 N 37

Відповідно до постанови Кабінету Міністрів України від 18 травня 2001 р. N 541 ( 541-2001-п ) "Про внесення змін та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

Унести такі зміни до наказу Держкомархіву України від 5 травня 2001 р. N 37 ( z0410-01 ) "Про впорядкування умов оплати праці працівників архівних установ":

у пункті 2 абзац перший підпункту 5 "а" після слів "відсутнього працівника" доповнити словами "або вакантною посадою".
