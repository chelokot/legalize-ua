Президент України; Указ від 22.06.1994 № 322/94

Про надання пільг релігійним організаціям

Стан: Чинний

Ідентифікатор: 322/94

Текст документа від 31.05.1995:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про надання пільг релігійним організаціям

( Із змінами, внесеними згідно з Указом Президента N 405/95 ( 405/95 ) від 31.05.95 )

Ураховуючи те, що релігійні організації існують в основному за рахунок пожертвувань віруючих, відіграють значну роль у духовному відродженні суспільства, піклуються про хворих, знедолених, інвалідів, беруть участь у благодійницькій діяльності, постановляю:

1. Установити, що стягнення з релігійних організацій плати за електричну енергію, що відпускається їм на комунально-побутові потреби, здійснюється за тарифами, передбаченими для міського населення.

( Стаття 2 втратила чинність на підставі Указу Президента N 405/95 ( 405/95 ) від 31.05.95 )

3. Цей Указ набирає чинності з дня його підписання.

Президент України Л.КРАВЧУК

м. Київ, 22 червня 1994 року N 322/94
