{ Постанова втратила чинність на підставі Постанови КМ N 920 ( 920-2016-п ) від 07.12.2016 }

Про внесення зміни до Статуту Дипломатичної академії України при Міністерстві закордонних справ

Кабінет Міністрів України постановляє:

Внести до Статуту Дипломатичної академії України при Міністерстві закордонних справ, затвердженого постановою Кабінету Міністрів України від 20 липня 1996 р. N 779 ( 779-96-п ) "Про Дипломатичну академію України при Міністерстві закордонних справ" (ЗП України, 1996 р., N 14, ст. 395), зміну, виклавши пункт 4 у такій редакції:

"4. Місцезнаходження Академії: 01025, м. Київ, вул. Велика Житомирська, 2.".
