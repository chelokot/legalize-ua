ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

24.06.2011 N 209

Зареєстровано в Міністерстві юстиції України 12 липня 2011 р. за N 850/19588

Про внесення змін до деяких нормативно-правових актів Національного банку України

{ Із змінами, внесеними згідно з Постановами Національного банку N 306 ( z1203-11 ) від 08.09.2011 N 346 ( z1590-12 ) від 17.08.2012 }

Відповідно до статті 56 Закону України "Про Національний банк України" ( 679-14 ), з метою приведення нормативно-правових актів Національного банку України у відповідність до законодавства України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. У пункті 2 розділу I Положення про порядок підготовки та атестації фахівців з дилінгових операцій на валютних ринках, затвердженого постановою Правління Національного банку України від 21.06.2001 N 234 ( z0603-01 ), зареєстрованого в Міністерстві юстиції України 18.07.2001 за N 603/5794 (зі змінами), слова "напрямом "Економіка і підприємництво" замінити словами "галуззю знань "Економіка та підприємництво", цифри "7.050105" та "8.050105" замінити відповідно цифрами "7.03050802" та "8.03050802", цифри та слова "24.05.97 N 507 ( 507-97-п ) "Про перелік напрямів та спеціальностей, за якими здійснюється підготовка фахівців у вищих навчальних закладах за відповідними освітньо-кваліфікаційними рівнями" замінити цифрами та словами "27.08.2010 N 787 ( 787-2010-п ) "Про затвердження переліку спеціальностей, за якими здійснюється підготовка фахівців у вищих навчальних закладах за освітньо-кваліфікаційними рівнями спеціаліста і магістра".

{ Пункт 2 втратив чинність на підставі Постанови Національного банку N 306 ( z1203-11 ) від 08.09.2011 }

{ Пункт 3 втратив чинність на підставі Постанови Національного банку N 346 ( z1590-12 ) від 17.08.2012 }

4. У тексті Положення про порядок зберігання Національним банком України та банками України документів в умовах особливого періоду, затвердженого постановою Правління Національного банку України від 26.03.2004 N 134 ( z0495-04 ), зареєстрованого в Міністерстві юстиції України 16.04.2004 за N 495/9094 (зі змінами), слова "документи постійного та тривалого зберігання" в усіх відмінках замінити словами "документи Національного архівного фонду та документи тривалого зберігання" у відповідних відмінках.

5. Визнати такою, що втратила чинність, постанову Правління Національного банку України від 09.09.2002 N 336 ( z0776-02 ) "Про вдосконалення порядку здійснення обов'язкового продажу надходжень в іноземній валюті на користь резидентів", зареєстровану в Міністерстві юстиції України 23.09.2002 за N 776/7064 (зі змінами).

6. Юридичному департаменту (В.В.Новіков) після державної реєстрації в Міністерстві юстиції України довести зміст цієї постанови до відома територіальних управлінь Національного банку України та банків України для використання в роботі.

7. Контроль за виконанням цієї постанови покласти на заступників Голови Національного банку України Кротюка В.Л., Соркіна І.В.

8. Постанова набирає чинності з дня її офіційного опублікування.
