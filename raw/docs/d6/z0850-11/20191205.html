Про внесення змін до деяких нормативно-правових актів Національного банку України

{ Із змінами, внесеними згідно з Постановами Національного банку N 306 ( z1203-11 ) від 08.09.2011 N 346 ( z1590-12 ) від 17.08.2012 N 232 ( v0232500-16 ) від 04.04.2016 }

Відповідно до статті 56 Закону України "Про Національний банк України" ( 679-14 ), з метою приведення нормативно-правових актів Національного банку України у відповідність до законодавства України Правління Національного банку України ПОСТАНОВЛЯЄ:

{ Пункт 3 втратив чинність на підставі Постанови Національного банку N 346 ( z1590-12 ) від 17.08.2012 }

У тексті Положення про порядок зберігання Національним банком України та банками України документів в умовах особливого періоду, затвердженого постановою Правління Національного банку України від 26.03.2004 N 134 ( z0495-04 ), зареєстрованого в Міністерстві юстиції України 16.04.2004 за N 495/9094 (зі змінами), слова "документи постійного та тривалого зберігання" в усіх відмінках замінити словами "документи Національного архівного фонду та документи тривалого зберігання" у відповідних відмінках.

Визнати такою, що втратила чинність, постанову Правління Національного банку України від 09.09.2002 N 336 ( z0776-02 ) "Про вдосконалення порядку здійснення обов'язкового продажу надходжень в іноземній валюті на користь резидентів", зареєстровану в Міністерстві юстиції України 23.09.2002 за N 776/7064 (зі змінами).

6. Юридичному департаменту (В.В.Новіков) після державної реєстрації в Міністерстві юстиції України довести зміст цієї постанови до відома територіальних управлінь Національного банку України та банків України для використання в роботі.

8. Постанова набирає чинності з дня її офіційного опублікування.
