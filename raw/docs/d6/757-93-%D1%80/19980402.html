Кабінет Міністрів України; Розпорядження від 18.09.1993 № 757-р

Про внесення змін у розпорядження Кабінету Міністрів України від 26 березня 1993 р. N 185 та від 23 липня 1993 р. N 542

Стан: Втратив чинність

Ідентифікатор: 757-93-р

Текст документа від 02.04.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 вересня 1993 р. N 757-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 315 ( 315-98-п ) від 17.03.98 )

1. Абзац третій розпорядження Кабінету Міністрів України від 26 березня 1993 р. N 185 ( 185-93-р ) доповнити кодами "7403.11000, 7403.12000, 7404.00990, 7413.00910, 7418.2000, 7419.99000, 7601, 1000, 7602.00110, 7602.00900, 7605, 19100, 7614.90100".

2. В абзаці 7 розпорядження Кабінету Міністрів України від 23 липня 1993 р. N 542 ( 542-93-р ) код "7607" замінити на код "7907".
