Президент України; Указ від 08.06.1995 № 431/95

Про визнання такими, що втратили чинність, деяких указів та розпоряджень Президента України

Стан: Чинний

Ідентифікатор: 431/95

Текст документа від 08.06.1995:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання такими, що втратили чинність, деяких указів та розпоряджень Президента України

У зв'язку із схваленням 7 червня 1995 року Верховною Радою України Конституційного Договору між Президентом України та Верховною Радою України "Про основні засади організації та функціонування державної влади і місцевого самоврядування в Україні на період до прийняття нової Конституції України" ( 1к/95-ВР ) постановляю:

1. Визнати такими, що втратили чинність, такі акти Президента України:

Указ Президента України від 31 травня 1995 року N 413 ( 413/95 ) "Про проведення опитування громадської думки з питань довіри громадян України Президентові України та Верховній Раді України";

Розпорядження Президента України від 2 червня 1995 року N 95 ( 95/95-рп ) "Про склад Центральної комісії з проведення опитування громадської думки з питання довіри громадян України Президентові України та Верховній Раді України";

Указ Президента України від 5 червня 1995 року N 420 ( 420/95 ) "Про підтвердження чинності Указу Президента України від 31 травня 1995 року N 413 "Про проведення опитування громадської думки з питань довіри громадян України Президентові України та Верховній Раді України";

Розпорядження Президента України від 5 червня 1995 року N 97 ( 97/95-рп ) "Про Положення про Центральну комісію з проведення опитування громадської думки в Україні".

2. Цей Указ набирає чинності з дня його підписання.

Президент України Л.КУЧМА

м.Київ, 8 червня 1995 року N 431/95
