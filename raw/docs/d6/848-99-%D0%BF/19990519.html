Текст документа від 19.05.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 травня 1999 р. N 848 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про відпуск розброньованих матеріальних цінностей для відновлення мостів на автомобільних дорогах Закарпатської області, що зазнали руйнувань внаслідок стихійного лиха

Кабінет Міністрів України постановляє:

1. Дозволити Державному комітетові по матеріальних резервах відпустити Закарпатській обласній державній адміністрації розброньовані з мобілізаційного резерву відповідно до постанови Кабінету Міністрів України від 12 травня 1998 р. N 667-029 два комплекти середніх автодорожніх розбірних мостів САРМ для відновлення мостів на автомобільних дорогах Закарпатської області, що зазнали руйнувань внаслідок стихійного лиха.

2. Міністерству фінансів зарахувати вартість розброньованих та відпущених середніх автодорожніх розбірних мостів САРМ у сумі 453,6 тис. гривень до надходжень коштів від продажу державних запасів товарів та фінансування Закарпатської області в рахунок субвенції, передбаченої Державним бюджетом України на 1999 рік ( 378-14 ) на ліквідацію наслідків стихійного лиха.

3. Контроль за виконанням цієї постанови покласти на Міністра транспорту Данькевича І.П.
