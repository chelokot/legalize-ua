КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 грудня 2005 р. N 540-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 17-р ( 17-2007-р ) від 24.01.2007 }

Про внесення зміни у додаток до розпорядження Кабінету Міністрів України від 17 липня 2003 р. N 419

Внести у додаток до розпорядження Кабінету Міністрів України від 17 липня 2003 р. N 419 ( 419-2003-р ) "Про перелік країн (територій), які не беруть участі в міжнародному співробітництві у сфері запобігання та протидії легалізації (відмиванню) доходів, одержаних злочинним шляхом, та фінансуванню тероризму" (Офіційний вісник України, 2003 р., N 30, ст. 1560) зміну, виключивши слово "Науру".

Прем'єр-міністр України Ю.ЄХАНУРОВ
