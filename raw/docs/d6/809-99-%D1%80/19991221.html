Кабінет Міністрів України; Розпорядження від 14.08.1999 № 809-р

Про дозвіл Держмитслужбі на здійснення митного оформлення вантажів, що надійшли на адресу ВАТ "Укрелектроапарат" (м. Хмельницький)

Стан: Втратив чинність

Ідентифікатор: 809-99-р

Текст документа від 21.12.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 серпня 1999 р. N 809-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 1459-р ( 1459-99-р ) від 21.12.99 )

Дозволити Держмитслужбі здійснити митне оформлення вантажів, що надійшли на адресу ВАТ "Укрелектроапарат" (м. Хмельницький) для власних виробничих потреб за контрактами згідно з додатком, як товарів критичного імпорту.
