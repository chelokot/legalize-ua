Внести до Указу Президента України від 14 жовтня 2005 року N 1445 ( 1445/2005 ) "Про створення Секретаріату Президента України" (зі змінами, внесеними Указами від 2 жовтня 2006 року N 814 ( 814/2006 ), від 26 лютого 2007 року N 143 ( 143/2007 ), від 23 березня 2007 року N 238 ( 238/2007 ), від 5 квітня 2007 року N 276 ( 276/2007 ), від 6 червня 2007 року N 507 ( 507/2007 ), від 9 листопада 2007 року N 1079 ( 1079/2007 ), від 24 грудня 2007 року N 1244 ( 1244/2007 ), від 23 січня 2008 року N 46 ( 46/2008 ), від 31 січня 2008 року N 73 ( 73/2008 ), від 24 березня 2008 року N 264 ( 264/2008 ), від 27 березня 2008 року N 270 ( 270/2008 ), від 4 листопада 2008 року N 997 ( 997/2008 ) та від 7 листопада 2008 року N 1002) ( 1002/2008 ) зміну, виклавши Схему розподілу обов'язків між Главою Секретаріату Президента України, його Першим заступником та заступниками, закріплення за ними структурних підрозділів, затверджену зазначеним Указом ( 1445/2005 ), у новій редакції, що додається ( 1161а/2008 ).

2. Цей Указ набирає чинності з дня його опублікування.
