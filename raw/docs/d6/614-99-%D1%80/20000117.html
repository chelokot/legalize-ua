Кабінет Міністрів України; Розпорядження від 26.06.1999 № 614-р

Про надання дозволу ДАК "Хліб України" на укладення договорів з фірмою "Дойц-Фар" про поставку техніки для створення машинно-технологічних станцій

Стан: Втратив чинність

Ідентифікатор: 614-99-р

Текст документа від 17.01.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 червня 1999 р. N 614-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 29-р ( 29-2000-р ) від 17.01.2000 )

1. Для забезпечення товаровиробників сільськогосподарською технікою погодитися з пропозицією ДАК "Хліб України" щодо надання їй дозволу на укладення з фірмою "Дойц-Фар" договорів про поставку техніки для створення машинно-технологічних станцій під заставу майна дочірніх підприємств Компанії згідно з додатком.

ДАК "Хліб України" разом з Мінфіном визначити умови застави нерухомого майна дочірніх підприємств Компанії.

2. Контроль за виконанням цього розпорядження покласти на Віце-прем'єр-міністра України Гладія М.В.
