Президент України; Указ від 22.06.1999 № 690/99

Про деякі питання оподаткування грального бізнесу

Стан: Втратив чинність

Ідентифікатор: 690/99

Текст документа від 22.06.1999:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про деякі питання оподаткування грального бізнесу

( Указ не набрав чинності згідно з пунктом 4 розділу XV "Перехідні положення" Конституції України ( 254к/96-ВР )

З метою спрощення справляння податків, забезпечення оптимального рівня податкових надходжень до відповідних бюджетів та згідно з пунктом 4 розділу XV "Перехідні положення" Конституції України ( 254к/96-ВР ) постановляю:

1. Установити, що оподаткування доходів від грального бізнесу у казино та з автоматичних розігрувальних пристроїв проводиться шляхом придбання торгового патенту, вартість якого встановлюється в таких розмірах (за рік):

для використання грального автомату з грошовим або майновим виграшем - 1400 гривень;

для використання грального столу з кільцем рулетки - 64000 гривень;

для використання інших гральних столів (спеціальних столів для казино, крім столів для більярду) - 48000 гривень за кожний стіл.

2. Покласти на Кабінет Міністрів України надання офіційних роз'яснень щодо цього Указу.

3. Цей Указ набирає чинності в порядку, передбаченому пунктом 4 розділу XV "Перехідні положення" Конституції України.

Президент України Л.КУЧМА

м. Київ, 22 червня 1999 року N 690/99
