Кабінет Міністрів України; Постанова від 05.03.2008 № 141

Про використання у 2008 році коштів, передбачених у державному бюджеті для здійснення платежів, що пов'язані з виконанням рішень закордонних юрисдикційних органів, прийнятих за наслідками розгляду справ проти України, та погашення заборгованості з виплати заробітної плати звільненим працівникам державної будівельно-промислової компанії "Атомспецбуд"

Стан: Чинний

Ідентифікатор: 141-2008-п

Текст документа від 14.07.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 березня 2008 р. N 141 Київ

Про використання у 2008 році коштів, передбачених у державному бюджеті для здійснення платежів, що пов'язані з виконанням рішень закордонних юрисдикційних органів, прийнятих за наслідками розгляду справ проти України, та погашення заборгованості з виплати заробітної плати звільненим працівникам державної будівельно-промислової компанії "Атомспецбуд"

{ Із змінами, внесеними згідно з Постановою КМ N 597 ( 597-2008-п ) від 02.07.2008 }

Кабінет Міністрів України постановляє:

1. Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) Міністерству юстиції за програмою 3601170 "Платежі на виконання рішень закордонних юрисдикційних органів, прийнятих за наслідками розгляду справ проти України, та погашення заборгованості із заробітної плати, належної для виплати, звільненим працівникам ДБПК "Атомспецбуд", здійснюється відповідно до Порядку використання коштів, передбачених у державному бюджеті для здійснення платежів, пов'язаних з виконанням рішень закордонних юрисдикційних органів, прийнятих за наслідками розгляду справ проти України, що затверджений постановою Кабінету Міністрів України від 7 березня 2007 р. N 408 ( 408-2007-п ) (Офіційний вісник України, 2007 р., N 18, ст. 716).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 597 ( 597-2008-п ) від 02.07.2008 }

2. Внести до Порядку ( 408-2007-п ), зазначеного у пункті 1 цієї постанови, зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 31

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 5 березня 2008 р. N 141

ЗМІНИ, що вносяться до Порядку використання у 2007 році коштів, передбачених у державному бюджеті для здійснення платежів, пов'язаних з виконанням рішень закордонних юрисдикційних органів, прийнятих за наслідками розгляду справ проти України ( 408-2007-п )

1. Пункт 2 доповнити підпунктами 5 і 6 такого змісту:

"5) погашення заборгованості з виплати заробітної плати звільненим працівникам ДБПК "Атомспецбуд";

6) здійснення заходів щодо забезпечення перекладу та опублікування в повному обсязі текстів рішень Європейського суду з прав людини українською мовою.".

2. Абзац перший пункту 3 викласти у такій редакції:

"Підставою для здійснення платежів, пов'язаних з виконанням рішень закордонних юрисдикційних органів, є:".

3. Доповнити Порядок ( 408-2007-п ) пунктом 7 такого змісту:

"7. Операції, пов'язані з бюджетними коштами, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.".
