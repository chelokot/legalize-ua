Держбуд України; Наказ, Перелік від 18.08.1999 № 197

Про затвердження Переліку об'єктів, затвердження проектів яких у межах законодавства не потребує висновку комплексної державної експертизи

Реєстрація: Мін'юст України від 22.09.1999 № 639/3932

Стан: Втратив чинність

Ідентифікатор: z0639-99

Текст документа від 26.09.2001:

ДЕРЖАВНИЙ КОМІТЕТ БУДІВНИЦТВА, АРХІТЕКТУРИ ТА ЖИТЛОВОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

N 197 від 18.08.99 Зареєстровано в Міністерстві м.Київ юстиції України 22 вересня 1999 р. vd990818 vn197 за N 639/3932

Про затвердження Переліку об'єктів, затвердження проектів яких у межах законодавства не потребує висновку комплексної державної експертизи

( Із змінами, внесеними згідно з Наказом Держбуду N 179 ( z0844-01 ) від 12.09.2001 )

На виконання доручення Кабінету Міністрів України від 02.07.99 N 13286/1 щодо визначення об'єктів, затвердження проектів яких у межах законодавства не потребує висновку комплексної державної експертизи, виходячи з положень статті 7 Закону України від 20.05.99 N 687-XIV ( 687-14 ) "Про архітектурну діяльність" НАКАЗУЮ:

1. Затвердити Перелік об'єктів, затвердження проектів яких у межах законодавства не потребує висновку комплексної державної експертизи, що додається.

2. Управлінню кошторисних норм, ціноутворення та експертизи (П.І.Губень) забезпечити доведення зазначеного Переліку до зацікавлених організацій.

3. Контроль за виконанням цього наказу покласти на Першого заступника Голови Комітету А.В.Беркуту.

Голова Комітету В.М.Гусаков

( Перелік об'єктів, затвердження проектів яких у межах законодавства не потребує висновку комплексної державної експертизи, втратив чинність на підставі Наказу Держбуду N 179 ( z0844-01 ) від 12.09.2001 )
