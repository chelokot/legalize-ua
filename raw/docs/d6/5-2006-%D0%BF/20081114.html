КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 січня 2006 р. N 5 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 954 ( 954-2008-п ) від 22.10.2008 }

Про внесення змін у додаток 2 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314

Кабінет Міністрів України постановляє:

Внести у додаток 2 до постанови Кабінету Міністрів України від 2 квітня 2001 р. N 314 ( 314-2001-п ) "Про встановлення ліміту легкових автомобілів, що обслуговують державні органи" (Офіційний вісник України, 2001 р., N 14, ст. 602; 2003 р., N 52, ст. 2766) такі зміни:

у позиції "Полтавська" цифри "10" замінити цифрою "9";

у позиції "Усього" цифри "253" замінити цифрами "252".
