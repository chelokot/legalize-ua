vd951229 vn328

( Постанова втратила чинність на підставі Постанови Нацбанку N 221 ( v0221500-99 ) від 05.05.99 )

Про затвердження Положення "Про порядок надання індивідуальних ліцензій на відкриття резидентами рахунків в іноземних банках"

Розглянувши проект Положення "Про порядок надання індивідуальних ліцензій на відкриття резидентами рахунків в іноземних банках" , Правління постановляє :

1. Затвердити це Положення ( v0346500-95 ).

2. Надіслати Положення регіональним управлінням Національного банку України та уповноваженим банкам для керівництва і використання в роботі.

3. Листи Національного банку України N 19029/939 ( v_939500-93 ) від 26.05.93 р. та N 19009/2954 від 15.12.93 р. вважати такими, що втратили чинність.

4. Контроль за виконанням цієї постанови покласти на Першого заступника Голови Правління В.О.Бондаря.

Голова Правління В.А.Ющенко
