КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 грудня 1999 р. N 2213 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

{ Постанова втратила чинність на підставі Постанови КМ N 469 ( 469-2010-п ) від 16.06.2010 }

Про утилізацію не придатного для використання та зберігання військового майна

На доповнення постанови Кабінету Міністрів України від 23 вересня 1998 р. N 1500 ( 1500-98-п ) "Про проведення експериментальної утилізації авіаційних засобів ураження, не придатних для подальшого використання і зберігання" Кабінет Міністрів України постановляє:

Погодитися з пропозицією Міністерства оборони про здійснення українсько-канадським спільним підприємством - товариством з обмеженою відповідальністю "Галев-Лтд" експериментальної комплексної утилізації не придатних для подальшого використання військово-морських та інших видів боєприпасів, військової і спеціальної техніки, списаних літальних апаратів, виключених в установленому порядку із складу Військово-Морських Сил кораблів і суден, іншого військового майна, термін експлуатації та зберігання якого закінчився, за номенклатурою і кількістю, узгодженою з Міністерством оборони, а також майна, що знаходиться на поверхні дна внутрішніх морських вод України, на умовах, передбачених постановою Кабінету Міністрів України від 23 вересня 1998 р. N 1500 ( 1500-98-п ).
