Про умови оплати праці працівників Національного науково-дослідного інституту охорони праці

( Із змінами, внесеними згідно з Наказами Державного комітету України з нагляду за охороною праці N 135 ( z0707-04 ) від 27.05.2004 - з 01.03.2004 N 210 ( z1198-04 ) від 17.09.2004 N 23 ( z0203-05 ) від 01.02.2005 N 82 ( z0579-05 ) від 14.05.2005 )

Відповідно до Положення про Державний комітет України з нагляду за охороною праці (Держнаглядохоронпраці України), затвердженого Указом Президента України від 16 січня 2003 року N 29/2003 ( 29/2003 ), постанови Кабінету Міністрів України від 4 березня 1994 року N 151 ( 151-94-п ) "Про створення Національного науково-дослідного інституту охорони праці у м. Києві" та на виконання постанови Кабінету Міністрів України від 11 лютого 2004 року N 166 ( 166-2004-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Затвердити схеми посадових окладів (місячних окладів) керівних, наукових та інших працівників, які проводять наукові і науково-технічні розробки, а також фахівців, службовців та робітників Національного науково-дослідного інституту охорони праці (далі - ННДІОП), підпорядкованого Держнаглядохоронпраці України, згідно з додатками 1-3.

2. Надати право директору ННДІОП у межах коштів, передбачених кошторисом: ( Абзац перший пункту 2 із змінами, внесеними згідно з Наказом Державного комітету України з нагляду за охороною праці N 82 ( z0579-05 ) від 14.05.2005 )

1) установлювати:

а) розміри посадових окладів (місячних окладів) працівникам ННДІОП згідно із затвердженими схемами;

б) розміри посадових окладів: заступникам директора ННДІОП, заступникам керівників структурних підрозділів - на 5-15 відсотків, головним бухгалтерам - на 10-30 відсотків, помічникам керівника - на 30-40 відсотків нижче посадового окладу, визначеного за схемами посадових окладів, затвердженими цим наказом, для відповідного керівника;

в) підвищені посадові оклади (місячні оклади) працівникам ННДІОП, які мають почесне звання, у тому числі: ( Абзац перший підпункту 1 "в" пункту 2 із змінами, внесеними згідно з Наказом Державного комітету України з нагляду за охороною праці N 82 ( z0579-05 ) від 14.05.2005 )

за почесні звання України, СРСР, союзних республік СРСР: "народний" - на 40 відсотків, "заслужений" - на 20 відсотків посадового окладу;

( Абзац третій підпункту 1 "в" пункту 2 виключено на підставі Наказу Державного комітету України з нагляду за охороною праці N 82 ( z0579-05 ) від 14.05.2005 )

( Абзац четвертий підпункту 1 "в" пункту 2 виключено на підставі Наказу Державного комітету України з нагляду за охороною праці N 82 ( z0579-05 ) від 14.05.2005 )

( Абзац п'ятий підпункту 1 "в" пункту 2 виключено на підставі Наказу Державного комітету України з нагляду за охороною праці N 82 ( z0579-05 ) від 14.05.2005 )

Посадові оклади працівників підвищуються, якщо діяльність працівників за профілем відповідає почесному званню. ( Абзац підпункту 1 "в" пункту 2 в редакції Наказу Державного комітету України з нагляду за охороною праці N 82 ( z0579-05 ) від 14.05.2005 )

ґ) доплати працівникам у розмірі до 50 відсотків посадового окладу (місячного окладу) відсутнього працівника або за вакантною посадою:

- за виконання обов'язків тимчасово відсутніх працівників;

- за суміщення професій (посад);

- за розширення зони обслуговування або збільшення обсягу виконуваних робіт.

Зазначені види доплат не встановлюються директору ННДІОП, його заступникам, керівникам структурних підрозділів інституту та їх заступникам;

д) доплати працівникам у розмірі до 40 відсотків годинної тарифної ставки (посадового окладу) за роботу в нічний час за кожну годину роботи з 10 години вечора до 6 години ранку;

е) доплати за вчене звання:

професора - у граничному розмірі 33 відсотки посадового окладу (ставки заробітної плати);

доцента, старшого наукового співробітника - у граничному розмірі 25 відсотків посадового окладу (ставки заробітної плати); ( Пункт 2 доповнено підпунктом 1 "е" згідно з Наказом Державного комітету України з нагляду за охороною праці N 82 ( z0579-05 ) від 14.05.2005 )

є) доплати за науковий ступінь:

доктора наук - у граничному розмірі 25 відсотків посадового окладу (ставки заробітної плати);

кандидата наук - у граничному розмірі 15 відсотків посадового окладу (ставки заробітної плати).

Зазначені доплати встановлюються, якщо діяльність працівників за профілем відповідає ученому званню або науковому ступеню.

( Пункт 2 доповнено підпунктом 1 "є" згідно з Наказом Державного комітету України з нагляду за охороною праці N 82 ( z0579-05 ) від 14.05.2005 )

ж) надбавки працівникам у розмірі до 50 відсотків посадового окладу (місячного окладу):

за високі досягнення у праці;

за виконання особливо важливої роботи (на термін її виконання);

за складність, напруженість у роботі.

Граничний розмір зазначених надбавок для одного працівника ННДІОП не повинен перевищувати 50 відсотків посадового окладу. У разі несвоєчасного виконання завдань, погіршення якості роботи, порушення трудової дисципліни ці надбавки скасовуються або зменшуються;

2) надавати працівникам матеріальну допомогу, у тому числі на оздоровлення, за винятком матеріальної допомоги на поховання, у сумі не більше, ніж один посадовий оклад (місячний оклад) на рік;

3) преміювати працівників відповідно до їх особистого внеску в загальні результати роботи згідно із затвердженими порядком і розмірами преміювання працівників.

Преміювання директора ННДІОП, установлення йому надбавок та доплат до посадового окладу, надання матеріальної допомоги здійснюється за рішенням відповідного керівника Держнаглядохоронпраці України за розподілом обов'язків.

3. Управлінню бухгалтерського обліку і звітності (Кулікова О.Л.) подати на державну реєстрацію Міністерству юстиції цей наказ, погоджений з Міністерством праці та соціальної політики і Міністерством фінансів.

4. Директору Національного науково-дослідного інституту охорони праці (Лисюк М.О.) запровадити ці умови оплати праці працівників з 1 березня 2004 року в межах фонду заробітної плати, передбаченого кошторисом.
