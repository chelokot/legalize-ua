ПОСТАНОВА від 8 листопада 2006 р. N 1558 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про внесення зміни до пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88

Кабінет Міністрів України постановляє:

В абзаці першому пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) "Питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2000 р., N 4, ст. 110; 2005 р., N 50, ст. 3129; 2006 р., N 3, ст. 92, N 33, ст. 2383) цифри "40" замінити цифрами "43", а цифри і слово "10 одиниць" замінити цифрою і словом "7 одиниць".
