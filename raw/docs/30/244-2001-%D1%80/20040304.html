Текст документа від 04.03.2004:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 червня 2001 р. N 244-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 104-р ( 104-2004-р ) від 04.03.2004 )

Про створення робочої групи для проведення аналізу комплексу питань щодо організації функціонування нафтопроводу Одеса - Броди

1. Для проведення разом з фахівцями США аналізу комплексу питань щодо організації функціонування нафтопроводу Одеса - Броди, його фінансування, укладення контрактів на транспортування нафти та вирішення інших організаційно-фінансових питань утворити робочу групу в складі згідно з додатком.

Дозволити керівникові робочої групи вносити у разі потреби зміни до її складу.

2. За результатами аналізу робочій групі підготувати до 25 серпня 2001 р. висновки щодо економічної ефективності функціонування нафтопроводу Одеса - Броди.

3. МЗС забезпечити організаційне сприяння у залученні фахівців США для участі в робочій групі.

4. Матеріально-технічне забезпечення діяльності робочої групи покласти на Мінпаливенерго та НАК "Нафтогаз України".
