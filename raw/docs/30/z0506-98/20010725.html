НАКАЗ

N 436 від 27.07.98 Зареєстровано в Міністерстві м.Київ юстиції України 12 серпня 1998 р. vd980727 vn436 за N 506/2946

Про затвердження Переліку товарів, що ввозяться за попередньою вантажною митною декларацією

( Із змінами, внесеними згідно з Наказами Державної митної служби N 157 ( z0198-99 ) від 17.03.99 N 369 ( z0443-99 ) від 16.06.99 N 250 ( z0285-00 ) від 28.04.2000 N 344 ( z0384-00 ) від 14.06.2000 N 99 ( z0202-01 ) від 16.02.2001 N 433 ( z0637-01 ) від 26.06.2001 )

На виконання постанови Кабінету Міністрів України від 02.04.98 N 419 ( 419-98-п ) "Про заходи щодо посилення контролю за ввезенням в Україну окремих видів товарів, що імпортуються суб'єктами підприємницької діяльності" НАКАЗУЮ:

1. Затвердити Перелік товарів, що ввозяться за попередньою вантажною митною декларацією (далі - Перелік), який додається.

2. Правовому управлінню (Тимошенко С.В.) зареєструвати цей наказ в Міністерстві юстиції.

3. Управлінню справами (Максимов Ю.Ю.) забезпечити доведення Переліку до особового складу митних органів.

4. Прес-центру (Котов О.І.), начальникам регіональних митниць, начальникам митниць довести зазначений Перелік до відома суб'єктів ЗЕД і громадян.
