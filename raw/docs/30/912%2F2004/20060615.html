Текст документа від 15.06.2006:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до деяких указів Президента України

{ Із змінами, внесеними згідно з Указами Президента N 1009/2004 ( 1009/2004 ) від 27.08.2004 N 510/2006 ( 510/2006 ) від 09.06.2006 }

Внести до указів Президента України такі зміни:

1. В Указі Президента України від 15 липня 2004 року N 803 ( 803/2004 ) "Про Державну службу України з нагляду за забезпеченням безпеки авіації":

статтю 1 доповнити словами "(далі - Державіаслужба) на базі Державного департаменту авіаційного транспорту України, що ліквідується";

{ Абзац третій статті 1 втратив чинність на підставі Указу Президента N 510/2006 ( 510/2006 ) від 09.06.2006 }

{ Абзац четвертий статті 1 втратив чинність на підставі Указу Президента N 510/2006 ( 510/2006 ) від 09.06.2006 }

{ Абзац п'ятий статті 1 втратив чинність на підставі Указу Президента N 510/2006 ( 510/2006 ) від 09.06.2006 }

{ Абзац шостий статті 1 втратив чинність на підставі Указу Президента N 510/2006 ( 510/2006 ) від 09.06.2006 }

у статті 3:

пункт 1 доповнити абзацом такого змісту:

"подати законопроект про внесення змін до Повітряного кодексу України, врахувавши рекомендації Міжнародної організації цивільної авіації (ІКАО) і Європейського Союзу щодо створення державної системи контролю за забезпеченням безпеки авіації та передбачивши, зокрема, створення незалежного органу з розслідування авіаційних подій";

пункт 2 викласти в такій редакції:

"2) ліквідувати Державний департамент авіаційного транспорту України";

доповнити статтю пунктом 6 такого змісту:

"6) подати нову редакцію Закону України "Про транспорт", врахувавши положення цього Указу";

доповнити Указ статтею 6 такого змісту: { Абзац чотирнадцятий статті 1 із змінами, внесеними згідно з Указом Президента N 510/2006 ( 510/2006 ) від 09.06.2006 }

{ Абзац п'ятнадцятий статті 1 втратив чинність на підставі Указу Президента N 510/2006 ( 510/2006 ) від 09.06.2006 }

"6. Призначити МАКСИМОВА Володимира Олексійовича Головою Державної служби України з нагляду за забезпеченням безпеки авіації";

у статті 3 Указу Указу слова "Державна служба України з нагляду за забезпеченням безпеки авіації" в усіх відмінках замінити словом "Державіаслужба" у відповідному відмінку. { Абзац сімнадцятий статті 1 із змінами, внесеними згідно з Указом Президента N 510/2006 ( 510/2006 ) від 09.06.2006 }

( Стаття 2 втратила чинність на підставі Указу Президента N 1009/2004 ( 1009/2004 ) від 27.08.2004 )
