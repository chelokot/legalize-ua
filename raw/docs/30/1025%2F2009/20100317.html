Текст документа від 17.03.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 300/2010 ( 300/2010 ) від 11.03.2010 }

Про внесення зміни до Указу Президента України від 23 травня 2005 року N 841

1. Внести до Указу Президента України від 23 травня 2005 року N 841 ( 841/2005 ) "Про кількість заступників Голови Служби безпеки України" (в редакції Указу від 16 листопада 2007 року N 1115 ( 1115/2007 ), зі змінами, внесеними Указами від 28 січня 2009 року N 41 ( 41/2009 ), від 10 березня 2009 року N 147 ( 147/2009 ), від 30 квітня 2009 року N 278 ( 278/2009 ) та від 18 червня 2009 року N 461) ( 461/2009 ) зміну, замінивши в абзаці першому слова "одного першого заступника та шістьох заступників" словами "двох перших заступників, у тому числі першого заступника Голови Служби безпеки України - начальника Головного управління по боротьбі з корупцією та організованою злочинністю Центрального управління Служби безпеки України, і п'ятьох заступників".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 11 грудня 2009 року N 1025/2009
