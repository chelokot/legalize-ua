Стан: Чинний

Текст документа від 17.10.2005:

ПЕНСІЙНИЙ ФОНД УКРАЇНИ ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ДЕРЖАВНОГО МАТЕРІАЛЬНОГО РЕЗЕРВУ

НАКАЗ

29.09.2005 N 145/272

Зареєстровано в Міністерстві юстиції України 17 жовтня 2005 р. за N 1202/11482

Про визнання таким, що втратив чинність, наказу Пенсійного

фонду України, Державного комітету України по матеріальних резервах від 27.08.99 N 113/186

Відповідно до пункту 13 Положення про Пенсійний фонд України, затвердженого Указом Президента України від 01.03.2001 N 121 ( 121/2001 ) (із змінами), пункту 5 Положення про Державний комітет України з державного матеріального резерву, затвердженого Указом Президента України від 20.10.2001 N 996 ( 996/2001 ) (із змінами), НАКАЗУЄМО:

1. Визнати таким, що втратив чинність, наказ Пенсійного фонду України, Державного комітету України по матеріальних резервах від 27.08.99 N 113/186 ( z0630-99 ) "Про затвердження Порядку передачі Державним комітетом України по матеріальних резервах Пенсійному фонду України цукру для подальшої його видачі пенсіонерам за їх згодою в рахунок погашення заборгованості з виплати пенсій", зареєстрований в Міністерстві юстиції України 20.09.99 за N 630/3923.

2. Юридичному управлінню Пенсійного фонду України (Рябцева Т.Б.) подати цей наказ для державної реєстрації до Міністерства юстиції України.

Голова правління Пенсійного фонду України Б.О.Зайчук

В.о. Голови Державного комітету України з державного матеріального резерву Р.Г. Головін
