Про форми списків виборців на виборчих дільницях для підготовки та проведення голосування з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів

Стан: Втратив чинність

Ідентифікатор: v0290359-10

Текст документа від 27.04.2010:

ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

ПОСТАНОВА

27.04.2010 N 290

Про форми списків виборців на виборчих дільницях для підготовки та проведення голосування з виборів депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів

Відповідно до пункту 4 статті 23, статей 31, 31-1, 32-3, частин другої, вісімнадцятої статті 67 Закону України "Про вибори депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів" ( 1667-15 ), частин другої - восьмої статті 27, частини сьомої статті 28, пункту 3 Прикінцевих положень Закону України "Про Державний реєстр виборців" ( 698-16 ), керуючись статтями 11-13, пунктом 7 статті 21 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Встановити форми:

попереднього списку виборців на звичайній виборчій дільниці (додаток 1) ( va290359-10 );

уточненого списку виборців на звичайній виборчій дільниці (додаток 2) ( va290359-10 );

списку виборців на спеціальній виборчій дільниці (додаток 3) ( va290359-10 );

витягу із списку виборців на звичайній виборчій дільниці для голосування за місцем перебування виборців, не здатних пересуватися самостійно (додаток 4) ( va290359-10 );

витягу із списку виборців на спеціальній виборчій дільниці для голосування за місцем перебування виборців, не здатних пересуватися самостійно (додаток 5) ( va290359-10 ).

2. Списки виборців на виборчих дільницях (додатки 1-3) ( va290359-10 ), витяги із списків виборців на звичайній та спеціальній виборчих дільницях для голосування за місцем перебування виборців, не здатних пересуватися самостійно (додатки 4, 5) ( va290359-10 ), друкуються на аркушах формату А3 з обох боків.

3. Визнати такою, що втратила чинність, постанову Центральної виборчої комісії від 28 березня 2008 року N 12 ( v0012359-08 ) "Про використання форм та зразків виборчих документів, установлених (затверджених) Центральною виборчою комісією відповідно до Закону України "Про вибори депутатів Верховної Ради Автономної Республіки Крим, місцевих рад та сільських, селищних, міських голів" ( 1667-15 ), під час проведення позачергових, повторних, проміжних або перших (у разі формування нових місцевих рад) місцевих виборів" у частині використання під час проведення позачергових, повторних, проміжних або перших (у разі формування нових місцевих рад) виборів депутатів Верховної Ради Автономної Республіки Крим, сільських, селищних, міських, районних у містах, районних, обласних, Київської та Севастопольської міських рад та сільських, селищних, міських голів форм виборчих документів, встановлених постановою Центральної виборчої комісії від 31 січня 2006 року N 351 ( v0351359-06, va351359-06 ).

4. Цю постанову надіслати Верховній Раді Автономної Республіки Крим, обласним, Київській та Севастопольській міським радам для подальшої передачі виборчій комісії Автономної Республіки Крим, обласним, Київській та Севастопольській міським, районним, міським, районним у містах, селищним, сільським територіальним виборчим комісіям, а також регіональним органам адміністрування Державного реєстру виборців для доведення до відома відповідних органів ведення Державного реєстру виборців.
