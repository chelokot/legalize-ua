{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для виконання програм та здійснення централізованих заходів з охорони здоров'я, здійснюється відповідно Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 375 ( 375-2008-п ) від 17.04.2008 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для виконання програм та здійснення централізованих заходів з охорони здоров'я, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 4 квітня 2007 р. N 601

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для виконання програм та здійснення централізованих заходів з охорони здоров'я

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених МОЗ у державному бюджеті ( 489-16 ) для виконання програм та здійснення централізованих заходів з охорони здоров'я (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються на централізовану закупівлю діагностичних та лікарських засобів, імунобіологічних препаратів (вакцин), виробів медичного призначення, медичного обладнання, санітарних автотранспортних засобів, інших товарів і послуг відповідно до програм і централізованих заходів з охорони здоров'я та забезпечення ними закладів охорони здоров'я (далі - товари і послуги).

3. Закупівля товарів і послуг за бюджетні кошти здійснюється МОЗ у встановленому законодавством порядку.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 375 ( 375-2008-п ) від 17.04.2008 }

4. МОЗ розподіляє централізовано закуплені товари і послуги в межах бюджетних призначень між Міністерством охорони здоров'я Автономної Республіки Крим, головними управліннями (управліннями) охорони здоров'я обласних, Київської та Севастопольської міських держадміністрацій (далі - територіальні органи охорони здоров'я), закладами охорони здоров'я, що належать до сфери управління МОЗ, та головними розпорядниками коштів державного бюджету, заклади охорони здоров'я яких забезпечуються товарами та послугами за рахунок бюджетних коштів (далі - головні розпорядники коштів), згідно з розрахунками, що проводяться з урахуванням потреби відповідно до заявок територіальних органів охорони здоров'я, зазначених закладів МОЗ та розпорядників коштів (далі - заявки).

5. Вимоги щодо складення і подання заявок встановлюються МОЗ виходячи з принципу ефективності використання бюджетних коштів із застосуванням конкретних критеріїв обґрунтування потреби в товарах і послугах, визначення її за номенклатурою та обсягами, а також з урахуванням наявних на початок року в закладах охорони здоров'я залишків товарів, включаючи ті, що надійшли із централізованими поставками у попередні роки.

6. З метою недопущення виникнення кредиторської заборгованості на кінець року до договорів про закупівлю товарів і послуг включається умова щодо коригування суми договору у разі зменшення бюджетних призначень внаслідок уточнення показників державного бюджету, а також надходження до МОЗ бюджетних коштів не в повному обсязі.

7. Після проведення в установленому порядку процедури державних закупівель МОЗ укладає договори про закупівлю товарів і послуг з її переможцями, а також з одержувачами бюджетних коштів у разі надання ними послуг з постачання, зберігання, монтажу, пусконалагодження або з організації постачання товарів.

У договорі про закупівлю товарів і послуг визначаються їх номенклатура, обсяг та вартість.

{ Абзац третій пункту 7 виключено на підставі Постанови КМ N 375 ( 375-2008-п ) від 17.04.2008 }

{ Пункт 7 в редакції Постанови КМ N 804 ( 804-2007-п ) від 06.06.2007 }

8. Товари і послуги поставляються і надаються територіальним органам охорони здоров'я, головним розпорядникам коштів, визначеним ними закладам охорони здоров'я або одержувачам бюджетних коштів для подальшого забезпечення закладів охорони здоров'я згідно з графіками, що додаються до договорів про закупівлю, та розподілом, що здійснюється МОЗ.

{ Пункт 8 в редакції Постанови КМ N 804 ( 804-2007-п ) від 06.06.2007 }

9. Заклади охорони здоров'я подають щокварталу у строк, визначений МОЗ, звіти про використання товарів за номенклатурою його територіальним органам та головним розпорядникам коштів для узагальнення та подання МОЗ за встановленою ним формою.

10. МОЗ проводить щокварталу моніторинг рівня забезпеченості закладів охорони здоров'я товарами і за його результатами коригує обсяги і номенклатуру поставок та перерозподіляє залишки згідно з фактичною потребою у таких товарах.

11. МОЗ подає у визначений для квартальної фінансової звітності строк Мінфіну інформацію про виконання програм і здійснення централізованих заходів з охорони здоров'я за встановленою ним формою.

{ Пункт 12 виключено на підставі Постанови КМ N 375 ( 375-2008-п ) від 17.04.2008 }

{ Пункт 13 виключено на підставі Постанови КМ N 375 ( 375-2008-п ) від 17.04.2008 }

14. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
