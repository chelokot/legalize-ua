КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 1 червня 2011 р. N 579 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 521 ( 521-2016-п ) від 23.08.2016 }

Про внесення зміни до пункту 2 постанови Кабінету Міністрів України від 28 серпня 2001 р. N 1119

Кабінет Міністрів України постановляє:

Внести зміну до пункту 2 постанови Кабінету Міністрів України від 28 серпня 2001 р. N 1119 ( 1119-2001-п ) "Про внесення змін до постанови Кабінету Міністрів України від 13 грудня 1999 р. N 2288" (Офіційний вісник України, 2001 р., N 35, ст. 1627; 2003 р., N 45, ст. 2358; 2005 р., N 27, ст. 1550; 2006 р., N 5, ст. 230; 2007 р., N 79, ст. 2959; 2008 р., N 35, ст. 1179; 2010 р., N 27, ст. 1063; 2011 р., N 30, ст. 1297), доповнивши його після слів "керівнику розвідувального органу Міністерства оборони" словами ", Прес-секретарю Президента України, Раднику Президента України, Раднику Президента України - Керівнику Головного управління Адміністрації Президента України".

Прем'єр-міністр України М.АЗАРОВ
