Про новий склад Редакційної колегії з видання збірників актів законодавства України

{ Із змінами, внесеними згідно з Указом Президента N 1186/98 від 26.10.98 }

На зміну статті 2 Указу Президента України від 15 березня 1996 року N 185 ( 185/96 ) затвердити новий склад Редакційної колегії з видання збірників актів законодавства України (додається).

СКЛАД Редакційної колегії з видання збірників актів законодавства України

Сузана Романівна Редакційної колегії

СТИЧИНСЬКИЙ - перший заступник Міністра юстиції

Броніслав Станіславович України, заступник голови Редакційної колегії

БОГАЧОВА - директор Центру правової реформи і

Олена Вікторівна законопроектних робіт при Міністерстві юстиції України

БУТЕЙКО - перший заступник Міністра закордонних Антон Денисович справ України

КУШНАРЬОВ - Глава Адміністрації Президента

Євген Петрович України

ПІДПАЛОВ - заступник Глави Адміністрації

Леонід Васильович Президента України

ТЕРТИЧНИЙ - начальник Управління систематизації Віталій Григорович законодавства, державних реєстрів, правової освіти та інформації Міністерства юстиції України.

СІРЕНКО - Голова Комітету Верховної Ради
