Про моніторинг соціально-економічного розвитку малих міст

{ Із змінами, внесеними згідно з Постановами КМ N 1192 ( 1192-2011-п ) від 23.11.2011 N 750 ( 750-2012-п ) від 18.07.2012 }

{ У назві і тексті Постанови слова "і селищ" виключено згідно з Постановою КМ N 750 ( 750-2012-п ) від 18.07.2012 }

З метою визначення оцінки соціально-економічного становища малих міст, своєчасного виявлення негативних тенденцій їх розвитку та забезпечення прийняття управлінських рішень Кабінет Міністрів України постановляє:

1. Запровадити проведення моніторингу соціально-економічного розвитку малих міст (далі - моніторинг).

Для проведення моніторингу використовуються показники соціально-економічного розвитку малих міст, перелік яких зазначений у додатку 1. { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 750 ( 750-2012-п ) від 18.07.2012 }

2. Установити такий порядок проведення моніторингу:

головні управління (управління) статистики, державні податкові служби, головні управління Пенсійного фонду в Автономній Республіці Крим, областях та м. Севастополі подають щороку до 20 червня Раді міністрів Автономної Республіки Крим, обласним та Севастопольській міській держадміністраціям відомості про стан соціально-економічного розвитку малих міст; { Абзац другий пункту 2 із змінами, внесеними згідно з Постановами КМ N 1192 ( 1192-2011-п ) від 23.11.2011, N 750 ( 750-2012-п ) від 18.07.2012 }

Рада міністрів Автономної Республіки Крим, обласні та Севастопольська міська держадміністрації подають до 20 липня Міністерству економічного розвитку і торгівлі і Міністерству регіонального розвитку, будівництва та житлово-комунального господарства відомості про стан соціально-економічного розвитку малих міст за встановленою Міністерством економічного розвитку і торгівлі формою. Разом із зазначеними відомостями Рада міністрів Автономної Республіки Крим, обласні та Севастопольська міська держадміністрації подають аналітичну записку про стан соціально-економічного розвитку малих міст у звітному році з визначенням проблем та пропозиціями щодо їх розв'язання за формою, визначеною в додатку 2; { Абзац третій пункту 2 із змінами, внесеними згідно з Постановами КМ N 1192 ( 1192-2011-п ) від 23.11.2011, N 750 ( 750-2012-п ) від 18.07.2012 }

Міністерство економічного розвитку і торгівлі проводить узагальнення та аналіз відомостей про стан соціально-економічного розвитку малих міст та подає щороку до 1 вересня звіт Кабінетові Міністрів України. { Абзац четвертий пункту 2 із змінами, внесеними згідно з Постановою КМ N 1192 ( 1192-2011-п ) від 23.11.2011 }

3. Надати Міністерству економічного розвитку і торгівлі право вносити за погодженням з Державною службою статистики у разі потреби зміни до переліку показників, за якими проводиться моніторинг.
