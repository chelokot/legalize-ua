Рішення про продовження строку дії Положення про Раду по залізничному транспорту держав-учасниць Співдружності Незалежних Держав

Стан: Втратив чинність

Ідентифікатор: 997_693

Текст документа від 13.11.1992:

Рішення про продовження строку дії Положення про Раду по залізничному транспорту держав-учасниць Співдружності Незалежних Держав

Дата підписання: 13.11.1992

Дата набуття чинності для України: 13.11.1992

Рада глав урядів Співдружності Незалежних Держав,

виходячи з необхідності подальшого розвитку взаємокорисного співробітництва, забезпечення стійких міждержавних економічних зв'язків, координації експлуатаційної діяльності залізниць, спільного використання вагонів і контейнерів, їх технічного обслуговування, ремонту і взаємозаліків,

вирішила:

1. Відзначити важливість проведеної в 1992 році Радою по залізничному транспорту держав - учасниць Співдружності роботи по координації діяльності залізничного транспорту на міждержавному рівні, виробленню узгоджених принципів її функціонування, підготовці нормативних документів по спільній експлуатації парків вантажних вагонів і контейнерів.

2. Продовжити строк дії Положення про Раду по залізничному транспорту держав-учасниць Співдружності ( 997_624 ) на невизначений термін.

3. Дозволити Раді по залізничному транспорту держав-учасниць Співдружності вносити до Положення про Раду по залізничному транспорту держав-учасниць Співдружності ( 997_624 ) зміни та доповнення за згодою всіх членів Ради.

Вчинено в місті Москві 13 листопада 1992 року в одному дійсному примірнику російською мовою. Дійсний примірник зберігається в Архіві Уряду Республіки Білорусь, який направить державам, що підписали це Рішення, його завірену копію.
