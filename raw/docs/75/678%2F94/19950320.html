УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 227/95 ( 227/95 ) від 16.03.95 )

Про поширення чинності Указу Президента України від 22 жовтня 1994 року N 629 на підприємства та організації військової торгівлі

Поширити чинність Указу Президента України від 22 жовтня 1994 року N 629 ( 629/94 ) "Про заходи щодо впорядкування розрахунків підприємств і організацій споживчої кооперації з постачальниками товарів народного споживання" на підприємства та організації військової торгівлі.
