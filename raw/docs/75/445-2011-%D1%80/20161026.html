{ Розпорядження втратило чинність на підставі Розпорядження КМ N 785-р ( 785-2016-р ) від 26.10.2016 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 12 жовтня 2010 р. N 1968

На часткову зміну абзацу другого розпорядження Кабінету Міністрів України від 12 жовтня 2010 р. N 1968 ( 1968-2010-р ) уповноважити Першого віце-прем'єр-міністра України - Міністра економічного розвитку і торгівлі Клюєва Андрія Петровича підписати Торговельну угоду між Урядом України та Урядом Королівства Таїланд.

Прем'єр-міністр України М.АЗАРОВ
