Питання Координаційної ради з питань державної служби при Президентові України

Стан: Втратив чинність

Ідентифікатор: 1084/2005

Текст документа від 19.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 480/2010 ( 480/2010 ) від 02.04.2010 }

Питання Координаційної ради з питань державної служби при Президентові України

1. Затвердити новий персональний склад Координаційної ради з питань державної служби при Президентові України (додається).

2. Внести до Указів Президента України такі зміни:

1) у частині другій статті 1 Указу Президента України від 11 лютого 2000 року N 208 ( 208/2000 ) "Про підвищення ефективності системи державної служби" (зі змінами, внесеними Указами від 4 січня 2003 року N 1 ( 1/2003 ) та від 5 березня 2004 року N 280 ( 280/2004 ) слова "Глава Адміністрації Президента України", "Міністр економіки та з питань європейської інтеграції України" та "заступник Глави Адміністрації Президента України - Керівник Головного управління організаційно-кадрової політики та взаємодії з регіонами Адміністрації Президента України" замінити відповідно словами "Державний секретар України", "Міністр економіки України" та "Керівник Головної служби регіональної та кадрової політики Секретаріату Президента України";

2) в Указі Президента України від 21 березня 2000 року N 473 ( 473/2000 ) "Про Координаційну раду з питань державної служби при Президентові України" (зі змінами, внесеними Указами від 4 січня 2003 року N 1 ( 1/2003 ), від 5 березня 2004 року N 280 ( 280/2004 ) та від 22 січня 2005 року N 77 ( 77/2005 ):

а) визнати такою, що втратила чинність, статтю 2;

б) у Положенні про Координаційну раду з питань державної служби при Президентові України, затвердженому зазначеним Указом ( 473/2000 ):

пункт 7 викласти в такій редакції:

"7. Головою Ради за посадою є Державний секретар України, а його заступниками - Міністр Кабінету Міністрів України та Начальник Головного управління державної служби України";

абзац перший пункту 10 викласти в такій редакції:

"10. Організаційне забезпечення діяльності Ради здійснюється Головною службою регіональної та кадрової політики Секретаріату Президента України, а також Головним управлінням державної служби України, яке виконує і функції робочого органу Ради".

Президент України В.ЮЩЕНКО
