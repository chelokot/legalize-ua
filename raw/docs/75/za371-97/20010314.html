ФОНД ДЕРЖАВНОГО МАЙНА УКРАЇНИ

НАКАЗ

N 908 від 21.08.97 Зареєстровано в Міністерстві м.Київ юстиції України 2 вересня 1997 р. за N 371/2175

( Наказ втратив чинність на підставі Наказу Фонду державного майна N 343 ( za226-01 ) від 02.03.2001 )

Про затвердження Порядку цільового кредитування приватизованих підприємств

( Додатково див. Постанову Нацбанку N 236 ( z0436-98 ) від 18.06.98 )

На виконання Державної програми приватизації на 1997 рік ( 294/97-ВР ), з метою забезпечення цільового кредитування технічного переозброєння приватизованих підприємств відповідно до статті 23 Закону України "Про приватизацію державного майна" ( 2163-12 ) НАКАЗУЮ:

1. Затвердити Порядок цільового кредитування приватизованих підприємств ( z0371-97 ).

2. Департаменту договірного менеджменту (Тараба В.П.) в триденний термін після підписання цього наказу направити Порядок на реєстрацію до Міністерства юстиції.

3. Департаменту договірного менеджменту у двотижневий термін розробити та затвердити Положення про порядок розгляду і надання кредитів з Державного позабюджетного фонду приватизації.

4. Контроль за виконанням цього наказу залишаю за собою.

Т.в.о.Голови Фонду В.Ковтюх
