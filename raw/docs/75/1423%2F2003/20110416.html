Президент України; Указ від 10.12.2003 № 1423/2003

Про внесення змін до Порядку складення присяги суддею, вперше призначеним на посаду

Стан: Втратив чинність

Ідентифікатор: 1423/2003

Текст документа від 16.04.2011:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 380/2011 ( 380/2011 ) від 06.04.2011 }

Про внесення змін до Порядку складення присяги суддею, вперше призначеним на посаду

Внести до Порядку складення присяги суддею, вперше призначеним на посаду, затвердженого Указом Президента України від 11 травня 1999 року N 493 ( 493/99 ) (зі змінами, внесеними Указами від 16 серпня 1999 року N 991 ( 991/99 ) та від 3 лютого 2003 року N 59 ( 59/2003 ), такі зміни:

а) пункт 2 доповнити після абзацу першого новим абзацом такого змісту:

"В окремих випадках суддя складає присягу, за дорученням Президента України, у присутності голови обласної державної адміністрації, членів відповідної ради суддів, голови відповідного апеляційного суду, суддів суду, в який його призначено, та начальника територіального управління державної судової адміністрації в урочистій обстановці у приміщенні, де встановлено Державний Герб України і Державний Прапор України".

У зв'язку з цим абзац другий вважати абзацом третім;

б) пункт 4 після слів "Президент України" доповнити словами "або за його дорученням голова обласної державної адміністрації".

Президент України Л.КУЧМА
