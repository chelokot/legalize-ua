РОЗПОРЯДЖЕННЯ від 10 жовтня 2007 р. N 862-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 149 ( 149-2009-п ) від 25.02.2009 }

Про зміну складу Державної акредитаційної комісії

Внести до складу Державної акредитаційної комісії, затвердженого постановою Кабінету Міністрів України від 1 серпня 2006 р. N 1073 ( 1073-2006-п ) (Офіційний вісник України, 2006 р., N 31, ст. 2232), такі зміни:

затвердити Шинкарука Василя Дмитровича - заступника Міністра освіти і науки заступником голови Комісії;

ввести до складу Комісії Михайліченка Миколу Васильовича - начальника управління ліцензування, акредитації та нострифікації МОН;

вивести із складу Комісії Горбунову Лідію Миколаївну, Рудавського Юрія Кириловича і Степка Михайла Филимоновича;

зазначити нову посаду Андріанова Віктора Михайловича - перший заступник Міністра культури і туризму.

Прем'єр-міністр України В.ЯНУКОВИЧ
