Текст документа від 29.06.2005:

ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

29.06.2005 N 595

Зареєстровано в Міністерстві юстиції України 11 липня 2005 р. за N 730/11010

Про визнання такими, що втратили чинність, деяких наказів Держмитслужби України

З метою приведення нормативно-правових актів Держмитслужби України у відповідність до Закону України від 25.03.2005 N 2505-IV ( 2505-15 ) "Про внесення змін до Закону України "Про Державний бюджет України на 2005 рік" та деяких інших законодавчих актів України" НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Держмитслужби України:

від 26.06.2001 N 431 ( z0556-01 ) "Про затвердження Порядку митного оформлення товарів та інших предметів, що переміщуються через межі території спеціальної економічної зони "Донецьк", зареєстрований у Міністерстві юстиції України 03.07.2001 за N 556/5747;

від 26.06.2001 N 432 ( z0596-01 ) "Про затвердження Порядку митного оформлення товарів та інших предметів, що переміщуються через межі території спеціальної економічної зони "Закарпаття", зареєстрований у Міністерстві юстиції України 17.07.2001 за N 596/5787;

від 26.12.2001 N 832 ( z0032-02 ) "Про затвердження Тимчасового порядку переміщення товарів та інших предметів через територію СЕЗ "Закарпаття" з метою здійснення операцій, передбачених у частині 4 статті 6 Закону України "Про спеціальну економічну зону "Закарпаття", зареєстрований у Міністерстві юстиції України 15.01.2002 за N 32/6320;

від 19.11.2002 N 636 ( z0959-02 ) "Про затвердження Порядку митного оформлення товарів та предметів, що переміщуються через межі території спеціальної економічної зони "Азов" резидентами при здійсненні операцій, передбачених підпунктами "в" і "е" пункту 2 статті 12 Закону України "Про спеціальні економічні зони та спеціальний режим інвестиційної діяльності в Донецькій області", зареєстрований у Міністерстві юстиції України 06.12.2002 за N 959/7247;

від 02.12.2002 N 672 ( z0985-02 ) "Про затвердження Порядку митного оформлення товарів та предметів, що переміщуються через межі території спеціальної економічної зони "Закарпаття" резидентами при здійсненні операцій, передбачених пунктами "в" і "е" статті 7 Закону України "Про спеціальну економічну зону "Закарпаття", зареєстрований у Міністерстві юстиції України 19.12.2002 за N 985/7273;

від 02.12.2002 N 673 ( z0986-02 ) "Про затвердження Порядку митного оформлення товарів та предметів, що переміщуються через межі території спеціальної економічної зони "Донецьк" резидентами при здійсненні операцій, передбачених підпунктами "в" і "е" пункту 3 статті 12 Закону України "Про спеціальні економічні зони та спеціальний режим інвестиційної діяльності в Донецькій області", зареєстрований у Міністерстві юстиції України 19.12.2002 за N 986/7274;

від 26.08.2003 N 577 ( z0765-03 ) "Про внесення змін до порядків, затверджених наказами Держмитслужби України від 19.11.2002 N 636 і від 02.12.2002 N 673", зареєстрований у Міністерстві юстиції України 04.09.2003 за N 765/8086.

2. Департаменту декларування та митних режимів (Науменко В.П.) і Юридичному департаменту (Боженко І.Ф.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Начальникам митних органів і спеціалізованих митних установ довести цей наказ до відома фізичних та юридичних осіб.

4. Установити, що наказ набирає чинності через 10 днів з дня його офіційного опублікування.

5. Контроль за виконанням наказу покласти на заступника Голови Служби Пашка П.В.

В.о. Голови Служби М.М.Салагор
