УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 470/2010 ( 470/2010 ) від 02.04.2010 }

Про внесення зміни до Указу Президента України від 8 травня 2007 року N 389

1. Внести зміну до Указу Президента України від 8 травня 2007 року N 389 ( 389/2007 ) "Про забезпечення підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу" (зі зміною, внесеною Указом від 31 серпня 2007 року N 802) ( 802/2007 ), доповнивши його статтею 2-1 такого змісту:

"2-1. Установити, що до складу Координаційної ради входить керівник Центру з питань безпеки та правопорядку.

Забезпечення діяльності Координаційної ради з питань забезпечення громадського порядку і громадської безпеки під час підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу здійснюється Центром з питань безпеки та правопорядку, з інших питань - Секретаріатом Президента України".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
