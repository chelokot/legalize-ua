КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 січня 2003 р. N 136 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 589 ( 589-2006-п ) від 27.04.2006 }

Про норми харчування у Всеукраїнському центрі професійної реабілітації інвалідів

Кабінет Міністрів України постановляє:

Установити, що харчування інвалідів, які проходять професійну реабілітацію у Всеукраїнському центрі професійної реабілітації інвалідів, проводиться за натуральними добовими нормами харчування відпочиваючих у санаторіях сфери управління Міністерства праці та соціальної політики, затвердженими постановою Кабінету Міністрів України від 13 березня 2002 р. N 324 ( 324-2002-п ) (Офіційний вісник України, 2002 р., N 12, ст. 592).
