Кабінет Міністрів України; Розпорядження від 29.03.2000 № 152-р

Про встановлення Державною комісією з цінних паперів та фондового ринку розмірів плати за реєстрацію цінних паперів

Стан: Втратив чинність

Ідентифікатор: 152-2000-р

Текст документа від 01.11.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 березня 2000 р. N 152-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1097 ( 1097-2011-п ) від 26.10.2011 }

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 45-р ( 45-2004-р ) від 04.02.2004 N 643-р ( 643-2006-р ) від 27.12.2006 }

Погодитися з рішенням Державної комісії з цінних паперів та фондового ринку про встановлення плати у розмірі:

{ Абзац другий виключено на підставі Розпорядження КМ N 643-р ( 643-2006-р ) від 27.12.2006 }

{ Абзац третій виключено на підставі Розпорядження КМ N 643-р ( 643-2006-р ) від 27.12.2006 }

за реєстрацію саморегулівної організації - 100 неоподатковуваних мінімумів доходів громадян;

за реєстрацію правил фондової біржі та іншого організаційно оформленого ринку цінних паперів - 25 неоподатковуваних мінімумів доходів громадян;

за реєстрацію змін до правил фондової біржі та іншого організаційно оформленого ринку цінних паперів - 12 неоподатковуваних мінімумів доходів громадян;

{ Абзац сьомий виключено на підставі Розпорядження КМ N 643-р ( 643-2006-р ) від 27.12.2006 }

за реєстрацію документів для сертифікації особи, що здійснює професійну діяльність з цінними паперами в Україні, - 5 неоподатковуваних мінімумів доходів громадян.

Прем'єр-міністр України В.ЮЩЕНКО
