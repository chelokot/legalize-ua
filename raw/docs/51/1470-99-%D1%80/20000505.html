Кабінет Міністрів України; Розпорядження від 31.12.1999 № 1470-р

Про дозвіл Держмитслужбі здійснювати митне оформлення заготовок для монет з нержавіючої сталі та мідно-нікелевих сплавів, які надходять на адресу Банкнотно-монетного двору

Стан: Втратив чинність

Ідентифікатор: 1470-99-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 грудня 1999 р. N 1470-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

З метою забезпечення виконання замовлень іноземних держав щодо виробництва монет на потужностях Банкнотно-монетного двору Національного банку дозволити Держмитслужбі здійснювати митне оформлення заготовок для монет з нержавіючої сталі (код згідно з ТН ЗЕД 73.26 19900) та мідно-нікелевих сплавів (код згідно з ТН ЗЕД 74.09 40190), які надходять на адресу Банкнотно-монетного двору за контрактами, укладеними Національним банком, як товарів критичного імпорту, із сплатою ввізного мита на заготовки для монет з нержавіючої сталі (код згідно з ТН ЗЕД 73.26 19900) за ставкою у розмірі 0,01 відсотка їх митної вартості та без сплати додаткового збору на ці товари, встановленого постановою Кабінету Міністрів України від 19 травня 1999 року N 840 ( 840-99-п ).

Прем'єр-міністр України В.ЮЩЕНКО
