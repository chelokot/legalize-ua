Кабінет Міністрів України; Розпорядження, Склад колегіального органу від 04.08.2010 № 1602-р

Про погодження складу наглядової ради Національної акціонерної компанії "Нафтогаз України"

Стан: Втратив чинність

Ідентифікатор: 1602-2010-р

Текст документа від 15.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 серпня 2010 р. N 1602-р Київ

Про погодження складу наглядової ради Національної акціонерної компанії "Нафтогаз України"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 233-р ( 233-2013-р ) від 15.04.2013 }

1. Погодити запропонований Міністерством палива та енергетики склад наглядової ради Національної акціонерної компанії "Нафтогаз України" згідно з додатком.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 16 липня 2008 р. N 972 ( 972-2008-р ) "Про погодження складу спостережної ради НАК "Нафтогаз України".

Прем'єр-міністр України М.АЗАРОВ
