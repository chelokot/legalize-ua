Про внесення змін до переліку органів ліцензування та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Стан: Втратив чинність

Ідентифікатор: 1695-2006-п

Текст документа від 26.08.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 грудня 2006 р. N 1695 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 609 ( 609-2015-п ) від 05.08.2015 }

Про внесення змін до переліку органів ліцензування та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України

Кабінет Міністрів України постановляє:

1. Внести до переліку органів ліцензування, затвердженого постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001; 2004 р., N 25, ст. 1650; 2006 р., N 11, ст. 755, N 22, ст. 1635; N 40, ст. 2685), такі зміни:

абзаци другий - п'ятий пункту 3 графи "Вид господарської діяльності" виключити;

доповнити перелік пунктами 38 і 39 такого змісту:

"38. Держгеолслужба пошук (розвідка) корисних копалин

видобування корисних копалин із родовищ, що мають загальнодержавне значення та включені до Державного фонду родовищ корисних копалин

видобування дорогоцінних металів і дорогоцінного каміння, дорогоцінного каміння органогенного утворення, напівдорогоцінного каміння

39. Укргеодезкарто- виконання топографо-геодезичних, графія картографічних робіт".

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 22 лютого 2006 р. N 194 ( 194-2006-п ) "Про внесення змін до переліку органів ліцензування" (Офіційний вісник України, 2006 р., N 8, ст. 451);

постанову Кабінету Міністрів України від 15 березня 2006 р. N 330 ( 330-2006-п ) "Про внесення змін до переліку органів ліцензування" (Офіційний вісник України, 2006 р., N 11, ст. 755);

пункт 32 змін, що вносяться до актів Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 25 травня 2006 р. N 754 ( 754-2006-п ) (Офіційний вісник України, 2006 р., N 22, ст. 1635).

3. Ця постанова набирає чинності з дня опублікування.
