Про затвердження переліку підприємств, які мають стратегічне значення для економіки і безпеки держави

( Із змінами, внесеними згідно з Постановами КМ N 103 ( 103-98-п ) від 30.01.98 N 1151 ( 1151-98-п ) від 27.07.98 N 801 ( 801-99-п ) від 10.05.99 )

Кабінет Міністрів України постановляє:

1. Затвердити перелік підприємств, які мають стратегічне значення для економіки і безпеки держави, згідно з додатком.

Рішення про внесення змін до переліку підприємств, які мають стратегічне значення для економіки і безпеки держави, приймаються Кабінетом Міністрів України за поданням Міністерства економіки.

2. Фонду державного майна у планах розміщення акцій підприємств, що не увійшли до цього переліку, не передбачати залишення акцій у державній власності, крім випадків, передбачених законодавством.
