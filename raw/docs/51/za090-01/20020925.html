Антимонопольний комітет; Розпорядження від 29.10.2001 № 140-р

Про затвердження Положення про продаж цілісних майнових комплексів державних підприємств, які мають стратегічне значення для економіки та безпеки держави чи займають монопольне становище на загальнодержавному ринку

Реєстрація: Мін'юст України від 28.12.2001 № 1090/6281

Стан: Втратив чинність

Ідентифікатор: za090-01

Текст документа від 25.09.2002:

АНТИМОНОПОЛЬНИЙ КОМІТЕТ УКРАЇНИ

РОЗПОРЯДЖЕННЯ

N 140-р від 29.10.2001 Зареєстровано в Міністерстві юстиції України 28 грудня 2001 р. за N 1090/6281

( Розпорядження втратило чинність на підставі Розпорядження Антимонопольного комітету

N 226-р ( za784-02 ) від 26.07.2002 )

Про затвердження Положення про продаж цілісних майнових

комплексів державних підприємств, які мають стратегічне

значення для економіки та безпеки держави чи займають монопольне становище на загальнодержавному ринку

Керуючись статтею 7 Закону України "Про Антимонопольний комітет України" ( 3659-12 ) та статтею 16 Закону України "Про приватизацію державного майна" ( 2163-12 ), Антимонопольний комітет України ПОСТАНОВИВ:

Затвердити Положення про продаж цілісних майнових комплексів державних підприємств, які мають стратегічне значення для економіки та безпеки держави чи займають монопольне становище на загальнодержавному ринку ( z1090-01 ), що додається.
