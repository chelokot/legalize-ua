{ Розпорядження втратило чинність на підставі Постанови КМ N 904 ( 904-2012-п ) від 03.10.2012 }

Про внесення змін у додаток до постанови Кабінету Міністрів України від 18 лютого 2009 р. N 148

Внести у додаток до постанови Кабінету Міністрів України від 18 лютого 2009 р. N 148 ( 148-2009-п ) "Деякі питання участі держави у капіталізації банків" (Офіційний вісник України, 2009 р., N 15, ст. 474; 2010 р., N 36, ст. 1231, N 65, ст. 2304, N 69, ст. 2491) такі зміни:

ввести до складу Експертно-аналітичної ради з питань участі держави у капіталізації банків Клюєва Андрія Петровича - Першого віце-прем'єр-міністра України - Міністра економічного розвитку і торгівлі, Колобова Юрія Володимировича - першого заступника Голови Національного банку (за згодою) та Матузку Ярослава Васильовича - директора департаменту правового забезпечення Міністерства фінансів, вивівши з її складу Арбузова Сергія Геннадійовича, Коцюбу Володимира Олександровича та Тігіпка Сергія Леонідовича;

затвердити Клюєва Андрія Петровича заступником голови Ради;

зазначити нові посади таких членів Експертно-аналітичної ради:

"МАКСЮТА - заступник Міністра економічного

Анатолій Аркадійович розвитку і торгівлі

СОТУЛЕНКО - член наглядової ради публічного

Ігор Миколайович акціонерного товариства "Державний експортно-імпортний банк України"

ЯЩУК - заступник директора Департаменту

Валентина Віталіївна фахової експертизи, начальник Управління економіки та фінансів Секретаріату Кабінету Міністрів України".

Прем'єр-міністр України М.АЗАРОВ
