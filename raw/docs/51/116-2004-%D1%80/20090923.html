КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 березня 2004 р. N 116-р Київ

Про підписання Угоди між Кабінетом Міністрів України та Урядом Киргизької Республіки про взаємну охорону секретної інформації

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 827-р ( 827-2007-р ) від 03.10.2007 N 1137-р ( 1137-2009-р ) від 23.09.2009 }

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Киргизької Республіки про взаємну охорону секретної інформації.

Уповноважити заступника Голови СБУ Павленка Анатолія Єгоровича підписати зазначену Угоду, дозволивши вносити у разі потреби до проекту Угоди зміни, що не мають принципового характеру. { Абзац другий із змінами, внесеними згідно з Розпорядженнями КМ N 827-р ( 827-2007-р ) від 03.10.2007, N 1137-р ( 1137-2009-р ) від 23.09.2009 }
