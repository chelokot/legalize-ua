Про внесення змін до ставок ввізного мита на окремі види товарів

( Із змінами, внесеними згідно з Постановами КМ N 916 ( 916-97-п ) від 22.08.97 N 1798 ( 1798-99-п ) від 27.09.99 N 40 ( 40-2000-п ) від 15.01.2000 N 121 ( 121-2000-п ) від 24.01.2000 N 751 ( 751-2000-п ) від 04.05.2000 )

Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита на окремі види товарів ( 4а-93, 4б-93 ) згідно з додатком.

2. Затвердити зміни, що вносяться до деяких рішень Кабінету Міністрів України щодо ставок ввізного мита на окремі види товарів (додаються).

3. Ця постанова набирає чинності через 10 днів після її опублікування у газеті "Урядовий кур'єр".
