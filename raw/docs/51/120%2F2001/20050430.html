Про зміни у складі Комісії при Президентові України з питань громадянства

Стан: Втратив чинність

Ідентифікатор: 120/2001

Текст документа від 30.04.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 740/2005 ( 740/2005 ) від 30.04.2005 )

Про зміни у складі Комісії при Президентові України з питань громадянства

1. Увести до складу Комісії при Президентові України з питань громадянства, затвердженого Указом Президента України від 9 грудня 1994 року N 746 ( 746/94 ) (із змінами, внесеними Указами Президента України від 22 квітня 1996 року N 275 ( 275/96 ), від 6 листопада 1997 року N 1254 ( 1254/97 ), від 13 жовтня 1998 року N 1135 ( 1135/98 ), від 6 березня 1999 року N 238 ( 238/99 ) та від 7 червня 2000 року N 770 ( 770/2000 ), таких осіб:

РУДЬКО - Керівник Управління з питань

Микола Олександрович громадянства Адміністрації Президента України, заступник Голови Комісії

САРДАЧУК - заступник Міністра закордонних

Петро Данилович справ України

ХАРЛАМОВ - заступник Міністра внутрішніх

Олександр Володимирович справ України - начальник міліції громадської безпеки.

2. Вивести зі складу Комісії Корнієнка М.В., Майданника О.І., Чалого П.Ф.

Президент України Л.КУЧМА
