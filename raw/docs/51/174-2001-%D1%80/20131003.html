Про віднесення посад спеціалістів Державної кримінально-виконавчої служби до категорії посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 174-2001-р

Текст документа від 03.10.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 травня 2001 р. N 174-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Про віднесення посад спеціалістів Державної кримінально-виконавчої служби до категорії посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженням КМ N 339-р ( 339-2004-р ) від 26.05.2004 Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

1. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести до сьомої категорії посад державних службовців посади спеціалістів Державної кримінально-виконавчої служби (установи виконання покарань, слідчі ізолятори, підрозділи кримінально-виконавчої інспекції), які не мають спеціальних звань: { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 339-р ( 339-2004-р ) від 26.05.2004, Постановою КМ N 1074 ( 1074-2006-п ) від 01.08.2006 }

начальника фінансового відділу, головного бухгалтера, заступника начальника фінансового відділу, заступника начальника відділу контролю за виконанням судових рішень, заступника головного бухгалтера, спеціаліста з бухгалтерського обліку, спеціалістів відділу (групи) (оперативного, інтендантського та господарського забезпечення, фінансового, контролю за виконанням судових рішень, по роботі з особовим складом, інформаційного, а також планово-виробничого (тільки для контрагентських установ). ( Абзац другий пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 339-р ( 339-2004-р ) від 26.05.2004 )

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 28 грудня 1994 р. N 953 ( 953-94-р ).
