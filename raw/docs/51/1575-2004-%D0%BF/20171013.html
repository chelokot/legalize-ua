КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 листопада 2004 р. N 1575 Київ

Про упорядкування розміру компенсаційних виплат в іноземній валюті працівникам дипломатичної служби України, направленим у довготермінове відрядження

{ Із змінами, внесеними згідно з Постановами КМ N 8 ( 8-2006-п ) від 11.01.2006 N 73 ( 73-2008-п ) від 22.02.2008 N 744 ( 744-2017-п ) від 04.10.2017 }

{ Дія цієї Постанови не поширюється на період реалізації пілотного проекту на працівників дипломатичної служби, направлених у довготермінове відрядження до закордонних дипломатичних установ України, визначених у пункті 1 Постанови КМ N 882 ( 882-2015-п ) від 07.10.2015, з урахуванням змін, внесених Постановою КМ N 233 ( 233-2017-п ) від 05.04.2017 }

{ Дія цієї Постанови не поширюється на період реалізації пілотного проекту на працівників апарату військових аташе та апарату представника Міністерства оборони при дипломатичному представництві України, направлених у довготермінове відрядження до закордонних дипломатичних установ України, визначених у пункті 1 Постанови КМ N 554 ( 554-2017-п ) від 09.08.2017 }

3. Розмір компенсаційних виплат в іноземній валюті, що здійснюються працівникам дипломатичної служби, направленим у довготермінове відрядження, за час відпустки становить: { Абзац перший пункту 3 в редакції Постанови КМ N 744 ( 744-2017-п ) від 04.10.2017 }

у разі проведення відпустки в Україні - 50 відсотків установлених норм компенсаційних виплат в іноземній валюті на місяць разом з установленими надбавками за відповідною посадою; { Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 744 ( 744-2017-п ) від 04.10.2017 }

у разі проведення відпустки в країні перебування або в третіх країнах - 75 відсотків установлених норм компенсаційних виплат в іноземній валюті на місяць разом з установленими надбавками за відповідною посадою. { Абзац третій пункту 3 із змінами, внесеними згідно з Постановами КМ N 8 ( 8-2006-п ) від 11.01.2006, N 744 ( 744-2017-п ) від 04.10.2017 }

Якщо працівник частину відпустки проводить в Україні, іншу частину - в країні перебування або в третій країні і при цьому йому оплачується проїзд в Україну і в зворотному напрямку, кожна частина відпустки в поточному календарному році оплачується з розрахунку 50 відсотків установлених норм компенсаційних виплат в іноземній валюті на місяць разом з установленими надбавками за відповідною посадою. { Абзац четвертий пункту 3 в редакції Постанови КМ N 744 ( 744-2017-п ) від 04.10.2017 }

Оплата проїзду у зв’язку з проведенням працівником відпустки в Україні (в обох напрямках) здійснюється один раз у поточному календарному році. { Пункт 3 доповнено абзацом згідно з Постановою КМ N 744 ( 744-2017-п ) від 04.10.2017 }

{ Пункт 4 виключено на підставі Постанови КМ N 73 ( 73-2008-п ) від 22.02.2008 }

5. Визнати такими, що втратили чинність, пункти 1, 2 і 5 постанови Кабінету Міністрів України від 4 березня 2004 р. N 261 ( 261-2004-п ) "Про затвердження норм та розміру відшкодування витрат в іноземній валюті на місяць працівникам дипломатичної служби, направленим у довготермінове відрядження" (Офіційний вісник України, 2004 р., N 10, ст. 592).

6. Ця постанова набирає чинності з дня опублікування.
