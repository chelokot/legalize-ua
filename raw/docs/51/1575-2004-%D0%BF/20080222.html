Про упорядкування розміру компенсаційних виплат в іноземній валюті працівникам дипломатичної служби України, направленим у довготермінове відрядження

Стан: Втратив чинність

Ідентифікатор: 1575-2004-п

Текст документа від 22.02.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 листопада 2004 р. N 1575 Київ

Про упорядкування норм та розміру відшкодування витрат в іноземній валюті працівникам дипломатичної служби України, направленим у довгострокове відрядження

{ Із змінами, внесеними згідно з Постановами КМ N 8 ( 8-2006-п ) від 11.01.2006 N 73 ( 73-2008-п ) від 22.02.2008 }

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 8 ( 8-2006-п ) від 11.01.2006 )

( Пункт 2 втратив чинність на підставі Постанови КМ N 8 ( 8-2006-п ) від 11.01.2006 )

3. Розмір відшкодування витрат в іноземній валюті, що виплачується працівникам закордонних дипломатичних установ України, які направлені у довгострокове закордонне відрядження, за час відпустки не може перевищувати:

у разі проведення відпустки в Україні - 50 відсотків установлених норм відшкодування витрат в іноземній валюті на місяць разом з установленими цією постановою надбавками за відповідною посадою;

у разі проведення відпустки в країні перебування або в третіх країнах - 75 відсотків норм відшкодування витрат в іноземній валюті на місяць разом з установленими цією постановою надбавками за відповідною посадою. ( Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 8 ( 8-2006-п ) від 11.01.2006 )

Якщо працівник частину відпустки проводить в Україні, іншу частину - в країні перебування або в третій країні і при цьому йому оплачується проїзд в Україну і в зворотному напрямку, обидві частини відпустки в поточному календарному році оплачуються з розрахунку 50 відсотків установлених норм відшкодування витрат в іноземній валюті на місяць разом з установленими цією постановою надбавками за відповідною посадою.

{ Пункт 4 виключено на підставі Постанови КМ N 73 ( 73-2008-п ) від 22.02.2008 }

5. Визнати такими, що втратили чинність, пункти 1, 2 і 5 постанови Кабінету Міністрів України від 4 березня 2004 р. N 261 ( 261-2004-п ) "Про затвердження норм та розміру відшкодування витрат в іноземній валюті на місяць працівникам дипломатичної служби, направленим у довготермінове відрядження" (Офіційний вісник України, 2004 р., N 10, ст. 592).

6. Ця постанова набирає чинності з дня опублікування.
