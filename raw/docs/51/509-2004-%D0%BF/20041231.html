КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 квітня 2004 р. N 509 Київ

Деякі питання надання субвенції з державного бюджету місцевим бюджетам на виконання інвестиційних проектів у 2004 році

( Із змінами, внесеними згідно з Постановами КМ N 1048 ( 1048-2004-п ) від 10.08.2004 N 1326 ( 1326-2004-п ) від 08.10.2004 N 1620 ( 1620-2004-п ) від 06.12.2004 N 1744 ( 1744-2004-п ) від 24.12.2004 N 1763 ( 1763-2004-п ) від 25.12.2004 N 1781 ( 1781-2004-п ) від 31.12.2004 )

Кабінет Міністрів України постановляє:

1. Затвердити такі, що додаються:

Порядок надання субвенції з державного бюджету ( 1344-15 ) місцевим бюджетам на виконання інвестиційних проектів у 2004 році;

перелік об'єктів, на які спрямовуються кошти субвенції з державного бюджету ( 1344-15 ) місцевим бюджетам на виконання інвестиційних проектів у 2004 році.

2. Державному казначейству інформувати щомісяця до 5 числа наступного періоду Міністерство фінансів і Міністерство економіки та з питань європейської інтеграції про здійснення видатків за об'єктами.

3. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям інформувати щокварталу до 15 числа місяця наступного періоду Міністерство економіки та з питань європейської інтеграції про використання коштів субвенції на виконання інвестиційних проектів за об'єктами.

4. Міністерству економіки та з питань європейської інтеграції подати до 20 лютого 2005 р. Кабінетові Міністрів України та Міністерству фінансів узагальнену інформацію про використання коштів субвенції на виконання інвестиційних проектів.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 19 квітня 2004 р. N 509

ПОРЯДОК надання субвенції з державного бюджету ( 1344-15 ) місцевим бюджетам на виконання інвестиційних проектів у 2004 році

1. Цей Порядок визначає механізм надання субвенції з державного бюджету місцевим бюджетам на виконання інвестиційних проектів (далі - субвенція) - безпосередньо бюджету Автономної Республіки Крим, обласним і районним бюджетам, бюджетам мм. Києва і Севастополя, міст республіканського (Автономної Республіки Крим), обласного та районного значення, селищним та сільським бюджетам (або їх об'єднанням).

2. Субвенція спрямовується на виконання інвестиційних проектів будівництва і реконструкції об'єктів виробничого та невиробничого призначення, виконання робіт з газифікації, водозабезпечення, водовідведення і теплопостачання у населених пунктах, будівництва інженерних захисних споруд, придбання обладнання, здійснення інших заходів, що сприяють розв'язанню соціально-економічних проблем у регіонах за переліком, сформованим на підставі пропозицій народних депутатів України та затвердженим постановою Кабінету Міністрів України від 19 квітня 2004 р. N 509. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1326 ( 1326-2004-п ) від 08.10.2004 )

3. Не дозволяється спрямовувати кошти субвенції на виконання ремонтних робіт.

4. Органи місцевого самоврядування передбачають кошти на співфінансування об'єктів за рахунок доходів, що не враховуються під час визначення обсягу міжбюджетних трансфертів (стаття 69 Бюджетного кодексу ( 2542-14 ), що зараховуються до загального фонду місцевих бюджетів у 2004 році (далі - доходи), але не більш як 20 відсотків обсягу цих коштів:

для селищних і сільських бюджетів (або їх об'єднань), бюджетів міст районного значення - не менш як 0,5 відсотка обсягу доходів, але не більш як 20 відсотків їх обсягу на кожний об'єкт;

для обласних та районних бюджетів, бюджетів міст республіканського (Автономної Республіки Крим) та обласного значення - не менш як 1 відсоток обсягу доходів, але не більш як 20 відсотків їх обсягу на кожний об'єкт;

для бюджетів мм. Києва і Севастополя - не менш як 2 відсотки обсягу доходів, але не більш як 20 відсотків їх обсягу на кожний об'єкт.

Обов'язковою умовою співфінансування є попереднє спрямування коштів місцевих бюджетів за цільовим призначенням (на кожний об'єкт).

5. Для здійснення видатків за рахунок субвенції замовники подають до відповідних органів Державного казначейства за місцем розташування титул будови (об'єкта), внутрішньобудівельний титул будови (об'єкта), титул на виконання проектно-вишукувальних робіт для будівництва, договір підряду (контракту) з визначенням вартості будівництва, наказ або рішення про затвердження проектно-кошторисної документації на чергу будівництва, пусковий комплекс або об'єкт та інші документи згідно з нормативно-правовими актами Державного казначейства щодо касового виконання державного бюджету за видатками.

Фінансові органи райдержадміністрації, виконкомів міських рад (міст республіканського (Автономної Республіки Крим) і обласного значення) надають управлінням Державного казначейства в Автономній Республіці Крим, областях, мм. Києві і Севастополі до 5 числа кожного місяця узагальнену інформацію про спрямування коштів місцевих бюджетів за цільовим призначенням на кожний об'єкт, для якого призначається субвенція. Територіальні органи Державного казначейства надають зазначену інформацію Державному казначейству до 10 числа кожного місяця.

Державне казначейство після отримання інформації спрямовує суми субвенції на виконання інвестиційних проектів з урахуванням пропорційності співфінансування з бюджетів різних рівнів.

6. Міністерство фінансів Автономної Республіки Крим, головні обласні фінансові управління, міські (мм. Києва і Севастополя) фінансові управління після затвердження переліку об'єктів та уточнення відповідних місцевих бюджетів, але не пізніше ніж у тижневий строк надають Міністерству фінансів України узагальнену інформацію про затверджені обсяги співфінансування з відповідних бюджетів та суми субвенції для кожного проекту з їх помісячним розподілом.

Міністерство фінансів України у тижневий строк після отримання інформації на підставі затверджених місцевими бюджетами обсягів коштів для кожного проекту та сум субвенції формує пооб'єктний зведений план асигнувань та передає його Державному казначейству.

Державне казначейство визначає порядок перерахування сум субвенції та забезпечує його дотримання.
