Кабінет Міністрів України; Розпорядження від 22.06.1999 № 595-р

Про запровадження державного регулювання оптових цін на пек електродний вітчизняного виробництва

Стан: Втратив чинність

Ідентифікатор: 595-99-р

Текст документа від 17.01.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 червня 1999 р. N 595-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 26-р ( 26-2000-р ) від 17.01.2000 )

Для запобігання надмірному зростанню цін Мінекономіки за погодженням з Мінпромполітики та Антимонопольним комітетом запровадити державне регулювання оптових цін на пек електродний вітчизняного виробництва шляхом встановлення їх граничного рівня для розрахунків з підприємствами-споживачами.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
