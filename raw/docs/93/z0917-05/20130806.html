Про затвердження Змін до Порядку застосування Плану рахунків бухгалтерського обліку бюджетних установ

Відповідно до Бюджетного кодексу України ( 2542-14 ), Закону України "Про Державний бюджет України на 2005 рік" ( 2285-15 ), Указу Президента України від 27.04.95 N 335 ( 335/95 ) "Про Державне казначейство України" (із змінами) та Положення про Державне казначейство, затвердженого постановою Кабінету Міністрів України від 31.07.95 N 590 ( 590-95-п ) (із змінами), і вимог постанови Кабінету Міністрів України від 28.10.98 N 1706 ( 1706-98-п ) "Про затвердження Програми реформування системи бухгалтерського обліку із застосуванням міжнародних стандартів" НАКАЗУЮ:

1. Затвердити Зміни до Порядку застосування Плану рахунків бухгалтерського обліку бюджетних установ, затвердженого наказом Головного управління Державного казначейства України від 10.12.99 N 114 ( z0890-99 ), зареєстрованого в Міністерстві юстиції України 20.12.99 за N 890/4183 (додаються).

2. Зміни до Порядку застосування Плану рахунків бухгалтерського обліку бюджетних установ ( z0890-99 ) головним розпорядникам бюджетних коштів довести до відома підпорядкованих установ, а органам Державного казначейства України та місцевим фінансовим органам - до установ, що ними обслуговуються.

3. Міністерствам, іншим центральним органам виконавчої влади, бюджетним установам, які отримують кошти державного або місцевих бюджетів, дотримуватись вимог Порядку застосування Плану рахунків бухгалтерського обліку бюджетних установ ( z0890-99 ) з урахуванням унесених змін.

В.о. Голови О.С.Даневич
