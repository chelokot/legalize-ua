ТЕХНІЧНИЙ ОПИС
бланків документів моряків

1. Технічний опис бланків документів, що засвідчують належну кваліфікацію моряків для займання посади на судні

{Назва глави 1 в редакції Наказу Міністерства інфраструктури № 863 від 04.11.2013 }

1.1 До бланків документів, що засвідчують належну кваліфікацію моряків для займання посади на судні, належать професійний диплом, сертифікат компетентності, підтвердження до професійного диплома, виданого іноземною державою, свідоцтво фахівця, свідоцтво фахівця про спеціальну підготовку, свідоцтво про спеціальну підготовку персоналу пасажирських суден, які виготовляються в одному форматі за єдиним дизайном, а також підтвердження цих документів, які виготовляються за іншим єдиним дизайном.

{Пункт 1.1 глави 1 в редакції Наказу Міністерства інфраструктури № 863 від 04.11.2013 , в редакції Наказу Міністерства розвитку громад, територій та інфраструктури № 535 від 23.06.2023 }

1.2. Бланки є надрукованими в п’ять фарб з лицьового та зворотного боків аркушами паперу із закругленими кутами форматом 105 × 148+/- 0,1 мм, які після внесення даних про особу власника документа запресовуються в плівку для ламінування.

{Пункт 1.2 глави 1 в редакції Наказу Міністерства інфраструктури № 863 від 04.11.2013 ; із змінами, внесеними згідно з Наказом Міністерства інфраструктури № 510 від 01.11.2018 }

1.3. Бланки друкуються на папері масою 150 г/м - 2 , який не просвічується в ультрафіолетових променях і має захисні волокна.

{Пункт 1.3 глави 1 в редакції Наказу Міністерства інфраструктури № 863 від 04.11.2013 }

1.4. У дизайні бланків використовуються складна графіка та захисні фарби, що запобігають можливості відтворення бланків засобами оргтехніки та загальної поліграфії.

У кожному з елементів графіки присутні антисканерні елементи:

- псевдорельєфні сітки;

- гільйоширні зображення;

- рисунки та орнаменти, що виконуються технікою "медаль" з використанням ірисного друку;

- мікрошрифти в позитивному і негативному відтворенні;

- вертикальної та горизонтальної будови.

1.5. Для захисту від ксерокопіювання використовується широкий асортимент захисних фарб: фарби, видимі та невидимі в різних діапазонах із різним кольором випромінювання в ультрафіолетовому світлі.

{Пункт 1.5 глави 1 в редакції Наказу Міністерства інфраструктури № 863 від 04.11.2013 }

{Пункт 1.6 глави 1 виключено на підставі Наказу Міністерства інфраструктури № 863 від 04.11.2013 }

1.6. Для захисту кваліфікаційних документів, використовується захисна плівка для ламінування, у яку бланк після внесення даних про особу власника документа запресовується термоламінатором за температури не менше ніж 150 ° С.

{Пункт 1.6 глави 1 в редакції Наказу Міністерства інфраструктури № 510 від 01.11.2018 ; із змінами, внесеними згідно з Наказом Міністерства розвитку громад, територій та інфраструктури № 535 від 23.06.2023 }

1.7. Плівка для ламінування забезпечує:

високі експлуатаційні якості документа (запобігання руйнівній дії перепадів кліматичних умов) і таким чином збереження елементів захисту на весь термін дії бланків;

створення єдиної монолітної структури з полімерної плівки, клею та верхньої частини паперу, що унеможливлює заміну інформації. За спроби відділення плівки від паперу відбувається руйнування документа;

надійність захисту документа завдяки комплексному застосуванню плівки для ламінування, захисних графічних елементів у дизайні бланків, захисних технологій та матеріалів.

{Пункт 1.7 глави 1 в редакції Наказу Міністерства інфраструктури № 510 від 01.11.2018 }

1.8. За конструкцією плівка для ламінування має вигляд однозгинного зошита із закругленими кутами, скріпленого по одній із коротких сторін.

{Пункт 1.8 глави 1 із змінами, внесеними згідно з Наказом Міністерства інфраструктури № 510 від 01.11.2018 }

1.9 Вимоги до плівки для ламінування:

формат - 111 × 154 +/– 1 мм, товщина - 250 мкм;

структура - полімерна основа (PET поліетилентерефталат - 150 мкм, РЕ-поліетилен - 40 мкм), клейовий шар (EVA-етилвінілацетат - 60 мкм);

опір на розтягування - 1091/1366 кг/см - 2 (за нормою ASTM D - 882);

приклеювання - 0,87 ± 0,05 kN/м (за нормою FTM 1).

{Пункт 1.9 глави 1 в редакції Наказів Міністерства інфраструктури № 863 від 04.11.2013 , № 510 від 01.11.2018 }

{Пункт 1.10 глави 1 виключено на підставі Наказу Міністерства інфраструктури № 510 від 01.11.2018 }

{Пункт 1.11 глави 1 виключено на підставі Наказу Міністерства інфраструктури № 178 від 16.05.2017 }

1.10. Строк зберігання плівки до ламінування (при температурі 22 + - 2 ° С та відносній вологості 50 + - 10 % ) повинен бути не менше 12 місяців.

{Пункт 1.10 глави 1 із змінами, внесеними згідно з Наказом Міністерства інфраструктури № 510 від 01.11.2018 }

1.11. Строк служби плівки для ламінування після припресування повинен бути не менше 10 років.

{Пункт 1.11 глави 1 із змінами, внесеними згідно з Наказом Міністерства інфраструктури № 510 від 01.11.2018 }

1.12. Плівки для ламінування впаковуються в коробки по 100 штук.

{Пункт 1.12 глави 1 в редакції Наказу Міністерства інфраструктури № 510 від 01.11.2018 }

2. Технічний опис бланка Послужної книжки моряка

2.1. Бланк Послужної книжки моряка (Seaman's Seagoing Service Record Book) являє собою брошуру форматом 105 × 148 мм +- 1 мм (у складеному вигляді), яка за структурою складається з обкладинки та внутрішнього блока.

2.2. Обкладинка виготовлюється з картону (щільність - 250 г/м), який обклеюється шкірозамінником типу "балакрон". Кольоровість обкладинки - 3 + 0 (на першій сторінці на шкірозамінник наноситься зображення методом тиснення золотою фольгою).

2.3. Внутрішній блок складається із 40 сторінок та друкується на спеціальному папері з водяним знаком, без оптичного відбілювача, щільністю 80-90 г/м, що не просвічується в ультрафіолетових променях. Кольоровість внутрішнього блока 3 + 3.

2.4. Кріплення обкладинки та внутрішнього блока Послужної книжки моряка забезпечується їх прошивкою.

2.5. При виготовленні бланка Послужної книжки моряка повинні бути враховані такі особливості:

- між другою сторінкою обкладинки та першою сторінкою внутрішнього блока вшивається плівка для холодної ламінації розміром 145 × 103 мм, при спробі відділення якої від паперу документ руйнується;

- на першій сторінці внутрішнього блока методом тиснення наноситься спеціальний захисний елемент зі скритим зображенням;

- семизначна наскрізна нумерація червоного кольору наноситься виключно на непарні сторінки в правому нижньому куті.

2.6. У дизайні бланка використовується складна графіка та присутні спеціальні захисні елементи, а саме:

- регулярна та нерегулярна фонові сітки;

- гільйошні зображення, мікротекст, захисний елемент типу "паркет";

- захисний елемент, що виконується методом "псевдорельєф".

Зазначені вище захисні елементи запобігають можливості відтворення бланків засобами оргтехніки та загальної поліграфії.

2.7. Після внесення даних про особу власника документа на першу сторінку внутрішнього блока наноситься плівка для холодної ламінації.
