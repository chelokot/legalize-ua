КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 грудня 1999 р. N 2199 Київ

( Постанова втратила чинність на підставі Постанови КМ N 336 ( 336-2004-п ) від 17.03.2004 )

Про утворення Інституту післядипломної освіти працівників сфери побутового обслуговування населення

З метою удосконалення підготовки і підвищення кваліфікації кадрів для сфери побутового обслуговування населення Кабінет Міністрів України постановляє:

1. Прийняти пропозицію Українського союзу об'єднань, підприємств і організацій побутового обслуговування населення (Укрсоюзсервіс), погоджену з Міністерством фінансів, Міністерством економіки та Міністерством освіти, щодо утворення Інституту післядипломної освіти працівників сфери побутового обслуговування населення на базі Київського технологічного технікуму, що ліквідується, з віднесенням Інституту до сфери управління Укрсоюзсервісу.

2. Утворення Інституту післядипломної освіти працівників сфери побутового обслуговування населення здійснити в межах коштів, що передбачені Укрсоюзсервісу на підготовку кадрів.

3. Укрсоюзсервісу здійснити необхідні організаційні заходи, пов'язані з утворенням Інституту післядипломної освіти працівників сфери побутового обслуговування населення, затвердити його Статут та забезпечити продовження навчання студентів технікуму, що ліквідується, за програмами підготовки молодших спеціалістів.
