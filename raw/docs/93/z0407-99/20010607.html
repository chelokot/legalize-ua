Про затвердження Інструкції про порядок видачі посвідчень

на ввезення товарів для виробництва космічної техніки

суб'єктами космічної діяльності згідно з контрактами,

укладеними суб'єктами космічної діяльності та зареєстрованими відповідно до законодавства

На виконання вимог Указу Президента України "Про державну підтримку космічної діяльності" від 27 жовтня 1998 року N 1191/98 та постанови Кабінету Міністрів України від 27 лютого 1999 року N 276 ( 276-99-п ) "Про заходи щодо державної підтримки космічної діяльності" НАКАЗУЮ:

1. Затвердити Інструкцію про порядок видачі посвідчень на ввезення товарів для виробництва космічної техніки суб'єктами космічної діяльності згідно з контрактами, укладеними суб'єктами космічної діяльності та зареєстрованими відповідно до законодавства (додається).

2. Управлінню космічних комплексів у встановленому порядку подати зазначену в п.1 цього наказу Інструкцію на реєстрацію до Міністерства юстиції України.

Відповідальний - начальник управління Засуха С.О.

3. Наказ довести до начальників управлінь, окремих відділів, керівників підприємств космічної галузі, суб'єктів космічної діяльності в частині, що їх стосується. Організувати опублікування тексту Інструкції в засобах масової інформації.

Відповідальний - начальник управління Бойко Г.С.

4. Контроль виконання цього наказу покласти на першого заступника генерального директора Комарова В.Г.

Генеральний директор О.Негода Затверджено Наказ генерального директора НКАУ 26.05.99 N 67

Інструкція про порядок видачі посвідчень на ввезення товарів для виробництва космічної техніки суб'єктами космічної діяльності згідно з контрактами, укладеними суб'єктами космічної діяльності та зареєстрованими відповідно до законодавства

1. Загальні положення

1.1. Ця Інструкція розроблена відповідно до Указу Президента України "Про державну підтримку космічної діяльності" від 27 жовтня 1998 року N 1191/98 та постанови Кабінету Міністрів України від 27 лютого 1999 року N 276 ( 276-99-п ) "Про заходи щодо державної підтримки космічної діяльності".

1.2. Інструкція є обов'язковою для виконання підприємствами, установами та організаціями незалежно від їх форм власності, що здійснюють виробництво (створення) космічної техніки (надалі суб'єкти космічної діяльності).

2. Порядок видачі посвідчень на ввезення товарів для виробництва космічної техніки суб'єктами космічної діяльності

2.1. Для одержання посвідчення на ввезення товарів для виробництва космічної техніки суб'єкт космічної діяльності подає до НКАУ для реєстрації завірену копію контракту (договору поставки) із зарубіжним постачальником, за яким увозиться товар для виробництва космічної техніки.

2.2. Головний виконавець державного контракту подає до НКАУ перелік товарів, що ввозяться ним на митну територію України для виробництва космічної техніки відповідно до зареєстрованого контракту (договору поставки) із зарубіжним постачальником, який укладено для виконання державного контракту (додаток 1).

2.3. Співвиконавці головного виконавця держконтракту подають до НКАУ узгоджений з головним виконавцем перелік товарів, що ввозяться ним на митну територію України для виробництва космічної техніки відповідно до зареєстрованого контракту (договору поставки) із зарубіжним постачальником, який укладено для виконання державного контракту (додаток 2).

2.4. Суб'єкти космічної діяльності, які виконують контракти, зареєстровані в порядку, визначеному постановою Кабінету Міністрів України від 4 червня 1998 року N 798 ( 798-98-п ) "Про заходи державного регулювання космічної діяльності", щодо виробництва (створення) космічної техніки в інтересах зарубіжних замовників або інших замовників, подають до НКАУ перелік товарів, що ввозяться на митну територію України за контрактом (договором поставки) із зарубіжним постачальником для виробництва космічної техніки (додаток 3).

2.5. Перелік відповідної форми оформлюється суб'єктом космічної діяльності на паперових носіях виключно засобами електронно-обчислювальної техніки, викладається державною мовою та разом з іншими необхідними документами подається до НКАУ. Обов'язково додається електронна копія.

2.6. Якщо згідно з нормами поставок товари для виробництва космічної техніки згруповані в партії та ввозяться на митну територію України за контрактом (договором поставки) для виконання різних контрактів (державних та недержавних), то суб'єкт космічної діяльності представляє до НКАУ переліки товарів, що ввозяться ним на митну територію України для виробництва космічної техніки, зокрема:

- для виконання кожного державного контракту;

- для виконання кожного контракту з іншими замовниками, в тому числі зарубіжними.

2.7. Облік видачі посвідчень на ввезення товарів для виробництва космічної техніки суб'єктами космічної діяльності ведеться в НКАУ.

Посвідчення оформляється у трьох примірниках за затвердженим постановою Кабінету Міністрів України від 27 лютого 1999 року N 276 ( 276-99-п ) зразком, два з них передаються суб'єкту космічної діяльності (один з яких передається ним до відповідного митного органу), а третій залишається в НКАУ.

Кожний аркуш посвідчення підписується уповноваженою особою та завіряється печаткою НКАУ.

2.8. НКАУ має видати посвідчення або відмовити в його видачі не пізніше ніж за 10 днів з дня надходження відповідно оформлених документів.

2.9. У видачі посвідчення може бути відмовлено, якщо:

подано не всі необхідні документи;

суб'єктом космічної діяльності порушено законодавство України.

Рішення про відмову у видачі посвідчення надсилається суб'єкту космічної діяльності протягом 5 робочих днів із зазначенням підстави.

2.10. Суб'єкт космічної діяльності має право оскаржити у порядку, визначеному законодавством, рішення НКАУ про відмову в видачі посвідчення на ввезення товарів для виробництва космічної техніки суб'єктами космічної діяльності.

2.11. Суб'єкт космічної діяльності подає до відповідного митного органу один примірник посвідчення, підписаного уповноваженою особою та завіреного печаткою НКАУ, і завірену копію контракту (договору поставки), згідно з яким ввозяться товари для виробництва космічної техніки.

2.12. Зразки підписів уповноважених осіб та печатки НКАУ направляються до Державної митної служби України.
