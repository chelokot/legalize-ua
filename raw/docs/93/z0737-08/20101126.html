ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ПИТАНЬ РЕГУЛЯТОРНОЇ ПОЛІТИКИ ТА ПІДПРИЄМНИЦТВА СЛУЖБА БЕЗПЕКИ УКРАЇНИ

НАКАЗ

26.06.2008 N 90/485

Зареєстровано в Міністерстві юстиції України 11 серпня 2008 р. за N 737/15428

{ Наказ втратив чинність на підставі Наказу Державного комітету України з питань регуляторної політики та підприємництва N 314/525 ( z1067-10 ) від 12.10.2010 }

Про унесення змін до Ліцензійних умов провадження господарської діяльності з впровадження, ввезення, вивезення голографічних захисних елементів

Відповідно до статей 8, 9 Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ), постанов Кабінету Міністрів України від 26.04.2007 N 667 ( 667-2007-п ) "Про затвердження Положення про Державний комітет України з питань регуляторної політики та підприємництва" і від 14.11.2000 N 1698 ( 1698-2000-п ) "Про затвердження переліку органів ліцензування" НАКАЗУЄМО:

1. Унести до Ліцензійних умов провадження господарської діяльності з впровадження, ввезення, вивезення голографічних захисних елементів, затверджених наказом Державного комітету України з питань регуляторної політики та підприємництва та Служби безпеки України від 08.04.2003 N 42/132 ( z0323-03 ), зареєстрованого в Міністерстві юстиції України 23.04.2003 за N 323/7644, такі зміни:

1) пункт 4.4 доповнити абзацом такого змісту:

"виконання вимог постанови Кабінету Міністрів України від 13.10.2000 N 1555 ( 1555-2000-п ) "Про затвердження положень з питань розповсюдження примірників аудіовізуальних творів, фонограм, відеограм, комп'ютерних програм, баз даних" в частині зберігання контрольних марок (у разі впровадження ГЗЕ на примірники аудіовізуальних творів, фонограм, відеограм, комп'ютерних програм, баз даних)";

2) у пункті 4.5:

в абзаці другому слово "власне" виключити, слова "рекомендацій виробника" замінити словами "технічних умов виробника";

абзац четвертий після слова "місць" доповнити словами та абревіатурою "зберігання, впровадження ГЗЕ,";

абзац п'ятий після слова та абревіатури "впроваджених ГЗЕ" доповнити словами та абревіатурою "порядок зберігання ГЗЕ,";

доповнити зазначений пункт абзацом такого змісту:

"мати спеціальне сховище (сейф, металева шафа) для зберігання ГЗЕ";

3) у пункті 5.4:

абзац шостий після слова "власні" доповнити словами "або орендовані", слова "(оформлені за договором довгострокової оренди)" виключити.

2. Департаменту ліцензування Державного комітету України з питань регуляторної політики та підприємництва (Іванченко О.Б.), Департаменту контррозвідувального захисту економіки держави Служби безпеки України (Рогач О.П.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Центру взаємодії із засобами масової інформації та громадськістю апарату Голови Служби безпеки України (Остапенко М.М.), Департаменту контррозвідувального захисту економіки держави Служби безпеки України (Рогач О.П.) забезпечити публікацію цього наказу у засобах масової інформації.

4. Контроль за виконанням наказу покласти на заступника Голови Державного комітету України з питань регуляторної політики та підприємництва Приступу М.І. і заступника Голови Служби безпеки України Скляра О.В.
