КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 грудня 2002 р. N 1965 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 99 ( 99-2013-п ) від 06.02.2013 }

Про внесення зміни до Типового положення про управління з питань внутрішньої політики обласних, Київської та Севастопольської міських державних адміністрацій

Кабінет Міністрів України постановляє:

В абзаці третьому пункту 3 Типового положення про управління з питань внутрішньої політики обласних, Київської та Севастопольської міських державних адміністрацій, затвердженого постановою Кабінету Міністрів України від 30 жовтня 1998 р. N 1715 ( 1715-98-п ) (Офіційний вісник України, 1998 р., N 44, ст. 1622), слова "та засобами масової інформації" виключити.
