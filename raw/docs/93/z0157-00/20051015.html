N 71 від 28.02.2000 Зареєстровано в Міністерстві м.Київ юстиції України 10 березня 2000 р. vd20000228 vn71 за N 157/4378

{ Наказ втратив чинність на підставі Наказу Державного комітету статистики N 273 ( z1138-05 ) від 19.09.2005 }

Про внесення змін до Порядку визначення обсягів продукції (робіт, послуг) у порівняльних цінах на підприємствах зв'язку

У зв'язку з тим, що Порядок визначення обсягів продукції (робіт, послуг) у порівняльних цінах на підприємствах зв'язку призначений для використання в роботі на певний час, НАКАЗУЮ:

1. У пункті 2 Порядку визначення обсягів продукції (робіт, послуг) у порівняльних цінах на підприємствах зв'язку, затвердженого наказом Міністерства статистики від 20.09.95 N 232 ( z0353-95 ) та зареєстрованого Міністерством юстиції України 5 жовтня 1995 р. за N 353/889, із змінами, затвердженими наказом Державного комітету статистики від 27.12.99 N 421 ( z0042-00 ) та зареєстрованими Міністерством юстиції України 25 січня 2000 р. за N 42/4263, цифри "1998" замінити на слово "попередній".

2. Контроль за виконанням наказу покласти на заступника Голови Комітету Остапчука Ю.М.
