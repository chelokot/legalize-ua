КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 листопада 2003 р. N 1793 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 626 ( 626-2008-п ) від 09.07.2008 }

Про доповнення пункту 3 постанови Кабінету Міністрів України від 5 червня 1995 р. N 392

Кабінет Міністрів України постановляє:

Пункт 3 постанови Кабінету Міністрів України від 5 червня 1995 р. N 392 ( 392-95-п ) "Про розміри грошових зборів за видачу телерадіоорганізаціям ліцензій на право користування каналами мовлення" (ЗП України, 1995 р., N 8, ст. 204) доповнити абзацом такого змісту:

"у 10 разів, якщо телерадіоорганізація ретранслює програми та передачі іноземних телерадіоорганізацій".

Прем'єр-міністр України В.ЯНУКОВИЧ
