КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 червня 1998 р. N 979 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1098 ( 1098-2003-п ) від 17.07.2003 )

Про фінансове забезпечення будівництва енергоблока N 3 Київської ТЕЦ-6

З метою забезпечення фінансування робіт, пов'язаних із закінченням будівництва енергоблока N 3 Київської ТЕЦ-6, Кабінет Міністрів України постановляє:

1. Національній комісії регулювання електроенергетики здійснити заходи щодо спрямування надходжень коштів, одержаних від підвищення тарифів на електричну енергію з 1 січня 1998 р. для споживачів Державної акціонерної енергопостачальної компанії "Київенерго" згідно з постановою Кабінету Міністрів України від 28 листопада 1997 р. N 1323 ( 1323-97-п ) "Про фінансове забезпечення будівництва енергоблоків N 2 Хмельницької та N 4 Рівненської АЕС", на фінансування будівництва енергоблока N 3 Київської ТЕЦ-6.

2. Рекомендувати Київській міській державній адміністрації з метою забезпечення цільового фінансування добудови енергоблока N 3 Київської ТЕЦ-6 переглянути тарифи на теплову енергію, передбачивши збільшення рентабельності теплоенерговиробництва не менш як на 3 відсотки.

3. Міністерству енергетики забезпечити створення Державною акціонерною енергопостачальною компанією "Київенерго" цільового позабюджетного фонду для фінансування робіт, пов'язаних із закінченням будівництва блока N 3 Київської ТЕЦ-6, за рахунок коштів, зазначених у пункті 1, а також коштів, одержаних відповідно до пункту 2 цієї постанови.

Міністерству енергетики у місячний термін розробити і погодити з Міністерством економіки, Міністерством фінансів, Державною податковою адміністрацією у м. Києві, Національною комісією регулювання електроенергетики положення про порядок створення, обліку та використання коштів зазначеного фонду.

4. Міністерству енергетики разом з Київською міською державною адміністрацією забезпечити:

комплектування штату будівельників, монтажників та експлуатаційного персоналу енергоблока N 3 Київської ТЕЦ-6 шляхом працевлаштування вивільнюваних працівників Чорнобильської АЕС;

закупівлю устаткування та комплектуючих, необхідних для завершення будівництва енергоблока N 3 Київської ТЕЦ-6, переважно у вітчизняних виробників.

5. Міністерству енергетики, Міністерству економіки, Міністерству фінансів, Державній податковій адміністрації у м. Києві підготувати пропозиції щодо виключення фактичних витрат на фінансування добудови енергоблока з валового доходу Державної акціонерної енергопостачальної компанії "Київенерго", який підлягає оподаткуванню.

6. Контроль за виконанням цієї постанови покласти на Першого віце-прем'єр-міністра України Голубченка А.К.

Перший віце-прем'єр-міністр України А.ГОЛУБЧЕНКО
