Кабінет Міністрів України; Розпорядження від 13.07.1994 № 521-р

Про віднесення посад начальників обласних центрів по нарахуванню і виплаті пенсій до 5 категорії державних службовців

Стан: Втратив чинність

Ідентифікатор: 521-94-р

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 липня 1994 р. N 521-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 503-р ( 503-2006-р ) від 04.10.2006 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади начальників обласних та Київського міського центрів по нарахуванню та здійсненню соціальних виплат і їх заступників до 5 категорії державних службовців. { Абзац перший із змінами, внесеними згідно з Розпорядженням КМ N 503-р ( 503-2006-р ) від 04.10.2006 }

Посади інших працівників центрів по нарахуванню та здійсненню соціальних виплат відносяться до відповідних категорій державних службовців місцевих органів державної виконавчої влади. { Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 503-р ( 503-2006-р ) від 04.10.2006 }

Прем'єр-міністр України В.МАСОЛ
