Реєстрація: Мін'юст України від 16.07.1999 № 471/3764

Стан: Втратив чинність

Ідентифікатор: z0471-99

Текст документа від 18.10.2010:

ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

N 116 від 18.06.99 Зареєстровано в Міністерстві м.Київ юстиції України 16 липня 1999 р. vd990618 vn116 за N 471/3764

{ Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку

N 1450 ( z0879-10 ) від 14.09.2010 }

Про затвердження Порядку узяття на облік та зняття з обліку відособлених підрозділів реєстратора (відділень, філій або представництв) для здійснення ними діяльності щодо ведення реєстрів власників іменних цінних паперів

{ Із змінами, внесеними згідно з Рішенням Держкомісціннихпаперів N 60 ( z0318-01 ) від 14.03.2001 }

З метою удосконалення державного контролю за діяльністю з ведення реєстрів власників іменних цінних паперів реєстраторами при використанні ними відособлених підрозділів та відповідно до абзацу першого статті третьої Закону України "Про державне регулювання ринку цінних паперів в Україні" ( 448/96-ВР ) Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити Порядок узяття на облік та зняття з обліку відособлених підрозділів реєстратора (відділень, філій або представництв) для здійснення ними діяльності щодо ведення реєстрів власників іменних цінних паперів (далі - Порядок) (додається).

2. Управлінню нагляду за інфраструктурою ринку цінних паперів - забезпечити реєстрацію Порядку в Міністерстві юстиції України.

3. Рішення набуває чинності відповідно до чинного законодавства України.

4. Скасувати наказ Державної комісії з цінних паперів та фондового ринку від 22.01.97 N 14 ( v0014312-97 ) "Про затвердження інструктивного листа щодо взяття на облік Державною комісією з цінних паперів та фондового ринку підпорядкованих підрозділів реєстратора для здійснення ними діяльності щодо ведення реєстрів власників іменних цінних паперів".

5. Керівнику прес-центру Шевкіній Л.В. - забезпечити опублікування цього рішення, відповідно до чинного законодавства.

6. Реєстраторам, які до набрання чинності цим Порядком перевели реєстраторську діяльність щодо окремих емітентів від відособлених підрозділів до себе, привести свою діяльність у відповідність до вимог п.4.2 Порядку. Термін приведення у відповідність та повідомлення територіальних управлінь - один місяць від дати набрання чинності цим Порядком.

7. Реєстраторам, які на момент набрання чинності цим Порядком мають у своєму складі відособлені підрозділи, діяльність щодо ведення реєстрів яких припинена, у термін не пізніше двох місяців від дати набуття чинності цим Порядком, зняти такі відособлені підрозділи з обліку в Комісії у встановленому Порядку.

8. Контроль за виконанням цього рішення покласти на Члена Комісії А.Т.Головка.

Голова Комісії О.Мозговий
