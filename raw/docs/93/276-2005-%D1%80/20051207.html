РОЗПОРЯДЖЕННЯ від 21 липня 2005 р. N 276-р Київ

Про встановлення строку виконання операцій з переробки та ремонту авіаційних двигунів, газотурбінних приводів та електростанцій, редукторів та їх складових частин на митній території України

( Із змінами, внесеними згідно з Розпорядженням КМ N 507-р ( 507-2005-р ) від 07.12.2005 )
