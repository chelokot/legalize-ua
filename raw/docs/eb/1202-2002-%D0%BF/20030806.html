Деякі питання Сорочинського ярмарку

Стан: Втратив чинність

Ідентифікатор: 1202-2002-п

Текст документа від 06.08.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 19 серпня 2002 р. N 1202 Київ

Деякі питання Сорочинського ярмарку

( Із змінами, внесеними згідно з Постановою КМ N 1214 ( 1214-2003-п ) від 06.08.2003 )

Кабінет Міністрів України постановляє:

1. Затвердити Віце-прем'єр-міністра України Кириленка Івана Григоровича головою Координаційного комітету з підготовки та проведення щорічного Сорочинського ярмарку, звільнивши від цих обов'язків Гладія Михайла Васильовича ( 741-99-п ).

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1214 ( 1214-2003-п ) від 06.08.2003 )

2. Внести до постанови Кабінету Міністрів України від 30 квітня 1999 р. N 741 ( 741-99-п ) "Про Сорочинський ярмарок" зміни, що додаються.

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 13 листопада 1999 р. N 2082 ( 2082-99-п ) "Про розширення складу Координаційного комітету з підготовки та проведення щорічного Сорочинського ярмарку".

Прем'єр-міністр України А.КІНАХ

Інд. 22

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 19 серпня 2002 р. N 1202

1. У пункті 2:

абзац перший визнати таким, що втратив чинність, у частині кількісного складу Координаційного комітету з підготовки та проведення щорічного Сорочинського ярмарку;

абзац другий викласти у такій редакції:

"Встановити, що до складу цього Комітету входять посадові особи згідно з додатком".
