Про визнання такими, що втратили чинність, постанов Кабінету Міністрів України з питань ввезення транспортних засобів на територію України

Стан: Чинний

Ідентифікатор: 760-2008-п

Текст документа від 27.08.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 серпня 2008 р. N 760 Київ

Про визнання такими, що втратили чинність, постанов Кабінету Міністрів України з питань ввезення транспортних засобів на територію України

Кабінет Міністрів України постановляє:

1. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України з питань ввезення транспортних засобів на територію України згідно з переліком, що додається.

2. Ця постанова набирає чинності з дня опублікування.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 27 серпня 2008 р. N 760

ПЕРЕЛІК постанов Кабінету Міністрів України з питань ввезення транспортних засобів на територію України, що втратили чинність

1. Постанова Кабінету Міністрів України від 31 травня 1994 р. N 341 ( 341-94-п ) "Про затвердження Правил ввезення транспортних засобів на територію України" (ЗП України, 1994 р., N 9, ст. 227).

2. Постанова Кабінету Міністрів України від 8 лютого 1995 р. N 94 ( 94-95-п ) "Про внесення змін і доповнень до Правил ввезення транспортних засобів на територію України" (ЗП України, 1995 р., N 4, ст. 109).

3. Постанова Кабінету Міністрів України від 28 листопада 1995 р. N 949 ( 949-95-п ) "Про внесення змін і доповнень до Правил ввезення транспортних засобів на територію України" (ЗП України, 1996 р., N 3, ст. 107).

4. Постанова Кабінету Міністрів України від 16 лютого 1998 р. N 146 ( 146-98-п ) "Про внесення змін та доповнень до деяких постанов Кабінету Міністрів України" (Офіційний вісник України, 1998 р., N 7, ст. 246).

5. Постанова Кабінету Міністрів України від 6 липня 1998 р. N 1014 ( 1014-98-п ) "Про внесення доповнення до Правил ввезення транспортних засобів на територію України" (Офіційний вісник України, 1998 р., N 27, ст. 996).

6. Пункт 1 постанови Кабінету Міністрів України від 29 березня 2000 р. N 575 ( 575-2000-п ) "Про приведення рішень Кабінету Міністрів України у відповідність з Угодою про партнерство та співробітництво між Україною та Європейськими Співтовариствами (Європейським Союзом)" (Офіційний вісник України, 2000 р., N 13, ст. 524).

7. Постанова Кабінету Міністрів України від 8 вересня 2004 р. N 1191 ( 1191-2004-п ) "Про внесення змін до Правил ввезення транспортних засобів на територію України" (Офіційний вісник України, 2004 р., N 36, ст. 2412).
