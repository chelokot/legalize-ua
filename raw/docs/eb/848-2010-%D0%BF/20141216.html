ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 15 вересня 2010 р. N 848

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України

{ Пункт 1 втратив чинність на підставі Постанови КМ N 700 ( 700-2014-п ) від 10.12.2014 }

2. У додатку до постанови Кабінету Міністрів України від 15 жовтня 2004 р. N 1365 ( 1365-2004-п ) "Деякі питання адаптації законодавства України до законодавства Європейського Союзу" (Офіційний вісник України, 2004 р., N 42, ст. 2763; 2005 р., N 9, ст. 475; 2009 р., N 20, ст. 641) позиції "Міністр економіки та з питань європейської інтеграції", "Голова Держнаглядохоронпраці", "Директор Координаційного бюро європейської та євроатлантичної інтеграції" замінити такими позиціями: "Міністр економіки", "Голова Держгірпромнагляду", "Директор Бюро європейської інтеграції".
