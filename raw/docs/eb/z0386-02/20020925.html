НАКАЗ

N 244 від 22.04.2002 Зареєстровано в Міністерстві м. Київ юстиції України 24 квітня 2002 р. за N 386/6674

( Наказ втратив чинність на підставі Наказу Державного комітету стандартизації, метрології та сертифікації N 498 ( z0782-02 ) від 30.08.2002 )

Про внесення доповнень до Переліку продукції, що підлягає обов'язковій сертифікації в Україні, і до Термінів уведення обов'язкової сертифікації окремих видів продукції в Україні

Відповідно до статті 14 Декрету Кабінету Міністрів України від 10.05.93 N 46-93 ( 46-93 ) "Про стандартизацію і сертифікацію" та на виконання доручення Кабінету Міністрів України від 27.03.02 N 3697/50 НАКАЗУЮ:

1. Доповнити Перелік продукції, що підлягає обов'язковій сертифікації в Україні, затверджений наказом Держстандарту України від 30.06.93 N 95 ( z0112-93 ) і зареєстрований в Міністерстві юстиції України 19.08.93 за N 112 (у редакції наказу Держстандарту України від 27.11.96 N 499 ( za728-96 ), зареєстрованого в Міністерстві юстиції України 19.12.96 за N 728/1753), зі змінами та доповненнями, унесеними наказами Держстандарту України від 17.05.97 N 268 ( z0209-97 ), від 04.07.97 N 388 ( z0304-97 ), від 11.09.97 N 549 ( z0461-97 ), від 20.01.98 N 27 ( z0072-98 ), від 27.01.99 N 37 ( z0234-99 ), від 05.05.99 N 205 ( z0299-99 ), від 14.06.99 N 322 ( z0404-99 ), від 14.06.99 N 323 ( z0416-99 ), від 25.10.99 N 287 ( z0784-99 ), від 10.12.99 N 389 ( z0897-99 ), від 29.12.99 N 418 ( z0013-00 ), від 27.03.2000 N 241 ( z0223-00 ), від 21.07.2000 N 448 ( z0454-00 ), від 24.07.2000 N 449 ( z0483-00 ), від 24.01.2001 N 29 ( z0118-01 ), від 25.01.2002 N 49 ( z0127-02 ) та зареєстрованими в Міністерстві юстиції України відповідно 05.06.97 за N 209/2013, 13.08.97 за N 304/2108, 09.10.97 за N 461/2265, 04.02.98 за N 72/2512, 15.04.99 за N 234/3527, 11.05.99 за N 299/3592, 22.06.99 за N 404/3697, 24.06.99 за N 416/3709, 15.11.99 за N 784/4077, 22.12.99 за N 897/4190, 13.01.2000 за N 13/4234, 11.04.2000 за N 223/4444, від 28.07.2000 за N 454/4675, 08.08.2000 за N 483/4704, 07.02.2001 за N 118/5309, 11.02.2002 за N 127/6415, розділом такого змісту: "40. Товари з паперу шкільні та канцелярські" (додається).

2. Доповнити Терміни уведення обов'язкової сертифікації окремих видів продукції в Україні, затверджені наказом Держстандарту України від 30.06.93 N 95 ( z0112-93, z0729-96 ), із змінами та доповненнями, унесеними та затвердженими наказом Держстандарту України від 27.11.96 N 499 ( z0728-96 ), із змінами та доповненнями, унесеними наказами Держстандарту України від 27.11.96 N 499, від 04.07.97 N 388 ( z0304-97 ), від 11.09.97 N 549 ( z0461-97 ), від 20.01.98 N 27 ( z0072-98 ), від 27.01.99 N 37 ( z0234-99 ), від 05.05.99 N 205 ( z0299-99 ), від 14.06.99 N 322 ( z0404-99 ), від 25.10.99 N 287 ( z0784-99 ), від 10.12.99 N 389 ( z0897-99 ), від 29.12.99 N 418 ( z0013-00 ) та зареєстрованими в Міністерстві юстиції України відповідно 19.12.96 за N 729/1754, 13.08.97 за N 304/2108, 09.10.97 за N 461/2265, 04.02.98 за N 72/2512, 15.04.99 за N 234/3527, 11.05.99 за N 299/3592, 22.06.99 за N 404/3697, 15.11.99 за N 784/4077, 22.12.99 за N 897/4190, 13.01.2000 за N 13/4234, 28.07.2000 за N 454/4675, 08.08.2000 за N 483/4704, рядком "40.Товари з паперу шкільні та канцелярські ...15.06.2002".

3. Управлінню державного нагляду та підтвердження відповідності (Баб'як О.М.) у п'ятиденний термін забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Українському науково-дослідному інституту стандартизації, сертифікації та інформатики (Камінський В.Ю.) після державної реєстрації цього наказу в Міністерстві юстиції України забезпечити його публікацію в інформаційному покажчику "Стандарти".

5. Контроль за виконанням цього наказу залишаю за собою.
