Про затвердження наглядових рад національних закладів (установ) культури України

{ Із змінами, внесеними згідно з Постановами КМ N 1723 ( 1723-98-п ) від 02.11.98 N 64 ( 64-2004-п ) від 21.01.2004 N 782 ( 782-2006-п ) від 31.05.2006 N 986 ( 986-2007-п ) від 01.08.2007 N 419 ( 419-2008-п ) від 23.04.2008 }

Відповідно до Указу Президента України від 16 червня 1995 р. N 451 ( 451/95 ) "Про Положення про національний заклад (установу) України" Кабінет Міністрів України постановляє:

Затвердити склад наглядових рад закладів (установ) культури, яким надано статус національних (додаються).

{ На часткову зміну Постанови затвердити склад наглядових рад національних історико-культурних заповідників згідно з Постановою КМ N 986 ( 986-2007-п ) від 01.08.2007 }
