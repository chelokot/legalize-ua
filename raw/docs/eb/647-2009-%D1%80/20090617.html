Кабінет Міністрів України; Розпорядження від 17.06.2009 № 647-р

Питання попереднього залучення сировини для виготовлення неопромінених паливних елементів для атомних електростанцій

Стан: Чинний

Ідентифікатор: 647-2009-р

Текст документа від 17.06.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 червня 2009 р. N 647-р Київ

Питання попереднього залучення сировини для виготовлення неопромінених паливних елементів для атомних електростанцій

Погодитися з пропозицією Мінпаливенерго щодо попереднього залучення державним підприємством "Національна атомна енергогенеруюча компанія "Енергоатом" для виготовлення неопромінених паливних елементів сировини (уранового оксидного концентрату), що належить іноземному суб'єкту господарської діяльності, який здійснює операції з давальницькою сировиною, з подальшою її компенсацією сировиною (урановим оксидним концентратом) за кодом згідно з УКТЗЕД 2844 10 90 00 ( 2371б-14 ), що належить зазначеному підприємству, до моменту постачання продуктів переробки сировини - неопромінених паливних елементів (твелів) за кодом згідно з УКТЗЕД 8401 30 00 00 ( 2371г-14 ) для атомних електростанцій.

Прем'єр-міністр України Ю.ТИМОШЕНКО
