Про ліцензування підприємницької діяльності із зберігання природного газу, постачання природного газу, транспортування природного газу, нафти і нафтопродуктів магістральними трубопроводами та транспортування природного і нафтового газу розподільними трубопроводами

Реєстрація: Мін'юст України від 23.12.1999 № 909/4202

Стан: Втратив чинність

Ідентифікатор: z0909-99

Текст документа від 06.04.2000:

НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

N 1517 від 20.12.99 Зареєстровано в Міністерстві м.Київ юстиції України 23 грудня 1999 р. vd991220 vn1517 за N 909/4202

Про ліцензування підприємницької діяльності із зберігання природного газу, постачання природного газу, транспортування природного газу, нафти і нафтопродуктів магістральними трубопроводами та транспортування природного і нафтового газу розподільними трубопроводами

( Із змінами, внесеними згідно з Постановою Нацкомелектроенергетики N 279 ( z0214-00 ) від 20.03.2000 )

Згідно з Указом Президента України від 21 квітня 1998 року N 335/98 "Питання Національної комісії регулювання електроенергетики України" та з Указом Президента України від 17 листопада 1998 року N 1257/98 "Про запровадження ліцензування діяльності господарюючих суб'єктів у сфері природних монополій" Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Установити, що підприємницька діяльність із постачання природного газу за нерегульованим тарифом з 1 лютого 2000 року без ліцензії забороняється.

2. Установити, що підприємницька діяльність з постачання природного газу за регульованим тарифом та з транспортування природного і нафтового газу розподільними трубопроводами з 1 травня 2000 року без ліцензії забороняється. ( Пункт 2 в редакції Постанови Нацкомелектроенергетики N 279 ( z0214-00 ) від 20.03.2000 )

3. Установити, що підприємницька діяльність із зберігання природного газу, транспортування природного газу, нафти і нафтопродуктів магістральними трубопроводами з 1 липня 2000 року без ліцензії забороняється. ( Пункт 3 в редакції Постанови Нацкомелектроенергетики N 279 ( z0214-00 ) від 20.03.2000 )
