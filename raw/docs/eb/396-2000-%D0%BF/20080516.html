КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 лютого 2000 р. N 396 Київ

{ Постанова втрачає чинність на підставі Постанови КМ N 93 ( 93-2003-п ) від 18.01.2003 з дати набрання чинності частиною тринадцятою статті 71 Митного кодексу України ( 92-15 ), яка набирає чинності з моменту набуття Україною членства у Світовій організації торгівлі }

Про призупинення дії постанови Кабінету Міністрів України від 18 вересня 1998 р. N 1460

Кабінет Міністрів України постановляє:

1. Призупинити до 1 травня 2000 р. дію постанови Кабінету Міністрів України від 18 вересня 1998 р. N 1460 ( 1460-98-п ) "Про внесення доповнення до постанови Кабінету Міністрів України від 27 січня 1997 р. N 65" (Офіційний вісник України, 1998 р., N 38, ст. 1392).

2. Ця постанова набирає чинності з дня її опублікування.
