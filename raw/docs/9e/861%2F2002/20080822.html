Про додаткові заходи щодо вдосконалення діяльності Державної комісії з цінних паперів та фондового ринку

Стан: Втратив чинність

Ідентифікатор: 861/2002

Текст документа від 22.08.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про додаткові заходи щодо вдосконалення діяльності Державної комісії з цінних паперів та фондового ринку

{ Із змінами, внесеними згідно з Указами Президента N 1488/2004 ( 1488/2004 ) від 15.12.2004 N 687/2008 ( 687/2008 ) від 05.08.2008 }

З метою дальшого вдосконалення державного регулювання ринку цінних паперів, визначення ефективного механізму реалізації Державною комісією з цінних паперів та фондового ринку своїх повноважень та у зв'язку з покладенням Законами України "Про інститути спільного інвестування (пайові та корпоративні інвестиційні фонди)" ( 2299-14 ), "Про обіг векселів в Україні" ( 2374-14 ) і "Про фінансові послуги та державне регулювання ринків фінансових послуг" ( 2664-14 ) на зазначену Комісію додаткових функцій постановляю:

{ Статтю 1 виключено на підставі Указу Президента N 1488/2004 ( 1488/2004 ) від 15.12.2004 }

{ Стаття 2 втратила чинність на підставі Указу Президента N 687/2008 ( 687/2008 ) від 05.08.2008 }

{ Стаття 3 втратила чинність на підставі Указу Президента N 687/2008 ( 687/2008 ) від 05.08.2008 }
