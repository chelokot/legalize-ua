Про затвердження проекту та титулу будови ліній електропередачі для видачі потужностей Рівненської та Хмельницької атомних електростанцій

Текст документа від 18.02.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 лютого 2006 р. N 45-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 222-р ( 222-2009-р ) від 18.02.2009 }

Про затвердження проекту та титулу будови ліній електропередачі для видачі потужностей Рівненської та Хмельницької атомних електростанцій

1. Затвердити поданий Мінпаливенерго проект будови "Лінії електропередачі 750 кВ для видачі потужностей Рівненської та Хмельницької атомних електростанцій: підстанція 750 кВ "Київська" із заходами, повітряна лінія 750-330 кВ (Макарівський район Київської області)", розроблений Державним проектно-вишукувальним і науково-дослідним інститутом "Укренергомережпроект" (м. Харків) та рекомендований до затвердження Центральною службою Укрінвестекспертизи Мінбуду, з такими основними техніко-економічними показниками:

трансформаторна потужність 750/330 кВ - 1 млн. кВА

протяжність двох ліній заходів 750 кВ - 1 і 0,6 кілометра

протяжність двох ліній заходів 330 кВ - по 55 кілометрів

загальна кошторисна вартість - 739395,490 тис. гривень

у тому числі:

будівельно-монтажних робіт - 216086,075 тис. гривень

устатковання та інвентарю - 273262,453 тис. гривень

пусконалагоджувальних робіт - 13916,397 тис. гривень

тривалість будівництва - 24 місяці

2. Затвердити титул будови "Лінії електропередачі, 750 кВ для видачі потужностей Рівненської та Хмельницької атомних електростанцій: підстанція 750 кВ "Київська" із заходами, повітряна лінія 750-330 кВ (Макарівський район Київської області)", що додається.
