Кабінет Міністрів України; Постанова від 20.07.2011 № 758

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань встановлення роздрібних цін на природний газ для потреб населення

Стан: Чинний

Ідентифікатор: 758-2011-п

Текст документа від 20.07.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 липня 2011 р. N 758 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань встановлення роздрібних цін на природний газ для потреб населення

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність:

пункт 1 постанови Кабінету Міністрів України від 8 грудня 2006 р. N 1697 ( 1697-2006-п ) "Про заходи щодо подальшого вдосконалення механізму забезпечення природним газом вітчизняних споживачів" (Офіційний вісник України, 2006 р., N 50, ст. 3321);

постанову Кабінету Міністрів України від 5 вересня 2007 р. N 1094 ( 1094-2007-п ) "Про внесення змін до Тимчасового порядку установлення роздрібних цін на природний газ для потреб населення" (Офіційний вісник України, 2007 р., N 67, ст. 2580);

пункт 4 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 28 січня 2009 р. N 36 ( 36-2009-п ) "Про внесення змін до деяких постанов Кабінету Міністрів України" (Офіційний вісник України, 2009 р., N 8, ст. 242).

Прем'єр-міністр України М.АЗАРОВ
