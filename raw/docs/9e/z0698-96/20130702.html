N 320 від 04.11.96 Зареєстровано в Міністерстві м.Київ юстиції України 4 грудня 1996 р. за N 698/1723

{ Наказ втратив чинність на підставі Наказу Міністерства оборони N 316 ( z0877-13 ) від 15.05.2013 }

Про затвердження Переліку додаткових видів грошового

забезпечення та інших виплат, що не підлягають облікові при відрахуванні аліментів з військовослужбовців

{ Із змінами, внесеними згідно з Наказами Міноборони N 109 ( z0329-01 ) від 02.04.2001 N 157 ( z0381-06 ) від 24.03.2006 }

Відповідно до постанови Кабінету Міністрів України від 26.02.93 N 146 ( 146-93-п ) "Про види заробітку (доходу), що підлягають облікові при відрахуванні аліментів", НАКАЗУЮ:

1. Затвердити Перелік додаткових видів грошового забезпечення та інших виплат, що не підлягають облікові при відрахуванні аліментів з військовослужбовців, що додається.

2. Командувачам видів Збройних Сил України, командувачам військ оперативних командувань, керівникам структурних підрозділів центрального апарату Міністерства оборони України та Генерального штабу Збройних Сил України, командирам військових частин, начальникам військових навчальних закладів, установ, організацій Збройних Сил України та підприємств, що входять до сфери управління Міністерства оборони України, забезпечити відрахування аліментів з військовослужбовців і вчасне перерахування (видачу) відрахованих сум одержувачам аліментів. { Абзац перший пункту 2 в редакції Наказу Міністерства оборони N 157 ( z0381-06 ) від 24.03.2006 }

Утримання аліментів з військовослужбовців, відповідно до названої постанови Кабінету Міністрів України, провадити з окладів грошового утримання, додаткових видів грошового забезпечення та інших виплат, за винятком зазначених у Переліку.

Утримання аліментів з військовослужбовців, які перебувають за кордоном, провадити з подвійного грошового забезпечення, одержуваного в Україні у національній валюті.

3. Наказ Міністра оборони України від 26.05.93 N 112 скасувати.

4. Наказ Міністра оборони СРСР від 05.08.83 N 195 вважати таким, що не застосовується в Збройних Силах України.

5. Контроль за виконанням цього наказу покласти на начальника Головного фінансово-економічного управління Міністерства оборони України.

6. Наказ розіслати до окремої військової частини.

Міністр оборони України генерал-лейтенант О.Кузьмук

Затверджено наказом Міністра оборони України від 04.11.96 N 320

Перелік додаткових видів грошового забезпечення та інших виплат, що не підлягають облікові при відрахуванні аліментів з військовослужбовців

1. Грошова допомога при звільненні з військової служби.

2. Одноразова допомога на початкове обзаведення прапорщикам, мічманам та військовослужбовцям рядового, сержантського та старшинського складу, які проходять військову службу за контрактом. { Пункт 2 із змінами, внесеними згідно з Наказом Міністерства оборони N 157 ( z0381-06 ) від 24.03.2006 }

3. Винагорода за закінчення вищих військових навчальних закладів. ( Пункт 3 в редакції Наказу Міноборони N 109 ( z0329-01 ) від 02.04.2001 )

4. Матеріальна допомога.

5. Грошова компенсація за піднайом (найом) житлового приміщення. { Пункт 5 із змінами, внесеними згідно з Наказом Міністерства оборони N 157 ( z0381-06 ) від 24.03.2006 }

6. Грошова компенсація замість норм харчування та речового майна. { Пункт 6 із змінами, внесеними згідно з Наказом Міністерства оборони N 157 ( z0381-06 ) від 24.03.2006 }

7. Компенсаційні виплати при відрядженнях, у тому числі польове забезпечення. ( Пункт 7 в редакції Наказу Міноборони N 109 ( z0329-01 ) від 02.04.2001 )

{ Пункт 8 виключено на підставі Наказу Міністерства оборони N 157 ( z0381-06 ) від 24.03.2006 }

9. Грошові суми, які виплачуються з фонду нагород та фонду допомог.

10. Премії, присуджені за створення видатних військово-теоретичних і військово-історичних праць та творів художньої літератури про Збройні Сили України.

11. Винагорода, що виплачується за винахід і раціоналізаторську пропозицію.

{ Пункт 12 виключено на підставі Наказу Міністерства оборони N 157 ( z0381-06 ) від 24.03.2006 }

13. Допомога в проведенні поховання і компенсація матеріальних витрат на ритуальні послуги та спорудження надгорбків.

14. Грошова допомога на оздоровлення. ( Перелік доповнено пунктом 14 згідно з Наказом Міноборони N 109 ( z0329-01 ) від 02.04.2001 )

15. Винагорода за тривалу безперервну військову службу. ( Перелік доповнено пунктом 15 згідно з Наказом Міноборони N 109 ( z0329-01 ) від 02.04.2001 )

16. Підйомна допомога та добові при переміщеннях. ( Перелік доповнено пунктом 16 згідно з Наказом Міноборони N 109 ( z0329-01 ) від 02.04.2001 )

17. Допомога у зв'язку з вагітністю та пологами. { Перелік доповнено пунктом 17 згідно з Наказом Міноборони N 109 ( z0329-01 ) від 02.04.2001; із змінами, внесеними згідно з Наказом Міністерства оборони N 157 ( z0381-06 ) від 24.03.2006 }
