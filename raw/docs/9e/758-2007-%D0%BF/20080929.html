Стан: Втратив чинність

Ідентифікатор: 758-2007-п

Текст документа від 29.09.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 травня 2007 р. N 758 Київ

Деякі питання Секретаріату Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановами КМ N 635 ( 635-2008-п ) від 16.07.2008 N 829 ( 829-2008-п ) від 17.09.2008 }

Відповідно до частини п'ятої статті 50 Закону України "Про Кабінет Міністрів України" ( 514-16 ) Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 635 ( 635-2008-п ) від 16.07.2008 }

Установити, що директори департаментів, заступники директорів департаментів та начальники управлінь, директор Координаційного бюро європейської та євроатлантичної інтеграції, його заступники, начальники управлінь у складі зазначених департаментів та Бюро Секретаріату Кабінету Міністрів України призначаються на посаду та звільняються з посади Кабінетом Міністрів України за поданням Міністра Кабінету Міністрів України.

{ Постанова із змінами, внесеними згідно з Постановою КМ N 829 ( 829-2008-п ) від 17.09.2008 }

Прем'єр-міністр України В.ЯНУКОВИЧ
