УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до додатка N 1 до Указу Президента України від 21 березня 2002 року N 277

1. Внести зміни до додатка N 1 до Указу Президента України від 21 березня 2002 року N 277 ( 277/2002 ) "Про переліки посад військовослужбовців і працівників правоохоронних органів, що підлягають заміщенню особами вищого офіцерського (начальницького) складу, та граничних військових і спеціальних звань за цими посадами" (в редакції Указу від 19 квітня 2006 року N 312 ( 312/2006 ), зі змінами, внесеними Указами від 16 червня 2006 року N 530 ( 530/2006 ), від 21 травня 2007 року N 436 ( 436/2007 ), від 25 жовтня 2007 року N 1020 ( 1020/2007 ), від 7 листопада 2007 року N 1069 ( 1069/2007 ), від 1 жовтня 2008 року N 881 ( 881/2008 ) та від 7 серпня 2009 року N 603) ( 603/2009 ), виклавши його в новій редакції (додається).

2. Цей Указ набирає чинності з дня його опублікування.
