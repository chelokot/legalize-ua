Верховна Рада України; Постанова від 07.09.2010 № 2495-VI

Про інформацію Кабінету Міністрів України про стан виконання Постанови Верховної Ради України "Про всенародне обговорення проекту Податкового кодексу України" та визнання такими, що втратили чинність, деяких рішень Верховної Ради України щодо проекту Податкового кодексу України

Стан: Чинний

Ідентифікатор: 2495-17

Текст документа від 07.09.2010:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про інформацію Кабінету Міністрів України про стан виконання Постанови Верховної Ради України "Про всенародне обговорення проекту Податкового кодексу України" та визнання такими, що втратили чинність, деяких рішень Верховної Ради України щодо проекту Податкового кодексу України

( Відомості Верховної Ради України (ВВР), 2010, N 44-45, ст.530 )

Заслухавши інформацію Кабінету Міністрів України про стан виконання Постанови Верховної Ради України від 8 липня 2010 року N 2454-VI ( 2454-17 ) "Про всенародне обговорення проекту Податкового кодексу України", Верховна Рада України постановляє:

1. Інформацію Кабінету Міністрів України про стан виконання Постанови Верховної Ради України від 8 липня 2010 року N 2454-VI ( 2454-17 ) "Про всенародне обговорення проекту Податкового кодексу України" взяти до відома.

2. Відповідно до частини другої статті 48 Регламенту Верховної Ради України ( 1861-17 ) визнати такими, що втратили чинність, Постанову Верховної Ради України від 17 червня 2010 року N 2353-VI ( 2353-17 ) "Про прийняття за основу проекту Податкового кодексу України", а також пункт 4 Постанови Верховної Ради України від 8 липня 2010 року N 2454-VI ( 2454-17 ) "Про всенародне обговорення проекту Податкового кодексу України" та зняти з розгляду проект Податкового кодексу України (реєстр. N 6509).

3. Кабінету Міністрів України невідкладно подати до Верховної Ради України новий проект Податкового кодексу України з урахуванням результатів всенародного обговорення.

4. Ця Постанова набирає чинності з дня її прийняття.
