Стан: Втратив чинність

Текст документа від 20.08.2002:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 729/2002 ( 729/2002 ) від 20.08.2002 )

Про внесення змін до Указу Президента України від 29 грудня 1999 року N 1625

З метою підвищення ефективності діяльності Адміністрації Президента України постановляю:

1. Реорганізувати:

Головне управління з питань діяльності військових формувань та правоохоронних органів в Головне управління з питань судової реформи, діяльності військових формувань та правоохоронних органів;

Управління інформації та зв'язків з громадськістю в Головне управління інформаційної політики.

У зв'язку з цим внести такі зміни до Указу Президента України від 29 грудня 1999 року N 1625 ( 1625/99 ) "Питання Адміністрації Президента України" (зі змінами, внесеними Указами від 23 лютого 2000 року N 278 ( 278/2000 ), від 9 березня 2000 року N 397 ( 397/2000 ), від 25 грудня 2000 року N 1370 ( 1370/2000 ), від 1 лютого 2001 року N 67 ( 67/2001 ), від 25 квітня 2001 року N 281 ( 281/2001 ), від 19 червня 2001 року N 453 ( 453/2001 ), від 21 липня 2001 року N 538 ( 538/2001 ), від 25 жовтня 2001 року N 1017 ( 1017/2001 ), від 3 червня 2002 року N 505 ( 505/2002 ), від 12 червня 2002 року N 540 ( 540/2002 ):

а) абзац "Головне управління з питань діяльності військових формувань та правоохоронних органів" викласти в такій редакції:

"Головне управління з питань судової реформи, діяльності військових формувань та правоохоронних органів";

б) абзац "Управління інформації та зв'язків з громадськістю" викласти в такій редакції:

"Головне управління інформаційної політики".

2. Внести відповідні зміни до додатка, зазначеного у статті 2 Указу Президента України від 29 грудня 1999 року N 1625 ( 1625/99 ).

Президент України Л.КУЧМА
