Питання Міжвідомчої комісії з питань демонополізації економіки

Стан: Втратив чинність

Текст документа від 13.11.2001:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Питання Міжвідомчої комісії з питань демонополізації економіки

( Із змінами, внесеними згідно з Указом Президента N 355/99 від 03.04.99 )

У зв'язку із змінами, що відбулися у структурі та складі Кабінету Міністрів України, постановляю:

1. Внести зміну до Положення про Міжвідомчу комісію з питань демонополізації економіки, затвердженого Указом Президента України від 21 березня 1995 року N 247 ( 247/95 ) (в редакції Указу Президента України від 11 грудня 1997 року N 1353 ( 1353/97 ), виклавши абзац перший пункту 8 у такій редакції:

"8. До складу Комісії входять за посадами керівники або заступники керівників Міністерства економіки України, Міністерства зовнішніх економічних зв'язків і торгівлі України, Міністерства фінансів України, Міністерства юстиції України, Державного комітету статистики України, Фонду державного майна України, члени Антимонопольного комітету України, Державної комісії з цінних паперів та фондового ринку, а також представники Адміністрації Президента України, Відділу з питань власності, підприємництва та конкурентної політики Кабінету Міністрів України".

2. Затвердити новий персональний склад Міжвідомчої комісії з питань демонополізації економіки (додається).

3. Визнати такими, що втратили чинність:

Розпорядження Президента України від 30 листопада 1996 року N 615 ( 615/96-рп ) "Про склад Міжвідомчої комісії з питань демонополізації економіки";

Розпорядження Президента України від 4 лютого 1997 року N 63 ( 63/97-рп ) "Про зміни у складі Міжвідомчої комісії з питань демонополізації економіки";

Розпорядження Президента України від 6 травня 1997 року N 194 ( 194/97-рп ) "Про зміни у складі Міжвідомчої комісії з питань демонополізації економіки";

Розпорядження Президента України від 11 липня 1997 року N 254 ( 254/97-рп ) "Про зміни у складі Міжвідомчої комісії з питань демонополізації економіки";

Розпорядження Президента України від 16 вересня 1997 року N 324 ( 324/97-рп ) "Про зміни у складі Міжвідомчої комісії з питань демонополізації економіки";

Указ Президента України від 11 грудня 1997 року N 1353 ( 1353/97 ) "Питання Міжвідомчої комісії з питань демонополізації економіки".
