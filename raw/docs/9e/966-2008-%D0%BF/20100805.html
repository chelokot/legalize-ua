Кабінет Міністрів України; Постанова від 05.11.2008 № 966

Про закупівлю державними банками та банками, у капіталізації яких взяла участь держава, послуг, безпосередньо пов'язаних з банківськими операціями

Стан: Втратив чинність

Ідентифікатор: 966-2008-п

Текст документа від 05.08.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 листопада 2008 р. N 966 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 666 ( 666-2010-п ) від 28.07.2010 }

Про закупівлю державними банками та банками, у капіталізації яких взяла участь держава, послуг, безпосередньо пов'язаних з банківськими операціями

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 864 ( 864-2009-п ) від 05.08.2009 }

{ Із змінами, внесеними згідно з Постановою КМ N 864 ( 864-2009-п ) від 05.08.2009 }

Кабінет Міністрів України постановляє:

1. Відповідно до пункту 6 Положення про закупівлю товарів, робіт і послуг за державні кошти, затвердженого постановою Кабінету Міністрів України від 17 жовтня 2008 р. N 921 ( 921-2008-п ) (Офіційний вісник України, 2008 р., N 80, ст. 2692), установити, що закупівля державними банками та банками, у капіталізації яких взяла участь держава, послуг, безпосередньо пов'язаних із здійсненням ними банківських операцій згідно із Законом України "Про банки і банківську діяльність" ( 2121-14 ), проводиться без застосування процедур, визначених зазначеним Положенням.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 864 ( 864-2009-п ) від 05.08.2009 }

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 14 травня 2008 р. N 445 ( 445-2008-п ) "Про закупівлю державними банками послуг" (Офіційний вісник України, 2008 р., N 35, ст. 1170).
