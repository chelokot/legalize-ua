N 43 від 18.10.95 Зареєстровано в Міністерстві м.Київ юстиції України 2 листопада 1995 р. vd951018 vn43 за N 397/933

Про внесення змін і доповнень до наказу Міністерства праці України від 07.10.93 N 78 "Про умови оплати праці працівників соціальних служб для молоді"

( Із змінами, внесеними згідно з Наказом Мінпраці N 18 ( z0092-96 ) від 15.02.96 )

Відповідно до доручення Кабінету Міністрів України від 21.09.95 N 17251/30 за погодженням з Міністерством фінансів України та Міністерством України у справах молоді і спорту, НАКАЗУЮ:

1. Внести такі зміни і доповнення до наказу Міністерства праці України від 07.10.93 N 78 ( z0160-93 ) "Про умови оплати праці працівників соціальних служб для молоді":

1.1. Додаток N 3 доповнити посадою "провідний спеціаліст" після посади "головний спеціаліст":

1.2. Додаток N 4 викласти у новій редакції, що додається.

1.3. В абзаці шостому підпункту "б" пункту 2 слова "до 0,5 мінімального розміру заробітної плати" замінити на слова "до 10 відсотків посадового окладу".

1.4. Абзац перший підпункту "г" пункту 2 викласти у такій редакції:

"г) надавати працівникам матеріальну допомогу, спрямовуючи на цю мету кошти у розмірі середньомісячного заробітку".

1.5. У пункті 3 слова "0,5 і 1,0 мінімальної заробітної плати" замінити на слова "15 і 20 відсотків посадового окладу".

1.6. ( Підпункт 1.6 втратив чинність на підставі Наказу Мінпраці N 18 ( z0092-96 ) від 15.02.96 ) У пункті 4 крапку в кінці речення замінити комою і доповнити словами "викладеному в редакції постанови Кабінету Міністрів України від 8 лютого 1995 року N 102 ( 102-95-п ) та у порядку, передбаченому постановою Кабінету Міністрів України від 13 червня 1995 року N 409 ( 409-95-п ) "Про підвищення заробітної плати на державних підприємствах, в установах і організаціях" і постановах Кабінету Міністрів України від 2 жовтня 1995 року N 778 ( 778-95-п ) "Про підвищення з 1 жовтня 1995 року заробітної плати працівників бюджетних установ і організацій".

2. Цей наказ набуває чинності через 10 днів після державної реєстрації.

Міністр М.Г.Каскевич
