Текст документа від 05.07.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 лютого 2001 р. N 50-р Київ

Про утворення міжвідомчої робочої групи з координації та контролю за ходом підготовки і реалізації проектів розвитку житлово-комунального господарства населених пунктів

{ Із змінами, внесеними згідно з Розпорядженням КМ N 551-р ( 551-2002-р ) від 26.09.2002 Постановою КМ N 147 ( 147-2006-п ) від 15.02.2006 Розпорядженнями КМ N 8-р ( 8-2007-р ) від 16.01.2007 N 865-р ( 865-2007-р ) від 10.10.2007 Постановою КМ N 451 ( 451-2013-п ) від 26.06.2013 }

1. З метою забезпечення координації та контролю за ходом підготовки і реалізації проектів розвитку житлово-комунального господарства населених пунктів, які підтримуються Міжнародним банком реконструкції та розвитку та Європейським банком реконструкції та розвитку, утворити міжвідомчу робочу групу у складі згідно з додатком.

{ На часткову зміну абзацу першого пункту 1 затвердити склад міжвідомчої робочої групи з питань підготовки і реалізації проектів розвитку житлово-комунального господарства населених пунктів з числа заступника Міністра будівництва, архітектури та житлово-комунального господарства (голова робочої групи), керівних працівників Мінекономіки, Мінбуду, Мінфіну, Мінприроди, НАЕР та працівників Секретаріату Кабінету Міністрів України згідно з Розпорядженням КМ N 8-р ( 8-2007-р ) від 16.01.2007 }

Голові міжвідомчої робочої групи затвердити її персональний склад. { Абзац другий пункту 1 в редакції Розпорядження КМ N 8-р ( 8-2007-р ) від 16.01.2007 }

2. Покласти відповідальність за підготовку та реалізацію проектів розвитку житлово-комунального господарства населених пунктів на Міністерство регіонального розвитку, будівництва та житлово-комунального господарства.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженнями КМ N 551-р ( 551-2002-р ) від 26.09.2002, N 8-р ( 8-2007-р ) від 16.01.2007, N 865-р ( 865-2007-р ) від 10.10.2007, Постановою КМ N 451 ( 451-2013-п ) від 26.06.2013 }

3. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 4 лютого 1998 р. N 61 ( 61-98-р ) та від 7 травня 1998 р. N 299 ( 299-98-р ).
