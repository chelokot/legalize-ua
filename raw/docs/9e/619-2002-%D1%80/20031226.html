РОЗПОРЯДЖЕННЯ від 28 жовтня 2002 р. N 619-р Київ

Про затвердження плану заходів щодо відновлення виробничої діяльності та стабілізації фінансово-економічного становища ВАТ "Макіївський металургійний комбінат"

( Із змінами, внесеними згідно з Постановою КМ N 2051 ( 2051-2003-п ) від 26.12.2003 )

1. Затвердити план заходів щодо відновлення виробничої діяльності та стабілізації фінансово-економічного становища ВАТ "Макіївський металургійний комбінат" (додається).

2. Погодитися з пропозицією НАК "Нафтогаз України" про участь Компанії в установленому порядку в санації ВАТ "Макіївський металургійний комбінат" та здійснення Компанією інвестицій у виробничу діяльність цього Товариства.

( Розпорядження доповнено пунктом 2 згідно з Постановою КМ N 2051 ( 2051-2003-п ) від 26.12.2003 )

3. Державній податковій адміністрації вжити заходів до виведення з податкової застави частини активів інвестора на суму, що не перевищує розмір інвестицій, необхідних для відновлення платоспроможності ВАТ "Макіївський металургійний комбінат.

( Розпорядження доповнено пунктом 3 згідно з Постановою КМ N 2051 ( 2051-2003-п ) від 26.12.2003 )

4. Контроль за виконанням розпорядження покласти на Міністра промислової політики М'ялицю А.К.

( Пункт 4 із змінами, внесеними згідно з Постановою КМ N 2051 ( 2051-2003-п ) від 26.12.2003 )
