Президент України; Розпорядження від 09.08.1999 № 188/99-рп

Про внесення змін до Розпорядження Президента України від 13 травня 1997 року N 199

Стан: Втратив чинність

Ідентифікатор: 188/99-рп

Текст документа від 26.08.1999:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Розпорядження Президента України від 13 травня 1997 року N 199

( Із змінами, внесеними згідно з Розпорядженням Президента N 203/99-рп від 26.08.99 )

Відповідно до статті 139 Конституції України ( 254к/96-ВР ) та статті 9 Закону України "Про Представництво Президента України в Республіці Крим" ( 2875-12 ):

Ввести до штатного розпису апарату Представництва Президента України в Автономній Республіці Крим, затвердженого Розпорядженням Президента України від 13 травня 1997 року N 199 ( 199/97-рп ) (із змінами, внесеними Розпорядженнями від 27 листопада 1997 року N 419 ( 419/97-рп ), від 17 березня 1998 року N 61, від 27 березня 1998 року N 68 ( 68/98-рп ), від 23 червня 1998 року N 335 ( 335/98-рп ) та від 17 листопада 1998 року N 550 ( 550/98-рп ), додаткову посаду заступника Постійного Представника Президента України в Автономній Республіці Крим. ( Абзац другий із змінами, внесеними згідно з Розпорядженням Президента N 203/99-рп від 26.08.99 )

Президент України Л.КУЧМА

м. Київ, 9 серпня 1999 року N 188/99-рп
