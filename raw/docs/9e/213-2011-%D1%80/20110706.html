Кабінет Міністрів України; Розпорядження від 17.03.2011 № 213-р

Про виділення коштів для надання гуманітарної допомоги Японії та здійснення невідкладної евакуації громадян України з її території

Стан: Чинний

Ідентифікатор: 213-2011-р

Текст документа від 06.07.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 березня 2011 р. N 213-р Київ

Про виділення коштів для надання гуманітарної допомоги Японії та здійснення невідкладної евакуації громадян України з її території

{ Із змінами, внесеними згідно з Розпорядження КМ N 644-р ( 644-2011-р ) від 06.07.2011 }

На виконання Указу Президента України від 11 березня 2011 р. N 284 ( 284/2011 ) "Про надання гуманітарної допомоги Японії":

1. Виділити Міністерству надзвичайних ситуацій 19893834 гривень для надання гуманітарної допомоги Японії та здійснення невідкладної евакуації громадян України з її території (далі - евакуація), у тому числі для відшкодування витрат, пов'язаних із наданням гуманітарної допомоги та здійсненням евакуації.

Міністерству фінансів здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 2857-17 ).

2. Міністерству надзвичайних ситуацій:

невідкладно здійснити надання гуманітарної допомоги та забезпечити здійснення евакуації;

узгодити з Міністерством фінансів та Міністерством економічного розвитку і торгівлі перелік витрат, пов'язаних з наданням гуманітарної допомоги та здійсненням евакуації;

узгодити з Міністерством економічного розвитку і торгівлі розміри витрат, пов'язаних з наданням гуманітарної допомоги та здійсненням евакуації, які підлягають відшкодуванню, та забезпечити їх відшкодування.

2-1. Дозволити Міністерству надзвичайних ситуацій передбачати у договорах про закупівлю товарів і послуг, пов'язаних із наданням гуманітарної допомоги Японії, попередню оплату в розмірі 100 відсотків їх вартості на строк не більш як один місяць.

{ Розпорядження доповнено пунктом 2-1 згідно з Розпорядженням КМ N 644-р ( 644-2011-р ) від 06.07.2011 }

3. Міністерству закордонних справ і Міністерству надзвичайних ситуацій узгодити з відповідними органами Японії питання доставки і передачі вантажу гуманітарної допомоги та здійснення евакуації.

4. Державній митній службі забезпечити оперативне митне оформлення вантажу гуманітарної допомоги, а Адміністрації Державної прикордонної служби - першочергове здійснення контролю під час його перевезення через державний кордон.

5. Міністерству надзвичайних ситуацій подати до 1 серпня 2011 р. Міністерству економічного розвитку і торгівлі, Міністерству фінансів і Державній казначейській службі звіт про використання коштів, виділених згідно з цим розпорядженням.

{ Пункт 5 із змінами, внесеними згідно з Розпорядженням КМ N 644-р ( 644-2011-р ) від 06.07.2011 }
