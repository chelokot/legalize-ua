КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 квітня 2007 р. N 674 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 800 ( 800-2010-п ) від 02.09.2010 }

Про затвердження складу спостережної ради Державної акціонерної компанії "Хліб України"

Кабінет Міністрів України постановляє:

1. На зміну пункту 3 постанови Кабінету Міністрів України від 14 березня 2001 р. N 240 ( 240-2001-п ) "Про затвердження Статуту Державної акціонерної компанії "Хліб України" (Офіційний вісник України, 2001 р., N 12, ст. 489) затвердити склад спостережної ради Державної акціонерної компанії "Хліб України", що додається.

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 23 квітня 2003 р. N 570 ( 570-2003-п ) "Про затвердження нового складу спостережної ради Державної акціонерної компанії "Хліб України" (Офіційний вісник України, 2003 р., N 17, ст. 764);

постанову Кабінету Міністрів України від 4 лютого 2004 р. N 115 ( 115-2004-п ) "Про склад спостережної ради Державної акціонерної компанії "Хліб України" (Офіційний вісник України, 2004 р., N 5, ст. 236);

постанову Кабінету Міністрів України від 25 січня 2006 р. N 49 ( 49-2006-п ) "Про затвердження складу спостережної ради Державної акціонерної компанії "Хліб України" (Офіційний вісник України, 2006 р., N 4, ст. 163).
