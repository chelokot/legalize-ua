{ Розпорядження втратило чинність на підставі Розпорядження КМ N 345-р ( 345-2006-р ) від 20.06.2006 }

Про затвердження розмірів лісосічного фонду та площі хвойних насаджень (сосни) для заготівлі живиці на 2006 рік

Затвердити розміри лісосічного фонду та площі хвойних насаджень (сосни) для заготівлі живиці на 2006 рік згідно з додатками 1 і 2.

Облдержадміністраціям розподілити в установленому порядку лісосічний фонд та площі хвойних насаджень (сосни) для заготівлі живиці між лісокористувачами.
