КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 липня 2010 р. N 661 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 315 ( 315-2012-п ) від 28.03.2012 }

Про внесення змін до постанови Кабінету Міністрів України від 22 лютого 2006 р. N 175

Відповідно до Указу Президента України від 6 січня 2010 р. N 8 ( 8/2010 ) "Про надання Українській академії аграрних наук статусу національної" Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 22 лютого 2006 р. N 175 ( 175-2006-п ) "Про затвердження нової редакції Статуту Української академії аграрних наук" (Офіційний вісник України, 2006 р., N 8, ст. 434) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 22

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 липня 2010 р. N 661

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 22 лютого 2006 р. N 175 ( 175-2006-п )

1. У назві та постановляючій частині постанови ( 175-2006-п ) слова "Української академії аграрних наук" замінити словами "Національної академії аграрних наук України".

2. У Статуті Української академії аграрних наук ( 175-2006-п ), затвердженому зазначеною постановою:

у назві Статуту ( 175-2006-п ) слова "Української академії аграрних наук" замінити словами "Національної академії аграрних наук України";

в абзаці першому пункту 1 слова "Українська академія аграрних наук" замінити словами "Національна академія аграрних наук України";

в абзаці першому пункту 44 слова "Української академії аграрних наук" замінити словами "Національної академії аграрних наук України";

пункт 2 викласти в такій редакції:

"2. Академії надано статус національної згідно з Указом Президента України від 6 січня 2010 р. N 8 ( 8/2010 ) "Про надання Українській академії аграрних наук статусу національної".

Академія є правонаступницею Української академії аграрних наук, яка заснована згідно з постановою Ради Міністрів УРСР від 22 вересня 1990 р. N 279 ( 279-90-п ) (ЗП УРСР, 1990 р., N 10, ст. 59) на базі Південного відділення ВАСГНІЛу.

Місцезнаходження Академії: Україна, 01010, м. Київ-10, вул. Суворова, 9.

Повне найменування: українською мовою - Національна академія аграрних наук України, англійською мовою - National academy of agrarian sciences of Ukraine.

Скорочене найменування: - НААН.".
