{ Розпорядження втратило чинність на підставі Розпорядження КМ N 109-р ( 109-2015-р ) від 18.02.2015 }

Про підписання Угоди між Кабінетом Міністрів України та Урядом Румунії стосовно співробітництва у сфері військових перевезень

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Румунії стосовно співробітництва у сфері військових перевезень.

Уповноважити Міністра оборони Єжеля Михайла Броніславовича підписати зазначену Угоду.
