Кабінет Міністрів України; Розпорядження від 29.11.2001 № 536-р

Про передачу Мінагрополітики повноважень з управління державним пакетом акцій ВАТ "Агропромсистема"

Стан: Втратив чинність

Ідентифікатор: 536-2001-р

Текст документа від 07.03.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 листопада 2001 р. N 536-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 301 ( 301-2003-п ) від 07.03.2003 )

Про передачу Мінагрополітики повноважень з управління державним пакетом акцій ВАТ "Агропромсистема"

1. Прийняти пропозицію Мінагрополітики, погоджену з Фондом державного майна та Київською міськдержадміністрацією, про передачу Мінагрополітики повноважень з управління державним пакетом акцій ВАТ "Агропромсистема" у розмірі 25 відсотків статутного фонду плюс одна акція.

2. Виключити з додатка 42 до постанови Кабінету Міністрів України від 3 червня 1999 р. N 951 ( 951-99-п ) "Про передачу повноважень з управління державними корпоративними правами Раді міністрів Автономної Республіки Крим, міністерствам, іншим центральним і місцевим органам виконавчої влади" (Офіційний вісник України, 1999 р., N 23, ст. 1053) таку позицію:

"915122 ВАТ "Агропромсистема".

Прем'єр-міністр України А.КІНАХ
