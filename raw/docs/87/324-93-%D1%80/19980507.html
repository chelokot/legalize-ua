КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 травня 1993 р. N 324-р Київ

Про прирівнення за умовами оплати праці керівних працівників Міністерства економіки і Міністерства фінансів

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1190-р ( 1190-93-р ) від 31.12.93 Постановою КМ N 1003 ( 1003-96-п ) від 02.09.96 }

{ Дію Розпорядження поширено в частині матеріально-побутового забезпечення, медичного і транспортного обслуговування на відповідних працівників центрального апарату Міністерства зовнішніх економічних зв'язків і торгівлі згідно з Постановою КМ N 613 ( 613-98-п ) від 07.05.98 }

( Абзац перший втратив чинність на підставі Постанови КМ N 1003 ( 1003-96-п ) від 02.09.96 )

( Абзац другий втратив чинність у частині прирівнення за умовами оплати праці керівних працівників Міністерства економіки і Міністерства фінансів на підставі Постанови КМ N 1003 ( 1003-96-п ) від 02.09.96 ) Прирівняти за умовами оплати праці, матеріально-побутового забезпечення, медичного і транспортного обслуговування перших заступників Міністра економіки і Міністра фінансів до міністрів України.

( Абзац третій втратив чинність у частині прирівнення за умовами оплати праці керівних працівників Міністерства економіки і Міністерства фінансів на підставі Постанови КМ N 1003 ( 1003-96-п ) від 02.09.96 ) Прирівняти за умовами оплати праці та медичного обслуговування заступників Міністра економіки і Міністра фінансів до перших заступників Міністра, начальників самостійних відділів (управлінь) цих міністерств - до заступників Міністра, заступників начальників самостійних відділів (управлінь) - до начальників самостійних відділів (управлінь), начальників відділів у складі управлінь, підвідділів у складі самостійних відділів - до заступників начальників самостійних відділів (управлінь).

Прирівняти за умовами медичного обслуговування помічників Міністра економіки і Міністра фінансів та помічників їх заступників, відповідального секретаря колегії, завідуючого секретаріатом Міністра до заступників начальників самостійних відділів (управлінь). ( Поширено чинність абзацу четвертого на експертів-радників при Міністрі економіки та економічного радника Міністра фінансів згідно з Розпорядженням КМ N 1190-р ( 1190-93-р ) від 31.12.93 )
