{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Про віднесення посади консультанта Президента України до третьої категорії посад державних службовців

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посаду консультанта Президента України до третьої категорії посад державних службовців.
