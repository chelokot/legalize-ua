Про мінімальні закупівельні ціни на окремі об'єкти державного цінового регулювання

( Щодо змін додатково див. Наказ Міністерства аграрної політики N 427 ( v0427555-05 ) від 25.08.2005 )

На виконання вимог Закону України "Про державну підтримку сільського господарства України" ( 1877-15 ) та постанови Кабінету Міністрів України від 26.05.2005 N 399 ( 399-2005-п ) "Про затвердження Методики встановлення мінімальної закупівельної ціни на окремі об'єкти державного цінового регулювання і переліку таких об'єктів на 2005/06 маркетинговий рік" НАКАЗУЮ:

1. Затвердити мінімальні закупівельні ціни на окремі об'єкти державного цінового регулювання на 2005/06 маркетинговий рік згідно з додатком.

2. Контроль за виконанням наказу покласти на першого заступника Міністра Демчака І.М.

Міністр О.П.Баранівський
