Про затвердження Порядку формування і використання активів Державної інноваційної фінансово-кредитної установи

Стан: Втратив чинність

Текст документа від 18.08.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 червня 2009 р. N 685 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 868 ( 868-2011-п ) від 03.08.2011 }

Про затвердження Порядку формування і використання активів Державної інноваційної фінансово-кредитної установи

{ Із змінами, внесеними згідно з Постановами КМ N 345 ( 345-2010-п ) від 31.03.2010 N 99 ( 99-2011-п ) від 07.02.2011 }

Кабінет Міністрів України постановляє:

Затвердити Порядок формування і використання активів Державної інноваційної фінансово-кредитної установи, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 42

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 17 червня 2009 р. N 685

ПОРЯДОК формування і використання активів Державної інноваційної фінансово-кредитної установи

{ У тексті Порядку слово "Мінекономіки" замінено словами "Міністерство економічного розвитку і торгівлі" у відповідному відмінку згідно з Постановою КМ N 99 ( 99-2011-п ) від 07.02.2011 }

1. Цей Порядок визначає механізми формування і використання активів Державної інноваційної фінансово-кредитної установи (далі - Установа).

2. Обсяг формування і використання активів визначається річним фінансовим планом, що затверджується в установленому порядку Державним агентством з інвестицій та управління національними проектами за погодженням з Міністерством економічного розвитку і торгівлі.

{ Пункт 2 із змінами, внесеними згідно з Постановами КМ N 345 ( 345-2010-п ) від 31.03.2010, N 99 ( 99-2011-п ) від 07.02.2011 }

3. Активи Установи формуються за рахунок:

коштів Державного бюджету України, що передбачаються для підтримки інноваційних та інвестиційних проектів, за напрямами і обсягом, що визначені законом про Державний бюджет України на відповідний рік, зокрема коштів, розпорядниками яких є міністерства, інші центральні органи виконавчої влади, що передаються Установі на договірних умовах;

коштів бюджету Автономної Республіки Крим, обласних і районних бюджетів, що передаються Установі на договірних умовах;

інвестицій;

добровільних внесків юридичних та фізичних осіб;

коштів та активів, отримуваних від власної чи спільної фінансово-господарської діяльності;

коштів, що надходять від повернення дебіторської заборгованості за інноваційними позиками, наданими у 1992-2000 роках Державним інноваційним фондом та його регіональними відділеннями;

інших джерел, не заборонених законодавством.

4. Порядок і умови надходження коштів до Установи з бюджету Автономної Республіки Крим, обласних і районних бюджетів визначаються Верховною Радою Автономної Республіки Крим та органами місцевого самоврядування у встановленому ними порядку.

5. Активи використовуються за напрямами, встановленими Статутом Установи.

6. Відбір інноваційних та інвестиційних проектів, що підлягають фінансуванню за рахунок коштів Установи, проводиться на конкурсних засадах.

Для проведення конкурсного відбору утворюється комітет, до складу якого входять представники міністерств, інших центральних органів виконавчої влади, наукових, експертних та громадських організацій (за їх згодою).

Порядок конкурсного відбору інноваційних та інвестиційних проектів, положення про конкурсний комітет та його склад затверджуються Міністерством економічного розвитку і торгівлі. { Абзац третій пункту 6 в редакції Постанови КМ N 99 ( 99-2011-п ) від 07.02.2011 }

Установа подає щокварталу до 15 числа місяця, що настає за звітним періодом, Мінфіну та Міністерству економічного розвитку і торгівлі звіт про відібрані інноваційні та інвестиційні проекти, умови їх фінансування та стан виконання за формою, затвердженою Мінфіном за погодженням з Міністерством економічного розвитку і торгівлі.

Міністерство економічного розвитку і торгівлі веде облік відібраних інвестиційних та інноваційних проектів та подає раз на півріччя Кабінетові Міністрів України узагальнену інформацію про стан виконання умов їх фінансування.

Умови фінансування інноваційних та інвестиційних проектів визначаються у порядку формування і використання коштів Установи, затвердженому Міністерством економічного розвитку і торгівлі.

{ Абзац шостий пункту 6 в редакції Постанови КМ N 99 ( 99-2011-п ) від 07.02.2011 } { Пункт 6 в редакції Постанови КМ N 345 ( 345-2010-п ) від 31.03.2010 }

7. Для покриття непередбачених витрат і відшкодування можливих збитків від проваджуваної діяльності утворюється резервний (страховий) фонд відповідно до Статуту Установи.

Розміщення коштів резервного (страхового) фонду та управління ним Установа здійснює з урахуванням умов безпечності, прибутковості, ліквідності та диверсифікованості.
