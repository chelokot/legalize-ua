Про затвердження Норм оплати праці офіційних опонентів

З метою впорядкування оплати праці офіційних опонентів та відповідно до постанов Кабінету Міністрів України від 28 червня 1997 року N 644 ( 644-97-п ) "Про затвердження Порядку присудження наукових ступенів і присвоєння вчених звань", від 07.02.2001 N 134 ( 134-2001-п ) (із змінами), від 19.05.2003 N 740 ( 740-2003-п ) НАКАЗУЄМО:

1. Затвердити Норми оплати праці офіційних опонентів за підготовку відзивів про дисертації та участь у захисті докторських і кандидатських дисертацій (додаються).

2. Уважати таким, що втратив чинність, наказ Вищої атестаційної комісії України і Міністерства праці та соціальної політики України від 27.06.2002 N 297/301 ( z0562-02 ) "Про норми оплати праці офіційних опонентів", зареєстрований у Міністерстві юстиції України 05.07.2002 за N 562/6850.

Голова Вищої атестаційної комісії України В.Мачулін

1. Ставки погодинної оплати праці офіційного опонента за участь у захисті дисертації (у гривнях):
