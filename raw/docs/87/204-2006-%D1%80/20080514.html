Кабінет Міністрів України; Розпорядження від 12.04.2006 № 204-р

Деякі питання щодо завершення будівництва першої черги Дністровської ГАЕС

Стан: Чинний

Ідентифікатор: 204-2006-р

Текст документа від 14.05.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 квітня 2006 р. N 204-р Київ

Деякі питання щодо завершення будівництва першої черги Дністровської ГАЕС

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 439-р ( 439-2006-р ) від 01.08.2006 N 410-р ( 410-2007-р ) від 13.06.2007 N 704-р ( 704-2008-р ) від 14.05.2008 }

З метою прискорення завершення будівництва першої черги Дністровської ГАЕС:

1. Рекомендувати НКРЕ здійснити в установленому порядку перегляд тарифу на електричну енергію, що реалізується ВАТ "Укргідроенерго", з урахуванням інвестиційної складової у розмірі 2 копійки за 1 кВт.год для забезпечення своєчасного повернення кредитних ресурсів, залучених ВАТ "Укргідроенерго" та спрямованих на фінансування завершення будівництва першої черги Дністровської ГАЕС у складі трьох гідроагрегатів згідно із затвердженим графіком, і погашення заборгованості з оплати поставлених для завершення будівництва першої черги зазначеної станції обладнання і комплектувальних виробів, виконаних робіт (наданих послуг) відповідно до договорів, укладених ВАТ "Укргідроенерго" до 1 травня 2007 р., та інвестиційної складової у розмірі 2,12 копійки за 1 кВт.год для фінансування зазначеного будівництва на період до введення в експлуатацію першого гідроагрегату.

{ Пункт 1 в редакції Розпоряджень КМ N 410-р ( 410-2007-р ) від 13.06.2007, N 704-р ( 704-2008-р ) від 14.05.2008 }

2. Взяти до відома, що ВАТ "Укргідроенерго": { Абзац перший пункту 2 із змінами, внесеними згідно з Розпорядженнями КМ N 410-р ( 410-2007-р ) від 13.06.2007, N 704-р ( 704-2008-р ) від 14.05.2008 }

відкриває відповідно до законодавства рахунок в установі визначеного на конкурсних засадах банку для акумулювання коштів, отриманих як інвестиційна складова тарифу на електричну енергію, що рекомендована до встановлення згідно з пунктом 1 цього розпорядження;

забезпечує цільове використання коштів для виконання робіт, закупівлі обладнання, комплектувальних виробів і послуг, необхідних для завершення будівництва та введення в експлуатацію першої черги Дністровської ГАЕС у складі трьох гідроагрегатів;

завершує у 2010 році будівництво об'єктів виробничого призначення Дністровської ГАЕС та об'єктів соціальної інфраструктури у м. Новодністровську згідно із затвердженим проектом;

забезпечує разом з Чернівецькою облдержадміністрацією цільове та ефективне використання коштів, що виділяються для будівництва об'єктів соціальної інфраструктури. { Пункт 2 доповнено абзацом згідно з Розпорядженням КМ N 439-р ( 439-2006-р ) від 01.08.2006 }

{ Пункт 3 виключено на підставі Розпорядження КМ N 704-р ( 704-2008-р ) від 14.05.2008 }

4. Мінпаливенерго забезпечити уточнення переліку та вартості об'єктів соціального призначення у складі проекту завершення будівництва першої черги Дністровської ГАЕС та у разі потреби подати в установленому порядку Кабінетові Міністрів України пропозиції щодо внесення змін до розпорядження Кабінету Міністрів України від 20 березня 2006 р. N 156 ( 156-2006-р ) "Про затвердження проекту будівництва першої черги Дністровської ГАЕС".

{ Розпорядження доповнено пунктом 4 згідно з Розпорядженням КМ N 410-р ( 410-2007-р ) від 13.06.2007 }
