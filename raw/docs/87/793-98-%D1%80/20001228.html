Кабінет Міністрів України; Розпорядження від 02.10.1998 № 793-р

Про створення тимчасової комісії з питань контролю за використанням коштів Пенсійного фонду, отриманих від реалізації майна, переданого в рахунок погашення заборгованості

Стан: Втратив чинність

Ідентифікатор: 793-98-р

Текст документа від 28.12.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 жовтня 1998 р. N 793-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 528-р ( 528-2000-р ) від 28.12.2000 )

Про створення тимчасової комісії з питань контролю за використанням коштів Пенсійного фонду, отриманих від реалізації майна, переданого в рахунок погашення заборгованості

( Із змінами, внесеними згідно з Розпорядженнями КМ N 167-р ( 167-99-р ) від 09.03.99 N 95-р ( 95-2000-р ) від 22.02.2000 )

З метою здійснення контролю за використанням коштів Пенсійного фонду, отриманих від реалізації майна, переданого в рахунок погашення заборгованості:

1. Утворити тимчасову комісію з питань контролю за використанням коштів Пенсійного фонду, отриманих від реалізації майна, переданого в рахунок погашення заборгованості, у складі, що додається.

2. Голові тимчасової комісії подати у двотижневий термін графік перевірок здійснення контролю за використанням коштів Пенсійного фонду, отриманих від реалізації майна, переданого в рахунок погашення заборгованості.

3. Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським держадміністраціям утворити відповідні комісії для здійснення зазначеного контролю на місцях.

Тимчасовій комісії на підставі звітів відповідних комісій на місцях щомісяця інформувати Кабінет Міністрів України про надходження до Пенсійного фонду коштів, отриманих від реалізації зазначеного майна, та цільове їх використання. ( Абзац другий пункту 3 із змінами, внесеними згідно з Розпорядженням КМ N 95-р ( 95-2000-р ) від 22.02.2000 )
