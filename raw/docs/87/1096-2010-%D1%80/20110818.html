КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 травня 2010 р. N 1096-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 866 ( 866-2011-п ) від 03.08.2011 }

Про утворення Організаційного комітету з підготовки та відзначення 75-річчя заснування Національного ботанічного саду імені М.М. Гришка

1. Утворити Організаційний комітет з підготовки та відзначення 75-річчя заснування Національного ботанічного саду імені М.М. Гришка у складі згідно з додатком.

Надати співголовам Організаційного комітету право вносити у разі потреби зміни до його складу.

2. Організаційному комітетові підготувати та подати в місячний строк Кабінетові Міністрів України проект плану заходів з підготовки та відзначення 75-річчя заснування Національного ботанічного саду імені М.М. Гришка.
