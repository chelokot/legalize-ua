ПОСТАНОВА від 21 вересня 2011 р. N 1014 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 310 ( 310-2012-п ) від 18.04.2012 }

Про затвердження складу Міжвідомчої комісії з міжнародної торгівлі

{ Із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2012-п ) від 12.03.2012 }

Кабінет Міністрів України постановляє:

1. Затвердити склад Міжвідомчої комісії з міжнародної торгівлі, що додається.

2. Визнати такими, що втратили чинність, постанову Кабінету Міністрів України від 21 квітня 2010 р. N 328 ( 328-2010-п ) "Про затвердження складу Міжвідомчої комісії з міжнародної торгівлі" (Офіційний вісник України, 2010 р., N 32, ст. 1179) та розпорядження Кабінету Міністрів України від 20 жовтня 2010 р. N 2003 ( 2003-2010-р ) "Про зміну складу Міжвідомчої комісії з міжнародної торгівлі" (Офіційний вісник України, 2010 р., N 81, ст. 2854).
