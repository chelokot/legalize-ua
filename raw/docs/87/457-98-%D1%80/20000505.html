Кабінет Міністрів України; Розпорядження від 29.06.1998 № 457-р

Про дозвіл Держмитслужбі на здійснення митного оформлення вантажу, що надійшов за контрактом від 16 травня 1996 р. N 101 з австрійською фірмою "Лаг Трейд Гмбх" на адресу Національної академії внутрішніх справ для власних потреб

Стан: Втратив чинність

Ідентифікатор: 457-98-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 червня 1998 р. N 457-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Про дозвіл Держмитслужбі на здійснення митного оформлення вантажу, що надійшов за контрактом від 16 травня 1996 р. N 101 з австрійською фірмою "Лаг Трейд Гмбх" на адресу Національної академії внутрішніх справ для власних потреб

Дозволити Держмитслужбі здійснити митне оформлення вантажу (м'ясні вироби та комплекти посуду), що надійшов за контрактом від 16 травня 1996 р. N 101 з австрійською фірмою "Лаг Трейд Гмбх" на адресу Національної академії внутрішніх справ для власних потреб, з нарахуванням митного збору за його перебування під митним контролем лише за перші 10 днів періоду, за який цей збір справляється.
