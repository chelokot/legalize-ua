КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 квітня 2007 р. N 209-р Київ

{ Розпорядження скасовано на підставі Розпорядження КМ N 1118-р ( 1118-2007-р ) від 17.12.2007 }

Про підвищення ефективності онкологічної допомоги

1. Для підвищення ефективності медичної допомоги, що надається онкологічним хворим, прийняти пропозицію МОЗ щодо передачі до сфери його управління Інституту онкології Академії медичних наук з перейменуванням у Всеукраїнський науково-дослідний інститут онкології.

2. МОЗ затвердити у двомісячний строк статут, структуру та штатний розпис Всеукраїнського науково-дослідного інституту онкології, визначити основні напрями його науково-практичної діяльності як головної науково-дослідної установи у сфері боротьби з онкологічними захворюваннями та вжити заходів до зміцнення наукової та матеріально-технічної бази Інституту.

Прем'єр-міністр України В.ЯНУКОВИЧ
