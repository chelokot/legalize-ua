Текст документа від 28.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 грудня 2011 р. N 1352 Київ

Про внесення зміни до пункту 3 постанови Кабінету Міністрів України від 25 жовтня 1992 р. N 596

Кабінет Міністрів України постановляє:

Внести зміну до пункту 3 постанови Кабінету Міністрів України від 25 жовтня 1992 р. N 596 ( 596-92-п ) "Про оголошення міст Києва, Львова, Одеси, Сімферополя, Дніпропетровська та Харкова пунктами в'їзду (виїзду) для здійснення інспекційної діяльності за міжнародними угодами" - із змінами, внесеними постановами Кабінету Міністрів України від 14 вересня 2005 р. N 917 ( 917-2005-п ) (Офіційний вісник України, 2005 р., N 37, ст. 2308) і від 2 грудня 2009 р. N 1295 ( 1295-2009-п ) (Офіційний вісник України, 2009 р., N 93, ст. 3179), виключивши в абзаці першому слова "та об'єднання "Авіалінії України".

Прем'єр-міністр України М.АЗАРОВ
