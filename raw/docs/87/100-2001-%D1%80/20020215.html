КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 20 березня 2001 р. N 100-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 158 ( 158-2002-п ) від 15.02.2002 )

Про колегію Мінекономіки

1. Дозволити Мінекономіки мати колегію у кількості 20 осіб.

2. Затвердити членами колегії Мінекономіки Гусакова Володимира Миколайовича, Зубарєва Валерія Володимировича, Кабана Петра Степановича, Медвецького Андрія Теодоровича, Меркушова Віктора Тимофійовича, Непрана Михайла Івановича, Парнюка Володимира Олександровича, Романюка Сергія Андрійовича.

Відповідно до розпорядження Президента України від 25 травня 1999 р. N 113 ( 113/99-рп ) затвердити членом колегії Мінекономіки Чоботаря Сергія Івановича як представника Українського союзу промисловців і підприємців, із правом дорадчого голосу.

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 4 листопада 1996 р. N 1348 ( 1348-96-п ) "Про колегію Міністерства економіки".
