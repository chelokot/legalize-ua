Верховна Рада України; Закон від 11.06.2009 № 1509-VI

Про внесення змін до деяких законодавчих актів України

Стан: Чинний

Ідентифікатор: 1509-17

Текст документа від 01.01.2011:

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законодавчих актів України

( Відомості Верховної Ради України (ВВР), 2009, N 46, ст.700 )

{ Із змінами, внесеними згідно з Кодексом N 2755-VI ( 2755-17 ) від 02.12.2010, ВВР, 2011, N 13-14, N 15-16, N 17, ст.112 }

Верховна Рада України постановляє:

I. Внести зміни до таких законодавчих актів України:

1. Статтю 290 Господарського кодексу України ( 436-15 ) (Відомості Верховної Ради України, 2003 р., NN 18-22, ст. 144) виключити.

{ Пункт 2 розділу I втратив чинність на підставі Кодексу N 2755-VI ( 2755-17 ) від 02.12.2010 }

3. У частині першій статті 6 Закону України "Про оренду землі" ( 161-14 ) (Відомості Верховної Ради України, 2004 р., N 10, ст. 102) слова "Господарським кодексом України" виключити.

II. Прикінцеві положення

1. Цей Закон набирає чинності з дня його опублікування.

2. Кабінету Міністрів України:

у двомісячний строк з дня набрання чинності цим Законом привести свої нормативно-правові акти у відповідність із цим Законом у частині скасування необхідності нотаріального посвідчення договорів оренди землі;

забезпечити перегляд і скасування міністерствами та іншими центральними органами виконавчої влади їх нормативно-правових актів, що суперечать цьому Закону.

Президент України В.ЮЩЕНКО

м. Київ, 11 червня 2009 року N 1509-VI
