МІНІСТЕРСТВО ВНУТРІШНІХ СПРАВ УКРАЇНИ

НАКАЗ

23.05.2006 N 516

Зареєстровано в Міністерстві юстиції України 31 травня 2006 р. за N 637/12511

Про внесення змін і доповнень до наказу МВС України від 25.07.2005 N 595 та затвердження Положення про спеціальний нагрудний знак МВС України "Громадський помічник дільничного інспектора міліції"

{ Із змінами, внесеними згідно з Наказом Міністерства внутрішніх справ N 550 ( z1219-10 ) від 11.11.2010 }

Відповідно до Закону України "Про участь громадян в охороні громадського порядку і державного кордону" ( 1835-14 ) та на виконання пунктів 5 та 6 рішення розширеного засідання колегії МВС України від 11 березня 2006 року (протокол N 1) щодо запровадження індивідуального нагрудного знака громадського помічника дільничного інспектора міліції та з метою дотримання законності в діяльності громадських помічників дільничних інспекторів міліції в сільській місцевості, підвищення їх авторитету серед населення, забезпечення особистої безпеки під час виконання покладених на них завдань із забезпечення правопорядку в сільських населених пунктах НАКАЗУЮ:

{ Пункт 1 втратив чинність на підставі Наказу Міністерства внутрішніх справ N 550 ( z1219-10 ) від 11.11.2010 }

2. Затвердити Положення про спеціальний нагрудний знак МВС України "Громадський помічник дільничного інспектора міліції" (додається) ( z0638-06 ).

3. Начальникам головних управлінь МВС України в Автономній Республіці Крим, Київській та Харківській областях, управлінь МВС України в областях та місті Севастополі до 1 вересня 2006 року забезпечити перерахування коштів для виготовлення спеціальних нагрудних знаків, організувати належний облік, видачу та носіння спеціальних нагрудних знаків громадськими помічниками дільничних інспекторів міліції в сільській місцевості.

4. Департаменту ресурсного забезпечення (Шевченко Г.О.) організувати виготовлення необхідної кількості спеціальних нагрудних знаків. Надалі при збільшенні чисельності громадських помічників дільничних інспекторів міліції в сільській місцевості, пошкодженні виробів за заявками та оплатою керівників ГУМВС, УМВС України своєчасно забезпечувати підрозділи додатковими примірниками спеціальних нагрудних знаків.

5. Департаменту громадської безпеки (Маєвський В.І.) у п'ятиденний строк після підписання наказу забезпечити його подання на державну реєстрацію до Міністерства юстиції України.

6. Контроль за виконанням наказу покласти на заступника Міністра внутрішніх справ України генерал-майора міліції Рудіка В.М.

7. Наказ надіслати за належністю.

Міністр Ю.В.Луценко

{ ЗМІНИ ТА ДОПОВНЕННЯ до Положення про громадського помічника дільничного інспектора міліції в сільській місцевості втратили чинність на підставі Наказу Міністерства внутрішніх справ N 550 ( z1219-10 ) від 11.11.2010 }
