25.01.2005 N 42

Зареєстровано в Міністерстві юстиції України 28 січня 2005 р. за N 113/10393

Про внесення змін до наказу Міністерства освіти і науки України від 08.08.2002 N 453

Відповідно до постанови Кабінету Міністрів України від 15.01.2005 N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства освіти і науки України від 08.08.2002 N 453 ( z0683-02 ) "Про упорядкування умов оплати праці працівників окремих бюджетних наукових установ Міністерства освіти і науки України", зареєстрованого Міністерством юстиції України 20.08.2002 за N 683/6971, із змінами та доповненнями, унесеними наказами Міністерства освіти і науки України: від 29.01.2004 N 71 ( z0191-04 ), зареєстрованим у Міністерстві юстиції України 13.02.2004 за N 191/8790; від 26.02.2004 N 161 ( z0301-04 ), зареєстрованим у Міністерстві юстиції України 09.03. 2004 за N 301/8900; та від 08.09.2004 N 713 ( z1131-04 ), зареєстрованим у Міністерстві юстиції України 13.09.2004 за N 1131/9730, виклавши додаток у редакції, що додається.

2. Керівникам Науково-дослідного інституту "Кримська астрофізична обсерваторія" та Науково-дослідного інституту "Миколаївська астрономічна обсерваторія" установити з 1 січня 2005 року посадові оклади керівних і наукових працівників у розмірах, передбачених додатком до наказу.

3. Контроль за виконанням наказу покласти на заступника Міністра Богомолова А.Г.

Міністр В.Г.Кремень

ПОГОДЖЕНО:

Міністерство праці та соціальної політики України

Примітка. Заступникам керівників установ, заступникам керівників структурних підрозділів установ, для яких наявність ступеня не передбачена кваліфікаційними вимогами, головним бухгалтерам, помічникам керівників посадові оклади встановлюються залежно від посадового окладу керівника без урахування підвищень за науковий ступіпь та ін.
