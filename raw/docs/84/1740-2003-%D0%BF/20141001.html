КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 листопада 2003 р. N 1740 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 409 ( 409-2014-п ) від 06.08.2014 }

Про внесення змін до постанови Кабінету Міністрів України від 1 грудня 1995 р. N 959

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 1 грудня 1995 р. N 959 ( 959-95-п ) "Про встановлення тимчасових норм споживання населенням електроенергії та природного газу, на оплату яких надається субсидія" (ЗП України, 1996 р., N 4, ст. 112; Офіційний вісник України, 1997 р., число 21, с. 37; 1998 р., N 30, ст. 1129) такі зміни:

пункт 1 доповнити абзацом такого змісту:

"Надати право місцевим органам виконавчої влади та органам місцевого самоврядування у разі використання населенням побутових електроприладів для обігріву приміщень у зв'язку з припиненням згідно з їх рішенням централізованого теплопостачання приймати рішення щодо застосування для розрахунку субсидій в опалювальний сезон норм споживання електроенергії, встановлених для будинків, обладнаних електроопалювальними установками. Зазначені розрахунки здійснюються починаючи з опалювального сезону 2003/04 року на підставі акта обстеження матеріально-побутових умов сім'ї та акта обстеження стану зовнішніх і внутрішньобудинкових електромереж на їх відповідність вимогам нормативно-правових актів";

пункт 2 викласти у такій редакції:

"2. Встановити, що під час нарахування населенню субсидій для відшкодування витрат на оплату за користування природним газом та електроенергією у житлових приміщеннях, обладнаних лічильниками, використовується обсяг їх фактичного споживання, але не вище норм, встановлених цією постановою та постановою Кабінету Міністрів України від 8 червня 1996 р. N 619 ( 619-96-п ) (ЗП України, 1996 р., N 13, ст. 360)".
