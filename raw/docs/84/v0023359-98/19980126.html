Про форми та зразки виборчих документів по виборах депутатів місцевих рад та сільських, селищних, міських голів

Відповідно до статті 17 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ) та статей 30, 34, 35, 40, 45, 46 і 56 Закону України "Про вибори депутатів місцевих рад та сільських, селищних, міських голів" ( 14/98-ВР ) Центральна виборча комісія ПОСТАНОВЛЯЄ:

Встановити форми та затвердити зразки таких виборчих документів:

протокол окружної (територіальної) виборчої комісії про реєстрацію кандидатів у депутати (одномандатний виборчий округ) (додаток N 1);

протокол окружної (територіальної) виборчої комісії про реєстрацію кандидатів у депутати (багатомандатний виборчий округ) (додаток N 2);

протокол окружної (територіальної) виборчої комісії про реєстрацію кандидатів на посаду сільського, селищного, міського голови (додаток N 3);

протокол дільничної виборчої комісії про результати підрахунку голосів по виборах депутатів (одномандатний виборчий округ) (додаток N 4);

протокол дільничної виборчої комісії про результати підрахунку голосів по виборах депутатів (багатомандатний виборчий округ) (додаток N 5);

протокол дільничної виборчої комісії про результати підрахунку голосів по виборах сільського, селищного, міського голови (додаток N 6);

протокол окружної (територіальної) виборчої комісії про результати виборів депутатів (одномандатний виборчий округ) (додаток N 7);

протокол окружної (територіальної) виборчої комісії про результати виборів депутатів (багатомандатний виборчий округ) (додаток N 8);

протокол окружної (територіальної) виборчої комісії про результати виборів сільського, селищного, міського голови (додаток N 9),

посвідчення кандидата у депутати ради (додаток N 10);

посвідчення кандидата на посаду сільського, селищного, міського голови (додаток N 11);

посвідчення довіреної особи кандидата у депутати ради (додаток N 12);

посвідчення довіреної особи кандидата на посаду сільського, селищного, міського голови (додаток N 13);

посвідчення уповноваженої особи місцевого осередку партії (блоку), громадської організації (додаток N 14).
