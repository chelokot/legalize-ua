Кабінет Міністрів України; Розпорядження від 03.07.2000 № 274-р

Про організацію виробництва з виготовлення паспортних документів

Стан: Втратив чинність

Ідентифікатор: 274-2000-р

Текст документа від 15.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 липня 2000 р. N 274-р Київ

{ Дію Розпорядження відновлено згідно з Постановою КМ N 378 ( 378-2005-п ) від 26.05.2005 }

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 935-р ( 935-2004-р ) від 23.12.2004 }

{ Із змінами, внесеними згідно з Розпорядженням КМ N 165-р ( 165-2002-р ) від 29.03.2002 Постановами КМ N 378 ( 378-2005-п ) від 26.05.2005 N 327 ( 327-2006-п ) від 15.03.2006 }

1. Прийняти пропозицію Мінфіну та МВС про утворення Державного центру виготовлення паспортних документів на Поліграфкомбінаті "Україна" за технологією, що визначена за результатами проведеного тендера.

Положення про Державний центр виготовлення паспортних документів затверджується Мінфіном та МВС. ( Пункт 1 доповнено абзацом згідно з Розпорядженням КМ N 165-р ( 165-2002-р ) від 29.03.2002 )

( Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 165-р ( 165-2002-р ) від 29.03.2002 )

2. МВС вжити заходів для забезпечення разом з Мінфіном створення Державного центру виготовлення паспортних документів, та в межах затвердженого кошторису видатків за рахунок асигнувань, передбачених Державним бюджетом України на виготовлення паспортних документів та створення Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування.

{ Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 165-р ( 165-2002-р ) від 29.03.2002, Постановами КМ N 378 ( 378-2005-п ) від 26.05.2005, N 327 ( 327-2006-п ) від 15.03.2006 }
