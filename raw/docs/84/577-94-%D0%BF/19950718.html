Про внесення змін до ставок ввізного мита на окремі види товарів

( Із змінами, внесеними згідно з Постановами КМ N 209 ( 209-95-п ) від 22.03.95 N 531 ( 531-95-п ) від 18.07.95 )

З метою стимулювання надходжень окремих видів товарів у країну Кабінет Міністрів України ПОСТАНОВЛЯЄ:

На доповнення до постанови Кабінету Міністрів України від 3 травня 1994 р. N 285 ( 285-94-п ) внести зміни до ставок ввізного мита на окремі види товарів згідно з додатком.
