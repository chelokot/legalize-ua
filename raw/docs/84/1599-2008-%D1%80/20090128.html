Кабінет Міністрів України; Розпорядження від 27.12.2008 № 1599-р

Про тимчасове покладення виконання обов'язків Голови Фонду державного майна України на Парфененка Д.М.

Стан: Втратив чинність

Ідентифікатор: 1599-2008-р

Текст документа від 28.01.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 27 грудня 2008 р. N 1599-р Київ

{ Розпорядження скасовано на підставі Розпорядження КМ N 53-р ( 53-2009-р ) від 28.01.2009 }

{ Дію Розпорядження зупинено згідно з Указом Президента N 1/2009 ( 1/2009 ) від 02.01.2009 }

Про тимчасове покладення виконання обов'язків Голови Фонду державного майна України на Парфененка Д.М.

Покласти тимчасово, до призначення в установленому порядку Голови Фонду державного майна України, виконання обов'язків Голови цього Фонду на заступника Голови Фонду державного майна України Парфененка Дмитра Миколайовича.

Прем'єр-міністр України Ю.ТИМОШЕНКО
