Верховна Рада України; Закон від 18.03.2009 № 1140-VI

Про ратифікацію Європейської конвенції про спільне кінематографічне виробництво

Стан: Чинний

Ідентифікатор: 1140-17

Текст документа від 23.10.2013:

ЗАКОН УКРАЇНИ

Про ратифікацію Європейської конвенції про спільне кінематографічне виробництво

( Відомості Верховної Ради України (ВВР), 2009, N 30, ст.426 )

{ Із змінами, внесеними згідно із Законом N 579-VII ( 579-18 ) від 18.09.2013, ВВР, 2014, N 20-21, ст.735 }

Верховна Рада України постановляє:

Ратифікувати Європейську конвенцію про спільне кінематографічне виробництво ( 994_136 ), вчинену 2 жовтня 1992 року в м. Стразбурзі (додається), з такою заявою:

"Згідно з пунктом 5 статті 5 Конвенції ( 994_136 ) компетентним органом з надання статусу продукту спільного виробництва в Україні є Державне агентство України з питань кіно". { Абзац із змінами, внесеними згідно із Законом N 579-VII ( 579-18 ) від 18.09.2013 }

Президент України В.ЮЩЕНКО
