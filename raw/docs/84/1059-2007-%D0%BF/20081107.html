ПОСТАНОВА від 22 серпня 2007 р. N 1059 Київ

Про внесення змін до постанови Кабінету Міністрів України від 31 січня 2001 р. N 74

{ Із змінами, внесеними згідно з Постановою КМ N 939 ( 939-2008-п ) від 25.10.2008 }

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 31 січня 2001 р. N 74 ( 74-2001-п ) "Про умови оплати праці працівників бюджетних науково-дослідних установ і організацій та інших наукових установ Національної академії наук" (Офіційний вісник України, 2001 р., N 5, ст. 182, N 21, ст. 938; 2002 р., N 15, ст. 796; 2005 р., N 4, ст. 219) такі зміни:

{ Абзац другий постановляючої частини втратив чинність на підставі Постанови КМ N 939 ( 939-2008-п ) від 25.10.2008 }

{ Абзац третій постановляючої частини втратив чинність на підставі Постанови КМ N 939 ( 939-2008-п ) від 25.10.2008 }

додатки 1-3 до постанови викласти в редакції, що додається.
