КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 червня 2006 р. N 878 Київ

Про надання гуманітарної допомоги Киргизькій Республіці

{ Із змінами, внесеними згідно з Постановою КМ N 1474 ( 1474-2006-п ) від 25.10.2006 }

На виконання Указу Президента України від 21 березня 2006 р. N 249 ( 249/2006 ) "Про надання гуманітарної допомоги Киргизькій Республіці" Кабінет Міністрів України постановляє:

1. Виділити Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи 2 087 784 гривень для надання гуманітарної допомоги Киргизькій Республіці у зв'язку з надзвичайною ситуацією, що склалася внаслідок інтенсивних опадів у період з 26 по 29 січня 2006 року. { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1474 ( 1474-2006-п ) від 25.10.2006 }

Міністерству фінансів здійснити зазначені видатки за рахунок резервного фонду державного бюджету ( 3235-15 ).

2. Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи:

узгодити у тижневий строк з Міністерством фінансів та Міністерством економіки перелік витрат, пов'язаних з наданням гуманітарної допомоги;

забезпечити закупівлю, відправлення і супроводження до місця призначення та передачу отримувачам вантажу гуманітарної допомоги.

3. Міністерству закордонних справ і Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи узгодити з відповідними органами Киргизької Республіки питання доставки вантажу гуманітарної допомоги.

4. Державній митній службі забезпечити оперативне митне оформлення вантажу гуманітарної допомоги, а Адміністрації Державної прикордонної служби - першочергове здійснення контролю під час перетинання державного кордону України.

5. Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи подати до кінця поточного року Міністерству економіки, Міністерству фінансів і Державному казначейству звіт про використання коштів, виділених відповідно до цієї постанови.

Прем'єр-міністр України Ю.ЄХАНУРОВ
