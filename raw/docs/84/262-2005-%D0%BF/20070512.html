Кабінет Міністрів України; Постанова від 02.04.2005 № 262

Питання державного обов'язкового особистого страхування осіб рядового, начальницького та вільнонайманого складу органів і підрозділів внутрішніх справ

Стан: Втратив чинність

Ідентифікатор: 262-2005-п

Текст документа від 12.05.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 2 квітня 2005 р. N 262 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 707 ( 707-2007-п ) від 12.05.2007 }

Питання державного обов'язкового особистого страхування осіб рядового, начальницького та вільнонайманого складу органів і підрозділів внутрішніх справ

Кабінет Міністрів України постановляє:

1. У Положенні про порядок і умови державного обов'язкового особистого страхування осіб рядового, начальницького та вільнонайманого складу органів і підрозділів внутрішніх справ республіки, затвердженому постановою Кабінету Міністрів УРСР від 29 червня 1991 р. N 59 ( 59-91-п ) - у редакції постанови Кабінету Міністрів України від 19 листопада 1992 р. N 627 ( 627-92-п ) (ЗП України, 1992 р., N 12, ст. 285; 1995 р., N 5, ст. 132, N 6, ст. 146; Офіційний вісник України, 1997 р., число 27, с. 127; 2003 р., N 23, ст. 1078), слова "Національна акціонерна страхова компанія "Оранта" в усіх відмінках замінити словами "страховики, уповноважені для здійснення цього виду страхування" у відповідному відмінку.

2. Міністерству внутрішніх справ разом з Міністерством фінансів провести у місячний строк тендер з визначення страховиків, уповноважених для здійснення державного обов'язкового особистого страхування осіб рядового, начальницького та вільнонайманого складу органів і підрозділів внутрішніх справ.
