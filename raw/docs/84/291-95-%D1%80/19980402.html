Кабінет Міністрів України; Розпорядження від 19.05.1995 № 291-р

Про уповноваження АТ "Селянський торговий дім "Україна-Агро" на здійснення експорту товарів за кодами ТН ЗЕД

Стан: Втратив чинність

Ідентифікатор: 291-95-р

Текст документа від 02.04.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 травня 1995 р. N 291-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 315 ( 315-98-п ) від 17.03.98 )

( Розпорядження втратило чинність в частині надання повноважень на здійснення експорту спирту за кодом ТН ЗЕД 22.07 на підставі Розпорядження КМ N 647-р ( 647-96-р ) від 05.10.96 )

Уповноважити акціонерне товариство закритого типу "Селянський торговий дім "Україна-Агро" здійснювати експорт товарів за кодами ТН ЗЕД 22.07 і 22.08.
