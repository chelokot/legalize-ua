КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 вересня 1996 р. N 1117 Київ

Про ліцензування використання радіочастот

( Із змінами, внесеними згідно з Постановами КМ N 1481 ( 1481-97-п ) від 30.12.97 N 1452 ( 1452-98-п ) від 16.09.98 N 1919 ( 1919-99-п ) від 18.10.99 )

( Слова "Міністерством зв'язку" замінено словом "Держкомзв'язку" згідно з Постановою КМ N 1919 ( 1919-99-п ) від 18.10.99 )

З метою вдосконалення механізму видачі ліцензій на використання радіочастот Кабінет Міністрів України постановляє: ( Вступна частина із змінами, внесеними згідно з Постановою КМ N 1919 ( 1919-99-п ) від 18.10.99 )

1. Створити Міжвідомчу комісію з питань ліцензування використання радіочастот у складі згідно з додатком.

2. Установити, що ліцензії на використання радіочастот видаються Держкомзв'язку на підставі рішення Міжвідомчої комісії з питань ліцензування використання радіочастот. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1919 ( 1919-99-п ) від 18.10.99 )

3. Держкомзв'язку разом з Головним управлінням з питань використання радіочастот при Кабінеті Міністрів України у двотижневий термін подати Кабінетові Міністрів України проект Положення про Міжвідомчу комісію з питань ліцензування використання радіочастот.
