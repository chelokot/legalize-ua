Президент України; Указ від 19.08.2008 № 719/2008

Питання Державного управління справами

Стан: Чинний

Ідентифікатор: 719/2008

Текст документа від 19.08.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Питання Державного управління справами

1. На часткову зміну статті 2 Указу Президента України від 23 січня 2007 року N 33 ( 33/2007 ) "Питання Державного управління справами" встановити, що Керівник Державного управління справами має п'ятьох заступників, у тому числі одного першого заступника.

2. Внести до Положення про Державне управління справами, затвердженого Указом Президента України від 17 грудня 2002 року N 1180 ( 1180/2002, 474/2000 ) (зі змінами, внесеними Указами від 8 жовтня 2003 року N 1160 ( 1160/2003 ), від 3 лютого 2004 року N 144 ( 144/2004 ), від 12 травня 2005 року N 780 ( 780/2005 ) та від 19 лютого 2007 року N 128) ( 128/2007 ), зміну, виклавши абзац другий пункту 9 у такій редакції:

"Керівник Державного управління справами має одного першого заступника та чотирьох заступників, яких призначає на посади та звільняє з посад Президент України за поданням Керівника Державного управління справами".

3. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 19 серпня 2008 року N 719/2008
