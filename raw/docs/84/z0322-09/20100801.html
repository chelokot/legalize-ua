Зареєстровано в Міністерстві юстиції України 8 квітня 2009 р. за N 322/16338

{ Постанова втратила чинність на підставі Постанови Національної комісії регулювання електроенергетики N 812 ( z0507-10 ) від 13.07.2010 }

Про внесення змін до постанови НКРЕ від 25.10.2008 N 1239

Відповідно до Закону України "Про державну підтримку та особливості функціонування дитячих центрів "Артек" і "Молода гвардія" ( 906-17 ), Указу Президента України від 14.03.95 N 213 ( 213/95 ) "Про заходи щодо забезпечення діяльності Національної комісії з питань регулювання електроенергетики України" (із змінами), постанови Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" (із змінами) Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Унести до постанови НКРЕ від 25.10.2008 N 1239 ( z1088-08 ) "Про затвердження Роздрібних цін на природний газ, що використовується для потреб населення", зареєстрованої в Міністерстві юстиції України 10.11.2008 за N 1088/15779, такі зміни:

заголовок постанови після слова "населення" доповнити словами "Міжнародного дитячого центру "Артек" і Українського дитячого центру "Молода гвардія";

пункт 1 після слова "населення" доповнити словами "Міжнародного дитячого центру "Артек" і Українського дитячого центру "Молода гвардія".

2. Заголовок Роздрібних цін на природний газ, що використовується для потреб населення, затверджених зазначеною постановою, після слова "населення" доповнити словами "Міжнародного дитячого центру "Артек" і Українського дитячого центру "Молода гвардія".

3. Ця постанова набирає чинності з дня її офіційного опублікування.

4. Управлінню цінової та тарифної політики нафтогазового комплексу в установленому порядку забезпечити подання цієї постанови на державну реєстрацію до Міністерства юстиції України.
