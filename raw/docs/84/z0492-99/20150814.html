{ Наказ втратив чинність на підставі Наказу Міністерства фінансів N 614/711 ( z0843-15 ) від 02.07.2015 }

Про затвердження Критеріїв оцінки та Порядку визначення

підприємств - резидентів України, під час провадження

якими зовнішньоекономічної діяльності застосовується режим сприяння

На виконання постанови Кабінету Міністрів України від 14.04.99 N 593 ( 593-99-п ) "Про сприяння зовнішньоекономічній діяльності" НАКАЗУЄМО:

1. Затвердити Критерії оцінки підприємств - резидентів України, під час провадження якими зовнішньоекономічної діяльності застосовується режим сприяння (додаються).

2. Затвердити Порядок визначення підприємств - резидентів України, під час провадження якими зовнішньоекономічної діяльності застосовується режим сприяння ( z0495-99 ) (додається).

Затверджено Наказ Держмитслужби, МЗЕЗторгу і ДПА 07.07.99 N 411/488/357

Зареєстровано в Міністерстві юстиції України 22 липня 1999 р. за N 492/3785

Критерії оцінки підприємств - резидентів України, під

час провадження якими зовнішньоекономічної діяльності застосовується режим сприяння

Під час провадження підприємствами - резидентами України зовнішньоекономічної діяльності режим сприяння, установлений постановою Кабінету Міністрів України від 14.04.99 N 593 ( 593-99-п ) "Про сприяння зовнішньоекономічній діяльності", застосовується до підприємств, які відповідають таким критеріям:

1) є зареєстрованими в Україні резидентами - платниками податків (податку на додану вартість, податку на прибуток, акцизного збору);

2) здійснюють зовнішньоекономічну діяльність протягом принаймні двох років, що передують моменту здійснення оцінки підприємства;

3) є прибутковими протягом двох років, що передують моменту здійснення оцінки підприємства;

4) не мають простроченої заборгованості за зовнішньоекономічними операціями протягом двох років, що передують моменту здійснення оцінки підприємства;

5) не мають заборгованості з податків і зборів (обов'язкових платежів) до бюджетів та державних цільових фондів протягом двох років, що передують моменту здійснення оцінки підприємства;

6) не мають порушень митного, податкового, у тому числі й валютного, законодавства протягом двох років, що передують моменту здійснення оцінки підприємства;

7) до підприємства не застосовувалися спеціальні санкції, передбачені статтею 37 Закону України "Про зовнішньоекономічну діяльність" ( 959-12 ), протягом двох років, що передують моменту здійснення оцінки підприємства.
