Верховна Рада України; Постанова від 16.12.2008 № 665-VI

Про дострокове припинення повноважень народного депутата України Тимошенка М.М.

Стан: Чинний

Ідентифікатор: 665-17

Текст документа від 16.12.2008:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про дострокове припинення повноважень народного депутата України Тимошенка М.М.

( Відомості Верховної Ради України (ВВР), 2009, N 9, ст.134 )

Відповідно до пункту 1 частини другої статті 81 Конституції України ( 254к/96-ВР ) Верховна Рада України постановляє:

Припинити достроково повноваження ( 25-17 ) народного депутата України Тимошенка Миколи Михайловича, обраного в багатомандатному загальнодержавному виборчому окрузі, Комуністична партія України, у зв'язку з особистою заявою про складення ним депутатських повноважень.
