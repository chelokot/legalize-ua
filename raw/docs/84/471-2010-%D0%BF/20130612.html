Кабінет Міністрів України; Постанова від 09.06.2010 № 471

Про утворення державного підприємства "Державна інвестиційна компанія"

Стан: Чинний

Ідентифікатор: 471-2010-п

Текст документа від 12.06.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 червня 2010 р. N 471 Київ

Про утворення державного підприємства "Державна інвестиційна компанія"

{ Із змінами, внесеними згідно з Постановами КМ N 848 ( 848-2011-п ) від 03.08.2011 N 392 ( 392-2013-п ) від 03.06.2013 }

Кабінет Міністрів України постановляє:

1. Утворити державне підприємство "Державна інвестиційна компанія" (далі - підприємство) з віднесенням його до сфери управління Державного агентства з інвестицій та управління національними проектами. { Пункт 1 із змінами, внесеними згідно з Постановою КМ N 848 ( 848-2011-п ) від 03.08.2011 }

2. Установити, що:

статутний фонд підприємства формується шляхом передачі до нього частини ліквідного майна Державної інноваційної фінансово-кредитної установи; { Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 392 ( 392-2013-п ) від 03.06.2013 }

майно та майнові права закріплюються за підприємством на праві господарського відання.

3. Державному агентству з інвестицій та розвитку подати в місячний строк Кабінетові Міністрів України проект статуту підприємства.

Прем'єр-міністр України М.АЗАРОВ
