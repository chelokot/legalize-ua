Кабінет Міністрів України; Постанова від 22.12.1999 № 2345

Про встановлення терміну виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах під час виготовлення частин ливарних машин

Стан: Втратив чинність

Ідентифікатор: 2345-99-п

Текст документа від 25.04.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 грудня 1999 р. N 2345 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 295 ( 295-2013-п ) від 27.03.2013 }

Про встановлення терміну виконання операцій з давальницькою сировиною у зовнішньоекономічних відносинах під час виготовлення частин ливарних машин

( Із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )

Відповідно до статті 2 Закону України "Про операції з давальницькою сировиною у зовнішньоекономічних відносинах" ( 327/95-ВР ) Кабінет Міністрів України постановляє:

1. Установити термін виконання операцій з давальницькою сировиною, що ввозиться на митну територію України, під час виготовлення частин ливарних машин (код згідно з УКТ ЗЕД 8454 90 00) 250 календарних днів з дати оформлення ввізної вантажної митної декларації.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 17 серпня 1998 р. N 681 ( 681-98-р ).

( Постанова із змінами, внесеними згідно з Постановою КМ N 1648 ( 1648-2001-п ) від 13.12.2001 )
