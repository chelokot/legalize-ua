Про доповнення пункту 3 Положення про Раду національних асоціацій товаровиробників при Кабінеті Міністрів України

Стан: Втратив чинність

Текст документа від 11.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 грудня 2008 р. N 1052 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про доповнення пункту 3 Положення про Раду національних асоціацій товаровиробників при Кабінеті Міністрів України

Кабінет Міністрів України постановляє:

Доповнити підпункт 3 пункту 3 Положення про Раду національних асоціацій товаровиробників при Кабінеті Міністрів України, затвердженого постановою Кабінету Міністрів України від 8 грудня 2006 р. N 1685 ( 1685-2006-п ) "Про утворення Ради національних асоціацій товаровиробників при Кабінеті Міністрів України" (Офіційний вісник України, 2006 р., N 50, ст. 3310), після слів "з питань" словами "виконання вимог Регламенту Європейського парламенту та Ради ЄС про реєстрацію, оцінку, авторизацію і обмеження хімічних речовин та препаратів (REACH), а також з інших питань".

Прем'єр-міністр України Ю.ТИМОШЕНКО
