{ Указ втратив чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України на 8-му щорічну зустріч держав - учасниць Конвенції про заборону застосування, накопичення запасів, виробництва і передачі протипіхотних мін та про їхнє знищення

1. Утворити делегацію України на 8-му щорічну зустріч держав - учасниць Конвенції про заборону застосування, накопичення запасів, виробництва і передачі протипіхотних мін та про їхнє знищення ( 995_379 ) (18 - 22 листопада 2007 року, м. Амман, Хашимітське Королівство Йорданія) в такому складі:

БЕРШЕДА - Постійний представник України при

Євген Романович Відділенні ООН та інших міжнародних організаціях у Женеві, глава делегації

БАБЕНКО - головний фахівець Департаменту управління

Михайло Юрійович рятувальними силами Міністерства України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

КОЛІСНИК - заступник начальника - начальник групи

Юрій Євгенович центру гуманітарного розмінування державного підприємства "Укроборонсервіс"

ЛУЦКЕВИЧ - завідувач відділу Головної служби зовнішньої Олексій Романович політики Секретаріату Президента України

ЩЕБЕТЮК - старший офіцер служби інженерних військ

Олександр Дмитрович Центрального управління Інженерних військ Головного управління оперативного забезпечення командування сил підтримки Збройних Сил України.

2. Міністрові закордонних справ України затвердити вказівки делегації України на 8-му щорічну зустріч держав - учасниць Конвенції про заборону застосування, накопичення запасів, виробництва і передачі протипіхотних мін та про їхнє знищення ( 995_379 ).

3. Кабінету Міністрів України вирішити питання щодо виділення коштів в іноземній валюті для забезпечення участі в роботі 8-ї щорічної зустрічі держав - учасниць Конвенції про заборону застосування, накопичення запасів, виробництва і передачі протипіхотних мін та про їхнє знищення ( 995_379 ) О. Луцкевича.
