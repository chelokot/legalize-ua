Відповідно до законів України "Про охорону прав на винаходи і корисні моделі" ( 3687-12 ) та "Про охорону прав на промислові зразки" ( 3688-12 ), НАКАЗУЮ:

2. Затвердити Інструкцію про розгляд та публікацію заяви власника патенту України про надання будь-якій особі дозволу на використання запатентованого промислового зразка, що додається.

3. Опублікувати зазначені в пунктах 1, 2 Інструкції в офіційному бюлетені Держпатенту України "Промислова власність".

4. Порядок надання відкритої ліцензії на винахід у відповідності до Тимчасового положення про правову охорону об'єктів промислової власності та раціоналізаторських пропозицій в Україні, затверджений наказом голови Держпатенту України від 4 червня 1993 року N 48, скасувати.

Голова Держпатенту України В.Петров

Затверджено наказом Держпатенту України від 10 листопада 1995 року N 164

Інструкція про розгляд та публікацію заяви власника патенту України про надання будь-якій особі дозволу на використання запатентованого промислового зразка

1. Загальні положення

1.1. Ця Інструкція розроблена відповідно до Закону України "Про охорону прав на промислові зразки" ( 3688-12 ) і є обов'язковою для всіх фізичних та юридичних осіб незалежно від форм власності.

1.2. Ця Інструкція визначає порядок подання до Державного департаменту інтелектуальної власності (далі - Департамент), що діє у складі Міністерства освіти і науки України, реєстрації та розгляду заяви власника патенту України про надання будь-якій особі дозволу на використання запатентованого промислового зразка. ( Пункт 1.2 із змінами, внесеними згідно з Наказом МОН N 392 ( z0577-00 ) від 16.08.2000 )

1.3. Власник патенту на промисловий зразок має право протягом строку дії патенту подати до Департаменту для публікації в офіційному бюлетені Департаменту заяву про надання будь-якій особі дозволу на використання запатентованого промислового зразка (далі - заява).

Заява приймається до розгляду та реєстрації після публікації відомостей про видачу патенту на промисловий зразок в офіційному бюлетені Департаменту.

( Пункт 1.3 із змінами, внесеними згідно з Наказом МОН N 392 ( z0577-00 ) від 16.08.2000 )

1.4. Заява може бути подана, якщо дозвіл на використання зазначеного промислового зразка на підставі ліцензійного договору раніше не надавався.

1.5. Дії, що пов'язані з наданням будь-якій особі дозволу на використання промислового зразка, за дорученням власника патенту може здійснювати представник у справах інтелектуальної власності або інша довірена особа. У цьому разі до заяви додається довіреність, оформлена у відповідності до чинного законодавства.

1.6. Якщо власником патенту є декілька осіб, то всі дії, пов'язані з наданням будь-якій особі дозволу на використання промислового зразка, визначається угодою між ними, а право підпису заяви може бути надано одній особі при наявності відповідної довіреності.

2. Подання заяви

2.1. Власник патенту або його довірена особа подає до Департаменту заяву (додаток N 1) в одному примірнику.

Заява викладається державною мовою стосовно одного промислового зразка.

Якщо власником патенту є іноземна особа, то у заяві здійснюється транслітерація (передача тексту буквами українського алфавіту) даних стосовно імені фізичної особи або повного офіційного найменування юридичної особи та її адреси, а у дужках зазначені дані та відомості стосовно місця проживання або місця перебування власника патенту наводяться мовою оригіналу.

Від імені юридичної особи заяву підписує особа, що має на це повноваження, із зазначенням її посади та буквеним позначенням прізвища, а її особистий підпис завіряється печаткою.

Заяву друкують на аркуші білого паперу форматом 210x297 мм шрифтом чорного кольору. Виправлення у заяві не допускаються.

Якщо подана на публікацію заява не відповідає вимогам цього пункту, Департамент повертає її для опрацювання із зазначенням підстав повернення.

( Пункт 2.1 із змінами, внесеними згідно з Наказом МОН N 392 ( z0577-00 ) від 16.08.2000 )

2.2. Після публікації відомостей про реєстрацію заяви в офіційному бюлетені Департаменту річний збір за підтримання чинності патенту зменшується на 50 відсотків, починаючи з року, наступного за роком такої публікації.

( Пункт 2.2 із змінами, внесеними згідно з Наказом МОН N 392 ( z0577-00 ) від 16.08.2000 )

2.3. Особа, яка виявила бажання скористатися зазначеним дозволом, зобов'язана укласти з власником патенту договір про платежі. У договорі про платежі вказується розмір платежів та умови їх сплати.

2.4. Якщо жодна особа не заявила власнику патенту про свої наміри щодо використання промислового зразка, він може подати до Департаменту письмове клопотання про відкликання своєї заяви.

Департамент розглядає подане клопотання і приймає рішення про публікацію в офіційному бюлетені Департаменту. У цьому разі, починаючи з року, наступного за роком публікації такого клопотання, річний збір за підтримання чинності патенту сплачується у повному розмірі.

( Пункт 2.4 із змінами, внесеними згідно з Наказом МОН N 392 ( z0577-00 ) від 16.08.2000 )

2.5. В період від дати надходження заяви до Департаменту до дати публікації в офіційному бюлетені Департаменту клопотання про відкликання заяви власник патенту не має права:

- передавати право власності на промисловий зразок;

- заключати ліцензійні договори.

( Пункт 2.5 із змінами, внесеними згідно з Наказом МОН N 392 ( z0577-00 ) від 16.08.2000 )

3. Розгляд та реєстрація

3.1. Розгляд та реєстрація заяви (клопотання) здійснюється протягом місяця від дати надходження до Департаменту.

( Пункт 3.1 із змінами, внесеними згідно з Наказом МОН N 392 ( z0577-00 ) від 16.08.2000 )

3.2. Департамент:

- розглядає заяву (клопотання);

- готує рішення про реєстрацію та публікацію заяви (додаток N 2) або клопотання (додаток N 3);

- реєструє заяву (клопотання) у відповідному Державному реєстрі;

- направляє на адресу власника патенту рішення про реєстрацію та публікацію заяви (клопотання);

- готує та направляє відомості про реєстрацію заяви (клопотання) для публікації в офіційному бюлетені Департаменту.

Департамент має право запросити додаткові матеріали, що необхідні для прийняття рішення про реєстрацію та публікацію заяви (клопотання). У цьому разі рішення про реєстрацію та публікацію заяви (клопотання) приймається у двотижневий строк від дати надходження додаткових матеріалів.

( Пункт 3.2 із змінами, внесеними згідно з Наказом МОН N 392 ( z0577-00 ) від 16.08.2000 )

3.3. Заява не може бути зареєстрована та опублікована, якщо патент визнано недійсним. У цьому разі Департамент повертає її за адресою, що вказана у заяві.

( Пункт 3.3 із змінами, внесеними згідно з Наказом МОН N 392 ( z0577-00 ) від 16.08.2000 )
