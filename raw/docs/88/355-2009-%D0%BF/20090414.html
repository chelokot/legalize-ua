Про доповнення постанови Кабінету Міністрів України від 28 травня 2008 р. N 530

Стан: Чинний

Текст документа від 14.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 квітня 2009 р. N 355 Київ

Про доповнення постанови Кабінету Міністрів України від 28 травня 2008 р. N 530

Кабінет Міністрів України постановляє:

Доповнити постанову Кабінету Міністрів України від 28 травня 2008 р. N 530 ( 530-2008-п ) "Деякі питання соціального захисту окремих категорій громадян" (Офіційний вісник України, 2008 р., N 42, ст. 1396) пунктом 14-1 такого змісту:

"14-1. Установити, що починаючи з 1 січня 2009 р. для призначення (перерахунку) пенсій відповідно до Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ) застосовується величина оцінки одного року страхового стажу 1,35 відсотка.".
