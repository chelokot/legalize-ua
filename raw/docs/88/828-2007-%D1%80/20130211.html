Кабінет Міністрів України; Розпорядження від 03.10.2007 № 828-р

Про підписання Угоди між Кабінетом Міністрів України та компанією "Венко інтернешнл лімітед" про розподіл вуглеводнів, які видобуваються у межах Прикерченської ділянки надр континентального шельфу Чорного моря

Стан: Дію відновлено

Ідентифікатор: 828-2007-р

Текст документа від 11.02.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 жовтня 2007 р. N 828-р Київ

Про підписання Угоди між Кабінетом Міністрів України та компанією "Венко інтернешнл лімітед" про розподіл вуглеводнів, які видобуваються у межах Прикерченської ділянки надр континентального шельфу Чорного моря

{ Розпорядження скасовано на підставі Розпорядження КМ N 740-р ( 740-2008-р ) від 21.05.2008 - дію зупинено згідно з Указом Президента N 566/2008 ( 566/2008 ) від 18.06.2008 }

{ Розпорядження N 740-р ( 740-2008-р ) від 21.05.2008 скасовано на підставі Розпорядження КМ N 58-р ( 58-2013-р ) від 11.02.2013 }

Схвалити проект Угоди між Кабінетом Міністрів України та компанією "Венко інтернешнл лімітед" про розподіл вуглеводнів, які видобуваються у межах Прикерченської ділянки надр континентального шельфу Чорного моря.

Уповноважити Віце-прем'єр-міністра України Клюєва Андрія Петровича підписати зазначену Угоду, дозволивши вносити в разі потреби до її проекту зміни, що не мають принципового характеру.

Прем'єр-міністр України В.ЯНУКОВИЧ
