Про внесення змін до наказу Міністерства фінансів України від 11.07.2001 N 337

Відповідно до постанови Кабінету Міністрів України від 15.01.2005 N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

Унести зміни до наказу Міністерства фінансів України від 11.07.2001 N 337 ( z0625-01 ) "Про впорядкування умов оплати праці працівників Державного гемологічного центру України", зареєстрованого в Міністерстві юстиції України 23.07.2001 за N 625/5816 (із змінами і доповненнями), виклавши додаток до нього у новій редакції (додається).

Виконуючий обов'язки першого заступника Міністра А.І.Мярковський
