НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

22.08.2005 N 689

Зареєстровано в Міністерстві юстиції України 7 вересня 2005 р. за N 999/11279

Про визнання такою, що втратила чинність, постанови НКРЕ від 20.12.99 N 1517 (із змінами та доповненнями, внесеними постановою НКРЕ від 20.03.2000 N 279)

Відповідно до Законів України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ), "Про засади державної регуляторної політики у сфері господарської діяльності" ( 1160-15 ), Указу Президента України від 21.04.98 N 335 ( 335/98 ) "Питання Національної комісії регулювання електроенергетики України", Указу Президента України від 01.06.2005 N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" Національна комісія регулювання електроенергетики України ПОСТАНОВЛЯЄ:

1. Визнати такою, що втратила чинність, постанову НКРЕ від 20.12.99 N 1517 ( z0909-99 ) "Про ліцензування підприємницької діяльності із зберігання природного газу, постачання природного газу, транспортування природного газу, нафти і нафтопродуктів магістральними трубопроводами та транспортування природного і нафтового газу розподільними трубопроводами", зареєстровану в Міністерстві юстиції України 23.12.99 за N 909/4202 (із змінами та доповненнями, внесеними постановою НКРЕ від 20.03.2000 N 279 ( z0214-00 ), зареєстрованою в Міністерстві юстиції України 06.04.2000 за N 214/4435).

2. Управлінню ліцензування (Самкова В.Ю.) забезпечити подання цієї постанови до Міністерства юстиції України в установленому законодавством порядку.
