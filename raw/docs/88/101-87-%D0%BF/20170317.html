Про зміну, доповнення і визнання такими, що втратили чинність, деяких рішень Уряду УРСР з питань проектно-кошторисної справи

Стан: Втратив чинність

Ідентифікатор: 101-87-п

Текст документа від 17.03.2017:

РАДА МІНІСТРІВ УКРАЇНСЬКОЇ РСР

ПОСТАНОВА від 26 березня 1987 р. N 101 Київ

Про зміну, доповнення і визнання такими, що втратили чинність, деяких рішень Уряду УРСР з питань проектно-кошторисної справи

{ Із змінами, внесеними згідно з Постановою КМ N 1066 ( 1066-2016-п ) від 23.11.2016 }

Відповідно до постанови Ради Міністрів СРСР від 19 лютого 1987 р. N 222 ( v0222400-87 ) "Про зміну, доповнення і визнання такими, що втратили чинність, деяких рішень Уряду СРСР з питань проектно-кошторисної справи" Рада Міністрів Української РСР постановляє:

1. Пункт 1 постанови Ради Міністрів УРСР від 27 січня 1982 р. N 48 ( 48-82-п ) "Про заходи по виконанню постанови Ради Міністрів СРСР від 4 грудня 1981 р. N 1145 "Про порядок і умови суміщення професій (посад)" (ЗП УРСР, 1982 р., N 3, ст. 26) після слів: "профспілковими органами" доповнити словами: "якщо інше не передбачене чинним законодавством".

2. Визнати такими, що втратили чинність, рішення Уряду Української РСР згідно з переліком, що додається.

3. Взяти до відома, що Рада Міністрів СРСР постановою від 19 лютого 1987 р. N 222 ( v0222400-87 ):

1) Пункт 1 постанови Ради Міністрів СРСР від 19 січня 1973 р. N 47 "Про авторський нагляд проектних організацій за будівництвом" - ЗП СРСР, 1973 р., N 3, ст. 10 (підпункт 1 пункту 1 постанови Ради Міністрів УРСР від 1 березня 1973 р. N 112 - ЗП УРСР, 1973 р., N 3, ст. 18) - виклав у такій редакції:

{ Абзац другий підпункту 1 пункту 3 втратив чинність на підставі Постанови КМ N 1066 ( 1066-2016-п ) от 23.11.2016 }

{ Абзац третій підпункту 1 пункту 3 втратив чинність на підставі Постанови КМ N 1066 ( 1066-2016-п ) от 23.11.2016 }

{ Абзац четвертий підпункту 1 пункту 3 втратив чинність на підставі Постанови КМ N 1066 ( 1066-2016-п ) от 23.11.2016 }

{ Абзац п'ятий підпункту 1 пункту 3 втратив чинність на підставі Постанови КМ N 1066 ( 1066-2016-п ) от 23.11.2016 }

{ Абзац шостий підпункту 1 пункту 3 втратив чинність на підставі Постанови КМ N 1066 ( 1066-2016-п ) от 23.11.2016 }

{ Абзац сьомий підпункту 1 пункту 3 втратив чинність на підставі Постанови КМ N 1066 ( 1066-2016-п ) от 23.11.2016 }

{ Абзац восьмий підпункту 1 пункту 3 втратив чинність на підставі Постанови КМ N 1066 ( 1066-2016-п ) от 23.11.2016 }

2) Визнав таким, що втратив чинність, пункт 4 розпорядження Ради Міністрів СРСР від 20 квітня 1967 р. N 904 (абзаци п'ятий і шостий пункту 1 розпорядження Ради Міністрів УРСР від 12 травня 1967 р. N 474).

ЗАТВЕРДЖЕНИЙ постановою Ради Міністрів УРСР від 26 березня 1987 р. N 101

ПЕРЕЛІК рішень Уряду Української РСР, що втратили чинність

1. Постанова Ради Міністрів УРСР від 3 квітня 1961 р. N 445 "Про зниження вартості проектних і розвідувальних робіт".

2. Пункт 1 вступної частини і пункт 3 постанови Ради Міністрів УРСР від 14 листопада 1964 р. N 1155 "Про впорядкування інженерних розвідувань для промислового, сільськогосподарського і житлово-цивільного будівництва на території Української РСР" (ЗП УРСР, 1964 р., N 11, ст. 151).

3. Пункт 2, підпункти 2 і 3 пункту 3 постанови Ради Міністрів УРСР від 7 січня 1980 р. N 15 "Про заходи по скороченню строків проектування та будівництва об'єктів тваринництва і птахівництва м'ясного напряму" (ЗП УРСР, 1980 р., N 2, ст. 9).
