Стан: Втратив чинність

Ідентифікатор: 989-97-п

Текст документа від 01.01.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 вересня 1997 р. N 989 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1544 ( 1544-2000-п ) від 12.10.2000 )

Про внесення доповнень до Положення про портові збори, затвердженого постановою Кабінету Міністрів України від 18 квітня 1996 р. N 442

( Із змінами, внесеними згідно з Постановами КМ N 847 ( 847-98-п ) від 10.06.98 N 2150 ( 2150-99-п ) від 25.11.99 )

Відповідно до статті 84 Кодексу торговельного мореплавства України ( 176/95-ВР ) Кабінет Міністрів України постановляє:

1. Внести доповнення до Положення про портові збори, затвердженого постановою Кабінету Міністрів України від 18 квітня 1996 р. N 442 ( 442-96-п ) (ЗП України, 1996 р., N 10, ст. 302), згідно з додатком.

2. Затвердити Порядок формування і використання коштів портового адміністративного збору (додається).

3. Міністерству транспорту за погодженням з Міністерством економіки та Міністерством фінансів у двомісячний термін розробити і затвердити порядок обліку та використання сум цільових портових зборів, що справляються у морських торгівельних портах.

4. Контроль за виконанням цієї постанови покласти на Відділ з питань транспорту і зв'язку Кабінету Міністрів України.

Прем'єр-міністр України В. ПУСТОВОЙТЕНКО

Інд.34 Додаток до постанови Кабінету Міністрів України від 8 вересня 1997 р. N 989

ДОПОВНЕННЯ, що вносяться до Положення про портові збори, затвердженого постановою Кабінету Міністрів України від 18 квітня 1996 р. N 442 ( 442-96-п )

1. Абзац перший пункту 1 після слів "якірний" доповнити словом "адміністративний".

2. Доповнити Положення новим розділом такого змісту:

"Адміністративний збір

31. Для суден груп А, Б, В, Г адміністративний збір нараховується під час кожного заходження судна у порт за такими ставками:

0,014 долара США за 1 куб. метр об'єму судна - із суден у закордонному плаванні;

0,0014 долара США за 1 куб.метр об'єму судна - із суден у каботажному плаванні.

Судна, які заходять у морські порти для здійснення процедур, пов'язаних з пропуском через державний кордон України, без виконання вантажних робіт, звільняються від сплати адміністративного збору.

Встановлені портами за погодженням із судновласником знижки із суднових зборів на адміністративний збір не поширюються.

32. Судна груп Д і Е звільняються від сплати адміністративного збору.

33. Суми, які порт одержує від адміністративного збору, розподіляються у такому співвідношенні: 10 відсотків спрямовується до державного бюджету, 90 відсотків - Укрморрічфлоту для фінансування витрат на провадження ним зовнішньоекономічної діяльності. Зазначені суми оподатковуються згідно із законодавством України. Суми, не використані протягом поточного року, перераховуються до державного бюджету".

У зв'язку з цим пункти 31-34 Положення вважати відповідно пунктами 35-38.

Міністр Кабінету Міністрів України А. ТОЛСТОУХОВ

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 8 вересня 1997 р. N 989

ПОРЯДОК формування та використання коштів портового адміністративного збору

1. Адміністративний збір справляється із суден, які заходять у морські порти України.

2. Кошти, які порт одержує від адміністративного збору, розподіляються в такому співвідношенні: 10 відсотків спрямовується до державного бюджету, 90 відсотків - Укрморрічфлоту або Держкомрибгоспу (залежно від того, до сфери управління якого органу належить порт) для фінансування витрат на провадження ними зовнішньоекономічної діяльності. ( Пункт 2 в редакції Постанови КМ N 847 ( 847-98-п ) від 10.06.98 )

3. Сумами портового адміністративного збору покриваються такі витрати Укрморрічфлоту та Держкомрибгоспу на провадження ними зовнішньоекономічної діяльності: ( Абзац перший пункту 3 із змінами, внесеними згідно з Постановою КМ N 847 ( 847-98-п ) від 10.06.98 )

сплата членських внесків у міжнародні морські організації, членом яких є Україна. До таких організацій належать Міжнародні морські організації (ІМО), Дунайська комісія, Міжнародна організація з морського супутникового зв'язку (ІНМАРСАТ), Міжнародна супутникова система (КОСПАС-САРСАД), Міжнародна організація із збереження ресурсів Антарктики (АНТКОМ), Міжнародна північно-атлантична риболовна організація (НАФО), Міжнародна північно-східноатлантична риболовна організація (НЕАФК), Міжнародна організація із збереження живих ресурсів Чорного моря, Міжнародна гідрографічна організація; ( Абзац другий пункту 3 із змінами, внесеними згідно з Постановами КМ N 847 ( 847-98-п ) від 10.06.98, N 2150 ( 2150-99-п ) від 25.11.99 )

утримання представництв при міжнародних спеціалізованих організаціях та виконання міжнародних програм, які мають зв'язок з торгівельним судноплавством і рибопромисловим флотом; ( Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 847 ( 847-98-п ) від 10.06.98 )

видатки на короткотермінові відрядження за кордон, пов'язані з участю у міжнародних конференціях, семінарах, симпозіумах тощо з питань торгівельного мореплавства, у порядку, встановленому відповідно Мінтрансом і Держкомрибгоспом; ( Абзац четвертий пункту 3 із змінами, внесеними згідно з Постановою КМ N 847 ( 847-98-п ) від 10.06.98 )

інші витрати, пов'язані з провадженням Укрморрічфлотом і Держкомрибгоспом зовнішньоекономічної діяльності. ( Абзац п'ятий пункту 3 із змінами, внесеними згідно з Постановою КМ N 847 ( 847-98-п ) від 10.06.98 )

4. Суми портового адміністративного збору акумулюються у національній валюті в установах системи Національного банку на балансовому рахунку "Кошти на фінансування загальнодержавних витрат на морському і річковому транспорті України" та на розрахунковому рахунку Держкомрибгоспу і оподатковуються згідно з законодавством України. ( Пункт 4 із змінами, внесеними згідно з Постановою КМ N 847 ( 847-98-п ) від 10.06.98 )

Суми, не використані протягом поточного року, перераховуються до державного бюджету.

5. Контроль за цільовим використанням коштів портового адміністративного збору здійснюється відповідно до законодавства.

Порядок обліку і використання цих сум визначається відповідно Мінтрансом і Держкомрибгоспом. ( Пункт 5 із змінами, внесеними згідно з Постановою КМ N 847 ( 847-98-п ) від 10.06.98 )
