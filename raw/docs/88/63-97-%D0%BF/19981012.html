Текст документа від 12.10.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 січня 1997 р. N 63 Київ

Про мінімальну митну вартість імпортних тютюнових виробів

( Із змінами, внесеними згідно з Постановами КМ N 1231 ( 1231-97-п ) від 06.11.97 N 1290 ( 1290-98-п ) від 17.08.98 )

Кабінет Міністрів України постановляє:

1. Установити мінімальну митну вартість імпортних тютюнових виробів згідно з додатком.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 18 листопада 1996 р. N 1408 ( 1408-96-п ) "Про встановлення індикативних цін на імпортні тютюнові вироби, що застосовуються при обчисленні розмірів сплати податку на добавлену вартість".

3. Ця постанова набирає чинності через 12 днів після опублікування її в газеті "Урядовий кур'єр".
