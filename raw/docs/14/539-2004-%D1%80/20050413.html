Текст документа від 13.04.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 липня 2004 р. N 539-р Київ

Про підписання Угоди між Кабінетом Міністрів України та Урядом Республіки Польща про академічне взаємовизнання документів про освіту та рівноцінність ступенів

( Із змінами, внесеними згідно з Розпорядженням КМ N 102-р ( 102-2005-р ) від 13.04.2005 )

Схвалити проект Угоди між Кабінетом Міністрів України та Урядом Республіки Польща про академічне взаємовизнання документів про освіту та рівноцінність ступенів.

Уповноважити Міністра освіти і науки Ніколаєнка Станіслава Миколайовича підписати зазначену Угоду, дозволивши йому вносити у разі потреби до її проекту зміни, що не мають принципового характеру. ( Абзац другий із змінами, внесеними згідно з Розпорядженням КМ N 102-р ( 102-2005-р ) від 13.04.2005 )
