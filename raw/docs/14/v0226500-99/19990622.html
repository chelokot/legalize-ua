Про внесення змін та доповнень до постанови Правління Національного банку України від 19.02.99 N 70

Стан: Втратив чинність

Ідентифікатор: v0226500-99

Текст документа від 22.06.1999:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 226 від 11.05.99 Зареєстровано в юридичному м.Київ департаменті Нацбанку 11 травня 1999 р. vd990511 vn226 за N 646

( Постанова втратила чинність на підставі Постанови Нацбанку N 296 ( v0296500-99 ) від 22.06.99 )

Про внесення змін та доповнень до постанови Правління Національного банку України від 19.02.99 N 70

На виконання постанови Кабінету Міністрів України від 19.04.99 N 611 ( 611-99-п ) "Про внесення доповнень до постанови Кабінету Міністрів України від 17.02.99 N 180" Правління ПОСТАНОВЛЯЄ:

1. Внести такі зміни та доповнення до постанови Правління Національного банку України від 19.02.99 N 70 ( v0623500-99 ) "Про закриття рахунків з обліку позабюджетних коштів бюджетних організацій, які утримуються з Державного бюджету України":

останній абзац пункту 2 та пункт 3 після слів "органів Державного казначейства України" доповнити словами "та навчальних закладів".

2. Контроль за виконанням цієї постанови покласти на Департамент платіжних систем (В.М.Кравець) та регіональні управління Національного банку України.

3. Постанова набуває чинності з дня її прийняття.

Голова В.А.Ющенко
