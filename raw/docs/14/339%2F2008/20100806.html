Президент України; Указ від 11.04.2008 № 339/2008

Про голову Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 339/2008

Текст документа від 06.08.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 799/2010 ( 799/2010 ) від 05.08.2010 }

Про голову Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва

1. Призначити ТИМОШЕНКО Юлію Володимирівну - Прем'єр-міністра України - головою Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва.

2. Визнати таким, що втратило чинність, Розпорядження Президента України від 6 грудня 2005 року N 1262 ( 1262/2005-рп ) "Питання Української частини Спільної міжурядової українсько-грузинської комісії з питань економічного співробітництва".

Президент України В.ЮЩЕНКО

м. Київ, 11 квітня 2008 року N 339/2008
