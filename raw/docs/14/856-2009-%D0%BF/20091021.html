Кабінет Міністрів України; Постанова від 08.07.2009 № 856

Про залучення у 2009 році іноземного кредиту під державну гарантію для реалізації інвестиційного проекту комплексного протипаводкового захисту у Львівській області на 2009-2011 роки

Стан: Чинний

Ідентифікатор: 856-2009-п

Текст документа від 21.10.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 липня 2009 р. N 856 Київ

Про залучення у 2009 році іноземного кредиту під державну гарантію для реалізації інвестиційного проекту комплексного протипаводкового захисту у Львівській області на 2009-2011 роки

{ Із змінами, внесеними згідно з Постановою КМ N 1070 ( 1070-2009-п ) від 07.10.2009 }

Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Львівської обласної державної адміністрації щодо залучення у 2009 році іноземного кредиту під державну гарантію в сумі, еквівалентній 50 млн. євро, шляхом укладення кредитного договору компанією "Aquasafety invest" (Великобританія) як кредитором і державним підприємством "Львівська обласна дирекція з протипаводкового захисту" як позичальником для реалізації інвестиційного проекту комплексного протипаводкового захисту у Львівській області на 2009-2011 роки з урахуванням Державної цільової програми комплексного протипаводкового захисту в басейнах річок Дністра, Пруту та Сірету, затвердженої постановою Кабінету Міністрів України від 27 грудня 2008 р. N 1151 ( 1151-2008-п ) (Офіційний вісник України, 2008 р., N 100, ст. 3341), та Комплексної програми захисту сільських населених пунктів і сільськогосподарських угідь від шкідливої дії вод на період до 2010 року та прогноз до 2020 року, затвердженої постановою Кабінету Міністрів України від 3 липня 2006 р. N 901 ( 901-2006-п ) (Офіційний вісник України, 2006 р., N 27, ст. 1942) (далі - проект).

2. Державному комітетові по водному господарству для реалізації проекту утворити в місячний строк державне підприємство "Львівська обласна дирекція з протипаводкового захисту" (далі - підприємство), яке визначається відповідальним виконавцем проекту.

3. Установити, що:

генеральний проектувальник комплексу протипаводкового захисту у Львівській області і генеральний підрядник будівництва об'єктів у рамках реалізації проекту затверджуються підприємством за поданням кредитора, зазначеного у пункті 1 цієї постанови;

публічне акціонерне товариство "Державний експортно-імпортний банк України", яке діє на підставі агентської угоди, укладеної з Міністерством фінансів від імені Кабінету Міністрів України 19 вересня 1996 р., є фінансовим агентом Кабінету Міністрів України із супроводження іноземного кредиту, що залучається під державну гарантію для реалізації проекту;

для надання державної гарантії підприємство подає Міністерству фінансів проект кредитного договору з визначенням схеми та умов залучення іноземного кредиту, проект договору щодо надання державної гарантії, проекти договорів генерального підряду на проектування і будівництво об'єктів у рамках реалізації проекту та виконання інших робіт і техніко-економічний розрахунок проекту (бізнес-план);

у період до надання державної гарантії Міністерство фінансів і підприємство укладають договір про належне забезпечення надання державної гарантії; { Абзац п'ятий пункту 3 в редакції Постанови КМ N 1070 ( 1070-2009-п ) від 07.10.2009 }

У договорі передбачаються зобов'язання підприємства щодо:

внесення плати за надання державної гарантії в строк, передбачений для сплати відсотків за іноземним кредитом, у розмірі 2 відсотки річних залишку суми гарантійних зобов'язань;

{ Абзац восьмий пункту 3 виключено на підставі Постанови КМ N 1070 ( 1070-2009-п ) від 07.10.2009 }

{ Абзац дев'ятий пункту 3 виключено на підставі Постанови КМ N 1070 ( 1070-2009-п ) від 07.10.2009 }

подання Міністерству фінансів інформації, необхідної для проведення моніторингу спроможності підприємства виконувати зобов'язання за іноземним кредитом.

Забезпеченням за наданою гарантією є право договірного списання коштів з поточних рахунків підприємства. { Пункт 3 доповнено абзацом згідно з Постановою КМ N 1070 ( 1070-2009-п ) від 07.10.2009 }

4. Уповноважити першого заступника Міністра фінансів Уманського Ігоря Івановича підписати документи, які стосуються надання державної гарантії щодо забезпечення виконання зобов'язань за іноземним кредитом, що залучається для реалізації проекту.

5. Міністерству фінансів під час складання проекту Державного бюджету України на 2010 та наступні роки враховувати в межах реальних можливостей бюджету видатки для реалізації проекту.

6. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 24 червня 2009 р. N 619 ( 619-2009-п ) "Про державну підтримку реалізації інвестиційного проекту із забезпечення розбудови та відновлення об'єктів протипаводкового захисту у Львівській області" (Офіційний вісник України, 2009 р., N 50, ст. 1667).
