Кабінет Міністрів України; Постанова від 18.12.1995 № 1017

Про порядок повітряного сполучення через державний кордон України

Стан: Чинний

Ідентифікатор: 1017-95-п

Текст документа від 04.09.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 грудня 1995 р. N 1017 Київ

Про порядок повітряного сполучення через державний кордон України

( Із змінами, внесеними згідно з Постановами КМ N 815 ( 815-98-п ) від 08.06.98 N 1402 ( 1402-2003-п ) від 04.09.2003 )

Відповідно до статті 10 Закону України "Про державний кордон України" ( 1777-12 ) Кабінет Міністрів України постановляє:

1. Установити, що:

міжнародне повітряне сполучення здійснюється з використанням аеропортів (аеродромів), в яких відкрито в установленому порядку пункти пропуску через державний кордон.

В окремих випадках міжнародне повітряне сполучення може здійснюватися також з використанням аеропортів (аеродромів), в яких відсутні пункти пропуску через державний кордон, у порядку, встановленому Державною авіаційною адміністрацією, Міністерством оборони, Адміністрацією Державної прикордонної служби, державним митним комітетом; ( Абзац третій пункту 1 із змінами, внесеними згідно з Постановами КМ N 815 ( 815-98-п ) від 08.06.98, N 1402 ( 1402-2003-п ) від 04.09.2003 )

перелік держав, з якими може здійснюватися міжнародне повітряне сполучення з того чи іншого аеропорту (аеродрому), характер транспортних перевезень, а також режим функціонування пунктів пропуску через державний кордон визначаються Державною авіаційною адміністрацією разом з Адміністрацією Державної прикордонної служби і Державним митним комітетом; ( Абзац четвертий пункту 1 із змінами, внесеними згідно з Постановами КМ N 815 ( 815-98-п ) від 08.06.98, N 1402 ( 1402-2003-п ) від 04.09.2003 )

перевезення працівників контрольних служб до пунктів пропуску з нерегулярним режимом функціонування та до аеропортів (аеродромів), з яких здійснюється виліт (посадка) повітряного судна, і назад, забезпечується адміністрацією аеропортів (аеродромів), авіакомпаній.

2. Державній авіаційній адміністрації, Адміністрації Державної прикордонної служби, Державному митному комітетові, Міністерству агропромислового комплексу, Міністерству охорони навколишнього природного середовища та ядерної безпеки, Міністерству охорони здоров'я визначити на підставі клопотань адміністрацій аеропортів (аеродромів), авіакомпаній режим (графік) роботи відповідних контрольних служб під час здійснення міжнародних повітряних перевезень, виходячи з інтенсивності руху і умов роботи.

( Пункт 2 із змінами, внесеними згідно з Постановами КМ N 815 ( 815-98-п ) від 08.06.98, N 1402 ( 1402-2003-п ) від 04.09.2003 )

3. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 6 квітня 1993 р. N 256 ( 256-93-п ) "Про запровадження прикордонного і митного контролю при здійсненні повітряного сполучення з державами, що утворилися на території колишнього Союзу РСР";

постанову Кабінету Міністрів України від 7 червня 1993 р. N 425 ( 425-93-п ) "Про внесення змін до постанови Кабінету Міністрів України від 6 квітня 1993 р. N 256";

постанову Кабінету Міністрів України від 30 червня 1993 р. N 491 ( 491-93-п ) "Про внесення доповнень до постанови Кабінету Міністрів України від 6 квітня 1993 р. N 256";

пункт 2 розпорядження Кабінету Міністрів України від 27 жовтня 1994 р. N 284 ( 284-94-р ).

4. Ця постанова вводиться в дію з 1 січня 1996 року.
