Про внесення змін до постанов Кабінету Міністрів України від 26 березня 2008 р. N 247 і від 3 грудня 2008 р. N 1082

Стан: Втратив чинність

Текст документа від 10.10.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 вересня 2009 р. N 1127 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 792 ( 792-2015-п ) від 30.09.2015 }

Про внесення змін до постанов Кабінету Міністрів України від 26 березня 2008 р. N 247 і від 3 грудня 2008 р. N 1082

{ Із змінами, внесеними згідно з Постановою КМ N 217 ( 217-2014-п ) від 18.06.2014 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 26 березня 2008 р. N 247 ( 247-2008-п ) "Про вдосконалення порядку розрахунків за спожитий природний газ населенням та установами і організаціями, які фінансуються з державного і місцевих бюджетів" (Офіційний вісник України, 2008 р., N 25, ст. 769) і від 3 грудня 2008 р. N 1082 ( 1082-2008-п ) "Питання удосконалення схем розрахунків за використану електроенергію та природний газ" (Офіційний вісник України, 2008 р., N 97, ст. 3198; 2009 р., N 18, ст. 577, N 47, ст. 1569, N 69, ст. 2377) - із змінами, внесеними постановою Кабінету Міністрів України від 7 жовтня 2009 р. N 1077 ( 1077-2009-п ), зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 37

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 23 вересня 2009 р. N 1127

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 26 березня 2008 р. N 247 ( 247-2008-п ) і від 3 грудня 2008 р. N 1082 ( 1082-2008-п )

1. У постанові Кабінету Міністрів України від 26 березня 2008 р. N 247 ( 247-2008-п ):

у пункті 1 слова "уповноваженим банком, який обслуговує" замінити словами "уповноваженими банками, які обслуговують", а після слів "відкрите акціонерне товариство "Державний ощадний банк України" доповнити словами "та публічне акціонерне товариство акціонерний банк "Укргазбанк";

доповнити пункт 1 Порядку відкриття поточних рахунків із спеціальним режимом використання для зарахування коштів, що надходять за спожитий природний газ, затвердженого зазначеною постановою ( 247-2008-п ), після слів "ВАТ "Державний ощадний банк України" словами "та публічне акціонерне товариство акціонерний банк "Укргазбанк".

{ Пункт 2 втратив чинність на підставі Постанови КМ N 217 ( 217-2014-п ) від 18.06.2014 }
