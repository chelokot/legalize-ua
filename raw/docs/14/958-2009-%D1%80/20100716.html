Кабінет Міністрів України; Розпорядження від 29.07.2009 № 958-р

Питання переведення системи реєстраційного обліку фізичних осіб з паперових на електронні носії

Стан: Втратив чинність

Ідентифікатор: 958-2009-р

Текст документа від 16.07.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 липня 2009 р. N 958-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 559 ( 559-2010-п ) від 07.07.2010 }

{ Дію Розпорядження зупинено згідно з Указом Президента N 675/2009 ( 675/2009 ) від 27.08.2009 }

Питання переведення системи реєстраційного обліку фізичних осіб з паперових на електронні носії

Виділити ДМС кошти в сумі 10 млн. гривень на безповоротній основі для поповнення статутного фонду державного підприємства "Документ" для здійснення заходів, пов'язаних із забезпеченням переведення системи реєстраційного обліку фізичних осіб відповідно до Закону України "Про свободу пересування та вільний вибір місця проживання в Україні" ( 1382-15 ) з паперових на електронні носії.

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 835-17 ).

Прем'єр-міністр України Ю.ТИМОШЕНКО
