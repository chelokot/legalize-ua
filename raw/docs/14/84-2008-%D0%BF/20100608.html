КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 22 лютого 2008 р. N 84 Київ

Про затвердження Порядку використання у 2009 році коштів, передбачених у державному бюджеті Міністерству промислової політики за деякими програмами

{ Із змінами, внесеними згідно з Постановою КМ N 89 ( 89-2009-п ) від 04.02.2009 }

{ У назві та тексті Постанови цифри "2008" замінено цифрами "2009" згідно з Постановою КМ N 89 ( 89-2009-п ) від 04.02.2009 }

{ Установити, що у 2010 році кошти, передбачені у державному бюджеті ( 2154-17 ) Міністерству промислової політики за програмами "Консервація виробничих потужностей промислових підприємств", "Реструктуризація підприємств з підземного видобутку залізної руди", "Забезпечення життєдіяльності Криворізького гірничо-збагачувального комбінату окислених руд", "Забезпечення міжнародного співробітництва у воєнно-промисловій і військово-технічній сферах", "Презентація українськими підприємствами вітчизняних товарів на міжнародній виставці "Ганновер Мессе", використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 382 ( 382-2010-п ) від 02.06.2010 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) Міністерству промислової політики за деякими програмами, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 22 лютого 2008 р. N 84

ПОРЯДОК використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) Міністерству промислової політики за деякими програмами

{ У назві та тексті Порядку цифри "2008" замінено цифрами "2009" згідно з Постановою КМ N 89 ( 89-2009-п ) від 04.02.2009 }

1. Цей Порядок визначає механізм використання у 2009 році коштів, передбачених Мінпромполітики у державному бюджеті ( 835-17 ) за програмами: "Консервація виробничих потужностей промислових підприємств", "Реструктуризація підприємств з підземного видобутку залізної руди", "Забезпечення життєдіяльності Криворізького гірничо-збагачувального комбінату окислених руд та відновлення будівництва його об'єктів", "Забезпечення міжнародного співробітництва у воєнно-промисловій і військово-технічній сферах", "Презентація українськими підприємствами вітчизняних товарів на міжнародній виставці "Ганновер Мессе" (далі - бюджетні кошти).

2. Бюджетні кошти спрямовуються:

за програмою "Консервація виробничих потужностей промислових підприємств" - на виконання робіт з консервації ртутного виробництва (відкачування та очищення стічних вод, утримання в робочому стані гірничих виробок, будівель та споруд поверхневого комплексу і головної понижувальної підстанції) на державному підприємстві гідрогеологічного захисту "Шахта 2-біс" відповідно до затвердженого проекту переведення підприємства у режим гідрогеологічного захисту та ліквідації споруд, не пов'язаних з гідрозахистом. { Абзац другий пункту 2 в редакції Постанови КМ N 89 ( 89-2009-п ) від 04.02.2009 }

Одержувачем бюджетних коштів за зазначеною програмою є державне підприємство гідрогеологічного захисту "Шахта 2-біс". Використання бюджетних коштів одержувачем здійснюється згідно з відповідним планом, затвердженим цим підприємством за погодженням з Мінпромполітики, та кошторисом робіт на 2009 рік, затвердженим в установленому порядку Мінпромполітики відповідно до проекту;

за програмою "Реструктуризація підприємств з підземного видобутку залізної руди" - на утримання майнового комплексу і відведення поверхневих стоків згідно з робочими проектами ліквідації шахти "Першотравнева" та переведення її у спеціальний режим гідрозахисту гірничих робіт і селитебних територій Тернівського району (реструктуризація шахт промислового об'єднання "Кривбасруда"), ліквідації державного підприємства "Шахта "Саксагань", ліквідації шахти "Гігант" (реструктуризація шахт промислового об'єднання "Кривбасруда"). { Абзаци четвертий і п'ятий пункту 2 замінено абзацом згідно з Постановою КМ N 89 ( 89-2009-п ) від 04.02.2009 }

{ Абзац п'ятий пункту 2 виключено на підставі Постанови КМ N 89 ( 89-2009-п ) від 04.02.2009 }

{ Абзац шостий пункту 2 виключено на підставі Постанови КМ N 89 ( 89-2009-п ) від 04.02.2009 }

Одержувачем бюджетних коштів за зазначеною програмою є державне підприємство "Кривбасшахтозакриття". Використання бюджетних коштів одержувачем здійснюється згідно з відповідним планом, затвердженим зазначеним підприємством за погодженням з Мінпромполітики, та кошторисом робіт на 2009 рік, затвердженим в установленому порядку Мінпромполітики відповідно до робочих проектів;

за програмою "Забезпечення життєдіяльності Криворізького гірничо-збагачувального комбінату окислених руд та відновлення будівництва його об'єктів" - на утримання дирекції комбінату, працівників бази комплектування устатковання і приладів, об'єктів незавершеного будівництва комбінату та забезпечення їх охорони.

Одержувачем бюджетних коштів за зазначеною програмою є Криворізький гірничо-збагачувальний комбінат окислених руд. Використання бюджетних коштів одержувачем здійснюється згідно з відповідним планом, затвердженим комбінатом за погодженням з Мінпромполітики, та кошторисом робіт на 2009 рік, затвердженим в установленому порядку Мінпромполітики;

за програмою "Забезпечення міжнародного співробітництва у воєнно-промисловій і військово-технічній сферах" - на:

- підготовку та участь українських експозицій у міжнародних виставках озброєння, військової техніки, технологій, товарів подвійного використання за рішеннями Організаційного комітету з питань підготовки і участі українських експозицій у міжнародних виставках озброєння, військової техніки, технологій, товарів подвійного використання відповідно до затвердженого в установленому порядку кошторису;

- забезпечення діяльності міжурядових двосторонніх комісій з питань військово-технічного співробітництва відповідно до затвердженого в установленому порядку кошторису;

за програмою "Презентація українськими підприємствами вітчизняних товарів на міжнародній виставці "Ганновер Мессе" - на підготовку та організацію участі України у зазначеній виставці, презентацію українськими підприємствами вітчизняних товарів відповідно до затвердженого кошторису.

3. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

{ Пункт 3 в редакції Постанови КМ N 89 ( 89-2009-п ) від 04.02.2009 }

4. Відкриття Мінпромполітики та одержувачам бюджетних коштів рахунків в органах Державного казначейства, перерахування бюджетних коштів та відображення проведених операцій, пов'язаних з використанням бюджетних коштів, у бухгалтерському обліку та фінансовій звітності про виконання державного бюджету здійснюється у порядку, встановленому Державним казначейством.

{ Пункт 4 в редакції Постанови КМ N 89 ( 89-2009-п ) від 04.02.2009 }

5. Оплата виконаних робіт здійснюється розпорядником бюджетних коштів (або одержувачем) у межах установлених обсягів видатків на підставі актів фактично виконаних робіт за їх кошторисною вартістю відповідно до умов договорів.

6. Одержувач бюджетних коштів подає Мінпромполітики щомісяця, не пізніше п'ятого числа наступного періоду звіт про виконання робіт.

7. Мінпромполітики складає та подає фінансову звітність про використання бюджетних коштів, а також здійснює контроль за їх цільовим та ефективним витрачанням в установленому законодавством порядку.
