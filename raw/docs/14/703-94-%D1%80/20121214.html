Кабінет Міністрів України; Розпорядження від 26.09.1994 № 703-р

Про заходи щодо забезпечення діяльності Вищої кваліфікаційної комісії адвокатури при Кабінеті Міністрів України

Стан: Втратив чинність

Ідентифікатор: 703-94-р

Текст документа від 14.12.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 вересня 1994 р. N 703-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1144 ( 1144-2012-п ) від 05.12.2012 }

З метою забезпечення діяльності Вищої кваліфікаційної комісії адвокатури при Кабінеті Міністрів України:

Київському міськвиконкому забезпечити службовим приміщенням Вищу кваліфікаційну комісію адвокатури;

організаційно-технічне забезпечення діяльності Вищої кваліфікаційної комісії адвокатури покласти на загальний відділ Кабінету Міністрів України;

Мінзв'язку забезпечити телефонним зв'язком зазначену Комісію.

Прем'єр-міністр України В.МАСОЛ
