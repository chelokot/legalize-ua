Стан: Чинний

Текст документа від 14.09.2006:

МІНІСТЕРСТВО БУДІВНИЦТВА, АРХІТЕКТУРИ ТА ЖИТЛОВО-КОМУНАЛЬНОГО ГОСПОДАРСТВА УКРАЇНИ

НАКАЗ

14.09.2006 N 303

Зареєстровано в Міністерстві юстиції України 21 вересня 2006 р. за N 1068/12942

Про втрату чинності наказу Держбуду від 13.10.2000 N 227 "Про затвердження Типових правил розміщення малих архітектурних форм для здійснення підприємницької діяльності"

Відповідно до завдань щодо приведення регуляторних актів у сфері містобудування та будівництва у відповідність до вимог Закону України "Про засади державної регуляторної політики у сфері господарської діяльності" ( 1160-15 ) та з метою створення сприятливих умов для розвитку інвестиційної діяльності НАКАЗУЮ:

1. Вважати таким, що втратив чинність, наказ Держбуду від 13.10.2000 N 227 ( z0755-00 ) "Про затвердження Типових правил розміщення малих архітектурних форм для здійснення підприємницької діяльності", зареєстрований у Міністерстві юстиції 27.10.2000 за N 755/4976 (зі змінами за наказом Держбуду від 16.10.2002 N 59 ( z0102-03 ), зареєстрованим у Міністерстві юстиції 06.02.2003 за N 102/7423).

2. Управлінню містобудування та архітектури (Сіленко М.В.):

2.1. Подати цей наказ на державну реєстрацію до Міністерства юстиції.

2.2. Забезпечити доведення наказу до відома місцевих органів виконавчої влади та органів місцевого самоврядування.

3. Контроль за виконанням цього наказу покласти на першого заступника Міністра А.В.Беркуту.

Віце-прем'єр-міністр України, Міністр будівництва, архітектури та житлово-комунального господарства В.В.Рибак
