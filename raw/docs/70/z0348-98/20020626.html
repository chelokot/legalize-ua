N 169 від 05.05.98 Зареєстровано в Міністерстві м.Київ юстиції України 26 травня 1998 р. vd980505 vn169 за N 348/2788

Про затвердження аеропортових зборів за обслуговування повітряних суден у міжнародному аеропорту "Дніпропетровськ"

( Із змінами, внесеними згідно з Наказом Міністерства транспорту N 415 ( z0537-02 ) від 20.06.2002 )

З метою приведення аеропортових зборів у відповідність з реальними витратами аеропорту і рекомендаціями Міжнародної організації цивільної авіації (ІКАО) та згідно з постановою Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" НАКАЗУЮ:

1. Затвердити аеропортові збори за обслуговування повітряних суден у міжнародному аеропорту "Дніпропетровськ" (додаються).

2. Дозволити міжнародному аеропорту "Дніпропетровськ" при укладанні договорів з експлуатантами на аеропортове обслуговування повітряних суден при виконанні регулярних та чартерних міжнародних польотів застосовувати знижки до аеропортових зборів не більше 40 відсотків, при виконанні регулярних польотів у межах України - не більше 80 відсотків. ( Пункт 2 в редакції Наказу Міністерства транспорту N 415 ( z0537-02 ) від 20.06.2002 )

3. Управлінню тарифної та цінової політики (Осадча Т.М.) разом з Головним управлінням правового забезпечення діяльності транспорту (Логінова Л.М.) в установленому порядку зареєструвати даний наказ у Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на Першого заступника Міністра транспорту України - Голову Державної авіаційної адміністрації В.О.Максимова.

Перший заступник Міністра Л.М.Костюченко

Затверджено Наказ Міністерства транспорту України від 05.05.98 N 169

Зареєстровано в Міністерстві юстиції України 26 травня 1998 р. за N 348/2788

Аеропортові збори за обслуговування повітряних суден у міжнародному аеропорту "Дніпропетровськ"

1. За аеропортове обслуговування повітряних суден (ПС), пов'язане із забезпеченням: зльоту-посадки, обслуговування пасажирів, понаднормативної стоянки пасажирського повітряного судна, авіаційної безпеки пасажирських перевезень, стягуються аеропортові збори за встановленими розмірами.

2. Розміри аеропортових зборів

2.1. Збір за зліт-посадку повітряного судна (без обслуговування повітряного руху) за кожну тонну максимально дозволеної злітної ваги ПС становить при виконанні польотів таких сполучень:

- внутрішнього - в межах України - 4,0 USD;

- міжнародного - поза межі країн СНД - 9,75 USD.

Збір збільшується, якщо в нічний час здійснюється:

- посадка або зліт - на 20%;

- як посадка, так і зліт - на 40%.

Нічний час встановлюється у таких межах:

- з 1 квітня по 30 вересня - з 20.00 до 06.00;

- з 1 жовтня по 31 березня - з 17.00 до 08.00.

( Підпункт 2.1 пункту із змінами, внесеними згідно з Наказом Міністерства транспорту N 415 ( z0537-02 ) від 20.06.2002 )

2.2. Збір за обслуговування в аеропорту одного пасажира залежно від виду сполучень становить:

- при внутрішньому - в межах України - 5,0 USD;

- при міжнародному - поза межі країн СНД - 11,0 USD.

( Підпункт 2.2 пункту із змінами, внесеними згідно з Наказом Міністерства транспорту N 415 ( z0537-02 ) від 20.06.2002 )

2.3. Збір за понаднормативну стоянку пасажирського повітряного судна за кожну годину понаднормативної стоянки та кожну тонну максимально дозволеної злітної ваги ПС - 0,20 USD.

Нормативний час безкоштовної стоянки пасажирського ПС становить 3 години.

Збір не стягується у разі затримки ПС, спричиненої метеорологічними умовами чи діями робітників аеропорту.

2.4. Збір за забезпечення авіаційної безпеки за кожного відправленого пасажира становить - 1,5 USD.

2.5. Рейс вважається міжнародним, якщо він починається та/або закінчується за межами державного кордону України, незалежно від кількості проміжних посадок на території України. ( Пункт 2 доповнено підпунктом 2.5 згідно з Наказом Міністерства транспорту N 415 ( z0537-02 ) від 20.06.2002 )

3. Аеропортові збори наведені без нарахування податку на додану вартість.

4. Експлуатанти сплачують 50% аеропортового збору у разі технічної посадки або повернення зі старту ПС, які не пов'язані з висадкою (посадкою) пасажирів, вивантаженням (завантаженням) багажу, пошти, а також у разі виконання гуманітарних рейсів та рейсів ПС військової авіації.

Звільняються від сплати аеропортового збору за обслуговування пасажирів експлуатанти повітряних суден при виконанні польотів, пов'язаних з пошуком та рятуванням людей, а також при виконанні санітарних та випробувальних польотів.

5. Іноземні експлуатанти сплачують аеропортові збори у доларах США або у валюті, визначеній відповідною міждержавною угодою.

Українські експлуатанти сплачують аеропортові збори у національній валюті.

Перерахунок доларів США в інші валюти здійснюється за курсом Національного банку України на дату надання послуг.
