Текст документа від 03.07.2001:

МІНІСТЕРСТВО ОХОРОНИ ЗДОРОВ'Я УКРАЇНИ

НАКАЗ

N 123 від 30.03.2001 Зареєстровано в Міністерстві юстиції України 30 березня 2001 р. за N 294/5485

( Наказ втратив чинність на підставі Наказу МОЗ N 224/387 ( z0557-01 ) від 08.06.2001 )

Про внесення зміни до наказу Міністерства охорони здоров'я України від 23.10.2000 N 266 "Про затвердження Тимчасового положення про порядок надання підтвердження реєстрації лікарських засобів"

З метою виконання доручення Кабінету Міністрів України від 09.12.2000 до N 9189/10 до листа Мінекономіки від 28.11.2000 N 44-38/4702-10 "Щодо створення єдиної міжвідомчої бази даних зареєстрованих в Україні лікарських засобів", на виконання рішення міжвідомчої робочої групи, створеної наказом Міністерства охорони здоров'я України від 29.12.2000 N 371 ( v0371282-00 ) "Про створення єдиної бази даних зареєстрованих в Україні лікарських засобів", та з метою недопущення відсутності життєво необхідних ліків в державі, сировини для забезпечення їх вітчизняного виробництва, зупинки вантажів на кордоні та можливого внаслідок цього соціального вибуху НАКАЗУЮ:

1. Внести таку зміну до наказу Міністерства охорони здоров'я України від 23.10.2000 N 266 ( z0051-01 ) "Про затвердження Тимчасового положення про порядок надання підтвердження реєстрації лікарських засобів", зареєстрованого у Міністерстві юстиції України 20.01.2001 за N 51/5242:

1.1. У пункті 1 слова "1 квітня 2001 року" замінити словами "15 травня 2001 року".

2. Даний наказ погодити з Державною митною службою України, Державним комітетом України з питань регуляторної політики та підприємництва.

3. Погоджений наказ в установленому порядку подати на державну реєстрацію до Міністерства юстиції України та забезпечити його опублікування в засобах масової інформації.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Коротка О.Ш.

В.о.Міністра О.О.Бобильова
