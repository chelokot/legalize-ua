Кабінет Міністрів України; Розпорядження від 06.02.2008 № 251-р

Про віднесення посад працівників Служби розпорядника Державного реєстру виборців до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 251-2008-р

Текст документа від 19.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 лютого 2008 р. N 251-р Київ

Про віднесення посад працівників Служби розпорядника Державного реєстру виборців до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженням КМ N 447-р ( 447-2008-р ) від 19.03.2008 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Служби розпорядника Державного реєстру виборців до таких категорій посад державних службовців:

перша - керівник Служби;

друга - заступник керівника Служби, начальник управління;

третя - заступник начальника управління, завідуючий відділом у складі управління, головний консультант.

{ Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 447-р ( 447-2008-р ) від 19.03.2008 }
