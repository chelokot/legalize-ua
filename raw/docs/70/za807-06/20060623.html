Держкомпідприємництво; Наказ від 23.06.2006 № 56

Про визнання такими, що втратили чинність, наказів Державного комітету України з питань регуляторної політики та підприємництва щодо Ліцензійних умов провадження професійної діяльності на ринку цінних паперів

Реєстрація: Мін'юст України від 07.07.2006 № 807/12681

Стан: Чинний

Ідентифікатор: za807-06

Текст документа від 23.06.2006:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ПИТАНЬ РЕГУЛЯТОРНОЇ ПОЛІТИКИ ТА ПІДПРИЄМНИЦТВА

НАКАЗ

23.06.2006 N 56

Зареєстровано в Міністерстві юстиції України 7 липня 2006 р. за N 807/12681

Про визнання такими, що втратили чинність, наказів Державного комітету України з питань регуляторної політики та підприємництва щодо Ліцензійних умов провадження професійної діяльності на ринку цінних паперів

Відповідно до Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ), Закону України від 06.09.2005 N 2800 ( 2800-15 ) "Про внесення змін до деяких законів України щодо ліцензування професійної діяльності на ринку цінних паперів" НАКАЗУЮ:

1. Визнати такими, що втратили чинність, накази Державного комітету України з питань регуляторної політики та підприємництва:

від 14.03.2001 N 49 ( za318-01 ) "Про затвердження Ліцензійних умов провадження професійної діяльності на ринку цінних паперів", зареєстрований в Міністерстві юстиції України 06.04.2001 за N 318/5509;

від 29.11.2001 N 145 ( z1043-01 ) "Про затвердження змін та доповнень до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів", зареєстрований в Міністерстві юстиції України 17.12. 2001 за N 1043/6234;

від 06.08.2002 N 80 ( z0766-02 ) "Про затвердження змін та доповнень до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів", зареєстрований в Міністерстві юстиції України 17.09.2002 за N 766/7054;

від 07.11.2003 N 117 ( z1095-03 ) "Про затвердження Змін та доповнень до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів", зареєстрований в Міністерстві юстиції України 27.11.2003 за N 1095/8416;

від 24.12.2003 N 137 ( z0029-04 ) "Про затвердження Змін та доповнень до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів", зареєстрований в Міністерстві юстиції України 13.01.2004 за N 29/8628;

від 31.03.2005 N 26 ( za432-05 ) "Про затвердження Змін та доповнень до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів", зареєстрований в Міністерстві юстиції України 25.04.2005 за N 432/10712.

2. Управлінню ліцензування (Іванченко О.Б.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням цього наказу покласти на першого заступника Голови Держпідприємництва України Ващенка К.О.
