РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про внесення змін до Розпорядження Президента України від 16 вересня 1996 року N 275

На зміну пункту 4 Розпорядження Президента України від 16 вересня 1996 року N 275 ( 275/96-рп ) "Про створення Міжвідомчої комісії з питань співробітництва України в рамках Центральноєвропейської ініціативи":

1. Призначити САГАЧА Ігоря Михайловича - заступника начальника Управління європейського регіонального співробітництва Міністерства закордонних справ України - національним координатором у справах Центральноєвропейської ініціативи від України.

2. Звільнити НІКІТЮКА Віктора Олеговича від виконання функцій національного координатора у справах Центральноєвропейської ініціативи від України.

Президент України Л.КУЧМА
