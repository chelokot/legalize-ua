( Розпорядження втратило чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про Міжвідомчу комісію з питань співробітництва України в рамках Центральноєвропейської ініціативи

На зміну пунктів 2 і 4 Розпорядження Президента України від 16 вересня 1996 року N 275 ( 275/96-рп ) "Про створення Міжвідомчої комісії з питань співробітництва України в рамках Центральноєвропейської ініціативи" (із змінами, внесеними Розпорядженням Президента України від 3 вересня 1997 року N 311 ( 311/97-рп ):

1. Призначити БЕРШЕДУ Євгена Романовича - першого заступника Міністра закордонних справ України - головою Міжвідомчої комісії з питань співробітництва України в рамках Центральноєвропейської ініціативи, увільнивши від виконання цих обов'язків Б. Гудиму.

2. Призначити КОРСУНСЬКОГО Сергія Володимировича - виконуючого обов'язки начальника Управління економічного та наукового співробітництва Міністерства закордонних справ України - національним координатором у справах Центральноєвропейської ініціативи від України, увільнивши від виконання цих обов'язків І. Сагача.

Президент України Л.КУЧМА
