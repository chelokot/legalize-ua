Про внесення змін до наказу ДПА від 01.07.2002 N 301

Відповідно до пункту 1 статті 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ) та з метою вдосконалення оперативного обліку платежів, що надходять до бюджету, контроль за справлянням яких здійснюється органами державної податкової служби згідно з чинними нормативно-правовими актами України, НАКАЗУЮ:

1. Затвердити Зміни до Порядку подання фінансовими установами органам державної податкової служби повідомлень про відкриття/закриття рахунків платників податків і зборів (обов'язкових платежів) та заповнення розрахункових документів у разі сплати (стягнення) платежів до бюджету або повернення платежів з бюджету, затвердженого наказом Державної податкової адміністрації України від 1 липня 2002 року N 301 ( z0735-02 ), зареєстрованого в Міністерстві юстиції України 6 вересня 2002 року за N 735/7023 (із змінами), що додаються.

2. Департаменту обліку та звітності (Ніколайченко В.І.) подати цей наказ до Міністерства юстиції України на державну реєстрацію.

3. Департаменту обліку та звітності (Ніколайченко В.І.), Департаменту інформатизації процесів оподаткування (Годунов О.Л.) забезпечити приведення функціонувального програмного забезпечення у відповідність до цього наказу в порядку та терміни, визначені для створення інформаційних систем.

4. Контроль за виконанням наказу покласти на заступника Голови Боєнка Л.Є.

Голова А.І.Брезвін

ЗМІНИ до Порядку подання фінансовими установами органам державної податкової служби повідомлень про відкриття/закриття рахунків платників податків і зборів (обов'язкових платежів) та заповнення розрахункових документів у разі сплати (стягнення) платежів до бюджету або повернення платежів з бюджету ( z0735-02 )

У додатку 4 до Порядку ( z0735-02 ):

1. Поле N 7 пункту 1 доповнити новим абзацом такого змісту:

"У разі погашення податкових векселів (податкових розписок) коштами при заповненні платіжного документа в резервному полі необхідно проставляти номер векселя".

2. У пункті 2:

2.1. Підпункт "д" виключити.

У зв'язку з цим підпункти "е" та "є" вважати відповідно підпунктами "д" та "е".

2.2. Додати нові підпункти "є" та "ж" такого змісту:

"є) погашення платниками податків податкових векселів коштами:

Приклад заповнення поля "Призначення платежу" в разі погашення платниками податків податкових векселів коштами.

------------------------------------------------------------------

| * |;109 |; | ;оплата податкового |; |; | ;ХХХХХХХХХХ |

| | | | векселя | | | |

|---+-----+----+-----------------------+----+----+---------------|

| 1 | 2 | 3 | 4 | 5 | 6 | 7 |

------------------------------------------------------------------

1 - службовий код ("*");

2 - код виду сплати ("109" - оплата податкового векселя);

3 - не заповнюється;

4 - друкується роз'яснювальна інформація про призначення платежу;

5 - не заповнюється;

6 - не заповнюється;

7 - друкується номер векселя, у рахунок погашення якого здійснюється платіж;

ж) погашення банком податкових векселів (податкових розписок) коштами:

Приклад заповнення поля "Призначення платежу" в разі погашення банком податкових векселів (податкових розписок) коштами за підприємство "Надія", яке має код 30611145:

------------------------------------------------------------------

| * |;109 |;30611145|;оплата податкового |; |; | ;ХХХХХХХХХХ |

| | | |векселя (податкової | | | |

| | | |розписки) | | | |

|---+-----+---------+--------------------+----+----+-------------|

| 1 | 2 | 3 | 4 | 5 | 6 | 7 |

------------------------------------------------------------------

1 - службовий код ("*");

2 - код виду сплати ("109" - оплата податкового векселя (податкової розписки);

3 - код за ЄДРПОУ (номер за ДРФО) платника, за якого здійснюється оплата (підприємство "Надія", яке має код за ЄДРПОУ 30611145);

4 - друкується роз'яснювальна інформація про призначення платежу;

5 - не заповнюється;

6 - не заповнюється;

7 - друкується номер податкового векселя (податкової розписки)".

"125 Авансові внески, нараховані на суму дивідендів та прирівняних до них платежів *".
