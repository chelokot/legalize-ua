Кабінет Міністрів України; Розпорядження від 28.12.1994 № 953-р

Про віднесення посад спеціалістів органів виконання покарань до сьомої категорії посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 953-94-р

Текст документа від 06.05.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 грудня 1994 р. N 953-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 174-р ( 174-2001-р ) від 06.05.2001 )

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести до сьомої категорії державних службовців посади спеціалістів органів виконання покарань, які не мають спеціальних звань:

начальника фінансової частини (відділу), заступника начальника фінансової частини (відділу), головного бухгалтера, заступника начальника спеціального відділу, спеціаліста з бухгалтерського обліку, спеціалістів відділу (оперативного, оперативно-режимного, спеціального, підготовки та комплектування кадрів, інтендантського і господарського забезпечення, планово-виробничого (тільки для контрагентських установ).

Прем'єр-міністр України В.МАСОЛ
