ЦЕНТРАЛЬНА ВИБОРЧА КОМІСІЯ

11.03.2003 N 13

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 44 ( v0044359-08 ) від 14.07.2008 }

Про внесення змін у додаток 1 до постанови Центральної виборчої комісії від 24 березня 1999 року N 21 "Про Координаційну раду при Центральній виборчій комісії з питань контролю за дотриманням законодавства про фінансування виборів, референдумів"

З метою ефективного виконання основних функцій Координаційною радою з питань контролю за дотриманням законодавства в частині фінансування виборів, референдумів, утвореною при Центральній виборчій комісії відповідно до постанови Центральної виборчої комісії від 24 березня 1999 року N 21 ( v0021359-99 ) "Про Координаційну раду при Центральній виборчій комісії з питань контролю за дотриманням законодавства про фінансування виборів, референдумів", враховуючи пункт 6 Положення про Координаційну раду при Центральній виборчій комісії з питань контролю за дотриманням законодавства про фінансування виборів, референдумів, керуючись статтею 11 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ), Центральна виборча комісія постановляє:

Внести зміни у додаток 1 до постанови Центральної виборчої комісії від 24 березня 1999 року N 21 ( v0021359-99 ) "Про Координаційну раду при Центральній виборчій комісії з питань контролю за дотриманням законодавства про фінансування виборів, референдумів", виклавши його у новій редакції (додається).

Заступник Голови Центральної виборчої комісії М.ДЕМЯНЕНКО
