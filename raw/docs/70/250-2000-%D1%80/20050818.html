Кабінет Міністрів України; Розпорядження від 05.06.2000 № 250-р

Про утворення робочої групи для опрацювання питань, пов'язаних з подальшим функціонуванням державних холдингових та акціонерних компаній

Стан: Втратив чинність

Ідентифікатор: 250-2000-р

Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 червня 2000 р. N 250-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

( Із змінами, внесеними згідно з Розпорядженнями КМ N 382-р ( 382-2000-р ) від 28.09.2000 N 413-р ( 413-2000-р ) від 20.10.2000 N 200-р ( 200-2003-р ) від 07.04.2003 )

1. Для опрацювання питань, пов'язаних з подальшим функціонуванням державних холдингових та акціонерних компаній, статутні фонди яких сформовано за рахунок закріплених у державній власності пакетів акцій, утворити робочу групу у складі згідно з додатком.

2. Міністерствам, іншим центральним органам виконавчої влади подати відповідно до компетенції у місячний термін робочій групі висновки з питань, зазначених у пункті 1 цього розпорядження, разом з пропозиціями щодо оптимального варіанту приватизації державних холдингових та акціонерних компаній.

3. Робочій групі опрацювати пропозиції міністерств, інших центральних органів виконавчої влади і в двомісячний термін після прийняття цього розпорядження подати до Кабінету Міністрів України свої висновки, а у разі необхідності - проект відповідних актів законодавства.

4. Установити, що проекти рішень Кабінету Міністрів України з питань утворення державних холдингових та акціонерних компаній підлягають узгодженню з робочою групою. ( Розпорядження доповнено пунктом 4 згідно з Розпорядженням КМ N 413-р ( 413-2000-р ) від 20.10.2000 )

5. Контроль за виконанням цього розпорядження покласти на Першого віце-прем'єр-міністра України Єханурова Ю.І.
