КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 жовтня 2010 р. N 947 Київ

Про запровадження електронної соціальної картки

{ Із змінами, внесеними згідно з Постановами КМ N 1018 ( 1018-2010-п ) від 10.11.2010 N 1113 ( 1113-2010-п ) від 08.12.2010 N 666 ( 666-2011-п ) від 22.06.2011 N 1250 ( 1250-2011-п ) від 07.12.2011 }

{ У тексті Постанови слова "Харківської та Чернівецької" в усіх відмінках замінено словами "Київської, Харківської та Чернівецької" у відповідному відмінку згідно з Постановою КМ N 1018 ( 1018-2010-п ) від 10.11.2010 }

Києві" - словами "Автономній Республіці Крим, м. Києві" згідно з Постановою КМ N 1113 ( 1113-2010-п ) від 08.12.2010 }

З метою створення єдиної інформаційно-аналітичної системи обліку та управління коштами соціальної сфери і запровадження електронної соціальної картки Кабінет Міністрів України постановляє:

1. Визначити, що Міністерство соціальної політики: { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1250 ( 1250-2011-п ) від 07.12.2011 }

є головним виконавцем та координатором роботи із запровадження електронної соціальної картки;

забезпечує організацію, спрямування і координацію роботи з підготовки проектів Концепції та Програми запровадження електронної соціальної картки і подання їх на розгляд Кабінету Міністрів України.

2. Віце-прем'єр-міністрові України - Міністрові соціальної політики: { Абзац перший пункту 2 в редакції Постанови КМ N 1250 ( 1250-2011-п ) від 07.12.2011 }

утворити та очолити Міжвідомчу комісію з питань запровадження електронної соціальної картки (далі - Міжвідомча комісія), включивши до її складу представників заінтересованих центральних органів виконавчої влади, Ради міністрів Автономної Республіки Крим, Київської міської, Київської, Харківської та Чернівецької обласних державних адміністрацій, а також за згодою представників об'єднань роботодавців і профспілкових об'єднань, які мають статус всеукраїнських, та експертів;

у тижневий строк після утворення Міжвідомчої комісії затвердити її персональний склад та положення про комісію, передбачивши в ньому вивчення міжнародного досвіду запровадження електронної соціальної картки із застосуванням технологій різних платіжних систем та проведення технічного, організаційного та фінансового аналізу передумов для створення єдиної інформаційно-аналітичної системи обліку та управління коштами соціальної сфери і запровадження електронної соціальної картки на всій території України.

3. Чернівецькій обласній державній адміністрації забезпечити проведення в 2011-2012 роках експерименту із створення інформаційно-аналітичної системи регіонального управління та управління коштами соціальної сфери.
