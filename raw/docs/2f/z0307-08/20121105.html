10.04.2008 N 552/5

Зареєстровано в Міністерстві юстиції України 15 квітня 2008 р. за N 307/14998

Про внесення змін до деяких нормативно-правових актів Мін'юсту

{ Із змінами, внесеними згідно з Наказом Міністерства юстиції N 1535/5 ( z1747-12 ) від 17.10.2012 }

Відповідно до Закону України "Про виконавче провадження" ( 606-14 ) та з метою спрощення процедури обліку бланків документів виконавчого провадження та бланків для копій документів виконавчого провадження НАКАЗУЮ:

1. Визнати таким, що втратив чинність, наказ Міністерства юстиції України від 26.09.2001 N 53/5 ( z0843-01 ) "Про затвердження Положення про порядок постачання, зберігання, обліку й витрачання бланків документів виконавчого провадження та бланків для копій документів виконавчого провадження", зареєстрований в Мін'юсті України 26.09.2001 за N 843/6034 (із змінами).

{ Пункт 2 втратив чинність на підставі Наказу Міністерства юстиції N 1535/5 ( z1747-12 ) від 17.10.2012 }

3. Департаменту державної виконавчої служби:

3.1. Подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами).

3.2. Довести цей наказ до відома Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, головних управлінь юстиції в областях, мм. Києві та Севастополі.

4. Контроль за виконанням цього наказу покласти на заступника Міністра юстиції України В.І.Цоклана.
