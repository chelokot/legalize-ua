Кабінет Міністрів України; Постанова від 14.04.1999 № 593

Про сприяння зовнішньоекономічній діяльності

Стан: Втратив чинність

Ідентифікатор: 593-99-п

Текст документа від 01.01.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 квітня 1999 р. N 593 Київ

Про сприяння зовнішньоекономічній діяльності

{ Із змінами, внесеними згідно з Постановами КМ N 390 ( 390-2002-п ) від 29.03.2002 N 810 ( 810-2004-п ) від 29.06.2004 N 455 ( 455-2009-п ) від 06.05.2009 N 1016 ( 1016-2011-п ) від 05.10.2011 }

На виконання Указу Президента України від 3 лютого 1998 р. N 79 ( 79/98 ) "Про усунення обмежень, що стримують розвиток підприємницької діяльності" Кабінет Міністрів України постановляє:

1. Надати право Державній митній службі під час провадження окремо визначеними підприємствами - резидентами України зовнішньоекономічної діяльності не застосовувати під час митного контролю і митного оформлення товарів і транспортних засобів заходів нетарифного регулювання та інших обмежень, установлених постановами Кабінету Міністрів України від 6 травня 1996 р. N 484 ( 484-96-п ) "Про затвердження переліку шляхів і напрямків транзиту підакцизних товарів через територію України та пункти на митному кордоні, через які здійснюється ввезення і вивезення цих товарів, та граничні терміни транзиту підакцизних товарів автомобільним і залізничним транспортом через територію України" (ЗП України, 1996 р., N 10, ст. 316, N 16, ст. 443; Офіційний вісник України, 1997 р., число 17, с. 43, число 24, с. 107, число 38, с. 4; 1998 р., N 28, ст. 1046, ст. 1057), від 12 серпня 1996 р. N 938 ( 938-96-п ) "Про подальше посилення контролю за ввезенням, вивезенням та переміщенням транзитом через територію України алкогольних напоїв і тютюнових виробів, на які встановлено акцизний збір" (ЗП України, 1996 р., N 16, ст. 443, N 20, ст. 566; Офіційний вісник України, 1997 р., число 5, с. 143, число 18, с. 106, число 28, с. 111, число 52, с. 154; 1998 р., N 1, ст. 11, із доповненнями, внесеними постановою Кабінету Міністрів України від 11 грудня 1996 р, N 1473 ( 1473-96-п ).

{ Пункт 1 із змінами, внесеними згідно з Постановами КМ N 390 ( 390-2002-п ) від 29.03.2002, N 810 ( 810-2004-п ) від 29.06.2004, N 455 ( 455-2009-п ) від 06.05.2009, N 1016 ( 1016-2011-п ) від 05.10.2011 }

2. Державній митній службі:

затвердити разом з Міністерством економіки та з питань європейської інтеграції і Державною податковою адміністрацією критерії оцінки та порядок визначення підприємств - резидентів України, під час провадження якими зовнішньоекономічної діяльності можуть не застосовуватися заходи нетарифного регулювання та інші обмеження, установлені постановами Кабінету Міністрів України; { Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 455 ( 455-2009-п ) від 06.05.2009 }

визначити критерії оцінювання та механізм визначення підприємств - резидентів України, щодо товарів і транспортних засобів яких може встановлюватися спрощений порядок застосування процедур митного контролю і митного оформлення. { Абзац третій пункту 2 в редакції Постанови КМ N 455 ( 455-2009-п ) від 06.05.2009 }

{ Пункт 2 в редакції Постанови КМ N 810 ( 810-2004-п ) від 29.06.2004 }

3. Державній митній службі визначити за погодженням з Міністерством економіки та з питань європейської інтеграції і Державною податковою адміністрацією та постійно оновлювати перелік підприємств - резидентів України, стосовно яких у разі митного оформлення товарів і транспортних засобів можуть не застосовуватися заходи нетарифного регулювання та інші обмеження, установлені постановами Кабінету Міністрів України згідно з пунктом 1 цієї постанови. Зазначений перелік підлягає широкому оприлюдненню у засобах масової інформації. ( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 810 ( 810-2004-п ) від 29.06.2004 )

4. У разі істотних порушень митного чи податкового законодавства підприємством - резидентом України, яке користується режимом сприяння, встановленим пунктом 1 цієї постанови, воно виключається з переліків підприємств, зазначених у пунктах 2 і 3 цієї постанови і провадить зовнішньоекономічну діяльність на загальних підставах. ( Абзац перший пункту 4 із змінами, внесеними згідно з Постановою КМ N 810 ( 810-2004-п ) від 29.06.2004 )

( Абзац другий пункту 4 виключено на підставі Постанови КМ N 810 ( 810-2004-п ) від 29.06.2004 )

5. З метою профілактики порушень митного і податкового законодавства та превентивного виявлення таких порушень дозволити проведення Державною митною службою разом з Міністерством економіки та з питань європейської інтеграції та Державною податковою адміністрацією спільних перевірок зовнішньоекономічної діяльності, що провадиться підприємством - резидентом України, яке користується режимом сприяння, встановленим пунктом 1 цієї постанови, не частіше одного разу на шість місяців. ( Пункт 5 із змінами, внесеними згідно з Постановою КМ N 810 ( 810-2004-п ) від 29.06.2004 )
