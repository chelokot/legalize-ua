Це Положення регулює порядок продажу нафти, газового конденсату, природного, скрапленого газу та вугілля на внутрішньому ринку України, встановлює порядок організації та проведення аукціону, визначає повноваження аукціонного комітету та бірж, на базі яких проводяться аукціони з продажу нафти, газового конденсату, природного, скрапленого газу та вугілля, зміст аукціонних угод і гарантії їх виконання. { Абзац перший пункту 1 із змінами, внесеними згідно з Постановами КМ N 631 ( 631-2001-п ) від 06.06.2001, N 619 ( 619-2006-п ) від 11.05.2006 }

Продаж скрапленого газу для потреб населення здійснюється на спеціалізованих аукціонах, на яких виробники скрапленого газу заявляють весь обсяг продукції, виробленої після закінчення попереднього спеціалізованого аукціону, в якому вони брали участь, та, які проводяться на умовах, визначених цим Положенням. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1736 ( 1736-2004-п ) від 23.12.2004 )

Спеціалізовані аукціони з продажу скрапленого газу проводяться окремо від інших аукціонів.

аукціон - спосіб продажу нафти, газового конденсату, природного, скрапленого газу та вугілля, згідно з яким покупцем визнається учасник аукціону, який запропонував найвищу ціну за нафту, газовий конденсат, природний, скраплений газ та вугілля відповідно до умов, визначених цим Положенням і типовим договором купівлі-продажу; { Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 1825 ( 1825-2006-п ) від 27.12.2006 }

нафта - нафта, що видобувається з родовищ суб'єктом підприємницької діяльності, який отримав відповідну ліцензію;

газовий конденсат - газовий конденсат, що видобувається з родовищ суб'єктом підприємницької діяльності, який отримав відповідну ліцензію, і проходить попередню переробку;

природний газ - природний газ власного видобутку суб'єктів підприємницької діяльності, крім зазначених у підпункті 1 пункту 2 постанови Кабінету Міністрів України від 27 грудня 2001 р. N 1729 ( 1729-2001-п ) "Про забезпечення споживачів природним газом" (Офіційний вісник України, 2001 р., N 52, ст. 2347; 2006 р., N 10, ст. 616, N 24, ст. 1769); { Пункт 2 доповнено абзацом згідно з Постановою КМ N 1825 ( 1825-2006-п ) від 27.12.2006 }

скраплений газ - газ вуглеводневий паливний для комунально-побутових потреб;

вугілля - вугілля кам'яне та буре для потреб населення і вугілля коксівне для потреб коксівного виробництва, що видобувається з родовищ суб'єктом підприємницької діяльності, який отримав відповідну ліцензію, а також продукти їх переробки на збагачувальних або брикетних фабриках; ( Абзац пункту 2 із змінами, внесеними згідно з Постановою КМ N 818 ( 818-2000-п ) від 17.05.2000 )

продавці - суб'єкти підприємницької діяльності, які видобувають нафту, газовий конденсат та вугілля на території України за отриманою відповідною ліцензією; виробники скрапленого газу, а також інші юридичні особи, які отримують нафту, газовий конденсат, скраплений газ та вугілля згідно з договорами про спільну діяльність із суб'єктами підприємницької діяльності, які отримали відповідну ліцензію, та іншими цивільно-правовими угодами, у тому числі зовнішньоекономічними контрактами; установи (підприємства, організації), уповноважені Кабінетом Міністрів України реалізувати частину видобутої нафти, газового конденсату, скрапленого газу та вугілля, що належить державі згідно з угодами про розподіл продукції, а також нафту, газовий конденсат, скраплений газ та вугілля, конфісковані або визнані відповідно до законодавства безхазяйним майном; уповноважені особи з продажу предмета податкової застави у разі, коли предметом такої застави є нафта, газовий конденсат, скраплений газ та вугілля; державна акціонерна компанія, яка утворюється на базі Держкомрезерву, що ліквідується, а також підприємства системи державного матеріального резерву, суб'єкти підприємницької діяльності - підприємства з видобутку природного газу; { Абзац восьмий пункту 2 із змінами, внесеними згідно з Постановою КМ N 1825 ( 1825-2006-п ) від 27.12.2006 }

покупці - суб'єкти підприємницької діяльності та інші юридичні особи всіх форм власності, резиденти України, які бажають придбати нафту, газовий конденсат, природний, скраплений газ та вугілля відповідно до умов аукціону від свого імені та за власний рахунок і не перебувають у стані ліквідації або проти яких не порушено справу про банкрутство; { Абзац пункту 2 із змінами, внесеними згідно з Постановою КМ N 1825 ( 1825-2006-п ) від 27.12.2006 }

Організація аукціону

6. Пропозиції з продажу нафти, газового конденсату, природного, скрапленого газу та вугілля, оформлені за затвердженим зразком, попередньо погоджені та зареєстровані комітетом, з метою своєчасного інформування біржею покупців подаються продавцями на біржу не пізніше ніж за п'ять робочих днів до дати проведення аукціону. Рішення про допуск біржею до аукціону щодо пропозицій, які надійшли після визначеного терміну, чи внесення зміни до раніше поданих пропозицій, приймається комітетом окремо. ( Пункт 25 із змінами, внесеними згідно з Постановою КМ N 631 ( 631-2001-п ) від 06.06.2001 )

26. Комітет має право припинити аукціон, якщо ціна 1 тонни нафти, газового конденсату, скрапленого газу, вугілля або ціна 1000 куб. метрів природного газу з однаковими якісними характеристиками і базисними умовами поставки за результатами аукціонного торгу підвищується більш як на 15 відсотків ціни попереднього аукціону або більш як на 30 відсотків середньозважених цін попередньої аукціонної сесії, розрахованих за групами продукції з однаковими базисними умовами поставки та якісними характеристиками.

{ Пункт 26 із змінами, внесеними згідно з Постановою КМ N 1825 ( 1825-2006-п ) від 27.12.2006 }

Аукціонні угоди. Порядок оформлення аукціонних документів

27. За підсумками аукціону між покупцем і продавцем укладаються аукціонні угоди в два етапи:

на першому - підписується аукціонне свідоцтво;

на другому - укладаються договори купівлі-продажу.

28. Після закінчення аукціону складається за затвердженою формою аукціонне свідоцтво у чотирьох примірниках, яке підписується уповноваженими особами покупця, продавця, біржі та комітету. ( Пункт 28 в редакції Постанови КМ N 631 ( 631-2001-п ) від 06.06.2001 )

29. Аукціонне свідоцтво є підставою для укладення договору купівлі-продажу між продавцем і покупцем нафти, газового конденсату, природного, скрапленого газу та вугілля. ( Абзац перший пункту 29 із змінами, внесеними згідно з Постановою КМ N 631 ( 631-2001-п ) від 06.06.2001 )

Договір купівлі-продажу в кожному випадку укладається окремо за результатами спеціалізованого аукціону з продажу скрапленого газу.

{ Пункт 29 із змінами, внесеними згідно з Постановою КМ N 1825 ( 1825-2006-п ) від 27.12.2006 }

30. На підставі аукціонного свідоцтва покупець і продавець протягом трьох днів зобов'язані підписати договір купівлі-продажу.

Згідно з умовами договору купівлі-продажу продавець зобов'язаний поставити нафту, газовий конденсат, природний, скраплений газ та вугілля покупцеві відповідно до визначеного базису поставки та якісної характеристики, а покупець - прийняти їх та оплатити.

{ Пункт 30 із змінами, внесеними згідно з Постановою КМ N 1825 ( 1825-2006-п ) від 27.12.2006 }

31. Якщо уповноважена особа продавця чи покупця - переможця аукціону відмовляється від підписання аукціонного свідоцтва після закінчення аукціонних торгів або продавець чи покупець відмовляються від підписання договору купівлі-продажу у визначений цим Положенням термін, результати аукціону щодо цих лотів за рішенням комітету анулюються. За невиконання зобов'язань передбачаються штрафні санкції в розмірах, установлених законодавством.

Порядок розрахунків за придбані нафту, газовий конденсат, скраплений газ та вугілля

32. Для відшкодування біржі витрат, пов'язаних з організацією та проведенням аукціону, з покупців, які підписали аукціонне свідоцтво, справляється комісійний збір у розмірі 0,5 відсотка загальної вартості придбаних обсягів нафти, газового конденсату, природного, скрапленого газу та вугілля. В разі потреби комітет змінює розмір комісійного збору. ( Абзац перший пункту 32 із змінами, внесеними згідно з Постановою КМ N 631 ( 631-2001-п ) від 06.06.2001 )

Якщо уповноважена особа покупця не з'явилася на аукціон без поважних причин, покупцеві повертається 50 відсотків суми попереднього внеску, а решта перераховується відповідному продавцеві.

У разі коли результати аукціону згідно з пунктом 31 цього Положення анулюються з вини покупця, попередній внесок йому не повертається, а перераховується продавцеві за вирахуванням комісійного збору біржі. ( Абзац третій пункту 32 із змінами, внесеними згідно з Постановою КМ N 631 ( 631-2001-п ) від 06.06.2001 )

Перерахування покупцем комісійного збору в повному обсязі є обов'язковою умовою реєстрації біржею договору купівлі-продажу. ( Пункт 32 доповнено абзацом згідно з Постановою КМ N 631 ( 631-2001-п ) від 06.06.2001 )

{ Пункт 32 із змінами, внесеними згідно з Постановою КМ N 1825 ( 1825-2006-п ) від 27.12.2006 }

33. Якщо покупці, які подавали заявки на участь в аукціоні, не придбали жодного лота, попередній внесок у повному обсязі повертається їм протягом трьох робочих днів, крім випадків, передбачених у пункті 32 цього Положення.

34. Усі права та обов'язки покупця і продавця та порядок проведення розрахунків за угодою, укладеною на аукціоні, обумовлюються у підписаному ними договорі купівлі-продажу. Усі розрахунки проводяться безпосередньо між продавцем та покупцем з урахуванням попереднього внеску покупця, перерахованого ним на поточний рахунок біржі для участі в аукціоні.

За вимогою продавця розрахунки за укладеною на аукціоні угодою можуть здійснюватися через біржу.

Продавець виконує свої зобов'язання щодо поставки нафти, газового конденсату, природного, скрапленого газу та вугілля після отримання коштів від покупця у повному обсязі відповідно до умов договору купівлі-продажу. Якщо покупець не перерахував кошти у повному обсязі на рахунок продавця в терміни, визначені договором купівлі-продажу, продавець негайно повідомляє про це комітет.

{ Пункт 34 в редакції Постанови КМ N 631 ( 631-2001-п ) від 06.06.2001; із змінами, внесеними згідно з Постановою КМ N 1825 ( 1825-2006-п ) від 27.12.2006 }

35. У разі ненадання біржі відповідних документів у термін, зазначений у договорі купівлі-продажу, біржа протягом трьох робочих днів повертає кошти покупцеві, а договір вважається неукладеним. ( Пункт 35 із змінами, внесеними згідно з Постановою КМ N 631 ( 631-2001-п ) від 06.06.2001 )
