ПОСТАНОВА від 17 червня 2005 р. N 484 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

Про внесення змін у додаток до постанови Кабінету Міністрів України від 15 жовтня 2003 р. N 1608

Кабінет Міністрів України постановляє:

Внести у додаток до постанови Кабінету Міністрів України від 15 жовтня 2003 р. N 1608 ( 1608-2003-п ) "Про утворення Міжвідомчої робочої групи з питань фінансування проектів місцевого розвитку без надання державної гарантії" (Офіційний вісник України, 2003 р., N 42, ст. 2208) зміни, виклавши його у редакції, що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 27

Додаток до постанови Кабінету Міністрів України від 15 жовтня 2003 р. N 1608 ( 1608-2003-п ) (у редакції постанови Кабінету Міністрів України від 17 червня 2005 р. N 484)

СКЛАД Міжвідомчої робочої групи з питань фінансування проектів місцевого розвитку без надання державної гарантії
