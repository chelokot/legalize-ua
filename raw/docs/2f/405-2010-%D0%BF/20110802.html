Кабінет Міністрів України; Постанова, Перелік від 09.06.2010 № 405

Про затвердження переліку суб'єктів літакобудування, щодо яких запроваджуються тимчасові заходи державної підтримки

Стан: Чинний

Ідентифікатор: 405-2010-п

Текст документа від 02.08.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 червня 2010 р. N 405 Київ

Про затвердження переліку суб'єктів літакобудування, щодо яких запроваджуються тимчасові заходи державної підтримки

{ Із змінами, внесеними згідно з Постановами КМ N 124 ( 124-2011-п ) від 02.02.2011 N 812 ( 812-2011-п ) від 27.07.2011 }

Відповідно до статті 2 Закону України "Про розвиток літакобудівної промисловості" ( 2660-14 ) Кабінет Міністрів України постановляє:

1. Затвердити перелік суб'єктів літакобудування, щодо яких запроваджуються тимчасові заходи державної підтримки, що додається.

2. Державному агентству з управління державними корпоративними правами та майном забезпечити здійснення контролю за відповідністю суб'єктів літакобудування, включених до затвердженого цією постановою переліку, вимогам, установленим Законом України "Про розвиток літакобудівної промисловості" ( 2660-14 ), та у разі виявлення невідповідності подати Кабінетові Міністрів України пропозиції щодо виключення суб'єкта (суб'єктів) літакобудування із зазначеного переліку.
