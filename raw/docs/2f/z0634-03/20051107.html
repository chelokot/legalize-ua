ДЕРЖАВНИЙ КОМІТЕТ ЛІСОВОГО ГОСПОДАРСТВА УКРАЇНИ

НАКАЗ

02.06.2003 N 91

Зареєстровано в Міністерстві юстиції України 23 липня 2003 р. за N 634/7955

( Наказ втратив чинність на підставі Наказу Державного комітету лісового господарства N 412 ( z1274-05 ) від 07.09.2005 )

Про впорядкування умов оплати праці працівників Української державної лісонасіннєвої інспекції Державного комітету лісового господарства України

( Із змінами, внесеними згідно з Наказами Державного комітету лісового господарства N 26 ( z0466-04 ) від 27.02.2004 N 162 ( z1225-04 ) від 14.09.2004 N 18 ( z0230-05 ) від 25.01.2005 N 292 ( z0639-05 ) від 22.04.2005 )

( У назві і тексті наказу слова "Українська державна лісонасіннєва станція "Укрдержліснасіння", "лісонасіннєва станція", "державна та зональна лісонасіннєва станція" замінено відповідно словами "Українська державна лісонасіннєва інспекція", "лісонасіннєва інспекція" та "державна зональна лісонасіннєва інспекція" згідно з Наказом Державного комітету лісового господарства N 26 ( z0466-04 ) від 27.02.2004 )

На виконання постанов Кабінету Міністрів України від 7 лютого 2001 року N 134 ( 134-2001-п ) "Про впорядкування умов оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери", від 10 січня 2002 року N 18 ( 18-2002-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" і від 19 травня 2003 року N 740 ( 740-2003-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів і організацій окремих галузей бюджетної сфери" та з метою впорядкування умов оплати праці працівників Української державної лісонасіннєвої інспекції НАКАЗУЮ:

1. Затвердити схеми посадових окладів (ставок заробітної плати) керівних працівників, фахівців, службовців, робітників Української державної лісонасіннєвої інспекції Державного комітету лісового господарства України згідно з додатками 1, 2.

2. Установити, що посадові оклади заступників керівників Української державної зональної лісонасіннєвих інспекцій "Укрдержліснасіння" (далі - лісонасіннєві інспекції) та заступників керівників структурних підрозділів цих лісонасіннєвих інспекцій встановлюються на 5-15 відсотків, а головних бухгалтерів на 10-30 відсотків нижче ніж посадовий оклад відповідного керівника, визначений за схемами посадових окладів, затверджених цим наказом.

3. Установити:

1) що посадові оклади (ставки заробітної плати) працівників лісонасіннєвих інспекцій, які мають почесне звання, підвищуються: ( Абзац перший підпункту 1 пункту 3 із змінами, внесеними згідно з Наказом Державного комітету лісового господарства N 292 ( z0639-05 ) від 22.04.2005 )

а) за почесні звання України, СРСР, союзних республік СРСР: "народний" - на 40 відсотків, "заслужений" - на 20 відсотків посадового окладу.

Посадові оклади працівників лісонасіннєвих інспекцій підвищуються, якщо діяльність працівників за профілем відповідає почесному званню.

( Підпункт 1 "а" пункту 3 в редакції Наказу Державного комітету лісового господарства N 292 ( z0639-05 ) від 22.04.2005 )

( Підпункт 1 "б" пункту 3 виключено на підставі Наказу Державного комітету лісового господарства N 292 ( z0639-05 ) від 22.04.2005 )

2) що місячні оклади прибиральників приміщень, які використовують дезінфекційні засоби, а також тих, що зайняті прибиранням туалетів, підвищуються на 10 відсотків;

3) доплати працівникам:

а) у розмірі до 50 відсотків посадового окладу відсутнього працівника або за вакантною посадою:

за виконання обов'язків тимчасово відсутніх працівників;

за суміщення професій (посад);

за розширення зони обслуговування або збільшення обсягу виконуваних робіт.

Зазначені види доплат не встановлюються керівникам лісонасіннєвих інспекцій, їх заступникам, керівникам структурних підрозділів лісонасіннєвих інспекцій та їх заступникам;

б) у розмірі до 40 відсотків годинної тарифної ставки (посадового окладу) за роботу в нічний час за кожну годину роботи з 10-ї години вечора до 6-ї години ранку;

в) за вчене звання: професора - у граничному розмірі 33 відсотки посадового окладу; доцента, старшого наукового співробітника - у граничному розмірі 25 відсотків посадового окладу; ( Підпункт 3 пункту 3 доповнено підпунктом "в" згідно з Наказом Державного комітету лісового господарства N 292 ( z0639-05 ) від 22.04.2005 )

г) за науковий ступінь: доктора наук - у граничному розмірі 25 відсотків посадового окладу; кандидата наук - у граничному розмірі 15 відсотків посадового окладу.

Зазначені доплати встановлюються, якщо діяльність працівників за профілем відповідає вченому званню або науковому ступеню.

( Підпункт 3 пункту 3 доповнено підпунктом "г" згідно з Наказом Державного комітету лісового господарства N 292 ( z0639-05 ) від

22.04.2005 ) 4) надбавки працівникам у розмірі до 50 відсотків посадового окладу:

за високі досягнення у праці;

за виконання особливо важливої роботи (на термін її виконання);

за складність, напруженість у роботі.

Граничний розмір зазначених надбавок для одного працівника не повинен перевищувати 50 відсотків посадового окладу.

У разі несвоєчасного виконання завдань, погіршення якості роботи і порушення трудової дисципліни ці надбавки скасовуються або зменшуються;

5) водіям автомобілів:

надбавки за класність у таких розмірах: водіям 2-го класу - 10 відсотків, водіям 1-го класу - 25 відсотків установленої тарифної ставки за відпрацьований час;

доплати за ненормований робочий день у розмірі 25 відсотків тарифної ставки за відпрацьований час.

4. Установити посадові оклади (ставки заробітної плати) керівникам, фахівцям, службовцям та робітникам структурних підрозділів і окремим працівникам лісонасіннєвих інспекцій, посади (професії) яких не передбачено цим наказом, у розмірах, установлених для аналогічних категорій працівників бюджетних установ, закладів та організацій відповідних галузей згідно з їх нормативно-правовими актами.

5. Надати право керівникам лісонасіннєвих інспекцій в межах фонду заробітної плати, затвердженого в кошторисах доходів і видатків:

а) установлювати працівникам конкретні розміри посадових окладів та доплат і надбавок до них;

б) надавати працівникам матеріальну допомогу, у тому числі на оздоровлення, за винятком матеріальної допомоги на поховання, у сумі не більше ніж один посадовий оклад на рік;

в) затверджувати порядок і розміри преміювання працівників відповідно до їх особистого внеску в загальні результати роботи.

6. Керівникам лісонасіннєвих інспекцій:

- установити посадові оклади (ставки заробітної плати) працівників, виходячи з розмірів та в терміни, передбачені додатками 1-2;

- у разі, якщо із запровадженням цього наказу заробітна плата працівників за відпрацьовану місячну норму праці з урахуванням доплат, надбавок, премій та інших виплат, крім тих, що не зараховуються до мінімальної заробітної плати відповідно до статті 3 Закону України "Про оплату праці" ( 108/95-ВР ), менша встановленого розміру мінімальної заробітної плати, провадити доплату до її розміру.

7. Управлінню кадрів (Клименко М.М.) та економічному управлінню (Кирилюк В.М.) унести зміни, що випливають із цього наказу, до контракту з генеральним директором "Укрдержліснасіння".

8. Скасувати наказ Держкомлісгоспу України від 06.03.2001 N 23 "Про впорядкування умов оплати праці працівників Української державної лісонасіннєвої станції "Укрдержліснасіння" Державного комітету лісового господарства України" (із змінами та доповненнями, унесеними наказом Державного комітету лісового господарства України від 18.01.2002 N 4).

9. Контроль за виконанням цього наказу покласти на заступника Голови Марчука Ю.М.

Голова комітету М.В.Колісниченко
