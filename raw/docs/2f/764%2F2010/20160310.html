Питання Комітету з Національної премії України імені Тараса Шевченка

Стан: Втратив чинність

Ідентифікатор: 764/2010

Текст документа від 10.03.2016:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 78/2016 ( 78/2016 ) від 03.03.2016 }

Питання Комітету з Національної премії України імені Тараса Шевченка

1. Затвердити новий персональний склад Комітету з Національної премії України імені Тараса Шевченка (додається).

У зв'язку з цим визнати такими, що втратили чинність:

статтю 3 Указу Президента України від 14 листопада 2005 року N 1599 ( 1599/2005 ) "Про деякі питання Комітету з Національної премії України імені Тараса Шевченка";

Указ Президента України від 19 грудня 2007 року N 1239 ( 1239/2007 ) "Про внесення змін до Указу Президента України від 14 листопада 2005 року N 1599";

абзац другий статті 1 Указу Президента України від 8 грудня 2008 року N 1150 ( 1150/2008 ) "Питання Комітету з Національної премії України імені Тараса Шевченка".

2. Голові Комітету з Національної премії України імені Тараса Шевченка подати у двотижневий строк пропозиції щодо вдосконалення роботи Комітету та процедури присудження Національної премії.
