КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 грудня 2001 р. N 1771 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Реєстраційний код акта : 44029/2008

Дата внесення до реєстру : 15.08.2008

Про внесення змін до постанови Кабінету Міністрів України від 7 лютого 2001 р. N 105

Кабінет Міністрів України постановляє:

Внести до переліку посад, що можуть бути заміщені військовослужбовцями Збройних Сил, Служби безпеки, інших військових формувань в органах виконавчої влади, інших цивільних установах, та граничних військових і спеціальних звань за цими посадами, затвердженого постановою Кабінету Міністрів України від 7 лютого 2001 р. N 105 ( 105-2001-п ) із змінами, внесеними постановою Кабінету Міністрів України від 26 липня 2001 р. N 882 ( 882-2001-п ), такі зміни:

1) у назві розділу "Національний інститут українсько-російських відносин" слова "українсько-російських відносин" замінити словами "проблем міжнародної безпеки";

2) розділ "Адміністрація Президента України" доповнити позицією такого змісту:

------------------------------------------------------------------

|"Референт Президента |полковник | 2 + 1*". |

|України | | |
