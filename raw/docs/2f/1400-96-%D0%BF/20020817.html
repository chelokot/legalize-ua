( Постанова втратила чинність на підставі Постанови КМ N 1178 ( 1178-2002-п ) від 17.08.2002 )

Про колегію Державного комітету у справах захисту прав споживачів

Кабінет Міністрів України постановляє:

1. На часткову зміну пункту 3 постанови Кабінету Міністрів України від 1 червня 1992 р. N 297 ( 297-92-п ) "Про створення Державного комітету України у справах захисту прав споживачів" дозволити Державному комітету у справах захисту прав споживачів мати колегію у кількості 12 чоловік.

2. Затвердити членами колегії Державного комітету у справах захисту прав споживачів Бородіча Леоніда Васильовича, Бурлакову Таїсію Віталіївну, Верещагу Євгена Михайловича, Єхнова Андрія Федоровича, Казакова Миколу Михайловича, Самчишина Олега Тимофійовича, Терещенка Івана Опанасовича.
