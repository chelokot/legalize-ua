УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Указів Президента України від 2 квітня 2010 року N 504 та від 5 квітня 2011 року N 352

{ Із змінами, внесеними згідно з Указом Президента N 592/2014 ( 592/2014 ) від 14.07.2014 }

1. Внести до Указів Президента України такі зміни:

1) в абзаці п'ятому пункту 7 Положення про Адміністрацію Президента України, затвердженого Указом Президента України від 2 квітня 2010 року N 504 ( 504/2010 ) (зі змінами, внесеними Указами від 5 квітня 2011 року N 352 ( 352/2011 ), від 30 червня 2011 року N 722 ( 722/2011 ) та від 8 липня 2011 року N 739) ( 739/2011 ), слова "Радник Президента України - Керівник Головного управління з питань діяльності правоохоронних органів" виключити;

{ Пункт 2 статті 1 втратив чинність на підставі Указу Президента N 592/2014 ( 592/2014 ) від 14.07.2014 }

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 29 листопада 2011 року N 1081/2011

{ Схема розподілу обов'язків між Главою Адміністрації Президента України, його Першим заступником і заступниками, радниками Президента України та закріплення за ними структурних підрозділів Адміністрації Президента України втратила чинність на підставі Указу Президента N 592/2014 ( 592/2014 ) від 14.07.2014 }
