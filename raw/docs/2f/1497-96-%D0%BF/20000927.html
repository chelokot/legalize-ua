Про Міжвідомчу комісію з питань регулювання закупівлі товарів (робіт, послуг) для державних потреб

Стан: Втратив чинність

Ідентифікатор: 1497-96-п

Текст документа від 27.09.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 грудня 1996 р. N 1497 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1469 ( 1469-2000-п ) від 27.09.2000 )

Про Міжвідомчу комісію з питань регулювання закупівлі товарів (робіт, послуг) для державних потреб

( Із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

Кабінет Міністрів України постановляє:

1. На часткову зміну пункту 2 постанови Кабінету Міністрів України від 4 червня 1996 р. N 611 ( 611-96-п ) "Про заборону використання бюджетних коштів для закупівлі товарів (робіт, послуг) іноземного походження" затвердити новий склад Міжвідомчої комісії з питань регулювання закупівлі товарів для державних потреб (додається). ( Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

Дозволити голові Міжвідомчої комісії з питань регулювання закупівлі товарів (робіт, послуг) для державних потреб вносити у разі потреби зміни до її складу. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 657 ( 657-98-п ) від 07.05.98 )

2. Внести до постанови Кабінету Міністрів України від 17 жовтня 1996 р. N 1272 ( 1272-96-п ) "Про ліквідацію робочих і консультативних органів Кабінету Міністрів України" такі зміни:

у додатку N 1 абзац четвертий виключити;

у додатку N 2 пункти 12 і 14 виключити.
