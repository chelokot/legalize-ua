ПОСТАНОВА від 1 серпня 2006 р. N 1073 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 149 ( 149-2009-п ) від 25.02.2009 }

Про затвердження складу Державної акредитаційної комісії

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 210-р ( 210-2007-р ) від 20.04.2007 N 348-р ( 348-2007-р ) від 26.05.2007 N 862-р ( 862-2007-р ) від 10.10.2007 N 640-р ( 640-2008-р ) від 17.04.2008 }

Кабінет Міністрів України постановляє:

1. Затвердити склад Державної акредитаційної комісії, що додається.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 21 січня 2003 р. N 107 ( 107-2003-п ) "Про затвердження складу Державної акредитаційної комісії" (Офіційний вісник України, 2003 p., N 4, ст. 144).
