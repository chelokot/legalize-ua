28.08.2007 N 243

{ Постанову скасовано на підставі Постанови Центральної виборчої комісії N 307 ( v0307359-07 ) від 04.09.2007 }

Про скасування реєстрації кандидатів у народні депутати України, включених до виборчого списку Блоку "НАША УКРАЇНА - НАРОДНА САМООБОРОНА": Народний Союз "Наша Україна", Політична партія "Вперед, Україно!", Народний Рух України, Українська Народна Партія, Українська республіканська партія "Собор", Партія Християнсько-Демократичний Союз, Європейська партія України, Партія захисників Вітчизни, - членів Громадянської партії "ПОРА", яка прийняла рішення про вихід із складу цього Блоку

До Центральної виборчої комісії 25 серпня 2007 року надійшли рішення N 3 та витяг із протоколу VII Громадянських зборів Громадянської партії "ПОРА" від 20 серпня 2007 року, підписані Головою Політради Громадянської партії "ПОРА" Годунком Ярославом Михайловичем та скріплені печаткою цієї партії, про вихід Громадянської партії "ПОРА" зі складу Блоку "НАША УКРАЇНА - НАРОДНА САМООБОРОНА": Народний Союз "Наша Україна", Політична партія "Вперед, Україно!", Народний Рух України, Українська Народна Партія, Українська республіканська партія "Собор", Партія Християнсько-Демократичний Союз, Європейська партія України, Громадянська партія "ПОРА", Партія захисників Вітчизни.

Розглянувши зазначені документи, відповідно до частин першої, другої, п'ятої та шостої статті 63 Закону України "Про вибори народних депутатів України" ( 1665-15 ), керуючись статтями 12, 13, пунктом 9 статті 19 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Скасувати реєстрацію кандидатів у народні депутати України, включених до виборчого списку ( v0087359-07 ) Блоку "НАША УКРАЇНА - НАРОДНА САМООБОРОНА": Народний Союз "Наша Україна", Політична партія "Вперед, Україно!", Народний Рух України, Українська Народна Партія, Українська республіканська партія "Собор", Партія Християнсько-Демократичний Союз, Європейська партія України, Партія захисників Вітчизни, - членів Громадянської партії "ПОРА", яка прийняла рішення про вихід із складу цього Блоку, згідно з додатком.

2. Цю постанову видати представникам Блоку "НАША УКРАЇНА - НАРОДНА САМООБОРОНА" та Громадянської партії "ПОРА" в Центральній виборчій комісії з правом дорадчого голосу.

Голова Центральної виборчої комісії В.ШАПОВАЛ
