{ Наказ втратив чинність на підставі Наказу Міністерства соціальної політики N 1629 ( z0096-17 ) від 28.12.2016 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 10.05.2006 N 173

На виконання пункту 2 постанови Кабінету Міністрів України від 20.05.2009 N 482 ( 482-2009-п ) "Деякі питання оплати праці працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів, що фінансуються з бюджету" та з метою впорядкування умов оплати праці працівників органів Державної служби з карантину рослин, віднесених до категорії посад державних службовців, НАКАЗУЮ:

1. Пункт 1 наказу Міністерства праці та соціальної політики України від 10.05.2006 N 173 ( z0544-06 ) "Про умови оплати праці працівників органів Державної служби з карантину рослин, віднесених до категорії посад державних службовців", зареєстрованого в Міністерстві юстиції України 11.05.2006 за N 544/12418 (зі змінами), доповнити новим абзацом такого змісту:

"Установити, що у разі, коли розміри посадових окладів працівників, зазначені у додатку, нижчі ніж визначений законом розмір мінімальної заробітної плати, посадові оклади установлюються на рівні відповідного розміру мінімальної заробітної плати.".

2. Директору департаменту з питань державного регулювання заробітної плати та умов праці Товстенку О.П. у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності з дня його офіційного опублікування.
