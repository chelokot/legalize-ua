Про зупинення дії постанов Кабінету Міністрів України від 11 травня 2006 р. N 665 і N 667

Стан: Втратив чинність

Ідентифікатор: 687-2006-п

Текст документа від 21.11.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 травня 2006 р. N 687 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1327 ( 1327-2007-п ) від 21.11.2007 }

Про зупинення дії постанов Кабінету Міністрів України від 11 травня 2006 р. N 665 і N 667

{ Із змінами, внесеними згідно з Постановою КМ N 837 ( 837-2006-п ) від 15.06.2006 }

Кабінет Міністрів України постановляє:

У зв'язку з хворобою Саєвича І.Б. зупинити дію постанови Кабінету Міністрів України від 11 травня 2006 р. N 665 ( 665-2006-п ) "Про звільнення Саєвича І.Б. з посади першого заступника Голови Державного комітету України з питань технічного регулювання та споживчої політики".

{ Постанова із змінами, внесеними згідно з Постановою КМ N 837 ( 837-2006-п ) від 15.06.2006 }
