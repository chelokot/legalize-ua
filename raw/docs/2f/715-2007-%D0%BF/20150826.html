ПОСТАНОВА від 12 травня 2007 р. N 715 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 609 ( 609-2015-п ) від 05.08.2015 }

Про внесення змін до переліку органів ліцензування

Кабінет Міністрів України постановляє:

Внести до переліку органів ліцензування, затвердженого постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) "Про затвердження переліку органів ліцензування" (Офіційний вісник України, 2000 р., N 46, ст. 2001; 2003 р., N 27, ст. 1327; 2004 р., N 36, ст. 2390, N 46, ст. 3046; 2006 р., N 20, ст. 1447, N 31, ст. 2211, N 42, ст. 2812; 2007 р., N 8, ст. 292), такі зміни:

абзац п'ятий графи "Вид господарської діяльності" пункту 1 виключити;

доповнити перелік ( 1698-2000-п ) пунктом 41 такого змісту:

"41. Держкомрибгосп діяльність, пов'язана з промисловим виловом риби на промислових ділянках рибогосподарських водойм, крім внутрішніх водойм (ставків) господарств".
