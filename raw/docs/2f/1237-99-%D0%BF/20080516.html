КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 липня 1999 р. N 1237 Київ

{ Постанова втрачає чинність на підставі Постанови КМ N 93 ( 93-2003-п ) від 18.01.2003 з дати набрання чинності частиною тринадцятою статті 71 Митного кодексу України ( 92-15 ), яка набирає чинності з моменту набуття Україною членства у Світовій організації торгівлі }

Про зниження ставок митних зборів для підприємств легкої та деревообробної промисловості Чернівецької області, які є учасниками економічного експерименту

На виконання Указу Президента України від 30 квітня 1999 р. N 461 ( 461/99 ) "Про економічний експеримент щодо стабілізації роботи підприємств легкої та деревообробної промисловості Чернівецької області" Кабінет Міністрів України постановляє:

Установити, що на період з 1 липня 1999 р. до 1 липня 2001 р. митне оформлення товарів, що імпортуються для власних виробничих потреб на митну територію України, або товарів власного виробництва, що експортуються з митної території України підприємствами легкої та деревообробної промисловості Чернівецької області, які є учасниками економічного експерименту, здійснюється із сплатою митних зборів у розмірі 50 відсотків ставок митних зборів, визначених постановою Кабінету Міністрів України від 27 січня 1997 р. N 65 ( 65-97-п ) "Про ставки митних зборів" (із змінами, внесеними постановами Кабінету Міністрів України від 7 березня 1998 р. N 285 ( 285-98-п ), від 13 травня 1998 р. N 670, ( 670-98-п ) від 21 вересня 1998 р. N 1477 ( 1477-98-п ), від 8 жовтня 1998 р. N 1625 ( 1625-98-п ), від 19 травня 1999 р. N 840 ( 840-99-п ) та від 23 червня 1999 р. N 1116 ( 1116-99-п ).
