КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 квітня 2000 р. N 729 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1488 ( 1488-2001-п ) від 16.11.2001 )

Про затвердження нового складу Міжвідомчої комісії з міжнародної торгівлі

( Із змінами, внесеними згідно з Постановою КМ N 23 ( 23-2001-п ) від 18.01.2001 )

Кабінет Міністрів України постановляє:

1. Затвердити новий склад Міжвідомчої комісії з міжнародної торгівлі (додається).

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 19 квітня 1999 р. N 634 ( 634-99-п ) "Про склад Міжвідомчої комісії з міжнародної торгівлі".
