Про внесення змін до наказу МНС України від 28.08.2002 N 222 "Про впорядкування умов оплати праці членів екіпажів морських суден аварійно-рятувального загону МНС України"

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи N 222 ( z0071-03 ) від 28.08.2002, до якого вносились зміни }

На виконання постанови Кабінету Міністрів України від 15 січня 2005 року N 36 ( 36-2005-п ) "Про підвищення з 1 січня 2005 р. посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести зміни до наказу МНС України від 28.08.2002 N 222 ( z0071-03 ) "Про впорядкування умов оплати праці членів екіпажів морських суден аварійно-рятувального загону МНС України", зареєстрованого в Міністерстві юстиції України 29.01.2003 за N 71/7392, із змінами, виклавши додатки 1-4, а також пункт 1 розділу II (Особливості оплати праці водолазів) у новій редакції, що додаються.

2. Ці зміни застосовуються з 1 січня 2005 року.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Муху В.А.

В.о. Міністра Г.В.Рева
