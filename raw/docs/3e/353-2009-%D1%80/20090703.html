Текст документа від 03.07.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 квітня 2009 р. N 353-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 643 ( 643-2009-п ) від 24.06.2009 }

Про внесення змін у додаток до постанови Кабінету Міністрів України від 8 листопада 2007 р. N 1315

Внести у додаток до постанови Кабінету Міністрів України від 8 листопада 2007 р. N 1315 ( 1315-2007-п ) "Про утворення Міжвідомчої комісії з питань міграції" (Офіційний вісник України, 2007 р., N 86, ст. 3169) такі зміни:

слова "Перший заступник Міністра внутрішніх справ" замінити словами "Заступник Міністра внутрішніх справ";

доповнити додаток ( 1315-2007-п ) словами "Керівник департаменту з питань державної безпеки Апарату Ради національної безпеки і оборони України".

Прем'єр-міністр України Ю.ТИМОШЕНКО
