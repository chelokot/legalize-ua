Про закріплення у державній власності пакету акцій ВАТ "Марганецький гірничо-збагачувальний комбінат"

Стан: Втратив чинність

Ідентифікатор: 930-98-р

Текст документа від 13.11.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 листопада 1998 р. N 930-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 1242-р ( 1242-99-р ) від 13.11.99 )

Про закріплення у державній власності пакету акцій ВАТ "Марганецький гірничо-збагачувальний комбінат"

Відповідно до пункту 14 Державної програми приватизації на 1998 рік ( 124/98-ВР ) закріпити у державній власності на 3 роки пакет акцій у розмірі 25 відсотків статутного фонду плюс одна акція ВАТ "Марганецький гірничо-збагачувальний комбінат".
