{ Розпорядження втратило чинність на підставі Розпорядження КМ N 427-р ( 427-2013-р ) від 19.06.2013 }

Про затвердження титулу будови з удосконалення вентиляції з бурінням вентиляційної свердловини

1. Затвердити поданий Міністерством енергетики та вугільної промисловості титул будови "Удосконалення вентиляції з бурінням вентиляційної свердловини відокремленого підрозділу "Шахта ім. XIX з'їзду КПРС" державного підприємства "Луганськвугілля", будівництво якої розпочалось у 1994 році, що додається.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 5 листопада 2008 р. N 1393 ( 1393-2008-р ) "Про затвердження титулу будови з удосконалення вентиляції з бурінням вентиляційної свердловини".
