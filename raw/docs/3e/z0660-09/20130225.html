Про затвердження Класифікатора додаткової митної інформації

{ Із змінами, внесеними згідно з Наказом Державної митної служби N 594 ( z0441-10 ) від 07.06.2010 }

Відповідно до статті 310 Митного кодексу України ( 92-15 ) та постанови Кабінету Міністрів України від 12.12.2002 N 1876 ( 1876-2002-п ) "Про відомчі класифікатори з питань митної статистики, які використовуються у процесі оформлення митних декларацій" НАКАЗУЮ:

1. Затвердити Класифікатор додаткової митної інформації, що додається.

2. Регіональній інформаційній митниці (Копосов С.А.) до дати набрання чинності цим наказом доопрацювати програмне забезпечення.

3. Центральному митному управлінню лабораторних досліджень та експертної роботи (Педешко А.І.) і Юридичному департаменту (Бабюк В.Л.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Начальникам митних органів забезпечити інформування суб'єктів підприємницької діяльності про вимоги цього наказу.

5. Установити, що цей наказ набирає чинності через 10 днів після його офіційного опублікування.

6. Контроль за виконанням наказу покласти на заступника Голови Державної митної служби України Дериволкова С.Д.

Голова Державної митної служби України А.В.Макаренко
