Про внесення зміни до пункту 8 Положення про Державний департамент у справах громадянства, імміграції та реєстрації фізичних осіб

Стан: Втратив чинність

Ідентифікатор: 889-2007-п

Текст документа від 18.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 липня 2007 р. N 889 Київ

{ Постанова втратила чинність одночасно з набранням чинності Указом Президента ( 405/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

{ Дію Постанови відновлено згідно з Постановою КМ N 559 ( 559-2010-п ) від 07.07.2010 }

{ Постанова втратила чинність на підставі Постанови КМ N 643 ( 643-2009-п ) від 24.06.2009 }

Про внесення зміни до пункту 8 Положення про Державний департамент у справах громадянства, імміграції та реєстрації фізичних осіб

Кабінет Міністрів України постановляє:

В абзаці першому пункту 8 Положення про Державний департамент у справах громадянства, імміграції та реєстрації фізичних осіб, затвердженого постановою Кабінету Міністрів України від 14 червня 2002 р. N 844 ( 844-2002-п ) "Про утворення Державного департаменту у справах громадянства, імміграції та реєстрації фізичних осіб" (Офіційний вісник України, 2002 р., N 25, ст. 1210, N 52, ст. 2387; 2003 р., N 30, ст. 1546, N 37, ст. 1981, N 40, ст. 2111; 2005 р., N 50, ст. 3126; 2006 р., N 11, ст. 752), слово "двох" замінити словом "трьох".
