Кабінет Міністрів України; Розпорядження від 09.08.2001 № 345-р

Про передачу Мінпромполітики повноважень з управління державними корпоративними правами Державної акціонерної компанії "Титан"

Стан: Втратив чинність

Ідентифікатор: 345-2001-р

Текст документа від 07.03.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 серпня 2001 р. N 345-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 301 ( 301-2003-п ) від 07.03.2003 )

Про передачу Мінпромполітики повноважень з управління державними корпоративними правами Державної акціонерної компанії "Титан"

1. Прийняти пропозицію Мінпромполітики, погоджену з Фондом державного майна та Мінекономіки, про передачу Мінпромполітики повноважень з управління пакетом акцій Державної акціонерної компанії "Титан", що належить державі, у розмірі 100 відсотків статутного фонду.

2. Доповнити розділ "Автономна Республіка Крим" переліку господарських товариств, повноваження з управління державними корпоративними правами яких передаються Мінпромполітики, визначеного додатком 5 до постанови Кабінету Міністрів України від 3 червня 1999 р. N 951 ( 951-99-п ) "Про передачу повноважень з управління державними корпоративними правами Раді міністрів Автономної Республіки Крим, міністерствам, іншим центральним і місцевим органам виконавчої влади" (Офіційний вісник України, 1999 р., N 23, ст. 1053, N 44, ст. 2175, N 46, ст. 2277, N 47, ст. 2314, N 48, ст. 2379; 2000 р., N 43, ст. 1844) такою позицією:

"05762329 ДАК "Титан", м. Армянськ".
