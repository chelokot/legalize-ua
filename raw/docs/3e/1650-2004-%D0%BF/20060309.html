КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 грудня 2004 р. N 1650 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 }

Про доповнення постанови Кабінету Міністрів України від 27 червня 1998 р. N 960

Кабінет Міністрів України постановляє:

Постанову Кабінету Міністрів України від 27 червня 1998 р. N 960 ( 960-98-п ) "Про умови оплати праці працівників Вищої ради юстиції" (Офіційний вісник України, 1998 р., N 26, ст. 939) доповнити пунктом 1-1 такого змісту:

"1-1. Надати право Голові Вищої ради юстиції установлювати надбавку за особливі умови проходження державної служби працівникам апарату Вищої ради юстиції у розмірі до 100 відсотків посадового окладу з урахуванням надбавки за ранг державного службовця та вислугу років".
