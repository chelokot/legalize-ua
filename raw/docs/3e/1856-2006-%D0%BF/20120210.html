КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 грудня 2006 р. N 1856 Київ

Про впорядкування робіт з утилізації непридатних та надлишкових ракет, боєприпасів і вибухових речовин

{ Із змінами, внесеними згідно з Постановами КМ N 469 ( 469-2010-п ) від 16.06.2010 N 50 ( 50-2012-п ) від 01.02.2012 }

Кабінет Міністрів України постановляє:

1. Утворити при Кабінеті Міністрів України Комісію з координації робіт з утилізації непридатних та надлишкових ракет, боєприпасів і вибухових речовин (далі - Комісія).

2. Установити, що:

головою Комісії є Перший віце-прем’єр-міністр України - Міністр економічного розвитку і торгівлі; { Абзац другий пункту 2 в редакції Постанов КМ N 469 ( 469-2010-п ) від 16.06.2010, N 50 ( 50-2012-п ) від 01.02.2012 }

передача непридатних та надлишкових ракет, боєприпасів і вибухових речовин (далі - боєприпаси) на утилізацію та проведення робіт з їх підготовки до утилізації здійснюються на підставі договорів, укладених з Міністерством оборони та виконавцями робіт. { Абзац третій пункту 2 із змінами, внесеними згідно з Постановою КМ N 469 ( 469-2010-п ) від 16.06.2010 }
