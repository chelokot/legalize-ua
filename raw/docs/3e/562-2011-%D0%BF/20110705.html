Деякі питання розвитку Донецького аеропорту

Стан: Чинний

Текст документа від 05.07.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 травня 2011 р. N 562 Київ

Деякі питання розвитку Донецького аеропорту

{ Із змінами, внесеними згідно з Постановою КМ N 691 ( 691-2011-п ) від 20.06.2011 }

Кабінет Міністрів України постановляє:

1. Відповідно до статті 8 Закону України "Про організацію та проведення фінальної частини чемпіонату Європи 2012 року з футболу в Україні" ( 962-16 ) Національному агентству з питань підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу та реалізації інфраструктурних проектів викупити у двомісячний строк будівлі і споруди по вул. Взльотній, 1 (літер А-2), 1г (літер А-1, Б-1, паркани і ворота N 1-4 та замощення N 1), загальною вартістю 15943473 гривні (без податку на додану вартість) та будівлю по вул. Взльотній, 1у (літер А-1), загальною вартістю 2349507 гривень (без податку на додану вартість), вартість яких підтверджено звітами про їх оцінку, що рецензовані Фондом державного майна, з оплатою витрат, пов'язаних із сплатою державного мита та платою за вчинення нотаріальних дій, загальною вартістю 237515,76 гривні.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 691 ( 691-2011-п ) від 20.06.2011 }

2. Внести до актів Кабінету Міністрів України зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 23 травня 2011 р. N 562

ЗМІНИ, що вносяться до актів Кабінету Міністрів України

1. У пункті 3 Порядку затвердження титулів будов (об'єктів), будівництво яких здійснюється із залученням бюджетних коштів або коштів підприємств державної власності, затвердженого постановою Кабінету Міністрів України від 8 вересня 1997 р. N 995 ( 995-97-п ) (Офіційний вісник України, 1997 р., число 37, с. 17; 2001 р., N 20, ст. 1466; 2008 р., N 34, ст. 1147; 2011 р., N 17, ст. 710, N 24, ст. 1001), слова "для об'єкта реконструкції аеровокзального комплексу (будівництво нового термінала, включаючи паркінг та огорожу)" замінити словами "для об'єктів реконструкції аеровокзального комплексу (будівництво нового термінала, включаючи паркінг та огорожу) та будівництва центру адміністративної та ділової авіації".

2. У додатку 2 до Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженої постановою Кабінету Міністрів України від 14 квітня 2010 р. N 357 ( 357-2010-п ) (Офіційний вісник України, 2010 р., N 39, ст. 1297; 2011 р., N 27, ст. 1132) у пункті 3 у позиції "проектування та будівництво термінала бізнес-авіації, проектування та підготовчі роботи з будівництва інфраструктури вантажного комплексу" слова "термінала бізнес-авіації" замінити словами "центру адміністративної та ділової авіації".

3. У пункті 11 Порядку використання запозичених у 2010 році коштів для виконання завдань та заходів Державної цільової програми підготовки та проведення в Україні фінальної частини чемпіонату Європи 2012 року з футболу, затвердженому постановою Кабінету Міністрів України від 27 жовтня 2010 р. N 990 ( 990-2010-п ) (Офіційний вісник України, 2010 р., N 84, ст. 2939; 2010 р., N 94, ст. 3335; 2011 р., N 17, ст. 710, N 24, ст. 1001):

в абзаці третьому слова "для об'єкта реконструкції аеровокзального комплексу (будівництво нового термінала, включаючи паркінг та огорожу)" замінити словами "для об'єктів реконструкції аеровокзального комплексу (будівництво нового термінала, включаючи паркінг та огорожу) та будівництва центру адміністративної та ділової авіації";

доповнити пункт абзацом такого змісту:

"договір купівлі-продажу майна разом з рецензованими Фондом державного майна звітами про його оцінку (у разі потреби).".

4. У назві і тексті розпорядження Кабінету Міністрів України від 20 квітня 2011 р. N 353 ( 353-2011-р ) "Про затвердження титулу на виконання проектно-вишукувальних робіт для будівництва термінала бізнес-авіації на території комунального підприємства "Міжнародний аеропорт Донецьк" та назві і тексті титулу, затвердженого зазначеним розпорядженням, слова "термінала бізнес-авіації" замінити словами "центру адміністративної та ділової авіації".
