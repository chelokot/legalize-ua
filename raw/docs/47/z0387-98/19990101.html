НКРЕ; Постанова від 17.06.1998 № 762

Про встановлення терміну ліцензування підприємницької діяльності з передачі електроенергії місцевими (локальними) електромережами

Реєстрація: Мін'юст України від 19.06.1998 № 387/2827

Стан: Втратив чинність

Ідентифікатор: z0387-98

Текст документа від 01.01.1999:

НАЦІОНАЛЬНА КОМІСІЯ РЕГУЛЮВАННЯ ЕЛЕКТРОЕНЕРГЕТИКИ УКРАЇНИ

ПОСТАНОВА

N 762 від 17.06.98 Зареєстровано в Міністерстві м.Київ юстиції України 19 червня 1998 р. vd980617 vn762 за N 387/2827

( Постанова втратила чинність на підставі Постанови Нацкомелектроенергетики N 1613 ( z0805-98 ) від 16.12.98 )

Про встановлення терміну ліцензування підприємницької

діяльності з передачі електроенергії місцевими (локальними) електромережами

Згідно із Законом України "Про електроенергетику" ( 575/97-ВР ) та Указом Президента України від 21 квітня 1998 р. N 335 ( 335/98 ) "Питання Національної комісії регулювання електроенергетики України" Національна комісія регулювання електроенергетики України (НКРЕ) ПОСТАНОВЛЯЄ:

1. Встановити, що підприємницька діяльність з передачі електричної енергії місцевими (локальними) електромережами створених в результаті реструктуризації галузей промисловості суб'єктів, для яких ця діяльність є основною, з 1.01.99 без ліцензії забороняється.

2. Вважати постанову НКРЕ від 18.12.97 N 1157 ( z0628-97 ) такою, що втратила чинність з 1.07.98.
