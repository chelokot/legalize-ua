КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 лютого 2010 р. N 107 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 266 ( 266-2015-п ) від 29.04.2015 }

Про внесення зміни до переліку напрямів, за якими здійснюється підготовка фахівців у вищих навчальних закладах за освітньо-кваліфікаційним рівнем бакалавра

Кабінет Міністрів України постановляє:
