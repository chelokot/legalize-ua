УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про відомчі заохочувальні відзнаки

{ Із змінами, внесеними згідно з Указами Президента N 1158/2007 ( 1158/2007 ) від 28.11.2007 N 46/2009 ( 46/2009 ) від 28.01.2009 }

З метою визначення порядку заснування заохочувальних відзнак міністерств та інших центральних органів виконавчої влади України постановляю:

1. Надати право міністерствам та іншим центральним органам виконавчої влади встановлювати відзнаки для заохочування працівників за значні трудові досягнення у відповідній галузі чи сфері діяльності.

Міністерства, центральні органи виконавчої влади відомчі заохочувальні відзнаки засновують після експертизи і позитивного висновку Комісії по державних нагородах України при Президентові України ( 747/94 ).

{ На часткову зміну статті 1 надати право Секретареві Ради національної безпеки і оборони України встановлювати відомчі заохочувальні відзнаки Апарату Ради національної безпеки і оборони України згідно з Указом Президента N 1158/2007 ( 1158/2007 ) від 28.11.2007 } { На часткову зміну статті 1 надати право начальнику Управління державної охорони України встановлювати відомчі заохочувальні відзнаки Управління державної охорони України згідно з Указом Президента N 46/2009 ( 46/2009 ) від 28.01.2009 }

2. Кабінету Міністрів України:

подати проект Примірного положення про відомчі заохочувальні відзнаки, передбачивши, що ці відзнаки можуть мати вигляд нагрудних знаків, значків, грамот, вітальних листів, не повинні відтворювати державні нагороди України і президентські відзнаки;

вирішити питання щодо джерел і порядку фінансування витрат, пов'язаних із виготовленням та врученням відомчих заохочувальних відзнак.
