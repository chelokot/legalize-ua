Про скорочення кількості посад заступників Голови Державного комітету України з державного матеріального резерву

Текст документа від 25.10.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 жовтня 2010 р. N 1971-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 2019-р ( 2019-2010-р ) від 25.10.2010 }

Про скорочення кількості посад заступників Голови Державного комітету України з державного матеріального резерву

1. Скоротити дві посади заступників Голови Державного комітету України з державного матеріального резерву.

2. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 3 лютого 2010 р. N 178 ( 178-2010-р ) та від 19 квітня 2010 р. N 934 ( 934-2010-р ) (Офіційний вісник України, 2010 р., N 29, ст. 1103).
