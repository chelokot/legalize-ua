Текст документа від 21.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 вересня 2011 р. N 980 Київ

Про внесення зміни до пункту 2 постанови Кабінету Міністрів України від 28 березня 2011 р. N 334

Кабінет Міністрів України постановляє:

Внести зміну до пункту 2 постанови Кабінету Міністрів України від 28 березня 2011 р. N 334 ( 334-2011-п ) "Деякі питання використання у 2011 році державних капітальних видатків" (Офіційний вісник України, 2011 р., N 24, ст. 999, N 35, ст. 1440, N 44, ст. 1785, N 46, ст. 1884), виклавши абзац четвертий підпункту 3 у такій редакції:

"50000 тис. гривень - на реконструкцію, розширення, придбання обладнання та меблів для Національного інституту раку по вул. Ломоносова, 33/43, у м. Києві - друга черга будівництва;".

Прем'єр-міністр України М.АЗАРОВ
