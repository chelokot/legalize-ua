Про внесення доповнення до Правил оформлення візових документів для в'їзду в Україну

Стан: Втратив чинність

Текст документа від 10.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 травня 2000 р. N 750 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 567 ( 567-2011-п ) від 01.06.2011 }

Про внесення доповнення до Правил оформлення візових документів для в'їзду в Україну

Кабінет Міністрів України постановляє:

Доповнити пункт 12 Правил оформлення візових документів для в'їзду в Україну, затверджених постановою Кабінету Міністрів України від 20 лютого 1999 р. N 227 ( 227-99-п ) (Офіційний вісник України, 1999 р., N 8, ст. 285), абзацом такого змісту:

"Оформлення віз типів С, Б, Н, К, П громадянам країн - членів Європейського Союзу, Канади, США та Японії здійснюється без подання відповідних запрошень".

Прем'єр-міністр України В.ЮЩЕНКО
