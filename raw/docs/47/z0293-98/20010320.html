Затверджено Наказ Ліцензійної палати України 28.04.98 N 49

Зареєстровано в Міністерстві юстиції України 8 травня 1998 р. за N 293/2733

Положення про порядок надання відомостей в електронному вигляді для ведення Єдиного ліцензійного реєстру

1. Положення про порядок надання відомостей в електронному вигляді для ведення Єдиного ліцензійного реєстру розроблено на виконання Указів Президента України від 7 лютого 1997 року N 104/97 "Про Ліцензійну палату України", від 16 липня 1997 року N 648/97 "Про Положення про Ліцензійну палату України", постанови Кабінету Міністрів України від 27 березня 1996 року N 364 ( 364-96-п ) "Про Єдиний ліцензійний реєстр" і в зв'язку з впровадженням Ліцензійною палатою автоматизованої системи поповнення інформаційної бази даних Єдиного ліцензійного реєстру (далі - Реєстр).

2. Органи, уповноважені Кабінетом Міністрів України видавати ліцензії на певні види підприємницької діяльності (далі - Ліцензіари), зобов'язані надсилати в Ліцензійну палату відомості про видані суб'єктам підприємницької діяльності (далі - Ліцензіати) ліцензії або про внесення змін до Реєстру у вигляді файлу у встановленому форматі (додаток).

Текстову інформацію відомостей заповнювати державною мовою. Файли з незаповненими полями, з помилковими кодами, що не відповідають вимогам ведення Реєстру, не можуть бути прийняті Ліцензійною палатою.

3. Ліцензіари при формуванні відомостей повинні керуватися наступною нормативно-довідковою базою:

- класифікацією форм власності (КФВ), затвердженою наказом Держстандарту України від 22.11.94 N 288 ( va288217-94 );

- класифікацією організаційно-правових форм господарювання (КОПФГ), затвердженою наказом Держстандарту України від 22.11.94 N 288 ( vb288217-94 );

- загальною класифікацією галузей народного господарства (ЗКГНГ), затвердженою наказом Мінстату України від 24.01.94 N 21 ( v0021202-94 );

- класифікацією видів економічної діяльності (КВЕД), затвердженою наказом Держстандарту України від 22.10.96 N 441 ( v0441217-96 );

- класифікацією об'єктів адміністративно-територіального устрою України (КОАТУУ), затвердженою наказом Держстандарту України від 31.10.97 N 659;

- довідником кодів видів діяльності, робіт, послуг за Єдиним ліцензійним реєстром, затвердженим наказом Ліцензійної палати від 13.04.98 N 41;

- системою позначень органів державного управління (СПОДУ).

4. Відомості повинні надсилатися до Ліцензійної палати разом з супровідним листом на дискетах 3.5" або через електронну пошту з використанням мереж INTERNET, "АСТРА" щомісяця (до 15 числа наступного за звітним місяця).

Супровідний лист повинен готуватися з допомогою редактора Word6.0\Win95, містити логотип фірмового бланка та текст, у якому вказується:

- місяць, рік, за який надаються звітні дані;

- загальна кількість ліцензій, наданих за звітний період;

- кількість ліцензій, наданих юридичним особам;

- кількість ліцензій, наданих фізичним особам.

1. Поле LR - код з Єдиного державного реєстру підприємств і організацій України (ЄДРПОУ), одержаний в органах державної реєстрації.

2. Поле LNU - повне найменування Ліцензіара.

3. Поле LGU - код відомчої підпорядкованості згідно із системою позначень органів державного управління (СПОДУ).

4. Поле LTE - код згідно із класифікацією об'єктів адміністративно-територіального устрою України (КОАТУУ): дві цифри - код області, наступні три цифри - код району (міста обласного підпорядкування).

5. Поле LPI - поштовий індекс відділення зв'язку Ліцензіара.

6. Поле LAD - місцезнаходження Ліцензіара (область, район, місто, вулиця, номер будинку тощо).

7. Поле LRV - порядковий номер керівника підрозділу, що відповідає за видачу ліцензій. Наприклад, якщо право підпису отримує нова посадова особа, то їй надається наступний порядковий номер.

8. Поле POSADA - посада керівника підрозділу, що відповідає за видачу ліцензій.

9. Поле FAM - прізвище, ім'я, по батькові керівника підрозділу, що відповідає за видачу ліцензій.

10. Поле FX - номер факсу підрозділу, що відповідає за видачу ліцензій.

11. Поле TF - номер телефону підрозділу, що відповідає за видачу ліцензій.

12. Поле OZ - ознака Ліцензіата: "Ю" - юридична, "Ф" - фізична особа.

13. Поле LT - код з Єдиного державного реєстру підприємств і організацій України (ЄДРПОУ) - для юридичних осіб або код з Державного реєстру фізичних осіб - платників податків та інших обов'язкових платежів (ДРФОППІОП) - для фізичних осіб.

14. Поле NU - повне найменування Ліцензіата - юридичної особи та прізвище, ім'я, по батькові керівника або прізвище, ім'я, по батькові Ліцензіата - фізичної особи.

15. Поле GU - код відомчого підпорядкування Ліцензіата за системою позначень органів державного управління (СПОДУ).

16. Поле TE - код згідно із класифікацією об'єктів адміністративно-територіального устрою України (КОАТУУ): дві цифри - код області, наступні три цифри - код району (міста обласного підпорядкування).

17. Поле PI - поштовий індекс відділення зв'язку Ліцензіата.

18. Поле AD - місцезнаходження Ліцензіата - юридичної особи або місце проживання Ліцензіата - фізичної особи (область, район, місто, вулиця, номер будинку тощо).

19. Поле OF - номер факсу Ліцензіата (заповнюється без тире і дужок).

20. Поле OT - номер телефону Ліцензіата (заповнюється без тире і дужок).

21. Поле FV - код форми власності згідно із класифікацією форм власності.

22. Поле PF - код організаційно-правої форми господарювання згідно із класифікацією організаційно-правових форм господарювання.

23. Поле D1 - код згідно із загальною класифікацією галузей народного господарства (ЗКГНГ).

24. Поле D1D - код згідно із довідником кодів видів діяльності, робіт, послуг Реєстру.

25. Поле NL - реєстраційний номер ліцензії.

26. Поле DN - дата початку дії ліцензії у форматі (YYYYMMDD). Наприклад, "19961205 " - п'яте грудня 1996 року.

27. Поле DK - дата кінця дії ліцензії у форматі (YYYYMMDD). Наприклад, "19991205" - п'яте грудня 1999 року.

28. Поле ERR - службове. Заповнюється програмним забезпеченням Реєстру інформацією про ідентифікатори полів даних, у яких знайдені помилки. Наприклад, текст "LT?TE?"- означає наявність помилок в ідентифікаційному коді та в коді території Ліцензіата.

29. Поле TYPE - код типу надісланих відомостей, може приймати значення:

0 - повідомлення щодо надання ліцензії;

1 - повідомлення щодо змін даних про Ліцензіата (місцезнаходження / місце проживання, місце дії, відомча підпорядкованість, номер телефону, факсу, номер ліцензії та термін її дії тощо);

2 - повідомлення щодо призупинення дії ліцензії;

3 - повідомлення щодо продовження дії призупиненої ліцензії;

4 - повідомлення щодо анулювання дії ліцензії.

30. Поле AD_DII - місце здійснення діяльності Ліцензіата (поштовий індекс, область, район, місто, вулиця, номер будинку тощо).

31. Поле D_NAK - дата у форматі (YYYYMMDD) рішення комісії щодо призупинення (продовження, анулювання) дії ліцензії.

32. Поле N_NAK - номер рішення комісії щодо призупинення (продовження, анулювання) дії ліцензії.

33. Поле T_ NAK - текст рішення комісії щодо призупинення (продовження, анулювання) дії ліцензії.

34. Поле K_KVED - код виду економічної діяльності за класифікацією видів економічної діяльності (КВЕД).

35. Поле T_TEXT - текстова примітка (заповнюється за наявності у виданій ліцензії додатка з переліком робіт, послуг).

36. Поле K_DREE - резервне поле (використовується при переході на нову версію програмного забезпечення Реєстру).
