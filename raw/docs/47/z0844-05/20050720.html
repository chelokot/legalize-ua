Про визнання такими, що втратили чинність, розпоряджень Державної комісії з регулювання ринків фінансових послуг України від 11.11.2003 N 115 та від 29.12.2003 N 186

Реєстрація: Мін'юст України від 03.08.2005 № 844/11124

Стан: Чинний

Ідентифікатор: z0844-05

Текст документа від 20.07.2005:

ДЕРЖАВНА КОМІСІЯ З РЕГУЛЮВАННЯ РИНКІВ ФІНАНСОВИХ ПОСЛУГ УКРАЇНИ

РОЗПОРЯДЖЕННЯ

20.07.2005 N 4360

Зареєстровано в Міністерстві юстиції України 3 серпня 2005 р. за N 844/11124

Про визнання такими, що втратили чинність, розпоряджень Державної комісії з регулювання ринків фінансових послуг України від 11.11.2003 N 115 та від 29.12.2003 N 186

Відповідно до Закону України "Про фінансові послуги та державне регулювання ринків фінансових послуг" ( 2664-14 ) Державна комісія з регулювання ринків фінансових послуг України ПОСТАНОВИЛА:

1. Визнати такими, що втратили чинність:

1.1) Розпорядження Державної комісії з регулювання ринків фінансових послуг України від 11.11.2003 N 115 ( z1085-03 ) "Про затвердження Положення про реєстрацію кредитних спілок", зареєстроване в Міністерстві юстиції України 26.11.2003 за N 1085/8406;

1.2) Розпорядження Державної комісії з регулювання ринків фінансових послуг України від 29.12.2003 N 186 ( z0080-04 ) "Про затвердження Положення про порядок державної реєстрації недержавних пенсійних фондів", зареєстроване в Міністерстві юстиції України 19.01.2004 за N 80/8679.

2. Юридичному департаменту забезпечити подання цього розпорядження до Міністерства юстиції України для державної реєстрації.

3. Управлінню організаційно-аналітичного забезпечення роботи керівника (Шевченко Т.М.) забезпечити публікацію цього розпорядження у засобах масової інформації після його державної реєстрації.

4. Контроль за виконанням цього розпорядження залишити за Головою Комісії.

Голова Комісії В.Суслов
