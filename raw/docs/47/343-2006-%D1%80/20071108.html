РОЗПОРЯДЖЕННЯ від 19 червня 2006 р. N 343-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 964-р ( 964-2007-р ) від 08.11.2007 }

Про затвердження складу спостережної ради НАК "Надра України"

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 535-р ( 535-2006-р ) від 02.11.2006 N 783-р ( 783-2007-р ) від 19.09.2007 }

1. Затвердити склад спостережної ради НАК "Надра України", що додається.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 26 серпня 2004 р. N 621 ( 621-2004-р ) "Про затвердження нового складу спостережної ради НАК "Надра України".
