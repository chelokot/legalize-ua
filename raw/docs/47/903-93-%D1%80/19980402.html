Кабінет Міністрів України; Розпорядження від 28.10.1993 № 903-р

Про надання повноважень ТОВ - Виробничо-комерційній фірмі "Штейн" на здійснення експорту мідного штейну

Стан: Втратив чинність

Ідентифікатор: 903-93-р

Текст документа від 02.04.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 жовтня 1993 р. N 903-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 315 ( 315-98-п ) від 17.03.98 )

Відповідно до Декрету Кабінету Міністрів України від 26 грудня 1992 р. N 16-92 ( 16-92 ) "Про встановлення спеціального режиму експорту окремих видів товарів" уповноважити здійснювати експорт мідного штейну (код ТН ЗЕД - 7401.10000) товариство з обмеженою відповідальністю - Виробничо-комерційну фірму "Штейн".
