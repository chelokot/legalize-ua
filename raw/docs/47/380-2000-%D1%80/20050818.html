КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 вересня 2000 р. N 380-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про Міжвідомчу координаційну раду для забезпечення координації та контролю за ходом підготовки і реалізації проекту Програмної системної позики

( Із змінами, внесеними згідно з Розпорядженням КМ N 558-р ( 558-2003-р ) від 04.09.2003 )

1. Утворити Міжвідомчу координаційну раду для забезпечення координації та контролю за ходом підготовки і реалізації проекту Програмної системної позики (далі - Міжвідомча рада), що підтримується Міжнародним банком реконструкції та розвитку, у складі згідно з додатком.

2. Установити, що:

Міжвідомча рада проводить засідання відповідно до плану роботи та регламенту, затверджених її головою;

організаційне забезпечення роботи Міжвідомчої ради здійснює Міністерство економіки.

3. Визначити Міністерство економіки відповідальним виконавцем проекту Програмної системної позики.
