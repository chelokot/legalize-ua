Президент України; Указ від 20.08.2007 № 720/2007

Про внесення зміни до Указу Президента України від 3 лютого 2006 року N 105

Стан: Чинний

Ідентифікатор: 720/2007

Текст документа від 20.08.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення зміни до Указу Президента України від 3 лютого 2006 року N 105

Відповідно до частини третьої статті 76 Закону України "Про судоустрій України" ( 3018-14 ) постановляю:

На часткову зміну статті 1 Указу Президента України від 3 лютого 2006 року N 105 ( 105/2006 ) "Про зміни у складі Вищої кваліфікаційної комісії суддів України" призначити членом Вищої кваліфікаційної комісії суддів України КИРИЛЮКА Руслана Івановича - Керівника Служби з представництва у судах України інтересів Президента України та створених ним консультативних, дорадчих та інших допоміжних органів і служб Секретаріату Президента України, увільнивши від виконання цих обов'язків І. Коліушка.

Президент України В.ЮЩЕНКО

м. Київ, 20 серпня 2007 року N 720/2007
