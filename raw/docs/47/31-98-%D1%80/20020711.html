Стан: Втратив чинність

Ідентифікатор: 31-98-р

Текст документа від 11.07.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 січня 1998 р. N 31-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 1002 ( 1002-2002-п ) від 11.07.2002 )

Про створення координаційної ради для організації робіт з підготовки та проведення еколого-економічного експерименту в містах Кривий Ріг, Дніпродзержинськ та Маріуполь

( Із змінами, внесеними згідно з Розпорядженням КМ N 424-р ( 424-2000-р ) від 26.10.2000 )

1. На виконання розпорядження Президента України від 11 липня 1997 р. N 235 ( 235/97-рп ) "Про еколого-економічний експеримент у містах Кривий Ріг, Дніпродзержинськ та Маріуполь" створити координаційну раду для організації робіт з підготовки та проведення еколого-економічного експерименту в містах Кривий Ріг, Дніпродзержинськ та Маріуполь у складі згідно з додатком.

2. Надати голові координаційної ради право вносити зміни до її складу та залучати в установленому порядку до розроблення матеріалів, необхідних для проведення еколого-економічного експерименту, окремих фахівців і науковців та отримувати від центральних органів виконавчої влади, інших організацій відповідну інформацію.

( Пункт 2 із змінами, внесеними згідно з Розпорядженням КМ N 424-р ( 424-2000-р ) від 26.10.2000 )

3. Голові координаційної ради раз на квартал інформувати Кабінет Міністрів України про хід підготовки та проведення еколого-економічного експерименту в містах Кривий Ріг, Дніпродзержинськ та Маріуполь.
