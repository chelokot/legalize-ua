КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 вересня 2007 р. N 1105 Київ

{ Постанову скасовано на підставі Постанови КМ N 1403 ( 1403-2007-п ) від 24.12.2007 }

{ Дію Постанови зупинено згідно з Указом Президента N 907/2007 ( 907/2007 ) від 20.09.2007 }

Про вилучення пакетів акцій із статутного фонду Національної акціонерної компанії "Енергетична компанія України"

Кабінет Міністрів України постановляє:

Міністерству палива та енергетики в установленому порядку вилучити із статутного фонду Національної акціонерної компанії "Енергетична компанія України" та передати Фонду державного майна для приватизації пакети акцій відкритих акціонерних товариств за переліком згідно з додатком.

У зв'язку з цим внести у додаток 1 до постанови Кабінету Міністрів України від 22 червня 2004 р. N 794 ( 794-2004-п ) "Про утворення Національної акціонерної компанії "Енергетична компанія України" (Офіційний вісник України, 2004 р., N 25, ст. 1651; 2007 р., N 44, ст. 1799) зміни, що додаються.
