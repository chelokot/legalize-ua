Верховна Рада України; Постанова від 30.11.2006 № 396-V

Про утворення Тимчасової слідчої комісії Верховної Ради України з питань розслідування витрат коштів, отриманих від приватизації ВАТ "Криворіжсталь"

Стан: Чинний

Ідентифікатор: 396-16

Текст документа від 16.03.2007:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

Про утворення Тимчасової слідчої комісії Верховної Ради України з питань розслідування витрат коштів, отриманих від приватизації ВАТ "Криворіжсталь"

( Відомості Верховної Ради України (ВВР), 2007, N 14, ст.170 )

{ Із змінами, внесеними згідно з Постановою ВР N 754-V ( 754-16 ) від 16.03.2007 }

З метою проведення розслідування з питання, що становить значний суспільний інтерес, відповідно до статті 89 Конституції України ( 254к/96-ВР ), статей 82, 83 Регламенту Верховної Ради України ( 3547-15 ) Верховна Рада України постановляє:

1. Утворити Тимчасову слідчу комісію Верховної Ради України з питань розслідування витрат коштів, отриманих від приватизації ВАТ "Криворіжсталь" (далі - Тимчасова слідча комісія).

2. Встановити, що кількісний склад народних депутатів України, які входять до складу Тимчасової слідчої комісії, становить 11 народних депутатів України.

3. Обрати головою Тимчасової слідчої комісії народного депутата України Гєллєра Євгенія Борисовича, заступником голови - Сенченка Андрія Віленовича.

{ Пункт 3 із змінами, внесеними згідно з Постановою ВР N 754-V ( 754-16 ) від 16.03.2007 }

4. Обрати до складу Тимчасової слідчої комісії таких народних депутатів України:

ЄРЕСЬКА - фракція "Блок Юлії Тимошенко";

Ігоря Геннадійовича

ЛУКАШУКА - фракція "Блок Юлії Тимошенко";

Олега Григоровича

МІРОШНИЧЕНКА - фракція Партії Регіонів;

Юрія Романовича

КИРИЧЕНКО - фракція Партії Регіонів;

Людмилу Федорівну

ПЄХОТУ - фракція Партії Регіонів;

Володимира Юлійовича

БОНДАРЯ - фракція Блоку "Наша Україна";

Олександра Миколайовича

ДАВИМУКУ - фракція Блоку "Наша Україна";

Степана Антоновича

Сергія Олександровича України;

МАРМАЗОВА - фракція Комуністичної партії

Євгена Васильовича України.

5. Матеріально-технічне, кадрове, інформаційне та організаційне забезпечення роботи Тимчасової слідчої комісії покласти на апарат Верховної Ради України.

6. Визначити термін діяльності Тимчасової слідчої комісії - шість місяців з дня прийняття цієї Постанови.

7. Звіт Тимчасової слідчої комісії про виконану роботу заслухати не пізніше тримісячного терміну з дня прийняття цієї Постанови.

8. Ця Постанова набирає чинності з дня її прийняття.
