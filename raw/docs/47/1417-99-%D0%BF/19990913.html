Кабінет Міністрів України; Постанова від 04.08.1999 № 1417

Про фінансування будівництва лінії швидкісного трамвая у м. Кривому Розі Дніпропетровської області

Стан: Втратив чинність

Ідентифікатор: 1417-99-п

Текст документа від 13.09.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 серпня 1999 р. N 1417 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1667 ( 1667-99-п ) 13.09.99 )

Про фінансування будівництва лінії швидкісного трамвая у м. Кривому Розі Дніпропетровської області

( Із змінами, внесеними згідно з Постановою КМ N 1476 ( 1476-99-п ) від 14.08.99 )

Кабінет Міністрів України постановляє:

1. Виділити Дніпропетровській обласній державній адміністрації капітальні вкладення в обсязі 14 млн. гривень на будівництво лінії швидкісного трамвая у м. Кривому Розі Дніпропетровської області.

Міністерству фінансів профінансувати зазначені витрати в межах загальних обсягів капітальних вкладень відповідно до Закону України "Про Державний бюджет України на 1999 рік" ( 378-14 ).

( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1476 ( 1476-99-п ) від 14.08.99 )

2. Міністерству економіки разом з Міністерством фінансів підготувати пропозиції про внесення змін і доповнень до постанови Кабінету Міністрів України від 23 березня 1999 р. N 452 ( 452-99-п ) "Про розподіл державних централізованих капітальних вкладень та переліки об'єктів, що фінансуються за їх рахунок у 1999 році", передбачивши приведення обсягів капітальних вкладень у відповідність з видатками державного бюджету.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
