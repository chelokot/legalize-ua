ПОСТАНОВА від 26 травня 2007 р. N 775 Київ

{ Постанову скасовано на підставі Постанови КМ N 104 ( 104-2008-п ) від 27.02.2008 }

Про внесення зміни до постанови Кабінету Міністрів України від 7 грудня 2005 р. N 1167

{ Додатково див. Постанову Окружного адміністративного суду міста Києва N 9/166 ( v_166805-07 ) від 12.12.2007 }

Кабінет Міністрів України постановляє:

Внести зміну до постанови Кабінету Міністрів України від 7 грудня 2005 р. N 1167 ( 1167-2005-п ) "Питання управління часткою держави у статутному фонді Національного депозитарію" (Офіційний вісник України, 2005 р., N 49, ст. 3065), доповнивши її пунктом 1-1 такого змісту:

"1-1. Установити, що функції з управління часткою держави у статутному фонді Національного депозитарію у кількості 2150 акцій додаткового випуску здійснює Міністерство фінансів.".
