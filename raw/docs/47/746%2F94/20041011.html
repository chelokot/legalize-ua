Про Комісію при Президентові України у питаннях громадянства

Стан: Втратив чинність

Текст документа від 11.10.2004:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Комісію при Президентові України у питаннях громадянства

( Із змінами, внесеними згідно з Указами Президента N 275/96 від 22.04.96 N 1254/97 від 06.11.97 N 1135/98 від 13.10.98 N 238/99 від 06.03.99 N 770/2000 від 07.06.2000 N 120/2001 ( 120/2001 ) від 28.02.2001 N 1094/2001 ( 1094/2001 ) від 15.11.2001 N 911/2002 ( 911/2002 ) від 08.10.2002 N 488/2004 ( 488/2004 ) від 27.04.2004 N 1200/2004 ( 1200/2004 ) від 11.10.2004 )

Утворити Комісію при Президентові України у питаннях громадянства в такому складі:

Голова Комісії

ШЕМШУЧЕНКО - директор Інституту держави і права Юрій Сергійович Національної Академії наук України

Заступник Голови Комісії

БРИТЧЕНКО - Керівник Управління з питань

Сергій Петрович громадянства Адміністрації Президента України, заступник Голови Комісії

Члени Комісії

УСІЧЕНКО - президент Товариства Червоного Іван Гнатович Хреста України (за згодою)

ШИШОЛІН - перший заступник Голови Державного Павло Анатолійович комітету у справах охорони державного кордону України

МИГОВИЧ - народний депутат України (за згодою) Іван Іванович

ЗАЄЦЬ - Державний секретар Міністерства Анатолій Павлович юстиції України

ШУЛЬГА - народний депутат України Микола Олександрович (за згодою)

ГОРЛАЧ - письменник (КОВАЛЕНКО) Леонід Никифорович

МОСКАЛЬ - Голова Державного комітету України Геннадій Геннадійович у справах національностей та міграції

ДАВИДЕНКО - директор Державного департаменту у Віктор Михайлович справах громадянства, імміграції та реєстрації фізичних осіб Міністерства внутрішніх справ України

НАЛИВАЙЧЕНКО - заступник Міністра закордонних справ Валентин Олександрович України

ЗАЄЦЬ - перший заступник Міністра юстиції Анатолій Павлович України - керівник апарату

СУБОТЕНКО - завідувач сектора по забезпеченню Валентина Павлівна діяльності Комісії з питань громадянства Управління з питань громадянства Адміністрації Президента України

ШИШОЛІН - перший заступник Голови Державної Павло Анатолійович прикордонної служби України - директор Департаменту охорони державного кордону

ТУЗ Сергій Іванович - заступник Голови Служби безпеки України

Відповідальний секретар Комісії

СУБОТЕНКО - завідувач сектора Відділу громадянства Валентина Павлівна Адміністрації Президента України
