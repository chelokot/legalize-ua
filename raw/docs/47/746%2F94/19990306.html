Про Комісію при Президентові України у питаннях громадянства

Стан: Втратив чинність

Ідентифікатор: 746/94

Текст документа від 06.03.1999:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Комісію при Президентові України у питаннях громадянства

( Із змінами, внесеними згідно з Указами Президента N 275/96 від 22.04.96 N 1254/97 від 06.11.97 N 1135/98 від 13.10.98 N 238/99 від 06.03.99 )

Утворити Комісію при Президентові України у питаннях громадянства в такому складі:

Голова Комісії

ШЕМШУЧЕНКО - директор Інституту держави і права Юрій Сергійович Національної Академії наук України

Заступник Голови Комісії

ЧАЛИЙ - завідуючий Відділом у питаннях Петро Федорович громадянства Адміністрації Президента України

Члени Комісії

МУСІЄНКО - письменник Олекса Григорович

УСИЧЕНКО - голова Національного комітету Іван Гнатович Товариства Червоного Хреста України

ЧЕРНИШОВ - заступник Міністра внутрішніх справ Валерій Серафимович України

БЄЛОВ - директор Національного інституту Олександр Федорович стратегічних досліджень

СТИЧИНСЬКИЙ - заступник Міністра юстиції України Броніслав Станіславович

ШИШОЛІН - перший заступник Голови Державного Павло Анатолійович комітету у справах охорони державного кордону України

ЗЕМЛЯНСЬКИЙ - перший заступник Голови Служби Юрій Володимирович безпеки України

МИГОВИЧ - народний депутат України (за згодою) Іван Іванович

ТРОЩИНСЬКИЙ - перший заступник Голови Державного Володимир Павлович комітету України у справах національностей та міграції

МАЙДАННИК - заступник Міністра закордонних

Олександр Іванович справ України

Відповідальний секретар Комісії

СУБОТЕНКО - завідувач сектора Відділу громадянства Валентина Павлівна Адміністрації Президента України

( Склад Комісії із змінами, внесеними згідно з Указами Президента N 275/96 від 22.04.96, N 1254/97 від 06.11.97, N 1135/98 від 13.10.98, N 238/99 від 06.03.99 )
