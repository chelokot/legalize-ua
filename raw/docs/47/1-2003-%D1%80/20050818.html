Ідентифікатор: 1-2003-р

Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 січня 2003 р. N 1-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про утворення робочої групи з підготовки пропозицій щодо удосконалення державного управління

З метою підготовки пропозицій щодо удосконалення структури центральних органів виконавчої влади, впорядкування їх повноважень та функцій, посилення взаємодії центральних та місцевих органів виконавчої влади утворити робочу групу у складі згідно з додатком.
