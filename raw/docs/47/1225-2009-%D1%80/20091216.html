Кабінет Міністрів України; Розпорядження від 07.10.2009 № 1225-р

Про спрямування коштів Стабілізаційного фонду для проведення аварійно-відбудовних робіт з ліквідації наслідків надзвичайної ситуації на магістральному водоводі у м. Керчі (Автономна Республіка Крим)

Стан: Чинний

Ідентифікатор: 1225-2009-р

Текст документа від 16.12.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 7 жовтня 2009 р. N 1225-р Київ

Про спрямування коштів Стабілізаційного фонду для проведення аварійно-відбудовних робіт з ліквідації наслідків надзвичайної ситуації на магістральному водоводі у м. Керчі (Автономна Республіка Крим)

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1620-р ( 1620-2009-р ) від 16.12.2009 }

1. Здійснити перерозподіл коштів Стабілізаційного фонду в сумі 6452,4 тис. гривень шляхом зменшення обсягу видатків за напрямом, передбаченим пунктом 16 частини першої статті 76 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), і збільшення обсягу видатків за напрямом, передбаченим пунктом 7 частини першої статті 76 зазначеного Закону ( 835-17 ), спрямувавши їх Мінрегіонбуду на безповоротній основі для фінансування об'єкта "Реконструкція магістрального водоводу діаметром 900 міліметрів від водоочисних споруд Північно-Кримського каналу до шосе Героїв Сталінграда у м. Керчі" (Автономна Республіка Крим).

Зазначені кошти Стабілізаційного фонду ( 835-17 ) використовуються відповідно до Порядку використання у 2009 році коштів Стабілізаційного фонду для реалізації інвестиційних проектів соціально-економічного розвитку регіонів, затвердженого постановою Кабінету Міністрів України від 28 січня 2009 р. N 47 ( 47-2009-п ) (Офіційний вісник України, 2009 р., N 8, ст. 245). { Пункт 1 в редакції Розпорядження КМ N 1620-р ( 1620-2009-р ) від 16.12.2009 }

2. Забезпечити без попереднього погодження з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету передбаченого пунктом 1 цього розпорядження перерозподілу коштів Стабілізаційного фонду:

Мінфіну - внесення відповідних змін до розпису державного бюджету ( 835-17 );

Державному казначейству - перерахування коштів Стабілізаційного фонду.

3. Мінрегіонбуду вжити заходів до погодження передбаченого пунктом 1 цього розпорядження перерозподілу коштів Стабілізаційного фонду з комітетами Верховної Ради України з питань фінансів і банківської діяльності та з питань бюджету.

{ Пункт 3 в редакції Розпорядження КМ N 1620-р ( 1620-2009-р ) від 16.12.2009 }
