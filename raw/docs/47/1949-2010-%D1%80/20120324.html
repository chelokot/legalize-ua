Стан: Втратив чинність

Ідентифікатор: 1949-2010-р

Текст документа від 24.03.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 жовтня 2010 р. N 1949-р Київ

Про утворення міжвідомчої робочої групи з проведення аналізу (інвентаризації) послуг, які надаються центральними органами виконавчої влади і підприємствами, установами та організаціями, що належать до сфери їх управління

{ Із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2012-п ) від 12.03.2012 }

1. Утворити міжвідомчу робочу групу з проведення аналізу (інвентаризації) послуг, які надаються центральними органами виконавчої влади і підприємствами, установами та організаціями, що належать до сфери їх управління (далі - міжвідомча робоча група), з числа керівників або заступників керівників Державного комітету з питань регуляторної політики та підприємництва, Міністерства економіки, Міністерства фінансів, Міністерства юстиції, Головного управління державної служби, Головного контрольно-ревізійного управління, Антимонопольного комітету, Служби безпеки, Ради підприємців при Кабінеті Міністрів України, Секретаріату Кабінету Міністрів України та інших заінтересованих органів.

Затвердити головою міжвідомчої робочої групи Першого віце-прем'єр-міністра України Хорошковського Валерія Івановича та його заступниками Голову Державної служби з питань регуляторної політики та розвитку підприємництва Бродського Михайла Юрійовича і заступника Керівника Секретаріату Кабінету Міністрів України Авксентьєва Юрія Анатолійовича. { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2012-п ) від 12.03.2012 }

Голові міжвідомчої робочої групи затвердити її персональний склад та графік роботи.

Надати голові міжвідомчої робочої групи право вносити у разі потреби зміни до її персонального складу.

2. Покласти на Державну службу з питань регуляторної політики та розвитку підприємництва організаційне та інформаційно-аналітичне забезпечення діяльності міжвідомчої робочої групи.

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2012-п ) від 12.03.2012 }

3. Міністерствам та іншим центральним органам виконавчої влади забезпечити подання Державній службі з питань регуляторної політики та розвитку підприємництва матеріалів, необхідних для проведення аналізу (інвентаризації) послуг, які надаються центральними органами виконавчої влади і підприємствами, установами та організаціями, що належать до сфери їх управління. { Пункт 3 із змінами, внесеними згідно з Постановою КМ N 230 ( 230-2012-п ) від 12.03.2012 }
