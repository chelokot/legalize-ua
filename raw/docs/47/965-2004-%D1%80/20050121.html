КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 23 грудня 2004 р. N 965-р Київ

( Виконання Розпорядження зупиняється на підставі Розпорядження КМ N 21-р ( 21-2005-р ) від 21.01.2005 )

Про передачу майнового комплексу військового містечка N 259 у власність територіальної громади

Прийняти пропозицію МНС, погоджену з Голосіївською районною радою м. Києва, щодо передачі майнового комплексу військового містечка N 259 (вул. Лютнева, 58д) з державної власності у власність територіальної громади Голосіївського району.
