Про представника України і його заступників у Раді Міжнародного союзу по охороні нових сортів рослин

Стан: Втратив чинність

Ідентифікатор: 952/95

Текст документа від 21.05.2019:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 248/2019 ( 248/2019 ) від 17.05.2019 }

Про представника України і його заступників у Раді Міжнародного союзу по охороні нових сортів рослин

{ Із змінами, внесеними згідно з Указами Президента N 658/2004 ( 658/2004 ) від 18.06.2004 N 700/2008 ( 700/2008 ) від 09.08.2008 }

1. Призначити ХАДЖИМАТОВА Валерія Атабековича - голову Державної служби з охорони прав на сорти рослин - представником України у Раді Міжнародного союзу по охороні нових сортів рослин, ТЕРЕЩУКА Сергія Миколайовича - народного депутата України - заступником представника України у Раді Міжнародного союзу по охороні нових сортів рослин (за згодою).

{ Стаття 1 із змінами, внесеними згідно з Указами Президента N 658/2004 ( 658/2004 ) від 18.06.2004, N 700/2008 ( 700/2008 ) від 09.08.2008 }

2. Кабінету Міністрів України привести рішення Уряду у відповідність з цим Указом.

Президент України Л.КУЧМА
