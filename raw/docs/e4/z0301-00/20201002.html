{ Із змінами, внесеними згідно з Постановами Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 N 3-1 ( z0372-04 ) від 10.03.2004 N 16-3 ( z0813-08 ) від 13.08.2008 N 13-2 ( z1508-13 ) від 13.08.2013 }

Відповідно до пунктів 9, 11 Положення про Пенсійний фонд України, затвердженого Указом Президента України від 06 квітня 2011 року N 384 ( 384/2011 ), та пункту 3 постанови Кабінету Міністрів України від 15 березня 2006 року N 332 ( 332-2006-п ) "Деякі питання пенсійного забезпечення службовців Національного банку", правління Пенсійного фонду України ПОСТАНОВЛЯЄ: { Преамбула із змінами, внесеними згідно з Постановою Пенсійного фонду N 13-2 ( z1508-13 ) від 13.08.2013 }

1. Затвердити Порядок виплати пенсій працівникам установ Національного банку України, які виходять на пенсію за віком як державні службовці (додається).

2. Управлінням виконання бюджету, юридичному та надходження доходів Пенсійного фонду України подати Порядок для реєстрації до Міністерства юстиції України.

Голова правління Б.О.Зайчук

Затверджено Постанова правління Пенсійного фонду України 27.04.2000 N 7-4

Зареєстровано в Міністерстві юстиції України 24 травня 2000 р. за N 301/4522

Порядок виплати пенсій працівникам установ Національного банку України, які виходять на пенсію за віком як державні службовці

1. Загальні положення

1.1. Цей Порядок підготовлений відповідно до пункту 3 постанови Кабінету Міністрів України від 15 березня 2006 року N 332 ( 332-2006-п ) "Деякі питання пенсійного забезпечення службовців Національного банку" і регулює питання виплати пенсій працівникам установ Національного банку України, які виходять на пенсію за віком як державні службовці (далі - одержувачі), за їх згодою через вклади до запитання (поточні рахунки) в установах Національного банку України. { Пункт 1.1 із змінами, внесеними згідно з Постановою Пенсійного фонду N 16-3 ( z0813-08 ) від 13.08.2008 }

1.2. Виплата пенсій згідно з цим Порядком здійснюється через поточні рахунки, що відкриваються в установах Національного банку України, з яким Пенсійний фонд України укладає відповідну угоду з визначенням санкцій за недотримання ним договору перед одержувачами. ( Пункт 1.2 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

1.3. Виплата пенсій відповідно до цього Порядку здійснюється за місцем функціонування установ Національного банку України.

1.4. Установи Національного банку України здійснюють відкриття поточних рахунків, проводять операції з зарахування сум пенсій на поточні рахунки відповідно до цього Порядку на підставі угод, укладених ними з управліннями Пенсійного фонду України у районах, містах, районах у містах, а також у містах та районах, а в адміністративно-територіальних одиницях, де функціонують центри з нарахування та виплати пенсій, - також з відповідними головними управліннями Пенсійного фонду України.

{ Пункт 1.4 розділу І із змінами, внесеними згідно з Постановами Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002, N 16-3 ( z0813-08 ) від 13.08.2008, N 13-2 ( z1508-13 ) від 13.08.2013 }

1.5. Операції з відкриття поточних рахунків, зарахування й виплати пенсій з них здійснюються установами Національного банку України безоплатно.

2. Відкриття поточних рахунків

2.1. Поточні рахунки одержувачам пенсій відкриваються установами Національного банку України в порядку, встановленому нормативно-правовими актами Національного банку України, що регулюють порядок відкриття та використання рахунків у національній та іноземній валюті. { Пункт 2.1 із змінами, внесеними згідно з Постановою Пенсійного фонду N 16-3 ( z0813-08 ) від 13.08.2008 }

2.2. Між установою Національного банку України і одержувачем пенсії укладається договір, і одержувачу видається ощадна книжка, в якій обов'язково зазначаються прізвище, ім'я та по батькові, номер поточного рахунку та реквізити установи банку, або платіжна картка. Положення договору не можуть погіршувати умов виплати пенсій, встановлених цим Порядком. Умови договору повинні передбачати можливість його розриву за ініціативою однієї із сторін.

2.3. Заяви про виплату пенсій через установи Національного банку України подаються одержувачем до органів Пенсійного фонду України за місцем проживання одержувачів пенсій (за формою згідно з додатком 1).

Заяви одержувачів про зарахування сум пенсій на поточні рахунки приймаються органами Пенсійного фонду України за умови пред'явлення паспорта та реєструються в установленому порядку.

( Пункт 2.3 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

2.4. Одержувачі пенсій можуть у будь-який час змінити установу банку, подавши нову заяву відповідно до вимог пункту 2.3 цього Порядку. Залишки коштів одержувачів можуть перераховуватися в інший банк на підставі їх доручення.

2.5. У разі надходження до установи Національного банку України відомостей про смерть одержувача пенсії установа банку зобов'язана припинити зарахування коштів на поточний рахунок з місяця, наступного за місяцем смерті одержувача, і повідомити про це орган Пенсійного фонду України.

Суми пенсій, зараховані на поточний рахунок одержувача, починаючи з місяця, наступного за місяцем смерті пенсіонера, підлягають поверненню установою Національного банку України відповідно органам Пенсійного фонду. ( Абзац другий пункту 2.5 із змінами, внесеними згідно з Постановою Пенсійного фонду N 3-1 ( z0372-04 ) від 10.03.2004 )

Суми пенсій, що належали одержувачу і не були зараховані на поточний рахунок у зв'язку з його смертю, виплачуються згідно із статтею 52 Закону України "Про загальнообов'язкове державне пенсійне страхування" ( 1058-15 ). { Абзац третій пункту 2.5 із змінами, внесеними згідно з Постановами Пенсійного фонду N 3-1 ( z0372-04 ) від 10.03.2004, N 16-3 ( z0813-08 ) від 13.08.2008 } ( Пункт 2.5 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

2.6. Якщо суми пенсій не одержуються з поточного рахунку більш як один рік, установа Національного банку України зобов'язана повідомити про це відповідний орган Пенсійного фонду України. ( Пункт 2.6 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

3. Зарахування пенсій на поточні рахунки

3.1. Органи Пенсійного фонду України на підставі заяв одержувачів пенсій про відкриття поточних рахунків складають списки на зарахування пенсій (за формою згідно з додатком 2) у двох примірниках, в яких зазначаються прізвище, ім'я та по батькові пенсіонера, номер пенсійної справи, розмір призначеної пенсії за місяць та опис до них у трьох примірниках (за формою згідно з додатком 3). Списки у двох примірниках та описи до них у двох примірниках подають установам Національного банку України, щомісячно до 28-го числа.

На підставі складених документів органи Пенсійного фонду України проводять перерахування установі Національного банку України коштів, необхідних для виплати пенсій через поточні рахунки одержувачів.

( Пункт 3.1 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002, в редакції Постанови Пенсійного фонду Постановою Пенсійного фонду N 3-1 ( z0372-04 ) від 10.03.2004 )

3.2. Установи Національного банку України зараховують суми призначених пенсій на поточні рахунки пенсіонерів не пізніше наступного операційного дня з моменту надходження сум пенсій від органів Пенсійного фонду України. { Пункт 3.2 із змінами, внесеними згідно з Постановами Пенсійного фонду N 3-1 ( z0372-04 ) від 10.03.2004, N 16-3 ( z0813-08 ) від 13.08.2008 }

( Пункт 3.3 виключено на підставі Постанови Пенсійного фонду Постановою Пенсійного фонду N 3-1 ( z0372-04 ) від 10.03.2004 )

4. Виплата пенсій з поточних рахунків

4.1. Протягом двох днів після зарахування сум пенсій на поточні рахунки одержувачів установа Національного банку України повертає завірені підписами та печатками другі примірники списків та описів до них органу Пенсійного фонду України.

Незараховані суми пенсій не пізніше наступного операційного дня повертаються установою Національного банку України органам Пенсійного фонду України з відповідною поміткою "не зараховано" на других примірниках списків та описів до них. ( Пункт 4.1 доповнено абзацом другим згідно з Постановою Пенсійного фонду Постановою Пенсійного фонду N 3-1 ( z0372-04 ) від 10.03.2004 )

Суми пенсій не зараховуються на поточні рахунки у разі:

- невідповідності будь-яких реквізитів, зазначених у списках, даним поточного рахунку одержувача пенсії;

- наявності даних про смерть одержувача;

- закриття поточного рахунку;

- письмової вимоги органу Пенсійного фонду України.

( Пункт 4.1 доповнено абзацом третім згідно з Постановою Пенсійного фонду Постановою Пенсійного фонду N 3-1 ( z0372-04 ) від 10.03.2004 ) { Пункт 4.1 із змінами, внесеними згідно з Постановами Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002, N 3-1 ( z0372-04 ) від 10.03.2004, N 16-3 ( z0813-08 ) від 13.08.2008 }

4.2. Органи Пенсійного фонду України на підставі завірених списків та описів до них про зарахування сум пенсій на поточні рахунки одержувачів роблять необхідні відмітки в особових рахунках, що є підставою для здійснення органами Пенсійного фонду України бухгалтерських записів у дебет відповідних субрахунків видатків. ( Пункт 4.2 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002, в редакції Постанови Пенсійного фонду Постановою Пенсійного фонду N 3-1 ( z0372-04 ) від 10.03.2004 )

4.3. Одержувачі можуть отримувати належні їм суми пенсій після їх зарахування на поточні рахунки протягом робочого часу установи банку, на їх першу вимогу.

5. Прикінцеві положення

5.1. Облік операцій, пов'язаних з виплатою пенсій через поточні рахунки одержувачів, ведеться установою Національного банку України та органами Пенсійного фонду в порядку, що визначається нормативно-правовими актами Національного банку та Пенсійного фонду за погодженням з Мінфіном.

5.2. Установи Національного банку відкривають окремі аналітичні рахунки для зарахування коштів від органів Пенсійного фонду України. ( Розділ 5 доповнено пунктом 5.2 згідно з Постановою Пенсійного фонду Постановою Пенсійного фонду N 3-1 ( z0372-04 ) від 10.03.2004 )

5.3. Установи Національного банку України, за письмовими запитами органів Пенсійного фонду України, зобов'язані подавати інформацію про зарахування сум пенсій на поточні рахунки та їх закриття. ( Пункт із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

5.4. Контроль за додержанням цього Порядку здійснюється органами Пенсійного фонду України.

5.5. Особи, винні в порушенні цього Порядку, несуть відповідальність згідно з чинним законодавством України.
