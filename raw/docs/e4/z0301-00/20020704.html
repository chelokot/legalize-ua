N 7-4 від 27.04.2000 Зареєстровано в Міністерстві м.Київ юстиції України 24 травня 2000 р. vd20000427 vn7-4 за N 301/4522

Про затвердження Порядку виплати пенсій працівникам установ Національного банку України, які виходять на пенсію за віком як державні службовці

( Із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

Відповідно до пунктів 4, 9 Положення про Пенсійний фонд України, затвердженого постановою Кабінету Міністрів України від 1 червня 1994 р. N 345 ( 345-94-п ), та пункту 3 постанови Кабінету Міністрів України від 28 січня 2000 р. N 166 ( 166-2000-п ) "Про реалізацію статті 64 Закону України "Про Національний банк України" при визначенні пенсії відповідно до Закону України "Про державну службу", правління Пенсійного фонду України ПОСТАНОВЛЯЄ:

1. Затвердити Порядок виплати пенсій працівникам установ Національного банку України, які виходять на пенсію за віком як державні службовці (додається).

2. Управлінням виконання бюджету, юридичному та надходження доходів Пенсійного фонду України подати Порядок для реєстрації до Міністерства юстиції України.

Голова правління Б.О.Зайчук

Затверджено Постанова правління Пенсійного фонду України 27.04.2000 N 7-4

Зареєстровано в Міністерстві юстиції України 24 травня 2000 р. за N 301/4522

Порядок виплати пенсій працівникам установ Національного банку України, які виходять на пенсію за віком як державні службовці

1. Загальні положення

1.1. Цей Порядок підготовлений відповідно до пункту 3 постанови Кабінету Міністрів України від 28 січня 2000 р. N 166 ( 166-2000-п ) "Про реалізацію статті 64 Закону України "Про Національний банк України" при визначенні пенсії відповідно до Закону України "Про державну службу" і регулює питання виплати пенсій працівникам установ Національного банку України, які виходять на пенсію за віком як державні службовці (далі - одержувачі), за їх згодою через вклади до запитання (поточні рахунки) в установах Національного банку України.

1.2. Виплата пенсій згідно з цим Порядком здійснюється через поточні рахунки, що відкриваються в установах Національного банку України, з яким Пенсійний фонд України укладає відповідну угоду з визначенням санкцій за недотримання ним договору перед одержувачами. ( Пункт 1.2 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

1.3. Виплата пенсій відповідно до цього Порядку здійснюється за місцем функціонування установ Національного банку України.

1.4. Установи Національного банку України здійснюють відкриття поточних рахунків, проводять операції з зарахування сум пенсій на поточні рахунки відповідно до цього Порядку на підставі угод, укладених ними з районними (міськими) відділами Пенсійного фонду або центрами з нарахування та виплати пенсій - у регіонах, де функціонують такі центри. ( Пункт 1.4 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

1.5. Операції з відкриття поточних рахунків, зарахування й виплати пенсій з них здійснюються установами Національного банку України безоплатно.

2. Відкриття поточних рахунків

2.1. Поточні рахунки одержувачам пенсій відкриваються установами Національного банку України в порядку, встановленому Інструкцією про відкриття банками рахунків у національній та іноземній валюті, затвердженою постановою Правління Національного банку України від 18 грудня 1998 р. N 527 ( z0819-98 ) і зареєстрованою в Міністерстві юстиції України 24.12.98 за N 819/3259.

2.2. Між установою Національного банку України і одержувачем пенсії укладається договір, і одержувачу видається ощадна книжка, в якій обов'язково зазначаються прізвище, ім'я та по батькові, номер поточного рахунку та реквізити установи банку, або платіжна картка. Положення договору не можуть погіршувати умов виплати пенсій, встановлених цим Порядком. Умови договору повинні передбачати можливість його розриву за ініціативою однієї із сторін.

2.3. Заяви про виплату пенсій через установи Національного банку України подаються одержувачем до органів Пенсійного фонду України за місцем проживання одержувачів пенсій (за формою згідно з додатком 1).

Заяви одержувачів про зарахування сум пенсій на поточні рахунки приймаються органами Пенсійного фонду України за умови пред'явлення паспорта та реєструються в установленому порядку.

( Пункт 2.3 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

2.4. Одержувачі пенсій можуть у будь-який час змінити установу банку, подавши нову заяву відповідно до вимог пункту 2.3 цього Порядку. Залишки коштів одержувачів можуть перераховуватися в інший банк на підставі їх доручення.

2.5. У разі надходження до установи Національного банку України відомостей про смерть одержувача пенсії установа банку зобов'язана припинити зарахування коштів на поточний рахунок з місяця, наступного за місяцем смерті одержувача, і повідомити про це орган Пенсійного фонду України.

Суми пенсій, зараховані на поточний рахунок одержувача, починаючи з місяця, наступного за місяцем смерті пенсіонера, підлягають поверненню установою Національного банку України відповідно органам Пенсійного фонду з відображенням суми переплат у звітності згідно з пунктом 3.3 цього Порядку.

Суми пенсій, що належали одержувачу і не були зараховані на поточний рахунок у зв'язку з його смертю, не включаються до спадщини і виплачуються згідно із статтею 91 Закону України "Про пенсійне забезпечення" ( 1788-12 ).

( Пункт 2.5 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

2.6. Якщо суми пенсій не одержуються з поточного рахунку більш як один рік, установа Національного банку України зобов'язана повідомити про це відповідний орган Пенсійного фонду України. ( Пункт 2.6 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

3. Зарахування пенсій на поточні рахунки

3.1. Органи Пенсійного фонду України на підставі заяв одержувачів пенсій про відкриття поточних рахунків подають установам Національного банку України, щомісячно до 28-го числа, списки на зарахування пенсій (за формою згідно з додатком 2) у двох примірниках, в яких зазначаються прізвище, ім'я та по батькові пенсіонера, номер пенсійної справи, розмір призначеної пенсії за місяць. ( Пункт 3.1 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

3.2. Установи Національного банку України зараховують суми призначених пенсій на поточні рахунки пенсіонерів кожного 1-го числа поточного місяця.

3.3. Установи Національного банку України зараховані суми пенсій на поточні рахунки відображають у рядку 11 "фактичні витрати управлінь НБУ на виплату пенсій пенсіонерам НБУ (-)" Розрахунку зобов'язання зі сплати збору на обов'язкове державне пенсійне страхування (за формою згідно з додатком 22 до Інструкції про порядок обчислення і сплати підприємствами, установами, організаціями та громадянами збору на обов'язкове державне пенсійне страхування, інших платежів, а також обліку їх надходження до Пенсійного фонду України, затвердженої постановою правління Пенсійного фонду України від 19.10.2001 N 16-6 ( z0998-01 ) та зареєстрованої в Міністерстві юстиції України 29.11.2001 за N 998/6189).

Зазначений звіт з указаним рядком подається до органів Пенсійного фонду України лише установами Національного банку України.

( Пункт 3.3 в редакції Постанови Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

4. Виплата пенсій з поточних рахунків

4.1. Протягом двох днів після зарахування сум пенсій на поточні рахунки одержувачів установа Національного банку України повертає завірені підписами та печатками другі примірники списків органу Пенсійного фонду України. ( Пункт 4.1 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

4.2. Органи Пенсійного фонду України на підставі завірених списків про зарахування сум пенсій на поточні рахунки одержувачів роблять необхідні відмітки в особових рахунках, без здійснення бухгалтерських записів у дебет відповідних субрахунків видатків і без відображення їх у місячній звітності за формою 2а "Звіт про виплату пенсій та допомоги" (згідно з додатком 2 до Інструкції по бухгалтерському обліку та звітності в органах Пенсійного фонду України, затвердженої постановою правління Пенсійного фонду України 13.12.94 N 11-4 ( z0046-95 ) та зареєстрованої в Міністерстві юстиції України 23.02.95 за N 46/582, зі змінами та доповненнями, затвердженими постановами правління Пенсійного фонду України 04.07.96 N 8-1 ( z0371-96 ) і 23.02.98 N 2-1 ( z0157-98 ) та зареєстрованими в Міністерстві юстиції України 22.07.96 за N 371/1396 і 10.03.98 за N 157/2597). ( Пункт 4.2 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

4.3. Одержувачі можуть отримувати належні їм суми пенсій після їх зарахування на поточні рахунки протягом робочого часу установи банку, на їх першу вимогу.

5. Прикінцеві положення

5.1. Облік операцій, пов'язаних з виплатою пенсій через поточні рахунки одержувачів, ведеться установою Національного банку України та органами Пенсійного фонду в порядку, що визначається нормативно-правовими актами Національного банку та Пенсійного фонду за погодженням з Мінфіном.

5.2. Установи Національного банку України, за письмовими запитами органів Пенсійного фонду України, зобов'язані подавати інформацію про зарахування сум пенсій на поточні рахунки та їх закриття. ( Пункт 5.2 із змінами, внесеними згідно з Постановою Пенсійного фонду N 9-4 ( z0556-02 ) від 15.05.2002 )

5.3. Контроль за додержанням цього Порядку здійснюється органами Пенсійного фонду України.

5.4. Особи, винні в порушенні цього Порядку, несуть відповідальність згідно з чинним законодавством України.
