УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 43/2008 ( 43/2008 ) від 21.01.2008 }

Про внесення змін до Указу Президента України від 11 вересня 2006 року N 749

Відповідно до частини четвертої статті 107 Конституції України ( 254к/96-ВР ) постановляю:

На часткову зміну Указу Президента України від 11 вересня 2006 року N 749 ( 749/2006 ) "Про склад Ради національної безпеки і оборони України" (зі змінами, внесеними Указами від 20 вересня 2006 року N 761 ( 761/2006 ), від 17 жовтня 2006 року N 884 ( 884/2006 ), від 15 листопада 2006 року N 966 ( 966/2006 ), від 24 листопада 2006 року N 1000 ( 1000/2006 ), від 14 грудня 2006 року N 1074 ( 1074/2006 ), від 18 січня 2007 року N 24 ( 24/2007 ) та від 12 лютого 2007 року N 104 ( 104/2007 ) ввести до складу Ради національної безпеки і оборони України КИРИЧЕНКА Сергія Олександровича - начальника Генерального штабу - Головнокомандувача Збройних Сил України.
