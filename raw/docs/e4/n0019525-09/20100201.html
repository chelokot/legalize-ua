РАДА НАЦІОНАЛЬНОЇ БЕЗПЕКИ І ОБОРОНИ УКРАЇНИ

РІШЕННЯ

Щодо участі України в операції Європейського Союзу "EU NAVFOR ATALANTA"

{ Рішення введено в дію Указом Президента N 41/2010 ( 41/2010 ) від 20.01.2010 }

Ураховуючи зобов'язання України як держави - члена Організації Об'єднаних Націй,

беручи до уваги Резолюції Ради Безпеки ООН N 1814 ( 995_h04 ) від 15 травня 2008 року, N 1816 ( 995_h12 ) від 2 червня 2008 року, N 1838 ( 995_h42 ) від 7 жовтня 2008 року, N 1844 ( 995_h56 ) від 20 листопада 2008 року, N 1851 ( 995_h68 ) від 16 грудня 2008 року та Угоду між Європейським Союзом і Україною про визначення загальної схеми участі України в операціях Європейського Союзу із врегулювання криз ( 994_648 ), ратифіковану Законом України від 6 березня 2008 року N 137-VI ( 137-17 ),

виходячи з необхідності забезпечення безпеки судноплавства у районі Африканського рогу, захисту прав, свобод та інтересів громадян України,

вважаючи, що розвиток довгострокового співробітництва України з Європейським Союзом у рамках Європейської політики безпеки і оборони сприятиме підтриманню миру і безпеки та національним інтересам держави,

Рада національної безпеки і оборони України вирішила:

1. Визнати за доцільне участь України в операції Європейського Союзу "EU NAVFOR ATALANTA".

2. Кабінету Міністрів України опрацювати питання щодо забезпечення участі України в операції Європейського Союзу "EU NAVFOR ATALANTA" та внесення в установленому порядку відповідних пропозицій.
