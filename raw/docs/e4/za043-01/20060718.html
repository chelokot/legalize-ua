ДЕРЖАВНА КОМІСІЯ З ЦІННИХ ПАПЕРІВ ТА ФОНДОВОГО РИНКУ

РІШЕННЯ

N 337 від 29.11.2001 Зареєстровано в Міністерстві юстиції України 17 грудня 2001 р. за N 1043/6234

{ Рішення втратило чинність на підставі Рішення Державної комісії з цінних паперів та фондового ринку

N 433 ( z0807-06 ) від 23.06.2006 }

Про затвердження змін та доповнень до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів

Відповідно до Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ) та з метою удосконалення процедури ліцензування професійних учасників ринку цінних паперів Державна комісія з цінних паперів та фондового ринку ВИРІШИЛА:

1. Затвердити зміни та доповнення до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів, затверджених наказом Держпідприємництва України від 14.03.01 N 49 ( za318-01 ) та рішенням Державної комісії з цінних паперів та фондового ринку від 14.03.01 N 60 ( z0318-01 ), зареєстрованих Міністерством юстиції України від 06.04.01 за N 318/5509 ( z1043-01 ).

2. Управлінню ліцензування діяльності професійних учасників ринку цінних паперів (К. Отченаш) забезпечити передачу змін та доповнень до Ліцензійних умов провадження професійної діяльності на ринку цінних паперів для затвердження до Державного комітету України з питань регуляторної політики та підприємництва та разом з Юридичним управлінням (Л. Волохов) забезпечити державну реєстрацію цього рішення в Міністерстві юстиції України.

3. Управлінню організаційного забезпечення (Н. Піскун) забезпечити публікацію цього рішення відповідно до чинного законодавства.

4. Рішення набирає чинності через десять днів після державної реєстрації.

5. Контроль за виконанням рішення покласти на члена Комісії - заступника Голови М. Волкова.

Голова Комісії О.Мозговий
