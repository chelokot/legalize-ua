Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 28 лютого 2005 р. N 158

Стан: Втратив чинність

Ідентифікатор: 44-2006-п

Текст документа від 14.02.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 січня 2006 р. N 44 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 202 ( 202-2007-п ) від 14.02.2007 }

Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 28 лютого 2005 р. N 158

Кабінет Міністрів України постановляє:

Внести зміну до підпункту 2 пункту 1 постанови Кабінету Міністрів України від 28 лютого 2005 р. N 158 ( 158-2005-п ) "Про часткове зняття обмежень щодо розпорядження об'єктами права державної власності" (Офіційний вісник України, 2005 р., N 9, ст. 472), доповнивши його після слів і цифр "більш як 50 відсотків статутного фонду" словами "крім випадків, установлених окремими рішеннями Кабінету Міністрів України".

Прем'єр-міністр України Ю.ЄХАНУРОВ
