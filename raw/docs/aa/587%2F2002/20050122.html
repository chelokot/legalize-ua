УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 77/2005 ( 77/2005 ) від 22.01.2005 )

Про внесення зміни до Указу Президента України від 17 травня 2001 року N 325

На зміну статті 2 Указу Президента України від 17 травня 2001 року N 325 ( 325/2001 ) "Про підготовку пропозицій щодо забезпечення гласності та відкритості діяльності органів державної влади" призначити МЕДВЕДЧУКА Віктора Володимировича - Главу Адміністрації Президента України - керівником робочої групи з підготовки пропозицій щодо забезпечення гласності та відкритості діяльності органів державної влади, увільнивши від виконання цих обов'язків Литвина В.М.

Президент України Л.КУЧМА
