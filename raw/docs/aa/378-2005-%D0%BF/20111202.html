Деякі питання виготовлення та використання бланків паспорта громадянина України для виїзду за кордон

Стан: Чинний

Ідентифікатор: 378-2005-п

Текст документа від 02.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 травня 2005 р. N 378 Київ

Деякі питання виготовлення та використання бланків паспорта громадянина України для виїзду за кордон

{ Із змінами, внесеними згідно з Постановами КМ N 327 ( 327-2006-п ) від 15.03.2006 N 858 ( 858-2007-п ) від 26.06.2007 N 810 ( 810-2009-п ) від 29.07.2009 N 1194 ( 1194-2011-п ) від 23.11.2011 }

У зв'язку з прийняттям Указу Президента України від 10 березня 2005 р. N 457 ( 457/2005 ) "Про внесення змін до Положення про паспорт громадянина України для виїзду за кордон та визнання такими, що втратили чинність, деяких указів Президента України" Кабінет Міністрів України постановляє:

1. Ліквідувати міжвідомчу комісію з питань координації робіт із створення та функціонування Єдиного державного реєстру фізичних осіб.

{ Пункт 2 втратив чинність на підставі Постанови КМ N 858 ( 858-2007-п ) від 26.06.2007 }

3. Внести до актів Кабінету Міністрів України зміни, що додаються.

4. Визнати такими, що втратили чинність, акти Кабінету Міністрів України згідно з переліком, що додається.

ПЕРЕЛІК актів Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 18 червня 2004 р. N 789 ( 789-2004-п ) "Про утворення міжвідомчої комісії з питань координації робіт із створення та функціонування Єдиного державного реєстру фізичних осіб" (Офіційний вісник України, 2004 р., N 25, ст. 1649).

2. Постанова Кабінету Міністрів України від 9 листопада 2004 р. N 1499 ( 1499-2004-п ) "Питання виготовлення ідентифікаційних документів, дані яких вносяться до Єдиного державного реєстру фізичних осіб" (Офіційний вісник України, 2004 р., N 45, ст. 2971).

3. Постанова Кабінету Міністрів України від 9 листопада 2004 р. N 1500 ( 1500-2004-п ) "Про затвердження Концепції створення Єдиного державного реєстру фізичних осіб" (Офіційний вісник України, 2004 р., N 45, ст. 2972).

4. Розпорядження Кабінету Міністрів України від 23 грудня 2004 р. N 935 ( 935-2004-р ) "Про внесення зміни до розпорядження Кабінету Міністрів України від 18 лютого 1998 р. N 96 і визнання такими, що втратили чинність, деяких розпоряджень Кабінету Міністрів України" (Офіційний вісник України, 2004 р., N 52, ст. 3454).

5. Постанова Кабінету Міністрів України від 23 грудня 2004 р. N 1723 ( 1723-2004-п ) "Про внесення змін до деяких постанов Кабінету Міністрів України" (Офіційний вісник України, 2004 р., N 51, ст. 3360).

6. Постанова Кабінету Міністрів України від 23 грудня 2004 р. N 1725 ( 1725-2004-п ) "Про затвердження технічного опису і зразка бланка паспорта громадянина України для виїзду за кордон" (Офіційний вісник України, 2004 р., N 52, ст. 3439).

7. Постанова Кабінету Міністрів України від 21 січня 2005 р. N 73 ( 73-2005-п ) "Про внесення зміни до пункту 3 постанови Кабінету Міністрів України від 23 грудня 2004 р. N 1725" (Офіційний вісник України, 2005 р., N 4, ст. 210).
