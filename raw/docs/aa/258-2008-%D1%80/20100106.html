КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 лютого 2008 р. N 258-р Київ

Про утворення комісії з розв'язання проблеми забезпечення житлом інвесторів, які зазнали збитків внаслідок діяльності групи будівельних компаній "Еліта-центр"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 140-р ( 140-2010-р ) від 06.01.2010 }

1. Утворити комісію з розв'язання проблеми забезпечення житлом інвесторів, які зазнали збитків внаслідок діяльності групи будівельних компаній "Еліта-центр", у складі згідно з додатком 1.

Дозволити голові комісії вносити у разі потреби зміни до її складу.

2. Затвердити план першочергових заходів з виконання Указу Президента України від 4 лютого 2008 р. N 89 ( 89/2008 ) "Про невідкладні заходи щодо розв'язання проблеми забезпечення житлом інвесторів, які зазнали збитків внаслідок діяльності групи будівельних компаній "Еліта-центр" згідно з додатком 2.
