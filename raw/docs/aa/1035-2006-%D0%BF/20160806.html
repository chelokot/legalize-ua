Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 липня 2006 р. N 1035 Київ

Про внесення змін до постанов Кабінету Міністрів України від 28 грудня 2000 р. N 1922 і від 26 жовтня 2001 р. N 1440

{ Із змінами, внесеними згідно з Постановою КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 28 грудня 2000 р. N 1922 ( 1922-2000-п ) "Про затвердження Положення про проведення атестації державних службовців" (Офіційний вісник України, 2001 р. , N 1-2, ст. 27; 2002 р., N 52, ст. 2397; 2003 р., N 23, ст. 1048, N 45, ст. 2352; 2005 р., N 20, ст. 1080) і від 26 жовтня 2001 р. N 1440 ( 1440-2001-п ) "Про затвердження Типового положення про проведення атестації посадових осіб місцевого самоврядування" (Офіційний вісник України, 2001 р., N 44, ст. 1983) зміни, що додаються.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 28

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 26 липня 2006 р. N 1035

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 28 грудня 2000 р. N 1922 ( 1922-2000-п ) і від 26 жовтня 2001 р. N 1440 ( 1440-2001-п )

{ Пункт 1 втратив чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

2. У Типовому положенні про проведення атестації посадових осіб місцевого самоврядування, затвердженому постановою Кабінету Міністрів України від 26 жовтня 2001 р. N 1440 ( 1440-2001-п ):

пункт 8 після слів "службових обов'язків" доповнити словами "знання та користування у своїй роботі державною мовою";

абзац другий пункту 10 після слів "стосунки з колегами" доповнити словами "знання та користування державною мовою під час виконання службових обов'язків".
