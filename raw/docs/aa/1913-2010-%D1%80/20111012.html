КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 вересня 2010 р. N 1913-р Київ

Про забезпечення підготовки та проведення у 2011 році в Україні 17-ї сесії Європейської конференції міністрів, відповідальних за регіональне та місцеве врядування

{ Із змінами, внесеними згідно з Розпорядженням КМ N 995-р ( 995-2011-р ) від 12.10.2011 }

1. Утворити Організаційний комітет з підготовки та проведення у 2011 році в Україні 17-ї сесії Європейської конференції міністрів, відповідальних за регіональне та місцеве врядування (далі - конференція), у складі згідно з додатком.

Надати голові Організаційного комітету право затвердити його персональний склад та вносити у разі потреби зміни до нього.

2. Затвердити план заходів з підготовки та проведення у 2011 році в Україні 17-ї сесії Європейської конференції міністрів, відповідальних за регіональне та місцеве врядування, що додається.

3. Визначити м. Київ місцем проведення конференції.

4. Міністерству регіонального розвитку, будівництва та житлово-комунального господарства разом з Міністерством фінансів передбачити у проекті Державного бюджету України на 2011 рік видатки на підготовку та проведення конференції виходячи з можливостей державного бюджету.

{ Пункт 4 із змінами, внесеними згідно з Розпорядженням КМ N 995-р ( 995-2011-р ) від 12.10.2011 }

5. Міністерству регіонального розвитку, будівництва та житлово-комунального господарства, Міністерству закордонних справ, Міністерству економічного розвитку і торгівлі, Міністерству фінансів, іншим заінтересованим центральним органам виконавчої влади, Київській міськдержадміністрації забезпечити підготовку та проведення конференції.

{ Пункт 5 в редакції Розпорядження КМ N 995-р ( 995-2011-р ) від 12.10.2011 }
