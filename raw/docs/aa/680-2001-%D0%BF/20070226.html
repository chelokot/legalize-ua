{ Із змінами, внесеними згідно з Постановою КМ N 999 ( 999-2006-п ) від 19.07.2006 }

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України зміни, що додаються.

Прем'єр-міністр України А.КІНАХ

Інд. 26

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 червня 2001 р. N 680

ЗМІНИ, що вносяться до деяких постанов Кабінету Міністрів України

{ Пункт 1 втратив чинність на підставі Постанови КМ N 999 ( 999-2006-п ) від 19.07.2006 }

2. У пункті 5 Положення про виплату інвалідам компенсацій на бензин, ремонт і технічне обслуговування автомобілів та на транспортне обслуговування, затвердженого постановою Кабінету Міністрів України від 17 березня 1998 р. N 296 ( 296-98-п ) (Офіційний вісник України, 1998 р., N 11, ст. 399), слова "підприємствами, організаціями, установами, з вини яких заподіяно каліцтво (захворювання)" замінити словами "робочими органами виконавчої дирекції Фонду соціального страхування від нещасних випадків на виробництві та професійного захворювання".
