Стан: Втратив чинність

Текст документа від 08.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 серпня 2000 р. N 1264 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про утворення Центру інформаційних ресурсів у структурі Секретаріату Кабінету Міністрів України

( Із змінами, внесеними згідно з Постановою КМ N 493 ( 493-2001-п ) від 15.05.2001 )

Кабінет Міністрів України постановляє:

Утворити в структурі Секретаріату Кабінету Міністрів України, затвердженій постановою Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) (Офіційний вісник України, 2000 р., N 4, ст. 110), Центр інформаційних ресурсів як структурний підрозділ Управління інформаційних ресурсів Департаменту внутрішньої політики Секретаріату Кабінету Міністрів України з трьох штатних одиниць. ( Абзац перший із змінами, внесеними згідно з Постановою КМ N 493 ( 493-2001-п ) від 15.05.2001 )

У зв'язку з цим збільшити граничну чисельність працівників Секретаріату Кабінету Міністрів України на одну одиницю і ввести її до штатного розпису зазначеного Центру.

Міністерству фінансів врахувати додаткові видатки по фонду оплати праці працівників Секретаріату Кабінету Міністрів України при уточненні показників Державного бюджету України на 2000 рік.

Прем'єр-міністр України В.ЮЩЕНКО
