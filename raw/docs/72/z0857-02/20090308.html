Про затвердження Тимчасового переліку посад офіцерського складу, які в мирний час можуть заміщатися цивільними особами (на умовах строкового трудового договору)

{ Із змінами, внесеними згідно з Наказами Міністерства оборони N 338 ( z0930-03 ) від 08.10.2003 N 2 ( z0056-06 ) від 06.01.2006 N 631 ( z1202-06 ) від 01.11.2006 N 200 ( z0446-07 ) від 26.04.2007 N 355 ( z0691-07 ) від 16.06.2007 N 385 ( z0759-07 ) від 02.07.2007 N 72 ( z0186-08 ) від 27.02.2008 N 48 ( z0177-09 ) від 04.02.2009 }

Згідно зі статтею 6 Закону України "Про внесення змін до Закону України "Про загальний військовий обов'язок і військову службу" ( 766-14 ) та з метою поліпшення якості заміщення посад офіцерського складу Збройних Сил України цивільними особами НАКАЗУЮ:

1. Затвердити Тимчасовий перелік посад офіцерського складу, які в мирний час можуть заміщатися цивільними особами (на умовах строкового трудового договору), що додається.

2. Наказ розіслати до окремої військової частини.
