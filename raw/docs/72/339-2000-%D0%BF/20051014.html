ПОСТАНОВА від 17 лютого 2000 р. N 339 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1020 ( 1020-2005-п ) від 14.10.2005 )

Про урядові комітети

( Із змінами, внесеними згідно з Постановами КМ N 1723 ( 1723-2000-п ) від 20.11.2000 N 154 ( 154-2001-п ) від 16.02.2001 N 656 ( 656-2001-п ) від 18.06.2001 N 1165 ( 1165-2001-п ) від 13.09.2001 N 1538 ( 1538-2001-п ) від 17.11.2001 N 1679 ( 1679-2001-п ) від 13.12.2001 N 810 ( 810-2002-п ) від 13.06.2002 N 1179 ( 1179-2002-п ) від 19.08.2002 N 1443 ( 1443-2002-п ) від 26.09.2002 N 1853 ( 1853-2002-п ) від 12.12.2002 N 577 ( 577-2003-п ) від 23.04.2003 N 461 ( 461-2004-п ) від 14.04.2004 N 472 ( 472-2004-п ) від 14.04.2004 )

З метою підвищення ефективності діяльності Кабінету Міністрів України та координації роботи центральних органів виконавчої влади у формуванні та реалізації державної політики Кабінет Міністрів України постановляє:

1. Установити, що в Кабінеті Міністрів України діють такі урядові комітети:

Урядовий комітет з питань оборони, оборонно-промислового комплексу та правоохоронної діяльності;

Урядовий комітет з питань промислової політики, паливно-енергетичного комплексу, екології та надзвичайних ситуацій;

Урядовий комітет економічного розвитку та з питань європейської інтеграції;

Урядовий комітет соціального, науково-технічного та гуманітарного розвитку;

Урядовий комітет з реформування аграрного сектору.

( Пункт 1 із змінами, внесеними згідно з Постановами КМ N 1723 ( 1723-2000-п ) від 20.11.2000, N 154 ( 154-2001-п ) від 16.02.2001; в редакції Постанови КМ N 1165 ( 1165-2001-п ) від 13.09.2001 )

2. Затвердити Загальне положення про Урядовий комітет (додається) і склад урядових комітетів згідно з додатками 1-5. ( Пункт 2 із змінами, внесеними згідно із змінами, внесеними згідно з Постановою КМ N 461 ( 461-2004-п ) від 14.04.2004 )

3. Установити, що проекти актів законодавства та інших документів подаються на розгляд Кабінету Міністрів України лише за умови попереднього їх схвалення відповідним Урядовим комітетом. У виняткових випадках, коли проекти актів законодавства та інших документів потребують невідкладного розгляду Кабінетом Міністрів України, за рішенням Прем'єр-міністра України вони можуть включатися до порядку денного засідання Кабінету Міністрів України без попереднього схвалення їх Урядовим комітетом.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 17 лютого 2000 р. N 339

ЗАГАЛЬНЕ ПОЛОЖЕННЯ про Урядовий комітет

1. Урядовий комітет є робочим органом Кабінету Міністрів України, основним завданням якого є формування та реалізація державної політики у відповідній сфері згідно із стратегією, визначеною Кабінетом Міністрів України.

2. Урядовий комітет у своїй діяльності керується Конституцією ( 254к/96-ВР ) і законами України, актами Президента України та Кабінету Міністрів України, а також цим Положенням.

3. Урядовий комітет:

розглядає та схвалює концепції проектів нормативно-правових актів та інших документів, що підлягають розробленню;

розглядає, врегульовує розбіжності та схвалює проекти нормативно-правових актів та інших документів, що подаються на розгляд Кабінету Міністрів України відповідно до встановленого регламенту;

розглядає інші питання, пов'язані з формуванням та реалізацією державної політики у відповідній сфері;

приймає рішення про оприлюднення проектів регуляторних актів, які не оприлюднювалися до внесення їх на розгляд Кабінету Міністрів України, та повторне оприлюднення проектів цих актів; ( Пункт 3 доповнено абзацом згідно з Постановою КМ N 472 ( 472-2004-п ) від 14.04.2004 )

приймає рішення про необхідність перегляду регуляторних актів, прийнятих Кабінетом Міністрів України, на підставі аналізу звітів про відстеження результативності цих актів. ( Пункт 3 доповнено абзацом згідно з Постановою КМ N 472 ( 472-2004-п ) від 14.04.2004 )

Скарги центральних органів виконавчої влади щодо відмови Держпідприємництва у погодженні проектів регуляторних актів, розроблених цими органами, а також центральних органів виконавчої влади, їх територіальних органів, Ради міністрів Автономної Республіки Крим, місцевих державних адміністрацій щодо рішень Держпідприємництва про необхідність усунення порушень принципів державної регуляторної політики у сфері господарської діяльності розглядає та приймає відповідне рішення за результатами їх розгляду Урядовий комітет економічного розвитку та з питань європейської інтеграції. ( Пункт 3 доповнено абзацом згідно з Постановою КМ N 472 ( 472-2004-п ) від 14.04.2004 )

4. Урядовий комітет має право:

1) створювати в разі потреби підкомітети, експертні комісії та робочі групи для розгляду окремих питань, що належать до його компетенції;

2) отримувати в установленому порядку від органів виконавчої влади необхідну для його роботи інформацію.

5. До складу Урядового комітету входять члени Кабінету Міністрів України, заступники Міністра Кабінету Міністрів України, керівники, заступники керівників центральних органів виконавчої влади, а також з правом дорадчого голосу народні депутати України (за згодою). ( Абзац перший пункту 5 в редакції Постанови КМ N 1723 ( 1723-2000-п ) від 20.11.2000, із змінами, внесеними згідно з Постановами КМ N 1179 ( 1179-2002-п ) від 19.08.2002, N 461 ( 461-2004-п ) від 14.04.2004 )

Склад Урядового комітету затверджується Кабінетом Міністрів України. ( Абзац другий пункту 5 в редакції Постанови КМ N 1723 ( 1723-2000-п ) від 20.11.2000 )

У роботі Комітету можуть брати участь з правом вирішального голосу члени Кабінету Міністрів України, які не входять до складу Урядового комітету.

6. Урядовий комітет очолює голова, який є Прем'єр-міністром України, Першим віце-прем'єр-міністром України або Віце-прем'єр-міністром України. ( Пункт 6 в редакції Постанови КМ N 1723 ( 1723-2000-п ) від 20.11.2000 )

7. Голова Урядового комітету несе персональну відповідальність за виконання покладених на Комітет завдань.

8. Організаційною формою роботи Урядового комітету є засідання, які скликаються за рішенням голови Комітету в міру потреби.

Засідання урядових комітетів проводяться у такі дні тижня: ( Абзац другий пункту 8 в редакції Постанови КМ N 461 ( 461-2004-п ) від 14.04.2004 )

Урядового комітету соціального, науково-технічного та гуманітарного розвитку і Урядового комітету з реформування аграрного сектору - у понеділок; ( Пункт 8 доповнено абзацом згідно з Постановою КМ N 461 ( 461-2004-п ) від 14.04.2004 )

Урядового комітету економічного розвитку та з питань європейської інтеграції і Урядового комітету з питань промислової політики, паливно-енергетичного комплексу, екології та надзвичайних ситуацій - у четвер; ( Пункт 8 доповнено абзацом згідно з Постановою КМ N 461 ( 461-2004-п ) від 14.04.2004 )

Урядового комітету з питань оборони, оборонно-промислового комплексу та правоохоронної діяльності - у п'ятницю. ( Пункт 8 доповнено абзацом згідно з Постановою КМ N 461 ( 461-2004-п ) від 14.04.2004 )

9. Засідання Урядового комітету вважається правоможним, якщо на ньому присутні не менш як дві третини членів Комітету.

У разі коли Міністр, керівник іншого центрального органу виконавчої влади, який є членом Урядового комітету, з поважних причин не може бути присутнім на засіданні Комітету, замість нього у роботі Комітету з правом вирішального голосу може брати участь один з його заступників (а замість керівника колегіального органу - один з членів цього органу) за попереднім погодженням з головою Урядового комітету. При цьому повинна бути дотримана умова абзацу першого цього пункту. ( Абзац другий пункту 9 в редакції Постанови КМ N 1723 ( 1723-2000-п ) від 20.11.2000, із змінами, внесеними згідно з Постановою КМ N 1853 ( 1853-2002-п ) від 12.12.2002 )

У разі відсутності голови Комітету засідання за його дорученням проводить один із членів Комітету. ( Пункт 9 доповнено абзацом третім згідно з Постановою КМ N 1723 ( 1723-2000-п ) від 20.11.2000 )

10. За рішенням голови Урядового комітету або за погодженням з ним у роботі Комітету можуть брати участь посадові особи органів виконавчої влади та Секретаріату Кабінету Міністрів України, якщо це необхідно для обговорення питання, включеного до порядку денного.

11. Порядок денний засідання Урядового комітету формується відповідальним секретарем Урядового комітету, визначеним із числа працівників структурного підрозділу Секретаріату Кабінету Міністрів України з питань організаційного забезпечення підготовки і проведення засідань урядових комітетів, та затверджується головою Комітету.

Відповідальний секретар Урядового комітету також забезпечує дотримання процедури підготовки і розгляду питань, ведення протоколу та оформлення прийнятих Урядовим комітетом рішень.

Проекти документів, що вносяться на розгляд урядових комітетів, повинні бути погоджені із заінтересованими органами державної влади та відповідати іншим вимогам, установленим Тимчасовим регламентом Кабінету Міністрів України ( 915-2000-п ). ( Пункт 11 в редакції Постанови КМ N 461 ( 461-2004-п ) від 14.04.2004 )

12. Рішення Урядового комітету приймаються шляхом консенсусу і оголошуються головуючим. ( Пункт 12 в редакції Постанови КМ N 1723 ( 1723-2000-п ) від 20.11.2000 )

13. Рішення Урядового комітету оформляються протоколом, який підписує голова Комітету.

14. Рішення Урядового комітету, прийняті в межах його компетенції, є обов'язковими для виконання.

Контроль за виконанням рішень Урядового комітету здійснює Секретаріат Кабінету Міністрів України.

15. Урядовий комітет у своїй роботі взаємодіє з іншими урядовими комітетами.

Для розгляду, врегулювання розбіжностей і схвалення проектів комплексних нормативно-правових актів та інших документів можуть провадитися спільні засідання урядових комітетів.

Спільні засідання урядових комітетів проводяться за погодженим рішенням голів відповідних комітетів.

16. Організаційне та матеріально-технічне забезпечення діяльності урядових комітетів здійснює Секретаріат Кабінету Міністрів України. ( Пункт 16 із змінами, внесеними згідно з Постановою КМ N 1723 ( 1723-2000-п ) від 20.11.2000, в редакції Постанови КМ N 461 ( 461-2004-п ) від 14.04.2004 )
