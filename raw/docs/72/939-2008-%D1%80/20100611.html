Про утворення Міжвідомчої робочої групи з питань реконструкції Національного спортивного комплексу "Олімпійський"

Текст документа від 11.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 липня 2008 р. N 939-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про утворення Міжвідомчої робочої групи з питань реконструкції Національного спортивного комплексу "Олімпійський"

1. Утворити Міжвідомчу робочу групу з питань реконструкції Національного спортивного комплексу "Олімпійський".

Затвердити головою Міжвідомчої робочої групи Віце-прем'єр-міністра України Васюника Івана Васильовича.

2. Голові Міжвідомчої робочої групи з питань реконструкції Національного спортивного комплексу "Олімпійський" затвердити її склад та вносити у разі потреби до нього зміни.

Прем'єр-міністр України Ю.ТИМОШЕНКО
