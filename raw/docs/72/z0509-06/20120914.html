МІНІСТЕРСТВО УКРАЇНИ У СПРАВАХ СІМ'Ї, МОЛОДІ ТА СПОРТУ

НАКАЗ

15.03.2006 N 793

Зареєстровано в Міністерстві юстиції України 3 травня 2006 р. за N 509/12383

{ Наказ втратив чинність на підставі Наказу Міністерства освіти і науки, молоді та спорту N 896 ( z1440-12 ) від 03.08.2012 }

Про внесення змін до наказу Міністерства України у справах сім'ї, молоді та спорту від 23 вересня 2005 року N 2098 "Про впорядкування умов оплати праці працівників бюджетних науково-дослідних установ Міністерства України у справах сім'ї, молоді та спорту"

На виконання постанови Кабінету Міністрів України від 20 лютого 2006 року N 172 ( 172-2006-п ) "Про встановлення посадового окладу (тарифної ставки) працівника I тарифного розряду Єдиної тарифної сітки та внесення змін у додаток 2 до постанови Кабінету Міністрів України від 30 серпня 2002 р. N 1298" НАКАЗУЮ:

1. Унести до наказу Міністерства України у справах сім'ї, молоді та спорту від 23 вересня 2005 року N 2098 ( z1286-05 ) "Про впорядкування умов оплати праці працівників бюджетних науково-дослідних установ Міністерства України у справах сім'ї, молоді та спорту", зареєстрованого в Міністерстві юстиції України 27 жовтня 2005 року за N 1286/11566, зміни, що додаються.

2. Керівникам бюджетних науково-дослідних установ провести розрахунки заробітної плати, починаючи з 1 січня 2006 року.

Міністр Ю.О.Павленко

ПОГОДЖЕНО: Заступник Міністра праці та соціальної політики України Н.І.Іванова

Заступник Міністра фінансів України В.М.Матвійчук

Голова Центрального комітету профспілки працівників культури України Л.Ф.Перелигіна

Додаток 1 до наказу Міністерства України у справах сім'ї, молоді та спорту 23.09.2005 N 2098 ( z1286-05 )

(у редакції наказу Мінсім'ямолодьспорту від 15.03.2006 N 793)
