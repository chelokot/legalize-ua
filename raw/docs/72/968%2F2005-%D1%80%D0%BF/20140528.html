N 929/2014-рп ( 929/2014-рп ) від 28.05.2014 }

Про Багатофункціональний культурний центр "Музей художника Івана Марчука"

( Із змінами, внесеними згідно з Розпорядженням Президента N 24/2006-рп ( 24/2006-рп ) від 06.02.2006 )

З метою популяризації кращих творів українського образотворчого, декоративно-ужиткового мистецтва, сприяння естетичному вихованню громадян, духовному збагаченню суспільства:

1. Підтримати ініціативу творчої громадськості щодо створення у місті Києві на Андріївському узвозі Багатофункціонального культурного центру "Музей художника Івана Марчука" (далі - Культурний центр).

( Із змінами, внесеними згідно з Розпорядженням Президента N 24/2006-рп ( 24/2006-рп ) від 06.02.2006 )

2. Київській міській державній адміністрації сприяти у вирішенні в установленому порядку питання щодо створення Культурного центру.

3. Міністерству культури і мистецтв України надати організаційно-методичну допомогу засновникам Культурного центру.

Президент України В.ЮЩЕНКО

м. Київ, 18 квітня 2005 року N 968/2005-рп
