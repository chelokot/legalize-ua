Кабінет Міністрів України; Розпорядження від 06.04.1999 № 272-р

Про утворення міжвідомчих робочих груп з координації роботи та підготовки проектів рішень щодо проведення пенсійної реформи

Стан: Втратив чинність

Ідентифікатор: 272-99-р

Текст документа від 28.04.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 квітня 1999 р. N 272-р Київ

( Із змінами, внесеними згідно з Розпорядженнями КМ N 1222-р ( 1222-99-р ) від 10.11.99 N 65-р ( 65-2000-р ) від 01.02.2000 N 201-р ( 201-2000-р ) від 28.04.2000 )

1. Прийняти погоджені пропозиції про утворення робочих груп у складі згідно з додатками 1 та 2 для координації роботи та підготовки проектів рішень щодо проведення пенсійної реформи, розроблення відповідних пропозицій та проектів законодавчих актів, їх фінансово-економічного обгрунтування.

2. Установити, що представники міністерств та інших центральних органів виконавчої влади, які включені до складу експертної робочої групи (додаток 2), залучаються (крім керівника групи) до роботи в цій групі на постійній основі на відповідний період.

Надати право керівнику експертної робочої групи залучати для виконання робіт висококваліфікованих спеціалістів, наукових і практичних працівників, співробітничати з міжнародними організаціями з питань одержання технічної допомоги в проведенні пенсійної реформи в Україні.

3. Міністру праці та соціальної політики Саханю І.Я. вирішити питання, пов'язані із створенням належних умов для роботи експертної робочої групи.

4. Контроль за виконанням цього розпорядження покласти на Віце-прем'єр-міністра України Жулинського М.Г.

( Пункт 4 в редакції Розпорядження КМ N 1222-р ( 1222-99-р ) від 10.11.99, із змінами, внесеними згідно з Розпорядженням КМ N 65-р ( 65-2000-р ) від 01.02.2000 )

5. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 12 вересня 1997 р. N 511 ( 511-97-р ).
