КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 січня 2002 р. N 89 Київ

( Постанова втрачає чинність з 01.01.2004 року на підставі Постанови КМ

N 1911 ( 1911-2002-п ) від 13.12.2002 )

Про внесення доповнень до постанови Кабінету Міністрів України від 11 вересня 1996 р. N 1094

( Дію Постанови відновлено згідно з Постановою КМ N 92 ( 92-2003-п ) від 18.01.2003 )

Кабінет Міністрів України постановляє:

1. Внести до переліку предметів промислового призначення, що застосовуються у виробничій сфері, вивезення (пересилання) яких громадянами України, іноземцями та особами без громадянства за межі митної території України забороняється, затвердженого постановою Кабінету Міністрів України від 11 вересня 1996 р. N 1094 ( 1094-96-п ) (ЗП України, 1996 р., N 17, ст. 486; Офіційний вісник України, 1997 р., число 36, с. 20), доповнення, що додаються.

2. Ця постанова набирає чинності з дня опублікування.

Прем'єр-міністр України А.КІНАХ

Інд. 27

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 січня 2002 р. N 89
