ПОСТАНОВА від 29 січня 2003 р. N 128 Київ

Про затвердження Прем'єр-міністра України Януковича В.Ф. керівником деяких консультативних, дорадчих та інших органів, утворених Кабінетом Міністрів України

( Із змінами, внесеними згідно з Постановами КМ N 753 ( 753-2005-п ) від 18.08.2005 N 1231 ( 1231-2005-п ) від 21.12.2005 )

Кабінет Міністрів України постановляє:

1. Затвердити Прем'єр-міністра України Януковича Віктора Федоровича:

( Абзац другий пункту 1 втратив чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

( Абзац третій пункту 1 втратив чинність на підставі Постанови КМ N 1231 ( 1231-2005-п ) від 21.12.2005 )

головою Організаційного комітету з підготовки та проведення заходів у зв'язку з 70-ми роковинами голодомору в Україні;

головою робочої групи з питань приватизації підприємств та ефективного управління корпоративними правами.

2. Увільнити Кінаха Анатолія Кириловича від обов'язків керівника органів, зазначених у пункті 1 цієї постанови.
