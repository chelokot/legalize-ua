{ Постанова втратила чинність на підставі Постанови КМ N 1146 ( 1146-2024-п ) від 04.10.2024 }

Про внесення змін до складу Державної акредитаційної комісії

Кабінет Міністрів України постановляє:

Ввести до складу Державної акредитаційної комісії, затвердженого постановою Кабінету Міністрів України від 12 лютого 1996 р. N 200 ( 200-96-п ) (ЗП України, 1996 р., N 7, ст. 216), Дідоренка Едуарда Олексійовича - ректора Луганського інституту внутрішніх справ.
