Президент України; Указ від 28.09.2007 № 925/2007

Про зупинення дії розпорядження Кабінету Міністрів України від 26 вересня 2007 року N 762-р

Стан: Втратив чинність

Ідентифікатор: 925/2007

Текст документа від 28.09.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії розпорядження Кабінету Міністрів України від 26 вересня 2007 року N 762-р

{ Додатково див. Конституційне подання Президента ( n0030100-07 ) від 28.09.2007 }

Кабінетом Міністрів України 26 вересня 2007 року видано розпорядження N 762-р ( 762-2007-р ), яким звільнено з посади одного із заступників Міністра оборони України.

Прийняття Кабінетом Міністрів України без погодження з Президентом України зазначеного рішення ( 762-2007-р ) щодо одного з керівників Міністерства оборони України, на яке Законом України "Про оборону України" ( 1932-12 ) покладено забезпечення проведення в життя державної політики у сфері оборони, функціонування, бойову та мобілізаційну готовність, боєздатність і підготовку Збройних Сил України до здійснення покладених на них функцій і завдань (стаття 10) ( 1932-12 ), не відповідає пунктам 1 та 17 частини першої статті 106 Конституції України ( 254к/96-ВР ), за якими Президент України забезпечує державну незалежність, національну безпеку, здійснює керівництво у сфері національної безпеки і оборони держави.

Отже, видавши розпорядження від 26 вересня 2007 року N 762-р ( 762-2007-р ), Кабінет Міністрів України діяв усупереч названим нормам Конституції України ( 254к/96-ВР ), чим також порушив і вимоги частини другої статті 8 Основного Закону ( 254к/96-ВР ) держави, за якими Конституція України ( 254к/96-ВР ) має найвищу юридичну силу, нормативно-правові акти приймаються на основі Конституції України ( 254к/96-ВР ) і повинні відповідати їй.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 26 вересня 2007 року N 762-р ( 762-2007-р ) "Про звільнення Терещенка В.І. з посади заступника Міністра оборони України".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
