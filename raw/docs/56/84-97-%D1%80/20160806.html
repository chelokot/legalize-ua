Кабінет Міністрів України; Розпорядження від 08.02.1997 № 84-р

Про віднесення посад державних службовців Автономної Республіки Крим до відповідних категорій

Стан: Втратив чинність

Ідентифікатор: 84-97-р

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 лютого 1997 р. N 84-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посаду головного державного інспектора праці Автономної Республіки Крим до третьої категорії посад державних службовців, заступників головного державного інспектора праці Автономної Республіки Крим - до четвертої категорії посад державних службовців, посади інших працівників територіальної державної інспекції праці Автономної Республіки Крим - до категорій відповідних посад працівників державних комітетів Автономної Республіки Крим.

Перший віце-прем'єр-міністр України В.ДУРДИНЕЦЬ
