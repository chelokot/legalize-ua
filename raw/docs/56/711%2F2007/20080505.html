Президент України; Указ, Склад колегіального органу від 15.08.2007 № 711/2007

Про оновлення складу Української частини Робочої групи (Секретаріату) з організаційного забезпечення діяльності Українсько-Російської міждержавної комісії

Стан: Втратив чинність

Ідентифікатор: 711/2007

Текст документа від 05.05.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 415/2008 ( 415/2008 ) від 05.05.2008 }

Про оновлення складу Української частини Робочої групи (Секретаріату) з організаційного забезпечення діяльності Українсько-Російської міждержавної комісії

З метою забезпечення ефективної діяльності Української частини Українсько-Російської міждержавної комісії постановляю:

1. Затвердити персональний склад Української частини Робочої групи (Секретаріату) з організаційного забезпечення діяльності Українсько-Російської міждержавної комісії (додається).

2. Надати право секретареві Української частини Робочої групи (Секретаріату) Українсько-Російської міждержавної комісії вносити в разі потреби зміни до складу Української частини Робочої групи (Секретаріату) з організаційного забезпечення діяльності Українсько-Російської міждержавної комісії.

3. Визнати таким, що втратив чинність, Указ Президента України від 17 березня 2007 року N 215 ( 215/2007 ) "Про склад Української частини Робочої групи (Секретаріату) з організаційного забезпечення діяльності Українсько-Російської міждержавної комісії".

Президент України В.ЮЩЕНКО

м. Київ, 15 серпня 2007 року N 711/2007
