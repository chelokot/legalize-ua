Кабінет Міністрів України; Розпорядження від 25.07.2002 № 419-р

Про встановлення плати за послуги, що надаються Державною комісією з цінних паперів та фондового ринку

Стан: Втратив чинність

Ідентифікатор: 419-2002-р

Текст документа від 01.07.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 липня 2002 р. N 419-р Київ

Про встановлення плати за послуги, що надаються Державною комісією з цінних паперів та фондового ринку

{ Із змінами, внесеними згідно з Розпорядженням КМ N 738-р ( 738-2009-р ) від 01.07.2009 }

Погодитися з рішенням Державної комісії з цінних паперів та фондового ринку про встановлення плати за надання послуг у сфері державного регулювання діяльності інститутів спільного інвестування у такому розмірі:

за реєстрацію регламенту інституту спільного інвестування та внесення його до Єдиного державного реєстру інститутів спільного інвестування - сімдесят неоподатковуваних мінімумів доходів громадян; { Абзац другий Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 738-р ( 738-2009-р ) від 01.07.2009 }

за внесення змін і доповнень до регламенту інституту спільного інвестування - тридцять п'ять неоподатковуваних мінімумів доходів громадян; { Абзац третій Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 738-р ( 738-2009-р ) від 01.07.2009 }

за видачу витягів з Єдиного державного реєстру інститутів спільного інвестування - двадцять неоподатковуваних мінімумів доходів громадян. { Абзац четвертий Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 738-р ( 738-2009-р ) від 01.07.2009 }

Кошти, отримувані Державною комісією з цінних паперів та фондового ринку від надання передбачених цим розпорядженням послуг, спрямовуються до державного бюджету.
