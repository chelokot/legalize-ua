УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до Указу Президента України від 21 березня 2002 року N 277

Внести до додатка N 1 до Указу Президента України від 21 березня 2002 року N 277 ( 277/2002 ) "Про переліки посад військовослужбовців і працівників правоохоронних органів, що підлягають заміщенню особами вищого офіцерського (начальницького) складу, та граничних військових і спеціальних звань за цими посадами" (в редакції Указу від 19 квітня 2006 року N 312 ( 312/2006 ), зі змінами, внесеними Указами від 16 червня 2006 року N 530 ( 530/2006 ), від 21 травня 2007 року N 436 ( 436/2007 ) та від 25 жовтня 2007 року N 1020) ( 1020/2007 ) такі зміни:

1) у розділі "Центральний апарат Міністерства оборони України" позицію "Головний інспектор Сухопутних військ" замінити двома позиціями такого змісту:

------------------------------------------------------------------

|інспектора - Головний військовий| |

|інспектор Головної інспекції | |

|--------------------------------+-------------------------------|

|Головний інспектор Сухопутних |генерал-майор"; |

|військ | |

------------------------------------------------------------------

2) у розділі "Інші установи та заклади Збройних Сил України":

позицію "Начальник Української військово-медичної академії" виключити;

позицію "Начальник головного військово-медичного клінічного центру" викласти в такій редакції:

------------------------------------------------------------------

|"Начальник головного військово- |генерал-майор медичної служби".|

|медичного клінічного центру | |
