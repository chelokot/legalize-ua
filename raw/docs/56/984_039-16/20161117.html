МОДУЛЬ 1. Підприємства та інформаційне суспільство

A. ТЕМИ ТА ЇХНІ ХАРАКТЕРИСТИКИ

(1) Теми, які повинні бути охоплені за 2017 референтний рік, вибрані з переліку в додатку I до Регламенту (ЄС) № 808/2004:

(a) системи ІКТ та їх використання на підприємствах;

(b) використання мережі Інтернет та інших електронних мереж підприємствами;

(c) електронна комерція;

(d) електронні бізнес-процеси та організаційні аспекти;

(e) ІКТ-компетентність одиниці підприємства та потреба в навичках ІКТ;

(f) перешкоди для використання ІКТ, мережі Інтернет та інших електронних мереж, а також для електронної комерції та електронних бізнес-процесів;

(g) доступ до та використання технологій, які забезпечують можливість підключення до мережі Інтернет або інших мереж з будь-якого місця в будь-який час (повсюдне підключення).

(2) Характеристики підприємств, які повинні бути зібрані:

(a) Системи ІКТ та їх використання на підприємствах

(i) для всіх підприємств:

- використання комп’ютерів;

(ii) для підприємств, що використовують комп’ютери:

- (необов’язково) наймані працівники або відсоток загальної кількості найманих працівників, які використовують комп’ютери для службових цілей:

(b) Використання мережі Інтернет та інших електронних мереж підприємствами

(i) для підприємств, що використовують комп’ютери:

- доступ до мережі Інтернет;

(ii) для підприємств із доступом до мережі Інтернет:

- наймані працівники або відсоток загальної кількості найманих працівників, які використовують комп’ютери з доступом до мережі Інтернет для службових цілей;

- підключення до мережі Інтернет: DSL або будь-який інший тип фіксованого широкосмугового підключення;

- підключення до мережі Інтернет: мобільне широкосмугове підключення через переносний пристрій з використанням мереж мобільного телефонного зв’язку (принаймні 3G);

- наймані працівники або відсоток загальної кількості найманих працівників, які використовують наданий підприємством переносний пристрій, що уможливлює мобільне підключення до мережі Інтернет мережами мобільного телефонного зв’язку, для службових цілей;

- наявність вебсайту;

- використання соціальних мереж не тільки для розміщення платної реклами;

- використання блогів та мікроблогів підприємств не тільки для розміщення платної реклами;

- використання вебсайтів, призначених для спільного доступу до мультимедійного контенту, не тільки для розміщення платної реклами;

- використання інструментів на основі вікі для обміну знаннями не тільки для розміщення платної реклами;

(iii) для підприємств з підключенням DSL або іншим типом фіксованого широкосмугового підключення до мережі Інтернет:

- максимальна договірна швидкість завантаження для найшвидшого фіксованого підключення до мережі Інтернет у Мбіт/с у діапазонах: [0,< 2], [2,< 10], [10,< 30], [30,< 100], [> 100];

- достатність швидкості фіксованого підключення до мережі Інтернет з огляду на фактичні потреби підприємства;

(iv) для підприємств, які мають вебсайт, інформація про забезпечення таких можливостей:

- опис товарів або послуг, прейскуранти;

- онлайнове замовлення, резервування або бронювання;

- можливість відвідувачів налаштовувати або розробляти онлайнові товари чи послуги;

- відстеження розміщених замовлень або відображення їхнього статусу;

- персоналізований контент на вебсайті для постійних/повторних відвідувачів;

- посилання або покликання на сторінки підприємства в соціальних медіа;

(v) для підприємств, що використовують соціальні медіа, а саме соціальні мережі, блоги та мікроблоги підприємств, вебсайти для спільного доступу до мультимедійного контенту або інструменти на основі вікі для обміну знаннями, для цілей, інших ніж розміщення платної реклами:

- використання соціальних медіа для розроблення іміджу підприємства або реалізації продуктів;

- використання соціальних медіа для отримання думок, відгуків або запитань клієнтів або надання відповідей на них;

- використання соціальних медіа для залучення клієнтів до розроблення чи оновлення товарів або послуг;

- використання соціальних медіа для співпраці з діловими партнерами або іншими організаціями;

- використання соціальних медіа для найму працівників;

- використання соціальних медіа для обміну поглядами, думками або знаннями в межах підприємства.

(c) Електронна комерція

(i) для підприємств, що використовують комп’ютери:

- отримання замовлень на товари або послуги, які були розміщені через вебсайт або застосунки (вебпродажі) у попередньому календарному році;

- отримання замовлень на товари або послуги через повідомлення типу ЕОД (продажі типу ЕОД) у попередньому календарному році;

- (необов’язково) розміщення замовлень на товари або послуги через вебсайт, застосунки або повідомлення типу ЕОД у попередньому календарному році;

(ii) для підприємств, які отримували замовлення на товари або послуги, що були розміщені через вебсайт або застосунки в попередньому календарному році:

- вартість обороту, виражена в абсолютних цифрах або як відсоток загального обороту електронних продажів за замовленнями, розміщеними через вебсайт або застосунки, у попередньому календарному році;

- відсоток обороту, що став результатом замовлень, отриманих через вебсайт або застосунки, з розподілом за продажами приватним споживачам (бізнес для споживача: B2C) та продажами іншим підприємствам (бізнес для бізнесу: B2B) і органам публічної влади (бізнес для держави: B2G), у попередньому календарному році;

- отримання замовлень через вебсайт або застосунки підприємства (у тому числі материнських або афілійованих підприємств, екстрамережі) у попередньому календарному році;

- отримання замовлень через вебсайт торговельного майданчика електронної комерції або через застосунки, що їх використовують кілька підприємств для торгівлі продукцією, у попередньому календарному році;

- відсоток обороту, що став результатом замовлень, отриманих через вебсайт або застосунки, з розподілом за замовленнями, отриманими через вебсайт або застосунки підприємства (у тому числі материнських або афілійованих підприємств, екстрамережі), і за замовленнями, отриманими через вебсайт торговельного майданчика електронної комерції або застосунки, що їх використовують кілька підприємств для торгівлі продукцією, у попередньому календарному році;

- отримання замовлень, розміщених клієнтами через вебсайт або застосунки, за походженням: власна країна, у попередньому календарному році;

- отримання замовлень, розміщених клієнтами через вебсайт або застосунки, за походженням: інші держави-члени ЄС, у попередньому календарному році;

- отримання замовлень, розміщених клієнтами через вебсайт або застосунки, за походженням: інші країни світу, у попередньому календарному році;

- (необов’язково) відсоток обороту, що став результатом замовлень, отриманих через вебсайт або застосунки, з розподілом за походженням: власна країна, інші держави-члени ЄС та інші країни світу;

(iii) для підприємств, що отримували замовлення на товари або послуги через повідомлення типу ЕОД:

- вартість обороту або відсоток загального обсягу електронних продажів за замовленнями, які були отримані через повідомлення типу ЕОД, у попередньому календарному році;

- отримані замовлення, що були розміщені клієнтами через повідомлення типу ЕОД, за походженням: власна країна, у попередньому календарному році;

- отримані замовлення, що були розміщені клієнтами через повідомлення типу ЕОД, за походженням: інші держави-члени ЄС, у попередньому календарному році;

- отримані замовлення, що були розміщені клієнтами через повідомлення типу ЕОД, за походженням: інші країни світу, у попередньому календарному році;

(iv) для підприємств, що розміщували замовлення через вебсайт, застосунки або повідомлення типу ЕОД:

- (необов’язково) розміщення замовлень на товари або послуги через вебсайт або застосунки у попередньому календарному році;

- (необов’язково) розміщення замовлень на товари або послуги через повідомлення типу ЕОД у попередньому календарному році;

- (необов’язково) розміщення замовлень через вебсайт, застосунки або повідомлення типу ЕОД на товари або послуги вартістю принаймні 1% від загальної вартості купівель, у попередньому календарному році;

(v) для підприємств, які розміщували замовлення через вебсайт, застосунки або повідомлення типу ЕОД вартістю принаймні 1% від загальної вартості купівель, у попередньому календарному році:

- (необов’язково) розміщення замовлень через вебсайт, застосунки або повідомлення типу ЕОД для постачальників, які розташовані у країні розташування підприємства, у попередньому календарному році;

- (необов’язково) розміщення замовлень через вебсайт, застосунки або повідомлення типу ЕОД для постачальників, які розташовані в інших державах-членах ЄС, у попередньому календарному році;

- (необов’язково) розміщення замовлень через вебсайт, застосунки або повідомлення типу ЕОД для постачальників, які розташовані в інших країнах світу, у попередньому календарному році.

(d) Електронні бізнес-процеси та організаційні аспекти

(i) для підприємств, що використовують комп’ютери:

- використання пакету комп’ютерних програм ERP (планування ресурсів підприємства) для обміну інформацією між різними бізнес-функціями;

- використання будь-якої програми для управління інформацією про клієнтів (програмного забезпечення для управління відносинами з клієнтами (CRM)), що дає змогу збирати, зберігати та надавати іншим бізнес-функціям інформацію про клієнтів підприємства;

- використання будь-якої програми для управління інформацією про клієнтів (програмного забезпечення для управління відносинами з клієнтами (CRM)), що дає змогу аналізувати інформацію про клієнтів для маркетингових цілей;

- електронний обмін інформацією, пов’язаною з управлінням ланцюгом постачання, з іншими підприємствами, що є постачальниками або клієнтами;

- (необов’язково) виставлення/надсилання рахунків-фактур будь-якого типу в електронній або паперовій формі іншим підприємствам протягом попереднього календарного року;

- (необов’язково) виставлення/надсилання рахунків-фактур будь-якого типу в електронній або паперовій формі органам публічної влади протягом попереднього календарного року;

- (необов’язково) виставлення/надсилання рахунків-фактур будь-якого типу в електронній або паперовій формі приватним споживачам протягом попереднього календарного року;

- (необов’язково) відсоток усіх рахунків-фактур, отриманих як електронні рахунки-фактури у стандартному форматі, придатному для автоматизованого опрацювання (електронних рахунків-фактур), протягом попереднього календарного року;

- (необов’язково) відсоток усіх рахунків-фактур, отриманих як звичайні рахунки-фактури в паперовій або електронній формі, не придатній для автоматизованого опрацювання, протягом попереднього календарного року;

- використання інструментів радіочастотної ідентифікації для ідентифікування особи або контролювання доступу;

- використання інструментів радіочастотної ідентифікації в рамках процесу виробництва та надання послуг;

- використання інструментів радіочастотної ідентифікації для ідентифікування продукту після процесу виробництва;
