Питання Державного комітету України по геології і використанню надр

Стан: Втратив чинність

Ідентифікатор: 467-92-п

Текст документа від 28.09.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 серпня 1992 р. N 467 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1481 ( 1481-2000-п ) від 28.09.2000 )

Питання Державного комітету України по геології і використанню надр

( Із змінами, внесеними згідно з Постановою КМ N 387 ( 387-96-п ) від 01.04.96 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 387 ( 387-96-п ) від 01.04.96 )

2. Установити граничну чисельність працівників центрального апарату Державного комітету по геології і використанню надр у кількості 143 одиниці.

3. Дозволити Державному комітетові по геології і використанню надр мати трьох заступників голови Комітету, в тому числі одного першого, і колегію у кількості дев'яти чоловік.

4. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 23 вересня 1991 р. N 219 ( 219-91-п ) "Питання Державного комітету України по геології і використанню надр" ( ЗП України, 1991 р., N 10, ст. 90).

Прем'єр-міністр України В.ФОКІН
