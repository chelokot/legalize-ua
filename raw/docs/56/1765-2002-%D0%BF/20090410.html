Кабінет Міністрів України; Постанова від 16.11.2002 № 1765

Про внесення зміни до Статуту Державної акціонерної компанії "Українське видавничо-поліграфічне об'єднання"

Стан: Втратив чинність

Ідентифікатор: 1765-2002-п

Текст документа від 10.04.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 листопада 2002 р. N 1765 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 302 ( 302-2009-п ) від 02.04.2009 }

Про внесення зміни до Статуту Державної акціонерної компанії "Українське видавничо-поліграфічне об'єднання"

Кабінет Міністрів України постановляє:

Доповнити пункт 6.4 Статуту Державної акціонерної компанії "Українське видавничо-поліграфічне об'єднання", затвердженого постановою Кабінету Міністрів України від 26 листопада 1998 р. N 1870 ( 1870-98-п ) "Про забезпечення діяльності Державної акціонерної компанії "Українське видавничо-поліграфічне об'єднання" (Офіційний вісник України, 1998 р., N 47, ст. 1732) абзацом такого змісту:

"Державні пакети акцій відкритих акціонерних товариств та державне майно, які були передані до статутного фонду Компанії, не можуть бути відчужені (передані) або перебувати в заставі без рішення засновника".

Прем'єр-міністр України А.КІНАХ
