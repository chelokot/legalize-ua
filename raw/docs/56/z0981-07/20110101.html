{ Наказ втратив чинність на підставі Наказу Державного комітету статистики N 402 ( z0940-10 ) від 27.09.2010 }

Про внесення змін до наказу Держкомстату України від 29.11.2002 N 420

Відповідно до Закону України "Про державну статистику" ( 2614-12 ) та з метою приведення нормативно-правових актів у відповідність до чинного законодавства НАКАЗУЮ:

1. Визнати таким, що втратив чинність, починаючи зі звіту за 2007 рік, наказ Державного комітету статистики України від 29.11.2002 N 420 ( z0969-02 ) "Про затвердження форми державного статистичного спостереження з питань діяльності музеїв та Інструкції щодо її заповнення", зареєстрований у Міністерстві юстиції України 13.12.2002 за N 969/7257, у частині затвердження форми державного статистичного спостереження N 8-НК "Звіт про діяльність музею за 200__ рік".

2. Контроль за виконанням цього наказу покласти на заступника Голови Власенко Н.С.

В.о. Голови В.О.Піщейко
