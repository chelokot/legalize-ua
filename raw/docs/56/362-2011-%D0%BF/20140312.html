КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 квітня 2011 р. N 362 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 65 ( 65-2014-п ) від 01.03.2014 }

Деякі питання використання бюджетних коштів, передбачених для утримання Служби зовнішньої розвідки

Кабінет Міністрів України постановляє:

1. Внести зміну до пункту 1 заходів щодо економного та раціонального використання бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів, затверджених постановою Кабінету Міністрів України від 22 жовтня 2008 р. N 943 ( 943-2008-п ) "Про економію бюджетних коштів, передбачених для утримання органів державної влади та інших державних органів" (Офіційний вісник України, 2008 р., N 84, ст. 2816; 2009 р., N 45, ст. 1507, N 83, ст. 2823, N 95, ст. 3269; 2010 р., N 5, ст. 200, N 60, ст. 2094, N 74, ст. 2621, N 81, ст. 2847, N 96, ст. 3403, ст. 3406, N 98, ст. 3494, N 100, ст. 3550; 2011 р., N 2, ст. 111), доповнивши його після слова "СБУ," словами "Служби зовнішньої розвідки,".

2. Дозволити Службі зовнішньої розвідки придбати меблі, необхідні для облаштування адміністративної будівлі, переданої Службі відповідно до розпорядження Кабінету Міністрів України від 5 вересня 2007 р. N 692 ( 692-2007-р ).
