Кабінет Міністрів України; Розпорядження від 02.12.2009 № 1470-р

Деякі питання Національного олімпійського комітету

Стан: Чинний

Ідентифікатор: 1470-2009-р

Текст документа від 01.08.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 грудня 2009 р. N 1470-р Київ

Деякі питання Національного олімпійського комітету

{ Із змінами, внесеними згідно з Розпорядженням КМ N 570-р ( 570-2013-р ) від 01.08.2013 }

Надати Національному олімпійському комітетові дозвіл на включення зображення Державного Герба України та його імітацій до знака для товарів і послуг як елемента, що не охороняється, з подальшою реєстрацією такого знака в установленому порядку для використання у своїй діяльності.

{ Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 570-р ( 570-2013-р ) від 01.08.2013 }

Прем'єр-міністр України Ю.ТИМОШЕНКО
