ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

23.03.2011 N 229

Зареєстровано в Міністерстві юстиції України 19 квітня 2011 р. за N 485/19223

{ Наказ втратив чинність на підставі Наказу Міністерства фінансів N 1278 ( z2187-12 ) від 05.12.2012 }

Про внесення змін до Порядку роботи відділу митних платежів регіональної митниці, митниці при здійсненні контролю за правильністю визначення країни походження товарів, що переміщуються через митний кордон України, та прийняття рішень про визначення країни походження товару

Згідно з пунктом 5 Порядку визначення країни походження товару, що переміщується через митний кордон України, затвердженого постановою Кабінету Міністрів України від 12.12.2002 N 1864 ( 1864-2002-п ), підпунктом 7 пункту 4 Положення про Державну митну службу України, затвердженого постановою Кабінету Міністрів України від 18.07.2007 N 940 ( 940-2007-п ), з метою впорядкування контролю за правильністю визначення країни походження товарів, що переміщуються через митний кордон України, та з метою забезпечення можливості оперативного прийняття рішень про визначення країни походження товару, підвищення ефективності роботи митних органів з перевірки країни походження товарів, що ввозяться на митну територію України, НАКАЗУЮ:

1. Внести до Порядку роботи відділу митних платежів регіональної митниці, митниці при здійсненні контролю за правильністю визначення країни походження товарів, що переміщуються через митний кордон України, та прийняття рішень про визначення країни походження товару (далі - Порядок), затвердженого наказом Держмитслужби від 09.11.2009 N 1070 ( z1268-09 ), зареєстрованого в Міністерстві юстиції України 29.12.2009 за N 1268/17284, такі зміни:

1.1. Пункт 5.1 глави 5 викласти в такій редакції:

"5.1. Рішення оформлюється за допомогою програмно-інформаційного комплексу "Інспектор-2006" за підписом посадової особи відділу або посадової особи ПМО, яка його оформлювала, та начальника відділу (особи, яка його заміщує) або начальника митного поста (особи, яка його заміщує). Форму Рішення наведено в додатку 2 до цього Порядку".

1.2. Додаток 2 до Порядку ( z1268-09 ) після слів "Начальник відділу або особа, яка його заміщує" доповнити словами "(Начальник митного поста або особа, яка його заміщує)".

2. Управлінню митно-тарифного регулювання (Демченко В.І.) і Управлінню правового забезпечення (Чорна Г.М.) в установленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Установити, що цей наказ набирає чинності через десять днів після його офіційного опублікування.

4. Контроль за виконанням наказу покласти на першого заступника Голови Служби Гутника А.Є.
