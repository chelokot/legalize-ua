{ Постанова втратила чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Про затвердження членів колегії Державного комітету промислової політики

Кабінет Міністрів України постановляє:

1. Дозволити Державному комітету промислової політики мати колегію у кількості 13 чоловік.

2. Затвердити членами колегії Державного комітету промислової політики Зубарєва Валерія Володимировича, Качура Олександра Степановича, Кондрашова Миколу Миколайовича, Кравчука Володимира Івановича, Мінченка Миколу Миколайовича, Ноговіцина Олексія Володимировича, Рижова Володимира Леонідовича, Фількіна Михайла Петровича.
