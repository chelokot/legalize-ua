Про втрату чинності деяких наказів Міністерства транспорту України

Відповідно до Положення про Міністерство транспорту та зв'язку України, затвердженого постановою Кабінету Міністрів України від 6 червня 2006 року N 789 ( 789-2006-п ), НАКАЗУЮ:

1. Уважати такими, що втратили чинність, накази Міністерства транспорту України:

від 22 червня 1995 року N 239 ( z0189-95 ) "Про затвердження Тарифів на перевезення пасажирів і багажу залізничним транспортом в міждержавному сполученні", зареєстрований в Міністерстві юстиції України 23 червня 1995 року за N 189/725;

від 18 вересня 1995 року N 311 ( z0340-95 ) "Про затвердження Тарифів на перевезення пасажирів і багажу залізничним транспортом в міждержавному сполученні", зареєстрований в Міністерстві юстиції України 25 вересня 1995 року за N 340/876;

від 19 грудня 1996 року N 406 ( z0739-96 ) "Про затвердження Тарифів на перевезення пасажирів і багажу залізничним транспортом у внутрішньодержавному сполученні", зареєстрований в Міністерстві юстиції України 25 грудня 1996 року за N 739/1764;

від 3 грудня 1997 року N 410 ( z0585-97 ) "Про затвердження Тарифів на перевезення пасажирів і багажу залізничним транспортом у внутрішньодержавному сполученні", зареєстрований в Міністерстві юстиції України 11 грудня 1997 року за N 585/2389;

від 14 лютого 2000 року N 53 ( z0113-00 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні", зареєстрований в Міністерстві юстиції України 29 лютого 2000 року за N 113/4334;

від 4 травня 2000 року N 209 ( z0290-00 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід-Захід", зареєстрований в Міністерстві юстиції України 18 травня 2000 року за N 290/4511;

від 19 лютого 2001 року N 103 ( z0191-01 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та вантажобагажу залізничним транспортом у внутрішньодержавному сполученні", зареєстрований в Міністерстві юстиції України 5 березня 2001 року за N 191/5382;

від 2 грудня 2002 року N 853 ( z0947-02 ) "Про затвердження Тарифів на перевезення пасажирів, багажу та товаробагажу залізничним транспортом у міжнародному сполученні Схід-Захід", зареєстрований в Міністерстві юстиції України 4 грудня 2002 року за N 947/7235.

2. Державній адміністрації залізничного транспорту України (Козак В.В) подати цей наказ до Міністерства юстиції України на державну реєстрацію в установленому порядку.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Фоменко К.О.
