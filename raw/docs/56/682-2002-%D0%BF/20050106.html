КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 травня 2002 р. N 682 Київ

( Постанова втратила чинність на підставі Постанови КМ N 16 ( 16-2005-п ) від 06.01.2005 )

Про внесення змін до Положення про Моторне (транспортне) страхове бюро

Кабінет Міністрів України постановляє:

Абзац перший пункту 1 Положення про Моторне (транспортне) страхове бюро, затвердженого постановою Кабінету Міністрів України від 28 вересня 1996 р. N 1175 ( 1175-96-п ) "Про порядок і умови проведення обов'язкового страхування цивільної відповідальності власників транспортних засобів" (ЗП України, 1996 р., N 18, ст. 510; Офіційний вісник України, 1999 р., N 14, ст. 557), викласти у такій редакції:

"1. Моторне (транспортне) страхове бюро - юридична особа, яка створена згідно із законодавством, є неприбутковою організацією і діє на основі свого Статуту, який затверджується Кабінетом Міністрів України."
