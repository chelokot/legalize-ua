Ідентифікатор: 1029/2009

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 461/2010 ( 461/2010 ) від 31.03.2010 }

Про зупинення дії окремих положень деяких постанов Кабінету Міністрів України

{ Додатково див. Конституційне подання Президента ( n0049100-09 ) від 11.12.2009 }

Кабінет Міністрів України 26 листопада 2009 року видав постанову N 1256 ( 1256-2009-п ) "Питання залучення державним українським об'єднанням "Політехмед" у 2009 році іноземного кредиту під державну гарантію для реалізації інвестиційного проекту щодо закупівлі автомобілів швидкої медичної допомоги з метою посилення соціальної захищеності громадян України", якою погодився з пропозицією Міністерства охорони здоров'я України щодо залучення іноземного кредиту в сумі, що не перевищує 250 млн. доларів США, для реалізації інвестиційного проекту щодо закупівлі автомобілів швидкої медичної допомоги з метою посилення соціальної захищеності громадян України під державну гарантію (пункт 1) ( 1256-2009-п ). При цьому Кабінет Міністрів України доручив Міністерству охорони здоров'я України та Міністерству фінансів України забезпечити обслуговування іноземного кредиту та авансового платежу, а також інших платежів і витрат, пов'язаних із реалізацією інвестиційного проекту, за рахунок коштів Державного бюджету України на 2009 ( 835-17 ) та наступні роки (пункт 8) ( 1256-2009-п ), а також вирішив низку інших, пов'язаних із залученням під державну гарантію зазначеного кредиту, питань.

Також 26 листопада 2009 року Кабінет Міністрів України видав постанову N 1270 ( 1270-2009-п ) "Питання залучення у 2009 році під державну гарантію іноземного кредиту для реалізації інвестиційного проекту щодо закупівлі засобів реабілітації (автомобілів) для забезпечення інвалідів з метою посилення соціальної захищеності громадян України", якою погодився з пропозицією Міністерства праці та соціальної політики України щодо залучення іноземного кредиту в сумі, що не перевищує 400 млн. доларів США (за офіційним курсом гривні, встановленим Національним банком України на день здійснення платежів відповідно до контракту), для реалізації інвестиційного проекту щодо закупівлі засобів реабілітації (автомобілів) для забезпечення інвалідів з метою посилення соціальної захищеності громадян України під державну гарантію (пункт 1) ( 1270-2009-п ). Зазначеною постановою ( 1270-2009-п ) Кабінет Міністрів України доручив Міністерству фінансів України забезпечити обслуговування іноземного кредиту та авансового платежу, а також інших платежів і витрат, пов'язаних із реалізацією інвестиційного проекту, за рахунок коштів Державного бюджету України на 2010 та наступні роки, що передбачатимуться Міністерству праці та соціальної політики України (пункт 7) ( 1270-2009-п ), і вирішив низку інших, пов'язаних із залученням під державну гарантію зазначеного кредиту, питань.

Названі положення постанов Кабінету Міністрів України N 1256 ( 1256-2009-п ) та N 1270 ( 1270-2009-п ) не відповідають Конституції України ( 254к/96-ВР ), виходячи з такого.

За Конституцією України ( 254к/96-ВР ) Кабінет Міністрів України є вищим органом у системі органів виконавчої влади (частина перша статті 113) ( 254к/96-ВР ); органи законодавчої, виконавчої та судової влади здійснюють свої повноваження у встановлених Конституцією ( 254к/96-ВР ) межах і відповідно до законів України та зобов'язані діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України (частина друга статті 6, частина друга статті 19) ( 254к/96-ВР ); Кабінет Міністрів України у своїй діяльності керується Конституцією ( 254к/96-ВР ) та законами України, здійснює визначені Конституцією ( 254к/96-ВР ) та законами України повноваження (частина третя статті 113, пункт 10 статті 116) ( 254к/96-ВР ).

Основним Законом держави ( 254к/96-ВР ) також визначено, що виключно законами України встановлюються Державний бюджет України і бюджетна система України, виключно законом про Державний бюджет України визначаються будь-які видатки держави на загальносуспільні потреби, розмір і цільове спрямування цих видатків (пункт 1 частини другої статті 92, частина друга статті 95) ( 254к/96-ВР ). Конституцією України ( 254к/96-ВР ) також закріплюється принцип, за яким держава прагне до збалансованості бюджету України (частина третя статті 95) ( 254к/96-ВР ).

Законом України "Про Державний бюджет України на 2009 рік" ( 835-17 ) установлено, що у 2009 році державні гарантії надаються Кабінетом Міністрів України загалом в обсязі, що не перевищує 37.000.000 тис. гривень (частина перша статті 14) ( 835-17 ).

Після прийняття зазначених рішень Кабінетом Міністрів України взято зобов'язань щодо надання державних гарантій за кредитами на суму понад 63 млрд. гривень, що суттєво перевищує обсяг гарантій, передбачений Законом України "Про Державний бюджет України на 2009 рік" ( 835-17 ).

Відтак, вирішивши названими підзаконними актами питання щодо надання державних гарантій в сумі, що перевищує встановлений зазначеним Законом ( 835-17 ) граничний обсяг, а також установивши підзаконними актами, що обслуговування та погашення цих кредитів, внесення інших платежів, пов'язаних із реалізацією інвестиційного проекту, здійснюватиметься за рахунок коштів, які не передбачені Законом України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та ще не затверджені в установленому порядку законами про Державний бюджет України на наступні роки, Кабінет Міністрів України порушив наведені вище норми частини другої статті 6, частини другої статті 19, пункту 1 частини другої статті 92, частин другої та третьої статті 95, частини третьої статті 113, пункту 10 статті 116 Конституції України ( 254к/96-ВР ), перебрав на себе повноваження Верховної Ради України, а отже, порушив норми статті 75, пунктів 3 і 4 частини першої статті 85 та статті 91 Конституції України ( 254к/96-ВР ), за якими Верховна Рада України є єдиним органом законодавчої влади в Україні, затверджує Державний бюджет України та вносить зміни до нього.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію:

пунктів 1-8 постанови Кабінету Міністрів України від 26 листопада 2009 року N 1256 ( 1256-2009-п ) "Питання залучення державним українським об'єднанням "Політехмед" у 2009 році іноземного кредиту під державну гарантію для реалізації інвестиційного проекту щодо закупівлі автомобілів швидкої медичної допомоги з метою посилення соціальної захищеності громадян України";

пунктів 1-9 та 11 постанови Кабінету Міністрів України від 26 листопада 2009 року N 1270 ( 1270-2009-п ) "Питання залучення у 2009 році під державну гарантію іноземного кредиту для реалізації інвестиційного проекту щодо закупівлі засобів реабілітації (автомобілів) для забезпечення інвалідів з метою посилення соціальної захищеності громадян України".

2. Цей Указ набирає чинності з дня його опублікування.
