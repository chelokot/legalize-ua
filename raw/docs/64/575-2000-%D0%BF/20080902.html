КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 29 березня 2000 р. N 575 Київ

Про приведення рішень Кабінету Міністрів України у відповідність з Угодою про партнерство та співробітництво між Україною та Європейськими Співтовариствами (Європейським Союзом)

{ Із змінами, внесеними згідно з Постановою КМ N 760 ( 760-2008-п ) від 27.08.2008 }

З метою забезпечення виконання Угоди про партнерство та співробітництво між Україною та Європейськими Співтовариствами (Європейським Союзом) ( 998_012 ) Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 760 ( 760-2008-п ) від 27.08.2008 }

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком (додається).

3. Міністерствам та іншим центральним органам виконавчої влади привести свої нормативно-правові акти у відповідність із цією постановою.

4. Ця постанова набирає чинності з дня її опублікування.

Прем'єр-міністр України В.ЮЩЕНКО

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 29 березня 2000 р. N 575

1. Постанова Кабінету Міністрів України від 24 жовтня 1996 р. N 1282 ( 1282-96-п ) "Про мінімальну митну вартість імпортних автомобілів та шин до них" (ЗП України, 1996 р., N 19, ст. 534).

2. Постанова Кабінету Міністрів України від 27 січня 1997 р. N 63 ( 63-97-п ) "Про мінімальну митну вартість імпортних тютюнових виробів" (Офіційний вісник України, 1997 р., число 7, с. 23).

3. Постанова Кабінету Міністрів України від 27 січня 1997 р. N 64 ( 64-97-п ) "Про внесення змін до постанови Кабінету Міністрів України від 24 жовтня 1996 р. N 1282" (Офіційний вісник України, 1997 р., число 7, с. 25).

4. Постанова Кабінету Міністрів України від 24 січня 1997 р. N 75 ( 75-97-п ) "Про внесення зміни до постанови Кабінету Міністрів України від 24 жовтня 1996 р. N 1282" (Офіційний вісник України, 1997 р., число 5, с. 144).

5. Постанова Кабінету Міністрів України від 6 листопада 1997 р. N 1231 ( 1231-97-п ) "Про внесення змін і доповнень до постанови Кабінету Міністрів України від 27 січня 1997 р. N 63" (Офіційний вісник України, 1997 р., число 46, с. 48).

6. Абзац другий підпункту 1 пункту 1 та пункт 2 постанови Кабінету Міністрів України від 16 лютого 1998 р. N 146 ( 146-98-п ) "Про внесення змін та доповнень до деяких постанов Кабінету Міністрів України" (Офіційний вісник України, 1998 р., N 7, ст. 246).

8. Постанова Кабінету Міністрів України від 17 серпня 1998 р. N 1290 ( 1290-98-п ) "Про внесення доповнень до постанови Кабінету Міністрів України від 27 січня 1997 р. N 63" (Офіційний вісник України, 1998 р., N 33, ст. 1230).
