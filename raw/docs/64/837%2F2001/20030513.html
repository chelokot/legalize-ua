Президент України; Указ від 13.09.2001 № 837/2001

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

Стан: Втратив чинність

Ідентифікатор: 837/2001

Текст документа від 13.05.2003:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 402/2003 ( 402/2003 ) від 13.05.2003 )

Про внесення змін до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України

1. Увести до складу Координаційного комітету по боротьбі з корупцією і організованою злочинністю при Президентові України, затвердженого Указом Президента України від 31 грудня 1999 року N 1659 ( 1659/99 ) (із змінами, внесеними Указами від 28 січня 2000 року N 108 ( 108/2000 ) та від 19 квітня 2001 року N 266 ( 266/2001 ), таких осіб:

ГЕРМАНЧУК - Голова Головного контрольно-ревізійного

Петро Кузьмович управління України

МІЩЕНКО - начальник управління Генеральної прокуратури Сергій Григорович України, секретар Комітету.

2. Вивести зі складу цього Комітету Блажівського Є.М. та Каленського М.М.

Президент України Л.КУЧМА

м. Київ, 13 вересня 2001 року N 837/2001
