Президент України; Указ від 24.07.2001 № 547/2001

Про внесення змін до Указів Президента України від 25 грудня 2000 року N 1371 та від 14 лютого 2001 року N 95

Стан: Втратив чинність

Ідентифікатор: 547/2001

Текст документа від 06.11.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президент N 1435/2005 ( 1435/2005 ) від 12.10.2005 )

Про внесення змін до Указів Президента України від 25 грудня 2000 року N 1371 та від 14 лютого 2001 року N 95

1. Перейменувати Політичну раду при Президентові України у Всеукраїнську політичну консультативну раду.

2. Призначити БЄЛОВА Олександра Федоровича - заступника Глави Адміністрації Президента України - Керівника Головного управління з питань внутрішньої політики Адміністрації Президента України - Секретарем Всеукраїнської політичної консультативної ради.

3. Звільнити Пустовойтенка В.П. від обов'язків Секретаря Політичної ради при Президентові України.

4. В Указі Президента України від 25 грудня 2000 року N 1371 ( 1371/2000 ) "Про Політичну раду при Президентові України" та Указі Президента України від 14 лютого 2001 року N 95 ( 95/2001 ) "Про Положення про Політичну раду при Президентові України" і Положенні, затвердженому зазначеним Указом, слова "Політична рада при Президентові України" в усіх відмінках замінити словами "Всеукраїнська політична консультативна рада" у відповідних відмінках.

Президент України Л.КУЧМА
