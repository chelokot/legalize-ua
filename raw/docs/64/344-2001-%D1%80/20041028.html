Деякі питання ВАТ "Укртелеком"

Стан: Втратив чинність

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 9 серпня 2001 р. N 344-р Київ

Деякі питання ВАТ "Укртелеком"

( Із змінами, внесеними згідно з Розпорядженням КМ N 777-р ( 777-2004-р ) від 28.10.2004 )

1. Відповідно до статті 3 Закону України "Про особливості приватизації відкритого акціонерного товариства "Укртелеком" ( 1869-14 ) закріпити у державній власності пакет акцій у розмірі 50 відсотків статутного фонду ВАТ "Укртелеком" плюс одна акція.

( Пункт 2 втратив чинність на підставі Розпорядження КМ N 777-р ( 777-2004-р ) від 28.10.2004 )
