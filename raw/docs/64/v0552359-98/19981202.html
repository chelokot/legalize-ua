N 552 від 02.12.98 м.Київ

vd981202 vn552

Про призначення виборів народного депутата України замість депутата, який вибув, в одномандатному виборчому окрузі N 78, Запорізька область

На підставі Постанови Верховної Ради України від 17 листопада 1998 року N 247-XIV ( 247-14 ) "Про дострокове припинення повноважень народного депутата України Кузнецова О.Б." та відповідно до пункту 20 статті 11, статті 50 Закону України "Про вибори народних депутатів України" ( 541/97-ВР ) і пункту 23 статті 14 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ) Центральна виборча комісія ПОСТАНОВЛЯЄ:

1. Призначити вибори народного депутата України замість депутата, який вибув, в одномандатному виборчому окрузі N 78 Запорізької області на неділю, 14 березня 1999 року.

2. Цю постанову надіслати Запорізькій обласній раді та опублікувати в газеті "Голос України" і в місцевих засобах масової інформації в межах виборчого округу N 78.

Голова Центральної виборчої комісії М.Рябець
