КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 вересня 1995 р. N 741 Київ

( Постанова втратила чинність на підставі Постанови КМ N 746 ( 746-2005-п ) від 16.08.2005 )

Питання Державного комітету з енергозбереження

( Із змінами, внесеними згідно з Постановами КМ N 357 ( 357-2000-п ) від 18.02.2000 N 1925 ( 1925-2002-п ) від 17.12.2002 )

Відповідно до Указу Президента України від 26 липня 1995 р. N 666 ( 666/95 ) "Про утворення Державного комітету України з енергозбереження" Кабінет Міністрів України постановляє:

1. Установити граничну чисельність працівників центрального апарату Державного комітету з енергозбереження (далі - Комітет) у кількості 90 чоловік.

Дозволити Комітетові мати п'ятьох заступників голови, у тому числі одного першого. ( Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 1925 ( 1925-2002-п ) від 17.12.2002 )

2. Міністерству фінансів під час уточнення показників Державного бюджету України на 1995 рік передбачити витрати на утримання апарату Комітету. До внесення відповідних змін здійснювати фінансування Комітету за рахунок загального обсягу асигнувань, передбачених у державному бюджеті на утримання органів державної виконавчої влади.

( Пункт 3 втратив чинність на підставі Постанови КМ N 357 ( 357-2000-п ) від 18.02.2000 ) 3. Установити, що за умовами медичного, транспортного і побутового обслуговування голова Комітету, його заступники, керівники структурних підрозділів та їх заступники прирівнюються до відповідних категорій працівників міністерств.

4. Міністерству зв'язку забезпечити Комітет всіма видами зв'язку.

5. Утворити при Комітеті Державну інспекцію з енергозбереження з відділеннями на місцях для здійснення контролю за дотриманням нормативів витрат паливно-енергетичних ресурсів.
