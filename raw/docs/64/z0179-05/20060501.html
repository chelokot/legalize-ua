{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 134 ( z0460-06 ) від 14.04.2006 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 03.11.2000 N 299

На виконання постанови Кабінету Міністрів України від 15.01.2005 N 37 ( 37-2005-п ) "Про підвищення посадових окладів працівників апарату органів виконавчої влади, органів прокуратури, судів та інших органів" НАКАЗУЮ:

1. Унести зміни до наказу Міністерства праці та соціальної політики України від 03.11.2000 N 299 ( z0844-00 ) "Про умови оплати праці працівників Комітету з Державних премій України в галузі науки і техніки", зареєстрованого в Міністерстві юстиції України 21.11.2000 за N 844/5065 (зі змінами), виклавши додаток у новій редакції (додається).

2. Ці умови застосовуються з 1 січня 2005 року.

В.о. Міністра М.Папієв

Заступник Міністра фінансів України О.С.Яременко
