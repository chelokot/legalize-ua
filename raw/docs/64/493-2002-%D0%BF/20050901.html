Кабінет Міністрів України; Постанова від 11.04.2002 № 493

Про підвищення посадових окладів (ставок заробітної плати) працівників Національного заповідника "Софія Київська"

Стан: Втратив чинність

Ідентифікатор: 493-2002-п

Текст документа від 01.09.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 квітня 2002 р. N 493 Київ

( Постанова втратила чинність на підставі Постанови КМ N 790 ( 790-2005-п ) від 22.08.2005 )

Про підвищення посадових окладів (ставок заробітної плати) працівників Національного заповідника "Софія Київська"

( Про підвищення з 1 березня 2004 р. на 10,8 відсотка посадових окладів додатково див. Постанову КМ N 166 ( 166-2004-п ) від 11.02.2004 )

( Про підвищення з 1 січня 2005 р. у два рази діючих станом на 1 березня 2004 р. максимальні посадових окладів додатково див.

Постанову КМ N 995 ( 995-2004-п ) від 03.08.2004 )

( Про підвищення з 1 вересня 2004 р. у два рази діючих станом на 1 березня 2004 р. посадових окладів додатково див. Постанову КМ N 1051 ( 1051-2004-п ) від 16.08.2004 )

( Про підвищення з 1 квітня 2005 р. на 10,7 відсотка та з 1 липня 2005 р. на 6,9 відсотка посадових окладів додатково див. Постанову КМ N 267 ( 267-2005-п ) від 09.04.2005 )

Кабінет Міністрів України постановляє:

1. Підвищити з 1 квітня 2002 р. у 2 рази діючі посадові оклади (ставки заробітної плати) працівників Національного заповідника "Софія Київська".

2. Державному комітетові будівництва, архітектури та житлової політики провадити витрати, пов'язані із введенням у дію цієї постанови, в межах видатків, передбачених у Державному бюджеті України ( 2905-14 ) за бюджетною програмою "Збереження архітектурної спадщини в заповідниках" на оплату праці.

3. Міністерству культури і мистецтв, Державному комітетові будівництва, архітектури та житлової політики за погодженням з Міністерством праці та соціальної політики і Міністерством фінансів привести свої нормативно-правові акти з питань оплати праці працівників Національного заповідника "Софія Київська" у відповідність з цією постановою.

Прем'єр-міністр України А.КІНАХ
