КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 грудня 1998 р. N 1925 Київ

( Постанова втратила чинність на підставі Постанови КМ N 16 ( 16-2005-п ) від 06.01.2005 )

Про внесення змін до Положення про Моторне (транспортне) страхове бюро

З метою посилення контролю за діяльністю Моторного (транспортного) страхового бюро Кабінет Міністрів України постановляє:

Внести до пункту 3 Положення про Моторне (транспортне) страхове бюро, затвердженого постановою Кабінету Міністрів України від 28 вересня 1996 р. N 1175 ( 1175-96-п ) "Про порядок і умови проведення обов'язкового страхування цивільної відповідальності власників транспортних засобів" (ЗП України, 1996 р., N 18, ст. 510; Офіційний вісник України, 1998 р., N 27, ст. 1002) такі зміни:

абзац третій виключити;

абзац п'ятий викласти в такій редакції:

"Наглядову раду Моторного (транспортного) страхового бюро очолює голова, який затверджується Кабінетом Міністрів України за поданням Укрстрахнагляду".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
