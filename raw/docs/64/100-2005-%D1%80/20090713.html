РОЗПОРЯДЖЕННЯ від 13 квітня 2005 р. N 100-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 674 ( 674-2009-п ) від 01.07.2009 }

Про затвердження складу наглядової ради Національного заповідника "Замки Тернопілля"

На виконання Указу Президента України від 15 січня 2005 р. N 35 ( 35/2005 ) "Про надання Державному історико-архітектурному заповіднику у місті Збаражі статусу національного" затвердити склад наглядової ради Національного заповідника "Замки Тернопілля", що додається.

Інд. 21
