Про зміни у складі Комісії при Президентові України з питань громадянства

Стан: Втратив чинність

Ідентифікатор: 1094/2001

Текст документа від 30.04.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 740/2005 ( 740/2005 ) від 30.04.2005 )

Про зміни у складі Комісії при Президентові України з питань громадянства

1. Увести до складу Комісії при Президентові України з питань громадянства, затвердженого Указом Президента України від 9 грудня 1994 року N 746 ( 746/94 ) (із змінами, внесеними Указами від 22 квітня 1996 року N 275 ( 275/96 ), від 6 листопада 1997 року N 1254 ( 1254/97 ), від 13 жовтня 1998 року N 1135 ( 1135/98 ), від 6 березня 1999 року N 238 ( 238/99 ), від 7 червня 2000 року N 770 ( 770/2000 ) та від 28 лютого 2001 року N 120 ( 120/2001 ), таких осіб:

ВАРЕНКА - заступника Державного секретаря

Валерія Івановича Міністерства внутрішніх справ України

ЗАЙЦЯ - першого заступника Державного

Анатолія Павловича секретаря Міністерства юстиції України

МОЦИКА - заступника Державного секретаря

Олександра Федоровича Міністерства закордонних справ України

ШУЛЬГУ - заступника директора Інституту

Миколу Олександровича соціології НАН України.

2. Вивести зі складу зазначеної Комісії Сардачука П.Д., Стичинського Б.С., Харламова О.В.

Президент України Л.КУЧМА
