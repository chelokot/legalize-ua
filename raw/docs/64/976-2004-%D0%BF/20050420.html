Кабінет Міністрів України; Постанова від 28.07.2004 № 976

Про встановлення пільгового тарифу на перевезення дітей залізничним транспортом

Стан: Чинний

Ідентифікатор: 976-2004-п

Текст документа від 20.04.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 липня 2004 р. N 976 Київ

Про встановлення пільгового тарифу на перевезення дітей залізничним транспортом

( Із змінами, внесеними згідно з Постановою КМ N 305 ( 305-2005-п ) від 20.04.2005 )

Кабінет Міністрів України постановляє:

1. Установити пільговий тариф на перевезення залізничним транспортом у внутрішньому сполученні (у пасажирських вагонах усіх категорій) дітей віком від шести до чотирнадцяти років у розмірі 75 відсотків вартості проїзду дорослого пасажира.

2. Внести до Порядку обслуговування громадян залізничним транспортом, затвердженого постановою Кабінету Міністрів України від 19 березня 1997 р. N 252 ( 252-97-п ) (Офіційний вісник України, 1997, р., число 12, с. 167; 2002 р., N 34, ст. 1588, N 37, ст. 1736), такі зміни:

пункт 60 викласти в такій редакції:

"60. Діти віком до шести років, які не займають окремого місця, мають право на безоплатний проїзд без проїзного документа. Діти віком від шести до чотирнадцяти років мають право на проїзд за дитячими проїзними документами з наданням місця. Порядок проїзду дітей визначається Правилами";

пункт 61 після слів "на шляху прямування" доповнити словами пасажирського поїзда".

3. Міністерству фінансів, Міністерству у справах молоді та спорту щороку під час складання проекту Державного бюджету України передбачати видатки, пов'язані з наданням дітям пільг на проїзд залізничним транспортом.

( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 305 ( 305-2005-п ) від 20.04.2005 )

4. Міністерству у справах молоді та спорту здійснювати щомісяця перерахування залізницям коштів на підставі рахунків за перевезення дітей, складених ними за обліковою формою, встановленою Укрзалізницею.

( Пункт 4 із змінами, внесеними згідно з Постановою КМ N 305 ( 305-2005-п ) від 20.04.2005 )

5. Ця постанова набирає чинності з 1 січня 2005 року.
