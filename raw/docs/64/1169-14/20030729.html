Про внесення зміни до статті 25 Закону України "Про селянське (фермерське) господарство"

Стан: Втратив чинність

Ідентифікатор: 1169-14

Текст документа від 29.07.2003:

ЗАКОН УКРАЇНИ

( Закон втратив чинність на підставі Закону N 973-IV ( 973-15 ) від 19.06.2003, ВВР, 2003, N 45, ст.363 )

Про внесення зміни до статті 25 Закону України "Про селянське (фермерське) господарство"

( Відомості Верховної Ради України (ВВР), 2000, N 1, ст. 1 )

Верховна Рада України постановляє:

1. Частину першу статті 25 Закону України "Про селянське (фермерське) господарство" ( 2009-12 ) (Відомості Верховної Ради України, 1993 р., N 32, ст. 341) доповнити реченням такого змісту: "Селянське (фермерське) господарство самостійно визначає розмір готівки, що постійно знаходиться в його касі на поточні витрати".

2. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 20 жовтня 1999 року N 1169-XIV
