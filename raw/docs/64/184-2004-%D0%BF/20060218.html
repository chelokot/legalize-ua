( У назві і тексті постанови цифри "2004" замінено цифрами "2005" згідно з Постановою КМ N 34 ( 34-2005-п ) від 15.01.2005 )

( У назві і тексті постанови цифри "2005" замінено цифрами "2006" згідно з Постановою КМ N 165 ( 165-2006-п ) від 18.02.2006 )

Кабінет Міністрів України постановляє:

Затвердити Порядок використання коштів, передбачених у Державному бюджеті України на 2006 рік ( 3235-15 ) на здійснення фінансової підтримки підприємств агропромислового комплексу через механізм здешевлення коротко- і довгострокових кредитів, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 22

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 18 лютого 2004 р. N 184

ПОРЯДОК використання коштів, передбачених у Державному бюджеті України на 2006 рік ( 3235-15 ) на здійснення фінансової підтримки підприємств агропромислового комплексу через механізм здешевлення коротко- і довгострокових кредитів

( Назва Порядку із змінами, внесеними згідно з Постановами КМ N 34 ( 34-2005-п ) від 15.01.2005, N 165 ( 165-2006-п ) від 18.02.2006 )

1. Цей Порядок визначає механізм використання коштів, передбачених у Державному бюджеті України на 2006 рік ( 3235-15 ) на здійснення фінансової підтримки підприємств агропромислового комплексу шляхом часткової компенсації відсоткової ставки за залученими цими підприємствами у банках коротко- і довгостроковими кредитами, а також короткостроковими кредитами, залученими у кредитних спілках (далі - компенсація).

Короткостроковим вважається кредит, залучений на строк до одного року, а довгостроковим - до трьох років.

( Пункт 1 із змінами, внесеними згідно з Постановами КМ N 34 ( 34-2005-п ) від 15.01.2005, N 165 ( 165-2006-п ) від 18.02.2006 )

2. Мінагрополітики доводить до Міністерства аграрної політики Автономної Республіки Крим, головних управлінь агропромислового розвитку обласних та управління агропромислового розвитку Севастопольської міської держадміністрацій обсяги коштів, які передбачаються для компенсації, виходячи із середнього обсягу виробництва валової продукції сільського господарства за попередні п'ять років.

( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 165 ( 165-2006-п ) від 18.02.2006 )

3. Компенсація надається на конкурсній основі підприємствам агропромислового комплексу, які залучили кредити у поточному році (далі - позичальники), за умови, що відсоткова ставка за кредитами банків не перевищує 21 відсотків річних для короткострокових кредитів та 20 відсотків - для довгострокових, а за кредитами кредитних спілок - 27 відсотків річних. ( Абзац пункту 3 із змінами, внесеними згідно з Постановою КМ N 34 ( 34-2005-п ) від 15.01.2005 )

Підприємствам агропромислового комплексу, які отримали компенсацію за довгостроковими кредитами у 2004-2005 роках, компенсація у поточному році надається на умовах, передбачених пунктом 8 цього Порядку. ( Пункт 3 доповнено абзацом згідно з Постановою КМ N 34 ( 34-2005-п ) від 15.01.2005; із змінами, внесеними згідно з Постановою КМ N 165 ( 165-2006-п ) від 18.02.2006 )

4. Для проведення конкурсу та вирішення інших питань щодо здійснення компенсації Рада міністрів Автономної Республіки Крим, обласні та Севастопольська міська держадміністрації утворюють комісії, до складу яких включаються представники місцевих фінансових органів та територіальних управлінь Національного банку.

Комісію очолює відповідно заступник Голови Ради міністрів Автономної Республіки Крим, заступник голови облдержадміністрації з питань агропромислового комплексу та заступник голови Севастопольської міськдержадміністрації.

Порядок проведення конкурсу та перелік документів, які подаються комісії позичальниками, а також форму довідки, зазначеної в абзаці шостому цього пункту, визначає Мінагрополітики за погодженням з Мінфіном.

Перевага надається передусім позичальникам, які не мають простроченої більш як на два місяці заборгованості з виплати заробітної плати, а також заборгованості перед державним і місцевими бюджетами (податкові платежі, позички тощо) та Пенсійним фондом і з орендної плати за земельні та майнові паї, а також позичальникам, які уклали біржові угоди про продаж сільськогосподарської продукції врожаю поточного року. ( Абзац четвертий пункту 4 із змінами, внесеними згідно з Постановою КМ N 34 ( 34-2005-п ) від 15.01.2005 )

Інформація про проведення конкурсу оприлюднюється в друкованих засобах масової інформації відповідних органів виконавчої влади.

Переможцям конкурсу комісія видає довідку в межах ліміту, затвердженого Мінагрополітики, з урахуванням коштів, що необхідні для обслуговування довгострокових кредитів, отриманих у 2004-2005 роках, для пред'явлення її банкам (кредитним спілкам), які надали кредити. На підставі отриманої довідки банки (кредитні спілки) укладають додаткову кредитну угоду із позичальником, в якій зазначається розмір компенсації. ( Абзац шостий пункту 4 із змінами, внесеними згідно з Постановою КМ N 165 ( 165-2006-п ) від 18.02.2006 )

5. Компенсація за короткостроковими кредитами надається:

( Абзац другий пункту 5 виключено на підставі Постанови КМ N 34 ( 34-2005-п ) від 15.01.2005 )

сільськогосподарським підприємствам, рибницьким, рибальським та риболовецьким господарствам - на кредитування виробничих витрат, пов'язаних із закупівлею пально-мастильних матеріалів, кормів, ветеринарних препаратів, запасних частин для ремонту техніки та обладнання, а сільськогосподарським підприємствам, крім того, із закупівлею мінеральних добрив, засобів захисту рослин, насіння, молодняку сільськогосподарських тварин, птиці, яєць для інкубації, запасних частин для ремонту сільськогосподарської і зрошувальної техніки та обладнання, енергоносіїв, а також здійсненням платежів фінансового лізингу і страхових платежів, - для кредитів у національній валюті у розмірі 10 відсотків річних, в іноземній - 7 відсотків річних; ( Абзац третій пункту 5 із змінами, внесеними згідно з Постановою КМ N 34 ( 34-2005-п ) від 15.01.2005 )

іншим підприємствам та організаціям агропромислового комплексу, в тому числі споживчої кооперації, - виключно на кредитування закупівлі у сільськогосподарських товаровиробників виробленої ними сільськогосподарської продукції, а також цукровим заводам на авансування вирощування цукрових буряків - для кредитів у національній валюті у розмірі 7 відсотків річних;

сільськогосподарським товаровиробникам - на кредитування кредитними спілками виробничих витрат, пов'язаних із закупівлею насіння і посівного матеріалу, кормів, мінеральних добрив, засобів захисту рослин, пально-мастильних матеріалів, молодняку сільськогосподарських тварин, птиці, сільськогосподарського інвентарю, запасних частин для ремонту сільськогосподарської техніки, - для кредитів у національній валюті у розмірі 10 відсотків річних.

6. Компенсація за довгостроковими кредитами надається:

сільськогосподарським підприємствам - на кредитування витрат, пов'язаних з придбанням основних засобів сільськогосподарського призначення, в тому числі сільськогосподарської та зрошувальної техніки, - для кредитів у національній валюті у розмірі 14 відсотків річних, в іноземній - 9 відсотків річних;

сільськогосподарським підприємствам - на кредитування витрат, пов'язаних з будівництвом і реконструкцією виробничих об'єктів сільськогосподарського призначення та систем зрошення, а також придбанням обладнання для переробки сільськогосподарської продукції і здійсненням платежів фінансового лізингу, - для кредитів у національній валюті у розмірі 12 відсотків річних, в іноземній - 8 відсотків річних;

риболовецьким господарствам - на кредитування витрат, пов'язаних з будівництвом і придбанням риболовних суден, - для кредитів у національній валюті у розмірі 12 відсотків річних, в іноземній - 8 відсотків річних;

ремонтним та сервісним підприємствам системи агропромислового комплексу - на кредитування закупівлі технологічного обладнання - для кредитів у національній валюті у розмірі 12 відсотків річних, в іноземній - 8 відсотків річних;

іншим підприємствам агропромислового комплексу, у тому числі споживчої кооперації, - виключно на кредитування закупівлі обладнання для переробки сільськогосподарської продукції - для кредитів у національній валюті у розмірі 8 відсотків річних, в іноземній - 6 відсотків річних. ( Абзац пункту 6 із змінами, внесеними згідно з Постановою КМ N 34 ( 34-2005-п ) від 15.01.2005 )

7. У разі залучення кредитів в іноземній валюті сума компенсації визначається виходячи з офіційного курсу гривні до іноземної валюти, встановленого Національним банком на дату нарахування плати за кредит.

8. Для отримання суми компенсації банки, які надали коротко- чи довгострокові кредити, подають до 7 числа місяця, що настає за звітним, Міністерству аграрної політики Автономної Республіки Крим, головним управлінням агропромислового розвитку обласних та управлінню агропромислового розвитку Севастопольської міської держадміністрацій по два примірники реєстрів позичальників, які взяли кредити у цих банках і за результатами конкурсу отримали право на компенсацію (далі - реєстр позичальників), і нотаріально посвідчених копій укладених кредитних угод, а також виписку банку про отримання позичальниками кредиту та довідку-розрахунок банку про суму плати за кредит за відповідний період з визначенням суми, що відшкодовується за рахунок компенсації.

( Пункт 8 із змінами, внесеними згідно з Постановою КМ N 165 ( 165-2006-п ) від 18.02.2006 )

9. Для отримання суми компенсації кредитні спілки, які надали короткострокові кредити, подають до 7 числа місяця, що настає за звітним, Міністерству аграрної політики Автономної Республіки Крим, головним управлінням агропромислового розвитку обласних та управлінню агропромислового розвитку Севастопольської міської держадміністрацій інформаційну довідку про діяльність кредитної спілки, по два примірники реєстрів позичальників, копій укладених кредитних угод, виписку кредитної спілки про отримання позичальником кредиту та довідку-розрахунок кредитної спілки про суму плати за користування кредитом за відповідний період з визначенням суми, що відшкодовується за рахунок компенсації, а також копії розрахункових документів (рахунки-фактури, касові чеки, прибуткові касові ордери), що засвідчують цільове використання коштів на суму отриманих кредитів.

( Пункт 9 із змінами, внесеними згідно з Постановою КМ N 165 ( 165-2006-п ) від 18.02.2006 )

10. Міністерство аграрної політики Автономної Республіки Крим, головні управління агропромислового розвитку обласних та управління агропромислового розвитку Севастопольської міської держадміністрацій складають та затверджують реєстр компенсаційних виплат за відповідними адміністративно-територіальними одиницями в розрізі банків та кредитних спілок і протягом п'яти днів подають його в двох примірниках Мінагрополітики.

Мінагрополітики на підставі реєстрів подає Державному казначейству в установленому порядку розподіл коштів для касового виконання державного бюджету за видатками на здійснення компенсації. Державне казначейство спрямовує кошти через Міністерство аграрної політики Автономної Республіки Крим, головні управління агропромислового розвитку обласних та управління агропромислового розвитку Севастопольської міської держадміністрацій банкам та кредитним спілкам, що надали кредити. ( Пункт 10 із змінами, внесеними згідно з Постановою КМ N 165 ( 165-2006-п ) від 18.02.2006 )

11. Форма реєстру позичальників, інформаційної довідки про діяльність кредитної спілки та реєстру компенсаційних виплат за відповідними адміністративно-територіальними одиницями в розрізі банків та кредитних спілок затверджується Мінагрополітики.

12. Нарахування сум компенсації за короткостроковими кредитами здійснюється з 1 січня до 31 грудня 2006 р., а за довгостроковими - з 1 січня до 31 грудня 2006 року. При цьому компенсація за грудень за довгостроковими кредитами здійснюється шляхом внесення авансового платежу до 31 грудня 2006 року.

( Пункт 12 із змінами, внесеними згідно з Постановами КМ N 34 ( 34-2005-п ) від 15.01.2005, N 165 ( 165-2006-п ) від 18.02.2006 )

13. За умови сплати позичальником відсотків за користування кредитом у повному обсязі банк або кредитна спілка повертає відповідну суму на рахунок позичальника.

14. Фінансова звітність про використання коштів державного бюджету для здійснення компенсації складається і подається в установленому порядку.
