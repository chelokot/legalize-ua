Про затвердження Порядку використання коштів, передбачених у державному бюджеті для здійснення заходів щодо формування позитивного інвестиційного іміджу України

Стан: Чинний

Ідентифікатор: 694-2011-п

Текст документа від 29.03.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 червня 2011 р. N 694 Київ

Про затвердження Порядку використання коштів, передбачених у державному бюджеті для здійснення заходів щодо формування позитивного інвестиційного іміджу України

{ Із змінами, внесеними згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

Відповідно до частини сьомої статті 20 Бюджетного кодексу України ( 2456-17 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання коштів, передбачених у державному бюджеті для здійснення заходів щодо формування позитивного інвестиційного іміджу України, що додається.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 15 червня 2011 р. N 694

ПОРЯДОК використання коштів, передбачених у державному бюджеті для здійснення заходів щодо формування позитивного інвестиційного іміджу України

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті за програмою "Заходи щодо формування позитивного інвестиційного іміджу України" (далі - бюджетні кошти).

2. Головним розпорядником бюджетних коштів та відповідальним виконавцем бюджетної програми є Держінвестпроект.

3. Бюджетні кошти використовуються з метою формування позитивного інвестиційного іміджу України за кордоном, просування інвестиційних проектів, зростання надходжень іноземних інвестицій, інтеграції України у світовий економічний простір шляхом інвестиційного співробітництва України з іноземними державами та суб'єктами господарювання і спрямовуються на розроблення та здійснення комплексу заходів щодо:

проведення за участю перших осіб іноземних держав та представників провідних світових компаній, міжнародних фінансових організацій щорічного міжнародного інвестиційного форуму;

підготовки, видання та розповсюдження матеріалів, відео- та поліграфічної продукції для презентації національних проектів; { Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

презентації національних проектів, інвестиційних можливостей України для ділової еліти у провідних міжнародних фінансових центрах;

інформаційного забезпечення національних проектів, у тому числі створення та підтримки функціонування інтерактивного веб-порталу;

розміщення інформації про інвестиційні можливості України у провідних світових засобах масової інформації, Інтернеті та друкованих виданнях; { Абзац шостий пункту 3 із змінами, внесеними згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

надання потенційним іноземним інвесторам інформації про умови провадження підприємницької діяльності, інвестиційні можливості України та її регіонів, зокрема шляхом дослідження інвестиційної привабливості регіонів, проведення конференцій та семінарів. { Абзац сьомий пункту 3 із змінами, внесеними згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

4. Розподіл бюджетних коштів у розрізі заходів, зазначених у пункті 3 цього Порядку, здійснюється згідно з планом заходів щодо формування позитивного інвестиційного іміджу України (далі - план заходів), затвердженого Держінвестпроектом.

Держінвестпроект подає Мінфіну план заходів у двотижневий строк після його затвердження. { Пункт 4 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

Для проведення кожного заходу Держінвестпроектом видається наказ, у якому зазначаються найменування заходу, його виконавець, дата і місце проведення, сума витрат на підготовку та проведення. { Пункт 4 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

До наказу додається кошторис витрат, пов’язаних з підготовкою та проведенням заходу, з відповідними розрахунками та обґрунтуванням. { Пункт 4 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

Держінвестпроект подає щокварталу до 20 числа Мінфіну інформацію про виконання плану заходів. { Пункт 4 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

5. Використання бюджетних коштів здійснюється з урахуванням необхідності виконання бюджетних зобов'язань минулих років, узятих на облік органами Казначейства.

6. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законом порядку.

Не допускається спрямування бюджетних коштів на: { Пункт 6 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

здійснення заходів, придбання товарів, виконання робіт, надання послуг, не пов’язаних з напрямами використання бюджетних коштів, що визначені пунктом 3 цього Порядку; { Пункт 6 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

здійснення видатків, що передбачені іншими бюджетними програмами; { Пункт 6 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

оплату посередницьких послуг; { Пункт 6 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

оплату проїзду, проживання, харчування та виплату добових особам, які беруть участь у міжнародних інвестиційних заходах за кордоном та в Україні (форумах, конгресах, конференціях, семінарах тощо), крім оплати витрат, пов’язаних з відрядженням членів офіційних делегацій, склад яких погоджено в установленому порядку; { Пункт 6 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

придбання основних засобів (меблів, оргтехніки, комп’ютерів, транспортних засобів тощо), а також на утримання установ, підприємств, громадських об’єднань; { Пункт 6 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

здійснення заходів, метою яких є отримання прибутку. { Пункт 6 доповнено абзацом згідно з Постановою КМ N 177 ( 177-2013-п ) від 20.03.2013 }

7. Відображення у первинному та бухгалтерському обліку інформації про отримані (створені) оборотні і необоротні активи, а також відкриття рахунків, реєстрація, облік бюджетних зобов'язань в органах Казначейства та проведення операцій, пов'язаних з використанням бюджетних коштів, здійснюються в установленому законодавством порядку.

{ Пункт 7 в редакції Постанови КМ N 177 ( 177-2013-п ) від 20.03.2013 }

8. Складення та подання фінансової і бюджетної звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.
