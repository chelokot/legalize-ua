Кабінет Міністрів України; Розпорядження від 30.11.1998 № 992-р

Про дозвіл Держмитслужбі на здійснення митного оформлення обладнання для виробництва дроту та спеціальних цвяхів, яке надійшло на адресу українсько-американського СП "Нейл Лтд." (м. Хмельницький)

Стан: Втратив чинність

Ідентифікатор: 992-98-р

Текст документа від 05.05.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 листопада 1998 р. N 992-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 764 ( 764-2000-п ) від 05.05.2000 )

Дозволити Держмитслужбі здійснити митне оформлення обладнання для виробництва дроту та спеціальних цвяхів, яке надійшло на адресу українсько-американського спільного підприємства "Нейл Лтд." (м. Хмельницький) за контрактом від 21 січня 1997 р. N 20124-01/97, укладеного підприємством з фірмою "Херборн + Брайтенбах ГмбХ" (Німеччина), відповідно до порядку та за офіційним валютним курсом Національного банку, що діяли на дату ввезення вантажу на митну територію України.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
