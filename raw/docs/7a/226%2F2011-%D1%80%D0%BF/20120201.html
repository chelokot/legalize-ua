Про міжвідомчу робочу групу з аналізу стану додержання законодавства про свободу слова та захист прав журналістів

Стан: Втратив чинність

Ідентифікатор: 226/2011-рп

Текст документа від 01.02.2012:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про міжвідомчу робочу групу з аналізу стану додержання законодавства про свободу слова та захист прав журналістів

{ Із змінами, внесеними згідно з Розпорядженнями Президента N 27/2012-рп ( 27/2012-рп ) від 25.01.2012 N 32/2012-рп ( 32/2012-рп ) від 01.02.2012 }

З метою гарантування конституційних прав громадян на свободу слова та забезпечення захисту прав журналістів, відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ):

1. Утворити міжвідомчу робочу групу з аналізу стану додержання законодавства про свободу слова та захист прав журналістів (далі - міжвідомча робоча група).

2. Призначити ЧЕПАК Дарію Олександрівну - Прес-секретаря Президента України - керівником міжвідомчої робочої групи.

3. Затвердити персональний склад міжвідомчої робочої групи (додається).

Надати керівникові міжвідомчої робочої групи право залучати до роботи в ній працівників центральних та місцевих органів виконавчої влади, інших державних органів, підприємств, установ і організацій (за погодженням з їх керівниками), одержувати в установленому порядку необхідні для роботи документи та матеріали. { Пункт 3 доповнено абзацом згідно з Розпорядженням Президента N 27/2012-рп ( 27/2012-рп ) від 25.01.2012 }

4. Міжвідомчій робочій групі оперативно інформувати Президента України про факти порушення законодавства про свободу слова та захист прав журналістів і подавати пропозиції щодо можливого реагування.

Президент України В.ЯНУКОВИЧ

м. Київ, 6 липня 2011 року N 226/2011-рп
