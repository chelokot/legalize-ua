Про вдосконалення структури управління зовнішньоекономічною діяльністю

Стан: Втратив чинність

Ідентифікатор: 530-93-п

Текст документа від 22.11.1993:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 липня 1993 р. N 530 Київ

Про вдосконалення структури управління зовнішньоекономічною діяльністю

( Із змінами, внесеними згідно з Постановою КМ N 945 ( 945-93-п ) від 22.11.93 )

З метою посилення координації проведення єдиної зовнішньоекономічної політики, в тому числі щодо країн, які утворилися на території колишнього Союзу РСР, Кабінет Міністрів України постановляє:

1. Покласти на Міністерство зовнішніх економічних зв'язків функції з розроблення стратегії економічного співробітництва з країнами, які утворилися на території колишнього Союзу РСР, проведення заходів щодо її реалізації, координації діяльності центральних органів державної виконавчої влади при укладанні та виконанні міжнародних договорів України з цими державами.

Ліквідувати Державний комітет України з питань економічного співробітництва з країнами, що утворилися на території колишнього Союзу РСР.

( Пункт 2 втратив чинність на підставі Постанови КМ N 945 ( 945-93-п ) від 22.11.93 )

( Пункт 3 втратив чинність на підставі Постанови КМ N 945 ( 945-93-п ) від 22.11.93 )

4. Міністерству фінансів виділити додаткові кошти на утримання центрального апарату Міністерства зовнішніх економічних зв'язків на 1993 рік у межах асигнувань, установлених на утримання органів державної виконавчої влади.

5. Визнати такими, що втратили чинність:

пункти 4 і 5 постанови Кабінету Міністрів України від 23 січня 1993 р. N 41 ( 41-93-п ) "Питання Міністерства зовнішніх економічних зв'язків";

постанову Кабінету Міністрів України від 20 травня 1993 р. N 361 ( 361-93-п ) "Про створення Державного комітету України з питань економічного співробітництва з країнами, що утворилися на території колишнього Союзу РСР".
