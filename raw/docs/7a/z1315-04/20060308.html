ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

30.09.2004 N 714

Зареєстровано в Міністерстві юстиції України 15 жовтня 2004 р. за N 1315/9914

Про затвердження Переліку товарів, митний контроль та митне оформлення яких здійснюються підрозділами Енергетичної регіональної митниці

( Із змінами, внесеними згідно з Наказом Державної митної служби N 16 ( z0077-06 ) від 17.01.2006 )

( У тексті Наказу слова "Центральна енергетична митниця" у всіх відмінках замінено словами "Енергетична регіональна митниця" у відповідному відмінку згідно з Наказом Державної митної служби N 16 ( z0077-06 ) від 17.01.2006 )

Відповідно до статті 71 Митного кодексу України ( 92-15 ) та з метою захисту економічних інтересів України, посилення контролю за переміщенням енергоносіїв та інших товарів через митний кордон України НАКАЗУЮ:

1. Затвердити Перелік товарів, митний контроль та митне оформлення яких здійснюються підрозділами Енергетичної регіональної митниці (далі - Перелік), що додається.

2. Установити, що митний контроль та митне оформлення:

визначених у Переліку товарів, що переміщуються через митний кордон України трубопровідним, залізничним, автомобільним, морським (річковим) транспортом та лініями електропередачі, здійснюються підрозділами Енергетичної регіональної митниці або за її погодженням іншими митними органами; ( Абзац другий пункту 2 із змінами, внесеними згідно з Наказом Державної митної служби N 16 ( z0077-06 ) від 17.01.2006 )

продукції, яка переміщується через митний кордон України в складі партії товарів, до якої входять товари, визначені в Переліку, за умови, що вартість такої продукції менша, ніж вартість решти товарів, здійснюється Енергетичною регіональною митницею за погодженням з митним органом, розташованим за місцем державної реєстрації суб'єкта зовнішньоекономічної діяльності; ( Абзац третій пункту 2 в редакції Наказу Державної митної служби N 16 ( z0077-06 ) від 17.01.2006 )

продуктів переробки давальницької сировини, попередньо оформленої підрозділами Енергетичної регіональної митниці у митних режимах переробки на митній території чи за межами митної території України, які не належать до товарів, визначених у Переліку, здійснюються підрозділами Енергетичної регіональної митниці;

суден закордонного плавання, що переміщуються через митний кордон України в межах нафтогавані Одеського морського торговельного порту, а також особистих речей членів екіпажу цих суден відповідно до переліку, визначеного постановою Кабінету Міністрів України від 13.12.2001 N 1652 ( 1652-2001-п ) "Про обсяги та порядок ввезення громадянами на митну територію України продуктів харчування для власного споживання та перелік предметів, що не можуть бути віднесені до особистих речей громадян", здійснюються підрозділом Енергетичної регіональної митниці в місті Одесі; ( Абзац п'ятий пункту 2 із змінами, внесеними згідно з Наказом Державної митної служби N 16 ( z0077-06 ) від 17.01.2006 )

продуктів переробки нафти сирої, які не належать до товарів, визначених у Переліку, та вироблених нафтопереробними заводами, що розташовані в зоні діяльності підрозділу Енергетичної регіональної митниці, здійснюються цим підрозділом. ( Пункт 2 доповнено абзацом шостим згідно з Наказом Державної митної служби N 16 ( z0077-06 ) від 17.01.2006 )

3. Установити, що доведення до митниць переліків електричних мереж, якими електроенергія переміщується через митний кордон України, здійснюється Енергетичною регіональною митницею.

4. Департаменту організації митного контролю (Заяц В.В.) і Департаменту правового забезпечення (Ступак Ю.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

5. Установити, що цей наказ набирає чинності через 20 днів з дня його офіційного опублікування.

6. Начальникам митниць інформувати суб'єктів підприємницької діяльності про вимоги цього наказу, у тому числі шляхом висвітлення його в засобах масової інформації та на наочних інформаційних стендах у місцях розташування відповідних підрозділів митниці та в місцях проведення митного контролю.

7. Контроль за виконанням наказу покласти на першого заступника Голови Служби Іванюка М.М.
