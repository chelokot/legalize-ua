28.10.2008 N 59

{ Постанова втратила чинність на підставі Постанови Центральної виборчої комісії N 415 ( v0415359-10 ) від 15.10.2010 }

Про форму заяви щодо включення до Державного реєстру виборців особи, яка проживає чи перебуває за межами України

Відповідно до статей 3, 5-7, частини п'ятої статті 8, статті 10, частин першої - третьої, одинадцятої статті 14, статті 19, частини другої статті 36 Закону України "Про Державний реєстр виборців" ( 698-16 ), керуючись статтями 12, 13, пунктом 8 статті 17 Закону України "Про Центральну виборчу комісію" ( 1932-15 ), Центральна виборча комісія постановляє:

1. Встановити форму заяви щодо включення до Державного реєстру виборців особи, яка проживає чи перебуває за межами України (додається) ( va059359-08 ).

2. Цю постанову надіслати Міністерству закордонних справ України.
