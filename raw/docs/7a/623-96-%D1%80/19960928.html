РОЗПОРЯДЖЕННЯ від 28 вересня 1996 р. N 623-р Київ

Про міжвідомчу робочу групу для координації робіт з підготовки проекту "Розвиток освітнього сектора України"

Відповідно до постанови Кабінету Міністрів України від 18 квітня 1996 р. N 440 ( 440-96-п ) "Про порядок підготовки та реалізації проектів розвитку економіки України, що підтримуються Міжнародним банком реконструкції та розвитку", утворити робочу групу для координації робіт з підготовки проекту "Розвиток освітнього сектора України" у складі згідно з додатком.

Дозволити голові міжвідомчої робочої групи вносити зміни до її персонального складу.

2. Рішення міжвідомчої робочої групи для координації робіт з підготовки проекту "Розвиток освітнього сектора України", прийняті в межах її компетенції, є обов'язковими для учасників проекту і доводяться до виконавців у вигляді протоколів засідань групи.
