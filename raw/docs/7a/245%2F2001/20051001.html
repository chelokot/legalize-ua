Президент України; Указ від 11.04.2001 № 245/2001

Про Комісію сприяння демократизації та розвитку громадянського суспільства

Стан: Втратив чинність

Ідентифікатор: 245/2001

Текст документа від 01.10.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1276/2005 ( 1276/2005 ) від 15.09.2005 )

Про Комісію сприяння демократизації та розвитку громадянського суспільства

( Із змінами, внесеними згідно з Указом Президента N 898/2002 ( 898/2002 ) від 07.10.2002 )

З метою сприяння прискоренню процесів становлення та розвитку в Україні інститутів громадянського суспільства, на підтримку ініціативи широких кіл громадськості та відповідно до пункту 28 статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Утворити при Президентові України Комісію сприяння демократизації та розвитку громадянського суспільства (далі - Комісія).

( Стаття 1 із змінами, внесеними згідно з Указом Президента N 898/2002 ( 898/2002 ) від 07.10.2002 )

2. Призначити головою Комісії МАЛИНКОВИЧА Володимира Дмитровича - директора українського відділення Міжнародного інституту гуманітарно-політичних досліджень.

3. Голові Комісії подати в місячний строк пропозиції щодо персонального складу Комісії та проект Положення про Комісію сприяння демократизації та розвитку громадянського суспільства.

( Стаття 3 із змінами, внесеними згідно з Указом Президента N 898/2002 ( 898/2002 ) від 07.10.2002 )

4. Покласти технічне забезпечення діяльності Комісії на Адміністрацію Президента України.

( Установити, що для організаційно-технічного забезпечення діяльності Комісії утворюється секретаріат Комісії у складі трьох осіб. Персональний склад секретаріату Комісії за поданням її секретаря затверджує голова Комісії - згідно з Указом Президента N 898/2002 ( 898/2002 ) від 07.10.2002 )

Президент України Л.КУЧМА
