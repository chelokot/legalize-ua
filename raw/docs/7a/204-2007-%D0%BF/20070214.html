Кабінет Міністрів України; Постанова від 14.02.2007 № 204

Про використання у 2007 році коштів, передбачених у державному бюджеті за бюджетними програмами з використання ядерної енергії

Стан: Чинний

Ідентифікатор: 204-2007-п

Текст документа від 14.02.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 лютого 2007 р. N 204 Київ

Про використання у 2007 році коштів, передбачених у державному бюджеті за бюджетними програмами з використання ядерної енергії

Кабінет Міністрів України постановляє:

1. Установити, що використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ), здійснюється:

за бюджетною програмою "Заходи по реалізації Комплексної програми створення ядерно-паливного циклу в Україні та приведенню об'єктів виробничого об'єднання "Придніпровський хімічний завод" в екологічно-безпечний стан" ( 489-16 ) відповідно до Порядку спрямування коштів, перерахованих державним підприємством "Національна атомна енергогенеруюча компанія "Енергоатом" до спеціального фонду державного бюджету в рахунок погашення його заборгованості цільовому галузевому фонду створення ядерно-паливного циклу в Україні, затвердженого постановою Кабінету Міністрів України від 13 червня 2005 р. N 444 ( 444-2005-п ) (Офіційний вісник України, 2005 р., N 24, ст. 1352; 2006 р., N 10, ст. 630);

за бюджетною програмою "Фізичний захист ядерних установок та ядерних матеріалів" ( 489-16 ) відповідно до постанови Кабінету Міністрів України від 22 червня 2005 р. N 501 ( 501-2005-п ) "Про порядок використання у 2005 році коштів державного бюджету, що спрямовуються на фізичний захист ядерних установок та ядерних матеріалів" (Офіційний вісник України, 2005 р., N 25, ст. 1444), з поширенням її дії на підприємства, що належать до сфери управління Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи;

за бюджетною програмою "Підтримка у безпечному стані енергоблоків та об'єкта "Укриття" Чорнобильської АЕС" ( 489-16 ) відповідно до Порядку використання у 2006 році коштів, передбачених у державному бюджеті для підтримки у безпечному стані енергоблоків та об'єкта "Укриття" Чорнобильської АЕС, затвердженого постановою Кабінету Міністрів України від 30 березня 2006 р. N 407 ( 407-2006-п ) (Офіційний вісник України, 2006 р., N 14, ст. 980);

за бюджетною програмою "Заходи щодо підготовки до зняття з експлуатації атомних енергоблоків та поводження з відпрацьованим ядерним паливом та радіоактивними відходами на Чорнобильській АЕС" ( 489-16 ) відповідно до Порядку використання у 2006 році коштів, передбачених у державному бюджеті для здійснення заходів щодо підготовки до зняття з експлуатації атомних блоків та поводження з відпрацьованим ядерним паливом і радіоактивними відходами на Чорнобильській АЕС, затвердженого постановою Кабінету Міністрів України від 30 березня 2006 р. N 408 ( 408-2006-п ) (Офіційний вісник України, 2006 р., N 14, ст. 981);

за бюджетною програмою "Створення Державного регістру джерел іонізуючого випромінювання" ( 489-16 ) відповідно до Порядку використання у 2006 році коштів, передбачених у державному бюджеті для створення Державного регістру джерел іонізуючого випромінювання, затвердженого постановою Кабінету Міністрів України від 4 травня 2006 р. N 609 ( 609-2006-п ) (Офіційний вісник України, 2006 р., N 18, ст. 1351).

2. Установити, що передбачене статтею 115 Закону про Державний бюджет України на 2007 рік ( 489-16 ) перерахування енергогенеруючими компаніями коштів до спеціального фонду державного бюджету за отримане у 1997-2000 роках органічне паливо здійснюється відповідно до Порядку перерахування енергогенеруючими компаніями коштів до спеціального фонду державного бюджету за отримане у 1997-2000 роках органічне паливо та їх використання, затвердженого постановою Кабінету Міністрів України від 27 квітня 2006 р. N 597 ( 597-2006-п ) (Офіційний вісник України, 2006 р., N 18, ст. 1342).

3. Пункт 2 розпорядження Кабінету Міністрів України від 27 грудня 2006 р. N 660 ( 660-2006-р ) "Питання внеску України до Рахунку ядерної безпеки Європейського банку реконструкції та розвитку" викласти у такій редакції:

"2. МНС та Державному казначейству забезпечити перерахування грошового внеску України до Рахунку ядерної безпеки ЄБРР у 2006 році у розмірі 18587,9 тис. гривень і у 2007 році у розмірі 9852,1 тис. гривень за рахунок коштів, передбачених у Державному бюджеті України відповідно на 2006 ( 3235-15 ) та на 2007 ( 489-16 ) роки за програмою "Внесок України до Рахунку ядерної безпеки ЄБРР".
