Питання діяльності Аграрного фонду на організованому аграрному ринку у 2006-2007 маркетинговому періоді

{ Із змінами, внесеними згідно з Наказом Міністерства аграрної політики N 584 ( z1131-06 ) від 16.10.2006 }

Відповідно до Закону України "Про державну підтримку сільського господарства України" ( 1877-15 ), Методики встановлення мінімальної закупівельної ціни на окремі об'єкти державного цінового регулювання, затвердженої постановою Кабінету Міністрів України від 26.05.2005 N 399 ( 399-2005-п ), та Порядку надання бюджетних позик у межах режиму державних заставних закупівель зерна, затвердженого постановою Кабінету Міністрів України від 09.07.2005 N 546 ( 546-2005-п ), НАКАЗУЮ:

1. Погодитись з пропозицією Аграрного фонду щодо формування ним у 2006 році державного продовольчого резерву у таких обсягах:

а) пшениця і суміш пшениці та жита (меслин) та жито (коди УКТ ЗЕД 1001, 1002 00 00 00 ( 2371а-14 ) - сукупно 565 тис. тонн;

б) цукор тільки з цукрових буряків (код УКТ ЗЕД 1701 12 ( 2371а-14 ) - 180 тис. тонн.

Рекомендувати Аграрному фонду в процесі формування державного продовольчого резерву перевагу надавати пшениці м'якій 3 та 4 класів, а також житу 1 класу групи "А".

2. Установити мінімальні та максимальні закупівельні ціни на об'єкти державного цінового регулювання і розміри бюджетних позик, що надаються під заставу цих об'єктів у 2006-2007 маркетинговому періоді (згідно з додатком).

3. Департаменту економічної стратегії та розвитку аграрного ринку (Розгон А.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням наказу покласти на заступника Міністра аграрної політики України Павлюк Н.А.

Міністр О.П.Баранівський
