Про ситуацію на грошово-кредитному ринку

{ Із змінами, внесеними згідно з Постановами Нацбанку N 333 ( v0333500-98 ) від 31.08.98 N 351 ( v0573500-98 ) від 04.09.98 N 489 ( z0785-98 ) від 20.11.98 }

Беручи до уваги розвиток грошово-кредитного ринку в Україні, після прийняття ряду упереджуючих заходів, а також з метою недопущення його дестабілізації, Правління Національного банку ПОСТАНОВЛЯЄ:

1. З 24 листопада 1997 р. встановити облікову ставку в розмірі 35 відсотків річних.

2. З 24 листопада 1997 р. встановити ломбардну ставку в розмірі 37 відсотків річних.

3. Встановити, що зміна розміру облікової ставки з 15 листопада 1997 р. не повинна розповсюджуватись на розмір кредитів, наданих (отриманих) до 15 листопада 1997 р.

( Пункт 4 втратив чинність на підставі Постанови Нацбанку N 333 ( v0333500-98 ) від 31.08.98 ) 4. Внести зміни до п.7 Положення "Про порядок формування банківською системою України обов'язкових резервів", затвердженого постановою Правління Національного банку України від 26.12.96 р. N 333 ( v0410500-96 ), реєстраційний N 410 від 31.12.96 р. збільшивши норму формування обов'язкових резервів з 11 до 15 відсотків.

Прийняті зміни ввести в дію, починаючи з 1 грудня 1997 р.
