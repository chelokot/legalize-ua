Про передачу Концерну радіомовлення, радіозв'язку та телебачення до сфери управління Державного комітету зв'язку та інформатизації

Стан: Втратив чинність

Ідентифікатор: 539-2001-п

Текст документа від 29.12.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 травня 2001 р. N 539 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1039 ( 1039-2008-п ) від 26.11.2008 - дію Постанови зупинено згідно з Указом Президента N 1194/2008 ( 1194/2008 ) від 24.12.2008 }

Про передачу Концерну радіомовлення, радіозв'язку та телебачення до сфери управління Державного комітету зв'язку та інформатизації

{ Із змінами, внесеними згідно з Постановами КМ N 918 ( 918-2004-п ) від 13.07.2004 N 857 ( 857-2007-п ) від 26.06.2007 }

На виконання Указу Президента України від 1 березня 2001 р. N 122 ( 122/2001 ) "Про деякі заходи щодо вдосконалення державного регулювання послуг електрозв'язку та радіозв'язку" Кабінет Міністрів України постановляє:

1. Передати Концерн радіомовлення, радіозв'язку та телебачення з усіма підприємствами та організаціями, що входять до його складу, до сфери управління Державного комітету телебачення і радіомовлення.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 857 ( 857-2007-п ) від 26.06.2007 }

2. Державному комітетові телебачення і радіомовлення подавати щороку Міністерству економіки та з питань європейської інтеграції пропозиції щодо визначення обсягів державного замовлення на виробництво і розповсюдження теле- та радіопрограм. ( Пункт 2 в редакції Постанови КМ N 918 ( 918-2004-п ) від 13.07.2004 )

3. Міністерству фінансів і Державному казначейству забезпечити застосування Державним комітетом зв'язку та інформатизації бюджетних призначень, передбачених Законом України "Про Державний бюджет України на 2001 рік" ( 2120-14 ) для Державного комітету інформаційної політики, телебачення та радіомовлення на фінансування трансляції телерадіопрограм, у тому числі на погашення заборгованості з оплати послуг, наданих Концерном радіомовлення, радіозв'язку та телебачення з розповсюдження телерадіопрограм, у сумі 41,9 млн. гривень, та щомісячне пропорційне фінансування зазначених видатків.

4. Державному комітетові зв'язку та інформатизації разом з Міністерством палива та енергетики, Радою міністрів Автономної Республіки Крим, обласними, Київською та Севастопольською міськими державними адміністраціями здійснити відповідні організаційні заходи щодо проведення інвентаризації заборгованості Концерну радіомовлення, радіозв'язку та телебачення перед енергопостачальними компаніями за спожиту електроенергію станом на 1 квітня 2001 р. та реструктуризації цієї заборгованості терміном на три роки з початком проведення розрахунків у грошовій формі з 1 червня поточного року щокварталу рівними частинами за умови своєчасного внесення Концерном поточних платежів за спожиту електроенергію.

5. Державному комітетові зв'язку та інформатизації протягом поточного року вжити заходів, спрямованих на вдосконалення виробничої структури Концерну радіомовлення, радіозв'язку та телебачення як цілісної системи радіорелейних мереж, супутникових станцій, передавальних засобів розповсюдження теле- і радіопрограм в Україні та за її межами.

Перший віце-прем'єр-міністр України Ю.ЄХАНУРОВ
