КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 лютого 2005 р. N 143 Київ

Про внесення змін та визнання такими, що втратили чинність, деяких рішень Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 626 ( 626-2008-п ) від 09.07.2008 }

З метою створення рівноправних засад для конкурентного середовища, недопущення втрати доходів та необґрунтованого витрачання бюджетних коштів Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України зміни, що додаються.

2. Визнати такими, що втратили чинність, рішення Кабінету Міністрів України згідно з переліком, що додається.

3. Міністерствам, іншим центральним органам виконавчої влади привести власні нормативно-правові акти у відповідність з цією постановою.
