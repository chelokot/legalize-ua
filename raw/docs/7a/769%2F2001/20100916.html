Текст документа від 16.09.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 900/2010 ( 900/2010 ) від 14.09.2010 }

Про утворення військових апеляційних та військових місцевих судів і затвердження їх мережі

{ Із змінами, внесеними згідно з Указами Президента N 1262/2004 ( 1262/2004 ) від 19.10.2004 N 599/2006 ( 599/2006 ) від 06.07.2006 N 730/2006 ( 730/2006 ) від 04.09.2006 }

Відповідно до пункту 23 частини першої статті 106 Конституції України ( 254к/96-ВР ) та статті 38-2 Закону України "Про судоустрій України" ( 2022-10 ) постановляю:

1. Утворити військові апеляційні суди на базі військових судів регіонів і Військово-Морських Сил та військові місцеві суди на базі військових судів гарнізонів.

2. Затвердити мережу і кількісний склад військових апеляційних та військових місцевих судів із загальною кількістю військових суддів 77 осіб (додається). { Стаття 2 із змінами, внесеними згідно з Указами Президента N 1262/2004 ( 1262/2004 ) від 19.10.2004, N 599/2006 ( 599/2006 ) від 06.07.2006, N 730/2006 ( 730/2006 ) від 04.09.2006 }

3. Визнати такою, що втратила чинність, статтю 3 Указу Президента України від 30 травня 1998 року N 572 ( 572/98 ) "Про мережу та кількісний склад військових судів України".

Президент України Л.КУЧМА
