Про визначення повноважних органів, відповідальних за виконання Угоди про співробітництво по припиненню правопорушень у сфері інтелектуальної власності

Стан: Втратив чинність

Ідентифікатор: 258-2003-р

Текст документа від 03.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 травня 2003 р. N 258-р Київ

Про визначення повноважних органів, відповідальних за виконання Угоди про співробітництво по припиненню правопорушень у сфері інтелектуальної власності

{ Із змінами, внесеними згідно з Постановою КМ N 904 ( 904-2011-п ) від 31.08.2011 }

Відповідно до статті 4 Угоди про співробітництво по припиненню правопорушень у сфері інтелектуальної власності ( 997_154 ) визначити повноважними органами, відповідальними за виконання зазначеної Угоди, Державну службу інтелектуальної власності, Міністерство закордонних справ, Міністерство внутрішніх справ, Міністерство юстиції, Міністерство економічного розвитку і торгівлі, Міністерство культури, Службу безпеки, Державну митну службу, Державну податкову службу, Антимонопольний комітет, Державну інспекцію з питань захисту прав споживачів.

{ Розпорядження із змінами, внесеними згідно з Постановою КМ N 904 ( 904-2011-п ) від 31.08.2011 }

Прем'єр-міністр України В.ЯНУКОВИЧ
