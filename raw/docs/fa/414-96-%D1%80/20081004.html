Кабінет Міністрів України; Розпорядження від 29.06.1996 № 414-р

Про склад Міжвідомчої робочої групи для координації робіт з підготовки проекту розвитку ринку електроенергетики

Стан: Втратив чинність

Ідентифікатор: 414-96-р

Текст документа від 04.10.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 червня 1996 р. N 414-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 871 ( 871-2008-п ) від 01.10.2008 }

Затвердити склад Міжвідомчої робочої групи для координації робіт з підготовки проекту розвитку ринку електроенергетики, що підтримується Міжнародним банком реконструкції та розвитку, згідно з додатком.

Дозволити голові Міжвідомчої робочої групи за погодженням з керівниками відповідних міністерств, відомств вносити зміни до персонального складу групи.

Прем'єр-міністр України П.ЛАЗАРЕНКО
