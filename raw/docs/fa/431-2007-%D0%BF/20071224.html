Кабінет Міністрів України; Постанова від 14.03.2007 № 431

Про призначення членів наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України"

Стан: Чинний

Ідентифікатор: 431-2007-п

Текст документа від 24.12.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 березня 2007 р. N 431 Київ

{ Щодо зупинення дії Постанови див. Указ Президента N 288/2007 ( 288/2007 ) від 10.04.2007 }

Про призначення членів наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України"

{ Із змінами, внесеними згідно з Постановою КМ N 1403 ( 1403-2007-п ) від 24.12.2007 }

З метою належного представлення інтересів держави як єдиного акціонера відкритого акціонерного товариства "Державний експортно-імпортний банк України" у вищому органі управління товариства та відповідно до статті 7 Закону України "Про банки і банківську діяльність" ( 2121-14 ) Кабінет Міністрів України постановляє:

{ Пункт 1 скасовано на підставі Постанови КМ N 1403 ( 1403-2007-п ) від 24.12.2007 }

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 7 лютого 2007 р. N 144 ( 144-2007-п ) "Про призначення членів наглядової ради відкритого акціонерного товариства "Державний експортно-імпортний банк України".

Прем'єр-міністр України В.ЯНУКОВИЧ
