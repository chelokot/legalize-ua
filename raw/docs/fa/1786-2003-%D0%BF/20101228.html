КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 листопада 2003 р. N 1786 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1158 ( 1158-2010-п ) від 15.12.2010 }

Про представника Кабінету Міністрів України в Комітеті Повноважних Представників Урядів держав - членів Об'єднаного інституту ядерних досліджень

Кабінет Міністрів України постановляє:

Затвердити заступника Міністра освіти і науки Стогнія Вадима Сергійовича представником Кабінету Міністрів України в Комітеті Повноважних Представників Урядів держав - членів Об'єднаного інституту ядерних досліджень, увільнивши від цих обов'язків Гриньова Бориса Вікторовича.

Прем'єр-міністр України В.ЯНУКОВИЧ
