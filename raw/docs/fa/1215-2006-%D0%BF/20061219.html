Про зупинення дії деяких постанов Кабінету Міністрів України

Стан: Втратив чинність

Ідентифікатор: 1215-2006-п

Текст документа від 19.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 серпня 2006 р. N 1215 Київ

Про зупинення дії деяких постанов Кабінету Міністрів України

{ Із змінами, внесеними згідно з Постановою КМ N 1361 ( 1361-2006-п ) від 26.09.2006 }

{ Постанова втратила чинність у частині зупинення дії Постанови КМ від 3 серпня 2006 р. N 1095 ( 1095-2006-п ) на підставі Постанови КМ N 1756 ( 1756-2006-п ) від 19.12.2006 }

Кабінет Міністрів України постановляє:

Зупинити дію постанов Кабінету Міністрів України від 3 серпня 2006 р. N 1095 ( 1095-2006-п ) "Про доповнення переліку та обсягів матеріалів, устаткування і комплектуючого обладнання, що використовуються для будівництва суден підприємствами суднобудівної промисловості, визначеними відповідно до статті 1 Закону України "Про заходи щодо державної підтримки суднобудівної промисловості в Україні", та ввозяться на митну територію України згідно з контрактами, укладеними цими підприємствами" і від 1 серпня 2006 р. N 1060 ( 1060-2006-п ) "Про внесення змін до Порядку призначення і виплати державної допомоги сім'ям з дітьми". { Постанова із змінами, внесеними згідно з Постановою КМ N 1361 ( 1361-2006-п ) від 26.09.2006 }
