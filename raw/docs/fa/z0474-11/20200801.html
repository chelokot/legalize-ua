МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

11.04.2011 N 1076/5

Зареєстровано в Міністерстві юстиції України 12 квітня 2011 р. за N 474/19212

Про підвищення ефективності роботи відділів державної реєстрації актів цивільного стану

{ Із змінами, внесеними згідно з Наказами Міністерства юстиції N 170/5 ( z0190-13 ) від 24.01.2013 N 2784/5 ( z2232-13 ) від 27.12.2013 N 339/5 ( z0125-20 ) від 03.02.2020 N 2449/5 ( z0676-20 ) від 17.07.2020 }

Відповідно до статей 5, 20 Закону України "Про державну реєстрацію актів цивільного стану" ( 2398-17 ), пункту 4 Положення про Міністерство юстиції України, затвердженого постановою Кабінету Міністрів України від 14.11.2006 N 1577 ( 1577-2006-п ), та з метою належної організації діяльності відділів державної реєстрації актів цивільного стану, підвищення ефективності їх роботи НАКАЗУЮ:

1. Начальникам міжрегіональних управлінь Міністерства юстиції України:

{ Абзац перший пункту 1 в редакції Наказу Міністерства юстиції N 339/5 ( z0125-20 )від 03.02.2020 } { Пункт 1 із змінами, внесеними згідно з Наказами Міністерства юстиції N 2784/5 ( z2232-13 ) від 27.12.2013 }

1.1. Забезпечити перегляд графіків роботи відділів державної реєстрації актів цивільного стану та графіків прийому громадян у відділах державної реєстрації актів цивільного стану, виходячи з таких вимог:

установлення вихідних днів для відділів державної реєстрації актів цивільного стану - неділя та понеділок; { Абзац другий підпункту 1.1 пункту 1 із змінами, внесеними згідно з Наказом Міністерства юстиції N 170/5 ( z0190-13 ) від 24.01.2013 }

здійснення прийому громадян у відділах державної реєстрації актів цивільного стану протягом кожного робочого дня з усіх питань, що належать до їх компетенції, у тому числі у разі потреби в один з робочих днів тижня щонайменше до 20-ї години, в суботу до 16-ї години шляхом встановлення гнучкого режиму роботи; { Абзац третій підпункту 1.1 пункту 1 із змінами, внесеними згідно з Наказами Міністерства юстиції N 170/5 ( z0190-13 ) від 24.01.2013, N 2449/5 ( z0676-20 ) від 17.07.2020 }

кількість годин прийому громадян має становити не менше 40 годин на тиждень; { Підпункт 1.1 пункту 1 доповнено новим абзацом четвертим згідно з Наказом Міністерства юстиції N 2784/5 ( z2232-13 ) від 27.12.2013 }

установлення одного санітарного дня на місяць для обробки приміщення архівосховища відділу державної реєстрації актів цивільного стану;

установлення одного з робочих днів тижня для надання працівниками відділів державної реєстрації актів цивільного стану безоплатно консультацій з питань, включених до пункту 10 Переліку платних послуг, які можуть надаватися відділами державної реєстрації актів цивільного стану, затвердженого постановою Кабінету Міністрів України від 22.12.2010 N 1168 ( 1168-2010-п ) (далі - Перелік);

обов'язкове здійснення державної реєстрації смерті в неробочі, святкові та вихідні дні, крім неділі, шляхом встановлення гнучкого режиму роботи. { Абзац сьомий підпункту 1.1 пункту 1 в редакції Наказу Міністерства юстиції N 2784/5 ( z2232-13 ) від 27.12.2013 }

1.2. { Абзац перший підпункту 1.2 пункту 1 виключено на підставі Наказу Міністерства юстиції N 2784/5 ( z2232-13 ) від 27.12.2013 }

З метою забезпечення наповнення Державного реєстру актів цивільного стану громадян вносити відомості, що містяться в книгах державної реєстрації актів цивільного стану та метричних книгах за 1996-2008, 1949-1945 роки кожного робочого дня протягом 3 годин. Під час проведення цієї роботи здійснювати прийом громадян з усіх питань у сфері державної реєстрації актів цивільного стану. { Підпункт 1.2 пункту 1 доповнено новим абзацом згідно з Наказом Міністерства юстиції N 170/5 ( z0190-13 ) від 24.01.2013 }

{ Підпункт 1.2 пункту 1 із змінами, внесеними згідно з Наказом Міністерства юстиції N 170/5 ( z0190-13 ) від 24.01.2013 }

1.3. З метою забезпечення належної організації роботи працівників відділів державної реєстрації актів цивільного стану з архівними документами вирішити питання щодо введення додаткових штатних одиниць технічних працівників за рахунок коштів спеціального фонду, отриманих за надання платних послуг відповідно до Переліку ( 1168-2010-п ), та в межах фонду заробітної плати, затвердженого в кошторисах установ за спеціальним фондом.

1.4. Інформувати населення, місцеві органи виконавчої влади та органи місцевого самоврядування, а також засоби масової інформації про затверджені графіки роботи відділів державної реєстрації актів цивільного стану та прийому громадян у відділах державної реєстрації актів цивільного стану.

1.5. Забезпечити постійне проведення працівниками відділів державної реєстрації актів цивільного стану роз'яснювальної роботи серед різних верств населення з питань діяльності органів державної реєстрації актів цивільного стану шляхом оприлюднення виступів, публікацій, коментарів у засобах масової інформації, зокрема в студіях радіомовлення, на телебаченні, створенням "гарячих ліній" тощо.

1.6. Забезпечити надання працівниками відділів державної реєстрації актів цивільного стану фізичним та юридичним особам, які звернулися за допомогою засобів телекомунікації (телефону, електронної пошти, інших засобів зв'язку), інформації про порядок надання адміністративних послуг у сфері державної реєстрації актів цивільного стану.

{ Пункт 1 доповнено новим підпунктом 1.6 згідно з Наказом Міністерства юстиції N 2784/5 ( z2232-13 ) від 27.12.2013 }

1.7. З метою забезпечення доступності адміністративних послуг у сфері державної реєстрації актів цивільного стану та зручності для фізичних та юридичних осіб:

облаштувати у приміщеннях відділів державної реєстрації актів цивільного стану: інформаційні стенди зі зразками документів та інформацією, необхідними для отримання адміністративних послуг, в обсязі, достатньому для отримання послуги без сторонньої допомоги; скриньки для висловлених фізичними та юридичними особами зауважень та пропозицій щодо якості надання адміністративних послуг;

розмістити на веб-сайтах міжрегіональних управлінь Міністерства юстиції України інформацію: про місцезнаходження відділів державної реєстрації актів цивільного стану (поштова адреса, номер телефону, електронна пошта); графіки їх роботи та прийому; про порядок надання адміністративних послуг;{ Абзац третій підпункту 1.7 пункту 1 із змінами, внесеними згідно з Наказом Міністерства юстиції N 339/5 ( z0125-20 )від 03.02.2020 }

управлінням державної реєстрації міжрегіональних управлінь Міністерства юстиції України здійснювати щорічний аналіз зауважень і пропозицій щодо якості надання адміністративних послуг у відділах державної реєстрації актів цивільного стану та за результатами вживати відповідних заходів. { Абзац четвертий підпункту 1.7 пункту 1 із змінами, внесеними згідно з Наказом Міністерства юстиції N 339/5 ( z0125-20 )від 03.02.2020 }

{ Пункт 1 доповнено новим підпунктом 1.7 згідно з Наказом Міністерства юстиції N 2784/5 ( z2232-13 ) від 27.12.2013 }

1.8. Забезпечити виконання вимог цього наказу та про проведену роботу інформувати Міністерство юстиції до 01.06.2011.

2. Департаменту у справах цивільного стану громадян (Кунда В.В.)

2.1. Подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (зі змінами).

{ Підпункт 2.2 пункту 2 виключено на підставі Наказу Міністерства юстиції N 2784/5 ( z2232-13 ) від 27.12.2013 }

3. Контроль за виконанням наказу покласти на заступника Міністра Панченко А.М.

4. Цей наказ набирає чинності з дня його офіційного опублікування.
