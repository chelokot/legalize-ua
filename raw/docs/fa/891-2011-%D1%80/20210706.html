Текст документа від 06.07.2021:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 серпня 2011 р. N 891-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 666 ( 666-2021-п ) від 30.06.2021 }

Про внесення змін до розпорядження Кабінету Міністрів України від 16 лютого 2011 р. N 123

1. Внести до розпорядження Кабінету Міністрів України від 16 лютого 2011 р. N 123 ( 123-2011-р ) "Про затвердження складу наглядових рад національних заповідників" зміни, що додаються.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 24 жовтня 2007 р. N 916 ( 916-2007-р ) "Про затвердження складу наглядової ради Національного історико-меморіального заповідника "Биківнянські могили".

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 31 серпня 2011 р. N 891-р

ЗМІНИ, що вносяться до розпорядження Кабінету Міністрів України від 16 лютого 2011 р. N 123 ( 123-2011-р )

1. У тексті розпорядження ( 123-2011-р ) цифри "1-13" замінити цифрами "1-14".

2. Увести до складу наглядової ради Національного заповідника "Херсонес Таврійський", затвердженого зазначеним розпорядженням ( 123-2011-р ), МІЛЛЕРА Уільяма Гріна - Надзвичайного і Повноважного Посла Сполучених Штатів Америки в Україні у 1993-1998 роках, досліджувача Міжнародного наукового центру імені Вудро Вільсона (за згодою), ЯЦУБУ Володимира Григоровича - голову Севастопольської міськдержадміністрації, вивівши з її складу САРАТОВА Валерія Володимировича.
