Кабінет Міністрів України; Розпорядження, Склад колегіального органу від 02.09.2010 № 1799-р

Про утворення Організаційного комітету з підготовки та відзначення 1000-річчя заснування Софійського собору

Стан: Чинний

Ідентифікатор: 1799-2010-р

Текст документа від 26.09.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 вересня 2010 р. N 1799-р Київ

Про утворення Організаційного комітету з підготовки та відзначення 1000-річчя заснування Софійського собору

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 249-р ( 249-2011-р ) від 30.03.2011 N 907-р ( 907-2011-р ) від 26.09.2011 }

1. Утворити Організаційний комітет з підготовки та відзначення 1000-річчя заснування Софійського собору у складі згідно з додатком.

Голові Організаційного комітету затвердити його персональний склад.

2. Організаційному комітетові підготувати та подати в місячний строк Кабінетові Міністрів України проект плану заходів з підготовки та відзначення 1000-річчя заснування Софійського собору.
