{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про передачу адміністративного будинку Українській державній кредитно-інвестиційній компанії

Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Української державної кредитно-інвестиційної компанії (далі - Компанія) про передачу у її повне господарське відання адміністративного будинку з майном та обладнанням по вул. Артема, 73, у м. Києві з метою формування статутного фонду Компанії.

2. Просити Фонд державного майна забезпечити здійснення до 15 лютого 1997 р. експертної оцінки вартості майна, що передається до статутного фонду Компанії.

3. Корпорації "Укрбудматеріали" забезпечити в місячний термін передачу Компанії зазначеного будинку.

4. Закріпити за корпорацією "Укрбудматеріали" у зазначеному будинку користування приміщеннями робочою площею 1507,6 кв. метрів на умовах оплати комунальних послуг та амортизації відповідної частини будинку.

5. Визнати такими, що втратили чинність, пункт 7 постанови Кабінету Міністрів УРСР від 24 червня 1991 р. N 51 ( 51-91-п ) "Про створення Української державної корпорації промисловості будівельних матеріалів" і розпорядження Кабінету Міністрів України від 21 квітня 1993 р. N 242 ( 242-93-р ) та від 5 грудня 1995 р. N 738 ( 738-95-р ).
