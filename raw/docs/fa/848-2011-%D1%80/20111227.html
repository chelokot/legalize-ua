Кабінет Міністрів України; Розпорядження від 22.08.2011 № 848-р

Про передачу у 2011 році деяких бюджетних призначень

Стан: Чинний

Ідентифікатор: 848-2011-р

Текст документа від 27.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 серпня 2011 р. N 848-р Київ

Про передачу у 2011 році деяких бюджетних призначень

{ Із змінами, внесеними згідно з Розпорядженням КМ N 909-р ( 909-2011-р ) від 28.09.2011 Постановою КМ N 1335 ( 1335-2011-п ) від 12.12.2011 }

1. Передати бюджетні призначення, передбачені у 2011 році Міністерству фінансів у загальному фонді державного бюджету ( 2857-17 ) (загальнодержавні витрати) за програмою 3511090 "Державні капітальні видатки, що розподіляються Кабінетом Міністрів України", у сумі 5650 тис. гривень головним розпорядникам бюджетних коштів, у тому числі: { Абзац перший пункту 1 із змінами, внесеними згідно з Постановою КМ N 1335 ( 1335-2011-п ) від 12.12.2011 }

1) Державній судовій адміністрації - 3000 тис. гривень для проведення капітального ремонту приміщень, з них:

Вінницькому апеляційному адміністративному суду - 1000 тис. гривень;

Одеському окружному адміністративному суду - 1000 тис. гривень;

окружному адміністративному суду Автономної Республіки Крим - 1000 тис. гривень;

{ Підпункт 1 пункту 1 в редакціїї Розпорядження КМ N 909-р ( 909-2011-р ) від 28.09.2011 }

2) Міністерству культури - 2650 тис. гривень для проведення ремонтних робіт, з них: { Абзац перший підпункту 2 пункту 1 із змінами, внесеними згідно з Постановою КМ N 1335 ( 1335-2011-п ) від 12.12.2011 }

Київському державному хореографічному училищу - 300 тис. гривень; { Абзац другий підпункту 2 пункту 1 із змінами, внесеними згідно з Постановою КМ N 1335 ( 1335-2011-п ) від 12.12.2011 }

Київській середній спеціалізованій музичній школі-інтернату імені М.В. Лисенка - 231,2 тис. гривень;

Харківському державному університету мистецтв імені І.П. Котляревського - 1 200 тис. гривень;

Львівській середній спеціалізованій музичній школі-інтернату імені С. Крушельницької - 918,8 тис. гривень.

Передачу бюджетних призначень здійснити в межах видатків розвитку.

2. Забезпечити:

1) головним розпорядникам бюджетних коштів:

погодження передачі бюджетних призначень, передбаченої пунктом 1 цього розпорядження, з Комітетом Верховної Ради України з питань бюджету;

розроблення та затвердження у разі потреби порядків використання відповідних бюджетних коштів;

подання щомісяця до 5 числа Міністерству фінансів звіту про використання бюджетних коштів;

2) після зазначеного погодження:

Міністерству фінансів - відкриття у разі потреби нових бюджетних програм та внесення відповідних змін до розпису державного бюджету;

Державній казначейській службі - перерахування бюджетних коштів відповідно до переданих бюджетних призначень.

Прем'єр-міністр України М.АЗАРОВ
