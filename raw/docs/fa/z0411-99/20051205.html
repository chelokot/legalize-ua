N 302 від 10.06.99 Зареєстровано в Міністерстві м.Київ юстиції України 24 червня 1999 р. vd990610 vn302 за N 411/3704

( Наказ втратив чинність на підставі Наказу Міністерства транспорту та зв'язку N 770 ( z1419-05 ) від 14.11.2005 )

Про внесення доповнення до таблиці 1 Ставок плати за користування вантажними вагонами залізниць

З метою зниження транспортних витрат вантажовласників, у відповідності до Статуту залізниць України, затвердженого постановою Кабінету Міністрів України від 6 квітня 1998 року N 457 ( 457-98-п ), та до постанови Кабінету Міністрів України "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)" від 25 грудня 1996 року N 1548 ( 1548-96-п ) НАКАЗУЮ:

1. Доповнити таблицю 1 Ставок плати за користування вантажними вагонами залізниць, затверджених наказом Міністерства транспорту України від 2 лютого 1999 року N 53 ( z0103-99 ), зареєстрованим у Міністерстві юстиції України 18 лютого 1999 року за N 103/3396, текстом такого змісту:

"У разі зайняття відправниками вагонів для навантаження маршрутів, а також при перевезенні залізничними лініями вузької колії вказані ставки застосовуються в розмірі 50 відсотків".

2. Укрзалізниці (А.В.Слободян) забезпечити своєчасне доведення цього наказу до відома вантажовідправників, організацій, установ, власників під'їзних колій, громадян - суб'єктів підприємницької діяльності України.

3. Головному управлінню тарифного та страхового регулювання (С.П.Щербина) разом з Головним управлінням правового забезпечення (Л.М.Логінова) у встановленому порядку зареєструвати цей наказ у Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника генерального директора Укрзалізниці Л.М.Петренка.

Міністр І.П.Данькевич
