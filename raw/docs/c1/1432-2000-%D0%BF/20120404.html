КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 вересня 2000 р. N 1432 Київ

{ Постанова втратила чинність одночасно з набранням чинності Указом Президента ( 236/2012 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Про Державну інспекцію з контролю за цінами

{ Із змінами, внесеними згідно з Постановами КМ N 268 ( 268-2006-п ) від 09.03.2006 N 667 ( 667-2010-п ) від 28.07.2010 }

Кабінет Міністрів України постановляє:

1. Утворити у складі Міністерства економіки на базі Державної інспекції з контролю за цінами та державних інспекцій з контролю за цінами в Автономній Республіці Крим, областях, містах Києві та Севастополі урядовий орган державного управління - Державну інспекцію з контролю за цінами та її територіальні органи в Автономній Республіці Крим, областях, містах Києві та Севастополі. { Пункт 1 із змінами, внесеними згідно з Постановою КМ N 667 ( 667-2010-п ) від 28.07.2010 }

2. { Пункт 2 втратив чинність в частині умов оплати праці на підставі Постанови КМ N 268 ( 268-2006-п ) від 09.03.2006 } Зберегти за працівниками центрального апарату Державної інспекції з контролю за цінами умови оплати праці, медичного та соціально-побутового забезпечення, що встановлені законодавством для працівників центрального апарату Міністерства економіки, а за начальником Державної інспекції з контролю за цінами - умови оплати праці, матеріально-побутового, медичного і транспортного обслуговування, визначені для заступників Міністра.

3. Міністерству економіки подати у місячний термін в установленому порядку Кабінетові Міністрів України проект Положення про Державну інспекцію з контролю за цінами.
