N 183/48 від 25.10.99 Зареєстровано в Міністерстві м.Київ юстиції України 11 листопада 1999 р. vd991025 vn183/48 за N 778/4071

( Наказ втратив чинність на підставі Наказу МЗС N 183/2241 ( z0852-00 ) від 15.11.2000 )

Про порядок підтвердження туристичного характеру поїздки іноземців з країн, у яких діють представництва Державного комітету України по туризму, та про внесення доповнень до Положення про порядок видачі референсу суб'єктам туристичної діяльності України, затвердженого спільним наказом Міністерства закордонних справ України та Державного комітету України по туризму від 25.12.96 N 164-09/61

Відповідно до постанов Кабінету Міністрів України від 20.02.99 N 227 ( 227-99-п ) "Про запровадження нового порядку оформлення візових документів для в'їзду в Україну" і від 29.04.99 N 728 ( 728-99-п ) "Про заходи подальшого розвитку туризму", відповідно до Закону України "Про туризм" ( 324/95-ВР ), з метою полегшення процедури та скорочення термінів отримання віз для в'їзду в Україну з метою туризму, збільшення потоку іноземних туристів в Україну, недопущення нелегальної міграції в Україну та враховуючи можливості представництв Держкомтуризму за кордоном, НАКАЗУЄМО:

1. Доповнити п.1.3 Положення про порядок видачі референсу суб'єктам туристичної діяльності України, яке затверджене спільним наказом Міністерства закордонних справ України та Державного комітету України по туризму від 25.12.96 N 164-09/61 ( z0761-96 ), зареєстрованим у Міністерстві юстиції України 30.12.96 N 761/1786, абзацом другим такого змісту: "Дія цього Положення припиняється в тих країнах, у яких створені представництва Держкомтуризму України".

2. Установити, що дипломатичні представництва та консульські установи України за кордоном (далі - консульські установи) видають візи для в'їзду в Україну з метою туризму на підставі звернень за встановленою формою (додаток) представництв Державного комітету України по туризму (далі - Представництва), якими підтверджується туристичний характер поїздки.

3. Представництва діють на підставі Положення про представництво Державного комітету України по туризму за кордоном, затвердженого наказом Державного комітету України по туризму від 27 вересня 1999 року N 38 та погодженого Кабінетом Міністрів України 12 жовтня 1999 року.

4. Консульському управлінню МЗС України у взаємодії з Держкомтуризмом України в місячний строк здійснити організаційні заходи щодо інформування консульських установ про вимоги цього наказу, забезпечивши їх необхідними інструктивними матеріалами.

5. Контроль за виконанням цього наказу покласти на заступника Міністра закордонних справ України О.І.Майданника та заступника Голови Державного комітету України по туризму Г.П.Науменка.
