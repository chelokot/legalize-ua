Стан: Втратив чинність

Текст документа від 14.07.2000:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

( Розпорядження втратило чинність на підставі Указу Президента N 889/2000 ( 889/2000 ) від 14.07.2000 )

Про новий склад Комісії з питань повернення в Україну валютних цінностей, що незаконно знаходяться за її межами

На зміну абзацу першого пункту 2 Розпорядження Президента України від 11 жовтня 1995 року N 295 ( 295/95-рп ) (із змінами, внесеними Розпорядженням від 9 січня 1996 року N 8 ( 8/96-рп ) та Указом від 30 червня 1998 року N 714 ( 714/98 ) затвердити новий персональний склад Комісії з питань повернення в Україну валютних цінностей, що незаконно знаходяться за її межами (додається).

Президент України Л.КУЧМА

м. Київ, 17 листопада 1998 року N 551/98-рп
