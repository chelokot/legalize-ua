Стан: Втратив чинність

Ідентифікатор: z0004-00

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 601 від 22.12.99 Зареєстровано в Міністерстві м.Київ юстиції України 10 січня 2000 р. vd991222 vn601 за N 4/4225

{ Постанова втратила чинність на підставі Постанови Національного банку N 79 ( z0237-09 ) від 17.02.2009 }

Про внесення змін до нормативно-правових актів Національного банку України з питань кредитування в іноземній валюті

{ Із змінами, внесеними згідно з Постановою Національного банку N 54 ( z0296-04 ) від 18.02.2004 }

Відповідно до статті 7 Закону України "Про Національний банк України" ( 679-14 ) та враховуючи ситуацію на грошово-кредитному ринку України, Правління ПОСТАНОВЛЯЄ:

1. Визнати такими, що втратили чинність:

- постанову Правління Національного банку України від 20.11.98 N 489 ( z0785-98 ) "Про встановлення тимчасового порядку кредитування в іноземній валюті", зареєстровану в Міністерстві юстиції України 10.12.98 за N 785/3225;

- абзац 3 пункту 5 постанови Правління Національного банку України від 17.12.98 N 524 ( z0005-99 ) "Про окремі питання, пов'язані з регулюванням діяльності комерційних банків", зареєстрованої в Міністерстві юстиції України 05.01.99 за N 5/3298.

( Пункт 2 втратив чинність на підставі Постанови Національного банку N 54 ( z0296-04 ) від 18.02.2004 )

3. Департаменту валютного регулювання (С.О.Яременко) у встановленому порядку довести текст постанови до відома Кримського республіканського, Операційного та територіальних управлінь Національного банку України і комерційних банків.

4. Контроль за виконанням цієї постанови покласти на Департамент валютного регулювання (С.О.Яременко).

5. Постанова набуває чинності через 10 днів після її державної реєстрації у Міністерстві юстиції України.

Голова В.А.Ющенко
