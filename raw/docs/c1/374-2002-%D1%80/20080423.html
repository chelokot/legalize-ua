{ Розпорядження втратило чинність на підставі Постанови КМ N 419 ( 419-2008-п ) від 23.04.2008 }

Про затвердження складу наглядової ради Національного історико-археологічного заповідника "Ольвія"

( Із змінами, внесеними згідно з Розпорядженням КМ N 801-р ( 801-2003-р ) від 26.12.2003 )

На виконання Указу Президента України від 17 січня 2002 р. N 36 ( 36/2002 ) "Про надання Державному історико-археологічному заповіднику "Ольвія" статусу національного" затвердити склад наглядової ради Національного історико-археологічного заповідника "Ольвія" (додається).

Прем'єр-міністр України А.КІНАХ

Інд. 28

ЗАТВЕРДЖЕНО розпорядженням Кабінету Міністрів України від 11 липня 2002 р. N 374-р
