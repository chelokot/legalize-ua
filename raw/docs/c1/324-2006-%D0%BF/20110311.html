Кабінет Міністрів України; Постанова від 15.03.2006 № 324

Про внесення зміни до переліку документів, які підлягають захисту голографічними елементами, та їх державних замовників

Стан: Втратив чинність

Ідентифікатор: 324-2006-п

Текст документа від 11.03.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 березня 2006 р. N 324 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 86 ( 86-2011-п ) від 09.02.2011 }

Про внесення зміни до переліку документів, які підлягають захисту голографічними елементами, та їх державних замовників

Кабінет Міністрів України постановляє:

Внести до переліку документів, які підлягають захисту голографічними елементами, та їх державних замовників, затвердженого постановою Кабінету Міністрів України від 5 липня 2002 р. N 932 ( 932-2002-п ) (Офіційний вісник України, 2002 р., N 28, ст. 1314; 2004 р., N 12, ст. 741, N 30, ст. 2016), зміну, виключивши такі позиції:

" Уніфікований адміністративний документ форми Держмитслужба МД-2

Книжка МДП (міжнародні дорожні перевезення) -"-

Посвідчення на реєстрацію транспортного -"- засобу (номерних агрегатів) в органах ДАІ МВС України

Декларація на ввезення/вивезення -"- транспортного засобу індивідуального користування, вузла, агрегату форми МД-7 ".

Прем'єр-міністр України Ю.ЄХАНУРОВ
