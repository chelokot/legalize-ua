Про внесення змін до постанови Кабінету Міністрів України від 3 лютого 2010 р. N 89

Кабінет Міністрів України постановляє:

Внести до постанови Кабінету Міністрів України від 3 лютого 2010 р. N 89 ( 89-2010-п ) "Питання Всеукраїнського фізкультурно-спортивного товариства "Колос" (Офіційний вісник України, 2010 р., N 8, ст. 389) зміни, що додаються.

Прем'єр-міністр України М.АЗАРОВ

Інд. 22

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 2 вересня 2010 р. N 806

ЗМІНИ, що вносяться до постанови Кабінету Міністрів України від 3 лютого 2010 р. N 89 ( 89-2010-п )

1. В абзаці другому пункту 2 постанови ( 89-2010-п ) слово "співголовам" замінити словом "голові".

2. Додаток до постанови викласти у такій редакції:

"Додаток до постанови Кабінету Міністрів України від 3 лютого 2010 р. N 89 ( 89-2010-п ) (у редакції постанови Кабінету Міністрів України від 2 вересня 2010 р. N 806)
