Текст документа від 01.06.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 листопада 2010 р. N 1057 Київ

Про затвердження переліку пунктів пропуску через державний кордон, через які здійснюється переміщення товарів військового призначення та ядерних матеріалів

{ Із змінами, внесеними згідно з Постановою КМ N 453 ( 453-2012-п ) від 21.05.2012 }

Відповідно до частини другої статті 195 Митного кодексу України ( 4495-17 ) Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 453 ( 453-2012-п ) від 21.05.2012 }

1. Затвердити перелік пунктів пропуску через державний кордон, через які здійснюється переміщення товарів військового призначення та ядерних матеріалів, згідно з додатком.

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

3. Ця постанова набирає чинності з дня опублікування.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 17 листопада 2010 р. N 1057

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 20 липня 1999 р. N 1289 ( 1289-99-п ) "Про затвердження переліку пунктів пропуску через державний кордон, через які здійснюється переміщення вантажів військового призначення, а також вантажів, що стосуються ядерної діяльності, у разі їх транзиту територією України" (Офіційний вісник України, 2008 р., N 57, ст. 1928).

2. Постанова Кабінету Міністрів України від 20 серпня 2003 р. N 1306 ( 1306-2003-п ) "Про внесення зміни до переліку пунктів пропуску через державний кордон, через які здійснюється переміщення вантажів військового призначення, а також вантажів, що стосуються ядерної діяльності, у разі їх транзиту територією України" (Офіційний вісник України, 2008 р., N 51, ст. 1735).

3. Постанова Кабінету Міністрів України від 31 липня 2006 р. N 1042 ( 1042-2006-п ) "Про внесення зміни до переліку пунктів пропуску через державний кордон, через які здійснюється переміщення вантажів військового призначення, а також вантажів, що стосуються ядерної діяльності, у разі їх транзиту територією України".
