НАКАЗ Міністра оборони України

14.04.2007 N 176

Зареєстровано в Міністерстві юстиції України 18 квітня 2007 р. за N 388/13655

Про визнання наказу Міністра оборони України від 25.04.2005 N 242 таким, що не застосовується в Збройних Силах України

Відповідно до постанов Кабінету Міністрів України від 28 березня 2007 року N 594 ( 594-2007-п ) "Деякі питання грошового забезпечення військовослужбовців, осіб рядового і начальницького складу у 2007 році" та від 19 квітня 2005 року N 299 ( 299-2005-п ) "Про встановлення розміру додаткової грошової винагороди деяким категоріям військовослужбовців та іншим особам" (зі змінами) НАКАЗУЮ:

1. Наказ Міністра оборони України від 25 квітня 2005 року N 242 ( z0481-05 ) "Про встановлення щомісячної додаткової грошової винагороди окремим категоріям військовослужбовців", зареєстрований в Міністерстві юстиції України 11 травня 2005 року за N 481/10761 (зі змінами), уважати таким, що з 1 квітня 2007 року не застосовується в Збройних Силах України.

2. Наказ розіслати до окремої військової частини.

Міністр оборони України А.С.Гриценко
