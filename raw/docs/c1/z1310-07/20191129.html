Ідентифікатор: z1310-07

29.10.2007 N 432

Зареєстровано в Міністерстві юстиції України 26 листопада 2007 р. за N 1310/14577

{ Наказ втратив чинність на підставі Наказу Міністерства внутрішніх справ N 864 ( z1163-19 ) від 16.10.2019 }

Про встановлення вартості номерних знаків легкових автомобілів, виготовлених відповідно до вимог державних стандартів, які мають комбінацію з чотирьох однакових цифр і в межах від 0001 до 0009, що видаються за бажанням власників легкових автомобілів

{ Із змінами, внесеними згідно з Наказом Міністерства внутрішніх справ N 126 ( z0305-10 ) від 20.04.2010 }

На виконання вимог постанови Кабінету Міністрів України від 30.08.2007 N 1076 ( 1076-2007-п ) "Про внесення змін до постанов Кабінету Міністрів України від 31 січня 1992 р. N 47 і від 11 липня 2000 р. N 1081" та з метою впорядкування діяльності підрозділів Державтоінспекції НАКАЗУЮ:

1. Встановити вартість номерних знаків легкових автомобілів, виготовлених відповідно до вимог державних стандартів, які мають комбінацію з чотирьох однакових цифр і в межах від 0001 до 0009, що видаються за бажанням власників легкових автомобілів, згідно з додатком.

Вимоги цього пункту не поширюються на вартість номерних знаків легкових автомобілів, що належать органам державної влади України. Для цієї категорії транспортних засобів вартість номерних знаків визначається на загальних підставах. { Пункт 1 доповнено абзацом згідно з Наказом Міністерства внутрішніх справ N 126 ( z0305-10 ) від 20.04.2010 }

2. Видачу зазначених номерних знаків здійснювати відповідно до постанови Кабінету Міністрів України від 07.09.98 N 1388 ( 1388-98-п ) "Про затвердження Порядку державної реєстрації (перереєстрації), зняття з обліку автомобілів, автобусів, а також самохідних машин, сконструйованих на шасі автомобілів, мотоциклів усіх типів, марок і моделей, причепів, напівпричепів, мотоколясок, інших прирівняних до них транспортних засобів та мопедів" (із змінами).

{ Пункт 2 із змінами, внесеними згідно з Наказом Міністерства внутрішніх справ N 126 ( z0305-10 ) від 20.04.2010 }

3. Начальникам управлінь (відділів) Державтоінспекції (далі - ДАІ) головних управлінь, управлінь МВС в Автономній Республіці Крим, областях, містах Києві та Севастополі:

3.1. Організувати вивчення цього наказу працівниками служб і підрозділів ДАІ та забезпечити виконання його вимог.

3.2. Забезпечити особистий контроль за діяльністю підпорядкованих управлінь (відділів) ДАІ в частині впорядкування закріплення за транспортними засобами номерних знаків при проведенні реєстрації (перереєстрації).

3.3. Замовлення номерних знаків, крім зазначених у додатку, проводити тільки в порядку зростання цифрових, а також літерних символів, визначених додатком (В) до ДСТУ 4278:2006. До повного використання наявних номерних знаків, крім зазначених у додатку, відповідної серії заборонити проведення замовлення номерних знаків з іншими літеросполуками.

4. Начальникові ДДАІ Калинському О.О. забезпечити в установленому порядку реєстрацію цього наказу в Міністерстві юстиції України.

5. Контроль за виконанням цього наказу залишаю за собою.

Т.в.о. Міністра В.М.Корнієнко
