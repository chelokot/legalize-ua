Про виборчі скриньки для голосування на виборах Президента України

( Із змінами, внесеними згідно з Постановою Центральної виборчої комісії N 163 ( v0163359-04 ) від 08.07.2004 )

Відповідно до частин першої та четвертої статті 74, частини десятої статті 75 Закону України "Про вибори Президента України" ( 474-14 ), керуючись статтями 11, 12, пунктом 9 статті 13, статтею 16 Закону України "Про Центральну виборчу комісію" ( 733/97-ВР ), Центральна виборча комісія постановляє:

1. Визначити такі розміри та інші параметри виборчих скриньок:

- велика (стаціонарна) виборча скринька виготовляється із прозорого матеріалу, зокрема поліпропілену, полівінілхлориду, поліметилметакрилату, полікарбонату, полістиролу, має розбірну конструкцію багаторазового використання; висота скриньки 1000 мм, довжина - 500 мм, ширина - 500 мм, кришка з отвором, розмір якого 230 х 8 мм, для виборчих бюлетенів; на лицьовому боці скриньки розміщується малий Державний Герб України;

- мала (переносна) виборча скринька виготовляється із прозорого матеріалу, зокрема поліпропілену, полівінілхлориду, поліметилметакрилату, полікарбонату, полістиролу, має розбірну конструкцію багаторазового використання; висота скриньки 310 мм, довжина - 300 мм, ширина - 300 мм, кришка з отвором, розмір якого 230 х 8 мм, для виборчих бюлетенів; на лицьовому боці скриньки розміщується малий Державний Герб України.

( Пункт 1 в редакції Постанови Центральної виборчої комісії N 163 ( v0163359-04 ) від 08.07.2004 )

2. Взяти до відома, що орієнтовна кількість виготовлення скриньок становить:

- великих (стаціонарних) - 102000 шт.;

- малих (переносних) - 89000 шт.

3. Скасувати постанову Центральної виборчої комісії від 17 серпня 1999 року N 185 ( v0185359-99 ) "Про зразки скриньок для голосування на виборах Президента України, народних депутатів України, депутатів місцевих рад та сільських, селищних, міських голів, всеукраїнському та місцевих референдумах" у частині, що стосується встановлення зразків скриньок для голосування на виборах Президента України.
