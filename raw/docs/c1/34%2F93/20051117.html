УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Національну раду соціального партнерства

( Із змінами, внесеними згідно з Указами Президента N 97/96 від 29.01.96 N 1083/96 від 15.11.96 N 560/97 від 19.06.97 N 834/98 від 31.07.98 N 51/2003 ( 51/2003 ) від 30.01.2003 N 1464/2003 ( 1464/2003 ) від 19.12.2003 N 1101/2005 ( 1101/2005 ) від 13.07.2005 N 1611/2005 ( 1611/2005 ) від 17.11.2005 )

З метою узгодженого вирішення питань, що виникають у соціально-трудовій сфері, у відносинах Уряду України, підприємців і професійних спілок, та згідно з домовленостями учасників зустрічі за "круглим столом" - Президента України і представників профспілкових об'єднань, яка відбулася 5 червня 1992 року, постановляю:

1. Підтримати ініціативу Кабінету Міністрів України, об'єднань підприємців та професійних спілок і утворити при Президентові України Національну раду соціального партнерства.

2. Затвердити персональний склад Національної ради соціального партнерства, що додається.

3. Схвалити пропозицію Кабінету Міністрів України, об'єднань промисловців та професійних спілок і призначити співголовами Національної ради соціального партнерства

КАСКЕВИЧА Михайла Григоровича - Міністра праці України,

АВГУСТИМОВА Віталія Леонідовича - віце-президента Українського союзу промисловців і підприємців, президента корпорації "Укрелекор",

КОСТРИЦЮ Василя Івановича - голову ради Федерації профспілки працівників кооперації та інших форм вільного підприємництва України,

САХАНЬ Іван Якович - Міністр праці та соціальної політики України.

( Стаття 3 із змінами, внесеними згідно з Указами Президента N 1101/2005 ( 1101/2005 ) від 13.07.2005, N 1611/2005 ( 1611/2005 ) від 17.11.2005 )

4. Співголовам Національної ради соціального партнерства М.Каскевичу, В.Августимову та В.Костриці у місячний строк подати Президентові України проект Положення про Національну раду соціального партнерства.

5. Кабінету Міністрів України вирішити питання щодо надання в установленому порядку приміщення для Національної ради соціального партнерства та матеріально-технічного забезпечення її діяльності.
