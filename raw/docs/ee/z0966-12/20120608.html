Примiтки:

1. У лікувальних закладах кухні для стерилiзацiї посуду повиннi мати додатково до норми котли стравоварильнi належної ємностi.


2. Кухні будинкiв дитини, кiмнат для тривалих побачень, вартових приміщень, дільниць соціальної реабілітації забезпечуються належним обладнанням, посудом, приборами та iнвентарем за фактичною потребою.


3. Термоси призначенi для доставки їжi в приміщення камерного типу виправних колоній максимального рівня безпеки, камери слiдчих iзоляторiв, арештних домів, дисциплінарних iзоляторiв виправних колоній, виховних колоній, у стацiонари лікувальних закладів та інфекційні ізолятори медичних частин установ. Кількість термосів повинна бути достатньою для забезпечення доставки необхідної кількості їжі окремо по кожній страві.


4. Стелажами для зберігання продуктів харчування  продовольчі склади та їдальні забезпечуються за наявною потребою.


5. Приміщення для миття посуду в режимних корпусах слідчих ізоляторів та відділень лікувальних закладів забезпечуються ваннами для миття посуду, стелажами для зберігання чистого посуду, котлами для нагрівання води, виходячи із фактичної потреби.
