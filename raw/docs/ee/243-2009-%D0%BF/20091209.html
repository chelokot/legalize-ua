Кабінет Міністрів України; Постанова від 18.03.2009 № 243

Про порядок використання у 2009 році коштів державного бюджету, які виділяються виробникам лікарських засобів для компенсації додаткових витрат, пов'язаних із зміною ставки акцизного збору на спирт етиловий

Стан: Чинний

Ідентифікатор: 243-2009-п

Текст документа від 09.12.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 18 березня 2009 р. N 243 Київ

Про порядок використання у 2009 році коштів державного бюджету, які виділяються виробникам лікарських засобів для компенсації додаткових витрат, пов'язаних із зміною ставки акцизного збору на спирт етиловий

{ Із змінами, внесеними згідно з Постановою КМ N 1297 ( 1297-2009-п ) від 02.12.2009 }

Відповідно до статті 26 Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) Кабінет Міністрів України постановляє:

1. Установити, що використання у 2009 році коштів, передбачених у державному бюджеті ( 835-17 ) Міністерству охорони здоров'я за програмою "Компенсація виробникам додаткових витрат, пов'язаних з підвищенням з 1 січня 2004 р. ставки акцизного збору на спирт етиловий, що використовується для виготовлення лікарських засобів", здійснюється відповідно до Порядку використання у 2006 році коштів державного бюджету, які виділяються виробникам лікарських засобів для компенсації додаткових витрат, пов'язаних із зміною ставки акцизного збору на спирт етиловий, затвердженого постановою Кабінету Міністрів України від 13 березня 2006 р. N 275 ( 275-2006-п ) (Офіційний вісник України, 2006 р., N 11, ст. 713), з урахуванням особливостей, визначених постановою Кабінету Міністрів України від 20 квітня 2007 р. N 642 ( 642-2007-п ) (Офіційний вісник України, 2007 р., N 30, ст. 1210).

2. Установити, що компенсація за рахунок бюджетних коштів виробникам лікарських засобів додаткових витрат, пов'язаних з підвищенням ставки акцизного збору на спирт етиловий, що використовується для виготовлення лікарських засобів у 2009 році, здійснюється за спирт, отриманий ними з 1 січня 2008 р. по 27 березня 2009 р. та використаний за цільовим призначенням протягом 2008 і 2009 років.
