{ Постанова втратила чинність на підставі Постанови КМ N 686 ( 686-2006-п ) від 17.05.2006 }

Про внесення змін до постанови Кабінету Міністрів України від 2 березня 1998 р. N 256

Кабінет Міністрів України постановляє:

Внести зміни у додаток до постанови Кабінету Міністрів України від 2 березня 1998 р. N 256 ( 256-98-п ) "Про затвердження переліку нафтових і газових родовищ з важковидобувними та виснаженими запасами", виклавши його в редакції згідно з додатком.
