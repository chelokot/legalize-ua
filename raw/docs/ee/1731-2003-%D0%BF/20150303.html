{ Із змінами, внесеними згідно з Постановами КМ N 1129 ( 1129-2005-п ) від 30.11.2005 N 509 ( 509-2011-п ) від 18.05.2011 N 127 ( 127-2013-п ) від 04.03.2013 N 147 ( 147-2014-п ) від 27.05.2014 N 69 ( 69-2015-п ) від 28.02.2015 }

Відповідно до частини сьомої статті 20 Бюджетного кодексу України ( 2456-17 ) Кабінет Міністрів України постановляє:

{ Вступна частина із змінами, внесеними згідно з Постановою КМ N 69 ( 69-2015-п ) від 28.02.2015 }

1. Затвердити Порядок спрямування коштів державного бюджету, призначених для фінансування розвитку мережі і утримання автомобільних доріг загального користування, що додається.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 509 ( 509-2011-п ) від 18.05.2011 }

2. Визнати такими, що втратили чинність, пункти 3-6 та 8-10 постанови Кабінету Міністрів України від 2 лютого 1993 р. N 83 ( 83-93-п ) "Про Порядок збору та використання коштів для фінансування витрат, пов'язаних з будівництвом, реконструкцією, ремонтом і утриманням автомобільних доріг загального користування" (ЗП України, 1993 р., N 4-5, ст. 83, N 11, ст. 225; 1994 р., N 4, ст. 104, N 10, ст. 237; 1995 р., N 5, ст. 133; Офіційний вісник України, 1997 р., число 21, с. 22; 1999 р., N 26, ст. 1240, N 48, ст. 2365; 2002 р., N 1, ст. 22) та розділи I-IV Порядку збору, затвердженого зазначеною постановою.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 5 листопада 2003 р. N 1731

ПОРЯДОК спрямування коштів державного бюджету, призначених для фінансування розвитку мережі і утримання автомобільних доріг загального користування

{ У назві і тексті Порядку слова "спеціальний фонд" у всіх відмінках виключено на підставі Постанови КМ N 509 ( 509-2011-п ) від 18.05.2011 }

1. Цей Порядок визначає механізм спрямування коштів, передбачених у державного бюджету на відповідний рік для фінансування розвитку мережі і утримання автомобільних доріг загального користування.

Головним розпорядником бюджетних коштів та відповідальним виконавцем відповідних бюджетних програм є Укравтодор. { Пункт 1 доповнено абзацом згідно з Постановою КМ N 69 ( 69-2015-п ) від 28.02.2015 }

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 69 ( 69-2015-п ) від 28.02.2015 }

2. Одержувачами бюджетних коштів є:

організації, які виконують функції замовника робіт з будівництва, реконструкції, ремонту і утримання автомобільних доріг загального користування в Автономній Республіці Крим, областях та м. Севастополі;

підприємства та організації, що належать до сфери управління Укравтодору та одержують кошти на розширення, реконструкцію і технічне переоснащенн.

{ Абзац четвертий пункту 2 виключено на підставі Постанови КМ N 69 ( 69-2015-п ) від 28.02.2015 }

3. Кошти державного бюджету спрямовуються на:

будівництво, реконструкцію, капітальний та поточний ремонт і експлуатаційне утримання автомобільних доріг загального користування державного значення та споруд на них; { Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 69 ( 69-2015-п ) від 28.02.2015}

будівництво, реконструкцію, капітальний та поточний ремонт і експлуатаційне утримання автомобільних доріг загального користування місцевого значення та споруд на них; { Абзац третій пункту 3 із змінами, внесеними згідно з Постановою КМ N 69 ( 69-2015-п ) від 28.02.2015}

розвиток виробничих потужностей дорожніх організацій та підприємств, що належать до сфери управління Укравтодору (розширення, придбання та будівництво, реконструкція і технічне переоснащення кар'єрів, асфальтобетонних заводів, полігонів для виробництва залізобетонних конструкцій, заводів і майстерень з ремонту будівельних і дорожніх машин, баз механізації, виробничих баз для дорожніх організацій, автобаз, гаражів, інженерно-лабораторних корпусів та комплексів дорожньої служби і дорожнього сервісу, лінійних житлових будинків, а також придбання дорожньо-будівельної, дорожньо-експлуатаційної техніки, обладнання і транспортних засобів, інших основних фондів, необхідних для будівництва, функціонування і утримання автомобільних доріг загального користування); { Абзац четвертий пункту 3 в редакції Постанови КМ N 1129 ( 1129-2005-п ) від 30.11.2005 }

проектно-вишукувальні, науково-дослідні та впроваджувальні роботи у сфері дорожнього господарства;

{ Абзац шостий пункту 3 виключено на підставі Постанови КМ N 69 ( 69-2015-п ) від 28.02.2015 }

здійснення витрат на проведення конкурсів і підготовку угод (контрактів, договорів) щодо надання автомобільних доріг загального користування у концесію або виконання робіт з будівництва, реконструкції, ремонту і утримання автомобільних доріг загального користування та споруд на них за рахунок коштів міжнародних фінансових організацій, інших кредиторів та інвесторів, співфінансування цих робіт згідно з відповідними угодами, нагляд за їх виконанням і прийняття доріг в експлуатацію, виконання боргових зобов'язань за залученими відповідно до законодавства кредитами на розвиток та утримання мережі автомобільних доріг загального користування; { Абзац сьомий пункту 3 із змінами, внесеними згідно з Постановою КМ N 127 ( 127-2013-п ) від 04.03.2013 }

здійснення за погодженням з Мінфіном витрат, пов'язаних з наданням автомобільних доріг загального користування у концесію, у тому числі необхідних для розроблення та/або перекладу з іноземної мови інвестиційних пропозицій, техніко-економічного обґрунтування інвестицій, конкурсної документації, а також для презентації інвестиційних проектів під час проведення міжнародних заходів (форумів, конференцій тощо); { Пункт 3 доповнено абзацом згідно з Постановою КМ N 1129 ( 1129-2005-п ) від 30.11.2005 }

здійснення видатків за іншими напрямами, пов’язаними з розвитком мережі і утриманням автомобільних доріг загального користування, визначеними законом про Державний бюджет України на відповідний рік. { Пункт 3 доповнено абзацом згідно з Постановою КМ N 147 ( 147-2014-п ) від 27.05.2014 }

4. Обсяг спрямування коштів державного бюджету за напрямами відповідно до пункту 3 цього Порядку визначається головним розпорядником коштів у межах бюджетних призначень з метою забезпечення сталого функціонування та збалансованого розвитку мережі автомобільних доріг загального користування в регіонах країни відповідно до вимог Закону України про Державний бюджет України на відповідний рік та з урахуванням пріоритетів, встановлених державними програмами, фактичного стану автомобільних доріг та необхідності погашення кредиторської заборгованості, яка виникла в межах планових показників попередніх бюджетних періодів.

4-1. Казначейство здійснює закупівлю іноземної валюти за офіційним курсом Національного банку на дату проведення операції в сумі, необхідній для виконання боргових зобов’язань за кредитами відповідно до умов укладених договорів, з віднесенням витрат на закупівлю іноземної валюти до видатків за бюджетною програмою “Виконання боргових зобов’язань за запозиченнями, залученими державою або під державні гарантії, на розвиток мережі автомобільних доріг загального користування.

{ Порядок доповнено пунктом 4-1 згідно з Постановою КМ N 127 ( 127-2013-п ) від 04.03.2013; із змінами, внесеними згідно з Постановою КМ N 69 ( 69-2015-п ) від 28.02.2015 }

5. Відображення у первинному та бухгалтерському обліку інформації про отримані (створені) оборотні і необоротні активи, а також відкриття рахунків, реєстрація, облік бюджетних зобов’язань в органах Казначейства та проведення операцій, пов’язаних з використанням бюджетних коштів, здійснюються в установленому законодавством порядку.

{ Пункт 5 в редакції Постанови КМ N 127 ( 127-2013-п ) від 04.03.2013 }

{ Пункт 6 виключено на підставі Постанови КМ N 127 ( 127-2013-п ) від 04.03.2013 }

{ Пункт 7 виключено на підставі Постанови КМ N 127 ( 127-2013-п ) від 04.03.2013 }

8. Здійснення видатків, пов'язаних з будівництвом та реконструкцією автомобільних доріг загального користування, проводиться відповідно до постанови Кабінету Міністрів України від 27 грудня 2001 р. N 1764 ( 1764-2001-п ) "Про затвердження Порядку державного фінансування капітального будівництва" (Офіційний вісник України, 2001 р., N 52, ст. 2374).

9. Складення та подання фінансової та бюджетної звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.

{ Пункт 9 в редакції Постанови КМ N 127 ( 127-2013-п ) від 04.03.2013 }

10. Внутрішній контроль за надходженням і витрачанням бюджетних коштів одержувачами відповідно до законодавства покладається на головного розпорядника бюджетних коштів.
