{ Установити, що у 2010 році кошти, передбачені у державному бюджеті ( 2154-17 ) за програмою "Державна підтримка Всеукраїнського фізкультурно-спортивного товариства "Колос" на організацію та проведення роботи з розвитку фізичної культури і спорту серед сільського населення", використовуються відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 450 ( 450-2010-п ) від 16.06.2010 }

{ Із змінами, внесеними згідно з Постановами КМ N 105 ( 105-2011-п ) від 16.02.2011 N 233 ( 233-2015-п ) від 22.04.2015 N 134 ( 134-2016-п ) від 24.02.2016 N 1136 ( 1136-2019-п ) від 24.12.2019 N 374 ( 374-2020-п ) від 06.05.2020 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання коштів, передбачених у державному бюджеті для державної підтримки організації та проведення Всеукраїнським фізкультурно-спортивним товариством “Колос” агропромислового комплексу роботи з розвитку фізичної культури і спорту серед сільського населення, що додається.

{ Постановляюча частина із змінами, внесеними згідно з Постановами КМ N 105 ( 105-2011-п ) від 16.02.2011, N 134 ( 134-2016-п ) від 24.02.2016 }

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 22

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 5 березня 2009 р. N 163

ПОРЯДОК використання коштів, передбачених у державному бюджеті для державної підтримки організації та проведення Всеукраїнським фізкультурно-спортивним товариством "Колос" агропромислового комплексу роботи з розвитку фізичної культури і спорту серед сільського населення

{ Назва Порядку із змінами, внесеними згідно з Постановами КМ N 105 ( 105-2011-п ) від 16.02.2011, N 134 ( 134-2016-п ) від 24.02.2016 }

{ У тексті Порядку слово "Мінмолодьспорт" замінено словом "МКМС" згідно з Постановою КМ N 1136 ( 1136-2019-п ) від 24.12.2019 }

{ У тексті Порядку слово "МКМС" замінено словом "Мінмолодьспорт" згідно з Постановою КМ N 374 ( 374-2020-п ) від 06.05.2020 }

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті за програмою "Фінансова підтримка громадських організацій фізкультурно-спортивного спрямування" на організацію та проведення роботи з розвитку фізичної культури і спорту серед сільського населення Всеукраїнському фізкультурно-спортивному товариству "Колос" агропромислового комплексу (далі - бюджетні кошти).

Головним розпорядником бюджетних коштів та відповідальним виконавцем бюджетної програми є Мінмолодьспорт.

{ Пункт 1 в редакції Постанови КМ N 134 ( 134-2016-п ) від 24.02.2016 }

2. Мінмолодьспорт спрямовує бюджетні кошти Всеукраїнському фізкультурно-спортивному товариству "Колос" агропромислового комплексу (далі - Товариство), зокрема: { Абзац перший пункту 2 в редакції Постанови КМ N 134 ( 134-2016-п ) від 24.02.2016 }

Центральній раді Товариства на її утримання та забезпечення діяльності (оплата праці і комунальних послуг, послуг зв'язку, оренди та внесення пов'язаних з нею платежів, оплата проведення поточного ремонту, транспортних витрат, організаційно-методичних заходів, придбання малоцінних, швидкозношувальних предметів, матеріалів, обладнання та інвентарю, обслуговування оргтехніки, встановлення і супроводження програмного забезпечення, банківських, юридичних, типографських та поліграфічних послуг, участі у короткострокових семінарах, нарадах, нарадах-навчаннях), організацію роботи із створення умов для розвитку фізичної культури і спорту серед сільського населення (оплата проведення масових фізкультурно-спортивних, фізкультурно-оздоровчих заходів і змагань, забезпечення навчально-тренувального процесу та участі спортсменів Товариства у змаганнях різного рівня, проведення змагань серед студентів вищих аграрних навчальних закладів, інших заходів, пов'язаних з фізкультурно-спортивною діяльністю Товариства);

Центральній школі вищої спортивної майстерності Товариства на її утримання, забезпечення діяльності та навчально-тренувального процесу (оплата праці і комунальних послуг, послуг зв'язку, оренди та внесення пов'язаних з нею платежів, оплата проведення поточного ремонту, транспортних витрат, придбання малоцінних, швидкозношувальних предметів, матеріалів, обладнання та інвентарю, обслуговування оргтехніки, встановлення і супроводження програмного забезпечення, банківських, юридичних, типографських та поліграфічних послуг, участі у короткострокових семінарах, нарадах, нарадах-навчаннях, організації і проведення навчально-тренувальних зборів вихованців школи та забезпечення їх участі у змаганнях державного рівня, здійснення заходів з навчально-методичної роботи).

{ Абзац четвертий пункту 2 виключено на підставі Постанови КМ N 233 ( 233-2015-п ) від 22.04.2015 }

{ Пункт 2 із змінами, внесеними згідно з Постановою КМ N 105 ( 105-2011-п ) від 16.02.2011 }

3. Розподіл бюджетних коштів проводиться з урахуванням поданих Товариством обґрунтування потреби в коштах та детальних розрахунків витрат, визначених на підставі штатної чисельності працівників, затверджених умов оплати праці, єдиного календарного плану фізкультурно-оздоровчих та спортивних заходів Товариства, встановлених норм та нормативів, діючих цін і тарифів, відповідної проектно-кошторисної документації, першочерговості та невідкладності виконання робіт, результатів фінансово-господарської діяльності за минулий період та прогнозних показників діяльності на поточний рік.

4. Операції з бюджетними коштами здійснюються відповідно до Порядку казначейського обслуговування державного бюджету за витратами ( z0130-13 ), затвердженого Мінфіном.

{ Пункт 4 в редакції Постанов КМ N 105 ( 105-2011-п ) від 16.02.2011, N 233 ( 233-2015-п ) від 22.04.2015 }

5. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

6. Розрахунок проводиться згідно з умовами договору про закупівлю товарів, робіт і послуг на підставі актів прийняття-передачі виконаних робіт і наданих послуг та документального підтвердження вартості витрат і проведеного розрахунку.

7. Складення та подання звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.

{ Пункт 7 із змінами, внесеними згідно з Постановою КМ N 105 ( 105-2011-п ) від 16.02.2011 }

8. Мінмолодьспорт у строки, визначені для подання квартальної та річної зведеної фінансової звітності, подає Мінфіну за встановленою ним формою відповідно квартальний та річний звіти про виконання паспорта бюджетної програми, що підготовлені Товариством.

{ Порядок доповнено пунктом 8 згідно з Постановою КМ N 105 ( 105-2011-п ) від 16.02.2011; із змінами, внесеними згідно з Постановою КМ N 134 ( 134-2016-п ) від 24.02.2016 }
