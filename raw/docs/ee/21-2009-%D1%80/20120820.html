Кабінет Міністрів України; Розпорядження від 14.01.2009 № 21-р

Деякі питання реалізації проекту приєднання до джерел електропостачання електроустановок металургійного заводу "Дніпросталь"

Стан: Чинний

Ідентифікатор: 21-2009-р

Текст документа від 20.08.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 14 січня 2009 р. N 21-р Київ

Деякі питання реалізації проекту приєднання до джерел електропостачання електроустановок металургійного заводу "Дніпросталь"

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 407-р ( 407-2009-р ) від 15.04.2009 N 586-р ( 586-2012-р ) від 20.08.2012 }

1. Погодитися з пропозиціями Міністерства енергетики та вугільної промисловості та Національної комісії, що здійснює державне регулювання у сфері енергетики, щодо: { Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 586-р ( 586-2012-р ) від 20.08.2012 }

визначення ТОВ "Металургійний завод "Дніпросталь" (за його згодою) замовником та інвестором проектування і будівництва - комірок відкритого розподільного пристрою 330 кВ на Придніпровській ТЕС для приєднання кабельної лінії напругою 330 кВ Придніпровська ТЕС - підстанція "Пічна"; кабельної лінії напругою 330 кВ Придніпровська ТЕС - підстанція "Пічна" від зазначених комірок до підстанції "Пічна"; підстанції 330 кВ "Пічна" напругою 330 кВ;

видачі ВАТ "Дніпроенерго", яке є власником електричних мереж, ТОВ "Металургійний завод "Дніпросталь" технічних умов на приєднання кабельної лінії 330 кВ Придніпровська ТЕС - підстанція "Пічна" до комірок відкритого розподільного пристрою напругою 330 кВ на Придніпровській ТЕС, погоджених з державним підприємством НЕК "Укренерго" та ВАТ енергопостачальною компанією "Дніпрообленерго", в яких передбачити вимоги щодо подальшої експлуатації енергетичних об'єктів.

{ Пункт 1 в редакції Розпорядження КМ N 407-р ( 407-2009-р ) від 15.04.2009 }

1-1. Рекомендувати Національній комісії, що здійснює державне регулювання у сфері енергетики, розробити та за погодженням з Міністерством енергетики та вугільної промисловості затвердити порядок закупівлі електричної енергії з оптового ринку електричної енергії України для ТОВ “Металургійний завод “Дніпросталь”, яке є власником, замовником та інвестором кабельної лінії напругою 330 кВ, приєднаної до комірок відкритого розподільного пристрою 330 кВ на Придніпровській ТЕС, без урахування нормативних технологічних витрат місцевих (локальних) електричних мереж відповідного класу напруги та плати за послуги з передачі електричної енергії ліцензіату з передачі електричної енергії місцевими (локальними) електричними мережами.

{ Розпорядження доповнено пунктом 1-1 згідно з Розпорядженням КМ N 586-р ( 586-2012-р ) від 20.08.2012 }

{ Пункт 2 виключено на підставі Розпорядження КМ N 407-р ( 407-2009-р ) від 15.04.2009 }

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 14 листопада 2007 р. N 1000 ( 1000-2007-р ) "Про механізм розподілу фінансових зобов'язань, пов'язаних з реалізацією проекту приєднання до джерел електропостачання електроустановок металургійного заводу "Дніпросталь".

Прем'єр-міністр України Ю.ТИМОШЕНКО
