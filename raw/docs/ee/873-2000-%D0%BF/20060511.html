ПОСТАНОВА від 2 червня 2000 р. N 873 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Про колегію Державного комітету будівництва, архітектури та житлової політики

Кабінет Міністрів України постановляє:

1. Дозволити Державному комітету будівництва, архітектури та житлової політики мати колегію у кількості 12 чоловік.

2. Затвердити Григора Анатолія Федоровича членом колегії Державного комітету будівництва, архітектури та житлової політики, увільнивши від цих обов'язків Білянського Олександра Максимовича, Марочка Вадима Григоровича.

3. Визнати таким, що втратив чинність, пункт 1 постанови Кабінету Міністрів України від 17 січня 2000 р. N 69 ( 69-2000-п ) (Офіційний вісник України, 2000 р., N 3, ст. 79).
