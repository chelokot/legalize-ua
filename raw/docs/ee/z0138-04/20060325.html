Про затвердження форм дозволу на відкриття магазину безмитної торгівлі, заяви про його одержання та рішення про зупинення дії дозволу

{ Із змінами, внесеними згідно з Наказами Державної митної служби N 240/241 ( z0398-05 ) від 04.04.2005 N 51/49 ( z0176-06 ) від 24.01.2006 }

На виконання абзацу другого пункту 2 постанови Кабінету Міністрів України від 17.07.2003 N 1089 ( 1089-2003-п ) "Про затвердження Порядку відкриття і ліквідації магазинів безмитної торгівлі та Правил продажу товарів магазинами безмитної торгівлі" НАКАЗУЄМО:

1. Затвердити такі форми:

форму дозволу на відкриття магазину безмитної торгівлі ( z0139-04 );

форму заяви про одержання дозволу на відкриття магазину безмитної торгівлі;

форму рішення про зупинення дії дозволу на відкриття магазину безмитної торгівлі ( z0140-04 ) (додаються).

{ Пункт 2 фактично втратив чинність у зв'язку з втратою чинності Наказу Державного комітету у справах охорони державного кордону N 203/220 ( z0206-97 ) від 21.05.97, до якого вносились зміни } 2. Уважати такою, що втратила чинність, главу 3 Інструкції про порядок видачі дозволів на розміщення та функціонування підприємств (установ) сфери обслуговування пасажирів закордонного прямування в пунктах пропуску через державний кордон України, затвердженої наказом Державного комітету у справах охорони державного кордону України та Державної митної служби України від 21.05.97 N 203/220 ( z0206-97 ) і зареєстрованої в Міністерстві юстиції України 03.06.97 за N 206/2010.

3. Перереєстрація виданих до 1 січня 2004 року дозволів на право відкриття безмитних магазинів, яка передбачена абзацом другим пункту 2 постанови Кабінету Міністрів України від 17.07.2003 N 1089 ( 1089-2003-п ) "Про затвердження Порядку відкриття і ліквідації магазинів безмитної торгівлі та Правил продажу товарів магазинами безмитної торгівлі", проводиться відповідно до пунктів 3-8 Порядку відкриття і ліквідації магазинів безмитної торгівлі, затвердженого цією постановою Кабінету Міністрів України, шляхом заповнення нового бланка дозволу, форма якого затверджується цим наказом.

Попередній дозвіл, надісланий разом із зазначеними в пунктах 3-8 цього Порядку документами, вилучається.

( Наказ доповнено пунктом 3 згідно з Наказом Державної митної служби N 240/241 ( z0398-05 ) від 04.04.2005 )

4. Управлінню технологій митного контролю (Сьомка С.М.) й Управлінню правової роботи (Мельник М.В.) Державної митної служби України забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

5. Управлінню справами (Дрозд Г.А.) Державної митної служби України, Управлінню прикордонного контролю та реєстрації (Антонюк В.Г.) Адміністрації Державної прикордонної служби України забезпечити тиражування та розсилку цього наказу до митних органів, органів охорони державного кордону після його державної реєстрації в Міністерстві юстиції України.

6. Установити, що цей наказ набирає чинності через 10 днів після його державної реєстрації.

7. Контроль за виконанням цього наказу покласти на першого заступника Голови Державної митної служби України Іванюка М.М. та першого заступника Голови Державної прикордонної служби України Шишоліна П.А.
