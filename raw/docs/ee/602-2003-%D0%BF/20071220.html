Текст документа від 20.12.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 квітня 2003 р. N 602 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1360 ( 1360-2007-п ) від 21.11.2007 }

Про внесення зміни до Статуту Державної акціонерної компанії "Укрресурси"

Кабінет Міністрів України постановляє:

Доповнити пункт 4 розділу IV Статуту Державної акціонерної компанії "Укрресурси", затвердженого постановою Кабінету Міністрів України від 21 січня 1995 р. N 46 ( 46-95-п ) "Питання Державної акціонерної компанії "Укрресурси" (із змінами, внесеними постановою Кабінету Міністрів України від 19 серпня 1999 р. N 1538 ( 1538-99-п ), після абзацу першого новим абзацом такого змісту:

"До скликання перших загальних зборів акціонерів та затвердження ними Статуту Компанії державні пакети акцій відкритих акціонерних товариств та державне майно, які були передані до статутного фонду Компанії, не можуть бути відчужені (продані) або передані в заставу без рішення засновника".

У зв'язку з цим абзац другий вважати абзацом третім.

Прем'єр-міністр України В.ЯНУКОВИЧ
