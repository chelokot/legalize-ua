КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 лютого 1998 р. N 170 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Української частини Міжурядової Українсько-Білоруської комісії з питань торгівельно-економічного співробітництва

Кабінет Міністрів України постановляє:

Затвердити Віце-прем'єр-міністра України Тігіпка Сергія Леонідовича головою Української частини Міжурядової Українсько-Білоруської комісії з питань торгівельно-економічного співробітництва, увільнивши від цих обов'язків Мінченка Анатолія Калениковича.
