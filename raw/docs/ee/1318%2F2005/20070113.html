УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 1084/2006 ( 1084/2006 ) від 15.12.2006 }

Про внесення змін до Указу Президента України від 8 лютого 2005 року N 208

Внести до Указу Президента України від 8 лютого 2005 року N 208 ( 208/2005 ) "Про деякі питання організації діяльності Ради національної безпеки і оборони України" зміни, виключивши:

1) частину другу статті 1;

2) у статті 3 абзаци третій, четвертий, шостий, восьмий, дев'ятий, одинадцятий, дванадцятий, чотирнадцятий, п'ятнадцятий.

У зв'язку з цим абзаци п'ятий, сьомий, десятий, тринадцятий, шістнадцятий та сімнадцятий вважати відповідно абзацами третім, четвертим, п'ятим, шостим, сьомим і восьмим.

Президент України В.ЮЩЕНКО

м. Київ, 22 вересня 2005 року N 1318/2005
