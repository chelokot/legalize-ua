Про формений одяг працівників міліції

Відповідно до частини другої статті 16 Закону України "Про міліцію" ( 565-12 ) Кабінет Міністрів України постановляє:

1. Затвердити форму одягу та знаки розрізнення працівників міліції згідно з описом і зразками, що додаються.

2. Міністерству внутрішніх справ, Міністерству економіки, Міністерству фінансів під час формування обсягів продукції, поставки яких здійснюватимуться для державних потреб, передбачати необхідні обсяги виготовлення форменого одягу та знаків розрізнення для працівників міліції.

( Додатки не наводяться )
