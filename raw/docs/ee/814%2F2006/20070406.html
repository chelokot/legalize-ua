УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін до деяких указів Президента України щодо Секретаріату Президента України

{ Із змінами, внесеними згідно з Указом Президента N 238/2007 ( 238/2007 ) від 23.03.2007 }

Відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Внести до указів Президента України такі зміни:

1) в Указі Президента України від 14 жовтня 2005 року N 1445 ( 1445/2005 ) "Про створення Секретаріату Президента України" (зі змінами, внесеними Указами від 18 листопада 2005 року N 1614 ( 1614/2005 ), від 12 грудня 2005 року N 1741 ( 1741/2005 ), від 26 січня 2006 року N 65 ( 65/2006 ), від 26 травня 2006 року N 439 ( 439/2006 ) та від 2 червня 2006 року N 466 ( 466/2006 ):

{ Підпункт "а" пункту 1 статті 1 втратив чинність на підставі Указу Президента N 238/2007 ( 238/2007 ) від 23.03.2007 }

б) статтю 4 викласти в такій редакції:

"4. Визначити таку структуру Секретаріату Президента України:

Глава Секретаріату Президента України;

перші заступники Глави Секретаріату Президента України, в тому числі Перший заступник Глави Секретаріату Президента України - Представник Президента України у Кабінеті Міністрів України;

заступники Глави Секретаріату Президента України;

Представник Президента України у Верховній Раді України;

Представник Президента України у Конституційному Суді України;

Прес-секретар Президента України;

Радники Президента України;

Офіс Президента України;

Служба Глави Секретаріату Президента України;

Головна служба інформаційної політики;

Головна державно-правова служба;

Служба Державного Протоколу і Церемоніалу;

Режимно-секретна служба;

Головна служба документального забезпечення;

Головна служба регіональної політики;

Головна служба кадрової політики;

Головна служба політичного аналізу;

Головна служба зовнішньої політики;

Головна служба безпекової та оборонної політики;

Головна служба з питань діяльності правоохоронних органів;

Головна служба соціально-економічного розвитку;

Служба з питань збереження національного культурного надбання;

Служба ситуативного аналізу;

Служба з питань звернень громадян;

Служба державних нагород та геральдики;

Служба з питань громадянства;

Служба з питань помилування;

Служба забезпечення зв'язків з Верховною Радою України та Кабінетом Міністрів України;

Служба забезпечення зв'язків з Конституційним Судом України";

в) статтю 5 визнати такою, що втратила чинність;

г) Схему розподілу обов'язків між Главою Секретаріату Президента України, його Першим заступником та заступниками, закріплення за ними структурних підрозділів ( 1445а/2005 ) викласти в новій редакції, що додається ( 814а/2006 );

2) у Положенні про Секретаріат Президента України, затвердженому Указом Президента України від 4 листопада 2005 року N 1548 ( 1548/2005 ) (зі змінами, внесеними Указом від 18 листопада 2005 року N 1614 ( 1614/2005 ):

а) підпункт 8 пункту 4 виключити;

б) абзаци другий-четвертий пункту 7 замінити сімома абзацами такого змісту:

"Глава Секретаріату Президента України;

перші заступники Глави Секретаріату Президента України, в тому числі Перший заступник Глави Секретаріату Президента України - Представник Президента України у Кабінеті Міністрів України;

заступники Глави Секретаріату Президента України;

Представник Президента України у Верховній Раді України;

Представник Президента України у Конституційному Суді України;

Прес-секретар Президента України;

Радники Президента України".

У зв'язку з цим абзац п'ятий вважати відповідно абзацом дев'ятим;

в) в абзаці першому пункту 8:

слова "Перший заступник Глави Секретаріату Президента України" замінити словами "перші заступники Глави Секретаріату Президента України";

слова "Представник Президента України у Кабінеті Міністрів України" виключити;

г) у пункті 9:

у підпункті 4:

слова "Першого заступника Глави Секретаріату Президента України" замінити словами "перших заступників Глави Секретаріату Президента України";

слова "Представника Президента України у Кабінеті Міністрів України" виключити;

слова "які очолюють відповідні головні служби Секретаріату" виключити;

д) пункт 10 викласти в такій редакції:

"10. Перші заступники Глави Секретаріату Президента України, заступники Глави Секретаріату Президента України виконують обов'язки відповідно до Схеми розподілу обов'язків між Главою Секретаріату Президента України, його першими заступниками та заступниками, закріплення за ними структурних підрозділів, яка затверджується Президентом України.

Перший заступник Глави Секретаріату Президента України - Представник Президента України у Кабінеті Міністрів України також представляє Президента України у відносинах з Кабінетом Міністрів України, забезпечує скоординовану діяльність перших заступників Глави Секретаріату Президента України та заступників Глави Секретаріату Президента України.

У разі відсутності Глави Секретаріату Президента України його повноваження здійснює визначений відповідним рішенням Глави Секретаріату Президента України Перший заступник Глави Секретаріату Президента України, а за відсутності перших заступників - заступник Глави Секретаріату Президента України";

е) у пункті 11 слова "Представник Президента України у Кабінеті Міністрів України" виключити;

є) у пункті 12 слова "очолює Прес-службу" виключити.

2. Ліквідувати Регіональні приймальні Президента України.

У зв'язку з цим визнати такими, що втратили чинність:

Розпорядження Президента України від 28 квітня 2005 року N 1014 ( 1014/2005-рп ) "Про Регіональні приймальні Президента України";

Розпорядження Президента України від 10 червня 2005 року N 1088 ( 1088/2005-рп ) "Питання Регіональних приймалень Президента України".

3. Цей Указ набирає чинності з дня його опублікування.
