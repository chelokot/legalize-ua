Держспоживстандарт України; Наказ від 03.03.2006 № 65

Про внесення змін до наказу Держстандарту України від 30.10.2001 N 526 "Про затвердження Типового положення про апеляційні комісії при уповноважених органах із сертифікації та порядок розгляду ними скарг"

Реєстрація: Мін'юст України від 23.03.2006 № 321/12195

Стан: Втратив чинність

Ідентифікатор: z0321-06

Текст документа від 03.03.2006:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ З ПИТАНЬ ТЕХНІЧНОГО РЕГУЛЮВАННЯ ТА СПОЖИВЧОЇ ПОЛІТИКИ

НАКАЗ

03.03.2006 N 65

Зареєстровано в Міністерстві юстиції України 23 березня 2006 р. за N 321/12195

Про внесення змін до наказу Держстандарту України від 30.10.2001 N 526 "Про затвердження Типового положення про апеляційні комісії при уповноважених органах із сертифікації та порядок розгляду ними скарг"

Відповідно до Законів України "Про підтвердження відповідності" ( 2406-14 ) та "Про стандарти, технічні регламенти та процедури оцінки відповідності" ( 3164-15 ) НАКАЗУЮ:

1. Унести до наказу Держстандарту України від 30.10.2001 N 526 ( z1074-01 ) "Про затвердження Типового положення про апеляційні комісії при уповноважених органах із сертифікації та порядок розгляду ними скарг", зареєстрованого в Міністерстві юстиції України 26.12.2001 за N 1074/6265 (далі - наказ), такі зміни:

1.1. У тексті наказу та Типового положення ( z1074-01 ) слова "уповноважені органи із сертифікації" у всіх відмінках замінити словами "призначені органи з оцінки відповідності" у відповідному відмінку.

1.2. У тексті Типового положення ( z1074-01 ) слова "уповноважений центральний орган виконавчої влади у сфері підтвердження відповідності" у всіх відмінках замінити словами "центральний орган виконавчої влади з питань оцінки відповідності" у відповідному відмінку.

2. Департаменту технічного регулювання (Баб'як О.М.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Державному підприємству "Український науково-дослідний і навчальний центр проблем стандартизації, сертифікації та якості" (Філіпчук Г.Г.) після державної реєстрації цього наказу в Міністерстві юстиції України забезпечити його публікацію.

4. Контроль за виконанням цього наказу покласти на заступника Голови Вівчарика В.П.

Голова М.Негрич
