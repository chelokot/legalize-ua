КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 червня 2006 р. N 857 Київ

Про визнання такими, що втратили чинність, постанов Кабінету Міністрів України з питань визначення банків - агентів Кабінету Міністрів України з обслуговування іноземних кредитів, що залучаються під гарантії Кабінету Міністрів України

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, постанови Кабінету Міністрів України з питань визначення банків - агентів Кабінету Міністрів України з обслуговування іноземних кредитів, що залучаються під гарантії Кабінету Міністрів України, згідно з переліком, що додається.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 27

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 24 червня 2006 р. N 857

ПЕРЕЛІК постанов Кабінету Міністрів України з питань визначення банків - агентів Кабінету Міністрів України з обслуговування іноземних кредитів, що залучаються під гарантії Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 20 грудня 1997 р. N 1428 ( 1428-97-п ) "Про визначення акціонерного товариства "Український інноваційний банк" банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитів, які надаються під гарантії Кабінету Міністрів України".

2. Постанова Кабінету Міністрів України від 7 травня 1998 р. N 618 ( 618-98-п ) "Про визначення акціонерного комерційного банку "Правекс-банк" України банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України" (Офіційний вісник України, 1998 р., N 19, ст. 680).

3. Постанова Кабінету Міністрів України від 4 червня 1998 р. N 797 ( 797-98-п ) "Про визначення комерційного банку "Фінанси і кредит" банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України".

4. Постанова Кабінету Міністрів України від 16 червня 1998 р. N 891 ( 891-98-п ) "Про визначення комерційного банку "Приватбанк" банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України".

5. Постанова Кабінету Міністрів України від 7 серпня 1998 р. N 1243 ( 1243-98-п ) "Про визначення Українського кредитного банку банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України".

6. Постанова Кабінету Міністрів України від 13 листопада 1998 р. N 1799 ( 1799-98-п ) "Про визначення Всеукраїнського акціонерного банку банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України".

7. Постанова Кабінету Міністрів України від 2 грудня 1998 р. N 1909 ( 1909-98-п ) "Про визначення акціонерного комерційного банку "Київ" банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України".

8. Постанова Кабінету Міністрів України від 21 грудня 1998 р. N 2032 ( 2032-98-п ) "Про визначення Промінвестбанку банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантію Кабінету Міністрів України".

9. Постанова Кабінету Міністрів України від 15 вересня 1999 р. N 1710 ( 1710-99-п ) "Про визначення Першого українського міжнародного банку банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під гарантії Кабінету Міністрів України".

10. Постанова Кабінету Міністрів України від 21 грудня 1999 р. N 2336 ( 2336-99-п ) "Про визначення Банку депозитно-кредитного (Україна) Лтд банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під державні гарантії".

11. Постанова Кабінету Міністрів України від 6 січня 2000 р. N 6 ( 6-2000-п ) "Про визначення акціонерного комерційного банку "Форум" банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під державні гарантії".

12. Постанова Кабінету Міністрів України від 18 травня 2000 р. N 823 ( 823-2000-п ) "Про визначення акціонерного банку "Укргазпромбанк" банком - агентом Кабінету Міністрів України з обслуговування іноземних кредитних ліній, що залучаються під державні гарантії".
