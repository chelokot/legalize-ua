N 259 від 10.10.95 Зареєстровано в Міністерстві м.Київ юстиції України 24 жовтня 1995 р. за N 385/921

Про затвердження цін на інформаційно-обчислювальні послуги

Відповідно до Закону України "Про державну статистику" ( 2614-12 ) а також "Положення про Державний реєстр звітних (статистичних) одиниць України", затвердженого постановою Кабінету Міністрів України від 14.07.93 N 538 ( 538-93-п ) та "Положення про державну реєстрацію суб'єктів підприємницької діяльності", затвердженого постановою Кабінету Міністрів України від 29.04.94 N 276 ( 276-94-п ) та, враховуючи постанови Кабінету Міністрів України від 08.02.95 N 102 ( 102-95-п ) "Про підвищення заробітної плати на державних підприємствах, в установах і організаціях", від 13.06.95 N 409 ( 409-95-п ) "Про підвищення заробітної плати на державних підприємствах, в установах і організаціях", наказу Мінекономіки України від 19.06.95 N 90 ( z0183-95 ) "Про внесення змін і доповнень до наказу Мінекономіки від 20.04.95 N 62 "Про тарифи на електроенергію", НАКАЗУЮ:

1. Затвердити розрахункові ціни за надання госпрозрахункових інформаційно-обчислювальних послуг користувачам та замовникам по формуванню та видачі інформації з бази даних Державного реєстру звітних (статистичних) одиниць України, що додаються.

2. Вважати таким, що втратив чинність наказ Мінстату України від 29.08.94 N 194 ( z0209-94 ).

3. Контроль за виконанням цього наказу покласти на заступника Міністра Осауленка О.Г.

Міністр М.І.Борисенко Затверджено наказом Міністерства статистики України від 10.10.95 N 259
