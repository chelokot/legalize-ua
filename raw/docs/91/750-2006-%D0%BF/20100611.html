Текст документа від 11.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 травня 2006 р. N 750 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 394 ( 394-2010-п ) від 02.06.2010 }

Про внесення змін до Порядку пропуску яхт через державний кордон

Кабінет Міністрів України постановляє:

Внести до Порядку пропуску яхт через державний кордон, затвердженого постановою Кабінету Міністрів України від 29 серпня 2002 р. N 1274 ( 1274-2002-п ) (Офіційний вісник України, 2002 р., N 36, ст. 1687), такі зміни:

пункт 1 викласти у такій редакції:

"1. Дія цього порядку поширюється на юридичних та фізичних осіб, діяльність яких пов'язана з експлуатацією яхт - палубних вітрильних, вітрильно-моторних або моторних суден індивідуального чи колективного користування для відпочинку, туризму та спорту";

пункт 3 після слова "пасажири" доповнити словами "у разі перетинання державного кордону";

у пункті 5 слова "Адміністрація порту і морський агент зобов'язані" замінити словами "Адміністрація порту чи морський агент зобов'язані";

у пункті 6:

абзац перший після слів "Капітаном яхти" доповнити словами "у разі перетинання державного кордону";

доповнити пункт підпунктами такого змісту:

"11) свідоцтво про право плавання під прапором держави;

12) документ, що підтверджує право власності на судно".

Прем'єр-міністр України Ю.ЄХАНУРОВ
