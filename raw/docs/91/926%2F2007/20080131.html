Про зупинення дії розпорядження Кабінету Міністрів України від 26 вересня 2007 року N 763-р

{ Додатково див. Конституційне подання Президента ( n0031100-07 ) від 28.09.2007 }

Кабінетом Міністрів України видано розпорядження від 26 вересня 2007 року N 763-р ( 763-2007-р ) "Про звільнення Семерея П.І. з посади члена Національної комісії з питань регулювання зв'язку України".

Названим актом ( 763-2007-р ) Кабінет Міністрів України прийняв рішення з кадрового питання діяльності Національної комісії з питань регулювання зв'язку України, до компетенції якої віднесено регулювання природних монополій у сфері зв'язку.

Між тим згідно з частиною третьою статті 42 Конституції України ( 254к/96-ВР ) види і межі монополії визначаються законом. Особливості правового регулювання зазначених питань передбачено Законами України "Про природні монополії" ( 1682-14 ) та "Про телекомунікації" ( 1280-15 ). Відповідно до статті 4 Закону України "Про природні монополії" ( 1682-14 ) Національна комісія з питань регулювання зв'язку України є органом регулювання у сфері зв'язку. Згідно зі статтею 20 Закону України "Про телекомунікації" ( 1280-15 ) членів Національної комісії з питань регулювання зв'язку призначає за поданням Прем'єр-міністра України на посади та припиняє їх повноваження на цих посадах Президент України.

Конституційним обов'язком Президента України є забезпечення національної безпеки, складовою якої є економічна та інформаційна безпека держави, та здійснення керівництва у цій сфері (стаття 17, пункти 1 і 17 частини першої статті 106 Конституції України) ( 254к/96-ВР ).

Ураховуючи, що створення ефективного механізму державного регулювання природних монополій за статтею 8 Закону України "Про основи національної безпеки України" ( 964-15 ) є одним із основних напрямів державної політики з питань національної безпеки України в економічній сфері, зазначене розпорядження Кабінету Міністрів України ( 763-2007-р ) не відповідає статтям 17, 42, пунктам 1 і 17 частини першої статті 106 Конституції України ( 254к/96-ВР ), Законам України "Про природні монополії" ( 1682-14 ) та "Про телекомунікації" ( 1280-15 ).

Крім того, названий акт Кабінету Міністрів України ( 763-2007-р ) не відповідає і частині другій статті 8 Конституції України ( 254к/96-ВР ), згідно з якою нормативно-правові акти мають прийматися на основі Конституції України ( 254к/96-ВР ) і відповідати їй, а також частині другій статті 6 та частині другій статті 19 Основного Закону ( 254к/96-ВР ) держави, за якими органи державної влади зобов'язані діяти лише в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України.

З огляду на викладене відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію розпорядження Кабінету Міністрів України від 26 вересня 2007 року N 763-р ( 763-2007-р ) "Про звільнення Семерея П.І. з посади члена Національної комісії з питань регулювання зв'язку України".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
