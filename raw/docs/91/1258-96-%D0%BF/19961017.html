КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 жовтня 1996 р. N 1258 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про виділення коштів для спорудження надгробка на могилі колишнього члена Президії Верховної Ради Української РСР П.Ю. Шелеста

Кабінет Міністрів України постановляє:

Виділити Київській міській державній адміністрації у 1996 році 8 тис. гривень для спорудження надгробка на могилі колишнього члена Президії Верховної Ради Української РСР П.Ю. Шелеста.

Міністерству фінансів профінансувати зазначені витрати за рахунок резервного фонду Кабінету Міністрів України.
