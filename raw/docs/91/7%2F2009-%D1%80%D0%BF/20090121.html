Стан: Чинний

Ідентифікатор: 7/2009-рп

Текст документа від 21.01.2009:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про призначення державних стипендій видатним діячам культури і мистецтва

Відповідно до Указу Президента України від 14 лютого 1996 року N 128 ( 128/96 ) (зі змінами, внесеними Указами від 25 січня 2002 року N 71 ( 71/2002 ), від 23 січня 2006 року N 58 ( 58/2006 ) та від 16 травня 2008 року N 444) ( 444/2008 ) призначити державні стипендії видатним діячам культури і мистецтва:

ВІЦЬКУ Івану Михайловичу - 1930 року народження, народному художникові України

ГЕРАСИМОВУ Віктору Володимировичу - 1941 року народження, заслуженому діячеві мистецтв України

ДІДУХУ Володимиру Євгеновичу - 1937 року народження, народному артистові України, лауреатові Національної премії України імені Тараса Шевченка

РЕУСУ Валентину Миколайовичу - 1940 року народження, народному артистові України, лауреатові Національної премії України імені Тараса Шевченка

РЄПІНУ Володимиру Олександровичу - 1931 року народження, заслуженому артистові України

ХАРЧЕНКУ Олесю Миколайовичу - 1946 року народження, народному артистові України, лауреатові Національної премії України імені Тараса Шевченка

ШАРАПОВУ Вадиму Михайловичу - 1924 року народження, заслуженому архітекторові України.

Президент України В.ЮЩЕНКО

м. Київ, 21 січня 2009 року N 7/2009-рп
