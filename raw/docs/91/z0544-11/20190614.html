Про внесення змін до наказу Міністерства охорони здоров'я України від 17.05.2005 N 188

З метою приведення у відповідність до вимог чинного законодавства наказів Міністерства охорони здоров'я України, зареєстрованих у Міністерстві юстиції України, керуючись Положенням про Міністерство охорони здоров'я України, затвердженим Указом Президента України від 13.04.2011 N 467 ( 467/2011 ), НАКАЗУЮ:

1. Підпункт 2.4 пункту 2 наказу Міністерства охорони здоров'я України від 17.05.2005 N 188 ( z0811-05 ) "Про затвердження Інструкції щодо організації епідеміологічного нагляду за кором", зареєстрованого в Міністерстві юстиції України 28.07.2005 за N 811/11091, викласти в такій редакції:

"2.4. Забезпечити високий рівень (97%) охоплення щепленнями проти кору дітей згідно з календарем профілактичних щеплень".

2. Унести до Інструкції щодо організації епідеміологічного нагляду за кором, затвердженої наказом Міністерства охорони здоров'я України від 17.05.2005 N 188 ( z0811-05 ), зареєстрованої в Міністерстві юстиції України 28.07.2005 за N 811/11091, такі зміни:

2.1. У розділі 2:

2.1.1. Пункт 2.2 викласти в такій редакції:

"2.2. На кожен виявлений випадок захворювання на кір, а також при підозрі на це захворювання медичні працівники лікувально-профілактичних закладів, а також ті, що займаються приватною практикою, направляють протягом 12 годин Екстрене повідомлення про інфекційне захворювання, харчове, гостре професійне отруєння, незвичайну реакцію на щеплення (форма N 058/о) ( za686-06 ), затверджене наказом Міністерства охорони здоров'я України від 10.01.2006 N 1 ( z0686-06 ), зареєстрованим у Міністерстві юстиції України 08.06.2006 за N 686/12560, до територіальної санітарно-епідеміологічної станції за місцем проживання хворого".

2.1.2. Пункт 2.3 викласти в такій редакції:

"2.3. Кожен випадок захворювання на кір підлягає реєстрації та обліку за місцем його виявлення у Журналі обліку інфекційних захворювань (форма N 060/о) ( za687-06 ), затвердженому наказом Міністерства охорони здоров'я України від 10.01.2006 N 1 ( z0686-06 ), зареєстрованим у Міністерстві юстиції України 08.06.2006 за N 686/12560".

2.1.3. Пункт 2.14 викласти в такій редакції:

"2.14. Своєчасне проведення планових профілактичних щеплень здійснюється згідно з календарем профілактичних щеплень".

2.2. Пункт 3.1 розділу 3 викласти в такій редакції:

"3.1. Реєстрація випадку кору чи підозри на це захворювання здійснюється в Журналі обліку інфекційних захворювань (форма N 060/о) ( za687-06 ), затвердженому наказом Міністерства охорони здоров'я України від 10.01.2006 N 1 ( z0686-06 ), на основі Екстреного повідомлення про інфекційне захворювання, харчове, гостре професійне отруєння, незвичайну реакцію на щеплення (форма N 058/о) ( za686-06 ), затвердженого наказом Міністерства охорони здоров'я України від 10.01.2006 N 1, зареєстрованим у Міністерстві юстиції України 08.06.2006 за N 686/12560".

3. Департаменту організації санітарно-епідеміологічного нагляду забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Контроль за виконанням наказу покласти на першого заступника Міністра Аніщенка О.В.

5. Цей наказ набирає чинності з дня його офіційного опублікування.

Міністр І.М.Ємець
