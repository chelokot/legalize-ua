Кабінет Міністрів України; Розпорядження від 03.08.1999 № 767-р

Про внесення змін до розпорядження Кабінету Міністрів України від 1 вересня 1998 р. N 711

Стан: Втратив чинність

Ідентифікатор: 767-99-р

Текст документа від 27.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 серпня 1999 р. N 767-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 614-р ( 614-2001-р ) від 27.12.2001 )

( Додатково див. Розпорядження КМ N 272-р ( 272-2000-р ) від 26.06.2000 )

На зміну розпорядження Кабінету Міністрів України від 1 вересня 1998 р. N 711 ( 711-98-р ) затвердити новий склад представників від Кабінету Міністрів України до Національної ради соціального партнерства (додається).

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

Інд. 26
