КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 15 серпня 1992 р. N 473 Київ

( Постанова втратила чинність на підставі Постанови КМ N 483 ( 483-2002-п ) від 11.04.2002 )

Про затвердження інвестиційних програм і проектів та проведення державної експертизи інвестицій

( Із змінами, внесеними згідно з Постановою КМ N 1308 ( 1308-98-п ) від 17.08.98 )

Кабінет Міністрів України постановляє:

( Пункт 1 втратив чинність на підставі Постанови КМ N 1308 ( 1308-98-п ) від 17.08.98 )

2. Установити, що державна експертиза інвестиційних програм і проектів провадиться Українською державною інвестиційною експертизою (Укрінвестекспертизою), що складається із окремих підприємств: Центральної, галузевих (міжгалузевих) та місцевих служб державної інвестиційної експертизи.

Служби Укрінвестекспертизи здійснюють свою діяльність на засадах повної господарської самостійності, госпрозрахунку, мають право юридичної особи і є незалежними від органів державної виконавчої влади у питаннях, віднесених до їх компетенції.

( Пункт 3 втратив чинність на підставі Постанови КМ N 1308 ( 1308-98-п ) від 17.08.98 )

( Пункт 4 втратив чинність на підставі Постанови КМ N 1308 ( 1308-98-п ) від 17.08.98 )

( Пункт 5 втратив чинність на підставі Постанови КМ N 1308 ( 1308-98-п ) від 17.08.98 )

6. Покласти на Центральну службу Укрінвестекспертизи методологічне керівництво роботою всіх служб Укрінвестекспертизи, щорічне узагальнення підсумків експертизи інвестиційних програм і проектів, організацію взаємодії з міністерствами, іншими центральними та місцевими органами державної виконавчої влади.
