Президент України; Указ від 02.04.2010 № 498/2010

Про ліквідацію Міжвідомчої робочої групи з питань протидії контрабанді та порушенням митних правил

Стан: Чинний

Ідентифікатор: 498/2010

Текст документа від 02.04.2010:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про ліквідацію Міжвідомчої робочої групи з питань протидії контрабанді та порушенням митних правил

Відповідно до пункту 28 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Ліквідувати Міжвідомчу робочу групу з питань протидії контрабанді та порушенням митних правил.

У зв'язку з цим визнати такими, що втратили чинність:

Указ Президента України від 22 листопада 2007 року N 1137 ( 1137/2007 ) "Про Міжвідомчу робочу групу з питань протидії контрабанді та порушенням митних правил";

Указ Президента України від 27 грудня 2007 року N 1263 ( 1263/2007 ) "Про внесення зміни до Указу Президента України від 22 листопада 2007 року N 1137";

Указ Президента України від 28 серпня 2009 року N 694 ( 694/2009 ) "Про внесення змін до Указу Президента України від 22 листопада 2007 року N 1137".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 2 квітня 2010 року N 498/2010
