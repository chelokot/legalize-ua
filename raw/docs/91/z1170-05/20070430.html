{ Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 172 ( z0390-07 ) від 17.04.2007 }

Про внесення змін до наказу Міністерства праці та соціальної політики України від 21.06.2004 N 139

Відповідно до постанови Кабінету Міністрів України від 22.08.2005 N 790 ( 790-2005-п ) "Про внесення змін та визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань оплати праці працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести до наказу Міністерства праці та соціальної політики України від 21.06.2004 N 139 ( z0770-04 ) "Про умови оплати праці працівників Центру сприяння інституційному розвитку державної служби", зареєстрованого в Міністерстві юстиції України 23.06.2004 за N 770/9369 (із змінами), такі зміни:

1.1. В абзаці 1 підпункту 1 "ґ" пункту 2 слова "відсутнього працівника або за вакантною посадою" виключити.

1.2. Викласти додаток у новій редакції (додається).

2. Ці зміни застосовуються з 1 вересня 2005 року.

Міністр В.Кириленко

ПОГОДЖЕНО:

Заступник Міністра фінансів України В.Матвійчук

Начальник Головного управління державної служби України Т.Мотренко
