Текст документа від 30.06.1993:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 грудня 1992 р. N 741 Київ

Про перелік товарів (продукції), на які встановлюється акцизний збір, та ставки цього збору

( Із змінами, внесеними згідно з Постановами КМ N 167 ( 167-93-п ) від 11.03.93 N 489 ( 489-93-п ) від 30.06.93 )

Кабінет Міністрів України постановляє:

1. Затвердити перелік товарів (продукції), на які встановлюється акцизний збір, та ставки цього збору, що додається.

2. Визнати такими, що втратили чинність:

постанову Кабінету Міністрів України від 21 липня 1992 р. N 403 ( 403-92-п ) "Про надання додаткових пільг по акцизному збору запорізькому виробничому об'єднанню "АвтоЗАЗ";

пункт третій постанови Кабінету Міністрів України від 30 вересня 1992 р. N 553 ( 553-92-п ) "Про внесення змін до системи регульованих цін на горілку та спирт питний".

3. Ця постанова вводиться в дію з дня набрання чинності Декрету Кабінету Міністрів України "Про акцизний збір" ( 18-92 ).
