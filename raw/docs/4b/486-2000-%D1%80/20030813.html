КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 грудня 2000 р. N 486-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 510-р ( 510-2003-р ) від 13.08.2003 )

Про затвердження робочого проекту реконструкції лікувального корпусу N 1 Клінічної лікарні "Феофанія"

Затвердити поданий Державним лікувально-оздоровчим управлінням робочий проект реконструкції лікувального корпусу N 1 Клінічної лікарні "Феофанія" у м. Києві, розроблений АТ "Медінвестпроект" (м. Київ), з такими основними розрахунковими техніко-економічними показниками:

місткість - 120 ліжок

площа забудови - 2960 кв. метрів

будівельний об'єм - 54600 куб. метрів

загальна площа - 15690 кв. метрів

розрахункова кошторисна вартість - 66599,59 тис. гривень

у тому числі базисна кошторисна - 4245,07 тис. гривень

вартість будівельно-монтажних

робіт у цінах 1997 року
