КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 11 липня 2001 р. N 814 Київ

( Постанова втратила чинність на підставі Постанови КМ N 79 ( 79-2006-п ) від 01.02.2006 )

Про голову Ради у справах інвалідів при Кабінеті Міністрів України

Кабінет Міністрів України постановляє:

Затвердити Міністра праці та соціальної політики Саханя Івана Яковича головою Ради у справах інвалідів при Кабінеті Міністрів України, звільнивши від цих обов'язків Жулинського Миколу Григоровича.
