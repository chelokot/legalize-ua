Текст документа від 27.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 27 квітня 2006 р. N 584 Київ

Про затвердження Порядку використання у 2006 році коштів, передбачених у державному бюджеті для забезпечення обслуговування кредитних ресурсів, що залучені для реалізації проекту "Циклон-4"

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2006 році коштів, передбачених у державному бюджеті для забезпечення обслуговування кредитних ресурсів, що залучені для реалізації проекту "Циклон-4" (додається).

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 21

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 27 квітня 2006 р. N 584

ПОРЯДОК використання у 2006 році коштів, передбачених у державному бюджеті ( 3235-15 ) для забезпечення обслуговування кредитних ресурсів, що залучені для реалізації проекту "Циклон-4"

1. Цей Порядок визначає механізм використання у 2006 році коштів, передбачених у державному бюджеті ( 3235-15 ) НКАУ за програмою "Забезпечення обслуговування кредитних ресурсів, залучених для реалізації проекту "Циклон-4" (далі - бюджетні кошти).

2. Одержувачем бюджетних коштів є Державне конструкторське бюро "Південне" імені М.К. Янгеля (м. Дніпропетровськ).

3. Бюджетні кошти спрямовуються на забезпечення обслуговування кредитних ресурсів, що залучені для реалізації проекту "Циклон-4".

4. Сума сплачених відсотків за користування кредитними ресурсами відповідно до кредитного договору від 18 листопада 2004 р. між Державним конструкторським бюро "Південне" імені М.К. Янгеля та лондонською філією банку "Кредит Свісс Фьорст Бостон Інтернешнл" відшкодовується до 24 травня та 24 листопада поточного року згідно з Порядком обслуговування державного бюджету за видатками ( z0716-04 ), затвердженим Державним казначейством.

5. Контроль за використанням бюджетних коштів здійснюється в установленому законодавством порядку.
