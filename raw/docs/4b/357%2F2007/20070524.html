Президент України; Указ від 26.04.2007 № 357/2007

Питання С. Піскуна

Стан: Втратив чинність

Ідентифікатор: 357/2007

Текст документа від 24.05.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 469/2007 ( 469/2007 ) від 24.05.2007 }

Питання С. Піскуна

Керуючись частиною п'ятою статті 124 Конституції України ( 254к/96-ВР ) та на виконання постанови Шевченківського районного суду м. Києва від 26 квітня 2007 року скасувати Указ Президента України від 14 жовтня 2005 року N 1441 ( 1441/2005 ) "Про звільнення С. Піскуна з посади Генерального прокурора України", поновивши С. Піскуна на посаді Генерального прокурора України.

У зв'язку з цим скасувати Указ Президента України від 4 листопада 2005 року N 1542 ( 1542/2005 ) "Про призначення О. Медведька Генеральним прокурором України".

Президент України В.ЮЩЕНКО

м. Київ, 26 квітня 2007 року N 357/2007
