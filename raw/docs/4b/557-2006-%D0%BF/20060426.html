Кабінет Міністрів України; Постанова від 26.04.2006 № 557

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для завершення будівництва транспортних рефрижераторних суден з високим ступенем готовності

Стан: Чинний

Ідентифікатор: 557-2006-п

Текст документа від 26.04.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 26 квітня 2006 р. N 557 Київ

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для завершення будівництва транспортних рефрижераторних суден з високим ступенем готовності

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Установити, що використання у 2006 році коштів, передбачених Міністерству промислової політики за бюджетною програмою "Заходи по завершенню будівництва транспортних рефрижераторних суден з високим ступенем готовності" ( 3235-15 ), здійснюється відповідно до постанови Кабінету Міністрів України від 16 листопада 2005 р. N 1098 ( 1098-2005-п ) "Про порядок використання коштів, передбачених у державному бюджеті для завершення будівництва транспортних рефрижераторних суден з високим ступенем готовності" (Офіційний вісник України, 2005 р., N 46, ст. 2895).

Прем'єр-міністр України Ю.ЄХАНУРОВ
