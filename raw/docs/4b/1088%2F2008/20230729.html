УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про День усиновлення

{ Із змінами, внесеними згідно з Указом Президента N 455/2023 ( 455/2023 ) від 28.07.2023 }

{ У тексті Указу цифри і слово "30 вересня" замінено цифрами і словом "17 вересня" згідно з Указом Президента N 455/2023 ( 455/2023 ) від 28.07.2023 }

Ураховуючи суспільну значущість усиновлення в забезпеченні права кожної дитини на виховання в сім'ї, з метою підтримки та розвитку національного усиновлення постановляю:

Установити в Україні День усиновлення, який відзначати щорічно 17 вересня.
