Про заходи щодо організації виконання Загальнодержавної комплексної програми розвитку високих наукоємних технологій

Стан: Чинний

Текст документа від 19.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 грудня 2004 р. N 1679 Київ

Про заходи щодо організації виконання Загальнодержавної комплексної програми розвитку високих наукоємних технологій

{ Із змінами, внесеними згідно з Постановами КМ N 93 ( 93-2006-п ) від 01.02.2006 N 147 ( 147-2006-п ) від 15.02.2006 N 207 ( 207-2008-п ) від 19.03.2008 }

Відповідно до статті 2 Закону України "Про Загальнодержавну комплексну програму розвитку високих наукоємних технологій" ( 1676-15 ) Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

2. Визначити Міністерство промислової політики державним замовником Загальнодержавної комплексної програми розвитку високих наукоємних технологій ( 1676-15 ).

{ Пункт 3 втратив чинність на підставі Постанови КМ N 207 ( 207-2008-п ) від 19.03.2008 }

4. Міністерству промислової політики разом з Міністерством фінансів, Міністерством економіки передбачити під час формування проектів Державного бюджету та Державної програми економічного і соціального розвитку України починаючи з 2005 року видатки для виконання завдань, визначених Загальнодержавною комплексною програмою розвитку високих наукоємних технологій ( 1676-15 ). ( Пункт 4 із змінами, внесеними згідно з Постановою КМ N 93 ( 93-2006-п ) від 01.02.2006 )

Виконуючий обов'язки Прем'єр-міністра України М.АЗАРОВ
