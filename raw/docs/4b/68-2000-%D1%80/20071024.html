Кабінет Міністрів України; Розпорядження від 02.02.2000 № 68-р

Про затвердження Тігіпка С.Л. головою Митно-тарифної ради України

Стан: Втратив чинність

Ідентифікатор: 68-2000-р

Текст документа від 24.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 лютого 2000 р. N 68-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

1. Затвердити Міністра економіки Тігіпка Сергія Леонідовича головою Митно-тарифної ради України, увільнивши від цих обов'язків Рогового Василя Васильовича.

2. Голові Митно-тарифної ради України подати в місячний термін пропозиції про склад Ради з урахуванням змін, які відбулися у системі центральних органів виконавчої влади.

Прем'єр-міністр України В.ЮЩЕНКО
