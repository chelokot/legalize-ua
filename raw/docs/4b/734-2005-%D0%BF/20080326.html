Кабінет Міністрів України; Постанова від 10.08.2005 № 734

Про порядок використання коштів державного бюджету, що спрямовуються за програмою "Гірничорятувальні заходи на вугледобувних підприємствах"

Стан: Втратив чинність

Ідентифікатор: 734-2005-п

Текст документа від 26.03.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 серпня 2005 р. N 734 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 245 ( 245-2008-п ) від 26.03.2008 }

Про порядок використання коштів державного бюджету, що

спрямовуються за програмою "Гірничорятувальні заходи на вугледобувних підприємствах"

( Із змінами, внесеними згідно з Постановою КМ N 102 ( 102-2006-п ) від 02.02.2006 )

Кабінет Міністрів України постановляє:

( Вступна частина в редакції Постанови КМ N 102 ( 102-2006-п ) від 02.02.2006 )

Установити, що кошти, передбачені у державному бюджеті для проведення гірничорятувальних заходів на вугледобувних підприємствах, спрямовуються на:

( Абзац перший постановляючої частини в редакції Постанови КМ N 102 ( 102-2006-п ) від 02.02.2006 )

забезпечення діяльності центрального штабу та воєнізованих гірничорятувальних загонів Державної воєнізованої гірничорятувальної служби у вугільній промисловості;

підвищення готовності підрозділів зазначеної Служби до виконання ними робіт, пов'язаних з ліквідацією надзвичайних ситуацій і невідкладним реагуванням на надзвичайні ситуації у вугільних підприємствах;

здійснення контролю за готовністю вугільних підприємств до виконання робіт з ліквідації аварійних ситуацій;

технічне переоснащення підрозділів Служби;

відшкодування безвідсоткової бюджетної позики, наданої для погашення заборгованості з виплати заробітної плати та компенсації за її несвоєчасну виплату. ( Постанову доповнено абзацом згідно з Постановою КМ N 102 ( 102-2006-п ) від 02.02.2006 )

Перерахування коштів та здійснення видатків проводиться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.
