Кабінет Міністрів України; Розпорядження від 29.11.2000 № 470-р

Про деякі заходи щодо забезпечення природним газом галузей національної економіки і населення в осінньо-зимовий період

Стан: Чинний

Ідентифікатор: 470-2000-р

Текст документа від 29.11.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 29 листопада 2000 р. N 470-р Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Реєстраційний код акта : 44288/2008

Дата внесення до реєстру : 09.09.2008

Про деякі заходи щодо забезпечення природним газом галузей національної економіки і населення в осінньо-зимовий період

Для забезпечення безперебійного постачання природним газом галузей національної економіки і населення в осінньо-зимовий період дозволити Держмитслужбі здійснювати до 31 грудня 2000 р. митне оформлення природного газу, що надійшов та надходитиме на адресу НАК "Нафтогаз України", без сплати митного збору за його перебування під митним контролем.

Прем'єр-міністр України В.ЮЩЕНКО
