Кабінет Міністрів України; Постанова від 16.08.1999 № 1485

Про встановлення пільгового тарифу на електричну енергію для підприємств, які видобувають вугілля з пластів крутого падіння

Стан: Втратив чинність

Ідентифікатор: 1485-99-п

Текст документа від 05.04.2019:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 серпня 1999 р. N 1485 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 260 ( 260-2019-п ) від 06.03.2019 }

Про встановлення пільгового тарифу на електричну енергію для підприємств, які видобувають вугілля з пластів крутого падіння

З метою поліпшення соціально-економічного становища підприємств, які видобувають вугілля з пластів крутого падіння, Кабінет Міністрів України постановляє:

1. Національній комісії регулювання електроенергетики України встановити для виробничих об'єднань з видобутку вугілля "Артемвугілля", "Дзержинськвугілля", "Орджонікідзевугілля" та шахті імені Гайового, з 1 вересня 1999 р. до 1 вересня 2000 р. роздрібний тариф на електроенергію в розмірі 8 коп. за 1 кВт.г за умови оплати спожитої електроенергії банківськими коштами.

Для компенсації втрат енергетичної галузі, спричинених постачанням зазначеним підприємствам електроенергії за пільговим тарифом, забезпечити відшкодування їх за рахунок оптової ціни на електричну енергію.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 28 квітня 1998 р. N 580 ( 580-98-п ) "Про встановлення пільгового тарифу на електричну енергію для відкритого акціонерного товариства "Запорізький виробничий алюмінієвий комбінат" (Офіційний вісник України, 1998 р., N 17, ст. 636).

3. Контроль за виконанням цієї постанови покласти на Міністра вугільної промисловості Тулуба С.Б.
