Держбуд України; Наказ, Положення від 08.10.1999 № 247

Про затвердження Положення про порядок залучення і використання коштів на фінансування житлового будівництва та додаткове соціальне забезпечення громадян України в рамках експерименту

Реєстрація: Мін'юст України від 15.10.1999 № 705/3998

Стан: Втратив чинність

Ідентифікатор: z0705-99

Текст документа від 23.12.2008:

ДЕРЖАВНИЙ КОМІТЕТ БУДІВНИЦТВА, АРХІТЕКТУРИ ТА ЖИТЛОВОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

N 247 від 08.10.99 Зареєстровано в Міністерстві м.Київ юстиції України 15 жовтня 1999 р. за N 705/3998

{ Наказ втратив чинність на підставі Наказу Міністерства регіонального розвитку та будівництва N 527 ( z1192-08 ) від 21.11.2008 }

Про затвердження Положення про порядок залучення і використання коштів на фінансування житлового будівництва та додаткове соціальне забезпечення громадян України в рамках експерименту

{ Із змінами, внесеними згідно з Наказом Держбуду N 71 ( z0412-02 ) від 12.04.2002 }

{ Щодо втрати чинності Наказу див. Наказ Міністерства регіонального розвитку та будівництва N 374 ( v0374661-08 ) від 20.08.2008 }

На виконання пункту 10 Указу Президента України "Про проведення експерименту в житловому будівництві на базі холдингової компанії "Київміськбуд" ( 735/99 ) НАКАЗУЮ:

1. Затвердити Положення про порядок залучення і використання коштів на фінансування житлового будівництва та додаткове соціальне забезпечення громадян України в рамках експерименту, що додається.

2. Наказ "Про затвердження Положення про порядок залучення і використання коштів на фінансування житлового будівництва та додаткове соціальне забезпечення громадян України в рамках експерименту" ввести в дію в установленому порядку.

3. Контроль за виконанням цього наказу залишаю за собою.

Голова Комітету В.М.Гусаков

( Положення про порядок залучення і використання коштів на фінансування житлового будівництва та додаткове соціальне забезпечення громадян України в рамках експерименту втратило чинність на підставі Наказу Держбуду N 71 ( z0412-02 ) від 12.04.2002 )
