УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про державні стипендії чемпіонам і призерам Олімпійських, Паралімпійських та Дефлімпійських ігор

{ Із змінами, внесеними згідно з Указами Президента N 377/2013 ( 377/2013 ) від 12.07.2013 N 353/2017 ( 353/2017 ) від 07.11.2017 N 4/2019 ( 4/2019 ) від 09.01.2019 }

1. Внести зміни до таких указів Президента України:

1) на зміну статті 1 Указу Президента України від 18 серпня 2004 року N 919 ( 919/2004 ) "Про державні стипендії чемпіонам і призерам Олімпійських, Паралімпійських та Дефлімпійських ігор" (зі змінами, внесеними Указами від 21 жовтня 2005 року N 1505 ( 1505/2005 ) та від 21 липня 2008 року N 642) ( 642/2008 ) затвердити Положення про державні стипендії чемпіонам і призерам Олімпійських, Паралімпійських та Дефлімпійських ігор у новій редакції (додається);

2) у статті 2 Указу Президента України від 21 жовтня 2005 року N 1505 ( 1505/2005 ) "Про внесення змін до деяких указів Президента України" слова "та затвердженому цим Указом Положенні" виключити;

3) пункт 3 статті 1 Указу Президента України від 21 липня 2008 року N 642 ( 642/2008 ) "Про збільшення розміру та кількості стипендій Президента України для видатних спортсменів та їх тренерів" виключити.

2. Установити, що державні стипендії чемпіонам і призерам Олімпійських, Паралімпійських та Дефлімпійських ігор, призначені в установленому порядку до набрання чинності цим Указом, у подальшому виплачуються у порядку та розмірах, передбачених Положенням, затвердженим цим Указом.

3. Цей Указ набирає чинності з дня його опублікування.

ЗАТВЕРДЖЕНО Указом Президента України від 10 вересня 2011 року N 907/2011

ПОЛОЖЕННЯ про державні стипендії чемпіонам і призерам Олімпійських, Паралімпійських та Дефлімпійських ігор

1. Державні стипендії чемпіонам і призерам Олімпійських, Паралімпійських та Дефлімпійських ігор (далі - державні стипендії) можуть бути призначені чемпіонам та призерам Олімпійських, Паралімпійських та Дефлімпійських ігор, які виступали у складі національних збірних команд України або колишнього Союзу РСР та за станом здоров'я не можуть брати участь у змаганнях найвищого світового рівня з відповідних видів спорту.

2. Державні стипендії призначаються громадянам України, які постійно проживають в Україні та не брали участі в офіційних міжнародних спортивних змаганнях за інші держави.

{ Пункт 2 із змінами, внесеними згідно з Указом Президента N 353/2017 ( 353/2017 ) від 07.11.2017 }

3. Державні стипендії призначаються:

чемпіонам Олімпійських, Паралімпійських та Дефлімпійських ігор у розмірі чотирьох прожиткових мінімумів для працездатних осіб кожна;

призерам Олімпійських, Паралімпійських та Дефлімпійських ігор, які посіли друге або третє місце на таких іграх, - у розмірі відповідно трьох з половиною та трьох прожиткових мінімумів для працездатних осіб кожна.

4. Державні стипендії призначаються Президентом України за поданням Міністерства молоді та спорту України.

Державні стипендії призначаються довічно.

Пропозиції щодо кандидатів на призначення державних стипендій попередньо розглядаються комісією з державних стипендій (далі - комісія), яка утворюється Міністерством молоді та спорту України.

Порядок проведення добору кандидатів на призначення державних стипендій ( z1579-13 ) затверджується Міністерством молоді та спорту України.

{ Пункт 4 в редакції Указу Президента N 377/2013 ( 377/2013 ) від 12.07.2013 }

5. Пропозиції щодо кандидатів на призначення державних стипендій вносять до комісії національні федерації з видів спорту.

Перелік документів, необхідних для внесення особи як кандидата на призначення державної стипендії, визначається Міністерством молоді та спорту України. { Абзац другий пункту 5 із змінами, внесеними згідно з Указом Президента N 377/2013 ( 377/2013 ) від 12.07.2013 }

6. Добір кандидатів на призначення державних стипендій здійснюється комісією з урахуванням таких критеріїв:

безпосередня участь у навчально-тренувальному процесі, зокрема робота у дитячо-юнацьких спортивних закладах незалежно від підпорядкування та форми власності, у спеціалізованих навчальних закладах спортивного профілю та підготовці спортсменів для національних збірних команд з олімпійських, паралімпійських, дефлімпійських видів спорту;

безпосередня участь у громадській діяльності щодо розвитку фізичної культури та спорту.

За результатами добору комісія вносить пропозиції щодо кандидатур на призначення державних стипендій Міністерству молоді та спорту України щороку до 15 вересня. { Абзац четвертий пункту 6 із змінами, внесеними згідно з Указом Президента N 377/2013 ( 377/2013 ) від 12.07.2013 }

7. Особі може бути призначено відповідно до цього Положення лише одну державну стипендію.

Державна стипендія виплачується щомісяця, незалежно від розміру одержуваної стипендіатом заробітної плати чи пенсії.

Виплата державних стипендій здійснюється Міністерством молоді та спорту України. { Абзац третій пункту 7 із змінами, внесеними згідно з Указом Президента N 377/2013 ( 377/2013 ) від 12.07.2013 }

8. У разі від'їзду стипендіата на роботу за кордон чи з інших причин (за винятком відрядження його Міністерством молоді та спорту України) на строк понад два місяці виплата державної стипендії припиняється до повернення його в Україну та відновлюється указом Президента України за клопотанням Міністерства молоді та спорту України.

Подання про припинення виплати державної стипендії або її відновлення вноситься Міністерству молоді та спорту України національною спортивною федерацією з виду спорту, Національним комітетом спорту інвалідів України або спортивною федерацією осіб з інвалідністю, що подавали пропозиції про призначення державної стипендії відповідному стипендіату. { Пункт 8 доповнено абзацом згідно з Указом Президента N 353/2017 ( 353/2017 ) від 07.11.2017; із змінами, внесеними згідно з Указом Президента N 4/2019 ( 4/2019 ) від 09.01.2019 }

{ Пункт 8 із змінами, внесеними згідно з Указом Президента N 377/2013 ( 377/2013 ) від 12.07.2013 }

9. Стипендіат може бути позбавлений державної стипендії Президентом України за поданням Міністерства молоді та спорту України у випадках: { Абзац перший пункту 9 із змінами, внесеними згідно з Указом Президента N 377/2013 ( 377/2013 ) від 12.07.2013 }

засудження його за умисний злочин;

дискваліфікації Міжнародним олімпійським комітетом, Міжнародним паралімпійським комітетом, іншою міжнародною спортивною організацією або національною спортивною федерацією з виду спорту;

порушення вимог антидопінгового законодавства; { Пункт 9 доповнено новим абзацом згідно з Указом Президента N 353/2017 ( 353/2017 ) від 07.11.2017 }

участі в офіційних міжнародних спортивних змаганнях за інші держави; { Пункт 9 доповнено новим абзацом згідно з Указом Президента N 353/2017 ( 353/2017 ) від 07.11.2017 }

припинення безпосередньої участі в навчально-тренувальному процесі або діяльності щодо розвитку громадського фізкультурно-спортивного руху, підготовці спортсменів для національних збірних команд з олімпійських, паралімпійських, дефлімпійських видів спорту, крім осіб, які досягли пенсійного віку. { Абзац шостий пункту 9 із змінами, внесеними згідно з Указом Президента N 353/2017 ( 353/2017 ) від 07.11.2017 }

10. У разі смерті стипендіата Міністерство молоді та спорту України за поданням національної спортивної федерації з виду спорту, Національного комітету спорту інвалідів України або спортивної федерації осіб з інвалідністю, що подавали пропозицію про призначення державної стипендії відповідному стипендіату, здійснює виплату державної стипендії у розмірі 50 відсотків його неповнолітнім дітям до досягнення ними 18-річного віку.

{ Пункт 10 із змінами, внесеними згідно з Указами Президента N 377/2013 ( 377/2013 ) від 12.07.2013, N 353/2017 ( 353/2017 ) від 07.11.2017, N 4/2019 ( 4/2019 ) від 09.01.2019 }
