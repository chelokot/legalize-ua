Кабінет Міністрів України; Розпорядження від 02.06.2010 № 1154-р

Про віднесення посад працівників Адміністрації Президента України до відповідних категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 1154-2010-р

Текст документа від 25.05.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 червня 2010 р. N 1154-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 446-р ( 446-2011-р ) від 25.05.2011 }

Про віднесення посад працівників Адміністрації Президента України до відповідних категорій посад державних службовців

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1766-р ( 1766-2010-р ) від 02.09.2010 }

1. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників Адміністрації Президента України до таких категорій посад державних службовців:

перша категорія - перший заступник Глави Адміністрації Президента України - Представник Президента України у Конституційному Суді України, Прес-секретар Президента України;

друга категорія - заступники Глави Адміністрації Президента України - керівники головних управлінь, перший заступник Керівника Головного управління, заступник Керівника Головного управління (управління), завідувачі самостійних відділів, керівники управлінь у складі головних управлінь, заступники керівників управлінь у складі головних управлінь, завідувачі відділів у складі головних управлінь (управлінь), Керівник Прес-служби, референти Президента України, уповноважений Президента України, радник Глави Адміністрації Президента України, заступник Керівника Головного управління - керівник управління, заступник керівника управління - завідувач відділу, завідувач відділу - головний інспектор; { Абзац третій пункту 1 в редакції Розпорядження КМ N 1766-р ( 1766-2010-р ) від 02.09.2010 }

третя категорія - заступники завідувачів самостійних відділів, завідувачі груп, заступники завідувачів відділів у складі головних управлінь (управлінь), заступник завідувача відділу - завідувач сектору, помічники Глави Адміністрації Президента України, першого заступника Глави Адміністрації Президента України, першого заступника Глави Адміністрації Президента України - Представника Президента України у Конституційному Суді України, заступника Глави Адміністрації Президента України - Керівника Головного управління, головний консультант, головний консультант - заступник головного інспектора, головний консультант-інспектор, старший консультант. { Абзац четвертий пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 1766-р ( 1766-2010-р ) від 02.09.2010 }

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 24 грудня 2005 р. N 572 ( 572-2005-р ) "Про віднесення посад працівників Секретаріату Президента України до відповідних категорій посад державних службовців" (Офіційний вісник України, 2005 р., N 52, ст. 3356).
