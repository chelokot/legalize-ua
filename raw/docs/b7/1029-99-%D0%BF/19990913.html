Стан: Втратив чинність

Ідентифікатор: 1029-99-п

Текст документа від 13.09.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 12 червня 1999 р. N 1029 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1667 ( 1667-99-п ) 13.09.99 )

Про фінансування будівництва об'єктів виробничого і невиробничого призначення в межах загальних обсягів капітальних вкладень, передбачених державним бюджетом

( Зміни в текст не внесені. Додатково див. Постанову КМ N 1097 ( 1097-99-п ) від 22.06.99 )

Кабінет Міністрів України постановляє:

1. Міністерству фінансів профінансувати в поточному році будівництво об'єктів виробничого і невиробничого призначення в межах загальних обсягів капітальних вкладень відповідно до Закону України "Про Державний бюджет України на 1999 рік" ( 378-14 ) згідно з переліком.( Перелік відсутній в БД )

2. Міністерству економіки разом з Міністерством фінансів за підсумками роботи народного господарства у першому півріччі 1999 р. підготувати пропозиції про внесення змін до постанови Кабінету Міністрів України від 23 березня 1999 р. N 452 ( 452-99-п ) "Про розподіл державних централізованих капітальних вкладень та переліки об'єктів, що фінансуються за їх рахунок у 1999 році", передбачивши при цьому приведення обсягів капітальних вкладень у відповідність з видатками державного бюджету.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
