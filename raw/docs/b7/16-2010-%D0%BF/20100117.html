Про внесення змін до постанов Кабінету Міністрів України від 21 грудня 2001 р. N 1713 та від 28 липня 2004 р. N 966

Кабінет Міністрів України постановляє:

Внести до постанов Кабінету Міністрів України від 21 грудня 2001 р. N 1713 ( 1713-2001-п ) "Про затвердження Порядку оплати або відшкодування вартості послуг, наданих окружним і дільничним виборчим комісіям під час підготовки та проведення виборів народних депутатів України" (Офіційний вісник України, 2001 р., N 52, ст. 2340; 2005 р., N 52, ст. 3318; 2006 р., N 11, ст. 723) та від 28 липня 2004 р. N 966 ( 966-2004-п ) "Про умови оплати праці членів виборчих комісій" (Офіційний вісник України, 2004 р., N 31, ст. 2063) зміни, що додаються.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 39

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 13 січня 2010 р. N 16

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 21 грудня 2001 р. N 1713 ( 1713-2001-п ) та від 28 липня 2004 р. N 966 ( 966-2004-п )

1. Пункт 5 Порядку оплати або відшкодування вартості послуг, наданих окружним і дільничним виборчим комісіям під час підготовки та проведення виборів народних депутатів України, затвердженого постановою Кабінету Міністрів України від 21 грудня 2001 р. N 1713 ( 1713-2001-п ), доповнити абзацом такого змісту:

"Відшкодування вартості автотранспортних послуг, пов'язаних з виїздом членів дільничної виборчої комісії до виборців, які звернулися до виборчої дільниці для організації їх голосування за межами приміщення для голосування без подання ними відповідної медичної довідки, що підтверджує неможливість самостійного прибуття на виборчу дільницю, є використанням бюджетних коштів всупереч їх цільовому призначенню.".

2. Пункт 4 постанови Кабінету Міністрів України від 28 липня 2004 р. N 966 ( 966-2004-п ) доповнити абзацом такого змісту:

"Виплата членам дільничної виборчої комісії заробітної плати за робочий час, витрачений для виїзду до виборців, які звернулися до виборчої дільниці для організації їх голосування за межами приміщення для голосування без подання ними відповідної медичної довідки, що підтверджує неможливість самостійного прибуття на виборчу дільницю, а також за робочий час, витрачений для проведення засідання дільничної виборчої комісії з метою доповнення списків виборців у день проведення голосування, є використанням бюджетних коштів всупереч їх цільовому призначенню.".
