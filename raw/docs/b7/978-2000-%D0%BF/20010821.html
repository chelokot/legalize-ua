Про затвердження переліку суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості

( Із змінами, внесеними згідно з Постановою КМ N 1106 ( 1106-2001-п ) від 21.08.2001 )

Кабінет Міністрів України постановляє:

Відповідно до статті 1 Закону України "Про заходи щодо державної підтримки суднобудівної промисловості в Україні" ( 1242-14 ) затвердити перелік суднобудівних підприємств, для яких запроваджуються заходи державної підтримки суднобудівної промисловості, передбачені зазначеним Законом (додається).
