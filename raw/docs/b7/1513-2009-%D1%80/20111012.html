Про проведення переговорів щодо укладення Генеральної угоди між Кабінетом Міністрів України, спільним представницьким органом сторони роботодавців на національному рівні та всеукраїнськими профспілками і профоб'єднаннями та галузевих (міжгалузевих) і територіальних колективних угод на новий строк

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 2 грудня 2009 р. N 1513-р Київ

Про проведення переговорів щодо укладення Генеральної угоди між Кабінетом Міністрів України, спільним представницьким органом сторони роботодавців на національному рівні та всеукраїнськими профспілками і профоб'єднаннями та галузевих (міжгалузевих) і територіальних колективних угод на новий строк

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 590-р ( 590-2010-р ) від 24.03.2010 N 1956-р ( 1956-2010-р ) від 12.10.2010 N 1005-р ( 1005-2011-р ) від 12.10.2011 }

{ У назві та тексті розпорядження, крім абзацу четвертого пункту 5, слова "галузеві і регіональні" у всіх відмінках замінено словами "галузеві (міжгалузеві) і територіальні" у відповідному відмінку згідно з Розпорядженням КМ N 1005-р ( 1005-2011-р ) від 12.10.2011 }

1. На звернення професійних спілок, які об'єдналися для ведення переговорів щодо укладення Генеральної угоди між Кабінетом Міністрів України, спільним представницьким органом сторони роботодавців на національному рівні та всеукраїнськими профспілками і профоб'єднаннями на новий строк (далі - повноважні представники Сторони профспілок), та відповідно до Закону України "Про колективні договори і угоди" ( 3356-12 ) затвердити склад групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення переговорів щодо укладення Генеральної угоди і здійснення контролю за її виконанням (далі - повноважні представники Сторони власників), згідно з додатком.

Надати право керівникові групи повноважних представників Сторони власників у разі потреби вносити зміни до складу представників від Кабінету Міністрів України, державних колегіальних органів, а за поданням спільного представницького органу Сторони роботодавців на національному рівні - до складу представників від роботодавців. { Абзац другий пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 1005-р ( 1005-2011-р ) від 12.10.2011 }

2. Повноважним представникам Сторони власників розпочати з повноважними представниками Сторони профспілок консультації та переговори щодо підготовки проекту Генеральної угоди між Кабінетом Міністрів України, спільним представницьким органом сторони роботодавців на національному рівні та всеукраїнськими профспілками і профоб'єднаннями на новий строк (далі - Генеральна угода) та її укладення.

3. Міністерствам, іншим центральним органам виконавчої влади, державним колегіальним органам визначати за зверненням Міністерства соціальної політики представників до складу робочих груп з розроблення розділів проекту Генеральної угоди.

{ Пункт 3 із змінами, внесеними згідно з Розпорядженням КМ N 1005-р ( 1005-2011-р ) від 12.10.2011 }

4. Керівникові групи повноважних представників Сторони власників інформувати Кабінет Міністрів України про хід переговорів щодо укладення Генеральної угоди.

5. Міністерствам, іншим центральним і місцевим органам виконавчої влади:

визначити і затвердити своїх повноважних представників для участі у переговорах щодо укладення галузевих (міжгалузевих) і територіальних колективних угод на новий строк (далі - галузеві (міжгалузеві) і територіальні угоди) та здійснення контролю за їх виконанням;

сформувати разом з всеукраїнськими галузевими об'єднаннями організацій роботодавців, обласними організаціями роботодавців (їх об'єднаннями) групи повноважних представників Сторони власників для участі у зазначених переговорах відповідного рівня (за їх згодою);

доручити своїм повноважним представникам не раніше ніж за три місяці до закінчення строку дії галузевих і регіональних угод або у строки, визначені цими угодами, розпочати такі переговори у разі письмового звернення професійних спілок, які мають відповідні повноваження;

своєчасно надавати повноважним представникам Сторони власників і Сторони профспілок необхідну інформацію для ведення переговорів, підготовки проекту Генеральної, галузевих (міжгалузевих) і територіальних угод.

6. Міністерству соціальної політики і Державному комітету телебачення і радіомовлення забезпечити висвітлення у засобах масової інформації ходу переговорів щодо укладення Генеральної угоди та її виконання, а іншим центральним і місцевим органам виконавчої влади - щодо укладення галузевих (міжгалузевих) і територіальних угод та їх виконання.

{ Пункт 6 із змінами, внесеними згідно з Розпорядженням КМ N 1005-р ( 1005-2011-р ) від 12.10.2011 }

{ Пункт 7 втратив чинність на підставі Розпорядження КМ N 1956-р ( 1956-2010-р ) від 12.10.2010 }

8. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 14 листопада 2005 р. N 453 ( 453-2005-р ) "Про ведення колективних переговорів з укладення Генеральної, галузевих і регіональних угод".
