Кабінет Міністрів України; Постанова від 14.12.2011 № 1304

Про завершення проведення експерименту з упровадження методів непрямої оцінки доходів громадян для призначення соціальної допомоги

Стан: Чинний

Ідентифікатор: 1304-2011-п

Текст документа від 14.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 грудня 2011 р. N 1304 Київ

Про завершення проведення експерименту з упровадження

методів непрямої оцінки доходів громадян для призначення соціальної допомоги

Кабінет Міністрів України постановляє:

1. Прийняти пропозицію Міністерства соціальної політики щодо завершення проведення експерименту з упровадження методів непрямої оцінки доходів громадян для призначення соціальної допомоги у Луцькому районі Волинської області, Олександрійському районі Кіровоградської області, Ленінському та Кіровському районах м. Кіровограда і Корюківському районі Чернігівської області.

2. Міністерству соціальної політики поінформувати у тижневий строк Кабінет Міністрів України про результати проведення експерименту.

3. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України від 27 квітня 2011 р. N 448 ( 448-2011-п ) "Про проведення експерименту з упровадження методів непрямої оцінки доходів громадян для призначення соціальної допомоги" (Офіційний вісник України, 2011 р., N 32, ст. 1348) та від 14 вересня 2011 р. N 958 ( 958-2011-п ) "Про продовження проведення експерименту з упровадження методів непрямої оцінки доходів громадян для призначення соціальної допомоги" (Офіційний вісник України, 2011 р., N 71, ст. 2674).

Прем'єр-міністр України М.АЗАРОВ
