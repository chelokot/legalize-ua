Президент України; Указ від 07.09.2007 № 829/2007

Про зупинення дії постанови Кабінету Міністрів України від 4 квітня 2007 року N 611

Стан: Втратив чинність

Ідентифікатор: 829/2007

Текст документа від 07.09.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанови Кабінету Міністрів України від 4 квітня 2007 року N 611

{ Додатково див. Конституційне подання Президента ( n0022100-07 ) від 07.09.2007 }

Кабінетом Міністрів України 4 квітня 2007 року видано постанову N 611 ( 611-2007-п ) "Про затвердження Порядку проведення у 2007 році аукціонів з продажу спеціальних дозволів на користування надрами".

Цією постановою ( 611-2007-п ) Кабінет Міністрів України затвердив Порядок проведення у 2007 році аукціонів з продажу спеціальних дозволів на користування надрами (далі - Порядок), яким визначено процедуру продажу таких дозволів на аукціонах.

Відповідно до Порядку ( 611-2007-п ) аукціон проводиться з числа допущених до участі в ньому претендентів. Переможець аукціону (покупець, який у процесі проведення аукціону запропонував за дозвіл найвищу ціну) має здійснити протягом 30 календарних днів після його проведення розрахунки за придбаний на аукціоні дозвіл шляхом внесення коштів на спеціальний реєстраційний рахунок організатора аукціону (пункти 2, 17, 21 Порядку) ( 611-2007-п )

Разом із цим Порядок ( 611-2007-п ) встановлює, що в разі якщо переможець аукціону не внесе всієї належної до сплати суми в 30-денний строк, він втрачає право на отримання дозволу, а переможцем аукціону оголошується наступний покупець, який запропонував найбільшу ціну (пункт 23) ( 611-2007-п ).

Такий механізм створює можливість для зловживань, зокрема недоброчесної змови двох або більше покупців для придбання на аукціоні дозволу за значно меншою, ніж реальна вартість, ціною, не забезпечує реальної конкуренції покупців.

Відтак, зазначена постанова Кабінету Міністрів України ( 611-2007-п ) не відповідає статті 42 Конституції України ( 254к/96-ВР ), за якою держава забезпечує захист конкуренції, недобросовісна конкуренція не допускається.

Тому названа постанова суперечить також частині другій статті 8 Основного Закону ( 254к/96-ВР ) держави, за якою нормативно-правові акти приймаються на основі Конституції України ( 254к/96-ВР ) і повинні відповідати їй, нормам частини другої статті 19 та частини третьої статті 113 Конституції України ( 254к/96-ВР ), які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією України ( 254к/96-ВР ), діяти на підставі та у спосіб, що нею передбачені.

Ураховуючи наведене та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 4 квітня 2007 року N 611 ( 611-2007-п ) "Про затвердження Порядку проведення у 2007 році аукціонів з продажу спеціальних дозволів на користування надрами".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
