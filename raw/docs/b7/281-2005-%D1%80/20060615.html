Про підготовчі заходи щодо будівництва нових енергоблоків Хмельницької АЕС

Стан: Чинний

Текст документа від 15.06.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 21 липня 2005 р. N 281-р Київ

Про підготовчі заходи щодо будівництва нових енергоблоків Хмельницької АЕС

{ Із змінами, внесеними згідно з Розпорядженням КМ N 332-р ( 332-2006-р ) від 15.06.2006 }

1. Мінпаливенерго разом з державним підприємством "Національна атомна енергогенеруюча компанія "Енергоатом" забезпечити проведення обстеження об'єктів, споруд та обладнання енергоблоків N 3 і 4 Хмельницької АЕС та за результатами подати пропозиції щодо можливості використання майданчика Хмельницької АЕС для будівництва енергоблоків N 3 і 4, зокрема:

визначити критерії відбору проекту енергоблоків за типом реакторної установки та з їх урахуванням провести конкурсний відбір;

підготувати матеріали для проведення:

- державної екологічної експертизи і державної експертизи ядерної та радіаційної безпеки щодо цих проектів;

- консультацій із сусідніми країнами стосовно наслідків введення в експлуатацію енергоблоків;

- громадських слухань з питань спорудження енергоблоків з обгрунтуванням рівня їх безпеки та впливу на навколишнє природне середовище.

2. Хмельницькій облдержадміністрації організувати у 2007 році за участю органів місцевого самоврядування, на території яких розташована Хмельницька АЕС, громадські слухання та провести місцеве дорадче опитування (консультативний референдум) громадян України з питань спорудження енергоблоків N 3 та 4 Хмельницької АЕС. { Пункт 2 в редакції Розпорядження КМ N 332-р ( 332-2006-р ) від 15.06.2006 }

3. Мінпромполітики, Мінекономіки і Мінпаливенерго підготувати до кінця 2006 року матеріали з оцінкою можливостей вітчизняних підприємств щодо виготовлення систем та елементів для енергоблоків N 3 і 4 Хмельницької АЕС.
