Президент України; Указ від 21.07.2008 № 639/2008

Про зупинення дії постанови Кабінету Міністрів України від 17 квітня 2008 року N 394

Стан: Чинний

Ідентифікатор: 639/2008

Текст документа від 21.07.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про зупинення дії постанови Кабінету Міністрів України від 17 квітня 2008 року N 394

{ Додатково див. Конституційне подання Президента ( n0027100-08 ) від 21.07.2008 }

Кабінетом Міністрів України 17 квітня 2008 року з посиланням на пункти 1, 3, 6 і 9 статті 116 Конституції України ( 254к/96-ВР ), статті 124, 127 і 128, пункт 12 розділу X "Перехідні положення" Земельного кодексу України ( 2768-14 ), статтю 82 і підпункт 7 пункту 5 розділу III "Прикінцеві положення" Закону України "Про Державний бюджет України на 2008 рік та про внесення змін до деяких законодавчих актів України" ( 107-17 ) видано постанову N 394 ( 394-2008-п ), якою затверджено Порядок проведення у 2008 році земельних аукціонів ( 394-2008-п ) та надано доручення окремим центральним органам виконавчої влади вчинити відповідні дії для забезпечення проведення таких аукціонів.

Названим Порядком ( 394-2008-п ) визначено процедуру підготовки, організації та проведення у 2008 році земельних аукціонів для продажу земельних ділянок або надання права на їх оренду, крім земельних ділянок, на яких розташовані об'єкти, що підлягають приватизації, земельних ділянок приватної власності, а також земельних ділянок сільськогосподарського призначення.

Зазначену постанову ( 394-2008-п ) видано Кабінетом Міністрів України всупереч Конституції України ( 254к/96-ВР ).

За Конституцією України ( 254к/96-ВР ) визначення правового режиму власності віднесено до сфери регулювання виключно законами України (пункт 7 частини першої статті 92) ( 254к/96-ВР ), право власності на землю гарантується та набувається і реалізується виключно відповідно до закону (частина друга статті 14) ( 254к/96-ВР ), право приватної власності набувається в порядку, визначеному законом (частина друга статті 41) ( 254к/96-ВР ), кожний громадянин має право користуватися природними об'єктами права власності народу відповідно до закону (частина друга статті 13) ( 254к/96-ВР ), громадяни для задоволення своїх потреб можуть користуватися об'єктами права державної та комунальної власності відповідно до закону (частина третя статті 41) ( 254к/96-ВР ).

Земельним кодексом України ( 2768-14 ) визначено, що право власності на землю набувається та реалізується виключно на підставі Конституції України ( 254к/96-ВР ), названого Кодексу ( 2768-14 ), а також інших законів, що видаються відповідно до них (частина друга статті 78) ( 2768-14 ), продаж земельних ділянок державної та комунальної власності громадянам та юридичним особам здійснюється на конкурентних засадах шляхом проведення аукціону (земельних торгів) у порядку, встановленому законом (статті 127, 134, 135, 137) ( 2768-14 ). Земельним кодексом України ( 2768-14 ) та Законом України "Про оренду землі" ( 161-14 ) визначено, що набуття права оренди земельних ділянок, що перебувають у державній або комунальній власності, здійснюється на аукціонах.

Проте ні Конституція України ( 254к/96-ВР ), ні жоден із названих законів, ні закони, на які Кабінет Міністрів України послався у постанові ( 394-2008-п ), про яку йдеться, не передбачають визначення порядку проведення аукціону (земельних торгів) підзаконним актом, не наділяють Кабінет Міністрів України повноваженням щодо затвердження порядку проведення аукціонів із продажу земельних ділянок.

За Основним Законом ( 254к/96-ВР ) держави Україна є правовою державою (стаття 1) ( 254к/96-ВР ), в якій визнається і діє принцип верховенства права (стаття 8) ( 254к/96-ВР ). Згідно із закріпленими Конституцією України ( 254к/96-ВР ) основами правового порядку органи державної влади зобов'язані діяти лише на підставі, в межах повноважень та у спосіб, що передбачені Конституцією ( 254к/96-ВР ) та законами України (частина друга статті 19) ( 254к/96-ВР ); Кабінет Міністрів України здійснює повноваження, визначені Конституцією ( 254к/96-ВР ) і законами України (пункт 10 статті 116, частина друга статті 120) ( 254к/96-ВР ), і видає постанови і розпорядження в межах своєї компетенції (частина перша статті 117) ( 254к/96-ВР ).

Відтак, постанову від 17 квітня 2008 року N 394 ( 394-2008-п ) видано Кабінетом Міністрів України з перевищенням повноважень, визначених для нього Конституцією ( 254к/96-ВР ) та законами України, всупереч вищезазначеним нормам Конституції України ( 254к/96-ВР ).

Ураховуючи наведене та відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 17 квітня 2008 року N 394 ( 394-2008-п ) "Про затвердження Порядку проведення у 2008 році земельних аукціонів".

2. Визнати таким, що втратив чинність, Указ Президента України від 25 квітня 2008 року N 406 ( 406/2008 ) "Про зупинення дії положення постанови Кабінету Міністрів України від 17 квітня 2008 року N 394".

3. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО
