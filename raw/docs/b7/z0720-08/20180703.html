{ Наказ втратив чинність на підставі Наказу Фонду державного майна N 680 ( z0703-18 ) від 22.05.2018 }

Про внесення змін до наказу Фонду державного майна України від 01.10.97 N 1065 "Про затвердження Положення про план приватизації майна"

Відповідно до Закону України від 3 червня 2008 року N 309-VI ( 309-17 ) "Про внесення змін до деяких законодавчих актів України", з метою приведення у відповідність до чинного законодавства нормативно-правових актів Фонду державного майна України НАКАЗУЮ:

1. Унести до Положення про план приватизації державного майна, затвердженого наказом Фонду державного майна України від 01.10.97 N 1065 ( z0490-97 ) та зареєстрованого в Міністерстві юстиції України 17.10.97 за N 490/2294, такі зміни:

1.1. Пункт 1.3 доповнити новим абзацом такого змісту:

"центрального органу виконавчої влади з питань земельних ресурсів".

1.2. Пункт 4 додатків до Типового плану приватизації державного майна ( z0490-97 ) викласти в такій редакції:

"4. Акт оцінки вартості об'єкта приватизації, який складається відповідно до законодавства і затверджується органом приватизації, та технічний паспорт земельної ділянки державної власності, яка підлягає продажу державним органом приватизації".

2. Департаменту реформування власності та з питань трансферу технологій, інноваційної діяльності та інтелектуальної власності (Красовський В.А.) у встановленому порядку подати наказ на державну реєстрацію до Міністерства юстиції України.

3. Департаменту реформування власності та з питань трансферу технологій, інноваційної діяльності та інтелектуальної власності (Красовський В.А.) у десятиденний строк після державної реєстрації цього наказу забезпечити його публікацію у "Державному інформаційному бюлетені про приватизацію".

4. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Шмуляра О.В.
