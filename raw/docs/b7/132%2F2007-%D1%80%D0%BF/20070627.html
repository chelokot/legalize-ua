Президент України; Розпорядження від 27.06.2007 № 132/2007-рп

Про призначення довічних державних стипендій видатним діячам культури і мистецтва

Стан: Чинний

Ідентифікатор: 132/2007-рп

Текст документа від 27.06.2007:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

Про призначення довічних державних стипендій видатним діячам культури і мистецтва

1. Відповідно до Указу Президента України від 20 жовтня 1998 року N 1152 ( 1152/98 ) (зі змінами, внесеними Указами від 21 лютого 2000 року N 263 ( 263/2000 ), від 25 січня 2002 року N 71 ( 71/2002 ) та від 23 січня 2006 року N 58) ( 58/2006 ) призначити довічні державні стипендії видатним діячам культури і мистецтва, які досягли сімдесятирічного віку:

АНДРУСЕНКУ Миколі Івановичу - 1922 року народження, народному артистові України

АНТОНОВІЙ Ніні Василівні - 1935 року народження, заслуженій артистці України

БІЛАШ Ларисі Іванівні - 1935 року народження, народній артистці України

ВОДОВОЗОВУ Альберту Федоровичу - 1932 року народження, заслуженому діячеві мистецтв України

ВОРОНІНУ В'ячеславу Анатолійовичу - 1934 року народження, заслуженому артистові України

КАГАРЛИЦЬКОМУ Миколі Федосійовичу - 1937 року народження, заслуженому діячеві мистецтв України

ЛІОЗНОВУ Григорію Семеновичу - 1924 року народження, заслуженому працівникові культури України

РАШЕЄВУ Миколі Георгійовичу - 1935 року народження, заслуженому діячеві мистецтв України

ЮР'ЄВУ Флоріану Іллічу - 1929 року народження, заслуженому працівникові культури України.

2. З набранням чинності цим Розпорядженням особам, зазначеним у пункті 1 цього Розпорядження, яким стипендія вже призначена Президентом України на певний строк, у подальшому виплачується стипендія, передбачена цим Розпорядженням.

Президент України В.ЮЩЕНКО

м. Київ, 27 червня 2007 року N 132/2007-рп
