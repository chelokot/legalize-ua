Про приватизацію ВАТ "Укртелеком"

Стан: Втратив чинність

Текст документа від 15.03.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 16 листопада 2000 р. N 454-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 292 ( 292-2006-п ) від 15.03.2006 }

Про приватизацію ВАТ "Укртелеком"

1. Погодитися з пропозицією Фонду державного майна та Держкомзв'язку щодо проведення приватизації ВАТ "Укртелеком" у порядку, визначеному Законом України "Про особливості приватизації відкритого акціонерного товариства "Укртелеком" ( 1869-14 ).

2. Редакції газети "Урядовий кур'єр" опублікувати у 10-денний термін інформацію про приватизацію ВАТ "Укртелеком".

Перший віце-прем'єр-міністр України Ю.ЄХАНУРОВ
