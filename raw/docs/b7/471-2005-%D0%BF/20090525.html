КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 червня 2005 р. N 471 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }

Про внесення змін у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403

Кабінет Міністрів України постановляє:

Внести у додаток 1 до постанови Кабінету Міністрів України від 26 лютого 2000 р. N 403 ( 403-2000-п ) "Про затвердження граничної чисельності працівників апарату міністерств, інших центральних органів виконавчої влади і підпорядкованих їм територіальних органів та встановлення ліміту легкових автомобілів, що їх обслуговують" (Офіційний вісник України, 2000 р., N 9, ст. 339; 2001 р., N 20, ст. 851; 2003 р., N 4, ст. 111, N 52, ст. 2821) такі зміни:

у позиції "Міністерство праці та соціальної політики" цифри "387" замінити цифрами "436";

позицію "Державний комітет у справах ветеранів 49 3" виключити.
