Зареєстровано в Міністерстві юстиції України 1 жовтня 2008 р. за N 917/15608

Про внесення змін до наказу Мінприроди України від 12.10.2004 N 386

Відповідно до Положення про Міністерство охорони навколишнього природного середовища України, затвердженого постановою Кабінету Міністрів України від 02.11.2006 N 1524 ( 1524-2006-п ), та з метою приведення нормативно-правових актів Мінприроди у відповідність до чинного законодавства НАКАЗУЮ:

1. У пункті 1.1 глави 1 Інструкції про порядок придбання, зберігання, обліку, перевезення, використання та застосування вогнепальної зброї, бойових припасів до зброї, пристроїв вітчизняного виробництва для відстрілу патронів, споряджених гумовими чи аналогічними за своїми властивостями метальними снарядами несмертельної дії, та зазначених патронів, а також спеціальних засобів державними інспекторами з охорони навколишнього природного середовища органів, що входять до сфери управління Міністерства охорони навколишнього природного середовища України ( z1383-04 ), затвердженої наказом Мінприроди України від 12.10.2004 N 386 ( z1382-04 ) , зареєстрованої в Мін'юсті України 27.10.2004 за N 1383/9982, слова та цифри "наказів Мінекоресурсів України від 11.08.2000 N 108 ( z0602-00 ) "Про затвердження Положення про державне управління екології та природних ресурсів в областях, містах Києві та Севастополі", зареєстрованого в Міністерстві юстиції України 13.09.2000 за N 602/4823 (із змінами та доповненнями)" замінити словами та цифрами "Положення про Державну екологічну інспекцію в областях, містах Києві та Севастополі ( z0120-07 ), затвердженого наказом Мінприроди від 19.12.2006 N 548 ( z0119-07 ), зареєстрованого в Мін'юсті 13.02.2007 за N 120/13387, наказів Мінприроди від 06.12.2006 N 526 ( z0038-07 ) "Про затвердження Положення про Державну Азово-Чорноморську екологічну інспекцію", зареєстрованого в Мін'юсті 18.01.2007 за N 38/13305, від 06.12.2006 N 527 ( z0039-07 ) "Про затвердження Положення про Державну екологічну інспекцію Азовського моря", зареєстрованого в Мін'юсті 18.01.2007 за N 39/13306, від 06.12.2006 N 528 ( z0040-07 ) "Про затвердження Положення про Державну екологічну інспекцію з охорони довкілля Північно-Західного регіону Чорного моря", зареєстрованого в Мін'юсті 18.01.2007 за N 40/13307, та наказу".

2. Державній екологічній інспекції (Костров М.М.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції в установленому порядку.

3. Контроль за виконанням цього наказу покласти на заступника Міністра - Головного державного інспектора України з охорони навколишнього природного середовища Тригубенка С.М.

Міністр Г.Філіпчук
