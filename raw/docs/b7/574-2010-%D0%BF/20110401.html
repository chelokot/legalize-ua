ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 липня 2010 р. N 574

ПОРЯДОК використання коштів, передбачених у державному бюджеті ( 2154-17 ) для створення Національного культурно-мистецького та музейного комплексу "Мистецький арсенал"

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті ( 2154-17 ) Державному управлінню справами за програмою "Створення Національного культурно-мистецького та музейного комплексу "Мистецький арсенал" (далі - бюджетні кошти).

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

2. Головним розпорядником бюджетних коштів та відповідальним виконавцем бюджетної програми є Державне управління справами. { Абзац перший пункту 2 із змінами, внесеними згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

Одержувачем бюджетних коштів є державне підприємство "Національний культурно-мистецький та музейний комплекс "Мистецький арсенал" (далі - підприємство).

3. З метою збереження та реставрації пам'яток історії та архітектури, забезпечення створення і функціонування музейної складової підприємства бюджетні кошти спрямовуються на покриття його поточних витрат, не забезпечених власними доходами.

До поточних витрат включається:

оплата праці штатних працівників підприємства;

оплата службових відряджень таких працівників;

справляння податків, зборів (обов'язкових платежів), оплата послуг фінансових установ;

оплата транспортних послуг;

оплата послуг зв'язку;

придбання предметів, матеріалів, інвентарю;

ремонт і обслуговування обладнання, програмного забезпечення;

оплата послуг з охорони території підприємства, зокрема відеоспостереження;

оплата комунальних послуг та енергоносіїв;

оплата послуг з утримання комунікаційних систем підприємства у належному стані;

проведення археологічних та спелеологічних досліджень і робіт на території підприємства за переліком, визначеним разом з Інститутом археології Національної академії наук та затвердженим Державним управлінням справами;

{ Абзац виключено на підставі Постанови КМ N 297 ( 297-2011-п ) від 17.03.2011 }

оплата витрат, пов'язаних з розглядом судових справ (державне мито, судовий збір, витрати на інформаційно-технічне забезпечення тощо), нотаріальних послуг; { Пункт 3 доповнено абзацом згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

розроблення тематико-експозиційних планів виставок "Прадавнє мистецтво України" та "Історія Старого арсеналу"; { Пункт 3 доповнено абзацом згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

розроблення дизайн-проектів виставок актуального мистецтва. { Пункт 3 доповнено абзацом згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

4. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законом порядку.

Попередня оплата таких товарів, робіт і послуг проводиться з урахуванням положень бюджетного законодавства.

Не допускається спрямування бюджетних коштів на:

придбання товарів, робіт і послуг, які безпосередньо не пов'язані із здійсненням заходів;

оплату посередницьких послуг;

здійснення заходів, метою яких є отримання прибутку.

{ Пункт 4 в редакції Постанови КМ N 297 ( 297-2011-п ) від 17.03.2011 }

5. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого в установленому порядку.

{ Пункт 5 із змінами, внесеними згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

6. Обсяг бюджетних коштів, які надаються підприємству для покриття поточних витрат, не забезпечених власними доходами, не повинен перевищувати за підсумками року 90 відсотків фактичного обсягу валового доходу без урахування коштів, передбачених для утримання підрозділів служби замовника у складі підприємства.

Відкриття асигнувань здійснюється відповідно до затвердженого головним розпорядником бюджетних коштів плану асигнувань (за винятком надання кредитів з бюджету) із загального фонду державного бюджету. { Абзац другий пункту 6 із змінами, внесеними згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

Державне управління справами складає після закінчення кожного кварталу одночасно з фінансовою звітністю за встановленою формою розрахунок обсягу бюджетних коштів, які повинне одержати підприємство за показниками фінансової звітності відповідного періоду, виходячи з фактично одержаного валового доходу (без урахування коштів для утримання служби замовника у складі підприємства).

Розрахунок обсягу бюджетних коштів подається їх головному розпоряднику та Мінфіну разом з інформацією про залишки бюджетних асигнувань на реєстраційних рахунках підприємства на звітну дату.

У разі коли обсяг бюджетних коштів, які повинне одержати підприємство за розрахунками на звітну дату, менша, ніж одержані на таку дату асигнування загального фонду державного бюджету, головний розпорядник може прийняти такі рішення:

1) надання бюджетних коштів припиняється (якщо сума надлишково виділених бюджетних коштів перевищує 50 відсотків середньомісячного планового обсягу бюджетних коштів);

2) обсяг бюджетних коштів зменшується у поточному періоді (в разі потреби - у наступних періодах) на суму надлишково виділених бюджетних коштів.

Рішення про припинення або поновлення відкриття асигнувань приймається головним розпорядником бюджетних коштів на підставі розрахунку обсягу таких коштів за показниками фінансової звітності. { Абзац восьмий пункту 6 із змінами, внесеними згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

За результатами діяльності підприємства за 11 місяців поточного бюджетного року Державне управління справами до 10 грудня подає Мінфіну відповідний розрахунок обсягу бюджетних коштів, який повинен бути одержаний із загального фонду державного бюджету, та в разі потреби - пропозиції щодо перерахування в дохід державного бюджету надлишково одержаних асигнувань. { Абзац дев'ятий пункту 6 із змінами, внесеними згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

Підприємство перераховує зазначені кошти не пізніше ніж за 10 днів до закінчення року, що підтверджується органом Державної казначейської служби. { Абзац десятий пункту 6 із змінами, внесеними згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }

7. Відображення у первинному та бухгалтерському обліку інформації про отримані (створені) оборотні і необоротні активи, а також відкриття рахунків, реєстрація, облік зобов'язань в органах Державної казначейської служби та проведення операцій, пов'язаних з використанням бюджетних коштів, здійснюються у порядку, встановленому Державною казначейською службою.

{ Пункт 7 в редакції Постанови КМ N 297 ( 297-2011-п ) від 17.03.2011 }

8. Складення та подання фінансової і бюджетної звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним витрачанням здійснюються в установленому законодавством порядку.

{ Порядок доповнено пунктом 8 згідно з Постановою КМ N 297 ( 297-2011-п ) від 17.03.2011 }
