Текст документа від 05.06.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 грудня 2007 р. N 1375 Київ

Про затвердження переліків підприємств з усіма стадіями технологічного процесу з виготовлення нафтопродуктів, що мають право виробляти бензини моторні сумішеві із вмістом етил-трет-бутилового ефіру або з добавками на основі біоетанолу

{ Назва Постанови із змінами, внесеними згідно з Постановою КМ N 319 ( 319-2015-п ) від 20.05.2015 }

{ Із змінами, внесеними згідно з Постановою КМ N 319 ( 319-2015-п ) від 20.05.2015 }

Кабінет Міністрів України постановляє:

1. Затвердити переліки підприємств з усіма стадіями технологічного процесу з виготовлення нафтопродуктів, що мають право виробляти бензини моторні сумішеві марки А-92 Ек, А-95 Ек, А-98 Ек з добавками на основі біоетанолу, вміст якого в зазначених бензинах становить від 2 об'ємних відсотків, або із вмістом етил-трет-бутилового ефіру від 5 об'ємних відсотків (додаються). { Пункт 1 із змінами, внесеними згідно з Постановою КМ N 319 ( 319-2015-п ) від 20.05.2015 }

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 3 серпня 2005 р. N 705 ( 705-2005-п ) "Про затвердження переліків нафтопереробних підприємств, які мають усі стадії технологічного процесу з виготовлення нафтопродуктів, та державних спиртових заводів, що вироблятимуть високооктанові кисневмісні добавки до бензинів з обов'язковою їх денатурацією бензином" (Офіційний вісник України, 2005 р., N 31, ст. 1873).
