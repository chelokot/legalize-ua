Стан: Втратив чинність

Ідентифікатор: 434-2007-п

Текст документа від 08.06.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 березня 2007 р. N 434 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 398 ( 398-2010-п ) від 07.06.2010 }

Про внесення змін до пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88

Кабінет Міністрів України постановляє:

1. Внести до пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88 ( 88-2000-п ) "Питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2000 р., N 4, ст. 110; 2006 р., N 52, ст. 3498; 2007 р., N 12, ст. 414) такі зміни:

в абзаці першому цифри "970", "193" і "71" замінити відповідно цифрами "978", "205" і "83";

в абзаці другому цифри "1172" замінити цифрами "1192".

2. Визнати такими, що втратили чинність;

постанову Кабінету Міністрів України від 16 січня 2007 р. N 20 ( 20-2007-п ) "Про внесення змін до пункту 2 постанови Кабінету Міністрів України від 24 січня 2000 р. N 88" (Офіційний вісник України, 2007 р., N 3, ст. 101);

пункт 2 постанови Кабінету Міністрів України від 14 лютого 2007 р. N 188 ( 188-2007-п ) "Деякі питання Секретаріату Кабінету Міністрів України" (Офіційний вісник України, 2007 р., N 12, ст. 414).
