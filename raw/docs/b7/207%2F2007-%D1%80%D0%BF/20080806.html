{ Розпорядження втратило чинність на підставі Указу Президента N 693/2008 ( 693/2008 ) від 06.08.2008 }

Про внесення змін до Розпорядження Президента України від 21 травня 2007 року N 110

На часткову зміну Розпорядження Президента України від 21 травня 2007 року N 110 ( 110/2007-рп ) "Про заходи щодо реформування Державної кримінально-виконавчої служби України":

1. Увести до складу Комісії з розроблення проектів Концепції реформування Державної кримінально-виконавчої служби України та Комплексної цільової програми реформування Державної кримінально-виконавчої служби України (далі - Комісія) ПУКШИНА Ігоря Геляровича - заступника Глави Секретаріату Президента України, - призначивши його головою Комісії, та БЕЗКОРОВАЙНОГО Віктора Дмитровича - Керівника Головної служби з питань діяльності правоохоронних органів Секретаріату Президента України.

2. Вивести зі складу Комісії В. Бондаря, увільнивши його від виконання обов'язків голови Комісії, та В. Гелетея.

Президент України В.ЮЩЕНКО

м. Київ, 25 вересня 2007 року N 207/2007-рп
