Текст документа від 13.06.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 червня 2007 р. N 818 Київ

Про визнання такими, що втратили чинність, деяких актів Кабінету Міністрів України з питань колегії Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, акти Кабінету Міністрів України з питань колегії Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи згідно з переліком, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 19

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 13 червня 2007 р. N 818

ПЕРЕЛІК актів Кабінету Міністрів України з питань колегії Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, що втратили чинність

1. Постанова Кабінету Міністрів України від 15 січня 1997 р. N 15 ( 15-97-п ) "Про затвердження членів колегії Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи".

2. Постанова Кабінету Міністрів України від 19 червня 1998 р. N 932 ( 932-98-п ) "Про кількість заступників Міністра та колегію Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи".

3. Постанова Кабінету Міністрів України від 4 серпня 1999 р. N 1428 ( 1428-99-п ) "Про затвердження членом колегії Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи Кахути В.Ф.".

4. Постанова Кабінету Міністрів України від 28 жовтня 1999 р. N 2007 ( 2007-99-п ) "Про членів колегії Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи".

5. Постанова Кабінету Міністрів України від 11 липня 2000 р. N 1105 ( 1105-2000-п ) "Про членів колегії Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи".

6. Постанова Кабінету Міністрів України від 10 квітня 2002 р. N 481 ( 481-2002-п ) "Про колегію Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" (Офіційний вісник України, 2002 р., N 15, ст. 799).

7. Постанова Кабінету Міністрів України від 28 серпня 2002 р. N 1309 ( 1309-2002-п ) "Про колегію Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" (Офіційний вісник України, 2002 р., N 36, ст. 1705).

8. Постанова Кабінету Міністрів України від 16 вересня 2002 р. N 1389 ( 1389-2002-п ) "Про колегію Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи" (Офіційний вісник України, 2002 р., N 38, ст. 1785).

9. Розпорядження Кабінету Міністрів України від 12 липня 2003 р. N 404 ( 404-2003-р ) "Про членів колегії МНС".

10. Розпорядження Кабінету Міністрів України від 27 жовтня 2003 р. N 639 ( 639-2003-р ) "Про зміну складу колегії МНС".

11. Розпорядження Кабінету Міністрів України від 15 жовтня 2004 р. N 734 ( 734-2004-р ) "Про затвердження Ревака С.С. членом колегії МНС".
