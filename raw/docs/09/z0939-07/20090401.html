ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

27.07.2007 N 262

Зареєстровано в Міністерстві юстиції України 15 серпня 2007 р. за N 939/14206

{ Наказ фактично втратив чинність у зв'язку з втратою чинності Наказу Державного комітету статистики N 476 ( z1133-06 ) від 09.10.2006, до якого вносились зміни }

Про внесення змін до Інструкції щодо складання форм державних статистичних спостережень N 2-інвестиції "Звіт про капітальні інвестиції", N 1-інвестиції "Звіт про інвестиції в основний капітал (капітальні вкладення)"

Відповідно до статей 4, 14, 18 Закону України "Про державну статистику" ( 2614-12 ), ураховуючи положення статей 80, 81, 95 Цивільного кодексу України ( 435-15 ), частини восьмої статті 19 та статті 55 Господарського кодексу України ( 436-15 ), з метою подальшого вдосконалення державних статистичних спостережень зі статистики капітальних інвестицій НАКАЗУЮ:

1. Унести зміни до Інструкції щодо складання форм державних статистичних спостережень N 2-інвестиції "Звіт про капітальні інвестиції" та N 1-інвестиції "Звіт про інвестиції в основний капітал (капітальні вкладення)", затвердженої наказом Держкомстату України від 09.10.2006 N 476 ( z1133-06 ), зареєстрованої у Міністерстві юстиції України 23.10.2006 за N 1133/13007 (далі - Інструкція); а саме:

1.1. В абзаці першому розділу "Загальні положення" слова "затверджені наказом Державного комітету статистики України від 26.06.2006 N 279 "Про затвердження форм державних статистичних спостережень зі статистики будівництва та капітальних інвестицій" вилучити.

2. Зміни, унесені цим наказом, увести в дію з 1 лютого 2008 року.

3. Департаменту статистики виробництва (Овденко Л.М.) підготувати і передати адміністративно-господарському департаменту (Ісаєва Н.О.) оригінал Інструкції ( z1133-06 ) зі змінами, унесеними цим наказом, для виготовлення.

4. Адміністративно-господарському департаменту (Ісаєва Н.О.) забезпечити контроль за своєчасним виготовленням та доставкою Інструкції ( z1133-06 ) зі змінами, унесеними цим наказом, на адресу головних управлінь статистики в Автономній Республіці Крим, областях, місті Києві та Управління статистики у місті Севастополі.

5. Департаменту фінансового забезпечення, бухгалтерського обліку та звітності (Кучіна І.Ю.) забезпечити фінансування робіт з виготовлення та доставки Інструкції ( z1133-06 ) зі змінами, унесеними цим наказом.

6. Контроль за виконанням цього наказу покласти на першого заступника Голови Піщейка В.О.

Голова О.Г.Осауленко
