Стан: Втратив чинність

Ідентифікатор: 799/2007

Текст документа від 28.09.2007:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 841/2007 ( 841/2007 ) від 07.09.2007 }

Про зупинення дії постанови Кабінету Міністрів України від 27 червня 2007 року N 885

{ Додатково див. Конституційне подання Президента ( n0019100-07 ) від 30.08.2007 }

Кабінетом Міністрів України 27 червня 2007 року видано постанову N 885 ( 885-2007-п ) "Про деякі заходи, пов'язані з удосконаленням системи обліку громадян, що використовується для забезпечення виконання законів України".

Зазначеною постановою ( 885-2007-п ) Кабінетом Міністрів України з посиланням на пункти 2 і 7 статті 116 Конституції України ( 254к/96-ВР ), розділ VI та пункт 4 розділу VII Закону України "Про Державний реєстр виборців" ( 698-16 ), статтю 9 Закону України "Про державну статистику" ( 2614-12 ) дано низку доручень центральним органам виконавчої влади.

Зокрема, пунктом 1 цієї постанови ( 885-2007-п ) Міністерству внутрішніх справ України доручено:

провести вибіркові перевірки із залученням дільничних інспекторів міліції стану дотримання порядку виконання громадянами обов'язку з реєстрації місця проживання (перебування), у тому числі тими, що тимчасово виїжджають за межі України, прийняти за їх результатами відповідні рішення;

забезпечити узагальнення на загальнодержавному та регіональному рівні інформації про осіб, що проживають (перебувають) в Україні, а також тих, що виїхали за межі України, для надання її у разі потреби згідно із законом органам, утвореним відповідно до Законів України "Про вибори народних депутатів України" ( 1665-15 ) і "Про Державний реєстр виборців" ( 698-16 );

разом з Міністерством закордонних справ України і Міністерством транспорту та зв'язку України подати Адміністрації Державної прикордонної служби України інформацію стосовно громадян, включених до Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування, наявності у них документів на право виїзду з України та в'їзду в Україну, а також паспорта громадянина України; забезпечити постійну взаємодію з питань обміну інформацією стосовно осіб, що тимчасово виїжджають за межі України, затвердити у разі потреби спільні акти;

забезпечити у передбачених законом випадках подання інформації, необхідної для складення списків виборців у разі проведення виборів, формування та функціонування Державного реєстру виборців, Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування, створення належних умов для проведення державних статистичних спостережень щодо демографічної ситуації в Україні та її регіонах, забезпечення реалізації виборчих прав громадян.

Пунктом 2 постанови ( 885-2007-п ) Міністерству оборони України, іншим центральним органам виконавчої влади, які здійснюють керівництво військовими формуваннями, органам військового управління, військовим комісаріатам, керівникам (командирам) військових частин, закладів, установ та організацій Збройних Сил України, інших військових формувань, правоохоронним органам спеціального призначення та Державному департаменту України з питань виконання покарань доручено забезпечити, зокрема, подання у триденний строк за зверненням відповідних підрозділів Міністерства внутрішніх справ України інформації, необхідної для забезпечення виконання вимог Законів України "Про свободу пересування та вільний вибір місця проживання в Україні" ( 1382-15 ) і "Про Державний реєстр виборців" ( 698-16 ).

Таким чином, нормативно-правовим актом Кабінету Міністрів України відповідні відносини врегульовано у спосіб, що не передбачений розділом VI та пунктом 4 розділу VII Закону України "Про Державний реєстр виборців" ( 698-16 ).

Відповідно до розділу VI, пункту 4 розділу VII Закону України "Про Державний реєстр виборців" ( 698-16 ), з посиланням на які Уряд врегулював зазначені вище питання, Кабінет Міністрів України:

- протягом місяця з дня офіційного оприлюднення названого Закону ( 698-16 ) за погодженням з розпорядником Державного реєстру виборців затверджує Положення про орган (відділ) ведення Державного реєстру виборців та Порядок утворення органів (відділів) ведення Державного реєстру виборців, а також Положення про регіональний орган (відділ) адміністрування Державного реєстру виборців та Порядок утворення регіональних органів (відділів) адміністрування Державного реєстру виборців (частина друга статті 34 Закону) ( 698-16 );

- до набрання чинності названим Законом ( 698-16 ) за поданням розпорядника Державного реєстру виборців затверджує обсяги фінансування видатків на первинне наповнення та первинне уточнення Державного реєстру виборців (частина третя статті 34 Закону) ( 698-16 );

- встановлює порядок і строки формування інформаційно-телекомунікаційної системи Державного реєстру виборців та здійснення інших заходів з метою формування, налагодження та введення в дію цієї системи (стаття 35, пункт 4 розділу VII Закону) ( 698-16 ).

Згідно з пунктом 4 розділу VII Закону України "Про Державний реєстр виборців" ( 698-16 ) Кабінет Міністрів України також забезпечує утворення відповідних структурних підрозділів у районних, районних у містах Києві та Севастополі державних адміністраціях як органів ведення Державного реєстру виборців та в обласних, міських у містах Києві та Севастополі державних адміністраціях як органів адміністрування Державного реєстру виборців, а також утворення відповідного структурного підрозділу Міністерства закордонних справ України, який за частиною сьомою статті 34 названого Закону ( 698-16 ) визначає у своєму складі підрозділ, що здійснює повноваження органу ведення Державного реєстру виборців та органу адміністрування Державного реєстру виборців стосовно виборців, які проживають (перебувають) за межами України.

Первинне ж формування бази даних Державного реєстру виборців та уточнення персональних даних Державного реєстру виборців за Законом України "Про Державний реєстр виборців" ( 698-16 ) покладається на Центральну виборчу комісію, яку визначено розпорядником Державного реєстру виборців і яка набуває відповідних повноважень з дня офіційного оприлюднення названого Закону ( 698-16 ) (частина перша статті 34, статті 36, 37).

Не передбачено повноважень Кабінету Міністрів України з врегулювання правовідносин, про які йдеться в постанові, і в статті 9 Закону України "Про державну статистику" ( 2614-12 ), яка визначає проведення органами державної статистики за рішеннями Кабінету Міністрів України статистичних спостережень.

Відтак, видавши постанову від 27 червня 2007 року N 885 ( 885-2007-п ) "Про деякі заходи, пов'язані з удосконаленням системи обліку громадян, що використовується для забезпечення виконання законів України", Кабінет Міністрів України діяв усупереч Законам України "Про Державний реєстр виборців" ( 698-16 ) та "Про державну статистику" ( 2614-12 ) та у спосіб, що ними не передбачені, чим порушив положення частини другої статті 6, частини другої статті 19 та частини третьої статті 113 Основного Закону ( 254к/96-ВР ) держави, які зобов'язують Кабінет Міністрів України керуватися у своїй діяльності Конституцією ( 254к/96-ВР ) та законами України, на підставі та у спосіб, що ними передбачені.

Ураховуючи викладене, відповідно до пункту 15 частини першої статті 106 Конституції України ( 254к/96-ВР ) постановляю:

1. Зупинити дію постанови Кабінету Міністрів України від 27 червня 2007 року N 885 ( 885-2007-п ) "Про деякі заходи, пов'язані з удосконаленням системи обліку громадян, що використовується для забезпечення виконання законів України".

2. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 30 серпня 2007 року N 799/2007
