Текст документа від 23.03.2000:

ПОСТАНОВА ВЕРХОВНОЇ РАДИ УКРАЇНИ

( Постанова втратила чинність на підставі Постанови ВР N 1596-III ( 1596-14 ) від 23.03.2000, ВВР, 2000, N 24, ст.194 )

Про утворення Лічильної комісії Верховної Ради України

( Відомості Верховної Ради України (ВВР), 1998, N 49, ст.305 )

Верховна Рада України постановляє:

1. Утворити постійно діючу Лічильну комісію Верховної Ради України з числа народних депутатів України у такому складі:

Левченко Анатолій Іванович,

Мішура Валерій Дмитрович,

Хмельовий Анатолій Петрович,

Стрижко Леонід Петрович,

Чичканов Сергій Владленович,

Штепа Наталія Петрівна,

Кириленко Вячеслав Анатолійович,

Манчуленко Георгій Манолійович,

Дроботов Анатолій Іванович,

Ніколаєнко Станіслав Миколайович,

Павленко Сергій Григорович,

Кононенко Юрій Савич,

Фурдичко Орест Іванович,

Альохін Володимир Ілліч,

Трофименко Лариса Сергіївна,

Малолітко Іван Федорович,

Заєць Володимир Володимирович,

Шуфрич Нестор Іванович,

Чаговець Василь Миколайович,

Подгорний Сергій Петрович,

Кафарський Володимир Іванович.

2. Відповідно до вимог статті 2.2.9 Регламенту Верховної Ради України ( 129а/94-ВР ) дозволити головуючому на засіданнях Верховної Ради України, у разі необхідності, давати доручення зазначеній Лічильній комісії.
