Питання Державної служби кінематографії

Стан: Чинний

Ідентифікатор: 251-2006-п

Текст документа від 18.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 березня 2006 р. N 251 Київ

Питання Державної служби кінематографії

{ Із змінами, внесеними згідно з Постановою КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність одночасно з набранням чинності Указом Президента ( 404/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

2. Внести зміни до Положення про державне посвідчення на право розповсюдження і демонстрування фільмів, затвердженого постановою Кабінету Міністрів України від 17 серпня 1998 р. N 1315 ( 1315-98-п ) (Офіційний вісник України, 1998 р., N 33, ст. 1253; 2001 р., N 13, ст. 554; 2004 р., N 42, ст. 2769; 2006 р., N 3, ст. 89), і Положення про Державний реєстр виробників, розповсюджувачів і демонстраторів фільмів, затвердженого постановою Кабінету Міністрів України від 14 січня 2004 р. N 27 ( 27-2004-п ) (Офіційний вісник України, 2004 р., N 2, ст. 51), що додаються.

3. Міністерству культури і туризму привести власні нормативно-правові акти у відповідність із цією постановою.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 28

{ Положення про Державну службу кінематографії втратило чинність одночасно з набранням чинності Указом Президента ( 404/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 березня 2006 р. N 251

ЗМІНИ, що вносяться до Положення про державне посвідчення на право розповсюдження і демонстрування фільмів ( 1315-98-п ) і до Положення про Державний реєстр виробників, розповсюджувачів і демонстраторів фільмів ( 27-2004-п )

1. У Положенні про державне посвідчення на право розповсюдження і демонстрування фільмів ( 1315-98-п ):

у тексті Положення слово "МКТ" замінити словом "Держкіно";

в абзаці першому пункту 9 слова "заступник Міністра культури і туризму" замінити словами "голова Держкіно";

у тексті додатка 1 до Положення слова "Міністерство культури і туризму" в усіх відмінках замінити словами "Державна служба кінематографії" у відповідному відмінку.

2. У Положенні про Державний реєстр виробників, розповсюджувачів і демонстраторів фільмів ( 27-2004-п ):

у тексті Положення слово "Мінкультури" замінити словом "Держкіно";

у додатку 1 до Положення слова "Міністерство культури і мистецтв України" замінити словами "Державна служба кінематографії".
