Про внесення змін в додаток до розпорядження Кабінету Міністрів України від 28 жовтня 1997 р. N 611

Стан: Втратив чинність

Ідентифікатор: 359-99-р

Текст документа від 08.08.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 квітня 1999 р. N 359-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 785-р ( 785-99-р ) від 08.08.99 )

1. Внести зміни в додаток до розпорядження Кабінету Міністрів України від 28 жовтня 1997 р. N 611 ( 611-97-р ) про закріплення регіонів України за керівниками міністерств, інших центральних органів виконавчої влади, виклавши його у редакції згідно з додатком.

2. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 27 серпня 1998 р. N 705 ( 705-98-р ).
