УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 208/2005 ( 208/2005 ) від 08.02.2005 )

Про внесення змін до складу Ради національної безпеки і оборони України

Увести до складу Ради національної безпеки і оборони України, затвердженого Указом Президента України від 7 серпня 2001 року N 605 ( 605/2001 ) (зі змінами, внесеними Указами від 27 грудня 2001 року N 1277 ( 1277/2001 ), від 22 травня 2002 року N 481 ( 481/2002 ), від 15 червня 2002 року N 557 ( 557/2002 ) та від 20 червня 2002 року N 574 ( 574/2002 ), ЗАТИНАЙКА Олександра Івановича - начальника Генерального штабу Збройних Сил України, вивівши зі складу цієї Ради Шуляка П.І.

Президент України Л.КУЧМА

м. Київ, 7 вересня 2002 року N 807/2002
