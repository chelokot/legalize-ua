КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 березня 2006 р. N 364 Київ

Про затвердження Порядку використання коштів державного бюджету, що виділяються для виконання заходів щодо реалізації Національної програми сприяння розвитку малого підприємництва в Україні на 2006 рік

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Затвердити Порядок використання коштів державного бюджету ( 3235-15 ), що виділяються для виконання заходів ( 81-2006-р ) щодо реалізації Національної програми сприяння розвитку малого підприємництва в Україні ( 2157-14 ) на 2006 рік, що додається.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 25

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 25 березня 2006 р. N 364

ПОРЯДОК використання коштів державного бюджету, що виділяються для виконання заходів ( 81-2006-р ) щодо реалізації Національної програми сприяння розвитку малого підприємництва в Україні ( 2157-14 ) на 2006 рік

1. Цей Порядок визначає механізм використання коштів, передбачених Держпідприємництву у державному бюджеті ( 3235-15 ) за програмою 8681030 "Заходи по реалізації Національної програми сприяння розвитку малого підприємництва в Україні у 2006 році" (далі - бюджетні кошти).

2. Розподіл бюджетних коштів здійснює Держпідприємництво. Зазначені кошти використовуються Держпідприємництвом та за його розпорядженням Українським фондом підтримки підприємництва для виконання заходів, затверджених розпорядженням Кабінету Міністрів України від 15 лютого 2006 р. N 81 ( 81-2006-п ).

Перерахування бюджетних коштів здійснюється відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

3. Бюджетні кошти спрямовуються на:

впровадження освітньої програми з питань підприємницької діяльності;

проведення конференцій, семінарів, засідань за круглим столом, форумів, міжнародних зустрічей, відзначення Дня підприємця із залученням суб'єктів малого підприємництва;

створення і сертифікацію відповідно до національних або міжнародних стандартів систем управління якістю та екологічного управління;

розвиток міжнародного співробітництва у сфері малого та середнього підприємництва;

стимулювання розвитку малого підприємництва в сільській місцевості.

4. Складання і подання фінансової звітності про використання бюджетних коштів здійснюється в установленому законодавством порядку.
