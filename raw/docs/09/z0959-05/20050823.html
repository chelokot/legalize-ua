Відповідно до Закону України "Про засади державної регуляторної політики у сфері господарської діяльності" ( 1160-15 ) та Указу Президента України від 1 червня 2005 року N 901 ( 901/2005 ) "Про деякі заходи щодо забезпечення здійснення державної регуляторної політики" НАКАЗУЮ:

1. Вважати такими, що втратили чинність, такі накази:

наказ Мінрибгоспу України від 01.04.96 N 51 ( z0149-96 ) "Про встановлення весняно-літньої заборони на лов риби в 1996 році у водоймах України", зареєстрований в Міністерстві юстиції України 01.04.96 за N 149/1174 (із змінами);

наказ Мінрибгоспу України від 14.03.97 N 39 ( z0098-97 ) "Про регулювання вилову раків у 1997 році", зареєстрований в Міністерстві юстиції України 27.03.97 за N 98/1902;

наказ Держкомрибгоспу України від 27.02.98 N 28 ( z0284-98 ) "Про порядок вилучення, обліку, зберігання, здачі, реалізації та звітності про обсяги вилову водних живих ресурсів", зареєстрований в Міністерстві юстиції України 30.04.98 за N 284/2724 (із змінами);

наказ Держкомрибгоспу України від 13.03.98 N 37 ( z0185-98 ) "Про встановлення весняно-літньої заборони на лов риби, інших водних живих ресурсів у рибогосподарських водних об'єктах України в 1998 році", зареєстрований в Міністерстві юстиції України 20.03.98 за N 185/2625;

наказ Держкомрибгоспу України від 21.09.98 N 126 ( z0735-98 ) "Про затвердження Інструкції про порядок проведення робіт з відтворення водних живих ресурсів", зареєстрований в Міністерстві юстиції України 19.11.98 за N 735/3175;

наказ Держкомрибгоспу України від 18.12.98 N 168 ( z0835-98 ) "Про затвердження режимів рибальства в 1999 році", зареєстрований в Міністерстві юстиції України 29.12.98 за N 835/3275;
