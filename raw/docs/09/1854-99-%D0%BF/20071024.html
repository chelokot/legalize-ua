Про голову української частини Міжурядової українсько-ізраїльської комісії з питань військово-технічного співробітництва

Стан: Втратив чинність

Ідентифікатор: 1854-99-п

Текст документа від 24.10.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 жовтня 1999 р. N 1854 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову української частини Міжурядової українсько-ізраїльської комісії з питань військово-технічного співробітництва

Кабінет Міністрів України постановляє:

Затвердити першого заступника Міністра промислової політики Падалка Віктора Григоровича головою української частини Міжурядової українсько-ізраїльської комісії з питань військово-технічного співробітництва.
