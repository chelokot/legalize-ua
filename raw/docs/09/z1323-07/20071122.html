22.11.2007 N 353

Зареєстровано в Міністерстві юстиції України 28 листопада 2007 р. за N 1323/14590

Про визнання наказу Управління державної охорони України від 28.02.2004 N 23 таким, що втратив чинність

На виконання пункту 2 Указу Президента України від 19 жовтня 2007 року N 982 ( 982/2007 ) "Про Положення про проходження військової служби за контрактом військовослужбовцями Управління державної охорони України" та у зв'язку із затвердженням Положення про проходження військової служби за контрактом військовослужбовцями Управління державної охорони України НАКАЗУЮ:

1. Уважати таким, що втратив чинність, наказ Управління державної охорони України від 28.02.2004 N 23 ( z0335-04 ) "Про затвердження Інструкції про проходження військової служби в Управлінні державної охорони України", зареєстрований у Міністерстві юстиції України 17 березня 2004 року за N 335/8934.

2. З наказом ознайомити особовий склад Управління державної охорони України в частині, що його стосується.

Начальник Управління генерал-лейтенант В.Гелетей
