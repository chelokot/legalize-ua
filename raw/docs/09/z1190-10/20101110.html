Реєстрація: Мін'юст України від 29.11.2010 № 1190/18485

Стан: Чинний

Ідентифікатор: z1190-10

Текст документа від 10.11.2010:

ДЕРЖАВНИЙ КОМІТЕТ УКРАЇНИ ІЗ ЗЕМЕЛЬНИХ РЕСУРСІВ

НАКАЗ

10.11.2010 N 794

Зареєстровано в Міністерстві юстиції України 29 листопада 2010 р. за N 1190/18485

Про внесення змін до наказу Держкомзему від 28.11.2003 N 295 "Про затвердження Порядку ведення журналу авторського нагляду за виконанням проекту землеустрою"

Відповідно до статті 64 Закону України "Про землеустрій" ( 858-15 ), статей 6, 9 Закону України "Про ліцензування певних видів господарської діяльності" ( 1775-14 ), постанови Кабінету Міністрів України від 14.11.2000 N 1698 ( 1698-2000-п ) "Про затвердження переліку органів ліцензування" НАКАЗУЮ:

1. Затвердити Зміни до Порядку ведення журналу авторського нагляду за виконанням проекту землеустрою, затвердженого наказом Держкомзему від 28.11.2003 N 295 ( z1162-03 ), зареєстрованого в Міністерстві юстиції України 16.12.2003 за N 1162/8483 (додаються).

2. Юридичному департаменту (Яроцька Е.М.) у встановленому порядку забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Цей наказ набирає чинності з дня його офіційного опублікування.

4. Контроль за виконанням цього наказу залишаю за собою.

Голова І.Ю.Лисенко

ЗАТВЕРДЖЕНО Наказ Держкомзему 10.11.2010 N 794

Зареєстровано в Міністерстві юстиції України 29 листопада 2010 р. за N 1190/18485

ЗМІНИ до Порядку ведення журналу авторського нагляду за виконанням проекту землеустрою ( z1162-03 )

Абзац другий пункту 1 Порядку викласти в такій редакції:

"Цей Порядок обов'язковий для всіх суб'єктів господарювання, які провадять господарську діяльність щодо проведення робіт із землеустрою, землеоціночних робіт відповідно до Ліцензійних умов провадження господарської діяльності щодо проведення робіт із землеустрою, землеоціночних робіт, затверджених наказом Держкомзему від 05.08.2009 N 423 ( z0821-09 ), зареєстрованих в Міністерстві юстиції України 31.08.2009 за N 821/16837".

Директор Юридичного департаменту Е.М.Яроцька
