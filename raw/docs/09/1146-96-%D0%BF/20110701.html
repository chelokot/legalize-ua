КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 вересня 1996 р. N 1146 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 667 ( 667-2011-п ) від 22.06.2011 }

Про надання медичної допомоги іноземним громадянам

( Із змінами, внесеними згідно з Постановою КМ N 79 ( 79-97-п ) від 28.01.97 )

Кабінет Міністрів України постановляє:

1. Установити, що з 1 жовтня 1996 р. надання медичної допомоги іноземним громадянам, крім тих, які працюють у посольствах та консульствах іноземних держав, здійснюється за плату, якщо інше не передбачено законодавством.

( Пункт 2 втратив чинність на підставі Постанови КМ N 79 ( 79-97-п ) від 28.01.97 )
