{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

Про внесення змін до розпорядження Кабінету Міністрів України від 26 липня 1999 р. N 733

Внести до розпорядження Кабінету Міністрів України від 26 липня 1999 р. N 733 ( 733-99-р ) (Офіційний вісник України, 1999 р., N 30, ст. 1551) такі зміни:

1) в абзаці першому слова "із Державних премій" замінити словами "з Національної премії";

2) в абзаці другому слова "вченого секретаря" замінити словами "керівника Секретаріату";

3) абзац третій викласти у такій редакції:

"четверта категорія - завідувач сектору".

Прем'єр-міністр України Ю.ЄХАНУРОВ
