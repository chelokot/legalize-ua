Про збільшення розміру плати за звання дійсного члена та члена-кореспондента Національної академії наук

Текст документа від 01.01.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 липня 1998 р. N 1105 Київ

( Постанова втратила чинність на підставі Постанови КМ N 735 ( 735-2001-п ) від 27.06.2001 )

Про збільшення розміру плати за звання дійсного члена та члена-кореспондента Національної академії наук

Відповідно до статті 3 Указу Президента України від 20 березня 1998 р. N 207 ( 207/98 ) "Про відзначення 80-річчя Національної академії наук України" Кабінет Міністрів України постановляє:

Збільшити плату за звання дійсного члена та члена-кореспондента Національної академії наук, встановивши її у розмірі для дійсних членів - 400 гривень, для членів-кореспондентів - 270 гривень щомісяця.
