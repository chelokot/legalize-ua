МІНІСТЕРСТВО ЮСТИЦІЇ УКРАЇНИ

НАКАЗ

18.05.2006 N 44/5

Зареєстровано в Міністерстві юстиції України 18 травня 2006 р. за N 579/12453

{ Наказ втратив чинність на підставі Наказу Міністерства юстиції N 2710/5 ( z1620-15 ) від 22.12.2015 }

Про внесення змін до Положення про умови і порядок проведення тендерів (конкурсів) з визначення спеціалізованих організацій для реалізації арештованого державними виконавцями майна

Відповідно до Законів України "Про державну виконавчу службу" ( 202/98-ВР ) та "Про виконавче провадження" ( 606-14 ) і з метою удосконалення порядку проведення тендерів (конкурсів) з визначення спеціалізованих організацій для реалізації арештованого майна НАКАЗУЮ:

1. Пункт 2.1 Положення про умови і порядок проведення тендерів (конкурсів) з визначення спеціалізованих організацій для реалізації арештованого державними виконавцями майна, затвердженого наказом Міністерства юстиції України від 11 листопада 2003 р. N 136/5 ( z1036-03 ), зареєстрованого в Міністерстві юстиції України 11 листопада 2003 р. за N 1036/8357 (із змінами і доповненнями), викласти в новій редакції:

"2.1. Для організації і проведення тендера (конкурсу) Міністерством юстиції України утворюється тендерна (конкурсна) комісія (далі - комісія) у складі голови комісії - першого заступника Міністра юстиції, заступника голови комісії - заступника Міністра юстиції, секретаря та 13 членів комісії: першого заступника директора Департаменту державної виконавчої служби, радника Міністра юстиції, представника Міністерства фінансів, представника Міністерства економіки, представника Міністерства внутрішніх справ, представника Державної податкової адміністрації, представника Державної митної служби, представника Державного казначейства, представника Служби безпеки, представника Фонду державного майна, представника Антимонопольного комітету, представника Генеральної прокуратури та представника Головного контрольно-ревізійного управління".

2. Першому заступнику директора Департаменту державної виконавчої служби Б.Я.Бачуку:

2.1. Забезпечити подання на державну реєстрацію наказу відповідно до Указу Президента України від 3 жовтня 1992 р. N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами і доповненнями).

2.2. Довести цей наказ до відома начальників державної виконавчої служби Автономної Республіки Крим, областей, міст Києва і Севастополя.

3. Контроль за виконанням цього наказу покласти на першого заступника Міністра юстиції П.М.Крупка.

Міністр Сергій Головатий
