Кабінет Міністрів України; Постанова від 09.06.2006 № 816

Про доповнення пункту 7 Порядку випуску, обігу та погашення векселів, які видаються на суму податку на додану вартість при імпорті товарів на митну територію України

Стан: Втратив чинність

Ідентифікатор: 816-2006-п

Текст документа від 12.01.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 9 червня 2006 р. N 816 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1236 ( 1236-2010-п ) від 27.12.2010 }

Про доповнення пункту 7 Порядку випуску, обігу та погашення векселів, які видаються на суму податку на додану вартість при імпорті товарів на митну територію України

Кабінет Міністрів України постановляє:

1. Доповнити пункт 7 Порядку випуску, обігу та погашення векселів, які видаються на суму податку на додану вартість при імпорті товарів на митну територію України, затвердженого постановою Кабінету Міністрів України від 1 жовтня 1997 р. N 1104 ( 1104-97-п ) (Офіційний вісник України, 1997 р., число 41, с. 26; 1998 р., N 28, ст. 1050, N 34, ст. 1277; 1999 р" N 27, ст. 1330; 2000 р., N 47, ст. 2040; 2001 р., N 43, ст. 1928; 2005 р., N 22, ст. 1212, N 51, ст. 3193; 2006 р., N 16, ст. 1192), абзацом такого змісту:

"Якщо митна вартість однієї партії товарів перевищує 80 млн. гривень, на повну суму податкового зобов'язання, нараховану за однією вантажною митною декларацією, може надаватися кілька податкових векселів".

2. Ця постанова набирає чинності з дня опублікування.
