КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 квітня 2008 р. N 419 Київ

Про затвердження складу наглядових рад національних історико-культурних заповідників

Кабінет Міністрів України постановляє:

1. На часткову зміну постанови Кабінету Міністрів України від 2 серпня 1996 р. N 913 ( 913-96-п ) затвердити склад наглядових рад національних історико-культурних заповідників, що додається.

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 11 липня 2002 р. N 374 ( 374-2002-р ) "Про затвердження складу наглядової ради Національного історико-археологічного заповідника "Ольвія";

розпорядження Кабінету Міністрів України від 26 грудня 2003 р. N 801 ( 801-2003-р ) "Про затвердження нового складу наглядової ради історико-археологічного заповідника "Ольвія";

постанову Кабінету Міністрів України від 1 серпня 2007 р. N 986 ( 986-2007-п ) "Про затвердження складу наглядових рад національних історико-культурних заповідників".
