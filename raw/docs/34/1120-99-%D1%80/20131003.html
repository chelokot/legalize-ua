Кабінет Міністрів України; Розпорядження від 22.10.1999 № 1120-р

Про віднесення посад працівників секретаріату Центральної виборчої комісії до категорій посад державних службовців

Стан: Втратив чинність

Ідентифікатор: 1120-99-р

Текст документа від 03.10.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 жовтня 1999 р. N 1120-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 703 ( 703-2013-п ) від 14.08.2013 }

1. Відповідно до статті 25 Закону України "Про державну службу" ( 3723-12 ) віднести посади працівників секретаріату Центральної виборчої комісії до таких категорій посад державних службовців:

перша категорія - посада керівника секретаріату Центральної виборчої комісії;

друга категорія - посада заступника керівника секретаріату Центральної виборчої комісії.

2. В абзаці третьому розпорядження Кабінету Міністрів України від 14 лютого 1998 р. N 75 ( 75-98-р ) (Офіційний вісник України, 1998 р., N 7, ст. 273) виключити слова "керівника секретаріату Центральної виборчої комісії".
