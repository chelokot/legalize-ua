Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для виконання Державної програми розвитку Національної депозитарної системи України

Стан: Чинний

Ідентифікатор: 455-2006-п

Текст документа від 20.12.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 5 квітня 2006 р. N 455 Київ

Про порядок використання у 2006 році коштів, передбачених у державному бюджеті для виконання Державної програми розвитку Національної депозитарної системи України

{ Із змінами, внесеними згідно з Постановою КМ N 1762 ( 1762-2006-п ) від 20.12.2006 }

Відповідно до статті 27 Закону України "Про Державний бюджет України на 2006 рік" ( 3235-15 ) Кабінет Міністрів України постановляє:

Установити, що у 2006 році кошти, передбачені у державному бюджеті ( 3235-15 ) для виконання Державної програми розвитку Національної депозитарної системи України, використовуються за напрямами, визначеними постановою Кабінету Міністрів України від 14 вересня 2005 р. N 907 ( 907-2005-п ) "Про порядок використання коштів, передбачених у державному бюджеті для виконання Державної програми розвитку Національної депозитарної системи України" (Офіційний вісник України, 2005 р., N 37, ст. 2302), а також на:

збільшення статутного капіталу Національного депозитарію. З цією метою Державне казначейство перераховує на реєстраційний рахунок Міністерства фінансів кошти в сумі 21 500 000 гривень для їх перерахування Міністерством платіжним дорученням на рахунок Національного депозитарію згідно з розписом видатків державного бюджету ( 3235-15 ). { Абзац другий постановляючої частини в редакції Постанови КМ N 1762 ( 1762-2006-п ) від 20.12.2006 }
