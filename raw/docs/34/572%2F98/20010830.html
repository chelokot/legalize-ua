Президент України; Указ від 30.05.1998 № 572/98

Про мережу та кількісний склад військових судів України

Стан: Втратив чинність

Ідентифікатор: 572/98

Текст документа від 30.08.2001:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про мережу та кількісний склад військових судів України

( Із змінами, внесеними згідно з Указом Президента N 769/2001 ( 769/2001 ) від 30.08.2001 )

Відповідно до пункту 23 статті 106 та частини першої статті 125 Конституції України ( 254к/96-ВР ) постановляю:

1. Утворити військові суди Луганського і Полтавського гарнізонів у складі трьох суддів кожний.

2. Перемістити військовий суд Калинівського гарнізону в м. Чернівці, перейменувавши його у військовий суд Чернівецького гарнізону.

( Стаття 3 втратила чинність на підставі Указу Президента N 769/2001 ( 769/2001 ) від 30.08.2001 )

4. Міністерству юстиції України разом з Верховним Судом України проаналізувати протягом трьох місяців роботу військових судів за 1997-1998 роки і внести пропозиції щодо зменшення їх кількості та чисельності працівників виходячи з реальних обсягів судової роботи і чисельності військовослужбовців військових формувань, дислокованих на території, яку обслуговують відповідні військові суди.

5. Цей Указ набирає чинності з 1 червня 1998 року.

Президент України Л.КУЧМА

м. Київ, 30 травня 1998 року N 572/98

( Мережа та кількісний склад військових судів України втратили чинність на підставі Указу Президента N 769/2001 ( 769/2001 ) від 30.08.2001 )
