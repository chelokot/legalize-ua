Про забезпечення виконання санкцій Ради Безпеки ООН щодо Руанди

Стан: Втратив чинність

Ідентифікатор: 1904-2000-п

Текст документа від 17.10.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 грудня 2000 р. N 1904 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 888 ( 888-2008-п ) від 01.10.2008 }

Про забезпечення виконання санкцій Ради Безпеки ООН щодо Руанди

{ Із змінами, внесеними згідно з Постановою КМ N 842 ( 842-2007-п ) від 20.06.2007 }

Кабінет Міністрів України постановляє:

1. Міністерствам, іншим центральним органам виконавчої влади, Раді міністрів Автономної Республіки Крим, обласним, Київській та Севастопольській міським державним адміністраціям, підприємствам, установам та організаціям незалежно від форми власності:

забезпечити в межах своєї компетенції виконання вимог резолюцій Ради Безпеки ООН від 17 травня 1994 р. N 918 ( 622-94-п ), від 9 червня 1995 р. N 997 та від 16 серпня 1995 р. N 1011 і вжити необхідних заходів для зведення до мінімуму можливих у зв'язку з цим втрат України;

надавати на вимогу Міністерства закордонних справ необхідну інформацію про стан виконання зазначених резолюцій.

2. Міністерству внутрішніх справ, Міністерству економіки, Міністерству оборони, Міністерству транспорту та зв'язку, Міністерству промислової політики, Адміністрації Державної прикордонної служби, Державній митній службі, Державній компанії з експорту та імпорту продукції і послуг військового та спеціального призначення "Укрспецекспорт" за участю Служби безпеки та Служби зовнішньої розвідки: { Абзац перший пункту 2 в редакції Постанови КМ N 842 ( 842-2007-п ) від 20.06.2007 }

забезпечити дотримання вимоги щодо запобігання продажу чи поставці фізичними та юридичними особами України або з території України чи з використанням морських і повітряних суден під прапором України озброєння, військових матеріалів усіх видів, у тому числі зброї, боєприпасів, військово-транспортних засобів, військової техніки, спорядження для воєнізованої поліції та запасних частин, зазначених у пунктах ML1 - ML15, ML17, ML19 - ML20 додатка до Порядку здійснення державного контролю за міжнародними передачами товарів військового призначення, затвердженого постановою Кабінету Міністрів України від 20 листопада 2003 р. N 1807 ( 1807-2003-п ) (Офіційний вісник України, 2003 р., N 48, ст. 2506; 2007 р., N 22, ст. 891), в Руанду або особам в сусідніх з Руандою державах, якщо такий продаж чи поставка призначені для використання цих видів озброєння чи військових матеріалів у Руанді, крім використання їх Урядом Руанди. { Абзац другий пункту 2 із змінами, внесеними згідно з Постановою КМ N 842 ( 842-2007-п ) від 20.06.2007 }

{ Абзац третій пункту 2 виключено на підставі Постанови КМ N 842 ( 842-2007-п ) від 20.06.2007 }

3. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 6 вересня 1994 р. N 622 ( 622-94-п ) "Про виконання санкцій Ради Безпеки ООН щодо Руанди".
