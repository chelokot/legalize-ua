КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 8 лютого 2006 р. N 66-р Київ

Про затвердження оновленого складу Української частини комісій з військово-технічного співробітництва

{ Із змінами, внесеними згідно з Розпорядженням КМ N 691-р ( 691-2008-р ) від 07.05.2008 }

Затвердити згідно з додатками 1-5 оновлений склад Української частини Міждержавної Українсько-французької комісії в галузі озброєння і військової техніки, міжурядових Українсько-Південно-Африканської комісії з військово-технічного співробітництва, українсько-німецької комісії з питань військово-технічного співробітництва, українсько-в'єтнамської та українсько-китайської ( 142-2003-р ) координаційних комісій з питань військово-технічного співробітництва.

Дозволити голові комісій вносити у разі потреби зміни до їх складу.
