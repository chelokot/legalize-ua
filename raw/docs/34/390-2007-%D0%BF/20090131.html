{ Із змінами, внесеними згідно з Постановою КМ N 388 ( 388-2008-п ) від 17.04.2008 }

{ Установити, що використання у 2008 році коштів, передбачених у державному бюджеті ( 107-17 ) для виконання природоохоронних заходів з формування національної екологічної мережі, здійснюється відповідно до Порядку, затвердженого цією Постановою, згідно з Постановою КМ N 388 ( 388-2008-п ) від 17.04.2008 }

{ Дію Постанови продовжено на 2009 рік з урахуванням положень Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) та особливостей, викладених в Постанові КМ N 32 ( 32-2009-п ) від 14.01.2009 }

Кабінет Міністрів України постановляє:

Затвердити Порядок використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для виконання природоохоронних заходів з формування національної екологічної мережі, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 33

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 7 березня 2007 р. N 390

ПОРЯДОК використання у 2007 році коштів, передбачених у державному бюджеті ( 489-16 ) для виконання природоохоронних заходів з формування національної екологічної мережі

1. Цей Порядок визначає механізм використання у 2007 році коштів, передбачених Мінприроди у державному бюджеті ( 489-16 ) за програмою "Формування національної екологічної мережі" (далі - бюджетні кошти).

Головним розпорядником бюджетних коштів є Мінприроди.

2. Бюджетні кошти спрямовуються відповідно до розробленого Мінприроди плану природоохоронних заходів (далі - план заходів) на:

ведення кадастрів рослинного та тваринного світу, територій та об'єктів природно-заповідного фонду, Червоної та Зеленої книг України;

визначення просторової структури, розроблення та опрацювання схем формування екомережі, розроблення проектів створення та розширення об'єктів природно-заповідного фонду загальнодержавного значення, організації та лісовпорядкування їх територій; { Абзац третій пункту 2 із змінами, внесеними згідно з Постановою КМ N 388 ( 388-2008-п ) від 17.04.2008 }

розроблення проектів землеустрою, оформлення та реєстрацію державних актів на право постійного користування землею, встановлення меж у натурі (на місцевості) установ природно-заповідного фонду загальнодержавного значення;

здійснення заходів, спрямованих на запобігання знищенню чи пошкодженню природних комплексів територій та об'єктів природно-заповідного фонду загальнодержавного значення, а також їх відновлення;

здійснення заходів щодо збереження видів тварин і рослин, занесених до Червоної книги України та міжнародних природоохоронних списків, рослинних угруповань, занесених до Зеленої книги України, поліпшення середовища їх існування чи зростання, створення належних умов для розмноження у природних умовах, розведення та розселення;

створення центрів для розведення рідкісних і таких, що перебувають під загрозою зникнення, видів тварин і рослин;

будівництво, реконструкцію, капітальний ремонт (у тому числі виготовлення проектно-кошторисної документації) та облаштування приміщень, придбання приміщень, споруд, спеціального обладнання, приладів, транспортних засобів і засобів зв'язку, форменого одягу та службової зброї установам природно-заповідного фонду загальнодержавного значення, зміцнення матеріально-технічної бази для управління зазначеними установами; { Абзац восьмий пункту 2 із змінами, внесеними згідно з Постановою КМ N 388 ( 388-2008-п ) від 17.04.2008 }

підготовку національних звітів, планів дій та заходів з питань збереження біо- та ландшафтного різноманіття, формування екомережі;

складення паспортів водно-болотних угідь, що мають міжнародне значення, і внесення змін до них; { Абзац десятий пункту 2 в редакції Постанови КМ N 388 ( 388-2008-п ) від 17.04.2008 }

розвиток еколого-освітньої та рекреаційної діяльності в установах природно-заповідного фонду, інформування громадськості з питань збереження біо- та ландшафтного різноманіття, формування екомережі.

3. План заходів затверджується Міністром охорони навколишнього природного середовища та подається на погодження Мінфіну і Віце-прем'єр-міністру України у місячний строк після набрання чинності цим Порядком. { Абзац перший пункту 3 із змінами, внесеними згідно з Постановою КМ N 388 ( 388-2008-п ) від 17.04.2008 }

На підставі аналізу інформації щодо стану виконання природоохоронних заходів та наявності кредиторської заборгованості на початок року Мінприроди передбачає в плані заходів видатки на здійснення зазначених заходів, що забезпечують погашення кредиторської заборгованості, з урахуванням необхідності виконання взятих на облік в органах державного казначейства бюджетних зобов'язань минулих років у разі їх відповідності паспорту бюджетної програми.

4. Закупівля товарів, робіт і послуг за рахунок бюджетних коштів здійснюється в установленому законодавством порядку.

{ Пункт 4 із змінами, внесеними згідно з Постановою КМ N 388 ( 388-2008-п ) від 17.04.2008 }

5. Операції, пов'язані з використанням бюджетних коштів, проводяться відповідно до Порядку обслуговування державного бюджету за видатками ( z0716-04 ), затвердженого Державним казначейством.

6. Попередня оплата товарів, робіт і послуг, що закуповуються за бюджетні кошти, здійснюється відповідно до постанови Кабінету Міністрів України від 9 жовтня 2006 р. N 1404 ( 1404-2006-п ) (Офіційний вісник України, 2006 р., N 41, ст. 2752).

7. Інформація про виконання плану заходів та використання бюджетних коштів подається розпорядниками бюджетних коштів нижчого рівня та їх одержувачами до Мінприроди щокварталу до 15 числа місяця, наступного за звітним періодом, за встановленою Мінприроди формою.

Мінприроди зводить і подає щокварталу зазначену інформацію до 20 числа місяця, наступного за звітним періодом, та щороку до 10 лютого наступного за звітним року Мінфіну.

8. Складення та подання фінансової звітності про використання бюджетних коштів, а також контроль за їх цільовим витрачанням здійснюються в установленому законодавством порядку.
