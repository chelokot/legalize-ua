Президент України; Указ від 09.01.1992 № 33

Про призначення керівного складу в Службі національної безпеки України

Стан: Чинний

Ідентифікатор: 33/92

Текст документа від 09.01.1992:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про призначення керівного складу в Службі національної безпеки України

Призначити на посади керівного складу в Службі національної безпеки України:

- полковника ДЕМИДЕНКА Миколу Петровича - начальником Управління по роботі з особовим складом СНБ України;

- полковника КОЖЕМ'ЯКІНА Анатолія Леонідовича - начальником Управління СНБ України по боротьбі з корупцією за злочинами в сфері економіки і управління;

- генерал-майора СІДАКА Володимира Степановича - редактором Інституту підготовки кадрів СНБ України;

- полковника БЕСАРАБА Омеляна Івановича - начальником Управління СНБ України по Херсонській області;

- полковника ВОЙТОВИЧА Івана Івановича - начальником Управління СНБ України по Івано-Франківській області;

- полковника ДЕМЕНКОВА Анатолія Олексійовича - начальником Управління СНБ України по Волинській області;

- генерал-майора ДЕНИЩИКА Олексія Івановича - начальником Управління СНБ України по Хмельницькій області;

- генерал-майора КАЛИНОВИЧА Льва Дмитровича - начальником Управління СНБ України по Одеській області;

- полковника САМОЙЛЕНКА Ігоря Петровича - начальником Управління СНБ України по Кіровоградській області;

- полковника СМІРНОВА Віталія Семеновича - начальником Управління СНБ України по Черкаській області;

- полковника СІЧІОКНО Бориса Івановича - начальником Управління СНБ України по Полтавській області;

- полковника ПШЕНИЧНОГО Валерія Йосиповича - начальником Управління СНБ України по Львівській області;

- полковника ТРОФИМЕНКА Володимира Ілліча - начальником Управління СНБ України по Миколаївській області;

- полковника УКРАЇНСЬКОГО Івана Олександровича - начальником Управління СНБ України по Рівненській області;

- полковника УХАЛЯ Арзена Михайловича - начальником Управління СНБ України по Закарпатській області;

- генерал-майора ХЛЕВІЦЬКОГО Бориса Тимофійовича - начальником Управління СНБ України по Донецькій області;

- полковника КУШНІРА Миколу Олександровича - начальником Управління СНБ України по Чернівецькій області;

- полковника РАДЧЕНКА Володимира Івановича - начальником Управління СНБ України по Тернопільській області.

Указ набуває чинності з дня підписання.

Президент України Л.КРАВЧУК
