Про затвердження змін до деяких нормативно-правових актів щодо обліку та оподаткування неприбуткових установ (організацій)

Реєстрація: Мін'юст України від 02.02.2005 № 147/10427

Стан: Чинний

Ідентифікатор: z0147-05

Текст документа від 17.01.2005:

ДЕРЖАВНА ПОДАТКОВА АДМІНІСТРАЦІЯ УКРАЇНИ

НАКАЗ

17.01.2005 N 20

Зареєстровано в Міністерстві юстиції України 2 лютого 2005 р. за N 147/10427

Про затвердження змін до деяких нормативно-правових актів щодо обліку та оподаткування неприбуткових установ (організацій)

У зв'язку з набранням чинності Закону України від 1 липня 2004 року N 1957-IV ( 1957-15 ) "Про внесення змін до Закону України "Про оподаткування прибутку підприємств", керуючись статтею 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ), НАКАЗУЮ:

1. Затвердити Зміни до Порядку визначення структури ознаки неприбуткових установ (організацій), затвердженого наказом Державної податкової адміністрації України від 3 липня 2000 року N 355 ( z0451-00 ) та зареєстрованого в Міністерстві юстиції України 27 липня 2000 року за N 451/4672, що додаються.

2. Затвердити Зміни до Порядку складання податкового звіту про використання коштів неприбутковими установами й організаціями, затвердженого наказом Державної податкової адміністрації України від 11 липня 1997 року N 233 ( z0290-97 ) та зареєстрованого в Міністерстві юстиції України 6 серпня 1997 року за N 290/2094 (у редакції наказу Державної податкової адміністрації України від 3 квітня 2003 року N 153 ( z0309-03 ), зареєстрованого в Міністерстві юстиції України 16 квітня 2003 року за N 309/7630), що додаються ( z0148-05 ).

3. Затвердити Зміни до Положення про Реєстр неприбуткових організацій та установ, затвердженого наказом Державної податкової адміністрації України від 11 липня 1997 року N 232 ( z0291-97 ) та зареєстрованого в Міністерстві юстиції України 6 серпня 1997 року за N 291/2095, що додаються ( z0149-05 ).

4. В.о. директора Департаменту методології Фліссак Н.П. в установленому порядку подати цей наказ до Міністерства юстиції України для державної реєстрації.

5. Контроль за виконанням цього наказу покласти на заступника Голови ДПА України Лекаря С.І.

Голова Ф.О.Ярошенко

ЗАТВЕРДЖЕНО Наказ Державної податкової адміністрації України 17.01.2005 N 20

Зареєстровано в Міністерстві юстиції України 2 лютого 2005 р. за N 147/10427

Зміни до Порядку визначення структури ознаки неприбуткових установ (організацій) ( z0451-00 )

1. У розділі II "Структура ознаки":

1.2. Абзац другий підпункту 3.1 пункту 3 після слів "Про пенсійне забезпечення" доповнити словами "Про загальнообов'язкове державне пенсійне страхування", "Про недержавне пенсійне забезпечення".

1.3. У абзаці другому підпункту 3.2 пункту 3 слова "Указом Президента України від 20 вересня 1993 року N 377 ( 377/93 ) "Про Тимчасове положення про кредитні спілки в Україні" замінити словами "Законом України "Про кредитні спілки" ( 2908-14 ).
