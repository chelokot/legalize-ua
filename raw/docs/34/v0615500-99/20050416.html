Стан: Втратив чинність

Ідентифікатор: v0615500-99

Текст документа від 16.04.2005:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

N 26 від 22.01.99 Зареєстровано в юридичному м.Київ департаменті Нацбанку 25 січня 1999 р. за N 615

( Постанова втратила чинність на підставі Постанови Національного банку N 101 ( z0359-05 ) від 31.03.2005 )

Про внесення доповнень до постанови Правління Національного банку України N 349 від 04.09.98 "Про введення обов'язкового продажу надходжень в іноземній валюті на користь резидентів - юридичних осіб"

З метою ефективного використання добровільних пожертвувань та заохочення благодійної діяльності Правління ПОСТАНОВЛЯЄ:

1. Пункт 1 постанови Правління Національного банку України від 04.09.98 N 349 ( v0575500-98 ) "Про введення обов'язкового продажу надходжень в іноземній валюті на користь резидентів - юридичних осіб" (із змінами, внесеними постановою Правління від 14.09.98 N 365 ( v0576500-98 ) доповнити абзацом такого змісту:

"з) що надходять безкоштовно у вигляді добровільних пожертвувань.".

2. Постанова набуває чинності з дня її прийняття.

3. Департаменту валютного регулювання (С.О.Яременко) довести зміст цієї постанови до відома Кримського республіканського, Головного, Операційного, обласних та по м.Києву і Київській області управлінь Національного банку України, а також комерційних банків для керівництва і використання в роботі.

4. Контроль за виконанням цієї постанови покласти на першого заступника Голови Правління В.С.Стельмаха.

Голова В.А.Ющенко
