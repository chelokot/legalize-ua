{ Постанова втратила чинність на підставі Постанови КМ N 1254 ( 1254-2007-п ) від 24.10.2007 }

Про голову Національної координаційної ради боротьби з наркоманією при Кабінеті Міністрів України

Кабінет Міністрів України постановляє:

Затвердити Віце-прем'єр-міністра України Смолія Валерія Андрійовича головою Національної координаційної ради боротьби з наркоманією при Кабінеті Міністрів України, увільнивши від цих обов'язкІв Дурдинця В.В.
