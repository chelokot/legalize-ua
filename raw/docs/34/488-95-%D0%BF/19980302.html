Про деякі зміни щодо матеріального забезпечення працівників прокуратури, судів, податкової служби, органів державної виконавчої влади та інших органів

Стан: Втратив чинність

Ідентифікатор: 488-95-п

Текст документа від 02.03.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 4 липня 1995 р. N 488 Київ

Про деякі зміни щодо матеріального забезпечення працівників прокуратури, судів, податкової служби, органів державної виконавчої влади та інших органів

( Про поширення чинності додатково див. Постанови КМ N 783 ( 783-95-п ) від 04.10.95 N 297 ( 297-96-п ) від 06.03.96 )

( Із змінами, внесеними згідно з Постановами КМ N 606 ( 606-96-п ) від 31.05.96 N 828 ( 828-97-п ) від 04.08.97 )

( Про поширення чинності додатково див. Постанову КМ N 259 ( 259-98-п ) від 02.03.98 )

Кабінет Міністрів України постановляє:

1. ( Пункт 1 втратив чинність в частині матеріальної допомоги працівникам податкової служби на підставі Постанови КМ N 828 ( 828-97-п ) від 04.08.97 ) На зміну абзацу першого підпункту "г" пункту 2 постанови Кабінету Міністрів України від 21 січня 1993 р. N 35 ( 35-93-п ), абзацу першого підпункту "г" пункту 2 постанови Кабінету Міністрів України від 21 січня 1993 р. N 38 ( 38-93-п ), абзацу першого підпункту "д" пункту 2 постанови Кабінету Міністрів України від 21 січня 1993 р. N 39 ( 39-93-п ), абзацу першого підпункту "д" пункту 2 постанови Кабінету Міністрів України від 21 січня 1993 р. N 40 ( 40-93-п ), підпункту "д" пункту 2 постанови Кабінету Міністрів України від 22 лютого 1994 р. N 112 ( 112-94-п ) надавати працівникам прокуратури, судів, податкової служби, органів державної виконавчої влади та інших органів матеріальну допомогу у розмірі середньомісячного заробітку.

2. ( Пункт 2 втратив чинність в частині надбавок Голові та заступникам Голови державної податкової адміністрації на підставі Постанови КМ N 828 ( 828-97-п ) від 04.08.97 ) Установити керівникам центральних органів державної виконавчої влади та їх заступникам, державним уповноваженим Антимонопольного комітету України надбавки за особливий характер роботи та інтенсивність праці у розмірі до 90 відсотків посадового окладу з урахуванням доплати за ранг.

( Поширити чинність пункту 2 згідно з Постановою КМ N 783 ( 783-95-п ) від 04.10.95 на:

віце-прем'єрів і Керуючого справами Уряду Автономної Республіки Крим, керівників і заступників керівників міністерств, державних комітетів та інших центральних органів державної виконавчої влади Автономної Республіки Крим;

голів і заступників голів обласних, Київської та Севастопольської міських державних адміністрацій )

( Поширити чинність пункту 2 на Генерального прокурора України та його заступників, прокурорів Автономної Республіки Крим, областей, мм. Києва і Севастополя та їх заступників, прирівняних до них прокурорів та їх заступників згідно з Постановою КМ N 297 ( 297-96-п ) від 06.03.96 ) ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 606 ( 606-96-п ) від 31.05.96 ) ( Поширити чинність пункту 2 на директора і заступника директора Державного архіву при Раді міністрів Автономної Республіки Крим згідно з Постановою КМ N 259 ( 259-98-п ) від 02.03.98 )

3. Видатки, передбачені пунктами 1 і 2 цієї постанови, здійснювати в межах асигнувань, передбачених у Державному бюджеті України на утримання відповідних органів.

4. Визнати такими, що втратили чинність, абзац шостий підпункту "б" та абзац другий підпункту "в" пункту 2 постанови Кабінету Міністрів України від 22 лютого 1994 р. N 112 ( 112-94-п ).

5. Ця постанова вводиться в дію з 1 липня 1995 року.
