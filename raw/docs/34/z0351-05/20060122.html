Державне казначейство; Наказ від 21.03.2005 № 48

Про запровадження наказів Державного казначейства України від 25.05.2004 N 89 та від 09.08.2004 N 136

Реєстрація: Мін'юст України від 31.03.2005 № 351/10631

Стан: Чинний

Ідентифікатор: z0351-05

Текст документа від 22.01.2006:

ДЕРЖАВНЕ КАЗНАЧЕЙСТВО УКРАЇНИ

НАКАЗ

21.03.2005 N 48

Зареєстровано в Міністерстві юстиції України 31 березня 2005 р. за N 351/10631

Про запровадження наказів Державного казначейства України від 25.05.2004 N 89 та від 09.08.2004 N 136

( Із змінами, внесеними згідно з Наказами Державного казначейства N 167 ( z1079-05 ) від 14.09.2005 N 240 ( z0011-06 ) від 16.12.2005 )

З метою виявлення недоліків, удосконалення та для подальшого запровадження в повному обсязі на всій території України Порядку обслуговування державного бюджету за видатками, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04 ) та зареєстрованого в Міністерстві юстиції України 10.06.2004 за N 716/9315, і Порядку обліку зобов'язань розпорядників бюджетних коштів в органах Державного казначейства України, затвердженого наказом Державного казначейства України від 09.08.2004 N 136 ( z1068-04 ) та зареєстрованого в Міністерстві юстиції України 30.08.2004 за N 1068/9667, НАКАЗУЮ:

1. Протягом II-IV кварталів 2005 року та I-II кварталів 2006 року провести на базі органів Державного казначейства України як розпорядників бюджетних коштів експеримент із запровадження в повному обсязі Порядку обслуговування державного бюджету за видатками, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04 ) та зареєстрованого в Міністерстві юстиції України 10.06.2004 за N 716/9315, і Порядку обліку зобов'язань розпорядників бюджетних коштів в органах Державного казначейства України, затвердженого наказом Державного казначейства України від 09.08.2004 N 136 ( z1068-04 ) та зареєстрованого в Міністерстві юстиції України 30.08.2004 за N 1068/9667. ( Пункт 1 із змінами, внесеними згідно з Наказами Державного казначейства N 167 ( z1079-05 ) від 14.09.2005, N 240 ( z0011-06 ) від 16.12.2005 )

2. За наслідками проведення експерименту підбити підсумки щодо доцільності запровадження Порядку обслуговування державного бюджету за видатками, затвердженого наказом Державного казначейства України від 25.05.2004 N 89 ( z0716-04 ) та зареєстрованого в Міністерстві юстиції України 10.06.2004 за N 716/9315, і Порядку обліку зобов'язань розпорядників бюджетних коштів в органах Державного казначейства України, затвердженого наказом Державного казначейства України від 09.08.2004 N 136 ( z1068-04 ) та зареєстрованого в Міністерстві юстиції України 30.08.2004 за N 1068/9667, у повному обсязі на всій території України.

3. Контроль за виконанням цього наказу покласти на першого заступника Голови Пашину Н.П. та заступника Голови Даневича О.С.

Голова П.Г.Петрашко
