Кабінет Міністрів України; Постанова від 08.10.1997 № 1122

Про надання Державному агентству рибного господарства права на видачу документів міжнародного зразка

Стан: Втратив чинність

Ідентифікатор: 1122-97-п

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 жовтня 1997 р. N 1122 Київ

Про надання Державному комітету рибного господарства права на видачу документів міжнародного зразка

{ Із змінами, внесеними згідно з Постановою КМ N 616 ( 616-2006-п ) від 11.05.2006 }

З метою забезпечення безпеки мореплавства флоту рибної промисловості Кабінет Міністрів України постановляє:

Надати право Державному комітету рибного господарства видавати дипломи, кваліфікаційні сертифікати та документи про відповідність компанії і суден згідно з вимогами Міжнародної конвенції про стандарти підготовки, сертифікації персоналу риболовних суден та несення вахти 1995 року ( 995_707 ), Міжнародної конвенції з охорони людського життя на морі 1974 року (SOLAS-74), Міжнародного кодексу з управління безпечною експлуатацією суден і попередженням забруднення 1993 року (МКУБ-93).

{ Постанова із змінами, внесеними згідно з Постановою КМ N 616 ( 616-2006-п ) від 11.05.2006 }
