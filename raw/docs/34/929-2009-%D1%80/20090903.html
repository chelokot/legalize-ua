Кабінет Міністрів України; Розпорядження, Перелік від 05.08.2009 № 929-р

Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов

Стан: Чинний

Ідентифікатор: 929-2009-р

Текст документа від 03.09.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 5 серпня 2009 р. N 929-р Київ

Про придбання квартир для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов

{ Із змінами, внесеними згідно з Постановою КМ N 861 ( 861-2009-п ) від 12.08.2009 Розпорядженнями КМ N 988-р ( 988-2009-р ) від 19.08.2009 N 1045-р ( 1045-2009-р ) від 03.09.2009 }

1. Погодитися з пропозицією Мінрегіонбуду щодо придбання Державною іпотечною установою квартир за переліком згідно з додатком на загальну суму 136 797,839 тис. гривень у житлових будинках, прийнятих в експлуатацію, та на об'єктах незавершеного житлового будівництва із строком здачі в експлуатацію не пізніше ніж 25 грудня 2009 р. за наявності відповідної банківської гарантії або іншого виду забезпечення виконання зобов'язань забудовників, що прийматимуться Державною іпотечною установою, або наявності графіка виконання будівельно-монтажних робіт, погодженого з керівником інспекції державного архітектурно-будівельного контролю в Автономній Республіці Крим, областях, мм. Києві та Севастополі, для забезпечення житлом громадян, які відповідно до законодавства потребують поліпшення житлових умов та перебувають на квартирному обліку.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 861 ( 861-2009-п ) від 12.08.2009, Розпорядженнями КМ N 988-р ( 988-2009-р ) від 19.08.2009, N 1045-р ( 1045-2009-р ) від 03.09.2009 }

2. Державній іпотечній установі передати квартири, придбані відповідно до пункту 1 цього розпорядження, головним розпорядникам бюджетних коштів за розподілом Мінпраці, погодженим з Мінсім'ямолодьспортом та Мінфіном.

3. Головним розпорядникам бюджетних коштів разом з Мінфіном під час уточнення показників Державного бюджету України на 2009 рік ( 835-17 ) та складання проектів державного бюджету на наступні роки передбачати кошти для компенсації Державній іпотечній установі витрат, пов'язаних з придбанням квартир відповідно до пункту 1 цього розпорядження, та кошти для придбання та будівництва житла для окремих категорій громадян, які відповідно до законодавства потребують поліпшення житлових умов та перебувають на квартирному обліку.
