Про внесення змін до наказу Міністерства України у справах молоді та спорту від 06.09.2005 N 1886

Відповідно до пункту 22 Загального положення про центр соціальних служб для сім'ї, дітей та молоді, затвердженого постановою Кабінету Міністрів України від 27 серпня 2004 року N 1126 ( 1126-2004-п ) (зі змінами), НАКАЗУЮ:

1. Унести до наказу Міністерства України у справах молоді та спорту від 06.09.2005 N 1886 ( z1103-05, z1104-05 ) "Про затвердження Типових структури і штатів республіканського (Автономної Республіки Крим), обласних, Київського та Севастопольського міських, районних, міських, районних у містах, селищних та сільських центрів соціальних служб для сім'ї, дітей та молоді", зареєстрованого в Міністерстві юстиції України 26.09.2005 за N 1103/11383 (далі - Наказ), такі зміни:

1.1. Типові структуру і штати республіканського (Автономної Республіки Крим), обласних, Київського та Севастопольського міських Центрів, затверджені Наказом ( z1103-05 ), викласти у новій редакції, що додається.

1.2. Унести до Типових структури і штатів районних, міських, районних у містах, районних у мм. Києві та Севастополі Центрів ( z1104-05 ), затверджених Наказом ( z1103-05 ), зареєстрованих у Міністерстві юстиції України 26.09.2005 за N 1104/11384, такі зміни:

1.2.1. Назву посади "головний спеціаліст-головний бухгалтер" замінити на назву "головний спеціаліст, головний бухгалтер".

1.2.2. Назву посади "провідний спеціаліст-юрисконсульт" замінити на назву "провідний спеціаліст, юрисконсульт".

1.2.3. У пункті 1 примітки після слів "за відсутності Центрів у районах" доповнити словами "в т.ч. у м. Севастополь".

2. Державній соціальній службі для сім'ї, дітей та молоді забезпечити державну реєстрацію цього наказу відповідно до Указу Президента України від 3 жовтня 1992 року N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (зі змінами).

3. Контроль за виконанням наказу покласти на директора Державної соціальної служби для сім'ї, дітей та молоді.

Міністр Ю.О.Павленко

Відповідно до пункту 22 Загального положення про центр соціальних служб для сім'ї, дітей та молоді, затвердженого постановою Кабінету Міністрів України від 27.08.2004 N 1126 ( 1126-2004-п ) (зі змінами), у республіканському (Автономної Республіки Крим) та обласних Центрах, за відсутності міського Центру, відповідними місцевими органами виконавчої влади гранична чисельність може збільшуватись додатково щонайбільше на 8 осіб.

У межах установленого фонду заробітної плати до штатного розпису Центрів можуть бути уведені, крім посад державних службовців, такі посади:

а) завідувача: господарства, копіювально-розмножувального бюро;

б) касира;

в) секретаря керівника;

г) водія автотранспорту - за наявності автомобіля;

ґ) прибиральниці службових приміщень - відповідно до встановлених нормативів;

д) охоронника.

Директори Центрів у залежності від нагальної потреби можуть змінювати чисельність відділу чи сектору в межах граничної чисельності працівників Центру за погодженням з керівником місцевого органу виконавчої влади, який затверджує граничну чисельність працівників зазначеного Центру.

Директор Державної соціальної служби для сім'ї, дітей та молоді Н.Л.Лук'янова
