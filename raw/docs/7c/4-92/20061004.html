Про прибутковий податок з доходів громадян, що перевищують 60000 купонів

Стан: Втратив чинність

Ідентифікатор: 4-92

Текст документа від 04.10.2006:

ДЕКРЕТ КАБІНЕТУ МІНІСТРІВ УКРАЇНИ

{ Декрет втратив чинність на підставі Закону N 139-V ( 139-16 ) від 14.09.2006, ВВР, 2006, N 43, ст.419 }

{ Декрет не діє в зв'язку з прийняттям Декрету N 13-92 від 26.12.92, ВВР, 1993, N 10, ст.77 }

Про прибутковий податок з доходів громадян, що перевищують 60000 купонів

( Відомості Верховної Ради України (ВВР), 1993, N 2, ст.16 )

{ Додатково див. Лист КМ N 18-506/4 (18_5-94-р) від 15.03.94 }

Кабінет Міністрів України постановляє:

1. Установити, що з 1 листопада 1992 р. із сум заробітків, одержуваних громадянами за виконання ними трудових обов'язків, і прирівняних до них доходів, одержуваних за місцем основної роботи (стаття 8 Закону України ( 1307-12 ) "Про прибутковий податок з громадян України, іноземних громадян та осіб без громадянства" , які перевищують 60000 купонів на місяць, прибутковий податок справляється в розмірі 12091 купона плюс 50 процентів із суми, що перевищує 60000 купонів.

2. Цей Декрет діє до прийняття Кабінетом Міністрів України декрету про прибутковий податок з громадян.

3. Цей Декрет набуває чинності з дня опублікування.
