ПОСТАНОВА від 11 липня 2001 р. N 788 Київ

{ Дію Постанови відновлено згідно з Постановою КМ N 686 ( 686-2007-п ) від 03.05.2007 }

{ Постанову скасовано на підставі Постанови КМ N 611 ( 611-2005-п ) від 21.07.2005 }

Про доповнення постанови Кабінету Міністрів України від 8 червня 1998 р. N 840

Кабінет Міністрів України постановляє:

Доповнити постанову Кабінету Міністрів України від 8 червня 1998 р. N 840 ( 840-98-п ) "Про утворення лізингової компанії "Укртранслізинг" пунктом 7 такого змісту:

"7. Міністерству транспорту разом з Фондом державного майна забезпечити відповідно до законодавства збільшення державної частки статутного фонду Компанії не менш як на 200 млн. гривень за рахунок власних коштів і майна залізниць та розміщення на договірних засадах замовлення на виготовлення літаків Ан-140, Ан-74ТК Харківським державним авіаційним виробничим підприємством".

Прем'єр-міністр України А.КІНАХ
