КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 вересня 1999 р. N 1759 Київ

{ Постанова втрачає чинність на підставі Постанови КМ N 93 ( 93-2003-п ) від 18.01.2003 з дати набрання чинності частиною тринадцятою статті 71 Митного кодексу України ( 92-15 ), яка набирає чинності з моменту набуття Україною членства у Світовій організації торгівлі }

Про деякі питання справляння митних зборів

З метою виходу з кризової ситуації, що склалася в ядерній галузі, своєчасного забезпечення атомних електростанцій свіжим ядерним паливом та необхідним обладнанням у період проведення планових ремонтів та підготовки до роботи в осінньо-зимових умовах Кабінет Міністрів України постановляє:

Установити, що дія абзацу четвертого пункту 1 постанови Кабінету Міністрів України від 27 січня 1997 р. N 65 ( 65-97-п ) "Про ставки митних зборів", із змінами, внесеними постановами Кабінету Міністрів України від 7 березня 1998 р. N 285 ( 285-98-п ), від 13 травня 1998 р. N 670 ( 670-98-п ), від 18 вересня 1998 р. N 1460 ( 1460-98-п ) та від 19 травня 1999 р. N 840 ( 840-99-п ), не поширюється на товари за кодами ТН ЗЕД 8401 30000 (тепловидільні елементи (касети) неопромінені (для ядерних реакторів)), 8401 40900 (частини ядерних реакторів), 8405 10000 (газогенератори чи парогенератори з очисними установками та без них), 8481 80630 (клапани із сталі).
