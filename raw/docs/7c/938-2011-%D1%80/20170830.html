Кабінет Міністрів України; Розпорядження від 12.09.2011 № 938-р

Питання Державної холдингової компанії "Дніпровський машинобудівний завод"

Стан: Чинний

Ідентифікатор: 938-2011-р

Текст документа від 30.08.2017:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 12 вересня 2011 р. N 938-р Київ

Питання Державної холдингової компанії "Дніпровський машинобудівний завод"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 599-р ( 599-2017-р ) від 30.08.2017 }

З метою збереження виробничого потенціалу акціонерних товариств, державні пакети акцій яких включені до статутного капіталу Державної холдингової компанії "Дніпровський машинобудівний завод" (далі - Компанія), та їх подальшого розвитку шляхом залучення інвестицій для реалізації інноваційних проектів Фонду державного майна в установленому законодавством порядку і відповідно до статутів Компанії та публічного акціонерного товариства "Дніпровський машинобудівний завод" забезпечити:

вилучення із статутного капіталу Компанії та продаж на конкурентних засадах пакета акцій публічного акціонерного товариства "Дніпровський машинобудівний завод" у розмірі 25 відсотків статутного капіталу та надходження отриманих від продажу коштів до державного бюджету;

вилучення в місячний строк після продажу пакета акцій, зазначеного в абзаці другому цього розпорядження, із статутного капіталу Компанії державного пакета акцій:

- публічного акціонерного товариства "Дніпровський машинобудівний завод" у розмірі 25 відсотків плюс одна акція статутного капіталу для його продажу на конкурентних засадах та надходження отриманих від продажу коштів до державного бюджету;

- публічного акціонерного товариства "Конструкторське бюро "Дніпровське" у розмірі 100 відсотків статутного капіталу для його продажу на конкурентних засадах після виключення з переліку об'єктів права державної власності, що не підлягають приватизації, та надходження отриманих від продажу коштів до державного бюджету; { Абзац п'ятий із змінами, внесеними згідно з Розпорядженням КМ N 599-р ( 599-2017-р ) від 30.08.2017 }

після вилучення із статутного капіталу Компанії зазначених державних пакетів акцій - здійснення заходів щодо ліквідації Компанії.

{ Абзац шостий із змінами, внесеними згідно з Розпорядженням КМ N 599-р ( 599-2017-р ) від 30.08.2017 }

Прем'єр-міністр України М.АЗАРОВ
