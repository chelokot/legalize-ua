Текст документа від 13.11.2001:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1071/2001 ( 1071/2001 ) від 13.11.2001 )

Про новий склад Всеукраїнської координаційної ради з питань розвитку духовності, захисту моралі та формування здорового способу життя громадян

На часткову зміну статті 2 Указу Президента України від 27 квітня 1999 року N 456 ( 456/99 ) "Про заходи щодо розвитку духовності, захисту моралі та формування здорового способу життя громадян" (із змінами, внесеними Указом Президента України від 17 вересня 1999 року N 1195 ( 1195/99 ) постановляю:

1. Призначити ЖУЛИНСЬКОГО Миколу Григоровича - Віце-прем'єр-міністра України - головою Всеукраїнської координаційної ради з питань розвитку духовності, захисту моралі та формування здорового способу життя громадян.

2. Затвердити новий склад Всеукраїнської координаційної ради з питань розвитку духовності, захисту моралі та формування здорового способу життя громадян (додається).

Дозволити голові Ради у разі потреби вносити зміни до її персонального складу.
