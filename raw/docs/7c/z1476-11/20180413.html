НАКАЗ

06.12.2011 N 327

Зареєстровано в Міністерстві юстиції України 20 грудня 2011 р. за N 1476/20214

{ Наказ втратив чинність на підставі Наказу Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 41 ( z0311-18 ) від 26.02.2018 }

Про внесення змін до наказу Мінбуду від 20.03.2006 N 69

У зв'язку з реорганізацією Міністерства регіонального розвитку та будівництва України та з метою забезпечення належного здійснення заходів, пов'язаних з виконанням постанови Кабінету Міністрів України від 01.03.2006 N 240 ( 240-2006-п ) "Про затвердження Правил підтвердження придатності нових будівельних виробів для застосування", НАКАЗУЮ:

1. Унести до наказу Мінбуду від 20.03.2006 N 69 ( z0577-06 ) "Про затвердження Порядку проведення роботи з підтвердження придатності нових будівельних виробів для застосування в будівництві та Переліку нових будівельних виробів, що підлягають перевірці та підтвердженню придатності для застосування в будівництві", зареєстрованого в Міністерстві юстиції України 18.05.2006 за N 577/12451 (далі - Наказ), такі зміни:

1.1. У пункті 4 Наказу ( z0577-06 ) слова "Управління технічного регулювання в будівництві" замінити словами "Департамент технічного регулювання та науково-технічного розвитку".

1.2. У пункті 5 Наказу ( z0577-06 ) слова "(Чеснок В.М.)" виключити.

1.3. У тексті Порядку проведення роботи з підтвердження придатності нових будівельних виробів для застосування в будівництві ( z0577-06 ), затвердженого Наказом, слова "Міністерство регіонального розвитку та будівництва" у всіх відмінках замінити словами "Міністерство регіонального розвитку, будівництва та житлово-комунального господарства" у відповідних відмінках.

2. Департаменту нормативно-правового регулювання (Татаринцева М.А.) разом з Департаментом технічного регулювання та науково-технічного розвитку (Барзилович Д.В.) забезпечити подання цього наказу в установленому порядку на державну реєстрацію до Міністерства юстиції.

3. Контроль за виконанням цього наказу покласти на заступника Міністра Ісаєнка Д.В.

4. Цей наказ набирає чинності з дня його офіційного опублікування.
