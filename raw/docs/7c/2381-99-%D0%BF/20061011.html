Про затвердження структури Служби Прем'єр-міністра України

( Із змінами, внесеними згідно з Постановами КМ N 466 ( 466-2000-п ) від 09.03.2000 N 660 ( 660-2001-п ) від 20.06.2001 N 932 ( 932-2001-п ) від 01.08.2001 )

Кабінет Міністрів України постановляє:

1. Затвердити структуру Служби Прем'єр-міністра України (додається).

2. Керівнику Служби Прем'єр-міністра України в тижневий термін подати на затвердження штатний розпис Служби.
