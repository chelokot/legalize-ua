1. Доповнити Тарифи за надання додаткових послуг правового і технічного характеру в Центральному відділі реєстрації шлюбів міста Києва з державним Центром розвитку сім'ї, затверджені наказом Міністерства юстиції України від 21.03.2008 N 453/5 ( z0244-08 ), зареєстровані в Міністерстві юстиції України 24.03.2008 за N 244/14935, позицією 18 такого змісту:

"

---------------------------------------------------------------------

|18 |Кур'єрські послуги | Одне обсл. |86,00 |

| |(по проставленню апостиля | | |

| |та легалізації) | | |

---------------------------------------------------------------------

"

2. Директору департаменту у справах цивільного стану громадян Кунді В.В. подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами).
