{ Наказ втратив чинність на підставі Наказу Державної служби статистики N 23 ( z0314-14 ) від 03.02.2014 }

Про внесення змін до наказу Держкомстату України від 17.08.2004 N 483

Відповідно до Закону України "Про державну статистику" ( 2614-12 ) та з метою приведення нормативно-правових актів у відповідність до чинного законодавства НАКАЗУЮ:

1. Визнати таким, що втратив чинність, починаючи зі звіту на початок 2008/2009 навчального року, наказ Державного комітету статистики України від 17.08.2004 N 483 ( z1058-04 ) "Про затвердження форми державного статистичного спостереження з питань діяльності вищих навчальних закладів та Інструкції щодо її заповнення", зареєстрований у Міністерстві юстиції України 30.08.2004 за N 1058/9657, у частині затвердження форми державного статистичного спостереження N 2-3нк "Звіт вищого навчального закладу на початок навчального року".

2. Контроль за виконанням цього наказу покласти на заступника Голови Власенко Н.С.

Голова О.Г.Осауленко
