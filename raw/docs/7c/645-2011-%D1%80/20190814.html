КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 6 липня 2011 р. N 645-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 623-р ( 623-2019-р ) від 14.08.2019 }

Про призначення координатора діяльності, пов'язаної з участю України в реалізації Стратегії Європейського Союзу для Дунайського регіону

{ Із змінами, внесеними згідно з Розпорядженням КМ N 42-р ( 42-2013-р ) від 30.01.2013 }

Призначити першого заступника Міністра економічного розвитку і торгівлі Максюту Анатолія Аркадійовича координатором діяльності, пов'язаної з участю України в реалізації Стратегії Європейського Союзу для Дунайського регіону.
