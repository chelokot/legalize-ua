Про затвердження нормативно-правових актів з питань функціонування електронного цифрового підпису в банківській системі України

Стан: Втратив чинність

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

17.06.2010 N 284

Зареєстровано в Міністерстві юстиції України 4 листопада 2010 р. за N 1034/18329

Про затвердження нормативно-правових актів з питань функціонування електронного цифрового підпису в банківській системі України

{ Із змінами, внесеними згідно з Постановами Національного банку

N 395 ( z0116-12 ) від 14.11.2011

N 442 ( v0442500-15 ) від 07.07.2015 }

Відповідно до пункту 7 статті 7 Закону України "Про Національний банк України" ( 679-14 ), частини сьомої статті 5 та частини другої статті 10 Закону України "Про електронний цифровий підпис" ( 852-15 ), з метою формування інфраструктури відкритих ключів банківської системи України і забезпечення умов для функціонування електронного цифрового підпису в банківській системі України Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Затвердити:

{ Абзац другий пункту 1 втратив чинність на підставі Постанови Національного банку N 442 ( v0442500-15 ) від 07.07.2015 }

{ Абзац третій пункту 1 втратив чинність на підставі Постанови Національного банку N 442 ( v0442500-15 ) від 07.07.2015 }

Правила оформлення Регламенту роботи центрів сертифікації ключів банків України (додаються) ( z1036-10 ).

2. Департаменту інформатизації (А.С.Савченко):

довести до відома центрів сертифікації ключів банків України зміст Положення про центри сертифікації ключів банків України, Правил реєстрації, засвідчення чинності відкритого ключа та акредитації центрів сертифікації ключів банків України в Засвідчувальному центрі Національного банку України ( z1035-10 ), Правил оформлення Регламенту роботи центрів сертифікації ключів банків України ( z1036-10 );

розробити перелік послуг, які надаються Засвідчувальним центром Національного банку України, технічні вимоги до центрів сертифікації ключів банків України, порядок обов'язкового передавання документованої інформації до Засвідчувального центру Національного банку України в разі припинення діяльності центру сертифікації ключів банку України, Примірний регламент роботи центрів сертифікації ключів банків України. { Абзац третій пункту 2 із змінами, внесеними згідно з Постановою Національного банку N 395 ( z0116-12 ) від 14.11.2011 }

3. Фінансовому департаменту (О.М.Кандибка) розробити тарифи на послуги, які надаються Засвідчувальним центром Національного банку України.

4. Контроль за виконанням цієї постанови покласти на заступника Голови Національного банку України П.М.Сенища.

5. Ця постанова набирає чинності з дня її офіційного опублікування.

Голова В.С.Стельмах
