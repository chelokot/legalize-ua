Текст документа від 15.10.1996:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 947/96 ( 947/96 ) від 15.10.96 )

Про внесення змін до Указу Президента України від 31 травня 1995 року N 405

1. Зупинити чинність статті 1 Указу Президента України від 31 травня 1995 року N 405 ( 405/95 ) "Про пільги щодо оподаткування" у частині, що стосується скасування пільг, згідно з переліком (додається).

2. Цей Указ набирає чинності з дня його підписання.
