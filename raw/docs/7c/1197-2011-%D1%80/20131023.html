РОЗПОРЯДЖЕННЯ від 28 листопада 2011 р. N 1197-р Київ

Про віднесення підприємств, установ та організацій до сфери управління Міністерства освіти і науки, молоді та спорту і Державної служби молоді та спорту

{ Із змінами, внесеними згідно з Розпорядженнями КМ N 693-р ( 693-2012-р ) від 19.09.2012 N 902-р ( 902-2013-р ) від 23.10.2013 }

1. Прийняти пропозицію Міністерства освіти і науки, молоді та спорту щодо віднесення до сфери управління:

Міністерства освіти і науки, молоді та спорту установ та організацій згідно з додатком 1.

{ Абзац третій пункту 1 виключено на підставі Розпорядження КМ N 902-р ( 902-2013-р ) від 23.10.2013 }

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 23 квітня 2005 р. N 122 ( 122-2005-р ) "Про передачу до сфери управління Міністерства у справах молоді та спорту підприємств, установ та організацій" (Офіційний вісник України, 2005 р., N 17, ст. 909);

розпорядження Кабінету Міністрів України від 18 серпня 2010 р. N 1672 ( 1672-2010-р ) "Про внесення зміни у додаток до розпорядження Кабінету Міністрів України від 23 квітня 2005 р. N 122" (Офіційний вісник України, 2010 р., N 65, ст. 2300).
