Про утворення групи супроводження проектів міждержавної програми транспортування нафти та газу до Європи (TACIS - INOGATE)

Стан: Втратив чинність

Ідентифікатор: 862-98-р

Текст документа від 09.11.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 жовтня 1998 р. N 862-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 448-р ( 448-2000-р ) від 09.11.2000 )

Про утворення групи супроводження проектів міждержавної програми транспортування нафти та газу до Європи (TACIS - INOGATE)

( Із змінами, внесеними згідно з Розпорядженням КМ N 161-р ( 161-99-р ) від 02.03.99 )

З метою сприяння реалізації міждержавної програми транспортування нафти та газу до Європи (TACIS - INOGATE) утворити групу супроводження проектів програми у складі згідно з додатком.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

Інд. 37

Додаток до розпорядження Кабінету Міністрів України від 28 жовтня 1998 р. N 862-р

ТАРАШЕВСЬКИЙ В.С. - голова Держнафтогазпрому

ЧЕРНИШОВ В.Г. - начальник Управління з питань державної політики в паливно-енергетичному комплексі апарату Кабінету Міністрів України.
