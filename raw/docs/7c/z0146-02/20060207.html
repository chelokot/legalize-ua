N 95 від 07.02.2002 Зареєстровано в Міністерстві м.Київ юстиції України 14 лютого 2002 р. за N 146/6434

( Наказ втратив чинність на підставі Наказу Міністерства праці та соціальної політики N 5 ( z0070-06 ) від 16.01.2006 )

Про внесення змін до наказу Міністерства праці та соціальної політики України від 25.05.2001 N 240

Відповідно до постанови Кабінету Міністрів України від 10 січня 2002 р. N 18 ( 18-2002-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Унести до наказу Міністерства праці та соціальної політики України від 25.05.2001 N 240 ( z0479-01 ) "Про впорядкування умов оплати праці працівників притулків для неповнолітніх служб у справах неповнолітніх", зареєстрованого в Міністерстві юстиції України 06.06.2001 за N 479/5670, такі зміни:

додатки 1 - 5 викласти у новій редакції, що додається.

2. Ці умови застосовуються з 1 лютого 2002 року.

Міністр І.Сахань
