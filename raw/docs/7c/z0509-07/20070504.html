Зареєстровано в Міністерстві юстиції України 16 травня 2007 р. за N 509/13776

Про внесення змін до нормативно-правових актів Мінпраці

З метою приведення нормативно-правових актів у відповідність до Закону України "Про внесення змін до деяких законодавчих актів України щодо органів і служб у справах неповнолітніх та спеціальних установ для неповнолітніх" ( 609-16 ) НАКАЗУЮ:

1. Унести до нормативно-правових актів Мінпраці такі зміни:

1.1. У Типовому положенні про центр реінтеграції бездомних громадян, затвердженому наказом Мінпраці від 14.02.2006 N 31 ( z0474-06 ), зареєстрованому в Міністерстві юстиції України 21.04.2006 за N 474/12348, пункт 3.6 розділу 3 після слів "інших закладах" доповнити словами "і установах".

1.2. У Типовому положенні про будинок нічного перебування ( z0475-06 ), затвердженому наказом Мінпраці від 14.02.2006 N 31 ( z0474-06 ), зареєстрованому в Міністерстві юстиції України 21.04.2006 за N 475/12349, в абзаці 3 пункту 3.1 розділу 3 слово "неповнолітніх" замінити словом "дітей".

1.3. У Типовому положенні про центр соціальної адаптації осіб, звільнених з місць позбавлення волі ( z0476-06 ), затвердженому наказом Мінпраці від 14.02.2006 N 31 ( z0474-06 ), зареєстрованому в Міністерстві юстиції України 21.04.2006 за N 476/12350, пункт 3.6 розділу 3 після слів "інших закладах" доповнити словами "і установах".

2. У пункті 2.5 розділу 2 Типового положення про соціальний готель, затвердженого наказом Мінпраці від 03.04.2006 N 98 ( z0450-06 ), зареєстрованого в Міністерстві юстиції України 18.04.2006 за N 450/12324, слово "неповнолітніх" замінити словом "дітей".

3. Управлінню у справах бездомних громадян та осіб, звільнених із місць позбавлення волі, Міністерства праці та соціальної політики (О.Суліма) забезпечити державну реєстрацію цього наказу в Міністерстві юстиції України.

4. Контроль за виконанням цього наказу покласти на заступника Міністра Б.Молчанова.

Міністр М.Папієв
