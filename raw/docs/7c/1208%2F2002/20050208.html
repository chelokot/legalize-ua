УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 208/2005 ( 208/2005 ) від 08.02.2005 )

Про внесення змін до складу Ради національної безпеки і оборони України

Внести до складу Ради національної безпеки і оборони України, затвердженого Указом Президента України від 7 серпня 2001 року N 605 ( 605/2001 ) (зі змінами, внесеними Указами від 27 грудня 2001 року N 1277 ( 1277/2001 ), від 22 травня 2002 року N 481 ( 481/2002 ), від 15 червня 2002 року N 557 ( 557/2002 ), від 20 червня 2002 року N 574 ( 574/2002 ) та від 7 вересня 2002 року N 807 ( 807/2002 ), такі зміни:

1. Увести до складу Ради ЯНУКОВИЧА Віктора Федоровича - Прем'єр-міністра України, АЗАРОВА Миколу Яновича - Першого віце-прем'єр-міністра України, Міністра фінансів України, РЕВУ Григорія Васильовича - Міністра України з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи, ХОРОШКОВСЬКОГО Валерія Івановича - Міністра економіки та з питань європейської інтеграції України, ШЕВЧУКА Василя Яковича - Міністра екології та природних ресурсів України.

2. Вивести зі складу Ради Дурдинця В.В., Кінаха А.К., Шлапака О.В. та Юшка І.О.

Президент України Л.КУЧМА
