УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 504/2014 ( 504/2014 ) від 06.06.2014 }

Про рішення Ради національної безпеки і оборони України від 17 листопада 2006 року "Про стан житлово-комунального господарства України та основні напрями його реформування"

Відповідно до статті 107 Конституції України ( 254к/96-ВР ) постановляю:

1. Увести в дію рішення Ради національної безпеки і оборони України від 17 листопада 2006 року "Про стан житлово-комунального господарства України та основні напрями його реформування" ( n0007525-06 ) (додається*).

2. Відповідно до частини другої статті 93 Конституції України ( 254к/96-ВР ) визначити як невідкладні для позачергового розгляду Верховною Радою України законопроекти:

"Про внесення змін до Закону України "Про об'єднання співвласників багатоквартирного будинку" (реєстраційний N 1215);

"Про державне регулювання в енергетиці України" (реєстраційний N 1221).

3. Контроль за виконанням цього Указу покласти на Секретаря Ради національної безпеки і оборони України.

Президент України В.ЮЩЕНКО

м. Київ, 16 грудня 2006 року N 1093/2006
