Зареєстровано в Міністерстві юстиції України 7 вересня 2007 р. за N 1045/14312

Про внесення змін до наказу ДПА України від 30.05.97 N 166

З метою удосконалення адміністрування податку на додану вартість та відшкодування його з бюджету, а також відповідно до статті 7 Закону України "Про податок на додану вартість" ( 168/97-ВР ) та керуючись статтею 8 Закону України "Про державну податкову службу в Україні" ( 509-12 ), НАКАЗУЮ:

1. Внести зміни до додатка 1 ( zi702-05 ) до податкової декларації з податку на додану вартість ( za702-05 ), затвердженої наказом Державної податкової адміністрації України від 30.05.97 N 166 ( z0250-97 ), зареєстрованої в Міністерстві юстиції України 09.07.97 за N 250/2054 (у редакції наказу Державної податкової адміністрації України від 15.06.05 N 213 ( z0702-05 ), виклавши його в новій редакції ( za045-07 ), що додається.

2. Висновки додатка 2 ( zd702-05 ) до Порядку заповнення та подання податкової декларації з податку на додану вартість, затвердженного наказом Державної податкової адміністрації України від 30.05.97 N 166 ( z0250-97 ), зареєстрованого в Міністерстві юстиції України 09.07.97 за N 250/2054 (у редакції наказу Державної податкової адміністрації України від 15.06.2005 N 213 ( z0702-05 ), доповнити новим пунктом 7 такого змісту:

"7) збільшується (зменшується) сума по податковому векселю, зарахована до складу податкових зобов'язань (податкового кредиту)".

3. Департаменту податку на додану вартість (Богдан А.В.) подати цей наказ до Міністерства юстиції України на державну реєстрацію.

4. Департаменту масово-роз'яснювальної роботи та звернень громадян (Косарчук В.П.) у десятиденний строк від дня реєстрації цього наказу в Міністерстві юстиції України через засоби масової інформації довести цей наказ до відома платників податку на додану вартість.

5. Контроль за виконанням цього наказу покласти на заступника Голови Боєнка Л.Є.

Голова А.І.Брезвін
