Кабінет Міністрів України; Постанова від 13.12.2000 № 1824

Про розмір стипендій імені Тараса Шевченка учням середніх загальноосвітніх навчальних закладів

Стан: Втратив чинність

Ідентифікатор: 1824-2000-п

Текст документа від 23.03.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 грудня 2000 р. N 1824 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 177 ( 177-2012-п ) від 07.03.2012 }

Про розмір стипендій імені Тараса Шевченка учням середніх загальноосвітніх навчальних закладів

( Із змінами, внесеними згідно з Постановою КМ N 882 ( 882-2004-п ) від 12.07.2004 )

На виконання статті 2 Указу Президента України від 1 серпня 2000 р. N 940 ( 940/2000 ) "Про вшанування пам'яті Тараса Григоровича Шевченка" Кабінет Міністрів України постановляє:

Установити, що розмір стипендій імені Тараса Шевченка учням середніх загальноосвітніх навчальних закладів дорівнює 4,375 мінімальної академічної стипендії студентів вищих навчальних закладів III-IV рівня акредитації. ( Постановляюча частина в редакції Постанови КМ N 882 ( 882-2004-п ) від 12.07.2004 )
