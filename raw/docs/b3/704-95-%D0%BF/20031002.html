Кабінет Міністрів України; Постанова від 30.08.1995 № 704

Про компетентні національні органи з питань виконання міжнародних конвенцій у галузі використання ядерної енергії

Стан: Втратив чинність

Ідентифікатор: 704-95-п

Текст документа від 02.10.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 серпня 1995 р. N 704 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1570 ( 1570-2003-п ) від 02.10.2003 )

Про компетентні національні органи з питань виконання міжнародних конвенцій у галузі використання ядерної енергії

( Із змінами, внесеними згідно з Постановою КМ N 1006 ( 1006-2001-п ) від 09.08.2001 )

У зв'язку з реорганізацією центральних органів державної виконавчої влади та відповідно до статті 7 Конвенції про оперативне оповіщення про ядерну аварію ( 995_026 ) та статті 4 Конвенції про допомогу в разі ядерної аварії або радіаційної аварійної ситуації ( 995_027 ) Кабінет Міністрів України постановляє:

1. Визначити Державний комітет ядерного регулювання компетентним національним органом і пунктом зв'язку, відповідальним за направлення і одержання оповіщень та інформації в разі ядерної аварії. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1006 ( 1006-2001-п ) від 09.08.2001 )

2. Визначити Міністерство палива та енергетики компетентним національним органом і пунктом зв'язку, уповноваженим робити та одержувати прохання про допомогу і приймати пропозиції про допомогу в разі ядерної аварії або радіаційної аварійної ситуації. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 1006 ( 1006-2001-п ) від 09.08.2001 )

3. Державному комітетові ядерного регулювання і Міністерству палива та енергетики вжити заходів для виконання зобов'язань України згідно із Конвенцією про оперативне оповіщення про ядерну аварію ( 995_026 ) та Конвенцією про допомогу в разі ядерної аварії або радіаційної аварійної ситуації. ( Пункт 3 із змінами, внесеними згідно з Постановою КМ N 1006 ( 1006-2001-п ) від 09.08.2001 )

4. Міністерству закордонних справ довести цю постанову до відома депозитарію зазначених конвенцій - генерального директора МАГАТЕ.
