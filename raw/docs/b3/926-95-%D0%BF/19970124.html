КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 листопада 1995 р. N 926 Київ

( Постанова втратила чинність на підставі Постанови КМ N 81 ( 81-97-п ) від 24.01.97 )

Про внесення змін до пункту 1 постанови Кабінету Міністрів України від 8 червня 1995 р. N 398

Кабінет Міністрів України постановляє:

На часткову зміну пункту 1 постанови Кабінету Міністрів України від 8 червня 1995 р. N 398 ( 398-95-п ) "Про Державну міжвідомчу експертну комісію з електронних контрольно-касових апаратів" (ЗП України, 1995 р., N 8, ст.206) покласти загальне керівництво діяльністю Державної міжвідомчої експертної комісії з електронних контрольно-касових апаратів на Віце-прем'єр-міністра України Пинзеника В.М.

Затвердити головою зазначеної Комісії заступника Міністра економіки Яременка О.С., увільнивши від цих обов'язків Гуреєва В.М.
