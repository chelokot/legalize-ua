Кабінет Міністрів України; Розпорядження від 13.12.2005 № 515-р

Про схвалення Концепції підвищення безпеки діючих енергоблоків атомних електростанцій

Стан: Втратив чинність

Ідентифікатор: 515-2005-р

Текст документа від 19.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 13 грудня 2005 р. N 515-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1270 ( 1270-2011-п ) від 07.12.2011 }

Про схвалення Концепції підвищення безпеки діючих енергоблоків атомних електростанцій

1. Схвалити Концепцію підвищення безпеки діючих енергоблоків атомних електростанцій ( 515а-2005-р ).

2. Мінпаливенерго щороку до 1 березня інформувати Кабінет Міністрів України та засоби масової інформації про результати роботи з підвищення безпеки діючих енергоблоків атомних електростанцій.

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 29 серпня 2002 р. N 504 ( 504-2002-р ) "Про схвалення Комплексної програми модернізації та підвищення безпеки енергоблоків атомних електростанцій".

Прем'єр-міністр України Ю.ЄХАНУРОВ
