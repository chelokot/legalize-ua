Текст документа від 01.01.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 липня 2006 р. N 419-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 1051 ( 1051-2012-п ) від 17.10.2012 }

Про внесення змін до розпорядження Кабінету Міністрів України від 26 травня 2006 р. N 295

Доповнити розпорядження Кабінету Міністрів України від 26 травня 2006 р. N 295 ( 295-2006-р ) "Про передачу цілісного майнового комплексу державного підприємства "Центр державного земельного кадастру при Державному комітеті України по земельних ресурсах" до сфери управління Мін'юсту" словами "крім майна, необхідного Держкомзему для забезпечення ведення державного земельного кадастру і здійснення землеустрою" та абзацом такого змісту:

"Перелік майна, необхідного Держкомзему для забезпечення ведення державного земельного кадастру і здійснення землеустрою, визначається Мін'юстом разом з Держкомземом за результатами інвентаризації майна державного підприємства "Центр державного земельного кадастру при Державному комітеті України по земельних ресурсах", яка повинна бути проведена до 21 серпня 2006 року".

Прем'єр-міністр України Ю.ЄХАНУРОВ
