Про ліквідацію кафедри підготовки спеціалістів з питань цивільної оборони у Київському національному університеті будівництва і архітектури

Стан: Чинний

Ідентифікатор: 796-2008-п

Текст документа від 10.02.2012:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 3 вересня 2008 р. N 796 Київ

Про ліквідацію кафедри підготовки спеціалістів з питань цивільної оборони у Київському національному університеті будівництва і архітектури

{ Із змінами, внесеними згідно з Постановою КМ N 48 ( 48-2012-п ) від 01.02.2012 }

Кабінет Міністрів України постановляє:

1. Погодитися з пропозицією Міністерства з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи щодо ліквідації кафедри підготовки спеціалістів з питань цивільної оборони у Київському національному університеті будівництва і архітектури, утвореної відповідно до постанови Кабінету Міністрів України від 4 березня 1996 р. N 278 ( 278-96-п ) (ЗП України, 1996 р., N 8, ст. 245; Офіційний вісник України, 2002 р., N 1, ст. 4).

Міністерству з питань надзвичайних ситуацій та у справах захисту населення від наслідків Чорнобильської катастрофи разом з Міністерством освіти і науки здійснити заходи щодо ліквідації зазначеної кафедри.

{ Пункт 2 втратив чинність на підставі Постанови КМ N 48 ( 48-2012-п ) від 01.02.2012 }
