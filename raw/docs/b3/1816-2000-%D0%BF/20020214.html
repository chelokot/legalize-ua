Про доповнення переліку культових споруд - визначних пам'яток архітектури, які не підлягають передачі у постійне користування релігійним організаціям

Стан: Втратив чинність

Ідентифікатор: 1816-2000-п

Текст документа від 14.02.2002:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 13 грудня 2000 р. N 1816 Київ

( Постанова втратила чинність на підставі Постанови КМ N 137 ( 137-2002-п ) від 14.02.2002 )

Про доповнення переліку культових споруд - визначних пам'яток архітектури, які не підлягають передачі у постійне користування релігійним організаціям

Ураховуючи загальнодержавне значення Успенського собору та Михайлівського собору - визначних пам'яток історії та культури, відбудову яких завершено Київською міською державною адміністрацією на виконання Указу Президента України від 9 грудня 1995 р. N 1138 ( 1138/95 ) "Про заходи щодо відтворення видатних пам'яток історії та культури", постанови Кабінету Міністрів України від 23 квітня 1999 р. N 700 ( 700-99-п ) "Про Програму відтворення видатних пам'яток історії та культури України", Кабінет Міністрів України постановляє:

Включити до переліку культових споруд - визначних пам'яток архітектури, які не підлягають передачі у постійне користування релігійним організаціям, затвердженого постановою Ради Міністрів УРСР від 5 квітня 1991 р. N 83 ( 83-91-п ) (ЗП УРСР, 1991 р., N 4, ст. 33), у розділ "м. Київ" Успенський собор Національного Києво-Печерського історико-культурного заповідника, який входить до ансамблю споруд верхньої частини Києво-Печерської лаври XI - XIX ст. (охоронний номер 4) та Михайлівський собор (охоронний номер 711), який входить до складу комплексу споруд Михайлівського Золотоверхого монастиря.

Прем'єр-міністр України В.ЮЩЕНКО
