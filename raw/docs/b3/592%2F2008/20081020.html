Текст документа від 20.10.2008:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 912/2008 ( 912/2008 ) від 09.10.2008 }

Про тимчасове виконання обов'язків голів місцевих державних адміністрацій

З метою забезпечення стабільного ефективного виконання місцевими державними адміністраціями покладених на них Конституцією ( 254к/96-ВР ) та законами України повноважень постановляю:

1. Кабінету Міністрів України одночасно із внесенням подання про звільнення з посади голови місцевої державної адміністрації вносити Президентові України пропозиції щодо заступників голови місцевої державної адміністрації, на яких пропонується покласти тимчасове виконання обов'язків голови цієї місцевої державної адміністрації.

2. Тимчасове виконання обов'язків голови місцевої державної адміністрації припиняється з дня видання акта Президента України про призначення голови відповідної місцевої державної адміністрації.

3. Визнати таким, що втратив чинність, Указ Президента України від 29 грудня 2006 року N 1164 ( 1164/2006 ) "Про тимчасове виконання обов'язків голів місцевих державних адміністрацій".

4. Цей Указ набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 26 червня 2008 року N 592/2008
