КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 8 листопада 1996 р. N 1379 Київ

Про внесення змін до ставок ввізного мита на окремі види товарів та до деяких рішень Кабінету Міністрів України

( Із змінами, внесеними згідно з Постановами КМ N 1120 ( 1120-97-п ) від 08.10.97 N 1213 ( 1213-97-п ) від 03.11.97 N 1432 ( 1432-97-п ) від 20.12.97 N 257 ( 257-98-п ) від 02.03.98 N 693 ( 693-98-п ) від 18.05.98 N 845 ( 845-98-п ) від 09.06.98 N 1212 ( 1212-98-п ) від 03.08.98 )

Кабінет Міністрів України постановляє:

1. Внести зміни до ставок ввізного мита на окремі види товарів ( 4а-93 ) згідно з додатком.

2. У додатку до постанови Кабінету Міністрів України від 18 липня 1995 р. N 531 ( 531-95-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів та до деяких рішень Уряду України" (ЗП України, 1995 р., N 10, ст. 246) види товарів за кодами 85.01 52910, 90.32 89900, у додатку до постанови Кабінету Міністрів України від 28 грудня 1995 р. N 1054 ( 1054-95-п ) "Про зміни ставок ввізного мита на окремі види товарів, які не виробляються або виробляються в недостатній кількості в Україні" (ЗП України, 1996 р., N 4, ст.139) вид товару за кодом 48.19 20900 та у додатку до постанови Кабінету Міністрів України від 27 березня 1996 р. N 360 ( 360-96-п ) "Про внесення змін до ставок ввізного мита на окремі види товарів та до деяких рішень Уряду України" вид товару за кодом 72.02 49500 виключити.

3. Ця постанова набуває чинності через 10 днів після її опублікування у газеті "Урядовий кур'єр".
