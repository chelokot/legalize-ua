МІНІСТЕРСТВО ЕКОЛОГІЇ ТА ПРИРОДНИХ РЕСУРСІВ УКРАЇНИ

НАКАЗ

06.06.2003 N 92-М

Зареєстровано в Міністерстві юстиції України 26 червня 2003 р. за N 518/7839

{ Наказ втратив чинність на підставі Наказу Міністерства охорони навколишнього природного середовища N 241 ( z0459-08 ) від 12.05.2008 }

Про затвердження Порядку видачі погодження для отримання ліцензії на експорт та імпорт озоноруйнівних речовин і продукції, що їх містить

{ Із змінами, внесеними згідно з Наказом Міністерства охорони навколишнього природного середовища N 198 ( z0589-06 ) від 03.05.2006 }

На виконання постанови Кабінету Міністрів України від 25.12.2002 N 1939 ( 1939-2002-п ) "Про переліки товарів, експорт та імпорт яких підлягає квотуванню і ліцензуванню у 2003 році" НАКАЗУЮ:

1. Затвердити Порядок видачі погодження для отримання ліцензії на експорт та імпорт озоноруйнівних речовин і продукції, що їх містить (додається).

2. Надати Державній екологічній інспекції виняткове право видачі погоджень на експорт та імпорт озоноруйнівних речовин і продукції, що їх містить, та право видачі листів-роз'яснень, якщо продукція не містить озоноруйнівних речовин.

3. Надати Республіканському комітету Автономної Республіки Крим з екології та природних ресурсів, державним управлінням екології та природних ресурсів в областях, містах Києві та Севастополі, державній інспекції охорони Чорного моря, державній екологічній інспекції Азовського моря право видачі суб'єктам підприємницької діяльності, що зареєстровані у відповідних регіонах, листів-роз'яснень, якщо продукція не містить озоноруйнівних речовин, за контрактами (договорами), загальна вартість яких не перевищує 10 тис. доларів США.

4. Державній екологічній інспекції (П. Свирид) подати наказ на державну реєстрацію в Міністерство юстиції України та після державної реєстрації довести цей наказ до відома Міністерства економіки та з питань європейської інтеграції України, Державної митної служби України, територіальних органів Міністерства екології та природних ресурсів України.

5. Республіканському комітету Автономної Республіки Крим з екології та природних ресурсів, державним управлінням екології та природних ресурсів в областях, містах Києві та Севастополі, державним інспекціям охорони Чорного та Азовського морів щокварталу подавати до Державної екологічної інспекції інформацію про видані листи-роз'яснення.

6. Уважати таким, що втратив чинність, Порядок видачі погодження для отримання ліцензії на експорт та імпорт озоноруйнівних речовин і продукції, що їх містить, затверджений наказом Мінекоресурсів від 27.05.2002 N 197 ( z0498-02 ), зареєстрованим у Міністерстві юстиції України 12.06.2002 за N 498/6786.

7. Контроль за виконанням цього наказу покласти на начальника Державної екологічної інспекції - Головного державного інспектора України з охорони навколишнього природного середовища П. Свирида.
