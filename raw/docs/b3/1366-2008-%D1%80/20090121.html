{ Розпорядження втратило чинність на підставі Розпорядження КМ N 36-р ( 36-2009-р ) від 21.01.2009 }

{ Дію Розпорядження зупинено згідно з Указом Президента N 1160/2008 ( 1160/2008 ) від 15.12.2008 }

Про розміщення Одеських апеляційного та окружного адміністративних судів

Погодитися з пропозицією Державної судової адміністрації щодо розміщення Одеських апеляційного та окружного адміністративних судів у будівлях навчальних корпусів N 1 і 27 та приміщеннях корпусу N 3 колишнього Одеського інституту Сухопутних військ (військове містечко N 217) по Фонтанській дорозі, 14, у м. Одесі.

Міноборони забезпечити у місячний строк передачу зазначених об'єктів до сфери управління Державної судової адміністрації.

Прем'єр-міністр України Ю.ТИМОШЕНКО
