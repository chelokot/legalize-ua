{ Із змінами, внесеними згідно з Наказом Державного комітету статистики N 296 ( z0608-10 ) від 26.07.2010 }

Відповідно до статей 4, 14, 18 Закону України "Про державну статистику" ( 2614-12 ), з метою подальшого вдосконалення державних статистичних спостережень зі статистики цін та отримання повної, всебічної й об'єктивної статистичної інформації НАКАЗУЮ:

1. Затвердити Інструкцію щодо заповнення форми державного статистичного спостереження N 1-ціни (буд) "Звіт про ціни придбання матеріальних ресурсів у будівництві", що додається.

2. Цей наказ набирає чинності з 1 лютого 2010 року.

3. Департаменту статистики цін (Драговоз О.М.):

3.1. Подати цей наказ на державну реєстрацію до Міністерства юстиції України.

3.2. Довести Інструкцію, затверджену цим наказом, до відома територіальних органів державної статистики.

4. Визнати таким, що втратив чинність з 1 лютого 2010 року, наказ Держкомстату від 22.12.2008 N 513 ( z0400-09 ) "Про затвердження Інструкції щодо заповнення форми державного статистичного спостереження N 1-ціни (буд) "Звіт про ціни придбання матеріальних ресурсів у будівництві", зареєстрований у Міністерстві юстиції України 30.04.2009 за N 400/16416.

5. Контроль за виконанням цього наказу покласти на заступника Голови Остапчука Ю.М.

ЗАТВЕРДЖЕНО Наказ Держкомстату 05.10.2009 N 366

Зареєстровано в Міністерстві юстиції України 23 жовтня 2009 р. за N 975/16991

ІНСТРУКЦІЯ щодо заповнення форми державного статистичного спостереження N 1-ціни (буд) "Звіт про ціни придбання матеріальних ресурсів у будівництві"

I. Загальні положення

1.1. Заповнення форми державного статистичного спостереження N 1-ціни (буд) "Звіт про ціни придбання матеріальних ресурсів у будівництві" (далі - форма N 1-ціни (буд)) проводиться на підставі первинних облікових документів, оформлених в установленому законодавством порядку.

{ Пункт 1.1 розділу I із змінами, внесеними згідно з Наказом Державного комітету статистики N 296 ( z0608-10 ) від 26.07.2010 }

1.2. Відповідальною за достовірність наданої інформації згідно з чинним законодавством є особа, яка засвідчує підписом форму N 1-ціни (буд).

II. Порядок заповнення форми N 1-ціни (буд)

2.1. Усі показники форми N 1-ціни (буд) заповнюються у відповідних одиницях виміру (згідно з графою "В") за переліком, який включає 49 найменувань матеріальних ресурсів.

2.2. У графі "А" вказується порядковий номер конкретного матеріального ресурсу.

2.3. У графі "Б" за кожним видом матеріального ресурсу заповнюється не більше п'яти найменувань конкретних матеріальних ресурсів із зазначенням їхніх марок та технічних характеристик.

2.4. Якщо організацією було придбано більше п'яти найменувань конкретних матеріальних ресурсів одного виду, то відбираються п'ять, придбання яких здійснюється на постійній основі, великими за обсягом партіями, від одного й того ж постачальника. Не включаються до звіту матеріальні ресурси, які придбані за акційними цінами.

2.5. У графі 1 відображається ціна придбання за одиницю виміру кожного з найменувань конкретних матеріальних ресурсів, наведених у графі "Б", з двома десятковими знаками без податку на додану вартість із урахуванням витрат на транспортування та зберігання матеріальних ресурсів.

Витрати на транспортування включають усі затрати (крім урахованих у відпускній ціні постачальника) на перевезення залізничним, автомобільним та іншими видами транспорту, навантажувально-розвантажувальні роботи.

{ Пункт 2.6 розділу II виключено на підставі Наказу Державного комітету статистики N 296 ( z0608-10 ) від 26.07.2010 }
