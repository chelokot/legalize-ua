Стан: Втратив чинність

Ідентифікатор: 485-2001-р

Текст документа від 18.01.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 18 жовтня 2001 р. N 485-р Київ

Про міжвідомчу комісію з питань реформування системи фінансування дорожнього сектору

( Із змінами, внесеними згідно з Розпорядженнями КМ N 486-р ( 486-2002-р ) від 19.08.2002 N 25-р ( 25-2006-р ) від 18.01.2006 )

З метою виконання умов, що передують набранню чинності Кредитною угодою (Відновлення автомагістралі М06 та реформа фінансування дорожнього сектору) між Україною та Європейським банком реконструкції та розвитку ( 996_030 ), підписаною 11 грудня 2000 р., та для забезпечення координації робіт, пов'язаних з реалізацією проекту "Відновлення автомагістралі М06 та реформа фінансування дорожнього сектору", утворити міжвідомчу комісію з питань реформування системи фінансування дорожнього сектору у складі згідно з додатком.

Дозволяти голові міжвідомчої комісії вносити у разі потреби зміни до її складу.
