Київ

Про оформлення довгострокових віз для в’їзду в Україну громадянам Угорщини

Міністерству закордонних справ забезпечити оформлення на умовах взаємності довгострокових віз для в’їзду в Україну громадянам Угорщини за нульовою тарифною ставкою консульського збору.
