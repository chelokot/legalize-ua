ПОСТАНОВА від 22 листопада 2005 р. N 1107 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 757 ( 757-2008-п ) від 27.08.2008 }

Про збільшення розміру стипендії Президента України для молодих учених

Кабінет Міністрів України постановляє:

Збільшити до 300 гривень на місяць з 1 січня 2006 р. розмір стипендії Президента України для молодих учених, встановлений постановою Кабінету Міністрів України від 26 вересня 2002 р. N 1462 ( 1462-2002-п ) "Про розмір стипендії Президента України для молодих учених" (Офіційний вісник України, 2002 р., N 40, ст. 1862).
