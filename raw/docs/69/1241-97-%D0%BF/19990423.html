Про затвердження переліку пунктів пропуску для повітряного сполучення, через які дозволяється вивезення спирту етилового, та алкогольних напоїв, що експортуються

Стан: Втратив чинність

Ідентифікатор: 1241-97-п

Текст документа від 23.04.1999:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 листопада 1997 р. N 1241 Київ

Про затвердження переліку пунктів пропуску для повітряного сполучення, через які дозволяється вивезення спирту етилового, та алкогольних напоїв, що експортуються

( Із змінами, внесеними згідно з Постановою КМ N 683 ( 683-99-п ) від 23.04.99 )

Кабінет Міністрів України постановляє:

1. Затвердити перелік пунктів пропуску для повітряного сполучення, через які дозволяється вивезення спирту етилового, та алкогольних напоїв, що експортуються (додається). ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 683 ( 683-99-п ) від 23.04.99 )

2. Кожна відправка спирту етилового, та алкогольних напоїв, що експортуються, через пункти пропуску для повітряного сполучення підлягає погодженню з Державною митною службою у визначеному нею порядку. ( Пункт 2 із змінами, внесеними згідно з Постановою КМ N 683 ( 683-99-п ) від 23.04.99 )

3. Контроль за виконанням цієї постанови покласти на голову Державної митної служби Деркача Л.В.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 6 листопада 1997 р. N 1241
