Кабінет Міністрів України; Постанова, Перелік від 06.11.1997 № 1241

Про затвердження переліку пунктів пропуску для повітряного сполучення, через які дозволяється вивезення спирту етилового, та алкогольних напоїв, що експортуються

Стан: Втратив чинність

Ідентифікатор: 1241-97-п

Текст документа від 18.06.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 листопада 1997 р. N 1241 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 390 ( 390-2013-п ) від 29.05.2013 }

Про затвердження переліку пунктів пропуску для повітряного сполучення, через які дозволяється вивезення спирту етилового, та алкогольних напоїв, що експортуються

{ Із змінами, внесеними згідно з Постановами КМ N 683 ( 683-99-п ) від 23.04.99 N 512 ( 512-2011-п ) від 18.05.2011 }

Кабінет Міністрів України постановляє:

1. Затвердити перелік пунктів пропуску для повітряного сполучення, через які дозволяється вивезення спирту етилового, та алкогольних напоїв, що експортуються (додається). ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 683 ( 683-99-п ) від 23.04.99 )

{ Пункт 2 виключено на підставі Постанови КМ N 512 ( 512-2011-п ) від 18.05.2011 }

3. Контроль за виконанням цієї постанови покласти на голову Державної митної служби.

{ Пункт 3 із змінами, внесеними згідно з Постановою КМ N 512 ( 512-2011-п ) від 18.05.2011 }

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО

Інд. 52

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 6 листопада 1997 р. N 1241

ПЕРЕЛІК пунктів пропуску для повітряного сполучення, через які дозволяється вивезення спирту етилового, та алкогольних напоїв, що експортуються ( Назва переліку із змінами, внесеними згідно з Постановою КМ N 683 ( 683-99-п ) від 23.04.99 )
