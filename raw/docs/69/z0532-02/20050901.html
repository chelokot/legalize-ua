( Наказ втратив чинність на підставі Наказу Міністерства фінансів N 858 ( z1555-05 ) від 08.12.2005 )

Про внесення змін до схеми посадових та місячних окладів працівників Музею коштовного і декоративного каміння

На виконання постанови Кабінету Міністрів України від 10.01.2002 N 18 ( 18-2002-п ) "Про підвищення посадових окладів (ставок заробітної плати) працівників установ, закладів та організацій окремих галузей бюджетної сфери" НАКАЗУЮ:

1. Внести до схеми посадових та місячних окладів, затвердженої наказом Міністерства фінансів України від 30.07.2001 N 359 ( z0680-01 ) "Про схему посадових окладів працівників Музею коштовного і декоративного каміння, що фінансується з Державного бюджету", зареєстрованим у Міністерстві юстиції України 9 серпня 2001 року за N 680/5871, зміни, виклавши її в новій редакції, що додається.

2. Контроль за виконанням наказу покласти на заступника Державного секретаря Макацарія С.М.

Міністр І.О.Юшко

Додаток до наказу Міністерства фінансів України 30.07.2001 року N 359 ( z0680-01 ) (у редакції наказу Міністерства фінансів України від 18.06.2002 року N 437)
