Стан: Втратив чинність

Ідентифікатор: 189-2003-р

Текст документа від 26.12.2003:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 березня 2003 р. N 189-р Київ

( Розпорядження втратило чинність на підставі Розпорядження КМ N 814-р ( 814-2003-р ) від 26.12.2003 )

Про затвердження складу групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий термін і здійснення контролю за її виконанням

1. Затвердити склад групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий термін і здійснення контролю за її виконанням (додається).

2. Визнати такими, що втратили чинність:

пункт 1 розпорядження Кабінету Міністрів України від 12 січня 2001 р. N 1 ( 1-2001-р ) "Про ведення колективних переговорів з укладення Генеральної, галузевих і регіональних угод";

розпорядження Кабінету Міністрів України від 28 грудня 2001 р. N 620 ( 620-2001-р ) "Про затвердження нового складу групи повноважних представників Сторони власників та уповноважених ними органів, які об'єдналися для ведення колективних переговорів з укладення Генеральної угоди на новий термін і здійснення контролю за її виконанням".
