Про виділення коштів для здійснення заходів з підготовки та проведення Третьої щорічної конференції Міжнародної асоціації антикорупційних органів

Стан: Чинний

Ідентифікатор: 1252-2008-р

Текст документа від 17.09.2008:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 17 вересня 2008 р. N 1252-р Київ

Про виділення коштів для здійснення заходів з підготовки та проведення Третьої щорічної конференції Міжнародної асоціації антикорупційних органів

1. Виділити Мін'юсту 2922,5 тис. гривень для здійснення заходів з підготовки та проведення Третьої щорічної конференції Міжнародної асоціації антикорупційних органів, яка відбудеться 3-6 жовтня 2008 р. у м. Києві.

Мінфіну здійснити зазначені видатки за рахунок коштів резервного фонду державного бюджету ( 107-17 ).

2. Мін'юсту подати до 1 грудня 2008 р. Мінфіну та Державному казначейству звіт про використання коштів, виділених згідно з цим розпорядженням.

Прем'єр-міністр України Ю.ТИМОШЕНКО
