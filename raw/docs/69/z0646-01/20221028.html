{ Наказ втратив чинність на підставі Наказу Міністерства інфраструктури N 646 ( z1228-22 ) від 25.08.2022 }

Про внесення змін до Порядку справляння плати за проходження суден шлюзами Дніпровського каскаду

Відповідно до постанови Кабінету Міністрів України від 20.06.2000 N 994 ( 994-2000-п ) "Про внесення змін до постанови Кабінету Міністрів України від 22 лютого 1999 р. N 236" НАКАЗУЮ:

1. Пункт 3.1 Порядку справляння плати за проходження суден шлюзами Дніпровського каскаду, затвердженого наказом Міністерства транспорту України від 09.06.99 N 299 ( z0408-99 ) і зареєстрованого в Міністерстві юстиції України 24.06.99 за N 408/3701, викласти в новій редакції:

"Сума плати за одне шлюзування кожного судна, плавучої споруди нараховується відповідно до розмірів плати, затверджених постановою Кабінету Міністрів України від 22.02.99 N 236 ( 236-99-п ) "Про затвердження граничних розмірів плати за проходження суден шлюзами Дніпровського каскаду" (у редакції постанови Кабінету Міністрів України від 20.06.2000 N 994 ( 994-2000-п ). При цьому розмір плати збільшується на суму податку на додану вартість відповідно до законодавства".

2. Департаменту транспортної політики (Легенький Г.М.) разом з Департаментом нормативно-правового забезпечення (Логінова Л.М.) у встановленому порядку зареєструвати цей наказ у Міністерстві юстиції України.

3. Контроль за виконанням цього наказу покласти на Першого заступника Міністра транспорту Цибенка В.Г.
