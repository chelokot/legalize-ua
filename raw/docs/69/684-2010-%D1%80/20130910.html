{ Розпорядження втратило чинність на підставі Постанови КМ N 644 ( 644-2013-п ) від 01.08.2013 }

Про голову Міжвідомчої комісії з організації укладення та виконання угод про розподіл продукції

Затвердити Першого віце-прем'єр-міністра України Клюєва Андрія Петровича головою Міжвідомчої комісії з організації укладення та виконання угод про розподіл продукції, утвореної постановою Кабінету Міністрів України від 12 липня 2000 р. N 1119 ( 1119-2000-п ) (Офіційний вісник України, 2000 р., N 29, ст. 1216; 2008 р., N 27, ст. 861), увільнивши від цих обов'язків Турчинова Олександра Валентиновича.
