Кабінет Міністрів України; Розпорядження від 10.06.2009 № 626-р

Про повноваження на реалізацію військового майна

Стан: Чинний

Ідентифікатор: 626-2009-р

Текст документа від 08.07.2015:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 10 червня 2009 р. N 626-р Київ

Про повноваження на реалізацію військового майна

{ Із змінами, внесеними згідно з Розпорядженням КМ N 697-р ( 697-2015-р ) від 08.07.2015 }

Надати концерну "Техвоєнсервіс" повноваження на реалізацію на внутрішньому ринку військового майна, що придатне для подальшого використання, але не може бути застосовано у повсякденній діяльності військ, і надлишкового військового майна (крім нерухомого майна, військової зброї та боєприпасів до неї, вибухових речовин), а також на реалізацію продуктів утилізації військового майна на внутрішньому ринку.

{ Текст Розпорядження із змінами, внесеними згідно з Розпорядженням КМ N 697-р ( 697-2015-р ) від 08.07.2015 }
