Президент України; Указ від 19.12.2005 № 1811/2005

Про внесення змін та визнання такими, що втратили чинність, деяких указів Президента України

Стан: Чинний

Ідентифікатор: 1811/2005

Текст документа від 19.12.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про внесення змін та визнання такими, що втратили чинність, деяких указів Президента України

1. Внести до указів Президента України такі зміни:

1) пункт 4 Положення про Міністерство юстиції України, затвердженого Указом Президента України від 30 грудня 1997 року N 1396 ( 1396/97 ) (зі змінами, внесеними Указами від 15 вересня 1998 року N 1019 ( 1019/98 ), від 9 лютого 1999 року N 145 ( 145/99 ), від 31 липня 2000 року N 934 ( 934/2000 ), від 7 серпня 2001 року N 596 ( 596/2001 ), від 11 січня 2002 року N 12 ( 12/2002 ), від 27 грудня 2002 року N 1233 ( 1233/2002 ), від 17 лютого 2003 року N 134 ( 134/2003 ), від 21 серпня 2004 року N 965 ( 965/2004 ), від 28 вересня 2004 року N 1143 ( 1143/2004 ) та від 26 липня 2005 року N 1136 ( 1136/2005 ), доповнити підпунктом 22-1 такого змісту:

"22-1) здійснює відповідно до законодавства державну реєстрацію друкованих засобів масової інформації та інформаційних агентств як суб'єктів інформаційної діяльності";

2) у Положенні про Державний комітет телебачення і радіомовлення України, затвердженому Указом Президента України від 27 серпня 2003 року N 920 ( 920/2003 ) (зі змінами, внесеними Указом від 30 червня 2004 року N 696 ( 696/2004 ):

а) в абзаці другому пункту 1, абзаці другому пункту 3, підпункті 1 пункту 4 слова "державної мовної політики" виключити;

б) в абзаці третьому пункту 3 слова "реалізації державної мовної політики" виключити;

в) у пункті 4:

підпункт 21 виключити;

підпункт 23 викласти в такій редакції:

"23) вживає заходів щодо забезпечення розвитку та функціонування української мови як державної в інформаційній та видавничій сферах";

підпункт 24 виключити;

г) в абзаці першому пункту 11 слова "державної мови" виключити.

2. Визнати такими, що втратили чинність:

Указ Президента України від 5 квітня 2001 року N 233 ( 233/2001 ) "Про вдосконалення забезпечення реалізації державної мовної політики";

статтю 2 Указу Президента України від 3 січня 2002 року N 10 ( 10/2002 ) "Про внесення змін до Указів Президента України від 15 грудня 1999 року N 1573 та від 5 квітня 2001 року N 233".

3. Цей Указ набирає чинності з дня його опублікування, крім пункту 1 та абзацу другого підпункту "в" пункту 2 статті 1, які набирають чинності з 1 березня 2006 року.

Президент України В.ЮЩЕНКО

м. Київ, 19 грудня 2005 року N 1811/2005
