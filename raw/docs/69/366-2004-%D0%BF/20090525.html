Текст документа від 25.05.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 березня 2004 р. N 366 Київ

Деякі питання Міністерства у справах сім'ї, дітей та молоді

{ Із змінами, внесеними згідно з Постановами КМ N 1757 ( 1757-2004-п ) від 25.12.2004 N 954 ( 954-2008-п ) від 22.10.2008 N 464 ( 464-2009-п ) від 13.05.2009 }

Кабінет Міністрів України постановляє:

1. Прийняти пропозицію Міністерства у справах сім'ї, дітей та молоді щодо віднесення Міжнародного дитячого центру-комплексу "Золотий ключик", Українського молодіжного центру, Державного інституту проблем сім'ї та молоді і Державного підприємства "Інформаційно-ресурсний центр" до сфери управління Міністерства. ( Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1757 ( 1757-2004-п ) від 25.12.2004 )

2. Взяти до відома, що Міністерство у справах сім'ї, дітей та молоді розміщується в будинку по вул. Десятинній, 14, у м. Києві.

{ Пункт 3 втратив чинність на підставі Постанови КМ N 464 ( 464-2009-п ) від 13.05.2009 }
