Про затвердження Змін до Положення про порядок реєстрації приватної нотаріальної діяльності

Відповідно до Закону України "Про нотаріат" ( 3425-12 ), постанови Кабінету Міністрів України від 22.02.94 N 114 ( 114-94-п ) "Про затвердження Положення про Вищу кваліфікаційну комісію нотаріату" (у редакції постанови Кабінету Міністрів України від 14.03.2006 N 281 ( 281-2006-п ) та з метою вдосконалення порядку реєстрації приватної нотаріальної діяльності НАКАЗУЮ:

1. Затвердити Зміни до Положення про порядок реєстрації приватної нотаріальної діяльності, затвердженого наказом Міністерства юстиції України від 04.03.94 N 10/5 ( z0041-94 ), зареєстрованого у Міністерстві юстиції України 10.03.94 за N 41/250 (із змінами), що додаються.

2. Департаменту нотаріату та реєстрації адвокатських об'єднань (Круковес Н.):

2.1. Подати цей наказ на державну реєстрацію відповідно до Указу Президента України від 03.10.92 N 493 ( 493/92 ) "Про державну реєстрацію нормативно-правових актів міністерств та інших органів виконавчої влади" (із змінами).

2.2. Довести цей наказ до відома начальника Головного управління юстиції Міністерства юстиції України в Автономній Республіці Крим, начальників обласних, Київського та Севастопольського міських управлінь юстиції та забезпечити його належне застосування в роботі.

3. Контроль за виконанням наказу залишаю за собою.

ЗМІНИ до Положення про порядок реєстрації приватної нотаріальної діяльності

1. Пункт 1 Положення ( z0041-94 ) викласти в такій редакції:

"1. Реєстрація приватної нотаріальної діяльності провадиться Головним управлінням юстиції Міністерства юстиції України в Автономній Республіці Крим, обласними, Київським та Севастопольським міськими управліннями юстиції (далі - органи юстиції).

Реєстрація приватної нотаріальної діяльності здійснюється в межах установленої для кожного нотаріального округу граничної чисельності приватних нотаріусів".

2. Пункт 2 Положення ( z0041-94 ) викласти в такій редакції.

"2. Особа, яка має намір зареєструвати приватну нотаріальну діяльність, подає до відповідного органу юстиції:

заяву про реєстрацію приватної нотаріальної діяльності;

свідоцтво про право на заняття нотаріальною діяльністю;

копію наказу Міністерства юстиції України про перемогу в конкурсі на реєстрацію приватної нотаріальної діяльності;

дві фотокартки розміром 3х4 см.

У заяві про реєстрацію приватної нотаріальної діяльності повинно бути вказано адресу розташування робочого місця".

3. У пункті 3 Положення ( z0041-94 ) слова "До заяви додаються: свідоцтво про право на заняття нотаріальною діяльністю та його копія; дві фотокартки розміром 3х4 см" вилучити.

4. У пункті 7 Положення ( z0041-94 ) слова "друкується на машинці" замінити словами "виготовляється за допомогою загальнотехнічних засобів".

5. Пункт 14 Положення ( z0041-94 ) доповнити абзацом сьомим такого змісту:

"Про припинення нотаріальної діяльності та анулювання реєстраційного посвідчення орган юстиції повідомляє Вищу кваліфікаційну комісію нотаріату".
