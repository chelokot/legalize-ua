КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 11 жовтня 2002 р. N 574-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Про внесення зміни до складу міжвідомчої робочої групи для сприяння розв'язанню проблем, пов'язаних з ліквідацією комерційного акціонерного банку "Слов'янський"

Увести до складу міжвідомчої робочої групи для сприяння розв'язанню проблем, пов'язаних з ліквідацією комерційного акціонерного банку "Слов'янський", утвореної розпорядженням Кабінету Міністрів України від 27 червня 2001 р. N 262 ( 262-2001-р ), із змінами, внесеними розпорядженням Кабінету Міністрів України від 29 серпня 2002 р. N 498 ( 498-2002-р ):
