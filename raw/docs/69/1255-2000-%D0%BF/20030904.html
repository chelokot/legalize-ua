Про внесення змін до постанови Кабінету Міністрів України від 18 червня 1999 р. N 1065

( Із змінами, внесеними згідно з Постановами КМ N 1265 ( 1265-2001-п ) від 26.09.2001 N 658 ( 658-2002-п ) від 17.05.2002 N 1368 ( 1368-2003-п ) від 27.08.2003 N 1413 ( 1413-2003-п ) від 04.09.2003 )

Кабінет Міністрів України постановляє:

1. Затвердити перелік пріоритетних видів економічної діяльності на територіях пріоритетного розвитку в Донецькій області, для яких встановлено спеціальний режим інвестиційної діяльності, що додається.

( Пункт 2 виключено на підставі Постанови КМ N 1368 ( 1368-2003-п ) від 27.08.2003 )

3. Визнати такими, що втратили чинність:

пункт 1 (у частині затвердження переліку пріоритетних видів економічної діяльності на територіях пріоритетного розвитку в Донецькій області, для яких установлено спеціальний режим інвестиційної діяльності) та пункт 2 постанови Кабінету Міністрів України від 18 червня 1999 р. N 1065 ( 1065-99-п ) (Офіційний вісник України, 1999 р., N 25, ст. 1165);

розпорядження Кабінету Міністрів України від 29 жовтня 1999 р. N 1177 ( 1177-99-р ) (Офіційний вісник України, 1999 р., N 44, ст. 2192).
