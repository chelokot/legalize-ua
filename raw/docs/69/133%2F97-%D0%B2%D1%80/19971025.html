Верховна Рада України; Закон від 06.03.1997 № 133/97-ВР

Про внесення змін до Закону України "Про вибори народних депутатів України"

Стан: Втратив чинність

Ідентифікатор: 133/97-вр

Текст документа від 25.10.1997:

ЗАКОН УКРАЇНИ

( Закон втратив чинність на підставі Закону N 541/97-ВР від 24.09.97, ВВР, 1997, N 43, ст.280 )

Про внесення змін до Закону України "Про вибори народних депутатів України"

( Відомості Верховної Ради України (ВВР), 1997, N 18, ст.132 )

Верховна Рада України постановляє:

1. У Законі України "Про вибори народних депутатів України" ( 3623-12 ) (Відомості Верховної Ради України, 1993 р., N 48, ст.455; 1995 р., N 1, ст.4) статтю 52 виключити.

2. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 6 березня 1997 року N 133/97-ВР
