Кабінет Міністрів України; Розпорядження від 04.01.1999 № 13-р

Про передачу Комітету з нової медичної техніки МОЗ до сфери управління Держкоммедбіопрому

Стан: Втратив чинність

Ідентифікатор: 13-99-р

Текст документа від 11.05.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 4 січня 1999 р. N 13-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 617 ( 617-2006-п ) від 11.05.2006 }

Погодитися з пропозицією МОЗ і Держкоммедбіопрому про передачу Комітету з нової медичної техніки МОЗ до сфери управління Держкоммедбіопрому.

Передачу здійснити у порядку, передбаченому постановою Кабінету Міністрів України від 21 вересня 1998 р. N 1482 ( 1482-98-п ) "Про передачу об'єктів права державної та комунальної власності".

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
