УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Дію Указу припинено згідно із Законом N 2473-VIII ( 2473-19 ) від 21.06.2018, ВВР, 2018, N 30, ст.239 }

Про внесення змін до Указу Президента України від 16 березня 1995 року N 227

З метою підтримки платоспроможності сільськогосподарських товаровиробників постановляю:

1. Доповнити частину першу статті 2 Указу Президента України від 16 березня 1995 року N 227 ( 227/95 ) "Про заходи щодо нормалізації платіжної дисципліни в народному господарстві України" (в редакції Указу Президента України від 31 березня 1995 року ( 277/95 ) N 277) реченням такого змісту: "З сільськогосподарських товаровиробників пеня за несвоєчасну сплату заборгованості за електроенергію, що виникла з 10 квітня 1995 року, не стягується".

2. Цей Указ набирає чинності з дня його підписання.

Президент України Л.КУЧМА

м.Київ, 9 грудня 1995 року N 1139/95
