Про внесення змін до Указу Президента України від 5 вересня 2001 року N 797

Стан: Втратив чинність

Ідентифікатор: 624/2004

Текст документа від 13.07.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 1102/2005 ( 1102/2005 ) від 13.07.2005 )

Про внесення змін до Указу Президента України від 5 вересня 2001 року N 797

Внести до Указу Президента України від 5 вересня 2001 року N 797 ( 797/2001 ) "Про додаткові заходи щодо прискорення вступу України до Світової організації торгівлі" (зі змінами, внесеними Указом від 28 травня 2003 року N 455 ( 455/2003 ) такі зміни:

1. Статтю 4 виключити.

2. У частині першій статті 6 слова "Державного секретаря з питань європейської інтеграції Міністерства економіки та з питань європейської інтеграції України" замінити словами "першого заступника Міністра економіки та з питань європейської інтеграції України".

Президент України Л.КУЧМА

м. Київ, 7 червня 2004 року N 624/2004
