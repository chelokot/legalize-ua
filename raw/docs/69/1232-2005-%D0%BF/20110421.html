Питання Державного казначейства України

Стан: Чинний

Ідентифікатор: 1232-2005-п

Текст документа від 21.04.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 грудня 2005 р. N 1232 Київ

Питання Державного казначейства України

{ Із змінами, внесеними згідно з Постановами КМ N 676 ( 676-2007-п ) від 26.04.2007 N 346 ( 346-2011-п ) від 28.03.2011 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність одночасно з набранням чинності Указом Президента ( 460/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

2. Внести до постанов Кабінету Міністрів України від 24 вересня 2005 р. N 983 ( 983-2005-п ) "Про утворення урядового органу державного управління у складі Міністерства фінансів" (Офіційний вісник України, 2005 р., N 39, ст. 2484) та від 12 жовтня 2005 р. N 1005 ( 1005-2005-п ) "Про призначення Шлапака О.В. головою Державного казначейства" зміни, що додаються.

3. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

{ Пункт 4 втратив чинність одночасно з набранням чинності Указом Президента ( 460/2011 ) на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 34

{ Положення про Державне казначейство України втратило чинність на підставі Постанови КМ N 346 ( 346-2011-п ) від 28.03.2011 }

ЗАВЕРДЖЕНО постановою Кабінету Міністрів України від 21 грудня 2005 р. N 1232

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 24 вересня 2005 р. N 983 ( 983-2005-п ) та від 12 жовтня 2005 р. N 1005 ( 1005-2005-п )

1. У постанові Кабінету Міністрів України від 24 вересня 2005 р. N 983 ( 983-2005-п ):

пункт 2 виключити;

у тексті постанови слова "Державне казначейство" в усіх відмінках замінити словами "Державне казначейство України" у відповідному відмінку.

2. У назві та тексті постанови Кабінету Міністрів України від 12 жовтня 2005 р. N 1005 ( 1005-2005-п ) слова "Державного казначейства" замінити словами "Державного казначейства України".

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 21 грудня 2005 р. N 1232

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 31 липня 1995 р. N 590 ( 590-95-п ) "Питання Державного казначейства" (ЗП України, 1995 р., N 11, ст. 262).

2. Постанова Кабінету Міністрів України від 28 червня 1997 р. N 656 ( 656-97-п ) "Про внесення зміни до Положення про Державне казначейство" (Офіційний вісник України, 1997 р., число 27, с. 124).

3. Постанова Кабінету Міністрів України від 17 лютого 1999 р. N 180 ( 180-99-п ) "Про деякі питання діяльності Державного казначейства України" (Офіційний вісник України, 1999 р., N 7, ст. 251).

4. Постанова Кабінету Міністрів України від 19 квітня 1999 р. N 611 ( 611-99-п ) "Про внесення доповнень до постанови Кабінету Міністрів України від 17 лютого 1999 р. N 180" (Офіційний вісник України, 1999 р., N 16, ст. 640).

5. Постанова Кабінету Міністрів України від 18 травня 1999 р. N 865 ( 865-99-п ) "Про доповнення пункту 1 постанови Кабінету Міністрів України від 17 лютого 1999 р. N 180" (Офіційний вісник України, 1999 р., N 21, ст. 953).
