Текст документа від 04.10.1995:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 23 серпня 1994 р. N 581 Київ

( Постанова втратила чинність на підставі Постанови КМ N 782 ( 782-95-п ) від 04.10.95 )

Про внесення змін до Положення про порядок проведення конкурсу при прийнятті осіб на роботу до органів державної виконавчої влади

Кабінет Міністрів України ПОСТАНОВЛЯЄ:

Пункт 15 Положення про порядок проведення конкурсу при прийнятті осіб на роботу до органів державної виконавчої влади, затвердженого постановою Кабінету Міністрів України від 20 грудня 1993 р. N 1047 ( 1047-93-п ) "Про порядок проведення конкурсу при прийнятті осіб на роботу до органів державної виконавчої влади" (ЗП України, 1994 р., N 4, ст.101) викласти в такій редакції:

"15. Підставою для укладення трудового договору керівником з переможцем конкурсу є рішення комісії про переможця конкурсу.

Керівник приймає рішення про стажування чи зарахування до кадрового резерву інших учасників конкурсу".

Прем'єр-міністр України В.МАСОЛ
