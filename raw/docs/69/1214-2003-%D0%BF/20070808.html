Деякі питання Координаційного комітету з підготовки та проведення щорічного Сорочинського ярмарку

Стан: Втратив чинність

Текст документа від 08.08.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 6 серпня 2003 р. N 1214 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1005 ( 1005-2007-п ) від 08.08.2007 }

Деякі питання Координаційного комітету з підготовки та проведення щорічного Сорочинського ярмарку

Кабінет Міністрів України постановляє:

1. На зміну пункту 1 постанови Кабінету Міністрів України від 19 серпня 2002 р. N 1202 ( 1202-2002-п ) "Деякі питання Сорочинського ярмарку" затвердити Віце-прем'єр-міністра України Кириленка Івана Григоровича головою Координаційного комітету з підготовки та проведення Сорочинського ярмарку.

2. Покласти на голову Координаційного комітету з підготовки та проведення Сорочинського ярмарку контроль за виконанням постанови Кабінету Міністрів України від 30 квітня 1999 р. N 741 ( 741-99-п ) "Про Сорочинський ярмарок".

3. Визнати таким, що втратив чинність, пункт 8 постанови Кабінету Міністрів України від 30 квітня 1999 р. N 741 ( 741-99-п ).
