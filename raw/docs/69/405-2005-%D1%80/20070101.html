Про створення спеціальної мережі стільникового зв'язку Національної системи конфіденційного зв'язку

Стан: Чинний

Ідентифікатор: 405-2005-р

Текст документа від 01.01.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 24 вересня 2005 р. N 405-р Київ

Про створення спеціальної мережі стільникового зв'язку Національної системи конфіденційного зв'язку

{ Із змінами, внесеними згідно з Постановою КМ N 1700 ( 1700-2006-п ) від 08.12.2006 }

1. Погодитися з пропозицією СБУ щодо створення спеціальної мережі стільникового зв'язку Національної системи конфіденційного зв'язку на базі державного підприємства "Українські спеціальні системи".

2. Департаменту спеціальних телекомунікаційних систем та захисту інформації СБУ:

розробити та затвердити у місячний строк Положення про спеціальну мережу стільникового зв'язку Національної системи конфіденційного зв'язку і граничні тарифи на послуги спеціального стільникового зв'язку;

забезпечити створення, розвиток, функціонування мережі та надання державним підприємством "Українські спеціальні системи" послуг спеціального стільникового зв'язку міністерствам, іншим центральним та місцевим органам виконавчої влади відповідно до тарифів.

3. СБУ під час складання проекту Державного бюджету України на відповідний рік передбачити видатки для фінансування заходів із створення, розвитку та забезпечення функціонування спеціальної мережі стільникового зв'язку.

4. З 1 січня 2007 р. виконання завдань, передбачених пунктами 2 і 3 цього розпорядження, покласти на Адміністрацію Держспецзв'язку.

{ Розпорядження доповнено пунктом 4 згідно з Постановою КМ N 1700 ( 1700-2006-п ) від 08.12.2006 }

Прем'єр-міністр України Ю.ЄХАНУРОВ
