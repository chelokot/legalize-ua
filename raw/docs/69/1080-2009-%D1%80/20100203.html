Кабінет Міністрів України; Розпорядження від 31.08.2009 № 1080-р

Про здійснення у 2009 році попередньої оплати будівельних матеріалів, конструкцій, виробів, необхідних для виконання робіт з будівництва стадіону в м. Львові

Стан: Чинний

Ідентифікатор: 1080-2009-р

Текст документа від 03.02.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 31 серпня 2009 р. N 1080-р Київ

Про здійснення у 2009 році попередньої оплати будівельних матеріалів, конструкцій, виробів, необхідних для виконання робіт з будівництва стадіону в м. Львові

{ Із змінами, внесеними згідно з Розпорядженням КМ N 245-р ( 245-2010-р ) від 03.02.2010 }

1. Погодитися з пропозицією Мінсім'ямолодьспорту та Львівської облдержадміністрації щодо здійснення у 2009 році попередньої оплати будівельних матеріалів, конструкцій, виробів, необхідних для виконання робіт з будівництва стадіону в м. Львові по вул. Стрийській-Кільцевій дорозі, за рахунок бюджетних коштів ( 835-17 ) у сумі 50 млн. гривень на строк до шести місяців.

{ Пункт 1 із змінами, внесеними згідно з Розпорядженням КМ N 245-р ( 245-2010-р ) від 03.02.2010 }

2. Державному казначейству здійснити попередню оплату зазначених у пункті 1 цього розпорядження будівельних матеріалів, конструкцій, виробів відповідно до укладених договорів і титулу будови, затвердженого в установленому порядку.

Прем'єр-міністр України Ю.ТИМОШЕНКО
