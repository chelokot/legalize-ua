КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 червня 1999 р. N 984 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1667 ( 1667-99-п ) 13.09.99 )

Про виділення коштів Севастопольській міській державній адміністрації для придбання тролейбусів

Кабінет Міністрів України постановляє:

1. Виділити у 1999 році Севастопольській міській державній адміністрації 900 тис. гривень для придбання двох тролейбусів, виготовлених виробничим об'єднанням "Південмаш" (м. Дніпропетровськ).

Міністерству фінансів профінансувати зазначені витрати в межах загальних обсягів капітальних вкладень, одержаних від централізації у державному бюджеті 10 відсотків суми амартизаційних відрахувань відповідно до Закону України від 29 грудня 1998 р. "Про внесення змін до Закону України "Про оподаткування прибутку підприємств" ( 371-14 ) та Закону України "Про Державний бюджет України на 1999 рік" ( 378-14 ).

2. Міністерству економіки разом з Міністерством фінансів за підсумками роботи народного господарства у першому півріччі 1999 р. підготувати пропозиції про внесення змін до постанови Кабінету Міністрів України від 23 березня 1999 р. N 452 ( 452-99-п ) "Про розподіл державних централізованих капітальних вкладень та переліки об'єктів, що фінансуються за їх рахунок у 1999 році", передбачивши приведення обсягів капітальних вкладень у відповідність із фактичними видатками державного бюджету.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
