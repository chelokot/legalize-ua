КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 1 квітня 2005 р. N 82-р Київ

{ Розпорядження втратило чинність на підставі Розпорядження КМ N 143-р ( 143-2011-р ) від 23.02.2011 }

Про внесення змін у додаток до розпорядження Кабінету Міністрів України від 24 лютого 2003 р. N 77

Внести у додаток до розпорядження Кабінету Міністрів України від 24 лютого 2003 р. N 77 ( 77-2003-р ) "Про перелік офшорних зон" (Офіційний вісник України, 2003 р., N 9, ст. 401) такі зміни:

у розділі "Центральна Америка" слово "Панама" виключити;

розділ "Європа" після слова "Гібралтар" доповнити словом "Кіпр".

Прем'єр-міністр України Ю.ТИМОШЕНКО
