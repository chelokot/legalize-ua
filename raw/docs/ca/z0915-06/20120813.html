Про встановлення заохочувальних відзнак Національного космічного агентства України

Відповідно до Указу Президента України від 18 листопада 1996 року N 1094 ( 1094/96 ) "Про відомчі заохочувальні відзнаки" та з метою вшанування працівників підприємств, організацій і установ космічної галузі України за багаторічну, бездоганну та плідну роботу на благо нашої держави НАКАЗУЮ:

1. Установити заохочувальні відзнаки Національного космічного агентства України (далі - НКАУ):

"Нагрудний знак О.М. Макарова" ( va689530-06 );

"Нагрудний знак М.К. Янгеля" ( va689530-06 ).

2. Затвердити:

Положення про заохочувальну відзнаку Національного космічного агентства України "Нагрудний знак О.М. Макарова";

Положення про заохочувальну відзнаку Національного космічного агентства України "Нагрудний знак М.К. Янгеля" ( z0916-06 );

Опис заохочувальної відзнаки Національного космічного агентства України "Нагрудний знак О.М. Макарова";

Опис заохочувальної відзнаки Національного космічного агентства України "Нагрудний знак М.К. Янгеля" ( z0916-06 ) (додаються).

3. Начальнику управління справами Бойку Г.С. здійснити у встановленому порядку реєстрацію заохочувальних відзнак НКАУ в Комісії державних нагород та геральдики при Президентові України.

4. Організаційне забезпечення заходів щодо нагородження заохочувальними відзнаками НКАУ "Нагрудний знак О.М. Макарова" ( va689530-06 ) та "Нагрудний знак М.К. Янгеля" ( va689530-06 ) покласти на начальника відділу кадрів Ульяненка О.А.

5. Контроль за виконанням наказу покласти на заступника Генерального директора Кузнєцова Е.І.

В.о. Генерального директора В.Г.Комаров

ЗАТВЕРДЖЕНО Наказ НКАУ 18.07.2006 N 200

Зареєстровано в Міністерстві юстиції України 1 серпня 2006 р. за N 915/12789

ПОЛОЖЕННЯ про заохочувальну відзнаку Національного космічного агентства України "Нагрудний знак О.М. Макарова"

1. Заохочувальна відзнака Національного космічного агентства України (далі - НКАУ) "Нагрудний знак О.М.Макарова" ( va689530-06 ) (далі - Нагрудний знак) запроваджена для вшанування працівників на підприємствах, установах та організаціях космічної галузі України за:

вагомий особистий внесок щодо впровадження космічних технологій у створення та виготовлення високотехнологічної цивільної продукції;

особистий творчий внесок у вирішення складних технічних проблем при створенні та випробуваннях ракетно-космічної техніки;

розробку програм підготовки та проведення випробувань ракет-носіїв, космічних апаратів, засобів наземного обладнання;

високі результати при експлуатації ракетно-космічної техніки;

особистий творчий внесок в реалізацію вітчизняних та міжнародних космічних проектів і програм;

значний внесок у підготовку кадрів, активну діяльність щодо пропаганди історії та досягнень космічної галузі.

2. Нагрудним знаком ( va689530-06 ) нагороджуються працівники Національного космічного агентства України, підприємств, установ та організацій космічної галузі України, а також працівники інших міністерств, відомств, підпорядкованих їм підприємств, які активно сприяють розвитку космічної галузі.

3. Нагрудним знаком ( va689530-06 ) нагороджуються працівники, які сумлінно пропрацювали на підприємствах, установах та організаціях не менше 10 років.

4. Висунення кандидатур для нагородження Нагрудним знаком ( va689530-06 ) здійснюється трудовим колективом, де працює особа, яку представляють до заохочення.

На представленого до нагородження Нагрудним знаком ( va689530-06 ) складається подання, яке після ухвалення трудовим колективом підприємства, установи, організації направляється до НКАУ.

5. Рішення про нагородження приймається Колегією Національного космічного агентства України та затверджується наказом НКАУ.

6. Особі, нагородженій Нагрудним знаком ( va689530-06 ), видається посвідчення за підписом Генерального директора НКАУ.

7. Вручення Нагрудного знака ( va689530-06 ) здійснюється Генеральним директором НКАУ або за його дорученням членами Колегії НКАУ та приурочується до урочистих дат (Загальнодержавні свята, Дня працівника ракетно-космічної галузі України, ювілейні дати працівників, підприємств, установ, організацій тощо).

8. Нагородженому Нагрудним знаком ( va689530-06 ) виплачується грошова винагорода в розмірі двох посадових окладів (на підприємствах, установах та організаціях - за рахунок підприємств, установ та організацій, а працівникам НКАУ - за рахунок кошторису витрат на його утримання).

9. Відомості про нагородження Нагрудним знаком ( va689530-06 ) заносяться у трудову книжку працівника, у якій робиться відповідний запис із зазначенням дати та номера наказу НКАУ.

10. Нагрудний знак ( va689530-06 ) носиться з правого боку грудей і розміщується нижче знаків державних нагород України.

11. Працівник може бути нагороджений Нагрудним знаком ( va689530-06 ) лише один раз. Утрачений Нагрудний знак повторно не видається.

В.о. Начальника управління справами НКАУ О.К.Седлецький

ОПИС заохочувальної відзнаки Національного космічного агентства України "Нагрудний знак О.М. Макарова"

Заохочувальна відзнака Національного космічного агентства України "Нагрудний знак О.М. Макарова" ( va689530-06 ) (далі - нагрудний знак) виготовляється з позолоченої латуні.

Нагрудний знак ( va689530-06 ) має форму круга жовтого металу з вміщеним на аверсі рельєфним погрудним зображенням О.М. Макарова.

У центрі зворотного боку нагрудного знака ( va689530-06 ) (реверса) розміщене рельєфне зображення емблеми Національного космічного агентства України, увінчане рельєфним написом у дві строки: "О.М. МАКАРОВ" та "1906-1999".

З обох боків краї нагрудного знака ( va689530-06 ) прикрашені рельєфним зображенням круглого лаврового вінка.

За допомогою вушка і кільця нагрудний знак ( va689530-06 ) з'єднується з планкою. Планка являє собою фігурну пластину жовтого металу, декоровану шовковою муаровою стрічкою з рельєфною лавровою гілкою жовтого металу, а також - вписаною у коло композицією у вигляді космічної ракети, покладеної на 8-променеву зірку.

Діаметр нагрудного знаку - 22 мм. Розмір планки - 24 х 16 мм.

Кріплення відзнаки - два цангові зажими.
