Про зміни у складі Комісії при Президентові України з питань громадянства

Стан: Втратив чинність

Ідентифікатор: 488/2004

Текст документа від 30.04.2005:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 740/2005 ( 740/2005 ) від 30.04.2005 )

Про зміни у складі Комісії при Президентові України з питань громадянства

Внести до складу Комісії при Президентові України з питань громадянства, затвердженого Указом Президента України від 9 грудня 1994 року N 746 ( 746/94 ) (зі змінами, внесеними Указами від 22 квітня 1996 року N 275 ( 275/96 ), від 6 листопада 1997 року N 1254 ( 1254/97 ), від 13 жовтня 1998 року N 1135 ( 1135/98 ), від 6 березня 1999 року N 238 ( 238/99 ), від 7 червня 2000 року N 770 ( 770/2000 ), від 28 лютого 2001 року N 120 ( 120/2001 ), від 15 листопада 2001 року N 1094 ( 1094/2001 ) та від 8 жовтня 2002 року N 911 ( 911/2002 ), такі зміни:

1. Увести до складу Комісії таких осіб:

БРИТЧЕНКО - Керівник Управління з питань

Сергій Петрович громадянства Адміністрації Президента України, заступник Голови Комісії

ДАВИДЕНКО - директор Державного департаменту у

Віктор Михайлович справах громадянства, імміграції та реєстрації фізичних осіб Міністерства внутрішніх справ України

НАЛИВАЙЧЕНКО - заступник Міністра закордонних справ Валентин Олександрович України.

2. Затвердити у складі Комісії таких осіб:

ЗАЄЦЬ - перший заступник Міністра юстиції

Анатолій Павлович України - керівник апарату

СУБОТЕНКО - завідувач сектора по забезпеченню

Валентина Павлівна діяльності Комісії з питань громадянства Управління з питань громадянства Адміністрації Президента України

ШИШОЛІН - перший заступник Голови Державної

Павло Анатолійович прикордонної служби України - директор Департаменту охорони державного кордону.

3. Вивести зі складу зазначеної Комісії Рудька М.О., Моцика О.Ф., Перова О.О.

Президент України Л.КУЧМА
