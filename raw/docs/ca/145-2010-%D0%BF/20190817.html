КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 лютого 2010 р. N 145 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 722 ( 722-2019-п ) від 14.08.2019 }

Про внесення зміни до пункту 1 Порядку визначення виробників і покупців спирту та здійснення контролю за його обігом

Кабінет Міністрів України постановляє:

У пункті 1 Порядку визначення виробників і покупців спирту та здійснення контролю за його обігом, затвердженого постановою Кабінету Міністрів України від 29 серпня 2002 р. N 1266 ( 1266-2002-п ) (Офіційний вісник України, 2002 р., N 36, ст. 1684; 2003 р., N 14, ст. 623; 2004 p., N 12, ст. 746, N 27, ст. 1788, N 51, ст. 3352; 2005 р., N 15, ст. 765; 2006 р., N 23, ст. 1715; 2007 р., N 39, ст. 1554; 2008 р., N 100, ст. 3318; 2009 р., N 22, ст. 697), слова "високооктанової кисневмісної добавки до бензинів" замінити словом "біоетанолу".
