Кабінет Міністрів України; Постанова, Перелік від 28.12.2011 № 1374

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань спрощеної системи оподаткування, обліку та звітності суб'єктів малого підприємництва

Стан: Чинний

Ідентифікатор: 1374-2011-п

Текст документа від 28.12.2011:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 28 грудня 2011 р. N 1374 Київ

Про визнання такими, що втратили чинність, деяких постанов Кабінету Міністрів України з питань спрощеної системи оподаткування, обліку та звітності суб'єктів малого підприємництва

Кабінет Міністрів України постановляє:

1. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України з питань спрощеної системи оподаткування, обліку та звітності суб'єктів малого підприємництва згідно з переліком, що додається.

2. Ця постанова набирає чинності з 1 січня 2012 року.

Прем'єр-міністр України М.АЗАРОВ

Інд. 70

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 28 грудня 2011 р. N 1374

ПЕРЕЛІК постанов Кабінету Міністрів України з питань спрощеної системи оподаткування, обліку та звітності суб'єктів малого підприємства, що втратили чинність

1. Постанова Кабінету Міністрів України від 16 березня 2000 р. N 507 ( 507-2000-п ) "Про роз'яснення Указу Президента України від 3 липня 1998 р. N 727" (Офіційний вісник України, 2000 р., N 12, ст. 461).

2. Пункт 14 змін, що вносяться до постанов Кабінету Міністрів України, затверджених постановою Кабінету Міністрів України від 6 травня 2001 р. N 450 ( 450-2001-п ) (Офіційний вісник України, 2001 р., N 20, ст. 856).

3. Постанова Кабінету Міністрів України від 19 березня 2008 р. N 222 ( 222-2008-п ) "Про доповнення постанови Кабінету Міністрів України від 16 березня 2000 р. N 507" (Офіційний вісник України, 2008 р., N 23, ст. 696).

4. Постанова Кабінету Міністрів України від 28 січня 2009 р. N 45 ( 45-2009-п ) "Про скасування постанови Кабінету Міністрів України від 20 грудня 2008 р. N 1118" (Офіційний вісник України, 2009 р., N 8, ст. 244).

5. Постанова Кабінету Міністрів України від 4 лютого 2009 р. N 67 ( 67-2009-п ) "Про доповнення постанови Кабінету Міністрів України від 28 січня 2009 р. N 45" (Офіційний вісник України, 2009 р., N 9, ст. 274).

6. Постанова Кабінету Міністрів України від 27 грудня 2010 р. N 1196 ( 1196-2010-п ) "Про внесення змін до постанови Кабінету Міністрів України від 16 березня 2000 р. N 507" (Офіційний вісник України, 2010 р., N 100, ст. 3560).
