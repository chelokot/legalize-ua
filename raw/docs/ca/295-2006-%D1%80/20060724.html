Кабінет Міністрів України; Розпорядження від 26.05.2006 № 295-р

Про передачу цілісного майнового комплексу державного підприємства "Центр державного земельного кадастру при Державному комітеті України по земельних ресурсах" до сфери управління Мін'юсту

Стан: Втратив чинність

Ідентифікатор: 295-2006-р

Текст документа від 24.07.2006:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 травня 2006 р. N 295-р Київ

Про передачу цілісного майнового комплексу державного підприємства "Центр державного земельного кадастру при Державному комітеті України по земельних ресурсах" до сфери управління Мін'юсту

{ Із змінами, внесеними згідно з Розпорядженням КМ N 419-р ( 419-2006-р ) від 24.07.2006 }

Прийняти пропозицію Мін'юсту щодо передачі цілісного майнового комплексу державного підприємства "Центр державного земельного кадастру при Державному комітеті України по земельних ресурсах" (м. Київ, вул. Хрещатик, 32а) до сфери управління зазначеного Міністерства, крім майна, необхідного Держкомзему для забезпечення ведення державного земельного кадастру і здійснення землеустрою. { Абзац із змінами, внесеними згідно з Розпорядженням КМ N 419-р ( 419-2006-р ) від 24.07.2006 }

Перелік майна, необхідного Держкомзему для забезпечення ведення державного земельного кадастру і здійснення землеустрою, визначається Мін'юстом разом з Держкомземом за результатами інвентаризації майна державного підприємства "Центр державного земельного кадастру при Державному комітеті України по земельних ресурсах", яка повинна бути проведена до 21 серпня 2006 року. { Розпорядження доповнено абзацом згідно з Розпорядженням КМ N 419-р ( 419-2006-р ) від 24.07.2006 }
