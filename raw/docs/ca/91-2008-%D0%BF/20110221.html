ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 27 лютого 2008 р. N 91

ПОРЯДОК використання коштів, передбачених у державному бюджеті для здійснення заходів з охорони і захисту, раціонального використання лісів, наданих у постійне користування агропромисловим підприємствам

{ Назва Порядку із змінами, внесеними згідно з Постановою КМ N 96 ( 96-2011-п ) від 07.02.2011 }

{ У тексті Порядку слово "Мінагрополітики" замінено словами "Міністерство аграрної політики та продовольства" у відповідному відмінку згідно з Постановою КМ N 96 ( 96-2011-п ) від 07.02.2011 }

1. Цей Порядок визначає механізм використання коштів, передбачених у державному бюджеті Міністерству аграрної політики та продовольства за програмою "Заходи з охорони і захисту, раціонального використання лісів, наданих в постійне користування агропромисловим підприємствам" (далі - бюджетні кошти).

Одержувачами бюджетних коштів є агропромислові підприємства, що належать до сфери управління Міністерства аграрної політики та продовольства. { Абзац другий пункту 1 із змінами, внесеними згідно з Постановою КМ N 446 ( 446-2010-п ) від 16.06.2010 }

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 96 ( 96-2011-п ) від 07.02.2011 }

2. Бюджетні кошти спрямовуються на здійснення заходів з охорони, захисту і раціонального використання лісів, наданих у постійне користування агропромисловим підприємствам (далі - заходи), відповідно до Державної цільової програми "Ліси України" на 2010-2015 роки, затвердженої постановою Кабінету Міністрів України від 16 вересня 2009 р. N 977 ( 977-2009-п ) (Офіційний вісник України, 2009 р., N 72, ст. 2475), та переліку робіт, що зазначені в додатку.

{ Пункт 2 в редакції Постанови КМ N 446 ( 446-2010-п ) від 16.06.2010 }

3. Міністерство аграрної політики та продовольства за погодженням з Мінфіном здійснює розподіл бюджетних коштів між агропромисловими підприємствами у такому співвідношенні:

70 відсотків - для виконання заходів у лісах державної власності пропорційно їх площі станом на 1 січня відповідного року; { Абзац другий пункту 3 із змінами, внесеними згідно з Постановою КМ N 96 ( 96-2011-п ) від 07.02.2011 }

30 відсотків - для оплати робіт, пов'язаних з виготовленням державних актів на право постійного користування земельними ділянками лісового фонду пропорційно обсягам робіт, визначеним у заявках агропромислових підприємств.

Міністерство аграрної політики та продовольства за погодженням з Мінфіном може здійснювати за підсумками дев'яти місяців поточного року перерозподіл невикористаних бюджетних коштів між агропромисловими підприємствами пропорційно потребі, визначеній у пропозиціях таких підприємств щодо зменшення або збільшення обсягів бюджетних коштів.

{ Пункт 3 в редакції Постанови КМ N 446 ( 446-2010-п ) від 16.06.2010 }

{ Пункт 4 виключено на підставі Постанови КМ N 446 ( 446-2010-п ) від 16.06.2010 }

5. Агропромислові підприємства складають регіональні плани заходів з урахуванням розміру виділених бюджетних асигнувань і подають їх Міністерству аграрної політики та продовольства. Міністерство аграрної політики та продовольства затверджує плани заходів та планові документи, що застосовуються в процесі виконання бюджету.

6. Операції, пов'язані з використанням бюджетних коштів, здійснюються відповідно до Порядку обслуговування державного бюджету за видатками та операціями з надання та повернення кредитів, наданих за рахунок коштів державного бюджету ( z0716-04 ), затвердженого Державним казначейством.

{ Пункт 6 в редакції Постанови КМ N 446 ( 446-2010-п ) від 16.06.2010 }

7. Агропромислові підприємства подають Міністерству аграрної політики та продовольства: { Абзац перший пункту 7 із змінами, внесеними згідно з Постановою КМ N 446 ( 446-2010-п ) від 16.06.2010 }

щокварталу до 15 числа наступного місяця інформацію про використання бюджетних коштів з метою здійснення заходів для її узагальнення і надіслання Мінфіну до 20 числа зазначеного місяця;

після закінчення бюджетного року звіт про використання бюджетних коштів для його узагальнення і надіслання Мінфіну до 1 лютого відповідного року. { Абзац третій пункту 7 із змінами, внесеними згідно з Постановою КМ N 96 ( 96-2011-п ) від 07.02.2011 }

8. Складення та подання звітності про використання бюджетних коштів, а також контроль за їх цільовим та ефективним використанням здійснюються в установленому законодавством порядку. { Пункт 8 із змінами, внесеними згідно з Постановою КМ N 96 ( 96-2011-п ) від 07.02.2011 }

Додаток до Порядку

ПЕРЕЛІК робіт з охорони і захисту, раціонального використання лісів, наданих у постійне користування агропромисловим підприємствам

{ Назва Додатка із змінами, внесеними згідно з Постановою КМ N 96 ( 96-2011-п ) від 07.02.2011 }

1. Лісовідновлення і захисне лісорозведення:

садіння і висівання лісу

догляд за лісовими культурами в переведенні на однократний

поповнення лісових культур

підготовка ґрунту під лісові культури

заготівля лісового насіння

вирощування посадкового матеріалу в розсадниках

придбання насіння та посадкового матеріалу

створення та вирощування плантацій

створення захисних лісових насаджень

ремонт і утримання протиерозійних гідротехнічних споруд

створення полезахисних лісових смуг

заміна похідних ялинників у поясі букових та дубових лісів на корінні типи деревостанів

створення та відновлення захисних деревно-чагарникових угруповань на верхній межі лісового поясу

створення захисних лісових насаджень уздовж малих річок

реконструкція порушених стихією та біотичними факторами лісостанів, спрямованих на формування змішаних багатоярусних лісів

розроблення високоефективних способів заліснення еродованих ділянок на стрімких схилах, кам'янистих розсипах

2. Охорона лісу від пожеж

3. Лісовпорядкування (базове лісовпорядкування) та інші проектно-вишукувальні роботи

4. Роботи, пов'язані з виготовленням державних актів на право постійного користування земельними ділянками лісового фонду

5. Забезпечення утримання лісової охорони агропромислових підприємств.
