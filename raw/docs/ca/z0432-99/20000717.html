N 450 від 22.06.99 Зареєстровано в Міністерстві юстиції України 2 липня 1999 р. за N 432/3725

( Наказ втратив чинність на підставі Наказу Мінекономіки N 136 ( z0420-00 ) від 29.06.2000 )

Про внесення доповнень до наказу МЗЕЗторгу від 24.02.96 N 133-а в редакції наказу МЗЕЗторгу від 10.09.98 N 576а

Відповідно до Указу Президента України від 07.11.94 N 659/94 "Про облік окремих видів зовнішньоекономічних договорів (контрактів) в Україні" (зі змінами та доповненнями) та у зв'язку з прийняттям Закону України "Про металобрухт" ( 619-14 ) НАКАЗУЮ:

1. У Переліку товарів, експорт яких здійснюється відповідно до конкретних заходів з метою запобігання антидемпінгових процедур, затвердженому наказом МЗЕЗторгу від 24.02.96 N 133-а ( z0125-96 ) та зареєстрованому в Міністерстві юстиції України 19.03.96 за N 125/1150 в редакції наказу МЗЕЗторгу від 10.09.98 N 576а ( z0564-98 ), зареєстрованого в Міністерстві юстиції України від 14.09.98 за N 564/3004 із змінами та доповненнями:

після слів "відходи та брухт чорних металів - 72.04" написати:

"(крім товарних позицій:

відходи та брухт легованої сталі: нержавіючої 720421000

сталі

відходи та брухт легованої сталі: іншої 720429000)";

в усіх абзацах після слів "тільки на ринки країн Латинської Америки, Азії та Африки" написати "(крім країн СНД)".

2. Управлінню правового забезпечення (Сервинський А.Ю.) забезпечити реєстрацію цього наказу в Міністерстві юстиції України.

3. Управлінню справами (Дробний В.В.) у десятиденний термін після реєстрації цього наказу в Міністерстві юстиції України забезпечити його публікацію в засобах масової інформації та довести до відома Державної митної служби України, Міністерства економіки АР Крим і регіональних управлінь зовнішніх економічних зв'язків.

4. Контроль за виконанням цього наказу покласти на заступника Міністра В.І.Олійника.

Міністр А.І.Гончарук
