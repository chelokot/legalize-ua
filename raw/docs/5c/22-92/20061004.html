Кабінет Міністрів України; Декрет від 29.12.1992 № 22-92

Про перенесення строку повернення кредиту, наданого підприємствам та організаціям будівельного комплексу для поповнення іхніх оборотних коштів

Стан: Втратив чинність

Ідентифікатор: 22-92

Текст документа від 04.10.2006:

ДЕКРЕТ КАБІНЕТУ МІНІСТРІВ УКРАЇНИ

{ Декрет втратив чинність на підставі Закону N 139-V ( 139-16 ) від 14.09.2006, ВВР, 2006, N 43, ст.419 }

Про перенесення строку повернення кредиту, наданого підприємствам та організаціям будівельного комплексу для поповнення їхніх оборотних коштів

( Відомості Верховної Ради України (ВВР), 1993, N 11, ст. 92 )

{ Додатково див. Лист КМ ( 18_5-94-р ) від 15.03.94 }

Враховуючи складне фінансове становище підприємств і організацій будівельного комплексу та надзвичайну ситуацію з розрахунками в капітальному будівництві, пов'язану із зростанням неплатежів замовників за виконані будівельно-монтажні роботи і заборгованості постачальникам, Кабінет Міністрів України постановляє:

1. Перенести строк повернення кредиту в сумі 15 млрд. карбованців, виданого підприємствам та організаціям будівельного комплексу згідно з постановою Верховної Ради України від 14 травня 1992 року N 2335-XII ( 2335-12 ).

2. Зобов'язати підприємства й організації будівельного комплексу забезпечити повернення зазначеного кредиту починаючи з квітня 1993 року рівними частинами з повним його погашенням у грудні 1993 року.

3. Зупинити дію пункту 2 постанови Верховної Ради України від 14 травня 1992 року N 2335-XII ( 2335-12 ) "Про надання дозволу Національному банку України на кредитну емісію ".

4. Цей Декрет набуває чинності з дня опублікування.

Прем'єр-міністр України Л.КУЧМА
