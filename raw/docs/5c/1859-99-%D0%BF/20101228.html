КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 7 жовтня 1999 р. N 1859 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1158 ( 1158-2010-п ) від 15.12.2010 }

Про представника Кабінету Міністрів України в Комітеті Повноважних Представників Урядів держав - членів Об'єднаного інституту ядерних досліджень

Кабінет Міністрів України постановляє:

Затвердити представником Кабінету Міністрів України в Комітеті Повноважних Представників Урядів держав - членів Об'єднаного інституту ядерних досліджень Гриньова Бориса Вікторовича, першого заступника голови Державного комітету України з питань науки та інтелектуальної власності.

Прем'єр-міністр України В.ПУСТОВОЙТЕНКО
