КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 25 липня 2002 р. N 1068 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 609 ( 609-2015-п ) від 05.08.2015 }

Про внесення зміни до постанови Кабінету Міністрів України від 14 листопада 2000 р. N 1698

Кабінет Міністрів України постановляє:

В абзаці третьому позиції 3 графи "вид господарської діяльності" переліку органів ліцензування, затвердженого постановою Кабінету Міністрів України від 14 листопада 2000 р. N 1698 ( 1698-2000-п ) (Офіційний вісник України, 2000 р., N 46, ст. 2001), слова "заготівля, обробка окремих видів ресурсоцінних відходів" виключити.
