Стан: Втратив чинність

Текст документа від 21.09.2010:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 вересня 2009 р. N 1156 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 846 ( 846-2010-п ) від 15.09.2010 }

Питання Департаменту державної виконавчої служби Міністерства юстиції

Кабінет Міністрів України постановляє:

1. На часткову зміну абзацу другого пункту 1 постанови Кабінету Міністрів України від 12 березня 2005 р. N 179 ( 179-2005-п ) "Про упорядкування структури апарату центральних органів виконавчої влади, їх територіальних підрозділів та місцевих державних адміністрацій" (Офіційний вісник України, 2005 р., N 11, ст. 522, N 43, ст. 2715; 2006 р., N 33, ст. 2391; 2007 р., N 10, ст. 354, N 48, ст. 1969; 2008 р., N 68, ст. 2270) установити, що директор Департаменту державної виконавчої служби Міністерства юстиції має шість заступників, у тому числі одного першого заступника директора Департаменту та одного заступника директора Департаменту - начальника відділу примусового виконання рішень.

2. Визнати такою, що втратила чинність, постанову Кабінету Міністрів України від 7 лютого 2007 р. N 146 ( 146-2007-п ) "Питання Департаменту державної виконавчої служби Міністерства юстиції" (Офіційний вісник України, 2007 р., N 10, ст. 354).

3. Міністерству юстиції забезпечити утримання у 2009 році апарату Департаменту державної виконавчої служби в межах затвердженого кошторису витрат.
