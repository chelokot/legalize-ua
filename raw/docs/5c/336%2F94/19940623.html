Президент України; Указ від 23.06.1994 № 336/94

Про визнання такими, що втратили чинність, Указів Президента України щодо організації роботи Кабінету Міністрів України

Стан: Чинний

Ідентифікатор: 336/94

Текст документа від 23.06.1994:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про визнання такими, що втратили чинність, Указів Президента України щодо організації роботи Кабінету Міністрів України

1. Визнати такими, що втратили чинність, Укази Президента України від 27 вересня 1993 року N 383 ( 383/93 ) "Про керівництво Кабінетом Міністрів України", від 6 жовтня 1993 року N 419 ( 419/93 ) "Про організацію роботи Кабінету Міністрів України" та N 420 ( 420/93 ) "Про реорганізацію структурних підрозділів Адміністрації Президента України та Кабінету Міністрів України".

2. Цей Указ набирає чинності з дня його підписання.

Президент України Л.КРАВЧУК

м.Київ, 23 червня 1994 року N 336/94
