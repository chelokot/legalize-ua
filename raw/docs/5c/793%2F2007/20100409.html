Про внесення змін до Указу Президента України від 14 лютого 2006 року N 133

{ Із змінами, внесеними згідно з Указом Президента N 277/2008 ( 277/2008 ) від 28.03.2008 }

Внести до Указу Президента України від 14 лютого 2006 року N 133 ( 133/2006 ) "Питання Комісії з опрацювання та комплексного вирішення питань реалізації державної політики у сфері раціонального використання та охорони земель" (зі змінами, внесеними Указом від 25 липня 2006 року N 637 ( 637/2006 ) такі зміни:

{ Стаття 1 втратила чинність на підставі Указу Президента N 277/2008 ( 277/2008 ) від 28.03.2008 }

2. У Положенні про Комісію з опрацювання та комплексного вирішення питань реалізації державної політики у сфері раціонального використання та охорони земель, затвердженому цим Указом:

1) підпункт 1 пункту 3 доповнити новим абзацом такого змісту:

"забезпечення додержання Конституції ( 254к/96-ВР ) та законів України, прав і свобод громадян у сфері регулювання земельних відносин, раціонального використання та охорони земель";

2) у пункті 6:

в абзаці першому слова "заступників голови" замінити словами "заступника голови";

абзац другий викласти у такій редакції:

"Комісію очолює голова, яким за посадою є Секретар Ради національної безпеки і оборони України";

3) у другому реченні пункту 7 слова "один із заступників голови" замінити словами "заступник голови";

4) пункт 8 доповнити новим абзацом такого змісту:

"Члени Комісії подають пропозиції до порядку денного її засідань, готують згідно з компетенцією питання для розгляду Комісією та пропозиції до проектів її рішень".

У зв'язку із цим абзац третій вважати абзацом четвертим.

Президент України В.ЮЩЕНКО

м. Київ, 27 серпня 2007 року N 793/2007
