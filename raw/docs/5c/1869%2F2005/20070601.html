УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

{ Указ втратив чинність на підставі Указу Президента N 399/2007 ( 399/2007 ) від 12.05.2007 }

Про внесення зміни до Указу Президента України від 14 грудня 1996 року N 1218

Внести до Указу Президента України від 14 грудня 1996 року N 1218 ( 1218/96 ) "Про заходи щодо створення Єдиної державної автоматизованої паспортної системи" зміну, замінивши в назві та преамбулі слова "Єдиної державної автоматизованої паспортної системи" словами "Державної інформаційної системи реєстраційного обліку фізичних осіб та їх документування".

Президент України В.ЮЩЕНКО
