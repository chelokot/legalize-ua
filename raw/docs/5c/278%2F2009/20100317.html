Про внесення зміни до Указу Президента України від 23 травня 2005 року N 841

Внести до Указу Президента України від 23 травня 2005 року N 841 ( 841/2005 ) "Про кількість заступників Голови Служби безпеки України" (зі змінами, внесеними Указами від 26 липня 2006 року N 647 ( 647/2006 ), від 15 листопада 2006 року N 968 ( 968/2006 ), від 16 квітня 2007 року N 305 ( 305/2007 ), від 12 травня 2007 року N 398 ( 398/2007 ), від 20 червня 2007 року N 543 ( 543/2007 ), від 24 жовтня 2007 року N 1006 ( 1006/2007 ), від 16 листопада 2007 року N 1115 ( 1115/2007 ), від 28 січня 2009 року N 41 ( 41/2009 ), від 10 березня 2009 року N 147 ( 147/2009 ) та від 2 квітня 2009 року N 213) ( 213/2009 ) зміну, виключивши з абзацу першого слова "у тому числі заступника Голови Служби безпеки України - начальника Слідчого управління Служби безпеки України та заступника Голови Служби безпеки України - директора Департаменту господарського забезпечення Служби безпеки України".

Президент України В.ЮЩЕНКО
