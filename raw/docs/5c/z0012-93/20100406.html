Про затвердження Інструкції про порядок встановлення лімітів на використання природних ресурсів у межах територій та об'єктів природно-заповідного фонду загальнодержавного значення та Інструкції про порядок видачі дозволів на спеціальне використання природних ресурсів у межах територій та об'єктів природно-заповідного фонду загальнодержавного значення

Реєстрація: Мін'юст України від 26.03.1993 № 12

Стан: Втратив чинність

Ідентифікатор: z0012-93

Текст документа від 06.04.2010:

МІНІСТЕРСТВО ОХОРОНИ НАВКОЛИШНЬОГО ПРИРОДНОГО СЕРЕДОВИЩА УКРАЇНИ

НАКАЗ

N 19 від 12.03.93 Зареєстровано в Міністерстві м. Київ юстиції України 26 березня 1993 р. за N 12

{ Наказ втратив чинність на підставі Наказу Міністерства охорони навколишнього природного середовища N 88 ( z0233-10 ) від 22.02.2010 }

Про затвердження Інструкції про порядок встановлення лімітів на використання природних ресурсів у межах територій та об'єктів природно-заповідного фонду загальнодержавного значення та Інструкції про порядок видачі дозволів на спеціальне використання природних ресурсів у межах територій та об'єктів природно-заповідного фонду загальнодержавного значення

{ Із змінами, внесеними згідно з Наказом Мінприроди N 43 ( z0111-94 ) від 11.05.94 Наказом Мінекобезпеки N 141/4 ( z0535-97 ) від 02.09.97 Наказом Міністерства охорони навколишнього природного середовища N 27 ( z0117-08 ) від 24.01.2008 }

Відповідно до Закону УРСР "Про охорону навколишнього природного середовища" ( 1264-12 ) на виконання постанови Кабінету Міністрів України від 10 серпня 1992 року N 459 ( 459-92-п ) "Про порядок видачі дозволів на спеціальне використання природних ресурсів і встановлення лімітів використання ресурсів республіканського значення" НАКАЗУЮ:

1. Затвердити погоджені з Міністерством економіки України Інструкцію про порядок встановлення лімітів на використання природних ресурсів у межах територій та об'єктів природно-заповідного фонду загальнодержавного значення та Інструкцію про порядок видачі дозволів на спеціальне використання природних ресурсів у межах територій та об'єктів природно-заповідного фонду загальнодержавного значення ( z0013-93 ), які додаються.

2. Управлінню заповідних та рекреаційних територій (СТЕЦЕНКО М. П.) довести Інструкції до зацікавлених міністерств і відомств, та державних управлінь охорони навколишнього природного середовища по Республіці Крим, областях, містах Києву і Севастополю.

3. Контроль за виконанням даного наказу покласти на заступника Міністра Шевчука В. Я.

Міністр Ю. КОСТЕНКО

{ Інструкція про порядок встановлення лімітів на використання природних ресурсів у межах територій та об'єктів природно-заповідного фонду загальнодержавного значення втратила чинність на підставі Наказу Міністерства охорони навколишнього природного середовища N 27 ( z0117-08 ) від 24.01.2008 }
