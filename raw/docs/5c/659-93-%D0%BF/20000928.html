Питання Державної міжвідомчої комісії України у справах випробувань і реєстрації засобів захисту та регуляторів росту рослин і добрив

Ідентифікатор: 659-93-п

Текст документа від 28.09.2000:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 серпня 1993 р. N 659 Київ

( Постанова втратила чинність на підставі Постанови КМ N 1481 ( 1481-2000-п ) від 28.09.2000 )

Питання Державної міжвідомчої комісії України у справах випробувань і реєстрації засобів захисту та регуляторів росту рослин і добрив

( Із змінами, внесеними згідно з Постановою КМ N 1630 ( 1630-99-п ) від 06.09.99 )

З метою здійснення дійового контролю за додержанням єдиного порядку державних випробувань, реєстрації засобів захисту та регуляторів росту рослин і добрив, їх використання в народному господарстві Кабінет Міністрів України постановляє:

( Пункт 2 втратив чинність на підставі Постанови КМ N 1630 ( 1630-99-п ) від 06.09.99 )

3. Призначити Петрунека Володимира Лукича головою Укрдержхімкомісії.

Доручити Петрунеку В.Л. внести у місячний термін до Кабінету Міністрів України погоджений з Міністерством економіки, Міністерством юстиції, Міністерством фінансів, Міністерством сільського господарства і продовольства, Міністерством охорони здоров'я, Міністерством охорони навколишнього природного середовища та Українською академією аграрних наук проект положення про Укрдержхімкомісію, а також пропозиції про її персональний склад.

( Пункт 4 втратив чинність на підставі Постанови КМ N 1630 ( 1630-99-п ) від 06.09.99 )

( Пункт 5 втратив чинність на підставі Постанови КМ N 1630 ( 1630-99-п ) від 06.09.99 )

6. Міністерству фінансів передбачати в державному бюджеті асигнування на утримання Укрдержхімкомісії й на державні випробування засобів захисту та регуляторів росту рослин і добрив, що випускаються за державним замовленням.

( Пункт 7 втратив чинність на підставі Постанови КМ N 1630 ( 1630-99-п ) від 06.09.99 )

8. Міністерству сільського господарства і продовольства вирішити питання щодо розміщення апарату Укрдержхімкомісії, створити належні умови для її роботи.

9. Визнати такими, що втратили чинність, абзац 2 пункту 1, пункти 2, 3, 4 і 5 постанови Кабінету Міністрів від 17 лютого 1993 р. N 115 ( 115-93-п ) "Про Державну міжвідомчу комісію у справах випробувань і реєстрації засобів захисту та регуляторів росту рослин і добрив".
