Про встановлення мінімального розміру регулятивного капіталу банків у гривнях

Стан: Втратив чинність

Ідентифікатор: v0091500-05

Текст документа від 15.02.2006:

ПРАВЛІННЯ НАЦІОНАЛЬНОГО БАНКУ УКРАЇНИ

ПОСТАНОВА

29.03.2005 N 91

Про встановлення мінімального розміру регулятивного капіталу банків у гривнях

( Із змінами, внесеними згідно з Постановами Національного банку

N 411 ( v0411500-05 ) від 07.11.2005

N 50 ( v0050500-06 ) від 15.02.2006 )

Відповідно до статей 7, 55, 58 Закону України "Про Національний банк України" ( 679-14 ), статей 30, 47 Закону України "Про банки і банківську діяльність" ( 2121-14 ), з метою підвищення рівня капіталізації банків, удосконалення порядку контролю за дотриманням банками мінімального розміру регулятивного капіталу та на виконання постанови Правління Національного банку України від 17.03.2004 N 112 ( z0445-04 ), зареєстрованої в Міністерстві юстиції України 07.04.2004 за N 445/9044, Правління Національного банку України ПОСТАНОВЛЯЄ:

1. Установити мінімальний розмір регулятивного капіталу (Н1) у гривнях у розмірі, еквівалентному розміру нормативного значення, установленого в євро відповідно до пунктів 2.2 та 2.3 глави 2 розділу II Інструкції про порядок регулювання діяльності банків в Україні, затвердженої постановою Правління Національного банку України від 28.08.2001 N 368 ( z0841-01 ) та зареєстрованої в Міністерстві юстиції України 26.09.2001 за N 841/6032 (зі змінами), якого банки мають дотримуватися:

1.1. Для діючих банків:

за станом на 30.12.2005 та протягом 2006 року:

для місцевих кооперативних банків - 10104 тис. грн.;

для банків, які здійснюють свою діяльність на території однієї області (регіональних), у тому числі спеціалізованих ощадних та іпотечних - 32478 тис. грн.;

для банків, які здійснюють свою діяльність на території всієї України (міжрегіональних), у тому числі спеціалізованих інвестиційних і розрахункових (клірингових), центрального кооперативного банку - 50522 тис. грн.

1.2. Для знову створених банків (залежно від строку їх діяльності):

а) для місцевих кооперативних банків:

до одного року діяльності - 7217 тис. грн.,

до двох років діяльності - 7939 тис. грн.,

до трьох років діяльності - 8661 тис. грн.,

до чотирьох років діяльності - 9743 тис. грн.,

починаючи з п'ятого року діяльності - 10826 тис. грн.;

б) для банків, які здійснюють свою діяльність на території однієї області (регіональних), у тому числі спеціалізованих ощадних та іпотечних:

до одного року діяльності - 21652 тис. грн.,

до двох років діяльності - 25261 тис. грн.,

до трьох років діяльності - 28870 тис. грн.,

до чотирьох років діяльності - 32478 тис. грн.,

починаючи з п'ятого року діяльності - 36087 тис. грн.;

в) для банків, які здійснюють свою діяльність на території всієї України (міжрегіональних), у тому числі спеціалізованих інвестиційних і розрахункових (клірингових), центрального кооперативного банку:

до одного року діяльності - 36087 тис. грн.,

до двох років діяльності - 39696 тис. грн.,

до трьох років діяльності - 43305 тис. грн.,

до чотирьох років діяльності - 50522 тис. грн.,

починаючи з п'ятого року діяльності - 57740 тис. грн.

2. Установити мінімальний розмір регулятивного капіталу (Н1) у гривнях для банків, що здійснюють операції з урахуванням вимог, установлених главою 5 Положення про порядок видачі банкам банківських ліцензій, письмових дозволів та ліцензій на виконання окремих операцій, затвердженого постановою Правління Національного банку України від 17.07.2001 N 275 ( z0730-01 ) та зареєстрованого в Міністерстві юстиції України 21.08.2001 за N 730/5921, якого банки мають дотримуватися, починаючи з 30.12.2005 та протягом 2006 року:

а) для місцевих кооперативних банків - 7217 тис. грн.;

б) для банків, які здійснюють свою діяльність на території однієї області (регіональних), у тому числі спеціалізованих ощадних та іпотечних - 21652 тис. грн.;

в) для банків, які здійснюють свою діяльність на території всієї України (міжрегіональних), у тому числі спеціалізованих інвестиційних і розрахункових (клірингових), центрального кооперативного банку - 36087 тис. грн.;

( Підпункт "г" пункту 2 втратив чиність на підставі Постанови Національного банку N 50 ( v0050500-06 ) від 15.02.2006 )

ґ) для банків, які здійснюють операції з банківськими металами та інші операції з валютними цінностями на міжнародних ринках, - 72175 тис. грн.

3. Установити мінімальний розмір регулятивного капіталу (Н1) у гривнях для банків, що мають намір отримати письмовий дозвіл або розширити перелік операцій, вимоги щодо виконання яких установлені главою 5 Положення про порядок видачі банкам банківських ліцензій, письмових дозволів та ліцензій на виконання окремих операцій, затвердженого постановою Правління Національного банку України від 17.07.2001 N 275 ( z0730-01 ) та зареєстрованого в Міністерстві юстиції України 21.08.2001 за N 730/5921, з дня набрання чинності цією постановою та протягом 2006 року:

3.1. Для отримання письмового дозволу на здійснення неторговельних операцій з валютними цінностями:

для місцевих кооперативних банків - 14435 тис.грн.;

для банків, які здійснюють свою діяльність на території однієї області (регіональних), у тому числі спеціалізованих ощадних та іпотечних - 39696 тис.грн.;

для банків, які здійснюють свою діяльність на території всієї України (міжрегіональних), у тому числі спеціалізованих інвестиційних і розрахункових (клірингових), центрального кооперативного банку - 57740 тис.грн.

3.2. Для отримання письмового дозволу на здійснення операцій з валютними цінностями в частині ведення рахунків клієнтів (резидентів та нерезидентів) в іноземній валюті та клієнтів-нерезидентів у грошовій одиниці України:

для місцевих кооперативних банків - 14435 тис.грн.;

для банків, які здійснюють свою діяльність на території однієї області (регіональних), у тому числі спеціалізованих ощадних та іпотечних - 39696 тис.грн.;

для банків, які здійснюють свою діяльність на території всієї України (міжрегіональних), у тому числі спеціалізованих інвестиційних і розрахункових (клірингових), центрального кооперативного банку - 57740 тис.грн.

3.3. Для отримання письмового дозволу на здійснення операцій з валютними цінностями в частині ведення кореспондентських рахунків банків (резидентів і нерезидентів) в іноземній валюті - 57740 тис.грн.

3.4. Для отримання письмового дозволу на здійснення операцій з валютними цінностями в частині ведення кореспондентських рахунків банків (нерезидентів) у грошовій одиниці України - 57740 тис.грн.

3.5. Для отримання письмового дозволу на здійснення операцій з валютними цінностями в частині відкриття кореспондентських рахунків в уповноважених банках України в іноземній валюті та здійснення операцій за ними:

для місцевих кооперативних банків - 14435 тис.грн.;

для інших банків - 39696 тис.грн.

3.6. Для отримання письмового дозволу на здійснення операцій з валютними цінностями в частині відкриття кореспондентських рахунків у банках (нерезидентах) в іноземній валюті та здійснення операцій за ними - 57740 тис.грн.

3.7. Для отримання письмового дозволу на здійснення операцій з валютними цінностями в частині залучення та розміщення іноземної валюти на валютному ринку України:

для місцевих кооперативних банків - 14435 тис.грн.;

для банків, які здійснюють свою діяльність на території однієї області (регіональних), у тому числі спеціалізованих ощадних та іпотечних - 39696 тис.грн.;

для банків, які здійснюють свою діяльність на території всієї України (міжрегіональних), у тому числі спеціалізованих інвестиційних і розрахункових (клірингових), центрального кооперативного банку - 57740 тис.грн.

3.8. Для отримання письмового дозволу на здійснення операцій з валютними цінностями в частині залучення та розміщення іноземної валюти на міжнародних ринках - 72175 тис.грн.

3.9. Для отримання письмового дозволу на здійснення операцій з валютними цінностями в частині здійснення операцій з банківськими металами на валютному ринку України - 57740 тис.грн.

3.10. Для отримання письмового дозволу на здійснення прямих інвестицій у фінансові установи в обсягах, що перевищують 5 відсотків регулятивного капіталу банку, а також прямих інвестицій у будь-яких розмірах в юридичні особи, які не є фінансовими установами, - 144349 тис.грн. Строк діяльності банку має становити не менше ніж три роки.

3.11. Для отримання письмового дозволу на довірче управління коштами та цінними паперами за договорами з юридичними та фізичними особами - 57740 тис.грн.

( Постанову доповнено пунктом 3 згідно з Постановою Національного банку N 411 ( v0411500-05 ) від 07.11.2005 )

4. Установити мінімальний розмір регулятивного капіталу (Н1) для здійснення банками інвестицій у статутні фонди фінансових установ, загальна сума яких у кожну фінансову установу не перевищує 5 відсотків регулятивного капіталу банку, у розмірі 57740 тис.грн. з дня набрання чинності цією постановою та протягом 2006 року. ( Постанову доповнено пунктом 4 згідно з Постановою Національного банку N 411 ( v0411500-05 ) від 07.11.2005 )

5. Департаменту методології банківського регулювання та нагляду (Н.В.Іваненко) довести зміст цієї постанови до відома самостійних структурних підрозділів, територіальних управлінь Національного банку України, а також банків для керівництва в роботі. ( Пункт 5 із змінами, внесеними згідно з Постановою Національного банку N 411 ( v0411500-05 ) від 07.11.2005 )

6. Постанова набирає чинності з дня її підписання.

7. Контроль за виконанням цієї постанови покласти на заступника Голови В.Л. Кротюка, Департамент банківського регулювання і нагляду (В.О.Зінченко), Департамент реєстрації та ліцензування (О.І.Пархоменко) та начальників територіальних управлінь Національного банку України. ( Пункт 7 із змінами, внесеними згідно з Постановою Національного банку N 411 ( v0411500-05 ) від 07.11.2005 )
