Кабінет Міністрів України; Постанова від 17.12.1993 № 1041

Про внесення змін в умови оплати праці працівників державної контрольно-ревізійної служби в Україні

Стан: Втратив чинність

Ідентифікатор: 1041-93-п

Текст документа від 15.06.1994:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 грудня 1993 р. N 1041 Київ

Про внесення змін в умови оплати праці працівників державної контрольно-ревізійної служби в Україні

( Із змінами, внесеними згідно з Постановою КМ N 409 ( 409-94-п ) від 15.06.94 )

Кабінет Міністрів України постановляє:

1. Затвердити нову редакцію додатків N 1-4 до постанови Кабінету Міністрів України від 5 липня 1993 р. N 515 ( 515-93-п ) "Питання державної контрольно-ревізійної служби в Україні", що додаються.

( Пункт 2 втратив чинність на підставі Постанови КМ N 409 ( 409-94-п ) від 15.06.94 )

3. Ця постанова набуває чинності з 1 грудня 1993 року.
