КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 22 лютого 2008 р. N 321-р Київ

Про затвердження титулу на виконання проектно-вишукувальних робіт для будівництва шахти N 3 "Червоноградська"

Затвердити поданий Мінвуглепромом титул на виконання проектно-вишукувальних робіт для будівництва шахти N 3 "Червоноградська" державного підприємства "Львіввугілля", що додається.

Прем'єр-міністр України Ю.ТИМОШЕНКО

Інд. 37
