Про Редакційну колегію з видання збірників актів законодавства України

{ Із змінами, внесеними згідно з Указом Президента N 826/98 від 31.07.98 }

У зв'язку з Указом Президента України від 22 січня 1996 року N 73 ( 73/96 ) "Про видання збірників актів законодавства України" та з метою забезпечення підготовки та видання збірників актів законодавства України постановляю:

1. Утворити Редакційну колегію з видання збірників актів законодавства України.

2. Затвердити персональний склад Редакційної колегії з видання збірників актів законодавства України (додається).

Президент України Л.КУЧМА

м.Київ, 15 березня 1996 року N 185/96
