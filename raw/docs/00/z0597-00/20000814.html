НАКАЗ

N 1684 від 14.08.2000 Зареєстровано в Міністерстві м. Київ юстиції України 8 вересня 2000 р. за N 597/4818

Про внесення змін до наказу Фонду від 30.07.98 N 1511

Відповідно до розділу I Положення про порядок визначення та застосування способів приватизації щодо об'єктів малої приватизації, затвердженого наказом Фонду від 30.07.98 N 1511 ( z0558-98 ) та зареєстрованого в Міністерстві юстиції України 10.09.98 за N 558/2998, НАКАЗУЮ:

1. Доповнити пункт 3 наказу Фонду державного майна від 30.07.98 N 1511 ( z0558-98 ) словами такого змісту: "(крім об'єктів групи Д)".

2. Департаменту індивідуального продажу забезпечити реєстрацію змін до наказу від 30.07.98 N 1511 ( z0558-98 ) в Міністерстві юстиції України.

3. Відповідальність за виконання наказу покласти на директора Департаменту індивідуального продажу В.В.Зеленського.

4. Контроль за виконанням цього наказу покласти на заступника Голови Фонду Л.Ф.Кальніченка.
