Про скасування постанови Кабінету Міністрів України від 28 грудня 1993 р. N 1066

Текст документа від 30.03.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 30 березня 2005 р. N 229 Київ

Про скасування постанови Кабінету Міністрів України від 28 грудня 1993 р. N 1066

У зв'язку з порушенням вимог постанови Кабінету Міністрів України від 21 січня 1992 р. N 26 ( 26-92-п ) "Про створення Української державної корпорації по транспортному будівництву" (ЗП України, 1992 р., N 2, ст. 42), а також Статуту Української державної корпорації по транспортному будівництву "Укртрансбуд" в частині процедури затвердження президента корпорації Кабінет Міністрів України постановляє:

Скасувати постанову Кабінету Міністрів України від 28 грудня 1993 р. N 1066 ( 1066-93-п ) "Про затвердження Гвоздя О.О. президентом Української державної корпорації по транспортному будівництву".

Прем'єр-міністр України Ю.ТИМОШЕНКО
