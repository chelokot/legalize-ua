Стан: Втратив чинність

Текст документа від 11.02.2000:

УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

( Указ втратив чинність на підставі Указу Президента N 208/2000 від 11.02.2000 )

Про внесення змін до складу Ради по роботі з кадрами при Президентові України

Внести до складу Ради по роботі з кадрами при Президентові України, затвердженого Указом Президента України від 27 лютого 1997 року N 186 ( 186/97 ) (зі змінами, внесеними Указами від 18 грудня 1997 року N 1358 ( 1358/97 ) та від 13 липня 1998 року N 767 ( 767/98 ), такі зміни:

1. Увести до складу зазначеної Ради БІЛОБЛОЦЬКОГО Миколу Петровича - Главу Адміністрації Президента України, поклавши на нього обов'язки співголови Ради.

2. Вивести зі складу Ради Кушнарьова Є.П.

Президент України Л.КУЧМА

м. Київ, 11 березня 1999 року N 246/99
