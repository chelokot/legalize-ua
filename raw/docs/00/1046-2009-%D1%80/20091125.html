КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 3 вересня 2009 р. N 1046-р Київ

Про затвердження переліку та обсягів товарів, які ввозяться на митну територію України для реконструкції спортивного комплексу комунального підприємства "Обласний спортивний комплекс "Металіст" та звільняються від сплати ввізного мита

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1414-р ( 1414-2009-р ) від 25.11.2009 }

Відповідно до пункту щ-1 частини першої статті 19 Закону України "Про Єдиний митний тариф" ( 2097-12 ) затвердити на 2009 рік перелік та обсяги товарів, які ввозяться на митну територію України для реконструкції спортивного комплексу комунального підприємства "Обласний спортивний комплекс "Металіст" та звільняються від сплати ввізного мита, що додається.
