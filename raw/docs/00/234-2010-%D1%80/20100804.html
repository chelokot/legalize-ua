{ Розпорядження втратило чинність на підставі Розпорядження КМ N 1594-р ( 1594-2010-р ) від 04.08.2010 }

Про внесення зміни до розпорядження Кабінету Міністрів України від 14 травня 2008 р. N 708

На часткову зміну абзацу другого розпорядження Кабінету Міністрів України від 14 травня 2008 р. N 708 ( 708-2008-р ) уповноважити першого заступника Міністра транспорту та зв'язку Шевченка Василя Васильовича підписати Угоду між Кабінетом Міністрів України та Урядом Алжирської Народної Демократичної Республіки про морське торговельне судноплавство.
