ПОСТАНОВА ПРЕЗИДІЇ ВЕРХОВНОЇ РАДИ УКРАЇНИ

( Постанова втратила чинність на підставі Постанови ВР N 179-XIV ( 179-14 ) від 14.10.98, ВВР, 1998, N 48, ст.297 )

Про благодійні фонди

( Відомості Верховної Ради України (ВВР), 1992, N 52, ст. 687 )

( Із змінами, внесеними згідно з Постановою Президії ВР N 3572-XII ( 3572-12 ) від 11.11.93, ВВР, 1993, N 46, ст.430 )

Президія Верховної Ради України постановляє:

1. Записку Комісії Верховної Ради України у справах молоді взяти до відома.

2. Комісії Верховної Ради України у справах молоді разом з Кабінетом Міністрів України до 1 лютого 1993 року підготувати проект закону України про благодійні фонди і внести його на розгляд Верховної Ради України.

Кабінету Міністрів України до 1 грудня 1992 року розробити тимчасові правила реєстрації благодійних фондів. До 15 листопада 1993 року визначити порядок справляння і розміри зборів за їх реєстрацію. ( Частина друга пункту 2 із змінами, внесеними згідно з Постановою Президії ВР N 3572-XII ( 3572-12 ) від 11.11.93 )

Міністерство юстиції України, Рада Міністрів Республіки Крим, місцеві органи державної виконавчої влади до прийняття Закону України про благодійні фонди здійснюють на підставі цих тимчасових правил державну реєстрацію відповідно міжнародних, всеукраїнських та місцевих благодійних фондів, які створюються юридичними та фізичними особами. ( Частина третя пункту 2 в редакції Постанови Президії ВР N 3572-XII ( 3572-12 ) від 11.11.93 )

3. Контроль за виконанням цієї Постанови покласти на Комісію Верховної Ради України у справах молоді.

Голова Верховної Ради України І.ПЛЮЩ
