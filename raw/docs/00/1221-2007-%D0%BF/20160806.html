Про віднесення посад Голови Адміністрації Державної спеціальної служби транспорту та його заступників до відповідних категорій посад державних службовців та умови оплати їх праці

Текст документа від 06.08.2016:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 10 жовтня 2007 р. N 1221 Київ

Про віднесення посад Голови Адміністрації Державної спеціальної служби транспорту та його заступників до відповідних категорій посад державних службовців та умови оплати їх праці

{ Із змінами, внесеними згідно з Постановою КМ N 465 ( 465-2016-п ) від 22.07.2016 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 465 ( 465-2016-п ) від 22.07.2016 }

2. Установити, що умови оплати праці Голови Адміністрації Державної спеціальної служби транспорту та його заступників, у тому числі розміри посадових окладів, встановлюються на рівні відповідних посад керівних працівників урядових органів державного управління.
