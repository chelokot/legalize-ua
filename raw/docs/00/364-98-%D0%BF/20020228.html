Про умови оплати праці членів окружних та дільничних виборчих комісій по виборах депутатів Верховної Ради Автономної Республіки Крим

( Із змінами, внесеними згідно з Постановою КМ N 1738 ( 1738-2001-п ) від 27.12.2001 )
