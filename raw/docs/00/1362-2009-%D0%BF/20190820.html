Кабінет Міністрів України; Постанова від 16.12.2009 № 1362

Про збільшення статутного капіталу Державної спеціалізованої фінансової установи "Державний фонд сприяння молодіжному житловому будівництву"

Стан: Чинний

Ідентифікатор: 1362-2009-п

Текст документа від 20.08.2019:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 16 грудня 2009 р. N 1362 Київ

Про збільшення статутного капіталу Державної спеціалізованої фінансової установи "Державний фонд сприяння молодіжному житловому будівництву"

{ Із змінами, внесеними згідно з Постановою КМ N 727 ( 727-2019-п ) від 14.08.2019 }

Кабінет Міністрів України постановляє:

1. Збільшити статутний капітал Державної спеціалізованої фінансової установи "Державний фонд сприяння молодіжному житловому будівництву" на суму 3900000 (три мільйони дев'ятсот тисяч) гривень за рахунок коштів, які надходять від повернення кредитів, наданих з державного бюджету молодим сім'ям та одиноким молодим громадянам на будівництво (реконструкцію) та придбання житла.

2. Внести до постанов Кабінету Міністрів України такі зміни:

{ Абзац другий пункту 2 втратив чинність на підставі Постанови КМ N 727 ( 727-2019-п ) від 14.08.2019 }

у пункті 3 Порядку використання у 2009 році коштів, передбачених у державному бюджеті для формування статутного капіталу державної спеціалізованої фінансової установи "Державний фонд сприяння молодіжному житловому будівництву" з подальшим спрямуванням на виконання Державної програми забезпечення молоді житлом, затвердженого постановою Кабінету Міністрів України від 8 квітня 2009 р. N 324 ( 324-2009-п ) (Офіційний вісник України, 2009 р., N 27, ст. 897), цифри і слова "26,1 млн. гривень" замінити цифрами і словами "30 млн. гривень".

Прем'єр-міністр України Ю.ТИМОШЕНКО
