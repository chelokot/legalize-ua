Президент України; Розпорядження від 07.12.2005 № 1272/2005-рп

Про делегацію України для участі у переговорах між Україною та Королівством Таїланд щодо підготовки проекту Договору між Україною та Королівством Таїланд про правову допомогу у кримінальних справах

Стан: Втратив чинність

Ідентифікатор: 1272/2005-рп

Текст документа від 07.02.2008:

РОЗПОРЯДЖЕННЯ ПРЕЗИДЕНТА УКРАЇНИ

{ Розпорядження втратило чинність на підставі Указу Президента N 104/2008 ( 104/2008 ) від 07.02.2008 }

Про делегацію України для участі у переговорах між Україною та Королівством Таїланд щодо підготовки проекту Договору між Україною та Королівством Таїланд про правову допомогу у кримінальних справах

1. Утворити делегацію України для участі у переговорах між Україною та Королівством Таїланд щодо підготовки проекту Договору між Україною та Королівством Таїланд про правову допомогу у кримінальних справах (грудень 2005 року, м. Бангкок, Королівство Таїланд) в такому складі:

ГОРБУНОВА - заступник Міністра юстиції України,

Лідія Миколаївна глава делегації

ГАЛУЩЕНКО - заступник керівника

Герман Валерійович департаменту - завідувач відділу Головної служби зовнішньої політики Секретаріату Президента України

КРАВЧУК - начальник управління міжнародних

Сергій Федорович зв'язків Генеральної прокуратури України

- завідувач відділу Головної МАРЧЕНКО державно-правової служби Секретаріату Людмила Іванівна Президента України

СИБІГА - начальник відділу Договірно-правового Андрій Іванович управління Міністерства закордонних справ України

ШЕВЧЕНКО - начальник управління - заступник

Катерина Георгіївна директора Департаменту міжнародного співробітництва Міністерства юстиції України.

Дозволити главі делегації України вносити в разі потреби зміни до складу делегації України, залучаючи до її роботи членів Експертної групи з підготовки проектів міжнародних договорів України про правові відносини та правову допомогу у цивільних і кримінальних справах, утвореної Указом Президента України від 24 квітня 2004 року N 476 ( 476/2004 ).

2. Міністерству юстиції України за погодженням з Міністерством закордонних справ України затвердити вказівки делегації України на переговори.

3. Кабінету Міністрів України вирішити питання щодо виділення коштів в іноземній валюті для забезпечення участі у переговорах Л. Горбунової, Г. Галущенка, С. Кравчука, Л. Марченко, К. Шевченко.

Президент України В.ЮЩЕНКО
