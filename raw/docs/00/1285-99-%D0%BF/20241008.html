ПОСТАНОВА від 19 липня 1999 р. N 1285 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 1146 ( 1146-2024-п ) від 04.10.2024 }

Про внесення змін до складу Державної акредитаційної комісії

Кабінет Міністрів України постановляє:

Внести до складу Державної акредитаційної комісії, затвердженого постановою Кабінету Міністрів України від 12 лютого 1996 р. N 200 ( 200-96-п ) "Про ліцензування, атестацію та акредитацію закладів освіти" (ЗП України, 1996 р., N 7, ст. 216), такі зміни:

вивести з її складу заступника Міністра освіти Богомолова Анатолія Григоровича;

ввести до її складу першого заступника Міністра освіти Холода Бориса Івановича, затвердивши його першим заступником голови Державної акредитаційної комісії.
