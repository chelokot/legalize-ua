Кабінет Міністрів України; Постанова від 21.04.1998 № 524

Про державний збір за видачу разових (індивідуальних) ліцензій із суб'єктів зовнішньоекономічної діяльності, що порушили Закон УРСР "Про зовнішньоекономічну діяльність"

Стан: Чинний

Ідентифікатор: 524-98-п

Текст документа від 14.12.1998:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 21 квітня 1998 р. N 524 Київ

Про державний збір за видачу разових (індивідуальних) ліцензій із суб'єктів зовнішньоекономічної діяльності, що порушили Закон УРСР "Про зовнішньоекономічну діяльність"

( Із змінами, внесеними згідно з Постановами КМ N 837 ( 837-98-п ) від 08.06.98 N 1965 ( 1965-98-п ) від 14.12.98 )

З метою поповнення доходної частини державного бюджету, запобігання незаконному вивезенню валютних та матеріальних цінностей за межі України, посилення відповідальності суб'єктів підприємницької діяльності за порушення законодавства України під час здійснення зовнішньоекономічних операцій та відповідно до статей 16 і 37 Закону УРСР "Про зовнішньоекономічну діяльність" ( 959-12 ) Кабінет Міністрів України постановляє:

1. Установити, що за видачу разових (індивідуальних) ліцензій на здійснення зовнішньоекономічної операції із суб'єктів зовнішньоекономічної діяльності, до яких згідно із статтею 37 Закону УРСР "Про зовнішньоекономічну діяльність" ( 959-12 ) Міністерством зовнішніх економічних зв'язків і торгівлі застосовано спеціальну санкцію у вигляді індивідуального режиму ліцензування, справляється державний збір у національній валюті України у розмірі 0,2 відсотка вартості товарів (продукції, робіт, послуг). При цьому перерахунки валюти здійснюються за курсом, установленим Національним банком України на дату платежу. ( Пункт 1 в редакції Постанови КМ N 1965 ( 1965-98-п ) від 14.12.98 )

2. Установити, що кошти, одержані від збору, передбаченого пунктом 1 цієї постанови, зараховуються до державного бюджету.

( Пункт 2 в редакції Постанови КМ N 837 ( 837-98-п ) від 08.06.98 )

3. Ця постанова набирає чинності з дня її опублікування.
