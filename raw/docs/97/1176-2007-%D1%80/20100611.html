КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 19 грудня 2007 р. N 1176-р Київ

{ Розпорядження втратило чинність на підставі Постанови КМ N 397 ( 397-2010-п ) від 02.06.2010 }

Про зміну складу Урядової комісії з розслідування причин та ліквідації наслідків аварії на орендному підприємстві "Шахта імені О.Ф. Засядька"

Ввести до складу Урядової комісії з розслідування причин та ліквідації наслідків аварії на орендному підприємстві "Шахта імені О.Ф. Засядька", утвореної розпорядженням Кабінету Міністрів України від 18 листопада 2007 р. N 997 ( 997-2007-р ), Турчинова Олександра Валентиновича - Першого віце-прем'єр-міністра України як голову Комісії, вивівши з її складу Клюєва Андрія Петровича.
