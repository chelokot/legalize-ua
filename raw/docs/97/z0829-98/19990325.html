N 161 від 15.12.98 Зареєстровано в Міністерстві м.Київ юстиції України 28 грудня 1998 р. за N 829/3269

( Наказ втратив чинність на підставі Наказу Мінекономіки N 33 ( z0182-99 ) від 15.03.99 )

Про затвердження граничного рівня оптової ціни на газ природний, що використовується для потреб населення, бюджетних установ і організацій, тих підприємств комунальної теплоенергетики та котелень промислових підприємств, які відпускають теплову енергію зазначеним споживачам, і тарифів на послуги з транспортування та реалізації природного газу для споживачів України

Згідно з повноваженнями, затвердженими постановою Кабінету Міністрів України від 25.12.96 N 1548 ( 1548-96-п ) "Про встановлення повноважень органів виконавчої влади та виконавчих органів міських рад щодо регулювання цін (тарифів)", НАКАЗУЮ:

1. Затвердити граничний рівень оптової ціни на газ природний, що використовується для потреб населення, бюджетних установ і організацій, тих підприємств комунальної теплоенергетики та котелень промислових підприємств, які відпускають теплову енергію зазначеним споживачам (додається).

2. Затвердити тарифи на послуги з транспортування та реалізації природного газу для споживачів України ( z0830-98 ) (додаються).

3. Затвердити Порядок формування граничного рівня оптової ціни на газ природний, що використовується для потреб населення, бюджетних установ і організацій, тих підприємств комунальної теплоенергетики та котелень промислових підприємств, які відпускають теплову енергію зазначеним споживачам, і тарифів на послуги з його транспортування та реалізації для споживачів України ( z0831-98 ) (додається).

4. Визнати таким, що втрачає чинність, наказ Мінекономіки від 31.10.97 N 121 ( z0561-97 ) "Про затвердження цін на газ природний і тарифів на послуги з його транспортування на 1998 рік", зареєстрований у Мін'юсті 27.11.97 за N 561/2365.
