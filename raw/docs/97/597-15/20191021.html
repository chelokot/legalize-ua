Верховна Рада України; Закон від 06.03.2003 № 597-IV

Про внесення змін до деяких законів України (щодо банкрутства гірничих підприємств)

Стан: Чинний

Ідентифікатор: 597-15

Текст документа від 21.10.2019:

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України (щодо банкрутства гірничих підприємств)

( Відомості Верховної Ради України (ВВР), 2003, N 24, ст.160 )

{ Із змінами, внесеними згідно із Законом N 2269-VIII ( 2269-19 ) від 18.01.2018, ВВР, 2018, N 12, ст.68 Кодексом N 2597-VIII ( 2597-19 ) від 18.10.2018, ВВР, 2019, N 19, ст.74 }

З метою запобігання знеціненню та втраті майна підприємств, у статутному фонді яких є державна частка цього майна, Верховна Рада України постановляє:

I. Внести зміни до таких законів України:

{ Пункт 1 розділу I втратив чинність на підставі Кодексу N 2597-VIII ( 2597-19 ) від 18.10.2018 }

{ Пункт 2 розділу I втратив чинність на підставі Закону N 2269-VIII ( 2269-19 ) від 18.01.2018 }

II. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 6 березня 2003 року N 597-IV
