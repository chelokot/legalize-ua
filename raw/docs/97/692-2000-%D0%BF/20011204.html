Про забезпечення виконання завдань з питань житлової політики

Стан: Чинний

Текст документа від 04.12.2001:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 квітня 2000 р. N 692 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про забезпечення виконання завдань з питань житлової політики

{ Із змінами, внесеними згідно з Постановою КМ N 1631 ( 1631-2001-п ) від 04.12.2001 }

Кабінет Міністрів України постановляє:

1. З метою забезпечення виконання завдань з питань житлової політики, збільшити граничну чисельність працівників Секретаріату Кабінету Міністрів України на чотири одиниці.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 1631 ( 1631-2001-п ) від 04.12.2001 }

2. Міністерству фінансів внести необхідні зміни до кошторису видатків на утримання Секретаріату Кабінету Міністрів України за рахунок загальних видатків на утримання органів виконавчої влади державного бюджету.

3. Визнати таким, що втратило чинність, розпорядження Кабінету Міністрів України від 9 березня 2000 р. N 116 ( 116-2000-р ).
