Про затвердження складу президії Вищої атестаційної комісії

Кабінет Міністрів України постановляє:

1. Затвердити склад президії Вищої атестаційної комісії згідно з додатком 1.

Не для друку

2. Визнати такими, що втратили чинність, постанови Кабінету Міністрів України згідно з переліком, що додається.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 1 липня 2002 р. N 913

ПЕРЕЛІК постанов Кабінету Міністрів України, що втратили чинність

1. Постанова Кабінету Міністрів України від 9 листопада 1998 р. N 1757 ( 1757-98-п ) "Про затвердження складу президії Вищої атестаційної комісії України".

2. Постанова Кабінету Міністрів України від 22 лютого 1999 р. N 240 ( 240-99-п ) "Про внесення змін до складу президії Вищої атестаційної комісії України".

3. Постанова Кабінету Міністрів України від 2 березня 2000 р. N 444 ( 444-2000-п ) "Про внесення змін до складу президії Вищої атестаційної комісії України".

4. Постанова Кабінету Міністрів України від 12 жовтня 2000 р. N 1548 ( 1548-2000-п ) "Про внесення змін до складу президії Вищої атестаційної комісії" (Офіційний вісник України, 2000 р., N 42, ст. 1788).

5. Постанова Кабінету Міністрів України від 23 квітня 2001 р. N 378 ( 378-2001-п ) "Про внесення змін до складу президії Вищої атестаційної комісії України" (Офіційний вісник України, 2001 р., N 17, ст. 749).
