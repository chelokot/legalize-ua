Про Український центр реструктуризації підприємств та розвитку приватного сектору

{ Із змінами, внесеними згідно з Постановами КМ N 1038 ( 1038-2000-п ) від 27.06.2000 N 64 ( 64-2002-п ) від 24.01.2002 N 1106 ( 1106-2003-п ) від 17.07.2003 N 503 ( 503-2009-п ) від 21.05.2009 }

З метою впровадження ефективних механізмів реалізації проекту технічної допомоги позики Світового Банку на розвиток підприємств (Кредитна угода про позику на розвиток підприємств між Україною і Міжнародним банком реконструкції та розвитку від 27 червня 1996 р. N UA-4057 ( 996_672 ), розроблення і здійснення наступних проектів розвитку приватного сектору Кабінет Міністрів України постановляє:

1. Прийняти пропозицію Фонду державного майна, погоджену з Світовим Банком, про утворення Українського центру реструктуризації підприємств та розвитку приватного сектору (далі - Центр) з покладенням на нього прав і обов'язків Фонду державного майна, які виконувалися групою впровадження проекту технічної допомоги відповідно до положень Кредитної угоди про позику на розвиток підприємств між Україною і Міжнародним банком реконструкції та розвитку від 27 червня 1996 р. N UA-4057.

2. Затвердити Положення про Український центр реструктуризації підприємств та розвитку приватного сектору, що додається.

3. До призначення радою Центру виконавчого директора Центру покласти виконання його обов'язків на Шепеля Валерія Івановича.

4. Раді Центру визначити обсяг його фінансування за рахунок невикористаних коштів технічного компонента позики Світового Банку на розвиток підприємств та затвердити кошторис на 1998 рік.

5. Контроль за виконанням цієї постанови покласти на Віце-прем'єр-міністра України з питань економіки Тігіпка С.Л.

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 3 листопада 1998 р. N 1736

ПОЛОЖЕННЯ про Український центр реструктуризації підприємств та розвитку приватного сектору

1. Український центр реструктуризації підприємств та розвитку приватного сектору (далі - Центр) утворено з метою організаційного і фінансового забезпечення виконання в рамках міжнародних договорів України та договорів з іноземними юридичними особами програм розвитку приватного сектору, а також інших програм реструктуризації підприємств. { Абзац перший пункту 1 в редакції Постанови КМ N 503 ( 503-2009-п ) від 21.05.2009 }

Центр є неприбутковою організацією.

2. У своїй діяльності Центр керується Конституцією ( 254к/96-ВР ) і законами України, актами Президента України і Кабінету Міністрів України, іншими нормативно-правовими актами, а також цим Положенням.

3. Центр є юридичною особою, має самостійний баланс, рахунки в установах банків (у тому числі валютний), печатку, відповідні штампи та бланк.

4. Центр несе відповідальність за своїми зобов'язаннями лише у межах свого майна. Центр не відповідає за зобов'язаннями держави, а держава не відповідає за зобов'язаннями Центру.

5. Основними завданнями Центру є:

організаційне забезпечення реалізації проектів реструктуризації підприємств та розвиту приватного сектору;

забезпечення цільового використання коштів технічної допомоги і кредитів міжнародних фінансових організацій, що спрямовуються на надання технічної допомоги підприємствам відповідно до проектів, участь в реалізації яких приймає Центр;

розроблення та здійснення проектів фінансового оздоровлення і реструктуризації підприємств, залучення іноземних та вітчизняних партнерів до виконання цих програм;

проведення навчання вітчизняних консультантів та працівників підприємств з питань їх реструктуризації та розвитку приватного сектору.

6. Центр відповідно до покладених на нього завдань:

формує робочі групи у складі іноземних консультантів та вітчизняних спеціалістів для роботи з підприємствами, які беруть участь у виконанні проектів їх реструктуризації та розвитку приватного сектору;

контролює ефективність діяльності цих груп;

залучає іноземних та вітчизняних консультантів для підготовки проектів реструктуризації підприємств, бізнес-планів тощо;

координує роботу, пов'язану з виконанням на підприємствах планів їх реструктуризації;

організує проведення тендерів для відбору іноземних та вітчизняних консультантів і укладає з переможцями відповідні контракти;

сприяє іноземним партнерам та їхнім експертам у встановленні зв'язків з адміністрацією підприємств, які беруть участь у виконанні його проектів, а також з органами державної влади;

подає донорським організаціям на їх запит звіти про ефективність роботи направлених ними іноземних консультантів;

надає державним та недержавним юридичним особам на підставі відповідних договорів експертні та консультаційні послуги, що необхідні для виконання завдань Центру, визначених цим Положенням;

надає послуги з питань реструктуризації підприємств шляхом проведення консультацій, забезпечення видання методичних матеріалів та довідкових посібників, організації семінарів і конференцій, укладення прямих договорів з державними та недержавними юридичними особами;

систематично проводить аналіз статистичних даних про хід реструктуризації підприємств, створює відповідний інформаційний банк;

виконує інші функції, пов'язані з реструктуризацією підприємств, розвитком приватного сектору, реалізацією проектів, пов'язаних з реструктуризацією підприємств та розвитком приватного сектору. { Абзац пункту 6 із змінами, внесеними згідно з Постановою КМ N 503 ( 503-2009-п ) від 21.05.2009 }

7. Для виконання своїх завдань Центр має право:

одержувати відповідну інформацію від державних органів приватизації, Держкомстату, інших органів виконавчої влади, органів місцевого самоврядування;

самостійно вести свою діяльність, включаючи складання кошторису, формування власної структури та штатного розпису;

залучати на договірних засадах юридичних та фізичних осіб для експертного та консультаційного забезпечення окремих робіт, що виконуються Центром в рамках відповідних програм, проектів та договорів; { Абзац четвертий пункту 7 в редакції Постанови КМ N 503 ( 503-2009-п ) від 21.05.2009 }

укладати угоди з юридичними особами про виконання окремих функцій, що належать до його компетенції.

8. З метою реалізації покладених на нього завдань Центр може утворювати регіональні філіали або представництва, що діють на підставі положень, затверджених радою Центру.

9. Джерелами фінансування діяльності Центру є: { Абзац пункту 9 в редакції Постанови КМ N 503 ( 503-2009-п ) від 21.05.2009 }

кошти міжнародних організацій, іноземних держав, урядів та уповноважених урядами іноземних держав органів, іноземних муніципальних органів, іноземних юридичних осіб, що виділяються для реалізації проектів, учасником яких є Центр; { Абзац пункту 9 в редакції Постанови КМ N 503 ( 503-2009-п ) від 21.05.2009 }

кошти, що надходять як безповоротна фінансова допомога чи добровільні пожертвування; { Абзац пункту 9 в редакції Постанови КМ N 503 ( 503-2009-п ) від 21.05.2009 }

коштів, що надходять від виконання ним завдань, передбачених цим Положенням;

інших надходжень, якщо це не суперечить законодавству України.

10. Центр володіє, користується та розпоряджається майном на праві оперативного управління відповідно до цілей, визначених цим Положенням.

11. Кошти Центру витрачаються відповідно до річного кошторису, що затверджується радою Центру. Не витрачені в поточному році кошти Центру використовуються за призначенням у наступний рік.

Майно та кошти Центру спрямовуються лише на забезпечення виконання завдань Центру та покриття витрат, пов'язаних з його діяльністю.

12. Органами управління Центру є рада Центру та виконавчий директор.

13. Рада Центру є вищим органом управління Центру і в межах своїх повноважень:

призначає на посаду та звільняє з посади виконавчого директора Центру і його заступників, визначає коло їх функціональних обов'язків;

приймає рішення про утворення, ліквідацію та реорганізацію регіональних філіалів та представництв Центру;

затверджує кошторис та робочий план Центру;

визначає стратегію розвитку Центру.

14. Рада Центру утворюється у складі Голови Держкомпідприємництва (голова ради), заступника Голови Держкомпідприємництва, по одному представнику від Мінекономіки, Мінфіну, Мінпромполітики, Фонду державного майна та Антимонопольного комітету.

До складу ради Центру можуть входити представники інших центральних органів виконавчої влади, а також міжнародних фінансових організацій, донорів, інших іноземних та вітчизняних юридичних осіб, які разом із Центром є учасниками програм розвитку приватного сектору та реструктуризації підприємств.

{ Пункт 14 в редакції Постанов КМ N 64 ( 64-2002-п ) від 24.01.2002, N 503 ( 503-2009-п ) від 21.05.2009 }

15. Персональний склад ради Центру, а також структуру, штатний розпис і кошторис Центру, положення про його органи управління затверджує голова ради Центру.

{ Пункт 15 із змінами, внесеними згідно з Постановою КМ N 503 ( 503-2009-п ) від 21.05.2009 }

16. Рішення ради Центру оформляються протоколами, які підписуються його головою.

17. Керівництво поточною роботою Центру здійснює його виконавчий директор, що призначається та звільняється з посади радою Центру. До компетенції виконавчого директора належать усі питання діяльності Центру, крім тих, які згідно з цим Положенням або рішенням ради Центру належать до компетенції ради.

18. Працівники Центру приймаються на роботу відповідно до законодавства. ( Пункт 18 із змінами, внесеними згідно з Постановою КМ N 1038 ( 1038-2000-п ) від 27.06.2000 )

19. Центр веде бухгалтерський облік та статистичну звітність відповідно до законодавства.

20. Діяльність Центру може бути припинена шляхом його ліквідації чи реорганізації відповідно до законодавства.
