Кабінет Міністрів України; Постанова, Перелік від 14.02.2007 № 202

Про визнання такими, що втратили чинність, постанов Ради Міністрів УРСР і Кабінету Міністрів України з питань управління об'єктами державної власності

Стан: Чинний

Ідентифікатор: 202-2007-п

Текст документа від 14.02.2007:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 лютого 2007 р. N 202 Київ

Про визнання такими, що втратили чинність, постанов Ради Міністрів УРСР і Кабінету Міністрів України з питань управління об'єктами державної власності

Кабінет Міністрів України постановляє:

Визнати такими, що втратили чинність, постанови Ради Міністрів УРСР і Кабінету Міністрів України з питань управління об'єктами державної власності згідно з переліком, що додається.

Прем'єр-міністр України В.ЯНУКОВИЧ

Інд. 25

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 14 лютого 2007 р. N 202

ПЕРЕЛІК постанов Ради Міністрів УРСР і Кабінету Міністрів України з питань управління об'єктами державної власності, що втратили чинність

1. Постанова Ради Міністрів УРСР від 11 липня 1983 р. N 299 ( 299-83-п ) "Про порядок створення, реорганізації і ліквідації підприємств, об'єднань, організацій і установ республіканського та місцевого підпорядкування" (ЗП УРСР, 1983 р., N 7, ст. 43).

2. Постанова Ради Міністрів УРСР від 26 червня 1987 р. N 229 ( 229-87-п ) "Про внесення змін та визнання такими, що втратили чинність, рішень Уряду УРСР у зв'язку з постановою Ради Міністрів УРСР та Укррадпрофу від 22 лютого 1985 р. N 82 "Про вдосконалення організації, системи оплати та стимулювання праці у будівництві" (ЗП УРСР, 1987 р., N 8, ст. 54).

3. Пункт 3 переліку рішень Уряду УРСР, що втратили чинність, затвердженого постановою Ради Міністрів УРСР від 12 серпня 1989 р. N 214 ( 214-89-п ) (ЗП УРСР, 1989 р., N 10, ст. 55).

4. Пункт 1 змін, що вносяться до рішень Уряду УРСР, затверджених постановою Ради Міністрів УРСР від 1 березня 1990 р. N 47 ( 47-90-п ) (ЗП УРСР, 1990 р., N 3, ст. 15).

5. Постанова Ради Міністрів УРСР від 22 вересня 1990 р. N 278 ( 278-90-п ) "Про заходи щодо створення і розвитку малих підприємств" (ЗП УРСР, 1991 р., N 1, ст. 1).

6. Пункт 3 змін, що вносяться до рішень Уряду України, затверджених постановою Кабінету Міністрів України від 19 жовтня 1991 р. N 280 ( 280-91-п ) (ЗП України, 1991 р., N 11, ст. 114).

7. Постанова Кабінету Міністрів України від 22 липня 1998 р. N 1129 ( 1129-98-п ) "Про деякі питання управління казенним підприємством" (Офіційний вісник України, 1998 р., N 30, ст. 1120).

8. Постанова Кабінету Міністрів України від 28 лютого 2005 р. N 158 ( 158-2005-п ) "Про часткове зняття обмежень щодо розпорядження об'єктами права державної власності" (Офіційний вісник України, 2005 р., N 9, ст. 472).

9. Постанова Кабінету Міністрів України від 21 липня 2005 р. N 632 ( 632-2005-п ) "Деякі питання приватизації об'єктів права державної власності" (Офіційний вісник України, 2005 р., N 30, ст. 1813).

10. Постанова Кабінету Міністрів України від 8 липня 2006 р. N 946 ( 946-2006-п ) "Питання реорганізації, ліквідації та реструктуризації державних підприємств" (Офіційний вісник України, 2006 р., N 28, ст. 2011).

11. Постанова Кабінету Міністрів України від 23 січня 2006 р. N 44 ( 44-2006-п ) "Про внесення зміни до пункту 1 постанови Кабінету Міністрів України від 28 лютого 2005 р. N 158" (Офіційний вісник України, 2006 р., N 4, ст. 158).
