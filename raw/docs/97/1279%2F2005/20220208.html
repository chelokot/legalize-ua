УКАЗ ПРЕЗИДЕНТА УКРАЇНИ

Про Спеціального представника України з питань придністровського врегулювання

{ Із змінами, внесеними згідно з Указами Президента N 267/2006 ( 267/2006 ) від 30.03.2006 N 699/2008 ( 699/2008 ) від 09.08.2008 N 759/2010 ( 759/2010 ) від 06.07.2010 N 905/2010 ( 905/2010 ) від 16.09.2010 N 375/2014 ( 375/2014 ) від 04.04.2014 N 229/2017 ( 229/2017 ) від 21.08.2017 N 45/2022 ( 45/2022 ) від 08.02.2022 }

З метою забезпечення реалізації ініціатив України та міжнародних домовленостей щодо врегулювання ситуації у Придністровському регіоні Республіки Молдова постановляю:

1. Затвердити Положення про Спеціального представника України з питань придністровського врегулювання (додається).

2. Призначити КЛИМЕНКА Юрія Аркадійовича Спеціальним представником України з питань придністровського врегулювання.

{ Стаття 2 із змінами, внесеними згідно з Указами Президента N 267/2006 ( 267/2006 ) від 30.03.2006, N 699/2008 ( 699/2008 ) від 09.08.2008, N 759/2010 ( 759/2010 ) від 06.07.2010, N 905/2010 ( 905/2010 ) від 16.09.2010, N 375/2014 ( 375/2014 ) від 04.04.2014, N 229/2017 ( 229/2017 ) від 21.08.2017, N 45/2022 ( 45/2022 ) від 08.02.2022 }

3. Звільнити ЧАЛОГО Петра Федоровича з посади Повноважного представника Президента України в переговорному процесі з політичного врегулювання конфлікту в придністровському регіоні Республіки Молдова.

4. Кабінету Міністрів України вирішити питання щодо матеріального та соціально-побутового забезпечення Спеціального представника України з питань придністровського врегулювання.

ПОЛОЖЕННЯ про Спеціального представника України з питань придністровського врегулювання

1. Спеціальний представник України з питань придністровського врегулювання (далі - Представник України) є посадовою особою, на яку покладається забезпечення реалізації ініціатив України та міжнародних домовленостей щодо врегулювання ситуації у Придністровському регіоні Республіки Молдова.

2. Представник України у своїй діяльності керується Конституцією України ( 254к/96-ВР ) та законами України, актами Президента України, Кабінету Міністрів України, міжнародними договорами України, а також цим Положенням.

3. Представника України призначає на посаду та звільняє з посади Президент України за поданням Міністра закордонних справ України.

4. Основними завданнями Представника України є:

представлення та забезпечення реалізації позиції України щодо врегулювання ситуації у Придністровському регіоні Республіки Молдова;

координація заходів державних органів України щодо врегулювання придністровської проблеми;

забезпечення ведення переговорів з іноземними державами та міжнародними організаціями - учасниками врегулювання ситуації у Придністровському регіоні Республіки Молдова, проведення консультацій з метою реалізації основних засад позиції України щодо врегулювання цієї ситуації;

аналіз ситуації в регіоні та підготовка пропозицій Президентові України щодо дальших дій України у процесі придністровського врегулювання;

підготовка матеріалів для участі Президента України у переговорах з іноземними державами та міжнародними організаціями - учасниками врегулювання ситуації у Придністровському регіоні Республіки Молдова;

сприяння захисту прав громадян України та закордонних українців, які проживають у Придністровському регіоні;

надання офіційних коментарів стосовно позиції України щодо врегулювання придністровської проблеми.

5. Представник України для виконання покладених на нього завдань має право:

одержувати в установленому порядку від органів виконавчої влади, органів місцевого самоврядування, підприємств, установ і організацій інформацію та документи, необхідні для його роботи;

залучати в разі потреби в установленому порядку представників органів виконавчої влади, експертів, учених до опрацювання питань, що належать до повноважень Представника України.

6. Представник України для виконання покладених на нього обов'язків взаємодіє з відповідними центральними та місцевими органами виконавчої влади, дипломатичними представництвами України.

7. Представник України щомісяця звітує перед Президентом України про проведену роботу.

8. Організаційне, інформаційне та інші види забезпечення діяльності Представника України здійснюються Міністерством закордонних справ України.
