МІНІСТЕРСТВО АГРАРНОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

08.04.2004 N 129

Зареєстровано в Міністерстві юстиції України 26 квітня 2004 р. за N 535/9134

Про доповнення до Переліку видів сільськогосподарської продукції, яка ввозиться на митну територію України як сировина для подальшої переробки

З метою поліпшення забезпечення вітчизняних підприємств сировиною та відповідно до постанови Кабінету Міністрів України від 19.06.98 N 931 ( 931-98-п ) "Про переміщення через митний кордон сільськогосподарської продукції, що ввозиться для переробки" (із змінами, унесеними згідно з постановою Кабінету Міністрів України від 11.10.02 N 1493 ( 1493-2002-п ) НАКАЗУЮ:

1. Доповнити Перелік видів сільськогосподарської продукції, яка ввозиться на митну територію України як сировина для подальшої переробки, затверджений наказом Міністерства агропромислового комплексу України від 07.10.98 N 297 ( z0724-98 ), зареєстрований в Мін'юсті 13.11.98 за N 724/3164 (із змінами, унесеними згідно з наказами Мінагрополітики від 05.09.2001 N 262 ( z0814-01 ) та від 14.07.2003 N 239 ( z0603-03 ), позицією такого змісту:

------------------------------------------------------------------

| | |"Група 05 |

|-----+---------------+------------------------------------------|

| |0511 99 10 90 |Сухожилля та жили, обрізи та аналогічні |

| | |відходи необробленої шкіри". |

------------------------------------------------------------------

2. Департаменту міжнародної інтеграції, інвестиційної політики та розвитку аграрного бізнесу (Письмак В.П.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

3. Контроль за виконанням наказу покласти на заступника Міністра Омельяненка Г.Г.
