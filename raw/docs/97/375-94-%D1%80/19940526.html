Кабінет Міністрів України; Розпорядження від 26.05.1994 № 375-р

Про дозвіл Держкомрезерву на виділення споживачам із державного резерву паперу

Стан: Чинний

Ідентифікатор: 375-94-р

Текст документа від 26.05.1994:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 26 травня 1994 р. N 375-р Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Дозволити Держкомрезерву виділити споживачам у травні ц.р. із державного резерву 990 тонн паперу згідно з додатками N 1-3.

Відпуск зазначеної кількості паперу провести на умовах попередньої оплати з перерахуванням одержаних коштів до державного бюджету.

Укрліспаперу повернути папір до державного резерву у IV кварталі 1994 року.

Виконуючий обов'язки Прем'єр-міністра України Ю.ЗВЯГІЛЬСЬКИЙ
