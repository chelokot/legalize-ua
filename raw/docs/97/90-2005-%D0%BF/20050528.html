Кабінет Міністрів України; Постанова від 24.01.2005 № 90

Про порядок компенсації у 2005 році виробникам - суб'єктам підприємницької діяльності додаткових витрат, пов'язаних з підвищенням ставки акцизного збору на спирт етиловий, що використовується для виготовлення лікарських засобів

Стан: Чинний

Ідентифікатор: 90-2005-п

Текст документа від 28.05.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 24 січня 2005 р. N 90 Київ

Про порядок компенсації у 2005 році виробникам - суб'єктам підприємницької діяльності додаткових витрат, пов'язаних з підвищенням ставки акцизного збору на спирт етиловий, що використовується для виготовлення лікарських засобів

( Із змінами, внесеними згідно з Постановою КМ N 403 ( 403-2005-п ) від 28.05.2005 )

Кабінет Міністрів України постановляє:

Установити, що у 2005 році компенсація виробникам - суб'єктам підприємницької діяльності додаткових витрат, пов'язаних з підвищенням з 1 січня 2004 р. ставки акцизного збору на спирт етиловий, що використовується для виготовлення лікарських засобів, проводиться відповідно до постанови Кабінету Міністрів України від 30 грудня 2003 р. N 2077 ( 2077-2003-п ) (Офіційний вісник України, 2003 р., N 52, ст. 2822).

У зв'язку з цим внести до зазначеної постанови зміни, що додаються.

Виконуючий обов'язки Прем'єр-міністра України М.АЗАРОВ

Інд. 28

( Зміни, що вносяться до постанови Кабінету Міністрів України від 30 грудня 2003 р. N 2077 ( 2077-2003-п ), втратили чинність на підставі Постанови КМ N 403 ( 403-2005-п ) від 28.05.2005 )
