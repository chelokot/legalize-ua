Про затвердження нового складу Міжвідомчої робочої групи з координації здійснення особливо важливих енергозберігаючих проектів

Стан: Втратив чинність

Ідентифікатор: 510-2004-р

Текст документа від 16.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 28 липня 2004 р. N 510-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 746 ( 746-2005-п ) від 16.08.2005 )

Про затвердження нового складу Міжвідомчої робочої групи з координації здійснення особливо важливих енергозберігаючих проектів

На часткову зміну абзацу першого розпорядження Кабінету Міністрів України від 13 грудня 2001 р. N 565 ( 565-2001-р ) затвердити новий склад Міжвідомчої робочої групи з координації здійснення особливо важливих енергозберігаючих проектів, що додається.
