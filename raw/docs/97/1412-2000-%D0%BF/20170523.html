ПОСТАНОВА від 11 вересня 2000 р. N 1412 Київ

{ Постанова втратила чинність на підставі Постанови КМ N 244 ( 244-2017-п ) від 05.043.2017 }

Питання діяльності Німецько-Українського фонду

Кабінет Міністрів України постановляє:

1. Скасувати пункт 2 постанови Кабінету Міністрів України від 8 липня 1999 р. N 1207 ( 1207-99-п ) "Про Положення про Німецько-Український фонд" (Офіційний вісник України, 1999 р., N 27, ст. 1336).

У зв'язку з цим поновити починаючи з 19 квітня 1999 р. дію пункту 2 постанови Кабінету Міністрів України від 19 квітня 1999 р. N 628 ( 628-99-п ) "Про Німецько-Український фонд" (Офіційний вісник України, 1999 р., N 16, ст. 653).

2. Пункт 1 постанови Кабінету Міністрів України від 8 липня 1999 р. N 1207 викласти в такій редакції:

"1. Схвалити зміни до Положення про Німецько-Український фонд, затвердженого постановою Кабінету Міністрів України від 19 квітня 1999 року N 628 "Про Німецько-Український фонд", виклавши його у редакції, що додається.

Доручити Міністерству фінансів підписати від імені Кабінету Міністрів України зазначене Положення, дозволивши йому вносити у разі потреби зміни і доповнення до нього".

Прем'єр-міністр України В.ЮЩЕНКО
