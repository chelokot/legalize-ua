Кабінет Міністрів України; Постанова від 20.11.2003 № 1808

Про порядок випуску, обігу і погашення податкових векселів при ввезенні (пересиланні) на митну територію України продовольчого зерна

Стан: Втратив чинність

Ідентифікатор: 1808-2003-п

Текст документа від 23.02.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 20 листопада 2003 р. N 1808 Київ

( Постанова втратила чинність на підставі Постанови КМ N 143 ( 143-2005-п ) від 23.02.2005 )

Про порядок випуску, обігу і погашення податкових векселів при ввезенні (пересиланні) на митну територію України продовольчого зерна

Кабінет Міністрів України постановляє:

1. Установити, що на період до 1 липня 2004 р. платники податку на додану вартість при ввезенні (пересиланні) на митну територію України товарів згідно з кодами УКТ ЗЕД 1001 10 00 90, 1001 90 99 00, 1002 00 00 00 ( 2371а-14 ) можуть за своїм рішенням надавати органам митного контролю податковий вексель строком до 180 днів згідно з Порядком випуску, обігу та погашення векселів, які видаються на суму податку на додану вартість при ввезенні (пересиланні) товарів на митну територію України, затвердженим постановою Кабінету Міністрів України від 1 жовтня 1997 р. N 1104 ( 1104-97-п ) (Офіційний вісник України, 1997 р., число 41, с. 26; 1998 р., N 28, ст. 1050, N 34, ст. 1277; 1999 р., N 26, ст. 1234, N 27, ст. 1330; 2000 р., N 47, ст. 2040; 2001 р., N 43, ст. 1928; 2002 р., N 2, ст. 69, N 7, ст. 288, N 42, ст. 1925; 2003 р., N 20, ст. 890), без урахування вимог, передбачених абзацами п'ятим і шостим пункту 4 зазначеного Порядку.

2. Визнати такими, що втратили чинність:

розпорядження Кабінету Міністрів України від 27 серпня 2003 р. N 539 ( 539-2003-р ) "Про строк погашення простих векселів платників податку на додану вартість у разі ввезення зернових культур, що закладаються до державного резерву" (Офіційний вісник України, 2003 р., N 35, ст. 1910);

розпорядження Кабінету Міністрів України від 23 вересня 2003 р. N 578 ( 578-2003-р ) "Про строк погашення векселів, які видаються на суму податку на додану вартість при ввезенні (пересиланні) товарів на митну територію України" (Офіційний вісник України, 2003 р., N 39, ст. 2072).
