ДЕРЖАВНИЙ КОМІТЕТ БУДІВНИЦТВА, АРХІТЕКТУРИ ТА ЖИТЛОВОЇ ПОЛІТИКИ УКРАЇНИ

НАКАЗ

N 248 від 01.11.2000 Зареєстровано в Міністерстві м. Київ юстиції України 17 листопада 2000 р. за N 829/5050

{ Наказ втратив чинність на підставі Наказу Міністерства регіонального розвитку, будівництва та житлово-комунального господарства N 327 ( z1216-12 ) від 02.07.2012 }

Про визнання таким, що втратило чинність, Примірного положення про госпрозрахункові підрозділи при місцевих органах містобудування та архітектури

У зв'язку з прийняттям постанови Кабінету Міністрів України від 20.07.2000 N 1146 ( 1146-2000-п ) "Про затвердження типових положень про управління містобудування та архітектури обласної, Київської та Севастопольської міської, відділ містобудування та архітектури районної у місті Києві, відділ містобудування, архітектури та житлово-комунального господарства районної, районної у місті Севастополі державної адміністрації", а також з метою забезпечення виконання вимог Указів Президента України від 03.02.98 N 79/98 ( 79/98 ) "Про усунення обмежень, що стримують розвиток підприємницької діяльності", від 26.02.99 N 219/99 ( 219/99 ) "Про основні напрями конкурентної політики на 1999-2000 роки та заходи щодо їх реалізації" та від 22.01.2000 N 89/2000 ( 89/2000 ) "Про запровадження єдиної державної регуляторної політики у сфері підприємництва" НАКАЗУЮ:

1. Вважати таким, що втратило чинність, Примірне положення про госпрозрахункові підрозділи при місцевих органах містобудування та архітектури, затверджене наказом Державного комітету України у справах містобудування і архітектури від 11.11.96 N 193 ( z0727-96 ), зареєстроване в Міністерстві юстиції України 19.12.96 за N 727/1752.

2. Управлінням і відділам Комітету, місцевим органам містобудування та архітектури прийняти даний наказ до відома та керівництва в роботі.

3. Місцевим органам містобудування та архітектури в установленому порядку здійснити заходи реорганізації госпрозрахункових підрозділів у підприємства комунальної власності, які виконують роботи з підготовки і комплектування вихідних даних на проектування, надають інші послуги у сфері містобудування та архітектури.

4. Контроль за виконанням наказу покласти на заступника Голови Комітету Присяжнюка В.Ф.

Голова Комітету В.М.Гусаков
