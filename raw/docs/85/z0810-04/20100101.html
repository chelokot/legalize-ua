ДЕРЖАВНИЙ КОМІТЕТ СТАТИСТИКИ УКРАЇНИ

НАКАЗ

17.06.2004 N 382

Зареєстровано в Міністерстві юстиції України 2 липня 2004 р. за N 810/9409

Про затвердження інструкцій щодо заповнення форм державних статистичних спостережень з обліку послуг

{ Із змінами, внесеними згідно з Наказами Державного комітету статистики N 228 ( z0894-07 ) від 20.07.2007 N 282 ( z0756-09 ) від 27.07.2009 }

Відповідно до статті 14 Закону України "Про державну статистику" ( 2614-12 ) та з метою удосконалення державних статистичних спостережень ринку послуг НАКАЗУЮ:

1. Затвердити:

1.1. Інструкцію щодо заповнення форми державного статистичного спостереження N 1-послуги, місячна "Звіт про обсяги реалізованих послуг" (додається).

1.2. Інструкцію щодо заповнення форми державного статистичного спостереження N 1-послуги, річна "Звіт про обсяги реалізованих послуг" (додається) ( z0811-04 ). { Інструкція втратила чинність зі звіту за 2007 рік на підставі Наказу Державного комітету статистики N 228 ( z0894-07 ) від 20.07.2007 }

1.3. Інструкцію щодо заповнення форми державного статистичного спостереження N 1-послуги (реклама), річна "Звіт про рекламну діяльність" (додається) ( z0812-04 ).

{ Підпункт 1.4 пункту 1 втратив чинність на підставі Наказу Державного комітету статистики N 282 ( z0756-09 ) від 27.07.2009 }

2. Поширити дію затверджених інструкцій щодо заповнення форм державних статистичних спостережень з обліку послуг на такі підприємства:

2.1. Інструкцію щодо заповнення форми державного статистичного спостереження N 1-послуги, річна "Звіт про обсяги реалізованих послуг" ( z0811-04 ) - на юридичних осіб усіх форм власності та їх відокремлених структурних підрозділів незалежно від форми господарювання, для яких надання послуг є основним видом діяльності.

2.2. Інструкцію щодо заповнення форми державного статистичного спостереження N 1-послуги, місячна "Звіт про обсяги реалізованих послуг" - на юридичних осіб усіх форм власності та їх відокремлених структурних підрозділів, для яких надання послуг є основним видом діяльності.

2.3. Інструкцію щодо заповнення форми державного статистичного спостереження N 1-послуги (реклама), річна "Звіт про рекламну діяльність" ( z0812-04 ) - на юридичних осіб та їх відокремлених структурних підрозділів незалежно від організаційно-правової форми господарювання та форми власності, основним видом діяльності яких є надання рекламних послуг.

2.4. Інструкцію щодо заповнення форми державного статистичного спостереження N 1-послуги (нерухомість), річна "Звіт про надання посередницьких послуг при операціях з нерухомістю" ( z0813-04 ) - на юридичних осіб та їх відокремлених структурних підрозділів незалежно від організаційно-правової форми господарювання та форми власності, основним видом діяльності яких є надання посередницьких послуг при операціях з нерухомістю.

3. Управлінню статистики послуг та соціальних програм (Калачова І.В.) передати управлінню справами (Царський В.І.) оригінали інструкцій, затверджених у пункті 1 цього наказу, для тиражування.

4. Фінансово-економічному управлінню (Сорокіна Т.В.) забезпечити фінансування виготовлення та доставки інструкцій, затверджених у пункті 1 цього наказу.

5. Управлінню справами (Царський В.І.) забезпечити контроль за своєчасним виготовленням та відправленням інструкцій, затверджених у пункті 1 цього наказу, на адресу головних управлінь статистики в Автономній Республіці Крим, в областях, у місті Києві та Управління статистики у місті Севастополі.

6. З моменту набрання чинності цим наказом скасувати всі роз'яснення, що додаються до форм державних статистичних спостережень з обліку послуг, затверджених наказом Держкомстату від 18 липня 2003 року N 221 ( v0221202-03 ).

7. Контроль за виконанням цього наказу покласти на заступника Голови Комітету Власенко Н.С.

Голова комітету О.Г.Осауленко
