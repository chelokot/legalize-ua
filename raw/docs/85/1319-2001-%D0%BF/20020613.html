Про заходи щодо вдосконалення комплексної утилізації військового майна Збройних Сил

{ Із змінами, внесеними згідно з Постановами КМ N 746 ( 746-2002-п ) від 01.06.2002 N 817 ( 817-2002-п ) від 13.06.2002 }

З метою вдосконалення організації комплексної утилізації непридатного для подальшого використання і зберігання військового майна Збройних Сил Кабінет Міністрів України постановляє:

1. Прийняти пропозицію Міністерства оборони, погоджену з Міністерством економіки та з питань європейської інтеграції, Міністерством промислової політики, щодо надання підприємствам, які на договірних засадах організовують роботи з комплексної утилізації озброєння, військової техніки та іншого військового майна Збройних Сил (далі - військове майно), згідно з додатком повноваження з реалізації на внутрішньому ринку продуктів утилізації (крім відходів і брухту дорогоцінних металів та дорогоцінного каміння).

Зазначені підприємства можуть реалізувати в установленому законодавством порядку продукти утилізації військового майна на зовнішньому ринку за умови, якщо їх подальше застосування в галузях національної економіки неможливе.

2. Встановити, що дія цієї постанови не поширюється на заходи та роботи, пов'язані з комплексною утилізацією звичайних видів боєприпасів, непридатних для подальшого використання і зберігання, та вибухових речовин.

3. Визнати такими, що втратили чинність, розпорядження Кабінету Міністрів України від 4 лютого 1998 р. N 59 ( 59-98-р ) і від 30 березня 2000 р. N 157 ( 157-2000-р ) (Офіційний вісник України, 2000 р., N 14, ст. 570).
