Текст документа від 01.01.2013:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 31 травня 2006 р. N 768 Київ

Про внесення змін до постанов Кабінету Міністрів України від 26 лютого 1993 р. N 143 і від 30 березня 1998 р. N 383

{ Із змінами, внесеними згідно з Постановою КМ N 1193 ( 1193-2012-п ) від 26.12.2012 }

Кабінет Міністрів України постановляє:

1. Внести до постанов Кабінету Міністрів України від 26 лютого 1993 р. N 143 ( 143-93-п ) "Про порядок справляння і розміри збору за реєстрацію об'єднань громадян" (ЗП України, 1993 р., N 7, ст. 147; 1994 р., N 6, ст. 155; 1996 р., N 3, ст. 361; Офіційний вісник України, 2005 р., N 34, ст. 2046) і від 30 березня 1998 р. N 383 ( 383-98-п ) "Про розміри і порядок справляння плати за державну реєстрацію благодійних організацій" (Офіційний вісник України, 1998 р., N 13, ст. 487; 2002 р., N 47, ст. 2133) зміни, що додаються.

2. Ця постанова набирає чинності з 1 січня 2007 року.

Прем'єр-міністр України Ю.ЄХАНУРОВ

Інд. 51

ЗАТВЕРДЖЕНО постановою Кабінету Міністрів України від 31 травня 2006 р. N 768

ЗМІНИ, що вносяться до постанов Кабінету Міністрів України від 26 лютого 1993 р. N 143 ( 143-93-п ) і від 30 березня 1998 р. N 383 ( 383-98-п )

{ Пункт 1 втратив чинність на підставі Постанови КМ N 1193 ( 1193-2012-п ) від 26.12.2012 }

2. Пункт 1 постанови Кабінету Міністрів України від 30 березня 1998 р. N 383 ( 383-98-п ) викласти у такій редакції:

"1. Установити такі розміри плати за державну реєстрацію благодійних організацій:

всеукраїнських - 1 неоподатковуваний мінімум доходів громадян;

міжнародних - 1,5 неоподатковуваного мінімуму доходів громадян;

місцевих благодійних організацій, а також відділень, філій, представництв всеукраїнських, міжнародних благодійних організацій - 0,5 неоподатковуваного мінімуму доходів громадян".
