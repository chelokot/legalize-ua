Про склад робочої групи з розроблення проектів Стратегії забезпечення економічної безпеки України та Національної програми забезпечення економічної безпеки України на період до 2005 року

Стан: Втратив чинність

Ідентифікатор: 345-98-р

Текст документа від 18.08.2005:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 25 травня 1998 р. N 345-р Київ

( Розпорядження втратило чинність на підставі Постанови КМ N 753 ( 753-2005-п ) від 18.08.2005 )

Про склад робочої групи з розроблення проектів Стратегії забезпечення економічної безпеки України та Національної програми забезпечення економічної безпеки України на період до 2005 року

( Із змінами, внесеними згідно з Розпорядженням КМ N 492-р ( 492-2000-р ) від 13.12.2000 )

1. З метою розроблення проекту Національної програми забезпечення економічної безпеки України на період до 2005 року створити робочу групу у складі згідно з додатком. ( Абзац перший пункту 1 із змінами, внесеними згідно з Розпорядженням КМ N 492-р ( 492-2000-р ) від 13.12.2000 )

Надати право керівнику робочої групи вносити зміни до її персонального складу.

2. Робочій групі підготувати і подати на розгляд Кабінету Міністрів України:

до 15 серпня 1998 року проект Стратегії забезпечення економічної безпеки України з відповідними рекомендаціями щодо її практичного застосування;

до 15 жовтня 1998 року проект Національної програми забезпечення економічної безпеки України на період до 2005 року.

3. Контроль за виконанням цього розпорядження покласти на Віце-прем'єр-міністра України з питань економіки Тігіпка С.Л.
