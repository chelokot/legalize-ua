КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 14 жовтня 1999 р. N 1899 Київ

{ Позначку "Не для друку" знято Розпорядженням КМ N 490-р ( 490-2008-р ) від 19.03.2008 }

Про погашення заборгованості із заробітної плати працівникам енергокомпаній

{ Із змінами, внесеними згідно з Постановами КМ N 84 ( 84-2000-п ) від 21.01.2000 N 116 ( 116-2000-п ) від 25.01.2000 }

З метою забезпечення своєчасних розрахунків за спожиту установами і організаціями, які фінансуються з державного бюджету, електричну та теплову енергію і погашення заборгованості із заробітної плати працівникам енергогенеруючих компаній та Національної енергетичної компанії "Укренерго" Кабінет Міністрів України постановляє:

1. Міністерству енергетики залучити в установленому порядку кредити комерційних банків на суму 90 млн. гривень під гарантію погашення цих кредитів та відсотків за їх використання Міністерством фінансів до кінця II кварталу 2000 р. за рахунок коштів, що передбачаються у Державному бюджеті України на 2000 рік для оплати електричної та теплової енергії, спожитої установами і організаціями, які фінансуються з державного бюджету.

{ Пункт 1 із змінами, внесеними згідно з Постановою КМ N 84 ( 84-2000-п ) від 21.01.2000 }

2. Дозволити Міністерству фінансів у межах суми, зазначеної у пункті 1 цієї постанови, перерахувати кошти, передбачені для оплати спожитої установами і організаціями, які фінансуються з державного бюджету, електричної та теплової енергії, централізовано на спеціальний рахунок Міністерства палива та енергетики.

Міністерству палива та енергетики укладати кредитні угоди з комерційними банками з урахуванням коштів, отриманих з державного бюджету відповідно до цієї постанови.

{ Пункт 2 в редакції Постанови КМ N 116 ( 116-2000-п ) від 25.01.2000 }

3. Контроль за виконанням цієї постанови покласти на Першого віце-прем'єр-міністра України Кінаха А.К.
