Про затвердження робочого проекту та титулу будови "Створення глибоководного суднового ходу р. Дунай - Чорне море на українській ділянці дельти. Повний розвиток"

Стан: Чинний

Ідентифікатор: 351-2007-р

Текст документа від 11.11.2009:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

РОЗПОРЯДЖЕННЯ від 30 травня 2007 р. N 351-р Київ

Про затвердження робочого проекту та титулу будови "Створення глибоководного суднового ходу р. Дунай - Чорне море на українській ділянці дельти. Повний розвиток"

{ Із змінами, внесеними згідно з Розпорядженням КМ N 1346-р ( 1346-2009-р ) від 11.11.2009 }

1. Затвердити поданий Мінтрансзв'язку робочий проект "Створення глибоководного суднового ходу р. Дунай - Чорне море на українській ділянці дельти. Повний розвиток", рекомендований до затвердження Центральною службою Укрінвестекспертизи Міністерства регіонального розвитку та будівництва, з такими основними показниками:

протяжність суднового ходу - 172,36 кілометра

протяжність морського підхідного - 3,432 кілометра

каналу

проектна осадка суден - 7,2 метра

загальна кошторисна вартість - 543453,595 тис. гривень

у тому числі:

будівельно-монтажні роботи - 367753,305 тис. гривень

устатковання та інвентар - 2753,889 тис. гривень

інші витрати - 172946,401 тис. гривень

тривалість будівництва - 22 місяці.

{ Пункт 2 втратив чинність на підставі Розпорядження КМ N 1346-р ( 1346-2009-р ) від 11.11.2009 }

3. Врахувати рекомендації Комісії із запиту, створеної відповідно до пункту 7 статті 3 Конвенції про оцінку впливу на навколишнє середовище в транскордонному контексті ( 995_272 ) (Еспо, Фінляндія, 25 лютого 1991 р.), під час реалізації робочого проекту.
