Стан: Чинний

Текст документа від 24.02.2020:

КАБІНЕТ МІНІСТРІВ УКРАЇНИ

ПОСТАНОВА від 17 червня 2009 р. N 681 Київ

Питання управління Державною іпотечною установою

{ Із змінами, внесеними згідно з Постановою КМ N 1054 ( 1054-2019-п ) від 18.12.2019 }

Кабінет Міністрів України постановляє:

{ Пункт 1 втратив чинність на підставі Постанови КМ N 1054 ( 1054-2019-п ) від 18.12.2019 }

2. Внести до постанов Кабінету Міністрів України такі зміни:

у пункті 1 постанови Кабінету Міністрів України від 8 жовтня 2004 р. N 1330 ( 1330-2004-п ) "Деякі питання Державної іпотечної установи" (Офіційний вісник України, 2004 р., N 41, ст. 2709; 2008 р., N 6, ст. 148) слова "з віднесенням її до сфери управління Міністерства фінансів" виключити;

абзац перший пункту 2 постанови Кабінету Міністрів України від 23 січня 2008 р. N 23 ( 23-2008-п ) "Про деякі питання Державної іпотечної установи" (Офіційний вісник України, 2008 р., N 6, ст. 148; 2009 р., N 32, ст. 1075) виключити.

3. Державній іпотечній установі у тижневий строк внести в установленому порядку на розгляд Кабінету Міністрів України:

проект Статуту Державної іпотечної установи;

проект положення про наглядову раду Державної іпотечної установи та пропозиції щодо її персонального складу.
