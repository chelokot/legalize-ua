Про затвердження Переліку пунктів пропуску через митний кордон України для автомобільного сполучення, через які здійснюється переміщення транспортних засобів

Реєстрація: Мін'юст України від 15.02.2002 № 150/6438

Стан: Втратив чинність

Ідентифікатор: z0150-02

Текст документа від 09.08.2002:

ДЕРЖАВНА МИТНА СЛУЖБА УКРАЇНИ

НАКАЗ

N 57 від 31.01.2002 Зареєстровано в Міністерстві м.Київ юстиції України 15 лютого 2002 р. за N 150/6438

Про затвердження Переліку пунктів пропуску через митний кордон України для автомобільного сполучення, через які здійснюється переміщення транспортних засобів

( Із змінами, внесеними згідно з Наказом Державної митної служби N 392 ( z0646-02 ) від 25.07.2002 )

( У назві й тексті Наказу, назві Переліку слова "пункти пропуску через митний кордон України" у всіх відмінках доповнено словами "для автомобільного сполучення" згідно з Наказом Державної митної служби N 392 ( z0646-02 ) від 25.07.2002 )

На виконання вимог Митного кодексу України ( 1970-12 ), з урахуванням спроможностей пунктів пропуску через митний кордон України для автомобільного сполучення й з метою вдосконалення порядку здійснення митного контролю та митного оформлення транспортних засобів за кодами 8701, 8702, 8703, 8704, 8705 ( 2371г-14 ) згідно з Українською класифікацією товарів зовнішньоекономічної діяльності (УКТ ЗЕД), що ввозяться громадянами в Україну для вільного використання, переміщуються транзитом через територію України, а також тимчасово ввозяться на митну територію України громадянами-резидентами, НАКАЗУЮ:

1. Затвердити Перелік пунктів пропуску через митний кордон України для автомобільного сполучення, через які здійснюється переміщення транспортних засобів за кодами 8701, 8702, 8703, 8704, 8705 ( 2371г-14 ) згідно з Українською класифікацією товарів зовнішньоекономічної діяльності (УКТ ЗЕД), що переміщуються громадянами з метою вільного використання на митній території України, транзиту через територію України, а також тимчасово ввозяться на митну територію України громадянами-резидентами (додається).

2. Інформаційно-аналітичному митному управлінню (Копосов С.А.) забезпечити внесення відповідних змін до програмного забезпечення.

3. Управлінню організації митного контролю (Терещенко С.С.) та Правовому управлінню (Мельник М.В.) забезпечити подання цього наказу на державну реєстрацію до Міністерства юстиції України.

4. Управлінню аналізу, прогнозування та зв'язків з громадськістю (Козик Л.Г.) забезпечити висвітлення цього наказу в засобах масової інформації.

5. Управлінню міждержавних зв'язків (Зарудний С.М.) інформувати митні органи суміжних з Україною держав про вимоги цього наказу.

6. Управлінню справами (Карпенко В.П.) після державної реєстрації наказу в Міністерстві юстиції України забезпечити тиражування та розсилку його в митниці, Міністерство внутрішніх справ України, Міністерство закордонних справ України, Держкомкордон України.

7. Начальникам митниць проінформувати громадян та зацікавлені організації про вимоги цього наказу, у тому числі шляхом висвітлення його в місцевих засобах масової інформації та на наочних інформаційних стендах у місцях розташування відповідних підрозділів митниці й у пунктах пропуску через митний кордон України. ( Пункт 7 в редакції Наказу Державної митної служби N 392 ( z0646-02 ) від 25.07.2002 )

8. Цей наказ набирає чинності через 10 днів після державної реєстрації його в Міністерстві юстиції України.

9. Контроль за виконанням наказу покласти на заступника Голови Служби Пашка П.В.

Голова Служби М.М.Каленський
