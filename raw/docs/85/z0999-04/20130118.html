Держфінпослуг; Розпорядження від 24.06.2004 № 1224

Щодо порядку внесення інформації про страховиків до Державного реєстру фінансових установ

Реєстрація: Мін'юст України від 10.08.2004 № 999/9598

Стан: Втратив чинність

Ідентифікатор: z0999-04

Текст документа від 18.01.2013:

ДЕРЖАВНА КОМІСІЯ З РЕГУЛЮВАННЯ РИНКІВ ФІНАНСОВИХ ПОСЛУГ УКРАЇНИ

РОЗПОРЯДЖЕННЯ

24.06.2004 N 1224

Зареєстровано в Міністерстві юстиції України 10 серпня 2004 р. за N 999/9598

Щодо порядку внесення інформації про страховиків до Державного реєстру фінансових установ

{ Із змінами, внесеними згідно з Розпорядженням Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг

N 2421 ( z2172-12 ) від 27.11.2012 }

Відповідно до Положення про Державний реєстр фінансових установ, затвердженого розпорядженням Державної комісії з регулювання ринків фінансових послуг України (далі - Держфінпослуг) від 28 серпня 2003 року N 41 ( z0797-03 ), зареєстрованого у Міністерстві юстиції України 11 вересня 2003 року за N 797/8118 (із змінами і доповненнями), та враховуючи те, що розпорядженням Держфінпослуг від 5 грудня 2003 року N 155 ( z1208-03 ) "Про Єдиний державний реєстр страховиків (перестраховиків) України", зареєстрованим у Міністерстві юстиції України 23 грудня 2003 року за N 1208/8529, Єдиний державний реєстр страховиків (перестраховиків) України визначено складовою частиною Державного реєстру фінансових установ, Державна комісія з регулювання ринків фінансових послуг України ПОСТАНОВИЛА:

1. Юридичному управлінню (Ткаченко Д.В.) та Департаменту страхового нагляду (Парнюк В.О.) до 22 вересня 2004 року забезпечити внесення до Державного реєстру фінансових установ (далі - Реєстр) інформації про страховиків, щодо яких уже внесено інформацію до Єдиного державного реєстру страховиків (перестраховиків) України.

2. Департаменту страхового нагляду (Парнюк В.О.) провести звірку інформації про страховиків, яка міститься в Єдиному державному реєстрі страховиків (перестраховиків) України, з інформацією, яку буде внесено до Реєстру, та забезпечити видачу страховикам, унесеним до Реєстру, свідоцтв про реєстрацію фінансової установи.

3. Установити, що після 22 вересня 2004 року юридичні особи, які створені з метою здійснення страхової діяльності, але ще не мають ліцензій на здійснення страхової діяльності, для одержання таких ліцензій можуть подавати документи до Нацкомфінпослуг лише за умов попереднього набуття ними статусу фінансової установи.

Документи для набуття статусу фінансової установи такі юридичні особи повинні подавати, починаючи з 25 серпня 2004 року. { Пункт 3 із змінами, внесеними згідно з Розпорядженням Національної комісії, що здійснює державне регулювання у сфері ринків фінансових послуг N 2421 ( z2172-12 ) від 27.11.2012 }

4. Юридичному управлінню (Ткаченко Д.В.) забезпечити подання цього розпорядження до Міністерства юстиції України для державної реєстрації.

5. Відділу взаємодії із засобами масової інформації та зв'язків з громадськістю забезпечити публікацію цього розпорядження у засобах масової інформації після його державної реєстрації.

6. Контроль за виконанням цього розпорядження залишаю за собою.

Голова Комісії В.Суслов
