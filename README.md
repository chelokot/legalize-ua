# legalize-ua

Законодавство України в git. Зараз тут дзеркало першоджерела: усі редакції нормативних актів з відкритих даних Верховної Ради, як є, без змін. Наступні кроки: розбір у Markdown, історія змін комітами.

## Що в `raw/`

- `raw/dumps/` — щоденні масові вивантаження з [data.rada.gov.ua](https://data.rada.gov.ua/open/data/zak): картки всіх документів (`doc.txt`), усі редакції (`doc-update.txt`) і довідники (види, стани, видавники, події, відношення). Кодування cp1251, поля через табуляцію.
- `raw/docs/<xx>/<nreg>/<YYYYMMDD>.html` — HTML кожної редакції з API Ради. `<nreg>` — системний номер документа в URL-кодуванні, `<xx>` — перші два символи sha1 від `nreg`.
- `raw/manifest/<xx>.tsv` — що завантажено: дата редакції, позначка зміни від Ради, HTTP-статус, sha256, розмір, час завантаження.

## Як оновлюється

Workflow `Fetch Rada` запускається щодня і вручну. Він виходить в інтернет з української IP-адреси, завантажує свіжі вивантаження, порівнює їх з маніфестом і докачує лише нові або змінені редакції, приблизно один запит на секунду. Результат комітиться пакетами. Повторний запуск продовжує з місця зупинки.

Джерело: [Верховна Рада України](https://zakon.rada.gov.ua), відкриті дані використовуються з обов'язковим посиланням на джерело.
